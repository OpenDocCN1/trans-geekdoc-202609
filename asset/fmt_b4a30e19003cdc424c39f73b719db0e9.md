
# 受限玻尔兹曼机与深度网络

## 受限玻尔兹曼机（RBM）

受限玻尔兹曼机（RBM）是一种基于能量的双部图模型，通过对称无向边由两个全连接层组成，但同一层中的单元之间没有连接。第一层由 $m$ 个可见单元 $v = (v_1, v_2, \dots, v_m)$ 组成，表示观测数据；第二层由 $n$ 个隐藏单元 $h = (h_1, h_2, \dots, h_n)$ 组成，可以是非线性特征检测器以捕捉观测数据中的高阶相关性。此外，$W = \{w_{ij}, w_{i2}, \dots, w_{mn}\}$ 是可见单元和隐藏单元之间的连接权重矩阵。典型的 RBM 结构如图 4-2 (a) 所示。

标准 RBM 设计仅用于二进制随机单元（BRBM）。然而，使用二进制单元不适用于实值数据（例如图像中的像素强度值）。因此，开发了一种名为高斯 RBM（GRBM）的新模型来解决标准 RBM 的这一局限性 [49]。GRBM 的能量函数定义为：

```
$E(v,h) = -\sum_{i,j} w_{ij}v_ih_j - \sum_{i=1}^m \frac{(v_i-b_i)^2}{2\sigma_i^2} - \sum_{j=1}^n c_jh_j \quad (4.1)$
```

$\sigma_i$ 是可见单元 $v_i$ 的高斯噪声的标准差，$w_{ij}$ 代表可见单元 $v_i$ 和隐藏单元 $h_j$ 的权重，$b_i$ 和 $c_j$ 分别是可见单元和隐藏单元的偏置。给定隐藏单元时可见单元的条件概率，以及反之隐藏单元的条件概率定义如下：

```
$p(v_i=1|h) = N\left(v|b_i+\sum_{j}w_{i,j}h_j,\sigma_i^2\right) \quad (4.2)$
```

```
$p(h_j=1|v) = f\left(c_j+\sum_{i}w_{i,j}v_i,\sigma_j^2\right) \quad (4.3)$
```

在这里，$N(\mu,\sigma^2)$ 指均值为 $\mu$、标准差为 $\sigma$ 的高斯概率密度，$f(x)$ 是 sigmoid 函数。在训练过程中，使用随机梯度下降最大化训练数据的似然性，参数的更新规则定义：

```
$\Delta w_{i,j} = \epsilon\left(\frac{1}{\sigma_i^2}v_ih_j\right)_{data} - \left(\frac{1}{\sigma_i^2}v_ih_j\right)_{model} \quad (4.4)$
```

```
$\Delta b_i = \epsilon\left(\frac{1}{\sigma_i^2}v_i\right)_{data} - \left(\frac{1}{\sigma_i^2}v_i\right)_{model} \quad (4.5)$
```

```
$\Delta c_j = \epsilon\left(\langle h_j\rangle_{data} - \langle h_j\rangle_{model}\right) \quad (4.6)$
```

在这里，$\epsilon$ 是学习率，$\langle\cdot\rangle_{data}$ 和 $\langle\cdot\rangle_{model}$ 分别代表输入数据（正相）和 RBM 模型（负相）的期望，$b_i$ 和 $c_j$ 分别是可见单元和隐藏单元的偏置。关于 GRBM 的更多细节见 [49]。

通常，RBM 可以两种方式使用：作为生成模型或判别模型，如图 4.2 所示。生成模型使用一层隐藏单元对可见单元的分布进行建模。此类模型是无监督训练的，并作为特征提取器使用。另一方面，判别模型可以对输入数据和相关类别的联合分布进行建模。判别模型使用具有两层可见单元的 RBM 进行训练，第一层表示输入数据，第二层表示目标类别的 Softmax 层。具有 $n$ 个隐藏单元的判别 RBM 是隐藏单元（称为特征）$\mathbf{h}=(h_1, h_2, \dots, h_n)$ 与输入数据的可见单元 $\mathbf{v}=(v_1, v_2, \dots, v_m)$ 以及目标 $\mathbf{y}\in\{1, 2, \dots, C\}$ 之间联合分布的参数模型，其定义为：

```
$p(\mathbf{y},\mathbf{v},\mathbf{h}) \propto e^{-E(\mathbf{y},\mathbf{v},\mathbf{h})} \quad (4.7)$
```

```
$E(y,v,h) = -h^T Wv - b^T v - c^T h - d^T \tilde{y} - h^T Uy \quad (4.8)$
```

在这里，$(W, b, c, d, U)$ 指模型参数，$\tilde{y} = (y_{i-1})_{i=1}^C$ 对应 $C$ 个类。关于判别 RBM 模型的更多细节见 [50]。

## 4.3.3 深度信念网络

深度信念网络（DBN）是一种与传统判别神经网络不同的生成概率模型。DBN 由一个可见层（观测数据）和能够学习前一层单元之间统计关系的隐藏层组成。它们对输入数据（观测值）和标签的联合概率分布建模，这有助于 P(Observations | Labels) 和 P(Labels | Observations) 的估计，而传统神经网络仅限于后者 [51]。提出 DBN 是为了解决在深层神经网络上应用反传播算法时遇到的问题，包括：

1. 训练阶段对标记数据集的限制。
2. 收敛所需时间长（学习过程慢）。
3. 陷入不良局部最优的自由参数数量增加。

如图 4.2 所示，DBN 可以被视为双部无向图模型的组合，每一个都是一个 RBM。DBN 可以使用无监督贪婪算法进行高效训练，如图 4.2(c) 所示。

根据 Hinton 等人 [52] 提出的贪婪层训练算法，第一个 RBM 使用 CD 算法从可见单元学习一层特征表示 $(h_1)$，如第 4.1.2 节所述。第一个 RBM 的隐藏单元 $(h_1)$ 被用作可见单元训练第二个 RBM。当最后一层的学习完成后，整个 DBN 训练完成。具有 $L$ 层的 DBN 可以如下建模观测数据向量 $v$ 和 $L$ 个隐藏层 $h_k$ 之间的联合分布：

```
$P(v, h^0, ..., h^L) = \left( \prod_{k=0}^L P(h^k | h^{k-1}) \right) P(h^{-1}, h^0) \quad (4.9)$
```

在这里，$v = h^0$，$P(h^k | h^{k-1})$ 是与 DBN 第 $k$ 层相关的 RBM 可见单元隐藏单元的条件分布，而 $P(h^{-1}, h^0)$ 是顶层 RBM 中的可见-隐藏联合分布。三层 DBN 作为生成模型的示例如图 4.2 (d) 所示，其中引入了符号 $Q$ 表示其精确或近似后验概率，这些概率被用于自下而上的推理。在底部 $Q$ 处，所有的后验概率都是近似的，除了顶层的 $P(h^l|h^{l-1})$，后者是由 RBM 构建的，从而使得该效应成为可能。深度置信网络（DBN）被认为是最流行的无监督学习方法之一，已成功应用于广泛领域（例如：人脸识别 [13]、语音识别 [14]、音频分类 [15] 等）。DBN 主要问题之一是它学习的特征表示对输入图像的局部偏移非常敏感，特别是当像素强度值（原始数据）直接分配给可见单元时。这可能导致输入图像的局部特征（已知这些特征对人脸识别很重要）被忽略。

## 4.3.4 卷积神经网络

卷积神经网络（CNN）是一种前馈多层神经网络，它与传统的全连接网络不同，通过在自动特征识别阶段结合了多个局部连接层，并在分类阶段使用了多个全连接层 [51]。如图 4.3 所示，CNN 架构由几个不同的层组成：多组局部连接层（每层包含若干个可学习内核）、下采样池化层以及一个或多个连接层。CNN 的内部结构与三个架构概念相关，这使得 CNN 在解决图像处理、计算机视觉和模式识别中的不同问题上取得了成功。

第一个概念同时应用于卷积层和池化层，其中每个神经元接收来自上一层一小区域的输入，该区域被称为局部感受野，其尺寸与卷积核相等 [53]。这种局部连接方案确保了 CNN 能够产生响应以捕捉局部依赖关系，并提取输入图像中的基础特征（例如边缘、曲线等），这些特征对于最小化类内差异和类间相似性、增强所学习的人脸特征表示的判别能力起着重要作用。

其次，卷积层通过应用共享参数（权重）来控制模型容量并降低了其复杂性。此时，通过使用相同的卷积核在人脸图像的不同位置检测特定特征，获得了一种形式的平移不变性 [54]。

最后，应用池化层中的非线性下采样减小了卷积层输出的空间尺寸，并减少了模型的自由参数数量。这些特征共同使得 CNN 在处理图像变形和其他几何变换（如平移、旋转和缩放）时变得非常稳健且高效 [51]。关于 CNN 的更多细节可以参阅文献 [55]。

# 4.4 提出的方法

如图 4.4 所示，提出了一种名为 FaceDeepNet 的新型多生物识别人脸识别系统，该系统旨在通过在从 FDT 方法获取的局部人脸特征表示（而非像素强度表示）之上训练所提出的深度学习方法（例如 CNN 和 DBN），来学习高级人脸特征表示。首先，详细描述所提出的 FDT-DRBM 方法的主要阶段。随后描述如何在现有的局部特征表示之上应用 FaceDeepNet 系统来学习额外的、互补的表示。

## 4.4.1 提出的 FDT-DRBM 方法

所提出的人脸识别算法首先使用 Viola-Jones 人脸检测器检测脸部区域 [56]。然后，在将输入图像 $f(x, y)$ 缩放到 $[0, 1]$ 范围后，应用 sigmoid 函数的简单预处理算法如下：

```
g(x,y) = \frac{1}{1+e^{(Th-f(x,y))}} (4.10)
```

$g(x, y)$ 是增强后的图像。对比度因子 (c) 和阈值 (Th) 分别实验设置为 5 和 0.3。如图 4.5 所示，sigmoid 函数的优势通过分别扩展和压缩人脸图像黑暗和明亮像素的值范围，减少光照变化的影响。随后，使用所提出的 FDT 方法估计增强后人脸图像中每个像素的分形维度值。如上所述，分形维度具有许多重要特性，例如反映人脸图像表面粗糙度和波动的能力，以及表示不同环境条件下（如光照变化）人脸特征的能力。

然而，分形估计方法非常耗时，无法满足实时性要求 [7]。因此，在检测到脸部区域后，将人脸图像缩放到 (64x64) 像素，以加速实验并满足实时系统的需求。结果被重构为行特征向量 FDTVector，它作为使用 DRBM 的非线性分类器的输入，以高效建模输入和目标类之间的联合分布。在本章中，DRBM 分类器用于判断一对人脸图像是否属于同一个人。接下来的两个章节将详细描述 FDT 和 DRBM 方法。

### 4.4.1.1 分形维度变换

使用所提出的 FDT 方法，将尺寸为 $M \times N$ 的人脸图像通过密度计数 (DBC) 算法转换为分形维度，其中尺寸为 $nx \times ny$ 的内核函数 $f(p, q)$ 应用于整个图像，产生一个表示覆盖每个像素所需的三维矩阵：

```
$N_d(x, y, d)$
```

在这里，$d = (1, 2, 3, \dots, r_{max})$ 是 $N_d(x, y, d)$ 的维度，它代表了应用不同缩放因子 $(r)$ 的内核函数 $f(p, q)$ 生成的特征图数量。这里，缩放因子 $(r)$ 的值实验性选择在 2 到 9 之间。内核函数通过对人脸图像的 $(7 \times 7)$ 相邻像素进行块处理，计算每个像素的分形维度值，如下：

```
$f(p, q) = \sum_{p=a}^b \sum_{q=a}^b \text{floor} \left[ \frac{P_{max} - P_{min}}{r} \right] + 1 \quad (4.12)$
```

在这里，$a$ 和 $b$ 是非负整数变量，用于将内核函数位于人脸图像的每个像素上，定义为 $a$ 和 $b = \text{ceil}((n - 1)/2)$。$P_{max}$ 和 $P_{min}$ 是处理块中相邻像素的最高和最低强度值。内核函数的尺寸是通过实验确定的，注意到增加其尺寸会影响计算出的分形维度的准确性，导致获取的图像变得不清晰，而减小其尺寸可能导致没有足够数量的周围像素来准确计算分形维度值。一旦获得了 $N_d(x, y, d)$ 矩阵，每个元素 $N_d(x, y, d)$ 中的每个数组都将存储在一个新的行向量 $(V)$ 中。换句话说，$N_d(x, y, d)$ 中所有数组的第一个元素将组成向量 $(V_1)$，所有的第二个元素将组成 $(V_2)$，如下：

```
$$\begin{pmatrix} P_{11} & P_{12} & \dots & P_{1rmax} \\ P_{21} & P_{22} & \dots & P_{2rmax} \\ \vdots & \vdots & \ddots & \vdots \\ P_{M1} & P_{M2} & \dots & P_{Mrmax} \end{pmatrix} = \begin{pmatrix} V_1 \\ V_2 \\ \vdots \\ V_{M \times N} \end{pmatrix} $$ (4.13)
```

最后，每个像素 $(x, y)$ 处的分形维度值通过其最小二乘法线性回归线的分形斜率计算得出：

```
$$FD(x, y) = \frac{S_t(x, y)}{S_r} $$ (4.14)
```

在这里，$(S_t)$ 和 $(S_r)$ 是平方和，计算方式如下：

```
$$S_t(x, y) = \sum_{r=1}^{j} \log(r)(V_{(x,y),r}) \left( \sum_{r=1}^{j} V_{(x,y),r} \right)^j $$ (4.15)
```

```
$$S_r(x, y) = \sum_{r=1}^{j} (\log(r))^2 $$ (4.16)
```

在这里，$j=r_{max} - 1$，图 4.6 展示了分形变换后的脸部图像。

### 4.4.1.2 判别性受限玻尔兹曼机

在分类阶段，一个具有两组单元的单一 RBM 被训练为非线性分类器，以高效地对输入和目标类进行联合建模。除了表示数据向量的可见单元外，还有一个表示预测类别的 softmax 标签单元。训练完成后，系统会尝试每一个可能的标签，并选择能量最低的标签作为最可能的类别。正如文献所示，计算等式 4.4 中的 $v_jmodel$ 是不可行的。因此，对比散度（CD）算法 [59] 成为一种标准的学习方法，该方法通过从 RBM 中采样 $k$ 步来近似等式 4.4 中的第二项，从而更新 RBM。高效的训练需要优化的训练参数（例如：学习率、权重代价、动量、权重的初始值、每个 mini-batch 的大小、隐藏单元的数量等）。还需要做出其他决策，包括使用的隐藏单元类型、每个轮（epoch）更新隐藏单元二值状态的次数、如何监控学习进度以及如何终止训练过程。单个样本的 CD 算法步骤可以实现如下：

1. 使用训练数据初始化可见单元 ($v_i$)，并使用等式 4.2 计算隐藏单元的概率。然后，从该概率分布中采样隐藏激活向量 ($h_j$)。
2. 计算 $(v_i)$ 和 $(h_j)$ 的外积，这称为正相。
3. 根据等式 4.3 从 $(h_j)$ 采样可见单元的重构 ($v'_i$)，并从 $(v'_i)$ 采样隐藏单元激活 ($h'_j$)。（一次 Gibbs 采样。）
4. 计算 $(v'_i)$ 和 $(h'_j)$ 的外积，这称为负相。
5. 使用等式 4.4、等式 4.5 和等式 4.6 更新权重矩阵和偏置。

CD-1 算法的计算步骤如图 4.7 所示。在 CD 学习算法中，对于许多应用，$k$ 通常被设置为 1。权重使用从均值为零的正态分布采样的小随机值初始化，标准差为 0.02。在正相中，通过计算可见单元的概率来确定隐藏单元的二值状态。由于训练数据在该阶段的概率增加，因此被称为正相。同时，在负相期间，模型生成的样本概率会降低。一个完整的正负相过程被视为一个轮（epoch），在每个轮结束时，计算模型生成的样本与实际数据向量之间的误差。最后，通过对可见单元概率关于权重求导来更新所有权重，这是正相贡献与负相贡献差的期望。算法 1 显示了使用 CD 算法训练 DRBM 分类器的伪代码过程。

**算法 1. 寻找最优 DRBM 分类器**
输入：训练集 $(x_n, y_n)$ 和测试集 $(x_t, y_t)$。
输出：最优 $h$。
初始化：$h=now$，学习率=0.002，权重代价=0.9，动量=0，轮数=300。
