## 数字的存储

存储的细节不在 AP 考试测试范围内。然而，它们有助于理解 `int` 和 `double` 类型之间的差异。

### 整数

Java 中的整数值精确存储，作为一串位（二进制数字）。其中一位存储整数的符号：0 表示正数，1 表示负数。

Java 内置整数类型 `byte` 使用一个字节（八位）存储。

![images](img/f066-07.jpg)

该图表示使用 `byte` 类型可以存储的最大正整数：2⁷ − 1。

Java 中的 `int` 类型使用四个字节（32 位）。留出一位作为符号位，可以存储的最大整数是 2³¹ − 1。一般来说，*n* 位整数使用 *n*/8 个字节存储，存储范围从 −2^(*n*−1) 到 2^(*n*−1) − 1。（注意负数多出的一个值来自于不需要存储 −0。）有两个你应该知道的 Java 常量。`Integer.MAX_VALUE` 保存 `int` 能容纳的最大值，即 2³¹ − 1。`Integer.MIN_VALUE` 保存 `int` 能容纳的最小值，即 −2³¹。

Java 内置整数类型有 `byte`（一个字节）、`short`（两个字节）、`int`（四个字节）和 `long`（八个字节）。其中，只有 `int` 在 AP Java 考试大纲范围内。

### 浮点数

Java 中有两种存储实数的内置类型：`float`（使用四个字节）和 `double`（使用八个字节）。**浮点数** 存储在两部分中：一个**尾数**，指定数字的数字；和一个指数。JVM（Java 虚拟机）使用科学计数法表示该数字：

![images](img/f067-01.jpg)

在这个表达式中，2 是该数字的**基数**或**底数**。在 `double` 类型中，11 位分配给指数，（通常）52 位分配给尾数。一位分配给符号。这是一个**双精度**数字。`float` 类型是**单精度**的，不在 AP Java 考试大纲范围内。

当浮点数转换为二进制时，大多数不能精确表示，导致**舍入误差**。这些误差会因算术运算而累积。例如：

![images](img/f067-02.jpg)

*   当执行的操作产生未定义结果时，Java 将此结果表示为 `NaN`，“非数字”。产生 `NaN` 的操作示例包括：对负数取平方根，以及 0.0 除以 0.0。
*   产生无限大或无限小数字的操作（如除以零），在 Java 中产生 `Infinity` 或 `-Infinity` 结果。

## 控制结构

控制结构是使程序语句按非顺序顺序运行的机制。主要有两种类型：决策制定和迭代。

#### 选择控制结构

这些包括 `if`、`if...else` 和 `switch` 语句。它们都是选择控制结构，为程序引入了决策能力。基于布尔表达式的真值，计算机将决定遵循哪条路径。`switch` 语句不属于 AP Java 考纲范围。
