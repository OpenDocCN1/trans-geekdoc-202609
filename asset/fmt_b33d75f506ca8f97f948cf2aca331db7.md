```python

```

## 在 Python 中创建自定义迭代器

另一方面，`__next__()` 会扫描并给出序列中的下一个元素，并在到达末尾时触发 `StopIteration` 异常。

### 示例

```python
class Power:
    """将实现 2 的幂"""
    def __init__(self, max=0):
        self.max = max

    def __iter__(self):
        self.m = 0
        return self

    def __next__(self):
        if self.m <= self.max:
            result = 2 ** self.m
            self.m += 1
            return result
        else:
            raise StopIteration
```
