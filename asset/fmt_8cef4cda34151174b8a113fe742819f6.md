# I 引言

加速发现具有所需性能的材料是计算化学和材料科学中长期面临的挑战。在探索海量化学空间时，精确量子化学计算的成本被证明是难以企及的。近年来，人们不断努力使用机器学习来克服这一瓶颈，除非一组简化的描述符允许我们准确地预测化学性质1–15或势能面16–25。虽然这些方法使用了费力手工构建的描述符，但深度学习已经能够利用图神经网络从分子结构预测性质。27。然而，由于缺乏平衡态下的原子位置，这些方法仅限于电子结构。最近，开发了从原子类型和位置中学习取向的模型。28–30。虽然神经网络通常被认为是“黑箱”，但最近人们投入了更多努力来解释其预测结果，以理解其运行机制。这可以通过训练模型31或直接设计具有可解释性的模型来实现。对于量子化学，我们中的一些人已经提出了这种基于深度张量神经网络（DNNs）的架构，不仅能够学习原子环境的表示，还能从空间和化学相关的角度为量子力学嵌入提供见解。28

在这里，我们基于这项工作，介绍了深度学习架构 SchNet，它允许通过对复杂的相互作用进行建模，以预测势能面或加速化学空间的探索。在 DNNs 中，SchNet 还能通过构造表示遵循原子系统基本对称性（构造不变性、旋转和平移不变性以及原子索引的不不变性）的分子和材料。这些方法在没有进一步约束的情况下预测完整的构型，并且势能面使用连续滤波器（卷积层）39 进行建模，通过专门设计的滤波器神经网络变得更具解释性。我们证明了所有这些方法都允许我们引入周期性边界条件（PBCs），从而实现对多种体相晶体力和和能量的准确预测。SchNet 和 DNNs 都提供了局部化学势，并提供了新的表示见解。28。对所得表示的分析表明，SchNet 学习了化学合理的原子类型嵌入，捕捉了周期表的结构。最后，我们使用由 SchNet 在化学经典数据上训练的能量守恒场，进行路径积分动力学（PIMD）模拟。

## C. 相互作用层

SchNet 的相互作用层根据与周围原子的两对相互作用精炼原子表示。在这里，我们使用连续滤波器层（连续操作的推广，例如高斯函数或径向基函数）对此进行建模。这是必要的，因为原子并不位于规则网格上，而是可以位于任意位置。因此，像卷积层那样使用滤波器张量是不可行的。我们需要逐逐地建模滤波器

原子系统可以由一组 $n$ 个原子描述，其电荷 $Z = (Z_1, \dots, Z_n)$ 和位置 $R = (r_1, \dots, r_n)$。SchNet 的层由特征图元组 $X^l = (x_1^l, \dots, x_n^l)$ 描述，其中 $x_i^l$ 的特征图数量为 $F$

带有原子级层的滤波器层构建了相互作用块的残差映射（见图 i）。我们在整个网络中使用偏移的 softplus 函数 $softplus(x - 0.5) + 0.5$ 作为激活函数。偏移确保了 $softplus(0)=0$ 和网络的收敛，同时具有无限阶的连接性。这使我们能够平滑势能面、力以及用于力训练所需的二阶导数以及振动模式。

### 1. 旋转不变性

通过使用相对位置计算对距离来包含旋转不变性是显而易见的。我们在高斯基底中展开距离

```
$e_k(r_i, r_j) = \exp(-\gamma(||r_i - r_j|| - \mu_{ij})^2)$
```

其中心以邻居和距离截断的均匀网格为中心。这具有去相关滤波器值相关性的作用，改善了优化问题的条件数。高斯函数的数量和超参数决定了滤波器的分辨率。对于本工作中的所有模型，我们将网格间距和缩放参数设置为 0.1 $1/\text{\AA}^2$。

### 2. 周期性边界条件

对于具有周期性边界条件（PBCs）的原子，每个原子特征向量 $x_i$ 在所有周期位置上都是等价的，即 $x_i = x_{i+R}$。由于卷积的线性线性，因此我们将 PBCs 应用于滤波器，以准确描述原子相互作用，同时保持对单元选择的不变性。对于跨越滤波器 $W^{(l)}(r_{ij}-r_{ij})$，我们得到卷积

```
$x_i^{(l+1)} = \frac{1}{n_{neighbors}} \sum_{j \in neighbors} x_j^{(l)} \odot W^{(l)}(r_{ij}-r_{ij})$

$x_i^{(l+1)} = \frac{1}{n_{neighbors}} \sum_{j \in neighbors} x_j^{(l)} \odot (W^{(l)}(r_{ij}-r_{ij}))$
```

由于我们在给定的截断范围内对所有周期进行求和，该滤波器 $W$ 现在取决于系统的 PBCs。

最后，分子或材料的性质 $P$ 得于所获得的原子波表示。我们使用全连接预测网络（见图 1）。根据性质是强度型（intensive）还是扩展型（extensive），我们分别通过对原子贡献求和或取平均来计算最终预测值 $P$。

由于内部原子嵌入对原子旋转等变，滤波器独立地应用于每个原子，通过对所有邻居原子的连续滤波器卷积，索引等变性在原子表示中得以保留。因此，作为跨原子权重的性质预测保证了不不变性。

在预测原子作用力时，我们使用 SchNet 根据原子位置预测能量

```
$\hat{E}(Z_1, ..., Z_n, r_{ij1}, ..., r_{ijn}) = \frac{\partial \hat{E}}{\partial r_i}(Z_1, ..., Z_n, r_{ij1}, ..., r_{ijn})$
```

当使用旋转不变的模型时，这确保了旋转等变的力预测，并保证了能量守恒场。$^{21}$

## F. 训练

我们通过最小化平方损失为每个性质目标 $P$ 训练 SchNet

```
$$\ell(P, P) = ||P - P\|^2$$
```

对于分子轨迹的能量和力的训练，我们使用

```
$$\ell((E, F_1, ..., F_n), (\hat{E}, \hat{F}_n)) = \rho ||E - \hat{E}||^2 + \frac{1-\rho}{N_{atoms}} \sum ||F_i - \hat{F}_i||^2 \quad (5)$$
```

其中 $\rho$ 是能量和力损失之间的权衡。所有模型都使用 ADAM 优化器通过小批量随机下降进行训练，批量大小为 32。我们每 100 个 epoch 以 0.996 的比例指数级衰减学习率。在每个实验中，我们将数据划分为给定大小 $N$ 的训练集，并使用验证集进行早停。由于我们预处理了邻近原子的索引，训练步骤中位于给定截断成本范围内的最大原子数量随系统大小线性缩放。
