
每个解码器有两个输入和一个输出。例如，解码器 D1 的第一个输入是形状为 `N×512 × 64²` 的 `skip4`，其第二个输入是 `b`：形状为 `N×1024 × 32²` 的桥接层输出。解码器 D1 首先通过转置卷积算子作用于第二个输入，使转置卷积的输出形状与第一个输入的形状匹配，以便沿通道方向进行拼接。拼接结果是一个形状为 `N×1024 × 64²` 的张量。该张量随后由一个基础块处理以得到 `up1`：D1 的输出，形状为 `N×512 × 64²`。从 Cell 06 中定义的 `Basic` 类可以看出，每个基础块包含两个卷积层。基础块会改变其输入的通道数，而不改变其输入的分辨率。在四个编码器和桥接层中，基础块增加图像通道数；在四个解码器中，基础块减少图像通道数。四个编码器中的四个 `MaxPool2d` 算子将图像尺寸减半。利用四个解码器中的四个转置卷积，我们使 U-Net 输出的分辨率与输入图像的分辨率相匹配。U-Net 输出图像的通道数可以是我们为项目设置的任意整数。例如，如果我们的项目用于分割数据集图像中的 10 个物体，我们 U-Net 的输出图像通道数将为 10，并且我们必须使用交叉熵损失函数进行模型训练。

## 9.2 使用注意力 U-Net 扩散模型生成二次曲线

从噪声开始，去噪扩散概率模型（DDPM）可以生成图像、音频甚至视频，其质量足以以假乱真。DDPM 系统是一种生成模型，由 Jonathan Ho、Ajay Jain 和 Pieter Abbeel 在其 2020 年发表的论文中提出（Ho *et al* 2020）。DDPM 经过训练以寻找给定噪声条件下的清晰图像条件分布函数，并利用该条件分布函数执行去噪任务。DDPM 的原理易于理解。假设你有一张位于装有清水水箱底部的《蒙娜丽莎》图像，你向水箱中的水滴加黑墨水。墨滴极小，两滴之间的时间间隔足够长，以便让每一滴墨水在水箱中充分扩散。滴滴墨水下去，你的图像被墨水颜料加噪，最终在第 1000 滴时，你的图像消失。这是一个前向过程。然后我们使用一种先进工具将墨水从水箱中滴滴取出。当所有 1000 滴墨水都从水箱的水中移除后，我们又能清晰地看到《蒙娜丽莎》。这是一个反向过程或去噪过程。DDPM 反向过程中用于图像生成的先进工具是 U-Net 模型。在使用数据集中的图像训练模型后，该模型可以从纯噪声生成假图像。这些假图像并非数据集中的原始图像，但风格与原始图像相同。例如，如果你用巴勃罗·毕加索的画作训练你的 U-Net 模型，你将获得具有毕加索绘画风格的假图像。去噪扩散概率模型在图像去噪任务中显示出了良好的效果。它们为噪声去除提供了一个概率框架，允许有效处理各种类型的噪声，并生成视觉上令人愉悦的去噪图像。

### 9.2.1 DDPM 中的前向过程

原始图像 `x[0]`（一条二次曲线或一张数字《蒙娜丽莎》图像）是一个具有未知 PDF `q` 的样本：`x[0]∼q(x)`。在前向过程或扩散过程中，来自标准正态分布的噪声被加到 `x[0]` 上以获得具有条件 PDF 的潜在图像 `x[1]`：`q(x[1]∣x[0])`。该前向过程基于方差调度 `0<β[1]<β[2]<⋯<β[T]≪ 1` 逐步进行。方差调度可以是线性、二次、余弦等，就像学习率调度一样。如果时间步 `T` 足够大（∼1000），我们的最终图像 `x[T]` 将是各向同性高斯噪声：`q(x[T]∣x[T−1]) = N(x[T];0,I)`。所有潜在图像 `x[1], …, x[T]` 具有与原始图像 `x[0]` 相同的维度。在时间步 `t`，潜在图像通过 `x_t = √(1 - β_t)x_{t - 1} + √(β_t)ε` 获得，其中 `ε` 是来自与 `x[0]` 维度相同的多元标准正态分布 `N(0,I)` 的样本。时间步 `t` 处潜在图像的 PDF 是由前一时间步 `t`−1 处的潜在图像给出的正态分布

```
q(x_t∣x_{t - 1}) = q(x_t∣x_{t - 1},x_0) = 𝕹(x_t;√(1 - β_t)x_{t - 1},β_tI)
```

(9.1)

我们知道两个独立正态分布的组合仍然是正态分布。如果两个独立正态分布是 `x ∼ 𝕹(x;0,σ₁²)` 和 `y ∼ 𝕹(y;0,σ₂²)`，则有 `z = x + y ∼ 𝕹(z;0,(σ₁²+σ₂²))`。根据这一事实以及 `α[t] = 1 − β[t]`、`ᾱ_t = ∏_{i=1}^t α_i`，时间步 `t` 处的潜在图像 `x_t = √(ᾱ_t)x_0 + √(1 - ᾱ_t)ε` 可以直接通过一个 PDF 从 `x[0]` 获得：

```
q(x_t∣x_0) = 𝕹(x_t;√(ᾱ_t)x_0,(1 - ᾱ_t)I)
```

(9.2)

扩散过程是一个马尔可夫链，具有方程 (9.2) 所示的近似后验概率分布函数。在前向过程结束时，我们得到 `x[T] ∼ q(x[T]∣x[0]) = 𝕹(x[T];0,I)`，即纯噪声。

```
q(x_{1:T}∣x_0) = ∏_{t=1}^T q(x_t∣x_{t - 1}) = q(x_T∣x_{T - 1})…q(x_2∣x_1)q(x_1∣x_0)
```

(9.3)

图 9.4(A) 中的二次曲线被用作原始图像，以在项目 9.2 中演示 DDMP 从噪声生成图像的能力。四千批二次曲线被用于在 DDMP 系统中训练一个 `U-Net` 模型。图 9.4(A) 中的一批二次曲线是由单元格 01-03 中的代码生成的；这些代码在前几章中已被多次使用。每批有 64 条曲线，每条曲线上有 64 个点。正向过程的函数在单元格 04 中定义。该函数的超参数设置在该函数前面。对于这个简单的项目，总正向步数设置为 `T = 200`。模型训练的时间嵌入维度在单元格 04 的第 2 行设置为 100。采用线性调度，beta 值在 200 步内从 0.001 增加到 0.2（单元格 04 第 03 行）。那里还列出了许多其他超参数，例如 `α`、`ᾱ`、`√ᾱ` 和 `√(1 - ᾱ)`。仅使用一条原始曲线在时间步 `t = 1, 25, 50 和 199` 添加噪声，以便我们在图 9.4(B) 中查看正向过程。在过程结束时，`ᾱ₁₉₉ = 4.2 × 10^(−10)`。根据公式 (9.2)，原始图像对最后一个潜在图像 `x[199]` 的贡献可以忽略不计。最后一个潜在图像中仅存在标准高斯噪声 `ε`。根据经验法则，我们知道 99.7% 的高斯噪声值位于三个标准差以内。这就是为什么在图 9.4(B) 中 `x[199]` 的值沿 `y` 轴分布在 -3 和 3 之间。在单元格 04 中定义的 `q_sample` 函数中，一个 Pytorch 函数 `gather()` 对我们来说是新的。在一个额外的 VS code 单元格中运行以下代码，你将了解该函数如何根据另一个 1D 张量 `t` 从 1D 张量 `z` 中选取元素：`z = torch.tensor([1, 2, 3, 4, 9]); t = torch.tensor([2, 0]); z.gather(dim = −1, index = t)`。这些额外代码的输出是 `[3, 1]`，即 `[z[t[0]], z[t[1]]]`。

### 9.2.2 DDPM 中的反向过程

在物理世界中，混合两种材料比混合后再分离它们更容易。在 DDPM 的数字世界中也是如此。正向过程比反向过程容易得多。反向过程是另一个马尔可夫链，起始于纯噪声 `x[T] ∼ pθ = N(x[T]; 0, I)`，并逐步向后进行以获得去噪的潜在图像：`x[T−1]…, x[t], x[t−1], …, x[0]`，其中 `θ` 代表 `U-Net` 的参数。图 9.4(C) 展示了从 `t = 199` 处纯噪声开始的反向过程结果。在时间步 `t−1`，潜在图像 `x[t−1]` 具有概率密度函数 (PDF) `pθ = N(x[t−1]; μθ, β[t]I)`，其中 `μθ` 来自训练好的 `U-Net` 模型。

反向 PDF `pθ` 对应于正向 PDF 的逆过程，且等于 `q(x[t−1]∣x[t], x[0])`，这被称为“正向过程后验分布”。详细推导见 DDPM 论文 (Ho *et al* 2020)。为求完整，以下公式 (9.3) 和 (9.4) 来自附录 I

```
q(x_{t - 1}∣x_{t},x_{0}) = 𝕹(x_{t - 1};μ̃(x_{t},x_{0}),β̃_{t}I) = q(x_{t}∣x_{t - 1},x_{0}) * q(x_{t - 1}∣x_{0}) / q(x_{t}∣x_{0})
```

(9.4)

```
μ̃(x_{t},x_{0}) = x_{t} - (1 - α_{t}) / √(1 - ᾱ_{t}) * ε
```

(9.5)

```
β̃_{t} = (1 - ᾱ_{t - 1}) / (1 - ᾱ_{t}) * β_{t}
```

(9.6)

上述公式将用于模型训练的变分下界损失。反向过程的联合概率分布为：

```
p_θ(x_{0:T}) = p_θ(x_{T}) * ∏_{t=1}^T p_θ(x_{t - 1}∣x_{t}) = p_θ(x_{0}∣x_{1}) * p_θ(x_{1}∣x_{2}) * ... * p_θ(x_{T - 1}∣x_{T}) * p_θ(x_{T})
```

(9.7)

由联合概率分布和 `∫q(x[0])dx[0] = 1`，我们得到系统用于模型训练的负对数似然（损失函数）：`L = −log (pθ) = −log ∫pθdx[1:T]`

```
L = - (∫ q(x_{0})dx_{0}) * log ∫ q(x_{1:T}∣x_{0}) * p_θ(x_{0:T}) / q(x_{1:T}∣x_{0}) dx_{1:T}
```

(9.8)

利用 Jensen 不等式，我们可以简化上述公式以得到系统的变分下界损失（附录 I）

```
L < - ∫ q(x_{0})dx_{0} ∫ q(x_{1:T}∣x_{0}) * log (p_θ(x_{0:T}) / q(x_{1:T}∣x_{0})) dx_{1:T} = L_{VLB}
```

## 变分下界公式

```
L_{VLB} = D_{KL}(q(x_{T}∣x_{0}) || p_θ(x_{T})) + ∑_{t=2}^{T} D_{KL}(q(x_{t - 1}∣x_{t},x_{0}) || p_θ(x_{t - 1}∣x_{t})) - E_{q}[log p_θ(x_{0}∣x_{1})]

L_{VLB} = L_{T} + ∑_{t=2}^{T} L_{t - 1} + L_{0}
```

该过程的变分下界是每个时间步损失之和：`L = L_0 + L_1 + ... + L_T`。`L_{VLB}` 中的每个 `D_{KL}` 项（`L_0` 除外）都是关于两个高斯分布之间的差异，因此可以直接计算。`L_{T}` 在模型训练期间可以忽略，因为它是一个常数；`L_0` 也被忽略，因为 DDPM 论文的作者发现不包含该项时效果更好。

基于 `q(x_{t-1}∣x_t,x_0) = 𝕹(x_{t-1};μ̃(x_t,x_0),β̃_t I)` 和 `p_θ(x_{t-1}∣x_t) = 𝕹(x_{t-1};μ_θ(x_t,t),σ_t² I)`，我们得到以下公式，其中 `C` 是与模型训练无关的常数，`t = 2,3,...,T`：

```
L_{t - 1} = D_{KL}(q(x_{t - 1}∣x_{t},x_{0}) || p_θ(x_{t - 1}∣x_{t})) = E_{q}( (1 / (2σ_{t}^{2})) * ||μ̃_{t}(x_{t},x_{0}) - μ_θ(x_{t},t)||^{2} ) + C
```
