## 关于 Web 及其历史

最近，人们倾向于为世界万维网划分版本号。大家讨论的最新版本是 `Web 3.0`。尽管术语 `Web 3.0` 尚不明确，但事实上，专家们讨论的大多数进展并非新事物。

网页是我们尖端社会中获取和共享数据的工具。在考虑娱乐、可携性和健康等人类活动时，`Web 3.0` 应该超越传统的网页，通过引入与通常未被视为注册实体的真实物体进行通信的方式，例如车辆和医疗设备。

为了完全理解 `Web 3.0` 的内涵，我们想看看描述之前阶段的特征。在 1991 年到 2004 年之间，互联网基本上是静态页面，这意味着你只需加载页面，它就会显示一些内容。帖子无法被查看或登录，也没有观察到任何分析数据；这被称为 `Web 1.0`。然后是 `Web 2.0`，它大约在 2004 年出现。在此期间，网页经历了重大的发展，但最显著的变化可能是网页的交互性，这意味着除了从网页上接收信息外，它们在我们使用 `Facebook`、`YouTube` 以及在 `Google` 上进行搜索时也开始直接从我们这里接收信息。最终，他们意识到可以将他们收集到的关于我们的每一条信息打包，以便更好地服务我们，并让我们在他们的网站上留存更久。下一个是 `Web 3.0`，它是网页的进步，最可能使用区块链创新和去中心化工具。Web 演进概述如图 1 所示。

### 第一时代 (Web 1.0)

很多时候，这一时期与世界万维网的早期阶段相比较。最初，网页是一系列（大部分）静态页面的集合，包含由规划页面或场地的组织或不同协会创建的数据和内容。人们达成共识，在此期间，创建内容是一项由专家完成的任务，在网页上拥有个人页面或发布单个内容并不简单。因此，在最初的版本中，客户端仅仅是数据消费者。此外，页面是孤立的数据片段。要查看来自不同来源的数据，应该从一个网站移动到另一个网站，而忽略了之前位置中包含的数据。

### 第二时代 (Web 2.0)

在网页的第二个时代，客户端参与到创建内容和参与网页以发现自己并与他人联系。在这里，重点在于协作工作的技术，例如非正式社区、`RSS` 频道、网站和内容分发管理（图片、文本和视频）。这些设备非常易用，允许任何人发布各种类型的内容。考虑到客户的兴趣，通过将来自多个源的数据整合到单个页面，创建动态且智能的 `Web 2.0` 页面变得更加简单。

### 第三时代 (Web 3.0)

将技术归类为 `Web 3.0` 的创新网页技术安排尚不明确。该领域的重大 IT 专家对未来网页的样貌有不同的想法。正如预期的那样，这些梦想受到他们所指导的业务类型或做事方式的局限。

负责世界万维网基础的蒂姆·伯纳斯-李（Tim Berners-Lee）创立了“语义网”（Semantic Web）这一术语。他主张将网页变成一个巨大的信息库，其中现代和复杂的问题可以得到解答 [3, 4]。

如果我们需要一个更具洞察力的网页，拥有允许我们在需要时找到数据的工具，那么掌握信息至关重要。数据应该被组织起来，以便机器像人类一样阅读和理解它们，而没有歧义。在这方面，我们希望创建智能代理，能够为我们服务进行检索并检索我们想要的数据，就像我们假设自己在进行检索一样。

这绝非另一个想法。它一直存在，但还没有真正产生影响。语义网在发展中面临两个根本性的困难。第一个是通过执行某些类型的元数据来为现有内容赋予语义重要性的工作。不是逻辑专家的普通客户应该有权创建机器可理解的语义内容。这个问题可以通过提供一种简单的方法来增加带有语义标签的内容来解决，这应该是连续地进行且成本极低的，或者至少是免费的。

未来的网页将是不可避免且普遍的处理环境的结果。就我们而言，网页不会消失，但它将进化并扩展，变得在我们的日常生活中无处不在。访问网页上的广泛数据将像看手表上的时间一样普通。我们将想要咨询数据，它也将在我们不知情的情况下影响我们的现状，无论我们是否承认。网页应用程序和服务的虚拟性将与我们生活的现实融合。

## 语义网栈 (Semantic Web Stack)

语义网栈，也被称为语义网蛋糕或语义网层级蛋糕，描述了语义网架构。一个全球标准机构——万维网联盟（`W3C`）驱动着语义网计划。

标准技术规范了传统信息并预测了互联网。通过连接网页中语义内容的可能性，语义网旨在将被非结构化和半结构化报告充斥的现状转换为“信息网”。语义网栈促进了 `W3C` 的资源描述框架。

语义网栈是一个用于组织化开发语言的框架，每一层都利用其他层的潜力。语义网网络描述了为了语义网而标准化的技术如何工作以使语义网成为可能。此外，它描述了语义网是传统超文本网页的扩展（而非替代）。

该概述由蒂姆·伯纳斯-李制定。该栈目前已经实现以创建这些层。（注释：2009 年世界语义网会议完成了一次创建语义网栈的明智访问。）

### 语义网技术

正如语义网栈所示，使用以下语言或技术来构建语义网。从栈的底部（如 `OWL`）的时期现在已经标准化并成为标准，用于构建语义网项目。在目前看来，栈的顶端如何完成尚不完美。栈的所有组件都应该被执行以实现语义网的梦想。

### 超文本网页技术

底层由超文本网页的深厚技术组成，这些技术在不改变的情况下提供了语义网的基础。为了使语义网顶层功能得到证明，国际化资源标识符（`IRIs`）用于识别语义网上的资源。`IRIs` 是 `URIs` 的推广。

# 语义网上的机器学习

由于数据以语义网的形式存在，机器学习将面临各种新机遇和挑战。通过利用数据中的模式并抵抗语义网数据中的某些固有问题（如矛盾信息和非平稳性），机器学习增强了本体背景知识。机器学习的一个通用挑战是，在学习过程中需要仔细处理信息缺失问题，特别是当统计单元是选定的，或者某个特征缺失的概率取决于感兴趣的特征时，这在多对多的连接中是典型的 [7]。

语义数据的核心目标是赋予计算机以更好的方法执行更有用的工作，然后进一步开发能够在网络上提供可靠交互的系统。`LOD` 被视为一组最佳实践，鼓励企业使用现有的本体在万维网上发布并相互链接其数据。简单来说，链接数据的概念是一种通过链接在 Web 上对数据进行紧密协作的方法。

要成为链接数据的一部分，源数据集中的资源应该与另一个数据源的资源具有 `RDF` 链接。

使用 `RDF` 链接，我们可以遍历图以发现关于资源的更多细节。对于构建 `RDFS` 图，需要探索图结构和知识库语义。可以根据相关性标记重要的节点。从这个重要节点开始，我们最大化其重要性以决定选择哪条连接边。本体挖掘应该包含所有能够从关联知识库中发现隐藏知识的成就 [8]。这些都可以通过机器学习方法实现。

语义网的原始动力是增加处理基于 Web 的信息的自动化程度，并提高基于 Web 的信息系统的互操作性。将机器学习概念引入推断链接数据中的隐藏知识，将为我们提供广泛的数据语义。这是让 Web 上的数据不仅是机器可读的而且是机器可理解的方法 [9, 10]。

在学习数据上应用推理可以消除异常并推导隐藏知识，这将是语义网的补充。文献综述详述了获取额外知识所需的推理。这可以用于向本体建议新的推理。

机器学习在语义网上的应用将极大地增强其能力。`LOD` 和机器学习这两个巨大领域都有蓬勃发展。当它们以适当的方式融合时，可以在获取更多实体信息方面取得更多进展。

# 语义网与农业

由于物联网（`IoT`）的最新进展，现在利用各种大规模物联网平台处理海量的传感器数据流已成为可能。这些物联网框架被用于实时收集、处理和解释数据流，从而部署能够提供决策辅助的智能解决方案。互操作性是全球物联网开发人员面临的一项严峻挑战。这是因为目前使用的物联网设备使用了多种数据格式、协议和技术来运行。由于缺乏物联网应用的标准准则，目前互操作性工具非常有限。语义网技术可以作为这一问题的解决方案。可以采用 `RDF` 来赋予数据语义化功能 [11]。语义网在农业科学中是一项被忽视的工具。尽管存在许多农业特有的资源，但过去的研究中很少有使用语义资源来解决农业问题的案例 [12]。

### 农业语义网技术
