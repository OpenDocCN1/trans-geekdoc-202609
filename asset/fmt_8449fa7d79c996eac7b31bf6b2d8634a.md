
参数 `ε>0` 为实数，`min_pts` 为正整数，`distance` 度量是 DBSCAN 的输入。这些参数的选择会影响 DBSCAN 的最终结果。几种选择这些值的方法讨论如下：

*   参数 `min_pts` 影响一个聚类中的点数。值越高，分配到同一聚类的点越多。保持较大的值会导致噪声或离群点被添加到聚类中。较低的值会导致更多的聚类和离群点。

*   `ε` 的值可以通过绘制每个点到其 `min_pts` 个最近邻的平均距离来选择。这些点的平均 `min_pts` 按升序绘制，`ε` 的值将是图中出现急剧增长的“拐点”。更多信息请参阅 *References* 部分的 [20]。较低的值会导致大量聚类和大量离群点，而较高的值会导致较少的聚类。

*   `distance` 函数的选择与 `ε` 值紧密相关。其选择应基于我们要解决的领域问题。

### 优势

DBSCAN 具有以下几个优势：

*   聚类的数量基于输入参数形成。无需像 *k*-means 那样向算法输入聚类数量。

*   它可以发现不同形状的聚类。即使一个聚类被另一个聚类包围，该算法也能工作。

*   它对离群点具有鲁棒性，且对处理点的顺序大多不敏感。

### 局限性

DBSCAN 应用面临的几个挑战如下：

*   如果存在密度差异很大的聚类，性能会下降。

*   性能取决于所使用的距离度量。最常用的度量是欧氏距离。在高维空间中基于欧氏距离选择 `ε` 值具有挑战性。

## 基于分布的聚类

**基于分布的聚类**基于这样一个假设：如果原始数据映射到多个分布，则属于同一聚类的样本应来自同一个分布。该类别下流行的算法之一是 `Gaussian Mixture Model (GMM)` [10]。

## GMM：K-Means 的扩展

GMM 是 k-means 模型的扩展，其中每个聚类都用多元高斯分布建模。因此，我们不仅要找到均值，还要找到一个描述聚类椭球形状的协方差。该分布的参数可以通过最大化观测数据的似然度来估计，这由一种称为**期望最大化**（**EM**）的算法完成，将在以下章节中讨论。这是一种软聚类技术，我们以某种软概率将数据分配给每个聚类。此外，通过这种聚类方法，我们本质上是为数据创建了一个概率生成模型（详见第 12 章 生成模型）。因此，利用 GMM，我们甚至可以采样出类似于数据集中点的新数据点；我们可以填补缺失的数据值。

让我们通过一维情况来理解 GMM 概率分布模型，如图 7.9 所示。这里，我们采用了三个具有不同均值和方差的单变量高斯分布的混合。从该分布中观测到任意点的概率由公式给出。这里，`π_k` 称为*混合权重*，且有 `Σ π_k = 1` `π_k ≥ 0`。假设我们有 20 个点来自最左边的聚类，10 个来自中间的聚类，另外 20 个来自最右边的聚类；那么我们可以取 `π = [0.4, 0.2, 0.4]`。请参考下图：

![](img/Image44705.jpg)

**图 7.9：** *三个单变量高斯分布。*

我们可以用一种简单的生成方式来解释 *x* 上的这个联合概率分布。要从 *P(x)* 中抽取样本 *x*，我们首先以离散概率 `π_k` 选择其中一个分量，即如果我们用离散随机变量 *Z* 表示混合分量，则 `P(Z=k) = π_k`。概率较大的分量被选中的频率更高。这类似于在 k-means 中选择一个聚类中心。现在，我们可以从相应的高斯分布 `N(μ_k, σ_k²)` 中采样 *X*。因此，这两个分布共同构成了 *X* 和 *Z* 的联合模型。

```
P(X, Z) = P(Z) P(X|Z)
```

变量 *Z* 有时被称为*潜在变量*或*隐变量*。未知 *Z* 值的存在有助于解释 *X* 值中的模式。关于该主题的详细讨论见第 5 章 统计推断与应用和第 12 章 生成模型。

对于聚类问题，我们有多变量数据，因此使用具有向量均值 `μ_k` （长度为 *n*，与数据特征数量相同）和协方差矩阵 `Σ_k` 的多元高斯分布。现在，我们需要通过**最大似然估计**（**MLE**）来估计这些参数。但直接将 MLE 应用于混合模型很难，因此我们将使用一种称为**期望最大化**（**EM**）**算法**的迭代算法。EM 有两个步骤：期望步骤（E-步）和最大化步骤（M-步）。我们知道如何计算高斯模型的 MLE 参数估计：令 `μ` 为数据的均值，即 `μ = (1/N) Σ x_i`；令 `Σ` 为由 *X* 减去 `μ` 与自身的外积形成的 `n×n` 矩阵的均值，即 `Σ = (1/N) Σ (x_i - μ)(x_i - μ)^T`。

### EM 算法

现在让我们讨论 EM 算法的步骤：

*   **初始化**均值 `μ_k`、协方差 `Σ_k` 和混合系数 `π_k`：启动 GMM 的一种方法是先运行 k-means，并将中心作为 `μ_k` 的初始估计。k-means 还能告诉我们哪些数据点属于哪个聚类。`Σ_k` 的一个好的初始估计是簇内协方差，而权重 `π_k` 是分配给每个聚类的数据点比例。

*   **期望步骤（E-步）**：

    *   对于每个数据点 `x_i`：

        *   对于每个聚类 *c*：

        *   按如下方式计算相对概率的度量 `γ(z_ik)`（称为责任）：

            ```
            γ(z_ik) = π_k N(x_i | μ_k, Σ_k) / Σ_j π_j N(x_i | μ_j, Σ_j)
            ```

*   **最大化步骤（M-步）**：使用责任重新估计参数，如下所示：

    *   对于每个聚类 *c*：

        *   与该聚类相关的总责任 `N_k`

            ```
            N_k = Σ_i γ(z_ik)
            μ_k = (1/N_k) Σ_i γ(z_ik) x_i
            Σ_k = (1/N_k) Σ_i γ(z_ik) (x_i - μ_k)(x_i - μ_k)^T
            π_k = N_k / N
            ```

迭代 E-步和 M-步直到收敛，即直到估计参数的范数不再显著变化。EM 算法的每一步都会增加我们模型的对数似然（详见第 5 章 统计推断与应用）。

> **注意：** EM 算法与 k-means 算法非常相似。k-means 不估计聚类的协方差，只估计聚类均值。它通过采用固定的单位协方差矩阵，假设聚类是圆形的。选择 `Σ_k = εI`，其中 `ε` 是由所有分量共享的方差参数，责任变为
>
> ```
> γ(z_ik) = π_k N(x_i | μ_k, εI) / Σ_j π_j N(x_i | μ_j, εI)
> ```
>
> 取极限 `ε → 0`，在分母中，最接近于零的项 `||x_i - μ_k||²` 将缓慢消失，该项的责任将趋近于 1。因此，我们得到了数据点到聚类的硬分配，即每个数据点被分配给具有最近均值的聚类。因此，在固定圆形协方差假设下，EM 算法退化为 k-means。

EM 算法可以推广到任何具有隐变量的模型。概率模型是指我们用 *X* 表示所有观测变量，用 *Z* 表示所有隐变量的模型。联合分布 `P(X, Z | θ)` 由一组参数 `θ` 控制。似然函数由 `P(X | θ) = Σ_Z P(X, Z | θ)` 给出。

## 基于层次的聚类

**层次聚类**从数据点构建聚类的层次结构。构建聚类层次结构的方法可分为两类：凝聚式和分裂式：

*   **凝聚式**是一种自底向上的方法，最初将每个数据点视为一个聚类，然后在沿层次结构向上移动时合并聚类。

*   **分裂式**是一种自顶向下的方法，最初将所有数据点视为一个聚类，然后在沿层次结构向下移动时分裂聚类。

寻找最优层次结构是 NP-hard 问题。因此，大多数情况下，聚类的合并和分裂是以贪婪方式决定的。用于合并和分裂的聚类选择基于聚类间的距离。而距离度量的选择极大地影响聚类的形状。该类别下流行的算法有**平衡迭代缩减和使用层次进行聚类**（**BIRCH**）[11]、**使用代表点进行聚类**（**CURE**）[12] 和**基于链接的稳健聚类**（**ROCK**）[13]。

### 凝聚式聚类

此类算法首先将每个数据样本单独视为一个聚类。计算所有现有聚类之间的距离。距离最短的两个聚类被合并，以层次化的方式在上一层形成一个聚类。这两个步骤重复执行，直到将聚类减少到所需的聚类数量。

## 簇间距离

我们如何计算簇之间的距离？用于计算簇间距离的算法称为链接算法。让我们了解常用于计算两个簇之间距离的链接算法类别 `d(C_i, C_j)`：

*   **单链接**：两个簇之间的距离定义为分别属于每个簇的两个数据样本之间的最短距离。定义如下：

    ```
    d(C_i, C_j) = min_{x∈C_i, y∈C_j} d(x, y)
    ```

*   **全链接**：两个簇之间的距离定义为分别属于每个簇的两个数据样本之间的最长距离。定义如下：

    ```
    d(C_i, C_j) = max_{x∈C_i, y∈C_j} d(x, y)
    ```

*   **平均链接**：两个簇之间的距离定义为一个簇中每个点到另一个簇中每个点的距离的平均值。

    ```
    d(C_i, C_j) = (1 / |C_i||C_j|) Σ_{x∈C_i} Σ_{y∈C_j} d(x, y)
    ```

*   **质心链接**：两个簇之间的距离定义为簇质心之间的距离。

*   **Ward 链接**：该方法的目标是最小化总簇内方差。簇的合并总是会导致簇内方差增加。选择合并的两个簇，使得簇内方差的增加最小化。

所有层次聚类算法的主要目标是在自底向上方法中寻找两个簇进行合并，在自顶向下方法中寻找一个簇进行分裂。选择簇的标准因算法而异，如前所述。要在较大数据集上执行这些操作，我们需要使用一种能高效工作的数据结构。

## BIRCH

**利用层次结构的平衡迭代缩减和聚类**（**BIRCH**）*[11]* 首先生成原始数据的紧凑摘要，该摘要尽可能多地保留分布信息，然后将聚类算法应用于摘要，而不是原始数据集。各种层次算法可以在大数据集上使用这种方法，此时完整数据集无法放入可用内存中。经过少量修改，它也可以适应非层次算法，如 k-means。

## 基于图的聚类

在基于图的方法中，数据样本表示为图的节点，这些节点之间的边表示它们的关系。一旦数据样本以图的形式表示，我们就可以应用基于图的算法来获得所需结果。该类别中流行的算法有 CLICK *[14]*、基于最小生成树的算法 *[15][16]*、归一化割与图像分割 *[17]* 以及谱聚类 *[18]*。基于图的聚类算法常用于社交网络分析、电网网络、电信网络以及通过接触传播的疾病扩散。

### 谱聚类

谱聚类技术利用相似度矩阵的特征值（谱）来执行降维。然后可以在降维后的数据集上应用任何聚类算法。

在应用图技术之前，我们必须将数据表示为图的形式。数据样本代表节点，边代表数据样本之间的相似度关系。这些边的值将形成*相似度矩阵*。我们必须将图划分为所需数量的组，使得不同组之间的边具有低值（较低相似度），而组内的边具有高值（较高相似度）。图划分是 NP-hard 问题。可以通过使用图拉普拉斯矩阵找到近似解。

假设所有数据样本都已枚举，相似度矩阵可以定义为对称矩阵 *A*，其中 `A_ij` 表示数据样本 *i* 和 *j* 之间的相似度关系。下一步是获取 *A* 的拉普拉斯矩阵。存在定义拉普拉斯矩阵的多种方式，每种方式对聚类算法的影响不同。定义拉普拉斯矩阵的一种方式如下：

```
L = D - A
```

以下是有助于我们快速找到近似解的图拉普拉斯矩阵的几个性质：

*   当 `A_ij ≥ 0` 且 *A* 为对称时，`L` 为半正定

*   `L` 的特征值为实数且非负，且对应的特征向量构成标准正交基

*   `L` 零空间的维数等于图的连通分量数量

划分图的算法如下：

1.  创建相似度矩阵 *A*。

2.  构建图拉普拉斯矩阵 `L`。

3.  计算特征值和对应的特征向量。

4.  选取对应最小的 *k* 个特征值的 *k* 个特征向量（实对称正定矩阵的特征值总是实数）。

5.  使用 *k* 个特征向量构建投影矩阵 *P*。

6.  使用 `X' = P^T X` 将数据投影到较低的 *k* 维空间。

7.  在降维后的数据上应用聚类算法。

## 基于模糊理论的聚类

模糊意味着模糊性。这发生在无法确定性地对对象进行分类的场景中。对象可以以一定的概率属于多个类。模糊集理论是经典集理论的扩展，其中元素以一定的概率（称为*隶属度*）属于一个集合。考虑根据年龄将人分为两组：年轻和年老。由于没有普遍认可的年龄阈值来界定一个人何时变老，这是模糊性的一个例子。一个 35 岁的人将以 0.6 的概率属于年轻，以 0.4 的概率属于年老。

在基于模糊理论的聚类算法中，数据样本与簇的关系从离散值 {0,1} 变为连续值 [0,1]。在这里，每个数据样本可以属于多个簇，属于某个簇的程度由连续值 [0,1] 表示。该类别中最流行的算法之一是**模糊 C-均值算法**（**FCM**）*[19]*。该类别下的算法输出软簇或重叠簇。模糊算法对初始条件相对不敏感。

## 模糊 C-均值

考虑一个包含 `n` 个数据样本的集合，该集合被划分为 `m` 个模糊簇，其中 `c_j` 是第 `j` 个簇的质心。样本 `x_i` 属于簇 `c_j` 的隶属度用 `u_ij ∈ [0, 1]` 表示，其中 `Σ_{j=1}^m u_ij = 1`。该值也称为*隶属度值*。`d` 是一个控制簇模糊程度的超参数（值越大，模糊程度越高）。*隶属度值* 定义如下：

```
u_ij = 1 / Σ_{k=1}^m ( ||x_i - c_j|| / ||x_i - c_k|| )^(2/(d-1))
```

第 `j` 个簇 `c_j` 的模糊质心定义如下：

```
c_j = Σ_{i=1}^n u_ij^d x_i / Σ_{i=1}^n u_ij^d
```

FCM 的目标是最小化以下函数：

```
J = Σ_{i=1}^n Σ_{j=1}^m u_ij^d ||x_i - c_j||²
```

K-means 算法优化的是上述相同的目标函数，但隶属度值 `u_ij` 将只能是 0 或 1。模糊程度由 `d ∈ [1, ∞)` 的值控制。当 `d → 1` 时，`u_ij` 变为 0 或 1，FCM 退化为 k-means 算法。

我们已经讨论了不同类别的聚类算法。没有明确定义的指南说明哪种算法最适合特定领域。我们必须在我们的问题上尝试不同的距离度量和聚类算法，以满足需求。
