## 2.2.1 梯度消失与爆炸问题

随着时间的推移，误差函数的偏导数根据神经网络中的每个权重成比例进行更新。在其他情况下，该导数非常小，导致无法进行更新。更新通过在神经网络深层乘以不同的偏导数来实现。如果这些偏导数非常小，总更新将变得极其微小并趋于零。在这种情况下，权重将无法更新，导致收敛延迟或不收敛。梯度消失是这种情况的名称。如果导数项很大，更新也将非常显著。在这种情况下，算法将超过最小值且无法收敛。梯度爆炸是这种情况的名称。防止这些问题的方法之一选择合适的激活函数。以下是最常用的激活函数。

### 2.2.2.3 Sigmoid 函数

Sigmoid 是一种“S”形状的数学函数（如图 2.7 所示），其公式如下：

```
$$y(x) = \frac{1}{1+e^{-x}} \quad (2.3)$$
```

#### 优点：

Sigmoid 函数是一个连续且可微的函数。它将输出限制在 0–1 的范围内，并为二分类提供非常具体的预测。

#### 缺点：

它具有产生梯度消失问题的潜力。它并不以 0 为中心。计算开销较大。

### 2.2.2.4 Softmax 函数

Softmax 函数是多分类的扩展。我将其用于多分类的最后一层。如图 2.8 所示，它将一组 $k$ 值的实数转换为概率分布，其中 $k$ 个概率与输入数值相匹配。在应用 softmax 之前，向量分量可能为负或大于 1，因此总和不为 1，但在应用 softmax 之后，每个分量都将在 0–1 范围内且总和为 1。softmax 函数定义如下：

```
$y(x_i) = \frac{e^{x_i}}{\sum_{K=1}^{K} e^{x_i}} \text{ 对于 } i=1,2,3,...K \quad (2.4)$
```

#### 优点：

它可以用于神经网络的输出层进行多分类。

#### 缺点：

由于存在指数项，计算速度较慢。

### 2.2.5 双曲正切 (tanh)

双曲正切或简称为“tanh”，表示如下：

```
$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}$$
```

它非常像 sigmoid 函数。它的范围为 -1 到 +1，并且以 0 为中心，如图 2.9 所示。

#### 优点：

- 到处连续。

- 围绕零分布。

- 输出限制在 -1 和 +1。

#### 缺点：

- 它可能会导致梯度消失问题。

- 计算开销大。

## 2.3 训练神经网络

由于每个神经网络都是函数的近似，它们不会等于预期的函数，而是会与一个称为“误差”的因子产生偏差。训练的目的是最小化这种误差。我们试图最小化与权重相关的误差，误差是网络中权重的函数。误差函数依赖于大量的权重，因此依赖于大量的变量。在数学中，该函数为零的点的集合被称为超曲面，我们的目标是通过选择一个点并沿着最小值的方向追踪曲线，来识别该表面上的最小值。

## 2.4 深度 CNN 的架构演变

在受生物启发的 AI 方法中，CNN 现在是最频繁利用的算法。Hubel 和 Wiesel 的神经生物学实验 [1] 是 CNN 历史的基础。他们的工作为一系列认知模型铺平了道路，CNN 最终取代了几乎所有的模型。多年来人们一直在各种尝试来增强 CNN 的性能。

### 2.4.1 CNN 的起源

LeCun 等人在 1989 年展示了世界上第一个多层 CNN——ConvNet，其起源源于 Fukushima 的 Neocognitron [2, 3]。与其前身 Neocognitron 的无监督强化学习方法不同，LeCun 建议通过反向传播技术对 ConvNet 进行监督训练 [4, 5]。因此，LeCun 的工作为当前的 CNN 奠定了基础。这种 ConvNet 成功地解决了手写数字和邮政编码识别问题 [6, 7]。LeCun 在 1998 年引入了增强版的 ConvNet，并开创了在文档识别应用中使用 CNN 进行字符分类的先河 [6]。由于 CNN 在光字符和指纹识别方面的卓越性能，CNN 分别在 1993 年和 1996 年在 ATM 和银行中商业化。在此期间，LeNet-5 在光字符识别方面创下了许多记录，但在其他图像识别问题上表现困难。

由于架构的复杂性和所需的处理量，CNN 的训练非常困难。21 世纪初，人们广泛认为用于 CNN 训练的反向传播技术未能收敛到误差表面的全局最小值。结果表明，CNN 在提取特征方面不如手工设计的特征 [8]。此外，当时没有可访问的各种分类的综合数据集。由于其性能相对较高，其他统计技术（特别是支持向量机 SVM）在当时比 CNN 更流行 [9, 10, 11]。同时，少数研究机构继续致力于 CNN，尝试提高其性能。研究人员 Simard、Strauss 和 Platt [12] 在 2003 年增强了 CNN 架构，并在与 SVM 和 MNIST 相比时在手写基准数据集上展示了卓越的性能 [12, 13]。除了光字符识别外，这种性能还促进了 CNN 研究，使其应用扩展到其他脚本的字符识别、视频会议中人脸识别的图像传感器放置以及严重犯罪控制 [14, 15, 和 16]。同样，基于 CNN 的消费者追踪系统已经在市场中工业化 [17, 18, 和 19]。此外，还研究了 CNN 在医学分割、异常检测和机器人视觉等额外应用中的潜力 [20, 21]。

深度卷积网络具有复杂的结构。21世纪初，人们广泛认为用于 CNN 训练的反向传播技术未能收敛到误差表面的全局最小值。结果表明，CNN 在提取特征方面不如手工设计的特征 [8]。此外，当时没有可访问的各种分类的综合数据集。由于其性能相对较高，其他统计技术（特别是支持向量机 SVM）在当时比 CNN 更流行 [9, 10, 11]。同时，少数研究机构继续致力于 CNN，尝试提高其性能。研究人员 Simard、Strauss 和 Platt [12] 在 2003 年增强了 CNN 架构，并在与 SVM 和 MNIST 相比时在手写基准数据集上展示了卓越的性能 [12, 13]。除了光字符识别外，这种性能还促进了 CNN 研究，使其应用扩展到其他脚本的字符识别、视频会议中人脸识别的图像传感器放置以及严重犯罪控制 [14, 15, 和 16]。

### 2.5.3 VGG

CNNs 帮助了图像识别任务。因此，视觉几何组（VGG）被构建为 19 层深，以识别深度和网络表示能力 [56]。发现，小尺寸滤波器（如 2013 年 ILSVRC 竞赛中的前沿网络 LeNet）对于捕捉图像中的复杂细节同时高效管理计算资源至关重要。对于 11×1 和 5×5 滤波器，VGG 用 3×3 过滤器代替，这证明了保持微型（3×3）滤波器可能会产生大滤波器（5×5 和 7×7）的错觉。因为包含参数较少，微型滤波器需要的处理资源更少。这导致 CNN 在研究中使用更小的滤波器。VGG 通过在每个卷积层之间添加 1×1 卷积降低了网络的整体复杂度。

在卷积层上使用最大池化和填充以维持空间分辨率进行网络调优 [25]。通过 VGG，我们能够对图像进行分类和定位。今年 ILSVRC 的冠军者因其简单性、同性和增强的深度而受到关注。

### 2.5.4 GoogLeNet

GoogLeNet 也称为 Inception-V1，获得了 2014 年 ILSVRC。GoogLeNet 的设计寻求以低成本获得准确性。它在 CNN 中提出了 inception 块，利用划分、变换和合并的方法来整合尺度变化。inception 块的构建类似于 GoogLeNet 的网络中网络（NIN）方法，用微网络替换卷积层。该块收集了各种尺寸的空间数据（1 到 5×5）。通过拆分、修改和组合特征，GoogLeNet 能够处理要求在同一类别内学习多个变体的问题。GoogLeNet 在使用大卷积之前添加了一个 1×1 卷积滤波器瓶颈层。它还使用了稀疏连接来减少重复，并通过移除不必要的特征图来节省成本。为了降低密度，最后一层使用了全局平均池化而不是全连接层。这些参数调整将参数数量从 13800 万减少到了 400 万。考虑因素还包括批归一化和作为优化器的 RmsProp。GoogLeNet 创建了辅助学习器以帮助收敛。
