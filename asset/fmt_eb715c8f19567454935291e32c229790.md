
$$\sum_{i=1}^n \sum_{j=1}^a (\tilde{Y}_i - \tilde{Y}_j) = 2\sum_{j=1}^a (\tilde{Y}_j - \tilde{Y}_j)\sum_{i=1}^n (\tilde{Y}_i - \tilde{Y}_i)\sum_{j=1}^a (\tilde{Y}_j - \tilde{Y}_j)(0) = 0$$

最后的结果是因为关于均值的离差和为零。

# 第 9 章

# 多因素受试间设计

## 9.1 概述

在本章中，我们考虑包含两个或多个因素的受试间设计。在多因素设计中，实验条件通过创建变量水平的所有组合形成。此类设计有两个优势：(1) 显而见的优势是经济性；可以在同一个实验中研究几个因素的影响。(2) 第二个优势是可以研究变量之间的组合（或交互）效应。一个具体的例子可以帮助说明这两点。Wiley 和 Voss (1999) 关注学生如何学习关于 19 世纪上半叶爱尔兰马铃薯荒的内容。设计中的一个因素是呈现格式：材料以单一的、教科式的章节（“文本格式”）呈现，或者分为八个超链接来源，就像在网上看到的那样（“网络格式”）。第二个因素是收到的指令：他们被要求就 1800 年至 1850 年间爱尔兰人口的变化写叙述 (N)、摘要 (S)、解释 (E) 或论证 (A)。因此，实验中有八种条件，对应于两种格式与四种指令类型的组合。阅读后，对学生的材料进行了测试。

Wiley 和 Voss 有几个可以在他们的设计中测试的假设。其中一个假设是，更复杂的网络格式会带来更深入的理解，因为它迫使读者整合多个来源的材料。因此，一个问题是这些格式在学习的平均效应上是否存在差异。第二个假设是论证指令会促进“更多的概念性理解”。因此，第三个问题是论证指令与其他指令之间的性能差异大小是否取决于格式。这是一个关于格式和指令之间是否存在交互的问题。

这些问题指向了本章的两个主要目标：

- 扩展第 8 章的模型、假设和分析，以处理多因素受试间设计。
- 引入交互的概念，并提供其分析说明。

## 9.2 双因素设计：模型

在这些设计中，有两个自变量 `A` 和 `B`，`A` 有 `a` 个水平，`B` 有 `b` 个水平，每个单元有 `n` 个得分。得分将表示为 `Y_{ijk}`，即 `A` 和 `B` 形成的总体第 `i` 个得分。我们想要关于总体均值的假设，因此需要一个将观测得分与总体均值联系起来的模型。考虑A$ 和 `B` 的特定组合，假设 `A_j` 和 `B_k`，在 9.1 描述的 Wiley-Voss 实验中，该单元由两种格式和一种指令组成。该单元中的得分仅由于能力、动机和身体状态等因素的个体差异误差变异而变化。更正式地表述：

```
Y_{ijk} = μ_{jk} + ε_{ijk} (9.1)
```

其中 `μ_{jk}` 定义为 `A_j` 和 `B_k` 形成的总体，`ε_{ijk}` 是 `A_j` 和 `B_k` 单元第 `i` 个得分的误差成分。

现在考虑不同处理组合之间的得分存在系统性差异。通过从等式 9.1 两侧减去 `μ`，表示得分相对于总体均值的偏差是有用的：

```
Y_{ijk} - μ = (μ_{jk} - μ) + ε_{ijk} (9.2)
```

| 总体参数 | 估计值 |
| --- | --- |
| `μ_{jk} = A_j` 和 `B_k` 得分的总体均值 | `\bar{Y}_{cdotjk} = \sum_{i} Y_{ijk} / n` |
| `μ_{j.} = \sum_{k} μ_{jk} / b = A_j` 条件下的总体均值 | `\bar{Y}_{jcdot} = \sum_{i,k} Y_{ijk} / nb` |
| `μ_{\cdot k} = \sum_{j} μ_{jk} / a = B_k` 条件下的总体均值 | `\bar{Y}_{\cdot k} = \sum_{i,j} Y_{ijk} / na` |
| `μ = \sum_{j,k} μ_{jk} / ab =` 所有总体的均值 | `\bar{Y}_{\cdot\cdot} = \sum_{i,j,k} Y_{ijk} / nab` |
| `ε_{ijk} = Y_{ijk} - μ_{jk} = Y_{ijk}` 的误差成分 | |

# 研究设计与统计分析

`μ_{jk}` 的变化可能由于三个原因之一；即它们对应于 `A` 的不同水平以及这些水平的不同组合。我们可以通过以下等式来表示这一观点：

```
(μ_{jk} - μ) = (μ_j - μ) + (μ_k - μ) - [(μ_{jk} - μ) - (μ_j - μ) - (μ_k - μ)] (9.3)
```

更简单的表示法：

```
$$\mu_{jk} - \mu = \alpha_j + \beta_k + (\alpha\beta)_{jk} (9.4)$$
```

方程 9.4 表示 `μ_{jk} - μ` 是三个效应之和。其中第一个效应 `α_j` 是处理 `A_j` 的*主效应*；其值代表了由处理 `A_j` 定义的总体中平均分与所有 `ab` 总体得分平均值之间的差异程度。同样，`β_k` 是处理 `B` 的主效应，反映了总体 `B` 中的平均分与所有 `ab` 总体得分平均值之间的差异程度。最后 `(αβ)_{jk}` 是 `A` 和 `B` 的*交互效应*。交互是在移除 `A` 和 `B_j` 的主效应后 `μ_{jk}` 与 `μ` 之间的差异；即：

```
(αβ)_{jk} = (μ_{jk} - μ) - (μ_j - μ) - (μ_k - μ) (9.5a)
```

这种交互通常通过简化方程 9.5a 中的右项来表示：

```
(αβ)_{jk} = μ_{jk} - μ_j - μ_k + μ (9.5b)
```

从方程 9.4 出发，我们可以替换方程 9.2 中的 `μ_{jk} - μ`。考虑到杂差差也会对观测数据产生贡献，我们得到了双因素设计假设检验的底层结构模型：

```
Y_{jk} - μ = α_j + β_k + ε_{jk} (9.6)
```

在现实中，总体之间的变异有四个可能的来源：操作 A 的效应；操作 B 的效应；A 和 B 的联合效应（或交互效应）；以及误差分量。框 9.1 给出了模型组件和相关假设的详细总结。

## 9.1 结构模型的组件

1. 处理 A 的主效应，`α_j = μ_j - μ`。假设因子 A 具有固定效应；即这些水平是人为选择的，并被视为代表了水平总体。那么 `∑_j α_j = 0`。对 A 主效应的 `F` 检验检验零假设：

```
H_0 : μ_1 = μ_2 = … = μ_j = … = μ_u.
```
