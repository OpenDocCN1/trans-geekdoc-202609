## 3.2 浮点数

Go 提供两种大小的浮点数，`float32` 和 `float64`。它们的算术特性由所有现代 CPU 实现的 IEEE 754 标准控制。

这些数值类型的值范围从极小到极大。浮点数值的限制可以在 `math` 包中找到。常量 `math.MaxFloat32`，即最大的 `float32`，约为 `3.4e38`，而 `math.MaxFloat64` 约为 `1.8e308`。最小的正值分别接近 `1.4e-45` 和 `4.9e-324`。

`float32` 类型大约提供 6 位十进制数字的精度，而 `float64` 约提供 15 位；大多数情况下应优先使用 `float64`，因为除非非常小心，否则 `float32` 计算会迅速累积误差，且无法精确表示为 `float32` 的最小正整数并不大：

```
var f float32 = 16777216 // 1 << 24
fmt.Println(f == f+1)    // "true"!
```

浮点数可以使用十进制字面量书写，如下所示：

```
const e = 2.71828 // (大约)
```

小数点前（`.707`）或后（`1.`）的数字均可省略。极小或极大的数值最好用科学计数法书写，即在十进制指数前加上字母 `e` 或 `E`：

```
const Avogadro = 6.02214129e23
const Planck   = 6.62606957e-34
```

使用 `Printf` 的 `%g` 动词打印浮点数非常方便，它会选择精度足够且最紧凑的表示形式，但对于数据表格，`%e`（指数形式）或 `%f`（非指数形式）可能更合适。这三个动词都允许控制字段宽度和数值精度。

```
for x := 0; x < 8; x++ {
    fmt.Printf("x = %d ex = %8.3f\n", x, math.Exp(float64(x)))
}
```

上述代码打印 *e* 的幂，精度为小数点后三位，在八字符宽的字段中右对齐：

```
x = 0   ex =    1.000
x = 1   ex =    2.718
x = 2   ex =    7.389
x = 3   ex =   20.086
x = 4   ex =   54.598
x = 5   ex =  148.413
x = 6   ex =  403.429
x = 7   ex = 1096.633
```

除了大量常用数学函数外，`math` 包还提供了用于创建和检测 IEEE 754 定义的特殊值的函数：正负无穷大，它们表示过大的数值和除以零的结果；以及 NaN（“非数字”），它是诸如 `0/0` 或 `Sqrt(-1)` 这类数学上存疑运算的结果。

```
var z float64
fmt.Println(z, -z, 1/z, -1/z, z/z) //  "0 -0 +Inf -Inf NaN"
```

函数 `math.IsNaN` 用于检测其参数是否为非数字值，`math.NaN` 则返回此类值。虽然想用 NaN 作为数值计算中的哨兵值，但检测某个计算结果是否等于 NaN 充满陷阱，因为与 NaN 的**任何比较***总是*得到 `false`：

```
nan := math.NaN()
fmt.Println(nan == nan, nan < nan, nan > nan) // "false false false"
```

如果返回浮点结果的函数可能失败，最好单独报告失败，如下所示：

```
func compute() (value float64, ok bool) {
    // ...
    if failed {
        return 0, false
    }
    return result, true
}
```

![函数 sin(r)/r 的曲面图。](img/surface.png)

```
// Surface 计算 3-D 曲面函数的 SVG 渲染。
package main

import (
    "fmt"
    "math"
)

const (
    width, height = 600, 320            // 画布大小（像素）
    cells         = 100                 // 网格单元数
    xyrange       = 30.0                // 轴范围 (-xyrange..+xyrange)
    xyscale       = width / 2 / xyrange // 每个 x 或 y 单位的像素数
    zscale        = height * 0.4        // 每个 z 单位的像素数
    angle         = math.Pi / 6         // x、y 轴夹角 (=30°)
)

var sin30, cos30 = math.Sin(angle), math.Cos(angle) // sin(30°), cos(30°)

func main() {
    fmt.Printf("<svg xmlns='http://www.w3.org/2000/svg' "+
        "style='stroke: grey; fill: white; stroke-width: 0.7' "+
        "width='%d' height='%d'>", width, height)
    for i := 0; i < cells; i++ {
        for j := 0; j < cells; j++ {
            ax, ay := corner(i+1, j)
            bx, by := corner(i, j)
            cx, cy := corner(i, j+1)
            dx, dy := corner(i+1, j+1)
            fmt.Printf("<polygon points='%g,%g %g,%g %g,%g %g,%g'/>\n",
                ax, ay, bx, by, cx, cy, dx, dy)
        }
    }
    fmt.Println("</svg>")
}

func corner(i, j int) (float64, float64) {
    // 找到单元格 (i,j) 角落处的点 (x,y)。
    x := xyrange * (float64(i)/cells - 0.5)
    y := xyrange * (float64(j)/cells - 0.5)

    // 计算曲面高度 z。
    z := f(x, y)

    // 将 (x,y,z) 等轴测投影到 2-D SVG 画布 (sx,sy) 上。
    sx := width/2 + (x-y)*cos30*xyscale
    sy := height/2 + (x+y)*sin30*xyscale - z*zscale
    return sx, sy
}

func f(x, y float64) float64 {
    r := math.Hypot(x, y) // 到 (0,0) 的距离
    return math.Sin(r) / r
}
```

注意函数 `corner` 返回两个值，即单元格角落的坐标。

程序工作原理的解释只需要基础几何知识，但跳过也没关系，因为重点是说明浮点计算。程序的核心是在三种不同坐标系之间映射，如图 3.2 所示。第一种是 100×100 个单元格的二维网格，由整数坐标 (*i*, *j*) 标识，从远处后角的 (0, 0) 开始。我们从后向前绘制，以便背景多边形可能被前景多边形遮挡。

![三种不同的坐标系。](img/surface-explain.png)

**图 3.2.** 三种不同的坐标系。

第二种坐标系是三维浮点坐标 (*x*, *y*, *z*) 组成的网格，其中 *x* 和 *y* 是 *i* 和 *j* 的线性函数，经过平移使原点位于中心，并按常量 `xyrange` 缩放。高度 *z* 是曲面函数 *f* (*x*, *y*) 的值。

第三种坐标系是二维图像画布，左上角为 (0, 0)。该平面上的点用 (*sx*, *sy*) 表示。我们使用等轴测投影将每个三维点 (*x*, *y*, *z*) 映射到二维画布上。点的 *x* 值越大或 *y* 值越**小**，在画布上显得越靠右。点的 *x* 值或 *y* 值越大，且 *z* 值越**小**，在画布上显得越靠下。*x* 和 *y* 的垂直和水平缩放因子源自 30° 角的正弦和余弦。*z* 的缩放因子 0.4 是一个任意参数。

对于二维网格中的每个单元格，主函数计算多边形 *ABCD* 四个角在图像画布上的坐标，其中 *B* 对应 (*i*, *j*)，而 *A*、*C* 和 *D* 是其邻居，然后打印一条 SVG 指令来绘制它。

## 3.3 复数

Go 提供两种大小的复数，`complex64` 和 `complex128`，其分量分别为 `float32` 和 `float64`。内置函数 `complex` 由实部和虚部创建一个复数，内置的 `real` 和 `imag` 函数提取这些分量：

点击此处查看代码图像

```
var x complex128 = complex(1, 2) // 1+2i
var y complex128 = complex(3, 4) // 3+4i
fmt.Println(x*y)                 // "(-5+10i)"
fmt.Println(real(x*y))           // "-5"
fmt.Println(imag(x*y))           // "10"
```

如果浮点字面量或十进制整数字面量后面紧跟 `i`，例如 `3.141592i` 或 `2i`，它就变成了一个*虚数字面量*，表示实部为零的复数：

点击此处查看代码图像

```
fmt.Println(1i * 1i) // "(-1+0i)", i² = -1
```

根据常量运算规则，复数常量可以与其他数字常量（整数或浮点数，实数或虚数）相加，这让我们可以自然地书写复数，如 `1+2i`，或等价地写作 `2i+1`。上面 `x` 和 `y` 的声明可以简化为：

```
x := 1 + 2i
y := 3 + 4i
```

复数可以使用 `==` 和 `!=` 进行相等性比较。如果两个复数的实部相等且虚部相等，则它们相等。

`math/cmplx` 包提供了用于复数运算的库函数，例如复数平方根和指数函数。

点击此处查看代码图像

```

```

```
// Mandelbrot 生成曼德勃罗分形的 PNG 图像。
package main

import (
    "image"
    "image/color"
    "image/png"
    "math/cmplx"
    "os"
)

func main() {
    const (
        xmin, ymin, xmax, ymax = -2, -2, +2, +2
        width, height          = 1024, 1024
    )

    img := image.NewRGBA(image.Rect(0, 0, width, height))
    for py := 0; py < height; py++ {
        y := float64(py)/height*(ymax-ymin) + ymin
        for px := 0; px < width; px++ {
            x := float64(px)/width*(xmax-xmin) + xmin
            z := complex(x, y)
            // 图像点 (px, py) 代表复数值 z。
            img.Set(px, py, mandelbrot(z))
        }
    }
    png.Encode(os.Stdout, img) // 注意：忽略错误
}

func mandelbrot(z complex128) color.Color {
    const iterations = 200
    const contrast = 15

    var v complex128
    for n := uint8(0); n < iterations; n++ {
        v = v*v + z
        if cmplx.Abs(v) > 2 {
            return color.Gray{255 - contrast*n}
        }
    }
    return color.Black
}
```

两个嵌套循环遍历一个 1024×1024 灰度光栅图像中的每个点，该图像代表复平面上 −2 到 +2 的部分。程序测试反复平方并加上该点所代表的数字，最终是否会“逃逸”出半径为 2 的圆。如果是，则根据逃逸所需的迭代次数对该点进行着色。如果不是，则该值属于曼德勃罗集，该点保持黑色。最后，程序将标志性分形的 PNG 编码图像写入其标准输出，如 图 3.3 所示。

## 3.4 布尔值

`bool` 类型的值，或称*布尔值*，只有两个可能的值：`true` 和 `false`。`if` 和 `for` 语句中的条件是布尔值，比较运算符如 `==` 和 `<` 会产生布尔结果。一元运算符 `!` 表示逻辑非，因此 `!true` 为 `false`，或者可以说 `(!true==false)==true`，尽管就风格而言，我们总是将冗余的布尔表达式如 `x==true` 简化为 `x`。

布尔值可以与 `&&`（逻辑与）和 `||`（逻辑或）运算符结合，它们具有*短路*行为：如果答案已由左操作数的值确定，则不会对右操作数求值，这使得可以安全地编写如下表达式：

```
s != "" && s[0] == 'x'
```

如果将 `s[0]` 应用于空字符串会导致 panic。
