#### 多头注意力机制

一个单独的**Head**，由矩阵集合 (`Q`, `K`, `V`) 定义，提供输入的更新表示并编码相关的上下文信息。这是通过在某些最优计算的子空间中测量输入嵌入投影后的向量相似度来实现的，这些子空间由对应的矩阵集合 (`W`^(q), `W`^(k), `W`^(v)) 决定。

然而，通过使用不同的 `W` 矩阵三元组来获取多个表示（多个查询）是合理的。这类似于 CNN 网络，其中多个不同的核/通道（参见 第 18.12.1 节）被应用于输入，每个核提取不同类型的相关性。

现在假设采用了 `h` 组三元组，即 (`W`[i]^(q), `W`[i]^(k), `W`[i]^(v))，`i` = 1, 2, …, `h`。在这种情况下，我们将得到 `h` 组查询/键/值矩阵，即 (`Q`[i], `K`[i], `V`[i])，`i` = 1, 2, …, `h`。由于训练期间所有 `W` 矩阵都是随机初始化的，我们期望得到 `h` 个不同的注意力矩阵（公式 (19.39)），即：

```
Attention[i] := Attention(Q[i], K[i], V[i]),  i = 1, 2, …, h.
```

### 19.3.7 编码器：添加与归一化层 I

构成多头矩阵（图 19.10）的输出向量 `z[n]`，`n` = 0, 1, …, `N` + 1，被作为输入提供给上一层，该层称为“添加与归一化”层。这是编码器块中两个结构相似的层中的第一个。“归一化”项表示归一化操作。“添加”项代表什么？在文献 [189] 中，以及在大多数后续实现中，采用了残差网络的原理，请参见图 18.33 和 18.34。因此，在此思路下，“添加与归一化”层接受向量之和作为输入，

```
${\\widehat{\\mathbf{t}}}\_{n}: = \\mathbf{x}\_{n} + \\mathbf{z}\_{n},\\ n = 0,1,\\ldots,N + 1.$
```

随后，计算生成向量所有维度上的均值和标准差，即，

```
${\\widehat{\\mu}}\_{n} = \\frac{1}{d\_{m}}\\sum\\limits\_{i = 1}^{d\_{m}}{\\widehat{t}}\_{ni},\\ \\ {\\widehat{\\sigma}}\_{n} = \\sqrt{\\frac{1}{d\_{m}}\\sum\\limits\_{i = 1}^{d\_{m}}{({\\widehat{t}}\_{ni} - {\\widehat{\\mu}}\_{n})}^{2}}.$
```(19.42)

该层的输出向量为以下归一化版本，

$t_{ni} = \frac{\widehat{t}_{ni} - \widehat{\mu}_{n}}{\widehat{\sigma}_{n} + \epsilon},\ \ \mathbf{t}_{n} = [t_{n1},t_{n2},\ldots,t_{nd_{m}}]^{T}$

其中 $\epsilon$ 是一个较小的正常数，用于避免可能出现的除以小数的情况。

另一种可能性是将所有向量 $\widehat{\mathbf{t}}_{n}, n = 0,1,\ldots,N + 1$ 一起考虑进行归一化。为此，我们有

#### 计算复杂度与优化

*   **自注意力层的计算需求**为 𝒪(*N*²)。相关计算可并行执行。相比之下，普通 RNN 对 *N* 呈线性依赖，但因其递归特性无法完全并行化。

*   **应对计算问题**：一条研究路线是利用涉及矩阵的低秩近似；参见文献 [193]、[88]。关于为解决复杂度问题而提出的大量变体的综述，可参见文献 [178]。

*   **Transformer 与 RNN 的联系**：文献 [102] 提供了一个有趣的视角，在二者间建立了桥梁。核心思想在于 Softmax 注意力分数的线性化，这也将计算复杂度依赖降至 𝒪(*N*)。
