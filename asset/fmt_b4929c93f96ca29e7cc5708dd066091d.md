
# 神经网络模型

神经网络模型的特征是其由若干层组成，每层包含单个单元或神经元。在某一层内部，每个单元接收来自前一层的输入并计算自己的输出。某一层内神经元产生的输出将作为该层序列中下一层的输入。

*   基于数学
*   可以检测非线性关系
*   可以处理复杂的模型结构

# 梯度提升

梯度提升是一种集成学习方法，它采用一系列决策树共同构建一个统一的预测模型。梯度提升的过程从一个初始模型开始，随后利用前一个模型的残差作为新目标来完善该模型。

*   基于规则
*   可以检测非线性关系
*   可以处理复杂的模型结构

# 随机森林

随机森林方法是机器学习和统计学中的集成学习技术。它在训练过程中构建许多决策树，其中每棵树都是从训练数据和特征的不同随机子集构建的。树的多样性有助于减少过拟合并增加模型的稳健性。对于分类模型，随机森林的输出对应单个树预测类别的众数。处理关联模型时，随机森林的输出代表来自单个树的平均预测。

*   基于规则
*   可以检测非线性关系
*   可以处理复杂的模型结构

# 贝叶斯网络

贝叶斯网络是基于贝叶斯定理的概率方法，通过考虑先验证据来预测未来事件。它利用有向无环图可视化预测变量与目标变量之间的因果关系。此外，贝叶斯网络的特征是条件概率的集合，有助于因果推断和概率推理。它通过概率方式表示和分析变量之间的关系，成为建模和理解复杂系统的价值工具。

# 如何选择正确的方法

选择正确的机器学习方法是我们需要做的最困难决策之一。使用错误的方法会导致不可用的结果，甚至更糟糕——错误的结果。我将为你提供具体的标准。为了做出这一决定，我们需要知道分析目的、数据类型和大小以及尺度。如果我们从左到右查看表格并回答问题，就可以决定正确的方法。我在图 2.7 中描述了各种场景，供你使用。

## 选择正确学习方法的指南

我在下文中使用了两个示例来演示如何使用这些指南。

### 案例 1

假设我们想根据乘客调查数据预测乘客对航空公司的推荐情况。`Recommendation` 是一个非度量目标变量，具有两个水平：`Yes` 和 `No`。以该变量为起点，我们将从左侧的第一列开始。

*   是否存在预定的目标变量？是的，它是推荐情况。因此，我们应该只关注监督学习方法。
*   它是分类的吗？是的，它是二元的。因此，我们必须跳过线性回归并选择逻辑回归。
*   我们期望的是线性关系还是非线性关系？不确定。所以我们可能预期两者都有。因此，我们仍然在选择中保留逻辑回归，但记住它的局限性（如前所述，从技术上讲，逻辑回归以对数曲线的形式显示非线性关系，但目标变量优势比与预测变量之间的关系仍然是线性的）。
*   我们是否检查预测变量之间的相互关系？如果回答是，那么我们必须跳过逻辑回归。如果不确定，我们可以保留它。让我们假设我们**不想**检查相互关系，因为这会让模型变得更复杂。
*   我们是否想进行因果推断？假设我们回答否。从技术上讲，即使我们不打算进行任何因果推断，也可以使用贝叶斯网络。因此，我们保持开放。
*   最终问题：我们是否需要模型复杂度？请注意，模型复杂度意味着该方法可以产生复杂的结构化模型，但也意味着模型难以被理解和解释。假设我们的回答是“否”，因为我们希望结果具有易于解释的性，特别是预测变量对目标变量的影响。在这种情况下，我们应该跳过神经网络、随机森林、梯度提升和贝叶斯网络。有了这个答案，我们将有两个选择：逻辑回归和决策树。
*   结论是，在这种情况下，我们需要使用监督学习，并关注两种方法：逻辑回归和决策树。为了找到有意义且良好的预测模型，我们需要使用这两种方法，通过不同的配置来构建多个模型。通过比较这些模型，我们将找到“冠军模型”。

### 案例 2

假设我们想在 COVID-19 肺炎流行期间，根据购物模式识别不同的公民群体。目标是根据他们在大流行期间共同的购物行为，查看社会上存在多少个不同的群体。让我们使用指南在这一案例中选择合适的机器学习方法。

*   是否存在预先定义的**变量？没有。我们并不打算预测某个特定的决策或行为。那么，我们应该关注表格后半部分的`unsupervised learning`（无监督学习）方法。
*   数据压缩是本研究的目的吗？不是。因此，我们将跳过`Principal Component`（主成分）方法。
*   社会或市场细分是本研究的目的吗？是的。因此，`Cluster analysis`（聚类分析）仍然是一个选择。
*   我们是否打算将变量分组为少数几个变量？不是。因此，我们保留`Cluster analysis`作为选项。
*   我们是否想根据某些维度的相似性，将观测值（公民）分组成不同的簇或分段？是的，我们想根据他们在大流行期间共同的购物行为将他们分组。因此，最终选择是`Cluster analysis`（聚类分析）。

如你所见，这些指南很容易遵循，不需要带有方框和箭头的复杂图表。请记住，在某些情况下，我们会得到四个或五个可能的选择，而在其他情况下，我们只有一个选择。对于前者，我们可以使用这些不同的学习方法通过不同的配置来开发多个模型。对于后者，当我们仅有一个选择时，我们仍然应该使用不同的配置开发几个模型以找到最佳模型。

# 集成学习 (Ensemble)

在数据挖掘中，有一种值得一提的重要方法，`ensemble modeling`（集成建模）。集成模型通过结合多个模型的预测结果来创建一个单一的共识预测。当单个模型之间意见不一致时，这是数据挖掘中的一种常见做法。集成模型通常比组成它的单个模型更准确。我们无法保证集成模型会比所有其他模型都好，但执行集成学习允许我们探索从其他个体模型组合成模型的可能性，并对其进行比较。这是数据挖掘中一种非常有用的方法。我们将在第 10 章中介绍集成建模的细节。

## 用户界面

对于这些软件，一个重要的标准是用户界面。目前我们看到 `SAS Enterprise Miner`、`Rapid Miner` 和 `SPSS Modeler` 具有可视化的界面，这对于学生、教师和研究人员来说非常友好。`SAS` 和 `Python` 则更依赖于代码，这对于数学和工程领域的人来说可能是一个挑战。此外，`Rapid Miner` 和 `R` 具有一定的学习曲线，需要大量的练习。但是，对于管理和社会科学领域的用户，这些软件提供的灵活性是必不可少的。我们通常通过拖放节点来创建工作图，从而构建预测模型。`R` 和 `Python` 也被工业界广泛接受，是数据科学家的必备技能。此外，`Python` 提供了丰富的库，用户可以访问并使用。

## 工作空间

下一项是工作空间。基本上，数据挖掘过程涉及许多步骤和模型，因此工作图可以帮助我们跟踪这些过程。通常，我们通过将节点拖入工作空间并连接它们来创建这样的工作图。导入数据文件、分区、探索、转换数据、建模和评估等步骤都可以在图中轻松完成。我通常使用不同的算法构建模型。

## 机器学习算法

关于这些软件提供的机器学习算法，我发现 `SAS Enterprise Miner`、`Rapid Miner` 和 `Python` 拥有更强大的算法，允许我们进行更复杂的建模。无论如何，`SPSS Modeler` 和 `R` 正在改进它们的算法，我们已经在这些应用中看到了更多功能。我想指出，所有软件都提供文本分析工具，但当处理文本数据时，`Text Miner` 更易用。文本解析、文本过滤、文本主题和文本聚类等步骤组织良好且连接紧密。另一方面，`Python` 提供了多功能的自然语言处理（NLP）工具和库，允许开发者处理不同的 NLP 任务，包括情感分析、词性标记、词建模、向量等。

## 价格

现在我们进入价格敏感的话题。在这些应用中，`R` 和 `Python` 是完全开源的，因此是免费的。`Rapid Miner` 也是一个开源应用，对学术界免费。但对企业来说不是免费，用于商业用途的开发者必须支付许可。`SPSS Modeler` 也不免费。对企业来说相当贵，对学术界来说仍然昂贵。我相信 IBM 终于将为教育目的免费提供 `SPSS Modeler`，这对我们来说是一个很好的选择。最后，`SAS Enterprise Miner` 对企业也很贵。对于大学，它包含在 SAS 校园软件包中，如果你的大学是 SAS 校园，它是免费的。如果不是，他们提供一个免费的云端版本 `SAS On Demand for Academics`。请注意，目前该版本仅在 Windows 操作系统上运行。

我还想总结一下这些应用程序的一些主要缺点。如上所述，`R` 和 `Python` 是编程语言，因此对新用户来说会有陡峭的学习曲线。它们都缺乏工作区视图，而且这些应用程序的可视化操作非常麻烦。`SPSS Modeler` 和 `Rapid Miner` 都有混乱的工作区设计、难以执行模型比较，以及节点和操作符名称令人困惑。在 `SPSS Modeler` 和 `Rapid Miner` 中，为了查看输出图形，我们必须经过额外的步骤，特别是 `SPSS Modeler`。`SAS Enterprise Miner` 在这方面具有优势，因为所有结果（无论是表格还是图形）都可以在同一个节点中。

此外，`SAS Enterprise Miner`（尤其是免费的云版）也有缺点。第一个缺点是 `SAS` 处理文件夹和文件的方式。与 `SPSS` 和 `Excel` 等软件不同，`SAS` 通过 `libraries` 管理文件夹。这意味着包含文件的文件夹必须连接到一个 `library`，且 `SAS Enterprise Miner` 必须连接到同一个 `library` 才能让我们访问该文件夹中的文件。打开文件确实很繁琐且需要几个步骤，但这就是 `SAS` 始终管理文件夹的方式，因为对于 `SAS` 项目来说这是一种高效的方法，特别是当你有很多包含大量文件的不同文件夹时。请注意，`SAS Enterprise Miner` 并不是为了上传文件、更改文件名或在文件夹之间移动文件而设计的。这些操作必须使用免费的 `SAS Studio` 完成。这需要一些时间来适应，一旦我们理解了流程，就会变得更容易。

如果我们在学术上使用免费的云版，软件速度也将受到限制，因为它取决于网络连接和服务器性能。由于它对所有教师、研究人员和学生都是免费的，因此会有许多人同时访问服务器，这可能会导致处理时间变慢。此外，如前提到的，此时的学术云版仅支持 `Windows OS`。此外，国际学生和研究人员如果从其他国家登录，可能会在访问共享文件夹时遇到困难。根据我使用 `SAS Enterprise Miner` 的经验，一切运行得很顺畅，我很少在运行模型时遇到延迟。注意，云版 `SAS Enterprise Miner` 拥有与企业版完全相同的功能，包括 `High-Performance` 节点和 `Text Miner`。

最后，重要的是数据挖掘软件并不是为了方便进行数据准备或修改而设计的。它们是数据挖掘软件应用，专门用于该任务。像 `Rapid Miner` 和 `SAS Enterprise Miner` 这样的软件应用甚至不允许我们更改数据。这是因为我们正在处理大量数据集，此类功能可能会在我们不知情的情况下意外更改数据。这将是一场灾难，因为输出将变得无效，而且我们无法找到错误所在的地方。因此，如果你发现自己无法在这些应用程序中更改数据甚至更改变量名，请不要惊讶。相应地，数据准备应该在使用数据挖掘软件之前完成。那么，我们该如何准备数据集呢？通常，每个供应商都有其他工具用于此目的。然而，如果你想避免学习另一个软件，我发现 `MS Excel` 是一个编码、合并和清洗数据的良好工具。在下载原始数据集后，我们可以使用 `Excel` 对数据进行编码、合并来自各种来源的数据并清洗数据。`Excel` 为这些任务有许多实用的功能，而且我们都熟悉这个应用程序。一旦我们有了清洗的数据集，只需要将其转换为 `SAS` 或 `SPSS` 格式，就可以使用我们的数据挖掘软件进行建模了。

总之，没有完美的数据挖掘软件，因为它们都有优缺点，并且服务于不同的群体。我们应该根据自己的需求、背景和项目目的来选择软件。由于通用性和适应性，像 `Python` 和 `R` 等编程软件受到这些领域理工科学生和研究人员的欢迎。它们也是某些数据科学家职位所需技能之一。另一方面，这并不意味着如果我们没有编程技能就不能进行数据挖掘。像 `SAS Enterprise Miner`、`SPSS Modeler` 和 `Rapid Miner` 这样的软件可以在不需要代码的情况下完成工作。随着数据挖掘市场的不断进步，商业管理和社会科学领域的学生应该利用这些技术。通过这些应用程序获得的技能让我们能够在没有编程背景的情况下很好地完成数据挖掘项目。在本书，我选择 `SAS Enterprise Miner` 是因为它的健壮性和易于使用的图表。它的云版也是免费且功能全的。我计划在其他书籍中使用 `SPSS Modeler` 和 `Rapid Miner`，所以请关注。
