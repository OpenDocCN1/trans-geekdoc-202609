## 第 1 章：Python 语言是什么？

Python 是一门世界知名的简单、强大且通用的计算机语言。它是开源语言，被称为高级语言、动态语言、图形用户界面语言、面向对象语言、解释器语言。Guido van Rossum 在 1991 年开发了 Python 语言。他出生于荷兰，目前居住在加利福尼亚州 Belmont。他是最佳的软件开发人员。Python 语言可以轻松创建复杂的程序，Python 命令非常简洁，编写 Python 程序很容易。它是免费的开源程序。像 Google 这样的大公司使用 Python 语言。Python 程序在 Windows、Linux、UNIX 和 Mac 等操作系统上运行。大型项目是否必须使用 C、C++ 和 Java 等语言编写？在 Python 语言中，您只需少量代码即可编写出最佳程序。用不同的计算机语言编写的程序可以在 Python 中使用，反之亦然。这是 Python 语言的最大特点。Python 拥有大量标准库，使用它们可以轻松创建程序。Python 可以用于网页应用、电子邮件解析、网络编程、桌面应用、Internet 协议、游戏、机器人程序、移动应用、GUI 应用、科学应用等。Python 也广泛用于人工智能、Internet 脚本、嵌入式脚本、数据库编程、系统工具、机器学习、图像处理、数据科学分析、Web 开发、机器人、自动化等领域。使用 Python 可以创建简单的聊天机器人，甚至可以创建一门编程语言。![python is.jpg](img/rsrc45.jpg)

Python 语言最流行的原因是它在全球范围内的普及。这是一门开源语言。任何人都可以免费下载。不需要支付费用。有大量的社区支持来开发程序。Python 拥有大量的标准库。使用这些库可以创建庞大的程序。编写代码非常容易。你可以用 Python 快速编写程序。Python 语言容易学习。像`Django`、`Flask`、`NumPy`、`SciPy`等框架可以简化程序编写。Python 语言程序也可以用于`C`和`Java`等语言。Python 学习者能立即获得更高薪的工作。基于这些原因，Python 语言非常流行。

1970 年，英国电视台播出了“Monty Python's Flying Circus”节目。Guido van Rossum 来自荷兰。他是这档电视节目的爱好者。他是一名出色的软件开发人员。1991 年，他开发了一门编程语言。他当时考虑将这个名字用于这门编程语言。然后他想起了这档电视节目。这档电视节目取名 Python，并以此命名他的编程语言。这就是 Python 语言的由来。
