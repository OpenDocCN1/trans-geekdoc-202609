## 3.1 深度学习

深度学习是一种机器学习（ML），它接收输入数据并产生输出。正如在机器学习中所讨论的，其区别在于它不需要输入数据特征的显式信息。相反，它会自动提取特征，因此，它非常“渴数据”。获取更多数据可以提高它的效率并帮助它变得准确。深度学习算法由神经网络组成。与其他机器学习技术一样，它有一个用于收集待处理信息 `x` 的输入层，然后是一个或多个隐藏层，最后是一个产生输出（即 `y`）的输出层。在这里，隐藏层设计得更为密集。这些隐藏层负责整个模型的运行功能。

## 3.2 感知机

构成神经网络的构建单元是神经元。那么深度学习中的神经元是什么呢？我们称之为感知机以及它的工作原理。感知机或单个神经元的思想非常简单。让我们从讨论和描述信息的正向传播开始。

(3.1)

## 3.8 经验损失 (Empirical Loss)

这些数字是随机初始化的，对问题一无所知，所以我们必须训练它。我们必须教它如何获得正确答案。因此，我们要做的第一件事是在网络犯错时告诉它，以便我们将来可以纠正它。在神经网络中如何做到这一点？神经网络的损失实际上定义了网络何时做出错误的预测。它接收输入并预测输出。

```
J(w) = (1/n * \sum_{i=1}^{n} L(f(x^{(i)};W), y^{(i)}))
```

(3.19)

然后将真实值（ground truth）实际输出与预测输出组合在一起。如果预测输出和真实输出相互接近，这本质上意味着损失将非常低。它没有犯错，但如果真实输出与预测输出相远，这意味着它应该有非常高的损失。它应该有很多错误，这个网络应该纠正这一点。现在假设我们不仅有来自一个学生的数据，还有来自许多不同的及格和不及格这门课程的学生的数据。因此，我们关心这个模型不仅适用于某一个学生，而且适用于整个学生群体。我们称之为**经验损失**，它只是所有单个学生损失的平均值。我们可以通过使用公式 (3.19) 计算这些每个学生的损失并取其平均值来完成。在训练网络时，我们想要做的不是最小化任何特定学生的损失，而是想要最小化整个训练集的损失。现在，我们想要使用不同的损失函数，因为我们神经网络的输出是不同的。

## 3.9 均方损失 (Mean Square Loss)

这是一个二分类问题，我们的输出是 0 或 1。我们已经学过，当分类器为 1 时，我们可能会使用 softmax 输出。对于那些不熟悉交叉熵的人来说，这个想法实际上是 50 多年前在麻省理工学院的一篇硕士论文中引入的。它被广泛应用于热力学等不同领域，现在被应用于机器学习和整个信息理论 [8]。它在这里做的本质上是计算这个 0, 1 输出与真实输出之间的损失，即学生及格或不及格。让我们假设现在不是计算 0 或 1 输出，而是想计算实际的成绩，即通常在课程中给出的。现在它不是 0, 1，而是成绩，可以是任何数字。

## 3.12 梯度下降

如何计算这一项？这是深度学习和神经网络的关键部分。在通用计算中，这一项本质上是唯一重要的。当我们尝试优化网络时，它也是训练过程中计算量最大的部分，被称为反向传播。我们将从一个具有一个隐藏层和一个输出的简单网络开始。计算损失关于 `W` `[2]` 的梯度，相当于告诉我们 `W` `[2]` 的微小变化如何影响我们的输出或损失。

如果我们将其视为一个导数，可以开始通过简单使用链式法则来计算它，如方程 (3.24) 所示。

```
∂J(W)/∂W_2 = ∂J(W)/∂ỳ * ∂ỳ/∂W_2
```

(3.24)

从损失通过输出反向，现在看起来像方程 (3.25)。

```
∂J(W)/∂W_1 = ∂J(W)/∂ỳ * ∂ỳ/∂W_1
```

(3.25)

我们不断重复这一操作。通过所有这些路径进行反向传播，我们就得到了梯度。我们无法保证这不是全局最小值。随机梯度下降的整个训练是一个贪心优化算法。我们只是采取这种贪心方法并仅优化局部最小值，如方程 (3.26) 所示。

```
∂J(W)/∂W_1 = ∂J(W)/∂ỳ * ∂ỳ/∂z_1 * ∂z_1/∂W_1
```

(3.26)
