
| 参数估计 | 贝叶斯网络通过指定先验概率并用观测数据更新来估计后验概率。后验分布反映了来自先验知识和数据的结合信息。 | 频率派方法使用极大似然估计等技术估计参数，其目标是找到使观测数据似然最大化的参数值。 |
| 推理 | 贝叶斯网络提供了一个概率推理框架，能够计算各种感兴趣的概率，例如后验概率、条件概率和预测。 | 频率派方法聚焦于点估计和假设检验。它们根据观测数据提供估计和检验，而不直接量化概率。 |
| 样本量 | 贝叶斯网络通过将先验知识纳入分析，可以有效处理较小的样本量。先验信息可以作为正则化项，有助于稳定估计并避免过拟合。 | 由于频率派方法依赖观测数据，通常需要较大的样本量来进行可靠的估计和假设检验。 |
| 可解释性 | 贝叶斯网络提供了一个基于概率解释结果的自然框架，使得更容易沟通不确定性并根据后验分布做出明智决策。 | 频率派方法倾向于更多关注相关性估计和 p 值，在不显式考虑不确定性的情况下，这些有时被误解或导致二元决策。 |

## 贝叶斯网络与因果推断

![](img/icon_4.jpg)实现贝叶斯网络方法时的一个常见问题是我们是否可以根据结果进行因果推理。如前所述，贝叶网络可以为变量之间的依赖关系和条件关系提供宝贵的见解。基本上，它们通过概率关系捕捉并表示变量之间的因果关系。然而，重要的是，如果没有先验领域知识或理论基础，单凭贝叶斯网络无法在严格意义上建立因果关系或推断因果关系。虽然它们没有显式地确定因果关系，但它们可以根据网络中建模的概率依赖关系推断因果关系。让我们进一步了解这些细节。

贝叶斯网络主要根据观测数据和假设捕捉变量之间的统计依赖关系。它们对变量之间的条件概率和关系方向进行建模，这对于预测、执行概率推理以及在给定观测证据的情况下估计事件概率非常有帮助。在贝叶斯网络中，节点之间的有向边表示条件依赖或因果关系。例如，如果变量 `A` 是网络变量 `B` 的父节点，这意味着 `A` 对 `B` 有直接的因果影响。网络结构以及每个节点关联的 `CPTs` 共同编码了变量之间的概率关系。

如前所述，贝叶斯网络本身不能证明因果关系。要证明真正的因果关系，我们需要隔离输入变量 `A` 并测试它在保持其他输入变量不变的情况下对输出变量 `B` 的影响。这通常在受控环境中进行，允许我们得出 `A` 确实导致 `B` 的结论。然而，这种方法并不适用于数据挖掘项目，因为它需要设置实验，并且只能检查一两个输入变量的因果效应。在数据挖掘中，贝叶斯网络的结果可以根据观测数据和网络结构建议因果关系，但通常需要进一步的实证证据或领域知识来确定因果关系。在我们之前的示例中，从贝叶斯网络中得出的概率关系表明 `A` 可能与 `B` 存在直接的因果关系。然后，研究人员使用进一步的理论基础、领域知识甚至额外的实证证据来证明 `A` 是否真的导致 `B`。

![](img/ufig16_4.jpg)尽管如此，贝叶斯网络可以作为工具帮助理解和表示因果假设。通过将领域知识和因果假设纳入网络结构和条件概率中，贝叶斯网络可以为推理潜在因果关系及其影响提供一个框架。具体来说，贝叶斯网络允许我们根据观测证据进行概率推断。这种推理可以用于分析网络内部的因果关系。因此，在本书中，当我们使用“因果推理”或“推断因果关系”术语时，我们主要指的是在假设拥有先验领域知识和因果假设的情况下，根据贝叶斯网络结构在概率推断方面确定的因果关系。

## 贝叶斯网络的不同类型

![](img/icon_5.jpg)贝叶斯网络是一种先进且强大的方法，当目标变量与预测变量一起确定时，可以用于监督学习。贝叶斯网络模型可以捕捉变量之间的依赖关系，并根据学习到的概率进行预测或分类。对于在有标记训练数据的领域，它是分类、关联和概率推理等任务的强大方法。

贝叶斯网络结构主要有四种类型：朴素贝叶斯（Naïve Bayes）、树增强朴素贝叶斯（`TAN`）、贝叶斯网络增强朴素贝叶斯（`BNAN`）和马尔可夫毯子（Markov Blanket）。图 16.4 以图的形式展示了这些网络结构的结构。

![图 16.4 四种贝叶斯网络学习算法。](img/fig16_4.jpg)

图 16.4 四种贝叶斯网络学习算法。

### 朴素贝叶斯

朴素贝叶斯方法经常用于构建贝叶斯网络，主要由于其简单性。在朴素贝叶斯网络中，目标变量作为所有其他节点（预测变量）的父节点，形成了一个简单的结构。预测变量之间没有其他连接，因为输入变量被假设为彼此是条件独立的。这种假设允许快速高效的训练和分类。然而，当预测变量之间相互依赖时，朴素贝叶斯可能会受到限制，因为它忽略了变量之间的任何依赖关系。

这种方法以简单和易于构建而闻名，使其成为对训练样本量要求较小的选择。它是数据挖掘项目中常用的监督学习算法，允许与其他机器学习技术进行直接比较。然而，它的适用性受到条件独立假设的限制，将其使用限制在预测变量与目标变量之间存在直接关系的简单网络中。在预计预测变量将表现出因果依赖复杂网络中，这种假设通常会被违反。

### 树增强朴素 (TAN)

`TAN` 通过添加一种树结构来捕捉变量之间的依赖关系，从而扩展了朴素贝叶斯。`TAN` 贝叶斯网络将目标变量与每个预测变量连接，并以树结构连接预测变量。该算法基于最大生成树算法构建网络。在 `TAN` 中，每个预测节点最多有两个父节点：目标节点和最多一个另一个预测节点。因此，每个预测节点只能有一条指向它的增强边。

通过放宽条件独立假设，这种方法在保留其简单性和高效的同时可以优于朴素贝叶斯。它保留了朴素贝叶斯的简单性和高效，但通过引入有限的变量依赖关系允许了更具表达能力的模型。然而，由于树结构的限制（每个预测节点最多有两个父节点：目标节点和另一个预测节点作为可选父节点），它不允许对预测变量之间的完整因果网络结构进行全面探索。

### 贝叶斯网络增强朴素 (BAN)

`BAN` 是 `TAN` 的扩展，它整合了更通用的贝叶斯网络结构。它通过在变量之间学习完整的贝叶斯网络结构来允许任意的变量间依赖关系。在 `BAN` 中，预测节点是目标节点的直接子节点，但在预测节点之间建立了一个几乎完整的贝叶斯网络，扩展了简单的树结构。因此，每个预测节点可以有多个父节点，但其中一个必须是目标变量。此外，目标变量必须是父节点而不能是子节点。`BAN` 学习算法类似于 `TAN` 学习算法，主要区别在于使用了无限制的贝叶斯网络（`BN`）学习算法而不是基于树的学习方法。无限制贝叶斯网络学习算法通常用于实际的机器学习应用。

与朴素贝叶斯（Naive Bayes）和 `TAN` 相比，`BAN` 提供了一种更灵活的建模方法。`BAN` 算法适用于从复杂系统的大数据中学习因果网络结构。它可以捕捉变量之间更复杂的关系，但代价是增加了训练和推理的计算复杂度。

### 马尔可夫毯 (Markov Blanket)

在贝叶斯网络的背景下，节点的马尔可夫毯是一个概念，它定义了一个节点集合，使得该节点与网络中的所有其他节点条件独立。换句话说，给定马尔可夫毯节点，该节点在概率上与网络中的所有其他节点独立。马尔可夫毯网络在目标变量与其预测变量之间建立连接，同时允许特定输入变量之间建立连接。仅允许目标变量的孩子具有额外的父节点，而所有其他变量与目标变量保持条件独立。

目标变量的马尔可夫毯包含三种节点：

- **父母 (Parents)**：贝叶斯网络中目标变量的父。这些是通过入边直接连接到目标节点的节点。
- **孩子 (Children)**：目标变量的子。这些是通过出边直接连接到目标节点的节点。
- **配偶 (Spouses)**：目标变量孩子的父母。这些是直接连接到目标变量孩子的节点，但不包括目标变量本身。

马尔可夫毯之所以重要，因为它代表了在预测目标变量或执行概率推理时需要观测或考虑的最小变量集。一旦知道了马尔可夫毯变量，毯子之外的变量与目标变量无关。马尔可夫毯提供了一种识别和利用贝叶斯网络中变量之间条件独立关系的方法。它通过关注最小相关变量集，帮助降低概率推理的计算复杂度。

### 网络结构学习算法

![](img/icon_4.jpg)贝叶斯网络过程中的一个重要步骤是从数据中学习网络结构。在数据挖掘中，采用学习算法来完成这项任务。在贝叶斯网络背景下，主要有两种学习算法：基于评分的算法和基于约束的算法（参见表 16.3）。在本节中，我们将对这些算法及其差异建立基础性的理解。

Table 16.3 基于评分的算法与基于约束的算法之间的差异

| 项目 | 基于评分的算法 | 基于约束的算法 |
| --- | --- | --- |
| 方法 | 优化评分指标（例如 `log-likelihood`、`BIC`、`AIC`）以找到最拟合数据的网络结构。 | 通过识别变量之间的条件独立关系来推断网络结构，而不直接优化评分指标。 |
| 目标 | 最大化评分指标以平衡模型复杂性和数据拟合度。 | 关注捕捉变量之间的直接条件依赖关系，以构建一个更具解释性的网络。 |
| 搜索空间 | 通过对网络结构进行局部修改（如添加、删除或反转边）来探索搜索空间。 | 利用统计检验来识别条件独立关系并构建骨架图，随后将其精化为部分有向无环图（DAG）。 |
| 评分指标 | 直接使用评分指标来评估和比较不同的网络结构。 | 不直接使用评分指标，但生成的网络结构可以使用单独的评分方法进行评分。 |
| 优点 | - 对于大型数据集具有高效性和可扩展性。<br>- 提供了模型拟合的直接衡量标准。<br>- 可以同时处理类别变量和连续变量。 | - 对过拟合具有鲁棒性，且需要的样本较少。<br>- 捕捉直接条件依赖关系，导致网络更具解释性。<br>- 处理混合数据类型。 |
| 局限性 | - 对局部最优敏感，可能无法彻底探索整个搜索空间。<br>- 需要较大的样本量来进行可靠的参数估计。 | - 由于关注直接依赖，可能无法捕捉某些复杂关系。<br>- 在对许多变量进行条件独立检验时，计算量巨大。 |
| 可解释性 | 生成的网络可能很复杂，更难解释。 | 网络结构通常反映直接的因果关系，更具解释性。 |
| 常见算法 | `Hill Climbing`、`Tabu Search`、`Genetic Algorithms` 以及 `Max-Min Hill Climbing (MMHC)`。 | `GES`、`IAMB` 算法以及 `PC (Peter & Clark)` 算法。 |

基于评分的算法是一种贝叶斯网络结构学习方法，它通过最大化评分指标来根据数据识别最可能的网络结构。该算法旨在根据特定的评分标准找到最拟合数据的网络结构。最常用的评分指标包括 `log-likelihood`、贝叶斯信息准则 (`BIC`) 和赤池信息准则 (`AIC`)。分数越高，模型与数据的拟合程度越好。

基于约束的算法是一种通过发现变量之间的概率依赖关系从数据中学习网络结构的方法，而不直接优化评分指标。基于约束的算法不是穷尽搜索所有可能的网络结构空间，而是迭代地测试和评估变量之间的条件独立关系，以确定网络结构。

这些方法都有其优缺点，方法的选择取决于数据集的大小、网络的复杂性、领域知识的可用性以及对结果模型所需的解释性要求等因素。

### 因果数据挖掘过程

![](img/icon_7.jpg)鉴于贝叶斯网络能够捕捉复杂网络中变量之间的概率关系，我想介绍因果数据挖掘的概念，以及贝叶斯网络如何应用于因果数据挖掘项目。

![](img/ufig16_5.jpg)在之前的章节中描述的常见数据挖掘项目中，我们的目标是使用机器学习算法从数据中检测未知关系，从而使我们能够预测目标变量。在这些项目中，结果是一个根据重要预测变量准确预测目标变量的预测模型。变量之间的特定关系（捕捉变量如何相互作用和影响）通常不是研究的重点。用户需要的是一个能够准确预测感兴趣的风险或事件的冠军模型。

如果在某些情况下，用户想要深入挖掘数据中的模式（关于变量如何相互作用和影响），因为他们需要更深层次的洞察呢？或者进一步，他们想知道哪个变量对另一个变量有直接因果影响，而后者又影响另一个变量，以此类推。理解复杂网络中的因果关系使组织能够理解预测并长期建立有效的业务策略。在这种情况下，顺序数据挖掘可能不起作用。我们需要一种新的数据挖掘。我称之为*因果数据挖掘*。

在我 2021 年发表于《空中运输管理杂志》（Journal of Air Transport Management）的文章中，我将*因果数据挖掘*定义为“一种利用因果机器学习算法从数据到因果网络中涉及变量及其相互关系的未知模式，以预测结果的方法”。对于这类数据挖掘项目，像 SEMMA 或 CRISP-DM 这样的通用流程可能并不适用，因为它们没有反映问题的因果本质。因此，我开发了一个六步的因果数据挖掘流程：理解、采样、探索、学习、评估和推断，即 USELEI (Truong, 2021b)）。在本节中，我将描述这一过程以及它如何用于因果数据挖掘。

图 16.5 展示了 USELEI 流程的六个步骤，表 16.4 描述了每一步的详细目的和细节 (Truong, 2021b)。

表 16.4 USELEI 因果数据挖掘流程

| 步骤 | 描述 |
| --- | --- |
| **第一步：理解 (UNDERSTANDING)** 目的：理解研究问题和目标 | 步侧重于从业务角度理解研究问题和研究目标。必须收集有关行业、市场、利益相关者、系统或组织的信息，然后将其转换为需要挖掘大数据来预测结果的问题陈述和研究问题。研究人员需要确定他们期望从因果数据挖掘中获得什么。应该描述系统的复杂性和动态，以及模型中可能的变量。 |
| **第二步：采样 (SAMPLING)** 目的：选择数据集、采样和划分 | 从可靠的数据源收集并采样数据。采样方法取决于目标总体和研究范围。数据集应该足够大，以包含用于知识发现的充分信息，但不应太大，以确保建模过程的效率。然后，将数据划分为训练样本和验证样本。训练样本用于训练模型，而验证样本用于验证模型。如果选择了交叉验证方法，则应将数据分为更多的子样本。 |
| **第三步：探索 (EXPLORING)** 目的：探索和准备数据 | 仔细探索数据集，以对变量、描述性统计、缺失值和离群值获得充分理解。必须正确分析和处理缺失数据和离群值，以避免信息丢失的同时减少偏差。因果数据挖掘数据准备中的一个关键步骤是离散化，它使用了离散化算法，如等距、归一化等距、等频、Kmeans 和树算法。 |
| **第四步：学习 (LEARNING)** 目的：学习无监督和监督因果网络并进行交叉验证 | 首先，构建无监督网络结构，以在不确定目标变量的情况下探索变量之间的初步因果关系。虽然该网络允许在变量之间进行因果推理并识别出对整个网络最重要的变量，但它没有指示每个变量对目标变量的重要性和影响。该网络是构建完整网络的起点。然后，使用已确定目标变量的因果学习算法构建监督网络。该网络允许研究人员预测目标变量，并检查每个预测因子对目标变量的重要性和影响。由于网络结构是从数据中学习的，因此通过比较训练和验证样本来验证创建的网络非常重要。对于大数据，建议使用更稳健的验证方法（如 k 折交叉验证），以最小程度减少过拟合问题。 |
| **第五步：评估 (EVALUATING)** 目的：评估网络性能和预测精度 | 使用模型拟合指标评估因果网络性能，以确保模型的可靠性和有效性。如果开发的模型不符合评估标准，则需要进行事后分析。在此步中，可以修改模型，通过逐个移除对目标变量预测贡献最低的变量来提高网络性能。这是一个迭代过程，持续进行直到达到满意的网络性能。 |
| **第六步：推断 (INFERRING)** 目的：进行目标分析、敏感性分析和因果推理 | 报告有影响的预测因子以及它们对目标变量的影响幅度。应该同时解释总效应和直接效应。此外，可以进行敏感性分析，以发现一个预测因子的变化如何影响目标变量。最后，进行因果推理，根据效应发生的条件检查所选预测因子与目标变量之间的因果连接。推断可用于开发不同的“假设”（what-if）场景，基于这些，决策者可以制定必要的策略来应对事件或减轻风险。 |

### USELEI 与 SEMMA 及 CRISP-DM 的区别

你可能会问：为什么我们需要另一个数据挖掘流程？USELEI 与另外两个流程（SEMMA 和 CRISP-DM）有什么不同？

表 16.5 提供了三种数据挖掘流程（USELEI、CRISP-DM 和 SEMMA）的总结和比较。这些流程在采样、数据探索与准备、建模和模型评估等步骤方面具有相似性。然而，对于因果数据挖掘，USELEI 流程比另外两个具有独特优势。它对构建因果网络结构、执行因果推理和进行敏感性分析有更多的强调。这些能力对于组织做出明智的业务决策非常有价值。

表 16.5 USELEI、CRISP-DM 和 SEMMA 的比较

| 项目 | USELEI | CRISP-DM | SEMMA |
| --- | --- | --- | --- |
| 步骤 | 理解→采样→探索与准备→学习与验证→评估→推断 | 业务理解→数据理解→数据准备→建模→评估→部署 | 采样→探索→修改→建模→评估 |
| 对业务问题的理解 | 是 | 是 | 否 |
| 采样过程 | 是 | 边缘 | 是 |
| 数据探索与准备 | 是 | 是 | 是 |
| 建模与验证 | 是 | 是 | 是 |
| 完整因果网络结构 | 是 | 否 | 否 |
| 模型评估 | 是 | 是 | 是 |
| 决策支持（因果推理） | 是 | 否 | 否 |
| 决策支持（敏感性分析） | 是 | 否 | 否 |

总体，SEMMA 和 CRISP-DM 是不需要变量间因果关系的顺序数据挖掘项目的优秀流程。USELEI 专为因果数据挖掘设计。虽然它服务的受众较窄，但该流程为开展因果数据挖掘项目提供了严谨且详尽的步骤。

我想提到贝叶斯网络在数据挖掘中起着至关重要的作用。这种方法允许我们从数据构建贝叶斯网络，提供变量间的概率关系。使用贝叶斯网络结构不仅是为了对目标变量进行预测，还为了通过推断检查变量之间的关系。我们在书中不会使用 `USEI`，但我将向你展示如何在示例中使用贝叶斯网络结构进行推断。

## 贝叶斯网络的参数调优

![](img/8.jpg)贝叶斯网络的参数调优通常涉及寻找最佳结构和设置以优化模型性能。与通常具有参数的机器学习算法不同，贝叶斯网络具有网络结构和参数估计过程。以下是调优贝叶斯网络时考虑的一些关键参数。

- **网络结构**：贝叶斯网络中节点（变量）和边（有向连接）的排列。不同的结构配置会导致不同的依赖关系。
- **节点和边**：添加或删除节点可以改变网络结构。添加新节点可以简化模型。
