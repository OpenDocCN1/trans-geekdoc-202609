## 附录 2

### 网络安全绩效指标

网络安全绩效可沿不同维度进行衡量。以下是可根据组织需求适当修改的示例指标集。

| 类别 | 指标 |
|---|---|
| 业务价值影响 | - 安全漏洞造成的损害和损失金额<br>- 预防安全攻击节省的金额<br>- 解决安全问题所花费的金额 |
| 生产力影响 | - 用于解决安全问题的工时数<br>- 因运营中断而损失的工时数 |
| 事件性质及发生频率 | - 安全漏洞数量<br>- 安全漏洞类型 |
| 准备程度 | - 第三方访问审查频率<br>- 具有有效网络安全政策的业务合作伙伴百分比<br>- 平均检测时间与平均响应时间<br>- 注销前员工凭证的天数 |
| 审计与合规 | - 遵守 ISO 27001 指南的程度<br>- 上次审计以来仍未解决的高风险发现数量 |
| 漏洞评估 | - 存在已知漏洞的系统数量<br>- 配置不正确的 SSL 证书数量<br>- 使用企业网络传输的数据量<br>- 具有“超级用户”访问级别的用户数量<br>- 特定期间内开放的通信端口数量<br>- 第三方访问关键企业系统的频率 |

### 网络安全准备度评分卡：准备情况

本评分卡可用于衡量组织从识别数据保护需求到保护数据、网络、设备、存储位置和人员方面的网络就绪状态。分数将揭示优势领域和改进机会。该评估工具旨在作为指南和模板，可根据组织的独特需求进行适当定制。

| 类别 | 问题 |
| --- | --- |
| **识别—组织角色认知** | 1. 领导层是否认识到其在供应链及更广泛范围内的组织角色和责任？这种认识是否在网络安全战略计划中明确记录？<br>0 = 否 1 = 是<br><br>2. 组织的目标、使命和目标是否在网络安全战略计划中明确记录？<br>0 = 否 1 = 是<br><br>3. 网络安全战略如何与整体组织战略保持一致，是否在网络安全战略计划中明确说明？<br>0 = 否 1 = 是<br><br>4. 是否设有跨职能团队协助供应链角色识别、风险评估、网络安全战略制定和对齐以及威胁场景识别？<br>0 = 否 1 = 是 |
| **识别—网络风险评估** | 1. 组织是否进行对其网络风险承受能力和漏洞的全面和定期评估？<br>0 = 否 1 = 是<br><br>2. 是否有由高层领导代表组成的跨职能团队参与此类风险评估？<br>0 = 否 1 = 是 |
