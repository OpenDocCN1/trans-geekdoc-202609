## Kraken

## Kubernetes

`Kubernetes` 是一个可移植、可扩展的开源平台，用于管理容器负载以及运行 Linux 容器和服务的主机集群。它由 Google 的工程师于 2014 年设计，拥有大型且快速增长的生态系统。`Kubernetes` 源自希腊语，意为舵手或导航员。由于 K 和 S 之间正好有八个字母，它通常被称为 `K8s`。

## KYC (了解您的客户)

`KYC` 是金融服务中的一系列活动或指南，服务提供者努力验证客户身份、适用性以及与其建立业务关系涉及的风险。`KYC` 文件通常包括身份证明和地址证明文件，如护照、驾照、选民证等。`KYC` 帮助银行、金融机构和加密货币交易所执行并完成洗钱政策。`eKYC` 指使用互联网或数字手段完成身份验证。

### Kimchi premium (韩国溢价)

`Kimchi premium` 是韩国与世界其他地区加密货币价格的差异。溢价通常出现在比特币价格中，并在 2018 年 1 月达到 55%。缺乏其他高回报投资渠道、对技术的深度兴趣以及在线赌博导致了韩国这种溢价产生。

## Ledger (账本)

账本是包含账户的簿，将日记中的分类和汇总信息以借贷的形式记录在其中。区块链是基于点对点 (`P2P`) 构建的公共电子账本，公链中可以开放共享，私有链中通过许可共享。它在不同用户之间共享，创建不可变或不可更改的交易记录，每条记录都有时间戳并与前一条记录链接。

## Libra (现为 Diem)

## Light Client (Light Client)

轻量客户端（也称为部分节点或轻量级客户端）是区块链生态系统中关键元素。它们帮助用户以安全去中心化的方式访问并与区块链交互，无需同步整个区块链。它们基于轻节点，只下载区块头以建立交易的真实性。当与整个区块链网络连接时，它们由全节点提供服务。

## Light Node (Light Node)

轻量级节点使用称为简化支付验证（`SPV`）的方法验证交易。`SPV` 允许节点在无需下载整个区块链的情况下验证交易是否已包含在区块中。通过 `SPV`，全节点通过允许轻量级节点连接并将交易传输到网络来提供服务，并在交易影响它们时通知它们。轻量级节点只需要下载区块链上所有区块的头部，这意味着它的下载和存储需求相对于全节点要低得多。

## Lightning_Network (闪电网络)

闪电网络是一种运行在基于区块链的加密货币之上的二层支付协议。它旨在实现参与节点之间的快速交易，并被提议作为解决比特币扩展性问题的解决方案。双方之间的交易将在区块链之外执行，即作为链下交易。这将减少交易处理时间和相关成本。`Thaddeus Dryja` 和 `Joseph Poon` 在于 2015 年制定了比特币闪电网络。

## Linux Foundation (Linux 基金)

`Linux Foundation` 总部位于美国旧金山，是一个成立于 2000 年的非营利技术财团，它是开源开发实验室和自由标准小组合并的，旨在使 Linux 标准化、支持其增长并促进其商业化采用。它促进开放或开源技术的采用。115 亿行代码、235,000 多名开发者和 19,000 多家贡献公司构成了 Linux 会的权力和全球影响。`Cloud Foundry`、`Delta Lake`、`Drone Code`、`Hyperledger Blockchain`、`Node.js` 和 `Open Chain` 都是 `Linux Foundation` 保护下的知名项目。

## Lite Coin (加密币)

## Liquidity_mining (流动性挖矿)

流动性挖矿（或收益农）是 `DeFi` 的一项功能，允许人们在去中心化交易所（`DEX`）或 `dApp` 上存入（或“质押”）加密货币或代币以获得奖励。它被 `Uniswap` 和 `Compound` 等 `DEX` 普及。交易通过流动性池内的代币交换进行。用户每次交易，用户将支付某些费用。自动做市商（`AMM`）收集费用并将其作为奖励授予流动性提供者。

### Liquidity_pools (流动性池)

流动性池是 `DEX` 的一项功能，允许人们在没有任何中间人的情况下进行相互交易。

## Main_Net (主网)

主网是一个术语，用于描述区块链协议完全开发并部署为活动网络，与测试网（`Testnet`）不同。主网上的加密货币交易正在广播、验证并记录在分布式账本技术上。主网是执行将数字货币从发送者传输到接收者功能的区块链。它还被视为项目的最终结果以及对各自区块链项目白皮书中所承诺的履行。

## Market Cap (市值)

市值（`Market capitalization`）是以美元金额或任何其他适用法币表示的公司的总市场价值。由于它代表了公司的市场价值，它是根据其加密货币的当前市场价格和流通中的发行发行总数计算的。`Coinmarketcap.com` 跟踪几乎 5000 种加密货币的市值，以及 24 小时和 7 天的价格变化及其流通供应量。

## Merkle Tree (默克尔树)

默克尔树（也称为哈希树）是一种安全高效地加密大量数据的数据结构。它被表示为哈希树，其中每个叶节点都标记有数据块的加密哈希值，每个非叶节点都标记有其子节点标签的加密哈希值。哈希树是哈希列表和哈希链的推广，允许对大量数据进行验证。它们提供了对大量数据的安全高效验证。

## Merkle Patricia Tree (默克尔帕特里亚树)

`Merkle Patricia` 树（或称 `Merkle Patricia Trie`）是默克尔树的变体，由以太坊用于优化存储大量数据，包括保存状态的能力。`Merkle Patricia` 树旨在提供一种加密认证的数据结构，可用于存储所有的（键，值）绑定。它结合了 `Patricia` 树和默克尔树的特点。

`Patricia` 树 是一种数据结构，也称为前缀树、基数树或字典树，通常用于实现路由表和用于路由器等低规格机器的系统。

### Merkle Root (默克尔根)

它是区块中包含的所有交易的哈希值的哈希。它是区块头的一部分。通过仅下载小的区块头和默克尔树，就可以建立交易已被区块链网络接受。无需下载整个区块链即可建立交易的有效性。

### Micro chain (微链)

微链是侧链的一种变体，允许链上的资产传输到另一个区块链。实际上，资产并没有从一条链传输到另一个链。它们在原始链上锁定并在目标链上创建。它们还将共识规则和智能合约逻辑从一条链扩展到另一链。侧链与父链强耦合，并作为父链共识规则的完整验证者。

### Micropayment (微支付)

微支付是一种小额交易，通常在线上进行，可以小到一分分之一。取决于支付系统，“微支付”可以定义为任何小于 1.00 美元、5.00 美元或更多的交易大小。区块链技术让在线即时微支付的想法从死寂中复活，并提供了一种让这些小支付可行的新方法。区块链消除了高昂的交易费用使微支付成功。这已通过基于 `MakerDAO Dai` 稳定币构建的会议币 `BuffiDai` 充分证明。它证明所有交易的处理成本仅为 0.20 美元，相比之下，如果商家接受信用卡支付，将产生 2400 美元的成本。

## 矿工

矿工是区块链网络中的一种节点，负责收集交易并将它们组织成区块。每当交易发生时，所有网络节点都会接收这些交易并验证其有效性。然后，矿工节点从内存池中收集这些交易，并在验证后开始将它们组装成区块。在比特币网络中，矿工获得两种奖励——新比特币（用于发现新的比特币区块，通过成功解决数学问题以获得与区块相关的私钥，从而确认区块并将交易写入其中）和交易手续费（用于验证交易，以便交易中涉及的比特币可以被花费）。

## 挖矿

加密货币挖矿是验证用户之间交易并将其添加到区块链公共账的过程。挖矿过程还负责通过计算机的处理能力解决复杂的数学问题，将新代币引入现有的流通量中。它是允许加密货币作为点对点中心化网络运行的关键要素之一，不需要第三方中央机构。

## 挖矿难度

挖矿难度是衡量挖矿所需计算机资源量的相对指标，例如：新鲜比特币。在比特币网络中，难度大约每 2,016 个区块增加或减少一次。如果之前的 2,016 个区块被挖得很容易，那么下一个 2,016 个区块的挖矿难度就会增加，反之亦然。在以太坊中，难度是根据寻找下一个以太坊区块有效解决方案所需的哈希次数或矿工数量来量的。随着更多矿工或算力加入网络，难度会自动增加，以确保新区块不会快速添加到网络。

## 矿池

在加密货币挖矿中，矿池是矿工对计算机资源或算力的聚合，他们在网络上共享处理能力来解决数学问题以寻找新区块。他们根据自己为发现和解决新区块贡献的算力和工作量平均分配奖励。`Slush Pool`（已挖出 125 万个 BTC）、`ViaBTC`、`AntPool` 和 `BTC.com` 是世界上一些领先的比特币矿池。`SparkPool`、`Ethpool`、`Nanopool` 和 `Dwarfpool` 是一些领先的以太坊矿池。

## Mint

`Bitcoin.com` 推出了 `Mint`，这是一个免费平台，让任何人都能快速轻松地创建代币。与 `Bitcoin.com` 的其他专业代币产品相结合，`Mint` 预计推动区块链的采用，因为它为庞大的新代币生态系统的发展提供了燃料。`Mint` 正在升级到 `Pitco 2.0`。

## Mist

`Mist` 是一款全功能软件，用于管理个人在以太坊区块链上的所有资产和合约。`Mist` 可以浏览 `DApps`、管理合约、管理 Ether 以及其他数字资产。它像通往区块链网络的窗口，访问网络中提供的不同应用程序和服务。它还支持 `Whisper`（去中心化通信协议）和 `Swarm`（去中心化存储平台）。

## Morden

以太坊 0.9 版本以 `Olympic` 的命名于 2015 年初发布。第一个公共测试网。到 2015 年年中，`Olympic` 被废弃并被 `Morden` 取代。随后，`Frontier` 以太坊官方版本 1 于 2015 年作为公共主网发布，并在 2016 年分叉到 `Homestead`。从测试网的角度来看，`Morden` 等同于 `Frontier`。它在 2016 年底废弃并被 `Ropsten` 取代。

## Multisig (多重签名)

多重签名（`Multisig`）是指使用多个密钥来授权区块链交易，而不是来自一个密钥的单一签名。它避免了单点故障，使得钱包被破解的难度大大增加。因此，多重签名钱包可以程序化：当使用 3 个密钥中的至少 2 个时即可授权交易。`Electrum`、`Armory` 和 `BitGo` 是多重签名钱包的示例。

## NAT (网络地址翻译)

`NAT` 将本地网络中注册或未注册的计算机 IP 地址翻译为单个 IP 地址。该地址通常由连接计算机到互联网的路由器使用。路由器可以连接到 `DSL` 调制解调器、电缆调制、`T1` 线路，甚至是拨号调制。区块链正在赋予智能 `NAT` 管理方案，以克服垂直模型中存在的限制。通过区块链实现 `NAT`，每个节点将对管理复杂的 `NAT` 和移动管理程序所需的必要参数达成共识。

## 数字银行

数字银行是一种没有任何分支的数字银行。数字银行并非物理存在于特定地点，而是完全在线的。数字银行也被提供数字和移动优先金融解决方案、支付和转账、贷款等的金融科技公司。`Chime`、`Monzo`、`Revolut`、`N26` 和 `Klarna` 是全球领先的数字银行。

## 网络价值模型

在区块链网络中，每个参与者都应该拥有价值，但网络本身应该设计为促进这种价值的产生。因此，价值模型基于以下原则：为 1) 为网络提供资金的人、2) 需要该网络的人以及 3) 经常使用网络的人创造价值。通常，我们看到一家大公司构建许可链或无许可的区块链网络，但真正驱动此类区块链网络采用和使用的实际上是使用它的供应商。因此，价值必须为所有方创造，并应该在原型设计阶段、最小可行性产品（`MVP`）阶段或网络阶段完成。如果在 `MVP` 阶段未完成，则应在进入市场阶段（即从 `MVP` 阶段扩展到生态系统生产状态的过程中）完成。

## Nexledger

`Nexledger` 是由三星 SDS 开发的开源混合、私有许可区块链平台。`Nexledger` 是一个全功能平台，其核心集成了监控工具、外部链接、应用程序编程接口和结构化的 DevOps 环境等组件。它提供兼容以太坊 (`Nexledger E`) 和 `Hyperledger Fabric` (`Nexledger F`) 版本。它提供两种产品：提供 API 库以集成多种区块链共识算法的 `Nexledger Universal`，以及帮助将每秒交易数 (`TPS`) 提高 15 倍的 `Nexledger Accelerator`。

## NFT (非同质化代币)

非同质化代币 (`NFT`) 是区块链数字账本上的一个数据单元，每个 `NFT` 可以代表一个独特的数字项目；因此它们是不可互换的。`NFT` 可以代表数字文件，如艺术、音频、视频、视频游戏物品、虚拟资产和其他创意作品。可以在 `NFT` 交易场购买 `NFT`。`NFT` 导致了数字收藏（也称为加密收藏品）的增长。`Cryptokitties`、`Cypherpunk`、`Topstops` 是一些领先的 `NFT`。它们在各个市场上出售——`NBA Top Shot`（篮球）、`Sorare`（足球）、`Decentral Land`（虚拟房地产）、`Axie Infinity`（视频游戏）。

## NGMI (没戏了)：

这是一种加密货币俚语，用于指示加密货币交易员或投资者将在某次交易中错失巨额利润。它也被用作一种模因币的名字，卖出 `NGMI` 代币的人将不允许买回。

### NiPoPoW (非交互式工作量证明)

由雅典大学、爱丁堡大学、伊利诺伊大学等开发。这些用于验证运行在工作量证明（`PoW`）共识机制的区块链网络是否发生了某个事件。这些可以在不连接区块链网络且不下载区块头的情况下，通过网络中的各种节点进行验证。它们支持侧链和手机手机区块链钱包。

### Node JS

`Node.js` 是一个开源、跨平台的后端 JavaScript 运行时环境，运行在 `V8` 引擎上并在网络浏览器之外执行 JavaScript 代码。它由 `Ryan Dahl` 编写于 2009 年发布。`Node.js` 让开发者可以使用 JavaScript 编写命令行工具和进行服务器端脚本——在服务器端运行脚本以便在页面发送到用户的网络浏览器之前生成动态网页内容。除了 JavaScript 之外，它还用 `C` 和 `C++` 编写。`Node JS` 正用于开发加密货币和建立区块链。

### Nodes (节点)

节点构成了区块链的基础设施。它们存储、传播和保护区块链数据，因此从理论上说，区块链存在于节点之上。全节点基本上是一个设备（如计算机），它包含了区块链交易历史的完整副本。点对点（`P2P`）协议允许节点在区块链网络中相互交互、通信并传播有关新区块和交易的信息。节点分为三种：矿工节点、轻节点和全节点。

### Nonce (仅使用一次的数字)

`Nonce` 是一个随机整数，是一个 32 位（4 字节）字段。它代表了矿工竞争求解并获得加密货币的数字。矿工调整 `Nonce` 以使其成为一个有效的数字，用于区块值的哈希。`Nonce` 是只能使用一次的数字。一旦找到了完美的 `Nonce`（也称为黄金 `Nonce`），它会被添加到哈希后的区块中。这完成了区块及其添加到区块链的操作。与该数字一起，该区块的哈希值将被重新哈希，以创建一个让区块链更强大、更安全的算法。

### Notary (公证)

在传统世界中，公证员是授权在法律事务中执行行为的人，特别是见证文件签名。分布式账本技术公司 `R3` 使用“公证服务”来防止其 `Corda` 区块链网络中的双重花费。公证集群是一种网络服务，通过对给定交易进行证明为共识提供唯一性。它仅适用于未签名的交易以及未消耗任何提议交易输入状态的交易。如果交易已经签名，它将拒绝交易并将其标记为双重花费尝试。它代表了交易在系统中作为有效或无效的终点。

### NVT ratio (NVT 比率)

`NVT` 代表网络价值与交易量的比率，通过将网络价值除以每日交易量来计算。它由 `Willy Woo` 于 2017 年引入。对于加密货币而言，`NVT` 可以等同于用于计算股票估值的市盈率（`P/E` 比率）。`NVT` 意味着区块链网络或加密货币是否被高。如果区块链网络的价值过高，且没有相应数量的交易或代币交换支撑，则表明存在一个很快就会纠正的潜在价格泡沫。
