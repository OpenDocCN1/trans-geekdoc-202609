关于项集，[67] 专注于流上频繁项集挖掘，[202] 除了描述 `IncMine` 的 MOA 实现外，还包含多种流上项集挖掘算法优缺点的对比。

关于序列模式，[180] 是近期综述，主要针对批处理场景。[174, 204] 是流上序列挖掘的两种方法。

关于频繁子树挖掘，[24, 69, 142] 详细阐述了各种“子树”概念并综述了相关批处理算法。[158] 提出了 `FQT-Stream`，一种用于在 XML 数据流上挖掘所有频繁树模式的在线算法。[34] 描述了本章采用的流模式挖掘通用方法，并特别将其应用于子树挖掘。

关于子图挖掘，两篇针对批处理情况的综述是 [142, 206]。从图流中挖掘频繁子图的两个算法是 `gspan` [251] 及其闭合图扩展 `CloseGraph` [252]。[35] 提出了图流中子图挖掘的核心集概念及第 10.2.1 节中的算法。[207] 探讨了在单个大型动态（流式）图中寻找频繁子图的问题。

我们省略了关于*关联规则*的讨论，因为通常它们是通过首先从数据集（或流）中挖掘频繁项集，然后从挖掘出的项集中确定频繁规则来获得的；也就是说，除了挖掘频繁项集之外，没有什么本质上特定于流设置的内容。树的关联规则或概率蕴涵在文献[23]中有讨论，并被证明在若干非平凡方面与集合上的关联规则表现不同。

序列模式挖掘框架（SPMF）[106]包含许多模式挖掘算法的实现，主要用于批处理设置，且多为 Java 语言。`IncMine`、`AdaGraphMiner` 和 `Moment` 的实现可在 MOA 网站的*扩展*部分获得。

#### MOA 及其生态系统简介

**M**assive **O**nline **A**nalysis（MOA）是一个开源软件框架，允许用户在不断演变的数据流上构建和运行机器学习及数据挖掘实验。它由新西兰怀卡托大学开发，并以一种名为恐鸟的大型、已灭绝、不会飞的鸟类命名，这种鸟过去只生活在新西兰。

MOA 的显著特点是它可以通过仅对数据进行一次扫描、每个数据项耗时极短，从大型数据集或流中学习和挖掘。在扫描数据时，它仅存储摘要和统计信息，而不是实例本身，因此内存使用通常也很小。

MOA 使用 Java 编写，并在 GNU 通用公共许可证条款下分发。它包含一组学习器、流生成器和评估器，可从图形用户界面（GUI）、命令行界面（CLI）和 Java API 使用。基于 Java 的优势在于可移植性以及强大且成熟的支持库。该语言使用广泛，自动垃圾回收等特性有助于减轻编程负担和错误。MOA 可在任何拥有合适 Java 虚拟机的平台上运行，如 Linux、Mac、Windows 和 Android。

MOA 的一个预期设计目标是易于使用且易于扩展。

有几个与 MOA 相关的开源软件库。其中一些，如 `ADAMS`、`MEKA` 和 `OpenML`，在其系统内部使用 MOA 执行数据流分析。`StreamDM` 包含 MOA 中一些最流行方法的 C++ 实现，而 `Apache SAMOA` 是一个新平台，利用 Hadoop 硬件在分布式环境中执行流挖掘。

在本书的这一部分中，我们将展示如何使用 GUI、CLI 和 Java API，以及如何掌握 MOA 算法、生成器和评估器。

在本章中，我们首先简要讨论 MOA 的架构以及如何安装软件。之后我们将介绍 MOA 的最新发展和可用的扩展，最后展示一些可以与 MOA 结合使用或作为其替代品的开源框架。目的不是使读者精通所有这些其他包，而是让他们了解这些工具的可能性。

### 11.1 MOA 架构

MOA 围绕*任务*的概念构建。在 MOA 中运行的所有实验都被定义为任务。有简单的任务，如将流写入文件或计算流的速度，但最重要的任务是评估任务。例如，在分类中，第 6.1 节描述了两种主要的评估方法：留出法和预测式。

MOA 包含用于分类、回归、聚类、异常检测、推荐和频繁模式挖掘的方法。任务通常由流源、学习器和评估参数组成，例如使用的实例数量、输出结果的周期性以及输出预测的文件名。此外，不同类型的任务需要不同的评估策略。

任务可以从 GUI 或 CLI 运行。

### 11.2 安装

MOA 可从 [`moa.cms.waikato.ac.nz`](https://moa.cms.waikato.ac.nz) 获取，最新版本始终可以作为压缩 zip 文件下载。发布包包含一个 `moa.jar` 文件，这是一个可执行的 Java jar 文件，可以作为 Java 应用程序运行或从命令行调用。它还包含 `sizeofag.jar` 文件，用于测量实验使用的内存。脚本 `bin\moa.bat`（Windows）和 `bin/moa.sh`（Linux 和 Mac）是启动 MOA GUI 的最简便方式。

### 11.3 MOA 的最新发展

本书未详细涵盖的 MOA 最新发展包括：

*   **多目标学习：** 一个用于多目标学习 [91, 188, 232] 的选项卡，其目标是同时预测多个相关的目标属性。多目标学习的例子包括同一建筑中温度的预测、同一路网中的轨迹预测或股票价格预测。

*   **异常检测**：一个用于基于距离的异常检测 [20, 120] 的选项卡。该选项卡使用最广泛采用的标准来确定一个元素是否为异常，该标准基于固定距离内邻居元素的数量，对比一个固定阈值。

*   **推荐系统**：MOA 有一个任务用于使用在线推荐算法。MOA 中的 `EvaluateOnlineRecommender` 任务接收一个评分预测器和一个数据集（每个训练实例为一个 [用户, 物品, 评分] 三元组），并评估模型在给定用户和物品的情况下预测评分的效果，随着处理实例越来越多。这类似于推荐系统的在线场景，其中用户对物品的新评分不断到达，系统必须对用户未评分的物品进行预测，以知道推荐哪些物品。有两种在线推荐算法可用：`BaselinePredictor` 和 `BRISMFPredictor`。第一种是一个非常简单的评分预测器，第二种实现了文献 [234] 中描述的一种分解算法。

### 11.4 MOA 扩展

以下有用的 MOA 扩展可从其网站获得：

*   **IBLStreams：** `IBLStreams` [225]，在第 8.4 节中描述，是一种用于数据流分类和回归问题的基于实例的学习算法。

*   **MOA-IncMine：** `IncMine`，由文献 [66] 提出并在第 10.3.4 节中描述，从不断演变的数据流中计算频繁闭项集。MOA 中的实现描述于文献 [202]，并使用了来自文献 [106] 的 `CHARM` 批量挖掘器实现。

#### MOA 扩展组件

*   **MOA-AdaGraphMiner:** `AdaGraphMiner` [35]（参见第 10.4 节）是一个用于在时变流中挖掘频繁子图的框架。它包含三种用于挖掘频繁闭合子图的新方法。所有方法均在闭合子图的核心集（图集合的压缩表示）上工作，并以批增量方式维护这些集合，但采用不同的方法来应对潜在的概念漂移。

*   **MOA-Moment:** `Moment` [70] 是一种基于流滑动窗口的闭合频繁项集挖掘器。此版本由 M. Jarka 实现（[www.admire-project.eu](http://www.admire-project.eu)）。

*   **MOA-TweetReader:** 该扩展从 Twitter Streaming API 读取并转换推文为 MOA 实例，以促进推文的流式分析。

*   **Classifiers & DDMs:** 该扩展提供多种已发布的集成分类器（`DWM`、`RCD`、`Learn++.NSE`、`EB`）、概念漂移检测器（`ECDD`、`PHT`、`Paired Learners`）和人工数据集（`Sine` 和 `Mixed`）。

*   **MODL split criterion and GK class summary:** 这种用于数值属性的新分裂标准基于 `MODL` 方法 [48]。`GK class summary` 基于 Greenwald 和 Khanna 的分位数摘要（参见第 6.4.3 节），但在该版本中，类别计数包含在摘要的每个元组中。

*   **Incrementally Optimized Very Fast Decision Tree (iOVFDT):** `Hoeffding tree`（第 6.3.2 节）的一种新扩展，提出于文献 [132]。

*   **Anytime Nearest Neighbor**: `Liu` 和 `Bell` 实现的基于文献 [227] 的随时分类器。

*   **Social Adaptive Ensemble 2 (SAE2)**: 基于社会的算法，包括 `Scale-Free Network Classifier (SFNClassifier)` [25, 126] 和 `Social Network Clusterer Stream (SNCStream)` [26]。

*   **Framework for Sentiment Analysis of a Stream of Texts**: 该项目旨在构建一个在线实时系统，能够分析传入的文本流并使用最小化的桌面应用程序可视化其主要特征 [18]。

*   **MOAReduction**: 一个允许用户在无漂移流上执行数据缩减技术的 MOA 扩展。它包含用于不同任务的多种缩减方法，如离散化、实例选择和特征选择，如文献 [205] 所述。

*   **MOA for Android**: 包含使 MOA 可作为 Android 应用程序一部分使用的软件。

### 11.5 ADAMS

`WEKA` 和 `MOA` 是执行数据挖掘分析任务的强大工具。通常在实际应用和专业环境中，数据挖掘过程复杂且包含多个步骤。这些步骤可视为工作流。专业数据挖掘人员会使用工作流构建解决方案，而非编写 Java 程序，这样非程序员用户也能更轻松地理解和维护。`Advanced Data mining And Machine learning System (ADAMS)` [213, 214] 是一个灵活的工作流引擎，旨在快速构建和维护真实世界的复杂工作流。它集成了 `MOA`、`WEKA` 和 `MEKA` 等数据挖掘应用，支持 `R` 语言、图像和视频处理及特征生成能力、电子表格和数据库访问、可视化、`GIS`、Web 服务，并支持使用脚本语言（`Groovy`/`Jython`）快速原型开发新功能。

ADAMS 的核心是工作流引擎，遵循“少即是多”的理念。它不让用户在画布上放置操作符（或称作 `actor`）并手动连接输入输出，而是使用树状结构。该结构和控制 `actor` 定义了数据在工作流中的流动方式；无需显式连接。树状结构源于内部对象表示和 `actor` 处理程序中子 `actor` 的嵌套。

### 11.6 MEKA

`MEKA` [212] 是怀卡托大学发起的一个开源项目，用于执行和评估多标签分类。它使用所谓的问题转换方法，使 `WEKA` 单标签（二分类或多分类）方法可作为多标签分类的基分类器；参见第 6.7 节。

`MEKA` 包含所有基本问题转换方法、高级方法（包括常作为近期多标签文献基准的各种分类器链变体），以及算法适配（如多标签神经网络和深度神经网络）。它包含两种自动阈值校准策略和多种文献中的评估指标。`MEKA` 易于通过 `CLI` 或 `GUI` 使用（图 11.3）。因此无需编程即可参数化、运行和评估分类器，适合不熟悉 Java 的从业者。不过，扩展 `MEKA` 的新分类器并将其集成到其他框架中非常简单。熟悉 `WEKA` 的用户几乎没有学习曲线——`WEKA` 的大部分文档和操作模式直接适用。任何新的 `MEKA` 分类器均可结合 `MEKA` 现有的任何集成方案和任何 `WEKA` 基分类器，无需编写额外代码，并可轻松与基准及最先进方法比较。`MEKA` 还支持多标签背景下的半监督和流式分类，如第 6.7 节所述。

### 11.7 OpenML

`OpenML` [238, 239] 是一个在线平台，科学家可在其中自动记录和共享机器学习数据集、代码和实验，在线组织它们，并直接基于他人的工作构建。它有助于自动化研究中许多繁琐的方面，易于集成到多种机器学习工具中，并提供易用的 `API`。它还支持大规模和实时协作，允许研究人员共享最新结果，同时追踪其影响力和复用情况。组合和关联的结果提供了丰富信息，可加速研究、辅助数据分析或实现实验全自动化。

### 11.8 StreamDM

**StreamDM-C++** [43] 是华为诺亚方舟实验室发起的一个开源项目。它用 C++ 为数据流实现了 Hoeffding 自适应树（第 6.3.5 节），并在华为内部得到了广泛应用。Hoeffding 自适应树能适应数据流中的变化，这是一个巨大的优势，因为标准决策树是使用数据快照构建的，无法随时间演变。

**用于 Spark Streaming 的 StreamDM** [39] 是一个用于挖掘大数据流的开源项目，它使用 **Spark Streaming** [253]，后者是核心 Spark API 的一个扩展，可实现对数据流的可扩展流处理。

### 11.9 Streams

**streams** [46] 框架是一个简单流处理环境的 Java 实现。它旨在提供一个清晰且易于使用的基于 Java 的平台来处理流数据。streams 库的核心模块是一层薄薄的接口和类 API，反映了流式处理过程的高层视图。该 API 是使用 streams 库实现自定义处理器和提供服务的基础。

streams 库的流分析模块提供了用于分析的在线方法实现，例如不同的近似计数算法和在线统计计算（如分位数摘要）。由于 streams 包含 MOA，因此 MOA 的方法可在该框架内使用。

### 11.10 Apache SAMOA

**Apache 可扩展高级海量在线分析 (SAMOA)** [181] 是一个为大数据流提供分布式机器学习的框架，具有可插入不同流处理平台的接口，这些平台运行在 Hadoop 生态系统中。
