
### 3.2.3 Hodgkin-Huxley 模型

(3.19)
```
da_Na/dt = λ_t [ α_Na(E)(1 - a_Na) - β_Na(E)a_Na ]
```

(3.20)
```
dh_Na/dt = λ_t [ α_h(E)(1 - h_Na) - β_h(E)h_Na ]
```

(3.21)
```
da_K/dt = λ_t [ α_K(E)(1 - a_K) - β_K(E)a_K ]
```

其中 `α(E)` 和 `β(E)` 分别是正向和反向速率函数，`λ_t` 是一个与温度相关的因子。正向和反向参数取决于电压，由 Hodgkin 和 Huxley 根据经验估算得出，如下所示：

(3.22)
```
α_Na(E) = (3.5 + 0.1E) / (1 - e^(-(3.5 + 0.1E)))
```

(3.23)
```
β_Na(E) = 4e^(-(E + 60)/18)
```

(3.24)
```
α_h(E) = 0.07e^(-(E + 60)/20)
```

(3.25)
```
β_h(E) = 1 / (1 + e^(-(3 + 0.1E)))
```

(3.26)
```
α_K(E) = (0.5 + 0.01E) / (1 - e^(-(5 + 0.1E)))
```

(3.27)
```
β_K(E) = 0.125e^(-(E + 60)/80)
```

正如神经网络与动作电位模拟器（SNNAP）文献 [\[12\]](#c03.xhtml#c3-bib-0012) 所述，`α(E)` 和 `β(E)` 参数已从原始的 Hodgkin–Huxley 版本转换而来，以符合当前的生理学惯例，即膜去极化被视为正值。此外，静息电位已偏移至 –60 mV（原版为 0 mV）。这些方程用于 SNNAP 中描述的模型。在图 3.4 中模拟了一个动作电位。对于该模型，参数设置为 `C_m` = 1.1 μF cm^(−2)，`ḡ_Na` = 100 ms cm^(−2)，`ḡ_K` = 35 mS cm^(−2)，`ḡ_l` = 0.35 mS cm^(−2)，和 `E_Na` = 60 mV。

仿真可以运行以生成一系列动作电位（AP），这在实践中发生于事件相关电位（ERP）信号的情况。如果钾电流的最大离子电导 `ḡ_K` 降低，模型将显示更高的静息电位。此外，当 `ḡ_K` = 16 mS cm^(−2) 时，模型将开始表现出振荡行为。图 3.5 展示了最大钾电导降低的 Hodgkin-Huxley 振荡模型的结果。

SNNAP 还可以对爆发式神经元和中央模式发生器进行建模。这源于这样一个事实：许多神经元表现出周期性的尖峰活动，随后跟随一段不活动期。几种无脊椎动物以及哺乳动物的神经元都是爆发式细胞，并表现出高频尖峰行为期与无尖峰活动期交替出现的现象。

### 3.2.4 Morris-Lecar 模型

比 Hodgkin-Huxley 模型更简单的用于模拟尖峰神经元的模型是 Morris-Lecar 模型 [\[14\]](#c03.xhtml#c3-bib-0014)。该模型是一个最小生物物理模型，通常表现出单个动作电位。该模型认为，去极化膜的缓慢钙波振荡导致爆发状态。Morris-Lecar 模型最初是为描述藤壶肌肉细胞的行为而开发的。将膜电位 (`E`) 和钾激活 `w_k` 与激活参数相关联的控制方程如下：

(3.28)
```
C dE/dt = I_i - ḡ_Ca a_Ca(E) (E - E_Ca) - ḡ_K w_k (E - E_K) - ḡ_l (E - E_l)
```

(3.29)
```
d w_k / dt = λ_t ( w_∞(E) - w_k ) / τ_k(E)
```

其中 `I_i` 是三种离子电流（钙 Ca、钾 K 和漏电流 `l`）的组合，类似于 Hodgkin-Huxley 模型，它们是最大电导 `ḡ`、激活成分（如 `a_Ca`、`w_k`）和驱动力 `E` 的乘积。钾激活变量 `w_k` 的变化与稳态激活函数 `w_∞`（一条 S 形曲线）和时间常数函数 `τ_k(E)`（一条钟形曲线）成正比。这些函数分别定义为：

(3.30)
```
w_∞(E) = 1 / (1 + e^(-(E - h_w) / S_w))
```

(3.31)
```
τ_k(E) = 1 / (e^((E - h_w) / 2 S_w) + e^(-(E - h_w) / 2 S_w))
```

参与钙电流计算的稳态激活函数 `a_Ca(E)` 定义为：

(3.32)
```
a_Ca(E) = 1 / (1 + e^(-(E - h_Ca) / s_m))
```

与 Hodgkin-Huxley 模型中的钠电流类似，钙电流也是一种内向电流。由于钙激活电流相对于钾电流而言是一个快速过程，因此将其建模为瞬时函数。这意味着对于每个电压 `E`，都要计算稳态函数 `a_Ca`。钙电流不包含任何失活过程。此处的激活变量 `w_k` 类似于 Hodgkin-Huxley 模型中的 `a_K`，最后，两个模型的漏电流是相同的 [[12]](#c03.xhtml#c3-bib-0012)。图 3.6 展示了 Morris-Lecar 模型的仿真。
