
此时前者较小，`1-NN` 将 `x` 标记为 `pos`。

### 属性归一化

有一种方法可以轻松解决这种情况。在训练集中，将所有属性的值缩放到并归一化到 `[0, 1]`，这样属性的影响将变得更加平衡。我们可以看到属性值的尺度可以从根本上影响 `k-NN` 的行为。

### 属性缩放的另一个方面

归一化在许多应用中可以减少误差，特别是当属性尺度差异很大。缺点是示例的描述被扭曲了。此外，将所有值限制在 0 到 1 之间的做法可能并不合理。例如，如果夏季和秋季之间的差异总是大于两个归一化的体温之间的差异。这取决于工程师的常识，可能还需要一些实验。

### 理论的实际局限性

工程师的世界对理论要求并不感兴趣。在实际应用中，训练样本只会稀疏地分布在实例空间，增加投票邻居的数量可能会适得其反。通常情况下，错误率会随着 `k` 的增加而提高，但只能提高到某一点后开始再次增长——如图 3.5 所示，横轴代表 `k` 的值，纵轴代表在独立测试集上测量的错误率。解释非常简单：较远的“最近邻居”可能会发现自己处于（实例空间中的）已被其他类别占据的区域；因此，它们只会误导分类器。考虑极端情况：如果训练包含 25 个训练样本，那么 `25-NN` 分类器就是没用的，因为它简单地将任何对象标记为训练数据中代表数量最多的类。

### 维度灾难

显然，在分类对象 `x` 时，它的某些最近邻居可能与 `x` 不相似，不参与投票。这通常发生在具有许多属性的领域中。假设每个属性的值都限制在单位长度区间 `[0 1]` 内。使用勾股定理，很容易证明在由这些属性定义的 `n` 维空间中最大欧几里得距离为 `dMAX = √n`。

![image](img/image112.png)![image](img/image474.png)

应当超过那三个较远的“负”邻居的权重。

![image](img/image261.png)![image](img/image122.png)类，因为正类邻居的总权重 `†^C 0:6 0:7 1:3` 大于负类邻居的权重 `†^(\-) 0:1 0:2 0:3 0:6`。正如图 3.6 所示，频率更频繁的负标签被正类邻居投票否决，因为后者距离 `x` 更近。

### 具体公式

让我们引入一个简单的公式来计算权重。假设 `k` 个邻居根据它们到 `x` 的距离 `d1;:::; dk` 进行了排序，使得 `d1` 是最小距离而 `dk` 是最大距离。第 `i` 个最近邻居的权重计算公式如下：

```
wi = (dk - di) / (dk - d1)
```

![image](img/image465.png) (3.4)

![image](img/image154.png)![image](img/image112.png)显然，由此得到的权重范围将从最远邻居的 0 到最近邻居的 1。这意味着该方法实际上只考虑了 `k-1` 个邻居（因为 `wk = 0`）。当然，这仅在 `k > 3` 时才有意义。如果我们使用 `k = 3`，那么只有两个邻居真正参与，加权 `3-NN` 分类器将退化为 `1-NN` 分类器。

表 3.4 在一个简单的玩具领域上展示了该过程。

![image](img/image112.png)![image](img/image112.png)另一个需要观察的重要点是，如果所有最近邻居到 `x` 的距离相同，那么根据等式(3.4)的分母部分，它们将获得相同的权重 `wi = 1`。读者可以很容易地验证，当且仅当 `dk = d1` 时，所有 `k` 个最近邻居到 `x` 的距离相同。

```
w1 = (8 - 1) / 7 = 1

```
