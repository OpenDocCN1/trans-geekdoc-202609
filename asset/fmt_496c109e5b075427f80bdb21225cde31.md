选项 A 错误。集中日志系统有利于监控和故障排除，但它并不能直接解决高峰期间的可扩展性问题。

选项 C 错误。增加数据备份的频率是数据完整性和恢复的良好做法，但不会直接处理可扩展性问题。

选项 D 错误。定期的安全培训对于公司的网络安全态至关重要，但它无法解决平台的架构可扩展性问题。

# 问题 258

一家电子商务公司正在为即将到来的黑色星期五促销做准备，预计网络流量将激增。为了确保系统在销售期间保持响应，实施以下哪种策略是**最有效**的？

- (A) 增加所有用户的密码复杂度
- (B) 限制销售商品的数量
- (C) 实施内容分发网络 (`CDN`)
- (D) 进行年度安全审计

**解析 258.** 正确答案：C。实施内容分发网络 (`CDN`)。`CDN` 将流量负载分布在多个服务器上，这些服务器通常在地理上分散。

这不仅加快了向用户交付内容的速度，有助于处理流量激增，确保系统在黑色星期五促销等高需求期间保持响应。

选项 A 错误。增加密码复杂度可以增强安全性，但不会直接影响高流量期间的系统响应能力。

选项 B 错误。限制销售商品的数量可能会减少服务器负载，但也可能减少潜在收入，而且不是提高系统响应能力的直接方法。

选项 D 错误。虽然年度安全审计对于识别漏洞至关重要，但它们无法直接解决高流量期间的系统响应问题。

# 问题 259

一家跨国公司在不同国家设有数据中心。由于监管限制，对这些数据中心的远程访问受到严格限制。公司的 IT 管理员需要一种安全化的方式来访问所有数据中心，而无需从工作站直接访问它们。公司应该考虑哪种解决方案？

- (A) 建立 `DMZ`
- (B) 实施跳板机 (`Jump server`)
- (C) 部署活动目录 (`Active Directory`)
- (D) 使用本地代理 (`Proxy`)

**解析 259.** 正确答案：B。实施跳板机。跳板机（也称为堡垒机）充当中间服务器，允许用户在访问另一个服务器或网络之前连接到它。它在两个网络（如内部网络和外部网络）之间提供了受控的访问手段。

选项 A 错误。`DMZ`（非军事化区）是一个物理或逻辑子网络，包含并将组织的面向外部的服务暴露给不可信的网络（通常是互联网）。它并不能提供像跳板机那样的集中访问点。

选项 C 错误。活动目录是用于 Windows 域网络的目录服务。它的设计目的不是提供对多个数据中心受控的远程访问。
