
如果程序不仅仅是一次性实验，你大概率希望编译一次并保存编译结果以备后用。这通过 `go build` 完成：

```
$ go build helloworld.go
```

这将创建一个名为 `helloworld` 的可执行二进制文件，可随时运行而无需进一步处理：

```
$ ./helloworld
Hello,
```

我们为每个重要示例都加上了标签，提醒你可以从书籍的源代码仓库 `gopl.io` 获取代码：

gopl.io/ch1/helloworld

如果你运行 `go get gopl.io/ch1/helloworld`，它将获取源代码并将其放入相应目录。更多相关内容请参见第 2.6 节和第 10.7 节。

现在让我们谈谈程序本身。Go 代码组织在包中，这类似于其他语言中的库或模块。一个包由单个目录下的一个或多个 `.go` 源文件组成，定义了包的功能。每个源文件以 `package` 声明开头（此处为 `package main`），说明该文件属于哪个包，随后是导入的其他包列表，然后是该文件中存储的程序声明。

Go 标准库拥有 100 多个包，用于输入输出、排序、文本处理等常见任务。例如，`fmt` 包包含用于格式化输出和扫描输入的函数。`Println` 是 `fmt` 中的基本输出函数之一；它打印一个或多个值，值之间用空格分隔，并在末尾添加换行符，使这些值显示为单行输出。

`main` 包比较特殊。它定义了一个独立的可执行程序，而非库。在 `main` 包中，`main` `function`（函数）也很特殊——它是程序执行的入口。`main` 做什么，程序就做什么。当然，`main` 通常会调用其他包中的函数来完成大部分工作，例如 `fmt.Println` 函数。

## 编译器包声明与导入

我们必须告诉编译器此源文件需要哪些包；紧随 `package` 声明之后的 `import` 声明即承担此角色。“hello, world”程序仅使用了另一个包中的一个函数，但大多数程序将导入更多包。

你必须准确导入所需的包。如果缺少导入或存在不必要的导入，程序将无法编译。这一严格要求防止了随着程序演进，对未使用包的引用累积。

`import` 声明必须跟在 `package` 声明之后。随后，程序由函数、变量、常量和类型的声明组成（分别由关键字 `func`、`var`、`const` 和 `type` 引入）；在大多数情况下，声明的顺序无关紧要。由于此程序仅声明了一个函数，而该函数又仅调用了另一个函数，因此它短小精悍。为节省篇幅，我们在展示示例时有时会省略 `package` 和 `import` 声明，但它们存在于源文件中，且编译代码时必须包含它们。

函数声明由关键字 `func`、函数名、参数列表（`main` 为空）、结果列表（此处也为空）以及包裹在大括号中的函数体——即定义其行为的语句——组成。我们将在第 5 章深入探讨函数。

除非同一行出现两条或更多语句或声明，否则 Go 不要求在语句或声明末尾加分号。实际上，特定记号后的换行会被转换为分号，因此换行的位置对 Go 代码的正确解析至关重要。例如，函数的左大括号 `{` 必须与 `func` 声明的末尾位于同一行，而不能独占一行；在表达式 `x + y` 中，允许在 `+` 运算符后换行，但不允许在其前换行。

Go 对代码格式化持强硬立场。`gofmt` 工具将代码重写为标准格式，`go` 工具的 `fmt` 子命令会对指定包中的所有文件（或默认情况下当前目录下的文件）应用 `gofmt`。本书中的所有 Go 源文件均已通过 `gofmt` 处理，你也应养成对自己的代码这样做的习惯。强制规定标准格式消除了大量关于琐事的无谓争论，更重要的是，它使各种自动化源代码转换成为可能，而如果允许任意格式，这些转换将不可行。

许多文本编辑器可配置为在每次保存文件时运行 `gofmt`，从而确保源代码始终保持正确格式。相关工具 `goimports` 还能根据需要自动插入和移除导入声明。它不在标准发行版中，但可通过以下命令获取：

```
$ go get golang.org/x/tools/cmd/goimports
```

对大多数用户而言，下载构建包、运行测试、查看文档等的常用方式是使用 `go` 工具，我们将在第 10.7 节探讨它。

## 1.2 命令行参数

大多数程序处理某种输入以产生输出；这几乎就是计算的定义。但程序如何获取用于操作的输入数据？某些程序自行生成数据，但更多时候，输入来自外部源：文件、网络连接、另一程序的输出、键盘输入的用户、命令行参数等。接下来的几个示例将讨论其中一些替代方案，首先从命令行参数开始。

`os` 包提供了以平台无关方式与操作系统交互的函数和其他值。命令行参数通过 `os` 包中的名为 `Args` 的变量提供给程序；因此，在 `os` 包之外任何地方，其名称均为 `os.Args`。

变量 `os.Args` 是一个字符串 *切片*。切片是 Go 中的基本概念，我们稍后将详细讨论。目前，可将切片视为数组元素的动态大小序列 `s`，其中单个元素可通过 `s[i]` 访问，连续子序列可通过 `s[m:n]` 访问。元素数量由 `len(s)` 给出。与大多数其他编程语言一样，Go 中的所有索引均使用包含首索引但不含尾索引的 *半开区间*，因为这简化了逻辑。例如，切片 `s[m:n]`（其中 0 ≤ `m` ≤ `n` ≤ `len(s)`）包含 `n-m` 个元素。

`os.Args` 的第一个元素 `os.Args[0]` 是命令本身的名称；其余元素是程序启动时传递给它的参数。形式为 `s[m:n]` 的切片表达式生成一个引用元素 `m` 到 `n-1` 的切片，因此我们下一个示例所需的元素位于切片 `os.Args[1:len(os.Args)]` 中。如果省略 `m` 或 `n`，它们分别默认为 0 或 `len(s)`，因此我们可以将所需切片简写为 `os.Args[1:]`。

下面是 Unix `echo` 命令的一个实现，它在单行上打印其命令行参数。它导入了两个包，以括号列表的形式给出，而非单独的 `import` 声明。两种形式均合法，但惯例上使用列表形式。导入顺序无关紧要；`gofmt` 工具会将包名按字母顺序排序。（当存在一个示例的多个版本时，我们通常会对其编号，以便你确知我们在讨论哪一个。）

gopl.io/ch1/echo1

```
// Echo1 prints its command-line arguments.
package main

import (
    "fmt"
    "os"
)

func main() {
    var s, sep string
    for i := 1; i < len(os.Args); i++ {
        s += sep + os.Args[i]
        sep = " "
    }
    fmt.Println(s)
}
```

注释以 `//` 开头。从 `//` 到行尾的所有文本均为程序员的注释，编译器会忽略它们。按照惯例，我们在包声明前紧跟一个注释来描述每个包；对于 `main` 包，此注释为一个或多个完整句子，描述整个程序。

`var` 声明声明了两个 `string` 类型的变量 `s` 和 `sep`。变量可在声明时初始化。若未显式初始化，则隐式初始化为其类型的 *零值*：数值类型为 `0`，字符串为空字符串 `""`。因此在本例中，声明隐式地将 `s` 和 `sep` 初始化为空字符串。我们将在第 2 章进一步讨论变量和声明。

对于数字，Go 提供了常见的算术和逻辑运算符。然而当应用于字符串时，`+` 运算符会 *拼接* 这些值，因此表达式

```
sep + os.Args[i]
```

表示字符串 `sep` 和 `os.Args[i]` 的拼接。程序中使用的语句

```
s += sep + os.Args[i]
```

是一个 *赋值语句*，它将 `s` 的旧值与 `sep` 和 `os.Args[i]` 拼接后赋回 `s`；它等价于

```
s = s + sep + os.Args[i]
```

运算符 `+=` 是一个 *赋值运算符*。每个算术和逻辑运算符（如 `+` 或 `*`）都有一个对应的赋值运算符。

`echo` 程序本可以在循环中逐个片段地打印输出，但此版本通过反复将新文本追加到末尾来构建字符串。字符串 `s` 最初为空，即值为 `""`，循环的每一轮都会向其添加一些文本；首次迭代后，还会插入一个空格，以便循环结束时，每个参数之间有一个空格。这是一个平方级（quadratic）的过程，如果参数数量很大可能代价高昂，但对于 `echo` 来说，这不太可能发生。我们将在本章和下一章展示许多 `echo` 的改进版本，它们将解决任何真正的低效问题。

循环索引变量 `i` 在 `for` 循环的第一部分声明。`:=` 符号是*短变量声明*的一部分，这是一种声明一个或多个变量并根据初始化值赋予它们适当类型的语句；下一章将详细介绍。

增量语句 `i++` 给 `i` 加 1；它等价于 `i += 1`，后者又等价于 `i = i + 1`。有一个对应的减量语句 `i--` 给 `i` 减 1。这些是语句，而非 C 语系大多数语言中的表达式，因此 `j = i++` 是非法的，且它们只能作为后缀使用，所以 `--i` 也不合法。

`for` 循环是 Go 中唯一的循环语句。它有多种形式，其中一种如下所示：

```
for initialization; condition; post {
    // zero or more statements
}
```

`for` 循环的三个组件周围从不使用圆括号。然而大括号是强制的，且左大括号必须与 `post` 语句在同一行。

可选的 `initialization` 语句在循环开始前执行。如果存在，它必须是一个*简单语句*，即短变量声明、增量或赋值语句，或函数调用。`condition` 是一个布尔表达式，在每次循环迭代开始时求值；如果其值为 `true`，则执行循环控制的语句。`post` 语句在循环体执行后运行，然后再次求值条件。当条件变为 false 时循环结束。

这些部分中的任何一个都可以省略。如果没有 `initialization` 和 `post`，分号也可以省略：

```
// 传统的 "while" 循环
for condition {
    // ...
}
```

如果在上述任何形式中完全省略条件，例如：

```
// 传统的无限循环
for {
    // ...
}
```

则循环为无限循环，尽管这种形式的循环可能通过其他方式终止，如 `break` 或 `return` 语句。

`for` 循环的另一种形式遍历来自字符串或切片等数据类型的*范围*值。为了演示，这是 `echo` 的第二个版本：

gopl.io/ch1/echo2

```
// Echo2 打印其命令行参数。
package main

import (
    "fmt"
    "os"
)

func main() {
    s, sep := "", ""
    for _, arg := range os.Args[1:] {
        s += sep + arg
        sep = " "
    }
    fmt.Println(s)
}
```

在循环的每次迭代中，`range` 产生一对值：索引和该索引处的元素值。在本例中，我们不需要索引，但 `range` 循环的语法要求如果我们处理元素，也必须处理索引。一种想法是将索引赋值给一个明显的临时变量如 `temp` 并忽略其值，但 Go 不允许未使用的局部变量，这会导致编译错误。

解决方法是使用*空标识符*，其名称为 `_`（即下划线）。当语法需要变量名但程序逻辑不需要时，可使用空标识符，例如在我们只需要元素值时丢弃不需要的循环索引。大多数 Go 程序员可能会如上所示使用 `range` 和 `_` 编写 `echo` 程序，因为对 `os.Args` 的索引是隐式的而非显式的，因此更容易写对。

此版本程序使用短变量声明来声明并初始化 `s` 和 `sep`，但我们同样可以分别声明这些变量。声明字符串变量有多种方式；以下全部等价：

```
s := ""
var s string
var s = ""
var s string = ""
```

为什么要偏好某种形式？第一种形式（短变量声明）最紧凑，但只能用于函数内部，不能用于包级变量。第二种形式依赖字符串的零值默认初始化，即 `""`。第三种形式极少使用，除非声明多个变量。第四种形式显式指明变量类型，当类型与初始值类型相同时这属于冗余，但在两者类型不同时则是必要的。实践中，通常应使用前两种形式之一，显式初始化表示初始值很重要，隐式初始化表示初始值无关紧要。

如上所述，每次循环迭代时，字符串 `s` 都会获得全新的内容。`+=` 语句通过连接旧字符串、一个空格字符和下一个参数来创建一个新字符串，然后将新字符串赋值给 `s`。`s` 的旧内容不再使用，稍后将被垃圾回收。

如果涉及的数据量很大，这可能代价高昂。一个更简单高效的解决方案是使用 `strings` 包的 `Join` 函数：

gopl.io/ch1/echo3

```
func main() {
    fmt.Println(strings.Join(os.Args[1:], " "))
}
```

最后，如果我们不关心格式，只想查看值（例如用于调试），可以让 `Println` 为我们格式化结果：

```
fmt.Println(os.Args[1:])
```

该语句的输出类似于 `strings.Join` 的结果，但带有方括号。任何切片都可以这样打印。

## 1.3 查找重复行

文件复制、打印、搜索、排序、计数等程序都具有相似的结构：一个对输入的循环、对每个元素的某种计算、以及即时或最终的输出生成。我们将展示一个名为 `dup` 的程序的三个变体；它部分受 Unix `uniq` 命令启发，该命令查找相邻的重复行。所用的结构和包是可以轻松适配的模型。

`dup` 的第一个版本打印标准输入中出现次数超过一行的每一行，并以其计数为前缀。该程序介绍了 `if` 语句、`map` 数据类型和 `bufio` 包。

gopl.io/ch1/dup1

```
// Dup1 打印标准输入中出现次数超过一次的每行文本，前面带有其计数。
package main

import (
    "bufio"
    "fmt"
    "os"
)

func main() {
    counts := make(map[string]int)
    input := bufio.NewScanner(os.Stdin)
    for input.Scan() {
        counts[input.Text()]++
    }
    // NOTE: ignoring potential errors from input.Err()
    for line, n := range counts {
        if n > 1 {
            fmt.Printf("%d\t%s\n", n, line)
        }
    }
}
```

与 `for` 一样，`if` 语句的条件两侧从不使用括号，但主体部分需要花括号。可以有一个可选的 `else` 部分，在条件为假时执行。

`map` 存储一组键值对，并提供常数时间复杂度的存储、检索或测试集合中某项的操作。键可以是任何可用 `==` 比较的类型，字符串是最常见的例子；值可以是任意类型。在本例中，键是字符串，值是 `int`。内置函数 `make` 创建一个新的空 map；它还有其他用途。Map 将在 4.3 节 中详细讨论。

每次 `dup` 读取一行输入，该行被用作 map 的键，对应的值递增。语句 `counts[input.Text()]++` 等价于以下两条语句：

```
line := input.Text()
counts[line] = counts[line] + 1
```

如果 map 尚不包含该键也没关系。第一次遇到新行时，右侧表达式 `counts[line]` 的值为其类型的零值，对于 `int` 即为 `0`。

为了打印结果，我们再次使用基于 `range` 的 `for` 循环，这次遍历 `counts` map。和之前一样，每次迭代产生两个结果：一个键和该键对应的 map 元素值。map 的迭代顺序未指定，但在实践中是随机的，每次运行可能不同。这种设计是有意为之，因为它防止程序依赖任何并不保证的特定顺序。

接下来介绍 `bufio` 包，它有助于使输入输出高效且方便。其最有用的特性之一是 `Scanner` 类型，它读取输入并将其拆分为行或单词；这通常是处理天然按行输入的最简单方式。

程序使用短变量声明创建一个新变量 `input`，指向一个 `bufio.Scanner`：

```
input := bufio.NewScanner(os.Stdin)
```

扫描器从程序的标准输入读取。每次调用 `input.Scan()` 读取下一行并移除末尾的换行符；结果可通过调用 `input.Text()` 获取。`Scan` 函数若有行则返回 `true`，无更多输入时返回 `false`。

函数 `fmt.Printf` 与 C 及其他语言中的 `printf` 类似，根据表达式列表产生格式化输出。其第一个参数是格式字符串，指定后续参数如何格式化。每个参数的格式由转换字符决定，即百分号后的字母。例如，`%d` 以十进制格式化整数操作数，`%s` 展开为字符串操作数的值。
