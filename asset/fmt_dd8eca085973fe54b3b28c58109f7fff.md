## 重放

## 第 2 层攻击

有许多不同类型的第 2 层网络攻击会影响第 2 层网络设备（如交换机），或第 2 层组件和协议（如 MAC 地址和 ARP）。

### ARP 投毒

根据第 1 章的内容，ARP 是一种将 IP 地址转换为 MAC 地址，然后将 IP 和对应的 MAC 地址存储在系统内存中的协议。这块内存区域称为 ARP 缓存（参见图 4-7）。

![Image](img/f0154-01.jpg)

**图 4-7**  

查看系统上的 ARP 缓存

ARP 投毒涉及黑客篡改一台或一组系统上的 ARP 缓存，使所有系统在 ARP 缓存中为特定 IP 地址（可能是默认网关的地址）存储了错误的 MAC 地址。通常，黑客会投毒 ARP 缓存，使默认网关 IP 地址（您路由器的 IP 地址）指向黑客的 MAC 地址。这将确保每当系统尝试向路由器发送数据时，它会从本地 ARP 缓存中检索黑客的 MAC 地址，然后将数据发送到黑客的系统，而不是路由器。这就是黑客通常在有线网络或无线网络上执行 MITM 攻击的方式。这还允许黑客捕获所有网络流量，即使在交换环境中也是如此。黑客只需在其系统上启用路由功能，以便所有数据随后传递给路由器并流向互联网，同时黑客已捕获每一条流向互联网的数据。

### MAC 泛洪

MAC 泛洪是指攻击者向交换机发送大量帧，导致其填满 MAC 地址表，并因此移除旧的有效 MAC 地址，但添加新的伪造 MAC 地址。这将导致交换机将来自网络上有效系统的所有帧进行泛洪。泛洪的帧会发送到交换机的每个端口，从而允许攻击者捕获并查看它们。

### MAC 克隆

MAC 克隆是指攻击者复制另一台系统的 MAC 地址并将其用于网络通信。这可用于绕过访问控制列表，其中仅允许来自特定 MAC 地址的流量进入网络。

## 域名系统攻击

域名系统 (DNS) 是一种名称解析技术，可将完全限定域名（如 `www.gleneclarke.com`）转换为 IP 地址。DNS 对网络通信至关重要，因为客户端使用系统的 DNS 名称，而在后台它会被转换为该系统的 IP 地址，客户端随后与该 IP 地址通信。让我们来看看针对 DNS 的一些攻击。

### DNS 投毒

在计算机中，投毒是指某人进入一个环境并故意在其中放置不正确的设置，以破坏该环境。您需要为 Security+ 认证考试熟悉的两个常见投毒示例是 DNS 投毒和 ARP 投毒。

DNS 投毒是指黑客攻破 DNS 服务器，并通过让 DNS 名称指向不正确的 IP 地址来投毒 DNS 条目。通常，黑客会修改 DNS 记录使其指向黑客的系统；这将强制该 DNS 名称的所有流量流向黑客的系统。

DNS 投毒也是篡改位于公司本地 DNS 服务器上的 DNS 缓存。DNS 缓存存储员工已访问过的网站名称及这些网站的 IP 地址（参见图 4-8）。缓存位于您的 DNS 服务器上，以便当另一位员工浏览同一网站时，DNS 服务器已经有该网站的 IP 地址，无需将查询转发到互联网。您本地办公室的 DNS 服务器只需将存储在 DNS 缓存中的 IP 地址发送给客户端。黑客有可能投毒 DNS 缓存，导致您的用户被发送到错误的网站。

![Image](img/f0155-01.jpg)

**图 4-8**  

查看 DNS 服务器上的 DNS 缓存

黑客将您引导至错误网站的另一种常用技术是修改驻留在每个系统上的 hosts 文件。hosts 文件用于将域名解析为 IP 地址，如果在本地 hosts 文件中找到条目，则系统将不会查询 DNS。*域名劫持* 是指通过修改 DNS 或 hosts 文件将某人引导至错误网站的术语。

#### 你的系统上没有任何有价值的东西？

在课堂上与学生讨论安全性时，我通常会讨论保护家庭网络和家用计算机的重要性。我通常会得到一名学生的回应：“我的系统上没有任何有价值的东西，所以如果黑客想浪费时间攻击我的系统，那就随他们去吧！”

## Domain Hijacking（域名劫持）

Domain hijacking is a type of attack that involves the hacker taking over a domain name from the original registrant. The hacker may hijack the domain by using social engineering techniques to gain access to the domain name and then switch ownership, or the hacker could exploit a vulnerability on the systems that host the domain name to gain unauthorized access to the domain registration.

## Uniform Resource Locator Redirection（URL 重定向）

Uniform Resource Locator (URL) redirection is a DNS attack that involves the attacker sending a request for a DNS name to a different location such as a malicious web site that the attacker is running.

## Domain Reputation（域名信誉）

Domain reputation is a rating on your domain name of whether or not the domain is known to send spam messages. If an employee in your company sends a lot of spam messages, your domain may be flagged as having a poor reputation due to the sending of those spam messages. Spam-filtering systems will block e-mail messages from systems with a poor domain reputation.
