
## 术语表

### M

**Motherboard**  
包含计算机硬件，包括`CPU`、内存插槽、固件以及外设插槽（如`PCI`（Peripheral Component Interconnect）插槽）。

**MPLS**  
Multiprotocol Label Switching，提供一种通过标签转发`WAN`数据的方式。

**MTBF**  
Mean Time Between Failures，量化新系统或修复后的系统在发生故障前平均能运行多长时间。

**MTD**  
Maximum Tolerable Downtime，系统在组织受到严重影响前可处于不可操作状态的总时间。

**MTTR**  
Mean Time to Repair，描述恢复故障系统所需的时间。

**MTU**  
Maximum Transmission Unit，网络上的最大`PDU`大小。

**Multicast**  
一对多网络流量，“多”是预先选定的。

**Multipartite virus**  
通过多种载体传播的病毒。也称为 multipart virus。

**Multiprocessing**  
在多个`CPU`上运行多个进程。

**Multiprotocol Label Switching**  
参见——`MPLS`。

**Multitasking**  
允许多个任务（重量级进程）在一个`CPU`上同时运行。

**Mutation**  
遗传算法概念，向算法引入随机变化。

**Mutual Aid Agreement**  
参见——Reciprocal agreement。

### N

**NAT**  
Network Address Translation，转换`IP`地址。

**NDA**  
Non-disclosure agreement，一种合同协议，确保个人或组织了解其对维护敏感信息机密性的法律责任。

**Need to know**  
要求主体在访问信息前需知晓该信息。

**Network access layer**  
`TCP/IP`模型层，结合了`OSI`模型的第 1 层和第 2 层。它描述第 1 层问题，如能量、比特以及承载它们的介质。

**Network Address Translation**  
参见——`NAT`。

**Network Interface Card**  
参见——`NIC`。

**Network Intrusion Prevention System**  
参见——`NIPS`。

**Network layer**  
`OSI`模型的第 3 层，描述从一个`LAN`上的系统到另一个`LAN`上的系统的数据路由。

**Network model (databases)**  
允许分支有两个父节点的层次型数据库类型。

**Network model (telecommunications)**  
网络协议套件如何运行的描述。

**Network stack**  
以软件或硬件编程的网络协议套件。

**Network-based Intrusion Detection System**  
参见——`NIDS`。

**NIC**  
Network Interface Card，将系统连接到网络的卡。

**NIDS**  
Network-based Intrusion Detection System，一种侦查型技术控制。

**NIPS**  
Network Intrusion Prevention System，一种旨在防止恶意网络流量的预防性设备。

**NIST SP 800-34**  
NIST Special Publication 800-34 “Contingency Planning Guide for Information Technology Systems”。

**Nonce Sum**  
参见——`NS`。

**Non-disclosure agreement**  
参见——`NDA`。

**Non-discretionary access control**  
基于主体的角色或任务的访问控制。

**Non-interference Model**  
确保不同安全域的数据彼此保持分离。

**Non-repudiation**  
确保特定用户执行了特定事务，且该事务未被篡改。

**Normal Response Mode**  
参见——`NRM`。

**Normalization**  
旨在使数据库表中的数据在逻辑上简洁、有序且一致。

**Northbridge**  
将`CPU`连接到`RAM`和视频内存，也称为 Memory Controller Hub（`MCH`）。

**NRM**  
Normal response mode，`SDLC`/`HDLC`模式，其中次级节点在获得主节点许可后可传输。

**NS**  
Nonce Sum，最新的`TCP`标志，用于拥塞通知。

### O

**OAuth**  
一种授权框架，允许以标准化方式进行通信并将授权委托给应用程序，而无需用户透露其凭据。

**Object**  
数据文件。

**Object**  
一个结合了代码和数据的“黑盒”，能够发送和接收消息。

**Object encapsulation**  
将进程视为“黑盒”处理。

**Object Linking and Embedding**  
参见——`OLE`。

**Object Request Brokers**  
参见——`ORBs`。

**Object-Oriented Analysis**  
参见——`OOA`。

**Object-oriented database**  
在面向对象框架中将数据与函数（代码）结合的数据库。

**Object-Oriented Design**  
参见——`OOD`。

**Object-Oriented Programming**  
参见——`OOP`。

**Occupant Emergency Plan**  
参见——`OEP`。

**OCSP**  
Online Certificate Status Protocol，一种用于查找吊销证书的客户端-服务器方法。

**OCTAVE**  
Operationally Critical Threat, Asset, and Vulnerability Evaluation，来自卡内基梅隆大学的风险管理框架。

**OECD Privacy Guidelines**  
Organization for Economic Cooperation and Development 隐私指南，包含八项原则。

**OEP**  
Occupant Emergency Plan，一种基于设施的计划，侧重于安全和疏散。

**OFB**  
Output Feedback，一种使用密钥部分进行反馈的`DES`流模式。

**OFDM**  
Orthogonal Frequency-Division Multiplexing，一种较新的无线复用方法，允许使用多个互不干扰的独立无线频率进行同时传输。

**Offshoring**  
外包给另一个国家。

**OIDC**  
OpenID Connect 提供了一种现代单点登录或联合身份验证框架，构建于`OAuth`授权协议之上。`SAML`的替代方案。

**OLE**  
Object Linking and Embedding，`DCOM`的一部分，用于将文档链接到其他文档。

**Onboarding**  
将新员工引入组织的过程，包括账户创建、授权授予，以及确保员工知晓所有相关政策和程序。

**One-Time Pad**  
理论上无法破解的加密，使用成对的随机字符垫。

**One-time password**  
可用于单次身份验证的密码。

**Online Certificate Status Protocol**  
参见——`OCSP`。

**OOA**  
Object-Oriented Analysis，理解问题域的高层方法，识别所有对象及其交互。

**OOD**  
Object-Oriented Design，一种面向对象的高层软件设计方法。

**OOP**  
Object-Oriented Programming，改变了旧的过程式编程方法，将程序视为一系列通过消息通信的连接对象。

**Open Authorization**  
参见——`OAuth`。

**Open Shortest Path First**  
参见——`OSPF`。

**Open source**  
源代码公开发布的软件，允许任何人检查、修改或编译代码。

**Open system**  
使用开放硬件和标准的系统，使用来自多个供应商的标准组件。

**OpenID Connect**  
参见——`OIDC`。

**Openness Principle**  
OECD Privacy Guideline 原则，规定个人数据的收集和使用应公开可得。

**Operating system**  
操作计算机的软件。

**Operationally Critical Threat, Asset, and Vulnerability Evaluation**  
参见——`OCTAVE`。

**Optimizing**  
`CMM`第 5 阶段。

**Orange Book**  
参见——`TCSEC`。

**ORBs**  
Object Request Brokers，用于定位对象并与之通信。

**Organizationally Unique Identifier**  
参见——`OUI`。

**Orthogonal Frequency-Division Multiplexing**  
参见——`OFDM`。

**OSI model**  
一个具有七层的网络模型：物理层、数据链路层、网络层、传输层、会话层、表示层和应用层。

**OSPF**  
Open Shortest Path First，一种开放的链路状态路由协议。

**OUI**  
Organizationally Unique Identifier，`MAC`地址的前 24 位。

**Output Feedback**  
参见——`OFB`。

**Outsourcing**  
使用第三方提供以前在内部执行的信息技术支持服务。

**Overt channel**  
符合安全策略的授权通信。

### P

**PaaS**  
Platform as a Service，提供预配置的操作系统，由客户配置应用程序。

**Packet**  
第 3 层`PDU`。

**Packet filter**  
一种简单快速的防火墙，没有状态概念。

**Packet-switched network**  
一种网络形式，带宽共享，数据以包为单位传输。

**Pairwise testing**  
一种组合软件测试形式，测试输入的唯一对。

**PAN**  
Personal Area Network，一种范围在 100 米或更小的极小型网络。

### P

**Panic bar**  
从内部打开外向门的紧急出口装置。

**PAP**  
密码认证协议，一种不安全的网络认证协议，以明文形式暴露密码。

**Parallel processing**  
在备用计算设施恢复关键处理组件，且不影响常规生产系统。

**Parent class**  
面向对象编程概念，允许对象从父类继承能力。

**Parity**  
一种实现数据冗余的方法，在磁盘使用和写入性能方面，其成本不像镜像那样高。

**Partial knowledge test**  
渗透测试的一种，测试人员在测试开始时获得部分内部信息。

**Passive infrared sensor**  
被动运动探测器，探测人体热量产生的红外能量。

**Passive RFID**  
无源 RFID 标签。

**Passphrase**  
由短语或句子中的单词组成的长静态密码。

**Password Authentication Protocol**  
参见——`PAP`。

**Password cracking**  
一种离线技术，攻击者已获得密码哈希或数据库的访问权限。

**Password guessing**  
一种在线技术，涉及尝试以特定用户身份向系统进行认证。

**Patch management**  
管理软件更新的过程。

**Patent**  
知识产权保护，在一段时间内授予使用、制造或销售发明的垄断权。

**Payment Card Industry Data Security Standard**  
参见——`PCI-DSS`。

**PCI-DSS**  
支付卡行业数据安全标准，由支付卡行业安全标准委员会（PCI SSC）制定的安全标准。

**PDA**  
个人数字助理，一种可置于掌心的小型联网计算机。

**PDU**  
协议数据单元，网络栈某一层的头部和数据。

**PEAP**  
受保护的 EAP，类似于 EAP-TTLS，包括不需要客户端证书。

**Penetration test**  
旨在确定攻击者能否渗透组织的安全测试。

**Permutation**  
（也称为置换）通过重新排列明文字符（类似字谜）来提供混淆。

**Personal Area Network**  
参见——`PAN`。

**Personal Digital Assistant**  
参见——`PDA`。

**Personal Identification Number**  
参见——`PIN`。

**Personally Identifiable Information**  
参见——`PII`。

**PGP**  
Pretty Good Privacy，集成了非对称、对称和哈希加密的软件。

**Phishing**  
伪装成合法网站（如银行）的恶意攻击，试图窃取账户凭证。

**Photoelectric motion sensor**  
主动运动探测器，将一束光发送过受监控空间至光电传感器。

**Physical controls**  
通过物理设备实施的控制，如锁、围栏和大门。

**Physical layer**  
OSI 模型第 1 层，描述比特等数据单位（由能量表示）及承载它们的介质。

**PII**  
个人身份信息，与特定个人关联的数据，如信用卡数据。

**PIN**  
个人识别号码，基于数字的密码。

**Ping**  
向节点发送 ICMP 回显请求并监听 ICMP 回显应答。

**Ping of death**  
发送畸形 ICMP 回显请求（Ping）的 DoS 攻击，其大小超过 IP 数据包的最大尺寸。

**Pipelining**  
CPU 特性，将多个步骤合并为一个组合过程，允许对不同指令同时进行取指、解码、执行和写回步骤。

**PKI**  
公钥基础设施，利用对称、非对称和基于哈希的加密来管理数字证书。

**Plaintext**  
未加密的消息。

**Plan maintenance**
