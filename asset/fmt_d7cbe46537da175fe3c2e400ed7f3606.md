## 13.2 贝叶斯学习中的变分近似

回顾一下，为了应用 EM 算法，给定观测值的情况下，潜在/隐变量后验的函数形式必须是已知的。然而，与后验相关的解析计算并不总是可处理的。在这种情况下，上一章讨论的标准形式的 EM 算法不再适用。在本节中，我们将描述一条替代路径，它建立在第 12.7 节给出的 EM 解释之上。

我们将再次采用一种通用符号，随后可根据具体问题的需求进行调整。设 `$\mathcal{X} = \{\mathbf{x}[1], \dots, \mathbf{x}[N]\}$` 为观测变量集，`$\mathcal{X}^{(l)} = \{\mathbf{x}[1]^{(l)}, \dots, \mathbf{x}[N]^{(l)}\}$` 为对应的 $N$ 个（局部）潜在变量集，它们已在第 12.4 节中定义。此外，在本节中，除了潜在变量外，我们将显式引入一组 $K$ 个（全局）隐随机参数 `$\boldsymbol{\theta} \in \mathbb{R}^K$`，其数量是固定的，并将伴随一个先验概率密度函数（PDF）。完全似然函数现在写为 `$p(\mathcal{X}, \mathcal{X}^{(l)}, \boldsymbol{\theta}; \boldsymbol{\xi})$`，其中 `$\boldsymbol{\xi}$` 是必须估计的未知非随机（超）参数集。正如贝叶斯学习中总是那样，目标是推断描述潜在变量以及隐随机变量的后验概率分布。

公式 (12.63) 中的泛函现在重新定义为

```
\mathcal{F}(q,\boldsymbol{\xi}) = \int q(\mathcal{X}^{l},\boldsymbol{\theta})\ln\frac{p(\mathcal{X},\mathcal{X}^{l},\boldsymbol{\theta};\boldsymbol{\xi})}{q(\mathcal{X}^{l},\boldsymbol{\theta})}\ d\mathcal{X}^{l}\ d\boldsymbol{\theta}.
```

(13.1)

公式 (12.66) 的对应式变为

```
\mathcal{F}(q,\mathbf{\xi}) = \ln p(\mathcal{X};\mathbf{\xi}) + \int q(\mathcal{X}^{l},\mathbf{\theta})\ln\frac{p(\mathcal{X}^{l},\mathbf{\theta}|\mathcal{X};\mathbf{\xi})}{q(\mathcal{X}^{l},\mathbf{\theta})}\ d\mathcal{X}^{l}\ d\mathbf{\theta},
```

![Equation](img/si6.png)(13.2)

由此可得

```
\ln p(\mathcal{X};\boldsymbol{\xi}) = \mathcal{F}(q,\boldsymbol{\xi}) + \text{KL}(q(\mathcal{X}^{(l)},\boldsymbol{\theta})||p(\mathcal{X}^{(l)},\boldsymbol{\theta}|\mathcal{X};\boldsymbol{\xi})).
```

![Equation](img/si7.png)

与公式 (12.67) 的区别在于，在我们当前的设定中，后验概率 `$p(\mathcal{X}^{(l)},\boldsymbol{\theta}|\mathcal{X};\boldsymbol{\xi})$` *不* 假定为已知；因此，为了使泛函值最大化，将库尔巴克-莱布勒（KL）散度 `$\text{KL}(q(\mathcal{X}^{(l)},\boldsymbol{\theta})||p(\mathcal{X}^{(l)},\boldsymbol{\theta}|\mathcal{X};\boldsymbol{\xi}))$` 设为零已不再可能。唯一的替代方案是求助于关于 $q$ 的泛函形式的计算上可处理的近似，这将允许对泛函关于 $q$（以及关于非随机参数 `$\boldsymbol{\xi}$`）进行优化。

关于函数优化泛函在数学上被称为*变分法*。该问题最简单的例子是计算连接曲面上两点的测地线。对该领域的巩固做出重大突破性贡献的两位数学家是瑞士裔德国数学家莱昂哈德·欧拉（1707–1783）和意大利出生的数学家兼天文学家约瑟夫-路易·拉格朗日（1736–1813）。有趣的是，拉格朗日继欧拉之后担任柏林普鲁士科学院数学部主任。

To address the current problem, we will constrain `q(𝒳^(l), θ)` within a specific family of functions. Note that in this case, if the unknown `p(𝒳^(l), θ|𝒳; ξ)` does not belong to the chosen family of functions, the KL divergence *cannot* become zero, and the lower bound of the marginal log-likelihood `ℱ(q, ξ)` *cannot* become *tight*. This is why the method is called variational approximation.
