
# 设计模式识别系统：特征生成与选择

历史上，设计模式识别系统的两个主要步骤是 `feature generation`（特征生成）和 `feature selection`（特征选择）阶段。选择信息丰富的特征至关重要。如果选择了“差”的特征，无论采用多么智能的分类器，性能注定会很差。特征生成/选择技术在文献[38,39]中有详细论述，感兴趣的读者可参考这些文献以获取更多信息。在此，我们仅涉及与当前线性分类器设计相关的少数概念。

让我们首先量化什么是“差”特征和“优”特征。选择特征的主要目标，从而选择将要工作的特征空间，可以概括为以下方式：选择特征以创建一个特征空间，使得表示训练模式的点分布得以满足。

## 散度矩阵

### 类内散度矩阵

```
Σ_w = Σ_{k=1}^M P(ω_k) Σ_k
```

(7.55)

其中 `Σ[k]` 是 `M` 个类别中第 `k` 个类别点的协方差矩阵。简而言之，`Σ[w]` 是特定 `l` 维特征空间中数据的平均协方差矩阵。

### 类间散度矩阵

```
Σ_b = Σ_{k=1}^M P(ω_k) (μ_k - μ_0)(μ_k - μ_0)^T
```

(7.56)

其中 `μ[0]` 是由以下公式定义的总体均值：

```
μ_0 = Σ_{k=1}^M P(ω_k) μ_k
```

(7.57)

### 混合散度矩阵

```
Σ_m = Σ_w + Σ_b
```

(7.58)

许多衡量所选特征空间“优劣”的准则都是围绕这些散度矩阵建立的；三个典型例子是（例如 [17,38]）：

$J_{1} := \frac{\text{trace}\{\Sigma_{m}\}}{\text{trace}\{\Sigma_{w}\}},\quad J_{2} = \frac{|\Sigma_{m}|}{|\Sigma_{w}|},\quad J_{3} = \text{trace}\left\{ \Sigma_{w}^{- 1}\Sigma_{b} \right\},$

其中 $|\cdot|$ 表示矩阵的行列式。请注意，前述准则的较大值表示良好的特征选择。

![图 7.10 三种不同的二维特征空间选择：(A) 类内方差小且类间距离小；(B) 类内方差大且类间距离小；(C) 类内方差小且类间距离大。这三者中最后一个是最佳选择。](img/gr010.jpg)

$J\_1$ 准则最容易理解。为简化论述，让我们专注于涉及三个类别的二维（两个特征，$x\_1$, $x\_2$）情况。回顾第二章公式 (2.31) 中随机向量 $\mathbf{x}$ 协方差矩阵的定义，主对角线上的元素是相应随机变量的方差。因此，对于每个类别 $k = 1, 2, 3$，相应协方差矩阵的迹将是两个特征各自方差之和，即

$\text{trace}\{\Sigma[k]\} = \sigma\_{k1}² + \sigma\_{k2}².$

因此，$\Sigma\_w$ 的迹是所有三个类别中两个特征总方差的平均值，

$\text{trace}\{\Sigma\_w\} = \sum\limits\_{k = 1}^{3}P(\omega\_k)\left( \sigma\_{k1}^{2} + \sigma\_{k2}^{2} \right): = s\_w.$

### 数学推导

类间离差矩阵的迹定义为：

```
trace{Σ_b} = ∑_{k=1}^{3} P(ω_k) [ (μ_{k1} - μ_{01})² + (μ_{k2} - μ_{02})² ]
```

这可以用向量符号表示为：

```
= ∑_{k=1}^{3} P(ω_k) ||μ_k - μ_0||² := s_b,
```

其中`μ_k = [μ_{k1}, μ_{k2}]^T`是第*k*类的均值，`μ_0 = [μ_{01}, μ_{02}]^T`是全局均值向量。

准则`J_1`定义为：

```
J_1 = (s_w + s_b) / s_w = 1 + s_b / s_w.
```

换句话说，平均总方差越小，均值到全局均值的平均欧氏距离平方越大，`J_1`的值就越大。对于其他两个准则也可以作出类似的论证。

$$ \mathbf{y} = \frac{\mathbf{\theta}^{T}\mathbf{x}}{||\mathbf{\theta}||}\frac{\mathbf{\theta}}{||\mathbf{\theta}||} $$

![Equation](img/si229.png)

其中 $\frac{\mathbf{\theta}}{||\mathbf{\theta}||}$ 是 `θ` 方向上的单位范数向量。从现在开始，我们将关注投影的标量值，$y := \mathbf{\theta}^{(T)}\mathbf{x}$，并忽略分母中的缩放因子，因为用相同的值缩放所有特征对我们的讨论没有影响。现在的目标是选择那个方向 `θ`，使得沿该方向投影后，(a) 两类中的数据彼此间距离尽可能远，且 (b) 每一类中围绕其均值的点的各自方差尽可能小。量化上述目标的一个准则是*费舍尔判别率*（FDR），定义为

其中 $\mu_1$ 和 $\mu_2$ 是沿 `θ` 方向投影后两类的（标量）均值，即

$$ \mu_k = \mathbf{\theta}^{T}\mathbf{\mu}_k, \quad k = 1, 2. $$

![Equation](img/si234.png)

然而，我们有

$$ (\mu_1 - \mu_2)² = \mathbf{\theta}^{T}(\mathbf{\mu}_1 - \mathbf{\mu}_2)(\mathbf{\mu}_1 - \mathbf{\mu}_2)^{T}\mathbf{\theta} = \mathbf{\theta}^{T}S_b\mathbf{\theta}, \quad S_b := (\mathbf{\mu}_1 - \mathbf{\mu}_2)(\mathbf{\mu}_1 - \mathbf{\mu}_2)^{T}. $$

![Equation](img/si235.png) (7.63)

注意：如果类别是等概率的，`S_b` 是公式 (7.56) 中类间散度矩阵的缩放版本（这很容易验证，因为在这种假设下，`μ_0 = 1/2(μ_1 + μ_2)`），并且我们有

`(μ_1 − μ_2)² ∝ θ^(T) Σ_b θ`。

此外，

`σ_k² = E[(y − μ_k)²] = E[θ^(T)(x − μ_k)(x − μ_k)^(T) θ] = θ^(T) Σ_k θ, k = 1, 2`，

这导致

`σ_1² + σ_2² = θ^(T) S_w θ`，

其中 `S_w = Σ_1 + Σ_2`。注意，如果类别是等概率的，`S_w` 变成了公式 (7.55) 中定义的类内散度矩阵的缩放版本，并且我们有

`σ_1² + σ_2² ∝ θ^(T) Σ_w θ`。

为了将 Fisher 判别式方法用作分类器，必须采用一个阈值 θ_0，并根据以下规则做出有利于某个类别的决策：

#### Fisher 判别式：二分类情况

$$y = {(\mathbf{\mu}_{1} - \mathbf{\mu}_{2})}^{T}\Sigma_{w}^{- 1}\mathbf{x} + \theta_{0}\left\{ \begin{matrix} {> 0,\ \text{class}\ \omega_{1},} \\ {< 0,\ \text{class}\ \omega_{2}.} \end{matrix} \right.$$

![Equation](img/si250.png) (7.69)

将公式 (7.69) 与公式 (7.20)–(7.22) 进行比较；后者是通过高斯情况下的贝叶斯规则获得的，当时两个类共享相同的协方差矩阵。观察可知，对于这种情况，两种方法产生的超平面是平行的，唯一的区别在于阈值。然而，请注意，高斯假设对于 Fisher 判别式并非必需。这证明了即使数据不服从正态分布，使用公式 (7.20)–(7.22) 也是合理的。在实践中，根据数据的不同，可能会使用不同的阈值。

最后，因为世界往往很小，可以证明如果目标类别标签不是 ±1，而是分别选择为 $\frac{N_{1}}{N}$ 和 $\frac{- N_{2}}{N}$，那么 Fisher 判别式也可以被视为最小二乘（LS）解的一个特例，其中 $N$ 是训练样本总数，$N_{1}$ 是类 $\omega_{1}$ 中的样本数，$N_{2}$ 是类 $\omega_{2}$ 中对应的样本数，例如 [41]。

Fisher 判别式方法的另一个观点是，它通过将数据从原始的 $l$ 维空间投影到一个较低的一维空间来执行降维。这种降维是以*监督*方式进行的，通过利用训练数据的类别标签。正如我们将在第 20 章中看到的，还有其他技术以降维以无监督的方式进行。现在显而易见的问题是，是否可能利用 Fisher 的思想将维度降低到不是一维，而是介于一和 $l$ 之间的另一个中间值，其中 $l$ 是特征空间的维数。事实证明这是可能的，但这也取决于类别的数量。更多关于降维技术的内容可以在第 20 章中找到。

## 7.7.3 Fisher 判别式：多分类情况

我们推广到多分类情况的出发点是在公式 (7.59) 中定义的 $J_{3}$ 准则。可以很容易地证明，用于二分类情况的 FDR 准则，一旦后者被考虑用于一维情况和等概率类别，就直接与 $J_{3}$ 准则相关。对于更一般的多分类公式化，任务变为估计一个 $l \times m,\ m < l$ 的矩阵 $A$，使得从原始 $\mathbb{R}^{(l)}$ 到新的、较低维度的 $\mathbb{R}^{(m)}$ 空间的线性变换，表示为

**y** = **A**^(T)**x**,

![Equation](img/si258.png) (7.70)

能够保留尽可能多的分类相关信息。请注意，在任何降维技术中，原始信息的一部分通常都注定会丢失。我们的目标是使这种损失尽可能小。因为我们选择用 $J_{3}$ 准则来量化分类相关信息，所以目标是计算 $A$ 以使其最大化。

### Fisher 判别准则与矩阵特征值分解

$J_3(A) = \text{trace}\{\Sigma_{wy}^{-1}\Sigma_{by}\}$ (7.71)

其中 $\Sigma_{wy}$ 和 $\Sigma_{by}$ 是变换后的低维空间中的类内离散矩阵和类间离散矩阵。最大化过程遵循矩阵优化的标准论证。代数推导较为复杂，此处直接给出最终结果。证明细节可参考文献 [17, 38]。矩阵 $A$ 由以下方程给出：

$$

(\Sigma_{wx}^{-1}\Sigma_{bx})A = A\Lambda \tag{7.72}

$$

矩阵 $\Lambda$ 是一个对角矩阵，其元素为 $l \times l$ 矩阵 $\Sigma_{wx}^{-1}\Sigma_{bx}$ 的 $m$ 个特征值（见附录 A），其中 $\Sigma_{wx}$ 和 $\Sigma_{bx}$ 分别是原始 $\mathbb{R}^l$ 空间中的类内和类间离散矩阵。目标矩阵 $A$ 由相应的特征向量组成。问题转化为选择 $m$ 个特征值/特征向量。

注意根据定义，$\Sigma_b$ 作为 $M$ 个相关（通过 $\boldsymbol{\mu}_0$）秩一矩阵之和，其秩为 $M-1$（问题 7.15）。因此，乘积 $\Sigma_{wx}^{-1}\Sigma_{bx}$ 仅有 $M-1$ 个非零特征值。这对降维施加了严格约束：最大维度 $m = M-1$（二分类任务中 $m=1$），与原始维度 $l$ 无关。有两种情况值得关注：

*   **$m = M-1$**：若 $A$ 由所有对应非零特征值的特征向量组成，则有

## 7.8 分类树

分类树基于一个简单而强大的思想，是分类任务中最流行的技术之一。它们是*多阶段*系统，将模式分类到某个类别是*顺序*实现的。通过一系列测试，类别按顺序被*拒绝*，直到最终做出决策，支持剩下的那个类别。每个测试的结果决定拒绝哪些类别，其类型为*二元*的“是”或“否”，且作用于*单个*特征。我们的目标是阐述一种称为*普通二元分类树*（OBCT）的特殊树类型的主要理念。它们属于一类更通用的构建树的方法，既用于分类也用于回归，称为*分类与回归树*（CART）[2,31]。该方法的变体也已被提出[35]。

OBCT 的基本思想是将特征空间划分为（超）*矩形*；即通过与坐标轴平行的超平面对空间进行划分。这在图 7.12 中进行了说明。通过一系列此类“问题”来执行将空间划分为（超）矩形：特征 `x[i] < a` 的值是否成立？这也称为*分裂准则*。这系列问题可以通过树结构很好地实现。图 7.13 展示了对应图 7.12 所示情况的树。树的每个节点对*单个*特征执行测试，如果它不是叶节点，则连接到两个*后代*节点：一个对应答案“是”，另一个对应答案“否”。

### 备注 7.5

*   如果 `J3` 与其他矩阵组合一起使用（例如用 `Σ[m]` 代替 `Σ[b]` 可能实现这种情况），则秩等于 `M - 1` 的约束被移除，可以获得更大的 `m` 值。

*   在许多实际情况下，`Σ[w]` 可能不可逆。例如，在*小样本量*问题中，特征空间的维数 `l` 可能大于训练数据的数量 `N`。此类问题可能出现在网页文档分类、基因表达谱分析和人脸识别等应用中。针对该问题有不同的解决途径；详见文献 [38] 的讨论及相关参考文献。

### Fisher 方法与降维

*   换句话说，将维度从 `l` 降至 `M - 1` 时，不会丢失信息（以 `J3` 准则衡量）。注意，在这种情况下，Fisher 方法产生 `m = M - 1` 个判别（线性）函数。这符合分类学中的一个通用结论：`M` 分类问题所需的最少判别函数数目为 `M - 1` [38]。回顾贝叶斯分类，我们需要 `M` 个函数 `P(ω[i]|x)`，`i = 1, 2, …, M`；然而，其中只有 `M - 1` 个是独立的，因为它们的总和必须为 1。因此，Fisher 方法提供了所需的最少线性判别函数数目。
