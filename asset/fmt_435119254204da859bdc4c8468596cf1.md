接下来我们实现一个多层前馈神经网络。在这种情况下，我们可以有多个隐藏层。在本例中，我们将使用多层神经网络作为回归器，即预测连续变量。首先在指定范围内生成了一组 75 个预测变量值。使用方程 `y = 4x² + 7.6` 生成对应的目标值并进行归一化。使用这组点训练多层神经网络。然后，使用训练好的模型生成预测值，并与从回归函数生成的实际数据点进行比较。

```python
import neurolab as nl
import matplotlib.pyplot as plt
# 创建训练样本，假设最小值为 -2，最大值为 2，训练点数为 75
minm_val = -2
maxm_val = 2
no_points = 75
x = np.linspace(minm_val, maxm_val, no_points)
y = 4*np.square(x) + 7.6
y /= np.linalg.norm(y)
input_data = x.reshape(no_points,1)
target = y.reshape(no_points,1)
# 创建具有 2 个隐藏层的网络 - 第一层有 12 个神经元，第二层有 8 个神经元
# 任务是预测值
net = nl.net.newp([-2, 12], [1, 2], 1)
# 然后将训练算法设置为梯度下降
error = net.train(input, target, epochs=200, show=100,
=0.01)
# 模拟网络生成预测
output_data = net.sim(input_data)
# 绘制结果
plt.plot(x, output_data, 'r')
plt.plot(x, y, 'b')
plt.legend(['Predicted', 'Actual'])
plt.title('Actual vs predicted')
plt.grid()
plt.show()
```

GT 观察到，Newtel 服务中心有大量的服务请求，这些请求在问题类型上具有重复性。这从服务请求的文本中显而易见。此外，在大多数情况下，客户需要遵循某些标准步骤来解决问题。因此，GT 专家推断，可以通过机器学习算法根据历史服务请求创建聚类服务请求的“桶（buckets）”。对于每个“桶”，都可以关联一组相应的标准解决方案。每当有新的服务请求到达 Newtel 服务中心时，另一个机器学习算法将识别出新请求应该标记的“桶”，提取出相应的标准解决方案并发送给客户。所有这些过程都将在没有任何人工干预的情况下完成。因此，可以在不增加额外人员的情况下处理额外的呼叫量。这将显著减少对额外人力的需求，从而对运营成本和盈利能力产生影响。

在 GT 提供的解决方案中，存储中的服务请求通过特定描述性字段的文本分析、解决每个请求所需的时间以及用户选择的分类变量的组合进行聚类。所选的具体文本分析技术是 `Word2Vector`，聚类技术是 `DBSCAN`。为了将新的服务请求分类到已创建的某个桶中，使用了 `Cosine Similarity`（余弦相似度）算法。让我们详细回顾一下技术解决方案。

### (V) 新 SR 分配到正确的桶 – 余弦相似度函数

#### 算法：

1. 使用 `word2vec` 函数根据 SR 的描述文本创建向量。
2. 使用 `cosine_similarity` 函数计算向量的相似度得分。
3. 根据该簇中所有服务请求的平均最大相似度得分，找到该服务请求所属的簇。
4. 如果没有找到与此 SR 向量匹配的簇，则该 SR 与训练库中的任何项都不相似，不分配到任何簇中。
