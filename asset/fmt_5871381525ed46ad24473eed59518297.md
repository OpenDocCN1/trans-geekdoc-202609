## 3

具体而言，字典原子将对应于二维冗余 DCT 变换，并按如下方式获得 [49]：

1. **a)** 考虑向量 `d[i] = [d[i, 1], d[i, 2], ..., d[i, 12]]^T`，*i* = 0, ..., 13，为以下形式的采样正弦波：

```
d_{i,t + 1} = cos(tπi / 14),  t = 0,...,11.
```

2. 然后构建一个 `(12 × 14)` 矩阵 `D̄`，其列为归一化到单位范数的向量 `d[i]`；`D` 类似于一个冗余 DCT 矩阵。

3. **b)** 构建 `(12² × 14²)` 字典 `Ψ`，根据 `Ψ = D ⊗ D`，其中 `⊗` 表示克罗内克积。以这种方式构建，生成的原子对应于与冗余 2D-DCT 变换相关的原子 [49]。
