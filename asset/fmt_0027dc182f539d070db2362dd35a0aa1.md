### 6.1.4 统计显著性

在评估分类器时，我们应关注结果的统计显著性。仅观察单个分类器的性能时，提供关于其统计显著性的一些见解是很方便的。我们可以使用参数估计的*置信区间*来指示估计的可靠性。为此，我们可以使用 Chernoff 界或 Hoeffding 界，它们比 Markov 不等式或 Chebyshev 不等式更精确，因为我们关心的度量是对单个项目评估的平均值。对于数量合理的大量数据点，通常适用正态分布近似；参见第 4.2 节。

#### 当比较两个分类器时

当比较两个分类器时，我们需要区分实验准确率中的随机差异和非随机差异。McNemar 检验 [173] 是流挖掘文献中最流行的非参数检验，用于评估两个分类器性能差异的统计显著性。该检验需要存储和更新两个变量：被第一个分类器误分类而第二个分类器未误分类的实例数 `a`，以及被第二个分类器误分类而第一个分类器未误分类的实例数 `b`。McNemar 统计量计算公式为 `M = |a − b − 1|²/(a + b)`。该检验服从 `χ²` 分布。在 0.99 置信度下，如果 `M > 6.635`，则拒绝原假设（即性能相等）。

尽管机器学习领域已有数十年历史，但关于比较分类器性能以及随之而来的显著性能差异度量问题，仍存在诸多争论。最新的贡献来自 Berrar [29]，他认为应关注性能差异的大小（以及该差异的合理界限），而非统计显著性。这项工作的成果是一种名为置信曲线的新评估工具，可直接显示差异大小。原假设显著性检验和 `p` 值的相关问题，也最近促使人们提出了该问题的贝叶斯替代方案 [78]。因此，目前无法给出关于性能度量的定论，因为经典和流式机器学习仍需进一步研究。特别是，尚未提出用于估计数据流随时间变化的效应量的度量。

### 6.1.5 挖掘过程的成本度量

同时度量三个评估维度的问题，导致了数据流挖掘中的另一个重要问题，即估算学习和预测过程在时间和内存方面的综合成本。例如，存在多种租赁成本选项：

*   **每小时使用成本**：Amazon Elastic Compute Cloud (Amazon EC2) 是一项提供云端可调整计算容量的 Web 服务。成本取决于时间和所租机器的规模（例如，配备 2 GB 内存的小型实例、8 GB 的大型实例或 16 GB 的超大型实例）。
*   **每小时及内存使用成本**：GoGrid 是一项类似于 Amazon EC2 的 Web 服务，但它按 RAM-小时收费。按定义，部署 1 GB 内存 1 小时即等于 1 RAM-小时。

上述定义的 RAM-小时的使用，在文献 [37] 中被引入作为流式算法所用资源的评估度量。尽管是为学习任务提出的，但它也可应用于其他数据挖掘任务。

## 6.2 基准分类器

批量学习促成了数百种不同分类器的发展，它们属于多种范式，如分治法、规则学习器、惰性学习器、核方法、图模型等。若要将这些范式中的方法 `streamify`（流式化），我们需要考虑如何使它们既增量又快速。有些方法天然具有增量和快速的特性，我们将从这些方法开始介绍。关于将批量方法应用于大型数据集的研究告诉我们，应寻找具有良好偏差管理能力的方法。如果一种方法具有高偏差（如我们接下来将介绍的方法），则其泛化能力将受到限制。产生更复杂模型的方法通常泛化能力更好，但必然具有更高的维护成本，并应控制过拟合。产生能够良好管理权衡（模型表示的复杂性与模型更新的速度）的方法，是数据流分类研究中的主要问题。

### 6.2.1 多数类

`Majority Class`（多数类）算法是最简单的分类器之一：它预测新实例的类别为最频繁的类别。它主要用作基准，也可用作决策树叶节点上的默认分类器。`Majority Class` 分类器非常易于计算和维护，因为它只需为每个类别保留一个计数器数组。

### 6.2.2 无变化分类器

另一种用于数据流的简单分类器是 `No-change`（无变化）分类器，它预测新实例的标签为前一个实例的真实标签。与 `Majority Class` 分类器一样，它不需要实例特征，因此非常易于实现。在入侵检测场景中，长时间的“无入侵”后伴随短暂的“入侵”时期，该分类器仅在边界情况下会出错，并能快速适应标签的一致模式。

当怀疑连续标签之间存在时间依赖性时，通常将前一个实例（或多个实例）的标签作为新属性添加进去是有益的。这种能力在文献 [42, 262] 中提出，在 MOA 中作为通用包装器 `TEMPORALLYAUGMENTEDCLASSIFIER` 可用。

### 6.2.3 朴素贝叶斯

`Naive Bayes`（朴素贝叶斯）是一种以计算成本低、简单著称的分类算法。作为一种增量算法，它非常适合数据流场景。然而，它假设属性之间相互独立，这在许多真实数据流中可能并不成立。

它基于贝叶斯定理，非正式表述如下：

```
Pr(c|d) = Pr(c)Pr(d|c) / Pr(d)
```

即，它说明了在考虑证据后事件概率如何被修正。更正式地表述为：

```
Pr(c|d) = Pr(c)Pr(d|c) / Pr(d)
```

其中 `Pr(c)` 是先验概率，即事件 `c` 的初始概率；`Pr(c|d)` 是后验概率，即考虑 `d` 后的概率；`Pr(d|c)` 是似然概率，即事件 `c` 发生时事件 `d` 的概率；`Pr(d)` 是事件 `d` 的概率。它基于条件概率的定义，即 `Pr(c ∩ d) = Pr(c)Pr(d|c) = Pr(d)Pr(c|d)`。

`Naive Bayes` 模型的构建过程如下：设 `x[1], …, x[k]` 为 `k` 个离散属性，假设 `x[i]` 可取 `n[i]` 个不同值。设 `C` 为类别属性，可取 `n[C]` 个不同值。收到一个无标签实例 `I = (x[1] = v[1],…,x[k] = v[k])` 时，`Naive Bayes` 分类器按如下方式计算 `I` 属于类别 `c` 的“概率”：

```
Pr(c|I) = Pr(c) ∏ Pr(x[i] = v[j] | c)
```

值 `Pr(x[i] = v[j] ∧ C = c)` 和 `Pr(C = c)` 从训练数据中估计得出。因此，训练数据的摘要仅是一个三维表，用于存储每个三元组 `(x[i], v[j], c)` 的计数 `n[i,j,c]`，即满足 `x[i] = v[j]` 且类别为 `c` 的训练实例数，连同一个用于 `C = c` 计数的一维表。该算法天然具有增量性：收到新样本（或一批新样本）时，只需增加相关计数即可。可随时根据当前计数进行预测。

### 6.2.4 多项式朴素贝叶斯

多项式朴素贝叶斯分类器 [171] 是用于文档分类的朴素贝叶斯扩展，通常能产生令人惊讶的良好结果。多项式朴素贝叶斯将文档视为词袋，因此它考虑了文档中每个词的频率，而不仅仅是其出现与否。由于词频通常与文本分类相关，因此与朴素贝叶斯相比，该方法在文本挖掘中更受青睐。

设 `n[wd]` 为词 `w` 在文档 `d` 中出现的次数。则给定测试文档的类别 `c` 的概率计算如下：

```
Pr(c|d) = Pr(c) * ∏ Pr(w|c)^n[wd] / Pr(d)
```

其中 `Pr(d)` 可被视为归一化因子。

但与朴素贝叶斯的一个关键区别在于对 `Pr(w|c)` 的解释：这里它是类别 `c` 的文档中 `w` 的出现次数与类别 `c` 的文档中总词数之比。换句话说，它是属于类别 `c` 的文档在任意位置观察到词 `w` 的概率。请注意，同样与朴素贝叶斯不同，文档中某词的缺失并不会使任何类别比其他类别更有可能，因为这相当于 0 次幂。

方便的是，通过维护适当的计数器，`n[wd]`、`Pr(w|c)` 和 `Pr(c)` 在数据流上很容易估计。可以通过将所有计数初始化为 1 而不是 0 来添加拉普拉斯修正。

可以通过在叶节点使用其他分类器（如朴素贝叶斯）或使用决策树集成（稍后将看到）来提高决策树的准确性。

构建树的基本方法是首先在开头创建一个根节点 `node = root`，然后执行以下操作：

1.  如果训练实例在该节点被完美分类，则停止。否则：
2.  将 `A` 分配为 `node` 的“最佳”决策属性。
3.  对于 `A` 的每个值，创建 `node` 的新后代（叶节点）。
4.  根据 `A` 的值分割训练实例，并将每个分割传递给相应的叶节点。
5.  递归地将此方法应用于每个叶节点。

两种常用度量用于选择最佳决策属性：

*   **信息增益**，即按属性分裂前后类别熵的差值。回想一下，样本 `S` 的熵 `H` 为 `H(S) = -∑ p[c] log p[c]`，其中 `p[c]` 是 `S` 中类别标签 `c` 的概率。按属性 `A` 分裂后 `S` 的熵为 `H(S,A) = ∑ (|S[a]|/|S|) H(S[a])`，其中 `S[a]` 是 `A` 取值为 `a` 的 `S` 的子集。`A` 的信息增益为 `IG(S,A) = H(S) − H(S,A)`。该度量在 C4.5 决策树算法后变得流行。
*   **基尼不纯度减少**，即按属性分裂前后基尼指数的差值。该度量在 CART 决策树算法后变得流行。随机变量 `C` 的基尼指数是 `C` 离散程度的另一种非线性度量，定义为 `Gini(C) = 1 - ∑ p[c]²`。

### 6.3.1 估计分裂准则

上述度量需要从有限样本中估计，但要以一种能泛化到未来示例的方式进行（即无论现在还是一个月、一年、十年后做出决策，假设平稳性，决策仍将相同）。这需要第 4.2 节所述那些浓度不等式精神的不等式，它们限定了有限样本上的估计值偏离其期望值的概率。

霍夫丁不等式常用于估计信息增益或基尼指数等度量。不幸的是，这些度量不能表示为独立随机变量之和，因此 Rutkowski 等人 [218] 近期的工作指出霍夫丁界是错误的工具。
