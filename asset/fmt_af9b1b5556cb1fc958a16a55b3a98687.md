
如图 5-24 所示，左侧神经网络的所有神经元均被激活，右侧神经元使用 Dropout 进行激活。Dropout 通过使某些神经元失活来定义不同的神经网络函数。因为梯度下降训练过程的每次迭代都会随机使部分神经元失活，所以不同的迭代针对的是不同的函数。因此，神经网络不会过度依赖少数几个神经元，这相当于群体的决策不依赖少数人，而是每个人都有机会参与，从而防止因过度依赖少数人而产生的偏见。Dropout 类似于数据归一化的思想。如果数据未归一化，数值较大的某些特征将对学习算法产生过大影响，而其他特征影响甚微。Dropout 也类似于权重正则化的思想。权重正则化通过惩罚项使所有权重变小，防止少数权重过大。

以一定概率使某网络层 Dropout 会导致该网络层总输出期望变小。例如，该网络层原本的总输出期望为 `e`，Dropout 丢弃概率为 `drop_p`，则期望值将变为 `e * (1 - drop_p)`。为了避免影响后续层，使用 Dropout 的输出层中每个神经元的输出通常除以 `(1 - drop_p)`。即如果某神经元的激活函数输出值为 `a`，则修改为输出 `a / (1 - drop_p)`。

因为训练的每次迭代中，Dropout 随机丢弃不同的神经元，即每次迭代的神经网络函数不同。因此损失函数的含义不是很明确，不同迭代的损失是不同函数的损失，而不是同一函数的损失。最终训练得到的函数可以看作是这些不同迭代产生的不同函数的平均。通过多个不同函数模型的平均可以获得更好的模型，正如通过多数人的投票而不是少数人的投票可以获得更好的结果一样。这再次体现了基于统计学习的机器学习的基本思想。Dropout 通过多个函数的平均可以有效避免过拟合。

此外，Dropout 仅用于训练模型，训练后的模型函数应当是明确的。因此，最终训练得到的神经网络函数应当是由所有处于激活状态的神经元组成的函数。因此，在验证和测试模型时，不应再使用 Dropout。

Dropout 可以作用于任意隐藏网络层的输出。如果该网络层的输出为 `x`，Dropout 操作可表示为：

`x = D ⊙ x`

其中，`D` 是与 `x` 形状相同的数组，`D` 中每个元素的值为 1 或 0，表示对应神经元是否被激活。数组 `D` 是基于 Dropout 丢弃率或存活率计算的掩码数组。可使用以下代码执行 Dropout 操作：

```python
retain_p = 1 - drop_p
mask = (np.random.rand(*x.shape) < retain_p) / retain_p
x *= mask
```

其中，`drop_p`、`retain_p = 1 - drop_p` 分别为丢弃率和保留率，`mask` 为保持激活状态的掩码数组。

反向推导时，只需将损失函数关于 Dropout 输出的梯度 `dx_output` 乘以该掩码 `mask` 即可。

```python
dx = dx_output * self._mask
```

其中 `dx_output` 是反向传播进来的关于 `x` 的损失函数梯度。

Dropout 操作可以实现为一个独立的 Dropout 层，代码如下：

```python
from Layers import *

class Dropout(Layer):
    def __init__(self, drop_p):
        super().__init__()
        self.retain_p = 1 - drop_p

    def forward(self, x, training=True):
        retain_p = self.retain_p
        if training:
            self._mask = (np.random.rand(*x.shape) < retain_p) / retain_p
            out = x * self._mask
        else:
            out = x
        return out

    def backward(self, dx_output, training=True):
        dx = None
        if training:
            dx = dx_output * self._mask
        else:
            dx = dx_output
        return dx
```

其中 `x` 是 Dropout 层上一层的输出。对于输入 `X`，以下代码使用 `dropout.forward(X)` 计算 Dropout 的输入，反向推导时，使用 `dropout.backward(dx_output)` 从关于 `X` 的反向输入梯度获取 Dropout 后的反向梯度。

##### Dropout 原理与应用

`Dropout` 是一种降低函数复杂度的技术。模型参数越多，模型越复杂。同理，神经网络不同网络层的参数不同，复杂度也不同。`Dropout` 可添加到任意隐藏层，参数较多的隐藏层丢弃率可设高，反之设低。对于模型参数较少的网络层，可不添加 `Dropout` 层。

`Dropout` 用于防止过拟合，但因其导致每次迭代使用不同函数，损失函数失去意义，无法用调试工具调试训练参数。常规做法是先关闭 `Dropout`（但可添加正则项防止过拟合），调优参数后再开启 `Dropout` 进一步提升模型质量。

`Dropout` 属于正则化技术。当网络规模相对数据集较小时，通常不需正则化，因为模型复杂度已较低。强行添加会降低模型表达能力，损害学习性能。此外，`Dropout` 显然不能置于输出层前后，因为网络在接近分类前无法“纠正”丢失带来的误差。实践中，`Batch Normalization` 已广泛取代 `Dropout`。

### 全连接神经网络的局限性

此前的神经网络中，每个输入样本为一维张量，各层神经元接收上一层的一维张量并输出。此类网络称为**全连接神经网络**（`Full Connection Neural Networks`）。对于图像等二维或三维张量，需将其展平为一维张量输入。展平会丢失图像固有的空间结构信息（如像素邻接关系），打乱展平张量的元素顺序不影响网络函数训练——即张量元素全同、顺序不同，仍产生相同网络函数。试想，将图像所有像素随机排列后仍能识别同一物体，这显然不合理，因为像素必须按特定空间结构排列才能形成有意义的图像。

用全连接网络处理展平图像数据，随图像尺寸增大，模型参数剧增。以 28×28 黑白图为例，展平后一维张量长度 784，单个神经元需 784 个权重参数。64×64×3 彩色图展平长度 12288，单神经元需 12288 参数。高分辨率图像（如 1280×1280×3）单神经元参数达 4915200。通常输入一维张量越长，首层神经元数也需相应增加，导致后续层神经元数跟着增加，模型参数随输入张量长度和网络深度呈指数级增长。巨大参数量使网络函数极其复杂，训练困难且易过拟合，即便采用防过拟合技术，海量参数也会导致内存消耗过大甚至无法存储。

## 卷积神经网络

**卷积神经网络**（`Convolutional Neural Networks`，简称 `CNN` 或卷积网络）利用图像特征的平移不变性，以极少权重参数处理图像，同时保持图像的内存空间结构。所谓图像平移不变性，指图像中的特征不因其在图像上的位置平移而改变。例如，猫从图像左上角移至右下角，仍是猫。

# Convolutional Neural Networks

Convolutional Neural Networks (CNNs) are neural networks specifically designed for images. CNNs are easy to parallelize and can leverage Graphics Processing Units (GPUs) to accelerate functions. In 2012, Hinton's student Alex Krizhevsky et al. used a CUDA GPU-based CNN called AlexNet to win the ImageNet competition, which reignited enthusiasm for neural network research and ushered in deep learning based on deep neural networks.

CNNs are the most exciting neural networks in deep learning and have become the core of deep learning. CNNs have revolutionized computer vision research. They are the top choice in the field of computer vision and continue to make breakthroughs in many computer tasks, with related research papers growing explosively. Beyond computer vision, CNNs have been extended to problems with one-dimensional sequential structures, such as time series analysis of audio, text, and gene sequences. CNNs have also been extended to domains where data has a graph structure, giving rise to new neural network technologies like Graph Neural Networks.

Here are some typical CNN applications:

*   Detecting, recognizing, locating, and labeling objects in images, e.g., identifying what objects are in an image and their locations. Famous applications include face recognition, object detection, and autonomous driving.

*   Speech recognition, sound synthesis, e.g., automatically converting speech to text, text to speech, music, etc.

*   Describing images and videos with natural language.

*   Road and obstacle recognition in autonomous vehicles.

*   Analyzing video game screens to guide agents to play games automatically.

*   Generating realistic-looking images. For example, generating realistic human faces, video face swapping (such as the famous DeepFake).
