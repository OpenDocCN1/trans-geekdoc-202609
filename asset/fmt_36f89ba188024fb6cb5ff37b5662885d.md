# 1.

Bart 收到一封似乎来自他律师的电子邮件，包含一个名为 `Courtdoc.zip` 的 ZIP 文件。Bart 双击该 ZIP 文件打开，弹出一个显示“此 Word 文档损坏”的消息。在后台，一个名为 `Courtdoc.zip.exe` 的文件正在运行并将其复制到本地 `APPDATA` 目录。然后它开始向外部服务器发送信标。以下哪项最能描述 Bart 安装的恶意软件？

**A.** 蠕虫

**B.** 病毒

**C.** 木马

**D.** 宏

![Image](img/r.jpg) **C.** 木马（Trojan）的定义是一种非自我复制的程序，它看起来有用的用途，但实际上具有不同的恶意目的。换句话说，它看起来无害，但在激活时并非无害。这正是本例中正在发生的情况。电子邮件不是传播 `Trojan` 的*唯一*方法，但钓鱼攻击确实非常有效。

![Image](img/w.jpg) **A** 是错误的，因为这描述的不是 `worm`（蠕虫）。`worm` 是一种自我复制、自我传播、自包含的程序，利用网络机制来传播自己。

![Image](img/w.jpg) **B** 是错误的，因为这描述的不是 `virus`（病毒）。`virus` 是一种具有自我复制能力的恶意计算机程序，它附于另一个文件并随宿主从一台计算机移动到另一台计算机。

![Image](img/w.jpg) **D** 是错误的，因为这描述的不是 `macro`（宏）。`macro` 是一条指令，可以自动扩展为多条指令以执行特定任务（就你的考试而言，通常与 Microsoft Office 产品相关）。

# 2.

你已经与目标机器建立了 `Netcat` 连接。可以使用哪个标志位来启动程序？

**A.** -p

**B.** -a

**C.** -l

**D.** -e

![Image](img/r.jpg) **D.** `Netcat` 通常被称为黑客攻击的瑞士军刀。你可以用它在目标机器上设置监听端口，然后再次访问该端口以制造各种混乱。与启动程序相关的标志位是 `-e`。例如，执行命令

```bash
nc –L –p 12657 –t –e cmd.exe
```

将在目标机器上打开一个 Windows 命令行壳；`-t` 标志通过你用 `-p` 标志定义的端口（`12657`）建立 Telnet 连接。

![Image](img/w.jpg) **A** 是错误的，因为 `-p` 标志表示你想要为会话使用的协议端口。

![Image](img/w.jpg) **B** 是错误的，因为 `-a` 不是可识别的 `Netcat` 标志。

![Image](img/w.jpg) **C** 是错误的，因为 `-l` 标志表示 `Netcat` 打开监听端口。顺便提一下，`-L` 标志的作用相同；但它会在入站会话完成后重新启动监听。

# 3.

Claire 正在浏览网页，一段时间后弹出一个消息显示她的系统已被恶意软件感染，并提供了一个点击以删除病毒的按钮。在她点击按钮后，出现了另一个消息窗口显示由于感染性质，系统已被隔离，并提供了一个带有支付说明的链接以便重新获得控制并清除病毒。以下哪项最能描述这种感染？

**A.** 间谍软件

**B.** 勒索软件

**C.** 木马

**D.** 广告软件

![Image](img/r.jpg) **B.** `ransomware`（勒索软件）的名字暴露了它的目的：恶意软件感染你的系统，然后限制对你的文件和文件夹的访问，要求支付赎金以重新获得控制。ECC 列出了五个不同的 `ransomware` 家族：`Cryptorbit`、`Cryptolocker`、`Cryptodefense`、`Cryptowall` 和警察主题。通常在线支付涉及 `bitcoin`，也可以通过其他途径。无论如何，永远不要攻击者付费——你只会给自己招麻烦。

![Image](img/w.jpg) **A** 是错误的，因为这描述的不是 `spyware`（间谍软件）。`spyware` 是一种秘密收集用户信息的恶意软件。

![Image](img/w.jpg) **C** 是错误的，因为这描述的不是 `Trojan`（木马）。`Trojan` 是一种非自我复制的程序，它看起来有用的用途，但实际上具有恶意目的。

![Image](img/w.jpg) **D** 是错误的，因为这描述的不是 `adware`（广告软件）。`adware` 是在内部显示广告的软件。

# 4.

Matty 正在检查恶意软件而不运行它。相反，她正在检查源代码、函数调用和其他指标。以下哪项最能描述 Matty 正在进行的分析类型？

**A.** 静态

**B.** 动态

**C.** 文件指纹

**D.** 代码模拟

![Image](img/r.jpg) **A.** ECC 定义了两种主要的恶意软件类型——`static`（静态）和 `dynamic`（动态）。在静态分析中，检查人员从不实际执行恶意软件。这被认为是“安全的”分析，但有一些静态工具可以帮助。

![Image](img/w.jpg) **B** 是错误的，因为 `dynamic` 分析是在监控环境中通过实际安装和运行恶意软件来检查检查的过程。

![Image](img/w.jpg) **C** 是错误的，因为 `file fingerprinting`（文件指纹）涉及为定的二进制文件计算哈希值。

![Image](img/w.jpg) **D** 是错误的，因为 `code emulation`（代码模拟）是一种检测方法，杀毒软件在虚拟机上执行恶意代码以模拟 CPU 和内存活动。

# 5.

渗透测试成员 Amy 尝试猜测 TCP 会话的 ISN。她最可能正在进行什么攻击？

**A.** XSS

**B.** 会话拼接

**C.** 会话劫持

**D.** 多部分攻击

![Image](img/r.jpg) **C.** `session hijacking`（会话劫持）背后的思想非常简单：攻击者等待会话开始，在完成所有烦人的身份验证后，跳入并窃取会话给自己用。在实践中，这比这要稍微困难且复杂得多，但整个攻击的关键在于确定用于会话的初始序列号（`ISN`）。`ISN` 由会话发起者在第一步（`SYN`）中发送。这在握手的的第二步（`SYN/ACK`）中通过将该 `ISN` 加 1 得到确认，另一个 `ISN` 由接收者生成。这个第二个数字由发起者在第三步（`ACK`）中确认，从那里开始通信就可以进行。根据 EC-Council 的说法，以下步骤描述了会话劫持：

1. 嗅探客户端和服务器之间的流量。

2. 监控流量并预测序列编号。

3. 使会话与客户端不同步。

4. 预测会话令牌并接管会话。

5. 向目标服务器注入数据包。

坦率地说，通过 EC-Council 对此事的解读来实施这种攻击，需要你进行相当大量的流量嗅探。而且如果你最初已经处于可以嗅探流量的位置，那么整个场景可能就变得没有意义了呢？你在考试中需要了解这一点，但在现实世界中的应用可能较少。

![Image](img/w.jpg) **A** 是错误的，因为跨站脚本是一种 Web 应用程序攻击。

![Image](img/w.jpg) **B** 是错误的，因为会话拆分（session splicing）是一种 IDS 规避方法。攻击者通过将负载“切分”到多个数据包中，交付一个 IDS 本会看到的负载。该负载可以分布在很长的时间内。

![Image](img/w.jpg) **D** 是错误的，因为 `multipartite` 指的是一种病毒类型，而不是需要确定 ISN 的攻击。

### 6.

攻击者希望让他的恶意软件尽可能隐蔽且不可检测。他采用了一种使用压缩技术来减小恶意软件大小的方法。以下哪项最能描述这种行为？

**A.** 加密器 (Crypter)

**B.** 封装器 (Wrapper)

**C.** 壳器 (Packer)

**D.** 压缩器 (Compressor)

![Image](img/r.jpg) **C.** 壳器使用压缩将恶意软件执行文件封装成更小的尺寸。这不仅减小了文件大小，还让恶意软件更难被某些防毒引擎检测。虽然它可以与 `ZIP` 文件进行比较，但它们存在差异。例如，提取是在内存中进行的，而不是磁盘上。但壳器与像 `.zip` 这样的通用压缩程序之间的 `primary` 区别在于，壳器在运行时对二进制文件进行解胀/恢复（而 `.zip` 提供的是更通用的压缩）。

![Image](img/w.jpg) **A** 是错误的，因为加密器（crypter）是一种软件工具，它结合加密和代码操纵，使恶意软件无法被 AV 和其他安全监控产品检测（在互联网术语中，它被称为 `fud,`，代表“完全不可检测”）。

![Image](img/w.jpg) **B** 是错误的，因为封装器（wrapper）用于将木马和合法程序绑定在一起，以便在执行合法程序时安装木马。

![Image](img/w.jpg) **D** 仅作为干扰项包含，并不是一个合法的术语。

### 7.

**A.** 无文件恶意软件

**B.** 僵尸网络 (Zombie)

**C.** 放大攻击 (Fraggle)

**D.** 高级持续性威胁 (APT)

![Image](img/r.jpg) **D.** NIST 对高级持续威胁（APT）的定义如下：“具有高水平专业知识和大量资源的对手，使其通过使用多种不同的攻击向量（例如网络、物理和欺骗）来创造实现其目标的机会，这些目标通常是在组织的信息技术基础设施内建立并扩展立足点，以持续外泄信息，和/或破坏或阻碍任务、计划或组织的关键方面，或者在未来处于可以这样做的位置；此外，高级持续威胁在很长时间内反复追求其目标，适应防御者的抵抗努力，并下决心维持执行其目标所需的交互水平。”

我不知道你们怎么想，但那段长篇文字让我想起了在使用 iPhone 之前必须接受的协议条款。

这真正的意思是 APT 是坏人（通常是资金充足的国家级攻击者），他们找到了进入你系统的方法，并在那里停留了很长时间。从事件响应（IR）的角度来看，APT 是一场噩梦，因为要追踪初始攻击向量、他们存在了多久以及他们访问了多少内容几乎是不可能完成。

![Image](img/w.jpg) **A** 是错误的，因为无文件恶意软件利用现有漏洞来感染系统。

![Image](img/w.jpg) **B** 是错误的，因为僵尸网络（zombie）指的是被控制并响应请求的系统。

![Image](img/w.jpg) **C** 是错误的，因为放大攻击（fraggle）是指使用 UDP 数据包发送到广播地址。

### 9.

Claire 工作的 Windows 系统开始显示异常，她联系了 IT 人员。调查显示，Claire 的系统感染了多种病毒。IT 人员通过删除多个文件和文件夹并使用 AV 工具删除了病毒，然后将机器连接到网络。当天晚些时候，Claire 的系统再次显示异常，IT 人员再次被联系。以下哪些项可能是再次感染的原因？（选择所有适用项）

**A.** Claire 再次访问了恶意网站。

**B.** Claire 打开了 Microsoft Outlook 邮件客户端，新收到的邮件被加载到本地文件夹 `.pst` 中。

![Image](img/w.jpg) **B** 是错误的，因为来自服务器的新邮件并不一定是原始感染的成因。
