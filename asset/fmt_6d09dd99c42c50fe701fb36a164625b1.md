## 4.1 神经网络

前面学习的线性回归使用数据特征的线性函数来表示特征与目标值之间的函数关系。线性函数过于简单，对于许多机器学习问题，特征与目标值之间的函数关系往往是非线性的。逻辑回归在线性函数的基础上进一步使用非线性函数 `σ(z)` 将线性函数的结果转换为 [0, 1] 之间的概率值，从而使特征与目标值之间存在非线性关系，但仅将线性加权求和转换为概率，也难以表示复杂函数。

如何表示复杂函数？

复杂函数通常可以分解为简单函数，或通过简单的四则运算或函数组合由简单函数构成。例如，逻辑回归的假设函数 `σ(xw + b)` 就是由函数 `z = xw + b` 和 `σ(z)` 组合而成，而函数 `xw + b` 则是由 `x`、`w`、`b` 通过乘法和加法组成的。

非常复杂的函数可以通过简单运算和函数组合来表示。**神经网络** 就是以这种方式将许多简单的 **神经元** 函数组合成一个复杂函数。神经元就是一个逻辑回归函数，即神经元函数对输入进行线性加权，然后使用非线性函数对加权求和进行非线性变换。当然，神经元函数中对加权求和执行非线性变换的函数也可能是其他类似于 `sigmoid` 函数的简单函数。神经网络由多个神经元（函数）组成，一个神经元的输出作为另一个神经元的输入，一个神经元接受其他神经元的输入，并将简单的加权求和和简单的（非线性）函数变换输出传递给其他神经元。神经元通过相互的输入输出连接形成网络，因此这个复杂函数被称为神经网络。

### 4.1.1 感知机与神经元

#### 1. 感知机

**感知机** 是一个具有二分类功能的简单函数。逻辑回归函数使用 `sigmoid` 函数将输入的线性加权求和转换为概率 `σ(xw)`，而感知机则使用阈值函数将输入的线性加权求和转换为 0 和 1：`sign_b`。其中 `sign_b` 是一个阶跃函数，根据 `z` 值是否大于阈值 `b` 输出 1 和 0：

$$
\begin{matrix} 
{sign\_b(z) = \left\{ \begin{matrix} 
1 & {\text{if } z >= b} \\ 
0 & \text{else} \\ 
\end{matrix} \right.} 
\end{matrix}
$$

感知机通过权重向量 `w` 计算输入 `x` 的加权求和 `xw`，然后根据加权求和是否超过某个阈值 `b` 输出 1 或 0 的值。例如，一个具有 3 个输入值的感知机计算如下：

$$f_{w,b}(x) = sign\_b(\sum\limits_{j = 1}^{3} w_j x_j)$$

感知机可以用一个简单的圆圈来可视化。图 4-1 中的感知机接受 3 个输入值并产生一个输出值 `f`：

图 4-1 感知机接受 3 个输入值并产生输出值 `f`

感知机也被称为 "**人工神经元**", 简称 "**神经元**"。它试图模拟人脑中的神经元。神经科学揭示，人脑由许多简单的神经元组成，如图 3-2 所示。

图 4-2 大脑神经元的结构

一个神经元通常有多个树突，主要用于接收传入的信息，而只有一个轴突，轴突末端有许多轴突末梢，可将信息传递给其他神经元，轴突末梢与其他神经元的树突建立连接以传递信号，该连接位置在生物学中称为“突触”。

每个神经元接受多个输入信号，每个输入信号对神经元的权重也不同。如果所有输入信号的加权求和超过神经元内部的“阈值”，则会产生一个输出信号。

用 `f_w` 表示感知机函数，即 `f_w = sign_b`，其中 `x` 是输入，`w` 是权重向量，即：

$$
\begin{matrix} 
{f\_w(x) = \left\{ \begin{matrix} 
1 & {\text{if } \sum\limits_{j} w_j x_j >= b} \\ 
0 & {else} \\ 
\end{matrix} \right.} 
\end{matrix}
$$

上述公式可以转换为：

$$
\begin{matrix} 
{f\_w(x) = \left\{ \begin{matrix} 
1 & {\text{if } \sum\limits_{j} w_j x_j - b >= 0} \\ 
0 & {otherwise} \\ 
\end{matrix} \right.} 
\end{matrix}
$$

`b` 可以是正数或负数，用 `b` 表示 −`b`，上述公式可以写为：

$$
\begin{matrix} 
{f\_w(x) = \left\{ \begin{matrix} 
1 & {\text{if } \sum\limits_{j} w_j x_j + b >= 0} \\ 
0 & {else} \\ 
\end{matrix} \right.} 
\end{matrix}
$$

因此，感知机函数通常可以写为 `f_w = sign(xw + b)`。

感知机可以直接表达最基本的逻辑计算函数：“与”、“或”、“与非”。图 4-3 展示了逻辑电路中“与门”、“与非门”、“或门”和“异或门”的功能。

```

```

图 4-3 是逻辑电路中“与门”、“与非门”、“或门”和“异或门”的功能图。

能够生成“与门”功能的感知机参数（`w[1]`、`w[2]`、`b`）可以有很多组，例如：(0.5, 0.5, −0.6)、(0.5, 0.5, −0.9)、(1, 1, −1)、(1, 1, −1.5) 等。例如，由参数 (0.5, 0.5, −0.6) 表示的感知机函数如下：

`sign(x[1]*w[1] + x[2]*w[2] + b) = sign(0.5*x[1] + 0.5*x[2] − 0.6)`

将 `x[1] = 0`、`x[2] = 0` 或 `x[1] = 1`、`x[2] = 0` 或 `x[1] = 0`、`x[2] = 1` 代入感知机函数，输出值为 0；将 `x[1] = 1`、`x[2] = 1` 代入感知机函数，输出值为 1。即该感知机实现了逻辑电路的“与门”功能。

能够生成“与非门”功能的感知机参数（`w[1]`、`w[2]`、`b`）也有很多组，例如：(−0.5, −0.5, 0.6)、(−0.5, −0.5, 0.9)、(−1, −1, 1)、(−1, −1, 1.5) 等。

能够生成“或”功能的感知机参数（`w[1]`、`w[2]`、`b`）也有很多组，例如：(1, 1, 0)、(1, 1, −0.5)、(0.5, 0.5, −0.3)。

对于感知机，可以使用不同的权重 `w[j]` 和偏置 `b` 来生成不同的具体功能（如“与”、“或”、“与非”等逻辑计算功能）。与逻辑回归函数一样，单个感知机本质上仍然表示一个线性可分函数。例如，由参数 (1, 1, −0.5) 表示的感知机是由直线 −0.5 + `x[1]` + `x[2]` = 0 分隔的 2 个半空间，位于一个半空间中的 (`x[1]`, `x[2]`) 的感知机输出值为 1，另一个半空间的输出值为 0。如图 4-4 所示：

#### 2. 神经元

神经元是对多个输入值的线性加权和执行线性或非线性变换以产生一个或多个输出值的函数或向量值函数。神经元接受多个输入值，对它们执行加权求和，然后通过线性或非线性函数产生一个输出或多个输出值。在神经元中将加权和进行线性或非线性变换的函数称为激活函数。

神经元函数表示如下：

$a = g(\sum\limits_{j}W_{j}x_{j})$

其中 `x[j]` 是输入值，`w[j]` 是对应输入的权重，它们的加权和 $\sum\limits_{j}W_{j}x_{j}$ 通过激活函数 `g` 产生输出值 `a`。神经元通常用圆圈表示，如下图 4-9 所示。

图 4-9 对输入加权并通过激活函数产生输出的人工神经元

有时也会表达神经元的偏置，即神经元函数写为：

$a = g(\sum\limits_{j}W_{j}x_{j} + b)$

相应地，可以将其可视化为如下图 4-10 所示的带偏置的神经元：

图 4-10 对输入加权加偏置后通过激活函数产生输出的人工神经元

神经元也常用下图 4-11 所示的更简化的圆圈表示：

图 4-11 接受多个输入值并产生单个输出值的人工神经元的符号表示

表示该神经元接受 3 个输入 `x[1]`、`x[2]`、`x[3]`（以及一个对应偏置的固定输入特征值 1），并产生一个输出值 $f_{w,b}(x) = g(\sum\limits_{j = 1}^{3}W_{j}x_{j} + b)$

如果用 `W[0]` 表示 `b`，用 `x[0]` 表示 1，则可表示为 $f_{w}(x) = g(\sum\limits_{j = 0}^{3}W_{j}x_{j})$

不同的激活函数决定了神经元的不同功能。线性回归、逻辑回归和感知机都使用具有不同激活函数的神经元。线性回归的激活函数是恒等函数 `g(z) = z`，直接输出加权和；而逻辑回归使用非线性激活函数（`sigmoid` 函数 `σ(z)`）对加权和进行变换。感知机使用阶跃函数 `sign(z)` 对加权和进行变换。因此，神经元是线性回归、逻辑回归和感知机的泛化。Softmax 回归可视为输出多个值的神经元，即其激活函数是 `softmax()` 函数。神经元的激活函数也可以是其他各种非线性函数，如 `tanh`、`ReLu` 函数等。
