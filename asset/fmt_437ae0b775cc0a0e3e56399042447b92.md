## 8.4 凸集投影基本定理

本节陈述了凸集理论中最著名的定理之一：凸集投影基本定理（POCS）。该定理是许多强大算法和方法的核心，其中一些在本书中有所描述。该定理的起源可追溯到冯·诺依曼 [98]，他针对两个子空间的情况提出了该定理。

约翰·冯·诺依曼（1903–1957）是匈牙利裔美籍犹太人。他是一位神童，22 岁便获得博士学位。很难概括他众多的重大贡献，这些贡献范围从纯数学到经济学（他被认为是博弈论的奠基人），从量子力学（他奠定了量子力学的数学框架基础）到计算机科学（他参与了 ENIAC——首台通用电子计算机——的开发）。他深度参与了氢弹研发的曼哈顿计划。

设 `C[k]`，`k` = 1, 2, …, `K`，为希尔伯特空间 `ℍ` 中有限个*闭*凸集，并假设它们有一个*非空*交集，

```
C = ⋂_{k=1}^{K} C_k ≠ ∅.
```

设 `T[C[k]]`，`k` = 1, 2, …, `K`，为相应的松弛投影映射

```
T[C[k]] = I + μ_k(P[C[k]] − I), μ_k ∈ (0, 2), k = 1, 2, …, K.
```

构成这些松弛投影的串联，

### 数学公式与定理说明

$$

T = T[C[K]] T[C[K-1]] \cdots T[C[1]],

$$

其中具体顺序并不重要。用文字描述，*T* 包含一系列松弛投影，从 *C*[1] 开始。随后，得到的点被投影到 *C*[2]，以此类推。

#### 定理 8.5

设 *C*[*k*] (*k* = 1, 2, …, *K*) 为希尔伯特空间 ℍ 中的闭凸集，且它们的交集非空。则对于任意 **x**[0] ∈ ℍ，序列 (*T*^(*n*)(**x**[0])), *n* = 1, 2, … 弱收敛于 $C = \bigcap_{k=1}^{K} C_{k}$ 中的一点。

参考文献 [17, 42] 给出了弱收敛的概念。当 ℍ 变为欧几里得（有限维）空间时，弱收敛的概念与熟悉的“标准”（强）收敛定义相吻合。弱收敛是强收敛的一个较弱版本，常见于无限维空间。若序列 **x**[*n*] ∈ ℍ 弱收敛于点 **x**[*] ∈ ℍ，则对任意 **y** ∈ ℍ，

$$

\langle \mathbf{x}_{n}, \mathbf{y} \rangle \underset{n \rightarrow \infty}{\rightarrow} \langle \mathbf{x}_{\ast}, \mathbf{y} \rangle,

$$

记作

$$

\mathbf{x}_{n} \underset{n \rightarrow \infty}{\overset{w}{\rightarrow}} \mathbf{x}_{\ast}.

$$

如前所述，在欧几里得空间中，弱收敛蕴含强收敛。但对于一般希尔伯特空间，这不一定成立。另一方面，强收敛总是蕴含弱收敛（例如，参考文献 [87]）（习题 [8.21]）。图 8.15 给出了该定理的几何图解。

该定理的证明在一般情况下略显技术性（例如，文献 [87]）。然而，对于涉及的凸集均为闭子空间的情况，证明可以简化（习题 8.23）。证明的核心在于：(a) `T[C[k]]` 的非扩张性，`k = 1, 2, …, K`，该性质被 `T` 保留；以及 (b) `T` 的不动点集为 `Fix(T) = ⋂_{k=1}^{K} C_k` 这一事实。

*   在所有 `C[k]`，`k = 1, 2, …, K` 均为闭子空间的特殊情况下，我们有

    ```
    T^(n)(x[0]) → P[C]x[0].
    ```

## 8.5 POCS 的并行版本

文献 [68] 中陈述了 POCS 算法的一个并行版本。除了其计算优势（当可利用并行处理时）外，该方案将作为我们推广到在线处理的工具，在在线处理中，可以应对凸集数量变为无限（或在实践中非常大）的情况。并行 POCS 的证明略显技术性，且严重依赖上一节陈述的结果。证明背后的概念是构造适当的乘积空间，这也是该算法被称为*乘积空间中的 POCS* 的原因。有关详细证明，感兴趣的读者可参考 [68]。
