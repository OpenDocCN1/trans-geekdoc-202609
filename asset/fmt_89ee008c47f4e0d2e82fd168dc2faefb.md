
# 固件与软件开发的差异

固件的存储本质上是非易失性的（ROM、EPROM 或闪存），而应用软件从易失性和虚拟内存运行 [[21]](#ch17.xhtml#r334)。使用固件开发的应用程序难以更新，因为该任务需要更换电路或通过无法在用户端管理的特殊过程重新编程。另一方面，使用软件开发的应用程序则简单得多，可以通过应用更新补丁频繁更改。由于固件用于监控硬件，它主要处理底层功能。软件用于管理硬件以及满足各种用户需求，因为软件涉及底层和高层功能 [[26]](#ch17.xhtml#r339)。

固件与设备软件之间的另一个显著区别是更新频率。如前所述，大多数设备的固件并非设计为由消费者修改。因此，设备制造商通常完全限制用户对固件的访问。这是一项必需的安全功能，因为当消费者篡改这些设备的固件时，相应地存在导致系统无法运行的可能性 [[21]](#ch17.xhtml#r334)。虽然设备的固件可能会更新，但应谨慎行事，因为这项任务不像构建和应用软件应用程序更新补丁那样常见且易于完成 [[44]](#ch17.xhtml#r357)。

软件与硬件应用开发之间的关键差异见表 9.1。

## 表 9.1 软件与固件应用开发的差异

| **差异** | **固件** | **软件** |
| --- | --- | --- |
| **功能** | 控制硬件设备 [[26]](#ch17.xhtml#r339)。 | 指示计算机做什么 [[44]](#ch17.xhtml#r357)。 |
| **更新** | 难以更新 [[26]](#ch17.xhtml#r339)。 | 易于更新 [[26]](#ch17.xhtml#r339)。 |

| **控制级别** | 为硬件设备提供底层控制 [[44]](#ch17.xhtml#r357)。 | 控制计算机的应用程序 [[44]](#ch17.xhtml#r357)。 |
| **示例** | 消费电器、电视遥控器、计算机外设和嵌入式系统 [[44]](#ch17.xhtml#r357)。 | 解释器、操作系统、Microsoft Office 应用程序 [[44]](#ch17.xhtml#r357)。 |

组织在招聘区块链应用开发人员时，一个重要的应用开发考量是努力招聘同时具备软件和固件开发经验的应用开发专业人员。这是因为区块链应用开发的某些方面——例如智能合约开发——类似于固件开发。为了进一步解释，正如第 2 章先前所讨论的，一旦智能合约在区块链上构建并激活，就不能像大多数软件应用程序那样，简单地通过性能或安全补丁进行更新。因此，在区块链应用开发生命周期中必须极其小心和勤勉，以帮助确保区块链应用的所有组件都能充分工作。

# 流行的应用开发框架

区块链是一项仍处于起步阶段的技术，提供了巨大的用例潜力。对基于区块链的应用程序的兴趣正在全面增长；因此，需要选择一个满足期望或强制要求的区块链系统[11]。区块链应用框架是一种 GUI（图形用户界面）或 CLI（命令行界面）软件，它能够以较少的编程语言交互，实现区块链应用程序的轻松开发和部署。所有主流的区块链应用框架都包含开发库、网络配置和共识协议。根据原型开发易用性的主观评估，框架可分为许可型或非许可型。组织可以有效地利用以太坊、Hyperledger、R3、Ripple 和 EOS 等多个区块链系统来创建和托管区块链应用程序[40, 42]。

区块链框架提供不同的目的、特性和功能。选择合适的框架主要取决于组织的目标和优先级。选择框架的一些标准包括所需的区块链类型（如公有链或私有链）、框架支持的编程语言、期望的共识方法和智能合约用途[1]。下文将进一步解释几个流行的区块链框架及其优缺点。同时也提醒读者，第 7 章在撰写当时对三个高度流行的区块链框架——即以太坊、Hyperledger 技术和 Corda——进行了细致的讨论。

## 以太坊

以太坊是一个开源的非许可型区块链平台。2013 年，俄罗斯裔加拿大程序员 Vitalik Buterin 提出了以太坊框架。该项目于 2014 年通过众筹获得资金，其第一个版本于 2015 年 7 月上线。以太坊拥有其原生加密货币，称为以太币。如果组织的解决方案需要一个公共平台，以太坊是一个值得考虑的优秀区块链框架。在撰写本文时，以太坊平台支持工作量证明共识算法，并计划在不久的将来将以太坊网络切换为权益证明共识算法。以太坊虚拟机（EVM）是一个去中心化的虚拟机，可以在公共节点的国际网络上运行脚本。以太坊赋予程序员构建和分发下一代分布式应用程序的能力[17]。

## Hyperledger

位于加利福尼亚州旧金山的 Linux 基金会于 2015 年 12 月成立了 Hyperledger 项目。它最初由 30 家公司发起，现已发展到拥有 120 多家赞助实体。Hyperledger 是一个开源项目，致力于为企业级区块链部署创建一套安全的协议、软件和库。Hyperledger 不支持比特币等加密货币，但它确实包含了为工业用途开发各种基于区块链的系统和应用程序所需的基础设施和标准。Hyperledger 框架提供以下架构层和组件[13]：

*   **共识层**：该层负责就区块交易的顺序达成一致，并验证其准确性。
*   **智能合约层**：负责处理交易请求，并仅批准合法交易。
*   **通信层**：该层处理点对点消息传输。
*   **身份管理服务**：这些服务对于维护和验证用户及系统身份，以及在区块链上建立信任至关重要。
*   **应用程序编程接口 (API)**：外部应用程序和客户端可以使用 API 与区块链进行交互。
*   目前，较为广泛使用的 Hyperledger 框架包括 `Sawtooth`、`Iroha`、`Fabric` 和 `Burrows`，详细说明如下[11]。

### Hyperledger Sawtooth

**Hyperledger Sawtooth**：一个由 Intel 赞助的区块链套件，基于经过时间证明 (PoET) 共识算法和模块化架构。对于区块链网络中的每个节点，该算法会生成一个随机等待时间，这意味着每个节点必须按分配的时长“休眠”或保持非活动状态。

### Hyperledger Iroha

**Hyperledger Iroha**：这一风味的 Hyperledger 由多家日本公司合作实现。Iroha 是一个对移动端友好的区块链平台，易于集成到现有的已开发解决方案中。

### Hyperledger Fabric

**Hyperledger Fabric**：这是一个由 IBM 开发的知名 Hyperledger 架构。Fabric 是构建高度可扩展应用程序的绝佳选择，被认为是最常用的 Hyperledger。Fabric 的一些优势包括其高度模块化从而带来的可扩展性、允许用户私下通信的私有通道通信能力，以及包括 Intel 和 IBM 在内的忠诚且支持性社区的支持。Fabric 允许开发人员利用整洁的代码和大量现成的解决方案与资源高效地构建应用程序。

## Corda

全球最大的银行机构 R3 创建了 Corda，这是一个开源区块链技术。Corda 作为一个专门为金融行业需求定制的专用分布式账本运行。它采用私有区块链运行模式，这意味着访问网络内容需要许可。Corda 为数字记录提供增强的隐私和细粒度的访问控制。此外，Corda 还允许企业通过智能合约直接交互，从而大幅减少甚至消除昂贵的交易成本和费用。与以太坊不同，且与 Hyperledger 类似，Corda 没有内置的加密货币或代币。虽然主要为银行和金融服务的潜在用例而构建，但 Corda 现在已被用于包括医疗保健和供应链在内的各种其他行业[42]。

## Ripple

Ripple 是一个开源的点对点框架，在去中心化环境中运行，以适应比特币、欧元、美元等形式的资金转账。Ripple 最初于 2012 年开发，最初命名为 `Open Coin`。Ripple 还提供其自己的加密货币，称为 XRP。Ripple 框架的优势包括快速的支付结算，仅需几分钟而非几天，相比之下某些传统结算系统需要数天。Ripple 协议还会自动为其交易选择最便宜的出价者。此外，由于 Ripple 消耗 XRP 来发送交易，垃圾邮件发送者需要花费大量 XRP 才能批量生成垃圾交易[22]。

## Quorum

作为一个受以太坊启发的区块链框架，Quorum 是一个基于许可的去中心化平台，用于部署去中心化应用 (DApps)。由 JPMorgan 开发，Quorum 为金融领域提供了一个区块链解决方案选择，在保持参与者隐私的同时提供高速度——目前高达近 100 笔交易/秒——和高吞吐量[39]。Quorum 使用三种共识算法：`Raft`、`Istanbul Byzantine Fault Tolerance` 和 `Quorum Chain`。与以太坊共识算法相比，这三种算法更加轻量级，这使得它比以太坊区块链更快[2]。

# 区块链应用的层级架构

区块链平台包含分层的数据共享架构。该架构基于功能概览、设计原则和分层协作。设计原则包括高安全性、高可扩展性、去中心化和高可用性等特性 [[40]](#ch17.xhtml#r353)。

作为软件系统，区块链由两层组成：**应用层**和**实现层**。应用层负责面向用户的组件，而实现层包含协议和代码，基本上是让应用程序“活”起来的一切。区块链中的这两个主要层级可能包含其他次要层级。区块链的第 0 层到第 1 层应包含支持加密货币所需的物理基础设施。另一方面，第 2 层及以上是第二实现层，可能包含闪电网络层，能够以极快的速度（闪电般的速度）处理大量交易 [[5]](#ch17.xhtml#r318)。

区块链技术共有五层，如下所示：

*   **应用层**：该第一层包括 DApps（去中心化应用）、DApp 浏览器、用户界面和应用托管。用户可通过 DApp 浏览器浏览去中心化应用。因此，用户可以看到完全不同的用户界面。该层的应用托管允许用户运行所有去中心化应用。没有此组件，任何 DApps 都无法在互联网上上线。当然，托管协议将完全去中心化。此外，运行这些托管服务器的风险极小。
*   **服务层**：该层位于应用层之后，旨在提供访问用户创建和运行 DApps 层所需的所有资源。该层适配各种治理实现、链下计算、状态通道、支持侧链和数据馈送。
*   **语义层**：该层包含参与要求、虚拟机和共识算法，后者是所有节点就账本细节达成一致的必要程序。参与要求是帮助网络确定谁有资格进入系统、谁没有资格的主要规则。此外，此功能主要用于私有区块链技术。虚拟机为所有网络活动提供安全高效的平台。
*   **网络层**：该层位于语义层之后。它包含可信执行环境（`TEE`），有助于架构解决可扩展性问题。它不仅帮助网络克服这一问题，还提高了其安全性。`TEE` 还有助于将数据存储在主网络之外。网络层还包含 `RLPX`；一种网络套件，可促进两个对等节点之间的数据传输。`RLPX` 提供用户界面以辅助区块链网络内的通信。区块分发网络是一种网络类型，如果用户请求，它将发送网页内容或页面。事实上，这在典型的互联网架构中也可见一斑。网络层允许用户遵循 `Roll Your Own Mechanism` 协议，可在需要时随时定制，使协议更具适应性。
*   **基础设施层**：这是最后一层，包含代币等特性，有助于以更安全的方式维护生态系统和网络的去中心化存储 [[1]](#ch17.xhtml#r314)。

# 区块链应用工具

区块链工具的主要目的是在创建区块链应用的各个阶段，相对轻松高效地解决出现的众多需求。此类工具还有助于提高对该技术的认知和实践经验。精通以下区块链工具且拥有深厚知识和经验的区块链专业人士目前在区块链就业市场上需求量很大 [[25]](#ch17.xhtml#r338)。以下是一些主要区块链开发工具和技术的简要说明：

*   **Solidity**：这是一种基于以太坊的编程语言，由英国软件开发者 `Gavin Wood` 于 2014 年提出。`Solidity` 是一种用于创建智能合约的高级面向对象语言。开发 `Solidity` 的主要目的是需要创建一种易于学习的编程语言。因此，`Solidity` 基于变量、字符串操作、类、算术运算和函数等通用编程概念。此外，它还借鉴了 `C++`、`Python`、`PowerShell` 和 `JavaScript` 等高级编程语言。`Solidity` 还拥有一个编译器，可将高级代码分解为简单指令 [[6]](#ch17.xhtml#r319)。
*   **Truffle**：创建此工具的目的是为开发和测试区块链智能合约提供一个精简高效的平台。它使用 `Ethereum Virtual Machine` 创建一个高度有用的开发环境和测试框架。`Truffle` 套件由 `Truffle`、`Ganache` 和 `Drizzle` 组成 [[37]](#ch17.xhtml#r350)。`Truffle` 还附带大量自定义部署库，有助于创建新的智能合约和解决区块链开发问题 [[25]](#ch17.xhtml#r338)。`Truffle` 也非常适合开发复杂的以太坊去中心化应用 [[38]](#ch17.xhtml#r351)。自动合约检查是 `Truffle` 作为区块链工具的另一个关键功能。对于自动合约检查，`Truffle` 可能会使用 `Mocha` 和 `Chai`。此外，`Truffle` 将协助智能合约的创建、链接、编译和部署。最重要的是，`Truffle` 包含一个可定制的构建流水线，确保遵循特定的开发方法 [[25]](#ch17.xhtml#r338)。

## Ganache

**Ganache** 是 Truffle 套件中的区块链工具，允许开发者构建自己的私有以太坊网络，用于检查去中心化应用、检查状态和执行命令，同时保持对链活动的完全控制 [25]。使用该工具，用户可以通过图形界面和 CLI 模式与智能合约交互 [46]。JavaScript 用于以太坊区块链的实现 [3]。Ganache 可从表 9.3 提供的链接下载。网站会自动检测机器上安装的操作系统，并将用户重定向到相应的二进制安装包 [4]。由于高级挖矿控制和内置区块浏览器，Ganache 是开发者常用的区块链工具。在创建智能合约期间，区块链开发者也使用 Ganache 进行测试 [25]。使用该平台的主要优势在于，它允许用户监控挖矿速度和 Gas 成本，以测试各种智能合约场景 [38]。

## ethers.js

**ethers.js** 库旨在成为以太坊区块链及其生态系统的全面且轻量级接口。这是一个客户端 GUI，允许用户构建钱包、与智能合约通信等 [38]。该工具体积很小（压缩约 88 KB；未压缩 284 KB），并附带完整的 TypeScript 定义文件和完整的 TypeScript 源代码。通过使用 ethers.js，可以导入和导出 JSON 钱包（`Geth`、`Parity` 和 `Crowdsale`）、BIP 39 助记词（12 词备份短语）和 HD 钱包（英语、意大利语、日语、韩语、中文等）。使用 `JSON-RPC`、`INFURA`、`Etherscan`、`Alchemy`、`Cloudflare` 或 `MetaMask` 连接到 `Ethereumxdx` 节点。ethers.js 执行保护客户端私钥等功能。它提供以太坊所需的完整功能，并包含广泛的用户文档 [16]。

## MetaMask

**MetaMask** 是一款网页浏览器插件，允许用户账户管理、区块链连接和区块链应用。在账户管理方面，MetaMask 帮助用户存储其公钥和私钥。对于区块链连接，MetaMask 用于连接到其他以太坊节点。MetaMask 的主要优势在于，用户无需成为以太坊节点即可与智能合约交互。这意味着用户无需在本地系统下载完整的区块链数据。对于区块链应用，MetaMask 注入了 `web3`（JavaScript API），帮助用户处理 JSON RPC 文本（XML 格式）。对于每笔交易，MetaMask 都会显示交易内容供用户确认 [24]。

## Infura
