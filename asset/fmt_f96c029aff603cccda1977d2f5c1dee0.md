
![image](img/PBPC0390-01-f02.jpg)

**图 1.2** 待机状态下带有漏电路径的 6T SRAM 单元结构。`BLs` 被预充至高电平，假设 `Q` 处存储的数据为“1”。

`SRAM` 单元有三种操作状态：写入、读取和待机。对于写入操作，需将要写入的值以互补方式同时施加到两条 `BLs`（即 `BL` 和 `BLB`）上。假设我们希望向单元写入“0”，即 `Q` 为“0”且 `QB` 为“1”，则 `BL` 被拉低而 `BLB` 拉高。一旦通过将 `WL` 置“1”导通 `M5` 和 `M6`，`BL` 驱动器将覆盖先前存储的值。为了容易地覆盖自强化触发器中的先前状态，`BL` 驱动器的设计驱动能力需强于触发器中的晶体管。

对于读取操作，在读取周期开始前，两条 `BLs` 均被预充至高电平，字线（`WL`）的导通标志着读取操作的开始。由于 `Q` 和 `QB` 处电压相反，其中一条 `BL` 将被单元拉低，随后 `BL` 感测放大器检测到该 `BL` 的放电。在电压模式感测方案中，`BL` 电压差 `ΔVBL`（`Q` 减 `QB`）的符号决定存储位的值。几十毫伏量级的 `ΔVBL` 足以高效区分哪条 `BL` 正在放电。例如，假设存储位在 `Q` 处为“1”，在 `QB` 处为“0”，一旦 `WL` 有效，`QB` 将向“0”放电；当获得几十毫伏的正 `ΔVBL` 时，基于锁存器的感测放大器将通过正反馈放大该微小电压差，最终输出逻辑“1”作为结果。

当 `WL` 接地，导致两个访问晶体管关闭时，单元处于待机状态。在待机状态下，两个交叉耦合的反相器因正反馈而相互增强，只要供电，数值即可保持。关于 `SRAM` 在待机状态下的一个显著问题是严重的亚阈值漏电。亚阈值漏电是指当栅源电压小于阈值电压时晶体管的漏源电流。亚阈值电流随阈值电压呈指数级变化，这导致在深亚微米工艺节点下产生巨大的亚阈值电流。图 1.2 展示了一个 `SRAM` 单元中的三条漏电路径，假设 `Q` 处存储位为“1”。注意 `BL` 和 `BLB` 始终预充至 `VDD` 以便于未来的读取操作。无论存储值如何，始终会有三个晶体管消耗漏电功耗。

与其他存储技术相比，`SRAM` 能够提供最快的访问速度，但这一优势是以密度和功耗为代价的权衡结果。由于一个 `SRAM` 单元需要六个晶体管的硅面积，`SRAM` 密度非常有限，因此比其他存储技术更昂贵。此外，由于待机状态下的漏电问题，其功耗很大。因此，`SRAM` 最适用于高性能为主要考量且容量要求不大的场景，即处理器的缓存。

# DRAM 理念与 Flash NVM

## DRAM 理念

DRAM 背后的理念是简单性。与 SRAM 一个单元由六个晶体管组成不同，每个 DRAM 单元仅由一个电容和一个访问晶体管组成。数据“0”或“1”由电容是完全充电还是放电来表示。然而，电容上的电荷会逐渐泄漏，经过一段时间后，电容上的电压变得太低，以至于感测放大器无法区分“1”和“0”。因此，与 SRAM 只要供电数据就能保持不同，DRAM 的保持时间是有限的，所有 DRAM 单元都需要定期读出并写回以确保数据完整性。通常，单元每 32 或 64 ms 刷新一次。这个过程称为*刷新*，这也是动态 RAM 名称的由来。图 1.3 显示了这种 1T1C 结构 DRAM 单元的电路图。

![image](img/PBPC0390-01-f03.jpg)

图 1.3 1T1C DRAM 单元结构的电路图

要写入 DRAM 单元，首先根据要写入的值将 `BL` 设为高或低。在 `WL` 置高打开访问晶体管后，选中单元中的电容被充电为“1”或放电为“0”。由于访问是通过 NMOS 晶体管进行的，写入“1”时存在 `Vth` 压降。为了防止这种 `Vth` 压降并维持较长的刷新周期，`WL` 的驱动电压通常被提升至 `Vpp`。

要读取 DRAM 单元，`BL` 首先预充电至 `Vdd/2`，然后使能 `WL`。由于电荷共享，`BL` 电压将根据电容之前充电的电压（即 `Vdd` 或 `0`）略微降低或升高。如果之前已充电，电荷共享将略微提升 `BL` 电压；否则，一些电荷将从 `BL` 分布到单元电容。在这两种情况下，存储电容的电压在读操作后都会改变；因此，读操作被称为破坏性的，需要即时写回。`BL` 上的微小电压变化可通过以下公式计算：

```
ΔV = ± (Cs / (Cs + Cb)) * (Vdd / 2)
```

`ΔV` 的符号取决于存储电容的状态。在现代 DRAM 器件中，存储电容的电容远小于 `BL` 的电容。通常，存储电容的电容是连接到数百或数千个其他单元的长 `BL` 电容的十分之一。相对电容值造成了这样一种情况：当存储电容中包含的少量电荷被放置在 `BL` 上时，`BL` 上产生的电压很小，难以从绝对意义上测量。在 DRAM 器件中，电压感测问题通过使用差分感测放大器来解决，该放大器将 `BL` 的电压与参考电压进行比较。

反过来，差分感测放大器的使用对 DRAM 阵列结构提出了一些要求。特别是，不再使用单个 `BL`，而是需要使用一对 `BL` 来感测任意 DRAM 单元中包含的电压值。此外，为了确保这对 `BL` 上的电压和电容值紧密匹配，`BL` 在路径长度和连接的单元数量方面必须紧密匹配。上述要求导致了两种截然不同的阵列结构：开放 `BL` 结构和折叠 `BL` 结构。

## Flash NVM

Flash 存储器是当今应用最广泛的 NVM 技术。这种主流存储器中的关键器件是浮栅（FG）晶体管。图 1.4 显示了 FG 晶体管的横截面图。与金属氧化物半导体场效应晶体管（MOSFET）不同，在控制栅和沟道之间增加了一个额外的浮栅。浮栅被氧化层隔离，能够捕获电荷并保持数年。因此，FG 晶体管基于电子是否被捕获来编码数据，并能在无电源的情况下保持数据。这就是“非易失性”一词的由来。

![image](img/PBPC0390-01-f04.jpg)

图 1.4 FG 晶体管的横截面

读操作的原理可描述如下。当浮栅中没有捕获电荷时，FG 晶体管的阈值电压为 `Vt0`；当捕获负电荷时，它们会吸引控制栅的正电荷；因此，需要更高的控制栅电压才能导通沟道，从而产生更高的阈值电压 `Vt1`。通过施加介于 `Vt0` 和 `Vt1` 之间的中间控制栅电压并测量电流，可以得知器件的状态。

FG 晶体管的写操作涉及将电子注入或拉出穿过氧化层势垒。有两种方法可以实现这一点：量子隧穿或热电子注入。在量子隧穿场景中，在控制栅上施加高电压，浮栅和沟道之间将发生量子隧穿，电子可以穿过氧化层势垒。对于热电子注入场景，电子在沟道中的高电场下被加速，直到其能量足以穿透氧化层。请注意，高能电子会破坏氧化层晶格，这种损伤会累积并导致有限的写入周期，通常约为 `10⁵` 次。

Flash 存储器有两种常见布局，如图 1.5 所示，串联 FG 晶体管的 NAND Flash 存储器和并联 FG 晶体管的 NOR Flash 存储器。NAND 和 NOR 这两个名称源于它们串联或并联的连接方式类似于 NAND 门或 NOR 门。NAND 布局相对于 NOR 布局具有密度优势，因为每行只有一个接地连接，因此广泛用于外部存储。NOR 布局延迟较低，因此广泛用于需要高性能的嵌入式系统。图 1.5 还展示了如何实现 NAND 和 NOR Flash 存储器的读取。不同施加电压幅度之间的关系如下所示：

```
Vread < Vpass < Vpgm < Verase
```

### 1.1.2.2 纳米级局限

随着技术向纳米级缩放，传统存储器架构面临一些挑战和局限。这些挑战由物理规则引起，并从两个角度进行总结。一方面，由于工艺变异导致晶体管可能存在失配问题，从而引起功能失效。另一方面，SRAM 或 DRAM 单元中的正反馈导致热失控失效 [28]。因此，NVM 被视为随技术缩放进行数据存储的潜在解决方案。

## 1.1.3 非易失性 IMC 架构

在传统计算架构中，所有数据都存储在存储器中。它与通用处理器分离，因此需要 I/O 连接。结果，在数据处理期间，所有数据都需要读出到外部处理器，之后再写回。然而，在面向数据的应用（如 ML 加速）中，这种架构会导致严重的 I/O 拥塞，从而极大地降低整体性能 [27,29–32]。此外，由于所有数据都需要被保持，即使当前不需要使用，也会消耗大量静态功耗 [26,28,33–39]。

理论上，通过增加更多 I/O 引脚或以更高频率运行它们，可以克服带宽问题。但实际上，I/O 频率受限于信号传播延迟和信号完整性问题，I/O 数量受限于封装技术，因此带宽几乎已达饱和。

除了提高内存带宽，减少处理器与内存之间通信的数据量是提升性能的另一种可行方案。传统上，处理器仅从主存读取原始数据。如果内存能在发送数据前执行某些操作，I/O 通信需求可显著降低 [40–42]。例如，若需对八个数求和，传统方式需将所有八个值加载到处理器中。然而，若两数相加作为存内逻辑操作执行，可在内存内预处理加法，仅需读出四个数即可。

要执行 IMC，需在内存内实现逻辑操作以便进行预处理。这种架构称为存内逻辑架构。理想存内逻辑架构的需求总结见 Figure 1.6。一个巨大的 NVM 阵列通过高带宽、节能的可重构 I/O 与数千个小型加速器核心相连。同时考虑到漏电流降低，与 NVM 相关的存内逻辑架构见文献 [43–47]。Figure 1.7 展示了一种通过构建 CMOS 电路与存储器件相结合的存内逻辑架构。示例展示了一个包含 `sum` 和 `carry` 逻辑的全加器。然而，这种单元级存内架构存在两大问题。首先，基于 CMOS 的逻辑构建在内存中，难以重构。其次，它只能执行低复杂度逻辑操作。示例中，一个简单的 1 位加器需要 ![image](img/ch01_stripin_si34.gif) 个晶体管，内存复杂度因此大幅增加。

# 1.2 Challenges and contributions

未来网络物理系统需要高效的实时数据分析 [48–52]，应用于机器人、脑机接口及自动驾驶汽车。文献 [53,54] 近期工作显示，ML 在实时数据分析中具有巨大潜力，训练时间显著缩短。

基于硬件的加速器目前用于辅助 ML 应用。在传统硬件加速器中，内存与逻辑间存在大量数据迁移 [55,56]，导致带宽墙和功耗墙。因此，对于数据导向计算，将逻辑加速器尽可能靠近内存放置，有助于缓解 I/O 通信开销 [57]。文献 [43] 提出了单元级 IMC，在存储阵列中嵌入简单逻辑电路。然而，内存中配备的相应存内逻辑无法实现复杂逻辑功能，且利用效率低，因为逻辑无法在存储单元间共享。此外，基于 CMOS 技术存在显著的内存漏电功耗。

新兴 ReRAM [58–64] 显示出成为数据密集型应用解决方案的巨大潜力。除了因非易失性带来的最小化漏电功耗，交叉阵列结构的 ReRAM 已被开发作为计算元件 [59,65]。因此，存储和逻辑组件均可按节能、节面积方式实现。更重要的是，它能提供真正的存内逻辑-内存集成架构，无需使用 I/O。然而，之前基于 ReRAM 交叉阵列的计算主要基于多电平值的模拟方式 [66] 或尖峰时间依赖可塑性（STDP）[67]。虽提升了计算容量，但纳米尺度 ReRAM 交叉阵列的严重不均匀性限制了其在精确、可重复数据分析中的广泛应用。此外，文献 [67] 提到额外的 AD 转换和 I/O 存在显著功耗。除了 ReRAM 交叉阵列，耦合 ReRAM 振荡器可用于模拟计算。通过将定点值映射到电压，耦合 ReRAM 振荡器可执行 L2 范数计算。因直接模拟计算，可实现显著加速和能效提升。

尽管非易失性 IMC 似乎是面向未来数据导向存储和计算系统的有前景解决方案，但近期新兴 ReRAM 因以下未解决的挑战仍处于起步阶段：

*   **电路层面**：尽管存在一些模拟器可执行混合 NVM-CMOS 电路仿真 [63,64]，基于 ReRAM 的计算操作尚未完全开发。缺乏 ReRAM 上详细的 IMC 实现，难以在基于 ReRAM 的非易失性存内加速器上运行真实应用。

*   **架构层面**：需探索存内架构的详细实现。传统内存控制器不适用于基于 ReRAM 的 IMC 系统。基于 CMOS 的控制总线及其通信协议需为这种新型架构重新定义。

*   **系统层面**：需找出哪些 ML 算法可映射到存内加速器。针对不同操作或算法，需设计不同加速器以实现更高并行性和更好能效。

本书阐述了探索基于 ReRAM 的逻辑运算与 NVM 存内计算架构的发展思路，以及将各类 ML 算法映射到此类架构上的具体细节。针对基于 ReRAM 的 IMC 实现，目标是开发 ReRAM 上不同运算的详细映射。我们提出了两种用于运算加速的基于 ReRAM 的结构：`ReRAM-crossbar`和`ReRAM oscillator network`。特别是，本书总结了以下进展：

*   首先，`NVM-SPICE`用于电路级仿真。介绍了漂移型 ReRAM 的模型及其仿真结果。此外，还展示了成形、置位（SET）和复位（RESET）过程的测量结果。对于扩散型 ReRAM，则采用子电路模型进行仿真。

*   其次，我们引入了一种用于矩阵-向量乘法的二值`ReRAM-crossbar`。由于 ReRAM 器件的非均匀性，所提出的二值`ReRAM-crossbar`相比传统模拟方式的`ReRAM-crossbar`能实现更精确的计算。此外，还讨论了三种交叉阵列结构，包括无源阵列、一晶体管一 ReRAM（`1T1R`）和一选择器一 ReRAM（`1S1R`）。

*   第三，我们描述了一种基于 ReRAM 的耦合振荡器网络，用于 L2-范数计算。基于扩散型 ReRAM 的开-关切换或漂移型 ReRAM 的成形过程，可以构建一个简单的振荡器。当基本振荡器形成网络时，根据拟合的仿真结果，它可以执行 L2-范数计算。

对于存内加速器，目标是确定架构设计。对于仅以 ReRAM 作为计算引擎的架构，我们详细设计了辅助 CMOS 逻辑，并定义了处理器与存储器之间的通信协议。对于同时以 ReRAM 和 CMOS 作为计算引擎的架构，我们开发了 3D CMOS-ReRAM 架构，通过引入以下两个主题，可实现更高的吞吐率和并行度：

*   首先，描述了一种分布式存内计算架构（`XIMA`）。除了传统的存储和加载指令外，我们还定义了两条新指令：`start`和`wait`。此外，所有逻辑块和数据块均成对构建，以最大程度减少数据处理通信延迟。指令队列和解码器等 CMOS 逻辑也已设计完成。

*   其次，展示了 3D CMOS-ReRAM 架构的设计空间探索。对于单层 3D 架构，ReRAM 器件通过过孔连接顶层字线（WLs）和底层位线（BLs）。所有其他 CMOS 逻辑均实现于底层。对于多层 3D 架构，我们分别使用两个 ReRAM 层作为数据缓冲和逻辑实现。此外，利用`TSVs`连接不同层。

对于基于 ReRAM 架构的数据分析映射，目标是专注于针对特定应用的加速器详细设计。此外，算法需要经过优化，以便所有运算均可完全映射到加速器上。我们在分布式存内架构（`XIMA`）和 3D CMOS-ReRAM 架构上，通过多个 ML 算法的案例研究，展示了带宽和能效的显著提升。

*   首先，针对`XIMA`，我们加速了三种 ML 算法。单层前馈神经网络（`SLFN`）的学习和推理过程已被优化并部分映射到无源二值`ReRAM-crossbar`上。此外，我们将二值卷积神经网络（`BCNN`）分别映射到无源阵列和`1S1R`阵列上，并采用了不同的映射方案。而且，基于 L2-范数梯度的学习和推理也在同时包含交叉阵列和耦合振荡器的 ReRAM 网络上实现。

*   其次，针对 3D CMOS-ReRAM 架构，我们也映射了优化后的`SLFN`算法。学习和推理阶段的所有运算均已实现，从而实现在线学习。此外，张量化神经网络（`TNN`）分别映射到单层和多层加速器上，并采用不同的映射方案。

对于映射到`XIMA`和 3D CMOS-ReRAM 加速器上的每一种 ML 算法，我们均在器件、架构和系统三个层面评估其性能。所有实现均展现出更高的吞吐率、带宽和并行度，且具有更好的能效。
