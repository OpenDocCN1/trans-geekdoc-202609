## 符号术语

+ `$k_{0x}, k_{0y}$` 线性弹簧
+ `$K_x, K_y$` 旋转弹簧
+ `$u_v, v_w$` 中间侧线性位移分量
+ `$\Phi$` 绕y轴的旋转
+ `$\Phi_y$` 结构的厚度
+ `$L_1$` 四边形底边长度
+ `$L_2$` 四边形右边长度
+ `$L_3$` 四边形顶边长度
+ `$L_4$` 四边形左边长度
+ `$\alpha_1$` `$L_4$`与`$L_1$`之间的夹角
+ `$\alpha_2$` `$L_1$`与`$L_2$`之间的夹角
+ `$\alpha_3$` `$L_2$`与`$L_3$`之间的夹角
+ `$\alpha_4$` `$L_3$`与`$L_4$`之间的夹角
+ `$a$` 椭圆最大直径
+ `$b$` 椭圆最小直径
