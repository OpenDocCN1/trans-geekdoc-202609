## 8.3 变分自编码器

### 8.3.1 什么是变分自编码器？

变分自编码器（VAE）是由 Kingma & Welling 等人（2013）和 Rezende, Mohamed & Wierstr 等人（2014）提出的一种生成模型方法。

VAE 是对传统自编码器（autoencoder, AE）的一种增强。图 8-12 展示了 VAE 的工作流程：

图 8-12 变分自编码器。编码器输出概率分布的参数。根据概率分布采样得到的隐向量被用作解码器的输入。解码器输出与编码器输入数据形状相同的数据。两者的误差作为损失函数值。

与 AE 将数据（如图像）映射到潜在空间中的固定长度向量不同，VAE 将数据映射到概率分布（实际上是映射到概率分布的参数），例如将图像 `x` 映射到高斯分布的参数，如输出高斯分布的均值参数 `μ` 和方差参数 `σ²`。

如果从该概率分布中随机采样一个隐向量数据点，根据高斯分布的特性，该数据点应集中在该 `μ` 附近，例如采样数据点 `z = μ + σ² * ε`，其中 `ϵ` 是一个极小的数。每个这样的采样点 `z` 都会被解码器映射为一幅图像 `x'`，因为这些 `z` 围绕在 `μ` 周围，所以这些解码出的 `x'` 也是与 `x` 非常相似的图像。也就是说，连续的隐向量 `z` 生成连续变化的数据 `x'`，这使得数据在隐空间中更加结构化，从而可以对隐向量进行有意义的编辑，并根据需要改变和控制数据。

编码器和解码器函数由神经网络的参数 `ϕ`、`θ` 决定，编码器神经网络的输出是隐向量 `z` 的概率密度参数（假设为高斯分布参数 `μ`、`σ²`），即对于每个输入 `x`，编码器输出的 `qϕ` 是一个概率分布的参数，这意味着 `x` 映射到不同隐变量 `z` 的似然大小（概率大小）。解码器函数 `pθ` 表示隐变量 `z` 被映射为与输入 `x` 形状相同的输出，输出也可以是概率，例如 `x` 是 28 × 28 大小的手写数字图像，其中每个像素的值为 1 或 0，那么解码器的输出 `pθ` 也是一个 28 × 28 的张量，表示每个位置对应输入 `x` 的值（如 1 或 0）的概率。

### 8.3.2 损失函数

VAE 的损失包括：重构损失和正则项。重构损失描述输出与输入的近似程度，可以使用逻辑回归的对数损失或平方差损失。正则项使潜在变量 `zz` 的分布尽可能接近标准正态分布。

将一个 `xx` 输入 VAE 的编解码流水线，完美的重构输出仍为 `xx`，实际输出为尽可能接近 `xx` 的 `xx'`。为了尽可能重构输入 `xx`，输出为 `xx` 的概率应最大，即 `pθ` 应最大。如果 VAE 中解码器的输出不是数据本身，而是不同数据 `xx` 的概率 `pθ`，那么对应最大化该概率的重构损失是最小化其负最大似然的对数 `−log(pθ)`，加上一个正则项，对于一个样本 `xx^((i))`，其损失 `li` 可表示为：

```
ℒi = −𝔼zz ∼ q[ϕ))] log p[θ)|zz)] + 𝕂𝕃(qϕ)) ∥ p(zz))
```

对于固定的 `xx^((i))`，它可被映射为一个概率分布 `qϕ))` 随机变量 `zz`，对于每个 `zz`，其输出为 `xx^((i))` 的概率为 `pθ)|zz)`，期望对数概率 `𝔼zz ∼ q[ϕ))] log p[θ)|zz)]` 即重构输出为 `xx^((i))` 的期望对数概率，最大化重构 `xx^((i))` 的概率即最大化期望对数概率，即最小化该负期望对数概率 `−𝔼zz ∼ q[ϕ))] log p[θ)|zz)]`。

损失函数的第二项是正则项，使用 Kullback-Leibler 散度表示 `zz` 的分布 `qϕ` 与标准正态分布 `p(zz) = N(0, 1)` 之间的距离，以描述它们的相似性。将此项作为正则项（惩罚项）促使 `zz` 的概率分布尽可能接近标准正态分布，就像限制神经网络的权重参数尽可能接近 0 一样。一方面，任何概率分布总可以用多元正态分布来近似，另一方面，任何正态分布也可以通过变换转化为标准正态分布。因此，`zz` 可以被视为标准正态分布。

对于 m 个样本 `xx^((i))`，总损失函数为各样本损失之和，即 `∑_{i=1}^{m} ℒ_i`。

从高斯分布 `𝒩0` 到高斯分布 `𝒩1`（它们的协方差矩阵 `Σ[0]` 和 `Σ[1]` 为非奇异矩阵）的 Kullback-Leibler 散度为：

```
D_KL(N_0 ∥ N_1) = 1/2 { tr(Σ_1^{-1} Σ_0) + (μ_1 - μ_0)^T Σ_1^{-1} (μ_1 - μ_0) - k + ln(|Σ_1| / |Σ_0|) }
```

其中 k 为向量空间的维度。KL 散度描述了两个分布的相似程度。

假设变分自编码器隐变量 `zz` 的高斯分布的均值向量和协方差矩阵为 `μ(z)` 和 `Σ(z)`，则该分布与标准正态分布的 KL 散度 `D[KL][N(μ(z), Σ(z)) ∥ N(0, 1)]` 可表示为：

```
D_KL[ N(μ(z), Σ(z)) ∥ N(0,1) ] = 1/2 ( tr(Σ(z)) + μ(z)^T μ(z) - k - log det(Σ(z)) )
```

上述 k 为高斯分布的维度。

`tr(Σ(z))` 为协方差矩阵 `Σ(z)` 的迹，即 `Σ(z)` 对角线元素之和。`det(Σ(z))` 为其行列式的值，任何多元高斯分布总可以通过一元线性变换转化为协方差矩阵为对角矩阵的高斯分布，即 `Σ(z)` 可视为对角矩阵。因此上述公式可简化为：

```
D_KL[ N(μ(z), Σ(z)) ∥ N(0,1) ] = 1/2 ( ∑_j σ_j² + ∑_j μ_j² - ∑_j 1 - log ∏_j σ_j² )
                                = 1/2 ( ∑_j σ_j² + ∑_j μ_j² - ∑_j 1 - ∑_j log σ_j² )
                                = 1/2 ∑_j ( σ_j² + μ_j² - 1 - log σ_j² )
                                = - 1/2 ∑_{j=1}^k (1 + log(σ_j²) - (μ_j)² - (σ_j)²)
```

其中，`σ[j]²` 为对角矩阵 `Σ(z)` 的第 j 个对角元素。在实践中，使用 `log σ[j]²` 代替 `σ[j]²` 在数值计算上更稳定，因为对数 `log` 比指数 `exp` 更稳定且不易溢出。因此，编码器实际输出的不是方差本身 `σ[j]²`，而是方差的对数，即 `log σ[j]²`。

### 8.3.3 参数重采样

一个样本 `xx^((i))` 通过编码器生成一个概率分布，实际输出为该概率分布的均值 `μ` 和 `log σ²`，如何从该多元高斯分布中获得一个隐变量 `zz`？因为只有将隐变量 `zz` 输入解码器，才能获得解码器的一个输出。这需要对该高斯分布进行采样以得到一个采样值 `zz`，然后将其送入解码器。然而，对概率分布的采样操作不可导（无法求导）。为此，论文中使用了“**重参数化技巧**”，将一般高斯分布 `zz ∼ N(μ, Σ)` 的采样转化为标准正态分布 `u ∼ N(0, 1)` 的采样，因为 `zz` 和 `u` 之间存在简单的线性变换：

```
z = μ + Σ^{1/2} u
```

根据该变换，只要对标准正态分布 `u ∼ N(0, 1)` 进行采样并获得一个采样值 `ϵ`，即可得到一般正态分布 `z ∼ N(μ, Σ)` 的采样：

```
z = μ + Σ^{1/2} ϵ = μ + σ ϵ = μ + (e^{1/2 log σ²}) ϵ
```

对标准正态分布 `N(0, 1)` 的随机采样使得随机采样操作不再依赖于 `μ` 和 `log σ²`，因此不需要关于它们的导数，即 `ϵ` 不依赖于 `μ` 和 `log σ²`，无需求其关于它们的梯度。

### 8.3.4 反向推导

反向推导包括重构损失关于模型参数的求导和正则项关于编码器参数的求导。首先，重构损失（如二分类交叉熵损失）的求导过程与一般神经网络相同。最终可获得重构损失关于采样 `z` 的梯度，设为 `dz`。根据上述采样过程，`μ` 的梯度 `du` 与 `dz` 相同，`log σ²` 用字母 `E` 表示，则重构损失关于 `log σ²` 的梯度 `dE = dz × ϵ × (e^{1/2 E}) 1/2`。已知 `du`、`dE`，即可对编码器的模型参数进行反向推导。该过程也与常规神经网络反向推导相同。

正则项，即 KL 损失，可用向量形式表示：

```
- 1/2 np.sum(1 + E - (μ)² - e^E)
```

其关于 `μ`、`E` 的梯度 `du`、`dE` 为：

```
du = μ
dE = - 1/2 (1 - e^E)
```

VAE 的编码器和解码器是两个神经网络：

```python

```

其中 `nz` 表示高斯分布的空间维度，例如 `nz=2` 表示二维多元高斯分布。

VAE 模型由编码器和解码器组成。下面的 `VAE` 类包含一个编码器和一个解码器。其方法 `forward()` 表示输入 `x` 通过编码器生成输出 `μ`（即 mu）和 log `σ`²（即 logvar）。然后通过参数重参数化采样得到采样的 `z`(sample_z)，再通过解码器得到输出 out。方法 `backward()` 使用参数指定的损失函数首先计算输入 `x` 和输出 `out` 之间的重构损失（即 `loss_fn(out, x)`）。根据该损失关于 out 的梯度 loss_grad，调用解码器的 `backward()` 计算重构损失关于解码器模型参数的梯度以及关于重采样 `z` 的梯度 dz。根据 dz，可以计算关于编码器输出的梯度 du 和 dE，即得到重构损失关于编码器输出的梯度向量 duE，加上 KL 损失关于 u 和 E 的梯度，调用编码器的 `backward()` 可以计算重构损失和 KL 损失关于编码器参数的梯度。`train_VAE_epoch()` 方法遍历数据集 dataset 进行一轮训练。
