#### 页面枚举/应用程序枚举

一旦你确定主机上运行着 Web 服务器，下一步就是查看 Web 应用程序并开始进行页面枚举（web page enumeration），通常称为应用程序枚举（web application enumeration）。你可以通过多种方式映射 Web 应用程序的攻击面。强大的`nmap`工具实际上有一个`NSE`脚本可用于破解应用程序的目录和文件路径。通过常用 Web 应用程序的文件和目录列表，它可以探测服务器中的每一项。根据服务器的响应，它可以判断这些路径是否存在。这对于识别诸如`Apache`或`Tomcat`管理页面等遗留在 Web 服务器上的可能被利用的路径非常有用。`http-enum` `NSE`脚本的语法如下：

```
nmap -sV --script=http-enum <target>
```
