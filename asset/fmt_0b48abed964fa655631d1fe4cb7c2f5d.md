
## 7. 不要对本质连续的自变量进行分类。
由于某些研究人员更习惯使用 `t` 检验和带回归的 `ANOVA`，我们看到使用中位数分割法（即认为中位数以下的所有值归为一类，中位数以上的所有值归为另一类）将本质上的预测变量转换为二分类变量。这种做法丢弃了信息并以任意的方式对观测值分类。例如，最小值和略低于中位数的值被放在同一类别中，尽管它们可能非常不同；但略高于中位数的值却被放在不同的类别中，尽管它们可能很相似。二分类化倾向于降低统计功效（参见 `Irwin & McClelland, 2001`），如果预测变量之间相关，还会产生虚假的显著效应（参见 `Maxwell & Delaney, 1993`）。在这种类错误最恶劣的版本中，研究人员从观察性研究的数据开始，对几个本质上连续且相关的变量进行分类，使用这些变量作为因子进行多因素 `ANOVA` 分析，然后像他们过过实验一样讨论结果。这种方法是不可接受的，因为它假装了连续变量是定类变量，且假装了相关变量是独立的。更多批评意见可以在 `Fitzsimmons (2008)` 和 `Pedhazur (1997)` 中找到。

## 8. 小心合并来自不同子组的数据。
如果我们在分析来自不同子组的数据时，而没有在模型中明确指出这一点，那么与组间差异相关的方差将贡献于误差项，并导致负偏的检验。此外，合并数据的统计结果可能与组成组的数据集结果不匹配。我们在第 17 章中指出，对于合并数据集，相关系数和回归系数可能是正的，尽管这两个统计量在每个组成数据集中都是负的。在 `ANOVA` 中，一个常见的错误是在实验设计中包含了因子（例如，平衡变量），但在统计分析中忽略了它们。

## 9. 注意假设。
许多统计检验的有效性取决于对总体的所出的假设。如果违反了这些假设，这些检验的结果可能与其名义值有很大差异。我们已经介绍了检查可能假设的程序，并讨论了违反这些假设的后果。我们应该利用统计软件的功能来检查结果，并查看峰度和偏度等汇总性指标。即使第一类错误率没有被严重扭曲，当数据不符合分析方法下的假设时，功效可能会丢失。在随后的章节中，我们讨论了替代程序，包括数据转换、非参数检验以及补偿方差或对其他影响抵抗抵抗检验。

## 26.3 结果解释

## 10. 正确解释 p 值。
记住，统计检验的 `p` 值是条件概率 `$p(data|H_0\text{ true})$`。如果 `$p = .01$`，这意味着如果零假设为真，获得与当前样本中获得的数据至少不符合零假设的概率为 `.01`。这并不意味着零假设为真的概率是 `.01`。相反的条件概率 `$p(H_0\text{ true})$` 等同于 `$p(data|H_0\text{ true})$`。

## 11. 正确解释置信区间。
置信区间经常被误解。如果研究人员计算出总体均值的置信区间从例如 5 延伸到 10，这并不意味着总体均值有 95% 的概率落在 5 到 10 之间。这并不意味着 `$p(data|H_0\text{ true})$` 是 `.95`。相反的条件概率 `$p(H_0\text{ true})$` 等同于 `$p(data|H_0\text{ true})$`。

即使第一类错误率没有被严重扭曲，当数据不符合分析方法下的假设时，功效可能会丢失。在随后的章节中，我们讨论了替代程序，包括数据转换、非参数检验以及补偿方差或对其他影响抵抗的检验。

## 12. 记住存在两种检验错误。
第一类错误的概率是 `$\alpha = p(\text{reject } H_0|H_0\text{ true})$`；第二类错误的概率是 `$\beta = p(\text{fail to reject } H_0|H_0\text{ false})$`。当我们设置 `$\alpha$` 时，`$\beta$` 会变大。我们必须在权衡时注意到这一点。

## 13. 发现显著结果并不意味着零假设为假。
假设零假设为真，获得与当前样本中获得的数据至少不符合零假设的概率为 `.01`。我们不能据此假设零假设为真，我们缺乏拒绝它的足够证据。

## 14. 发现显著结果并不意味着零假设为假。
偶然地，我们可能采样到一组相对于零假设的数据。为了降低第一类错误的概率，我们可以设置较小的 `$\alpha$` 并运行功效良好的检验。我们应该运行功效良好的重复实验，并对我们的发现保持谦虚：显著结果是对概率的陈述，而不是对真实的宣告。

## 15. 区分统计显著性和效应量。
研究人员通常通过统计检验提供的 `p` 值来对重要性做出判断。然而，`p` 值不仅取决于效应的大小，还取决于样本量。大样本量可能会导致显著的结果，即使效应量小到在实际或理论上没有意义。例如，`Cohen (1990)` 讨论了《纽约时报》的一篇为“儿童身高与测试成绩有关”的文章，文章报道了一项涉及近 14000 名儿童的研究，显示在控制了出生顺序和身体发育等因素后，年龄与性别调整后的身高成绩之间存在“明确”的联系。在考虑生长激素后，我们注意到对于 14000 的样本，即使相关性仅为 `.0278`，我们也得到了 `p < .001`。使用回归预测 `IQ` 和身高，我们发现 `IQ` 从 100 变为 130 的预测变化需要 14 英尺身高，而预测的四英寸身高需要大约 230 分的 `IQ`。我们不仅要考虑显著水平，还要考虑效应量。

## 16. 记住效应量的测量也很重要。
`APA` 任务建议在主要结果中始终呈现效应量的测量，越来越多的期刊现在要求在结果部分包含效应量。然而，对于任何给定的研究，样本中的估计效应量是一个具有自身采样分布的统计量。因此，在报告效应量测量时应提供置信区间（参见第 6 章）。

## 17. 注意有显著差异的组与无显著差异的组之间并不一定显著。
假设 `A` 组的条件（因子 `C`）有显著效应，但 `C` 并不显著。

## 684 研究设计与统计分析

对于组 `A₂`，我们不能据此认为 `C` 的效应在 `A₁` 和 `A₂` 之间是不同的。如果我们想拒绝两组都具有 `C` 效应的零假设，必须直接测试 `C` 效应在 `A₁` 和 `A₂` 之间是否存在显著差异——即必须测试 `A x C` 交互作用。此外，注意，如果 `A₁` 存在显著的 `C` 效应，但在 `A₂` 完全没有 `C` 效应，这种交互作用可能并不显著。这是因为交互作用（即差异之差异）的标准误比这些大。

这个问题在第 10 章中会有更详细的讨论。

## 18. 执行多次统计检验可能会将整体第一类错误率提高到不可接受的水平。
如果我们在同一数据集上进行更多的统计检验，就越可能犯第一类错误——也就是说，我们越可能发现显著性结果。对于某些类型的检验，控制第一类错误的程序已经非常完善，但对于其他类型则几乎不存在。在第 10 章中，我们讨论了用于控制对比族第一类错误的程序。我们区分了计划内对比（即理论驱动的）和非计划内对比，并提供了这两种情况下的第一类错误控制方法。然而，在某些领域这种控制并不常见。对于多因素方差分析（`ANOVA`），在具有许多因素的设计中在同一水平上测试每个主效应和交互作用会导致第一类错误的巨大膨胀。此外，我们注意到，即使预测变量对第一类错误极其敏感，多元回归中也明确解决了第一类错误的控制，特别是当加入方程的预测变量是从较大的变量池中选出时。在回归章节中，我们区分了理论驱动的分析和所谓的“事后拟合”（`ad hoc fitting`），即为了凑巧解释较大的 `R²` 值而收集的变量。我们还讨论了 `Steiger (1980)` 的建议，对个体相关性进行联合检验（第 18 章）。这是很有用，因为假设有 15 个变量，就有 `(15)/2 = 105` 个两两相关性。非常仔细且以不同的方式观察你的数据并没有问题——正如俗话说，如果你对数据进行足够的拷刑，它们就会招供的！问题在于，如果你在不考虑第一类错误的情况下进行大量测试，你可能会承认任何结果。

## 19. 注意，即使是不显著的结果也能为某一效应增加累积证据。
假设一个研究人员进行了一项涉及 60 名参与者的研究，并发现了一个相当大且具有统计意义的意外效应。此外，假设该效应具有理论意义且未被预测，假设另一位研究人员需要用 40 名参与者重复该研究以确认其存在性。如果效应是显著的，那么说明了一个成功的揭示，我们增加了对该效应存在的信心。但假设第二项研究中的效应并不显著；估计的效应方向相同，但大小仅为原始研究中发现效应的三之二。事实上，我们如何解释估计效应量与实际结果之间的“差异”呢？事实上，由于第二次研究的参与者较少，我们预期的估计结果中存在抽样变异。确实，我们现在对效应量有两个不同的估计，而我们对效应量的最佳估计是该效应的某种平均值。

## 一最后的思考、建议与警告
需要注意的是，尽管在保持其他几个变量不变的情况下改变一个变量在样本回归方程中易于理解，但它可能并不对应现实世界中任何可能的操纵。尽管具有其局限性，回归分析可以成为推进研究问题知识和理论计划中非常有用的部分，因为它提供了对数据有用的描述，并建议了可以通过各种研究技术进行的问题和因果推测。

## 符号与基础求和运算

我们需要共同语言来讨论与实验设计和统计摘要相关的推导和计算公式。这种语言存在于此处符号系统中。如果你现在尝试掌握它，你的努力将获得丰厚的回报。我们从规则规则开始，将它们应用于一些基础统计量。

### A.1 单组得分

#### A.1.1 一些基本规则

在如 `$Y_1, Y_2, Y_3, Y_4, \dots$` 的一组得分中，下标除了区分各个得分外没有其他作用。数量 `n` 是组得分的总数。假设 `n = 5`，我们想要表示所有五个得分都相加。我们可以写成：

```
$Y_1 + Y_2 + Y_3 + Y_4 + Y_5$
```

或者简短地：

```
$Y_1 + Y_2 + \dots + Y_5$
```

更简短地，我们写成：

```
$\sum_{i=1}^{5} Y_i$
```

这个表达式读作“对所有从 1 到 5 的 `i` 求 `Y` 的值”。通常，`i = 1, 2, \dots, n`（即 `i` 取 1 到 `n` 的值），一组 `n` 个得分的求和表示为：

```
$\sum_{i=1}^{n} Y_i$
```

变量 `i` 是 *索引*，而 1 和 `n` 是 *求和限*。¹当演示的上下文很清晰时，索引和限通常会被省略。因此，我们经常用 `$\sum Y$` 表示一组得分需要求和。以下是求和的三条规则。

规则 1。常数乘以变量之和等于常数乘以变量之和；或

```
ΣCY = CΣY
```

项 `C` 是一个常数，意味着它的值不随 `i` 的变化而改变；`Y` 的值取决于 `i`，因此 `Y` 相对于 `i` 来说是一个变量。该规则很容易证明。

```
ΣCY = CY1 + CY2 + CY3 + ... + CNY
= C(Y1 + Y2 + Y3 + ... + Yn)
= CΣY
```

规则 2。常数之和等于 `n` 倍该常数，其中 `n` 等于求和数量的数量；或

```
ΣC = C + C + ... + C = nC
```

规则 3。求和符号适用于括号内数量的分配律。

# 示例 1.

```
Σ^n (X_i - Y_i) = Σ^n X_i - Σ^n Y_i
```

证明。

```
Σ(X - Y) = (X1 - Y1) + (X2 - Y2) + ... + (Xn - Yn)
= (X1 + X2 + ... + Xn) - (Y1 + Y2 + ... + Yn)
= ΣX - ΣY
```

# 示例 2.

```
Σ(X - Y)^2 = ΣX^2 + ΣY^2 - 2ΣXY
```

证明。

```
Σ(X - Y)^2 = Σ(X1 - Y1)^2 + ... + (Xn - Yn)^2
= (X1^2 + Y1^2 - 2X1Y1) + (X2^2 + Y2^2 - 2X2Y2) + ... + (Xn^2 + Yn^2 - 2XnYYn)
= (X1^2 + X2^2 + ... + Xn^2) + (Y1^2 + Y2^2 + ... + Yn^2) - 2(X1Y1 + X2Y2 + ... + XnYYn)
= ΣX^2 + ΣY^2 - 2ΣXY
```

#### A.1.2 应用求和规则

我们可以应用求和规则来证明第 2 章（节 2.3.1）中提到的均值和方差的性质。在本节中，应该清楚，尽管在每个表达式中没有显式给出索引和限，但我们对 `i` 从 1 到 `n` 求和。

##### 均值的性质

- 1. `$\Sigma(Y - \bar{Y}) = 0$`；所有得分关于均值的偏差之和为零。应用规则 3，我们得到：

```
$\Sigma(Y - \bar{Y}) = \Sigma Y - \Sigma \bar{Y}$
```

因此，`$\bar{Y}$` 是常数；无论求和索引的值如何，它的值都相同。因此，应用规则 2，我们将最后一个方程重写为：

```
$\Sigma(Y - \bar{Y}) = \Sigma Y - n\bar{Y}$
```

因为 `$\bar{Y} = \Sigma Y/n$`，我们可以将其重写为：

```
$\Sigma(Y - \bar{Y}) = \Sigma Y - n\frac{\Sigma Y}{n} = \Sigma Y - \Sigma Y = 0
```

- 2. `$\frac{\Sigma(Y + k)}{n} = \bar{Y} + k$`；如果给所有得分加上一个常数，均值会增加该常数。应用规则 3，我们得到得到：

```
$\frac{\Sigma(Y + k)}{n} = \frac{\Sigma Y + \Sigma k}{n} = \frac{\Sigma Y}{n} + \frac{nk}{n}$
```

应用规则 2 并注意 `$\frac{\Sigma Y}{n} = \bar{Y}$`，我们得到：

```
$\frac{\Sigma(Y + k)}{n} = \bar{Y} + k
```

- 3. `$\frac{\Sigma kY}{n} = k\bar{Y}$`；如果所有得分乘以一个常数，均值乘以该常数。应用规则 1，我们得到：

```
$\frac{\Sigma kY}{n} = k\bar{Y}$
```

- 4. `$\Sigma(Y - \bar{Y})^2$` 是最小的。假设存在某个值 `$\bar{Y} + d$`，使得偏差和比任何其他值都小。这个距离和为 `$\Sigma[Y - (\bar{Y} + d)]^2$`。根据规则 3 展开，我们得到：

```
$\Sigma[Y - (\bar{Y} + d)]^2 = \Sigma[(Y - \bar{Y}) - d]^2 = \Sigma[(Y - \bar{Y})^2 - 2d(Y - \bar{Y}) + d^2]$
```

展开后为：

```
= \Sigma(Y - \bar{Y})^2 - 2d\Sigma(Y - \bar{Y}) + \Sigma d^2
```

应用规则 1，由于 `$\Sigma(Y - \bar{Y}) = 0$`，我们重写最后一项：

```
$2d\Sigma(Y - \bar{Y}) = 2d(0) = 0
```

应用规则 2，我们得到：

```
$\Sigma d^2 = nd^2
```

因此，

```
$\Sigma[Y - (\bar{Y} + d)]^2 = \Sigma(Y - \bar{Y})^2 + nd^2
```

当 `d = 0` 时，它是最小的；即我们对均值的平方偏差。

##### 方差的性质

- 1. 给所有得分加上常数不会改变方差。如果给所有得分加上常数 `k`，新的方差为：

`$\sigma_{Y+k}^2 = \frac{\Sigma(Y+k - (\bar{Y}+k))^2}{n-1} = \frac{\Sigma(Y - \bar{Y})^2}{n-1} = \sigma_Y^2$`

- 2. 将所有得分乘以常数 `k` 等于将方差乘以 `k^2`，将标准差乘以 `k`。我们得到：

`$\sigma_{kY}^2 = \frac{\Sigma(kY - k\bar{Y})^2}{n-1} = \frac{k^2\Sigma(Y - \bar{Y})^2}{n-1}$`

根据规则 1，这变为：

`$\sigma_{kY}^2 = \frac{k^2\Sigma(Y - \bar{Y})^2}{n-1} = k^2\sigma_Y^2$`

##### z 得分

性质允许我们证明一组 `z` 得分的均值为0，方差为1。回想：

`$z = \frac{Y - \bar{Y}}{\sigma_Y}$`

为了得到一组 `n` 个得分的平均值，我们将它们求和并除以 `n`，记住 `$\Sigma(Y - \bar{Y}) = 0$`。那么：

```
$$\frac{\Sigma_z}{n} = \frac{\Sigma(Y - \bar{Y})}{n\sigma_Y} = \frac{(0)}{n\sigma_Y} = 0$$
```

为了证明 `z` 得分的方差（因此是标准差）为1，展开 `z` 的公式：

```
$z = \left(\frac{1}{\sigma_Y}\right)Y - \left(\frac{1}{\sigma_Y}\right)\bar{Y}$
```

注意 `1/\sigma_Y` 是关于求和索引 `i` 的常数。由于从变量中加（减）不会改变其方差（见方差的第一个性质），`z` 的方差与 `(1/\sigma_Y)` 的方差相同。但根据方差的第二个性质，我们知道常数 `(1/\sigma_Y)` 乘以变量 `(Y)` 的方差等于常数的平方乘以变量的方差。也就是说：

```
$$\sigma_z^2 = \left(\frac{1}{\sigma_Y}\right)^2 = 1$$
```

#### A.1.3 原始公式

求和规则可以用于获取方差和协方差等数量的原始公式。这些原始公式或计算公式包含得分之和、得分平方和交叉积，而不是差的平方和差的交叉积。这使得它们能够最小化舍入误差，并方便与没有方差和相关性键的简单手计算器使用。

`Y` 方差表达式的分子是 `$SS_{Y} = \Sigma(Y - \bar{Y})^2$`。为了得到原始公式，展开求和符号内的数量。因此

```
$\Sigma(Y - \bar{Y})^2 = \Sigma(Y^2 + \bar{Y}^2 - 2Y\bar{Y})$
```

应用规则 3，我们得到：
