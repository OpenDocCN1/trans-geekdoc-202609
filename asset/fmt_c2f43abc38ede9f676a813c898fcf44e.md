
# 网络安全工具与技术

成功分析、评估和防御网络需要一套广泛的工具。分析师必须了解可评估路由、路径和延迟的工具的用途和基本用法。你应该能够收集有关系统网络接口、流量统计、路由以及网络上其他本地系统的信息。端口和漏洞扫描工具也可以帮助评估网络，开源情报收集工具可以在不实际扫描目标网络的情况下提供详细信息。`netcat` 和 `curl` 等实用程序有助于传输和获取数据；`hping`、`tcpdump` 和 Wireshark 允许你创建、捕获和分析数据包及网络流量。

## 考试要点

**网络安全的基础是安全设计。** 基于风险或安全要求划分不同的安全区域有助于保护网络。DMZ、内部网和外部网都是常见的网络分段选项，零信任网络将分段概念扩展到使每个系统都能自我防御。NAC 可保护网络免受不受信任设备连接的影响，而端口安全和环路防护、广播风暴防护等端口级保护可确保恶意或配置错误的系统不会导致网络问题。端口跨越和镜像通过创建其他端口流量的副本来实现数据包捕获。VPN 用于将网络流量通过隧道传输到另一位置，它们可以是加密的，也可以只是简单的隧道传输。

**网络设备用于为网络和系统提供安全服务。** 网络设备有多种类型。跳板服务器和跳板机提供了一种安全的方式来访问另一安全区域中的系统。负载均衡器将负载分散到各个系统中，并可以使用不同的调度选项以及主动/主动或主动/被动设计等运行模式。代理服务器要么将一组客户端的连接集中转发到服务器，要么将一组服务器的连接集中转发到客户端，通常作为一种负载均衡策略。内容和 URL 过滤器根据规则限制可进出网络的信息，数据丢失防护系统监控以确保不应离开系统或网络的数据被识别并标记、安全发送或阻止。NAT 网关允许多个系统使用单个公共地址，同时防止未经特殊配置的入站连接。IDS 和 IPS 设备根据恶意行为、签名或流量异常进行识别并采取行动。HSM 创建、存储和管理加密密钥和证书，也可用于卸载加密处理。传感器和收集器等数据收集设备有助于数据收集。防火墙用于构建安全区域，并放置在信任边界处。UTM 设备将这些安全功能和能力中的许多结合到单个设备或系统中。

## 网络安全服务与管理技术

网络安全服务和管理技术有助于确保网络保持安全。带外管理将管理接口置于单独的 VLAN 或物理网络上，或要求直接连接，以帮助防止攻击者访问管理接口。访问控制列表用于网络设备，根据端口、协议或 IP 地址等信息阻止或允许特定流量。服务质量协议和设置可用于确定流量优先级，以确保重要流量能够通过网络，同时限制攻击和错误配置的影响。由于路由协议缺乏重要的安全功能，路由安全颇具挑战性。经过身份验证的路由协议确实存在，它们有助于限制针对路由协议的攻击所造成的某些影响。DNS 安全也有限，但 DNSSEC 有助于验证 DNS 服务器和响应。必须正确配置 DNS 服务器，以防止区域传送和其他 DNS 攻击。TLS 广泛用于保护网络流量，充当许多其他协议的封装层。监控服务和系统有助于确保它们保持在线和可访问，但由于可生成的信息量巨大，且如果验证和监控未完全验证服务响应，则可能出现误报，因此需要谨慎操作。文件完整性监视器检查文件是否已更改，并可针对更改发出警报，或将现有文件恢复到更改前或删除前的状态。蜜罐和蜜网用于收集有关攻击者的信息，蜜文件和虚假遥测数据用于识别潜在的入侵以及从您环境中的系统收集信息的攻击者。

## 安全协议

安全协议提供了安全发送和接收信息的方法。许多原始的互联网协议是不安全的——它们不提供加密或身份验证，并且可能被捕获、分析或修改。使用协议的安全版本或使用替代的安全服务和协议，是确保网络安全的重要组成部分。关键协议包括语音和视频协议（如 `SRTP`）；电子邮件协议（如 `IMAPS` 和 `POPS`）；以及安全协议（如 `DMARC`、`DKIM` 和 `SPF`）。文件传输可以通过 `SFTP` 或 `FTPS` 完成，而不使用 `FTP`；目录服务可以从 `LDAP` 迁移到 `LDAPS`。某些协议没有那么多或那么完整的安全选项。事实上，`DNS`、路由和 `DHCP` 都缺乏安全通信选项。网络管理员在设计和运营网络时必须考虑到这些因素。

## 用于网络评估的命令行工具

安全专业人员必须知道如何使用命令行工具来收集网络和系统信息。命令行工具是您网络评估和管理工具包的重要组成部分。路由信息可以使用 `ping`、`tracert`、`traceroute` 和 `pathping` 来收集。DNS 信息由 `dig` 和 `nslookup` 提供。关于网络和流量的系统信息可以由 `ipconfig`、`ifconfig`、`netstat`、`arp` 和 `route` 提供。端口扫描通常涉及 `nmap` 和 `Nessus`，但也可以使用一系列其他工具，包括其他基于 IP 的扫描器。`netcat` 是许多安全专业人员使用的多功能工具，因为它体积小、可移植且功能广泛。`curl` 根据 URL 检索信息，`hping` 允许进行数据包构造和分析。OSINT 工具如 `theHarvester`、`Sn1per` 和 `DNSEnum` 允许在不直接与目标系统通信的情况下收集信息。最后，数据包捕获工具如 `tcpdump` 和 `Wireshark` 允许在命令行或 GUI 环境中分析和审查流量，沙箱（如 `Cuckoo`）可用于在安全环境中测试恶意软件的存在。

# 第 13 章 无线与移动安全

大多数组织网络的重要部分现在都是无线的，与有线网络相比，无线网络面临许多安全挑战。它们广播信号，且经常可以从组织拥有和管理的空间之外访问。蜂窝网络和点对点商用无线网络甚至完全不在客户的控制范围内，这意味着它们承载的流量可能需要被视为正在遍历潜在的敌对网络路径。

在本章中，您将了解常见的无线连接选项——从蓝牙和蜂窝到 Wi-Fi——以及它们最常使用的网络模型。随后您将深入了解无线攻击。考虑到这一点，您将探索无线网络设计和安全的最佳实践。在此过程中，您还将了解无线认证、多种形式的 EAP，以及如何保护无线控制器和接入点的安全。

本章的后半部分侧重于移动设备管理。移动设备部署模型（如自带设备 [BYOD] 和企业自有、个人启用 [COPE]）是组织关于如何将设备交到最终用户手中的决策的关键部分。一旦部署了这些设备，您还需要对其进行管理，您将了解移动设备管理工具、常见功能和重要的控制能力。通过周密的规划，您可以确保设备在发放或注册时是安全的，在其整个生命周期中得到良好管理，并能处理盗窃、丢失或使用寿命结束的情况。

## 构建安全的无线网络

无线网络遍布我们的组织。从使用强大工具对用户进行认证、管理和监控的企业网络，到家庭和小型企业中用于为住户、客户或访客提供连接的简单无线路由器，Wi-Fi 无处不在。然而，Wi-Fi 网络并非您将遇到的唯一网络类型——蓝牙、蜂窝、Zigbee 和其他类型的连接也存在于组织中。与有线网络不同，这些无线网络不会在组织的墙壁之外停止，这使得无线网络安全成为一个截然不同的挑战。许多设备都有能力创建自组网，或桥接其有线和无线网络连接，这意味着组织中的设备最终也可能成为恶意行为者通往网络或设备本身的路径。

### 连接方式

设计安全网络通常始于对您将要部署或保护的网络连接类型的基本了解。Security+ 考试大纲列出了一系列无线连接类型，将在以下各节中介绍。

#### 蜂窝网络

*蜂窝*网络通过将地理区域划分为“小区”，利用塔的覆盖实现设备与塔或基站之间的无线通信，为手机等移动设备提供连接。现代蜂窝网络使用 LTE（长期演进）4G 及相关技术，以及正在全球稳步部署的新型 5G 网络。5G 需要更高的天线密度，但也提供更大的带宽和吞吐量。蜂窝服务提供商和需要蜂窝连接的组织过去倾向于在 4G 网络需要覆盖的地方放置塔，而 5G 网络将需要更多地关注天线部署，这意味着组织未来可能需要将 5G 天线布局作为建筑和设施设计工作的一部分。

蜂窝连接通常由蜂窝运营商提供，而非组织自身，这与 Wi-Fi 或其他公司可能选择自行实施的技术不同。这意味着蜂窝网络在组织外部是安全的、受管理的和受控的，通过蜂窝连接发送的流量会经过第三方网络。因此，蜂窝数据需要像对待外部网络连接一样对待，而不是自己的企业网络。

#### Wi-Fi

*Wi-Fi* 一词涵盖了一系列用于提供无线联网的无线协议。Wi-Fi 主要依赖 2.4 GHz 和 5 GHz 无线电频段，并在这些频段内使用多个信道以允许多个网络共存。Wi-Fi 信号可以达到相当长的距离，尽管 Wi-Fi 运行的频率会被墙壁和树木等常见障碍物阻挡或削弱。尽管存在这些阻碍，Wi-Fi 网络最重要的安全顾虑之一是它们会超出组织拥有或控制的空间。

表 13.1 列出了当前和历史上的 Wi-Fi 标准，范围从首个广泛部署的 Wi-Fi 标准 802.11b，到目前部署最广泛的标准 802.11ac。802.11ax（即 Wi-Fi 6）正稳步普及，但组织可能仍会广泛部署现有的 802.11ac 设备，直到将其作为正常升级的一部分进行替换。在许多环境中，仍可能遇到 802.11n、802.11g 甚至更旧的标准。

幸运的是，WPA2 和 WPA3 等 Wi-Fi 协议提供了安全特性和功能，有助于保护无线信号安全。这些功能包括加密选项、网络帧保护和认证选项。

#### Wi-Fi 网络模式

Wi-Fi 设备最常部署在自组网模式或基础设施模式下。自组网模式允许设备直接相互通信，而基础设施模式则通过基站或接入点发送流量。Wi-Fi 网络使用服务集标识符（`SSIDs`）来标识其网络名称。`SSIDs` 可以广播，也可以设为私有。

#### 蓝牙

**蓝牙**是一种短距离无线标准。与 Wi-Fi 和许多其他技术一样，它在 2.4 GHz 频段运行，该频段被许多不同的无线协议使用。蓝牙主要用于低功耗、短距离（小于 100 米，通常为 5–30 米）的连接，这些连接没有很高的带宽需求。蓝牙设备通常采用点对点模式而非客户端-服务器模式进行连接。

由于蓝牙的设计和实现旨在易于发现、配置和使用，因此它也相对容易受到攻击。蓝牙确实支持加密，但加密依赖于双方设备使用的 PIN 码。耳机等设备的固定 PIN 码会降低其连接的安全性。针对认证以及协商加密密钥的攻击意味着蓝牙可能容易受到窃听以及其他攻击。

#### NFC

**近场通信（NFC）**用于设备之间极短距离的通信。您可能见过 NFC 用于支持 Apple Pay 或 Google Wallet 的支付终端，通过手机进行支付。NFC 的范围限制在约 4 英寸左右，这意味着它不用于构建设备网络，而是主要用于低带宽、设备对设备的用途。这并不意味着 NFC 不会受到攻击，但这确实意味着威胁通常会来自靠近 NFC 设备的近距离。拦截 NFC 流量、重放攻击和欺骗攻击都是 NFC 实现需要考虑的问题。同时，NFC 设备必须确保仅在期望时响应查询，以免攻击者仅将接收器移入范围内即可激活 NFC 事务或响应。

#### RFID

**射频识别（RFID）**是一种相对短距离（从某些被动标签的不到一英尺，到主动标签的约 100 米）无线技术，它使用标签和接收器来交换信息。RFID 可以使用主动标签、半主动标签或被动标签部署。主动标签拥有自己的电源，并始终发送信号供读取器读取；半主动标签有电池为其电路供电，但由读取器激活；被动标签则完全由读取器供电。
