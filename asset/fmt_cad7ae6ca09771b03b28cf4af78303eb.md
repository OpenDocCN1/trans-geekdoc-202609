## 问题 217

## 问题 223
一家热门在线购物平台发现某些产品评论包含一个奇怪的链接，点击该链接会将用户引导至一个与平台非常相似但会收集登录凭据的网站。评论中的漏洞系统可能允许攻击者发布此类链接？

(A) 会话劫持 (Session Hijacking)
(B) 跨站脚本 (XSS)
(C) 密码破解 (Password Spraying)
(D) 凭据填充 (Credential Stuffing)

### 解析 223
**正确答案：B. 跨站脚本 (XSS)。** XSS漏洞允许攻击者向网页内容中注入恶意脚本。如果平台的审核系统没有对输入进行适当清理，可能会允许攻击者嵌入指向钓鱼网站的恶意链接。

**选项 D 错误。** 凭据填充攻击涉及使用大量有效用户名和密码自动尝试获取访问。它与在网页内容中插入恶意链接无关。

## 问题 229
安全审计员发现网站的登录表单返回如“列名错误”或“未找到表”等详细错误信息。攻击者可以使用这些信息利用哪种类型的漏洞？

- (A) 暴力破解攻击 (Brute Force Attack)
- (B) SQL 注入 (SQLi)
- (C) 中间人攻击 (Man-in-the-Middle Attack)
- (D) 会话劫持 (Session Hijacking)

### 解析 229
**正确答案：B. SQL 注入 (SQLi)。** 当网站提供详细的数据库错误信息时，它可以为攻击者提供数据库结构的线索，使其更容易构建成功的 SQL 攻击。

**选项 D 错误。** 会话劫持涉及接管活跃的用户会话。详尽的数据库错误信息在此类攻击中不起直接作用。

## 问题 230

- (D) Security marker（安全标记）

### 解析 231
**正确答案：B. Honeytoken。** Honeytokens 是策略性放置的欺骗性数据，它们没有实际价值或现实用途，但会被严密监控。它们的唯一目的是检测未经授权的交互，因为对 honeytoken 的任何访问或使用都可能是恶意的或未经授权的。

**选项 A 错误。** 在描述的语境下，并没有一种公认的名为“Honeystring”的安全术语。

**选项 C 错误。** Canary tokens 是 honeytoken 的特定类型，可以起到相同的作用。然而，考虑到给出的选项和问题的背景，“Honeytoken”是最准确的答案。

**选项 D 错误。** 从广义上说，安全标记可以是任何用于安全目的的标记或指示，但它不是专门放置的用于检测未经授权访问的欺骗性数据。

## 问题 232
你是一家使用云基础设施的公司的安全顾问。在安全审查期间，你发现云中的开发、测试环境和生产环境之间没有定义边界。这可能导致无意的交互和数据泄露。这种场景说明了哪种漏洞？

- (A) 不安全的 API 端点
- (B) 弱的加密方法
- (C) 缺乏资源隔离
- (D) 备份策略不足

### 解析 232
**正确答案：C. 缺乏资源隔离。** 云特定的漏洞可能由于云基础设施的共享性质而产生。在这种情况下，开发、测试和生产等不同环境之间没有边界或隔离可能会导致漏洞。如果没有适当的资源隔离，引入开发环境的恶意代码可能会进入生产环境，或者机密的生产数据可能会在测试环境中暴露，导致潜在的数据泄露。

**选项 A 错误。** 不安全的 API 端点涉及用于管理和与云服务交互的 API 未能妥善保护的漏洞。

**选项 B 错误。** 弱的加密方法指的是使用过时或有漏洞的加密算法，这与环境的混合没有直接关系。
