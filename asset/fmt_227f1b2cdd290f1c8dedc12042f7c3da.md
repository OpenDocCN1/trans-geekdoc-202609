MAP 估计一个更微妙的问题是，我们得到的结果取决于我们如何定义概率分布。从一种表示变换到另一种等价表示会改变结果，这并不理想，因为度量单位是任意的（例如，测量距离时，我们可以使用厘米或英寸）。为了理解这个问题，假设我们计算 `x` 的后验。如果我们定义 `y = f(x)`，则 `y` 的分布由公式 2.44 给出。`dx/dy` 项称为雅可比矩阵，它衡量单位体积通过 `f` 后大小的变化。令 `ˆx = arg max_x p_x(x)` 为 `x` 的 MAP 估计。通常 `x = arg max_x p_x(x)` 并不由 `f(x)` 给出。例如，设 `X ~ N(6,1)` 且 `y = f(x)`，其中 `f(x) = 1/(1+exp(−x+5))`。

### 可信区间

除了点估计，我们通常还需要一个确定性的度量。对某个（标量）量 `θ` 的确信程度的一个标准度量是其后验分布的宽度。这可以使用 `100(1−α)%` 可信区间来估计，它是一个（连续的）区域 `C = (ℓ, u)`（代表下限和上限），包含 `1−α` 的后验概率质量，即 `C_α(D)` 其中 `P(ℓ ≤ θ ≤ u) = 1 − α` (5.1)。

可能存在许多这样的区间，所以我们选择一个使得每个尾部有 `(1−α)/2` 的质量；这称为中心区间。如果后验具有已知的函数形式，我们可以使用 `ℓ = F⁻¹(α/2)` 和 `u = F⁻¹(1−α/2)` 计算后验中心区间，其中 `F` 是后验的累积分布函数 (cdf)。如果我们不知道函数形式，但可以从后验中抽取样本，则可以使用后验分位数的蒙特卡洛近似：我们只需对 `S` 个样本进行排序，并找到位于排序列表 `α/S` 位置处的那个样本。当 `S → ∞` 时，这收敛到真实分位数。人们经常混淆贝叶斯可信区间与频率学派置信区间。然而，它们并不相同，正如我们在 TODO 节中讨论的那样。通常，可信区间通常是人们想要计算的，但置信区间通常是他们实际计算的，因为大多数人学的是频率学派统计而不是贝叶斯统计。幸运的是，计算可信区间的机制与计算置信区间几乎一样简单。

### 比例差异的推断

有时我们有多个参数，并且我们有兴趣计算这些参数的某个函数的后验分布。例如，假设你要从 Amazon.com 购买某样东西，并且有两个供应商以相同的价格提供该商品。供应商 1 有 90 条好评和 10 条差评。供应商 2 有 2 条好评和 0 条差评。你应该从谁那里购买？ 18. 表面上看，你应该选择供应商 2，但我们不能非常确定供应商 2 更好，因为它的评价很少。在本节中，我们将概述对该问题的贝叶斯分析。类似的技术可用于在各种不同情境下比较各组间的比率或比例。

## 贝叶斯模型选择

通常，当面对一组不同复杂度的模型（即参数分布族）时，我们该如何选择最好的一个？这被称为模型选择问题。一种方法是使用交叉验证来估计所有候选模型的泛化误差，然后选择看起来最好的模型。

然而，这需要对每个模型进行 `K` 次拟合，其中 `K` 是 CV 折数。一种更有效的方法是跨模型处理后验。

由此，我们可以轻松计算 MAP 模型，`m = arg max_m p(m|D)`。这被称为贝叶斯模型选择。如果我们对模型使用均匀先验，这相当于选择使以下公式最大化的模型：

```
∫
p(D|m) = p(D|θ)p(θ|m) dθ  (5.4)
```

该量被称为边际似然、积分似然或模型 `m` 的证据。关于如何执行此积分的细节将在后续章节讨论。但首先，我们给出该量含义的直观解释。

### 贝叶斯奥卡姆剃刀

人们可能会认为，使用 `p(D|m)` 来选择模型将总是倾向于参数最多的模型。

```
ˆ
```

如果我们使用 `p(D|θ_m)` 来选择模型，其中 `ˆ θ_m` 是模型 `m` 参数的 MLE 或 MAP 估计，那么这是正确的，因为参数更多的模型将更好地拟合数据，从而获得更高的似然。然而，如果我们对参数进行积分（边缘化），而不是最大化它们，我们将自动免受过拟合之害：参数更多的模型不一定具有更高的边际似然。这被称为贝叶斯奥卡姆剃刀效应（MacKay 1995b; Murray and Ghahramani 2005），得名于奥卡姆剃刀原则，即应选择能充分解释数据的最简单模型。

理解贝叶斯奥卡姆剃刀的一种方法是注意到，根据概率链式法则（公式 2.3），边际似然可以重写如下：

```
p(D) = p((x1,y1)) p((x2,y2)|(x1,y1))
       p((x3,y3)|(x1,y1) : (x2,y2)) ···  (5.5)
       p((xN,yN)|(x1,y1) : (xN−1,yN−1))
```

这类似于似然的留一交叉验证估计（第 1.3.4 节），因为我们根据所有过去的点预测每个未来的点。（当然，上述表达式中数据的顺序无关紧要。）如果模型过于复杂，它将过拟合早期的样本，进而对剩余样本预测不佳。

理解贝叶斯奥卡姆剃刀效应的另一种方法是注意到概率必须归一。因此 `∑ p(D′) p(m|D′) = 1`，其中求和是在所有可能的数据集上进行的。能预测许多事物的复杂模型必须将其概率质量分散得很薄，因此对于任何给定的数据集，其获得的似然不会比简单模型大。这有时被称为概率质量守恒原则，如图 5.3 所示。

有时不清楚如何设置先验。当我们进行后验推断时，先验的细节可能并不太重要，因为似然通常无论如何都会压倒先验。但在计算边际似然时，先验扮演着更重要的角色，因为我们正在对所有可能的参数设置进行加权平均，权重由先验决定。如果先验模糊不清，正确的贝叶斯方法是给先验设定一个先验。如果先验模糊不清，正确的贝叶斯方法是给先验设定一个先验。

### 贝叶斯因子

假设我们对模型的先验是均匀的，`p(m) ∝ 1`。那么模型选择等同于选择边际似然最高的模型。现在假设我们只考虑两个模型，称它们为零假设 `M0` 和备择假设 `M1`。将贝叶斯因子定义为边际似然的比率：

$$ \text{BF}_{1,0} \triangleq \frac{p(D|M_1)}{p(D|M_0)} = \frac{p(M_1|D)/p(M_1)}{p(M_2|D)/p(M_0)} \tag{5.26} $$

## 先验

贝叶斯统计最具争议的方面在于其对先验的依赖。贝叶斯派认为这是不可避免的，因为没有人是一块`干净的石板`或`空白的画布`：所有推断都必须基于关于世界的特定假设进行。然而，人们可能有兴趣最小化先验假设的影响。我们在下面简要讨论一些实现此目的的方法。

### 非信息先验

如果我们对 `θ` 应该是什么没有强烈的信念，通常会使用非信息或无信息先验，让数据说明一切。

### 鲁棒先验

在许多情况下，我们对先验不是非常确定，因此我们需要确保它不影响结果。这可以通过使用鲁棒先验 (Insua and Ruggeri 2000) 来实现，它们通常具有厚尾，这避免了强制事物过于接近先验均值。

### 共轭先验的混合

鲁棒先验很有用，但使用起来计算成本可能很高。共轭先验简化了计算，但通常不够鲁棒，且不够灵活，无法编码我们的先验知识。然而，事实证明，共轭先验的混合也是共轭的，并且可以近似任何类型的先验 (Dallal and Hall 1983; Diaconis and Ylvisaker 1985)。因此，此类先验在计算便利性和灵活性之间提供了良好的折衷。

## 分层贝叶斯

计算后验 `p(θ|D)` 的一个关键要求是指定先验 `p(θ|η)`，其中 `η` 是超参数。如果我们不知道如何设置 `η` 怎么办？在某些情况下，我们可以使用非信息先验，这是我们上面讨论过的。一种更贝叶斯的方法是给我们的先验设定一个先验！用图模型术语（第 TODO 章）表示，我们可以将这种情况表示如下：

$$ \eta \to \theta \to D \tag{5.27} $$

这是一个分层贝叶斯模型的示例，也称为多层模型，因为存在多层未知量。

## 贝叶斯决策理论

我们已经了解了概率论如何用于表示和更新我们对世界状态的信念。然而，最终我们的目标是将我们的信念转化为 ∫ 37 行动。在本节中，我们讨论实现这一目标的最佳方式。

我们的目标是设计一个决策系统或策略，`f(x) : X → Y`，以最小化期望损失 `R_exp(f)`（见公式 1.1）。在贝叶斯决策理论方法中，观察到 `x` 后的最优动作被定义为使后验期望损失最小化的动作 `a`：
