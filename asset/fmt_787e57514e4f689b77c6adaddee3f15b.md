# Listing 5.12: hashing_vectorize.py

```python
from sklearn.feature_extraction.text import HashingVectorizer
sentences = ['the mouse ate the cheese', 'the horse ate the hay', 'the mouse saw the horse', 'the mouse scared the horse']
vectorizer = HashingVectorizer(norm=None, n_features=8)
sentence_vectors = vectorizer.fit_transform(sentences)

print(sentence_vectors.toarray())
```

另一种对句子数组进行向量化的方法涉及 `TfidfVectorizer` 类。Listing 5.13 显示了 `tfidf_vectorize.py` 的内容，说明如何使用 Sklearn 中的 `TfidfVectorizer` 类对句子数组进行向量化。

# Listing 5.13: tfidf_vectorize.py

```python
from sklearn.feature_extraction.text import TfidfVectorizer
import matplotlib.pyplot as plt
import seaborn as sns
sentences = ['the mouse ate the cheese', 'the horse ate the hay', 'the mouse saw the horse', 'the mouse scared the horse']
vectorizer = TfidfVectorizer(norm=False, smooth_idf=False)
sentence_vectors = vectorizer.fit_transform(sentences)
print("vectorized sentences:")
print(sentence_vectors.toarray())
tfidf = vectorizer.fit_transform(sentences).toarray()
# display the tfidf frequencies:
sns.heatmap(tfidf,annot=True,cbar=False)
plt.show()
```

Listing 5.13 与 Listing 5.12 类似，只是使用了 `TfidfVector` 类代替了 `HashingVector` 类。另一个区别是用于可视化的 Seaborn Python 库，它说明了如何在 Seaborn 中创建热图。注意，附录 F 包含有关 Seaborn 的更多信息。

现在运行 Listing 5.13 中的代码，你将看到以下输出（数字已从 8 位小数截断为 3 位小数，以避免向量在多行中“换行”）：

```

 \[1.693 0.   2.386 1.287 0.   0.   0.   2. \]  
 \[0.   0.   0.   1.287 1.287 2.386 0.   2. \]  
 \[0.   0.   0.   1.287 1.287 0.   2.386 2. \]\]
```

Listing 5.14 显示了 `gensim_vectorize.py` 的内容，说明如何使用 gensim 中的 `word2vec` 类对句子数组进行向量化。

# Listing 5.14: gensim_vectorize.py

```python
from gensim.models import Word2Vec
sentences = [
    "the mouse ate the cheese",
    "the horse ate the hay",
    "the mouse saw the horse",
    "the mouse scared the horse"
]
model = Word2Vec(sentences, vector_size=100, window=5, min_count=1, workers=4)
print(model.wv['mouse'])
```

# Listing 5.18: scrape_text3.py

```python
import requests
import re
from bs4 import BeautifulSoup  # removes non-alphanumeric characters

def remove_non_alpha_chars(text):  # define the pattern to keep
    regex = r'[^a-zA-Z0-9]'
    return re.sub(regex, '', text)

src = "[`www.github.com`](https://www.github.com)"  # retrieve html web page as text
text = requests.get(src).text  #print("text:",text)  # parse into BeautifulSoup object
soup = BeautifulSoup(text, "html.parser")
```
