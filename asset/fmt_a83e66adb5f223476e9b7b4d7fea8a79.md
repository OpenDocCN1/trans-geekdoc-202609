## 运算符 + 重载

在类中添加 `__add__()` 函数将重载 `+` 运算符。

### 示例

1. 启动 IDLE。
2. 导航到“文件”菜单并点击“新建窗口”。
3. 输入以下内容：

```python
class Planar:

    def __init__(self, x_axis=0, y_axis=0):
        self.x_axis = x_axis
        self.y_axis = y_axis

    def __str__(self):
        return "({0},{1})".format(self.x_axis, self.y_axis)

    def __add__(self, z):
        x_axis = self.x_axis + z.x_axis
        y_axis = self.y_axis + z.y_axis
        return Planar(x_axis, y_axis)
```
