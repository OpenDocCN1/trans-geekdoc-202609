
注意：使用`int()`转换浮点数会截断小数部分。

示例：

启动 IDLE。

导航到`File`（文件）菜单并点击`New Window`（新建窗口）。

输入以下内容：

```python
int(3.9) # 应该输出 3
```

注意：使用`float()`转换整数时会加上`.0`。

示例：

启动 IDLE。

导航到`File`（文件）菜单并点击`New Window`（新建窗口）。

输入以下内容：

```python
float(5) # 应该输出 5.0
```

注意：使用`complex()`转换整数会生成复数。

示例：

启动 IDLE。

导航到`File`（文件）菜单并点击`New Window`（新建窗口）。

输入以下内容：

```python
complex(1) # 应该输出 (1+0j)
```

## 总结

类型转换有时被称为强制类型转换，允许将一种类型转换为另一种。

示例：

启动 IDLE。

导航到`File`（文件）菜单并点击`New Window`（新建窗口）。

输入以下内容：

```python
int("4.5") # 会抛出 ValueError
float("4") # 应该输出 4.0
str(10)    # 应该输出 '10'
```
