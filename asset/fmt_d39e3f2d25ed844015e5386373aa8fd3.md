保护系统的很大一部分工作是确保您遵循关于操作系统加固和应用程序安全的最佳实践。`系统加固` 是指从系统中移除不必要的软件和功能的概念。其原则基于这样一个可能性：安装在系统上的软件越多、安装的操作系统功能越多，存在的漏洞就越多，黑客入侵您系统的途径也就越多。

本章重点介绍如何通过遵循良好的操作系统加固和应用程序加固技术来缓解系统安全威胁。

### 认证目标 6.01

## 理解操作系统加固

操作系统 (OS) 加固是移除操作系统不必要功能、禁用不必要服务以及移除不必要账户的过程。从系统中移除不必要功能的目的是减少 `攻击面`，攻击面由黑客可以入侵的系统组件构成。因此，您需要减少在系统上运行的软件数量（请参见 图 6-1）。

![Image](img/f0232-01.jpg)

**图 6-1**  

卸载软件可减少系统的攻击面。

您需要执行许多任务来加固系统。大多数任务涉及移除不必要的组件、卸载不必要的软件、禁用不需要的服务以及禁用不必要的账户。本节概述了您为加固系统应采取的一些核心步骤。

![Image](img/exam.jpg)

**针对 Security+ 认证考试，请了解系统加固的概念及其包含的内容——它是从系统中卸载不必要的软件并禁用不需要的服务的过程。加固还涉及给系统打补丁和禁用未使用的账户。**

#### 卸载不必要的软件

加固系统的第一步是确保从系统中卸载任何不必要的软件。首先，重点卸载可能安装在系统上的不必要的第三方软件。例如，当您从商店购买一台新电脑时，系统通常预装了一堆您从未使用过的软件。从公司安全的角度来看，系统应该被重新格式化并应用全新的操作系统安装，无论是手动安装还是通过镜像部署。对于家用个人电脑，如果您无法重新安装一份全新的操作系统副本，请检查已安装的软件并移除每一款您不打算使用的软件。

请注意，当今的 Windows 操作系统仅安装了最少的功能或角色，但您可以通过以下步骤从 Windows 客户端或 Windows Server 操作系统中卸载第三方应用程序：

1. 在 Windows 客户端系统上，在“开始”菜单中输入 `control panel`，然后从搜索结果中选择“控制面板”。
2. 在“控制面板”中，单击“程序”（请参见 图 6-2）。

![Image](img/f0233-01.jpg)

**图 6-2**  

在 Windows 系统上管理已安装的程序

3. 单击“卸载程序”。
4. 随后将显示已安装应用程序的列表。要移除某个应用程序，请选中它并单击“卸载”。在“确认卸载”对话框中，单击“是”。

#### 卸载不必要的操作系统组件

卸载任何不打算使用的软件应用程序后，接下来应专注于移除不会被使用的操作系统组件。例如，在 Windows 2000 Server 时代，Microsoft 默认安装了其 Web 服务器软件 Internet Information Services (IIS)。这造成了巨大的安全问题，因为 IIS 存在多个漏洞，如目录遍历和缓冲区溢出漏洞。如果网络管理员卸载了 IIS，那些攻击就不会在该服务器上生效。

要在 Windows 客户端或 Windows Server 中卸载不使用的操作系统功能，请执行以下步骤：

1. 在 Windows 客户端系统上，在“开始”菜单中输入 `control panel`，然后从搜索结果中选择“控制面板”。
2. 在“控制面板”中，单击“程序”（请参阅 图 6-2）。
3. 选择“启用或关闭 Windows 功能”。这将打开“Windows 功能”对话框，您可以在其中启用和禁用不同的 Windows 功能。
4. 要在 Windows Server 操作系统上添加/删除功能，请选择“开始”按钮并单击“服务器管理器”图标。这将启动服务器管理器。
5. 选择“管理” \| “删除角色和功能”。
6. 连续单击两次“下一步”。
7. 系统将显示已安装角色的列表。要卸载某个角色，请取消选中该角色旁边的复选标记，然后单击“下一步”。
8. 系统将显示已安装的 Windows 功能列表。要卸载某个功能，请清除其复选框，然后单击“删除”以卸载未选中的角色和功能。

#### 禁用不必要的服务

卸载所有不必要的软件后，将重点转移到系统后台运行的服务或守护进程上。每个服务为操作系统提供一项功能。例如，Windows 系统上常见的服务包括：

- **Print Spooler** 该服务负责 Windows 环境中的打印功能。
- **Workstation** 该服务允许您的系统连接到另一台系统上的共享文件夹。
- **Server** 该服务允许其他系统连接到您系统上的共享文件夹。
- **Messenger** 该服务存在于旧版 Windows 中，当有人使用 `net send` 命令时，负责向其他用户或计算机发送消息。**应禁用此服务。**
- **Remote Desktop Services** 该服务允许用户远程访问计算机并对其进行控制。

关键在于，作为负责加固系统的安全专业人员，您必须获取系统上正在运行的服务列表，然后评估每个服务是否必要。如果某项服务在单台机器上不需要，则通过 Windows 的“服务”控制台禁用该服务；要为多台机器禁用服务，可使用组策略在 Active Directory 域中集中禁用。要在 Windows 中查看服务列表，请执行以下步骤：

1. 在 Windows 系统上，选择“开始” \| “管理工具” \| “服务”。
2. 右键单击要停止的服务，然后选择“停止”。
3. 为确保服务在 Windows 下次启动时不自动运行，必须将“启动类型”设置为“禁用”。右键单击该服务并选择“属性”。这将打开“属性”对话框。
