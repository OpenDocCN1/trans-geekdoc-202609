
# Windows 可执行安装包安装

Windows 可执行安装包安装起来更容易。就像安装其他 Windows 应用程序一样，我们只需选择适当的选项并点击“Next”（下一步）即可完成安装。当安装选项出现时，不要急着进入下一步（此处演示的系统本身是 64 位的）。必须注意的是，勾选“Add Python 3.6 to PATH”将 Python 3.6 添加到环境变量后，以后可以在 Windows 命令提示符下直接方便地启动 Python 的交互式提示符或 Python 命令。选择“Add Python 3.6 to PATH”后，选择自定义安装。当然，也可以选择第一项进行安装，这意味着 Python 安装在 C 盘的用户目录下。但此时您最好知道用户目录是什么，以便将来在必要时能找到安装的 `Python.exe` 文件。按照说明操作，Python 将成功安装在系统中。

## 3. 启动 Python

Python 可以通过两种方式启动。

### 3.1 启动 Python 自带的 IDLE

如果您想运行 Python，可以点击 Windows 桌面上的“Start”（开始）按钮，在出现的搜索框中输入“IDLE”以启动一个 Python 桌面应用程序，快速提供“read-evaluate-print-loop”（读取-求值-打印循环）提示符。IDLE 是 Python 自带的简单 IDE（集成开发环境），是 Python 的图形界面编辑器。IDLE 可被视为集成开发环境的简易版。其功能看似简单，但有助于初学者学习 Python 语言本身。这里提供了一个 REPL 环境，即读取用户输入（“Read”）、求值计算（“Evaluate”）、然后打印结果（“Print”），接着出现提示符“Loop”，从而循环往复。

### 3.2 在 Windows 命令提示符下启动 Python

启动 Python 的另一种方法是通过 Windows 命令提示符运行 Python 程序。在 Windows 搜索框中输入 `cmd`（或按 `Win+R` 键打开运行提示框；注意键盘上的 `Win` 键），或点击开始按钮在弹出的搜索框中输入 `cmd` 并按回车键启动 Windows 命令行窗口。

> **注意：** 此处看到的 `>` 后闪烁的光标是 Windows 提供的命令提示符。安装 Python 时，由于勾选了“Add Python 3.6 to PATH”选项并将安装的 Python 添加到了 Windows 的环境变量中，因此在提示符 `>` 后输入 `python` 即可成功启动 Python。提示符 `>>>` 表示 Python 安装成功且已启动。提示符 `>>>` 是 Python 专用的。

接下来，在第一种或第二种启动模式下执行 `print("Hello Python!")`。如果您想返回 Windows 命令提示符，可以通过按快捷键 `Ctrl+Z` 实现。上述两种方法均为 REPL 形式，适合编写相对较短的程序或命令，具有简单灵活的优点。如果程序功能较多且调用更多模块或包，REPL 形式不太便于维护。

# 第 4 章：Python 数据类型

Python 和其他编程语言使用数据类型在内存中逻辑地存储值。区分带有值的数据有助于操作执行得更快。我们还将在本章讨论其他重要的编程概念，如标识符和保留关键字。

## 数据类型

对象支持的操作及其描述由数据类型决定。因此，了解数据类型对程序员非常重要。Python 语言提供了若干功能丰富的内置数据类型。在解释每种数据类型及其支持的操作之前，通常会检查对象的类型。Python 提供了一个特定的内置函数 `type()` 来执行这些操作。它返回一种称为类型对象的特殊类型，该类型可进一步细分为其他类型。

### 类型检测函数 `type()`

使用 `type()` 函数可快速检查变量的类型，或确定它们能执行的操作类型。

例如：

```
type(example)  # 其中 example = 8
```

我们将通过 `type()` 函数得到输出 `int`。`type()` 函数非常简单。它可以快速帮助我们检测对象的实际类型，无论是通过变量名还是值。

### 空对象 (`None`)

Python 中另一种特殊的类型称为空对象。它只是空的，可以容纳空值。

### 简单数值类型

#### 整数

整数类型 (`int`) 就是整数，用于表示整数，例如 `100`、`2016` 等。整数字面量有四种表示方式：十进制、二进制（以 `0B` 或 `0b` 开头）、八进制（以数字 `0` 开头）和十六进制（以 `0X` 或 `0x` 开头）。

Python 的整数可以表示有限范围，这与系统的最大整数一致。例如，32 位计算机上的整数是 32 位，可表示的数字范围是 `-2³¹` ~ `2³¹-1`。64 位计算机上的整数是 64 位，可表示的数字范围是 `-2⁶³` ~ `2⁶³-1`。

接下来，看一些整数代码示例，如下所示：

```
first = 231283
type(first)
# <type 'int'>
first
# 231283
```

在上述代码中，第 1 行变量 `first` 的值是一个十进制整数，属于 `int` 类型。这在接下来的几行中得到了验证。第 4 到 5 行直接输出 `first` 的值，结果为 `231283`。

十进制数可以使用指定函数转换为二进制、八进制或十六进制。示例代码如下：

```
bin(20)   # 将十进制 20 转换为二进制 '0b10100'
oct(20)   # 将十进制 20 转换为八进制 '0o24'
hex(20)   # 将十进制 20 转换为十六进制 '0x14'
```

#### 长整数

`Long` 是整数的超集，可以表示无限大的整数（实际上仅受计算机虚拟内存大小限制）。长整数字面量后跟字母 `l` 或 `L`（推荐使用大写 `L`）。长整数和整数的操作相同。示例代码如下：

```
first = 13798433 * 3749803498
# <type 'long'>
```

从长远来看，整数和长整数逐渐统一为整数类型。从 Python 2.3 开始，将不再报告整数溢出错误，结果将自动转换为长整数。现在这两种整数类型可以说是无缝结合了，长整数后缀 `L` 变成了可选的。

#### 浮点类型

`Float` 用于表示实数。例如，`3.14`、`9.19` 等都是浮点类型。浮点字面量可以用十进制或科学计数法表示。Python 中的科学计数法表示如下：

```
<实数> e 或 E <整数>
```

其中，`e` 或 `E` 代表以 10 为底，后面的整数代表指数，指数的正负用 `+` 或 `-` 表示，其中 `+` 可以省略。例如，`1.34E3` 表示 `1.34x10³`，`1.5E-3` 表示 `1.5x10^-3`。

示例代码如下：

```
>>> 1.2e5  # 浮点数为 1.2×10⁵
# 120000.0
```

#### 布尔类型

布尔类型可视为一种特殊的整数。布尔数据只有两个值：`True` 和 `False`，分别对应整数的 `1` 和 `0`。每个 Python 对象天生就具有布尔值（`True` 或 `False`），随后可用于布尔测试（如 `if`、`while`）。如果定义了方法 `__nonzero__()` 或 `__len__()` 并返回 `0` 或 `False`，用户定义的类实例返回 `False`。除上述对象外，所有对象的布尔值均为 `True`。本节涉及大量后续讲解的知识。此处你只需知道布尔值只能是 `True` 和 `False`。

#### 复数类型

复数类型用于表示数学中的复数。例如，`5+3j` 和 `-3.4-6.8j` 都是复数类型。Python 中的复数类型是一般计算机语言中没有的数据类型。它具有以下两个特征：

1. 复数由实数和虚数组成，表示为 `real+imagj` 或 `real+imagJ`。
2. 复数的实部和虚部 `imag` 均为浮点类型。

应注意，复数必须包含代表虚部的 `j` 或 `J`，例如 `1j` 和 `1J` 是复数，而 `0.0` 不是复数。即使实部为 `1`，代表虚部的实部也不能省略。

复数的示例代码如下：

```
sample = 6+2j
sample
# (6+2j)
sample.real          # 实部
# 6.0
type(sample.real)
# <class 'float'>
sample.imag          # 虚部
# 2.0
type(sample.imag)
# <class 'float'>
```

## 标识符和关键字

### 标识符

在现实生活中，人们经常用一些名称来标记事物。例如，每种水果都有名称来标记。同样，如果想在程序中表达某事物，需要开发者自定义一些符号和名称，称为标识符。例如，变量名、函数名等都是标识符。

Python 中的标识符由字母、数字和下划线 `_` 组成，其命名方法需遵循特定规则，如下所示：

1. 标识符由字母、下划线和数字组成，且不能以数字开头。

   示例代码如下：

   ```
   FromNo12      # 合法标识符
   From#12       # 非法标识符。标识符不能包含 # 符号。
   2ndObj        # 非法标识符。标识符不能以数字开头。
   ```

2. Python 中的标识符区分大小写。例如，`andy` 和 `Andy` 是不同的标识符。

3. Python 中的标识符不能使用关键字。例如，`if` 不能用作标识符。

此外，为规范标识符的命名，对标识符的命名提出以下建议：

1. **见名知意**：给出有意义的名称，力求一眼就能看出标识符的含义，从而提高代码的可读性。例如，用 `name` 表示定义的名称，用 `student` 表示定义的学生。

2. 命名变量时，许多计算机语言建议使用驼峰命名法。但是，Python 中不推荐使用驼峰命名法（首选 snake_case）。

### 关键字

在 Python 中，具有特殊功能的标识符称为关键字。关键字已被 Python 自身使用，开发者不允许定义与关键字同名的标识符。Python 中的关键字各代表不同的含义。如果想查看关键字信息，可以输入 `help()` 命令进入帮助系统查看。

示例代码如下：

```
>>> help()        # 进入帮助系统
help> keywords    # 查看所有关键字列表
help> return      # 查看关键字 return 的说明
help> quit        # 退出帮助系统
```

# 第 5 章：Python 变量

编程是一项艰巨的任务，需要付出努力才能掌握各种主题。程序员注定要了解计算机如何存储数据。这将使理解其资源并成功整合数据类型以创建理想的应用程序变得容易。对于代码行数较少的程序，这可能看起来很愚蠢，但当你使用先进的第三方库来创建复杂的应用程序时，这将变得至关重要。在上一章中，我们详细讨论了数据类型，在本章中，我们将详细讨论用于重复使用存储数据的变量。

## 变量

在现实生活中，当我们在超市购买东西时，通常需要使用购物车来存放商品。毕竟，商品购买后，我们可以在收银台结账。让我们想象一下，如果你想在程序中对多个数据求和，你需要先存储数据，然后再将数据相加。在 Python 中，需要变量来存储数据。变量可以理解为在超市购物时使用的购物车，它们的类型和值在赋值的那一刻就被初始化了。变量的赋值用等号表示，示例代码如下。我们将在下一章详细讨论赋值操作。

```
Num1 = 257 # Num1 是一个变量，就像一个购物车，存储数据 257
Num2 = 87 # Num2 也是一个变量，存储的数据是 87
Result = num1+num2 # 累加两个“购物车” num1 和 num2 中的数据，然后放入 result 变量
```

在上面的示例中，`num1`、`num2` 和 `result` 是变量。其中，变量 `num1` 和 `num2` 就像购物车，它们存储的数据分别是 257 和 87。变量 `result` 中存储的数据是两个“购物车” `num1` 和 `num2` 中数据的累加和。

## 变量的类型

变量用于存储数据，那么你有没有想过我们应该让变量占用多少空间以及存储什么类型的数据？在解释变量类型之前，让我们看一个生活中的例子。例如，我们需要运输一台电脑。大卡车和小轿车都可以完成。但是，如果我们用大卡车运输一台电脑，就有点大材小用，浪费了大卡车的空间。同样，如果变量用于存储数据，为了充分利用内存空间，我们可以为变量指定不同的类型。

### 5.1 数字类型

Python 中的数字类型包括整数、浮点数和复数类型。示例代码如下：

```
x = 1
x = 3.232
x = 5.65f
```

### 5.2 布尔类型

布尔类型是一种特殊的整数，只有两个值：`True` 和 `False`。如果布尔值被作为数值进行计算，`True` 将被视为整数 1，`False` 视为整数 0。

### 5.3 字符串类型

Python 中的字符串被定义为一组用引号括起来的字符，引号可以是单引号、双引号或三引号（三个连续的单引号或双引号）。字符串有索引规则，第一个字符的索引是 0，第二个字符的索引是 1，依此类推。以下是字符串的示例代码：

```
Str1='God'
Str2="This is great"
Str3='''You are lost'''
```

### 5.4 列表和元组类型

我们可以把列表和元组看作普通的“数组”。它们可以容纳任意数量的任意类型的值，这些值称为元素。区别在于列表中的元素包含在方括号 `[]` 中。元素的数量和值可以随意修改。元组中的元素包含在圆括号 `()` 中。元素不能被修改。让我们看看列表和元组的表示方法。

```
A_list = [1,768,' lost'] # 这是一个列表
A_tuple = (1,2464,' great') # 这是一个元组
```

### 5.5 字典类型

字典是 Python 中的一种映射数据类型，由键值对组成。字典可以存储不同类型的元素，这些元素包含在花括号 `{}` 中。通常，字典的键将以字符串或数字的形式表示，而值可以是任意类型。示例代码如下：

```
Sample = {"name": "Rob", "age": 67} # 这是一个字典
```

在上面的代码中，变量 `Sample` 是字典类型，存储了两个元素，第一个元素的键是 name，值是 Rob。第二个元素的键是 age，值是 67。

在 Python 中，只要定义了变量且变量存储了数据，该变量的数据类型就已经确定了。这是因为系统会根据值自动识别变量的数据类型，开发人员无需显式指定变量的数据类型。如果你想查看变量的类型，可以使用 `type(变量名)`。示例代码如下：

```
>>> dude = 5.234
>>> type(dude) # 使用 type 函数查看类型
<class 'float'>
```

在上面的代码中，变量 `dude` 存储的值是 5.234，系统会根据该值自动判断 `dude` 变量的数据类型为 float。因此，当使用 `type` 函数查看变量 `dude` 的数据类型时，结果是 float。

## Python 中的注释是什么？

Python 中的单行注释以 `#` 开头，示例代码如下：

```
# This is the start
print("Hello, This is the end!" ) # Second comment
```

多行注释可以使用三个引号作为开始和结束符号，这三个引号可以是三个单引号或三个双引号。例如，当进入 `print` 函数的声明文件时，`print` 函数的相关说明都是用三引号注释的。

```
''' Comment here ''' # 单引号注释
""" Comment here """ # 双引号注释
```

## 行和缩进

Python 最重要且讨论最多的特性是它使用不同形式的缩进，而不使用大括号 `{}`。示例代码如下：

```
if {Enter the Boolean entity here}
    print ("This is right") # Get use of a placeholder
else:
    print ("This is wrong") # Get use of a placeholder
```

上面的程序使用了不一致数量的空格进行缩进，这将导致运行错误。

```
if {Enter the Boolean entity here}
    print ("get this")
    print ("This is right")
else:
    print ("Do this")
    PRINT ("This is wrong") # 不一致的缩进将导致运行错误
```

由于上述程序的缩进不一致，执行后将出现缩进错误。

**注意：**

1. 对于第一次使用缩进作为代码块的人来说，他可能会对缩进的宽度感到困惑。这里，我们建议使用 4 个空格。
2. 制表符在不同的文本编辑器中代表不同的空白宽度。如果我们使用的代码需要跨平台使用，建议你不要使用制表符。

Python 通常一次写一条语句一行，但如果语句在语法上太长，就需要换行，这可以通过在语句外部添加一对括号来实现。

## 什么是语句？

当声明变量时，表达式被用来创建和处理对象。如果加入了一些逻辑控制，就形成了语句。也可以说语句包含表达式，因此语句是 Python 程序最基础的基础设施。

## Python 赋值语句

学习 Python 中的赋值语句，能让学习其他语句变得更容易。学习 Python 赋值语句主要是为了掌握并理解其逻辑。
