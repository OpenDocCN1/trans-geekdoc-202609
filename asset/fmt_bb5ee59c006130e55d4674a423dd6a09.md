顺序覆盖算法的应用范围比上一节所暗示的要得多。可能最重要的是，该技术可以用于谓词逻辑中表示的概念归纳。

### 1. 谓词与递归

#### 谓词：比属性更高的表达能力

属性值逻辑（attribute-value logic）的一个严重局限性是它不够灵活，无法捕捉数据之间的某些关系。例如，`y` 位于 `x` 和 `z` 之间的这一事实可以使用谓词 `between(x,y,z)` 来描述——更准确地说，谓词是项“between”，而 `(x,y,z)` 是该谓词参数的列表。

读者会同意，试图通过属性及其取值来表达相同的关系至少是非常困难的。属性可以被视为单参数谓词的特例。例如，对于给定的示例 `x`，形状是圆形的这一事实可以写成 `circular(x)`。但在处理具有更多参数的谓词时，这种类比就不再显而易见了。

#### 谓词逻辑中的规则归纳

这是一个规则示例，表示如果 `x` 是 `y` 的父母，且同时 `x` 是一个女性，那么这个父母实际上是 `y` 的母亲：

```
if parent(x,y) AND female(x) then mother(x,y)
```

我们可以看到，该规则与我们上面看到的规则 `R1` 和 `R2` 结构相同：前件中的条件列表后跟一个结论。事实上，这里也可以使用相同的顺序覆盖算法。但有一点不同：在选择要添加到前件的候选谓词时，我们不能忘记如果改变参数，谓词的含义也会改变。例如，如果将 `parent(x,y)` 替换为 `parent(x,z)`，之前规则的含义就会改变。

#### 规则允许递归定义

规则可以比上一节更有趣。例如，它们可以是递归的。为了说明这一点，考虑以下规则：

```
if parent(x,y) then ancestor(x,y)
```

注意这是 `ancestor`（祖先）的定义。如果我们还有后续：

```
if parent(x,z) AND ancestor(z,y) then ancestor(x,y)
```
