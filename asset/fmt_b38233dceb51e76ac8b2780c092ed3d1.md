
回到`chap9.php`并重新加载页面。你得到了什么？输出中多了一句`Fatal error: Uncaught Error: Cannot access private property Movie::$id...`，对吧？这是因为`$id`是一个私有（private）属性。私有类成员只能在声明它们的类内部进行访问，我们不允许在`chap9.php`中访问`$id`属性，因为它在`Movie`类的外部。这就是访问修饰符的工作原理；它们本质上控制了我们是否可以在声明该成员的类外部访问特定的类成员。理解了吗？

在 PHP 中，访问修饰符对于属性是强制性的，但对于方法来说是可选的。如果我们没有为属性声明修饰符，将会得到错误消息。如果我们不为方法声明修饰符，默认修饰符为`public`。从 PHP `7.1.0`开始，我们还可以为类常量添加访问修饰符。如果我们不为常量声明修饰符，默认是`public`。除了`public`和`private`成员外，PHP 还有`protected`（保护）成员。这些成员可以在声明它们的类内部以及继承该类的任何子类中访问。我们将在下一章讨论`protected`成员和继承。

此时，你们中的一些人可能疑惑为什么我们想让类成员变为`private`。例如，如果我们无法访问`$id`属性，为什么要费劲声明它呢？原因是，虽然私有成员不能在声明它的类外部访问，但在类内部是可以访问的。例如，我们可以在`Movie`类内部写一个函数，根据`$id`属性显示页面标题。要查看它是如何工作的，请将以下代码添加到`Movie.php`中（在`conversion()`方法之后，`Movie`类的结束大括号之前）：

```php
public function displayHeading($tag){ if (substr($this->id, 0, 1) == 'N') return "<$tag>Movies</$tag>"; else return "<$tag>Award Winning Movies</$tag>"; }
```

此方法使用内置的`substr()`函数检查`$id`是否以'N'开头。如果是，它将返回一个包含“Movies”一词的 HTML 元素（由参数`$tag`定义为`<tag>Movies</tag>`）；如果不是，它将返回一个包含“Award Winning Movies”一词的元素。接下来，将`chap9.php`中的行`echo $mov1->id.'<BR>';`替换为`echo $mov1->displayHeading('H1');`。由于`displayHeading()`是一个`public`方法，我们在类外部访问它没有问题。如果你现在运行代码，将看到“Movies”作为一个`<h1>`元素显示出来。理解了吗？

## 9.6 Getter 和 Setter

在上一节节中，我们讨论了`public`和`private`类成员之间的区别。只要可能，如果类外部的代码不需要访问这些成员，我们就应该将类成员声明为`private`。这种防止外部代码不必要访问类成员的行为被称为封装（encapsulation）。封装使我们能够轻松更改类成员，而不影响类外部的代码。例如，如果我们想将`Movie`类中的`$id`属性名称改为`$movieID`，我们只需要在`Movie`类内部进行更改，类外的任何代码都不会受到影响。这是将类属性声明为`private`的优点之一。

将类属性声明为`private`的另一个优点是它可以防止对对象属性进行未经授权的修改。为了了解为什么，请将以下代码添加到`chap9.php`中：

```php
$mov1->rentalPrice = -20;
echo $mov1->rentalPrice.'<BR>';
```

这里，我们首先将`-20`分配给`$mov1`的`$rentalPrice`属性。接下来，我们使用`echo`输出它的值。如果你运行上面的代码，将得到输出 -20。如你所示，我们成功地将`$mov1`的`$rentalPrice`属性更改为 -20。这是因为`$rentalPrice`是一个`public`属性。因此，我们可以在`Movie`类之外访问它并将其更改为任何值。这不是想要的，因为租金不应该是负数。

为了防止此类修改发生，我们不应该将`$rentalPrice`属性声明为`public`。相反，我们应该将其声明为`private`。尝试在`Movie.php`中将`$rentalPrice`属性改为`private`并再次运行`chap9.php`，你得到了什么？你得到了类似下面的输出，对吧？

`Fatal error: Uncaught Error: Cannot access private property Movie::$rentalPrice in…`

由于它现在是`private`属性，我们不再允许访问和修改`$mov1`的`$rentalPrice`属性。

只要可能，我们应该始终将类属性声明为`private`；这有助于防止对它们的任何未经授权的访问或修改。然而，如果我们将所有类属性声明为`private`，如果类外部的代码需要访问或修改这些属性会怎样？在这种情况下，我们可以使用 getters 和 setters。这些魔方法允许我们对`private`和`protected`属性提供限制且受控的访问。要查看其原理，请将以下方法添加到`Movie.php`（在`displayHeading()`方法之后，`Movie`类的结束大括号之前）：

```php
public function get($propertyRequested){ if ($propertyRequested == 'id') return 'You do not have permission to access id.<BR>'; else return $this->$propertyRequested; }
public function set($propertyToModify, $value){ if ($propertyToModify == 'rentalPrice' && $value > $this->rentalPrice) $this->rentalPrice = $value; else echo 'Failed to modify '.$propertyToModify.'<BR>'; }
```

`get()`方法被称为 getter；它控制哪些属性可以被访问，并且有一个参数`$propertyRequested`，该参数存储我们想要访问的属性名称。在`get()`方法内部，我们使用`if-else`语句检查`$propertyRequested`是否等于'id'。如果是，返回“You do not have permission to access id.”；否则返回`$this->$propertyRequested`。

接下来`set()`方法被称为 setter；它控制哪些属性可以被修改。它有两个参数；第一个存储要修改的属性名称（`propertyToModify`），第二个存储要赋值给该属性的新值（`value`）。在我们的`set()`方法内部，我们使用`if-else`语句检查`$propertyToModify`是否等于'rentalPrice'且`$value`是否大于`$this->rentalPrice`。如果两个条件都满足，允许我们修改`$rentalPrice`；否则，输出“Failed to modify [属性名]”。理解了吗？很好！现在，让我们看看如何使用 getters 和 setters。要做到这一点，我们只需使用`->`运算符，后跟属性名。在后台，只要我们定义了`get()`和`set()`方法，PHP 就会自动调用这些魔方法。

首先，让我们将`Movie`类中所有属性的访问修饰符改为`private`。接下来，再次加载`chap9.php`。记得之前尝试将`$mov1`的`$rentalPrice`属性更改为 -20 并得到了致命错误吗？如果你现在加载`chap9.php`，将不再得到错误。相反，你将得到以下输出：

`Failed to modify rentalPrice`

`4.99`

这是因为我们定义了`get()`和`set()`方法。当我们尝试修改`$rentalPrice`属性的值时，PHP 会自动调用`set()`方法。由于 -20 小于当前的`$rentalPrice`值（即 4.99），我们的`set()`方法阻止了我们更改`$rentalPrice`值。当我们使用`echo`语句输出`$rentalPrice`值时，`get()`方法为提供了 4.99 作为输出。

接下来，将以下代码添加到`chap9.php`并再次运行页面：

```php
$mov1->id = 'A12387';
echo $mov1->id;
```

你将得到

`Failed to modify id`

你没有权限访问已添加到输出中的 id。在这里，`set()`方法阻止了我们修改`$id`属性。同样，`get()`方法阻止了我们访问`$id`属性。最后但同样重要的一是，将以下代码添加到`chap9.php`并运行该页面：

```php
$mov1->rentalPrice = 5.99;
echo $mov1->rentalPrice;
```

你会在输出中看到增加了 5.99。在这里，我们尝试将`$rentalPrice`的值改为`5.99`。由于`5.99`大于当前的`$rentalPrice`值，`set()`方法允许我们进行此更改。当我们再次使用`echo`语句输出`$rentalPrice`的值时，`get()`方法返回了 5.99 作为输出。

明白了吗？太棒了！

## 9.7 输出对象的字符串表示

除了`set()`和`get()`方法之外，PHP 中另一个常用的魔术方法是`toString()`方法。让我们在`Movie`类中添加一个。

将以下代码添加到`Movie.php`中（位于`set()`方法之后，`Movie`类的结束括号之前）：

```php
public function toString(){
    return
    'Discount = '.self::DISCOUNT.'%'.
    '<BR>Id = '.$this->id.
    '<BR>Title = '.$this->title.
    '<BR>Rental Price (USD) = '.$this->rentalPrice; }
```

此方法简单地返回一个包含`Movie`类相关信息的字符串。注意到上面方法中的新关键字`self`吗？这个关键字用于访问早先在类中定义的`DISCOUNT`常量。之前我们学过，为了访问定义该常量的类之外的常量，可以使用类名或对象名。例如，在`chap9.php`中，我们使用`$mov1::DISCOUNT`、`$mov2::DISCOUNT`和`Movie::DISCOUNT`来访问`DISCOUNT`常量。如果我们想在`Movie`内部内部（即在定义它的类内部）访问这个常量呢？要做到这一点，我们可以使用类名或`self`关键字。在上面的`toString()`方法中，我们使用了`self`关键字。或者，我们也可以使用类名`Movie::DISCOUNT`。在声明`toString()`方法后，我们就可以用它来打印`Movie`类对象的字符串表示。要实现这一点，我们只需使用`echo`语句即可。为了查看它是如何工作的，将以下几行添加到`chap9.php`并再次运行页面：

```php
echo '<BR>';
echo $mov1;
```

你会在输出中看到 Discount = 10%

Id = N0001

Title = Lusso

Rental Price (USD) = 5.99

# 第 10 章：继承

在上一章节中，我们涵盖了面向对象编程（OOP）的基础知识。OOP 中的一些概念对初学者来说可能有些难以理解。如果这是你第一次接触 OOP，你可能需要多读几遍之前的章节以完全掌握这些概念。一旦你熟悉了第 9 章涵盖的主题，我们就可以开始学习 OOP 中一个更高级但同样重要的概念——继承。正如其名所示，继承涉及到两个或多个类之间的关系。通过继承，可以声明类，使得其中一个类是另一个类的子类（也称为子类），而另一个被称为父类或基类。这使我们能够将相关的类组合在一起。解释继承最简单的方法就是看例子。

## 10.1 编写子类

我们将使用第 9 章中的`Movie`类作为父类来进行说明。打开编辑器并创建一个名为`AwardWinningMovie.php`的新文件。在 htdocs 文件夹中将以下代码添加到`AwardWinningMovie.php`：

```php
<?php
include "Movie.php";

class AwardWinningMovie extends Movie{ private $award;

    public function construct($id, $title, $rentalPrice, $award){
        parent::construct($id, $title, $rentalPrice);
        this->award = $award;
    }

    public function recommend($country){
        switch ($this->award){
            case 'Best Picture':
                $others = 'The Rail';
                break;
            case 'Best Actor':
                $others = '1729';
                break;
            default:
                $others = 'And so begins';
        } return
        'You might like:<BR>'.
        '<BR>Title = '.$others;
    }
}
```

在这里，我们使用了`Movie`类作为父类。现在，我们在`chap9.php`中添加以下代码并运行：

```php
$mov1 = new AwardWinningMovie('N0001', 'Lusso', 5.99, 'Best Picture');

echo $mov1;
```

你会在输出中看到 Discount = 10%

Id = N0001

Title = The Rail

Rental Price (USD) = 5.99

作为输出。简单直接吧？

## 10.3 重新回顾访问修饰符

很好！现在让我们重新回顾访问修饰符的概念。之前我们提到，当一个类扩展另一个类时，它会继承所扩展类的所有公共（public）和受保护（protected）类成员。这意味着它可以直接访问这些成员而不受任何限制。然而，这并不适用于私有（private）类成员。子类不允许直接访问父类的私有成员。

为了理解这意味着，尝试将`Movie`类中的`conversion()`方法更改为私有方法。换句话说，将`Movie.php`中的行：

```php
public function conversion($country)
```

改为：

```php
private function conversion($country)
```

接下来，再次加载`chap10.php`。你得到了什么？你会收到类似下面输出的错误信息，对吧？

`Fatal error: Uncaught Error: Call to private method Movie::conversion() from context 'AwardWinningMovie'...`

这是因为当`conversion()`是私有方法时，我们不允许在定义它的类之外（即`Movie`类之外）直接访问它。因此，`AwardWinningMovie`类中的`recommend()`方法不允许访问它。

接下来，将`conversion()`更改为受保护方法并再次加载`chap10.php`。现在一切都正常了，对吧？这是因为子类允许直接访问父类中的受保护成员。因此，`AwardWinningMovie`类中的`recommend()`方法现在允许访问`Movie`类中的`conversion()`方法。

明白了吗？太棒了！将`conversion()`更改为受保护方法后，注意我们只允许在声明它的类以及继承该类的任何子类内部直接访问它。换句话说，我们只能在`Movie`和`AwardWinningMovie`类内部直接访问它。

回想起我们之前在`chap9.php`中访问该方法了吗？当`conversion()`是公共方法时，这是没问题的。现在它是一个受保护方法，如果你再次加载`chap9.php`，将会得到错误。如果你想直接访问`chap9.php`中的`conversion()`方法，你必须将其改回公共方法。

```php
echo $awm->displayHeading('H1');
```
