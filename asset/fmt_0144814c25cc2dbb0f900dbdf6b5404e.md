
目前，大多数高效 `SR` 模型 [16,17] 采用特征蒸馏技术来减少参数数量。然而，这种方法对硬件不友好，并且显著降低了推理速度 [19]。为了克服这些局限性，我们为轻量级图像 `SR` 提出了一种带有高效变换器的残差网络（`RNET`）。这引入了一种称为“局部残差连接”的新方法。该方法在保持硬件友好性的同时，有效地平衡了参数数量和恢复性能。为了实现优越的视觉质量，我们设计了一个混合特征提取块（`HFE B`）；它由三个主要部分组成：(1) 使用蓝图可分离卷积（`BSCov`）[20] 构建的局部特征提取模块，这是深度可分离卷积（`DSConv`）[21] 的改进版，通过更好地利用内核内相关性来实现高效分离并减少冗余；(2) 一个注意力模块，由增强空间注意力（`ESA`）[16] 和对比感知通道注意力（`CCA`）[22] 组成，以增强模型能力；以及 (3) 一个高效变换器模块，包括执行跨通道特征交互的多 `BSCov` 头转置注意力（`MBTA`）和门控 `BSCov` 前馈网络（`GBFN`）。该变换器模块具有线性复杂度，大大减少了计算压力，使网络能够更好地聚合长距离特征。通过整合这些组件，我们的 `RNET` 显著提高了超分辨率任务的性能，同时生成了视觉上吸引人且细节丰富的恢复图像。

我们的主要贡献如下：

- 我们提出了一个利用 `BSCov` 和两个高效注意力模块的局部特征提取模块，并展示了其在 `SR` 任务中的有效性。
- 我们提出了一个高效变换器模块，可以在不显著增加计算复杂性的情况下增强全局特征提取。该模块有助于生成更多细节的恢复图像。
- 我们提出了一种局部残差连接策略，这与常用的特征蒸馏方法不同。该策略保持了低参数数量并取得了优异的性能。

## 2. 相关工作

### 2.1. 基于 CNN 的图像超分辨率

近年来，深度卷积神经网络（`CNN`）在底层视觉任务中的成功应用已被广泛认可 [23,24]。特别是，`SRCNN` [2] 首次将深度卷积神经网络引入图像 `SR` 任务；作者使用了一个开创性的三层卷积神经网络来映射 `LR` 和 `HR` 图像之间的相关性；他们取得了令人鼓舞的结果，并为单图像超分辨率任务提供了新的方法。随后，提出了一些进一步的方法以增强卷积神经网络在 `SR` 任务中的能力，其中，增加网络深度和使用残差连接被广泛认为是有效的方法。`Kim` 等人 [3] 提出了 `VDSR`，

该研究使用一个19层卷积神经网络来实现单图像超分辨率重建（`SISR`）。`Lim` 等人 [12] 修改了 `SRResNet` [25] 以构建一个更深、更宽的残差网络，称为 `EDSR`，该网络拥有大量可学习参数，极大地提升了超分辨率性能，并作为基线启发了许多后续工作 [16,26]。例如，`Zhang` 等人 [4] 在原始残差模块中添加了密集块，随后 `Zhang` 等人 [26] 使用残差通道注意力机制进一步增强了网络能力。在过去五年中，多项研究探索了不同的网络框架，如循环神经网络 [15,16]、图神经网络 [27] 和生成对抗网络（`GANs`）[25,28]。具体而言，`Xintao` 等人 [28] 使用具有残差中残差结构的网络，并通过 `GAN` 的训练策略成功恢复了更真实的纹理细节信息。

### 2.2. 高效超分辨率

现有的超分辨率模型通常需要引入巨大的计算成本以提升性能，这限制了这些方法的实际应用。为了解决这一问题，许多轻量级网络被设计出来。例如，深度循环卷积网络（`DRCN`）[29] 和深度循环残差网络（`DRRN`）[30] 通过引入递归层来共享参数从而减少计算量。`Lai` 等人 [31] 将使用拉普拉斯金字塔的传统图像算法与深度学习相结合，实现了实时重建。`Tai` 等人 [32] 提出了 `MemNet`，它使用门控机制将深层特征与浅层信息联系起来。`Zhang` 等人 [33] 使用重参数化模块构建了一个可用于移动设备的快速推理模型。`Hui` 等人 [17] 提出的 `IDN` 通过使用组卷积并组合短期和长期特征来压缩模型大小。随后，`Hui` 等人 [22] 提出了一种基于 `IDN` 的信息蒸馏策略，通过分割操作逐步提取分层特征，进一步提高了模型效率。基于此工作，`Liu` 等人 [16] 进一步改进了 `IMDN` 中的多重信息蒸馏模块，取得了更好的结果。此外，`Han` 等人 [34] 提出了自校准卷积和像素聚焦模块，在不增加复杂度的情况下实现了性能提升。`Wang` 等人 [35] 提出了一种轻量级上下文变换层（`CTL`），并基于此构建了上下文变换网络（`CTN`）。`CTN` 在轻量级遥感图像超分辨率任务和自然图像超分辨率任务中均取得了良好效果。

### 2.3. 视觉Transformer

`Transformer` [5] 在自然语言处理领域的成功也引起了计算机视觉界的关注。`Transformer` 的核心思想是自注意力机制，它捕捉序列元素之间的长期信息。`Transformer` 已成功应用于许多先进的视觉任务，包括图像分类 [6]、目标检测 [36] 和分割 [37]。尽管 `Transformer` 在研究图像像素之间的长期依赖关系方面展现了强大的能力，但仍有大量工作表明卷积可以帮助 `Transformer` 实现更好的视觉表示 [38,39]。`ViT` [6] 是第一个用 `Transformer` 替代卷积的工作。为了生成序列元素，`ViT` 将二维图像块展平为向量并输入 `Transformer`。此外，`Transformer` 也被引入到底层视觉任务中 [8,9]，特别是超分辨率 [10,11]。`Liang` 等人 [11] 提出了 `SwinIR`，首次将 `Swin Transformer` [7] 引入 `SISR`，并展示了 `Transformer` 在超分辨率任务中的巨大潜力。`Wang` 等人 [40] 提出了细节保留 `Transformer`（`DPT`），引入了一种考虑全局空间-角度关系的新自注意力机制。`DPT` 已成为光场图像超分辨率领域的最先进方法。目前，大多数 `ViT` 将图像分割成一系列块，然后通过自注意力机制学习它们之间的依赖关系。这有助于网络建立优秀的长程或全局依赖。然而，自注意力机制带来了巨大的计算量和 `GPU` 资源消耗。因此，设计高效的视觉 `Transformer` 已成为近年来一个热门且开放的研究话题。

## 3. 方法

在本节中，我们首先介绍带有高效 `Transformer` 的残差网络（`RNET`）的整体架构。然后，我们介绍混合特征提取块（`HFEB`），它能够高效地提取图像的纹理信息。最后，我们介绍高效 `Transformer`（`ET`）模块。

### 3.1. 网络结构

我们提出的带有高效 `Transformer` 的残差网络（`RNET`）的整体结构如图1所示。`RNET` 由三个主要部分组成：浅层特征提取模块、深层特征提取模块和图像重建模块。

![](img/e4200cc4308edaf8913e513b0f96dbb6_78_0.png)

关于浅层特征提取模块：首先，给定输入的 low-resolution image `I_{LR} ∈ R^{H × W × G_{in}}`，我们使用 `BSConv` 获得浅层特征 `F_0 ∈ R^{H × W × C}`。`BSConv` 的结构如图3所示。该过程可以表示为：

```
F_0 = H_{BSConv}(I_{LR})  (1)
```

其中 `H_{BSConv}(·)` 表示 `BSConv`。接下来，深层特征提取模块由多个直接连接的混合特征提取块（`HFEB`）组成，该过程可以表示为：

```
F_n = H_{HFEB}^n(F_{n-1})  (2)
```

其中 `H_{HFEB}^n(·)` 表示第 n 个 `HFEB`。`F_{n-1}` 和 `F_n` 分别表示第 n 个 `HFEB` 的输入特征和输出特征。此外，我们使用一层 `BSConv` `H_{BSConv}(·)` 来平滑深度特征。最后，图像重建模块 `H_{Rec}(·)` 由带有像素乱序的 `3 × 3` 标准卷积组成；其目的是上采样融合特征并将其恢复到高分辨率（`HR`）尺寸。最终，我们通过添加全局残差连接来融合浅层和深层特征。该过程可以表示为：

```
I_{SR} = H_{Rec}(H_{BSConv}(F_n) + F_0)  (3)
```

其中 `I_{SR}` 表示通过上述网络恢复的最终图像。

### 3.2. 混合特征提取块

在本小节中，我们介绍混合特征提取块（`HFEB`）：该模块的具体结构如图2所示。我们使用 `BSConv` 代替传统卷积，从而大大减少了计算负担。此外，我们使用局部残差连接代替可分离蒸馏结构。`Kong` 等人 [19] 证明，局部残差结构可以在保持模型能力的同时显著减少推理时间。

![](img/e4200cc4308edaf8913e513b0f96dbb6_79_0.png)

图 2. (a) `CCA` 块的结构。(b) `ET` 块的结构。(c) 我们的混合特征提取块（`HFEB`）的结构。(d) `ESA` 块的结构。

`HFEB` 分为三个主要部分来提取图像特征：即局部特征提取模块、混合注意力机制和高效 `Transformer`。首先，我们使用几个堆叠的 `BSConv` 和 `LeakyRelu` 层来提取局部特征。具体而言，每个 `BSConv` 层都配备了一个 `LeakyRelu` 激活函数。给定输入特征 `F_{in}`，这部分可以描述为：

```
F_{LF1} = σ(H_{BSConv}(F_{in}))
F_{LF2} = σ(H_{BSConv}(F_{LF1}))
F_{LF3} = σ(H_{BSConv}(F_{LF2}))
F_{out1} = F_{in} + F_{LF3}   (4)
```

其中 `F_{LFn}` 表示第 n 个 `BSConv` 和 `LeakyRelu` 组合模块的输出，`σ(·)` 表示 `LeakyRelu` 激活函数，`H_{BSConv}(·)` 表示 `BSConv` 操作，`F_{out1}` 表示整个局部特征提取模块的输出。

接下来，为了获取更详细的信息，我们首先将局部特征部分的输出通过一个 `1 × 1` 卷积，然后将其送入混合注意力模块。该模块由轻量级增强空间注意力（`ESA`）块 [16] 和对比感知通道注意力（`CCA`）块 [22] 组成，这个过程可以表述为：

```
F_{out2} = H_{CCA}(H_{ESA}(H_{conv1×1}(F_{out1})))   (5)
```

`H_{CCA}(·)` 和 `H_{ESA}(·)` 分别代表 `CCA` 块和 `ESA` 块。`H_{conv1×1}(·)` 代表 `1 × 1` 卷积。`F_{out2}` 代表混合注意力模块的输出。

最后，为了更好地聚合全局信息，我们将混合注意力模块的输出输入到高效 `Transformer`（`ET`）模块。该模块由多 `BSConv` 头转置注意力（`MBTA`）和门控 `BSConv` 前馈网络（`GBFN`）组成；它在保持 `Transformer` 全局特征提取能力的同时大大减少了计算负担。整个过程可以描述为：

```
F_{out} = H_{ET}(F_{out2}) = H_{GBFN}((H_{MBTA}(F_{out2})))   (6)
```

其中 `H_{ET}(·)` 代表 `ET` 块。`H_{GBFN}(·)` 和 `H_{MBTA}(·)` 分别代表 `GBFN` 和 `MBTA`。`F_{out}` 代表整个 `HFEB` 的输出。

#### 3.2.1. BSConv

`BSConv` 是一种将标准卷积分解为逐点 `1 × 1` 卷积和深度卷积的方法。它可以被视为可分离卷积的一种变体。`BSConv` 的结构如3所示。与可分离卷积类似，它比标准卷积具有更小的计算负担，且研究表明 `BSConv` 在大多数情况下比标准卷积取得更好的结果 [20]。

![](img/e4200cc4308edaf8913e513b0f96dbb6_80_0.png)

**图 3.** `BSConv` 的结构，其中 `DWConv` 代表深度卷积。

#### 3.2.2. ESA 和 CCA

`ESA` 和 `CCA` 模块在超分辨率（`SR`）任务中的有效性已得到证明 [16,22]，因此我们将这两个模块引入我们的 `HFEB` 中。`ESA` 的结构如2d所示。它使用 `1 × 1` 卷积来减少输入通道，并使用步幅卷积和步幅最大池化来减小空间尺寸。然后，为了获得更好的结果和更高的效率，使用一组 `BSConv` 层代替标准卷积来提取特征。特征通过 `1 × 1` 卷积进行处理以恢复原始通道。最后，`Sigmoid` 函数生成注意力矩阵并与输入特征相乘。为了实现空间和通道信息的双重获取，我们在 `ESA` 模块之后添加了 `CCA` 模块 [22]。`CCA` 模块的结构如2a所示；该结构代表了一种专为低级图像处理设计的通道注意力模块。与传统的通道注意力模块不同，`CCA` 采用标准差和均值的总和代替全局池化。这一修改被证明有利于增强图像的细节和纹理结构信息。4展示了加入这两个模块前后特征图的可视化结果。在集成 `ESA` 和 `CCA` 模块后，本文提出的 `HFEB` 表现出提取更清晰边缘和纹理信息的能力。这两个注意力模块的引入使我们的网络能够进一步提高单图像超分辨率（`SISR`）的准确性。

### 3.3. 高效Transformer

受 `Restormer` [41] 的启发，为了实现更好的全局建模能力，我们采用了一种高效 `Transformer` 模块，如2b所示，由 `MBTA` 和 `GBFN` 组成，以进一步提高网络性能。具体结构如5所示。

![](img/e4200cc4308edaf8913e513b0f96dbb6_81_0.png)

**图 5.** 我们的高效 `Transformer` (`ET`) 块架构。(a) `ET` 中 `MBTA` 的架构。(b) `ET` 中 `GBFN` 的架构。

#### 3.3.1. 多BSCConv头转置注意力 (MBTA)

传统 `Transformer` 中的计算成本主要来自自注意力层。键-查询点积交互的时间和内存复杂度随输入的空间分辨率呈二次方增长。另一方面，`MBTA` 通过使用跨通道而非跨空间的自注意力，大大降低了计算开销；具体结构如5a所示。`MBTA` 的过程描述如下：对于输入张量 `X ∈ R^{H × W × C}`，我们首先通过 `1 × 1` 逐点卷积实现跨通道的像素级特征聚合，随后使用 `3 × 3` `BSCconv` 提取通道上下文信息。使用深度卷积的优点在于，它能在生成全局特征图之前更好地关注局部上下文。查询（`Q`）、键（`K`）和值（`V`）由上述过程生成。该过程可以公式化为：

```
Q = H^{q}_{BSCconv}(H^{q}_{p}(LN(X)))
K = H^{k}_{BSCconv}(H^{k}_{p}(LN(X)))
V = H^{v}_{BSCconv}(H^{v}_{p}(LN(X)))   (7)
```

其中 `H_{BSCconv}(·)` 表示 `BSCConv`，`H_{p}(·)` 表示 `1 × 1` 逐点卷积，而 `LN` 表示层归一化。

接下来，通过重塑查询和键投影并通过其点积生成大小为 `R^{C × C}` 的转置注意力映射。该过程可以公式化为：

```
Attention(Q,K,V) = V · Softmax(K · Q/α)
\hat{X} = H_{p}(Attention(Q,K,V)) + X   (8)
```

其中 `Softmax` 表示生成概率映射的 softmax 函数，`α` 是一个可学习的缩放参数，用于控制应用 softmax 函数前 `K` 和 `Q` 点积的大小，而 `H_{p}(·)` 表示逐点 `1 × 1` 卷积。

上述操作成功地将 `Transformer` 的复杂度降低为线性通道复杂度，从而有效地降低了计算成本。

#### 3.3.2. 门控BSConv前馈网络 (GBFN)

为了进一步恢复结构信息，高效 `Transformer` 采用了门控 `BSConv` 前馈网络（`GBFN`）。这个前馈网络有两个重要组件：门控机制和 `BSConv`。与 `MBTA` 类似，我们使用 `BSConv` 来学习空间相邻像素之间的局部信息，这对于图像恢复和重建中的局部相似性信息学习非常有效。具体结构如5b所示。该过程可以公式化如下：

```
X_{gate} = φ(H_{BSCONV}^{H}(H_{p} LN(X))) ⊙ H_{BSCONV}^{S}(H_{p} LN(X))
\tilde{X} = H_{p}(X_{gate})   (9)
```

其中 `φ` 表示 `GELU` 函数，`LN` 表示层归一化，`⊙` 表示逐元素乘法，而 `H_{p}(·)` 表示逐点 `1 × 1` 卷积。

总的来说，`GBFN` 通过流水线中各自的层级控制信息流，从而允许每一层关注与其他层互补的精细细节。与 `MBTA` 相比，`GBFN` 能够提供更丰富的上下文信息。

### 3.4. 损失函数

我们的网络使用平均绝对误差（`MAE`，也称为 `L1`）损失函数进行优化，以便于公平比较。损失函数描述如下：给定包含若干对 `LR` 和 `HR` 输入的训练集 `{I_{LR}^{i}, I_{HR}^{i}}`，训练目标是最小化 `L1` 损失函数：

```
L(Θ) = 1/N Σ_{i=1}^{n} ||H_{model}(I_{LR}^{i}) - I_{HR}^{i}||_{1}   (10)
```
