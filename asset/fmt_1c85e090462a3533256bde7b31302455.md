
通向时变建模的一种途径是考虑结构固定但参数随时间变化的图模型，称为*切换线性动态系统*（SLDS）。此类模型满足那些线性动态模型从一种参数设置跳变到另一种参数设置的系统需求；因此，未观测变量同时具有离散和连续的性质。在时刻 `n`，一个切换离散变量 `s[n] ∈ {1, 2, …, M}` 从 `M` 个可用的（子）系统中选择单个 LDS。`s[n]` 的动态特性也被建模为符合马尔可夫哲学，且从一个 LDS 到另一个 LDS 的转移由 `P(s[n] | s[n − 1])` 控制。该问题由来已久，其起源可追溯至卡尔曼开创性论文发表后不久 [35]；例如，参见 [18] 和 [2,3] 以获取关于此类网络中近似推理任务相关技术的较新综述。

另一种途径是考虑结构和参数均随时间变化。一种方法是采用准平稳原理，假设数据序列在时间上是分段平稳的（例如，[12,54,66]）。非平稳性被构想为一系列先前通过预分段子区间学习得到的平稳模型的级联。另一种方法假设结构和参数在持续变化（例如，[42,79]）。后一种情况的一个例子是贝叶斯网络，其中每个节点的父节点以及定义条件分布的参数均随时间变化。采用一个单独的变量来定义每个时刻的结构；即有向连接边的集合。该概念在图 16.23 中进行了说明。该方法已被应用于主动摄像头跟踪任务 [79]。

![Figure 16.22 用于变分近似框架的包含三条链的 FHMM 简化图结构。与观测变量相关的节点被解除链接。](img/gr022.jpg)

图 16.22 用于变分近似框架的包含三条链的 FHMM 简化图结构。与观测变量相关的节点被解除链接。

## 16.7 学习图模型

学习图模型包含两个部分。给定一定数量的观测值，必须同时确定图结构及其相关参数。

### 16.7.1 参数估计

一旦确定了图模型，就必须估计未知参数。例如，在一个涉及离散变量的贝叶斯网络中，必须估计条件概率的值。在第 16.5 节中，介绍了在 HMM 背景下学习未知参数的情况。关键点在于最大化观测输出变量上的联合 PDF。这是用于不同图结构参数估计的最流行准则之一。在 HMM 情况下，部分变量是未观测的，因此引入了 EM 算法。如果图的所有变量均可观测，则参数学习任务就变成了一个典型的最大似然问题。更具体地，考虑一个具有 `l` 个节点的网络，这些节点代表变量 `x[1], …, x[l]`，它们被紧凑地写为随机向量 `x`。另设 `x[1], x[2], …, x[N]` 为一组观测值；则

```
θ̂ = arg max_θ p(x₁, x₂, …, x_N; θ)
```

其中 `θ` 包含图中的所有参数。如果涉及潜在/隐藏变量，则必须将它们边缘化掉。第 12 章和第 13 章中讨论的任何参数估计技术均可使用。此外，还可以利用图的特殊结构（即潜在的独立性）来简化计算。在 HMM 情况下，其贝叶斯网络结构被利用，将乘积求和算法引入其中。除了最大似然法，还可以采用与参数估计/推断相关的任何其他方法。例如，可以在未知参数上施加先验 `p(θ)` 并求助于 MAP 估计。此外，假设参数为随机变量，也可以采用完全贝叶斯假设。这种做法预设未知参数已作为额外节点包含在网络中，并适当链接到它们所影响的变量节点。事实上，这正是我们在 图 13.2 中所做的，尽管当时我们尚未谈论图模型（另见 图 16.24）。注意，在这种情况下，为了对网络变量执行任何推断，必须将参数边缘化掉。例如，假设我们的 `l` 个变量对应于贝叶斯网络的节点，其中局部条件分布为

```
p(x[i] | Pa[i]; θ[i]), i = 1, 2, …, l
```

取决于参数 `θ[i]`。此外，假设（随机）参数 `θ[i]`，`i = 1, 2, …, l`，是相互独立的。那么变量上的联合分布由下式给出：

```
p(x_1,x_2,...,x_l) = ∏_{i = 1}^{l} ∫_{θ_i} p(x_i|Pa_i;θ_i) p(θ_i) dθ_i.
```

使用方便的先验，例如共轭先验，可以显著简化计算；我们已在第 12 章和第 13 章中演示了此类示例。

![图 16.24 贝叶斯网络的一个示例，其中包含了与参数相关的新节点，以便将它们视为随机变量，这符合贝叶斯参数学习方法的要求。](img/gr024.jpg)

图 16.24 贝叶斯网络的一个示例，其中包含了与参数相关的新节点，以便将它们视为随机变量，这符合贝叶斯参数学习方法的要求。

除了前述技术（它们是底层过程生成式建模的产物）之外，判别式技术也已得到发展。

在一般设定中，让我们考虑一个模式识别任务，其中（输出）标签变量 `y` 和（输入）特征变量 `x[1], …, x[l]` 根据一个可以在图上分解的分布联合分布，该分布由向量参数 `θ` 参数化，即 `p(y, x[1], x[2], …, x[l]; θ) := p(y, x; θ)` [13]。此类建模的一个典型例子是朴素贝叶斯分类器，我们在第 7 章中讨论过，其图形表示见图 16.25。对于给定的训练数据集，`(y[n], x[n])`，`n = 1, 2, …, N`，对数似然函数变为

```
L(Y,X;θ) = ∑_{n = 1}^{N} ln p(y_n, x_n; θ).
```

(16.62)

通过最大化 $L(\cdot,\cdot;\boldsymbol{\theta})$ 来估计 $\boldsymbol{\theta}$，可以得到一个估计值，该估计值保证了根据最大似然准则，相应分布对可用训练集的最佳拟合。然而，我们的最终目标不是对数据的生成“机制”建模。我们的最终目标是正确地对它们进行分类。让我们将公式 (16.62) 重写为：

```
$L(Y,X;\boldsymbol{\theta}) = \sum\limits_{n = 1}^{N}\ln P(y_{n}|\boldsymbol{x}_{n};\boldsymbol{\theta}) + \sum\limits_{n = 1}^{N}\ln p(\boldsymbol{x}_{n};\boldsymbol{\theta}).$
```

为了偏向分类任务，仅最大化上述两项中的第一项来获得 $\boldsymbol{\theta}$ 更为合理，即：

```
$L_{c}(Y,X;\boldsymbol{\theta}) = \sum\limits_{n = 1}^{N}\ln P(y_{n}|\boldsymbol{x}_{n};\boldsymbol{\theta}) = \sum\limits_{n = 1}^{N}\left( \ln p(y_{n},\boldsymbol{x}_{n};\boldsymbol{\theta}) - \ln\sum\limits_{y_{n}}p(y_{n},\boldsymbol{x}_{n};\boldsymbol{\theta}) \right),$ (16.63)
```

其中对 $y_{n}$ 的求和是对 $y_{n}$ 所有可能取值（类别）进行的。这被称为*条件对数似然*（参见例如 [19,20,67]）。所得估计值 $\widehat{\boldsymbol{\theta}}$ 保证了在给定特征值的情况下，后验类概率在训练数据集上整体最大化；毕竟，贝叶斯分类是基于根据后验概率的最大值来选择 $\boldsymbol{x}$ 的类别。然而，必须小心。采用此类方法的代价是条件对数似然不可分解，必须调用更复杂的优化方案。最大化条件对数似然并不保证错误概率也被最小化。只有当 $\boldsymbol{\theta}$ 的估计旨在最小化经验错误概率时，才能保证这一点。然而，这种准则难以处理，因为它不可微；已有尝试通过使用近似平滑函数或爬山贪婪技术来处理它（例如 [58] 及其参考文献）。请注意，条件对数似然背后的基本原理与第 15.4.3 节讨论的条件随机场背后的原理密切相关。

![Figure 16.25 The Bayesian network associated with the naive Bayes classifier. The joint PDF factorizes as p(y,x\_{1},\\ldots,x\_{l}) = p(y)\\prod\_{i = 1}^{l}p(x\_{i}|y)Equation.](img/gr025.jpg)

图 16.25 为与朴素贝叶斯分类器相关的贝叶斯网络。联合 PDF 分解为 $p(y,x_{1},\ldots,x_{l}) = p(y)\prod_{i = 1}^{l}p(x_{i}|y)$![Equation](img/si356.png)。

判别式学习的另一途径是通过*最大化间隔*来获得 `θ` 的估计。概率类间隔（例如，[21,59]）定义为

$d_{n} = \min\limits_{y \neq y_{n}}\frac{P(y_{n}|\mathbf{x}_{n};\mathbf{\theta})}{P(y|\mathbf{x}_{n};\mathbf{\theta})} = \frac{P(y_{n}|\mathbf{x}_{n};\mathbf{\theta})}{\max_{y \neq y_{n}}P(y|\mathbf{x}_{n};\mathbf{\theta})} = \frac{p(y_{n},\mathbf{x}_{n};\mathbf{\theta})}{\max_{y \neq y_{n}}p(y,\mathbf{x}_{n};\mathbf{\theta})}.$

![Equation](img/si365.png)

其思路是估计 `θ`，使所有训练数据上的最小间隔最大化，即

$\widehat{\mathbf{\theta}} = {arg\, max}_{\mathbf{\theta}}\ \min(d_{1},d_{2},\ldots,d_{N}).$

![Equation](img/si366.png)

感兴趣的读者也可参考 [10,55,60] 了解相关综述和方法。

#### 示例 16.4

本示例的目标是在一个通用贝叶斯网络中获取条件概率表中的值，该网络由 `l` 个离散随机节点/变量 `x[1], x[2], …, x[l]` 组成。我们假设所有涉及的变量均可被观测，并且我们拥有包含 `N` 个观测值的训练集。将采用最大似然法。令 `xi` (`n = 1, 2, …, N`) 表示第 `i` 个变量的第 `n` 个观测值。

在贝叶斯网络假设下，联合概率密度函数 (PDF) 由下式给出：

```
P(x_1,...,x_l) = ∏_{i=1}^{l} P(x_i | Pa_i; θ_i),
```

相应的对数似然函数为：

```
L(X; θ) = ∑_{n=1}^{N} ∑_{i=1}^{l} ln P( x_i(n) | Pa_i(n); θ_i ).
```

假设 `θ[i]` 与 `θ[j]` (`i ≠ j`) 互不相交，则可以分别对每个 `θ[i]` (`i = 1, 2, …, l`) 进行优化。这一性质被称为似然函数的*全局分解*。因此，只需在每个节点上局部执行优化即可，即：

```
l(θ_i) = ∑_{n=1}^{N} ln P( x_i(n) | Pa_i(n); θ_i ),  i = 1,2,...,l.  (16.64)
```

现在让我们关注所有涉及变量均为离散的情况，此时任意节点 `i` 处的未知量是相应条件概率表中的条件概率值。为便于表示，用 `h[i]` 表示由 `x[i]` 的父变量状态索引组成的向量。然后，对于 `x[i]` 和 `h[i]` 所有可能的取值组合，相应的（未知）概率记为 `P[x[i]|h[i]](x[i], h[i])`。例如，如果所有涉及的变量均为二元变量且 `x[i]` 有两个父节点，则 `P[x[i]|h[i]](x[i], h[i])` 总共可取八个需估计的值。公式 (16.64) 现在可重写为

```
l(θ_i) = ∑_{h_i} ∑_{x_i} s(x_i, h_i) ln P_{x_i|h_i}(x_i, h_i),
```

其中 `s(x[i], h[i])` 是特定组合 `(x[i], h[i])` 在训练集的 `N` 个样本中出现的次数。我们假设 `N` 足够大，使得所有可能的组合至少出现一次，即 `s(x[i], h[i]) ≠ 0, ∀(x[i], h[i])`。现在要做的就是在考虑到以下条件的情况下，最大化公式 (16.65) 关于 `P[x[i]|h[i]](·, ·)` 的值：

##### 学习参数

$$

\sum_{x_i} P_{x_i|\mathbf{h}_i}(x_i, \mathbf{h}_i) = 1.

$$

![Equation](img/si382.png)

注意，对于不同的 **h**[i] 值，$P[x_i|\mathbf{h}_i]$ 是独立的。因此，公式 (16.65) 的最大化可以针对每个 **h**[i] 单独进行，很容易看出：

$$

\widehat{P}_{x_i|\mathbf{h}_i} = \frac{s(x_i, \mathbf{h}_i)}{\sum_{x_i} s(x_i, \mathbf{h}_i)}.

$$

![Equation](img/si384.png) (16.66)

简而言之，未知条件概率的最大似然估计符合我们的常识；给定父节点值的特定组合 **h**[i]，$P[x_i|\mathbf{h}_i]$ 由数据集中特定组合 ($x_i$, **h**[i]) 出现的次数占 **h**[i] 出现总次数的比例来近似（将公式 (16.66) 与第 16.5.2 节中的维特比算法联系起来）。现在可以看出，为了获得良好的估计，训练点的数量 $N$ 应该足够大，以使每种组合出现足够多的次数。如果平均父节点数量大和/或状态数量大，这将对训练集的规模提出很高的要求。这就是条件概率参数化可以发挥巨大作用的地方。

### 16.7.2 学习结构

在上一小节中，我们假设图的结构是已知的，任务是估计未知参数。现在我们将注意力转向学习结构。一般来说，这是一项困难得多的任务。我们只打算提供一些大致方向的概述。

一条路径被称为**基于约束**的方法，它试图构建一个满足数据独立性的网络，这些独立性通过在训练数据集上进行不同的统计检验来“测量”。该方法很大程度上依赖于直觉，这类方法在实践中并不特别流行。

另一条路径被称为**基于评分**的方法。这将任务视为一个典型的模型选择问题。选择要最大化的评分在模型复杂度和对数据的拟合精度之间提供了权衡。贝叶斯信息准则 (BIC) 和最小描述长度 (MDL) 等经典模型拟合准则已被采用等。所有这些准则的主要困难在于它们的优化是一个 NP-hard 任务，关键问题是找到合适的近似优化方案。

第三条主要路径源于贝叶斯哲学。它不是使用单一结构，而是通过将适当的先验嵌入问题来采用一组结构集合。有兴趣进行进一步深入研究的读者可参考更专业的书籍和论文（例如 [22, 41, 53]）。
