## 观察随机变量

现在，当我们涉及到统计学时，我们需要观察第一个主题是随机变量。在概率论中，这些随机变量用 `X` 符号表示，它是一个所有可能的变量都表现为你在某次随机实验中出现的数值结果变量。随机变量有连续或离散两种选择。这意味着，有时你的随机变量是函数，将结果映射到其空间内部的实值。我们将看看这方面的几个例子，以便稍后理解它。我们将从一个掷骰子的随机变量示例开始。我们要观察的随机变量将用 `X` 表示，它将取决于你投掷骰子后得到的结果。这里自然产生的 `X` 的选择将把标记为 `1` 的结果映射到值 `i`。这意味着，如果 `X` 等于 `1`，你就会把在骰子上掷出 `1` 的事件映射为值 `i`。你可以对骰子上的任何数字进行这种映射，甚至可以更进一步，选出一些有点奇怪的映射。例如，你可以将 `Y` 映射为结果 `0`。这个过程可能很困难，我们不会花太多时间，但它可以帮助你看到它是如何运作的。当我们准备好写出这个时，会有概率，显示为随机变量 `X` 的结果 1 的概率 `P`。它看起来如下：

```
PX(i) or (x=i)
```

## 分布

现在我们需要观察这个过程中的概率分布是什么样的。我们在这里的意思是，查看随机变量每个结果的概率是多少。或者简单来说，我们将看到在掷骰子时得到某个特定数字（如六或三）的概率有多大。为了开始，我们需要看一个例子。让 `X`（或随机变量）作为我们投掷骰子后得到的结果。我们还假设骰子是没有经过手脚的，因此在每次投掷骰子时，六个面中概率都是相同的。掷骰子并获得特定数字的概率分布包括：

```
PX(1) = PX(2) = … = PX(6) = 1/6
```

在这个例子中，它与我们对随机变量的操作是一样的，但它具有不同类型的含义。你的概率分布更多是关于可能发生的事件的光谱，而我们的随机变量示例完全关于存在哪些变量。通过概率论，`P(X)` 部分将指出我们正在处理随机变量 `X` 的概率分布。在查看这些例子时，你可以注意到你的分布有时会同时包含两个或多个变量。当这种情况发生时，我们称之为联合分布。如果涉及多一个变量，你的概率现在将由每个变量决定。

## 独立性

在机器学习中，你可以处理的另一个变量是确定问题具有多大的独立性。一个例子是，当标签样本 `i` 不受 `j` 的影响时，训练样本 `j` 和 `i` 与底层空间是独立的。无论一个变量的结果如何，回想掷骰子和抛硬币的例子。骰子上出现什么数字都没关系。硬币会有自己的结果。反之亦然。随机变量 `X` 总是与变量 `Y` 独立。无论 `Y` 的值是什么，但以下代码需要成立：

```
P(X|Y) = P(X)
```

在上述情况下，`X` 和 `Y` 出现的值被忽略了，因为在此时这些变量的值将不再重要。

如果人类拥有几乎无限的空闲时间，世界会变成什么样？这是一种可能的未来吗？无法预知这项技术未来将我们带向何方。现在，它是 IT 领域最受关注的话题之一，这主要因为它在许多领域具有巨大的潜力。如果技术继续以如此之快的速度改进，那么很有可能在不远的将来，机器本身将编写其他机器。届那时，最好的问题不是机器未来将做什么，而是我们将做什么？本书提供了关于什么是 `machine learning` 以及 `machine learning` 类型的信息。它还提供了关于为 `machine learning` 奠定的基础的信息。你将获得用于 `machine learning` 的不同算法的信息。作为初学者，练习一些 `machine learning` 的算法有助于增强你的理解。书中有些项目你可以在周末完成，或者如果你想，也可以扩展它们。多加练习对提高你 `machine learning` 的知识至关重要。记住 `machine learning` 中使用的许多词汇是很困难的。
