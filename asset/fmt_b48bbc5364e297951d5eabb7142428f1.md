
\Sigma = \begin{bmatrix} 1.00 & 0.99 \\ 0.99 & 1.00 \end{bmatrix}.

$$

## 14.9 吉布斯采样

*吉布斯采样* 是最流行且应用最广泛的采样方法之一。它也被称为 *热浴* 算法。尽管吉布斯采样在统计物理学中早已为人所知并被使用，但两篇论文 [9,10] 对其在贝叶斯和机器学习社区的广泛应用起到了催化作用。

乔赛亚·威拉德·吉布斯 (1839–1903) 是一位美国科学家，他在热力学方面的工作为物理化学奠定了基础。他与詹姆斯·克拉克·麦克斯韦 (1831–1879) 和路德维希·爱德华·玻尔兹曼 (1844–1906) 一起，开创了统计力学领域。他还与奥利弗·海维赛德 (1850–1925) 共同被誉为如今所知向量分析的奠基人。

吉布斯采样适用于从多维分布中抽取样本，可视为更通用的梅特罗波利斯方法的一个特例。

设马尔可夫链在时刻 *n* 的随机向量为

**x**[*n*] = *x*[*n*, …, *x**n*]^T。

吉布斯采样的基本假设是：在给定其余变量的条件下，每个变量 *x**n*（*d* = 1, 2, …, *l*）的 *条件* 分布，即

*p*(*x**n*|{*x**n*： *i*≠*d*}), (14.51)

是已知的，且易于采样。在每次迭代中，根据公式 (14.51)，仅为其中一个变量抽取一个样本，其余变量的值冻结为上一迭代中已获得的值。该方案总结如下。

### 算法 14.4：吉布斯采样器

*   初始化 `x_0(1), …, x_0(l)`，任意设定。

*   **对于** `n = 1, 2, …, N`，**执行**

    1.  **对于** `d = 1, 2, …, l`，**执行**

        *   采样 `x_n(d) ~ p(x | {x_n(i), i < d}, {x_{n-1}(i), i > d})`

    2.  **结束 For**

*   **结束 For**

请注意，在上述方案中，所有维度都是按顺序访问的。另一种版本是按随机顺序访问它们。

Gibbs 方案可以看作是马尔可夫链的一种实现，其中转移矩阵/PDF 是由 `l` 个基础转移依次构建的，即，

```
T = B[1]⋯B[l]
```

其中每个单独的基础转移作用于相应的维度，即逐坐标地。对于连续变量，可以很容易地验证

```
B_d(x|y) = p( x(d) | { y(i) } : i ≠ d ) ∏_{i ≠ d} δ( y(i) - x(i) ),  d = 1,2,…,l.
```

换句话说，只有分量 `x(d)` 发生变化，而其余分量保持不变。不难看出，期望的联合分布 `p(x) = p(x(1), …, x(l))` 相对于每一个 `B[d]`，`d = 1, 2, …, l` 都是不变的（问题 14.13）。因此，它在它们的乘积下也将是不变的

```
T = B[1]⋯B[l].
```

遍历性通过要求所有条件概率*严格*为正来保证，这确保了链收敛到期望的 `p(x)`。

#### 备注 14.3

*   Gibbs 采样作为 Metropolis 方法的一个实例，继承了其类似随机游走的收敛性能。

*   Gibbs 采样适用于许多图模型（第 16 章），这些模型是用条件分布来描述的。通常，这些分布可以通过拒绝采样及其变体等技术以一种简单的方式进行采样，如第 14.4 节所述。

### 吉布斯采样的变体

*   **无拒绝采样**：在吉布斯采样中，没有样本会被拒绝。如果将吉布斯采样视为梅特罗波利斯方法的一个实例，通过将公式 (14.51) 作为建议分布的特定选择，也可以证明这一点（问题 14.14）。

*   **分组吉布斯采样**：吉布斯采样一次采样一个变量。如果变量高度相关，这会导致算法在状态空间中移动非常缓慢。在这种情况下，最好对变量*组*进行采样（不一定互不相交），并从区块中的变量采样，条件是其余变量。这被称为分组吉布斯采样 [16]，它通过在状态空间中实现更大幅度的移动来提高性能。

*   **塌陷吉布斯采样**：在塌陷吉布斯采样中，积分消去（边缘化）一个或多个变量，并从剩余变量中采样。例如，对于三个变量的情况，吉布斯采样依次从 `p(x₁|x₂, x₃)`、`p(x₂|x₁, x₃)` 和 `p(x₃|x₁, x₂)` 采样以完成迭代步骤。在塌陷吉布斯采样中，我们可以积分消去（例如 `x₃`，即被“塌陷”的变量），并依次从 `p(x₁|x₂)` 和 `p(x₂|x₁)` 采样。这样采样就在低维空间中进行，因此效率更高。如果塌陷变量是另一个相关变量的共轭先验（例如，它们都属于指数族分布），则塌陷单个变量是可处理的。因此，`x₃` 不参与吉布斯采样。随后，我们可以从 `p(x₃|x₁, x₂)` 采样。这可以由*劳-布莱克威尔*定理证明，该定理指出：通过解析积分消去 `x₃` 创建的估计量的方差，将始终低于（或等于）直接吉布斯采样的方差 [23]。

## 14.10 寻找更高效的方法：讨论

为了规避上述基本马尔可夫链方案的缺点——即缓慢的类随机游走收敛和局部陷阱问题——已经提出了许多更高级的方法。详细介绍这些方案超出了本章的范围，感兴趣的读者可参考更专业的书籍和文章，例如 [5, 22, 24, 30, 38]。下面，我们简要讨论一些最流行的研究方向。

一类称为*辅助变量马尔可夫链蒙特卡洛*的算法很受欢迎。这类方法在梅特罗波利斯-黑斯廷斯算法中，用辅助变量扩充目标分布或建议分布。引入辅助变量旨在帮助算法逃离可能的局部陷阱，或者在归一化常数难以处理时将其抵消。此类方法包括*模拟退火* [17]、*模拟回火* [25] 和*切片采样* [15] 等算法。切片采样技术的基本原理建立在我们在第 14.4 节中的讨论之上；回顾一下，从 `p(x)` 采样等价于从以下区域均匀采样：

```
𝒜 = {(x, u): x ∈ ℝˡ, 0 ≤ u ≤ p(x)}.
```

文献 [31] 建议采用一种基于 Gibbs 的切片采样器实现；`x` 的每个分量均通过单变量切片采样策略依次更新。结果表明，切片采样器提高了标准 Metropolis–Hastings 算法的收敛速度。

文献 [29] 利用一个辅助变量，从而避开了归一化常数的计算。在归一化常数难以计算的情况下，这一点至关重要。

另一种采样理念涵盖了*基于种群*的方法。为克服局部陷阱问题，在信息交换策略下并行运行若干条（种群）马尔可夫链，从而改善收敛性。此类技术的典型例子包括*自适应方向采样* [12] 和*进化*蒙特卡洛方法，后者建立在遗传算法所用的论据之上 [22]。

另一个方向是*哈密顿*蒙特卡洛方法，其利用经典力学中优雅的哈密顿方程相关论据 [26,30]。对于以下形式的 PDF：

```
p(x) = (1/Z_E) exp(-E(x)),
```

`E(x)` 可解释为系统的势能（第 15.4.2 节）。一旦建立起这种联系，便引入一个辅助随机向量 `q`，并将其解释为系统的动量；因此，相应的动能可表示为：

```
K(q) = (1/2) sum_{i=1}^{l} q_i².
```

哈密顿函数由此给出：

```
H(x, q) = E(x) + K(q),
```

它定义了如下分布：

```
p(x, q) = (1/Z_H) exp(-H(x, q)) = (1/Z_E) exp(-E(x)) (1/Z_K) exp(-K(q)) := p(x)p(q).
```

其中 `Z_K` 是与动能相关的各高斯项的归一化常数。目标分布 `p(x)` 作为 `p(x, q)` 的边缘分布获得。可以通过数值求解哈密顿方程来从 `p(x, q)` 中采样，丢弃 `q` 即可得到从目标分布中抽取的样本。变量随时间的演化由等效系统的相关哈密顿动力学给出。

此类方法可能会显著提高收敛速度；原因在于通过哈密顿解释，利用了隐藏在 `E(x)` 导数中的信息（即 `q̇ = - ∂E(x)/∂x`），以便系统检测指向高概率质量的方向。

在*可逆跳马尔可夫链蒙特卡洛*算法中，Metropolis-Hastings 算法被扩展以适应维数可变的状态空间 [13]。当涉及不同维数的多参数模型时，此类方法是合适的。因此，马尔可夫链被赋予了在不同维数模型之间跳跃的自由。

### 变分推断还是蒙特卡洛方法

在本章开头，我们提到过变分推断技术（在第 13 章中讨论过）是蒙特卡洛方法的确定性替代方案。我们现在将尝试用几行文字勾勒出这两种方法各自的优缺点。关于前者（即变分推断）通往贝叶斯学习路径的主要优点如下：

*   对于中大规模任务，它们在计算上更高效。

*   相当容易确定何时停止迭代，并知道何时已达到收敛。

*   可以计算似然函数的下界。

关于蒙特卡洛方法的优点如下：

*   它们可应用于更一般的情况，例如，没有计算上方便的先验的模型，或结构在变化的模型。

*   它们不依赖于诸如均场近似之类的近似。

## 14.11 案例研究：变点检测

变点检测任务在许多科学学科中具有重大意义，涉及范围从工程学和社会学到经济学和环境研究。积累的文献浩如烟海；参见例如 [1,19,36] 及其参考文献。变点识别任务的目的是检测观测序列中的分割，使得每个块中的数据在统计上“相似”，换句话说，服从一个共同的概率分布。第 17 章中讨论的隐马尔可夫模型和动态贝叶斯方法，都属于这一更一般问题范畴。我们在此例中的目标是演示 Gibbs 采样在变点检测任务背景下的应用（参见例如 [4]）。

设 `x[n]` 为对应于事件计数的离散随机变量，例如，单位时间内的电话呼叫请求数、Web 服务器上单个文档的请求数、放射性材料的粒子发射数或工作环境中的事故数。我们采用泊松过程来模拟 `x[n]` 的分布，即

```
P(x;λ) = (λτ)^x / x! * e^(-λτ).
```

(14.52)

泊松过程已被广泛用于模拟在时间间隔 `τ` 内发生的事件数量。在我们的例子中，我们选择了 `τ = 1`。参数 `λ` 被称为过程的*强度*（参见例如 [32]）。

我们假设观测值 `x[n]`（`n = 1, 2, …, N`）是由两个不同的泊松过程 `P(x; λ[1])` 和 `P(x; λ[2])` 生成的。此外，模型的变化在未知时刻 `n[0]` 突然发生。我们的目标是估计后验概率：

`P(n[0] | λ[1], λ[2], x[1:N])`

此外，`λ[1]` 和 `λ[2]` 的确切值未知。唯一可用的信息是泊松过程强度 `λ[i]`（`i = 1, 2`）服从先验伽马分布，即：

```
p(λ) = Gamma(λ|a,b) = (1/Γ(a)) * b^a * λ^(a-1) * exp(-bλ),
```

其中 `a`、`b` 为已知正值。最后我们假设对变化时刻没有先验信息；因此先验选择为均匀分布 `P(n_0) = 1/N`。基于上述假设，对应的联合分布由下式给出：

`p(n[0], λ[1], λ[2], x[1:N]) = p(x[1:N] | λ[1], λ[2], n[0]) * p(λ[1]) * p(λ[2]) * P(n[0])`

或者

$p(n\_{0},\\lambda\_{1},\\lambda\_{2},\\mathbf{x}\_{1:N}) = \\prod\\limits\_{n = 1}^{n\_{0}}P(x\_{n}|\\lambda\_{1})\\prod\\limits\_{n = n\_{0} + 1}^{N}P(x\_{n}|\\lambda\_{2})p(\\lambda\_{1})p(\\lambda\_{2})P(n\_{0}).$

![Equation](img/si336.png)

取对数以消除乘积，并积分掉相应变量，得到吉布斯采样所需的以下条件分布（习题 14.15）：

*p*(*λ*[1]|*n*[0], *λ*[2], **x**[1 : *N*]) = Gamma(*λ*[1]|*a*[1], *b*[1]),

![Equation](img/si337.png) (14.53)

以及

### 数学公式推导

$$

a_{1} = a + \sum\limits_{n = 1}^{n_{0}}x_{n},\quad b_{1} = b + n_{0}.p(\lambda_{2}|n_{0},\lambda_{1},\mathbf{x}_{1:N}) = \text{Gamma}(\lambda_{2}|a_{2},b_{2}),a_{2} = a + \sum\limits_{n = n_{0} + 1}^{N}x_{n},\quad b_{2} = b + (N - n_{0}),

注意，前两个条件分布服从伽马分布，正如我们在第 14.4 节末尾所述，有多种不同的方法可用于从中生成样本。最后一个分布是离散分布，可以按照算法 14.1 中讨论的方法抽取样本。我们现在准备好应用吉布斯采样了。

### 算法 14.5：用于变点检测的吉布斯采样

*   获得 `x[1:N] := {x[1], …, x[N]}` 后，选择 `a` 和 `b`。

*   初始化 `n_0⁰`。

*   **For** `i = 1, 2, …` **Do**

    1.  `λ_1^(i) ~ Gamma(λ | a + ∑_{n=1}^{n_0^(i-1)} x_n, b + n_0^(i-1))`

    2.  `λ_2^(i) ~ Gamma(λ | a + ∑_{n=n_0^(i-1)+1}^{N} x_n, b + (N - n_0^(i-1)))`

    3.  `n_0^(i) ~ P(n_0 | λ_1^(i), λ_2^(i), x[1:N])`

*   **End For**
