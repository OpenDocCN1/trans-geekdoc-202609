
| 卡方自动交互检测 (CHAID) | CHAID 是一种非参数方法，通过根据分类预测变量递归地将数据划分为同质子组来创建决策树，使用卡方检验评估变量之间的独立性并寻找显著分割。 |

## 节点分割是如何工作的？

![](img/icon_7.jpg)从上面的示例中，我们看到树是如何根据乘客决策的层级结构构建的。我们还可以看到，这些节点是如何被分割的是构建该树的关键。那么，节点分割是如何工作的？

节点分割是构建树的层级结构的关键过程，因为它决定了数据在树的每一层中应该如何隔离。在这个过程中，算法选择一个变量，相应的节点被划分为两个或多个分支。划分的依据是能够优化分离每类中个体的标准。如果变量是分类的，则分支代表节点内不同的类别。相反，如果变量是连续的，则分支表示节点内的特定区间。在每次分割时，都会应用一个分离条件来决定如何将父节点划分为子节点。这一过程持续直到满足预定义的停止标准。这一过程被称为 `recursive partitioning`。

![](img/ufig8_2.jpg)递归涉及根据分裂准则将数据集递归地划分为更小且同质的子集（节点）。目标是创建一个表示数据底层关系的层级树状结构，使其便于解释和做出决策。此过程包括以下步骤。

1. **选择分裂准则**：在树的每个节点上，算法选择一个变量和一个对应的分裂准则将数据划分为子节点。分裂准则的选择取决于目标变量的尺度，并可能包括 `F-test`、`Chi-Square test`、`Gini impurity` 或 `Entropy` 等衡量标准。

2. **分割数据**：使用选定的分裂准则将节点划分为两个或多个子节点。每个子节点代表树中从当前节点出发的分支。

3. **停止标准**：算法检查是否满足任何停止标准。常见的停止标准包括达到最大树深度、每个叶节点具有最小样本数，或达到特定的不纯度减少水平。

4. **递归过程**：如果不满足停止标准，过程将对每个分支继续递归。子节点变成新的父节点，过程继续。

5. **叶节点**：当满足停止标准或没有进一步有意义的分割时，过程停止，树的最终节点被称为叶节点。叶节点代表目标变量的最终预测。

递归划分过程一直持续到满足所有停止标准或树完全生长。然而，完全生长的树可能会导致过拟合，即模型捕捉了训练数据的噪声和特定细节，导致预测能力差。为了缓解过拟合，可以使用剪枝来简化树。我们将在本章中介绍剪枝技术。

总体，决策树中的递归划分是一种自上而下的方法，从整个数据集开始递归地将其划分为子集。这个过程是高效的，并允许决策树处理分类和连续变量，使其成为强大的数据模型。

## 缺失值对决策树有影响吗？

![](img/icon_8.jpg)在传统的统计研究中，缺失值是一个大问题，因为它们可能显示数据信息的缺失并影响结果。回归方法对缺失值敏感，因为它们倾向于需要完整的数据来建立拟合良好的模型。此外，缺失值会导致信息丢失并可能在数据中产生偏差。然而，决策树是非参数方法，并基于逻辑规则。由于树是通过将父节点分裂为多个子节点构建的，缺失值对构建树过程的影响较小，因为这种方法处理缺失值的方式非常有效。

本质上决策树在分割过程中自然地处理缺失值。以下是决策树处理缺失值的一些典型方法。

### 缺失值的分裂准则

决策树可以使用不同的分裂准则（如 `Gini impurity` 或 `Entropy`）来确定每个节点处划分数据的最佳变量和阈值。当某个数据点具有缺失值时，算法通常会将缺失值视为单独的类别或组。具有缺失值的数据点会遍历分裂两个分支，算法根据可用数据计算每个分支的不纯度或误差。这允许决策树利用非缺失值的信息来做出决策，即使某些值是缺失的。

### 使用插补法

某些决策树实现可能支持缺失值的插补。我们已经在第 5 章中介绍过这一主题。

### 创建多个分支

如果数据点在多个变量上有缺失值，决策树会从当前节点创建多个分支，以考虑缺失和非缺失值的组合。算法会分别评估每个分支，并考虑每个数据点的可用值。

### 预测过程中的缺失值处理

在对新数据进行预测时，如果变量存在缺失值，决策树仍然能够根据可用值遵循适当的分支做出预测。如果一个数据点在多个变量上有缺失值，树将向下遍历多条路径到达叶子节点，并将这些路径的预测结果组合形成最终预测。

![](img/ufig8_3.jpg)需要注意的是，某些数据挖掘软件可能内置了支持，能够更高效地处理决策树建模中的缺失值。建议使用这些内置算法。SAS Enterprise Miner 具有此类处理缺失值的内置算法（详情请见下一页）。

## 决策树方法的优缺点

![](img/icon_8.jpg)决策树是数据挖掘中一种非常流行的方法。它是一种非参数方法，可以检测非线性关系。它可以用于各种测量标度，并且对缺失值或离群值不敏感。树的结构逻辑性，易于理解和解释。由于我们采用了需要使用不同方法和配置开发多个模型的策略，因此理解决策树的优缺点至关重要，这让我们可以将该方法与我们在第 7 章中过的回归方法以及之后将涵盖的其他高级方法进行比较。我将该方法的关键优缺点总结如下。

### 决策树的优点

*   **可解释性**：决策树为决策过程提供了透明且直观的表示。树的分层结构易于理解和解释，使其成为向非专家解释预测结果价值工具。

*   **处理非线性和复杂关系**：通过使用决策树，研究人员可以通过层次结构有效地捕捉变量之间的非线性关系和复杂的相互作用。

*   **数据类型的灵活性**：决策树可以用于构建关联模型或分类模型，使其具有多功能性并适用于广泛的应用。它们也可以同时处理连续型和分类预测变量。

*   **无关特征**：决策树对建模数据中的无关变量很有用，因为它们专注于对数据划分更有信息量的变量。

*   **可扩展性**：决策树处理大型数据集的效率更高，不需要高计算能力。

*   **处理缺失值**：由于递归划分过程的本质，决策树能够通过划分过程有效地处理缺失值。

*   **集成方法**：可以使用随机森林（Random Forests）和梯度提升（Gradient Boosting）等集成方法结合决策树，这通常能提高预测性能并减少过拟合。

*   **提供变量重要性**：输出提供相对变量重要性图，这使我们更容易识别重要的预测变量。

### 决策树的缺点

*   **过拟合**：决策树对过拟合敏感，特别是当树很深且结构复杂时。

*   **不稳定性和方差**：数据的微小变化可能导致截然不同的树结构，从而产生高方差。

*   **对主导类别的偏差**：在数据集不平衡的分类模型中，决策树可能偏向多数类，导致性能欠优。

*   **难以处理数值离群值**：决策树对连续变量的标度敏感，离群值可能对树的结构产生不成比例的影响。

*   **全局最优与局部最优**：决策树算法的贪婪性质可能导致单个节点出现次优划分，尽管这些划分对整体最优有所贡献。

*   **缺乏系数**：与回归不同，决策树模型的输出不提供用于评估影响的系数。尽管存在这些局限性，决策树仍然是一种非常有价值且被广泛使用的机器学习方法，特别是对于需要可解释性、处理非线性关系以及同时处理分类和连续变量的数据挖掘项目。然而，为了解决某些缺点，通常会应用剪枝（pruning）、集成方法和仔细的超参数调优来改进模型。

## 两种不同的决策树

![](img/icon_4.jpg)从上一个示例中可以看出，如何划分节点是开发良好的决策树模型的关键。在数据挖掘中，树源自数据，而不是我们的我们的常识规则或业务规则。因此，拥有有效的划分规则对于产生具有良好预测能力的决策树模型非常重要。划分算法允许我们对不同类型的树进行分类。

两种主要的决策树类型是分类回归树（CART）和 CHAID（卡方自动交互检测）。我将介绍这些树的一些概括描述以及何时使用哪一种。像往常一样，我将避免数学公式，侧重于实际应用。

![](img/ufig8_4.jpg)

### 分类回归树 (CART)

![](img/ufig8_5.jpg)CART 是由 Breiman 等人 (1984) 开发的一种流行的决策树方法。如果你感兴趣，可以在他们的书籍《分类回归树》中阅读该方法的细节。我跳过了该方法的数学细节。基本上，CART 是一二叉树，它使用算法反复将一个父节点分为两个子节点。CART 可同时用于分类和连续目标变量。回归树用于连续目标变量，而分类树用于分类目标变量。具体来说：

*   **关联模型**：回归树依赖于通过最小平方偏差（`LSD`）测量评估节点的纯度，这有效地量化了节点内的方差。

*   **分类模型**：在分类树中，评估依据是等价 Gini 指数。Gini 分数为 0 表示类别之间完全相等，而分数为 1 则表示最高程度的不平等。

尽管如此，大多数数据挖掘软件应用都具有相同的 `CART` 树特征，因此我们不需要担心将它们分开。从本质上说，`CART` 使用所谓的二分划分；即算法重复地将一个父节点分裂为两个子节点。这就是为什么 `CART` 被称为二叉树的原因。由于分裂过程的复杂性，我们不讨论该过程的细节。本质上，该过程根据划分准则搜索最佳划分算法，并在满足停止标准时停止划分过程。只要我们理解 `CART` 的二分划分本质，就没问题。至于缺失值，它们被视为一个单独的组，只有当两个类别之间实际上存在高度相似性时，才会与其他任何类别合并。

`CART` 树的形式类似于图 8.2 所示的示例。如图所示，每个父节点分裂为两个子节点，且不少于此。

## 卡方自动交互检测 (CHAID)

![](img/ufig8_6.jpg)CHAID 由 Kass 在 1980 年提出。该方法基于卡方统计量。卡方检验是一种非参数检验，用于检查分类变量之间的差异。该检验产生一个 0 到 1 之间的概率值。卡方值越接近 0，表示两个变量之间存在显著差异。同样，越接近 1，表示变量之间没有显著差异。与 `CART` 不同，`CHAID` 倾向于将一个父节点分裂为两个以上的子节点。

通常，`CHAID` 可同时用于关联模型（连续目标变量）和分类模型（分类目标变量），但它需要分类预测变量（无论是序数的还是类名的）。然而，许多软件应用接受间隔输入，并在生长树之前自动将值分组到不同的范围内。`CHAID` 算法自 Kass 算法以来已经有了显著进化，现在可以通过 `F-test` 的 `p-value` 来处理连续目标变量。

`CHAID` 使用两个统计检验来确定下一个最佳划分：

*   关联模型（具有连续目标变量）：`F-Test` (`p-value`)。

*   分类模型（具有分类目标变量）：`Chi-Square test` (`p-value`)。

再次，我不深入介绍 `CHAID` 的详细划分过程，这是一个复杂的步进过程。本质上，该过程根据 `F-test` 或 `Chi-Square test` 调整后的 `p-value` 搜索最佳划分算法，并在满足停止标准时停止划分过程。请记住，`CHAID` 将节点分裂为两个或多个子节点，这是与 `CART` 的主要区别。图 8.3 显示了 `CHAID` 树的示意图。至于缺失值，一个缺失值被视为一个单独的值。更具体地说，它被认为是一个新类别（对于类名预测变量）或不受任何顺序限制（对于序数预测变量）。

## 树剪枝

![](img/icon_4.jpg)剪枝是确保我们拥有具有良好预测能力的决策树模型的重要步骤。剪枝决策树意味着移除冗余子树并将其替换为叶子节点。具有过多分支和层次的大树可能会导致过拟合。此外，此类树非常难以理解和解释。基本上，这些树使用相同的预测变量来构建树级结构，但倾向于多次分裂节点以创建许多不同的分支，希望提高模型拟合度。然而，该过程可能会创建非常大的树，它们仅适用于训练样本并导致过拟合。剪枝树有助于防止由于过度训练训练数据导致的过拟合，使我们的模型能够泛化到新的数据集。此外，它还可以为我们提供一个更简单的树，在不损害模型拟合性能的情况下。图 8.4 显示了决策树剪枝的示意图。

图 8.4 决策树剪枝的示意图。

图 8.4 决策树剪枝的示意图。

树剪枝的过程包含以下几个步骤：

1.  生长全树：第一步是生长决策树直到达到深度或满足指定的停止标准。在此阶段，算法递归分区数据并创建分支。

2.  评估节点重要性：生长全树后，我们评估每个节点对性能提升的重要性。贡献较小或在统计上不显著的节点是剪枝候选。

3.  复杂度剪枝：复杂度剪枝（也称为最小复杂度剪枝）是决策树剪枝的一种常用方法。它涉及引入一个复杂度参数 (`alpha`) 来平衡模型的复杂性。算法评估移除每个节点的影响并计算复杂度得分。

4.  选择最佳剪枝水平：算法在验证集上评估模型性能并迭代剪枝，直到进一步剪枝会导致预测性能下降。最佳剪枝水平对应于准确性和简单性之间平衡最好的子树。

5.  剪枝树：一旦确定了最佳剪枝水平，通过移除对应水平以上的节点和分支对树进行剪枝。生成的剪枝树是全树的简化版本。

剪枝通过降低决策树的复杂度来帮助防止过拟合，从而提高了其预测能力。它还通过创建更直观、简洁的决策过程表示来增强模型的可解释性。然而，需要注意的是剪枝是一个数据驱动的过程，最佳剪枝水平可能根据数据集而变化。应使用定期验证为每个决策树确定最佳剪枝策略。

决策树剪枝分为两种类型：预剪枝和后剪枝。

*   **预剪枝**（也称为早期停止规则）是一种在树达到特定大小或深度限制时防止其生长的方法。这些特定指标包括 `Gini 指数` 或 `熵`。在预剪枝期间，我们根据决策树中每个节点的指标来评估剪枝准则。

*   **后剪枝**涉及在构建整棵树后进行剪枝的过程。在这种方法中，我们首先让树生长到最大程度，然后从下而上逐个剪掉子树。我们从最低的决策节点开始该过程，并使用 `Gini Impurity`（基尼纯度）或 `Information Gain`（信息增益）等指标来决定保留该决策节点还是将其替换为叶子节点。

### 手动或自动剪枝

数据挖掘项目通常不建议进行手动剪枝，因为它取决于研究者的解释和决策，可能会产生偏差。它还需要移除子树有明确的依据和理由。例如，我们如何知道哪些分支是冗余并需要删除的？我们如何证明这一决策是合理的？过程中的错误可能导致模型拟合效果更差，甚至产生一个无用的树。此外，对于层次结构简单的树，手动剪枝可能是可行的。然而，当我们拥有一大量节点和分支的大型树时，是不可能手动剪枝的。这也违背了挖掘更大数据集的初衷。

我推荐的剪枝方法是 `自动剪枝`。基本上，我们为树的生成和子树选择设置特定的评估要求，然后让软件根据这些配置进行剪枝。通常，我们会告诉软件如何选择子树、子树评估方法以及我们是否想要进行交叉验证。软件使用搜索算法找到符合这些标准和要求的最佳树。通常，对于关联模型，我们使用 `mean squared error`（均方误差）作为评估方法；对于分类模型，我们使用 `misclassification rate`（误分类率）作为评估方法。软件将选择使 `MSE` 或 `MR` 最小的树。

### CART 与 CHAID 的区别

![](img/icon_8.jpg)我在表 8.2 中总结了 `CART` 和 `CHAID` 树之间的一些主要区别。总来说，这两类树非常相似。某些差异源于节点划分的方式。作为一个提醒，`CART` 使用二分划分算法，而 `CHAID` 使用多叉划分算法。这两种树都允许我们构建关联模型或分类模型。然而，`CART` 倾向于连续或定序预测变量，而 `CHAID` 倾向于分类预测变量。尽管如此，大多数数据挖掘软件应用都允许我们使用预测变量的组合。

| 树类型 | `CART` | `CHAID` |
| --- | --- | --- |
| 目标变量 | 同时支持连续和分类目标变量 | 同时支持连续和分类目标变量 |
| 预测变量 | 优先考虑连续或定序变量 | 优先考虑分类变量 |
| 划分分支数量 | 仅两个分支 | 两个或多个分支 |
| 划分规则 | 仅二分划分：`Gini`、`Entropy` 或 `variance` | 多叉划分：`F-test` 或 `卡方检验` |
| 树的大小 | 较小、较高的树 | 较大、较矮的树 |
| 剪枝建议 | 是 | 是 |
| 离群值影响 | 无 | 无 |
| 缺失值影响 | 无 | 无 |
| 数据要求 | 不需要大量数据 | 需要大量数据 |
| 对过拟合的敏感性 | 是 | 较低 |

此外，由于划分方式的不同，`CART` 倾向于产生一棵较小（较细）但较高的树（二分划分），而 `CHAID` 倾向于产生一棵较大但较矮的树（多叉划分）。`CHAID` 训练模型可能比 `CART` 需要更多数据，但比 `CART` 不容易过拟合。有些作者指出 `CHAID` 不需要剪枝，但我建议对两种类型都进行剪枝，以避免产生巨大的树。我们稍后将检查一些示例。很难判断哪种树的效果更好，因为它们各有优缺点。选择取决于数据。我的建议是使用两种类型的不同预测变量构建多棵树。
