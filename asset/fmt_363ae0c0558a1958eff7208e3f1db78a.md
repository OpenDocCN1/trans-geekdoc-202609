
### 如何通过赋值声明变量？

要回答这个问题，请检查下面给出的示例：

```
my_variable = 20
```

请注意，实际上你是将变量 `my_variable` 等同于 20，而不仅仅是将变量设置为 20。

如果你想增加变量的值，请在命令行输入此语句：

```
>>> my_variable = my_variable + 5
```

为了了解 Python 将如何响应此命令，请调用 `print` 命令：

```
>>> print(my_variable)
```

下一行将显示此结果：

```
25
```

如果你想用 `my_variable` 存储字面字符串 “violet”，只需按以下方式将变量设置为 “violet”：

```
>>> my_variable = "violet"
```

为了知道 `my_variable` 当前存储的内容，请使用 `print` 命令：

```
>>> print(my_variable)
```

下一行，你将看到：

这些只是在 Python 中处理变量的简单方法，请务必亲自实践。

### Python 中的数据类型

Python 拥有不同的数据类型，以增强其对应用程序开发人员和程序员的重要性，因为提供了足够有效的数据。数据类型包括数字、日期、字符串、时间、布尔值和列表。

#### 数字数据类型

Python 可以在你不声明的情况下区分数字类型；这是使用 Python 最大的优势之一。凭借其内置函数，当你运行语句时，Python 会自动识别一种数据与另一种数据的区别。这些用于数值的内置函数共有四种，即：浮点数、复数、整数和长整数。值得注意的是，你使用的 Python 版本将决定活跃的内置数字函数的数量。然而，对于 Python 3，仅支持三种（浮点数、整数和复数）类型。

##### 浮点数

这些是实数。它们也被称为浮点数。浮点数表示实数。值得注意的是，当你想书写浮点数时，请在其中加入小数点，以将其与分数区分开来。另一种方式，你可以使用科学计数法书写浮点数；大小写均可；其中字母 ‘e’ 相当于 10 的幂。示例如下：

```
>>> 7.4e2
7400.0
>>> 7.4e2
742
```

你可以尝试其他数字序列以增强对浮点数的灵活运用。

##### 整数

与浮点数不同，整数不带小数点书写。它们是正负整数。Python 中的整数很多，下面仅给出少数作为指导，说明其他整数将如何处理；

**二进制整数**

要书写二进制整数，请使用 `0b` 或 `0B` 作为前缀（是数字零，不是字母 `o`）。示例如下：

```
>>> a = 0b3200
>>> print(a)
3200
```

**常规整数**

它们只是普通的数字，无论正负。例如 243、-110、3 等。

**十六进制整数**

它们也称为十六进制。要书写十六进制整数，请使用前缀 `0X` 或 `0x`（数字零和字母 eks）。示例如下：

```
>>> hex_lit = 0xA0B
>>> print(hex_lit)
238
```

**八进制**

这与其他进制一样，也使用 `0o` 或 `0O` 作为前缀表示。示例：

```
>>> c = 0O29
>>> print(c)
29
```

##### 复数

它们类似于实数，因为它们是实数，但总是成对出现。此外，复数也是虚数的集合。在组合中，它们采用浮点数和实数的形式，如下所示：`c + bJ`，其中 `c` 是浮点数，`b` 也是浮点数，`J` 是虚数的平方根。请看下面的例子：

```
>>> x = 5 + 6j
>>> y = 8 - 2j
>>> z = x + y
>>> print(z)
(13+4j)
```

请注意，复数在 Python 中的使用受到限制。

#### 字符串数据类型

字符串是特殊的数据，因为它们是包含字母、符号和数字组合的 Unicode 字符。在定义时，编码时请用“匹配的单引号或双引号”将字符串括起来。请看下面的例子：

```
>>> stringA = "The best student is Python."
>>> stringB = "The best student is Python."
```

万一你处理的是用单引号括起来的字面字符串，而该字符串内部也包含单引号，请在字符串内的单引号前加上反斜杠 (`\`) 以转义该字符。例如：

```
>>> stringC = 'It is good to be smart.'
```

要打印 `stringC`：

```
>>> print(stringC)
It is good to be smart.
```

如果引号用普通双引号括起来，编码就会很简单，如下所示：

```
>>> stringC = "It is good to be smart"
```

同样，每当你的引号括在另一个双引号内时，请在嵌入的引号前加上反斜杠。请看这个例子：

```
>>> doc = "The programmer reiterated: \"You will always choose Python programming language as the best among others.\""
>>> print(doc)
The programmer reiterated: "You will always choose Python programming language as the best among others"
```

字符串以多种方式处理索引或下标数字。请记住，Python 索引从 0（零）开始，而不是 1。因此，任何字符串的第一个字符必须从零开始。为了说明字符串索引在 Python 中如何工作，请在命令行定义字符串 "Hello Python"：

```
>>> s = "Hello everyone, it is Python"
```

这是 Python 为该字符串建立的索引：

```
-12 -11 -10 -9 -8 -6 -6 -5 -4 -3 -2 -1
H  e  l  l  o     e  v  e  r  y  o  n  e  ,     i  t     i  s     P  y  t  h  o  n
( 从 0 写到无穷大 )
```

为了检查字符串的第一个字符，请输入变量名 `s` 和方括号中的索引 0，如下所示：

```
>>> s[0]
```

你将得到此输出：

```
'H'
```

请注意，这更容易检查，因为你知道它的索引号是零。有趣的是，当你想访问同一字符串的最后一个字符时，你没有这个特权。那该怎么做呢？为了检查最后一个字符，请使用此表达式：

```
>>> s[len(s)-1]
```

你将得到输出：

```
'n'
```

该表达式向你介绍了 `len()` 函数。实际上有一种更简单的方法来访问字符串的最后一项：

```
>>> s[-1]
'n'
```

要访问倒数第二个字符：

```
>>> s[-2]
'o'
```

除了使用索引外，你还可以在字符串上使用其他函数和数学运算符。

#### 日期和时间数据类型

大量应用程序能有效地处理日期和时间信息，这在 Python 编程中同样适用。要使用时间和日期函数，请使用此命令：`datetime.now()`。这将生成当前日期和时间，因为它与内置的 Python 代码通信以执行该函数。你可以通过在命令提示符下编码以下内容，直接从 Python 访问时间和日期：

```
>>> from datetime import datetime
>>> datetime.now()
datetime.datetime(2019, 4, 20, 4, 17, 19, 60352)
```

你会注意到数字的格式不太易读，你可能希望使用可读的格式，因此，请使用命令 `strftime` 使其成为可能。请查看下面给出的格式：

```
>>> from time import strftime
>>> strftime("%Y-%m-%d %H:%M:%S")
'2019-04-20 05:35:03'
```

请注意，`strftime` 命令的首字母缩写为：Y（年）、M（月）、D（日）、M（分）和 S（秒）。

#### 布尔数据类型

基本上，在 Python 中用于生成肯定和否定响应的数据类型是布尔值。响应通常为 true 或 false。例如，创建几个变量来存储布尔值并按如下方式打印结果：

```
bool_a = 7 == 2*3
bool_b = 9 < 2 * 2**3
bool_c = 7 > 2 * 4 + 1
print(bool_a)
print(bool_b)
print(bool_c)
```

Python Shell 将显示以下结果：

```
False
True
False
```

#### 列表数据类型

简单来说；列表是可用于存储任意类型和数量的变量信息的数据类型。为了定义你的列表，你必须按以下方式为它们分配项目类型：

```
my_list = [item_1, item_2, item_3]
```

也许你想创建一个空列表，这在 Python 中也是允许的，如下所示：

```
my_list = []
```

为了更好地理解，让我们创建一个动物列表：

```
animals = ["goat", "cow", "pig", "dog", "duck", "lizard"]
```

你还记得 Python 中如何处理索引吗？很好，这是一个索引列表，animals 列表中的第一个项目的索引为零。要访问列表中的第一个项目，可以使用命令打印该动物：

```
>>> print(animals[0])
goat
```

要使用 print 命令获取列表中第三个颜色的名称，可以输入：

```
>>> print(animals[4])
dog
```

你也可以尝试其他动物类型。为了确定给定列表中动物的数量，请使用 `len()` 函数：

```
>>> len(animals)
6
```

你的列表中总共有六种动物。如果万一你在列表中包含了一个不需要的项目并想将其移除，请使用 `remove()` 方法——这在不需要的项目很多时最适用。为了说明这一点，请检查：

```
>>> animals.remove("goat")
```

使用此打印命令查看更新后的列表：

```
>>> print(animals)
['cow', 'pig', 'dog', 'duck', 'lizard']
```

同样，如果你想向列表中添加项目，请按以下方式使用 `append()` 命令：

```
>>> animals.append("dog")
```

现在使用此打印命令访问更新后的列表：

```
>>> print(animals)
['cow', 'pig', 'dog', 'duck', 'lizard', 'dog']
```

动物 ‘dog’ 被添加到了列表的末尾。此外，如果你想在已列出的项目之间插入列表，请使用 Python 的 `insert()` 方法，语法如下：

```
list.insert(index, obj)
```

此处所需的基本参数是 index 和 object。同时，index 这里指新项目的特定位置，而 object 是项目本身。将语法规则应用于上面给出的示例，这是命令：

```
>>> animals.insert(4, "cat")
```

查看新列表：

```
>>> print(animals)
['cow', 'pig', 'dog', 'duck', 'cat', 'lizard', 'dog']
```

#### 字典数据类型

正如本书开头所述，Python 的变量和数据类型提供了一组唯一的键。字典在编码时很重要，因为它确保了对值的大量访问。简单来说，字典更像是一个列表，它使用不可变的唯一键来代替仅创建对值的访问。要分隔键，请使用冒号并将其括在花括号中。请查看下面的字典结构：

```
x = {key_1: c, key_2: d, key_3: cd}
```

同时，空字典将采用以下格式：

```
x = {}
```

字典的一个惊人事实是，它可以用来存储和操作成对的键值，如目录、菜单、登录数据或电话簿中的条目。此外，修改字典上的数据也是完全可能的。为了理解字典的结构及其工作原理，请考虑创建一个鼓配件及其价格的菜单，以键值对的形式存储：

```
menu = {"base": 14.40, "snare": 30, "cymbals": 20}
```

对于键值对及其在字典中的存储方式，请使用 `len()` 函数，如下所示：

```
>>> len(menu)
3
```

使用 print 命令获取 menu 字典中的当前条目：

```
>>> print(menu)
{'cymbals': 20, 'snare': 30, 'base': 14.40}
```

如果你想在 menu 字典中输入新条目，可以使用此格式：

```
d[key_4] = b
```

将此结构应用于 menu 字典，你可以按以下格式添加鼓配件 kick: 7：

```
menu["kick"] = 7
```

为了获取更新后的菜单，请使用 print 命令：

```
>>> print(menu)
```

你应该从一开始就得到此字符串：

```
{"base": 14.40, "kick": 7, "snare": 30, "cymbals": 20}
```

如果你想使用 `del` 命令从列表中删除任何项目，方式如下：（以 “base” 为例）

```
>>> del menu["base"]
```

查看删除 spam 后的修改列表：这显然是你将看到的列表：

```
{"kick": 7, "snare": 30, "cymbals": 20}
```

如果你想更改任何键的值，请使用下面的命令为其分配一个新值（以键 “snare” 为例，将其从 30 改为 25）：

```
>>> menu["snare"] = 25
```

再次访问 print 命令查看更新后的菜单：

```
>>> print(menu)
```

这将显示为列表：

```
{"kick": 7, "snare": 25, "cymbals": 20}
```

如果你想删除字典中的所有条目以存储其他内容，请使用函数 `dict.clear()`。这是命令：

```
>>> dict.clear(menu)
```

查看 menu 字典发生了什么，打印如下：

```
>>> print(menu)
{}
```

这将使你能够通过在字典上重复上述步骤来存储新数据。

## Python 运算符指南

### 算术运算符

在深入探讨运算符之前，您需要理解 Python 通过其内置计算引擎处理数学表达式。您可以轻松编写脚本来自动化任务，例如计算税费、小费、折扣或房租。以下是运算符、其功能和符号（注意：因为它们是数学运算，其符号与数学中的一致）：

| 运算符 | 功能 | 符号 |
| :--- | :--- | :--- |
| **加法** | 将左操作数和右操作数的值相加 | `+` |
| **减法** | 从左操作数的值中减去右操作数的值 | `-` |
| **乘法** | 将左操作数和右操作数的值相乘 | `*` |
| **除法** | 用右操作数除以左操作数的值 | `/` |
| **取模** | 返回左操作数除以右操作数/分母的余数 | `%` |
| **幂运算** | 执行指数计算 | `**` |
| **整除** | 执行向下取整除法 | `//` |

> **注意**：核心运算符是减法、乘法、除法和加法。它们通过配套表达式输入，并按其清理后的十进制数的相反顺序排列。

#### 示例

**减法**：

```
>>> 50 - 5
45
```

**除法**：

```
>>> 25 / 5
5.0
```

使用除法时，请注意取模运算符（`%`）给出执行除法的余数：

```
>>> 27 % 5
2
```

分母将在清除小数后返回余数：

```
>>> 23 / 8
2.875
```

**指数运算**：通过将基数提升到 `**` 运算符后数字指定的幂来调用：

```
>>> 4 ** 3
64
```

**加法**：

```
>>> 6 + 7
13
```

**乘法**：

```
>>> 5 * 7
35
```

这些运算应按其在编码策略中使用的方式给出。为此，您应该了解如何安排它们的使用。我们将使用一个服装预算策略。请查看下面的变量及其成本：

- 材料成本：`$55.55`
- 设计费率：`5.5%`
- 小费：餐费 + 税费的 `10%`（注意：您的小费基于表面成本和额外营业税，因此您需要获取餐饮信息和营业税的总和）。

要使用它们，请使设计费率和小费可用。为此，您应该给出表面总成本的比例：

```python
material = 55.55
```

使用 `100` 作为除数，为这两个变量分配费率的小数值：

```python
design_charge = 5.5 / 100
tip = 10 / 100
```
