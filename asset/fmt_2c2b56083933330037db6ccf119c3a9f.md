
在文献 [35] 中，使用 `ResNet-50` 网络 ([71]) 替代了编码器网络，并使用一个 2 层 MLP 投影头将表示投影到 128 维的潜在空间中。参考第 19.6.2 节中的通用方案，请注意，在这种情况下，输入集合 𝒳 和输出集合 ℋ 分别是单例，即 *N* = 1。编码器的输入由图像（而非图像块）组成，编码器相应地输出 2048 维向量。

现在让我们考虑两个不同的输入样本，例如表示为向量的图像 `x` 和 `x'`。它们每一个都会生成一对相应的变换版本，即 `(x̃_i, x̃_j)` 和 `(x̃'_i, x̃'_j)`。根据前面给出的定义，`(x̃_i, x̃_j)` 和 `(x̃'_i, x̃'_j)` 构成正样本对，而诸如 `(x̃_i, x̃'_j)` 或 `(x̃'_i, x̃_j)` 这样的样本对则对应负样本对，因为它们源自不同的图像。

为了满足当前的符号表示需求，我们保留 `N_t` 来表示可用训练样本的数量。经过数据增强步骤后，将会有 `2 * N_t` 个样本。此外，对于每一对正样本，将会有 `2 * (N_t - 1)` 个负样本。

训练的目标是获得所涉及参数 `θ`、`ϕ` 的估计值，使得对应于正样本对的输出被“拉近”，而与负样本对关联的输出被“推远”。在文献 [35] 中，使用了以下准则，称为*归一化温度缩放交叉熵*（NT-Xent），

### 对比学习损失函数

$(\mathbf{\theta}_*,\mathbf{\phi}_*) = \arg\min_{\mathbf{\theta},\mathbf{\phi}}\mathcal{L}(\mathbf{\theta},\mathbf{\phi})$

$$\mathcal{L}(\mathbf{\theta},\mathbf{\phi}) = - \sum_{(i,j) \in P^{+}}\ln\frac{\exp\left( \text{sim}(\mathbf{z}_{i},\mathbf{z}_{j})/\tau \right)}{\sum_{k = 1,k \neq i}^{2N_{t}}\exp\left( \text{sim}(\mathbf{z}_{i},\mathbf{z}_{k})/\tau \right)}.$$

求和遍历所有正样本对 ($P^+$)，每对考虑两次，即 $(i, j)$ 和 $(j, i)$。$\text{sim}(\cdot, \cdot)$ 是相似度度量，在文献 [35] 中采用归一化内积，即

$$\text{sim}(\mathbf{z}_{i},\mathbf{z}_{j}) = \frac{\mathbf{z}_{i}^{T}\mathbf{z}_{j}}{\|\mathbf{z}_{i}\|\|\mathbf{z}_{j}\|}.$$

毫无疑问，可以并且已经提出和使用了不同的相似度函数。所谓的温度参数 $\tau$ 是用户定义的参数。注意在公式 (19.53) 中，分子中正样本对的样本越相似，相似度函数的对应值越大（越接近 1）。相反，分母中负样本对的样本越不相似，相似度函数的对应值越小（接近 0）。

因此，通过最小化上述代价函数，编码器被训练以“学习”是什么语义特征使两个模式相似以及什么使它们不相似。换一种说法，用自监督学习（SSL）文献中流行的术语来说，模型学习的是**不变性**。数据增强被用来利用这些不变性的揭示。例如，使用裁剪结合给定图像的不同视角，SSL 模型被训练产生一种对不同裁剪具有**不变性**的表示。

正如自监督学习中总是发生的那样，在下游任务训练期间，只使用编码器，这与第 19.6.3 节所述一致。

公式 (19.53) 中涉及的损失函数与文献 [188] 中引入的所谓 infoNCE（噪声对比估计）损失函数非常相似，后者是通过信息论论证推导得出的。噪声对比估计方法最早见于文献 [69]。其基本思想是通过学习区分输入数据与人工生成的噪声，来估计描述模型的未知参数。因此，参数估计依赖于与数据形成对比的噪声。

对比学习准则的另一条路径是引入一个边界参数 `m`，它要求来自不同类别的样本（例如正样本和负样本）之间的距离大于 `m > 0`。*三元组损失* [195] 是该家族的一个典型例子。损失函数涉及三个样本：查询点或锚点、一个正样本和一个负样本。三元组损失要求两个距离之差（即查询点与正样本之间的距离，以及同一查询点与负样本之间的距离）大于边界 `m`。更正式地，三元组损失函数表示为

```
L = ∑_{(i,j) ∈ P⁺} ∑_{(i,k) ∈ P⁻} [ ||z_i - z_j||₂ - ||z_i - z_k||₂ + m ]₊
```

其中 `P⁻` 是所有负样本对的索引集，`[·]₊` 是合页损失函数（即 `max{0, ·}`，另见第 11.10 节）。该损失函数惩罚那些负样本到查询点的距离比相应正样本的距离小 `m` 的样本对。

多年来，人们提出并使用了各种对比损失函数（相关综述见例如 [13]）。文献 [183] 展示了各种对比损失的统一框架。此外，对比学习还被用于掩码自监督的背景下，以使输出与正确的掩码块相匹配，并与错误的掩码块形成对比（见例如 [183]、[9]）。在*动量对比*（MoCo）方案 [72] 中，对比学习被视为一个过程：利用对比损失，将在两个分支之一中产生的编码查询向量 `q`，与在另一分支中产生的编码键字典 `k₀, k₁, …` 进行匹配。字典键通过一组数据样本即时定义。

文献 [186] 对对比自监督学习进行了理论分析，指出只要两个视图提供关于标签的*冗余信息*，学到的表示在下游预测任务上就近乎最优。

### 备注 19.10

### 非线性投影器

非线性投影器 `g[ϕ]` 通常是一个具有两到三层的前馈神经网络，采用 ReLU 非线性激活函数。正如文献 [35] 所指出的，该投影器网络的使用对编码器的学习过程有益。值得注意的是，对比损失意味着信息的丢失，因为网络经过训练使得 `z = gϕ` 在变换下保持不变。因此，`g[ϕ]` 可能会移除对下游任务重要的信息，如颜色或方向。通过利用 `g[ϕ]`，更多信息可以被形成并保留在 `h` 中，后者是下游任务中使用的输入表示。

### 对比学习的理论分析

文献 [194] 提供了对比学习的理论分析。该文献引入了两个性质，即 **对齐** 和 **均匀性**。对齐倾向于赋予相同样本相似特征的编码器。均匀性促进保留最大信息的特征分布。研究表明，在无限负样本的极限下，对比损失直接优化这两个性质。这符合对比学习的精神，即表示应对不必要的细节保持不变，同时尽可能保留更多信息（例如文献 [188]）。

### 与深度度量学习的关系

对比技术与一系列称为 **深度度量学习** 技术的算法密切相关；相关评论见文献 [13]。

## 19.6.6 自蒸馏技术

知识蒸馏已被用作一种迁移学习方法。其核心思想是将大型网络（例如具有许多层和参数的神经网络）训练后获得的知识“蒸馏”/迁移到一个较小的网络中。这通常也是一个早期的想法，首次在文献 [166] 中用于将 RNN 的层级结构压缩为单个 RNN。随后，该思想在文献 [29] 和 [84] 中被用于模型压缩。

在迁移学习的背景下，该方法的基本原理是首先通过大量 **标记** 数据训练一个大型/复杂模型，称为 **教师** 模型。随后，通过一个主要由 **未标记** 样本组成的训练数据集训练一个较小的网络，称为 **学生** 模型。后一个训练集也称为 **迁移** 集。用于训练学生网络的目标/伪标签是教师网络的相应输出。例如，在文献 [84] 中，训练学生时，两个网络都接收相同的输入样本，而用于学生的伪标签是教师输出处相应的 **软** 类别概率。正如文献 [84] 所指出的，通过适当地将知识从大型网络蒸馏到小型网络，后者继承了前者的泛化特性。

采用两个共享知识的不同网络的思想已被用于自监督框架中。为此，输入样本的两个不同视图分别馈送给两个 **不同** 的编码器。其中一个分支作为教师进行训练，生成目标/伪标签，即作为目标网络运行。另一个分支作为学生，有时称为 **在线** 分支，被训练以预测相应的目标/伪标签。回顾一下，这种基本原理也属于图 19.16 所示的通用思想范畴。教师和学生网络在一组未标记数据上 **同时** 训练，目标是使两个网络分支的相应输出尽可能匹配。

然而，必须对上述设置保持谨慎。始终存在我们所谓的 **训练坍塌** 危险，这对应于一种不希望出现的平凡解。换句话说，两个分支的输出坍塌为一个常数。为了规避这一缺点，出现了一条研究路线，并提出了各种技术。

#### BYOL

在文献[66]中，提出了*bootstrap your own latent* (BYOL) 算法。对应的架构如图 19.21 所示。

通过从两个分布 `t ~ T` 和 `t' ~ T'` 中采样，生成输入的两个不同增强视图。在当前设置中，我们也假设（如第 19.6.5 节所述）通用方案的输入输出集合，即 `X`、`H`，为单例（`N = 1`）。

学生（在线）部分包含三个网络：

a) 表示（编码器）网络 `f_θ₁(·)`，

b) 投影网络 `g_θ₂(·)`，

c) 预测器网络 `q_θ₃(·)`。

在教师分支中，使用结构相同的表示网络和投影网络模型，但它们由不同的参数集参数化，即 `f_ξ₁(·)` 和 `g_ξ₂(·)`。

![图 19.21 BYOL：通过从两个分布 t ~ T 和 t' ~ T' 中采样，生成输入的两个增强视图。训练期间，在每个迭代步骤中，输出 z' 被固定，反向传播算法所需的用于参数更新的梯度仅在上层（学生）分支中向后传递。符号“sg”表示“停止梯度”操作。一旦所有 θ₁、θ₂、θ₃ 参数更新完成，教师分支的参数 ξ₁、ξ₂ 通过 EMA 动量方案进行更新。](img/gr021.jpg)

图 19.21 BYOL：通过从两个分布 `t ~ T` 和 `t' ~ T'` 中采样，生成输入的两个增强视图。训练期间，在每个迭代步骤中，输出 `z'` 被固定，反向传播算法所需的用于参数更新的梯度仅在上层（学生）分支中向后传递。符号“sg”表示“停止梯度”操作。一旦所有 `θ₁`、`θ₂`、`θ₃` 参数更新完成，教师分支的参数 `ξ₁`、`ξ₂` 通过 EMA 动量方案进行更新。

训练期间，参数集合（`θ₁`、`θ₂`、`θ₃`）被调整以最小化两个分支*归一化*输出差的平方范数。换句话说，学生分支的输出 `q_θ₃(z)` 和教师的输出 `z'` 首先通过各自的欧几里得范数进行归一化，即

$$

\overline{\mathbf{q}}_{\mathbf{\theta}_{3}}(\mathbf{z}) = \frac{\mathbf{q}_{\mathbf{\theta}_{3}}(\mathbf{z})}{||\mathbf{q}_{\mathbf{\theta}_{3}}(\mathbf{z})||_{2}},\ \text{and}\ \overline{\mathbf{z}}^{\prime} = \frac{\mathbf{z}^{\prime}}{||\mathbf{z}^{\prime}||_{2}},

$$

![Equation](img/si484.png)

最优参数集由此得出为

$$

(\mathbf{\theta}_{1 \ast},\mathbf{\theta}_{2 \ast},\mathbf{\theta}_{3 \ast}): = \arg\min\limits_{\mathbf{\theta}_{1},\mathbf{\theta}_{2},\mathbf{\theta}_{3}}\sum\limits_{n = 1}^{N_{t}}||\overline{\mathbf{z}}_{n}^{\prime} - \overline{\mathbf{q}}_{\mathbf{\theta}_{3}}(\mathbf{z}_{n})||_{2}^{2},

$$

![Equation](img/si485.png)

其中 $N_{t}$ 用于表示训练数据样本的数量。请注意，优化仅针对定义学生分支的参数进行。在第 $t$ 次迭代步骤中，教师分支的参数通过所谓的*指数移动平均*（EMA）（动量）原理进行更新，即

$$

\boldsymbol{\xi}_{i}^{(t)} = \alpha\boldsymbol{\xi}_{i}^{(t-1)} + (1 - \alpha)\boldsymbol{\theta}_{i}^{(t)},\quad i = 1, 2,

$$

![Equation](img/si486.png)

其中 `α ∈ [0, 1]` 是用户定义的动量项。由于参数 `ξ` 不是通过反向传播方案更新的，因此每个迭代步骤计算出的梯度仅在学生分支中传播。这由 "sg" 符号表示，该符号指示 "stop gradient"（停止梯度）传播操作。经验表明，使用这种训练策略，BYOL 避免了坍缩解。

在文献 [66] 中，使用了不同的卷积残差网络来实现编码器。对于宽度乘数为 1 的 ResNet-50 ([71]) 情况，编码输出 `h` 是一个 2048 维向量。然后，表示向量通过投影网络 `g` 投影到一个低维空间。后者实现为一个多层感知机，包含一个具有 4096 个节点的线性层，随后是批量归一化和 ReLU 激活函数，最后一层是一个具有 256 个输出节点的线性层。网络 `q` 具有与 `g` 相同的架构。

请注意，BYOL 在两个分支之间引入了两种类型的*不对称性*。一种是在线分支和目标分支之间的架构不对称性，这是由于上层分支中存在预测器。另一种来自于每个分支中使用的不同参数更新机制。这些不对称性有助于克服坍缩解。

避免坍缩解的上述基本原理衍生出许多变体，它们采用不同的损失目标和/或不同的架构，例如文献 [10] 中提出的所谓 *data2vec* 方案。文献 [145] 对 EMA 进行了研究，结果表明该算法具有某些稳定性质。此外，该文献还研究并比较了许多围绕 EMA 方案演进的方法。

#### SimSIAM

在文献 [34] 中，提出了所谓的*简单孪生网络*。它保留了 BYOL 中两个分支的主要思想，但不是采用 EMA 算法来更新目标分支，而是强制两个分支共享参数。然而，在反向传播算法的每次迭代中，会采用停止梯度操作来冻结其中一个分支中参数的适应，并将相应的输出视为常量。这种简单的修改被证明有助于增强对坍缩现象的鲁棒性。

在文献 [182] 中，尝试理解 BYOL 和 SimSIAM 方案关于其对坍缩鲁棒性的动力学特性。

#### DINO

*无标签蒸馏* (DINO) 算法在文献 [32] 中提出，它是 BYOL 的一个变体。保留了 EMA 方案。区别在于每个分支的输出被*离散化*为一个 `K` 维向量，并且两个分支的输出都通过我们熟悉的 softmax 操作转换为 `K` 个概率。然后，通过交叉熵损失函数量化两个分支之间的相似性。

DINO 方案是该主题一系列研究的演进，参见例如 [30]、[31]。其基本思想是将生成的输出表示离散化，然后求助于聚类论证。例如，在文献 [31] 中，提出了*多视角间的分配交换* (SwAV) 方案。两个分支的输出被离散化，形成一个包含 `K` 个原型的代码本，然后在参数学习的*同时*执行聚类操作。通过鼓励两个分支中的聚类分配相似来实现分支间的相似性。通过采用适当的正则化来促进形成的聚类尽可能均匀地分布，从而抑制坍缩。

## 19.6.7 基于相关性的技术

我们迄今为止所讨论的所有技术的主要思想，都是以某种方式（取决于具体方法）强制来自两个不同分支的数据之间的相似性/非相似性。在本小节的最后一类中，相关性的概念被用作相似性的度量。这导致了略微不同的任务公式化需求，我们将此类方案视为一个不同的类别。

我们讨论的舞台是典型相关分析 (CCA)，其在 20.4 节 中有更详细的论述。CCA 背后的主要思想是：如果涉及两组随机变量（两个随机向量），它们的相关性值取决于随机向量所表示的坐标系。CCA 的目标是为每组变量寻找一对线性变换，使得变换后的变量最大化相关。CCA 的主要思想已被推广为涉及非线性变换。例如，在文献 [5] 中，目标变为*联合*学习两个网络的参数，使其输出最大化相关。

#### Barlow Twins

这是该系列方案的一个典型例子。*Barlow Twins* 架构 [202] 遵循 图 19.19 中那样两个相同（参数共享）分支的理念。然而，它采用基于相关性的相似性强制损失，而不是对比损失。正如我们将看到的，这种损失函数具有避免坍缩的“内在”特性。

为简化符号，分别用 `z` 和 `z'` 表示两个分支的输出。为了形成相对于共享参数集 `θ`、`ϕ` 待最小化的损失函数，对一个输入样本的小批量求和，以计算相应的归一化互相关矩阵的元素，即：

```
C_{i,j} = \frac{\sum_{n}z_{ni}z_{nj}^{\prime}}{\sqrt{\sum_{n}z_{ni}^{2}}\sqrt{\sum_{n}z_{nj}^{\prime 2}}},
```

为简化起见，我们假设 `z[n]` 和 `z[n]'` 已被中心化为零均值。用于优化相关参数的损失函数被选定为使归一化互相关矩阵 `C` 尽可能接近单位矩阵 `I`。换句话说，对角线元素 `C[ii]` 尽可能接近 1，而非对角线元素 `C[ij]`（其中 `i ≠ j`）尽可能接近 0。这种损失函数可以表述为

```
L := Σ_i (1 - C_ii)² + λ Σ_i Σ_{j, j ≠ i} C_ij²
```

(19.54)

最小化 `L` 会迫使对角线元素接近 1，同时迫使非对角线元素接近 0，`λ` 是用户定义的正则化参数，用于权衡这两项的相对重要性。正如文献 [202] 指出的那样，试图将 *invariance*（不变性）项中的所有对角线元素都等同于 1，等同于增加两个向量在同一（第 *i* 维）维度上所有元素 `z[i]` 和 `z[i]'` 之间的相关性。换句话说，最小化任务通过这一不变性项，迫使两个分支的最终输出嵌入对输入变换施加的扭曲保持不变。同时，*redundancy reduction*（冗余降低）项通过试图将互相关矩阵的非对角线元素归零，对不同向量维度上的向量分量进行去相关。因此，输出单元包含关于输入样本的非冗余信息。冗余项的作用可被视为类似于对比损失函数（公式 19.53）中分母的角色，后者试图增加负样本对之间的不相似性。文献 [202] 表明，公式 (19.54) 中的损失函数是信息瓶颈目标 [184] 的一个实例化。
