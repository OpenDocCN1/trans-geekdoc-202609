### 5.7.1 二元随机变量

### 5.7.6 协方差与相关性

两个随机变量 `X` 和 `Y` 之间的 `covariance` 衡量了 `X` 和 `Y`（线性）相关的程度，这意味着 `X` 如何随 `Y` 变化，反之亦然。

- 随机变量平方的期望与该随机变量期望的平方之间的差是方差：`E(X²) – E(X)²`。

- 协方差 `E(XY) – E(X)E(Y)` 与方差相同，但这里比较的是两个随机变量，而不是单个随机变量与其自身。

- 相关系数 `Corr(X, Y) = ![img](img/138-1.png)` 是归一化后的协方差。

相关性的几个重要属性是：

1. `-1 ≤ corr[X, Y] ≤ 1`。因此，在相关矩阵中，对角线上的每个元素均为 1，其他元素在 -1 到 1 之间。

2. `corr[X, Y] = 1` 当且仅当 `Y = aX + b`（对于某些参数 `a` 和 `b`），即如果 `X` 和 `Y` 之间存在线性关系。

3. 根据属性 2，似乎相关系数与回归线的斜率有关，即表达式 `Y = aX + b` 中的系数 `a`。然而，回归系数实际上由 `a = cov[X, Y] / var[X]` 给出。解释相关系数的更好方法是将其视为一种线性程度。
