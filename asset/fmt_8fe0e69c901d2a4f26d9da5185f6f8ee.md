
得益于 `Apache Kafka`、`Apache Flink` 和 `Spark Streaming` 等系统，人们可以摄取数据并在过程中进行分析。因此，`ML` 模型可以在数据产生时进行处理，并交付即时洞察。例如，零售链的订单可以根据各门店实时销售数据进行动态调整。

这一趋势的关键特征是在线学习算法，它根据新数据的到来增量地更新 `ML` 模型。与批量学习相比，在线学习的优势在于它能确保模型无需重新训练整个数据集即可保持更新，从而节省了计算资源并降低了延迟。

## 3.8.2.2 在 BI 中的应用

实时数据流构成了以下用例的基础：动态定价、欺诈检测和客户体验个性化。例如，电子商务网站将应用有关客户交互的流数据，为消费者提供实时产品推荐，从而提高其转化率。在金融服务领域，实时异常检测系统可以快速警报疑交易，从而减少因欺诈造成的损失。

## 3.8.2.3 未来前景

集成了实时 `ML` 的 BI 系统不仅能提供事件反应，还能基于 `ML` 算法提供事件预测和实时响应。随着此类 BI 系统的普及，运营敏捷性将成为行业相继出现的新热门词汇。

## 3.8.2.4 IoT 驱动的 BI 洞察

`IoT` 设备（例如传感器、可穿戴设备和智能家电）持续收集指标数据，包括温度、位置、能源消耗和用户交互。随后，`ML` 模型通过处理数据样本提取出可操作的洞察。例如，在制造业中，由 `IoT` 启的预测性维护系统将分析传感器数据，预测设备何时可能发生故障并提前安排相应的维修。

零售商利用 `IoT` 数据优化店内布局和库存管理。通过使用 `ML` 对客户移动和产品交互进行分析，可以使模型建议商店配置，以实现销售额和客户满意度的最大化。

## 3.8.2.5 挑战与解决方案

`IoT` 数据具有高速度、高容量和多变性的显著特征，这给传统的 BI 系统带来了复杂性。因此，边缘计算以及分布式数据处理框架成为极具前景的解决方案，能够在靠近数据样本源的地方进行实时分析。此外，联邦学习正在开发保护隐私的技术，确保在不损害任何个人数据集的情况下对 `IoT` 数据进行分析。

## 3.8.3 决策中的新兴 ML 技术

`ML` 领域目前正经历着新一波创新创新技术的诞生，并将彻底改变 BI 集合中的决策理念。在这里，创新从早期的模型扩展出来，并可能用于进一步增强对过程的复杂且具有情境感知能力的洞察。

### 3.8.3.1 BI 中的强化学习

`RL` 通过试错训练智能体（agents）做出顺序决策，现在在 BI 应用中越来越受到关注。`RL` 在优化复杂系统（如供应链或投资组合）方面表现优异，其决策具有连锁反应。它在医疗健康和金融领域极其有用。

### 3.8.3.2 图神经网络 (GNNs)

`GNNs` 正在成为分析关系数据（如社交网络、供应链和客户交互）的重要工具。它们被用于社交媒体营销或预测客户流失。

### 3.8.3.3 自监督学习

依赖海量数据进行预训练的自监督学习使得 BI 在标记数据稀缺的领域成为可能。这将提高欺诈检测的准确性。

### 3.8.3.4 应用与未来影响

这些新技术开始推向 BI 的边界，因为它们导向了更好、更高效的过程。使用这些方法将带来额外的可扩展性、适应性和智能性。可解释 AI 支持了这种对透明度和信任的关键需求，而集成实时数据流则带来了更快的响应速度和更高的敏捷性。随着 `IoT` 更深层次贡献，基于 BI 的洞察范围从丰富的数据集中得到了丰富和扩展。因此，这些共同构成了下一代 BI 系统，使企业能够在不断流动的环境中以更高的精度、效率和预见性进行运营。

## 3.9 总结

`ML` 已与 BI 融合，通过利用数据实现对效率的规范性洞察以及创新策略，重新定义了组织内部决策方式的跨越。这些发现定义了 `ML` 在支持 BI 功能中的关键作用，并为围绕基于 `ML` 的解决方案实施业务运营提供了战略步骤。

### 3.9.1 ML 在带决策的 BI 中的作用

通过将 `ML` 整合到 BI 中，它将 BI 从回顾性分析工具转变为前瞻性的决策中心。传统的 BI 系统非常擅长总结过去趋势，但通常不具备对当前业务挑战进行预测和建议的能力。`ML` 在此过程中提供了帮助，因为它会处理海量数据并发现那些在不同场景下原本无法检测的模式。

预测分析是 `ML` 对 BI 的主要贡献之一。企业能够回归回归、随机森林（`Random Forests`）和梯度提升机器（`Gradient Boosting Machines`）等模型准确地预测销售、需求和市场趋势。这是企业能够更好地优化库存水平、资源利用和客户需求的能力之一。类似地，由 `RL` 和优化算法驱动的规范性分析为更改价格或在过程中优化供应链等结果提供了可操作的建议。

预测一直是 `ML` 承担的主要角色。但远超预测，`ML` 的意义大得多。事实上，通过无监督学习技术，企业可以进行客户细分、异常检测和探索性分析，揭示经典 BI 系统可能会错过的洞察。聚类算法的使用将有助于将这些内容归类为有意义的子集，作为针对性营销活动的基础并交付独特的客户体验。

此外，机器学习增强了商业智能（BI）的实时响应能力。实时数据流结合在线学习算法，确保决策能够根据最新信息做出。在电子商务和金融等领域，决策滞后可能会导致损失或风险增加。

尽管前景广阔，但不应忽视在 BI 中应用机器学习面临的挑战。必须解决数据质量、可扩展性问题、伦理问题和可解释性，才能真正利用机器学习驱动的 BI 系统。然而，所有这些问题正随着新的预处理工具、分布式计算、联邦学习和可解释人工智能（XAI）技术的发展逐步得到解决。

## 3.9.2 机器学习驱动的业务管理战略路线图

简而言之，必须采用路线图，并结合战略对齐技术，才能在无缝融入实现机器学习与 BI 所有潜在利益的过程中，否则将面对残酷的现实，以真正捕捉某些完整的运营现状。这一路线图的实际结果意味着了一系列在技术、组织和文化上定义的步骤和操作。

### 3.9.2.1 数据驱动的文化

这为数据驱动文化背景下机器学习赋能的业务管理奠定了基础。组织必须构建一种将数据视为战略资产的环境，并使具备充分数据素养的员工能够更好地解释数据提供的洞察。执行管理层的支持是必要的，因为在任何问题上，这都取决于领导层如何驱动这种数据驱动决策（DDDM）的实践。

### 3.9.2.2 投资基础设施和数据质量

高质量数据是机器学习模型的命脉。业务数据样本需要通过数据湖、数据仓库和集成平台等稳健的数据基础设施进行集中和标准化。需要建立数据治理框架，以确保数据的一致性、准确性并符合监管要求。应该建立预处理流水线，以自动化数据清洗、转换和特征工程，为机器学习分析准备数据。

### 3.9.2.3 选择最适合应用场景的适当机器学习技术

不同的业务应用需要不同的机器学习技术。对于预测任务，强大的监督学习模型主要是梯度提升回归树（GBM）和深度神经网络。像 k-means 聚类等无监督学习技术最适用于细分和探索性分析。此类应用非常适合优化问题，图神经网络（GNN）完美适合分析关系型数据样本。因此，企业需要分析其特定的应用，并在过程中选择最有前景的应用。

### 3.9.2.4 实时能力的整合

运行动态业务的人员应该能够将实时数据流注入 BI 系统。通过使用 `Apache Kafka` 和 `Spark Streaming` 等技术结合在线学习算法，流数据的摄取和处理是可行的。模型的更新确保了实时可行性，允许对开发中的事件做出快速响应，从而增强了运营灵活性，并提高了对不同场景下客户的响应速度。

### 3.9.2.5 挖掘物联网和新兴数据源

物联网（`IoT`）设备的使用增加为企业改进其 BI 系统提供了新途径。`IoT` 传感器数据和基于位置的信息将为运营和客户行为分析带来急需的丰富。边缘计算框架支持在边缘进行 `IoT` 数据处理，从而支持实时分析。企业应寻求与新兴数据源建立伙伴关系和合作，以补充他们现有的数据集样本。

### 3.9.2.6 实现可扩展且灵活的技术

可扩展性至关重要，因为处理日益增长的数据量、速度和多样性是必不可少的。分布式计算平台、云机器学习服务以及 GPU 等硬件加速器使企业能够扩展其机器学习能力。同样重要的是灵活性，模块化架构和 API 意味着组织可以在新工具和技术出现时轻松集成。

### 3.9.2.7 组建跨职团队

这种强大的机器学习驱动 BI 部署需要技术、分析和特定领域团队之间的跨学科协作。开发和部署符合业务目标的解决方案将需要数据科学家、工程师和业务分析师之间的合作。只有当跨职团队将其变为现实时，机器学习洞察才能证明在技术上是正确的、可操作的且与决策相关的。

### 3.9.2.8 监控、评估与迭代

机器学习模型和 BI 还需要对性能和相关性进行持续监控，以便决策者了解输出。持续创新是保持领先的关键。企业需要探索联邦学习和自监督学习等新兴技术，以数据驱动经济中开启新的可能性。无论是预测分析还是客户细分，机器学习的 BI 系统重新定义了运营的方式。

### 4.1 AI、ML 和 IoT 简介

ML 是 AI 最重要的子集之一，旨在开发允许计算机获取新数据并提供预测的算法。由于大数据的增加和更好的计算能力，ML 在过去的几十年中进展速度比任何时候都快 2。

因此，IoT 指一组连接和交互的设备，它们能够从周围环境中收集信息并对其进行操作，使物体智能化。通过无线通信、传感器和数据处理技术，智能 IoT 的增长清晰可见。目前，IoT 已应用于智能家居、医疗保健、工业控制和智慧城市等几乎所有领域。万物是指 AI 与 IoT 的结合，通过将 AI 集成到决策和数据处理中来增强设备 3。AI、ML 和 IoT 之间的关系如图 4.1 所示](#ch04.xhtml#_24032-0872-004-Figure-001)。

#### 4.1.1 在现代业务管理中的重要性

##### 4.1.1.1 提高效率和生产力

通过 AI、ML 和 IoT 为现代业务管理增加价值。AI 允许组织实时分析大量数据并对变化提供及时的决策和响应。由于它们旨在从性能数据中学习以帮助业务预测，并执行其他降低运营成本的功能，这些进步得到了支持 3。

##### 4.4.1.1.2 驱动创新和提升客户体验

除了优化生产力外，AI、ML 和 IoT 的采用继续为当前的业务管理开启新机会。通过这些技术，特定组织可以发现市场机会并开发独特的产品和服务。在消费者分析中，AI 收集消费者行为模式的数据，使公司能够应用适当的营销策略，甚至根据消费者偏好设计产品 1。
