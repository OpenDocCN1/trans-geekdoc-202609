# 扫描和枚举

在配置文件阶段收集 IP 地址后，黑客进入扫描阶段。黑客现在正在进行侦察，但这被视为*主动侦察*，因为他们实际上正在向组织的系统发送流量。

扫描阶段的目标是通过查明系统上开放的端口号，来找出系统上运行的服务。一旦黑客发现开放的端口号，他们将对系统进行*横幅抓取*，这会报告在该端口上运行的软件版本。黑客想知道软件版本的原因是为了研究如何利用该软件。

为了找出系统上运行的服务，黑客将对系统进行端口扫描，这会报告哪些端口是开放的。要进行端口扫描，黑客将使用像 `nmap`（命令行）这样的程序。例如，你可以使用 `nmap -sT 10.0.0.1` 对 10.0.0.1 系统进行端口扫描。图 20-6 显示了 `nmap` 命令的输出。你将在“用于评估安全的工具”部分进一步了解端口扫描。

网络映射软件也可用于识别已连接到网络的无效系统。这被称为*流氓系统检测*。

网络应用程序（如 Web 服务器、FTP 服务器，甚至启用了远程桌面的系统）使用客户端连接的端口号。作为安全专业人员，你可以通过对具有这些开放端口的系统进行*端口扫描*来在网络上定位这些系统。端口扫描的结果将告诉你哪些系统上有哪些端口开放，这应该有助于你评估黑客可能以何种方式攻破系统，因为每个应用程序都有不同的针对性漏洞利用。

# 漏洞扫描器

漏洞扫描器与端口扫描器截然不同。漏洞扫描器会扫描系统的已知漏洞，然后报告发现的问题。漏洞扫描器基于一个不断更新的漏洞数据库做出决策。当你进行扫描时，漏洞扫描器会将你的系统补丁级别和配置与漏洞数据库进行比较，以查看你是否未遵循最佳实践（即是否存在漏洞）。

- **Nessus** Nessus（参见图 20-9）是一款流行的漏洞扫描器，已存在多年，可用于扫描网络以识别漏洞和系统上缺失的补丁。

# 获取访问权限/初始利用

一旦黑客知道系统上运行了哪些端口以及这些端口上运行的软件版本，他们就会研究如何利用该软件。在流行产品上寻找漏洞利用代码是多么容易令人惊讶——只需去 Google 输入 **`exploit`**，然后加上你想要利用的产品名称。

黑客可以使用任何攻击类型进行 *初始利用* 以获取系统访问权限，但如今获取系统访问权限的流行方法包括缓冲区溢出攻击和其他类型的注入攻击。

一旦黑客获得系统访问权限，他们可能需要执行 *权限提升* 攻击。如果黑客攻破了系统但没有管理员访问权限，就需要这种攻击。黑客可以执行 *权限提升* 攻击以获得管理员访问权限。黑客可以通过多种方式执行权限提升攻击；例如，他们可以从 Windows 系统的 SAM 数据库中获取密码哈希，或者通过在具有系统级访问权限的进程相同地址空间中加载恶意 DLL 来执行 DLL 注入。

# 维持访问权限/持久化

一旦黑客获得了系统访问权限，他们希望确保稍后仍能获得访问权限。为了确保 *持久性*（即黑客稍后仍能获得访问权限），黑客会植入后门，例如创建管理员账户，或在系统上植入 Rootkit 或特洛伊木马病毒。

# 掩盖踪迹/清理

黑客过程的最后阶段是掩盖踪迹。黑客知道大多数安全专业人员会在其系统上实施审计或日志记录功能，并记录执行的任何活动。黑客制造可疑活动后，会在系统上找到日志文件，然后删除这些文件，或删除日志中与黑客活动相关的条目。因此，安全专业人员保护其日志文件至关重要，以确保没有人能销毁它们。

在渗透测试结束时，你将清理现场。这意味着如果你在系统上植入了一些后门，例如安装后台服务或创建后门账户，则需要在渗透测试结束时移除这些项目。你不希望在渗透测试完成后导致系统变得脆弱。

# 执行渗透测试的步骤

理解黑客过程的关键在于，作为渗透测试人员，你应该遵循该过程，使你的渗透测试类似于黑客获取访问权限所做的事情。这一点很重要，因为许多安全专业人员可能不会花时间执行分析阶段的步骤，这意味着你永远不知道你的组织在互联网上暴露了什么。在一门“道德黑客与对策”课程中，一位学员突然拿起手机冲出教室，打电话回办公室让他们拔掉内网服务器的网线——作为课程的一部分，他在分析自己的公司，发现他们的内网服务器暴露在互联网上！如果他没有分析他的公司，他永远不会知道机密信息正暴露在互联网上。

当你进行渗透测试时，遵循黑客过程并使用黑客使用的工具来执行真正的测试，看看系统是否可能被攻破，但也要遵循一个关于如何进行渗透测试的总体计划。以下是渗透测试中一些常见步骤的列表：

## 初次会议

通过与高层管理人员会面来启动流程，以了解他们希望您执行的工作范围。此时，您应确认是否可以执行所有类型的测试，例如拒绝服务攻击、缓冲区溢出攻击和密码攻击（仅举几例）。此外，此时您应重申：无法保证拒绝服务情况不会发生。

## 起草法律文件

初次会议后，咨询律师并起草一份法律文件，声明您被授权执行渗透测试。务必让您为其执行渗透测试的组织的授权代表签署该文件。

## 制定渗透测试计划

文件签署后，规划您将执行的攻击或测试类型。制定计划的目的是使您遵守纪律、遵循方法论开展工作，而非随意地入侵他人的网络。

## 测试渗透测试计划

测试您将用于执行不同类型攻击的工具，以确保它们正常工作，并查看执行时是否会导致拒绝服务。

## 执行渗透测试

此时您已在客户现场，按照计划执行渗透测试。务必测试密码破解、无线破解和缓冲区溢出攻击。同时测试组织的物理安全要素和社会工程学攻击。务必记录您所做的一切，包括每个步骤的开始和结束时间。

## 编写发现报告

测试完成后，编写发现报告。您不必包含所有活动的日志，但应随时备查以便参考。您应包含系统上攻击成功与失败的屏幕截图，以及改进安全性的建议。

## 汇报结果

在此阶段，您将再次与高层管理人员会面，汇报发现并提交报告副本。确保客户在已完成的评估上签字确认。

## 销毁报告副本

作为最后一步，确保您不再持有任何额外的评估副本，无论是打印形式还是电子形式。

# 执行漏洞评估

您可以执行的另一种安全测试（而非渗透测试）是漏洞评估。漏洞评估被视为一种被动评估类型，因为您并非实际模拟针对系统的攻击。通过漏洞评估，您旨在识别网络及其系统配置中的任何弱点，而不关心实际测试这些弱点以查看是否能攻破系统。

当管理层要求您评估安全性，但对您将在系统上运行黑客工具感到不安时，您应执行漏洞评估。其主要优势在于这是一种安全的评估类型，不会给系统带来拒绝服务的风险。

## 执行手动评估

执行漏洞评估时，我建议首先对网络及其系统进行手动评估。通过手动评估，您本质上是在执行配置评估，验证网络、客户端、设备和服务器的配置。在此手动评估中，您将检查是否遵循了最佳实践，例如确保每个系统都有密码策略并使用了防病毒软件。请记住，在大型网络上这可能耗时很长，因此拥有一份清单以保持进度至关重要。

## 执行自动化评估

执行漏洞评估时，您极有可能使用漏洞评估软件，例如 `LANguard` 或 `Nessus`。这是两款领先的漏洞评估产品，它们绝对能为您省去大量工作！为便于讨论，我将使用 `GFI LANguard` 来演示漏洞扫描器的实用性。
