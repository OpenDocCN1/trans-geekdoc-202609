
# Stellar

`Stellar` 是一个由分布式账本技术（`DLT`）驱动的支付协议。`Stellar` 使创建、发送和交易所有形式的货币（美元、披索、比特币和其他货币）的数字表示成为可能。它的设计使得世界上所有的金融系统可以在单个网络上协同工作。`Lumen` 是 `Stellar` 的原生货币，在 `Stellar` 网络成立时创建了 1000 亿个 `Lumen`。

## 管家 (Steward)

用于 `Sovrin` 网络，促进互联网上自主主权身份（`SSI`）的使用。`Sovrin` 管家是通过运行验证者节点来运营网络的组织，这些节点负责在 `Sovrin` 账本上进行读写操作。这些受信任的志愿者捐赠时间、资源和计算力来运行和维护网络，同时遵守 `Sovrin` 治理框架的要求。目前有来自6个大洲13个国家的50 名管家。

## 自杀合约 (Suicide contract)

自杀合约是一种带有安全回退选项的合约，可以通过所有者或受信任地址将其“杀掉”。这通常用于紧急情况，例如由于钱包或账户受到攻击或功能运行错误导致资金被抽取时。

# Swarm

`Swarm` 是一个分布式存储平台和内容分发服务，构建在以太坊区块链之上，拥有原生代币 `BZZ`。`Swarm` 用户向网络上传数据，这些数据会被分成小块。激励机制确保了节点操作者在发现、存储和传播数据块时获得奖励。`Swarm` 计账协议（`SWAP`）确保节点操作者在路由消息时进行协作。`ZetaSeek`（用户特定搜索引擎）、`Upala`（dApps 的唯一身份）、`Waggle`（无垃圾邮件去中心化电子邮件服务）和 `Swarmify`（去中心化音乐流媒体）都是在 `Swarm` 上构建的项目。

# 同步

区块链中的同步是指与主网保持一致。当启动一个新节点时，它需要从创世区块开始开始与当前区块链同步。新节点在为网络做出贡献或验证交易之前，需要追赶并达到网络速度。取决于协议和节点类型，同步可能需要大量时间。为了加速节点与区块链的同步，正在使用镜像技术。

# 合成衍生品

这些代表通过反向工程从单一证券获得现金流的证券。它们的设计目的是为了模拟衍生品，同时改变现金流和期限等重要属性。有一个名为 `Synthetix` 的区块链协议，可以在以太坊区块链上发行合成资产。它们通常以名为 `Synths` 的 `ERC 20` 智能合约形式存在，可以在不拥有资产的情况下提供资产回报。`Synths` 可以加密货币、索引或贵金属等现实资产进行交易。

# 安全代币

它们代表资产或公司的所有权，并为代币持有者提供资产收益或公司利润份额。从本质上说，它们可交易的金融资产。它们与实用代币不同；实用代币用于比特币、莱特币和以太坊等生态系统。另一方面，证券代币提供了生态系统的所有权。涉及出售证券代币以筹资金的发行称为证券代币发行（`STOs`）。`Sapien Equity Token`、`Robinhood Casino` 和 `Solarstake` 都是 `STO` 的示例。

# 滑点

滑点是加密交易预期价格与实际交易价格之间的差额。这是由于交易订单进入市场到实际执行之间的价格变动造成的。防止滑点的最佳方法是使用限价单而非市场市单。限价单为订单设置了最高买入限制或最低卖出限制，在满足条件之前不会执行。

# Terra

`Terra` 是一个区块链平台，包含许多挂钩不同法币货币的稳定币。稳定币的抵押由 `Luna` 币提供。它支持 `Oracle` 系统和智能合约，并有大规模用户采用的计划。`Luna` 和 `Terra` 在币安、火币等交易所交易。

# 测试网

除运行网络之外的第二个区块链网络，开发者用于测试新版本的客户端软件，而不会产生真实价值风险。比特币有比特币测试网（`Bitcoin Testnet`），以太坊有 `Ropsten`、`Kovan`、`Rinkeby`，而 `Hyperledger` 有 `Umbra`。

# Kovan 测试网

`Kovan` 指一个支持 `Parity` 客户端并使用权威证明（`PoA`）共识的以太坊测试网。它是 `Ethcore` 在 `Ropsten` 攻击后发行的第一个 `PoA` 测试网。

# Rinkeby 测试网

它指一个支持 `Geth` 客户端并使用权威证明共识的以太坊测试网。

# Ropsten 测试网

它指一个同时支持 `tGeth` 和 `Parity` 客户端并使用权威证明共识的以太坊测试网。它与主网非常相似。更多细节请参考第 `R` 节的 `Ropsten`。

# Tether

`Tether` 是一种具有争议的稳定币加密货币，代币由 `Tether` 有限 发。它曾虚假声称每个代币都有一个美元支持，但在 2019 年 3 月 14 日将支持改为包含对关联公司的贷款。

# Theta

`Theta` 区块链是唯一的去中心化视频流媒体和传输端到端基础设施，提供了技术和经济解决方案。它基于多 `BFT` 共识、签名传播方案并支持微支付。投资者包括索尼、三星等。

# Timothy_May

`Timothy C. May`，广为人 `Tim May`，是一位美国技术/政治作家、电子工程师和英特尔高级科学家。他创造了“加密无政府主义”（`Cryptoanarchy`）一词，政府不仅是多余的，而且是无关的。他的加密无政府主义运动导致了 `David Chaum`、`Wei Dai` 等密码朋克人的出现，他们编写了加密货币，并为比特币和区块链等去中心化加密货币的诞生奠定了基础。

# 上月（To the Moon）

“`To the Moon`”是一个用于加密货币价格破表时的感叹词。同样，当一个硬币的价格正在“涨月”（mooning）时，意味着价格已经达到了顶峰。相关信息：加密交易所 `Bitmex` 已与太空机器人公司 `Astrobotic` 合作，通过月球任务将比特币送上月球。

# 代币

代币是构建在现有区块链上的资产的数字表示。它们的设计旨在实现唯一性、即时可传输性、流动性、数字稀缺性和安全性。全球超过 380 个交易所交易着超过 10,000 种不同的代币。

# TPS（每秒交易数）

区块链网络中对现有区块链数据进行更改的输入或添加被称为交易。每秒可以容纳此类交易的数量为 `TPS`，它决定了区块链的速度。比特币的 `TPS` 为 7，以太坊为 25，莱特币为 56，`Cardano` 为 250，`ICON` 为 9000。

# 交易块

交易块指的是区块链上的交易集合，可以进行哈希处理并提交到区块链。它们类似于存储和记录交易的数字文件。

# 交易费用

验证交易并将其添加到区块链的工作由矿工或验证者执行。矿工使用强大的计算机来确认交易并维护区块链网络。为了做到这一点，他们将获得每笔确认并包含在区块中的交易费用奖励。这些交易费用是他们在每个区块添加到区块链网络时获得的区块奖励之外的。通常矿工优先验证手续费较高的交易。

# 三难题

指加密项目在设计底层架构和优化时必须解决的可扩展性困境。它们涉及扩展性的方面，如速度和交易量、节点分布以及防止网络完整受到破坏。

# Troll Box

这是一个为加密货币爱好者轻松交流而创建社交应用程序。存在于 `BTC-E` 和 `Poloniex` 等交易所。`Troll Box` 上的用户有助于提供不受审查、相关、准确和及时的新闻，帮助成员做出更好的交易决策。

# 无须（Trustless）

互联网创建了廉价且灵活的全球基础设施，并依赖于认可的权威或中介来促进信任。需要一种既具有互联网属性又能够在无信任中介的情况下提供真实声明的全球信息系统，这种系统被称为无须。区块链实现了信任计算。

# 图灵测试

由艾兰·图灵于1950 年发明，最初被称为模仿游戏，评估机器表现出人类同等智能和行为的能力。机器将与人类和评估者进行对话，如果评估者无法区分机器和人类，则认为机器通过了测试。结果基于机器提供的答案与人类答案的相似程度，而不是必然正确答案。

# 图灵完备

如果一台机器可以执行任何其他可编程计算机能够执行的计算，则被认为是图灵完备的。现代计算机在这意义上都是图灵完备的。运行在以太坊区块链上的以太坊虚拟机（`EVM`）也能够处理任何“可计算函数”。简而言之，它能够完成你使用任何传统计算机和编程语言可以完成的工作

# 代币化

代币化是一个将业务商品、策略或服务转换为可交易且可在区块链上记录的离散单元的过程。有助于增加底层资产的流动性并促进价值的释放。

# 代币经济学

加密货币的供需特征代表了代币经济学。它基于哈佛心理学家`BF·斯金纳`（`BF Skinner`）于1972年提出的代币经济理念。他认为通过提供某些可识别价值的单位，可以控制行为并激励积极行动。它还研究加密货币在更广泛生态系统中的运行方式，涵盖代币分配以及激励机制如何促进网络中的积极行为。

# Tendermint

一种用于构建区块链（特别是 `Cosmos` 生态系统）的区块链应用和领先的拜占庭容错（`BFT`）引擎。支持 `Tendermint Core` 和 `Gaia`。`Tendermint core` 为所有忽略编程语言的区块链应用提供 Web 服务器、数据库和支持库。

# Tezos

`Tezos` 是一个基于权益证明（`Proof of Stake`）的开源区块链网络，以 `TEZ` 作为原生货币，促进点对点交易和智能合约。`Tezos` 智能合约使用形式化验证，使其在数学上是验证的。

# TVL (总锁仓量)

`DeFi` 世界中的 `TVL` 指单个去中心化交易所（`DEX`）、去中心化应用（`dApp`）或整个生态系统内部持有的资金。`Curve Finance`、`Uniswap`、`Sushiswap`、`Bancor` 和 `Balancer` 是根据各自的 `TVL` 的一些领先 `DEX`。

# Ubuntu

`Ubuntu` 是由 `Mark Shuttleworth` 于 2004 年 10 月创建的 Linux 发行版。它基于 `Debian`，主要由自由开源软件组成，旨在解决 Linux 中存在的由于各种不支持的社区版导致的碎片化问题。它与以太坊的许多开发工具兼容。`Ubuntu` 是一个完整的 Linux 操作系统，提供社区和专业支持。事实上，它被称为世界上第一个免费软件，也是第一个按照可预测间隔和节奏定期发布的操作系统。`Ubuntu Desktop` 还是世界上最广泛使用的 Linux 工作站平台。`Ubuntu Server` 是 `Openstack` 项目的参考操作系统，也是 `AWS`、`Google` 和 `Azure` 上流行的操作系统。

# 父区块 (Uncle Blocks)

父区块与比特币的孤儿区块（`Orphan blocks`）类似；当两个区块在同一时间被挖掘并提交到账本时，它们会在以太坊区块链中创建。只有一个作为一个区块进入账本，另一个不能，因为它的工作证明份额相对较低。以太坊系统中父区块会有奖励，与比特币中的孤儿区块不同。`UTXO` 基于 `Hal Finney` 的可重用工作证明提案，而该提案又基于 `Adam Back` 的 `Hashcash` 提案。

# Uniswap

`Uniswap` 是最流行的基于以太坊的 `DEX`，是一种用于交换加密货币的去中心化金融协议。该协议通过智能合约和自动做市商（`AMM`）模型促进以太坊区块链上加密货币代币之间的自动交易。由 `Hayden Adams` 于 2018 年使用 `Solidity` 开发。

# 不可链接性

它有助于为公共区块链提供匿名性。在比特币中，当难以链接属于同一用户的多个地址和交易时，就会发生不可链接性。

# 美元币 (USD Coin)

`USD Coin` (`USDC`) 是一种挂钩美元的数字稳定币，运行在以太坊、`Stellar` 和 `Algorand` 区块链上。每个 `USDC` 都有一个储备美元支持。`USD Coin` 由一个名为 `Centre` 的财团管理。它由 `Circle` 公司创立，该公司帮助互联网企业在一个统一的平台上接受和支付付款。

# UTXO (未花费交易输出)

`UTXO` 定义了区块链交易中未被花费的输出，即可以作为新交易的输入。换句话说，它可以定义为执行加密货币交易后剩余的数字货币金额。它有助于简单地防止双花费，无需扫描整个区块链。比特币使用 `UTXO` 模型来防止双重计算和花费。`UTXO` 基于 `Hal Finney` 的重用工作证明提案，该提案又基于 `Adam Back` 的 `Hashcash` 提案。

# UBIN (项目 UBIN)

`Project Ubin` 是一个与行业合作的项目，旨在探索区块链和分布式账本技术（`DLT`）用于支付和证券清结算与结算。该项目旨在帮助新加坡管理局（`MAS`）和行业通过在代币化新加坡元、重新设计实时全额结算（`RTGS`）货币转账、交收即付（`DvP`）和跨境支付中的实际实验和广泛的生态协作，更好地理解 `DLT` 及其可能带来的收益。

# *Ursa*

`Hyperledger Ursa` 是一个共享加密库，防止加密工作的重复，从而提高区块链网络的整体安全性。`Ursa` 的两个主要组件是 `Base-Crypto` 库和 `Z-Mix`。它的库作为 `Hyperledger` 和非 `Hyperledger` 项目使用加密的仓库。

# 验证者 (Validator)

验证者是验证区块链上所有输入交易并用其私钥对这些验证过的交易进行签名的人。

# 空壳软件 (Vaporware)

它是一种早期向公众发布的产品（通常是计算机硬件或软件），但延迟延迟要么从未制造或被正式取消。在区块链领域，它指的是由于缺乏适当的用例或技术支持项目的承诺或主张而从未实现或启动的加密货币项目。`Tron` 和 `Verge` 在早期曾被认为是加密世界的空壳软件。

# VeChainThor

`VeChainThor` 是一个公共区块链，由 `Sunny Lu` 于 2015 年构思并于 2016 年发布。它旨在让企业用户大规模采用区块链技术，以增强供应链可见性、碳信用和防伪服务。它为供应链提供数字可验证的可溯性。它托管了 `VeChain` 生态系统，使用物理跟踪设备跟踪供应链的每个阶段。由 `VeChain` (`VET`) 代币和 `VeThor` 令牌 (`VTHO`) 驱动，`VET` 用于价值的存储和传输，`VTHO` 作为能量令牌（燃料）支付网络上的交易。

# VIPER (Viper 协议)

`Viper Protocol` 是基于 `Harmony` 区块链的跨链多产品 `DeFi`（去中心化金融）协议。`VIPER` 是原生治理和收益生成令牌，用于 `Viper Exchange/DEX` 以及在 `Harmony` 区块链上运行的所有 `DeFi` 产品。它还兼容币安智能链、`Fantom` 等。

# VMAC (v消息认证码)

`VMAC` 是一种基于分组密码的消息的消息认证码（`MAC`）算法，使用了 2007 年 4 月由 `Ted Krovetz` 和 `Wei Dai` 提出的通用哈希。该算法旨在用于 64 位系统上的高性能，并有形式化分析的支持。

# Vyper

`Vyper` 是一种用于编写智能合约的合约导型 Python 编程语言。它由 `Vitalik Buterin` 和 `Gavin Wood` 创建。它的功能比 `Solidity` 少，但使合约更安全且易于审计。它取代了最初为以太坊开发的 `Serpent`。

## 维里克·布特林

`Vitalik Buterin` 是以太坊的联合创始人兼创造。他在2011年作为《比特币杂志》联合创始人的身份进入加密货币世界。他在2014年与 `Gavin Wood` 一起发了太坊。他还因慈善事业而闻名，向各种机构和基金会捐赠了价值超过15 亿美元的加密货币。

## W3C (万维网联盟)

`W3C` 成立于1994年，由万维网发明者蒂姆·伯纳斯-李领导，致力于开发万维网标准。这些开放标准供所有人访问，以便 Web 能够作为一个“单一网络”运行，并推动人类的创新。`W3C` 致力于促进以下设计原则：1. 全民性 Web（无论硬件、软件、母语、身体或心理能力如何，所有人都能受益）和2. 万物皆 Web（通过手机、智能手机、自助终端、交互式语音响应系统等访问 Web）。

## 钱包

钱包是一种允许加密货币用户存储和检索数字资产的应用程序。五种主要的加密货币钱包包括移动钱包、桌面钱包、纸质钱包、硬件钱包和在线钱包。

## Web3.js

它指的是一组库，允许用户使用 `HTTP`、`WebSocket` 协议或 `JSON` 远程过程调用 (`RPC`) 与本地或远程以太坊节点交互。它由以太坊基金会创建，便于获取用户账户、发送交易以及与智能合约进行交互。

## 信任网 (Web_of_Trust)

信任网是用于 `PGP`（优佳隐私）的一个概念。它最初由 `Phil Zimmerman`、`GnuPG` (`GNU Privacy Guard`) 以及其他 `OpenPGP` 兼容系统创建，用于建立公钥与其所有者之间关系的真实性。它以去中心化的方式使用信任模型，被认为是依赖中心权威的公密钥基础设施 (`PKI`) 中心化信任模型的良好替代方案。

## Web3

`Web3` 可以被称为互联网后端的革命，而 `Web2` 是前端革命。它是一组由区块链引导的协议集，旨在重新设计互联网后端的连接方式，将互联网逻辑与计算机逻辑相结合。它赋予用户控制自己数据的能力，并创建了一个原生结算层。它为互联网带来了被遗忘和删除的权利。

## 大卫维

`Wei Dai` 是一位计算机工程师和著名的密码朋克，因对密码学和加密货币的贡献而闻名。他是 `Terra Sciences` 的程序员，也是微软加密货币研究小组的成员。他开发了 `Crypto++` 密码库，创建了 `b-money` 加密货币系统，并共同提出了 `VMAC` 消息认证算法。他还通过识别加密块链模式（`CBC`）中的漏洞为 `SSH2` 漏洞的发现做出了贡献。

## Wei

`Wei` 是以太（以太坊网络使用的加密货币币）的最小单位。一个 `wei` 是一个以太的十亿分之一。`Wei` 以计算机工程师大卫维命名，他因对密码学和加密货币领域的贡献而闻名。

## 巨鲸 (Whale)

巨鲸指的是持有大量比特币的个人或实体。凭借持有大量的加密货币，他们具有操纵货币价格和估值的潜力。`Barry Silbert`、`Tim Draper`、`Michael Novogratz`、`Tyler & Cameron Winklevoss` 都是著名的比特币巨鲸。

## 什么时候买兰基 (When Lambo)

这是一个用来代表加密货币成功的俚语。当一个新的加密货币或代币被发布时，人们会问“When Lambo”，以表示币价何时能足够买一辆兰基尼。

## 私语 (Whisper)

`Whisper` 是以太坊 `P2P` 协议栈的一部分，允许用户通过区块链运行的网络进行消息传递。它是一个纯基于身份的消息传递系统，提供简单的底层 `API`，且不基于或不受底层硬件属性和特征的影响。

## 世界状态 (World State)

世界状态是一个键值存储，随着交易和链码执行而更新。它是 `Hyperledger Fabric` 账本的一个组件。它代表链交易日志中所有键的最新值。每当键的值改变时，世界状态就会发生变化。
