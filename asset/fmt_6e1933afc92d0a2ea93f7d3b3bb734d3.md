
将计算得到的 `Z` 值与给定显著性水平 `α` 下的显著性值 `Z_{α/2}` 进行比较。如果 `Z` 值落在定义的临界区内，则以置信度 `1 - α` 拒绝原假设。选择 `α = 0.01`，我们可以断定原假设（即此处的专家委员会的主张）是错误的，并可以 99% 的置信度将其拒绝。

现在，让我们看几个假设检验的例子，在这些例子中我们将遵循上述步骤来验证统计假设。

### 示例：检验一枚骰子是否均匀或无偏

检验一枚骰子是否均匀或无偏（即所有六个面值出现的可能性相等）。一枚骰子被投掷 9000 次，出现 5 或 6 的次数为 3600 次。这枚骰子是否无偏？

对于一枚无偏骰子，每个面的概率为 `1/6`。我们可以将出现 5 或 6 的事件视为成功，并用 `S` 表示。我们有 `P(S) = 1/3`。出现除 5 或 6 以外的任何值均视为失败。因此，我们得到一个二项分布变量，试验次数 `n = 9000`，成功概率 `p = 1/3`，观察到的成功次数为 3600。此处，原假设为 `H_0: p = 1/3`，即 `p = 0.333...`，备择假设为 `H_1: p ≠ 1/3`。设随机变量 `X` 表示成功的计数。对于二项分布，均值为 `np`，方差为 `npq`：

因此，对于大 `n`，`μ = 3000` 且 `σ² = 2000`

所以，`Z = (3600 - 3000) / √2000 ≈ 13.42`

由于 `Z > Z_{0.005} ≈ 2.576`，选择显著性水平 `α = 0.01`，根据正态分布的经验法则可知此点。因此，`Z` 落在临界区或拒绝域内。所以，我们可以以 99% 的置信度拒绝原假设。因此，该骰子不是一枚均匀骰子。

## 统计推断

让我们考虑一个具有概率密度 `f(x; θ)` 的随机变量 `X`。此处，`θ` 表示分布的参数集合，或更正式地说，`θ` 表示参数向量。例如，在正态分布的情况下，`θ = (μ, σ²)`。所有参数可能取值的集合称为参数空间。因此，参数空间定义了一族概率分布：

```
{ f(x; θ) : θ ∈ Θ }
```

现在，让我们考虑一个来自总体的大小为 `n` 的随机样本 `X_1, X_2, ..., X_n`，其概率密度函数为 `f(x; θ)`。我们能否将参数向量 `θ` 作为样本值的函数进行估计？也就是说，我们能否定义一个统计量 `t` 来近似总体参数？设向量 `X = (X_1, X_2, ..., X_n)`，那么我们想要寻找样本统计量：

```
θ̂ = t(X)
```

使得 `θ̂` 的分布集中在总体参数 `θ` 的真实值附近。此处，`t(·)` 描绘了统计量 `θ̂` 的估计量函数。在这种情况下，统计量 `θ̂` 称为总体参数 `θ` 的估计量。

### 估计量的性质

现在让我们讨论什么样的统计量性质使其成为一个好的估计量：

*   **无偏性**：如果 `E(θ̂) = θ`，则估计量 `θ̂` 称为总体参数 `θ` 的无偏估计量。假设对于一个具有概率分布 `f(x)` 的未知总体，我们已知期望：`E(X) = μ` 和 `Var(X) = σ²`。样本点 `X_i` 可以视为一组 `n` 个独立同分布（i.i.d.）随机变量 `X_1, X_2, ..., X_n`，它们取值 `x_1, x_2, ..., x_n`，且每个 `X_i` 均具有均值 `μ` 和方差 `Var(X_i) = σ²`。对于统计量样本均值 `X̄`，我们有 `E(X̄) = μ`。

    因此，样本均值是总体均值的无偏估计。样本方差的期望如下：

    ```
    E(S²) = (n-1)/n σ²
    ```

    证明参考见延伸阅读部分 [3]。因此，样本方差不是总体方差的无偏估计。

*   **一致性**：对于任意估计量 `θ̂_n`，我们可以定义一个变量序列：`θ̂_1, θ̂_2, ..., θ̂_n`。此处，`θ̂_n` 取决于所取样本值的数量 `n`。如果这一数值序列 `θ̂_n` 依概率收敛于真实参数值，则称估计量 `θ̂` 为参数值 `θ` 的一致估计量。我们将其表示为 `θ̂_n → θ`，其中算子 `→` 表示依概率收敛，即对于任意任意小的 `ε`：

    ```
    lim_{n→∞} P(|θ̂_n - θ| > ε) = 0
    ```

    显然，样本均值是总体均值的一致估计量。

*   **有效性**：对于一个总体参数，可能存在多个无偏且一致的估计量。因此，需要进一步的准则来选择最佳估计量。方差较小的那个称为有效估计量，因为它的取值倾向于更紧密地集中在参数的正确值周围，因此我们的估计将更接近实际值。对于正态分布，由于钟形曲线的对称性，样本中位数也是总体均值 `μ` 的无偏估计。那么，应该选择哪一个作为更好的估计量？这里我们可以比较两个估计量的方差或标准误的平方。现在，`Var(X̄) = σ²/n`，且可以证明对于样本中位数 `Md`，`Var(Md) ≈ πσ²/(2n)`。因此，样本均值是 `μ` 的更有效估计量。

*   **充分性**：如果一个估计量包含样本中关于被估计总体参数的所有信息，则称其为充分估计量。估计量的这一性质超出了本书进一步讨论的范围。

### 最小方差无偏估计量

如果统计量 `T` 是总体参数 `θ` 的无偏估计量，且 `T` 在所有无偏估计量类中具有最小方差，则称 `T` 为 `θ` 的最小方差无偏估计量。形式上：

*   `E(T) = θ`
*   `Var(T) ≤ Var(T')` 对所有无偏估计量 `T'` 成立

MVU 是唯一的。要检验一个无偏估计量是否为 MVU，可使用克拉默-拉奥不等式。该不等式为参数无偏估计量的方差提供了一个下界。量 `E(θ̂) - θ` 通常称为估计量的偏差。对于无偏估计量，偏差为零。

### 似然函数

设 `X` 为服从概率分布 `f(x; θ)` 的随机变量。来自该概率分布的给定随机样本 `X_1, X_2, ..., X_n` 可视为一组 `n` 个 i.i.d 随机变量 `X_1, X_2, ..., X_n`，它们取值为 `x_1, x_2, ..., x_n`，且每个 `X_i` 均具有概率密度 `f(x_i; θ)`。我们将这些随机变量 `X_1, X_2, ..., X_n` 的联合密度函数定义为似然函数 `L`：

```
L(θ; x_1, ..., x_n) = ∏_{i=1}^n f(x_i; θ)
```

由于随机变量 `X_1, X_2, ..., X_n` 相互独立，联合密度函数表示为乘积形式。显然，似然函数总是正数，即 `L > 0`。对两边取对数可将乘积转化为对数之和，即 `log L = ∑_{i=1}^n log f(x_i; θ)`。这称为对数似然。

## 克拉默-拉奥不等式

若 `T` 是总体参数函数 `g(θ)` 的无偏估计量，则：

```
Var(T) ≥ [g'(θ)]² / I(θ)
```

因此，这给出了无偏估计量方差的一个下界。此处，分母中的量称为样本中包含的关于参数 θ 的费舍尔信息量，记为 `I(θ)`。费舍尔信息量值越高，样本中关于该参数的信息就越多。

若我们要估计参数 `θ`，函数 `g(θ)` 可取为恒等函数 `g(θ) = θ`，因此 `g'(θ) = 1`。于是，克拉默-拉奥不等式呈现以下形式：

```
Var(T) ≥ 1 / I(θ)
```

换句话说，我们估计 `θ` 的精度（即方差的倒数）受限于费舍尔信息量。

我们将在某些正则性假设下，证明单参数 `θ` 的单变量分布的克拉默-拉奥不等式。理解该证明很重要，因为它向我们展示了寻找 MVU 估计量的一种途径。

### 正则性假设

*   参数空间是 R 中的开区间
*   偏导数 `∂/∂θ log f(x; θ)` 存在
*   `I(θ) = E[(∂/∂θ log f(x; θ))²]` 存在且对所有 `θ` 均为正
*   概率密度函数 `f(x; θ)` 可在积分号下求导

## 克拉默-拉奥不等式的证明

由于 `L` 是样本 `X_1, ..., X_n` 的联合概率密度函数 `∏ f(x_i; θ)`，其中 `θ` 是参数，对 `θ` 求导并利用正则性条件，可得：

```
∂/∂θ log L = ∑ ∂/∂θ log f(x_i; θ)
```

设 `T` 为 `g(θ)` 的无偏估计量。因此，`E(T) = g(θ)`。

对两边关于 `θ` 求导，并利用正则性条件对积分求导：

```
∂/∂θ E(T) = g'(θ)
```

此处，`T` 和 `∂/∂θ log L` 是两个实随机变量，对任何给定样本均取固定实值。任意两个随机变量 `X, Y` 的协方差为 `Cov(X, Y) = E(XY) - E(X)E(Y)`。因此，此处：

```
Cov(T, ∂/∂θ log L) = g'(θ)
```

相关系数 `ρ = Cov(X, Y) / √(Var(X)Var(Y))`。利用期望的柯西-施瓦茨不等式，我们已证明 `Cov(X, Y)² ≤ Var(X)Var(Y)`，当且仅当 `X` 和 `Y` 线性相关。

此外，`Var(∂/∂θ log L) = I(θ)`，这是根据 `I(θ)` 的定义。

因此，`g'(θ)² ≤ Var(T) I(θ)`。此处：

```
Var(T) ≥ g'(θ)² / I(θ)
```

将此方差代入上述不等式并整理，即得克拉默-拉奥不等式：

```
Var(T) ≥ [g'(θ)]² / I(θ)
```

现在，我们将探讨无偏估计量何时达到这一最小方差界。重新整理前一等式，得：

```
Var(T) - [g'(θ)]² / I(θ) = E[ (T - g(θ)) - g'(θ)/I(θ) * ∂/∂θ log L ]²
```

此处：

```
X = T - g(θ)
Y = ∂/∂θ log L
```

这符合期望的柯西-施瓦茨不等式 `Cov(X, Y)² ≤ Var(X)Var(Y)` 的形式，我们已知当且仅当随机变量 `X` 与 `Y` 线性相关时，该不等式取等号。因此，等号成立当且仅当 `T - g(θ)` 与 `∂/∂θ log L` 线性相关，即：

```
T - g(θ) = k(θ) * ∂/∂θ log L
```

此处，`k(θ)` 可能依赖于 `θ`，但与样本无关。在这种情况下，无偏估计量 `T` 称为最小方差界（MVB）估计量。

### 示例

假设 `X_1, ..., X_n` 来自均值为已知零值、尺度参数 `σ²` 未知的正态分布的随机样本。`σ²` 的一个 MVB 为 `T = (1/n) ∑ X_i²`。

因为 `E(T) = σ²`，统计量 `T` 是 `σ²` 的无偏估计量。现在，让我们看看 `T` 能否达到克拉默-拉奥下界。

```
∂/∂θ log L = ∑ (X_i²/σ⁴ - 1/σ²) = n/σ⁴ * (T - σ²)
```

样本的似然函数如下：

```
L = (2πσ²)^{-n/2} exp(-∑ X_i² / 2σ²)
```

因此，`T - σ²` 与 `∂/∂θ log L` 线性相关，因为 `n/σ⁴` 与样本无关。因此，`T` 是 `σ²` 的 MVB。类似地，我们可以证明：在总体尺度参数已知的情况下，正态分布的 MVB 估计量均值 `μ` 为样本均值 `X̄`。建议您自行尝试验证。

到目前为止，我们讨论了如何检验估计量的优劣并选择最优者，但估计量作为样本的任意函数，可以采取任何函数形式。如何定义估计量？是凭直觉，还是有寻找可能估计量的程序？这将在下一节中解答。

## 最大似然估计法（MLE）

最大似然原则在于寻找未知参数 `θ` 的一个值 `θ̂ ∈ Θ`，使得对所有可能的 `θ` 值均有 `L(θ̂) ≥ L(θ)`。这定义了一个标量场 `L(θ)` 的优化问题，其中 `Θ` 表示参数空间。

由于 `log L` 是 `L` 的非递减函数，`L` 和 `log L` 在同一点取得最优值。因此，我们可以最大化 `log L` 代替最大化 `L`。利用微分学，通过求解 `∂/∂θ log L = 0` 可找到最优值。为确保该方程确实给出似然函数的最大值，必须进行二阶导数检验 `∂²/∂θ² log L < 0`，或 `∂²/∂θ∂θᵀ log L` 的海森矩阵必须为负定矩阵（针对向量值参数）。

### 示例

让我们求泊松分布参数 `λ` 的 MLE 估计值。

假设 `X_1, ..., X_n` 为来自总体的样本，似然函数如下：

```
L = ∏ e^{-λ} λ^{x_i} / x_i!
```

此外，`L > 0`，因为来自泊松分布的所有样本均为正，使得 `λ > 0` 始终为正。估计量的方差可通过克拉默-拉奥最小方差界获得：

```
Var(λ̂) ≥ 1 / I(λ) = λ/n
```

而且，`λ̂ - λ` 与 `∂/∂λ log L` 线性相关，因此克拉默-拉奥不等式中的等号应成立，即 `Var(λ̂) = λ/n`。

> **注意：一个更一般的结果如下：若给定总体密度为 `f(x; θ)` 且存在 MVB 估计量 T，则似然方程 `∂/∂θ log L = 0` 的解即为 T。**

此外，MLE 估计量具有相合性和有效性。我们仅陈述关于此的以下两个定理：

**定理（克拉默-拉奥）**：给定样本量为 n，当 `n → ∞` 时，似然方程 `∂/∂θ log L = 0` 有一个解，该解依概率收敛于参数 `θ` 的真实值 `θ₀`。

该定理表明 MLE 估计量是相合的。

**定理**：若 MLE 估计量存在，则它们是在估计量类中最有效的。

**示例**：单变量正态分布参数 `θ = (μ, σ²)` 的 MLE 估计为来自单变量正态分布 `N(μ, σ²)` 的样本 `X_1, ..., X_n`。`L(θ)` 由 `∏ f(x_i; θ)` 给出。

```
log L = -n/2 log(2π) - n/2 log σ² - 1/(2σ²) ∑ (x_i - μ)²
```

我们知道 `σ²` 的估计 `σ̂² = (1/n) ∑ (x_i - μ̂)²` 是有偏的。因此，MLE 估计并不总是无偏估计。

**示例**：多元高斯分布的 MLE 估计。假设我们有从多元高斯分布中采样的 `X_1, ..., X_n`。我们想要使用 MLE 估计该分布的参数 `θ = (μ, Σ)`。此处 `μ` 是一个向量，`Σ` 是一个矩阵。因此，我们需要计算对数似然关于向量和矩阵的偏导数。有了第 3 章 中讨论的向量微积分背景，推导过程很容易理解。感兴趣的读者可参阅延伸阅读 [5]。

> **注意：MLE 估计如下：**
>
> ```
> μ̂ = (1/n) ∑ X_i
> Σ̂ = (1/n) ∑ (X_i - μ̂)(X_i - μ̂)ᵀ
> ```

还有其他估计方法，如最小二乘法、矩估计法、贝叶斯参数估计（MAP）。我们将简要讨论贝叶斯估计，即借助贝叶斯规则估计参数 `θ`。

```
P(θ|X) = P(X|θ)P(θ) / P(X)
```

我们必须找到使后验概率 `P(θ|X)` 最大化的 `θ` 值；这被称为参数 `θ` 的最大后验概率（MAP）估计。

```
θ̂_MAP = argmax_θ P(θ|X)
```

分母 `P(X)` 被忽略，因为它与我们希望最大化右侧所针对的参数 `θ` 没有直接的函数依赖关系。与 MLE 一样，我们可以对后验概率取对数，得到：

```
log P(θ|X) = log P(X|θ) + log P(θ) + const
```

因此，MLE 和 MAP 的唯一区别在于，后者允许我们将关于参数的先验信念注入到估计计算中。现在，如果我们在 MAP 估计中使用最简单的先验，即均匀先验，我们会在所有可能的 `θ` 值上分配相等的权重，即 `P(θ) = const`。在这种情况下，MAP 估计为 `θ̂_MAP = θ̂_MLE`，这与 MLE 相同。

## 估计量的偏差-方差分解

我们已将估计量的偏差定义为 `Bias(θ̂) = E(θ̂) - θ`。将统计量 T 视为随机变量，我们可以计算 T 在估计参数 `θ` 时的均方误差 (MSE) 为：`MSE = E[(θ̂ - θ)²]`，其中 `θ̂_i` 表示第 i 个样本的统计量值。

我们可以很容易地证明 `MSE = Var(θ̂) + Bias(θ̂)²`。证明如下：

```
MSE = E[(θ̂ - θ)²]
    = E[(θ̂ - E(θ̂) + E(θ̂) - θ)²]
    = E[(θ̂ - E(θ̂))²] + (E(θ̂) - θ)²
    = Var(θ̂) + Bias(θ̂)²
```

因此，`MSE = Var(θ̂) + Bias(θ̂)²`。这被称为偏差-方差分解，即偏差和方差都对 MSE 有贡献。

## 应用——将机器学习问题表述为统计推断

在本节中，我们将讨论如何用概率论的术语表述不同的机器学习问题。然后，我们将看到，学习模型无非是使用我们迄今为止学到的技术来估计概率分布的参数。

## 数据分布

假设我们得到一个包含 N 条记录的数据集。每条记录有 m 个属性或特征，即每个数据样本是一个向量 `X_i`。我们可以将任何数据点视为一个随机向量。每个特征 `X_j` 可以视为一个随机变量，从数据集的第 i 个属性列取值 `x_{ij}`。这些属性中有很多可能不相互独立。因此，我们可以将数据集表示为从随机向量 `X = (X_1, ..., X_m)` 的多元联合概率分布 `P(X)` 中抽取的样本。
