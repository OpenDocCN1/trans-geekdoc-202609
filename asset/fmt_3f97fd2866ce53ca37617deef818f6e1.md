
# Security+ 认证：系统加固

Security+ 认证考核您对系统加固概念和程序的掌握。请记住，系统加固是指移除不必要的软件并禁用系统上不必要的服务。这些服务可能容易受到缓冲区溢出攻击，因此运行的服务越少越好！

在加固系统时，请花时间调查正在运行的服务，并确定每个服务的作用。发现某服务的用途后，您需要决定是否需要运行该服务。请确保拥有一个测试系统，以便确定禁用该服务的结果，并确保其不会对系统产生负面影响。

请注意，禁用服务通常会关闭与该服务关联的端口。端口是由正在运行的程序或服务在系统上打开的。要关闭端口，只需禁用打开该端口的服务或结束该应用程序即可。您也可以使用防火墙阻止对该端口的访问。

## 保护管理接口和应用程序

在保护系统时，请确保限制对管理软件（接口）的访问。原则在于：如果管理工具对某些员工不可用，他们将无法更改系统或应用程序的配置。

您可以通过多种方式限制对系统和应用程序管理接口的访问，其中最好的方法之一是使用系统提供的策略。此外，从 Windows Vista 开始，如果登录用户没有执行特定命令的权限，Microsoft 现在会限制对这些命令的访问。此功能称为用户账户控制 (UAC)。

不要依赖某人没有某个程序——恶意用户会想办法获取该程序以进行更改。限制用户权限和权限也很重要。

## 禁用不必要的账户

系统加固中一个常被忽视的方面是禁用未被使用的账户。您可能不想立即删除该账户，因为可能会发现公司里有人需要该账户，或者系统上运行的某个软件可能需要该账户。请注意，`Administrator` 账户在 Windows 10 中默认是禁用的。

要在 Windows 中禁用账户，请执行以下步骤：

1. 在 Windows 10 或 Windows Server 中，单击“开始”按钮，然后输入 `control panel`。从搜索结果中选择“控制面板”条目。
2. 依次选择“系统和安全” \| “管理工具” \| “计算机管理”
3. 在“计算机管理”控制台中，展开左侧的“本地用户和组”
4. 选择“用户”文件夹以查看系统上的用户帐户列表（请参阅图 6-4）

不仅应禁用不必要的帐户，还应密切关注拥有系统管理访问权限的帐户数量。在某些环境中，建议最多只有两个帐户拥有管理特权。

### 补丁管理

加固系统的关键后续步骤之一是确保为系统打补丁。当你为系统打补丁时，你会将软件修复程序应用于系统上运行的软件中的已知漏洞。软件中的这些漏洞是黑客利用以获取系统访问权限的途径。如果你不定期为系统打补丁，可以肯定的是，你的系统可能会被经验丰富的黑客攻破。

Security+ 考试需要熟悉的补丁类型包括以下内容：

- **安全热修复程序** 安全热修复程序，也称为关键更新，是一种安全更新，应尽快应用到系统中，因为该漏洞会使系统面临严重的安全风险。
- **补丁** 补丁，也称为更新，是针对软件或操作系统代码中特定问题的修复，不需要立即应用，因为其安全风险不如热修复程序所解决的风险严重。
- **服务包** 服务包提供产品的所有更新，包括从产品发布之时起直到服务包发布之时的补丁和安全热修复程序。如果你安装了服务包，就不需要单独安装每个补丁，因为服务包包含了截至该时间点的所有更新。你仍需安装服务包发布后出现的补丁和安全修复程序。

要为系统打补丁，可以从“开始”菜单中运行 `Windows Update` 程序，或使用集中式补丁管理软件（如 `Windows Server Update Services (WSUS)`）一次性将补丁部署到多个系统。作为安全专业人员，重要的是要评估补丁是如何部署到系统的，并确保该策略能让系统通过安全修复程序保持最新状态。

作为补丁部署策略的一部分，请确保网络管理员在未先测试补丁的情况下不将其应用到系统。管理员应拥有一组测试系统，优先向其部署补丁，以确保补丁不会导致业务应用程序停止工作。一旦补丁在测试系统上通过验证，应将其部署到一小部分生产系统。在验证补丁未给这小部分生产系统带来问题后，即可将补丁部署到更大范围的系统。

![Image](img/exam.jpg)

> **及时为系统打补丁对系统安全至关重要。保持系统已打补丁状态将有助于消除软件中通常允许黑客入侵系统的漏洞。**

打补丁时的另一个考量因素是，应用系统上已安装的其他第三方软件的任何更新。当你应用操作系统更新时，其他第三方公司的软件不会被修补，因此研究如何为系统上运行的第三方软件应用更新非常重要。

你还应考虑在操作系统和系统上运行的应用程序中启用自动更新功能。如果启用自动更新，可以降低日后忘记应用更新的风险——它们将自动应用。

### 密码保护

你应纳入系统加固程序的最后一项做法是为资产设置密码保护功能。从系统角度来看，这意味着你要确保对 `CMOS` 设置程序进行了密码保护，以防止未经授权的 `CMOS` 更改。此外，确保操作系统加载时提示输入密码。如今大多数系统都会要求输入用户名和密码（这比仅要求密码更好），但关键是要确保没有系统在启动时自动登录。

考虑对其他资源（如路由器、交换机甚至打印机）进行密码保护。大多数人不会考虑为笔记本电脑或手机等移动设备使用密码——但这些设备包含敏感的公司信息，因此在系统启动时也应对其进行密码保护。

不仅系统启动时应要求输入密码，还应确保在这些设备上遵循良好的密码实践。所有密码长度应至少为八个字符，并应混合使用大小写字母、数字和符号。此外，要确保用户没有将密码记录下来，因为别人很容易找到记录密码的纸条。

### 注册表加固

在系统加固方面，你也可以对注册表进行加固。注册表是 Windows 系统所有设置的数据库。通常，你通过“控制面板”配置系统，但也可以在 Windows 中使用 `regedit.exe` 通过注册表进行更改。如果在注册表中进行了错误的更改，可能会导致系统无法正常运行，因此只有熟悉注册表时才应进入其中。

就注册表加固而言，最重要的一点是确保只有管理员拥有对注册表关键区域进行更改的权限。例如，恶意软件可能会将自身添加到注册表的“运行”部分，该部分存放自动启动的程序。你可以修改注册表“运行”区域的权限，以确保只有管理员可以修改该部分。

在讨论注册表时，我还应提到，更改注册表可用于锁定系统，因为注册表中有许多设置在“控制面板”中找不到。以下是关于使用注册表的一些要点：

- `Regedit.exe` 是我们用来修改注册表的工具。
- 你可以右键单击注册表的某个区域，然后选择“权限”命令来修改该区域的权限。
- 你可以使用 `regedit.exe /E` 命令将注册表中的设置导出到 `.reg` 文件。
- 你可以使用 `regedit.exe <filename.reg>` 命令导入注册表设置文件。这是一种确保注册表自定义设置轻松部署到多个系统的绝佳方法。

### 磁盘加密

在加固系统时，你还应考虑加固系统上的驱动器。你可以通过设置硬盘上文件和文件夹的权限来实现这一点，但据发现，如果攻击者能够启动到备用操作系统并访问驱动器，他们可以绕过这些权限。因此，你应该考虑加密硬盘。如果加密驱动器的内容，未经授权的人员无法访问文件，除非他们拥有解密密钥——即使他们启动到了备用操作系统。

你应该了解不同的驱动器加密技术：

#### 加密文件系统 (EFS)

加密文件系统 (EFS) 是 Windows 中的一项安全功能，可应用于位于 NTFS 格式驱动器上的文件。你可以转到文件的属性，然后在“常规”选项卡上，单击“高级”按钮。随后你可以将属性设置为加密该文件。默认情况下，只有加密文件的人才能解密该文件。请注意，这是一种加密单个文件而非整个硬盘驱动器的方式。

#### BitLocker

BitLocker 是 Windows 中的一项驱动器加密功能，允许你加密整个驱动器。建议在笔记本电脑等移动设备上使用，这样如果笔记本电脑丢失或被盗，你可以确信硬盘驱动器已加密。

#### BitLocker To Go

BitLocker To Go 是一项允许你加密 USB 驱动器的功能。由于这些是便携式驱动器，容易丢失或被盗，因此你应该使用 BitLocker To Go 对其进行加密。

## 系统加固程序

现在你已经对系统加固有了一个大致的了解，让我们来看看安全管理员用来加固网络和系统的一些常用工具。在本节中，你将了解网络加固以及所使用的一些软件工具。

### 网络安全加固

网络加固的第一个方面是更新所有网络设备上的固件。网络设备虽然是硬件，但就它们由软件运行这一点而言，类似于计算机。运行网络设备的软件称为 `firmware`，存储在称为 EEPROM 的闪存中，EEPROM 代表 `electrically erasable programmable read-only memory`（电可擦除可编程只读存储器）。通常你可以访问设备制造商的网站，下载该设备修订后的更新版固件。该版本的固件将包含创建时所有 bug 的修复程序。

更新固件后，请务必为设备配置了密码，以便只有授权人员才能对其进行管理。如今大多数设备（如路由器和交换机）都支持 Web 管理界面，你应该对其进行密码保护，并在支持的情况下将其配置为使用 HTTPS。

在考虑加固网络时，请确保使用尽可能安全的设备。例如，使用交换机代替集线器，因为交换机具有过滤功能，可确保交换机仅将流量发送到目标系统所在的端口。这意味着很难有人在网络上放置嗅探器并捕获流量，因为流量永远不会到达执行数据包嗅探的设备。在集线器曾是流行网络设备的时候，数据包会被发送到集线器上的所有端口，任何安装了嗅探器的系统都能查看所有网络流量。

#### MAC 限制和过滤

MAC 过滤是一种流行的访问控制方法，在网络交换机和无线接入点等许多不同设备中均有实现。通过无线接入点，你可以实施 MAC 过滤来控制哪些 MAC 地址可以连接到无线网络。请注意，这也称为 `MAC limiting`，因为你是通过 MAC 地址限制哪些设备可以访问无线网络。

交换机上的 MAC 过滤含义略有不同，它允许你限制哪些系统可以向网络上的其他系统发送数据。交换机上的过滤通常与端口安全功能一起配置，允许你限制交换机上的哪些端口可以作为发往特定系统的数据的“源端口”。

#### 802.1X

加固网络的一种流行方法是确保任何连接到网络的人员，在允许网络连接之前都提供有效的凭据。这不同于正常的操作系统登录，因为当你登录系统时，系统通常已经具有网络访问权限。802.1X 标准是一种用于控制网络访问（有线和无线）的 IEEE 标准，通常称为基于端口的访问控制保护。使用 802.1X 时，在你向 802.1X 环境进行身份验证之前，不会被授予网络访问权限。

802.1X 的工作方式是：你有一个客户端，如台式机系统、笔记本电脑或网络设备，希望连接到网络交换机或无线接入点。网络交换机或无线设备称为 `authenticator`（认证器），需要在授予网络访问权限之前对连接设备进行身份验证。交换机或无线接入点向运行 RADIUS 或 DIAMETER 等协议的中央认证服务器发送认证请求（请参见 图 6-5）。这些是不同类型网络环境中常见的认证服务器。

#### 安全管理协议

### 网络设备加固与系统加固工具

作为路由器和交换机等网络设备加固的一部分，您应确保设备上仅运行安全管理协议。例如，您应禁用 Telnet 作为远程管理协议，因为它不会加密管理系统与设备之间的通信。这包括认证流量未加密，这意味着攻击者可以捕获 Telnet 流量并查看您的 Telnet 用户名和密码。作为一种加固技术，您应确保禁用 Telnet 但启用 SSH 作为远程管理协议。SSH 会加密 SSH 客户端（管理员的管理系统）与网络设备之间的所有通信——包括认证流量。

### 非法设备检测

监控网络环境的部分工作是监控网络中的非法机器和设备。非法机器是指连接到网络但不属于该网络的机器。个人将系统或设备连接到网络的原因有多种：

- **非法系统** 有人可能将运行数据包嗅探器的系统连接到网络，意图捕获网络上传输的机密信息，如密码。
- **非法设备** 非法设备的一个示例是连接到网络的无线路由器。员工可能将无线路由器连接到网络，以便他们可以携带移动设备或笔记本电脑在办公室内移动，并使用公司网络进行互联网访问。

尽管加固网络基础设施和使用网络交换机上的端口安全等功能应能降低非法系统或设备连接到您网络的几率，但重要的是要确保您监控并跟踪哪些系统和设备连接到了网络。一旦识别出连接到网络的未授权设备，您应立即在交换机上禁用该端口，然后调查该非法系统或设备。
