
对于 CASP 考试，你需要对 ACL 及其格式有基本的理解。Cisco 环境中标准 ACL 的命令格式如下：

```
access-list access-list-number {permit|deny} {host|source-wildcard|any}
```

还有扩展型 ACL。这些规则能够更细致地查看流量并检查更多项目，例如：

- 协议
- 端口号
- 区分服务代码点 (DSCP) 值
- 优先级值
- 同步序列号位 (SYN) 位的状态

扩展型 IP、ICMP、TCP 和 UDP ACL 的命令格式如下：

```
access-list access-list-number {permit|deny} [protocol] {host|source-wildcard|any} [port] {host|destination-wildcard|any} [destination-port]
```

## 主机级防火墙

现在我们回顾了防火墙，让我们把注意力转向主机级防火墙。防火墙通常设置在信任与不可信网络元素之间的分界线上，但也可以放置在主机系统上。主机级防火墙是直接运行在网络主机或设备上的设备。部署主机级防火墙的目的是保护安装在设备上的设备免受攻击。主机级防火墙通常具有预定义的规则，用于保护主机免受特定的攻击模式。主机级防火墙可以与隔离和修复结合使用。某些主机级防火墙还可以防止恶意软件攻击网络上的其他设备。添加主机级防火墙是基于深度防御的概念。该概念的示例见[图 4.3](Figure 4.3)。

![](img/7868547987f5920cfe632b85047c64af_254_0.png)

**图 4.3** 深度防御与多层保护

主机级防火墙通过检查和控制入站和出站流量来工作。虽然有多种防火墙，但只有主机级防火墙设计为驻留在终端主机上并保护其免受攻击。与所有防火墙一样，主机级防火墙通过检查通过接口的流量来工作。它的工作方式与边防人员和海关人员的工作非常相似。当人和货物跨越一个国家的边界进入另一个国家时，它们会接受检查。所有防火墙都通过使用规则来工作。

主机级防火墙的一个真实优势是，它可以通过添加另一层控制来增加深度防御。如果网络防火墙失效，主机级防火墙将作为额外的防御层。主机级防火墙的缺点是，如果主机故障，防火墙可能会被攻破。另一个缺点是在多主机主机级防火墙系统中更新策略会很困难。主机级防火墙产品示例包括 Windows Firewall、IPTables、Norton Personal Firewall、Zone Labs ZoneAlarm、Sunbelt Personal Firewall 和 Sygate Personal Firewall。

![](img/7868547987f5920cfe632b85047c64af_255_0.png)

一种可以修改主机防火墙设置的恶意软件示例是 Conficker，它能够禁用若干个与外部世界通信所需的高级 TCP 和 UDP 端口。这些修改是通过主机无法察觉的注册表更改完成的。一旦更改完成，主机防火墙就会被攻破。当然，还有更高级的规避方法，例如创建自定义 TCP 栈。

即使有边缘保护（放置在网络边缘的设备）和主机级防火墙，攻击有时仍然能够渗透。这就是为什么公司正在增加能够检查 Web 数据的应用协议感知防火墙。下一代防火墙（Nextgen firewalls）可以帮助对可疑网络流量进行隔离/修复。下一代防火墙通常位于军事区/外部/内部网络之间的边缘，有助于关键资产的隔离。

Web 防火墙（WAF）是一种解决 Web 应用程序安全问题的下一代技术。WAF 并不是传统防火墙的替代品，而是增加了另一层保护。传统防火墙阻止或允许流量，而 WAF 可以防止跨站脚本、隐藏字段篡改、Cookie 污染甚至 SQL 注入。WAF 通过检查 TCP/IP OSI 层的高层来运行，并与特定的 Web 应用结合得更密切。可以这样想：传统的防火墙可能会在边界拒绝入站流量。但跨 80 或 443 端口的流量呢？对于公司或组织来说，保持跨互联网通信可能不是一个可行方案。这就是 WAF 发挥作用的地方。WAF 在保护这些组织免受社交网络和其他 Web 2.0 应用中固有的新兴威胁方面可能是巨大的，而传统防火墙的设计无法防御这些威胁。WAF 的开源示例是 ModSecurity。商业选项通过 Barracuda Networks、Fortinet 和 Cisco Systems 提供。顺便提一下，用于 Suricata IDS 项目的解析器（HTP Library）是由 ModSecurity 的 Ivan Ricardo 编写的；这些可能是不远的未来值得关注的两个项目。

无论以何种方式进行测试，也无论使用哪一组特定标准，信任操作系统（TOS）的基本属性包括：

**硬件保护** TOS 必须从底层开始进行设计。安全的硬件是安全的起点。

**长期受保护存储** TOS 必须能够提供跨越电源周期和其他事件的受保护存储能力。

**隔离** TOS 必须能够隔离程序。TOS 必须防止程序 A 访问程序 B 的信息。

**用户进程与监视进程分离** 用户功能和监视功能必须分离。

信任操作系统不仅限于软件，还必须考虑它们所运行的硬件。这就是信任计算基础（TCB）的目的。信任计算基础（TCB）是计算机内部所有保护机制的总和，负责执行安全策略。这包括硬件、控制措施和进程。TCB 负责机密性和完整性。它是系统中唯一运行在高信任级别上的部分。这种信任级别就是安全内核所在的地方。安全内核处理所有用户和应用程序的访问系统资源的请求。较小的安全内核易于验证、测试和确认其安全性。

因此，虽然 TOS 是构建在 TCB 之上的，但这两个概念都是基于理论的。这些模型的大部分工作始于 20 世纪 70 年代初。在此期间，美国政府资助了一系列关于计算机安全的论文。这些论文构成了信任计算的基础基石。它们是安全模型、安全系统，以及安全将如何实现、哪些主体可以拥有权限。简单来说，它们是形式化 TOS 设计的一种方法。安全模型建立在旨在执行完整性和机密性的控制措施之上。我在这里列出了一些较著名的安全模型。此列表并非详尽无遗，而是突出了由早期研究人员开发的一些较著名的模型。

## Bell–LaPadula

Bell–LaPadula 模型使用强制性访问控制来执行美国国防部（DoD）的多级安全策略。要访问信息，主体必须通过并满足信息的分类级别。Bell–LaPadula 模型由以下属性定义：

- 简单安全性（Simple Security）：该属性规定，处于某一机密性级别的主体不允许读取处于更高机密性级别的信息。这有时被称为“不向上读”。
- 星型安全性（Star Security）：该属性规定，处于某一机密性级别的主体不允许向处于较低的机密性级别写入信息。这也被称为“不向下写”。
- 强星型安全性（Strong Star Security）：该属性规定，主体不能向上读或向下写。

## Biba

早期的 Biba 模型是为了解决完整性问题而设计的。Biba 仅针对未经授权的用户提供保护。不检查可用性和机密性。它还假设内部威胁受到了良好编码实践的保护，因此重点关注外部威胁。Biba 模型具有以下定义属性：

- 简单完整性（Simple Integrity）：该属性规定，处于某一完整性级别的主体不允许读取处于较低完整性的对象。
- 星型完整性（Star Integrity）：该属性规定，处于某一完整性级别的对象不允许写入处于更高完整性级别的对象。
- 调用（Invocation）：该属性禁止处于某一完整性级别的主体调用处于更高完整性级别的主体。

## Clark–Wilson

Clark–Wilson 模型创建于 1987 年。它与 Bell-LaPadula 和 Biba 的不同之处在于它的开发初衷是用于商业活动。它与 Biba 模型的不同之处在于主体受到限制。处于某一访问级别的主体可以读取一组数据，而处于另一访问级别的主体则可以访问另一组数据。Clark–Wilson 是基于能力的安全示例。

Clark–Wilson 模型控制系统的内部一致性，其开发是为了确保数据只能以保护一致性的方式进行被操纵。Clark–Wilson 规定必须执行职责分离，主体必须通过应用程序访问数据，并且需要审计。数据在更改时不能被篡改，且数据的完整性必须保持一致。

## Brewer and Nash

最后是 Brewer and Nash 模型。它与 Bell–LaPadula 模型有些相似。它有一个绰号“中国墙”模型。它的设计被推广为防止利益冲突问题的手段。在中国墙一侧工作的人员无法看到墙另一侧的数据。例如，中国墙模型将防止为一家政府承包商提供咨询的雇员访问属于另一家政府承包商的数据，从而防止任何利益冲突。

![](img/7868547987f5920cfe632b85047c64af_261_0.png)

当实施良好时，安全模型可以帮助防止许多类型的攻击。其中一个例子是“混淆代理”（confused deputy）问题。混淆代理的概念基于前提：计算机程序可能会被攻击者欺骗而误用其权限。考虑跨站请求伪造（CSRF）攻击。CSRF 是一种针对网站的攻击。在 CSRF 中，客户端无法区分对任何网站的权限。这类攻击经常在讨论为什么需要能力安全时提到。

## 端点安全解决方案

构建安全是一个良好的开始，但还需要更多工作。一个领域是端点安全。端点安全由放置在客户端系统上的控制措施组成，例如 USB、反病毒软件、反恶意软件等。客户端上的控制措施是非常重要的。

作为 CASP，你能够检查从端点到网络的安全，并考虑构建安全区域以限制攻击者的范围。这从流量进入网络到用户最初连接网络及其资源。这需要深度防御和可用性控制。可以使用几种方法构建安全区域，包括：

**面向向量（Vector-Oriented）** 该方法关注用于发起攻击的常见向量。包括禁用优盘自动运行、禁用 USB 端口。

**以信息为中心（Information-centric）** 该方法关注在数据之上叠加控制。示例包括信息控制、应用控制、主机控制和网络控制。

**受保护区域（Protected Enclaves）** 该方法规定某些区域比其他区域更安全。控制措施可能包括 VPN、防火墙的策略部署以及 VLAN 的部署。

在考虑端点安全时，谁是更大的威胁，内部人员还是外部人员？尽管数字取决于参考报告，大量的攻击是由内部人员发起的。信任内部人员如果决定采取恶意行动，可能会绕过控制措施来访问、查看、更改、破坏或删除其雇不允许的数据。但不要忘记外部人员——他们可能通过偶尔的外部入侵（如恶意软件）获得访问内部网络的权限。目前，有报告显示传统攻击的成功率很高。这包括简单的攻击。一旦攻击者利用高级权限提升和针对特定配置的漏洞，攻击的复杂性就会大幅增加，以提供未来的访问、提取数据并规避安全机制。这是 CASP 不能仅依赖边界安全的另一个原因。

一个起点是实施最小权限原则。该原则是指用户应仅拥有其所需的访问——即只允许根据用户工作所需的最小权限。该概念也可以应用于计算机上的进程；每个系统组件或进程都应具有执行其职责所需的最小权限。

通过消除可能导致漏洞和计算机受攻击的不必要权限来保护主机的安全性。目标是在给定的场景下，认证安全防护专业人员（CASP）应该能够选择并排查主机的安全控制措施。一个很好的起点是加固操作系统。防御信息系统局（DISA）和国家安全局（NSA）等机构提供了多种加固指南。MITRE 提供了一个很好的针对特定操作系统的参考：http://nvd.nist.gov/cce/index.cfm。其他终端和主机安全解决方案还包括：

## 补丁管理

补丁管理是保持应用程序和操作系统安全的关键。组织应该建立完善的补丁管理测试和部署系统。补丁在分发之前应在沙箱中运行以确保安全。

## 数据外泄

遗憾的是，盗窃和丢失将会发生。CASP 应该验证组织是否有处理此类情况的政策和程序。数据外泄是一个巨大的问题，公司需要政策和程序来处理。

## 主机防火墙

深度防御规定公司不仅要考虑企业防火墙，还要考虑主机防火墙。

## 日志监控

日志监控是一种主要的检测控制措施。它可以用于识别问题，并为持续的问题和安全疑虑找到可行的解决方案。

## 变更监控

必须控制变更并按顺序进行。变更控制程序应该列明如何批准和实施变更，以及如何通知最终用户。

## 配置锁定

并非所有人都应该拥有更改设备或硬件的权限。可以使用配置控制来防止未经授权的更改。

## 可用性控制

可用性控制涉及公司在需要时获取数据的能力。一些常见的解决方案包括 RAID、冗余服务器和云存储。

## 终端安全的常见威胁

加固是一个很好的起点，但 CASP 也应该理解常见威胁。通过对下文列出的威胁的理解，你可以开始为主机系统选择合适的安全控制措施。内部和外部人员造成的大部分损害是由针对服务器和终端用户的恶意软件造成的。

以下是其中几种类型的威胁：

## 病毒

病毒是一种设计用于感染计算机系统的软件。某些病毒会破坏系统，而另一些可能会显示消息或仅留在计算机中。病毒通常通过三种方式访问系统：电子邮件、网络或 CD/DVD/USB 介质。

## 蠕虫

蠕虫与病毒不同，它们不需要用户参与即可复制和传播。RTM 蠕虫被认为是第一个蠕虫，由 Robert Morris 在 1988 年创建。

## 间谍软件

间谍软件与病毒和蠕虫密切相关。在许多方面，间谍软件类似于木马；大多数用户不知道已经安装了间谍软件，因为代码隐藏在隐蔽的位置。间谍软件可能会记录键记录、将用户重定向到未请求的恶意网站、用弹出窗口骚扰用户或监控用户活动。DNS 重定向和交替数据流（ADS）的使用允许间谍软件分发者将一个流隐藏在另一个后面。对驱动器进行快速搜索将找不到违规执行文件的痕迹，因为它在存储所有文件目录列表的主文件表（MFT）中没有条目。几年来，间谍软件演变成了提示用户付费的防病毒软件——恐吓软件（scareware）。

## 木马

木马是伪装成有用程序但包含恶意负载的程序。许多时候，木马被用于远程访问和控制主机计算机。这些程序被称为远程访问木马（RATs）。许多木马让攻击者获得受害者计算机的完全控制权，允许攻击者执行程序、访问注册表、开启摄像头和麦克风、控制浏览器以及启动和停止应用程序。旧示例包括 NetBus、Back Orifice 和 Ghost Rat。

## 垃圾邮件

垃圾邮件是未经请求的电子邮件。它被无差别地发送给许多邮件列表、个人或新闻组。其目的是诱发响应，欺骗用户访问恶意网站或购买假货或仿制品。针对移动设备的短信（短信息服务）垃圾邮件也是日益严重的问题。

## 增量攻击

增量攻击的目标是随着时间缓慢地做出更改。通过在很长时间内做出如此微小的更改，攻击者希望保持不被察觉。这里是两种主要的增量攻击：

- 数据涂改（Data doodling），通常与数据库攻击相关，如果攻击者能够访问系统并能对数据或文件进行增量更改，则可能是可能的。
- 香肠攻击（Salami attack），与数据涂改类似，涉及对账户进行微小更改。

## 键盘记录器

键盘记录器可以是硬件或软件。它们附着在计算机上并记录击键。

![](img/7868547987f5920cfe63b85047c4af_266_0.png)

CASP 候选人应该了解恶意软件及其代表的威胁，以及常见的攻击向量和防御这些威胁的技巧。

# 反恶意软件

反恶意解决方案并不是新鲜事。从计算机早期开始，就产生了反恶意解决方案的需求。最早的之一是杀毒工具。弗雷德·科恩通常被认为创造了“计算机病毒”一词。最早的反恶意程序与如今的工具大不相同。

> 恶意软件能教我们关于配置管理的什么？配置管理就是建立已知环境并进行维护。所有类型的恶意软件都会对未经授权的对硬件、软件和固件的更改进行记录、测试和批准。配置管理应贯穿系统的生命周期。
