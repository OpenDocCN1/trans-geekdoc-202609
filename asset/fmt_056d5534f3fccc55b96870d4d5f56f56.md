### 6.2.1.1 数据量化

要在所提的 3D 多层 CMOS-ReRAM 加速器上实现完整的训练算法，需要对实数精度进行仔细评估。与软件双精度浮点格式（64 位）相比，训练算法中的数值被截断为有限精度。通过软件交叉验证，可以在硬件资源和测试精度之间达到一个平衡点。带有 `I` 位整数位和 `F` 位小数位的通用 `N` 位定点表示如下所示：

```
Value = (-1)^S * (I_bits + F_bits)
```

在所述加速器中，首先需要为归一化输入数据（如 `x` 和 `y`）分配固定的 16 位位宽，并带有比例因子 `S_x` 和 `S_y`。对于 SLFN 中的权重（如 `A` 和 `B`），可以通过求动态范围的对数（即 `log2(max|W|)`）来确定 `I`，而 `F` 设为 `N - I`。此外，需要基于测试精度应用贪婪搜索法来寻找最优位宽。通过应用交叉验证来评估效果，逐步减小位宽。通过动态调整位宽，我们的目标是找到在可接受的测试精度损失下的最小位宽。

### 6.2.1.2 用于数字化矩阵-向量乘法的 ReRAM 层实现

矩阵-向量乘法以输出层（4.7）计算为例进行说明，其中 `H` 中的每个元素使用 `H = X * W` 计算。这种乘法可以用二进制乘法 [147] 来表示。

```
H_acc = Σ (X_bin[i] XOR W_bin[j]) * 2^(i+j)
```

其中 `H_acc` 是来自 ReRAM 交叉阵列的加速结果。`X_bin` 是 `X` 的二进制位，位宽为 `N_x`；`W_bin` 是 `W` 的二进制位，位宽为 `N_w`。如上所述，位宽 `N_x` 和 `N_w` 在设计中通过交叉验证决定，以实现精度和硬件使用的平衡 [236]。

**步骤 1：并行数字化**：需要一个 `N_x * N_w` ReRAM 交叉阵列。每个内积由 ReRAM 交叉阵列产生，如图 6.19(a) 所示。`X` 设为交叉阵列输入，`W` 写入 ReRAM 单元。在 `N_x * N_w` ReRAM 交叉阵列中，每列 ReRAM 的电阻相同，但列间电阻 `R_col` 不同。因此，每列的输出主要取决于梯级阈值电压 `V_th`。若内积结果为 `P`，则步骤 1 的输出类似 `O = [0, ..., 0, 1, 1, ..., 1]`，其中 `k` 和 `m`。

![Figure 6.19 数字化矩阵-向量乘法在 ReRAM 交叉阵列上的详细映射：(a) 并行数字化；(b) XOR；(c) 编码；(d) 映射图例](img/PBPC0390-06-f19.jpg)

**步骤 2：XOR**：通过运算 `X_bin XOR W_bin` 来识别 `k` 的索引。注意，仅当来自步骤 1 的 `X_bin` 和 `W_bin` 时，`XOR_out` 才为 `1`。ReRAM 交叉阵列输入和电阻的映射如图 6.19(b) 所示，阈值电压配置为 `V_th_xor`。因此，通过 XOR 运算识别 `k` 的索引。

**步骤 3：编码**：第三步作为一个编码器产生二进制格式的 `H_bin`，阈值同步骤 2。来自第二步的输入产生类似 `O_xor` 的结果，其中仅第 `k` 个输入为 `1`。结果，仅读出第 `k` 行，此步骤中不发生电流合并。相应的二进制格式 `H_bin` 作为中间结果存储在第 `k` 行，如图 6.19(c) 所示。编码步骤需要一个 `N_h * N_h` ReRAM 交叉阵列，其中 `N_h` 是表示 `0` 到 `2^N_h - 1` 所需的二进制位数。

### 6.2.2 TNNs 的片上设计

TNNs 是当前另一类重要的机器学习架构。在本节中，我们将根据第 4.4 节中的算法和网络，映射基于两层 TNN 的推理过程。本节还讨论了如何利用所提的 3D 多层 CMOS-ReRAM 架构来设计 TNN 加速器。

#### 6.2.2.1 在多层架构上的映射

让我们首先讨论 CMOS 层设计，它执行 TNN 计算的高层控制。然后介绍一种基于 TNN 架构和点积引擎的高并行 ReRAM 加速器。

##### CMOS 层加速器

###### TNN 在 3D 多层 CMOS-ReRAM 加速器上的映射

为了在 3D 多层 CMOS-ReRAM 加速器上完整映射 TNN，CMOS 逻辑主要需要设计用于逻辑控制和同步，采用顶层状态机。它为计算核准备输入数据，监控 ReRAM 逻辑计算的状态，并确定神经网络的计算层。图 6.22 展示了 TNN 在所提议的 3D 多层 CMOS-ReRAM 加速器上的详细映射。这是一种折叠架构，利用神经网络中每一层的顺序操作。测试数据将通过硅通孔 (TSV) 从 ReRAM 存储器中收集，然后送入向量核，通过 ReRAM 层中高度并行的处理单元执行向量-矩阵乘法。ReRAM 层拥有许多分布式的 ReRAM 交叉阵列结构以并行执行乘法。随后，来自 ReRAM 的计算输出将被传输到标量核以执行累加。标量核可执行加法、减法和比较。然后，来自标量核的输出将以流水线方式发送到 Sigmoid 函数模型，用于激活矩阵的计算，该模型执行公式 (4.4) 的计算。激活矩阵将用于下一层的计算。因此，整个 TNN 推理过程可以映射到 3D 多层 CMOS-ReRAM 加速器上。

![图 6.22 CMOS 层上的数据控制与同步，包含高度并行的基于 ReRAM 的处理单元](img/PBPC0390-06-f22.jpg)

此外，为了支持 ReRAM 上的 TNN 计算，需要一个专用的索引查找表 (LUT)。由于权重矩阵实际上如图 4.8 所示被折叠成一个高维张量，因此设计了一个称为双射函数的正确索引选择函数。权重矩阵索引的双射函数也由 CMOS 层执行。基于顶层状态图，它将通过确定索引来选择张量核的正确切片。然后，相应的 ReRAM 交叉阵列区域将被激活以执行向量-矩阵乘法。

##### ReRAM 层加速器

在 ReRAM 层中，本节介绍 ReRAM 层加速器的设计，该设计利用单指令多数据流 (SIMD) 方法支持数据并行性，以实现高度并行的计算。

###### ReRAM 层上高度并行的 TNN 加速器

TNN 加速器的设计必须支持高度并行的张量火车矩阵-向量乘法，通过利用矩阵乘法的结合律。根据公式 (4.28)，核心张量需要与多个矩阵相乘，这与通用神经网络不同。因此，如果采用传统的串行矩阵-向量乘法，数据需要多次存储在 ReRAM 阵列中，这非常耗时。由于 TNN 中张量核的尺寸远小于通用神经网络中的权重，因此可以在 ReRAM 逻辑层中放置多个矩阵-向量乘法引擎。当输入数据加载时，核心张量的索引即可得知。例如，根据公式 (4.28) 中的求和，需要给定输入计算中间结果。公式 (4.28) 中的核心张量可以在输入数据加载前以并行方式预计算。

如图 6.23 所示，张量核 (TC1-6) 存储在 ReRAM 逻辑层中。当输入数据到达时，逻辑层控制器首先加载每个张量核的索引。控制器将张量核中相应的数据写入 ReRAM 单元。因此，核心张量的矩阵-向量乘法可以并行执行以计算中间矩阵，同时最后一个核心正在加载过程中。获得所有中间矩阵后，它们可以与最终核心相乘，从而使 ReRAM 逻辑层中的操作变得高效。

![图 6.23 (a) 基于 ReRAM 的 TNN 加速器；(b) 基于树的并行部分结果乘法；(c) 基于 ReRAM 的点积引擎](img/PBPC0390-06-f23.jpg)

###### ReRAM 层上高度并行的点积引擎

我们进一步在 ReRAM 层上开发了数字化的基于 ReRAM 的点积引擎。张量火车矩阵-向量运算可以通过 ReRAM 层上的快速点积引擎高效加速，如图 6.23(b)所示。通过获取核心的正确索引，每个运算可被分解为向量-向量点积运算。此处，我们基于文献 [237] 设计了点积引擎。为便于理解，输出矩阵为 `C`，输入矩阵为 `A` 和 `B`。总体方程为 `C = A * B`，维度分别为 `M x N`、`M x K` 和 `K x N`。`C` 中的每个元素遵循：

```
C[i][j] = sum(A[i][k] * B[k][j])
```

其中 `A[i][k]` 和 `B[k][j]` 分别是 `A` 和 `B` 中的元素。基本实现思路是将矩阵-向量乘法分解为两个向量 `a` 和 `b` 的多个内积运算。通过采用 `a` 和 `b` 的定点表示，这种乘法可用二进制乘法表示：

```
Result = sum(a_bit[m] * b_bit[n] * 2^(m+n))
```

其中 `R_accel` 是来自 ReRAM 交叉阵列的加速结果。`a_bit[m]` 是位宽为 `M` 的 `a` 的二进制位，`b_bit[n]` 是位宽为 `N` 的 `b` 的二进制位。如前所述，位宽 `M` 和 `N` 在算法层面优化期间决定。基于公式 (22) 的矩阵-向量乘法可在 ReRAM 层上总结为四个步骤。

**步骤 1：索引双射**：选择正确的张量核心切片 `G_core`，其中一对索引 `(i, j)` 确定来自 `G_core` 的一个切片。在当前示例中，索引 `i_sel` 和 `j_sel` 分别代表从核心 `TC1` 和 `TC2` 中选取的两个切片。

**步骤 2：并行数字化**：需要一个 `N x M` 的 ReRAM 交叉阵列。如图 6.23(c)所示，每个内积由 ReRAM 交叉阵列产生。`a_vec` 设置为交叉阵列输入，`b_mat` 写入 ReRAM 单元。在 `N x M` ReRAM 交叉阵列中，每列 ReRAM 的电阻相同，但各列中的第 `k` 个电阻不同。因此，每列的输出主要取决于阶梯状的阈值电压 `V_th`。如果内积结果为 `IP_res`，则步骤 1 的输出类似于 `Out_vec`，其中包含 `Out_vec[i]` 和 `Out_vec[j]`。

**步骤 3：异或（XOR）**

此步骤旨在通过运算 `a_bit XOR b_bit` 识别 `k` 的索引。请注意，仅当 `a_bit` 和 `b_bit` 来自步骤 1 时，`XOR_out` 才成立。ReRAM 交叉阵列输入与电阻的映射也如图 22(c) 所示，阈值电压配置为 `V_th_xor`。因此，通过异或运算识别 `k` 的索引。

**步骤 4：编码**

第三步产生二进制格式的 `H_bin` 作为编码器，其阈值同步骤 2。第二步的输入产生类似 `O_xor` 的结果，其中仅当 `k` 输入为 `1` 时成立。结果是，仅读出第 `k` 行，且此步骤中不发生电流合并。相应的二进制格式 `H_bin` 为中间结果，存储在第 `k` 行中，如图 6.23(c)所示。编码步骤需要一个 `N_h * N_h` ReRAM 交叉阵列，其中 `N_h` 为用二进制格式表示 `0` 到 `2^N_h - 1` 所需的位数。

通过应用这四个步骤，可将不同的张量核映射到 ReRAM 交叉阵列上，以并行执行矩阵-向量乘法。与最先进的实现相比，该方法能更快、更节能地执行矩阵-向量乘法。

#### 6.2.2.2 在单层架构上映射 TNN

此外，本节展示了如何根据第 4.4 节的算法和网络，映射基于两层 TNN 的推理过程。本节进一步讨论了如何利用 3D 单层 CMOS-ReRAM 架构设计 TNN 加速器。与第 2.2 节的映射相比，分布式映射可实现更高的并行度。

##### TNN 加速器设计

根据公式 (4.28)，`G_core` 需要与 `N_core` 矩阵相乘，这与通用神经网络不同。在该公式中，只需从每个张量核中取出 3D 矩阵的一个切片（即 2D 矩阵）来执行矩阵-向量乘法。因此，计算复杂度可显著降低。我们在图 6.24 中展示了 TNN 两个隐藏层之间的详细加速器设计。由于神经网络参数被压缩，遵循图 5.12(b)，可将 TNN 的所有权重存储在 ReRAM 交叉阵列中。输入数据 `x_in` 由多个张量核、CMOS 池化和激活函数串行处理。

![图 6.24 用于 TNN 的高并行 3D 单层 CMOS-ReRAM 加速器映射细节](img/PBPC0390-06-f24.jpg)

张量核的详细设计也如图 6.24 所示。在每个张量核中，必须将 3D 矩阵的不同切片存储在不同的 ReRAM 交叉阵列中。由于一次仅使用一个 2D 矩阵，因此使用两个张量核多路选择器（MUX），以便仅将一个矩阵连接到输入电压和输出 ADC。TC 选择模块根据 `i_sel` 和 `j_sel` 控制输入和输出 MUX。对于中间的张量核，可移除 ADC/DAC 对，因为 ReRAM 交叉阵列输入不需要数字表示。

##### TNN 在 3D CMOS-ReRAM 架构上的优势总结

从算法优化角度来看，这种张量化有利于实现大型神经网络。首先，通过执行张量化，可压缩神经网络的规模。此外，采用小张量秩也可降低计算负载。其次，权重矩阵的张量化可将大矩阵分解为许多小的张量核矩阵，从而有效减少 ReRAM 的配置时间。最后，小矩阵的乘法可在 ReRAM 上以高度并行的方式执行，以加速大型神经网络的处理时间。

从硬件计算架构角度来看，所提出的 3D CMOS-ReRAM 加速器可大幅提高能效和神经网络处理速度。矩阵-向量乘法可由 ReRAM 交叉阵列固有实现。与 CMOS 相比，多位张量核权重可由单个 ReRAM 表示，加法可通过电流合并实现。此外，由于所有用于神经网络权重的张量核均存储在 ReRAM 器件中，可实现更好的面积效率。由于 ReRAM 的非易失性，所提出的 CMOS-ReRAM 功耗远小于 CMOS 实现。在图 6.24 所示的 TNN 加速器设计中，仅 3D 矩阵的一个切片处于激活状态，而大多数矩阵处于非激活状态。对于传统 CMOS 实现，非激活张量核权重会消耗巨大的静态功耗。但在所讨论的架构中，非激活矩阵不消耗功率，从而实现了高能量利用率，带来了更好的能效。

实验中实现了不同的基线以进行性能比较。各基线详情如下：
