
让我们应用梯度下降方案，推导一个迭代算法来最小化我们熟悉的代价函数：

```
J(θ) = 𝔼[(y − θᵀx)²] = σᵧ² − 2θᵀp + θᵀΣₓθ
```

其中 `Σ[x] = E[xx^T]` 为输入协方差矩阵，`p = E[xy]` 为输入-输出互相关向量（第 4 章）。关于 `θ` 的相应代价函数梯度很容易看出为（例如，附录 A）

```
∇J(θ) = 2Σ[x]θ − 2p.
```

![Equation](img/si39.png)(5.5)

在本章中，除非另有说明，我们也将坚持使用零均值联合分布的输入-输出随机变量。因此，协方差矩阵与相关矩阵重合。如果不是这种情况，公式 (5.5) 中的协方差将被相关矩阵替代。讨论重点在于实数数据，我们将在需要时指出与复值数据情况的差异。

采用公式 (5.5)，公式 (5.3) 中的更新递归变为

```
θ^(i) = θ^(i−1) − μ(Σ[x]θ^(i−1) − p) = θ^(i−1) + μ(p − Σ[x]θ^(i−1)),
```

![Equation](img/si40.png)(5.6)

其中步长被视为常数，且已吸收因子 2。迭代相关步长值的更一般情况稍后将讨论。我们现在的目标变为寻找所有能保证收敛的 `μ` 值。为此，定义

```
c^(i) := θ^(i) − θ[*],
```

![Equation](img/si41.png)(5.7)

其中 `θ[*]` 是通过求解相应的正规方程（第 4 章）得到的（唯一）最优 MSE 解，

```
Σ[x]θ[*] = p.
```

![Equation](img/si42.png)(5.8)

从公式 (5.6) 两边减去 `θ[*]` 并代入公式 (5.7)，我们得到

```
c^(i) = c^(i−1) + μ(p − Σ[x]c^(i−1) − Σ[x]θ[*]) = c^(i−1) − μΣ[x]c^(i−1) = (I − μΣ[x])c^(i−1).
```

![Equation](img/si43.png)(5.9)

回想一下，`Σ[x]` 是一个对称正定矩阵（第 2 章）；因此它的所有特征值均为正，此外（附录 A.2）它可以写为

```
Σ[x] = QΛQ^T,
```

![Equation](img/si45.png)(5.10)

其中

```
Λ := diag{λ[1], …, λ[l]} 和 Q := [q[1], q[2], …, q[l]],
```

![Equation](img/si46.png)

这里 `λ[j]`, `q[j]`, `j` = 1, 2, …, `l` 为协方差矩阵的特征值及相应的归一化（正交）特征向量，

```
q[k]^T q[j] = δ[kj], k, j = 1, 2, …, l ⇒ Q^T = Q^(−1).
```

![Equation](img/si49.png)

即矩阵 `Q` 为正交矩阵。将 `Σ[x]` 的因式分解代入公式 (5.9)，可得

```
c^(i) = Q(I − μΛ)Q^T c^(i−1)
```

![Equation](img/si50.png)

或

```
v^(i) = (I − μΛ)v^(i−1) (5.11)
```

![Equation](img/si51.png)

其中

```
v^(i) := Q^T c^(i), i = 1, 2, … (5.12)
```

![Equation](img/si52.png)

前面使用的“技巧”是一个标准技巧，其目的是“解耦”公式 (5.6) 中 `θ^(i)` 的各个分量。确实，`v^(i)` 的每个分量 `v^(i)(j)`，`j` = 1, 2, …, `l`，都遵循一条独立于其余分量的迭代路径；换句话说，

```
v^(i)(j) = (1 − μλ[j])v^(i−1)(j) = (1 − μλ[j])²v^(i−2)(j) = ⋯ = (1 − μλ[j])^i v^(0)(j) (5.13)
```

![Equation](img/si56.png)

其中 `v^(0)(j)` 是 `v^(0)` 的第 `j` 个分量，对应于初始向量。很容易看出，如果

```
|1 − μλ[j]| < 1 ⇔ −1 < 1 − μλ[j] < 1, j = 1, 2, …, l
```

![Equation](img/si59.png) (5.14)

等比数列趋于零且

```
v^(i) → 0 ⇒ Q^T(θ^(i) − θ[*]) → 0 ⇒ θ^(i) → θ[*].
```

![Equation](img/si60.png) (5.15)

注意，(5.14) 等价于

```
0 < μ < 2/λ[max]
```

![Equation](img/fx002.jpg) (5.16)

其中 `λ[max]` 表示 `Σ[x]` 的最大特征值。

### 时间常数

图 5.6 显示了对于 `0 < 1 − μλ[j] < 1` 这种情况，`v^(i)(j)` 随迭代步数演变的典型草图。假设由红线表示的包络线（近似）呈指数形式，`f(t) = exp(−t/τ[j])`。将 `v^(i)(j)` 和 `v^(i−1)(j)` 的值（来自 (5.13)）分别代入 `f(t)` 中，作为对应时刻 `t = iT` 和 `t = (i−1)T` 的值；则时间常数为

```
τ_j = -1 / ln(1 - μλ_j),
```

![Equation](img/si69.png)

假设两次连续迭代之间的采样时间为 `T = 1`。对于较小的 `μ` 值，我们可以写成

```
τ_j ≈ 1/(μλ_j), for μ ≪ 1.
```

![Equation](img/si71.png)

也就是说，最低收敛速率与对应最小特征值的分量相关。然而，这仅在足够小的 `μ` 值下成立。对于更一般的情况，这可能不成立。回顾一下，收敛速率取决于项 `1 − μλ[j]` 的值。这也被称为第 `j` 个模式。其值不仅取决于 `λ[j]`，还取决于 `μ`。让我们考虑一个例子，即 `μ` 取非常接近最大允许值的情况，`μ ≈ 2/λ[max]`。此时，对应最大特征值的模式的绝对值将非常接近 1。另一方面，对应最小特征值的模式的时间常数将由 `|1 − 2λ[min]/λ[max]|` 的值控制，这可能远小于 1。在这种情况下，对应最大特征值的模式表现出较慢的收敛。

![Figure 5.6 Convergence curve for one of the components of the transformed error vector. Note that the curve is of an approximate exponentially decreasing type.](img/gr006.jpg)

**图 5.6** 变换误差向量的一个分量的收敛曲线。注意该曲线呈近似指数衰减类型。

为了获得步长的最优值，必须选择其值，使得由此产生的最大绝对模式值最小化。这是一个极大极小任务：

```
μ_o = arg min_μ max_j |1 - μλ_j|,
s.t.      |1 - μλ_j| < 1, j = 1,2,…,l.
```

![Equation](img/si75.png)

该任务可以通过图形轻松求解。**图 5.7** 显示了模式的绝对值（对应于最大、最小和一个中间特征值）。模式的（绝对）值最初随 `μ` 的增加而减小，然后开始增加。观察到最优值出现在最大和最小特征值对应的曲线相交处。确实，这对应于极小极大值。偏离 `μ[o]`，最大模式值增加；增加 `μ[o]`，对应最大特征值的模式变大，减小它，对应最小特征值的模式增加。在交点处我们有

```
1 - μ_o λ_min = - (1 - μ_o λ_max),
```

![Equation](img/si77.png)

由此得出

```
μ_o = 2 / (λ_max + λ_min).
```

![Equation](img/si78.png)(5.17)

在最优值 `μ_o` 处，有两个最慢模式；一个对应 `λ_min`（即 `1 - μ_o * λ_min`），另一个对应 `λ_max`（即 `1 - μ_o * λ_max`）。它们具有相等的幅度但相反的符号，由下式给出：

```
± (ρ - 1) / (ρ + 1)
```

其中

```
ρ := λ_max / λ_min.
```

换句话说，**收敛速率取决于协方差矩阵特征值的分布范围**。

![Fig. 5.7 As the step-size value increases, the time constant of each mode starts to decrease and then starts to increase after a certain point. The solid line corresponds to the maximum eigenvalue, the red line to the minimum eigenvalue, and the dashed lines to the intermediate eigenvalues. The overall optimum μ_o corresponds to the point where the red line intersects the solid line.](img/gr007.jpg)

**图 5.7** 随着步长值的增加，每个模式的时间常数开始减小，然后在某个点后开始增加。实线对应最大特征值，红线对应最小特征值，虚线对应中间特征值。整体最优 `μ_o` 对应红线与实线的交点。

### 参数误差向量的收敛

根据 (5.7) 和 (5.12) 中的定义，我们得到：

```
θ^(i) = θ_* + Q v^(i) = θ_* + [q_1, ..., q_l] [v^(i)(1), ..., v^(i)(l)]^T = θ_* + Σ_{k=1}^l q_k v^(i)(k)
```

(5.18)

或

```
θ^(i)(j) = θ_*(j) + Σ_{k=1}^l q_k(j) v^(0)(k) (1 - μλ_k)^i, j = 1,2,…,l.
```

换句话说，`θ^(i)` 的各分量作为 `(1 - μλ_k)` 的幂（即 `(1 - μλ_k)^i`）的加权平均，收敛到最优向量 `θ_*` 的相应分量。无法以闭式计算相应的时间常数；不过，我们可以给出下界和上界。下界对应于收敛最快模式的时间常数，上界对应于最慢模式的时间常数。对于 `μ ≪ 1` 的小值，我们可以写成

```
1/(μλ_max) ≤ τ ≤ 1/(μλ_min).
```

### 学习曲线

我们现在将重点转移到均方误差（MSE）上。回顾公式 (4.8) 可知

```
J(θ^(i)) = J(θ_*) + (θ^(i) - θ_*)^T Σ_x (θ^(i) - θ_*),
```

或者，利用公式 (5.18) 和 (5.10) 并考虑到特征向量的标准正交性，我们得到

```
J(θ^(i)) = J(θ_*) + Σ_{j=1}^l λ_j |v^(i)(j)|^2 ⇒ J(θ^(i)) = J(θ_*) + Σ_{j=1}^l λ_j (1 - μλ_j)^(2i) |v^(0)(j)|^2,
```

它渐近收敛到最小值 `J(θ[*])`。此外，观察到该收敛是单调的，因为 `λj²` 为正值。遵循与之前类似的论证，现在每个模式各自的时间常数为

```
τ_j^mse = -1 / (2 ln(1 - μλ_j)) ≈ 1/(2μλ_j).
```
