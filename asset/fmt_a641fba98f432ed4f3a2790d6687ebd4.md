### 示例 8.11

让我们通过熟悉的二次函数优化任务来演示上述发现：

```
f(x) = (1/2)x^T A x - b^T x
```

不难发现，极小化点出现在线性方程组

```
A x[*] = b
```

的解处。根据公式 (8.106) 中的定义，对二次函数求梯度并令其为零，我们可直接得到

```
Prox_{λf}(x) = (A + (1/λ)I)^{-1} (b + (1/λ)x)
```

![Equation](img/si532.png)(8.119)

令 $\epsilon = \frac{1}{\lambda}$，则公式 (8.119) 中的递归变为

**x**[k] = (A + \epsilon I)^(-1)(b + \epsilon **x**[k - 1])。

![Equation](img/si534.png)(8.120)

经过一些简单的代数运算（问题 8.37），我们最终得到

**x**[k] = **x**[k - 1] + (A + \epsilon I)^(-1)(b - A **x**[k - 1])。

![Equation](img/si535.png)(8.121)

在数值线性代数中，该方案被称为*迭代修正*算法 [58]。当矩阵 A 接近奇异时会用到它，因此通过 \epsilon 进行正则化有助于求逆。请注意，在每次迭代中，**b** - A **x**[k - 1] 是当前估计值所产生的误差。该算法属于一大类算法家族，称为平稳迭代或迭代松弛方案；我们将在第 10 章遇到此类方案。

这里有趣的是，由于该算法作为近端最小化算法的一个特例出现，即使 \epsilon 不小，也能保证收敛到解！
