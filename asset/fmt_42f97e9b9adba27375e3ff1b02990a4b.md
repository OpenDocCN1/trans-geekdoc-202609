
## 3.6.5 通过加权求和计算交叉熵损失

样本的加权求和与 `z` 的 softmax 函数输出即为概率 `f`。已知加权求和 `z` 即可计算 `f`，进而计算交叉熵损失。以下代码计算多个样本的加权求和 `Z` 及其目标类别标签 `y` 的交叉熵损失：

```python
# https://deepnotes.io/softmax-crossentropy
def softmax(Z):
    A = np.exp(Z - np.max(Z, axis=1, keepdims=True))
    return A / np.sum(A, axis=1, keepdims=True)

def softmax_cross_entropy(Z, y):
    m = len(Z)
    F = softmax(Z)
    log_Fy = -np.log(F[range(m), y])
    return np.sum(log_Fy) / m
```

使用一组 `Z` 测试该函数：

```python
Z = np.array([[2, 25, 13], [54, 3, 11]])  # 每行对应一个样本
y = np.array([2, 1])
softmax_cross_entropy(Z, y)
```

输出：

```
31.500003072148047
```

如果目标标签采用 one-hot 向量形式，以下代码从加权求和计算交叉熵损失：

```python
def softmax_cross_entropy_one_hot(Z, y):
    F = softmax(Z)
    loss = -np.sum(y * np.log(F), axis=1)
    return np.mean(loss)
```

```python
Z = np.array([[2, 25, 13], [54, 3, 11]])  # 每行对应一个样本
y = np.array([[0, 0, 1], [0, 1, 0]])
softmax_cross_entropy_one_hot(Z, y)
```


## 3.6.6 Softmax 回归的梯度计算

Softmax 回归的目标是找到使交叉熵损失 ℒ(`W`) 最小化的 `W`，求解算法仍为梯度下降法。为此，需要计算 ℒ(`W`) 对 `W` 的梯度，即对每个 `W[jk]` 的偏导数。

### 1. 交叉熵损失对加权求和的梯度

设一个样本为 (`x`, `y`)，`f`(`x`) = `softmax`(`x``W`) 可视为 `z` = (`z`[1], `z`[2], `z`[3]) = (`x``W`[, 1], `x``W`[, 2], `x``W`[, 3]) 和 `f`(`z`) = `softmax`(`z`) = `softmax`(`z`[1], `z`[2], `z`[3]) 的复合函数。

引入辅助中间变量 `a` = (`a`[1], `a`[2], `a`[3]) = (`e`^(`z`[1]), `e`^(`z`[2]), `e`^(`z`[3]))。但

$f(z) = f(a) = \begin{pmatrix} f_{1}, & f_{2}, & f_{3} \end{pmatrix} = \begin{pmatrix} \frac{a_{1}}{a_{1} + a_{2} + a_{3}}, & \frac{a_{2}}{a_{1} + a_{2} + a_{3}}, & \frac{a_{3}}{a_{1} + a_{2} + a_{3}} \end{pmatrix}$

令 ℒ = −`log`(`f`[`y`]) = −(`log`(`a`[`y`]) − `log`(`a`[1] + `a`[2] + `a`[3]))

$$
\begin{matrix}
\frac{\partial\mathcal{L}}{\partial z_{i}} = - \frac{1}{a_{y}}\frac{\partial a_{y}}{\partial z_{i}} - \frac{1}{a_{1} + a_{2} + a_{3}}(\frac{\partial a_{1}}{\partial z_{i}} + \frac{\partial a_{2}}{\partial z_{i}} + \frac{\partial a_{3}}{\partial z_{i}}) \\
= - \frac{1}{a_{y}}\frac{\partial a_{y}}{\partial z_{i}} - \frac{1}{a_{1} + a_{2} + a_{3}}e^{z_{i}} \\
= - \frac{1}{a_{y}}1{(y==i)}e^{z_{y}} - \frac{1}{a_{1} + a_{2} + a_{3}}e^{z_{i}} \\
= - 1{(y==i)} + \frac{e^{z_{i}}}{\sum\limits_{1}^{3}e^{z_{i}}} = f_{i} - 1{(y==i)}
\end{matrix}
$$

其中，符号 `1`(`y` == `i`) 表示当 (`y` == `i`) 成立时值为 1，否则值为 0。

因此，ℒ 对 `z` = (`z`[1], `z`[2], `z`[3]) 的梯度为：

$\nabla_{z}\mathcal{L} = (\frac{\partial\mathcal{L}}{\partial z_{1}},\frac{\partial\mathcal{L}}{\partial z_{2}},\frac{\partial\mathcal{L}}{\partial z_{3}}) = (f_{1} - 1{(y==1)},f_{2} - 1{(y==2)},f_{3} - 1{(y==3)})$

若 `y`=1，则：

∇[`z`]ℒ = (`f`[1] − 1, `f`[2], `f`[3])

也就是说，对于任意 C 分类问题，若某 `y` 的分类为 i，则：

∇[`z`]ℒ = (`f`[1], `f`[2], ⋯, `f`[`i`] − 1, ⋯, `f`[`C`]) = `f` − `I`[`i`]

符号 `I`[`i`] 表示一个 one-hot 向量，其第 i 个分量为 1，其余分量为 0。若样本的目标值 `y` 用该 one-hot 向量表示，即 `y` = `I`[`i`]，则：

∇[`z`]ℒ = `f` − `y`

这与线性回归损失 $\frac{1}{2} \parallel f - y \parallel^{2}$ 对 `f` 的梯度、逻辑回归交叉熵损失 −(`y``log`(`f`) + (1 − `y`)`log`(1 − `f`)) 对加权求和 `z` 的梯度惊人地一致。但仍有区别。线性回归是损失函数值关于 `f` 的梯度，而逻辑回归和 softmax 回归是关于加权求和 `z` 而非 `f` 的梯度。梯度均为 `f` − `y`，但逻辑回归的概率由 `f` = `σ`(`z`) 计算，softmax 回归的概率由 `f` = `softmax`(`z`) 计算。

因此，对于由多个样本特征构成的向量 `Z`，用 ℒ 表示所有样本的总损失，则 ℒ 对加权求和 `Z` 的梯度为：

∇[`Z`]ℒ = `F` − `I`[`i`]

或

∇[`Z`]ℒ = `F` − `Y`

该形式与逻辑回归损失函数对加权求和的梯度相同，也与线性回归损失函数 $\frac{1}{2} \parallel F - Y \parallel^{2}$ 关于输出 `F` 的梯度一致。

根据公式 (12)，计算交叉熵对 `Z` 的梯度的代码如下：

```python
def grad_softmax_crossentropy(Z, y):
    F = softmax(Z)
    I_i = np.zeros_like(Z)
    I_i[np.arange(len(Z)), y] = 1
    return (F - I_i) / Z.shape[0]
```

```python
def grad_softmax_cross_entropy(Z, y):
    m = len(Z)
    F = softmax(Z)
    F[range(m), y] -= 1
    return F / m
```

使用 2 个样本的 `Z` 及其目标值 `y` 测试该函数：

### 2. 交叉熵损失对权重参数的梯度

已得到损失函数对加权求和 `z` 的梯度，进而可得损失函数对模型参数 `W` 的梯度。因为 `z`[`i`] = `x``W`[, `i`] 对 `W`[, `i`] 的梯度为 `x`，而对其他 `W`[, `j`] 其梯度为 0，故：

$\frac{\partial z_{i}}{\partial W_{,j}} = 1(i==j)x$

因此，有：

$$
\begin{matrix}
\frac{\partial\mathcal{L}}{\partial{W W_{,j}}} & {= \sum\limits_{i = 1}^{3}\frac{\partial\mathcal{L}}{\partial z_{i}}\frac{\partial z_{i}}{\partial{W W_{,j}}} = \frac{\partial\mathcal{L}}{\partial z_{j}}\frac{\partial z_{j}}{\partial{W W_{,j}}}} & {= (f_{j} - 1{(y==j)})x x}
\end{matrix}
$$

也就是说，对于每个 `j` = 1, 2, 3，有：

$$
\frac{\partial\mathcal{L}}{\partial{W W_{,1}}} = (f_{1} - 1{(y==1)})x x
$$

$$
\frac{\partial\mathcal{L}}{\partial{W W_{,2}}} = (f_{2} - 1{(y==2)})x x
$$

$$
\frac{\partial\mathcal{L}}{\partial{W W_{,3}}} = (f_{3} - 1{(y==3)})x x
$$

注意：因为 `W W_{,1}` 是列向量，如果 `x x` 是行向量，则上述 $\frac{\partial\mathcal{L}}{\partial{W W_{,j}}}$ 也是行向量。如果想将 $\frac{\partial\mathcal{L}}{\partial{W W}}$ 写成与 `W W` 形状相同的矩阵形式，则：

$$
\begin{matrix}
\frac{\partial\mathcal{L}}{\partial{W W}} & {= (\frac{\partial\mathcal{L}}{\partial{W W_{,1}}}^{T},\frac{\partial\mathcal{L}}{\partial{W W_{,j}}}^{T},\cdots,\frac{\partial\mathcal{L}}{\partial{W W_{,C}}}^{T})} \\
& {= {x x}^{T}(f_{1} - 1{(y==1)},f_{2} - 1{(y==2)},\cdots,f_{C} - 1{(y==C)})}
\end{matrix}
$$

如果使用独热向量来表示目标值（标签）`y y`，可以写成更简洁的公式：

$$
\frac{\partial\mathcal{L}}{\partial{W W}} = {x x}^{T}{(f f - y y)}
$$

其中，假设 `x x`、`f f`、`y y` 均为行向量形式。这是一个与 `W W` 形状相同的矩阵。如果 C 是类别数，n 是数据特征数，则 `x x` 是 1 × n 向量，`x x`^(`T`) 是 n × 1 向量，`W W` 是 n × C 矩阵，因为 `z z` = `x x``W W`、`f f` = `softmax`(`z z`)，所以 `f f`、`y y` 是 1 × C 向量。因此，`x x`^(`T`)(`f f` − `y y`) 是 n × C 的矩阵。

对于矩阵

$$
\begin{matrix}
{X = \begin{bmatrix}
{x x^{(1)}} \\
{x x^{(2)}} \\
\vdots \\
{x x^{(i)}} \\
\vdots \\
{x x^{(m)}} \\
\end{bmatrix}}
\end{matrix}
$$

`F F`、`Y Y` 是对应这些样本的预测值矩阵和目标值矩阵：

$$
\begin{matrix}
{F = \begin{bmatrix}
{f f^{(1)}} \\
{f f^{(2)}} \\
\vdots \\
{f f^{(i)}} \\
\vdots \\
{\mathbf{f}^{(m)}} \\
\end{bmatrix}}
\end{matrix}
$$，

$$
\begin{matrix}
{Y = \begin{bmatrix}
{y y^{(1)}} \\
{y y^{(2)}} \\
\vdots \\
{\mathbf{y}^{(i)}} \\
\vdots \\
{y y^{(m)}} \\
\end{bmatrix}}
\end{matrix}
$$。

则损失函数关于权重 `W W` 的梯度向量形式为：

$$
\frac{\partial\mathcal{L}}{\partial{W W}} = {X X}^{T}{(F F - Y Y)}
$$

类似地，可以在 Softmax 回归的交叉熵损失中加入正则项。如果目标值用整数表示，损失函数变为：

$$
L(W W) = - \frac{1}{m}\sum\limits_{i = 1}^{m}\log(f_{y^{(i)}}^{(i)}) + \lambda \parallel W W \parallel^{2}
$$

如果目标值用独热向量表示，则损失函数变为：

$$
L(W W) = - \frac{1}{m}\sum\limits_{i = 1}^{m}y^{(i)}\cdot\log(f^{(i)}) + \lambda \parallel W \parallel^{2}
$$

则损失函数关于权重 `W W` 的梯度为：

$$
\frac{\partial\mathcal{L}}{\partial{W W}} = {X X}^{T}{(F F - Y Y)} + 2\lambda W W
$$
