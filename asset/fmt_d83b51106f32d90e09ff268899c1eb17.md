
RMR-HFS 相比其他特征选择（`RRelief`、`MI` 和 `RFE`）对每种方法（`MLP`、`RNN`、`LSTM`）的优越性。总体而言，带有 `RMR-HFS` 的 `LSTM` 实现了优于 `MLP`、`RNN`、`RNN-HFS`、带有 `RRelief` 的 `RNN`、带有 `MI` 的 `RNN`、带有 `RFE` 的 `RNN`、带有 `RMR-HFS` 的 `LSTM`、带有 `Relief` 的 `LSTM` 以及带有 `MI` 的 `LSTM` 等方法的预测性能。如图 (v) 所示，图 (a) 的部分在图 (b) 中仅观察到 5 个样本。不同方法在训练样本和测试样本上的预测负载对比如图 (b) 所示。它显示 `RMR-LSTM` 的图比其他方法更接近实际负载。它展示了所提方法 `RMR-LSTM` 优于其他方法的优越性能。

预测模型的性能可以通过许多方式进行评估。`MAPE` 和 `RMSE` 被用作预测方法的额外评估指标。`MAPE` 和 `RMSE` 的计算如下：

```
$$MAPE = \frac{100}{n} \sum_{t=1}^{n} \left| \frac{Y_t - F'_t}{Y_t} \right| ; \quad (12)$$
```

```
$RMSE = \sqrt{\frac{1}{n} \sum_{t=1}^{n} [Y_t - F'_t]^2} ; \quad (13)$
```

其中 `n` 代表实例数量，`$Y_t$` 代表观测时间的实际值，`'$F'_t$'` 代表该时间的预测值。

# 5. 结论

深度神经网络是研究人员自动学习输入输出之间复杂映射的一种不确定工具。电力负载具有不确定性和非线性特征。因此，利用深度学习方法可以实现未来负载的准确预测。通过提供关键特征和相关的输入数据可以增强深度学习的性能。因此，在此处，过滤器和特征选择的结合是通过针对数百个欧洲电力负载进行的实验确定的。此外，这些因素可能会影响未来的性能。其他的深度学习技术也可以提高准确性。
