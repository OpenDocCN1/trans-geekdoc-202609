
### 循环神经网络 (RNN)

一种可以处理序列数据的神经网络。它具有反馈循环，允许它记住过去的输入，并使用这些信息来处理未来的输入。

* 擅长涉及序列数据的任务。
* 适用于长期依赖问题。
* 理解和实现较为复杂。
* 需要大量数据进行训练。

### 长短期记忆 (LSTM) 网络

`RNN` 的一种变体，专门设计用于处理序列数据中的长期依赖关系。

* 非常擅长处理涉及长期依赖关系的任务。
* 准确率高。
* 理解和实现较为复杂。
* 需要大量数据进行训练。

### 径向基函数网络 (RBFN)

一种使用径向基函数计算网络输出的神经网络。

* 擅长回归任务。
* 准确率高。
* 理解和实现较为复杂。
* 需要大量数据进行训练。

## 神经网络训练

![](img/ufig9_4.jpg)

`前向传播` 和 `反向传播` 是训练 `FNNs` 的两个基本过程。它们共同工作，使网络能够从数据中学习并改进其预测。`前向传播` 是用于处理数据并对给定输入做出预测的基本机制。它将输入数据通过神经网络以生成预测或输出。`反向传播` 也称为 `backpropagation`，是一种用于训练 `FNNs` 的学习算法。它评估预测输出与实际目标值之间的差异（误差），然后调整网络的 `weights`（权重）和 `biases`（偏置），以在训练过程中使误差最小。

1. `前向传播`：
   * 输入数据被馈入神经网络，它从输入层到输出层正向通过各层。
   * 在每一层，输入数据与层的 `weights` 和 `biases` 相乘，然后对结果应用激活函数以引入非线性。
   * 每一层的输出成为下一层的输入，此过程一直持续到在输出层生成最终输出。
   * `前向传播` 本质上是根据神经网络当前的 `weights` 和 `biases` 进行预测的过程，而不考虑实际目标值。

2. `反向传播`：
   * `反向传播` 是一种根据前向传播期间预测误差来更新神经网络 `weights` 和 `biases` 的学习算法。
   * 在 `前向传播` 和预测之后，使用 `loss function` 计算预测误差，该函数量化了预测与真实值之间的偏差，并作为网络性能的衡量。
   * `反向传播` 通过计算 `loss function` 的 `gradients` 来工作。`gradients` 代表了 `loss` 对网络参数（`weights` 和 `biases`）变化的敏感性，指示了为了减少误差应该以什么方向和程度调整每个参数。
   * 使用计算出的 `gradients`，通过优化算法调整 `weights` 和 `biases`，以使 `loss` 最小并提高网络性能。

总之，`forward propagation` 是将输入数据通过神经网络以生成预测的过程，而 `backward propagation` 是计算 `loss function` 的 `gradients` 并使用它们在训练期间更新网络参数的过程。这些过程共同构成了训练 `FNNs` 的基础，对于使网络从数据中学习并提高其预测能力至关重要。

## 神经网络的优缺点

![](img/icon_8.jpg)

神经网络是一种非常强大的机器学习算法。这种方法已用于许多领域，并在人工智能的研究中起着至关重要的作用。尽管如此，神经网络并非完美，仍然面临挑战。对我们来说，理解这种方法的优缺点很重要，这样我们就可以决定何时是使用神经网络进行数据挖掘项目的正确时机。

### 神经网络的优点

* `非线性`：神经网络可以很好地捕捉数据中的非线性关系，使得这种方法适用于传统线性模型可能会失败的复杂问题。
* `适应学习`：它们可以实时学习并适应新数据。因此，它们对于数据不断变化的动态环境建模非常有效。
* `无限信息`：这种方法不仅限于输入数据，因为它使用了许多隐藏层来创建层与层之间的连接。在训练过程中会产生更多信息来生成良好的模型。
* `并行处理`：神经网络可以同时处理多个输入。因此，它们可以用于需要高效率的任务，如图像识别和自然语言处理。
* `容错性`：这种方法对数据中的噪声和错误具有韧性。当某些数据缺失或损坏时，网络仍然可以良好运行，因为信息存储在网络中而不是数据库中。
* `特征提取`：可以从原始数据中自动提取相关变量，消除了手动选择的需要。

### 神经网络的缺点

* `黑箱`：神经网络通常被视为 `black box`，因为很难理解模型如何工作以及变量之间如何关联。换句话说，我们将输入数据馈给模型，它预测输出变量的值。但我们并不真正理解黑箱内部发生了什么。这种解释性的缺失可能使得该方法不适用于需要透明度的应用。
* `过拟合`：神经网络很容易产生 `overfitting`，特别是当我们使用大量数据时。这意味着它们在训练数据上表现良好，但在新的、未见过的数据上表现不佳。换句话说，模型不具泛化性。
* `数据需求`：这种方法需要大量的标注数据进行有效训练，这在某些应用中可能是一个重大的瓶颈。
* `计算密集型`：训练过程可能是计算密集型的，需要很高的计算能力更长的训练时间。
* `超参数配置`：为神经网络设置超参数具有挑战性，并且必须仔细进行以获得最佳性能。由于确定网络架构的配置没有直接的规则，建模过程需要实验来获得最佳性能。

尽管有这些缺点，神经网络仍然是一种强大的机器学习方法，其应用也在迅速增长，特别是深度学习方法。通过理解其优势和劣势，我们可以为我们的研究使用这种方法制定良好的策略。再次，本书的目的是为实现神经网络（一种复杂的机器学习算法）提供简单的介绍和指南。因此，我们不会深入探讨神经网络建模中的复杂方法。

## 神经网络的基础概念

![](img/shut3_2.jpg)

如前所述，神经网络方法是一种复杂的机器学习方法。即使我们关注最简单的神经网络形式，理解模型如何工作仍然是一个挑战。以下基础概念构成了神经网络的基础，帮助你理解神经网络的架构和训练过程（表 9.2）。

### 表 9.2 神经网络的基础概念

| 术语 | 描述 |
| --- | --- |
| 神经元 (节点) | 神经元也称为节点或单元，是神经网络的基础构建模块。它接收输入，使用激活函数对其进行处理，并产生输出。 |
| 连接 (边) | 连接连接神经元。每个连接都有一个关联的权重，该权重决定了所连神经元之间的影响程度。 |
| 激活函数 | 激活函数是一种根据输入的加权之和来确定神经元输出的函数。常见的激活函数包括 sigmoid、`ReLU`（修正线性单元单元）和 `tanh`（双曲正切）。 |
| 权重 | 神经元之间的每个连接都分配有一个权重，代表了该连接的强度或重要性。这些权重决定了一个神经元的输入对另一个神经元输出的影响程度。 |
| 偏置 | 在每个神经元的输入加权和上会加上一个偏置项。它允许网络学习对某些值的偏置，并提高模型的准确性。 |
| 层 | 神经元在神经网络中按层组织。输入层接收输入数据，输出层产生最终输出，中间可以有一个或多个隐藏层。 |
| 前向传播 | 前向传播是输入信号逐层通过网络传输以产生输出的过程。层中的每个神经元接收来自上一层的输入，使用其激活函数进行计算，并将输出传递到下一层。 |
| 反向传播 (或后向传播) | 反向传播是根据预测误差调整网络中权重和偏置的过程。它涉及计算损失函数的梯度并调整参数以最小化误差。 |
| 训练 | 训练神经网络涉及使用训练数据集迭代地调整权重和偏置。目标是最小化误差或损失函数，并提高网络的预测准确性。 |
| 损失函数 | 损失函数衡量神经网络的预测输出与实际目标值之间的差异。它量化了误差，并指导训练期间参数的调整。 |
| 优化算法 | 优化算法在训练期间用于根据计算出的梯度调整网络参数。梯度下降是用于此目的的常用优化算法。 |

现在，我们对神经网络有了一些基本的了解。如之前的 [图 9.3] 所示，神经网络模型由输入节点、隐藏节点和输出节点之间的连接组成。那么，我们如何在不涉及复杂数学的情况下表达这些连接呢？为了演示这一点，我使用了一个带有一个隐藏层的神经网络架构。[图 9.4] 以简单的方式展示了节点之间的连接。

[图 9.4] 神经网络模型中节点之间的连接。

### 网络连接

基本上，输出节点是连接到该节点的隐藏节点及其对应权重的函数。本质上，从隐藏节点到输出节点的每条路径都有一个权重，类似于回归权重。权重捕捉了该关系在模型中的重要性。同样，隐藏节点是连接到该节点的输入节点及其对应权重的函数。在每个方程中，我们还有一个偏置节点。偏置是与每个节点关联的可学习参数。偏置节点允许我们将函数向左或向右移动，这对于训练模型至关重要。我们一直提到的函数被称为 `激活函数`。这些连接的数学表达式要复杂得多，但请相信我，它们的意思仅于此。我们将很快进入一些常用激活函数的细节。

所以你可能会奇怪，为什么我不将这些方程表示为带有截距加上回归权重乘以输入变量加上误差的线性回归方程。原因是 `激活函数` 可能是线性的，也可能是非线性的。这是神经网络的优势，因为它可以捕捉复杂网络架构中输入节点、隐藏节点和输出节点之间的非线性关系。

## 激活函数

## Neural Network Searching

![](img/icon_4.jpg)

In neural network training process, sometimes we may face the so-called local optimum. This situation describes a local optimum which is the optimal solution within a specific neighborhood of candidate solutions. It differs from a global optimum, which represents the optimal solution among all potential solutions, rather than being limited to a particular subset. `Figure 9.6` illustrates the local optimum vs. global optimum. As you can see, point A shows the global optimum in terms of the lowest error. The training process may result in two local optimums, which are point B and point C, which appear to be the network with the lowest error only within a local set of solutions. In other words, the training process may mistake point B or point C as the optimum due to the flaw in the learning algorithm.

![Figure 9.6 Global optimum and local optimum](img/fig9_6.jpg)

`Figure 9.6` Global optimum and local optimum.

Of course, we want a global optimum since the local optimum is not the actual optimal solution and may lead to a poor fit model. Overcoming local optimum problems in neural networks is not an easy task since we must build a very good optimization model, which is not in the scope of this book. However, a local optimum is not always the worst thing. In some cases, when we build larger neural networks, the local optimum with reasonably low error is acceptable.

### SAS Enterpriser Miner's Network Searching Methods

SAS Enterprise Miner 在 `AutoNeural` 节点下提供了三种方法，如下：

- `Train`：所有选定的函数都将进行训练，直到满足停止条件。
- `Increment`：一次添加一个节点，且不重复使用激活函数。如果某一层降低了平均误差，则保留该层；否则将其从模型中移除。
- `Search`（`Default`）：根据预设的架构添加节点，性能最好的网络将成为最终模型。

作为训练过程的一部分，利用 `AutoNeural` 节点的 `Termination` 属性来指定终止方法。当超过最大运行时间时，训练将总是结束，并保留选择标准最佳的模型。

共有三种终止方法，如下：

- `Overfitting`（`Default`）：当检测到过拟合时，训练终止。
- `Training Error`（训练误差）：当训练数据集误差减少小于 0.001 时，训练终止。
- `Time Limit`（时间限制）：当超过 `Total Time` 属性指定的时间时，训练停止。
