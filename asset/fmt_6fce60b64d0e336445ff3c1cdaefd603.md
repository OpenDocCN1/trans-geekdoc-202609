
# 黑客技术精要——道德黑客与渗透测试初学者指南

## 简介

确保您的 IT 基础设施、服务和应用程序安全的一种有效方法，是聘请自由职业的白帽黑客对其进行攻击。无论您喜不喜欢，黑客都会渗透您的系统，因此参与这一过程以弥补安全漏洞将对您有益。遗憾的是，许多公司没有足够的资源进行渗透测试。对于需要以较低价格获得此项服务的小公司来说，众包是一个绝佳的选择。您可以在合适的时间以实惠的价格获得所需的人才。当您不亲自了解这些参与者时，您面临的风险是：对方可能不像他们声称的那样经验丰富，或者无法胜任工作。最大的风险是他们会保留收集到的信息以备后用。幸运的是，有一些受信任的公司充当您与黑客之间的中介。他们为您联系技术娴熟、经过审核的黑客，并提供框架和计划，收取一定费用。一些最大且最常见的众包公司包括 `HackerOne`、`Bugcrowd` 和 `Synack`。这些公司及同类公司提供三项主要服务：

- 漏洞赏金计划
- 渗透测试
- 漏洞披露

漏洞披露涉及客户创建并发布漏洞披露计划。它定义了黑客如何以及在何处联系中介或客户以报告新发现的漏洞。其中包含了黑客、中介和客户的期望与责任。有些黑客曾在供应商有机会修补漏洞之前，就不负责任地向公众披露其发现。然而，他们之所以这样做，是因为对公司不合理的回应感到沮丧。渗透测试是为众包企业带来最大收入的服务。他们以特定价格将客户与一群技术高超的黑客联系起来，针对特定工作范围开展工作。大多数与这些公司合作的黑客是兼职的——全职从事此工作的人不多。众包黑客在单个工作中能赚多少钱，取决于他们被选中的工作类型、经验和技能组合。一些黑客自愿从事这项工作以保障其国家的政府资源安全，而另一些则将收入捐给慈善机构。漏洞赏金公司可以为您节省大量资金和时间。并非所有黑客报告的漏洞都易于复现或构成安全威胁。漏洞赏金计划供应商会告诉您需要修复哪些已报告的漏洞。他们的工作是弄清哪些漏洞是真实的。无论您的 IT 安全团队有多优秀，公司都应该要求开展漏洞赏金计划。根据项目持续时间、工作经验量和黑客水平，这可能需要花费您从几千美元到几万美元不等。确定您的预算和想要完成的服务类型。如果您确定有必要进行众包，请与一家将为您管理流程并消除大部分风险的公司交谈。

### 第 1 章：网络钓鱼攻击

网络钓鱼是一种社会工程学攻击。在大多数情况下，它被用于访问并窃取用户数据，例如信用卡号和登录凭证。当入侵者伪装成受信任的一方，并欺骗受害者打开短信、即时消息或电子邮件时，就会发生此类攻击。随后，受害者被诱导点击链接，从而允许攻击者冻结系统或安装恶意软件。这种攻击具有破坏性，可能导致身份盗窃、资金被盗和未经授权的购买。在政府或企业网络中，网络钓鱼授予入侵者立足点，并为更大规模的攻击（如 APT，高级持续性威胁）打开大门。在 APT 攻击中，组织可能遭受重大经济损失以及许多其他损害。

网络钓鱼攻击示例可以是电子邮件，例如 `myuniversity.edu`，可能会发送给教职员工。邮件告知收件人其用户密码将在短时间内过期。邮件将包含说明，引导用户前往 `myuniversity.edu/renewal` 以更新密码。当收件人点击链接时，可能会发生以下几种情况：

*   他们可能被重定向到一个虚假页面 `myuniversity.edurenewal.com`，该页面与实际的更新页面非常相似。系统要求用户输入旧密码和新密码。攻击者监控该页面并获取原始密码，从而获得对大学网络的访问权限。
*   链接可能将用户重定向到真实的密码更新页面。在重定向过程中，入侵者在后台激活恶意脚本，劫持用户的会话 Cookie。结果是形成了一次反射型 XSS 攻击，使攻击者能够访问特权信息。

电子邮件钓鱼诈骗是一场数字游戏。欺诈性消息会发送给大量收件人，因此即使只有极少比例的收件人上当受骗，攻击者仍能收集大量信息。入侵者拥有提高成功率的技巧。他们确保钓鱼消息看起来非常像目标机构发出的实际邮件。他们制造紧迫感，迫使收件人采取行动。消息中包含的链接看起来像合法链接。

鱼叉式网络钓鱼并非针对随机人员；它针对特定企业或个人。它是网络钓鱼的高级版本，需要关于组织的特殊知识。当攻击者获取有效的登录凭证时，他们可能成功实施第一阶段的 APT 攻击。

为了保护组织免受网络钓鱼攻击，企业和用户都需要采取预防措施：

*   **用户需要保持警惕。** 任何伪造的消息都会有一些小错误暴露其真面目。
*   **企业应遵循以下几个步骤，以减少鱼叉式网络钓鱼和网络钓鱼攻击：**
    *   建立双因素认证 (2FA)。此方法要求用户在访问敏感信息时进行额外的验证步骤。
    *   除了 2FA，公司还应制定严格的密码管理策略。员工应定期更换密码，并为不同的应用程序使用不同的密码。
    *   企业应组织教育宣传活动。

### 第 2 章：高级持续性威胁 (APT)

APT 是一个宽泛的术语。它描述了入侵者发起的一次攻击活动，旨在在网络上建立恶意的长期存在，以窃取敏感数据。入侵者或入侵者团队会仔细搜寻并挑选目标，通常是政府网络或大型企业。这些入侵可能造成巨大损害，包括：

*   知识产权窃取
*   敏感信息泄露
*   网站完全被接管
*   关键基础设施遭到破坏

APT 攻击与传统的 Web 应用程序攻击略有不同，因为：

*   它们是人工执行的
*   它们复杂得多
*   它们绝非一击即走式攻击
*   它们的目标通常是渗透整个网络

## APT 发展阶段

一次成功的高级持续性威胁分三个阶段发生：

1.  **渗透：** 在大多数情况下，企业是通过以下方式之一被渗透的：授权人类用户、网络资源或 Web 资产遭到攻陷。这可以通过社会工程学攻击（如鱼叉式网络钓鱼）或恶意上传（如 SQL 注入）来实现。此外，入侵者可以同时对目标发起 DDoS 攻击。这会分散网络人员的注意力并削弱安全边界。一旦实现初始访问，入侵者就会安装后门 Shell。这种恶意软件赋予他们网络访问权限和远程控制权。
2.  **扩展：** 一旦建立了立足点，他们就会扩大存在范围。他们沿着组织的层级向上移动，通过访问高度敏感的数据来攻陷员工。在此过程中，他们收集企业的关键信息，如财务记录、员工数据和产品线信息。他们可以将这些信息出售给竞争对手，或破坏产品线并摧毁公司。
3.  **提取：** 在 APT 事件期间，窃贼将窃取的数据存储在他们正在攻击的网络内部某个安全的地方。收集到足够数据后，他们会在不被察觉的情况下悄悄提取数据。当信息被提取时，您的安全团队会被“白噪音”干扰分散注意力。

## 缓解策略

*   阻止被盗数据提取和防止后门安装的最佳方法是监控出站和入站流量。养成检查网络边界流量的习惯，以便任何异常行为都不会被忽视。
*   在网络边界部署 Web 应用程序防火墙，以帮助过滤发往 Web 应用程序服务器的流量。网络防火墙和其他内部流量监控服务也有帮助。
*   白名单控制网络可访问的域和用户可安装的应用程序。它减少了入侵者可利用的攻击面。此安全措施并非万无一失。为了使其更有效，始终要有严格的更新策略，确保用户运行应用程序的更新版本。
*   您的员工是最大且最脆弱的软肋。目标分为三类：
    *   粗心的用户
    *   恶意内部人员
    *   被攻陷的用户
*   仔细审查所有员工及其有权访问的信息。
*   一旦发现操作系统和软件网络漏洞，立即修补。
*   加密远程连接，以防入侵者利用它们访问您的网络。
*   过滤传入邮件。这可以防止网络钓鱼攻击和垃圾邮件。
*   立即记录安全事件，以改进白名单和任何其他策略。

### 第 3 章：渗透测试

渗透测试有时被称为渗透测试。它是针对您的 PC 系统模拟的网络攻击，旨在查明是否存在可利用的漏洞。在 Web 应用程序安全领域，渗透测试通常用于增强 WAF（Web 应用程序防火墙）。渗透测试有时涉及尝试突破多个应用程序系统，如前端/后端服务器和应用程序协议接口（API），以检查其易感性；例如，面临代码注入攻击风险的未清理输入。渗透测试提供的见解有助于修补检测到的漏洞并增强 WAF 安全策略。渗透测试过程可分为五个阶段：

## 规划与侦察

确定测试的范围和目标，包括要使用的测试方法和应解决的系统。收集情报（例如域名、网络、邮件服务器），以帮助更好地了解目标及其潜在漏洞。

## 扫描

第二步涉及了解目标应用程序在面对不同入侵尝试时的行为。这通过以下方式实现：

- **静态分析**：检查应用程序的代码，以粗略推测其运行时的行为。工具可一次性扫描完整代码。
- **动态分析**：在运行状态下检查应用程序的代码。这种扫描方法更实用，因为它提供了应用程序性能的实时视图。

## 获取访问权限

使用 Web 应用程序攻击（如后门、SQL 注入和跨站脚本攻击）来揭示目标的漏洞。测试人员尝试利用这些易感性，通常通过窃取数据、提升权限、拦截流量和其他操作来了解可能造成的破坏程度。

## 维持访问权限

旨在查看该易感性是否可用于在目标系统中维持立足点——并可能给攻击者足够的时间访问深层数据。其理念是模拟高级持续性威胁；它们在系统中长期潜伏，以便访问组织的敏感数据。

## 分析与报告

渗透测试的发现将被汇总成一份报告，详细记录：

- 发现的漏洞
- 攻击者访问的任何敏感数据
- 测试人员在未被检测到的情况下留在系统中的时长。

安全人员分析这些信息，以帮助他们配置企业的 WAF 设置并应用其他安全解决方案，从而修补发现的易感性并防止未来的攻击。

## 渗透测试类型

- **外部渗透测试**：针对互联网上可见的公司资产进行，如公司网站、Web 应用程序、电子邮件等。
- **内部渗透测试**：模拟恶意内部人员的攻击。
- **盲测**：测试人员仅获知企业名称。安全人员随后将看到实际攻击如何发生。
- **双盲测试**：安全人员未被告知攻击。
- **目标测试**：安全人员和测试人员协同工作，互相通报行动。

### 什么是社会工程学？

操纵他人以泄露机密信息被称为社会工程学。攻击者可能寻求任何类型的信息，但主要针对登录凭据和银行信息。

## 社会工程学攻击的表现形式

### 来自朋友的邮件

犯罪分子可以通过社会工程学或黑客手段获取某人的电子邮件密码，从而访问其联系人列表，并可能访问其社交网络联系人。攻击者随后向受害者的联系人发送邮件，或在其社交媒体页面发布消息。

这些消息通常：

- **包含链接**：认为邮件来自朋友，您可能毫不犹豫地点击。这样做会让犯罪分子通过安装恶意软件控制您的计算机。
- **包含下载**：可能是嵌入病毒的图片、文档或视频。

### 来自其他受信任方的邮件

网络钓鱼攻击是一种社会工程学攻击。它模仿受信任方，并以合理的理由诱导您泄露敏感数据或登录凭据。这些消息使用令人信服的借口或故事来：

- 紧急求助：编造悲惨故事并索要钱财。
- 实施网络钓鱼：您可能收到似乎来自您的银行或其他合法来源的邮件或消息。
- 为慈善筹款索要捐款：利用您的善良和慷慨。
- 要求验证您的凭据：包含将您引导至外观逼真的虚假网站的链接。
- 告知您中了彩票或类似奖项：索要个人财务信息以便“汇款”给您。
- 冒充您的同事或老板：可能要求您提供某项目的最新进展，然后索要机密信息。

### 诱饵场景

这些骗局利用人们想要的东西作为诱饵。它们包装成令人惊叹的交易（通常有良好的评价显示卖家可信）。上钩可能导致您失去对计算机的控制，甚至更糟——损失银行账户中的所有资金。

### 对从未提问的查询的回复

攻击者可能假装拥有您提问的解决方案。他们通常冒充数百万人使用的公司。他们将此消息发送给尽可能多的人。不使用该公司服务的人会忽略该消息，但客户很可能会上钩。

### 制造麻烦

这种类型的社会工程学攻击由意图制造破坏的犯罪分子实施。他们入侵受害者的账户（最可能是社交媒体账户）并制造事端。

## 不要成为受害者

### 牢记提示

- 即使消息看似紧急，也要放慢脚步。
- 核实事实。
- 不要点击链接。使用搜索引擎查找真实网站。
- 邮件劫持很常见。
- 避免可疑下载。
- 外国人的馈赠不是真的。

## 如何保护自己

- 删除索要密码和财务信息的请求。
- 忽略求助请求。
- 将垃圾邮件过滤器设置为高级别。
- 保护您的电子设备。

### 第 4 章：反黑客：救世主还是义警？

当新的蠕虫或病毒发起攻击时，系统管理员和用户通常会措手不及。但是，一两年后，系统管理员和用户继续让相同的威胁未被检测到，这可以接受吗？您的 ISP 和互联网上大量的带宽是否应该继续被蠕虫流量和病毒消耗，而这些本可以轻松预防？最近许多蠕虫和病毒的攻击目标是早已有补丁可用的漏洞，甚至早在数月前就已发布补丁。如果管理员和用户能及时修补漏洞，病毒根本不会对其系统构成威胁。另一点是，当出现新威胁时，操作系统和杀毒软件供应商会推出更新和补丁以覆盖漏洞或检测并清除威胁，所有用户都应采取必要措施保护其系统和互联网社区的其他成员。但如果用户无知或选择不采取任何必要行动来遏制威胁，反而传播感染；社区应该做出回应吗？根据许多人的观点，这在伦理和道德上是错误的。这被视为私刑执法。持这一观点的人认为，报复并自行处理问题，在法律上讲，使你与最初的威胁一样糟糕。最近互联网上传播着 W32/Fizzer@MM 蠕虫。一些运营商决定编写代码以自动禁用该蠕虫。这段代码被移除，以便对该策略的合法性进行进一步调查。它应该被合法化吗？在上述情况下，任何未感染的机器都不会受到影响。运营商并没有创建反蠕虫程序，而更像是一种“疫苗”代码，且该代码位于一个已被蠕虫感染的站点上。只有拥有受感染设备的人才会想要连接到该站点。即使这些设备的所有者不知道蠕虫的存在，运营商通过清理他们的设备，仍然是在为他们提供服务，对吧？这种行为可以定义为自卫，但在这种情况下，存在用户甚至不知道自己被感染的情况。当一个无防护的用户被感染时，整个互联网都处于风险之中。虽然这样的用户对其设备拥有主权，但他们对互联网的其他部分没有主权。当用户连接到互联网时，应该有准则约束每一位用户。与现实生活不同，没有互联网警察部队。然而，应该有一个或多个组织拥有制定病毒疫苗或反蠕虫程序的权限。它们将寻找受感染的计算机并尝试清理它们。从道德上讲，入侵某人的计算机以尝试清理它，并不比最初攻击该设备的蠕虫或病毒更糟糕。这是一个滑坡谬误，反黑客行为处于降至恶意开发者水平与合理自卫之间的灰色地带。

### 第 5 章：道德黑客

道德黑客，也称为白帽黑客，是一位 IT 安全专家，拥有与恶意黑客（黑帽黑客）相同的技能组合。他们使用与黑帽黑客相同的技术来揭示公司系统中的弱点和漏洞。恶意黑客在操作前未获得受害者的同意，其目的在于造成破坏、获取名声或牟利。相反，道德黑客受组织委托，入侵该组织的系统，以查明是否存在可被黑帽黑客利用的安全漏洞。人们首次尝试入侵计算机系统是在 20 世纪 60 年代。20 世纪 70 年代，公司和政府组建了“虎队”。他们的工作是寻找计算和电信系统中的任何漏洞——他们是第一批白帽黑客。在 20 世纪 80 年代和 90 年代，更多人拥有了个人计算机，这使得黑客行为成为一种全球现象。“道德黑客”这一术语由 John Patrick 于 1995 年提出。此后，道德黑客成为一种合法职业。

## Certified Ethical Hacker (CEH) Certification

拥有道德黑客认证至关重要。在组织雇佣白帽黑客之前，他们需要确保该黑客技术娴熟，并将技能用于造福公司而非造成损害。认证道德黑客认证由新墨西哥州的一个非营利组织——电子商务委员会 (EC-Council) 定义。该认证使信息安全专业人员合法化，并允许他们被认可为道德黑客。该认证要求极高。它涵盖了众多安全工具、攻击向量和概念，每位学员都必须深入理解。许多组织对其予以认可，其中包括美国国防部和国家安全局 (NSA)。要获得认证黑客资格，学员必须通过 CEH 考试。为准备考试：

- 学员可以参加 EC-Council 提供的 CEH 培训计划。三家认证培训中心包括 Affinity IT Security、Pearson Vue Testing Center 和 EC-Council。
- EC-Council 在其网站上提供 CEH 考试大纲和 CEH 手册。
- 多家机构提供备考课程。
- EC-Council 鼓励考生参加模拟测试。

要参加 CEH 考试，考生必须完成 EC-Council 提供的培训计划，并证明在 5 个领域中至少有 3 个领域的经验。或者，他们需要在信息安全领域拥有两年工作经验。Web 应用程序是黑客的主要目标。由于其复杂的多层架构，它们容易受到攻击。它们还存储敏感数据，且可从外部轻松访问。认证黑客对现代攻击技术、威胁向量和软件系统有广泛的了解。他们可以利用这些知识帮助公司了解其 Web 应用程序的安全状况、威胁等级，以及如何提高安全性。
