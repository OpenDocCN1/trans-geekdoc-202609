
# NeRF 和 3D 高斯泼溅在 3D 场景合成中的应用

本章介绍截至 2023 年底用于 3D 场景合成的最新计算机视觉发展。在第一节中，使用 `MiDaS` 进行图像深度估计。在第二节中，通过 Nvidia Instant NeRF，介绍了神经辐射场的原理，即如何通过光线追踪从一组图像中合成 3D 场景。在最后一节中，使用一个 2D 高斯泼溅程序来介绍 3D 高斯泼溅，通过光栅化实现 3D 场景的实时渲染。

我们正处于一个开发机器学习算法以赋予计算机对世界的 3D 视觉的伟大时代。图像深度估计是计算机视觉中的一项基础任务，它使机器能够从 2D 感知场景的 3D 结构。通过准确提取图像或视频帧上物体的深度信息，计算机可以理解每幅图像上物体的空间布局，并为执行器做出正确决策，从而有效地与环境交互。NeRF（Mildenhall *et al* 2020）和 3D 高斯泼溅（Kerbl *et al* 2023）是从 2D 图像创建 3D 模型的两种不同技术。NeRF 是一种新颖技术，它利用深度学习从一组照片建模 3D 场景。它将场景表示为一个连续的 3D 函数，该函数预测 3D 空间中每个点的颜色和不透明度。NeRF 旨在通过训练神经网络模型从多幅 2D 图像中学习底层场景表示来捕捉复杂的 3D 场景，从而允许合成 3D 场景的新视角。因其能够生成高质量的 3D 重建和场景新视角而广受欢迎。然而，NeRF 合成 3D 场景需要大量计算，速度不足以满足实时项目的需求。一种称为“3D 高斯泼溅”的技术允许我们从一组图像创建照片级真实感的 3D 模型。它通过用数百万个 3D 高斯粒子表示任意场景来工作。每个粒子具有橄榄球形状，其大小和方向由一个具有九个参数的 3D 高斯协方差矩阵决定。每个橄榄球都有自己的 3D 位置坐标、RGB 颜色和不透明度。然后将这些粒子投影到 2D 平面上并混合在一起以创建图像。与其他辐射场方法相比，3D 高斯泼溅具有多项优势，例如更快的训练和渲染、更高的视觉质量、3D 可编辑性以及对空白空间更好的处理。3D 高斯泼溅的一个局限是其模型训练需要大量的 GPU 显存（24 GB）。

## 12.1 使用 MiDaS 进行图像深度估计

传统上，深度估计严重依赖昂贵的硬件，如立体相机。机器学习的出现彻底改变了计算机视觉领域，包括图像深度估计。近年来，研究人员发明了许多图像深度估计技术。一些技术使用监督学习，例如 [MiDaS](https://github.com/isl-org/MiDaS)（Ranftl *et al* 2020），其模型已在 10 个不同的数据集上使用多目标优化进行训练，以确保在广泛输入上的高质量。利用自监督视觉变换器，Facebook 的 `DINOv2` 模型可用于图像分类、实例检索、视频理解以及语义分割和深度估计。

在使用任何复杂的 AI 模型估计图像深度信息之前，我想演示一个简单的项目，该项目使用 `OpenCV`、[cvzone](https://github.com/cvzone/cvzone) 和 [mediapipe](https://google.github.io/mediapipe/) 库来测量你的脸与笔记本电脑摄像头之间的距离。我们还需要一个钥匙扣卷尺进行一些测量以用于校准。我们将笔记本电脑摄像头视为一个焦距为 *f* 的薄透镜。通常，*f* 的值为几毫米，而我脸部到摄像头的物距 *u* 约为 500 毫米。例如，我的手机焦距为 3.5 毫米。在 *u* >> *f* 的条件下，根据图 12.1 所示的薄透镜方程，我们得到物体的像距 ![image](img/bk978-0-7503-6244-3ch12ieqn23.gif) = *f*。如果物体的高度或宽度为 *H*，像的高度或宽度为 *h*，我们有方程 tan(*θ*) = *H*/*u* = *h*/*f*，由此我们得到用于项目 12.1.1 代码中测量物距的公式：

$$u = \frac{f}{h}H.$$
