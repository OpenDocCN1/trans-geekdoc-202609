因此，该熵表达式对树是精确的。然而，对于带环的更一般图，这只能近似成立，称为*贝特熵近似*。图越接近树，近似效果越好；简明的相关介绍见文献[83]。

结果表明，在树的情况下，乘积-求和算法能得到真实的边缘值，因为不涉及近似，且最小化自由能等价于最小化 KL 散度。因此，从这个角度看，乘积-求和算法具有优化的意味。在许多实际情况下，贝特近似足够准确，这解释了有环信念算法在实践中常取得良好性能的原因（见如文献[52]）。有环信念传播算法在有环图中不保证收敛，因此可以选择直接最小化贝特能量代价；尽管这类方案比消息传递慢，但保证收敛（如文献[85]）。

文献[75,77]给出了乘积-求和算法的另一种解释，将其视为适当选取的代价函数的优化算法。在指数族分布的背景下，提供了一个用于精确推理和近似推理的统一框架。均场近似和有环信念传播算法均被考虑在内，并被视为近似可实现均值参数凸集的不同方式，这些参数与相应分布相关。虽然我们不作详细阐述，但将提供一些“略述”，指示该理论发展的核心要点。同时，这也是让我们接触指数族背景下凸对偶、熵、累积生成函数和均值参数等概念之间有趣相互作用的好机会。

指数族（第 12.8.1 节）中的一类概率分布可写为

```
p(x;θ) = C exp(∑_{i∈I} θ_i u_i(x)) = exp(θ^T u(x) - A(θ)),
```

![Equation](img/si166.png)

其中

```
A(θ) = -ln C = ln ∫ exp(θ^(T) u(x)) dx,
```

![Equation](img/si167.png)

对于离散变量，积分变为求和；`A(θ)` 是一个凸函数，称为*对数配分函数*或*累积量生成函数*（问题 16.14, [75,77]）。结果表明，`A(θ)` 的共轭函数，记为 `A*(μ)`，是 `p(x; θ(μ))` 的*负熵*函数，其中 `θ(μ)` 是在给定 `μ` 值时，使共轭函数定义中的最大值成立的 `θ` 值；我们称 `θ(μ)` 和 `μ` 为对偶耦合（问题 16.15）。此外，

```
𝔼[u(x)] = μ,
```

![Equation](img/si172.png)

其中期望是关于 `p(x; θ(μ))` 计算的。这是将 `μ` 解释为均值参数向量的一个有趣视角；回顾第 12.8.1 节，这些均值参数定义了相应的指数分布。然后

```
A(θ) = max_{μ∈M} (θ^T μ - A*(μ)),
```

![Equation](img/si174.png)(16.23)

其中，`M` 是根据公式 (13.78) 中共轭函数的定义，保证 `A*(μ)` 有限的集合。结果表明，在树结构图中，和积算法是求解公式 (16.23) 的拉格朗日对偶形式的一种迭代方案 [75,77]。此外，在这种情况下，集合 `M`（可证明是一个凸集）可以用一种直接的方式显式刻画，并且负熵 `A*(μ)` 具有显式形式。这些性质在含环图中不再成立。均场近似涉及对集合 `M` 的内部近似；因此，它将优化限制在一类有限的分布中，对于这些分布，熵可以精确恢复。另一方面，环路信念传播算法提供了一种外部近似，从而扩大了分布类；熵只能近似恢复，对于成对马尔可夫随机场的情况，这可以采用贝特近似的形式。

前面总结的理论发现已推广到结树的情况，其中势函数涉及两个以上的变量。此类方法涉及所谓的 *Kikuchi* 能量，这是贝特近似的一种推广 [77,84]。这些论点的渊源在于统计物理学 [37]。

*   除了前面介绍的近似技术外，另一类流行的方法是马尔可夫链蒙特卡洛 (MCMC) 框架。此类技术在第 14 章中进行了讨论（另见例如 [25] 及其参考文献）。

## 16.4 动态图模型

迄今为止讨论的所有图模型都是为了满足统计特性随时间保持固定的随机变量的需求而开发的。然而，情况并非总是如此。事实上，*时间自适应* 和 *时变* 术语是本书许多部分的核心。本节的重点是处理统计特性不固定、而是允许发生变化的随机变量。许多时间序列以及顺序获得的数据都属于这一设定，应用范围涵盖信号处理、机器人技术、金融和生物信息学等领域。

与本章前几节讨论的内容相比，一个关键区别在于，现在观测是按顺序感知的，并且它们发生的*特定序列*包含重要信息，任何后续推断任务都必须尊重并利用这些信息。例如，在语音识别中，特征向量产生的顺序非常重要。在典型的语音识别任务中，原始语音数据被*顺序*分割成短（通常重叠）的时间窗口，并从每个窗口获得一个特征向量（例如，相应时隙中样本的 DFT）。这在 图 16.14 中进行了说明。这些特征向量构成了观测序列。除了驻留在这些观测向量具体值中的信息外，观测出现的顺序还揭示了关于所讲单词的重要信息；我们的语言和口语是高度结构化的人类活动。类似的论点也适用于诸如学习和推理生物分子（例如 DNA 和蛋白质）等应用。

![图 16.14 一个语音片段和 N 个时间窗口，每个长度均为 500 ms。显式展示了三个片段，它们分别对应时间区间 [0,500]、[500,1000] 和 [3500,4000]。从每个片段中生成一个相应的特征向量 y。在实践中，允许连续窗口之间重叠。](images/B9780443292385000226/gr014.jpg)

虽然任何类型的图模型都有其动态对应物，但我们将重点关注*动态贝叶斯网络*家族，特别是称为*隐马尔可夫模型*的一种特定类型。

### 状态空间模型用于序列数据

建模序列数据的一种非常流行且有效的框架是通过所谓的*状态-观测*或*状态空间*模型。在时间 `n` 观测到的每组随机变量 `y[n] ∈ ℝ^l`，都与一个相应的未观测（隐含）随机向量 `x[n]` 相关联（其维数不一定与观测值的维数相同）。系统动态通过隐含变量建模，而观测值被视为带有*噪声*的传感设备的输出。所谓的隐马尔可夫模型建立在以下两个独立性假设之上：

(1) `x[n + 1] ⊥ (x[1], …, x[n − 1]) | x[n]`, (16.24)

(2) `y[n] ⊥ (x[1], …, x[n − 1], x[n + 1], …, x[N]) | x[n]`, (16.25)

其中 `N` 是观测总数。第一个条件通过转移模型定义系统动态：

```
p(x[n + 1] | x[1], …, x[n]) = p(x[n + 1] | x[n]), (16.26)
```

第二个条件通过观测模型定义：

```
p(y[n] | x[1], …, x[N]) = p(y[n] | x[n]). (16.27)
```

简而言之，*给定当前，未来独立于过去；给定当前，观测值独立于未来和过去*。

上述独立性通过图 16.15 的图形进行图形化表示。如果隐含变量是离散性质的，则生成的模型称为隐马尔可夫模型。另一方面，如果隐含变量和观测变量均为连续性质，则生成的模型处理起来会相当复杂。然而，对于某些特殊情况，已经开发并可以开发出解析上可处理的工具。在所谓的*线性动态系统*（LDS）中，系统动态和观测值的生成建模为：

```
x[n] = F[n]x[n − 1] + η[n], (16.28)
y[n] = H[n]x[n] + v[n],
```

其中 `η[n]` 和 `v[n]` 是均值为零、相互独立的噪声干扰，由高斯分布建模。这就是著名的卡尔曼滤波器，我们已经在第 4 章中讨论过，并且将在第 17 章中从概率角度进行探讨。公式 (16.28) 和 (16.29) 的概率对应形式为：

```
p(x[n]|x[n − 1]) = N(x[n]|F[n]x[n − 1], Q[n]),
p(y[n]|x[n]) = N(y[n]|H[n]x[n], R[n]),
```

其中 `Q[n]` 和 `R[n]` 分别是 `η[n]` 和 `v[n]` 的协方差矩阵。

## 16.5 隐马尔可夫模型

隐马尔可夫模型由 图 16.15 和公式 (16.26) 及 (16.27) 所示的图模型表示。潜在变量是离散的；因此，我们将*转移*概率写为 `P(x[n]|x[n-1])`，这对应一个概率表。观测变量可以是离散的，也可以是连续的。基本上，HMM 用于建模一种*准平稳*过程，该过程在若干个（例如 `K` 个）子过程中发生*突发*变化。每一个子过程都由不同的统计特性描述。也可以将其视为一个组合系统，包含若干子系统；每个子系统根据不同的统计模型生成数据/观测值；例如，一个可能服从高斯分布，另一个可能服从学生 `t` 分布。观测值由这些子系统发射；然而，一旦接收到观测值，我们并不知道它是由哪个子系统发射的。这让人联想到概率密度函数 (PDF) 的混合建模任务；然而，在混合建模中，我们并不关心观测值出现的顺序。

出于建模目的，我们将每个观测值 `y[n]` 与一个潜在变量 `k[n] = 1, 2, …, K` 相关联，该变量是一个（随机）索引，指示生成相应观测向量的子系统/子过程。我们将其称为*状态*。每个 `k[n]` 对应于通用模型中的 `x[n]`。完整观测集序列 `(y[n], k[n])`，`n = 1, 2, …, N`，在一个二维网格中形成一条轨迹，其中一轴为状态，另一轴为观测值。图 16.16 展示了 `K = 3` 时的情况。这样的路径揭示了每个观测值的来源；`y[1]` 由状态 `k[1] = 1` 发射，`y[2]` 由 `k[2] = 2` 发射，`y[3]` 由 `k[3] = 2` 发射，而 `y[N]` 由 `k[N] = 3` 发射。请注意，每条轨迹都与一个概率分布相关联，即完整集合的联合分布。确实，图 16.16 所示轨迹发生的概率取决于 `P((y[1], k[1]=1), (y[2], k[2]=2), (y[3], k[3]=2), …, (y[N], k[N]=3))` 的值。我们很快就会看到，网格中可以绘制的某些可能轨迹在实践中是不允许的；这可能是由于与相关系统/过程相关的数据生成机制的物理约束所致。

#### HMM 状态转移概率

正如已经所述，隐马尔可夫模型的动态特性用分布 `p(x[n] | x[n-1])` 来描述，对于 HMM 而言，这变为一组概率

```
P(k[n]|k[n-1]),  k[n], k[n-1] = 1, 2, …, K
```

![Equation](img/si210.png)

表示系统在时刻 `n` 从状态 `k[n-1]` “跳转”到状态 `k[n]` 的概率，其中系统在时刻 `n-1` 处于状态 `k[n-1]`。通常，该概率表可能随时间变化。在标准 HMM 形式中，该概率被视为与时间无关，我们称该模型为**齐次**的。因此，我们可以写为：

```
P(k[n]|k[n-1]) = P(i|j) := P_ij,  i, j = 1, 2, …, K
```

![Equation](img/si214.png)

注意，根据建模假设，其中一些转移概率可以为零。图 16.17A 展示了一个三状态系统的示例。该模型属于所谓的**从左到右**类型，允许两种转移：(a) 自转移和 (b) 从低索引状态到高索引状态的转移。系统一旦跳入状态 `k`，便根据概率分布 `p(y|k)` 发射数据，如 图 16.17B 所示。除了从左到右模型，文献 [8,63] 还提出了其他替代方案。状态对应系统的特定物理特征。例如，在语音识别中，建模一个口语单词所选状态的数量取决于该单词内预期的声音现象（音素）数量。通常每个音素使用三到四个状态。另一种建模路径使用语音单词不同版本产生的平均观测数作为状态数的指示。从转移概率角度看，HMM 本质上是一个生成观测序列的随机有限状态自动机。注意，图 16.17 的语义不同于 图 16.15 给出的图形结构，切勿混淆。图 16.17 是状态间转移概率的图形解释，并未涉及相关随机变量间的独立性。一旦采用了状态转移模型，图 16.16 网格图中的某些轨迹将不被允许。在 图 16.18 中，黑色轨迹不符合 图 16.17 的模型。
