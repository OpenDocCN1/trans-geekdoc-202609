
它是保护在线服务和网站免受各种安全威胁的侵害，这些威胁试图利用应用程序代码中的漏洞。内容管理系统（如 `WordPress`）、SaaS 应用程序和数据库管理工具是此类攻击最常见的目标。攻击者总是以 Web 应用程序为目标，因为：

*   它们拥有复杂的源代码，因此很可能存在未被发现的漏洞。
*   一旦成功操纵源代码，攻击者可以获取大量敏感私人信息，获利巨大。
*   攻击易于执行，因为它们可以实现自动化，并一次性不加区分地部署到成千上万个目标上。

未加防护的 Web 应用程序面临更高的被攻击风险。这些攻击的后果包括法律诉讼、许可证被吊销、客户关系受损和信息窃取。漏洞是由缺乏代码清理引起的，攻击者利用这一点来获取访问权限或操纵源代码。这些漏洞允许以下攻击向量：

## SQL 注入

攻击者使用恶意 SQL 代码操纵后端数据库，从而获取信息访问权。随后，他可以非法查看列表、获得管理员访问权限或删除表。

## 跨站脚本攻击 (XSS)

这是一种攻击者以用户为目标的攻击，以便他们可以修改页面内容、激活特洛伊木马或访问账户。

## 远程文件包含

此攻击用于将文件远程注入 Web 应用程序服务器。随后可在应用程序中执行恶意代码或脚本。攻击者还可能窃取或操纵数据。

## 跨站请求伪造 (CSRF)

此攻击可能导致未经授权的资金转移、数据窃取或密码更改。当攻击者使用恶意 Web 应用程序诱导你的浏览器执行非预期操作时，就会发生这种情况。

理论上，彻底的输入/输出清理可以消除所有漏洞，使应用程序免受非法操纵。然而，完全清理在实践中从来都不切实际，因为许多应用程序处于持续开发状态。此外，应用程序之间频繁集成，创造了一个非常复杂的编码环境。

## Web 应用防火墙 (WAF)

`Web 应用防火墙 (WAF)` 是用于缓解应用安全威胁的软件和硬件解决方案。它们旨在评估传入流量并阻断任何攻击尝试。部署 `WAF` 无需更改你的应用程序。`WAF` 使用各种启发式方法来识别可以与应用程序交互的流量以及需要阻断的流量。一个持续更新的签名库让它们能即时识别恶意行为者。大多数 `WAF` 可定制以适应特定的安全场景，并应对任何新出现的威胁。

## 其他安全方法

除了 `WAF`，Web 应用程序还可以使用其他方法进行保护。这些流程必须包含在每个清单中：

*   **信息收集**：手动审查应用程序以了解客户端代码和入口点。
*   **授权**：对应用程序进行路径遍历测试。
*   **加密学**：确保所有数据传输均已加密保护。
*   **拒绝服务**：加强针对拒绝服务威胁的防护。

### 结论

最初，“黑客”一词指的是精通计算机操作系统和机器代码的程序员。如今，它指从事黑客活动的任何人。黑客行为是改变系统特性以达到非创建者原始目的的目标的行为。“黑客”一词通常被负面看待，尤其是那些不了解道德黑客工作的人。在黑客世界里，道德黑客是好人。他们的角色是什么？他们利用自己渊博的计算机知识造福而非作恶。他们寻找组织和企业计算机安全中的漏洞，以防止恶意行为者利用它们。

对于热爱技术和计算机世界的人来说，考虑从事道德黑客职业将是明智之举。你可以通过“入侵”系统获得报酬（且数额可观）。起步并非易事——正如其他任何职业一样。然而，如果你下定决心，你可以迅速跻身于这一利润丰厚的职业。

当你决定踏上这段旅程时，你必须培养耐心。对许多人来说，第一步通常是获得计算机科学学位。你也可以获得 `A+` 认证 (`CompTIA`)，你必须参加并通过两门不同的考试。要参加资格考试，你需要拥有不少于 500 小时的实际计算经验。需要经验，以及 `CCNA` 或 `Network+` 资格来提升你的职业生涯。

一旦获得必要的资格，你就可以进入网络支持的下一阶段。在这一步中，你将进行更新和监控、弱点测试、安装安全程序等工作。你需要网络安全领域的经验，你的目标应该是成为一名网络工程师。凭借网络支持经验，你可以期待开始获得丰厚的薪水。你将不再只是支持网络，而是规划和设计它们。既然你想成为一名道德黑客，你的重点应放在安全方面。努力获得安全认证，如 `TICSA`、`CISSP` 或 `Security+`。信息安全至关重要。

你现在将处于信息安全领域。你的角色将是评估网络和系统安全，并处理任何安全漏洞。在此工作期间，专注于渗透测试并尝试获得 `CEH` (`Certified Ethical Hacker` 认证道德黑客) 认证。作为一名道德黑客，你的主要角色是利用你所有的安全和技术知识尝试突破网络安全。然后，你将提供一份详细的发现报告和改进网络的建议。道德黑客的平均薪资为 71,000 美元（不含奖金），自由职业者收入更高，具体取决于经验或技能。
