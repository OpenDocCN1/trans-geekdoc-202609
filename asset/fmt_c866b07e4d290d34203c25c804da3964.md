
其中 `X[n] = [x[n], x[n-1], ..., x[n-q+1]]`，`y[n] = [y[n], y[n-1], ..., y[n-q+1]]^T`，且 `e[n] = [e[n], e[n-1], ..., e[n-q+1]]^T`，满足 `e[n] = y[n] - x[n]^T \theta[n-1]`。集成员 APA 的随机分析 [34] 确立了其均方误差 (MSE) 性能，该分析通过采用能量守恒论证进行（第 5 章）。

## 8.8 约束学习

在一组约束条件下进行学习，在信号处理和机器学习中普遍具有重要意义。我们已经讨论了多项此类学习任务。第 5 章和第 4 章讨论的波束成形即是典型一例。在第 3 章引入过拟合概念时，我们讨论了正则化的概念，这是对未知参数向量范数进行约束的另一种形式。在其他一些情况下，我们掌握有关未知参数的先验信息；这些额外信息可用一组约束条件给出。

例如，若对图像像素值进行估计，则数值必须为非负。近年来，未知参数向量可能已知为稀疏向量；即其仅有少数分量非零。此时，约束相应的 `ℓ[1]` 范数可显著提高迭代方案求解的精度和收敛速度。显式考虑底层稀疏性的方案称为*稀疏促进*算法。第 10 章将更详细地探讨此类算法。

### 来自 POCS 理论的算法

源自 POCS 理论的算法特别适合以一种优雅、稳健且相对直接的方式处理约束。请注意，每个约束的目标是在解空间中定义一个区域，所需的估计值被“强制”位于该区域内。在本节的其余部分，我们将假设所需的估计值必须满足 *M* 个约束，每个约束定义一个*凸*点集，`C[m]`，`m = 1, 2, …, M`。此外，

```
⋂_{m=1}^{M} C_m ≠ ∅,
```

这意味着这些约束是一致的（也存在可以放宽此条件的方法）。随后可以证明，映射 `T` 定义为

```
T := P[C[m]]…P[C[1]],
```

是一个*强吸引非扩张*映射，(8.25) （例如，文献 [6,7]）。请注意，如果将投影算子的串联替换为它们的凸组合，同样的结论也成立。

在存在一组约束的情况下，算法 8.2 中的 APSM 唯一的区别在于，更新递推公式 (8.39) 现在被以下公式取代：

```
θ_n = T( θ_{n-1} + μ_n( ∑_{k=n-q+1}^{n} ω_k P_{S_{ε,k}}(θ_{n-1}) - θ_{n-1} ) ).
```(8.44)

换句话说，对于 *M* 个约束，必须执行 *M* 次额外的投影操作。同样的情况也适用于公式 (8.38)，区别在于括号内的求和项。

### 备注 8.6

*   APSM 的约束形式已成功应用于波束成形任务，特别是在处理非平凡约束方面，这正是鲁棒波束成形所要求的 [77,80,103,104]。它也已被高效地用于稀疏感知学习（例如，[47,83]；另见第 10 章）。相关技术的更详细综述见文献 [89]。

### 组合后自适应扩散 APSM

目标是计算一个位于所有这些集合交集中的点，其中 `n = 1, 2, …`。遵循与扩散 LMS 类似的推理，得到了**算法 8.3**中给出的组合后自适应版本的 APSM。

#### 算法 8.3：组合后自适应扩散 APSM

##### 初始化

1. **对于** `k = 1, 2, …, K`，**执行**
   * `θ_k(0) = 0 ∈ ℝ^l`；或任何其他值。
2. **结束循环**
3. 选择 `A`：`A^T 1 = 1`
4. 选择 `q`：每个时间瞬间处理的性质集合的数量。

##### 主循环

**对于** `n = 1, 2, …, q − 1`，**执行**；初始阶段，即 `n < q`。

1. **对于** `k = 1, 2, …, K`，**执行**
   * `ψ_k(n − 1) = ∑_{m ∈ N_k} a_{mk} θ_m(n − 1)`；`N_k` 是节点 `k` 的邻域。
2. **结束循环**
3. **对于** `k = 1, 2, …, K`，**执行**
   * 选择 `ω_1, …, ω_n`：`∑_{j=1}^n ω_j = 1, ω_j > 0`
   * 选择 `μ_k(n) ∈ (0, 2M_k(n))`。
   * `θ_k(n) = ψ_k(n - 1) + μ_k(n)( ∑_{j = 1}^{n}ω_j P_{S_{ε,j}^{(k)}}( ψ_k(n - 1) ) - ψ_k(n - 1) )`
4. **结束循环**

**对于** `n = q, q + 1 …`，**执行**

1. **对于** `k = 1, 2, …, K`，**执行**
   * `ψ_k(n − 1) = ∑_{m ∈ N_k} a_{mk} θ_m(n − 1)`
2. **结束循环**
3. **对于** `k = 1, 2, …, K`，**执行**
   * 选择 `ω_n, …, ω_{n - q + 1}`：`∑_{j = n - q + 1}^{n}ω_j = 1, ω_j > 0`。
   * 选择 `μ_k(n) ∈ (0, 2M_k(n))`。
   * `θ_k(n) = ψ_k(n - 1) + μ_k(n)( ∑_{j = n - q + 1}^{n}ω_j P_{S_{ε,j}^{(k)}}( ψ_k(n - 1) ) - ψ_k(n - 1) )`
4. **结束循环**

参数序列 `Mk` 定义如下：

$$
M_{k}(n) = \sum\limits_{j = n - q + 1}^{n}\frac{\omega_{j}\left\| P_{S_{\epsilon,j}^{(k)}}\left( \mathbf{\psi}_{k}(n - 1) \right) - \mathbf{\psi}_{k}(n - 1) \right\|^{2}}{\left\| \sum_{j = n - q + 1}^{n}\omega_{j}P_{S_{\epsilon,j}^{(k)}}\left( \mathbf{\psi}_{k}(n - 1) \right) - \mathbf{\psi}_{k}(n - 1) \right\|^{2}},
$$

初始周期同理定义。

### 备注 8.7

*   基于 APSM 的扩散算法的一个重要理论性质是它们具有 **asymptotic consensus**（渐近一致性）。换句话说，节点会渐近地收敛到 **相同的** 估计值。这种渐近一致性不是均值意义上的，这与 diffusion LMS 的情况不同。这很有趣，因为没有采用显式的一致性约束。
*   在文献[22]中，组合步骤之后、适应步骤之前使用了一个额外的投影步骤。该额外步骤的目标是“协调”局部信息——包括输入/输出观测值——与来自邻域的信息，即从邻居节点获得的估计值。这能加快收敛速度，代价仅为增加一次投影。
*   文献[22]还处理了部分节点受损且相关观测值噪声极大的场景。为应对该场景，APSM 算法不再基于超平板，而是围绕 Huber 损失函数重新表述，该函数是在鲁棒统计背景下发展起来的，用于处理存在离群值的情况（另见第 11 章）。

## 8.10 优化非光滑凸损失函数

在存在一组约束的情况下，利用凸损失函数估计参数是优化领域一个成熟且研究深入的领域，在广泛的学科中有众多应用。主流方法遵循拉格朗日乘子法 [11,15] 的思想，或所谓*内点法* [15,90] 的基本原理。在本节中，我们将关注一条替代路径，考虑迭代方案，这些方案可视为第 5 章讨论的梯度下降法的推广。原因在于，此类技术衍生出的变体能很好地随维度缩放，并启发了许多算法，这些算法被机器学习界建议用于在线学习。稍后，我们将转向建立在所谓*算子/映射*和*不动点*理论框架之上的更高级技术。

尽管我们的讨论舞台设定在欧几里得空间 `ℝ^(l)`，但一切所述均可推广到无限维希尔伯特空间；我们将在第 11 章中考虑此类情况。
