
# 聚类分析概述

## 杰卡德距离

杰卡德距离是两个集合之间差异性的度量。它定义为集合并集与交集大小之差与并集大小之比。

表 13.3 层次聚类与划分聚类的区别

| 层次聚类 | 划分聚类 |
| --- | --- |
| 1. **层次结构**：层次聚类通过根据相似性或距离度量迭代地合并或分裂簇，从而创建一个层层嵌套的簇结构。 | 1. **固定的簇数量**：划分聚类方法（如 `k-means` 或 `k-medoids`）需要提前指定簇的数量。 |
| 2. **凝聚与分裂型**：它可以是凝聚的（从每个数据点作为单独的簇开始，并将它们合并在一起），也可以是分裂的（从一个单一簇开始并将其拆分为更小的簇）。 | 2. **非层次性**：划分聚类不创建簇的层次结构。它根据预定义的标准将每个数据点分配给某一个且仅一个簇。 |
| 3. **簇的数量**：层次聚类不需要提前指定簇的数量。它产生一个具有不同粒度的层次结构，允许用户根据自己的需求选择簇的数量。 | 3. **目标函数优化**：划分方法旨在优化目标函数，例如最小化簇内方差或最大化簇间差异性。 |
| 4. **簇的表示**：层次聚类的结果可以使用树图（dendrograms）进行可视化，树图展示了簇的层次结构以及它们合并时的距离。 | 4. **速度**：划分算法通常比层次聚类快，特别是对于大型数据集，因为它们不需要对所有数据点进行两两距离计算。 |
| 5. **计算开销大**：层次聚类的计算开销可能很大，特别是对于大型数据集，因为它需要计算所有数据点之间的两两距离或相似性。 | 5. **对初始化敏感**：划分方法中簇质心的初始选择会显著影响最终的聚类结果，使得它们对初始化敏感。 |
| 6. **噪声数据处理**：该算法对数据中的噪声和离群值具有鲁棒性，因为它不依赖于全局优化准则，而是依赖于局部相似性。 | 6. **离群值处理困难**：划分方法对离群值敏感，因为它们试图优化全局准则。离群值会影响簇中心并扭曲结果的簇。 |

# 层次聚类

![](img/icon_4.jpg)层次聚类将数据点分组成层次结构化的簇。它创建了一种名为树图（dendrogram）的树形结构，代表了不同相似性水平上的嵌套簇。层次聚类是一种更灵活的方法，因为它不需要我们预先确定簇的数量。

## 树图

树图是层次聚类的一部分。它是层次聚类过程的可视化表示，其中数据点根据其相似性连续合并成簇。树图中的每一步都显示了通过合并两个现有簇或单个数据点形成了一个新簇。

为了帮助你理解树图的工作原理以及如何解释图表，我提供了一个简单的示例。假设我们有一个六个数据点的数据集：A、B、C、D、E 和 F。要使用层次聚类创建树图，我们首先将每个数据点视为单独的簇。然后，我们根据距离度量（例如 `Euclidean distance`）迭代地合并最近的簇，直到所有数据点都在一个最终簇中。图 13.4 显示了该示例的树图。

![图 13.4 树图示例。](img/fig13_4.jpg)

图 13.4 树图示例。

* A 和 B 形成簇 `[A, B]`。
* E 和 F 形成簇 `[E, F]`。
* 簇 `[E, F]` 与 D 合并形成簇 `[D, [E, F]]`。
* 簇 `[D, [E, F]]` 与 C 合并形成簇 `[C, [D, [E, F]]]`。
* 所有数据点现在属于同一个簇。

如你所见，树图允许我们直观地检查数据是如何连续合并成簇的。它创建了一个簇的层次结构，且簇是嵌套并组织成树的形式的。

层次聚类有两种主要类型，如下：

1. **凝聚聚类（自底而上）**：凝聚聚类从每个数据点作为一个单独的簇开始，迭代地合并最相似的簇，直到所有数据点属于同一个簇。在每一步中，算法根据选定的距离度量识别最近的一对簇并合并它们。这个过程一直持续到所有数据点在一个簇中（图 13.5）。
2. **分裂聚类（自顶而下）**：分裂聚类采取相反的方法。它从所有数据点在一个簇开始，递归地将簇拆分为更小、更不同的簇，直到每个数据点都有自己的簇。在每一步中，算法识别出最相似的簇并根据选定的距离度量将其划分为两个新簇。这个过程一直持续直到每个数据点形成一个单独的簇（图 13.6）。

![图 13.5 凝聚聚类（自底而上）。](img/fig13_5.jpg)

图 13.5 凝聚聚类（自底而上）。

![图 13.6 分裂聚类（自顶而下）。](img/fig13_6.jpg)

图 13.6 分裂聚类（自顶而下）。

距离度量的选择在层次聚类中起着至关重要的作用。连接准则（linkage criterion）决定了在合并或分裂过程中如何计算簇之间的距离。常见的连接方法包括单链、全链和平均链。稍后介绍不同的距离测量。

层次聚类有几个优点。它可以通过形成簇的层次结构来揭示数据内在的结构和关系。树图提供了聚类过程的可视化表示，易于解释。层次聚类还能处理各种类型的数据，包括数值型、分类和二进制数据。

然而，层次聚类的计算开销可能很大，特别是对于大型数据集，因为需要进行两两距离计算。此外，距离度量的选择、连接准则以及树图的解释可能会根据数据和应用而异。

# 划分聚类

![](img/icon_4.jpg)划分聚类（也称为分区聚类）是一种聚类算法，旨在将数据集划分为互不重叠的簇。与创建簇层次结构的层次聚类不同，划分聚类直接将每个数据点分配给特定的簇。目标是优化预定义的目标函数，例如最小化簇内距离并最大化簇间距离。

最著名的划分聚类算法之一是 `k-means`。`k-means` 方法通过迭代更新簇质心并将数据点分配给最近的质心，将数据划分为 `K` 个不同的簇。算法迭代地分配数据点并调整簇质心，直到收敛。目标是最小化数据点与其相应簇质心之间的距离平方和。

`k-means` 聚类算法包括以下步骤。

1. **初始化**：选择聚类数量 `K`，并在数据范围内随机初始化 `K` 个质心。
2. **分配**：根据距离度量（通常是欧几里得距离）将每个数据点分配给最近的质心。这一步创建了 `K` 个聚类。
3. **更新**：通过计算分配到该簇的所有数据点的平均值，重新计算每个聚类的质心。
4. **迭代**：重复步骤 `2` 和 `3` 直到收敛。当质心不再发生显著变化或达到预设的最大迭代次数时，即发生收敛。
5. **结果**：一旦算法收敛，每个数据点都属于特定的聚类，聚类质心代表每个聚类的中心。

K-means 是一种简单且高效的算法，但其成功取决于质心的初始选择和聚类数量（`K`）。聚类数量 `K` 的选择通常基于领域知识，或使用肘部法、轮廓系数分析等技术来确定最佳聚类数。因此，可以使用不同的初始化多次运行算法，并选择误差最低的聚类结果。

K-means 聚类对于大型数据集具有很高的效率和可扩展性。然而，它也有一些局限性。首先，它假设聚类是球形的，且每个数据点只属于一个聚类。它对初始质心位置也敏感，这会导致不同的初始化产生不同的结果。

# 两步聚类分析

两步聚类分析算法是聚类分析中的一种常用策略。它结合了层次聚类和 k-means 聚类的元素来执行分析。它在处理大型数据集或具有混合变量类型（连续型和分类）的数据集时特别有用。

该过程涉及以下两个主要步骤：

1. **预聚类**：在第一步中，使用层次聚类算法（如凝聚聚类）创建一个初步的聚类方案。这一预聚类步骤有助于识别潜在的簇，并降低大型数据集的计算复杂度。
2. **两步聚类**：在这一步中，算法将 k-means 聚类算法应用于预聚类数据。k-means 算法根据案例与质心之间的距离迭代地将案例分配到簇中。每次迭代中都会重新计算质心，直到实现收敛。

## 两步聚类分析的优势

* **适用于大型数据集**：两步聚类分析在处理大型数据集时高效且具有可扩展性。
* **自动确定聚类数量**：该技术根据统计标准自动确定最佳聚类数量，减轻了我们预先指定聚类数量的负担。
* **处理混合数据类型**：两步聚类分析可以处理分类变量和连续变量，适用于具有不同类型变量的数据集。

## 两步聚类分析的局限性

* **对离群值敏感**：与其他聚类算法一样，两步聚类分析对离群值敏感，这可能会影响聚类结果。
* **依赖预定义的距离度量**：算法假设数据点之间的相似性可以使用预定义的距离度量来衡量，但这可能无法始终准确捕捉到数据的底层结构。
* **缺乏可解释性**：生成的聚类并不总是具有清晰且易于解释的含义，需要进一步的分析和验证。

![](img/ufig13_4.jpg) 总体而言，两步聚类分析是数据挖掘项目的一种有用方法，因为它能很好地处理具有不同类型变量的大数据。此外，聚类数量的自动确定提高了过程的效率。

# 在 SAS Enterprise Miner 中聚类分析

![](img/icon_9.jpg) 在 SAS Enterprise Miner 中，聚类分析列在“探索”（Explore）组而不是“模型”（Model）组。这是因为在数据挖掘中，聚类分析通常被用于探索数据。

SAS Enterprise Miner 为聚类分析提供了两个不同的节点：模型组中的 `Cluster` 节点和 HPDM 组中的 `HP Cluster` 节点。SAS Enterprise Miner 预配置了聚类分析步骤，因此我们不需要执行聚类分析过程中的每一个步骤。与要求用户手动执行所有步骤的传统统计软件相比，这是一个巨大的优势。这个内置工具使得运行聚类分析的过程变得更容易，但也降低了我们在分析过程中的控制能力。请记住，SAS Enterprise Miner 使用两步聚类算法，并且对配置的更改非常有限。我将向你展示 SAS Enterprise Miner 中可以更改的一些配置。

## 两步聚类算法

SAS Enterprise Miner 有一个内置的两步聚类算法，描述如下：

* 步骤 1：使用层次聚类自动寻找聚类数量。使用立方聚类标准（`CCC`）来确定聚类数量。
* 步骤 2：使用 k-means 聚类根据距离度量将对象分配到簇中。

## 距离度量

SAS Enterprise Miner 未提供之前描述的所有距离度量。虽然有些人可能认为这是一个缺点，但另一些人可能认为优点，因为我们不需要花费时间选择正确的度量。软件提供了两种常用的距离度量，如下：

* `Cluster` 节点：欧几里得距离（Euclidean distance）。
* `HP Cluster` 节点：欧几里得距离或曼哈顿距离（Manhattan distance）。

## 缺失值处理

SAS Enterprise Miner 有一个内置的缺失值工具来处理缺失值。它提供了几种选项，包括 `Default`（默认）、`Ignore`（忽略）、`Mean`（平均值）、`Midrange`（中位范围）或 `Omit`（省略）。这个工具使我们更容易处理缺失值，因为我们不需要插补缺失值。

## 数据标准化

SAS Enterprise Miner 还有一个内置的数据标准化工具，有助于解决离群值带来的任何问题。它提供了多种选项，包括 `None`（无）、`Standardization`（标准化，默认值）和 `Range`（范围）。
