##### 6.1.4.1 在 ReRAM 交叉阵列网络上映射矩阵-向量乘法

随着二值忆阻器交叉阵列网络的引入，可以执行矩阵-向量乘法[147]。与多电平模拟忆阻器交叉阵列相比，它在工艺变异下具有更好的非均匀性。正如第 6.1.2 节所讨论的，机器学习中的关键操作（特征提取和卷积）需要大量的矩阵-向量乘法。

如前所述，关键操作(6.13)和(6.14)需要大量的矩阵-向量乘法。例如，以`W`为例说明在交叉阵列上的乘法映射。对于`W`中的每个元素，遵循以下关系，这里我们以`W * x`的操作为例说明在交叉阵列上的乘法映射。对于`W`中的每个元素，遵循

```
y_i = Σ_j W_ij * x_j
```

其中`W_ij`和`x_j`分别是`W`和`x`中的元素。

对于图 6.4 中的交叉阵列结构，流过每条位线(BL)的电流遵循

```
I_BL_i = Σ_j G_ij * V_WL_j
```

因此，我们可以将`W`和`x`分别映射到`G`和`V`上。通过使用二进制数字化测量流过 BL 的电流，可以在数字域中得出结果`y`。详细操作可参考文献[147]中的工作。

注意，对于实数，只需进行几次移位加法即可完成利用忆阻器交叉阵列进行矩阵-向量乘法的最终过程。图 6.5 表明，我们只需采用 8 位精度的四次移位加法即可计算最终的内积。此外，Sigmoid 函数可以通过查找表(LUT)在忆阻器交叉阵列中实现。

##### 6.1.4.2 在耦合 ReRAM 振荡器网络上映射 L2 范数计算

在耦合振荡器网络中，我们使用类似于图 3.15(a)所示的忆阻器振荡器单元（Rs 替换为 PMOS）。通过改变 PMOS 的栅极电压，可以如图 3.15(d)所示控制振荡频率。参考前人工作[209, 210]，提出的耦合忆阻器振荡器网络如图 5.8(a)所示。此处，振荡器通过忆阻器直接耦合。每个振荡器的振荡频率由多个输入电压决定。如图 3.15(d)所述，电压控制 PMOS 可视为电压控制电阻。图 5.8(b)和 5.8(c)分别是单输入和多输入振荡器的原理图。直接耦合后，可以获得一个反相器和一个二极管连接的 NMOS 反馈电阻。这些元件保证电流仅从振荡器网络流向`V_out`。在`V_out`处设计了一个 RC 电路，以便测量`V_out`的直流电压。输出电压指示耦合振荡器的相对同步程度。

为了在振荡器网络上执行(4.14)，我们只需为图 5.8(c)中的每个振荡器使用两个输入。更具体地说，可以有如下映射函数：

```
V_in_i = α * (W_ij + x_j)
```

其中`α`是将振荡器输入电压关联起来的比例因子，`W_ij`和`x_j`分别是矩阵`W`和`x`中的元素。

正如文献[209, 210]所述，当图 5.8(c)中每个振荡器有两个输入时，耦合振荡器网络可以作为匹配度(DOM)电路工作，通过将`V_out`拟合为`a * V_in² + b * V_in + c`多项式来计算 L2 范数。因此，输出电压遵循

```
V_out = k * ||W - x||² + V_offset
```

其中`k`是拟合参数，`V_offset`是`W = x`时的输出电压。

因此，可以利用耦合忆阻器振荡器网络实现机器学习中的 L2 范数误差函数。L2 范数结果是通过曲线拟合而非精确计算获得的。与其他实现相比，这种振荡器网络能以快得多的速度完成运算，因为平方运算`(W_ij - x_j)²`可以由振荡器电路同时执行。此外，累加也由耦合网络自动实现。
