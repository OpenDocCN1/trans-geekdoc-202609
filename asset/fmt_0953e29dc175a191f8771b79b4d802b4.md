## 2.1 引言

机器学习（ML）应用在数字时代无处不在。机器学习方法因为其解决复杂问题和从海量数据提供决策支持系统的能力而备受关注。各种编程语言（例如 Python, R, MATLAB）提供了不同的机器学习方法软件包。大量的资源和出版物讨论了机器学习方法的理论框架以及软件模块在各种平台上的实际用法。然而，据我们所知，还没有关于机器学习方法的概念、机制以及算法内部中间操作序列的可运行代码的资源。机器学习方法通常以“黑箱”产品的形式呈现，无法提供对其机制的深入见解，也不允许根据用户需求进行修改。从基本原理开发机器学习算法始终是理想的，特别是使用开源免费软件，以适应用户的拟合和分析需求。因此，建议关注这两种常见的机器学习方法，并使用开放的 R 软件开发可运行代码以展示其应用。

在成功应用机器学习的领域，现代农业是产生大量数据的部门之一，来自产量监测器、土壤和肥料设备等。

Dey 等人（2019年）包含了农业领域（Liakos 等人，2018年；Zhou 等人，2019年）。这些示例的共同主题是丰富数据集可用性。

机器学习（ML）的一些成功应用包括作物产量预测（Lów 等人，2018年）、投入量化（Tantlaki 等人，2019年）、物候学和作物健康监测（Behmaman 等人，2015年）、杂草分类与定位（dos Santos Ferreira 等人，2017年）、动物行为与健康监测（Borchers 等人，2017年）以及植物疾病分类（Ferentinos，2018年）。

这些应用大部分使用了在多种编程语言中以黑箱模块形式提供的适用于不同机器学习方法的软件包，例如 Scikit-learn 和 TensorFlow（Pedrosa 等人，2011年；Abadi 等人，2015年；Sarkar 等人，2018年）；R语言中的 nnet 和 caret（Ramasubramanian and Singh，2017年；Kuhn，2019年）；以及 MATLAB 中的 Statistic and ML 工具箱（Martinez and Martinez，2015年）。所有的软件包对于训练、开发和测试机器学习模型都是非常用的，但它们各有优缺点。Python 和 R（R Core Team，2019年）在工业界更受青睐，因为它们免费、开源且跨平台；而 MATLAB 作为商业软件，需要年度订阅，通常在学术界使用。

在机器学习的农业应用中，害虫识别和杂草物种正在被解决。对于这些农业应用，开发的机器学习软件包经过了适配和测试，但仍然缺乏可靠的解决方案。这可能是由于缺乏相关资源来帮助农业研究人员理解机器学习方法的机制。在这方面有更清晰的认识将有助于定制方法以适应特定的农业应用。因此，本章侧重于处理农田现场数据示例，并对用户开发、解码的常用机器学习方法的应用进行概述。特别是在农业领域，本章可能会将一些研究人员简单的“应用型”思维变为“开发型”思维。这种影响将有助于为其他特定的农业问题开发解决方案，而不限于上述常见的应用。

### 2.3.1 整体机器学习模型开发流程

本章概述了解码机器学习模型开发的整体处理阶段（图 2.1），并在随后进行了描述。该过程所需的数据生成自从识别和分类的不同农业应用（豆蚜和杂草物种）获取的数字图像。机器学习模型的实际输入数据需要是结构化格式（具有相同的数据类型特征）并提取数据（Rasband，2019年；Shindelin 等人，2012年）。ImageJ 是一种开源、基于 Java 且免费的图像处理软件，允许插件形式开发特定任务和用户代码应用程序（Igathinane 等人，2009年）。ImageJ 还支持其他几种语言的插件开发（例如 JavaScript、Python、Ruby、Clojure、Scala）。原始图像使用 ImageJ 的阈值方法进行预处理，以获得用于进一步处理的二值图像。ImageJ 提供了二值图像的多种测量（特征）选项，例如对象面积、长轴和短轴、边界框的宽度和高度以及 Feret 维度等。这些基础测量可以用于导出额外的形状特征，以满足不同应用的需求（Iginathanine 等人，2008年；Sunoy 等人，2017年，2018年；Du and Sun，2004年）。

评估过的形状特征使用 R（一种开源免费的统计软件，R Core Team，2019年）进行处理。开发了一个用户代码 R 程序来处理数据并基于线性判别分析（LDA）和 k-最近邻（kNN）算法构建机器学习模型（图 2.1）。初始数据处理包括数据清洗、特征选择以及将数据集分为训练集和测试集。机器学习模型是通过运行在机器学习算法内部的各种中间过程开发的。根据模型性能和处理所需的时间，将用户代码模型的结果与来自可用 R 包的黑箱模型进行了比较。

在本章中，我们使用以下数据集：(i) 尾花（iris），(ii) 豆蚜和 (iii) 杂草种子。尾花数据集用于不同机器学习分类方法的演示和解码，而另外两个数据集用于展示机器学习分类方法在农田应用中的应用。

随后将讨论每个数据集的简要描述以及获取特征的过程。

尾花是数据分析中广为人知的多变量数据集，由 Fisher（1936年）引入以演示 LDA。由于尾花数据集在最近的文献中广泛用于展示和测试分类方法（Kamaralaz and Abdullah，2019年；Singh and Srivastava，2019年；Bai 等人，2019年），本研究也采用了此类数据集来评估解码的 LDA 和 KNN 算法的性能。尾花数据集包含来自三种尾花品种（setosa、versicolor 和 virginica）的 150 个观测值。每个数据点由四个特征（单位 cm）组成，如花萼长、花萼宽、瓣长和瓣宽。该数据集预装在 R 软件命令中，可以使用 `data(iris)` 命令导入。

$$Aspect ratio = \frac{a}{b} (2.1)$$

$$Circularity = \frac{4\pi A}{P^2} (2.2)$$

$$Roundness = \frac{4}{\pi} (2.3)$$

$$Solidity = \frac{A}{H} (2.4)$$

$$Reciprocal = \frac{b}{a} (2.5)$$

$$Rectangularity = \frac{A}{P} (2.6)$$

$$Diameter = \frac{P}{\pi} (2.7)$$

$$Eccentricity = \sqrt{1 - \frac{b^2}{a^2}} (2.8)$$

$$Area = \frac{P^2} (2.9)$$

$$Hollowness = 1 - \frac{A}{H} (2.10)$$

$$Ratio = \frac{A}{W} (2.11)$$

$$Shape = \frac{A}{L} (2.12)$$

$$Value = \frac{A}{C} (2.13)$$

清洗数据集至关重要，因为 ML 模型对噪声、离群值和不数据敏感（Chu 等人，2016）。平均而言，约 60% 的时间花在清洗、过滤和编辑数据上，以便更容易进行探索、理解和建模。

常见步骤包括：

- 检查缺失值。

- 替换缺失值。

- 忽略不完整的记录。

- 将数据类型修改为格式。

在 R 中，使用 `is.na()` 和 `is.nan()` 检查缺失值的存在。如果存在，用户可以选择用指定值替换数据，或使用 `na.omit()` 将其忽略。数据清洗后，最好使用 `as.numeric()`、`as.integer()`、`as.character()` 或 `as.factor()` 转换数据类型。

用于 ML 建模的数据由特征（预测变量）和结果（因变量）组成。大部分特征是相关的，其余是不相关的。使用所有可用特征开发 ML 模型会导致计算负担和准确性下降。因此，必须仔细识别并选择相关特征以建立模型，同时排除其他特征。特征选择经常与降维混淆。两种方法都试图减少数据集中特征或属性的数量。然而，降维通过创建所有特征的新组合来实现（Das 等，2020a），而特征选择方法则筛选预测结果用处较小的无关特征。通常，相关特征越少越好，因为它们能产生更简单、更具效益的模型。特征选择方法可以分为三类：过滤、包装和嵌入方法。

过滤方法为数据集中的每个特征分配分数。根据分数对特征排序，这意味着输出变量的顺序。根据排名选择或丢弃特征。过滤方法的示例包括信息增益（Joachims，1998）、卡方检验（Jin 等人，2006）和 Relief（Kira 和 Rendell，1992）。

包装方法使用内置的 ML 分类和回归算法，根据如下方法创建特征子集

前向或后向选择以及启发式选择。这些选定的特征被交给预测模型算法，并根据模型的准确率为特征子集分配分数。同样，对每个特征子集进行分析，选择产生模型准确率最高的一个。包装方法的一个示例是前向选择和后向选择算法（Mao, 2004）。
