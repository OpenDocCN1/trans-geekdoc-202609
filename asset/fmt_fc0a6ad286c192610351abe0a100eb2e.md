
某些数据修改技术（如 `imputation` 或 `transformation`）依赖于对数据分布或关系的某些假设。如果违反了这些假设，修改后的数据可能无法准确表示底层模式，导致结果产生偏差。

在特定项目和数据集的背景下，仔细考虑数据修改技术的优缺点至关重要。技术的选择应该根据研究目的、分析的要求和局限性，以及对数据特征的深入理解来指导。

## 替换

![](img/icon_9.jpg)如前所述，替换是一种数据清洗的有用数据修改技术。我们可以通过为某些变量重新分配值，来移除数据集中的错误信息或纠正错误，从而确保数据的准确性。SAS Enterprise Miner 有一个用于此工具的专用节点。我在下面列出了一些我们必须使用 `Replacement` 节点来清理数据的典型场景。

*   ![](img/ufig5_3.jpg) **删除错误信息**：我们倾向于假设收集到的数据总是正确的。然而，你可能会惊讶地发现，由于数据采集工具的缺陷、数据采集过程或参与者的输入错误，数据集往往包含错误。我们可以在探索步骤中，通过使用变量的可视化和描述性统计来检查数据，从而检测这些错误，如第 4 章所示。例如，当在使用直方图探索年龄数据时，我们注意到有一些年龄为零的情况。显然，这些是错误信息，因为年龄不能为零。同样，尽管数据描述明确指出只调查了成年人，我们仍可能看到年龄小于 18 岁的情况。出现这种情况有几个原因：首先，参与者错误输入的年龄信息，导致其无法用于分析；其次，这是一个缺失值（参与者决定留白），被软件或问卷工具编码为零。无论何种情况，我们都应该将这些值视为缺失值而非零，以避免误读数据。使用 `Replacement` 节点，我们可以移除错误信息，软件将把这些值视为缺失数据。

*   **纠正错误**：在某些情况下，当错误信息非常明显时，我们可以对数据集进行纠正。例如，在使用直方图探索收入信息时，我们发现了几个薪资为负的情况。假设在检查问卷后，我们发现薪资在本应为正数时被错误地输入为负值。这种错误信息会导致建模步骤出现错误的预测。在这种情况下，我们可以使用 `Replacement` 节点通过删除负号来纠正错误。另一个例子是分类变量中出现的拼写错误，这创建了几个新级别并导致了误导信息。例如，由于拼写错误，职位名称“Manaer”应该与“Manager”视为相同，但软件认为它们是两个类别。使用 `Replacement` 节点，我们可以对此类数据进行纠正。

*   **重新分配值**：`Replacement` 节点的一个常见应用是重新分配缺失值。你可能会惊讶地发现，数据提供者对缺失值的编码方式非常不同，取决于他们收集数据的方式或用于存档数据的标准。我见过缺失值被编码为空白、零或 9。这些都是可以使用 `Replacement` 节点清理数据的典型场景。

## 缺失值插补

![](img/icon_9.jpg)在数据挖掘中，缺失值是指某些变量数据的缺失或缺乏。缺失值可能由于多种原因产生，例如数据错误、数据不完整。根据数据集的不同，缺失值可以用不同的方式表示：

*   空白单元格：在大多数数据集中，缺失值通常由空白单元格表示。这些单元格对于相应的变量没有值或信息。
*   Null 或 NA 值：某些数据集使用特定的代码或标记（如 `null` 或 `NA`）来指示缺失值。这些代码通常被分配用于数据的缺失。
*   占位符值：在某些情况下，缺失值可能使用与有效值不同的占位符值表示。例如，使用 `-1` 或 `9999` 来表示数值变量中的缺失值。SAS Enterprise Miner 使用 `.` 来表示缺失值。

为了缓解这些问题，必须应用适当的技术来处理缺失值，例如插补（用估计值替换缺失值）或排除（删除缺失率过高的观测值或变量）。技术的选择取决于特定数据集、缺失数据的性质以及项目目的。可以使用 `Replacement` 节点来删除缺失值。挑战在于决定删除操作是否会导致预测建模中出现任何服务器端问题。我将重点介绍插补，这是处理缺失值最常用的策略。

![](img/ufig5_6.jpg)

基本上，插补是一个使用估计值对数据集中的缺失值进行估计或填充的过程。这是一种用于处理具有缺失值数据的技术，确保数据集在进行进一步分析之前是完整的。插补方法有很多种。当我们决定用用（或选择）插补方法时，有以下几个重要的考虑因素。

- 插补方法的选择应由数据集的特征、缺失数据的性质和分析目的来指导。不同的方法有不同的假设，并可能导致不同的结果。
- 插补会给数据集引入不确定性，因为填充的值是基于可用数据估算的。在执行后续建模时，考虑到这种不确定性至关重要。
- 实施插补时应谨慎，因为如果缺失数据不是完全随机的，可能会引入偏倚。这意味着数据背后可能有某些特定原因，使其成为系统性缺失而非随机缺失。理解数据缺失的原因并考虑插补值中的潜在偏倚至关重要。
- 记录插补过程是一个良好的做法，包括所使用的方法和所做的任何假设，以确保分析的透明和可重复性。

![](img/ufig5_7.jpg)总体而言，插补是数据修改中广泛使用的技术，用于处理缺失值并确保数据集的完整性。插补方法的选择应该根据缺失数据的特征和分析目的进行仔细考虑。理解与插补相关的局限性和潜在偏倚非常重要。表 5.2 显示了一些常见的插补方法及其特征。对于每种方法，我包含了简要描述、假设、插补值是如何计算的以及我们何时可以使用这种方法。你不需要担心计算这些值，因为软件会自动完成这项任务。但我们需要知道何时使用哪种方法。注意，这些方法主要用于区间尺度变量，因为它们需要定量计算。由于分类变量的非度量性质，分类变量的插补方法非常有限。

### 表 5.2 常见插补方法

| 插补方法 | 描述 | 使用时机 |
| --- | --- | --- |
| 均值 | 用可用值的平均值替换缺失值。假设缺失值与观测值的平均值相似。`Imputed value = Mean (available data)` | 用于区间变量。对于正态分布且包含少量缺失值的数据集，这是一个很好的选择。 |
| 中位数 | 用可用值的中位数替换缺失值。与均值插补相比，它对离群值不敏感。`Imputed value = Median (available data)` | 用于区间和顺序变量。对于非正态分布（偏态）且包含少量缺失值的数据集，这是一个很好的选择。对于顺序数据也是一个很好的选择。 |
| 全差范围 | 用该变量可用数据的最小值和最大值的中点替换缺失值。全差范围是中心趋势的一种粗略测量。`Imputed value = (max + min)/2` | 用于区间变量。对于正态分布的数据集，这是一个很好的选择。 |
| 分布 | 使用数据的分布来填充缺失值。这种方法基于这样一个假设：缺失值是随机分布的，并且可以从观测数据的值中估计。估计值根据非缺失观测值的概率分布来确定。 | 用于区间和分类变量。如果缺失值是随机分布的，这是一个很好的选择。这种方法通常不会显著改变数据的分布。 |
| 基于树的方法 | 也称为预测均值匹配，使用决策树来插补数据集中的缺失值。它对于插补同时具有连续和分类数据类型的变量中的缺失值特别有用。由于每个输入变量的插补值依赖于其他输入变量的值，与直接用变量的均值或中位数替换缺失值相比，这种插补方法可能提供更高的准确性。 | 用于区间和分类变量。这种方法应用于非线性关系或多次插补（当创建多个插补数据集时）。 |
| 带有代理分裂的树插补 | 是基于树插补的扩展，在插补缺失值时结合代理变量。代理分裂是在决策树中创建的额外划分规则，用于处理预测变量中的缺失值。 | 用于区间和分类变量。如果我们具有高缺失率、预测变量之间存在复杂的依赖关系或交互作用，这种方法是一个很好的选择。 |
| 中最小间距 | 使用观测数据的中位数和最小值来插补缺失值。它指定了包含在间距的数据比例。它假设缺失值将落在相邻最小值定义的范围内。计算此统计量有两个步骤：(1) 使用 `N` 百分比的数据（例如 10%）修剪数据；(2) 中最小间距值的计算方法为修剪后数据的最大值加最小值除以二。`Imputed value = [max(trimmed data) + min(trimmed data)]/2` ![](img/tab5_2a.jpg) | 用于区间变量。当时间序列中的最小值具有实际意义或代表某种下限时，它是很有用的。 |
| 稳健 M 估计器 | 稳健 M 估计器是用于估计中心位置或位置参数的统计估计量。它们对离群值不敏感。主要的 M 估计器有：(1) 土耳双权重；(2) 鲁伯；(3) 安德鲁斯波。![](img/tab5_2b.jpg) | 用于区间变量。在处理包含离群值或与大多数数据显著偏离的数据时，它们非常有用。 |

## 归一化

![](img/ufig5_9.jpg)数据归一化，也称为变量缩放，是机器学习中的预处理步骤，将数据集的变量转换为相似的范围。它是最流行的转换技术之一。首先，让我们讨论未归一化数据与归一化数据之间的区别，以及为什么在某些情况下对数据进行归一化。表 5.3 展示了未归一化数据与归一化数据之间的差异。图 5.1 利用散点图和直方图说明了这些差异。

### 表 5.3 归一化数据与未归一化数据

| 项目 | 未归一化数据 | 归一化数据 |
| --- | --- | --- |
| 范围 | 未归一化的数据在不同变量之间可能有不同的范围。值的跨度很大，使得难以直接进行比较或解释。 | 归一化数据被转换为具有一致的范围。它们通常落在一个预定义的范围内，例如 `[0, 1]` 或 `[−1, 1]`，使得更容易跨特征比较值。 |
| 偏差 | 未归一化的数据可能会因为范围的固有差异而表现出偏差。值较大的变量可能会主导分析或对模型产生不成比例的影响。 | 归一化有助于消除由不同范围引起的偏差。通过缩放数据，所有变量对建模过程的贡献更加均衡。 |
| 离群值 | 未归一化数据中的离群值会对整个建模过程产生显著影响。 | 根据所使用的归一化方法，离群值对整体数据表示的影响较小。某些归一化技术（如 `robust scaling`）可以更有效地处理离群值。 |
| 解释 | 解释未归一化数据的幅度可能具有挑战，因为每个变量的范围不同。 | 归一化数据允许更直观的解释和比较。值被转换为标准范围，能够根据相对大小进行比较和评估。 |

![](img/icon_8.jpg)数据归一化在数据挖掘中提供了巨大的收益，但也带来了一些挑战。以下是数据归一化的的一些主要优缺点。

### 优点

*   提高机器学习算法的性能：通过将数据带入一致的范围，归一化防止某些变量主导其他变量，并确保所有变量对学习过程的贡献相等。
*   减轻离群值的影响：数据归一化可以通过缩放数据来减少离群值的影响，使其对极端值不敏感。
*   简化解释和可视化：数据归一化允许对数据进行更容易的解释和可视化。当数据被缩放到公共范围时，模式和趋势会变得更加明显，比较和理解不同变量也变得更简单。
*   加速优化算法的收敛：某些机器学习方法需要搜索优化。优化算法在处理归一化后的数据时可以收敛得更快。

### 缺点

*   丢失原始数据分布：归一化改变了数据的原始分布，将其压缩或拉伸以适应特定的范围。这可能会导致某些关于数据分布的信息丢失，而这些信息在某些分析场景中可能是相关的。
*   增加解释的复杂性：虽然归一化在某些情况下可以简化解释，但也可能引入复杂性。转换后的值需要转换回原始比例以便有意义的解释，这可能是挑战性的，特别是当处理多种归一化技术或复杂的数据转换时。
*   归一化过程中对离群值的敏感性：尽管归一化有助于减轻离群值的影响，但某些归一化技术（如 `min-max normalization`）对极端值敏感。离群值会不成比例地影响归一化数据，导致潜在的失真或信息丢失。
*   特定的考量：数据归一化的适用性取决于特定的数据和机器学习方法。在某些情况下，为了有意义的解释或与某些算法兼容，可能需要保持数据的原始比例。应该根据数据的需求、特征以及预期的建模技术来仔细评估归一化。

表 5.4 给出了常见的数据归一化方法。在选择归一化方法时，我们必须考虑几个因素。

### 表 5.4 常见的数据归一化方法及使用场景

| 归一化方法 | 描述 | 使用场景 |
| --- | --- | --- |
| Min-Max 归一化（也称为重缩放） | 公式：$X' = \frac{X - X_{min}}{X_{max} - X_{min}}$ 范围：`[0, 1]` | 当你想将数据缩放到特定范围时，特别是当已知分布是有边界的。 |
| Z-score 归一化（也称为标准化） | 公式：$X^{'} = \frac{X - X_{mean}}{SD}$ | 当你想将数据标准化为均值为 0、标准差 (SD) 为 1 时。这种方法通常用于分布未知或不符合正态分布的数据。 |
| 稳健缩放（也称为位数和 MAD 缩放） | 公式：$X^{'} = \frac{X - X_{median}}{MAD}$ | 当你有具有离群值或偏态分布的数据，并且你想根据中位数和中位绝对偏差 (MAD) 而不是平均值和标准差来缩放数据时。 |
| 对数转换 | 公式：$X^′ = log(X)$ | 当数据高度偏斜或包含指数增长时，应用对数转换有助于规范分布。 |
| 幂转换 | 公式：$X^′ = X^n$ | 当数据具有特定的幂律关系时，幂转换有助于规范分布。常见的幂值包括：`n = 0.5`（平方根）、`n = 2`（平方）和 `n = −1`（倒数）。 |

*   归一化的目的：你是为了提高机器学习模型的性能而对数据进行归一化吗？还是为了更容易可视化或解释？
*   你处理的数据类型：你处理的是数值数据还是类别数据？注意，归一化仅适用于间隔变量。
*   数据集的大小：如果你有一个大型数据集，可能需要使用更高效的归一化方法。
*   你使用的算法：某些算法（如 K 近邻和人工神经网络）对数据的尺度敏感度比其他算法更高。此外，线性回归对于正态分布的数据效果最好。如果你正在使用这些算法，那么你应该使用归一化来确保所有变量都在同一尺度上。

## 变量离散化

![](img/ufig5_11.jpg)`变量离散化` 是将连续变量转换为分类变量的过程。在数据挖掘中，当你想要将一个具有连续刻度的变量转换为离散类别时，这是一个常见的预处理步骤。如前，为了确保一致性，我将使用 `间隔变量` 这一术语。这种转换在某些场景下非常有用，例如当你想捕捉非线性关系，或者当特定的数据挖掘算法需要将原始变量视为分类变量时。图 5.2 说明了离散化的概念。输入是连续变量，输出是具有离散层级的分类变量。

![图 5.2 数据离散化。](img/fig5_2.jpg)

图 5.2 数据离散化。

将间隔变量转换为分类变量通用方法描述如下：

1. **确定类别的数量和范围**：决定你想要为新变量创建的类别或组的数量。这个数字代表了分类变量所需的层级。这一决策可能取决于特定数据集、变量的性质以及分析目的。你也可以考虑使用领域知识或统计技术来指导你的决策。
2. **划分数值范围**：将间隔变量的值范围划分为不同的区间或箱。每个箱代表一个类别或层级。区间的定义方式应当能够捕捉数据中有意义的区别，同时在类别数量与每个类别包含的信息之间保持平衡。
3. **为数据点分配类别**：根据数据值落在定义的区间，将原始间隔变量的每个数据点映射到其对应的类别。这种映射可以通过 `if-else` 语句、数学函数或数据挖掘软件中的专用函数来实现。
4. **将类别编码为新的分类变量**：一旦数据点被分配到类别，将每个类别表示为新分类变量的一个独立层级。这一步可以根据软件的不同有不同的方式。

例如，考虑将间隔变量 `age`（年龄）转换为分类变量。我们根据特定的年龄范围定义如 `young`（年轻）、`middle-aged`（中年）和 `elderly`（老年）等类别。根据预定义的这些箱范围创建三个不同的箱。然后，将连续的年龄值相应分配给这些箱。最后，创建新的分类变量（我们称之为 `r_age`），并编码为三个级别：`young`、`middle-aged` 和 `elderly`。

需要注意的是，将间隔变量转换为分类变量会通过数据的离散化导致某些信息的丢失。此外，选择的具体方法和类别数量可能会影响数据挖掘的结果。我强烈建议尝试不同的分类方案，并评估它们对模型性能的影响。

### 表 5.5 变量离散化方法及适用场景

| 离散化方法 | 说明 | 适用场景 |
| --- | --- | --- |
| 等宽/分箱（等宽分箱） | 该方法将间隔变量的范围划分为预定数量的箱，并根据值所在的箱分配标签。 | 当你想在不考虑分布的情况下进行简单的离散化时。这种方法对异常值不敏感。 |
| 分位数/分箱（等频分箱） | 该方法将数据划分为大小相同的子集，以确保每个箱包含相同数量的数据点。 | 当你想让数据代表均匀时。这种方法对倾斜数据很有帮助，但可能导致大小不一。 |
| 聚类 | 该方法应用如 `k-means` 等算法将相似的值归类，然后根据相似性分配标签。 | 当你想让数据自己决定边界时。 |
| 领域特定阈值 | 该方法根据领域知识或特定需求定义阈值，并根据这些阈值分配标签。 | 当领域已有成熟的阈值或标准时。 |

### 航空公司推荐数据集
