# 13.13 案例研究：高光谱图像解混

*高光谱图像解混*（HSI）是在一组约束条件下稀疏回归建模的典型应用。这是一个很好的“借口”，让我们通过一个极具实际重要性的任务来演示分层贝叶斯建模方法的应用。

在*高光谱遥感*中，来自地球表面的电磁太阳能量由位于卫星、飞机或空间站上的敏感扫描仪进行测量。这些扫描仪对电磁辐射的多个波段敏感。地球表面的不同特性导致能量在不同波段的反射各异。例如，在可见-红外范围内，土壤的矿物和水分含量、水体的沉积物以及植被的水分含量是反射能量的主要贡献者。相反，在红外的热端，是表面的热容和热学特性对反射做出贡献。因此，每个波段测量的是同一块地表的不同特性。通过这种方式，可以创建对应于每个波段反射能量空间分布的地球表面图像。现在的任务是利用这些信息来识别各种地表覆盖类型，即建设用地、农业用地、森林、火烧迹地、水体、病害作物等。

图 13.23 说明了从高光谱图像数据立方体（该立方体包含两个空间维度和一个光谱维度）生成像素光谱特征的过程。每幅图像对应单个波长（波段），每个像素对应地球表面的特定斑块。像素的*光谱特征*就是一个向量，包含在各个光谱波段测量到的辐射亮度值。近年来技术的进步使得成像光谱仪得以实现，它们能够收集数百个相邻光谱波段的数据。数据量的大幅增加传递了可被充分利用的空间/光谱信息，从而准确确定被成像物体的类型和性质。

![Figure 13.23 Each image corresponds to a specific wavelength band and each pixel to a particular patch of the earth's surface. The signature of a pixel is a vector whose coefficients measure the radiance of the respective patch of the earth in the different bands (modified image taken from [71]).](images/B9780443292385000196/gr023.jpg)

**图 13.23** 每幅图像对应一个特定的波长波段，每个像素对应地球表面的一个特定斑块。像素的特征是一个向量，其系数测量地球相应斑块在不同波段的辐射亮度（图片取自 [71] 并经修改）。

高光谱遥感的一个内在局限在于，由于遥感器空间分辨率较低，单个像素往往记录的是不同地物混合的光谱特征。这引出了光谱解混（SU）[37]的需求，它是高光谱图像处理中至关重要的一步，近来引起了强烈的科学兴趣。SU 是将观测像素的测量光谱分解为一组组成光谱特征（或称`endmembers`）及其对应比例（或称`abundances`）的过程。执行 SU 的一种广泛使用的模型是线性混合模型。

假设一个由 `M` 个光谱波段组成的遥感高光谱图像，令 `y ∈ ℝ^M` 为包含单个像素（特定地表斑块）测量光谱特征（即所有光谱波段的辐射值）的向量。另令 `X = [x[1], x[2], …, x[l]]` 代表 `M × l` 的端元特征矩阵，其中 `x[i] ∈ ℝ^M, i = 1, 2, …, l` 包含第 `i` 个端元的光谱特征，`l` 是场景中存在的（可能的）不同端元（地表/物质类型）的总数。最后，令 `θ = [θ[1], θ[2], …, θ[l]]^T` 为与 `y` 相关的`丰度向量`，其中 `θ[i]` 表示 `x[i]` 在 `y` 中的丰度分量。线性混合模型假设测量像素光谱与端元光谱之间存在线性关系，表达式为

```
y = Xθ + η
```

其中 `η` 代表加性噪声值，假设其为零均值高斯分布随机向量的样本，具有独立同分布（i.i.d.）元素，即 `η ∼ N(η|0, β^(−1)I[M])`，其中 `β` 表示噪声方差的倒数（精度），`I[M]` 为 `M × M` 单位矩阵。注意，公式 (13.143) 中的模型在其多元形式下是一个典型的回归模型，因为现在每次测量的输出是一个向量而非标量（另见第 4 章的 4.9 节）。输出变量已被测量，矩阵 `X` 假定为已知，确实存在估计其元素的方法。

利用此类模型恢复丰度系数，将是对本书当前及前几章所述内容的直接应用。然而，必须考虑一个物理约束，这使得任务更具挑战性。丰度系数为非负，即

```
θ[i] ≥ 0,  i = 1, 2, …, l.
```

此外，一个合理的假设是：图像中存在的端元只有少数几个会对单个像素 `y` 的光谱产生贡献。换句话说，丰度向量 `θ` 在 `X` 中接受`稀疏`表示。

因此，我们的目标是在给定光谱测量值 `y` 和端元矩阵 `X` 的情况下，在非负性和稀疏性约束下估计 `θ`。显然，实现这一目标有不同的途径。因为我们目前正在探索贝叶斯世界，所以将采用贝叶斯框架。为此，将首先采用一个能表达我们对感兴趣参数先验信念的合适先验模型，然后使用变分贝叶斯方法进行贝叶斯推断，正如之前所讨论的那样。

## 13.13.1 分层贝叶斯建模

公式 (13.143) 中高斯噪声的存在意味着

```
p(y|θ,β) = N(y|Xθ,β^{-1}I_M) = (2π)^{-M/2}β^{M/2}exp(-β/2||y - Xθ||²).
```

![Equation](img/si708.png)(13.145)

我们现在将注意力转向为模型参数选择合适的先验，这些参数被视为随机变量 `θ`、`β`。作为非负噪声精度 `β` 的先验，我们采用伽马分布（第 13.3 节，公式 (13.25)），表示为

```
p(β) = Gamma(β|c,d) = d^c/Γ(c) β^{c-1}exp(-dβ),
```

![Equation](img/si710.png)(13.146)

其中 `c` 和 `d` 是相应的参数（在实验中设为 10^{-6}）。

对于丰度向量 `θ`，我们定义了一个以共轭形式表达的两层分层先验，该先验对丰度系数施加稀疏性和非负性。受 [70] 启发，选择了一个非负截断高斯先验，即

```
p(θ|α) = NR_+^(l),
```

![Equation](img/si712.png)(13.147)

其中 **α** := [*α*[1], *α*[2], …, *α*[*l*]]^(*T*) 为精度参数向量，*A* = diag{*α*[1], …, *α*[*l*]} 为对应的对角矩阵，而 𝒩[ℝ[+]^(*l*)] 表示 *l* 元正态分布，该分布在 ℝ^(*l*) 的非负正交象限 ℝ[+]^(*l*) 处被截断 [84]。在层次结构的第二层中，精度参数也被视为随机变量，*α*[*i*], *i* = 1, 2, …, *l*，它们服从逆伽马分布，即

```
$p(\alpha_{i}) = {IGamma} \left( \alpha_{i}|1,\frac{b_{i}}{2} \right) = \frac{b_{i}}{2}\alpha_{i}^{- 2}\exp\left( - \frac{b_{i}}{2}\frac{1}{\alpha_{i}} \right),$
```

其中 *b*[*i*], *i* = 1, 2, …, *N* 为尺度超参数。这两个层次结构通过对精度 **α** 进行积分消元 [84]，在丰度向量 **θ** 上形成了一个非负截断的多元拉普拉斯先验，即

```
$p(\mathbf{\theta}|\mathbf{b},\beta) = \prod\limits_{i = 1}^{l}\sqrt{\beta b_{i}}\exp\left( - \sqrt{\beta b_{i}}|\theta_{i}| \right)I_{\mathbb{R}_{+}^{l}}(\mathbf{\theta}),$
```

其中 $I_{\mathbb{R}_+^l}(\boldsymbol{\theta})$ 为指示函数，若 $\boldsymbol{\theta} \in \mathbb{R}_+^l$ 则 $I_{\mathbb{R}_+^l}(\boldsymbol{\theta}) = 1$（反之若 $\boldsymbol{\theta} \notin \mathbb{R}_+^l$ 则为 0）。在我们的公式中，公式 (13.148) 中促进稀疏性的尺度超参数也被假定为随机变量，并通过为每个 $b_i$ ($i = 1, 2, \dots, l$) 假设以下的 Gamma 先验分布从数据中推断得出：

```
p(b_i) = Gamma(b_i|\kappa,\nu) = \frac{\nu^\kappa}{\Gamma(\kappa)}b_i^{\kappa - 1}\exp\left( - \nu b_i \right).
```

公式 (13.150) 中的超参数 $\kappa$ 和 $\nu$ 也被设为较小的值（实验中为 $10^{-6}$）。

采用了分层贝叶斯模型后，第 13.3 节讨论的变分 EM 算法被应用于在给定观测值的条件下获得丰度参数后验分布的估计值 $q(\theta_i)$，$i = 1, 2, \dots, l$。在实验中，将分别使用 $q(\theta_i)$ 的均值作为未知参数值的估计。推导细节可参考文献 [85]。变分 EM 算法的另一种替代途径是采用蒙特卡洛技术（参见例如文献 [14]）。
