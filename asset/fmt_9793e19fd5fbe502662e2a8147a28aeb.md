
对于自回归序列数据，可以从由初始真实数据序列 `x[0]`、`x[1]`、⋯、`x[T−1]` 组成的样本特征中预测下一时刻 T 的输出 `x[T]`，然后从 `x[1]`、`x[2]`、⋯、`x[T]` 预测 `x[T+1]`，从 `x[2]`、`x[3]`、⋯、`x[T+1]` 预测 `x[T+2]`，以此类推持续预测。也就是说，初始序列 `x[0]`、`x[1]`、⋯、`x[T−1]` 可用于预测后续的多个时刻。这种预测类型称为**长期预测**（或**长期预测**）。由于预测不一定准确，将预测值作为真实值来预测下一个值会更加不准确，即随着时间的推移，预测值与真实值之间的误差会越来越大。另一种是**短期预测**，极端情况是每个时刻都始终使用该时刻对应时间窗口的真实数据（如当前时刻及前 T-1 个时刻）来预测下一时刻的数据。短期预测之所以效果好，是因为输入数据样本全为真实数据，且仅预测下一时刻的数据，但其要求每个预测时刻使用的数据必须是真实数据，而非上一时刻的预测数据。

以下代码采用长期预测的方法，从初始时刻的真实数据样本出发预测后续一系列时刻的数据。并将这些预测值与测试集对应的目标值进行可视化对比，以观察该模型的预测性能。

ys =[]
for i in range(400):
    y = nn.forward(x)   
    ys.append(y[0][0])

    x = np.append(x, y.reshape(1,-1), axis=1)

### 7.1.10 k-gram 语言模型

语言模型是计算当 $w_1, w_2, \cdots, w_{n-1}$ 出现时，$w_n$ 的概率 $P(w_n|w_1, w_2, \cdots, w_{n-1})$。根据公式 $P(A|B) = \frac{P(A \cap B)}{P(B)}$，条件概率 $P(w_i|w_1, w_2, \cdots, w_{i-1})$ 可以表示为：

$P(w_i|w_1,w_2,\cdots,w_{i-1}) = \frac{P(w_1,w_2,w_3,\cdots,w_{i-1},w_i)}{\sum\limits_w P(w_1,w_2,w_3,\cdots,w_{i-1},w)} = \frac{P(w_1,w_2,w_3,\cdots,w_{i-1},w_i)}{P(w_1,w_2,w_3,\cdots,w_{i-1})}$

即 $w_1, w_2, w_3, \cdots, w_{i-1}, w_i$ 同时出现的联合概率 $P(w_1, w_2, w_3, \cdots, w_{i-1}, w_i)$ 除以边缘概率 $\sum\limits_w P(w_1,w_2,w_3,\cdots,w_{i-1},w)$，后者即 $P(w_1, w_2, w_3, \cdots, w_{i-1})$。后者也可以看作仅包含随机变量 $w_1, w_2, w_3, \cdots, w_{i-1}$ 的联合概率。

要计算条件概率，需要求出联合概率 $P(w_1, w_2, w_3, \cdots, w_{i-1})$ 和 $P(w_1, w_2, w_3, \cdots, w_{i-1}, w_i)$。这些概率可以通过统计方法用频率近似计算。例如，要统计两个词 $w_1 = \text{"中国"}$ 和 $w_2 = \text{"人"}$ 同时出现的联合概率 $P(\text{"中国"}, \text{"人"})$，可以在语料库（如大量文本）中统计“中国人”出现的次数为 n，所有 $w_1$ 和 $w_2$ 的组合（如“你好”、“打球”、“中国梦”）出现的次数为 m。用该频率 n/m 来近似概率 $P(\text{"中国"}, \text{"人"})$。

但如果 $i$ 较大，这种计算显然不现实，主要存在两个问题：

*   由于 $w_j$ 很多，$w_1, w_2, w_3, \cdots, w_{i-1}, w_i$ 的组合数量会呈指数级增长，统计计算 $P(w_1, w_2, w_3, \cdots, w_{i-1}, w_i)$ 非常困难。

*   序列 $w_1, w_2, w_3, \cdots, w_{i-1}, w_i$ 很有可能在语料库中根本不出现，导致概率 $P(w_1, w_2, w_3, \cdots, w_{i-1}, w_i)$ 为 0。

为了解决上述计算条件概率依赖参数过多的问题，通常引入**马尔可夫假设**，即假设一个词的概率仅与它前面出现的有限个词有关。在极端情况下，假设一个词的出现与其周围的词相互独立，即其出现概率不依赖于其他词。这种语言模型称为**一元语言模型**。此时，句子 $S = w_1, w_2, w_3, \cdots, w_n$ 的概率计算变得非常简单：

$P(w_1, w_2, w_3, \cdots, w_n) = P(w_1) \times P(w_2) \times P(w_3) \times \cdots P(w_n)$

但这种语言模型显然是不合理的，因为文本中词的出现并非相互独立，而是存在依赖关系。如果语言模型假设一个词出现的概率仅依赖于它前面出现的一个词，这种语言模型称为**二元语言模型**（bigram）。

$P(w_1, w_2, w_3, \cdots, w_n) = P(w_1) \times P(w_2|w_1) \times P(w_3|w_2) \times \cdots P(w_n|w_{n-1})$

以此类推，如果语言模型假设一个词的概率仅依赖于它前面的 $k-1$ 个词，这种语言模型称为**k-gram 语言模型**（**k-gram**）。k-gram 语言模型是时间窗口方法在语言模型上的具体应用，即利用前 $k-1$ 个词来预测下一个词的概率。

显然，$k$ 越大，预测准确率越高。例如，对于二元语言模型，如果当前词是“中国”，下一个词可能有很多，难以预测具体是哪一个；但如果是四元模型，依次出现的词是“我”、“是”、“中国”，那么下一个词是“人”的概率（可能性）就会非常高。但 $k$ 越大，上述两个问题就越严重。为了规避上述两个困难，传统语言模型一般采用三元或四元语言模型（3-gram 或 4-gram）。

如果构建了这样一个 k-gram 语言模型，就可以根据前面出现的 $k-1$ 个词，预测词表中每个词作为下一个词出现的概率，从而预测整个句子出现的概率。

语言模型是各种自然语言处理问题的基础。例如，可以利用语言模型从开头的词进行长期预测，即根据语言模型的概率对下一个词进行采样，并不断重复这一过程生成一系列后续词，从而自动生成文章、小说、诗歌、散文、评论等文本。

k-gram 语言模型在用固定长度“时间窗口”数据进行预测时存在一些明显的局限性。主要有两个问题：

*   时间窗口长度难以确定。如果时间窗口太短，会导致目光短浅。例如，在机器翻译中，往往需要根据长上下文准确理解当前词的含义；在文本生成中，根据前面的长文本才能正确预测下一个词，如“上学路上，张某儿子看见一位摔倒的老太太。这段话最后一个词用“他”还是“她”，需要根据前面的“儿子”来确定。算法的计算量与样本数据长度成正比。如果时间窗口太长，会耗费更多时间。对语言模型而言，时间窗口过长会使概率估计变得非常困难。此外，对于短序列样本（如短句），需要填充许多空白元素，造成空间浪费。对于许多序列数据问题，不同时刻依赖的数据序列长度往往不同且变化，难以确定一个合适的时间窗口长度。

*   使用普通神经网络对序列数据预测问题建模，随着时间窗口变大，模型参数规模会变大。与单独处理每个原始数据样本相比，如果使用长度为 3 的时间窗口，输入数据样本的长度会增加 3 倍。为了更好地捕捉数据特征，每层神经元数量会相应增加，导致模型参数量呈指数级增长，这不仅消耗更多计算资源，还增加了模型函数的复杂度，容易导致训练过拟合。

时间窗口只是一种短期记忆行为，人在理解事物时，不仅会用到短期记忆，还会用到所有的过往记忆。为了处理这种变长序列数据，研究者模拟人类的长期记忆行为，发明了**循环神经网络**（**Recurrent Neural Networks**，**RNN**）。RNN 在传统神经网络的神经元中增加了**存储/记忆单元**，使得历史计算信息得以保存。换句话说，神经元具有了记忆功能，每一当前时刻的计算不仅依赖于当前的输入，还依赖于存储的历史信息，从而使数据和计算结果能在时间维度上传递，使得循环神经网络理论上可以记忆任意长度的序列信息。正如卷积神经网络能提取空间维度的特征，循环神经网络能在时间维度上传递信息，它是非循环神经网络在时间维度上的延伸。

## 7.2 循环神经网络

### 7.2.1 不具备记忆功能的非循环神经网络

上文学习的神经网络都是不具备记忆功能的神经网络，它们表示一个不具备记忆功能的函数，不同样本之间的输入输出相互独立，没有任何关联。假设该神经网络记为 $y = f(x)$，对于两个不同的输入 $x_i, x_j$，它们的输出 $f(x_i), f(x_j)$ 互不相关。

非循环神经网络表示的函数类似于编程语言中不具备记忆功能的函数，例如 C 语言中没有静态变量的函数和 Python 语言中的函数。如：

```python
def f(x):
    y = 0
    y += x*x
    return y

print(f(2), '\t', f(3))
print(f(3), '\t', f(2))
```

```
4 9
9 4
```

无论是先计算 `f(2)` 再计算 `f(3)`，还是先计算 `f(3)` 再计算 `f(2)`，`f(2)` 和 `f(3)` 的结果仅取决于各自的输入 2 和 3，`f(2)` 和 `f(3)` 的执行顺序无关紧要。

如果使用无环神经网络根据当前词预测下一个词的概率，这种预测也独立于词的处理顺序。如图 7-12 所示，假设语言中只有 "good"、"drink" 和 "wine" 三个词，对于输入词序列 "good drink" 中的每个词，神经网络都输出每个词作为下一个词的概率。

图 7-12 非循环神经网络从词 "good" 预测 "good"、"drink" 和 "wine" 作为下一个词的概率，以及从词 "drink" 预测 "good"、"drink" 和 "wine" 作为下一个词的概率，二者相互独立。无论输入序列是 "good to drink"、"wine is good to drink" 还是 "drink good wine"，从词 "good" 预测 "good"、"drink" 和 "wine" 作为下一个词的概率都是相同的。

无论这三个词在句子中以何种顺序出现，例如 "wine is good" 和 "drinking good wine"，对于每个词，神经网络根据该词预测每个词作为其下一个词的概率，结果都是一样的。用这种神经网络来表示语言模型，每个词的输出值仅取决于它自己，与其他词无关。这显然是不合理的。

不失一般性，如果神经网络只有一层或一层神经元，即：

`y = f(x) = g(xW + b)`

并假设非线性激活函数为 sigmoid 函数，该神经网络可用 Python 代码表示为：

```python
class FNN(x):
    # ...
    def forward(self, x):
        y = sigmoid(np.dot(x, self.W) + self.b)
        return y
```
