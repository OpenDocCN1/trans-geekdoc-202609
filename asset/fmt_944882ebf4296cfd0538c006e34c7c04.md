
*   **内围边界**：该边界通常涉及物理屏障，如墙壁、门和窗，视外围边界的上下文而定，可以是外部的，也可以是内部的。
*   **内部区域**：这是最内层的安全级别，由内围和外围边界包围的建筑物内部、办公室、工位等组成。

在一个全面的安全计划中，会涵盖对这三个层面的控制。每一层的安全通常由专门挑选的设备组合构成，它们协同工作以提供有效的物理安全系统。

在每一层中，有两个概念在起作用：自然准入控制方法和领域强化。`Natural access control`（自然准入控制）涉及利用自然设计元素（如建筑结构和景观美化）来引导人员进出空间。另一方面，`territorial reinforcement`（领域强化）则采用结构、系统和设备来防止未经授权的进入，并明确区分公共区域和私有区域。

*   访问控制和监控系统
*   入侵检测和报告系统
*   视频监控系统

### 访问控制

从上述列表可以看出，`access control`（访问控制）是物理安全系统的首要核心组件。事实上，大多数安全专家都同意，任何基础设施安全系统的首要和最基本目标是威慑潜在入侵者。这就是访问控制的目标。*你无法破坏、损毁或窃取你无法物理接触到的东西*。

设计高效访问控制系统的基础涉及三个术语：`ingress`（入站/进入）、`egress`（出站/离开）和 `regress`（再入/返回）。根据定义，`ingress` 是个人进入财产的权利，而 `egress` 是离开财产的合法权利。同样，`regress` 是指再次进入财产的合法权利。

在安全术语中，`right`（权利）是指由某公认权威来源授予某人或某群体的 `legal privilege`（法律特权）或 `permission`（许可）。该来源可以是政府、合法认可的政府代理人或资产的合法认可所有者。延伸而言，拥有访问资产权利的人被称为 `authorized`（授权的，由认可的权威授权），而未被授予此权利的任何人则被标记为 `unauthorized`（未授权的）。当 `unauthorized`（未授权）人员试图访问其无权访问的资产时，他们就成为入侵者。

因此，访问控制涉及基于 `authorization`（授权）来控制对资产的 `ingress`、`egress` 和 `regress`。特别是，限制未授权人员访问重要资产，是你能采取的最基本的安全步骤。

访问控制始于外围边界。根据所研究的具体示例，这可能是组织物理财产的地界线，或其设施的大门。

回顾一下，外围边界的目标是控制谁可以步行或跨越该边界。此处的控制可以很简单，如在财产边缘种植树篱，或设置适当的视觉标志警告未授权人员勿入；也可以很复杂，如带有大门和武装警卫的带刺铁丝网围栏。

访问控制工作通常延伸至外围和内围边界之间的区域。这些工作可以包括自然准入控制技术，如员工和访客停车场的战略性布局，以及利用景观特征将人员引导至指定的出入口，并阻断其他可能的进出点。这也延伸至清晰地标记设施和财产的 `ingress` 和 `egress` 通道。

物理基础设施的内围边界控制涉及使用墙壁、窗户和门等物理结构，它们可作为 `barriers`（屏障），阻碍入侵者从外围边界推进到内部区域。同样，视具体讨论的安全场景而定，这些屏障可能是包围整个内部环境的建筑外部结构的一部分，也可以是控制进出个别工作区域的内部结构。

`Interior security`（内部安全）是基础设施安全的最内层级别，涉及对内围边界内区域的监控。这种监控可能由人力和电子安全系统共同组成，用于观察、跟踪和检测入侵者，以及记录各类活动的证据。授权人员与电子设备的结合，构成了内部安全级别的有效安全工具。

## 物理安全控制与认证系统

### 安全策略与访问控制

一个将三个安全层级整合在一起的关键组件是设计良好且文档完善的 `security policy`（安全策略），它规定了如何在每个层级实施安全。企业和组织制定全面的安全策略，定义谁被授权访问不同的资产，以及他们在访问这些资产时被允许做什么。

例如，允许员工和访客自由进入组织内的所有部门会带来各种安全风险。您需要维护访问控制，以创建一个减少人类贪婪本性诱惑的环境。如果每个人都可以在组织内部自由移动，就很难实施保护措施来防止他们访问或拿走物理或网络资产。

您还需要维护访问控制以防止意外事故。例如，您不希望销售代表不小心将咖啡洒在工程部门的生产服务器上。相反，应在每个层级制定一个连贯的 `access control policy`（访问控制策略），为授权人员提供对选定资产的适当访问级别，同时阻止未授权人员访问资产。然后，根据需要使用正确类型和数量的访问控制设备（传感器、屏障、日志、ID 徽章或保安）来强制执行这些策略。

通常，徽章或智能卡用于控制访问。当员工移动到 RFID 传感器的近程范围内时，也可以通过 RFID 应答器识别。应答器存储访问代码并使用无线电接收器和发射器。

这些访问控制技术、系统和设备将在本章剩余部分中详细讨论。

### 物理安全控制

强制执行访问控制措施最初可能包括在通往办公室的门上安装锁，并使用类似的 `physical barriers`（物理屏障）隔离部门或网络区域。许多公司的前门或入口处设有接待员以控制访问，如图 6.2 所示。在营业时间内，`receptionist`（接待员）充当物理屏障，询问客户来访的性质。

在某些机构中，访客可能需要由 `escort`（陪同人员）陪同，以物理方式限制其在公司内的活动范围。为了增加访问控制，可以雇佣人工守卫来控制对特定受限内部区域（如实验室）或通往受限区域（如地下室）的电梯井的访问。

屏障可用于通过访问控制提供安全性。夜间，物理屏障可能只是一扇锁着的门。门也可能配备传感器和警报器。警报器可以是本地报警器（如警笛），也可以直接连接到外部监控系统或警察部门。

大多数安全边界的主要物理屏障是 `lockable door`（可上锁的门）或 `gate`（闸门），如图 6.3 所示。门提供物理屏障，但它本身只能挡住诚实的人。另一方面，锁通过其钥匙提供屏障的认证功能。持有 `key`（钥匙）意味着该人拥有或知道获得通过门访问所需的信息。

### 认证系统

`Authentication`（认证）是确定某人是其声称身份的过程。回顾一下，有效的访问控制涉及基于 `authorization`（授权）控制对资产的入口、出口和回归。特别是，限制未授权人员访问重要资产是您可以采取的最基本安全步骤。因此，授权基于认证。认证涉及多个因素：

*   `Knowledge`（知识因素）：只有指定人员应该知道的东西（您知道的东西）
*   `Possession`（持有因素）：只有指定人员应该拥有的东西（您拥有的东西）
*   `Inherence`（固有因素）：只有指定人员才是的东西（您本身的东西）
*   `Location`（位置因素）：只有指定人员所在的地方（您所在的地方）

许多物理认证系统基于依赖持有因素的 `single authentication factors`（单因素认证），例如持有可开锁的钥匙设备。钥匙可以是物理钥匙或虚拟钥匙，视需要而定，用于开启物理或虚拟锁定机制。

更智能有效的认证方法涉及 `two-factor authentication`（双因素认证），这是一个需要两个因素才能授予授权的过程。这基于知识和持有因素。高级授权和认证方法包括 `multifactor authorize and authentication systems`（多因素授权和认证系统）。在这些系统中，信息必须呈现给认证设备，后者将其传递给安全控制器的认证系统。访问控制系统中常用许多不同的认证设备。主要设备类型将在本章后续章节中介绍。

#### RFID 徽章

以类似的方式，`射频识别 (RFID)` 技术可部署为一种认证工具。如图 6.6 所示，RFID 系统利用自供电的 `RFID 标签`，可用作信标以追踪位置或认证邻近度。`有源 RFID 标签`提供更长的范围，但价格昂贵得多，且需要更多电力。`无源 RFID 标签`由 RFID 读取器发射的电磁能量供电，价格可能非常低廉。低频 RFID 标签范围较短，但通常更可靠，且受金属屏障影响较小。

高频标签范围较长，但任何障碍物都会造成更多干扰。现代 UHF RFID 标签即使放置在金属表面上似乎也能良好工作。无源 RFID 标签也常用于追踪库存物品和设备，并在许多应用中取代了条形码。

回顾第 4 章“ICS 模块与要素加固”，`NFC` 是一种高频 RFID 标准，非常适合安全应用，因为它要求近距离接触。邻近性很重要，因为这可以最大限度地减少任何未经授权的隐蔽访问尝试。正如第 4 章所述，创建流氓 RFID 读取器以从目标获取徽章数据相对容易，如图 6.7 所示。为徽章系统采用 `NFC` 技术可因其近距离要求而降低数据被窃取的风险。

### 智能卡

`智能卡`包含一个嵌入式集成电路，可能仅仅是一个存储芯片或一个安全微控制器。它可能能够通过直接物理接触与读取器连接，或者在非接触式卡的情况下，通过有源 RF 接口进行通信。在某些情况下，智能卡可能采用 ID 技术的组合，如图 6.8 所示。

![图 6.8 智能卡 ID 技术](img/c06f008.png)

**图 6.8** 智能卡 ID 技术

`国际标准化组织 (ISO)` 和 `国际电工委员会 (IEC)` 已发布国际标准——`ISO/IEC 7816-4:2020` 和 `ISO/IEC 1443`——用于非接触式智能卡和智能芯片的标准化。这些设备通常在 13.56 MHz 下运行，且必须在距离读取器 4 英寸范围内才能与其通信。

智能卡中的微控制器可编程以执行任意数量的安全功能。除了简单地在卡中 `存储` 信息用于认证目的外，还可实现许多高级卡上功能，包括 `加密` 和 `PKI 认证` 服务，以及随机数生成、哈希和读取器验证。此外，生物特征数据可存储在卡上，并在认证过程中与读取器共享，以便读取器将该数据与从实时生物特征扫描仪接收的数据进行比较，如图 6.9 所示。

许多应用将智能卡视为任何包含智能功能集的卡、钥匙扣或便携式解决方案。它们难以复制，并可能包含额外的安全功能，使复制更加困难。

`磁条卡` 和 `条形码卡` 是提供单因素物理认证的廉价方式。它们通常易于复制，当然也易于窃取。然而，低成本也允许使用短期凭证频繁生成卡片，从而提高安全性。

#### 生物特征扫描仪

`生物特征识别` 是用于描述利用人体物理特征验证个人身份的访问控制机制的术语。生物特征认证涉及使用独特的个人生理特征来验证人们是否为他们自称的身份。

每个人都拥有独特的物理特征，将他们与其他人区分开来。即使是同卵双胞胎也有独立且独特的 DNA、声纹、指纹、眼部特征和其他特征。生物特征认证中最常涉及的特质包括声纹、指纹、掌纹、签名、面部特征以及视网膜和虹膜扫描，如图 6.11 所示。

![图 6.11 典型生物特征认证方法](img/c06f011.png)

## 生物识别设备准确性

然而，并非所有生物识别扫描设备在验证用户方面都具有同等的准确性。表 6.1 显示了不同生物识别扫描设备在准确验证人员方面的评级情况。

### 表 6.1 生物识别设备对比

| 生物识别类型 | 误报率 (False Positive Rate) | 漏报率 (False Negative Rate) |
| :--- | :--- | :--- |
| 掌纹 | 1.43% | 4% |
| 面部结构 | 0.1% | 0.8–1.6% |
| 声纹 | 2–5% | 5–10% |

对于指纹，美国政府的数据分别显示误报率和漏报率为 0.1% 和 0.4%。

一般来说，人眼的特征——虹膜和视网膜扫描——往往使其成为最可靠的认证来源。在列表中剩余的生物识别变量中，指纹读取往往比语音扫描更准确。然而，指纹可能会留在光滑表面上并被后续利用。为克服这种可能性，已开发出指静脉扫描仪，可将指尖静脉模式转换为数字表示。另一方面，疾病和用户压力水平会影响语音模式。

如表所示，存在两种基本类型的认证失败：

*   **类型 1，拒真（误拒）或假阴性失败**：这是一种导致对个人产生错误拒绝的报告，从而将本应拥有访问权限的人员拒之门外，无法进入设施或安全区域。
*   **类型 2，纳伪（误纳）或假阳性失败**：这是一种错误地通过个人认证的报告，可能导致向本不应拥有访问权限的人员提供设备或数据访问权限。在这两种认证失败类型中，此类最为严重，因为它可能向恶意人员授予访问权限。

由于存在误报和不准确的可能性，可能需要结合生物识别设备使用第二种访问控制方法。在需要更高安全性的区域，可使用护照、额外指纹或其他类型的验证，以确保个人未被错误识别。

### 远程访问监控和自动化访问控制系统

*远程监控* 是指从远程位置或控制室对设备进行监控或测量。在安全领域，这涉及通过通信系统对安全系统进行外部访问。

*远程访问监控* 系统用于在尝试未经授权的访问时通知监管安全人员。在这些系统中，控制器监控基础设施传感器的 *开/闭状态*。当传感器（如磁性开关或运动探测器）被触发时，系统会自动将其识别为入侵，并通知指定的安全人员。

可使用各种传感器来检测自动门或闸门的开启、关闭、上锁或解锁状态。它们也可被配置为在指定门或闸门处发起开启、关闭、上锁或解锁状态。
