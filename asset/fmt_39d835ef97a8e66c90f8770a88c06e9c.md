
## 问题 270。
中型企业的首席技术官（CTO）Liam 注意到有几个软件应用程序没有定期更新，导致了潜在的安全漏洞。经过调查，他发现没有特定的团队或个人被指定为这些应用程序的所有。为了增强安全性，Liam 应该强调什么？

- (A) 立即停用所有无所有者的应用程序
- (B) 为所有业务应用程序分配明确的所有权
- (C) 对所有应用程序进行每月漏洞评估
- (D) 将这些应用程序的管理工作外包给第三方供应商

### 解析 270。
**正确答案：B. 为所有业务应用程序分配明确的所有权。** 分配明确的所有权可确保有指定的团队或个人负责应用程序的维护、更新和安全性。当所有权明确时，所有者有责任维护和保护应用程序的安全，从而减少漏掉更新等疏忽风险。

**选项 A 错误。** 立即停用可能不切实际或不可行，特别是当这些应用程序对业务运营至关重要时。

**选项 C 错误。** 虽然每月漏洞评估可以帮助识别安全问题，但它们没有解决场景中强调的问题根源——缺乏所有权和责任制。

**选项 D 错误。** 外包可能会转移责任，但不能确保应用程序将获得更好的管理或更安全。无论管理是内部还是外包，所有权的清晰度都是至关重要的。

## 问题 271。
Sophia 收到一封来自银行的邮件，要求她由于系统升级尽快更新个人详情。邮件中包含一个链接，重定向指向一个与其银行网站相似的网站。她应该**首先**做什么？

- (A) 点击链接并及时更新她的个人详情，以避免任何不便
- (B) 将邮件转发给朋友和家人，以确保他们了解银行的系统升级
- (C) 立即删除邮件且不采取任何操作
- (D) 通过官方渠道联系她的银行以验证邮件的真实性

### 解析 271。
正确答案：D. 通过官方渠道联系她的银行以验证邮件的真实性。在根据未经请求的邮件采取行动之前（尤其是要求个人信息或凭据的邮件），直接与其声称代表的机构或实体验证其合法性至关重要。

钓鱼攻击通常利用恐惧、紧急性或感知的权威来诱导受害者提供敏感数据。防御此类尝试的最佳方法是在采取行动之前独立验证任何意外或可疑的请求。

选项 A 错误。通过提供个人详情来直接响应潜在的钓鱼邮件是一个常见错误，使用户户面临欺诈和身份盗窃的风险。

选项 B 错误。将可能恶意的邮件转发给他人可能会进一步传播威胁，并可能危及他们的安全。

选项 C 错误。虽然删除邮件可能防止 Sophia 掉入钓鱼陷阱，但告知银行此类可疑邮件仍然是一个做法，这样他们可以采取适当措施并警告其他客户。

## 问题 274。
一名员工接到一个自称来自 IT 部门的人的电话。来电者说员工的电脑需要紧急更新，并索要登录凭据以远程执行更新。该员工由于关于冒充的哪种警旗信号而产生怀疑？

- (A) 打电者没有使用技术术语
- (B) IT 通常通过邮件发送更新通知
- (C) 员工没有预料到会有更新
- (D) 来电者的声音听起来陌生

### 解析 274。
正确答案：B. IT 通常通过邮件发送更新通知。如果组织的标准程序是通过邮件发送更新通知，那么索要凭据的非请求电话就是一个明显的警旗。

冒充是社交工程攻击中常用的策略，攻击者伪装成受害者信任的人。识别偏离标准程序的行为有助于识别冒充尝试。

选项 A 错误。是否使用技术术语并不是判断冒充的可靠指标。一些真实的 IT 人员为了让非技术员工更容易理解会避免使用术语。

选项 C 错误。虽然意外更新可能可疑，但它们本身并不一定意味着冒充。合法的意外更新可能会发生。

选项 D 错误。声音陌生并不是可靠的指标，因为大型组织可能有许多员工从未接触过的 IT 人员。

## 问题 276。
TechDynamics 是一家不断增长的科技初创公司，计划扩大业务规模并为全球客户提供服务。鉴于其客户群跨多个时区，TechDynamics 应在何时安排系统维护以确保干扰最少？

- (A) 在其总部当地时间最忙碌的时段
- (B) 根据其全球客户的高峰时段进行错峰安排
- (C) 仅在发生系统故障时
- (D) 在大多数客户的非峰时段建立固定的维护窗口

### 解析 276。
正确答案：D。在大多数客户的非峰时段建立固定的维护窗口。在服务于跨不同时区的全球客户时，在大多数客户最不活跃的小时段建立维护窗口至关重要。这可以最大限度地减少干扰，并确保大多数客户运营顺畅。

选项 A 错误。仅关注总部当地时间会忽略全球客户的运营时间。这种方法可能会导致其他时区客户的干扰。

选项 B 错误。虽然根据全球客户的高峰时段错峰维护看起来很合逻辑，但它可能导致维护计划变得复杂且难以管理，特别是在客户群增长的情况下。

选项 C 错误。等待系统故障再进行维护是被动的，而不是主动的。这种方法可能会导致更长时间且不可预测的停机时间，从而导致更大的干扰和潜在的安全风险。

## 问题 277。
一家国防承包商正在研发一种新的导弹系统。虽然详细的图纸和操作细节属于机密，但他们有一份只有少数合作伙伴和利益相关者可以查看的概述文档。该概述文档应该如何分类？

- (A) 公开 (Public)
- (B) 受限制 (Restricted)

### 解析 277。
正确答案：B. 受限制 (Restricted)。

当对文档或数据的访问需要限制在特定的个人组时，使用“受限制”分类。在这种情况下，只有少数合作伙伴和利益相关者允许查看概述文档，因此“受限制”是最恰当的分类。

选项 A 错误。“公开”分类允许任何人访问该文档，这不适用于此场景。

选项 C 错误。虽然“机密 (Confidential)”分类可以提供水平的保护，但它不像“受限制”那样专门地将访问限制在定义的组内。

选项 D 错误。“绝密 (Top Secret)”是一个高级别的分类，更适用于详细的图纸和操作细节，而不是概述文档。

## 问题 279。
CyberSecure Corp 的安全分析师审查了一份漏洞报告，该漏洞允许攻击者上传恶意脚本。一旦这些脚本被执行，他们就可以获得应用程序的完全控制。该漏洞主要应如何分类？

- (A) 完整性漏洞 (Integrity)
- (B) 可用性漏洞 (Availability)
- (C) 远程代码执行漏洞 (Remote code execution)
- (D) 泄露漏洞 (Disclosure)

### 解析 279。
正确答案：C。远程代码执行漏洞允许攻击者在目标系统上运行任意命令或脚本。在场景中，该漏洞允许攻击者上传并执行恶意脚本，这与该分类一致。

选项 A 错误。虽然该漏洞会影响应用程序的完整性，但主要关注的是攻击者远程执行代码的能力。

选项 B 错误。可用性漏洞主要涉及服务或系统的中断，防止授权用户访问。场景中并未指示任何可用性的中断。

选项 D 错误。泄露漏洞涉及对信息的未经查看或访问。描述的漏洞超出了简单的泄露，允许执行脚本。

## 问题 280。
一家金融机构正在更新其基础设施，以确保客户财务数据不受内部和外部威胁。下列措施中，对于防止内部内部用户访问客户财务数据最有效？

- (A) 在机构网络周围部署防火墙
- (B) 为所有客户账户实施双重身份验证 (2FA)
- (C) 根据最小权限原则执行严格的访问控制
- (D) 为所有员工进行年度安全意识培训

### 解析 280。
正确答案：C。根据最小权限原则执行严格的访问控制。最小权限原则 (PoLP) 确保用户仅获得执行工作所需的所需的权限，不再更多。通过根据该原则执行严格的访问控制，金融机构可以最大限度地减少未经授权的内部用户访问敏感财务数据的风险。

选项 A 错误。边界防火墙更多地关注防止外部威胁，没有专门解决未经授权的内部访问。

选项 B 错误。实施双重身份验证 (2FA) 主要用于验证用户身份，不能防止已通过验证的内部用户访问数据。

选项 D 错误。虽然安全意识培训至关重要，但它不是防止内部授权访问财务数据最有效的特定措施。

## 问题 281。
Alice 是某初创公司的系统管理员，正准备为公司部署一个新网站。为了确保用户与网站之间的通信安全，她计划为该网站获取数字证书。在此之前，Alice 必须先执行哪一步才能从证书颁发机构（CA）获得证书？

- (A) 生成一对公私密钥对
- (B) 向 CA 提交护照扫描件
- (C) 下载最新的 CA根证书
- (D) 使用对称加密对网站进行加密

### 解释 281。
正确答案：A. 生成一对公私密钥对。在 Alice 向 CA 请求数字证书之前，她必须先生成一对公私密钥对。完成后，她会创建一个包含其公钥和一些额外信息的证书签名请求（CSR）。然后将 CSR 提交给 CA 进行签名。

选项 B 错误。对于标准的 SSL/TLS 证书，CA 通常不要求护照扫描件。它们可能会有身份验证流程，但那通常是针对扩展验证（EV）证书的。

选项 C 错误。虽然通过下载其根证书来信任一个 CA 可能是必要的，但这并不是请求数字证书之前所需的步骤。

选项 D 错误。对称加密与获取数字证书的过程无关。

## 问题 282。
TechFin 银行正在考虑为其交易处理实施一个新的软件系统。在推出系统之前，网络安全团队坚持进行一种特定类型的分析，以理解这种变化可能如何影响组织的安全态势。团队指的是什么？

- (A) 风险偏好评估
- (B) 性能基准测试
- (C) 影响分析
- (D) 渗透测试

### 解释 282。
正确答案：C. 影响分析。影响分析评估组织内变化的潜在后果。在 TechFin 银行的背景下，网络安全团队将使用这种分析来理解新软件系统可能会引入哪些漏洞、影响现有的安全措施，或其他方式影响银行的整体安全性。

选项 A 错误。风险偏好评估是指确定组织为了实现目标而愿意接受的数量和类型。它并不关注特定变化带来的后果。

选项 B 错误。性能基准测试侧重于将组织的性能指标与行业标准或最佳实践进行比较，而不是评估变化的潜在安全影响。

选项 D 错误。虽然渗透测试对于评估系统中的漏洞至关重要，但它无法提供变化对组织安全态势可能产生影响的全局视图。

## 问题 283。
ABC 公司的软件开发团队创建了一个利用创新算法的独特应用程序。公司希望确保竞争对手无法合法地复制或模仿其应用程序的功能。以下哪种方法是保护该知识产权最合适的？

- (A) 为用户界面设计申请版权
- (B) 为创新算法申请专利
- (C) 将应用程序代码存储在加密箱中
- (D) 确保所有用户都签署可接受使用政策（AUP）

### 解释 283。
正确答案：B. 为创新算法申请专利。专利为发明提供法律保护，允许发明者或专利持有者在一定时间内对专利工艺、设计或发明拥有专有权。在这种情况下，对算法申请专利将防止竞争对手在法律上复制应用程序独特的功能。

选项 A 错误。为用户界面设计版权只会保护应用程序的视觉外观和元素，而不保护其独特的功能或底层算法。

选项 C 错误。虽然将应用程序代码存储在加密箱中可以防止受未经授权的访问，但如果竞争对手独立开发了类似的功能，它并不能提供防止复制的法律保护。

选项 D 错误。可接受使用政策（AUP）定义了允许用户如何使用软件或系统，但它不能提供防止竞争对手复制应用程序独特功能的保护。

## 问题 284。
SecureBank 正在为其新的在线交易系统选择供应商。银行非常希望确保选定的供应商具有稳健的安全措施，以及维护这些措施的记录。作为供应商选择过程的一部分，以下哪一步与银行的关注点最相关？

选项 D 错误。评估营销策略无法对安全实践提供深层见解。

## 问题 285。
XYZ Corp 是一家智能家居设备制造商，未在其产品中实施标准的安全实践。一家热门科技网站发布了一篇详细说明这些漏洞的深度评测。XYZ Corp 最可能面临以下哪种结果？

- (A) 获得创新技术奖项
- (B) 声誉损害导致销量下降
- (C) 与科技零售商的合作增加
- (D) 招聘人数激增

### 解释 285。
正确答案：B. 声誉损害导致销量下降。负面评测（尤其是强调安全漏洞的评论）会导致消费者失去信任，可能导致销量下降。

选项 A 错误。在公开安全漏洞的情况下，获得创新奖项是不可能的。

选项 C 错误。考虑到产品缺陷的负面报道，与科技零售商的合作可能会受到损害或至少推迟。

选项 D 错误。负面评测（尤其是强调安全漏洞的评论）不太可能增加招聘。潜在员工可能对加入一家声誉受损的公司产生顾忌。

## 问题 287。
XYZ 公司的高级高管 John 接到一个自称来自银行欺诈部门的人的电话。来电者要求 John 通过提供发送到其注册手机号的 OTP（一次性密码）来确认某些交易。John 可能面临哪种形式的社会工程攻击？

- (A) 钓饵 (Baiting)
- (B) 问答 (Quizzing)
- (C) 语音诈骗 (Vishing)
- (D) 钓鱼攻击 (Pharming)

### 解析 287。
正确答案：C. 语音诈骗 (Vishing)。Vishing 是 voice phishing 的缩写，是指利用电话欺骗用户交出用于身份盗窃的隐私信息。

语音诈骗攻击利用信任，通过语音通话操纵受害者披露敏感信息。攻击者通常伪装成合法实体或部门（例如银行欺诈部门），以使他们的骗局看起来真实。

选项 A 是错误的。钓饵涉及诱导受害者在免费或有利下载的名下下载恶意软件。

选项 B 是错误的。问答不是一种公认的社会工程攻击类型。

选项 D 是错误的。钓鱼攻击（Pharming）涉及将网站流量重定向到虚假网站，通常是为了获取登录凭据。

## 问题 288。
零售公司 DeltaCorp 评估安全泄露可能会导致 100 万美元的销售损失。公司确定他们可以忍受高达 50 万美元的损失，但超过此金额的任何损失都将严重影响运营。超出忍受水平后，他们决定购买网络安全保险。以下哪个术语最描述 500,000 美元的数字？

- (A) 风险偏好 (Risk appetite)
- (B) 风险阈值 (Risk threshold)
- (C) 风险容量 (Risk capacity)
- (D) 风险评估 (Risk assessment)
