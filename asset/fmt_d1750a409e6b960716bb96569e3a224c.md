
## 1. CSP 的挑战

CSP 向 EVs 发送挑战是优先级确定过程的第一步。最初，CSP 使用多个属性权威的属性创建不同优先级的优先级策略。随后，CSP 广播这些优先级策略以及对应的挑战（ABE）和 EV 可充电的最大能量。挑战的格式为 `challenge_p = CT_p, TS, Sig(CT_p, TS)` \tag{3}，其中 `TS` 为时间戳，`Sig(CT_p, TS)` 为 CSP 对密文 `CT_p` 的签名。

为了计算优先级策略的密文，CSP 对不同优先级的消息 `g_t^{r_p}` 进行加密，其中 `g_t ∈ G_T`，`r_p \stackrel{R}{\leftarrow} Z_p^*` 是 CSP 为每个优先级 `p`（`1 ≤ p ≤ N`）随机选择的元素，`N` 为优先级的数量。对于每个优先级，CSP 创建访问策略 `(A, δ)`，其中 `A ∈ {Z_p^*}^{l×n}`，`l` 为该访问矩阵的行数，`δ` 是将访问矩阵的行映射到属性的函数。`ρ` 是另一函数，将属性映射到其权威 `ρ: [l] → U_θ`，即 `{ρ(·): T(δ(·))}`。为了加密消息 `g_t^{r_p}`，CSP 需要相关属性权威的公钥以及公共参数。CSP 首先创建两个随机向量 `v = (z, v_2, ..., v_n)^T` 和 `w = (0, w_2, ..., w_n)^T`，其中 `{z, v_2, ..., v_n, w_2, ..., w_n}` 均为从 `Z_p^*` 中随机选取的元素。我们用 `λ_x` 表示随机秘密 `z` 在第 `x` 行的分享，即 `λ_x = (A_x · v)`，而 `w_x` 表示 `0` 的分享，即 `w_x = (A_x · w)`，其中 `A_x` 为访问矩阵 `A` 的第 `x` 行。随后，CSP 为每一行选择随机元素 `t_x \stackrel{R}{\leftarrow} Z_p^*` 并计算密文 `CT_p` 如下：

```
C0 = g_t^{r_p} · e(g, g)^z;

{C1,x = e(g, g)^{λ_x} e(g, g)^{a_{ρ(x)} t_x}, C2,x = g^{-t_x}, C3,x = g^{y_{ρ(x)} t_x} g^{w_x}; C4,x = F(δ(x))^{t_x}, x∈[l]}
```

以同样的方法，CSP 为每个优先级创建不同策略的密文，然后广播不同优先级的挑战。

## 2. EV 的响应

为了获得优先级充电服务，每个 EV 需要检查优先级策略，判断其属性是否满足某一优先级，然后解密相应的密文以向 CSP 证明其优先级，如图 6 所示。每个 EV 使用其秘密键解密相应的密文，并利用解密后的消息 `g_t^{r_p}` 计算会话密钥。随后，EV 使用会话密钥对解密后的消息进行加密，以作为拥有相应优先级的证明。

EV 取策略 `(A, δ)` 以及对应的密文 `(CT)`，并使用其秘密键 `(K_{GID,u}, K'_{GID,u})` 对访问矩阵中满足属性的子集行 `A_x` 进行计算：

```
C1,x · e(K_{GID,δ(x)}, C2,x) · e(H(GID), C3,x) · e(K'_{GID,δ(x)}, C4,x) = e(g, g)^{λ_x} · e(H(GID), g)^{w_x}
```

然后，它计算常数 `c_x ∈ Z_p`，使得 `Σ_x c_x A_x = (1, 0, ..., 0)`，并计算：

```
Π_x e(g, g)^{λ_x} · e(H(GID), g)^{w_x}^{c_x} = e(g, g)^z
```

这之所以成立，是因为 `λ_x = (A_x · v)` 且 `w_x = (A_x · w)`，而 `⟨(1, 0, ..., 0) · v⟩ = z`，`⟨(1, 0, ..., 0) · w⟩ = 0`。消息可以解密为 `g_t^{r_p} = C0 / e(g, g)^z`。EV 使用收到的 `g_t^{r_p}` 与 CSP 计算会话密钥 `k = g_t^{r_i · r_p}`，其中 `r_i ∈ Z_p^*` 是 `EV_i` 选取的随机数。EV 向 CSP 发送 `H_k(g_t^{r_p})`、`g_t^{r_i}`，后者将被 CSP 用于建立会话密钥。`H_k(g_t^{r_p})` 作为 EV 证明其正确解密了属性基加密挑战的凭证。此外，EV 还应发送其需要充电的能量数量。
