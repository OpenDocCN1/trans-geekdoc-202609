
# 渗透测试

安全评估漏洞分析的另一面是**渗透测试**，或**渗透测试**。渗透测试简单来说就是攻击网络以发现安全弱点。这本质上涉及尝试闯入自己的（或客户的）系统。渗透测试的存在是为了让组织利用资源（外部或内部）尝试闯入其网络或系统，并可能对其发起攻击，以获取有关其网络漏洞的信息，从而评估其风险级别。

渗透测试不仅寻找漏洞，还搜索**漏洞利用**数据库（旨在利用特定漏洞的计算机程序）。这些漏洞利用可用于向目标系统投递载荷，从而授予黑客对该系统的访问权限。

渗透测试是外部安全公司的一项蓬勃发展的业务。这项服务可以成为帮助组织发现其网络漏洞的宝贵工具。然而，也有许多开源渗透测试工具可供个人或组织使用。某些 Linux 发行版不仅包含渗透测试实用程序，还包含**漏洞模拟器**，可作为这些测试的目标进行部署。

## 渗透测试流程

有多个用于进行渗透测试的标准框架和方法论。以下是一些最著名的渗透测试框架：

*   开源安全测试方法论手册（OSSTMM，`www.isecom.org/research.html#content5-9d`）
*   渗透测试执行标准（PTES，`www.pentest-standard.org`）
*   NIST SP 800-115（`https://csrc.nist.gov/publications/detail/sp/800-115/final`）
*   信息系统安全评估框架（ISSAF，`www.oissg.org/issaf`）
*   开放 Web 应用安全项目测试指南（OWASP，`http://owasp.org/www-project-web-security-testing-guide`）
*   洛克希德·马丁网络攻击链（`www.lockheedmartin.com/en-us/capabilities/cyber/cyber-kill-chain.html`）

每种渗透测试方法论都有其自己的渗透测试流程方法。然而，所有方法都共享渗透测试流程的三个一般阶段：

*   **谈判**：定义并商定测试范围
    *   商定涉及人员。
    *   承诺采用的交战规则。
*   **渗透测试**：实施攻击
    *   评估风险。
    *   进行发现。
    *   制定测试计划。
    *   进行技术安全测试。
*   **文档编制**：生成报告和文档
    *   分析测试结果。
    *   发布并交付测试结果。

### 谈判渗透测试

渗透测试员用于研究和攻击网络的技能与**黑帽黑客**用于获取组织网络访问权限的技能没有区别。然而，主要区别在于合法的渗透测试员是**白帽黑客**，他们不会利用技能窃取有价值的敏感信息或破坏组织财产。相反，他们将生成并提供一份给组织的报告，称为**简报**。该简报将重点介绍测试期间发现的组织安全策略和实践中的薄弱环节，包括黑客如何绕过网络边界防御以获取访问权限等项目。

在公司聘请外部渗透测试组织或公司进行测试的情况下，双方将确定谁在测试中扮演什么角色。通常有三组：

*   **红队**，实施攻击
*   **蓝队**，通常由受害者组成（即网络管理员）
*   **白队**，监控测试

人们最初可能会认为渗透测试公司只会进来执行一套完整的攻击，以确保网络 100% 经过漏洞测试。然而，通常情况并非如此。在测试开始之前，渗透测试员和客户必须谈判并明确建立测试的确切参数。

例如，许多渗透测试公司认为，既然黑客对可以或不可以攻击的内容没有限制，渗透测试员也不应有限制。这个想法非常合理，但会让一些公司感到不安，这就是为什么要花费大量时间来定义可以攻击的内容。

对于公司来说，设置一个合理的攻击时间窗口也很重要。在这种情况下，公司知道如果在该窗口之外发生违规，那不是渗透测试员，而是真正的恶意攻击。

此阶段必须定义的关键项目包括：

*   **要完成什么？** 也许公司遇到了网络钓鱼攻击问题，用户无意中泄露了密码。在这种情况下，目标将是减少成功的网络钓鱼尝试次数。
*   **可以攻击哪些系统（人员或其他），以及持续多长时间？** 例如，如果我正在进行网络钓鱼攻击，渗透测试员不一定对攻击目标范围之外的事物感兴趣。请记住，根据公司的运营方式，这可能是一个非常模糊的领域，通常是白队管理员难以定义的最大领域之一。
*   **蓝队中谁会知道这次攻击？** 假设你正在进行社会工程学攻击，目标是渗透公司以获取服务器机房的访问权限。当你在走廊里走得很可疑时有人质疑你会怎样？如果他们要求出示证件，而你无法从前台获得访客证件会怎样？也许他们只是把你护送出大楼。然而，如果这发生在大楼关闭的夜晚，结果可能会截然不同，你可能最终会被戴上手铐。将公司联系人设为快速拨号，或拥有首席信息安全官（CISO）或首席安全官（CSO）的授权信会非常方便。换句话说，重要的是公司里有人知道，但他们不参与测试本身。这样，如果发生意外情况，你可以迅速联系那个人并解释情况。
*   **法律问题**：关于道德和非道德黑客行为有许多法律。公司需要知道他们将面临什么，渗透测试公司需要知道在地方、州和联邦层面什么是合法和非法的。公司需要确保渗透测试员已签署联邦法律要求的所有必要保密和不披露协议。

### 渗透测试类型

一旦渗透测试的细节经过谈判并达成一致，下一阶段涉及执行已商定的各种攻击。基本上，渗透测试可以在三种场景下进行：

*   **黑盒测试**：黑盒渗透测试是一种渗透测试方法，其中道德黑客对被攻击的系统或网络基础设施没有任何事先了解，客户公司也不提供此类关键细节。
*   **白盒测试**：白盒渗透测试是一种渗透测试方法，其中道德黑客对被攻击的系统或网络基础设施拥有完全和完整的了解。
*   **灰盒测试**：进行灰盒渗透测试的道德黑客将对其尝试攻击的目标系统或基础设施拥有部分了解。

### 黑盒渗透测试

请花一分钟思考一下，当你被蒙上眼睛时，你能看到周围的什么。你只能看到黑暗和黑色。你无法看到周围世界的任何信息。没有任何物理细节可供参考，你必须依靠其他感官来摸索前行。**黑盒渗透测试**与此类似。

**黑盒渗透测试**的最终目标是尝试模拟外部实体对客户基础设施的攻击，因为除非攻击者是内部威胁，否则外部实体不应有权访问公司网络基础设施和防御措施的内部细节，如图 9.4 所示。
