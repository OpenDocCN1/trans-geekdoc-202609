func merge(a, b []int) []int {
	ret := make([]int, 0, len(a)+len(b))
	i, j := 0, 0
	for i < len(a) && j < len(b) {
		if a[i] < b[j] {
			ret = append(ret, a[i])
			i++
		} else {
			ret = append(ret, b[j])
			j++
		}
	}
	ret = append(ret, a[i:]...)
	ret = append(ret, b[j:]...)
	return ret
}

  ..

  if lvl <= maxLevel {
    lvl++
    // 每次拆分我们会有 2 个 goroutine。

    // 并发对左侧排序。
    go func() {
      l = numCPU(n[:i], lvl)
      wg.Done()
    }()
    // 并发对右侧排序。

      r = numCPU(n[i:], lvl)

    }()

    wg.Wait()
    // 将元素排序并合并有序列表。

  l = numCPU(n[:i], lvl)
  r = numCPU(n[i:], lvl)

第二个结构体类型名为 `list`，通过指向 `first` 和 `last` 来表示节点集合。这些字段分别指向链表中的节点，就像节点中的 `next` 和 `prev` 字段一样。

```go
func (l *list[T]) add(data T) *node[T] {
    n := &node[T]{
        data: data,
        prev: l.last,
    }
    if l.first == nil {
        l.first = &n
        l.last = &n
        return &n
    }
    l.last.next = &n
    l.last = &n
}
```

集合。使此函数正常作用的关键是对每个类型为 T 的值调用 `String()` 方法。

问题在于，编译器需要获知并验证类型为 T 的值确实具有名为 `String` 的方法。在声明泛型类型 T 时，提供了 `fmt.Stringer` 接口作为约束。现在编译器知道要检查传递给函数的任何类型替换和数据是否具有该行为方法集。

这非常棒，因为接口再次被用于相同的目的，且语言不需要新的关键字。
