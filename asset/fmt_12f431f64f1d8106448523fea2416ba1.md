
`traceroute` 与 `tracert` 在一个关键方面表现不同：`traceroute` 发送 UDP 数据包，而 Windows 上的 `tracert` 发送 ICMP 数据包。这意味着您可能会收到路径上主机的不同响应。然而，每个测试过程的基本功能是相同的：生存时间 (TTL) 值从 1 开始设置，并随每个发送的数据包递增。路由器将 TTL 减 1，丢弃 TTL 为 0 的数据包，并针对这些数据包发回 ICMP 超时消息。这会告诉 `traceroute` 路径中每一步的路由器是哪个。您还会注意到显示了延迟信息，这有助于识别是否存在缓慢或有问题的链路。

`pathping` 是一种 Windows 工具，它也可以追踪到目标的路由，同时提供延迟和丢包信息。`pathping` 在一段时间内计算数据，而不是单次路径遍历，从而提供关于网络上可能发生情况的更多见解，但它可能会慢得多，因为每一跳都有 25 秒的时间来收集统计数据。图 12.6 显示了针对 `www.wiley.com` 的 `pathping`。

![图 12.6 www.wiley.com 的示例 pathping](img/c12f006.png)

**图 12.6** `www.wiley.com` 的示例 `pathping`

### 系统级网络信息

收集关于系统的网络信息是技术人员的另一项常见任务。Security+ 考试重点关注四种常在本地系统上运行以收集其网络配置和状态信息的工具：

*   `ipconfig` (Windows) 和 `ifconfig` (Linux) 显示其运行所在主机的当前 TCP/IP 网络配置。这将包括系统上存在的接口、IPv4 和 IPv6 IP 地址、与这些接口关联的 MAC 地址、连接速度、网络掩码、广播域以及关于连接的其他详细信息。这两个命令也可用于启用和禁用接口、刷新或释放 DHCP 地址以及控制网络接口。

*   `netstat` 按协议提供网络统计信息，包括每个连接的本地地址和远程地址，以及 TCP 连接的状态。其他统计信息（如按进程 ID 列出的开放端口、网络接口列表和服务）在不同版本中的可用性各不相同。

*   `arp` 提供关于本地主机 ARP 缓存的信息。在 Windows 系统上，使用 `-a` 标志将显示系统上每个接口的当前 ARP 缓存，但在 Linux 系统上，相同的标志将显示 ARP 信息的另一种格式。`arp` 可用于从 ARP 表中添加和删除主机，并作为被动侦察工作的一部分。

*   `route` 用于显示和修改系统的路由表。与此处列出的许多其他工具一样，`route` 的功能和标志在 Windows 和 Linux 之间有所不同。尽管命令行有差异，但这两个工具都具有添加、显示和删除路由的相似底层功能。

### 端口和漏洞扫描

扫描系统、端口和漏洞是安全从业者和网络管理员的常见任务。发现设备、识别它们提供的服务以及存在的任何漏洞，对于防御者、渗透测试团队和攻击者来说都是必要的。许多工具可以执行这些功能，但 Security+ 考试重点关注两种常用工具和一类通用工具：`nmap`、Nessus 和 *IP 扫描器*。

`nmap` 是一款非常流行的端口扫描工具，适用于 Windows 和 Linux。它可以扫描主机、服务、服务版本和操作系统，并可通过脚本提供额外功能。基本的 `nmap` 用法非常简单：`nmap [` *`主机名`* 或 *`IP 地址`* `]` 将扫描一个系统或网络范围。其他标志可以控制扫描类型，包括 TCP 连接、SYN 和其他扫描类型、端口范围以及许多其他功能。

图 12.7 显示了对一个开放多种服务的示例系统的 `nmap` 扫描。您会立即注意到潜在的脆弱服务，如 FTP、两个数据库服务、IRC 以及各种其他有趣的服务。管理员可以使用端口扫描来识别意外的系统和服务，并检查他们可能无法直接访问的系统上的配置更改。

![图 12.7 来自系统的示例 nmap 扫描](img/c12f007.png)

**图 12.7** 来自系统的示例 `nmap` 扫描

*Nessus* 是一款漏洞扫描工具。虽然 `nmap` 只会识别正在运行的服务的端口、协议和版本，但 Nessus 会尝试识别该服务是否存在漏洞，并提供这些漏洞的完整报告及有用信息，包括文档和修复程序的参考。Nessus 的替代品（如开源的 OpenVAS 和商业工具 Rapid7 的 Nexpose）也常与 Nessus 一起部署，但 Security+ 考试大纲重点关注 Nessus。

IP 扫描工具还有许多其他选择，范围从使用 `netcat` 测试开放端口的简单选项，到 Angry IP Scanner 和 Spiceworks IP Scanner 等完整工具。还有许多其他工具存在，并且可能在你合作的组织中被使用。它们都基于相似的原则运行：它们尝试连接系统，然后连接到它们配置扫描的每个 IP 地址或系统上的每个端口，并报告发现的内容。

#### 数据传输和通用工具

`netcat` 常被称为网络界的“瑞士军刀”，因为它可用于多种用途。它也是一个非常小的程序，这意味着它可以轻松传输到可能需要 `netcat` 这类工具的系统上。`netcat` 可用于抓取横幅以确定服务类型等简单用途。它可以提供本地或远程 Shell，允许与服务建立原始连接，传输文件，并允许你与 Web 服务器交互。

使用 `netcat` 连接服务非常简单：

```
nc [hostname] [port]
```

随后可以直接发出 SMTP 或 HTTP 等命令。

`netcat` 既可以充当监听器，也可以充当客户端，从而允许执行 Shell 操作或文件传输。使用 `netcat` 进行文件传输首先需要设置一个监听器：

```
nc -lvp [port] > /home/example/file.txt
```

然后使用 `netcat` 下载文件很简单：

```
nc [listener IP] [port] < /file/location/for/download/file.txt
```

`netcat` 用途广泛，意味着它可用于许多目的。你甚至可以用 `netcat` 进行端口扫描！

`curl` 实用程序常见于 Linux 系统，用于通过 URL 传输数据。这意味着它常被用于手动执行 HTTP `get` 等 HTTP 命令，或获取 HTTP 头部。它也可用于通过 FTP、FTPS 和 SFTP 传输文件，以及用于各种使用 URL 的协议的通用目的。使用 HTTP `get` 检索页面的示例 `curl` 命令如下：

```
curl --request GET https://www.example.com
```

此类别中的最后一个通用工具是 `hping`，一种用于组装和分析 TCP/IP 数据包的工具。渗透测试人员和安全分析师有时需要构建自定义数据包来测试问题或漏洞，或查看防火墙是否会正确响应。使用 `hping` 进行分析还可以提供操作系统指纹识别等信息，或根据数据包详情帮助推测系统上线时长。它适用于 Linux 和 Windows，使其成为在各种情况下都有用的工具。

收集情报的另一种方法是使用 `scanless`，这是一种利用第三方扫描器收集信息的端口扫描器。`scanless` 工具利用 viewdns、yougetsignal 和 spiderip 等端口扫描器。`scanless` 随后使用这些工具运行端口扫描，而不会暴露运行扫描的系统作为扫描源。基本命令行很简单，返回的端口扫描数据非常类似于 `nmap` 扫描，输出取决于你选择的扫描工具：

此类信息收集工具可以帮助网络管理员和安全专业人员检查其自身网络的配置，也可以帮助渗透测试人员（或攻击者）收集有关目标的信息。作为安全专业人员，你应该了解这些工具及其提供的信息类型，以便选择合适的工具收集所需信息。

#### 数据包捕获和重放

对于需要识别攻击、执行被动侦察，并在渗透测试期间记录其在网络上自身行动的安全专业人员来说，捕获和分析网络流量的能力非常重要。许多 Linux 和 Unix 系统默认提供 `tcpdump`，这是一款命令行数据包捕获工具。它可以使用各种过滤和输出选项捕获数据包。由于网络流量可能很大，使用 `tcpdump` 捕获到文件通常是个好主意。一个典型的 `tcpdump` 命令行，用于将 Linux 系统主网络接口上 TCP 端口 80 的流量捕获到 PCAP 文件，如下所示：

```
tcpdump -w capture.pcap -i eth0 tcp port 80
```

### 摘要

安全专业人员需要了解企业安全网络中使用的关键安全概念，以及如何实施安全网络设计。网络分段和网络访问控制等关键要素确保系统和设备位于适当的安全区域中，并且只有期望的系统连接到网络。端口安全等保护措施可防止已连接机器发起的攻击影响网络，而 VPN 则通过公共或不受信任网络中的隧道连接网络和系统。

许多安全工具都可作为安全设备和装置使用。通过跳板机进行安全访问，让管理员能够安全地跨越安全边界。负载均衡器、代理、NAT 网关和内容过滤器都为网络设备提供保护，而防火墙、IDS 和 IPS 设备以及 DLP 工具则提供专注的安全功能。安全和设备管理设计选项包括带外管理技术、访问控制列表、服务质量功能、路由协议安全选项、DNS 安全配置、广泛使用 TLS 和启用 TLS 的服务、监控工具，甚至包括用于捕获和分析攻击者工具及技术的工具。

使用安全协议和服务代替不安全版本，以及了解每种协议和服务的局限性和实施要求也很重要。一旦攻击者进入网络，他们将尝试访问网络流量，安全协议将有助于确保攻击者拦截的流量不易被其访问。安全电子邮件、FTP、HTTP 和 Secure Shell 等选项都是安全网络设计工具包的一部分。

即使所有这些防御措施都已到位，你仍需能够识别多种攻击：中间人攻击、第 2 层攻击、DNS 攻击和分布式拒绝服务攻击，包括运营技术攻击。这些攻击各自具有可识别的特征，范围从流量模式到交换机行为。
