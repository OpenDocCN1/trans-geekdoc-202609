
当唐纳德·D·特朗普当选美国总统时，他正式提高了对中国出口产品的关税，发起了 2019 年针对中国的贸易战，其理由包括：(i) 中国长期的大贸易顺差减缓了美国就业工作的创造；(ii) 中国对知识产权的非法和不公平获取；以及 (iii) 中国对美国领导的国际体系及其自身国家安全的影响 [19]。尽管美国发动贸易战是为了维护其经济利益，但不同学者对这场贸易战的影响有不同意见。Li 和 Lin 基于数值模拟结果认为，在贸易战谈判中，美国获得的比中国多，并证实了美国的议价能力比中国强 [20]。相反，Waugh 利用贸易冲击对消费影响的证据表明，中国的报复性关税将导致美国出现集中的损失 [21]。一个更通用的论点是，中美两国都无法在贸易战中获胜，只有通过合作才能实现双赢局面。Berthou 等人基于一个多区域动态一般均衡模型得出结论，没有人能在贸易战中获胜，且全球实际 GDP 总额在两年后下降了多达 3% [22]。

贸易战提供了一个自然实验，以识别民族主义对世界上两个最大经济体之间经济冲突的影响。然而，与民族主义研究的一个重要问题是如何准确衡量它。由于国家关系是一个相对抽象的概念，在这项研究中，我通过报纸的文本数据来量化民族主义。事实上，民族主义与媒体是紧密结合在一起的。

## 2.3 媒体与审查系统

Montiel 等人调查了国际冲突期间国家媒体民族主义的产生 [23]。民族主义对公共媒体也有影响。通过研究 2016 年 9 月 29 日的印巴军事冲突，Pandit 和 Chattopadhyay 认为，印度媒体始终坚持爱国的战斗言调，并有意识地掩盖了少数声音的分歧 [24]。媒体报道与民族主义之间的强相关性使我们能够将媒体作为衡量指标的指标。使用新闻文章允许我们衡量民族主义，另一个问题是某些政府使用的审查系统。中国的审查系统限制了对政权有害的信息报道。通常，这种媒体审查被视为维护政权和控制公众情绪的一部分。广泛认为威权限制了媒体独立性。例如，Lorenz 认为中国会战略性地调整报告数量 [25]。King 等人对社交媒体进行文本分析，比较了实施审查前后的内容，表明审查是为了防止未来可能发生的活动 [26]。从当局的角度来看，审查是确保新闻内容符合政府利益的手段。因此，通过比较贸易战这一自然实验期间两国民族主义的影响差异，可以识别媒体审查系统的影响。此外，我们还可以确定贸易战引发的民族主义是否符合政府利益。

## 4.2 新闻情感

为了解释美国（中文）新闻语料库中每篇文章对中国（美国）的观点，我利用情感得分从新闻文章检索情感信息。大规模新闻语料库的一个挑战是设计一种适当且正确的算法，以捕捉不同语言编写的每个文档的情感得分。此外，我们选定的报纸有很多新闻来源，在不同时间提供新信息，因此效率是情感分析算法的另一个重要标准。基于这些考虑，我在文本分析中应用字典法，通过根据预设的正（负）情感字典计算每个情感唤醒词的总频率。为了计算时间 `t` 时文章 `i` 的绝对情感得分 (`Σ`)，我使用位置数 (`p`) 减去负面词数 (`n`)，除以情感唤醒词的总数 (`p+n`)，公式如下：

```
Σ_{it} = (P_{it} - n_{it}) / (P_{it} + n_{it})
```

## 5.2 从审查到民族主义

我使用媒体一致性作为民族主义代理。报纸中的情感一致性是我在解释动态时需要考虑的重要因素。报纸自然地或由于审查关注某些群体；另一方面，新闻一致性取决于当前情绪。我通过跨平台聚合情感并在媒体审查压力下衡量一致性。换句话说，新闻一致性比传统的媒体情感更能解释民族主义。对于每个国家，我定义 `t` 时报纸 `i` 的情感一致性代理 `c_i ∈ [0,1]` 为：

```
c_{it} = 1 / (1 + |Σ_{it}|)
```

其中 `Σ_{it}` 是 `t` 时的平均情感，如第 4.2 节所述，`Σ̄_i` 是 `t` 时所有新闻的平均值。
