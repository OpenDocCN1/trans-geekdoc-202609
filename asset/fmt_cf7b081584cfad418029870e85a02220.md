
![Equation](img/si348.png)

其中，值矩阵 $V \in \mathbb{R}^{(N + 2) \times d_{v}}$ 现在对应于编码器的 $N + 2$ 个输出。注意力矩阵第 $n$ 行的向量为

$$
\mathbf{z}_{n}^{\prime} = \sum\limits_{j = 0}^{N + 1}s_{nj}\mathbf{v}_{j},\ n = 0,1,\ldots,N^{\prime} + 1.
$$

![Equation](img/si350.png)

换句话说，在这一层中，解码器的更新嵌入表示为与编码器输出相关联的值向量的线性组合。这非常合理。解码器的最终输出应该是对编码器输入序列的响应。然而，编码器的输入在其输出处的嵌入向量中得到了最优表示，这些向量编码了驻留在输入序列中的丰富上下文信息。

**步骤 6**：在最后一步中，计算相应的 Head 矩阵，即

$$
\text{Head} = \text{Attention}(Q, K, V)W^{0} \in \mathbb{R}^{(N^{\prime} + 2) \times d_{m}}.
$$

![Equation](img/si351.png)

推广到多头情况是直接的，它遵循与第 19.3.6 节相同的理念。

图 19.13 中解码器块的其余层，即两个“Add & Normalize”层和全连接网络层，具有与编码器块中对应层相同的结构。

#### Transformer 推理过程

一旦通过反向传播算法完成训练，所有未知参数均已被估计并固定。换句话说，我们已经获得了与编码器和解码器部分中所有层和块的所有 `W^(q)`、`W^(k)`、`W^(v)`、`W⁰` 矩阵相关的参数，以及定义所有全连接网络和词汇嵌入矩阵的参数的估计值。

在推理期间，一个词序列被呈现给编码器的输入端，Transformer 网络通过在解码器提供相应的输出来进行响应。让我们专注于我们的翻译示例。

##### 步骤 1：输入分词

输入序列“Je suis étudiant”通过词汇和位置嵌入进行分词，并用 `⟨SOS⟩` 和 `⟨EOS⟩` 标记的相应嵌入进行增强，以形成序列 `x[0], x[1], …, x[4]`，该序列被送入第一个编码器块。

##### 步骤 2：编码器输出

编码器相应的输出嵌入 `h[0]^(L), h[1]^(L), …, h[4]^(L)` 被送入解码器的所有块中，具体是在各自的编码器-解码器注意力层中。

##### 步骤 3：解码器自回归生成

以下子步骤按顺序进行：

###### 1. n = 0

解码器输入由 `y[0]` 组成，它被设置为等于对应于 `⟨SOS⟩` 标记的嵌入。解码器通过为输出 `ŷ_0` 分配值来进行响应。该向量的值是条件概率，条件是编码器处的输入序列以及 `⟨SOS⟩` 的嵌入。在 `ŷ_0` 中，经过硬阈值操作后，值最大的元素的维度 `i` 被选中，这被认为是解码器决定的词汇单词的 id。以我们的例子为例，假设决策是正确的，如果单词“I”的词汇索引是 1524，那么 `ŷ_0` 中值最大的维度应该等于 `i = 1524`。

###### 2. n = 1

解码器输入由 `y[0], y[1]` 组成，其中 `y[1]` 是与“I”相关的嵌入。解码器将响应一个新的输出向量 `ŷ_1`。经过硬阈值处理后，值最大的元素所关联的维度指示了在此步骤决定的单词的 id。以我们的例子为例，这个维度应该等于 235，因为这是我们假设的单词“am”的 id。

###### 3. n = 2

解码器输入变为 `y[0]`、`y[1]`、`y[2]`，其中后者是与单词“am”相关联的嵌入向量。随后解码器将产生一个新的输出，`ŷ₂`，预期该输出将导致对单词“a”的预测。

上述过程将重复进行，直到预测出令牌 `⟨EOS⟩` 并使算法停止。在本例中，我们预期 `ŷ₄` 中数值最大的元素出现在对应于序列结束符号 ID 的维度上。表 19.1 总结了推理任务的上述步骤。

####### 表 19.1 推理阶段的解码器输入与输出序列

嵌入向量 `y[0]` 对应于 `⟨SOS⟩` 符号。

| 解码器输入 | 解码器输出 |
| :--- | :--- |
| n = 0: `y[0]` | `ŷ₀ → I → y₁` |
| n = 1: `y[0]`, `y[1]` | `ŷ₀, ŷ₁ → am → y₂` |
| n = 2: `y[0]`, `y[1]`, `y[2]` | `ŷ₀, ŷ₁, ŷ₂ → a → y₃` |
| n = 3: `y[0]`, `y[1]`, `y[2]`, `y[3]` | `ŷ₀, ŷ₁, ŷ₂, ŷ₃ → student → y₄` |
| *n* = 4: `y[0]`, `y[1]`, `y[2]`, `y[3]`, `y[4]` | $\widehat{\mathbf{y}}_0, \widehat{\mathbf{y}}_1, \widehat{\mathbf{y}}_2, \widehat{\mathbf{y}}_3, \widehat{\mathbf{y}}_4 \rightarrow \langle \text{EOS} \rangle \rightarrow \text{STOP}$ |

前面的算法是次优的。这是因为在每一步中，我们针对单个量（单个向量最大值的维度）进行优化，同时保持先前的决策固定。实践中已提出并使用了更复杂的方案。例如，在*波束搜索*算法中（如文献 [177]），每个阶段会选择多个（条件）概率值（例如最大的 *K* 个，*K* = 5 为典型值），并将其随时间传播。尽管这种算法仍然是次优的，但通过这种方式，最终决策基于依赖于连续符号组合的信息，而非单独依赖每个阶段。

## 19.4 GPT：生成式预训练 Transformer

[189] 中 Transformer 网络的发表在理论和应用层面都引发了新一轮研究热潮，并提出了许多源于基本思想的变体。在 NLP 任务框架下，最早的尝试包括 GPT [147] 和 BERT [43] 模型。除了之前讨论的翻译任务，这些网络还被用于广泛的其他 NLP 任务，如文本蕴含、问答、语义相似度评估、情感分析、文档分类和文本生成。

第一个*生成式预训练 Transformer*，即 GPT-1，建立在一个相当古老的思想之上（例如第 19.2.2 节）。首先，使用无标签数据预训练一个网络。预训练阶段完成后，描述网络的学习参数被用作下一阶段监督学习的初始估计。在后者中，使用有标签数据进行所谓的微调以适应特定任务。根据预训练的类型，会产生不同的方法。我们将在第 19.6 节更详细地讨论此类技术。

在 GPT 中，预训练期间，Transformer 网络被训练以学习预测/生成输入分词文本序列的下一个词，记为 $\mathcal{U} = \{\mathbf{u}_1, \mathbf{u}_2, \dots, \mathbf{u}_N\}$，在目前的讨论中，*N* 代表所有令牌，包括特殊符号的令牌。与包含编码器和解码器两部分的原始 Transformer 网络不同，GPT 仅采用一堆 Transformer 块。每个块包含：a) 一个掩码自注意力层，b) 一个残差“加法与归一化”层，c) 一个前馈全连接网络，以及 d) 一个最终的残差“加法与归一化”层，见图 19.14。换句话说，其结构类似于图 19.13 完整 Transformer 网络的解码器块，忽略了编码器-解码器注意力层及其上方的“加法与归一化”层。本节旨在阐述 GPT 背后的总体思想，而不深入细节，详情请参阅相关文献。

![Figure 19.14 Each block of the GPT architecture consists of four layers. The outputs of each layer become the inputs to the layer above. The input sequence embeddings, un, n = 1,2,...,N, feed the first in the hierarchy block.](img/gr014.jpg)

**图 19.14** GPT 架构的每个块由四层组成。每层的输出成为上一层的输入。输入序列嵌入 `u[n]`，*n* = 1,2,...,*N*，馈送给层级中的第一个块。

### 预训练

类似于公式 (19.44) 的概念，预训练期间，代价函数建立在条件概率之上，即

### 19.4 GPT：小样本学习器

$$J_{1}(\mathbf{\theta}) = \sum\limits_{\mathcal{U}}\sum\limits_{n}\ln P(\mathbf{u}_{n}|\mathbf{u}_{n - 1},\mathbf{u}_{n - 2},\ldots,\mathbf{u}_{n - k};\mathbf{\theta})$$

其中 `θ` 是网络中涉及的所有参数的集合。在 GPT 中，`k` 是所谓的*上下文窗口*的大小。换句话说，`k` 决定了参与条件概率的过去信息的窗口。当然，由于 GPT 不涉及单独的编码器，条件概率仅取决于过去的输入标记。第一个求和是对语料库中所有可能的文本序列进行的。换句话说，GPT 被预训练为执行非线性预测器的任务。

请注意，对于下一个词预测，Transformer 最后一个块的顶部会使用一个额外的网络，该网络首先将输出线性变换回词汇表的维度，随后接一个 softmax 非线性层。这正是 图 19.9 中解码器所用技术的完全相同应用。因此，在 GPT 中，单个 Transformer 块堆栈可被视为同时充当编码器和解码器。

预训练相关的主要思想是：通过强迫网络利用大量未标注语料库学习预测，它等效地学习了驻留在相关数据类型中的基本结构和上下文信息。通过挖掘这些信息，网络可以在顶层块的输出处编码出一种*通用表示*，随后只需少量适配即可迁移到广泛的任务中。这一基本原理直接源自第 18.16 节讨论的迁移学习，并将成为第 19.6 节的主题。

#### 监督微调

预训练完成后，可以使用训练好的 Transformer 执行监督学习 NLP 任务，例如本节开头提到的那些任务。例如，在情感分析或文档分类任务中，给定一个包含 `M` 个标记的序列，即 $\mathcal{X} = \{\mathbf{x}[1], \mathbf{x}[2], \ldots, \mathbf{x}[M]\}$ 及其对应的类别标签 `y`，目标是最大化条件概率 $P(y|\mathcal{X})$。

在微调期间，一个由新参数集 `w` 参数化的额外网络会被添加到预训练 Transformer 网络最后一个块的顶部。这不同于预训练期间使用的额外网络（该网络将向量转换为词概率）。例如，对于分类任务，微调期间采用的额外网络的目标是将最后一个 Transformer 块的输出转换为*类别*概率。这是通过首先应用 a) 线性变换将相应输出带入由特定任务决定的正确维度（例如类别数量），随后 b) 通过 softmax 非线性将最终输出转换为类别概率来实现的。该额外网络的权重通过最大化关于 `w` 的代价函数来学习，

$$J_{2}(\mathbf{w}) = \sum\limits_{(y,\mathcal{X})}\ln P(y|\mathcal{X}).$$

在微调期间，也可以结合公式 (19.51) 和 (19.50) 并关于 `θ` 和 `w` 进行优化。换句话说，不必将预训练 Transformer 的参数固定在预训练期间获得的最优值，而是可以将它们用作初始估计，并在针对特定监督学习任务的微调过程中获得更新后的估计。然而，请注意，由于当今模型的规模非常大，这种替代方案在实践中可能没有用处。

### 19.4.1 GPT：小样本学习器

原始 GPT 架构采用微调来完成下游任务。然而，在语言处理中，这可能仍然需要数千到数万个学习样本的数据集，参见 [27]。这与人类形成对比，人类可以通过从少量示例或简单指令中泛化来执行新的语言任务。为了弥合这一差距，GPT 的后续版本用采用 *meta-learning* 理论的方法，替代了针对每个特定下游任务都需要的微调步骤。^(¹³⁹)

正如 [27] 所指出的，在预训练期间，语言模型会发展出一套 *broad set of skills* 和 *pattern recognition abilities*，这些能力以某种方式编码在学习到的参数中。这些“知识”随后可在 *inference* 阶段用于适应或识别特定任务，例如翻译、问答等。此外，事实证明，这种“上下文”学习能力可以随规模显著提升。为此，GPT-1 的后续版本，如 GPT-2 ([148]) 和 GPT-3 ([27])，其规模比 GPT-1 大得多。表 19.2 总结了相关数字。

*Zero-shot setting*：在此设置中，仅给出任务描述，不提供任何示例。

## 19.5 BERT：来自 Transformers 的双向编码器表示

GPT 系列构建于单个 transformer block 栈之上，采用 masked self-attention 机制。换句话说，GPT 是 *unidirectional* 语言模型，每个 token 只能关注序列中的前序 token。
