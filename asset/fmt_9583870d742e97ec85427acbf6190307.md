
## 术语表

### node

网络上的每个设备。节点可以是工作站、打印机、路由器或文件服务器。

### normal backup

也称为完全备份，复制所有选定的文件并将每个文件标记为已备份。

### nslookup

一种 `TCP/IP` 命令行实用程序，用于排查 `DNS` 名称解析问题。

### NTFS

参见 New Technology File System。

### object

在计算中，几乎所有东西都是对象。文件是对象，窗口也是对象。对象具有类型、各种属性和一组操作。它们可以是物理设备（如 `COM` 端口），也可以是抽象的（如线程）。

### offline backups

保持脱机状态的备份。它们从服务器操作中移除，需要加载介质（通常是磁带）才能恢复。

### offline storage

一种介质类型（如磁带），用于存储数据备份且不易访问。必须将数据从磁带复制回硬盘才能访问。

### off-site storage

一个与文件服务器分开的位置，用于存储备份磁带。完整备份应始终保存在异地。

### online backups

存储在联机状态的备份，以便立即可用。

### Open Systems Interconnection (OSI) model

这是 `PC` 网络中使用最常见的网络模型，由七层组成：应用层、表示层、会话层、传输层、网络层、数据链路层和物理层。

### OSI

参见 Open Systems Interconnection。

### packet

通过网络作为一个整体传输的小的、可管理的数据片段。数据包必须包含头部部分、数据部分，在大多数情况下还包含循环冗余校验 (`CRC`) 部分，也称为尾部。

### PAP

参见 Password Authentication Protocol。

### partition

物理磁盘的一个逻辑划分，被视为一个独立的硬盘。对硬盘进行分区后，需要决定哪个分区将作为系统分区，哪个将作为活动分区。另请参阅 active partition 和 system partition。

### pass-through authentication

当您的凭据不在本地目录服务数据库中时发生。

### password

登录期间访问网络的密钥。

### Password Authentication Protocol (PAP)

一种认证协议，客户端通过将用户名和密码传递给服务器来向其进行身份验证。然后服务器将此信息与其密码存储进行比较。由于密码以明文传递，因此在安全性受关注的环境中不建议使用。

### penetration testing

一种安全测试类型，涉及测试人员使用黑客技术攻破系统，以确定系统是否安全。

### Performance Monitor

一种实用程序，跟踪系统组件和应用程序的资源使用情况，并提供关于网络的性能信息，以帮助定位瓶颈、确定哪些资源过度紧张以及规划系统容量升级。

### permissions

分配给用户的资源（如文件或打印机）的访问权限。

### personally identifiable information (PII)

可用于识别个人身份的信息。

### phishing

一种攻击类型，涉及黑客诱骗某人点击链接，该链接指向一个看起来真实的站点，并试图从用户那里收集个人信息。

### ping

一种命令行工具，用于验证 `TCP/IP` 连接。

### platform

一种计算机系统类型。例如，`Intel x86` 和 `UNIX` 是平台。

### Point-to-Point Tunneling Protocol (PPTP)

一种较旧的 `VPN` 协议，用于加密 `VPN` 客户端和 `VPN` 服务器之间的通信。

### POP

参见 Post Office Protocol。

### port number

分配给 `TCP/IP` 应用程序的唯一地址。

### port security

大多数交换机上的一项功能，允许您将交换机上的端口配置为仅允许来自具有特定 `MAC` 地址的系统的连接。

### Portable Operating System Interface (POSIX)

电气和电子工程师协会 (`IEEE`) 基于 `UNIX` 开发的一种用于文件命名和标识的标准。为了符合 `POSIX` 标准，软件必须满足某些要求，例如区分大小写的文件名、硬链接和额外的时间戳。

### POSIX

参见 Portable Operating System Interface。

### Post Office Protocol (POP)

从邮件服务器向客户端下载邮件的协议。`POP3` 邮件服务器将邮件保存在邮件投递箱中，直到工作站准备好接收它。

### PPTP

参见 Point-to-Point Tunneling Protocol。

### 预共享密钥 (PSK)

参与数据加密和解密的双方均知晓的密码或密钥值。

### 打印服务器

控制网络打印并处理打印请求。打印服务器可以是硬件设备，也可以是软件解决方案。

### 属性

对象的一种特征。例如，用户对象有一个“城市”属性，用于描述该用户所在的城市。

### 协议

一组管理格式和交互的规则，使机器能够跨网络进行通信。Windows 支持多种协议，包括 `TCP/IP`、`IPSec` 和 `PPTP` 等。

### 协议分析器

也称为数据包嗅探器，一种用于监控网络流量的工具。

### 代理服务器

位于客户端工作站和 `Internet` 之间的本地服务器，提供安全性，无需每个工作站都直接连接到 `Internet`，并代表客户端访问 `Internet`，使多台计算机能够共用一个 `Internet` 连接。

### 公钥加密

一种由公钥和私钥组成的加密技术。公钥可免费提供给任何需要它的人，而私钥由密钥所有者保密。

### 公共无线网络

由第三方运营的公共数据网络，向用户收取月费以换取无线数据服务。

### RAID

参见 独立（或廉价）磁盘冗余阵列。

### 随机存取存储器 (RAM)

短期存储内存，物理上驻留在计算机的内存芯片上。因为计算机应用程序在处理过程中使用 `RAM`，所以计算机中 `RAM` 的数量是决定计算机运行状况好坏的主要因素。

### RAT

代表远程访问木马 (`RAT`)，是一种恶意软件，它为系统打开一个后门，以便黑客可以连接并控制该系统。

### 独立（或廉价）磁盘冗余阵列 (RAID)

一种具有容错能力的磁盘配置，其中物理存储的一部分包含有关存储在磁盘上数据的冗余信息，从而在访问硬盘数据时发生问题时将数据丢失降至最低。

### 注册表

`Windows` 系统上所有软件和硬件设置的中央数据库。

### 注册表编辑器

一种 `Microsoft` 工具（`REGEDIT.EXE` 或 `REGEDT32.EXE`），用于查看和修改注册表。

### 远程访问服务

在服务器上运行的拨号服务，使用户能够通过电话线远程访问网络。

### 远程身份验证拨号用户服务 (RADIUS)

一种中央身份验证服务器，可用于验证尝试连接到有线或无线网络、拨号连接到 `RAS` 服务器或 `VPN` 连接到 `VPN` 服务器的个人身份。

### 远程过程调用 (RPC)

一种进程间通信 (`IPC`) 机制，程序员利用它创建由多个过程组成的应用程序——一些在本地计算机上运行，另一些则通过网络在远程计算机上运行。此外，也是程序发送到网络上计算机的请求，要求该计算机执行任务。

### 征求意见稿 (RFC)

由 `Internet` 工程任务组 (`IETF`) 发布的文档，定义了 `TCP/IP` 的标准。

### 预留

为特定 `DHCP` 客户端保留的 `IP` 地址。

### RFC

参见 征求意见稿。

### RJ-45 连接器

用于双绞线电缆的连接器。它看起来像电话连接器，但更宽。有八个针脚；因此有八根导线。以太网实现可以使用四根或全部八根导线。如果只使用四根导线，你应该了解的针脚是 1、2、3 和 6。`RJ-45` 跳线既可以直接插在双绞线网络适配器的背面，也可以（不太常见）连接到外部收发器。跳线通常连接到墙面插座，后者通过布线连回配线架，最终连回布线集线器。

### 基于角色的访问控制 (RBAC)

根据分配给用户的角色授予访问权限。

### 根

(1) 目录结构的顶层，在此层之上无法进行引用。(2) `UNIX/Linux` 中的管理员账户。

### route

一种命令，可用于添加、修改、删除以及显示一个或所有接口的路由信息。用于配置网络路由表。

### 路由器

连接多个物理网络或网段的设备。当数据包到达路由器时，路由器读取网络地址，并将其转发到目的地或另一台路由器。

### 路由

将数据包从一个网段转发到另一个网段的过程，直到其到达最终目的地。路由器通过查看接收到的数据包的网络地址，决定将网络数据包发送到何处，然后再将其传递下去。

### 路由表

路由器已知的可用路由列表。路由器利用它来确定数据是否发往本地网络。

### RPC

参见 远程过程调用。

### SAM

参见 安全访问管理器数据库 和 安全账户管理器。

### 可扩展的

具有根据需求进行变更的能力。

### 脚本

一种小型的、未编译的程序，用脚本语言编写，在系统上或网页中执行。

### 密钥加密

使用密钥管理服务器中的一个称为批量加密密钥的单一密钥来加密和解密消息。密钥加密的两个例子是 `DES` 和 `CAST`。

### 安全哈希算法 (SHA)

一种用于验证数据完整性的哈希算法。

### 安全套接字层 (SSL)

一种基于证书的协议，用于加密通信。

### 安全账户管理器 (SAM) 数据库

一种安全数据库，维护 `Windows` 系统上的所有用户和组及其密码和其他属性。

### 安全断言标记语言 (SAML)

一种 `Internet` 标准语言，用于定义与基于声明的身份验证配合使用的安全令牌。

### 安全控制

为保护公司资产而采取的安全措施。安全控制的一个例子是设施周边的围栏，或用于保护网络资源免受 `Internet` 上人员侵害的防火墙。

### 安全描述符

描述对象的安全属性，包含以下部分：所有者安全 `ID`（标识对象的所有者，使该人员能够更改对象的权限）；主组的安全 `ID`（仅由 `POSIX` 子系统使用）；自主访问控制列表（标识被允许和拒绝访问的组和用户）；以及系统访问控制列表（指定哪些事件记录在安全日志文件中）。

### 安全 ID (SID)

在网络上唯一标识每个用户、工作站和服务器。

### 安全事件

发生的导致安全担忧的事件。

### 网段

承载网络广播的一部分网络。

### 服务器

为网络用户提供共享资源的计算机。

### 服务器警报

与服务器和资源使用相关的系统生成的通知消息，发送给用户或计算机。当 `UPS` 服务可用时，服务器警报会针对安全和访问问题、用户会话问题、打印机问题以及因断电导致的服务器关机发出警告。

### 服务器镜像

复制完整的服务器以减轻主服务器的负载。

### 服务

`Windows` 操作系统提供的离散功能单元。

### Service Pack

一种提供新功能、增加更多能力或修复早期版本中 `Bug` 的程序。`Service Pack` 在程序的完整版本发布之间提供软件更新。

### Service Set Identifier (SSID)

无线网络的名称。

### Session

两台计算机之间的可靠对话。因为面向连接的服务可以提供可靠通信，所以当两台计算机需要在会话中通信时会使用它们。会话一直维持到两台计算机决定完成通信为止。会话就像电话通话：通过拨号（握手）建立通话，与对方交谈（交换数据），说“再见”，挂断电话结束。

### Share

一种设置，用于使打印机、光驱和目录等资源可供网络上的用户使用。

### Shell

一种在服务器与客户端之间，或用户与操作系统之间提供通信的程序。

### Shielded Twisted-Pair (STP)

一种双绞线，在导线股与外层绝缘层之间具有箔层屏蔽。

### SID

参见 Security ID。

### Simple Mail Transfer Protocol (SMTP)

一种用于通过互联网发送邮件的协议。

### Simple Network Management Protocol (SNMP)

一种用于监控和配置网络设备的互联网标准。`SNMP` 网络由管理系统和代理组成。

### Single Sign-On (SSO)

只需登录一次，即可访问来自不同环境的资源。

### SMTP

参见 Simple Mail Transfer Protocol。

### Sniffer

一种网络监控工具，用于分析网络上的流量，并有助于解决与基础设施相关的问题。

### SNMP

参见 Simple Network Management Protocol。

### SSID

参见 Service Set Identifier。

### Static Entries

手动添加的条目。这适用于静态配置的路由器（由网络管理员手动更新路由表）、`ARP` 缓存，或 `hosts` 文件和 `DNS`。

### Static Routing

早期路由器使用的一种配置方法。它要求精确编程哪些网络可以在哪些接口之间路由，特别是在有许多网络接口的情况下。

### STP

参见 Shielded Twisted-Pair。

### Stripe Sets Without Parity

类似于卷集，但提供性能增益。这些集合可以将 2 到 32 个空闲空间区域组合为单个卷。但是，空闲空间必须位于不同的硬盘上，且每个硬盘必须包含相同数量的、你想要用于条带集大小的空闲空间。

### Striping Data

同时跨多个驱动器写入数据。`RAID 5` 使用一种在多个硬盘上条带化数据的方法，并包含奇偶校验信息。这些奇偶校验信息分布在各驱动器上，而不是存储在单个硬盘上。

### Structured Query Language (SQL)

数据库用于管理数据库系统和操作数据库中数据的语言。

### Subnet Mask

确定 `IP` 地址中哪些位适用于网络 `ID`，哪些位是主机 `ID` 的一部分。

### Subnetting

将 `IP` 地址范围分解为多个 `IP` 地址范围。

### Switch

一种类似于集线器的网络设备，但仅将数据转发到连接目标地址的交换机端口。交换机用于替代集线器以提高网络性能。

### Symmetric Encryption

发送方和接收方使用单个密钥来加密和解密数据。

### System Administrator

管理网络。此人负责确保网络功能平稳运行（例如，备份完成、网络流量平稳运行、需要时有可用驱动器空间）。

### System Partition

在 `Windows` 中，存放启动所需的硬件特定文件的位置。在基于 `Intel` 的计算机上，活动分区即为系统分区。

### Task Manager

一种用于观察和删除进程的工具；在查看进程和线程时提供更细粒度的详细信息，包括删除单个进程或设置其优先级的选项。

### TCP/IP

参见 Transmission Control Protocol/Internet Protocol。

### Telnet

一种用于远程连接到应用程序或服务器的终端仿真程序。

### Tracert

一种常用的命令行实用程序，通过追踪从源到目标的路由，定位 `TCP/IP` 通信路径上的故障。遇到的每个路由器接口都会回显到屏幕上，并附带一些关于路径计时的统计信息。

### Transmission Control Protocol/Internet Protocol (TCP/IP)

目前最常用的协议。`TCP/IP` 是互联网构建所基于的一种可路由协议。`TCP/IP` 非常健壮，通常与 `Unix` 系统相关联。`TCP/IP` 最初于 1970 年代设计，供国防高级研究计划局 (`DARPA`) 和美国国防部 (`DOD`) 用于连接全国各地的系统。这种设计要求具备应对不稳定网络条件的能力。因此，`TCP/IP` 的设计包含了重新路由数据包的能力。

### Transport Layer

(1) 确保数据可靠交付到目的地的 `OSI` 层。传输层包含两个协议：传输控制协议 (`TCP`) 和用户数据报协议 (`UDP`)。

(2) `TCP/IP` 模型第 3 层所在的 `TCP/IP` 层。传输层的主要职责是提供从一个应用程序到另一个应用程序的通信。

### Transport Layer Security (TLS)

一种基于证书的协议，用于加密通信。

### Tree

`Active Directory` 中共享同一 `DNS` 命名空间的域层次结构。

### Trivial File Transfer Protocol (TFTP)

类似于文件传输协议，但不需要用户身份验证。

### Trust Relationship

两个域之间的连接。建立信任后，一个域的用户可被授予访问另一个域上资源的权限。

### Trusted Platform Module (TPM)

一种用于存储加密密钥的计算机芯片。

### Tunnel

建立 `PPP` 会话时，`PPTP` 在客户端和远程 `PPTP` 服务器之间创建控制连接。

### Twisted-Pair Cable

一种将导线绞合以帮助减少干扰的电缆类型。双绞线有两种类型：屏蔽和非屏蔽。另请参见 Coaxial (or Coax) Cable 和 Fiber-Optic Cable。

### UDP

参见 User Datagram Protocol。

### Unattended Backup

备份程序在计划时间启动，执行指定的备份，然后终止。

### UNC

参见 Universal Naming Convention。

### Uniform Resource Locator (URL)

提供万维网上文档的地址。

### Uninterruptible Power Supply (UPS)

一种常用于文件服务器的电池备份系统，用于在停电时保护数据。

### Universal Naming Convention (UNC)

一种连接到计算机上共享资源的标准化方式。语法始终为 `\\computername\sharename`。

### Unix
