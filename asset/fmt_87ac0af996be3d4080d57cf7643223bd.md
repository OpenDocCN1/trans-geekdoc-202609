## Torch 类 `nn.Linear(1,1)` 用于创建全连接层

## 优化器与学习率调度器

有多种优化器，它们用于计算损失函数的梯度，并在模型训练期间通过 `optimizer.step()` 自动更新模型权重数组。Adam（自适应矩估计）优化器是最流行的。深入研究优化器的数学算法既不容易，也没有必要。

![](img/bk978-0-7503-6244-3ch1uf12_pr.gif)

学习率是模型训练中最重要的超参数。PyTorch 提供了许多学习率调度器，用于在模型训练期间改变学习率。最通用的调度器是 `LambdaLR`。你可以定义任何以训练轮数（`i`）为变量的函数。初始学习率（`lr`[0]）通常在 Cell 01 中为优化器设定，第 `i` 个 epoch 的学习率等于 `lr`[0] 乘以 Lambda 函数的值。

在 Extra-Cell-02 中，第一个函数用于恒定学习率：`lr`[`i`] = 0.5 × `lr`[0]。使用第二个 lambda 函数，学习率在 20,000 个 epoch 的模型训练过程中线性下降。如果选择第三个或第四个函数，学习率将呈指数下降。第五个 lambda 函数与 PyTorch 中的 `CosineAnnealingLR` 调度器相同。第六个 lambda 函数有三个区段：`i` < 10,000，`i` 在 10,000 和 17,000 之间，以及 `i` > 17,000。最后一个 lambda 函数类似于 PyTorch 中的 `StepLR` 调度器。它从一个名为 `lr_list` 的列表中，按索引 `i`//5000 选取一个数字。

### 1.5 用于非线性回归的激活函数

#### 我们的世界因许多现象具有非线性而变得美丽

在计算机视觉项目中，我们必须使用多个神经层来处理非线性数学问题。然而，模型中一系列的多个线性层工作起来就像单个线性层一样。例如，假设我们的模型有两个全连接线性层：`Y[1] = w[1]*X + b[1]` 和 `Y[2] = w[2]*Y[1] + b[2]`，我们将得到 `Y[2] = w[2]*w[1]*X + (w[2]*b[1] + b[2])`，这仍然是一个线性层。

为了避免这一数学问题，我们必须在两个线性层之间添加一个激活函数。激活函数有很多种，它们都是非线性的。以下是四种常用的激活函数类别：

1.  **Sigmoid 类** `nn.Sigmoid()`: `f(x) = 1 / (1 + e^{-x})`
2.  **双曲类** `nn.Tanh()`: `f(x) = (e^{x} - e^{-x}) / (e^{x} + e^{-x})`
3.  **线性整流单元类** `nn.ReLU()`: `f(x) = x (x >= 0), 0 (x < 0)`
4.  **Leaky ReLU 类** `nn.LeakyReLU(0.1)`: `f(x) = x (x >= 0), 0.1x (x < 0)`

我们将在项目 1.5.1 中针对 `y(x) = e^{-5x}` 的非线性回归使用 Sigmoid 类作为激活函数。所有激活函数中的变量 `x` 可以是标量或数组。如果 Sigmoid 函数的输入是数组或矩阵，Sigmoid 函数将逐元素作用于该数组。Sigmoid 函数输出的每个元素值都在范围 `[0, 1]` 内。

在该项目中，根据函数 `y(x) = e^{-5x}` 创建了一个 csv 数据文件，其中 `x` 在 0.0 和 1.0 之间。`x` 数组的长度为 51。我们希望使用一个具有两个全连接层的模型来模拟这个指数函数。
