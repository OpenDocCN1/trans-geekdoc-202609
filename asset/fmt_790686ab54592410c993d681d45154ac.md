### 函数

函数封装重复或复杂的操作，使代码更有条理、高效且可复用。在 R 语言中，函数可以是内置的、用户定义的，或从包中加载的。自定义函数使用 `function()` 关键字定义，后跟函数名称及其参数（在括号中）。函数体则包含在花括号 `{}` 中。让我们为各种业务场景创建一些自定义函数。

#### 电子商务

一个函数，用于计算电子商务网站上某产品产生的总收入，给定产品价格和销售数量：

```r
# 计算总收入的函数
calculate_revenue <- function(price, num_sold) {
  total_revenue <- price * num_sold
  return(total_revenue)
}
```

这里，`price` 是电子商务网站上产品的价格，`num_sold` 是销售数量。该函数将价格与销售数量相乘来计算产品产生的总收入，并返回结果：

```r
# 定义向量以计算收入
price <- c(250, 2099, 1999, 750)
num_sold <- c(1000, 250, 100, 1150)

# 计算每个产品的总收入
total_revenue <- calculate_revenue(price, num_sold)

# 打印结果
total_revenue
```

## 输出

```
## 250000 524750 199900 862500
```

这里，我们定义了两个向量 `price` 和 `num_sold`，分别包含四种不同产品的价格和销售数量。然后我们将这些向量作为参数传递给 `calculate_revenue` 函数，该函数计算每个产品的总收入并返回一个结果向量。

#### 市场营销

一个函数，用于计算营销活动的转化率，给定展示次数和点击次数：

```r
# 计算转化率的函数
calculate_conversion_rate <- function(impressions, clicks) {
  conversion_rate <- clicks / impressions
  return(conversion_rate)
}
```

这里，`impressions` 是营销信息展示的次数，`clicks` 是被点击的次数。该函数通过将点击次数除以展示次数来计算转化率。

你可以将 `calculate_conversion_rate` 函数用于包含展示次数和点击次数的数据向量：

```r
# 定义展示次数和点击次数向量
impressions <- c(1205, 2000, 1532, 4101)
clicks <- c(90, 75, 82, 210)

# 计算每个广告活动的转化率
conversion_rates <- calculate_conversion_rate(impressions, clicks)

# 打印转化率
conversion_rates
```

## 输出

```
## 0.07468880 0.03750000 0.05352480 0.05120702
```

这里，我们定义了两个数据向量 `impressions` 和 `clicks`，分别包含四个不同广告活动的展示次数和点击次数。然后我们将这些向量作为参数传递给 `calculate_conversion_rate` 函数，该函数计算每个活动的转化率并返回一个结果向量。我们也可以使用 `round()` 来对结果进行四舍五入。

#### 金融

一个函数，用于计算贷款的复利，给定本金、利率、贷款期限（年）以及每年计息次数：

```r
# 计算复利的函数
calculate_compound_interest <- function(principal, interest_rate, years, compounding_frequency) {
  n <- compounding_frequency
  interest <- principal * (1 + interest_rate / n)^(n * years) - principal
  return(interest)
}

# 定义向量输入
principal <- c(5000, 7500, 9200)
interest_rate <- c(0.05, 0.06, 0.09)
years <- c(1, 2, 3)
compounding_frequency <- c(1, 2, 4)

# calculate compound interest for each set of inputs
compound_interest <- calculate_compound_interest(principal, interest_rate, years, compounding_frequency)

# view output
compound_interest
```

## 输出结果

```
## [1] 250.0000 941.3161 2815.6599
```

这告诉我们，对于第一组输入（`principal = 5000`，`interest_rate = 0.05`，`years = 1`，`compounding_frequency = 1`），复利将是 250.00 卢比。同样，对于第二组输入（`principal = 7500`，`interest_rate = 0.06`，`years = 2`，`compounding_frequency = 2`），复利将是 941.3161 卢比，依此类推。

> **注意**：虽然 R 会自动返回函数最后一行的值，但显式使用 `return()` 函数来指示函数返回的内容被认为是更好的实践。这有助于使函数更具可读性且更易于理解，特别是对于可能不熟悉该函数行为的其他用户。

例如，下面的 `calculate_revenue` 函数在不使用 `return` 语句的情况下也能工作：

```r
# calculate total revenue (without return statement)
calculate_revenue <- function(price, num_sold) {
  price * num_sold
}
```

### 保存数据

在 R 中，根据你正在处理的数据类型以及想要保存的格式，有多种保存数据的方法。下面讨论其中几种。

#### 另存为 CSV 文件

逗号分隔值（CSV）文件是存储和交换表格数据的常用方式。要将数据另存为 CSV 文件，可以使用 `write.csv()` 函数。示例如下：

```r
# save data as a CSV file
write.csv(netflix_df, file = "Netflix_Data.csv")
```

这将在你的工作目录中创建一个名为 `Netflix_Data.csv` 的 CSV 文件。`file` 参数指定要创建的文件名。

需要注意的一点是，`write.csv()` 默认会在输出文件中包含行名。如果你不想包含行名，可以将 `row.names` 参数设置为 `FALSE`。请参考以下示例：

```r
write.csv(netflix_df, file = "Netflix_Data.csv", row.names = FALSE)
```

这将从输出文件中排除行名。

#### 另存为文本文件

有时，你可能想将数据另存为文本文件而不是 CSV 文件。你可以使用 `write.table()` 将数据另存为文本文件。示例如下：

```r
# Create a data frame
my_data <- data.frame(x = 1:5, y = c("A", "B", "C", "D", "E"))

# Save data as a text file
write.table(my_data, file = "my_data.txt", sep = "\t", row.names = FALSE)
```

这将在你的工作目录中创建一个名为 `my_data.txt` 的文本文件。`sep` 参数指定分隔符（在本例中为制表符），`row.names = FALSE` 从输出中移除行名。

#### 另存为二进制文件

R 提供了将数据另存为二进制文件的功能，这是一种以紧凑高效方式存储数据的文件格式。要将数据另存为二进制文件，可以使用 `saveRDS()` 函数。它创建一个可移植的二进制文件，可以轻松地在不同的 R 安装或版本之间共享和使用。如果你需要与可能未安装相同包或 R 版本的人共享数据，这会特别有用。

与以基于文本的格式（如 CSV）保存相比，使用 `saveRDS()` 以二进制格式保存对象通常更高效。二进制文件体积更小，读写速度快得多。要将数据另存为二进制文件：

```r
# create a sample data
my_data <- list(x = 1:5, y = c("A", "B", "C", "D", "E"))

# save data as a binary file
saveRDS(my_data, file = "my_data.rds")
```

这将在你的工作目录中创建一个名为 `my_data.rds` 的二进制文件。这些只是保存数据的众多方法中的几个示例。根据你的需求，可能还有其他更合适的函数或文件格式。

### R 编码规范

您可以遵循许多约定和最佳实践，以在 R 中编写清晰、高效且可维护的代码。下面列出了一些：

*   R 区分大小写，意味着大写和小写字母会被区别对待。对变量和函数名使用小写字母是一种良好的实践。
*   为变量和函数使用有意义的名称。这有助于提高代码的可读性和可理解性。使用易于理解和记忆的描述性变量名。
*   缩进在 R 中很重要，能让您的代码更具可读性。因此，您应该始终如一地缩进代码，使用空格或制表符。
*   为您的代码添加注释，解释您在做什么以及为什么这么做。这使得其他人（以及未来的您自己）更容易理解您的代码。
*   编写模块化代码。将代码拆分为小型的、可复用的函数，以便在代码的不同部分中使用。这使您的代码更易于阅读、理解和维护。
*   避免使用 R 中已定义的变量名，例如 `mean`、`sum` 或 `sd`。这可能导致意外行为。
*   使用包。R 拥有庞大的包生态系统，可以为您节省大量时间和精力。使用 `dplyr`、`tidyr` 和 `ggplot2` 等包来简化您的代码。
