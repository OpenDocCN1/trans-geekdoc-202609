
请注意，`θ[n−1]` 是基于包括时刻 `n−1` 在内的观测值估计得到的。因此，训练对 (`y[n]`, `x[n]`) 可被视为一个未参与训练的测试样本，用于测量误差。然而，必须指出的是，累积损失*并非*与最终获得的参数向量相关的泛化性能的直接度量。这种度量应涉及 `θ[N−1]`，并针对若干测试样本进行测试。

围绕累积损失建立的一系列方法的目标是推导相应的上界。我们这里的目的是概述此类方法背后的实质，而不求助于证明；这些包含一系列界，可能会变得有点技术性。感兴趣的读者可查阅相关参考文献。我们将在第 8 章所谓的*遗憾分析*背景下，回到累积损失及相关界。

在 LMS 的背景下，文献 [21] 中证明了以下定理。

#### 定理 5.1

令 `C = max_n ||x_n||`，`μ = β / C²`，`0 < β < 2`。则由算法 5.1 生成的预测集合 `ŷ_0, …, ŷ_{N-1}` 满足以下界限：

```
∑_{n=0}^{N-1} (y_n - ŷ_n)² ≤ inf_θ { C² ||θ||² / (2β(1-β)c) + L(θ, S) / ((2-β)² c(1-c)) },  (5.54)
```

其中 `0 < c < 1` 且

```
L(θ, S) = ∑_{n=0}^{N-1} (y_n - θ^T x_n)²,  (5.55)
```

其中 `S = {(y_n, x_n), n = 0, 1, …, N-1}`。

随后可以最优地调整 `β` 以使上界最小化。请注意，这是一个*最坏情况*场景。该调整是通过限制线性函数集来实现的，使得 `||θ|| ≤ Θ`。令

##### 数学推导与分析

`L_Θ(S) = min_{||θ|| ≤ Θ} L(θ, S)`

并且还假设存在一个上界 `L`，使得

`|L_Θ(S)| ≤ L`。

然后可以证明 [21] 可得

```
∑_{n=0}^{N-1} (y_n - ŷ_n)² ≤ L_Θ(S) + 2ΘC√L + (ΘC)².
```

请注意，之前的分析是在未引用任何概率论证的情况下进行的。通过引入不同的假设 [21] 可以推导出替代界。这类涉及类似假设的界，在各种算法的分析中经常遇到。我们将在本书后面遇到此类示例。

##### 备注 5.2

*   **本节提出的分析方法**，关于 LMS 的瞬态和稳态性能，可被视为最原始的一种，其渊源可追溯至 Widrow 和 Hoff 的早期工作 [102]。另一种在平均意义上分析随机算法的流行途径是所谓的*平均法*，它在步长 `μ` 取较小值的假设下运作。另一种建立在步长较小假设 `μ ≈ 0` 周围的方法是所谓的常微分方程法 (ODE) [57]。差分更新方程被“转化”为微分方程，这为利用李雅普诺夫稳定性理论的论证铺平了道路。一种替代的优雅理论工具，可作为分析自适应方案的瞬态、稳态和跟踪性能的载体，即所谓的*能量守恒*法，该方法在 [82] 中提出，后在 [3,105] 中扩展。关于 LMS 以及其他在线方案的性能分析的更多内容，可参阅更专业的书籍和论文 [4,13,47,62,83,91,92,96,103]。

*   **LMS 的 `H^∞` 最优性**。LMS 算法这一非常简单的结构，竟能经受住时间的考验，并成为实际应用中最流行、应用最广泛的方案之一，这可能令人惊讶。原因在于，除了其低复杂度外，它还拥有鲁棒性这一优势。通过估计的 `H^∞` 优化理论，给出了 LMS 算法的另一种优化风味。

*   假设我们的数据服从公式 (5.38) 的回归模型，其中现在不对 `η` 的性质做任何假设。给定输出观测样本序列 `y[0], y[1], …, y[N-1]`，目标是获得 `s[n]` 的估计值 `ŝ[n|n-1]`，其中 `s[n]` 由 `s[n] = θ^(T)x[n]` 生成，基于包括时刻 `n-1` 在内的训练集（因果性），使得

```
(∑_{n=0}^{N-1} |ŝ_{n|n-1} - s_n|²) / (μ^{-1}||θ||² + ∑_{n=0}^{N-1} |η_n|²) < γ².  (5.59)
```

*   分子是总平方估计误差。分母包含两项。一项是噪声/干扰能量，另一项是未知参数向量的范数。假设从 `θ_{-1} = 0` 开始迭代，该项度量了来自初始猜测的干扰能量。结果表明，LMS 方案是使以下代价最小化的方案：

```
γ_opt² = inf_{{ŝ_{n|n-1}}} sup_{{θ, η_n}} ( ∑_{n=0}^{∞} |ŝ_{n|n-1} - s_n|² / (μ^{-1}||θ||² + ∑_{n=0}^{∞} |η_n|²) ).
```

*   此外，结果表明最优值对应于 `γ_opt² = 1` [46,83]。注意，基本上 LMS 优化的是一种最坏情况。它使得在最坏（最大）干扰情况下估计误差最小。这种类型的最优性解释了 LMS 在“非理想”环境下的鲁棒性能，这在实践中经常遇到，此时许多建模假设不再成立。这种偏离模型的情况可以被 `η_n` 所容纳，后者因此“失去”了其独立同分布、白色、高斯或任何其他数学上吸引人的性质。

最后，指出公式(5.59)中的界与公式(5.54)中的界存在相似性，这很有意思。实际上，在前者中我们进行了如下替换：

`ŝ[n|n−1] = ŷ[n], s[n] = y[n], η[n] = y[n] − θ^(T)x[n]`。

忽略常数的值，所涉及的量是相同的。毕竟，`H^∞` 是关于最大化最坏情况的 [55]。

## 5.6 仿射投影算法

正如将在仿真部分验证的那样，基本 LMS 算法的一个主要缺点是其收敛速度相当低。为了改进这一点，多年来提出了许多变体。*仿射投影算法*（APA）属于所谓的*数据重用*家族，其中在每个时刻都会重用过去的数据。这种基本原理有助于算法“学得更快”并提高收敛速度。然而，除了增加复杂度之外，更高的收敛速度是以*增加失调电平*为代价实现的。

APA 最初在文献 [48] 中提出，后来又在文献 [72] 中提出。设当前可用的估计为 `θ[n−1]`。根据 APA，更新后的估计 `θ` 必须满足以下约束条件：

`x[n−i]^T θ = y[n−i], i = 0, 1, …, q−1`。

换句话说，我们*强制*参数向量 `θ` 在其输出端产生最近 `q` 个时刻的期望响应样本，其中 `q` 是用户定义的参数。同时，APA 要求 `θ` 在欧几里得范数意义上尽可能接近当前估计 `θ[n−1]`。因此，APA 在每个时刻求解以下约束优化任务：

```
θ_n = argmin_θ ||θ - θ_{n-1}||² s.t. x_{n-i}^T θ = y_{n-i}, i = 0,1,…,q-1.
```

(5.60)

如果定义 `q × l` 矩阵

### 仿射投影算法推导

```
X_n = [x_n^T; …; x_{n-q+1}^T],
```

则约束集合可紧凑地写为

`X_n θ = y[n]`,

其中

`y[n] = [y[n], …, y[n-q+1]]^T`.

在公式 (5.60) 中使用拉格朗日乘子法（附录 C）可得（问题 5.10）：

```
θ[n] = θ[n-1] + X_n^T (X_n X_n^T)^{-1} e[n],  (5.61)
e[n] = y[n] - X_n θ[n-1].  (5.62)
```

前提是 `X_n X_n^T` 可逆。该算法总结在 算法 5.2 中。

#### 算法 5.2：仿射投影算法

**初始化**

1.  `x[-1] = … = x[-q+1] = 0`，`y[-1], …, y[-q+1] = 0`
2.  `θ[-1] = 0 ∈ R^l`（或任意其他值）。
3.  选择 `0 < μ < 2` 且 `δ` 取较小值。

**算法步骤**

*   **For** `n = 0, 1, …` **Do**
    1.  `e[n] = y[n] - X[n]θ[n-1]`
    2.  `θ[n] = θ[n-1] + μ X[n]^T (δ I + X[n] X[n]^T)^{-1} e[n]`
*   **End For**

当输入为时间序列时，对应的输入向量记为 `u[n]`，通过将所需的负时间索引样本 `u[-1], u[-2], …` 设置为零来初始化。请注意，在算法中，也使用了一个取较小值的参数 `δ`，以防止相关矩阵求逆中的数值问题。此外，还引入了步长 `μ`，它控制更新的大小，其存在的合理性稍后将得到证明。由于涉及矩阵求逆和矩阵运算，APA 的复杂度比 LMS 增加，需要 `O(q³)` 次乘加运算（MADs）。利用 `X[n] X[n]^T` 的特殊结构（针对涉及的输入-输出变量为随机过程实现的情况），也开发了 APA 的快速版本（参见 [42, 43]）。

APA 的收敛分析比 LMS 更复杂。结果表明，只要 `0 < μ < 2`，就能保证算法的稳定性。失调度近似由以下公式给出 [2, 34, 83]：

```
M ≈ (μ q σ²_v) / (2 - μ q)
```

换句话说，随着参数 `q` 的增加，即重用的过去数据样本数量增加，失调度也会增加。

##### APA 的几何解释

让我们看看与 APA 相关的优化任务(5.60)。每一个 `q` 个约束都在 `l` 维空间中定义了一个超平面。因此，由于 `θ[n]` 被约束位于所有这些超平面上，它将位于它们的*交集*上。假设 `x[n−i]`，`i=0,…,q−1` 是线性无关的，这些超平面共享一个非空交集，这是一个维度为 `l−q` 的*仿射集*。仿射集是线性子空间（即通过原点的平面）沿常数向量平移的结果；也就是说，它定义了一个一般位置的平面。因此，`θ[n]` 可以位于这个仿射集中的任何位置。从这个集合中无限多个点中，APA 选择在欧氏距离意义上最接近 `θ[n−1]` 的那个点。换句话说，`θ[n]` 是 `θ[n−1]` 在由 `q` 个超平面的交集定义的仿射集上的*投影*。回顾几何知识，点 `a` 在线性子空间/仿射集 `H` 上的投影 `P_H(a)` 是 `H` 中与 `a` 距离最小的点。图 5.13 展示了 `q=2` 情况下的几何关系；APA 的这个特例也称为双归一化数据重用 LMS [7]。

![图 5.13 APA 相关的几何关系，q=2 且 l=3。两个超平面的交集是一条直线（维度为 3−2=1 的仿射集）；`θ[n]`是`θ[n−1]`在这条直线上的投影（点 1），当`μ=1`且`δ=0`时。点 2 对应`μ<1`的情况。点 3 是`θ[n]`在由(`y[n]`，`x[n]`)定义的超平面上的投影。这是`q=1`的情况。后一种情况对应于第 5.6.1 节的归一化 LMS（NLMS）。](images/B9780443292385000111/gr013.jpg)

在理想无噪声情况下，未知参数向量将位于由(`y[n]`，`x[n]`)定义的所有超平面的交集上，`n=0,1,…,q−1`，而这正是 APA 试图利用的信息以加速收敛。然而，这也是它的缺点。在任何实际系统中都存在噪声；因此强制更新位于这些超平面的交集上不一定是好的，因为它们在空间中的位置也由噪声决定。事实上，引入 `μ` 的原因就是为了应对这种情况。一种替代技术，利用投影，同时用超板（其宽度取决于噪声方差）替代超平面来解释噪声，将在第 8 章中讨论。此外，那里不需要矩阵求逆。
