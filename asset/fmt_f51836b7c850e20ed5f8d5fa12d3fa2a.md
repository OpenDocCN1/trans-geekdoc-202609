## 第三步：模型训练

### 划分数据集

模型训练的第一步是随机划分数据集。这使你能在训练期间保留部分数据隐藏，以便在将模型投入生产前使用这些数据来评估模型。具体来说，这是为了针对偏差-方差权衡进行测试。如果你有兴趣了解更多，请参阅“扩展学习与阅读”部分。

划分数据集将为你提供两组数据：

*   **训练数据集**：用于训练模型的数据。你的大部分数据将放在这里。许多开发者估计约占 80%。
*   **测试数据集**：训练期间从模型中保留的数据，用于测试模型对新数据的泛化能力。

### 模型训练术语

模型训练算法会迭代地更新模型的参数，以最小化某个`损失函数`。

让我们定义这两个术语：

*   **模型参数**：模型参数是训练算法可以更新以改变模型行为的设置或配置。根据上下文，你还会听到其他更具体的术语来描述模型参数，例如`权重`和`偏置`。`权重`是随着模型学习而变化的值，更多地特指神经网络。
*   **损失函数**：损失函数用于量化模型距离目标的程度。例如，如果你试图根据当天的天气预测刨冰的销量，你会关心预测尽可能准确。因此，你可以将损失函数定义为“模型预测的刨冰销量与正确销量之间的平均距离”。你可以在刨冰示例中看到这是两个紫点之间的差异。

### 综合运用

端到端的训练过程如下：

*   将训练数据输入模型。
*   根据结果计算`损失函数`。
*   朝着减少损失的方向更新`模型参数`。

你将持续循环执行这些步骤，直到达到预定义的停止条件。这可能基于训练时间、训练周期数，甚至是更智能或更具应用感知的机制。

### 专家建议

训练模型时请记住以下建议。

*   从业者通常使用已包含模型和模型训练算法可用实现的机器学习框架。你可以从头实现这些，但除非你在开发新模型或算法，否则可能不需要这样做。
*   从业者使用一个称为`模型选择`的过程来确定使用哪个模型或模型。成熟模型的列表在不断增长，即使是经验丰富的机器学习从业者，在用机器学习解决问题时也可能会尝试许多不同类型的模型。
*   **超参数** 是模型上的设置，它们在训练期间不会改变，但会影响模型训练的速度或可靠性，例如模型应识别的聚类数量。
*   做好迭代的准备。

用机器学习进行务实的问题解决很少是一门精确的科学，你可能对数据或问题有假设，但最终证明是错误的。不要气馁。相反，要养成尝试新事物、衡量成功并跨迭代比较结果的习惯。

### 扩展学习

#### 线性模型

线性模型是入门课程中最常见的模型之一，它通过线性函数（想想 `y = mx + b` 或 x-y 图表上的直线）简单地描述一组输入数字和一组输出数字之间的关系。

分类任务通常使用密切相关的逻辑模型，它增加了一个额外的变换，将线性函数的输出映射到范围 `[0, 1]`，解释为“属于目标类的概率”。线性模型训练速度快，并能为你提供一个极好的基线，以便与更复杂的模型进行比较。虽然更复杂的模型获得了大量媒体关注，但对于大多数新问题，建议考虑从简单模型开始。

#### 树模型

树模型可能是入门课程中第二常见的模型类型。它们通过构建极其庞大的嵌套 `if/else` 代码块结构来学习分类或回归，在每个 `if/else` 代码块处将世界分割成不同的区域。训练过程确定这些分割的确切位置以及分配给每个叶子区域的值。

例如，如果你试图确定光传感器处于阳光下还是阴影中，你可能会训练一个深度为 1 的树，其最终学习到的配置可能如下所示：

```
if (sensor_value > 0.698), then return 1; else return 0;
```

基于树的模型 `XGBoost` 常被用作此类模型的开箱即用实现，并包含此处未讨论的增强功能。尝试使用树模型快速获得基线，然后再转向更复杂的模型。

#### 深度学习模型

深度学习极其流行且强大，是一种基于人脑功能概念模型的现代方法。模型（也称为神经网络）由神经元集合（非常简单的计算单元）组成，这些神经元通过`权重`（表示允许多少信息从一个神经元流向下一个神经元的数学表示）连接在一起。训练过程涉及为每个`权重`寻找数值。

针对不同类型的问题建模或处理不同类型的数据，已经确定了各种神经网络结构。

一个简短（但不完整！）的值得注意的示例列表包括：

### 机器学习模型类型

*   **FFNN**：构建神经网络最直接的方式，前馈神经网络（`FFNN`）将神经元按一系列层级构建，每层中的每个神经元都包含通往上一层所有神经元的`权重`。
*   **CNN**：卷积神经网络（`CNN`）表示网格组织数据上的嵌套滤波器。在处理图像时，它们是迄今为止最常用的模型类型。
*   **RNN/LSTM**：循环神经网络（`RNN`）和相关的长短期记忆（`LSTM`）模型类型旨在有效表示传统计算中的 `for` 循环，在迭代某个对象时收集状态。它们可用于处理数据序列。
*   **Transformer**：一种更现代的 `RNN`/`LSTM` 替代架构，Transformer 架构支持在涉及数据序列的更大数据集上进行训练。

### 使用 Python 库进行机器学习

对于更经典的模型（线性、基于树的模型）以及一组常见的机器学习相关工具，请查看 `scikit-learn`。该库的网络文档也面向初学者组织，是熟悉一些极其有用的工具和技术的绝佳场所。

对于深度学习，`mxnet`、`tensorflow` 和 `pytorch` 是三个最常用的库。对于绝大多数机器学习需求，这些库在功能上是配对且等效的。

*   **损失函数**：用于量化模型距离目标的程度。

### 使用对数损失

对数损失旨在计算模型对其生成预测的不确定程度。在此语境下，不确定性是指模型认为生成的预测正确的可能性。

![](img/image00088.jpeg)

例如，假设您试图预测客户购买夹克或 T 恤的可能性。

对数损失可用于了解模型对特定预测的不确定性。在某一实例中，您的模型可能以 5% 的确定性预测客户将购买 T 恤。在另一实例中，您的模型可能以 80% 的确定性预测客户将购买 T 恤。对数损失使您能够衡量模型对其预测准确性的信念程度。

在这两种情况下，模型都预测客户将购买 T 恤，但模型对该预测的确定性可能会发生变化。

##### 术语

*   **词袋**：一种用于从文本中提取特征的技术。它统计单词在文档（语料库）中出现的次数，然后将该信息转换为数据集。
*   **数据向量化**：一种将非数值数据转换为数值格式的过程，以便机器学习模型使用。
*   **轮廓系数**：一个从 -1 到 1 的分数，用于描述建模过程中发现的簇。接近零的分数表示簇重叠，小于零的分数表示数据点被分配到了错误的簇。接近 1 的分数表示成功识别出了离散的非重叠簇。
*   **停用词**：自然语言处理工具在构建数据集时移除的一组单词。没有一份被所有自然语言处理工具通用的通用停用词列表。
