
其中 $x^p$ 和 $x^d$ 分别是决策向量 $x$ 的位置相关部分和距离相关部分。$h_i$ 和 $g_i$ 分别是第 $i$ 个形状函数和景观函数。从公式可以看出，LMF 基准测试套件中同时使用了基于乘法的公式化模型和基于加法的公式化模型，这与上述介绍的基准测试（仅使用单一公式化模型）明显不同。

为了更好地模拟和反映现实应用中 LSMOPs 的特性，LMF 继承了 LSMOP 基准测试套件的共同特征，例如决策变量的非均匀分组、目标函数的混合可分以及变量耦合。此外，LMF 还进行了以下改进：

1. 引入了位置相关变量与距离相关变量之间的混合耦合。
2. 采用了更灵活的决策变量分组。
3. 通过增加位置相关变量之间的相关性增强了形状函数。
4. 创造了决策变量对目标函数的不平衡贡献。

## 2.3 性能指标

随着多目标进化算法（MOEAs）的广泛应用，新的 MOEA 不断被提出。为了研究它们的性能，需要通过某些指标对它们获得的解集质量进行量化。在本节中，这些指标被分为三类：仅评估收敛性的指标、仅评估多样性的指标以及同时评估收敛性和多样性的指标。这些指标被广泛用于评估针对大规模多目标和非大规模多目标优化而定制的 MOEA 性能。

### 2.3.1 评估收敛性的性能指标

非支配个体比例（RNI）、纯度（Purity）和世代间距离（GD）是仅评估解集收敛性的三个代表性性能指标。具体而言，给定解集 $A$，RNI 的数学公式如下：

```math
RNI(A) = \frac{|A_1|}{|A|}
```

其中 $|A_1|$ 是解集 $A$ 中非支配解的数量，$|A|$ 代表解集 $A$ 的规模。显然，RNI 越大，解集 $A$ 的收敛性越好。

纯度是一个可以同时比较多个解集的性能指标。给定 $N$ 个解集 $A^1, A^2, \dots, A^N$ ($N \ge 2$)，令 $r_i = |A_1^i|$ ($i = 1, 2, \dots, N$) 表示第 $i$ 个解集中非支配解的数量。$N$ 个解集中所有非支配解的并集表示为 $A^* = \bigcup_{i=1}^N \{A_1^i\}$。随后，对 $A^*$ 执行非支配排序算法 [30] 可以获得一个新的解集 $A_1^*$，其中 $A_1^*$ 保留了非支配解。令 $r_i^*$ 表示 $A_1^*$ 中来自 $A^i$ 的非支配解的数量，即：

(2.7) $r_i^* = |\{\gamma \mid \gamma \in A_1^i \text{ and } \gamma \in A_1^*\}|$

那么，第 $i$ 个解集的纯度可以获得：

(2.8) $P_i = \frac{r_i^*}{r_i}, i = 1, 2, \dots, N$

显然，$P_i$ 越大，第 $i$ 个解集越好。GD 通过一组参考点来评估解的质量。具体而言，给定一个参考集 $Z = \{z_1, z_2, \dots, z_{|Z|}\}$ 和一个非支配集合 $A = \{a_1, a_2, \dots, a_{|A|}\}$，其中 $|Z|$ 和 $|A|$ 分别表示 $Z$ 和 $A$ 中参考点和解的数量。解集的 GD 值计算为：

```math
GD(A) = \frac{1}{|A|} \left( \sum_{i=1}^{|A|} (d_i)^p \right)^{1/p}
```

其中 $d_i$ 是解 $a_i$ 到其在 $Z$ 中最近参考点的欧几里得距离，$p$ 是一个通常设置为 1 的整数参数。显然，GD 值越小，解集 $A$ 的收敛性越好。

### 2.3.2 仅评估多样性的性能指标

间距（SP）[31]、最大散度（MS）[19]、$C_{\mu}$ [32] 和 CPF [33] 是评估解集多样性的最具代表性的性能指标。具体而言，SP 计算解集 $A$ 中每个解到其他解最小距离的标准差，如下：

```math
SP(A) = \sqrt{\frac{1}{|A|} \sum_{i=1}^{|A|} (d_i - \bar{d})^2}
```

其中 $d_i = \min_{k \in A, k \neq i} \sum_{m=1}^{M} |f_m^i - f_m^k|$，$f_m^i$ 和 $f_m^k$ 分别是第 $i$ 个和第 $k$ 个解的第 $m$ 个目标值。$\bar{d}$ 是所有 $d_i$ 的平均值，其中 $1 \leq i \leq |A|$。值得注意的是，SP 接近零是理想的，这意味着解均匀分布在帕累托前沿上。

MS 通过考虑每个目标上的最大扩展范围来衡量解集 $A$ 的范围。其定义为：

```math
MS(A) = \sqrt{\sum_{i=1}^{M} \max_{a, a' \in A} (a_i - a'_i)^2}
```
