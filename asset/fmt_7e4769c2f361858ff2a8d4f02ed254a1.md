# A12: 命令行哈希处理

在本实验中，Windows 用户将有机会通过命令行提示符进行哈希操作，以验证下载文件的完整性。Linux 用户在他们的操作系统中内置了类似的工具。Windows 用户可以从微软下载一个名为 Checksum Verifier (FCIV) 的工具，这是一个用于计算和验证文件加密哈希计算的命令行实用程序。FCIV 可以计算 MD5 或 SHA-1 加密哈希值。我们将在实验 A16 中再次使用该工具。

阅读说明，然后在此处下载并安装该工具：

## 从命令行验证文件完整性

按照以下步骤开始验证文件完整性：

1. 下载 FCIV 安装程序。
2. 在你的 C 盘根目录下创建一个名为 FCIV 的文件夹。
3. 将程序安装到`c:\FCIV`文件夹。

为了简化此工具的操作，下载的程序将移动到此文件夹以验证文件完整性。

4. 将上一个练习中的 SHA 镜像移动到 fciv 文件夹。
5. 打开命令行提示符。输入`cd \fciv`切换到 fciv 文件夹。
6. 输入`dir .`查看文件夹中的文件。你现在应该能看到三个文件。花点时间查看 readme 文件。
7. 输入`fciv`，你将看到一个帮助屏幕，显示正确的语法是`fciv.exe [Commands] <Options>`。
8. 但是，如果你对默认的 MD5 哈希满意，只需输入`fciv`和文件名。让我们就那样操作。首先，通过输入生成 SHA 图片的哈希：

```
fciv.exe sha.jpg
```

9. 将此值与你在上一个练习中创建的 hashes 文档中保存的 MD5 进行比较。它们应该是匹配的。
10. 接下来，输入以下内容对 readme 文档生成 MD5 校验和：

```
fciv.exe readme.txt
```

11. 我在发布时的值以 07ac 结尾。如果你的值不同，请记录你的最后四个字符。微软不太可能更新此文档，但你可以尝试进行更改，并使用新的哈希检查来验证文档是否已修改。

12. 返回 Windows。打开 readme 文件进行细微修改并保存覆盖原始文件。关闭文档。
13. 再次对 readme 文档生成另一个 MD5 校验和：

```
fciv.exe readme.txt
```

是同一个文档吗？如果你回去并删除了之前的更改，它还会具有相同的原始 MD5 哈希吗？

14. 如果你愿意，可以使用生成的 SHA-1 值重复此练习。你会发现它的工作原理相同。

## 验证下载文件的完整性

当你从互联网下载内容时，如何确保没有发生意外的修改？一种方法是使用数字签名，这是另一种结合了非对称加密和哈希的哈希检查类型。但如果创建者没有对文件进行数字签名呢？常见的解决方案是发布者在其端生成并发布哈希值。下载文件后，你生成自己的哈希值。如果你的哈希与发布的哈希值匹配，你就知道你的机器上有一份未修改的原始文件副本。这是一个涉及用户理解哈希及哈希工具的手工哈希检查。

Web 上有很多网站可以下载文件。可以通过浏览器进行，也可以使用 FTP 工具进行。有些网站明确发布了哈希，而有些没有：Windows 中没有原生的哈希检查工具，下载发行版的站点倾向于让哈希值更可见。Linux 通常从称为镜像站的 FTP 服务器下载。在美国的地址是 http://ftp.us.debian.org/debian/dists/ 你将找到数百个文件及其哈希。对于本实验，我选择了几个 Windows 工具来验证完整性，但在练习中请勿安装或使用它们。

1. 访问 www.febooti.com 并查看这些工具及其发布的哈希。
2. 进入下载页面。下载本次练习所需的 hex 和 CRC 程序。将两个文件都放在你的`c:\fciv`文件夹中。可以随意下载并尝试任何其他程序。FileWeak 非常有趣，因为它允许你操作文件的元数据。留在下载页面；我们将返回这里查看当前的哈希。
3. 打开你的命令行提示符，通过输入`cd c:\fciv`切换到 fciv 文件夹。然后运行`dir`查看两个新的可执行文件。
4. 通过输入`fciv.exe ftweak-hex.exe`为`ftweak-hex.exe`生成哈希。

![](img/7868547987f5920cfe632b85047c64af_664_0.png)

5. 转到下载页面查看计算出的哈希值。比较你计算的 MD5 值与 fciv 的 MD5 值。如果它们匹配，说明你下载成功且没有损坏。
6. 计算并比较他们的其他工具`ftweak-hash`的值。他们还为哪些其他类型的哈希计算了值？
7. 要使用不同的 GUI 哈希工具，请下载并安装它们的哈希选项。这些选项会在 Windows 属性中添加额外的标签页，并向你显示许多类型的哈希。

如果你想要更新的命令行哈希工具，可以从 md5deep.sourceforge.net 下载 md5deep。
