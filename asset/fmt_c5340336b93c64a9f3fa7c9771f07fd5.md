## 2.2 概率与随机变量

随机变量 `x` 是其变化由机会/随机性引起的变量。随机变量可视为一个函数，它为实验的结果赋予一个值。例如，在抛硬币实验中，相应的随机变量 `x` 可取值 `x[1] = 0`（若实验结果为“正面”）和 `x[2] = 1`（若结果为“反面”）。

我们将用小写罗马字母表示随机变量，如 `x`，而用数学斜体表示实验进行后它所取的值，如 `x`。

若随机变量的值为离散性质，则用一组*概率*来描述；若其值位于实轴某一区间内的任意位置（不可数无限集），则用*概率密度函数*（PDF）来描述。关于更正式的处理和讨论，请参见文献 [4,6]。

### 2.2.1 概率

虽然“概率”和“或然”这两个词在我们的日常词汇中非常常见，但概率的数学定义并非一目了然，多年来已提出了许多不同的定义。毋庸置疑，无论采用哪种定义，最终推导出的性质和规则保持不变。最常用的两个定义如下：

#### 相对频率定义

事件 `A` 的概率 `P(A)` 定义为极限

```
P(A) = lim_{n→∞} (n_A / n)
```

(2.1)

其中 `n` 为总试验次数，`n_A` 为事件 `A` 发生的次数。该定义的问题在于，在任何物理实验中，`n_A` 和 `n` 可以很大，但始终是有限的。因此，该极限只能作为一种*假设*使用，而非实验上可达到的结果。在实践中，对于较大的 `n` 值，常使用

```
P(A) ≈ n_A / n
```

(2.2)

但必须谨慎使用，特别是在事件概率非常小的情况下。

#### 公理化定义

这一概率定义可追溯至 1933 年 Andrey Kolmogorov 的著作，他在测度论的背景下，发现了概率论与集合论及实变函数数学理论之间的密切联系，如文献 [5] 所述。

事件的概率 `P(A)` 是分配给该事件的一个非负数，即

```
P(A) ≥ 0.
```

(2.3)

必然发生的事件 `C` 的概率等于 1，即

```
P(C) = 1.
```

(2.4)

若两个事件 `A` 和 `B` 互斥（不能同时发生），则 `A` 或 `B` 发生（记为 `A ∪ B`）的概率由下式给出

```
P(A ∪ B) = P(A) + P(B).
```

(2.5)

事实证明，这三个定义性质（可视为各自的*公理*）足以推导出该理论的其余部分。例如，可以证明不可能事件的概率等于零，例如 [6]。

上述定义概率的两种方法并非唯一。另一种解释符合我们在本书多处将要使用的概率概念，即在*贝叶斯学习*的语境下，由 Cox [2] 提出。在那里，概率被视为关于某一事件的*不确定性*的度量。以米诺斯文明是否因圣托里尼岛附近发生的地震而毁灭这一问题的不确定性为例。这显然不是一个可以通过重复试验来检验其概率的事件。然而，通过综合历史和科学证据，我们可以量化我们对这种推测的不确定性表达。此外，随着新的考古发现带来更多历史证据，我们还可以修正我们不确定性的程度。通过分配数值来代表信念的程度，Cox 开发了一组编码此类信念常识性质的公理，并得出了一组与我们即将回顾的规则等价的规则；另见 [4]。

概率论的起源可追溯至 17 世纪中叶 Pierre Fermat（1601–1665）、Blaise Pascal（1623–1662）和 Christiaan Huygens（1629–1695）的著作中。概率和随机变量均值的概念均可在其中找到。发展该理论的最初动机似乎与任何“服务社会”的目的无关；其目的是满足赌博和机会游戏的需求！

### 2.2.2 离散随机变量

离散随机变量 `x` 可以从有限或*可数*无限集合 $\mathcal{X}$ 中取任意值。事件“`x` = `x` ∈ $\mathcal{X}$”的概率表示为

`P(x = x)` 或简写为 `P(x)`。

函数 `P` 称为*概率质量函数*（PMF）。作为事件的概率，它必须满足第一公理，即 `P(x) ≥ 0`。假设 $\mathcal{X}$ 中的任意两个值不能同时发生，且每次实验后总会出现单个值，则第二和第三公理合起来给出

```
\sum_{x \in \mathcal{X}} P(x) = 1.
```

(2.7)

集合 $\mathcal{X}$ 也称为*样本*空间或*状态*空间。

#### 联合概率与条件概率

两个事件 `A`、`B` 的*联合概率*是指两个事件同时发生的概率，记为 `P(A, B)`。现在让我们考虑两个随机变量 `x`、`y`，其样本空间分别为 $\mathcal{X} = \{x_1, \dots, x_{n_x}\}$ 和 $\mathcal{Y} = \{y_1, \dots, y_{n_y}\}$。让我们采用相对频率定义，并假设我们进行了 `n` 次实验，$\mathcal{X}$ 中的每个值分别出现了 $n_1^{(x)}, \dots, n_{n_x}^{(x)}$ 次，$\mathcal{Y}$ 中的每个值分别出现了 $n_1^{(y)}, \dots, n_{n_y}^{(y)}$ 次。那么，

$P(x_i) \approx \frac{n_i^x}{n},\ i = 1,2,\ldots,n_x,\quad\text{and}\quad P(y_j) \approx \frac{n_j^y}{n},\ j = 1,2,\ldots,n_y.$

![Equation](img/si25.png)

用 $n_{ij}$ 表示值 $x_i$ 和 $y_j$ 同时出现的次数。则 $P(x_i,y_j) \approx \frac{n_{ij}}{n}$。简单的推理表明，值 $x_i$ 出现的总次数 $n_i^x$ 等于

$$n_i^x = \sum_{j = 1}^{n_y} n_{ij}.$$

![Equation](img/si31.png)(2.8)

将上式两边同时除以 $n$，即可得到以下*求和规则*。

![Equation](img/fx001.jpg)(2.9)

事件 $A$ 在另一事件 $B$ *已发生* 条件下的*条件概率* 记作 $P(A|B)$，其定义为

![Equation](img/fx002.jpg)(2.10)

前提是 $P(B) \neq 0$。可以证明这确实是一个概率，因为它满足所有三条公理 [6]。如果采用相对频率定义，我们可以更好地理解其物理意义。设 $n_{AB}$ 为两个事件同时发生的次数，在 $n$ 次实验中设 $n_B$ 为事件 $B$ 发生的次数。则有

$$P(A|B) = \frac{n_{AB}}{n}\frac{n}{n_B} = \frac{n_{AB}}{n_B}.$$

![Equation](img/si36.png)(2.11)

换句话说，事件 $A$ 在另一事件 $B$ 已发生条件下的条件概率，是 $A$ 发生的相对频率，但这不是相对于实验总次数，而是相对于事件 $B$ 发生的次数。

换个角度看，并采用类似的随机变量记号，根据公式 (2.9)，条件概率的定义也称为概率的*乘积规则*，写作

![Equation](img/fx003.jpg)(2.12)

为了将它们与联合概率和条件概率区分开来，概率 `P(x)` 和 `P(y)` 被称为*边缘概率*。乘积法则可以直接推广到 `l` 个随机变量，即：

```
P(x[1], x[2], …, x[l]) = P(x[l] | x[l−1], …, x[1]) P(x[l−1], …, x[1])
```

这递归地导出了乘积形式：

```
P(x[1], x[2], …, x[l]) = P(x[l] | x[l−1], …, x[1]) P(x[l−1] | x[l−2], …, x[1]) … P(x[1])
```

**统计独立性**：当且仅当两个随机变量的联合概率等于各自边缘概率的乘积时，称这两个随机变量是统计独立的，即：

```
P(x, y) = P(x) P(y)  (2.13)
```

#### 贝叶斯定理

贝叶斯定理是乘积法则和联合概率对称性质 `P(x, y) = P(y, x)` 的直接推论，其表述为：

![Equation](img/fx004.jpg) (2.14)

其中边缘概率 `P(x)` 可以写为：

```
P(x) = ∑_{y ∈ Y} P(x, y) = ∑_{y ∈ Y} P(x | y) P(y)
```

它可以被视为公式 (2.14) 右边分子的归一化常数，这保证了对 `y ∈ Y` 所有可能值求和 `P(y | x)` 的结果为 1。

##### 贝叶斯定理在机器学习中起核心作用

贝叶斯定理在机器学习中起核心作用，它将成为开发贝叶斯技术以估计未知参数值的基础。

### 2.2.3 连续随机变量

到目前为止，我们一直关注离散随机变量。现在我们的兴趣转向将概率的概念推广到取实轴 `ℝ` 上值的随机变量。

出发点是计算随机变量 `x` 落在区间 `x₁ < x ≤ x₂` 内的概率。注意这两个事件 `x ≤ x₁` 和 `x₁ < x ≤ x₂` 是互斥的。因此，我们可以写出

`P(x ≤ x₁) + P(x₁ < x ≤ x₂) = P(x ≤ x₂).` (2.15)

我们将 `x` 的*累积分布函数*（CDF）定义为

![Equation](img/fx005.jpg) (2.16)

那么，公式 (2.15) 可以写为

`P(x₁ < x ≤ x₂) = Fₓ(x₂) − Fₓ(x₁).` (2.17)

注意 `Fₓ` 是一个单调递增函数。此外，如果它是连续的，则称随机变量 `x` 为*连续*型。假设它也是可微的，我们可以将 `x` 的*概率密度函数*（PDF）定义为

![Equation](img/fx006.jpg) (2.18)

这进而导出

`P(x₁ < x ≤ x₂) = ∫[x₁]^(x₂) pₓ(x) dx.` (2.19)

此外，

`Fₓ(x) = ∫[−∞]^(x) pₓ(z) dz.` (2.20)

利用微积分中熟悉的论证，概率密度函数可以解释为

`ΔP(x < x ≤ x + Δx) ≈ pₓ(x) Δx.` (2.21)

这正是其被称为“密度”函数的由来，即 x 落在微小区间 Δ*x* 内的概率 (Δ*P*)，除以该区间的长度。注意，当 Δ*x* → 0 时，该概率趋于零。因此，连续随机变量取任意单一值的概率为零。此外，由于 *P*(−∞ < *x* < +∞) = 1，我们有

```
∫[−∞]^(+∞) p_x(x) dx = 1.
```

通常，为简化符号，会省略下标 x 而写作 *p*(*x*)，除非为了避免可能的混淆而有必要保留。还要注意，我们采用小写 “*p*” 表示概率密度函数 (PDF)，大写 “*P*” 表示离散事件的概率。

关于概率的所有前述规则均可直接推广到 PDF 的情况，方式如下：

```
p(x|y) = p(x,y) / p(y),  p(x) = ∫_{-∞}^{+∞} p(x,y) dy.
```

### 2.2.4 均值与方差

与任何随机变量相关的最常见且最有用的两个量是其均值和方差。均值（有时称为期望值）表示为

方差表示为 *σ*_x²，定义为

![Equation](img/fx008.jpg) (2.25)

对于离散变量，积分替换为求和。方差是衡量随机变量取值围绕其均值分散程度的指标。

均值的定义可推广至任意函数 *f*(*x*)，即

```
𝔼[f(x)] := ∫_{-∞}^{+∞} f(x) p(x) dx.
```

容易证明，关于两个随机变量 *y*、*x* 的均值可写成乘积形式

𝔼[*x*, *y*][*f*(*x*, *y*)] = 𝔼[*x*][𝔼[*y*|*x*][*f*(*x*, *y*)]],

![Equation](img/si66.png) (2.27)

给定两个随机变量 *x*、*y*，它们的*协方差*定义为

cov(*x*, *y*) := 𝔼[(*x* − 𝔼[*x*])(*y* − 𝔼[*y*])],

![Equation](img/si74.png) (2.30)
