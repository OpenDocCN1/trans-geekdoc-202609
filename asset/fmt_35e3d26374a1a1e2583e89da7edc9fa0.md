
根据目标值是否为连续实数，监督学习分为**回归**和**分类**。例如，房价是连续实数，因此房价预测问题是回归问题。在图像分类问题中，需要识别图像属于哪个类别（如猫、狗、飞机等），图像的类别是离散值，因此图像分类问题是分类问题。

分类问题通常也是通过学习一个连续的目标值（即物体属于每个类别的概率）来进行分类的。本章将介绍三种经典回归：线性回归、逻辑回归和 Softmax 回归。因为这三种机器学习技术的假设函数预测值都是连续值，所以它们被称为回归，但后两者用于解决二分类和多分类问题。

监督学习依赖于具有已知目标值的训练数据，但在许多情况下，人工标注以指定每个数据样本的目标值既耗时又费力。例如，对于人脸检测问题，每张人脸需要标注 68 个关键点的位置，如果城市中有数百万张人脸需要标记，这是多大的工程？同样，给数百万张图像标注类别也是一项繁重的劳动。

在不知道样本真实值的情况下，能否学习这些数据之间的某些规律？**无监督学习**是在不知道真实值的情况下进行的机器学习方法。例如，聚类算法可以分析数据样本以确定它们属于哪个聚类中心。主成分分析（PCA）可以确定数据的主成分，进而用于降低数据维度，即将高维数据表示为低维形式。自编码器将数据本身作为目标值，即使用 `(x^(i), x^(i))` 作为样本进行监督学习，并可通过编码和解码过程的自监督学习过程，获得数据的内在特征。

缺乏真实值监督使得无监督学习非常困难。虽然无监督学习看似无目的，且难以学习到高质量的规律或数学模型，但它可以克服获取监督数据的困难，常被用作监督学习的一种辅助技术。

一种折中的学习方法是**半监督学习**，它为一小部分数据提供真实值，而大部分数据没有真实值。它避免了监督学习获取样本的高昂成本，并能以监督的方式引导学习过程。因此，它是一种非常有前景的机器学习方法。

此外，还有一种**强化学习**方法，它通过与环境交互获得的经验来学习环境的模型和决策，并用于指导行为决策。

### 3.1.3 什么是线性回归？

针对这个餐车利润问题，用什么样的数学函数 `f(x)` 来表示样本特征（城市人口）`x` 和样本标签（餐车利润）`y` 之间的映射关系？通过观察图 2-1，可以认为由 `x` 和 `y` 形成的坐标点几乎在一条直线上（共线），或者说 `x` 和 `y` 几乎满足线性关系。因此，在无数种数学函数中，可以用线性函数来表示 `x` 和 `y` 之间的这种线性关系：

```
y = f(x) = wx + b
```

该函数称为**假设函数**，或**函数模型**，或**模型**。

该线性函数由参数 `w` 和 `b` 决定，不同的参数 `w` 和 `b` 代表不同的线性函数。如果有多个数据样本 `(x^(i), y^(i))`，可以通过最小化样本特征 `x` 的预测值 `f(x)` 和真实值 `y` 的某种误差度量，来获得参数值 `(w, b)`，这些获得的参数值所表示的线性函数能很好地描述 `x` 和 `y` 之间的关系。求解参数 `(w, b)` 的过程称为**模型训练**或**训练模型**。

**线性回归**是利用**线性函数**表示自变量（特征）和因变量（真实值）之间的关系，并基于一组样本数据求解一个最优线性函数的过程。

那么什么是“最优”？

对于每个样本 `x^((i))`, `y^((i))`，使用符号 `f^((i))` 来表示预测值 `f(x^((i)))`。对于餐车利润问题，方差 `(f^((i)) - y^((i)))²` 可用于表示单个样本的预测误差，以下均方误差可用于表示所有样本的预测误差：

```
L = \frac{1}{m}\sum\limits_{i = 1}^{m}(f^{(i)} - y^{(i)})^{2} = \frac{1}{m}\sum_{i = 1}^{m}(wx^{(i)} + b - y_{i})^{2}
```

`L` 可视为未知参数 `w` 和 `b` 的函数 `L(w, b)`，用于描述模型在样本数据上的预测误差。`L(w, b)` 称为**损失函数**（也称为**误差函数**）。模型训练即求使损失函数 `L(w, b)` 取最小值的参数 `w` 和 `b`。

当然，函数乘以常数不影响其最小值参数。有时为使求导更简单，将右侧公式除以 2 作为损失函数：

```
L(w,b) = \frac{1}{2m}\sum\limits_{i = 1}^{m}(f^{(i)} - y^{(i)})^{2} = \frac{1}{2m}\sum\limits_{i = 1}^{m}(wx^{(i)} + b - y^{(i)})^{2}
```

线性回归即求使损失函数取最小值的参数 `w`, `b`。解决此最小值问题有两种方法：正规方程法和梯度下降法。

### 3.1.4 正规方程求解线性回归问题

损失函数 `L(w, b)` 是 `w`, `b` 的多元函数，`L(w, b)` 对 `w`, `b` 的偏导数为：

```
\frac{\partial L}{\partial w} = \frac{1}{2m}\frac{\partial{(\sum(wx^{(i)} + b - y^{(i)})^{2})}}{\partial w} = \frac{1}{m}\sum(wx^{(i)} + b - y^{(i)})x^{(i)}
```

```
\frac{\partial L}{\partial b} = \frac{1}{2m}\frac{\partial{(\sum(wx^{(i)} + b - y^{(i)})^{2})}}{\partial b} = \frac{1}{m}\sum(wx^{(i)} + b - y^{(i)})
```

函数 `L(w, b)` 取最小值的必要条件是其对自变量 `w`, `b` 的梯度或偏导数等于 0，即：

```
\frac{\partial L}{\partial w} = \frac{1}{m}\sum(wx^{(i)} + b - y^{(i)})x^{(i)} = 0
```

```
\frac{\partial L}{\partial b} = \frac{1}{m}\sum(wx^{(i)} + b - y^{(i)}) = 0
```

令

```
X = \begin{pmatrix} 1 & x^{(1)} \\ 1 & x^{(2)} \\ 1 & \vdots \\ 1 & x^{(m)} \end{pmatrix}\quad W = \begin{pmatrix} b \\ w \end{pmatrix}\quad y = \begin{pmatrix} y^{(1)} \\ y^{(2)} \\ \vdots \\ y^{(m)} \end{pmatrix}
```

去掉方程系数 `\frac{1}{m}`，上述方程可写成矩阵/向量形式：

`XW - y = 0`

移项并两边同乘 `X^T`：

`X^T X W = X^T y`

两边同乘 `X^T X` 的逆矩阵 `(X^T X)^{-1}`：

`W = (X^T X)^{-1} X^T y`

由此得到 `W = (b, w)`。公式 (6) 即为求解 `W` 的**正规方程**。

使用正规方程法求解上述“餐车利润问题”的代码如下：

```python
import numpy as np

data = np.loadtxt('food_truck_data.txt', delimiter=",") # data 是 m*2 矩阵，每行代表一个样本
train_x = data[:, 0]    # 城市人口，m*1 矩阵
train_y = data[:, 1]    # 餐车利润，m*1 矩阵

X = np.ones(shape=(len(train_x), 2))
X[:, 1] = train_x 
y = train_y

XT = X.transpose()
XTy = XT @ y
w = np.linalg.inv(XT@X) @ XTy
print(w)
```

```
[-3.89578088 1.19303364]
```

模型函数 `f(x) = wx + b` 已得到，代入城市人口值 `x` 即可预测餐车利润，例如预测人口为 46,000 的城市的餐车利润：



### 3.1.5 梯度下降法求解线性回归问题

正规方程法需计算矩阵乘积和逆矩阵。若数据特征数或样本数较大，耗时较长。因此，通常使用梯度下降法求解上述优化问题。

为求解 `L(w, b)` 的未知模型参数 `w`, `b`，梯度下降法从 `w[0]`, `b[0]` 的初始值出发，通过以下公式迭代更新 `w`, `b`：

```
w := w - \alpha\frac{\partial L}{\partial w}
```

```
b := b - \alpha\frac{\partial L}{\partial b}
```

令

```
x = \begin{pmatrix} x^{(1)} \\ x^{(2)} \\ \vdots \\ x^{(m)} \end{pmatrix}\quad y = \begin{pmatrix} y^{(1)} \\ y^{(2)} \\ \vdots \\ y^{(m)} \end{pmatrix}\quad b = \begin{pmatrix} b \\ b \\ \vdots \\ b \end{pmatrix}
```

偏导数可用向量形式表示：

```
\frac{\partial L}{\partial w} = np.mean((wx + b - y) \odot x)
```

```
\frac{\partial L}{\partial b} = np.mean((wx + b - y))
```

系数 `1/m` 可并入学习率，利用 numpy 向量化运算易于编写计算梯度的代码：

```python
X = train_x
w,b = 0.,0.
dw = np.mean((w*X+b-y)*X)
db = np.mean((w*X+b-y))
print(dw)
print(db)
```

```
-65.32884974555671
-5.839135051546393
```

因此，求解线性回归的梯度下降算法代码可写为：

```python
def gradient_descent(x,y,w,b,alpha=0.01, iterations = 100,epsilon = 1e-9):    
    history=[]
    for i in range(iterations):
        dw = np.mean((w*x+b-y)*x)
        db = np.mean((w*x+b-y))       
        if abs(dw) < epsilon and abs(db) < epsilon:
           break
     
        # Update w: w = w - alpha * gradient
        w -= alpha*dw 
        b -= alpha*db 
        history.append([w,b])  
       
    return history
```

调用上述梯度下降法，设学习率 `alpha = 0.02` 和迭代次数，可求得假设函数参数：

```python
alpha = 0.02
iterations=1000
history = gradient_descent(X,y,w,b,alpha,iterations)
print(len(history))
print(history[-1])
```

```
1000
[1.1822480052540145, -3.7884192615511796]
```

`history` 记录迭代过程中每一步的模型参数，最后一个参数为最优参数。

如何判断梯度下降法是否收敛到最优解？

对于输入输出变量均为单值的假设直线函数 `f(x)`，可通过在样本点二维平面上绘制该假设直线函数，直观观察是否收敛。为此，编写函数根据模型参数 `(w, b)` 绘制假设函数对应的直线：

```python
def draw_line(plt,w,b,x,linewidth =2):
    m=len(x)
    f = [0]*m
    for i in range(m): 
       f[i] = b+w*x[i]
    plt.plot(x, f, linewidth)  
```

为了观察迭代的收敛情况，对于具有 2 个以上数据特征（自变量）的线性回归问题，通用的做法是绘制**损失曲线**（**代价曲线**），即迭代过程中损失（代价）的变化。为此，可以使用以下损失函数来计算参数 `w`、`b` 对应的损失。

```python
def loss(x,y,w,b):
    m = len(y)
    return np.mean((x*w+b-y)**2)/2
    cost = 0   
    for i in range(m):  
        f =  x[i]*w+b
        cost += (f-y[i])**2
    cost /=(2*m)
    return cost

print(loss(X,y,1,-3))
```
