
# 贝叶斯分类器与最近邻规则

## 二次判别函数

$$g(\mathbf{x}) = \underbrace{\frac{1}{2}\left( \mathbf{x}^{T}\Sigma_{2}^{-1}\mathbf{x} - \mathbf{x}^{T}\Sigma_{1}^{-1}\mathbf{x} \right)}_{\text{二次项}} \underbrace{+ \mathbf{\mu}_{1}^{T}\Sigma_{1}^{-1}\mathbf{x} - \mathbf{\mu}_{2}^{T}\Sigma_{2}^{-1}\mathbf{x}}_{\text{一次项}} \underbrace{- \frac{1}{2}\mathbf{\mu}_{1}^{T}\Sigma_{1}^{-1}\mathbf{\mu}_{1} + \frac{1}{2}\mathbf{\mu}_{2}^{T}\Sigma_{2}^{-1}\mathbf{\mu}_{2} + \ln\frac{P(\omega_{1})}{P(\omega_{2})} + \frac{1}{2}\ln\frac{|\Sigma_{2}|}{|\Sigma_{1}|}}_{\text{常数项}} = 0.$$

![Equation](img/si82.png) (7.19)

仔细观察公式 (7.19)，可以很容易地注意到：一旦两个类别的协方差矩阵变得相等，二次项就会抵消，判别函数变为线性；因此，对应的超曲面是一个**超平面**。也就是说，在上述假设下，最优贝叶斯分类器变成了一个**线性**分类器，经过一些直接的代数运算（读者可自行尝试）可以写为：

```
g(x) = (μ₁ - μ₂)ᵀ Σ⁻¹ x - ½ (μ₁ᵀ Σ⁻¹ μ₁ - μ₂ᵀ Σ⁻¹ μ₂) + ln(P(ω₁)/P(ω₂))
```

其中 `Σ` 是公共协方差矩阵。

### 马氏距离

$$||\mathbf{\mu}_{1} - \mathbf{\mu}_{2}||_{\Sigma^{-1}} := \sqrt{(\mathbf{\mu}_{1} - \mathbf{\mu}_{2})^{T}\Sigma^{-1}(\mathbf{\mu}_{1} - \mathbf{\mu}_{2})}$$

是向量 $(\mathbf{\mu}_{1} - \mathbf{\mu}_{2})$ 的 $\Sigma^{-1}$ 范数，也称为 $\mathbf{\mu}_{1}$ 和 $\mathbf{\mu}_{2}$ 之间的 **马氏距离**。马氏距离是欧氏距离的推广；注意当 $\Sigma = I$ 时，它退化为欧氏距离。

图 7.5 展示了二维空间下的三种情况。实线对应于协方差矩阵为特殊形式 $\Sigma = \sigma^2 I$ 的等概率类别。根据公式 (7.20)，对应的判别超平面可写为：

$$g(\mathbf{x}) = (\mathbf{\mu}_{1} - \mathbf{\mu}_{2})^{T}(\mathbf{x} - \mathbf{x}_{0}) = 0. \tag{7.23}$$

分隔线（超平面）穿过连接均值点 `μ₁` 和 `μ₂` 的线段的中点（`x₀ = ½(μ₁ + μ₂)`）。此外，它垂直于由向量 `μ₁ − μ₂` 定义的该线段，这可以通过上述超平面定义轻松验证。确实，对于决策曲线（图 7.5 中的实心黑线）上的*任意*点 `x`，由于中点 `x₀` 也位于该曲线上，因此对应的向量 `x − x₀` 平行于该线。因此，公式 (7.23) 中的内积等于零意味着决策线垂直于 `μ₁ − μ₂`。红线对应 `P(ω₁) > P(ω₂)` 的情况。它更靠近类别 `ω₂` 的均值点，从而扩大了判定为概率较大类别的区域。请注意，在这种情况下，公式 (7.22) 中比率的对数为正。最后，虚线对应于等概率情况，且公共协方差矩阵具有更一般的形式 `Σ ≠ σ²I`。分隔超平面穿过 `x₀`，但会旋转以垂直于向量 `Σ⁻¹(μ₁ − μ₂)`，根据公式 (7.20)–(7.21)。对于这三种情况中的每一种，未知点均根据其位于相应超平面的哪一侧进行分类。

### M 类问题泛化

之前针对二分类任务所述内容可推广至更一般的*M*类问题。与类别*ω*[*i*]，*ω*[*j*]相关的两个相邻区域ℛ[*i*]，ℛ[*j*]的分离超曲面遵循与之前相同的论证。例如，假设所有协方差矩阵均相同，则区域通过超平面进行划分，如图 7.6 所示。注意，判决线（实红线）平分连接三个类别均值的线段（虚线）。此外，每个区域ℛ[*i*]，*i* = 1, 2, …, *M*均为凸集（问题 7.2）；换言之，连接ℛ[*i*]内任意两点的线段上的所有点也位于ℛ[*i*]内。

![Figure 7.6 When data are distributed according to the Gaussian distribution and they share the same covariance matrix in all classes, the feature space is partitioned via hyperplanes, which form polyhedral regions. Note that each region is associated with one class and it is convex.](img/gr006.jpg)

图 7.6 当数据在所有类别中均服从高斯分布且共享相同的协方差矩阵时，特征空间通过超平面进行划分，形成多面体区域。注意每个区域对应一个类别且为凸集。

有两种特殊情况尤为重要，它们能得出简单的分类规则。该规则将针对一般*M*类问题进行表述。

#### 最小距离分类器

存在两种特殊情况，在这两种情况下，最优贝叶斯分类器的计算变得非常简单，且具有浓厚的几何特征。

##### 最小欧氏距离分类器

在以下假设下：(a) 每个类别中的数据服从高斯分布，即公式(7.16)；(b) 类别等概率；(c) 所有类别具有形式为*Σ* = *σ*²*I*的共同协方差矩阵（各个特征相互独立且具有共同方差），贝叶斯分类规则等价于

```
Assign x to class ω_i: i = argmin_j (x - μ_j)^T (x - μ_j), j = 1,2,... M.
```

*   这是在采用上述假设下贝叶斯规则的直接推论。换句话说，计算**x**到所有类别均值的欧氏距离，并将其分配给使该距离最小的类别。
*   对于二分类情况，该分类规则对应于图 7.5 中的实黑线。确实，回顾几何基础知识，位于平分线段**μ**[1] − **μ**[2]的超平面左侧的任意点，在欧氏距离意义上都更靠近**μ**[1]而非**μ**[2]。对于位于超平面右侧的任意点，情况则相反。

##### 最小马氏距离分类器

在先前采用的假设下，但协方差矩阵采用更一般的形式*Σ* ≠ *σ*²*I*时，规则变为

将 $\mathbf{x}$ 分配给类别 $\omega_{i}$：$i = \arg\min\limits_{j}{(\mathbf{x} - \mathbf{\mu}_{j})}^{T}\Sigma^{- 1}(\mathbf{x} - \mathbf{\mu}_{j}),\quad j = 1,2,\ldots M.$

![Equation](img/si107.png)(7.25)

因此，不是寻找最小欧氏距离，而是寻找最小马氏距离；后者是欧氏距离的一种加权形式，旨在考虑底层高斯分布的形状 [38]。对于两类情况，此规则对应于图 7.5 中的虚线。

### 备注 7.2

*   在统计学中，采用数据分布的高斯假设有时被称为*线性判别分析*（LDA）或*二次判别分析*（QDA），具体取决于对底层协方差矩阵所采用的假设，这将分别导致线性或二次判别函数。在实践中，通常采用最大似然（ML）方法来获得未知参数的估计，即均值向量和协方差矩阵。回顾第 3 章的示例 3.7，通过 $N$ 次观测 $\mathbf{x}[n],\ n=1,2,\ldots,N$ 获得的高斯 PDF 均值的 ML 估计等于

$${\widehat{\mathbf{\mu}}}_{ML} = \frac{1}{N}\sum\limits_{n = 1}^{N}\mathbf{x}_{n}.$$

![Equation](img/si109.png)

*   此外，利用 $N$ 次观测获得的高斯分布协方差矩阵的 ML 估计由下式给出（问题 7.4）

$${\widehat{\Sigma}}_{ML} = \frac{1}{N}\sum\limits_{n = 1}^{N}(\mathbf{x}_{n} - {\widehat{\mathbf{\mu}}}_{ML}){(\mathbf{x}_{n} - {\widehat{\mathbf{\mu}}}_{ML})}^{T}.$$

![Equation](img/si110.png)(7.26)

*   这对应于协方差矩阵的一个有偏估计量。若（问题 7.5）

### 协方差矩阵估计

$$\widehat{\Sigma} = \frac{1}{N - 1}\sum_{n = 1}^{N}(\mathbf{x}_{n} - \widehat{\mathbf{\mu}}_{ML})(\mathbf{x}_{n} - \widehat{\mathbf{\mu}}_{ML})^{T}.$$

![Equation](img/si111.png)

注意，考虑到其对称性，协方差矩阵中待估计参数的数量为 $O(l^2/2)$。

### 示例 7.3

在一个二分类任务中，两个等概率类别中的每一个的数据都服从高斯分布，均值分别为 **μ**[1] = [0, 0]^T 和 **μ**[2] = [3, 3]^T，共享一个公共协方差矩阵

$$\Sigma = \begin{bmatrix} 1.1 & 0.3 \\ 0.3 & 1.9 \end{bmatrix}.$$

使用贝叶斯分类器将点 **x** = [1.0, 2.2]^T 分类到两个类别之一。

因为类别是等概率的，服从高斯分布，且共享相同的协方差矩阵，贝叶斯分类器等价于最小马氏距离分类器。点 **x** 到类别 *ω*[1] 均值的（平方）马氏距离为

$$d_1^2 = [1.0, 2.2] \begin{bmatrix} 0.95 & -0.15 \\ -0.15 & 0.55 \end{bmatrix} \begin{bmatrix} 1.0 \\ 2.2 \end{bmatrix} = 2.95,$$

其中左边中间的矩阵是协方差矩阵的逆矩阵。同理，对于类别 *ω*[2]，我们得到

$$d_2^2 = [-2.0, -0.8] \begin{bmatrix} 0.95 & -0.15 \\ -0.15 & 0.55 \end{bmatrix} \begin{bmatrix} -2.0 \\ -0.8 \end{bmatrix} = 3.67.$$

因此，该模式被指派给类别 *ω*[1]，因为它到 **μ**[1] 的距离比到 **μ**[2] 的距离更小。验证一下，如果改用欧氏距离，该模式将会被指派给类别 *ω*[2]。

## 7.4 朴素贝叶斯分类器

我们已经看到，在需要估计协方差矩阵的情况下，未知参数的数量级为 `O(l²/2)`。对于高维空间，除了该估计任务极其艰巨这一事实外，还需要大量数据点，以获得统计上良好的估计并避免过拟合，正如第 3 章所讨论的。在这种情况下，人们不得不满足于次优解。确实，在使用相关参数的糟糕估计时采用最优方法，可能会导致整体性能变差。

*朴素贝叶斯分类器* 是次优分类器的一个典型且流行的例子。其基本假设是特征向量中的各分量（特征）在统计上是独立的；因此，联合概率密度函数（PDF）可以写成 *l* 个边缘概率密度函数的乘积，

```
p(x|ω_i) = ∏_{k=1}^{l} p(x_k|ω_i),  i = 1,2,...,M.
```

在采用高斯假设后，每个边缘分布由两个参数（均值和方差）描述；这导致每个类总共需要估计 `2l` 个未知参数。与 `O(l²/2)` 个参数的数量相比，这是一个巨大的节省。结果表明，当数据样本量有限时，这种简化的假设所得到的结果可能比最优贝叶斯分类器更好。

尽管朴素贝叶斯分类器是在高斯分布数据的背景下引入的，但其使用在更一般的情况下也是合理的。在第 3 章中，我们讨论了维度灾难问题，并强调了高维空间是稀疏分布的。换句话说，对于固定有限数量的数据点 *N*，位于每个维度固定大小的超立方体内，空间维度越大，任意两点之间的平均距离就越大。因此，为了在大空间中获得一组参数的良好估计，需要更多的数据。粗略地说，如果在实轴上获得 PDF 的足够好估计需要 *N* 个数据点，那么在 *l* 维空间中获得类似精度将需要 `N^l` 个数据点。因此，通过假设特征相互独立，最终将估计 *l* 个一维 PDF，从而大大减少了对数据的需求。

独立性假设是许多机器学习和统计任务中常见的假设。正如我们将在第 15 章中看到的，可以采用介于两个极端（即完全独立和完全依赖）之间的较温和的独立性假设。

## 7.5 最近邻规则

虽然贝叶斯规则提供了关于分类错误概率的最优解，但其应用需要估计相应的条件 PDF；一旦特征空间的维数取得相对较大的值，这并非易事。这为考虑替代分类规则铺平了道路，这将成为我们从现在开始的关注焦点。

*k-最近邻* (*k-NN*) 规则是一种典型的非参数分类器，也是最流行和最知名的分类器之一。尽管它很简单，但仍在使用，并与一些更复杂的方案齐名。
