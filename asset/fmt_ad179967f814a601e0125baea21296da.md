
在该示例中，当 `try` 语句检测到错误时，将执行 `except` 中的打印语句并输出异常描述信息。当无错误时，将执行 `else` 中的打印语句。

# 第 16 章：Python 中的文件管理

Python 是一种通常涉及大量文件操作的编程语言。它拥有一个专门的库来处理文件管理功能。本章将全面介绍 Python 中所有可用的文件管理方法。我们还提供了 Python 编程代码语句供您进一步分析。让我们开始吧！

## 文件的打开与关闭

让我们想象一下，如果您想使用 Word 文档编写简历，流程应该是怎样的？

1. 打开 Word 文档软件并创建一个新文件。
2. 编写个人简历信息。
3. 保存文件。
4. 关闭 Word 文档软件。

同样，在 Python 中操作文件的整体过程与使用 Word 编写简历的过程非常相似。

1. 打开一个文件或创建一个新文件。
2. 读取/写入数据。
3. 关闭文件。

接下来，我们将分别介绍文件的打开与关闭。

### 文件的打开

在 Python 中，使用 `open` 方法打开文件，语法格式如下：

```
open(文件名 [访问模式信息])
```

在上述格式中，文件名必须填写，而访问模式信息是可选的（访问模式将在本章后面详细描述）。例如，使用以下示例代码打开一个名为 "country.txt" 的文件：

```
entity = open('country.txt')
```

需要注意的是，如果使用 `open` 方法打开文件时未指定访问模式，则必须保证文件存在，否则将报告以下异常信息。

```
FileNotFound {
    // 我们无法找到指定的文件
}
```

### 文档模式

如果使用 `open` 方法仅提供文件名来打开文件，则我们只能读取该文件。如果打开的文件允许写入数据，则必须指明文件的模式。Python 中有许多文件访问模式。`RB`、`WB` 和 `AB` 模式均以二进制模式操作文件。通常，这些模式用于处理二进制类型的文件，如声音或图像。

### 文档的关闭

始终使用 `close` 方法关闭打开的文件。即使程序退出后文件会自动关闭，但考虑到数据安全，每次使用文件后都应使用 `close` 方法将其关闭。否则，一旦程序崩溃，文件中的数据可能无法保存。`close` 方法使用非常简单，具体示例如下：

```
# 创建一个名为 country.txt 的新文件
sample = open('country.txt', 'w')
# 关闭该文件
sample.close()
```

## 文档的读取与写入

文件最重要的能力是接收数据或提供数据。文件的读写无非是将数据写入文件或从文件中读取数据。接下来，本节将分别解释文件的读取与写入。

### 写入文档

向文件写入数据需要使用 `write` 方法完成。在操作文件时，每次调用 `write` 方法，写入的数据都将追加到文件末尾。

**示例：向文件写入数据**

```
f = open('data.txt', 'w')
f.write('This is an example for writing data')
f.close()
```

程序运行后，程序所在路径下将生成一个名为 `data.txt` 的文件。打开该文件，可以看到数据已成功写入。

> **注意：** 向文件写入数据时，如果文件不存在，系统会自动创建文件并写入数据。如果文件已存在，原文件的数据将被清空并重写新数据。

### 读取文档

从文件读取数据时，可以通过多种方式获取，如下所示。

#### 1. 使用 read 方法读取文件

`read` 方法可从文件读取数据，其定义语法如下：

```
read(size)
```

在上述方法中，`size` 表示从文件读取的数据长度，单位为字节。如果未指定 `size`，则读取文件的所有数据。

**示例：使用 read 方法读取文件**

```
example = open('data.txt', 'r')
value = f.read(22)
value = f.read()
```

#### 2. 使用 readlines 方法读取文件

如果文件内容很少，可以使用 `readlines` 方法一次性读取整个文件的内容。`readlines` 方法返回一个列表，列表中的每个元素为文件中的每一行数据。假设文件 `data.txt` 包含三行数据，则使用 `readlines` 方法读取文件的方式如下例所示。

**示例：使用 readlines 方法读取文件**

```
sample = open('data.txt', 'r')
entity = f.readlines()
```

### 文件读写的应用——制作文件备份

在实际开发中，文件的读写可以实现许多功能。例如，文件备份就是读写文件的过程。

此时，如果要为 `data.txt` 制作备份文件，需要读取原文件的数据，并将获取的数据写入备份文件。与原文件相比，备份文件存储了与原文件相同的数据。

**示例：制作文件备份**

```

## 文件的定位、读取与写入

在之前的学习中，文档的读写都是按顺序进行的。然而，在实际开发中，可能需要从文件的特定位置开始读写。此时，我们需要定位文件的读写位置，包括获取文件当前的读写位置和定位文件指定的读写位置。在下一节中，将详细介绍这两种定位方法。

### 1. 使用 tell 方法获取文件当前的读写位置

在读写文件的过程中，如果想知道当前位置，可以使用 `tell` 方法获取。`tell` 方法返回文件的当前位置，即文件指针的当前位置。

**示例：使用 tell 方法获取文件当前的读写位置**

```
place = get.tell()
print("Required position:", place)
value = set.read(3)
print("The data read is:", str)

```

### 2. 使用 seek 方法定位文件指定的读写位置

如果在读写文件的过程中需要从指定位置开始读写，可以使用 `seek` 方法。`seek` 方法的定义语法如下：

```
seek(offset[, whence])
```

`seek` 方法的参数说明如下。

1. `offset`：表示偏移量，即要移动的字节数。
2. `whence` 表示方向。该参数有三个值：
   - `SEEK_SET` 或 `0`（默认）：`whence` 参数表示从文件起始位置偏移。
   - `SEEK_CUR` 或 `1`：表示从文件当前位置偏移。
   - `SEEK_END` 或 `2`：表示从文件末尾偏移。

**示例：使用 seek 方法定位文件指定位置**

```
value.seek(4)
# Find Current position
place = get.tell()

```

## 文件的重命名与删除

有时，需要对文件进行重命名和删除。Python 的 `os` 模块默认已包含这些功能。接下来，本节将详细解释文件的重命名与删除。

### 文件的重命名

`os` 模块的 `rename` 方法可完成文件重命名，格式如下：

```
os.rename(src, dst)
```

在上述格式中，`src` 指要修改的文件名，`dst` 指修改后的新文件名。例如，将文件 "Hotel.txt" 重命名为 "Restaurant.txt" 的示例代码如下：

```
import os
os.rename("hotel.txt", "restaurant.txt")
```

### 文档的删除

`os` 模块的 `remove` 方法可完成文件删除，格式如下：

```
os.remove(path)
```

在上述格式中，`path` 指指定路径下的文件。例如，删除当前路径下文件 "Tour.txt" 的示例代码如下：

```
import os
os.remove("tour.txt")
```

## 文件夹操作

在实际开发中，有时需要以编程方式操作文件夹，如创建和删除。正如文件操作需要 `os` 模块一样，文件夹操作也需要 `os` 模块。在下一节中，将说明文件夹的创建、当前目录的获取、文件默认目录的更改和文件夹的删除。

### 1. 创建文件夹

`os` 模块的 `mkdir` 方法用于创建文件夹，示例代码如下：

```
import os
os.mkdir("Executive")

`os` 模块的 `getcwd` 方法用于获取当前目录。示例代码如下：

os.getcwd()
```

### 3. 更改默认目录

`os` 模块的 `chdir` 方法用于更改默认目录，例如，将当前目录更改为上一级目录的代码如下：

import os
os.chdir("../")

### 4. 获取目录列表

`os` 模块的 `listdir` 方法用于获取目录列表。例如，获取当前路径下的子目录列表，代码如下：

import os
os.listdir("./")
```

### 5. 删除文件夹

`os` 模块的 `rmdir` 方法用于删除文件夹。例如，以下代码删除当前路径下的 "Executive" 目录：

```
import os
os.rmdir("Executive")
```
