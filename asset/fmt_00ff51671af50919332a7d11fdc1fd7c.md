
这一背景引发了相关研究热潮，许多有趣的发现挑战了以往的观点。在本书编写之时，这仍是一个热门研究课题。我们的目的不是提供广泛的相关讨论，而是给出一些基本方向和见解，并使读者意识到该问题。例如，文献[34]指出，一个更深层的困难，特别是在高维问题中，源于`鞍点`的激增。此类点的存在会显著减慢训练算法的收敛速度。文献[53]指出，大量鞍点对梯度下降的影响尚不清楚，因为梯度值可能非常小而减慢收敛速度，但算法似乎能逃离这些临界点。文献[32]声称，在大规模网络中，大多数局部极小值产生较低的代价值，并在测试集上表现出相似的性能。此外，随着网络规模增大，找到劣质（高代价值）局部极小值的概率快速下降。这两篇文献都借用了统计物理学中高斯随机场的结果。文献[98]通过不同的数学路径得出了本质相似的结果。文中证明，对于平方误差损失函数和深度线性神经网络，每一个局部极小值也是全局极小值。此外，每一个不是全局极小值的临界点必然是鞍点。在一定独立性假设下，结果可推广到非线性网络。在一篇较新的文献[40]中，通过梯度下降算法的收敛性回答了该问题。对于平方误差损失函数的情况，证明了梯度下降在训练深度神经网络时能找到全局极小值；尽管代价函数关于相关参数是非凸的。文中证明梯度下降能在多项式时间内实现零训练损失。该文涉及三种不同类型的过参数化神经网络：全连接、卷积和残差深度网络，将在第 18.12 节讨论。文献[104]研究了随机梯度下降的收敛性，并指出只要这些区域的邻域包含足够的梯度信息，算法就不会卡在直径较小的局部极小值处。邻域大小由步长和梯度噪声控制。鞍点的情况及如何逃离它们在文献[93,145]等中有论述。相关理论结果的总结见文献[42,195]等。

### 泛化性能与双重下降曲线现象

上一段简要介绍了与训练算法收敛性和优化任务非凸性相关的一些问题。讨论的重点现在转向深度网络的泛化性能相关问题。这仍是一个存在开放理论挑战的任务，该课题是当前活跃的研究领域。

任何学习器（当然包括深度神经网络）的泛化性能，由训练误差与测试误差之间的差异来量化。好的学习器是指测试误差和训练误差取值接近的情况。此外，正如我们在第 3 章讨论的，如果参数数量相对于训练数据规模足够大，就会发生过拟合，我们预期测试误差会偏离训练误差。然而，在深度网络的情况下，我们面临一个“悖论”。

训练非常大的过参数化网络，其中参数数量`K`大于训练集大小`N`，即使`没有显式正则化`，所得网络在大多数情况下也表现出良好的泛化性能！这一发现与我们熟悉的图 3.12 的 U 型曲线相矛盾。第 3.13 节的要点是，随着参数数量（模型复杂度）`K`的增加，测试误差最初下降至某一点，然后开始上升。同时，训练误差持续下降至零。文献[11]挑战了测试误差这种被广泛接受的行为，报告称测试误差的 U 型趋势仅在`欠参数化`区域成立，即`K`小于`N`的取值区域。然而，如果在`过参数化`区域持续增加参数数量，使`K`大于`N`，则测试误差可能会再次开始下降。事实上，最小测试误差往往出现在“无限复杂度”处，即模型越过参数化，测试误差越小。这被称为`双重下降误差曲线`现象，让机器学习界感到困惑。图 18.17 展示了双重下降误差曲线的总体趋势。测试误差曲线的两部分故意显示为不连续，因为从欠参数化区域到过参数化区域的过渡部分形状取决于具体情况。例如，在某些模型中（如文献[12]、[65]），测试误差在`K = N`处趋于无穷大。重要的结论是，测试误差在`K = N`点之后开始下降。在本书当前版本编写之时，对双重下降曲线的解释和完全理解仍是正在进行的研究课题。

![图 18.17 训练误差持续降至零。在欠参数化（K < N）区域，测试误差随着参数数量的增加开始下降，并在某一点开始上升。在过参数化区域（K > N），测试误差再次持续下降。](img/gr017.jpg)

**图 18.17** 训练误差持续降至零。在欠参数化（`K` < `N`）区域，测试误差随着参数数量的增加开始下降，并在某一点开始上升。在过参数化区域（`K` > `N`），测试误差再次持续下降。

文献 [222] 表明，深度神经网络能轻松拟合`随机标签`。换句话说，神经网络的有效容量足以对整个数据集进行暴力`记忆`。此外，文中指出，这与经典的凸经验风险最小化形成对比，后者需要显式正则化来排除平凡解；而在深度神经网络的世界里，正则化似乎有助于改善模型的最终测试误差，但其缺失并不一定会导致泛化性能变差。请注意，在过参数化区域，存在不止一种可能的解。

人们试图通过梯度下降算法施加的隐式正则化来解释双重下降曲线现象。最简单的例子是欠定模型的最小二乘解。我们知道（例如第 6.4 节和第 9.5 节），对于这种参数多于方程的模型，使用输入矩阵的伪逆可得到最小范数解。文献 [4] 表明，对于最小二乘任务且从零开始迭代，梯度下降算法收敛于最小 ℓ₂ 范数解。事实证明，当使用梯度下降算法（例如 [63]）或其随机梯度版本（例如 [159]）时，类似的论据对其他代价函数和模型也成立。正如文献 [191] 所述，训练目标存在许多全局极小值，其中大多数泛化效果不佳，但优化算法（如梯度下降）会将解偏向于一个确实能良好泛化的特定极小值。文献 [101] 通过实验研究了批量大小对泛化能力的影响，指出小批量大小具有有益效果。该文献中的一些论点在文献 [39] 中受到质疑。

文献 [11] 在函数平滑性和小范数解的背景下讨论了过参数化网络的泛化能力。回顾一下，在过参数化区域，所有可能的学习预测器都（几乎）完美地学习了训练数据，并对应于（理论上的）零训练误差。换句话说，学习到的预测器是（接近）完美的插值器。文献 [11] 提出了这样一个问题：为什么某些预测器，特别是来自更复杂模型的预测器，会比其他预测器具有更低的测试误差？文中给出的答案是（针对文中研究的问题），所需的似乎恰当的归纳偏置是函数的`规则性`或`平滑性`，由特定的函数空间范数来度量。这符合奥卡姆剃刀原则（第 3.9.2 节）。选择完美拟合观测数据的最平滑函数，可视为与观测相容的最简单解释。包含大量参数的复杂模型（更大的函数类）包含更多与数据相容的候选预测器，因此我们能够找到具有更小范数、因而“更简单”的插值函数。函数插值平滑性问题在文献 [24] 中再次被提及。文中表明，拟合 `l` 维数据的平滑函数至少需要 `lN` 个参数。换句话说，过参数化 `l` 倍对于平滑插值是必要的，这暗示深度学习中使用的大规模模型或许是一种必然。

文献 [12] 指出，双重下降曲线的关键特征也可以在两个简单的随机特征模型中，通过最小二乘/最小范数预测器（即通过数据矩阵的伪逆，第 6.2 节）观察到。文献 [65] 处理了高维最小二乘回归中的最小 ℓ₂ 范数。文中表明，在大规模神经网络中观察到的双重下降行为，在这些更简单的模型中也得到了恢复，这表明过参数化具有潜在益处。涉及岭回归背景下随机特征的双重下降曲线现象在文献 [133] 中有论述。

正如开头所述，这是一个新的研究领域，许多问题和议题仍未解决，不同观点共同推动了讨论（例如 [99]、[140]）。文献 [119] 提供了双重下降曲线现象的简要历史。

## 18.12 卷积神经网络

在我们迄今为止的讨论中，我们假设神经网络的输入层接收的是`特征向量`。这与前几章讨论的任何其他分类器/预测器一致。特征向量是从原始数据生成的，旨在紧凑地保留与当前机器学习任务相关的信息。为此，多年来已经开发了大量技术库，以适应不同应用中数据的性质（例如 [204]）。

20 世纪 80 年代末，另一项突破出现了，当时特征生成阶段被整合为神经网络训练的一部分。其理念是`从数据中学习`特征，`同时`学习神经网络的参数，而不是`独立地`进行。此类网络被称为`卷积神经网络`（CNN），其成功首次在 OCR 任务中的数字识别中得到验证 [111]。“卷积”这个名称源于神经网络的前几层执行卷积运算，而不是全连接网络（第 18.3.1 节）中基本的内积运算。

### 18.12.1 卷积的必要性

让我们首先确保理解为什么在实践中不能直接将神经网络的输入馈送原始数据，例如图像数组或语音片段数字化版本的采样值，以及为什么`预处理`对于生成特征是必要的。这对任何预测器/学习器均适用，而不仅限于神经网络。我们在介绍章节中曾评论过这个问题，但那时理解其真正必要性还为时过早。在许多应用中，直接处理原始数据会使任务变得根本无法处理。

让我们以一个 256 × 256 的图像数组为例。将其向量化后得到输入向量 **x** ∈ ℝ^(*l*)，其中 *l* ≈ 65000。假设第一层的节点数为 *k*[1] = 1000。那么，在全连接网络中，连接所有输入节点到第一层所有节点所涉及的参数 *θ*[*j**k*]，*j* = 1, 2, …, 65000，*k* = 1, 2, …1000 的数量将达到 6500 万量级。如果输入图像是分辨率约为 1000 × 1000 像素的高分辨率图像，这个数字将进一步激增。此外，如果我们处理的是彩色图像，例如采用 RGB（红-绿-蓝）颜色表示方案，输入的维度将乘以三，参数数量也会随之增加。而且，随着隐藏层的增加，参数数量会持续增长。除了相关的计算负载问题外，我们知道训练具有大量参数的网络会严重挑战泛化性能。此类网络需要海量的训练数据才能应对过拟合倾向。

除了参数数量的激增，将图像数组向量化还会导致信息丢失；这是因为我们丢弃了像素在图像区域内如何相互关联这一重要信息。事实上，多年来开发的各种特征生成技术的目标正是如此。也就是说，提取能够量化图像中像素值之间的`相关性`或其他统计`依赖性`的信息。通过这种方式，可以高效地“编码”驻留在原始数据中的与学习相关的信息。

通过采用卷积，可以同时解决这两个问题，即参数爆炸问题以及有用统计信息的提取问题。任何卷积网络涉及的基本步骤包括：

*   卷积步骤，
*   非线性步骤，
*   池化步骤。

#### 卷积步骤

减少参数数量的一种方法是通过`权重共享`，这在第 18.3.1 节末尾已简要讨论。我们现在将借用这一权重共享的思想，并以更复杂的方式加以利用。为此，让我们关注网络输入包含图像的情况。输入图像数组记为`I`。对于图 18.18A 的情况，这是一个 3×3 数组；注意输入`未`向量化。为了强调我们将摆脱全连接前馈网络中乘加（内积）运算的基本原理，我们将使用不同的符号`h`，而不是`θ`，来表示相关参数。

现在让我们引入权重/参数共享的概念。回想一下，在全连接网络中，每个节点都与一个参数`向量` **θ**[i] 相关联，用于第 i 个节点，其维度等于前一层节点的数量。相反，现在每个节点将仅与`单个`参数相关联。为此，将节点排列成二维数组的形式，如图 18.18B 所示。对于图中的情况，我们假设有四个节点排列成 2×2 数组`H`。第一个节点由`h(1, 1)`表征，第二个由`h(1, 2)`表征，依此类推。换句话说，任何终止于第一个节点的连接都将乘以相同的权重`h(1, 1)`，其余节点也有类似的论证。这种基本原理大幅减少了参数数量。然而，为了使其合理，我们必须摆脱全连接网络内积运算的基本原理。确实，为了理解原因，让我们假设在全连接网络中每个节点使用单个参数。那么与第一个节点相关的线性组合器的输出将是`O(1, 1) = h(1, 1)a`，其中`a`是从前一层接收到的节点所有输入之和。第二个节点的相应输出将是`O(1, 2) = h(1, 2)a`，依此类推。因此，所有节点基本上将提供关于输入值的相同信息；唯一的区别将是作用在来自前一层的`相同`输入信息上的不同权重。

![图 18.18 (A) 3×3 输入图像数组。(B) 隐藏层的“节点”可视为二维数组的元素。每个节点对应与数组`H`对应元素相关联的单个参数。在这种情况下，相应数组的大小为 2×2。要执行卷积，需将矩阵`H`滑过矩阵`I`。对于图中的特定设置，有四种不同的位置，在(A)中用不同的颜色和/或线型表示。](img/gr018.jpg)

图 18.18 (A) 3×3 输入图像数组。(B) 隐藏层的“节点”可视为二维数组的元素。每个节点对应与数组`H`对应元素相关联的单个参数。在这种情况下，相应数组的大小为 2×2。要执行卷积，需将矩阵`H`滑过矩阵`I`。对于图中的特定设置，有四种不同的位置，在(A)中用不同的颜色和/或线型表示。

现在让我们引入一个不同的概念，即我们保持每个节点一个参数，但隐藏层的每个输出都传达关于从前一层接收到的各种输入的`不同`信息。为此，我们将引入卷积。在此背景下，隐藏层的节点被解释为数组`H`的元素，我们将`H`与输入数组`I`进行卷积。隐藏层的第一个输出值将是

```
O(1, 1) = h(1, 1)I(1, 1) + h(1, 2)I(1, 2) + h(2, 1)I(2, 1) + h(2, 2)I(2, 2).
```

如果我们将 2 × 2 矩阵 *H* 放在 *I* 的顶部，从左上角开始（图 18.18A 中完整的红色方框表示 *H* 矩阵的位置），则会获得上述结果。然后，我们将两个矩阵重叠部分的对应元素相乘并相加。从物理角度来看，得到的 *O*(1, 1) 值是 *I* 数组中一个`局部`区域的加权平均值。在之前的操作中，图像的对应区域由数组 *I* 左上角 2 × 2 部分内的像素组成。为了获得第二个输出值 *O*(1, 2)，我们将 *H* 向右滑动一个像素，如虚线红色方框所示，并重复上述操作，即

```
O(1, 2) = h(1, 1)I(1, 2) + h(1, 2)I(1, 3) + h(2, 1)I(2, 2) + h(2, 2)I(2, 3).
```

遵循相同的原理，我们滑动 *H* 以“扫描”整个图像数组；因此，又获得了两个输出值，即 *O*(2, 1) 和 *O*(2, 2)。*H* 在 *I* 顶部的四个可能位置在 图 18.18A 中分别用实心红色、虚线红色、深灰色和虚线灰色方框表示。每个位置可获得一个输出值。因此，在上述场景中，第一隐藏层的输出形成一个 2 × 2 数组 *O*。输出数组的每个元素都编码了输入图像不同区域的信息。

在更一般的设定中，两个矩阵 *H* ∈ ℝ^(*m* × *m*) 和 *I* ∈ ℝ^(*l* × *l*) 之间的卷积运算是另一个矩阵，定义为

```
O(i,j) = \sum\limits_{t = 1}^{m}\sum\limits_{r = 1}^{m}h(t,r)I(i + t - 1,j + r - 1),
```

(18.63)

在我们的情况下，*m* < *l*。简而言之，*O*(*i*, *j*) 包含输入数组中一个窗口区域的信息。根据公式 (18.63) 中的定义，元素 *I*(*i*, *j*) 是该窗口区域左上角的元素。窗口的大小取决于 *m* 的值。输出矩阵的大小取决于人们采用何种假设来处理 *I* 边界处的元素/像素。我们稍后将回到这一点。严格来说，在信号处理术语中，公式 (18.63) 称为`互相关`运算。对于卷积运算，正如公式 (4.49) 中已定义的那样，首先必须进行索引翻转。^(¹¹⁹)

之前的讨论“迫使”我们将隐藏层视为一个个相邻节点的集合。而在 CNN 中，每个隐藏层对应一个（或多个，稍后将见）矩阵 `H`。此外，`H` 用于执行卷积运算。从信号处理的角度来看，该矩阵是一个`滤波器`，它作用于输入以产生输出。在机器学习术语中，它也被称为`核`矩阵，而非滤波器。输出矩阵通常被称为`特征图`数组。

总之，通过执行卷积运算而非内积运算，我们实现了最初的目标：(a) 组成隐藏层的参数被`所有`输入像素`共享`，我们不再为每个输入元素（像素）配备专用的参数集；(b) 隐藏层的输出编码了输入图像各区域内的局部邻域相关信息。此外，由于隐藏层的输出也是一个图像数组，可以将其视为第二个隐藏层的输入，从而构建一个包含许多层的网络，每一层都执行卷积运算。

事实上，这种滤波操作传统上被用于从图像中生成特征。不同之处在于，滤波器矩阵的元素是`预先选定`的。以此矩阵为例：

```
H = \begin{bmatrix} {- 1\ } & {- 1\ } & {- 1} \\ {- 1\ } & {8\ } & {- 1} \\ {- 1\ } & {- 1\ } & {- 1} \\ \end{bmatrix}.
```

上述滤波器被称为`边缘检测器`。将图像数组 `I` 与前述矩阵 `H` 进行卷积，可检测图像中的边缘。图 18.19A 显示了小船图像，图 18.19B 显示了用上述滤波器矩阵 `H` 对左侧图像进行滤波后的输出。边缘检测在图像理解中至关重要。此外，通过适当改变 `H` 中的值，可以检测不同方向的边缘，例如对角线、垂直、水平；换言之，改变 `H` 的值可以生成不同类型的特征。我们已更接近 CNN 背后的核心思想。

*   •  不使用`固定`的滤波器/核矩阵（如边缘检测器示例），而是将滤波器矩阵 `H` 的值的计算交给训练阶段。换句话说，我们使 `H` 具有数据自适应性，而非预先选定。
*   •  不使用单个滤波器矩阵，而是采用多个。每个矩阵将生成不同类型的特征。例如，一个可能生成对角线边缘，另一个生成水平边缘等。因此，每个隐藏层将包含多个滤波器矩阵。每个滤波器矩阵的元素值将在训练阶段通过优化某个准则来估计/学习。换句话说，CNN 的每个隐藏层都能`最优地`生成一组特征。

图 18.20 展示了 CNN 的输入和第一隐藏层。输入包含一个图像数组。隐藏层由三个滤波器矩阵组成，即 `H`[1]、`H`[2]、`H`[3]。观察可知，每个特征图数组都是将不同的滤波器矩阵在输入图像上滑动（卷积）得到的结果。使用的滤波器越多，提取的特征图越多，原则上网络性能应越好。然而，使用的滤波器越多，需要学习的参数也越多，从而引发计算量以及过拟合问题。请注意，输出特征图数组中的每个像素编码了由相应滤波器矩阵对应位置所定义的窗口区域内的信息。
