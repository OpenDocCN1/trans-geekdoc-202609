## 第 5 章 等式与不等式约束下的优化

## 5.1 引言

让我们全局观察等式约束下的优化问题。显然，每增加一个约束都会使问题更具限制性，任何给定点都需要满足更多条件才能可行。然而，一旦一个点可行，它在最优性上的竞争就变小了。这是因为那些不满足新约束的先前可行点变得不可行，并从可行集中被剔除。注意，当添加约束时，目标函数的梯度需要位于包含之前梯度的更高维线性子空间内。新增约束的梯度与之前约束的梯度结合形成一个基。因此，所考虑点的梯度更有可能位于这个线性子空间内。

现在假设添加一个不等式约束 `h(x) <= 0`，假设点 `x` 满足该约束及之前的约束。这有助于我们增加 `∇f(x)` 所在的子空间吗？为了回答这个问题，我们需要考虑两种详尽且互斥的情况：`h(x) < 0`，此时添加的约束在 `x` 处是非紧（有时称为非活跃的）；以及 `h(x) = 0` 的情况，此时约束在 `x` 处是紧（或活跃的）。

让我们处理第一种情况。鉴于约束是非紧，在任何方向上改变 `x` 都不会违反该约束。因此，我们在检查 `x` 处的局部最优性时需要考虑的方向在额外约束下并没有减少。换句话说，`∇h(x)` 不能被添加到跨越 `∇f(x)` 所在子空间的基中。提到这一点可能看起来很奇怪，但它等同于坚持将 `∇h(x)` 引入基中，迫使 `∇h(x)` 在 `∇f(x)` 的表达式中的系数为零。换句话说，这等同于使 `∇h(x)` 的拉格朗乘子为零。寻找拉格朗乘子 `μ` 的问题……

## 5.2 等式与不等式约束下的优化

下文定理经过论证，是本节的 KKT 条件。

## 定理

**定理 5.1.** 考虑以下约束问题：

```
min_x f(x),     (5.1)
s.t.  g_i(x) = 0,  1 <= i <= m,
      h_j(x) <= 0,  1 <= j <= k.
```

假设 `x*` 是可行解。同时，假设紧约束的梯度在 `x*` 处是线性独立的。那么，`x*` 为局部最小值的必要条件是存在 `λ_i, 1 <= i <= m` 和 `μ_j <= 0, 1 <= j <= k`，使得：

```
∇f(x*) - Σ_{i=1}^m λ_i ∇g_i(x*) - Σ_{j=1}^k μ_j ∇h_j(x*) = 0 ∈ R^n
```

并且

```
Σ_{j=1}^k μ_j h_j(x*) = 0.
```

注意条件 `μ_j h_j(x*) = 0, 1 <= j <= k` 逻辑上遵循上述定理。这些被称为*互补松性条件*。特别是，与非紧约束相关的拉格朗乘子为零。另一方面，尽管可能不大，零也是紧约束拉格朗乘子的一个可能值。

**示例.** 考虑以下凸优化问题：

```
min_{x_1, x_2}  4x_1^2 + x_2^2 - x_1 - 2x_2,
s.t.  2x_1 + x_2 <= 1,
      x_1^2 <= 1.
```

**解.** 引入拉格朗日乘数，我们得到拉格朗日函数为：

`L(x_1, x_2, μ_1, μ_2) = 4x_1^2 + x_2^2 - 2x_2 - μ_1(2x_1 + x_2 - 1) - μ_2(x_1^2 - 1).`

KKT 条件为：

- (i) `2x_1 - 1 + 2μ_1 - 2μ_2x_1 = 0`，
- (ii) `2x_2 - 2 - μ_1 = 0`，
- (iii) `μ_1(x_1 + x_2 - 1) = 0`，
- (iv) `μ_2(x_1^2 - 1) = 0`，
- (v) `2x_1 + x_2 <= 1`，
- (vi) `x_2^2 <= 1`，
- (vii) `μ_1, μ_2 <= 0`。

我们从假设 `μ_1 = 0` 开始。根据 (ii) 可得 `x_2 = 1`，而 (i) 产生 `x_1 = 1`。由于 `μ_2 <= 0` 且 `x_1 < 1`，因此根据 (iv)，我们得出 `μ_2 = 0`，这导致 `x_1 = 1/2`。这一结果结合 `x_2 = 1` 与 (v) 冲突，从而否定了 `μ_1 = 0` 的假设。由于剩下的唯一选择是 `μ_1 < 0`，根据 (iii) 得到 `2x_1 + x_2 - 1 = 0`，即 `x_2 = 1 - 2x_1`。将原问题转换为以下单变量问题：

```
min_{x_1} 4x_1^2 + (1 - 2x_1)^2 - x_1 - 2(1 + 2x_1), s.t. x_1^2 <= 1.
```

目标函数是二次的，在 `x_1 = 1/10` 处取得全局最小值。事实证明该解满足约束条件 `x_1 <= 1`（严格不等式），因此它是该约束优化问题的最优解。简单计算即可得到解 `(x_1, x_2) = (1/16, 7/8)`。为了完整起见，注意根据 (ii) `μ_1 = -1/4`，根据 (iv)（由于 `x_1 < 1`），`μ_2 = 0`。

2. 最优解满足哪些一阶必要条件 (FOCs)？

## 5.2.1 二阶条件 (SOC)

以下定理给出了最优性的二阶条件 (SOCs)。

> **定理 5.2.** 设 `x*, λ` 和 `μ` 为满足定理 5.1 条件的三元组。对于可行解 `x*`，令 `A` 为不等式约束的（可能为空）集合。那么，`x*` 处取得局部最小值的必要条件是：
>
> ```
> d^T ∇^2 f(x*) - Σ_{i=1}^m λ_i ∇^2 g_i(x*) - Σ_{j∈A} μ_j ∇^2 h_j(x*) d >= 0,     (5.2)
> ```
>
> 对于所有满足 `d^T ∇g_i(x*) = 0 (1 <= i <= m)` 且 `d^T ∇h_j(x*) = 0 (j ∈ A)` 的方向 `d`。将“`>=`”符号替换为“`>` (`d ≠ 0`)”，该条件是充分的。

### 5.2.2 凸规划

考虑以下约束优化问题：

`min f(x)`，

s.t. `g_i(x) = 0, 1 <= i <= m, h_j(x) <= 0, 1 <= j <= k.`

为了构造可行解，需要两个假设。第一个是函数 `g_i(x), 1 <= i <= m` 是仿射的。事实上，如果额外 `g_i(x) = 0`，则意味着对于任何 `0 <= α <= 1` 的 `α`，都有 `g_i(αx* + (1-α)x) = 0`。注意对于此类函数 `∇^2 g_i(x) = 0`。第二个假设是函数 `h_j(x), 1 <= j <= k` 是凸的。特别是，对于任何 `x`，`∇^2 h_j(x)` 非负。对于此类函数，如果 `h_j(x*) <= 0` 且 `h_j(x) = 0`，那么对于任何 `0 <= α <= 1` 的 `α`，`h_j(αx* + (1-α)x) <= 0`。

现在考虑定理 5.2。如果 `f(x)` 是凸的，那么 `x*` 结合最优值 `λ` 和 `μ` 满足最小点的 FOC，如果满足上述条件，则 SOC 同样满足。在简单的分析中：考虑优化时只需考虑 FOC。更重要的是，省略的定理 4.4 的对应结论也成立。

> **定理 5.3.** 如果 `f(x)` 是凸的，`g_i(x), 1 <= i <= m` 是仿射的，且 `h_j(x), 1 <= j <= k` 是凸的，那么如果 `x*` 满足 (5.1) 的 FOC，则是全局最优解。

应用于此类问题的优化理论分支称为凸规划。本节使用的术语是：凸集的交集本身是凸集，这形成了问题的可行集。对偶函数像以前一样通过 `(λ, μ)` 定义，但增加了一个额外的约束：`μ >= 0`。此外，在凸规划的情况下，满足定理 5.2 中的条件对于全局最小化（而非局部最小化）是充分的。注意在最大化问题的情况下，凸规划的假设要求 `h_j(x), 1 <= j <= k` 是凹的（而非凸的）。然而，如果假设 `f(x)` 是凹的，回现在 `μ_j >= 0, 1 <= j <= k`，且由于 `∇^2 f(x*)` 非正的，不等式 (5.2) 需要反转。

最后，我们想说明第 4.2.1 节中的示例 1 到示例 7 满足凸规划条件。对于这些示例中的某些，上述断言已得到证明。其余示例留给读者。最后，该条件适用于第 2.3.2 节介绍的最小二乘问题。具体而言，对于该节定义的 `A`，`∇^2f(x*) = A^TA`，该矩阵在 `A` 为满秩矩阵时被证明是可逆的。因此，矩阵也是正的。^a

## 5.2.3 示例：两个独立分类变量的极大似然估计 (MLEs)

假设有两个随机变量。第一个有 `k` 种可能，第二个有 `h` 种。总体中的每个个体都拥有这两个类别中的一个特征。用 `α_i` 表示属于第一个变量第 `i` 类的概率，`1 <= i <= k, α_i >= 0`，且 `Σ_{i=1}^k α_i = 1`。同样地为第二个类别定义 `β_j, 1 <= j <= h`。最后假设这两个类别是独立的。

为了估计定义的概率，取一个容量为 `N` 的样本。用 `N_{ij}` 表示属于所谓 `(i,j)` 单元的随机数量，`1 <= i <= k, 1 <= j <= h`。假设没有任何一个值 `Σ_{j=1}^h N_{ij}, 1 <= i <= k` 和 `Σ_{i=1}^k N_{ij}, 1 <= j <= h` 等于零。在不与概率相关的常数范围内，似然函数正比于：

`Π_{1<=i<=k, 1<=j<=h} (α_iβ_j)^{N_{ij}}`

MLE 最大化该值。或者，可以极大化该函数的对数。因此，面临的是以下凹约束极大化问题：

```
max_{p_{ij},1<=i<=k,1<=j<=h} Σ_{1<=k,1<=j<=h} N_{ij}(log α_i + log β_j),
s.t.  Σ_{i=1}^k α_i = 1,
      Σ_{j=1}^h β_j = 1,
      α_i >= 0,  1<=i<=k,
      β_j >= 0,  1<=j<=h.
```

这是一个我们接下来要解决的凸规划问题。
由于任何决策变量为零都会导致目标函数值为负无穷，因此对应的拉格朗日值为 0。因此，拉格朗日函数等于：

```
Σ_{1<=k,1<=j<=h} N_{ij}(log α_i + log β_j) - λ_1 (Σ_{i=1}^k α_i - 1) - λ_2 (Σ_{j=1}^h β_j - 1)
```

对 `α_i` 求导，我们得到：

```
(Σ_{j=1}^h N_{ij}) / α_i - λ_1 = 0
```

将其设为 0，得到：

```
α_i ∝ Σ_{j=1}^h N_{ij},  1<=i<=k.
```

`Σ_{i=1}^k α_i = 1` 的事实意味着 `α_i` 的极大似然估计（MLE）等于：

```
α_i = (Σ_{j=1}^h N_{ij}) / (Σ_{l=1}^k Σ_{j=1}^h N_{lj}),  1<=i<=k.
```

对于 `β_j` 存在类似的 MLE 表达式：

```
β_j = (Σ_{i=1}^k N_{ij}) / (Σ_{l=1}^k Σ_{i=1}^h N_{il}),  1<=j<=h.
```

最后，检查上述问题，我们可以看到 `α` 和 `β` 变量在意义上是分离的。因此，它们可以作为两个独立的问题来解决。此外，结果表明每个问题与第 3.2.4 节所述的问题相同。特别是，上述结果适用于 `Σ_{j=1}^h N_{ij}, 1<=i<=k` 和 `Σ_{i=1}^k N_{ij}, 1<=j<=h` 为零的情况。

## 支持向量机 (SVM)

考虑由满足 `a^T x - b = 0` 的所有 `x ∈ R^n` 组成的超平面。设 `x_i ∈ R^n, 1<=i<=m` 为一组点。点位于超平面上方（或下方）如果 `a^T x_i - b > 0`（或 `a^T x_i - b < 0, 1<=i<=m`）。在前一种情况下，令 `y_i = 1`，在后一种情况下，令 `y_i = -1, 1<=i<=m`。反之，假设给定 `y_i, 1<=i<=m` 的值，寻找这样的超平面。在大多数情况下，当数据是随机的时，不存在超平面。然而，当 `m` 个点可以分为两类时，它是存在的。在这种情况下，超平面将一类点与另一类分开。显然，这是一个同义反复。参见图 5.1 所示的情况。

一旦存在这样的超平面，通常存在无穷多个。重点在于最大程度分离它们的那一个，这一点将很快说明。当然，这个概念需要定义：首先注意到对于第一类的所有点，`a^T x_i - b >= C_1`，其中 `C_1 > 0`；同样地，对于第二类的所有点，`a^T x_i - b <= -C_2`，其中 `C_2 > 0`。这可以表述为 `y_i(a^T x_i - b) >= min(C_1, C_2), 1<=i<=m`。在不失一般性的情况下，我们可以替换右侧的值（否则除以 `a` 和 `b` 的所有项以改变超平面）。记住这个常数，我们实际上得到了两个平行的超平面。一个是 `a^T x - b - 1 = 0`，第一类的所有点都在其上方；另一个超平面是 `a^T x - b + 1 = 0`，第二类的所有点都在其下方。

我们的目标是找到一对 `a ∈ R^n` 和 `b ∈ R`，使得两个超平面 `a^T x + b - 1 = 0` 和 `a^T x + b + 1 = 0` 之间的距离最大。根据 (3.23)，我们知道这个距离等于 `||a||`。因此，我们希望最小化 `||a||`：

```
min_{a,b ∈ R^n} ||a||^2
```
