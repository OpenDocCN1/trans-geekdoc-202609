### 参数值的影响

所得到的 pdf 的实际用处（在贝叶斯公式中的成功）取决于`a²`的选择。在图 2.4 中，使用了`a²` = 1，但不能保证这在任何未来的应用中有效。为了能够正确调整它，我们需要理解它如何影响复合 pdf 的形状。

检查高斯公式发现，非常小的`a²`值会导致`x`与`µi`之间的差异产生巨大的敏感性；单个钟形函数将非常“窄”，且生成的 pdf 将由“山谷”分隔的陡峰标记。相反，高`a²`的结果将是几乎平坦的 pdf。在两个极端之间寻求折中，如果我们让`a²`取于示例之间的距离，效果将会很好。最简单的解决方案是使用`a² = µmax - µmin`，其中`µmax`和`µmin`分别是`µi`的最大值最小值。如果你认为这太粗略，可以考虑通过示例的数量进行标准化：`a² = (µmax - µmin)/m`。较大的训练集（具有高`m`）将导致高斯分布缩小。最后，在某些领域中，可能会认为每个钟形函数应该有一个自己的方差，与最近的钟形函数的距离成比例。在这种情况下，我们不再允许通过公式 (2.15) 设置`a²`的值。

## 相似性：最近邻分类器

两个看起来非常的植物可能代表同一物种；同样，症状相似的患者患有相同疾病的情况常见。简而言之，相似的对象通常属于同一类——这一观察了一种流行的分类方法的基础：当要求确定对象`x`的类别时，找到与它最相似的训练示例。并将`x`标记为该示例的类。

本解释了如何评估示例之间的相似性，介绍了使用这些相似性进行分类的具体机制，将该方法与贝叶斯分类器的性能进行比较，并介绍了克服某些固有缺陷的方法。

## 3.1 k-近邻规则

我们如何确定一个对象相对于`x`比相对于`y`更相似呢？有些人可能怀疑这是否可行。长颈鹿比马还是比斑马更相似？这类问题引起了怀疑。回答这些问题涉及了太多任意且主观的因素。

### 属性向量的相似性

本书所阐述机器学习任务将这些反对降到了最低。分类器比较的不是真实物体，而是它们基于属性的描述——这绝不是不可逾越的问题。因此，在第 1 章的示例领域中，两个饼之间的相似性可以通过计算它们差异的属性数量来建立：差异越少，相似性越高。表 3.1 中的第一行给出了对象`x`的属性值。对于随后的 12 个训练示例，最右侧的一列指定了给定示例与`x`之间的差异数量。在`ex5`处找到最小值，我们得出结论这是与`x`最相似的训练示例，这表明我们应该将`x`标记为`pos`，即`ex5`的类别。

处理连续属性也同样简单。每个示例都可以表示为`n`维空间中的一个点，这使得计算任意两个示例之间的几何距离成为可能，例如通过欧几里得距离（第 3.2 节将更多关于如何衡量向量之间的距离的内容）。再次，示例在实例空间中越接近，它们的相互相似性就越大。顺便说一下，这就是最近邻分类器的命名来源：在实例空间中，距离`x`最小的训练示例从几何角度来说，就是`x`的最近邻。

### 从单个邻居到 k 个邻居

在噪声领域中，最近邻的证词是不可信的。如果这一个样本的类别标签是错误的怎么办？更稳健的方法是识别不是一个，而是几个最近邻，然后让他们投票。这就是所谓的 k-NN 分类器的精髓，其中`k`是投票邻居的数量——通常是一个由用户指定的参数。表 3.2 中的伪代码总结了该算法。

注意，在二分类领域中，`k`应该是一个奇数以防止出现平局。例如，4-NN 分类器可能会面临正邻居数量与负邻居相同的情况。这在 5-NN 分类器上不会发生。对于具有两个以上类的领域，使用奇数个最近邻不能防止平局。例如，7-NN 分类器可能会发现三个邻居属于`C1`，三个邻居属于`C2`，一个邻居属于`C3`。设计分类器的工程师随后需要定义一种机制在`C1`和`C2`之间进行选择。

### 欧几里得距离

在平面上，点`x = (x1, x2)`和`y = (y1, y2)`之间的几何距离通过勾股定理获得，推广到具有`n`个连续属性的领域，其中`x = (x1, ..., xn)`和`y = (y1, ..., yn)`之间的欧几里得距离定义如下：

```
dE(x, y) = sqrtsum (xi - yi)²)
```
