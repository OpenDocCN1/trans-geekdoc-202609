
我们省略了文献 [198] 中给出的并已在 MOA 版本的 HOT（即 `HOEFFDINGOPTIONTREE`）中实现的其他一些细节。叶节点间的投票是加权的，而非使用简单的多数投票。需要限制树增长的策略，因为如果不加控制，选项树往往会增长得非常快。用于回归的 HOT 在构建过程中有细微差别，相关内容见文献 [140]。

### 7.6.2 随机森林

Breiman [55] 在批处理设定下提出了随机森林，它是树的集成，这些树在输入端和决策树的内部构建过程中都使用了随机化。输入通过采用自助采样样本进行随机化，这与标准的 Bagging 相同。树的构建通过要求每个节点只能使用随机选择的属性子集进行分裂来实现随机化。该子集通常很小，其大小例如为属性总数的平方根。此外，树在生长过程中不进行剪枝。随机森林通常是在许多批处理任务中表现最好的分类器方法之一。

流式随机森林的实现已由 Abdulsalam 等人 [2] 等人提出，他们并未完全使用 Hoeffding Tree，而是采用了另一种类型的在线树构建器。利用 Hoeffding Tree 并发挥 GPU 算力的实现见文献 [167]。这些以及大多数其他流式随机森林实现都采用“替换失败者”策略来应对概念漂移。

遗憾的是，这些随机森林算法都无法有效地与前述各种基于 Bagging 和 Boosting 的算法竞争。然而，最近 Gomes 等人 [125] 提出了自适应随机森林（ARF）算法，它似乎是一个强有力的竞争者。与之前尝试为数据流学习复制随机森林 [124] 的做法相反，ARF 包含一种有效的重采样方法和自适应算子，能够在无需针对不同数据集进行复杂优化的情况下应对不同类型的概念漂移。文献 [125] 中展示的 ARF 并行实现与串行实现相比，在分类性能方面没有退化，因为树和自适应算子彼此独立。

### 7.6.3 受限 Hoeffding Tree 的感知机堆叠

在机器学习中反复观察到的一个现象是：通常，复杂模型会被那些不试图对属性间复杂交互建模的简单模型所超越。Bifet 等人 [31] 针对 Hoeffding Tree 集成研究了这种可能性。与全 Hoeffding Tree 的随机森林不同，他们提出使用带有感知机算法作为元学习器的堆叠方法，并使用小型树。

更准确地说，他们的算法枚举大小为 *k* 的所有属性子集，并在每个子集上学习一棵 Hoeffding Tree。这些树作为输入提供给一个堆叠算法，该算法使用感知机算法作为元学习器。树的生长很快，因为每棵树都很小，我们期望元学习器最终会给最佳的 *k* 个属性组合分配较大的权重。

由于在 *n* 个属性中有 $\binom{n}{k}$ 个大小为 *k* 的集合，因此对于大多数 *n* 值，只有较小的 *k* 值是可行的。当 *k* = 1 时，该算法退化为感知机，但 *k* = 2 被发现适用于中等规模的数据集。为了应对概念漂移，该方法为每棵树添加了一个 `ADWIN` 变化检测器。当一棵树的错误率发生显著变化时，该树将被重置，并使用该属性组合学习一棵新树。文献 [31] 表明，该方法在简单合成数据集上的表现优于 ADWIN Bagging，这表明在预测关键不在于属性的复杂组合的情况下，该方法可能表现良好。

该方法在 MOA 中作为 `LIMATTCLASSIFIER` 实现。

### 7.6.4 自适应大小 Hoeffding Tree

自适应大小 Hoeffding Tree（ASHT）方法 [38] 在 MOA 中作为 `OZABAGASHT` 实现，它创建一个具有以下限制的 Hoeffding Tree 集成：

*   集成中的每棵树都有一个关联值，代表其可达到的最大内部节点数。
*   在一棵树发生节点分裂后，如果其大小超过其关联值，则该树将被重置为一个叶节点。

如果集成中有 *N* 棵树，分配最大尺寸的一种方法是选择 2 的幂：2, 4, … 直到 $2^k$。该方法背后的直觉是：较小的树能更快地适应变化，而较大的树在变化很少或没有变化的时期表现更好，仅仅是因为它们是用更多数据构建的。大小限制为 *s* 的树重置频率约为大小限制为 2*s* 的树的两倍。这为这组树创建了一系列不同的重置速度，因此总有一部分树能很好地逼近当前的变化率。

集成的输出可以是所有树的多数投票，尽管文献 [38] 通过实验发现，按其误差平方的反比对它们进行加权效果更好。每棵树的误差由 `EWMA` 估计器监控。

重要的是要注意，重置会一直发生，即使在平稳数据集上也是如此，但这种行为不应损害集成的预测性能。

## 7.7 循环概念

在许多场景中，数据流分布的演变方式是：过去出现的分布在未来重新出现。具有明显每日、每周或每年周期性的数据流（如天气、客户销售和道路交通）就是例子，但重现也可能以非周期性的方式发生。

针对这些场景，已提出了*循环*或*反复出现的概念*框架 [112, 127, 143, 219]。提案的细节各异，但主要思想是保存一个过去曾有用但已从集成中移除的分类器库，例如因为它们在某个时刻表现不佳。尽管如此，仍会定期重新检查它们的准确性，以防它们似乎又表现良好，如果是，则将它们重新加入集成。

估计一个分类器的准确性所需的样例远少于从头构建一个新分类器所需的样例，因此这种方案以内存换取训练时间。当库变得太大时，需要额外的规则来丢弃分类器。

Gonçalves 和 de Barros [143] 提出的 RCD 循环概念框架可作为 MOA 扩展获得。

## 8 回归

回归是一种学习任务，其目标是预测一个数值，而不是像分类那样预测一个分类属性。分类中使用的一些技术可用于回归，但并非全部。决策树、感知机和惰性学习经过修改后可用于回归。

### 8.1 简介

给定一个要预测的*数值*属性，称为*结果* (outcome)，回归算法构建一个模型，为每个未标记实例 *x* 预测 *x* 的结果的数值预测 *y*。

回归问题的例子包括无法简化为离散标签的数量预测，例如股市价格、产品销量、时间延迟或网站访问量。可以通过将结果的值离散化为区间，将回归问题归约为分类问题；反之，也可以将离散类别转换为数值变量，利用回归算法进行分类。当然，这些转换不一定能产生最优结果。

最简单的回归算法是返回目标属性的平均值。这相当于分类中的多数类方法，即一种不使用其他属性信息的学习器。一种在非流式回归中更有用的方法是*线性回归*。

线性回归构建一个形式为

```
f(x) = w0 + w1*x1 + ... + wp*xp
```

的线性模型 *f*，该模型最小化残差平方和：

```
RSS(w) = Σ(yi - f(xi))²
```

其中输入是 *N* 对 (*x*[*i*]*, y*[*i*]) 的集合。然而，精确解是

```
w = (X^T X)^-1 X^T y
```

这很难增量计算，更不用说在流式设置中了。可以使用随机投影草图给出近似解（例如参见 [73, 248]），但它们在实际数据挖掘中的应用仍处于初步阶段。因此，我们寻找其他更明显具有增量性和自适应性的策略。

### 8.2 评估

为了评估回归方法，我们可以使用与分类相同的方法论，如留出法、预测式和交错测试-训练法，但错误分类率度量不适用。回归中通常考虑以下度量：

*   **均方误差 (MSE)：** 这是最常用的度量，通过实际值与预测值之差的平方的平均值给出误差：

```
MSE = (1/N) * Σ(yi - ŷi)²
```

*   **均方根误差：** 均方误差的平方根：

```
RMSE = sqrt(MSE)
```

*   **相对平方误差：** 回归方法的 MSE 与最简单回归方法（均值回归算法）的 MSE 之比：

```
RSE = MSE(model) / MSE(mean)
```

*   **相对平方根误差：** 相对平方误差的平方根：

```
RRSE = sqrt(RSE)
```

*   **平均绝对误差：** 该度量类似于 MSE，但考虑差值的绝对值：

```
MAE = (1/N) * Σ|yi - ŷi|
```

*   **相对绝对误差：** 类似于相对平方误差，但考虑差值的绝对值：

```
RAE = MAE(model) / MAE(mean)
```

很容易看出，所有这些度量都可以通过在内存中维护固定数量的值来增量计算。

### 8.3 感知机学习

感知机 [37] 在第 6.5 节中作为一种在线分类方法被提出。然而，它也可以很自然地被视为一种回归方法。

给定一个实例对 (*x*[*i*]*, y*[*i*]) 的数据流，其中 *x*[*i*] 是一个示例，*y*[*i*] 是其数值结果值，感知机的目标是在示例上最小化 MSE。为此，策略再次是沿着下降误差梯度的方向移动权重向量 *w* 中的每个权重。

在这种情况下，更新规则变为：

```
w <- w + η * (yi - ŷi) * xi
```

与分类一样，权重可以在每个单独示例上更新，如上述权重所示，或者以小批量为单位进行单次更新步骤。这使我们能够微调更新时间和自适应性之间的权衡。

### 8.4 惰性学习

惰性学习是分类和回归中最简单、最自然的模型之一——特别是 *k* 近邻算法。给定实例间的距离函数 *d*，回归中的 *k*-NN 方法找到最接近待预测实例的 *k* 个实例，并对它们的结果取平均。与分类一样，平均值可以根据到每个邻居的距离进行加权。

该方法的性能强烈依赖于所使用的距离函数。对于具有数值属性的稠密实例，欧几里得距离可能是合适的。对于文本数据，余弦相似度度量或 Jaccard 系数可能更合适。

`IBLStreams` 是由 Shaker 和 Hüllermeier [225] 提出的用于流式回归的惰性学习实现。除了流式 *k*-NN 的基本思想外，它还包括用于从数据库中移除异常点、移除与数据库中已有实例过于接近的实例（因此不太有用），以及自适应选择数据库大小和参数 *k* 的启发式方法。

### 8.5 决策树学习

#### 带漂移检测的快速增量模型树 (FIMT-DD)

带漂移检测的快速增量模型树 (FIMT-DD) 是一种用于流式回归的决策树，由 Ikonomovska 等人 [139] 提出。它是 Hoeffding Tree 方法的扩展，主要在以下方面有所不同：

##### 分裂标准

使用**方差缩减**代替信息增益；即，选择使方差 ![](img/pg146-in-1.png) 最大程度缩减的属性进行分裂。

##### 数值属性

它们通过第 6.4.2 节中详尽二叉树方法的扩展来处理。在树的每个节点，该方法存储一个 `key` 值，并为两个范围 `≤ key` 和 `> key` 分别保留以下信息：

*   数值结果值的总和，
*   结果值平方的总和，以及
*   实例数量的计数。

##### 剪枝

使用一些剪枝规则以避免存储结果的每一个单独值。

##### 叶节点的线性模型

在叶节点使用感知机以适应漂移。

##### 概念漂移处理

在决策树的内部节点使用 Page-Hinkley 检测来检测错误率的变化。

##### 树更新

当子树表现不佳时，利用新到达的实例生长一棵备选树；当（且仅当）备选树表现更好时，它将替换原始树。

总体而言，FIMT-DD 的行为类似于用于分类的 Hoeffding Trees，是回归任务的最先进方法之一。[140] 中随后提出了一种用于回归的选项树。

### 8.6 决策规则

决策规则是一种兼具高表达能力与高可解释性的形式化方法。因此，在批处理场景下，学习决策规则集受到了高度关注。在流式场景中，由 Almeida、Ferreira、Gama、Duarte 和 Bifet [12, 13, 90–92] 开发的 AMRules 算法是第一个且仍然是最流行的规则学习系统。

AMRules 代表自适应模型规则，专门设计用于随着数据流演进而向规则集中添加和移除规则。AMRules 中的规则形式为 `A → M`，其中：

*   前件 `A` 是字面量的合取，`M` 是发出预测的模型。
*   字面量要么是形式为 `A = a` 的条件，其中 `A` 是离散属性，`a` 是其值之一；要么是形式为 `A ≤ v` 或 `A ≥ v` 的条件，其中 `A` 是连续属性，`v` 是实数值。如果示例 `x` 满足规则前件中的所有条件，我们称该规则**覆盖**示例 `x`。
*   模型 `M` 是一个回归模型。AMRules 支持三种类型的回归器：
    1.  由该规则覆盖的示例计算得出的目标属性均值；
    2.  属性的线性组合；以及
    3.  一种自适应策略，在 (1) 和 (2) 之间选择，挑选近期示例上 MSE（均方误差）较低的那个。

AMRules 维护一组既不互斥也不完备的规则，这意味着它们不必覆盖所有示例，且一个示例可能被多条规则覆盖。这使其区别于决策树，后者自然可视为一组互斥且完备的规则。规则集可视为有序或无序；AMRules 同时支持这两种视图。若视为有序，示例的预测为覆盖它的第一条规则的预测。若视为无序，则对覆盖该示例的所有规则进行评估并将其预测结果取平均。此外，AMRules 维护一条特殊的*默认*规则，它没有前件，在没有规则覆盖示例时应用。

算法的核心在于创建新规则、扩展现有规则和删除表现不佳规则的方法。

##### 规则扩展

以类似于 Hoeffding Tree 对树的处理方式，对于每条规则和每个属性，算法监控若将该属性添加到规则中所引入的标准差缩减 (SDR)。如果所有潜在属性中最大的两个 SDR 度量的比值超过阈值，则将具有最大 SDR 的特征添加到规则中以扩展它。当接收到一个示例时，若规则集为有序，则用它更新计算覆盖它的第一条规则的 SDR 值所需的统计量；若规则集为无序，则更新覆盖它的所有规则的统计量。仅当规则接收到一定最小数量的示例 `N[min]` 后，才会考虑对其进行扩展。

##### 规则创建

如果默认规则被扩展，它将成为一条普通规则并被添加到模型的规则集中。一个新的默认规则会被初始化以替代被扩展的那条。

##### 规则删除

使用 Page-Hinkley 检测监控每条规则在其覆盖示例上的错误率。如果检测指示其累积错误超过阈值，则该规则可能被移除。

据 [90, 92] 报道，AMRules 在各种合成和真实数据集上的平均性能优于 IBLStreams 和 FIMT-DD。无序版本似乎能达到比有序版本略低的错误率；然而，这是以可解释性为代价的，因为如果预测来自单条规则，比作为多条规则预测的平均值更容易理解。

### 8.7 MOA 中的回归

MOA 目前包含本章讨论的算法：Average（或 Majority）算法、Perceptron、IBLStreams（作为扩展）和 AMRules。
