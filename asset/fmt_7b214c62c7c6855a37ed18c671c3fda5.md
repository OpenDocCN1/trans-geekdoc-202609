
# 深度神经网络（DNNs）在信道均衡领域的应用日益增加

通常，DNNs 是具有大量隐藏层的神经网络，并具备特征学习能力。在 Ye 等人（2017）中，DNN 被用于 OFDM 网络的信道估计和信号检测。Caciularu 和 Burshtein（2020）中提出了一种基于变分自动编码器的盲均衡器和解码器，用于 ISI 信道中传输符号的均衡和检测。他们证明了与常模算法（CMA）等现有技术相比，基于 DNN 的均衡器在误差率方面有显著提高。Aboutaleb 等人（2020）的研究中提出了一种基于 DNN 的均衡器，用于多层记录的均衡和检测。在这项工作中，卷积神经网络被用于 Viterbi 检测算法的均衡。

# 小波神经网络（WNN）是时间序列分析中的重要工具

与 RBF 神经网络类似，它们是由多个神经元组成的单隐藏层网络，神经元线性添加到输出节点。但与 RBF 神经网络不同，WNN 隐藏层中的神经元利用小波函数进行激活（Yang 和 Hu，2016）。尽管 ANN 可以用于建模任何非线性系统，但经典的 sigmoid 神经网络有一系列缺点。使用 sigmoid 激活函数时，训练算法可能会收敛到局部最优。此外，传统神经网络中的随机权重初始化会导致训练时间延长。WNN 允许对网络参数进行构造初始化，从而缩短训练时间（Alexandridis 和 Zapranis，2013）。WNN 已应用于多种预测场景，如负载预测（Ribeiro 等，2019）、风速预测（Zhang 等，2019）、分布式协作学习（Xie 等，2019）以及信道均衡（Majumder，2020b；Majumder 和 Giri，2020）。

# Pradhan 等人提出了首批用于 WNN 均衡均衡算法（Pradhan 等，2006）

他们提出了一种使用基于扩展尔曼滤波的递归算法训练 WNN 的方案，并证明了其优于 MLP 和 RBF 神经网络。最近，Nanda 等人开发了基于共生生物搜索（SOS）算法训练的 WNN 均衡器（Nanda 和 Jonwal，2017）。他们优化了 WNN 的输出权重以达到所需性能，同时保持平移和扩张参数不变。

# 近期，群体智能算法在各个领域的求解中引起了广泛关注（Nayyar 等，2018；Nayyar 和 Nguyen，2018）

群体智能是指人工智能的一个领域，通过从自然界动物或昆虫的集体行为中获取灵感来设计智能多代理系统（Beni，2020）。Lipa 等人（2015）的研究中，为认知无线网络提出了一种仿生时间同步协议。该协议的灵感来自萤火虫的同步现象，它们似乎一起发光或变暗。

Sutantyo 和 Levi 提出了一种受萤火虫和青蛙启发的同步算法（Sutantyo 和 Levi，2015）。他们通过仿真证明了所提出的基于群体模型具有鲁棒性。Zhao 等（2019）将群体智能应用于风能潜力和预测，这对于风电场管理非常有益。

近期提出了许多基于群体智能的优化算法。蚁群优化算法和粒子群优化是此类算法的最好示例（Mavrovouniotis 等，2017）。受蝗虫群群行为启发，Saremi 等（2017）为悬臂梁提出了一种名为蝗虫优化（GOA）的优化算法。Mirjalili 等人根据海参在移动和觅食时的群集行为，提出了一种名为海参种群优化（SSA）的优化算法。

除了群体智能算法，另一类自然启发算法是进化算法。它们的能力并非来源于群体行为，而是源于进化论以及物种如何世代世代代的发展。该类中的一些优化算法包括遗传算法（Mirjalili，2019）、差分演化（DE）（Opara 和 Arabas，2019）以及基于生物地理学的优化（BBO）（Ma 等，2017）。

由于人工神经网络（ANN）能够精确模拟无线信道中存在的非线性特性，文献中提出了几种通过受自然启发算法优化的神经网络。Das 等人提出了一种由粒子群优化（PSO）算法训练的神经网络均衡器，用于恢复通过经间干扰（ISI）信道和非线性信道的传输信号（Das et al. 2014）。Panda 等人提出了一种基于定向搜索优化（DSO）的神经网络训练算法，用于非线性信道上的均衡（Panda et al. 2015）。随后，作者在 Panda 等人（2014）中还提出了一种由洗牌蛙跳跃算法（SFLA）训练的神经网络均衡器。Sahu 等人（2018）的研究中引入了径向基神经网络用于无线通信信道的均衡，作者提议用 SFLA 训练 RBF-NN。在他们的研究中，Ingle 和 Jatoth（2020）通过 Levy 搜索增强了 JAYA 优化算法，以缓解其因种群多样性缺乏和探索能力弱而导致的缺点。所提出的优化算法随后被用于训练模糊神经网络（FLNN）均衡器。Das 等人（2018）提出了一种量子行为 PSO 算法用于训练基于 ANN 的均衡器。在这项工作中，除了训练网络权重，作者还利用量子 PSO 算法优化了 ANN 扑。

通过广泛的文献调查发现，与 FIR 结构的自适应均衡器相比，基于神经网络的均衡器更适用于非线性信道的均衡。此外，决策反馈均衡器在具有深度谱零点的时变信道中提供更好的 BER 性能。尽管近期有一些关于自然启发算法训练的简单 DFE 均衡器的工作（Iqbal et al. 2015），但基于神经网络的 DFE 及其通过元启发式算法训练的文献较少。受基于 WNN 的均衡器及其 SOS 算法训练的启发（Nanda and Jonwal 2017），我们提出了一种 WNN 决策反馈均衡器（WNN DFE），用于遭受 ISI 和非线性的通信信道。这项工作的重要贡献如下：

1. 提出了一种基于 WNN 和决策反馈原理的新型均衡器架构。所提出的结构允许对通过时变信道和具有深度谱零点信道的传输符号进行均衡。
2. 在这项工作中，我们开发了一种使用布谷搜索优化（CSO）的 WNN 新训练方法。根据我们对现有文献的调查，目前不存在使用 CSO 训练 WNN DFE 均衡器的方案。
3. 与 Nanda 和 Jonwal（2017）提出的 WNN 均衡器相比（其训练过程中仅修改外层权重），所提出的 WNN DFE 训练了网络的所有权重，包括平移和扩张参数。考虑到涉及大量参数，这尤其具有挑战性，但显著提升了性能。

本章其余部分的结构如下：第 8.2 节介绍了研究系统模型和均衡的基本原理。第 8.3 节描述了小波原理和小波神经网络的架构。第 8.4 节介绍了 CSO 算法并给出的 WNN DFE 架构。本节还给出了 WNN DFE 的 CSO 训练算法。第 8.5 节给出并讨论了仿真结果。最后，本章在 8.6 节总结并讨论了未来的工作范围。

## 8.2 系统模型

### 8.2.1 信道均衡

所提均衡器的系统模型如图 8.1 所示。其中，信道被建模为 FIR 滤波器，冲激响应为 `h` = [h₁...hᵢ..., h_Nh]，其中 `N_h` 是响应长度。冲激响应 `h` 反映了信道响应、发射和接收滤波器的组合影响。在这项工作中，我们考虑基带等效模型，信道由时间 `n` 的二进制相移键控（BPSK）符号 `u(n) ∈ {+1, −1}` 激发。信道对输入 `u(n)` 的响应输出为：

```
v(n) = ∑_{i=1}^{N_h} h_i u(n−i)
```

通过发射功率放大器时，非线性效应以函数 `Φ` 的形式引入信号。接收到的信号进一步被加白高斯噪声 `w(n)` 污染，其均值为 `E[w(n)] = 0`，方差为 `σ²`。因此，自适应均衡器的输入给出：

```
x(n) = Φ(v(n)) + w(n)
```

其中 `N` 是接收符号的数量。均衡的目的是减轻 FIR 信道引起的 ISI 效应以及发射/接收硬件引起的失真。需要注意的是，在典型的通信接收机中，均衡器工作在基带并位于匹配滤波器之后。均衡器重构传输序列 `u(n)` 或其延迟版本 `y(n) = u(n−d)`，其中 `d` 是延迟。均衡器使用数据集 `{x(n), y(n)}`, `n = 1, ..., N` 进行训练，目标是最小化误差期望 `E[e(n)] = E[(ŷ(n) — y(n))²]`，其中 `ŷ(n)` 是对应于输入 `x(n)` 的均衡器实际输出。训练完成后固定权重，后续符号根据这些权重进行检测。最后一级是决策设备，它将连续信号映射为离散符号（图 8.1）。对于 BPSK 传输，决策设备的输出给出：

```
û(n) = sign{ŷ(n)} = { 1,  |ŷ(n)| ≥ 0; -1, 其他 }
```

### 8.2.2 决策反馈均衡

第 8.2.1 节描述的线性均衡器模型在 ISI 问题不严重的信道（如线路电话）上是有效的。信道的 ISI 严重程度取决于频谱特性，并用谱值比（EVR）来衡量（Haykin 2008）。具有较大 EVR 的信道具有更高的谱零，线性均衡器需要产生更高的增益来补偿，这将导致噪声增加且性能下降。DFE 等非线性均衡器不受此类限制，通过利用均衡器的先前输出来消除当前符号的 ISI。图 8.2 显示了 DFE 的简化框图，由三个单元组成：前馈滤波器、决策设备和反馈滤波器。均衡器的输入是有噪声的信号 `x(n)`，而输出是传输符号的估计值 `û(n)`。如果前馈滤波器和滤波器的长度分别为 `N_f` 和 `N_b`，则这些滤波器在时间 `n` 的状态给出：

```
x(n) = [x(n), ..., x(n−N_f+1)]  (8.4)
```

```
u(n) = { [y(n−1), ..., y(n−N_b)],  训练模式; [û(n−d−1), ..., û(n−d−N_b)],  决策引导模式 }  (8.5)
```

决策设备的输入随后变为：

```
ŷ(n) = ∑_{i=1}^{N_f} x(n−i+1) h_i^f − ∑_{j=1}^{N_b} û(n−d−j) h_j^b  (8.6)
```

其中 `[h_1^f, ..., h_{N_f}^f]` 和 `[h_1^b, ..., h_{N_b}^b]` 分别是前馈和反馈滤波器的系数。

![](img/fd1f01f43f8aeb7701cd9d187a2e8d_205.png)

图 8.2 DFE 的简单框图。

在训练模式下，方程 (8.6) 中的符号 `[û(n−d−1), ..., û(n−d−N_b)]` 被已知目标向量 `[y(n−1), ... y(n−N_b)]` 替换。误差信号给出：

```
e(n) = { y(n) − ŷ(n),  训练模式; û(n−d) − ŷ(n),  决策引导模式 }  (8.7)
```

训练算法的目标是最小化 `E[e(n)²]`，这通过调整前馈和反馈滤波器的权重来实现。

## 8.3 小波神经网络

小波首次引入多分辨率分析领域，后应用于信号处理在内的许多领域（Goswami and Chan 2011）。另一方面，WNN 通常是一个由输入层、隐藏层和输出层组成的三层神经网络。与 ANN 相，WNN 的隐藏层使用小波基作为激活函数而不是 sigmoid 函数。WNN 的思想是迭代更新适用于训练数据的小波基参数。在本节中，将解释小波分析和 WNN 的基本概念。

### 8.3.1 小波分析

小波变换区别于傅里叶变换的能力在于它能够在时频域内高效地表示任意信号。它允许我们识别特定频率成分出现、存在或消失的时间。这是由于小波基函数的紧支撑特性。小波基函数的紧支撑允许小波变换高效地表示信号中的突变或局部特征。

小波基由母小波 `ψ` 的平移和扩张产生。母小波是一种短持续振荡信号，其平均值为零，即：

```
∫ ψ(t) dt = 0  (8.8)
```

满足容性条件等其他要求（Goswami and Chan 2011）。母小波的平移和扩张版本给出：

```
ψ_{a,b}(t) = (1/√a) ψ((t−b)/a)  (8.9)
```

其中

- `a > 0` 是尺度或扩张因子，且
- `b` 是位置或平移因子。

让我们考虑任意函数 `x(t)`。`x(t)` 的连续小波变换（CWT）给出

```
W(a,b) = ∫_{-∞}^{∞} x(t) ψ_{a,b}(t) dt  (8.10)
```

其中 `a ≠ 0`。

小波变换 `W(a,b)` 可以被信号 `x(t)` 中对应基函数 `ψ_{a,b}(t)` 分量的“强度”或“幅度”。逆小波变换 (IWT) 允许从小波系数 `W(a,b)` 重建原始信号：

```
x(t) = (1/C_ψ) ∫_{-∞}^{∞} ∫_{-∞}^{∞} (1/a²) W(a,b) ψ_{a,b}(t) da db  (8.11)
```

其中

```
C_ψ = ∫_{-∞}^{∞} |ψ(ω)|² / ω dω.
```

由于连续小波变换 (CWT) 具有高计算复杂度，离散小波变换 (DWT) 在实践中应用更多。但在 DWT 中，并不是对时间进行离散化，而是将平移和缩放参数取为离散值。如果将方程 (8.10) 中的 `a` 和 `b` 分别替换为 `2^{-j}` 和 `k2^{-j}`，其中 `j,k ∈ ℤ`，则函数 `x(t) ∈ L²` 的 DWT 给出为

```
W_ψ x(j,k) = 2^{j/2} ∫_{-∞}^{∞} x(t) ψ(2^j t − k) dt  (8.12)
```

为了研究从小波系数重建函数的方法以及 WNN（小波神经网络）背后的思想，多分辨率分析 (MRA) 发挥着重要作用。MRA 在不同近似水平或尺度上观察函数。函数 `x(t)` 的各种尺度分解是从将其投影到足够高分辨率的子空间 `C_M` 开始，即

```
x_M = ∑_k c_{M,k} φ(2^M t − k) ∈ C_M  (8.13)
```

因此，空间 `C_∞` 是原始模拟（连续时间）信号 `x(t)` 的空间，而 `x_M ∈ C_M ⊆ C_∞` 是它的低分辨率版本。每个级别的子空间 `C_j` 本身由更粗的近似子空间 `C_{j-1}` 和一个小波子空间 `W_{j-1}` 组成。由于子空间是嵌套的，我们可以写成

```
C_M = W_{M-1} + C_{M-1}
    = ∑_{i=1}^{I} W_{M-i} + C_{M-I}  (8.14)
```

其中 `I` 是子空间或小波分解的层数。

对应子空间中的信号关系如下：

```
x_M(t) = ∑_{i=1}^{J} y_{M-i}(t) + x_{M-J}(t)  (8.15)
```

其中

- `x_{M-J}(t)` 是 `x_M` 最粗的近似，
- `x_j(t) = ∑_k c_{j,k} φ(2^j t − k) ∈ C_j`  (8.16)
- `y_j(t) = ∑_k w_{j,k} ψ(2^j t − k) ∈ W_j`  (8.17)

### 8.3.2 小波神经网络

WNN 将小波和神经网络的原理合为一体。从方程 (8.15) 可以得出，任意函数可以使用来自小波和近似子空间的基函数进行近似。这一思想导致了 WNN 的发展，其中缩放因子和位置因子被迭代调整以近似目标函数。

WNN 的最简单形式仅包含一个隐藏神经元，如图 8.3 所示。它包含输入 `x`、经过 `τ` 平移和由因子 `δ` 缩放的小波函数。该函数的输出 `y` 计算方式如下：

```
y = ψ_{δ,τ}(x) = ψ((x−τ)/δ)  (8.18)
```

此类神经元的输出 `y` 仅在输入位于函数 `ψ_{δ,τ}(x)` 的支撑范围内时才为非零。若干此类单个“小波神经元”或“波子”（wavelons）构成了 WNN 的隐藏层，它们的输出通过线性组合来近似给定函数。小波神经网络根据其架构主要分为两种。第一种基于关系 (8.16)，其中仅使用缩放函数 `φ` 来近似给定函数。在此类 WNN 中，小波分析和神经网络操作是分开执行的（Veitch 2005）。这类网络被称为波网（wavenet），其中网络的信号输入在隐藏层中使用不同的小波基进行分解，然后在输出层进行组合。在波网的架构中，平移和缩放因子是固定的。

![](img/fd1f01f43f8aeb7703cd9d187a2e8_0)

图 8.3 单个波子。

只有从隐藏层到输出的权重 `w_i` 被修改。此类网络的输出给出为

```
y = ∑_{i=1}^{N_θ} w_i φ_{δ,τ}(x)  (19)
```

其中

- `N_θ` 是覆盖待分析函数域的隐藏层单元数，
- `φ_{δ,τ}` 是缩放函数。

波网受限于固定的基函数集，不适用于响应变化的通道。在小波网络的架构中，隐藏单元的平移和缩放参数也被修改。在常用命名中，此类网络被称为*小波网络*（wavelet networks），并在本文中被考虑。图 8.4 显示了一维小波网络的架构。与下一节讨论的多维 WNN 不同，该网络的输入 `x` 是标量或一维序列。该网络中的波子显示为 `ψ_1, ..., ψ_{N_ψ}`，具有相应的平移参数 `τ_1, ..., τ_{N_ψ}` 和缩放参数 `δ_1, ..., δ_{N_ψ}`。输出 `y` 通过加权和获得：
