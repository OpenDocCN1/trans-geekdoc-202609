### 实际问题

在高斯混合任务的实际应用中，可能会遇到的一个问题是：混合成分之一的中心位于某个数据点上（或非常接近该数据点），例如 $\boldsymbol{\mu}[k]^{(j+1)} = \mathbf{x}[n]$，其中 $k$ 和 $n$ 取某些值。在这种情况下，相应高斯分布的指数项变为 1，而该特定成分在对数似然中的贡献等于 $(2\pi\sigma[k]^2)^{-l/2}$。如果此外 $\sigma[k]$ 非常小，这将导致似然值变得很大，尽管这并不表明真实模型已被学习。稍后我们将看到，使用先验可以缓解此类问题。

### 可识别性

与 EM 算法在分布混合背景下相关的另一个问题是：在参数空间中获得的解不是唯一的。对于 $K$ 个混合成分的情况，对于每一个解（参数空间中的一个点），存在 $K! - 1$ 个其他点产生相同的分布。例如，让我们在一维空间中拟合一个两个高斯分量的模型，这将得到相应均值的估计值 $\hat{\mu}[1]$ 和 $\hat{\mu}[2]$。然而，在相应的参数空间中，存在不确定性：这些值究竟定义了点 $\boldsymbol{\mu}[a] = [\hat{\mu}[1], \hat{\mu}[2]]^T$ 还是点 $\boldsymbol{\mu}[b] = [\hat{\mu}[2], \hat{\mu}[1]]^T$。这两个点都产生相同的分布。我们说我们模型中的参数是不可识别的。如果对于 $\boldsymbol{\theta}[1] \neq \boldsymbol{\theta}[2]$，有 $p(\mathbf{x}; \boldsymbol{\theta}[1]) \neq p(\mathbf{x}; \boldsymbol{\theta}[2])$，则称定义分布族 $p(\mathbf{x}; \boldsymbol{\theta})$ 的参数（向量）是*可识别的*（参见文献 [7]）。尽管在我们的语境中——我们的兴趣在于计算 $p(\mathbf{x})$——不可识别性不会造成任何问题，但在关注点在于参数的情况下，这可能是一个问题（参见例如文献 [36]）。

### 学生 $t$ 分布混合

基于正态分布的混合模型的一个显著缺陷是其对异常值的敏感性。有人提出用尾部更重的学生 $t$ 分布（参见第 13.5 节）替换正态分布，以缓解这些缺陷，并已在 EM 算法框架下对所得模型进行了相关处理。尽管步骤变得稍微复杂一些，但迄今为止探讨的思想在这种情况下也能很好地迁移（参见例如文献 [9,10,35,37]）。

## 12.6.1 高斯混合建模与聚类

聚类属于无监督学习家族，是机器学习的重要组成部分，本书不予涵盖。关于聚类的广泛覆盖见文献 [41] 等。然而，通过 EM 算法进行混合建模的任务给了我们一个机会简要论述几句。在不涉及正式定义的情况下，聚类的任务是将若干点 `x[1], …, x[N]` 分配到 `K` 个组或簇中。分配到同一簇的点必须比分配到不同簇的点更“相似”。一些聚类算法需要用户将簇的数量 `K` 作为输入变量提供。其他方案则将其视为一个由算法从数据中恢复的自由参数。聚类中的另一个主要问题是量化“相似性”。不同的定义会导致不同的聚类结果。聚类是点到簇的一种特定分配。通常，根据最优性准则将点分配到簇是一个 NP-hard 任务（见文献 [41] 等）。因此，通常任何聚类算法都只能提供次优解。

### 高斯混合建模

高斯混合建模是常用的聚类算法之一。其主要假设是：属于同一簇的点服从具有未知均值和协方差矩阵的同一高斯分布（这是此处定义相似性的方式）。每个混合成分定义一个不同的簇。因此，目标是对可用数据点运行 EM 算法，以便在收敛后提供后验概率 `P(k|x[n])`，其中 `k = 1, 2, …, K`，`n = 1, 2, …, N`，每个 `k` 对应一个簇。然后，根据以下规则将每个点分配给簇 `k`：

```
assign x_n to cluster k = argmax_i P(i|x_n), i = 1,2,...,K.
```

用于聚类的 EM 算法可被视为一种更原始方案的改进版本，该方案称为 *k-means*（K 均值）或 *isodata* 算法。在 EM 算法中，每个点 `x[n]` 相对于每个簇 `k` 的后验概率是递归计算的。此外，与簇 `k` 相关联的点的均值 `μ[k]` 计算为*所有*训练点的加权平均值（公式 12.60）。相比之下，在 *k-means* 算法中，每次迭代时后验概率在 `{1, 0}` 中取二进制值；对每个点 `x[n]`，计算其到所有当前可用均值估计的欧氏距离，并根据以下规则估计后验概率：

```
P(k|x_n) = { 1, if ||x_n - μ_k||² < ||x_n - μ_j||², j ≠ k,
           { 0, otherwise.
```

*k-means* 算法不涉及协方差矩阵。尽管它很简单，但毫不夸张地说，它是最著名的聚类算法，多年来已提出许多理论论文和改进版本（例如参见 [41]）。鉴于其普及度，我们将在算法 12.1 中给出其描述。

### 算法 12.1：k-means 或 isodata 聚类算法

#### 初始化

1.  选择簇的数量 `K`。
2.  将 `μ[k]`，`k = 1, 2, …, K` 设为任意值。

#### 对于 `n = 1, 2, …, N`，执行

##### K-means 算法步骤

1. 确定最近的聚类均值，记为 `μ[k]`，到 `x[n]`。
2. 设置 `b(n) = k`。

#### End For

#### For `k = 1, 2, …, K`，Do

1. 更新 `μ[k]`，`k = 1, 2, …, K`，作为所有满足 `b(n) = k`、`n = 1, 2, …, N` 的点的均值。

#### End For

#### Until 两次连续迭代之间 `μ[k]`，`k = 1, 2, …, K` 不再发生变化。

`k-means` 算法也可以作为 EM 算法的一个极限情况推导得出（例如，参考文献 [34]）。注意，EM 算法和 `k-means` 算法都只能恢复**紧凑簇**。换句话说，如果点分布在环形簇中，则这类聚类算法不合适。

在第 12.4 节中介绍了 EM 算法，并指出：关于参数集 `ξ` 最大化完全对数似然的期望，等价于最大化相应的证据函数，即 `p(X; ξ)`。然而，这一点并未明确展示。在本节中，这一联系将变得清晰。将表明 EM 算法基本上是最大化证据的一个紧致*下界*。此外，这种对 EM 的解释将允许进行推广，以将其扩展到涉及后验 `p(X^(l)|X; ξ)` 的计算在计算上不可处理的情况。
