
$\sum\limits_{n = 1}^{N}{(x_{n} - \mu)}^{2} = \sum\limits_{n = 1}^{N}{(x_{n} - S_{\mu})}^{2} + N{(S_{\mu} - \mu)}^{2}$

![Equation](img/si197.png)

到联合 PDF 中，我们得到

$p(\mathcal{X};\mu) = \frac{1}{{(2\pi\sigma^{2})}^{\frac{N}{2}}}\exp\left( - \frac{1}{2\sigma^{2}}\sum\limits_{n = 1}^{N}{(x_{n} - S_{\mu})}^{2} \right)\exp\left( - \frac{N}{2\sigma^{2}}{(S_{\mu} - \mu)}^{2} \right),$

![Equation](img/si198.png)

根据因式分解定理，这证明了该断言。

以类似的方式，可以证明（问题 3.10），如果未知参数是方差 `σ²`，则 `S̄_σ² := (1/N) ∑_{n=1}^N (x_n - μ)²` 是充分统计量；如果 `μ` 和 `σ²` 都未知，则充分统计量是集合 `(S_μ, S_σ²)`，其中

```
S_σ² = (1/N) ∑_{n=1}^N (x_n - S_μ)².
```

换句话说，在这种情况下，所有关于未知参数集合的信息（这些信息可以从可用的 `N` 个观测值中提取）都可以通过仅考虑观测值的和及其平方和来完全恢复。

## 3.8 正则化

我们已经看到，在回归模型线性且存在高斯白噪声源的假设下，LS 估计量是 MVU 估计量。我们还知道，通过收缩 MVU 估计量的范数可以提高性能。实现这一目标的方法有很多，将在本书后面讨论。在本节中，我们重点介绍其中一种可能性。此外，我们将看到，试图保持解的范数较小在机器学习背景下服务于重要需求。

**正则化** 是一种数学工具，用于将先验信息施加于解的结构上，该解作为优化任务的结果而得出。正则化最初由伟大的俄罗斯数学家 Andrey Nikolayevich Tychonoff（有时拼作 Tikhonov）针对积分方程的求解提出。有时也称为 Tychonoff–Phillips 正则化，以表彰 David Phillips 独立开发了该方法 [29,39]。

在我们的任务背景下，为了收缩参数向量估计量的范数，我们可以将 Eq. (3.12) 中给出的平方误差和最小化任务重新表述为

```
minimize     J(θ) = ∑_{n=1}^N (y_n - θ^T x_n)²,
```

subject to `‖θ‖² ≤ ρ`，

其中 `‖·‖` 代表向量的欧几里得范数。这样，我们不允许 LS 准则完全“自由”地寻找解，而是*限制*搜索解的空间。显然，使用不同的 `ρ` 值，可以实现不同程度的收缩。正如我们已经讨论的，`ρ` 的最优值无法通过解析方法获得，必须通过实验来选择一个性能良好的估计量。对于之前使用的平方误差损失函数和约束条件，优化任务可以等价地写为 [6,8]

![Equation](img/fx003.jpg)(3.41)

对于特定的 `λ ≥ 0` 和 `ρ` 的选择，这两个任务是等价的。请注意，这个新的代价函数 `L(θ, λ)` 包含一项用于度量模型的*拟合优度*（或称*misfit*，即误差），另一项用于量化参数向量范数的*大小*。很容易看出，对 Eq. (3.41) 中的 `L` 关于 `θ` 求梯度并令其为零，我们可以得到 Eq. (3.13) 线性回归任务的 LS 解的*正则化版本*，

```
(∑_{n=1}^{N} x_n x_n^T + λ I) θ̂ = ∑_{n=1}^{N} y_n x_n,
```

(3.42)

其中 `I` 是维度适当的单位矩阵。`λ` 的存在使得新解偏离了从未正则化的 LS 公式中获得的解。该任务也称为*岭回归*。岭回归试图减小估计向量的范数，*同时*尽量保持平方误差和较小；为了实现这一*组合*目标，向量分量 `θ[i]` 会被修改，使得来自输入空间中信息量较小方向的拟合优度测量项中的贡献被最小化。换句话说，那些与信息量较小方向相关的分量将被推向较小的值，以保持范数较小，同时对拟合优度测量项产生最小影响。我们将在第 6 章更详细地回到这个问题。岭回归最早见于文献 [18]。

必须强调的是，在实践中，偏置参数 `θ[0]` 通常不包含在正则化项的范数中；惩罚偏置会使该过程依赖于为 `y` 选取的原点。确实，很容易验证，如果在代价函数中将常数项加到每个输出值 `y[n]` 上，若偏置项包含在范数中，预测值不会仅仅发生相同常数的平移。因此，通常岭回归被表述为

```
minimize L(θ, λ) = ∑_{n=1}^{N} (y_n - θ_0 - ∑_{i=1}^{l} θ_i x_{ni})² + λ ∑_{i=1}^{l} |θ_i|².
```

(3.43)

结果表明（问题 3.11），关于 `θ[i]`（`i = 0, 1, …, l`）最小化 Eq. (3.43) 等价于使用*中心化*数据并忽略截距项来最小化 Eq. (3.41)。也就是说，求解该任务

### 优化问题与参数估计

目标函数定义为：

$$

\text{minimize}\quad L(\mathbf{\theta},\lambda) = \sum_{n = 1}^{N}\left( (y_{n} - \overline{y}) - \sum_{i = 1}^{l}\theta_{i}(x_{ni} - \overline{x}_{i}) \right)^{2} + \lambda\sum_{i = 1}^{l}|\theta_{i}|^{2},

$$

![Equation](img/si211.png)(3.44)

其中 $\theta_0$ 的估计值由公式 (3.43) 给出，利用获得的估计值 $\hat{\theta}_i$ 表示为：

$$

\widehat{\theta}_{0} = \overline{y} - \sum_{i = 1}^{l}\widehat{\theta}_{i}\overline{x}_{i},

$$

![Equation](img/si212.png)

这里均值定义为：

$$

\overline{y} = \frac{1}{N}\sum_{n = 1}^{N}y_{n}\quad\text{and}\quad\overline{x}_{i} = \frac{1}{N}\sum_{n = 1}^{N}x_{ni},\quad i = 1,2,\ldots,l.

$$

![Equation](img/si213.png)

换句话说，$\hat{\theta}_0$ 补偿了输出变量和输入变量样本均值之间的差异。值得注意的是，如果公式 (3.42) 中用作正则化项的欧几里得范数被其他范数（如 $\ell_1$ 范数，或一般的 $\ell_p$ 范数，$p > 1$，详见 第 9 章）替代，类似的论证依然成立。

从另一个角度来看，减小范数可以被视为一种试图“简化”估计器结构的尝试，因为现在回归量中只有较少数量的分量具有重要影响。如果考虑非线性模型，如第 3.2 节所述，这一观点会变得更加清晰。在这种情况下，公式 (3.41) 中相应参数向量范数的存在迫使模型摆脱非线性展开中不太重要的项，即 $\sum_{k = 1}^{K - 1}\theta_{k}\phi_{k}(\mathbf{x})$，并有效地将 $K$ 推向更低的值。

尽管在当前背景下，复杂性问题以一种相当隐蔽的形式出现，但可以通过选择不同的函数和范数作为正则化项，使其成为博弈中的主要参与者；正如我们接下来将看到的，有许多理由可以证明这种选择是合理的。

#### 逆问题：病态条件与过拟合

机器学习中的大多数任务都属于所谓的*逆问题*。后者包含了所有必须根据一组可用的输出/输入观测值（训练数据）来推断/预测/估计模型值的问题。用不太数学的术语来说，在逆问题中，必须从已知结果中解开未知原因，或者换句话说，反转因果关系。逆问题通常是*病态的*，相对于*良态*问题而言。良态问题的特征在于：(a) 解的存在性，(b) 解的唯一性，以及 (c) 解的稳定性。后一个条件在机器学习问题中通常被违反。这意味着获得的解可能对训练集的变化非常敏感。*病态条件*是用来描述这种敏感性的另一个术语。这种行为的原因在于，用于描述数据的模型可能很复杂，即未知自由参数的数量相对于数据点的数量而言很大。这种现象在机器学习中表现为*过拟合*。这意味着在训练过程中，未知模型的估计参数过度学习了特定训练数据集的特殊性，导致模型在处理除训练集以外的数据集时表现不佳。事实上，第 3.5 节讨论的 MSE 准则试图精确量化这种任务对数据的依赖性，即通过改变训练集，获得的估计值偏离真实值的平均偏差。

当训练样本数量相对于未知参数数量较少时，可用信息不足以“揭示”一个足够好地拟合数据的模型，并且由于噪声和可能存在的异常值，它可能会产生误导。正则化是应对模型复杂性（即使其变得不那么复杂、更平滑）的一种优雅且高效的工具。有不同的方法可以实现这一点。一种方法是约束未知向量的范数，就像岭回归所做的那样。当处理比线性模型更复杂的模型时，可以对所涉及的非线性函数的平滑度施加约束，例如，通过在正则化项中引入模型函数的导数。此外，当采用的模型和训练点数量使得无解时，正则化也能提供帮助。例如，在公式 (3.13) 的最小二乘线性回归任务中，如果训练点数 $N$ 小于回归量 $\mathbf{x}[n]$ 的维度，那么 $(l + 1) \times (l + 1)$ 矩阵 $\overline{\Sigma} = \sum_{n}\mathbf{x}_{n}\mathbf{x}_{n}^{T}$ 将不可逆。确实，求和中的每一项都是一个向量与其自身的外积，因此是一个秩为一的矩阵。因此，正如我们从线性代数中所知，我们至少需要 $l + 1$ 个线性无关的此类矩阵项来保证它们的和是满秩的，从而可逆。然而，在岭回归中，这可以被绕过，因为公式 (3.42) 中 $\lambda I$ 的存在保证了左侧矩阵是可逆的。此外，当 $\overline{\Sigma}$ 可逆但病态时，$\lambda I$ 的存在也能提供帮助。通常在这些情况下，得到的最小二乘解具有非常大的范数，因此是无意义的。正则化有助于将原始的病态问题替换为一个“附近”的良态问题，其解近似于目标解。

正则化有助于获得解的另一个例子是：当模型阶数相对于数据量较大时，尽管我们知道模型是稀疏的。也就是说，模型参数中只有极小比例是非零的。对于这类任务，使用参数向量的 `ℓ₁` 范数来正则化平方误差和代价函数，通过将最不显著的参数赋值为零，从而促进稀疏解的产生；向量的 `ℓ₁` 范数由其分量绝对值之和组成。该问题将在第 9 章和第 10 章中讨论。

正则化与贝叶斯学习中使用先验的任务密切相关，我们将在第 3.11 节中讨论这一点。最后，请注意，正则化并非解决过拟合问题的灵丹妙药。事实上，在公式 (3.3) 中选择合适的函数集 `ℱ` 是第一个关键步骤。估计量复杂度的问题及其对所有可能数据集测量的“平均”性能的影响，将在第 3.9 节中讨论。

##### 示例 3.4

本示例旨在演示：通过岭回归获得的估计量，其均方误差（MSE）性能可能优于无约束最小二乘（LS）解。让我们再次考虑 示例 3.2 中阐述的标量模型，并假设数据按以下方式生成：

```
y[n] = θₒ + η[n],  n = 1, 2, …, N
```

为简单起见，我们假设回归变量 `x[n] ≡ 1`，且 `η[n]`，`n = 1, 2, …, N` 为独立同分布（i.i.d.）的零均值高斯噪声样本，方差为 `σ²_η`。

我们在 示例 3.2 中已经看到，最小二乘参数估计任务的解是样本均值 `θ̂_MVU = (1/N) Σ_{n=1}^N y_n`。我们也已证明该解的 MSE 为 `σ²_η / N`，并且在前述噪声高斯假设下，它达到了 Cramér–Rao 界。现在的问题是：有偏估计量 `θ̂_b`（对应于相关岭回归任务的解）能否实现低于 `MSE(θ̂_MVU)` 的 MSE？

可以很容易地验证，公式 (3.42) 经适配以满足当前线性回归场景的需求后，结果为

$$

\widehat{\theta}_b(\lambda) = \frac{1}{N + \lambda}\sum_{n=1}^{N}y_n = \frac{N}{N + \lambda}\widehat{\theta}_{\text{MVU}},

$$

![Equation](img/si227.png)

其中我们显式地表达了估计值 $\widehat{\theta}_b$ 对正则化参数 $\lambda$ 的依赖关系。注意对于相关的估计器，我们有 $\mathbb{E}[\widehat{\theta}_b(\lambda)] = \frac{N}{N + \lambda}\theta_o$。

简单审视前面的关系式，会让我们回到与公式 (3.24) 相关的讨论。确实，通过遵循类似于第 3.5.1 节中的一系列步骤，可以验证（见问题 3.12）$\text{MSE}(\widehat{\theta}_b)$ 的最小值为

$$

\text{MSE}\left( \widehat{\theta}_b(\lambda_*) \right) = \frac{\frac{\sigma_\eta²}{N}}{1 + \frac{\sigma_\eta²}{N\theta_o²}} < \frac{\sigma_\eta²}{N} = \text{MSE}\left( \widehat{\theta}_{\text{MVU}} \right),

$$

![Equation](img/si230.png)(3.45)

该值在 $\lambda_* = \sigma_\eta² / \theta_o²$ 处取得。因此，关于岭回归估计器是否能改善 MSE 性能的问题，在当前背景下答案是肯定的。事实上，*总是*存在一个 $\lambda > 0$，使得求解公式 (3.41) 一般任务的岭回归估计器，能够实现比 MVU 估计器 [5, Section 8.4] 更低的 MSE。

## 3.9 偏差-方差困境

本节将进一步拓展第 3.5 节的内容。在那里，我们使用 MSE 准则来量化相对于未知参数的性能。这种设定有助于我们理解某些趋势，并更好地消化“有偏”与“无偏”估计的概念。而在本节中，虽然准则保持不变，但将用于更一般的设定。为此，我们将关注点从未知参数转移到因变量上，目标变为在给定回归向量测量值 `x = x` 的情况下，获得因变量 `y` 的估计器。

让我们首先考虑回归的更一般形式，

```
y = g(x) + η,
```

(3.46)

为简单起见且不失一般性，我们再次假设因变量取实轴上的值，即 `y ∈ ℝ`。首先要解决的问题是：是否存在一个能保证最小均方误差性能的估计器。

### 3.9.1 均方误差估计

我们的目标是估计一个未知的（通常是非线性的）函数 `g(x)`。该问题可以置于更一般的估计任务框架中。

考虑*联合分布*的随机变量 `y, x`。然后，给定任意观测值 `x = x ∈ ℝ^(l)`，任务是获得一个函数 `ŷ := ĝ(x) ∈ ℝ`，使得

```
ĝ(x) = arg min[f : ℝ^(l) → ℝ] 𝔼 [(y − f(x))²],
```

(3.47)

其中期望是针对给定 `x` 值时 `y` 的条件概率计算的，换句话说，即 `p(y|x)`。

我们将证明最优估计器是 `y` 的均值，即

```
f(x) = E[y|x] (3.48)
```

**证明**

我们有

```
E[(y - f(x))²] = E[(y - E[y|x] + E[y|x] - f(x))²]
             = E[(y - E[y|x])²] + E[(E[y|x] - f(x))²] + 2E[(y - E[y|x])(E[y|x] - f(x))]
```

其中为了符号便利，省略了期望对 `x` 的依赖。很容易看出，右边最后一项（乘积项）为零，因此我们得到以下结果：

#### 数学推导与最优估计
