
### 19.1.2.2 范围缩放

第二种归一化技术是将变量映射到提供的范围 `[a, b]` 内。公式给出

$$X = a + \frac{(X - \min X)(b - a)}{\max X - \min X}$$ (19.3)

其中我们假设存在 `min X` 和 `max X`。实现如下：

```
.quantQ.preml.scaleNorm::[sample;range]

// sample -- 需要归一化的值数组

// range -- a 和 b 的二维数组

:range[0] + ((sample-min[sample])*(range[1]-range[0]))
```

我们假设 `min X` 和 `max X` 存在。
