## 信息论

任何信息大体上可被视为不确定性的消除。知道某人通过了考试可能不足为奇，但知道某人考了第一名则相当令人惊讶。因此，信息可被视为“惊讶程度”。信息在涉及不可能事件时更有价值。因此，信息量与事件发生概率的倒数相关。让我们用函数 `H(A)` 表示关于事件 A 的信息。如果 A 和 B 是两个无关事件，观察两者获得的信息增益应等于分别观察每个事件获得的信息增益之和。即 `H(A,B) = H(A) + H(B)`。此外，由于 A、B 无关或独立，我们有 `P(A,B) = P(A)P(B)`。因此，对数函数是将概率与信息增益联系起来的良好候选者。此外，H 必须与 P 成反比；因此，我们定义观察事件 A 获得的信息如下：

## 熵

设 X 为遵循概率分布 `p(x)` 的任意离散随机变量。发送方希望将 X 的值传达给接收方。传输的平均信息量可通过计算所发送信息的期望来得出，即：

```
H[X] = E[I(x)] = Σ p(x) I(x) = -Σ p(x) log p(x)
```

指定随机变量 `X` 状态所需的平均信息量 `H[X]` 称为该随机变量的*熵*。对于离散分布，熵的计算很简单。设 `X` 为取整数值 1 到 5 的离散随机变量，概率为 `p = {0.1, 0.6, 0.05, 0.05, 0.2}`。然后，以 2 为底取对数，我们得到以比特为单位的熵 `H = –(.1 × log₂.1 + .6 × log₂.6 + 2 × .05 × log₂.05 + .1 × log₂.1 + .2 × log₂.2) = 1.67`。

在*图 4.20*中，最左边的分布在 `x=2` 处尖峰突起，与中间和右侧分布相比，该分布的熵最低，后两者均匀分散在更多值上。最右边的分布是均匀分布，具有最大熵。我们可以证明，对于取 M 个可能离散值、概率为 `p = {p₁, p₂, …, p_M}`（其中 `Σ p_i = 1`）的离散随机变量，最大熵配置由均匀分布达到。

我们可以将 H 视为一个标量场 `H(p₁, p₂, …, p_M)`（在*第 3 章，向量微积分*中引入），它将概率的 M 元组 `p` 映射为相应的熵，并使用拉格朗日乘数法最大化 H 以强制执行概率归一化约束 `Σ p_i = 1`，如下所示：

```
L = H(p) + λ(Σ p_i - 1)
∂L/∂p_i = -log p_i - 1 + λ = 0
p_i = e^(λ-1) = constant
```

请参阅下图：

![](img/Image42245.jpg)

**图 4.21：** *恒定 H 的椭圆等高线*

这表明离散分布的*最大熵*配置是*均匀分布*。

类似地，连续分布的熵可定义如下：

```
h(X) = -∫ p(x) log p(x) dx
```

这称为*微分熵*或连续熵。与离散熵不同，微分熵可以为负。

现在，让我们寻找连续分布的最大熵配置。对于给定均值 `μ` 的连续分布，最大熵配置由指数分布 `p(x) = (1/μ)e^(-x/μ)` 达到。如果分布的二阶矩或方差 `σ²` 也被指定，则最大熵配置为正态分布 `p(x) = (1/√(2πσ²))e^(-(x-μ)²/(2σ²))`。这些也可以使用相同的拉格朗日乘数技巧来证明。

可以使用联合概率分布 `p(x, y)` 以相同方式为变量 X、Y 的联合分布定义熵：

```
H[X, Y] = -Σ Σ p(x, y) log p(x, y)
```

利用概率乘积法则，`p(x, y) = p(x)p(y|x)`。因此，我们可以写成：

```
H[X, Y] = -Σ Σ p(x)p(y|x) log [p(x)p(y|x)]
```

或者，

```
H[X, Y] = -Σ p(x) log p(x) Σ p(y|x) - Σ p(x) Σ p(y|x) log p(y|x)
```

由于 `Σ p(y|x) = 1`，我们可以将 `H[X, Y]` 写为：

```
H[X, Y] = H[X] + H[Y|X]
```

这里，`H[Y|X]` 称为*条件熵*，即给定 X 取特定值 x 后 Y 的剩余熵。

## 相对熵或 KL 散度

假设发送方希望将随机变量 X 的值传达给接收方。X 遵循某个未知分布 `p(x)`，我们用 `q(x)` 对其进行了近似。如果使用 `q(x)` 来构建编码方案以将 x 的值传输给接收方，则编码 X 所需的平均额外信息量（以奈特为单位）由差值给出：

```
D_KL(p||q) = Σ p(x) log (p(x)/q(x))
```

这用符号 `D_KL(p||q)` 表示，称为相对熵或*库尔巴克-莱布勒散度，或 KL 散度*。这也给出了同一随机变量 X 上两个概率分布 `p(x)` 和 `q(x)` 之间差异的度量。然而，它不是对称度量，即 `D_KL(p||q) ≠ D_KL(q||p)`。因此，我们不能称其为距离函数。

**KL 散度总是非负的，`D_KL(p||q) ≥ 0`，当且仅当 `p(x) = q(x)` 时等号成立**。该证明源于 `-log` 函数的凸性。我们知道对于凸函数 `f`，给定两点 `a`、`b`，对于 `λ ∈ [0, 1]` 有以下关系：

```
f(λa + (1-λ)b) ≤ λf(a) + (1-λ)f(b)
```

*詹森不等式* 将其推广到 *n* 个点：给定定义域内的凸函数 `f` 和具有权重 `λ_i` 的 *n* 个点 `x_i`：

```
f(Σ λ_i x_i) ≤ Σ λ_i f(x_i)
```

设 `p(x)` 表示离散随机变量 X 的任意离散分布；则 `Σ p(x) = 1`。在詹森不等式中用 `p(x)` 替换 `λ_i`，我们得到：

```
Σ p(x) f(x) ≥ f(Σ p(x)x)
```

对于连续随机变量，前面的不等式也成立，我们可以写成：

```
∫ p(x) f(x) dx ≥ f(∫ p(x)x dx)
```

现在，`-log(x)` 是凸函数。所以，我们有：

```
-Σ p(x) log q(x)/p(x) ≥ -log Σ p(x) q(x)/p(x)
```

即，`D_KL(p||q) ≥ -log Σ q(x)`

因此，`D_KL(p||q) ≥ 0`，因为 `Σ q(x) = 1`

我们将在后面的许多理论中使用 KL 散度的这一性质，例如*第 12 章：生成模型*中的变分推断。KL 散度不对称，即 `D_KL(p||q) ≠ D_KL(q||p)`。**詹森-香农 (JS) 散度** 是 KL 散度的一个对称化和平滑版本，定义如下：

```
D_JS(p||q) = ½ D_KL(p||m) + ½ D_KL(q||m)
```

其中 `m = ½(p + q)`

这用于衡量两个概率分布之间的相似性。

## 互信息

让我们考虑两个随机变量 X、Y 的联合分布，记为 `p(x, y)`。如果 X、Y 独立，我们可以写成 `p(x, y) = p(x)p(y)`。如果变量不独立，则可以通过考虑 `p(x, y)` 和 `p(x)p(y)` 之间的 KL 散度来衡量它们与独立变量的接近程度。这称为变量 X 和 Y 之间的互信息，记为 `I(X; Y)`：

```
I(X; Y) = D_KL(p(x, y) || p(x)p(y))
```

由于 KL 散度非负，我们看到 `I(X; Y) ≥ 0`，当且仅当 x 和 y 独立时等号成立，即 `p(x, y) = p(x)p(y)` 独立。此外，显然 `I(X; Y) = I(Y; X)`，即互信息是对称的。

我们可以用条件熵重写互信息如下：

```
I(X; Y) = H[Y] - H[Y|X] = H[X] - H[X|Y]
```

该关系可使用 KL 散度的定义和概率乘积法则推导得出。以下是基于上述条件熵定义的 `I(X; Y)` 的一些性质。

1.  `I(X; Y) ≥ 0`

2.  `I(X; Y) = 0` 若 X、Y 独立

3.  `I(X; Y) = I(Y; X)` 互信息是对称的

利用这些熵和信息增益的概念，我们可以设计出一个用于分类和回归的简单算法，称为决策树。

## 决策树

决策树是一种简单但强大的监督机器学习算法，用于解决分类和回归问题。决策树训练算法根据信息增益或互信息等标准，递归地将数据集划分为越来越小的子集。让我们通过一个简单的例子来说明这一点，即如何根据测量到的水果高度和宽度将水果分类为橙子或柠檬，如*图 4.22 (最右侧)*所示：

![](img/figure-4.21.jpg)

**图 4.22：** *决策树示例*

我们有一些水果的样本数据，即它们的高度和宽度，如*图 4.22（最左侧）*所示。中间的树展示了一棵决策树，其中每个矩形节点都是决策节点。第一个决策节点位于根部，包含整个数据集。检查水果*宽度 > 7 cm*与否，将数据集垂直分成两部分。基于水果的高度，左侧垂直分割在*高度 = 6 cm*处水平分割，右侧垂直分割在*高度 = 10 cm*处水平分割。最终，我们得到数据的四个分割，且每个分割中仅有一类水果占主导。这种数据集的树表示称为*决策树*。最终节点称为树的叶节点。叶节点代表一个类别。叶节点中占多数的数据点的类别标签即为该叶节点代表的类别。
