## 3 基础参数模型和学习的统计视角

在上一章中，我们介绍了监督学习问题，以及解决该问题的两种方法。在本章中，我们将考虑一种被称为参数建模的通用学习方法。特别是，我们将介绍线性回归和逻辑回归，这是两种这样的参数模型。参数模型的关键点在于它包含一些参数 `theta`，这些参数是从训练数据中学习的。然而，一旦学习了参数，训练数据就可以丢弃，因为预测只取决于 `theta`。

## 3.1 线性回归

回归是监督学习的两项基本任务之一。我们现在介绍线性回归模型，这可能是（至少从历史上看）解决问题最流行的方法。尽管它非常简单，但它惊奇地有用，并且是通往深度学习等高级方法的重要阶石，见第 6 章。

如上一章所述，回归等同于学习输入变量 `x = [x_1, x_2, ..., x_p]^T` 与数值输出 `y` 之间的关系。输入可以是类别的或数值的，但我们将假设所有 `p` 个输入都是数值，并讨论类别输入。回归等同于学习输入变量 `x` 与数值输出 `y` 之间的关系。在数学框架下，回归是学习：

在统计视角下，`epsilon` 是一个随机变量，且与 `x` 独立。回归对应于：
`y = f(x) + epsilon`  `(3.1)`

### 线性回归模型

回归模型假设输出 `y` 可以描述为 `x` 的仿射组合加上噪声项 `epsilon`。对于示例 2.2，我们：
`y = theta_0 + theta_1 x_1 + ... + theta_p x_p + epsilon`  `(3.2)`

我们将 `theta_, theta_1, ..., theta_p` 称为系数。线性回归模型在模型中假设噪声项 `epsilon` 均值为零且与数据无关。为了紧凑地表示，我们引入向量 `theta = [theta_0, theta_1, ..., theta_p]^T`，这样我们可以将线性回归写作：

`y = theta_0 + theta_1 x_1 + ... + theta_p x_p = theta^T x`  `(3.3)`

这种符号表示 `x` 是 `p+1` 维的 `p` 维版本（在第一个位置使用常数）。`theta_0, theta_1, ..., theta_p` 是模型参数。

回归模型是 `theta` 的参数函数。

> 仿射函数是一个线性函数加上常数。

回归模型是 `theta` 的参数函数。`theta` 可以取任意值，因此学习模型等同于基于观测找到 `theta` 的合适值。在讨论如何这样做之前，我们先看看如何使用模型。

监督学习的目标是对未见过的输入 `x* = [1, x_1*, ..., x_p*]^T` 进行预测 `y_hat(x*)`。假设我们已经为线性回归模型学习了一些参数值 `hat{theta}`。由于噪声 `epsilon` 是均值为零的随机变量且与所有观测变量独立，我们在预测中将 `epsilon` 替换为 `0`。因此，线性回归模型的预测形式为：

`y_hat(x*) = hat{theta}_0 + hat{theta}_1 x_1* + hat{theta}_2 x_2* + ... + hat{theta}_p x_p* = hat{theta}^T x*`  `(3.4)`

噪声 `epsilon` 通常被称为不可归约误差或预测中的偶然不确定性。我们在图 3.1 中展示了线性回归模型所做的预测。
