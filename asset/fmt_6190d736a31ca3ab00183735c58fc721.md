
We show that when (how) batch size distribution has effect on performance measures by considering different distribution types such as uniform, Poisson, geometric, and discrete phase-type (DPH) distribution in Examples 8.2 and 8.3.

*   From Figure 8.6 it can be observed that the mean recurrence time decreases with increasing `µ[1]` for a specific value of `b` (`ρ = 0.50`). This behavior is observed across all four batch size distributions. At the same time, the mean recurrence time is lowest for UB and highest for DPB (for fixed `b` and `µ[1]`). The rate of decrease for DPB is also higher than the other distributions. Furthermore, the mean recurrence time for a fixed `µ[1]` decreases with increasing `b`.
*   Figure 8.7 depicts a similar pattern for the mean recurrence time with varying `b` and `µ[1]` (or `ρ = 0.99`) across the four batch size distributions. The figure shows that the mean recurrence time increases at a specific `b` and `µ[1]` when `ρ` takes a higher value. This holds across all four distributions. The mean recurrence time increases with increasing traffic intensity (`ρ`), however, it starts decreasing when the service rate is increased.
*   From Figure 8.8 it can be seen again that the mean busy period is a decreasing function of `b` and `µ[1]` (`ρ = 0.50`) across all four batch size distributions. As the service rate increases, the mean busy time in the system decreases. This holds across all four distributions. The mean busy period is lowest for UB and highest for DPB.
*   Figure 8.9 depicts the plot of the mean busy period for `ρ = 0.99`. The mean busy period values are higher for `ρ = 0.99` compared to `ρ = 0.50`.
*   The behavior of the mean number in system can be observed in Figure 8.10 for `b` and `µ[1]` (`ρ = 0.50`). As the batch size increases, the performance measure increases monotonically for a fixed `µ[1]`, whereas it decreases with increasing `µ[1]` for a fixed `b`. All four batch size distributions exhibit the same behavioral pattern. DPB has the highest expected number in system among the distributions. As the service rate increases, the transactions in the system will be processed at a faster rate, resulting in a decrease in the mean number in system.
*   Figure 8.11 displays the plot of the mean number in system for `ρ = 0.99`. Although the different batch size distributions exhibit similarity in trends, the mean number in system for `ρ = 0.99` is significantly higher than that for `ρ = 0.50`.
*   Figure 8.12 depicts the behavior of the mean busy period `µ[NS]` for `b` and `µ[1]` at `ρ = 0.50`. The performance measure `µ[NS]` decreases with increasing `b` (for fixed `µ[1]`) and also decreases with increasing `µ[1]` (for fixed `b`) across all four batch size distributions. DPB has the highest `µ[NS]` for a fixed `b` and `µ[1]`, but the difference between DPB and GB is not enough to make them look distinct, therefore the behavior of DPH and GB appears to be the same.
*   Figure 8.13 depicts the behavior of `µ[NS]` for `b` and `µ[1]` at `ρ = 0.99`, showing a degree of insensitivity to the batch size distribution type. In this case, `µ[NS]` increases with increasing `ρ`. Among the four distributions, DPB has the highest `µ[NS]` and UB has the lowest `µ[NS]`.

## Example 8.3

The effect of batch size distribution on some performance measures under different scenarios is investigated and the specific numerical values are displayed in Table 8.1, 8.2, 8.3 and 8.4. For this purpose, we fix the block pegging rate `µ[2] = 1` and vary the transaction processing rate `µ[1] = 0.5, 1.5`; batch size `b = 5, 50, 150, 200` and traffic intensity `ρ = 0.5, 0.90, 0.95, 0.99`.

We set the parameters for the Uniform, Poisson, and Geometric distributions to 3, 1, and 0.5 respectively. At a tolerance level of `10^(-13)`, the truncation values for the batch size are 3 for Uniform, 13 for Poisson, and 34 for Geometric. On the other hand, the DPH distribution (see DPH representation below) has a maximum batch size of 50 at the same tolerance level.

```
α = (0.4, 0.3, 0.3), T = 
( 0.3    0.11   0.01627 )
( 0.1    0.2    0.25    )
( 0.12   0.3    0.12    )
```

When `µ[1] = 0.5` and for Mean-RT, the effect of batch size distribution is significant at low `b` values (`b = 5` and `50`) as `ρ` increases (high `ρ` values). When `b` takes larger values (`150` and `200`), the effect of the distribution is less pronounced, as shown in Table 8.1. When we observe `µ[1] = 1.5`, the above behavior holds true as well. However, the difference among the four batch size distributions is slightly reduced in this case. Similar comments can be made for the other performance measures in Table 8.2, Table 8.3 and Table 8.4. In summary, smaller `b` and `µ[1]` values lead to larger `ρ` values, which amplifies the effect of batch size distribution on the measures.
