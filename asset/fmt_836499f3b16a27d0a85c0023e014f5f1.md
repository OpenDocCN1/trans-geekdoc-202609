
相反，当某个簇内部的示例间平均距离很高时，分裂就有意义了。具体的解决方案并不容易形式化，因为一旦我们指定簇`C`要被分裂为`C1`和`C2`，我们需要决定`C`中的哪些示例将进入第一个簇，哪些进入第二个簇。然而，很多时候，在`C`中识别出两个相互距离最大的示例是完全可以的，然后将它们分别处理为新创建的`C1`和`C2`的代码向量。

![image](img/image112.png)

## k-Means 的分层应用

另一种改进依赖于递归调用。该技术从对`k = 2`运行`k-means`开始，获得两个簇。之后，对这两个簇中的每一个应用`k-means`，同样设置`k = 2`。该过程一直持续直到满足适当的终止标准——例如用户想要获得的簇的最大数量，或者相邻簇之间的最小距离。

这种分层版本规避了`k-means`的一个严重缺点：必须提供簇的数量，因为在这种情况下，数量是自动找到的。这在目标是识别贝叶斯分类器或 RBF 网络中的高斯中心时特别有用。

# 14.5 自组织特征映射：引言

![image](img/chapter_title_below.png)

让我们现在介绍另一种无监督学习方法，这次是借用神经网络领域。该技术被称为自组织特征映射（self organizing feature map，SOFM）³。在这种背景下，常用的另一个名称是 Kohonen 网络（Kohonen networks），以纪念它的发明者。

### 思想

解释 SOFM 性质最好的方法是将物理引力原理作为比喻。最初由随机数生成器生成的代码向量，受到一系列示例（属性向量）的影响，每个示例都会向不同的方向“拉”该向量。从长期来看，代码向量将稳定在一个代表所有这些冲突力量折中的位置。

整个网络由一组排列在二维矩阵中的神经元组成，如图 14.6 所示。该矩阵中的每个节点（神经元）代表一个与训练示例长度相同（属性数量相同）的代码向量。底部是一个输入属性向量，它并行连接到所有神经元。其思想是通过训练实现：相邻的神经元对相似的输入向量产生类似的响应。为了简单起见，图片中的输入向量只有两个属性，`x1`和`x2`。实际上，它可以有很多属性。

`w1 ... xn`其中`n`是属性的数量。如果`1`是用户指定的学习率，则单个权重根据如下公式进行修改：

```
wi = wi + 1(xi - wi)
```

注意，如果`xi > wi`，`i`权重会增加，因为括号内的项为正。反之，如果`xi < wi`，权重会减小，因为该项为负。我们从这种意义上说权重被`x`吸引。它被吸引的强度取决于学习率的值。

### 数值示例

假设展示了一个示例`x = (0.2, 0.8)`，并假设获胜的神经元权重为`w = (0.3, 0.7)`。如果学习率为`1 = 0.1`，则权重计算如下：

```
w1 = w1 + 1(x1 - w1) = 0.3 + 0.1(0.2 - 0.3) = 0.29
w2 = w2 + 1(x2 - w2) = 0.7 + 0.1(0.8 - 0.7) = 0.71
```

### 哪些权重会被示例吸引

一旦向矩阵展示了一个示例`x`，就会启动一个双步骤的过程。第一步（“竞争”）的任务是在矩阵中识别与`x`最相似的神经元。为此，使用了欧几里得距离——距离越小，相似性越高。一旦确定了胜者，第二步将更新该获胜神经元的权重以及其邻域内所有神经元的权重。

### 关于“邻域”的说明

任务是在矩阵中识别与`x`最相似的神经元。为此，使用了欧几里得距离——距离越小，相似性越高。一旦确定了胜者，第二步将更新该获胜神经元的权重以及其邻域内所有神经元的权重。

通常，邻域的大小不是固定的。相反，常见的做法是如图 14.7 右所示随时间缩小。最终，邻域将退化为单个神经元，即赢得竞争的那个。其思想是从粗略的近似开始，然后进行微调。

### 为什么它是有效的？

自组织特征映射的动机是确保神经矩阵中物理位置相近的代码向量对相似的示例产生响应。这就是为什么相同的权重更新公式应用于胜者邻域内的所有神经元。

# 14.6 一些重要细节

在概述原理之后，现在让我们来看一些细节，如果没有这些细节，该技术将无法运行。

### 归一化

除非所有向量都被归一化为单位长度（即长度等于 1），否则该技术效果不好。这既适用于描述示例的向量，也适用于神经元的权重向量。幸运的是，单位长度归一化很容易。假设一个示例描述如下：

```
x = (x1; ...; xn)
```

为了获得单位长度，我们将每个属性的值除以原始属性向量`x`的长度：

```
wi = xi / sqrt(sum(xj²))
```
