
- **SSL 解密器** SSL 和 TLS 解密器是企业网络上的设备，用于解密消息，以便 DLP 策略可以审查内容。它们也用于让恶意软件检测功能在消息解密后对其进行扫描，或允许云监控服务扫描消息。

- **媒体网关** 媒体网关设备是一个组件，用于将数据流从一种通信形式转换为另一种。例如，媒体网关可以将网络上的数据转换为 3G 无线网络使用的格式。

- **HSM** *硬件安全模块 (HSM)* 是一种设备，通常是一张卡，可安装在服务器中，用于执行加密功能并管理这些加密功能的密钥。

- **负载均衡器** 负载均衡器是一种设备，用于将负载分摊到多台服务器上，以免单台服务器因工作过载而陷入瘫痪。

- **DDoS 缓解器** DDoS 缓解器将放置在互联网和您的公共互联网资源（如 Web 服务器和电子邮件服务器）之间。DDoS 缓解器是一种监控从互联网传入您公共服务器的网络流量的设备，可识别可能旨在使您的服务器过载的流量。缓解器检查数据包的特征，包括源 IP 地址和 HTTP 标头，以确定流量是否来自僵尸网络。如果是，缓解器将阻止该流量，使其无法到达您的公共服务器。

- **汇聚交换机** 在大多数组织中，每层楼都在布线间有一台交换机，该楼层的用户连接到这台交换机。每层楼的交换机再连接到数据中心内的汇聚交换机。该汇聚交换机充当所有交换机的连接点，但也可能是三层交换机，能够将流量路由到互联网。如果它不是三层交换机，则会连接到路由器，再由路由器连接到互联网。

- **分流器和端口镜像** 网络交换机可配置为将所有网络流量的副本发送到某个端口，您可在该端口上运行监控软件或 IDS。这至关重要，因为交换机会过滤流量，防止除目标之外的任何人看到该流量。您也可以安装网络分流器设备，它包含多个端口和一个监控端口，并接收所有流量的副本。

- **带外管理** 带外管理涉及连接到网络设备上的管理端口，以管理该设备（例如，连接到交换机上的控制台端口以配置设备）。在保护设备时，请务必通过在管理接口上配置用于认证的密码来锁定这些接口。

- **DNS** 在 DNS 服务器上实施安全性时，请务必限制哪些系统可以接收区域传输，并考虑使用 DNSSec 来保护 DNS 区域数据的完整性。

- **路由安全** 路由安全涉及保护路由设备免受攻击，包括防止黑客获得访问权限并操纵路由表。请通过限制设备上运行的协议和锁定正在运行的协议来加固路由设备。

- **服务质量** 您应监控网络性能，并衡量用户通过电话和基于云的服务所接收的服务质量 (QoS)。

- **监控服务** 务必锁定所有监控服务和协议，以免黑客访问受监控的数据。例如，确保设备使用支持数据认证和加密的 SNMP 第 3 版。

- **文件完整性监视器** 您可以实施文件完整性监视器，以监控网络上文件的更改。如果文件被更改，您可以设置发送警报给您。

**SDN** 软件定义网络是一项可在虚拟化环境中配置的功能，它允许您创建虚拟网络并对网络流量进行分段。

## 业务连通性考量

在审视组织的企业安全时，您还需要考虑业务地点的地理因素，因为办公室的位置会影响您可能遇到的自然灾害类型以及应急人员的响应时间。

您还应考虑事件响应程序，以及在发生安全事件时贵企业将依赖的恢复控制类型。您将在第 18 章了解更多关于灾难恢复和业务连通性的内容，而第 21 章则讨论事件响应。

## 安全设备与网络设备的部署

在设计网络时，将不同的安全设备和网络设备放置在正确的位置至关重要。以下列表列出了关键安全设备和网络设备及其应放置的位置：

- **传感器** 传感器应部署在每个网段上，以便捕获该网段的网络流量并将其发送给收集器或分析引擎。

- **收集器** 您可以在任意网段上放置单个收集器，并让每个传感器将捕获的流量发送给该收集器。

- **关联引擎** 关联引擎应运行在有权访问收集器数据的系统上，并应放置在安全的网段上。

- **过滤器** 这些组件用于过滤不同类型的流量，应放置在网络边缘。例如，您可以在代理服务器上使用 URL 过滤器来阻止用户访问特定站点。代理服务器位于 Internet 连接与用户之间，以便审查每个被访问的网站并过滤掉已被禁止的网站。

- **代理服务器** 正向代理是一种部署在网络边缘、位于 Internet 连接与用户之间的设备。用户对 Internet 资源的所有请求都会经过代理，以便其过滤掉任何未经授权的内容。反向代理部署在 DMZ 中，用于将网络内的服务器（如 Web 服务器）发布到 Internet。当 Internet 上的系统尝试访问您的服务器时，它首先会联系反向代理（该代理分配了 DNS 名称），然后反向代理将流量转发给内部系统。

- **跳板服务器** 跳板服务器是一种用于访问或管理另一安全区域内设备的系统。跳板服务器经过加固，并配置了安全通信协议（如 `SSH`），它部署在包含待访问设备的区域中。防火墙有严格的规则限制可用于与跳板服务器通信的协议和系统。

- **防火墙** 防火墙应部署在网络边缘，以保护网络免受来自 Internet 的未经授权流量的侵入。您也可以在不同网段之间部署防火墙，以控制网段间的流量。

- **VPN 聚合器** VPN 聚合器同样部署在网络边缘，但在防火墙之后，以便防火墙能阻断可能针对 VPN 聚合器的恶意流量。防火墙需要开放端口以允许 VPN 流量到达 VPN 聚合器。

- **SSL 加速器** SSL 加速器可部署在执行大量加密功能的任何系统或服务器内部。

- **负载均衡器** 负载均衡器通常部署在 DMZ 中，一般用于对 Web 应用程序的请求进行负载均衡。您也可以在内部网络中部署负载均衡器，用于可能需要多台服务器分担负载的网络服务。

- **DDoS 缓解设备** DDoS 缓解设备部署在 Internet 与您的公共 Internet 资源（如网站和电子邮件服务器）之间，以保护这些资源免受 DDoS 攻击。

- **分流器和端口镜像** 您可以在每个网段上部署网络分流设备，使其将所有数据的副本发送给监控系统。监控系统连接到镜像端口，并运行软件以监控网络流量。

# 配置管理

构建安全网络基础设施的一部分是确保公司制定了配置管理策略，该策略规定了在网络上实施变更所需遵循的变更管理流程。这包括在生产环境中实施变更前，先在测试环境中部署该变更。

变更管理还涉及拥有最新的网络 `diagrams`（网络拓扑图），并确保有一个可应用于新设备的 `baseline configuration`（基线配置）。基线配置是一种用于确保所有设备配置一致的工具，从而防止配置错误的发生。您还应确保对网络上的系统和设备使用标准化命名约定，以帮助理解设备名称的含义。您还应记录网络上使用的 Internet 协议 (IP) 地址方案，特别是当您使用多个网段且每个网段使用不同 IP 地址块时。

# 设备安全防护

本章的最后一个主题回顾了一些保护网络设备的常见做法。在过去的几章中，您已经读到过保护系统和设备应采取的常见步骤。让我们结合网络设备回顾其中的一些要点：

- **权限提升** 请务必随时了解攻击者连接到系统或设备后，如何提升其在系统上的权限并获得管理访问权限。这通常是由于产品漏洞导致的，因此请务必为系统或设备应用更新。为设备应用更新涉及在固件版本发布时升级设备上的固件。

- **弱密码** 我简直不敢相信还有这么多管理员在使用弱而明显的密码。在对一家公司的 Cisco 路由器进行评估时，我查看了运行配置，发现该公司管理员配置了路由器的 Telnet 访问，密码却是 `telnet`。我还通过输入密码 `cisco` 获得了路由器的管理访问权限。这些不仅不是强密码，而且是黑客尝试获取访问权限时会尝试的常见密码。这个例子中的另一个安全问题是，我本不应该能够查看密码，因为它们本应在配置中加密。使用 Cisco 设备时，您可以使用 `service password-encryption` 命令对配置文件中的密码进行加密。

- **后门** 检查网络设备是否存在潜在后门。我发现的一个典型例子是：网络管理员在路由器的控制台端口配置了密码，却未在路由器的辅助端口（如果存在）设置密码。辅助端口就像另一个控制台端口，拥有路由器物理访问权限的人可以连接到该端口来管理设备。请务必为这些设备上的所有端口设置密码保护！

- **默认账户** 请留意系统或设备上存在的默认账户，并务必使用强密码保护这些账户。如果可能，您应将默认账户重命名为不那么显而易见的名称。

# 认证总结

在本章中，你学习了可用于帮助提高网络环境安全性的常见网络组件。请务必熟练掌握本章内容，因为在 Security+ 考试中，你一定会遇到关于防火墙、NAT、NAC 及其他安全设备的问题。以下是关于本章需要记住的一些要点：

- **DoS** 可以对网络系统和设备发起多种拒绝服务攻击。在防火墙上实施洪水防护应该能保护你的系统免受大多数 DoS 攻击，因为大多数攻击都涉及黑客试图用大量信息淹没你的系统，导致系统崩溃。洪水防护会阻止洪水消息进入你的网络。

- 了解包过滤防火墙（无状态）、状态包检测防火墙和应用层防火墙之间的区别。

- 不同的防火墙拓扑包括双宿主防火墙、屏蔽主机防火墙和屏蔽子网防火墙。你的防火墙设计应在网络中创建不同的区域，例如私有区域和公共区域。

- 代理服务器是流行的设备，允许你控制网络上的用户在访问互联网时可以使用的内容和应用程序类型。

- 了解基于主机的 IDS 和基于网络的 IDS 之间的区别。还要了解 IDS 检测入侵，而 IPS 既检测又防止入侵。

- 利用网络设计原则帮助创建安全的网络环境，例如创建多个网段并控制可从一个网段传递到另一个网段的流量。

- 不要混淆 NAT 和 NAC。NAT 是一项用于互联网访问的功能，可将私有地址信息转换为公共地址。NAC 用于检查连接到网络的系统状态，如果不满足要求，则该系统不会被连接到网络。

- 关于网络设备的常见安全实践包括确保使用复杂密码、重命名或禁用默认账户，以及通过补丁保持系统处于最新状态，仅举几例。

### 理解防火墙

- 包过滤防火墙允许你根据第 3 层报头（IP）和第 4 层报头（TCP 或 UDP）过滤流量。状态包检测防火墙可以进行包过滤，但也了解会话的上下文。应用层防火墙可以查看数据包中的应用数据并做出决策。

- DMZ 是一个区域，允许来自互联网的选定流量到达公共服务器，如 DNS、FTP 和 HTTP 服务器。

- 代理服务器通常将防火墙功能与内容控制功能结合在一起。例如，你可以限制用户可以访问的站点或他们用于访问互联网的应用程序类型。

### 使用入侵检测系统

- 基于网络的入侵检测系统分析网络流量以识别可疑活动。

- 入侵检测系统 (IDS) 记录可疑活动并通知管理员，但入侵防御系统 (IPS) 会采取纠正措施。例如，IPS 可能会将发起可疑流量的人员从网络中断开。

- 就考试而言，要了解 IDS 可以基于特征码（基于特征码的 IDS）检测可疑流量，也可以基于流量超出正常活动的参数（基于异常的 IDS）来识别可疑流量。还要了解启发式监控涉及基于过去经验检测可疑流量。

### 网络设计和管理原则

- 通过在网络交换机上使用 VLAN 在网络内创建通信边界。

- 你也可以通过在网络上放置路由器并使用路由器上的访问控制列表控制可进入不同网段的流量来创建不同的网段（例如，将访客的无线网络与企业网络分离）。

- 数据丢失防护 (DLP) 技术可用于防止某人窃取或共享敏感公司数据。

- 网络准入控制 (NAC) 允许你在授予系统有线或无线网络访问权限之前检查系统的状态。

- 在邮件网关上实施垃圾邮件过滤功能和防病毒软件，以保持员工邮箱没有垃圾邮件和包含病毒的邮件。

### 保护设备

- 确保网络设备具有强密码。

- 务必为设备打补丁以消除其上的漏洞。

- 如果可能，重命名或禁用设备上的默认账户。
