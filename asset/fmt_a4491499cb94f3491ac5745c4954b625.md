
观察模式，我们所需的最小连接是基于 `customerNr` 将 `Customer` 和 `Invoice` 表连接起来。表之间其余的导航可以用子查询完成，因为我们不需要在最终结果的 `select` 列表中包含那些表中的任何其他列。这种方法导出了一个包含一个连接和嵌套子查询的表述，如下所示：

```
select customerNr, customerName, invoiceNr
from   Customer natural join Invoice
where invoiceNr in
    (select invoiceNr from Lineitem
     where itemCode in
         (select itemCode from Item
          where title = 'Quinquo'))
```

或者，我们可以用连接替换任意子查询。例如，以下表述使用了三个连接且无子查询：

```
select customerNr, customerName, invoiceNr
from      Customer natural join Invoice
natural join Lineitem
natural join Item
```

如果您的 SQL 方言不支持 `natural join` 语法，请改用条件连接语法或旧式 SQL-89 连接语法。

作为子查询的否定示例，以下查询列出了没有山脉的国家。对于给定的数据，结果仅为一个国家：荷兰。

```
select countryName from Country
where countryName not in
    (select countryName from Mountain)
```

能否用内连接替换否定子查询？不能！但是，您可以用外连接替换它。例如，上述查询可重新表述为：

```
select countryName
from Country natural left outer join Mountain
where mtName is null
```

该查询也可以用集合差运算来表述，如下所示：

```
select countryName from Country
except
select countryName from Mountain
```

要列出拥有山脉的国家，可以使用以下查询：

```
select countryName from Country
where countryName in
    (select countryName from Mountain)
```

这执行的是集合交集，等价于：

```
select countryName from Country
intersect
select countryName from Mountain
```

本节剩余部分讨论量化比较子查询。回顾一下，比较子查询可用于构造以下形式的条件：

*   ```
    expression Θ [all | some | any] (subquery)
    ```

其中 Θ 是比较运算符（例如 =, >），而 `all`、`some` 和 `any` 是量词。在没有量词的情况下，子查询必须返回单个值，这可以通过使用函数来保证（见下一节）。如果使用了此类量词，我们就得到一个量化比较子查询。这些量词具有以下含义：

| 量词 | 含义 | 解释 |
| :--- | :--- | :--- |
| `some` | 意为 | 至少一个 |
| `any` | 意为 | 至少一个 |
| `all` | 意为 | 每一个（逐个取） |

因此，以下等价关系成立：

*   ```
    in            ≡            = some     ≡     = any
    ```

*   ```
    not in     ≡            <> all
    ```

为避免混淆，应使用 `in` 和 `not in` 代替其等价的量化比较，且应始终使用 `some` 代替 `any`。在 SQL 中，`some` 和 `any` 被视为同义词。然而，在英语中并非总是如此。例如，“<> any”在英语中意为“not in”，但在 SQL 中不是！要理解这一点，请自行计算以下查询的结果。

*   ```
    select countryName from Country
    ```

*   ```
    where population <> any (select population from Country)
    ```

评估子查询后，我们可以将条件表示为“population <> `any` (190000000, 1000000000, 16000000, 270000000)”。在英语中，“<> any”意为“= none”。因为每个人口数都等于其自身，我们预期不会返回任何行。但该查询返回了所有人口数，因为每个人口数都不等于某些（即至少一个）人口数，而 SQL 将“<> any”视为“<> some”。

作为量化比较的正确用法，考虑查询：哪个国家人口最多？这可以表述如下。

*   ```
    select countryName
    ```

*   ```
    from        Country
    ```

*   ```
    where population >= all (select population from Country)
    ```

请记住，`all` 被解释为分配性的“每一个，单独取”而非集合性的。查询结果正确地列出了 India。正如下一节所讨论的，`max` 函数也可用于将搜索条件重述为 `population = (select max(population) from Country)`。然而，正如稍后所讨论的，量化比较也能处理一些函数无法处理的情况（例如分组极值）。

## 12.9 SQL：标量运算符和包函数

*标量* 是一个数据值（例如数字、字符串或日期）。本节简要讨论 SQL-89 中可用的标量运算符和包函数，以及后续版本中包含的进一步运算符和函数。

在 SQL-89 中，标量运算符是四个算术运算符 `+`、`−`、`*` 和 `/`。作为一元运算符，`+` 和 `−` 提供数字的符号（例如 `+3` 或 `−3`）。如果省略，则假定为 `+`（例如 `3 = +3`）。作为二元运算符，`+` 和 `−` 执行加法和减法。二元运算符 `*` 和 `/` 执行乘法和除法；它们没有一元版本。每个都是作用于数字的数字生成运算符。它们的操作数可以作为列名、常量、函数调用，或由这些通过算术运算符和可能的括号形成的表达式出现。标量表达式可用作 `select` 列表或搜索条件中的项。

### 使用标量运算符进行简单计算

让我们首先使用这些运算符在 SQL 中提供一个简单的计算器功能，以计算算术表达式的值。我们只需在数据库中包含一个仅有一行的虚拟表，然后将该表达式作为该表 `select` 列表中的唯一项。某些 DBMS 内置了虚拟表，但让我们通过发出命令 `create table C (c char)` 来创建我们自己的虚拟表，然后用虚拟值 "c" 填充此表：`insert into C values ("c")`。现在我们可以使用此表进行简单计算。

作为一个简单的例子，要计算将 2 加到 3 和 4 的乘积上所得的和，我们可以发出以下查询。

```
select 2 + 3 * 4 from C     →     14
```

对于此类计算，不会访问 C 的内容，因此其内容无关紧要（除了将 C 限制为一行可确保所需值仅显示一次）。在 SQL Server 中，`from` 子句是可选的，因此你可以直接使用 `select 2 + 3 * 4`，而无需创建虚拟表。算术运算符遵循常规的优先级约定。乘法和除法具有最高优先级，加法和减法次之。同一级别的运算符具有左结合性（即按其出现的顺序从左到右求值）。括号可用于覆盖此求值顺序（带括号的表达式会在被外部运算之前先求值）。例如：`2 + 8/2 * 4 = 18`。

对于精确数值数据上的除法运算，SQL 标准将结果的小数位数（小数点后的位数）留给具体实现定义。在许多 SQL 方言（包括 SQL Server）中，此小数位数为 0，因此如果操作数是整数，除法运算符将执行整数除法，例如：

```
select 14/3 from C          →     4
```

可以通过使其中一个操作数为实数来获得实数除法。例如：

```
select 14.0/3 from C     →     4.666666
```

在某些方言中，这显示为 `4.666666E+000`。这里，“E”读作“乘以 10 的多少次方”，因此上述值读作“4.666666 乘以 10 的 0 次方”。因为 10⁰ = 1，所以该结果归结为 4.666666。

SQL-92 引入了 `cast` 函数，以便将数据重新转换或转换为另一种类型的数据（有一些限制）。这可用于控制除法结果的小数位数。例如，在 SQL Server 中，以下查询的结果为 4.67。结果是舍入（如此处所示）还是截断取决于具体实现。

```
select cast(14.0/3 as numeric(9,2)) from C          →     4.67
```

当算术操作数类型不同时，结果通常会被强制转换为“更大”的类型。例如，通过包含一个实数操作数，除法的结果被强制转换为实数。当涉及列名而非常数时，通过乘以 1.0 可实现强制转换为实数（例如 `select 1.0 * quantity/2`）。

同一类型的两个数字（例如 `smallint`）之间的算术运算结果可能会被强制转换为更大的类型（例如 `integer`），以避免可能的溢出问题。由于并非所有 SQL 方言的行为都相同，你应该查阅你所用方言的数值计算规则。

作为一个使用标量运算符的实际例子，考虑表模式 `LineItem(invoiceNr, itemCode, qty, unitPrice)`。假设单价以美元存储，汇率为 1 AUD = 0.70 USD，可以按如下方式请求发票 502 中单价高于 100 澳元的项目及行总额（以澳元计）。
