连接成功后应看到 SMTP 欢迎信息。

2. 输入命令告诉服务器“你好，我来自这个域”。

   ![technicalstuff](img/technicalstuff.png)每条命令执行后会收到不同编号的回复，例如 `999 OK`，这些信息可以忽略。

3. 输入命令告诉服务器你的电子邮件地址。

   示例：

   ```
   mail from:yourname@yourdomain.com
   ```

   你可以使用任何电子邮件地址替换 `yourname@yourdomain.com`。

4. 输入命令告诉服务器收件人地址。

   示例：

   ```
   rcpt to:yourname@yourdomain.com
   ```

   同样，任何地址均可。

5. 输入命令告知服务器消息正在继续。

   示例：

   ```
   data
   ```

6. 输入以下内容作为消息正文：

   ```
   A relay test!
   ```
