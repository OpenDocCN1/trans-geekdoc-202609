
## 第一步：建立结论

第一步是建立以下结论：`如果 h(n)是一致的，则任何路径上 f(n)的值是非递减的`。证明直接来源于一致性的定义。假设`n'`是`n`的后继节点；则存在某个动作`a`使得`g(n') = g(n) + c(n, a, n')`，我们有

> `f(n') = g(n') + h(n') = g(n) + c(n, a, n') + h(n') ≥ g(n) + h(n) = f(n)`。

![hand](img/00006.jpg)

下一步是证明：`当 A^(\*)选择节点 n 进行展开时，到该节点的最优路径已经被找到`。如果不是这样，则在从起始节点到`n`的最优路径上会存在另一个前沿节点`n'`，这源于图分离性质（[Figure 3.9]）。由于`f`沿任何路径是非递减的，`n'`的`f`成本会低于`n`，因此会先被选择。

基于上述两个观察，可以得出结论：`A^(\*)`使用 GRAPH-SEARCH 扩展的节点序列是`f(n)`非递减顺序。因此，第一个被选中的目标节点必然是最优解，因为`f`是目标节点（`h = 0`）的真实成本，而后续目标节点的成本至少与其相等。

`f`成本沿任何路径非递减的事实也意味着我们可以在状态空间中绘制**轮廓**，就像地形图上的等值线一样。[Figure 3.25]展示了一个例子。在标记为 400 的轮廓内，所有节点的`f(n)`小于或等于 400，以此类推。由于`A^(\*)`总是扩展`f`成本最低的前沿节点，可以看出`A*`搜索从起始节点向外扩展，按`f`成本的同心带逐层添加节点。

### CONTOUR

---

与统一成本搜索（即`h(n) = 0`的`A^(\*)`搜索）相比，带状会“围绕”起始状态呈圆形。使用更准确的启发函数时，带状会向目标方向伸展，并更紧密地集中在最优路径周围。如果`C^(\*)`是最优解路径的成本，则可得出以下结论：

> • `A^(\*)`会扩展所有`f(n)` < `C^(\*)`的节点。

> • `A^(\*)`可能在选择目标节点前，先扩展一些位于“目标轮廓”（`f(n) = C^(\*)`）的节点。

完备性要求在`C^(\*)`及以下成本下只有有限数个节点，这在所有步骤成本超过某个有限的ε且`b`为有限时成立。

注意`A^(\*)`不会扩展`f(n)` > `C^(\*)`的节点——例如在[Figure 3.24]中，尽管它是根节点的子节点，Timisoara 仍未被扩展。我们说该子树被**剪枝**；由于`h[SLD]`是可接受的，算法可以安全忽略该子树，同时仍保证最优性。剪枝——在不必逐一检查的情况下消除可能性——是许多 AI 领域中重要的概念。

---

### PRUNING

---

最后的观察是，在所有通过从根节点延伸搜索路径并使用相同启发信息的最优算法中，`A^(\*)`对于任何一致启发函数都是**最优高效**的。也就是说，除了可能在`f(n) = C^(\*)`的节点间进行 tiebreaking（平局）外，没有其他最优算法保证会扩展的节点数少于`A^(\*)`。

### OPTIMALLY EFFICIENT

---

`A^(\*)`搜索是完备、最优且最优高效的，这令人满意。但这并不意味着`A^(\*)`是解决所有搜索需求的答案。关键在于，对于大多数问题，目标轮廓内的状态数量仍然是解的长度的指数级。虽然分析细节超出本书范围，但基本结果如下。对于步骤成本恒定的问题，运行时间随最优解深度`d`的增长，以**绝对误差**或**相对误差**来分析。绝对误差定义为`Δ ≡ h^(\*) − h`，其中`h^(\*)`是从起点到目标的实际成本，相对误差定义为`ε ≡ (h^(\*) − h)/h^(\*)`。

-   复杂度结果在很大程度上取决于关于状态空间所做的假设。最简单的模型是一个只有一个目标的状态空间，基本上是一个具有可逆动作的树。（8-谜题满足第一和第三个假设。）在这种情况下，A*（*）的时间复杂度是指数级的，即 *O*（*b*^Δ），其中 Δ 为最大绝对误差。对于固定步骤成本，我们可以将其写为 *O*（*b*^(ε*d*)），其中 *d* 为解的深度。对于几乎所有实际使用的启发式函数，绝对误差至少与最优路径代价 *h*（*） 成正比，因此是常数或递增的，时间复杂度是指数级的 d。我们也可以看到更准确的启发式函数的影响：*O*（*b*^(ε*d*)) = *O*((*b*^ε)^*d*)，所以有效分支因子（在下一节中更正式定义）是 *b*^ε。

## 3.5.3 记忆受限启发式搜索

-   减少 A*（*）记忆需求的最简单方法是将迭代加深的思想适应启发式搜索情境，从而得到 **迭代加深 A**（*） (IDA^(\*)) 算法。IDA^(\*) 与标准迭代加深的主要区别在于，它使用 *f*-成本（*g* + *h*）作为切断值，而不是深度；在每次迭代中，切断值为上一次迭代中超过切断值的任何节点的最小 *f*-成本。IDA^(\*) 适用于许多步长成本为 1 的问题，并且避免了维护有序节点队列所带来的巨大开销。遗憾的是，它像 uniform-cost search 的迭代版本（Exercise 3.17）一样，也受到实数成本的困难影响。本节简要介绍了另外两种记忆受限算法，即 RBFS 和 MA^(\*)。

-   使用所有可用的内存是合理的，因此，使用 `MA`^(\*)（记忆受限的 A^(\*)）和 `SMA`^(\*)（简化的 MA^(\*)）这两种算法可以实现这一点。`SMA`^(\*) 更简单，因此我们将对其进行描述。`SMA`^(\*) 的工作方式与 A^(\*) 相同，即不断扩展最佳的叶子节点，直到内存已满。此时，它无法在不丢弃已有节点的情况下向搜索树中添加新节点。`SMA`^(\*) 始终丢弃 *最差* 的叶子节点——即具有最高 *f*-值的节点。类似于 RBFS，`SMA`^(\*) 然后将被遗忘节点的值向其父节点回传。通过这种方式，被遗忘子树的祖先节点知道该子树中最佳路径的质量。有了这类信息，`SMA`^(\*) 只有在所有其他路径都被证明比已遗忘的路径更差时，才会重新生成该子树。换句话说，如果一个节点 *n* 的所有后代都被遗忘，那么我们将不知道从 *n* 应该往哪个方向走，但仍然知道从 *n* 向任何方向前进的价值。

完整的算法在这里不作展开，但有一个细节值得注意。我们说 `SMA`^(\*) 会扩展最佳的叶子节点并删除最差的叶子节点。如果所有叶子节点的 *f*-值相同，`SMA`^(\*) 会扩展 *最新* 的最佳叶子节点，并删除 *最旧* 的最差叶子节点。当只有一个叶子节点时，这两者是相同的，但在这种情况下，当前的搜索树必须是一条从根节点到叶子节点的单一路径，且该路径占满了所有的内存。如果该叶子节点不是目标节点，那么即使它位于最优解路径上，该解路径也无法在现有内存中到达。因此，该节点可以被恰如其分地丢弃，就像它没有后继节点一样。

`SMA`^(\*) 在存在可达解的前提下是完备的，即当可达解的最浅目标节点的深度 *d* 小于内存大小（以节点数表示）时。如果任何最优解是可达的，则它是最优的；否则，它会返回最佳的可达解。实际中，`SMA`^(\*) 是一种相当稳健的选择，尤其在状态空间是图形、步 _cost 不均匀、且节点生成成本高于维护前沿和已探索集合开销时，它非常适合用于寻找最优解。

在非常困难的问题上，`SMA`^(\*) 往往会在许多候选解路径之间不断切换，只有极小一部分能够同时容纳在内存中。（这类似于磁盘存储系统中的 **thrashing** 问题。）此时，反复生成相同节点的额外时间会导致本应在无限内存情况下可解的问题变得不可解。也就是说，**记忆限制可以使计算时间下的问题变得不可解。** 尽管目前没有理论解释时间与内存之间的权衡，但这似乎是一个不可回避的问题。唯一的出路是放弃最优性要求。

## 3.6 HEURISTIC FUNCTIONS

本节探讨用于 8-puzzle 的启发式函数，以此说明启发式在一般情况下的本质。

8-puzzle 是最早的启发式搜索问题之一。正如在 Section 3.2 中提到的，该拼图的目标是水平或垂直滑动方块，直到配置与目标配置一致（Figure 3.28）。

随机生成的 8-puzzle 实例的平均解决成本约为 22 步。分支因子约为 3。（当空白块在中间时，有 4 种可能的移动；在角落时，有 2 种；沿边时，有 3 种。）这意味着，如果 exhaustive tree search 扩展到深度 22，它将检查大约 3²² ≈ 3.1 × 10¹⁰ 个状态。图搜索可以通过因子约 170,000 来削减这个数值，因为只有 9!/2 = 181,440 个可到达的不同状态。（见 Exercise 3.4。）这个数值是可管理的，但 15-puzzle 的对应数值大约是 10¹³，因此下一步是寻找一个好的启发式函数。如果我们想使用 A^(\*) 找到最短解，就需要一个永不高估目标步数的启发式函数。对于 15-puzzle，已有悠久的启发式历史；下面是两个常用候选：

> • *h*[1] = 误配块的数量。例如，在 Figure 3.28 中，所有八个方块都错位，因此起始状态的 *h*[1] = 8。*h*[1] 是可采纳的启发式，因为显而易见，任何错位的方块至少需要被移动一次。

> • *h*[2] = 方块到目标位置的距离之和。由于方块不能沿对角线移动，距离计算为水平和垂直距离之和，这被称为 **city block distance** 或 **Manhattan distance**。 *h*[2] 也是可采纳的，因为每一次移动最多只能使一个方块离目标更近一步。起始状态中方块 1 到 8 的 Manhattan distance 为

> *h*[2] = 3 + 1 + 2 + 2 + 2 + 3 + 3 + 2 = 18。

如预期，这两个启发式函数都不高估实际解决成本，而实际解决成本为 26。

### 3.6.1 启发式准确性对性能的影响

一种表征启发式质量的方式是 **有效分支因子** *b*^(\*)。如果 A^(\*) 为特定问题生成的节点总数为 *N*，而解的深度为 *d*，则 *b*^(\*) 是一棵均匀深度为 *d* 的树需要拥有的分支因子，才能容纳 *N* + 1 个节点。因此，

> *N* + 1 = 1 + *b*^(\*) + (*b*^(\*))² + … + (*b*^(\*))^(*d*)。
