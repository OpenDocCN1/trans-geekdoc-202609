
# 梯度提升与随机森林对比

| 偏差-方差权衡 | 随机森林通过平均多棵树的预测结果来减少方差。它较不容易过拟合，并且在噪声数据上表现良好。 | 梯度提升旨在通过最小化之前树所犯的错误来减少偏差和方差。它倾向于获得较低的偏差，但可能更容易过拟合。 |
| :--- | :--- | :--- |
| 并行性 | 随机森林可以并行训练每棵树，因为每棵树都是独立的。 | 梯度提升顺序训练树，限制了并行性。然而，可以使用并行化的梯度提升实现技术来克服这一限制。 |
| 超参数 | 随机森林的超参数包括树的数量、树的最大深度以及每次分裂考虑变量数量。 | 梯度提升的超参数包括学习率、树的数量和树的最大深度。 |
| 预测 | 随机森林通过对所有树的预测进行平均或投票来进行预测。 | 在梯度提升中，预测通过累加所有树的预测来实现，其中每棵树的贡献取决于其学习率。 |
| 可解释性 | 随机森林相对容易解释，因为它提供了变量重要性衡量，并可以显示每个变量对整体预测的贡献。 | 梯度提升（尤其是树的数量很多时）由于训练过程的顺序性，解释起来可能更复杂。 |
| 变量选择 | 随机森林为每棵树随机选择变量子集，导致树之间的相关性较低。 | 在梯度提升中，变量选择基于信息增益或梯度重要性，变量通常按顺序使用。 |

# 梯度提升的基本概念

![](img/shut3_2.jpg)

梯度提升是一种强大的集成学习方法，通过迭代组合弱学习器来创建一个强大的预测模型。为了正确执行该方法，我们需要理解一些重要的概念。[表 15.2](#chapter15.xhtml#tbl15_2) 展示了关键概念及其描述。

| 术语 | 描述 |
| :--- | :--- |
| 梯度提升 | 梯度提升是一种强大的集成学习方法，通过梯度下降法最小化误差，顺序组合弱学习器来创建一个强大的预测模型。 |
| 集成学习 | 梯度提升是一种集成学习方法，通过组合多个弱学习器（预测能力有限的个体模型）创建一个稳健且准确的预测模型。最终预测通过聚合所有单个弱学习器的预测获得。 |

| 术语 | 说明 |
| :--- | :--- |
| 弱学习器 | 在梯度提升的背景下，弱学习器是指性能略优于随机猜测的模型，但其自身的准确性并不高。梯度提升常用决策树作为弱学习器，但也可以使用其他模型。 |
| 梯度下降 | 梯度提升通过使用梯度下降优化来最小化指定的损失函数。它计算损失函数的梯度，并调整后续的弱学习器以纠正之前学习器产生的错误。学习过程旨在迭代减少损失并提高整体模型性能。 |
| 提升 (Boosting) | 梯度提升采用提升算法，按顺序构建集成模型，每个弱学习器都关注其前者的错误。后续学习器会对训练数据中的误分类示例赋予更高的权重，以纠正之前模型所犯错误。 |
| 残差 | 在梯度提升中，后续的弱学习器被训练用于预测前一个学习器产生的残差或误差。目标是通过完善模型的预测来逐步减少剩余误差。 |
| 损失函数 | 损失函数衡量模型性能并量化预测值与真实值之间的差异。在梯度提升中，算法在训练过程中最小化损失函数，以迭代地提高模型的预测能力。 |
| 学习率 | 学习率是控制梯度下降步长的超参数。它决定了每个弱学习器的贡献对最终集成模型的影响程度。较低的学习率使算法收敛较慢，但可以提高泛化能力；较高的学习率会导致收敛加快，但可能会增加过拟合风险。 |
| 树深度和树的数量 | 这些是控制单个决策树复杂大小的超参数。树深度影响模型捕捉数据复杂关系的能力，而树的数量决定了提升的迭代次数和整体模型复杂度。 |
| 随机梯度提升 | 随机梯度提升 (`SGB`) 是传统梯度提升算法的一种变体，在训练过程中引入了随机性。它结合了梯度提升和随机学习的概念，以增强模型的泛化能力并降低过拟合风险。 |
| 梯度提升加法模型 | 梯度提升加法模型 (`GBAM`) 是梯度提升的一种变体，扩展了传统算法以处理加法模型。加法模型是由单个输入变量函数之和组成的模型，其中每个函数仅取决于单个输入变量。 |
| 变量重要性 | 梯度提升提供了变量重要性的衡量标准，指示每个输入变量在做出预测时的相对贡献。它允许用户识别出影响最大的预测因子，并获得对底层数据模式的洞察。 |

# 梯度提升方法的优缺点

![](img/icon_8.jpg)

梯度提升是一种强大且广泛使用的机器学习算法，它具有若干优点和缺点。了解这些优劣可以帮助我们决定何时使用这种方法，并为预测建模步骤选择正确的配置。

## 梯度提升的优点

1. **高预测准确性**：梯度提升以其卓越的预测准确性著称。通过结合多个弱学习器，它创建了一个强大的集成模型，能够捕捉数据中的复杂关系并产生高度准确的预测。
2. **捕捉非线性关系**：梯度提升模型可以有效捕捉预测变量与目标变量之间的非线性关系，使其适用于数据呈现复杂模式的各种现实世界应用。
3. **变量重要性**：该方法提供了变量重要性的见解，使我们能够识别哪些预测因子在做出预测时影响最大。这些信息有助于变量选择，并对底层问题有更好的理解。
4. **灵活性**：梯度提升可以处理各种数据类型，包括数值型、分类型和文本型数据。它可以既用于关联模型也用于分类模型，是一种多用途的方法。
5. **对异常值的鲁棒性**：由于其集成性质，梯度提升对异常值具有较高的鲁棒性。随着模型从多个弱学习器的集体行为中学习，异常值的影响被降到了最低。
6. **处理缺失数据**：该方法处理缺失数据时不需要显式的数据填充技术。梯度提升中的决策树可以在训练过程中内部处理缺失值。
7. **无数据分布假设**：梯度提升不假设数据遵循任何特定分布，适用于底层数据分布未知的情况。

## 梯度提升的缺点

1. **潜在的过拟合**：梯度提升容易出现过拟合，特别是当模型复杂或数据集较小时。恰当的超参数调优和配置对于缓解这种风险至关重要。
2. **计算密集型**：训练梯度提升模型可能是计算密集且耗费时的，特别是在处理大型数据集或深树时。并行化和优化实现有助于解决这一问题。
3. **超参数调优**：为梯度提升寻找的超参数是一项具有挑战性的任务。模型的性能对超参数设置非常敏感，通常需要进行大量的实验来找到正确的配置。
4. **黑箱模型**：梯度提升的集成性质使其成为黑箱模型。换句话说，要解释模型的完整结构并完全解释其预测是非常困难的。
5. **数据不平衡**：梯度提升在处理不平衡数据集（某一类远多于另一类）时可能会困难。可能需要类别加权和数据重采样等技术来解决这个问题。

# 梯度提升步骤

![](img/icon_7.jpg)

梯度提升是一种迭代算法，以顺序方式结合弱学习器（单个决策树）以创建一个强大的预测模型。那么，它是如何工作的？以下是训练梯度提升模型的通用步骤。

1. **初始化模型**：通过定义初始预测来初始化模型，这在关联模型中通常设置为目标变量的平均值，在分类模型中设置为优势比的对数。
2. **计算残差**：计算实际目标值与初始预测之间的残差或误差。这些残差代表了模型需要学习和改进的信息。
3. **训练弱学习器**：在变量和计算出的残差上训练弱学习器（例如决策树）。弱学习器通常是很浅的，这意味着它的深度很小且分裂次数很少。目标是根据残差找到最佳分裂点，以最小化损失函数（例如关联模型中的均方误差 `MSE` 或分类模型中的对数损失）。

## 训练过程

4. **计算学习率**：确定一个学习率，它控制每个弱学习器对最终预测的贡献。学习率有助于防止过拟合，并控制每个弱学习器对集成模型的影响。
5. **更新模型**：通过将弱学习器的预测值加到之前的预测值中来更新模型。预测值通过学习率加权，这决定了每个弱学习器对整体模型的贡献。
6. **更新残差**：通过从实际目标值减去预测值来更新残差。这些更新后的残差代表了下一个弱学习器需要关注的剩余信息。
7. **重复步骤 3–6**：按照指定的迭代次数或直到满足停止条件，重复步骤 3–6。在每次迭代中，在更新后的残差上训练一个新的弱学习器，并相应地更新模型和残差。
8. **完成模型**：一旦完成所有迭代，通过组合所有弱学习器的预测来获得最终模型。学习率决定了每个弱学习器对最终预测的贡献。
9. **预测**：对新数据进行预测时，将数据通过每个弱学习器，并使用学习率组合它们的预测结果。最终预测是所有弱学习器预测之和。

值得注意的是，梯度提升算法存在变体，它们引入了额外的优化和增强以提高性能和训练速度。

这些步骤概述了训练梯度提升模型的一般过程。实际实现可能涉及额外的超参数调优，并根据所选梯度提升算法处理特定的细微差别。

# 梯度提升损失函数

![](img/icon_4.jpg)

在梯度提升中，损失函数的选择至关重要，因为它决定了算法在每次迭代中如何更新模型。损失函数衡量预测值与实际值之间的差异，算法旨在通过反复向集成模型中添加新模型来最小化这种差异。

梯度提升中最常用的损失函数是用于回归模型的 `MSE`（均方误差）和用于分类模型的 `cross-entropy loss`（交叉熵，也称为 `log loss`）。`MSE` 衡量预测值与实际值之间的平均平方差，而 `cross-entropy loss` 衡量预测概率分布与实际概率分布之间的差异。我将在节中提供常用损失函数的列表。

无论使用哪种特定的损失函数，算法都通过计算损失函数对预测值的负梯度来更新模型参数。该梯度提供了关于预测误差方向和大小的信息，并用于在最小化损失的方向上更新模型。

学习率也用于控制每次迭代中更新的大小。较低的学习率会导致更新幅度较小、收敛较慢，而较高的学习率会导致更新幅度较大、收敛较快。学习率的选择很重要，因为它决定了准确性与收敛速度之间的平衡。

![](img/ufig15_2.jpg)

以下是回归模型和分类模型中最常用的损失函数及其适用场景。

## 带有连续目标变量的回归模型损失函数

1. **均方误差** (`MSE`)：回归问题中最广泛使用的损失函数，`MSE` 计算预测值与实际值之间的平均平方差。
2. **平均绝对误差** (`MAE`)：`MAE` 衡量预测值与实际值之间的平均绝对差，这使其比 `MSE` 对离群值更不敏感。
3. **Huber 损失**：Huber 损失是 `MSE` 和 `MAE` 的结合，在误差较小时表现像 `MSE`，在误差大时表现像 `MAE`。它在两者之间取得了平衡，并且对离群值具有鲁棒性。
4. **分位数损失** (Quantile loss)：适用于分位数回归，其目标是预测目标分布的分位数。它优化预测分位数与实际分位数之间的差异。
5. **泊松损失** (Poisson loss)：当目标变量遵循泊松分布时使用该损失函数，例如计数数据回归问题。

## 带有类别目标变量的分类模型损失函数

1. **逻辑损失** (`log loss`)：二分类模型中最常用的函数。`log loss` 通过对错误分类进行加惩罚来衡量分类器的性能。
2. **多分类逻辑损失** (`multi-class log loss`)：用于多分类模型，该损失函数扩展了二分类交叉熵以处理多个类别，衡量预测概率与实际类别值之间的差异。
3. **指数损失** (`exponential loss`)：主要用于 `AdaBoost` 算法中的二分类模型。该损失函数为分类错误的样本分配更高的权重。

这些损失函数在引导梯度提升算法优化模型性能方面起着至关重要的作用。每个损失函数都有其优缺点，选择合适的损失函数取决于数据特征、目标变量类型以及建模目标。

# 梯度提升加法模型与随机梯度提升

![](img/icon_5.jpg)

在我们讨论的传统梯度提升算法之外，还有两种流行的梯度提升变体。它们是 `GBAM` 和 `SGB`。我们讨论了这些算法之间的主要区别，让我们更深入理解这种流行的机器学习方法。[表 15.3](#chapter15.xhtml#tbl15_3) 总结了这三种梯度提升类型的异同点。

## 表 15.3 传统梯度提升、GBAM 和 SGB 的区别

| 项目 | 传统梯度提升 | 梯度提升加法模型 (GBAM) | 随机梯度提升 (SGB) |
| :--- | :--- | :--- | :--- |
| 训练方法 | 传统梯度提升顺序训练弱学习器（通常是决策树），每个新学习器都专注于最小化之前学习器犯的错误。 | `GBAM` 通过允许包含不同类型的弱学习器（不仅限于决策树）扩展了传统的提升。允许组合不同的模型，如线性模型、决策树或神经网络。 | `SGB` 通过使用训练数据的随机子集来训练每个弱学习器，在训练过程中引入了随机性。 |
| 学习率 | 传统梯度提升使用固定的学习率，决定了每个弱学习器对整体集成模型的贡献。通常需要手动调优。 | `GBAM` 使用学习率来控制每个模型组件的贡献，类似于传统的梯度提升。 | `SGB` 使用与传统梯度提升相似的固定学习率。 |

| 特性 | 传统梯度提升 (Traditional Gradient Boosting) | GBAM | SGB |
| :--- | :--- | :--- | :--- |
| **分裂选择** | **确定性分裂选择**：传统梯度提升确定性地选择最佳分裂点，旨在最小化基于残差的损失函数。 | **弱学习器选择的灵活性**：`GBAM` 在选择弱学习器方面提供了灵活性。允许适用于不同类型变量和数据特征的不同模型。 | **随机子采样**：`SGB` 在每次迭代中随机采样训练数据的子集，增加了弱学习器的多样性并减少了过拟合。 |
| **模型** | 传统梯度提升倾向于创建高方差的复杂模型，特别是在迭代次数很大时。 | 与传统梯度提升相比，`GBAM` 可以提供更好的模型解释性，特别是当包含线性模型或其他内在可解释模型时。 | `SGB` 由于随机子采样引入了方差减少的权衡。它可以减少过拟合，但可能会增加偏差。 |
| **训练效率** | 由于其顺序性以及需要按顺序训练每个弱学习器，传统梯度提升可能比其他提升算法慢。 | 训练 `GBAM` 可能比传统梯度提升慢，特别是如果涉及神经网络等计算密集型模型时。 | `SGB` 比传统梯度提升更快，因为它在较小的数据子集上训练每个弱学习器。这使得它对于大型数据集更具扩展性。 |

## 梯度提升加法模型 (GBAM)

本质上，`GBAM` 是梯度提升的一种变体，它将传统算法扩展到处理加法模型。加法模型是由单个预测变量函数之和组成的模型，其中每个函数仅取决于一个预测变量。与传统梯度提升不同（在集成中的每个新模型都是在前一个模型的残差上训练的），而在 `GBAM` 中，新模型不是在残差上训练，而是基于原始输入变量训练的。

`GBAM` 算法的工作原理为每个预测变量构建一组基函数，然后将这些函数的线性组合拟合目标变量。基函数可以是任何类型的函数，可以根据特定问题和预测变量的复杂度进行选择。在每次迭代中，算法通过对损失函数关于当前预测的梯度进行模型拟合，向线性组合中添加新的基函数。这允许算法逐渐细化模型并提高其在训练数据上的性能。

`GBAM` 与传统梯度提升相比几个优点。首先，它很好地处理预测变量与目标变量之间的非线性关系，这对于许多现实世界问题非常重要。其次，通过为每个预测变量选择合适的基函数，将领域知识纳入模型。最后，通过将预测分解为单个预测变量函数的和，提供了更具解释性的模型。

然而，`GBAM` 也有一些局限性。首先，它需要为每个预测变量选择合适的基函数，这可能耗时且需要专家知识。其次，它可能无法捕捉预测变量之间复杂的交互，这可能会限制其在某些问题上的性能。最后，由于需要存储每个预测变量的基函数，它可能比传统梯度提升慢且需要更多内存。

## 随机梯度提升 (SGB)

`SGB` 是梯度提升的一种变体，它在训练过程中引入了随机性。在传统梯度提升中，集成中的每个新模型都在相同的样本和变量上训练，这会导致过拟合和模型泛化能力差。`SGB` 通过在每次迭代中随机采样数据和变量的子集解决了这个问题，带来了更多样化的模型集合和更好的预测能力。

`SGB` 与传统梯度提升的主要区别在于，它在较小的数据子集上训练每个弱学习器。这使得它对于大型数据集更具扩展性。

总结，传统梯度提升顺序训练弱学习器，使用固定的学习率并确定性选择选择。`GBAM` 扩展了这种方法以包含不同类型的弱学习器，并提供了灵活性解释性。最后，`SGB` 引入了随机子采样来提高训练效率并减少过拟合，但引入了方差-偏差权衡。这些算法之间的选择取决于数据集大小、解释性需求以及准确性和训练效率之间的权衡偏好等因素。

# 梯度提升超参数调优指南

如前所述，梯度提升涉及超参数调优，这是寻找优化配置和解决过拟合的关键步骤。由于梯度提升的复杂性及其许多变体，在调优超参数时，考虑计算资源、时间限制和数据集的大小很重要。建议使用交叉验证来评估不同超参数设置下的模型性能。通过迭代调优超参数并评估模型性能，你可以找到使模型准确性和泛化能力最大的组合。

以下是一些需要考虑的重要超参数及其调优技术。

1. **树的数量**：此超参数决定了集成中弱学习器（树）的数量。增加树的数量可以提高模型性能，但也会增加训练时间。找到正确的平衡点以避免过拟合至关重要。你可以尝试不同的值并使用交叉验证来选择最优数量。
2. **学习率**：学习率控制每个弱学习器对整体模型的贡献。较低的学习率使模型更稳健，但增加了收敛所需的迭代次数。较高的学习率可能会导致收敛更快，但可能导致过拟合。尝试不同的学习率以找到最优值。

### 3. 树的最大深度

该超参数决定了单个决策树的深度。更深的树可以捕捉数据中更复杂的关系，但容易过拟合。较浅的树可以减少过拟合，但可能导致欠拟合。根据问题的复杂性和可用数据调整最大深度是非常重要的。

### 4. 子采样 (Subsampling)

子采样是指训练每个弱学习器时使用的训练样本的比例。使用小于 1.0 的值会引入随机性并减少过拟合。然而，将其设置得过低可能会导致欠拟合。交叉验证有助于识别最佳子采样值。

### 5. 变量子采样 (Variable subsampling)

该超参数决定了训练每个弱学习器时使用的变量比例。它引入了随机性并有助于减少过拟合。你可以尝试不同的值（例如 0.5、0.8）来找到最佳的变量子采样率。

### 6. 自动超参数优化

还有一些自动超参数优化技术可用，例如贝叶斯优化、遗传算法或基于梯度的优化。这些方法可以有效地搜索超参数空间并找到最优值，通常使用引导式探索过程。
