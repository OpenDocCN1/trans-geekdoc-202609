
其中 `μ` 被称为位置参数，`b` 是称为多样性的尺度参数。它的期望为 `E[x] = μ`，方差为 `var[x] = β^2`。图 2.2 和 2.4 显示了累积分布函数的示例，说明了正态分布，因为均值相同，且选择的 `b` 使得方差也相同。如果数据表明密度函数比正态分布更尖峰，则该分布是一个合适的选择。

接下来，我们考虑一种被称为 Beta 分布的概率密度，`x ~ Beta(α, β)`。它只定义在区间 `(0,1)` 上，其概率密度函数为：

`Beta(x|α, β) = Γ(α + β) / (Γ(α)Γ(β)) x^{α-1}(1-x)^{β-1},`

![](img/c6c76bf52016db7e78a5e30d4766ef81_62_0.png)

图 2.17：不同 `μ` 和 `b` 值的拉普拉斯概率密度函数，其选择使得均值和方差与图 2.2 相同。

其中 `α` 和 `β` 是正实数。函数 `Γ(z)` 被称为*伽函数*（gamma function），定义为：

$$\Gamma(z) = \int_{0}^{\infty} x^{z-1} \exp(-x)dx.$$

使用*分部积分法*，我们可以计算：

$$\Gamma(z+1) = \int_{0}^{\infty} x^z \exp(-x)dx = \left[ -x^z \exp(-x) \right]_0^{\infty} + \int_{0}^{\infty} z x^{z-1} \exp(-x)dx.$$

第一项消失，因为在零处有 `z` 的正幂，而当 `x` 趋于无穷大时 `exp(-x)` 趋于零的速度比任何 `x` 的幂次方都快。因此：

$$\Gamma(z+1) = \int_{0}^{\infty} x^{z-1} \exp(-x)dx = z\Gamma(z), \quad (2.14)$$

这被视为阶角的实数扩展。如果 `z=n` 是整数，再次使用上述关系导致：

$$\Gamma(n+1) = n\Gamma(n) = n(n-1)\dots\Gamma(1),$$

由于 `Γ(1) = 1`。分数

$$B(\alpha, \beta) = \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)}$$

被称为 *Beta 函数*（beta function），它命名了该分布。它与二项式系数有关。如果 `α = m` 和 `β = n` 是整数：

$$\frac{1}{B(m,n)} = \frac{(m+n-1)!}{(m-1)!(n-1)!} = \frac{m+n}{m} \binom{m}$$

通过此，我们看到 Beta 密度函数的形状与二项分布的概率密度函数相似（2）。主要区别在于，二项分布中的随机变量是成功次数 `m`，而 Beta 分布中的随机变量是 `x`。它占据成功的概率。正因如此，Beta 分布被视为比例的分布。我们将在 2.6 节看到如何利用这种相似性。

图 19 显示了不同 `α` 和 `β` 取值的 Beta 密度函数，包含了许多形状。当 `α = β = 1` 时，Beta 分布变为均匀分布。当 `α` 或 `β` 小于 1 时，密度函数将在区间边缘趋于无穷。

![](img/c6c76bf52016db7e78a5e30d4766ef81_64_0.png)

图 19：不同 `β` 和 `α` 值的 Beta 概率密度函数。

期望的计算为：

`E[x] = ∫_0^1 x Beta(x|α,β)dx = Γ(α+β)/(Γ(α)Γ(β)) ∫_0^1 x^{α}(1-x)^{β-1}dx = Γ(α+1)Γ(β)/Γ(α+β+1) ∫_0^1 Beta(x|α+1,β)dx = α/(α+β).`

其中我们使用了伽函数的性质（2.14）以及任何概率密度函数在其范围内的积分为一的事实。方差给出：

$$var[x] = \frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$$

当 `α=β` 时，期望始终为 `1/2`，而方差为 `(4(2α+1))^{-1}`。因此，这些值的概率密度函数图关于 `1/2` 对称，而图 2.20 中的累积分布函数通过 `1/2`。

- Beta 分布可以视为二元结果实验概率的分布，其中 `x` 是成功的概率，`1-x` 是失败的概率。如果 `x` 服从 `Beta(x|α,β)` 分布，那么 `1-x` 服从 `Beta(1-x|β,α)` 分布。

![](img/c6c76bf52016db7e78a5e30d4766ef81_65_0.png)

图 2.20：不同 `β` 和 `α` 值的 Beta 累积分布函数。

正如我们从二元变量的伯努利分布移动到多个互不相同结果实验的分类分布，我们将 Beta 分布扩展为 `K` 个概率的分布 `0 ≤ x_k ≤ 1, k=1,…,K`，这些概率之和为一：

$$\sum_{k=1}^K x_k = 1$$

概率在随机变量向量 `x = (x_1,…,x_K)^T` 中。因为约束 `x` 只能位于长度为 `K` 的向量空间的子集内。对于 `K=3`，如图 2.21 所示。向高维推广被称为*单纯形*（simplex）。对于 `K=3`，`2`-单纯形是三角形。

对于 `x ~ Dir(α)`，该分布被称为 *狄利克雷分布*（Dirichlet distribution），其概率密度函数给出：

$$Dir(α) = \frac{Γ(α_1 + … + α_K)}{Γ(α_1)…Γ(α_K)} \prod_{k=1}^K x_k^{α_k-1}, \quad (2.15)$$

参数 `α = (α_1,…,α_K)^T` 被称为*浓度参数*（concentration parameters）。它们都是正数。当 `K=2` 时，狄利克雷分布就是 Beta 分布。

图 2.22 显示了单纯形上不同 `α` 取值的三维狄利克雷概率密度函数。密度函数所取的值由颜色指示。

![](img/c6c76bf52016db7e78a5e30d4766ef81_66_0.png)

图 2.21：由于元素限制，**x** 可能位置的单纯形。

当 `α_1 = … = α_K` 时，该分布被称为*对称狄利克雷分布*或*平坦狄利克雷分布*。后者的命名具有误导性，因为只有当所有浓度参数都取值为1时，它才是平坦的。此时，狄利克雷分布变为单纯形上的均匀分布。在这种情况下，

```
$$\text{Dir}(\mathbf{x}) = \frac{\Gamma(K)}{\Gamma(1)\cdots\Gamma(1)} \prod_{k=1}^K x_k^{0}=(K-1)!$$
```

这是单纯形体积的倒数。对于 `K=3`，2单纯形的体积为 1/2。

我们在[图 2.22]中看到，对于 `α=(5,5)^T`，概率质量集中在中心；而对于 `α=(5,2)^T`，它集中在具有最小浓度参数的角的对侧边缘。对于 `α=(5,2)^T`，概率质量集中在浓度参数最大的角上。

当其中一个浓度参数 `α_i` 小于1时，概率密度函数将在相应的边缘 `x_k=0` 处趋于无穷大。对于[图 2.22]，这对于 `α=(0,8,0,2)^T` 是可见的，但对于 `α=(0,8,0,2)^T` 则几乎可见。


## 2.5 连续随机变量函数

在机器学习中，数据有时是其他数据的函数，考虑随机变量函数并推导出概率密度函数的技巧是非常重要的。如果 `x` 是一个概率密度函数为 `f_x(x)` 的连续随机变量，那么对于连续变量 `g`，`g(x)`也是一个连续随机变量，但它的概率密度函数 `f_g(y)` 是什么？我们加上下标是为了明确概率密度函数和累积分布函数所指的是哪一个随机变量。

我们将注意力限制在 `g` 是单射变换的情况下。即 `g` 的每个值恰好生成一个 `y` 值，而每个 `y` 值恰好由一个 `x` 值生成。基于此，存在一个反函数 `g^{-1}` 使得 `x=g^{-1}(y)`。由于 `g` 是连续的，它必须是严格递减或递增的。

先取递增的情况，可以使用累积分布函数 `F_x` 和 `F_y` 推导出概率密度函数。给定一个 `y`，

`F_y(y) = p(g(x) ≤ y)`.

现在，由于 `g` 是严格递增的，如果 `g(x) ≤ y`，则同时 `x ≤ g^{-1}(y)`。因此，

`F_y(y) = p(x ≤ g^{-1}(y)) = F_x(g^{-1}(y)) = ∫_{-∞}^{g^{-1}(y)} f_x(x)dx`.

使用换积分法，令 `x=g^{-1}(t)`，上限变为 `y`，并得到 `dx=(g^{-1})'(t)dt`.

`F_y(y) = ∫_{-∞}^{y} f_x(g^{-1}(t))(g^{-1})'(t)dt`.

为了找到概率密度函数，我们对 `y` 求导。根据微积分基本定理：

`f_y(y) = f_x(g^{-1}(y))(g^{-1})'(y)`.

严格递减情况的推导也是类似。然而，由于 `g` 是递减的，`g(x)` 小于等于 `y` 仅当 `x ≥ g^{-1}(y)` 时。

`F_y(y) = p(x ≥ g^{-1}(y)) = 1 - F_x(g^{-1}(y)) = 1 - ∫_{-∞}^{g^{-1}(y)} f_x(x)dx`.

![](img/c6c76bf52016db7e78a5e30d4766ef81_73_0.png)

图 2:24：不同自由度 k 的 `χ^2` 概率密度函数。

再次，通过换积分法并对 `y` 求导，得到：

`f_y(y) = -f_x(g^{-1}(y))(g^{-1})'(y)`.

由于 `g` 是递减的，所以 `g^{-1}` 及其导数为负值。这使得整个表达式为正。

与严格递增的情况相比，`g^{-1}(y)` 的导数始终为正，这两种情况可以总结为：

`f_y(y) = f_x(g^{-1}(y)) |(g^{-1})'(y)| = f_x(g^{-1}(y)) |dx/dy|`  (2.17)

其中最后使用了常用的简写符号。这被称为变量代换法，在它的推导过程中，我们改变了积分中的变量。另一个名称是直接变换法。

我们先通过一个例子来说说明 `g` 不是单射变换的情况。设 `x` 服从正态分布 `N(0,1)`，令 `y=x^2`。当 `-∞ < x < ∞` 时，有 `0 ≤ y < ∞`。每个 `y` 值由两个值 `x_1 = -√y` 和 `x_2 = √y` 生成。采用相同的方法：

```
$F_y(y) = p(x^2 ≤ y) = p(-√y ≤ x ≤ √y) = F_x(√y) - F_x(-√y)$
$ = ∫_{-∞}^{√y} f_x(x)dx - ∫_{-∞}^{-√y} f_x(x)dx$
$ = ∫_{-∞}^{√y} f_x(t) 1/(2√t) dt - ∫_{-∞}^{-√y} f_x(t) -1/(2√t) dt$,
```
