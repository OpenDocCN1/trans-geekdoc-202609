### 基于图像导数的核

让我们首先了解导数在恒定强度、阶跃和斜坡强度不连续性/斜坡的开始与结束处的行为。*图 10.13* 绘制了像素强度图，描绘了强度斜坡和阶跃。

在图像中，沿一个维度，像素 `x` 的邻域像素为 `x + 1` 和 `x - 1`。利用此信息，一维函数的一阶导数基本定义如下：

`f'(x) = f(x + 1) - f(x)`

一阶导数的性质如下：

*   在恒定强度区域为零
*   在强度斜坡/阶跃的开始和结束处非零
*   沿强度斜坡非零

类似地，二阶导数的定义如下：

`f''(x) = f(x + 1) + f(x - 1) - 2f(x)`

二阶导数的性质如下：

*   在恒定强度区域为零
*   在强度斜坡/阶跃的开始和结束处非零
*   沿强度斜坡为零

*图 9.13* 显示了强度值的一阶和二阶导数。我们可以验证这些导数的性质。导数提供了关于恒定强度、斜坡上升/下降和阶跃强度的信息。数字图像中的边缘表现得像斜坡强度。识别这些斜坡将有助于我们寻找边缘，从而辅助图像锐化。接下来，我们将使用二阶导数进行图像锐化。请参考下图：

### 拉普拉斯核——二阶导数

最简单的各向同性（在所有方向均等适用）导数算子是*拉普拉斯算子*，对于二元函数定义如下：

`∇²f = ∂²f/∂x² + ∂²f/∂y²`

由于任何阶导数都是线性的，拉普拉斯算子是线性算子。我们需要将该算子以离散格式表示用于二维图像，如下所示：

`∇²f(x, y) = f(x+1, y) + f(x-1, y) + f(x, y+1) + f(x, y-1) - 4f(x, y)`

离散化的拉普拉斯算子可写为：

```
0  1  0
1 -4  1
0  1  0
```

2.     # Exponent part of gaussain function mean=0, sd=1

## Sobel 核：一阶导数

迄今讨论的拉普拉斯核是二阶导数，用于测量斜率的变化。而 Sobel 核是一阶导数，用于测量斜率，并像 LoG 一样结合了高斯平滑。

Sobel 核由两个核组成，分别计算水平轴和垂直轴方向导数的近似值。可以使用 OpenCV 库获取各种尺寸的 Sobel 滤波器。*代码 9.8* 展示了获取 Sobel 滤波器的步骤。`getDerivKernels()` 输出两个大小为 `dim×1` 的向量，这两个向量需要相乘以获得可分离向量：

```
1. def get_sobel_kernel(dim=3):
2.     sobelx_sep = cv.getDerivKernels(1, 0, dim, normalize=True)
3.     sobelx = np.outer(sobelx_sep[0], sobelx_sep[1])
4.     sobely_sep = cv.getDerivKernels(0, 1, dim, normalize=True)
5.     sobely = np.outer(sobely_sep[0], sobely_sep[1])
6.     return sobelx, sobely
```

## 非线性滤波器

*中值滤波器* 是一种用于去除噪声的非线性滤波器（对“椒盐噪声”有效：这是一种由尖锐突发干扰引起的噪声形式，表现为稀疏分布在图像上的黑白像素）。大小为 `n×n` 的 *中值滤波器* 在应用于某像素时，将其替换为该像素及其邻域像素的中值（`n×n` 个像素的中值），卷积核中心与待处理像素对齐。滤波器在整个图像上滑动。为了覆盖边界像素，通常使用 *边界复制* 填充，即用最近像素值填充边界。

*平均滤波器* 在应用于某像素时，将其替换为该像素及其邻域像素的平均值（`n×n` 个像素的平均值），卷积核中心与待处理像素对齐。与所有其他滤波器一样，该滤波器通过在每个可能的像素上滑动来应用于图像。

同样，*最大（最小）滤波器*会将像素值替换为 *n×n* 个像素（像素及其邻域）中的最大（最小）值。这种非线性滤波器广泛用于推断图像的网络中。

我们讨论了空间域中的几种滤波器及其在提取图像各种特征方面的用途。这些特征帮助我们执行所需的操作/对图像进行分类。为各种分类任务策划滤波器并非易事。事实上，我们可能无法识别出所有有助于执行分类任务的滤波器。由于这些复杂性，研究人员想到了根据分类任务来学习这些滤波器。

## 学习滤波器

**深度神经网络** (**DNN**) 在根据分类任务自动学习特征方面表现出色。我们能否将 DNN 和卷积操作结合起来，根据图像修改/分类任务自动学习滤波器/卷积核？可以，结合这两种操作的网络称为 **卷积神经网络** (**CNN**)。

> **注意：** 我们能否将图像作为输入馈送给 DNN 以执行图像分类任务？可以。DNN 的输入层维度将等于 `w × h × d`（图像的维度）。对于 224×224 的 RGB 图像，将需要 224×224×3=150,528 个输入层维度。随着深层的增加，待学习的参数会进一步增加。因此，由于维度较高，DNN 可能无法学习参数（维度灾难）。

## 卷积神经网络

为了克服 DNN 在图像处理中巨大的参数空间，利用了在输入数据间共享参数的卷积操作。卷积操作的这种参数共享机制，结合 DNN，极大地推动了图像推理算法的发展，这些网络被称为 **卷积神经网络** (**CNN**)。CNN 的主要构建模块是卷积、池化（下采样）和 **全连接** (**FC**) 层。

CNN 由多个卷积层和池化层组成。通常，卷积层后面跟着一个池化层。这种组合层重复堆叠以提取更好的特征。在网络的末端，存在全连接层，它们根据卷积层和池化层提取的特征帮助进行分类，如 *图 9.23* 所示：

## 卷积层

这是 CNN 的核心构建模块，卷积操作在此执行。网络的大部分计算发生在这一层。假设卷积层的输入维度为 ![](img/2376.jpg)。在此层中应用 ***n*** 个大小各异但深度相同为 ***d*** 的卷积核，如 *图 9.24* 所示。

每个卷积核与输入块卷积以产生一个二维 *特征图*。卷积核在输入的 ***w × h*** 平面上从左上角滑动到右下角以进行卷积。卷积核的滑动步长可以是一个像素或多个。这称为 *步长*。在特定方向上滑动/跳过的像素数将是该方向上的 *步长* 值。如果卷积核向右或向下移动一个像素以进行下一次卷积操作，则步长为 1。

由于缺少映射到卷积核单元的单元，输入块边缘沿的单元格（***w × h*** 平面）无法与卷积核中心对齐。卷积操作无法在输入块的每个单元格上执行，这会导致特征图尺寸减小（维度小于 ***w × h***）。为避免这种情况，我们可以在输入块边缘沿填充常数值（通常为 0），使得卷积核中心能与 ***w × h*** 平面内的每个单元格对齐。这称为 *填充*。

有三种常用的填充值方式：

*   **有效填充**：在有效填充中，仅当输入与卷积核之间的单元格存在一对一映射时才执行卷积操作。这会减小输出尺寸，因为有效卷积无法在输入的每个单元格上进行。
*   **同类填充**：在同类填充中，输入被填充值，使得输出尺寸与输入相同（***w × h*** 平面）。
*   **完全填充**：在完全填充中，输入被填充值，使得输出尺寸大于输入尺寸（***w × h*** 平面）。
