fMRI 分析的主要目标之一是检测、研究和表征不同的 FBN，并将它们与特定的心理和身体活动联系起来。为了实现这一点，接受 fMRI 扫描的受试者（人）会接触到精心设计的实验程序，以便尽可能可控地激活 FBN。

ICA 已成功用于 fMRI 解混，即用于估计上述矩阵 `A` 和 `Z`。如果我们将 `X` 的每一列视为随机向量 `**x**` 的一个实现，则 fMRI 数据生成机制可以建模为遵循经典的 ICA 潜在模型，即 `**x** = A**s**`<mml:math><mml:mi mathvariant="bold">x</mml:mi><mml:mo linebreak="goodbreak" linebreakstyle="after">=</mml:mo><mml:mi>A</mml:mi><mml:mi mathvariant="bold">s</mml:mi></mml:math>![Equation](img/si629.png)，其中 `**s**` 的各分量在统计上是独立的，而 `A` 是一个未知的混合矩阵。ICA 的目标是恢复解混矩阵 `W` 和 `Z`。然后从 `W` 中获得矩阵 `A`。在 fMRI 任务中使用 ICA 可以通过以下论据来证明。同一列中 `Z` 的非零元素对 `X` 的单个元素的形成有贡献，对于每个时间点 `n`，它们对应不同的 FBN。因此，假设它们对应于统计独立的源。

作为将 ICA 应用于 `X` 的结果，人们希望获得的矩阵 `Z` 的每一行都能与一个 FBN 相关联，即与一个空间活动图相关联。此外，`A` 的相应列可以代表相应的时间激活模式。

#### 2. 计算特征向量（特征脸）的直接方法

一种直接的方法是使用 `svd.m` MATLAB® 函数对矩阵 `X` 执行 SVD，即 `X = U * D * V^T`。这样，特征脸就是 `U` 的列。然而，这需要大量的计算工作，因为 `X` 有太多行。或者，你可以按如下步骤进行：

1.  首先计算乘积 `A = X^T * X`。

2.  然后使用 `svd.m` MATLAB® 函数计算 `A` 的 SVD，即 `A = V * D² * V^T`，以此计算 `X` 的右奇异向量。

3.  然后根据公式 `u_i = (1 / σ_i) * X * v_i` 计算每个特征脸，其中 `σ_i` 是 SVD 的第 `i` 个奇异值。

4.  最后，随机选择一张人脸，使用前 5、30、100 和 600 个特征向量对其进行重构。

接下来遵循以下步骤：

1.  使用 `im2col.m` MATLAB® 函数从图像中提取所有大小为 `12 × 12` 的可能滑动补丁，并将它们作为列存储在矩阵 `X` 中。

3.  作为下一步，分别对每个图像补丁进行去噪。特别是，假设 `y_i` 是重塑为列向量的第 `i` 个补丁，使用 OMP（10.2.1 节）来估计一个稀疏向量 `θ_i ∈ ℝ¹⁹⁶`，满足 `||θ_i||_0 = 5`，使得 `||y_i - A * θ_i||` 很小。

4.  然后 `ŷ_i = Ψ * θ_i` 是第 `i` 个去噪后的补丁。

5.  最后，对重叠补丁的值取平均以形成完整的去噪图像。
