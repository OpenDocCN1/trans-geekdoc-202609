
- **事件日志** 在 Windows 系统上，请查看事件查看器中与安全事件相关的条目。

- **审核日志** 如果已启用审核，请查看应用程序、系统或设备的审核日志以发现可疑活动。

- **安全日志** 如果设备有安全日志，请检查其中与安全相关的信息。

- **访问日志** 大多数服务器和设备都有访问日志，可让您查看谁获得了对资源的访问权限。就物理安全而言，电子锁通常具有访问日志，以便您查看谁在不同时间获得了进入设施的权限。

### 常见审计区域

必须在所有关键应用程序和设备上启用审计和日志记录。本章已经查看了您可以考虑审计的服务示例，但调查所有设备和软件的审计和日志记录功能至关重要。以下是网络上应启用审计或日志记录的其他区域列表：

*   **Security application**  

    如果您拥有执行特定功能的安全设备或应用程序，请务必研究该设备的审计功能。大多数软件和设备将允许您审计谁有权访问该设备，以及对该设备的任何管理更改。

*   **DNS**  

    审计 DNS 的更改，因为这是黑客会投毒以将客户端重定向到错误系统的区域。

*   **Performance**  

    性能问题可能是安全事件——例如，如果您注意到系统运行非常缓慢，可能是感染了病毒，或者黑客可能将其用作僵尸系统进行其他处理。使用性能监视器来识别运行缓慢的系统区域。

*   **Access**  

    如前所述，大多数设备和服务将允许您记录谁获得了对系统的访问权限。这可能是有助于证明在企业发生非法活动（如盗窃）时谁有权进入设施的关键信息。

*   **Firewall**  

    定期查看防火墙日志非常有用，因为它们将显示通过防火墙的流量，包括流量的源 IP 地址，或在防火墙被丢弃的数据包及其原因。

*   **Antivirus**  

    查看防病毒软件的日志，以确保更新正在发生。

*   **Proxy server**  

    代理服务器日志可以提供关于谁浏览了互联网以及他们访问了哪些站点的详细信息。

*   **Wireless access point**  

    如果您在家里或办公室使用无线路由器，可以查看路由器上的日志以查看任何安全相关事件（参见 Figure 19-10）。您还可以启用日志记录以监控内部用户的互联网活动。

![Image](img/f0767-01.jpg)

**Figure 19-10**  

在无线接入点（路由器）上查看日志

*   **User access and rights review**  

    请务必定期审查所有人在系统上的权利。这包括检查用户权利分配以及管理组中的成员资格。

*   **Storage and retention policies**  

    许多公司受法规管辖，规定必须存储和保留文档和电子邮件等信息一定的时间。审查策略并确保所有员工都遵守。

*   **Group policies**  

    组策略是从一个中心位置在整个网络上强制实施审计的好方法。通过组策略，您可以启用审计并管理安全日志的大小，以免日志填满并停止记录事件。

# 认证总结

在本章中，您了解了监控系统的重要性以及可用于监控系统或网络上活动的不同工具。以下是关于监控的一些要点：

*   确保服务器和设备为核心服务（如 Web 和 FTP）启用了日志记录。

*   确保防火墙、代理服务器和无线接入点等设备启用了日志记录，以监控这些设备上的活动。

*   在系统上配置审计，并务必定期评估审计选项，以确保它们未被网络管理员禁用。

*   在 Windows 系统上使用本地安全策略在独立系统上启用审计，但在 Active Directory 环境中使用组策略在多个系统上配置审计。

*   Windows 中的 **Performance Monitor** 用于监控系统的运行状况，包括处理器和内存使用情况。

*   **Message Analyzer/Network Monitor** 和 **Wireshark** 是数据包嗅探器（或协议分析器）的示例，用于监控网络流量并识别网络上运行的流量类型方面的任何安全相关问题。

*   您可以在 Windows 和 Linux 中使用许多命令行实用程序来帮助监控系统上的活动。

通过深入理解本章呈现的材料，您将不会在考试中遇到任何与监控相关的问题。这些材料不仅对考试很重要，而且在您通过考试后继续进行在职故障排除和系统监控时也将非常重要！
