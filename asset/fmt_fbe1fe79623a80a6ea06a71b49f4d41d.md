
### 定义 14.5.
上链复形 `C^* = {C^q, δ^q}` 是一堆阿贝尔群 `C^q` 和一串排列成序列 `⋯ ← C^{q+2} \overset{δ^{q+1}}{→} C^{q+1} \overset{δ^{q}}{→} C^{q} \overset{δ^{q-1}}{→} C^{q-1} ← ⋯` 的同态 `δ^q: C^q → C^{q+1}`，使得对于任意维度 `q`，`δ^q ∘ δ^{q-1} = 0`，即两个上边缘为零。

`C^*` 的 `q`-维上同调循环群 `Z^q(C^*) := ker δ^q`，其元素称为 `q`-维上链。`q`-维上链群 `B^q(C^*) := im δ^q`，其元素称为 `q`-维上边缘链。商群 `H^q(C^*) := Z^q(C^*)/B^q(C^*)` 称为 `C^*` 的 `q`-维上同调群。

### 定义 14.6.
`C^*`, `D^*` 是上链复形。上链映射 `f^*: C^*→D^*` 是一串同态 `f^* = {f^q: C^q → D^q}`，使得对于任意维度 `q`，`δ^q ∘ f^q = f^{q+1} ∘ δ^q`。它诱导上同调群的同态 `f^*: H^*(C^*) → H^*(D^*)`。

### 定义 14.7.
两个上链映射 `f^*: C^* → D^*` 被称为上链同伦。如果存在一串同态 `T^* = {T^q: C^q → D^{q-1}}`，使得对于每个维度 `q`，`δ^{q-1} ∘ T^q + T^{q+1} ∘ δ^q = g^q - f^q`，则 `T^*` 是耦合 `f^*, g^*` 的上链同伦，记为 `f^* = g^*: C^* → D^*`。上链同伦的上链映射诱导相同的上同态。

拓扑变化是曲面内部和边界变换为另一个曲面的内部和边界的过程。

#### 算法 14.7：判断二维链之间的关系是否等价。

```
过程 Chain of q dimension

//输入：n, k //

//输出：{0,1}// 

计算 Z_q(K) = {z_q ∈ C_q(K); ∂z_q = 0} = Ker_q

计算 B_q(K) = {b_q ∈ C_q(K); ∃c_{q+1} ∈ C_{q+1}(k), 使得 ∂c_{q+1} = b_q} = Im∂_{q+1}

计算 H_q(K) = Z_q(K)/B_q(K)

结束过程 Chain of q dimension
```

商群 `H_q(K)` 中的元素是 `Z_q(K)` 中元素 `B_q(K)` 的陪集（模）。因此，由复形 `K` 的模 `B_q(K)` 在 `q` 维闭链 `z_q` 上确定的等价类为 `z_q + B_q(K)`，记为 `[z_q]`。我们称 `z_q` 为一个 `q` 维同调类，并且对于任意 `[z_q] + [z_q'] = [z_q + z_q']`，我们有 `H_q(K) = {[z_q]; z_q ∈ Z_q(K)}`。如果 `z_q, z_q' ∈ Z_q(K)`，则 `[z_q] ↔ z_q - z_q' ∈ B_q(K)`。我们称 `z_q, z_q'` 为上同调 `q` 维闭链，记为 `z_q - z_q' ∼ 0` 或 `z_q ∼ z_q'`。

对于任意 `q` 维链 `c_q, c_q' ∈ C_q(K)`，如果 `c_q - c_q' ∈ C_q(K)`，则我们称 `c_q, c_q'` 为上同调 `q` 维链，记为 `c_q - c_q'`。显然，`q` 维链之间的同调关系是一种等价关系。`c_q ∈ C_q(K)` 的同调等价类为 `[c_q] = c_q + B_q(K)`；我们称之为 `c_q` 的 `q` 维同调类。

### 14.2.4 胞腔同调边界算法

许多常用的空间可以切割成简单的形状。我们可以研究由标准砖块创建的空间，这是复形概念的起源。历史上第一个被研究的复形是单纯复形。目前，胞腔复形正在被越来越多地使用和研究。砖块即胞腔，建立链群和同调群的方法称为胞腔一致性理论。胞腔复形比单纯复形更灵活。分解所需的胞腔数量较少；因此，计算更方便。在本节中，我们主要介绍胞腔复形的一些同伦性质作为基本事实。我们主要研究有限胞腔复形，但也关注单一胞腔复形，即空复形。

### 定义 14.8.
如果拓扑空间 `Y` 同胚于一个 `q` 维实心球，则称其为 `q` 维闭实心 `q` 球。如果拓扑空间 `Y` 同胚于一个 `q` 维开实心球，则称其为 `q` 维胞腔。`Int D^q := D^q - S^{q-1}`。

### 定义 14.9.
设 `(Y, B)` 为一个胞腔复形对，`Y - B` 由一个 `k` 维胞腔构成。则，

$$
\begin{cases} 
H_q(Y,B)=0, & \text{若 } q \neq k \\ 
H_k(Y,B) = \mathbb{Z} 
\end{cases}
$$

### 定义 14.10.
设 `(X, A)` 为一个胞腔复形对。`(X, A)` 的 `q` 维胞腔链定义为 `C_q(X, A) := H_q(X^q ∪ A, X^{q-1} ∪ A)`。根据上述引理，它是一个自由阿贝尔群。胞腔边界算子 `∂_q : C_q(X - A) → C_{q-1}(X - A)` 定义为三元组 `(X^q ∪ A, X^{q-1} ∪ A, X^{q-2} ∪ A)`，它们在正合同序列 `H_q(X^q ∪ A, X^{q-1} ∪ A) \xrightarrow{d_*} H_{q-1}(X^{q-1} ∪ A, X^{q-2} ∪ A)` 中是同胚的。

#### 命题 14.1.
`C_*(X, A) := {C_q(X, A), ∂_q}` 是一个链复形。

*此链复形称为 `(X, A)` 的胞腔链复形。*

### 定义 14.11.
设 `(X, A)` 和 `(Y, B)` 为胞腔复形对，且 `f : (X, A) → (Y, B)` 为确定胞腔链映射的胞腔映射：

`f_*^C = {f_q^C} : C_*(X, A) → C_*(Y, B)`，其中 `f_q^C : C_q(X, A) → C_q(Y, B)` 定义为 `f` 诱导的同态映射，`f_* : H_q(X^q ∪ A, X^{q-1} ∪ A) → H_q(Y^q ∪ B, Y^{q-1} ∪ B)`。

#### 命题 14.2.
`f_*^C = {f_q^C} : C_*(X, A) → C_*(Y, B)` 是一个链映射。

根据上述定理和引理，我们可以得到胞腔一致性同调分类算法（算法 14.8）

#### 算法 14.8：胞腔一致性分类算法

```
过程 Cellular homology

//输入：胞腔复形对 (X,A)//

//输出：{0,1} // 

计算胞腔链复形 `C_*(X, A; G)`

Hom `C_*(X, A; G) = H_q(X^q ∪ A, X^{q-1} ∪ A) \xrightarrow{i_*} H_q(X^q ∪ A, A) \xrightarrow{j_*} H_q(X, A)`

`im i^* = j^* Z^q(C^*(X, A))`

计算 `Θ^* : H^*(X, A) \xrightarrow{≅} H^*(C^*(X, A))`

计算上同调序列

`0 ← C^*(A) \xrightarrow{j^*} C^*(X) \xrightarrow{i^*} C^*(X, A) ← 0`

结束过程 Cellular homology
```

该算法为建立胞腔边界同态模型奠定了基础。

设 `X` 为一个胞腔复形。我们用 `{e_i^q}` 表示 `X` 中的一组胞腔。那么，在 `q` 维胞腔链群中，边界同态 `∂_q` 可以写为 `∂_q(e_i^q) = Σ_j [e_i^q: e_j^{q-1}] e_j^{q-1}`。系数 `[e_i^q: e_j^{q-1}]` 是两个胞腔之间的相关系数。由相关系数组成的矩阵 `{[e_i^q: e_j^{q-1}]}` 称为关联矩阵（incidence matrix）。

为了计算相关系数 `([e_i^q: e_j^{q-1}])`，我们取一点 `b ∈ e^{q+1}`。其在粘贴映射 `π_{(q+1)}` 下的原像是 `S^{(q-1)}` 中的一对径向点 `a, a'`。由于路径映射在 `S^{(q-1)}` 上的度，两个原像点 `a, a'` 相差 `(-1)^q` 倍。可调整的定向 `e^q` 允许 `a` 的值为正。

因此，链 `C_*(P^n)` 具有以下形式：

$$
\begin{array}{ccccccc} 
\text{偶维} & 0 & \text{1维} & 2 & \dots & 0 \text{ 奇维} & 2 \text{ 偶维} & 0 \text{ 奇维} & 2 & \dots & 1+(−1)^n \text{ n维} \\ 
\mathbb{Z} & \longleftarrow & \mathbb{Z} & \longleftarrow & \dots & \longleftarrow & \mathbb{Z} & \longleftarrow & \mathbb{Z} & \longleftarrow & \dots & \longleftarrow & \mathbb{Z} 
\end{array}
$$

正则胞腔复形比一般胞腔复形更小，但比单纯复形更简单。通过引入正则胞腔复形的概念，讨论了胞腔复形的一致性和边界。

紧致豪斯多夫空间中的胞腔复形结构定义为将胞腔 `X` 分解为有限个互不相交胞腔 `{s_i^q|q ≥ 0, 1 ≤ i ≤ r_q; r_q ≥ 0}` 的并集，使得：

- 对于任意 `q` 维胞腔 `s_i^q`，存在一个连续映射 `φ_i^q: D^q → X`，它将 `D^q - S^{q-1}` 同胚映射到 `s_i^q`。
- `q` 维胞腔的边界 `\bar{s}_i^q: = \bar{s}_i^q - s_i^q` 中的每个点都属于维数小于 `q` 的胞腔。

`X` 的 `q` 维骨架 `X^q: = ∪_{k ≤ q} s_i^k` 是 `X` 中维数 `≤ q` 的胞腔的并集。它是 `X` 的闭子集。

如果 `A` 是 `X` 中某些胞腔的并集，则 `X` 的闭子集 `A` 称为 `X` 的子复形。这些胞腔自然地给出了 `A` 的胞腔细分 `A^q = A ∩ X^q`。

### 定义 14.12.
如果胞腔 `X` 上的复形结构满足比上述定义中 (1) 和 (2) 更强的条件，则称为正则：

- (1') 对于任意 `q` 维胞腔 `s_i^q`，存在 `φ_i': (D^q, S^{q-1}) → (\bar{s}_i^q, s_i^q)`；
- (2') 每个胞腔 `s_i^q` 的边界是 `X` 中胞腔的并集。换句话说，每个胞腔的边界是 `X` 的一个子复形。在本节中，我们只考虑正则胞腔复形。

单纯复形显然是正则胞腔，且可以证明任何正则胞腔复形都可以进一步分解为单纯复形。

进一步考虑胞腔链群，并假设正则胞腔复形 K 的每个胞腔 `s` 都有一个定向。显然，零维单纯形只有一种定向。如前所述，`q` 维胞腔链群 `C_q(K)` 是基于 `[s_i^q | 1 ≤ i ≤ r_q]` 的自由阿贝尔群，且边际同态 `∂: C_q(K) → C_{q-1}(K)` 基于关联矩阵 `([s_i^q : s_j^{q-1}]`。对于正则胞腔复形，这一点显而易见。

### 命题 14.3.
若 `s_i^q > s_j^{q-1}`，则 `[s_i^q : s_j^{q-1}] = ±1`；否则 `[s_i^q : s_j^{q-1}] = 0`。

细分映射 `Sd: K → SdK` 是一个胞腔映射。由其确定的胞腔链映射被称为细分链映射 `Sd#: C_*(K) → C_*(SdK)`。

### 命题 14.4.
K 的每个胞腔均已定向。设 `s^q` 为 K 的 q 维定向胞腔。则 `Sd#s^q = Σ_{[t^{-1},...,t^0][s^q: t^{q-1}]}...[t^1: t^0]s^qt^{q-1}...\tilde{t}^0`。

此公式是对所有胞腔序列 `t^{q-1}`, ..., `\tilde{t}^0` 进行求和。实际上，它仅得出满足条件 `s^q > t^{q-1} > ... t^0` 的胞腔序列 `t^{q-1} > ... t^0` 之和。否则，关联系数之积 `[s^q : t^{q-1}...]...[t^1: t^0] = 0`。当 q = 0 时，该公式应理解为 `Sd#s^0 = \tilde{s}^0`。

### 定义 14.13.
K 的每个胞腔均已定向。设 `s^q` 和 `s^{p+q}` 为 K 上的两个胞腔。定义 SdK 上的交系链：

`I(s^{q*}, s^{p+q}) = Σ_{t^{p+q+1},...,t^{q+1}}[s^{p+q} : t^{p+q-1}]...[t^{q+1}: s^q].\tilde{s}^{p+q}\tilde{t}^{p+q-1}...,\tilde{t}^{q-1}\tilde{s}q`。

求和是在 K 的所有处进行的，且满足所有胞腔序列 `\tilde{t}^{p+q-1} > ... t^{q-1}` 符合 `s^{p+q} > t^{p+q-1} > ..., t^{q+1} > s^q` 的条件。

我们现在引入交系链的边界。

### 推论 14.1.
交系链的边界 `∂ I(s^{q*}, s^{p+q}) = (-1)^p I(∂ s^{q*}, s^{p+q}) + I(s^{q*}, ∂ s^{p+q})`。因此，双线性对应 `I: C^q(K) × C_{p+q}(K) → C_p(SdK)` 确定了一个双线性对应 `I: H^q(K) × H_{p+q}(K) → H_p(SdK)`。可以证明，该边界公式是该命题和积（Cup product）边界公式的直接推论。根据上述理论，我们得到算法 14.9，即正则胞腔同调边界算法：

#### 算法 14.9: 正则胞腔同调边界

```
过程 正则胞腔同调边界

//输入: 定向胞腔 $s^{q*}$//

//输出: {0,1}// 

输入满足条件 `⟨ s^{q*}, t^q ⟩ = { 1, if  t^q = s^q ; 0, if  t^q ≠ s^q }` 的余链（cocochain）；

计算余环（cocycle） `Z^q(SdK)`；

计算余边界（coboundary）链 `B^q(SdK)`；

计算上同调（cohomology） `H^q(SdK)`；

结束过程 正则胞腔同调边界
```
