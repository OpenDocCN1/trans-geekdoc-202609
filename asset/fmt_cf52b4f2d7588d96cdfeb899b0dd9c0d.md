
因此，CNN 中的一层会有在三个维度（宽度、高度和深度）上排列的神经元。CNN 通常包含按不同顺序和数量堆叠的不同层类型，以产生最佳架构。这些层包括：

*   **卷积层**：包含多个滤波器，用于从图像数据中提取特征。
*   **池化层**：对数据执行下采样，以专注于最相关的模式。
*   **全连接层**：连接在网络末端，赋予网络对数据样本进行分类的能力。

最后，在大多数网络结构的末端，通常会添加一个 **Softmax 分类器** 以提供输出类别。

## 迁移学习

在深度学习中，模型定义和模型训练通常是一项繁重的任务。深度学习往往非常“贪婪”地需要数据。因此，对于初始模型训练，大型数据集至关重要——然而，解决这一问题的一种方法是利用一种称为**迁移学习**的技术。迁移学习使为一个任务训练的模型能够适应另一个任务，而无需完全重新训练原始模型。

传统机器学习算法通常使用在先前收集的训练数据上训练的统计模板对未来数据进行预测。自 1995 年以来，迁移学习研究吸引了越来越多的兴趣和关注，曾使用过许多名称，如“学会学习”、“知识迁移”、“归纳迁移”、“多任务学习”、“上下文敏感学习”、“基于知识的归纳偏置”以及“增量/累积学习”。目前，迁移学习方法似乎在视觉计算相关文献中无处不在。

## 深度学习中的迁移学习

正如深度学习领域已知的那样，使用迁移学习的原因是为了改进学习。这是通过利用源任务的知识来实现的。通常，很少有人倾向于从头构建和训练整个卷积神经网络，主要是因为不常见或不容易找到具有足够规模的、所需数据类型的数据集。同时，在大规模数据集（如 `ImageNet`）上训练 CNN，然后将该 CNN 用作感兴趣任务的初始化或固定特征提取器，这种做法更为常见。

## 分类方案

CNN 通常由一个包含许多层的分布式网络组成。这些层负责特征提取。最后一层是 Softmax，负责实际的分类。这赋予了 CNN 训练特征提取的独特能力，而不是将特征定义留给预先确定。从 CNN 不同层提取的这些特征也被用来训练单独的分类器，例如支持向量机 (`SVM`)、k 近邻 (`kNN`) 和随机森林 (`RF`) 以进行预测。

### 支持向量机 (SVM)

**支持向量机** (`SVM`) 是一种分类模型。该模型旨在找到具有最大“间隔”将数据分离为不同类别的超平面，即位于超平面两侧的最近点之间的距离被最大化。如果数据是可分的，在数据空间中放置超平面的问题就简化了。通常数据可能不可分，因此必须在数学上定义数据点落在超平面“错误”一侧的惩罚。令 `C` 定义超参数，它代表允许错误分类点的权重有多大。然后，较大的 `C` 会严重惩罚错误分类的点，同时鼓励更贴合训练数据的超平面。另一方面，较小的 `C` 允许更多的错误分类点，希望这能产生一个更具泛化能力的分类器。因此，参数 `C` 是克服 `SVM` 过拟合的主要工具，通常通过验证来确定。`SVM` 有三种核函数 `K`，它们将输入数据转换到另一个欧几里得空间。核函数可以是线性的、非线性的，也可以是高斯的（使用径向基函数）。

### k 近邻 (kNN)

**k 近邻** (`kNN`) 是一种相对简单的分类模型，它使用已知数据集对新数据进行分类。新数据点根据其 `k` 个最近邻中占多数的类别进行分类。其背后的思想很简单。例如，同一类别的点应该具有相似的特征。因此，同一类别点的特征应该彼此足够相似。因此，这些点应该“靠近”同一类别的其他点。这里的“邻近性”指的是特征空间中点的位置以及它们之间的距离。距离通常使用欧几里得距离来度量。当 `k` 值较高时，分类更能抵抗离群数据点的影响。因此 `k` 代表一个可用于有效验证的超参数。这些分类器简单直观。然而，它们往往难以扩展，因为分类需要为每个待考虑的新数据点重新访问所有数据点。此外，分类器必须拥有所有训练数据点的先验知识才能对新数据点进行分类。自然地，这导致需要大量内存来存储所有训练数据以及分类协议。

### 随机森林 (RF)

**随机森林** (`RF`) 是一种创建一组决策树的分类方法。这些树是从主训练集中随机选择的子集。然后它汇总来自不同决策树的投票来决定测试对象的最终类别。`RF` 是一种流行的集成方法。它使用装袋技术，该技术涉及通过从树的内部节点中排名最高的测试中选择和随机选择测试集来生成新的训练数据集。它需要很少的参数调整，并可用于自然地对特征重要性进行排序。`RF` 在大型数据集上运行高效，并报告准确的分类性能。这些特性使 `RF` 成为机器学习中流行的分类算法。

## 总结

与针对物理模型的显式编程不同，深度学习有助于生成计算系统，从数据中提取模式和知识。这与人类大脑识别和推断模式以进行复杂决策的方式非常相似。深度学习提供了一个计算框架，用于根据给定的一组输入数据获得所需的输出。

感知机是机器学习单元的简单形式。它可以非常高效地对复杂函数进行线性逼近。类似地，人工神经网络基于一组感知机，包含输入层、输出层和隐藏层，所有层通过权重、激活函数和偏置连接。人工神经网络可以帮助将非线性数学函数单元纳入系统，从而使用较小的特征集准确逼近输入数据。凭借其基于特征的输出，它可以协助图像分析任务，并已被证明在视觉计算应用中很有用。然而，传统的基于多感知机的人工神经网络的一个缺点是，对于人脸识别等复杂任务，特征参数的数量可能变得非常大，导致网络在计算上变得低效。

卷积神经网络目前是视觉计算应用的事实标准机器学习技术。这已被证明在许多领域都很有用，并在解决具有挑战性的任务中展现了其优势，例如赢得许多 `ImageNet` 竞赛。该网络是稀疏连接的，而不是全连接的，拥有相对较少的权重。凭借卷积和池化功能以及网络的松散连接性，它比传统的基于多感知机的网络具有优势。因此，它非常适合模式识别和匹配，因此已被证明非常擅长解决许多具有挑战性的视觉计算相关问题。

# 第 3 章：视觉计算的深度学习模型

深度学习旨在利用多层处理单元（神经元）来模拟和学习数据集中的复杂排列，以像人脑一样识别它们。深度学习算法通过操纵与神经元相关的参数以产生所需输出，利用一系列重复或多个人工神经元来学习非常复杂的数据。正如上一章所述，深度学习是一个具有多个隐藏层的神经网络。这可以与人类通过应用智能来解决复杂问题的思维方式相关联。同样，深度学习通过使用深层来找出给定分类问题的高效解决方案来实现这一点。

## 深度学习与卷积神经网络

深度学习在图像和视频分析、目标跟踪、人体动作识别、图像风格化和人脸识别等多个应用领域均获得了成功的认可。其当下的流行归功于计算能力的增强，如图形处理单元的出现、硬件成本的降低以及网络连接速度的提升。此外，深度学习的流行还得益于可用于训练和测试算法的海量数据。深度学习在视觉计算问题中取得主要成功，源于高效卷积神经网络的出现。基于此，近期已有大量预训练模型可供使用。

### 卷积神经网络

近年来，卷积神经网络（CNN）在视觉计算领域产生了重大影响。这归功于其利用非线性多层架构学习复杂特征的能力。尽管起源于 1990 年代初期，但由于假设基于梯度下降的特征提取将因相关优化问题目标函数中的局部极小值而总是过拟合，CNN 曾被研究界摒弃。然而，其在 2012 年 `ImageNet` 竞赛中的卓越成功改变了这种悲观看法。如今，最先进的深度模型被用于几乎所有视觉计算应用，包括但不限于检测、识别、分类和信息检索。

#### 监督学习与前馈网络

监督学习是机器学习最常见的形式之一。为理解该概念，请考虑构建一个将纸币分类为真钞或伪钞的系统这一问题。首先会收集大量图像数据集（真钞和假钞），然后在训练时，向机器展示一张照片及其类别，机器随后以两个分数的形式产生输出，每个类别一个分数。理想情况下，如果机器给目标类别打出最高分，则假定其输出良好。然而，我们几乎可以肯定机器在训练前无法产生此类输出。幸运的是，可以通过计算代价函数来跟踪机器在训练时的性能，该函数衡量机器输出与目标分数之间的差异（误差）。为减小误差，机器随即扰动其内部可调参数。通常这些参数被称为权重，它们定义了从输入到输出的映射。展示图像、估算分数、与目标比较并调整权重的这一训练过程会迭代进行，直到达到零误差或极小的可接受误差。一旦训练完成，机器的权重便具有了智能值，可用于将新的（未见过的）纸币图像以最小误差映射到某一类别。上述场景解释了前馈神经网络的基本工作原理。

#### 现成特征提取与迁移学习

有趣的是，研究表明 CNN 能高效学习通用视觉特征。因此，这些特征可直接配合简单分类器来解决视觉计算问题。这种被称为现成特征提取的方法，已被多位研究者用于在视觉计算任务中取得有希望的结果。研究者建议，与其从头训练 CNN，不如将迁移学习作为解决视觉计算任务的首选方法。同样，一些研究表明，对于图像数量较少的数据集，现成特征提取技术优于从头训练网络。

#### 网络架构与训练动态

正如上一章所讨论的，如图 3.1 所示的神经网络，只有经过训练才能执行分类纸币这一认知任务。在图 3.1 的示例中，网络有 2 个输入、2 个包含 4 个神经元的隐藏层和 2 个输出，因此它有 (2² × 2² × 2²) = 12 个连接。因此，每个连接都有一个权重。正如上述示例所述，训练涉及基于输出误差对权重进行迭代微调。显然，第 `l` 层的每个神经元都连接到第 `l` – 1 层每个神经元的输出。这当然是全连接神经网络（NN）的关键属性，因为一层的输出成为下一层的输入，所以称为前馈 NN。传入输入并获得预测输出称为前向传播。这涉及计算每个隐藏层神经元的总净输入，将结果通过非线性（激活）函数，然后对下一层神经元重复该过程。

#### 激活函数与反向传播

CNN 中使用过各种激活函数。如今，线性修正单元（`ReLU`）是最流行的激活函数，它只是一个简单的阶跃函数 `f(z) = max(z,0)`。在反向传播过程中，权重被调整以最小化误差。这是通过一种称为反向传播的技术实现的。该过程通过反向计算，得出误差关于权重的偏导数。该计算指示了由于权重发生微小变化而导致误差减小的幅度。随后，权重沿计算梯度的相反方向进行调整。调整权重后，输出误差发生变化，因此在下一次迭代前，必须重新计算偏导数。由于神经网络涉及大量参数，算法往往会过拟合——一种模型在训练数据集上表现极佳（分类误差最小），却无法在新的未见数据集上泛化的现象。避免过拟合的方法包括使用大规模训练数据集、在验证集性能开始变差时立即停止训练、正则化和 `Dropout`。

#### CNN 的数学公式

就像前馈神经网络一样，CNN 可以定义为由一系列更简单的函数 `p` 组成的函数 `q`，使得

```
q = p[l]∘p[l−1]∘⋯∘p[1], (3.1)
```

其中每个函数 `p` 定义了前一层输入 `x[l−1]` 到其输出 `x[l]` 的映射，表示为

```
x[l] = f(Σw[l]x[l−1] + b), (3.2)
```

其中 `f` 为激活函数，`w[l]` 为权重，`b` 为偏置。

#### CNN 架构原则

因此，卷积神经网络（CNN）是一种考虑输入数据空间结构的人工神经网络。为确保平移和扭曲不变性，CNN 结合了三个架构思想——共享权重、局部感受野和空间或时间亚采样。权重共享是指在空间中应用重复的（共享）神经元瓦片的过程。这导致待优化参数减少，从而提高学习效率。由于将神经元连接到上一层所有神经元不切实际，尤其是在大维度数据（如图像）中，局部感受野确保神经元仅连接到输入体积中的局部区域。亚采样和局部平均通过降低特征图分辨率来提高算法效率，从而降低输出对平移和扭曲的敏感性。总体而言，CNN 呈现 3D 结构张量形状，具有 W × H × D 维度，其中 W（宽度）和 H（高度）为空间维度，D 为特征维度。具体而言，CNN 的结构使其最适合图像、语音和时间序列任务。更具体地说，该算法因用于将权重应用于输入的卷积运算而得名。

### CNN 最早于 20 世纪 90 年代被发现

然而，遗憾的是，尽管它们在文档识别方面取得了突破，但由于人们假设神经网络将始终过拟合或陷入局部极小值，研究人员便弃之不顾。然而，研究表明，优化问题搜索空间中局部极小值的存在并不一定是个大问题。当局部极小值仅是微弱非最优时，性能差异仅受轻微影响。此外，避免局部极小值的一种常规方法是扰动算法的稳定性，使其突然跳出局部最优。通过逐渐并重复地增加和减小学习率来改变学习率，会降低算法的稳定性，从而赋予算法跳出局部最优的能力。此外，随机梯度下降（`SGD`）优化算法也引入了某种噪声或随机性，这有助于算法从局部极小值中跳出。从本质上讲，当今 CNN 与 90 年代 CNN 之间显著的差异包括：极大规模数据集（如 `ImageNet`）的可用性，`GPU` 并行处理能力带来的更快计算速度，训练开始时初始化权重的先进技术，以及用于区分激活函数的简单易用方法。

### CNN 的架构

典型 CNN 的结构由多层组成，这些层大致分为三类。它们分别是卷积层（`CONV`）、下采样层（`POOL`）和全连接层（`FC`）。此外，激活函数在架构中也可被视为一层。通常，上述层的组合会以特定方式排列，其唯一目标是将网络的输入转换为一种能够产生输出的有用表示。

#### 卷积层

这是 CNN 的基本构建模块。如前所述，其名称源于数学（卷积）算子。该层计算神经元权重与输入体积一小区域之间的标量积。神经元排列成二维滤波器/核的堆栈，延伸至输入体积的深度。因此它们是三维结构的。在前向传播期间，每个核在输入体积的宽度和高度上进行卷积，以生成二维特征图，如图 3.2 所示。因此，这些特征图是每个空间位置卷积操作的输出。与前馈神经网络相比，此处滤波器代表神经元，当它们遇到边缘等视觉特征时会被激活。正如之前讨论的，CNN 使用局部连接来降低复杂度。因此，每个神经元连接到一个局部区域，其空间维度由称为感受野的滤波器大小定义，且其深度始终等于输入体积的深度。

![图 3.2 卷积操作示例。](img/fig3_2_B.jpg)

图 3.2 卷积操作示例。

因此，对于 `256 × 256 × 3` 的输入图像，如果感受野为 `3 × 3`，则 `CONV` 层中的每个神经元将共有 `3 × 3 × 3 = 27` 个连接和 1 个偏置参数。显然，连接在空间上是局部的，但在输入深度方向上是全连接的。随后，特征图（即输出）的大小通过三个超参数计算得出——深度、零填充和步幅。深度指部署的滤波器数量。滤波器越多，检索到的信息越多，因为每个滤波器都学会寻找特定特征。步幅定义了滤波器在输入上滑动的模式，`S = 1` 意味着滤波器每次沿输入移动一个像素。零填充定义了围绕输入体积放置的零像素数量，以保持输出体积的空间大小。可以使用以下公式计算输出的空间大小：

```
O = { (I - F + 2P) / S } + 1, (3.3)
```

其中 `I` 是输入的空间大小，`F` 是滤波器大小，`P` 是零填充数，`S` 是步幅。因此，如果应用于大小为 `[224 × 224 × 3]` 的输入图像，并假设神经元的感受野大小为 `3 × 3`，深度 `K = 64`，步幅 `S = 1`，零填充 `P=1`，则得到 `(224 - 3 + 2) / 1 + 1 = 224.` 这意味着该特定 `CONV` 层的输出体积大小为 `[224 × 224 × 64]`。因此，将有 `224 × 224 × 64 = 3211264` 个神经元，每个神经元具有 `3 × 3 × 3 = 27` 个权重和 1 个偏置。有趣的是，与其拥有 `3211264 × 27` 个权重和 `3211264` 个偏置，权重共享的概念使得同一切片上的所有神经元共享相同的权重和偏置。因此，权重和偏置的数量大幅减少至 1728 和 64。

#### 激活函数

如前所述，在神经网络中，激活函数在向神经元输出引入非线性方面起着重要作用。引入这种非线性使神经网络成为通用函数逼近器，从而赋予其理解各种关系类型的能力。CNN 最有效且最常用的激活函数是线性修正单元（`ReLU`）。这涉及零阈值函数的逐元素应用，`f(x) = max(o, x)`，其中 `x` 是神经元的输入。与其他激活函数相比，使用 `ReLU` 的 CNN 训练速度快数倍。激活层不会给其输入引入额外参数。此外，它不会改变输入的维度。在架构中，激活层放在每个 `CONV` 层之后。此外，拥有多个 `FC` 层的网络也会部署它，最后一个全连接层除外。

#### 池化层

池化层通常插入在连续的 `CONV` 层之间。其主要功能是持续减少参数数量，并通过减小特征图的空间大小来降低网络的计算复杂度。因此，它们汇总相邻神经元的输出。对于特征图的每个二维切片，最常见的池化操作类型称为 `MAX-POOLING`，通常取每个 `2 × 2` 区域的最大值，从而丢弃 75% 的激活值，如图 3.3 所示。

因此，池化操作不引入新参数。相反，它导致特征图的第一和第二维度收缩。该操作接受两个参数：步幅 `S` 和空间维度 `F`。因此，池化操作将特征图从 `W[1] × H[1] × D` 降维至 `W[2] × H[2] × D` 维度。此处 `W[2]` 和 `H[2]` 通过以下公式计算：

```
W_2 = (W_1 - F) / S + 1, H_2 = (H_1 - F) / S + 1. (3.4)
```

有趣的是，该操作引入了相对于弹性畸变的平移不变性。

#### 全连接层

全连接层拥有与前一层激活值全连接的神经元，与 `CONV` 和 `POOL` 层不同，`FC` 具有二维维度。它们通常被配置为输出网络的预测标签/类别。因此 `FC` 通常是网络的最后一层。在赢得 2012 年 ImageNet 大规模视觉识别挑战赛（`ILSVRC`）的工作中，使用了 3 个 `FC` 层，从那时起这已成为大多数研究人员的经验法则。直观地讲，在计算结束时展平三维特征图，为我们解释学习到的空间不变特征提供了途径。
