
*   关于复杂度，RVM 的算法步骤涉及海森矩阵的求逆，其复杂度达 `O(N³)`。正如第 11.11 节所讨论的，求解 SVM 的高效方案的复杂度范围从线性扩展到（近似）二次。此外，RVM 的内存需求对训练集规模呈 `O(N²)` 依赖，而 SVM 则呈线性依赖。除了复杂度外，求逆（大）矩阵必须谨慎进行，以避免因可能的（近）奇异性导致的数值不稳定。而且，总体而言，对于相似的误差率，RVM 收敛所需的训练时间比 SVM 更长。

*   [89] 开发了一种快速 RVM 算法，通过分析边际似然的性质。这使得候选基函数（`Φ` 的列）能够按顺序添加和删除，以单调地最大化边际似然。该迭代算法以构造方式运行，直到所有相关基函数（其关联权重非零）均被包含在内。若 `M` 表示相关项的数量，复杂度达 `O(M³)`，当 `M << N` 时，比原始 RVM 更高效。

*   RVM 的主要优势在于，在相似的泛化误差水平下，它们通常比 SVM 产生更稀疏的解。这使得训练完成后的预测步骤比由 SVM 产生的预测模型更高效。此外，SVM 受制于用户相关的超参数 `C`（回归中的 `ϵ`），通常通过交叉验证寻找，这涉及针对不同值的多次训练。

*   在 [8] 中，采用了一种基于*变分界近似*方法的不同算法途径，将在接下来进行描述。

## 13.8 凸对偶与变分界

在上一章中，介绍了用高斯分布近似一般 PDF 的拉普拉斯技术。此类近似的驱动力在于利用高斯 PDF 计算友好的特性。在本节中，我们将从另一个视角处理该任务，即通过引入一个额外参数来最大化手头 PDF 的下界，该参数被引入问题中，且下界依赖于它。我们的理论框架是凸对偶，这是凸分析中一个著名且强有力的工具。

设函数 `f : ℝ^(l) ↦ ℝ`。函数

`f* : ℝ^(l) ↦ ℝ`，

定义如下^(⁹⁴)

$$f^{\ast}(\mathbf{\xi}) = \max\limits_{\mathbf{x}}\left\{ \mathbf{\xi}^{T}\mathbf{x} - f(\mathbf{x}) \right\},$$

称为 `f` 的 *共轭*。共轭函数的定义域由所有使最大值有限的 $\mathbf{\xi} \in \mathbb{R}^{(l)}$ 组成。共轭函数的一个显著性质是其 *凸性*；无论 `f` 是否为凸函数，此性质均成立。这种凸性是一族（关于 $\mathbf{\xi}$ 为凸的）仿射函数逐点最大化的结果 [12]。

对公式 (13.78) 关于 $\mathbf{x}$ 进行最大化，得到 $\mathbf{x}^{\ast}$ 的值，使得

$$\mathbf{x}^{\ast} : \nabla f(\mathbf{x}^{\ast}) = \mathbf{\xi}, \tag{13.79}$$

进而得到值

$$f^{\ast}(\mathbf{\xi}) = \mathbf{\xi}^{T}\mathbf{x}^{\ast} - f(\mathbf{x}^{\ast}). \tag{13.80}$$

公式 (13.79) 和 (13.80) 给出了共轭函数的几何解释。线性函数 $\mathbf{\xi}^{T}\mathbf{x}$ 的图像定义了一个超平面，其方向由 $\mathbf{\xi}$ 控制；后者现在等于 $\nabla f(\mathbf{x}^{\ast})$，这定义了 $f(\mathbf{x})$ 的图像在 $\mathbf{x}^{\ast}$ 处的切超平面的方向。该切超平面可描述为

$$g(\mathbf{x}) = f(\mathbf{x}^{\ast}) + (\mathbf{x} - \mathbf{x}^{\ast})^{T}\nabla f(\mathbf{x}^{\ast}),$$

或利用公式 (13.80)，

$$g(\mathbf{x}) = \mathbf{\xi}^{T}\mathbf{x} - f^{\ast}(\mathbf{\xi}). \tag{13.81}$$

对于 **x** = 0，公式 (13.81) 变为 `g(0) = −f*(ξ)`。这在 图 13.10 中有所说明。因此，`f*(ξ)` 对应于 `ξ^(T)x` 的图形为了与 `f(x)` 的图形“相切”所必须经历的位移。这一切的一个副产品对我们来说非常有用。可以证明（问题 13.16），如果 `f` 是凸函数，则 `(f*)* = f`，在这种情况下我们可以写成

```
f(\mathbf{x}) = \max\limits_{\mathbf{\xi}}\left\{ \mathbf{x}^{T}\mathbf{\xi} - f^{\ast}(\mathbf{\xi}) \right\}。
```

因此，一旦计算出 `f*`，*f* 的一个下界就随时可得，即

`f(x) ≥ x^(T)ξ − f*(ξ)`，

其中 `ξ` 现在被解释为一个参数。为了进一步研究这个界，我们将公式 (13.79) 和 (13.80) 代入公式 (13.83) 以得到^(⁹⁵)

`f(x) ≥ f(x*) + (x − x*)^(T)∇f(x*)`，

其中右边是描述在 `x*` 处与 `f(x)` 相切的超平面的线性函数 `g(x)`。当 `x = x*` 时该界变得紧致（见 图 13.10）。我们很快就会看到如何使这个线性函数成为非线性函数的一个界；只需变换函数的自变量即可。

![图 13.10 穿过原点的直线 y = ξx 的方向由 ξ 控制（ξ = tan α）。共轭函数 f⁎ 在 ξ 处的（负）值定义了直线 y = g(x) 与垂直轴的交点；g(x) 由 ξx 平移而成，直到它在 x⁎ 处与 f 相切。](img/gr010.jpg)

图 13.10 穿过原点的直线 `y = ξx` 的方向由 `ξ` 控制（`ξ = tan α`）。共轭函数 `f*` 在 `ξ` 处的（负）值定义了直线 `y = g(x)` 与垂直轴的交点；`g(x)` 由 `ξx` 平移而来，直到它在 `x*` 处与 `f` 相切。

如果将公式 (13.78) 和 (13.82) 中的 max 运算替换为 min 运算，则针对凸函数所述的一切均适用于凹函数。请注意，根据此定义，共轭函数是*凹*的，因为它是一组凹函数逐点最小化的结果（仿射函数可视为凸或凹）。此外，如果涉及的函数既非凸也非凹，则可以寻找使其变为凸或凹的*可逆*变换。

在我们的语境中，引入共轭函数的概念是因为我们期望这种函数（如公式 (13.83) 那样为概率密度函数提供界限）可能会导致一种函数形式，从而使所涉及的积分计算变得易于处理。

### 示例 13.3

计算对数函数 `f(x) = ln x, x > 0` 的共轭。

对数函数已知是凹函数。因此

```
f*(ξ) = min_{x > 0} { ξx - ln x },
```

或

```
x*: 1/x = ξ ⇒ x* = 1/ξ.
```

因此，

`f*(ξ) = 1 + ln ξ`。

所以，

```
ln x = min_{ξ > 0} { ξx - 1 - ln ξ }.
```

### 示例 13.4

考虑单变量拉普拉斯概率密度函数，我们已在 13.5 节 中见过，

#### 推导共轭函数下界

拉普拉斯先验分布定义为：

$$

p(\theta) = \frac{\lambda}{2}\exp\left( - \lambda|\theta| \right),\quad\theta \in \mathbb{R}.

$$

![Equation](img/si320.png)(13.84)

我们的目标是用其共轭函数推导一个下界。从公式 (13.84) 可得：

$$

\ln p(\theta) = \ln\frac{\lambda}{2} - \lambda|\theta|.

$$

![Equation](img/si321.png)

定义函数 `f(x)` 为：

$$

f(x) = \ln\frac{\lambda}{2} - \lambda\sqrt{x},\quad x > 0.

$$

![Equation](img/si322.png)(13.85)

则有：

$$

\ln p(\theta) = f(\theta^2).

$$

![Equation](img/si323.png)(13.86)

注意 `f(x)` 是关于 `x` 的凸函数（习题 13.17）。`f(x)` 的共轭函数推导如下（注脚 ⁹⁶）：

$$

f^{\ast}(\xi) = \max_{x}\left\{ - \frac{\xi}{2}x - f(x) \right\},\ \xi > 0.

$$

![Equation](img/si329.png)(13.87)

参数 `ξ` 约束为正值，因为当 `ξ ≤ 0` 时，关于 `x` 的最大值变为无穷大，这违背了共轭函数的定义。回顾公式 (13.85)，最大化过程得出：

$$

x_{\ast}:\lambda x^{- \frac{1}{2}} = \xi\Rightarrow x_{\ast} = \lambda^{2}\xi^{- 2}.

$$

![Equation](img/si331.png)(13.88)

结合公式 (13.87) 和 (13.88) 得到：

$$

f^{\ast}(\xi) = \frac{\lambda^{2}}{2}\xi^{- 1} - \ln\frac{\lambda}{2}.

$$

![Equation](img/si332.png)(13.89)

因此，我们得到该下界：

##### 数学推导与近似

$f(x) \geqslant - \frac{\xi}{2}x - \frac{\lambda^{2}}{2}\xi^{- 1} + \ln\frac{\lambda}{2}$

![Equation](img/si333.png)

或

$\ln p(\theta) \geqslant - \frac{\xi}{2}\theta^{2} - \frac{\lambda^{2}}{2}\xi^{- 1} + \ln\frac{\lambda}{2},\quad\xi > 0.$

![Equation](img/si334.png)

因为这对 `∀ξ > 0` 皆成立，我们可以用 `ξ^{-1}` 替换 `ξ`，以便于符号表示，从而得到

$$p(\theta) \geqslant \frac{\lambda}{2}\exp\left( - \frac{\xi^{- 1}}{2}\theta^{2} \right)\exp\left( - \frac{\lambda^{2}}{2}\xi \right),\tag{13.90}$$

![Equation](img/si337.png)

利用高斯符号及其积分性质后，可重写为

$p(\theta) \geq \mathcal{N}(\theta|0, \xi)\phi(\xi),\quad \xi > 0,\tag{13.91}$

![Equation](img/si338.png)

其中

$$\phi(\xi) = \frac{\lambda}{2}\sqrt{2\pi\xi}\exp\left( - \frac{\lambda^{2}}{2}\xi \right),\quad \xi > 0.$$

![Equation](img/si339.png)

这确实非常有趣。所得下界对 `θ` 的函数依赖呈高斯性质；该高斯项以零为中心，方差为 `ξ`。关于 `ξ` 进行最大化，将得到所需的近似。**图 13.12** 展示了不同 `ξ` 值下的近似结果。观察可知，对涉及变量引入变换，可使所得界中的函数变为*非线性*函数。

![Figure 13.12 The Laplacian (red curves) and the approximating Gaussians for two different values of ξ.](img/gr012.jpg)

**图 13.12** 拉普拉斯分布（红色曲线）及两个不同 `ξ` 值下的近似高斯分布。

对于多元拉普拉斯分布，假设参数向量具有独立分量，可以平凡地证明

##### 数学公式

$$

p(\mathbf{\theta}) = \prod\limits_{k = 0}^{K - 1}p(\theta_{k}) \geqslant \mathcal{N}(\mathbf{\theta}|0,\Xi)\prod\limits_{k = 0}^{K - 1}\phi(\xi_{k}): = \widehat{p}(\mathbf{\theta};\mathbf{\xi}),

$$

其中 $\boldsymbol{\xi} = [\xi_0, \dots, \xi_{K-1}]^T$ 且

$$

\Xi := \text{diag}\{\xi_0, \xi_1, \dots, \xi_{K-1}\}.

$$

##### 备注 13.3

*   通过优化其共轭（对偶形式）的下界来表示凸函数的方法称为**变分法**，相关参数 `ξ_k` 称为**变分参数** [69]。其在机器学习背景下的应用最早见于文献 [31]（另见 [35]），随后得到广泛推广并应用于不同场景。

*   该方法已用于获得多种适合稀疏感知学习的 PDF 的变分近似，例如 Jeffreys 先验、Student's `t` 分布、广义高斯分布（见如 [61]）和逻辑回归模型 [33]（问题 [13.18]）。与拉普拉斯近似法相比，变分方法提供了针对相应变分参数进行优化的额外灵活性（见 [33] 相关讨论）。但读者需注意，这两种近似并不总是好的。这从 [图 13.12] 可明显看出。可能局部获得良好近似，但非全局。然而实践表明，在贝叶斯学习背景下，先验的不良近似（此类近似用于此处）不一定导致后验的不良近似。这无法保证，只有实际性能才能最终裁决。

## 13.9 稀疏感知回归：变分界贝叶斯路径

本节旨在演示如何利用凸对偶性及相应的变分界，在相应积分计算上难以处理的情况下，近似证据函数的计算。我们选择在稀疏感知学习框架下描述该方法；这也有助于我们与第 9 章建立联系。

为符合第 9 章的假设，且不失一般性，假设涉及数据均值为零。若非，可通过减去各自的样本均值来中心化训练数据；因此设 `θ_0 = 0` 并假设参数数量为 `K`。此时回归模型变为

$$

\mathbf{y} = \mathbf{\Phi}\boldsymbol{\theta} + \boldsymbol{\eta},\quad \boldsymbol{\eta}, \mathbf{y} \in \mathbb{R}^N,\ \boldsymbol{\theta} \in \mathbb{R}^K,\ K > N.

$$

我们得知“秘密”在于 **θ** 的大多数分量（几乎）为零。在第 13.5 节中，我们评论了高斯先验在为稀疏随机向量提供合理统计描述方面的不足。一种在稀疏建模中广受欢迎的重尾分布是拉普拉斯分布。毕竟，为 **θ** 采用拉普拉斯先验，即

```
p(θ) = ∏_{k=1}^K p(θ_k) = ∏_{k=1}^K (λ/2) exp(-λ|θ_k|)
```

并结合如公式 (13.22) 所示的观测值 **y** 的高斯条件 PDF `p(y|θ)`，使得 MAP 估计与我们熟悉的 LASSO 任务（第 9 章讨论过）完全相同。基于此，我们将围绕拉普拉斯 PDF 来构建本节内容。图 13.13A 显示了不同 `λ` 值下的拉普拉斯分布。在 图 13.13B 中提供了二维图，从中可以明显看出该 PDF 尊重稀疏解，这表现为其沿两个轴的衰减较慢。

![Figure 13.13 (A) The one-dimensional Laplacian for different values of λ. (B) A plot of a two-dimensional Laplacian PDF.](img/gr013.jpg)

图 13.13 (A) 不同 `λ` 值下的一维拉普拉斯分布。(B) 二维拉普拉斯 PDF 图。

拉普拉斯 PDF 的问题在于，它在公式 (12.14) 中的存在使得积分的计算在计算上变得难以处理。此外，回顾第 12.8 节，拉普拉斯 PDF 不属于计算上极具吸引力的指数族分布。为了便于处理，我们将采用变分界近似方法，按照公式 (13.90) 和 (13.92) 用高斯分布来近似拉普拉斯分布。变分参数将通过 EM 算法最大化相应证据来确定。这种恢复稀疏解的方法最早是在文献 [21] 中针对字典学习背景引入的。

为简化起见，设我们回归模型中的噪声序列为方差为 `σ_η² := 1/β` 的白噪声。则

```
p(y|θ; β) = N(y|Φθ, β^(-1)I)
```

并利用公式 (13.92)，我们可以写成

##### 数学推导

$$
