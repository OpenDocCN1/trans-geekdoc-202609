
# 定义 17.26
向量丛 `E` 的截面 `S` 是从底流形 `M` 到总空间 `E` 的一一对应连续截面 `s`：

```
S : M → E, x → s(x) .
```

还要求该一一对应截面是纤维保持的截面，即满足

```
π · S = id_M .
```

在点 `P ∈ M` 的邻域 `U` 中取局部坐标系时，截面 `S` 表示为

```
S: U → π^{-1}(U) = U × F
x → s(x) = (x; ξ^1(x), …, ξ^k(x)) .
```

在底流形 `M` 的每一点 `x ∈ U`，对应于纤维 `F_x` 上的向量 `ξ(x)`，向量截面等同于 `M` 上的一个 `k` 维向量值函数。

进一步分析由向量丛 `E` 的截面组成的空间 `Γ(E)`。

```
Γ(E) = {s, s 是向量丛 E 的截面} .
```

向量丛的纤维是一个 `k` 维向量空间。可以利用纤维的向量空间结构来定义截面集合 `Γ(E)` 的向量空间结构。`Γ(E)` 中任意两个局部截面 `ξ(x)` 和 `η(x)` 可以相加

```
ξ(x) + η(x) = [ξ + η](x) .
```

逐点向量可以相加。截面也可以逐点乘以数，截面 `ξ(x)` 可以乘以底流形上的函数 `f(x)`

```
f(x)ξ(x) = [fξ](x) .
```

那么，向量总空间集合 `Γ(E)` 本身构成一个向量空间。向量丛 `E` 是局部平凡的，即在 `π^{-1}(U)` 中有 `k` 个线性无关的光滑截面。其他光滑截面可以表示为这些 `k` 个光滑截面的线性组合，其系数是底流形上的光滑函数。因此，`Γ(E)` 是一个秩为 `k` 的 `F`-模。在 `M` 中每一点 `x` 的邻域 `U` 中，可以找到 `π^{-1}(U)` 上每条纤维 `F_x` 上的基向量 `{e_a(x)}_1^k`，称为活动标架。每个截面 `ξ(x)` 都可以用活动标架展开。

```
ξ(x) = Σ_{a=1}^{k} ξ^a(x)e_a(x) .
```

向量丛截面 `ξ(x)` 也可以称为底流形上的 `k` 维秩场。

当纤维的基向量变换时，活动标架也变换。变换矩阵为 `g ∈ GL(k, R)`。在变换群 `G = GL(k, R)` 的作用下，纤维 `k` 维向量空间 的原点 `O` 保持不变，零点是向量丛纤维的一个特殊点，称为向量丛的零截面。秩为 `K` 的向量丛 `E` 是局部平凡的，即底流形上的任意开邻域 `U` 上，我们通常选择 `k` 个处处非值的线性无关光滑截面作为活动标架，任意光滑截面通常可以表示为 `1.1`，即作为系数为截面函数的 `k` 个截面的线性组合。然而，向量丛 `E` 的非零光滑截面不一定存在。下面给出一个例子。

## 例 17.2
量子力学中带电粒子的薛定谔波函数 `ψ(x, y, z)` 是底空间 `R^3` 上的复线丛截面。在分析磁单极子周围的带电粒子时，磁单极子的位置是磁场强度的奇点。单极子周围的电磁场是一个拓扑非平凡对称场。有必要在底空间 `R^3 - {O}` 中分析粒子波函数 `ψ(x, y, z)`。这里，必须引入两个开邻域

```
U_+ = {(x, y, z) ∈ R^3 - {O}, z > -ε},   U_- = {(x, y, z) ∈ R^3 - {O}, z < +ε} .
```

在每个开邻域中，复线丛是平凡的。设 `ψ_+` 为相应邻域中复线丛的截面。在两个邻域的重叠区域，`U_+ ∩ U_-` 同伦等价于 `R^2 - {O}`。在重叠区域上的两个波函数之间需要一个转移函数（复相位因子）联络

```
ψ_+ = e^{inφ} ψ_-,   (φ 是方位角) .
```

为了规范变换，这个转移函数是 `e^{inφ} ∈ U(1)`。当 `n ≠ 0` 时，整个复线丛是一个非平凡的扭转丛。因为带电粒子波函数应该是单值连续函数，所以 `n` 应该是一个整数。为了对向量丛的截面，即流形上的向量场进行微分，必须在向量丛上引入‘联络’结构。联络的概念是黎曼几何发展历史中的一个核心概念，也是微分几何在各种数学分支和理论物理中的应用中的核心概念。

向量丛上的联络已成为现代微分几何最重要的基本概念之一，其应用范围非常广泛。联络的概念可以推广到任意向量丛，而光滑流形上的联络正是该流形切丛的联络。向量丛上的联络为向量丛任意光滑截面的微积分提供了手段；同时，平行移动的概念也可以移植到向量丛中。

在纤维丛理论中，局部地，联络由一组基本微分表达式给出。设 `U` 是流形 `M` 上的局部邻域，局部坐标为 `u^i, 1 ≤ i ≤ m`。假设在 `E` 的邻域 `U` 上有 `q` 个光滑截面 `s_α` `1 ≤ α ≤ q`，使得它们处处线性无关。这样的 `q` 个截面称为 `E` 在 `U` 上的局部标架场。显然，在每一点 `p ∈ U`，`{du^i ⊗ s_α, 1 ≤ i ≤ m, 1 ≤ α ≤ q}` 构成张量空间 `T_p^* ⊗ F_p` 的基。`D s_α` 是...的局部截面

邻域 `U` 上的丛 `T^*(M) ⊗ F`，因此可以排序为

```
D s_α = Σ_{1 ≤ i ≤ m \\ 1 ≤ β ≤ q} Γ_{α i}^{β} du^i ⊗ s_β
```

其中 `Γ_{α i}^{β}` 是 `U` 上的光滑函数。

注意

```
ω_α^β = Σ_{1 ≤ i ≤ m} Γ_{α i}^{β} du^i .
```

那么，

```
D s_α = Σ_{β=1}^{q} ω_α^β ⊗ s_β .   (17.15)
```

此外，引入矩阵记法以简化计算。我们用 `S` 表示局部标架场的列矩阵，用 `ω` 表示由 `ω_α^β` 组成的矩阵，即

```
S = [s_1 \\ ⋮ \\ s_q] ,   ω = [ω_1^1 … ω_1^q \\ ⋮ ⋱ ⋮ \\ ω_q^1 … ω_q^q] ,
```

那么，`17.15` 可以记为 `DS = ω ⊗ S`。矩阵 `ω` 称为联络矩阵，它取决于局部标架场的选择。

```
A = [a_1^1 … a_1^q \\ ⋮ ⋱ ⋮ \\ a_q^1 … a_q^q] .
```

在此，`det A ≠ 0`。

设联络 `D` 使得局部标架场 `S'` 的联络为 `ω'`。那么，根据联络条件，我们得到

```
D S' = d A ⊗ S + A · D S
     = (d A + A · ω) ⊗ S
     = (d A · A^{-1} + A · ω · A^{-1}) ⊗ S'
```

因此，

```
ω' = d A · A^{-1} + A · ω · A^{-1}   (17.16)
```

## 定理 17.8
在任何向量丛上，联络总是存在的。

证明。取 `M` 的一个坐标覆盖 `{U_a}`。根据向量丛的局部平凡结构，可以假设每个 `U_a` 都有一个局部标架场 `S_a`。根据联络的局部结构，需要在每个 `U_α` 上构造一个 `q × q` 矩阵 `ω_α`，使得当局部标架场改变时，它们可以适应变换律。这就完成了证明。在联络计算中，我们需要在 `E` 的邻域 `U` 上取 `q` 个光滑截面 `s_α` `1 ≤ α ≤ q`，使得它们在每处都线性无关。这 `q` 个截面称为 `E` 在 `U` 上的局部标架场。在具体计算中，计算每个邻域的主成分，局部标架场可以看作是在 `E` 上取 `q` 个截面。□
