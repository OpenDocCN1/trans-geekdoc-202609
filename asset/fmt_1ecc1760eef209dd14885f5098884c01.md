
`Pharming`（钓网）是一种伪装攻击，威胁行为者将受害者从有效的网站或资源重定向到恶意网站，该网站可以被伪装成用户面前的有效站点。`Pharming` 可以通过修改受害者系统上的`host file`、通过`DNS poisoning`（DNS 投毒）或利用`DNS server`中的漏洞来实现。图 4-1 展示了 `pharming` 的工作原理。

![图 4-1 Pharming 示例](img/04fig01.jpg)

**图 4-1** Pharming 示例

图 4-1 中展示了以下步骤：

**步骤 1**。用户（Omar）访问一个合法的网站并点击一个合法的链接。

**步骤 2**。Omar 的系统被破坏，`host file`被修改，Omar 被重定向到一个看似合法的恶意网站。（这也可以通过破坏`DNS server`或伪造`DNS reply`（DNS 回复）来实现。）

**步骤 3**。恶意软件被下载并安装到 Omar 的系统中。

**提示**

为了帮助防止 `pharming` 攻击，保持软件更新并定期运行反病毒检查非常重要。你还应该更改网络基础设施设备（包括你的家用路由器）中的默认密码。当然，你还需要注意你访问的网站，并在打开邮件时保持小心。

与 `pharming` 类似的攻击被称为`malvertising`（恶意广告）。`malvertising` 涉及在受信任的网站上嵌入恶意广告。点击这些广告的用户无意中会被重定向到托管恶意软件的网站。

## 社会工程学攻击

社会工程学攻击利用组织中最薄弱的环节，即人类用户。如果攻击者能让用户泄露信息，那么攻击者造成伤害比使用任何其他侦察方法容易得多。社会工程学可以通过电子邮件或网页误导以及提示用户点击某些导致攻击者获取信息的链接来实现。社会工程学也可以由内部人员或外部实体通过电话或面对面进行。

一个主要的例子是攻击者利用普通用户行为。假设你是公司中负责防火墙和其他安全设备的安全专业人员。攻击者可以发布一个薪水丰厚的职位，并对你（受害者）极具吸引力。你决定申请。随后，犯罪分子（攻击者）与你安排了面试。由于你可能会“展示”你的技能，攻击者可能会让你解释你是如何配置防火墙的。这会让攻击者无需进行任何类型的扫描或侦察就能获得有关组织的知识。

### 网络钓鱼

通过`phishing`（网络钓鱼），攻击者向用户展示看似有效、受信任的链接或附件。当用户点击时，会被提示披露机密信息，如用户名和密码。示例 4-1 显示了钓鱼邮件的示例。

### 鱼叉式钓鱼

`鱼叉式钓鱼` 是一种以非常特定的方式构建、并直接针对特定个人群体或公司的钓鱼尝试。攻击者会研究受害者及其所属组织，以便使电子邮件看起来真实，并可能让它们看起来像是来自公司内部受信任的用户。`示例 4-2` 展示了鱼叉式钓鱼邮件的示例。

### 鲸钓鱼

`鲸钓鱼` 与钓鱼和鱼叉式钓鱼类似，是一种针对公司高层和关键人物的攻击。与实施鱼叉式钓鱼攻击的威胁者一样，实施鲸钓鱼攻击的威胁者也会创建电子邮件和网页来传播恶意软件或收集敏感信息；然而，鲸钓鱼攻击者的邮件和网页具有更正式或更严肃的感觉。鲸钓鱼邮件的设计看起来像关键业务邮件，或来自公司内外具有合法权限的人的邮件。在鲸钓鱼攻击中，网页被设计为专门针对高知名度受害者。在普通的钓鱼攻击中，邮件可能是来自银行或服务提供者的虚假警告。在鲸钓鱼攻击中，邮件或网页将以更严肃的高管形式创建。其内容旨在针对高级经理（如 CEO）或可能拥有组织内价值账户凭据的个人。

![](img/key_topic_icon2.jpg)

鲸钓鱼攻击的主要目标是窃取敏感信息或破坏受害者系统，然后针对其他关键高知名度人物。

### 语音钓鱼

`语音钓鱼`（`voice phishing` 的缩写）是一种在电话对话中进行的社会工程攻击。攻击者说服用户泄露私人个人和财务信息，或关于他人或公司的信息。

![](img/key_topic_icon2.jpg)

语音钓鱼的目标通常是窃取信用卡号、社会安全号码和其他可用于身份盗骗计划的信息。攻击者在执行语音钓鱼攻击时可能会冒充并伪造主叫显示 ID 以隐藏自己的身份。

### 短信钓鱼 (Smishing)

由于钓鱼一直是威胁者的一种有效策略，他们已经找到了除了使用电子邮件以外的方法，欺骗受害者点击恶意链接或激活邮件中的恶意软件。钓鱼活动通常使用短信向移动设备发送恶意软件或恶意链接。

![](img/key_topic_icon2.jpg)

`短信钓鱼 (SMS)` 的示例是近年来出现的比特币相关短信诈骗。许多受害者收到了信息，指示他们点击链接确认账户并领取比特币。当用户点击此类链接时，他或她可能会被骗在攻击者的网站上输入敏感信息。

你可以通过不点击来自任何未知短信发送者的链接来帮助缓解短信钓鱼攻击。有时攻击者会伪造合法实体的身份（例如您的银行、互联网提供商、社交媒体平台、Amazon 或 eBay）。如果你没有预期收到此类信息，就不应该点击通过短信发送的任何链接。例如，如果你收到一条关于 Amazon 订单问题的随机信息，请不要点击该链接。相反，直接访问 Amazon 网站，登录并在 Amazon 网站上验证是否存在问题。同样，如果你收到一条说信用卡交易或账单有问题的消息，请直接拨打银行而不是点击链接。如果你收到一条你中奖了的消息，那很可能是短信钓鱼尝试，你不应该点击该链接。

### USB 掉入攻击

许多渗透测试人员和攻击者已使用`通用串行总线 (USB) 掉入攻击` 成功攻破受害者系统。这种类型的攻击仅只需将 USB 闪盘（有时称为 USB 密钥或 USB 优存器）无人看管，或将其放置在战略位置。通常情况下，用户认为设备丢失了，并将其插入系统以确定应该把设备归还给谁；在他们反应过来之前，他们已经在下载并安装恶意软件了。插上你在办公室外街上随手丢弃的 USB 闪盘可能会导致安全泄露。

![](img/key_topic_icon2.jpg)

Google 反滥用研究团队 Elie Bursztein 的研究表明，大多数用户会毫不犹豫地将 USB 驱动器插入系统。作为其研究的一部分，他在伊利诺伊大学厄巴纳-香槟分校丢弃了近 300 个 USB 闪盘，并测量了谁插入了这些驱动器。结果显示，98% 的 USB 驱动器被捡起，对于 45% 的驱动器，有人不仅插了驱动器，还点击了文件。

另一种社会工程技术涉及丢弃一个包含 USB 闪盘的钥匙扣，其中可能还包括孩子或宠物的照片以及一两把真正的钥匙。这些个人化的细节可能会促使受害者尝试识别所有者以归还钥匙扣。这种社会工程攻击非常有效，而且可能是灾难性的。

### 落水池攻击

`落水池攻击` 是一种针对性攻击，发生在攻击者分析目标受害者访问的网站时。攻击者随后扫描这些网站可能的漏洞。如果攻击者发现可以被破坏的网站，则向该网站注入 JavaScript 或类似的代码注入，旨在在用户返回该网站时进行重定向。（这种重定向也称为 `跳转攻击`。）用户随后会被重定向到一个带有某种利用代码的网站。其目的是感染网络中的计算机，从而允许攻击者为了间谍或其他原因在网络中建立立足点。

![](img/key_topic_icon2.jpg)

落水池攻击通常是针对特定组织的用户设计的。因此，组织应该制定政策来防止此类攻击。例如，此类政策可能要求定期更新反恶意软件应用程序，并使用与系统其他部分及网络较少连接的安全虚拟机浏览器。为了避免网站在攻击中被破坏，管理员应使用正确的编程方法并定期扫描组织网站的恶意软件。用户教育对于帮助防止此类攻击至关重要。

## 物理攻击

作为渗透测试人员或红队成员，你可能会被要求模拟现实世界的威胁者或犯罪分子如何破坏组织的物理安全，以获得对基础设施、建筑、系统和员工的访问权限。在本节中，你将学习各种类型的物理攻击。

### 尾随攻击

通过 `pigbacking`（搭电），未经授权的人员会跟随已授权的人员进入受限区域——这通常在获得该人员同意的情况下。`Tailgating（尾随）` 本质上是相同的，但有一点不同：它通常在没有获得授权人员同意的情况下发生。搭电和尾随都可以通过使用访问控制门（以前称为“人肉道”）来防御。访问控制门是一个通常只能容纳一个人的狭小空间。它有两组间距很密的门；在第一组门关闭之前第二组门无法打开，从而创造了一个类似于休息室的空间，人们在其中会被身份识别（且无法逃脱）。访问控制门经常用于服务器房和数据中心。多因素身份认证通常与访问控制门配合使用；例如，第一道门处可能需要感应卡和 PIN 码，第二道门处需要生物识别。

![](img/key_topic_icon2.jpg)

**提示**

访问控制门是预防性安全控制的示例。转闸机、双门和安保人员也可以消除搭电和尾随，并有助于解决一般的机密性问题。这些选项通常比访问控制门便宜，但有效性较低。

### 翻垃圾桶

通过 `Dumpster diving（翻垃圾桶）`，人员在垃圾和回收容器中搜寻私人信息。为了保护敏感文件，组织应尽可能长时间将它们存储在安全的地方。当不再需要这些文件时，组织应该将其粉碎。（有些组织会焚烧文件，或聘请经过认证的专业第三方进行粉碎处理。）翻垃圾桶的人可能会在纸张以及硬盘或可移动的介质上找到信息。

![](img/key_topic_icon2.jpg)

### 窥肩攻击

通过 `shoulder surfing（窥肩攻击）`，某人通过观察受害者的肩膀来获取诸如个人身份信息（PII）、密码和其他机密数据。这样做的方法一种是靠近某人并从其肩膀处看一眼他们在笔记本电脑、手机或平板电脑上输入什么内容。也可以通过使用双筒望远镜甚至望远镜从远处进行这种攻击。此类攻击在拥挤的地方往往特别成功。此外，窥肩攻击也可以小型隐藏摄像头和麦克风来实现。用户意识和培训是预防的关键。电脑显示器还有特殊的屏幕滤膜，可以防止他人从角度看到屏幕。

![](img/key_topic_icon2.jpg)

### 复制胸卡

攻击者可以执行不同的 `badge cloning attacks（胸卡复制攻击）`。例如，攻击者可以克隆用于进入建筑的胸卡/卡片。可以使用专门的软件和硬件来执行这些克隆攻击。攻击者还可以利用社会工程技术伪装员工或其他任何授权用户，通过仅创建自己的胸卡并试图欺骗其他用户让他们进入建筑来进入。这甚至可以在不完全克隆胸卡射频（RF）功能的情况下完成。

![](img/key_topic_icon2.jpg)

**提示**

攻击者经常可以从 Twitter、Instagram 和 LinkedIn 等社交媒体网站获取有关公司胸卡设计（外观和感觉）的详细信息，因为人们在入职或离职时会发布展示胸卡的照片。

### 浏览器漏洞利用框架 (BeEF)
