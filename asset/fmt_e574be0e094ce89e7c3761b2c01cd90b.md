
```go
display(path+".value", v.Elem())
}

default: // 基本类型、通道、函数
	fmt.Printf("%s = %s\n", path, formatAtom(v))
}
}
```

让我们按顺序讨论各种情况。

### 切片和数组

两者的逻辑相同。`Len` 方法返回切片或数组值的元素数量，`Index(i)` 以 `reflect.Value` 形式检索索引 `i` 处的元素；如果 `i` 越界则会 panic。这些类似于序列上的内置 `len(a)` 和 `a[i]` 操作。`display` 函数在序列的每个元素上递归调用自身，将下标表示法 `"[i]"` 追加到路径后。

虽然 `reflect.Value` 有许多方法，但只有少数几个可以安全地在任意给定值上调用。例如，`Index` 方法可以在 `Slice`、`Array` 或 `String` 类型的值上调用，但在其他类型上会 panic。

### 结构体

`NumField` 方法报告结构体中的字段数量，`Field(i)` 将第 *i* 个字段的值作为 `reflect.Value` 返回。字段列表包括从匿名字段提升的字段。要将字段选择器表示法 `".f"` 追加到路径，我们必须获取结构体的 `reflect.Type` 并访问其第 *i* 个字段的名称。

### 映射

`MapKeys` 方法返回一个 `reflect.Value` 切片，每个映射键对应一个。像往常一样遍历映射时，顺序是未定义的。`MapIndex(key)` 返回与 `key` 对应的值。我们将下标表示法 `"[key]"` 追加到路径后。（此处我们偷了个懒。映射键的类型不限于 `formatAtom` 能最好处理的类型；数组、结构体和接口也可以是有效的映射键。扩展此情况以完整打印键是练习 12.1。）

### 指针

`Elem` 方法返回指针指向的变量，同样作为 `reflect.Value`。即使指针值为 `nil`，此操作也是安全的，此时结果的 Kind 为 `Invalid`，但我们显式使用 `IsNil` 来检测空指针，以便打印更合适的消息。我们在路径前加上 `"*"` 并加上括号以避免歧义。

### 接口

同样，我们使用 `IsNil` 测试接口是否为 nil，如果不为 nil，则使用 `v.Elem()` 获取其动态值并打印其类型和值。

观察这两个示例之间的区别：

```go
var i interface{} = 3
Display("i", i)
// Output:
// Display i (int):
// i = 3
Display("&i", &i)
// Output:
// Display &i (*interface {}):
// (*&i).type = int
// (*&i).value = 3
```

在第一个示例中，`Display` 调用 `reflect.ValueOf(i)`，它返回一个 Kind 为 `Int` 的值。正如我们在 12.2 节 中提到的，`reflect.ValueOf` 总是返回一个具体类型的 `Value`，因为它会提取接口值的内容。

在第二个示例中，`Display` 调用 `reflect.ValueOf(&i)`，它返回一个指向 `i` 的指针，Kind 为 `Ptr`。`Ptr` 的 switch case 会对此值调用 `Elem`，它返回一个代表变量 `i` 本身的 `Value`，Kind 为 `Interface`。像这样间接获得的 `Value` 可以代表任意值，包括接口。`display` 函数会递归调用自身，这一次它会为接口的动态类型和值分别打印组件。

按目前的实现，如果 `Display` 在对象图中遇到循环，将永远不会终止，例如这个吞噬自己尾巴的链表：

```go
// 一个指向自身的结构体
type Cycle struct{ Value int; Tail *Cycle }
var c Cycle
c = Cycle{42, &c}
Display("c", c)
```

`Display` 打印出这种不断增长的展开：

```
Display c (display.Cycle):
c.Value = 42
(*c.Tail).Value = 42
(*(*c.Tail).Tail).Value = 42
(*(*(*c.Tail).Tail).Tail).Value = 42
...ad infinitum...
```

许多 Go 程序至少包含一些循环数据。使 `Display` 对此类循环具有鲁棒性比较棘手，需要额外的记账工作来记录迄今为止已跟踪的引用集合；开销也很大。通用的解决方案需要 `unsafe` 语言特性，正如我们将在 13.3 节 中看到的那样。

对 `fmt.Sprint` 而言，循环不构成太大问题，因为它很少尝试打印完整的结构。例如，当它遇到指针时，会通过打印指针的数值来中断递归。它可能会在尝试打印包含自身作为元素的切片或映射时陷入困境，但这种罕见情况不值得花费巨大精力去处理循环。

**练习 12.1：** 扩展 `Display`，使其能够显示键为结构体或数组的映射。

**练习 12.2：** 通过限制放弃递归前的步数，使 `display` 在循环数据结构上使用安全。（在 13.3 节 中，我们将看到另一种检测循环的方法。）

## 12.4 示例：编码 S 表达式

`Display` 是一个用于显示结构化数据的调试例程，但它距离能够将任意 Go 对象编码或 *封送* 为适合进程间通信的可移植符号中的消息已经不远了。

正如我们在 4.5 节 中所见，Go 标准库支持多种格式，包括 JSON、XML 和 ASN.1。另一种仍被广泛使用的符号是 *S 表达式*，即 Lisp 的语法。与其他符号不同，Go 标准库不支持 S 表达式，这在很大程度上是因为尽管经历过多次标准化尝试且存在许多实现，但 S 表达式并没有一个公认的通用定义。

在本节中，我们将定义一个包，使用支持以下结构的 S 表达式符号来编码任意 Go 对象：

```
42             整数
"hello"        字符串（带 Go 风格引号）
foo            符号（未加引号的名称）
(1 2 3)        列表   （用括号括起来的零个或多个项）
```

布尔值传统上使用符号 `t` 表示真，用空列表 `()` 或符号 `nil` 表示假，但为简单起见，我们的实现将忽略它们。它也会忽略通道和函数，因为它们的状态对反射是不透明的。并且它会忽略实数和复数浮点数以及接口。为它们添加支持是 练习 12.3。

我们将使用 S 表达式按如下方式编码 Go 的类型。整数和字符串以显而易见的方式编码。空值编码为符号 `nil`。数组和切片使用列表符号编码。

结构体被编码为字段绑定的列表，每个字段绑定都是一个包含两个元素的列表，其第一个元素（一个符号）是字段名，第二个元素是字段值。映射也被编码为键值对的列表，每个键值对对应映射中的一个条目。传统上，S 表达式使用单个 *cons* 单元 `(key . value)` 来表示每个键值对，而不是两个元素的列表，但为了简化解码，我们将忽略点对列表表示法。

编码由单个递归函数 `encode` 完成，如下所示。其结构本质上与上一节中的 `Display` 相同：

`gopl.io/ch12/sexpr`

```go
func encode(buf *bytes.Buffer, v reflect.Value) error {
	switch v.Kind() {
	case reflect.Invalid:
		buf.WriteString("nil")
	case reflect.Int, reflect.Int8, reflect.Int16,
		reflect.Int32, reflect.Int64:
		fmt.Fprintf(buf, "%d", v.Int())
	case reflect.Uint, reflect.Uint8, reflect.Uint16,
		reflect.Uint32, reflect.Uint64, reflect.Uintptr:
		fmt.Fprintf(buf, "%d", v.Uint())
	case reflect.String:
		fmt.Fprintf(buf, "%q", v.String())
	case reflect.Ptr:
		return encode(buf, v.Elem())
	case reflect.Array, reflect.Slice: // (value ...)
		buf.WriteByte('(')
		for i := 0; i < v.Len(); i++ {
			if i > 0 {
				buf.WriteByte(' ')
			}
			if err := encode(buf, v.Index(i)); err != nil {
				return err
			}
		}
		buf.WriteByte(')')
	case reflect.Struct: // ((name value) ...)
		buf.WriteByte('(')
		for i := 0; i < v.NumField(); i++ {
			if i > 0 {
				buf.WriteByte(' ')
			}
			fmt.Fprintf(buf, "(%s ", v.Type().Field(i).Name)
			if err := encode(buf, v.Field(i)); err != nil {
				return err
			}
			buf.WriteByte(')')
		}
		buf.WriteByte(')')
	case reflect.Map: // ((key value) ...)
		buf.WriteByte('(')
		for i, key := range v.MapKeys() {
			if i > 0 {
				buf.WriteByte(' ')
			}
			buf.WriteByte('(')
			if err := encode(buf, key); err != nil {
				return err
			}
			buf.WriteByte(' ')
			if err := encode(buf, v.MapIndex(key)); err != nil {
				return err
			}
			buf.WriteByte(')')
		}
```
