
# 组合类型

在第 3 章中，我们讨论了作为 Go 程序数据结构构建块的基本类型；它们是我们世界的原子。在本章中，我们将了解*组合*类型，即通过以各种方式组合基本类型而创建的分子。我们将讨论四种这样的类型——数组、切片、映射和结构体——并在本章末尾，展示如何使用这些类型的结构化数据编码为 JSON 数据并从中解析，以及如何用于从模板生成 HTML。

## 数组和结构体

数组和结构体是*聚合*类型；它们的值是内存中其他值的连接。数组是同质的——其元素都具有相同的类型——而结构体是异质的。数组和结构体都是固定大小的。相比之下，切片和映射是动态数据结构，会随着值的添加而增长。

### 4.1 数组

数组是一个具有特定类型且长度固定的元素序列，元素个数可以为零或更多。由于长度固定，数组在 Go 语言中很少直接使用。切片可以增长和收缩，功能强大得多，但要理解切片，我们必须先理解数组。

通过传统的下标表示法访问单个数组元素，下标范围从零到数组长度减一。内置函数 `len` 返回数组中的元素个数。

```
var a [3]int             // 3 个整数的数组
fmt.Println(a[0])        // 打印第一个元素
fmt.Println(a[len(a)-1]) // 打印最后一个元素，a[2]

// 打印索引和元素。
for i, v := range a {
    fmt.Printf("%d %d\n", i, v)
}

// 仅打印元素。
for _, v := range a {
    fmt.Printf("%d\n", v)
}
```

默认情况下，新数组变量的元素初始为元素类型的零值，数字类型的零值为 `0`。我们可以使用*数组字面量*通过一组值来初始化数组：

```
var q [3]int = [3]int{1, 2, 3}
var r [3]int = [3]int{1, 2}
fmt.Println(r[2]) // "0"
```

在数组字面量中，如果省略号 `...` 出现在长度的位置，则数组长度由初始化值的个数决定。`q` 的定义可以简化为：

```
q := [...]int{1, 2, 3}
fmt.Printf("%T\n", q) // "[3]int"
```

数组的大小是其类型的一部分，因此 `[3]int` 和 `[4]int` 是不同的类型。大小必须是常量表达式，即在程序编译时就能计算出值的表达式。

```
q := [3]int{1, 2, 3}
q = [4]int{1, 2, 3, 4} // 编译错误：无法将 [4]int 赋值给 [3]int
```

正如我们将看到的，数组、切片、映射和结构体的字面量语法是相似的。上面的具体形式是按顺序列出值，但也可以指定索引和值的配对列表，如下所示：

```
type Currency int

const (
    USD Currency = iota
    EUR
    GBP
    RMB
)

symbol := [...]string{USD: "$", EUR: "€", GBP: "£", RMB: "¥"}

fmt.Println(RMB, symbol[RMB]) // "3 ¥"
```

在这种形式中，索引可以按任意顺序出现，且可以省略部分索引；如前所述，未指定的值将取元素类型的零值。例如：

```
r := [...]int{99: -1}
```

定义了一个包含 100 个元素的数组 `r`，除最后一个元素值为 −1 外，其余均为零。

如果数组的元素类型是*可比较的*，则该数组类型也是可比较的，因此我们可以直接使用 `==` 运算符比较该类型的两个数组，该运算符判断所有对应元素是否相等。`!=` 运算符是其否定形式。

```
a := [2]int{1, 2}
b := [...]int{1, 2}
c := [2]int{1, 3}
fmt.Println(a == b, a == c, b == c) // "true false false"
d := [3]int{1, 2}
fmt.Println(a == d) // 编译错误：无法比较 [2]int == [3]int
```

作为一个更实际的例子，`crypto/sha256` 包中的 `Sum256` 函数生成存储在任意字节切片中的消息的 SHA256 加密哈希值或*摘要*。摘要有 256 位，因此其类型为 `[32]byte`。如果两个摘要相同，则这两条消息极有可能相同；如果摘要不同，则消息不同。以下程序打印并比较 `"x"` 和 `"X"` 的 SHA256 摘要：

gopl.io/ch4/sha256

```
import "crypto/sha256"

func main() {
    c1 := sha256.Sum256([]byte("x"))
    c2 := sha256.Sum256([]byte("X"))
    fmt.Printf("%x\n%x\n%t\n%T\n", c1, c2, c1 == c2, c1)
    // Output:
    // 2d711642b726b04401627ca9fbac32f5c8530fb1903cc4db02258717921a4881
    // 4b68ab3847feda7d6c62c1fbcbeebfa35eab7351ed5e78f4ddadea5df64b8015
    // false
    // [32]uint8
}
```

两个输入仅相差一位，但摘要中约有一半的位都不同。请注意 `Printf` 的动词：`%x` 用于以十六进制打印字节数组或切片的所有元素，`%t` 用于显示布尔值，`%T` 用于显示值的类型。

调用函数时，每个参数值的副本被赋值给对应的参数变量，因此函数接收的是副本而非原值。以这种方式传递大型数组可能效率低下，且函数对数组元素的任何修改仅影响副本，不影响原数组。在这方面，Go 语言像对待其他类型一样对待数组，但这与隐式按引用传递数组的语言不同。

当然，我们可以显式传递数组指针，这样函数对数组元素的任何修改对调用者都将可见。以下函数将 `[32]byte` 数组的内容置零：

```
func zero(ptr *[32]byte) {
    for i := range ptr {
        ptr[i] = 0
    }
}
```

数组字面量 `[32]byte{}` 生成一个包含 32 个字节的数组。数组的每个元素都具有 `byte` 的零值，即零。我们可以利用这一事实编写另一个版本的 `zero`：

```
func zero(ptr *[32]byte) {
    *ptr = [32]byte{}
}
```

使用数组指针既高效又允许被调用函数修改调用者的变量，但数组因其固定大小而天生缺乏灵活性。例如，`zero` 函数不接受指向 `[16]byte` 变量的指针，也无法添加或删除数组元素。出于这些原因，除 SHA256 这种固定大小哈希的特殊情况外，数组很少用作函数参数；相反，我们使用切片。

### 4.2 切片

切片代表元素类型相同的可变长度序列。切片类型写作 `[]T`，其中元素类型为 `T`；它看起来就像没有大小的数组类型。

数组和切片关系紧密。切片是一种轻量级数据结构，提供对数组子序列（或全部）元素的访问，该数组称为切片的*底层数组*。切片有三个组成部分：指针、长度和容量。指针指向切片可访问的第一个数组元素，这不一定是数组的第一个元素。长度是切片元素的个数；它不能超过容量，容量通常是从切片开始到底层数组末尾的元素个数。内置函数 `len` 和 `cap` 返回这两个值。

多个切片可以共享同一个底层数组，并可能引用该数组的重叠部分。图 4.1 展示了一个表示一年中月份的字符串数组，以及它的两个重叠切片。该数组声明如下：

```
months := [...]string{1: "January", /* ... */, 12: "December"}
```

所以 January 是 `months[1]`，December 是 `months[12]`。通常，索引为 0 的数组元素会包含第一个值，但因为月份总是从 1 开始编号，我们可以在声明中省略它，它将被初始化为空字符串。

*切片操作符* `s[i:j]`，其中 0 ≤ `i` ≤ `j` ≤ `cap(s)`，会创建一个新切片，引用序列 `s` 中从 `i` 到 `j-1` 的元素，序列 `s` 可以是数组变量、数组指针或另一个切片。生成的切片有 `j-i` 个元素。如果省略 `i`，则默认为 0；如果省略 `j`，则默认为 `len(s)`。因此切片 `months[1:13]` 引用了所有有效月份的范围，`months[1:]` 也是如此；切片 `months[:]` 引用整个数组。让我们为第二季度和北半球夏天定义重叠的切片：
