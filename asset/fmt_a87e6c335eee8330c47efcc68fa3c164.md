
## 每个人的网络安全

![](img/cover.jpg)

# 前言

网络空间是我们所有人生活中至关重要的一部分。尽管我们都在使用它，但其大部分基础设施和运作机制对我们而言却是不可见的。

这一无处不在的系统起源于美国政府高级研究计划局（ARPA）开发的一个网络，该网络最初旨在连接政府和大学的研究实验室。参与者彼此信任且负责，因此安全性几乎未受到任何重视。

其后果延续至今。这个小型网络如野草般疯狂生长，直到连接起全球数十亿计算设备。在每一个阶段，设计决策的制定都优先考虑“下一个伟大的事物”，而安全性仍然几乎未受到任何重视。

于是我们发现自己身处这样一个环境——网络空间——它对我们许多人而言近乎一项基本服务，却需要付出巨大努力，以防范犯罪活动的负面后果、将网络空间视为廉价武力倍增器的政府行为，以及无聊和粗心大意者的不假思索的行为。

使网络空间更加安全是我们这个时代面临的挑战之一。这不仅（或许甚至主要）不是一项技术挑战。它要求政府和企业在可能的情况下鼓励安全，并确保其自身行为不破坏安全。

遗憾的是，一些有能力推动网络安全改进的人——律师、政治家——并不具备充分理解这些问题的技能。本书旨在通过以非技术背景读者也能理解的方式描述这些问题，来帮助改善这一状况。

这不是一篇研究专著，因此我未收录研究文献的参考文献。对于希望更深入探究特定主题的读者，有大量网站可提供进一步信息。我希望您在此阅读的内容足以让您理解那些更具技术性的阐述。

当今成功的书籍，其标题似乎要么包含三个动词，模仿《吃、祷告、爱》的模式；要么包含“女孩”一词。我想不出符合第二种类型的标题，也觉得“计算、攻击、防御”作为第一种类型的标题并不合适。

# 第一章 简介

网络空间——计算机系统、设备及连接它们的网络的组合——无处不在。网络空间最显而易见的部分，也是大多数人接触过的部分，是互联网，但网络空间还有许多其他组成部分：自动化生产线、独立的军事网络，以及技术上属于互联网一部分但普通用户难以访问的暗角。我们作为个体，显性地利用网络空间进行工作、购物和娱乐；但它在不那么显性却更重要的层面上，被用于维持我们社会的运转，涉及制造业、服务业、金融市场和政府。

尽管网络空间无处不在，但即使我们在使用它时，其大多数结构对我们而言也是不可见的。我们通过手机或电脑与它交互，但为网站提供动力、让我们能够管理银行账户、预订行程和酒店、使用电子邮件或社交媒体通信的服务器，并不容易被察觉。连接我们的接口设备与这些服务的“管道”也几乎完全隐藏。从用户角度来看，使这个庞大、复杂的系统如此不显山露水、行云流水，是一项重大成功。

然而，从安全角度来看，网络空间的不可见性造成了一个问题——人们对其运作方式缺乏直觉，因此无法轻易判断哪些行为潜在危险。这有点像游览一个以旅游为主的城市，却因未意识到贫民窟的存在而误入歧途。在网络空间中，很难评估任何特定行为的风险，许多“规则”都缺乏解释，或者至少缺乏有意义的解释，使用户无法理解规则在何种情况下有合理的例外。例如，一条常见规则是“不要打开陌生人的电子邮件附件”，但在实践中这往往行不通。如果你不知道 `From:` 电子邮件地址可以被伪造，那么看似相反的规则“打开熟人发来的附件没问题”有时会导致不幸的后果。

年轻人在互联网环境中长大，在某些方面对危险更为敏锐，但即使是他们也很容易对风险视而不见，并被那些为私利利用网络空间的人所欺骗。关于网络空间的教育会有所帮助，这也是本书的目的，但一知半解是危险的（亚历山大·蒲柏语）。

网络安全问题可追溯至互联网前身 Arpanet 的早期：这是一个连接政府和大学计算机的网络，并假设所有参与者都是值得信赖且须负责的。因此，安全问题在 Arpanet 基础设计中未被严肃对待——许多此类设计沿用至今。根本问题在于向后兼容性：每项新发展都必须继续允许现有计算机、网络和系统协同工作，即使整体系统的规模和范围呈爆炸式增长。Arpanet 还被设计为可在核攻击中幸存，因此采用了分布式设计。这种设计延续至今的网络空间。网络空间没有整体管理，决策由利益相关者混乱协作制定。

在许多方面，互联网是其自身成功的受害者。从最初那一小组连接的计算机，它发展到包含更多政府和大学计算机，包括国际上的。20 世纪 80 年代初，电话公司介入，允许不同城市计算机间的专用连接，随后允许计算机通过拨号相互连接，并利用原为语音设计的电话线传输数据。

1995 年万维网的引入标志着连接性的又一次转变。个人突然拥有了从企业和政府（包括遥远的）获取信息的“杀手级应用”；而这些企业和政府需要大型计算机向想要的人提供这些 `web pages`。大致同一时期，此前仅限学术界使用的电子邮件，成为普通人普遍的沟通方式。

浏览器和服务器开发了新功能，服务器不再仅提供内容，还支持与用户交互，包括允许用户上传内容。再一次，为一种用途设计的机制被改造为做其未设计之事，且新用途淹没了旧用途。

在另一维度，变化的是网络空间的 `scale`：数十亿人（超过世界人口一半）获得了参与设备；服务器为响应而变得更大、更快。

网络空间就是这么野蛮生长。没有中央规划；有趣的人想出利用现有基础设施和系统的新方法，在急于创造新事物时大多不考虑所造成的安全问题。结果，网络安全必须在安全从未被设计进去的世界中工作，因此必须尽可能有效地进行改造。不幸的是，安全不是那种可后期添加的属性——要真正有效，必须在设计和实现的每个阶段都考虑它。正如我们将看到的，试图设计对策以解决网络空间许多部分的安全弱点，必然是人为拼凑的，因此相对无效。

这当然是犯罪分子和一些国家政府的福音，他们能利用安全弱点谋取私利。想利用安全弱点者与试图让网络空间更安全者之间存在军备竞赛。改进安全的努力常被偏好便利而非安全的用户破坏。许多行为者虽口头服务于安全，实则偏好大量泄露。许多互联网企业（及一些政府）利用安全弱点收集用户数据，若网络空间更安全则难以收集。例如，许多互联网企业试图以增强认证安全为由收集用户电话号码，其真实动机是掌握电话号码可访问关于他们的另一大批数据。

网络安全改进薄弱且零散的原因之一是缺乏中央治理。网络空间控制分散在：管理某些方面但无实权的国际机构；基础设施所有者（如连接跨国的管道）；提供电话连接且往往拥有大型通信基础设施的（前）电话公司；提供大型服务器（用于网站和计算）的企业，如 `Apple`、`Amazon` 和 `Google`；以及国家政府。所有利益相关者激励不同，有时差异巨大，发展成为竞争利益拔河的结果。大多会大声宣称安全重要，但这往往仅弱弱转化为行动（甚至无行动），因为其他利益竞争或压倒它。即使有最好的意愿，改造安全也很难，所以整体上缺乏动力不足为奇。

网络空间国际合作困难。在某些方面，它是第一个后威斯特伐利亚……

一些国家试图在网络空间（重）构建国家边界。控制跨越此类边界的流量收效有限，并非不努力。即使流量可控，每国最终仍使用相同硬件、系统、应用……

第 2 章介绍网络空间幕后发生的事，即我们用于浏览网页、发送电子邮件或在网络空间中进行其他操作的接口实际如何工作。第 3 章讨论如何通过加密保护内容，包括传输中（从一地移动到另一地）和静止时（存储在某处时）。第 4 章描述构成网络空间的节点的安全问题，包括我们都在用的边缘设备（如手机和个人电脑），以及提供网页和基于网络服务并执行大规模计算的更强大计算机——称为 `servers`。第 5 章描述移动数据的管道的安全问题，从跨洲海底电缆到手机与耳机间的蓝牙连接。第 6 章描述设置和管理节点及管道配置的安全问题，使它们能按预期协同工作，即使出错时也是如此。第 7 章描述与用户直接交互的高层活动的安全问题。这包括电子邮件和万维网（以下简称 Web）的使用。由于区块链是热门话题且有重大、复杂的安全问题，我们也将讨论。

# 第 2 章：网络空间如何运作

## 2.1 网络空间初体验

几乎每个人都以某种形式熟悉网络空间，但我们用于使用各种在线系统的接口不一定能揭示幕后太多情况。三大最流行接口是网页浏览、社交媒体和电子邮件，大多数人通过手机访问。不过，个人电脑仍用于访问，特别是计算密集型、数据密集型或需要可视化的任务。

### 网页浏览与网络空间

网页浏览是最直观的。网页内容存储在大型计算机系统上，称为 Web 服务器。每当有人打开浏览器并输入 URL（或点击链接）时，请求就会被发送到相应的服务器，然后网页被发送回浏览器。虽然界面给人一种我们在访问网站的印象，但现实是网站的页面在访问我们。

### Web 服务器

在 Web 早期，Web 服务器向浏览器提供预构建的网页，随后由浏览器负责在用户使用的任何设备上显示它们。超文本标记语言（HTML）描述了网页每个部分是什么类型的内容（标题、段落），这使得 Web 浏览器能够以在用户特定设备上产生最佳效果的方式显示页面。例如，浏览器可以将显示的页面适配至可用的屏幕尺寸。

当 Web 服务器获得在请求时动态创建页面的能力后，出现了更多有趣的可能性。现在，特定用户看到的网页可以为该用户定制——也许针对不同国家或地区的用户有所不同。

当用户的浏览器能够向服务器传达个性化信息时，这种能力变得更加强大。其显而易见的用途是搜索——用户输入搜索词，搜索引擎（一种专门的 Web 服务器）返回一个包含与上传搜索词匹配结果的定制页面。用户可以与银行 Web 服务器通信，并看到一个包含其个人账户余额的页面。

下一阶段发生在浏览器具备下载小段软件（连同页面内容）的能力时。Web 服务器利用这一机制，可以让浏览器代表其执行某些操作。这是网上银行、网上购物以及所有其他双向交互（用户既输入信息又查看内容）的关键。

这些机制也有负面作用——它们可以且确实被用来在浏览器中存储信息（`cookies`），这些信息可以识别同一用户何时再次访问同一 Web 服务器，以及越来越多的其他服务器。换句话说，这个丰富的通信通道成为了追踪用户行为的渠道。

在某些交互中，重点更多在于从用户到网站的信息流，而非相反；例如，上传视频到 YouTube。机制是相同的——服务器下载代码，建立一个从浏览器到服务器的通信通道来控制上传。

社交媒体网站使用这一相同的基本机制，但它们不是使用（通用的）浏览器，而是将交互打包在一个应用程序中，并尽可能让用户下载该应用。对社交媒体网站或企业的优势在于，应用程序可以运行*任意*代码，而非浏览器中运行的受限代码。因此交互可以更丰富。这种更丰富的交互不一定是好事——正是它使得详细收集每个用户（有时甚至包括其系统）的数据成为可能。

许多其他企业也做同样的事：创建一个直接与其 Web 服务器交互的应用程序，而不是让用户使用浏览器访问其网站。该应用程序只不过是其网站的一个专用前端，但它允许同类型的更丰富交互。这主要有利于企业而非用户。此类所有应用程序的风险在于，它们可能实现粗糙，因而存在自身严重的安全弱点，且无法利用大多数现代浏览器内置的安全措施。

### 通信工具

用户遇到网络空间的另一个主要方式是作为通信工具：电子邮件、即时通讯（多种形式）和视频聊天。其中一些是一用户设备与另一用户设备之间的对称交互，但一些通信应用将所有通信路由通过服务器。第一种选择更难实现但更私密，但大多数工具使用第二种选择。

区分同步通信（消息立即传送到另一端），如视频聊天和即时通讯；以及缓冲或异步通信，即可存储在某个中间位置直到接收者可用（电子邮件），这也很有用。

### 业务与基础设施

网络空间还有许多方面对普通用户并不明显。许多企业与其员工保持通信，尤其是那些不在办公室工作的员工。它们还收集数据，通常是实时的，关于其业务活动。例如，交通系统随时跟踪每一列火车或每一架飞机的位置，以及它们性能表现的许多其他细节和何时可能需要维护。为了实现在线酒店预订网站，酒店连锁必须持续准确地记录哪些房间在何时可用。零售店精确跟踪其每家门店售出的商品，以便装载并调度送货卡车，使其恰好在需要时到达，且车上装载的正是所需产品。电网和油气管道必须跟踪其输送系统的全程性能，并能控制远程设备调高或调低、开启或关闭。

企业还利用网络空间相互通信，提供供应链信息或以我们从在线零售商购物的相同方式相互采购。与消费者网购不同，这些交互通常是自动化的。例如，汽车装配线基于所有组件从供应商的准时制交付，以便零件在需要时刚好到达装配线。这降低了仓储所需的成本和空间。

### 政府用途

政府面向公民地使用网络空间，在线提供服务，如更新驾照、征收税款等。

政府还将网络空间作为权力工具使用。几乎所有通信都在网络空间中传输，因此大量情报收集已从无线电拦截转移到网络空间拦截。政府还将网络空间作为武器系统，规划（有时实施）针对其他国家的网络攻击。

### 犯罪活动

罪犯利用网络空间，既作为收集信息的方式，也作为实施犯罪的手段。直到最近，除了直接攻击金融机构和金融转账外，很难直接在网络空间赚钱，但 `cryptocurrencies`（加密货币）的兴起使得从个人和企业勒索钱财成为可能，且无法追踪，这在网络空间中创造了一类新的犯罪。

### 总结

因此，普通人看到的网络空间部分只是冰山一角。组织之间以及网络空间内部存在大量其他通信和交互。整个系统过于复杂，无法直接由人工管理，因此幕后还有一层自我管理，确保即使用户采取的行动发生变化，连接仍能保持运行。

个人在网络空间面临安全问题，但在网络空间其他不太可见的部分也存在许多其他漏洞。

## 2.2 什么是网络空间？

网络空间是世界上所有连接的数字基础设施的总和。最明显的部分是互联网，以及其中的万维网。但也存在各种其他网络，主要是军事网络，它们未显式连接到互联网，还有所有连接到互联网但未被人类显式使用、且我们往往会忽略的设备。

网络空间可被视为由三种不同类型的实体组成：

### 节点

节点是通过网络相互连接的对象，它们执行计算、存储数据、与人类交互以及与物理世界交互。

最明显的节点类型是计算机，范围从大型强大的服务器到个人计算机。但还有其他更常见的节点类型。例如，大多数人使用手机与网络空间交互，手机只是一种专用计算机。越来越多的还有**物联网设备**，这些节点通常不直接与人类交互，但具有实用功能：视频摄像头、灯光开关、恒温器、运动探测器和医疗设备。不太明显的是**网络物理系统**，例如现代生产线中使用的机器人和机械，以及控制管道和电网的设备。

之所以存在这系列设备——它们都包含计算能力并连接到网络——是因为从通用计算设备入手并对其进行编程以特定方式运行，几乎总是比直接构建专用设备来实现该功能更容易。结果是，网络空间几乎已成为一种单一文化，因为只有少数计算机制造商、操作系统提供商（`Windows`、`Mac`、`Linux`）、手机系统（`Android`、`iOS`）和网络交换机提供商（`Ericcson`、`Cisco`、`Huawei`）。

这引入了与任何单一文化相关的漏洞：针对特定类型系统的攻击可以同时对许多目标取得成功。攻击者可以迅速扩大攻击规模并造成严重破坏。他们还可以对特定类型的所有节点尝试撒网式攻击，指望至少能攻破一些目标。

### 管道

管道是将节点相互连接的连接器。它们传输多种形式的数据：电子邮件、网页请求、网页内容本身、数字编码的语音、视频、音频、软件、许多其他类型的数据传输，以及管理管道网络本身的控制消息。

管道可以硬连线以在两个固定端点之间移动数据。例如，海底电缆连接大陆并能承载海量数据；大容量网络在国家内部移动数据，光纤和同轴电缆将数据传入和传出企业、住宅和公寓楼。

其他管道无线传输数据。这些包括将手机与本地基站连接的蜂窝网络、几百平方米范围内的 Wi-Fi、蓝牙及连接约两米短距离的类似系统，以及用于 RFID 标签和近场设备的厘米级超短距离无线连接。

### 管理基础设施

管理基础设施管理节点和管道的组织方式，以便数据能找到通往其预期目的地的路径，并确保资源按照商定的规则共享。节点和管道都会随着用户移动、系统故障或更换而加入或离开网络，因此该基础设施还必须应对动态情况。网络空间的规模决定了其中大部分管理必须实现自动化。

### 网络空间中的人

从某种意义上说，人也可以被视为网络空间的一部分，原因有二。首先，网络空间中流动的大量数据之所以移动，是因为它们要发往特定的个人。因此，网络空间必须有方法发现每个人在何处以及如何连接到网络——人必须拥有从网络空间内部向外看讲得通的地址或接入点。

其次，个人在网络空间中行动，我们通常希望他们对这些行为负责。这是一个艰难的权衡：我们有时希望能像在现实世界中那样匿名行动，但所有国家已有机制在匿名性助长犯罪时加以限制，类似的机制也需要迁移到网络空间。大型在线企业渴望收集关于每个人的大量数据以建立模型，从而（据称）改进定制广告投放，这使情况变得模糊不清。结果是，个人在网络空间行动时对被识别持警惕态度，因为他们不信任政府或跨国企业不会滥用通过观察已知个人及其行为而获得的信息。

## 2.3 节点

由于网络空间包含数十亿个节点，必须有方法识别哪个是哪个。这个问题比看起来更复杂，因为同一个物理对象（比如一部手机）可能随时间出现在多个地方，有时甚至同时出现在多个地方。例如，无论你何时移动（有时甚至只是乘电梯上楼），你的手机都会连接到不同的基站以维持与蜂窝网络的连接。

识别设备依赖于每个设备拥有唯一标识符。对于手机，有一个唯一号码，即**IMEI**（国际移动设备识别码），它与手机硬件绑定。蜂窝网络可以在手机连接网络时检查 `IMEI`，从而绝对确定是哪部手机。

其他手机标识符与其**SIM 卡**相关联。SIM 卡是物理手机与为该手机提供服务的运营商之间的关联。它们可以在大多数手机中插拔更换，因此它们不标识手机本身，但对于想要接听电话的用户来说，它们更接近于用户的标识符。与 SIM 卡关联的第一个标识符是**国际移动用户识别码（IMSI）**，它包含国家、运营商和关联个人的详细信息（如果明确售予实名登记的个人，某些国家要求如此）。例如，`IMSI` 用于确定手机是否在另一家公司的网络上拥有漫游权限。

与手机 SIM 卡关联的第二个标识符是电话号码。加上国家和地区代码，每个号码在全球范围内都是唯一的。这是将来电连接到被叫特定手机的主要方式。

蜂窝网络必须跟踪连接到其基站的所有手机的这些标识符，以便将来电发送到正确的位置并正确计费。

与手机系统并行的是规模大得多的互联网，它连接计算机（各种大小和复杂度）以及使用 Wi-Fi 连接功能的手机。每个设备由一个称为 **MAC**（介质访问控制）地址的唯一地址标识，它是六组十六进制数对。
