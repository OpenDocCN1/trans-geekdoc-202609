
\Delta\mathbf{\theta}^{(i)} = a\Delta\mathbf{\theta}^{(i - 1)} - \mu\frac{\partial J\left( \mathbf{\theta} + a\Delta\mathbf{\theta}^{(i - 1)} \right)}{\partial\mathbf{\theta}}|_{\mathbf{\theta}^{(i - 1)}}.

![Equation](img/si202.png)

与之前的动量更新规则的区别在于，代价函数的梯度是在将 `θ` 沿当前修正项 `Δθ^((i−1))` 的方向推进后计算的。

![Equation](img/si203.png)

换句话说，梯度不是在当前可用的参数估计值处计算，而是在其近似未来值处计算。据 [197] 报道，这可以显著提高收敛速度。`a` 的取值范围与动量算法的情况相同。

### AdaGrad 算法

AdaGrad 算法在第 8 章公式 (8.71) 中以其在线形式在凸代价函数设定下被引入。借用该算法背后的主要原理，在我们当前的框架中可以重述为

$$

\mathbf{\theta}^{(i)} = \mathbf{\theta}^{(i-1)} - \mu\mathbf{G}[i-1]^{-1/2}\mathbf{g}^{(i-1)},

$$

![Equation](img/si204.png)

根据定义

$$

\mathbf{g}^{(i)} := \frac{\partial J}{\partial\mathbf{\theta}}|_{\mathbf{\theta}^{(i)}}

$$

![Equation](img/si205.png)

是在相应估计值 `θ^((i))` 处计算的梯度。

![Equation](img/si172.png)

而矩阵 `G[i]`

![Equation](img/si207.png)

是直到并包括第 `i` 次迭代的所有梯度向量外积之和，即

$$

G_{i} := \sum\limits_{t = 0}^{i}\mathbf{g}^{(t)}\mathbf{g}^{{(t)}^{T}}.

$$

![Equation](img/si208.png)

在实践中，矩阵 `G[i]` 被视为对角矩阵；因此其根矩阵的逆在计算上很有吸引力。在这种情况下，如果 `D` 是网络的总参数数量，`D × D` 矩阵 `G[i]` 的对角线上包含相应梯度的平方，即

```
G_i(d,d) = ∑_{t=0}^{i} (g_d^{(t)})²,  d = 1,2,...,D,
```

其中 `g_d^{(t)}` 表示第 `d` 个分量在迭代 `(t)` 时的梯度，即 `g_d^{(t)} = ∂J / ∂θ_d^{(t)}`，而 `θ_d` 是 `θ ∈ ℝ^D` 的第 `d` 个元素。通常，使用一个小常数 `ϵ` 来避免可能的除零错误，每个参数向量分量的相应更新形式为

```
θ_d^{(i)} = θ_d^{(i-1)} - μ / (√G_{i-1}(d,d) + ϵ) * g_d^{(i-1)},  d = 1,2,...,D.  (18.35)
```

`ϵ` 的值可以是 10^(-8) 量级左右。简而言之，AdaGrad 中的步长依赖于迭代次数，并且对每个分量都不同。`μ` 的值通常设置为接近 0.01。对每个单独参数的修正与其梯度值成反比。较大的梯度值导致较小的步长。因此，随着迭代的进行，每个维度会随时间趋于均衡。这在训练深度网络时可能是有益的，因为不同层中梯度的尺度可能在数量级上差异很大。

然而，AdaGrad 的主要缺点是分母中平方梯度的累积，这可能会在若干次迭代后冻结更新。

### 带 Nesterov 动量的 RMSProp

在 RMSProp 中，AdaGrad 中使用的梯度平方和被所有过去平方梯度的递归定义衰减平均值所取代。这样，远期的历史样本会被指数级丢弃。同时，采用了 Nesterov 类型的动量原理。主要递归公式总结如下：

#### 自适应矩估计算法

更新方程为：

```
g = ∂J(θ + aΔθ^(i-1)) / ∂θ |_(θ^(i-1))
v^(i) = β v^(i-1) + (1 - β) g ∘ g
Δθ_d^(i) = a Δθ_d^(i-1) - μ / (√(v_d^(i)) + ε) g_d,  d = 1,2,…,D
θ^(i) = θ^(i-1) + Δθ^(i)
```

其中 `β` 是用户定义的参数。第一个递归公式计算 Nesterov 类型修正后的梯度。第二个根据衰减平均原理更新梯度值的平方。“∘”运算表示逐元素乘法。第三个递归按 AdaGrad 原理计算修正项，第四个提供更新。算法从 `v^((0)) = 0`、`Δθ^((0))` 和 `θ^((0))` 的初始条件开始。超参数的一些典型值为 `ε = 10^(-8)`、`β = 0.9` 和 `μ = 0.001`。

RMSProp 算法由 Hinton 等人在一次讲座中提出。^(¹¹⁷)

文献 [103] 中提出的 Adam 算法借鉴了遗忘平方梯度过去值的概念，但它也以类似于动量算法的方式引入并传播梯度的值。此外，它还引入了一些重要的归一化处理，以解决可能引入的偏差。Adam 算法演变的核心递推公式为：

```
g = ∂J/∂θ|θ^(i-1), m^(i) = β₁m^(i-1) + (1 - β₁)g, v^(i) = β₂v^(i-1) + (1 - β₂)g ∘ g,
```

其中 ∘ 表示逐元素乘法，`β₁` 和 `β₂` 为用户定义的参数。随后，获得的矩估计值会被归一化，即：

```
m̂^(i) = m^(i) / (1 - β₁^i),   v̂^(i) = v^(i) / (1 - β₂^i).
```

这些归一化处理了两个梯度矩倾向于偏向零的趋势，这在早期迭代中尤为明显，因为它们是以零值初始化的。随着迭代进行，归一化系数趋向于 1。参数向量第 *d* 个分量的更新计算如下

*   编写本书时，训练深度神经网络最流行的算法似乎是 Adam、简单随机梯度下降（带或不带动量）以及 RMSProp（带或不带 Nesterov 动量项）。选择取决于具体应用及用户的熟悉程度。此外，使用小批量似乎已成为趋势。

### 一些实用提示

训练神经网络与其数学严谨性相比，仍带有浓厚的实用工程色彩。本节介绍了一些经验证明有助于改进反向传播算法性能的实用提示（更详细的讨论见文献 [113]）。

#### 预处理输入特征/变量

建议对输入变量进行预处理，使其在训练集上具有（近似）零均值。此外，应对它们进行缩放，使其都具有相似的方差，这假设所有变量同等重要。如果所用的非线性函数属于压缩类型，建议其方差也应与激活（压缩）函数的取值范围相匹配。而且，如果输入变量不相关，则有利于算法的收敛。实现这一点的一种方法是通过适当的变换，例如 `PCA`。

#### 选择对称激活函数

在采用压缩类型激活函数的情况下，希望神经元的输出以同等概率取正值和负值。毕竟，一层的输出将成为下一层的输入。为此，可以使用公式 (18.8) 中的双曲激活函数。推荐值为 `a = 1.7159` 和 `c = 4/3`。这些值保证了如果输入按前述建议进行预处理，即归一化为方差等于 1，则激活函数输出的方差也等于 1，且相应的均值等于零。然而，正如我们很快将在第 18.6.1 节中看到的，目前此类激活函数似乎不太流行。

#### 目标值

目标值的选择应仔细考虑，以与所用的激活函数保持一致。这些值的选择应使压缩函数的极限值偏移一小部分。否则，算法倾向于将权重推向大值，这会减慢收敛速度；激活函数被驱动至饱和区，导致激活函数的导数变得非常小，进而导致梯度值变小。对于双曲正切函数，使用前述讨论的参数，目标类别标签选择 `±1` 似乎是正确的。注意，在这种情况下，饱和值为 `a = ±1.7158`。在第 18.5 节中，我们将看到输出激活函数的选择应由所采用的最优性准则决定。

#### 初始化

在训练神经网络时，任何优化方案的权重参数初始化都至关重要。从一组“错误”的值开始会对训练产生许多不良影响。初始化会影响算法收敛的快慢。此外，初始值在算法是收敛到低代价点还是高代价点（良好或不良的局部极小值）方面起着关键作用。此外，泛化性能也可能受初始化影响。然而，必须指出的是，与这些问题相关的理论基础尚不清晰，许多概念尚未被充分理解，目前仍构成正在进行的研究领域（另见第 18.11.1 节的讨论）。

权重被随机初始化为某些 `small values`（较小值）。为此，已经开发了许多不同的方案，这从使用标准相关软件包时提供的众多选项中可见一斑。

例如，如果使用压缩类型的激活函数并分配较大的初始值，则所有激活函数都将在其饱和点处工作。这会将梯度驱动至非常小的值，进而减慢收敛。当权重初始化为非常小的值时，对梯度的影响是相同的。初始化必须使每个神经元的运算发生在激活函数图的（近似）线性区域，而不是饱和区域。可以证明（[113]，问题 18.4），如果输入变量预处理为零均值和单位方差，并使用前述讨论参数值的双曲正切函数，则初始化权重的最佳选择是从零均值和标准差等于以下值的分布中抽取数值赋予权重：

```
σ = m_in^(-1/2)
```

其中 `m_in` 是相应神经元中的输入（突触连接）数量。

初始化期间的一个关键问题是所谓的神经元间 `symmetry breaking`（对称性打破）。很容易证明，如果两个隐藏神经元使用相同的激活函数（通常情况如此）并连接到相同的输入，那么如果它们用相同的值初始化，它们的梯度将相等，且在下降迭代后其更新值将保持相等。毫无疑问，这是一种导致冗余的不良效应。这就是为什么将所有初始值设为零不是一个好习惯。随机初始化有助于避免此类情况。另一方面，试图避免大值符合试图避免所谓的 `exploding gradient phenomenon`（梯度爆炸现象），这是反向传播固有的（见第 18.6 节）。因此，建议从较小的随机值开始。

为实现上述目的，可能的方案包括均匀分布或高斯分布。例如，文献 [50] 建议通过均匀分布初始化权重

$\\theta\_{ij}^{r} \\sim \\mathcal{U}\\left( - \\sqrt{\\frac{6}{m\_{in} + m\_{out}}},\\ \\ \\sqrt{\\frac{6}{m\_{in} + m\_{out}}}\\ \\right)$,

其中 $m\_{in}$ 和 $m\_{out}$ 分别是相应层 $r$ 的输入数和输出数。该启发式方法背后的目标是将所有层初始化为具有相同的激活方差和相同的梯度方差。然而，该推导基于线性单元的假设。上述方法也存在许多变体，例如，从 $\\mathcal{U}( - \\frac{1}{\\sqrt{m\_{in}}},\\ \\frac{1}{\\sqrt{m\_{in}}})$ 中抽取样本。此外，也可以使用相同方差的零均值高斯分布，有时则使用截断高斯分布。与权重相反，偏置可以设置为零，这似乎是最常用的场景。

然而，所有这些方法在使用时都应始终保持谨慎，在使用之前，了解其他研究人员在类似情况下之前使用过什么方法是个好主意。此外，还应考虑所采用的非线性类型（参见例如 [68,95]）。在文献 [68] 中，权重的初始化仅考虑了前一层的大小。更具体地说，建议从方差为 $2/m\_{in}$ 的零均值（截断）高斯分布中抽取样本。据报道，当采用修正线性单元（第 18.6.1 节）时，后者更为合适。对于双曲正切非线性，前面提到的均匀分布似乎是更流行的选择。

#### 批量归一化

与单层模型相比，训练多层结构的一个主要区别在于，随着前几层参数的迭代更新，每一层的输入分布在训练过程中会发生变化。这通过要求使用更低的学习率/步长，拖慢了训练过程。此外，它使得训练对参数初始化变得敏感，特别是在存在饱和非线性的情况下。

解决和应对此类现象的一种方法是采用所谓的*批量归一化* [86]。正如已经讨论过的，在预处理期间，建议将输入变量缩放到零均值附近的单位方差，以避免各个输入值的动态范围存在较大差异。批量归一化受此事实启发，试图在所有层中对网络产生的激活值施加这种缩放。基本思想存在不同的变体。例如，一些方法在非线性之前应用归一化，一些则在之后。我们将采用后一种选项来演示该方法。

参考图 18.11，让我们考虑第 $j$ 个神经元的输出 $y\_j$，为了表示简便，表示相应层 $r$ 的上标已被省略。激活 $y\_j$ 构成了下一层 $r + 1$ 所有神经元的输入。此外，假设使用大小为 $K$ 的小批量。在更新参数至下降方向之前，当正在考虑第 $m$ 个小批量时，会跟踪相应激活的所有值，并计算其样本均值和相应方差：

$$

\mu_{j}^{(m)} = \frac{1}{K}\sum_{k = 1}^{K}y_{j}^{(k)},\quad \sigma_{j}^{(m)} = \sqrt{\frac{1}{K}\sum_{k = 1}^{K}\left( y_{j}^{(k)} - \mu_{j}^{(m)} \right)^{2}},

$$

![Equation](img/si249.png)

其中 $y_{j}^{(k)}$ 是第 $j$ 个神经元在由第 $m$ 个小批次的第 $k$ 个样本激发时的响应。随后计算对应的归一化激活值：

$$

\widehat{y}_{j}^{(k)} = \frac{y_{j}^{(k)} - \mu_{j}^{(m)}}{\sigma_{j}^{(m)}}.

$$

![Equation](img/si251.png) (18.36)

简而言之，在将激活值传递给上一层之前，每个激活值都被归一化为零均值、单位方差。

然而，批量归一化更进一步。它不直接使用归一化后的变量，而是施加一个进一步的线性变换，即：

$$

\overline{y}_{j}^{(k)} = \gamma_{j}\widehat{y}_{j}^{(k)} + \beta_{j},

$$

![Equation](img/si252.png) (18.37)

其中 $\gamma_{j}$ 和 $\beta_{j}$ 在反向传播框架中作为额外参数被学习。通过这种方式，我们弥补了归一化隐式地对每个神经元施加的同等对待，并赋予网络单独调整每个神经元表达能力的自由。

事实证明，批量归一化允许使用更高的学习率并加速收敛。此外，据报道它对初始化不那么敏感，也可以充当正则化器 [86]。与批量归一化相关的进一步理论发现可参见，例如 [105]。
