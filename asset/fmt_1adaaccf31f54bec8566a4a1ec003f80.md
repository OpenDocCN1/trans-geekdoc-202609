# 前言

> “Go 是一门开源编程语言，能让构建简单、可靠且高效的软件变得容易。”（摘自 `golang.org` 上的 Go 官方网站）

Go 语言于 2007 年 9 月由 Robert Griesemer、Rob Pike 和 Ken Thompson 在 Google 共同构思，并于 2009 年 11 月正式发布。该语言及其配套工具的设计目标是：表达能力强、编译和执行均高效、且能有效编写可靠健壮的程序。

Go 在表面上类似于 C 语言，和 C 一样，它是专业程序员的工具，以最小的代价达到最大的效果。但它远不止是 C 语言的更新版。它从许多其他语言中借鉴并改良了优秀的思想，同时避免了导致复杂性和不可靠代码的特性。其并发机制新颖高效，其对数据抽象和面向对象编程的处理方式异常灵活。它拥有自动内存管理，即`垃圾回收`。

Go 特别适合构建网络服务器等基础设施，以及面向程序员的工具和系统，但它确实是一门通用语言，应用领域广泛，涵盖图形学、移动应用和机器学习等多个领域。它因能在表达力与安全性之间取得平衡，而成为无类型脚本语言的热门替代品：Go 程序的运行速度通常快于动态语言编写的程序，且因意外类型错误导致崩溃的情况少得多。

Go 是一个开源项目，因此其编译器、库和工具的源代码可免费供任何人获取。项目贡献来自活跃的全球社区。Go 可在类 Unix 系统——Linux、FreeBSD、OpenBSD、Mac OS X——以及 Plan 9 和 Microsoft Windows 上运行。在其中一个环境中编写的程序通常无需修改即可在其他环境中工作。

本书旨在帮助你立即开始高效地使用 Go，并用好它，充分利用 Go 的语言特性和标准库编写清晰、地道且高效的程序。

## Go 的起源

正如生物物种一样，成功的语言会衍生出融合祖先优势的后代；杂交有时会带来意想不到的优势；极少数情况下，会出现没有先例的激进新特性。通过审视这些影响，我们可以深入了解一门语言为何呈现当前形态，以及它适应怎样的环境。

![](img/influences.png)

Go 有时被描述为“类 C 语言”，或“21 世纪的 C 语言”。从 C 语言，Go 继承了表达式语法、控制流语句、基本数据类型、按值调用参数传递、指针，最重要的是，继承了 C 语言对编译生成高效机器代码的程序的重视，以及与当前操作系统抽象自然协作的特性。

但 Go 的家族树中还有其他祖先。一条主要的影响脉络来自 Niklaus Wirth 的语言系列，始于 Pascal。Modula-2 启发了包的概念。Oberon 消除了模块接口文件和模块实现文件的区别。Oberon-2 影响了包、导入和声明的语法，而 Object Oberon 提供了方法声明的语法。

Go 祖先的另一个谱系，也是让 Go 在近期编程语言中独树一帜的原因，是一系列在贝尔实验室开发的鲜为人知的研究语言，它们都受到 Tony Hoare 1978 年关于并发基础的开创性论文中`通信顺序进程`（CSP）概念的启发。在 CSP 中，程序是由没有共享状态的进程并行组合而成的；进程通过通道进行通信和同步。但 Hoare 的 CSP 是一种用于描述并发基本概念的形式化语言，而非用于编写可执行程序的编程语言。

Rob Pike 等人开始尝试将 CSP 实现为实际的语言。第一个称为 Squeak（“一种与鼠标通信的语言”），它提供了一种处理鼠标和键盘事件的语言，具有静态创建的通道。随后是 Newsqueak，它提供了类 C 的语句和表达式语法以及类 Pascal 的类型表示法。它是一门带有垃圾回收的纯函数式语言，同样旨在管理键盘、鼠标和窗口事件。通道成为了第一类值，可动态创建并存储在变量中。

Plan 9 操作系统通过一种名为 Alef 的语言延续了这些思想。Alef 试图使 Newsqueak 成为一门可行的系统编程语言，但其缺少垃圾回收使得并发编程过于痛苦。

Go 中的其他构造也在各处显示出非祖先基因的影响；例如 `iota` 大致源自 APL，带嵌套函数的词法作用域源自 Scheme（以及此后的大多数语言）。这里也能发现新颖的变异。Go 创新的切片提供了具有高效随机访问的动态数组，同时也允许类似链表的复杂共享安排。而 `defer` 语句是 Go 独有的新特性。

## Go 项目

所有编程语言都反映了其创造者的编程理念，这通常包含对早期语言感知缺陷的显著反应。Go 项目源于对 Google 内部多个软件系统复杂性爆炸的挫败感。（这一问题绝非 Google 独有。）

正如 Rob Pike 所言，“复杂性是可乘的”：通过让系统的某一部分变得更复杂来修复问题，会缓慢但坚定地给其他部分增加复杂性。在不断增加功能、选项、配置以及快速交付代码的持续压力下，很容易忽视简洁性，尽管从长远来看，简洁性是优秀软件的关键。

简洁性要求在项目开始时投入更多工作将想法提炼到本质，并在项目生命周期中保持更多自律，以区分好的变更与坏的或有害的变更。付出足够的努力，好的变更可以在不妨碍 Fred Brooks 所谓的设计“概念完整性”的前提下被接纳，但坏的变更不能，而有害的变更则以便利性为名牺牲了简洁性。只有通过设计的简洁性，系统才能在增长过程中保持稳定、安全和连贯。

Go 项目不仅包含语言本身、其工具和标准库，最后但同样重要的是，还包含一种激进简洁的文化议程。作为一门较新的高级语言，Go 具有后见之明的优势，基础做得很好：它拥有垃圾回收、包系统、一等函数、词法作用域、系统调用接口，以及文本通常以 UTF-8 编码的不可变字符串。但它的特性相对较少，也不太可能增加更多。例如，它没有隐式数值转换、没有构造函数或析构函数、没有运算符重载、没有默认参数值、没有继承、没有泛型、没有异常、没有宏、没有函数注解，也没有线程局部存储。语言成熟稳定，并保证向后兼容性：旧的 Go 程序可以用更新版本的编译器和标准库进行编译和运行。

# Go 语言概述

Go 拥有足够完善的类型系统，能避免动态语言中常见的粗心错误，但其类型系统比同类型的静态语言更简单。这种设计有时会在更广泛的类型框架内形成孤立的“非类型化”编程区域，Go 程序员不会像 C++ 或 Haskell 程序员那样，费尽心力将安全属性表达为基于类型的证明。但在实践中，Go 在不增加复杂类型系统负担的情况下，提供了相对强类型系统的大部分安全性和运行时性能优势。

Go 鼓励程序员关注现代计算机系统设计，特别是局部性的重要性。其内置数据类型和大多数库数据结构的设计旨在自然工作，无需显式初始化或隐式构造函数，因此代码中隐藏的内存分配和内存写入相对较少。Go 的聚合类型（结构体和数组）直接持有其元素，相比使用间接字段的语言，需要更少的存储空间、更少的分配和更少的指针间接寻址。既然现代计算机是并行机器，Go 基于 CSP（通信顺序进程）提供了并发特性。Go 的轻量级线程（`goroutines`）具有可变大小的栈，初始大小足够小，使得创建一个 `goroutine` 开销很低，创建百万个也切实可行。

Go 的标准库常被描述为“开箱即用”，为 I/O、文本处理、图形、加密、网络和分布式应用提供了整洁的构建块和 API，并支持许多标准文件格式和协议。库和工具广泛使用约定来减少配置和解释的需求，从而简化程序逻辑，使不同的 Go 程序更加相似，也更易于学习。使用 `go` 工具构建的项目，仅通过文件名、标识符名和偶尔的特殊注释，即可确定项目的所有库、可执行文件、测试、基准测试、示例、平台特定变体和文档；Go 源代码本身即包含构建规范。

## 书籍结构

我们假设您已掌握一门或多门其他编程语言，无论是编译型的（如 C、C++、Java）还是解释型的（如 Python、Ruby、JavaScript），因此我们不会像面对完全初学者那样事无巨细地解释。表面语法、变量和常量、表达式、控制流及函数对您都应当熟悉。

- 第 1 章 是 Go 基本构造的教程，通过十余个处理日常任务的程序（如读写文件、格式化文本、创建图像、与互联网客户端和服务器通信）进行介绍。

- 第 2 章 描述 Go 程序的结构元素——声明、变量、新类型、包和文件以及作用域。

- 第 3 章 讨论数字、布尔值、字符串和常量，并解释如何处理 Unicode。

- 第 4 章 描述复合类型，即使用数组、映射、结构体和 `slices`（切片，Go 语言处理动态列表的方法）由简单类型构建而成的类型。

- 第 5 章 涵盖函数，并讨论错误处理、`panic` 和 `recover` 以及 `defer` 语句。

第 1 章至第 5 章涵盖了基础内容，这些是任何主流命令式语言的组成部分。Go 的语法和风格有时与其他语言不同，但大多数程序员能快速上手。剩余章节聚焦于 Go 方法较不传统的主题：方法、接口、并发、包、测试和反射。

Go 对面向对象编程有独特的见解。没有类层次结构，甚至没有类；复杂对象行为通过组合而非继承从简单行为创建而成。方法可关联到任何用户定义类型，而不仅限于结构体，具体类型与抽象类型（`interfaces`，接口）的关系是隐式的，因此具体类型可能满足其设计者未曾知晓的接口。方法在 第 6 章 介绍，接口在 第 7 章 介绍。

- 第 8 章 展示 Go 的并发方法，基于通信顺序进程（CSP）思想，由 `goroutines` 和 `channels`（通道）体现。

- 第 9 章 解释基于共享变量的更传统的并发方面。

- 第 10 章 描述包——组织库的机制。本章还展示如何有效使用 `go` 工具，它在单个命令内提供编译、测试、基准测试、程序格式化、文档生成等众多任务。

- 第 11 章 讨论测试，Go 采用显著的轻量级方法，避免充满抽象的框架，青睐简单的库和工具。测试库提供了基础，必要时可在其上构建更复杂的抽象。

- 第 12 章 讨论反射——程序在执行期间检查自身表示的能力。反射是强大工具，但需谨慎使用；本章通过展示其如何实现一些重要的 Go 库，解释如何找到正确的平衡点。

- 第 13 章 解释使用 `unsafe` 包绕过 Go 类型系统进行底层编程的细节，以及何时适用。

每章都包含若干练习，供您测试对 Go 的理解，并探索书中示例的扩展与替代方案。

## 更多信息来源

关于 Go 的最佳信息来源是官方网站 `https://golang.org`，提供文档访问，包括 *Go Programming Language Specification*（Go 编程语言规范）、标准包等。还有编写 Go 及编写高质量 Go 代码的教程，以及各类在线文本和视频资源，将成为本书的宝贵补充。Go Blog（`blog.golang.org`）发布了一些关于 Go 的最佳文章，涵盖语言现状、未来规划、会议报告，以及各类 Go 相关主题的深度解析。

在线访问 Go 语言资源最有用的特性之一（而这也是纸质书籍令人遗憾的局限性）在于：可以直接运行网页中描述的 Go 程序。该功能由 `play.golang.org` 上的 Go Playground 提供，并可嵌入其他页面中，例如 `golang.org` 的主页或 `godoc` 工具提供的文档页面。

Playground 让用户能方便地进行简单实验，通过编写短程序来验证对语法、语义或库包的理解，在许多方面取代了其他语言中的“读取-求值-打印循环”（REPL）。其持久化的 URL 非常适合与他人分享 Go 代码片段、报告 Bug 或提出建议。

Go Tour（`tour.golang.org`）构建于 Playground 之上，由一系列简短的互动课程组成，涵盖 Go 语言的基本概念和结构，引导读者有序地了解该语言。

Playground 和 Tour 的主要短板是：它们只允许导入标准库，且出于实际或安全考虑，许多库特性（例如网络功能）受到限制。它们还需要联网才能编译和运行每个程序。因此，对于更复杂的实验，你必须在自己的计算机上运行 Go 程序。幸运的是，下载过程非常简单，从 `golang.org` 获取 Go 发行版并开始编写和运行自己的 Go 程序，通常只需几分钟。

由于 Go 是一个开源项目，你可以在 `https://golang.org/pkg` 在线阅读标准库中任意类型或函数的源代码；这些代码也包含在下载的发行版中。利用这一点可以弄清某事物的工作原理，解答关于细节的疑问，或者仅仅是看看专家是如何编写高质量 Go 代码的。

# 1. 教程

本章将带领大家游览 Go 语言的基本组成部分。我们希望提供足够的信息和示例，帮助你快速上手并尽早做出实用的东西。本书中的示例（包括本章）都针对你在现实世界中可能遇到的任务。在本章中，我们将尝试让你领略用 Go 编写程序的多样性，范围涵盖从简单的文件处理和图形绘制到并发的互联网客户端和服务器。我们当然不会在第一章解释所有内容，但在一门新语言中研究此类程序是一个有效的入门途径。

学习一门新语言时，人们自然倾向于用已熟知语言的风格来编写代码。学习 Go 时请留意这种偏见，并尽量避免。我们已努力阐释和解释如何编写地道的 Go 代码，因此在编写自己的代码时，请以此处的代码为指南。

## 1.1 Hello, World

我们将从经典的“hello, world”示例开始，它最早出现在 1978 年出版的《C 程序设计语言》开头。C 语言是 Go 语言最直接的影响来源之一，“hello, world”展示了许多核心概念。

点击此处查看代码图片

gopl.io/ch1/helloworld

```
package main

import "fmt"

func main() {
    fmt.Println("Hello, ")
}
```

Go 是一门编译型语言。Go 工具链将源程序及其依赖转换为计算机原生机器语言的指令。这些工具通过一个名为 `go` 的单一命令访问，该命令包含若干子命令。最简单的子命令是 `run`，它编译一个或多个以 `.go` 结尾的源文件，将其与库链接，然后运行生成的可执行文件。（全书统一使用 `$` 作为命令提示符。）

```
$ go run helloworld.go
```

不出所料，这将打印

