
# 信任路径（Trusted Path）

一种允许用户（通过输入设备）直接与信息系统的安全功能通信的机制，并具有足够的信任度来支持系统安全策略。该机制只能由用户或信息系统的安全功能激活，不能被不可信的软件模仿。

# 漏洞（Vulnerability）

信息系统、系统安全程序、内部控制或实施中的缺陷，这些缺陷可能被威胁源利用或触发。

# 漏洞评估（Vulnerability Assessment）

对信息系统中漏洞的正式描述和评估。
