
##### 错误答案及解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。`Sashimi`、`Spiral`（螺旋模型）和 `Waterfall`（瀑布模型）是软件开发方法论，它们不描述开发人员直接支持运维的模型。

#### 5. 在系统开发生命周期（SDLC）的哪个阶段，安全应成为流程的一部分？

1.  A. 启动前
2.  B. 开发/获取期间
3.  C. 系统实施时
4.  D. SDLC 不包含安全流程

##### 正确答案及解析：A

答案 `A` 正确；安全是整个 `SDLC` 流程的关键组成部分，通常始于启动前的安全计划。

##### 错误答案及解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。安全是 `SDLC` 的第一步，也是 `SDLC` 每个阶段的一部分。

#### 6. 一个对象根据输入消息的上下文不同而表现出不同的行为。这说明了面向对象编程的哪个概念？

1.  A. 委托
2.  B. 继承
3.  C. 多实例化
4.  D. 多态

##### 正确答案及解析：D

答案 `D` 正确；多态（基于希腊词根“poly”和“morph”，分别意为“多”和“形”）：允许重载运算符，根据输入消息的上下文执行不同的方法。

##### 错误答案及解析：A、B 和 C

答案 `A`、`B` 和 `C` 不正确。委托允许对象将消息委托给其他对象。继承意味着对象从其父类继承能力。多实例化意为“多个实例”，即两个名称相同但数据不同的对象。

#### 7. 两个同名对象拥有不同的数据。这说明了面向对象编程的哪个概念？

1.  A. 委托
2.  B. 继承
3.  C. 多实例化
4.  D. 多态

##### 正确答案及解析：C

答案 `C` 正确；多实例化意为“多个实例”，即两个名称相同但拥有不同数据的对象。

##### 错误答案及解析：A、B 和 D

答案 `A`、`B` 和 `D` 不正确。委托允许对象将消息委托给其他对象。继承意味着对象从其父类继承能力。多态允许重载运算符，根据输入消息的上下文执行不同的方法。

#### 8. 什么敏捷方法可以自动化系统管理任务，包括服务器部署和配置管理？

1.  A. 软件配置管理（SCM）
2.  B. 安全编排、自动化与响应（SOAR）
3.  C. 持续集成和持续交付（CI/CD）
4.  D. 集成开发环境（IDE）

##### 正确答案及解析：A

答案 `A` 正确；软件配置管理（`SCM`）是一种敏捷方法，可自动化系统管理任务，包括服务器部署和配置管理。

##### 错误答案及解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。安全编排、自动化与响应（`SOAR`）是一种用于集中管理安全运营的敏捷方法论。持续集成和持续交付（`CI/CD`）专注于通过流水线快速部署代码更新。集成开发环境（`IDE`）通过为程序员提供一个可执行多种功能的单一界面来提高生产力。

#### 9. 程序员为用户名变量分配了 20 字节，攻击者输入了一个 1000 字节长的用户名。所有 1000 字节都被复制到了栈中。攻击者执行了哪种类型的攻击？

1.  A. 缓冲区溢出
2.  B. 跨站脚本攻击（XSS）
3.  C. 模糊测试
4.  D. 检查时间/使用时间（TOC/TOU）

##### 正确答案及解析：A

答案 `A` 正确；当程序员未执行变量边界检查时，会发生缓冲区溢出。

##### 错误答案及解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。跨站脚本攻击（`XSS`）利用第三方在受信任站点的安全上下文中执行 Web 脚本语言（如 `JavaScript`）。模糊测试是一种黑盒软件测试形式，将随机畸形数据作为输入输入软件程序以确定其是否会崩溃。检查时间/使用时间（`TOCTOU`）攻击也称为竞争条件：攻击者试图在操作系统检查条件后、使用条件前修改该条件。

#### 10. 哪种数据库语言用于创建、修改和删除表？

1.  A. 数据定义语言（DDL）
2.  B. 数据操作语言（DML）
3.  C. 数据库管理系统（DBMS）
4.  D. 结构化查询语言（SQL）

##### 正确答案及解析：A

答案 `A` 正确；数据定义语言（`DDL`）用于创建、修改和删除表。

##### 错误答案及解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。数据操作语言（`DML`）用于查询和更新存储在表中的数据。数据库管理系统（`DBMS`）管理数据库系统并提供安全功能。结构化查询语言（`SQL`）是一种数据库查询语言，包含 `DDL` 和 `DML`。`DDL` 比 `SQL` 更具体，或者它是本题更好的答案。

#### 11. 一个数据库包含一个主键为空的条目。违反了哪个数据库概念？

1. A. 实体完整性
2. B. 规范化
3. C. 参照完整性
4. D. 语义完整性

##### 正确答案及解析：A

答案 `A` 正确；实体完整性意味着每个元组都有一个非空的唯一主键。

##### 错误答案及解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。规范化旨在使数据库表中的数据在逻辑上简洁、有序且一致。参照完整性意味着辅助表中的每个外键都与父表中的一个主键匹配：如果不成立，则参照完整性已被破坏。语义完整性意味着每个属性（列）的值与属性数据类型一致。

#### 12. 哪种漏洞允许第三方在受信任站点的安全上下文中重定向静态内容？

1. A. 跨站请求伪造 (CSRF)
2. B. 跨站脚本攻击 (XSS)
3. C. PHP 远程文件包含 (RFI)
4. D. SQL 注入

##### 正确答案及解析：A

答案 `A` 正确；跨站请求伪造（`CSRF`）允许第三方在受信任站点的安全上下文中重定向静态内容。

##### 错误答案及解析：B、C 和 D

答案 `B`、`C` 和 `D` 不正确。跨站脚本攻击（`XSS`）：第三方在受信任站点的安全上下文中执行 Web 脚本语言（如 `Javascript`）。`XSS` 与 `CSRF` 相似；区别在于 `XSS` 使用主动代码。`PHP` 远程文件包含（`RFI`）：篡改正常的 `PHP` 变量以引用远程内容，可能导致恶意 `PHP` 代码的执行。`SQL` 注入通过前端 `Web` 服务器操纵后端 `SQL` 服务器。

#### 13. 哪种语言允许 CORBA（公共对象请求代理体系结构）对象通过消息接口进行通信？

1. A. 分布式组件对象模型 (DCOM)
2. B. 接口定义语言 (IDL)
3. C. 对象链接与嵌入 (OLE)
4. D. 对象管理指南 (OMG)

##### 正确答案及解析：B

答案 `B` 正确；接口定义语言（`IDL`）允许 `CORBA` 对象通过消息接口进行通信。

##### 错误答案及解析：A、C 和 D

答案 `A`、`C` 和 `D` 不正确。`DCOM`（分布式组件对象模型）是一种 `Microsoft` 对象代理，用于在网络上定位对象。对象链接与嵌入（`OLE`）是 `DCOM` 的一部分，提供了一种将文档链接到其他文档的方式。对象管理指南是一个干扰项，利用了 `OMG` 这个术语：对象管理组（`OMG`）开发了 `CORBA`。

#### 14. 哪种数据库高可用性选项允许多个客户端同时访问多个数据库服务器？

1. A. 数据库提交
2. B. 数据库日志
3. C. 复制数据库
4. D. 影子数据库

##### 正确答案及解析：C

答案 `C` 正确；数据库复制镜像一个活动数据库，允许客户端对多个复制数据库进行同时读写。

##### 错误答案及解析：A、B 和 D

答案 `A`、`B` 和 `D` 不正确。`DBMS` 可能会尝试提交更新：使挂起的更改永久化。数据库日志是所有数据库事务的日志。影子数据库类似于复制数据库，但有一个关键区别：影子数据库镜像主数据库的所有更改，但客户端不访问影子数据库。

#### 15. 专家系统的哪个组件由“如果/那么”语句组成？

1. A. 逆向链接
2. B. 正向链接
3. C. 推理引擎
4. D. 知识库

##### 正确答案及解析：D

答案 `D` 正确；知识库由“如果/那么”语句组成。这些语句包含专家系统用于做决策的规则。

##### 错误答案及解析：A、B 和 C

答案 `A`、`B` 和 `C` 不正确。正向链接从无前提开始，向前工作以确定解决方案。逆向链接从一个前提开始，向后工作。推理引擎遵循由知识库形成的树，并在匹配时触发规则。
