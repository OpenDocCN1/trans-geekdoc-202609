
## Auxiliary Classifier GAN (AC-GAN) [137]

Proposed the concept of an auxiliary classifier. The class conditional encoding vector `c` augments the input to the generator. The discriminator receives real/fake samples as input and provides two types of predictions: judging whether the input is real or fake, and estimating the corresponding class probabilities. For an `M` classification task, the discriminator has `M + 1` outputs: one for real/fake prediction, and `M` for class probabilities. This is claimed to produce higher quality samples by adding more structure to the GAN latent space.

## Information Maximizing GAN (InfoGAN) [33]

Unlike conditional GANs and AC-GANs that rely on predefined conditional information `c`, the input to the InfoGAN generator contains two vectors: one for random noise `z`, and one for random attributes `c`. The discriminator receives real/fake samples and outputs two types of results: a) predicting whether the sample is real or fake; b) estimating the conditional attribute sample `c` of the input. In this way, InfoGAN attempts to identify and disentangle salient attributes in a completely unsupervised manner. For example, InfoGAN is claimed to successfully disentangle writing style from digit shape on the MNIST dataset, and pose from lighting in 3D rendered images.

## StyleGAN [100]

The core idea is to learn to separate high-level attributes (such as pose and identity of a face) from low-level/stochastic variation attributes (such as hair, freckles) in a completely unsupervised manner. To this end, it uses two sets of (latent) random vectors: one for noise (e.g., `z`), and one for style (e.g., `w`). Furthermore, this information is not fed directly into the network but is injected into the intermediate layers of the generator (at different scales). In this way, the generator adjusts various image features at different scales, adjusting the "style" of the image at each convolutional layer. The input to the generator starts from a learnable constant. The style random variable `w` is produced by the output of a separate fully connected neural network, whose input is driven by another set of random variables. The rationale for this nonlinear mapping is to allow the network to learn to disentangle the various aspects of style, so that each dimension of the style variable corresponds to an independent real-world attribute (e.g., head pose or lighting).

Interestingly, many of the above innovations have been adopted in diffusion models, see Section 19.7.

Besides generating images, GANs have also been used as generative models for other modalities such as audio, video, EEG, molecular graphs, etc., see [67].

## Example 19.1: Basic Experiment for Generating Handwritten Character Images

This example aims to describe a basic experiment using a GAN to generate handwritten character images. For this, the generator and discriminator networks need to be designed.

### Generator Network

Contains 100 input nodes, driven by i.i.d. Gaussian noise samples with zero mean and unit variance. The network contains three hidden layers with 256, 512, and 1024 neurons, respectively. The nonlinear function used by the hidden layer neurons is Leaky ReLU (see Section 18.6.1), `α = 0.2`. The output layer has 784 units, with the output nonlinear function being the tanh function. The number of output units is set equal to the dimension of the vectorized images in the MNIST image dataset.^(¹³¹)

### Discriminator Network

判别器拥有 784 个输入节点，以匹配与 28 × 28 MNIST 图像相关的 1 × 784 尺寸向量。判别器由三个隐藏层组成，分别包含 1024、512 和 256 个神经元。带有 `α = 0.2` 的 Leaky ReLU 单元被用作隐藏层神经元的激活函数。输出是一个单一的二元 Sigmoid 节点，代价函数为二分类交叉熵函数（公式 (18.44)）。在训练过程中，采用了 Dropout 方法，丢弃隐藏神经元的概率设为 0.3。训练使用了 Adam 优化器（习题 19.9）。输入图像被归一化到 [−1, 1] 范围内。用于训练的图像数量为 60000 张，小批量的大小等于 100。

## 19.2.6 变分自编码器

GANs 的核心在于这样一个概念：通过用随机噪声向量 `z` 的对应样本 `z[n]` 激发生成器网络，来生成随机向量 `x` 的样本 `x[n]`，`n = 1, 2, …`。此外，请回顾 GANs 并不涉及任何显式的概率论证。相比之下，*变分自编码器*（VAEs）是概率生成模型。此外，在这种情况下被称为解码器的生成器，是由其后验概率密度函数（PDF）已从数据中*学习*到的随机变量所激发的。训练建立在贝叶斯学习论证之上；请参见第 12 章和第 13 章。变分自编码器最早由文献 [103] 和 [154] 提出。

VAEs 背后的基本假设是：我们得到一组观测值 `x[n]`，`n = 1, 2, …, N`，它们是随机向量 `x ∈ ℝ^(l)` 的样本。此外，后者是另一个过程的结果，该过程涉及一组*潜在*随机变量 `z ∈ ℝ^(m)`，通常 `m ≪ l`。也就是说，VAEs 属于更广泛的生成机制范畴，其底层生成机制沿着以下步骤演变：

*   根据某个概率密度函数 `p(z; θ)` 生成一个样本 `z[n]`，其中 `θ` 是一组未知参数。
*   根据条件概率密度函数 `p(x|z[n]; θ)` 生成一个样本 `x[n]`。

正如我们从贝叶斯相关章节所知，在存在潜在（未观测）变量的情况下，估计一组参数 `θ` 的一种方法是通过 EM 算法。应用该算法的前提是知道后验概率 `p(z|x)`；这对于对（未知的）潜在变量进行平均化是必需的。通常情况下，此后验概率不可用（或 EM 计算所需的积分在计算上可能难以处理），因此必须求助于近似。在第 13 章中，在均场近似框架下采用了因子分解形式。相比之下，根据 VAEs，后验概率的近似 `q(z|x; ϕ)` 是通过神经网络来实现的；向量 `ϕ` 表示一组未知参数，它们必须与 `θ` 一起被学习。

### 变分自编码器 (VAE) 组件

在 VAE 的术语中，`q(z|x; ϕ)` 被称为概率**编码器**；确实，给定一个观测值 `x`，它会生成 `z` 可能取值的分布（例如高斯分布），`z` 也被称为**编码**。另一方面，`p(x|z; θ)` 被称为概率**解码器**；给定一个编码 `z`，它会生成对应的 `x` 可能取值的分布。与第 19.2.4 节中讨论的自编码器的主要区别在于，在变分自编码器的语境下，编码器的设计目的不是为每个输入变量输出*单个值*；相反，它旨在提供相应的*概率分布*。解码器也是如此。

VAE 背后的概念现在应该已经很清楚了。一旦我们学习了与后验和条件分布的近似模型相关的参数 `ϕ` 和 `θ`，我们就可以生成新样本：生成潜变量的样本 `z[n]`，随后利用这些样本通过从学习到的条件分布 `p(x|z[n]; θ)` 中采样来生成样本。现在剩下的就是 a) 为条件分布 `p(x|z; θ)` 和后验近似 `q(z|x; ϕ)` 采用显式的参数化模型，以及 b) 确定估计未知参数的方法。

#### 参数化模型

文献 [103] 中提出了以下模型：

*   **对于先验**，采用标准多元高斯分布，即 `p(z) = N(z|0, I)`。因此，根据这种选择，先验不依赖于任何参数。
*   **对于后验近似**，`q(z|x; ϕ)`，也选择多元高斯分布，具有对角协方差矩阵（`Σ[n] = diag{σ[ni]²}[i=1]^(m)`），即
    `q(z|x[n]; ϕ) = N(z|μ[n], Σ[n])`。
*   这里的关键点在于，上述均值和方差作为编码网络的输出提供；在最简单的情况下，采用单隐藏层网络（也可以考虑更深的网络和其他变体）。更具体地说，

```
h[n] = tanh(W[1]x[n] + b[1])
```

(19.18)

```
μ[n] = W[2]h[n] + b[2]
ln σ[n]² = W[3]h[n] + b[3]
```

其中 `ln σ[n]²` 表示对由方差组成的向量进行逐元素操作。因此，参数 `ϕ` 包含定义网络的所有参数集合，即 `W[1]`, `W[2]`, `W[3]`, `b[1]`, `b[2]`, `b[3]`，它们分别是维度适当的矩阵和偏置向量。注意，为了保证方差取非负值，我们对其对数进行建模。然后，可通过指数运算获得其值。

*   对于条件 PDF，如果它也是高斯分布，则使用与上述类似的模型，其中 `x` 和 `z` 的角色互换，且 `θ` 包含相关解码器网络的参数。另一方面，如果观测值具有离散性质，则应使用不同的模型。例如，对于二值图像，可以采用伯努利分布来实现解码器网络，例如 [103]。

图 19.7 展示了 VAE 的架构。对于每个观测值 `x[n]`，编码器网络输出相应的均值和方差，它们定义了相应潜变量 `z[n]` 的特定后验多元高斯 pdf。从后验 pdf 采样，可根据条件在解码器网络的输出端生成与原始输入匹配的样本。

#### 代价函数

遵循第 13 章中的论点，理想情况下应最大化关于未知参数的观测值似然。然而，对于这种情况，似然的计算是不可解的。相反，我们将最大化其相关的*下界*，即公式 (13.1) 和 (13.2)。假设观测值为 i.i.d.，并调整至当前的符号约定，该下界 ℱ 变为，

$$
\ln p(\mathbf{x}_{1},\mathbf{x}_{2},\ldots,\mathbf{x}_{n};\mathbf{\theta}) = \sum\limits_{n = 1}^{N}\ln p(\mathbf{x}_{n};\mathbf{\theta}) \geq \sum\limits_{n = 1}^{N}\mathcal{F}(\mathbf{\theta},\mathbf{\phi};\mathbf{x}_{n}),
$$

![Equation](img/si135.png)

其中

$$
\mathcal{F}(\mathbf{\theta},\mathbf{\phi};\mathbf{x}[n]) := \mathbb{E}_{q}\left[ \ln p(\mathbf{x}[n],\mathbf{z};\mathbf{\theta}) - \ln q(\mathbf{z}|\mathbf{x}[n];\mathbf{\phi}) \right].
$$

![Equation](img/si136.png)(19.21)

请注意，在上式中，我们显式引入了后验 $q(\mathbf{z}|\mathbf{x}[n];\mathbf{\phi})$![Equation](img/si137.png) 的符号，这与公式 (12.63) 中下界的定义形成对比，后者是以潜在函数的任意分布来给出下界的定义。在联合分布项上应用贝叶斯定理并回顾 KL 散度的定义（见公式 (2.161)）后，公式 (19.21) 可重写为，

$$
\mathcal{F}(\mathbf{\theta},\mathbf{\phi};\mathbf{x}_{n}) = \underbrace{\underset{\text{重构项}}{\mathbb{E}_{q}\left[ \ln p(\mathbf{x}_{n}|\mathbf{z};\mathbf{\theta}) \right]}} - \underbrace{\underset{\text{先验匹配项}}{\text{KL}\left( q(\mathbf{z}|\mathbf{x}_{n};\mathbf{\phi})||p(\mathbf{z}) \right)}},
$$

![Equation](img/si138.png)(19.22)

我们假设先验分布不依赖于任何参数。下界包含两项。右侧第一项是关于潜在变量的期望值。为了最大化下界，该项应针对各自的观测值 `x[n]` 进行最大化；这促使解码器学会*重构*数据。第二项是非正的（KL 散度是非负量，见 问题 12.7）。为了最大化下界，应最小化 KL 散度；因此，相应的后验分布将保持接近先验分布；后者被选为标准多元高斯分布 `N(z|0, I)`。因此，先验充当正则化项，将网络的潜在变量“推”向标准高斯分布，使其尽可能紧密地匹配。
