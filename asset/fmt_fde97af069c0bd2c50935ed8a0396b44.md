
为了保持`gSBX`中后代的稀疏性，直观的方法是让后代具有与父代相同或更高的稀疏度。为了实现这一目的，如果父代的变量为零，则`gSBX`将后代的对应变量设置为零。根据`c_1^i = x_1^i = 0`，如果我们设置`alpha_1 = 0`，则提出的`gSBX`进一步修复了`alpha_1`和`alpha_2`。

(9.13)

```
alpha_1 = { 0,               if x_1^i = 0
            alpha_1,         otherwise }
```

以及

(9.14)

```
alpha_2 = { 0,               if x_2^i = 0
            alpha_2,         otherwise. }
```

`gSBX`的主要步骤列在算法 9.1 中。从算法可以看出，从种群`P`中随机选择两个父代`x_1`和`x_2`，用于生成两个后代解`c_1`和`c_2`。对于每一个维度，顺序确定`mu_1`、`mu_2`、`beta_1`、`beta_2`、`alpha_1`以及`alpha_2`，并相应地计算决策变量`c_1^i`和`c_2^i`。`P`中的所有解都经过此过程，所有新生成的解构成了后代种群。
