
图 11.1 展示了一个多流形数据集`{M_1, M_2, M_3, …}`。通过使用幺架投影，我们可以获得一个坐标覆盖`{U, W, V, …}`，其元素由`m`个线性无关的向量组成。随后我们得到一个切空间，即幺架丛中的纵向空间。

我们使用自然坐标`(∂/∂u_1, …, ∂/∂u_m)`来表示流形上的每个坐标邻域。因此，流形上的任意幺架可以表示为

$$X_i^k\left(\frac{\partial}{\partial u^k}\right)_p, 1 \leq i \leq m.$$

其中`(X_i^k)`是一个`m*m`非退化矩阵。

如果流形数据集中存在噪声，数据可能会失去其局部几何特征。因此，算法将不会收敛，且其准确率会下降。在现实世界中，噪声总是存在的。算法对噪声的敏感性阻碍了其广泛应用。

流形学习的理论基础包括以下内容：

1. 当两个样本点足够接近时，它们邻近区域在降维后保持不变。这一假设被称为局部同胚假设。
2. 要求样本点覆盖流形。这一假设被称为密度假设。
3. 通常，我们假设数据集是光滑且连续的。这一假设被称为连续性假设。噪声可能会违背这三个假设，从而产生不准确的结果。

我们构建了一个数据集，并实验性地展示了噪声问题。有两个数据集`N_1(φ_1, E), N_2(φ_2, E)`，且我们有`φ_1 = 1, 1/√3, …, 1/√(2n+1), …, 1/√19`，`φ_2 = -φ_1`。我们采用标准正态分布来验证噪声的影响。噪声的`φ_1`分别等于 0.1, 0.2, 0.5 和 1。这四种情况被分别添加到两个数据集`N_1`和`N_2`中。对于每个数据集，我们抽样了 1000 个点，并采用了`GTM`算法 [2]。实验结果如下所示。

接下来，我们将在理论上分析噪声对流形学习算法的影响。通常，我们主要分析局部线性映射算法。我们假设在`d`维空间`R^d`中存在一个数据集`X = {x_1, x_2, …, x_N}`。对于任意点`x_0`，`U(x_0)`表示`x_0`的邻域。如果我们有`x_1, x_2, …, x_k ∈ U(x_0)`，点`x_0`与其邻居点之间的权重值可以用`w_i`表示，且我们有

$$x_0 = \sum_{i=1}^{k} w^i x_i, \quad \sum_{i=1}^{k} w^i = 1. \quad (11.2)$$

其中`x_i' = x_i + ε_i, (i = 0, 1, 2, …, k)`是受噪声扰动的邻居点，且相应的变换如下：

$$x_0' = \sum_{i=1}^{k} w^{i'} x_i', \quad \sum_{i=1}^{k} w^{i'} = 1. \quad (11.3)$$

这里，我们有`X^0 = (x_1, x_2, …, x_k)`，`X^{0'} = (x_1', x_2', …, x_k')`，`w = (w^1, w^2, …, w^k)^T`，`w' = (w^{1'}, w^{2'}, …, w^{k'})^T`，且

$$x_0 = X^0 w, \quad x_0' = X^{0'} w'. \quad (11.4)$$

通过上述理论分析，我们知道噪声由两种类型组成；一种包含原始样本点的薄弱之处，另一种则完全不属于前一种类型。对于第一种情况，有许多改进方法。许多算法考虑到第一种情况，因为它们无法忽视这种情况。如果我们添加一个正则化项，可以使局部线性嵌入算法更具鲁棒性 [3]。局部切空间对齐算法具有良好的抗噪能力 [4]。局部平滑算法可以被视为使用局部加权算法的预处理方法 [5]。这些改进方法都关注第一种情况。然而，本文采用一种新方法，在保持原有优势的同时消除第二种噪声的影响。本节将此类噪声视为一种新的流形数据结构。我们将噪声从原始样本数据中分离出来并进行处理。因此，我们引入了基于幺架丛的联络学习算法。

## 11.2 基于幺架丛的纵向空间联络学习模型

通常，维数为`m`的流形`M`上不存在全局幺架场。然而，仿射联络是存在的。因此，在幺架丛`P`中存在全局幺架场。我们可以从这个角度处理多个流形结构，这比处理流形`M`更容易。

网格索引是目前的研究热点，`LTMADS`算法是该领域中的一个著名算法 [5, 6]。许多研究都试图提高现有算法的性能。通过使用帧束的全局帧，我们可以改进算法的收敛性，如下所示：

### 算法 11.1：通用算法

- (1) 初始化`k=0`。将`x_0 ∈ R^m`设为初始化点，并设`β > 0`；
- (2) 设`N_k > 0, H_k > 0`；
- (3) 通过均值零构造`Φ_k`和`h_k → H_k`；
- (4) 设`x_t = Ω_k = S_k ∪ {p_k} ∪ Φ_k`，其中`S_k`是以下选择点的集合：
  - a) `f(x_t) < f_k - N_k(h_k)^{1+β}`，
  - b) `x_t`是`Ω_k`中的最优点，并设`k = k+1`；
- (5) 如果`f(x_t) < f_k - N_k(h_k)^{1+β}`，则应设`x_{k+1} = x_t`并转到步骤 3。否则，继续循环并选择`x_{k+1}`为最优点。
- (6) 如果算法收敛，则应终止。否则，转到步骤 2。

### 算法 11.2：流形上的算法

- (1) 初始化`n = k = 0, A_0^m, Δ_0^p`。将`p_0 ∈ M`设为初始化点，并令`β, δ > 0`；
- (2) 令`D_k`；
- (3) 构造`p_t ∈ Ω_k = {S_k} ∪ {p_k} ∪ Φ_k`并令
  - a) `f(p_t) < f_k - δ(Δ_k^m)^{1+β}`，
  - b) `p_t ∈ Ω_k`是最优点。
- (4) 如果`f(p_t) < f_k - δ(Δ_k^m)^{1+β}`，设`k = k+1`且`p_{k+1} = p_t`。更新`A_k^m, Δ_k^p`并转到步骤 2；
- (5) 否则，设`n = p_k`且`k = k+1, n = n+1, p_{k+1} = arg min(f(p_k), f(p_t))`。更新`A_k^m, Δ_k^p`；
- (6) 如果算法收敛，则应返回`p_k`。否则，转到步骤 2。

该算法可以替代传统方法。通过引入流形上的帧结构，可以显著增强传统方法的收敛性。

## 11.3 基于帧束的水平空间连接学习模型

我们提到，定义在流形`M`上的纵向空间场`V`满足 Pfaff 方程`θ^i = 0, 1 ≤ i ≤ m`。在本节中，我们将讨论每个点`P`的切子空间`H`中 Pfaff 方程`θ^j = 0, 1 ≤ i, j ≤ m`的变分形式 [7]。

切空间`T_x(p)`可以分解为每个点`x ∈ p`的直和形式。

$$T_x(p) = V(x) \oplus H(x) \ . \tag{11.6}$$

这里，流形`M`上的水平空间`H(x)`与切空间`T_p(M)(p = π(x))`同构。水平空间`H`在移动`L_a (a ∈ GL(m; R))`下不变，这意味着对于每个点`x ∈ p`，我们有

$$(L_a)_*H(x) = H(L_a(x)) \ . \tag{11.7}$$

由仿射联络`∇`决定的水平空间场`H`始终具有上述两个性质。因此，我们利用这两个性质提出改进的算法。在上一节中，我们介绍了使用纵向空间的全局坐标进行多重流形结构数据分类。我们通过增加计算时间来改进算法性能。整个数据集的维度从`m`变为`m^2`。为改变这一现象，我们采用切空间的水平空间场。因为水平空间场是`m`维的切子空间，我们可以通过降低原始数据集的维度来减少时间复杂度。

### 算法 11.4：基于帧束的水平空间连接学习模型

- (1) 用张量结构表示原始数据集；
- (2) 通过降维算法获得低维嵌入数据集；
- (3) 使数据集中的每个点满足`θ^j_i = 0`，并基于纵向空间模型获得每个点的`m`条线；
- (4) 使用帧束的接触算子将所有切向量移动到同一个帧场中；
- (5) 计算每对点之间的距离。

## 12 谱估计学习

### 12.1 谱估计的概念与定义

谱分析是流形学习中非常重要的一部分。在此简要分析谱分析方法的相关内容。

#### 12.1.1 谱估计方法的研究背景

近年来，谱分析方法在信号处理和图像分割方面取得了良好的成果。因此，谱估计学习方法引起了广泛的关注。作为一种经典的数学分析和代数方法，谱分析方法已经具有完整的理论基础。它在高维数据的低维表示和聚类中有着非常广泛的应用。谱分析在许多无监督学习算法中也发挥着至关重要的作用，如图像分割、数据挖掘、数据压缩和语音识别。因此，谱估计学习方法逐渐成为机器学习研究中的重要技术和解决问题的关键技术。一些研究者提出了基于相似矩阵特征值分解的多种谱聚类方法。这些方法被认为是非常有效的，并且谱聚类和降维方法已经得到了广泛的验证。
