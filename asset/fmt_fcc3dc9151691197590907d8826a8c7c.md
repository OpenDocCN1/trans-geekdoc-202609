
> **图 7-42** 输出门决定当前时刻的新历史信息 $C_t$ 有多少（$\mathbf{H}_t = \mathbf{O}_t \odot \tanh(C_t)$）参与下一时刻的细胞计算

如图 7-43 所示，Cell 由当前记忆单元、遗忘门、输入门和输出门组成。当前计算单元计算当前时刻的激活值 $\tilde{C}_t$，该值由输入数据和上一时刻的隐藏状态决定。遗忘门决定保留多少 $C[t]$，输入门决定当前激活值 $\tilde{C}_t$ 有多少记录在总历史信息 $C[t]$ 中，输出门决定当前时刻的历史记忆 $C[t]$ 有多少参与下一时刻的计算。

> **图 7-43** Cell 由当前记忆单元、遗忘门、输入门和输出门组成

最后，Cell 还从 $\mathbf{H}_t$ 计算当前的输出值 $\mathbf{Z}_t$。

$$\mathbf{Z}_t = \mathbf{H}_t \mathbf{W}_y + \mathbf{b}_y$$

公式 (7-24) 至 (7-30) 构成了 LSTM Cell 的计算过程。

### 7.7.2 LSTM 的反向推导

根据 4.2 节的反向推导公式，如果已知当前时刻损失函数 $\mathcal{L}_t$ 对 $Z_t$ 的梯度 $dZ = \frac{\partial \mathcal{L}_t}{\partial Z_t}$，则可得到损失函数对 $\mathbf{H}_t$、$\mathbf{W}_y$、$\mathbf{b}_y$ 的梯度：

$$\frac{\partial \mathcal{L}_t}{\partial \mathbf{W}_y} = \mathbf{H}_t^T \frac{\partial \mathcal{L}_t}{\partial Z_t} \quad \quad \frac{\partial \mathcal{L}_t}{\partial \mathbf{b}_y} = \text{np.sum}\left(\frac{\partial \mathcal{L}_t}{\partial Z_t}, \text{axis}=0, \text{keepdims}=\text{True}\right) \quad \quad \frac{\partial \mathcal{L}_t}{\partial \mathbf{H}_t} = \frac{\partial \mathcal{L}_t}{\partial Z_t} \mathbf{W}_y^T$$

损失函数关于 $\mathbf{H}_t$ 的梯度还包括来自后续时刻的梯度，所以：

$$\frac{\partial \mathcal{L}}{\partial \mathbf{H}_t} = \frac{\partial \mathcal{L}_t}{\partial Z_t} \mathbf{W}_y^T + \frac{\partial \mathcal{L}^{t-}}{\partial \mathbf{H}_t}$$

同理，损失函数关于 $C_t$ 的梯度也分两部分，一部分来自公式 (7-29) 即输出 $\mathbf{H}_t$，另一部分是 $C_t$ 本身输出到下一时刻的梯度：

$$\frac{\partial \mathcal{L}}{\partial \mathbf{C}_t} = \mathbf{O}_t \odot \tanh'(C_t) \frac{\partial \mathcal{L}_t}{\partial \mathbf{H}_t} + \frac{\partial \mathcal{L}^{t-}}{\partial \mathbf{C}_t}$$

由 $\frac{\partial \mathcal{L}}{\partial \mathbf{H}_t}$ 和公式 (7-29)，可得损失函数关于 $\mathbf{O}_t$ 的梯度：

$$\frac{\partial \mathcal{L}}{\partial \mathbf{O}_t} = \frac{\partial \mathcal{L}}{\partial \mathbf{H}_t} \odot \tanh(C_t)$$

由 $\frac{\partial \mathcal{L}}{\partial \mathbf{C}_t}$ 和公式 (7-27)，可得损失函数关于 $i_t, f_t, C_{t-1}, \tilde{C}_t$ 的梯度：

$$\frac{\partial \mathcal{L}}{\partial \mathbf{I}_t} = \frac{\partial \mathcal{L}}{\partial \mathbf{C}_t} \odot \tilde{C}_t$$

$$\frac{\partial \mathcal{L}}{\partial \mathbf{F}_t} = \frac{\partial \mathcal{L}}{\partial \mathbf{C}_t} \odot C_{t-1}$$

$$\frac{\partial \mathcal{L}}{\partial \tilde{C}_t} = \frac{\partial \mathcal{L}}{\partial \mathbf{C}_t} \odot \mathbf{I}_t$$

$$\frac{\partial \mathcal{L}}{\partial C_{t-1}} = \frac{\partial \mathcal{L}}{\partial \mathbf{C}_t} \odot \mathbf{F}_t$$

令 $ZI_t = (\mathbf{X}_t, \mathbf{H}_{t-1})\mathbf{W}_i + \mathbf{b}_i$，$ZF_t = (\mathbf{X}_t, \mathbf{H}_{t-1})\mathbf{W}_f + \mathbf{b}_f$，$ZO_t = (\mathbf{X}_t, \mathbf{H}_{t-1})\mathbf{W}_o + \mathbf{b}_o$，则可得：

$$\frac{\partial \mathcal{L}}{\partial \mathbf{ZI}_t} = \sigma'(ZI_t) \frac{\partial \mathcal{L}}{\partial \mathbf{I}_t} = \mathbf{I}_t(1 - \mathbf{I}_t) \frac{\partial \mathcal{L}}{\partial \mathbf{I}_t}$$

$$\frac{\partial \mathcal{L}}{\partial \mathbf{ZF}_t} = \sigma'(ZF_t) \frac{\partial \mathcal{L}}{\partial \mathbf{F}_t} = \mathbf{F}_t(1 - \mathbf{F}_t) \frac{\partial \mathcal{L}}{\partial \mathbf{F}_t}$$

$$\frac{\partial \mathcal{L}}{\partial \mathbf{ZO}_t} = \sigma'(ZO_t) \frac{\partial \mathcal{L}}{\partial \mathbf{O}_t} = \mathbf{O}_t(1 - \mathbf{O}_t) \frac{\partial \mathcal{L}}{\partial \mathbf{O}_t}$$

得到 $\frac{\partial \mathcal{L}}{\partial \mathbf{ZI}_t}, \frac{\partial \mathcal{L}}{\partial \mathbf{ZF}_t}, \frac{\partial \mathcal{L}}{\partial \mathbf{ZO}_t}$ 后，可同样求得损失函数关于 $\mathbf{W}_i, \mathbf{W}_f, \mathbf{W}_o, \mathbf{X}_t, \mathbf{H}_{t-1}$ 的梯度。请参考 4.2 节。

### 7.7.3 LSTM 代码实现

LSTM Cell 共有 4 个单元，每个单元类似于非循环神经网络中的神经元，即先计算加权和，再通过激活函数产生非线性输出。最后更新总历史信息 $C_t$ 和状态 $\mathbf{H}_t$。最后，Cell 从 $\mathbf{H}_t$ 计算当前输出值 $y_t$。模型参数包括 4 个单元中需要学习的模型参数，即 $(\mathbf{W}_i, \mathbf{b}_i)$、$(\mathbf{W}_f, \mathbf{b}_f)$、$(\mathbf{W}_o, \mathbf{b}_o)$、$(\mathbf{W}_c, \mathbf{b}_c)$ 以及计算最终输出 $y_t$ 的模型参数 $(\mathbf{W}_y, \mathbf{b}_y)$。

import numpy as np

def lstm_params_init(input_dim, hidden_dim, output_dim, scale=0.01):
    normal = lambda m, n: np.random.randn(m, n) * scale
    two = lambda: (normal(input_dim + hidden_dim, hidden_dim), np.zeros((1, hidden_dim)))

    Wi, bi = two()  # 输入门参数
    Wf, bf = two()  # 遗忘门参数
    Wo, bo = two()  # 输出门参数
    Wc, bc = two()  # 候选细胞状态参数

    Wy = normal(hidden_dim, output_dim)
    by = np.zeros((1, output_dim))

    params = [Wi, bi, Wf, bf, Wo, bo, Wc, bc, Wy, by]
    return params

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def lstm_forward(params, Xs, state):
    [Wi, bi, Wf, bf, Wo, bo, Wc, bc, Wy, by] = params

    (H, C) = state         # 初始状态
    Hs = {}
    Cs = {}
    Zs = []
    Hs[-1] = np.copy(H)
    Cs[-1] = np.copy(C)
    Is = []
    Fs = []
    Os = []
    C_tildas = []

    for t in range(len(Xs)):
        X = Xs[t]
        XH = np.column_stack((X, H))

        if False:
            print("XH.shape", XH.shape)
            print("Wi.shape", Wi.shape)
            break

        I = sigmoid(np.dot(XH, Wi) + bi)
        F = sigmoid(np.dot(XH, Wf) + bf)
        O = sigmoid(np.dot(XH, Wo) + bo)
        C_tilda = np.tanh(np.dot(XH, Wc) + bc)

        C = F * C + I * C_tilda
        H = O * np.tanh(C)  # O * C.tanh() # 输出状态
        Y = np.dot(H, Wy) + by  # 输出

        Zs.append(Y)
        Hs[t] = H
        Cs[t] = C
        Is.append(I)
        Fs.append(F)
        Os.append(O)
        C_tildas.append(C_tilda)

    return Zs, Hs, Cs, (Is, Fs, Os, C_tildas)
```

同样，某一时刻的前向计算也可以作为一个单独的函数使用：

```python
def lstm_forward_step(params, X, H, C):
    [Wi, bi, Wf, bf, Wo, bo, Wc, bc, Wy, by] = params
    XH = np.column_stack((X, H))

    I = sigmoid(np.dot(XH, Wi) + bi)
    F = sigmoid(np.dot(XH, Wf) + bf)
    O = sigmoid(np.dot(XH, Wo) + bo)
    C_tilda = np.tanh(np.dot(XH, Wc) + bc)

    C = F * C + I * C_tilda
    H = O * np.tanh(C)  # O * tanh(C) # 输出状态
    Y = np.dot(H, Wy) + by  # 输出

    return Y, H, C, (I, F, O, C_tilda)
```
