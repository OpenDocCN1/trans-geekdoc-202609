## 第 1 章：学习量子寄存器

- **目标**：学习如何在 Q 中操作量子寄存器。
- **任务**：阅读关于量子寄存器及其在量子算法中应用的材料。

## 第 2 章：实现量子寄存器操作

- **目标**：编写 Q 代码来操控量子寄存器。
- **任务**：创建一个名为 `QuantumRegisters.qs` 的新文件并编写以下 Q 代码：

```qsharp
namespace QuantumRegisters {
  open Microsoft.Quantum.Canon;
  open Microsoft.Quantum.Intrinsic;

  operation RegisterOperations() : Unit {
    using (register = Qubit[4]) {
      ApplyToEach(H, register); // 对寄存器中的所有量子比特应用 Hadamard 门
      CNOT(register[0], register[1]); // 纠缠前两个量子比特
      CNOT(register[2], register[3]); // 纠缠最后两个量子比特

      // 测量量子比特
      let result = MultiM(register);
      Message($"Register operation result: {result");

      // 重置量子比特
      ResetAll(register);
    }
  }
}
```

- **目标**：编写 Q 代码实现量子传态。
- **任务**：创建一个名为 `QuantumTeleportation.qs` 的新文件并编写以下 Q 代码：

```qsharp
namespace QuantumTeleportation {
  open Microsoft.Quantum.Canon;
  open Microsoft.Quantum.Intrinsic;

  operation TeleportQubit() : Unit {
    using (qubits = Qubit[3]) {
      H(qubits[0]);
      CNOT(qubits[0], qubits[1]);
      CNOT(qubits[1], qubits[2]);
      H(qubits[1]);

      // 测量量子比特
      let result = (M(qubits[0]), M(qubits[1]));
      if (result == (One, One)) {
        X(qubits[2]);
        Z(qubits[2]);
      } elif (result == (One, Zero)) {
        X(qubits[2]);
      } elif (result == (Zero, One)) {
        Z(qubits[2]);
      }

      // qubit[0] 的状态现在已传送到 qubit[2]
      Message($"Teleportation result: {result");

      // 重置量子比特
      ResetAll(qubits);
    }
  }
}
```
