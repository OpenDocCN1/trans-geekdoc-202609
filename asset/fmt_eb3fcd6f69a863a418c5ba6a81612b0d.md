### 6.1.4: Residual recognition

The final component of the loss function is the attack classification cross-entropy loss:

```
\begin{array}{r} {\mathcal{L}_{AC}(G) = \underset{I_{c},\delta}{\mathbb{E}}\left\lbrack {- \log\left( \frac{e^{\Psi_{i}(I_{r},I_{c} + \delta)}}{\sum\limits_{j = 1}^{A}e^{\Psi_{j}(I_{r},I_{c} + \delta)}} \right)} \right\rbrack} \\ \end{array}
```
