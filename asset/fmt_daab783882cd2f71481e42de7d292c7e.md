
# 数据增强与迁移学习在组织病理学图像分类中的应用

数据增强是获取足够多样化样本并从图像中学习深度网络的关键步骤。小规模训练数据集可能导致网络过拟合。通常，所需数据量远大于实际可获取的数据量；这在生物医学数据中尤为明显。在这种情况下，数据增强将用于通过修改现有数据集来生成额外的人工数据。

## 分类方法

本节解释了第 1 个实验的方法论。预训练 CNN 的最后三层配置为 1000 个类别。因此，必须对这些层进行微调，以适应新的二分类问题（HNSCC 肿瘤和正常组织学）。为实现这一点，从预训练 CNN 中提取了除最后三层以外的所有层，然后对它们进行重新训练以对头颈肿瘤进行分类。因此，在不断更新最后三层的同时，保留了 CNN 的权重。图 8.2 展示了如何将此方法论应用于 `VGG-16` 模型的示例。

如前所述，我们总共取了 1,424 张图像，通过根据图像输入层的大小调整图像尺寸，将其输入 CNN 模型。`AlexNet` 模型要求输入图像尺寸为 `227 x 227 x 3`，其中 3 为颜色通道数。`VGG`、`GoogLeNet` 和 `ResNet` 架构要求输入图像尺寸为 `224 x 224 x 3`，而 `Incv3` 和 `IncResNet` 模型要求输入图像尺寸为 `229 x 229 x 3`。之后，图像被随机划分为 80% 的训练集（1,140 张图像）和 20% 的测试集（285 张图像），随后进行了旋转（90、180 和 270 度）、水平左右翻转和垂直翻转。沿图像裁剪了尺寸为 `32 x 32` 的小重叠补丁。数据增强通常有助于防止网络过拟合和记忆训练图像的确切细节。

对于迁移学习，除最后一层全连接层外，源模型的所有层均被复制到目标网络中。然后修改最后的全连接层，以使模型适应我们的二分类 HNSCC 分类任务。为了使新层比迁移层学习得更快，可以为全连接层增加学习率因子，并将初始学习率设为 `.0001`。

对于网络训练，所有网络模型均训练了 15 个周期，批量大小为 128。训练采用带动量的随机梯度下降，动量设为 0.90。此处，初始学习率设为 0.0001 作为起点，并在每次更新后递减。程序每三次迭代验证一次网络，并选定 120 次迭代为最大迭代数。为进行公平比较，不同方法使用相同的训练集和测试集进行训练和测试。不同深度学习模型实现的统计性能测量结果汇总于表 8.1。

## 现成特征提取

现成特征提取策略是一种利用预训练网络提取学习到的特征，然后用它们训练第三方分类器的方法，无需在训练上消耗时间和精力。此处，用于执行分类的四种常见机器学习算法包括支持向量机（`SVM`）、k-近邻（`kNN`）、随机森林（`RF`）或全连接单层感知机（`FC`）。深度学习模型被用于构建这些机器学习分类器。

此处我们解释如何从 CNN 全连接层的激活层提取判别特征，然后用它们训练 SVM 分类器，如 `SVM`、`kNN` 和 `RF`，以解决分类问题（HNSCC 肿瘤和正常组织学）。判别特征也可以从 CNN 不同层的激活层提取，然后用于训练 SVM 分类器。图 8.3 描述了如何进行现成特征提取。特征从 `VGG-16` 模型的最后一层连接层（`FC8`）提取。图像数据集被输入分类器以对其进行训练。

## 实验结果与讨论

### 实验设置

八个预训练的 CNN 网络被用于输入四个分类器，性能结果见表 8.4。对于每个分类器，均使用不同八个预训练 CNN 的全连接层提取的特征进行训练。分类器使用线性函数作为核函数，并采用序列最小优化方法寻找分离超平面。我们将其平均核大小设置为 `2.0`。RF 分类器在每种方法生成的特征向量上使用 `50` 棵树进行训练。所有其他参数均未优化，均取自 R 语言中 RF 实现的标准参数。

尽管图像数据集规模较小，但结果显示不同模型间均具有良好的准确率。`AlexNet` 模型实现了高度成功的分类，准确率达 `98.25%`，紧随其后的是 `ResNet50` 和 `ResNet101` 模型，准确率分别为 `97.89%` 和 `96.84%`。但 `VGG16`、`VGG19`、`GoogLeNet` 和 `IncV3` 的分类准确率接近，分别为 `95.44%`、`95.79%`、`95.09%` 和 `93.33%`，而 `IncResNet` 模型表现最差。

在比较八种方法的时间性能时，值得注意的是 Series Network 比 DAG Network 更快。`AlexNet` 速度最快，训练仅需 `15` 分钟，其次是 `VGG16`、`VGG19`、`GoogLeNet` 和 `ResNet50`。然而，`IncV2`、`ResNet101` 和 `IncResNetV3` 耗时较长（测试环境为 `2.2 GHz` 双核 `i7 CPU` 计算机）。

结果表明，`AlexNet`、`ResNet50` 和 `ResNet101` 的精确度没有显著差异。它们的正确分类率接近且较高，分别为 `98.74%`、`98.73%` 和 `98.72%`。尽管 `IncResNet` 模型的准确率和精确率与其他模型相比最差，但它拥有最高的灵敏度（召回率）。

因此，我们展示了 `AlexNet`、`VGG16`、`VGG19`、`GoogleNet`、`IncV3`、`ResNet50`、`ResNet101` 和 `IncResNetV2` 等流行模型在组织病理学图像数据集上使用微调策略时的表现。`AlexNet` 和 `ResNet` 模型被发现比其他模型更准确、精确和可靠。它们的灵敏度范围在 `99.00%` 到 `97.00%` 之间。

关于评估，三个实验中的分类器均根据准确率的标准性能标准进行评估。为评估各种方法，训练和测试使用了相同的图像。比较采用两次 `10` 折交叉验证进行。对于每次交叉验证，基于九折训练样本，通过参数空间中的网格搜索计算每个特征集的性能值。因此，每次交叉验证的数值可能略有不同，报告的是平均最优值。

重要的是要强调，目前尚无共识认为微调策略优于现成特征提取策略。就性能而言，在生物医学成像领域，这两种策略尚未进行彻底比较，也没有共识表明哪种更好。生物医学领域的一些研究表明微调优于现成特征。然而，这并不完全具有决定性。此外，正如所述，微调比使用现成特征计算量更大，且涉及处理更多超参数。而现成特征方法从 CNN 提取特征通常较快，仅需调整最终分类器的超参数，这通常可通过交叉验证高效完成。

本研究在考虑 `VGG-16` 结果时的另一个关键观察是特定 FC 层错误预测的数量。在该模型使用 SVM 产生的 `57` 个错误预测中，`36` 个来自 FC 层 `34`，`17` 个来自 FC 层 `35`（原文逻辑疑似有误，此处保留原文数字对应关系）。该模型仅在使用 FC 层 `35` 配合 SVM 时实现了 `100%` 的性能准确率，FC 层 `35` 和 SVM 相比其他层提供了略好的结果。尽管无法确认使用特定 FC 层是否存在潜在联系，但这是一个值得探索的领域。此外，本项目中使用的不同层也是一个关注点。模型中的层与图像的特定特征相关，用于将图像转换为一组有意义的数字。然而，哪一层对应何种特征仍在研究中。对层的更多了解有助于回答为何某些层（FC 层 `35`）表现优于其他层（FC 层 `34`）。

不同全连接层（FC 层）的结果也可用于评估识别肿瘤和非肿瘤图像的能力。信息从 `VGG-Face` 模型中提取并输入到一个新算法中。为确保软件不会直接生成 `VGG-Face` 模型的结果，FC 层 36 被用作最后一个 FC 层。如果靠近 `VGG-Face` 模型最后一层（FC 层 37）的 FC 层表现更好，则表明当图像特征提取位置非常接近最后一层（该层更专门针对人脸）时，软件表现更好。然而，如果离最后一层较远的 FC 层表现更好，则可以假设这些层学习到了更通用的信息，因此人脸识别算法可以成功用于任何其他图像，如肿瘤图像。由于 FC 层 36 被用作软件的最后一层，研究中的所有 12 个结果均证实，人脸识别算法可用于成功识别肿瘤和非肿瘤图像。然而，应注意到 FC 层 33 和 35 的表现优于 FC 层 36，这表明在人脸识别算法中使用较低的 FC 层能产生更好的结果。

深度学习方法已被证明在各种用途的学习中极为有效。它们与大多数机器学习模型不同。然而，大多数模型强调学习复杂的分类器，而 CNN 则强调学习复杂的特征。确实，网络的所有层都有助于提取和学习日益复杂的特征。输出层除外，它基于这些特征充当一个相对简单的分类器。

另一方面，CNN 通常需要大型数据集进行训练；这就是为什么近期的方法趋向于使用在大型图像数据集上预训练的现有模型的迁移学习策略。CNN 可高效用于迁移学习，即网络可在源任务（如 `ImageNet` 数据集）上训练，然后在目标任务（如组织病理学图像数据集）上复用。这些训练好的模型可进一步针对新数据集进行微调以获得更好的拟合，或从其激活层提取特征以馈送分类器。

正如文献所述，迁移学习技术非常有用，特别是在目标任务的数据稀缺时。因此，组织病理学领域已研究深度迁移学习以克服数据稀缺问题。本质上有两种迁移学习策略，即使用从预训练网络中提取的现成特征，以及针对手头任务微调预训练网络。CNN 的泛化特性使其特征可迁移到其他应用，这鼓励研究人员将迁移学习用于组织学图像。正如所解释的，这些特征也被用于训练单独的分类器进行预测，当没有足够的数据集从头训练 CNN 时，这特别有用。
