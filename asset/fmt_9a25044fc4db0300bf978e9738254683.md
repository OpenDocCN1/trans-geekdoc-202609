在 `build` 方法中，我们定义了一个包含三个全连接层的基本顺序模型。对于每个全连接层，单元数量由 `hp.Int` 决定，它允许 `keras_tuner` 在指定范围内探索不同的值。同样，学习率使用 `hp.Float` 设置，提供调优器可探索的范围。模型使用标准的二元交叉熵损失函数和准确率作为指标进行编译：

    def build(self, hp):

        model = Sequential()

        model.add(

            Dense(

                units=hp.Int('units_1',

                             min_value=32,

                             max_value=128,

                             step=32

                             ),

                input_dim=X_train.shape[1]

            )

        )

        model.add(ReLU())

        model.add(

            Dense(

                units=hp.Int(

                    'units_2',

                    min_value=16,

                    max_value=64,

                    step=16

                )

            )

        )

        model.add(ReLU())

        model.add(

            Dense(

                units=hp.Int(

                    'units_3',

                    min_value=8,

                    max_value=32,

                    step=8

                )

            )

        )

        model.add(ReLU())

        model.add(Dense(1, activation='sigmoid'))

        optimizer = SGD(
