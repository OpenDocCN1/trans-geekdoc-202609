
在数字世界中，图像通过像素呈现。像素，也称为图像元素，可理解为显示屏上微小的发光区域。像素数量越多，图像分辨率越高，分辨率越高，表示效果越好。图像的每个像素将表示该位置的强度值。强度值用 `[0, 255]` 范围内的整数表示。表示一个像素需要一个字节。对于前面示例中的灰度椭圆图像，`24 = 6*4` 字节足以表示 24 个采样值的数字化。编程上，一个大小为 `6x4` 的二维无符号字节数组足以表示此图像。

**注意：表示一个彩色像素需要多少字节？**

颜色像素的外观取决于红、绿、蓝三个分量的值。通常，每个分量的取值范围为 `[0, 255]`。因此，表示一个颜色像素需要 3 个字节。这种图像表示格式称为 RGB。在编程中，表示分辨率为 `w×h` 的彩色图像需要一个大小为 `w×h×3` 的三维数组。

## 空间滤波

**滤波**是指通过数学运算修改或拒绝图像的特定分量。将滤波器应用于空间域中表示的图像的过程称为**空间滤波**。空间滤波通过用像素值或其邻域像素值的函数来替换像素，从而修改图像的像素。我们可以将空间操作大致分为三大类：

1.  单像素操作
2.  邻域像素操作
3.  几何空间变换

在*单像素操作*中，变换函数仅接收一个像素输入，并输出一个用于替换当前考虑像素的值。在*邻域像素操作*中，变换函数接受当前考虑的像素及其邻域，并输出一个用于替换当前考虑像素的值。在*几何空间变换*中，对图像中像素的空间排列进行修改。

## 几何空间变换

在**几何空间变换**中，变换函数接受原始图像的像素坐标 `(x, y)`，并输出变换后图像中该像素的新位置坐标 `(a, b)`。保持点、直线、平行性和平面的二维变换称为*仿射变换*。*仿射变换*保持共线性（即，最初位于一条直线上的所有点，变换后仍位于该直线上）和距离比（例如，线段的中点在变换后仍是该线段的中点）。

## 邻域像素操作

变换函数可以考虑像素及其邻域像素的强度值，输出一个将用于替换变换后图像中当前考虑像素的强度值。这个变换函数或表示该函数的矩阵称为*滤波器*、*核*或*滤波器核*。将滤波器或核应用于输入图像的每个像素的过程称为*图像滤波*。图像滤波也可以看作是从图像中提取有助于推断图像的特征。不同的滤波器提供图像的各种特征。如果变换函数/矩阵是线性的，则称为*线性空间滤波器*；否则称为*非线性空间滤波器*。

考虑执行图像 `I` 与滤波器之间乘积求和运算的简单*线性空间滤波器*。设图像 `I` 为二维，每个像素代表像素强度。位置 `I(x, y)` 处的图像像素通过 `I(x, y)` 访问。滤波器 `w` 可以是各种尺寸。为简单起见，考虑 3×3 二维滤波器。线性滤波器应用于图像的每个像素以获得变换后的图像 `G`。*以下公式*展示了 3×3 内核在图像位置 `I(x, y)` 处像素上的应用。

`G(x, y) = Σ Σ w(s, t) * I(x+s, y+t)`

内核中心与考虑中的像素对齐。以中心为原点对内核单元编号，如*图 9.6*所示。对齐后，计算相应单元值的乘积并求和。结果值 `G(x, y)` 用于替换位置 `I(x, y)` 处的像素值。本例中考虑了 3×3 大小的内核，但内核可以是任意尺寸。通常选择奇数维度的内核，如 `k×k`，其中 `k` 为奇数正整数。优势在于将考虑中的图像像素与内核原点对齐后，考虑像素周围各方向的周围像素数量保持相等。参考下图：

![](img/Image45820.jpg)

**提示：当所有周围像素不可用时（如边界像素情况）会发生什么？**

**如果某像素没有映射到内核尺寸的周围像素，则可以用常数值代替缺失的周围像素。这称为填充。**

这种线性运算称为*相关*或*互相关*。对于尺寸为 `m × n where m = 2a + 1` `&` `n = 2b + 1` 的内核 `w`，*相关*定义如下：

`G(x, y) = Σ Σ w(s, t) * I(x+s, y+t)`

另一种重要的线性运算称为卷积。*卷积*运算定义如下：

`G(x, y) = Σ Σ w(s, t) * I(x-s, y-t)`

*卷积*运算可用相关来定义：将内核旋转 180°并执行相关运算。*图 9.7*描绘了与图像像素相乘的内核单元：

## 卷积性质

卷积运算满足交换律、结合律和分配律。

`w * I = I * w` `w * (I1 + I2) = w * I1 + w * I2` `(w1 * w2) * I = w1 * (w2 * I)`

由于卷积满足交换律，在运算 `w * I` 中，执行相关前可将内核 `w` 或图像 `I` 旋转 180°。考虑 `L` 个内核 `w1, w2, ..., wL` 依次在图像 `I` 上卷积的情况。因卷积满足交换律，我们不必与 `L` 个内核分别卷积，而是可用一个内核 `w`，其通过 `w = w1 * w2 * ... * wL` 获得。

**注意：相关或互相关仅满足分配律。**

## 可分离内核

若二维函数 `f(x, y)` 可表示为两个一维函数乘积 `f(x, y) = f1(x) * f2(y)`，则称其为*可分离*。二维内核为矩阵 `W`，若可表示为两个一维向量 `u` 和 `v` 的外积，其维度为 `m×1` 和 `1×n`，即 `W = u * v^T`，则称为*可分离内核*。

## 可分离内核卷积

理解执行卷积运算所需的计算量。考虑尺寸为 `M×N` 的图像 `I` 和尺寸为 `m×n` 的内核 `W`。一次卷积运算需 `m×n` 次乘法和加法。此运算须应用于图像每个像素，总共需 `M×N×m×n` 次乘法和加法。

可分离内核能否降低计算量？是的，使用可分离内核可实现降低。设尺寸为 `m×n` 的内核 `W` 可表示为维度为 `m×1` 和 `1×n` 的两个一维向量 `u` 和 `v` 的外积 `W = u * v^T`。将 `u` 内核应用于完整图像所需计算量为 `M×N×m`。应用另一内核 `v` 代价为 `M×N×n`。总计将内核 `W` 应用于完整图像的计算代价为 `M×N×(m+n)`。此计算优势定义如下：

`(M×N×m×n) / (M×N×(m+n)) = (m×n) / (m+n)`

**提示：如何判断内核是否可分离？**

**内核 `W` 的秩因维度 `m×n` 恒为 1。这些秩 1 内核的乘积秩恒为 1（原因：矩阵乘法 AB 可表示为用 B 的列作权重的 A 的列的线性组合，参考第 2 章 线性代数）。此时，内核可分离当且仅当其秩为 1。**

**示例**：考虑可表示为两个 3×1 滤波器乘积的 3×3 滤波器。检查其秩：

`rank(W) = 1`

**示例**：考虑另一 3×3 滤波器 Sobel（详见后续章节）。检查其秩：

`rank(W) = 2`

存在不同滤波器或内核，通过卷积运算帮助提取图像的不同特征。这些特征有助于推断图像。其中常用的有平滑滤波器如高斯、边缘检测滤波器如拉普拉斯与 Sobel，将在后续章节讨论。

## 高斯内核

标准差为 `σ`、零均值为 `μ=0` 的一维高斯函数表示如下：

`G(x) = (1 / (σ√(2π))) * exp(-x² / (2σ²))`

高斯函数值围绕均值的分布对称。*图 9.8*展示了未归一化因子 `1/(σ√(2π))` 的 `σ=1` 高斯函数 `G(x)` 图像。68%值落在距均值 `σ` 范围内。距均值 `2σ` 范围内覆盖 95%值。`3σ` 占 99.7%值。此信息对设计固定长度高斯内核至关重要。另一重要性质是高斯函数永不等于零。此性质在滤波运算中很有用：更近像素获得更高权重，且在所有方向对称。参考下图：

![](img/Image45900.jpg)

**图 9.8：** *高斯函数中的值分布*

处理图像需二维高斯函数及其二维矩阵形式的离散近似。因 99%值在 `3σ` 距离内覆盖，内核可包含此距离内的值。因此尺寸为 `7×7`（`3σ` 在一轴相反方向各延伸）的内核足以捕捉函数行为。

二维情况下，高斯函数为各维度高斯函数的乘积。高斯函数乘积仍为高斯函数。此处 `x` 表示沿 `x` 轴距原点的距离。同理，`y` 表示沿 `y` 轴距原点的距离。

`G(x, y) = (1 / (2πσ²)) * exp(-(x² + y²) / (2σ²))`

## 高斯函数的离散近似

现在，让我们获取高斯函数的离散近似，它可以作为卷积操作中的核用于图像处理。为简化问题，让我们考虑零均值 `μ=0` 和标准差 `σ=1`。有了这些值，函数变为如下形式：

`G(x, y) = (1 / (2πσ²)) * exp(-(x² + y²) / (2σ²))`

编写代码时，仅考虑函数的变量部分 `exp(-(x² + y²) / 2)`。以下代码展示了实现。它从二维空间接受 `(x, y)` 坐标值，并输出高斯函数变量部分的值：以下代码展示了二维高斯函数的实现。

```python
1. import numpy as np
2. def gaussian_fn_2d(x, y):
3.     # 高斯函数的指数部分 均值=0, 标准差=1
4.     exp_part = np.exp(-(np.power(x, 2.) + np.power(y, 2.)) / 2.)
5.     return exp_part
```
