
# 无线网络与 IP 地址黑客攻击指南

## 无线网络认证技术

各种无线网络设备使用许多认证技术。这些包括：`WEP`、`WPA`、`WPA2`、`WPA3`、`WPA2 + AES`、`WPA + AES`、`WPA + TKIP/AES`、`WPA + TKIP` 等。`WEP` 和 `WPA` 是无线网络中最常用的两种认证技术。在学习如何黑客攻击无线网络之前，了解这两种技术有助于建立坚实的基础。它还将帮助你收集关于接入点所需的信息。

### WEP

`WEP`（有线等效保密）是 IEEE 802 的一种安全算法。它的开发初衷是克服传统有线连接的数据机密性问题。它通过加密传输的数据来防止窃听，提供了更好的数据保护。`WEP` 认证使用两种方法：

*   **开放系统认证 (OSA)** – OSA 可帮助你访问任何 `WEP` 网络以及接收未加密的文件
*   **共享密钥认证 (SKA)** – SKA 允许配备无线调制解调器的计算机完全访问任何 `WEP` 网络，并交换加密和未加密的数据。

### WPA

在 `WEP` 中发现的弱点导致了 Wi-Fi Protected Access 的开发。`WPA` 成为具有无线互联网连接的计算设备的安全标准。`WPA` 对 802.11 WLAN 上的数据进行加密。除此之外，`WPA` 使用 48 位初始值，而不是 `WEP` 使用的 24 位，这使其具有更高的初始值。然而，据报道 `WPA` 多次受到 `DDoS` 攻击的影响。

## 一般攻击类型

*   **中间人攻击：** 指拦截两个人之间的通信以窃取数据。
*   **拒绝服务 (`DDoS`)：** 要做到这一点，你必须用流量淹没网络。结果，它无法满足任何请求，导致系统不可用。
*   **嗅探：** 涉及拦截通过网络传输的数据包。

除了上述攻击外，还有各种类型的攻击可能危害计算机网络安全，这在两种类型的黑客攻击中都很有用。理解这些攻击不仅有助于你了解如何黑客攻击网络，还能学习网络安全。此外，它还将帮助你成为一名道德黑客。

### 什么是 IP 地址？

`IP` 地址只不过是一个数字标识符。它标识网络（如互联网）中的 PC、智能手机或任何其他设备。你可以把它想象成普通邮件地址。如果我知道你的普通邮件地址，我就知道你在哪里，可以给你寄信。有了 `IP` 地址，我可以（大致）知道你的设备在哪里，并给你发送一些互联网流量。换句话说，你在互联网上由你的 `IP` 地址标识。通常，你的互联网提供商为你家里的路由器分配一个公共 `IP` 地址。当你家庭网络中的设备想要通过互联网发送流量时，它们将使用那个公共 `IP` 地址（在所有设备间共享）。互联网上的通信通过数据包进行。每一块数据被放入一个包中，你可以把它想象成一封信。在信封上，你总是写上源和目的 `IP` 地址。互联网会负责将数据包送达正确的目的地。现在，正如你所见，如果你发送流量出去，你会写上你的 `IP` 作为源 `IP`。这是对方知道它并发送一些流量回来的唯一途径。

### 我们真的需要使用真实的 IP 地址作为源吗？

当然！想象一下你想下载一部电影、查看一个网页，或你在互联网上做的任何其他事情。你联系一个第三方服务器，它发送你请求的内容。它需要知道发送到哪里，所以它需要知道你的 `IP`。

### 我有危险吗？

这取决于情况，但在大多数情况下，你没有危险。从上面的段落可以看出，知道别人的 `IP` 是合法的。你需要它来发送回流量。如果你的 `IP` 地址落入坏人之手会怎样？仅仅知道你的 `IP` 地址，没有人能伤害你。然而，他们可以开始扫描你的电脑，看看你是否有可利用的漏洞来访问你的数据。我们稍后会谈到这一点。
