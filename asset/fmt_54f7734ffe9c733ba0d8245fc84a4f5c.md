
# 开发针对敏感信息和个人身份信息（PII）控制的策略和程序

## 联邦信息安全管理法 (FISMA)

FISMA 于 2002 年签署成为法律。制定 FISMA 是为了解决非国家安全政府机构的信息安全需求。FISMA 要求对政府所有和运营的 IT 基础设施和资产进行保护。FISMA 带来的重大变化是建立了一套清晰的信息安全指南，旨在保护联邦 IT 基础设施和数据资产。FISMA 规定了以下职责：

- 开发并维护一个具有整个 IT 安全架构和框架的信息保证（IA）计划。
- 确保每年进行信息安全培训，以保持员工经过适当的培训并获得认证。
- 对信息安全有重大责任的人员实施问责制。

FISMA 还要求定期的风险评估、风险评估策略和程序、定期的（至少每年一次）测试和评估，以及对高级管理层进行适当的培训和教育，以便部署适当的安全意识计划。

## 萨班斯-奥克斯法案 (SOX)

SOX 于 2002 年签署成为法律。该法强制了许多改革以增强企业责任、财务披露并打击公司和会计欺诈。第 302 节和第 404 节涉及 IT 基础设施和信息安全。第 302 节要求 CEO 和 CFO 证明组织具有适当的内部控制。它还要求 CEO 和 CFO 对财务报告内部控制的有效性进行报告。

第 404 节对管理结构、控制目标和控制程序提出了要求。遵守第 404 节要求公司建立旨在存档记录并保护其免受破坏、丢失、未经授权的更改或其他滥用的基础设施。它要求建立一套全面的控制措施，并由 CEO 和 CFO 负责。

## IT 治理协会框架 (The Governance Institute Framework)

IT 治理协会开发了一个流程，该流程从为企业 IT 设置目标开始，提供初始方向，然后演变为一个持续循环。

该框架包括物理安全等领域。必须定义物理安全，并采取适当的保护措施来保护 IT 基础设施和资产。安全策略是另一项强制性控制措施。它们定义并涵盖了整个组织，作为组织整体 IT 安全架构和框架的一个要素。

为了符合组织面临的许多规则和法规，公司通常会进行定期审计。公司要求、组织所属行业、特定法律和指令会影响审计的频率。虽然有许多类型的审计，但安全专业人员通常对 IT 审计最感兴趣。审计是对信息系统或网络内部控制措施的检查。审计的目标是评估适当的安全控制、程序和指南。审计员的任务是检查内部和外部客户的需求，并验证是否遵循了适当的实践。

归根结底，如何处理风险是董事会和高层管理的责任。高层管理由 CEO、CFO 以及公司章程中定义的其他公司官员组成。这些个人负责控制和监督组织中的所有部门。高层管理负最终责任，并负责决定对公司最优的方案。

## 数据风险

数据已成为许多组织的命脉。虽然我小时候的医生诊所在接待台后面有一个显示文件、文件夹和文档的显示器，但现在计算机以数字格式存储着相同的信息。从安全专业人员的角度来看，有两个关键考虑点：静态数据和传输中数据。静态数据可以存储在硬盘、外部存储器、CD、DVD 甚至优存盘中。什么是静态数据？安全专家布鲁斯·施耐德（Bruce Schneider）将静态数据描述为“人们跨越时间与自己通信的一种”。

## 静态数据

各种产品可用于现有磁盘和介质驱动器产品的数据加密。保护静态数据的选项包括软件加密，例如加密文件系统（EFS）和 TrueCrypt。还有硬件加密的选项。两种著名的硬件加密选项是硬件安全模块（HSM）和可信平台模块（TPM）。

HSM 是一种针对管理加密密钥的一类安全微处理器。HSM 有两种类型：插在计算机主板外设组件互连（PCI）插槽上的插卡式设备，以及独立的外部设备。在这两种情况下，连接到 HSM 的计算机都用于生成密钥、对对象签名和验证。

TPM 是一种特殊的芯片，可以安装在计算机的主板上，用于硬件认证。TPM 认证的是计算机本身而非用户。TPM 使用计算机的启动序列来确定平台的信任状态。TPM 将加密过程置于硬件层面。如果有人移除设备并尝试从另一台计算机启动硬盘，硬盘将失败并拒绝任何访问。这比可能仅用于加密硬盘上少数文件夹的软件加密选项提供了更高水平的安全性。TPM 设计为一种廉价的方法，以妥善保护启动环境并识别系统。

HSM 和 TPM 对硬盘和固定存储设备均有效，但便携设备必须防止损坏、未经授权的访问和暴露。一种很好的方法是要求所有使用便携设备、USB 优存盘、手持设备或任何可移动存储介质设备的员工对他们的妥善和安全负责。这从政策开始，延伸到用户培训。例如，政策可能要求笔记本电脑用户至少每周连接一次公司内网，以接收最新的软件补丁。还可以制定政策，要求在便携设备上使用加密。未能妥善保护静态数据会导致此类攻击：

- 窃取（slurping），一种非法下载或复制计算机数据的技术。通常用于数据外泄。
- 如开关刀（Switchblade）和黑锯（Hacksaw）等恶意软件。
- 如病毒、蠕虫、木马和键盘记录器软件。

静态数据的保护不仅在设备在使用期间，在寿命结束时也是必要的。所有达到寿命终点的设备都应妥善处置。适当的处置可以包括：

- 驱动器擦除
- 零化
- 消磁
- 物理破坏

CASP 考试要求你理解妥善处置数据的重要性。

## 传输中数据

第二个关注点是数据在传输过程中。数据处理或从一个位置移动到另一个位置时，都需要适当的控制。基本问题是许多协议和应用程序通过明文发送信息。电子邮件、网页和 FTP 等服务设计时未考虑安全性，发送信息的控制措施很少且没有加密。不安全协议示例包括：

- `FTP`：明文用户名和密码
- `Telnet`：明文用户名和密码
- `HTTP`：明文
- `SMTP`：用户名和密码，以及所有明文数据

对于未受任何形式加密的传输中数据，存在许多危险，包括：

- 窃听
- 嗅探
- 劫持
- 数据篡改

高价值数据需要保护。一种方法是安全专业人员将数据分类。例如，组织可能要求所有电子邮件用户使用某种形式的加密，如 S/MIME、OpenPGP 或 GPG。移动用户应被使用虚拟专用网络（VPN）。与包含敏感信息的数据库和 Web 服务器通信的个人应使用 HTTPS、SSL 或 TLS。安全专业人员可能还想评估附件的风险，并审查允许的附件类型（表 6.1）。

## 电子数据交换

对于传输中的数据，可以使用电子数据交换 (EDI)。然而，EDI 正在失去地位，并被基于 XML 的事务处理所取代。EDI 的设计初衷是为了安全性，并弥补不同系统之间的差距。EDI 用于以发送系统和接收系统都能理解的格式交换数据。使用的 ANSI X12 格式为组织带来了便利，因为信息是通过电子传输的，减少了纸质工作并减少了错误。

尽管 EDI 简化了通信，但必须配合适当的安全控制来实施。幸运的是，EDI 具有解决安全和重复交易问题的控制措施。常见的控制措施包括：

- 验证发送者和接收者的传输控制
- 防止对数据进行未经授权更改的操纵控制
- 验证合作伙伴身份的授权控制
- 保护信息机密性的加密控制

EDI 为组织增加了新的关注层面，因为文档是以电子方式处理的。EDI 的一个主要关注点是授权过程应该增加额外的控制层。

## 变化的网络边界

另一个日益引起安全专业人员关注的问题是，随着云计算的兴起，网络边界越来越难以定义。网络边界是定义控制的点。这种边界化和不断变化的网络边界产生了巨大影响，因为从历史上看，这条分界线位于物理网络的边缘。云计算的概念代表了思维的转变，用户不需要了解特定技术的细节。用户可以根据其特定需求以设定的速率消耗服务，随时提供按需服务。图 6.2 显示了云服务的示例。

成本和易用性是云计算的两个大优势，但在考虑将关键应用程序和敏感数据迁移到公共和共享环境时，必须考虑安全问题。为了解决这些问题，提供商必须开发足够的控制措施，以提供与组织不使用云时相同或更高水平的安全性。

云计算不是网络边界变化的唯一方式。远程办公和外包也在改变网络边界。远程办公允许员工在家工作，避免通勤上班。根据 FlexJobs 的说法，医疗、IT、教育、非营利以及销售营销部门是最常见的允许远程办公的部门。有时外包可能成为安全风险。例如 Verizon 发现其一名员工将自己的工作外包给了中国。该员工让中国的其他人替他工作，而他自己看猫视频并更新社交简介。更多信息请访问：http://edition.cnn.com/2013/01/17/business/us-outsource-china/

## 企业网络中个人设备的风险

时代在变。如果你在街上询问个人他们是否拥有手机或平板电脑，答案对于一个或两个问题可能都是肯定的。这些人很可能会将这些设备带到工作中并连接到公司的基础设施。确定是否允许这样做是组织的责任，并将需要制定自带设备 (BYOD) 或自带技术 (BYOT) 政策。

由于这种趋势对公司具有巨大影响，因为公司正在制定政策，规定这些设备是否以及如何在公司网络上使用或允许使用。在某些方面，这种趋势有利于公司，因为公司可以避免为用户提供手机和其他移动设备。只需记住，政策和控制措施涵盖的不仅仅是手机。

许多人都有 USB 优盘；这些设备使得移动信息和端口数据传输变得简单。它们还导致了恶意软件感染增加、敏感信息泄露以及未经授权访问事件的增加。

> 你的公司允许使用优盘吗？如果是，你可能需要重新考虑。US-CERT 报告说，Conficker 病毒通过优盘发生了大规模感染。在许多情况下，现代恶意软件使用优盘感染未修补的系统。最佳实践是禁用自动运行 (Autorun) 并限制 USB 设备。

# 声誉有价值吗？

虽然我们通常认为资产是某种有形物体，但资产也可以是无形的。声誉就是一个很好的例子。随着业务规模的扩大以及互联网增加了新闻报道在全球范围内快速传播的能力，公司必须更加努力地保护自己的声誉。英国石油（BP）、强生公司（Johnson & Johnson）和美国联邦应急管理局（FEMA）等全球性组织的经验表明，保护企业声誉意味着不仅要合规，还要力求管理企业形象。如果客户认为公司做法不当或未能提供有效的安全控制，可能会损失数十亿美元。

一旦确定了所有资产，评估资产的人员必须问的不能仅仅是资产的原始成本。你必须开始考虑任何可能使用的潜在控制措施的投资回报。其他关键考虑因素还包括：

- 获取或创建该资产花费了多少成本？
- 如果资产遭到破坏，其责任是什么？
- 如果资产无法使用，生产成本是多少？
- 该资产对竞争对手和外国政府的价值是多少？
- 该资产有多么关键，它的损失将对公司产生什么影响？

为资产定价并非易事。资产估值是一项需要大量专业知识和工作才能正确完成的困难任务。在现实生活中，这一过程通常由具有此类任务背景并可以使用专用软件和工具的专业人员团队执行。

如果已经建立了信息分类计划，资产的识别和估值将变得更容易。可以根据特定的组织或行业将信息分为机密性、完整性和可用性（CIA）三个级别。我们将在下一节探讨这一主题。

# 信息分类

信息分类在许多方面加强了组织的实力。将信息标记为“秘密”或“绝密”有助于员工看到信息的价值，并给予其更高标准的对待。信息分类还规定了谁可以处理特定信息。例如，公司政策可能规定：“离开工作时，所有敏感文档必须从员工办公桌上移除。我们支持整洁桌面政策。”

目前采用了两种广泛的信息分类系统。每种系统都关注 CIA 安全三元组的不同部分。这两种方法如下：

## 政府分类系统

该系统侧重于机密性。

## 商业分类系统

该系统侧重于完整性。

政府信息分类系统分为：未分类（Unclassified）、机密（Confidential）、秘密（Secret）和绝密（Top Secret）类，如表 6.3 所示。

**表 6.3** 政府信息分类

| 分类 | 说明 |
| :--- | :--- |
| 绝密 (Top Secret) | 泄露会对国家安全造成严重损害。此类信息需要最高级别的控制。 |
| 秘密 (Secret) | 预计泄露会对国家安全造成严重损害，并可能暴露重要的科学、技术、操作、后勤以及许多其他进展。 |
| 机密 (Confidential) | 泄露可能对国家安全造成损害，应防止其泄露。 |
| 未分类 (Unclassified) | 信息不敏感，除非在分类中附加“仅供官方使用（FOUO）”，否则不需要保护。未分类信息通常不会导致任何损害，但随着时间的推移，未分类 FOUO 信息可能会被汇总，以推断出更高分级的信息。 |

商业信息分类系统不仅关注机密性，还关注信息的完整性；因此，它被分为公开（public）、敏感（sensitive）、隐私（private）和机密（confidential），如表 6.4 所示。

**表 6.4** 商业信息分类

| 分类 | 说明 |
| :--- | :--- |
| 机密 (Confidential) | 这是最敏感的评级。这是保持公司竞争力的信息。此类信息仅供内部使用，但其发布或更改可能会严重影响或损害公司。 |
| 隐私 (Private) | 这类受限信息被认为具有个人性质，可能包括医疗记录或人力资源信息。 |
| 敏感 (Sensitive) | 这些信息需要控制以防止其向未经授权的第三方发布。机密性的丢失或完整性的丢失可能会导致损害。 |
| 公开 (Public) | 这与未分类信息类似，其泄露或发布不会对公司造成损害。 |

取决于业务所属的行业及其特定需求，这些选项中通常会有一个比另一个更合适。无论选择哪种分类系统，安全专业人员在信息分类和帮助确定分类指南方面都起着关键作用。一旦组织开始分类过程，就必须思考如果特定信息泄露会发生什么，以及其发布将如何影响组织。

# 风险评估

一旦组织的资产完成了清点、估值和分类，就可以开始下一步。在这一步中，风险评估是识别潜在风险和威胁的阶段。这些活动通常由风险评估小组执行，并确定威胁发生的概率。该团队受高层管理人员委托，识别威胁并检查已识别威胁的影响。

这一过程可以基于真实的美元金额，也可以基于非金额价值。当使用非金额价值时，团队通常根据总分确定所需的最低安全控制措施。一种常见的方法是根据识别出的漏洞在资产的机密性、完整性和可用性方面的应用，将其来确定总分。在查看定性和定量风险评估之前，让我们先简要回顾一下关于执行该项目的团队的一些事实。

# 风险管理团队

风险管理团队负责识别和分析风险。其成员应由来自全公司的经理和员工组成。

在确定团队目的后，可以分配任务负责开发和实施风险管理计划的责任。该团队应由公司结构中职位足够高的人领导，以便于与高级评估人员交流，并获得风险评估过程所需的资金。成功的结果可以通过许多方式来衡量。成功可能意味着团队能够降低保险成本、减少针对公司网站的攻击或验证对隐私法的合规性。

管理，识别有形和无形资产，并开始识别潜在威胁。这些威胁的影响必须以某种方式进行衡量。一种方法是以美元价值来评估威胁。团队只是在问一个问题：这需要多少成本？

威胁并不一定会导致损失。要发生损失，威胁必须与漏洞相结合。这种漏洞可能是空心服务器机房门的易被穿透性。或者，也可能是其他地方缺乏加固的备份设施。甚至可能是前台区缺乏视频监控。导致的损失可能是以下任何一种情况：

- 财务损失
- 员工、客户或顾客的人身危险或伤害
- 泄露机密或违反法律
- 机密信息泄露
- 设备、硬件或软件被盗

要开始计算损失，你需要对过程中的所有要素进行量化，包括资产价值、影响和威胁频率。以下是步骤：

1. 确定每项信息资产的资产价值 (AV)。
2. 识别针对资产的威胁。
3. 确定每项信息资产相对于每个威胁的暴露因子 (EF)。
4. 计算单次损失期望 (SLE)。
5. 计算年度发生率 (ARO)。
6. 计算年度损失期望 (ALE)。

> 这是一个耗时的过程，因为必须对所有资产进行处理。

最广泛使用的两个定量风险评估公式是：

```
SLE = AV × EF
```

以及

```
ALE = ARO × SLE
```

定量风险评估的优势在于它分配了美元价值。美元价值易于理解。如果有人说，潜在威胁与漏洞结合可能导致 100 万美元的损失，这个数值对于管理层来说很容易处理和概念化。定量风险评估的主要缺点是它是基于美元的，团队必须尝试为所有要素计算出一个美元价值。这是非常耗时的，而且必须对定量要素应用一些定性衡量。由于这是一项极其巨大的任务，定量评估通常在自动化软件工具的帮助下进行。这些工具可以帮助趋势分析并寻找随时间变化的模式。趋势分析通过检查历史数据来确定损失频率或损失程度的模式。例如，大西洋沿岸的飓风变得越来越具有破坏性。自 1990 年以来，美国历史上最昂贵的十场飓风中已有五场发生。
