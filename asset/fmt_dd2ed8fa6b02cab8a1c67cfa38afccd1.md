
| `q` | 电荷 |
| `D` | 掺杂区长度 |
| `L` | `ReRAM` 薄膜厚度 |
| `w` | 掺杂比 `w = D/L`（非易失性状态变量） |

### 表 3.1 ReRAM 模型参数

| 符号 | 说明 |
| :--- | :--- |
| `w` | 归一化漂移速度 |
| `R_on` | 低阻态电阻 (LRS) |
| `R_off` | 高阻态电阻 (HRS) |
| `f(w)` | 定义边界条件 `w=0` 或 `w=1` 的窗口函数 |
| `μ_v` | 小电场下的迁移率 |
| `F_c` | 晶体中特定移动原子的特征场 |

此外，ReRAM 的减速效应如图 3.4(a)所示，当 `w` 接近边界 `w=0` 或 `1` 时，漂移速度迅速下降，不再与施加的电流呈线性关系。这种非线性动态效应可以用以下任一窗口函数来表征 [135, 136]：

```
f(w) = 1 - (2w - 1)^(2p)  (Joglekar 窗口函数)
```

```
f(w) = w(1 - w)  (Biolek 窗口函数)
```

因此，考虑掺杂因子 `w` 的电荷诱导漂移效应、减速效应和强电场效应的完整非线性动态 ReRAM 模型可从式 (2.2) 到 (2.6) 得出：

```
dw/dt = μ_v * (R_on / D²) * i(t) * f(w)
```

```
R(w) = R_on * w + R_off * (1 - w)
```

将推导出的 ReRAM 动态函数 (3.5)–(3.7) 结合到修正节点分析 (MNA) 矩阵中，可以推导出以下雅可比项：

```
∂i/∂v = G(w)
```

```
∂i/∂w = (∂G/∂w) * v
```

```
∂(dw/dt)/∂w = (∂/∂w)[μ_v * (R_on / D²) * i(t) * f(w)]
```

其中 `G(w)` 是电导，`∂G/∂w` 是电导的非易失性状态变量导数；`μ_v`、`R_on`、`D` 为常数；`f(w)` 为窗口函数。回顾一下，其他参数定义见表 3.1。因此，线性化系统方程所需的所有雅可比项均可建立，据此可在类 SPICE 仿真器中相应地实现考虑非易失性状态变量的 ReRAM 器件仿真。

#### 3.1.2 扩散型 ReRAM 器件

近期研究 [137, 138] 报道了一种扩散型 ReRAM 器件。不同于常见的漂移型 ReRAM，扩散型 ReRAM 的初始状态在无外部电压或电流施加时始终为 HRS，且 `R_off = 1 MΩ`。当输入电压超过阈值 `V_th = 1 V` 持续一段时间（如 1 ms）后，扩散型 ReRAM 将切换到 LRS，`R_on = 1 kΩ`。器件开启后，若施加电压降至另一阈值 `V_hold = 0.5 V` 以下约 20 ms，电阻将缓慢恢复回 HRS。此类器件作为自动开/关选择器显示出巨大潜力。下文中，我们用 `R_on` 和 `R_off` 表示扩散型 ReRAM 的两种状态。

在大多数应用中，扩散型 ReRAM 与漂移型 ReRAM 串联，形成一选择器一 ReRAM (1S1R) 结构。这种扩散型 ReRAM 可作为突触模拟器 [137] 和选择器 [138]。我们在图 3.10 中使用 SPICE 仿真表征这两种 ReRAM。此处根据文献 [139] 设置漂移型 ReRAM 参数 `R_on = 100 Ω`，`R_off = 16 kΩ`，根据文献 [138] 设置扩散型 ReRAM 参数 `R_on = 1 kΩ`，`R_off = 1 MΩ`。后续章节将使用 SPICE 模型进行 1S1R 性能评估。

### 3.2 ReRAM 交叉阵列结构

如前所述，ReRAM 是一种两端器件，可观察到夹在金属电极之间的亚化学计量比过渡金属氧化物 (`TMO_x`)。这种器件可用作具有离子电阻状态的非易失性存储器，从而产生两种非易失性状态：HRS 和 LRS。通过施加 SET 电压 (`V_set`) 或 RESET 电压 (`V_reset`)，可将状态从 HRS 变为 LRS，或反之亦然。

两种状态 RHS 和 LRS 分别代表 `R_off` 和 `R_on`。读取 ReRAM 单元时，可向 ReRAM 施加读电压 `V_read`。`I_read_HRS` 和 `I_read_LRS` 遵循：

```
I_read = V_read / R(w)
```

其中 `V_th` 是 ReRAM 的阈值电压。

## ReRAM 交叉阵列结构

由于 ReRAM 器件的高密度，可以构建交叉阵列结构作为 ReRAM 阵列 [59, 140–144]。这种交叉阵列结构可用作高密度数据存储的存储器。通过控制字线（WL）和位线（BL）的电压，可以对存储阵列进行读取或写入。例如，我们可以在第 `i` 条 WL 上施加 `V_write`，在第 `j` 条 BL 上施加 `0`，以将数据写入第 `i` 行、第 `j` 列的 ReRAM 单元中。

#### 3.2.1 模拟与数字化 ReRAM 交叉阵列

本节将介绍传统的模拟 ReRAM 交叉阵列和数字化 ReRAM 交叉阵列。这两种结构的 I/O 接口和 ReRAM 器件电阻值的数量各不相同。

##### 3.2.1.1 传统模拟 ReRAM 交叉阵列

ReRAM 是一种基于两端结器件的新兴非易失性存储器，其电阻可由外部施加电流的积分来控制。交叉阵列的结构天然支持矩阵-向量乘法，其中向量由行输入电压电平表示，矩阵由 ReRAM 电阻网格表示。为了计算矩阵-向量乘法 `y = Wx`。如图 3.11 所示，通过将 `W` 配置到 ReRAM 交叉阵列中并将 `x` 设置为交叉阵列输入，模拟计算可直接由 ReRAM 交叉阵列实现，输出为 `y`。

![图 3.11 带有 ADC 和 DAC 的传统模拟式 ReRAM 交叉阵列](img/PBPC0390-03-f11.jpg)

然而，这种模拟 ReRAM 交叉阵列有两个主要缺点。首先，由于较大的 ReRAM 工艺变异，连续值 ReRAM 电阻的编程在实际中极具挑战性。具体而言，ReRAM 电阻由流过器件的电流积分决定，这会导致如图 3.12(a)所示的开关曲线。由于工艺变异，曲线可能会发生偏移，导致中间值非常难以可靠地编程，如图 3.12(b)所示。其次，模数转换器（ADC）和数模转换器（DAC）既耗时又耗电。在我们的仿真中，如图 3.13 所示，在 65 nm 工艺下，模数和数模转换可能消耗高达 85.5% 的总运算能量。

![图 3.12 (a) 器件变异下的 ReRAM 开关曲线。(b) 不同 ReRAM 目标电阻的编程不准确性](img/PBPC0390-03-f12.jpg)

![图 3.13 (a) 模拟式 ReRAM 交叉阵列的功耗。(b) 模拟式 ReRAM 交叉阵列的面积消耗](img/PBPC0390-03-f13.jpg)

##### 3.2.1.2 数字化 ReRAM 交叉阵列

为克服上述问题，提出了一种用于矩阵-向量乘法的全数字化 ReRAM 交叉阵列。首先，如图 3.12 所示，导通态（ON-state）和截止态（OFF-state）比中间值可靠得多，因此只允许 ReRAM 采用二进制值，以减少 ReRAM 编程的不准确性。其次，部署了无需 A/D 转换的纯数字接口。

在 ReRAM 交叉阵列中，我们用 `V_WL[i]` 和 `V_BL[j]` 分别表示第 `i` 条 WL 和第 `j` 条 BL 上的电压。`R_LRS` 和 `R_HRS` 分别表示低电阻态（LRS）和高电阻态（HRS）的电阻。在每个感测放大器（SA）中，都有一个电阻固定且较小的感测电阻 `R_sense`。这三个电阻的关系为 `R_LRS < R_sense < R_HRS`。因此，第 `j` 条 BL 上的电压可表示为

```
V_BL[j] = (Σ_i g_ij * V_WL[i]) / (Σ_i g_ij + 1/R_sense)
```

其中 `g_ij` 是 `R_ij` 的电导。

数字化交叉阵列的关键思想在于使用比较器。由于模拟交叉阵列每列的输出电压是连续值，因此使用比较器根据施加在 SA 上的参考阈值将其数字化：

```
V_BL[j] > V_ref ? 1 : 0
```

然而，模拟电压值数字化带来的问题是信息丢失。为克服此问题，可采用三种技术。首先，使用多阈值以增加量化电平，从而保留更多信息。其次，将乘法运算分解为三个子运算，二进制交叉阵列可很好地处理这些子运算。第三，在数字化后能保留最多信息的区域精心选择阈值。

与传统的模拟 ReRAM 交叉阵列 [145, 146] 相比，数字 ReRAM 交叉阵列的优势如下：

*   它在工艺变异下具有更好的 ReRAM 器件编程精度，且无需额外的 ADC 转换。
*   由于数字 ReRAM 交叉阵列中仅配置 LRS 和 HRS，因此不需要高 HRS/LRS 比，从而可以采用低功耗（高 LRS）器件 [139]。此外，使用低功耗 ReRAM 器件时，线电阻对 IR 压降的影响很小。
*   二进制输入电压在大尺寸交叉阵列中对 IR 压降具有更好的鲁棒性。

然而，在数字 ReRAM 交叉阵列实现中，ReRAM 器件的面积和能耗会增加。这将在第 3.5 节中讨论。

#### 3.2.2 ReRAM 交叉阵列的连接方式

ReRAM 交叉阵列有三种连接方式：直接连接 ReRAM、一晶体管一 ReRAM (1T1R) 和 1S1R。下面将详细描述这些方法及其差异。

##### 3.2.2.1 直接连接 ReRAM

直接连接 ReRAM，也称为无源 ReRAM 阵列，是一种仅包含 ReRAM 器件的交叉阵列结构。每条 WL 和 BL 通过单个漂移型 ReRAM 相连。直接连接 ReRAM 的结构如图 3.14(a)所示，此处以 `N` 条 WL（`i ∈ [1, N]`）和 `M` 条 BL（`j ∈ [1, M]`）为例。要执行写操作，需要在 `WL[i]` 和 `BL[j]` 之间施加写电压 `V_write`。在这种情况下，连接它们的 ReRAM（`R_ij`）可以被精确配置。

![图 3.14 ReRAM 交叉阵列实现对比：(a) 含偷路的直接连接；(b) 需额外控制信号的 1T1R；(c) 无需额外控制信号的无偷路 1S1R；(d) 模拟与数字接口对比](img/PBPC0390-03-f14.jpg)

然而，这种结构存在偷路问题。在该示例中，紫色路径是我们期望的理想电流路径，但可能存在另一条由绿色标识的路径。该路径由 `R_ik`、`R_lk` 和 `R_lj` 组成，因此我们可以看到 `V_write` 也施加在了这三个 ReRAM 的串联上。在某些情况下，其中两个处于 LRS，一个处于 HRS，导致处于 HRS 的 ReRAM 器件上施加了非常大的电压。在这种情况下，该 ReRAM 的状态也可能被配置，这是我们不希望发生的。

##### 3.2.2.2 一晶体管一 ReRAM

在 1T1R 结构中，正如文献 [145] 所示，一个 NMOS 晶体管与每个 ReRAM 器件串联连接。因此，每条字线 (WL) 通过一个晶体管和一个 ReRAM 连接到一条位线 (BL)，如图 3.14(b)所示。NMOS 晶体管用作电压控制选择器，以便我们可以配置每个 ReRAM 单元的连通性。1T1R 的主要优势在于避免了直接连接结构中的偷漏路径。在图 3.14(b)中，我们使用一个信号来控制连接到同一 WL 的晶体管。显而易见，我们只需在目标 `V_WL`、`V_BL` 上施加电压，并仅将 `V_WL` 置高；只有目标单元才能被配置。该结构的指标可总结如下：

*   对 ReRAM 器件非线性要求低，因为电压仅施加在目标单元上。
*   控制器设计比直接连接结构容易得多。

然而，1T1R 结构仍有一个缺点，即交叉阵列面积取决于晶体管，与 ReRAM 器件相比不可缩放。因此，当 ReRAM 交叉阵列尺寸较大时，这不是一个好的选择。

##### 3.2.2.3 一选择器一 ReRAM

一种无偷漏路径的数字 ReRAM 交叉阵列如图 3.14(c)所示。在此架构中，每个漂移型 ReRAM 与一个扩散型 ReRAM（作为选择器）串联连接。与前两种实现相比，1S1R 可保持良好的可扩展性，且无需额外控制器即可消除偷漏路径。与文献 [150] 相比，选择器的 `R_OFF` 仅对数字 ReRAM 的操作产生微小影响。由于如图 3.10 所示 `R_OFF >> R_ON`，1S1R 的静态电阻几乎等于 `R_ON`。此外，当选择器处于关断状态时，施加电压的大部分分布在选择器器件上。由于每条偷漏路径至少会连接三个 1S1R，因此工作电压 `V_OP` 只需满足以下方程即可消除偷漏路径：

```
V_OP > 3 * V_TH
```

我们将在第 3.7.5 节进一步讨论关于无偷漏路径效应的仿真结果。

### 3.3 基于 ReRAM 的振荡器

文献 [151, 152] 中观察到了 ReRAM 器件中的振荡行为，这是由漂移型 ReRAM 的成形过程实现的。最近的扩散型 ReRAM [137, 138] 显示了作为振荡器的可行性。基于 ReRAM 的振荡器可如图 3.15(a)所示构建。在此基于 ReRAM 的振荡器中，一个物理电阻 `R_S` 与 ReRAM 器件串联。输出电压将取决于 `R_S` 与 ReRAM 电阻 `R_R` 的比例。随着电容 `C` 的充/放电，输出电压 `V_OUT` 将趋近于 `V_DD`。为了使振荡工作，我们对结构中的 ReRAM 器件有以下要求：

*   在相对较高的电压 `V_TH` 下，ReRAM 的电阻 `R_R` 显著降低至 `R_ON`。
*   如果我们将电压降至较低值 `V_H`，`R_R` 将升高至 `R_OFF`。

![Figure 3.15](img/PBPC0390-03-f15.jpg)

因此，如果图 3.15(a) 中的所有参数都经过良好拟合，我们可以建立振荡，公式如下：

```

```
