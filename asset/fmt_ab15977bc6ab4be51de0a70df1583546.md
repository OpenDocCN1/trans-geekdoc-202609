```solidity
pragma solidity ^0.8.0;

contract DecentralizedIdentity {
    struct Identity {
        string name;
        uint256 age;
        address wallet;
    }

    mapping(address => Identity) public identities;

    function createIdentity(string memory name, uint256 age) public {
        identities[msg.sender] = Identity(name, age, msg.sender);
```

### 智能合约

智能合约管理列表中的任务。

```solidity
pragma solidity ^0.8.0;

contract ToDoList {
    struct Task {
        uint256 id;
        string content;
        bool completed;
    }

    uint256 public taskCount;
    mapping(uint256 => Task) public tasks;

    event TaskCreated(uint256 id, string content, bool completed);
    event TaskCompleted(uint256 id, bool completed);

    function createTask(string memory content) public {
        taskCount++;
        tasks[taskCount] = Task(taskCount, content, false);
        emit TaskCreated(taskCount, content, false);
    }

    function toggleComplete(uint256 id) public {
        Task storage task = tasks[id];
        task.completed = !task.completed;
        emit TaskCompleted(id, task.completed);
    }
}
```

1. **函数 `createTask()`**  
   创建新任务并发出事件以通知创建。

2. **函数 `toggleComplete()`**    
   在完成和未完成之间切换任务状态。

### 合约部署

编辑迁移文件 `2_deploy_contracts.js` 以部署合约：

```javascript

module.exports = function (deployer) {
    deployer.deploy(ToDoList);
};
```

**启动 Ganache：**

```bash

```

**编译并部署合约：**


**下载与安装：**

```bash
sudo apt install software-properties-common
sudo add-apt-repository -y ppa:ethereum/ethereum
sudo apt update
sudo apt install ethereum
```

**启动节点：**

```bash
geth --http --syncmode "light"
```

### 配置私有网络

**创世文件创建：**  
创建一个名为 `genesis.json` 的文件。

```json
{
  "config": {
    "chainId": 1234,
    "homesteadBlock": 0,
    "eip150Block": 0,
    "eip155Block": 0,
    "eip158Block": 0
  },
  "difficulty": "1",
  "gasLimit": "8000000",
  "alloc": {}
}
```

**初始化网络：**

```bash
geth init genesis.json
```

**启动：**

```bash
geth --networkid 1234 --http
```

# 最终结论

## 对区块链在数字社会中角色的反思

区块链不仅仅是一项技术；它是一个日益数字化和互联社会中深刻变革的催化剂。凭借其去中心化控制、确保透明度和促进安全的能力，区块链正在重新定义我们与数据、系统以及彼此互动的方式。

在一个信任往往需要由第三方中介的世界里，区块链提供了一个强大的新范式：一种通过直接在技术中创造信任来消除中介的系统。这种变革影响广泛，从强化个人隐私到重塑医疗、金融、物流和治理等领域的整个价值链。

区块链还通过使数百万传统银行体系之外的人能够通过去中心化网络获得金融服务，在推动金融普惠方面发挥着关键作用。这种普惠对于创建一个更公平的社会至关重要，在这样的社会中，机会不受地理或制度障碍的限制。

同时，区块链面临着需要解决的挑战，以使其大规模采用具有可持续性。可扩展性、环境影响和监管等问题需要创新的解决方案以及行业、政府和技术社区之间的协作。然而，持续的进步和新兴创新（如区块链 3.0 和 Web3 集成）表明，我们才刚刚开始探索这项变革性技术的全部潜力。

区块链在数字社会中的角色不仅限于作为效率或创新的工具。它代表了一场向更透明、协作和赋权的未来迈进的哲学和技术运动。随着我们不断前进，区块链将成为数字基础设施的重要组成部分，塑造我们与系统、数据以及至关重要的彼此互动的方式。
