
𝔼 \[(y−f(x))²\] = 𝔼 \[(y−𝔼[y|x])²\] + (𝔼[y|x]−f(x))²

其中我们考虑到，对于固定的 `x`，项 `𝔼[y|x]` 和 `f(x)` 不是随机变量。从公式 (3.49) 我们最终得到我们的结论：

𝔼 \[(y−f(x))²\] ≥ 𝔼 \[(y−𝔼[y|x])²\]

 □

注意这是一个非常优雅的结果。在均方误差（MSE）意义上，未知函数在点 `x` 处值的最优估计由 `ĝ(x) = 𝔼[y|x]` 给出。有时，后者也被称为 `y` 关于 `x = x` 的条件回归。这通常是一个非线性函数。可以证明，如果 `(y, x)` 取值于 `ℝ × ℝ^l` 且服从联合高斯分布，则最优 MSE 估计器 `𝔼[y|x]` 是 `x` 的线性（仿射）函数。

前面的结果推广到 `y` 是取值于 `ℝ^k` 的随机向量的情况。给定 `x = x` 的值，最优 MSE 估计等于：

```
ĝ(x) = 𝔼[y|x],
```

现在 $\widehat{\mathbf{g}}(\mathbf{x}) \in \mathbb{R}^{k}$（问题 3.15）。此外，如果 $(\mathbf{y}, \mathbf{x})$ 是联合高斯随机向量，则 MSE 最优估计器也是 $\mathbf{x}$ 的仿射函数（问题 3.16）。

本小节的发现可以通过物理推理完全证明。为简单起见，假设公式 (3.46) 中的噪声源均值为零。那么，对于固定值 $\mathbf{x} = \mathbf{x}$，我们有 $\mathbb{E}[y|\mathbf{x}] = g(\mathbf{x})$，相应的 MSE 等于

MSE $= \mathbb{E}[(y - \mathbb{E}[y|\mathbf{x}])²] = \sigma_{\eta}²$。 (3.51)

没有其他 $\mathbf{x}$ 的函数能做得更好，因为最优函数达到的 MSE 等于噪声方差，这是不可约的；它代表了系统的内在不确定性。正如公式 (3.49) 所示，任何其他函数 $f(\mathbf{x})$ 将导致 MSE 增加量 $(\mathbb{E}[y|\mathbf{x}] - f(\mathbf{x}))²$，这对应于与最优函数的偏差。

### 3.9.2 偏差-方差权衡

我们刚刚看到，在 MSE 意义下，回归任务中因变量的最优估计器由条件期望 $\mathbb{E}[y|\mathbf{x}]$ 给出。在实践中，任何估计器都是基于特定的训练数据集计算的，例如 $\mathcal{D}$。让我们显式地表达对训练集的依赖，并将估计器表示为由 $\mathcal{D}$ 参数化的 $\mathbf{x}$ 的函数，即 $f(\mathbf{x}; \mathcal{D})$。量化估计器性能的一个合理度量是其与最优估计器的均方偏差，用 $\mathbb{E}_{\mathcal{D}}[(f(\mathbf{x}; \mathcal{D}) - \mathbb{E}[y|\mathbf{x}])²]$ 表示，其中均值是针对所有可能的训练集计算的，因为每个训练集都会导致不同的估计器。遵循与公式 (3.22) 类似的路径，我们得到

正如在 MSE 参数估计任务中更换训练集时那样，与最优估计器的均方偏差包含两项。第一项是估计器围绕其自身均值的方差，第二项是该均值与最优均值的平方差，即偏差。结果表明，*不能*同时使*两项*都变小。对于数据集 𝒟 中固定数量的训练点 *N*，试图最小化方差项会导致偏差项增加，反之亦然。这是因为为了减小偏差项，必须增加所采用估计器 *f*(⋅;𝒟) 的复杂度（更多自由参数）。这反过来又会导致在更换训练集时方差增大。这是我们已经讨论过的过拟合问题的一种表现。同时减小这两项的唯一方法是增加训练数据点的数量 *N*，同时*仔细*增加模型的复杂度，以实现上述目标。如果在增加训练点数量的同时过度增加模型复杂度，总体 MSE 可能会增加。这被称为*偏差-方差困境*或*权衡*。这是任何估计任务中普遍存在的问题。通常，我们将其称为*奥卡姆剃刀*法则。

奥卡姆是一位逻辑学家和唯名论经院中世纪哲学家，他提出了以下节约法则：“勿以多元论之，若无必要。”伟大的物理学家保罗·狄拉克（1902–1984）从美学角度表达了相同的观点，这构成了数学理论的基础：“一个具有数学之美的理论，比一个丑陋但符合数据的理论更有可能是正确的。”在我们的模型选择语境中，这意味着必须选择能够“解释”数据的最简单模型。尽管这不是一个科学证明的结果，但它构成了许多已开发的模型选择技术 [1,32,33,40] 和 [37, Chapter 5] 背后的基本原理，这些技术在复杂度与准确性之间进行权衡。

现在让我们尝试通过考虑所有可能的集合 𝒟 来求给定 **x** 下的 MSE。为此，请注意，如果在符号中显式引入 𝒟，则公式 (3.52) 的左边是关于 𝒟 的均值，作用于公式 (3.49) 的第二项。很容易看出，通过重新考虑公式 (3.49) 并对 y 和 𝒟 同时取期望，给定 **x** = **x** 的值，得到的 MSE 变为（请尝试推导，遵循类似于公式 (3.52) 的论证）

```
MSE(x) = E[y|x] E[D] [(y - f(x;D))²] = σ[η]² + E[D] [(f(x;D) - E[D][f(x;D)])²] + (E[D][f(x;D)] - E[y|x])²
```

(3.53)

这里使用了公式 (3.51)，并利用了第 2 章所述的乘积法则。接下来，可以对 `x` 取均值。换句话说，这是在所有可能训练集上平均后的、针对所有可能输入的预测 MSE。所得的 MSE 也称为*测试*误差或*泛化误差*，它是衡量所采用模型性能的指标。请注意，公式 (3.53) 中的泛化误差涉及对（理论上）所有特定规模 `N` 的可能训练数据集进行平均。相反，所谓的*训练误差*是在单个数据集（即用于训练的那个数据集）上计算的，这会导致对误差的过于乐观的估计。我们将在第 3.13 节中回到这个重要问题。

让我们考虑一个简单但具有教学意义的例子，以演示偏差和方差之间的这种权衡。我们得到一组训练点，它们是根据以下形式的回归模型生成的：

```
y = g(x) + η.
```

函数 `g(x)` 的图形如 图 3.7 所示。函数 `g(x)` 是一个五阶多项式。训练集的生成方式如下。对于每个集合，在区间 `[-1, 1]` 内以 `N` 个等距点 `x[n]`，`n = 1, …, N` 对 `x` 轴进行采样。然后，每个训练集 `D[i]` 创建为：

```
D[i] = {(x[n], g(x[n]) + η[n, i]): n = 1, 2, …, N},  i = 1, 2, …
```

其中 `η[n, i]` 表示从白噪声过程中独立同分布（i.i.d.）抽取的不同噪声样本。换句话说，由于噪声值不同，所有训练点具有相同的 `x` 坐标但不同的 `y` 坐标。图 3.7 中 `(x, y)` 平面上的灰点对应于 `N = 10` 情况下训练集的一个实现。为了比较，无噪声点集 `(x[n], g(x[n]))`，`n = 1, 2, …, 10` 显示为 `g(x)` 图上的红点。

观测数据用灰点表示。这些是将噪声添加到红点（位于与未知 `g(⋅)` 相关的红色曲线上）后的结果。用固定多项式 `f₁(x)` 拟合数据会导致高偏差；观察可知，大多数数据点都位于直线之外。另一方面，“估计量”的方差将为零。相反，拟合高次多项式 `f₂(x; 𝒟)` 会导致低偏差，因为相应的曲线穿过所有数据点；然而，相应的方差将很高。

首先，我们将非常天真地选择一个固定的线性模型来拟合数据，

```
ŷ = f₁(x) = θ₀ + θ₁x
```

其中 `θ₁` 和 `θ₀` 的值是任意选取的，与训练数据无关。这条直线的图形如 图 3.7 所示。由于未涉及训练且模型参数是固定的，因此随着训练集的改变不会产生变化，且 `𝔼[𝒟][f₁(x)] = f₁(x)`，方差项等于零。另一方面，偏差的平方等于 `(f₁(x) − 𝔼[y|x])²`，预计会很大，因为模型的选择是任意的，未考虑训练数据。

接下来，我们转向另一个“极端”。我们选择一个相对复杂的函数类，例如高阶（10 阶）多项式 `f₂`。生成的估计值对用于训练的相应集合 `𝒟` 的依赖关系显式地表示为 `f₂(⋅; 𝒟)`。请注意，对于每一个集合，相应的最优模型图形预计都将穿过训练点，即

```
f₂(xₙ; 𝒟ᵢ) = g(xₙ) + ηₙ,ᵢ,  n = 1, 2, …, N.
```

这在 图 3.7 中针对一条曲线展示了。请注意，通常如果多项式（模型）的阶数很大，且待估计的参数数量大于训练点的数量，这总是成立的。对于图中所示的例子，我们给出了 10 个训练点，而对于一个 10 阶多项式（包括偏置项），需要估计 11 个参数。通过求解一个包含 10 个方程（`N = 10`）和 11 个未知数的线性方程组，可以在训练点上获得完美拟合。这就是当模型阶数很大时，可以在训练数据集上实现*零*（或实际上非常小）误差的原因。我们将在第 3.13 节中回到这个问题。

对于这个高阶多项式拟合的实验设置，以下推理成立。每个点 $x_n$ 处的偏差项为零，因为

$$

\mathbb{E}_{\mathcal{D}}[f_2(x_n;\mathcal{D})] = \mathbb{E}_{\mathcal{D}}[g(x_n)+\eta] = g(x_n) = \mathbb{E}_{\mathcal{D}}[y|x_n].

$$

另一方面，点 $x_n$ ($n=1,2,\dots,N$) 处的方差项预计会很大，因为

$$

\mathbb{E}_{\mathcal{D}} \left[(f_2(x_n;\mathcal{D})-g(x_n))²\right] = \mathbb{E}_{\mathcal{D}} \left[(g(x_n)+\eta-g(x_n))²\right] = \sigma_\eta².

$$

假设函数 $f_2$ 和 $g$ 足够连续平滑，且点 $x_n$ 采样得足够密集以覆盖实轴上的感兴趣区间，我们预期在所有点 $x \neq x_n$ 处会有类似的行为。

## 3.10 最大似然方法

到目前为止，我们将估计问题视为围绕一组训练样本的优化任务，而未关注生成这些点的潜在统计规律。我们仅利用统计学来检验估计量在何种条件下是有效的。然而，优化步骤并未涉及任何统计信息。在本章剩余部分，我们将越来越多地引入统计学。在本节中，将介绍*最大似然*（ML）方法。毫不夸张地说，ML 和 LS 是参数估计所依托的两大支柱，也是新方法灵感的源泉。ML 方法由 Ronald Aylmer Fisher 爵士提出。

我们将再次首先在一般设定下阐述该方法，独立于回归/分类任务。给定一组 $N$ 个观测值，$\mathcal{X} = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_N\}$，它们源自某概率分布。我们假设这 $N$ 个观测值的联合 PDF 属于已知的参数化函数类型，记为 $p(\mathcal{X}; \boldsymbol{\theta})$，其中参数向量 $\boldsymbol{\theta} \in \mathbb{R}^K$ 未知，任务是估计其值。该联合 PDF 称为给定观测集 $\mathcal{X}$ 下 $\boldsymbol{\theta}$ 的*似然函数*。根据 ML 方法，估计值由下式给出

### 最大似然估计的性质

根据最大似然方法，我们假设给定观测集合，未知参数的估计值是使相应似然函数最大化的值。

由于对数函数 `ln(·)` 是单调递增的，因此可以转而寻找*对数似然函数*的最大值：

```
∂ln p(X;θ) / ∂θ |_{θ = θ̂_ML} = 0.  (3.56)
```

假设观测值是独立同分布（i.i.d.）的，最大似然估计量具有以下一些非常吸引人的性质：

*   **渐近无偏**：即假设我们采用的概率密度函数（PDF）模型是正确的，且存在真实参数 `θ_o`，则有

    ```
    lim_{N→∞} E[θ̂_ML] = θ_o.  (3.57)
    ```

*   **渐近一致性**：即给定任意 `ε > 0`，

    ```
    lim_{N→∞} Prob{ |θ̂_ML - θ_o| > ε } = 0,  (3.58)
    ```

    也就是说，对于较大的 `N` 值，我们期望最大似然估计值以高概率非常接近真实值。

*   **渐近有效性**：即它达到了克拉梅-罗下界。

*   **充分统计量性质**：如果存在未知参数的充分统计量 `T(X)`，则仅凭 `T(X)` 即可表达相应的最大似然估计量（习题 3.20）。

*   **最优性**：此外，假设存在有效估计量，则该估计量在最大似然意义上是最优的（习题 3.21）。
