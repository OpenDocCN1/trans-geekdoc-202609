###### 分层专家混合模型

专家混合模型概念的一个直接推广是以分层方式增加更多层级的门控函数，从而产生所谓的 `分层专家混合模型` (HME)。这一思想在图 12.13 的框图中得到了说明。这种架构类似于树结构，专家作为叶节点，门控网络作为非终端节点，输出（求和）节点作为根节点。分层专家混合模型将空间划分为一组嵌套区域，在分层放置的门控网络控制下，专家之间的信息得以组合。这种层级结构符合更一般的“分而治之”策略思想。

![图 12.13 具有两层层级的分层专家混合模型框图。](img/gr013.jpg)

图 12.13 具有两层层级的分层专家混合模型框图。

与决策树相比，HME 围绕软决策规则演化，这与 CART 中采用的硬决策规则形成对比。硬决策通常会导致信息丢失。一旦做出决策，以后就无法更改。相反，软决策规则赋予网络保留信息的优势，直到做出最终决策。例如，根据硬决策规则，如果一个样本位于靠近决策面的位置，它将根据其所在一侧的标签进行标记。然而，在软决策规则中，与该点相对于决策面的位置相关的信息将被保留，直到必须做出最终决策的阶段，此时会考虑到随着处理过程发展而变得可用的更多信息。

注意，专家混合模型的训练也可以通过另一条路径进行，即通过优化代价函数，而无需采用概率论证（另见例如 [19]）。

### 12.9.2 混合逻辑回归模型

遵循第 12.9.1 节，组合原理也可应用于分类任务。为此，我们为每个专家采用二分类逻辑回归模型，给定输入值 `x` 的组合规则现在写为

```
P(y; Ξ, P) = Σ_{k=1}^K P_k s_k^y (1 - s_k)^(1 - y),
```

其中使用了第 7.6 节中 logistic 回归的定义，标签 `y ∈ {0, 1}` 的值分别对应两个类别 `ω_1` 和 `ω_2`，并且

```
s_k := σ(θ_k^(T) x)
```

表示第 `k` 个专家的输出。同第 12.9.1 节一样，`Ξ` 是未知参数集，`P` 是门控网络对应的集合。调用与线性回归情况类似的论证，我们可以很容易地说明完整数据集的似然由下式给出

```
P(y, Z; Ξ, P) = Π_{n=1}^N Π_{k=1}^K (P_k s_nk^y_n (1 - s_nk)^(1 - y_n))^z_nk,
```

其中 `s_nk := σ(θ_k^(T) x_n)`，`y` 是训练样本标签 `y_n` (`n = 1, 2, …, N`) 的集合。遵循 EM 算法应用于相应对数似然函数的标准论证，可以很容易地证明第 `j` 次迭代的 E 步由下式给出

```
Q(Ξ, P; Ξ^(j), P^(j)) = Σ_{n=1}^N Σ_{k=1}^K γ_nk (ln P_k + y_n ln s_nk + (1 - y_n) ln(1 - s_nk)),
```

![Equation](img/si421.png)(12.110)

其中

```
γ_nk = E[z_nk] = P(k | y_n, Ξ^(j), P^(j)) = (P_k^(j) s_nk^y_n (1 - s_nk)^(1 - y_n)) / (Σ_{i=1}^K P_i^(j) s_ni^y_n (1 - s_ni)^(1 - y_n)).
```

![Equation](img/si422.png)(12.111)

请注意，在公式 (12.111) 中，本应使用符号 `s_nk^(j)`, `s_ni^(j)`，但我们试图使其稍微简洁一些。

在 M 步中，关于 `P_k` 的极大化形式与回归任务中的相同，其结果为

```
P_k^(j + 1) = (1/N) Σ_{n=1}^N γ_nk.
```

为了获得专家的参数，必须采用迭代方案。观察可知，方程 (12.110) 与方程 (7.38) 的唯一区别在于：(a) 存在涉及 `P[k]` 的项，(b) 对 `k` 求和，以及 (c) 存在乘法因子 `γ[nk]`。前两点在针对单个 `θ[k]` 的优化中不起任何作用，而后者只是一个常数。因此，该优化类似于第 7.6 节中用于二分类逻辑回归的优化，梯度和 Hessian 矩阵相同，仅乘法因子不同（以及符号不同，因为那里考虑的是负对数似然）。向多类情况的扩展是直接的，并遵循类似的步骤。
