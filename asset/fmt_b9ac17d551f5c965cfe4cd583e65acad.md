## 3.1 引言

印度系语言的光学字符识别（OCR）由于其在许多实时应用中的广泛使用，最近越来越受到关注。早期的大多数工作显示出在英语、日语和中文等语言上具有更高的识别性能。然而，奥里亚语（Odia）的性能远未满足实时需求。奥里亚语是印度的宪法语言之一，专门用于奥里萨邦、贾贾坎德邦和西孟加尔邦。约有2700 万人使用奥里亚语作为基本交流语言。奥里亚语 OCR 模型的主要挑战在于如何高精度地检测字符。奥里亚字母包含 400 多个字符类，包括元音、辅音、变音（元音变体）、复合字符（辅音变体）、某些特殊符号和数字。所提议的方法将字符识别任务分为 211 类字符，并使用三阶段混合架构来检测类别标签。值得一提的是，该方法仅适用于奥里亚字符。

OCR 的发展有着丰富的历史 [8, 30, 37]。从 OCR 机器到现代基于软件的识别系统，主要目标是忽略字符的位置、字体大小及其在视觉视野中的方向，进行识别和分类。随着现代设备的出现，独立字体风格检测也成为一个有趣的研究领域。广而言，OCR 系统有两个步骤，即字符提取和字符检测。提取过程涉及图像增强 [1]、倾斜和错误纠正、二值化 [18, 19, 42–44]、行词分离以及字符分离。图像增强和错误消除技术旨在使图像做好 OCR 准备。这些步骤被整体视为预处理步骤，随后可以是字体检测过程 [31]。字体检测通过利用特定字体的检测算法提高准确性。关于奥里亚字符识别的报道较少，且在大多数案例中，仅考虑了基础字符 [7, 29]。许多研究人员已对印度语言（如孟加拉语 [6, 11] 和天瓦那特语 Devnagari [34]）中的基础和复合字符进行了研究。Chaudhuri 等人 [6] 研究了孟加拉语的 35 个变体字符并实现了 96% 的准确率。随后，Garain 等人 [17] 使用基于运行数的方法研究了孟加拉字母的 300 个变体，在自收集的数据集上显示出 99.69% 的准确率，而天瓦那特语字符识别获得了 96.00% 的准确率。然而，其他印度文字（如卡纳塔德语 Kannada [33]、古鲁木语 Gurmukhi）的性能仍有待显著提高。

关于奥里亚字符识别的研究报道较少。许多研究已开展手写奥里亚 OCR。Padhi 等人 [32, 33] 基于尺寸和统计信息设计并使用 `ANN` 分类奥里亚变体，在自收集的数据集上获得了 94% 的准确率。Pal 等人 [36] 使用二次分类器和梯度曲率对 52 类奥里亚字符实现了 91% 的准确率。Kumar 等人 [20] 使用蚁算法对 50 类手写奥里亚字符提出了一种方法，实现了 90% 的准确率。Basa 等人 [4, 25] 展示了一个分类系统，使用树方法将奥里亚字符分为两组，并进一步使用不同的 `ANN`。他们形成了 51 类手写奥里亚字符数据集，并显示其方法提供了 90% 的总体准确率。Das 等人 [10] 使用极端学习机（`ELM`）对奥里亚字符提出模型，并分析了 `ELM` 参数及其对准确率的影响。

同样，已发表许多手写奥里亚数字的作品，总结如下。Sarangi 等人 [41] 报告了最早的手写奥里亚数字识别工作之一，使用霍普菲神经网络（Hopfield neural network）实现了 95.4% 的准确率。随后，Sarangi 等人 [39] 通过使用下界和上界（LU）网络提出了一种识别模型，其准确率达到 85.3%。Bhowmik 等人 [5] 使用隐隐马尔可夫模型报告了奥里亚数字的出现，实验获得了 90.5% 的结果。Roy 等人 [38] 研究了用于手写识别的直方图特征，并实现了 94.81% 的准确率。Sarangi 等人 [40] 使用 LU 分解和朴素分类器获得了 85.3% 的准确率。Dash 等人 [12] 使用曲率和已知分类器作为判别函数和改进判别函数，分别实现了 98.4% 和 98.5% 的准确率。Mishra 等人 [26] 独立研究了 DCT 和小波特征。Dash 等人 [14] 使用基于区域的小波变换和 `k-NN` 分类器提出了奥里亚数字识别。Mahto 等人 [24] 设计了一种方法，带有象限均特征的简单 `ANN` 可以实现 93.2% 的准确率。Mishra 等人 [28] 使用轮廓特征在奥里亚数据集上产生了 96.3% 的准确率。Mishra 等人 [27] 使用弦和角度特征构建手写奥里亚模型。Dash 等人 [15] 使用基于二值对称性的特征和自收集的数字数据集实现了 95% 的准确率。

从文献综述可以看出，大多数研究仅限于检测 51 个基础奥里亚字符和十个数字字符。奥里亚语有超过 400 类字符，这些字符是由一个或多个基础字符生成的。一些示例字符及其类别如图 3.1 所示。此外，上述大多数工作致力于描绘 11 个元音，

## 3.2 背景

### 3.2.1 通用 OCR 阶段

通常，完整的 OCR 过程分为多个阶段。图像采集是任何计算机视觉应用的第一步也是关键的一步。对于字符识别，通过平板扫描仪捕捉图像。也可以使用强大的手机摄像头获取文档的数字图像，但这需要额外的处理。在图像采集后，通过预处理步骤去除已知错误。图像增强、去噪、倾斜检测与修正、页面分割、二值化和字体检测是 OCR 模型中使用的若干预处理方法。分割是分离行、单词和字符的过程，在手写和触摸式字符识别中对确定识别准确率具有更高的意义。每个分离的字符都被输入到模型中以确定类别标签。模型可以通过各种学习和分类方法以及特征匹配模型（特征+模板）推导出。识别出字符类别后，必须将相应的 ASCII 或 Unicode 代码写入文本文件。在此阶段，同时处理单词和行的分离至关重要。从分割步骤获得的信息在此处文中使用，尽管识别过程可能无法产生预期结果。标点和错误的存在可能导致某些不必要的字符，这可以通过后字典匹配和上下文信息来解决。通用模型的概述如图 3.2 所示。

### 3.2.2 结构相似性

人眼关注图像的结构而非亮度和对比。`SSIM` [47] 通过给图像质量一个类似于人类主观评价的值来解释这一点。这在公式 3.1 和 3.2 中用数学表达式表示。`SSIM` 的整体展示如图 3.3 所示。

```
$SSIM = [l(x,y)]^c [c(x,y)]^c [s(x,y)]^c \quad (3.1)$
```

其中 `$s$` 代表结构，`$c$` 代表对比，`$l$` 代表局部亮度。该表达式与人类视觉系统相关，通过取 `$a = \beta = \gamma = 1$` 可以简化为：

```
$SSIM = \frac{(2\mu_x\mu_y + C_1)(2\sigma_{xy} + C_2)}{(\mu_x^2 + \mu_y^2 + C_1)(\sigma_x^2 + \sigma_y^2 + C_2)} \quad (3.2)$
```

其中 `$C_1 = (K_1 L)^2，$C_2 = (K_2 L)^2，$L$` 代表最高强度。`$K_1$` 和 `$K_2$` 的值通过哲学研究计算，并分别设置为 0.01 和 0.03。

`SSIM` 在结构域而非误差域评估图像。因此，对于每个模板，目标图像的分数不同。它的范围从 0 到 1，较高的值表示匹配良好。实验观察到，211 类字符的识别性能非常对于

### 3.2.5 通用回归神经网络 (`GRNN`)

`GRNN` [45] 由 Specht 于 1991 年开发，该网络的主要优势是不需要训练。对于给定的训练集 `$(x_i, y_i)$`，从自变量 `$x_{test}$` 估计未知因变量 `$y_{test}$` 的公式如下：

```
$y_{test} = \sum_{i=1}^{n} y_i \exp\left(-\frac{D_i^2}{2\sigma^2}\right) \quad (3.8)$
```

其中 `$\sigma$` 是平滑因子（此处选择为 `$\sqrt{2}$`），`$p$` 是维度 `$X$`，`$n$` 是训练集的大小，`$D_i$` 是 `$x_{test}$` 到每个对应 `$x_i$` 的距离。这里使用欧几得距离计算 `$D_i$`，并表示为：

```
$D_i^2 = \sum_{j=1}^{p} (x_{j,i} - x_{test,j})^2 \quad (3.9)$
```

图 3.6 显示了 `GRNN` 网络的整体模型，它可以处理前一阶段预测的动态性质。当预测多标签时，预测并不总是一致的，这取决于输入的性质。`GRNN` 可以在单次通过中以高精度比较并预测输出标签。这是基于每个类预先计算的样本；因此它可以处理噪声。为了固定样本量，我们对每个类执行了 `k-means` 聚类，**k** 值为 50。每个类存储了 50 个聚类中心，以作为 `GRNN` 模型的模式输入。

### 3.3 提出的方法

提出的预测模型由三个阶段组成。第一阶段使用基于 `SSIM` 的模板匹配将可能的预测标签数量减少到 20 个。这些可能的字符类根据其几何形状进一步减少到十类。在此阶段，我们使用了投影轮廓匹配来从几何上匹配相似字符。字符的最终预测在最后一个阶段通过机器学习学习方法完成。我们采用了 `LFD` 特征和 `GRNN` 来预测最终类别。所提三阶段混合模型的整体框图如图 3.7 所示。模型的每个阶段在算法 3.1 到 3.3 中描述。

![](img/d1bf16e7dc1fe5d49ee33c2dfa5cdb06_71_0.png)

**图 3.7** 所提混合模型的框图。

#### **算法 3.1:** 第一阶段检测算法

```
**数据：** 模板图像 $\{I_1, I_2, \dots, I_m\}$ 和预处理格式的测试字符图像 $(T)$
**结果：** 前 20 个可能的字符
**for** $I_k \leftarrow \{I_1, I_2, \dots, I_m\}$ **do**
	将 $I_k$ 和 $T$ 调整大小为 $60 \times 60$;
	$S_k \leftarrow SSIM(I_k, T)$;
**end**
返回最大 $S_k$ 的 20 个字符类
```

#### 算法 3.2: 第二阶段检测算法

**数据：** 来自第一阶段的 20 个模板图像 `{$I_1, I_2, \dots, I_{20}$}` 和预处理格式的测试字符图像 (`T`)

**结果：** 最可能的字符

```
$[Top_k, Left_k, Bottom_k, Right_k] =ProjectionCount(T)$;
for $I_k \leftarrow \{I_1, I_2, \dots, I_{20}\}$ do
  $[Top_k, Left_k, Bottom_k, Right_k] =ProjectionCount(I_k)$;
  $\tau_k = KRCC([Top_k, Left_k, Bottom_k, Right_k], [Top_k, Left_k, Bottom_k, Right_k])$
end

丢弃所有 KRCC 为 0 或负值的选项；
返回具有最大 $\tau_k$ 的最多 10 个字符类；
```

#### 算法 3.3: 第三阶段检测算法

**数据：** 来自第二阶段的 `{(DI_1, Y_1), (DI_2, Y_2), \dots, (DI_{10}, Y_{10})}` 特征集和预处理格式的测试字符图像 (`T`)，其中 `$DI_i = \{DI_i^1, DI_i^2, \dots, DI_i^{s_i}\}$`；

**初始化：** `$\sigma = \sqrt{2}$`

**结果：** 最终字符标签预测 `Y`

```
$DI_T \leftarrow LFD(T)$;
for $i \leftarrow 1, 2, \dots, 10$ do
  对于 $DI_i$ 中的每个样本 $j$ do
    $D_{i,j}^2 = \sqrt{\sum_{k=1}^{s_i} (DI_i^k - DI_T^k)^2}$;
    $Y_{i,j} = \text{vector}(i, 10)$;
  end
end

$Y_p = \frac{\sum_{i=1}^{10} \sum_{j=1}^{s_i} Y_{i,j} \exp(-\frac{D_{i,j}^2}{2\sigma^2})}{\sum_{i=1}^{10} \sum_{j=1}^{s_i} \exp(-\frac{D_{i,j}^2}{2\sigma^2})}$;
$x = \arg_{max}(Y)$;
返回 $Y$;
```
