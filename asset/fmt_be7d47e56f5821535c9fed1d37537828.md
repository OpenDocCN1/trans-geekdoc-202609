## 1.2 张量库 numpy

张量也称为**多维数组**，是多个值的规则排列。张量运算是深度学习中最重要的运算。本章介绍 Python 张量库 numpy。

### 1.2.1 什么是张量？

最简单的张量是单个数字，也称为**标量**。例如 2、3.6 等都是标量。

#### 向量

##### Vectors and Matrices

###### Vectors

In physics, a vector is a quantity possessing both magnitude and direction; for example, force and velocity are both quantities with magnitude and direction. Vectors are represented as an ordered set of numbers through Cartesian coordinate decomposition, such as `(2, 5, 8)`, enabling vectors to be studied using mathematical methods. In linear algebra, a vector is defined as an ordered set of numbers, i.e., a one-dimensional array (1D tensor). Another example: a student's regular grade, lab grade, final exam grade, and overall grade can be represented as a vector: `(regular grade, lab grade, final exam grade, overall grade)`. The coefficients and unknowns of the equation `a*x[1] + b*x[2] + c*x[3] = d` can be represented as vectors: `(a, b, c, d)`, `(x[1], x[2], x[3])`.

In other words, vectors in linear algebra are abstractions of vectors from various practical problems. A vector (an ordered set of numbers) can be represented as: `a = (a[0], a[1], ..., a[n-1])`, where each number has a definite sequence number (or index) in this sequence. Vectors are also called **one-dimensional tensors** or **one-dimensional arrays**. A one-dimensional tensor can be represented by a sequence container, such as Python's `list`:

```python
a = [2, 5, 8]
a[1] = 30        # Access its elements via index
print(a[0], a[1], a[2])
```

Mathematically, vectors can be written in row or column form, called **row vectors** and **column vectors** respectively. For example, the column vector form corresponding to the row vector `(2, 3, 5)` is:

$$

\begin{pmatrix} 2 \\ 3 \\ 5 \end{pmatrix}

$$

A vector in this form is called a **column vector**.

The row and column forms of the same vector are called **transpose** relations; that is, the transpose of the row vector `(x[1], x[2], ..., x[n])` is its column vector.

$$

(x_{1}, x_{2}, \cdots, x_{n})^{T} = \begin{pmatrix} x_{1} \\ x_{2} \\ \vdots \\ x_{n} \end{pmatrix}

$$

Here, the superscript `T` denotes the transpose operation, converting a row vector into its column vector form. Conversely, a column vector can also be transposed into a row vector form:

$$

\begin{pmatrix} x_{1} \\ x_{2} \\ \vdots \\ x_{n} \end{pmatrix}^{T} = (x_{1}, x_{2}, \cdots, x_{n})

$$

A vector with only 2 values `(x, y)` can be visualized by a point (more precisely, a directed line segment) in a 2D Cartesian coordinate system. For example, the 2 elements of the vector `(1, 3)` represent a point on the 2D plane as x and y coordinates, shown as point A in Figure 1-5; the vector `(1, 3)` is represented by the directed line segment OA from the coordinate origin O to point A. The vector `(3, 1)` can be represented by coordinate point B, or by the directed line segment OB.

![](img/file207.png)

**Figure 1-5** A vector can be represented as a point on a plane, or as a directed line segment from the origin (starting point) to that point.

Therefore, a vector can be represented as a point on a plane, or as a directed line segment from a certain starting point (origin) to that point. When a vector is represented by a directed line segment, the starting point can be different from the origin; as long as two directed line segments have the same magnitude and direction, they represent the same vector. For example, CD and OB represent the same vector, where the coordinates of C and D are `(-0.5, 0.5)` and `(2.5, 1.5)` respectively.

Similarly, a vector with 3 values `(x, y, z)` can be visualized by a point or line segment in a 3D Cartesian coordinate system.

####### Vector Norms

For a vector `v = (x, y)` with 2 elements, its length can be represented by the Euclidean distance `sqrt(x² + y²)` from the coordinate point `(x, y)` to the origin `(0, 0)` on the Cartesian coordinate system. This distance `sqrt(x² + y²)` represents the distance from the coordinate point to the origin. This Euclidean distance is usually denoted by the symbol `||v||_2`, i.e.:

$$

\parallel v \parallel_{2} = \sqrt{x^{2} + y^{2}}

$$
