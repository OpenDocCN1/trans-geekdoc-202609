
## 算法 1

```
Require: Direct Sensory Matrix S, Binary Index Matrix B, H, T, λ1, λ2, λ3, rank bound r
Ensure: Reconstruct Matrix X̂
1: [n,t] ← size(S);
2: S' ← S;
3: for S'(i,j) in S' do
4: if B(i,j)=0 then
5: S'(i,j) ← average of the two nearest values;
6: end if
7: end for
8: [U,Σ,V] ← SVD(S');
9: L ← U·Σ_r^{1/2};
10: R ← V·Σ_r^{1/2};
11: repeat
12: β1 ← f(L,R);
13: Calculate ∇_l and ∇_r according to Eq. (25);
14: α_l ← arg min_α f(L−α∇_l,R);
15: α_r ← arg min_α f(L,R−α∇_r);
16: L ← L−α_l∇_l;
17: R ← R−α_r∇_r;
18: until (β2−β1)/β1 < threshold;
19: X̂ ← L·R^T;
20: return X̂;
```

where

```
∇_l^1 = 2((LR^T)∘B − S)R
∇_l^2 = 2λ1 L
∇_l^3 = 2λ2 H^T H L R^T R
∇_l^4 = 2λ3 L R^T T T^T R
∇_r^1 = 2((RL^T)∘B^T − S^T)L
∇_r^2 = 2λ1 R
∇_r^3 = 2λ2 R L^T H^T H L
∇_r^4 = 2λ3 T T^T R L^T L
```

### 算法 2

```
FaultyDATADETECTION()
Require: Direct Sensory Matrix S, Existence Matrix E, Faulty Data Detection Matrix D
Ensure: Faulty Data Detection Matrix D
1: [n,t] ← size(S);
2: T = S T;
3: for i ← 1 to n do
4: for j ← 1 to t do
5: if E(i,j)=0 or D(i,j)=0 then
6: continue ;
7: end if
8: el ← new Array();
9: for k ← j - ⌊window/2⌋ to j + ⌊window/2⌋ do
10: if k≠j and E(i,j)≠0 and D(i,j)≠0 then
11: el ← [el, T(i,k)];
12: end if
13: end for
14: ratio = max(el) - min(el);
15: m = mean(el);
16: if |T(i,k) - m| < ratio/2 then
17: D(i,j) ← 0;
18: end if
19: end for
20: end for
21: return D;
```

错误数据检测方法基于交通状况数据集的时间稳定性。在图 3B 中，我们可以观察到交通状况数据集具有良好的时间稳定性特征（>95% 数据的连续时隙差异 <20%）。因此，我们可以利用这一特征在重建前区分错误数据，使 `D` 在起始点更接近 `F`。

连续时隙之间的差异在公式 (9) 中制定。因此，我们可以引入矩阵 `T` 来存储每条道路连续时隙之间的差异，计算公式为 `T = X T`，其中 `T` 在公式 (17) 中定义，`T(i, j)` 表示 `X(i, j - 1)` 和 `X(i, j)` 之间的差异。

算法 2 展示了错误数据检测方法的伪代码。错误数据检测方法的主要思想是计算第 `i` 条道路连续时隙差异的平均值，并将其与 `T(i, j)` 进行比较；如果它们之间的差异小于动态阈值，则认为 `X(i, j)` 为正常数据。阈值由每条道路中最大的变化范围决定。但考虑到一天中不同时间的变化梯度不同，我们进一步将 288 个时隙细分为几个具有窗口宽度的片段，以便使阈值更精确。因此，我们在每次循环中按算法 2 计算 `ratio`，并将 `T(i, j)` 与窗口范围内点的平均值进行比较，以判断 `X(i, j)` 是正常数据还是错误数据。`D` 首次执行时初始化为全 1，这可能导致某些正常数据被误判。然而，`D` 的目标是尽可能多地标记出错误数据，这也确保了 ODC 方法的收敛性。

除了在重建前检测错误数据外，我们还需要根据估计的 `X̂` 更新 `D`。我们需要一个 `n × t` 矩阵来记录 `X` 和 `X̂` 之间的差异，定义如下：

$$\delta_{n\times t} = |X - X̂| \tag{26}$$

如果 `δ(i,j)` 小于下阈值 `thres_l` 且 `D(i,j)` 为 1，我们将其设为 0。如果 `δ(i,j)` 大于上阈值 `thres_u` 且 `D(i,j)` 为 0，我们将其设为 1。`thres_l` 和 `thres_u` 取决于数据偏差的容忍度。如果 `X(i,j)` 是缺失数据点（即 `E(i,j)` 为 0），则不执行任何操作。`updateFDM()` 的伪代码如算法 3 所示。

## 15 用于智能交通系统的安全数据传播

Zouina Doukha’ and Iman Loumachi

USTHB 大学, 阿尔及尔, 阿尔及利亚

### 1 介绍

21 世纪的开端见证了计算机网络的非凡变革。这尤其适用于新兴的无线技术，它们旨在扩展通信能力到其存在可以创造新类型网络的环境，例如蜂窝网络、移动自组网络（`MANETs`）、无线传感器网络（`WSNs`）、无线网状网络（`WMN`）等。车载自组网络（`VANETs`，这一扩展的一种有前景的形式）支持道路基础设施，后者成为一个地理空间，承载着可以交换数据的移动车辆，以扩大驾驶员对其环境的可见性，从而获得安全、有益且愉快的旅行体验。`VANETs` 具有几个显著特征。高移动性可能导致网络分区，从而引起连接丢失。车辆的移动相对可预测，因为它受到道路、标志和建筑物等障碍物的约束。在架构上，每辆车都配备了一个称为车载单元（`On-Board Unit`）的无线设备，允许其与其他车辆以及路侧单元（`RSUs`）通信，后者可用作接入点，提供与骨干网络的连接，后者提供多种服务，如交通管理和互联网接入。嵌入式设备为车辆提供了高计算、内存和感知能力，以及无限的能源，这是由车辆电池保证的。与其他无线网络（如 `MANETs` 和 `WSNs`）相比，这是 `VANETs` 的一个显著优势。然而，在设计传播协议时必须考虑许多挑战，例如异构环境、网络分区、可扩展性以及因信号失真导致的丢包。

事实上，蜂窝、蓝牙和超宽带等多种技术都可用于 `VANETs`。然而，专用短程通信/车载环境无线接入（`DSRC/WAVE`）因其适用性和低设备成本而成为 `VANETs` 的首选技术。最近，云计算技术的兴起使其能够与车载技术集成，利用其存储、数据处理能力，主要是其可靠的数据访问能力 [1]。将云计算与车载网络集成显得势在必行，以推动 `VANET` 应用并提供创新服务，提高交通系统的安全性、保安性和效率。
