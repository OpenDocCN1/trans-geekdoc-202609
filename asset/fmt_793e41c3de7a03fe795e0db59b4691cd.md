
# 无线网络安全

**无线网络** 是连接企业和家庭系统的一种流行方法，因为它易于部署且成本相对较低。它使网络比以往任何时候都更通用。工作站和便携式系统不再受线缆束缚，而是可以在部署的无线接入点的信号范围内自由移动。然而，这种自由也带来了额外的漏洞。历史上，无线网络一直相当不安全，主要是因为最终用户和组织缺乏知识，以及设备制造商设置的不安全默认配置。无线网络面临与任何有线网络相同的漏洞、威胁和风险，此外还面临远程窃听、数据包嗅探以及新形式的 DoS 和入侵。为可靠访问和安全性妥善管理无线网络并不总是一件简单或直接的事情。本节将探讨各种无线安全问题。

## 数据辐射

**数据辐射** 是通过电磁信号传输数据。计算机内部或网络中的几乎所有活动都使用某种形式的数据辐射来执行。然而，该术语通常用于关注不需要的辐射，或因辐射而面临风险的数据。

电子移动时就会发生辐射。电子的运动会产生磁场。如果你能读取该磁场，就可以在别处重现它，以复现电子流。如果原始电子流用于通信数据，那么重现的电子流也是原始数据的重现。这种形式的电子窃听听起来像科幻小说，但却是科学事实。美国政府自 20 世纪 50 年代起就在 `TEMPEST` 项目下研究辐射安全。

防范窃听和数据窃取需要多管齐下的努力。首先，你必须对所有电子设备保持物理访问控制。其次，在未经授权的人员仍可能获得物理访问或接近的情况下，你必须使用屏蔽设备和介质。第三，你应始终使用安全加密协议传输任何敏感数据。

## 保护无线接入点

**无线小区** 是物理环境中无线设备可以连接到无线接入点的区域。无线小区可能泄漏到安全环境之外，允许入侵者轻松访问无线网络。你应该调整无线接入点的强度，以最大化授权用户的访问并最小化入侵者的访问。这可能需要独特的无线接入点放置、屏蔽和噪声传输。

### 802.11 标准

**802.11** 是无线网络通信的 IEEE 标准。该标准的各个版本（技术上称为修正案）已在无线网络硬件中实现，包括 `802.11a`、`802.11b`、`802.11g` 和 `802.11n`。`802.11x` 有时用于统称所有这些特定实现；然而，首选使用 `802.11`，因为 `802.11x` 容易与 `802.1x` 混淆，后者是一种独立于无线的认证技术。`802.11` 标准的每个版本或修正案都提供了略微更好的吞吐量：分别为 2 MB、11 MB、54 MB 和 200 MB+，如表 11.7 所述。`b`、`g` 和 `n` 修正案都使用相同的频率；因此，它们保持向后兼容性。

#### 表 11.7：802.11 无线网络修正案

| 修正案 | 速度 | 频率 |
| :--- | :--- | :--- |
| 802.11 | 2 Mbps | 2.4 GHz |
| 802.11a | 54 Mbps | 5 GHz |
| 802.11b | 11 Mbps | 2.4 GHz |

#### 无线网络标准

| 标准 | 速度 | 频率 |
| :--- | :--- | :--- |
| 802.11g | 54 Mbps | 2.4 GHz |
| 802.11n | 200+ Mbps | 2.4 GHz 或 5 GHz |

### 网络模式

在部署无线网络时，你应该部署配置为使用 `infrastructure mode`（基础架构模式）而非 `ad hoc mode`（自组网模式）的无线接入点。自组网模式意味着任意两个无线网络设备（包括两个无线网络接口卡 [NIC]）可以在没有中央控制机构的情况下进行通信。基础架构模式意味着需要一个无线接入点，系统上的无线 NIC 无法直接交互，并且会强制执行无线接入点针对无线网络访问的限制。

在基础架构模式的概念中，存在几种变体，包括独立模式、有线扩展模式、企业扩展模式和桥接模式。当无线接入点将无线客户端相互连接，但不连接到任何有线资源时，会出现 `stand-alone`（独立）模式基础架构。无线接入点专门充当无线集线器。当无线接入点充当连接点，将无线客户端链接到有线网络时，会出现 `wired extension`（有线扩展）模式基础架构。当使用多个无线接入点 (WAP) 将大型物理区域连接到同一个有线网络时，会出现 `enterprise extended`（企业扩展）模式基础架构。每个无线接入点将使用相同的 `extended service set identifier (ESSID)`（扩展服务集标识符），以便客户端可以在该区域漫游，同时保持网络连接，即使其无线 NIC 将关联从一个无线接入点更改为另一个。当无线连接用于链接两个有线网络时，会出现 `bridge`（桥接）模式基础架构。这通常使用专用无线网桥，并在有线网桥不方便时使用，例如在楼层之间或建筑物之间链接网络。

### 保护 SSID

无线网络被分配一个服务集标识符 (SSID)（BSSID 或 ESSID），以将一个无线网络与另一个区分开来。如果同一个无线网络涉及多个基站或无线接入点，则会定义一个扩展站集标识符 (ESSID)。SSID 类似于工作组的名称。如果无线客户端知道 SSID，他们就可以将其无线 NIC 配置为与相关的 WAP 通信。不过，了解 SSID 并不总能获得访问权限，因为 WAP 可以使用多种安全功能来阻止未经授权的访问。SSID 由供应商默认定义，由于这些默认 SSID 广为人知，标准安全实践要求在部署前将 SSID 更改为唯一的内容。

SSID 通过一种称为 `beacon frame`（信标帧）的特殊传输由 WAP 广播。这允许范围内的任何无线 NIC 看到无线网络，并使连接变得尽可能简单。然而，应禁用这种默认的 SSID 广播，以保持无线网络的隐蔽性。即便如此，攻击者仍可使用无线嗅探器发现 SSID，因为 SSID 仍必须用于无线客户端与 WAP 之间的传输中。因此，禁用 SSID 广播并非真正的安全机制。相反，应使用 WPA2 作为可靠的身份验证和加密解决方案，而不是试图隐藏无线网络的存在。

### 进行现场勘测

发现物理环境中可能存在未经授权无线访问区域的一种方法是执行现场勘测。`site survey`（现场勘测）是调查环境中部署的无线接入点的存在性、强度和覆盖范围的过程。此任务通常涉及携带便携式无线设备四处走动，记录无线信号强度，并将其绘制在建筑物的平面图或示意图上。

应进行现场勘测，以确保所有可能使用无线设备的位置都有足够的信号强度，同时将不应允许无线访问的位置（公共区域、跨楼层、其他房间内或建筑物外部）的无线信号最小化或消除。现场勘测对于评估现有无线网络部署、规划当前部署的扩展以及规划未来部署非常有用。

### 使用安全加密协议

IEEE 802.11 标准定义了无线客户端在正常网络通信跨无线链路发生之前，可用于向 WAP 进行身份验证的两种方法。这两种方法是 `open system authentication (OSA)`（开放系统认证）和 `shared key authentication (SKA)`（共享密钥认证）。OSA 意味着不需要真正的身份验证。只要客户端和 WAP 之间可以传输无线电信号，就允许通信。同样，使用 OSA 的无线网络通常以明文传输所有内容，因此不提供任何保密性或安全性。SKA 意味着在网络通信发生之前必须进行某种形式的身份验证。802.11 标准为 SKA 定义了一种可选技术，称为有线等效保密 (WEP)。对原始 802.11 标准的后续修正增加了 WPA、WPA2 和其他技术。

#### WEP

`Wired Equivalent Privacy (WEP)`（有线等效保密）由 IEEE 802.11 标准定义。它旨在为无线网络提供与有线或缆线网络相同级别的安全性和加密。WEP 可防止针对无线传输的数据包嗅探和窃听。

WEP 的一个次要好处是，它可以配置为防止未经授权访问无线网络。WEP 使用预定义的共享密钥；然而，它不是典型的动态对称加密解决方案，而是共享密钥是静态的，并在所有无线接入点和设备接口之间共享。该密钥用于在通过无线链路传输之前加密数据包，从而提供机密性保护。哈希值用于验证接收到的数据包在传输过程中未被修改或损坏；因此 WEP 也提供完整性保护。知晓或持有该密钥不仅允许加密通信，还充当一种基本的身份验证形式，因为没有它，将禁止访问无线网络。

WEP 发布后不久即被破解。如今，破解 WEP 只需不到一分钟，因此它成为一种毫无价值的安全预防措施。幸运的是，有 WEP 的替代方案，即 WPA 和 WPA2。WPA 是对 WEP 的改进，因为它不使用相同的静态密钥来加密所有通信。相反，它与每个主机协商一组唯一的密钥。然而，使用单个密码短语来授权与基站的关联（即允许新客户端建立连接）。如果密码短语不够长，可能会被猜测。通常建议密码短语为 14 个字符或更长。

WEP 加密采用 Rivest Cipher 4 (RC4)，一种对称流密码（有关加密的更多一般信息，请参见第 6 章“密码学和对称密钥算法”以及第 7 章“PKI 和密码学应用”）。由于其设计缺陷和 RC4 的实现问题，WEP 在几个方面很薄弱，其中两个是使用静态公共密钥和 IV（初始化向量）的糟糕实现。由于这些弱点，WEP 破解可以在发现足够多的被不当使用的 IV 后揭示 WEP 密钥。这种攻击现在可以在 60 秒内完成。发现 WEP 密钥后，攻击者可以加入网络，然后监听所有其他无线客户端的通信。因此，不应使用 WEP。它不提供真正的保护，并可能导致错误的安全感。

#### WPA

**Wi-Fi Protected Access (WPA)** 旨在取代 WEP；它是一个临时修复方案，直到新的 802.11i 修正案完成。制定新修正案的过程耗时数年，因此 WPA 在市场上站稳了脚跟，至今仍被广泛使用。此外，WPA 可用于大多数设备，而 802.11i 的功能则排除了某些低端硬件。

802.11i 是定义取代 WEP 的加密解决方案的修正案。然而，当 802.11i 最终确定时，WPA 解决方案已被广泛使用，因此他们无法按原计划使用 WPA 名称；因此它被命名为 WPA2。但这并不表示 802.11i 是 WPA 的第二个版本。事实上，它们是两套完全不同的技术。802.11i（即 WPA2）实现了类似于 IPSec 的概念，为无线通信带来了迄今为止最好的加密和安全性。

Wi-Fi Protected Access 基于 LEAP 和临时密钥完整性协议（TKIP）密码系统，并通常采用秘密口令进行身份验证。不幸的是，使用单一静态口令是 WPA 的致命弱点。攻击者只需对 WPA 网络运行暴力猜测攻击即可发现口令。如果口令长达 14 个字符或更多，这通常是一个耗时过长以至于不可行的尝试，但并非不可能。此外，WPA 的 LEAP 和 TKIP 两种加密选项现在均可通过多种破解技术被破解。虽然比攻破 WEP 更复杂，但 WPA 不再提供长期可靠的安全性。

#### WPA2

最终，一种新的无线安全保护方法被开发出来，至今仍普遍被认为是安全的。这就是称为 *802.11i* 或 *Wi-Fi Protected Access 2 (WPA2)* 的修正案。它是一种称为 *Counter Mode Cipher Block Chaining Message Authentication Code Protocol (CCMP)* 的新加密方案，基于 AES 加密方案。2017 年底，一种称为 KRACK（密钥重装攻击）的攻击概念被披露，它能破坏客户端与 WAP 之间最初的四次握手，迫使其重用先前使用的密钥，在某些情况下甚至使用仅由零组成的密钥。大多数易受攻击的无线设备已更新或有可用更新来解决此问题。更多信息请见 [`www.krackattacks.com/`](https://www.krackattacks.com/)。

#### 802.1X/EAP

WPA 和 WPA2 均支持称为 *802.1X/EAP* 的企业级身份验证，这是一种基于端口的标准网络访问控制，确保客户端在完成适当身份验证之前无法与资源通信。实际上，802.1X 是一种移交系统，允许无线网络利用现有网络基础设施的身份验证服务。通过使用 802.1X，远程认证拨入用户服务（RADIUS）、终端访问控制器访问控制系统（TACACS）、证书、智能卡、令牌设备和生物识别等其他技术和解决方案可集成到无线网络中，提供相互认证和多因素认证的技术。

*可扩展认证协议 (EAP)* 不是一种特定的认证机制；而是一个认证框架。实际上，EAP 允许新的认证技术与现有的无线或点对点连接技术兼容。超过 40 种不同的 EAP 认证方法被广泛支持。这些包括 LEAP、EAP-TLS、EAP-SIM、EAP-AKA 和 EAP-TTLS 等无线方法。并非所有 EAP 方法都是安全的。例如，EAP-MD5 和一种称为 LEAP 的预发布 EAP 也可被破解。

#### PEAP

*受保护的可扩展认证协议 (PEAP)* 将 EAP 方法封装在一个提供认证和潜在加密的 TLS 隧道中。由于 EAP 最初设计用于物理隔离的信道，因此假设路径是安全的，EAP 通常不加密。因此 PEAP 可以为 EAP 方法提供加密。

#### LEAP

*轻量级可扩展认证协议 (LEAP)* 是思科专有的 WPA 替代方案，用于替代 TKIP。这是在 802.11i/WPA2 系统被批准为标准之前，为解决 TKIP 的缺陷而开发的。2004 年发布了一款名为 Asleap 的攻击工具，可利用 LEAP 提供的最终薄弱保护。应尽可能避免使用 LEAP；建议改用 EAP-TLS 作为替代，但如果必须使用 LEAP，强烈建议使用复杂密码。

#### MAC 过滤

*MAC 过滤* 是授权无线客户端接口 MAC 地址的列表，由无线接入点用于阻止所有未授权设备的访问。虽然是一个有用的功能，但管理起来可能比较困难，且倾向于仅用于小型、静态环境。此外，拥有基本无线黑客工具的黑客可以发现有效客户端的 MAC 地址，然后将该地址伪造到他们的攻击无线客户端上。

#### TKIP

*临时密钥完整性协议 (TKIP)* 旨在取代 WEP，且无需更换传统无线硬件。TKIP 在 WPA（Wi-Fi Protected Access）名称下被实施到 802.11 无线网络中。TKIP 的改进包括：一个密钥混合功能，在将初始化向量（IV）（即随机数）与秘密根密钥结合后，再将该密钥与 RC4 配合使用以执行加密；使用序列计数器防止数据包重放攻击；以及使用一个名为 Michael 的强完整性检查。

TKIP 和 WPA 于 2004 年正式被 WPA2 取代。此外，针对 WPA 和 TKIP 的特定攻击（即 coWPAtty 和基于 GPU 的破解工具）已使 WPA 的安全性变得不可靠。

#### CCMP

CCMP（带有密码分组链接消息认证码协议的计数器模式）被创建用于取代 WEP 和 TKIP/WPA。CCMP 使用带有 128 位密钥的 AES（高级加密标准）。CCMP 是 802.11i 指定的 802.11 无线网络的首选标准安全协议。迄今为止，尚无成功针对 AES/CCMP 加密的攻击。

## 确定天线放置位置

部署无线网络时，天线放置位置应是一个考虑因素。在进行适当的现场勘测之前，不要固守特定位置。将无线接入点及/或其天线放置在一个可能的位置；然后测试不同位置的信号强度和连接质量。只有在确认潜在的天线放置位置提供令人满意的连接性后，才应将其固定下来。

寻求最佳天线放置位置时，请考虑以下准则：

- 使用中心位置。
- 避免实体物理障碍物。
- 避免反射性或其他平坦金属表面。
- 避免电气设备。

如果基站具有外置全向天线，通常应将其垂直向上放置。如果使用定向天线，将焦点指向期望使用的区域。请记住，无线信号会受到干扰、距离和障碍物的影响。在设计安全无线网络时，工程师可能会选择定向天线，以避免在不希望提供信号的区域进行广播，或用更强的信号专门覆盖某个区域。

## 天线类型

无线客户端和基站可使用多种天线类型。许多设备可将其标准天线替换为更强（即增强信号）的天线。

标准的直杆或极化天线是*全向天线*，可在垂直于天线本身线路的所有方向上发送和接收信号。这是大多数基站和某些客户端设备上常见的天线类型。这种天线有时也称为基站天线或胶棒天线（因为大多数都覆盖着柔性橡胶涂层）。

### 无线天线与安全

大多数其他类型的天线是定向的，意味着它们将发送和接收能力集中在一个主要方向上。`定向天线` 的一些示例包括八木天线、罐头天线、面板天线和抛物面天线。八木天线的结构类似于传统的屋顶电视天线。八木天线由一根带有横截面的直杆制成，用于捕捉主杆方向上的特定无线电频率。罐头天线由一端密封的管子制成。它们沿着管子开口端的方向聚焦。最早的一些罐头天线是用 Pringles 薯片罐制作的。面板天线是扁平设备，仅从面板的一侧聚焦。抛物面天线用于聚焦来自极远距离或微弱信号源的信号。

### 调整功率电平控制

某些无线接入点提供物理或逻辑方式的天线功率电平调整。功率电平控制通常由制造商设置为适合大多数情况的设置。然而，如果在执行现场勘测和调整天线位置后，无线信号仍然不令人满意，则可能需要进行功率电平调整。但请记住，更改信道、避开反射面和信号散射面以及减少干扰，在提高连接可靠性方面通常更为重要。

调整功率电平时，应进行微调，而不是试图将设置最大化或最小化。此外，请记下初始/默认设置，以便需要时可以恢复到该设置。每次调整功率电平后，在重新执行现场勘测和质量测试之前，请重置/重启无线接入点。有时降低功率电平可以提高性能。重要的是要记住，某些无线接入点能够提供高于其销售国家/地区法规允许的功率电平。

### WPS

`Wi-Fi Protected Setup (WPS)` 是无线网络的安全标准。其目的是简化将新客户端添加到安全性良好的无线网络所涉及的工作。它通过在管理员按下基站上的 WPS 按钮触发该功能后，自动将第一个寻找网络的新无线客户端连接到网络来运作。然而，该标准还要求提供一个代码或个人识别号 (PIN)，该代码或 PIN 可以远程发送到基站，以触发 WPS 协商，而无需物理按下按钮。这导致了一种暴力猜测攻击，黑客可在数小时内（通常少于六小时）猜出 WPS 代码，进而将其自己的未授权系统连接到无线网络。

WPS 是大多数无线接入点上默认启用的功能，因为它是设备通过 Wi-Fi 联盟认证的要求。作为以安全为重点的预部署流程的一部分，禁用它非常重要。如果设备不提供关闭 WPS 的功能（或关闭开关不起作用），请升级或更换基站的固件，或更换整个设备。
