## 8.12 在线学习与大数据应用：讨论

在线学习算法已在第 4 章、第 5 章和第 6 章中进行了探讨。本节旨在首先总结部分研究发现，同时展开讨论，对比在线方案与其批处理对应方案的性能。

回顾一下，获取参数预测器

$$\hat{y} = f_{\boldsymbol{\theta}}(\boldsymbol{x})$$

的最终目标是选择 $\boldsymbol{\theta}$，以优化公式 (8.65) 中的*期望损失/风险*函数。出于实际原因，通常采用公式 (8.66) 中相应的经验公式代替。从学习理论的角度来看，只要相应的函数类足够受限 [94]，这样做是合理的。现有文献中有大量关于获取性能界限的研究，这些界限衡量的是通过期望损失获得的最优值与通过经验损失获得的最优值之间的接近程度，作为样本点数 $N$ 的函数。请注意，当 $N \to \infty$ 时，回顾概率论和统计学中众所周知的论点，经验风险趋于期望损失（在一般假设下）。因此，对于非常大的训练数据集，采用经验风险可能与使用期望损失没有太大区别。然而，对于长度较短的数据集，会出现许多问题。除了 $N$ 的值之外，另一个关键因素登场了；这就是我们在其中搜索解的函数族的*复杂度*。换句话说，泛化性能不仅关键取决于 $N$，还关键取决于这一函数集有多大或多小。针对均方误差（MSE）的具体情况，相关讨论已在第 3 章中呈现，是在偏差-方差权衡的背景下。更一般理论的根源可追溯到 Vapnik-Chervonenkis 的开创性工作；参见 [31,95,96]，以及 [88] 中关于主要观点的非数学性总结。

### 强凸损失函数

*   当损失函数为强凸时，可以推导出更紧的遗憾界 [43]。若函数 $f: \mathcal{X} \subseteq \mathbb{R}^l \mapsto \mathbb{R}$ 满足：$\forall \boldsymbol{y}, \boldsymbol{x} \in \mathcal{X}$，

    $$f(\boldsymbol{y}) \geq f(\boldsymbol{x}) + \boldsymbol{g}^{T}(\boldsymbol{y} - \boldsymbol{x}) + \frac{\sigma}{2}||\boldsymbol{y} - \boldsymbol{x}||^{2},$$

    对于 $\boldsymbol{x}$ 处的任意次梯度 $\boldsymbol{g}$ 均成立，则称该函数为 $\sigma$-*强凸*。还可以证明，若 $f(\boldsymbol{x}) - \frac{\sigma}{2}||\boldsymbol{x}||^{2}$ 为凸函数，则函数 $f(\boldsymbol{x})$ 为强凸（习题 8.30）。

*   对于 $\sigma$-强凸损失函数，若子梯度算法的步长以 $\mathcal{O}(\frac{1}{\sigma n})$ 的速率递减，则平均累积损失将以 $\mathcal{O}(\frac{\ln N}{N})$ 的速率趋近于最优预测器的平均损失（习题 8.31）。第 8.10.3 节讨论的 PEGASOS 算法即属于此类情况。

*   文献 [4,5] 为一组非强凸光滑损失函数（如平方误差和逻辑回归）推导出了 $\mathcal{O}(1/N)$ 的收敛速率，即使在常数步长的情况下也成立。该分析方法遵循统计论证。

在后续内容中，将讨论一些针对我们当前讨论需求量身定制的结果。

*   **小规模任务**：这类任务受限于训练点的数量 $N$。在这种情况下，可以降低优化误差，因为计算负载不是问题，并能达到由可用训练点数量所允许的最小可能估计误差。在这种情况下，实现了近似-估计权衡。

*   **大规模/大数据任务**：这类任务受限于计算资源。因此，与在最大允许计算负载下更精确但计算更复杂的算法相比，计算廉价且精度较低的算法可能最终获得更低的超额误差，因为它有利可图地利用了更多的数据。

### 批量学习与在线学习

本小节的重点在于探究如果用在线算法代替批量算法，是否会导致性能损失。这里涉及一个非常微妙的问题，从实用角度来看却非常重要。我们将讨论范围限定在可微凸损失函数上。

与算法性能（在平稳环境中）相关的两个主要因素是其收敛速率和收敛后的精度。批量算法用于最小化公式 (8.66) 的一般形式写为

$$

\boldsymbol{\theta}^{(i)} = \boldsymbol{\theta}^{(i - 1)} - \mu_{i}\Phi_{i}\nabla J_{N}\left( \boldsymbol{\theta}^{(i - 1)} \right) = \boldsymbol{\theta}^{(i - 1)} - \frac{\mu_{i}}{N}\Phi_{i}\sum\limits_{n = 1}^{N}\mathcal{L}^{\prime}\left( \boldsymbol{\theta}^{(i - 1)},y_{n},\mathbf{x}_{n} \right).

$$

对于梯度下降，`Φ[i] = I`；对于牛顿型递归，`Φ[i]` 是损失函数的逆海森矩阵（第 6 章）。

请注意，这些并非矩阵 `Φ` 的唯一可能选择。例如，在 Levenberg–Marquardt 方法中，采用的是方雅可比矩阵，即

```
Φ[i] = [∇J(θ^(i−1))∇^(T)J(θ^(i−1)) + λI]^(−1)
```

其中 `λ` 是正则化参数。文献 [3] 中提出了*自然梯度*，它基于由所采用的预测模型 `f_θ(x)` 所隐含的噪声分布相关联的 Fisher 信息矩阵。在这两种情况下，所涉及的矩阵在渐近意义上表现得像海森矩阵，但在初始收敛阶段可能提供更好的性能。欲进一步讨论，感兴趣的读者可参阅文献 [49,56]。

正如在第 5 章和第 6 章（第 6.7 节）中已经提到的，简单梯度下降法（针对均方误差情况）收敛到相应最优值的速率是*线性*的，即

```
ln(1/‖θ^(i) − θ_*(N)‖) ∝ i
```

而牛顿型算法的相应速率（近似地）是二次的，即

```
ln ln(1/‖θ^(i) − θ_*(N)‖) ∝ i.
```

相比之下，公式 (8.98) 的在线版本，即

```
θ[n] = θ[n−1] − μ[n]Φ[n]L'(θ[n−1], y[n], x[n])
```

(8.98)

基于当前样本点(*y*[*n*], **x**[*n*])的梯度*噪声*估计。这会减慢收敛速度，特别是在算法接近解时。此外，参数向量的估计会在最优值附近波动。我们在 LMS 情况下广泛研究了这一现象，当时*μ*[*n*]被赋予常数值。这就是在随机梯度理论中，*μ*[*n*]必须是递减序列的原因。然而，它*不能*下降得太快，这由条件∑[*n*]*μ*[*n*] → ∞（第 5.4 节）保证。此外，回顾我们在那里的讨论，向**θ**[*]的平均收敛速率为𝒪(1/*n*)，即*次线性*（例如公式(6.53)）。该结果也涵盖了公式(8.99)中给出的更一般的在线算法情况（参见文献[56]）。但请注意，所有这些结果都是在若干假设下推导出来的，例如算法足够接近解。

我们现在的主要兴趣转向比较批量算法和相应在线算法收敛到**θ**[*]的速率，即最小化期望损失的值，这是我们学习任务的最终目标。既然目的是比较性能，给定相同数量的训练样本，让我们对在线算法的*n*和批量算法的*N*使用相同的数字。遵循文献[12]并对*J**n*应用二阶泰勒展开，可以证明（问题 8.32）：

```
θ*_n = θ*_{n-1} - (1/n) Ψ_n^{-1} L'(θ*_{n-1}, y_n, x_n)
```

其中

```
Ψ_n = (1/n) ∑_{k=1}^n ∇²L(θ*_{n-1}, y_k, x_k)
```

请注意，公式 (8.100) 的结构与公式 (8.99) 相似。此外，随着 `n → ∞`，`Ψ[n]` 收敛于期望损失函数的海森矩阵 `H`。因此，对于涉及加权矩阵的适当选择并设定 `μ[n] = 1/n`，公式 (8.99) 和 (8.100) 可以以相似的速率收敛到 `θ[*]`；因此，在两种情况下，决定最终估计值与最优 `θ[*]` 接近程度的关键因素是所用数据点的数量。文献 [12,56,93] 表明

```
C
```

其中 `C` 是取决于所用相关期望损失函数具体形式的项。*因此，经过对涉及参数的适当微调，批处理算法及其在线版本均可使其以相似的速率收敛到 `θ[*]`。* 再次强调，由于大数据应用中的关键因素不是数据而是计算资源，与批处理算法相比，廉价的在线算法虽然是一种计算需求更大的方案，却能实现增强的性能（更低的超额误差）。这是因为对于给定的计算负载，在线算法可以处理更多的数据点（问题 8.33）。更重要的是，在线算法无需存储数据，数据到达时即可即时处理。关于该主题的更详细论述，感兴趣的读者可参阅文献 [14]。

在文献 [14] 中，两种形式的批处理线性支持向量机（第 11 章）与其在线随机梯度对应版本进行了对比测试。测试在 RCV1 数据集 [53] 上进行，训练集包含 781,265 篇文档，由（相对）稀疏的特征向量表示，包含 47,152 个特征值。经过适当调整且采用递减步长的随机梯度在线版本，与其批处理对应版本相比，在大幅降低的计算时间（不到十分之一）下实现了可比的错误率。
