## 3.1 引言

社交网络网站（`SNS`）作为一个强大的平台和通信广播媒介。互联网的增长和 `SNS` 的使用在很大程度上便利了人们。这些平台也为全球许多人提供了不受阻碍地表达自我的途径。仇恨文本是人们用来用粗俗语言表达观点的词汇或词组。这些观点通常针对他人、产品或任何持有不同观点的组织 [1,2]。`SNS` 已成为发布此类可能导致其他网络犯罪的有害内容的舒适且更方便的媒介。此外，在帖子中隐藏身份的能力使得具有攻击性的评论者变得易于为。图 3.1 显示了 `SNS` 中的仇恨文本评论。

目前，仇恨文本的发布频率日益增加，这要求现代技术在这些帖子到达许多用户之前对其进行自动检测和删除。社交网络服务（SNS） [3]正在进行大量的研究，因为这些平台产生了海量数据，可以对这些模式和见解进行分析。这些网站还被用于实验检测某些不良行为，例如发布仇恨言论 [4]。由于大多数服务提供者保持匿名性，且此类内容的来源被隐藏且无法追踪，这些滥用者发现他们更容易逃脱法而不被捕获。许多社交网络平台由于无知或出于热度的考虑，并没有投入过多精力删除此类帖子。处理该问题的方法之一是开发自动化技术，以执行分析、识别并最终消除此类粗俗信息。研究人员已很大程度上使用了自然语言处理技术和机器学习技术 [5,6]来开发此类检测技术。虽然在该领域的类似工作有所增加，但由于数据分散且形式、语言各异 [7]，问题也出现了。通过机器学习提出特征提取的研究在一定程度上有助于产生检测独特且重要信息属性的衍生方法。

该研究执行的任务产生了一系列与原始特征列表相关的特征。虽然要获得这样的特征子集非常复杂，但预测此类特征的模型在准确性和分类方面已取得了显著的成就。社交媒体分析中包含的传统方法包括词袋模型（bag of words）、N-grams、单字模型（uni-grams）和 TFIDF，以及语义和句法分析 [8]。本章专注于 Twitter 数据。

推文的分类应基于已有的类别，并遵循预定的步骤，如预处理、特征检测、提取和分解 [9]。这些过程通过不同的方案执行，以提高准确率的水平。机器学习方法有助于根据学习场景对可用数据进行分类。监督方法（如 `SVM`）被广泛应用于分类中。它们根据预定义的标签产生分类输出。这些是简单的二分类器，通过将类成员从输入空间中分离的过程形成一个超平面。

`SVMs` 也用于非线性映射，这有助于将输入空间映射到高维特征空间。这些平面通过超平面的最大间隔进行分离，这是一种结合数据点的线性方法 [10]。`SVMs` 还用于检测表示分离超平面的信息点。图 3.2 描述了用于检测仇恨文本的建议模型。

## 3.2 相关工作

在 [11]中，作者提出了一种使用 `PCA` 检测针对少数群体的仇恨文本的新方法。建议方法使用了改进的向量嵌入技术。`RNN` 用于分类检测仇恨文本。预测目标。数据集是使用网络爬虫在 Facebook 页面进行定制的。使用向量嵌入模型方法在降低复杂性的同时，还提供了更广泛的主题，而 `RNN` 提高了分类的准确率。

众包概念在 [12]中提出，其中作者使用了它们来收集和分类攻击性和非攻击性文本。作者使用了多级分类器来分类如种族主义等词汇。主成分分析被用于 [13]，以从推文中进行有效的特征提取。建议方法使用了不同的坐标图。这些技术实现了自动化和过滤的双重目标。在这里，具有方差的变量不支持多变量分类，但 `PCA` 有助于解决这些问题。这些方法被证明是有效的。

在 [14]中，作者利用 `LDA` 从 `PCA` 未考虑且方差较小的特征中提取有用数据。作者确定这些丢弃的特征具有有用信息，并通过 `LDA` 进行提取。该技术被命名为 `PDCA`，与 `PCA` 和 `LDA` 相比，提高了分类准确率。他们在 Facebook 的特定社区帖子上进行了实验。另一种使用 N-grams 的监督技术在 [15]中引入。这项研究有助于消除冗余特征，并引入了用于语义分析的新词典。建议词典的开发仅考虑与品牌相关的项目，这有助于降低复杂性，但提供了广泛的主题。建议词典的性能随后与其他使用 `SVM` 的标准方法进行了比较。结果令人印象深刻，引入的 `DNA2` 机器学习算法与建议词典结合使用时，在情感分析方面也被证明有效的。

在 [16]中，`CNN` 用于调查 Twitter 的训练数据，建议模型表明在考虑许多领域时，`DLT` 可以更高效地识别仇恨文本。该工作为进一步探索使用神经网络促进大型数据集的准确分类提供了途径。

## 3.3 建议方法

通过现有文献已知，提高仇恨文本检测的准确率有很大的空间。此外，从现有工作中可以看出，计算复杂度没有得到充分的讨论和处理。考虑到这些空间，本章提出了一种改进的主成分分析（`IPCA`）和改进的卷积神经网络（`MCNN`）的结合，以提高整体性能。`IPCA` 算法用于高效特征提取，`MCNN` 用于提高分类准确率。

### 3.3.1 预处理

#### 归一化

归一化在本工作中被作为一种预处理方法。去除噪声和清洗数据是非常重要的，因为它们在很大程度上影响分类准确性。特征之间的向量空间也应该保持较短，因为它会影响计算时间。预处理涉及的步骤包括分词、停用词移除和词干提取。通过分词将复杂的推文分解为简单的句子。使用 `NLTK` 分词器在词级对推文进行划分。具有不同行为（如动词、名词等）的单词被视为一体。在修剪过程中，所有的单词前缀和后缀都会删除。在这种情况下，语法错误被忽略，这结合了两个概念：词频 (`TF`) 和文档频率 (`DF`)。

词频是特定术语在文档中出现的次数。术语在文档中的出现频率反映了其重要性。词频将数据中的每个文本描述为一个矩阵，行表示文档数量，列表示所有文档中不同术语的数量。包含特定短语的单词数量称为文档频率。术语的文档频率反映了它的常见程度。术语的权重是逆文档频率 (`IDF`)，它旨在当短语出现频率较低时最小化该术语的权重。

#### 修剪与向量化

修剪过程采用了 `POTTER` [17] 方法。另一项名为 `TF-IDF` 的研究是一种将文本转换为有用向量的文本向量化方法，即词频-逆文档频率。

实验中推文可能包含不重要的单词，由于考虑了分类，因此不需要考虑。建议的工作利用 `NLTK` 库 [18] 的效率来移除此类停用词，并减少对分类的影响。然后使用 `N`-gram 模型进行分词。预处理的最后一步包括归一化。本工作使用最小最大归一化将数据 [19] 线性变换到预定义的边界内。归一化由公式 (3.1) 表示。

#### 归一化公式

这种归一化可以表示为公式 (3.1)

```
${N\prime} = \left( \frac{N - MIn\left( N \right)}{Max\left( A \right) - Min\left( A \right)} \right. \ast \left( {B - D} \right) + D$ (3.1)
```

这里，`N` 表示经过归一化的输出。`B`、`D` 表示预定义的边界，`A` 表示需要转换的实际数据。该转换通过取标准差 (`SD`) 来获取归一化输出值。执行归一化的目的是消除无效和噪声的特征。
