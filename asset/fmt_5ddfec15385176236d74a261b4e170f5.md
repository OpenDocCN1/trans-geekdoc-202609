### (3) 相位约束

`VT` 是输电系统中的一种感应传感器，主电压相量在变换到次级侧后会发生滞后。此外，每两个相量之间的相位差主要取决于变压器的等效阻抗以及通过它的负载电流。相位约束的基本假设是电力变压器系统中三相角之间的差保持恒定。因此，第一个相位约束表示了相位不平衡的容差，其公式形式为：

```
std(Φ) - C_5 < 0,
```

其中 `Φ` 由方程 (7.8) 给出。此外，根据输电系统中的相位和电压平衡，我们可以得到以下矩阵：

```
[ I_A  I_a ]            [ 1  exp(j·2π/3)  exp(j·4π/3) ] [ c^1  c^4 ]
[ I_B  I_b ]  = (1/3) × [ 1  exp(j·4π/3)  exp(j·2π/3) ] [ c^2  c^5 ]
[ I_C  I_c ]            [ 1  1            1           ] [ c^3  c^6 ],
```

其中 `c^i` 由方程 (7.11) 给出。然后，我们可以得到
