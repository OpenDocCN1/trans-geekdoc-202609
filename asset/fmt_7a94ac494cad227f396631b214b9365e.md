
```
$\Sigma = \langle M, G, P, \mathcal{F}, \mathcal{A}, \mathcal{I}, \mathcal{G}, B, \nabla\varphi = \iota\rangle$
```

其描述如下：

### (1) 基础结构
`$\langle M, G \rangle$`，其中 `M` 是有限维实数可微流形，`G` 是有限维李群。

### (2) 中间集
`M` 上一个固定的主纤维丛 `P(M,G)`，以 `G` 为其纤维，加上相关的张量丛和外代丛。

### (3) 派生场空间
势空间 `$\mathcal{A}$`、场空间 `$\mathcal{F}$` 以及电流或源空间 `$\mathcal{I}$`。`$\mathcal{A}$`、`$\mathcal{F}$` 和 `$\mathcal{I}$` 是我们构造中作为中间集出现的丛截面空间。

### (4) 对场的公理限制
动力学规则 `$\nabla\varphi = \iota$` 以及场 `$\varphi \in \mathcal{F}$` 与其势 `$\alpha \in \mathcal{A}$` 之间的关系 `$\varphi = d(\alpha)$`，以及相应的边界条件 `B`。在这里，`d(\alpha)` 表示关于连接 `$\alpha$` 的协变外导数，`$\nabla$` 是一个协变狄拉克类算子。作为替代方案，我们可以通过变分原理给出动力学。（在这种情况下）的优势是，运动被视为产生一种“最小努力原则”。^8

### (5) 对称群
`$\mathcal{G} \subseteq \text{Diff}(M) \otimes \mathcal{G}'$`，其中 `Diff(M)` 是 `M` 的微分同群，`$\mathcal{G}'$` 是主丛 `P` 的规范变换群。

> ^8 并不总是这样，因为变分原理只给我们一个极值行为，可以是极大值或最小值。

### (6) 物理上可区分的场空间
如果 `K` 是 `$\mathcal{F}$`、`$\mathcal{A}$` 或 `$\mathcal{I}$` 场流形之一，那么物理上不同的场的空间为 `$\mathcal{K}/\mathcal{G}$`。

在更复杂的分析中，我们可以用一个更精细的概念来替换我们的理论概念。实际上，在科学理论中，我们通过不断改进的近似在科学实践本身中进行。然而，对于本工作的目标而言，我们的经验理论概念已经足够了。

再次，我们基于 da Costa 和 Doria (2007) 展开阐述。我们所理解的直到第一量子化理论水平的物理经典部分很容易适应之前的方案。我们详细讨论几个例子：麦克斯韦电磁理论、哈密顿力学、广义相对论和经典规范场理论。

设 `M = \mathbb{R}^4` 具有某种微分结构，奇异的或标准的。无论如何，物理可以被视为一种*局部*现象，因此底层时空的全局属性可能是不重要的。^9 因此考虑标准情况。我们赋予 `M` 由其乘积结构诱导的笛卡尔坐标，并令 `$\eta = \text{diag}(-1,+1,+1,+1)$` 为 `M` 上的对称常数闵可斯基量张量。

那么 `M` 就是闵时空，即我们进行特殊相对论的物理区域。众所周知，从保持不变张量 `$\eta$` 不变的线性变换中，我们得到了著名的相对论收缩和膨胀现象。

我们使用标准的物理符号。如果 `F_{\mu\nu}(x)` 是电磁场的分量，即 `M` 上的可微协变 2-张量，`$\mu, \nu = 0, 1, 2, 3$`，那么麦克斯韦方程为：

```
$\partial_{\mu}F^{\mu\nu} = j^{\nu}$
$\partial_{\mu}F_{\nu\rho} + \partial_{\rho}F_{\mu\nu} + \partial_{\nu}F_{\rho\mu} = 0$
```

逆变向量分量由 `M` 上的四个光滑函数集合 `j^{\mu}(x)` 给出，该电流作为麦克斯韦场 `F_{\mu\nu}` 的源。

众周知，麦克斯韦方程等价于狄拉克类集合：

```
$\nabla\varphi = \iota$
```

其中

```
$\varphi = (1/2)F_{\mu\nu}\gamma^{\mu\nu}$
```

以及

```
$\iota = j_{\mu}\gamma^{\mu}$
```

```
$\nabla = \gamma^{\rho}\partial_{\rho}$
```

最后，我们在 `$\mathcal{F}$` 上有两个群作用：第一个是洛伦兹-庞因加作用 `L`，它是 `M` 的微分同群作用的一部分；然后是 `P` 的规范变换群 `$\mathcal{G}'$` 的作用，作用于 `$\mathcal{A}$`。因此，我们将对称群 `$\mathcal{G}$` 取为 `M` 的允许对称性和主丛对称性的乘积 `L \otimes \mathcal{G}'`。

我们必须加上势空间 `$\mathcal{A}$` 和电流空间 `$\mathcal{I}$`，它们是来自 `M` 和 `S^1` 的结构。这两个空间具有相同的拓扑结构作用于它们。我们的区别在于规范变换群 `$\mathcal{G}'$` 作用于它们的方式。我们得到 `$\mathcal{I}/\mathcal{G}'=\mathcal{I}$`，而 `$\mathcal{A}/\mathcal{G}' \neq \mathcal{A}$`。

$\varphi=\iota$

被视为对我们对象的公理限制；边界条件 `B` 是 (i) 来自 `M` 和 `S^1` 的派生结构集，由于我们处理的是柯西条件，我们必须在 `M` 中指定一个局部或全局类光超曲面 `C`，在其上面我们 (ii) 加上形如 `$\forall x \in C f(x) = f_0(x)$` 的句子，其中 `f_0`是一组固定函数，而 `f` 是场函数和方程对 `C` 的适当限制。

泛义地说，只需要得到一个电磁场的特定例子，并证明它满足上述的形式化构造即可。这同样适用于接下来的例子。

在这里，哈密顿力学被看作“哈密顿流体”的动力学。我们力学的基础结构始于基本集合，即一个 `2n` 维实光滑流形，以及实辛结构群 `Sp(2n, R)`。哈密顿流形中的相空间是辛流形：即赋予了辛形式的偶数维流形，如 `M`，即 `M` 上一个非退化的闭 2-形式 `$\Omega$`。该形式的施加可以看作是将线性丛 `L(M)` 还原到一个固定主丛 `P(M, Sp(2n, R))` 的选择；然而，给定这样一个还原，并不能自动推导出 `M` 上的诱导 2-形式是闭形式。

所有其他对象的构造方式与前一个例子相同。然而，我们必须证明，对于力学结构的类，我们仍然有一个类似于狄拉克的方程作为动力公理。哈密顿方程为：

```
$i_X\Omega = -dh$,
```

其中 `i_X` 表示关于 `M` 上矢量场 `X` 的内积，`h` 是哈密顿函数。该方程等价于

```
$L_X\Omega = 0$,
```

或者

```
$d(i_X\Omega) = 0$,
```

其中 `LX` 是关于 `X` 的李导数。条件 `d\varphi=0` 其中 `$\varphi=ix\Omega$` 是哈密顿力学的退化类狄拉克方程。我们没有得到一个完整的类狄拉克算子 `$\nabla \neq d$`，因为 `M` 视为辛流形并不具有规范的度量结构，因此我们无法定义相对于 `d` 的规范散度 `$\delta$`。作用在具有辛形式的 `M` 上的群是规范变换群；它是 `M` 的微分同胚的子群，使得辛形式在规范变换下映射后仍为辛形式。

我们可以将 `M` 上所有哈密顿量的空间看作“势空间”，并将所有形如 `ix\Omega` 的空间看作“场空间”。

当然，我们可以直接利用变分原理进行动力学，并开始所有拉格朗日述的公理化。^10

解释是显而易见的：`h` 是系统的哈密顿量，在满足某些简单条件下，可以看作系统的总能量。辛形式沿哈密顿流的李导数不变性，既等同于庞加莱积分不变定理，也等同于刘物定理。

## 广义相对论

广义相对论是一种引力理论，它将这种基本力解释为源自时空的伪黎曼结构。也就是说，在广义相对论中，我们从一个时空流形四维实、足够的光流形^11 开始，赋予一个伪黎曼度量张量。引力效应源于该张量。

> ^10 这里有几个微妙点，因为我们开始的拉格朗量是一个超正则拉格朗量；参见 Abraham and Marsden (1978)。
> ^11 这里允许存在奇异流形。

对于任何四维、非紧、实、可微流形 `M`，我们可以赋予它无限个不同的、非等价的具有洛伦兹符号即 `-+++` 的度量张量。该集合是不可数的，且具有连续统的势。

因此，`M` 作为拓扑流形的基础结构或其可微结构并不能确定一个特定的伪黎曼度量张量；也就是说，从严格的角度来看，当我们选择一个具有洛伦兹符号的特定度量张量 `g` 时，我们确定的 `M` 上一般线性丛到伪正交丛的依赖于 `g` 的还原是一一对应的。现在遵循我们的配方：

- 我们取 `C^k` 类 `1 \le k \le \infty` 的四维实流形和洛伦兹正交群 `O(3,1)` 为基本集合。

对于零质量粒子的情况，该方程。高自旋场通过 Bargmann-Wigner 方程或其代数对应物来处理。薛定谔方程是从狄拉克方程组通过一个“标准”极限过程得到的，该过程在形式上可以表述为向相应的 Suppes 谓词添加新的公理。

## 广义场论

有时人们可能希望以一种非常通用、独立于运动方程的方式来讨论场论；此时，我们将闵尔夫基空间的构造作为几何背景，并将场论的欧拉-拉格日方程作为动力学公理；或者我们可以将变分原理作为一种形式算法来推导系统的动力学。

我们将简要提到我们关于物理公理化的一些结果。

**命题 9.1.** 经典力学、薛定谔量子力学、电磁学、广义相对论和规范场论可以在 Zermelo-Fraenkel 集合理论内进行公理化。

因此，所有已知的理论物理结果都成为 ZF 定理，只要它们能够按照通常数学标准给出严谨的表述，且不需要“极大”对象的帮助。

**命题 9.2.** 在任何一致的物理 ZF 公理化中，都存在“具有物理意义”的不可判句。

我们所说的“物理意义”是指描述物理实际情况的句子，例如，对于特定的拉格朗量 `L`，句子“`L` 描述了一个谐振子”的形式化版本在 ZF 内是形式不可判的；或者“`X` 是混沌矢量场。”我们可以说，任何两个如概述所示的物理 ZF 公理化都具有相同的不可判句。

这意味着，对于各种构造，为物理选择特定的公理体系仅仅是口味问题。它不会影响我们从公理框架中推导出的结果。更多细节请参阅 da Costa and Doria (2007)。

我们可以将上述技术扩展到几个科学领域。例如，萨缪尔森在《经济分析理论基础》中提出的经济学大部分内容，或者某些特定结果，如纳什均衡定理，都能轻松地融入我们的构造。

我们从一开始就带着一个特定目标：我们希望遵循希尔伯特在其第 6 问题中提出的计划，即，我们提出了一种物理公理化方法，这种方法使我们能够探索这些理论中许多有趣的数学后果。

我们现在希望在这些理论的公理化版本中获得哥德尔句不可判句的具体示例；在更通用的框架下，我们希望看到元数学结果和技术在应用于这些理论或其公理化版本时产生的影响和后果。

分析中实际不可解决问题的首次显式构造直到20 世纪60 年年代才由 Scarpellini 完成以及几年后的 Adler 和 Richardson 完成。Richardson 的结果是目前最有趣的，因为它们等同于构造了一个从形式系统理论到经典初等分析的函子。

从这里开始，我们假设形式构造是在一阶公理化理论 `T` 内进行的，该理论被认为包含 Zermelo-Fraenkel (ZF) 理论以及至少部分的选择公理。
