
# UNIX 命令参考

## 目录操作

### rmdir
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `rmdir -p directory` | 删除目录及其上层空父目录（`-pi` 作用相同，但每次删除前提示） | `rmdir -p /home/bin/dir1` | 删除 `dir1` 目录；若 `bin` 为空则删除；若 `home` 为空则也删除 |

### cp
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `cp file1 newname` | 复制文件并重命名 | `cp old new` | 在当前目录下复制 `old` 为 `new` |
| `cp file dir2/` | 复制文件到目录并保留原名 | `cp file dir2/` | 将 `file` 复制到 `dir2/` 并保留原名 |
| `cp ../dir1/*.` | 复制上级目录 `dir1` 下所有内容到当前目录 | `cp ../dir1/*.` | 将 `dir1` 下所有内容复制到当前目录 |
| `cp -p name target` | 保留原文件所有权限 | `cp -p execut1 execut2` | 复制可执行文件 `execut1` 为 `execut2`，保留执行权限 |
| `cp -R directory target` | 复制目录并重命名 | `cp -R old junk` | 复制目录 `old` 为 `junk` |
| `cp -f name target` | 强制覆盖已存在的目标路径 | 无 | 无 |

> **注意**：若复制文件到已存在的 `newfile`，`newfile` 内容将被覆盖。

### mv
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `mv initial final` | 重命名文件/目录 | `mv temp script_1` | 将 `temp` 重命名为 `script_1` |
| `mv script.exe ~/bin` | 移动文件到其他目录并保留原名 | `mv script.exe ~/bin` | 将 `script.exe` 移动到 `~/bin` 并保留原名 |
| `mv script_1 script.exe ~/bin` | 批量移动多个文件到目录 | `mv script_1 script.exe ~/bin` | 将 `script_1` 和 `script.exe` 移动到 `bin` 目录 |

### pwd
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `pwd` | 打印当前工作目录 | `pwd` | 可能输出 `/home/bob` |

## 打印命令

### pr
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `pr [option] filename` | 打印文件到默认打印机（选项可组合） | `pr userlist` | 打印 `userlist` 内容 |
| `pr +k filename` | 从第 k 页开始打印 | `pr +5 userlist` | 从第 5 页开始打印 `userlist` |
| `pr -k filename` | 按 k 列打印 | `pr -2 userlist` | 以两列打印 `userlist` |
| `pr -a filename` | 横向多列打印（配合 `-k`） | `pr -3a userlist` | 以三列横向打印 `userlist` |
| `pr -d filename` | 双倍行距打印 | `pr -d userlist` | 双倍行距打印 `userlist` |
| `pr -h "header" filename` | 指定页眉而非文件名 | `pr -h "users" userlist` | 以 `users` 作为页眉打印 `userlist` |

> **注意**：`pr` 的选项可以组合使用。

### lpconfig
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `lpconfig printer_id queue` | 配置远程打印机到本地打印队列 | `lpconfig prntr1 bobprt` | 配置 `prntr1` 接受来自 `bobprt` 的打印请求 |
| `lpconfig -r queue` | 从本地系统移除队列 | `lpconfig -r bobprt` | 若操作者为所有者或 root，移除 `bobprt` |
| `lpconfig -d queue` | 设置默认打印队列 | `lpconfig -d vpprnt` | 设置 `vpprnt` 为默认打印队列 |

### lpstat
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `lpstat [-options]` | 显示打印机状态信息 | `lpstat` | 显示当前用户向默认打印机提交的所有请求状态 |
| `lpstat -u "user1, user2"` | 显示指定用户的请求状态 | `lpstat -u "bob"` | 显示用户 `bob` 的所有请求状态 |
| `lpstat -s` | 显示队列及其对应打印机 | 无 | 无 |
| `lpstat -t` | 显示所有打印状态信息 | 无 | 无 |
| `lpstat -d` | 显示 `lp` 命令的默认打印机 | 无 | 无 |
| `lpstat -r` | 显示行打印机调度程序是否运行 | 无 | 无 |

### lp
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `lp [-option] file(s)` | 打印指定文件（选项可组合） | `lp junkfile` | 以默认设置打印 `junkfile` |
| `lp -d dest file(s)` | 指定打印目标队列 | `lp -dbobsq zoom` | 将 `zoom` 发送到 `bobsq` 队列打印 |
| `lp -n number file(s)` | 指定打印份数 | `lp -n5 crash` | 打印 5 份 `crash` |
| `lp -t title file(s)` | 指定横幅页标题 | `lp -t "Bobs" cash` | 在 `cash` 打印输出的横幅页上显示 `Bobs` |
| `lp -o option file(s)` | 使用打印机特定选项 | `lp -od output` | 双面打印 `output` |
| | | `lp -obold output` | 以粗体打印 `output` |
| | | `lp -ohalf output` | 纸张对半打印 `output` |
| | | `lp -oquarter output` | 每张纸打印 4 页 `output` |
| | | `lp -olandscape output` | 横向打印 `output` |
| | | `lp -oportrait output` | 纵向打印 `output` |

### cancel
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `cancel request_id` | 停止打印作业或从队列移除（`request_id` 通过 `lpstat` 获得） | `cancel 5438` | 停止 ID 为 5438 的打印作业 |
| `cancel -a printer` | 移除当前用户对指定打印机的所有请求 | `cancel -a bobsprt` | 移除当前用户到 `bobsprt` 的所有请求 |
| `cancel -u login_id` | 移除指定用户的所有排队打印请求 | `cancel -u bob` | 取消用户 `bob` 的所有排队打印请求 |

## 进程管理

### ps
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `ps` | 显示当前终端关联的活动进程 | `ps` | 显示 PID、终端、累计时间、命令名 |
| `ps -e` | 显示所有进程 | `ps -e` | 显示所有进程的 PID、终端、累计时间、命令名 |
| `ps -f` | 显示完整进程信息 | `ps -f` | 显示 UID、PID、PPID、C、STIME、TTY、TIME、COMMAND |
| `ps -u user_id` | 显示指定用户的所有进程 | `ps -u bob` | 显示用户 `bob` 的所有进程 |
| `ps -ef` | 显示所有进程的完整列表 | `ps -ef` | 显示当前所有进程的完整列表 |

### kill
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `kill process_id` | 停止指定 PID 的进程 | `kill 6969` | 终止 PID 为 6969 的进程 |
| `kill -9 process_id` | 强制销毁指定 PID 的进程 | `kill -9 6969` | 强制终止 PID 6969，无机会清理 |

## 文本搜索

### grep
| 命令 | 说明 | 示例 | 结果 |
|------|------|------|------|
| `grep string file` | 搜索字符串并打印匹配行 | `grep mike letter` | 在 `letter` 中搜索 `mike` 并打印匹配行 |
| `grep -c string file` | 仅打印匹配行数 | `grep -c hayes bankletter` | 在 `bankletter` 中搜索 `hayes` 并输出匹配行数 |
| `grep -i string file` | 忽略大小写搜索 | `grep -i hi file1` | 在 `file1` 中搜索 `hi`、`HI`、`Hi`、`HI` 并打印所有匹配行 |
| `grep -n string file` | 显示匹配行及行号 | `grep -n abc alpha` | 在 `alpha` 中搜索 `abc` 并显示行号 |
| `grep -v string file` | 打印不匹配的行 | `grep -v lead pencils` | 打印 `pencils` 中不包含 `lead` 的行 |
| `grep -x string file` | 仅打印完全匹配的行 | `grep -x time meetings` | 仅打印 `meetings` 中完全匹配 `time` 的行 |
| `ps -ef | grep bob` | 管道配合使用：筛选包含 `bob` 的进程 | `ps -ef | grep bob` | 在完整进程列表中仅显示包含 `bob` 的行 |
| `grep -i jan b_days > mymonth` | 重定向输出到文件 | `grep -i jan b_days > mymonth` | 在 `b_days` 中忽略大小写搜索 `jan` 并写入 `mymonth` |
