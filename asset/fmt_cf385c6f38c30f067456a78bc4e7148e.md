**摘要：** 上锁挂牌（LOTO）是一种通过隔离和保护设备能源源来显著减少工作相关事故的程序。在工业 4.0 时代，安全程序必须向由机器学习或物联网等技术支持的更智能程序演进。LOTO 程序指示了如何进行安全操作。本文提出了一种实现 LOTO 表单自动生成的方法。第一步从现有的 LOTO 表单中提取信息，下一步开发文本挖掘和词相似性方法。评估了多种选项，旨在生成表单。在实践中，自动生成表单将能够实现 LOTO 程序，从而减少事故风险。

**关键词：** 工业 4.0；安全与环境；文本挖掘；上锁挂牌；`Apriori` 算法；随机森林。

# 1. 引言

工作事故可能导致严重的人员和物质后果。工业环境中，事故频率应通过现代方法和预防措施降至最低。发生事故的制造环境面临着受伤和死亡的最高风险（Bulazcelli 等，2008）。美国职业安全与健康管理局发布了能源控制的指南。自 1988 年以来，这些指南是强制性的（职业安全与健康管理局，1989）。标准要求雇主上锁设备。上锁挂牌是对能源源（液压、电气等）的隔离。LOTO 包含在技术人员进行干预时防止设备重启。这些设备由断路器锁定。在工业中，LOTO 遵循一个特定的上锁表单系统。

在工业 4.0 时代，本研究基于“操作者 5.0”的愿景——即通过信息和技术实现的智能、富有创意且资源丰富的操作者，以确保生产的连续性和员工福利（Romero 和 Stare，2021）。随着行动和决策比例的增加，人类与增强现实等技术的协作将改进这些流程并确保操作人员的安全。全球范围内，预测模型和人工智能（AI）将通过新的策略来优化维护并整合到整个过程中。机器学习（ML）技术为制造业提供了许多机会（Jamwal 等，2021a）。工业员工的安全也可以通过机器学习得到改进，特别是在生产期间（Jamwal 等，2021a）。

## 4.1. PDF 文件转换

为了实现本研究的目标1，第一步是通过检索名称和标识符来获取 LOTO 表格数据库。本研究的合作伙伴 CONFORMIT 是一家加拿大公司，负责开发、市场化和实施此类健康、安全和环境管理软件（如 LOTO 表格）。可用的 LOTO 表格为 PDF 格式，如图 3 所示。首先，我们需要将 PDF 文件转换为字符串。使用了 Python 库 "`PDF2Text`" (Kushari and Shivananda 2021) 和 "`pdfminer`" 在 Python 中将 PDF 转换为文本并进行格式化。"`pdfminer`" 允许我们保留 PDF 文件中文本的顺序，但有时单词之间的空格可能会被删除，这使得提取机器名称等重要单词变得非常困难。这些问题通过 "`pdfminer`" 解决，这也是我们选择使用它的原因。在文件转换为 txt 格式后，我们就能将 LOTO 导入到 Python 的工作表中。

## 4.2. 预处理

一旦获得数据，目标将编写仅包含设备名称作为条目的日志表格。因此，有必要建立数值预测。

为了检测信息，我们需要从 LOTO 表格中检索（机器名称、需要锁定的设备、需要遵循的指令），并结合所需的字典，必须对与每个表格相关的字符串进行以下准备。使用 Python 的 `nltk` 库执行了以下步骤：

- 对字符字符串进行分词（Tokenization），以隔离存在的每个单词
- 删除不携带重要信息的单词
- 删除过短的单词（<2 个字符）（这可能会在检测单词间的相似性时产生问题）

LOTO 表格的处理和这些表格的编写需要提取相关信息，这些信息将构成我们自动生成表格的数据。文本挖掘对于完成此任务非常重要（De 2019）。

## 4.3. 分析

下一步是搜索分析表格单词与设备单词之间的相似性。这一步是获取通过相似性进行单词关联的数据框的主要挑战。NLTK 库中的几种算法可用于此目的。`J-Winkler` 距离算法是衡量两个单词之间相似性的另一种方法（Yulianto and Nurhasaman 2021）。

该方法采用 0 到 1 之间的比例：1:1 对应两个相同的单词。相似性的计算稍微复杂，并且单词长度经过了压缩。针对拼写错误的简单改进也经过了权重减少。尽管存在这些缺点，仍然选择了 Jan-Winkler 距离，因为它对短单词有更好的识别率。

# 5. LOTO 表格预测模型

基于现有的锁定表，文本挖掘允许获取一个可靠的数据库，可以在其中应用分类算法。获取此数据库需要在识别重要单词和提取不携带重要信息的方面投入大量工作。Natural Language Toolkit 等库允许处理这些 PDF 格式的文件，这在行业中非常常见。

关联规则的研究是文本挖掘中的关键步骤，因为它试图揭示大型数据集中有意义的值。关联规则被推荐用于聚类分析，但它们被认为是各个领域的通用数据。具体而言，它们被建议用于关联规则分析。最重要且简单的是 `Apriori` 算法（Agrawal and Srikant 1994）。`Apriori` 算法允许对数据库中发现的属性值进行不同的组合。关联规则的探索由置信度阈值控制。这些阈值的设置是为了寻找搜索区域，使得计算过程成为可能（Dhabi et al., 2021）。像 `Apriori` 这样的算法允许提取模式并根据机器类型选择操作序列。机器名称可以与锁定指令直接关联。医学文本信息已进行相关研究（Toun et al., 2021），使用了 `Apriori` 算法。类似的工作可以应用于 LOTO 表格等安全程序。

## 4.5 性能评估

机器名称、设备和指令的检索可以视为多标签分类问题。检索问题可以通过计算我们的算法在测试集上的准确率来计算。准确率是已检索的相关实例的比例。

# 6. 结论

本研究处于工业 4.0 背景下，ESH 4.0 可以通过提供由人类编写的安全程序来提高工业安全性。本文介绍了生成 LOTO 集合的工作，即第一个识别出的子图是从需要锁定的机器名称中提取信息，以及正确排序它们的指令。将 PDF 文本格式的 LOTO 集合转换为可用的数据库，用于基于机器名称的逻辑建模并经过了测试。如果发现从图中提取数据时存在的某些错误对方法影响很大，则可能需要对数据库进行处理。

在第二个子目标中，研究项目的步骤是结合 `Apriori` 和随机森林算法的机器学习模型的训练和测试。最后，需要调整关联算法和装袋算法的参数，根据上述行生成 LOTO 表单。这项工作目前基于文本 pdf 文件，也可以对图像 pdf 进行文本识别。事实上，许多工业者仅有 PDF 图片形式的表单，这些表单是改进预测模型的重要来源。由于主题涉及记录记录，代理将遵循预测结果，且必须确保在编写安全实践时实际使用此类任务。
