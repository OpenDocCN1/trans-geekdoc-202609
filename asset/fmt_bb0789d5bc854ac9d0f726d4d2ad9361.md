## 17.1 简介

本章承接第 14 章，后者的重点是蒙特卡洛方法。我们现在的兴趣转向一种特殊的采样类型，称为序贯采样方法。与第 14 章中讨论的蒙特卡洛技术不同，这里我们假设想要从中采样的分布是时变的，并且采样将以序贯方式进行。本章的主要重点是用于状态空间动态模型推断的粒子滤波技术。与经典形式的卡尔曼滤波不同，此处允许模型是非线性的，和/或涉及变量的相关分布为非高斯分布。

## 17.2 序贯重要性采样

在本节中，我们的关注点转向数据序贯到达的任务，我们的目标变为从其联合分布中采样。换句话说，我们接收随机向量 `x[n]` 的观测值 `x[n] ∈ ℝ^l`。在某一时刻 `n`，令 `x[1:n] = {x[1], …, x[n]}` 表示可用样本的集合，并令相应的联合分布记为 `pn`。毫无疑问，这项新任务需要特别对待。不仅任务的维度（随机变量的数量，即 `x[1:n]`）现在是时变的，而且经过一段时间后，维度将变得非常大，并且通常我们预期相应的分布 `pn` 形式相当复杂。此外，在时刻 `n`，即使我们知道如何从 `pn` 中采样，所需的采样时间至少也将达到 `n` 的阶。因此，随着 `n` 的增加，即使是这种情况对于较大的 `n` 值也可能在计算上不可行。序贯采样在粒子滤波背景下的动态系统中具有特别的意义，我们将很快处理此类系统。我们的讨论将围绕第 14.5 节介绍的重要性采样方法展开。

### 17.2.1 重要性采样回顾

回顾公式 (14.28)，已知：(a) 一个函数 `f(x)`；(b) 一个期望分布 $p(\mathbf{x}) = \frac{1}{Z}\phi(\mathbf{x})$；(c) 一个建议分布 `q(x)`。我们有

$$
\mathbb{E}\left\lbrack f(\mathbf{x}) \right\rbrack := \mu_{f} \approx \sum\limits_{i = 1}^{N}W(\mathbf{x}_{i})f(\mathbf{x}_{i}) := \widehat{\mu},
$$ (17.1)

其中 `x[i]` 是从 `q(x)` 中抽取的样本。回顾一下，估计值

$$
\widehat{Z} = \frac{1}{N}\sum\limits_{i = 1}^{N}w(\mathbf{x}_{i})
$$ (17.2)

对应于真实归一化常数 `Z` 的无偏估计量，其中 `w(x[i])` 是未归一化权重，$w(\mathbf{x}_{i}) = \frac{\phi(\mathbf{x}_{i})}{q(\mathbf{x}_{i})}$。注意，公式 (17.1) 中的近似等价地意味着对期望分布的以下近似：

![Equation](img/fx001.jpg) (17.3)

换句话说，即使是连续的 PDF 也可以用一组离散点及其分配的权重来近似。我们称该分布由粒子 `x[i]`、$i = 1, 2, \dots, N$ 及其相应的归一化权重 `W^((i)) := W(x[i])` 定义的*离散随机测度*来近似。该近似随机测度记为 $\chi = \{\mathbf{x}_{i}, W^{(i)}\}_{i=1}^{N}$。

此外，我们已经在 14.5 节中指出，重要性采样的一个主要缺点是权重的方差很大，这在高维空间中会变得更加严重，而我们从现在开始的兴趣将集中在高维空间。让我们进一步详述方差问题，并寻找绕过/减少这种不良行为的方法。

可以证明（例如参考文献[35]和习题 17.1），公式(17.1)中相应估计量`μ̂`的方差由下式给出：

```
var[μ̂] = (1/N) ( ∫ f²(x)p²(x)/q(x) dx - μ_f² )
```

观察可知，如果分子`f²(x)p²(x)`趋向于零的速度比`q(x)`慢，那么对于固定的`N`，方差`var[μ̂] → ∞`。这表明非常仔细地选择`q`至关重要。通过最小化公式(17.4)不难发现，使方差达到最小（零）的`q(x)`的最优选择与乘积`f(x)p(x)`成正比（不妨一试！）。我们稍后将利用这一结果。当然，请注意比例常数应为`1/μ[f]`，这是未知的。因此，这一结果只能作为一个基准。

关于方差问题，让我们把注意力转向公式(17.2)中`Z`的无偏估计量`Ẑ`。可以证明（习题 17.2）：

```
var[Ẑ] = (Z²/N) ( ∫ p²(x)/q(x) dx - 1 )
```

根据其定义，`Ẑ`的方差与权重的方差直接相关。事实证明，在实践中，公式(17.5)中的方差呈现出对维数的指数依赖性（例如参考文献[12,16]和习题 17.5）。在这种情况下，样本数`N`必须过大，才能使方差保持相对较小。部分应对与方差相关问题的一种方法是*重采样*技术。

### 17.2.2 重采样

重采样是一种非常直观的方法，其中尝试对从 `q` 中抽取的可用样本（粒子）进行*随机*修剪，通过（最有可能）丢弃与低权重相关的样本，并用权重值较大的样本替换它们。这是通过从 `p(x)` 的近似 `p̂(x)` 中抽取样本来实现的，该近似基于公式 (17.3) 中的离散随机测度 `{x[i], W^(i)}[i=1]^N`。在重要性采样中，涉及的粒子从 `q(x)` 中抽取，并适当计算权重以“匹配”期望的分布。增加重采样这一额外步骤后，从 `p` 的离散近似 `p̂` 中抽取一组*新的*无权重样本。使用重采样步骤，我们仍然获得近似按 `p` 分布的样本；此外，低权重的粒子已以高概率被移除，从而增加了下一时刻探索具有较大概率质量区域的概率。从离散分布中采样有不同的方法。

*   **多项式重采样。** 此方法等同于示例 14.2 中提出的方法。每个粒子 `x[i]` 关联一个概率 `P[i] = W^(i)`。重新抽取 `N` 个（新）粒子将从每个粒子 `x[i]` 生成 `N^(i)` 个“后代”（`∑_{i=1}^N N^(i) = N`），具体取决于它们各自的概率 `P[i]`。因此，`N¹, …, N^(N)` 将遵循多项式分布（第 2.3 节），即：

```
P(N¹,...,N^(N)) = ( N / (N¹...N^(N)) ) ∏_{i=1}^N P_i^(N^(i)).
```

*   这样，最初抽取的粒子的概率（权重 `W^(i)`）越高，该粒子被重新抽取的次数 `N^(i)` 就越大。

*   此时，所需分布的新离散估计由下式给出：

```
\overline{p}(\mathbf{x}) = \sum\limits_{i = 1}^{N}\frac{N^{(i)}}{N}\delta(\mathbf{x} - \mathbf{x}_{i}).
```

*   根据多项分布的性质，我们有 `𝔼[N^(i)] = N*P[i] = N*W^(i)`，因此 `\overline{p}(\mathbf{x})` 是 `\hat{p}(\mathbf{x})` 的无偏近似。

*   **系统重采样**。系统重采样是多项式方法的一种变体。回顾示例 14.2，每当需要（重新）抽取一个粒子时，都会从均匀分布 `𝒰(0, 1)` 生成一个新样本。相比之下，在系统重采样中，该过程并非完全随机。为了生成 `N` 个粒子，我们仅随机选择一个样本 `u¹ ~ \mathcal{U}(0, \frac{1}{N})`。然后定义

```
u^{(j)} = u^{(1)} + \frac{j - 1}{N},\quad j = 2,3,\ldots,N,
```

*   并设定

```
N^{(i)} = {card}\ \left\{ \text{All~}j:\sum\limits_{k = 1}^{i - 1}W^{(k)} \leqslant u^{(j)} < \sum\limits_{k = 1}^{i}W^{(k)} \right\},
```
