
# Python 机器学习：机器学习领域初学者综合指南

## Python 编程语言概述

### 简介

Python 是人们偏爱的几种多范式编程语言之一。它可用于多种用途，是解释型语言，且易于理解。Python 的工作方式令人惊叹，因为它使用户能够为复杂和简单的设计创建和使用各种程序。这意味着 Python 拥有一些特殊的插件，允许创建可在其他平台上运行的简单代码。因此，掌握 Python 知识，你就能确信自己能够在同一范式内处理不同的语言。

令人惊讶的是，当使用 Python 编码时，它能快速产出结果。尽管 Python 提供了对不同平台的访问，但它能即时给出结果。同样，使用 Python 编写代码变得很简单，就像在说人类语言一样。Python 拥有这种多任务特性，允许用户使用不同的风格实现单一的编程代码。风格可能会影响代码的最终结果；尽管结果肯定相同，只是略有修改。

Python 易于学习，但语法的核心重点是可读性。正因如此，维护风险大幅降低。模块和包是 Python 支持的基本要素；这些实现了代码的重用和程序的模块化。Python 的这些惊人特性使其成为程序员始终会使用并推荐给他人的领先语言之一。

### 核心特性

在编码时，Python 解释器及标准库始终可用。这些非常重要，因为它们确保了通过库免费访问其他外部平台，甚至包括它们的发行版。它们以二进制形式提供，并且无论平台如何，始终与其源代码保持关联。

Python 通过引用计数和循环检测垃圾收集器来管理内存。它具有动态解析功能，基本上在执行项目时绑定并保存方法及其他变量名。这使得编码不仅简单，而且极其实用。

Python 编程语言拥有诸如 `map`、函数归约等过滤器，以增强其在代码执行每个节点的使用。它拥有推导式、列表函数、字典、表达式集合和生成器。其标准库基本上是两个：`itertools` 和 `functools`。这些库负责函数实现，特别是来自其他来源的函数。

该编程语言的核心重点可概括为以下格言：

- **优美胜于丑陋**
- **显式胜于隐式**
- **简单胜于复杂**
- **复杂胜于繁琐**
- **可读性很重要**

许多人不解 Python 为何能以简单方式运行，尽管它处理复杂任务。这是因为它设计有广泛的扩展。这些扩展使得向现有应用程序添加接口变得更容易。Python 强调，拥有简单的语法和语法规则是赋予程序员编码方法论动态性的主要关键。

### 发展历史

在发展过程中，Python 经历了两次显著的发展。20 世纪 80 年代，它最初由 Guido Van Rossum 开发。然而，Python 近期的发展是由 Python 软件基金会主导的。

### 应用

Python 的用途包括：设计网站、游戏开发、数值编程、串口通信等。无论 Python 用于何处，其优雅始终存在，且多样的风格使网页设计非常独特。

### 执行模型

Python 编程语言本质上是解释型的。因此，在启动或运行给定代码之前，需要一次性编译所有编写的代码，以便通过 `print` 命令进行后续解释。同时，使用 Python，你作为程序员可以极大地促进不同软件设计背景的成长。抽象细节的过程是一种机制，作为 Python 的核心焦点，即使是新手也能理解。此外，使用 Python 编码相对简短；代码短但输出体面。

Python 的一个显著问题是，尽管它确保了快速开发，但执行速度略微滞后。Python 会编译代码，但当执行过程与 C 和 C++ 等其他语言相比时，它相对较慢。Python 的工作流程是：编码、调试、接收和执行。它通常包含 Linux 发行版和 macOS 系统以确保其速度。除了确保工作时的速度外，现代计算机相对较快，这也增强了 Python 的运行方式——这对它来说是一个优势。

### 生产力与调试

Python 始终是程序员的选择，因为它在提高生产力方面效率极高。Python 的步骤依次是编辑、测试和调试。有趣的是，Python 代码输入中的错误永远不会导致带有错误的分段故障；这使许多程序员认为它是最容易调试的语言之一。Python 不会通过解释器创建带有错误的分段故障，而是会引发一种异常。如果该异常仍未被捕获，它将作为堆栈跟踪打印出来——只是为了保证万无一失。

Python 编程语言使用调试器来检测编程中的变异性。除此之外，它还在编码时评估任意表达式的情况。有趣的是，这些调试器也是用 Python 语言编写的。这强化了 Python 拥有内省能力的事实。这还会深入代码行，在需要时对其进行必要的评估。

### 行业采用

总之，为了证明 Python 一直以来非常有用，许多其他技术都采用了它。其中包括 YouTube、BitTorrent、Eve Online、Google Search、Maya、iRobot 机器、Google App Engine 等。通过 Python 完成工作的有效性是使用它的一大优势。

## 第 1 章 – 认识 Python

由于本书面向初学者，因此向您介绍如何开始使用 Python 编程语言、它的用处、缺点、为何备受青睐以及更多相关内容至关重要。

总体而言，Python 被视为一种具有高级编程语言功能的开源语言。它诞生于 20 世纪 80 年代，由 Guido van Rossum 开发，后由 Python 软件基金会管理。Guido 受到启发的一个因素是 ABC 语言源自一门塑造了他职业生涯的语言。正如本书简介部分所述，Python 是最强大的语言之一，可用于创建游戏、编写 GUI 以及开发 Web 应用程序。

就 Python 代码的阅读和编写能力而言，它或多或少就像阅读和编写普通的英语语句；实际上它们并非用机器可读语言编写。Python 程序无需在机器运行前进行处理；它们只会被解释执行。此外，Python 是一种解释型语言（它拥有一个解释器）。这意味着每次编码后运行程序时，解释器都会遍历代码并将其翻译成机器可读的字节码。

Python 是一种面向对象的语言，允许用户管理和控制数据结构，因为它拥有庞大的数据结构类型。它也反对创建和运行程序（注：原文 "It has objected to create and run programs too" 疑为笔误，译文直译原意）。因为在 Python 中所做的一切都对程序员和用户有利，所有函数、对象、类、数据类型和方法在 Python 中地位平等。它是一种高级语言。为了充分发挥满足程序员需求的功能，Python 作为一种工具，能高效地开发生活方式、造福整个社会、造福人类的应用程序以及经济。

毫无疑问，Python 让一切变得更好；它提高了生产力、沟通效率和工作效率。任何语言的基本特征之一是它可能消亡并灭绝，从而被更新的语言取代——多年来 Python 证明并非如此。只有极具生命力的语言才能经受住时间的考验。Python 本身经受住了时间的考验，并证明自诞生以来在应用的各个方面都很有用。因为 Python 非常有利可图、简单且高效，所以推荐给所有人，尤其是想以编程为职业的人——没有编程基础的人肯定会觉得这很有趣。

简要介绍了 Python 之后，您想必已对它有所了解。那么，您可能会问，Python 有什么优势？使用 Python 编程语言的优势怎么强调都不为过，主要包括：

### 提高生产力

尽管 Python 编程使用的代码相对较短、更简单，与 C++ 等其他高级编程语言相比并没有多少代码量。同样，Python 拥有旨在产出更高生产力的完善内置功能。此外，它还拥有标准库，以及使用第三方模块和其他源库的机会。这些独特功能使 Python 语言编程更具产出和高效。

### 易于学习

尽管 Python 非常有效，但学习起来相当容易。这就是为什么许多人更喜欢并认为 Python 是学习编程的良好入门语言。事实上，许多程序员会反复向初学者推荐它。这是因为 Python 使用简单的语法以及更短的代码。

### 易于阅读

Python 程序使用精确、清晰且简洁的指令，非常易于阅读。即使没有扎实编程背景的人最终也会发现它非常容易——这是 Python 的优势。由于编辑、运行和调试功能的循环，用 Python 编写的程序易于维护、调试或增强——这就是可读性。

### 广泛支持主流平台

Python 编程跨平台运行于 Windows、macOS、Linux/UNIX 和其他操作系统，甚至适用于小型设备。此外，它还可以在遥控器、家电中使用的微控制器、玩具、嵌入式设备等设备上运行。

### 软件质量

凭借 Python 的可读性功能，代码的可重用性和可维护性使其成为一种杰出的编程语言，而不仅仅是古老的脚本语言。软件质量基于这样一个事实：代码的统一性超越了传统脚本。因此，即使是没有编程预备知识的人也非常容易阅读。Python 设置中连贯性功能的增强也使其具有高质量和独特性。能够重复使用相同代码的机制也是 Python 编程的一个独特属性。

### 少劳多得

程序员偏爱 Python 的原因之一是，较少的编码工作就能产出高生产力。除此之外，程序能即时运行，无需像 Java 或 C++ 等其他语言那样经历编译过程。换句话说，一旦程序正常运行，需要输入、调试或维护的东西就更少了。这鼓励程序员更快地推进工作。

### 程序耐用性

耐用性意味着可以在不同平台上为给定程序运行相同的代码。凭借单一代码串，可在其他平台上执行相同操作，尽管可能存在差异，这可能是因为是在不同平台上运行相同代码。编写优秀图形、用户界面等的多样化选项始终存在。同时，来自 Windows 和 Linux 等其他程序的代码将强烈要求脚本代码，这将导致它们无法在其他平台上使用。

### 组件集成与交互

通过不同的机制，Python 脚本可以轻松与应用程序的其他部分通信。此外，这种集成允许 Python 被用作定制和扩展工具的产品。Python 经历的变革使其代码能够调用 C 和 C++ 库，也能被 C 和 C++ 程序调用。令人惊叹的是，该代码还可以与 Java 和 .NET 组件集成。它可以通过 COM 和 Silverlight 等框架进行通信。由于这种集成，代码可以通过串口与设备接口，并通过 XML-RPC、SOAP 和 CORBA 等接口在网络上交互。

### 允许使用多样化的内置库

Python 的特别之处之一，也是人们偏爱它的原因，是因为它自带一个标准字典（注：原文 "standard dictionary" 疑指 "standard library"，此处直译原文）。该库支持一系列应用级编程任务，从文本模式匹配到网络脚本编写。此外，Python 既可作为内置库的扩展，也可作为大量第三方应用支持软件的扩展。Python 的第三方领域提供用于网站构建、数值编程、串口访问、游戏开发等方面的工具。

### 易于操作

使用 Python 获得的乐趣是人们更喜欢它而非其他语言的另一个因素。这是因为艰巨的任务（编码）被揭秘为或多或少像普通家务一样简单。因此，Python 使用内置工具。虽然考虑到其相关性的层面，这种理由可能显得薄弱，但生产力的提高和软件质量的改善也是与之并列的显著理由。

说了这么多关于 Python 构建方式的内容，问题依然存在：Python 是“脚本语言”吗？还是 Python 与脚本有关？要回答这个问题，请知悉 Python 是一种通用编程语言，常用于脚本角色。此外，Python 通常被定义为面向对象的脚本语言。这是一种支持 OOP 且整体面向脚本角色的定义。如果非要用一句话概括，可以说 Python 更广为人知的是一种通用语言。

要全面了解 Python，请在任意 Python 交互提示符下输入命令 `import this`（您将在本书后续内容中理解这一点）。这将调用 Python 中隐藏的一个“彩蛋”——一组渗透于语言及其用户社区的设计原则。其中，首字母缩略词 EIBTI 现在是“显式优于隐式”这条规则的时髦行话。

## 第 2 章 – Python 实战

### 安装 Python (Windows)

开始使用 Python 的一部分工作是在 Windows 上安装 Python。安装的第一步是从下面的链接下载您首选版本的安装包：

https://www.python.org/downloads/

访问此链接，您将被定向到一个页面。在该页面上，您需要在 Python 2 和 3 的两个最新版本之间进行选择：`Python 3.5.1` 和 `Python 2.7.11`。反之，如果您在寻找特定版本，可以浏览页面以找到早期版本的下载链接。通常，您会选择下载最新版本，即 `Python 3.5.1`（于 2015 年 12 月 7 日发布）——或者下载 Python 2 的最新版本 `2.7.11`。但是，您下载的版本必须取决于您想要进行的项目类型，虽然 Python 3 是该语言的现在和未来，但诸如第三方工具或兼容性之类的问题可能要求您下载 Python 2。

下载完成后，您可以通过点击下载的 `.exe` 文件继续安装。标准安装将包含 `IDLE`、`pip` 和文档。

### 安装 Python (Mac)

如果您使用的是 Mac，可以从以下链接下载安装包：

https://www.python.org/downloads/mac-osx/

学习的进程正进一步深入 Python 编程语言。实际上，Python 是一种适应性强且功能强大的语言，可从多个角度使用。这仅意味着当代码或声明要在逐行的基础上进行尝试，或者当您在探究其特性时，Python 可以被智能地使用。令人难以置信的是，Python 可以用于脚本模式，特别是当您想要解释整个声明文档或应用程序时。然而，使用 Python 需要极度小心——特别是当您正在接触或连接它时。这种谨慎对每种编程语言同样适用。

为了以交互方式使用 Python，可以使用命令行窗口或 `IDLE 开发环境`。既然您是编程或使用 Python 的初学者，将会有不同的步骤来介绍您如何连接和配合 Python 编程语言。以下是与 Python 快速交互的基本操作特性：

### 命令行交互

对于初学者来说，与命令行交互是使用 Python 的最简单方法。通过查看 Python 对在 `>>>` 提示符下输入的每条完成命令的反应，就可以简单地想象 Python 是如何工作的。命令行可能不是与 Python 交互的最受青睐方式，但多年来，它已被证明是初学者探究 Python 如何工作的最简单方法。

#### 使用命令行启动 Python

如果您使用的是 macOS、GNU/Linux 和 UNIX 框架，应运行 `Terminal` 工具以访问命令行。另一方面，如果您使用的是 Windows，可以通过右键点击开始菜单并启动 `Windows PowerShell` 来访问 Python 命令行。

由于编程指令需要输入命令，当您需要 Python 为您做某事时，您将通过输入它知道的命令来指令它，以获得类似的输出。命令的细微调整可能会给出理想的输出；请小心。有了这个，Python 将把这些命令翻译成您的计算机或设备能够理解和执行的指令。

让我们看看一些指南，以了解 Python 是如何工作的。请注意，您可以使用 `print` 命令来打印通用程序 "Heydays, Savants!"。

1.  首先，打开 Python 的命令行。
2.  然后，在 `>>>` 提示符下，输入以下内容（不要在 print 和括号之间留空格）：
    `print ("Heydays, Savants!")`
3.  现在，您应该按回车键，以便告诉 Python 您已完成该命令。

命令行窗口将立即显示 `Heydays, Savants!`。同时，Python 的反应正如它在书面安排中被告知的那样，它可以与之关联。

另一方面，要查看当您要求它使用 `print` 命令的错误语法打印相同字符串时它将如何错误地反应，请在 Python 命令提示符下输入并回车以下命令：

`Print("Heydays, Savants!")`

结果将是：

`Syntax error: invalid language structure`

这是当您使用无效或片段说明时会得到的情况的一个例子。请注意，Python 是一门**大小写敏感**的编程语言，因此每当您收到误解消息时，可能是因为您用大写字母写了 `print`。

显然，除了 print 命令外，您还可以直接在引号内输入您的声明，如下所示：

`"Primes, Savants!"`

请注意，声明是指令发出后您希望显示的词语；不过，能填入的词语不限于此处给出的示例。

#### 如何退出 Python 命令行

要退出 Python，您可以输入以下任一命令：

`quit()` 或 `exit()`。

随后，按住 `Control-Z` 然后按 `Enter`；Python 应该会退出。

您对 Python 编程的熟悉程度现在应该变得有趣了；还有很多部分需要学习，耐心会有回报。

### IDLE 的区域：Python 的集成开发环境 (IDE)

Python 最迷人的部分之一是 `IDLE`（集成开发和学习环境）工具。尽管这个特定工具包含在 Python 的安装包中，但您也可以下载越来越复杂的第三方 IDE。`IDLE` 工具为您提供了一个越来越有效的平台来编写代码并引人入胜地使用 Python。

要访问 `IDLE`，您可以浏览到您找到命令行图标的相同文件夹，或开始菜单（正如您从命令行交互中了解到的）。当您点击 `IDLE` 图标时，您将被引导至 `Python Shell 窗口`。这将带我们进入与 `Python Shell 窗口` 交互的部分。

### 与 Python Shell 窗口连接

当您位于 `Python Shell 窗口` 时，您将看到一个下拉菜单和一个类似于您在命令行窗口中看到的 `>>>` 提示符（讨论的主要连接）。有一个特定的 `IDLE` 编辑功能用于处理过去的命令。现在，您将使用相同的 `IDLE` 编辑菜单来回溯您过去的命令，剪切、复制和粘贴过去的语句，并在所有事情中，进行任何形式的编辑。

显然，`IDLE` 与命令行交互相比更像是一个飞跃。令人难以置信的是，`Python Shell 窗口` 的菜单下拉列表中有以下菜单项：

`File`、`Windows`、`Help`、`Shell`、`Options`、`Edit` 和 `Debug`。
