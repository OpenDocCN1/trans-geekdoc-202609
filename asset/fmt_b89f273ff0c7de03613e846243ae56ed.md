
此外，受 `homotopy`（拟续）算法族的启发，其中 $\lambda$ 允许变化，SpaRSA 可以扩展为求解一系列问题，这些问题对应于一系列 $\lambda$ 值。一旦为特定的 $\lambda$ 值获得了解，它就可以用作附近 $\lambda$ 值的“热启动”。因此，与从“冷启动”求解单个值相比，可以以很小的额外计算成本计算一系列值的解。这种技术遵循 `continuation strategy`（延续策略），该策略也用于其他算法的背景中（例如 [66]）。延续策略已被证明是提高收敛速度的非常成功的工具。

### FISTA 算法

文献 [11] 提出了基本 IST 方案的一个有趣变体，通过仅简单的修改且几乎没有额外的计算负担，将收敛率提高到了 $O(1/i^2)$。该方案称为 `fast iterative shrinkage-thresholding algorithm`（快速迭代收缩阈值算法，FISTA）。该方案是文献 [96] 的演进，后者为可微代价函数的情况引入了基本思想，包含以下步骤：

#### 算法迭代公式

```
\mathbf{\theta}^{(i)} = S_{\lambda\mu}\left( \mathbf{z}^{(i)} + \mu X^{T}\left( \mathbf{y} - X\mathbf{z}^{(i)} \right) \right),
\mathbf{z}^{(i + 1)} := \mathbf{\theta}^{(i)} + \frac{t_{i} - 1}{t_{i + 1}}\left( \mathbf{\theta}^{(i)} - \mathbf{\theta}^{(i - 1)} \right)
```

![Equation](img/si103.png)

其中

```
t_{i + 1} := \frac{1 + \sqrt{1 + 4t_{i}^{2}}}{2}
```

![Equation](img/si104.png)

初始点为 `t[1] = 1` 和 `z¹ = θ⁰`。

![Equation](img/si105.png)
![Equation](img/si106.png)

简而言之，在阈值操作中，`θ^(i-1)` 被 `z^(i)` 替代，后者是两个连续 `θ` 更新的特定线性组合。因此，在计算成本略微增加的情况下，实现了收敛速度的显著提升。

在文献 [17] 中使用了硬阈值版本，令 `μ = 1`，阈值函数 `H[k]` 使用目标解的稀疏度 `k`，假设该值已知。在后续版本 [19] 中，松弛参数可变，使得每一迭代步骤的误差最大程度减少。研究表明，在 `θ` 为 `k`-稀疏向量的约束下，该算法收敛到代价函数 `||y - Xθ||_2` 的局部最小值。此外，该后续版本是稳定的，若满足某种形式的 RIP（限制等距性质），则能得到近似最优解。

#### 坐标下降法

通用方案 Eq. (10.2) 的一个修改版本，沿着文献 [84] 的思路，逐分量获取更新，即一次更新一个向量分量。因此，一次“完整”迭代包含 `l` 步。该算法称为*坐标下降法*，其基本迭代形式如下（见 Problem 10.5）：

```
\theta_{j}^{(i)} = S_{\lambda/{\|\mathbf{x}_{j}^{c}\|_{2}^{2}}}\left( \theta_{j}^{(i - 1)} + \frac{{\mathbf{x}_{j}^{c}}^{T}\mathbf{e}^{(i - 1)}}{\|\mathbf{x}_{j}^{c}\|_{2}^{2}} \right),\quad j = 1,2,\ldots,l.
```

![Equation](img/si110.png)(10.9)

如果 `X` 的列未归一化为单位范数，该算法将先前报道的软阈值算法中的常数 `c` 替换为 `X` 相应列的范数。已证明并行坐标下降算法也收敛到 (9.6) 的 LASSO 极小化解 [50]。利用线搜索技术确定每次迭代的最速下降方向来改进该算法的方法也已被提出（参见 [124]）。

迭代收缩算法族的复杂度主要贡献来自两个矩阵-向量乘积，其计算量为 $\mathcal{O}(Nl)$![Equation](img/si111.png)，除非 `X` 具有可利用的特殊结构（如 DFT）以减轻负载。

文献 [85] 提出了两阶段阈值（TST）方案，该方案融合了迭代收缩族和 OMP 的论点。该算法方案包含两个阈值阶段。第一步与公式 (10.2) 完全相同。然而，此处它仅用于确定“显著”的非零位置，正如上一小节介绍的 CSMP 算法那样。然后，在可用支撑集的约束下，求解一个最小二乘（LS）问题以提供更新后的估计。随后进行第二步阈值处理。两个阶段的阈值操作可以不同。在硬阈值处理中，两步均使用 $H_{k}$![Equation](img/si62.png)；这产生了文献 [58] 中提出的算法。对于后一种方案，如果 RIP 对 $\delta_{3k} < 0.58$![Equation](img/si112.png) 成立，则可推导出收敛性和性能界。换句话说，TST 与 CSMP 方法的基本区别在于：后者通过检查相关项 $X^{T}\mathbf{e}^{(i-1)}$![Equation](img/si113.png) 获取最显著的非零系数，而 TST 族则通过检查 $\mathbf{\theta}^{(i-1)} + \mu X^{T}\mathbf{e}^{(i-1)}$![Equation](img/si114.png) 获取。不同方法之间的差异可能很小，不同算法类别之间的界限不一定清晰分明。然而，从实际角度来看，微小的差异有时可能带来性能的显著提升。

文献 [41] 在图模型（第 15 章）的背景下，将 IST 算法框架视为一种*信息传递*算法，并得出了以下修正递归：

```
**θ**^((*i*)) = *T**i*) + *X*^(*T*)**z**^((*i* − 1))),
```

![Equation](img/si115.png)(10.10)

```
\mathbf{z}^{(i - 1)} = \mathbf{y} - X\mathbf{\theta}^{(i - 1)} + \frac{1}{\alpha}\mathbf{z}^{(i - 2)}\bar{T_{i}^{\prime}\left( \mathbf{\theta}^{(i-2)}+X^{T}\mathbf{z}^{(i-2)} \right)},
```

![Equation](img/si116.png)(10.11)

其中 $\alpha = \frac{N}{l}$，上划线表示相应向量所有分量的平均值，*T*[*i*]^′ 表示逐分量阈值规则的相应导数。与 IST 系列相比，方程 (10.11) 右侧新出现的额外项，在欠采样-稀疏性权衡方面（第 10.2.3 节）提供了算法性能的提升。请注意，*T*[*i*] 依赖于迭代，并通过某些参数的定义进行控制。文献 [91] 提出了一个无参数版本。关于消息传递算法的详细论述可参见文献 [2]。

#### 备注 10.2

*   方程 (10.6) 中的迭代将 IST 算法族与凸优化中的另一个强大工具联系起来，该工具建立在*邻近映射*或*Moreau 包络*的概念之上（参见第 8 章以及，例如，文献 [32,105]）。给定一个凸函数 *h* : ℝ^(*l*) → ℝ 和一个 *μ* > 0，关于 *h* 且指标为 *μ* 的邻近映射，*Prox*[*μh*] : ℝ^(*l*) ↦ ℝ^(*l*)，被定义为（唯一的）最小化子

### 近端算子与近端梯度下降法

#### 近端算子的定义

近端算子定义为：

```
\text{Prox}_{\mu h}(\mathbf{x}) := \arg\min_{\mathbf{v} \in \mathbb{R}^{l}} \left\{ h(\mathbf{v}) + \frac{1}{2\mu} \|\mathbf{x} - \mathbf{v}\|_2^2 \right\}, \quad \forall \mathbf{x} \in \mathbb{R}^{l}.
```

![Equation](img/si122.png)(10.12)

#### 问题设定

假设我们要最小化一个凸函数，该函数由两部分之和给出：

```
f(\boldsymbol{\theta}) = J(\boldsymbol{\theta}) + h(\boldsymbol{\theta}),
```

![Equation](img/si123.png)

其中 $J$ 是凸且可微的，$h$ 也是凸的，但不一定光滑。

#### 近端梯度迭代

可以证明（见 第 8.14 节），以下迭代收敛到 $f$ 的一个极小值点：

```
\boldsymbol{\theta}^{(i)} = \text{Prox}_{\mu h}\left( \boldsymbol{\theta}^{(i-1)} - \mu \frac{\partial J(\boldsymbol{\theta}^{(i-1)})}{\partial \boldsymbol{\theta}} \right),
```

![Equation](img/si124.png)(10.13)

其中 $\mu > 0$，且 $\mu$ 也可以是迭代依赖的，即 $\mu[i] > 0$。

![Equation](img/si120.png) ![Equation](img/si125.png)

#### 应用于 L1 正则化代价函数

如果我们用该方案来最小化熟悉的代价函数：

```
J(\boldsymbol{\theta}) + \lambda \|\boldsymbol{\theta}\|_1,
```

![Equation](img/si126.png)

我们将得到公式 (10.6)；这是因为 $h(\boldsymbol{\theta}) := \lambda \|\boldsymbol{\theta}\|_1$ 的近端算子被证明（见 [31,32] 和 第 8.13 节）与软阈值算子相同，即：

```
\text{Prox}_h(\boldsymbol{\theta}) = S_\lambda(\boldsymbol{\theta}).
```

![Equation](img/si128.png)

#### 理解近端算子

为了更直观地理解该算子，注意如果 $h(\mathbf{x}) \equiv 0$，其近端算子等于 $\mathbf{x}$ 本身，此时公式 (10.13) 退化为我们熟悉的梯度下降算法。

![Equation](img/si129.png)

### 非贪心算法求解替代形式

迄今为止讨论的所有非贪心算法都是为了求解公式 (9.6) 中定义的任务而开发的。这主要是因为这是一个更容易求解的任务；一旦固定了 `λ`，它就变成了一个无约束优化任务。然而，也存在一些算法是专门为求解替代形式而开发的。

#### NESTA 算法

NESTA 算法由文献 [12] 提出，用于求解其 (9.8) 形式下的任务。采用这条路径具有一定优势，因为 `ϵ` 可能作为与噪声相关的不确定性的估计值给出，这在许多实际应用中可以轻松获得。相比之下，预先选择 `λ` 的值则更为复杂。在文献 [28] 中，认为值 `λ = σ_η√(2 ln l)`（其中 `σ[η]` 为噪声标准差）具有某些最优性质；然而，这一论点依赖于 `X` 的正交性假设。

NESTA 很大程度上依赖于 Nesterov 的通用方案 [96]，因此得名。原始 Nesterov 算法对光滑凸函数 `f(θ)` 执行约束最小化，即：

```
min_{θ ∈ Q} f(θ),
```

其中 `Q` 是一个凸集，在我们的情况下，它与 (9.8) 中的二次约束相关联。该算法由三个基本步骤组成。第一步涉及一个辅助变量，类似于公式 (10.3) 中的步骤，即：

```
w^(i) = arg min_{θ ∈ Q} { (θ - θ^(i-1))^T ∂f(θ^(i-1))/∂θ + L/2 ||θ - θ^(i-1)||_2² },
```

其中 `L` 是梯度 `f` 必须满足的 Lipschitz 系数的上界。与公式 (10.3) 的区别在于，该最小化现在是一个约束最小化。然而，Nesterov 还增加了第二步，涉及另一个辅助变量 `z^(i)`，其计算方式与 `w^(i)` 类似，但用 `Q` 的代理函数替代了平方欧几里得范数，且线性化项现在被加权累积梯度所取代。

```
\sum\limits_{k = 0}^{i - 1}\alpha_{k}\left( \mathbf{\theta} - \mathbf{\theta}^{(k)} \right)^{T}\frac{\partial f\left( \mathbf{\theta}^{(k)} \right)}{\partial\mathbf{\theta}}.
```

![Equation](img/si136.png)

*   该项的作用是平滑通往解的路径的“之字形”摆动，其效果是显著提高收敛速度。该方案的最后一步涉及对先前获得的变量进行平均，

```
\mathbf{\theta}^{(i)} = t[i]\mathbf{z}^{(i)} + (1 - t[i])\mathbf{w}^{(i)}.
```

![Equation](img/si137.png)

*   参数 `α[k]`（`k = 0, …, i − 1`）和 `t[i]` 的值源自理论，从而保证收敛。与其近亲 FISTA 一样，该算法享有 `O(1/i²)` 的收敛速率。在我们的案例中，待最小化的函数 `∥θ∥[1]` 不是光滑的，NESTA 使用了其平滑的近端函数。此外，结果表明可以为 `z^(i)` 和 `w^(i)` 获得闭式更新。如果选择 `X` 使其具有标准正交行，则每次迭代的复杂度为 `O(l)`，加上执行乘积 `X^(T)X` 所需的计算量，后者是计算量最大的部分。然而，如果感知矩阵被选为允许快速矩阵-向量乘积计算的酉变换的子矩阵（例如，欠采样 DFT 矩阵），则该复杂度可以大幅降低。例如，对于欠采样 DFT 矩阵的情况，复杂度相当于 `O(l)` 加上执行两次快速傅里叶变换（FFT）的负载。此外，延续策略也可用于加速收敛。文献 [12] 表明，NESTA 在保持与针对 (9.6) 公式开发的算法具有竞争力的复杂度、且能以可承受的方式扩展到大规模问题的同时，展现出了良好的精度结果。此外，NESTA 以及 Nesterov 方案总体上具有普适性，允许将它们用于其他优化任务。

*   公式 (9.7) 中的任务已在文献 [14] 和 [99] 中进行了探讨。在前者中，算法包含在 `ℓ₁` 球 `∥θ∥₁ ≤ ρ` 上的投影（另见第 10.4.4 节）每一迭代步。该算法计算量最大的部分由矩阵-向量乘积组成。在文献 [99] 中，针对同一任务推导了一种拟合算法，其中界 `ρ` 成为被允许变化的拟合参数。该算法也被称为 LARS-LASSO，这已有报道。

### 10.2.3 选哪个算法？一些实用提示

我们已经讨论了许多算法替代方案，以求得 `ℓ₀` 或 `ℓ₁` 范数最小化任务的解。我们的重点在于计算需求较低且能很好地扩展到超大规模问题的方案。我们未涉及求解 `ℓ₁` 凸优化任务的内点法等开销更大的方法。此类方法的综述见文献 [72]。内点法沿牛顿型递归演进，其每迭代步的复杂度至少为 `𝒪(l³)` 阶。正如通常情况那样，存在权衡。复杂度较高的方案往往能带来性能提升。然而，此类方案在大规模问题中变得不切实际。其他未讨论算法的示例可见文献 [14,35,118,121]。谈到复杂度，必须指出，最终真正重要的是算法收敛到指定精度的解所需的计算机时间/内存等总体资源，而非单步迭代的复杂度。例如，某算法单步迭代复杂度可能很低，但可能需要过多的迭代次数才能收敛。

计算负荷只是表征算法性能的诸多指标之一。迄今为止，全书中我们已考虑了许多其他性能度量，如收敛速率、跟踪速度（针对自适应算法）以及对噪声和/或有限字长计算的鲁棒性。毫无疑问，所有这些性能度量在此也都很有意义。然而，在量化稀促算法性能时，还有一个特别重要的方面。这与*欠采样-稀疏性权衡*或*相变曲线*有关。

我们在第 9 章重点关注的主要问题之一，是推导并给出在欠定观测集 `y = Xθ` 下，保证 `ℓ₀` 最小化唯一性及其与 `ℓ₁` 最小化任务等价的条件，以恢复足够稀疏的信号/向量。在讨论本节各种算法时，我们列举了许多不同的与 RIP 相关的条件，某些算法必须满足这些条件才能恢复目标稀疏向量。事实上，必须承认这相当令人困惑，因为每个算法都有其自身必须满足的条件。此外，在实践中，这些条件不易验证。尽管这些结果对于建立收敛性、增强信心以及帮助我们更好地理解算法为何及如何工作无疑很重要，但仍需进一步的实验证据来为算法建立良好的性能界限。此外，我们所处理的所有条件（包括相干性和 RIP）均为充分条件。实践表明，对于给定的 `N` 和 `l`，稀疏信号恢复可在远高于理论预测的稀疏度水平下实现。因此，在提出新算法或从现有算法库中选择算法时，必须通过实验证明该算法可恢复的稀疏度水平范围，以观测数和维度的百分比表示。因此，为了选择算法，应投给这样一个算法：对于给定的 `l` 和 `N`，它在大多数情况下都有潜力恢复 `k` 稀疏向量，且 `k` 尽可能高，即以*高概率*恢复。
