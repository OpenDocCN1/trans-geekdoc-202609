# 第 10 章：在 ImageNet 上训练 SqueezeNet

在关于在 ImageNet 大规模视觉识别挑战（ILSVRC）上训练深度神经网络的最后一个章节中，我们将讨论可以称是目前为止我最喜欢的深度学习架构——SqueezeNet。它由 Iandola 等人在他们 2016 年的论文《SqueezeNet: AlexNet-level accuracy with 50x fewer parameters and < 0.5MB model size》[30] 中引入。

光是这本书的标题（指论文标题）就应该引起你的兴趣。我们在书中之前讨论的大多数架构中，其模型大小介于 100MB (ResNet) 到 553MB (VGGNet) 之间。AlexNet 的模型权重为 249MB，也处于这个范围的中间。我们最接近“微型”模型大小的是 28MB 的 Googlet——但我们仍然可以做得更小，同时保持最先进的准确率。

正如 MobileNet 的工作所示，答案是肯定的，尽管通过应用 1x1 和 3x3 卷积来减少模型大小，且不使用全连接层。结果是一个权重为 4.9MB 的模型，通过模型压缩进一步缩小到 0.5MB，这也被称为权重剪枝和“模型稀疏化”（将跨层 50% 的最小权重值设为零）。在本章中，我们将关注 SqueezeNet 的原始实现。模型压缩的概念（包括量化）超出了本书的范围，可以在相关的学术出版物 [30] 中找到。

## 10.1 理解 SqueezeNet

在本节中，我们将：

1. 回顾 Fire Module，这是负责减少模型参数并保持高水平精度的关键微架构。
2. 回顾整个 SqueezeNet 架构（即宏观架构）。
3. 使用 mxnet 手动实现 SqueezeNet。

### 10.1.1 Fire Module

Iandola 等人的工作具有两个目的。第一个是为进一步研究设计卷积神经网络提供案例，使其能够在大幅减少参数数量的情况下进行训练（同时获得高水平的精度）。第二个是验证瓶颈+预激活版本的残差模块确实比原始残差模块获得更高的精度。Fire 模块的实现方式非常巧妙，因为它依赖于 1x1 和 3x3 卷积的组合。图 10.1：Fire 模块的可视化。

（注：由于原文文本在某些部分存在大量逻辑重复和乱码字符，上述翻译已根据上下文逻辑进行了清理和整合，以确保技术文档的连贯性。）

在输入馈入网络后，学习了 96 个滤波器，每个滤波器的大小为 `7 x 7`。使用 `2 x 2` 的步长将空间维度从 `227 x 227` 缩小到 `111 x 111`。为了进一步缩小空间维度，应用了池大小为 `3 x 3` 步长 `2 x 2` 的最大池化，得到输出卷为 `55 x 55 x 96`。

接下来，我们有三个滤波器模块。前两个模块应用 16 个压缩滤波器（squeeze filters），将输入卷的大小从 `55 x 55 x 96` 缩小到 `55 x 55 x 16`。然后应用 `64 x 1` 滤波器和 `64 x 3` 滤波器——这 128 个滤波器在通道维度上拼接，输出尺寸为 `55 x 55 x 128`。第三个模块将 `1 x 1` 压缩滤波器的数量增加到 32，使得 `1 x 1` 和 `3 x 3` 扩展滤波器（expand filters）的数量增加到 64。在最大池化操作之前，我们的空间操作结果为 `55 x 55 x 256`。通过池大小为 `3 x 3` 步长为 `2 x 2` 的最大池化层，空间维度缩小到 `27 x 27 x 256`。从那里开始，我们应用四个滤波器模型。第一个模块使用 32 个 `1 x 1` 压缩滤波器和 128 个 `1 x 1` 和 `3 x 3` 滤波器。第二个模块将 `1 x 1` 压缩滤波器的数量增加到 64，`1 x 1` 和 `3 x 3` 扩展滤波器增加到 192，导致输出卷为 `27 x 27 x 384`。最后一个滤波器模块将数量增加到 64，`1 x 1` 和 `3 x 3` 扩展滤波器增加到 256。拼接这些扩展滤波器后，我们的卷大小变为 `27 x 27 x 512`。随后应用另一个最大池化操作缩小空间维度到 `13 x 13 x 256`。

应用最后一个模块，将 `1 x 1` 压缩滤波器增加到 64，`1 x 1` 和 `3 x 3` 扩展滤波器增加到 256。拼接通道维度，我们得到输出卷为 `13 x 13 x 512`。

我们对整个 `13 x 13 x 13` 卷执行全局平均池化（global averaging），将其缩小到 `13 x 13 x 1000`。我们获取这些激活值并通过 softmax 层以获得每个类别 `N` 的输出概率。

如你所示，网络中应用了全连接层。与 GoogleNet 和 ResNet ，使用全局平均池化有助于（通常是完全消除）对全连接层（FC layers）的需求。减少全连接层的好处是减少所需的参数。请记住，全连接层中的所有节点都是密集连接的（当前层的每个节点与后续层的其他节点连接）。然而，卷积层根据定义是稀疏的，需要的内存更少。用卷积和平均池化替换一组全连接层可以大幅减少网络所需的参数。

## 10.13 实现 SqueezeNet

现在我们有了 SqueezeNet 架构，让我们开始实现。创建一个名为 `mxsqueezenet.py` 的新文件，使用 `mxnet.nn.conv` 子模块：

```
mxnet
|   __init__.py
|   nn
|       |__init__.py
|       conv
|       mxconv
|           __init__.py
```

这是我们实现 SqueezeNet的地方。打开 `mxsqueezenet.py` 开始工作：

```python
# 导入必要的包
import mxnet as mx

class MxSqueezeNet:
    @staticmethod
    def squeeze(input, numFilter):
        # FIRE模块的第一部分由若干个1x1
        # 压缩滤波器组成，后跟一个激活函数
        squeeze_xi1 = mx.Convolution(data=input, kernel=(1, 1),
            stride=(1, 1), num_filter=numFilter)
        act_xi1 = mx.LeakyReLU(data=squeeze_xi1,
            act_type="elu")

        # 返回压缩层的激活值
        return act_xi1
```

第4行定义了我们的SqueezeNet类——所有构建和创建SqueezeNet架构都都存在于该类中。第6行定义了`squeeze`方法，它是FIRE模块的一部分。`squeeze`函数需要一个输入（前一个层）以及`numFilter`，即层应学习的 `1 x 1` 滤波器数量（第9和10行）。一旦我们计算出 `1 x 1` 卷积，我们在第11和12行将值通过激活函数。在原始论文中使用了标准的ReLU激活，但这里我们使用EL。如之前对不同架构的实验所示，用EL替换ReLU可以提高分类准确率。我将在第10.4节中证明这一观点。第15行将 `1 x 1` 的返回给调用函数。

现在已经定义了`squeeze`方法，让我们创建该函数：

```python
@staticmethod
def fire(input, numSqueezeFilter, numExpandFilter):
    # 构造1x1压缩，紧接着是1x扩展
    squeeze_xi1 = MxSqueezeNet.squeeze(input, numSqueezeFilter)
    expand_xi1 = mx.Convolution(data=squeeze_xi1,
        kernel=(1, 1), stride=(1, 1), num_filter=numExpandFilter)
    relu_expand_xi1 = mx.LeakyReLU(data=expand_xi1,
        act_type="elu")
```

`fire`方法需要三个参数：

1. `input`: FIRE模块的输入层。
2. `numSqueezeFilter`: 要学习的压缩滤波器数量。
3. `numExpandFilter`: 要学习的扩展滤波器数量。根据论文的实现，我们将对 `1 x 1` 和 `3 x 3` 卷积使用相同数量的扩展滤波器。第20行调用了`squeeze`函数，缩小了输入维度。基于`squeeze_xi1`，我们在第21和22行应用了 `1 x 1` 扩展。我们对 `3 x 3` 扩展执行类似的操作：

```python
# 构造3x3扩展
expand_xi3 = mx.Convolution(data=squeeze_xi1, kernel=(3, 3),
    stride=(1, 1), num_filter=numExpandFilter)
relu_expand_xi3 = mx.LeakyReLU(data=expand_xi3,
    act_type="elu")
```

```python
# FIRE模块的输出是1x1和3x3激活
# 在通道维度上的拼接
output = mx.sym.Concat(relu_expand_xi1, relu_expand_xi3,
    dim=1)
```

```python
# 返回FIRE模块的输出
return output
```

我们由此学习了`numExpandFilter`，每个都是 `3 x 3`，并使用`squeeze_xi1`作为输入。我们使用 `1 x 1` 填充以确保空间维度不会缩小，以便后续在函数中拼接。

## 10.1 理解 SqueezeNet

`build` 方法接受一个参数，即我们想要学习的类别总数。在 ImageNet 的情况下，我们将 `classes` 设置为 1000。

**第 44 行** 实例化了我们的数据变量，即输入网络的输入批次。根据这些数据，我们为 SqueezeNet 中定义了第一个卷积层。该层产生 96 个过滤器，其中 `7 x 7` 的过滤器大小为 `2 x 2`。在通过最大池化缩小空间维度之前，我们应用了 ELU 激活函数（**第 49 行**）。

```

# Block #9-10: FIRE => DROPOUT => CONV => RELU => POOL

kernel=(1, 1), stride=(1, 1))

```

我们的最后一个代码块处理平均池化操作的展平并创建 softmax 输出：
