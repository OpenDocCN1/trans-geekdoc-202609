
## 问答集

- **我已经运行了 SafeBack、FileList 和 FileCnvt，现在必须运行 Filter_I。它会做什么？**
  - 它是一个智能过滤器，会删除二进制数据以及非单词的 ASCII 数据。

- **FilterJ 和 FileList 是否必须在包含位元流备份的相同目录中运行？**
  - 是的，`FilterJ` 和 `FileList` 必须在包含位元流备份的相同目录中运行。

- **如果磁盘高度碎片化，应该使用 GetSlack 和 GetFree，还是使用其他程序更合适？**
  - 应该使用 `GetSlack` 和 `GetFree`。

- **TextSearch Plus 的搜索字符串是否区分大小写？**
  - 不区分大小写。

- **在 Norton Utilities 中，哪个工具主要用于重建碎片文件？**
  - 在 Norton Utilities 中，`Disk Editor` 主要用于重建碎片文件。

- **创建磁盘拷贝的两种工具选择是什么？**
  - 创建磁盘拷贝的两种工具选择是：`DOS DiskCopy`（最佳）和 `AnaDisk`。

- **三种隐藏磁盘数据的方法：**
  - 磁盘内嵌磁盘
  - 在轨道之间写入数据
  - 在图形中隐藏数据

- **你决定查看网络浏览器缓存，你会使用什么工具？**
  - `unmozify`

- **在 UNIX 中，用什么命令将内存写入磁盘、关闭机器并重新启动？**
  - `Shutdown -r`

- **在 UNIX 中，用什么命令可以重新启动机器并使其以单用户模式启动？**
  - `Halt -q`

- **你有一台 UNIX 系统处于单用户模式，且已设置从紧凑盘（CD）启动。此时你应该输入什么命令让 UNIX 系统从 CD 启动？**
  - `Boot`

- **在 UNIX 中，哪个日志记录系统上输入的命令？**
  - `HISTORY`

- **在 UNIX 中，哪些文件记录登录和注销时间？**
  - `WTMP` 和 `BTMP`

- **最少应记录哪十项日志？**
  - 登录、注销、特权变更、账户创建、文件删除、`su` 访问、失败登录、未使用的账户、重启和远程访问。

- **名称两种在 Intel 平台上通常运行的 UNIX 版本。**
  - `BSD` 和 `LINUX`。

- **如果你把 UNIX 磁盘放在 Intel 平台上且无法启动，你的下一步该做什么才能使其启动？**
  - 使用另一张装有相同 UNIX 版本的“裸机”磁盘，并从该磁盘启动。确保将启动磁盘设置为主盘（Primary Master Hard Drive, PMHD）。

- **DOS 使用 autoexec.bat 和 config.sys，那么 UNIX 中类似的启动文件是什么？**
  - `rc` 文件。

- **黑客喜欢在哪些 UNIX 文件中添加陷阱（booby traps）？**
  - `rc` 文件。

- **你已将 UNIX 系统重新启动到单用户模式，首先应该查看哪些文件？**
  - `rc` 文件。

- **Linux 的根包（rootkit）名称是什么？**
  - `Knark`。

- **哪个 UNIX 文件在系统崩溃时保存内存内容？**
  - `Core file`。

- **lastlog 会显示哪两项信息？**
  - 系统上谁在使用以及关键词（如 “crash”）。

- **分析崩溃转储文件时，四大主要 UNIX 命令是什么？**
  - `Ps`、`netstat`、`nfsstat` 和 `arp`。

- **如果你正在进行崩溃转储分析，应该使用什么类型的机器？**
  - 使用相同操作系统版本的机器。

- **对于 RedHat Linux，验证所有重要系统文件完整性的命令是什么？**
  - `rpm -VA`。

- **如果你的上一条命令显示用户 Bragger23 上午登录并在 Solaris5 上当前登录，你想查看 Bragger23 正在内存中运行的所有进程，应该输入什么命令？**
  - `ps -aux | grep Bragger23`。

- **为了从系统中移除 Bragger23 并收集内存证据，你应遵循哪些步骤？**
  1. 移除 Bragger23 的所有进程：
     * `kill -9 1365`

     * `kill -9 1087`
     * `kill -9 3001`
  2. 收集内存证据：
     * `ps -aux > a:\\Solaris5RAMproc.txt`

- **Q: Radius 日志显示什么内容？**
  - **A:** 显示远程系统上谁建立了连接。

- **Q: 列出十个 UNIX 日志文件及其各自的用途。**
  - **A:**
    1. `ACCT` 或 `PACCT`：记录计算机上每位用户输入的所有命令，并标注命令的日期/时间。
    2. `ACULOG`：记录拨号调制解调器使用情况。
    3. `LASTLOG`：记录每位用户的最近一次登录（或失败登录）。
    4. `LOGINLOG`：记录失败的登录尝试。
    5. `MESSAGES` 或 `SYSLOG`：主系统日志，包含大量消息，可配置为存放防火墙和路由器日志。
    6. `SULOG`：记录所有以 root 进行登录的尝试。
    7. `UTMP` 和 `UTMPX`：记录当前登录到计算机的所有用户，`who` 命令访问该文件。
    8. `WTMP` 和 `WTMPX`：记录过去和当前的所有登录，包括系统启动和关闭，`last` 命令访问该文件。
    9. `VOLD.LOG`：记录访问外部介质（CD‑ROM、软盘等）时出现的错误。
    10. `XFERLOG`：记录通过 FTP 从计算机传输的所有文件。

    ```
    QUIT
    ```
