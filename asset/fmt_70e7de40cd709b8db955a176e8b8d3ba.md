
## 13.3 线性回归的变分贝叶斯方法

让我们再次考虑熟悉的回归任务

```
$q_{\mathbf{\theta}}^{(j + 1)}(\mathbf{\theta}) \propto {(g(\mathbf{\theta}))}^{\lambda + N}\exp\left( \mathbf{\phi}^{T}(\mathbf{\theta})\left( \mathbf{v} + \sum\limits_{n = 1}^{N}\mathbb{E}_{q_{\mathbf{x}_{n}^{l}}^{(j + 1)}}\left\lbrack \mathbf{u}(\mathbf{x}_{n},\mathbf{x}_{n}^{l}) \right\rbrack \right) \right).$
```

![Equation](img/si64.png)(13.20)

因此，后验 $p(\mathbf{\theta}|\mathcal{X})$ 的近似 $q_{\mathbf{\theta}}^{(j + 1)}(\mathbf{\theta})$ 与共轭先验具有相同的形式，其中

```
$\widetilde{\lambda} = \lambda + N,\quad\widetilde{v} = v + \sum\limits_{n = 1}^{N}\mathbb{E}_{q_{\mathbf{x}_{n}^{l}}^{(j + 1)}}\ \left\lbrack \mathbf{u}(\mathbf{x}_{n},\mathbf{x}_{n}^{l}) \right\rbrack.$
```

![Equation](img/si67.png)(13.21)

请注意，公式 (13.21) 的形式与 (12.77) 中的相同。我们只需要对隐变量进行平均。这是一个非常优雅的结果，因为我们并未对 $q_{\mathbf{\theta}}$ 的函数形式做任何假设。换句话说，一旦我们采用指数族形式作为完整变量集的概率密度函数（PDF）以及参数先验的函数形式，后续的迭代就变成了“自家人的事务”。

**y** = *Φ***θ** + **η**, **y** ∈ ℝ^(*N*), **θ** ∈ ℝ^(*K*)。

![Equation](img/si68.png)

在第 12.5 节中，我们处理了 **η** 为高斯分布且先验 *p*(**θ**) 也是高斯分布的情况。我们使用 EM 算法来优化证据 *p*(**y**)，以求解定义这两个采用的高斯 PDF 的超参数；请注意，对于这种情况，人们可以绕过 EM 算法，转而采用解析计算来获得证据，随后使用优化技术来估计未知的超参数。

在本节中，我们将采用一些假设，这些假设不允许对后验 *p*(**θ**|**y**) 进行易处理的解析计算，而后验是标准 EM 算法和证据 *p*(**y**) 的解析计算的先决条件。这种方法绝非教学玩具，而是具有浓厚的实践色彩。我们将详细展开这项任务，建议读者仔细研读这些推导，因为一旦选择变分贝叶斯方法来处理任务，在实践中遇到的情况通常都与此类似。

假设

*p*(**y**|**θ**, *β*) = 𝒩(*Φ***θ**, *β*^(−1)*I*)。

![Equation](img/si72.png)(13.22)

也就是说，噪声服从高斯分布，为简单起见，我们将其视为白噪声，*Σ*[*η*] = *σ*[*η*]²*I*，且 $\beta = \frac{1}{\sigma_{\eta}^{2}}$。与第 12.5 节所做的相反，现在我们将更加“民主”，赋予每个参数分量 *θ*[*k*] 拥有不同方差 $\sigma_{k}^{2} := \frac{1}{\alpha_{k}},\ k = 0,1,\ldots,K - 1$ 的自由度。此外，我们更进一步。*β* 和 *α*[*k*] (*k* = 0, …, *K* − 1) 的值将不被视为确定性变量。我们也将它们视为随机变量 (*β*, *α*[*k*])，并为它们分配先验 PDF；这些先验 PDF 又由另一组超参数控制。更具体地说，除了公式 (13.22) 之外，我们的模型还包含 [8]

$p(\mathbf{\theta}|\mathbf{\alpha}) = \prod\limits_{k = 0}^{K - 1}\mathcal{N}(\theta_{k}|0,\alpha_{k}^{- 1})$

![Equation](img/si79.png)(13.23)

$p(\mathbf{\alpha}) = \prod\limits_{k = 0}^{K - 1}{\text{Gamma}}(\alpha_{k}|a,b)$

![Equation](img/si80.png)(13.24)

和

$p(\beta) = \text{Gamma}(\beta|c, d)$

![Equation](img/si81.png)(13.25)

请注意，先验的上述选择表明了我们想要在指数族分布的框架内“玩”这个游戏的意愿。先验 $p(\mathbf{\alpha})$ 是公式 (13.23) 的共轭先验（参见第 12 章）。此外，如果我们将 $\mathbf{\theta}$ 视为固定，公式 (13.25) 将是公式 (13.22) 的共轭先验。图 13.2 提供了我们模型中涉及的各个变量之间依赖关系的图形化表示。箭头表示条件依赖。图形模型将在第 15 章中以正式方式进行探讨。请注意，这种模型在所涉及参数之间的依赖关系中形成了各个层级的*层次结构*。

![Figure 13.2 A graphical illustration of the dependencies among the various variables involved in the model of linear regression. The red circle indicates the random variable that is observed, gray circles indicate hidden random variables, and squares correspond to deterministic parameters. The direction of each arrow indicates the direction of the dependence between the connected variables. The red box indicates that the above dependencies hold for all N time instants.](img/gr002.jpg)

图 13.2 线性回归模型中涉及的各个变量之间依赖关系的图形化说明。红圈表示被观测的随机变量，灰圈表示隐藏随机变量，方框对应确定性参数。每个箭头的方向表示相连变量之间依赖关系的方向。红框表示上述依赖关系对所有 $N$ 个时刻均成立。

这种层次结构的概念正是我们所谓的*分层贝叶斯建模*的核心。每个涉及的概率密度函数（PDF）都用特定的（超）参数来表示。由于这些参数的值未知，它们也被视为随机变量，其先验用一组新的超参数来表示。它们每一个又依次被视为一个随机变量，并关联一个新的先验，称为*超先验*。这种基本原理可以扩展以构建不同层级的层次结构。通常，在层次结构的最高层，相应的（未知）超参数由用户根据经验赋值；例如，整体模型对其具体值可能相对不敏感，这使得相应的选择成为一项相当容易的工作。

我们当前的任务包含以 $\mathbf{\theta}$、$\mathbf{\alpha}$ 和 $\beta$ 形式分组的参数类隐变量，且不涉及其他未观测变量。观测集现在由 $\mathbf{y}$ 给出。此外，请注意后验 $p(\mathbf{\theta}, \mathbf{\alpha}, \beta|\mathbf{y})$ 在解析上是不可处理的。我们将求助于变分贝叶斯 EM 算法来获得上述后验 PDF 的估计。

使用均场近似，我们假设后验的近似（为了符号方便，已省略对 $\mathbf{y}$ 的依赖）分解为

$q(\mathbf{\theta}, \mathbf{\alpha}, \beta) = q_{\mathbf{\theta}}(\mathbf{\theta})q_{\mathbf{\alpha}}(\mathbf{\alpha})q_{\beta}(\beta)$
