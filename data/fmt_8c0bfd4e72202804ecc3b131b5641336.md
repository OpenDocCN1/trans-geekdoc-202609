
在普通状态空间搜索中，我们只能问：这个特定状态是否为目标？若不是，再看下一个状态。而 CSP 则在发现部分赋值不满足约束后，可以立即丢弃对该部分赋值的进一步细化。我们还能立刻看到是哪些变量违背了约束，从而集中注意力于关键变量。因此，许多对普通状态空间搜索不可行的问题，在以 CSP 形式化后可以快速求解。

### 6.2 约束传播：CSP 中的推理

在常规状态空间搜索中，算法只能做一件事：进行搜索。在 CSP 中，算法有选择：可以搜索（从多个可能的赋值中选择新的变量赋值），或者执行一种特定的 `推理`，即 `约束传播`：利用约束减少变量的合法取值数量，进而进一步减少其他变量的合法取值，以此类推。约束传播可以与搜索相互交织，也可以在搜索开始前作为预处理步骤。有时这种预处理本身就能解决整个问题，从而无需进行任何搜索。

关键思想是 `局部一致性`。如果我们把每个变量视为图中的节点（参见 Figure 6.1(b)），把每个二元约束视为弧，那么在图的各个部分强制执行局部一致性会导致不一致的取值在整个图中被消除。局部一致性有多种类型，我们逐一介绍。

#### 6.2.1 节点一致性

一个变量（对应 CSP 网络中的节点）是 `节点一致`，当该变量的所有取值都满足该变量的单元约束时。例如，在变体的澳大利亚地图涂色问题（Figure 6.1）中，南澳大利亚州（SA）不喜欢绿色，其变量 `SA` 的初始域为 `{red, green, blue}`。通过消除绿色，使 `SA` 成为节点一致，剩余域为 `{red, blue}`。当网络中每个变量都满足节点一致性时，我们说该网络是节点一致的。

总是可以通过执行节点一致性消除 CSP 中所有的单元约束。同时，也可以将所有 n 元约束转换为二元约束（参见 Exercise 6.6）。因此，通常定义的 CSP 求解器只处理二元约束；我们在本章其余部分均基于此假设，除非另有说明。

#### 6.2.2 弧一致性

变量在 CSP 中是 `弧一致`，当该变量的所有取值都满足该变量的二元约束时。形式上，若 `X[i]` 相对于另一个变量 `X[j]` 为弧一致，则对于 `X[i]` 当前域 `D[i]` 中的每一个取值，都存在 `D[j]` 中的某个取值能够满足弧 `(X[i], X[j])` 上的二元约束。若网络中每个变量都与其他所有变量满足弧一致性，则该网络为弧一致。例如，考虑约束 `Y = X²`，且 `X`、`Y` 的域均为数字集合。我们可以把该约束明确写为

最流行的弧一致性算法是 AC-3（参见 Figure 6.3）。为了使每个变量都弧一致，AC-3 算法维护一个弧的队列（实际上，弧的考虑顺序并不重要，数据结构本质上是集合，但传统上称之为队列）。初始时，队列中包含 CSP 中的所有弧。AC-3 然后从队列中弹出任意一个弧 `(X[i], X[j])`，并使 `X[i]` 相对于 `X[j]` 成为弧一致。如果这并未改变 `D[i]`，算法直接进入下一个弧。但如果这使 `D[i]` 缩小（即域变小），则需要把所有与 `X[i]` 相邻的弧 `(X[k], X[i])` 加入队列，其中 `X[k]` 是 `X[i]` 的邻居。我们这样做是因为 `D[i]` 的变化可能进一步使 `D[k]` 的域被缩小，即使我们之前已经处理过 `X[k]`。如果 `D[i]` 缩小至空，则说明整个 CSP 没有满足的解，AC-3 可直接返回失败。否则，我们继续检查，尝试从变量的域中删除值，直到队列为空。此时，我们得到的 CSP 与原始 CSP 具有相同的解集——它们都具有相同的解——但弧一致的 CSP 通常域更小，搜索更快。

AC-3 的时间复杂度分析如下。假设有 `n` 个变量，每个变量的域大小至多为 `d`，且有 `c` 个二元约束（弧）。每个弧 `(X[k], X[i])` 最多只能加入队列 `d` 次，因为 `X[i]` 最多只能删除 `d` 个值。检查弧一致性的时间为 `O(d²)`，因此总体最坏情况时间为 `O(c d³)`。

可以将弧一致性的概念扩展到处理 n 元而非仅二元约束的情况；这称为 **广义弧一致性** 或有时称为 **超弧一致性**，取决于作者。若变量 `X[i]` 相对于一个 n 元约束为 **广义弧一致**，则对于 `X[i]` 的每一个取值 `v`，都存在一个满足约束的元组，该元组的所有值都取自对应变量的域，并且该元组的 `X[i]` 位置等于 `v`。例如，若所有变量的域为 `{0, 1, 2, 3}`，则要使变量 `X` 与约束 `X < Y < Z` 保持广义弧一致，需要从 `X` 的域中删除 2 和 3，因为当 `X` 为 2 或 3 时，该约束无法满足。

#### 6.2.3 路径一致性

Arc consistency 可以大幅降低变量的取值域，有时能够找到解（通过将每个变量的取值域缩小到大小为 1），有时则能够发现问题无解（通过将某个取值域缩小到大小为 0）。但对于其他网络，弧一致性无法做出足够的推理。考虑在澳大利亚进行的地图涂色问题，但只允许两种颜色：红色和蓝色。弧一致性在这种情况下无能为力，因为每个变量已经是弧一致的：每个变量都可以与其相邻变量的颜色相同（或相反）。然而，显然该问题没有解：因为西澳大利亚、北领地和南澳大利亚相互相邻，它们单独就需要至少三种颜色。

弧一致性通过使用弧（二元约束）来收紧一元约束（单元约束）的取值域。为了在诸如地图涂色等问题上取得进展，我们需要一种更强的概念——**路径一致性**。路径一致性通过隐式约束来收紧二元约束，这些约束是通过观察变量的三元组来推导的。

#### 路径一致性

若集合 `{X[i], X[j]}` 相对于第三个变量 `X[m]` 具有路径一致性，则对于集合 `{X[i] = a, X[j] = b}` 的每个与 `{X[i], X[j]}` 约束相容的赋值，都存在一个对 `X[m]` 的赋值，使得 `{X[i], X[m]}` 与 `{X[m], X[j]}` 都满足约束。路径一致性之所以得名，是因为可以把它看作是从 `X[i]` 到 `X[j]` 的路径，其中 `X[m]` 位于中间。

我们来看看路径一致性在仅用两种颜色涂色澳大利亚地图时的表现。我们将集合 `{WA, SA}` 与 `NT` 建立路径一致性。首先枚举该集合的所有满足约束的赋值，只有两种：`{WA = red, SA = blue}` 和 `{WA = blue, SA = red}`。可以看出，在这两种赋值下，`NT` 既不能取 `red` 也不能取 `blue`（因为这会与 `WA` 或 `SA` 冲突）。由于没有合法的 `NT` 取值，我们消除这两种赋值，最终得到 `{WA, SA}` 没有合法赋值。因此，我们可以断定该问题无解。PC-2 算法（Mackworth，1977）实现路径一致性的方式与 AC-3 实现弧一致性的方式非常相似，因此这里不再展开。

#### 6.2.4 K‑consistency
