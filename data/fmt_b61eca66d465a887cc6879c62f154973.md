
```matlab
for l = 1:L-1
    ...
    D = rand(size(A)(1), size(A)(2));
    D = (D < keep_prob);
    # 将部分隐藏单元置零
    A = A .* D;
    # 除以 keep_prob 以保持 A 的期望值不变
    A = A ./ keep_prob;
    # 将 D 存储在 dropoutMat 元胞数组中
    dropoutMat{l} = D;
    ...
endfor
```

在反向传播周期中，我们有：

```matlab
for l = (L-1):-1:1
    ...
    D = dropoutMat{l};
    # 根据相同的 dropout 矩阵将 dAl 置零
    dAl = dAl .* D;
    # 除以 keep_prob 以维持期望值
    dAl = dAl ./ keep_prob;
    ...
endfor
```
