### 作者简介

**Roselyn Teukolsky** 拥有康奈尔大学理学硕士学位，自 1980 年起一直教授编程和计算机科学。她曾在《数学教师》和《全国数学教师理事会年鉴》上发表文章，并著有 Barron’s *ACT Math and Science Workbook*，合著 Barron’s *SAT 1600: Aiming for the Perfect Score*。她获得的奖项包括 Edyth May Sliffe 杰出数学教学奖和纽约州数学联盟 (NYSML) 颁发的 Alfred Kalfus 杰出教练奖。多年来，Teukolsky 女士曾担任 AP 计算机科学阅卷员。

Teukolsky 女士开始教授 AP 计算机科学时，考试使用的编程语言是 Pascal，那是考试采用的第一种语言。到她撰写本书时（1997 年），软件开发正向面向对象编程转变，AP 考试的语言已切换为 C++。2004 年，考试语言再次变更，改为 Java。20 多年来，Teukolsky 女士始终让本书——无论其以何种形式呈现——保持最新状态。

### 诊断测试

本书开头的全真模拟测试可作为诊断测试使用。它附带一份诊断图表，标明了每道选择题对应的考点，以及复习章节中讨论该考点的页码。所有选择题均提供详细的答案解析，所有简答题均提供完整的解答和评分标准。完成复习后，你也可以将此测试作为一次模拟考练习。

#### 复习与练习

第 1 章介绍了应对考试中选择题和简答题的技巧与建议。

第 2 章至第 9 章各章均包含某一主题的综合复习、测试你对该主题理解程度的选择题练习，以及所有题目的详细答案解析。这些题目旨在帮助你复习考试当天应掌握的 Java 子集相关部分。少数题目并非典型的 AP 考试题目——例如，测试语法底层细节的题目。然而，这些练习题中的大多数，以及诊断测试和模拟测试中的所有选择题，都具有代表性，能反映真实的考题风格。请注意，这些练习题中的几组题目前面都附有一段共同的代码供题目引用。需知晓的是，AP 考试通常会将每个代码示例对应的题目数量限制在两道以内。

在线另有三套完整的模拟测试。你可以选择练习（不计时）模式或计时模式进行测试。所有选择题均附有详细的答案解析，自由回答题均提供完整解答和评分标准。

#### 致学生

本书旨在帮助你备考 AP 计算机科学 A 考试。通常在完成 AP 课程后使用。不过，既然它包含了所有考试主题的完整总结，你也可以在整个学年配合合适的教材用于自学。你还可以将本书作为以 Java 为编程语言的大学第一学期课程的补充教材。

考前，请研读第 1 章中的技巧，并尽可能多地尝试模拟测试。务必查看书末的附录，其中提供了考试中偶尔会出现的实用计算机术语词汇表。最后一个建议：先自己做题，再看答案。祝你考试顺利！

### 导言

*计算机科学：应对大量琐碎细节的枯燥艺术。*

*—Stan Kelly-Bootle，《魔鬼的 DP 词典》（1981）*

AP 计算机科学 A 考试是一场为期三小时的笔试。**不允许携带书籍、计算器或计算机！** 考试包含两个权重相等的部分：

- 第一部分：40 道选择题，1 小时 30 分钟
- 第二部分：4 道自由回答题，1 小时 30 分钟

第一部分由机器评分——你将用铅笔在答题卡上填涂答案。每道答对的题得 1 分。答错不扣分，不答的题不计分。

选择题部分答错不扣分。

第二部分由人工评分——你将在提供的答题册上书写答案。自由回答题通常涉及编写 Java 方法来解决给定问题。有时会有分析算法或设计和修改数据结构的问题。你可能被要求编写或设计一个完整的类。为确保评分一致，每位阅卷人遵循相同的评分标准，你的四道答案每道可能由不止一位阅卷人审阅。每题满分 9 分，适用时给予部分分。你的姓名和学校对阅卷人隐藏。

你两个部分的原始分将被转换为 1 到 5 的整数分数，其中 1 代表“完全不合格”，5 代表“极其合格”。请注意，各大学授予 AP 学分的政策差异巨大。考试大致涵盖大学一学期入门课程的内容。

AP 考试使用的语言是 Java。考试只会测试 Java 语言的一个子集。不过，在编写自由回答题的解答时，你可以使用任何 Java 特性，包括那些不在 AP 子集中的特性。有关此子集的完整说明，请访问 College Board 网站。除非另有明确说明，否则本书中的每个语言主题都是 AP Java 子集的一部分。请注意，整个子集都在本书中涵盖了。

对于考试的选择题和自由回答题部分，附录中都会提供一份快速参考。你可以通过查阅 College Board 网站上的 "AP Computer Science A Java Quick Reference" 文档提前查看该参考。
