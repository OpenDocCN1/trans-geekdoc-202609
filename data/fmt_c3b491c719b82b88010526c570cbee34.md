
# 模型拟合评估指标

## 回归模型指标

### RMSE（均方根误差）

`RMSE` 是依赖尺度的，可以比较具有相同目标变量且相同尺度的模型之间的预测误差。它通过使用平均分消除了样本量的影响，并使用平方值的影响而非实际差异的影响。需要注意的是，`RMSE` 是依赖尺度的，并不能告诉我们准确性，因为它们不是以百分比表示。例如，我们有两个模型，一个的 `RMSE` 为 0.12，另一个的 `RMSE` 为 0.36。在这种情况下，我们可以得出第一个模型的拟合效果更好的结论，因为它的 `RMSE` 较低。然而，我们无法就准确性的角度得出该模型的拟合结论，因为 `RMSE` 很难解释。

### MAPE（平均绝对百分比误差）

在这种背景下，平均绝对百分比误差 (`MAPE`) 是一个更好的指标，因为它代表了百分比误差。换句话说，`MAPE` 是独立于尺度的，并告诉我们百分比误差。`MAPE` 越低，预测准确性越高。它还通过使用平均值和绝对值的影响消除了样本量的影响。`MAPE` 没有标准的截断值。但我的经验法是，`MAPE` 为 0.05 或低意味着模型拟合极佳，`MAPE` 为 0.1 或低意味着拟合良好。

### RSE（相对平方误差）与 EP（解释力）

除了 `MAPE` 之外，相对平方误差 (`RSE`) 是另一个以百分比表示的独立尺度指标。如公式所示，`RSE` 是 `SSE` 除以 `SST`，表示模型中未解释方差的比例。`RSE` 允许我们计算解释力 (`EP`)。`EP` 是 `SSR` 除以 `SST`，表示模型中已解释方差的比例。`EP` 是 1 减去 `RSE`。`EP` 是一个重要指标，因为它代表了模型根据预测变量的方差解释目标变量方差的程度。简单来说，它展示了模型能多好地解释方差。`EP` 为 92% 模型解释方差的比例，这可以来评估模型拟合效果。

![](img/ufig6_16.jpg)

再次提到 `RSE` 和 `EP` 是可以用来评估模型拟合的。我的经验法是 `EP` 为 90% 或更高意味着模型拟合极佳，`EP` 在 70% 到 90% 之间意味着拟合良好。在大多数情况下，`EP` 为 50% 到 70% 是可以接受的。表 6.4 展示了我的推荐模型拟合指标。

| 指标 | 描述 | 推荐截断值 |
| --- | --- | --- |
| `RMSE` | 依赖尺度，数据集中预测值与实际值之间平均误差的衡量 | 无；取决于数据 |
| `MAPE` | 独立尺度，数据集中预测值与实际值之间百分比误差的衡量 | `MAPE` = 0.05 或更低：极佳；`MAPE` = 0.05–0.1：良好；`MAPE` = 0.1–0.15：可以 |
| `RSE` | 独立尺度，与始终预测实际值的简单基准模型相比，模型预测的相对改进衡量 | `RSE` = 0.1 或更低：极佳；`RSE` = 0.1–0.3：良好；`RSE` = 0.3–0.5：可以 |
| `EP` | 独立尺度，模型捕捉输入变量与目标变量之间底层关系的程度衡量 | `EP` = 90% 或更高：极佳；`EP` = 70%–90%：良好；`EP` = 50%–70%：可以 |

## 分类模型指标

通常，在大多数数据挖掘项目中，我们倾向于预测一个事件和一个非事件。在这种情况下，我们通常有一个二分类目标变量，其取值为 `1`（事件）或 `0`（非事件）。我们将事件（`1`）视为正例，将非事件（`0`）视为负例。例如，我们想要预测航班取消的风险，因此 `1` 表示 `cancellation`，`0` 表示 `no cancellation`。在这种情况下，取消的案例是正样本，未取消的案例是负样本。有几个基于混淆矩阵计算的模型拟合指标。最常见的指标包括误分类率、预测准确率、灵敏度、特异性和 `F-1 score`。以下是基于混淆矩阵计算这些指标的公式。

### 表 6.7 模型拟合指标及描述

| 模型拟合指标 | 描述 |
| --- | --- |
| 误分类率 (MR) | 模型误分类目标变量（包括实际正例和实际负例）的频率 |
| 预测准确率 (ACC) | 模型预测目标变量（包括实际正例和实际负例）的准确程度；`ACC = 1 - MR` |
| 灵敏度、召回率或真正例率 (TPR) | 正结果（事件）出现的概率，或模型预测真正例（事件）的能力 |
| 特异性、选择性或真负例率 (TNR) | 负结果（非事件）出现的概率，或模型预测真负例（非事件）的能力 |
| F1 score | 另一种准确率指标；它是灵敏度（召回率）和精确率（正例预测值）的调和平均数；高 F1 分意味着低假阳性（FP）和低假阴性（FN） |

```
$$Misclassification~rate~\left( MR \right) = \frac{FP + FN}{Total} = \frac{FP + FN}{TP + TN + FP + FN}$$

$$Accuracy~\left( {ACC} \right) = \frac{TP + TN}{Total} = \frac{TP + TN}{TP + TN + FP + FN} = 1 - MR$$

$$Sensitivity,~Recall,~or~True~positive~rate~\left( TPR \right) = \frac{TP}{TP + FN}$$

$$Specificity,~Selectivity,~or~True~negative~rate~\left( TNR \right) = \frac{TN}{TN + FP}$$

$$F1~score = \frac{2TP}{2TP + FP + FN}$$
```

![](img/ufig6_20.jpg)

检查多个指标而非只看一个指标至关重要。这是因为虽然准确率（`ACC`）向我们展示了整体准确性，但它并没有告诉我们假阴性（`FN`）或假阳性（`FP`）是否存在任何问题。例如，我们的准确率为 90%，意味着误分类率为 10%。乍一看，我们似乎有一个很好的预测模型，因为模型在 90% 的情况下都能准确预测目标变量。然而，如果我们观察其他指标并发现灵敏度（召回率）仅为 50%，那么我们需要进一步调查。灵敏度也被称为真正例率，它告诉我们模型预测正例（事件）的能力如何。低灵敏度意味着我们有高假阴性。那么，为什么我们的整体预测准确率仍然很高？正如我们在第 3 章中所讨论的，主要原因之一是我们可能拥有不平衡的数据集。

## 提升图

![](img/ufig6_22.jpg)

提升图（Lift chart）是另一种评估分类模型性能的常用指标。提升率（Lift）衡量预测模型有效性的指标，计算方法为使用预测模型和不使用预测模型获得的结果之比。提升图（或提升曲线）展示了提升率值与响应率之间的图形化表示。在给定的响应率下，提升值越高的模型性能越好。

基本上，X 轴显示百分比，Y 轴显示提升率值。基本上，对于任何给定的案例数量（X 值），提升值代表了我们预期预测出的正样本数量。请记住，基准线（无模型）是一条与 Y 轴在 `1` 处相交的水平线。例如，如果我们在没有任何预测模型的情况下选择 10% 的数据，我们默认预期可以预测出 10% 的正样本；即我们没有任何模型，只是简单地随机选择案例。这就是我们所说的没有提升（或 `Lift = 1`）。

提升图向我们展示，在选定案例的情况下，通过构建预测模型，我们能够预测出更多的正样本，这表明了模型的有效性。图 6.11 展示了提升图的一个示例。该图表表明，如果我们使用预测模型选择 20% 的案例，我们应该能够预测出 2.5 (20%) 或 50% 的正样本，因为提升值为 `2.5`。这意味着这是不使用模型时的 2.5 倍。提升值越高，模型越好。再次，我们需要将此提升图与其他模型进行比较，以决定哪种模型更好。

## 基尼系数

![](img/ufig6_23.jpg)

基尼系数是一种用于衡量模型判别能力的指标，即模型在区分正样本和负样本方面的有效性。在机器学习背景下，基尼系数用于衡量特征的各个属性之间正样本率的均衡程度。它的范围从 `0` 到 `1`。基尼系数越高，模型越好。从本质上说，基尼系数表示我们的模型离完美模型有多近，以及离随机模型有多远。

计算基尼系数的方法有多种，但常用方法是使用 ROC 曲线下的面积（`AUROC`）。大多数软件都提供 AUROC 值。一旦我们找到了 ROC 图的 AUROC 值，就可以按照如下方式计算基尼系数，也称为 Somers' D Gini。Somers' D 以 Robert H. Somers 的名字命名，他在 1962 提出了这一指标。

`Gini = 2 * AUROC - 1`

![](img/ufig6_24.jpg)

基尼系数没有标准的截断值，但根据经验法则，基尼系数达到 `0.6` 或以上即可被认为是模型拟合良好。

## 成本敏感学习 (CSL)

![](img/ufig6_25.jpg)

正如第 3 章 所示，CSL 是一种流行的方法，允许我们根据误分类的成本来评估和选择模型。它是增强不平衡数据集中预测模型性能的有效方法。本质上，当我们做出业务决策时，仅凭误分类率可能不是选择预测模型的最佳方法。必须考虑误分类的成本，因为在业务世界中，通常假阴性（false negatives）和假阳性（false positives）的成本是不等的。

让我们来看信用卡欺诈交易预测建模的示例。准确分类的成本为 `0`。误分类的成本必须被考虑，因为在业务世界中，通常假阴性的成本和假阳性的成本是不等的。

## 类别（多分类）目标变量

在大多数数据挖掘项目中，我们处理的是二分类目标变量，因为我们通常旨在预测事件与非事件的发生。在某些情况下，我们拥有具有多个级别的分类目标变量。它们也被称为多分类目标变量。

那么，在这种情况下我们如何衡量模型拟合度呢？本质上，我们使用与描述二分类目标变量相同的指标并进行一些修改。最显著的区别是，多分类目标变量的混淆矩阵级别更多，因此更加复杂。表 6.12 显示了具有三个级别（1、2 和 3）的目标变量的混淆矩阵。例如，我们想要预测疫情期间居民的购物行为。他们有三个选择：1 – 线上购物；2 – 路边自提；3 – 店内购物。混淆矩阵包含了所有三个级别的实际值和预测值。挑战在于我们如何计算模型拟合度指标，这些指标需要 `TP`、`TN`、`FP` 和 `FN`。对于三类目标变量，我们需要找到一种计算这些值的方法。

### 表 6.12 三分类目标变量的混淆矩阵

| | 预测 1 | 预测 2 | 预测 3 |
| --- | --- | --- | --- |
| 实际 1 | a | l | m |
| 实际 2 | x | b | n |
| 实际 3 | y | z | c |

我在下方解释了一种用于为多分类目标变量计算 `TP`、`TN`、`FP` 和 `FN` 的方法。基本上，我们需要对这三个类分别进行计算。对于每一类，我们将该类视为正类，将另外两个类视为负类。以下公式允许我们计算每一类的这些值。

#### 对于类别 1

* `TP = a`
* `TN = b + c + n + z`
* `FP = x + y`
* `FN = l + m`

#### 对于类别 2

* `TP = b`
* `TN = a + c + m + y`
* `FP = l + z`
* `FN = x + n`

#### 对于类别 3

* `TP = c`
* `TN = a + b + l + x`
* `FP = m + n`
* `FN = y + z`

一旦我们计算了每一类的 `TP`、`TN`、`FP` 和 `FN`，就可以使用与针对二分类目标变量相同的公式来计算模型拟合度指标。注意，当我们计算模型拟合度指标时，必须对每一类分别计算。这与二分类目标变量的情况不同，后者只需要计算一次。例如，在这个例子中，我们需要为所有三个类别计算以下指标。

##### 类别 1：

* `MR (Class 1)`
* `ACC (Class 1)`
* `TPR (Class 1)`
* `TNR (Class 1)`
* `F1 score (Class 1)`

##### 类别 2：

* `MR (Class 2)`
* `ACC (Class 2)`
* `TPR (Class 2)`
* `TNR (Class 2)`
* `F1 score (Class 2)`

##### 类别 3：

* `MR (Class 3)`
* `ACC (Class 3)`
* `TPR (Class 3)`
* `TNR (Class 3)`
* `F1 score (Class 3)`

* `AUROC`（曲线下面积）
* `Lift` 图
