
你必须让一切围绕目的、复制和复用。这将成为为你的组织赢回价值的核心。出去使用 API 是快速赢回价值的好方法，因为如果你去使用 `AWS` 企业搜索、`GCP Vision API` 或 `AWS` 转录服务，所有的训练、所有的模型构建；所有的艰苦工作都由托管和运营这些 API 的人完成了。所以那笔前期投资已经花出去了，但不是由你或你的组织花的。所以你可以直接切入将其注入工作流的节点，并能快速做一些有趣且有用的事情。

从预算行项到真正投入运营，你必须基于潜在 ROI 以统一的方式应用你的机器学习战略。做完这件事后，你就会知道你是出于正确的理由选择了正确的路径。然后你可以开始考虑在尽可能多的应用中复制结果和流程。迁移学习无论是在模型还是部署层面都在此发挥作用，你将很快了解到，一旦你弄清了如何以质量和速度去做，将其应用到一套事物上会变得快得多。这就是你的团队齐心协力、能够交付成果的力量。

是的，我一直回到这一点。我始终围绕着战略。因此，你的机器学习战略必须处于你试图传达内容的最前沿。你希望它是可定义且可重复的；你希望能够分享这一愿景。你希望你的电梯演讲是自上而下的。人们必须知道这正在发生。这必须成为组织知晓正在发生之事的一部分。这非常有力，因为当你思考在何处以及何时使用机器学习时，你将从那些懂得如何在实践中思考案例的人那里获得最佳的自下而上工作。每个人都可以思考何时可能发生什么，人们可以带来他们所有关于机器学习用例的主题专家想法，并将其与你的机器学习战略相匹配。当这两者结合在一起时，那就是为你的组织创造成功的地方。

现在，这种成功不仅源于构思阶段。它源于周密规划并以成功的方式将其运营化。它部分源于你的 ROI 模型。这需要持续监控，以便你确切了解发生了什么，这样你就能知道，从季度到季度，从月度到月度，这项工作是否成功？这个模型是否有效？是否需要调优？你是否需要对其做些什么？

与此同时，你可能会进入一个领域，不得不在合成数据与其他数据战略之间做决定。现在，如果你正在构建机器学习模型，并且确切知道该做什么，而且在整个过程中对数据的样子有很好的了解，并且能够构建出类似真实数据的合成数据，这很可能意味着你确切了解正在发生什么。你可能处于一个有利位置，构建一些合成数据并拥有更多数据可用于训练和其他事情，这对你可能很有效。否则，你可能不得不研究其他数据战略以变得更复杂一些，但我认为能够创建合成数据绝对是你应该考虑的事情。这值得进一步考量。

所以你需要确保拥有可重复的框架，它们是明确 MLOps 计划的关键。一旦你进入这个构建流水线并将机器学习运营化的过程，你会发现以可定义和可重复的方式去做是成功的关键。

但是，如果你没有合适的团队，这行不通。你可能不得不寻找供应商；你可能不得不建立内部团队。你可能不得不采取一些措施来把事情做对。但我要告诉你，如果你有战略和构思在进行，却没有团队来执行，可能是时候踩刹车、多思考一会儿、深入挖掘，弄清楚能引入谁来使其成功。

话虽如此……花时间真正从整体上思考机器学习，是解决这一主题棘手问题的难点所在。

## 1. 人才从何而来？

就我个人而言，我认为你可以从组织内部培养人才。领域知识与对机器学习的深度理解相结合，将是一项团队工作。不太可能由单个人成为这方面的单点故障。在我的职业生涯中，我有帮助内部人才成长的良好记录。作为一名专业人士，我最自豪的成就之一就是看到某人获得晋升。话虽如此，现在是时候出去开始构建你现有人员的工具箱了。真正花时间投资于人们作为团队成员和个人贡献者的成长与发展。

我们正处于学习机器学习的黄金时代。现在网上存在的培训资源多到你无法全部消化。它们以各种不同的形式存在。我最喜欢的是在线实验室。它们让你能在实践中做一些原本需要大量硬件和软件才能完成的事情。我用得最多的一个叫 `Coursera`。人们构建了完善的工具示例来展示如何做机器学习。你不仅可以阅读相关内容，还可以深入示例中实际操作一番。这正是自 2015 年产品发布以来吸引我使用 `TensorFlow` 的原因。如此多的人慷慨地分享他们的知识、技能和能力。他们通过一些易于获取的课程、讲座甚至几个证书，在网上分享着通往机器学习王国的钥匙。我已经学习了 50 多门课程。其中一些比其他的好。你可以在我的 `LinkedIn` 个人资料上看到它们，或者直接在 `Coursera` 上搜索 `TensorFlow` 并挑选一门激发你灵感的课程。

有时，仅靠建立内部团队的速度不够快。承诺和激进的时间表会将事情推向远超自然节奏的程度。帮助内部人才在机器学习方面（或任何方面）发展世界级技能都需要时间。我认识到这是一个长期目标，也是你必须有目的地去构建的东西。这就是为什么你有几个选择可以开始寻找补充人才的方法。其中一种方式是雇佣承包商或外部供应商人才，让他们帮助你启动项目。另一种方式是找到合适的产品或公司，帮助你快速起步。目前有几家公司正在做这件事，其中一些可能会对你的组织产生重大影响。

数据将驱动最终结果。通常，组织中的数据源没有经过良好的索引，也没有清晰映射的特征和关联。即使获取现成的数据源也是一个真正的挑战。在大多数情况下，人们使用的那些数据集是专门为这种用途而创建的。这些数据集并非自然产生于“野外”。即使制作定制的合成数据集，对于试图大规模落地机器学习的组织来说也是一个挑战。这就是为什么使用外部产品来管理数据甚至访问 `API` 都需要规划和持续的投入。这意味着发送给 `API` 的数据必须保持一致。不断变化的数据流无论是在内部还是外部管理都是一场噩梦。
