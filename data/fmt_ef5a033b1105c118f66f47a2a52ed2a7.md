# 作用域

变量具有作用域，定义了它们可以在哪里被访问。有两种主要的作用域：局部和全局。

## 局部变量

定义在函数内部的变量是局部变量，只能在该函数内部访问。

```python
def my_function():
    local_var = "I am local"
    print(local_var)

my_function()
# 在函数外打印 local_var 将引发错误
```

## 全局变量

定义在任何函数之外的变量是全局变量，可以在程序的任何地方访问。

```python
global_var = "I am global"

def my_function():
    print(global_var)

my_function()
```

要在函数内部修改全局变量，使用 `global` 关键字：

```python
counter = 0

def increment():
    global counter
    counter += 1

increment()
print(counter)
```

# 数据类型

Python 有几种内置数据类型。最常见的有：

- 整数 `int`: 整数，例如 `5`, `-10`。
- 浮点数 `float`: 小数，例如 `3.14`, `-0.5`。
- 字符串 `str`: 字符序列，例如 `"hello"`, `'Python'`。
- 布尔值 `bool`: 逻辑值，例如 `True` 或 `False`。
- 列表 `list`: 有序的可变集合，例如 `[1, "apple", 3.5]`。
- 元组 `tuple`: 有序的不可变集合，例如 `(1, "apple", 3)`。
- 集合 `set`: 无序的唯一元素集合，例如 `{1, 2, 3}`
- 字典 `dict`: 键值对，例如 `{"name": "Alice", "age": 25}`

使用 `type()` 函数检查变量的类型：

```python
print(type(10))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("hello"))  # <class 'str'>
print(type(True))     # <class 'bool'>
```

# 字符串

字符串可以使用单引号、双引号或三引号。


可以使用索引访问字符串中的单个字符。索引从 0 开始。

字符串是不可变的，一旦创建就无法更改。

Python 提供了许多字符串方法：


# 列表

列表用于在单个变量中存储多个项并包含不同的数据类型。

```python

print(fruits[0])  # apple
fruits[1] = "orange"  #更改项
fruits.append("orange")  # 添加到末尾
fruits.insert(1, "mango")  # 在索引1处插入
fruits.pop()  # 删除最后一个项
del fruits[1]  # 删除索引为1的项
```

列表是可变的，这意味着它们可以更改。

```python
numbers = [1, 2, 3]
numbers.append(4)
numbers[0] = 10
numbers.clear()  # 清空列表
```

可以使用 `for` 循环遍历列表：

```python
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)
```

列表推导式提供了一种创建列表的简洁方式：

```python
numbers = [1, 2, 3, 4, 5]
squares = [x**2 for x in numbers]  # [1, 4, 9, 16, 25]
```

# 类和对象

类是创建对象的蓝图。

```python
class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        return f"{self.name} says Woof!"

my_dog = Dog("Buddy", "Golden Retriever")
print(my_dog.bark())
```

继承允许一个类继承另一个类的特征：

```python
class Cat(Dog):
    def meow(self):
        return f"{self.name} says Meow!"

my_cat = Cat("Whiskers", "Persian")
print(my_cat.bark()) # 继承的方法
print(my_cat.meow())  # 自己的方法
```

### 遍历字符串与索引

`print (c)`

### 修改字符串

要对字符串进行更改，你需要创建一个新的字符串变量。此新变量可以存储修改后的字符串。
例如，让我们来看以下编程挑战：

“编写一个程序，将字符串中所有的元音替换为下划线字符。”

起初，你可能认为可以简单地应用字符串索引来修改相关的字符。例如：
`word = "hello"`
`word[1] = "_"`
`word[4] = "_"`

但字符串是不可变的，这将不起作用！
相反，你需要定义一个新的变量来存储更改，然后应用循环来检查序列中的每个字符以“创建”新字符串。例如：
`word = "hello"`
`newword = ""`
`for c in word:`
`if c === 'e' or c == 'o':`
`newword += "_"`
`else:`
`newword += c`
