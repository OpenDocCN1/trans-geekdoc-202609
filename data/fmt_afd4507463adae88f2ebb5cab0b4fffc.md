
此刻，你正在阅读我为 2021 年撰写的最后文字，它们汇集于这篇关于机器学习资产的文章中。本周有点“改变游戏规则”的意味，因为我开始撰写新论文/演示文稿，用于 2022 年的演讲。该演示文稿的标题将是“医疗领域未来 5 年的机器学习”。目前，我计划将演示文稿分为 3 部分：1) 医疗领域全景映射，2) 规划未来 5 年，3) 机器学习将在医疗领域这 5 年的映射中处于何种位置。分享完这则新闻，让我们回到这篇关于机器学习资产文章的核心内容。

我大部分关于机器学习资产学术相关研究的搜索，都指向了你如何选择管理运行机器学习作业或其他工作的资源或设备。我偶然发现的研究非常偏战术性，而非战略性。我原以为会有更多关于将机器学习作为知识产权资产进行管理的学术文章比较突出。结果，冒出来的大多是关于从浏览器控制和启动机器学习工作的界面内容。这是从屏幕上的字面视角审视机器学习资产的一种方式，但并非我本周想了解的那种财务权重较重的资产定义。我对公司或个人生成的机器学习资产的经济价值感到好奇。

每次你从事机器学习项目，都会开始开发资产。这些资产要么被视为有价值，要么可能不会产生任何真正的可折旧资产。这个话题让人联想到 2019 年《哈佛商业评论》的一篇文章 [1]。那篇文章转向了机器学习如何帮助管理金融资产，而非更传统的问题——机器学习工具本身应如何作为资产记录在企业账面上。将构建软件的资金支出视为可折旧资产是很容易的。你也可以认为，为机器学习构建的模型可能在公司围墙之外（越来越多的是虚拟围墙）具有价值。大多数买卖模型的市场并非昂贵的交易场所。模型的激增似乎降低了其价值 [2]。也许是模型的商品化以及构建大型语言（基础）模型的极高成本影响了价值。甚至有人利用机器学习挖掘知识产权数据，读来颇有意思 [3]。我还读到了一种用于神经网络模型的数字水印技术，令人惊讶 [4]。我不确定他们在实践中如何能看到水印。

你也可以从另一个方向切入，考虑开源元素与高度专有元素之间竞争的本质。机器学习工作流的许多核心要素要么是开源的，要么是高度专有且锁定在 API 后的。像 `GPT-3` 这样的模型纯粹是专有且 API 驱动的。许多昂贵的模型通过 API 提供服务，这与 `TensorFlow`、`Scikit-learn`、`PyTorch` 和 `Keras` 等通过学术努力或开源仓库共享的开源根基截然不同。事物的开源本质或许能解释为何大多数组织在机器学习领域没有大片知识产权。
