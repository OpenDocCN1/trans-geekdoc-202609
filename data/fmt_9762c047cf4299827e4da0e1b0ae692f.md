
# 数据是流行病学和传染病研究的核心

数据不仅用于检测和预防传染病的传播，还用于寻找治疗方法和疫苗来治疗并可能预防这些疾病。目前正在收集 COVID-19 感染者的数据，包括个人的个人、工作和旅行详情，他们与他人的接触和关联，以及他们的社交活动。所收集的数据可以使用各种数据科学技术进行分析，以提取有价值的信息，从而检测疾病传播并加以预防。

例如，为接触者追踪目的构建的图可以使用链路分析技术进行分析，以确定可能因现有感染而染上 COVID-19 的人员。聚类技术可用于从收集的数据中确定潜在 COVID-19 病例的聚类。决策树可用于对个体进行分类，例如某县特定种族来源的个体更易感染 COVID-19。我们希望此类数据科学技术可用于识别无症状感染者，他们可能是病毒的潜在传播者。例如，如果无症状感染者病毒检测呈阳性，则可以研究这些人的行为模式和基因构成，以了解他们无症状的原因。利用这些信息，可以对其他无症状人员进行病毒检测，并警告他们的接触者。

虽然在患者中检测病毒至关重要，但预防甚至更为关键。考虑到即使一个人存活下来，疾病也会对其生活造成影响，因此预防疾病比感染病毒更好。因此，可以从 COVID-19 病例极少的国家收集数据并了解趋势。然后，获得的信息可用于预防世界其他地区的疾病。

数据科学还可用于开发治疗方法和疫苗。数据驱动的科学和医学已被科学家和医学博士广泛接受。关于病毒 DNA 的信息、易感个体的基因构成、与疾病相关的所有信息以及各种数据库中的信息可以被整合和分析，以确定对 COVID-19 患者可能有用的治疗方法。此外，来自西班牙流感等疾病以及 SARS 等其他传染病的数据，以及为这些疾病生成的治疗方法和疫苗，可用于开发针对 COVID-19 的新治疗方法和疫苗。换句话说，必须收集、存储和分析每一条数据，包括关于患者的数据、既往相关传染病的数据、针对各种传染病现有的治疗方法和疫苗，以及人类和非人类种群的历史趋势，以便为我们今天面临的大流行提供解决方案。

数据收集、数据存储、数据共享（不同机构和国家之间）以及数据分析（例如应用数据科学技术）是开发应对大流行解决方案的关键活动。这些解决方案可能是医疗解决方案，也可能是行为和社会解决方案，例如佩戴遮盖口鼻的口罩、护目镜、面罩、手套、发套和其他防护设备。例如，可以让一组人只戴口罩，另一组人戴口罩和面罩进行实验，以确定前一组感染 COVID-19 的概率是否更高。同样，可以逐步增加社交聚会的人数并研究结果。如果我们要分析数据以产生有用的结果，此类调查必须基于准确可靠的数据。此外，在各种场景下进行彻底的风险分析并让公众了解潜在危险也很重要。

## 14.4 隐私影响及潜在解决方案

每当收集关于个人的数据，并对这些数据进行存储、管理、共享和分析时，都极有可能侵犯个人隐私。一个人可能对 COVID-19 检测呈阳性这一简单事实，就可能导致该人承受巨大的污名，甚至在康复后仍被所有人排斥。另一方面，我们需要告知各相关人员，他们可能曾与 COVID-19 患者接触。这可以在不透露患者姓名的情况下完成。

收集和分析数据的另一个问题是接触者追踪。可以检查存储在个人智能手机中的数据，并从中找出该人的所有接触者。告知该人的接触者至关重要。然而，这意味着必须查看其手机中的数据，或了解该人过去两周左右进行的所有活动。这意味着在未经本人知情的情况下收集关于其的数据，将侵犯其隐私。收集的数据可能不仅关乎该人的症状或接触过谁，还可能涉及其基因图谱。

隐私困境给从事医疗保健分析的人员带来了巨大挑战。拒绝访问数据意味着潜在的数百万人死亡。拥有数据访问权意味着侵犯个人隐私，这可能给个人带来严重后果，例如因既往病史被拒保，或利用数据确定个人行为模式进而实施勒索。此外，为治疗患者，医疗服务提供者可能需要访问其基因图谱。从此信息中，他们可能得知该人未来可能患上的疾病。保险公司可能会拒绝为该人尚未患上的疾病提供保障。因此，我们该如何在为 COVID-19 患者提供最佳护理的同时，确保他们的隐私？解决方案可能在于隐私感知和基于策略的数据收集、存储、管理、共享和分析。

我们已经对隐私感知和基于策略的数据收集、存储、管理、共享和分析进行了研究 [THUR2018]。即策略指导整个数据生命周期的活动。例如，收集数据、存储数据、管理数据、共享数据和分析数据的策略是什么？各种隐私保护数据科学技术从分析角度审视隐私。策略应指导这一过程。同样，策略也应指导其他过程，例如我与谁共享我收集的关于患者的数据？数据共享策略是什么？即使在数据删除方面，我们也需要策略，因为我们需要确保数据被妥善删除。

下一步是检查数据科学活动的各个方面，包括隐私感知的基于策略的数据生命周期过程，并探索区块链技术如何安全地应用于这些活动中涉及的各种分布式事务。此外，还需要探索供应链中的智能合约，包括数据供应链以及金融交易的执行。最后，需要进一步探索区块链在网络安全中的应用，包括勒索软件和对抗性机器学习等领域。我们相信，区块链是将数据科学与网络安全整合在一起的粘合剂。

## 14.5 重访数据隐私的多目标框架

### 多目标隐私框架回顾

在本节中，我们重新审视在 NSF 研讨会上讨论并在第 5 章中针对 COVID-19 隐私方面所呈现的多目标框架。如前所述，尽管有人尝试提出能够应对多种不同场景的隐私解决方案/定义，但我们认为**不存在一种适用于所有场景的数据隐私通用解决方案**。相反，需要针对不同的应用领域定制多个维度，以实现切实可行的解决方案。

首先，不同领域需要不同的数据效用定义。其次，我们需要理解正确的隐私风险定义。例如，在数据共享场景中，给定特定背景知识下的重新识别概率可被视为衡量隐私风险的正确指标。最后，必须考虑给定协议的计算、存储和通信成本。这些成本对于涉及密码学的隐私保护协议尤为显著。因此，第一步是为 COVID-19 应用提出数据效用的定义、确定可接受的风险，并计算成本（例如存储成本）。给定这三个维度，可以设想一个多目标框架，其中不同维度的侧重点如下：

*   **在风险和成本约束下最大化效用**：这适用于限制特定隐私风险至关重要的场景。
*   **在效用和成本约束下最小化隐私风险**：在某些场景（例如 COVID-19 医疗护理等医疗护理）中，可能不允许效用显著下降。在此设置下，协议的参数值（例如差分隐私中的 `ε`）的选择方式是：在给定效用约束的情况下，尽最大努力保护隐私。请注意，在某些场景中，可能不存在能满足所有约束的参数设置。
*   **在效用和风险约束下最小化成本**：在某些情况下（例如密码学协议），您可能希望找到能满足所有效用和风险约束的、开销最小的协议参数设置。

为了更好地说明这些维度，请参考文献 [INAN2012] 中解决的隐私保护记录匹配问题。该问题的现有解决方案通常遵循两种方法：清洗技术和密码学技术。文献 [INAN2012] 提出了一种结合这两种方法的混合技术。这种方法使用户能够在隐私、准确性和成本之间进行权衡。这与本章讨论的多目标优化框架类似。这些多目标优化是通过在清洗后的数据上运行阻塞阶段来实现的，该阶段以隐私保护的方式过滤掉不满足匹配条件的记录对。通过披露更多信息（例如差分隐私数据统计），与密码学技术相比，所提方法的成本显著降低。另一方面，即使在隐私要求很高的情况下，其产生的匹配结果也比清洗技术准确得多。使用不同的隐私参数值可以实现不同的成本、风险和效用结果。

为了实现数据隐私的多目标优化框架，我们认为需要更多研究来为不同应用领域确定合适的效用、风险和成本定义。特别是定义正确且现实的隐私风险至关重要。从石油开采到航空旅行，许多人类行为都涉及风险与收益。在许多情况下（例如试图开发一架永不发生故障的飞机），规避所有风险要么成本过高，要么不可能。同样，我们认为为所有人规避所有隐私风险成本过高。此外，假设攻击者可能知晓一切过于悲观。因此，需要在现实攻击者场景下提出隐私风险定义。

正如我们在第三部分某些章节中所讨论的，大数据产生的一个主要问题是：在关联许多（大）数据集时，可以提取出意想不到的信息。也就是说，我们需要隐私保护数据关联技术。我们重新审视第 5 章中针对 COVID-19 应用讨论的相关问题和研究方向：

*   **控制提取内容并检查提取内容是否可被使用和/或共享的技术**。
*   **同时支持个人隐私和群体隐私**：在群体隐私方面，理解从数据中提取了什么信息很重要，因为这可能导致歧视。此外，在处理安全与隐私问题时，理解个人隐私与集体安全之间的权衡也很重要。
*   **高效且可扩展的隐私增强技术**：多年来开发了多种此类技术，包括 `oblivious RAM`、安全多方计算、多输入加密和同态加密。然而，它们尚未能实际应用于大型数据集。我们需要对这些技术进行工程化改造，例如利用并行化来微调其实现，并可能将它们与其他技术（如差分隐私）结合使用（正如文献 [SCAN2007] 中描述的记录链接协议那样）。在这方面，一种可能的进一步方法是首先使用匿名/清洗后的数据，然后根据具体情况获取特定的非匿名数据。
*   **数据隐私策略的可用性**：策略必须易于用户理解。我们需要面向普通用户的工具，并需要了解用户对隐私的期望。
*   **数据服务货币化方法**：数据集所有组织可以不直接出售数据，而是基于这些数据集出售隐私保护数据分析服务。此时需解决的问题是：如果隐私保护数据分析工具可用，数据周围的商业模式将如何变化？此外，如果数据被视为可出售的商品，是否存在关于数据买卖合同的法规？这些合同能否包含隐私条款，例如要求已通知相关数据主体？
*   **数据发布**：鉴于隐私影响，或许我们应该放弃发布数据的想法，而是要求数据使用者利用受控环境（可能位于云中）来使用数据。这样将更容易控制数据的正确使用。一个问题在于大学中使用的研究数据以及基于数据研究的可重复性。
*   **隐私对数据质量的影响**：近期研究表明，人们尤其是在社交网络中会撒谎，因为他们不确定自己的隐私是否得到保护。这导致数据质量下降，进而影响基于这些数据的决策和策略。此外，2020 年和 2021 年发布了大量关于 COVID-19 的假新闻。因此，我们需要技术将实际有用的数据与虚假数据区分开来。
*   **风险模型**：可以识别大数据与风险的不同关系类型：(a) 大数据可能增加隐私风险；(b) 大数据可能在许多领域降低风险（例如国家安全）。开发这两类风险的模型对于识别合适的权衡和隐私增强技术至关重要。

### 数据所有权

关于谁是一段数据（例如医院关于 COVID-19 患者的数据）的所有者的问题，通常是一个棘手的问题。或许最好用**利益相关者**的概念来取代这一概念。每个数据项都可以与多个利益相关者相关联。利益相关者的概念与风险紧密相关。每个利益相关者都会有不同的（可能相互冲突的）目标，这可以根据多目标优化进行建模。在某些情况下，一个利益相关者可能不知道其他利益相关者的存在。例如，数据所涉及的用户（因此是该数据的利益相关者）可能不知道执法机构正在使用这些数据。需要调查技术解决方案以消除冲突。

### 人为因素

为隐私提出的所有解决方案（以及将在后续章节讨论的机密性）都需要进行调查，以确定人为参与的程度，例如，用户将如何与数据交互，以及其关于数据使用和/或保护的具体任务是什么，以增强可用性？

### 数据生命周期框架

大数据隐私的综合方法需要基于系统的数据生命周期方法（如第 13 章所述）。需要识别生命周期中的各个阶段，并确定其隐私要求和影响。相关阶段包括：

#### 数据获取

我们需要机制和工具来防止设备获取关于其他个人的数据（当使用 Google Glass 等设备时相关）；例如，我们能否想出机制，自动阻止设备在特定地点录制/获取数据（或通知用户周围有录制设备）。我们还需要技术，让每个被记录的主体对数据的使用有发言权。

#### 数据共享

用户需要被告知数据共享/传输给其他方。在某些关于 COVID-19 的情况下，用户可能必须授予共享其相关数据的权限。

解决上述挑战需要跨学科研究，涉及计算机科学与工程、信息系统、统计学、风险模型、经济学、社会科学、政治学、人因工程和心理学等许多不同领域。我们认为，所有这些视角都是开发有效解决方案所必需的，以解决大数据时代的隐私问题，并协调安全与隐私。

## 14.6 机密性与访问控制的作用

在确保患者隐私至关重要的同时保证数据效用，控制数据访问对于维护机密性也至关重要。因此，我们将重新审视 NSF 大数据安全与隐私研讨会上讨论的访问控制挑战，以及本书第 5 章中列出的挑战。特别是，我们将讨论与 COVID-19 应用相关的大数据访问控制策略。存在若干数据机密性技术和机制，最著名的是访问控制系统和加密。这两种技术已被广泛研究。然而，对于大数据的访问控制系统（包括为 COVID-19 收集的海量数据），我们需要以下方面的方法：

### 合并大量访问控制策略

在许多情况下，大数据意味着整合来自多个来源的数据（例如，与 COVID-19 相关的患者数据、患者病史、疫苗数据）。这些数据可能关联着各自的访问控制策略（称为“粘性策略”），即使数据与其他数据集成，这些策略也必须得到执行。因此，需要集成策略并解决冲突。

### 自动管理大数据的授权，特别是授予权限

如果需要细粒度访问控制，在大数据集上进行手动管理是不可行的。我们需要技术，根据用户的数字身份、配置文件和上下文，以及数据内容和元数据，自动授予授权。

### 在异构多媒体数据和地理空间数据上执行访问控制策略

基于内容的访问控制是一种重要的访问控制类型，根据数据内容授予或拒绝授权。在处理对安全至关重要的视频监控应用时，基于内容的访问控制至关重要。就隐私而言，此类视频必须受到保护。支持基于内容的访问控制需要理解受保护数据的内容，而在处理多媒体大数据源时，这极具挑战性。最后，在某些情况下，必须保护关于患者（例如位置）和疫苗（疫苗存储位置）的地理空间信息。

### 在大数据存储中执行访问控制策略

一些最新的大数据系统允许用户使用 Java 等编程语言提交任意作业。例如，在 `Hadoop` 中，用户可以提交用 Java 编写的任意 `MapReduce` 作业。这给为不同用户高效执行细粒度访问控制带来了重大挑战。尽管已有一些现有工作（KHAN2014，ULUS2014）尝试将访问控制策略注入提交的作业中，但仍需进一步研究如何在新开发的大数据存储中高效执行此类策略。

### 自动设计、演进和管理访问控制策略

在数据源、用户、应用程序以及数据使用持续变化的动态环境中，自动设计和演进策略的能力至关重要，以确保数据随时可用，同时保证数据机密性。用于管理策略的环境和工具也至关重要。

## 14.7 公民自由如何保障？

美国公民自由联盟（`ACLU`）发布了关于平衡接触者追踪与隐私的优秀文章（COVID，APPL）。这些文章讨论了苹果、谷歌等智能手机公司利用蓝牙技术进行接触者追踪的提案。`ACLU` 还强烈支持基于策略的数据收集和分析。例如，文章指出：

> 将隐私保护嵌入设计的技术原则是一类重要的保护措施。仍然需要严格的政策（<https://www.justsecurity.org/69444/how-to-think-about-the-right-to-privacy-and-using-location-data-to-fight-covid-19/>）来防止越权和滥用。这些政策至少应包括以下内容：
>
> *   **自愿性**：只要可能，检测呈阳性的人必须同意应用程序进行的任何数据共享。决定使用追踪应用应是自愿且非强制的。安装、使用或报告不得作为返回工作或上学的前提条件。
> *   **用途限制**：数据不应用于公共卫生以外的目的——不用于广告，特别是不用于任何惩罚性或执法目的。
> *   **最小化**：必须制定政策，确保仅收集必要信息，并禁止与公共卫生工作之外的任何人共享数据。
> *   **数据销毁**：技术以及相关政策和程序都应确保在不再需要保留数据时将其删除。
> *   **透明度**：如果政府获取任何数据，必须完全透明地说明获取了什么数据、从何处获取以及如何使用这些数据。
> *   **不得任务蔓延**：必须制定政策，确保追踪工作不会在抗击 COVID-19 的努力结束后继续存在。
>
> 这些政策至少必须到位，以确保任何追踪应用程序都将有效，并符合公民自由和人权。

虽然隐私倡导者仍然担心隐私侵犯，但他们也理解需要进行数据收集和分析以挽救生命。然而，当我们将 `ACLU` 现在的立场与他们 2002 年的立场进行比较时，我们看到了变化。这部分归因于我们现在对政策感知的数据收集和分析了解得更多。当时的担忧是，我们不想以牺牲隐私为代价获得虚假的安全感。此外，当时某些人即使与恐怖主义毫无关联，也被政府拘留。然而，大流行病截然不同。即使一个人看起来非常健康，也可能有必要对其进行检测，因为他/她可能是无症状感染者。因此，与反恐调查相比，人们似乎对 COVID-19 的检测和接触者追踪表现出更大的包容度。

除了隐私倡导者，还有一些人拒绝戴口罩、拒绝停止去酒吧，他们声称自己的公民自由受到了侵犯。尽管回在 2002 年，当普通大众在机场排队接受更广泛的检查时，并没有提出那么多担忧。这可能是因为我们能在电视上看到可怕的恐怖袭击。至于 COVID-19，我们看到了医院里发生的情况，但出于某种原因，人们似乎不那么担心，因为他们可能认为这不会发生在自己身上。我相信持续的教育是解决这一问题的关键。必须每天警告人们，不采取预防措施不仅可能导致他们自己死亡，还可能感染他人，包括他们死亡概率高得多的年迈亲属。戴口罩或面罩会带来一些不便，但为了挽救人类，做出小小的牺牲（甚至巨大的牺牲）是值得的。政治不应干预人类生命，2001 年和 2002 年不应，当然今天更不应。

## 14.8 平衡安全与安保 vs. 隐私与公民自由

前几节的讨论表明，无论我们讨论的是国家安全还是大流行病，核心都在于平衡安全与安保（例如，挽救生命、保护个人免受恐怖袭击）与隐私与公民自由。如果我们能同时拥有安全、安保、隐私和公民自由，那该多好？但我们知道这是不可能的。为了安全，我们需要牺牲公民自由的某些方面。问题在于牺牲多少？这就是我们的挑战。

有人会争辩说，如果我们没有所有数据进行分析并向流行病学家和医生提供建议，以便 COVID-19 患者获得适当的医疗护理，我们就面临大规模伤亡的严重危险。那些认为公民自由至上的人会争辩说，如果数据被用于勒索个人、拒绝提供医保等坏目的，我们就不是一个文明社会。此外，他们还认为，数据落入坏人之手也可能导致谋杀和强奸等敌对行为。也就是说，了解个人的行踪会给凶手和强奸犯提供绝佳的作案机会。最终，我们需要权衡取舍。在某些时期，我们必须专注于安全（例如，大流行加剧）；在其他一些时期，隐私应得到更多考虑（例如，病例寥寥无几时）。
