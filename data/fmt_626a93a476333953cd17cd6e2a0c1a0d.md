## 上下文模型

我们迄今讨论的模型对每个词只有一种表示。然而，在包括英语在内的许多语言中，单词的含义会根据其上下文而改变。例如，单词 *bank* 在以下短语中可能有两种不同的含义：'*bank of a river*', '*Indian Bank*'。然而，我们将只有一个该词的稠密或稀疏表示。这是不正确的。因此，我们需要单词的上下文表示，即单词表示会根据相邻单词而变化。捕捉此信息的一种方法是使用序列模型，如 RNN 或双向 RNN。

## ELMo 模型

与 `word2vec` 和 `GLoVe` 等传统词嵌入不同，`ELMo` 词嵌入是包含该词的整个句子的函数。因此，同一词在不同语境下可以有不同的词向量表示。

**来自语言模型的嵌入** 词向量是使用双层双向 LSTM 模型计算的。输入词嵌入源自基于 CNN 的字符嵌入模型。字符表示使用 16 维字符嵌入和宽度为三个字符的 128 个卷积滤波器、ReLU 激活函数和最大池化。请参考下图：

## BERT

### 来自 Transformers 的双向编码器表示 (BERT)

**来自 Transformers 的双向编码器表示** (**BERT**) [[6]](#c11.xhtml#c11_ref6) 是另一种使用 Transformer 层堆栈的上下文语言模型。Transformer 架构首次在 第 11 章，序列建模 的*语言翻译*中引入。那里我们有 Transformer 编码器和解码器。BERT 模型仅使用 Transformer 的编码器部分。下图展示了具有两个 Transformer 编码器层的 BERT 架构。输入 Token 的数量与输出 Token 的数量相同 (N)。我们将这些称为 `transformed features`。请参考下图：

![BERT architecture with 2 transformer encoder layers](img/Figure-12.9.jpg)

**图 11.9：** *具有 2 个 Transformer 编码器层的 BERT 架构*

输入是大小为 H 的 Token 嵌入序列。输出是大小为 H 的向量序列。输出序列的长度与输入序列相同。这些向量是输入向量的上下文嵌入。对于 BERT，通常使用固定的序列长度。然而，输入可以是可变长度的，因此必须对输入进行填充以使其长度相同。

由于 Transformer 架构不是循环的，并且一次性看到整个序列，我们必须有一种方法来保留文本中的顺序信息。此外，文本中存在自然片段，如句子和段落。保留这些输入信息对于更好地建模文本非常重要。这是通过位置编码和片段编码来完成的。

#### 位置编码

由于我们的词嵌入是向量，为了编码单词的位置，我们不能直接使用整数。使用整数 `i` 的向量表示来编码位置。我们知道任何整数最简单的向量表示是二进制（6 位）表示，如下表所示，针对整数 0-7。我们看到最低有效位 (LSB) 在连续位之间交替。下一位每两个数字变化一次，再下一位每四个数字变化一次，依此类推。二进制交替信号的连续对应物是正弦函数 `sin(ωt)`。此外，我们可以通过改变参数 `ω` 来控制它们交替的频率。因此，使用正弦函数，我们可以为序列定义位置编码 `PE(pos, 2i)`，定义如下：

#### BERT 预训练任务的输入表示

由于 BERT 接受固定大小的输入，首先通过零填充使每个句子长度相等，并使用以下步骤标记句子的分隔和结束。

1.  每个输入序列的第一个 Token 是特殊的分类 Token – `[CLS]`。此 Token 用于分类任务，作为整个序列表示的聚合。在非分类任务中会被忽略。

2.  对于单文本句子任务，此 `[CLS]` Token 后跟 WordPiece Token 和分隔 Token – `[SEP]`。

3.  对于句子对任务，两个句子的 WordPiece Token 由另一个 `[SEP]` Token 分隔。此输入序列也以 `[SEP]` Token 结尾。

#### WordPiece 分词

分词从根本上说是将文本分解为 Token 的过程。**词表外单词** (**OOV**) 或词汇表中不包含的单词，被视为“*未知*”。解决此问题的一种更好且现代的方法是将文本分词为子词单元，在大多数分割中可以保留语言学意义。因此，即使一个单词对模型未知，单个子词 Token 可能保留足够的信息供模型推断含义。WordPiece 就是一种此类算法。给定文本，WordPiece 首先将文本预分词为单词（通过在标点符号和空白处分割），然后将每个单词分词为子词单元，称为 wordpieces。例如，让我们以下图所示的句子为例：

BERT 中使用的掩码机制不适用于中文。在英语中，单词作为语义单位，而单个字符没有任何含义。中文字符则不然：某些字符本身就具有固有含义，例如火（火， *huŏ*）、水（水， *shuĭ*）或木（木， *mù*）。例如，字符“灵”（*líng*）根据其搭配的不同，可以表示聪明（机灵， *jīlíng*）或灵魂（灵魂， *línghún*）。百度研究人员开发了其他适合中文的预训练任务。他们开发了隐藏字符串而非单个字符的掩码机制，并将他们的模型命名为**通过知识集成增强表示**（**ERNIE**）。

## ERNIE

**通过知识集成增强表示**（**ERNIE**）*\[7\]* 模型是一种基于 Transformer 的模型，旨在通过知识掩码策略（包括实体级掩码和短语级掩码）学习增强的语言表示。ERNIE 在多项中文语言任务上超越了 Google 的 BERT。

以下是 ERNIE 特有的其他一些预训练任务：

1.  **知识掩码任务**：随机短语被掩码，命名实体被掩码，模型被训练以预测完整的被掩码短语或命名实体。

2.  **大小写预测任务**：预测单词是否大写。

3.  **标记-文档关系预测任务**：该任务预测片段中的标记是否出现在原始文档的其他片段中。它在一定程度上能使模型具备捕捉文档关键词的能力。

4.  **句子距离任务**：对 NSP 的增强。该任务被建模为一个三分类问题。“0”表示两个句子在同一文档中相邻，“1”表示两个句子在同一文档中但不相邻，“2”表示两个句子来自两个不同文档。

5.  **IR 相关性任务**：这是一个三分类任务，用于预测*查询和标题*之间的关系。我们将查询作为第一个句子，标题作为第二个句子。0-> 强相关，1-> 弱相关，2-> 无相关。

## OpenAI 的生成式预训练

**生成式预训练**（**GPT**）是另一种基于 Transformer 的模型，但它仅使用 Transformer 的解码器模块堆栈。这与 BERT 不同，后者仅使用编码器模块且是非自回归的，即仅利用序列中的前序标记来预测下一个标记。在标准 Transformer 架构中，解码器接收词嵌入与上下文向量拼接后的输入。在 GPT-2 中，由于没有编码器模块，第一个词嵌入的上下文向量被零初始化。研究发现 GPT 在许多自然语言理解任务上优于 BERT。

## 结论

在本章中，我们涵盖了自然语言中的语言结构、利用这些语言结构预处理文本的方法，以及从文本数据中提取特征。我们还介绍了各种文本模型，如向量空间模型、概率模型和神经语言模型。利用这些模型，我们演示了 NLP 重要应用的概览，如文本分类、文本相似度、信息检索应用、摘要生成、问答系统等。

在下一章中，我们将讨论不同的生成式建模技术及其在图像生成和文本生成中的应用。

## 重点回顾

*   语言模型类型：向量空间、概率、神经网络

*   由 LSI 或任何神经语言模型生成的词嵌入具有距离保持性，即含义相似且出现在相似语境中的单词，其嵌入向量在嵌入空间中会彼此接近。

*   上下文语言模型可以根据单词的上下文为同一单词创建不同的嵌入。

*   神经语言模型并不总是需要大量数据，因为我们有 BERT、ELMO 和 GPT-3 等模型，它们可以用较小的数据集进行微调。
