
### 2.2.4 复随机变量

复随机变量 $z \in \mathbb{C}$ 定义为

$$z = x + jy \tag{2.36}$$

其中 $x, y$ 是实随机变量且 $j := \sqrt{-1}$。

请注意，对于复随机变量，PDF **无法** 定义，因为形如 $x + jy \le x + jy$ 的不等式没有意义。当我们写 $p(z)$ 时，我们指的是实部和虚部的联合 PDF，表示为

$$p(z) := p(x, y). \tag{2.37}$$

对于复随机变量，均值和协方差的概念定义为

$$\mathbb{E}[z] := \mathbb{E}[x] + j\mathbb{E}[y] \tag{2.38}$$

以及

$$\text{cov}(z_1, z_2) := \mathbb{E}[(z_1 - \mathbb{E}[z_1])(z_2 - \mathbb{E}[z_2])^*] \tag{2.39}$$

其中“$*$”表示复共轭。后一定义导出了复变量的方差，

$$\sigma[z]^2 = \mathbb{E}[|z - \mathbb{E}[z]|^2] = \mathbb{E}[|z|^2] - |\mathbb{E}[z]|^2. \tag{2.40}$$

类似地，对于复随机向量 $\mathbf{z} = \mathbf{x} + j\mathbf{y} \in \mathbb{C}^{(l)}$，我们有

$$p(\mathbf{z}) := p(x_1, \dots, x_l, y_1, \dots, y_l), \tag{2.41}$$

其中 $x_i, y_i, i = 1, 2, \dots, l$ 分别是所涉及实向量的分量。

协方差矩阵和相关矩阵的定义类似：

$$\text{Cov}(\mathbf{z}) := \mathbb{E}[(\mathbf{z} - \mathbb{E}[\mathbf{z}])(\mathbf{z} - \mathbb{E}[\mathbf{z}])^H], \tag{2.42}$$

其中“$H$”表示埃尔米特（转置和共轭）运算。

### 2.2.5 随机变量的变换

设 $\mathbf{x}$ 和 $\mathbf{y}$ 为两个随机向量，它们通过如下变换相关联：

$$\mathbf{y} = \mathbf{f}(\mathbf{x}), \tag{2.43}$$

其中 $\mathbf{f} : \mathbb{R}^l \mapsto \mathbb{R}^l$ 是一个**可逆**（向量）函数。也就是说，给定 $\mathbf{y}$，可以唯一地得到 $\mathbf{x} = \mathbf{f}^{-1}(\mathbf{y})$。我们已知 $\mathbf{x}$ 的联合 PDF $p_{\mathbf{x}}(\mathbf{x})$，任务是求得 $\mathbf{y}$ 的联合 PDF $p_{\mathbf{y}}(\mathbf{y})$。

该变换的雅可比矩阵定义为

```
J(y; x) := ∂(y₁,y₂,…,yₗ)/∂(x₁,x₂,…,xₗ) := 
[ ∂y₁/∂x₁ … ∂y₁/∂xₗ ]
[ ⋮       ⋱ ⋮       ]
[ ∂yₗ/∂x₁ … ∂yₗ/∂xₗ ].
```

然后，可以证明（例如，[6]）

```
p_y(y) = p_x(x) / |det(J(y; x))| |_{x = f⁻¹(y)}.
```

其中 `|det(⋅)|` 表示矩阵行列式的绝对值。对于实随机变量，如 $y = f(x)$，公式简化为

```
p_y(y) = p_x(x) / |dy/dx| |_{x = f⁻¹(y)}.
```

## 2.3 分布示例

本节提供了一些值得注意的分布示例。这些分布常用于建模在广泛应用中遇到的变量的随机性质，并将在本书后续章节中使用。

### 2.3.1 离散变量

#### 伯努利分布

如果一个随机变量是二元的，$\mathcal{X} = \{0, 1\}$，并且满足

#### 二项分布

如果随机变量 $x$ 服从参数为 $n, p$ 的二项分布，记作 $x \sim \text{Bin}(x|n, p)$，则 $\mathcal{X} = \{0, 1, \dots, n\}$ 且

$$P(x=k) = \binom{n}{k} p^k (1-p)^{n-k} \tag{2.53}$$

其中由定义

$$\binom{n}{k} := \frac{n!}{(n-k)!k!} \tag{2.54}$$

例如，该分布模拟了在 $n$ 次连续试验中“正面”出现的次数，其中 $P(\text{heads}) = p$。二项分布是伯努利分布的推广，当在公式 (2.53) 中令 $n=1$ 时即得到伯努利分布。二项分布的均值和方差为（问题 2.1）：

$$\mathbb{E}[x] = np \tag{2.55}$$

$$\sigma[x]^2 = np(1-p) \tag{2.56}$$

图 2.2A 显示了 $p=0.4$ 和 $n=9$ 时概率 $P(k)$ 作为 $k$ 的函数。图 2.2B 显示了相应的累积分布。观察到后者呈阶梯状，这始终是离散变量的情况。

#### 多项式分布

这是二项分布的一种推广，适用于每次实验的结果不再是二元的，而是可以取 `K` 个可能值之一的情况。例如，不再是抛硬币，而是投掷一个具有 `K` 个面的骰子。每个可能的 `K` 个结果发生的概率分别为 `P[1]`、`P[2]`、…、`P[K]`，我们记为

$$\mathbf{P} = [P_1, P_2, \dots, P_K]^T.$$

进行 `n` 次实验后，假设面 $x = 1$、$x = 2$、…、$x = K$ 分别出现了 $x_1$、$x_2$、…、$x_K$ 次。我们称随机（离散值）向量

$$\mathbf{x} = [x_1, x_2, \dots, x_K]^T, \tag{2.57}$$

服从多项式分布，$\mathbf{x} \sim \text{Mult}(\mathbf{x}|n, \mathbf{P})$，如果

$$\binom{n}{x_1, x_2, \dots, x_K} := \frac{n!}{x_1! x_2! \dots x_K!}. \tag{2.58}$$

注意变量 $x_1, \dots, x_K$ 受约束条件限制

$$\sum_{k=1}^{K} x_k = n,$$

并且也有

$$\sum_{k=1}^{K} P_k = 1.$$

均值、方差和协方差由下式给出

##### 多项分布的统计特性

$$\mathbb{E}[\mathbf{x}] = n\mathbf{P}, \quad \sigma[x_k]^2 = nP_k, \quad k = 1, 2, \dots, K, \quad \text{cov}(x_i, x_j) = -nP_i P_j, \quad i \ne j.$$

多项分布的特例，即仅进行一次实验（$n = 1$）的情况，称为**类别**分布。后者可视为伯努利分布的推广。

#### 高斯分布

高斯分布或正态分布是所有科学学科中应用最广泛的分布之一。我们称随机变量 $x$ 为**高斯**或**正态**分布，参数为 $\mu$ 和 $\sigma^2$，记作 $x \sim \mathcal{N}(\mu, \sigma^2)$ 或 $\mathcal{N}(x|\mu, \sigma^2)$，若

##### 高斯概率密度函数

$$p(x) = \frac{1}{\sqrt{2\pi}\sigma}\exp\left( - \frac{(x - \mu)^{2}}{2\sigma^{2}} \right). \tag{2.63}$$

可以证明，对应的均值和方差为

$$\mathbb{E}[x] = \mu \quad \text{and} \quad \sigma[x]^{2} = \sigma^{2}. \tag{2.64}$$

根据均值定义，我们有

$$
\mathbb{E}[x] = \frac{1}{\sqrt{2\pi}\sigma}\int_{-\infty}^{+\infty}x\exp\left( - \frac{(x - \mu)^{2}}{2\sigma^{2}} \right) dx 
= \frac{1}{\sqrt{2\pi}\sigma}\int_{-\infty}^{+\infty}(y + \mu)\exp\left( - \frac{y^{2}}{2\sigma^{2}} \right) dy.
\tag{2.65}
$$

由于指数函数的对称性，涉及 $y$ 的积分结果为零，唯一保留的项来自 $\mu$。考虑到概率密度函数积分为 1，我们得到该结果。

为了推导方差，从高斯概率密度函数的定义出发，我们有

$$
\int_{-\infty}^{+\infty}\exp\left( - \frac{(x - \mu)^{2}}{2\sigma^{2}} \right) dx = \sqrt{2\pi}\sigma.
\tag{2.66}
$$

对两边关于 $\sigma$ 求导，我们得到

$$
\int_{-\infty}^{+\infty} \frac{(x - \mu)^2}{\sigma^3} \exp\left( - \frac{(x - \mu)^2}{2\sigma^2} \right) dx = \sqrt{2\pi}
\tag{2.67}
$$

或

$$
\sigma_x^2 := \frac{1}{\sqrt{2\pi}\sigma} \int_{-\infty}^{+\infty} (x - \mu)^2 \exp\left( - \frac{(x - \mu)^2}{2\sigma^2} \right) dx = \sigma^2,
\tag{2.68}
$$

这证明了该断言。

图 2.4 展示了两种情况的图形，即 $\mathcal{N}(x|1, 0.1)$ 和 $\mathcal{N}(x|1, 0.01)$。这两条曲线均围绕均值 $\mu = 1$ 对称分布。观察可知，方差越小，概率密度函数 (PDF) 在均值周围变得越尖锐。

Fig. 2.6 展示了等概率密度值对应的等值线轮廓。在 Fig. 2.6A 中，轮廓为圆形，对应 Fig. 2.5A 中具有协方差矩阵 $\Sigma_1$ 的对称 PDF。Fig. 2.6B 中所示轮廓对应 Fig. 2.5B 中的 PDF，其关联的协方差矩阵为 $\Sigma_2$。可以观察到，通常情况下，等值曲线为椭圆/超椭球体。它们以均值向量为中心，主轴的朝向及其确切形状由相关协方差矩阵的特征结构控制。确实，所有获得相同概率密度值的点 $\mathbf{x} \in \mathbb{R}^l$ 都满足：

$$
(\mathbf{x} - \boldsymbol{\mu})^T \Sigma^{-1} (\mathbf{x} - \boldsymbol{\mu}) = \text{constant} = c.
\tag{2.72}
$$

我们知道协方差矩阵除了是正定的，还是**对称**的，即 $\Sigma = \Sigma^T$。因此，其特征值为实数，对应的特征向量可以选取形成一组标准正交基（见附录 A.2），从而实现其对角化：

$$
\Sigma = U \Lambda U^T,
\tag{2.73}
$$

其中

$$
U := [\mathbf{u}_1, \dots, \mathbf{u}_l],
\tag{2.74}
$$

此处 $\mathbf{u}_i$（$i = 1, 2, \dots, l$）为标准正交特征向量，且

$$
\Lambda := \text{diag}\{\lambda_1, \dots, \lambda_l\}
\tag{2.75}
$$

分别构成各自的特征值。我们假设 $\Sigma$ 可逆，因此所有特征值均为正（由于是正定矩阵，其特征值为正，见附录 A.2）。由于特征向量的标准正交性，矩阵 $U$ 是正交的，表示为 $U U^T = U^T U = I$。因此，公式 (2.72) 现在可以写为

$$y^T \Lambda^{-1} y = c$$

其中我们使用了线性变换

$$y := U^T (\mathbf{x} - \boldsymbol{\mu})$$

这对应于绕 $U$ 旋转坐标轴并将原点平移至 $\boldsymbol{\mu}$。公式可以写为

```
y_1² / λ_1 + ... + y_l² / λ_l = c
```

由此可以很容易地看出，这是一个描述 $\mathbb{R}^l$ 中（超）椭球面的方程。从公式可以明显看出，它以 $\boldsymbol{\mu}$ 为中心，且椭球面的主轴平行于 $\mathbf{u}_1, \dots, \mathbf{u}_l$（将 $\mathbf{x}$ 替换为标准基向量，$[1, 0, \dots, 0]^T$ 等）。各主轴的大小由相应的特征值控制。这在图 2.6B 中显示。对于对角协方差且对角线元素相等的特殊情况，所有特征值均等于公共对角线元素的值，椭球面变为（超）球面（圆），如图 2.6A 所示。
