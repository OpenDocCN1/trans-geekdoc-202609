
# 恶意软件与恶意代码

在本章中，您将探索各种类型的恶意软件，以及每种恶意软件类型的区别要素、行为和特征。您将了解应寻找的指标、组织用于应对每种恶意软件的响应方法，以及有助于防范它们的控制措施。

最后，您将探索针对旨在防止恶意软件攻击的防护技术和系统的攻击。您将了解对抗性人工智能的概念、针对机器学习（`ML`）系统的攻击，以及 `ML` 算法如何防范对抗性攻击。

术语 `malware` 描述了一系列有意设计用于对系统和设备、网络或用户造成危害的软件。恶意软件还可以收集信息、提供非法访问，并采取广泛的行动，而这些行动可能是系统或网络的合法所有者不希望发生的。`SY0-601 Security+` 考试目标包含许多最常见的恶意软件类型，您需要熟悉其中的每一种，如何区分它们，如何识别它们，以及对抗它们的常用技术。

## 勒索软件

`Ransomware` 是一种接管计算机然后索要赎金的恶意软件。勒索软件有多种类型，包括加密恶意软件，它会加密文件，然后将其作为人质，直到支付赎金为止。其他勒索软件技术包括：威胁因盗版软件或色情内容向执法部门举报用户，或威胁暴露受害者硬盘或设备中的敏感信息或图片。

防范勒索软件最重要的防御措施之一，是一个有效的备份系统，它将文件存储在一个单独的位置，这样即使被其备份的系统或设备遭到勒索软件感染并加密，备份也不会受影响。准备应对勒索软件的组织需要确定其响应策略；在某些情况下，支付赎金导致文件被返还，而在其他情况下，攻击者只是索要更多钱财。

## 特洛伊木马

`Trojans`（特洛伊木马）是一种通常伪装成合法软件的恶意软件。之所以称它们为特洛伊木马，是因为它们依赖毫无戒心的个人运行它们，从而为攻击者提供了一条进入系统或设备的路径。`远程访问特洛伊木马` 为攻击者提供对系统的远程访问权限。一些合法的远程访问工具被用作 `RATs`，这使得很难判断一个工具是合法的远程支持工具，还是攻击者用于远程访问的工具。反恶意软件工具在发现可能被用作 `RATs` 的远程访问工具时，也可能导致误报，但禁用此检测功能可能导致 `RATs` 未被检测到。安全从业者通常结合使用安全意识培训——鼓励用户不下载不可信软件——以及能够检测特洛伊木马和 `RAT` 类行为及已知恶意文件的反恶意软件工具，来对抗特洛伊木马和 `RATs`。

## 蠕虫

与需要用户交互的特洛伊木马不同，`worms`（蠕虫）会自我传播。虽然蠕虫通常与利用脆弱服务进行传播联系在一起，但任何类型的自动化传播手段都是可能的，这意味着蠕虫也可以通过电子邮件附件、网络文件共享或其他方法进行传播。蠕虫还会自我安装，而不需要用户点击它们，这使它们非常危险。

## Rootkit（Rootkit/隐藏型恶意软件）

`Rootkits` 是专门设计用于允许攻击者通过后门访问系统的恶意软件。许多现代 Rootkit 还包含旨在通过多种技术隐藏自身以逃避检测的功能，这些技术范围从利用文件系统驱动程序确保用户无法看到 Rootkit 文件，到感染磁盘主引导记录（`MBR`）中的启动代码，从而允许针对全盘加密系统发起攻击。

Rootkit 检测具有挑战性，因为感染了此类恶意软件的系统不再可信。这意味着检测 Rootkit 的最佳方法是从受信任的系统或设备测试疑似系统。在无法做到这一点的情况下，Rootkit 检测工具会寻找 Rootkit 典型的行为和特征码。完整性检查和针对预期响应的数据验证等技术对于 Rootkit 检测也很有用，反 Rootkit 工具通常结合使用这些技术来检测复杂的 Rootkit。

一旦发现 Rootkit，清除工作可能很棘手。虽然一些反恶意软件和反 Rootkit 工具能够清除特定的 Rootkit，但只要条件允许，最常见的建议是重建系统或从已知良好的备份中恢复。随着虚拟机、容器、系统镜像和软件定义环境变得更加普遍，它们简化了恢复流程，在许多情况下，恢复速度可能与确保感染 Rootkit 的系统已被正确且彻底清理的速度一样快，甚至更快。

与您将在此处读到的许多恶意软件类型一样，防范 Rootkit 的最佳方法是常规安全实践，包括打补丁、使用安全配置，并确保使用权限管理。安全启动等工具以及可验证实时系统和文件的技术，也可用于帮助防止 Rootkit 成功安装或持久驻留。

## 后门

`Backdoors`（后门）是绕过正常身份验证和授权程序、允许攻击者访问系统、设备或应用程序的方法或工具。后门可以基于硬件或软件，但在 `Security+` 考试的大多数场景中，您将关注基于软件的后门。

与我们在此讨论的许多恶意软件类型一样，恶意软件感染可能包含多种恶意软件工具。事实上，特洛伊木马和 Rootkit 通常包含后门，以便攻击者访问它们已感染的系统。

正如 Rootkit 一样，软件和硬件制造商有时也会使用后门为系统和软件提供持续访问权限。制造商安装的后门令人担忧，因为它们可能未被披露，如果被攻击者发现，它们可以提供您可能不知情的访问权限。

检测后门有时可以通过检查意外开放的端口和服务来完成，但更复杂的后门工具可能利用现有服务。示例包括基于 Web 的后门，它们在现有 Web 服务下需要不同的 `URL`，以及通过使用加密或混淆通道隧道传输到远程控制主机来隐藏其流量的后门。

## 僵尸程序

`Bots`（僵尸程序/受控端）是感染了恶意软件的受远程控制系统或设备。僵尸程序组被称为 `botnets`（僵尸网络），攻击者控制僵尸网络以执行各种操作，范围从进一步的入侵和感染，到拒绝服务攻击或充当垃圾邮件中继。大型僵尸网络可能涉及数十万个僵尸程序，有些总数甚至达到数百万。

许多僵尸网络 `命令与控制`（`C&C`）系统以客户端-服务器模式运行，如图 3.1 所示。在此模型中，它们将联系中央控制系统，后者提供命令和更新，并跟踪僵尸网络中有多少系统。互联网中继聊天（`IRC`）过去常用于管理客户端-服务器僵尸网络，但许多现代僵尸网络依赖安全 `HTTP`（`HTTPS`）流量来帮助隐藏 `C&C` 流量，并防止防御者轻松监控和分析。

### 对等僵尸网络控制模型

除了客户端-服务器僵尸网络外，图 3.2 所示的对等僵尸网络控制模型也经常被使用。对等网络将僵尸节点相互连接，这使得攻击者更难通过攻陷单个中央服务器或少量已知的 C&C IP 地址或域名来摧毁网络。加密的对等流程可能极难识别，尽管监控网络流量以查找基于行为的模式以及大型多组织数据集的机器学习工具可以提供帮助。

![图 3.2 对等僵尸网络控制模型](img/c03f002.png)

**图 3.2** 对等僵尸网络控制模型

许多僵尸网络使用快速通量 DNS，它利用许多 IP 地址来响应一个或多个完全合格域名的查询。频繁更新（快速通量）意味着控制主机网络中的许多系统会持续不断地注册和注销其地址，通常每隔几分钟就进行一次。更高级的技术还会对 DNS 区域的 DNS 服务器执行类似的快速更改，使网络更难被摧毁。在受控网络中，可以通过强制 DNS 请求使用组织控制的 DNS 服务器，而不是允许出站 DNS 请求，来防御此类技术。记录所有 DNS 请求在恶意软件狩猎时也能提供有用信息，因为机器生成的 DNS 条目在日志中通常很容易被发现。虽然 IRC 过去常用于僵尸网络控制，但较新的僵尸网络通常使用快速通量 DNS 和伪装成看似无害的 Web、DNS 或其他流量的加密 C&C 通道。

检测僵尸网络通常通过使用网络监控工具（如 IPS 和 IDS）及其他网络流量分析系统来分析僵尸流量来完成。通过逆向工程和分析与僵尸网络相关的恶意软件感染可收集更多数据。底层恶意软件可使用防病毒和反恶意软件工具，以及端点检测和响应工具等进行检测。

#### 僵尸网络与分布式拒绝服务 (DDoS) 攻击

僵尸网络可用于攻击服务和应用程序，针对应用程序的分布式拒绝服务 (DDoS) 攻击是僵尸网络的一种常见应用。僵尸网络依赖其规模（可淹没应用程序和服务）以及其中系统的数量（使得几乎无法识别哪些主机在恶意消耗资源或发送带有恶意意图的看似合法流量）。

识别僵尸网络驱动的 DDoS 攻击需要监控网络流量、趋势，有时还需要来自互联网服务提供商的上游可见性。其症状可能难以与合法流量的大幅增长区分开来，这意味着可能需要安全信息和事件管理 (SIEM) 系统等安全工具，它们能关联来自多个来源的数据。行为分析工具也有助于将 DDoS 与更典型的流量模式区分开来。

#### 键盘记录器

`键盘记录器` 是从键盘捕获按键的程序，尽管键盘记录器应用程序也可能捕获其他输入，如鼠标移动、触摸屏输入或连接设备的信用卡刷卡数据。键盘记录器的工作方式多种多样，范围从从内核捕获数据的工具，到 API 或脚本，甚至直接从内存捕获。无论它们如何捕获数据，键盘记录器的目标都是捕获用户输入，以便攻击者分析和利用。

防止软件键盘记录通常侧重于常规安全最佳实践，以确保不安装包含键盘记录器的恶意软件，包括打补丁和系统管理，以及使用反恶意软件工具。由于许多键盘记录器旨在窃取密码，使用多因素认证 (MFA) 可以帮助限制键盘记录器的影响，即使它无法完全击败键盘记录器本身。

在底层系统不可信的更复杂的安全环境中，使用可启动的 USB 驱动器可以防止使用潜在受损的底层操作系统。

#### 逻辑炸弹

与此处描述的其他类型恶意软件不同，`逻辑炸弹` 不是独立的恶意程序。相反，它们是放置在其他程序内部的函数或代码，当设定的条件满足时就会激活。某些恶意软件使用此类代码在特定日期或满足一组条件时激活。虽然与其他类型的恶意软件相比相对罕见，但逻辑炸弹是软件开发和系统管理中的一个考量因素，如果成功激活，可能会产生重大影响。

## 病毒

计算机`病毒` 是能够自我复制和自我传播的恶意程序。病毒需要一种或多种感染机制来传播自身，通常配合某种搜索能力以寻找新的传播目标。病毒通常还具有`触发器`（设定病毒执行的条件）和`有效载荷`（病毒所做、投递或执行的动作）。病毒种类繁多，包括：

- **驻留型病毒**，在系统或设备运行时保留在内存中
- **非驻留型病毒**，执行、传播，然后关闭
- **引导扇区病毒**，驻留在驱动器或存储介质的引导扇区内
- **宏病毒**，利用文字处理软件或其他工具内部的宏或代码进行传播
- **电子邮件病毒**，通过电子邮件作为附件或作为邮件本身的一部分利用电子邮件客户端中的缺陷进行传播

### 无文件病毒

`无文件病毒` 攻击在许多关键方面与传统病毒相似。它们通过垃圾邮件和恶意网站等方式传播，并利用浏览器插件和 Web 浏览器本身的缺陷。一旦成功进入系统，它们会将自身注入内存并进行进一步的恶意活动，包括通过注册表项或其他技术在重启时通过相同过程重新感染系统的能力。在其整个活跃生命周期中，它们始终驻留在内存中，从不需要本地文件存储——事实上，许多无文件攻击唯一的存储痕迹就是其持久化技术的痕迹，如图 3.3 所示的注册表项。

## 间谍软件

**间谍软件**是一种旨在获取个人、组织或系统信息的恶意软件。间谍软件有多种类型，每种类型针对不同类型的信息。许多间谍软件包会追踪用户的浏览习惯、已安装软件或类似信息，并将其回传至中央服务器。有些间谍软件相对无害，但也存在恶意间谍软件，它们以敏感数据为目标，允许远程访问网络摄像头，或以其他方式为其安装所在的系统提供非法或不需要的访问权限。间谍软件与身份盗窃和欺诈、广告及流量重定向、数字版权管理（DRM）监控以及**跟踪软件**相关联，后者是一种用于非法监控伴侣关系中另一半的间谍软件。

间谍软件最常使用反恶意软件工具来对抗，尽管用户意识有助于防止安装包含在软件安装程序中的间谍软件（从而充当一种特洛伊木马），或通过间谍软件可能看起来像有用工具或无害实用程序的其他途径进行安装。

### 潜在有害程序 (PUP)

虽然许多类型的恶意软件感染具有恶意性，但**潜在有害程序 (PUP)** 是用户可能不需要但不像其他类型恶意软件那样危险的程序。PUP 通常在用户不知情的情况下安装，或作为软件捆绑包或其他安装过程的一部分进行安装。PUP 包括广告软件、浏览器工具栏、Web 浏览器追踪程序等。大多数杀毒软件和反恶意软件程序都可以检测并移除潜在有害程序，组织可以限制用户权限以防止安装额外软件，或限制可安装的软件，从而防止在组织拥有的 PC 上安装 PUP 和其他不需要的应用程序。

如果你确实在系统上看到了 PUP 报告，请记住，你不应立即假定系统已被攻陷，就像你对待本章讨论的其他恶意软件那样。与最终用户讨论安全意识和最佳实践，使用适当的工具进行移除，并恢复正常操作，这可能就是你处理大多数 PUP 安装所需做的一切。

## 恶意代码

恶意软件并非你可能遇到的唯一类型的恶意代码。非恶意软件的脚本和自定义构建的代码也可能被恶意行为者利用。这些攻击可以通过网络连接在本地或远程发生，并且通常利用内置工具，如 `Windows PowerShell` 和 `Visual Basic`，或 Linux 系统上的 `Bash` 和 `Python`。甚至内置于 Microsoft Office 套件中的宏也可能被攻击者利用。

`PowerShell` 是 Windows 内置的脚本语言，因其提供的强大功能而成为恶意行为者的热门目标。`PowerShell` 允许远程和本地执行、网络访问以及许多其他功能。此外，由于它默认可在 Windows 系统上使用且通常不受严格监控，攻击者可以利用它以多种不同方式发起攻击，包括无文件恶意软件攻击，即一旦浏览器或插件被攻破，就在本地执行 `PowerShell` 脚本。

针对 `PowerShell` 攻击的防御措施包括使用受限语言模式，该模式限制 `PowerShell` 中的敏感命令；以及使用 `Windows Defender` 内置的应用程序控制工具或 `AppLocker` 来验证脚本，并限制可运行的模块和插件。开启 `PowerShell` 日志记录以及 Windows 命令行审核也是一个好主意。

许多 Windows 系统都安装了 Microsoft Office，用 `Visual Basic for Applications (VBA)` 编写的 Microsoft Office 宏是攻击者的另一个目标。尽管宏病毒不再像过去那样普遍，但嵌入 Office 文档中的宏以及其他应用程序中的类似功能仍是攻击者的潜在目标，如果在 Office 中发现新漏洞，宏病毒的流行度可能会上升。

对防御者而言幸运的是，Microsoft Office 默认禁用宏。这意味着针对基于宏的恶意软件的主要防御措施是教育用户不要在未知或不可信的文档上启用宏，并对组织通过电子邮件或其他方式接收的任何 Office 文档进行适当的扫描。

`PowerShell`、`VBA` 和宏都在 Windows 系统上很流行，但 Linux 系统也成为攻击目标。攻击者可能将 `Python`、`Perl` 和 `Bash` 等常见语言和工具作为其攻击过程的一部分。这些语言可用于创建使用绑定或反向 Shell 的持久远程访问，以及许多其他有用的漏洞利用工具。`Metasploit` 是一种流行的漏洞利用工具，包含利用上述每种语言的 Rootkit。

防止使用编程语言和 Shell 等内置或预先存在的工具可能很困难，因为它们是用户与其所在系统进行交互和使用的重要组成部分。这使得防止攻击者通过漏洞、被攻陷的账户和其他方式访问系统的安全措施成为最重要的防御层之一。

值得庆幸的是，现有工具如 `chkrootkit` 和 `rkhunter` 可用于搜索 Rootkit，帮助防御者搜索和识别 Rootkit。基于行为的安全工具也可以监控系统日志和网络流量，帮助防御者识别被攻陷的系统。

## 对抗性人工智能

**对抗性人工智能**是一个新兴领域，攻击者利用人工智能 (AI) 实现恶意目的。对抗性 AI 攻击的重点目前倾向于数据投毒，向安全和分析 AI 及 ML 算法提供服务于攻击者目的的对抗性输入，或针对隐私的攻击。

了解此处使用的两个关键术语会有所帮助。第一个是**人工智能**，其重点是通过结合机器学习、深度学习及旨在模拟人类智能的相关技术来完成“智能”任务。第二个是**机器学习**，它是 AI 的一个子集。ML 系统在演进过程中会自我修改，以更好地完成其设定的任务。

随着 AI 和 ML 在安全工具集和企业分析工具中变得越来越普遍，驱动机器学习系统的训练数据被有意或无意地污染，从而提供错误响应的危险也在持续增长。一个简单的例子是：组织部署了一个网络监控工具，研究典型网络流量以建立正常行为的基线。如果网络上的系统已经被攻陷，那么基线将包含一个假设，即被攻陷系统的行为是正常的！

每项新技术都为攻击者提供了新的攻击面，ML 也不例外。**机器学习算法的污染训练数据**将成为目标，而**机器学习算法本身的安全性**将变得越来越重要。同时，随着 ML 工具和技术使用的增加，新的攻击和防御技术也将随之开发。作为安全分析师，你现在可以采取一些基本步骤：

- 了解源数据的质量和安全性。
- 与 AI 和 ML 开发人员合作，确保他们在安全环境中工作，并且数据源、系统和工具以安全的方式进行维护。
- 确保对 AI 和 ML 算法的更改经过审查、测试和记录。
- 鼓励审查以防止算法中出现有意或无意的偏见。
- 尽可能聘请领域专家。

## 总结

### 恶意软件概述

恶意软件有多种形式。

- **勒索软件**：加密您的文件，或威胁在您不付款或不执行某项操作时泄露您的数据。
- **特洛伊木马**：外观看似合法软件，实则为恶意程序。
- **蠕虫**：自我传播，通常以易受攻击的应用程序或服务为目标。
- **Rootkit**：帮助攻击者访问系统并长期维持访问权限。
- **后门**：绕过身份验证和系统安全，允许攻击者（有时甚至是合法用户）通过隐蔽的访问方法进入系统。
- **僵尸程序**：使系统成为命令与控制网络的一部分，允许攻击者同时控制大量系统执行诸如发起 DDoS 攻击等操作。
