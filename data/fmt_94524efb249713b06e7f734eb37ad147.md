### 13.21 DP 的棒断构造

DP 的棒断构造建立在以下规则之上：

$$P_1 = \beta_1 \sim \text{Beta}(\beta|1, \alpha)$$

$$\beta_i \sim \text{Beta}(\beta|1, \alpha), \quad (13.153)$$

$$P_i = \beta_i \prod_{j=1}^{i-1} (1 - \beta_j), \quad i \geq 2. \quad (13.154)$$

证明如果步数是有限的，即我们假设对于某个 $T$，有 $P_i = 0, \ i > T$，那么 $\beta_T = 1$。

### 13.23 IBP 概率

$$P(Z) = \prod_{k=1}^{K} \frac{\alpha}{K} \frac{\Gamma\left( m_k + \frac{\alpha}{K} \right) \Gamma\left( N - m_k + 1 \right)}{\Gamma\left( N + 1 + \frac{\alpha}{K} \right)}$$

以及

$$P([Z]) = \frac{K!}{\prod_{h = 0}^{2^{N} - 1}K_{h}!}\prod\limits_{k = 1}^{K}\frac{\alpha}{K}\frac{\Gamma\left( m_{k} + \frac{\alpha}{K} \right)\Gamma\left( N - m_{k} + 1 \right)}{\Gamma\left( N + 1 + \frac{\alpha}{K} \right)},$$

分别。注意 `K[h]`，`h = 1, 2, …, 2^(N) − 1` 是与第 `h` 个非零二进制数相关联的行向量在 `Z` 中出现的次数。
