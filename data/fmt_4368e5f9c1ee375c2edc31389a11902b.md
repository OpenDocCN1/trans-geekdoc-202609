## 10.2 稀疏促进算法

### 10.2.1 贪婪算法

在上一章中，我们的重点是强调从欠定线性方程组恢复稀疏信号/参数向量的理论中一些最重要的方面。现在我们将注意力转向该问题的算法层面（例如，[52,54]）。目前的问题变成了讨论能够实现未知参数集恢复的*高效*算法方案。在第 9.3 节和第 9.5 节中，我们看到约束 `ℓ₁` 范数最小化（基追踪）可以通过线性规划技术求解，LASSO 任务可以通过凸优化方案求解。然而，此类通用技术往往效率低下，因为它们通常需要许多迭代才能收敛，且相应的计算资源对于实际应用可能过大，尤其是在高维空间 `ℝˡ` 中。因此，为了开发针对这些特定任务量身定制的高效算法，投入了大量的研究精力。我们的目标是为读者提供一些表征相关研究活动的总体趋势和理念。我们将重点关注最常用和被引用最多的算法，这些算法在结构上同时也很简单，因此读者无需深厚的优化知识即可理解它们。此外，这些算法以某种方式涉及的论据，与我们在阐述理论时已使用的概念直接相关；因此，它们也可以从教学角度被利用，以加深读者对该主题的理解。我们首先回顾批处理算法这一类，其中假设所有数据在算法应用前均可用，然后我们将转向在线/时变自适应方案。此外，我们的重点在于适用于任意感知矩阵的算法。之所以这样说明，是为了指出在文献中，针对特定形式的高度结构化感知矩阵，也开发了高效算法，利用其特定结构可降低计算需求 [61,93]。

这类算法研究活动大致沿着三个家族发展：(a) 贪婪算法，(b) 迭代收缩方案，和 (c) 凸优化技术。我们使用“大致”一词是因为在某些情况下，很难将某个算法归属到特定家族。

#### 贪心算法与正交匹配追踪

贪心算法由来已久；例如，参考文献 [114] 提供了详尽的参考文献列表。在字典学习的背景下，一种称为*匹配追踪*的贪心算法在文献 [88] 中被提出。贪心算法建立在一系列*局部*最优*单项*更新之上。在我们的语境中，目标是 (a) 揭示感知矩阵 `X` 的“活跃”列，即对应未知参数非零位置的那些列，以及 (b) 估计相应的稀疏参数向量。对应非零向量分量的索引集也称为*支撑集*。为此，`X` 的活跃列集合（以及支撑集）在每一迭代步骤中增加一列。

在后续过程中，将获得未知稀疏向量的更新估计。假设在第 `(i-1)` 次迭代步骤中，算法已选定记为 `x[j[1]]^(c)`、`x[j[2]]^(c)`、...、`x[j[i-1]]^(c)` 的列，其中 `j[1]`、`j[2]`、...、`j[i-1]` ∈ {1, 2, ..., `l`}。这些索引是当前可用支撑集 `S^((i-1))` 的元素。令 `X^((i-1))` 为 `N × (i-1)` 矩阵，其列为 `x[j[1]]^(c)`、`x[j[2]]^(c)`、...、`x[j[i-1]]^(c)`。另令当前解的估计为 `θ^((i-1))`，这是一个 `(i-1)`-稀疏向量，在支撑集索引之外的所有位置均为零。文献 算法 10.1 中给出的*正交匹配追踪*（OMP）方案递归地构建稀疏解。

##### 算法 10.1：OMP 算法

该算法通过 `θ^((0)) := 0`、`e^((0)) := y` 和 `S^((0)) = ∅` 进行初始化。在第 `i` 次迭代步骤中，执行以下计算步骤：

###### 1. Select the column

选择 `X` 的列 `x[j[i]]^(c)`，该列与相应的误差向量 `e^((i-1)) := y - Xθ^((i-1))` **最大程度相关**（即形成最小角度），即：

```
x_{j_i}^c: j_i := {arg max}_{j = 1,2,...,l} |(x_j^c)^T e^{(i-1)}| / ||x_j^c||_2.
```

###### 2. Update the support and the corresponding set of active columns

更新支撑集和相应的活动列集合，`S^((i)) = S^((i-1)) ∪ {j[i]}` 和 `X^((i)) = [X^((i-1)), x[j[i]]^(c)]`。

###### 3. Update the estimate of the parameter vector

更新参数向量的估计：仅使用 `X` 的活动列，求解使误差范数最小的最小二乘（LS）问题，即：

```
θ̃ := arg min_{z ∈ ℝ^i} ||y - X^{(i)}z||_2^2.
```

#### 算法步骤

1.  通过将 `θ̃` 的元素插入相应位置 `(j_1, j_2, ..., j_i)`（即支撑集）来获得 `θ^((i))`（其余 `θ^((i))` 的元素保持零值）。

2.  更新误差向量：

    ```
    e^{(i)} := y - Xθ^{(i)}.
    ```

算法在误差范数小于预选的用户定义常数 `ε₀` 时终止。以下是相关备注。

###### 备注 10.1

*   因为步骤 3 中的 `θ^((i))` 是最小二乘（LS）任务的结果，根据第 6 章可知，误差向量与涉及的活动列所张成的子空间正交，即：

    ```
    e^{(i)} ⊥ span{x_{j_1}^{(c)}, ..., x_{j_i}^{(c)}}.
    ```

    这保证了在下一步中，计算 `X` 的列与 `e^{(i)}` 的相关性时，之前选定的列不会被重新选中；它们因与 `e^{(i)}` 正交而产生零相关性（见图 10.1）。

    **图 10.1** 第 `i` 次迭代的误差向量正交于当前可用活动列张成的子空间。此处为三维欧几里得空间 `ℝ³` 且 `i=2` 时的示意图。

*   与当前可用误差向量具有最大相关性（内积绝对值最大）的列，是在用当前可用活动列线性组合近似 `y` 时，相比其他任何列能最大程度减小误差的 `ℓ₂` 范数。这是贪婪策略的核心所在。这种最小化是针对单一项进行的，其余项保持固定，因为它们是从前序迭代步骤获得的（见问题 10.1）。

*   从所有分量为零开始，若算法在 `k₀` 次迭代后停止，结果将是一个 `k₀`-稀疏解。

*   注意，这种搜索策略不保证最优性。唯一的保证是误差向量的 `ℓ₂` 范数在每一步迭代中都减小。一般来说，无法保证算法能获得接近真实解的结果（例如文献 [38]）。然而，在对 `X` 结构施加特定约束下，可以获得性能界（例如文献 [37, 115, 123]）。

算法的复杂度为 `𝒪(k₀lN)` 次操作，这主要源于相关性的计算，加上第 3 步中求解最小二乘（LS）任务的需求，其复杂度取决于所使用的具体算法。`k₀` 是所得解的稀疏度，因此也是执行的总迭代步数。

另一个证明基于误差向量相关性选择列合理性的定性论证如下。假设矩阵 `X` 是标准正交的。令 `y = Xθ`。则 `y` 位于 `X` 的活动列张成的子空间中，即那些对应 `θ` 非零分量的列。因此，其余列与 `y` 正交，因为假设 `X` 是标准正交的。在第一步迭代中，计算 `y` 与所有列的相关性，可以确定会选择其中一个活动列。非活动列产生零相关性。类似的论证对所有后续步骤均成立，因为所有活动都发生在一个与 `X` 的所有非活动列正交的子空间中。在 `X` 不标准正交的更一般情况下，我们仍可将相关性作为量化几何相似性的度量。相关性/内积幅度越小，两个向量越正交。这将我们带回相互相干性的概念，它是 `X` 的列之间最大相关性（最小夹角）的度量。

###### OMP 可恢复最优稀疏解：充分条件

我们已经指出，通常无法保证 OMP 能恢复最优解。然而，当未知向量相对于感测矩阵 `X` 的结构具有足够的稀疏性时，OMP 可以精确求解公式 (9.20) 中的 `ℓ₀` 最小化任务，并在 `k₀` 步内恢复解，其中 `k₀` 是满足相关线性方程组的最稀疏解。

**定理 10.1**

设感测矩阵 `X` 的相互相干性（第 9.6.1 节）为 `μ(X)`。假设线性系统 `y = Xθ` 接受一个满足以下条件的解：

```
||θ||₀ < ½ (1 + 1/μ(X))
```

(10.1)

则 OMP 保证在 `k₀ = ||θ||₀` 步内恢复最稀疏解。

根据第 9.6.1 节，在上述条件下，任何其他解必然稀疏度更低。因此，用 `k₀` 个 `X` 的列来表示 `y` 的方式是唯一的。在不失一般性的前提下，假设真实支撑集对应于 `X` 的前 `k₀` 列，即：

```
y = Σ_{j=1}^{k₀} θ_j x_j^c,  θ_j ≠ 0,  ∀ j ∈ {1,…,k₀}.
```

该定理是以下命题的直接推论。

**命题 10.1**

如果条件 (10.1) 成立，则 OMP 算法永远不会选择真实支撑集之外索引的列（参见例如文献 [115] 和问题 10.2）。用更正式的方式表述为：

```
j_i = {arg max}_{j = 1,2,...,l} |(x_j^c)^T e^{(i-1)}| / ||x_j^c||_2 ∈ {1,...,k₀}.
```

![Equation](img/si38.png)

该命题的几何解释如下。如果在 `ℝˡ` 空间中，`X` 的所有列向量之间任意两两组合形成的夹角都接近 90°（列向量近似正交），这保证了 `μ(X)` 足够小，那么与那些不参与生成 `y` 线性组合的非活跃列向量相比，`y` 将更倾向于（形成更小的角度）参与其形成的任意一个活跃列向量。图 10.2 说明了这种几何关系，涵盖了向量互相正交的极端情况（图 10.2A），以及向量不正交但任意两列向量之间的夹角足够接近 90° 的更一般情况（图 10.2B）。

![Figure 10.2 (A) In the case of an orthogonal matrix, the observations vector y will be orthogonal to any inactive column, here, x[3]^(c). (B) In the more general case, it is expected to “lean” closer (form smaller angles) to the active than to the inactive columns.](images/B9780443292385000160/gr002.jpg)

图 10.2 （A）在正交矩阵的情况下，观测向量 `y` 将与任何非活跃列向量正交，此处为 `x[3]^(c)`。 （B）在更一般的情况下，预期 `y` 会更“倾向于”（形成更小的角度）活跃列向量，而非非活跃列向量。

简而言之，上述命题保证了在第一次迭代中，将选中一个对应于真实支撑集的列向量。以类似的方式，这对所有后续迭代也同样成立。在第二步中，将选择另一个不同于先前所选的列向量（如前所述）。在第 `k₀` 步，将选中对应于真实支撑集的最后一个剩余活跃列向量，这必然导致零误差。为此，只需将 `ε₀` 设为零即可。

####### LARS 算法

最小角回归（LARS）算法 [48] 与 OMP 共享前两个步骤。它选择 `j[i]` 为当前可用活跃集之外的一个索引，以使与残差向量的相关性最大化。然而，它不是通过执行最小二乘（LS）拟合来计算 `θ^((i))` 的非零分量，而是计算这些分量，使得残差向量与活跃集中的所有列向量等相关，即：

```
|x[j]^(c)^T(y - Xθ^((i)))| = constant, ∀j ∈ S^((i)),
```

![Equation](img/si43.png)

我们假设 `X` 的列已归一化，这在实践中很常见（另请回顾 备注 9.4）。换句话说，与 OMP 强制误差向量与活动列正交不同，LARS 要求该误差与每个活动列形成相等的角度。与 OMP 一样，可以证明，只要目标向量足够稀疏且 `X` 的列满足非相干性，LARS 就能精确恢复最稀疏解 [116]。

进一步的微小修改引出了 LARS-LASSO 算法。根据该版本，活动集中先前选定的索引可以在后续阶段被移除。这赋予了算法从先前的错误决策中“恢复”的潜力。因此，这种修改背离了定义贪婪算法的严格基本原理。事实证明，该版本求解 LASSO 优化任务。该算法与文献 [99] 中建议的算法相同，被称为*同伦*算法。同伦方法基于从一个优化任务到另一个优化任务的连续变换。这一系列任务的解位于一条连续的参数化路径上。其思想是：虽然优化任务本身可能难以求解，但可以通过缓慢改变参数来追踪这条解路径。对于 LASSO 任务，变化的是参数 `λ`（例如见 [4,86,104]）。以公式 (9.6) 中的正则化版 LASSO 任务为例。当 `λ = 0` 时，任务最小化 `ℓ₂` 误差范数；当 `λ → ∞` 时，任务最小化参数向量的 `ℓ₁` 范数，此时解趋于零。事实证明，当 `λ` 从大值变化到小值时，解路径是折线的。该解路径上的顶点对应的向量仅在条目子集上具有非零元素。该子集保持不变，直到 `λ` 达到下一个临界值，这对应于折线路径的一个新顶点和一个新的潜在非零值子集。因此，解是通过沿这条折线路径的一系列步骤获得的。

##### 压缩感知匹配追踪（CSMP）算法

严格来说，此处讨论的算法并非贪婪算法，但正如文献 [93] 所述，它们本质上是贪婪算法。与 OMP 在每次迭代步骤中执行单项优化以使支撑集增加一项不同，这些算法试图首先获得支撑集的估计，然后利用该信息计算目标向量的最小二乘（LS）估计，约束在相应的活动列上。该方法的精髓在于感知矩阵的近正交性质，假设其满足 RIP 条件。
