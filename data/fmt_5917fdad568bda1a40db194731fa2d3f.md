## 12 黑客性格

### 案例研究

通过研究许多讲述或撰写他们作为黑客或网络犯罪经历的人，我们似乎可以通过分析他们的性格来获得关于他们成就的知识。

在社区内多年有名的人是凯文·密特尼（Kevin Mitnick）。密特尼在入侵电话网络（电话诈骗）方面取得了巨大成功，直到他在 80 年代进入联邦监狱。随后，他成为一名有影响力的作家和演讲者。他著名的著作之一是《The Art of Intrusion: The Real Stories Behind the Exploits of Hackers, Intruders and Deceivers》，与威廉·西蒙（William Simon）合著（Mitnick and Simon, 2005）。

这本书详细描述了许多黑客的经历，据称是真实故事，并在许多案例中描述了了足够的兴趣和动机，让我们对他们的性格有一定的见解。

### 12.1 Comrade

被称为 Comrade 的黑客在迈阿密当青少年时就开始了他的活动。关于他的一些早期作品，Comrade 说，“我们是为了好而进入政府网站。”Comrade 与另一个名为 neoh 的黑客建立了友谊，另一个年轻人只比 Comrade 大一岁，但住在 3000 英里外。关于他的兴趣，neoh 说，“我不知道我为什么一直这样做。强迫性人格？贪财？还是对权力的渴望？我可以列出许多可能性。”此外，neoh 在与作者密特尼通信时写道：“你启发了我……我读了关于你所做的一切信息。我想像你一样成为一个名人。”

另一个名叫 Khalid Ibrahim 的人，他自称来自巴基斯坦，开始招募 `Comrade` 和 `neoh`。Khalid 的兴趣在于与其他黑客合作，这些人可能愿意入侵特定的目标——首先是处处，然后是美国。Khalid 表示，如果成功渗透他所指定的目标，他将支付现金。

`Comrade` 的兴趣正如他所指出的那样，他知道 Khalid “正在给人付钱，但我从未想为了钱而交出我的信息。我觉得我做的事情只是到处看看，但如果我开始收钱，我就会变成一个真正的罪犯。”

### 12.2 Adrian Lamo

艾德里安·拉莫（Adrian Lamo）在青少年时期住在新英格兰，并在很早的时候就培养了自己的黑客技能。

根据他父母的话，L 先生参与黑客活动是因为几位特定的知名黑客给了他灵感。他的黑客策略是理解攻击目标（即某个特定程序或网络）的设计者的思维过程。在某个案例中，他发现一个请求协助处理盗信用卡号码的客户，而本该提供帮助的技术人员根本没有理会。随后，艾德里安给受害者打了电话，询问他是否收到过回复。当那个男人说没有时，艾德里安转发了正确的答案以及关于该问题的所有相关文档。正如 Lamo 所：“我从中获得了满足感，因为我想要相信这样一个宇宙：像你的数据库被某人窃取这种不可思的事情……可以在一年后由一个攻破了你最初信任的公司的入侵者给出解释。”

艾德里安对他哲学的描述可以总结为：“我相信任何复杂系统都有共同点，无论是计算机还是宇宙……对我来说，黑客行为与其说是关于技术，倒不如说是关于宗教。”

### 12.3 Gabriel

加布里尔（Gabriel）住在加拿大的一个小镇上，他的母语是法语。尽管他认为自己是一个白帽黑客，但当发现某个“安全性如此糟糕，需要给别人教训”的网站时，他偶尔也会实施恶意行为。年轻时，他发现了美国南部一家小银行的 `IP addresses` 详情，尽管该银行拥有广泛的国家和国际联系。他发现该银行的一台服务器运行着允许用户远程访问工作站的软件。最终，他找到了远程访问 `terminal service` 的方法，因此他基本上可以拥有那个潜在系统。他还找到了银行防火墙的密码，因此攻入那台机器让他能够访问同一网络上的其他计算机系统。结果，加布里尔接触了大量的内部信息，但他对盗取资金没有任何兴趣。“我在他们的服务器上发现了很多关于物理安全的文档，但没有一个和黑客有关的……他们在物理安全方面做得很好，但对计算机安全来说还不够。”

### 12.4 Eric

埃里克（Eric）是一名安全顾问，他经常抱怨道“当我报告一个漏洞时，我经常听到：‘这没什么什么。有什么大不了的？’”。埃里克和他的一些同事承认收集了不同类型的服务器软件，并达到了拥有该类别中所有主要产品源代码的程度，仅此一个例外。埃里克说：“这是我最后一个没有的，我不知道为什么，对我来说攻入那一个很有趣。”埃里克坚持追求这一目标一年多，最终“我终于找到了 CEO 的电脑，那挺有意思的。我对它进行了 `port-scanned` 几天，一直没有任何响应，但我知道他的电脑就在那里。”

事实证明，CEO 使用笔记本电脑，每天早上只开启大约 2 小时。他会进入办公室，检查邮件，然后离开。埃里克感到受到了挑战，并尝试确定 CEO 的密码：“你知道，事实是，我无法解释它。这只是我的一种猜密码的能力。我能预判人们使用的密码。我也有这种感觉，我能预判他们未来会使用什么密码。”（注：此处翻译处根据语境，原文中 `port-scanned` 之后为动词，但结尾处原文似乎略显生乱或重复，已按逻辑通达意译）

### 12.5 Whurley

从米特尼克（Mitnick）的书中选出的最后一个例子涉及一个绰名为 `Whurley` 的安全顾问。他被拉斯维加斯的一家度假村聘用进行安全审计。他注意到本该提供服务的员工非常疏忽，包括一名员工经常丢失工牌以获得免费食物。“当我走出去时，我看到一个空位。她大方地让我坐在她的桌子旁。当我去洗手间时，她给了我密码。所以我告诉她我要 `network security` 并向她展示无线接入点。她回答说：‘随便，我不懂那些极客的东西。’”

除了描述个人黑客性格外，许多作者还尝试描述通用的性格特征。

### 12.6 黑客性格描述

李·蒙森（Lee Munson）是 `Comparitech` 的安全研究员，也是 `Sophos Naked Security` 博客的贡献者。蒙森写道：

> “很难定义黑客的少数几个性格特征。一个典型的黑客画像是一个男性，年龄 14 到 40 岁，智力高于平均水平，对技术充满执着的奇心，不墨成规，内向，并且有着广泛的知识兴趣。黑客的动力是学习关于他们感兴趣的主的一切。”

事实上，大多数在技术方面表现出色的黑客并没有技术方面的爱好或兴趣。黑客倾向于吞噬信息，将其储存起来，以备未来某个随机的技术琐事可以帮助他们解决有趣的问题。

经济利益驱动着一些破解者。信用卡和银行欺诈提供了利用破解增加个人财富的机会。

埃里克·斯蒂芬·雷蒙德（Eric Stephen Raymond）是 `Open Source Initiative` 的联合创始人，这是一个建立黑客社区与商业世界之间桥梁的组织。雷蒙德写道：

> “虽然高智力在黑客中很常见，但它并不是人们预期的先决条件。另一个特征可能更为重要：大脑吸收、保留和引用大量‘无意义’细节的能力，并信任后来的经验能赋予其背景和意义。一个分析能力平平但拥有这种特征的人可以成为有效的黑客，但缺乏这种特征的天才很快会被那些经常将厚厚的参考手册内容录入大脑的人所超越。[例如，在本文档的第一版书籍制作期间，我仅用了四个工作日就学会了相当复杂的排版语言 TeX，主要是通过阅读肯纳斯那 477 页的手册。我的编辑对此的震惊反应真的让我感到意外，因为多年与黑客打交道让我习惯将这种表现视为常态且意料之中的。——ESR]”

与刻板印象相反，黑客通常智力上并不狭隘；他们倾向于对任何能提供精神刺激的主题感兴趣，并且能够以专业甚至有趣的方式论述许多冷门话题——前提是你能让他们开口说话，而不是让他们立刻回到自己的黑客活动中……

从迈尔斯-布里格斯类型（Myers-Briggs）及类似的心理测量系统来看，黑客似乎集中在相对稀有的 `INTJ` 和 `INTP` 类型；即内向型、直觉型和思考型（与主流文化中占主的外向-感觉型人格相反）。`ENT[JP]` 类型在黑客中也比较集中，但属于少数。

Rick Nauert 在临床、行政和学术医疗保健领域拥有 25 年以上的经验。他目前是落基山健康专业大学（Rocky Mountain University of Health Professionals）健康促进与健康博士项目的副教授。Nauert 将黑客的人格特质比作自闭症的症状（2016 年）。

网络攻击每年给私营和企业部门造成的损失超过 5750 亿美元。虽然安全机构正在寻找“伦理”黑客来帮助对抗此类攻击，但对于导致人们追求并精通黑客技术的格特质，人们知之甚少。

新研究表明，一种被称为 `systemizing`（系统化）的特征为理解黑客的产生和动力提供了洞察。有趣的是，这些人格特质与许多自闭症行为和特征相似。

英国邓邓的阿伯泰大学（Abertay University）心理学系的 Elena Rusconi 博士表示：“我们发现，个体构建和理解系统的动力——被称为 `systemizing`——与黑客技能和专业知识之间存在正相关。”

“特别是，我们发现这种驱动与破解性能之间存在正相关且特定的相关。”

#### 什么是系统化？

`systemizing` 是指倾向于将系统推理和抽象思维应用于事物或经验。理论上认为它存在于一个连续谱上，其另一端是被称为 `empathizing`（共情）的人格特质，即倾向于随和并对他人产生共情。对 `systemizing` 的偏好通常与自闭症或阿斯伯格综合（自闭症的一种较轻形式）有关。

在研究中，Rusconi 的小组发现，志愿者“伦理”黑客在一系列旨在评估其系统化技能的代码破解挑战中，表现远高于平均水平。

### 博弈论

网络安全领域的一项重要技术可以是应用我们所知的博弈论（Morris, 1994; Von Neumann and Morgenstern, 1944）。

出于本课程的目的，我们将仅对博弈论进行介绍性说明，特别是现在所谓的“双人零和游戏”。`zero-sum`（零和）一词是指一种限制，即在这样的游戏中一方获得的任何收益，其对手都会失去。也许这种双人零和游戏最简单的例子涉及抛硬币。硬币的两面标记为 `heads`（正面）或 `tails`（反面），一名玩家抛掷，另一名玩家猜测结果。让我们把这两个玩家称为 `Mary` 和 `Norman`。

#### 收益

按照惯例，我们总是将行玩家的正收益结果标记为正数；列玩家将该值视为损失。

```
| 表 13.1 正面或反面 |
| --- |
| | Norman (列玩家) |
| 选择 | H | T |
| Mary (行玩家) | +1 | -1 |
| | -1 | +1 |
```

更广泛地说，在这样的游戏中，每个玩家都预先知道这个收益矩阵，但博弈论提供了分析方法，使每个玩家能够确定自己的最佳策略。

在这个例子中，抛币者没有策略，但我们可以稍微修改游戏：说不是进行抛掷，而是由 `Mary` 简单选择她的结果之一（`H` 或 `T`），`Norman` 猜测结果，然后他们比较自己的选择。

在这个模型中，每个人都会开发一种策略来确定自己的选择，但快速分析将显示没有获胜策略，因为每个玩家都有 50–50% 的获胜机会。

然而，假设我们创建一个游戏，每个玩家的获胜策略可能不同。例如，有两个玩家，每个人都会喊数字一或二。其中一个玩家被指定为“奇数”——假设是 `Oliver`——另一名玩家是“偶数”，她被称为 `Evelyn`。如果每个玩家所喊数字的和是奇数，`Oliver` 赢得该金额；如果和是偶数，`Evelyn` 赢得该金额。使用上述游戏矩阵模型，我们得到：

```
| 表 13.2 喊出“一”或“二” |
| --- |
| | Evelyn (偶数) |
| 选择 | One | Two |
| Oliver (奇数) | -2 | 3 |
| | 3 | -4 |
```

不要将此游戏或我们的任何一个游戏视为一次性事件，而要考虑如果游戏可以重复，玩家会怎么做。每个人都试图制定一种策略，以增加自己的胜率。其中一种“策略”可能仅仅是对玩法进行随机选择，在这种情况下，在上面的例子中，奥利弗（Oliver）会有 50%的时间选择“一”，在另外 50%的时间内选择“二”。伊芙琳（Evelyn）也会进行类似的推理。

在这种情况下，如果奥利弗选择“一”，他有一半时间会输两美元，另一半时间赢三美元；换句话说，`0.5(−2) + 0.5(3) = +0.5`。

另一方面，如果奥利弗有一半时间选择“二”，他的结果将是 `0.5(3) + 0.5(−4) = −0.5`。因此，从奥利弗的角度来看，他应该一直选择“一”。但伊芙琳并非傻瓜，她会察觉到这一策略，一直选择“二”，从而在每次游戏中赢得三美元。因此，为了让这样的游戏具有竞争性，每位玩家必须确定一种策略，或者说每个潜在选择的概率。

假设奥利弗有 60%（3/5）的时间选择“一”，40%（2/5）的时间选择“二”；那么这种策略（假设伊芙琳随机玩）在他叫“一”时将为他带来净收益 `-2(3/5) + 3(2/5) = 0`，当他叫“二”时，他赢得 `3(3/5) − 4(2/5) = 1/5`。所以，当他叫“一”时随时间持平，而叫“二”时赢得 0.5。
