### B. 学习形成能

我们训练 `SchNet` 模型来预测来自 `CONF` 的 131 个具有最多九个原子的分子的各种性质。遵循 `Gilmer` 等人的方法，我们使用 10000 个分子的验证集。我们对所有性质的 `$P_i$` 原子误差进行求和。

我们使用 `$T$` 个相互作用块和具有 64 个特征维度的原子来预测多达 $10^4$ 个梯度下降参数。由于规模较小，我们没有使用截断。对于高斯展开，我们使用高达 2 Å 的范围来包含原子。预测误差列在表 I 中，其中我们与消息传递神经网络-22 进行了比较，后者使用原子位置的额外键合信息来学习分子表示。`SchNet` 对极化率 `$\alpha$` 和静电势（$R^2$）的预测在准确性方面明显下降。这是由于将能量分解为原子组合，对于这些性质并不合适。对于 `SchNet` 等[29]，我们采用了一种选定的变体[56]，它获得全局表示且不受此问题影响。`SchNet` 在 8 个块中的 2 个块中达到或超过了性能，这是因为对性质不合适的原子组合分解。图 3 显示了 `SchNet` 在 `$T \in \{1, 2, 3\}$` 个相互作用块下对总能量 `$U_i$` 的学习曲线，与具有 `$T=3$` 个相互作用块的性能最好的 DNN 相比。使用 1100 个训练示例，最佳误差仅从 0.01 eV 改进到 0.014 eV，所需的 epoch 数量从 2000 减少到少于 750。

`$r_{cut}$`。对于具有周期性边界条件（PBCs）的原子，每个原子特征向量 `$x_i$` 在所有周期位置上都是等价的，即 `$x_i = x_{i+R}$`。由于卷积的线性线性，因此我们将 PBCs 应用于滤波器，以准确描述原子相互作用，同时保持对单元选择的不变性。对于跨越滤波器 `$W^{(l)}(r_{ij}-r_{ij})$`，我们得到卷积

```
$x_i^{(l+1)} = \frac{1}{n_{neighbors}} \sum_{j \in neighbors} x_j^{(l)} \odot W^{(l)}(r_{ij}-r_{ij})$

$x_i^{(l+1)} = \frac{1}{n_{neighbors}} \sum_{j \in neighbors} x_j^{(l)} \odot (W^{(l)}(r_{ij}-r_{ij}))$
```

由于我们在给定的截断范围内对所有周期进行求和，该滤波器 `$W$` 现在取决于系统的 PBCs。

最后，分子或材料的性质 `$P$` 得于所获得的原子波表示。我们使用全连接预测网络（见图 1）。根据性质是强度型（intensive）还是扩展型（extensive），我们分别通过对原子贡献求和或取平均来计算最终预测值 `$P$`。

由于内部原子嵌入对原子旋转等变，滤波器独立地应用于每个原子，通过对所有邻居原子的连续滤波器卷积，索引等变性在原子表示中得以保留。因此，作为跨原子权重的性质预测保证了不不变性。

在预测原子作用力时，我们使用 `SchNet` 根据原子位置预测能量

```
$\hat{E}(Z_1, ..., Z_n, r_{ij1}, ..., r_{ijn}) = \frac{\partial \hat{E}}{\partial r_i}(Z_1, ..., Z_n, r_{ij1}, ..., r_{ijn})$
```

当使用旋转不变的模型时，这确保了旋转等变的力预测，并保证了能量守恒场。$^{21}$

## F. 训练

我们通过最小化平方损失为每个性质目标 `$P$` 训练 `SchNet`

```
$$\ell(P, P) = ||P - P||^2$$
```

对于分子轨迹的能量和力的训练，我们使用

```
$$\ell((E, F_1, ..., F_n), (\hat{E}, \hat{F}_n)) = \rho ||E - \hat{E}||^2 + \frac{1-\rho}{N_{atoms}} \sum ||F_i - \hat{F}_i||^2 \quad (5)$$
```

其中 `$\rho$` 是能量和力损失之间的权衡。所有模型都使用 `ADAM` 优化器通过小批量随机下降进行训练，批量大小为 32。我们每 100 个 epoch 以 0.996 的比例指数级衰减学习率。在每个实验中，我们将数据划分为给定大小 `$N$` 的训练集，并使用验证集进行早停。由于我们预处理了邻近原子的索引，训练步骤中位于给定截断成本范围内的最大原子数量随系统大小线性缩放。
