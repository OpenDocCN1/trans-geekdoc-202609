### 20.8.3 因子分析器混合模型：压缩感知的贝叶斯视角

让我们回到公式 (20.79) 中的原始模型，并将其重述为一种更“流行”的形式。矩阵 `A` 的维度为 `l × m`，其中 `m < l`，且 `z ∈ ℝ^(m)`。现在令 `m > l`。例如，`A` 的列可能包含一个过完备字典的向量。因此，本节可被视为第 20.6 节的概率对应版本。通过对 `z` 施加稀疏性来表达建模所需的低维性；我们可以用相应的观测值来重写模型 [47]

```
x[n] = A(z[n] ∘ b) + ϵ[n],  n = 1, 2, …, N,
```

其中 `N` 是训练点的数量，向量 `b ∈ ℝ^(m)` 的元素为 `b[i] ∈ {0, 1}, i = 1, 2, …, m`。乘积 `z[n] ∘ b` 是逐点向量乘积，即

```
z[n] ∘ b = z[nb[1], znb[2], …, znb[m]]^(T).
```

(20.93)

如果 `∥b∥₀ ≪ l`，则 `x[n]` 可由 `A` 的列稀疏表示，且其内在维度等于 `∥b∥₀`。采用与之前相同的假设，我们可以写出

#### 概率分布定义

$p(\boldsymbol{\epsilon}) = \mathcal{N}(\boldsymbol{\epsilon}|0, \beta^{-1}\mathbf{I}_l),\quad p(\mathbf{z}) = \mathcal{N}(\mathbf{z}|0, \alpha^{-1}\mathbf{I}_m)$

其中显式引入了 $l$ 和 $m$ 以提示相关维度。为保持一般性，我们假设 $\mathbf{z}$ 的元素对应的精度值不等于 1。

#### 观测数据分布

根据标准推导（参考公式 (12.15)），观测值 $\mathbf{x}_n$ ($n=1,2,\dots,N$) 服从分布：

$$\mathbf{x} \sim \mathcal{N}(\mathbf{x}|0, \boldsymbol{\Sigma}_x) \tag{20.94}$$

协方差矩阵为：

$$\boldsymbol{\Sigma}_x = \alpha^{-1}\mathbf{A}\boldsymbol{\Lambda}\mathbf{A}^T + \beta^{-1}\mathbf{I}_l \tag{20.95}$$

其中：

$$\boldsymbol{\Lambda} = \text{diag}\{b_1,\dots,b_m\} \tag{20.96}$$

这保证了在公式 (20.95) 中，只有 $\mathbf{A}$ 中对应非零 $b_i$ 值的列对 $\boldsymbol{\Sigma}_x$ 的形成有贡献。

#### 矩阵乘积重写

矩阵乘积可重写为：

$$\mathbf{A}\boldsymbol{\Lambda}\mathbf{A}^T = \sum_{i=1}^m b_i \mathbf{a}_i \mathbf{a}_i^T$$

由于只有 $\|\mathbf{b}\|_0 := k \ll l$ 个非零项参与求和，这对应一个秩为 $k < l$ 的矩阵（前提是 $\mathbf{A}$ 的相应列线性无关）。此外，假设 $\beta^{-1}$ 很小，则 $\boldsymbol{\Sigma}_x$ 的秩约等于 $k$。

我们的目标现在变为学习涉及的参数；即 `A`、`β`、`α` 和 `Λ`。这可以在标准的贝叶斯框架下完成，通过在 `α`、`β`（通常为伽马概率密度函数）以及 `A` 的列上施加先验：

```
p(a_i) = N(a_i | 0, (1/l)I_l), i = 1,2,...,m,
```

这保证了每一列具有单位期望范数。`b` 的元素的先验被选为服从伯努利分布（更多细节请参见 [47]）。

在推广该模型之前，让我们看看所采用模型的潜在几何解释。回顾我们的统计学基础（另见第 2 章的 2.3.2 节），一组联合高斯变量的大部分活动发生在一个（超）椭球体内，其主轴由协方差矩阵的特征结构决定。因此，假设 `x` 的值接近于一个子空间/（超）平面，通过调整 `Σ[x]` 的元素（训练后），得到的高斯模型公式 (20.94) 和 (20.95) 可以充分对其建模，使得相应的高概率区域形成一个足够扁平的椭球体（有关图示请参见 图 20.15）。

![图 20.15 位于超平面附近的数据点可以通过一个高斯概率密度函数充分建模，其高概率区域对应于一个足够扁平的（超）椭球体。](img/gr015.jpg)

图 20.15 位于超平面附近的数据点可以通过一个高斯概率密度函数充分建模，其高概率区域对应于一个足够扁平的（超）椭球体。

一旦我们建立了因子模型的几何解释，就让我们的想象力自由发挥。这种观点能否扩展到对源自子空间并集的数据进行建模？对此挑战的一个合理回应是求助于因子混合模型：每个子空间对应一个。然而，事情远不止于此。已经证明（例如，[27]），一个紧致流形可以被有限个拓扑圆盘覆盖，其维数等于流形的维数。将拓扑圆盘与定义足够扁平的超椭球体的主超平面相关联，可以用足够数量的因子（每个椭球体对应一个）来对沿流形发生的数据活动进行建模 [47]。

*因子分析器混合模型*（MSA）定义为：

```
p(x) = ∑_{j=1}^{J} P_j N(x | μ_j, α_j^{-1} A_j Λ_j A_j^T + β^{-1} I_l),
```

(20.97)

其中 $\sum_{j = 1}^{J}P_{j} = 1$，$\Lambda[j] = \text{diag}\{b[j[1]],\dots,b[j[m]]\}$，$b[j[i]] \in \{0, 1\}$，$i = 1, 2, \dots, m$。对于固定的 $J$ 和预选的 $\Lambda[j]$，第 $j$ 个因子的公式 (20.97) 中的展开形式早已为人所知；在此背景下，通过施加适当的先验并调用诸如变分 EM（例如 [79]）、EM [175] 和最大似然 [180] 等技术，在贝叶斯框架下实现未知参数的学习。在对该问题的较新处理中，每个 $\Lambda[j], j = 1, 2, \dots, J$ 的维数以及因子数目 $J$，均可由学习方案来学习。为此，*非参数先验*被引入（参见例如 [40,47,94] 及第 13.11 节）。随后，模型参数通过 Gibbs 采样（第 14 章）或变分贝叶斯技术计算得出。请注意，一般而言，不同因子最终可能呈现不同的维数。

对于*非线性流形学习*，公式 (20.97) 的几何解释如图 20.16 所示。数字 $J$ 是用于覆盖流形的足够扁平椭球体的数量，$\boldsymbol{\mu}[j]$ 是流形上的采样点，列向量 $A[j]\Lambda[j]$（近似）张成局部 $k$ 维切子空间，噪声方差 $\beta^{-1}$ 取决于流形曲率，而权重 $P[j]$ 反映流形上各处点的相对密度。该方法还被用于矩阵补全（另见第 20.10.1 节），通过对相关矩阵进行低秩矩阵近似 [40]。

![Figure 20.16 The curve (manifold) is covered by a number of sufficiently flat ellipsoids centered at the respective mean values.](img/gr016.jpg)

图 20.16 曲线（流形）被若干个以相应均值为中心的足够扁平的椭球体所覆盖。

一旦模型通过在训练数据集 $\boldsymbol{x}[n], n = 1, 2, \dots, N$ 上进行贝叶斯推断而学习完成，随后即可用于压缩感知，即能够利用 $K \ll l$ 次测量获得任意 $\boldsymbol{x}$，该 $\boldsymbol{x}$ 属于环境空间 $\mathbb{R}^{(l)}$ 但“位于”由公式 (20.97) 建模的 $k$ 维流形中。为此，完全类似于第 9 章所述内容，必须确定一个感测矩阵，此处记为 $\Phi \in \mathbb{R}^{(K \times l)}$，以便能够从测量（投影）向量中恢复 $\boldsymbol{x}$：

$$

\boldsymbol{y} = \Phi\boldsymbol{x} + \boldsymbol{\eta},

$$

其中 `η` 表示（未观测到的）测量噪声样本向量；现在所需的就是计算后验概率 `p(x|y)`。假设噪声样本服从高斯分布，且因为 `p(x)` 是高斯分布的加和，很容易看出后验概率也是高斯分布的加和，由公式 (20.97) 中的参数和噪声向量的协方差矩阵决定。因此，与 `l` 相比，`x` 可以通过少得多的测量数 `K` 来恢复。文献 [47] 进行了理论分析，将流形维度 `k`、环境空间维度 `l` 以及高斯/亚高斯类型的感知矩阵 `Φ` 联系起来；这类似于 RIP（限制等距性质），从而保证稳定嵌入（第 9.9 节）。

必须指出第 9 章开发的技术与本节之间的一个主要区别。在那里，假设生成数据的模型是已知的；信号用 `s` 表示，写为

```
s = Ψθ
```

其中 `Ψ` 是字典矩阵，`θ` 是稀疏向量。也就是说，假设信号位于由 `Ψ` 的某些列张成的子空间中；为了恢复信号向量，必须在子空间的并集中搜索它。相比之下，在本节中，我们必须“学习”信号（此处用 `x` 表示）所在的流形。

## 20.9 非线性降维

迄今为止考虑的所有技术都建立在线性模型周围，这些模型关联观测变量和潜在变量。在本节中，我们将关注它们的非线性亲戚。我们的目的是讨论一些最流行的方向，而不会深入太多细节。感兴趣的读者可以从文中提供的参考文献中获得更深入的理解和相关实现细节。^(¹⁵⁹)

### 20.9.1 核 PCA

顾名思义，这是经典 PCA 的核化版本，首次在文献 [161] 中提出。正如我们在第 11 章中所见，任何线性方法的核化版本背后的思想都是将原本位于低维空间 `ℝ^l` 中的变量，映射到高维（可能是无限维）的再生核希尔伯特空间（RKHS）中。这是通过采用隐式映射来实现的，

```
x ∈ ℝ^l ↦ ϕ(x) ∈ ℍ
```

(20.98)

设 `x_n, n = 1,2,…,N` 为可用的训练样本。假设数据已中心化，映射到 `ℍ` 后图像的样本协方差矩阵由下式给出^(¹⁶⁰)

```
Σ̂ = (1/N) ∑_{n=1}^N ϕ(x_n) ϕ(x_n)^T
```

(20.99)

目标是执行 `Σ̂` 的特征分解，即

```
Σ̂ u = λ u
```

(20.100)

根据 `Σ̂` 的定义，可以证明 `u` 位于 `span{ϕ(x₁), ϕ(x₂), ..., ϕ(xₙ)}` 中。确实，

```
λu = (1/N ∑ₙ₌₁ᴺ ϕ(xₙ)ϕᵀ(xₙ)) u = 1/N ∑ₙ₌₁ᴺ (ϕᵀ(xₙ)u) ϕ(xₙ)
```

且对于 `λ ≠ 0`，我们可以写成

```
u = ∑ₙ₌₁ᴺ aₙ ϕ(xₙ)
```

(20.101)

结合公式 (20.100) 和 (20.101)，结果表明（习题 20.7）该问题等价于对相应的核矩阵进行特征分解（第 11 章）

```
𝒦 a = N λ a
```

(20.102)

其中

```
a := [a₁, a₂, …, aₙ]ᵀ
```

(20.103)

正如我们在第 11.5.1 节中已知，核矩阵的元素为 $\mathcal{K}(i,j) = \kappa(\mathbf{x}_i, \mathbf{x}_j)$，其中 $\kappa(\cdot, \cdot)$ 为所采用的核函数。因此，$\hat{\mathbf{\Sigma}}$ 的第 $k$ 个特征向量，对应于公式 (20.102) 中 $\mathcal{K}$ 的第 $k$ 个（非零）特征值，表示为

$$

\mathbf{u}_k = \sum_{n=1}^{N} a_{kn} \mathbf{\phi}(\mathbf{x}_n), \quad k = 1,2,\ldots,p,

$$ (20.104)

其中 $\lambda_1 \ge \lambda_2 \ge \ldots \ge \lambda_p$ 表示按降序排列的相应特征值，$\lambda_p$ 为最小的非零特征值，且 $\mathbf{a}_k^T := [a_{k1}, \ldots, a_{kN}]$ 为核矩阵的第 $k$ 个特征向量。假设后者已归一化，使得 $\langle \mathbf{u}_k, \mathbf{u}_k \rangle = 1,\ k = 1,2,\ldots,p$，其中 $\langle \cdot, \cdot \rangle$ 为希尔伯特空间 $\mathbb{H}$ 中的内积。这在相应的 $\mathbf{a}_k$ 上施加了等价的归一化条件，其来源于

$1 = \left\langle \mathbf{u}_{k},\mathbf{u}_{k} \right\rangle = \left\langle \sum\limits_{i = 1}^{N}a_{ki}\mathbf{\phi}(\mathbf{x}_{i}),\sum\limits_{j = 1}^{N}a_{kj}\mathbf{\phi}(\mathbf{x}_{j}) \right\rangle = \sum\limits_{i = 1}^{N}\sum\limits_{j = 1}^{N}a_{ki}a_{kj}\mathcal{K}(i,j) = \mathbf{a}_{k}^{T}\mathcal{K}\mathbf{a}_{k} = N\lambda_{k}\mathbf{a}_{k}^{T}\mathbf{a}_{k},\quad k = 1,2,\ldots,p.$

![Equation](img/si452.png)(20.105)

我们现在准备好总结执行核主成分分析（kernel PCA）的基本步骤；即计算相应的潜变量（核主成分）。给定 $\mathbf{x}[n] \in \mathbb{R}^{(l)},\ n = 1,2,\ldots,N$ 和一个核函数 $\kappa(\cdot,\cdot)$：

*   计算 $N \times N$ 核矩阵，其元素为 $\mathcal{K}(i,j) = \kappa(\mathbf{x}_{i},\mathbf{x}_{j})$。

*   计算 $\mathcal{K}$ 的 $m$ 个主特征值/特征向量 $\lambda_{k},\ \mathbf{a}_{k},\ k = 1,2,\ldots,m$（公式 (20.102)）。

*   执行所需的归一化（公式 (20.105)）。

#### 核主成分分析

*   给定特征向量 **x** ∈ ℝ<sup>l</sup>，通过计算其在每个主特征向量上的 *m* 个投影，获得其低维表示，

```
z_k := ⟨ϕ(x), u_k⟩ = ∑_{n=1}^N a_{kn} κ(x, x_n), k = 1,2,…,m.
```

公式 (20.106) 中给出的操作对应于输入空间中的*非线性映射*。请注意，与线性 PCA 相反，主特征向量 **u**<sub>k</sub>，*k* = 1,2,…,m，并未显式计算。我们所知道的只是沿这些方向的各自（非线性）投影 *z*<sub>k</sub>。然而，归根结底，这正是我们最终感兴趣的。

##### 备注 20.7

*   核 PCA 等价于在 RKHS ℍ 中执行标准 PCA。可以证明，如 PCA 所讨论的，与主特征向量相关的所有性质对于核 PCA 仍然有效。即：(a) 主特征向量方向最优地保留了大部分方差；(b) 用 *m* 个主特征向量来近似 ℍ 中的向量（函数）时，其均方误差 (MSE) 相对于任何其他 *m* 个方向而言是最小的；(c) 在特征向量上的投影是不相关的 [161]。

*   回顾备注 20.1，度量多维缩放 (MDS) 方法需要 Gram 矩阵的特征分解。因为核矩阵是在相应 RKHS 中的 Gram 矩阵，核 PCA 可被视为 MDS 的核化版本，其中输入空间中的内积已被 Gram 矩阵中的核运算所取代。

*   请注意，核 PCA 方法不考虑数据所在流形的显式底层结构。

*   一种称为核熵成分分析 (ECA) 的核 PCA 变体已在文献 [103] 中提出，其中选择主方向是为了最大化 Renyi 熵。

### 20.9.2 基于图的方法

#### 拉普拉斯特征映射

该方法的出发点是假设数据集 𝒳 中的点位于一个光滑流形 ℳ ⊃ 𝒳 上，其内在维数等于 *m* < *l* 且嵌入在 ℝ<sup>l</sup> 中，即 ℳ ⊂ ℝ<sup>l</sup>。维数 *m* 由用户作为参数给出。相反，核 PCA 中不需要这一点，在那里 *m* 是主成分的数量，在实践中，通过使 *λ*<sub>m</sub> 和 *λ*<sub>m+1</sub> 之间的间隙具有“较大”值来确定。

该方法背后的主要理念是计算数据的低维表示，以便 𝒳 ⊂ ℳ 中的*局部邻域信息*得到最优保留。通过这种方式，试图获得一个反映流形几何结构的解。为实现这一点，按顺序执行以下步骤。

##### Step 1: Construct a graph
