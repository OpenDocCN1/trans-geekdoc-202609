高斯 PDF 具有许多良好的性质，我们将在本书后续内容中逐一发现。目前，请注意如果协方差矩阵是对角的，

```
Σ = diag{σ_1², ..., σ_l²}
```

也就是说，当所有元素的协方差 `cov(x[i], x[j]) = 0, i, j = 1, 2, …, l` 时，组成 **x** 的随机变量在统计上是独立的。一般来说，这并不成立。不相关的变量不一定独立；独立性是一个强得多的条件。然而，如果它们服从多元高斯分布，这确实成立。事实上，如果协方差矩阵是对角矩阵，那么多元高斯分布可以写为

```
p(x) = ∏_{i = 1}^{l} (1 / (√(2π) σ_i)) exp( - (x_i - μ_i)² / (2 σ_i²) ).
```

换句话说，

```
p(x) = ∏_{i = 1}^{l} p(x_i),
```

这就是统计独立性的条件。

### 中心极限定理

这是概率论和统计学中最基本的定理之一，它部分解释了高斯分布广受欢迎的原因。考虑 *N* 个相互独立的随机变量，每个变量服从其自身的分布，均值为 `μ[i]`，方差为 `σ[i]², i = 1, 2, …, N`。定义一个新的随机变量为它们的和，

```
x = ∑_{i = 1}^{N} x_i.
```

则该新变量的均值和方差由下式给出

```
μ = ∑_{i = 1}^{N} μ_i  and  σ² = ∑_{i = 1}^{N} σ_i².
```

可以证明（例如参考文献 [4,6]），当 `N → ∞` 时，归一化变量

```
z = (x - μ) / σ
```

的分布趋于标准正态分布，对于对应的概率密度函数（PDF），我们有

$p(z)\underset{N\rightarrow\infty}{\rightarrow}\mathcal{N}(z|0,1).$

在实践中，即使将相对较少数量 $N$ 的随机变量相加，也能获得对高斯分布的良好近似。例如，如果各个 PDF 足够平滑，且每个随机变量都是独立同分布（i.i.d.），则 $N$ 在 5 到 10 之间的数值可能就足够了。术语 i.i.d. 将在本书中大量使用。该术语意味着随机变量的连续样本是从描述该变量的同一分布中独立抽取的。

## 2.4 随机过程

随机变量的概念被引入用于描述结果为单个值的随机实验，例如掷硬币实验中的“正面”或“反面”，或玩西洋双陆棋时掷骰子得到的一到六之间的值。

在本节中，引入了 `stochastic process`（随机过程）的概念来描述每次实验结果为函数或序列的随机实验；换句话说，每次实验的结果是无限多个值。在本书中，我们只关注与序列相关的随机过程。因此，随机实验的结果是一个 `sequence`（序列），`u[n]`（有时也表示为 `u(n)`），`n ∈ ℤ`，其中 `ℤ` 是整数集合。通常，`n` 被解释为时间索引，而 `u[n]` 称为 `time series`（时间序列），或在信号处理术语中称为 `discrete-time signal`（离散时间信号）。相反，如果结果是一个函数 `u(t)`，则称为 `continuous-time`（连续时间）信号。在本章其余部分，我们将采用自由变量 `n` 的时间解释，这不失一般性。

在讨论随机变量时，我们使用符号 `x` 表示随机变量，一旦实验进行，它从样本空间中取一个值 `x`。类似地，我们将使用 `u[n]` 表示单次实验产生的特定序列，并使用正体字体 `u[n]` 表示相应的 `discrete-time`（离散时间）随机过程，即指定特定序列作为实验结果的规则。随机过程可以被视为一个序列族或 `ensemble`（集合）。单个序列称为 `sample sequences`（样本序列）或简称为 `realizations`（实现/样本函数）。

就我们的符号约定而言，通常我们将为过程和随机变量保留不同的符号。我们已经使用了符号 `u` 而不是 `x`；这仅出于教学原因，只是为了确保读者能够轻松识别何时关注随机变量，何时关注随机过程。在信号处理术语中，随机过程也称为 `random signal`（随机信号）。图 2.11 说明了涉及随机过程的实验结果是一系列值。

![图 2.11 每个实验的结果与离散时间随机过程相关联，是一系列值。对于每一种实现，在任意时刻（例如 n 或 m）获得的相应值分别构成了相应随机变量 u[n] 或 u[m] 的结果。](images/B9780443292385000081/gr011.jpg)

图 2.11 每个实验的结果与离散时间随机过程相关联，是一组序列值。对于每一种实现，在任意时刻（例如 n 或 m）获得的相应值分别构成了相应随机变量 `u[n]` 或 `u[m]` 的结果。

请注意，将时间固定为特定值 `n = n[0]`，会使 `u[n[0]]` 成为一个随机变量。确实，对于我们执行的每个随机实验，在时刻 `n[0]` 都会产生一个单一值。从这个角度来看，随机过程可以被视为无限随机变量的集合，`{u[n], n ∈ ℤ}`。那么，是否有必要将随机过程与随机变量/向量分开研究？答案是肯定的，原因在于我们将允许不同时刻对应的随机变量之间存在特定的时间依赖性，并研究这种依赖性对随机过程时间演化的相应影响。随机过程将在第 5 章中探讨，其中底层的时间依赖性将被利用以简化计算，并将在第 13 章中在高斯过程的背景下进行探讨。

### 2.4.1 一阶和二阶统计量

要完整描述一个随机过程，必须知道所有可能的随机变量组合 `u[n], u[m], …, u[r]` 的联合 PDF（离散值随机变量的 PMF）：

`p(u[n], u[m], …, u[r]; n, m, …, r)` (2.98)

请注意，为了强调这一点，我们显式地标出了联合 PDF 所涉及时刻的依赖关系。然而，从现在起，为了符号表示的方便，这将被省略。在实践中，以及在本书中，最常见的情况是仅基于 `p(u[n])` 和 `p(u[n], u[m])` 计算一阶和二阶统计量。为此，以下量具有特别的意义。

**时刻 n 处的均值**：

`μ[n] := 𝔼[u[n]] = ∫[−∞]^(+∞) u[n] p(u[n]) du[n]` (2.99)

**时刻 n, m 处的自协方差**：

#### 协方差与自相关

**协方差**定义为：

$$ \text{cov}(n, m) := \mathbb{E} \left[ (u[n] - \mathbb{E}[u[n]])(u[m] - \mathbb{E}[u[m]]) \right] \tag{2.100} $$

**时刻 $n, m$ 处的自相关**：

$$ r(n, m) := \mathbb{E} \left[ u[n] u[m] \right] \tag{2.101} $$

> **注意**：为简化符号，下标已从相应符号中省略，例如使用 $r(n, m)$ 代替更正式的记法 $r_u(n, m)$。我们将这些均值称为集合平均，以强调它们传达了构成该过程的序列集合上的统计信息。

复随机过程的相应定义为：

$$ \text{cov}(n, m) = \mathbb{E} \left[ (u[n] - \mathbb{E}[u[n]])(u[m] - \mathbb{E}[u[m]])^* \right] \tag{2.102} $$

以及

$$ r(n, m) = \mathbb{E} \left[ u[n] u[m]^* \right] \tag{2.103} $$

### 2.4.2 平稳性与遍历性

#### 定义 2.1 严格平稳性

若随机过程 $u[n]$ 的统计特性对原点移动不变，即 $\forall k \in \mathbb{Z}$，则称该过程为*严格平稳*（SSS）。

#### 定义 2.2 宽平稳性

如果随机过程 `u[n]` 的均值在所有时间点上均为常数，且自相关/自协方差序列仅依赖于所涉及时间索引的差值，则称该过程为*宽平稳*（WSS），即

```
μ[n] = μ,  and  r(n, n − k) = r(k).
```

![Equation](img/si257.png) (2.105)

请注意，WSS 是二阶平稳性的一个较弱版本；在后一种情况下，所有可能的二阶统计量均与时间原点无关。而在前一种情况下，我们仅要求自相关（自协方差）和均值与时间原点无关。之所以关注这两个量（统计量），是因为正如我们将在第 4 章中看到的那样，它们在线性系统研究和均方估计中具有重要意义。

显然，严平稳（SSS）过程也是 WSS 过程，但一般来说，反之则不成立。对于 WSS 过程，自相关变为一个序列，仅以单个时间索引作为自由参数；因此，其值（衡量两个时刻随机变量间的关系）仅取决于这两个时刻相差多少，而不取决于它们的具体数值。

从基础统计学课程中我们知道，给定随机变量 x，其均值可由样本均值近似。进行 `N` 次连续的独立实验，设 `x[n], n = 1, 2, …, N` 为获得的数值，称为观测值。样本均值定义为
