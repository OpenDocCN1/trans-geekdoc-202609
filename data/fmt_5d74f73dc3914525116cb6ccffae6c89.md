
在机器学习中，归一化是一种将特征缩放到共同范围的方法，这对于所有数据集都是必要的。当数据超出范围时，必须使用。机器学习中有多种标准化方法。标准化缩放和极值缩放是两种常用的归一化方法。特征值通过平移和缩放进行归一化，使其范围变为 0 到 1。方法见公式 3.6。

```
$X_n = \frac{X - Xmin}{Xmax - Xmin}$
```

其中 `$X_n$` 是归一化值，`$Xmax$` 是最大值，`$Xmin$` 是最小值。当 `X` 为最大值时，归一值为 0。相反，当 `X` 既不是最大值也不是最小值时，归一化值在 0 到 1 之间。当特征分布未知或不精确时，标准化方法有助于模型表现更好、更准确。

标准化缩放也称为 Z Score，是一种基于均值并具有单位标准差的策略。通过将特征值除以标准差并减去均值进行数学计算。公式 3.7 给出了标准化的表达式。

```
$X' = \frac{X - \mu}{\sigma}$
```

其中 `$\mu$` 是均值，`$\sigma$` 是特征的标准差。与极值缩放方法不同，标准化技术不限制特征值在特定范围内。KNN、K-means 聚类、主成分分析和其他基于距离的机器学习算法都能从这种策略中受益。
