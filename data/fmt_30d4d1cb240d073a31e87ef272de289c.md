
# 云计算概念与安全

云计算的目的是为组织提供数据库、电子邮件或其他服务等功能，而无需组织自行托管这些服务。例如，要托管自己的数据库服务器或电子邮件服务器，你需要服务器硬件和软件，这需要花钱。让其他人托管这些服务（由他们购买硬件和软件），而你支付月度订阅费通过互联网访问这些服务，这可能更容易。对于许多云服务，你只需为所使用的服务和所使用的数据存储付费。

尽管组织可以通过让其他人通过互联网托管服务来节省购买硬件和软件的初始成本，但云计算存在一些安全考量：

## 许多客户共享服务

如果多个客户订阅了同一项服务，一个客户是否可能访问另一个客户的数据？您需要信任提供商将客户信息与其他订阅者的信息隔离开来。这通常通过虚拟化技术来实现。

## 法律问题

在大多数情况下，如果执法部门有合法理由要求数据提供商提供对其存储信息的访问权限，提供商将不得不全面披露该信息。

## 谁来管理安全

弄清提供商提供了哪些服务，以及您是否负责系统的安全配置，这一点至关重要。大多数公有云提供商必须定期接受第三方安全审计。

在考虑部署网络服务和应用程序时，您可以选择在本地安装、由他人托管，或使用云服务。以下列表概述了这些选项中的每一个：

## 本地部署

本地部署意味着您在您站点内的服务器上安装应用程序或服务。这涉及大量的前期时间和成本，包括规划部署、购买服务器、软件和高可用性解决方案。您还负责维护服务器。

## 托管

采用托管解决方案时，您的组织仍然购买软件和许可证并维护服务器，但您需要支付费用给第三方公司，由其提供服务器和基础设施来托管应用程序。

## 云

采用云解决方案时，您支付月度订阅费，软件已安装在后台的服务器上（您无法访问这些服务器）。您可以对软件和服务进行配置更改以满足您的需求，但无需维护服务器——它们由云提供商维护。

以下是与云计算相关的一些其他术语和概念，您应为 Security+ 认证考试熟悉这些内容：

## VDI/VDE

虚拟桌面基础设施（`VDI`）和虚拟桌面环境（`VDE`）是虚拟化功能，它们在中央服务器上托管用户的桌面环境，然后将其交付给瘦客户机。用户与桌面操作系统进行交互，就像它在本地安装一样。

## 弹性与自动化

虚拟化和云服务提供了许多弹性和自动化工具及功能，可帮助降低环境中的安全风险。

### 自动化/脚本

为了帮助降低安全风险，尽可能自动化更多任务非常重要。自动化的好处在于，因为您只是日复一日地运行自动化任务或脚本，所以会犯更少的错误。更少的配置错误意味着环境中更少的漏洞。

您不仅应该拥有`自动化的处理流程`（配置步骤），还应该自动化任何`持续监控`步骤，以帮助确保不会错过任何安全警报或通知。您还希望自动化`配置验证`，即审查环境的配置设置以确保其准确性的过程。

### 模板和主镜像

基于云的环境中的`模板`允许您在创建虚拟机时向其应用标准配置设置。将这些配置设置模板与操作系统的`主镜像`相结合，可让您快速预配虚拟机，并在几分钟内让它们运行起来。

## 非持久性

在使用云解决方案或虚拟化环境时，您有多种方法可以撤销对系统所做的更改。以下列表概述了撤销更改的解决方案：

### 创建快照

在虚拟化环境中，您可以创建快照，它们类似于配置状态的保存点。

### 还原到已知状态

您可以将系统还原到快照，以撤销自该快照以来的更改。

### 回滚到已知配置

某些软件会自动保存您的配置状态，并允许您回滚到其中一个已保存的配置状态。

### 弹性与可扩展性

弹性和可扩展性是任何基于云的解决方案的两个重要特征。在云计算语境中，`弹性`是指根据工作负载需求启动新服务器，然后在工作负载减少时关闭这些服务器。`可扩展性`是指确保随着您的需求增长，解决方案能与您同步增长。

### 分布式分配

许多私有云解决方案的一项出色功能是`分布式分配`，它允许您将虚拟机分布在许多主机系统上。大多数私有云解决方案会查看主机系统上的现有工作负载，并就虚拟机应在哪个主机系统上运行给出建议。

## 云功能

新的 Security+ 考试扩展了您必须理解的一些云概念，以便通过认证考试。在本节中，您将了解一些不同的云相关功能。

### 容器

正如本章前面提到的，容器是一项功能，允许您在隔离环境中运行应用程序，该环境拥有分配给它的自己的资源，非常类似于虚拟机。容器与 VM 的区别在于，容器更轻量级，因为它共享主机系统的操作系统内核。这就是为什么容器在提供 VM 隔离功能的同时，性能却优于 VM。Docker 是提供容器的软件示例，也是 Windows 10 的一项功能。

### 微服务/API

微服务是编程到应用程序编程接口（`API`）中的一项功能或组件，随后可由其他应用程序调用。微服务的好处在于，每个组件都是一个完整的工作单元，可以独立于 `API` 中的其他组件进行发布和更新。

`应用程序编程接口`是开发人员创建的一组函数，允许其他开发人员调用此功能。例如，假设我们经营一家创建防火墙产品的公司。作为防火墙设备的一部分，我们有一个 Web 界面，包含所有常见的防火墙配置选项，允许管理员对其进行配置。作为产品的创建者，我们还可以创建一个 `API`，其中包含一系列函数，这些函数是可以对设备进行的不同类型的配置更改（参见图 16-3）。创建 `API` 的好处是，它允许其他开发人员创建他们自己的 Web 管理页面（如果他们不喜欢我们创建的页面）。当开发人员创建他们的 Web 页面时，只需向其中添加链接或按钮，以调用 `API` 即可。请注意，如今我们称之为“Web API”，因为它们通过 HTTP 流量进行。

## 基础设施即代码

基于云的环境和集成在云中的基础设施组件的一大好处是，我们可以利用软件定义网络和软件定义可见性等技术：

### 软件定义网络（SDN）

`SDN` 是一种从中心点管理网络设备配置的方式。`SDN` 使用控制器应用程序和 `API` 将配置更改集中部署到网络设备。

### 软件定义可见性（SDV）

`SDV` 是一种监控整个网络环境的方法，具备实时响应安全事件的能力。

### 其他云功能

从术语角度来看，还有许多其他云功能您应该了解：

## 无服务器架构

无服务器架构是云计算的一大优势，因为您无需投资服务器硬件；相反，您只需在云中创建该服务的一个实例。例如，在 Azure 中，您无需安装 SQL Server 即可托管数据库；您只需直接在 Azure 中创建数据库，而在后台，云服务提供商（微软）负责管理服务器基础设施。

## 服务集成

服务集成是云计算的一种交付模型，允许本地数据与云数据进行交互。

## 资源策略

云资源策略允许您管理云中存在的资源，例如 VM、数据库和 Web 应用程序。您可以配置不同类型的策略来管理这些资源，例如成本控制策略有助于管理您每月在这些资源上的支出，卫生策略允许您随时间清理不需要的资源，合规性策略允许您实施安全控制以保护资源。

## 传输网关

传输网关是一种机制，为您提供安全的专用链接，允许您将本地网络扩展到云网络。

## 云网络安全解决方案

现在您了解了云计算的一些特性，让我们来看看可用于保护云资源（例如在云中运行的应用程序和数据）的不同安全控制。我们还将在本节介绍一些云计算的常见安全解决方案。

## 云安全控制

安全控制是一种用于保护资源的机制；因此，“云”安全控制是一种用于保护云资源的机制。有许多不同类型的云安全控制——通用安全控制、保护存储的控制、网络安全控制以及保护计算环境的控制。

### 云的通用安全控制

通用安全控制是您作为云订阅一部分所拥有的控制，不一定专门适用于存储或网络。请务必了解这些针对 Security+ 考试的通用安全控制：

- **跨区域的高可用性** 当您使用云服务提供商创建不同资源时，可以选择您想要的高可用性级别。您可以在区域内实现高可用性，也可以跨区域实现。
- **资源策略** 如前所述，您可以对资源设置策略，例如限制资源的月度成本、用于保护资源的合规性策略，以及随时间清理未使用资源的策略。
- **密钥管理** 云门户中提供了用于管理所用身份验证凭据（称为密钥）的工具，例如密码、应用程序令牌和密钥。
- **集成和审核** 您可以在资源上配置云审核，以帮助您跟踪谁在从何处使用什么资源。

### 存储安全控制

云的一大优势是您可以将数据存储在云中，然后从世界任何地方访问。这意味着您还应采取额外措施，通过实施以下不同的存储安全控制来保护这些资源：

- **权限** 您可以通过在数据上设置权限来限制对数据的访问，以控制谁可以访问它。
- **加密** 您可以对数据进行加密，以便未经授权的个人无法访问数据。确保数据在静止状态（存储中）和传输过程中均已加密。许多云服务提供商默认加密数据。
- **复制** 您可以将数据复制到另一个云区域，以便获得数据的高可用性和业务连续性（如果发生区域性中断）。
- **高可用性** 高可用性确保数据始终可用。云服务提供商在不同服务的后台实现高可用性功能，但您也可以将数据复制到另一个区域以确保高可用性。

### 网络安全控制

可以在云中实施许多安全控制，以为您的云网络环境提供安全性：

- **虚拟网络** 在云中，您可以创建多个虚拟网络并将不同的系统连接到每一个网络。例如，您可以为会计人员创建一个虚拟网络，并在该网络上运行会计服务器 VM。
- **公共和私有子网** 您可以创建多个公共和私有子网。公共子网是允许通信到 Internet 的网络（本质上是通往 Internet 的网关）。您还可以将云基础设施划分为多个没有直接 Internet 访问权限的私有子网。
- **分段** 您可以将资源分段到不同的虚拟网络中，以控制对这些资源的通信。
- **API 检查和集成** 云服务提供商提供许多 API，可用于检查云中的元素以确保合规性。例如，Google Cloud 有一个数据丢失防护 (DLP) API，可以调用它来检查存储在云中的数据，并验证其中未存储敏感数据。您也可以使用允许您检查云中网络流量的 API。

### 计算安全控制

在云环境中，计算资源是云中的虚拟机、容器或应用程序服务（如数据库服务）等资源。您可以使用许多安全控制来保护这些计算资源：

- **安全组** 您可以创建具有不同资源权限级别的不同安全组。
- **动态资源分配** 云计算的一大特性是虚拟机仅使用所需的 RAM 和磁盘空间。如果活动量大，这些资源会即时增加以处理工作负载，然后在负载减轻时再次降低。
- **实例感知** 您需要实施能够区分云中运行的应用程序服务实例的安全控制。如果您使用的安全控制不了解实例，攻击者可能会创建一个应用程序服务的流氓实例，并可能执行数据渗漏攻击。
- **虚拟私有云 (VPC) 端点** 虚拟私有云 (VPC) 是云中资源的私有网络。VPC 端点允许您通过专用地址与应用程序服务通信。
- **容器安全** 通过遵循安全最佳实践，确保您正在保护容器环境，例如锁定容器中运行的操作系统，包括保护 root 或管理员账户。

## 云安全解决方案

您可以在云中使用许多安全解决方案来实施云安全。以下是一些常见的云安全解决方案：

- **CASB** `云访问安全代理 (CASB)` 是一种安全服务，位于您的本地环境和云提供商的环境之间。CASB 允许您定义适用于从当前本地环境流向云的网络流量的安全策略。
- **应用程序安全** 寻找云中应用程序的安全解决方案。您需要使用能让您深入了解应用程序中发生的情况及其包含的数据的解决方案。您还想了解敏感数据上的访问控制设置，以便密切监控谁有权访问该数据。云服务提供商通常提供许多合规性功能，允许您监控这些要素。

### 下一代安全 Web 网关 (SWG)

安全 Web 网关 (SWG) 是一种网关产品，所有流量都通过它进行传输，它能防止用户访问互联网或云中可能包含恶意软件的网站，这些恶意软件可能会感染其系统或内部网络/云网络。

**务必了解本节提到的云安全解决方案。特别要注意，CASB 允许您定义安全策略，这些策略应用于从当前本地环境流向云的网络流量。**

### 云环境中的防火墙考量

当您寻找适用于云环境的防火墙产品时，应考虑多个因素以辅助决策：

- **成本** 防火墙解决方案的成本。
- **分段需求** 如果您需要一种防火墙解决方案，允许您处理多个网段并控制这些网段之间的流量。
- **开放系统互连 (OSI) 层** 防火墙在 OSI 模型的哪一层运行，以及您希望按何种数据类型过滤流量。例如，如果您想要检查数据包的有效载荷，您将需要使用应用层防火墙（第 7 层），而不是包过滤防火墙（第 3 层）。

### 云原生控制与第三方解决方案

关于在云中实施安全控制，最后一点建议是：您应首先调查云解决方案自带的安全控制（原生控制），然后再寻找第三方解决方案。CSP 不断改进其云解决方案的功能，并增加内置于其产品中的安全控制数量。

# 认证总结

在本章中，您学习了云计算概念以及保护云资源应考虑的不同因素。以下是备考 Security+ 认证考试时，关于本章需要记住的一些要点：

- 虚拟化技术允许您在单台物理服务器上运行多台虚拟化计算机。
- 您可以将快照与虚拟机配合使用，作为将系统恢复到先前状态的一种方法。
- 云计算是通过互联网托管服务，为企业省钱，因为它们不必安装自己的服务器。
- 考试需了解的三种主要云模型是 SaaS、PaaS 和 IaaS。
- 容器类似于轻量级虚拟机，因为它们共享宿主系统的操作系统内核。
- 要着眼于使用云安全控制在云中实施安全。
