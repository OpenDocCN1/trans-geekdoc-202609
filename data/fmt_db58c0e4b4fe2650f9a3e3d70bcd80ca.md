
确定脑电活动的传播、其方向以及频率内容至关重要。基于`MVAR`模型的`DTF`已被用于此目的[\[120\]](#c17.xhtml#c17-bib-0120)。在此方法中，所有`EEG`通道的信号被视为多元随机过程的实现。短时`DTF`(`SDTF`)也已被开发[\[119\]](#c17.xhtml#c17-bib-0119)，用于对`EEG`的短时段进行自回归(`AR`)系数的估计和评估。

`MP`和`SDTF`已被用于分析自主手指运动规划期间的`EEG`活动，我们将结合自主动作期间皮层活动特征的表征来讨论结果。

`MP`已被应用于`EEG`的分解以获得无参考数据，并构建了平均功率图。`ERP/ERS`的计算方法如第17.3.2节所述。

模型阶数通常在模型误差不再显著减小的点上选择。一个著名的标准称为赤池信息准则(`AIC`)[\[121\]](#c17.xhtml#c17-bib-0121)，已被广泛用于此目的。根据`AIC`，正确的模型阶数将是使以下准则最小化的*p*值：

(17.13)

```
AIC(p) = 2 log(det(V)) + (2kp)/N
```

其中`V`是模型噪声的方差矩阵，*N*是每个通道的数据长度，*k*是通道数。最近，一种更精确的模型阶数估计技术已被提出[\[122\]](#c17.xhtml#c17-bib-0122)。使用该方法，未知噪声情况下的噪声信息准则(`IC`)可按[\[122\]](#c17.xhtml#c17-bib-0122)计算：

(17.14)

```
IC(ρ) = (ρ + 1 - w + (2(n_e - ρ)² + n_e - ρ) / (6(n_e - ρ)) - Σ_{i=1}^k (λ̄_{n_e-ρ}² / (λ_i - λ̄_{n_e-ρ})²)) · log(λ̄_{n_e-ρ}^{-(n_e-ρ)} Π_{i=ρ+1}^{n_e} λ_i) + 2g(ρ, n_e)β(w-1)
```

其中在该方程中*g*(*ρ*, *n*[*e*]) = *k*(*n*[*e*] − *ρ* + 2)(*n*[*e*] − *ρ* + 2)/2，且`λ̄_{n_e-ρ}`是最小的*n*[*e*] − *ρ*个特征值的平均值。在该方程中，*n*[*e*]是通道数，*ρ*是待估计的阶数，*w*是数据矩阵中的时间点数。

`DTF`模式的转换可以针对左手和右手手指运动的不同`EEG`通道进行说明，分别如图17.11和图17.12所示。

信号源移动的方向是通过信号间的互相关来实现的，这些互相关是在相关矩阵`R`(*n*)估计过程中针对不同时间偏移计算的。这些时间偏移通过变换到频域被转换为相位偏移。通道间的相位依赖性反映在传递矩阵中。`DTF`值表示某一频率下信号分量的方向（而非延迟量）[\[116\]](#c17.xhtml#c17-bib-0116)。然而，当通道数增加导致`MVAR`系数数量增加时，`DTF`值的分析将变得困难。

如前一节所述，脑活动的相干性可以从另一个角度呈现，即脑连接。这一概念在神经科学中起核心作用。不同脑区活动间的时间相干性常被定义为功能连接，而有效连接则被定义为能产生与实验观察到的皮层区域间相同时间关系的最简单脑回路[\[123\]](#c17.xhtml#c17-bib-0123)。已提出多种方法，利用`EEG`和`fMRI`数据估计不同脑区在运动和认知任务中如何协同工作[124–126]。

结构方程建模(`SEM`)[\[127\]](#c17.xhtml#c17-bib-0127)在第8章中有详细解释，也被用于从高分辨率（空间和时间均高分辨率）`EEG`数据建模此类活动。解剖学和生理学约束已被利用将欠定方程组转化为定解方程组。

基于`EEG`的功能连接在`BCI`中的应用可以为`BCI`研究开辟两个新方向。一个是模拟从思维到行动的路径，而无需任何反馈（视觉、触觉等）。第二个方向是在大脑超扫描框架中实现从一个大脑到另一个大脑的信息传输。在这样的框架中，执行相似或竞争性任务的多个大脑会接受`EEG`扫描。这或许是大脑间通信或脑互联网(`IoB`)建立的主要基础。

## 17.7 通用空间模式的应用

正如第7章所述，`CSP`可能是`BCI`分类中使用的最有效的特征选择算法。2000年初，在一个两分类`BCI`设置中，`Ramoser`等人[72]提出了一种`CSP`，它学习最大化一类带通滤波`EEG`信号的方差，同时最小化另一类信号的方差。形式上，`CSP(w)`最小化空间协方差矩阵的瑞利商，以实现两类数据`X[1]`和`X[2]`之间的方差不平衡，并使用以下公式定义：

(17.15)

```
J(w) = (w^T X_1^T X_1 w) / (w^T X_2^T X_2 w) = (w^T C_1 w) / (w^T C_2 w)
```

其中`T`表示转置，`X[i]`是第`i`类的数据矩阵（训练样本为行，通道为列），`C[i]`是第`i`类信号的空间协方差矩阵，假设`EEG`信号均值为零。正如第7章所述，`CSP`问题通常通过广义特征值方程求解：

(17.16)

```
C_1 w = λ C_2 w
```

或`C_2^{-1} C_1 w = λ w`。在`BCI`的两分类模式检测和识别中，`CSP`被广泛用作一种有效方法。大多数现有的基于`CSP`的方法在逐受试者的基础上利用协方差矩阵，从而忽略了受试者间的信息。`CSP`及其变体受到了广泛关注，并一直是`BCI`最高效的特征提取方法之一。然而，尽管其数学原理直观，`CSP`容易过拟合数据，且对噪声高度敏感。为解决这些缺点，最近有人提出通过正则化项引入先验信息来改进`CSP`学习过程。`Lotte`和`Guan`[132]回顾、分类并比较了11种不同的正则化`CSP`方法：从`EEG`协方差矩阵估计中的正则化[133]到几种不同的正则化方法，如复合`CSP`[134]、带泛化学习的正则化`CSP`[135]、带对角加载的正则化`CSP`[134]和不变`CSP`[136]。他们将这些方法应用于从17名患者记录的`EEG`，并验证了带`Tikhonov`正则化的`CSP`的优越性，其中`J(w)`的优化通过最小化`||w||²`受到惩罚，从而最小化伪迹和离群值的影响。`w`的正则化也可用于减少`EEG`通道数量，而不损害分类得分。`Farquhar`等人[137]将`CSP`转化为带有`l[1]`-范数惩罚的二次约束二次优化问题，`Arvaneh`等人[138]使用了`l[1]/l[2]`-范数约束。最近，在[133]中，应用了一种计算成本高昂的准`l[0]`-范数原则，以获得`w`的稀疏解。

**图 17.14** 应用`CSP`对大脑皮层活动进行分类的结果，分别针对(a)左手和(b)右手运动。

在[133]中，`CSP`已被修改用于受试者间迁移，其中利用了所考虑受试者协方差矩阵的线性组合。在这种方法中，使用了一个复合协方差矩阵，它是涉及受试者的协方差矩阵的加权和，从而得出复合`CSP`。

为了减轻噪声的影响，公式(17.24)中的目标函数可以在估计每一类的协方差矩阵期间，或在通过向空间滤波器`w`[132]施加先验来最小化`CSP`代价函数的过程中进行正则化。

文献[135]中提出的用于估计类`C̃_i`的正则化协方差矩阵的方法如下：

(17.17)

```
C̃_i = (1 - γ)P + γI
```

其中

(17.18)

```
P = (1 - β)C_i + βG_i
```

在上述方程中，`C_i`为初始空间协方差矩阵，`G_i`为所谓的通用协方差矩阵，`γ`和`β` ∈ [0, 1]为正则化参数。`G_i`通过对类别`i`的若干次试验的协方差矩阵求平均来进行经验估计。

在对`CSP`目标函数进行正则化时，相反地，向`CSP`目标函数添加一个正则化项，以惩罚不满足给定先验的结果空间滤波器。这导致了一个略有不同的目标函数，如文献[132]所示：

(17.19)

```
J(w) = (w^T C_{X_1} w) / (w^T C_{X_2} w + αQ(w))
```

其中，由惩罚参数`α` ≥ 0加权的惩罚函数`Q(w)`指示空间滤波器`w`在多大程度上满足给定先验。为了最大化`J(w)`，该项需要被最小化。遵循本书第7章中的讨论，文献中定义了不同的二次和非二次惩罚函数，如文献[132, 137]和[139]中的那些。在文献[132]中实现11种不同正则化方法所取得的结果表明，在数据含噪的情况下，正则化平均可使结果提高约3%。然而，最佳算法在平均分类准确率上比`CSP`高出约3-4%，在中位数分类准确率上高出近10%。正则化方法也更稳健，即它们在各类别和受试者间表现出更低的方差。在各种方法中，文献[132]中提出的加权`Tikhonov`正则化`CSP`据报具有最佳性能。

在`CSP`中，通常并非使用所有`EEG`通道。在实际`BCI`应用中，如图17.15高亮显示的，从中央-顶叶头皮区域（运动皮层上方的电极）记录的数据，在实施`CSP`滤波器之前，首先在8至30`Hz`之间进行带通滤波。

## 17.8 多类脑机接口

通常，一个用于执行完整`BCI`任务或检测各种身体运动的良好模型变得有用且重要。如果没有一个稳健的多类分类器，这是无法实现的。大多数文献涉及二分类问题，可使用`SVM`等高效分类器求解。对于通用应用，`NNs`等多类分类器一直是一种选择。此类算法的效率或计算复杂度通常受到质疑。

文献[28]中介绍了两种用于`BCI`的新分类方法。其中一个分类器基于到黎曼均值的距离，另一个在黎曼切空间中工作。显然，`LDA`、`SVM`和`NNs`等流行的分类算法无法直接在黎曼流形上实现，因为它们基于投影到超平面。

在该`BCI`方法中，考虑短时片段，每个片段包含`EEG`信号的`T_s`个采样点或试验，形式为矩阵`X_i = [x_{t+T_i} ... x_{t+T_i+T_s-1}] ∈ R^{n×T_s}`，对应于时间`T_i`开始的真实或想象运动的第*i*次试验。定义`P_i`为*n* × *n*样本协方差矩阵：

(17.20)

```
P_i = (1 / (T_s - 1)) X_i X_i^T
```

表示所有*n* × *n*对称矩阵在实方阵空间中的空间为`S(n) = {S ∈ M(n), S^T = S}`，表示所有*n* × *n*对称正定（`SPD`）矩阵的集合为`P(n) = {P ∈ S(n), u^T P u > 0, ∀ u ∈ R^n}`。然后，为了找到最接近新测试输入`X`（未知类别的`EEG`试验）的类别，我们使用训练集计算上述样本协方差矩阵以得到`P_i`。接着，将其应用于`X`以计算样本协方差矩阵`P`。在下一步中，我们计算所有类别*k* = 1, …, *K*的黎曼（也称为几何）均值，如文献[28]所示：

(17.21)

```
P̄(P_1, …, P_I) = argmin_{P ∈ P(n)} Σ_{i=1}^I δ_R²(P, P_i)
```

其中`δ_R(P_1, P_2)`称为`X_1`和`X_2`之间的黎曼测地线距离，定义为：

(17.22)

```
δ_R(P_1, P_2) = ||log(P_1^{-1} P_2)||_F = [Σ_{i=1}^n log² λ_i]^{1/2}
```

其中`λ_i, i = 1, …, n`是`P_1^{-1} P_2`的实特征值。使`δ_R(P, P̂_k)`取得最小值的类别`k̂`将是`X`对应的类别。

第二种多分类方法是使用黎曼切空间。在此方法中，首先应用公式(17.20)。假设该最小化的结果记为`P_ϑ`，则`X`对应的类别估计如文献[28]所示：

(17.23)

```
s_i = upper(P_ϑ^{-1/2} Log_{P_ϑ}(P_i) P_ϑ^{-1/2})
```

其中`upper(·)`算子保留对称矩阵的上三角部分，并将其向量化，对角线元素赋予单位权重，非对角线元素赋予`√2`权重。
