
为了将逻辑回归值映射到二元类别，你需要定义一个**分类阈值**（也称为**决策阈值**）。这是一个由人类选择的值，而非模型训练选择的值，通常在大多数情况下，该阈值假定为 0.5。逻辑回归模型输出 0 到 1 之间的值。假设人类设定的分类阈值为 0.6，模型预测值为 0.7，则模型预测为正类。分类阈值的选择强烈影响假阳性和假阴性的数量。分类阈值大多取决于具体问题，必须进行微调。精确率-召回率曲线表明模型预测正类的效果如何。精确率是指真阳性数量除以正预测总数，而召回率也称为真阳性率（TPR）。召回率是指机器学习模型正确识别为感兴趣类别（即“正类”）的数据样本百分比，占该类别总样本数的比例。

精确率和召回率对于评估模型都很重要。然而，如果你提高精确率，会降低召回率，反之亦然。

如果你想最小化假阳性，则提高分类阈值。对于这些问题，精确率对你非常重要。例如，你宁愿模型将垃圾邮件分类为非垃圾邮件，也不愿将非垃圾邮件分类为垃圾邮件。当你更关注正类而非负类时，应使用精确率。

如果你想最小化假阴性，则降低分类阈值。对于这些问题，召回率对你非常重要。换句话说，你倾向于让模型将未患病患者分类为患病，但如果将患病患者识别为未患病则会是个问题。在这类场景中，如果你更关注负类而非正类，应使用召回率。

召回率回答的问题是：在所有可能的正样本中，模型正确识别了多少？

### 曲线下面积 (AUC)

在本节中，我们将介绍分类问题中两种类型的曲线下面积。

*   **AUC ROC**：用于分类问题中的平衡数据集，即我们试图预测的两个类别拥有相同数量的样本。
*   **AUC PR**：用于分类问题中的不平衡数据集，例如信用卡交易中的欺诈识别。假设你有 10,000 笔信用卡交易，欺诈数据可能是每 1,000 笔交易中只有 1 笔。

#### AUC ROC

ROC 曲线（受试者工作特征曲线）是一张展示分类模型在所有分类阈值下性能的图表。该曲线绘制两个参数：真阳性率和假阳性率。你可以参考此链接查看图表外观：

`https://developers.google.com/machine-learning/crash-course/classification/roc-and-auc`

AUC ROC（ROC 曲线下面积）测量整个 ROC 曲线下方的二维面积。它指的是一个 0.0 到 1.0 之间的数字，代表二元分类模型将正类与负类分开的能力。

AUC 越接近 1.0，模型区分类别的能力越强。当类别平衡，或当你希望赋予正负类预测能力同等权重时，使用 AUC ROC 曲线。

#### AUC PR

PR 曲线是一张以精确率值为 y 轴、召回率值为 x 轴的图表。PR 曲线关注少数类，使其成为不平衡二元分类模型的有效诊断工具。

精确率-召回率曲线下面积（AUC PR）测量 PR 曲线下方的二维面积。在类别不平衡的情况下，对于高度偏斜的领域，推荐使用精确率-召回率曲线（PR 曲线）。AUC PR 更关注少数类。它可以结合我们在第 2 章中介绍的欠采样或过采样一起使用。

### 特征交叉

*特征交叉*，或称合成特征，是通过将两个或多个特征相乘（交叉）而创建的。它可以是将同一特征与自身相乘 [`A * A`]，也可以是将多个特征的值相乘，例如 [`A * B * C`]。在机器学习中，特征交叉通常在独热编码特征上执行——例如，`binned_latitude × binned_longitude`。（更多信息请参阅 `https://developers.google.com/machine-learning/crash-course/feature-crosses/video-lecture`。）

使用特征交叉主要有两种方式：

*   当单个特征本身的预测能力不如组合特征时，会使用特征交叉。例如，我们有一个模型需要预测在一天中的某个时刻，基于街道位置的人群拥挤程度。如果我们从这两个特征构建特征交叉，[`location (market, curbside) × time of the day`]，那么我们将获得比单独使用任一特征强得多的预测能力。例如，如果周二晚上有农贸市场，人群会更拥挤。如果周二晚上没有农贸市场，人群会较少。
*   在具有高度复杂模型的线性问题中，特征交叉用于通过将两个或多个特征相乘（交叉）来在线性模型中表示非线性。线性学习器可很好地扩展到海量数据。在海量数据集上使用特征交叉是学习高度复杂模型的一种高效策略。让我们看一个例子。如图 3.1 所示，圆点代表患病者，矩形代表健康者。很难用直线或线性方法将它们分开。

#### TensorFlow Transform

提高 TensorFlow 模型性能需要高效的输入流水线。首先我们将讨论 TF Data API，然后介绍 TensorFlow Transform。

#### TensorFlow Data API (tf.data)

高效的数据输入流水线可以通过减少设备空闲时间，大幅提高模型执行速度。请考虑采纳 `here` 中详述的以下最佳实践，使您的数据输入流水线更加高效：

*   使用预取转换来重叠预处理和训练步骤的模型执行。此转换将数据生成的时间与数据消费的时间解耦。`tf.data` API 提供了 `tf.data.Dataset.prefetch` 转换。
*   `tf.data.Dataset.interleave` 转换可并行化数据读取。通过使用 interleave 转换，您可以减轻各种数据提取开销的影响。
*   使用缓存转换在第一个 epoch 期间将数据缓存在内存中。`tf.data.Dataset.cache` 转换可以缓存数据集，无论是在内存中还是在本地存储上。这将节省一些操作（如文件打开和数据读取）在每个 epoch 中重复执行。
*   在一批数据集上向量化用户定义函数。数据集被传递给 map 转换。
*   在应用 interleave、prefetch 和 shuffle 转换时减少内存使用量。

#### TensorFlow Transform

TensorFlow Transform 库是 TensorFlow Extended (TFX) 的一部分，它允许您在训练模型之前执行转换，并生成一个 TensorFlow 图，该图在训练期间复现这些转换。使用 tf.Transform 可避免训练-服务偏差。在 Google Cloud 中，您可以使用 Cloud Dataflow 创建转换流水线。TF Transform 在训练和服务期间进行转换的一些步骤包括分析训练数据、转换训练数据、转换评估数据、生成元数据、馈送模型和服务数据，如图 3.4 所示。

### 复习题

1.  您是公司的数据科学家。您有一个数据集，其中所有特征均为类别特征。您使用某些算法训练了模型。某些算法对此数据效果良好，但更换算法后性能下降。哪种数据转换策略可能会提高模型性能？

    1.  将数据写入 TFRecords。
    2.  使用类别特征创建特征组合。
    3.  对所有类别特征使用独热编码。
    4.  对特征进行过采样。

2.  您正在从事一个基于神经网络的项目。提供给您的数据集包含不同范围的列。在为模型训练准备数据时，您发现梯度优化难以将权重移动到最优解。您应该怎么做？

    1.  使用特征构造来组合最强特征。
    2.  使用归一化技术。
    3.  通过去除缺失值的特征来改进数据清洗步骤。
    4.  更改分区步骤以减小测试集维度并获得更大的训练集。

3.  您在一家信用卡公司工作，被要求使用 AutoML Tables 基于历史数据创建一个自定义欺诈检测模型。您需要优先检测欺诈交易，同时将误报降至最低。训练模型时应使用哪个优化目标？

    1.  使对数损失最小化的优化目标。
    2.  在召回率为 0.50 时使精确率最大化的优化目标。
    3.  使精确率-召回率曲线下面积 (AUC PR) 最大化的优化目标。
    4.  使接收者操作特征曲线下面积 (AUC ROC) 最大化的优化目标。

4.  您是一名数据科学家，正在处理一个带有时间序列数据的分类问题，仅经过几次实验就在训练数据上实现了 99% 的接收者操作特征曲线下面积 (AUC ROC)。您尚未探索使用任何复杂算法，也未花费任何时间进行超参数调优。为了识别并修复问题，您的下一步应该是什么？

    1.  通过使用复杂度较低的算法来解决模型过拟合问题。
    2.  通过在模型训练期间应用嵌套交叉验证来解决数据泄露问题。
    3.  通过移除与目标值高度相关的特征来解决数据泄露问题。
    4.  通过调整超参数以降低 AUC ROC 值来解决模型过拟合问题。

5.  您正在 Vertex AI 上使用 TPU 训练 ResNet 模型，以直观地对汽车发动机缺陷类型进行分类。您使用 Cloud TPU 性能分析器插件捕获训练配置文件，并观察到其高度受输入限制。您希望减少瓶颈并加快模型训练过程。您应该对 `tf.data` 数据集进行哪些修改？（选择两项。）

    1.  使用 interleave 选项读取数据。
    2.  将 prefetch 选项设置为等于训练批次大小。
    3.  减少 repeat 参数。
    4.  减少转换中的批次大小参数。
    5.  增加 shuffle 的缓冲区大小。

6.  您受命为一个 ML 训练模型开发输入流水线，该模型以低延迟处理来自不同来源的图像。您发现输入数据无法放入内存。按照 Google 推荐的最佳实践，您应如何创建数据集？

    1.  创建 `tf.data.Dataset.prefetch` 转换。
    2.  将图像转换为 TFRecords，将图像存储在 Cloud Storage 中，然后使用 `tf.data` API 读取图像进行训练。
    3.  将图像转换为 `tf.Tensor` 对象，然后运行 `Dataset.from_tensor_slices()`。
    4.  将数据转换为 TFRecords。
