数据科学和数据挖掘是新兴的研究领域，它们允许我们分析大数据并利用分析结果做出明智的业务决策。本章介绍了数据科学和数据挖掘中的一些关键概念、AI 和 ML 的演变、数据挖掘如何在不同行业中用于提高安全和增强运营效率、大数据特征以及伦理考量。这些都是我们在深入数据挖掘过程和方法之前需要清楚的重要概念。与传统的统计研究倾向于理论驱动和使用小样本量不同，数据挖掘项目是探索性的、数据驱动的并使用大数据。本质上，我们的目标是从数据中发现未知的模式。换句话说，我们为业务收集了大量数据，我们需要找出这些数据能告诉我们关于业务运营的有用见解。我们从数据中发现的模式允许我们做出明智的决策来改进业务运营。

本章还涵盖了数据挖掘中的伦理考量。数据挖掘涉及从大型数据集中提取模式、知识和洞察，虽然它提供了价值信息，但也引发了重大的伦理关注。数据挖掘中的伦理考量是指负责任和尊重数据使用的原则、指南和道德价值观。遵循这些伦理原则和指南可确保数据挖掘是以负责任且尊重个人权利和福祉的方式进行的。这有助于在数据科学家和公众之间建立信任，促进数据驱动见解的积极影响，同时尽量减少潜在伤害。

## 数据挖掘过程

在第一章中，我们定义了数据挖掘并讨论了数据挖掘的一些主要特征。这是一种探索性的、数据驱动的方法，用于从大数据中检测未知模式，并为我们的业务提供见解，使能够做出明智的业务决策。为了正确执行数据挖掘，我们需要遵循一个过程，引导我们通过特定步骤来妥善地探索和分析数据。由于大数据往往带有噪声，结果出现错误的可能是。

## SEMMA 过程

第一个过程是 SEMMA，代表 `Sample-Explore-Modify-Model-Assess`（采样-探索-修改-建模-评估）。该过程由 SAS 研究所提出，但已应用于许多行业，特别是学术研究人员。SEMMA 实际上集成在 `SAS Enterprise Miner` 软件中，用于指导用户进行数据挖掘。SEMMA 是分析大数据以发现新模式时应遵循的数据挖掘步骤序列（图 2.1）。

```

```

图 2.1 SEMMA 过程。

下面解释了 SEMMA 过程中的每一步。

### 1. 采样 (SAMPLE)

在采样步骤中，我们从数据采样开始，即选择整个数据集的一部分（样本）用于分析。样本应该足够大，以包含足够的信息以供检索；同时又要足够小，以便高效使用。如果原始数据集过大，我们可以决定对其进行采样。例如，我们有一个包含 1000 万数据点的数据集，使用整个数据集可能会增加计算时间。对于数据挖掘而言，其中 10% 的数据就能为我们提供一百万条记录，这应该足够了。因此，我们想要采样 10% 的数据进行分析。

然而，如果我们没有正确地采样，我们的样本可能会偏离原始数据，从而产生采样偏差。换句话说，我们的样本不能代表整个数据集，数据挖掘的结果可能是无效的。因此，我们需要选择正确的采样方法来最大限度地减少采样偏差，并为数据挖掘获得一个高质量的数据集。

此外，此阶段还涉及数据划分，将数据划分为子样本。训练样本用于训练模型，验证样本用于验证模型。在某些情况下，我们还可以使用测试样本来测试最终模型。最后，如果我们的数据集是一个不平衡的数据集，模型可能会遭受过拟合。在这种情况下，可能需要重采样以确保数据集的平衡。不同采样方法的细节将在第 3 章中介绍。

### 2. 探索 (EXPLORE)

在探索步骤中，我们需要通过数据可视化，发现变量之间预期和意料之外的关系以及异常情况，来探索并理解数据。通过使用数据可视化，我们可以为不同的变量生成不同格式的多个图表。这样，我们可以对变量、尺度和数值有深入的理解。

这一步骤可以使用特征，如描述性统计、缺失值检测和变量选择。这是理解变量和数据的重要步骤，它允许我们决定在分析数据之前如何准备和修改数据。请记住，“垃圾进，垃圾出”的原则在这里仍然适用。

### 3. 修改 (MODIFY)

修改步骤用于为分析准备数据。根据探索步骤得的发现，我们可能需要转换、过滤或创建新变量，以提高数据集的质量。

### 4. 建模 (MODEL)

在建模步骤中，我们对数据应用各种建模技术以构建预测模型。这是一个迭代过程，我们通过测试不同的算法来找到与我们的数据最匹配的模型。

### 5. 评估 (ASSESS)

评估步骤用于根据初始业务目标评估所开发的模型。我们检查模型是否满足要求，并确定其是否准备好部署或是否需要进一步的迭代。

## CRISP-DM 过程

第二个过程是 CRISP-DM，代表 `Cross-Industry Standard Process for Data Mining`（跨行业数据挖掘标准流程）。这是一个广泛使用的数据挖掘过程模型，特别适合业务应用。CRISP-DM 包含六个主要步骤（图 2.2）：

1. 业务理解
2. 数据理解
3. 数据准备
4. 建模
5. 评估
6. 部署

```
![图 2.2 CRISP-DM 过程。](img/fig2_2.jpg)
```

图 2.2 CRISP-DM 过程。

下面解释了 CRISP-DM 过程中的每一步。

### 1. 业务理解

这一初始阶段专注于从业务角度理解项目目标和需求，然后将其转化为数据挖掘问题定义和初步计划。这包括识别业务目标、评估情况、确定数据挖掘目标和制定项目计划。

### 2. 数据理解

数据理解阶段从初始数据收集开始，并进行活动以熟悉数据、识别数据质量问题、发现数据中的初步见解或检测有趣的子集，从而为隐藏信息形成假设。这包括收集初始数据、描述数据、探索数据和验证数据质量。

### 3. 数据准备

数据准备阶段涵盖从初始原始数据构建最终数据集的所有活动，这些数据将输入建模工具。任务包括选择数据、清洗数据、构建数据、整合数据和格式化数据。这是数据挖掘项目中最耗时的阶段。

### 4. 建模

在建模步骤中，我们使用适当机器学习算法开发预测模型，并对这些模型进行特定配置。这是一个迭代过程。

### 5. 评估

在评估步骤中，我们评估、比较并选择预测准确性高且具有泛化能力的模型。在这一步中，我们需要仔细验证模型，以确保模型是可靠且有效的。最终结果是`冠军模型`（champion model）。

### 6. 部署

在最后一步部署中，我们将冠军模型的预测算法以代码的形式进行部署，并在操作系统中创建一个实际应用程序。该应用程序使用真实数据和经过验证的算法来做出实际预测。组织和企业可以此此应用程序商业化。

请注意，步骤的顺序并不是线性的。实际上，该过程需要在特定步骤之间来回移动。流程图使用箭头表示各个阶段之间主要且反复的相互连接。图中的外圆代表了数据挖掘中固有的迭代特性。即使在解决方案部署后，数据挖掘过程仍在继续。在整个过程中获得的洞察可能会引发新的业务查询，而未来的数据挖掘工作将从先前的迭代中积累的洞察中获益。

![](img/ufig2_3.jpg)

正如我们所看到的，CRISP-DM 非常注重实战导向，这就是为什么从业者在业界广泛使用它来解决现实业务问题。从学术研究的角度来看，SEMMA 更合适，因为它更侧重于执行数据挖掘的过程。尽管如此，哪种过程效果最好取决于你数据挖掘项目的目的。在本书中，我们将使用 SEMMA 过程作为数据挖掘示例和项目，因为我们没有涵盖在现实应用中部署预测算法的内容。需要注意的是，SAS Enterprise Miner 拥有将冠军模型部署到现实操作系统所需的所有功能，但完成该任务需要编程技能。

## USELEI 流程

在某些特殊情况下，我们的业务问题可能要求我们对海量数据中的变量进行因果推断。这是风险分析项目中的常见问题，因为我们想知道一个变量的变化是否会导致另一个变量的变化。在这种情况下，预期结果是基于一个预测变量的变化得出目标变量的概率。为了发现这种因果网络，应该使用一种特定方法——贝叶斯网络（Bayesian Networks），并在最后在假设我们有先验领域知识和因果假设的情况下进行因果推断。由于文献中还没有这种流程，我为此类项目开发了一种新流程。我将其命名为理解-采样-探索-学习-评估-推断（USELEI）流程（图 2.4）。该流程对于所谓的因果数据挖掘特别有用。我将在第 16 章中详细介绍这一流程和贝叶斯网络方法。

## 如何分类数据挖掘方法？

![](img/ufig2_4.jpg)

对于数据挖掘初学者来说，常见的问题是：“我应该用哪种方法来分析我的数据？”这是老师在教授统计课程时经常收到的问题。在这种情况下，学生通常期望一个清晰且具体的答案，以便他们可以使用该方法完成课堂作业或项目。我在数据挖掘课程中也面临相同的问题，我的学生通常期望我准确告诉他们应该使用哪种方法以及在分析中包含哪些变量。然而，数据挖掘的情况并非那么简单，因为数据挖掘项目是探索性的，而不是确认性的。我们的目标是从数据中发现未知模式。记得吗？我们想知道数据将告诉我们关于变量之间关系的什么。

这种选择并不是非黑即白那样简单清晰。我们需要考虑许多因素，即使如此，仍需要反复尝试。但没有人说数据挖掘是简单的。这就是为什么数据科学家这份工作非常有吸引力，因为它需要一套特定的技能。我记得 Netflix 曾举办过一次数据挖掘竞赛，所有团队都获得相同的数据集和一个目标变量。选择正确方法并配置正确算法以产生最佳预测的团队将赢得比赛。所以，你可以看到，数据挖掘中的困难使我们能够区分出优秀的数据科学家和平庸的数据科学家。

正如第 1 章所描述的，数据挖掘是一种探索性的、数据驱动的方法。数据挖掘项目的目的不是解释已经发生了什么或正在发生什么，而是从数据中发现未知的、隐藏的模式，以预测未来将来将发生什么。因此，对上述问题的简单回答是：“这取决于你的数据和你的项目目的。”当然，没有人会满意于这个答案，因为它太模糊了。但事实是，在探索和理解数据之前，我们不知道哪种方法可能有效。即使如此，鉴于数据的大量和噪声，很难推测哪种方法会产生最好的预测模型。但当我们作为数据科学家时，这类项目的现实是我们期望从数据中探索和发现新模式，而不是去确认我们已经知道或认为已经知道的。

数据挖掘是一个非常广泛的领域，包含许多方法，这可能会让数据科学家感到困惑。因此，确定如何为我们的项目目的选择合适的方法非常重要。在许多情况下，我们为分析选择多种方法，使用这些方法训练多个模型，并选择最好的一个。如前节所述，这个最好的模型被称为 `champion model`（冠军模型）。我们需要使用多种方法的原因是数据挖掘的探索性质。

分类数据挖掘方法有几种方法，根据数据类型或分析目的。数据类型通常包括定量和定性。定量数据是使用间距、比例或顺序尺度的数字。定性数据是文本、声音、图像和视频。我们还有混合数据，由定量和定性数据组成。自然地，大多数数据挖掘方法都是定量的，因为有许多定量分析数据的方法。另一方面，由于定性数据的性质，定性方法非常稀少。文本挖掘是我们是我们用于分析文本数据的典型方法。即使我们使用文本挖掘，最终也会应用一些定量方法来理解结果。用于分析声音、图像和视频的高级方法通常是基于定量的，例如 `convolutional neural networks`、`natural language processing` 或 `voice recognition`。你可以看到，即使我们拥有数据并知道我们拥有什么类型的数据，很难确定哪种方法效果最好。

![](img/ufig2_5.jpg)在本书中，我主要根据分析的目的是对数据挖掘方法进行分类。因此，当你清楚你的变量及其量纲，并且对数据分析有明确的目的时，你就应该能够确定可以用于开发预测模型的合适方法。然而，请注意，每种方法都有其优缺点，而且由于数据挖掘是一种数据驱动的方法，哪种方法最有效永远没有绝对的结论。换句话说，在运行数据分析之前，我们无法推测哪种算法对于给定数据效果最好。基本上，我们通过探索多个选项并根据分析结果确定最佳方法，这正是数据挖掘的主要目标。我的建议是选择几种方法并配置各种模型，以观察哪个模型产生最好的预测结果。即使我们选择只使用一种方法，我们也应该开发几个具有不同配置的模型并进行比较，以选出最好的一个。再次，那个模型被称为`冠军模型`（champion model）。请记住，这里的`最佳模型`一词是相对的；即，它不是真正的最好，因为我们必须测试所有可能的模型才能找到真正的最优。`最佳模型`指的是我们可用模型中预测准确率和预测能力最高的一个。因此，它是一个相对的最优。
