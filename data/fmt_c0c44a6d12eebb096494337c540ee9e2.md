
## 9.2.4 gSBX 中的均匀交叉

gSBX 同样引入了均匀交叉的理念，该方法已用于许多遗传算子中以提高多样性。具体而言，均匀交叉以 0.5 的概率交换两个后代 `c1` 和 `c2` 在每个维度上的决策变量。根据 (9.5)，我们有：

```
c1^i = x_1^i + (beta_1 - 1)(x_1^i - x_2^i) / 2
c2^i = x_2^i + (1 + beta_1)(x_1^i - x_2^i) / 2
c1^i = x_2^i - (beta_1 - 1)(x_1^i - x_2^i) / 2
```

因此，通过设置 `alpha_2 = -beta_1 - 1`，可以将 `c_2^i` 变为 `c_1^i`。同样，通过设置 `alpha_1 = -beta_2 - 1`，可以将 `c_1^i` 变为 `c_2^i`。

在交换 `c_1^i` 和 `c_2^i` 时应特别注意。例如，如果梯度 `g_1^i >= 0`，那么当 `x_1^i < x_2^i` 时将 `c_1^i` 变为 `c_2^i` 是不合理的，因为 `x_1^i` 应该沿着 `g_1^i` 的负方向移动。因此，应该应用某些限制来限制均匀交叉，只有当 `g_1^i(x_1^i - x_2^i) > 0` 且 `g_2^i(x_1^i - x_2^i) < 0` 时才能进行均匀交叉。总而言之，所提出的 gSBX 在 `beta_1 <= 0.5` 且 `g_1^i(x_1^i - x_2^i) > 0` 且 `g_2^i(x_1^i - x_2^i) < 0` 时将 `alpha_1` 和 `alpha_2` 设置为 `alpha_1 = -beta_2 - 1`，否则取反。

(9.12)

```
alpha_2 = { -beta_1 - 1,  lambda <= 0.5  and g_1^i(x_1^i - x_2^i) > 0,
            and g_2^i(x_1^i - x_2^i) < 0,
            beta_2 - 1,   otherwise }
```

其中 `lambda` 在每个维度上从均匀分布 `U[0, 1]` 中采样。
