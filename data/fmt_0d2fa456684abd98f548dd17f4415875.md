### 13.5.1 Helper.php

我们从 `Helper.php` 开始。在 Brackets 中打开此文件，你会看到我们创建名为 `Helper` 的类。该类没有属性和构造函数。在类内部，我们的任务是实现五个公共方法：`passwordsMatch()`、`isValidLength()`、`isEmpty()`、`isSecure()` 和 `keepValues()`。

让我们从 `passwordsMatch()` 方法开始。该方法有两个参数，`$pw1` 和 `$pw2`。在这个项目中，为了保持我们的代码与旧版本的 PHP 兼容，我们不会对函数和方法使用类型声明。考虑到这一点，请尝试自己动手声明 `passwordsMatch()` 方法。接下来，在方法内部，我们需要检查两个参数的值是否相等。如果是，我们返回 `true`；否则，我们返回 `false`。请尝试自己实现。提示：你需要使用一个 `if-else` 语句。一旦你完成了 `if-else` 语句，`passwordsMatch()` 方法就完成了。

接下来，让我们来看 `isValidLength()` 方法。该方法有三个参数 `$str`、`$min` 和 `$max`。`$min` 的默认值为 `8`，而 `$max` 的默认值为 `20`。如果你不熟悉函数（和方法）的默认值，可以参考第 7.1 节。在方法内部，我们需要检查 `$str` 的长度是否小于 `$min` 或大于 `$max`。如果是，我们返回 `false`。否则，我们返回 `true`。请尝试自己编写该方法。提示：你可以使用内置函数 `strlen()` 来获取 `$str` 的长度。

在 `isValidLength()` 方法之后，我们有了 `isEmpty()` 方法。该方法有一个参数 `$postValues`，它存储一个数组。该方法检查数组中是否任何一个元素为空字符串。在方法内部，我们需要使用 `foreach` 循环来遍历 `$postValues` 中的每个元素，并使用 `if` 语句检查该元素是否等于空字符串。如果是，我们返回 `true`。在遍历完所有元素后，如果没有发现空字符串，我们返回 `false`。换句话说，我们在 `foreach` 循环之外返回 `false`。请尝试自己编写这个方法。关于使用 `foreach` 循环的帮助，你可以参考第 6.3.5 节。

接下来，我们有 `isSecure()` 方法。该方法有一个参数 `$pw`，用于检查它是否包含至少一个小写字母、一个大写字母和一个数字。为了实现这一点，我们需要使用正则表达式。正则表达式允许我们将上述需求（用英文编写）转换为 PHP 可以理解的表达式。所有的正则表达式必须以分隔符开始和结束。该分隔符可以是任何非字母数字、非反斜杠且非空白的字符。常用的分隔符包括正斜杠（`/`）、井号（`#`）和波浪号（`~`）。我们将在代码中使用波浪号。

“至少一个小写字母”的正则表达式是 `~[a-z]+~`，其中 `~` 是分隔符，`[a-z]` 代表小写字母集，`+` 代表“至少一个”。“至少一个大写字母”的正则表达式是 `~[A-Z]+~`，“至少一个数字”的正则表达式对应是 `~[0-9]+~`。要检查 `$pw` 是否满足上述正则表达式，我们需要使用一个名为 `preg_match()` 的内置函数。

接下来，让我们来看 `Database.php` 文件。在这个文件中，我们创建了一个类 `Database`，其中包含三个常量 `SELECTSINGLE`、`SELECTALL` 和 `EXECUTE` 以及一个私有属性 `$pdo`。此外，我们还有一个用于创建新 `PDO` 对象的构造函数。你需要修改构造函数中的两个地方。首先，在第 13 行，你需要将“Your Password”更改为你的实际密码。接下来，注意 `$pdo` 是 `Database` 类的属性。我们在第 9.2 节中学习过，要访问类的任何属性，需要在类内部使用 `$this` 关键字。因此，在第 13 行，你需要更改：

`$this->pdo = …` 第 14 行也是如此。尝试自己来实现这一点。完成后，构造函数就编写完成了。接下来，我们需要在 `Database` 类中添加一个名为 `queryDB()` 的公共方法。编写这个方法需要你熟悉在 PHP 中预处理语句（prepared statements）。如果不熟悉，可以参考第 11.4 节。

`queryDB()` 方法有三个参数：`$sql`、`$mode` 和 `$values`。`$sql` 代表要执行的 SQL 语句，`$mode` 表示方法是否需要从数据库获取任何行，`$values` 的默认值为 `array()`（即空数组），用于将变量绑定到 `$sql` 中的占位符。尝试自己声明这个方法。

在方法内部，我们需要使用 `$pdo` 属性（提醒：你通过 `$this->pdo` 访问它）来准备 SQL 语句（`$sql`）并将结果赋值给变量 `$stmt`。尝试自己来实现这一点。接下来，我们需要将值绑定到 SQL 语句中的占位符。绑定的占位符和值是以二维数组（`$values`）传递给方法的。如果你不熟悉二维数组，请参考第 5.3.1 节。

假设占位符是 `:username` 和 `:password`，要绑定的变量分别为 `$uname` 和 `$pwd`，用户需要向 `queryDB()` 方法传递以下数组：

```php
$values = array(
  array(':username', $uname),
  array(':password', $pwd)
);
```

为了处理这个数组，我们使用下面的 `foreach` 循环：

```php
foreach($values as $valueToBind){
  $stmt->bindValue($valueToBind[0], $valueToBind[1]);
}
```

当该循环第一次运行时，数组 `(':username', $uname)` 被赋值给 `$valueToBind`。在循环内部，我们使用 `bindValue()` 方法将 `$uname`（`$valueToBind[1]`）绑定到 `:username`（`$valueToBind[0]`）。当循环第二次运行时，我们使用 `bindValue()` 方法将 `$pwd` 绑定到 `:password`。明白了吗？

将上述 `foreach` 循环复制到 `queryDB()` 方法中，并在继续操作之前确保你已经理解了它。

为占位符绑定值后，我们需要使用 `$stmt` 调用 `execute()` 方法。尝试自己来实现这一点。最后，我们需要判断是否有任何值可以被获取。我们使用第二个参数 `$mode` 来完成。`$mode` 可以取三个常量之一：`SELECTSINGLE`、`SELECTALL` 或 `EXECUTE`。这三个常量在之前的类中已经定义。我们使用 `if` 语句来判断是否应该获取任何结果。`if` 语句的工作原理与下面的伪代码类似：

```php
if ($mode is not equal to SELECTSINGLE, SELECTALL and EXECUTE){
  throw an Exception('Invalid Mode' 作为错误消息
} else if ($mode equals SELECTSINGLE){
  使用 $stmt 来调用 fetch(PDO::FETCH_ASSOC) 方法并使用 return 关键字返回结果
} else if ($mode equals SELECTALL){
  使用 $stmt 来调用 fetchAll(PDO::FETCH_ASSOC) 方法并使用 return 关键字返回结果

```

首先，我们检查 `$mode` 的值是否有效（即它必须是 `SELECTSINGLE`、`SELECTALL` 或 `EXECUTE` 之一）。接下来，我们检查 `$mode` 是否为 `SELECTSINGLE` 或 `SELECTALL`，并分别使用 `$stmt` 变量调用 `fetch(PDO::FETCH_ASSOC)` 或 `fetchAll(PDO::FETCH_ASSOC)` 方法。然后我们使用 `return` 关键字返回获取的结果。尝试自己将伪代码转换为 PHP 代码。

**提示**：要访问 `Database` 类中定义的常量，你需要使用 `self` 关键字或类名后跟 `::` 运算符。例如，要访问 `EXECUTE`，你可以写成 `Database::EXECUTE`。关于在类中使用常量，请参考第 9.7 节。要抛出异常，你只需创建一个新的 `Exception` 对象并将错误消息传递给构造函数。关于抛出异常，请参考第 12.1.3 节。一旦你完成了 `if` 语句，`queryDB()` 方法就完成了，`Database` 类也是如此。
