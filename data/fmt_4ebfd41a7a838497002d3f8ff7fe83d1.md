
# 13.5 当贝叶斯推断遇上稀疏性

稀疏性感知学习的贝叶斯方法很快将成为我们的主要关注点。不过，我们将利用这一节来“热身”。先验概率密度函数（PDF）的使用与代价函数正则化之间的密切关系，已在第 12.2.2 节中讨论过。在那里，对于回归任务，采用高斯先验并结合高斯噪声，导致了最大后验估计（MAP）与岭回归的等价性。稍作推导便可表明，将噪声建模为高斯分布，并为每个权重采用拉普拉斯先验，即

$$
p(\theta_k) = \frac{\lambda}{2}\exp\left( - \lambda|\theta_k| \right),
$$

会使 MAP 等价于最小二乘（LS）代价的 $\ell_1$ 范数正则化。然而，对于一个对代价函数不感兴趣的贝叶斯派而言，拉普拉斯先验中隐藏的秘密在于该分布的**重尾**特性。这与具有极**轻尾**的高斯 PDF 形成鲜明对比。换句话说，高斯随机变量的观测值远离其均值的概率下降得非常快。例如，观测到的变量偏离均值超过 $2\sigma$、$3\sigma$、$4\sigma$ 和 $5\sigma$ 的概率分别为 0.046、0.003、$6 \times 10^{-5}$ 和 $6 \times 10^{-7}$。也就是说，如果我们提供高斯先验，基本上就是告知学习过程去寻找均值“附近”的值；远离均值的值会受到严重惩罚。然而，在稀疏性感知学习中，这将是传递给学习机制的错误信息。假设先验均值为零，虽然我们预期参数的大多数分量为零，但仍希望其中少数分量较大。因此，我们的先验信息应当选择那些赋予大数值以较小（但不过小）概率的分布。因此，对贝叶斯派而言，稀疏性感知学习便等同于施加重尾先验。现在让我们回到当前任务，看看这一简短介绍如何与我们的模型相关联。根据公式 (13.23) 和 (13.24) 的模型，我们的先验 PDF $p(\boldsymbol{\theta})$ 是通过边缘化掉超参数 $\boldsymbol{\alpha}$ 获得的（问题 13.10），即

$$
p(\mathbf{\theta};a,b) = \int p(\mathbf{\theta}|\mathbf{\alpha})p(\mathbf{\alpha})\ d\mathbf{\alpha} = \int\prod\limits_{k = 0}^{K - 1}\mathcal{N}\left( \theta_{k}|0,\alpha_{k}^{- 1} \right)\text{Gamma}(\alpha_{k}|a,b)\ d\mathbf{\alpha} = \prod\limits_{k = 0}^{K - 1}\text{st}\left( \theta_{k}|0,\frac{a}{b},2a \right),
$$

其中 $\text{st}(x|\mu,\lambda,\nu)$ 是 Student's $t$ 概率密度函数，定义为

```
st(x|\mu,\lambda,\nu) = \frac{\Gamma(\frac{\nu + 1}{2})}{\Gamma(\frac{\nu}{2})}\left( \frac{\lambda}{\pi\nu} \right)^{1/2}\frac{1}{\left( 1 + \frac{\lambda{(x - \mu)}^{2}}{\nu} \right)^{\frac{\nu + 1}{2}}}.
```

参数 *ν* 称为自由度。图 13.5 显示了不同 *ν* 值下 Student's *t* 概率密度函数（PDF）的图形。当 *ν* → ∞ 时，Student's *t* 分布趋向于具有相同均值和精度 *λ* 的高斯分布。观察 Student's *t* PDF 的重尾特性，尤其是在 *ν* 取较低值时。回顾我们的情况，由于使用了无信息超先验，超参数 *a* 被赋予了一个较小的值。因此，本节的处理倾向于回归模型的稀疏解。它会尽可能将参数 `θ[k]` 推向零。也就是说，通过将相应参数设为零来剪枝不太相关的基函数 `ϕk`。这也是对每个参数 `θ[k]`（`k = 0, 2, …, K − 1`）使用不同超参数 `α[k]` 的原因，这为学习过程提供了更大的自由度来单独调整它们。在早期，这种方法被称为自动相关性确定（ARD）[48, 53, 55]。文献 [24] 提供了关于自适应正则化与剪枝关系的有趣讨论。

![图 13.5 观察到对于低自由度值 *ν*，Student's *t* PDF 具有重尾。相反，高斯 PDF 是轻尾 PDF。](img/gr005.jpg)

文献 [42] 提出了各种促稀疏先验的统一。这些源自公式 (13.52) 的起始积分，通过代入 `p(a)` 的不同分布而得到。除了 Student's *t* PDF，还可以得到拉普拉斯分布、马蹄分布、广义双曲分布和正态-杰弗里斯分布作为特例。这一先验族被称为高斯尺度混合（GSM）先验。

图 13.6A 清楚地演示了 Student's *t* 分布施加稀疏性的特性。在二维空间中，当远离零点时，概率质量倾向于坐标轴；即 PDF 在稀疏解附近达到峰值，从而**从概率上强制稀疏性**。相反，高斯分布不太给大值机会（参见图 13.6B）。

![图 13.6 (A) Student's *t* 在零点附近尖锐峰值并沿轴缓慢下降；因此，稀疏解受青睐。(B) 高斯分布在零点附近峰值并沿所有方向快速衰减。](img/gr006.jpg)

# 13.6 稀疏贝叶斯学习

在第 13.3 节中，每个未知参数 `θ[k]`（`k = 0, 1, …, K − 1`）的先验被赋予了各自的方差 `σ_k² := 1/α_k`。反过来，这些方差被视为隐随机变量，并以一组超参数的形式为每个方差分配了先验。

文献 [88, 96] 中模型稍作修改。保留了为先验使用不同方差的概念，但将方差视为确定性参数而非随机变量。^(⁹¹)

```
p(y|θ; β) = N(y|Φθ, β^(−1)I),
```

```
p(θ; α) = N(θ|0, A^(−1)),
```

![Equation](img/si221.png) (13.55)

其中

`A := diag{α[0], …, α[K − 1]}`.

![Equation](img/si222.png) (13.56)

精度 `β` 也被视为未知的确定性参数。我们的目标是 (a) 获取 `β` 和 `α[k]`（`k = 0, 1, …, K − 1`）的估计值，以及 (b) 计算预测分布 `p(y|x, y)`，其中 `y` 是观测向量。^[92]

在本节中，我们将采用一条不同的路径，利用所涉及概率密度函数（PDF）的高斯特性。将采用 II 型最大似然法，该方法在备注 12.2 中已介绍。II 型似然被定义为在积分消去参数 `θ` 后的边际似然。遵循第 12.2 节中的讨论并为满足我们当前的需求，公式 (12.15) 写为

`p(y; α, β) = N(y|0, β^(−1)I + ΦA^(−1)Φ^(T))`.

![Equation](img/si225.png) (13.57)

此外，为了完整起见，公式 (12.16)、(12.17) 和 (12.10) 采取以下形式

`p(θ|y; α, β) = N(θ|μ, Σ; α, β)`,

![Equation](img/si226.png) (13.58)

其中

`μ = βΣΦ^(T)y`, `Σ = (A + βΦ^(T)Φ)^(−1)`.

![Equation](img/si227.png) (13.59)
