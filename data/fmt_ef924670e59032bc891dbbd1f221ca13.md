正如我们通过观察浅滩水面可以发现某些迹象一样，你在虚拟世界中的扫描和枚举工作将引导你走向正确的方向。而且，一旦你对正在查看的内容有了某些经验，你的连接成功率将会提高。正如本学习指南的伴随书籍——*CEH Certified Ethical Hacker All-in-One Exam Guide, Fifth Edition* 中提到的，既然你已经学会了如何对客户进行足迹探测（footprint），现在是时候学习如何在你发现的内容中挖掘相关且显著的信息了。在足迹探测之后，你需要进行基础扫描；然后当你发现一台运行中的机器时，你需要深入了解它，提出一些相当“隐私”的问题。

![Image](img/examp.jpg)

**学习技巧**

首先，最重要的是精通你的通用网络知识。对端口号、协议和通信握手了如指掌般熟悉。顺便，花些时间思考并写下你能想到的一个系统与另一个系统通信时会发生的所有步骤。了解该过程是如何启动的——系统首先在哪里查找名称解析、哪些协议找到你所需的 MAC 和 IP 地址、使用了哪些传输协议以及为什么——这不仅有助于你通过这次考试，还会让你成为一名更好的渗透测试员。

学习路由/交换基础知识如何影响你的工作：例如，你应该知道`routing`协议（如 `OSPF` 或 `BGP`）决定了路由器之间如何通信以及如何做出数据包移动决策，而`routed`协议（如 `IP`）是提供网络层地址的协议。虽然这类问题并不多，但关于子网划分的问题将会出现，所以要熟练掌握数学。

在扫描方面，要非常熟悉你的扫描工具。EC-Council 绝对*喜爱* `nmap`，所以要熟悉它的语法、响应、结果、开关……以及所有内容。你将就各种扫描工具的使用、输出、语法等接受抽测提问，因此要通过练习来准备——这是准备此考试的绝对最佳方法。

最后，Windows 和 Linux 架构基础知识不会占据考试的大部分内容，但请放心，你将会在这些方面上接受测试——特别是两者之间的任何不同之处。例如，某些工具可以在 Windows 上运行，但在 Linux 上不行，反之亦然。每种架构都有内置工具和服务（例如，要非常熟悉 Windows 中 `net` 命令的使用），这些工具在另一种架构上的运行方式可能不同，所以请务必重点学习这些内容。
