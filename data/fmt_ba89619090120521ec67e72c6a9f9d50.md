# 第 6 章：领域 5：身份与访问管理

## 1. 哪种密码破解攻击在给定足够时间后总会成功？

1. A. 暴力破解
2. B. 字典攻击
3. C. 混合攻击
4. D. 彩虹表攻击

**正确答案及解析：A**。答案 A 正确；给定足够时间，暴力破解攻击总会成功。

### 错误答案及解析

`B`、`C` 和 `D`。答案 `B`、`C` 和 `D` 均不正确。字典攻击只能破解存在于字典或单词列表中的密码。混合攻击会在字典单词的后面追加、前面前置或修改字符。彩虹表使用预计算的哈希值。并非所有彩虹表都是完整的，且彩虹表对加盐哈希的效果较差。

## 2. 密码破解和密码猜测有什么区别？

1. A. 它们是相同的
2. B. 密码猜测尝试登录系统；密码破解尝试确定用于创建哈希的密码
3. C. 密码猜测使用盐值；密码破解不使用
4. D. 密码破解有账户锁定风险，密码猜测没有

### 正确答案及解析

**B**。答案 `B` 正确；密码破解依赖于破解密码的哈希值；密码猜测尝试登录系统。

### 错误答案及解析

`A`、`C` 和 `D`。`A` 不正确：密码猜测与密码破解不同。`C` 不正确，因为盐值是密码破解的问题，而非密码猜测的问题。`D` 不正确：密码猜测存在账户锁定风险。

## 3. 同一系统上的两个用户拥有相同的密码，但 `/etc/shadow` 文件中存储的哈希值不同。哈希值不同的最可能原因是什么？

1. A. 用户名不同，所以哈希值会不同
2. B. 使用了多种哈希算法
3. C. 使用了彩虹表
4. D. 使用了盐值

### 正确答案及解析

**D**。答案 `D` 正确；盐值是一个与用户密码一起进行哈希运算的随机数，这使得两个密码相同的用户极不可能拥有相同的哈希值。

### 错误答案及解析

`A`、`B` 和 `C`。答案 `A`、`B` 和 `C` 均不正确。在大多数系统中，不同的用户名不会影响密码哈希。在同一系统上使用多种哈希算法是可能的，但不太可能。彩虹表不用于创建哈希；它们作为数据库，包含大多数或所有可能密码的哈希输出。

## 4. 哪种认证方法会以明文形式暴露密码？

1. A. CHAP
2. B. Kerberos
3. C. PAP
4. D. SESAME

### 正确答案及解析

**C**。答案 `C` 正确；密码认证协议 (`PAP`) 在网络上以明文形式暴露密码。

### 错误答案及解析

`A`、`B` 和 `D`。答案 `A`、`B` 和 `D` 均不正确。`CHAP`、`Kerberos` 和 `SESAME` 均不会暴露明文密码。

## 5. 视网膜扫描和虹膜扫描的主要区别是什么？

1. A. 视网膜扫描无创，虹膜扫描有创
2. B. 虹膜扫描侵犯个人隐私，视网膜扫描不侵犯
3. C. 虹膜扫描随个人健康状况变化，视网膜扫描稳定
4. D. 视网膜扫描随个人健康状况变化，虹膜扫描稳定

### 正确答案及解析

**D**。答案 `D` 正确；视网膜中的血管可能因特定健康状况而发生变化。

### 错误答案及解析

`A`、`B` 和 `C`。`A` 不正确，因为视网膜扫描是有创的——它们可能泄露用户健康信息。`B` 不正确，因为虹膜扫描无创。`C` 不正确，因为虹膜扫描（相对而言）稳定，不受尝试访问用户的总体健康状况影响。

## 6. 组织在实施基于角色的访问控制 (RBAC) 时，需要做出的最重要的决定是什么？

1. A. 确定每个用户的安全许可
2. B. 明确定义用户在系统中的角色
3. C. 明确标记用户的数据
4. D. 用户必须在 IT 系统中相互隔离，以防止敏感数据泄露

### 正确答案及解析

**B**。答案 `B` 正确；在基于角色的访问控制 (`RBAC`) 中，必须明确定义用户的角色，以便根据这些角色限制对数据的访问，符合组织策略。

### 错误答案及解析

`A`、`C` 和 `D`。答案 `A` 不正确，因为在 `RBAC` 中不考虑用户的许可。答案 `C` 不正确，因为 `MAC` 会给每个对象打标签并将其与主体的许可进行比较，而非 `RBAC`。答案 `D` 不正确，因为在 `RBAC` 中用户不会相互隔离。

## 7. 哪种访问控制方法在授予访问权限前，可以审查诸如尝试访问时间等额外因素？

1. A. 自主访问控制
2. B. 基于属性的访问控制
3. C. 基于角色的访问控制
4. D. 基于规则的访问控制

### 正确答案及解析

**B**。答案 `B` 正确；基于属性的访问控制 (`ABAC`) 允许考虑无数额外因素，包括尝试访问时间等要素，以做出访问控制决策。

### 错误答案及解析

`A`、`C` 和 `D`。答案 `A`、`C` 和 `D` 均不正确。自主访问控制涉及由主体控制对对象的访问，主体对其创建或被授予完全控制权的对象拥有完全控制权。基于角色的控制基于主体的角色。基于规则的访问控制考虑管控访问决策的已定义规则，最常与防火墙或类似类型的控制相关联。

## 8. 哪种服务被称为云身份，并允许组织利用云服务进行身份管理？

1. A. IaaS
2. B. IDaaS
3. C. PaaS
4. D. SaaS

### 正确答案及解析

**B**。答案 `B` 正确；身份即服务 (`IDaaS`)，也称为云身份，允许组织利用云服务进行身份管理。

### 错误答案及解析

`A`、`C` 和 `D`。答案 `A`、`C` 和 `D` 均不正确。`IaaS`（基础设施即服务）提供完整的虚拟化操作系统，由客户从操作系统层面向上进行配置。`PaaS`（平台即服务）提供预配置的操作系统，由客户配置应用程序。`SaaS`（软件即服务）从操作系统到应用程序均已完全配置，客户只需使用应用程序即可。

## 9. 第二类生物特征错误还被称为？

1. A. 交叉错误率 (CER)
2. B. 等错误率 (EER)
3. C. 错误接受率 (FAR)
4. D. 错误拒绝率 (FRR)

### 正确答案及解析

**C**。答案 `C` 正确；错误接受率 (`FAR`) 被称为第二类错误。请记住，错误拒绝通常比错误接受更严重，且 II 大于 I。

### 错误答案及解析

`A`、`B` 和 `D`。答案 `A`、`B` 和 `D` 均不正确。交叉错误率 (`CER`) 和等错误率 (`EER`) 是同义词，用于衡量生物特征系统的准确性。错误拒绝率 (`FRR`) 是第一类错误。

## 10. 在 Kerberos 中，哪个部分是单点故障？

1. A. 票据授予票据
2. B. 领域
3. C. 密钥分发中心
4. D. 客户端-服务器会话密钥

### 正确答案及解析

**C**。`C` 是正确答案，因为 `KDC` 是 Kerberos 中唯一能够认证主体的服务。如果 `KDC` 失去可用性，则不会签发票据授予票据，也无法进行新的认证。

### 错误答案及解析

`A`、`B` 和 `D`。`A` 不正确，因为 `TGT` 是由主体从 `KDC` 接收的。`B` 不正确，因为领域是共享认证的 Kerberos 网络。`D` 不正确，因为可以签发新的 C-S 会话密钥。

## 11. 什么是用于交换安全信息（包括认证数据）的基于 XML 的框架？

1. A. Kerberos
2. B. OpenID
3. C. SAML
4. D. TACACS

**错误答案与解析：** `A`、`B` 和 `D`。答案 `A`、`B` 和 `D` 不正确。`Kerberos` 是一种第三方认证服务，可用于支持单点登录。`OpenID` 是一种用于交换认证数据的框架，但并非基于 XML。`TACACS` 是一种集中式访问控制系统，要求用户发送 ID 和静态（可重用）密码进行认证。

## 12. 哪种认证协议利用令牌来传达身份信息详情？

1. A. OAuth
2. B. OIDC
3. C. SAML
4. D. Kerberos

**正确答案与解析：** `B`。答案 `B` 正确；`OpenID Connect (OIDC)` 采用令牌（如 ID 令牌），并被定义为一种认证协议。

**错误答案与解析：** `A`、`C` 和 `D`。答案 `A`、`C` 和 `D` 不正确。`OAuth` 确实使用令牌，但它提供的是授权而非认证。`SAML` 和 `Kerberos` 都可被视为认证协议，但两者均不使用令牌来传达身份信息。`SAML` 使用断言，而 `Kerberos` 通过票据运作。

## 13. 服务器 A 信任服务器 B。服务器 B 信任服务器 C。因此服务器 A 信任服务器 C。什么术语描述了这种信任关系？

1. A. 域信任
2. B. 林信任
3. C. 非传递信任
4. D. 传递信任

**正确答案与解析：** `D`。`D` 是正确答案。传递信任存在于两个合作伙伴及其所有合作伙伴之间。例如：如果 A 信任 B，在传递信任中，A 将信任 B 以及 B 的所有信任合作伙伴。

**错误答案与解析：** `A`、`B` 和 `C`。域信任和林信任是不那么具体的术语，不一定要求是传递的。非传递信任是传递信任的反面。

## 14. 一项规定用户在尝试查看数据前必须有业务需求的策略，是强制执行什么的示例？

3. C. 职责轮换
4. D. 职责分离

**错误答案与解析：** `A`、`C` 和 `D`。答案 `A`、`C` 和 `D` 不正确。最小权限比需知原则粒度更粗：用户拥有完成工作所需的最小权限，但对象通常仍被分组在一起（例如允许备份管理员访问所有备份磁带）。职责分离旨在将敏感任务分配给多个主体。职责轮换旨在缓解串通舞弊。

## 15. 在指纹扫描系统中，什么技术会提高误接受率 (FAR) 并降低误拒率 (FRR)？

## 6. 哪种测试类型向渗透测试人员提供内部信息，包括网络图、策略和程序，有时还包括之前渗透测试人员的报告？
