
![](img/shut7_1.jpg)我们已经涵盖了 SEMMA 过程的前三个步骤：采样、探索和修改。所有这些努力都是为了在该过程中最重要的一步——建模做准备。在这一步中，研究人员选择机器学习方法，构建并配置多个模型，使用数据训练模型并对模型进行评估。这些步骤的结果是预测模型，它们产生对目标变量的预测结果。因此，你可以看到这一步在数据挖掘中的重要性，以及为什么我们需要正确地执行它。这一步中的任何错误都会导致预测模型失效。为了正确且高效地完成建模步骤，理解我们所选机器学习方法的底层基础并进行适当的配置至关重要。

我将用最流行的数据挖掘方法——回归来开启建模步骤。本章描述了两种回归方法：线性回归和逻辑回归。它们在许多研究领域被广泛使用，因为其分析过程标准且直观，结果也易于解释。这些方法允许我们推导出反映预测变量与目标变量之间关系的回归方程。例如，这些方法可以用于预测客户对产品的购买情况或航班延误的风险。

![](img/ufig7_1.jpg)本质上，线性回归是在目标变量为连续型时的一种关联方法。目标变量与预测变量之间的关系是线性关系。另一方面，逻辑回归是在目标变量为二元（逻辑回归）或分类（多项逻辑回归）时的一种分类方法。这种回归以 logit 函数的形式呈现了预测变量与目标变量之间的非线性关系。由于回归方法出现在大多数统计学书籍和课程中，本章将对其统计基础进行简要描述，更多地关注如何将这些方法用于数据挖掘目的。我将使用一些实际示例来演示和解释数据挖掘过程以及如何解释结果。如果你对学习这些方法的统计基础感兴趣，我包含了一些你可以使用的参考文献。

## 什么是回归方法？

回归是一种流行的方法，用于估计一个因变量（目标变量）和多个自变量（预测变量）之间的关系。回归的目标是找到一个数学函数或模型，根据自变量的值来预测因变量的值。注意，在大多数统计书中，作者使用`dependent variable`和`independent variable`这两个术语。我将坚持使用书中的术语`target variable`和`predictor`，以确保一致性。但你应该记住，在本章中，`target variable`等同于因变量，而`predictor`等同于自变量。

![](img/ufig7_2.jpg)让我们来看一个例子。假设我们想预测客户是否选择去餐厅用餐。因此，目标变量是用餐决策（是或否）。预测变量可能包括性别、种族、年龄、教育、收入、饮食偏好和健康状况。从数据导出的回归模型可以识别与用餐决策有显著关系的预测变量，并估计这些预测变量与目标变量之间的数学关系。具体来说，回归方法通过估计模型中预测变量的系数（权重），来最小化目标变量预测值与实际值之间的差异。

回归方法的主要优势是易于理解、使用和解释。回归的数学基础与我们在统计课程中看到的相同，因此很容易找到。在书中，我将更多地关注其目的以及如何使用它。

## 线性回归与逻辑回归

![](img/ufig7_3.jpg)回归主要有两种类型：线性回归和逻辑回归。两者都是具有某些差异的方法。线性回归是一种目标变量为连续型的关联方法。![](images/ufig7_4.jpg)另一方面，逻辑回归是一种目标变量为二元的分类方法。在这种情况下，我们称之为逻辑回归。为了避免混淆，下表`Table 7.1`提供了线性回归和逻辑回归的示例。

### 表 7.1 线性回归与逻辑回归示例

| 回归方法 | 示例 |
| --- | --- |
| 线性回归 | 目标变量是学生的成绩；它是从 0 到 600 的连续变量。预测变量包括年龄、种族、高中 GPA 和收入。 |
| 逻辑回归 | 目标变量是学生选择某个专业的决策（二元变量）。另一个例子是学生选择四个专业之一的：营销、会计、财务或管理。预测变量包括年龄、种族、高中 GPA 和收入。 |

![](img/ufig7_5.jpg)由于目标变量的不同，这些方法使用了不同的估计方法，导致了假设和结果解释上的差异。具体来说，线性回归使用普通最小二乘法（`OLS`）来估计回归方程。另一方面，逻辑回归使用极大似然法（`ML`）进行估计。

这些方法的回归方程如下所示。我尝试避免典型的数学符号，以使方程更容易理解，因此我用更有序的方式命名变量，而不是使用希腊字母。

对于线性回归：

```
target = c1*predictor + c2*predictor + c3*predictor + ... + error
```

对于逻辑回归：

```
logit(target) = c1*predictor + c2*predictor + c3*predictor + ... + error
```

其中

1.  `target` 是目标变量
2.  `predictor` 是预测变量
3.  `int` 是截距
4.  `coe` 是对应预测变量的回归系数
5.  `error` 是误差项

你可以发现，在逻辑回归中，我们并不直接估计目标变量，而是估计该变量的 logit 值。当然，理解 logit 值的含义非常困难。因此，当我们解释逻辑回归的结果时，我们将使用优势比（odds ratios）而不是相关系数。我很快会详细介绍。

![](img/ufig7_6.jpg)图 7.1 中的图表展示了线性回归方程与逻辑回归方程的区别。如你所见，线性回归只能检测目标变量（`Y`）与预测变量（`X`）之间的线性关系。另一方面，逻辑回归可以检测目标变量（`Y`）与预测变量（`X`）之间以 logit 函数形式存在的非线性关系。在逻辑回归中，目标变量是二元的（0 或 1），因此 `Y` 只能是值之一。但注意，`logit(Y)` 与 `X` 之间的关系仍然是线性的，如上面的方程所示。因此，逻辑回归检测非线性关系的能力局限于 logit 函数和相关系数的线性效应。这是逻辑回归与其他非线性方法（如决策树、神经网络或随机森林）之间的主要区别，后者可以检测更复杂的非线性形式。

### 估计方法

本质上，估计方法是用于计算回归方程所有组件的值（包括截距、回归系数和误差项）的统计方法。普通最小二乘法（OLS）是线性回归的估计方法。它是一种常用的方法，用于使误差平方和最小化。`OLS` 的数学基础在许多统计书中都有解释，因此我在这里进行了介绍。我想强调的是，使用这种方法会对线性回归产生一些严格的假设。

### 假设要求

![](img/ufig7_7.jpg)传统统计研究中的线性回归受到非常严格的假设限制以确保结果的有效性，包括正态性、同方差、线性、非共线性、连续变量无缺失值。换句话说，当我们违反这些假设时，软件仍然运行分析并产生输出。然而，我们无法确定结果是否有效，因此无法据此得出有效的结论。注意，在传统的统计研究中，我们通常只有少量预测变量（独立变量）并使用非常小的样本量。例如，如果我们有 5 个预测变量并使用 0.25 的效应量，所需的样本量为 57 条记录。如果有 10 个预测变量，我们只需要 75 条记录的样本。

在数据挖掘中，我们使用具有许多预测变量和极大样本量的数据集。因此，我们在假设方面在线性回归具有更大的灵活性；即我们不需要像传统统计研究那样完全满足所有假设即可运行分析。主要原因是根据中心极限定理，当样本量足够大，样本分布可以假设为近似正态。因此，当我们将线性回归作为机器学习算法处理大数据时，我们不需要测试并满足所有假设。尽管如此，仍然建议检查几个关键项目并在某种程度上进行数据转换或修改，因为这有助于提高回归模型的性能。例如，线性回归在完整数据集上运行更好，因此强烈建议处理和填充缺失值。此外，由于正态性是该方法的一个重要假设，对数据归一化允许我们获得更好的模型拟合。最后，处理异常值会减少数据中的噪声，从而获得更好的拟合模型。

![](img/icon_8.jpg)你可能会问：如果不符合测试假设，我们还需要担心结果的有效性吗？这是一个很好的问题，因为我们应该始终关注结果的可靠性和有效性。在数据挖掘研究中，我们使用更严格的步骤来确保结果质量。如第 3 章所示，我们通常将样本分为训练样本、验证样本和测试样本。训练样本用于训练模型，验证样本用于验证模型。这是确保训练的模型对于训练样本之外的样本也是有效的；即我们没有过拟合问题。通过比较这三个样本的模型结果，我们可以评估模型的性能并确保模型的可靠性和有效性。因此，即使我们不满足所有假设，这些步骤仍然允许我们保证可靠性。

### 关键假设

虽然我们不需要满足所有假设，但仍然需要检查以下内容：

- **目标变量必须是连续的**：这对于建立模型非常重要。
- **预测变量必须是连续的**：这是一个关键要求，尽管数据挖掘中具有一定的灵活性。
- **正态性**：这是参数方法最常用的假设之一，特别是 `OLS`。虽然我们不需要达到完全的正态，但越接近正态分布模型越好。
- **非共线性**：线性回归假设预测变量是独立的。共线性表示独立变量之间存在相关性，我们需要在运行分析之前证明它不存在。
- **无缺失值**：对于传统统计研究，回归分析需要完整的数据集。

### 线性回归模型拟合评估

在 `OLS` 过程中，评估模型拟合情况非常重要。那么什么是模型拟合？我们已经在第 6 章中详细介绍过。基本上，一方面，我们有由回归方程表示理论回归模型；另一方面，我们有目标变量和所有预测变量的数据。现在我们需要将数据拟合到该理论模型上，看看它们是否拟合良好。模型拟合衡量了我们的模型与数据的拟合程度。

```
Residuals = Actual data – Predicted data
```

我在第 6 章中描述了关联模型的通用模型拟合指标，包括 `RMSE`、`MAPRE`、`RSE`、`Ethe P`、实际值预测值图以及残差预测值图。在本章中，我将专注于线性回归方法的特定指标。具体来说，当我们使用线性回归时，还需要评估 `F-test` 和 `R²`。表 7.4 解释了这些指标以及如何使用它们。

### 表 7.4 线性回归特定的模型拟合指标

| 指标 | 描述 |
| --- | --- |
| F-test | `F-test` 用于检验整体模型的显著性。换句话说，显著的 `F-test` 表示我们的回归模型比没有任何预测变量的模型更拟合数据。我们期望得到显著的 `F-test`。 |
| `R²` 或决定系数 | `R²` 是线性回归模型常用的模型拟合指标。它衡量了目标变量的方差中由预测变量共同解释的百分比。对于 `R²` 没有标准的优劣标准，因为它取决于模型中预测变量的数量。然而，我的经验准则如下：<br><br>* `R²` 高于 0.7：模型拟合良好<br>* `R²` 在 0.5–0.7 之间：模型拟合可接受<br>* `R²` 低于 0.5：模型拟合较差<br><br>注意，`R²` 的解释应基于模型中预测变量的数量，因为预测变量越多，`R²` 越低。因此，对于许多预测变量的模型（这通常是），较低的 `R²` 是可以接受的。 |
| Adjusted `R²` | `Adjust R²` 是 `R²` 的修正版本，仅考虑对模型性能有影响的预测变量。建议使用 `adjusted R²`。使用上述相同的阈值。 |

在线性回归中，当我们回顾 `F-test` 和 `R²` 的材料时，可能会看到一些术语、符号和公式。我将它们包含在表 7.5 中以便快速参考。以下是显示如何使用 `SSR` 和 `SSE` 计算 `SST` 的公式。

### 表 7.5 线性回归中的关键术语和符号

| 术语 | 符号 | 描述 |
| --- | --- | --- |
| 目标变量 (Target variable) | `y` | 目标变量（因变量）的实际值。 |
| 预测变量 (Predictor) | `x` | 预测变量（自变量）的实际值。 |
| 目标变量均值 (Mean of target variable) | $\bar{y}$ | 目标变量的平均值。 |
| 预测值 (Predicted value) | $\hat{y}$ | 模型估计的目标变量预测值。 |
| 误差 (Error) | `e` | `Error`（残差）是目标变量实际值与预测值之间的差异。 |
| 误差平方和 (Sum of Squared Error) | `SSE` | 数据与模型预测值的距离。 |
| 总平方和 (Sum of Squared Total) | `SST` | 数据与均值的距离。 |
| 回归平方和 (Sum of Squared Regression) | `SSR` | 均值与模型预测值的距离。 |

```
R^{2} = \frac{SST - SSE}{SST} = \frac{Explained variance}{Total variance}
```

正如第 6 章所解释的，这些公式仅适用于线性回归，而不适用于其他方法。你可以看到，在线性回归中，`R²` 实际上与我们在第 6 章中讨论的解释力相同。

### 模型选择过程

![](img/icon_7.jpg) 在回归建模过程中，模型选择是训练模型的关键步骤。它描述了预测变量是如何进入回归分析的。我们可能认为可以一次性输入所有变量，分析告诉我们哪些预测变量是显著的。然而，在分析中一次性输入所有变量会增加计算时间并使模型拟合变差。可能会让你惊讶的是，决定变量如何进入模型的方法有很多。通过选择正确的变量选择方法，我们可能改进模型拟合。

基本上，回归文献展示了线性回归中三种主要的变量选择方法：`backward`（后向）、`forward`（前向）和 `stepwise`（逐步）。我将用简单的方法结合一些图来解释它们以便理解。然后我将向你展示在 `SAS Enterprise` 中使用的具体方法。

![](img/ufig7_8.jpg) 我想在这里说明的一个重要点是，这三种方法本质上都是 `stepwise methods`（逐步方法）。`Stepwise method` 是数据挖掘中使用的一种迭代变量选择方法，用于识别预测模型中最相关的变量子集。因此，使用术语 `stepwise` 指特定过程可能会混淆。因此我将它们重命名为 `forward stepwise`（前向逐步）、`backward stepwise`（后向逐步）和 `adaptive stepwise`（适应逐步）。对于下面的每种方法，我描述了变量选择的步骤并在图中演示了它们（图 7.2）。你可以想象，这些方法每种都会产生许多模型，最后一个通常是最好的。

*   **前向逐步 (Forward Stepwise)** (图 7.2)

    1.  过程从一个没有任何预测变量的模型（空模型）开始。
    2.  将最显著的变量逐个添加到模型。显著变量是指与目标变量显著关联的变量。通常，最显著的预测变量是 p 值最小或提供 `R²` 增长最大的变量。
    3.  当所有考虑的变量都添加或满足预定义的停止规则时，停止选择。

*   **后向逐步 (Backward Stepwise)** (图 7.3)

    1.  过程从一个包含所有预测变量的模型（全模型）开始。
    2.  将不显著的变量从模型中移除。
    3.  当没有变量剩余或满足预定义的停止规则时，停止选择。

*   **适应逐步 (Adaptive Stepwise)** (图 7.4)

    这种方法实际上是前向逐步，但有一个关键区别。在模型中添加额外的变量后，它可以移除当前模型中但不再显著的变量。换句话说，它是自适应的。在某些情况下，`adaptive stepwise` 也称为 `bidirectional stepwise`（双向逐步）。

    1.  过程从一个没有任何预测变量的模型（空模型）开始。
    2.  将最显著的变量逐个添加到模型。
    3.  在添加额外的变量后，模型中非显著的变量将被移除。
    4.  当所有考虑的变量都添加或满足预定义的停止规则时，停止选择。
