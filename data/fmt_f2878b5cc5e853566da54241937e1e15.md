另一种处理该方法的途径是通过 EM 算法。这会导出一组等价的递推公式 [88]，但实践经验表明，前面给出的那组更新公式收敛得更快。

关于在分组稀疏背景下以及多测量向量（MMV）情况下（即解矩阵中每个非零行的元素在时间上相关）的 SBL 框架扩展，已在文献 [100,101] 中报道。此外，在后一篇文献中，提供了理论分析，表明 SBL 代价函数具有非常理想的性质：其全局最小值与 MMV 问题的最稀疏解相吻合。

#### 13.6.1 尖峰和平板法

这是一种施加稀疏性的经典技术 [43,51]。让我们考虑熟悉的回归模型，

`y = θ^(T)ϕ(x) + η` (13.64)

引入了一组新的辅助二值*指示*变量，`s[k] ∈ {0, 1}, k = 0, 1, …, K − 1`。另设施加在 `θ` 上的先验为高斯分布，`p(θ) = N(θ|0, σ²I)`。顾名思义，指示变量控制公式 (13.64) 求和中参数的存在或缺失。例如，若 `s[k] = 1`，则相应参数 `θ[k]` 存在；若 `s[k] = 0`，则 `θ[k]` 被移除；这就是向模型施加稀疏性的方式。为此，采用了指示变量的联合伯努利先验分布（第 2 章），即

```
P(s) = ∏_{k=0}^{K-1} p^{s_k} (1-p)^{1-s_k}
```

(13.65)

其中参数 `0 ≤ p ≤ 1` 指定了先验稀疏性水平。这被证明等价于在参数上采用以下先验：

![公式](img/fx007.jpg) (13.66)

后者被称为*尖峰和平板*先验。其名称源于这样一个事实：如果 `s[k] = 0`，则在零点施加一个“尖峰”，而值 `s[k] = 1` 施加一个“平板”，因为高斯分布是一个宽阔的分布（对于足够大的 `σ²`）。相应的后验不是高斯分布，其计算可以通过调用近似推断技术来完成，例如变分推断或蒙特卡洛方法（参见，例如，[29] 及其参考文献）。

基本尖峰和平板方案的变体也存在（参见，例如，[80]）。在后一参考文献中，表明可以将基于经典 `ℓ₀` 的稀疏性约束强加于最小二乘（LS）准则（第 9 章）作为这些变体之一的极限情况获得。这条路径提供了概率方法和基于优化的稀疏性技术之间的另一种联系。另一种联系将在第 13.9 节中讨论。

## 13.7 相关向量机框架

文献 [88] 的工作中一个重要方面是引入了用于回归和分类的*相关向量机*。受第 11 章讨论的支持向量回归（SVR）启发，考虑了一个特定的回归模型，即：

```
y(x) = θ₀ + ∑_{k=1}^{N} θ_k κ(x, x_k) + η.
```

换句话说，考虑了公式 (12.1) 的一般回归模型，其中 `K = N + 1`，`N` 是观测值的数量，且

```
ϕ_k(x) = κ(x, x_k),
```

其中 `κ(⋅, ⋅)` 是核函数，定义见第 11 章，以输入观测点 `x[k]` 为中心，`k = 1, 2, …, N`。因此，参数的数量变得等于（加一）训练点的数量。

该任务可以通过 SBL 理念或通过采用变分近似原理来处理，以施加稀疏性。文献 [88] 指出，变分贝叶斯方法在计算上更为密集，在实践中得到的超参数均值与使用 SBL 方法获得的值相同。

受 SVR 中支持向量定义的启发，对公式 (13.67) 有贡献的幸存数据点被称为*相关向量*。此外，RVM 框架中使用的核函数不必是对称正定函数，因为建模不一定与再生核希尔伯特空间（RKHS）相关联。

### 13.7.1 采用逻辑回归模型进行分类
