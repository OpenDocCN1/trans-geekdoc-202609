## 10.2 线性代数与概率论基础

线性代数和概率论可以被视为机器学习概念的支柱或基石。如果没有对这些数学基础的先备知识和理解，机器学习的概念及其应用就无法成立。本章的这一节将详细介绍线性代数和概率论在机器学习中的概念和作用 [10]。

### 10.2.1 什么是线性代数？

线性代数可以被描述为数学的一个利基领域，主要关注向量、矩阵以及可以在这些数据结构上可能执行的各种相关操作。线性代数的概念可以被视为机器学习技术的基础构建模块 [10,11]。

#### 10.2.1.1 机器学习线性代数中的重要概念

虽然熟练掌握主要的线性代数概念对于理解机器学习背后的底层概念非常重要，但仍有一些线性代数概念是了解机器学习如何工作所必需。以下讨论了其中几个概念：

1. **向量和矩阵**：数学中在机器学习领域起着重要作用的两个基本概念是向量和矩阵。它们可以被视为一种称为`张量（tensors）`的更复杂实体示例。
   - `张量`可以被描述为阶（或秩），定义了表示它所需的数组的总维度。
   - 数学中的`向量`是由数字集合组成的，而`矩阵`由 2 维`向量`组成。

`向量`的概念在监督机器学习算法中起着至关重要的作用（目标变量），而从数据中提取的特征形成了`矩阵`。可以使用`矩阵`执行许多操作，如共轭、乘法、秩和变换。两个具有相同元素数量和维度的`向量`可以执行减法加法 [11]。

2. **对称矩阵**：`对称矩阵`在线性代数和机器学习中都起着至关重要的作用。线性代数`矩阵`主要用于执行函数。在大多数情况下，这些函数性质上是对称的，相应的`矩阵`也是如此。这些定义的函数及其值可用于测量特征距离以及特征协方差。

`对称矩阵`的一些已识别特征如下 [12]：
   - `矩阵`及其逆在性质上都是对称的。
   - 特征值仅由实数组成。
   - `矩阵`与其转置相乘得到`对称矩阵`。
   - `对称矩阵`具有分解属性。
   - 对于具有线性无关列的`矩阵`，`矩阵`与其转置相乘得到的`矩阵`性质上是可逆的。

3. **特征值和特征向量**：`特征向量`的概念可以解释为显示标量变化的`向量`，表示方向上的微小变化。与`特征向量`对应的`特征值`实际上与幅度相关，并被用作缩放因子。`特征值`和`特征向量`的概念都是数学和计算中的基本概念。

`向量`的概念在监督机器学习算法中起着至关重要的作用（作为目标变量），而从数据中提取的特征形成了`矩阵`。可以使用`矩阵`执行许多操作，如共轭、乘法、秩和变换。两个具有相同元素数量和维度的`向量`可以同时执行减法加法 [11]。

4. **主成分分析（PCA）**：在许多情况下，在处理基于机器学习的问题时，研究人员通常发现维度是一个挑战。`主成分分析（PCA）`是一种流行的技术，通常用于解决与高度相关且规模较大的数据集相关的问题 [14]。

通常，在高维数据集中，唯一识别单个特征对目标变量的影响是一项挑战。这可以通过以下事实证明：每个单个特征与所需的具有相关性，并以类似的方式主导目标变量 [13,15]。此外，数据可视化在高维数据集中变得具有挑战性。这些问题可以通过`PCA`方法轻松解决，该方法具有将维度从多维转换为 3D 或 2D 的能力。降维的操作是确保不会由于最大方差的变化而导致信息丢失。`PCA`的概念建立在数学的正交因子之上，通过减少数据中存在的特征数量使计算模型变得不复杂 [14]。

#### 10.2.1.2 线性代数在机器学习中的作用

线性代数的概念在各种机器学习算法中起着各种作用，讨论如下：

1. **线性代数对精通机器学习的重要性**：线性代数的概念对于从根本上理解机器学习算法非常重要。微积分等概念有助于获取应用所需的基础知识，例如`张量`和`向量`。学习这些技术有助于更好地理解和应用如单纯形法和空间`向量`等概念 [13]。

2. **机器学习中的预测/分析**：改进的线性代数概念不仅支持敏锐清晰地理解机器学习概念和算法，还为其增加了更多维度。`矩阵`和`向量`有助于增加我们对特定主题的视野和视角。可以添加的维度是无限的。它帮助我们提高可视化能力，并建立各种图表以便进行更好的分析和理解。

3. **线性代数有助于创建机器学习算法**：线性代数可以用于构建相对有效的监督学习和无监督机器学习算法。`逻辑回归`、`线性回归`、`决策树`和`支持向量机（SVM）`是可以在线性代数的支持下几乎从零开始创建的几种监督学习算法。此外，线性代数在无监督算法中也起着作用，包括`奇异值分解（SVD）`、`聚类`和`主成分分析`。线性代数有助于对机器学习项目建立深入的理解，并为自定义各种参数提供了灵活性 [15,16]。

4. **线性代数用于机器学习中更好的图形处理**：基于机器学习的项目总是由各种类型的图像、音频、视频或边缘检测以及各种待处理的图形解释构成的。机器学习算法还配备了分类器，它可以根据指定的类别训练给定数据集的一部分。分类器的另一个工作是消除来自已训练数据中的错误。在这种情况下，针对大型数据集的复杂计算可以使用线性代数的概念来执行，它使用`矩阵分解`等技术来处理和应对不同项目的巨大数据。`Q-R`和`L-U分解`是可用于`矩阵分解`的一些常用技术 [17]。

5. **线性代数提高你对统计学的理解**：为了更好地理解机器学习中组织和整合数据所需的统计学概念，线性代数的基础理解非常重要。线性代数由各种方法、运算和符号组成，支持将`多变量分析`等高级统计概念整合到任何给项目中，这有助于更好地理解一个变量的增加如何影响另一个变量 [15,16]。

### 10.2.2 概率论

概率论可以被解释为一种数学框架，主要用于量化数据，并在无法确定的场景下提供便利。概率论可以被认为是多种机器学习算法的基础 [16]。**图 10.2**显示了概率概念的数学表示。

#### 10.2.2.1 什么是概率？

概率可以被解释为介于 0 和 1 值之间的任何事件，该值对应于对事件发生可能性的假设。考虑到随机性的性质，某些估计概率的某些原理和方法更接近现实。

#### 10.2.2.2 概率的数学

考虑到概率的数学框架，需要重要的理论和公理，以充分利用该理论作为机器学习的工具。概率的概念主要是关于各种结果的可能性的。在这里，每个可行结果的集合被称为**样本空间**。例如，掷硬币的`样本空间`是 {正面，反面}，或者水的温度是冰点和沸点之间的所有可能值。在任何给定时刻，所考虑的`样本空间`中只有一个可能的结果 [17]。

这里，事件 `ω` 的概率为 `P(ω)`。

`Ω`（大 Omega）是`样本空间`。

`ω`（小写 omega）是特定结果。概率的两个基本公理可以定义如下：

- `0 ≤ P(ω) ≤ 1`
- `∑ P(ω) = 1`

根据给定的规则，任何给定事件发生的概率必须落在 0（即不可能）和 1（对应确定）之间，且所有事件之和应为 1。这一给定公理可以进一步扩展到`样本空间`必须包含所有可能的结果。因此，这是非常合理的。

```
P(x) = Σ_y P(x, y)
```

在这里，项 `P(x)` 可以定义为**边缘概率分布**。例如，确定在不同季节选择范围内穿连帽衫的概率计算方法如下：

我会穿一件连帽衫，`P(Hoodie) = P(Hoodie,Sunny) + P(Hoodie,Cloudy) + P(Hoodie,Rainy) = 3/9`。同样的计算概念也可以用于寻找所有天气条件下各种衣物品的边缘概率。

- **条件概率分布**：在给定 `y` 的情况下，`x` 的**条件概率分布**可以定义为：

```
P(x|y) = P(x, y) / P(y)
```

在这里，在观测到 `y` 后，`x` 的条件概率（即在观测结果为 `y = y` 的情况下）计算出的 `x = x` 的概率为 `P(x, y)/P(y)` [18]。

条件概率仅存在于 `P(y) > 0` 的情况。在 `y` 不可能发生的场景中，根本就没有对 `y` 的观测。

通过 `P(y)` 乘以上一个方程的两边，可以得到概率的**链式法则** `P(x|y) = P(x, y) · P(y)`。

`链式法则`可以建立任意数量随机变量的联合分布假设：`P(x, y, z) = P(x|y, z) · P(y, z) = P(x|y, z) · P(y|z) · P(z)`。

- **贝叶斯法则**：两个变量的`链式法则`可以用两种等价的方式写：
  - `P(x, y) = P(x|y) · P(y)`
  - `P(x, y) = P(y|x) · P(x)`

如果我们将两边相等并除以 `P(y)`，就得到了`贝叶斯法则`：

```
P(x|y) = (P(y|x) · P(x)) / P(y)      (10.3)
```

- **贝叶斯法则**：`贝叶斯法则`对于统计学和机器学习大部分至关重要。如前所述，它是贝叶斯统计学的驱动力。这个简单的规则允许我们在从数据中收集更多观测值时，更新对数值的认知。我将在稍后的文中进一步讨论`贝叶斯法则`（以及贝叶斯统计学）[19]。

#### 10.2.2.3 独立性与条件独立性

在上例中，我们看到 `P(x|y) ≠ P(x)`，因为观测 `y` 为我们提供了关于 `x` 的信息。情况总是如此吗？假设 `P(x, y)` 是一个联合分布，其中 `x` 代表商店冰淇淋的数量，`y` 代表月亮每天被物体击中的次数。知道其中任何一个值会给我们提供关于另一个值的信息吗？显然不会！所以在这种情况下，`P(x|y) = P(x)`！通过将此代入`链式法则`，我们发现在这种场景下得到 `P(x, y) = P(x | y) · P(y) = P(x) · P(y)`。这直接引出了我们对**独立性**的定义。如果 `P(x, y) = P(x) · P(y)`，则认为两个变量 `x` 和 `y` 是独立的。

类似的概念是**条件独立性**。如果在给定另一个变量 `z` 的情况下，`P(x, y | z) = P(x | z) · P(y | z)`，则称两个变量 `x` 和 `y` 是条件独立的。例如，`x` 是表示是否下雨的随机变量，`y` 是表示外面道路是否潮湿的随机变量。这确实表明这些事件是相互相关的。如果外面地面是湿的意味着意味着一直在下雨，如果下雨，地面就会变湿。现在变量 `z` 可以指示外面是否真的在下雨，并明确表示我的草地湿了。所以，下雨的条件确实是在下雨。

独立性和条件独立性的概念在表示机器学习术时非常有意义。

## 10.3 机器学习的基础概念

机器学习基本上是一系列允许我们从数据中学习的技巧集合。机器学习领域关注于任何给定输入的概率。机器学习的各种类型如下：

- **监督学习**：监督学习的概念侧重于将输入映射到输出。一些实际例子包括：
  - 分类
  - 回归
  - 诊断
  - 检测

高维数据的问题在于它消耗更多的内存空间，涉及高计算量，并且难以进行解释和可视化。此外，许多算法可能无法处理高维数据。因此，建议尽可能减少数据维度，将其映射到较低的维度，同时不损害数据所携带的信息。这种方法将问题归结为在低维空间上寻找一种分布，该分布支持与原始数据分布相似的特征特性 [29]。

iii. **分布式数据表示**（也称为密度估计）的特征是在观测到数据后，对未观测的底层概率密度函数进行估计的构建。`异常检测`可以被视为密度估计的主要示例之一。

- **强化学习**：强化学习领域主要涉及训练人工智能智能体使其能够轻松地完成特定任务。人工智能智能体的学习过程始于帮助它们在给定的环境中采取行动，并根据其行为接收奖励。智能体的主要目标是预期长期奖励或收益的最大化。在强化学习的多个场景中，概率概念通常被使用。让智能体进行学习的过程通常侧重于智能体的学习过程，即量化采用某一特定动作相对于其他动作的效用的不确定性。

### 10.4.2 机器学习（ML）概念

机器学习可以被定义为计算机科学的一个领域，处理从输入数据创建算法或模型。亚瑟·萨缪尔（1959）[1]（Arthur Lee Samuel 是计算机游戏和人工智能领域的美国先驱，他在 1959 年普及了“机器学习”这一术语）将机器学习领域定义为“赋予计算机在不需要显式编程的情况下学习能力的研究领域”。凯文·墨菲在其开创性著作中进一步指出，机器学习仅仅是算法的集合，能够自动检测或提取数据中各种未被发现的和隐藏的模式，并用它们来预测未来数据或其他重要信息 [31]。

通过学习算法从数据中提取知识可以解释如下：

- **从数据中提取各种隐藏模式——示例**：一组垃圾邮件中的文本模式识别。
- **将数据分类并分组到不同类别——示例**：将所有传入邮件分类为垃圾邮件或非垃圾邮件。
- **基于当前数据预测未来结果——示例**：预测传入垃圾邮件的发生。

众所周知，机器学习算法被分为四类：

- **监督学习**：这被解释为一种*预测学习*方法，主要目标是从一组标记的输入-输出对中学习。这些集合为进一步处理提供了示例，以将数据分类到组中或预测数据，其中输入被称为“*特征*”，而输出被称为“*响应变量*”。
- **无监督学习**：无监督学习类别处理的是知识*发现*过程，其目标是通过过滤处理并将其从无结构的噪声数据中分离出来，从而学习数据内部的结构化模式。
- **强化学习**：强化学习的过程与连接的环境交互的过程，以便承担各种决策任务。
