### 算法 17.1：重采样

#### 初始化

1. 输入样本 `x[i]` 及相应权重 `W^(i)`，`i = 1, 2, …, N`。
2. `c[0] = 0`，`N^(i) = 0`，`i = 1, 2, …, N`。

#### 主循环

**For** `i = 1, 2, …, N`, **Do**

1. `c[i] = c[i - 1] + W^(i)`；构建 CDF。

**End For**

#### 重采样步骤

1. 从 `\mathcal{U}(0, 1/N)` 中抽取 `u¹ ~`。
2. `i = 1`。
3. **For** `j = 1, 2, …, N`, **Do**
   1. `u^(j) = u¹ + (j - 1)/N`。
   2. **While** `u^(j) > c[i]`
      * `i = i + 1`
   3. **End While**
   4. `\overline{x}_j = x_i`；分配样本。
   5. `N^(i) = N^(i) + 1`
*   **End For**

输出包含新样本 ${\overline{\mathbf{x}}}_{j}$，其中 $j = 1, 2, \dots, N$，且所有权重均设为 $\frac{1}{N}$。样本 $\mathbf{x}[i]$ 经过重采样后将出现 $N^{(i)}$ 次。

上述两种重采样方法并非唯一选择（参见文献 [13]）。但系统重采样因其实现简便，通常是首选。系统重采样最早见于文献 [27]。

只要粒子数量趋于无穷大，重采样方案产生的估计值就会收敛到其真实值（问题 17.3）。

### 17.2.3 序贯采样

现在将我们在重要性采样中获得的经验应用于序贯到达粒子的情况。此类技术的早期示例可追溯至 20 世纪 50 年代（如文献 [20, 38]）。在时刻 $n$，我们的目标是从联合分布中抽取样本：

$$

p_{n}(\mathbf{x}_{1:n}) = \frac{\phi_{n}(\mathbf{x}_{1:n})}{Z_{n}}, \tag{17.6}

$$

这基于建议分布 $q_{n}(\mathbf{x}_{1:n})$，其中 $Z_{n}$ 是时刻 $n$ 的归一化常数。然而，我们将坚持本书在任何时递归设定中采用的目标：保持计算复杂度**固定，且独立于**时间瞬间 $n$。这一原则要求对相关量进行**时递归计算**。为此，我们选择如下形式的建议分布：

$$

q_{n}(\mathbf{x}_{1:n}) = q_{n-1}(\mathbf{x}_{1:n-1}) q_{n}(\mathbf{x}_{n}|\mathbf{x}_{1:n-1}). \tag{17.7}

$$

由公式 (17.7) 可知：

$$q_{n}(\mathbf{x}_{1:n}) = q_{1}(\mathbf{x}_{1})\prod\limits_{k = 2}^{n}q_{k}(\mathbf{x}_{k}|\mathbf{x}_{1:k - 1}).$$

![Equation](img/si61.png)(17.8)

这意味着只需选择 $q_{k}(\mathbf{x}_{k}|\mathbf{x}_{1:k - 1})$，$k = 2, 3, \dots, n$，以及初始（先验）$q_{1}(\mathbf{x}_{1})$。请注意，给定过去的情况下，$q_{k}(\cdot | \cdot)$ 中涉及的随机向量的维度在所有时间瞬间保持*固定*。从另一个角度来看，公式 (17.8) 揭示了：为了抽取一个跨越至时间 $n$ 的单个（多元）样本，即 $\mathbf{x}_{1:n}^{(i)} = \{\mathbf{x}_{1}^{(i)}, \mathbf{x}_{2}^{(i)}, \dots, \mathbf{x}_{n}^{(i)}\}$，我们是*递归地*构建它的；我们首先抽取 $\mathbf{x}_{1}^{(i)} \sim q_{1}(\mathbf{x})$，然后抽取 $\mathbf{x}_{k}^{(i)} \sim q_{k}(\mathbf{x}|\mathbf{x}_{1:k - 1}^{(i)})$，$k = 2, 3, \dots, n$。相应的未归一化权重也是递归计算的 [16]。确实，

$$

w_{n}(\mathbf{x}_{1:n}) := \frac{\phi_{n}(\mathbf{x}_{1:n})}{q_{n}(\mathbf{x}_{1:n})} = \frac{\phi_{n - 1}(\mathbf{x}_{1:n - 1})}{q_{n}(\mathbf{x}_{1:n})}\frac{\phi_{n}(\mathbf{x}_{1:n})}{\phi_{n - 1}(\mathbf{x}_{1:n - 1})} = \frac{\phi_{n - 1}(\mathbf{x}_{1:n - 1})}{q_{n - 1}(\mathbf{x}_{1:n - 1})}\frac{\phi_{n}(\mathbf{x}_{1:n})}{\phi_{n - 1}(\mathbf{x}_{1:n - 1})q_{n}(\mathbf{x}_{n}|\mathbf{x}_{1:n - 1})} = w_{n - 1}(\mathbf{x}_{1:n - 1})a_{n}(\mathbf{x}_{1:n}) = w_{1}(\mathbf{x}_{1})\prod\limits_{k = 2}^{n}a_{k}(\mathbf{x}_{1:k}),

$$

#### 公式与推导

![Equation](img/si69.png) (17.9)

其中

$$a_{k}(\mathbf{x}_{1:k}) := \frac{\phi_{k}(\mathbf{x}_{1:k})}{\phi_{k - 1}(\mathbf{x}_{1:k - 1})q_{k}(\mathbf{x}_{k}|\mathbf{x}_{1:k - 1})}, \quad k = 2,3,\ldots,n.$$

![Equation](img/si70.png) (17.10)

现在提出的问题是如何选择 $q_{n}(\mathbf{x}_{n}|\mathbf{x}_{1:n - 1}),\ n = 2,3,\ldots$ ![Equation](img/si71.png)。一种合理的策略是选择它以最小化权重 $w_{n}(\mathbf{x}_{1:n})$ ![Equation](img/si72.png) 的方差，给定样本 $\mathbf{x}_{1:n - 1}$ ![Equation](img/si73.png)。结果表明，使方差实际上为零的最优值（问题 17.4）由下式给出：
