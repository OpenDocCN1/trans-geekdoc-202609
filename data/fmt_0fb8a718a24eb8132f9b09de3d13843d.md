### 什么是相等？

- `==` 测试值是否相等

- `===` 测试值是否相等且数据类型是否相同

`==` 运算符会在相等性测试中进行自动类型转换，参见列表 7.1。

### 列表 7.1.

```php
$age_string = "18";
if ($age == 18)
{
    echo 'You can vote';
}
else
{
    echo 'You can not vote';
}
```

输出如下：

```
You can vote
```

然而，`===` 要求两个值在类型相同且相等时才为真，如列表 7.2 所示。

### 列表 7.2.

```php
$age_string = "18";
if ($age === 18)
{
    echo 'You can vote';
}
else
{
    echo 'You can not vote';
}
```

其结果为：

```
You can not vote
```

你也可以将条件逻辑直接嵌入 HTML 中，如下所示：

```php
<?php if ($age > 18) : ?>
```

请注意，在上述示例中，当使用花括号（{}）时，`else if` 也可以替换为 `elseif`。但是，当使用冒号（:）来定义 if/elseif 条件时，如果你把 `elseif` 拆分成两个词（即 `else if`），则会导致解析错误。

## 7. 真值、比较、条件与复合条件

大多数现代编程语言都有一个三元运算符，其作用本质上类似于 if/else 语句的简写形式。假设你需要一段代码，其中包含一个布尔值，用于指示某人是否已达到投票年龄。清单 7.5 展示了一种编写方式。

```
1. $able_to_vote = NULL;
2. if ($age > 18) {
   $able_to_vote = true;
}
else {
   $able_to_vote = false;
}
```

更简洁的写法是使用三元运算符，如下所示：

```
$able_to_vote = ($age > 18) ? true : false;
```

三元运算符在两个括号之间放置一个条件语句，后面跟着一个问号（?），然后是条件为真时赋的值，再后跟一个冒号（:），最后是条件为假时赋的值。你通常需要创建一个变量，并将三元运算的结果赋值给该变量。更多信息请参阅三元运算符文档。

> [2] 三元运算符：http://php.net/manual/en/language-operators.php
