## 4.4.2 单侧检验与双侧检验

我们刚刚讨论的检验是单侧或方向性检验的一个例子。由于我们感兴趣的是性能是否优于变化，因此拒绝域仅包含 `Y` 的最大可能值（二项分布的上尾）。并不是所有的假设检验都是方向性的。在许多情况下，偏离零假设的任何一个方向都会引起关注。例如，在 Roy 关于算术技能的数据研究中（见第 2 章），我们可能想知道加法或减法的表现是否存在显著差异；如果有，这可能会影响这些技能的教学方式。为了测试这种差异，我们可以为加法得分高的学生分配加号，为减法得分高的学生分配一个负号。然后我们可以询问加号（或负号）出现的概率是否显著不同于 `.5`。任何一个结果（即加法优于减法或减法优于加法）都具有意义。另一个例子是马萨诸塞大学医学院的研究人员收集了抑郁和焦虑等临床状态的季节性变化数据。比较冬季和夏季的抑郁得分，如果冬季得分较高，我们分配加号；如果较低，则分配负号。在这两个例子中，`H_0` 将为

`H_0 : π = .5`

备择假设将为

`H_1 : π ≠ .5`

在这种情况下，`H_0` 是无方向的；因此，如果我们发现证据表明 `π` 大于或小于 `.5`，我们就拒绝 `H_0`。我们可能希望 `α` 为 .05，但这样拒绝域就被平分为两半——在分布的上尾，另一半在下尾。转向标记为 `π=.50` 的列，假设给两个方向的权重相同，且 `α` 接近 .05，如果 `Y ≤ 5` 或 `Y ≥ 15`，则拒绝 `H_0`。这通常被称为双侧检验或无方向检验。请注意，如果我们使用这些拒绝域，第一类错误的实际概率为 `.021+.021=.042`。如果我们发现 `Y=16`，我们将拒绝 `H_0`，因为该统计量落在拒绝域内。使用表 4.2，我们找到 `p(Y≥16|π=.50)=.0040+.0011+.0020+0=.0059`。但由于 `H_1` 是无方向的，我们必须考虑分布下尾中同样极端的结果，因此 `p` 值等于 `p(Y≥16|π=.50) + p(Y≤4|π=.50) = 2 × 0.0059 = 0.0118`。我们刚刚概述的程序（使用二项分布检验假设 `H_0: π = .50`）被称为符号检验。

# 假设检验的基础

### 4.4.3 使用软件识别拒绝域

我们可以使用软件来识别零假设下的拒绝域或区域。这样做有几个优点，包括计算速度快，以及比表 C 参数参数范围更大。在 `R` 中，`stats` 包中的 `qbinom` 函数计算二项分布的临界值。输入参数是样本量 (`n`)、成功概率 (`π`) 以及与 `α` 相关的值。默认情况下，该函数返回分布下尾的值。我们考虑三种情况：

- 下尾临界值的方向性假设（例如，`H_0; π < .5`）。在这种情况下，`qbinom` 直接提供临界值。例如，如果 `n = 8` 且 `α = .05`，`qbinom(.05, size = 8, prob = .5)` 返回 2。这意味着当 `Y < 2` 时，我们可以拒绝 `H_0`。
- 上尾临界值的方向性假设（例如，`H_0; π > .5`）。在这里，我们使用 `lower.tail = FALSE` 来计算上尾概率：`qbinom(.05, size = 8, prob = .5, lower.tail = FALSE)` 返回 6，这意味着当 `Y > 6` 时，我们可以拒绝 `H_0`。
- 双侧备择假设（例如，`H_0; π ≠ .5`）。在这种情况下，我们将每个尾部的概率除半。然后按照与方向性检验相同的指导，分别对下尾和上尾应用 `qbinom`。例如，如果 `n = 8` 且 `α = .05`，我们使用 `α/2` 来识别下尾临界值：`qbinom(.025, size = 8, prob = .5)` 返回 1，意味着当 `Y < 1` 时拒绝。对于上尾临界值，`qbinom(.025, size = 8, prob = .5, lower.tail = FALSE)` 返回 7，意味着当 `Y > 7` 时拒绝。

## 4.5 检验的功效

### 4.5.1 决策中的错误

在决定拒绝或不拒绝假设时，我们可能会犯两种错误。如果零假设是真的，拒绝它是假阳性，我们称之为第一类错误。正如我们刚刚讨论的，这种错误的的概率是 `α`，即显著性水平。这意味着第一类错误率由研究人员控制。如果零假设是假的，我们可以通过未能拒绝它产生另一种错误；这是假阴性。当零假设为假时未能拒绝它被称为第二类错误，其概率 `p(fail H_0 | H_1)` 被称为 `β`（希腊字母 beta）。补概率，即 `p(reject H_0 | H_1)`，称为检验的功效。因此，功效 = `1 - β`。下表有助于澄清 `α`、`β` 和功效的含义：

| 总体中的决策 | 拒绝 `H_0` | 不拒绝 `H_0` |
| :--- | :--- | :--- |
| `H_0` 真 | `α` = 第一类错误率 | `1 - α` |
| `H_1` 假 | 功效 = `1 - β` | `β` = 第二类错误率 |

### 4.5.2 计算功效

功效是一个条件概率：是在零假设为假的情况下拒绝零假设的概率。计算功效的第一步是确定零假设被拒绝的条件（见框 4.2）。一旦找到 `H_0` 的拒绝域，我们必须在假设 `H_a` 且某个备择假设 `H_A` 正确的情况下，计算在拒绝域内观察到结果的概率。明确 `H_a` 和 `H_A` 之间的区别很重要；备择假设的类决定了拒绝域的位置（右、左或双尾）。相比之下，`H_a` 是一个特定的备择假设；功效是在假设 `H_A` 为真的对 `H_0` 检验的。显然，总体参数的真实值是未知的。但如果假设了参数的某个值，就可以计算备择检验的功效。

让我们说明 ESP 实验功效计算。假设我们要检验 `H_0: π = .25` 与备择假设 `H_a: π > .25`。此外，假设 Rachel 的 ESP 能力较弱；具体来说，我们假设她的能力允许她在 35% 的时间内正确识别卡片。在这个例子中，这是我们特定的备择假设：

`H_a: π = .35`

`H_0` 和 `H_A` 为我们的实验指定了不同的采样分布，如图 4.4 所示。我们的示例假设 `H_1` 正确描述了实验不同结果的概率；两个分布之间的大量重叠意味着这两个假设将无法区分。因此，我们可以预计功效会很低。

计算功效的步骤适用于所有的统计检验。这些步骤总结在框 4.3 中。应用于我们的示例：

- 1. 假设 `H_0` 为真计算 `Y` 的理论分布。在示例中，分布位于表 4.2 的 .25 列。
- 2. 确定拒绝域。在示例中（`n = 20, α = .05; H_a: π > .25`），区域是 `Y ≥ 9`。如图 4.4 所示，结果是离散的，我们选择不超过 0.05 的最大 `α`；在这种情况下，`α = .0409`。
- 3. 假设 `H_a` 为真计算 `Y` 的概率分布。在示例中，`π = .35` 用于 4.2。
- 4. 计算 .35 列中 `Y ≥ 9`（拒绝域）的概率和。这就是条件概率 `p(Y ≥ 9 | H_A = .35)`，也是 `H_0` 对 `H_A` 检验的功效。在这种情况下，功效为 .2376。
