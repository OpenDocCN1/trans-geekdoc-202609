
```q
operation ApplyControlledUnitary(controlQubits : Qubit[], targetQubit : Qubit, unitary : (Qubit => Unit)) : Unit {
  let n = Length(controlQubits);
  for i in 0..n-1 {
    let exponent = PowD(2.0, IntAsDouble(i));
    ControlledOnInt(1, unitary)(controlQubits[i], targetQubit, exponent);
  }
}
```

为了提取相位信息，我们对控制比特应用逆`QFT`。

## 逆量子傅里叶变换

```q
operation ApplyInverseQFT(controlQubits : Qubit[]) : Unit {
  let n = Length(controlQubits);
  for i in 0..n-1 {
    for j in 0..i-1 {
      let angle = -2.0 * PI() / PowD(2.0, IntAsDouble(i-j+1));
      Controlled R1(angle, [controlQubits[j]], controlQubits[i]);
    }
    H(controlQubits[i]);
  }
}
```

最后，我们测量控制比特以获得估计的相位。

```q
operation MeasureQubits(controlQubits : Qubit[]) : Result[] {
  return ForEach(MResetZ, controlQubits);
}
```

# 理解量子游走

量子游走主要有两种表现形式：离散游走（discrete walk）和连续游走（continuous walk）。

### 离散量子游走

在离散量子游走中，状态根据硬币操作（coin operator）移动。离散量子游走交替应用硬币操作和位移操作（shift operator），决定步者的移动。

相反，连续量子游走由哈密顿量（Hamiltonian）驱动。连续量子游走的状态随薛定谔方程演化。

# 量子相位估计算法

`Quantum Phase Estimation (QPE)`算法是一种强大的量子例程，用于估计酉正算子的特征值。`QPE`是若干高级量子算法的基础，包括用于分解的 Shor 算法以及各种量子模拟技术。

## 概念概述

`QPE`利用叠加和纠缠原理从量子态中提取相位信息。该算法由三个主要步骤组成：

1. **初始化**：准备一个叠加态的量子态。

2. **控酉操作**：应用控控酉操作来编码特征值相位。

3. **逆量子傅里叶变换 (QFT)**：执行逆 QFT 以提取与特征值相关的相位信息。

## 数学公式

给定一个酉算子`U`和一个具有特征值`e^{2πiθ}`的特征向量`|u⟩`，目标是估计相位`theta`。该算法涉及以下步骤：

1. **准备状态**：初始化两个寄存器——一个处于叠加态的控制寄存器和一个处于特征态`|u⟩`的目标寄存器。

\[
|\psi\rangle = \frac{1}{\sqrt{N}} \sum_{k=0}^{N-1} |k\rangle |u\rangle
\]

2. **应用控操作**：根据控制寄存器的状态，对目标寄存器应用控酉操作。这使得控制寄存器与相位信息纠缠。

\[
\sum_{k=0}^{N-1} |k\rangle U^k |u\rangle = \sum_{k=0}^{N-1} |k\rangle e^{2\pi i k \theta} |u\rangle
\]

3. **逆 QFT**：在控制寄存器上执行逆 QFT 以提取相位`theta`。

\[
|\psi_{\text{final}}\rangle = \frac{1}{\sqrt{N}} \sum_{y=0}^{N-1} e^{2\pi i y \theta} |y\rangle
\]

## 哈密顿量表示

要解决的问题由哈密顿量（Hamiltonian）表示，它描述了系统的能量。初始哈密顿量`H_i`简单且容易准备，而最终哈密顿量`H_f`则编码了问题的解决方案。系统的哈密顿量随时间`t`从`H_i`演变为`H_f`，公式如下：

\[
H(t) = (1 - \frac{t}{T}) H_i + \frac{t}{T} H_f
\]

其中`T`是总退火时间。如果演化足够慢，系统将保持在基态中，最终态对应于最优解。
