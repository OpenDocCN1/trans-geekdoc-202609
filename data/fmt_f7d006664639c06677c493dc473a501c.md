**摘要—** 本文描述了针对油气储层地球物理参数空间分布的数据驱动机器学习方法。利用多核学习来整合多尺度特征，从而有效地将储层先验知识与地震数据相结合。通过机器学习技术对地震数据中的属性进行聚类，可以提取地质特征。最后，利用预测值调整模型参数，并更新储层地质参数。利用实际油气现场数据对储层进行了重建。

**关键词—** 向量回归；多核学习；储层建模；特征提取

近年来，学习方法已成为解决噪声或异构数据等复杂建模问题的有效方案。Demyanov 等人证明了半监督向量回归方法能够将油气属性转化为储层模型。核主、支持机和多核学习等方法已应用于储层建模和储层分类 [7]-[8]。

## I. 引言

机器学习是许多应用领域的研究工具。其核心思想是获取数据之间的相关性以提高系统性能。机器学习聚焦于如何从数据中提取隐藏信息，然后产生能够发现这些隐藏信息模型或算法。机器学习算法包括支持机、决策树和贝叶斯分类器。

机器学习的目标是基于训练数据和实际目标数据获取一个模型。该模型可以估计输入与输出数据之间的关系，通常是输入与输出之间的依赖关系。根据机器学习方法，根据独立和依赖样本 $(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)$，在一组特征计算中，可以隐式地执行非线性映射。

作为一种数据驱动技术，机器学习基于这样一个原理：从数据中提取依赖关系比假设某些先验关系更好。当数据依赖关系不明确或模型无法准确描述时，它将发挥良好的作用。

Mercer定理（Mercer定理）：设 X 为 $R^n$ 上的紧集，$X\times X\to R$ 是一个连续且对称的函数，如果该函数的积分在亥尔伯特空间中满足正定条件

```
$\forall \ f(x,y) = \sum \lambda_i f_i(x)f_i(y)$
```

则存在一个特征空间 F 和一个映射 $\varphi: X \to F$，

```
$k(x,y) = \varphi(x) \cdot \varphi(y)$
```

Mercer 定理是核的必要条件。在实际应用中，用于学习模型的方法是直接定义核，这意味着定义特征空间。此时，我们可以使用 Mercer 定理来测试核是否有效。或者可以使用不同的核。

通常情况下，预先未知目标数据的具体描述，很难定义符合条件的核。这时，会根据非零性选择核函数并经常使用。常用的核函数包括多项式核函数、径向基核和拉普拉斯核，可以使用。

```
线性核: $k(x_i,x_j) = x_i^T x_j$
```

```
多项式核函数: $k(x_i,x_j) = (x_i^T x_j)^d$
```

径向基核：

```
$k(x_i,x_j) = \exp(-\frac{||x_i-x_j||^2}{2\sigma^2})$
```

拉普拉斯核：

```
$k(x_i,x_j) = \exp(-\frac{||x_i-x_j||}{\sigma})$
```

考虑到核函数的参数会影响模型的复杂性和建模结果，本文采用基本核函数和高斯核函数（其参数较少且能更好地解决非线性问题）作为支持向量的核。

## II. 向量回归与多核学习方法

### A. 支持向量回归的基本思想

Vapnik 等人引入了 ε 不敏感损失函数，并提出了一种使用支持机通过回归问题解决预测时间序列的方法。这种方法被称为支持向量回归 (SVR)。多维线性回归模型根据所有输入数据的预测值 (f) 与实验值 (y) 之间的差异计算损失。SVR 的主要特征之一是它最小化了误差界，即大于 y 和 $f(x)$ 之间的差值。

### B. 核函数的原理

如果存在向量回归模型，其中 x 和 f 代表输入数据和输出数据，其结果可以表示为核函数 $K(x, x_i)$ 的线性组合，其中 $K_i$ 是核。核函数将输入向量 x 映射到高维特征空间，使得非线性映射从线性不可分空间变为线性可分空间，并使用新的学习方法来解决原始回归问题。非线性映射如下：

```
$x \to \phi(x)$
```

核函数将输入数据映射到新的特征空间，原始数据被转换为：

```
$(\phi(x), y_1), (\phi(x), y_2), \dots, (\phi(x), y_j)$
```

由于支持向量回归的学习方法，它可以表示为高维特征空间中输入样本和预测样本的线性组合。核函数将非线性映射和内积计算结合起来。

### C. 多核学习的基础

多核学习通过多个核的组合来取代单一核。多核函数更加灵活。使用多个函数代替单核函数可以增强决策函数的解释性，并获得比单核函数或模型核组合模型更优性能 [1] [3]。

构建基本核模型的基本方法是选择一组基本函数，优化它们的凸组合，然后求解。

当使用一组核函数构造核模型时，有必要解决特征空间中原始数据的分类或回归问题以及基本核权重系数。随着多核学习的不断发展，可以选择最优核函数显著提高模型的精度。

在多核学习中，如何通过调整参数构造适用于实际应用的核方法是一个领域的热点。分析每个核的映射和应用场景，然后通过各种核函数使模型获得更好的泛化能力。

### D. 多核方法与简单核

多核方法的基本原理是寻找一组具有多尺度能力的核并进行融合。这比合成核更灵活，随着输入数据规模的增加，多核方法可以从合成核提供更完整的选择。随着多核方法的发展，多核方法逐渐获得了更多的理论依据。目前，多核方法已应用于多个领域。例如原始支持机的分类方法 [12]；多尺度支持向量回归方法可以解决样本分类的欠拟合问题。支持回归的多尺度核在斑点检测和模式识别中展现了卓越的性能。在发展中，多核方法得到了进一步的促进和应用。

由于其重要性和近似能力，高斯核常用于图像以构建图像的尺度和交互特征。在多核方法中，高斯函数被广泛使用。高斯函数的表达式为：

```
$k(x,z) = \exp(-\frac{||x-z||^2}{2\sigma^2})$
```

### E. 实验流程的建立

对于提取出的地质特征，可以使用多核学习（multiple kernel learning）作为回归方法来预测这些特征。在完成核学习训练后，井测数据可以作为模型的指标值。模型在目标上的误差可用于优化多核学习过程中的参数。

多核学习在选择输入特征方面具有较高的自由度。X 和 Y 坐标与核作为输入特征相关，所有输入特征均对应其他核特征。多核学习公式对应的模型所示：

```
$K(\tilde{x},\tilde{y}) = \mathbf{d} \cdot \mathbf{d} + e^{-\frac{(\tilde{x}-\tilde{y})^2}{2\sigma_1^2}} + \sum_{m=1}^{M} w_m e^{-\frac{(\tilde{x}-\tilde{y})^2}{2\sigma_m^2}}$
```

带有 X、Y 坐标上的参数 $a_i$（$x_1$ 和 $x_2$），所有输入特征对应其他核特征。多核学习通过 MKL 规则自动更新。它们被用于寻找井处的孔隙度测量值。

使用多尺度核方法，当输入数据非均匀分布或模型具有多尺度结构时，常数使得模型拟合更加灵活，使得多尺度核具有广泛的应用。

确定合成核学习方法后，下一个问题是优化合成核的参数。通常，合成核与支持向量方法结合，将目标投影到不同的优化问题中求解，例如 Boosting、半定规划、二次规划等方法。为了快速获得最优权重，这些算法有效地解决了多核学习过程。

本文使用了一种多尺度核学习算法 [10]，这是一种两层优化方法。第一层优化多核函数的权重，第二层求解支持向量回归问题。在权重空间中，可以使用梯度下降法。

## III. 提取地质特征与多核

### A. 地质特征提取

多核学习模型将处理和特征提取技术 [6] [11] 应用于地震数据，提取地震数据噪声的相关性并获取特征信息。

### B. 震波矢量特征

对于整体的一阶梯度 $z=f(x,y)$，梯度意味着函数在某点的导数沿该方向可以达到最大值，这可以表示为一个二维方向。通常，其在像素点处的导数可以用相邻像素之间的差值来近似。

每个像素的梯度通常定义为该像素与其像素梯度的最大值。使用一阶或二阶算子（卷积方法）获取原始图中像素的特征邻域，随后使用梯度算子对每个像素进行卷积。可以获得多个梯度算子。Sobel、Robson 和 Laplace 梯度也被用于此。

在油气勘探中，河道位置和边缘区域是重要的地质特征 [2]。地震属性的边界可以突出地震数据中变化剧烈的局部区域，并确定该区域埋藏的主要沉积体的边界。Laplace 梯度算子用于检测地震属性的边缘。

### C. 地物理参数的孔隙度预测

实验使用了多种组合特征来构建多核学习模型以预测孔隙度，包括使用不同输入方法的多核学习和单一支持向量回归核模型。模型的内部参数根据地震数据值和孔隙度值进行更新。

首先，我们使用地震数据（波阻抗）和坐标（X, Y）这两个输入特征构建多核学习模型，然后使用该模型预测孔隙度。可以看出，尽管使用地震数据和坐标分布的多核学习预测的孔隙度在井处存在一些异常点，且某些局部区域存在许多异常值，但这些无法通过地质结构和孔隙度值还原。

使用所有输入特征构建单一支持向量回归模型。除坐标以外的地质特征是从地震数据中提取的，代表了区域的静态地质解释。从上方看，多核模型与该小层的地下岩结构保持一致，存在许多具有相似孔隙度的小区域。这不符合实际储层物理参数的异质性，也违反了储层物理性质空间分布的自然规律。由于地质特征包含多尺度结构和更多异质信息，在高维空间中对模型进行的是线性回归。数据使用单一核进行映射，储层的多尺度结构将被汇总，无法准确反映数据的相关性和实际地质特征的准确性。

由于卷积处理提取地震数据的特征，数据的边缘信息可能会丢失，这对模型的整体预测产生影响。其次，多核模型中的参数没有经过优化，而是根据先验知识进行调整，这给最终模型带来了不确定性。特征的选择和聚类是人工完成的。本研究使用具有不同参数的基函数来提高能力。是否存在更好的核函数仍有待探索。

最后，我们构建了一个多核学习模型。我们从地震数据的多尺度表示（高斯平滑）中提取输入特征，然后使用具有强映射能力的高斯核从多个尺度提取特征。结果如图1所示。

在未来，机器学习在油气勘探和恢复中的应用可以使用多核学习或其他学习方法，对储层与其他变量的相关性进行深入分析和研究，形成机器学习应用于储层领域的完整理论，为油气田开发提供更精细的描述。
