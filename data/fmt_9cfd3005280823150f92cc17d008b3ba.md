- **Evidence Number:** `100`
- **Unique Description:** `Suspect’s USB drive`
- **Examiner:** `Bob Smith`
- **Notes:** `Suspect’s USB drive found in top desk drawer`

### 9. 设置镜像目标路径

使用以下信息设置镜像目标，然后选择 **Finish**：

- **Image Destination Folder:** `c:\forensicsimages`

- **Image Fragment Size (MB):** `0`（表示不拆分为多个镜像文件）

### 10. 开始创建取证镜像

### 11. 完成操作

镜像完成后关闭 FTK Imager。

### 12. 验证镜像文件

验证在 Windows 的 `c:\forensicsimages` 文件夹中可以看到镜像文件。

## Analysis Tools

一旦获取了嫌疑人驱动器的镜像，你就可以对证据执行分析，并在嫌疑人的系统上定位任何感兴趣的文件（通过处理镜像，而非嫌疑人系统上的实际驱动器）。

### Autopsy

**Autopsy** 是一款开源的数字取证分析工具，可用于分析使用 `dd` 或 FTK Imager 获取的镜像。使用 Autopsy，你也可以添加本地磁盘并直接分析本地驱动器，而无需先创建驱动器镜像（这非常适合学习 Autopsy，但在调查过程中，你应始终使用驱动器的副本进行工作）。

使用 Autopsy，你可以浏览驱动器内容，查看所有文件及任何已删除的文件（参见 Figure 21-7）。Autopsy 还具有提取相关信息的功能，例如系统上的用户账户、访问过的互联网站点和最近访问的文件，并以易于查找的方式显示这些信息。Autopsy 允许你标记感兴趣的文件，并生成包含标记工件的 Excel 或 HTML 格式报告。你还可以使用 Autopsy 执行关键字搜索。

### 实时分析工具

*实时分析* 是指调查人员决定在活动系统上执行调查，而不是获取系统的镜像。这样做有几个原因——其中之一是您可能怀疑嫌疑人正在使用驱动器加密，如果您关闭系统，驱动器就会被加密。因此，您不关闭系统，而是对系统执行实时分析。您也可能执行实时分析以检查内存内容，因为内存中也可能包含证据。

实时分析工具非常适合响应安全事件（如恶意软件感染系统），因为实时分析工具具有许多显示系统当前状态的功能。实时分析工具还可用于监控正在运行的进程；定位系统上的所有图形文件；以及查看 PST 文件、电子邮件密码、注册表和 Internet 历史记录等，仅举几例。

**CAINE** 是一款可用于事件响应和计算机取证的实时分析工具示例。

### 移动设备取证

计算机取证的一个不断增长的领域是移动设备取证——在手机、平板电脑或智能手机（如 Android 或 iPhone）等移动设备上查找证据。存储在移动设备上的信息存储在不同的区域。以下总结了可以定位移动设备数据的常见区域：

- **ROM**：只读存储器存储移动设备的操作系统。
- **EEPROM**：电可擦除可编程只读存储器包含移动设备的系统数据。这些数据存储在 **EEPROM** 中，以便服务提供商根据需要进行更新。
- **SIM 卡**：位于手机背面电池下方，用户身份模块（**SIM**）包含一个微处理器和 **EEPROM**，用于存储移动网络的路由信息和认证信息。旧手机默认将联系人和短信存储在 **SIM** 卡上，但较新的手机必须配置才能这样做。
- **内存**：根据移动设备的不同，您可能拥有额外的内存或存储卡插槽，用于存储图片、视频和数据文件等其他数据。

鉴于移动设备类型不同，执行移动设备取证的方式将取决于设备本身，但移动设备存在三个关键问题：

- **维持供电**：由于移动设备的某些数据可能存储在断电时会丢失数据的内存中，请确保能够维持设备供电。这意味着在扣押移动设备时，您应尝试为该设备找到电源适配器。
