## 6.7 总结与历史备注

- 在决策树中，属性值是逐个进行测试的，每次测试的结果指示了应该发生什么：要么是另一个属性测试，要么如果到达叶子节点则对类标签做出决策。可以说，决策树由一组部分排序的测试组成，每个测试序列定义了树中由叶子终止的一个分支。
- 从典型的训练集中可以创建许多备选的决策树。通常情况下，上较小的树，其主要优势是可解释性、消除无关和冗余属性以及降低对噪声数据的过拟合风险。
- 从数据归纳决策树的最典型程序以递归方式进行，始终试图寻找提供关于类标签最大信息的属性。这种方法倾向于使生成的决策树更小。`best`属性通过信息论的简单公式确定。
- 决策树归纳的一个重要方面是剪枝。主要动机是确保所有的树分支都有充分证据的支持。此外，剪枝减小了树的大小，具有某些优势（见上文）。存在两种通用的剪枝类型。(1) 在`post-pruning`（后剪枝）中，树被完全生成，然后进行剪枝。(2) 在`on-line pruning`（在线剪枝，这可能是一个误称）中，一旦用于确定下一个属性的训练子集变得太小，树的生成就会停止。在这两种情况下，剪枝程度都由用户设置的参数（分别表示`c`和`m`）控制。
- 决策树可以转换为规则集，并对其进一步进行剪枝。在一个具有`K`个类的领域中，只需指定`K-1`个类的规则即可，剩余的类成为`default class`。规则通常更容易解释。规则剪枝算法有时会导致更紧凑的分类器，尽管计算成本显著增加。

历史备注：决策树背后的思想由 Hoveland 和 Hund 在 20 世纪 50 年代后期提出。这项工作后来在 Hunt 等人 [39] 的书中得到了总结，该书报告了对他们的概念学习系统（`CLS`）进行多次实现的经验。Friedman 等人 [30] 独立开发了类似的方法。Breiman 等人 [11] 达到了研究的早期高潮，在书中描述了系统`CART`。随后，这一思想被 Quinlan [75, 76] 引入了机器学习领域。也许著名的实现是 Quinlan [78] 的`C4.5`。本章基于`C4.5`的简化版本。

## 7.1 PAC 学习

![image](img/chapter_title_below.png)

计算学习理论贡献的最有用思想可能是“概率近似学习”，有时缩写为`PAC learning`。让我们先解释其底层原理，并推导出一个公式，这将提供一些有用的指导。

### 假设与定义

如果我们围绕几个简化假设建立分析，分析将会变得更容易。首先，训练示例（以及所有未来的示例）是完全无噪声的。其次，所有属性都是离散的（没有属性是连续值的）。第三，分类器的形式为属性值的的逻辑表达式；该表达式对于正示例为真，对于负示例为假。最后，存在至少一个表达式可以正确分类所有训练示例。¹

每个逻辑表达式都可以被看作关于分类器应该是什么样的一个假设。所有假设共同构成了一个假设空间，其大小（不同假设的数量）为`|H|`。在上述假设下，`|H|`是一个有限数。

### 不准确的分类器在训练集上可能仍然成功

可用训练数据很少能穷尽底层类别所有的微妙之处；一个正确标记所有训练示例的分类器在未来可能仍然很糟糕。如果增加更多训练示例，这些错误发生的频率通常会降低，因为这些添加可能反映了数据未能代表的方面。多少个训练示例将给我们公平的成功机会？为了找到答案，我们首先考虑一个错误率实际上超过`E`的分类器。借此，我们确立了 m 个训练示例成功消除所有错误率超过`E`的分类器的概率上界。

![image](img/image602.png)

通过此，我们确立了 m 个训练示例成功消除所有错误率超过`E`的分类器的概率上界。

![image](img/image374.png)

为了变得有用，最后一个表达式必须经过修改。我们从数学上知道`1 - E < e^(-E)`，这意味着`(1 - E)^m < e^(-mE)`。考虑到这一点，我们能够以指数形式表示该上界：

```
P < |H|.(1 - E)^m (7.1)
```

### 消除糟糕的分类器

假设大于`E`的错误率被认为是不可接受的。性能如此糟糕的分类器从训练集中被归纳出来的（即它分类了所有训练示例）的概率有多大？

![image](img/image605.png)

假设空间由`H`组成。让我们考虑一种理论可能性：我们在 m 个示例上评估所有分类器，然后只保留那些从未犯错误的分类器。在这些“幸存者”中，有些令人失望，因为虽然它们在训练集上没有错误，但它们在整个实例空间上的错误率实际上超过了`E`。假设有`k`个这样的分类器。

![image](img/image164.png)

在没有整个实例空间评估每个分类器的情况下，无法确定`k`的具体值。由于这不可能，我们只能说`k ≤ H`，这是一个好一点，因为在许多现实情况下`H`是已知的，或者至少可以计算。²

```
P < k.(1 - E)^m < H.(1 - E)^m (7.2)
```
