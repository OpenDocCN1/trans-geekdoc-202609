*   **降低模型复杂度：** 使用低复杂度的假设函数（模型）或通过正则化来限制假设函数（模型）的复杂度。

### 3.2.2 验证集、测试集

通过可视化展示训练模型函数和真实样本数据，可以观察模型函数是欠拟合还是过拟合，从而直接直观地判断模型函数拟合得好不好。然而，这种方法仅适用于可以用曲线和曲面表示的非常简单的假设函数。许多实际问题具有复杂的假设函数和大量的数据特征。例如，一张图像可能拥有数百万个特征。深度学习中的神经网络函数拥有数千个参数。此类数据样本和假设函数无法可视化。

从前面的示例可以看出，对于此类问题，往往不可能仅根据下降的损失函数曲线来判断最终模型函数是否拟合数据。即使某个函数对训练样本的损失很小，它对不在训练集中的其他样本也可能产生较大误差；即会出现过拟合问题。换句话说，模型函数的“泛化能力”不足，无法更好地表达实际样本数据特征与目标值之间的关系。“过拟合”发生的原因是训练模型过分关注如何更好地拟合训练集，因此训练出的模型对不同于训练集的数据会产生更大的误差。当然，仅根据损失函数的值也难以判断模型函数是过拟合还是欠拟合。在某些情况下，即使损失函数的值很小，也可能是欠拟合。

训练模型的目的是利用模型预测新数据。即使模型能很好地拟合训练数据，如果对新数据的预测效果差，也是无用的。正如运动员训练是为了在队内名列前茅，但无法保证在面对其他对手时也能表现同样出色。

为了帮助判断模型函数是过拟合还是欠拟合，除了损失函数曲线外，通常借助与训练集不同的样本集来评估模型函数的质量。

因此，在机器学习中，除了用于训练模型的训练集外，通常还会使用单独的测试集来评估训练好的模型。对于模型函数，可以计算测试集中样本的预测误差（即预测值与目标值之间的误差）。如果测试集样本的误差与训练集样本的误差相似，则可以初步判断该模型函数具有较好的泛化能力。测试集应尽可能涵盖各种不同的数据，以评估训练好的模型是否具有良好的泛化能力。

除了训练集和训练模型的算法外，不同假设函数模型的性能也不同。例如，在前面的二维数据点多项式拟合问题中，不同次数的多项式函数得到的训练模型函数性能不同；有的欠拟合，有的过拟合。此外，训练算法中的超参数（如学习率、批量大小、迭代次数等）也对训练结果有很大影响。例如，在其他条件不变的情况下，迭代次数直接影响训练误差；迭代次数过少可能导致欠拟合，过多可能导致过拟合。

通过验证集评估不同模型的预测误差，有助于选择合适的假设函数和训练超参数，从而获得泛化能力更强的训练模型。

例如，在训练模型时，可以同时计算训练集和验证集的损失（误差）。当训练迭代开始时，验证误差和训练误差都会从高到低持续下降。随着迭代次数增加，验证集误差反而变大，表明泛化能力变差。此时应尽早停止迭代。这种方法称为**早停法**。即验证集可用于防止训练过程中迭代次数过多。再如，对于前面的多项式拟合，若无可视化辅助，可以利用不同次数多项式模型函数在训练集和验证集上的训练误差和验证误差，帮助选择合适次数的多项式函数。

因此，训练集用于训练模型，验证集用于评估和选择模型，有时还会使用单独的测试集来测试最终模型。有时测试集和验证集不加区分。

针对前面正弦采样点的拟合问题，以下代码总共采样了三个样本集：训练集、验证集和测试集。

```python
import numpy as np
import matplotlib.pyplot as plt
%matplotlib inline

n_pts = 10
x_train, y_train = sample(n_pts)
x_valid, y_valid = sample(n_pts)
x_test, y_test = sample(n_pts)
```

如果你想选择不同次数的假设函数，例如 `K=0, 1, 2, 3, ... 9`，可以使用这些不同次数的假设函数进行训练，并计算训练误差和验证误差。

```python
def rmse(a, b):
    return np.sqrt(np.mean(np.square(a - b)))

M = 10
errors_train = []
errors_valid = []
for K in range(M):
    X = np.array([np.power(x_train, k) for k in range(K + 1)])
    X = X.transpose()

    # w, history = gradient_descent_vec(X, y, lr, iterations)
    XT = X.transpose()
    XTy = XT @ y_train
    w = np.linalg.inv(XT @ X) @ XTy
    # w = np.linalg.pinv(X) @ y
    # print("w=:", w)

    predict_train = X @ w
    error_train = rmse(y_train, predict_train)

    X_valid = np.array([np.power(x_valid, k) for k in range(K + 1)])
    X_valid = X_valid.transpose()
    predict_valid = X_valid @ w
    error_valid = rmse(y_valid, predict_valid)

    errors_train.append(error_train)
    errors_valid.append(error_valid)

plt.plot(errors_train, 'o-', mfc="none", mec="b", ms=10, c="b", label="Training")
plt.plot(errors_valid, 'o-', mfc="none", mec="r", ms=10, c="r", label="Valid")
plt.legend()
plt.xlabel("degree")
plt.ylabel("RMSE")
plt.ylim(0, 1.5)
plt.show()
```

训练集、验证集和测试集的适当大小（样本数量）应该是多少？这取决于实际问题。对于某些问题，获取样本的成本较低，样本模型可达数十万甚至数百万。例如，购物网站很容易收集大量用户购物行为数据，训练集样本数据占所有样本数据的比例可以高达 90% 以上，而验证集和测试集占所有样本数据的比例可以低至 5% 左右，因为总样本数非常大，5% 的样本数量已经很大了。对于某些问题，获取样本的成本昂贵，总样本数量相对较少。例如，在医学影像领域，验证集和测试集占总样本数的比例会相对较高，例如高达 20%，自然训练集的比例就会降低。对于一般规模的样本，通常可以将训练集、验证集和测试集的样本数量占所有样本数量的比例设置为 60%、20%、20%。这种比例划分不是绝对的，应根据实际问题确定。

### 3.2.3 学习曲线

狭义上，学习曲线通常指不同数量训练样本的训练误差和验证误差（或得分）。即计算不同数量训练样本的训练误差（或得分）以及验证样本的训练误差（或得分），然后绘制训练误差（或得分）曲线和验证误差（或得分）曲线。通过对比训练曲线和验证曲线，有助于观察训练的过拟合和欠拟合情况。

广义上，任何有助于判断训练情况的曲线都可以称为学习曲线，例如训练损失曲线和准确率曲线。仅训练样本的曲线可用于观察训练是否收敛，但无法判断是欠拟合还是过拟合。只有验证样本的曲线才有助于判断是否过拟合或欠拟合。通常所说的学习曲线是指一条训练曲线和一条验证曲线。

针对前面的问题，可以为特定的假设函数（例如 9 次多项式函数）绘制训练损失曲线和验证损失曲线，观察训练集和验证集的损失（误差）如何随迭代次数变化。

下面的 `loss()` 函数计算模型参数对应的假设函数在样本集（`X`、`y`）上的损失，`learning_curves_trainSize()` 计算不同大小（`trainSize`）训练集的训练损失和验证损失，并绘制训练损失曲线和验证损失曲线。
