## 14.1 引言

在第 12 章和 13 章中，我们探讨了贝叶斯推断任务。第 13 章的大部分内容专门用于处理近似技术，当涉及的概率密度函数（PDF）足够复杂，以至于积分计算变得难以处理时，这些技术提供了解决途径。所有这些技术本质上都是确定性的；也就是说，目标是用另一个能够简化相关计算的数学表达式来近似相应 PDF 的数学表达式。此类方法包括拉普拉斯近似，以及基于均场理论或凸对偶概念的变分方法。确定性近似方法也将在第 15 章中用于近似推断，以处理图模型。

在本章中，我们将关注具有更浓厚统计色彩的近似方法，这些方法基于使用数值技术随机生成样本；这些样本代表了底层分布，该分布可以是连续的，也可以是离散的。这是一个历史悠久的领域，其起源可追溯到 20 世纪 40 年代末和 50 年代初，当时斯坦尼斯拉夫·乌拉姆、约翰·冯·诺依曼和尼古拉斯·梅特罗波利斯在洛斯阿拉莫斯的开创性工作为此奠定了基础，术语 `Monte Carlo`（蒙特卡洛）被创造出来作为此类技术的统称，灵感源自摩纳哥著名的赌场（例如，参见文献 [28] 了解历史背景）。此类技术的首次应用与第一台计算机的发展同步，用于曼哈顿计划中氢弹的研发；此后不久，蒙特卡洛方法几乎被所有涉及统计计算的科学领域所采用。

正如开创性思想常有的情况一样，当我们事后回顾时，即一旦它们被陈述出来，基本思想似乎很简单。我们当前感兴趣的任务是计算一个涉及 PDF 的积分；这也可以解释为计算一个“期望”。这种观点允许我们利用大数定律，在给定足够数量样本的情况下，用涉及量的样本均值来近似该积分。

要在一章中浓缩一个拥有数十年历史的领域显然是不可能的。我们的目标是介绍基本概念、定义和方向，旨在满足典型机器学习任务的相关需求，而不是将其作为一个独立的实体来审视。

我们从使用变换的更经典方法开始，然后转向拒绝采样和重要性采样技术。随后，我们将回顾基于马尔可夫链理论论据的更强大方法。将介绍并讨论 Metropolis-Hastings（梅特罗波利斯-黑斯廷斯）和 Gibbs（吉布斯）采样方法。最后，将探讨一个关于变点检测任务的案例研究。

## 14.2 蒙特卡洛方法：主要概念

我们的出发点是计算以下形式的积分

𝔼[*f*(**x**)] :  = ∫[ − ∞]^∞*f*(**x**)*p*(**x**) *d***x** (14.1)

其中 **x** ∈ ℝ^(*l*) 是一个随机向量，*p*(**x**) 是对应的分布。^(¹⁰⁶)

回到公式 (14.1)，假设我们手头有一组从 *p*(**x**) 中抽取的独立同分布（i.i.d.）样本，**x**[1], …, **x**[*N*]。则近似计算为

```
𝔼[f(x)] ≈ (1/N) ∑_{i=1}^N f(x_i) = Ē_{f,N}
```

(14.2)

其合理性由 (a) *大数定律* 和 (b) *中心极限定理* [32] 保证。我们用 `𝔼[f(x)] = μ[f]` 表示期望，相应的方差记为 `var[f(x)] := 𝔼 [(f(x) − 𝔼[f(x)])²] = σ[f]²`。那么，上述两个定理保证了对于较大的 `N` 值，

```
\lim\limits_{N\rightarrow\infty}{\overline{\mathbb{E}}}_{f,N} = \mu_{f},
```

(14.3)

以及

```
p\left( {\overline{\mathbb{E}}}_{f,N} \right) \approx \mathcal{N}\left( {\overline{\mathbb{E}}}_{f,N} \middle| \mu_{f}, \frac{\sigma_{f}^{2}}{N} \right).
```

(14.4)

公式 (14.3) 中的极限指的是*几乎必然收敛*的概念，即

```
{Prob} \left\{ \lim\limits_{N\rightarrow\infty} \middle| {\overline{\mathbb{E}}}_{f,N} - \mu_{f} \middle| = 0 \right\} = 1.
```

公式 (14.4) 中的近似高斯分布保证了：随着 `N` 的增加，所得估计值 `{\overline{\mathbb{E}}}_{f,N}` 在真实值 `μ[f]` 周围的方差（随着 `N` 个样本集合的改变而变化）会减小。

因此，如果从分布 `p(x)` 生成样本 `x[n]`，`n = 1, 2, …, N`，则使用蒙特卡洛技术提供了一种近似公式 (14.1) 中积分的方法，并具有以下良好特性：(a) 近似误差按 `1/sqrt(N)` 递减；(b) 使用 `N` 个样本获得的估计值是真值的无偏估计；(c) 收敛速率*独立于*维数 `l`。后一特性与基于确定性数值积分的方法形成对比，后者通常具有随着维数增加而减慢的收敛性。在蒙特卡洛技术中，如果对获得的精度不满意，只需生成更多样本即可。

现在的关键点变成了开发从 `p(x)` 生成独立同分布（i.i.d.）样本的技术。这并非易事，尤其是对于高维空间。请注意，一旦有了从 `p(x)` 抽取的 i.i.d. 样本，公式 (14.2) 中估计器达到一定精度就与维数无关。另一方面，随着维数增加，抽取典型的 `p(x)` 的 i.i.d. 样本变得更难。我们稍后将回到这一点。在后续内容中，我们将重点介绍实现上述目标的一些基本方向。

### 14.2.1 随机数生成

随机数生成既可以作为实验的结果实现，也可以通过计算机实现。例如，抛掷一枚均匀硬币可以生成 0（正面）或 1（反面）的随机序列。另一个例子是对应于放射性发射间距的数字序列；这种实验生成服从指数分布的样本序列。然而，这些方法实用价值不大，重点一直放在通过计算机使用*伪随机数生成器*生成样本的技术上。此类方法的核心在于保证生成一个*整数*序列 `z[i]` 的算法，这些整数近似服从实轴上某一区间内的*均匀分布*。在后续内容中，服从任意分布的随机数/向量的生成是通过各种方法*间接*获得的，每种方法都有其优缺点。在区间 `(0, M)` 内生成整数的路径遵循一般递归公式：

```
z[i] = g(z[i−1], …, z[i−m]) mod M
```

其中 `g` 是一个依赖于先前生成的 `m` 个样本的函数，`mod` 表示取模运算；即 `z[i]` 是 `g(z[i−1], …, z[i−m])` 除以 `M` 的余数。较简单的形式是线性版本：

```
z[i] = α z[i−1] mod M,  z[0] = 1,  i ≥ 1
```

(14.5)

其中 `M` 是一个大素数，`α` 是一个整数。递归 (14.5) 生成 1 到 `M−1` 之间的数字序列。该方法称为*线性同余生成器*或 Lehmer 算法 [20]。

如果 `α` 选择得当，则生成的数字序列将呈现周期性，周期为 `M − 1`。这就是我们称这些生成器为伪随机的原因，因为周期性序列永远不能声称是随机的。然而，对于较大的 `M` 值，只要 `N ≤ M − 1`，获得的序列就可以具有均匀分布的足够随机性。例如，`M` 取 10⁹ 阶的值足以满足大多数应用。请注意，并非所有可能的参数 `α` 选择都能保证生成一个好的生成器。实际上，只有当序列通过许多相关的随机性测试，并随后在各种应用中成功使用时，才被接受为随机序列（参见，例如 [32]）。一个能产生相当好的均匀分布随机序列的常用参数选择是 `α = 7⁵` 和 `M = 2³¹ − 1`（参见，例如 [34]）。更多关于此主题的内容可参见 Knuth 的经典著作及其参考文献 [18]。一旦获得整数序列，均匀分布的实随机数序列即可通过比值 `x_i = z_i / M ∈ (0,1)` 获得（事实上，随机性测试正是应用于此序列）。

#### 备注 14.1

*   请注意，即使是在 `(0, 1)` 上生成均匀分布的（伪）随机数序列也并非易事，尽管均匀分布是一种“简单”的分布；即所有值出现的概率相等。此外，在实践中，概率密度函数（PDF）通常仅在其归一化常数范围内已知，即

```
p(x) = ϕ(x) / Z,
```

其中

```
Z = ∫[−∞]^(+∞) ϕ(x) dx.
```

*   然而，如果 `ϕ(x)` 形式复杂，上述积分可能难以处理。计算后验 PDF 时常会遇到这种情况。上述观点表明，从一般 `p(x)` 采样的过程比均匀分布情况要困难得多。即使 `Z` 可用，在高维空间中任务变得更难。为了充分覆盖高维空间中的一个区域所需的点数，呈指数级依赖于相应的维度（维度灾难，见第 3.12 节）。因此，需要大量的点才能在高维空间中获得 `p(x)` 的良好表示。在实践中，人们更倾向于从 `p(x)` 取相对较高值的区域生成样本。然而，维度越高，定位高概率区域的任务就越困难。类似的论点也适用于离散性质的随机变量，其中变量可取的状态数非常大。理想情况下，为了获得有代表性的样本序列，必须访问所有状态。

## 14.3 基于函数变换的随机采样

在本节中，我们将探讨一些从概率密度函数（PDF）`p(x)` 抽取样本的最基本技术。

### 函数反演

设 `x` 为具有概率密度函数（PDF）`p(x)` 的实随机变量，其对应的累积分布函数为

```
F_x(x) = ∫[−∞]^(x) p(τ) dτ.
```

从概率论可知，定义为

$$u := F_x(x)$$

的随机变量 $u$ 在区间 $0 \le u \le 1$ 内呈**均匀分布**，这与 $p(x)$ 的性质无关（参见 [32] 和问题 14.1）。如果进一步假设函数 $F_x$ 存在逆函数 $F_x^{-1}$，则可以写为

$$x = F_x^{-1}(u).$$

因此，遵循相反的推理，可以通过先生成均匀分布 $\mathcal{U}(0, 1)$ 的样本，然后对其应用逆函数 $F_x^{-1}$ 来生成 $p(x)$ 的样本（问题 14.2）。

只要 $F_x$ 存在易于计算的逆函数，此方法效果良好。然而，只有少数概率密度函数（PDF）能“自豪地”拥有解析形式的逆函数。

#### 示例 14.1

使用从均匀分布 $\mathcal{U}(0, 1)$ 生成样本 `u[n]` 的伪随机发生器，生成遵循指数分布的样本 `x[n]`：

$$p(x) = \lambda \exp(-\lambda x), \quad x \ge 0,\ \lambda > 0.$$

我们有

$$F_x(x) = \int_0^x \lambda \exp(-\lambda \tau)\, d\tau = 1 - \exp(-\lambda x).$$

令

$$u := F_x(x)$$

并解出 $x$，得到

$$x = -\frac{1}{\lambda}\ln(1 - u) := F_x^{-1}(u).$$

因此，如果`u[n]`是从均匀分布中抽取的样本，则序列

```
x_n = - (1/λ) * ln(1 - u_n),  n = 1,2,...,N,
```

是从公式(14.8)的指数概率密度函数（PDF）中抽取的样本。图 14.1 显示了生成样本的直方图，其中`N = 1000`，以及`λ = 1`时的`p(x)`曲线。

#### 示例 14.2

**从离散分布生成样本**。此处介绍了一种从离散分布生成样本的直观方法。我们将在第 17.2 节中使用此类分布。

设`x_1, x_2, ..., x_K`表示发生概率分别为`P_1, P_2, ..., P_K`的离散随机事件，且满足`∑_{k=1}^K P_k = 1`。则以下简单算法可从此分布中抽取样本。

#### 算法 14.1

**离散分布采样**

*   定义`a_k = ∑_{i=1}^{k-1} P_i`，`b_k = ∑_{i=1}^k P_i`，`k = 1,2,...,K`，`a_1 = 0`。
*   **For** `i = 1,2,...` **Do**
    1.  `u ~ U(0,1)`
    2.  选择
        *   `x_k` 如果 `u ∈ [a_k, b_k)`，`k = 1,2,...,K`

### 函数变换

我们将通过一个涉及两个随机变量（设为 `r` 和 `ϕ`）变换为两个新变量（`x` 和 `y`）的例子来演示该方法。设

```
x = g_x(r, ϕ)
```

和

```
y = g_y(r, ϕ).
```

现在假设逆变换存在唯一解，且可用解析形式表示（一般情况下并非如此），即

```
r = g_r(x, y), ϕ = g_ϕ(x, y).
```

根据第 2.2.5 节 可知，若 `p_r,ϕ(r, ϕ)` 是 `r` 和 `ϕ` 的联合分布，则 `x` 和 `y` 的联合分布由下式给出

```
p_x,y(x,y) = p_r,ϕ(g_r(x,y), g_ϕ(x,y)) / |det(J(x,y;r,ϕ))|
```

(14.9)

其中 `|det(J(x,y;r,ϕ))|` 是雅可比矩阵行列式的绝对值，

#### Box–Muller 方法

```
J(x,y;r,ϕ) = [ ∂g_x/∂r  ∂g_x/∂ϕ ]
             [ ∂g_y/∂r  ∂g_y/∂ϕ ]
```

为简化起见，我们假设每个 `(r,ϕ)` 值对应一个 `(x,y)` 值。现在让我们看看如何通过分别从均匀分布和指数分布中为 `ϕ` 和 `r` 抽取样本，来生成高斯分布 `p(x) = N(x|0, 1)` 的样本；回顾 示例 14.1，我们描述了一种从指数分布生成样本的技术。

令 `r` 服从指数分布，

$$p_{r}(r) = \frac{1}{2}\exp\left( - \frac{r}{2} \right),\quad r \geqslant 0,$$

令 `ϕ` 服从均匀分布 $\mathcal{U}(0, 1)$，

$$p_{\phi}(\phi) = \left\{ \begin{matrix} {\frac{1}{2\pi},\ } & {\quad 0 \leqslant \phi \leqslant 2\pi,} \\ {0,\ } & {\quad\text{否则},} \\ \end{matrix} \right.$$

并假设它们相互独立，即

$$p_{r,\phi}(r,\phi) = p_{r}(r)p_{\phi}(\phi).$$

按如下方式生成两个新的随机变量：

$$x = \sqrt{r}\cos\phi,$$

$$y = \sqrt{r}\sin\phi.$$

上述变换的物理解释是 `x`、`y` 对应于某点的笛卡尔坐标，而 `r`、`ϕ` 是其极坐标（图 14.3）。由公式 (14.14) 和 (14.15)，我们可以写出

```
r = x² + y²
```

```
ϕ = arctan(y / x)
```

将公式 (14.9) 调整以适应当前需求，并使用公式 (14.11)–(14.13)，我们得到

```
p_{x,y}(x,y) = (1 / 2π)(1 / 2) exp(-(x² + y²) / 2) * 2
             = (1 / √(2π)) exp(-x² / 2) * (1 / √(2π)) exp(-y² / 2)
```

其中我们用到了（问题 14.3）

```
|J(x,y;r,ϕ)| = 1/2
```

因此，我们已经证明了使用公式 (14.14) 和 (14.15) 中给出的变换，可以生成标准高斯分布的样本。
