## kNN 的优点：

- 简单且易于用于分类应用，因为它基于 k 值和欧几里得距离函数工作。
- kNN 算法不需要任何训练阶段，因为它基于实例的学习器，且比需要训练的算法（如 LDA 和 Naive Bayes）更快。
- 输出的准确率不受向数据集添加新数据的影响，因此可以无缝地添加数据。

## kNN 的缺点：

- kNN 在大型数据集上表现不好，因为计算新测试实例与训练集中每个其他实例之间的距离计算开销很大。
- 同样，对于高维（许多特征属性）数据集，算法在计算每个维度的距离时会变得更加复杂。
- 它对噪声数据敏感，在使用 kNN 之前应采取数据预处理措施消除任何缺失值或离群值。

## 2.3.8 机器学习方法的评估

评估所开发模型的效率是机器学习的重要组成部分。有多种指标可以评估模型的效率，其中混淆矩阵、准确率（accuracy）、精确率（precision）、召回率（recall）和 F 分常用于分类应用。

### 2.3.8.1 混淆矩阵

混淆矩阵以矩阵的形式传了模型的正确性。它主要用于确定具有两个或多个类别的机器学习模型的分类有效性。矩阵的行包含实际值，列包含预测值（图 2.7）。

以下是与混淆矩阵相关的四个基本术语：

- *真阳性 (TP)*——实际数据属于类别 1 且模型正确将其分类为类别 1 的情况。
- *假阴性 (FN)*——实际数据属于类别 1 但模型错误地将其分类为类别 2 的情况。
- *假阳性 (FP)*——实际数据属于类别 2 但模型错误地将其分类为类别 1 的情况。
- *真阴性 (TN)*——实际数据属于类别 2 且模型正确将其分类为类别 2 的情况。

以下性能参数，即准确率、精确率、召回率、F 分数、宏平均（基于类别数量）和加权平均（根据每个类的样本数量对每个类加权），是根据混淆矩阵中的 TP、FN、FP 和 TN 值计算的（图 2.7）。

### 2.3.8.2 准确率

分类问题中的准确率是模型预测正确的总数（TP 和 TN）与输入数据总数之比。如果类别接近平衡，它是评估模型的良好标准。

```math
Accuracy = \left( \frac{TP + TN}{TP + FP + FN + TN} \right) \times 100% \quad (2.19)
```

## 常见机器学习方法解析

### 2.3.8.3 精确率

精确率是一个量化在所有分类为正的案例中正确分类为正的案例数的指标。它是 TP 与 TP 和 FP 之和的比率。精确率的结果位于 0.0 到 1.0 之间，0.0 表示没有精确率，1.0 表示完全或完美的精确率。

```math
Precision = \frac{TP}{TP + FP} (2.20)
```

### 2.3.8.4 召回率

召回率是在感兴趣的类别中正确分类为正的案例比例。它是 TP 与类别总实例（TP 和 FN）的比率。它是一个 0.0 到 1.0 之间的值。

```math
Recall = \frac{TP}{TP + FN} (2.21)
```

### 2.3.8.5 F 分数

F 分数是精确率和召回率之间的平衡，通过它们的调和平均值确定。当数据分布不均匀时，这种方法比准确率更可靠。如果类别分布均匀（平衡数据集），F 分数与准确率相同。

```math
F-score = 2 \times \frac{Precision \times Recall}{Precision + Recall} (2.22)
```
