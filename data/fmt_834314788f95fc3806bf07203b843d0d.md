
# 遍历性与功率谱密度

## 样本均值与遍历性

对于足够大的 `N` 值，我们期望样本均值接近真实均值 `𝔼[x]`。用更正式的说法，这由 `μ̂[N]` 是一个**无偏**且**一致**的估计量这一事实所保证。我们将在第 3 章讨论此类问题；不过，我们可以在此回顾一下。每次重复 `N` 次随机实验时，都会产生不同的样本，因此会计算出不同的估计值 `μ̂[N]`。因此，这些估计值定义了一个新的随机变量 `μ̂[N]`，称为估计量。它是无偏的，因为很容易证明

`𝔼[μ̂[N]] = 𝔼[x]`

并且它是一致的，因为当 `N → +∞` 时其方差趋于零（习题 2.8）。这两个性质保证了，以高概率，对于较大的 `N` 值，`μ̂[N]` 将接近真实均值。

要将样本均值近似的概念应用于随机过程，必须拥有 `N` 个实现，并使用*不同*的实现（代表序列集合）在不同时刻“跨过程”计算样本均值。同样，样本均值论证可用于近似自协方差/自相关序列。然而，这是一项昂贵的操作，因为现在每个实验都会产生无限数量的值（一个值序列）。此外，在实际应用中，通常只有一个实现可供用户使用。

为此，我们现在将定义一类特殊的随机过程，其中样本均值运算可以显著简化。

### 定义 2.3：遍历性

如果一个随机过程的完整统计特性可以由其任一实现确定，则称该过程为*遍历*。

换句话说，如果一个过程是遍历的，那么每一个单独的实现都携带相同的统计信息，并能描述整个随机过程。由于从单个序列只能获得一组概率密度函数（PDF），我们得出结论：*每个遍历过程必定是平稳的*。非平稳过程根据原点的选择不同，拥有无限组 PDF。例如，从单个实现只能得到一个均值，并作为序列值的（时间）平均值获得。因此，遍历随机过程的均值必须对所有时刻恒定，或与时间原点无关。对于所有高阶统计特性也是如此。

一种特殊的遍历类型是*二阶*遍历性。这意味着只能从单个实现获得高达二阶的统计特性。二阶遍历过程必定是宽平稳过程（WSS）。对于二阶遍历过程，以下成立：

`𝔼[u_n] = μ = lim_{N→∞} μ̂_N`

其中

```
\widehat{\mu}_N := \frac{1}{2N + 1}\sum_{n = -N}^{N}u_n.
```

此外，

```
\text{cov}(k) = \lim_{N\rightarrow\infty}\frac{1}{2N + 1}\sum_{n = -N}^{N}(u_n - \mu)(u_{n - k} - \mu),
```

其中两个极限均指均方意义下的极限。换句话说，很容易看出估计量 $\widehat{\mu}[N]$ 是无偏的，因此遍历性要求其方差在极限情况下趋于零，即

```
\lim_{N\rightarrow\infty}\mathbb{E} \left[ |\widehat{\mu}_N - \mu|^{2} \right] = 0,
```

自协方差也有类似情况。请注意，通常遍历性仅要求假设用于均值和协方差的计算，而非所有可能的二阶统计量。在这种情况下，我们称之为*均值遍历*和*协方差遍历*过程。

> **总之，当涉及遍历过程时，整体平均“跨过程”可以作为时间平均“沿过程”获得**；参见图 2.12。

![图 2.12 对于遍历过程，所有时间瞬间的共同均值（整体平均“跨”过程），计算为时间平均“沿”过程。](img/gr012.jpg)

在实践中，当仅有来自单次实现的有限数量样本可用时，均值和协方差近似为相应的样本均值。

一个问题是确立过程成为均值遍历或协方差遍历的条件。此类条件确实存在，感兴趣的读者可在更专业的书籍中找到相关信息，例如 [6]。结果表明，均值遍历性的条件依赖于二阶统计量，而协方差遍历性的条件依赖于四阶统计量。

在统计学以及机器学习和信号处理中，在*预处理阶段*从数据中减去均值是非常常见的。在这种情况下，我们称数据为*零均值化*（或*中心化*）。由此产生的新过程现在具有*零均值*值，且协方差和自相关序列重合。从现在起，我们将假设均值已知（或计算为样本均值）然后被减去。这种处理简化了分析而不损害一般性。

### 示例 2.2：非遍历的 WSS 过程

本示例的目标是构建一个平稳但非遍历的过程。设一个平稳过程 $u[n]$，

$$
\mathbb{E}[u[n]] = \mu,
$$

且

$$
\mathbb{E}[u[n]u[n - k]] = r_u(k).
$$

定义过程

$v[n] = a u[n]$

其中 $a$ 是取值于 $\{0, 1\}$ 的随机变量，概率为 $P(0) = P(1) = 0.5$。此外，$a$ 和 $u[n]$ 统计独立。则有

$$
\mathbb{E}[v[n]] = \mathbb{E}[a u[n]] = \mathbb{E}[a]\mathbb{E}[u[n]] = 0.5\mu
$$

以及

$$
\mathbb{E}[v[n]v[n-k]] = \mathbb{E}[a^2]\mathbb{E}[u[n]u[n-k]] = 0.5 r_u(k).
$$

因此，$v[n]$ 是 WSS。然而，它不是遍历的。确实，某些实现将等于零（当 $a=0$ 时），由此产生的作为时间平均的均值和自相关将为零，这与集合平均不同。

## 2.4.3 功率谱密度

傅里叶变换是以紧凑方式在频域表示函数/序列关于其自由变量（如时间）变化的不可或缺工具。随机过程本质上与时间相关。现在的问题是随机过程是否可以用傅里叶变换来描述。答案是肯定的，对于至少是 WSS 的过程，实现这一目标的途径是通过自相关序列。在给出必要定义之前，总结自相关序列的一些常见性质是有用的。

### 自相关序列的性质

设 $u[n]$ 为 WSS 过程。其自相关序列具有以下性质（针对更一般的复值情况给出）：

#### 性质 I

$$r(k) = r^*(-k), \quad \forall k \in \mathbb{Z}.$$

该性质是原点选择不变性的直接结果。确实，

$$r(k) = \mathbb{E}[u[n]u[n-k]^*] = \mathbb{E}[u[n+k]u[n]^*] = r^*(-k)$$

#### 性质 II

$$r(0) = \mathbb{E}[|u[n]|^2]$$

即，自相关在 $k=0$ 处的值等于相应随机变量模的均方。将变量模的平方解释为其能量，$r(0)$ 可解释为相应的（平均）功率。

#### 性质 III

$$r(0) \ge |r(k)|, \quad \forall k \ne 0$$

证明见习题 2.9。换句话说，对应于两个不同时刻的变量之间的相关性（按模值）不能大于 $r(0)$。正如我们将在第 4 章中看到的，将期望解释为内积，这一性质本质上是内积的 Cauchy–Schwarz 不等式（另见第 8 章附录）。

#### 性质 IV

随机过程的自相关序列是*正定*的。即，

![Equation](img/fx021.jpg) (2.116)

**证明**

根据自相关的定义，证明很容易得到，

$$
0 \le \mathbb{E}\left[ \middle| \sum_{n=1}^{N}a_n u_n|^2 \right] = \sum_{n=1}^{N}\sum_{m=1}^{N}a_n a_m^* \mathbb{E}\left[ u_n u_m^* \right]
$$

这证明了该断言。严格来说，我们应该称其为半正定。然而，“正定”这个名称在文献中沿用至今。当在第 13 章介绍*高斯过程*时，这一性质将很有用。 □

#### 性质 V

设 $u[n]$ 和 $v[n]$ 为两个 WSS 过程。定义新过程

$z[n] = u[n] + v[n]$

然后，

$r_z(k) = r_u(k) + r_v(k) + r_{uv}(k) + r_{vu}(k)$

其中两个联合 WSS 随机过程之间的**互相关**定义为

![Equation](img/fx022.jpg) (2.119)

证明直接源于定义。注意，如果这两个过程是**不相关**的，即当 $r_{uv}(k) = r_{vu}(k) = 0$ 时

那么

$r_z(k) = r_u(k) + r_v(k)$

显然，如果过程 $u[n]$ 和 $v[n]$ 相互独立且均值为零，这也成立，因为此时 $\mathbb{E}[u[n]v^*(n-k)] = \mathbb{E}[u[n]]\mathbb{E}[v^*(n-k)] = 0$

#### 性质 VI

$r_{uv}(k) = r_{vu}^*(-k)$

证明类似于性质 I。

### 定义 2.4：功率谱密度

给定一个 WSS 随机过程 `u[n]`，其*功率谱密度*（PSD）（或简称为*功率谱*）定义为其自相关序列的傅里叶变换，

```
S_u(ω) = Σ_{k=-∞}^{∞} r_u(k) e^{-jωk}
```

利用傅里叶变换的性质，我们可以通过*逆傅里叶变换*以下述方式恢复自相关序列：

```
r_u(k) = (1/2π) ∫_{-π}^{π} S_u(ω) e^{jωk} dω
```

由于自相关序列的性质，从实际角度来看，PSD 具有一些有趣且有用的性质。

#### PSD 的性质

*   WSS 随机过程的 PSD 是 `ω` 的*实*且*非负*函数。事实上，我们有

$$
S(\omega) = \sum_{k = -\infty}^{+\infty} r(k) \exp(-j\omega k) = r(0) + \sum_{k = -\infty}^{-1} r(k) \exp(-j\omega k) + \sum_{k = 1}^{\infty} r(k) \exp(-j\omega k) = r(0) + \sum_{k = 1}^{+\infty} r^{\ast}(k) \exp(j\omega k) + \sum_{k = 1}^{\infty} r(k) \exp(-j\omega k) = r(0) + 2 \sum_{k = 1}^{+\infty} \text{Real}\left\{ r(k) \exp(-j\omega k) \right\},
$$

这证明了 PSD 是实数的断言。⁴

*   `S(ω)` 图下的面积与随机过程的功率成正比，表达式为

$$
\mathbb{E}\left[ |u_n|^2 \right] = r(0) = \frac{1}{2\pi} \int_{-\pi}^{+\pi} S(\omega) d\omega,
$$

由将 `k = 0` 代入公式 (2.123) 得到。我们马上就会讲到这一性质的物理意义。

### 功率谱密度的物理解释

我们现在准备好论证为何自相关序列的傅里叶变换被赋予了“功率谱密度”这一特定名称。我们将讨论限制在实随机过程上，尽管类似的论证对更一般的复数情况也同样成立。图 2.14 显示了一个非常特殊的线性系统的冲激响应的傅里叶变换的幅值。对于频率范围 $|\omega - \omega_{o}| \leq \frac{\Delta\omega}{2}$ 内的任意频率，傅里叶变换为单位值，否则为零。这样的系统被称为*带通滤波器*。我们假设 $\Delta\omega$ 非常小。然后，利用公式 (2.130) 并假设在区间 $|\omega - \omega_{o}| \leq \frac{\Delta\omega}{2}$ 内，$S_{u}(\omega) \approx S_{u}(\omega_{o})$，我们得到

```
S_{d}(\omega) = \begin{cases} {S_{u}(\omega_{o}),\;} & {\text{if}\ \ |\omega - \omega_{o}| \leq \frac{\Delta\omega}{2},} \\ {0,\;} & {\text{otherwise}.} \\ \end{cases}
```

(2.133)

因此，

$$
\Delta P := \mathbb{E}\left[ |d_{n}|^{2} \right] = r_{d}(0) = \frac{1}{2\pi}\int_{-\pi}^{+\pi}S_{d}(\omega)d\omega \approx S_{u}(\omega_{o})\frac{\Delta\omega}{\pi},
$$

由于实随机过程的功率谱密度具有对称性，`u[n] ∈ ℝ` (`Su = Su`)。因此，

$$
\frac{1}{\pi}S_{u}(\omega_{o}) = \frac{\Delta P}{\Delta\omega}.
$$

换句话说，值 `Su` 可以解释为频率（频谱）域中的功率密度（单位频率间隔的功率）。

此外，这也证实了之前的论述：对于 `ω ∈ [−π, +π]` 的任何值，功率谱密度都是*非负*实函数（功率谱密度作为序列的傅里叶变换，具有周期 `2π`，例如 [8]）。

#### 备注 2.2

*   注意，对于任意平稳随机过程，仅有一个自相关序列对其进行描述。然而，逆命题不成立。单个自相关序列可能对应多个平稳随机过程。回顾一下，自相关是随机变量乘积的均值。然而，许多随机变量可以具有相同的均值。
