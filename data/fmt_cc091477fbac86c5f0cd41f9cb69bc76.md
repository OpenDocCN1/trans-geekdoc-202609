## 问题 100
一家大公司的财务部门仍然依靠一个遗留应用程序进行季度报告。已知该应用程序存在一些安全缺陷，但由于其关键性，无法轻易替换。该公司如何**最佳地**缓解与该应用程序相关的风险？

- (A) 对财务团队进行最新网络安全威胁的培训
- (B) 在最新的硬件上运行遗留应用程序以提高性能
- (C) 将遗留应用程序放在 Web 应用防火墙 (WAF) 之后
- (D) 频繁更改访问该应用程序的用户密码

**解释 100.** **正确答案：C. 将遗留应用程序放在 Web 应用防火墙 (WAF) 之后。** 通过将应用程序置于 WAF 之后，公司可以过滤、监控并阻止针对应用程序漏洞的恶意 HTTP 流量，从而为遗留应用程序中潜在的安全缺陷提供了一层保护。

**选项 A 错误。** 虽然培训至关重要，但它不能直接解决遗留应用程序中的漏洞。

**选项 B 错误。** 使用最新的硬件可能会提高应用程序性能，但不能缓解与其漏洞相关的安全风险。

**选项 D 错误。** 虽然频繁更改密码可以增强安全性，但它们无法解决遗留应用程序固有的漏洞。

## 问题 105
在一次安全审计中，发现某应用程序使用明文哈希值存储密码。安全团队建议了一种方法，即使用原始密码结合盐（salt）并进行多次哈希处理。这种方法被称为什么？

- (A) 密钥聚类 (Key clustering)
- (B) 防止彩虹表攻击 (Rainbow table prevention)
- (C) 密钥轮换 (Key rotation)
- (D) 密钥扩展 (Key stretching)

**解释 105.** **正确答案：D. 密钥扩展。** 密钥扩展是指对密码（通常是结合盐值）进行多次哈希处理的过程。这种重复的哈希过程使得暴力攻击变得更加耗时且困难，因为攻击者不仅需要猜测密码，还要以原始过程相同的次数应用哈希函数。

**选项 A 错误。** 密钥聚类涉及不同的密钥从相同的明文产生相同的密文，这与描述的场景无关。

**选项 B 错误。** 虽然盐可以防止彩虹表的有效利用，但多次对密码进行哈希的行为并不专门称为“防止彩虹表”。

**选项 C 错误。** 密钥轮换涉及定期更改加密密钥。它与多次哈希处理密码无关。
