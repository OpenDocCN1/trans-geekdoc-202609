
![](img/ufig7_9.jpg)

重要的问题是，我们应该使用哪种逐步回归法？Table 7.6 描述了每种方法的适用场景。如上所述，自适应逐步回归似乎能够选择最能预测目标变量的预测变量。与正向和反向逐步回归（后者的过程是线性且顺序的）不同，自适应逐步允许我们通过添加和删除变量来获得最佳的模型拟合效果。换句话说，它可以为模型拟合选择最佳预测变量组合。因此，这种方法被推荐用于数据挖掘。该方法的缺点是它可能需要更多的计算时间，在某些情况下可能会过拟合。尽管如此，通过对子样本进行交叉验证，我们可以评估预测能力并避免过拟合。

### Table 7.6 何时使用逐步回归？

| 何时使用正向逐步？ | 何时使用反向逐步？ | 何时使用自适应逐步？ |
| --- | --- | --- |
| **预测变量数量大** 在处理大量潜在预测变量时，正向逐步回归的计算效率更高，因为它从空模型开始并增量添加变量。 | **多重共线性担忧** 如果担心预测变量之间存在多重共线性（高相关性），反向逐步有助于识别并移除冗余预测变量。 | **穷尽搜索** 自适应逐步允许对显著预测变量进行穷尽搜索，而不会导致计算量过大。 |

## 如何阅读和理解回归方程及结果？

![](img/icon_8.jpg)

运行回归分析后，我们使用所有推荐的指标来检查模型拟合情况，包括 `R²`、`F` 检验、`RMSE`、`MAPE`、`RSE`、`EP`、实际值与预测值对比图以及残差与预测值对比图。假设所有标准标准，说明模型拟合良好。下一步是报告和解释回归分析的输出结果。我们如何理解这些输出结果？可以得出哪些结论？

这些在进行任何类型的数据分析时都是常见问题，在数据挖掘中，由于我们的模型中有大量的预测变量，这变得尤为重要。现在我们来看一些简单的假设性回归方程，学习如何阅读和理解预测结果。为了简化解释，我限制了预测变量的数量。我们将在本章后面通过 SAS Enterprise Miner 数据挖掘示例查看一些实际回归结果。

对于线性回归，估计结果通常包含以下信息：

*   截距
*   未标准化回归系数 (`B`)
*   `B` 的标准误差
*   标准化回归系数 (`beta`)
*   `t` 值
*   显著性值 (`p` 值)
*   `B` 的 95% 置信区间

为了正确解释回归结果，我们关注显著性值、未标准化系数和标准化系数。Table 7.8 提供了这些术语的描述以及在解释回归结果时的用法。

### Table 7.8 显著性值、未标准化回归系数与标准化回归系数

| 术语 | 描述 |
| --- | --- |
| 显著性值 (`p` 值) | 显著性值（`p` 值）是用于评估估计系数（也称为回归权重或 `beta` 值）显著性的统计量。它决定了每个预测变量与目标变量之间的关系是否具有统计学意义，还是随机产生的。 |
| 显著性水平 (`alpha`) | 显著性水平是指在评估估计系数的统计显著性时使用的判定阈值。 |
| 未标准化回归系数 (`B`) | 未标准化回归系数是线性回归中的指标，用于以原始单位量化预测变量与目标变量之间的关系。 |
| 标准化回归系数 (`beta`) | 标准化回归系数是线性回归中的指标，用于在将两个变量标准化到共同尺度后，量化预测变量与目标变量之间的关系。标准化系数范围在 `0` 到 `1` 之间，在所有情况下都通过标准差使用相同的尺度进行测量。 |

确定了显著预测变量后，我们需要解释它们与目标变量之间的关系。为了做到这一点，我们使用未标准化回归系数（`B`）。基本上，未标准化回归系数是线性回归中一种衡量指标，用于量化预测变量与目标变量在其原始单位之间的关系。在我们的 `SAT` 预测示例中，假设回归结果显示 `GPA` 和 `family income` 的未标准化系数分别为 `120` 和 `0.01`。此外，截距为 `105`。根据该输出，我们可以将回归方程写如下：

`SAT score = 105 + 120*GPA + 0.01*family_income`

在这个方程中，我们得到了截距和未标准化系数。该方程表明，假设 `family income` 和 `GPA` 是 `SAT scores` 的两个显著预测变量，且它们与 `SAT` 分数均正相关。这些预测变量通过 `GPA` 捕捉了学生的学术表现，通过 `income` 捕捉了家庭教育资源和 `SAT` 辅导。因此，如果我们知道学生这些预测变量的值，就可以根据该方程预测学生的 `SAT score`。更重要的是，我们根据系数相关性知道每个预测变量的变化将如何影响目标变量。换句话说，我们可以看到这些预测变量在预测 `SAT score` 的重要性以及该影响的程度（称为效应大小）。例如，`GPA` 的系数相关性为 `120`；即如果 `GPA` 每增加一分，`SAT score` 将增加 `120` 分。同样，如果 `family income` 增加 `$1`，`SAT score` 将增加 `0.01` 分。为了更直观地理解这一点，可以说如果 `family income` 增加 `$10,000`，`SAT score` 将提高 `0.01*10,000` 或 `100` 分。

注意，我没有在这个方程中包含误差项，因为我们已经在评估模型拟合度时使用了误差。误差代表了预测的 `SAT scores` 与实际分数之间的差异，由于我们的模型拟合得良好，该误差是可以接受的。此外，在这一步中，我们使用上述方程根据这两个显著预测变量的变化来预测 `SAT scores` 的变化。因此，误差是无关的。

### 标准化回归系数 (`beta`)

你可能会注意到，未标准化系数取决于预测变量的单位。换句话说，它们是依赖尺度的。例如，我们可以得出结论认为 `GPA` 的回归系数比 `family income` 高，但无法确定高出多少，因为它们的尺度不同（`GPA` 是分数，而 `income` 是美元）。为了进行有意义的比较，我们需要使用标准化系数。

标准化回归系数是线性回归中一种衡量指标，用于在两个变量标准化到共同尺度后，量化预测变量与目标变量之间的关系。标准化系数介于 `0` 和 `1` 之间，并且在所有情况下通过标准差使用相同的尺度进行测量。换句话说，它们是不依赖尺度的。因此，它们可以直接比较。例如，如果 `GPA` 和 `family income` 的标准化系数分别为 `0.68` 和 `0.34`，我们可以得出 `GPA` 的回归系数高于 `family income`。
