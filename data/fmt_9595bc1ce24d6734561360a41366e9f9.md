
一旦感知机算法运行并收敛，我们就得到了相关神经元/感知机的突触权重 `θ[i]`（`i = 1, 2, …, l`）以及偏置项 `θ[0]`。这些现在可用于对未知模式进行分类。图 18.2A 展示了基本神经元元素的相应架构。特征 `x[i]`（`i = 1, 2, …, l`）被施加到输入节点。依次地，每个特征乘以相应的突触（权重），然后将偏置项加到它们的线性组合上。该操作的结果随后通过一个称为 `activation` 函数的非线性函数 `f`。根据非线性的形式，会出现不同类型的神经元。在更经典的 McCulloch–Pitts 神经元中，激活函数是 Heaviside 函数，即：

```
f(z) = { 1,  if z > 0
       { 0,  if z ≤ 0
``` (18.5)

通常，求和运算和非线性运算会合并，以在相应的图中形成一个 `node`，从而得到图 18.2B 所示的架构。在后续内容中，术语 neuron 和 node 将交替使用，后者表示大型网络中的一个神经元。

因此，一个（人工）神经元的基本模型包含 (a) 一个线性组合器、(b) 一个阈值（偏置）和 (c) 一个非线性函数的级联。注意，由于非线性函数的存在，神经元的输出指示了输入模式来源的类别。对于 Heaviside 非线性函数，来自类别 `ω[1]` 的模式输出为 1，来自类别 `ω[2]` 的模式输出为 0。

从之前的讨论中，我们只需保留多层网络的结构；我们的重点将转向寻找估计突触未知权重和神经元偏置的方法。然而，从概念角度来看，我们必须记住，每一层都执行到新空间的映射，每次映射都提供输入数据的一种不同的、希望更具信息量的表示，直到最后一层，此时任务已被转化为易于求解的任务。

### 18.3.1 全连接网络

前面介绍的前馈网络也称为*全连接网络*。此名称旨在强调任一层中的每个神经元/节点都直接连接到*前一层*的*每个*节点。第一隐藏层的节点与输入层的节点*全*连接。换句话说，*每个*神经元都关联一个*向量*参数，其维度等于前一层（输入层）节点的数量。所执行的代数运算是*内积*。

为了更正式地总结全连接网络中发生的操作类型，让我们关注多层神经网络的第 *r* 层，并假设它包含 *k*[*r*] 个神经元。该层的输入向量由前一层节点的输出组成，记为 **y**^(*r* − 1)。令 **θ**[*j*]^(*r*) 为与第 *r* 层第 *j* 个神经元相关的突触权重向量（包含偏置项），其中 *j* = 1, 2, …, *k**r*，第 18.4 节)。其维度为 *k*[*r* − 1] + 1，其中 *k*[*r* − 1] 是前一层（即第 *r* − 1 层）神经元的数量，加 1 则对应偏置项。然后，在非线性变换之前执行的操作是内积：

```
*z*[*j*]^(*r*) = **θ**[*j*]^(*r**T*)**y**^(*r* − 1), *j* = 1, 2, …, *k*[*r*].
```

将所有输出值收集到一个向量中，**z**^(*r*) = \[*z*[1]^(*r*), *z*[2]^(*r*), …, *z*[*k*[*r*]]^(*r*)\]^(*T*)，并将所有突触向量作为行依次堆叠在一个矩阵 Θ 中，我们可以整体地写为：

```
**z**^(*r*) = *Θ***y**^(*r* − 1), where *Θ* :  = \[**θ**[1]^(*r*),**θ**[2]^(*r*),…,**θ**[*k*[*r*]]^(*r*)\]^(*T*).
```

第 *r* 个隐藏层的输出向量，在将每个 *z*[*i*]^(*r*) 通过非线性函数 *f* 处理后，最终由下式给出：

```
$\\mathbf{y}^{r} = \\begin{bmatrix} 1 \\\\ {f\\left( \\mathbf{z}^{r} \\right)} \\\\ \\end{bmatrix},$
```

上述符号表示 `f` 单独作用于各个向量分量，而向量扩展一维是为了按照标准惯例纳入偏置项。

对于具有许多层和每层许多节点的大型网络，这种连接方式在参数（权重）数量方面被证明代价高昂，其数量级为 `k[r] * k[r - 1]`。例如，如果 `k[r - 1] = 1000` 且 `k[r] = 1000`，这将达到 100 万参数的数量级。请注意，该数字仅来自某一层参数的贡献。然而，正如第 3.8 节已讨论的那样，大量参数会使网络在训练时容易发生过拟合。

相反，可以采用所谓的*权重共享*技术（例如 [156,204]），通过适当的内置约束，让一组参数在多个连接间*共享*。将在第 18.12 节讨论的卷积网络，就属于这类权重共享网络。正如我们将看到的，在卷积网络中，卷积运算取代了内积运算，这允许大量的权重共享，从而大幅减少所需的参数数量。

#### 备注 18.2

*   **浅层网络与深层网络**：从现在起，我们将网络中的层数称为网络的*深度*。最多具有三层（两个隐藏层）的网络称为*浅层*网络，而具有三层以上的网络称为*深层*网络。

## 18.4 反向传播算法

前馈神经网络由若干层神经元组成，每个神经元由相应的突触权重集及其偏置项决定。从这个角度来看，神经网络实现了一个非线性参数函数 `ŷ = f_θ(x)`，其中 `θ` 代表网络中存在的所有权重/偏置。因此，训练神经网络似乎与训练任何其他参数预测模型没有什么不同。所需的只是 (a) 一组训练样本，(b) 一个损失函数 `L(y, ŷ)`，以及 (c) 一个迭代方案，例如梯度下降，以执行相关代价函数（经验损失；见第 3 章第 3.14 节）的优化，

```
J(θ) = Σ_{n=1}^{N} L(y_n, f_θ(x_n)).
```

训练神经网络的困难在于其多层结构使梯度计算变得复杂，而梯度参与了优化过程。此外，McCulloch-Pitts 神经元基于不连续的 Heaviside 激活函数，该函数不可微。开发用于训练神经网络的实用算法的第一步是用 Heaviside 激活函数的可微近似来替代它。

**Logistic Sigmoid 神经元**：一种可能性是采用 logistic sigmoid 函数，即

```
f(z) = σ(z) := 1 / (1 + exp(-a z)).
```

该函数的图形如 图 18.8 所示。请注意，参数 `a` 的值越大，对应的图形就越接近 Heaviside 函数的图形。另一种可能性是使用

```
f(z) = a tanh(c z / 2),
```

其中 `c` 和 `a` 是控制参数。该函数的图形如 图 18.9 所示。请注意，与 logistic sigmoid 函数相反，这是一个反对称函数，即 `f(−z) = −f(z)`。两者也被称为 *squashing*（压缩）函数，因为它们将输出限制在有限的数值范围内。

### 代价函数的非凸性
