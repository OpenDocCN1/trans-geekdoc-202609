
其中 $\omega_{C}(K)$ 是对偶 SVM 任务的解，见公式 (11.86)–(11.88)，可以写成更紧凑的形式：

$$
\omega_{C}(K) = \max_{\mathbf{\lambda}}\left\{ \mathbf{\lambda}^{T}\mathbf{1} - \frac{1}{2}\mathbf{\lambda}^{T}G(K)\mathbf{\lambda}: 0 \leqslant \lambda_{i} \leqslant C, \mathbf{\lambda}^{T}\mathbf{y} = 0 \right\},
$$

$G(K)$ 的每个元素由 $[G(K)]_{i,j} = [K]_{i,j}y_{i}y_{j}$ 给出；$\mathbf{\lambda}$ 表示拉格朗日乘子向量，$\mathbf{1}$ 表示所有元素均等于 1 的向量。文献 [65] 展示了如何将 (11.92) 转化为半定规划 (SDP) 优化任务并相应求解。

许多作者探索的另一条路径是假设建模非线性函数以求和形式给出，

$$f(\mathbf{x}) = \sum\limits_{m = 1}^{M}a_{m}f_{m}(\mathbf{x}) = \sum\limits_{m = 1}^{M}a_{m}{\langle f_{m},\kappa_{m}( \cdot ,\mathbf{x})\rangle}_{\mathbb{H}_{m}} + b = \sum\limits_{m = 1}^{M}\sum\limits_{n = 1}^{N}\theta_{m,n}a_{m}\kappa_{m}(\mathbf{x},\mathbf{x}_{n}) + b,$$

其中每个函数 $f_{m}$，$m = 1, 2, \dots M$ 都位于不同的 RKHS $\mathbb{H}_{m}$ 中。与一组训练数据相关联的相应复合核矩阵由 $K = \sum_{m = 1}^{M}a_{m}^{2}K_{m}$ 给出，其中 $K_{1}, \dots, K_{M}$ 是各个 RKHS 的核矩阵。因此，假设有一个数据集 $\{(y_{n}, \mathbf{x}_{n}), n = 1, \dots, N\}$，MKL 学习任务可以表述如下：

$$
\min\limits_{f}\sum\limits_{n = 1}^{N}\mathcal{L}\left( y_{n},f(\mathbf{x}_{n}) \right) + \lambda\Omega(f),
$$

其中 $\mathcal{L}$ 表示损失函数，$\Omega(f)$ 为正则化项。遵循这一基本原理，出现了两大主要趋势。第一种趋势优先考虑稀疏解，而第二种则旨在提升性能。

在第一种趋势的背景下，解被约束为稀疏的，从而使核矩阵计算迅速，并突出数据集中点之间的强相似性。此外，这种基本原理可应用于核类型已预先选定且目标是计算最优核参数的情况。一种方法（例如 [4,114]）是采用形式为 $\Omega(f) = \left( \sum_{m = 1}^{M}a_{m}{\| f_{m}\|}_{\mathbb{H}_{m}} \right)^{2}$ 的正则化项，该项已被证明能促进集合 $\{a_{1},\dots,a_{M}\}$ 的稀疏性，因为当平方误差损失替代 $\mathcal{L}$ 时，它与组 LASSO 相关联（参见第 10 章）。

与促进稀疏性的准则相反，另一种趋势（例如 [30,63,92]）围绕这样一个论点展开：在某些情况下，稀疏 MKL 变体与原始学习任务相比可能不会表现出性能提升。此外，某些数据集包含单个数据对之间的多种相似性，这些相似性无法通过单一类型的核来突出，而需要多个不同的核来改进学习。在此背景下，首选形式为 $\Omega(f) = \sum_{m = 1}^{M}a_{m}{\| f_{m}\|}_{\mathbb{H}_{m}}^{2}$ 的正则化项。这些方法有几种变体，它们要么对任务施加额外约束（例如 $\sum_{m = 1}^{M}a_{m} = 1$），要么以略微不同的方式定义空间的求和（例如 $f( \cdot ) = \sum_{m = 1}^{M}\frac{1}{a_{m}}f_{m}( \cdot )$）。例如，在 [92] 中，作者将 (11.93) 重述如下：

```
minimize with respect to a  J(a), subject to  sum_{m = 1}^{M}a_{m} = 1,  a_{m} >= 0,
```

(11.94)

其中

$$J(\mathbf{a}) = \min\limits_{f_{1:M},\mathbf{\xi},b}\begin{Bmatrix} {\frac{1}{2}\sum_{m = 1}^{M}\frac{1}{a_{m}}{\| f_{m}\|}_{\mathbb{H}_{m}}^{2} + C\sum_{n = 1}^{N}\xi_{n},} \\ {y_{i}\left( \sum_{m = 1}^{M}f_{m}(\mathbf{x}_{n}) + b \right) \geqslant 1 - \xi_{n},} \\ {\xi_{n} \geqslant 0.} \\ \end{Bmatrix}.$$

优化问题被置于 RKHS（再生核希尔伯特空间）中；然而，问题的表述总是以这样的方式进行，以便可以调用核技巧。

## 11.14 非参数稀疏感知学习：加性模型

我们已经指出，表示定理（由公式 (11.17) 总结）提供了驻留在 RKHS 中的函数的一种近似，该近似以位于点 $\mathbf{x}_1,\dots,\mathbf{x}_N$ 处的相应核为基础。

然而，我们知道任何插值/近似方法的精度都取决于点的数量 $N$。此外，正如第 3 章所讨论的，$N$ 需要多大或多小在很大程度上取决于空间的维数，呈现出对维数的指数依赖（维数灾难）；基本上，必须用“足够”多的数据填充输入空间，才能以足够好的精度“学习”相关联的函数。^(⁸¹)

根据加性模型的基本原理，未知函数被限制在*可分*函数族内，即

$$f(\mathbf{x}) = \sum_{i=1}^{l} h_i(x_i), \quad \text{其中 } \mathbf{x}=[x_1,\dots,x_l]^{(T)}.$$

回想一下，这种展开的一个特例是线性回归，其中 $f(\mathbf{x})=\mathbf{\theta}^{(T)}\mathbf{x}$。

我们将进一步假设每个函数 $h_i(\cdot)$ 都属于一个由相应核 $\kappa_i(\cdot,\cdot)$ 定义的 RKHS $\mathbb{H}_i$，

$$\mathbb{H}_i := \{ h_i : \mathbb{R} \to \mathbb{R} \mid \| h_i \|_i < \infty \},$$

$$\kappa_i(\cdot,\cdot):\mathbb{R}\times\mathbb{R}\mapsto\mathbb{R}.$$

令对应的范数记为 `\|\cdot\|_i`。对于正则化总平方误差代价 [93]，优化任务现在被表述为

```
minimize with respect to f  1/2 ∑_{n=1}^{N} (y_n - f(x_n))² + λ ∑_{i=1}^{l} ‖h_i‖_i,
```

```
s.t.  f(x) = ∑_{i=1}^{l} h_i(x_i).
```

将公式 (11.97) 代入 (11.96) 并遵循类似于第 11.6 节中使用的论证，可以很容易地得到

$$\hat{h}_i(\cdot) = \sum_{n=1}^{N} \theta_{i,n} \kappa_i(\cdot, x_{i,n}),$$

其中 `x_{i,n}` 是 `x_n` 的第 *i* 个分量。沿着第 11.7 节所采用的相同路径，优化可以用以下形式重写

```
θ_i = [θ_{i,1}, …, θ_{i,N}]^T,  i = 1, 2, …, l,
```

作为

$$
\{\hat{\boldsymbol{\theta}}_i\}_{i=1}^l = \arg\min_{\{\boldsymbol{\theta}_i\}_{i=1}^l} J(\boldsymbol{\theta}_1,\ldots,\boldsymbol{\theta}_l)
$$

其中

$$
J(\boldsymbol{\theta}_1,\ldots,\boldsymbol{\theta}_l) := \frac{1}{2}\left\| \boldsymbol{y} - \sum_{i=1}^l \mathcal{K}_i\boldsymbol{\theta}_i \right\|^2 + \lambda\sum_{i=1}^l \sqrt{\boldsymbol{\theta}_i^T\mathcal{K}_i\boldsymbol{\theta}_i},
$$

(11.99)

且 $\mathcal{K}_i$，$i=1,2,\ldots,l$ 为相应的 $N \times N$ 核矩阵

$$
\mathcal{K}_i := \begin{bmatrix}
\kappa_i(x_{i,1},x_{i,1}) & \cdots & \kappa_i(x_{i,1},x_{i,N}) \\
\vdots & \ddots & \vdots \\
\kappa_i(x_{i,N},x_{i,1}) & \cdots & \kappa_i(x_{i,N},x_{i,N})
\end{bmatrix}.
$$

观察到公式 (11.99) 是第 10.3 节中定义的 `group LASSO` 的一种（加权）版本。因此，该优化任务通过将部分向量 `\boldsymbol{\theta}_i` 推向零值来强制稀疏性。为 group LASSO 开发的任何算法也可在此处采用（例如，见文献 [10,93]）。

除了平方误差损失外，还可以采用其他损失函数。例如，文献 [93] 中也讨论了 `logistic regression` 模型。此外，如果公式 (11.95) 中的可分模型无法充分捕捉 *f* 的整体结构，则可以考虑涉及分量组合的模型，例如方差分析（ANOVA）模型（如文献 [67]）。

方差分析（ANOVA）是统计学中一种分析变量间相互作用的方法。根据该技术，函数 *f*(**x**)，**x** ∈ ℝ^(*l*)，*l* > 1，被分解为若干项；每一项均给定为涉及 **x** 的 `subset` 的函数之和。从这个角度来看，公式 (11.95) 形式的可分函数是 ANOVA 分解的一种特例。更一般的分解将是

$$f(\mathbf{x}) = \sum_{i} f_i(x_i) + \sum_{i<j} f_{ij}(x_i, x_j) + \dots$$

(11.100)

并且这可以推广到涉及更多的分量。将公式 (11.100) 与公式 (11.2) 进行比较，ANOVA 分解可被视为多项式展开的一种推广。同样的思想已被用于将核函数 *κ*(**x**, **y**) 分解为其他核函数之和，这些核函数是 **x** 和 **y** 所涉及分量的 `subset` 的函数，从而产生了所谓的 ANOVA 核 [116]。

涉及稀疏加性核模型的技术已被用于许多应用，例如矩阵和张量补全、基因表达补全、基于核的字典学习、网络流和频谱制图（相关综述见文献 [10]）。

## 11.15 案例研究：作者身份识别

文本挖掘是数据挖掘的一部分，它分析文本数据以检测、提取、表示和评估文本中出现的模式，并将其转化为现实世界的知识。文本挖掘应用的几个例子包括垃圾邮件检测、基于主题的文本分类、文本情感分析、文本作者身份识别、文本索引和文本摘要。换句话说，关注点可以在于检测识别作者的文本基本形态特征（作者身份识别），在于识别复杂表达的情感（情感分析），或在于将来自多个文本的冗余信息压缩为简洁摘要（摘要生成）。

在本节中，我们将重点关注作者身份识别的情况（例如，文献 [115]），这是文本分类的一个特例。任务是给定一组带有相应作者标签的训练文本，确定给定文本的作者。为了完成此任务，需要对文本数据进行表示和处理。因此，文本挖掘相关的第一个决策是如何表示数据。

将文本表示在向量空间中是非常常见的，遵循向量空间模型（VSM）[97]。根据 VSM，一个文本文档 *T* 由一组术语 *w*[*i*] 表示，0 ≤ *i* ≤ *k*，*k* ∈ ℕ，每个术语映射到向量 **t** = [*t*[1], *t*[2], …, *t*[*k*]]^(*T*) ∈ ℝ^(*k*) 的一个维度。每个维度中的元素 *t*[*i*] 表示相应术语 *w*[*i*] 在描述文档时的重要性。例如，每个 *w*[*i*] 可以是一种语言词汇表中的一个单词。因此，在实际应用中，*k* 可以非常大，大到足以满足特定任务所需的单词数量。*k* 的典型示例为 10⁵ 阶。

分配 *t*[*i*] 值的广泛使用方法如下：

### 词袋方法

#### 词袋，频率法

词袋方法处理文本依赖于这样一个假设：文本 `T` 无非是其所包含单词的直方图。因此，在词袋假设中，我们不关心原文中单词的顺序。我们关心的是术语 `w[i]` 在文档中出现了多少次。因此，`t[i]` 被赋值为 `w[i]` 在 `T` 中的出现次数。

#### 词袋，布尔法

词袋 VSM 模型的布尔法限制 `t[i]` 的值，使得 `t[i] ∈ {0, 1}`；如果在 `T` 中至少找到一次 `w[i]`，则 `t[i]` 被赋值为 1，否则 `t[i] = 0`。

词袋方法已被证明是高效的，例如在早期的垃圾邮件过滤应用中，单个单词是判断电子邮件是否为垃圾邮件的明确指标。然而，垃圾邮件发送者很快就适应并改变了他们发送的文本，通过插入空格拆分单词：单词 "pills" 会被替换为 "p i l l s"。词袋方法随后需要应用预处理来应对这种情况，甚至要处理不同词形的变化（通过词干提取或词形还原）或拼写错误（通过使用词典纠正错误）。

### 字符 N-gram

一种对噪声具有高鲁棒性的替代表示方法是 *字符 n-gram*。这种表示基于文本中长度为 `n` 的字符子序列（也称为 `n`-gram 的阶）。要使用 `n`-gram 表示文本，我们将文本 `T` 分割成（通常是连续的）长度为 `n` 的字符组，然后将它们映射到向量空间中的维度（词袋 `n`-gram）。下面我们给出一个如何从给定文本中提取 `n`-gram 的示例。

#### 示例 11.5

给定输入文本 `T = A_fine_day_today`，字符和单词 2-gram（`n = 2`）如下：

*   **唯一字符 2-gram**：`"A_"`、`"_f"`、`"fi"`、`"in"`、`"ne"`、`"e_"`、`"_d"`、`"da"`、`"ay"`、`"y_"`、`"_t"`、`"to"`、`"od"`。

*   **唯一单词 2-gram**：`"A_fine"`、`"fine_day"`、`"day_today"`。

观察到 "ay" 和 "da" 在短语中出现了两次，但在序列中只出现一次，因为每个 `n`-gram 都被唯一表示。尽管这种方法已被证明非常有用 [20]，但 `n`-gram 的序列仍未被利用。

### N-gram 图

下面我们描述一种更复杂的表示，它考虑了 `n`-gram 的序列，同时也允许噪声的存在。这种表示称为 *n-gram 图* [46]。`n`-gram 图指示了 `n`-gram 在文本中如何 *共现*。

#### 定义 11.4

如果 `S = {S[1], S[2], …}`，`S[k] ≠ S[l]`，对于 `k ≠ l`，`k, l ∈ ℕ` 是从文本 `T` 中提取的 *不同 n-gram* 的集合，且 `S[i]` 是第 `i` 个提取的 `n`-gram，则 `G = {V, E, W}` 是一个图，其中 `V = S` 是顶点 `v` 的集合，`E` 是形式为 `e = {v[1], v[2]}` 的边 `e` 的集合，`W : E → ℝ` 是一个给每条边分配权重 `w[e]` 的函数。

要生成 `n`-gram 图，我们首先从文本中提取唯一的 `n`-gram，为每个创建一个顶点。然后，给定一个用户定义的距离参数 `D`，我们考虑在文本中彼此距离 *在* `D` 范围 *内* 的 `n`-gram；这些被视为 *邻居*，它们各自的顶点通过一条边连接。为每条边分配一个权重。`n`-gram 图中最常用的边加权函数是图中相连 `n`-gram 在文本中共现的次数。

### 值相似度 (VS)
