### 4.9.2 约束线性估计：波束形成情况

我们已经在 4.9.1 节中处理过一个约束线性估计任务，旨在获得固定值参数向量的无偏估计量。在本节中，我们将看到那里开发的过程很容易应用于未知参数向量需要满足某些线性约束的情况。

我们将在*波束形成*的背景下演示这种约束任务。图 4.19 说明了波束形成任务的基本框图。波束形成器包含一组天线元件。我们考虑天线元件沿直线均匀间隔排列的情况。目标是对各个天线元件接收到的信号进行线性组合，以便：

*   将阵列的主波束指向空间中的特定方向，以及
*   最优地降低噪声。

第一个目标给设计者施加了一个约束，这将保证阵列在特定期望方向上具有高增益；对于第二个目标，我们将采用 MSE（均方误差）准则。

![图 4.19 波束形成器的任务是获得权重 w0,…,wl−1 的估计值，以最小化噪声的影响，同时施加一个约束：在无噪声情况下，从期望角度 ϕ 入射到阵列的信号保持不受影响。](img/gr019.jpg)

图 4.19 波束形成器的任务是获得权重 `w[0]`、`w[l-1]` 的估计值，以最小化噪声的影响，同时施加一个约束：在无噪声情况下，从期望角度 `ϕ` 入射到阵列的信号保持不受影响。

更正式地说，假设发射机足够远，以保证阵列“看到”的波前是平面的。设 `s(t)` 为在载波频率 `ω[c]` 下发射的信息随机过程。则调制信号为

```
r(t) = s(t) e^(j ω[c] t)
```

如果 `Δx` 是阵列相邻元件之间的距离，则在时刻 `t[0]` 到达第一个元件的波前将以以下延迟到达第 `i` 个元件：

```
Δt_i = t_i - t_0 = i (Δx cos ϕ) / c,  i = 0, 1, ..., l - 1
```

其中 `c` 是传播速度，`ϕ` 是阵列与波前传播方向形成的夹角，`l` 是阵列元件的数量。从基础电磁学课程我们知道

```
c = (ω[c] λ) / (2π)
```

其中 `λ` 是相应的波长。在时刻 `t` 取一个快照，第 `i` 个元件从方向 `ϕ` 接收到的信号将是

$r_{i}(t) = s(t - \Delta t_{i})e^{j\omega_{c}(t - i\frac{2\pi\Delta x\cos\phi}{\omega_{c}\lambda})} \approx s(t)e^{j\omega_{c}t}e^{- 2\pi j\frac{i\Delta x\cos\phi}{\lambda}},\quad i = 0,1,\ldots,l - 1,$

![Equation](img/si420.png)

其中我们假设信号随时间的变化相对缓慢。在将接收信号转换到基带（乘以 $e^{-j\omega_{c}t}$）后，时刻 $t$ 接收信号的向量（每个阵列元素一个）可以写成以下线性回归型公式：

$$

\mathbf{u}(t): = \begin{bmatrix} {u_{0}(t)} \\ {u_{1}(t)} \\ \vdots \\ {u_{l - 1}(t)} \\ \end{bmatrix} = \mathbf{x}s(t) + \mathbf{\eta}(t),

$$

![Equation](img/si422.png)(4.105)

其中

$$

\mathbf{x}: = \begin{bmatrix} 1 \\ e^{- 2\pi j\frac{\Delta x\cos\phi}{\lambda}} \\ \vdots \\ e^{- 2\pi j\frac{(l - 1)\Delta x\cos\phi}{\lambda}} \\ \end{bmatrix},

$$

![Equation](img/si423.png)

向量 $\mathbf{\eta}(t)$ 包含加性噪声以及来自 $\phi$ 以外方向的信号造成的任何其他干扰，因此

#### 数学推导与波束形成器约束优化

**η**(*t*) = [*η*~0~(*t*), …, *η*~*l*−1~(*t*)]^(*T*)

![Equation](img/si425.png)

且假设其均值为零；***x*** 也称为 *导向向量*。波束形成器作用于输入向量信号的输出为：

*ŝ*(*t*) = **w**^(*H*)**u**(*t*)

![Equation](img/si426.png)

此处必须使用埃尔米特转置，因为涉及的信号现为复值。

我们首先施加约束。理想情况下，在无噪声环境下，期望能精确恢复从期望方向 *ϕ* 入射到阵列上的信号。因此，**w** 应满足以下约束：

**w**^(*H*)**x** = 1

![Equation](img/si427.png) (4.106)

这保证了在无噪声时 *ŝ*(*t*) = *s*(*t*)。

![Equation](img/si428.png)

注意，若将 **w**^(*H*) 和 ***x*** 分别视为 *H* 和 *X*，则公式 (4.106) 是公式 (4.97) 的一个实例。为考虑噪声影响，我们要求最小化均方误差 (MSE)：

𝔼 [|*s*(*t*) − *ŝ*(*t*)|²] = 𝔼 [|*s*(*t*) − **w**^(*H*)**u**(*t*)|²]

![Equation](img/si430.png)

然而，

*s*(*t*) − **w**^(*H*)**u**(*t*) = *s*(*t*) − **w**^(*H*)(**x***s*(*t*) + **η**(*t*)) = − **w**^(*H*)**η**(*t*)

![Equation](img/si431.png)

因此，最优 **w**[*] 由以下约束优化任务得出：

$\\mathbf{w}\_{\\ast}: = \\text{arg}\\min\\limits\_{w}(\\mathbf{w}^{H}\\Sigma\_{\\eta}\\mathbf{w})\\text{s.t.}\\mathbf{w}^{H}\\mathbf{x} = 1$

![Equation](img/si432.png)(4.107)

这是(4.99)中任务的一个实例，其解由公式(4.100)给出；将其适配到当前的符号表示及其复值形式中，我们得到

![Equation](img/fx021.jpg)(4.108)

和

$\\widehat{s}(t) = \\mathbf{w}\_{\\ast}^{H}\\mathbf{u}(t) = \\frac{\\mathbf{x}^{H}\\Sigma\_{\\eta}^{- 1}\\mathbf{u}(t)}{\\mathbf{x}^{H}\\Sigma\_{\\eta}^{- 1}\\mathbf{x}}$

![Equation](img/si433.png)(4.109)

最小均方误差等于

$\\text{MSE}(\\mathbf{w}\_{\\ast}) = \\frac{1}{\\mathbf{x}^{H}\\Sigma\_{\\eta}^{- 1}\\mathbf{x}}$

![Equation](img/si434.png)(4.110)

用于估计波束成形器权重的代价函数的另一种表述，这在实践中常见，其目标是最小化输出功率，约束条件与之前相同，

$\\mathbf{w}\_{\\ast}: = \\text{arg}\\min\\limits\_{\\mathbf{w}}\\mathbb{E}\\left\\lbrack \\middle| \\mathbf{w}^{H}\\mathbf{u}(t)|^{2} \\right\\rbrack,\\text{s.t.}\\quad\\ \\ \\ \\mathbf{w}^{H}\\mathbf{x} = 1$

![Equation](img/si435.png)

或者等价地

$\\mathbf{w}\_{\\ast}: = \\text{arg}\\min\\limits\_{\\mathbf{w}}\\mathbf{w}^{H}\\Sigma\_{u}\\mathbf{w},\\text{s.t.}\\quad\\ \\ \\ \\mathbf{w}^{H}\\mathbf{x} = 1$

![Equation](img/si436.png)(4.111)

这一次，波束形成器被推向减小其输出信号，由于约束的存在，这等价于以最优方式最小化源自噪声以及从不同于 `ϕ` 方向入射到阵列上的所有其他干扰源的贡献。如果将 `Σ[η]` 替换为 `Σ[u]`，则公式 (4.111) 中任务的求解结果显然与公式 (4.109) 和 (4.110) 的求解结果相同。

这种线性约束任务被称为*线性约束最小方差*（LMV）或*卡蓬*波束形成或*最小方差无失真响应（MVDR）波束形成*。关于波束形成的简明介绍，请参见例如文献 \[48\]。波束形成任务的广义线性版本也已被提出（例如 \[10,32\]）（问题 4.21）。图 4.20 显示了以角度 `ϕ` 为函数的波束模式。公式 (4.108) 中设计最优权重组的期望角度为 `ϕ = π`。天线单元数量为 `l = 10`，间距选为 `Δx/λ = 0.5`，噪声协方差矩阵选为 `0.1*I`。波束模式幅度单位为 dB，即纵轴显示 `20log10(|w*^(H)x(ϕ)|)`。因此，任何从不接近 `ϕ = π` 方向到达的信号都会被抑制。如果使用更多单元，主波束会变得更尖锐。

## 4.10 时变统计：卡尔曼滤波

到目前为止，我们关于线性估计任务的讨论仅限于平稳环境，即假设所涉及随机变量的统计特性随时间不变。然而，在实践中往往并非如此，统计特性可能在不同时刻有所不同。事实上，后续章节将投入大量精力研究时变环境下的估计任务。

鲁道夫·卡尔曼（1930–2016）是第三位科学家，前两位是维纳和柯尔莫戈洛夫，他们的重大贡献奠定了估计理论的基础。卡尔曼出生于匈牙利，后移居美国。他是基于状态空间表述的系统理论之父，这与系统更为有限的输入-输出描述形成对比。

1960 年，卡尔曼在两篇开创性论文中提出了著名的卡尔曼滤波器，它利用状态空间表述，以一种优雅的方式适应时变动态 \[18,19\]。我们将在两个联合分布的随机向量 `y`、`x` 的一般背景下推导卡尔曼滤波器的基本递推公式。任务是给定 `y` 的观测值来估计 `x` 的值。设 `y` 和 `x` 通过以下递推公式线性相关：

```
![](img/fx022.jpg)
```

其中 **η**[*n*], **x**[*n*] ∈ ℝ^(*l*), **v**[*n*], **y**[*n*] ∈ ℝ^(*k*)。向量 **x**[*n*] 称为系统在时刻 *n* 的**状态**，而 **y**[*n*] 是输出，即可观测（测量）的向量；**η**[*n*] 和 **v**[*n*] 分别是噪声向量，称为**过程**噪声和**测量**噪声。矩阵 *F*[*n*] 和 *H*[*n*] 维度适当，并假定为已知。观察可知，所谓的**状态方程**提供了与相关系统时变动态相关的信息。事实证明，大量现实世界的任务都可以转化为公式 (4.112) 和 (4.113) 的形式。该模型称为 **y**[*n*] 的**状态空间**模型。为了推导给定 **y**[*n*] 测量值下的时变估计器 ${\\widehat{\\mathbf{x}}}\_{n}$，将采用以下假设：

*   𝔼[**η**[*n*]**η**[*n*]^(*T*)] = *Q*[*n*], 𝔼[**η**[*n*]**η**[*m*]^(*T*)] = *O*, *n* ≠ *m*
*   𝔼[**v**[*n*]**v**[*n*]^(*T*)] = *R*[*n*], 𝔼[**v**[*n*]**v**[*m*]^(*T*)] = *O*, *n* ≠ *m*
*   𝔼[**η**[*n*]**v**[*m*]^(*T*)] = *O*, ∀*n*, *m*
*   𝔼[**η**[*n*]] = 𝔼[**v**[*n*]] = 0, ∀*n*

其中 `O` 表示零元素矩阵。也就是说，`η[n]`、`v[n]` 互不相关；此外，不同时刻的噪声向量也被认为是不相关的。也存在放宽其中某些条件的版本。相应的协方差矩阵 `Q[n]` 和 `R[n]` 假定为已知。

时变估计任务的推导围绕状态变量的两类估计器展开：

*   **第一个** 记为

    ```
    x̂_{n|n-1}
    ```

    它基于截至时刻 `n-1`（含）所接收到的所有信息；换句话说，即相应随机向量 `y[0]`、`y[1]`、…、`y[n-1]` 的观测值 `y[0]`、`y[1]`、…、`y[n-1]`。这被称为先验或 *先验* 估计器。

*   **第二个估计器** 在时刻 `n` 被称为 *后验* 估计器；它记为

    ```
    x̂_{n|n}
    ```

    并在观测到 `y[n]` 后通过更新 `x̂_{n|n-1}` 来计算。

为推导该算法，假设在时刻 `n-1` 所有所需信息均可获得，即后验估计器的值以及相应的误差协方差矩阵

```
x̂_{n-1|n-1},  P_{n-1|n-1} := E[e_{n-1|n-1} e_{n-1|n-1}^T]
```

其中

$\mathbf{e}_{n - 1|n - 1} := \mathbf{x}_{n - 1} - \widehat{\mathbf{x}}_{n - 1|n - 1}$.

![Equation](img/si465.png)

**步骤 1**：利用 $\widehat{\mathbf{x}}_{n - 1|n - 1}$![Equation](img/si466.png)，根据状态方程预测 $\widehat{\mathbf{x}}_{n|n - 1}$![Equation](img/si462.png)；即，

$\widehat{\mathbf{x}}_{n|n - 1} = F_{n}\widehat{\mathbf{x}}_{n - 1|n - 1}$.

![Equation](img/si467.png)(4.114)

换句话说，忽略噪声的贡献。这是自然的，因为预测不可能涉及未观测到的变量。

**步骤 2**：获得相应的误差协方差矩阵，

$P_{n|n - 1} = \mathbb{E}\left\lbrack (\mathbf{x}_{n} - \widehat{\mathbf{x}}_{n|n - 1}){(\mathbf{x}_{n} - \widehat{\mathbf{x}}_{n|n - 1})}^{T} \right\rbrack$.

![Equation](img/si468.png)(4.115)

然而，

$$

\mathbf{e}_{n|n - 1} := \mathbf{x}_{n} - \widehat{\mathbf{x}}_{n|n - 1} = F_{n}\mathbf{x}_{n - 1} + \boldsymbol{\eta}_{n} - F_{n}\widehat{\mathbf{x}}_{n - 1|n - 1} = F_{n}\mathbf{e}_{n - 1|n - 1} + \boldsymbol{\eta}_{n}.

$$

![Equation](img/si469.png) (4.116)

结合公式 (4.115) 和 (4.116)，很容易看出

$$

P_{n|n-1} = F_{n}P_{n-1|n-1}F_{n}^{(T)} + Q_{n}.

$$

![Equation](img/si470.png) (4.117)
