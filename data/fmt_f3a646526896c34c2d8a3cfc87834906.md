# 第 2 章：量子计算基础

量子电路模型由一系列应用于 `qubits`（量子比特）的量子门组成，`qubits` 表示为处于叠加态的物理系统。与经典比特（可以是 0 或 1）不同，`qubits` 可以同时存在于这两个状态的叠加态中。这一特性允许量子计算机并行执行许多计算。

量子电路是一系列按照特定顺序排列的量子门序列，用于实现所需的计算。这些门是经典逻辑门的量子类比，通过利用叠加和纠缠等量子现象的操作来操纵 `qubits`。

### 量子比特与量子态

一个 `qubit` 通常表示为二维复向量空间中的一个向量。`qubit` 的状态可以写为：

$\ket{\psi = \alpha \ket{0} + \beta \ket{1}}$

其中 $\ket{0}$ 和 $\ket{1}$ 是基态，$\alpha$ 和 $\beta$ 是复数，满足 $|\alpha|² + |\beta|² = 1$。这一归一化条件确保发现 `qubit` 处于任一状态的总概率为 1。

### 量子门

量子门是作用于 `qubits` 以改变其状态的酉操作。一些最常见的量子门包括：

- **Hadamard 门 (H)**：从基态创建叠加态。

  $H \ket{0} = \frac{1}{\sqrt{2}}(\ket{0} + \ket{1})$

- **Pauli-X 门**：类似于经典非门门，它翻转 `qubit` 的状态。

  $X \ket{0} = \ket{1}, \quad X \ket{1} = \ket{0}$

- **Pauli-Y 和 Pauli-Z 门**：分别绕布洛赫球的 Y 轴和 Z 轴旋转。

- **控非门 (CNOT)**：一种双比特门，如果控制比特处于 $\ket{1}$ 状态，则翻转目标量子比特。

### 构建量子电路

构建量子电路涉及指定应用于一组 `qubits` 的一系列量子门。每个门操作都由一个酉矩阵表示，电路的整体操作通过这些单独门的矩阵乘法获得。

考虑一个使用 Hadamard 门和 CNOT 门创建纠缠态的简单量子电路。这在 Q 中可以表示如下：

#### 在 Q# 中创建纠缠态

```qsharp
namespace QuantumCircuits {
  open Microsoft.Quantum.Intrinsic;
  open Microsoft.Quantum.Canon;

  operation CreateEntanglement() : () {
    using (qubits = Qubit[2]) {
      // 对第一个比特应用 Hadamard 门
      H(qubits[0]);
      // 以第一个比特为控制位，第二个比特为目标应用 CNOT 门
      CNOT(qubits[0], qubits[1]);
    }
  }
}
```

Hadamard 门在第一个比特上创建一个叠加态，CNOT 门将其与第二个比特纠缠。结果状态是纠缠态。

### 量子电路模型的优势与挑战

量子电路模型具有许多种优势：

- **并行性**：量子门可以在叠加态上并行操作，实现大规模并行计算。

- **非局部性**：量子纠缠允许比特之间存在非局部相关性，促进了强大的计算技术。

- **可扩展性**：量子电路理论上可以扩展到处理巨大的计算，超越经典计算机的能力。

然而，挑战依然存在：

- **退相干**：量子态非常脆弱，容易受到外部噪声的影响，导致错误。

- **纠错**：实现稳健的量子纠错技术至关重要，但非常复杂。

- **物理实现**：构建和维护能够可靠执行量子电路的量子硬件仍然是一个工程挑战。

量子电路模型是实现量子计算的强大框架。通过理解和利用量子门、叠加和纠缠，我们可以构建出比经典算法更有效地解决复杂问题的量子电路。

### 量子测量的本质

在经典计算中，测量比特不会改变其值。但在量子计算中，测量量子比特会使其叠加态坍缩到基态之一。这种坍缩是概率性的，由量子比特态向量的振幅决定。
