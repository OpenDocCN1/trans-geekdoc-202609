尽管这是书中最长的一章，但它本可以更长。作为一名 `CSA+`，你真的应该熟悉我们在这里描述的每一个工具。理想情况下，你应该精通每种工具。我们的目标不是为你提供我们认为你应该拥有的深度知识，而是对这些必备的职业工具进行高层次的概述。我们希望你以此作为对任何你不熟悉的产品进行自学的跳板。虽然考试只需要你对这些内容有通用的了解，但你对职业工具更深入的知识可能会增强你在现实世界中的表现。

A. `mv`
B. `cp`
C. `md5sum`

### 答案

**1. D.** 下一代防火墙（`NGFWs`），例如 Palo Alto 制造的，可以连接到威胁情报源以快速识别攻击并与他人共享这些信息。它们具有在沙箱中运行应用程序的能力，以便在允许进入网络之前确定是否是安全的。

**2. B.** 安全信息和管理（`SIEM`）系统旨在收集、存储和报告安全信息及事件。

**3. C.** `OpenVAS`（此外 `Qualys`、`Nessus`、`Nikto` 和 `Microsoft Baseline Security Analyzer`）是你应该熟悉的漏洞扫描器。

**4. D.** `Metasploit` 是最广泛使用的开源利用框架。

**5. C.** `Burp Suite` 是一个集成 Web 应用测试平台，通常用于映射和分析 Web 应用程序的漏洞。它能够拦截网络流量并允许分析师检查每个请求和响应。

**6. A.** 通过向应用程序发送随机值来测试应用程序的工具类称为模糊工具（`fuzzing tools`）。`Untidy`、`Peach Fuzzer` 和微软的 `Regex Fuzzer` 都在在本范围内。

**7. B.** `Sourcefire` 是一个入侵防御系统，可以配置为阻止包含问题值的指向 Web 服务器的流量。列出的其他工具都不是 `IPS`，也无法预期能够执行当前任务。

**8. C.** 尽管列出的任何选项在特定条件下可能有效，但 `nmap` 是最佳答案，因为你可以用它快速远程地检查网络上的所有主机。`Snort` 和 `Wireshark` 只有在捕获进发该服务器的流量时才能识别服务器。`netstat` 需要你远程登录到所有主机并查看端口 `1337` 是否正在监听，这种检查大型网络的方法非常耗时。

**9. A.** `Tcpdump` 可以配置为仅捕获指向本地主机特定端口的流量，这将随着时间的推移收集任何其他受损主机的源 IP 地址。此外，`tcpdump` 可以捕获数据包并保存到远程共享文件中，这允许你监控其变化，而不是反复检查。

**10. D, E.** `dd` 工具通常用于为硬盘驱动器等次级存储设备制作位级取证副本。`cp`（复制）命令或 `mv`（移动）命令理论上可以分别复制或移动特定文件，但它们显然无法对磁盘或文件系统制作取证副本。为了确保数据的完整性，你可以使用 `md5sum` 或 `shasum`，但后者更优，特别是当你使用 `SHA-256` 或更好的算法时。

## 术语表

**访问控制列表 (ACL)**：一组控制资源访问方式的规则。

**认证 (Accreditation)**：管理层对系统整体安全性和功能充分性的正式认可。

**行政控制 (Administrative control)**：管理层主要通过策略和程序实施的安全机制；也称为管理控制或策略控制。

**高级持续性威胁 (APT)**：对任何隐蔽且持续的计算机黑客尝试的命名，通常由拥有大量资源的组织或政府在较长时间范围内进行协调和执行。

**异常分析 (Anomaly analysis)**：任何侧重于测量观测值偏离基准的程度，并确定该偏差是否具有统计学意义的技巧。

**评估 (Assessment)**：收集信息并据此做出判断的过程。

**审计 (Audit)**：由独立的第三方进行的系统检查，通常由监管合规要求的驱动。

**信标 (Beaconing)**：受攻击的计算机与外部控制器之间的定期出站连接。

**黑洞 (Black hole)**：配置为接收任何带有特定源或目的地址的数据包且不做出任何响应的设备。

**蓝队 (Blue team)**：培训活动或演习的关注者群体；他们通常负责组织基础设施的防御。

**认证 (Certification)**：对系统安全组件及其对相关法规的合从情况进行全面的技术评估。

**监管链 (Chain of custody)**：显示证据在调查过程的每个阶段如何收集、传输和保存的历史记录。

**云计算 (Cloud computing)**：使用共享的远程计算设备以提供更高的效率、性能、可靠性、扩展性和安全性。

**补偿控制 (Compensating control)**：当无法实现其他控制时，满足其他要求的安全控制。

**抑制 (Containment)**：试图阻止威胁进一步扩散的行动。

**信息和相关技术控制框架 (COBIT)**：ISACA 开发的用于妥善管理 IT 的框架和一组控制目标。

**跨站点脚本 (XSS)**：Web 应用程序漏洞，允许恶意用户执行任意的客户端脚本。

**DNS 汇洞 (DNS sinkhole)**：一种技术，对恶意域名的 DNS 查询返回与目标主机不匹配的 IP 地址，从而防止恶意软件有效通信。

**双重控制 (Dual control)**：一种需要两个或多个方共同完成任务的实践。

**邮件采集 (E-mail harvesting)**：获取电子邮件地址的过程，通常是为了破坏目标的信息系统。

**评估 (Evaluation)**：将观测值与特定值或标准进行比较并报告它们之间差异（如果有）的事件。

**事件 (Event)**：任何可以被观察、验证和记录的发生。

**误报 (False positive)**：报告某给定条件存在但实际上并不存在的报告。

**防火墙 (Firewall)**：一种允许授权数据流过而阻止未经授权流的设备。

**取证获取 (Forensic acquisition)**：从被查获的证据中提取数字内容以便进行分析的过程。

**模糊测试 (Fuzzing)**：一种技术，通过向目标程序发送大量格式错误、意外或随机的数据来触发故障，从而发现软件中的缺陷和漏洞。

**加固 (Hardening)**：通过减少漏洞和功能来保护信息系统的过程。

**哈希函数 (Hashing function)**：一种单向函数，接受文件等变长数据序列并产生一个称为哈希值的固定长度结果；有时被称为数字指纹。

**启发式 (Heuristic)**：一种“经验法则”或其他任何基于经验的、不完美的问题解决方法。

**启发式分析 (Heuristic analysis)**：应用启发式以实际（尽管不完美）的方法发现威胁。

**蜜罐网 (Honeynet)**：为了唯一目的是诱导攻击者尝试攻破而创建的网络。

**基于主机的入侵检测系统 (HIDS)**：一种关注特定主机行为及其网络接口数据包的入侵检测系统。

**事件 (Incident)**：损害组织安全态势的一个或多个相关事件。

**事件响应 (Incident response)**：抵消事件对信息系统影响的过程。

**工业控制系统 (ICS)**：一种允许专用软件控制系统物理行为的信息物理系统。

**IT 基础库 (ITIL)**：一个可定制的框架，提供了内部 IT 服务的目标、实现这些目标所需的通用活动，以及满足这些确立目标所需的每个过程的输入输出值。

**输入验证 (Input validation)**：一种通过对提供的数据进行适当值测试来保护系统免受异常用户输入影响的方法。

**拦截代理 (Interception proxy)**：客户端与服务器之间的中继系统，允许在将消息转发到目的地之前对其进行检查。

**国际标准化组织 (ISO)**：一个独立的非政府国际组织，是全球最大的国际标准制定和发布机构。

**入侵检测系统 (IDS)**：一种识别违反安全策略并生成警报的系统。

**入侵预防系统 (IPS)**：是`IDS`的一种，能够阻止任何检测到的违规行为。

**隔离 (Isolation)**：是指信息系统的部分（如受侵害的主机）防止与系统其余部分通信的状态。

**跳板机 (Jump box)**：是指作为外部用户访问网络受保护部分的跳板的计算机。

**逻辑控制 (Logical control)**：是用于限制访问对象的软件或硬件工具；也称为技术控制。

**中间人攻击 (Man-in-the-middle attack)**：是指攻击者拦截两个终端之间通信的攻击，以获取对消息内容的非法访问并可能对其进行篡改。

**强制访问控制 (MAC)**：是一项在所有对象和主体上始终执行访问控制的策略。

**美国国家标准与技术研究院 (NIST)**：是商务部的一个机构，负责促进创新和工业竞争力。

**NetFlow**：一种用于收集和分发 IP 流量统计数据的思科私有协议。

**Netstat**：流行的命令行工具，提供网络连接状态和监听套接字的信息。

**网络分段 (Network segmentation)**：是将网络的不同部分划分到子区域的做法，以阻碍攻击者的努力、改进流量管理并防止敏感数据泄露。

**网络入侵检测系统 (NIDS)**：是一种专注于流经网络的数据包的`IDS`。

**Nmap**：一种流行的开源工具，允许映射网络主机及其正在监听的端口。

**开放 Web 应用安全项目 (OWASP)**：是一个促进网络安全并提供开发指南、测试程序和代码审查步骤的组织。

**运行控制 (Operational control)**：是一种用于威慑、延迟、防止、检测或响应针对物理财产威胁的保护措施；也称为物理控制。

**数据包分析器 (Packet analyzer)**：是一种捕获网络流量、对其进行某种形式的分析并报告结果的工具；也称为网络嗅探器或包嗅探器。

**补丁管理 (Patch management)**：识别、测试、应用、验证和记录软件漏洞修复程序的过程。

**补丁 (Patching)**：是对软件缺陷的修复应用。

**支付卡行业数据安全标准 (PCI DSS)**：是保护存储、处理或传输支付卡信息的全球标准。

**渗透测试 (Penetration test)**：根据所有者或高级管理层的要求对网络及其系统模拟攻击的过程，目的是衡量组织对此类攻击的抵抗水平并发现环境中任何可利用的漏洞。

**个人健康信息 (PHI)**：是与个人的过去、现在或未来的身体或心理健康状况相关。

**个人身份信息 (PII)**：是指如社会安全号码或生物识别特征等可用于区分个人身份的信息。

**钓鱼 (Phishing)**：是指利用欺诈电子邮件诱导接收者提供敏感信息或采取可能损害其信息系统的操作；是社交工程的一种。

**物理控制 (Physical control)**：是一种用于威慑、延迟、防止、检测或响应针对物理财产威胁的保护措施；有时被称为运行控制。

**公钥基础设施 (PKI)**：是一个由程序、流程、通信协议和公钥加密组成的框架，使不同群体的人能够进行安全通信。

**红队 (Red team)**：是在安全评估或演练中充当攻击者的小组。

**回归测试 (Regression testing)**：是对已修改的代码进行测试的正式过程，以确保没有功能和安全特征受到修改的损害。

**监管环境 (Regulatory environment)**：是指组织的存在或运行方式受到正式机构设立的法律、规则或法规控制的环境。

**修复 (Remediation)**：是将安全控制措施应用于已知漏洞，以将其风险降低到可接受的水平。

**远程认证拨号用户服务 (RADIUS)**：是一种认证、授权和计费（AAA）远程访问协议。

**反向工程 (Reverse engineering)**：是通过解构某个事物以发现其特征和组成部分的过程。

**风险 (Risk)**：任何信息系统资产遭受损坏或损失的可能性，以及发生这种情况的后果。

**风险承受能力 (Risk appetite)**：是指高级高管愿意承担的风险量。

**Rootkit**：通常是一种恶意软件应用程序，它会干扰操作系统的正常报告，通常通过隐藏特定的资源（如文件、进程和网络连接）。

**沙箱 (Sandbox)**：是一种控制类型，将进程从操作系统中隔离以防止安全违规。

**清除 (Sanitization)**：是指在特定的努力范围内使给定介质上数据的访问变得不可行的。

**安全信息和事件管理 (SIEM)**：是一个收集、聚合、分析、报告和存储安全信息的软件产品。

**安全策略 (Security policy)**：是由高级管理层（或选定的委员会或委员会）编写的总体性声明，规定了安全在组织内部扮演的角色，或规定了特定方面的强制性要求。

**职责分离 (Separation of duties)**：是一项将关键功能划分为子任务的做法，并确保没有人可以执行所有这些任务，防止任何个人破坏关键业务流程或在整个组织范围内进行未经测试的管理更改。

**Sherwood 应用业务安全架构 (SABSA)**：是一种分层安全架构模型，其中高层定义策略，低层引导实际实施，从而提供可追溯链。

**社交工程 (Social engineering)**：是指操纵人员使他们采取他们通常不会采取的操作，这些操作通常涉及违反安全策略或程序。

**社交媒体画像 (Social media profiling)**：是从社交媒体上获取并分析特定个人信息的过程，旨在创建可能包含身份信息、偏好的漏洞的画像。

**鱼叉式钓鱼 (Spear phishing)**：针对特定个人或群体的钓鱼尝试。

**静态代码分析 (Static code analysis)**：是一种旨在识别软件缺陷或安全策略违规的技术，通过在执行程序的情况下检查代码来实现。

**压力测试 (Stress test)**：是对超出软件计划阈值的极端需求的测试，以确定其稳健性。

**监控控制与数据采集系统 (SCADA)**：用于在大地理范围内远程监控和控制电力及工厂等物理系统。

**syslog**：一种用于通信事件消息的流行协议。

**技术控制 (Technical control)**：是用于限制访问对象的软件或硬件工具；也称为逻辑控制。

**终端访问控制器访问控制系统 (TACACS)**：一种认证、授权和计费（AAA）远程访问协议。

**开放组架构框架 (TOGAF)**：一种提供了在业务、数据、应用和技术四个层面设计、实施和治理企业信息架构方法的框架。

**趋势分析 (Trend analysis)**：对对随时间变化的模式的研究，以确定它们如何、何时以及为何发生变化。

**可信工厂 (Trusted foundry)**：一个能够开发原型或生产级微电子设备，并能确保其产品完整性的组织。

**虚拟专用网络 (Virtual private network)**：连接两个或多个物理上属于不同网络的设备的系统，允许它们像连接到同一局域网一样交换数据。

**漏洞 (Vulnerability)**：信息系统中的缺陷，可能使攻击者能够破坏该系统的安全性。

**鲸鱼攻击 (Whaling)**：针对高管等高知名目标的鱼叉式网络钓鱼攻击。

**白队 (White team)**：负责计划、记录、评估或主持训练演习的人员小组。

**写保护器 (Write blocker)**：一种在获取存储设备内容时防止对其进行修改的设备。

**零日 (Zero day)**：一种广大软件开发者和安全专业人士社区未知的漏洞或利用程序。
