## 问题 501
一家公司的网站临时被一个幽默的表情包篡改，但没有敏感数据被盗取，也没有造成重大损害。攻击者留了一条信息，炫耀他们首次成功的黑客。哪种威胁行为者最可能负责这次攻击？

+   (A) 内部威胁
+   (B) 高级持续性威胁 (APT)
+   (C) 不成熟的攻击者
+   (D) 国家级

**解释 501.** **正确答案：C. 不成熟的攻击者。** 不成熟的攻击者（通常被称为“脚本小子”）通常利用预制的工具或脚本来执行基础攻击。他们的动机通常是为了炫耀或进行小恶作剧，例如为了好玩或证明自己的能力而篡改网站，而不是执行复杂或具有破坏性的攻击。

**选项 A 错误。** 内部威胁是指组织内部的个人，他们可能有与个人不满或财务利益相关的特定动机。他们的攻击通常更有针对性，并且可能比仅仅篡改网站更有害。

**选项 B 错误。** 高级持续性威胁 (APT) 技能高超，通常代表具有特定长期目标的组织团体。他们的攻击是复杂且隐蔽的，旨在长时间内进行数据窃取或系统攻破。

**选项 D 错误。** 国家级行为者受政治、军事或间谍目的的驱动。简单的网站篡改，尤其是带有幽默表情包的篡改，并不符合他们的典型动机或方法。

## 问题 502
一家金融机构经历了未经授权交易的增加。他们希望实施一种控制措施，允许他们实时识别可疑交易。以下哪项是该场景最好的检测性控制？

+   (A) 为所有用户实施多因素身份验证系统
+   (B) 建立安全运营中心 (SOC) 以监控网络流量
+   (C) 在其网络上安装入侵检测系统 (IDS)
+   (D) 将交易功能限制在少数受信任的 IP 地址上

**解释 502. 正确答案：C. 在其网络上安装入侵检测系统 (IDS)。** 入侵检测系统 (IDS) 通过监控网络流量中的可疑活动和潜在威胁充当检测性控制。在这种情况下，它可以配置为检测与未经授权交易相关的模式，从而允许及时干预。

**选项 A 错误。** 实施多因素身份验证系统是一种预防性控制，通过要求两种或更多验证方法提供额外的安全层。虽然它减少了未经访问的风险，但无法检测可疑交易。

**选项 B 错误。** 建立安全运营中心 (SOC) 是处理安全事件的广泛方法，虽然它可以包含检测性控制，但仅仅建立 SOC 并不能提供对未经授权交易的特定实时检测。

**选项 D 错误。** 将交易功能限制在少数受信任的 IP 地址上是一种预防性控制，限制了潜在交易的来源。虽然它可以减少未经授权交易的数量，但它无法检测这些交易。

## 问题 503
GammaTech 为其员工制定了一项新的远程访问策略。当员工尝试从未知位置访问公司网络时，系统会在授予访问之前请求额外的验证。该策略强调了身份验证的哪种因素？

+   (A) 员工回答的基于知识的问题
+   (B) 员工的指纹扫描
+   (C) 员工访问点的物理坐标
+   (D) 发送到员工手机的短信代码

**解释 503. 正确答案：C. 员工访问点的物理坐标。** 通过验证访问点的位置或坐标，GammaTech 正在利用多因素身份验证中的“你所在的位置”因素。这强调了用户的地理位置。

**选项 A 错误。** 基于知识的问题属于“你所知道的”因素，因为用户根据他们回忆的信息进行回答。

**选项 B 错误。** 指纹扫描属于“你所是的”因素，因为它是生物识别，是个人特有的物理特征。

**选项 D 错误。** 发送到手机的短信代码属于“你所拥有的”因素，因为它是发送到用户拥有的设备上的。

## 问题 507
一家大型集团的 IT 部门每天花费几个小时手动对数千个工作站部署补丁和更新。以下哪些解决方案能够提高此过程的效率并为 IT 团队节省时间？

- (A) 禁用自动更新并进行每月补丁会议
- (B) 实现自动化补丁管理系统
- (C) 设计一个轮班运行的专门补丁团队
- (D) 教导用户自行安装更新

**解释 507。** 正确答案：实现自动化补丁管理系统。通过实施自动化补丁管理系统，IT 部门可以简化所有工作站补丁和更新的部署，确保一致性，减少手动工作，并节省宝贵的时间。

**选项 A 错误。** 禁用自动更新并进行每月补丁会议无法解决手动补丁效率低下的问题，并可能让系统暴露在漏洞中的时间更长。

**选项 C 错误。** 虽然指定专门团队可能会分配工作负载，但它并没有消除与手动补丁相关的效率低下的问题。

**选项 D 错误。** 依赖用户安装更新会引入不一致性、潜在的延迟和额外风险，因为并非所有用户都具备技术知识或会记得定期更新。

## 问题 508
Epsilon 公司最近聘用了 Jenny 担任初级网络管理员。为了确保安全，他们只赋予 Jenny 完成其特定任务所需的访问权限，例如监控网络流量，但不允许修改防火墙规则。这种授予 Jenny 权限的方法符合哪种安全原则？

- (A) 强制性访问控制 (MAC)
- (B) 基于角色的访问控制 (RBAC)
- (C) 时段限制
- (D) 最小权限原则

**解释 508。** **正确答案：D. 最小权限原则。** 最小权限原则规定，应授予用户完成工作功能所需的最低访问级别——或最少权限。在 Jenny 的情况下，她只被授予其角色所需的权限，这符合该原则。

**选项 A 错误。** MAC 涉及信息分类并将用户许可级别与这些分类相匹配。Jenny 的访问不是基于分类的。

**选项 B 错误。** RBAC 根据组织内的角色分配权限。虽然 Jenny 的权限可能与其角色一致，但该场景特别强调了授予最少必要的访问，这是最小权限原则的特征。

**选项 C 错误。** 时段限制根据当前时间确定访问，与最小权限原则没有直接关系。

## 问题 510
CyberSec 公司的 CISO 想要确定过去一个月用户行为是否存在异常。具体来说，他们担心非工作时间的未经授权传输。以下哪些自动化报告对这项调查最有帮助？

- (A) 非工作时间网络活动报告
- (B) 用户密码更改频率报告
- (C) 硬件清单审计报告
- (D) 软件许可合规报告

## 问题 511
在审查 IDS 日志时，安全专家注意到一系列警报，显示单个外部 IP 正在发送利用已知漏洞的负载。然而，接收这些负载的内部系统已打补丁，对该漏洞不受。以下哪项描述了这种类型的 IDS 警报？

- (A) 误报 (False positive)
- (B) 漏报 (False negative)
(C) 真阳性 (True positive)
(D) 真阴性 (True negative)

**解析 511. 正确答案：C. 真阳性。** 真阳性意味着 IDS 正确识别了恶意或异常流量。在这种情况下，即使内部系统没有漏洞，IDS 也正确标记了该流量，因为流量确实是恶性的。

**选项 A 错误。** 假阳性意味着 IDS 错误地将良性流量标记为恶意，而这里的情况并非如此。

**选项 B 错误。** 假阴性意味着 IDS 未能识别出恶意或异常流量，但在这种场景中，IDS 正确地识别了恶意流量。

**选项 D 错误。** 真阴性意味着 IDS 正确地将良性流量标记为良性。此场景中的流量是恶性的，因此不适用。

## 问题 512
某组织最近的一台工作站遭受了恶意软件感染。一名安全分析师被要求审查受感染系统的端点日志，以收集更多关于该事件的信息。端点日志中的以下哪项最能指示初始的恶意软件感染点？

- (A) 显示用户成功登录和注销事件的日志
- (B) 显示系统健康检查状态为“OK”的条目
- (C) 记录最近从临时目录安装并执行的未知 .exe 文件的日志
- (D) 详细说明到域控制器网络连接性检查的条目

解析 512. 正确答案：C. 记录最近从临时目录安装并执行的未知 .exe 文件的日志。记录了未知 .exe 文件安装和执行（尤其是从从临时目录执行）的端点主机是潜在恶意活动的强有力指标。此类日志可以确定系统上恶意软件的初始感染点。

选项 A 错误。用户登录和注销事件是常规日志，除非与其他可疑活动相关，否则不会提供有关恶意软件感染的特定信息。

选项 B 错误。系统健康检查状态条目旨在提供系统健康的一般信息，并未说明与恶意软件相关的系统操作或更改。

选项 D 错误。到域控制器的网络连接性检查在许多网络环境中是常态，并不会直接指示恶意软件活动。

## 问题 513
一名安全分析师正在审查 IPS 日志，发现有多个警报源自单个 IP 地址，该地址尝试访问不同的公司服务器。分析师试图确定攻击的类型。以下哪条日志记录最能指示端口扫描活动？

- (A) 在短时间内对不同端口进行多次连续连接尝试
- (B) 每 3 秒对 Web 服务器的 80 端口进行重复连接尝试
- (C) 从同一 IP 地址对 FTP 服务器进行多次失败登录尝试
- (D) 每 5 秒对网络网关进行持续 ping

# 解析 513. **正确答案：A. 在短时间内，对单台服务器上的不同端口进行多次连续连接尝试。**

端口扫描是一种攻击者探测服务器或主机以确定正在运行哪些服务的活动。对各种端口的快速连接尝试表明，攻击者正试图发现开放端口及其上面运行的服务。

**选项 B 错误。** 虽然对单个端口的重复连接尝试可能很可疑，但它并不是端口扫描。这可能指示 DoS 攻击。

**选项 C 错误。** 多次失败登录尝试表明 FTP 服务器可能遭受了暴力破解攻击，而不是端口扫描。

**选项 D 错误。** 定期向网络网关发送 ping 可能是网络制图或检查连接性的指示，但并不意味着端口扫描活动。

解析 515. 正确答案：C. 投资冗余电源和不间断电源系统。鉴于该地区频繁停电，拥有冗余电源和 UPS 可以确保操作平稳进行，避免导致系统崩溃、数据损坏或安全泄露。

选项 A 错误。虽然节能服务器可以降低成本，但它们没有解决停电和维持运营的首要问题。

选项 B 错误。太阳能板促进了绿色能源，但在夜间或阴天可能无法提供持续且即时的电力备份。

选项 D 错误。将运营限制在白天对于数据中心来说是不可行的，因为它限制了运营能力，并且没有直接解决停电问题。

## 问题 516
一家中型企业在经历一系列恶意软件感染后，对其办公工作站的安全表示担忧。作为一名安全分析师，以下哪些建议最能提高工作站的安全基线？

- (A) 安装多个杀毒软件以确保最大的检测率
- (B) 设置带有网络安全卫生提示的屏幕保护程序以教育用户
- (C) 禁用工作站上不必要的和服务端口
- (D) 频繁更换桌面壁纸以防止单调

解析 516. **正确答案：C. 禁用工作站上不必要的和服务端口。** 通过禁用不必要的和服务端口，可以减少潜在的攻击向量和漏洞，从而提高工作站的安全基线。

选项 A 错误。安装多个杀毒软件可能会导致冲突并降低系统性能。最好使用一个强大且持续更新的杀毒解决方案。

选项 B 错误。虽然网络安全卫生提示具有启发性，但它们对工作站的技术安全基线没有直接贡献。

**选项 D 错误。** 更改桌面壁纸对安全没有帮助。其主要目的是美观。

## 问题 517
一家大型金融机构计划升级 IT 基础设施，以便更高效地利用硬件资源、更快地部署应用程序并缩短服务器配置时间。在评估不同技术时，以下哪项可以直接满足这些需求？

- (A) 网络分段
- (B) 入侵检测系统
- (C) 虚拟化
- (D) 多因素身份认证

**解析 517。** **正确答案：C. 虚拟化。** 虚拟化允许多个虚拟机运行在单个物理宿主机上，从而最大化地利用硬件资源。它能够实现对新服务器和应用程序的快速配置和部署，满足该金融机构的需求。

**选项 A 错误。** 网络分段将网络划分为较小的子网，主要出于安全和性能考虑。虽然这是一项最佳实践，但它无法解决硬件高效利用或应用程序快速部署的问题。

**选项 B 错误。** 入侵检测系统 (IDS) 负责监控并检测网络中的恶意活动。虽然它对安全至关重要，但它无法满足硬件资源效率或更快服务器配置的需求。

**选项 D 错误。** 多因素身份认证是一种安全过程，用户通过多种身份识别方法验证自己的身份。它不会影响硬件资源效率或应用程序部署时间。
