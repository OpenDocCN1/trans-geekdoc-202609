
# 朴素贝叶斯分类器与贝叶斯信念网络

## 总结

朴素贝叶斯分类器基于应用贝叶斯定理（强朴素独立假设）的基础概率分类器。贝叶斯定理中借助新可用信息改变的先验概率被归为后验概率。

朴素贝叶斯分类器的一个主要优势是它只需要少量的训练信息（数据）来衡量分类（排列）所需的参数（变量的均值和差异）。在朴素贝叶斯分类器中，始终假设变量是独立的，并且只需要确定每个类的因子/变量的变化（方差），而不是整个协方差矩阵。由于对数据集所有特征同样重要且独立的朴素假设，这被称为朴素贝叶斯分类器。

朴素贝叶斯分类器是直接线性分类器，以结果简单且高效而闻名。朴素贝叶斯分类器的改进版本源于信息收集（数据集）通常是自治（相互独立）的假设。在大多数实际场景中，“独立”假设经常被违反。然而，朴素贝叶斯分类器往往仍然表现非常好。

### 6.4.5 朴素贝叶斯分类器的应用

**文本分类：** 朴素贝叶斯分类器是用于学习分类文本文档的最成功算法之一。它根据分类概率更高的类别对文档进行分类。它使用上述算法来检查在特定“标题（Title）”下对文档分类概率的排列和组合。它在文档分类、语言检测和情感检测方面有各种应用，这些对于传统零售商、电子商务零售商和其他企业非常有用，可以帮助他们根据反馈表、社交媒体评论等中的关键词来判断客户的情绪。

**垃圾邮件过滤：** 垃圾邮件过滤是朴素贝叶斯文本分类最广为人知的用途。目前，几乎所有的邮件提供商都内置了这一功能，利用朴素贝叶斯分类器根据某些条件以及将邮件分类为“垃圾邮件”的概率来识别垃圾邮件。朴素贝叶斯垃圾邮件过滤已成为识别非法的垃圾邮件与真实邮件（有时称为“ham”）的主流机制。用户还可以安装独立的邮件过滤程序。服务器端邮件过滤器如 `DSPAM`、`Spam Assassin`、`Spam Bayes` 和 `ASSP` 使用了贝叶斯垃圾邮件过滤技术，该功能有时会嵌入邮件服务器软件本身中。

**混合推荐系统：** 它使用了朴素贝叶斯分类器和协同过滤。推荐系统（被 `eBay`、`阿里巴巴 (Alibaba)`、`Target`、`Flipkart` 等电子商务零售商使用）应用机器学习和数据挖掘技术来过滤未见信息，并可以预测用户是否喜欢给定资源。例如，当我们登录这些零售商网站时，根据登录时使用的文本和历史购买数据，系统会自动为特定的登录画像（persona）推荐产品。其中一种算法是将朴素贝叶斯分类方法与协同过滤相结合，实验结果表明，该算法在准确性和覆盖率方面的性能优于其他算法。

**在线情感分析：** 在线应用使用了监督机器学习（朴素贝叶斯）和实用计算。在情感分析的情况下，让我们假设有三种情感：好的（nice）、坏的（nasty）或中性的（neutral），并使用朴素贝叶斯分类器区分它们。简单情感建模将基于统计的分类器与动态模型相结合。朴素贝叶斯分类器采用“单字”和“词对”等特征并确定用户的情感。它将用户的言语分配到好、坏和中性类，分别标记为 `+1`、`-1` 和 `0`。这种二进制输出驱动了一个简单的一阶动态系统，其情感状态代表了实验人物形象的模拟情感状态。

### 6.4.6 朴素贝叶斯分类器处理连续数值特征

在上面的示例中，我们看到朴素贝叶斯分类器模型使用训练数据的频率表进行计算。因此，每个属性数据本质上应该是类别的，这样就可以创建类值和特征值的组合。但在连续数值数据的情况下，是不可能的，因为它不具备数据类别。

在这些情况下采用的解决办法是根据某些数据范围对连续数据进行离散化。这也被称为分箱（binning），因为单个类别被称为箱（bins）。例如，假设我们想向访问特定银行的所有客户推销某种信用卡。我们必须将访问银行的人归类为对新卡感兴趣的候选人或对新卡不感兴趣的候选人，并根据这种分类，销售人员将接触客户进行销售。在这种情况下，客户在银行营业时间内持续访问银行，在将他们归类为感兴趣/不感兴趣类别之前，我们想要评估的属性具有不同的值。

如果我们绘制银行 8 小时营业时间期间访问银行的客户人数图，分布图将是一条连续曲线。但如果我们引入一种逻辑，根据他们进入银行的时间对客户进行分类，那么我们就能将客户放入“箱”或桶（buckets）中进行我们的分析。然后，我们可以尝试评估哪个时间段最适合针对对新信用卡感兴趣的客户。通过进入时间对客户进行分类生成的箱如图 6.5 所示。

## 6.5 贝叶斯信念网络

我们必须注意到，朴素贝叶斯分类器的一项重要假设是属性值 `a*[1]`、`a*[2]`、`a*[n]` 对于目标值是条件独立的。当这一条件满足时，朴素贝叶斯分类器产生输出。尽管这种假设显著减少了计算的复杂性，但在许多实际场景中，这种条件独立的要求变成了算法应用的一个困难限制。因此，在本节中，我们将讨论贝叶斯信念网络的方法，它假设在属性集中，概率分布可以有条件概率关系，也可以有条件独立假设。这与朴素贝叶斯所有属性条件独立的假设不同，因为信念网络提供了灵活性，可以将部分属性声明为条件相关的，而让其他属性保持条件独立的假设。关于一个属性对另一个属性影响的先验知识或信念将在本节稍后通过联合概率进行处理。

让我们复习条件概率的概念。如果一个不确定事件 `A` 取决于知识或信念 `K`，那么在假设 `K` 已知的情况下对 `A` 的信念程度表示为 `P(A|K)`。传统上，条件概率通过联合概率表示如下：

![images](img/165-2.png)

# 重新排列 (6.9)，我们得到乘积规则

`P(A, K) = P(A|K)P(K)`

这可以扩展到三个变量或属性：

`P(A, K, C) = P(A|K, C)P(K, C) = P(A|K, C)P(K|C)P(C)`

对于一个包含 `n` 个属性的集合，乘积规则的通用形式变为：

`P(A[1], A[2], ..., A[n]) = P(A[1]|A[2], ..., A[n])P(A[2]|A[3], ..., A[n])P(A[n]-1|A[n])P(A[n])` (6.10)

乘积规则的这个版本被称为`链式法则`。

![images](img/166-1.png)

**图 6.6** 链式规则

让我们通过图 6.6 中的图表来理解链式规则。从联合概率公式 6.10 中，我们可以写道：

`P(A, B, C, D, E) = P(A|B, C, D, E)P(B|C, D, E)P(C|D, E)P(D|E)P(E)`

但从图 6.6 看出，`E` 与 `C` 和 `D` 不相关，这意味着变量 `C` 和 `D` 的概率不受 `E` 的影响，反之亦然。同样，`A` 只直接受 `B` 的影响。通过应用独立性知识，我们可以简化上述方程为：

`P(A, B, C, D, E) = P(A|B)P(B|C, D)P(C|D)P(D)P(E)`

我们在下一节中详细讨论独立性和条件独立性的概念。

### 6.5.1 独立性与条件独立性

我们将已知知识 `K` 的情况下 `A` 的条件概率表示为 `P(A|K)`。如果 `P(A|K) = P(A)`，则称变量 `A` 和 `K` 是独立的，这意味着 `K` 对 `A` 的不确定性没有影响。同样，联合概率可以写为 `P(A, K) = P(A)P(K)`。

扩展这一概念，如果 `P(A|C) = P(A|K, C)`，则称在给定 `C` 的情况下，变量 `A` 和 `K` 是条件独立的。

这种条件独立性概念也可以扩展到属性集合。如果满足以下条件，我们就可以说在给定变量集合 `C[1], C[2], ..., C[l]` 的情况下，变量集合 `A[1], A[2], ..., A[n]` 与变量集合 `B[1], B[2], ..., B[m]` 是条件独立的：

`P(A[1], A[2], ..., A[n] | B[1], B[2], ..., B[m], C[1], C[2], ..., C[l]) = P(A[1], A[2], ..., A[n] | C[1], C[2], ..., C[l])`

如果我们将此定义与朴素贝叶斯分类器中的假设进行比较，可以看出朴素贝叶斯分类器假设在给定目标值 `V` 的情况下，实例属性 `A[1]` 与实例属性 `A[2]` 条件独立，这可以使用通用乘积规则和条件独立性公式的应用写为：

`P(A[1], A[2] | V) = P(A[1] | A[2], V)P(A[2] | V) = P(A[1] | V)P(A[2] | V)`

贝叶斯信念网络描述了属性集合在联合空间中的联合概率分布。图 6.7 中展示了一个贝叶斯信念网络。该图由节点和弧组成。节点表示我们感兴趣计算条件概率的离散或连续变量。弧表示变量之间的因果关系。

我们从这个网络图中得到的两个重要信息点用于确定变量的联合概率。首先，弧断言在给定网络中其直接前驱节点的情况下，节点变量与其网络中的非后代节点是条件独立的。如果两个变量 `A` 和 `B` 通过有向路径连接，则 `B` 称为 `A` 的后代。其次，每个变量的条件概率表提供了该变量在给定直接前驱节点值情况下的概率分布。chapter006.xhtml#fig6_7。

如上所述，通过使用贝叶斯网络，我们希望根据其他变量的观测值来推断目标变量的值。请注意，在我们处理的随机变量情况下，无法推出一个单一值，但我们的意图是在给定其他变量观测值的情况下，推断目标变量的概率分布。通常，贝叶斯网络可以用于给定其余变量的值或分布，计算任何节点变量子集的概率分布。

### 6.5.2 贝叶斯信念网络在机器学习中的应用

我们已经看到，贝叶斯网络为变量及其关系创建了一个完整模型，因此可以用于回答关于它们的概率查询。该网络的一个用途是当另一组变量子集（称为证据变量）的状态被观测到时，寻找关于变量子集状态的更新知识。这种概念通常被称为在给定某些证据的情况下计算变量后验分布的概率推断过程，它为与检测相关的应用提供了一个通用的充分统计量。因此，如果想通过选择变量子集的值来最小化某些期望损失函数或决策错误，那么这种方法是非常有效的。换句话说，贝叶斯网络是一种自动将贝叶斯定理应用于复杂问题的机制。贝叶斯网络用于对计算生物学和生物信息学等领域进行建模，如蛋白质结构和基因调节网络、医学、法医学、文档分类、信息检索、图像处理、决策支持系统、体育博彩和游戏、房地产分析以及其他领域。

## 6.6 总结

* 贝叶斯方法为概率学习方法奠定了基础，这些方法考虑了关于替代假设的 `prior`（先验）概率知识，以及在假设给定观测各种训练数据的 `likelihood`（似然）概率。然后根据假设的先验和观测数据为每个候选假设分配一个 `posterior`（后验）概率。

* `MAP` 假设是给定数据时最可能的假设。由于没有其他假设更有可能，因此这也是最优假设。

* 贝叶斯最优分类器通过结合所有备选假设的预测并以其后验概率为权重，计算每个新实例最可能的分类。

* `Naïve Bayes classifier` 提出了一个朴素假设，即在实例分类的情况下，属性值是条件独立的。这一简化假设大大减少了计算开销，而不会丢失结果的有效性。在这一假设生效的情况下，朴素贝叶斯分类器输出 `MAP` 分类。

* 朴素贝叶斯分类器已被证明在许多实际应用中有用，被认为是强大的学习方法之一。即使不满足条件独立假设，朴素贝叶斯分类器在为其他学习方法提供标准方面也非常有效。

* `Bayesian Belief network` 提供了一种处理更实际场景的机制，即在考虑观测到的剩余变量联合概率分布的同时，考虑变量子集的条件独立性。
