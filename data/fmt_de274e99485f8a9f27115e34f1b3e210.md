
随机梯度下降有不同的扩展方式，它们不采用贪心方法。它们采用自适应方法，稍微观察四周。这些计算随机梯度的成本通常更昂贵，而在实践中计算随机梯度实际上非常廉价。这就是使用它的原因之一，另一个原因是，实践中局部最小值往往是足够的。

## 3.13 实践中的神经网络优化

在实践中训练这些网络的见解使其变得极其复杂，这回到了之前提出的问题：在实践中训练神经网络是极其困难的。这是实践中神经网络损失地图的可视化 `[11]`。这是大约年前的一篇论文，作者可视化了深度神经网络最后一个地图的形状，你可以在这里看到许多局部最小值。管理这种损失并找到最优真值是极其困难的。现在回想我们之前为梯度下降定义的更新方程。

$$
W \leftarrow W - \eta \frac{\partial J(W)}{\partial W}
$$

(3.27)

考虑方程 (3.27)，在这里我们取权重并减去，向负梯度方向移动。在该方向上更新我们的权重。这就是我们说的学习率，它本质上决定了我们在每次迭代中迈出多大步。在实践环境中，学习率可能非常困难且对于确保你再次避免局部最小值非常重要。所以，如果我们设置的学习率太慢，模型可能会陷入局部最小值。像这样，即使在达到全局最小值的情况下，收敛也会非常缓慢。如果我们将学习率设置太大，梯度基本上会爆炸，并且偏离损失本身。将学习率设置为正确的数值也是糟糕的，这在实践中可能极其枯燥。现在，我们应该跳过某些局部最小值并进入一个合理的局部全局最小值？然后在全局最小值内收敛。我们如何巧妙地做到这一点？一种方案我们可以尝试许多不同的可能的学习率，看看哪种在实践中效果最好 `[12]`。在实践中，这是一个非常常用的技术，很多人只是尝试许多学习率并看哪个最好，让我们更聪明一点。设计一种根据上一次结果调整其学习率的自适应算法如何？

## 3.15 小批量 (Mini Batches)

现在为了继续讨论实践中训练这些网络的技巧，我们将关注梯度下降批量和通用数据批量这一非常强大的想法。

| 算法 | `PC 3.2` |
| --- | --- |
| * 随机权重 `[~] Ɲ(0,ẟ²)` | |
| * 循环直到收敛 | |
| a. 计算梯度，`\frac{\partial J(W)}{\partial W}` | |
| b. 更新权重，`W \leftarrow W - \eta \frac{\partial J(W)}{\partial W}` | |
| * 返回权重 | |

梯度的计算非常复杂。如果我们像 `PC 3.2` 中描述的那样，对训练数据集中的所有数据样本计算这种反向传播算法，在现代数据集中这可能是海量的。这本质上等同于对所有这些数据点进行求和。在大多数现实问题中，这种计算开销极大，在每次迭代中进行计算是不可行的。相反，人们提出了随机梯度下降的想法。这涉及到从我们的数据集中选取单个点，计算该点的梯度，然后用它来更新我们的权重。这非常棒，因为计算单个点的梯度比计算许多个点的梯度要容易得多。但同时，由于我们只观察一个点，这可能会产生极大的噪声。因此，我们每次都会选取不同的点，但尽管如此，当我们移动时沿着该方向迈一步。在那一点，我们迈出的步并不一定代表整个数据集。是否存在某种折中方案，让我们不必使用随机的？虽然它是随机梯度，但在这种意义上我们仍然可以保持某种程度上的效率，而不是计算单个点的噪声梯度。

少于 100 个或大约在该范围内的顺序比随机梯度下降准确得多，因为我们还考虑了更大的群体。这种梯度估计准确度的提高允许能够更快地收敛。这意味着我们可以增加学习率，并在每一步中更信任我们的梯度。这最终意味着我们可以更快地训练。然而，这允许大规模的并行计算，因为我们可以将批量分到各个 `GPU` 上。将批量发送到所有 `GPU` 同时计算梯度，然后将它们聚合回来进一步加速。

## 3.17 正则化

在这里我们讨论深度神经网络的正则化。深度正则化是我们可以引入网络中的一种技术 `[14]`。它将抑制学习复杂模型的产生。正如我们之前看到的，我们的模型不仅能够泛化训练集之外的数据，还要泛化测试集中的数据。深度学习中最流行的正则化技术是一种非常简单的想法，称为 `dropout`。

# 4 联邦学习中的用户参与与激励

Muhammad Ali Zeb and Samina Amin

DOI: [10.1201/9781003466581-4](https://doi.org/10.1201/9781003466581-4)

## 4.1 引言

确保机器学习模型用于预测的长期有效性是一项挑战性任务。数据会随时间变化。使用在某些数据上训练的模型对未来数据进行预测可能由于未来数据模式的变化而不再有效。这种情况被称为概念漂移。学习模型需要适应数据的变化才能在长期预测中保持有效。本章讨论了确保自适应学习过程的一些可能技术，包括联邦学习方法的使用。

利用社交媒体平台维持用户对某些问题或产品的兴趣对于公司和政治组织至关重要。本章研究了用户情感的漂移，以及分类模型如何适应 `X` 上不断变化的政治叙事，以应对随时间推移对某些政治问题的框架构建。构建政治话语框架和维护用户情绪对于选举和公投等政治活动的结果可能很重要。框架构建是塑造公众对问题或产品认知的重要因素。它是分享关于世界的故事，而不是将其作为知识或信息呈现，这些信息可能包含也不包含事实元素。这些故事通常经过框架构建，以围绕特定问题建立政治叙事。

情感分析可以解释为对在线社交媒体内容或文本中所传达的情感、倾向和意见的计算分析 `[1, 2]` 或多模态情感分析 `[3]`。社交媒体平台为用户分享他们对政治问题、商业产品（物品）、国家和全球事件以及其他用户感兴趣的领域的观点提供了巨大机会。这些意见展示了用户社区的集体情感。本章利用自然语言处理（`NLP`）和传统的深度学习（`DL`）方法，研究了用户对某一问题随时间以及应对外部事件表达的情感变化。用户情感可能会随推移而变化，因此大多数基于静态情感和主题建模的方法可能不足以提供长期的情感洞察。尽管在处理用户生成的数据时需要考虑隐私问题 `[4]`，但这项工作重点关注探索社交媒体情感的可变性对塑造政治话语的影响。该分析可用于衡量用户对关键政治政策和问题的反馈。一些工作已经总结了用户对特定主题（如电影）的意见 `[5]`。Gamson 等 `[6]` 提供的数据显示，用户会主动选择与其所属主题组（主题社区）相关的媒体内容，这些内容与普遍意见相关，或将其置于一个对应框架中。这被认为是一种故意的“回声室”或“支柱化”。`NLP` 在在线社交媒体文本上的其他应用包括灾害预测 `[7]`、疾病检测 `[8, 9, 10]`、政治选举 `[11, 12]` 以及情感分析 `[13]`。虽然可以使用 Aziz、Gul 和 Uddin 提出的方法通过社交网络分析来研究这些复杂网络中的概念漂移 `[14]`，但本章仅探索了推文文本来检测漂移的用户意见。

目前已经探索了多种技术，这些技术可以分析社交媒体上政治问题的塑造，以及用户关系如何随时间对某些政治主题和实体发生变化。本章研究了社交媒体用户语言使用模式的变化。本章重点关注以下主要要点：

*   研究如何自动化新数据的情感标记过程，探索与基于词典的方法结合或替代的方法。我们研究了集成分类器的使用，特别是借助词嵌入技术的帮助测试了 `DL` 和 `TL` 技术的结合。
*   负面和正面感知取决于用户对某一问题的态度，我们意图识别基于上下文的主题/问题评估，而非仅仅是文本的词义意义。一个人的负面可能是另一个人的正面，反之亦然。
*   结合基于上下文的技术，实现情感分析和文本分类的新数据探索过程的自动化。
*   通过自动识别对某一问题的负面和正面情感的感知，来识别基于社区的问题评估。

在情感分析和分类过程中发现的一个挑战是缺乏训练集的可访问性。在分类过程中，搜索关键词被用作每个类别的代表，大多数文本都包含这些关键词。另一方面，情感分析可以通过经常用于表达特定类型情感的词汇含义相似性来泛化。例如，文献已将负面词汇归类为负面词典，将正面词汇归类为正面词典 `[15]` 已探索了用于关键词提取影响分析的上下文嵌入技术。然后使用不同的评分机制，根据负面和正面词的计数和频率，将新到达的文本分类为负面、正面或中性类。高度偏向的词在文本分类到某个类别时可能有更大的权重。因此，现有的某些词典可以作为起点，以一定程度的准确性为新文本标记情感标签。
