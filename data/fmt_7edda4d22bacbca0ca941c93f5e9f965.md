## 实函数分析

实分析是处理实数 ![](img/r.jpg) 以及实值函数和序列性质的数学领域。在本节中，我们将涵盖实分析的几个主题，特别是与 ML/AI 相关的实函数。我们将从实线定义开始。

*有理数* 是可以用任意两个整数的比精确表示的数 ![](img/569C3eqig1.jpg)。存在无法用这种形式表示的数，例如，不存在平方为 2 的有理数，即 √2 是*无理数*。所有有理数和无理数的集合称为*实数*集，记为 ![](img/r.jpg)。从几何上看，点的集合 ![](img/r.jpg) 可以用一条无始无终的线来表示。存在比你能想到的最小数还小的实数。也存在比我们能想到的最大数还大的实数。集合 ![](img/r.jpg) 是稠密的，即无论你能想到的两个实数 *a* 和 *b* 有多接近，都存在另一个实数 *c* 使得 *a* < *c* < *b*。整数集合不是稠密的，因为两个连续整数之间不存在整数。

**定义**：设 `a`, `b` ∈ ℝ，`a` < `b`。一个*开区间* `I` 是 ℝ 的一个子集，表示为 `I = (a, b) = {x ∈ ℝ: a < x < b}`。整条实数线用开区间 `(-∞, +∞)` 表示。类似地，*闭*且*有界区间* 由集合 `I = [a, b] = {x ∈ ℝ: a ≤ x ≤ b}` 定义。

**∈-邻域的定义**：以点 `x₀ ∈ ℝ` 为中心的对称开区间：`(x₀ – ∈, x₀ + ∈), ∈ > 0`，对于给定的 ∈ 称为 `x₀` 处的 ∈-*邻域*。选择任意小的正数 ∈，我们可以得到非常接近 `x₀` 的点，然后研究函数在 `x₀` 邻近局部的行为。形式上，∈-*邻域* 表示为所有满足 `|x – x₀| < ∈` 的实数 `x` 的集合。请参考下图：

![](img/Figure-3.1.jpg)

**图 3.1：** *实数线上的邻域*

**内点的定义**：设 `S ⊆ ℝ`。如果存在一个邻域 `N(x, ∈)`，使得 `N(x, ∈) ⊆ S`，则点 `x ∈ S` 称为 `S` 的内点。如果 `S` 的每个点都是内点，则集合 `S` 称为*开集*。开集的有限交和任意并都是开集。

**ℝ 子集的上下界、上确界和下确界的定义**：如果对于所有 `x ∈ S` 都有 `x ≤ M`，则实数 `M` 称为 `S ⊆ ℝ` 的一个*上界*。如果集合 `S` 有上界，则称 `S` *有上界*。类似地，可以定义*下界*。如果实数 `α` 满足：(i) `α` 是 `S` 的一个上界；且 (ii) 不存在严格小于 `α` 的 `S` 的上界，则 `α` 称为 `S` 的最小上界（上确界/sup）。如果上确界存在，则它是唯一的，记作 `sup S`。最大下界（或下确界/inf）类似定义，记作 `inf S`。

***注意：集合的最大元素称为最大元。Sup S 与 Maximum(S) 不同。事实上，每个集合（有上界）甚至可能没有最大元。例如，S = {1 – 1/n, n = 1, 2, …} 没有最大元。1 是该集合的一个上界，但 1 ∉ S。然而，Sup S = 1。***

**完备性公理**：ℝ 的任何非空有上界子集都有最小上界或上确界。类似地，ℝ 的任何非空有下界子集都有下确界。

现在，让我们定义实函数。函数的概念是用数学方式表示一个变量如何依赖于另一个变量。例如，行星的位置是时间的函数。

**单变量实值函数的定义**：实变量函数 `f` 是一种映射，它将定义域内的每个实数 `x` 映射为一个实数 `f(x)`。*函数的定义域* 是函数被定义为有效的实数线子集，记作 `D ⊆ ℝ`，其中 `D` 是函数的定义域。

**示例**：`f(x) = √x`；该函数的定义域 `D` 为 `D = ℝ⁺ ∪ {0}`。该函数将每个正实数映射为其平方根。

**定义**：(*函数的复合*) 设 `f: D → E` 和 `g: E → ℝ` 为函数。设 `h` 为 `E` 上的函数，其中 `f(D) ⊆ E`。则对于每个 `x ∈ D`，有 `f(x) ∈ E`，因此 `g(f(x)) ∈ ℝ`。函数 `h: D → ℝ` 使得 `h(x) = g(f(x)), x ∈ D`。则称 `h` 为 `f, g` 的复合函数，函数 `h` 记作 `g ∘ f`。

## 函数的极限

设 `f(x) = (x² - 1)/(x - 1)`。

该函数在 `x=1` 处未定义，因为分母在 x=1 处为零。但当我们无限接近 1 时，函数取什么值？这由函数 `f` 当 `x → 1` 时的极限回答，记作 `lim_{x→1} f(x)`。

**定义**：(*函数 f(x) 在给定点 a 处的极限*) 如果对于 `L` 的任意选取的 δ-邻域（无论多小），都存在 `a` 的一个 ∈-邻域，使得对于 `a` 的 ∈-邻域内的所有 `x`，`f(x)` 都在 `L` 的 δ-邻域内，即对于所有 `x`，`|x – a| < ∈ ⇒ |f(x) – L| < δ`，则称 `L` 为函数在给定点处的极限，我们记作：

`lim_{x→a} f(x) = L`

现在，对于 1 的邻域内任意一点 `x` 且 `x ≠ 1`，我们可以重写：

`(x² - 1)/(x - 1)` 为 `x + 1`

设 `L = 2`。应用上述定义，如果我们选择 `δ > 0`，则对于任意满足 `|x – 1| < δ` 的 `x`，有 `|f(x) – L| = |x + 1 – 2| = |x – 1| ≤ δ`。因此，`lim_{x→1} f(x) = 2`。请参考下图：

![](img/Figure-3.2.jpg)

**图 3.2：** `f(x) = (x² - 1)/(x - 1)` 的图像

让我们再看一个例子：

`f(x) = x sin(1/x)`

该函数在 `x=0` 处未定义。从图像来看，该函数在 `x=0` 处的极限似乎是 `L=0`。选择 `L=0` 的一个小邻域：

`|f(x) - 0| = |x sin(1/x)| ≤ |x|`

取 `∈ = δ`，我们有：

## 连续函数

如果函数 `f(x)` 将定义域中接近 `x₀` 的点映射为值域中相近的点，则称函数 `f(x)` 在其定义域内的点 `x₀` 处*连续*。

为了更好地理解这一点，让我们先考虑一个将相近点映射为远离点的非连续函数示例。

`f(x) = sgn(x)`，符号函数。

在开区间 `(- ∈/2, ∈/2), ∈ > 0` 中取两点 `a > 0`, `b < 0`。选择任意小的 ∈，我们有 `|a - b| ≤ |a| + |b| < ∈`，但 `f(a) = 1` 且 `f(b) = –1`。因此，尽管 `a` 和 `b` 非常接近，`f(a)` 和 `f(b)` 却相距甚远。因此，`f` 在点 0 处不连续。

如果函数在其定义域的每一点都*连续*，即它总是将相近的点映射为相近的值，则称该函数*连续*。我们可以使用邻域正式地表示这一点。

**定义** (*连续函数*) 设 `f: D → ℝ`，其中 `D ⊆ ℝ`，并假设 `c ∈ D`。如果对于 `c` 的任意选取的 ϵ-邻域，都存在 `f(c)` 的一个 δ-邻域，使得：`c` 的 ϵ-邻域内的任意 `x` 都映射到 `f(c)` 的 `δ`-邻域内的某点 `f(x)`，即 `|x – c| < ∈ and x ∈ D ⇒ |f(x) – f(c)| < δ`，则称 `f` 在 `c` 处连续。

如果我们写 `L = f(c)`，这与极限定义相同。因此，如果 `lim_{x→c} f(x) = f(c)`，我们称函数在 `c` 处连续。例如，函数 `f(x) = |x|, x ∈ ℝ` 是 ℝ 上的连续函数，因为对于任意 `∈ > 0`，选择 `δ = ∈` 即可。

如果函数 `f: D → ℝ` 在其定义域的每一点都连续，则称其为*连续函数*。

以下是关于连续函数的几个重要定理，我们将不加证明地陈述：

**Bolzano 定理**：设 `I = [a, b]` 为闭且有界区间，`f: I → ℝ` 在 `I` 上连续。如果 `f(a)` 和 `f(b)` 异号，则在 `I` 中至少存在一点 `c` 使得 `f(c) = 0`。一个更广义的结果由以下定理给出：

**介值定理**：设 `I = [a, b]` 为闭且有界区间，`f: I → ℝ` 在 `I` 上连续。如果 `f(a) < f(b)`，则 `f` 在 `I` 中至少一次取遍区间 `(f(a), f(b))` 内的每一个值。

## 函数的导数

函数在某一点的导数表示该函数在该点的变化率。求导数的过程称为*求导*。

**定义**：函数 `f` 在 `x_0` 处的*右导数*（其中 `x_0` 是函数定义域内的一点）定义为函数在点 `x_0` 右侧邻域内的变化率。*变化率*是函数值的变化量与 `x` 值在轴上向 `x_0` 右侧发生微小变化（设为 `x_0 + h`，其中 `h` (>0) 很小）的比值。变化率由下式给出：

```
(f(x_0 + h) - f(x_0)) / h
```

该比值代表割线的斜率，如 *图 3.4* 所示：

![](img/Figure-3.4.jpg)

**图 3.4：** *导数与切线*

随着 `h` 变得非常小，这条割线趋于成为 `x_0` 处的切线。函数图像在点 `(x_0, f(x_0))` 处的这条切线的斜率即为函数 `f` 在 `x_0` 处的右导数，正式写作：

```
f'_+(x_0) = lim_{h->0+} (f(x_0 + h) - f(x_0)) / h
```

我们称此为 `x_0 + h`，因为 `x_0 + h` 在 `x_0` 的右侧。类似地，我们可以定义左导数 `f'_-(x_0)` 为：

```
f'_-(x_0) = lim_{h->0+} (f(x_0) - f(x_0 - h)) / h
```

对于轴上 `x_0` 左侧的任意点 `x_0 - h`。

当且仅当函数 `f` 在 `x_0` 处同时具有右导数和左导数，且这两个导数相等时，*函数 f 在 `x_0` 处可导*。这意味着函数图像在 `x_0` 邻域内是光滑的，即如果你取 `x_0` 邻域内函数的一段极小线段，可以用一条小线段来近似它。这就是可导函数也被称为光滑函数的原因。现在，如果函数可导，我们可以将导数重写为对称差商形式：
