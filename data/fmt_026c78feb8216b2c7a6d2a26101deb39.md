
`while`循环在特定条件保持真的同时重复执行代码块。其语法如下：

```
while (条件为真) 
{ 
  //代码
}
```

让我们看一个示例：

```
$d = 1;
while ($d < 5) { 
  echo 'The value of $d is '.$d.'<BR>'; 
  $d++; 
}
```

在示例中，我们声明了一个变量`$d`并赋值为`1`。`while`循环检查`$d < 5`是否为真。如果是，它执行大括号内部的语句。换句话说，它执行了第 5 行的`echo`语句并在第 6 行将`$d`加 1。结果是`$d`变成了 2。接下来，循环返回第 3 行检查`$d`是否仍然小于 5。如果是，它再次执行大括号中的代码。这种检查和更新`$d`值的过程持续直到`$d < 5`不再为真。

## 6.3.7 Do-while 循环

`do-while`循环与`while`循环非常相似，但测试条件位于循环的最后。这意味着循环大括号内的代码始终至少执行一次。语法为：

```
do {
  //某些任务
} while (条件为真);
```

注意，测试条件后面需要一个分号（`;`）。

6 } while ($e<0); 在第 1 行，我们首先声明并初始化了一个变量`$e`，赋值为`100`。接下来，我们有从 3 到 6 行的`do-while`循环。在循环内部，程序执行第 4 行的`echo`语句并在第 5 行将`$e`的值增加到`101`。最后，它到达第 6 行的测试条件。由于`$e`的值小于`0`，测试失败。程序退出`do-while`循环且不再重复循环中的任务。如果你运行上述代码，你将得到输出`The value is 100`。虽然`$e`的原始值不满足测试条件（`$e < 0`），但由于测试条件位于闭合大括号之后，大括号内的代码会被执行一次。

## 4. 流程控制中的其他主题

太棒了！我们涵盖了 PHP 中所有主要的控制结构。在结束本章之前，我想介绍几个更多与 PHP 流程控制相关的杂题。

### 1. 布尔值

首先，让我们来谈谈`bool`数据类型。我们在第 4.3 章遇到过这种数据类型，并了解到它只能存储两个值之一——`true`或`false`。在 PHP 中，大多数值都可以转换为`true`或`false`（即转换为`bool`数据类型）。转换为`false`的值包括：

- 代表零的数字（例如`0`和`0.0`）

- 空字符串（例如`''`，它由两个单引号组成，中间没有包含文本）

- 字符串`"0"`

- 零元素的数组，以及

- 一个名为`NULL`的特殊值。

相反，大多数其他值（如`1`、`3.4`和`"Hello"`）都会转换为`true`。我们已经看到控制结构如何根据条件求值是`true`还是`false`来决定是否执行某块代码。假设我们有以下`if`语句：

```php
if ("hello") {
    echo 'if block';
} else {
    echo 'else block';
}
```

如果我们运行上述语句，我们将得到输出`if block`。这是因为字符串`"hello"`被转换成了`true`。对于任何控制结构，只要条件求值为`true`，无论它是比较的结果（例如`$a < 5`）还是转换为`true`的值，对应的代码块都将被执行。在上面的`if`语句中，由于`if`条件（`"hello"`）求值为`true`，因此执行了`if`块。懂了吗？很好！

### 6.4.2 Break, Continue

接下来，让我们讨论`break`和`continue`语句。这些语句可以修改我们控制结构的行为。我们之前讨论`switch`语句时已经遇到过`break`语句。当满足特定的`switch case`时，`switch`语句会执行后续的所有内容，直到遇到`break`语句。除了在`switch`语句中使用它外，我们可以在循环中使用`break`语句。`break`语句会结束其所在循环的执行。让我们来看一个例子：

```php
for ($i = 0; $i < 50; ++$i) {
    echo "$i<BR>";
    if ($i == 4) {
        break;
    }
}
```

在这里，我们在`for`循环内部有一个`if`语句。`break`语句会结束其所在循环的执行。（此处省略原文中大量重复的句子，按要求不重复输出）。

### 6.4.3 替代语法

接下来，让我们讨论替代（alternative）。PHP 为它的某些控制结构提供了替代语法，特别是`if`、`while`、`foreach`和`switch`。这种语法涉及将左大括号替换为冒号，并将最后一个右大括号分别替换为`endif;`、`endwhile;`、`endforeach;`或`endswitch;`。让我们用`if`语句来说说明。假设我们要根据`$a`的值显示不同的输出，可以使用以下代码：

```php
$a = 5;
if ($a == 5){
    echo '<BR>The value of a is ';
}else{
    echo 'Not five';
}
```

或者，我们可以这样做：

```php
$a = 5;
if ($a == 5):
    echo '<BR>The value of a is ';
else:
    echo 'Not five';
endif;
```

比较这两个`if`语句。注意在上面的第二个`if`语句中，我们将左大括号替换为了冒号？此外，我们将最后一个右大括号替换为了`endif;`语句。如果你运行上述代码，两种语法都将输出`The value of a is 5`。

### 6.4.4 显示 HTML 代码

最后，让我们讨论输出 HTML 代码的技巧。到为止，我们一直在使用`echo`语句在控制结构中输出 HTML 代码（例如`<BR>`标签）。这种技术易用，对于简单的 HTML 代码效果良好。但如果我们需要输出更复杂的 HTML 代码，它可能会变得繁琐，特别是当代码使用了大量的单双引号时。例如，如果我们想用`echo`语句输出以下 HTML 代码`<a href="names.php" target="_blank">The names are 'Aaron', 'Peter', 'James', 'Max', 'Jenny' and 'Don'.</a><img src="names.jpg" alt="Names" height="42" width="42">`，我们需要转义大量的引号。在这种情况下，可以使用一种技巧在 PHP 和 HTML 代码之间切换。为了演示，假设我们想使用`for`循环输出三次 HTML 代码`<h1>Hello</h1>`，下面的代码展示了我们可以如何操作（使用上一节提到的替代语法）：

```php
<?php
for ($i = 0; $i < 3; ++$i):
    echo '<h1>Hello</h1>';
endfor;
?>
```

这个循环使用`echo`语句输出 HTML 代码。或者，如果我们不想使用`echo`语句，可以如下所示：

```php
<?php
for ($i = 0; $i < 3; ++$i): ?>
    <h1>Hello</h1>
<?php endfor; ?>
```

# 5 ?> 仔细研究这两个循环，你注意到了什么区别？首先，注意我们在第二个循环的第 2 行结尾添加了`?>`？这个`?>`标签关闭了第 1 行的`<?php`标签。当发生这种情况时，第二个循环中第 2 行之后的任何代码将不再被解释为 PHP 代码，而是被解释为 HTML 代码。这解释了为什么我们不需要使用`echo`语句在第 3 行输出`<h1>Hello</h1>`。接下来，在第 4 行，我们再次打开了 PHP 标签。当 PHP 看到这个开启标签时，它知道后面跟着的是 PHP 代码。当它遇到`endfor;`语句时，它意识到这是一个`for`循环并寻找要评估的条件。当它在第 2 行找到条件时，它会将`$i`加 1 并再次运行第 3 行。这会一直重复，直到条件`$i < 3`不再有效。学会了吗？如果你运行上面的循环，你会发现两种情况下都会以`<h1>`标题的形式显示三次“Hello”。仔细研究这两个循环以理解这项技术是如何工作的。刚开始可能会有点困惑。核心思想是在切换到 HTML 代码之前关闭 PHP 标签，并在 HTML 代码之后再次打开它。这使得在不需要使用`echo`语句的情况下插入 HTML 代码方便得多。

# 第 7 章：函数

在本章中，让我们开始讨论函数。我们在之前的章节中已经遇到过函数。例如，在第 5 章中，我们学习了使用各种 PHP 函数来处理字符串和数组。在本章中，我们将学习定义自己的函数。

## 7.1 定义自己的函数

要定义自己的函数，我们使用以下语法：

```php
function functionName(list of parameters) { //要执行的代码； //返回语句，如果有的话 }
```

所有函数声明都必须以`function`关键字开头。接下来是函数名。PHP 中的函数名对大小写不敏感，并且可以包含字母、数字或下划线。然而，它们必须以字母或下划线开头。与变量名类似，我们在命名函数时通常使用`camelCase`（驼峰命名法）或下划线。在书中，我们将使用`camelCase`。在函数名之后，我们用一对括号将函数所需的参数列表（如果有）括起来。参数是用于存储传递给函数的值的变量；我们传递的值称为参数（arguments）。声明函数后，我们使用大括号括起我们想要函数执行的代码。如果函数返回结果，我们使用`return`关键字。学会了吗？让我们来看一些例子。

### 示例 1

```php
function displayGreetings(){
    echo 'Hello';
}
```

在这里，我们声明了一个名为`displayGreetings()`的函数，它没有参数（如函数名后的一对空括号所示）。该函数简单地输出单词“Hello”。若要调用该函数，我们使用它的名称后跟一对括号：`displayGreetings();`。

这将产生：

Hello

作为输出。

### 示例 2

```php
function displayGreetings2($name, $message){
    echo "Hello $name, $message";
}
```

在这里，我们声明了一个名为`displayGreetings2()`的函数，它有两个参数`$name`和`$message`。如果我们使用以下语句调用函数：

`displayGreetings2('Jamie', 'good morning');`

参数`'Jamie'`和`'good morning'`将分别赋值给参数`$name`和`$message`。当我们运行上面的代码时，我们将得到：

Hello Jamie, good morning

作为输出。

### 示例 3

在声明函数时，我们可以为参数提供默认值。

```php
function displayGreetings3($name, $message = 'have a good day'){
    echo "Hello $name, $message";
}
```

在上面的示例中，我们将`'have a good day'`声明为参数`$message`的默认值（参考下划线代码）。要调用该函数，可以使用以下语句：

`displayGreetings3('Jamie');`

`echo '<BR>';`

`displayGreetings3('Jamie', 'how are you?');`

在第一次函数调用中，我们省略了第二个参数。当我们这样做时，函数将使用默认值`'have a good day'`作为`$message`的值。如果我们运行上面的代码，我们将得到：

Hello Jamie, have a good day

Hello Jamie, how are you?

作为输出。

当我们在声明带有默认值的参数函数时，请注意，带有默认值的参数必须放在不带默认值的参数之后。如果我们声明函数为`function redundantDefault($a = 1, $b){ //某些代码 }`，则`$a`的默认值将不起作用，因为它在`$b`（不带默认值）之前；调用函数时我们仍然需要提供两个参数。

### 示例 4

最后但同样重要的是，函数可以在完成任务后返回一个结果。

```php
function addNumbers($num1, $num2, $num3){
    return $num1 + $num2 + $num3;
    echo 'Hello';
}
```

上面的函数使用`return`语句返回`$num1`、`$num2`和`$num3`的和。一旦执行了`return`语句，函数就会退出，返回语句后的任何语句都不会执行。我们可以将函数返回的结果赋值给变量，或使用`echo`语句直接显示结果。

如果我们使用以下语句调用上面的函数：`echo addNumbers(9, 6, 1);`将得到：

16

作为输出。`echo 'Hello';`语句不会被执行。

## 7.2 类型声明

之前的示例说明了我们在定义函数时需要了解的关键点。在进入下一章之前，我想在本节中讨论类型声明（也称为类型提示）。类型声明是为新版本 PHP 添加的特性。该特性是可选的，但很好。首先，什么是类型声明？如之前所述，PHP 是一种弱类型语言。在上面的示例中，当我们声明函数时，没有指定数据类型。如果我们传递给函数的参数类型无效，PHP 会尽力尝试执行函数。例如，参考上一节的示例 4，如果我们尝试运行以下语句`echo addNumbers('9', '6', '1');`我们不会得到任何错误。尽管我们向`addNumbers()`函数传递了三个字符串，PHP 会自动将它们转换为整数并执行函数。因此，我们将得到 16 作为输出。这种灵活性使得 PHP 一成为非常易编程的语言。然而，根据你构建网站的需求，你可能希望在数据类型不时不运行函数。在这种情况下，可以使用类型声明。类型声明允许我们在声明函数时指定参数的数据类型。该特性从 PHP 5 开始可用。然而，在 PHP 5 中类型声明对标量类型无效。标量类型是指存储单个值的数据类型，例如`int`、`float`、`bool`和`string`。类型声明仅适用于数组等类型。要在标量类型上使用类型声明，我们需要 PHP 7 及更高版本。此外，我们需要在脚本中添加`strict_types`声明并将`strict_types`设置为 1。为了说明它是如何工作的，让我们来看一个示例。这个示例在 PHP 7 中运行。

在 Brackets 中创建一个新文件并命名为`typedec.php`。向其添加以下代码。

```php
<?php
declare(strict_types=1);

function addNumbersStrict(int $num1, int $num2, int $num3){
    return $num1 + $num2 + $num3;
    echo 'Hello';
}

echo addNumbersStrict('9', '6', '1');
```

在这里，我们使用内置函数`declare()`将`strict_types`设置为`1`。该语句必须是脚本中的第一条语句。接下来，我们声明一个名为`addNumbersStrict()`的函数，带有三个参数`$num1`、`$num2`和`$num3`。我们通过在名称名前添加`int`来指示这些参数必须是`int`类型。最后，我们通过向其传递`'9'`、`'6'`和`'1'`来调用该函数。如果你运行上面的代码，你将得到与下面所示类似的输出：`Fatal error : Uncaught TypeError: Argument 1 passed to addNumbersStrict() must be of the type int, string given...`接下来，将`echo`语句改为

```php
echo addNumbersStrict(9 , 6 ,1);
```

并重新运行代码。由于`9`、`6`和`1`都是`int`类型，我们现在不会遇到任何错误。相反，我们将得到`16`作为输出。明白了吗？除了对参数进行类型声明外，如果我们使用的是 PHP 7 及以上版本，还可以对返回类型进行声明。要做到这一点，我们可以在函数声明的括号后使用冒号来指示返回类型。向`typedec.php`中添加以下代码：

```php
function addTwoNums($a, $b): int {  
    return $a + $b;  
}
echo '<BR>'.addTwoNums(3, 1);
```

在这里，我们指示`addTwoNums()`的返回值应该应该是`int`类型。接下来，我们使用`3`和`1`作为参数调用该函数。如果你运行上面的代码，你将得到`4`作为输出。接下来，将最后一行改为

```php
echo '<BR>'.addTwoNums(3.9, 1);
```

再次运行页面。你将得到以下输出：`Fatal error : Uncaught TypeError: Return value of addTwoNums() must be of the type int, float returned...`这是因为`3.9 + 1`为我们得到了`4.9`，它不是`int`类型。
