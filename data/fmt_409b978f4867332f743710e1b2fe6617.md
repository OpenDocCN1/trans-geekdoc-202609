## 多重回归中的其他主题 609

老年参与者的 `TC` 预测因子，且对于 BMI 值较大的参与者，年龄是 `TC` 的一个不有效的预测因子。

我们该如何解释方程 22.14 中的其他回归系数及其在图 22.8 中的显著性检验？年龄的系数 5.209 是 `BMI = 0` 时预测 `TC` 的斜率。标准误差 1.383 及其对应的 t 值 3.765 同样依赖于 `BMI = 0` 的值。同样，`BMI` 的系数 7.844 是 `age = 0` 时预测 `TC` 随 `BMI` 变化的斜率，标准误差和 t 值也仅适用于 `age = 0`。

我们可能对 `age = 0` 且 `BMI = 0` 时发生的情况不感兴趣，但我们可能感兴趣某个系数在另一个预测因子的特定值处是否显著。例如，我们可能想测试 `age = 20` 时预测 `TC` 随 `BMI` 变化的斜率是否显著。有几种方法可以进行测试。我们可以通过将 `age = 20` 代入方程 22.15 来找到该值。我们也可以建立 `age = 20` 时斜率的标准误差表达式并进行相应的 t 检验。然而，执行这种简单效应检验最简单的方法是对变量进行转换并回归

假设我们创建变量 `age20 = age - 20`。那么我们可以对 `TC` 对 `age20`、`BMI` 和 `age20xBMI`（通过 `age20` 和 `BMI` 相乘得到的变量）进行回归。所得方程为：

```
TC = 33.931 + 5.209 age20 + 5.135 BMI – 0.135 age20 × BMI
```
