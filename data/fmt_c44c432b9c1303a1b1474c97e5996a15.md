
# 生成器深度解析与 Python 编程实战

## 什么是生成器？

生成器与 Python 中的函数非常相似。函数与生成器的唯一区别在于，后者使用 `yield` 关键字来返回值。因此，作为一条简单的规则，只需记住：每当你在 Python 编程示例中看到 `yield` 关键字时，它自动就是一个生成器函数。

格式如下：

```python
def function_name():
    yield
```

## 什么是生成器对象？

生成器对象是在从头创建生成器函数时形成的。它们通常由 Python 编程语法中存在的方法结构实现。请始终记住，对象是面向对象的系统性结构，如果协调不当可能会导致事故。

格式如下：

```python
generator_object = generator_expression
```

## 生成器有哪些应用？

生成器通常用于处理复杂计算。它们也可用于创建协调不佳的可迭代函数。它们可用于创建复杂的斐波那契数列。生成器被广泛用于开发人工智能应用。许多嵌入式系统也使用生成器以更快地实现硬件资源。

在下一节中，我们将使用斐波那契数列示例详细解释生成器原理。

代码如下：

```python
def fibonacci_example(parameters):
    first, second = 3, 4
    # use generators
    yield first
    yield second
    # generator expression
    yield from fib()
    for item in display_results():
        yield item
```

在该示例中，会发生以下实现过程：

1.  首先，你需要创建一个定义以启动创建斐波那契数列的过程。你可以输入所需的值作为输入来启动该过程。
2.  在下一步中，你需要在 `yield` 关键字的帮助下开始使用生成器，以便为这些变量赋值。在这里，变量代表我们将在下一步中要查看的迭代原则。
3.  随后，你需要创建对象来表示生成器表达式机制。你可以使用这些对象来遍历变量并创建一个遵循斐波那契数列的变化序列。
4.  最后，我们再次使用生成器来打印结果。

通过该程序，我们了解到生成器可以减少通常需要处理的资源。

## 生成器如何用于机器学习？

生成器是训练科学模型的一个优秀组件原则。许多机器学习项目使用监督模型来执行操作。监督学习系统高度依赖预处理技术来显示各种结果。为了减少机器学习模型中的过拟合问题，可以使用生成器。你可以使用数组在 Python 中实现生成器。

在下一节中，我们将给出一个示例，帮助你理解生成器在 Python 中的优势。

Python 代码如下：

```python
# create a list
list_name = [1, 2, 3, 4, 5]

def machine():
    obj1 = gen(parameters)
    obj2 = gen.machine
    yield next(obj1)
```

你可以使用生成器在数据点之间创建范围。这里 `yield` 代表生成器表达式。机器学习是一个广泛的学科，学习生成器将帮助你创建没有任何欠拟合和过拟合错误的模型。

# 第 9 章：如何用 Python 编程？

本章将简单介绍基本的 Python 语法结构，帮助你进行 Python 编程。Python 是一门动态类型语言，定义逻辑所需的代码块非常少。Python 由不同的程序结构组成，了解它们对于编写完美的代码非常重要。

## a) 注释

注释是在阅读代码时向程序员提供信息的简便方法。它们通常在程序中跟在 `#` 后面。注释在运行时不会被编译。示例如下：

```python
# this is a definition
def add(parameters):
    pass
```

注释最初是为了从结构上组织代码而开发的。然而，随着时间的推移，注释已成为编程中不可或缺的一部分。

## b) 字面量

字面量在编程中也称为常量。这些是可以通过赋值运算符赋给变量的值。如果需要，所有字面量都可以被替换。字符串也属于字面量，通常可以使用不同的系统函数进行操作。示例如下：

```python
a = 355
```

此处 `355` 是被赋给变量 `a` 的字面量。

## c) 变量

变量用作内存存储，用于存储赋值的字面量并在需要时使用。在处理函数和逻辑语句时，变量非常重要。你可以使用逻辑语句轻松更改已赋值的变量。示例如下：

```python
first = 3
```

此处 `first` 是变量名，`3` 是已赋给该变量的字面量值。请始终记住，变量只能通过赋值语句进行赋值。

## d) 数据类型

数据类型用于对创建的变量进行分类。创建变量时，为其分配指定的内存位置很重要。然而，每次都创建固定大小的内存位置是不可行的。因此，在创建变量时指定数据类型很重要。有许多默认数据类型，如整数、浮点数、双精度浮点数和字符。示例如下：

```python
a = 4788  # Here int is the data type (inferred)
```

## e) 条件语句

编程由逻辑语句组成。处理复杂代码时，我们需要使用控制流语句以获得期望的结果。Python 提供了许多控制流语句，如条件语句和循环。条件语句是一种控制流语句，我们可以通过逻辑判断来选择执行路径。`if-else` 是表示条件语句的简便方式。示例如下：

```python
if a > 3:
    # print the statement
    pass
else:
    # print another statement
    pass
```

## f) 运算符

运算符用于将语句组合成表达式。在上一章中，我们已详细讨论了运算符模块。请务必确保在调试代码前了解运算符优先级。

## g) 字符串

字符串是 Python 中最重要的数据类型之一。通常，我们会处理大量的字符串字面量。数据集通常以字符串形式组合，可以使用 Python 默认提供的一些字符串函数进行操作。示例如下：

```python
a = "This is a string"
a.lower()
```

使用此系统函数，你可以将字符串字面量转换为小写。你可以查阅文档以了解其他可用的字符串函数。

## h) 异常

Python 还提供了高级异常处理机制来处理错误。程序在运行时通常会遇到错误。向最终用户显示错误以帮助他们了解所犯的错误非常重要。为了实现这一点，我们使用 `try`、`except` 块来捕获异常及其错误输出。

## i) 列表

Python 使用可用的结构处理多个数据。有不同的数据结构，如列表、元组和字典，用于处理多维数据。如果你正在尝试开发机器学习应用程序，掌握这些结构非常重要。

## 简单代码的实现

如前所述，要远程重启或关机，Python 首先必须能在本地控制计算机重启或关机。以下是该功能的实现。首先，仅让 Python 控制本地计算机重启或关机。此次开发也称为第一次开发，可作为小软件开发过程中第一个版本的简单程序。

如果想控制本地计算机重启或关机，可以使用 `os.system()` 方法并传入相关的 Shell 指令。可以通过 Shell 命令 `shutdown` 控制计算机关机，也可以通过 Shell 命令 `shutdown -r` 控制计算机重启。

以下是 Python 代码：

```python
import os

# shutdown the system
os.system("shutdown -s -t 1")
```

执行上述代码后，计算机将自动关机。如果想用 Python 代码控制本地计算机重启，可以通过以下 Python 代码实现：

```python
import os

# restart the system
os.system("shutdown -r -t 1")
```

执行上述代码后，计算机将自动重启。因此，简单版本的代码如下：

```python
import os

result = input("Please enter what you want to do: shutdown input 1, restart input 2")
# Note: 1 enclosed in double quotation marks. Because the input is a string instead of the number
if result == "1":
    # shut down
    os.system("shutdown -s -t 1")
    print("shutdown instruction is ready")
elif result == "2":
    # Restart
    os.system("shutdown -r -t 1")
    print("restart instruction is ready")
else:
    print("no operation performed")
```

执行上述程序后，我们将被提示输入所需操作，如下所示：

```text
Please enter the operation you wish to perform: shutdown input 1, restart input 2
```

如果我们想关机，可以输入 `1` 并按回车。如果想重启，可以输入 `2` 并按回车。如果输入其他信息并按回车，则不执行任何操作。例如，输入 `3` 并按回车键将输出以下信息：

```text
Please enter what you want to do: shut down input 1, restart input 2
3
no operation performed
```

如果输入 `2` 并按回车，将执行重启命令，如下所示：

```text
Please enter the operation you wish to perform: shutdown input 1 and restart input 2
2
The restart command was executed successfully.
```

随后，计算机将在一分钟内自动关机并重启。同样，如果执行上述代码后，输入 `1` 并按回车键，将执行关机操作。至此，已实现如何通过 Python 代码控制本地计算机的重启和关机。这是小目标软件的第一个版本，即简单版本。尚未达到最终目标，因此需要进一步开发。

## 开发过程中的调试

有时，编写软件时会出现某些错误和问题。尝试解决这些问题的过程称为调试。开发本项目时，我们也会遇到各种问题。这没关系。我们只需要找出问题所在，并改进相应的程序即可。

## 程序打包的概念

将编写的程序代码转变为可直接执行的软件的过程称为程序打包。例如，现在编写的脚本只能在 Python 编辑器中运行。打包成软件后，无需 Python 编辑器支持，即可直接在操作系统中运行。

## Python 程序打包的方法

读者可以使用一些工具将 Python 程序打包成可执行的应用软件。在 Python 中，常用的打包工具包括 `py2exe`、`PyInstaller` 等。这些工具不需要完全掌握，大家可以选择一个认为合适的工具。本书将介绍如何通过 `PyInstaller` 打包 Python 程序。

要使用 `PyInstaller`，首先需要安装它。这里可以直接使用 `pip` 安装 `PyInstaller`。首先，打开 `cmd` 命令行界面，然后输入指令。通过 `pip install pyinstaller` 指令安装 `PyInstaller`，只需等待安装完成。安装完成后，会出现安装成功的提示信息。此外，读者可以在 Python 安装目录下的 `Scripts` 目录中看到安装的工具文件 `pyinstaller.exe`。

接下来，可以使用 `PyInstaller` 工具将 Python 程序打包成应用软件。例如，本项目完整程序的路径是 `D:/sample/project.py`，我电脑的 Python 安装目录是 `D:/Python`。因此，可以通过以下 `cmd` 指令打包本项目的 Python 程序：

```cmd
D:\> D:\Python\Scripts\pyinstaller.exe D:\sample\project.py
```

成功打包的可执行程序可以在 `D:/dist` 目录中找到。`sample` 文件夹是刚才打包生成的与 `project.py` 程序相关的软件文件夹。

扩展名为 `.exe` 的文件是打包后生成的可执行文件。双击该文件即可直接运行。此时，只要向指定邮箱发送“关机”或“重启”指令，仅通过打开程序即可远程控制当前计算机重启或关机。

可以看到，目前打包的程序需要依赖许多文件。由于依赖文件过多，将打包后的程序迁移到其他计算机运行非常不方便。实际上，也可以将所有依赖文件打包进一个 `.exe` 文件中；打包时只需添加 `-F` 参数即可。同时，打开软件后会出现一个 `cmd` 界面。在某些情况下，你不希望软件有这个 `cmd` 界面，打包时也可以通过 `-w` 参数直接屏蔽它，这样在某些情况下会美观得多。

接下来，我将展示如何将所有依赖文件打包成一个没有 `cmd` 界面的 `.exe` 文件。打包的 `cmd` 指令如下：
