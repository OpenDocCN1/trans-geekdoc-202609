### 在 Windows 10 中配置权限

在本练习中，您将学习设置 NTFS 权限和共享文件夹权限，以保护 Windows 10 系统上的 Data 文件夹。

1. 登录到 Windows 10 VM 并在 C 盘创建一个名为 `Data` 的文件夹。
2. 右键单击 `Data` 文件夹并选择“属性”。
3. 选择“安全”选项卡，然后单击“高级”按钮。
4. 单击“禁用继承”按钮，然后在提示时选择“将所有继承的权限从该对象中删除”。
5. 单击“确定”关闭窗口。
6. 单击“编辑”按钮以更改权限。
7. 单击“添加”以将用户或组添加到权限列表，然后输入 `sales;administrators` 并单击“确定”。
8. Sales 被添加到权限列表中。选择 Administrators，然后在“允许”列中选择“完全控制”。选择 Sales，然后在“允许”列中选择“修改”权限。
9. 单击“确定”关闭所有窗口。

#### 共享 Data 文件夹

10. 右键单击 `Data` 文件夹，选择“属性”，然后选择“共享”选项卡。
11. 在“共享”选项卡上，单击“高级共享”按钮。
12. 选中“共享此文件夹”复选框。请注意，共享名称与文件夹名称相同——在本例中为 Data。单击“权限”以设置共享权限。
13. 单击“删除”以移除 Everyone 具有“读取”权限的默认权限。
14. 单击“添加”，输入 `administrators;sales`，然后单击“确定”。
15. 选择 Administrators，然后选择“完全控制”作为权限。
16. 选择 Sales，然后选择“更改”作为权限。
17. 单击“确定”。
18. 再次单击“确定”。

# Linux 文件权限

在 Linux 中保护文件略有不同。Linux 对文件和文件夹有三种权限，每种权限都有一个关联的数值：

- **读取 (R)**：4
- **写入 (W)**：2
- **执行 (X)**：1

三个实体可以拥有对文件或文件夹的这三种权限：文件所有者、组和其他所有人（“其他”）。要查看分配给文件的权限，可以使用 Linux 中的 `ls -l` 命令列出文件（请参见图 7-14）。

# 数据加密

可以在许多不同的地方启用加密。关键在于，无论何时您在某种类型的内存或设备上存储数据，都应该调查是否可以加密该数据——大多数情况下您都可以！以下列表概述了一些加密信息的常用领域：

- **全盘** 当今大多数操作系统都支持全盘加密 (FDE)。例如，Windows 7 及更高版本拥有 `BitLocker`，它允许您加密整个驱动器的内容，包括操作系统。要启动系统，个人需要知道密钥，以便引导文件可以被解密。
- **数据库** 在数据库中存储信息时，加密敏感信息至关重要。例如，如果您的公司有一个存储客户信用卡号码甚至客户网站密码的应用程序，则应在数据库中加密该数据，因为如果未加密，黑客有可能访问数据库并发现这些信息。
- **单个文件** 如果您不加密整个驱动器的内容，可以考虑加密选定敏感文档的内容。例如，您可以使用 Windows 中的加密文件系统 (EFS) 来加密单个文件。
- **可移动介质** 如果您在可移动驱动器（如闪存驱动器）上存储数据，请务必加密该驱动器上的所有公司数据。闪存驱动器太容易丢失或遗忘在某处，如果数据未加密，任何人都可以读取！
- **移动设备** 大多数移动设备允许您加密其内容，以便在丢失或被盗时，无人能够检索其中的数据。

![Image](img/exam.jpg)

> **针对 Security+ 考试，请记住，任何类型的可移动驱动器或移动设备上的数据都应加密，以保持机密性。**

## 基于硬件的加密

数据加密可以由系统上的软件或硬件（安装在系统上的计算机芯片）执行。使用基于硬件的加密的好处是它优于软件解决方案，并且由于计算的复杂性，您会发现硬件解决方案执行工作的速度快得多！

### TPM

**可信平台模块 (TPM)** 是系统上的一个计算机芯片，用于存储加密数据所用的加密密钥。使用密码加密数据的应用程序容易受到字典攻击，而 TPM 内置了防字典攻击模块。在 Windows 中，`BitLocker` 支持使用 TPM 存储密钥。请记住，要使用它，你必须拥有支持 TPM 的 BIOS。

### HSM

**硬件安全模块 (HSM)** 是一张添加到系统中的卡，包含一个加密处理器，用于在硬件级别执行非对称加密功能。它还包含存储系统所用加密密钥的芯片。

### USB 和硬盘加密

如前所述，你应确保任何硬盘和可移动存储（如 USB 驱动器）都经过加密，以便未经授权的个人无法访问数据。

![Image](img/exam.jpg)

> **针对 Security+ 考试，请熟悉 TPM。另请注意，如果你使用 TPM 加密驱动器内容，应保留一份密钥副本，以便在 TPM 芯片或主板发生故障时能够解密磁盘内容。**

## 其他数据安全注意事项

实施数据安全时，你还应考虑许多其他因素，包括以下内容：

- **云存储**：如果你将信息存储在云中，请务必了解你组织关于此方面的安全策略。由于数据的敏感性质，某些组织无法将数据存储在云中。
- **SAN**：大多数组织都有存储区域网络来存储所有数据。请务必花时间验证 SAN 是否以安全方式配置。
- **处理大数据**：确保用于存储公司数据的任何大数据处于安全状态，并且在网络上的客户端访问时使用安全通道。大数据是组织用于分析和做出商业决策的大型数据集。
- **传输中数据、静态数据、使用中数据**：确保你通过权限或加密来保护存储中的数据，并通过加密来保护传输中的数据。此外，通过限制用户在软件中可对该数据执行的操作，确保数据在使用时也是安全的。

## 实施数据策略

你在 第 2 章 中了解到，对任何组织而言，安全最重要的方面之一是拥有详细的安全策略，明确组织内所有的应该做和不应该做的事。更新安全策略并包含数据策略非常重要，数据策略应规定以下内容：

- **擦除**：确保策略规定设备必须被安全擦除，在设备不再使用时清除设备上的所有数据。还要确保策略规定丢失或被盗的设备应被远程擦除。
- **处置**：务必在策略中规定如何处置存储数据的设备。例如，更换系统中的硬盘时，高安全环境需要粉碎旧硬盘，以确保没有人能拿到该驱动器上的数据。
- **保留**：确保你的组织制定了保留策略，规定数据和记录的保留时长。
- **存储**：确保策略规定数据可以存储在何处。例如，你可能希望在策略中包含 USB 记忆棒是否为公司文件的有效存储选项，或公司是否允许使用云存储。

## 数据安全和隐私实践

处置和销毁数据有多种不同的方法。所有组织都应实施数据销毁和介质清理策略，以帮助 IT 专业人员了解如何从旧硬盘和移动设备等设备中移除数据。以下是一些处置数据以保护组织隐私的选项：

- **焚烧**：销毁敏感文档的一种简单方法是焚烧文档。
- **粉碎**：你可以粉碎文档以销毁敏感信息。务必使用交叉切割碎纸机；普通碎纸机将文档切成条状，很容易复原。你可以购买专用类型的碎纸机来销毁旧硬盘。
- **制浆**：你可以利用化学品将敏感文档制成浆，将纸张分解成液体/糊状形式。
- **粉碎/粉碎化**：粉碎销毁旧硬盘并将其化为细小颗粒。
- **消磁**：消磁是从硬盘中移除磁场的过程，导致数据丢失。
- **清除**：清除数据意味着从存储介质（如硬盘）中永久擦除它。
- **擦除**：你可以使用程序安全擦除驱动器，这意味着多次覆盖驱动器以确保数据无法恢复。

![Image](img/exam.jpg)

> **针对 Security+ 考试，了解设备不再需要后确保数据机密性的不同技术。在高安全环境中，旧驱动器会被物理销毁，以确保没有人能恢复其中的数据。**

## 应用程序安全和 BYOD 顾虑

Security+ 认证考试新增的一个热门主题是应用程序安全最佳实践和*自带设备 (BYOD)* 顾虑。在本节中，你将了解有助于创建更安全应用程序环境的常见最佳实践，以及允许用户将个人设备带入办公室时应考虑的事项。

### 应用程序安全最佳实践

首先让我们看看一些有助于创建更安全应用程序基础设施的常见最佳实践。虽然其中一些主题在前面的章节中已涉及，但复习它们很重要：

- **密钥管理**：确保应用程序以安全的方式创建加密密钥并存储它们。
- **凭据管理**：确保应用程序中使用的任何安全凭据都以安全方式使用，并且它们也以加密格式存储在数据库中。
- **认证**：确保你的应用程序对所有应用程序用户进行认证，并根据该认证控制用户有权访问的内容。
- **地理标记**：验证应用程序是否使用任何地理标记功能，将地理识别信息与照片或视频等媒体一起存储。这可能是一个隐私问题，因为物理位置可能从此地理标记数据中确定。
- **加密**：确保应用程序加密任何敏感信息，包括网络通信和存储中的敏感数据。
- **应用程序白名单**：根据应用程序的目的，验证其是否具有白名单功能，这是一个可在应用程序中配置的允许列表。例如，电子邮件程序可以有联系人白名单，即软件中允许发送电子邮件的联系人列表。
- **传递信任/认证**：这指的是一项功能，允许你的应用程序信任受另一个环境信任的安全主体，因为你的应用程序信任该其他环境。

### BYOD 安全顾虑

如今一个巨大的安全顾虑是员工将自己的个人设备（如手机、平板电脑和笔记本电脑）带入办公室，并用它们执行公司任务。允许员工使用个人设备时，以下代表了一些顾虑，在设计 BYOD 策略时应予以考虑：

- **数据所有权**：你要确保如果允许员工使用自己的个人设备工作，明确信息归公司所有，而非员工。如果员工离职，他们必须从设备中擦除所有公司数据。
- **支持所有权**：重要的是要明确如果设备出现问题，谁负责设备的支持。大多数公司会确保员工知道他们负责自己的设备支持。
- **补丁管理**：明确谁负责保持设备通过补丁保持最新。同样，这可能被视为员工的工作，并且应该明确告知员工，他们必须保持设备上的补丁级别最新。
- **杀毒软件管理**：决定谁管理杀毒软件功能。如果是员工，则确保员工在设备上安装了杀毒软件并保持病毒定义最新。
- **取证**：您的 BYOD 策略应明确规定，如果个人设备发生安全事件，公司有权对设备执行取证分析。员工可能不同意这一点，这是不允许将个人设备用于工作的充分理由。
- **隐私**：另一个敏感话题是对设备隐私的期望。您应该让员工同意，如果他们要在设备上存储公司数据，则您有权查看和监控设备上的活动。同样，员工可能不同意这一点，因此，您不应允许公司数据存放在个人设备上。
- **入职/离职**：当允许需要访问您的系统和网络的个人设备时，您需要确保已制定程序，将这些个人设备添加到身份和访问管理（IAM）系统中，该系统用于识别公司外部的人员或设备并控制对系统的访问。将新设备添加到系统的过程称为 `onboarding`，而从系统中移除设备的过程称为 `offboarding`。
- **遵守公司政策**：另一个重要点是确保员工在使用个人设备时遵守公司政策。这可能包括杀毒软件和补丁管理政策以及可接受使用政策。
- **用户接受**：确保员工同意使用个人设备工作的条款，如果他们不同意，您将不得不禁止使用该设备。请记住，您的目标是保护公司的利益。
- **架构/基础设施考量**：您需要考虑为允许个人设备访问您的系统而需要对网络基础设施进行的任何更改。例如，您可能需要向设备创建和部署证书，或扩展 DHCP 服务器上的 IP 范围。
- **法律顾虑**：允许个人设备用于商业用途存在许多法律顾虑，这些通常是公司稳妥行事并表示“不允许个人设备用于工作目的”的原因。法律顾虑的示例包括数据归属权、对设备执行取证调查以及员工隐私（因为设备归他们所有）。
- **可接受使用政策**：确保员工在使用其个人设备时同意可接受使用政策。通常，员工想使用自己的设备是为了绕过可接受使用政策。
- **车载摄像头/视频**：如果物理安全是顾虑，您可能需要禁用摄像头，以免在工作场所拍摄照片和视频。

# 安全系统设计

在网络内的每个系统和设备上实施安全性是环境安全的关键。本章重点演示了一些用于提高系统安全性的常用工具，如防火墙和杀毒软件。本节旨在回顾查看主机安全性时的关键点。

## 硬件/固件安全

在实施系统和设备安全性时，至关重要的是要关注可以增加系统或设备安全性的硬件功能或固件功能。例如，支持 TPM 模块的设备可以使用 TPM 模块实现全盘加密。以下是一些可以增加设备安全性的硬件或固件功能：

### FDE/SED

如前所述，全盘加密（FDE）是一项安全功能，允许设备加密整个硬盘，以帮助在设备丢失或被盗的情况下保持机密性。您还可以使用 `自加密驱动器 (SED)` 来保护数据，这是一种特殊的硬盘驱动器，无需额外软件或用户输入即可自动加密驱动器内容。例如，您可以使用 Opal 驱动器，这是一种独立的硬盘驱动器，可自动始终加密驱动器上的数据。

### TPM

在使用全盘加密时，您可以使用可信平台模块（TPM），它是位于主板上的计算机芯片，用于存储 FDE 功能的加密密钥。

### HSM

需要高级别安全性的环境可以利用硬件安全模块（HSM），它是一个附加卡或单独的设备，负责管理环境的加密密钥。

### UEFI/BIOS

有许多 UEFI 或 BIOS 功能可以启用以帮助硬件安全。例如，使用启用 BIOS 的系统，您可以为设备添加启动密码，防止从光驱或 USB 驱动器启动，并对 BIOS 设置程序进行密码保护。使用统一可扩展固件接口（UEFI），您将拥有更高级的安全启动功能，如 `Secure Boot`，它在启动期间验证启动设备的完整性。

### 安全启动和证明

`Secure Boot` 是一项设备安全功能，启用后涉及系统对启动文件进行数字签名。文件签名后，系统将在启动期间仅加载经过数字签名的文件。这有助于防止他人在该系统上启动另一个操作系统，以获取对系统及其数据的访问权限。在此语境下，`Attestation`（证明）意味着系统已根据数字签名按预期方式启动。

### 供应链

供应链是产品在到达客户之前必须经过的组织和人员名单。请务必确认在发生硬件故障时，您能够快速订购零件并收到交付。

### 硬件信任根

硬件信任根是系统信任的执行安全功能的硬件组件（例如，生成并存储密钥对的 TPM）。

### EMI/EMP

电磁干扰（EMI）是来自外部源的干扰，会扭曲正在传输的信息。电磁脉冲（EMP）是电磁能量的爆发。确保使用不受 EMI/EMP 影响的技术，例如光纤布线代替双绞线布线，以保护您的数据。

## 操作系统加固和反恶意软件

实施主机安全的第一步是通过加固设备并安装任何反恶意软件功能来锁定系统或设备。以下是锁定系统要采取的关键步骤：

### 操作系统安全和设置

确保您已查看系统或设备上的设置，以将设备置于安全状态。尽可能更改设置，以便不使用默认设置，因为黑客知道并预期默认设置。

### 操作系统加固

加固系统或设备意味着您需要花时间删除不必要的功能并禁用不必要的服务。每个功能都有漏洞，因此删除它们可以减少系统上的漏洞。

### 补丁管理

确保您已将最新固件应用到设备并修补了软件。

# 操作系统类型与安全加固

根据您所审查的操作系统类型，您需要优化将系统置于安全状态所采取的步骤。以下是您可能遇到的一些常见操作系统类型：

- **网络操作系统** 网络操作系统设计用于在服务器上运行。请务必仅加载网络操作系统所需的服务，以帮助减少暴露的漏洞数量。
- **服务器操作系统** 服务器操作系统旨在为客户端提供资源，如文件和打印机。通过仅安装所需的软件并及时应用补丁来锁定每台服务器。
- **工作站** 工作站是用户用来访问网络资源的设备。请务必安装反恶意软件并保持客户端处于最新状态。
- **设备** 设备是指用户使用的任何装置。请务必调查设备上运行的任何服务或协议，以便在需要时将其禁用。
- **信息亭** 信息亭是位于公共场所（如大楼前厅）的计算机系统，供人们出于特定目的使用。请务必锁定信息亭并限制其上可运行的应用程序。
