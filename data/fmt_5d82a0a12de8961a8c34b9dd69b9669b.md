
基于主机的防火墙通常会将信息写入日志，或在因系统上配置的规则而丢弃流量时显示警报。查找包含诸如 `dropped packet src=24.35.45.3:63378 TCP dst=32.46.58.62:80 TCP` 等信息的输出。在此信息中，你应能看到源和目标 IP 地址（`24.35.45.3` 和 `32.46.58.62`）、源和目标系统使用的端口号（`:63378` 和 `:80`）以及协议（`TCP`）。

## 应用程序白名单

应用程序白名单是为系统配置一份允许使用的已批准软件列表。如果有人尝试安装或运行列表之外的应用程序，将收到一条错误消息，提示该应用程序未获授权。你可以使用 Windows 中的 `AppLocker` 创建一份获授权在系统上运行的应用程序列表。

## 可移动介质控制

可移动介质控制是指控制系统上可访问的介质，例如光驱和可移动介质（如外置 USB 驱动器）。当用户尝试连接或访问不允许使用的驱动器时，屏幕上通常会弹出一条通知，提示他们无权访问该驱动器。你可以通过 Windows 中的组策略配置可移动介质控制，如即将介绍的练习 5-1 所示。

## 高级恶意软件工具

高级恶意软件工具会通知你检测到的恶意软件，并提供关于该恶意软件的详细信息。它们还会报告恶意软件是否已成功清除或移至隔离区。

## 补丁管理工具

补丁管理工具旨在协助将补丁部署到网络上的系统。使用补丁管理工具时，你应该能看到输出，例如系统需要哪些补丁，以及向系统部署补丁时的状态更新。如果由于某些原因补丁未能应用到一个或多个系统，你也会收到通知。

## UTM

`统一威胁管理 (UTM)` 系统是一种集成了多种安全功能的设备，例如防火墙、`IDS/IPS`、网关杀毒软件和网关反垃圾邮件、内容过滤以及数据丢失防护等内置安全技术。`UTM` 系统会输出大量信息，例如可疑流量警报、被拦截的病毒和垃圾邮件数量报告，以及内容过滤违规数量摘要。

## DLP

数据丢失防护 (`DLP`) 解决方案可防止用户将敏感信息发送到公司外部。当用户尝试将数据复制到 USB 驱动器时，可能会收到来自 `DLP` 解决方案的错误消息，提示他们没有权限；或者如果用户尝试发送包含被 `DLP` 拦截的敏感信息的电子邮件，用户通常会收到一封电子邮件，提示因 `DLP` 违规，内容未发送。

## 数据执行保护

数据执行保护 (`DEP`) 是一项可启用的功能，用于防止应用程序代码在用于存储数据的内存区域（称为数据页）中执行。启用 `DEP` 后，系统会将不用于执行程序的内存块标记为不可执行页面，从而防止恶意软件在该内存块中运行。你可以通过转到命令提示符并输入 `wmic OS Get DataExecutionPrevention_SupportPolicy` 来验证系统上是否启用了 `DEP`。你将收到输出 `0`（始终关闭）、`1`（始终开启）、`2`（针对 Windows 二进制文件开启）或 `3`（针对所有程序和服务开启）。

## Web 应用程序防火墙

Web 应用程序防火墙旨在保护 Web 服务器免受恶意流量侵害，仅允许发往 Web 应用程序的流量通过防火墙。被防火墙阻止的流量会被写入日志文件，以便系统管理员查看被阻止的流量。

## 基于云与本地部署的漏洞

本章包含的漏洞大多是考虑到本地部署网络进行讨论的，这意味着这些是你会在局域网内的系统和设备上发现的漏洞。

许多常见漏洞也可能存在于云环境中，其中大多数与配置错误有关：

- **开放端口** 确保不要在云资源（如虚拟机 (VM) 或应用程序）上打开不必要的端口。例如，许多 IT 管理员会创建一个 Azure VM，然后打开远程桌面协议 (RDP) 端口以远程连接到该 VM。在这种情况下，Azure 提供了堡垒主机选项，因此你无需在每个 VM 上打开 RDP 端口。
- **身份验证方法** 由于云应用程序可从世界任何地方访问，你应该配置多因素身份验证 (MFA)，以便当你或其他人尝试使用你的帐户登录时，会向你的手机发送一个需要输入以进行身份验证的身份验证代码。
- **条件访问策略** 你可以使用条件访问策略来帮助提高安全性，并保护资源免受弱密码或弱身份验证的侵害。条件访问策略允许你在用户访问云资源时实施限制。例如，你可以让策略应用于用户、组、设备，甚至他们的 IP 位置。
- **权限过多** 留意用户在云环境中被授予过多权限的情况（例如，将不必要的用户添加到全局管理员组）。

## 识别物理威胁

在深入探讨不同类型的恶意软件之前，我想让你熟悉一下企业在现实世界中遇到的一些常见物理威胁。在本节中，我将讨论一些针对系统和设备的常见物理威胁类型，并讨论如何将针对公司资产的威胁降至最低。

### 窥探

在第 4 章中，你了解了垃圾箱搜寻的概念，这涉及黑客翻阅你的垃圾并拿走可能有助于攻击的机密文件。黑客不仅可能对你的企业进行垃圾箱搜寻，你的员工也可能窥探他人桌面上的文件，甚至翻阅他们的文件柜查看与他们无关的文档。

为防止此类窥探攻击导致信息泄露，请务必在企业内实施清洁桌面政策。`clean desk policy` 规定敏感文件不得随意摆放在外，不用时必须归档保存。

你还必须保护存放在文件柜中的信息，确保文件柜位于安全区域并上锁，以防止未经授权的人员访问信息。

![Image](img/exam.jpg)

**你应该知道，所有文件在处置前都应粉碎，以防止窥探或垃圾箱搜寻。**

教育企业中的所有员工，确保他们粉碎所有待丢弃的文件，不要将未粉碎的文件直接扔进垃圾桶或回收箱。所有待处理的公司文件都必须先经过碎纸机处理！

### 资产盗窃与丢失

许多物理安全威胁来自设备的丢失或被盗，例如笔记本电脑或移动设备（智能手机、平板电脑等）。许多公司都有规定：如果员工将公司笔记本电脑或移动设备留在汽车内，不得将其放在显眼处，以防止砸窗抢夺式盗窃。在这种情况下，一些公司在政策中规定由员工负责赔偿笔记本电脑或电子设备。鼓励员工将所有电子设备锁在汽车后备箱中，而不是将其可见地放在副驾驶座位或后排座位上。值得注意的是，一些组织可能会因员工不遵守此类政策而对其进行训斥，以确保员工认识到妥善处理公司资产、做出负责任决策的价值。

在办公室内，你可以通过使用防盗锁线缆来帮助阻止笔记本电脑、平板显示器、投影仪甚至台式计算机等设备被盗。`lockdown cable` 是一种连接并锁定在设备上的小型线缆，用于将设备固定在桌面上。这些防盗锁线缆无法阻止心存不轨的小偷偷窃设备，但能起到威慑作用，防止路人顺手牵羊。图 5-1 显示了一个防盗锁线缆。

#### 远程擦除设备

确保员工了解立即报告移动设备丢失或被盗的重要性，以便你能尽快远程擦除这些设备。擦除设备会从服务器向设备发送信号，以擦除其所有数据及配置。这可确保丢失或被盗的移动设备上不包含敏感信息。

#### 设备上的安全防护措施

在移动设备上实施安全防护措施非常重要，这样如果设备被盗或丢失，你可以让他人尽可能难以使用该设备。

大多数设备支持设置某种形式的密码或 PIN 码，这样如果有人偷走了设备，他们就需要知道访问代码才能使用它。大多数移动设备（如 iPhone 和 Android 手机）支持在一段时间不使用后锁定设备（称为自动锁定）。此锁定功能意味着如果设备丢失或被盗，发现或偷窃设备的人将需要知道解锁码才能访问它。你可能还想启用设备支持的任何设备追踪功能，以便在设备丢失或被盗时定位设备。

对于笔记本电脑，请务必在设备上设置 BIOS 开机密码，并更改笔记本电脑的启动顺序，以防止他人在偷走设备后从 CD-ROM 启动并安装他们自己的操作系统。请务必设置 BIOS 管理员密码，以防止他人进入 BIOS 并进行更改，例如更改启动顺序。

如果无法在 BIOS 中设置启动密码，请考虑使用 BitLocker 等工具进行全盘加密。BitLocker 是内置于 Windows 系统中的驱动器加密功能，它不仅加密驱动器内容，还充当启动密码。

## 数据加密

在第 12 章中，你将了解加密知识，但重要的是要注意，保护笔记本电脑或移动设备上机密数据的一个重要步骤是对该数据进行加密，以防设备丢失或被盗。如果数据已加密，那么即使设备丢失或被盗，你也能确保公司数据的安全。同样，可用于加密整个磁盘的技术的一个好例子是 BitLocker。

![Images](img/job.jpg)

**在规划移动设备安全性时，始终假设设备会落入不受信任方的手中。因此，你需要确保在设备上使用自动锁定和数据加密等功能，以维护其数据的机密性。**

## 人为错误

另一个你应该了解的针对系统的重要物理安全威胁是人为错误。例如，一名试图对系统执行升级的员工——可能是增加内存或更换硬盘——可能会通过`静电放电 (ESD)`烧毁系统的主板。ESD 是静电在你身上积累，当你触摸另一个物体（如计算机组件）时转移到该物体上。这种静电转移足以损毁或严重损坏计算机组件。

为防止此类情况发生，应对桌面支持团队进行 ESD 方面的教育，并指导他们使用防静电腕带，以便在维修系统前始终将自己接地。

### 破坏

针对系统的另一个常见威胁是破坏，这通常（但不总是）是由不满的员工造成的。识别公司资产容易遭受破坏的情况非常重要。在我的安全课程中，我太多次听到学员讲述公司数据库被不满员工篡改的事件。

你需要识别易受破坏的系统，并确保为这些系统制定了恢复计划。`恢复计划`包含恢复系统的分步程序，但也确保你在机房货架上备有充足的备件。

## 认证目标 5.03

## 审视恶意软件

现在你已经了解了一些针对系统的常见物理威胁，让我们来看看当今对系统构成威胁的几种恶意软件类型。恶意软件是指任何损害或滥用系统的软件，包括从系统中删除文件、监控系统上的活动，甚至仅仅是降低系统运行速度这样简单的行为。

### 权限提升

权限提升是指黑客发现操作系统或安装在系统上的某个软件中的缺陷，利用该缺陷可将黑客的权限从普通用户权限提升为管理员访问权限。一旦黑客获得了对系统的管理员访问权限，他们就可以对系统进行任何想要的更改，包括为未来的访问植入后门。

权限提升有三种类型：

- **垂直权限提升** 普通用户访问者能够将其权限提升为管理员访问权限
- **水平权限提升** 保持相同的访问级别，但访问的资源不同
- **权限降级** 管理员访问者能够降低其权限级别，以便访问特定用户可访问的数据

### 病毒

安全领域最大的关注点之一是系统被病毒攻陷。病毒是一种感染系统（如计算机、平板电脑或智能手机）的恶意软件。感染可能会破坏系统上的数据、阻止系统启动，或仅仅是占用系统资源，导致系统变慢。本节讨论常见的病毒类型。

#### 可执行文件病毒

早期的病毒是可执行文件病毒，病毒附着在可执行文件上，但在你运行该文件之前不会被激活。这种病毒通常通过用户共享文件（通过软盘、闪存驱动器或网络驱动器）在系统间传播。

#### 引导扇区病毒

引导扇区病毒是一种严重的病毒，它攻击引导扇区代码并将其覆盖。引导扇区是磁盘上的第一个扇区，包含启动引导序列的操作系统加载器代码。当引导扇区病毒覆盖此扇区时，会阻止系统从受感染的磁盘启动。

#### 宏病毒

如今大多数应用程序都支持宏，宏是一种在软件应用程序中实现任务自动化的方式。例如，借助 Microsoft Office 套件，我们能够使用 Visual Basic for Applications (VBA) 创建宏，VBA 是一种功能强大的编程语言，可以操作应用程序和操作系统。

宏病毒是使用宏语言编写的代码，执行删除文件或向通讯录中的所有人发送电子邮件等恶意操作。宏通常在文件中创建，并在有人打开该文件时自动触发。

#### 逻辑炸弹病毒

逻辑炸弹是一种病毒，当你安装包含逻辑炸弹的软件时，它会被植入系统。你安装的软件应用程序会按预期运行，直到发生特定事件（如特定日期）。当你运行该软件时，它总是会检查那个特定日期，如果在该日期运行软件，它就会执行其恶意行为。离职或被解雇的不满员工常用这种方法在特定日期删除数据来破坏公司数据。他们对软件进行编程（正常运行时表现正常），使其在特定日期删除数据。

![Image](img/exam.jpg)

**考试重点：逻辑炸弹病毒会等待特定事件（如特定日期）发生后才被激活。**

#### 蠕虫病毒

蠕虫病毒是当今有害且常见的病毒。蠕虫病毒是一种可怕的病毒类型，因为它具有无需用户激活即可自我复制的独特特征。蠕虫病毒可以通过多种方式自我复制：

- **网络协议** 蠕虫病毒可以通过使用标准网络协议在网络上自动自我复制，并通过利用系统上运行的网络应用程序中的漏洞来攻陷系统。一个很好的例子是 2003 年的 Blaster 蠕虫，它通过 RPC 端口（端口 135）进行复制。谁能忘记 2003 年的 SQL Slammer 蠕虫病毒，它在 10 分钟内感染了互联网上约 75,000 个系统？SQL Slammer 利用 SQL Server 上已知的缓冲区溢出漏洞，通过 UDP 端口 1434 连接到未打补丁的 SQL Server。
- **电子邮件** 蠕虫病毒可以通过电子邮件自动传播。病毒随电子邮件发送给用户，当用户打开邮件时，病毒代码执行并遍历用户的联系人列表，将邮件发送给所有联系人。臭名昭著的电子邮件病毒例子包括 2000 年的 ILOVEYOU 病毒和 2010 年主题为“Here you have”的病毒。
- **闪存驱动器** 新一波蠕虫病毒通过闪存驱动器（U 盘）复制来感染系统。一旦蠕虫病毒进入系统，它会等待有人将闪存驱动器插入该系统，然后蠕虫病毒复制到 U 盘。用户将 U 盘带到另一个系统，一旦驱动器连接到 USB 端口，病毒就会从 U 盘复制到系统。Conficker 就是一种可以通过 USB U 盘复制传播的蠕虫病毒。

#### 特洛伊木马病毒

特洛伊木马病毒是一种用户被欺骗安装的程序，因为它看起来有用，但实际上它是一种感染系统的病毒。特洛伊木马病毒通常通过在系统上打开一个 TCP/IP 端口来修改系统，这允许黑客连接到系统并控制它。

值得注意的是，特洛伊木马病毒的功能不止于在系统上打开端口，而且由于大多数人现在都有防火墙来阻止对特洛伊木马打开的端口的访问，你可能会发现特洛伊木马病毒会在系统上植入广告软件或键盘记录器。

## 木马病毒故障排除

在结束木马病毒话题之前，我想介绍一些常用的 Windows 命令，如果你怀疑自己已被感染，可以使用这些命令来追踪木马病毒。这里的目标是结束打开端口的程序，从而关闭该端口。

用于追踪木马病毒的第一个命令是 `netstat` 命令。如果你使用 `netstat -na` 命令，将会看到处于侦听状态的本地端口列表。*侦听* 意味着端口处于打开状态，正在等待有人连接，这与当时实际已有人连接的情况不同。

要找出是哪个程序打开了端口，可以向 `netstat` 添加 `-o` 开关，这将显示打开该端口的程序的进程 ID (PID) 编号。在图 5-2 中，请注意端口 12345（NetBus 端口）处于侦听状态，而负责打开端口 12345 的 PID 是编号 208。

![Image](img/f0198-01.jpg)

**图 5-2**  

使用 netstat 显示打开端口的程序的进程 ID

一旦你获得了负责打开端口的应用程序的进程 ID 编号，就可以追踪与该进程 ID 关联的 EXE 文件。如果你使用 `tasklist` 命令，将会看到在内存中运行的进程（EXE 文件）以及与每个进程关联的 PID（请参阅图 5-3）。请注意，在下面的输出中，`Patch.exe` 是与该 PID 关联的 EXE 文件，并负责打开该端口！另请注意，你可以使用管道 (`|`) 功能配合 `tasklist` 命令查找特定条目。例如，你可以使用 `tasklist | find "208"` 来在结果中查找包含 "208" 的条目。

![Image](img/f0199-01.jpg)

**图 5-3**  

使用 tasklist 显示在内存中运行的可执行文件

一旦你使用了 `tasklist` 命令并知晓了该进程，便可以使用 `taskkill` 命令终止该进程。通过 `taskkill` 命令，你可以指定要终止的 EXE 文件，或使用 `/PID` 开关通过 PID 进行搜索。图 5-4 中所示的代码使用 `taskkill` 命令通过 PID 编号强制终止进程。

终止进程后，请务必检查系统上通常会自动启动程序的配置区域。这包括“开始”菜单中的“启动”程序组，以及注册表中位于 `HKLM\Software\Microsoft\Windows\CurrentVersion\Run` 的“运行”部分（请参阅图 5-5）。在我们的示例中，如果你运行 `regedit.exe` 并导航到注册表的“运行”部分，将会看到 `Patch.exe` 被设置为在 Windows 重启时自动运行。你需要删除此条目。
