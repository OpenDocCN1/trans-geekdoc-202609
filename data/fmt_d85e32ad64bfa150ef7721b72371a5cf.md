## 5.3.4 模型

### 5.3.4.1 微调方法与设计决策

借鉴 `ASAG` 的经验，我们将误解检测概念化为 `RTE` 问题。在这个框架下，我们将回复映射为假设。`LLMs` 的输入大小受预设 token 数量的限制。对于这项任务，我们使用了 `RoBERTa Large`，其限制为 512。因此，前提和假设的总长度不能超过 509 个 token。由于参考答案长度为 352 个 token，这带来了一个挑战。为了克服这一局限性并确保假设有足够的空间，我们专注于压缩前提中的 token 数量。我们通过手动对问题和参考答案进行总结解决了这一挑战，导致问题占用 62 个 token（43 个单词），参考答案占用 98 个 token（76 个单词），同时保留了核心信息。在总结参考答案时，我们的目标是尽可能简洁地传达功率的变化及其背后的原因。这产生了 160 个 token 的前提，为假设留下了 349 个 token。以下是总结后的问题和参考答案：

*   问题：电阻 `R[1]` 和 `R[2]` 与电压源 `Vs` 串联，电阻 `R[3]` 与 `R[2]` 并联。当 `R[2]` 的电阻减小时，`R[1]`、`R[2]`、`R[3]` 和 `Vs` 的功率会增加、减少还是保持不变？

*   参考答案：随着 `R[2]` 电阻的减小，`R[1]` 的功率将增加，因为 `P = I^2*R` 且电流增大。`Vs` 消耗的功率将增加，因为它通过减少的等效电阻携带了更大的电流。`R[3]` 的功率将减少，因为 `R[2]` 和 `R[3]` 并联组合上的电压降较小。随着 `R[2]` 趋于零电阻，`R[2]` 的功率最终将下降到零，因为它将不再产生电压降。

在回审注释时，我们发现在许多情况下，一个句子只有在前一个句子的语境中才会表现出误解。因此，将前置句包含在输入中至关重要。为了将前置句与分类句隔离开，我们使用换行符将它们连接起来。由于响应中的所有句子都被合并成单个段落并已分成了句子，因此响应中不能包含换行符。因此，我们选择换行符作为假设和假设句中的“粘合剂”，并假设（由于模型的黑箱性质）模型会将其识别为分隔符。对于响应的第一句，我们使用空字符串代替前置句。换句话说，假设句是以换行符开始的。

由于我们输入结构的设计，任何形式的截断都会导致信息丢失。截断前提会危及参考答案。将分类句放在开头会损害来自前置句的上下文和依赖关系。将分类句置于末尾则会损害句子本身。因此，我们禁用了截断。

### 5.3.4.2 超参数和分词器

我们使用 `Adam` 优化器对 `RoBERTa Large MNLI` 进行微调，其中 `ϵ = 1e-8`，学习率为 `1e-5`，权重衰减为 `0.01`，并使用交叉熵损失函数。训练在前 10% 的数据上进行线性预热。微调过程最多持续 20 个 epoch，并带有早停机制。批量大小设为五。在每个 epoch 之后记录模型性能，并根据在验证集上显示最高宏 F1 分数的 epoch 选择最佳模型。

响应包含领域特定词汇，这些词对于模型的分词器来说可能并不熟悉。这些词被分割为分词器可识别的较小子词单元。然而，当无法进行分割时，分词器会将这些词标记为 `unknown`，随后它们会被模型忽略。鉴于领域特定词汇在此任务中携带了大量的权重和语义上下文，将它们纳入分词器的词表和模型的嵌入中是至关重要的。为了实现这一点，我们生成了数据集中所有唯一单词列表。随后，我们将此列表与分词器的词表（区分大小写）进行比较，以识别模型未知的单词。我们识别并向模型词表中添加了以下 27 个单词：

*   `G[x]`（表示电阻 `x` 的电导率）：`G[1]`, `G[2]`, `G[3]`

*   `I[x]`（表示 `Rx` 的电流）：`I[1]`, `I[2]`, `I[3]`

*   `Ieq`（不清楚代表什么，但假设为“等效电流”或“总电流”）

*   `Kirchhoff`

*   `KCL`, `KVL`（基尔霍夫电流/电压定律）

*   `P[x]`（表示与电阻 `x` 相关的功率）：`P[1]`, `P[2]`, `P[3]`

*   `R[x]`（表示电阻 `x` 或相关电阻）：`R[1]`, `R[2]`, `R[3]`

*   `R_eff`（假设表示有效电阻）

*   `R_eq`（假设表示等效电阻）

*   `R_n`（不清楚代表什么）

*   `R_tot`, `R_total`（表示总电阻）

*   `V[x]`（表示与电阻 `x` 相关的电压）：`V[1]`, `V[2]`, `V[3]`

*   `V_out`（表示输出电压）

*   `amperage`, `wattage`

值得注意的是，我们发现许多领域特定词已经存在于模型的词表中。例如 `R`、`V[s]`、`W`、`amps`、`ohms` 和 `current`。`R` 表示电阻，`V[s]` 在电气工程领域指电压源（即电池）。尽管这些术语存在于模型的词表中，但 `R` 和 `V[s]` 等词对模型的具体含义对我们来说是未知的。

随着我们在不断发展的误区检测领域中探索，未来研究还出现了几个其他方向。首先，受限于模型的 token 限制，我们必须最小化测验题目和参考答案的大小，这牺牲了宝贵的信息。探索具有更高 token 限制并在 `RTE` 任务上超越 `RoBERTa` 的大模型（如 `T5`、`PaLM` 和 `Megatron-Turing NLG`）可能是未来研究的一个很有前景的方向。`T5` 拥有 4,096 个 token 的限制，而 `PaLM` 和 `Megatron-Turing NLG` 将限制进一步扩展到 8,000 个，为通过前提丰富上下文提供了绝佳机会。其次，在检测复杂误区时观察到的挑战凸显了对更复杂策略和彻底模型设计的需求。第三，我们对 `RoBERTa Large MNLI` 进行了浅层超参数调优，广泛的超参数调优可能会进一步提高整体性能或特定误区的性能。第四，误区检测默认是一个多标签分类问题，由于缺乏足够的数据尚未进行探索。第五，由于样本量较低，我们从训练数据中排除了三种误区，这可以作为未来研究的一部分。从本质上说，我们的研究为提升学生回答中的误区检测开辟了充满可能的大门。
