```
Ẋ = F(X) + P(X)
```

(3.5)
```
φ̇(X₀) = f(X₀) + z(φ)p(φ)
```

其中：

(3.6)
```
z(φ) = dφ(X₀) / dX₀
```

对于相位分别为 `φ[1]` 和 `φ[2]` 的一对振荡器，使用相同的分析（见 **图 3.2**，假设 `p[12] = p[21]`）：

(3.7)
```
φ̇₁ = f + z₁(φ₁)p₁₂(φ₁, φ₂)
```

(3.8)
```
φ̇₂ = f + z₂(φ₂)p₂₁(φ₂, φ₁)
```

如果进一步假设相位差 `φ[2] − φ[1] = φ` 变化缓慢，则 [[2]](#c03.xhtml#c3-bib-0002)：

(3.9)
```
φ̇₁ = f + Γ₁₂(φ₁ − φ₂)
```

(3.10)
```
φ̇₂ = f + Γ₂₁(φ₂ − φ₁)
```

(3.11)
```
Γᵢⱼ(φ) = 1/(2π) ∫₀²π zᵢ(ψ)pᵢⱼ(ψ, ψ + φ) dψ
```

`Γᵢⱼ(ϕ)` 称为相位相互作用函数 (PIF)。类似地，对于 `N_R` 个区域，第 `i` 个振荡器的相位变化率由下式给出：

(3.12)
```
dϕ_i/dt = f_i + Σ_{j=1}^{N_R} Γ_ij(ϕ_i - ϕ_j - d_ij)
```

其中 `f_i` 是第 `i` 个振荡器的固有频率。在这些公式中有两个关键假设：第一个假设是扰动足够小，以至于微分可以等效地在 `X₀` 处计算，而不是在 `X` 处。第二个假设是振荡器相位的相对变化相对于振荡频率足够缓慢，因此相位偏移项可以用时间平均值代替。

在 [[2]](#c03.xhtml#c3-bib-0002) 中，上述 WCO 模型的一个扩展被用于描述振荡器网络中的动态相位变化。贝叶斯模型比较的使用允许推断大脑同步过程的潜在机制。这已被应用于来自生理模型的合成双手手指运动数据以及视觉工作记忆研究的脑磁图 (MEG) 数据。WCO 方法通过使用描述相位变化如何由瞬时相位的成对差异驱动的微分方程，适应了信号的非平稳性。

### 3.2.3 霍奇金-赫胥黎模型

最早的物理模型很可能是基于霍奇金和赫胥黎于 1952 年发表的、获得诺贝尔奖的乌贼巨轴突数学模型 [8–10]。霍奇金和赫胥黎方程之所以重要，不仅因为它们代表了在定量描述相关生物学现象方面最成功的数学模型，还因为推导乌贼模型可直接适用于多种神经元和其他可兴奋细胞。根据该模型，神经轴突可能受到刺激，并在细胞膜附近产生激活的钠 (Na⁺) 和钾 (K⁺) 通道，从而导致神经轴突的电兴奋。兴奋源于膜电位对离子运动的影响，以及膜电位与电压门控膜通道开闭之间的相互作用。当膜极化、内表面排列净负电荷、外表面排列大小相等但符号相反的净正电荷时，膜电位会增加。该电位可通过以下公式简单地与电荷量 `Q` 联系起来：

(3.13)
```
E = Q / C_m
```

其中 `Q` 以库仑/平方厘米 (Coulombs cm⁻²) 为单位，`C_m` 是膜电容的度量，单位为法拉/平方厘米 (farads cm⁻²)，`E` 的单位为伏特。在实践中，为了对动作电位 (APs) 进行建模，细胞膜内表面的电荷量 `Q⁽⁺⁾`（以及外表面的 `Q⁽⁻⁾`）必须在数学上与流经刺激电极进入细胞的刺激电流 `I_stim` 相关联。图 3.1b 说明了神经元兴奋如何通过充当信号转换器而导致动作电位的产生 [[11]](#c03.xhtml#c3-bib-0011)。

然后使用 公式 (3.13) 计算电位（通常称为电场力）`E`。霍奇金和赫胥黎模型如 **图 3.3** 所示。在该图中，`I_memb` 是正电荷流出细胞的结果。该电流主要由三种电流组成，即钠电流、钾电流和漏电流。漏电流是由于内外侧的钠离子和钾离子并不完全相等所致。

霍奇金和赫胥黎估算钠和钾电流的激活和失活函数，并推导出一个数学模型来描述类似于巨型乌贼的动作电位。该模型是一个使用电压门控通道的神经元模型。霍奇金-赫胥黎模型的空间钳制版本可以用四个常微分方程很好地描述 [[12]](#c03.xhtml#c3-bib-0012)。该模型描述膜电位 (`E`) 随时间的变化，详见 [[13]](#c03.xhtml#c3-bib-0013)。总膜电流是容性电流和离子电流之和，即：

(3.14)
```
I_memb = C_m * dE/dt + I_i
```

其中 `I_i` 是离子电流，如 **图 3.1** 所示，可视为三个单独分量之和：钠电流、钾电流和漏电流：

(3.15)
```
I_i = I_Na + I_K + I_leak
```

`I_Na` 可通过最大电导 `ḡ_Na`、激活变量 `a_Na`，失活变量 `h_Na`，以及驱动力 (`E – E_Na`) 联系起来：

(3.16)
```
I_Na = ḡ_Na * a_Na³ * h_Na * (E - E_Na)
```

类似地，`I_K` 可通过最大电导 `ḡ_K`、激活变量 `a_K`，以及驱动力 (`E – E_K`) 联系起来：

(3.17)
```
I_K = ḡ_K * a_K * (E - E_K)
```

和 `I_leak` 与最大电导 `ḡ_l` 以及驱动力 (`E – E_l`) 有关，公式如下：

(3.18)
```
I_l = ḡ_l (E − E_l)
```
