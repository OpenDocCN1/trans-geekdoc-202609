
# 视觉计算深度学习 实战

## 献词

献给所有帮助人类的深度学习算法

## 前言

深度学习是一种人工智能实体，它通过密集的数据驱动算法，在训练阶段后教会自己进行预测。深度学习通过采用人工神经网络，其功能很像人脑，能够对数据进行分类和分析。深度学习已使视觉计算领域的许多棘手问题得以解决。从目标检测到用于诊断的图像分类，深度学习展示了人工深度神经网络在解决现实世界视觉计算问题方面的强大能力，其准确度甚至超越人类。因此，随着大多数传统图像处理和计算机视觉技术实际上已被深度学习技术取代，深度学习已被证明有潜力解决视觉计算领域许多最具挑战性的问题。

本书深入浅出地介绍了适用于视觉计算领域的深度学习世界。书中对深度学习背后的理论和架构提供了通俗易懂的解释。为了帮助读者更好地掌握深度学习的概念及其在现实生活中的应用，本书还辅以大量现实生活中的案例，范围涵盖从人脸识别到癌症图像分类。本书旨在作为一份激发思考的指南，并为爱好者在视觉计算领域开发和实施自己的人工智能项目提供灵感来源。

## 第 1 章 简介

2017 年 9 月，苹果发布了 iPhone X。随之而来的是 Face ID——苹果基于人脸识别的先进生物识别系统，嵌入在手机的硬件和软件之中。不久之后，我弄到了一部 iPhone X。要使用人脸识别作为身份识别系统——并借此访问各种 App，包括让我登录银行账户的 App——我首先必须录入我的人脸。录入过程涉及遵循一组简单的说明，我需要以特定的姿势和角度将面部呈现在手机摄像头前。在录入人脸几分钟内，我就能开始享受只需看一眼手机即可解锁并使用的便利。

再说另一个故事。几年前，我和当时 4 岁的儿子在当地公园散步。孩子们凭借其娇小的身材、大大的眼睛、圆嘟嘟的脸颊，以及脸上流露出的天真与活力，似乎天生就能吸引大人的注意和喜爱。当我们沿着公园的一条小路漫步时，遇到一位中年妇女，她短暂地停下脚步，冲我儿子说“你好”，并报以一个社交性的微笑。我儿子礼貌地回了招呼。从那以后，我们经常在公园见到她，并互致问候。我儿子大概永远不会忘记她的脸。人类处理最常见的视觉对象是人脸。人大脑拥有处理人脸、识别人脸的惊人能力——往往在第一眼看到某张脸后几十年仍能认出。

在人脑如何区分人脸与基于算法的人脸识别系统（如苹果的 Face ID）如何工作之间，可以找到一个关键的相似之处。对人类而言，识别人脸是一项微不足道的任务。尽管所有人脸都相似——拥有两只眼睛、一个鼻子和一张嘴，且排列方式一致——我们仍能在许多不同的角度和光照条件下识别和辨认人脸，且往往轻而易举。据信，人类通过模板匹配过程进行图像识别，感知到的物体（例如人脸）以一组真正代表特定物体的离散特征形式存储在长时记忆中。当呈现一个新物体时，其特征可以与长时记忆中现有的特征进行比较，以检索最佳匹配。因此，可以确定两个不同的过程：第一个是学习过程，大脑通过特征教会自己认识特定物体。例如，在我儿子在公园的故事中，他的大脑学习了他在公园遇到的那位女士的面部。然后，在第二个过程中，输入的人脸与存储的人脸模板进行比较，以找到精确匹配。

有趣的是，Apple 的 Face ID 识别和区分面部的方式，与我们人类在大脑中识别和辨认面部的方式非常相似。在注册阶段，Face ID 从不同位置和角度读取面部，并最终将面部的物理特征转换为数学表征——通常每张面部对应几百个浮点数。在识别过程中，手机上的红外传感器读取面部，计算与该面部对应的数学表征，并与存储的模板面部进行“距离维度”的比较。同样可以看出，就像大脑一样，面部匹配系统首先学习面部特征，然后将其与模板面部进行比对，以查看是否存在匹配，从而验证给定的准确性阈值。

无论是在计算机世界还是在人类大脑中，物体识别背后的基本思想都是信息压缩，或是从数据中自动形成有用的表征。从根本上说，我们可以将这种表征学习的过程称为深度学习。一个很好的例子是我们表示原子结构的常用方式，如图 1.1 所示。虽然原子包含围绕由质子和中子组成的原子核运动的电子，但其结构绝不像图 1.1 所示那样具有确定的形态。事实上，电子在任意给定时刻的位置从来不是可预测的，我们只能获得其围绕原子核位置的概率估计。然而，如图 1.1 所示呈现原子结构，有助于我们形成关于原子、分子和宏观物质的一份表征学习认知。

从宏观层面来看，深度神经网络由编码器和解码器组成。编码器的功能是在数据中寻找有用的模式，并形成一种表征学习的形式。同样，解码器的功能是从表征中生成高分辨率数据，其中生成的数据是新的样本或表达性知识。从根本上说，这就是深度学习的工作原理。

随着强大计算工具和传感器数据的近期爆发式增长，深度学习已成为机器学习的核心工具。深度学习已在广泛的领域和多样的场景中得到应用。虚拟助手（如 Siri 和 Alexa）、生物特征面部识别、聊天机器人、图像分析工具和计算机辅助诊断系统，均由深度学习辅助的模型和算法积极驱动。事实上，得益于深度学习算法的爆发式发展和预训练深度学习模型的可用性，整个人工智能领域最近已占据了中心舞台。此外，视觉计算领域的许多问题正通过深度学习方法和工具得到解决。从基础的图像分析任务到复杂的疾病诊断实践，深度学习在几乎所有与视觉计算相关的问题中都扮演了核心角色。因此，有必要编写一本专门阐述视觉计算领域深度学习积累知识与最新发展的书籍。

本书概述了应用于视觉计算领域问题的深度学习方法与技术。本书的第一部分致力于阐释深度学习——从基本概念到构建深度学习模型的机制。本书涵盖了足够的深度学习理论，以便读者掌握深度学习的基本要素。为了补充深度学习的理论与知识，本书还涵盖了若干实际案例，演示如何在视觉计算领域成功应用深度学习。

## 第 2 章 深度学习的基础

本章提供了关于深度学习的简要入门材料。我们提供了理解深度学习所必须牢记的基本概念和技术，视角是尝试解决视觉计算中的问题。

### 简介

人工智能（AI）被定义为一种使机器或算法能够模仿人类行为的技术。人工智能的大部分引擎由机器学习（ML）的方法和技术驱动，深度学习是其中的一部分。深度学习使计算模型能够通过一种模仿人类大脑感知和理解多模态信息的方式来学习和表征数据。尽管深度学习直到最近才变得非常流行，但它的历史相当悠久。

深度学习是一种机器算法通过示例进行学习的机制。它是一种获得模型最优配置的机制，从而能从一组输入数据中获得期望的输出。从数学角度来看，可以将此过程视为获得期望函数 `g(y[1], y[2],..., y[n])` 以映射输入函数 `f(x[1], x[2],..., x[m])`。存在多种获取此类关系的方法——从线性近似到利用复杂的非线性形式。通常，与物理定律或现象相关的变量之间的显式数学关系可以被构建出来。例如，如果我们采用著名的牛顿第二运动定律，该定律指出施加在质量为 `m` 的物体上的力 `F` 是 `m` 与加速度的乘积，而加速度是物体速度变化的速率。这可以简单地表述为线性关系 `F = ma`。因此，给定 `m` 和 `a` 的输入值，人们可以轻松预测必须施加的力。同样，如果我们采用爱因斯坦著名的方程 `E = mc²`，我们可以看到物质 `m` 的能量与光速 `c` 之间存在非线性关系。

对于选定的一组物理现象，以及更直接的现实生活情境，可以推断出变量间的此类相关性，并可将其显式地以线性或非线性形式写出。然而，现实世界的许多问题过于复杂或过于动态，无法找到相关变量之间此类显式的关系。

考虑系统输入与输出之间的关系，如图 2.1 所示。图 2.1(a)中所示的输入输出关系显然是线性的，可以使用形式为 `F(x) = ax + b` 的函数进行建模，其中 `a` 和 `b` 是模型空间中的特征值（或参数）。在某种意义上，具有特定值 `a` 和 `b` 的函数 `F(x)` 能够紧密拟合图 2.1(a)中的数据集，这就是一个学习好的模型。如果模型的输入输出模式现在发生变化，如图 2.1(b)所示，线性模型将不再有效。然而，我们可以求助于形式为 `F(x) = ax³ + bx² + cx + d` 或 `F(x) = Ce^(Ax)` 的模型（其中 `a`、`b`、`c`、`d`、`C` 和 `A` 是相应非线性模型的参数），这将更适合对图 2.1(b)所示的数据进行建模。

尽管线性和非线性模型适合对简单数据集进行建模，但对于实际应用，这种函数式建模很难获得。例如，对于像在图像中识别苹果这样的视觉计算任务，寻找能够映射苹果图像的像素线性组合是不可能的。即使使用简单的非线性函数组合，这样的任务也可能令人望而生畏，因为可能需要处理数量巨大且经常相互冲突的参数。因此，必须寻找一种通用方法，通过该方法可以对适用于实际应用的复杂和多维数据集进行建模。这是机器学习，特别是深度学习技术，能够帮助我们的一个领域。此类模型可以接收足够大的数据作为输入并对其进行处理，利用高层信息或知识提取数据中的一般模式。它们旨在模仿人类推断物体以及从物体中提取知识的方式。因此，教会机器了解世界的一个合理途径是模仿人脑——特别是神经元如何利用数据进行学习和推断。

### 感知机

第一个受大脑神经元启发的机器学习计算模型，由 Warren McColloch 和 Walter Pitts 提出，他们二人在 1940 年代从事计算神经科学领域的工作。他们想了解人脑如何利用相互连接的神经元产生复杂的模式。他们试图将其作为提出的感知机模型的基础，该模型最初由 Rosenblatt 于 1958 年提出，当时他在康奈尔航空实验室工作。

McColloch 和 Pitts 的感知机是一个基于生物神经元工作原理的数学模型。神经元是大脑中相互连接的神经细胞，统称为神经网络。它们通过电信号和化学信号处理和传递信息。当细胞膜两侧的离子浓度发生变化而产生动作电位时，生物神经元就会受到刺激。通常，细胞外空间钠离子浓度较高，而细胞内空间钾离子浓度较高。在动作电位期间，离子在神经元膜上来回传输，引起电变化，从而传递神经冲动。

与人类神经元的功能类似，感知机神经模型接收一系列输入信号 `x[1]`、`x[2]`、`x[3]`，这些信号要么是兴奋性的，要么是抑制性的。信号可以通过 `w[1]`、`w[2]`、`w[3]` 进行加权，以便根据需要调整其影响。最后，计算加权和。如果输入信号的加权和达到选定的阈值，模型输出 1，否则输出 0。因此，模型通过执行加权和，基于输入信号（即 `x[1]`、`x[2]`、`x[3]`）做出输出决策，进而生成二进制输出（即 0 或 1），如图 2.2 所示。

感知机是一种分类技术，可广泛用于视觉计算应用，例如计算机视觉和图像识别。假设我们有一张图片，希望算法告诉我们这张图片是不是苹果，可以使用分类来实现。输入可以是图像的像素，感知机的权重可以通过苹果数据集得出，输出将是一个二元分类，告诉我们输入图像是否为苹果。然而，就像函数一样，单个神经元非常有限，许多现实世界的问题无法用二元分类器解决。因此，感知机的思想可以扩展到人工神经网络（ANN），其中多个神经元可以连接在一起。

### 人工神经网络

本质上，ANN 是由单个感知机组成的集合，形成一个神经元网络，连接在一起以实现网络各部分的并行信号处理。感知机单元之间包含权重，以控制彼此的影响。图 2.3 展示了 ANN 的基本结构布局。ANN 的一个关键组件是位于网络输入和输出之间的隐藏层。隐藏层有助于为输入分配非线性权重并将其导向输出，即它们有助于将非线性数学函数应用于网络的特定部分以产生期望的最终输出。这些函数通常被称为激活函数。例如，在人脸检测任务中，一个隐藏层可以调整为识别输入图像中的眼睛，另一个可以调整为识别鼻子，依此类推。整个网络随后可以识别输入图像中人脸的存在。

![Figure 2.3: Representation of a multilayer neural network with a hidden layer.](img/fig2_3_B.jpg)

**图 2.3：** 具有隐藏层的多层神经网络示意图。

具体而言，在基于多层感知机概念的 ANN 中，每个神经元都连接到前一层和后一层的神经元。输入层和输出层之间的连接由若干隐藏层定义，这些隐藏层由激活函数连接。激活函数 `A` 通常采用以下形式：

```
A = F(∑_{i=1}^{n} w_i x_i + b), (2.1)
```

其中，`w[i]` 是分配给神经元 `i` 的权重，`b` 是偏置值，`n` 是神经元的数量。输入数据定义输入层中神经元的数量。在激活函数的帮助下，隐藏层执行多次特征提取以进行分类。最后，所有隐藏层提供一个特征集作为输出。输出层神经元的数量等同于输入数据可被划分的类别数量。输出的准确性，即输入属于给定类别的概率，通过损失函数（也称为 Softmax）来衡量。

### 神经网络激活函数与偏置

激活函数本身可以采取特定形式，尽管这在很大程度上不应过于重要。人工神经网络（ANN）中常用的激活函数形式包括：

*   线性函数：`F(x) = ax`
*   修正线性单元：`F(x) = max(0, x)`
*   双曲正切：`F(x) = tan(x)`
*   Logistic 函数：`F(x) = 1 / (1 + e^x)`
*   反正切：`F(x) = 1 / (1 + tan(x))`

同样，在网络中，每个神经元都会添加一个偏置，通常是一个二进制值。偏置单元是奇异的，因为它们不连接到前一层。偏置函数使激活函数能够沿给定方向（例如右、左、上、下）激活。在模型中引入偏置增加了其灵活性，确保模型能按预期进行训练。

### 反向传播与损失函数

一旦神经网络构建完成（包含初始权重），误差函数会告诉我们模型距离所需的期望预测有多远。为了高效获取网络权重的最优值，可以执行**反向传播**。反向传播算法包含几个阶段：

1.  使用初始权重排列，模型生成初始预测。
2.  计算误差函数。
3.  算法计算误差相对于各个权重的变化率，以便迭代地进行误差最小化。

这些在反向传播算法中回溯权重并更新它们的迭代或优化运行，通常被称为**轮次**。

因此，神经网络接收输入数据并将输入通过网络传递到输出。网络必须通过损失函数 `S` 评估其表现，例如均方误差：

```
S = 1/n * Σ(i=1 to n) (Y_i¹ - Y_i²)²  (2.2)
```

此处，`Y_i¹` 代表期望输出，`Y_i²` 代表网络的预测结果。通过使用反向传播的一系列迭代，网络调整其权重和偏置以确保损失函数最小化。因此，从输入开始，通过一系列权重和偏置的调整，网络产生期望输出。简而言之，ANN 是一个建模给定输入与期望输出之间关系的优化系统。

### 超参数调优

为解决给定任务而设计 ANN 通常不是一个简单直接的过程。它需要仔细的思考和实验。输入的选择、隐藏层的数量、激活函数的选择、Softmax 的性质、优化算法的选择以及训练网络的轮次数，所有这些都需要慎重考虑。这个过程被称为**超参数调优**。

### 多层感知机的局限性

多层感知机模型在为预测建模提供良好近似方面表现出色。值得注意的是，这些模型的本质意味着各层是全连接的，即每个感知器都连接到其他每个感知器。因此，对于视觉计算相关问题（需求主要涉及像素域中的图像），参数数量会呈指数级快速增长。此外，这类模型不能有效编码空间信息，这往往使它们难以用于解决常见的视觉计算问题。为克服这些问题，研究人员提出了更复杂的模型。因此，流行的**卷积神经网络（CNN）**模型成为视觉计算领域的当前宠儿。

#### 卷积神经网络

CNN 是一种三维网络结构，其中一层的神经元并不总是连接到下一层的神经元。每层中的神经元负责分析数据较小部分的特定功能。因此，CNN 首先执行**卷积**，涉及扫描输入数据的一个小部分以创建特定映射。第二步涉及**池化**，旨在降低特征的维度。在图像的情况下，卷积操作扫描图像并分析图像的小部分以生成特征集。池化操作随后在保留关键信息的同时将此特征集减少到可管理的数量。

因此，CNN 可以解释为层的组合，每层负责不同的任务，如卷积或池化。此类网络通过允许图像作为输入通过，然后经过包含卷积、池化和其他全连接层的一组层，最终提供单个类别的输出，该类别属于图像可能的类别集合，如图 2.4 所示。

最初引入 CNN 时，它们与普通神经网络有相似之处，主要包含持有可学习权重和偏置的神经元。每个神经元通常接收多个输入，执行点积，最后可选择跟随一个非线性函数。与普通人工神经网络一样，CNN 也在最后一层拥有损失函数（如 Softmax）。此外，用于学习普通神经网络的方法仍适用于 CNN。

近年来，CNN 的发展随着每年的推移不断提升整体能力，提出了更复杂、计算需求更高的网络模型。最近，ImageNet 挑战赛的顶尖模型是 **Inception-v4** 模型架构，它通过使用 75 个可训练层，在 ImageNet 挑战赛上实现了 3.08% 的顶部错误率，超越了之前在图像分类中称霸的 ResNet 和 GoogLeNet。然而，最新最先进模型的缺点之一是训练运行时间不断增加。
