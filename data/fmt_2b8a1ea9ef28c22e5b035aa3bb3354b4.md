
最后，我们应用 $S_2$ 的逆，使得 $z = S_2^{-1}(y)$，它给出了文档 $d$ 的签名 $T'$，即 $T' \in k^m$。

- **Verification**：为了证明签名 $d$ 的真实性，我们必须检查 $F'(x_1, x_2, \dots, x_n) = T''$。

如果需要对大尺寸文档进行签名，则必须应用哈希函数并计算哈希值以验证其真实性。Rainbow 签名方案由于在有限域上进行简单的矩阵运算（乘法和求逆）而提供简单性。由于密钥和签名大小小，因此比 OV 更有效。尽管存在多种攻击，Rainbow-Separation 攻击（Fraenkel and Yesha, 1979）和 MinRank 攻击（Kipnis and Shamir, 1999）可找到线性映射以将多项式变为二次映射。

### 9.5.3 Quartz 签名方案 (2, 129, 103, 3, 4)

Quartz 签名方案由 Patarin 等人于 2001 年提出。它基于 HFE 陷门函数。它旨在生成非常短的签名，即仅 128 位。它是为特定应用设计的。然而，已经存在经典算法（RSA、ECC、DSA 等）可以生成长度大于 320 位的签名。私钥和公钥是具有以下参数的 HFE 映射：$(F, d, n, a, v) = GF(2), 129, 103, 3, 4$；$F$ 为有限域，$d$ 表示多项式的次数，$n$ 为扩展域的大小，$a$ 表示移除的方程数，$v$ 表示醋变量数。

在 Quartz 算法中，我们将使用公钥 $(Pu_t)$ 将 $F^{107}$ 到 $F^{100}$ 的二次方程映射并给出输入 $n-a=100$ 位。首先，我们必须为消息 $m_0 = SHA\text{-}1(m), SHA\text{-}1(m_0) 0x00, SHA\text{-}1(m_0) 0x01, SHA\text{-}1(m_0 || 0x02)$ 计算四个签名，SHA 代表安全哈希算法。然后，将它们全部组合成一个 128 位长的签名。在其验证过程中，我们必须四次应用公钥 ($Pu_s$)。通常存在两种已知攻击：Kipnis 和 Shamir（1999）提出的 MinRank 和直接代数攻击。它尚未在实践中使用以产生缓慢的签名。

## 9.6.2 Winternitz 一次签名方案 (W-OTS)

在引入 LD-OTS 之后，Merkle 曾提到 Winternitz 向他建议了这种方法并命名为 Winternitz 一次签名方案。其核心思想是使用一个字符串 $(S_0)$ 同时签名消息摘要中的各个位。它使用了与 LD-OTS 相同的单向函数和加密函数，并高效地生成更短的签名。原始 W-OTS 的构造如下：

- **密钥生成**：设置同时签署的位数 $w \ge 2$。然后计算：

```
$t_1 = \left\lceil \frac{n}{w} \right\rceil, t_2 = \left\lceil \frac{\log_2 t_1 + w}{w} \right\rceil, t = t_1 + t_2 \quad (9.19)$
```

签名密钥 $(S_i)$ 的选取使得：

```
$S_i(x) = (x_{i-1}, \dots, x_1, x_0) \in [0,1]^{n} \quad (9.20)$
```

验证密钥 $(V_i)$ 通过对 $S_i$ 中的每个位应用单向函数 $f : [0,1]^w \to \{0,1\}^w$ 的 $2^w-1$ 次得到：

```
$V_k(y) = (y_{k-1}, \dots, y_1, y_0) \in [0,1]^{n} \quad (9.21)$
```

$y_i = f^{2^w-1}(x_i)$ 对于 $0 \le i \le t-1$。

- **签名生成**：构造待签名的消息摘要 $g(D)=M=(m_{n-1}, \dots, m_0)$。为了用消息摘要 $d$ 除以 $w$，在它前面补最少数量的零。字符串 $d$ 被分成 $t-1$ 个位，使得 $d=a_{t-1} \| \dots \| a_0$，其中 $\|$ 表示字符串的拼接，$a_i$ 是属于 $(0,1,2^w-1)$ 的整数。接下来，计算校验和：

```
$c = \sum_{i=0}^{t-1} (2^w - a_i) \quad (9.22)$
```

然后，为了将二进制表示法除以 $w$，我们在前面补最少数量的 0，且字符串被分成 $t_2$ 组，使得：

```
$c = a_{t_2-1} \| \dots \| a_0 \quad (9.23)$
```

最后，计算出签名为：

```
$\sigma = \{f^{a_{t-1}}(x_{t-1}), \dots, f^{a_1}(x_1), f^{a_0}(x_0)\} \quad (9.24)$
```

- **验证**：为了验证上述签名，计算位字符串 $a_{t-1}, ..., a_1, a_0$ 并检查等性，如下：

```
$$(f^{2^w-a_{t-1}}(\sigma_{t-1}), ..., f^{2^w-a_0}(\sigma_0)) = (y_{t-1}, ..., y_0) \quad (9.25)$$
```

如果计算出的签名逻辑上是正确的，则满足以下等式：

```
$$(f^{2^w-a_i}(\sigma_i)) = f^{2^w}(x_i) = y_i \quad (9.26)$$
```
