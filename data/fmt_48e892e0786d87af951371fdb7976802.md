# 网络包嗅探

在第 10 章中，我们简要提及了地址解析协议（ARP）欺骗的概念。如果我们访问交换机，就可以进行 ARP 欺骗；但这次我们将使用一个为中间人（MITM）攻击设计的程序。图 12.11 显示了网络拓扑图。ARP 欺骗攻击将覆盖受害者的 ARP 表，使受害者的流量通过 BackTrack 系统，无论目的地何。

我们最感兴趣的菜单部分是“嗅探和攻击选项”。由于我们的 BackTrack 服务器只有一个以太网连接，我们无法进行桥接攻击。我们也想捕获通过系统的流量，因此在示例中不选择`-o`选项。我们可以通过`-t`选项限制 ettercap 只嗅探特定端口的流量，例如 80 端口的 Web 流量。然而，没有必要限制自己——我们不妨捕获所有流量，以期望获得敏感数据。

首先，我们希望为攻击选择`-M`选项。然而，帮助信息并没有让我们了解还有哪些额外的选项可用。以下文本节选自`ettercap`手册页（man page）的片段：

`-M, --mitm <METHOD:ARGS>`

MITM 攻击：此选项将激活 MITM 攻击。MITM 攻击完全独立于嗅探。攻击的目标是劫持数据包并将其重定向到 ettercap。必要时，嗅探引擎将转发它们。你可以选择你喜欢的 MITM 攻击，并结合其中某些攻击以同时执行不同的攻击。如果 MITM 方法需要某些参数，你可以在冒号后指定它们（例如，`-M dhcp:ip_pool,netmask,etc`）。

以下可用的 MITM 攻击有：

`arp ([remote],[oneway])`

该方法实现了 ARP 毒化 MITM 攻击。ARP 请求/响应被发送给受害者以毒化它们的 ARP 缓存。一旦缓存被毒化，受害者会将所有数据包发送给攻击者，攻击者反过来可以修改并将其转发到真实目的地。在静默模式（`-z`选项）下，仅选择第一个目标；如果你想在静默模式下毒化多个目标，请使用`-j`选项从文件中加载列表。你可以选择空目标，它们将被展开为“ANY”（局域网中的所有主机）。目标列表将与主机列表（通过 arp 扫描创建）合并，结果将用于确定攻击的受害者。

参数`remote`是可选的，如果你想嗅探针对网关的远程 IP 地址毒化攻击，则必须指定它。事实上，如果你在`TARGETS`中指定了受害者和网关（GW），ettercap 将仅嗅探它们之间的连接，但为了让 ettercap 嗅探通过网关的连接，你必须使用此参数。`oneway`参数将强制 ettercap 仅从`TARGET1`向`TARGET2`进行毒化。如果你只想毒化客户端而不是路由器（路由器可能部署了 ARP 监视），则此项非常有用。

示例：目标为`/10.0.0.1-5/` `/10.0.0.15-20/`，主机列表为`10.0.0.1 10.0.0.3 10.0.0.16 10.0.0.18`；如果目标相互重叠，受害者之间的关联将是`1`和`16`、`1`和`18`、`3`和`16`、`3`和`18`；相同 IP 地址的关联将被跳过。

注意：如果你成功毒化了一个客户端，必须在内核中设置正确的路由表并指定网关。如果你的路由表不正确，被毒化的客户端将无法访问互联网。

基于 MITM 攻击选项的手册页信息，我们可以选择远程或单向的 ARP 毒化方法。`remote`选项允许我们嗅探通过网关离开局域网的流量。`oneway`选项在网络内部提供了更多的控制；选择单向选项将限制源自第一个目标的 ARP 毒化，对我们来说就是受害者系统（`192.168.1.100`）。如果部署了 ARP 篡改检测控制，网关路由器的 ARP 欺骗可能会被检测并发送报警。

提示：`Ettercap`也可以用于嗅探通过加密通道发送的流量，包括安全壳（`SSH`）和安全套接层（`SSL`）协议。尽管我们拦截了用户名和密码，受害者并不会察觉到任何异常。如果登录正确，数据将继续在受害者系统与`pWnOS`服务器之间不受阻地传输。只要我们的`MITM`攻击运行，我们就会持续拦截流量。捕获网络数据还有许多其他方法；在专业渗透测试中，用于获取登录凭据的利用方法包括如下：

- **域名系统（DNS）缓存毒**：允许攻击者将受害者的数据请求替换为恶意数据。使用`DNS`缓存中毒的攻击示例是网络钓鱼（pharming）。

- **DNS 伪造**：这种技术是一种时序攻击，其即在有效的`DNS`查询响应返回之前，向系统返回一个虚假的`DNS`查询响应。使用`DNS`伪造的攻击示例也包括网络钓鱼。

- **用户界面（UI）视觉欺骗**：允许恶意用户使用`JavaScript`等 Web 脚本语言，将网站上的有效链接替换为恶意链接。点击劫持（Clickjacking）是 UI 欺骗的另一个术语。

- **边界网关协议（BGP）劫持**：这种攻击通过利用`BGP`广播通信并注入无效路由数据来获取 IP 地址。`IP`劫持这种攻击的另一种说法，用于垃圾邮件或分布式拒绝服务（`DDoS`）攻击。

- **端口窃取**：一种二层攻击，通过伪造受害者的媒体访问控制（`MAC`）地址将交换机端口流量重定向到攻击系统，从而覆盖网络中的`ARP`表。这允许攻击系统拦截任何旨在受害者的返回通信。这可以用于`DoS`攻击或用于拦截流量。

- **动态主机配置协议（DHCP）欺骗**：对`DHCP`服务器的攻击，使用伪造的`DHCP`消息获取 IP 地址。它通过伪造受害者的`DHCP`租约通信将合法系统踢出网络。`DHCP`欺骗对于实施`DoS`攻击很有用。

- **互联网控制消息协议（ICMP）重定向**：这种攻击向受害者系统发送`ICMP`重定向，通知系统存在更短的网络路径。这种攻击允许攻击系统作为`MITM`攻击拦截并转发流量。

- **MITM（中间人攻击）**：一种通过中继数据拦截两个系统之间流量的方法，数据可以是明文或加密的。在网络中拦截或被动收集数据的能力为专业渗透测试人员提供了一种获取登录凭据或其他敏感数据的手段，这些数据可用于以高权限访问目标系统。

### 社会工程

根据 ISSAF 的标准，社会工程可以分解为以下攻击（`Open Information Systems Security Group, 2006`）：

- **窥窥**（Shoulder surfing）：观察授权用户访问系统，并在其将凭据输入系统时获取这些凭据。

- **工作站的物理访问**：允许物理访问系统为渗透测试人员提供了安装恶意代码（包括后门访问）的机会。

- **伪装成用户**：假装成用户联系帮助台，请求访问信息或高权限。

- **伪装成监控人员**：假装成审计员或安全人员请求访问系统。

- **翻找垃圾桶**（Dumpster diving）：在垃圾容器中搜寻包含敏感信息的计算机打印件。

- **处理（发现）敏感信息**：寻找落在办公桌或桌子上未妥善保护的敏感文档。

- **密码存储**：寻找存储在电脑附近的手写密码。

- **反向社会工程学**：假装成处于权力位置的人（如帮助台员工），在帮助受害者解决问题的同时，从受害者处获取敏感信息。
