```python
function partition(arr, pivot):
    smaller_subarray = []
    larger_subarray = []
    for x in arr:
        if x < pivot:
            append x to smaller_subarray
        else if x > pivot:
            append x to larger_subarray
    return smaller_subarray, larger_subarray
```

#### 20.3.2.4 算法：插入排序

输入：一个无序数组 `arr`。

输出：按升序排列的数组 `arr`。

```python
function insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j = j - 1
        arr[j + 1] = key
    return arr
```

#### 20.3.2.5 算法：合并

输入：三个已排序的数组——`arr1`, `arr2` 和 `arr3`。

输出：包含 `arr1`, `arr2` 和 `arr3` 中所有元素的合并数组。

```python
function merge(arr1, arr2, arr3):
    merged_arr = []
    i = j = k = 0
    while i < len(arr1) and j < len(arr2) and k < len(arr3):
        if arr1[i] <= arr2[j] and arr1[i] <= arr3[k]:
            append arr1[i] to merged_arr
            i = i + 1
        else if arr2[j] <= arr1[i] and arr2[j] <= arr3[k]:
            append arr2[j] to merged_arr
            j = j + 1
        else:
            append arr3[k] to merged_arr
            k = k + 1
    while i < len(arr1):
        append arr1[i] to merged_arr
        i = i + 1
    while j < len(arr2):
        append arr2[j] to merged_arr
        j = j + 1
    while k < len(arr3):
        append arr3[k] to merged_arr
        k = k + 1
    return merged_arr
```

```
T(n) = \Theta(n log n) (20.2)
```

因此，融合排序的时间复杂度为 `$\Theta(n log n)$`，这使得对于中等规模的数据集，它比快速排序和归并排序等传统算法更高效。对于较小的子数组（规模 `<=` 阈值），由于使用了插入排序，其时间复杂度为 `O(k^2)`，其中 `k` 是子数组的大小。融合排序的这种自适应特性使其在处理不同规模和特征的数据集时表现卓越。
