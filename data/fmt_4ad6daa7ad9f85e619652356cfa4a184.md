## 13.9 运行代码

在运行代码之前，我们需要对`php.ini`进行一些更改。按照第 2.1 节的说明找到`php.ini`并在 Brackets 中打开它。滚动到页面底部并添加以下行（如果你在之前的章节中尚未执行）：

```ini
error_reporting=E_ALL

display_errors=On

date.timezone=America/New_York
```

接下来，我们想在`php.ini`中再添加一行。具体来说，我们想添加一行来预置`debugging.php`。预置文件意味着指定让 PHP 在处理任何其他 PHP 脚本之前处理此文件。之前，我们在`UI_include.php`中使用`include`语句将`debugging.php`添加到 PHP 脚本中。这对于大多数错误都有效。但如果包含`debugging.php`的文件存在语法错误，它将不起。如果你希望即使存在语法错误`debugging.php`也能工作，你就需要预置该文件。这样做，在`php.ini`中添加行`auto_prepend_file="DOCUMENT_ROOT>/phpproject/includes/debugging.php"`，其中`<DOCUMENT_ROOT>`指你 htdocs 文件夹的实际路径。要找到此路径，在浏览器中加载`http://localhost/dashboard/phpinfo.php`并搜索“DOCUMENT_ROOT”（不带引号）。你会看到旁边列出的路径。你需要将`<DOCUMENT_ROOT>`替换为列出的路径。例如，如果路径是`/opt/lampp/htdocs`，该行应该是`auto_prepend_file="/opt/lampp/htdocs/phpproject/includes/debugging.php"`。由于书籍宽度限制，上面的代码在书中可能显示为两行。不要将其分成两行，它应该在`php.ini`中写为单行。

在预置`debugging.php`后，如果你使用的是 PHP 7.2 及以上版本，还应该关闭`track_errors`。`track_errors`是 PHP 的内置功能，自 PHP 7.2 起已弃用。然而，该功能默认设置为“开启”。在某些服务器上，开启可能会导致“Directive ‘track_errors’ is deprecated found on line 0 in file Unknown”的警告。要关闭它，只需在`php.ini`底部添加`track_errors=Off`即可。你现在可以保存文件并重启 Apache。

接下来，进入`UI_include.php`并注释掉`debugging.php`的`include`语句。由于我们已经预置了该文件，不应再次包含它。然后，在浏览器中启动`http://localhost/phpproject/signup.php`并注册两个新账户。
