
#### 卡尔曼滤波算法总结

其中 $\hat{\theta}_{n|n-1}$ 是在 $\hat{\theta}_{n-1} = E[\theta_{n-1} | x_{n-1}, \dots, x_1]$ 条件下对 $\theta[n]$ 的预测，后者是 $n-1$ 时刻的最优 MS 估计。如果高斯假设成立，这种估计器是最佳序贯估计器；如果不考虑分布，它是最佳线性估计器。基于卡尔曼滤波用于 ERP 信号跟踪的整体算法可总结如下：

#### 方程组 (9.36)–(9.42)

(9.36)
```
C_{\hat{\theta}_0} = C_{\theta_0}
```

(9.37)
```
\hat{\theta}_0 = E[\theta_0]
```

(9.38)
```
\hat{\theta}_{n|n-1} = F_{n-1} \hat{\theta}_{n-1}
```

(9.39)
```
C_{\hat{\theta}_{n|n-1}} = F_{n-1} C_{\hat{\theta}_{n-1}} F_{n-1}^T + G_{n-1} C_{w_{n-1}} G_{n-1}^T
```

(9.40)
```
K_n = C_{\hat{\theta}_{n|n-1}} H_n^T (H_n C_{\hat{\theta}_{n|n-1}} H_n^T + C_{v_n})^{-1}
```

(9.41)
```
C_{\hat{\theta}_n} = (I - K_n H_n) C_{\hat{\theta}_{n|n-1}}
```

(9.42)
```
\hat{\theta}_n = \hat{\theta}_{n|n-1} + K_n (x_n - H_n \hat{\theta}_{n|n-1})
```
