
换句话说，熵可以被视为随机发射符号的信源随机性的度量。最大值对应于将要发射内容的最大不确定性，因为当所有符号等概率时出现最大值。熵的最小值等于零，这对应于除一个事件发生概率等于一之外，所有事件发生概率均为零的情况。

#### 2.5.1 二元随机变量

二元随机变量的熵由下式给出：

```
H(x) = -p log₂ p - (1 - p) log₂ (1 - p)
```

#### 2.5.2 连续随机变量

之前给出的所有定义都可以推广到连续随机变量的情况。然而，这种推广必须谨慎进行。回顾一下，在实轴区间上取值的随机变量取任意单一值的概率为零。因此，相应的信息量是无限的。

为了定义连续变量 `x` 的熵，我们首先对其进行*离散化*，并形成相应的离散变量 `x_Δ`，即：

```
x_Δ := nΔ,  if  (n - 1)Δ < x ≤ nΔ
```

![Equation](img/si410.png) (2.153)

其中 `Δ > 0`。

然后，

```
P(x_Δ = nΔ) = P(nΔ - Δ < x ≤ nΔ) = ∫_{(n - 1)Δ}^{nΔ} p(x) dx = Δ p̄(nΔ)
```

![Equation](img/si412.png) (2.154)

其中 `p̄(nΔ)` 是 `p(x)` 在 `x ∈ (nΔ - Δ, nΔ]` 区间上的最大值和最小值之间的一个数（根据微积分中值定理，这样的数是存在的）。然后我们可以写成

##### 连续随机变量的熵

$H(x_{\Delta}) = - \sum\limits_{n = - \infty}^{+ \infty}\Delta\overline{p}(n\Delta)\log\left( \Delta\overline{p}(n\Delta) \right),$

![Equation](img/si415.png) (2.155)

并且由于

$\sum\limits_{n = - \infty}^{+ \infty}\Delta\overline{p}(n\Delta) = \int_{- \infty}^{+ \infty}p(x)\ dx = 1,$

![Equation](img/si416.png)

我们得到

$H(x_{\Delta}) = - \log\Delta - \sum\limits_{n = - \infty}^{+ \infty}\Delta\overline{p}(n\Delta)\log\left( \overline{p}(n\Delta) \right).$

![Equation](img/si417.png) (2.156)

请注意，当 $\Delta \to 0$ 时，$x[\Delta] \to x$。然而，如果我们在公式 (2.156) 中取极限，则 $-\log\Delta$ 趋向于无穷大。这是与离散变量相比的关键区别。

连续随机变量 $x$ 的熵定义为极限

$H(x): = \lim\limits_{\Delta\rightarrow 0}\left( H(x_{\Delta}) + \log\Delta \right),$

![Equation](img/si421.png)

或者

![Equation](img/fx036.jpg) (2.157)

这就是连续变量的熵也被称为*微分熵*的原因。

请注意，熵仍然是描述 $x$ 的分布的随机性（不确定性）的度量。这通过以下示例得到证明。

### 示例 2.8

给定一个随机变量 $x \in [a, b]$。在所有能描述该变量的可能概率密度函数（PDF）中，找到使熵最大化的那个。

该任务转化为以下约束优化任务：

#### 最大化熵函数

最大化关于 $p$ 的 $H$：

$$H = -\int_a^b p(x) \ln p(x) \, dx$$

约束条件：

$$\int_a^b p(x) \, dx = 1$$

该约束保证了结果函数确实是一个概率密度函数（PDF）。执行上述约束优化（问题 2.15），结果为：

$$

p(x) = \begin{cases}

\frac{1}{b - a}, & \text{if } x \in [a,b], \\

0, & \text{otherwise}.

\end{cases}

$$

换句话说，结果是均匀分布，这确实是最随机的分布，因为它不对区间 $[a, b]$ 内的任何特定子区间给予偏好。

我们将在第 12.8.1 节讨论这种估计 PDF 的方法。这种优雅的 PDF 估计方法源自 Jaynes [3,4]，称为**最大熵法**。在其更一般的形式中，会涉及更多约束以适应特定问题的需求。

## 2.6 随机收敛

我们将以一些关于随机变量序列收敛的定义，结束这场概率论及相关概念的记忆复习之旅。

考虑一个随机变量序列 `x[0], x[1], …, x[n]…`。

我们可以将此序列视为一个离散时间随机过程。由于随机性，该过程的一个实现，如 `x[0], x[1], …, x[n]…` 所示，可能收敛，也可能不收敛。因此，随机变量收敛的概念必须谨慎对待，并由此发展出了不同的解释。

回顾基础微积分知识，如果 `∀ϵ > 0` 存在一个数 `n(ϵ)` 使得

```
|x[n] − x| < ϵ, ∀n ≥ n(ϵ)。
```

(2.162)

则数列 `x[n]` 收敛于值 `x`。

### 处处收敛

如果随机过程的每一个实现 `x[n]` 都根据公式 (2.162) 给出的定义收敛于某个值 `x`，则称该随机序列*处处收敛*。请注意，每个实现收敛到不同的值，该值本身可视为随机变量 x 的一个结果，我们记为

```
x_n → x as n → ∞。
```

(2.163)

通常用 `xn` 表示随机过程的一个实现（结果），其中 `ζ` 表示一个特定的实验。

### 几乎处处收敛

相比于前一种收敛，一个较弱的版本是*几乎处处收敛*。考虑结果集 `ζ`，使得

```
lim xn = x(ζ), n → ∞。
```

如果满足

```
P(x[n] → x) = 1, n → ∞。
```

(2.164)

则称序列 `x[n]` 几乎处处收敛。

请注意，`{x[n] → x}` 表示由*所有*满足 `lim xn = x(ζ)` 的结果组成的事件。这与处处收敛的区别在于，现在允许有限个或可数无限个实现（即零概率集合）不收敛。通常，这种类型的收敛被称为*几乎必然*收敛或*概率为 1* 收敛。

### 均方收敛

如果满足以下条件，我们称随机序列 `x[n]` 在*均方意义上*收敛于随机变量 x：

```
𝔼 [|x[n]−x|²] → 0,  n → ∞.
```

### 依概率收敛

给定随机序列 `x[n]`、随机变量 x 和非负数 `ϵ`，则 `{|x[n] − x| > ϵ}` 是一个事件。我们定义新的数列 `P({|x[n]−x|>ϵ})`。如果构造的数列趋于零，则称 `x[n]` *依概率* 收敛于 x：

```
P({|x[n]−x|>ϵ}) → 0,  n → ∞,  ∀ϵ > 0.
```

### 依分布收敛

给定随机序列 `x[n]` 和随机变量 x，分别设 `Fn` 和 `F(x)` 为其累积分布函数（CDF）。如果对于 `F(x)` 的*每一个*连续点 x 都有

```
Fn → F(x),  n → ∞,
```

则称 `x[n]` *依分布* 收敛于 x。

可以证明，如果随机序列要么几乎处处收敛，要么均方收敛，则它必然依概率收敛；如果它依概率收敛，则它必然依分布收敛。反之则不一定成立。换句话说，最弱的收敛形式是依分布收敛。

## 3.1 简介

参数建模是贯穿本书始终的主题。多个章节聚焦于这一重要问题的不同方面。本章提供了与利用参数模型描述可用数据这一学习任务相关的基本定义和概念。

正如在介绍性章节中已指出的那样，大类机器学习问题最终等同于函数估计/逼近任务。该函数在学习/训练阶段通过挖掘可用训练数据集中蕴含的信息而被“学习”得出。该函数将所谓的输入变量与输出变量联系起来。一旦建立了这种函数关系，便可以反过来利用它，基于对相应输入变量的测量来*预测*输出的值；这些预测随后可用于进入决策阶段。

在参数建模中，上述将输入与输出相关联的函数依赖关系是通过一组参数来定义的，其数量是*固定*且先验已知的。参数的值未知，必须根据可用的输入-输出观测值进行估计。与参数方法相对的是所谓的*非参数*方法。在这些方法中，参数可能仍参与建立输入-输出关系，但其数量*不*固定；它取决于数据集的大小，并随观测值的数量而增长。非参数方法也将在本书中讨论（例如第 11 章和第 13 章）。然而，本章的重点在于参数模型。
