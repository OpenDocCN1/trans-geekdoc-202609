
虽然 MAC 地址描述了每个物理设备是什么，但用另一个执行相同工作的设备替换它通常很方便，有时甚至必要，且要求无缝切换。因此，为了在纯物理层面之上提供一个抽象层级，所有联网设备都被分配 **IP 地址**。在最初的版本（称为 `IPv4`）中，这些是 32 位地址，写作四组 0 到 255 之间的数字（每组基于地址的 8 位），例如 `64.233.160.1`。然而，由于连接到互联网的设备数量庞大，新版本 `IPv6` 于 2000 年代中期推出。它使用 128 位，地址写作 8 组十六进制数字。

IP 地址是分层的。例如，在 `IPv4` 中，第一组数字指定互联网的一个高层区域（通常由单一大型企业或互联网服务提供商拥有），下一组指定子区域，再下一组指定更小的区域，最后一组指定一组本地计算机的地址。因此，知道 IP 地址提供了一种自然的分层方式来查找拥有该地址的特定设备。

## 2.4 人员

虽然人员严格来说不属于网络空间的一部分，但他们扮演着重要角色。特别是，当他们在网络空间中行动时，必须以某种形式被识别。

对于网络空间中的经济交易，必须有支付交易的方式，因此此类场景对识别具体涉及哪个人有最严格的要求。这通常通过将信用卡与在线身份或账户关联来完成。因为信用卡公司已经验证发卡对象，这将特定的现实世界中的人与每个在线账户联系起来。

信用卡在线使用的增加催生了新机制，以验证花钱的人是否有权这样做。在物理世界中，持有信用卡和 PIN 码可验证这种权利。在网络空间中，信用卡号容易泄露，且无法直接对照卡片核对 PIN 码。

电话号码也已成为个人标识符，而非物理位置标识符。电话号码与特定个人关联的程度因国家而异，取决于在不提供政府身份证明的情况下购买 SIM 卡有多容易。电话号码显然可作为寻找特定个人进行短信/消息联系的方式。

电子邮件地址也被用作标识符，而不仅仅是接收信息的方式。许多网站在注册过程中要求提供电子邮件地址，然后通过向该账户发送包含注册最后步骤的邮件来显式验证。一次性电子邮件地址可供那些想注册又不透露个人详细信息的人使用，但一些网站会检查此类邮件的主机并拒绝它们，因此这方面存在一点“军备竞赛”。

最后，一些在线网站使用 handle（自由选择的名称）作为标识符，而不是电子邮件地址。虽然这些名称是自由选择的，但它们往往包含或暗示个人信息，甚至身份。

我们都在网络空间中拥有身份，通常是多重身份，因此从网络空间内部的视角看，我们只是另一种边缘设备。

## 2.5 管道

互联网上的设备通过管道连接，使数据能够四处移动。这些管道从跨洲际移动大量数据的巨型管道，到手机与一组无线耳机之间的连接，范围广泛。

正如我们从 IP 命名方案中看到的，互联网是分层组织的。要从互联网的一个部分到达另一个部分需要管道，还需要交换机来接收传入流量并将其向更接近目的地的方向转发。换句话说，如果互联网上的设备像建筑物，那么连接它们的结构就像道路和十字路口的网络。实际上，它更像火车站和调车场的网络，因为数据可以在交换机处暂存，等待容量将其发送出去。

互联网的顶层由可一次性移动大量数据的宽管道和大容量交换机组成，这些交换机能接收每个传入数据片段，决定其应遵循哪条传出连接以更接近目的地，并将其放置在该传出连接上。

高层交换机相互连接，但也必须有从这些交换机到低层交换机的连接，从低层交换机进一步向下连接，以此类推直到本地层级。换句话说，任何规模的区域交换机必须连接该区域内的所有节点，同时也要有连接（可能是多个）到更高层级的交换机。

设备可以扮演双重角色。例如，你的手机在接收发给你的邮件时充当边缘设备，但在从互联网向耳机流式传输音乐时充当交换机（此时耳机成为边缘设备）。

## 2.6 配置

节点和管道是网络空间的基本物理结构，但实际使用它们来移动和存储数据需要一些额外的结构：使其工作的规则，以及允许节点和管道加入和离开的机制。

网络中的每条路径必须在其两端之间传输数据。为此，两端的节点必须理解并使用协议。这些协议对应于道路规则，其中边对应道路和高速公路。

关于流量将如何在每条边上移动的协议称为 `protocols`。与高速公路上个体驾驶员可根据路况做出理性决策不同，管道中的流量只是数据，因此所有管理必须由两端的节点完成。一旦流量进入管道，它将在可预测的时间后到达另一端（如果管道被挖掘机切断，则可能无法到达）。

特定数据传输的目标节点不太可能直接连接到源节点。节点和交换机（统称）必须能够通过一系列边从起点将流量路由到目的地。任何交换机都必须能够接收传入流量，并确定应使用哪条传出管道将该流量移至更接近目的地的位置。为此，它维护一个 `routing table`，其中包含将目的地映射到适当传出边的条目。这有点像开车问路，被告知“向右转行驶 10 英里，然后再问一次”。

由于 IP 地址的层级结构，路由表不必为每个可能的目的地都有条目。对于远程目的地，只需知道将以特定前缀（如 `173.`）开头的 IP 地址发向哪个方向即可。路由表将包含物理位置较近的 IP 地址的更多细节，以及直接连接到它的设备的完整地址。

发送节点还必须意识到，管道另一端的接收节点可能并不总有足够的容量来存储和处理传入流量。必须有商定数据发送速率的方式。有时这是通过预先协议约定发送多少流量以及多快来完成。有时是通过让接收方确认已收到发送方的每个数据块，从而隐式地允许发送方发送下一个数据块。当然，这意味着边上存在额外流量，这些流量用于控制网络本身的运行。

正如现实世界的高速公路一样，必须有机制来处理边缘故障，以便流量能够绕过故障点进行路由。因此，路由表必须不断更新以反映不断变化的网络拓扑，这也需要控制消息。

流量的变异性也意味着整个区域可能变得拥塞，因此可能需要将流量绕过整个区域以避免拥塞。正如现实世界中那样，这可能会造成一种动态局势，导致不稳定发生——将流量引导至拥塞区域周围会产生新的拥塞区域，而原来的区域则变得不那么拥塞。随后这一过程会反向进行。拥塞控制机制可能被颠覆（现实世界中也是如此），以制造人为拥塞，或将流量引向特定地点以便对手进行分析。

特定节点或节点集可能希望阻止来自世界某些部分的流量，或阻止特定类型的流量，因此网络中也包含称为 `firewalls`（防火墙）的网关。例如，这些网关可以封锁整个国家，即所谓的“中国防火墙”，但它们更常用于仅阻止特定类型的流量进入企业或政府的子网络。换句话说，它们充当流量过滤器，允许某些流量通过而丢弃其他流量。

个人也会在手机或个人电脑上使用一种网关。这些被称为 `malware detection systems`（恶意软件检测系统）或 `antivirus systems`（杀毒系统），用于阻止特定类型的流量进入。

除了维持流量流动且方向正确的控制功能外，网络管理的另一个方面是将人类可读的地址（如 `cnn.com`）映射为 IP 地址，以便访问。实现这一机制的是 `Domain Name Service`（DNS，域名服务）。它由一组维护两种名称之间映射关系的特殊系统组成。

互联网是目前地球上规模最大的网络，连接着所有国家的设备。然而，还有其他网络（至少在理论上）未连接到互联网。大多数军队拥有自己独立、更安全的网络，这些网络与互联网没有直接连接。尽管这些网络在物理上是隔离的，但它们使用与互联网相同类型的节点、管道和控制机制，因为否则做法既不切实际又成本高昂。这使得它们一旦被攻击者访问，就会面临与普通互联网相同的许多攻击——单一文化问题再次显现。

网络之间的隔离可能是虚幻的，有时可以跨越它们之间的“气隙”。例如，用于破坏伊朗铀离心机的 Stuxnet 恶意软件，是通过从互联网加载的 USB 密钥引入的，随后这些密钥被插入控制离心机的隔离网络计算机中。这是这些隔离网络的常见弱点——必须有机制更新其中节点上的软件，而这创造了一个桥接通道。

每当互联网上的设备与这些隔离网络上的设备彼此靠近时，它们还可能利用人耳听不到的高频音频进行通信，或利用一台设备的摄像头拍摄另一台设备的屏幕图像。

## 2.7 流量类型

使互联网成为可能的关键发展是 `packet switching`（分组交换）的概念。发明分组交换的原因，正如银行等机构不再使用多队列，转而采用单一大队列配合多服务窗口一样。如果数据传输是先传完第一整批数据，再传第二批，依此类推，小批量数据将不得不等待，潜在时间很长，直到大批量数据传输完成。想象一下一条短信卡在电影下载后面的情景。

相反，发送到网络连接上的每一批数据都被分割成相当小的片段，每个片段独立发送。这意味着小数据传输不会卡在大数据传输后面，因为无论片段来自哪一批数据，它们以大致相同的速率向目的地推进。小数据批次会比大批次更早传完所有片段，但将所有数据都分割开能公平地利用管道容量。（正如我们将看到的，这种技术在分割和重组数据块时引入了开销，这本身也带来了问题。）

虽然分组交换是平等的，但也意味着某些类型的数据得不到良好服务。例如，如果数据传输是实时观看的大型视频（而非单纯下载），关键在于新帧必须以足够快的速率出现以供观看。此类流量面临着持续不断的截止日期要求，其他干扰这些截止日期的流量会产生直接、可观察的性能影响。

语音通常通过转换为数据（称为 `Voice Over IP`，即 VOIP）在网络上传输，这也有相同的问题。如果下一段语音数据未能及时到达以便按适当速度播放，音频质量会听起来断断续续，体验不佳。作为人类，我们能察觉毫秒级的延迟，即使无法有意识地感知。

为了处理这些特殊流量，仅使用移动数据包的机制，需要额外的协议层。这增加了管道操作的复杂性，管道必须对紧急流量特殊对待；节点也必须确保有足够的空闲缓冲容量以维持其流动。

## 2.8 深网

互联网中有部分内容并非对所有人常规可访问。我们已提到过那些（至少在理论上）未连接到互联网的网络。

另一个对普通用户不太可访问的网络空间部分称为 `deep web`（深网）。它包含未被搜索引擎索引的节点和内容，因此大多不可见，因为无法直接找到它们。

深网包含两类不同的内容。第一类是隐藏内容，指不能通过简单访问包含它的网页来获取。当你登录网站时，你获得了访问该站点数据存储中内容的权限，这些内容通常是个性化的。例如，登录银行网站时，你可以看到账户余额。此类内容他人不可见，也无法被搜索引擎索引，因为它仅在你个人查看时才存在。

深网的第二部分由没有公共访问路径的节点组成。搜索引擎查找万维网所有页面的方式是从显而易见的地方开始，然后顺着链接发现新地方。如果一个网站建立后没有任何链接指向它，就无法通过常规方式发现。但该网站仍可通过将地址分享给可信赖的朋友来发挥作用。（这是 `security by obscurity`（隐匿性安全）的一个例子，因为它依赖于包含地址的邮件不被邮件提供商扫描，从而提取地址并搜索。）

## 2.9 暗网

`dark web`（暗网）是深网的子集，包含试图隐藏自身的节点，通常因为它们用于非法或违法活动。

与通过不与万维网其余部分建立显式连接来隐藏自身的深网站点不同，暗网站点需要特殊机制才能到达其节点。这些可能是完全不同的通信方式，因此所用的应用程序必须从头构建。暗网中其他更流行的部分看起来像万维网，其地址看起来有点像传统的 URL，但必须以不同的方式访问。

即使你知道暗网站点的地址，也无法通过浏览器直接访问。暗网最常见的部分基于 `Tor 匿名路由器`。该路由器接受连接请求，目标是地址看起来像 URL 但以“.onion”结尾的暗网站点。然后，它利用志愿者计算机组成的网络，将流量随机路由通过中间站点，以切断你与你正在连接的网站之间的联系。最后，基于 Tor 的暗网站点只接受来自 Tor 网络节点的连接。因此，在你和暗网站点之间是 Tor 路由器，它将你的行为（可能被监视你节点的人看到）与你正在访问的目标网站解耦。监视 Tor 网络的另一端可以发现有人正在访问某个特定的暗网站点，但无法判断是谁。

此类暗网站点出售毒品、武器、网络攻击、被盗信用卡及信用卡号等产品，并被用于人口贩卖。它们也被用于更良性的目的，例如允许抗议运动进行通信和策划，甚至还有传统网站的暗网版本，供那些不想让其在线活动被追踪的人使用。

暗网还有另一部分（更暗的网络）使用自己的协议进行通信。这当然要求两端都使用专用软件（暗网浏览器和暗网 Web 服务器）才能理解通信的内容。

## 2.10 万维网

对许多人来说，万维网*就是*互联网。这是因为 Web 浏览器能做网络空间中普通人所做的许多事情，且都在单一环境中完成。这一理念在 Chromebook 中得到了明确体现，Chromebook 是一种仅具有 Web 浏览器界面来连接互联网的笔记本电脑。我们将在第 7 章回到 Web 话题。

## 2.11 社会层面

尽管网络空间是一项技术产物，但它存在于我们的社会互动之中，并在许多方面赋能了这些互动，这必然影响了其运作和使用方式。

互联网的原始基础是阿帕网，由美国政府开发，旨在促进研究并连接一小组大学和研究实验室。尽管这极不合适，但阿帕网的许多设计因互联网的增量式发展而保留了下来。曾有过几轮研究项目旨在从头设计一个新的互联网，但它们都撞上了现有系统的沉没成本这一障碍。

特别是，阿帕网连接的是可信站点，因此很少关注使其安全。网络安全不得不完全通过后期加装来实现。

IP 地址（和域名）的分配由国际联盟管理，因此你不能直接将一台计算机连接到互联网。对于普通公民，他们的 IP 地址由其互联网服务提供商（ISP）管理，后者可能为每个用户分配一个固定 IP 地址（实际上是其连接到 ISP 内部网络的接入点），或者每次计算机连接时动态生成一个。（这进一步变得复杂，因为家用调制解调器或路由器可能向外部世界呈现单个 IP 地址，但为家庭中的每台计算机和手机生成本地 IP 地址。）

然而，这一分配过程虽然有一定结构，但并不提供 IP 地址与现实世界位置之间的简单映射。例如，一个大型组织可能被分配一大段 IP 地址，比如 `100.200.*.*`，并可能将这些分配给许多不同地方的计算机。当然，如果 ISP 动态分配 IP 地址，IP 地址与街道地址之间就没有必然关系。

因此，网络的结构相当混乱，除了最基本的意义外，几乎没有所谓的“管理”。如果出了问题，没人可投诉。进步是通过超国家机构、国家政府以及大型 ISP 和跨国企业等大玩家之间的协作取得的。没有网络空间警察部队来强制执行即使是最基本的安全行为。

然而，给互联网带来不安全性的最大社会力量是便利性几乎总是胜过安全性。这仍然是一股强大的力量。在一个又一个场景中，当个人、企业和政府必须在这两个属性之间权衡时，便利性获胜。因此，虽然互联网起步时安全性很低，但后续发展本可以引入安全性，却因性能、成本、缺乏想象力以及在截止日期前产出结果的需要而未能做到。随着网络空间规模扩大并变得更加普及，我们现在看到的大多数网络安全问题将变得影响更大，毫无疑问还有我们尚未意识到的新问题。

导致网络空间安全问题的另一个问题是，发生的许多事情既隐藏在视野之外又不符合直觉。这部分归功于互联网的成功；人们可以使用 Web 浏览器访问世界的信息，而无需真正了解幕后发生了什么来提供这种体验。将此与火车、车站和轨道等交通系统对比。我们可能不太了解信号系统或机车如何工作，但至少我们对车厢如何组成列车、列车如何必须等待绿灯、以及从一地到另一地可能需要多长时间有一些直觉。没有这种直觉，普通人很难就如何行动做出明智决定。

大部分网络空间是自我管理的，即普通数据流量在无人干预的情况下从一处移动到另一处。确实，许多发生的事情太复杂，无法直接管理。然而，必须有人类控制网络空间某些方面的地方，尽管是在高度抽象的层面，普通网络空间用户通过决定去这里或那里、做这件事或那件事，也在一定意义上“控制”着它。

人类与网络空间之间的这种接口创造了一种新的漏洞，统称为 `社会工程学`。社会工程学指的是通过操纵人类在与网络空间互动时的行为，来操纵网络空间的所有方式。这可能从社交媒体企业利用粘性和标题党制造流量的方式

## 2.12 治理

正如我们所见，互联网拥有一种松散的治理结构，因其起源而略带以美国为中心色彩。大部分基础设施由大型互联网服务提供商（ISP）或电信公司拥有和管理。保持与互联网所有其他部分一致的必要性约束了任何特定的基础设施所有者。对网络空间进行任何改进的最大问题之一是利益相关者的数量庞大，且他们对问题的理解千差万别。

### 网络中立性

网络中立性是指传输数据的组织，即提供“管道”的一方，不向特定的其他组织提供优惠服务这一原则。最近，这一原则受到了冲击，例如，流媒体娱乐服务希望获得更有力的保证，确保其多少数据能以多快的速度传输。

### 互联网结构与国家边界

互联网全球化且略带无政府主义的结构，与威斯特伐利亚体系下的国际法律原则不太契合。这导致各国政府试图将互联网划分为其可控的国家级子网。

其中最著名的是所谓的“中国防火长城”。中国政府通过过滤设备中体现的规则与庞大的人工监管团队相结合的方式，控制进出中国（以及中国境内）的流量。然而，即使是这种资源充足且严厉的手段也存在漏洞，因为有必要为游客，尤其是国际商务人士提供访问其本国节点的权限，以便他们在中国期间使用。因此，中国的许多国际酒店以普通方式连接互联网。此类漏洞使得各种规避防火长城的变通方法成为可能。

其他国家，特别是俄罗斯，曾尝试将其国家互联网段与世界其他部分切断。这将需要在短时间内开启中国所使用的同类过滤机制，甚至可能完全切断连接。此类想法的难点在于，不实际尝试很难确保所有“门”都已关上。虽然进行过短期测试，但经济影响使得全面测试难以实施。

根本问题在于互联网结构跨越国界，因此一个国家使用的网站不一定位于该国，甚至不在同一大陆。

#### 数据存储与隐私

互联网结构与国家边界引发问题的另一个领域是数据存储位置。数据保护和隐私规则因国家而异，因此数据能否被执法或情报机构访问，取决于其存储地点。出于隐私担忧，各国越来越多地立法规定本国公民数据的存放位置。

## 2.13 安全问题

正如我们在第 1 章中讨论的，网络空间中的大多数安全问题源于安全在其底层系统设计中几乎从未被考虑。然而，即使安全曾是设计的一部分，在一个复杂、分布式、增量式、跨越全球的系统设计中，仍存在许多棘手问题。

思考网络空间安全的典型起点源于中世纪城堡的设计。城堡由城墙界定，旨在阻挡攻击者，且常呈环状排列，以便攻破一重城墙不意味着整座城堡沦陷。将此作为安全模型的问题在于城堡必然有城门。历史上，绝大多数城堡是通过城门被攻破的，往往是内应打开城门，而非靠冲垮城墙。网络空间亦是如此：安全机制往往类似于建造更厚更高的墙，却未充分重视数据必须进出区域和系统这一事实，而这些交互发生的地方往往防守薄弱。当然，无论在网络空间还是现实世界，城墙都比城门更显眼、更气派。
