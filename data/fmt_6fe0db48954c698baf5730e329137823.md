
然而，创建此类网站的动机无疑是快速扩张的原因。许多此类网站都有财务激励，要么是因为它们的创建者为了报酬而制作它们（请注意上面引用的马其顿韦莱斯的例子），要么是因为网站本身可能为读者提供了一种购买机制——无论是合法产品还是诈骗物品。

似乎更多网站更核心的目的是主张某种政治观点，这些观点可能会提出完全虚假的信息或带有误导的信息。

## 24.4 是讽刺还是虚假新闻？

对于信息消费者来说，一个巨大的挑战在于，可能被认为是虚假新闻的内容与那些旨在讽刺的内容之间存在着相似性。确实，讽刺是一种重要的叙事形式。

众所周知，我们从小熟悉的许多童谣实际上是由于规避报复而伪装的讽刺，针对权主。考虑以下例子（Fallon, 2014）：

《黑羊》

```
黑羊，黑羊，你有羊毛吗？
有的，是的，是的，三大包！
给主人一份，
给太太一份，
留给住在巷尾的小男孩。
```

《小杰克·霍内》

```
小杰克·霍内
坐在角落里，
吃着派；
他伸进拇指，
掏出一颗梅子，
说：“我是个乖的孩子！”
```

一种解释认为小杰克·霍内指的是托马斯·霍内。霍内是一个管家，被授权将一个大派交给亨利八世，其中包含了为了让修道院免受国王的反基督教运动而提供的贿赂。

《扬基杜德》

```
扬基杜德进城，
骑着小马；
在帽子上插了一根羽毛，
称其为意大利面！
```

显然，扬基杜德是这首歌中一个愚蠢的人物，可以追溯到革命时期。然而在当时，意大利面是伦敦花花的最爱食物，这个词已成为时尚的代名词。最初唱这首歌的英国士兵是在侮辱美国殖民者，暗示他们是傻瓜，认为在帽子上插羽毛就能像伦敦社交人士一样时髦。

### 杂锦

人们可能会纳奇，为什么一本关于行为网络安全的书中会有一章名为“杂锦”（Potpourri）。

“potpourri”一词在韦尔-韦布斯特词典（Merriam-Webster）和法语标准词典拉罗塞（Larousse）中都有许多有趣的定义，因为它源自法语并被引入英语。

韦尔-韦布斯特词典的定义如下：

**potpourri**

名词

pot·pour·ri | \ ˌpō\-pu˙-ˈrē \

potpourri 定义

1. 一种通常保存的花卉、草药和香料的混合物。

2. 各种物的混合物。

相反，`potpourri` 的法语定义是：

- 各种物的混合物；

- 各种物的集合；

- 各种物的杂烩；

- 各种物的多样性。

本章中 `potpourri` 的目的是描述在行为网络安全中可能遇到的不同类型的威胁。我们将使用这些威胁来说明可用于检测它们的各种方法。

将这些汽车示例转化到网络安全背景下，我们可能会将 D 级网络犯罪分子认为是被指向某个网站的人，该网站可能包含可以被下载并运行的嵌入软件，以创建某种形式的攻击。在这种情况下，这种行为不需要任何技能或知识，只需在发现并复制恶意软件后采取行动即可。有时，此类行为的实施者被称为“脚本小子（script kiddies）”。

C 级网络犯罪分子可能是能够发动某种 DDoS 攻击的人。例如，通过下载“Low Orbit Ion Cannon”（低轨道离子炮）程序，只需输入 URL 即可启动各种类型的 DDoS 攻击。

B 级网络犯罪分子可能是具有高水平编程技能的人，足以创建蠕虫、病毒或勒索软件，并将其发布以攻击某些经过精心挑选的目标站点。

最后，A 级网络犯罪分子实际上可能是一个政府或由一个或多个政府资助的大型组织。无疑，A 级攻击的例子可能是 `Stuxnet` 及其多个变体。`Stuxnet` 已被可靠地认为是美国和以色列政府的合作项目。

## 25.2 美国司法部起诉网络犯罪分子的成功：谁在赢？

为了了解网络犯罪分子与执法部门相比的相对成功率以及执法部门威慑网络犯罪分子的能力，多年来关于网络攻击的数据非常不透明。在某些方面，情况依然如此，但现在有了稍微清晰的图景，这无疑是因为在某种程度上，对于被认为是计算机犯罪的起诉报告有了更具协调性的努力。

其一个主要原因是，自从计算机时代开始以及随着病毒、蠕虫、拒绝服务和勒索软件出现而相应的安全担忧以来，法律的发展根本没有跟上技术的发展速度。例如，考虑以下情况：我可能有一个非常重要的文件或一组文件，从现实角度评估具有重大的货币价值。为了讨论起见，让我们假设这些信息价值 100 万美元。现在，一个网络犯罪分子通过某种方式成功复制了所有这些信息。是否发生了盗窃？

当然，我们的直觉会说是。但如果你查看任何关于盗窃的法律定义，这种行为都无法被描述为盗窃。

网络安全社区更加关注那些需要至少具备编程技能才能创建和分发的恶意软件类型：病毒、蠕虫、特洛马、机器人等。但现在已有充分记录表明，DDoS 攻击的数量和强度呈指数级增长，这已成为系统管理员及其组织关注的重点。

在 2011 年发布的《世界基础设施安全报告》（`WISC`, 2011）中指出，报告中记录的 DDoS 攻击数量，自 2004 年研究的第一年以来已增长了 10 倍，且受意识形态驱动的“黑客主义”和破坏行为已成为最易于识别的 DDoS 攻击动机。在同一份报告的 2012 年版本中（`WISC`, 2012），这种向政治动机驱动的趋势被量化如下：“35%[连接互联网的组织]报告了政治或意识形态攻击动机……31%报告称将虚无主义或破坏行为作为攻击动机。”在过去的 7 年里，DDoS 攻击的数量和强度正以指数级速度增长。正如`WISC` (2011) 所报告的那样，2011 年，10-Gbps（吉比特每秒）范围内的泛洪攻击显著增加。

DDoS 攻击已经进入主流，并被描述为“新常态”。在最形式的形式，DDoS 攻击是一组协调一致的服务请求，例如访问 Web 页面。这些请求可能来自互联网上的许多节点，通过人类操作或电子动作产生，且这些请求需要被攻击网站的资源支持。此外，现在通过某些类型的攻击，人们只需输入 URL 并点击即可参与其中，从而使能够参与 DDoS 攻击的用户数量增加到几乎每一个能够访问互联网的人。例如，低轨道离子炮（`LOIC`）在互联网上可以易于获取，使用该软件启动或参与 DDoS 攻击只需输入网站名称。通常，DDoS 攻击的目标仅仅是让网站产生如此巨大的流量，以至于主系统的带宽容量被过载并导致崩溃。网站崩溃的组织，其恢复时间可能从几小时到几天不等（图 25.1）。

尽管过去十年对 DDoS 攻击进行了大量的研究，但关于特定攻击的协调信息寥寥无几。这是可以理解的，因为被攻击的网站可能不想公开此类攻击发生过。然而，攻击小组越来越多地公开其击垮了一个网站（Dominguez, 2011; Mutton, 2011; Poulson, 2010; Singel, 2011）。不过，由于特定事件的影响，DDoS 攻击可能与突然涌入的请求无法区分。例如，当发生重大事件时——例如某位名人去世——新闻网站的合法请求可能会异常增加；或者当热门门票开始发售时，票务代理服务可能会被淹没。我们使用“异常事件”一词来描述 Web 服务需求快速增加的情况，这可能发生在 DDoS 攻击下，也可能发生在合法的高流量下。因此，更精确地监控此类异常事件的能力，可能是开发更好的防御或检测机制的有用工具。
