
通常情况下，当我们有足够的数据时，后验 `p(h|D)` 会集中在单一概念上，即 MAP 估计：

```
p(h|D) → ĥ_MAP  (3.4)
```

其中 `ĥ_MAP` 是后验众数，

```
ĥ_MAP = arg max_h p(h|D) = arg max_h p(D|h) p(h)
       = arg max_h [log p(D|h) + log p(h)]  (3.5)
```

### 3.2.2 先验

先验是由人类而非机器选择的，因此它是抽象的。先验的主观性是有争议的。例如，一个年轻人和一位数学相关的教师将会得出不同的结论。由于概率项严重依赖于 `N`，而先验保持稳定，随着我们获得越来越多的数据，MAP 估计将趋向于最大似然估计或 MLE：

```
hMLE ≜ arg max_h p(D|h) = arg max_h log p(D|h)  (3.6)
```

换句话说，假设我们有足够的数据，我们会看到数据压倒了先验。

### 3.2.4 后验预测分布

后验预测分布的概念通常用于贝叶斯设定中，它利用给定观测数据的参数的整个后验分布，产生一个区间上的概率分布，而不仅仅是一个点估计。

```
p(x̃|D) = E_{h|D}[p(x̃|h)] = ∑_h p(x̃|h)p(h|D)  (3.7)
       = ∫ p(x̃|h)p(h|D)dh
```

这仅仅是每个单独假设预测的加权平均，被称为贝叶斯模型平均。

```
p(θ|Da,Db) = p(θ,Db|Da) / p(Da) ∝ p(θ,Db|Da)
           = p(Db,θ|Da)
           = p(Db|θ)p(θ|Da)
           = Bin(Nb1|θ, Nb1+Nb0) Beta(θ|Na1+a, Na0+b)
           = Beta(θ|Na1+Nb1+a, Na0+Nb0+b)  (3.10 and 2.19 combined)
```

这使得贝叶斯推断特别适合在线学习，稍后我们将看到。

### 3.4 Dirichlet-多项模型

在上一节中，我们讨论了如何推断硬币正面朝上的概率。在本节中，我们将这些结果推广到推断具有 `K` 个面的骰子朝上面 `k` 的概率。

#### 3.4.1 似然

假设我们观测到 `N` 次掷骰子，`D = {x1, x2, ..., xN}`，其中 `xi ∈ {1, 2, ..., K}`。似然的形式为

```
p(D|θ) = (N! / (N1! ... NK!)) ∏_{k=1}^K θ_k^{Nk}  (3.23)
```

其中 `Nk = ∑_{i=1}^N I(yi = k)` 与公式 2.21 实质相同。

#### 3.4.2 先验

```
Dir(θ|α) = (1/B(α)) ∏_{k=1}^K θ_k^{αk-1} I(θ ∈ S_K)  (3.24)
```

#### 3.4.3 后验

```
p(θ|D) ∝ p(D|θ)p(θ)
       ∝ ∏_{k=1}^K θ_k^{Nk} ∏_{k=1}^K θ_k^{αk-1}
       = Dir(θ|α1+N1, ..., αK+NK)  (3.27)
```

根据公式 2.38，MAP 估计由下式给出

```
θ̂_k = (Nk + αk - 1) / (N + α0 - K)  (3.28)
```

如果我们使用均匀先验，`αk = 1`，我们恢复 MLE：

```
θ̂_k = Nk / N  (3.29)
```

#### 3.4.4 后验预测分布

单次多努利试验的后验预测分布由以下表达式给出：

```
p(X = j|D) = ∫ p(X = j|θ)p(θ|D)dθ  (3.30)
           = ∫ [∫ p(X = j|θj) p(θ_{-j}, θj|D) dθ_{-j}] dθj  (3.31)
           = ∫ θj p(θ|D) dθj = E[θj|D] = (αj + Nj) / (α0 + N)  (3.32)
```

其中 `θ_{-j}` 是除 `θj` 以外的 `θ` 的所有分量。上述表达式避免了零计数问题。

事实上，这种贝叶斯平滑形式在多项情况下比二项情况下重要得多，因为一旦我们开始将数据分配到许多类别中，数据稀疏的可能性就会增加。

### 3.5 朴素贝叶斯分类器

假设特征在给定类别标签的条件下是独立的，那么类条件密度具有以下形式

```
p(x|y=c, θ) = ∏_{j=1}^D p(xj|y=c, θ_{jc})  (3.33)
```

由此产生的模型被称为朴素贝叶斯分类器 (NBC)。类条件密度的形式取决于每个特征的类型。我们在下面给出几种可能性：

*   对于真值特征，我们可以使用高斯分布：

    `p(x|y,θ) = ∏_{j=1}^D N(xj | µ_{jc}, σ²_{jc})`，其中 `µ_{jc}` 是类别 `c` 中特征 `j` 的均值，`σ²_{jc}` 是其方差。

*   对于二元特征，`xj ∈ {0,1}`，我们可以使用伯努利分布：

    `p(x|y,θ) = ∏_{j=1}^D Ber(xj | µ_{jc})`，其中 `µ_{jc}` 是特征 `j` 在类别 `c` 中出现的概率。这有时被称为多元伯努利朴素贝叶斯模型。我们将在下面看到它的一个应用。

然而，由于罕见词对于分类目的最为重要，这些是我们最希望仔细建模的词。
