
# 基带网络

基带网络，只有一个信道；一次只能发送一个信号。

# 术语表

## A

### Baseline

实施保障措施的统一方式，属于管理控制。

### Baselining

捕获当前系统安全配置时间点理解的过程。

### Basic Input Output System

参见——`BIOS`。

### Basic Rate Interface

参见——`BRI`。

### Bastion host

### Bayesian filtering

贝叶斯过滤，使用数学公式分配概率以做出决策，如识别垃圾邮件。

### BCI

商业连续性学会。

### BCP

业务连续性计划，确保业务运营连续性的长期计划。

### BCP/DRP project manager

BCP/DRP 项目经理，确保 BCP/DRP 不仅完成，而且定期测试的关键联系人。

### bcrypt

基于 Blowfish 的慢速密码哈希算法。

### Bell-LaPadula

专注于维护对象机密性的安全模型。

### Best evidence rule

最佳证据规则，要求使用最有力的证据。

### Best practice

最佳实践，保护资产机密性、完整性和可用性的最佳方式的共识。

### BGP

边界网关协议，互联网上使用的路由协议。

### Biba

专注于维护对象完整性的安全模型。

### Big Bang testing

大爆炸测试，测试所有集成软件组件的集成测试。

### Binary image

内存的位级副本。

### BIOS

基本输入输出系统，通常存储在固件中。

### Black box software testing

黑盒软件测试，不向测试人员提供任何内部细节：软件被视为接收输入的黑盒。

### Blowfish

一种分组密码，使用 32 位至 448 位（默认 128 位）密钥加密 64 位数据。

### Bluetooth

802.15 网络，一种 PAN 无线技术。

### Bollard

挡车柱，设计用于阻挡车辆，通常部署在建筑入口前。

## B

### Book cipher

使用知名文本（如字典）中的完整单词作为明文的一对一替换的加密方法。

### Boot sector virus

### BOOTP

Bootstrap Protocol，无盘系统用于通过网络引导的协议。

### Bootstrap Protocol

参见——`BOOTP`。

### Border Gateway Protocol

参见——`BGP`。

### Bot

### Botnet

中心化的僵尸命令与控制（C&C）网络，由被称为“bot herders”的人类管理。

### Bottom-Up programming

从低级技术实现细节开始，逐步构建完整程序概念的编程方法。

### Breach Attack Simulations

参见——`BAS`。

### Breach notification

通知其个人数据已被泄露或极有可能已被泄露的相关人员。

### Brewer-Nash

参见——`Chinese Wall Model`。

### BRI

Basic Rate Interface，提供两个 64 K 数字 ISDN 信道。

### Bridge

具有两个端口的第 2 层设备，用于连接网段。

### Broadband

具有多个信道的网络；可同时发送多个信号，如有线电视。

### Broadcast

发送给局域网上所有站点的流量。

### BRP

Business Recovery Plan，详述从破坏性事件中恢复后恢复正常业务运营所需的步骤。也称为 Business Resumption Plan。

### Brute force attack

尝试每一个可能的密钥或组合的攻击。

### BS-25999

英国标准学会（BSI）制定的连续性标准。

### Buffer overflow

攻击者可在缓冲区变量末尾之后插入数据的状况。

### Bus

将网络节点串联连接的物理网络拓扑。

### Business Continuity Plan

参见——`BCP`。

### Business interruption testing

部分或完全故障转移到备用站点。

### Business Owners

也称为 Mission Owners，创建信息安全计划并确保其拥有适当人员配备、资金支持和组织优先级的高级管理层成员。

### Business Recovery Plan

参见——`BRP`。

### Business Resumption Plan

参见——`BRP`。

### Bytecode

## C

### Cable modem

通过宽带有线电视提供互联网接入。

### Cache memory

### Caesar Cipher

### Callback

### Caller ID

### Capability Maturity Model

参见——`CMM`。

### Carrier Sense Multiple Access

参见——`CSMA`。

### CASB

### CASE

Computer-Aided Software Engineering，使用程序协助其他计算机程序的创建和维护。

### CBC

### Central Processing Unit

### Centralized access control

### Channel Service Unit/Data Service Unit

### Charged Couple Discharge

参见——`CCD`。

Confidentiality, Integrity, and Availability（机密性、完整性、可用性）。
