
| **APA** | $\frac{1}{2}\mu\sigma_{\eta}^{2}\text{trace}\{\Sigma_{x}\}\mathbb{E}\left\lbrack \frac{q}{\|\mathbf{x}\|^{2}} \right\rbrack + \frac{1}{2}\mu^{-1}\text{trace}\{\Sigma_{x}\}\text{trace}\{\Sigma_{\omega}\}$ |

| **RLS** | $\frac{1}{2}(1 - \beta)\sigma_{\eta}^{2}l + \frac{1}{2}(1 - \beta)^{-1}\text{trace}\{\Sigma_{\omega}\Sigma_{x}\}$ |

对于 $q = 1$，可得到归一化 LMS 的结果。在高斯输入假设和高系统阶数 $l$ 下，有 $\mathbb{E}\left\lbrack \frac{1}{\|\mathbf{x}\|^{2}} \right\rbrack \approx \frac{1}{\sigma_{x}^{2}(l - 2)}$ [11]。

根据表 6.1，有以下备注。

#### 备注 6.4

*   **对于平稳环境**，RLS 的性能独立于 $\Sigma[x]$。当然，如果已知环境是平稳的，理想情况下应选择 $\beta = 1$。但请回顾，对于 $\beta = 1$，算法存在稳定性问题。

*   **注意**，对于较小的 $\mu$ 和 $\beta \approx 1$，LMS 和 RLS 中的两个参数存在“等价”关系 $\mu \approx 1 - \beta$。即较大的 $\mu$ 值有利于 LMS 的跟踪性能，而较小的 $\beta$ 值则有利于更快的跟踪；这是预期内的，因为算法会遗忘过去。

## 6.10 LS 解的计算方面

关于 LS 方法的高效求解以及 RLS 的计算高效实现的文献汗牛充栋。在本节中，我们将仅重点介绍多年来所遵循的一些基本方向。大多数可用的软件包都实现了此类高效方案。

开发各种算法方案的一个主要方向是应对数值稳定性问题，正如我们在备注 6.2 中已经讨论的那样。主要关注点是保证 *Φ*[*n*] 的对称性和正定性。为达到此目的所遵循的途径是利用 *Φ*[*n*] 的平方根因子进行运算。

### Cholesky 分解

从线性代数可知，每一个正定对称矩阵（如 *Φ*[*n*]）都接受以下分解：

*Φ*[*n*] = *L*[*n*]*L*[*n*]^(*T*)

其中 *L*[*n*] 是下三角矩阵，且其对角线上的元素为正。此外，该分解是唯一的。

关于 LS 任务，重点关注更新因子 *L*[*n*]，而不是 *Φ*[*n*]，以提高数值稳定性。Cholesky 因子的计算可以通过高斯消元法的修改版本 [22] 来实现。

### *QR* 分解

从数值稳定性的角度来看，计算矩阵平方因子的一个更好的选择是通过 *QR* 分解方法。为简化讨论，让我们考虑 *β* = 1 和 *λ* = 0（无正则化）的情况。此时，正定（样本）协方差矩阵可以分解为

*Φ*[*n*] = *U*[*n*]^(*T*)*U*[*n*]。

根据线性代数 [22]，我们知道 (*n* + 1) × *l* 矩阵 *U*[*n*] 可以写成一个乘积形式：

*U*[*n*] = *Q*[*n*]*R*[*n*]，

其中 `Q[n]` 是一个 `(n + 1) × (n + 1)` 正交矩阵，`R[n]` 是一个 `(n + 1) × l` 上三角矩阵。请注意，`R[n]` 与 Cholesky 因子 `L[n]^(T)` 相关。事实证明，就数值稳定性而言，处理 `U[n]` 的 `QR` 因子比处理 `Φ[n]` 的 Cholesky 分解更可取。`QR` 分解可以通过不同的途径实现：

*   **Gram–Schmidt** 输入矩阵列的正交化。我们在讨论用于求解滤波情况下正规方程的阵列阶梯算法时，已在第 4 章中见过这条路径。利用输入信号的时移特性，也开发出了用于 LS 滤波任务的阵列阶梯型算法 [31,32]。

*   **Givens 旋转**：这也是一条流行的路线 [10,41,52,54]。

*   **Householder 变换**：文献 [53,55] 遵循了这条路线。使用 Householder 变换从数值角度来看能得到一个特别稳健的方案。此外，该方案呈现高度的并行性，可在并行处理环境中得到适当利用。

与 `QR` 分解相关的综述论文精选见文献 [2]。

### 快速 RLS 版本

另一条活跃的研究路线，特别是在 20 世纪 80 年代，是利用与滤波任务相关的特殊结构；即滤波器的输入包含来自随机信号/过程实现的样本。遵循我们采用的符号约定，输入向量现在将表示为 `u` 而不是 `x`。此外，为了讨论需要，我们将滤波器阶数 `m` 引入符号体系中。在这种情况下，两个连续时刻的输入向量（回归量）除两个分量外共享所有分量。确实，对于一个 `m` 阶系统，我们有

```
u_{m,n} = [u_n; ...; u_{n - m + 1}],  u_{m,n - 1} = [u_{n - 1}; ...; u_{n - m}]
```

并且我们可以将输入向量划分为

```
u_{m,n} = [u_n, u_{m-1,n-1}]^T = [u_{m-1,n}, u_{n-m+1}]^T
```

这一性质也称为*时移*结构。这种输入向量的划分导致

$$

\Phi_{m,n} = \begin{bmatrix} {\sum\limits_{i = 0}^{n}u_{i}^{2}} & {\sum\limits_{i = 0}^{n}\mathbf{u}_{m - 1,i - 1}^{T}u_{i}} \\ {\sum\limits_{i = 0}^{n}\mathbf{u}_{m - 1,i - 1}u_{i}} & \Phi_{m - 1,n - 1} \end{bmatrix} = \begin{bmatrix} \Phi_{m - 1,n} & {\sum\limits_{i = 0}^{n}\mathbf{u}_{m - 1,i}u_{i - m + 1}} \\ {\sum\limits_{i = 0}^{n}\mathbf{u}_{m - 1,i}^{T}u_{i - m + 1}} & {\sum\limits_{i = 0}^{n}u_{i - m + 1}^{2}} \end{bmatrix},\ m = 2,3,\ldots,l

$$

![Equation](img/si298.png)(6.59)

对于复变量，转置被埃尔米特转置所取代。将公式 (6.59) 与公式 (4.60) 进行比较。这两个分区看起来很像，但它们是不同的。矩阵 $\Phi[m, n]$ 不再是托普利茨矩阵。其下分区由 $\Phi[m - 1, n - 1]$ 给出。此类矩阵被称为*近托普利茨矩阵*。所需做的就是通过减去一个秩一矩阵，将 $\Phi[m - 1, n - 1]$ “修正”回 $\Phi[m - 1, n]$，即

Φ[m−1, n−1] = Φ[m−1, n] − **u**[m−1, n]**u**[m−1, n]^(T).

![Equation](img/si302.png)

事实证明，这种修正虽然可能会使推导过程略微复杂化，但仍可通过应用矩阵求逆引理得出计算高效的阶递归方案，这与第 4.8 节的 MSE 情况相同。此类方案源于 Martin Morf 在斯坦福大学的开创性博士论文 [42]。针对 LS 情况，已推导出 Levinson 型、Schur 型、分裂 Levinson 型以及格-梯型算法 [3,27,28,43,44,60,61]。前文在 *QR* 分解下提到的某些方案利用了输入信号的时移结构。

除了阶递归方案外，根据文献 [33] 的研究，还开发出了许多固定阶快速 RLS 型方案。回顾公式 (6.45) 中卡尔曼增益的定义，对于 *l* 阶系统，我们有

```
k_{l + 1,n} = Φ_{l + 1,n}^{-1} u_{l + 1,n} = [ *  *; *  Φ_{l,n-1} ]^{-1} [ *; u_{l,n-1} ] = [ Φ_{l,n}  *; *  * ]^{-1} [ u_{l,n}; * ],
```

![Equation](img/si303.png)

其中 * 表示该元素的任意值。略去细节，下分区可将 *l* 阶、*n*−1 时刻的卡尔曼增益与 *l*+1 阶、*n* 时刻的卡尔曼增益联系起来（阶跃升）。然后可利用上分区获得 *l* 阶、*n* 时刻的时间更新卡尔曼增益（阶跃降）。此类过程避免了矩阵运算，从而得出每次时间更新复杂度为 7*l* 的 𝒪(*l*) RLS 型算法 [7,9]。然而，这些版本被证明在数值上是不稳定的。文献 [5,58] 提出了数值稳定版本，仅增加极小的额外计算开销。上述所有方案也均已扩展用于求解（正则化）指数加权 LS 代价函数。

此外，为了降低复杂度，还推导出了获得近似解的变体；这些方案使用协方差矩阵或逆协方差矩阵的近似值 [14,38]。`fast Newton transversal filter`（FNTF，快速牛顿横向滤波器）算法 [45] 利用宽度为 `p` 的带状矩阵来近似逆协方差矩阵。这种建模具有特定的物理解释。带状逆协方差矩阵对应于 `p` 阶 AR 过程。因此，如果输入信号可以用 AR 模型充分建模，FNTF 即可获得最小二乘性能。此外，这种性能的计算代价为 `O(p)` 而非 `O(l)`。在 `p ≪ l` 的应用中，这可能非常有效。例如，在音频会议中，输入信号是语音。语音可以用 15 阶 AR 模型高效建模，而滤波器阶数可能高达几百个抽头 [49]。FNTF 填补了 LMS（`p = 1`）与（快速）RLS（`p = l`）之间的空白。此外，FNTF 构建于稳定快速 RLS 的结构之上。最近，带状逆协方差矩阵近似已成功应用于谱分析 [21]。更多高效 LS 方案可参阅 [15,17,20,24,29,57]。
