![Equation](img/si349.png)

p(\mathbf{y};\beta) \geqslant \mathcal{N}(\mathbf{y}|0,\beta^{-1}I + \Phi\Xi\Phi^{T})\prod\limits_{k=1}^{K}\phi(\xi_{k}) := \widehat{p}(\mathbf{y};\beta,\Xi).

## 13.10 期望传播

*期望传播*是用于近似后验 PDF 的变分技术的一种替代方法。感兴趣的任务与本章开头第 13.2 节所讨论的任务相同。假设我们有一组观测值 $\mathcal{X}$，其分布遵循 $p(\mathcal{X}|\mathbf{\theta})$，以及一个先验 $p(\mathbf{\theta})$，对应于未知参数集 $\mathbf{\theta}$。^(⁹⁷)

记 `q(\mathbf{\theta})` 为后验的估计。出发点是通过最小化 KL 散度来计算 `q`，

\text{KL}(p||q) = \int p(\mathbf{\theta}|\mathcal{X})\ln\frac{p(\mathbf{\theta}|\mathcal{X})}{q(\mathbf{\theta})}\ d\mathbf{\theta}.

![Equation](img/si360.png)(13.95)

请注意，`KL(p||q)` 与 `KL(q||p)` 散度不同，后者涉及公式 (13.2) 中的界。由于 KL 散度不对称，这两种方法最小化的是不同的代价。在进一步讨论之前，有必要强调与这两种形式的 KL 散度相关的某些含义。

*   **I-投影**：`KL(q||p)` 散度由下式给出

```
KL(q||p) = ∫ q(θ) ln (q(θ) / p(θ|X)) dθ.
```

(13.96)

*   这有时被称为 *I-投影* 或 *信息投影*。仔细观察可知，在 `p(θ|X)` 取较小值的参数空间区域中，`KL(q||p)` 会取较大值，而最小化过程会推动 `q(θ)` 在这些区域也取较小值。现在考虑 `p(θ|X)` 为双峰分布，而 `q(θ)` 被约束为单峰分布的情况。此时，最小化 `KL(q||p)` 将迫使 `q` 接近 `p` 的两个峰值中的任意一个，以便在 `p` 取较小值的区域也获得较小的值。

*   **M-投影**：我们现在将重点转向 `KL(p||q)` 散度，其定义见公式 (13.95)。这也被称为 *M-投影* 或 *矩投影*。对于前面讨论的情况，在 `p` 取较大值的区域，`KL(p||q)` 会取较大值，最小化过程会估计 `q` 使其在这些区域也取较大值。因此，估计值 `q` 的峰值会位于 `p` 的两个峰值之间，作为两者的折中。显然，这不是一个好的结果，因为该估计在 `p` 取较小值的区域放置了高概率质量。这一讨论指出了期望传播方法在实践中预期表现出的性能的一些局限性，因为它基于 `KL(p||q)` 最小化。

我们现在假设 `p(X, θ)` 可以分解，即

```

```

#### 讨论要点

*   通常情况下，无法保证算法会收敛，这是该方法的一个主要缺点。不过，可以证明如果迭代确实收敛，解是一个特定能量函数的稳定点 [49]。回想一下，在变分贝叶斯方法中，保证收敛到局部最优点。当然，人们可以直接优化期望传播方法的 KL 散度，这能保证收敛，但在这种情况下算法更复杂且更慢。

*   考虑到我们关于 KL 散度两种形式的讨论，当真实后验是多模态时，期望传播方法表现不佳。然而，对于其他场景（如 Logistic 型模型），期望传播方法相比变分方法或基于拉普拉斯近似的方法，能提供有竞争力甚至有时更好的性能（参见 [39,49]）。

*   期望传播算法首次在 [49] 中提出，它是对之前称为 *assumed density filtering* (ADF) 或 *moment matching* 的方法的修改（例如 [58] 及其参考文献）。

*   **α-Divergence**：在详细讨论了 KL 散度的两种形式之后，有趣的是指出这两种公式都可以作为更一般家族（称为 α 散度家族）的特例获得，其定义为

```
D_α(p||q) = (1/(α(1-α))) ∫ p(x)^α q(x)^(1-α) dx
```

(13.110)

*   其中 `α ∈ ℝ` 是一个参数。注意，`KL(p||q)` 在 `α → 1` 的极限下获得，而 `KL(q||p)` 在 `α → -1` 时获得；`D_α(p||q)` 是非负的，且当 `p = q` 时变为零（参见 [2]）。

## 13.11 非参数贝叶斯建模

贝叶斯方法在参数建模方面一直是当前和前几章关注的焦点。其潜在假设是未知参数的数量是固定且有限的。我们现在将注意力转向一个更一般的任务。我们将假设模型的隐藏结构不是固定的，而是允许随着数据增长。换句话说，其复杂度不是先验指定的，而是留待从数据中确定。这就是此类模型被称为 *nonparametric*（非参数）的原因；回想第 3 章，如果自由参数的数量是固定的且独立于数据集大小，则模型被称为参数模型。

我们将避免从数学严谨的意义上处理非参数贝叶斯模型。这条路会使我们稍微偏离本书的目的，也偏离普通读者的数学技能。因此，我们将满足于以一种数学上“谦逊”的方式呈现主要概念。一旦掌握了基础知识，热心的读者可以通过参考更专业的文献（参见 [27]）深入探讨该主题。为了演示非参数贝叶斯模型背后的思想，我们将从熟悉的混合建模任务开始。随后，将引入所谓的矩阵分解问题，并在非参数背景下对其进行处理。

在第 13.4 节中，假设有 *K* 个混合成分（簇）。每个混合成分通过一个均值和精度矩阵未知的高斯 PDF 进行建模，即 `(μ[k], Q[k])`，*k* = 1, 2, …, *K*。反过来，这些参数被视为随机实体，并赋予了先验分布——均值服从高斯 PDF，精度矩阵服从 Wishart 分布。每个混合成分的概率 `P[k]`，*k* = 1, 2, …, *K*，要么被视为常数，在 M 步中进行优化；要么被视为随机变量，并与其关联一个狄利克雷 PDF 先验（问题 13.7）。目标是获得与每个观测点关联的标签的*后验概率*估计，即 `P(k[n]|X)`。在那里，我们通过均场近似求助于变分技术，后验由函数 `qZ := qZ` 近似，其中 `z[n]`，*n* = 1, 2, …, *N*，为 0-1 编码向量，在对应特定混合成分（*k*）的位置上置 1，其余元素为零。我们将此类向量称为*独热*向量。通过这种方式，实现了观测点在 *K* 个高斯分布簇中的等效聚类。

前述任务的非参数对应形式表达方式几乎相同，但有一个重要的区别。混合成分的数量 *K* 不再固定为一个有限值；事实上，混合成分的数量允许是*可数无限*的。现在出现两个问题：(a) 如何处理无限数量的簇，以及 (b) 如何处理与无限多概率值相关的先验分布？

为了说明如何处理无限性，请回顾在非参数建模中，数据点的数量仍然是有限的，等于 *N*。因此，无论采用何种模型，混合成分（簇）的数量不可能超过 *N*；后者对应于最坏情况，即每个点都属于不同的簇。因此，尽管理论上可以有无限多个簇，但只有有限子集是*非空*的。因此，我们只需要获得非空混合成分的显式表示即可。

关于第二个问题，可以证明，一种倾向于将数据分配给少量群体的、关于无限多分组的*先验*分布 `P(Z)` 是*中餐馆过程* (CRP)；这是整数分区 [1,22,65] 上的一种分布。

我们将首先陈述从该过程中生成抽样（实现）的算法，然后为那些对相关理论方面感兴趣的读者提供更多细节。

### 13.11.1 中餐馆过程

该名称源于加利福尼亚一些超大型中餐馆中看似无限的餐桌数量。每张桌子对应一个簇/混合成分，每位顾客对应一个观测值。第一位顾客坐在第一张桌子旁。第二位顾客以概率 `\frac{1}{1 + \alpha}` 坐在第一张桌子旁，以概率 `\frac{\alpha}{1 + \alpha}` 坐在一张新桌子旁。第 *n* 位顾客以与该桌已就坐人数成正比的概率坐在先前已被占用的桌子之一旁，并以与 *α* 成正比的概率坐在一张新桌子旁。参数 *α* 称为*浓度参数*。其值越大，被占用的桌子越多，坐在同一张桌子旁的顾客越少。用更正式的方式表达，设 `k[n]` 表示第 *n* 位顾客的桌子。则可以写为

P(k_n = k|k_{1:n - 1}) = \begin{cases} 

\frac{n_k}{n - 1 + \alpha}, & \text{if } k \leq K_{n - 1}, \\

\frac{\alpha}{n - 1 + \alpha}, & \text{otherwise,}

\end{cases}

其中 $K_{n-1}$ 是先前到达的 $n-1$ 位顾客所占据的桌子数量，$n_k$ 是已经坐在第 $k$ 张桌子上的顾客数量。可以证明，被占据桌子的期望数量按 $\alpha \ln n$ 增长；也就是说，聚类的期望数量随数据数量增长（例如，[19]）。公式 (13.111) 中的规则为随着新数据依次到达时将数据分配给聚类提供了采样理念。可以证明（例如，见 [19]），由此产生的概率 $P(k_1, \dots, k_n)$ 独立于数据到达的顺序（标签变更除外）；这是一个重要的不变性质。

图 13.14 说明了从 CRP 过程中抽取的一个样本。每位顾客以一定概率坐在先前被占据的桌子之一，或者选择坐在一张新桌子上。观察到顾客选择新桌子的概率迅速下降。相反，顾客坐在已被占据桌子上的概率随该桌子的受欢迎程度增加而增加（强者愈强）。

### 13.11.2 狄利克雷过程

本节简要讨论 CRP 所属的更一般的数学框架。初次阅读时可跳过本节。

随机过程的概念在第 2.4 节中已介绍。*狄利克雷过程*（DP），记为 $G$，最早见于文献 [16]，是一个*分布上的分布*，它通过 (a) *浓度参数* $\alpha$，以及 (b) 所谓的*基分布* $G_0$（定义在空间 $\Theta$ 上）来定义，我们记作 $G \sim \text{DP}(\alpha, G_0)$。我们称 $G \sim \text{DP}(\alpha, G_0)$ 为 DP，如果对于*任意*划分

(G(T_1), \dots, G(T_K)) \sim \text{Dir}(\alpha G_0(T_1), \dots, \alpha G_0(T_K))
