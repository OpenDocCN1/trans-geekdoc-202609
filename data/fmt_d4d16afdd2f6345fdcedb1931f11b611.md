
李群的整体性质研究是研究李群空间的拓扑性质。首先，我们讨论群空间的连通性。如果群中任意两个元素，作为群空间中的对应点，可以被包含在群空间内的一个完全包含的连通中，则称群空间是连通的。这样的连续群称为单连通群。`SO(3)` 群是一个简单李群。相反，如果群空间被分成几个不相连的部分，则这个连续群称为混合连续群。对于简单李群，群中的元素可以表示为无穷多个无穷小元素。除了无穷小元素外，在群空间的每个连续切片中还需要给出一个特殊元素（包括常元素），它们的乘积可以表示任何元素。对于线性表示，我们可以看到，简单李群的任意元素 $R$ 的表示矩阵 $D(R)$ 可以通过生成元计算出来，但对于混合李群，我们还必须知道空间反演元素的表示矩阵 $D(\sigma)$。

在混合李群的群空间中，包含常元素的连续片对应的元素集合构成了混合李群的不变子群，其他连续元素对应变换子群的陪集。因此，混合李群的性质由简单李群（不变子群）的性质和每个连续片中的代表元素（陪集）决定。

**定理 6.2.** *若 `N` 是连通李群，则存在一个单连通李群 `M`，它是 `N` 的覆盖群。*

*证明.* 根据拓扑覆盖空间的理论知识，当 `N` 是连通流形时，存在一个单连通流形 `M` 是 `N` 的覆盖空间；`P: M → N` 是覆盖映射。

对于以 `e_N` 为起点的路径 `x`: `[0, 1] → N`，`x(0) = e_N`，`x` 所属的路径类 `[x]` 是 `M` 中的一个点，并覆盖映射 `P[x] = x(1)`。

对于 `N` 中以 `e_N` 为起点的两条路径 `x, y`，我们定义 `z` 为 `z`: `[0, 1] → N`，`z(t) = x(t)y(t)`。我们将 `M` 中点的乘法定义为 `[x][y] = [z]` 或 `[x][y] = [xy]`。这个定义很重要，因为当 `[x*] = [x]` 且 `[y*] = [y]` 时，`H1` 是路径 `x` 和 `x*` 的固定点同伦，`H2` 是路径 `y` 和 `y*` 的固定点同伦。我们定义 `H(s, t) = H1(s, t)H2(s, t)`，其中 `H` 是路径 `xy` 和 `x*y*` 的固定点同伦，即 `[xy] = [x*y*]`。进一步地，`[e_N]`（`N` 中常路径 `e_N` 的路径类）`= e_M` 是 `M` 的单位元。在 `M` 中，点 `[x]` 的逆元为 `[x]^{-1} = [x^{-1}]`，其中 `x^{-1}(t) = (x(t))^{-1}`。

在定义了乘法之后，`M` 显然是一个群。覆盖映射 `P([x][y]) = P[xy] = x(1)y(1) = P[x]P[y]` 是群同态。

由于 `M` 存在于 `N` 中邻域 `P(V*)` 的某个开邻域 `V*` 中，`M` 可以被赋予微分结构，从而使 `M` 成为李群。进一步地，`M` 和 `N` 局部微分同构。因此，`Λ(M) = Λ(N)`。□

**定理 6.3.** *设 `G` 是连通李群。则存在唯一的（在同构意义下）单连通李群 `Ĝ`，以及从 `Ĝ` 到 `G` 的覆盖映射 `f`，使得 `(Ĝ, f)` 是 `G` 的覆盖群，这被称为 `G` 的万有覆盖群。*

*证明.* 设 `(Ĝ, f)` 是流形 `G` 的万有覆盖流形，`f^{-1}(e) = Γ`。设 `e* ∈ Ĝ` 且 `a*, b* ∈ Ĝ`。则 `Ĝ` 中存在路径 `r1*, r2*` 分别连接 `e*` 与 `a*`，以及 `e*` 与 `b*`。因此，`r1 = f(r1*)`，`r2 = f(r2*)` 分别是 `G` 中从 `e` 到 `a = f(a*)` 以及从 `e` 到 `b = f(b*)` 的路径。因此，`r = r1 · r2` 是 `G` 中从 `e` 到 `ab` 的路径。

将 `r` 提升为 `Ĝ` 中以 `e*` 为起点的路径，并设其终点为 `c*`。在 `Ĝ` 中定义乘法如下：`a*b* = c*`。需要注意的是，`c*` 不依赖于 `r1*` 和 `r2*` 的选择。设 `w1, w2` 分别是 `Ĝ` 中连接 `e*` 与 `a*` 以及 `e*` 与 `b*` 的其他路径。则 `w1, w2` 分别是 `G` 中连接 `e` 与 `a` 以及 `e` 与 `b` 的路径。进一步地，`w = w1 · w2` 是 `G` 中从 `e` 到 `ab` 的路径。设 `w*` 是 `w` 的提升，由于 `Ĝ` 是单连通的，`ri*` 可以连续变换为 `wi*`。因此，`w1` 可以连续变换为 `r1`，且 `w` 可以连续变换为 `r`。由于 `w` 和 `r` 的起点和终点相同，`w*` 和 `r*` 的终点也相同。因此，上述定义的 `Ĝ` 乘法是良定义的。

`Ĝ` 中乘法的结合律可以通过路径乘法的结合律得到。

由定义可知，`e*` 是一个单位元。进一步地，`(a*)^{-1}` 对应的路径 `r1^{-1}` 是 `G` 中连接 `e` 和 `a^{-1}` 的路径。它被提升为 `Ĝ` 中连接 `e*` 和 `(a*)^{-1}` 的路径。然后，我们知道 `a* (a*)^{-1} = e*`，即 `(a*)^{-1}` 是 `a*` 的逆元。

综上所述，`Ĝ` 是一个群。我们知道 `f` 是从 `Ĝ` 到 `G` 的群同态，因为 `f(a* b*) = ab = f(a*) f(b*)`。

由于 `f` 是覆盖映射，`Ĝ` 的逆运算和乘法是连续的，且 `Ĝ` 的群结构是一个局部群，我们可以证明 `Ĝ` 是一个拓扑群。此外，`Ĝ` 不仅是连通拓扑群，还是局部李群；因此，存在唯一的解析结构使得 `Ĝ` 成为一个李群。

因此，证明完毕。□

如果 `(G1, f1)` 也是 `G` 的万有覆盖群，则 `Ĝ` 到 `G1` 的同胚映射 `f'` 使得 `f = f1 f'`。因此，`f1 f'(e*) = f(e*) = e`。显然，`L_{e1^{-1}} f'` 仍然是同胚，且 `L_{e1^{-1}} f'(e*) = e1`。`L_{e1^{-1}} f'` 仍记为 `f'`。则，

```
f1 f'(a* b*) = f(a* b*) = f(a*) f(b*) = f1 f'(a*) f1 f'(b*)
```

因为 `f1` 是局部同构，所以在单位邻域内

```
f'(a* b*) = f'(a*) f'(b*)
```

进一步地，`Ĝ` 和 `G1` 是连通的，且 `f'` 是一一对应；因此 `f'` 是李群的同构。

> *推论 6.2. 设 `(Ĝ, f)` 是连通李群 `G` 的万有覆盖群。则 `df` 是李代数 `g_{Ĝ}` 到李代数 `g_G` 的同构映射。*

这一结论可由 `f` 是从 `Ĝ` 到 `G` 的同态且局部为同构这一事实得出。

> *定理 6.4. 连通群 `G` 必被一个单一覆盖群 `(Ĝ, f)` 覆盖，称为 `G` 的万有覆盖群。进一步地，`f` 是同构当且仅当 `G` 本身是单连通李群。*

在此，我们可以给出两个覆盖群的例子：

- `f : R^1 → S^1, f(t) = e^{2π i t}, t ∈ R^1`；因此，`R^1` 是 `S^1` 的覆盖群。
- `Ad : S^3 → SO(3)`。对于 `SO(3)`，对于任意适当的单位邻域 `V`，`Ad^{-1}(V)` 有两个连通分支，即它是“双层”覆盖，而上述第一种情况是“无限多层”覆盖。

从上文的定义和连通群的性质可以看出，由于李代数是李群的局部结构不变量，因此当 `f: G1 → G2` 是李群的连续态时，`df : g1 → g2` 就是李代数的同构映射。另一方面，当 `G1` 和 `G2` 的李代数 `g1` 和 `g2` 同构时，必然存在一对同态映射，例如李群 `Ĝ` 和 `fi : Ĝ → Gi` (`i = 1, 2`)。

### 6.2.1 基于覆盖思想的算法研究现状

覆盖技术是研究代数几何的重要工具，例如在基于研究的变换、模型映射以及奇点等方面的应用。覆盖思想已应用于许多领域，如数据挖掘和机器学习。

- 1) 张教授等人 [28] 给出了 M-P 神经元的几何意义，并通过球面投影变换将神经网络的优化设计问题转化为某些最优覆盖问题。他们将神经元对应于几何样本的球面邻域。通过这种几何直观方法，他们设计了多层前馈神经网络作为“分类器”，并将此设计视为“球面邻域”，输入 `x^i` (`i = 1, 2, 3, …, d`) 按其所属类别进行划分。最简单的设计方法之一是使用一组球面邻域覆盖某一类的 `x^i` (`i = 1, 2, 3, …, d`)，而不覆盖不属于该类的 `x^i` (`i = 1, 2, 3, …, d`)。因此，不同类型的输入被不同组的球面邻域所覆盖。然后，将同一组球面邻域对应的神经元输出通过“或门”组合起来。这样，一个分类器就被设计出来了。覆盖中的球面邻域对应于隐层。最小覆盖对应于最小隐层神经网络结构。他们还证明了任何次优覆盖方法和球面邻域方法都可以给出一种神经网络学习算法，这被称为邻域覆盖算法。

- 2) 王守杰院士 [30] 提出的仿生模式识别（拓扑模式识别）的理论基础在于，它确认了特征空间中相似样本的连续性（即不能将其分割为两个互不邻接的部分）。在引入仿生模式识别中同类样本的连续性规则后，对某类事物的“认知”本质上是对特征空间中形成的所有事物无限集合的“形状”的分析与“理解”。仿生模式识别基于特征空间中某类样本分布的最优覆盖。

- 3) 朱永红 [33] 提出了一种利用覆盖概念将更集中的样本聚合在一起，以发现样本集中隐含类别的覆盖聚类算法。对于稀疏样本，他使用最短距离法获得聚类效果。

- 4) 何青和石钟志 [31] 提出了一种基于超曲面分类和判别方法的基本算法，即通过区域整合计算，获得由闭曲面组成的若干超平面组合。让一类超曲面划分空间，即在样本点周围形成一个闭合区域。该区域由多个分类超平面包围，使得该区域覆盖尽可能多的同类样本点，而不覆盖异类样本点。

- 5) 吴涛和张玲等人 [29] 通过结合支持向量机（SVM）中的核函数方法与构造性学习的覆盖算法，提出了一种新的核覆盖算法。通过在样本空间中通过覆盖覆盖场来叠加覆盖域，属于同一类型的覆盖区域合并为特征空间中的一个球体，并最小化分类误差。因此，在特征空间中，我们找到每个类别的最佳包络，使相似区域的相似集成结合在一起。核覆盖算法结合了覆盖算法和 SVM 的优点，同时具有运行速度快、精度高和鲁棒性强的优势。

- 6) 张俊平 [37] 提出了一种流形学习方法，该方法可以通过有限数量的数据点描述嵌套流形结构。有限数据点集可以覆盖嵌套流形的支撑场，从而在保持所需码表尽可能少的同时，不丢失嵌套流形的结构信息。为了从有限样本集描述流形结构，本文借鉴了邻域覆盖的思想。定义 `(x, ρ)` 为伪测度空间，设 `B_r(x)` 为半径为 `r` 的闭球邻域覆盖的闭数，设 `S` 为 `χ` 的子集，设 `ε` 为正常数。那么，描述流形结构的邻域数量可以定义为点集 `X ⊂ χ` 的最小数量，使得 `S ⊆ ∪_{x_i ∈ X} B_ε(x_i)`。这确保了在使用邻域覆盖后，任何数据支撑集元素与 `X` 中最近元素之间的最大差异小于或等于 `ε`。使用局部邻域覆盖集，以确保不会丢失信息的整体结构。然后，获得局部邻域覆盖集对应的二维映射。最后，结合核函数和坐标映射的思想，将整体数据集映射到二维空间并进行重构。

可以看出，在机器学习领域，覆盖思想已被广泛使用。本书主要基于群的视角。我们可以使用李群的特殊代数几何来有效地表示样本数据。样本的特征空间嵌入到微分流形中形成一个李群。

通过对李群性质的分析，李群的性质与其群空间的连通性密切相关。当李群的群空间是多重连通时，该群的实表示是多值的。在学习过程中，直接分析多值表示问题往往很困难。因此，我们可以求解李群的问题，并利用李群与覆盖群之间的协变关系来解决此问题。覆盖的主要思想是覆盖同类问题，从而将不同类问题分离开。这种方法的优点显而易见：通过对同类样本的学习，可以获得更好的学习能力。当我们能够拟合许多类型的问题时，我们可以使用李群的特殊代数几何在最大程度上保持问题空间的不变性。

首先，我们考虑单连通情况下李群机器学习的覆盖算法。

### 6.2.2 李群机器学习的单连通覆盖
