
# Hyperledger Fabric 与 Nem 平台对比

## Hyperledger Fabric

对于正在探索使用哪个智能合约平台的开发者来说，Hyperledger 可能是一个绝佳选择，原因有几点。随着时间的推移，该平台已被证明是以太坊的可靠替代方案。`Hyperledger Fabric` 是一个许可制区块链基础设施，支持智能合约的执行。因为它是许可制网络，所有参与者都具有已知身份，这使其成为组织在创建智能合约的同时，遵守要求身份已知的数据保护法律的理想解决方案。

使 Hyperledger 独特且更灵活的功能之一是，开发者只需安装合适的模块，即可使用 JavaScript 以及其他常见编程语言创建智能合约。因此，在该平台上，开发者无需像依赖 `Solidity` 那样仅依赖一种语言就能编写智能合约。

### Hyperledger Fabric 的挑战

与以太坊不同，该平台缺乏自己的代币系统，虽然此功能提供了诸多优势，但也有其缺点。例如，它限制了可在该平台上开发的智能合约类型。对于希望开发需要支付转账的智能合约（如 ICO）的公司或组织来说，以太坊将是更好的选择。您将在 Hyperledger 中发现的其他主要功能包括：

*   许可制成员资格
*   可靠性能
*   支持插件组件
*   开源且免费使用
*   开发者可使用多种语言编写智能合约
*   由 IBM 支持

如前所述，该平台的一个主要缺点是缺乏代币系统。

## Nem

一些开发者偏爱 Nem 的原因之一是它是用 Java 编写的，而 Java 是一门广为人知的编程语言。因此，无需专门为区块链平台学习一门新编程语言（如 `Solidity`）。一些开发者偏爱该平台的另一个充分理由是 Java 实际上更成熟，因此与较新的编程语言相比，安全漏洞更少。

大多数安全专家透露，Nem 发布的 `Mijin V.2` 更新使该区块链网络成为区块链领域最安全的智能合约平台。除了改进 NEM 区块链外，该更新被视为一个行业里程碑，开启了分布式账本数据库功能新可能性的时代。Nem 最大的卖点或许在于其高度可扩展。例如，以太坊每秒处理约 15 笔交易 (TPS)，而 Nem 每秒可处理数百笔交易。这就是为什么越来越多的开发者被 Nem 吸引。请看 Nem 关键特性的总结：

*   卓越性能
*   Java 语言使其易于使用
*   可扩展
*   无平台专用语言

尽管有其优势，但也存在一些缺点，其中之一是工具不多。由于其使用的代码并非基于区块链，该平台去中心化程度较低。最后，与其他平台相比，Nem 的开发者社区也较小。

# 选择智能合约平台时需考虑的因素

如果您有兴趣选择一个智能合约平台，区块链领域有很多可供选择。我们刚刚探讨了其中几个，但在选择之前，有几件事您需要考虑。

## 考虑平台的声誉

多年来，对于想要创建加密代币的人来说，以太坊已比其他智能合约区块链平台更受欢迎。以太坊的开发者团队创建了 `Ethereum Virtual Machine` (EVM)。它是一个图灵完备系统，任何人都可用于开发区块链应用。以太坊拥有丰富的生态系统，使开发者创建去中心化应用 (dApps) 更轻松。

如果您需要通过去中心化实现安全性，以太坊也是最佳选择，这是因为它使用了 `PoW` 共识机制。目前，大量去中心化金融项目使用以太坊平台。随着向 `Ethereum 2.0` 的过渡，这也将把区块链从 `PoW` 过渡到 `PoS`，可扩展性问题将得到缓解，平台安全性将进一步提高。

## 如果您不需要代币

事实是，并非所有项目都需要加密代币。如果您的项目属于这一类，那么您很可能对需要许可制区块链的用例感兴趣。例如，如果您正在尝试开发供应链保障系统，则不需要加密代币。适合您项目的最佳智能合约平台类型是企业级区块链解决方案，此类平台之一是 `Hyperledger Fabric`。像 `Quorum` 这样的智能合约平台将适合对金融科技特定用例感兴趣的公司。`Quorum` 也是一个企业级区块链平台，在 JP Morgan 的协助下开发。2020 年，ConsenSys 收购了该公司。

# 第 7 章：区块链技术及其挑战

![Image](img/Image00024.jpg)

多年来，有兴趣进入区块链领域的公司名单持续增长。尽管分布式账本技术有许多优势，但在普遍采用之前，它仍需克服几大障碍。这些挑战范围从缺乏适当监管到可扩展性低，以及合格人员不足。在本节中，我们将梳理区块链技术面临的技术和组织挑战，并了解第三代解决方案为应对其中一些挑战所做的实施。

## 区块链技术的主要挑战

多年来，区块链技术主流采用面临的挑战之一关乎声誉。目前，大多数人将区块链技术等同于比特币和加密货币。不幸的是，世界仍将加密货币（并由此关联区块链）视为欺诈、投机者、黑客和恶意行为者的代名词。我们将同时探讨非技术或组织层面的挑战，以及技术层面的挑战，如缺乏互操作性、与遗留系统集成困难、可扩展性问题、分布式账本技术的复杂性以及人才短缺。

企业层面的一些组织挑战包括对技术缺乏足够的认知和理解、缺乏良好的治理、缺乏用户体验等。我们将探讨大多数挑战，以及区块链领域为应对其中大多数挑战所做的努力。

### 形象挑战

#### 形象问题

事实上，区块链技术面临的主要挑战之一是形象问题。正如第一章所述，中本聪发布比特币白皮书使区块链因比特币而普及。这为更多区块链项目打开了大门，随后区块链便与加密货币联系在了一起。我们也见证了多个诈骗加密项目掠夺人们的辛苦钱。许多人认为涉足加密货币的人都是利用该技术从事犯罪活动的骗子和黑客。

加密货币领域的负面形象正反映在区块链技术上，导致许多组织和个人在采用该技术前慎重考虑。大众需要理解比特币、以太坊、莱特币等加密货币与比特币区块链、以太坊区块链等区块链之间的区别。本书的目的之一是进一步启迪人们了解区块链的含义，以及如果更多个人和公司采用它，将对我们的世界产生何种影响。

区块链不同于加密货币，事实上，加密货币只是分布式账本技术的一个应用示例。在下一节中，我们将探讨区块链在全球不同行业的其他用例。随着更多人获得启迪，我们将见证人们对区块链负面看法的显著减少，这反过来将增加他们拥抱区块链的意愿。

值得欣慰的是，不同行业在区块链领域的多项合作倡议正带来积极变化，此类倡议和相互依存是推动区块链领域走向全球主流采用的绝佳方式。

### 主流企业恐惧区块链的颠覆性

大多数组织对区块链的颠覆性感到不适。对于一些觉得会因区块链技术而失去市场份额或最终被淘汰的企业来说，这甚至成了一种噩梦。区块链涉及 80% 的业务流程变革和 20% 的技术实施。这意味着从传统任务执行方式的彻底转变。这也适用于多年来见证数字技术显著变革的大多数行业。

请记住，区块链技术消除了对中心化权威的依赖，将信任和权威置于去中心化网络中。强大中心机构失去控制权令人不安，许多人宁愿对抗这种趋势。当然，我们可能无法完全知晓区块链实施将颠覆哪些行业和机构，以及将影响业务的哪些领域。这意味着*需要一种富有想象力的方法，以帮助发掘分布式账本技术提供的巨大机遇，以及它将如何改变我们的生活。*

### 成本与效率

毫无疑问，区块链网络能高效快速地执行点对点交易，但这伴随着高昂的总成本，尽管不同区块链的成本各异。以目前采用 PoW 共识的比特币区块链为例，运行验证交易并在公共账本间共享交易的节点成本巨大。估算显示，比特币网络验证和共享交易的年成本约为 6 亿美元，且该数字持续增加。事实上，该估算不包括购买专用挖矿硬件的成本。

除了成本，比特币价格下跌的部分原因是对比特币挖矿对环境影响的担忧。这意味着任何希望实施区块链解决方案的组织都需要在做决定前仔细权衡。这一挑战通常被称为*“区块链悖论。”*

### 安全与隐私

尽管比特币等区块链提供假名性（因为网络上的交易与钱包而非人关联），但许多潜在应用更倾向于明确与人身份关联的智能合约和交易。这将导致存储和访问分布式账本上数据的隐私及安全问题。提高区块链技术的接受度还要求利益相关者基于信任、安全和价值的概念，主动解决隐私问题。每个希望使用区块链的组织都必须审视隐私和安全如何影响区块链解决方案的设计。

### 既得利益集团的既得利益

区块链创新者必须克服的最大障碍是现有法规。因为大多数现有法规主要偏向现任者及其既得利益，而非新进入者——区块链公司。信息数字化进程正在高强度的监管环境下进行。这并不奇怪，因为政府长期确立的权威主要是为了保护消费者和财产权。

全球监管机构因分布式账本技术面临新挑战，正在探索保护消费者和市场的方法。遗憾的是，全球主要经济体监管机构的僵化做法仅抑制了该领域的增长和创新。然而，随着政府对区块链的价值产生兴趣，监管机构的观点正逐渐转变。

越来越多的国家正在探索创建央行数字货币（CBDC），中国处于领先地位，已在部分城市测试数字人民币。随着政府看到区块链技术的更多益处，最终将建立支持创新理念和项目同时保护消费者的监管模式。该领域法规的建立将进一步改善公众对区块链技术的看法，并促进采用。

### 法规

法规在应对技术进步时总是滞后，比特币区块链等许多技术在试图解决传统系统固有的低效做法时，设法规避了监管。然而，区块链解决问题的方法减少了监管，这实际上是其诞生的动因之一。中心化系统在面临自身问题时，始终充当某种*“减震器”*。

另一方面，去中心化网络可能不如中心化系统对冲击具有韧性，如果在解决方案设计中不加以充分考虑，这会直接影响参与者。这解释了为什么许多人建议区块链应用应在现有监管框架内运行，而非绕过它们。这意味着不同行业的监管机构必须清晰理解分布式账本技术及其对各领域消费者和企业的影响。

### 与遗留系统集成

#### 区块链与遗留系统的集成

企业组织面临的挑战之一是将区块链与遗留系统集成。对于希望使用区块链的公司而言，它们需要对原有系统进行彻底重构，或者想出一种同时集成这两种技术的方案。但这种集成面临的挑战是缺乏熟练的开发人员，因为大多数公司无法获得所需的区块链人才来协助完成这一过程。

当然，它们可以通过聘请外部服务来应对这一局面；然而，区块链领域的大多数解决方案要求有意向的公司投入大量资源和时间，才能实现成功的过渡。

另一个令大多数组织望而却步的因素是，在向分布式账本技术过渡期间，数据泄露和丢失的发生率很高。大多数公司在修改数据库时通常非常谨慎和保守，他们这样做是有充分理由的。他们试图避免数据损坏或丢失的风险，因为这可能会对其运营产生负面影响。区块链领域也在致力于开发解决方案，以允许遗留系统连接到区块链后端。

此类解决方案的一个杰出范例是 `Modex Blockchain Database`。该产品旨在帮助缺乏相关技术显著知识的个人享受分布式账本技术的诸多优势，并消除因敏感信息丢失而可能面临的任何障碍。

### 分布式账本技术仍不成熟

区块链和 DLT 总体而言仍是一项不成熟的技术，这也解释了为什么它面临着多项实施挑战。这引出了区块链技术面临的一些技术挑战。

#### 可扩展性

可扩展性无疑是区块链领域面临的最困难障碍之一。你可以将其简单视为缺乏规模；其含义是，与传统平台相比，分布式账本处理交易的速率受到限制。目前，大多数传统企业每秒处理数千笔交易，但大多数顶级区块链网络仍远远落后。对于私有链而言，可扩展性通常不是问题，因为受信任的参与方参与了此类网络中节点的活动，这是一种极佳的商业策略。由于网络结构的原因，`Bitcoin` 和 `Ethereum` 等顶级区块链网络一直无法有效处理其网络上的交易量。

我们能在链上处理的交易数量是有限的，这种缺乏规模的问题对于需要网络在保持低延迟的同时促进高交易吞吐量的组织来说是一个主要挑战。那么，针对可扩展性问题，有哪些可用的区块链解决方案呢？

##### 1. 链下解决方案

许多区块链平台认为，链下解决方案将提升区块链网络的交易速度，同时去中心化和安全性也应在数字账本上得到最大化保障。如果你不理解什么是链下扩容解决方案，它是指允许在不给区块链造成过重负担的情况下执行交易的解决方案。因此，任何采用链下扩容解决方案的协议都允许其平台上的用户发送和接收资金，而交易详情不会出现在主链上。目前，许多区块链项目正在探索各种链下解决方案，试图解决可扩展性问题，我们将了解其中一些。

##### 2. 加速芯片

`Skynet Core` 是加速芯片领域的先驱，该解决方案可提高确认速度和交易速度。该项目专注于解决区块链技术采用面临的挑战以及物联网 (`IoT`) 的功能性问题。`Skynet` 的核心目标之一是提供一个端到端系统，这包括一个极具扩展性的 `IoT` 区块链网络和一个免许可的区块链 `IoT` 芯片，称为 `Skynet Core`。

该项目旨在提供数十亿个免许可的区块链芯片，它们将被部署到全球各地的设备上，并通过公司的区块链网络进行连接。这种免许可的区块链芯片旨在取代我们目前使用的 `CPU`，它拥有为分布式账本技术和 `IoT` 优化的核心。借助该硬件，`Skynet Core` 设备能够为数字货币防盗提供充分保护，并轻松运行高吞吐量的区块链网络。

##### 3. 侧链

解决可扩展性问题最有前景的解决方案之一是使用侧链。它本质上是一条独立的区块链，但不是一个独立的平台，因为它以某种方式锚定在主链上。因此，侧链和主链具有互操作性——资产可以在两条链之间自由流动。创建侧链的主要原因是减轻区块链网络所承受的负载。实现这一点的方法是将交易通过所有关联的侧链发送，并将交易的最终状态添加到主区块链上。这种机制有助于减轻主区块链处理大量交易的负担。

为了确保资金转移，存在多种侧链解决方案。例如，某些解决方案将数据从主链移动到一个特殊地址，同时在侧链上发行等量的资产。另一种选择是将资金发送给托管方，由其将存入的资金兑换为侧链上的资金。

##### 4. 分片

`Ethereum` 是探索使用分片作为扩容解决方案的区块链网络之一。分片简单来说就是将计算和存储需求从单一区块链网络分散到单个节点上。采用分片的网络会将其区块链分割成多个独立的区域，称为分片。网络会为每个分片分配一小组节点进行维护。

这意味着网络上的节点不必处理整个网络的交易负载。每个节点只需维护与其分片或分区相关的信息。分片的使用消除了区块链网络中每个节点都必须参与交易的必要性。

##### 5. 多层结构

这也是区块链项目正在致力于的解决方案之一，旨在帮助提升规模。它指的是将区块链技术的两个独立方面——交易处理和数据存储——进行隔离。`Cardano` 就是致力于该解决方案的区块链网络之一。该项目通常被视为第三代区块链，是一个去中心化的开源区块链项目，具有分层结构。其结构包含两个关键要素：`Cardano Computational Layer (CCL)` 和 `Cardano Settlement Layer (CSL)`。

该项目的双层架构使 `Cardano` 独树一帜，因为大多数现有的区块链网络都在单层上运行，这最终会导致网络拥堵、降低交易速度并导致费用飙升。`Cardano` 的结算层处理交易确认以及原生代币的流动。另一方面，网络的计算层负责维护网络安全。此外，它还处理智能合约的部署，核心开发人员将其编程为能够识别数据的身份。

#### 因缺乏标准化而导致的有限互操作性

##### 互操作性：区块链面临的重大挑战

互操作性是区块链领域面临的一大挑战。目前有超过 6,500 个项目利用不同的区块链平台（其中大多数是独立平台）和解决方案，它们拥有不同的编码语言、协议、隐私措施和共识机制。由于存在许多不同的网络，且缺乏一个通用标准来允许这些网络之间进行适当通信，区块链领域无疑处于一种混乱状态。

由于各种区块链协议缺乏统一性，诸如安全性等基本流程缺乏一致性。这使得该技术的大规模采用变得非常困难。建立针对不同区块链协议的行业标准，有助于企业验证概念验证、协作开发应用程序并共享区块链解决方案。这也将有助于使区块链平台与现有系统的集成变得轻而易举。好消息是，许多区块链项目已经在提供各种区块链网络之间的互操作性。

###### 主要互操作性项目

目前，大多数区块链网络允许创建侧链，正如我之前提到的，侧链就是沿主区块链并行运行的区块链。但最近区块链领域的互操作性项目数量有所增加。这是为了响应不同区块链相互通信并提升技术潜力的需求。我们将看看三个优秀的互操作性项目示例。

####### 1. Polkadot

该项目是一个高知名度的多链技术，致力于改善区块链的互操作性。Polkadot 的核心目标之一是促进智能合约数据在不同区块链平台间的传输。该项目的生态系统拥有多条“平行链”，它们本质上是独立的区块链。这些平行链在特性上各不相同，但它们仍属于 Polkadot 生态系统。

考虑到网络的链数量，Polkadot 区块链上的交易分布在广泛区域。连接所有平行链的是一条中继链，Polkadot 区块链项目的目标是使公共网络、私有链以及预言机和无许可接口能够无缝连接。该互操作性项目背后的团队希望构建一个互联网，让独立的区块链解决方案能够利用 Polkadot 的中继链来交换信息。

####### 2. Cosmos 区块链

这个区块链互操作性项目是区块链领域最有趣的项目之一，它运行在称为 Tendermint Byzantine 的容错协议上。该项目的目标之一是成为多个项目的枢纽。其结构由多条独立区块链（称为“分区”）组成，这些分区连接到一条称为“枢纽”的中心区块链。这些分区接入 Cosmos 网络，并得益于 Cosmos 枢纽可以相互通信。此外，还可以连接新的分区。

Cosmos 网络互操作性项目的一个显著特点是，它允许分区保留其共识机制。在这种情况下，为每个分区提供动力的是 Tendermint Core，它除了提供安全且一致的共识引擎外，还提供了增强的性能。得益于 IBC 连接，Cosmos 区块链可以轻松连接从公共到私有项目的各种分区。

####### 3. 区块链工业联盟 (BIA)

越来越多的区块链项目聚集在一起，授权其区块链相互通信。一个极好的例子是 BIA，这是由三个区块链项目（AION、WANChain 和 ICON）组成的联盟，旨在允许它们的区块链相互通信。该联盟的主要目标是解决区块链孤岛问题。团队成员有一个共同的目标，即促进各个孤立区块链之间的互联互通。

他们主要关注跨链交易和通信的研究。他们还将专注于制定通用的行业标准，BIA 中的每个参与区块链都在致力于连接区块链协议。

在我们看到区块链技术大规模实施之前，我们讨论过的现有区块链平台面临的主要问题必须得到解决。有趣的是，在短时间内，区块链在其结构和功能方面经历了快速改进。这是一项相对年轻的技术，旨在解决这些问题的新项目不断涌现，这表明区块链确实有潜力颠覆各行各业。这些障碍肯定会比我们大多数人想象的更早得到解决。
