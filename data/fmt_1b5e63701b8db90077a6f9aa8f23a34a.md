# 2. 相关工作

## 2.1. 异常检测

异常检测可以分为基于`GAN`、基于`CNN`和基于自编码的检测方法。Morais R.等人[25]提出了一种方法来对监控视频中人类运动的正常模式进行建模，并使用动态骨架特征进行异常检测。Neelu Madan等人[26]提出了一种自监督模块，该模块可应用于各种先进的图像和视频异常检测框架。Feng等人[27]提出了一个多实例框架（`MIST`），并将其应用于弱监督视频异常检测（`WS-VAD`），在`MIST`中优化多实例伪标签生成器和自引导注意力增强特征编码器，并使用自训练方案。在无监督学习领域，最早使用基于`GAN`的可预测性建模的研究是Thomas Schlegl提出的`AnoGAN` [28]，该方法涉及通过在正常样本潜在空间中深层卷积`GAN`（`DCGAN`）进行正常解剖变化的无监督学习。作者还在推断阶段设计了两个损失函数，以计算生成图和原始图之间的差异。根据加权值和设定的阈值确定异常区域。Xia等人[29]提出了用于语义分割中故障检测和异常检测的两种方法。他们设计了一个使用语义分割模块`M`与`GAN`网络相结合的网络框架，以实现异常项目的检测。在工业异常检测中，自编码网络是主流网络。记忆模块和知识蒸馏模型[30,31]也广泛应用于用于异常检测的自编码网络中。Bae J.等人[32]认为，在当前的自编码网络建模过程中，位置和邻域信息被忽略了，这影响了正常特征的分布。他们提出了一种新的建模方法，其中给定邻域特征的_conditional_概率用于估计正态分布，并使用多层感知机网络进行建模。为了提高工业异常检测的速度，Kim D.等人[33]提出了一种快速自适应补丁记忆（`FAPM`）方法，消除了不必要的计算，具有良好的准确性和速度。

## 2.2. 动作识别

解决方案的基础可以分为两部分：第一部分是依赖提取的人体骨架信息进行姿态估计，第二部分直接提取图像的时空特征进行分类。Si Jie等人[34]提出了基于人体骨架的时空图卷积网络（`ST-GCN`），通过模拟动态骨骼，将人体骨架节点表示为图卷积节点，并使用时空卷积图来表示多层骨架关节序列。此外，Li提出了动作-结构图卷积网络（`AS-GCN`），结合动作链接和结构链接[35]，能够同时学习时空动作的特征；他们提出应将识别头与未来姿态预测头相加，并通过自监督建立动作模型。Zhang X.[36]使用非对称相关性指标和更先进的上下文感知图卷积网络（`CA-GCN`）来计算上下文信息，进一步扩大了算法的灵活性。Cheng等人[37]提出了一种新的shift `GCN`（`shift-GCN`），用于以人体骨架作为时空图来建模图卷积神经网络，并有效降低了计算复杂度。

在基于图像的时空算法中，Carreira等人[38]提出的双流扩展3D卷积网络（3D）通过扩展卷积层并将核从2D池化到3D来实现时空特征的学习。由光流和RGB组成的双流架构也增强了网络性能。Liu T.[39]提出了`STILL`，一种用于时空交互学习的双流网络。`STILL`摒弃了早期双流网络中分离捕获空间和时间信息的做法，更加关注视频中空间和时间信息的强互补性和相关性。通过建立时间流和空间流的互联，它能够有效地提高识别准确率。Ji Lin等人[40]提出了一种计算高效的时序偏移模块（`TSM`），结合2D `CNN`主干网络，使其能够利用边缘设备实现低延迟的视频识别。Limin Wang等人[41]使用RGB差异和曲线光流场作为网络输入，并提出了时序网络（`TSN`），以模拟整个视频的长期结构用于长程时间序列建模，作为动作识别的新框架。

## 3.1. 动作识别

### 3.1.1. 人-物交互特征提取

通过观察破坏性动作的视频，我们发现，在发生破坏行为的片段中，手在运动和特征方面与商品更加相关，特别是在具有明显破坏特征的动作期间。因此，我们对不同帧对象之间的运动关系进行编码。我们将单个商品和手定义为我们的检测对象。其中，每个对象的特征包含该对象的中心坐标及其高度、宽度和标签，形成一个向量，并将这些数据传递到多层感知机（`MLP`）网络，生成`d`维特征并指定特性。其中，每个对象的特征包含它们自身的2D坐标和标签信息，以商品为关键点。

使用主干`CNN`（例如，`ResNet–152` [42]），我们可以提取每个对象的图像特征`F`。文献[21]中的观察表明，位置嵌入表现更好

```
f_j^t = GAP(Res_n(RoI(f)))                                       (1)
```

### 3.1.2. 人机交互图卷积网络

我们首先定义图卷积中的节点特征。在获得感兴趣区域的位置编码特征后，我们将节点的位置特征与图像特征连接起来。这两类特征的融合是通过 `1 × 1` 卷积核实现的。通过这一步骤，我们将获得物体的位置以及图像特征的融合特征 `x_j^v`。融合特征可以串联起来形成图中物体节点的特征，即节点矩阵 `X`。

![](img/e4200cc4308edaf8913e513b0f96dbb6_335_0.png)

图 2. 基于置信度引导的异常检测架构的算法流程概览。我们使用 `U-net` 网络作为自编码器。自编码器分为两部分；一部分是语义分割网络，输出语义分割图；另一部分是具有置信度引导的异常增强模块的自编码器，输出重建图像。我们对原始地图、语义分割图和重建图使用两种函数。通过计算重建地图与原始地图之间的余弦距离以及分割地图与重建地图之间的感知损失，我们获得两个异常图。最终异常图通过加权融合获得。

在为视频第 `t` 帧中的不同对象创建交互邻接矩阵时，一种流行的方法是使用对象的位置信息来定义节点之间的连续性。我们将对象 `i` 的节点坐标定义为 `$U_i$`。相对坐标被输入到 `MLP` 层，并作为相邻节点之间大小为 1 的提议概率放入关键矩阵的对应点。获得大小为 `$N × N$` 的邻接矩阵 `G`：

```
G^l_{i,j} = MLP(U_i - U_j) (2)
```

我们使用图卷积网络（`GCNs`）[43] 来生成人机交互图。图卷积与标准卷积的不同之处在于，执行图卷积等同于在图节点内执行消息传递。`GCN` 的输出是每个物体节点更新后的特征；所有物体节点的特征可以聚合在一起用于视频分类。形式上，我们可以将一层图的卷积表示为

```
P = GXW (3)
```

其中 `G` 表示维度为 `$N × N$` 的邻接图，`X` 是图中物体节点的输入特征，维度为 `$N × d$`，`W` 是层数为 `$d × d$` 维度的权重矩阵，而图卷积层的输出 `Z` 仍然具有 `$N × d$` 维度。在我们的网络中，`W` 是 `$d × 1$` 维度的权重矩阵。它被用作最终分类器。

此外，输出是动作类别概率。我们将层 `Graph^{a}` 的输出 `P` 定义为

```
P_{l} = σ(G^{l}TXW)  (4)
```

最后，图卷积计算后的输出结果被传递到 sigmoid 函数 `σ`，该函数计算大小为 `N` 的动作类别概率 `P_{l}`。

### 3.1.3. 时间交互模块

运动中的轨迹特征对于理解视频至关重要。在描述运动时，我们使用了 [21] 中提出的时间交互模块。它计算轨迹片（tractlet）的特征为 `g(x_{i}^{1}, …, x_{i}^{T})`，并使用非局部块 [44] 作为函数 `h` 来结合和聚合轨迹片的信息。它还使用 [23] 中提出的三维卷积神经网络架构，对视频序列执行三维卷积操作和平均池化；随后，将获得 `N` 维的特征 `P_{T}`。我们将三维特征 `P_{D}` 和轨迹片特征拼接如下：

```
P_{T} = σ(W_{p}^{T}[P_{D}, h(g(x_{i}^{1}, …, x_{i}^{T})_{i=1}^{N})])  (5)
```

其中 `[]` 表示串联，而 `W_{p}^{T}` 用作具有交叉熵损失的最终分类器。最后，我们通过乘以概率来组合动作类别概率 `P_{I}` 和时间交互概率 `P_{T}`，这是一种类似于先前工作 [45,46] 的方法。`P_{F}` 代表大小为 `N` 的最终预测向量。

```
P_{F} = P_{T} × P_{I}  (6)
```

## 3.2. 置信度引导的异常检测

在识别异常动作的过程中，商品包装损坏特征的出现是识别破坏行为发生的最可靠依据；然而，检测和定义损坏部分仍然很困难，因为损坏特征并不出现在正常的消费活动中。图像中损坏特征的检测等同于分布外（`OOD`）对象的检测。在分类中，`OOD` 对象将被分类为分布中的任何可能对象。基于动作识别，我们对商品区域进行了语义分割，并为了简化计算的复杂度，我们将分割模型的分类结果分为 `L = n + 2` 类，即 `n` 种商品、顾客和背景。具体而言，`x` 是大小为 `w × h` 的视频帧，`L = {1, 2, …, r, L}` 是表示语义标签的整数集合。通过将图像 `x` 发送到分割模型 `M` 获得像素级语义标签，其中我们使用 `U-Net` [47] 作为我们的分割模型。同时，另一种类型的 `U-Net` [48] 被用作自编码器。它去除了编码器中的最后一个批归一化层和 `ReLU` 层，取而代之的是一个 `L2` 归一化层，使特征具有共同的尺度。

分割完成后，我们根据分割的语义标签图对合成前后的图像背景进行掩膜，并将背景像素处理为黑色，以减少背景像素在比较过程中产生的干扰，并减少训练和测试所需的计算量。

### 3.2.1. 置信度引导的差异增强模块

我们使用编码器从输入视频第 `t` 帧中提取特征，然后生成查询图 `q_{t}`。其大小为 `H × W × C`，其中 `H, W` 和 `C` 分别是高度、宽度和通道数。`q_{t}^{k} ∈ ℝ^{C}(k = 1, …, K)` 表示查询图中大小为 `1 × 1 × C` 的单个查询，其中 `K = H × W`。我们还使用内存项，其中包含记录各种正常数据的 `M` 个项目。正常数据由包含人员和商品的正常帧的编码器生成。顾客的正常帧在视频开始时拍摄。我们将内存中的项目标记为

使用 `v_m ∈ ℝ^C (m = 1, ⋯ M)`。我们计算每个查询 `q_t^k` 与记忆中所有项 `v_m` 之间的余弦相似度，以获得大小为 `M × K` 的二维相关性图。通过构建全局 softmax 函数，获得 `q_t^k` 与 `v_m` 匹配的 Probability `w_t^k`。图 3 展示了置信度引导差异增强模块的流程图。

```
w_t^{k,m} = softmax [ exp((v_m)^T q_t^k) / sum_{m'=1}^{M} exp((v_{m'})^T q_t^k) ]  (7)
```

![](img/e4200cc4308edaf8913e513b0f96dbb6_337_0.png)

**图 3.** 置信度引导差异增强模块的示意图。为了读取正常记忆中的项，我们计算查询 `q_t^k` 与项 `v_m` 之间的匹配概率 `w_t^{k,m}`，并对项应用加权平均以获得特征。根据查询 `q_t^k` 的置信度，使用全连接层来改变项的权重。最后，我们将项乘以其权重，并将这些项相加以获得重构查询。

我们在 `hat{q}_t` 上添加了一个全连接层作为网络的置信度分支，用于衡量网络评估的置信水平。当网络置信水平较低时，我们依次反转原始权重 `w_t^{k,m}` 以获得与原图差异更大的特征。通过引导解码器将异常特征导向相似性最小的方向，可以增加差异。变换后的特征图和查询特征被组装到解码器中。公式如下。

```
hat{q}_t^k = { sum_{m'=1}^{M} w_t^{k,m'} v_{m'}   if FC(q_t^k) < δ
               sum_{m'=1}^{M} (1 - w_t^{k,m'}) v_{m'}   if FC(q_t^k) ≥ δ }  (8)
```

为了训练置信度的全连接层，我们仅将正常项输入到全连接层中。我们用 `w_t^{k,m}` 表示正常特征 `q_t^k` 与记忆项 `v_m` 的相似度。我们将 `y` 定义为输入正常特征的目标概率分布。目标概率分布可以为网络提供“提示”。置信度 `c` 表示查询属于记忆项的概率。通过训练，正常特征在全连接网络中获得更高的置信度。公式如下：

```
w_t^{k',m} = (1-c) · w_t^{k,m} + c · y_t^{k,m}  (9)
```

我们使用负对数似然的预测来计算任务损失。为了防止网络总是选择接收整个真值以最小化损失函数，我们添加了一个二元交叉熵损失函数，并使用超参数 `λ` 平衡这两个损失；损失函数如下：

```
L_c = λ( sum_{m=1}^{M} y_i^{k,m} log 1/w_i^{v,m} ) + (1-λ) log 1/c  (10)
```

### 3.2.2. 浅层特征比较

在计算商品损坏特征值的过程中，并非所有异常特征值对判断结果的影响都相等。如果在比较图像的过程中仅比较每个像素的单特征值，计算结果会产生较大误差，这不利于对受损区域的整体理解。这是因为商品异常特征的产生与商品包装的破坏之间存在很强的因果关系。因此，我们综合了选定视频帧前后 `n` 帧中手部节点的变化，并执行了像素级特征向量拼接。我们让相邻两帧节点的横坐标和纵坐标变化分别表示为 `k_{xm}^{p}`，`k_{yn}^{p}`，规定向左和向下移动为负值，其中 `p` 代表手，`m` 是 `n` 帧中的第 `m` 帧。

```
hat{θ} = arctan( sum_{m=2}^{n} K_{xm}^{p}, sum_{m=2}^{n} k_{yn}^{p} )  (11)
```
