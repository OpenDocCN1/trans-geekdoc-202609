# 数据银行 (Data bank)

一种多维数据模型。也称为多维数据库。

# 调试 (Debugging)

用于测试和识别程序中错误的程序。编程错误分为两类：语法和逻辑。

# 数据定义系统 (Data definition system)

该系统使用数据字典定义数据库的逻辑。

# 决策模型 (Decision model)

决策模型为决策系统提供了分析能力。决策模型中包含三类模型：战术、操作和战略。

# 数据字典 (Data dictionary)

包含数据库结构描述的字典。
