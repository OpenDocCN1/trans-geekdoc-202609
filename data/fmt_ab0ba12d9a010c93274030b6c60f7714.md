
如果函数是碗状的（就像这一个一样），那么通往最小值的路径涉及朝着减小梯度的方向移动。函数达到最小值，然后进一步减小。通常情况下，函数在最小值处的斜率为零；在例例中，最小值处的 `(x, y)` 坐标恰好也是 `(0, 0)`，但并不一定如此。

我们现在有了理解最速下降法（也称为梯度下降法）的方法。假设我们位于坐标 `(1, 1)`。我们想到达曲线的底部，那里的斜率为零，函数值最小。在曲线上的任何一点，你只有两条路可以走。走一条会让你远离底部；走另一条会让你靠近底部。朝正确方向迈一步的诀窍在于，首先计算你当前位置的斜率或梯度。（“梯度”一词有更具体的含义，但让我们在此处使用它。）在这种情况下，对于 `x` = 1，梯度是 2。如果函数是碗状的（就像这一个一样），那么通往最小值的路径涉及朝着减小梯度的方向移动。因此，我们迈一步，使 `x` 坐标的值减少某个步长（`η`）乘以该点的梯度：

```
x[new] = x[old] - η * gradient
y[new] = x²[new]
```

让我们花一点时间来看看为什么减小 `x` 值的步骤会减小梯度。对于我们的方程，梯度由 `2*x` 给出。因此，如果 `x` 的新值小于 `x` 的旧值，那么新位置的梯度将比之前低。新的 `x` 坐标给了我们一个新的 `y` 坐标。我们最终到达一个新位置。我们重复这个过程，直到梯度变为零或接近于零。（我们已经到达底部或足够接近底部的地方。）这里有一张描述该过程的图：

![](img/p072_01.png)

步长 `η` 必须是一个很小的数字，一个分数（例如 0.1）。为什么呢？主要是因为当你接近底部时，你必须非常小心，不要越过最小值，导致最终落到曲线另一侧的更高位置。如果你这样做，取决于函数的类型，算法可能会开始带你向曲线的更高处移动，远离最小值。此外，请注意，虽然算法的每次迭代中步长是相同的，但沿着曲线的跳跃幅度在开始时较大，随着你接近底部会变小。再次问，为什么？这是因为我们从 `x` 坐标中减去梯度的倍数来得到新的 `x` 坐标。这个倍数或步长在我们的算法中是不变的。但改变的是梯度：它变得越来越小。因此，沿着曲线的跳跃也逐渐变小。

像上面所示具有单一、定义最小值的函数也被称为凸函数。当我们找到碗的底部时，从技术上说，我们找到了函数的“全局”最小值。（如果一个函数有多个最小值，那么其中每一个被称为“局部”最小值。）

现在考虑最小化涉及两个输入的函数的情况。这里是该函数：

`z = x² + y²`

![](img/p073_01.png)

该图显示了碗状的 3D 表面，称为椭圆抛物面。如果你从碗底方的任何位置开始，就可以很容易地想象沿着该抛物面的表面下降的过程。与 2D 情况的区别在于，我们使用任何位置的梯度来计算新的 `x` 和 `y` 坐标，而不仅仅是 `x` 坐标。（操作相同：从每个坐标中减去梯度乘以某个步长。）这随后给了我们一个新的 `z` 坐标，我们到了表面上的一个新位置。反复执行此操作使我们到达碗的底部。

这是另一个函数，有助于直观理解为什么某些函数可能找不到最小值。

3D 表面由此方程定义：

`z = y² - x²`

这一切听起来可能非常抽象，但梯度下降不仅对 Widrow 和 Hoff 的算法至关重要，对现代机器学习也至关重要。但在将梯度下降与 Widrow 和 Hoff 的工作联系起来之前，我们需要处理一个重要的细节。

再次看这个函数：

`z = x² + y²`

记得当我们有一个变量函数（`y = x²`）时，我们可以使用微积分来确定导数 ![公式内容：dy/dx 等于 2x。](img/p075_01.png) 并使用该值执行梯度下降。但当函数涉及多个变量时，我们该做什么？嗯，有一个整个被称为多元或多变量微积分领域。虽然面对整个多元微积分可能会望而生畏，但我们可以通过关注一些简单的概念来理解它在机器学习中的核心作用。

想象你正站在椭圆抛物面 `z = x² + y²` 表面的某一点。为了确定最陡峭下降的方向，由于我们有两个变量，我们必须关注两个方向。遵循 Thompson 用简单方式表述事情的建议，我们知道沿着表面移动意味着变量 `z` 值的微小变化。因此，我们的任务是分别计算 ![公式内容：z 对 x 的偏导和 z 对 y 的偏导。](img/p075_02.png) 或“`z` 的微小变化除以 `x` 的微小变化”以及“`z` 的微小变化除以 `y` 的微小变化”。

用微积分语言来说，我们是在取 `z` 对 `x` 的偏导以及 `z` 对 `y` 的偏导。对于我们的椭圆抛物面，偏导数为：![公式内容：z 对 x 的偏导等于 2x。公式内容：z 对 y 的偏导等于 2y。](img/p076_01.png)

注意符号的细微变化：使用 `∂x` 代替 `dx`，使用 `∂y` 代替 `dy`。这个符号“`∂`”表示相对于许多变量之一（w.t.）的偏导。为了理解接下来的概念，我们不需要担心如何导出这些解析式。

这里最重要的概念是，对于这个例子，最陡峭下降的方向由两个偏导给出。假设你在这样一个位置：

`x = 3`, `y = 4`，`z = 3² + 4² = 25`

在这个位置，偏导值为：

`2x = 2 × 3 = 6`

`2y = 2 × 4 = 8`

如果你把这些数字写成这种形式，它看起来很熟悉：`[6, 8]`。它是一个向量！

所以，如果你必须沿最陡峭的方向移动，这个方向可以通过向量推断出来。记得向量有一个幅度（长度）和一个方向。在这种情况下，我们的向量是从 `[0, 0]` 指向 `[6, 8]` 的箭头。这个向量被称为梯度。一点技术：梯度远离最小值。因此，为了走向最小值，你必须沿着相反方向迈出一小步，或者沿着梯度的负方向。

如果说这次讨论有什么收获，那就是：对于多维或高维函数（即多个变量的函数），梯度由一个向量给出。向量的分量是该函数相对于每个变量的偏导。

对于我们的椭圆抛物面，梯度写为：

![](img/p077_01.png)

梯度可以写成行向量或列向量。

函数 `f` 取决于三个变量，并在 4D 空间中绘制。我们无法直观地看到它的样子。仅仅通过方程，无法判断该函数是否存在一个我们可以向下下降的全局最小值。但我们可以利用偏导数写出梯度。（再次，我们并不是试图弄清楚具体如何对每个变量对函数求导；假设如果函数可以求导，微积分就会提供答案。你可以使用 Wolfram MathWorld 来查找这些导数。）

![](img/p078_01.png)

现在，给定 `x`、`y` 和 `z` 的一组值，我们可以计算该函数在该点处的梯度，向反方向迈出一小步，并更新 `x`、`y` 和 `z` 的值。如果函数具有全局最小值或局部最小值，通过迭代这一过程我们就能到达那里。我们的分析还连接了两个重要概念之间的纽带：一方面是函数，另一方面是向量。请记住这一点。这些看似互不关联的数学领域——向量、矩阵、线性代数、微积分、概率与统计以及优化理论（我们尚未触及后两者）——在我们理解机器为何学习时，所有这些都将汇聚在一起。

## 神经元的微光

伯纳德·维德罗（Bernard Widrow）从 1956 年的达特茅 AI 会议回来时带着他所说的“心头之患”：构建一种能够思考机器的渴望。“它一直都在，”六十多年后他告诉我，“我从未真正摆脱那个念头。”然而，在 1956 年，年轻的维德罗敏锐地意识到构建思考机器是徒劳的，转而转向更实用的事务。构建自适应滤波器就是这种追求之一。

在信号处理领域，过滤器接收输入信号，对其进行处理并产生具有某些特定属性的输出信号。假设你正在制作某些业余电子设备，需要测量一个信号。但你的信号中混杂着频率为 60 Hz 的干扰嗡嗡声。那是来自交流电源的干扰。过滤器可以接收带有噪声的输入，只移除 60 Hz 的成分，并输出一个干净的信号。这种过滤器很容易设计，因为噪声是为人知的；它始终是 60 Hz。但通常，滤波器需要学习噪声的特性；它需要自适应。

考虑这种自适应滤波器的一个重要应用：数字通信。任何用过拨号调制调器连接互联网的人都会记得调制调器发出的独特声音。首先是拨号音调，然后是拨号数字的音调，接着是哔哔声和断续的尖锐声，在大约二十秒后是沉默。这就是“握手”的声音：两个数字设备正在通过通常用于模拟语音信号的电话线寻找相互通信的最佳方式。数字设备必须传输和接收 0 和 1 的流。但模拟传输线路可能有噪声——因此，你需要一个过滤器来消除可能损坏数据的噪声。这包括消除调制调器可能会听到的自身传输的回声。但为了这些目的构建一个通用的过滤器是不可能的。在两个通信设备的每个实例中，噪声可能是且通常是不同的。握手过程中发生的部分是：

```

```

![](img/p080_01.png)

此误差 `en` 被反馈到过滤器中。自适应滤波器改变自身使误差最小化。名为 `FILTER` 的黑盒具有一些特性或参数，这些参数可以进行调整使过滤器具有自适应性。

你可能会说，如果你知道期望信号，滤波器的意义何在？对于任何通用输入，你不知道期望信号。但有方法知道对于已知输入过滤器应该产生什么。例如，这就是调制调器在握手期间所做的：它们传输一个预先约好的信号，让对方知道预期。这就是期望信号 `dn`。但信号通过嘈杂的传输传输，因此输入 `xn` 只是被噪声污染的 `dn`。但与我们之前看到的 60 Hz 嗡嗡声不同，这种噪声是随机的。接收器需要一个过滤器以 `xn` 为输入并产生尽可能接近期望信号 `dn` 的信号 `yn`。为了做到这一点，算法必须学习噪声的统计特性，以便预测每个时间步的噪声，并实时从 `xn` 中减去它以产生期望信号。

虽然这一切与人工智能和机器学习相去甚远，但我们可以看到机器学习的微光。这种联系——特别是与罗森布拉特的感知器和人工神经元的联系——当我们写下滤波器的细节时，将变得更加明显。

一段关于机器学习（ML）的小型插曲：我们应该如何计算平均误差？仅仅将误差相加来求平均值是不够的；正如我们之前看到的，负误差和正误差会相互抵消，从而给出一个平均误差很低的错误印象。我们可以将误差的绝对值相加并取平均：这被称为平均绝对误差（MAE）。但数学家们更倾向于取误差项平方的平均值，并称之为均方误差（MSE）。事实证明，MSE 具有一些 MAE 不具备的良好统计特性。此外，MSE 在处处都是可微的。（可微函数是指在其定义域内每处都有导数的函数，这个定义域可以是比如 `xy` 平面。）而 MAE 则不是。这也有极大的帮助，我们在训练神经网络时会看到这一点。还有一个值得提及的事实：如果你想让误差估值能够惩罚极端离群值，那么 MSE 比 MAE 做得更好，因为在 MSE 中误差对平均值的贡献随着误差的平方而增加，而在 MAE 中，这种增加是呈线性增长的。

回到滤波器。我们对每个时间步的误差进行平方，将所有平方误差相加，然后求期望值。在概率论中，随机变化事物的期望值（或“期望”）有非常具体的含义，但我们先不用管那个。这里的关键见解是我们需要最小化平方误差的期望值 `E`。我们将该值称为 `J`：

![](img/p084_01.png)

`J` 的值必须最小化。如果你观察联系 `J` 与滤波器参数 `w` 的方程形式，很明显，连接这两者的函数是二次的（这意味着它涉及 `w` 的二次幂）。我们已经见过这种二次函数是凸的（例如 `y = x²` 或 `z = x² + y²`）。因此，当 `J` 最小化时，我们处于某个碗形函数的底部。此时，`J` 的斜率（或梯度）为零。这为我们提供了寻找 `w` 优值的另一种方法。我们可以简单地将 `J` 对 `w` 的梯度置零并求解方程：

![](img/p084_02.png)

1931 年，维纳（Wiener）和德国数学家埃伯哈德·霍普（Eberhard Hopf）利用线性代数技术设计了一种解决此类方程的方法。但这需要关于所有不同时间步输入之间的相关性，以及输入与期望输出之间相关性的先验知识。这些并不是总是已知的，即使已知，计算量也可能非常巨大。此外，维纳的工作是应用于模拟滤波器的。

我们也可以通过最陡下降法来最小化 `J`。为什么呢？嗯，因为它是一个碗形的凸函数，我们总是可以通过迭代沿着通往底部的路径找到使平方误差期望值最小的 `w` 值。因此，无论滤波器是由一个系数（`w0`）、两个（`w0, w1`）、三个（`w0, w1, w2`）还是更多系数描述的，这一结论都成立。最陡下降法将让你找到最小值。但这种方法也有局限性：我们需要能够计算出 `J` 对滤波器系数的偏导数。

还有其他计算方面的考虑。

例如，给定 `xn` 及其对应的 `yn` 以及期望输出 `dn`，可以使用最陡下降法来计算参数（在我们的示例中为：`w0, w1, w2`）。麻烦在于，为了找到参数的优值，你需要越来越多的输入、输出和期望输出样本，而且这些计算所需的时间也越来越长。

此外，考虑到针对某个数据样本计算出的误差并不能代表所有可能的误差，你在每个时间步计算的用于通往最小值的梯度只是一个近似值。有时它指向正确的方向，但大多数时候并不是的。在我们那个沿着梯田山丘走到村庄的类比中，这就像除了要在黑暗中导航外，你还有点醉。你没有沿着最陡峭的路径走到下一个平台，而是胡乱撞撞地走下去。你甚至可能爬到下一个平台。希望如果你步迈得足够小，即使是这种“醉汉步”也能带你到达村庄。在实践中，这种方法的算法确实成功了。这种方法被称为随机梯度下降（SGD），其中“随机”一词是指下降过程中每一步的方向都是微随机的。

这就是威德（Widrow）在离开斯坦福大学之前在麻理工学院所的工作。但在滤波器之外，他还在思考自适应神经元（或神经元件），并意识到训练神经元与训练滤波器并没有区别。

## 与伯尼共过的周末

当特德·霍夫（Ted Hoff）在 1959 年秋季那个命运的日子走进斯坦福大学威德的办公室时，威德开始与他讨论这些想法。“所以，我当时正站在黑板前向特德解释随机梯度和二次碗形……以及自适应滤波器、自适应神经元件以及……谈论如何通过求导得到梯度的分量，”威德告诉我。“我不知道是怎么发生的，但我们想出了一个主意，我们可以得到随机梯度，一个代数上非常粗糙的梯度——不需要对任何东西求导，不需要计算平均值，也不需要平方。”

他们设计的技巧可以应用于自适应滤波器或人工神经元。到目前为止，我们已经学到示例自适应滤波器的输出由下式给出：

`yn = w0.xn + w1.xn1 + w2.xn2`

设计一个自适应滤波器涉及到学习 `w0`、`w1` 和 `w2` 的值。如果你回想起罗森布特的感知机，你会发现它也涉及到学习权重，以便将新数据正确分类为超平面的一侧。罗森布特的算法并不是以梯度下降的形式的。但维纳和霍普的算法是。

下方的图展示了维纳和霍普设计的自适应神经元的思考方式。

神经元产生输出 `y`：

`y = w0x0 + w1x1 + w2x2`

![](img/p087_01.png)

在这里，`x0` 始终为 1；这使得 `w0` 成为偏置项 `b`。实际输入是 `x1` 和 `x2`。它们共同组向量 `x`。系数集合 `w0`、`w1` 和 `w2` 是向量 `w`。因此：

`y = w.x`

⇒ `y = wᵀx`

假设你有几个训练样本，拥有输入及其对应的期望输出（`d`）。那么，自适应神经元对每个输入所犯的误差由：

`error(e) = d − y = d − wᵀx`

## 训练与 LMS 算法

训练神经元涉及每次为其提供一个输入，每个输入代表一个字母。算法利用输入和期望输出来调整其权重并生成正确的输出。但通过改变权重以便为输入字母“T”获得正确输出，可能会导致它在输入字母“J”时出现错误。如果是这样，算法会再次调整权重。当然，现在新的权重可能会导致输入字母“T”时出现错误。你重复这个过程，并一直持续，直到神经元对字母“T”正确输出 1，对字母“J”正确输出 -1。可以使用最陡下降法来训练神经元。

假设你有一组训练样本：输入及其对应的输出。如果你计算了神经元对所有输入样本所产生的误差，并将误差平方的期望值作为所有权重（或系数）的函数绘图，你将得到一个碗形函数（当然，是在我们无法可视的高维空间中）。然后，你可以使用最陡下降法来最小化期望值。在每一步中，你计算函数对每个权重的梯度，然后通过向相反方向迈出一小步（朝向最小值）来修改权重。

```
w[new] = w[old] + μ(-Δ)
```

*其中*：

* `μ` = 步长

* `Δ` = 梯度

回想我们之前的讨论，梯度仅仅是一个向量，其中每个元素都是均方误差 `J` 对每个权重的偏导数。

该向量的每个元素都将是一个可以使用微积分规则计算的解析表达式。一旦你有了这些表达式，只需代入权重的当前值即可得到梯度，然后你可以用它来计算新权重。问题在于：你需要用到微积分，虽然我们的梯度只有三个元素，但在实践中，它的元素数量可能是几十、数百、几千甚至更多。Widrow 和 Hoff 想要寻找某种更简单的方法。这就是他们想出的办法：

```
w[new] = w[old] + μ(-Δ[est])
```

他们决定不计算整个梯度，而是只计算它的估计值。这个估计值仅基于一个数据点。它不涉及计算误差平方的期望值。相反，他们只是对其进行估计。但根据单个样本来估计统计参数通常是不可忌的。尽管如此，Widrow 和 Hoff 还是采用了它。通过少量的分析，

```
w[new] = w[old] + 2μεx
```

*其中*：

* `μ` = 步长

* `ε` = 基于单个数据点的误差

* `x` = 代表单个数据点的向量

误差本身由下式给出：

```
ε = d - w^T x
```

这是简单的代数。基本上，对于每个输入，你计算误差并利用它来更新权重。
