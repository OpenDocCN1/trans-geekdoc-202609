## 4.4 建议方案的运行模式

在我们的方案中，CSP 支持两种运行模式：优先模式和常规模式。在优先模式下，CSP 没有足够的能量供应来满足 EV 当前的充电需求。因此，它对请求进行优先级排序，并在不超过总能量供应的前提下为高优先级请求充电。在同一优先级内，请求按先到先充（FCFC）顺序服务。多授权 ABE 用于保护优先级确定过程 [6]。在常规模式下，CSP 拥有足够的能量供应以满足所有传入的充电请求。下一节将解释每种运行模式下使用的协议。

## 4.4.1 建议方案的优先模式

在此模式下，CSP 应首先通过使用多授权 ABE 向 EV 发起挑战来确定 EV 的充电优先级。思路是 CSP 使用多授权 ABE 发送加密消息。然后，只有拥有给定优先级所需密钥的 EV 才能解密挑战消息。接着，每个 EV 应发送解密消息的证明以获得相应的优先级。最后，CSP 在不超过能量供应的前提下为最高优先级请求充电，并对具有相同优先级的 EV 使用 FCFC 程序。确定优先级的详细步骤概述如下：

- **1. CSP 的挑战**：从 CSP 向 EV 发送挑战是优先级确定过程的第一步。最初，CSP 利用来自多个属性授权机构的属性创建不同优先级的优先级策略。然后，CSP 广播这些优先级策略及相应的挑战（ABE）以及 EV 可充电的最大能量量。挑战的格式为 `challenge_p = CT_p, TS, Sig(CT_p, TS)`，其中 `TS` 为时间戳，`Sig(CT_p, TS)` 为 CSP 对密文 `CT_p` 的签名。

为了计算优先级策略的密文，CSP 对不同优先级加密不同的消息 `g_t^{r_p}`，其中 `g_t ∈ G_T`，`r_p \stackrel{R}{\leftarrow} Z_p^*` 为 CSP 为每个优先级 `p` 选择的随机元素，且 `{1 ≤ p ≤ N}`，`N` 为优先级数量。对于每个优先级，CSP 创建一个访问策略 `(A, δ)`，其中 `A ∈ {Z_p^*}^{l×n}`，`l` 为该访问矩阵的行数，`δ` 为将访问矩阵的行映射到属性的函数。`ρ` 为将属性映射到其授权机构的另一个函数 `ρ: [l] → U_θ`，即 `{ρ(·): T(δ(·))}`。为加密消息 `g_t^{r_p}`，CSP 需要相关属性授权机构的公钥和公共参数。CSP 首先创建两个随机向量 `v = (z, v_2, ..., v_n)^T` 和 `w = (0, w_2, ..., w_n)^T`，其中 `{z, v_2, ..., v_n, w_2, ..., w_n}` 为从 `Z_p^*` 中随机选择的元素。我们用 `λ_x` 表示对应于第 `x` 行的随机秘密 `z` 的份额，即 `λ_x = (A_x · v)`；`w_x` 表示 0 的份额，即 `w_x = (A_x · w)`，其中 `A_x` 为访问矩阵 `A` 的第 `x` 行。然后，CSP 为每一行选择一个随机元素 `t_x \stackrel{R}{\leftarrow} Z_p^*` 并计算密文 `CT_p` 如下：

```
C0 = g_t^{r_p} · e(g, g)^z;
{C1,x = e(g, g)^{λ_x} e(g, g)^{a_{ρ(x)} t_x}, C2,x = g^{-t_x}, C3,x = g^{y_{ρ(x)} t_x} g^{w_x}; C4,x = F(δ(x))^{t_x}, x∈[l].
```

以相同的方法，CSP 为每个优先级创建具有不同策略的不同密文，然后广播不同优先级的挑战。

## 2. EV 的响应。为了获得优先充电服务，每个 EV 需要检查优先级策略，确定其属性是否能满足某个优先级，然后解密相应的密文以向 CSP 证明其优先级，如图 6 所示。每个 EV 使用其密钥解密相应的密文，并利用解密出的消息 `g_t^{r_p}` 计算会话密钥。然后，EV 使用会话密钥加密解密出的消息，作为拥有相应优先级的证明。

EV 接受策略 `(A, δ)` 和相应的密文 `(CT)`，并使用其密钥 `(K_{GID,u}, K'_{GID,u})` 针对访问矩阵中满足属性的行子集 `A_x`，然后对每一行 `x`，EV 计算：

```
C1,x · e(K_{GID,δ(x)}, C2,x) · e(H(GID), C3,x) · e(K'_{GID,δ(x)}, C4,x) = e(g, g)^{λ_x} · e(H(GID), g)^{w_x}
```

接着，它计算常数 `c_x ∈ Z_p` 使得 `Σ_x c_x A_x = (1, 0, ..., 0)` 并计算：

```
Π_x e(g, g)^{λ_x} · e(H(GID), g)^{w_x}^{c_x} = e(g, g)^z.
```

这成立是因为 `λ_x = (A_x · v)` 且 `w_x = (A_x · w)`，其中 `⟨(1, 0, ..., 0) · v⟩ = z` 且 `⟨(1, 0, ..., 0) · w⟩ = 0`。消息可解密为 `g_t^{r_p} = C0 / e(g, g)^z`。EV 使用接收到的消息 `g_t^{r_p}` 与 CSP 计算会话密钥 `k = g_t^{r_i · r_p}`，其中 `r_i ∈ Z_p^*` 为 `EV_i` 选择的随机数。EV 发送 `H_k(g_t^{r_p})`、`g_t^{r_i}` 给 CSP，CSP 将用其建立会话密钥。`H_k(g_t^{r_p})` 作为 EV 正确解密了基于属性加密挑战的证明。此外，EV 还应发送其所需的充电能量量。
