
从这个角度来看，很容易理解为什么在增加更多层时，训练误差不应该增加。在最坏的情况下，当所有信息都已提取到第 `r` 层时，我们预期增加一层额外的层应该实现恒等映射，即 `y^(r) = H(y^(r-1)) = y^(r-1)`。也就是说，额外的层不添加任何信息，只是将输入简单地复制到输出。然而，一旦网络变得非常深，准确率似乎会“饱和”，优化工具很难在可行的时间内找到足够精确的恒等映射解。

![Figure 18.32 When a network is very deep, it turns out that the training error starts increasing when the number of layers exceeds some number, instead of being decreased (red curve) as expected from theory.](img/gr032.jpg)

**图 18.32** 当网络非常深时，训练误差会在层数超过某个数值时开始增加，而不是像理论预期的那样减小（红色曲线）。

绕过这一困难的一种方法在文献 [67] 中提出。其思路是拟合一个替代的等效映射，即

`F(y^(r-1)) = H(y^(r-1)) - y^(r-1)`。

于是原始映射 `H(y^(r-1))` 就等于 `F(y^(r-1)) + y^(r-1)`。实践表明，针对残差映射 `F` 进行优化比针对原始映射 `H` 进行优化更容易。在极端情况下，当需要实现恒等映射时，似乎将残差推向零比拟合恒等映射更容易。

残差表示的使用并非新事物，之前已在矢量量化的背景下使用过。残差学习的核心在于引入所谓的*残差*构建模块，如**图 18.33**所示。这样，若干层（如图所示为两层）被堆叠在一起，并通过所谓的捷径连接或跳跃连接，*显式地*让这些层去拟合残差映射。每个权重层对其输入执行变换，例如卷积。如果 `y^(r)` 和 `y^(r-1)` 维度不同，则恒等映射捷径会被修改为 `W y^(r-1)`，其中 `W` 是一个维度合适的矩阵。

**图 18.33** 网络中的两个连续层被组合在一起，它们隐含的组合变换通过恒等映射来执行，由红线捷径/跳跃连接实现。

**图 18.34**A 示出了一个所谓的纯净网络（不涉及残差）的示意图示例，该网络由一系列卷积层组成。其残差对应版本如**图 18.34**B 所示。注意，如果使用恒等捷径，则不涉及额外参数，训练遵循标准的反向传播原理。残差网络的一种变体，称为*高速公路*网络，已被提出（例如 [60,184]），其中引入了额外的数据依赖门控函数来控制捷径中的信息流动。

### DenseNet

正如之前所解释的，ResNet 由一系列连接的残差块组成。这样，一层不仅接受来自其直接前驱层的输入，还通过快捷（跳跃）连接接受来自更早一层的输入，并将这两者相加。相比之下，在 DenseNet [83] 中，构建模块是所谓的密集块，它们将多个层组合在一起，且块内的每一层都接收来自块内*所有*前面层的输入。此外，这些输入不是相加，而是拼接在一起。报告的结果表明，通过这种方式，可以在不牺牲性能的前提下减少涉及的操作数和参数量。尝试的层数高达 250 层。

## 18.13 循环神经网络

回顾上一节，卷积网络的核心在于权重共享的概念。也就是说，同一个滤波器矩阵在图像数组上滑动，而不是为每个图像像素分配特定的权重。这样，神经网络可以轻松扩展到不同维度的图像。

本节的关注点转向*序列*数据的情况。即输入向量不是独立的，而是按顺序出现的。而且，它们出现的具体顺序包含了重要信息。例如，此类序列出现在语音识别和语言处理中，如机器翻译。毫无疑问，单词出现的顺序至关重要。动态图模型，如卡尔曼滤波和隐马尔可夫模型（HMM），已在 **第 16 章** 和 **第 17 章** 中介绍，它们是处理序列数据的模型。

通过卷积进行权重共享也可用于此类情况（参见 [110]）。这类网络被称为*时延*神经网络。然而，跨时间滑动滤波器以执行卷积是一种局部性质的操作。输出是滤波器冲激响应长度所跨越的时间窗口内输入样本的函数，出于实际原因，该长度不能太长。

为了克服上述有限记忆的缺点，本节重点关注建立在*状态*概念之上的网络。就像 HMM 和卡尔曼滤波一样，状态向量“编码”了*直到*当前时刻 `n` 的过去历史。*循环神经网络*（RNN）背后的思想是在每个时刻应用*相同*类型的操作（权重共享，这证明了“循环”术语的合理性），同时涉及*当前状态*（过去历史）以及当前*输入*的值。这样，网络可以很好地扩展到不同长度的序列；这是因为不在不同时刻分配特定权重，而是在整个时间轴上共享相同的权重。

RNN 涉及的变量有：

*   时间 `n` 的状态向量，记为 `h[n]`。
    该符号提醒我们 `h` 是隐变量向量（神经网络术语中的隐藏层）；状态向量构成了系统的*记忆*，
*   时间 `n` 的输入向量，记为 `x[n]`，
*   时间 `n` 的输出向量，`ŷ_n`，以及目标输出向量 `y[n]`。

该模型通过一组未知参数矩阵和向量来描述，即 `U`、`W`、`V`、`b` 和 `c`，它们必须在训练过程中学习，这类似于 HMM 中的未知参数，也在训练过程中学习。

描述 RNN 模型的方程为：

```
h[n] = f(U * x[n] + W * h[n-1] + b)
y_hat[n] = g(V * h[n] + c)
```

其中非线性函数 `f` 和 `g` 逐元素作用，并单独应用于其向量参数的每个元素。简而言之，一旦观测到新的输入向量，状态向量就会更新。其新值取决于最新信息，该信息由输入 `x[n]` 传递，以及累积在 `h[n-1]` 中的过去历史。输出取决于更新后的状态向量 `h[n]`。也就是说，它取决于直到当前时刻 `n` 的“历史”，这由 `h[n]` 表示。

注意方程 (18.67) 和 (18.68) 与 **第 4 章** 中定义的扩展卡尔曼滤波非常相似。然而，请注意，在当前情况下，涉及的矩阵和向量 `U`、`W`、`V`、`b` 和 `c` 是未知的，必须被学习。这种在扩展卡尔曼滤波背景下看待 RNN 的观点已在 [29] 中采用。`f` 的典型选择是双曲正切函数 `tanh` 或 `ReLU` 非线性函数。初始值 `h[0]` 通常设为零向量。输出非线性函数 `g` 通常选择为 公式 (18.45) 中引入的 `softmax` 函数。

从上述方程可以看出，参数矩阵和向量在所有时间点都是*共享*的。在训练期间，它们通过随机数进行初始化。与方程(18.67)和(18.68)相关的图模型如图 18.35A 所示。在图 18.35B 中，图在有观测值的各个时间点上被*展开*。例如，如果感兴趣的序列是一个包含 10 个单词的句子，则 `N` 设置为 10，而 `x[n]` 是对相应输入单词进行编码的向量。

![Figure 18.35 (A) The input, x, “feeds” the (hidden) state, h, which is updated using also its previous value (self-loop in the graph). In turn, it generates the output, \widehat{\mathbf{y}}Equation. (B) The operations involved in an RNN as time evolves are shown, starting from an initial value h0 of h. ### 18.13.1 通过时间的反向传播

训练 RNN 遵循与 **第 18.4.1 节** 中讨论的用于训练前馈神经网络的反向传播算法相似的基本原理。毕竟，RNN 可以被视为一个具有 `N` 层的前馈网络。顶层是时间点 `N` 处的层，第一层对应时间 `n` = 1。一个区别在于 RNN 中的隐藏层也会产生输出，即 `ŷ_n`，并直接由输入馈送。然而，就训练而言，这些差异不影响主要基本原理。

通过梯度下降方案学习未知的参数矩阵和向量，这与方程(18.10)和(18.11)一致。结果表明，代价函数关于未知参数所需的*梯度*通过从*最晚*时间点 `N` 开始，并*逆时间*向后 `n` = `N` - 1, `N` - 2, ..., 1 递归地进行。这就是该算法被称为*通过时间的反向传播*（BPTT）的原因。

代价函数是时间 `n` 上相应损失函数贡献之和，这些贡献取决于 `h[n]`、`x[n]` 的相应值，即

```
$J(U,W,V,\mathbf{b},\mathbf{c}) = \sum\limits_{n = 1}^{N}J_{n}(U,W,V,\mathbf{b},\mathbf{c}).$
```

例如，对于交叉熵损失函数情况，

```
$J_{n}(U,W,V,\mathbf{b},\mathbf{c}) := - \sum\limits_{k}y_{nk}\ln{\widehat{y}}_{nk},$
```

其中求和是针对 `y` 的维度进行的，

$$

\widehat{\mathbf{y}}_n = g(\mathbf{h}_n, V, \mathbf{c}) \quad \text{and} \quad \mathbf{h}_n = f(\mathbf{x}_n, \mathbf{h}_{n-1}, U, W, \mathbf{b}).

$$

![Equation](img/si476.png)

结果表明，计算代价函数关于各个参数矩阵和向量的*梯度*的核心，在于计算 `J` 关于*状态向量* `h_n` 的梯度。一旦计算出后者，关于未知参数矩阵和向量的其余梯度就很容易得出。为此，请注意每个 `h_n`（`n = 1, 2, ..., N-1`）以两种方式影响 `J`：

*   **直接地**，通过 `J_n`，
*   **间接地**，通过 RNN 结构施加的*链*影响，即：
    `h_n → h_{n+1} → ... → h_N`。

![Equation](img/si479.png)

也就是说，除了 `J_n` 之外，`h_n` 还影响所有后续的代价值 `J_{n+1}, ..., J_N`。

##### 梯度消失与梯度爆炸

梯度消失与梯度爆炸的任务已在 **18.6 节** 中引入并讨论，背景是反向传播算法。同样的问题也存在于 BPTT 算法中。毕竟，后者是反向传播概念的一种特定形式，而且如前所述，RNN 可以被视为一个多层网络，其中每个时间瞬间对应不同的一层。事实上，在 RNN 中，梯度消失/爆炸现象以一种相当“激进”的方式出现，考虑到 `N` 可以取很大的值。

梯度传播的乘法性质可以在公式 (18.69) 中清晰地发现。为了帮助读者掌握主要概念，让我们简化设定，假设只涉及一个状态变量。那么状态向量变为标量 `h[n]`，矩阵 `W` 变为标量 `w`。此外，假设输出也是标量。那么公式 (18.69) 中的递归简化为：

$$

\frac{\partial J}{\partial h_{n}} = \frac{\partial h_{n + 1}}{\partial h_{n}}\frac{\partial J}{\partial h_{n + 1}} + \frac{\partial\widehat{y}_{n}}{\partial h_{n}}\frac{\partial J}{\partial\widehat{y}_{n}}.

$$

###### 长短期记忆（LSTM）网络

LSTM 网络背后的关键思想，源自开创性论文 [77] 的提出，即所谓的*单元状态*，它有助于克服网络内部长期依赖导致的梯度消失/爆炸现象相关问题。

####### 梯度流的数学分析

假设公式 (18.67) 中的 `f` 为标准 tanh 函数，并利用已知表^[120] 中其对应的导数：

```
∂h_{n+1}/∂h_n = w(1 - h_{n+1}²)
```

根据 tanh 函数的定义，`h[n+1]` 的幅值小于 1。写出两个连续步骤的递推关系，可得：

```
∂J/∂h_n = w²(1 - h_{n+1}²)(1 - h_{n+2}²) ∂J/∂h_{n+2} + 其他项。
```

不难看出，小于 1 的项相乘会导致数值消失，特别是考虑到实际中序列可能相当长，例如 `N` = 100。因此，对于接近 `n` = 1 的时刻，公式 (18.70) 右侧第一项对梯度的贡献将涉及大量幅值小于 1 的数的乘积。另一方面，`w` 的值将以 `w^n` 的幂次形式起作用。因此，如果其值大于 1，会导致相应梯度出现爆炸值（参见，例如 [154]）。

####### 缓解技术

在许多情况下，可以将反向传播算法*截断*至几个时间步。另一种方法是将 tanh 非线性替换为 ReLU。针对数值爆炸的情况，可以引入*裁剪*技术，一旦数值超过预设阈值，即将其裁剪至该阈值。

然而，另一种在实践中常用的技术是用替代结构取代前面描述的标准 RNN 公式，这种结构能更好地应对由长期依赖引起的此类现象。
