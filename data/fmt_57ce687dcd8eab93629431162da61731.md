### 逻辑回归

#### 逻辑方程

逻辑回归适用于目标变量。以下是方程：

```
Logit(Y) = log(p / (1 - p)) = β0 + β1x1 + β2x2 + ... + βnxn + ε
```

其中：

* `Y` 是目标变量
* `p` 是概率
* `x[1]` 到 `x[n]` 是预测变量
* `β[0]` 是截距
* `β[1]` 到 `β[n]` 是回归系数
* `ε` 是残差

该方程的另一种便于解释的形式是几率比：

$$Odds\left( Y \right) = \left( \frac{p}{1 - p} \right) = e^{(β0 + β1x1 + β2x2 + ... + βnxn + ε)}$$

#### 估计方法

逻辑回归系数的方法与线性回归不同。估计方法是极大似然估计（MLE）。简单来说，我们首先假设目标变量的概率分布，然后我们使用似然函数来计算概率。

#### 假设要求

正如所解释的，由于 MLE 的性质，逻辑回归不需要正态性、同方差性和线性等严格假设。通常情况下，逻辑回归具有以下假设：

* **二分类目标变量**：目标变量必须是二分类的，即有两个不同的类别。例如，1——发生事故；0——无事故。
* **多个预测变量**：逻辑回归需要多个预测变量。然而，它不需要连续预测变量，可以很好地处理二分类或分类变量。基本上对预测变量的尺度没有限制。
* **线性**：预测变量与目标变量的 logit 值之间存在线性关系。

此外，逻辑回归有一些与该方法相关的模型拟合度指标。这些指标与线性回归的模型拟合指标非常相似。表 7.15 总结了这些回归方法之间的模型拟合度指标。因此，我们可以看到这些方法之间等效的模型拟合指标。

表 7.15 线性回归与逻辑回归的特定拟合度指标

| 线性回归 | 逻辑回归 |
| --- | --- |
| 总平方和 (SST) | 基准模型的 `−2LL` |
| 残差平方和 (SSE) | 提议模型的 `-2LL` |
| 回归平方和 (SSR) | 基准与提议模型之间 `-2LL` 的差值 |
| 模型拟合的 F 检验 | 基准与提议模型之间 `-2LL` 差异的卡方检验 |
| 决定系数 (R²) | 伪 R² 指标 |
| *来源*: Hair 等人，2019 | |

卡方检验和伪 R² 是逻辑回归的特定指标。为了理解 `-2LL` 差异的卡方检验，我们需要先理解 `-2LL`。因此，我将 `-2LL` 的描述包含在表 7.16 中。

表 7.16 推荐的逻辑回归特定指标

| 逻辑回归指标 | 描述 |
| --- | --- |
| `-2LL` (`−2 Log Likelihood`) | 衡量模型与似然度的拟合程度。良好模型的特征是观测结果的似然度较高或 `-2LL` 较低。在模型完美拟合数据的理想情况下，似然值达到 1，`-2LL` 分值变为 0。 |
| `-2LL` 差异的卡方检验 | 逐步回归过程中两个模型之间 `-2LL` 的差值。我们期望得到显著的卡方检验结果，这表明建模步骤有所改进。 |
| 伪 R² | 与始终预测平均值的模型相比，衡量模型与数据的拟合优劣。两种最常见的伪 R² 是：<br>• McFadden 的 R²<br>• Cox & Snell R²。注意，伪 R² 的范围不是 0 到 1，因为它的上限要低得多。因此，通俗规则是伪 R² 在 0.2 到 0.4 之间被认为拟合良好。 |

### 模型选择方法

在逻辑回归中，我们也有之前描述的三种逐步方法。它们包括向前逐步、向后逐步和自适应逐步。虽然逻辑回归使用的是二目标变量而不是连续变量，但它也使用了相同逐步方法。因此，我建议从自适应逐步法开始选择变量，因为它允许我们找到产生良好模型拟合的预测变量最佳组合。

### 如何阅读和理解逻辑回归结果？

再次，在尝试解释逻辑回归结果之前，我们需要确保模型拟合良好。假设我们已经检查了逻辑回归的模型拟合指标，包括 `-2LL`、`-2LL` 的卡方检验、伪 R²、`RMSE`、`RSE`、`EP`、误分类率、准确率、敏感性、特异性、F1 分数、Gini 系数、`LOC chart` 和 `Lift chart`，并且我们发现模型拟合令人满意。下一步是解释逻辑回归结果，以识别显著的预测变量及其对目标变量的影响。

通常，逻辑回归的估计结果包括：

* 逻辑系数 (`B`)
* 标准误
* `Wald statistic`：系数显著性检验
* 自由度
* 显著性值 (`p-value`)
* `Exp(B)` 或优势值比
* `Exp(B)` 的 95% 置信区间

我们关注有助于我们解释结果的重要输出内容。由于使用了 `logit` 函数，逻辑回归的结果更难阅读和理解。为了理解估计结果，我们将主要关注显著性值、逻辑系数和优势值比。例如，假设我们为目标变量为学生选择 A 专业的示例发现了以下回归方程：
