
## 问题 471。
在某公司中心数据库最近遭受网络攻击后，IT 部门被赋予增强网络基础设施安全的任务。以下哪种技术是确保不同部门（如人事和财务部门）无法访问对方敏感数据的**最佳**技术？

- (A) 实施基于部门的网络分
- (B) 升级整个网络的带宽
- (C) 为所有部门使用单一强密码
- (D) 将所有部门数据移动到云端

### 解析 471。
**正确答案：A。实施基于部门的网络分。** 网络分将网络划分为多个段或子网，每个段充作为一个独立的小型网络。这限制了段与段之间的访问，并通过确保只有段内的人员可以访问其资源来保护敏感数据。

**选项 B 错误。** 虽然升级带宽可能会提高网络速度，但它没有解决部门数据隔离的安全问题。

**选项 C 错误。** 为所有部门使用单一强密码不能防止一个部门访问另一个部门的数据。它还引入了单点故障。

**选项 D 错误。** 将数据移动到云端可以提供一些安全优势，但如果没有适当的访问控制和分，不同部门仍然可以访问对方的数据。

## 问题 472。
财务部门员工 Maya 调到了人事部门。IT 部门正在考虑她的访问需求。以下哪种操作最符合**最小权限原则**？

- (A) 保留 Maya 对财务系统的访问权限，并授予对人事系统的额外访问权限
- (B) 移除所有之前的访问权限，并仅提供其对人事系统的访问权限
- (C) 授予 Maya 管理员权限，以方便她在部门之间的转换
- (D) 在过渡期内将 Maya 对财务和人事系统的访问权限限制为只读

### 解析 472。
正确答案：B。移除所有之前的访问权限，并仅提供其对人事系统的访问权限。

当员工从一个部门转到另一个部门时，他们的访问需求会发生。为了遵循最小权限原则，重新评估并调整访问权限至关重要，Maya 不再需要访问财务系统，应该只访问其人事部门新职位所需的资源。

**选项 A 错误。** 当 Maya 不再该部门工作时，保留对财务系统的访问权限是没有必要的，并且可能带来安全风险。

**选项 C 错误。** 授予管理员权限是过度的，并且将为 Maya 提供比其新职位需求更多的访问权限。

**选项 D 错误。** 虽然只读访问限制了潜在的损害，但如果 Maya 的新职位只需要访问人事系统，那么为两个系统提供访问权限是不必要的。

## 问题 473。
一家金融机构 BankCorp 最近经历了针对其员工的钓鱼攻击激增。这些攻击通常涉及与合法 URL 相似但有细微差异的 URL。为了减少员工意外访问这些恶意网站的风险，BankCorp 应该实施哪种措施？

- (A) 实施域名系统（DNS）防火墙
- (B) 采用 URL 扫描来识别并拦截恶意 URL
- (C) 依靠员工手动报告可疑 URL
- (D) 使用虚拟专用网络（VPN）重定向员工的网络流量

### 解析 473。
正确答案：B。采用 URL 扫描来识别并拦截恶意 URL。URL 扫描通过检查完整 URL 并与已知的恶意 URL 或模式对比，识别潜在的恶意网站。这种方法可以阻止访问设计成与合法 URL 相似的 URL。

**选项 A 错误。** 虽然 DNS 防墙可以帮助访问恶意域名，但 URL 扫描通过检查完整 URL（不仅仅是域名）提供了更细粒度的控制。

**选项 C 错误。** 仅依赖员工的手动报告可能不如自动 URL 扫描那样高效有效。这还会给员工识别每个恶意 URL 带来不当责任。

**选项 D 错误。** 使用 VPN 只是更改流量路由并提供加密通信。它本身不提供 URL 扫描功能。

## 问题 474。
某制造公司的 IT 团队正在部署一套基于 IoT 的机械监控系统。他们希望确保这些 IoT 设备即使受到攻击也不会影响其主公司网络。他们应该实施什么来实现这一点？

- (A) 在所有 IoT 设备上安装杀病毒软件
- (B) 定期修补和更新设备固件
- (C) 将 IoT 设备放置在专用 VLAN
- (D) 为 IoT 设备启用多身份认证

### 解析 474。
正确答案：C。将 IoT 设备放置在专用 VLAN。将 IoT 设备放置在专用 VLAN（虚拟局域网）提供了网络隔离，确保设备与主公司网络分离。这种策略确保了即使 IoT 设备受到攻击，也不会对网络系统造成直接威胁。

**选项 A 错误。** 许多 IoT 设备不支持传统的杀病毒软件，即使支持，也没有实现所需的隔离。

**选项 B 错误。** 虽然定期修补和更新设备固件对于安全性至关重要，但它并没有提供与主公司网络的隔离。

**选项 D 错误。** 启用多身份认证可以增强设备安全性，但没有提供场景中指定的网络隔离。

## 问题 475。
某零售公司的内容过滤日志显示多次拦截了 `.exe` 访问，指向以 `.exe` 结尾的文件下载 URL。源 IP 地址属于一个销售点 (POS) 终端。安全团队首要关注的问题应该是？

- (A) POS 终端可能软件过旧
- (B) 内容过滤规则可能存在配置错误
- (C) POS 终端可能已被入侵并正尝试下载恶意执行文件
- (D) 公司的互联网速度太慢

解析 475. 正确答案：C。POS 终端可能已被破解，并正尝试下载恶意执行文件。POS 终端不应从互联网下载可执行文件，尤其是在没有管理监督的情况下。多次尝试下载“.exe”文件可能表明 POS 终端已被破解，且恶意软件正尝试下载更多载荷。

选项 A 错误。虽然软件过时是一个安全隐患，但它不会表现为多次被阻止的可执行文件下载尝试。

选项 B 错误。内容过滤规则的配置错误可能会拦截合法内容，但无论内容过滤规则如何，POS 终端尝试下载可执行文件的特定行为都是可疑的。

选项 D 错误。公司的网络速度与过滤系统拦截的具体内容无关。

## 问题 476。
某公司希望实施一种解决方案，在允许远程服务器连接到主网络之前，验证其软件完整性。以下哪种解决方案最能通过**证明（attestation）**实现这一目标？

- (A) 基于主机的防火墙
- (B) 白名单应用
- (C) 远程证明 (Remote attestation)
- (D) VPN 隧道

解析 476. 正确答案：C。远程证明。远程证明是一个过程，其中设备（如服务器）向远程实体（如网络控制器）证明其运行的是正版且未经修改的软件。它允许在远程设备连接到主网络之前验证其软件完整性。

选项 A 错误。基于主机的防火墙用于根据一组可配置的规则控制进出设备的入站站网络流量。它不验证设备本身的软件完整性。

选项 B 错误。白名单应用仅允许指定的软件在系统上运行。虽然它可以通过确保只运行批准的软件来增强安全性，但它无法在连接到另一个网络时证明设备或其软件的状态或完整性。

选项 D 错误。VPN 隧道加密了互联网上两点之间的连接。虽然它确保了通信的安全，但它并不验证设备的软件完整性。

## 问题 477。
ABC Tech 拥有包含 Linux 和 Windows 服务器的混合环境。他们希望确保运行在 Linux 服务器上的进程仅具有特定资源的权限，并限制其执行某些操作。以下哪种工具最适合此任务？

- (A) 在其 Windows 服务器上使用组策略并将其应用于 Linux 服务器
- (B) 实施严格的用户培训方案，向用户介绍安全最佳实践
- (C) 在强制模式（enforcing mode）下启用安全增强 Linux (SELinux)
- (D) 限制用户对 Linux 服务器的访问

解析 477. 正确答案：C。在强制模式下启用安全增强 Linux (SELinux)。SELinux 通过限制进程可以的操作仅限于其策略中定义的操作来提供强制访问控制，确保其仅访问特定资源。通过将 SELinux 设置为强制模式，这些策略将得到积极执行。

选项 A 错误。组策略是 Windows 特有的，无法直接应用于 Linux 服务器。

选项 B 错误。虽然用户培训是一项良好的安全实践，但它无法提供限制 Linux 服务器上进程所需的强制控制。

选项 D 错误。限制用户对 Linux 服务器的访问无法直接控制在这些服务器上的进程的操作。

## 问题 478。
安全分析师 Liam 正在调查一起潜在的入侵。他发现恶意攻击者通过更改 HTTP Header来伪装另一个用户向服务器发送请求，从而获得授权的访问。这属于哪种应用程序攻击？

- (A) 跨站请求伪造 (CSRF)
- (B) 跨站脚本攻击 (XSS)
- (C) HTTP Header 伪造
- (D) 会话劫持 (Session Hijacking)

解析 478. 正确答案：C。HTTP Header 伪造。HTTP Header 伪造涉及操纵请求中的 HTTP Header 以伪装、欺骗或干扰系统，通常通过绕过安全控制或伪装其他用户。在描述的场景中，恶意攻击者通过更改 HTTP Header 来伪装另一个用户，这表明 HTTP Header 伪造攻击。

选项 A 错误。跨站请求伪造 (CSRF) 涉及在用户不知情的情况下触发其在已认证的 Web 应用程序上执行操作。虽然它涉及伪造，但不涉及描述所示的直接操纵 HTTP Header。

选项 B 错误。跨站脚本攻击 (XSS) 涉及向其他用户查看的 Web 内容注入恶意脚本。该场景不涉及注入脚本。

选项 D 错误。会话劫持涉及接管用户的会话以执行未经授权的操作。它并不专门涉及 HTTP Header 的操纵。

## 问题 479。
ABC Corp 最近由于承包商将受感染的笔记本电脑连接到公司网络而面临安全泄露。管理层希望实施解决方案，确保任何连接到公司网络的设备都符合公司的安全标准，包括最新的防病毒定义。ABC Corp 应该考虑哪种解决方案？

- (A) 入侵检测系统 (IDS)
- (B) 虚拟私网络 (VPN)
- (C) 网络访问控制 (NAC)
- (D) Web 应用防火墙 (WAF)

解析 479. 正确答案：C。网络访问控制 (NAC)。网络访问控制 (NAC) 允许组织为设备连接到公司网络设置策略。NAC 可以在设备连接之前评估其安全态是否符合预定义的标准（例如更新防病毒定义、所需的补丁）。

选项 A 错误。入侵检测系统 (IDS) 监控网络流量的可疑活动并发出警报，但在允许网络访问之前评估设备安全态。

选项 B 错误。虚拟私网络 (VPN) 允许对网络的安全远程访问，但本身不评估设备的安全态。

选项 D 错误。Web 应用防火墙 (WAF) 专注于通过监控和过滤 HTTP 流量来保护 Web 应用程序。它不用于评估设备安全态。

## 问题 480。
CyberFirm 一直面临钓鱼攻击问题，攻击者伪造他们的域名来发送欺诈邮件。他们已经实现了 DKIM 来对邮件签名，但希望增加额外措施来指定哪些邮件服务器授权代表他们的域名发送邮件。CyberFirm 应该采用哪种安全措施？

- (A) SPF
- (B) PGP
- (C) SSL 证书
- (D) IMAP

解析 480. 正确答案：A。SPF。发送者策略框架 (SPF) 用于防止电子邮件伪造。它允许域所有者指定哪些邮件服务器授权代表其域名发送邮件。接收服务器随后可以根据域名 DNS 中的 SPF 记录验证发送服务器。

选项 B 错误。PGP (Pretty Good Privacy) 用于加密和解密文本、电子邮件、文件、目录和整个磁盘分区，但它没有为域名定义授权的邮件服务器。

选项 C 错误。SSL 证书为用户 Web浏览器与网站之间提供安全连接，确保数据机密性。它不是专门为验证域名的发送邮件服务器而设计的。

选项 D 错误。IMAP（互联网消息访问协议）是电子邮件客户端从邮件服务器检索消息的协议。它对于为域名指定授权的邮件服务器没有帮助。

## 问题 481。
一个 Web 应用程序要求用户使用发送到电子邮件的令牌进行身份验证。安全分析师 Alex, 观察到登录后，如果他再次提交相同的令牌，他将获得不受限制的访问权限。这种情况描述了哪种类型的漏洞？

- (A) 跨站请求伪造 (CSRF)
- (B) 重放攻击 (Replay Attack)
- (C) 中间人攻击 (MitM)
- (D) 跨站脚本 (XSS)

**解释 481. 正确答案：B. 重放攻击。** 重放攻击（也称为回放攻击）发生在攻击者拦截数据并重新传输数据时。在这种场景中，Alex 能够重用身份验证令牌（token）来获取访问，这表明系统没有防止重放令牌被多次接受的机制。

**选项 A 错误。** 跨站请求伪造 (CSRF) 是一种攻击，诱骗受害者在已身份验证的 Web 应用程序上执行不希望的操作。它不涉及重用身份验证令牌。

**选项 C 错误。** 虽然中间人攻击 (MitM) 可能涉及拦截双方之间的数据，但描述的场景并不涉及攻击者实时修改或中继信息。

**选项 D 错误。** 跨站脚本 (XSS) 漏洞允许攻击者向网页中注入恶意脚本。该场景并未指示任何脚本注入。

## 问题 482。
一家大型律师事务所有一个集中的文档库，律师在其中存储客户信息、法律草案和其他敏感数据。新助理律师 Jenna 加入了该事务所，她需要能够查看客户文档，但不应该能够修改或删除它们。应该授予 Jenna 哪种类型的权限？

- (A) 只读 (Read-Only)
- (B) 完全控制 (Full Control)
- (C) 修改 (Modify)
- (D) 执行 (Execute)

**解释 482. 正确答案：A. 只读。** 只读权限允许用户查看和打开文件或资源，但不允许他们对其进行修改、删除或执行。在这种场景中，授予 Jenna 只读访问可以确保她能够查看客户文档，而不进行任何更改或删除。

**选项 B 错误。** 完全控制将赋予 Jenna 修改、删除甚至更改文档权限的能力，这超出了她职位所需的权限。

**选项 C 错误。** 修改权限允许用户对文档进行更改，根据场景要求，这对于 Jenna 来说并不合适。

**选项 D 错误。** 执行权限通常与运行程序或脚本有关，与 Jenna 查看文档的需求无关。

## 问题 483。
一家软件开发公司的 IT 部门希望确保在开发环境中只能运行公司批准的开发工具，以防止任何未经授权或潜在有害的软件运行。IT 部门应该采用什么来实现这一目标？

- (A) 实现网络分段
- (B) 定期进行漏洞评估
- (C) 安装稳定的防火墙
- (D) 建立应用白名单

**解释 483. 正确答案：D. 建立应用白名单。** 建立应用白名单可以确保只有特定的、预先批准的应用程序可以在开发环境中运行。这将防止任何未经授权或潜在的软件被执行，直接符合公司的目标。

**选项 A 错误。** 虽然网络分段可以隔离网络的不同部分并限制潜在威胁的传播，但无法阻止未经授权的应用程序在段内运行。

**选项 B 错误。** 定期的漏洞评估可以识别系统漏洞，但它们不会主动防止特定应用程序的运行。

**选项 C 错误。** 状态检测防火墙监控活动连接的状态，并根据状态参数阻止或允许流量，但它不规定工作站上可以执行哪些应用程序。

## 问题 484。
一公司正在实施一种系统，以确保发布到生产环境的代码未被篡改，并获得了特定团队成员的批准。他们应该实施哪种加密技术？

- (A) 对代码进行对称加密
- (B) 使用 SHA-256 对代码进行哈希处理
- (C) 使用团队成员的公钥加密代码
- (D) 团队成员的数字签名

**解释 484. 正确答案：D. 团队成员的数字签名。** 数字签名提供了完整性和不可否认性。通过让特定团队对代码进行数字签名，公司可以确保代码没有被篡改（完整性），并且它是由指定个人批准的（不可否认性）。

**选项 A 错误。** 对称加密提供了机密性，但在这种场景下它没有提供所需的完整性和不可否认性。

**选项 B 错误。** 对代码进行哈希提供了一种检查更改（完整性）的机制，但它没有提供不可否认性或特定团队成员批准的证据。

**选项 C 错误。** 使用团队成员的公钥加密不能提供不可否认性。此外，只有拥有相应私钥的团队成员才能解密，这对于生产环境发布可能是不理想的。

## 问题 485。
在组织的安全审查期间，安全分析师注意到多个用户账户有多次登录失败尝试，每个账户都使用了几个常用的密码。这种场景最好描述的是哪种密码攻击？

- (A) 暴力破解攻击 (Brute Force Attack)
- (B) 字典攻击 (Dictionary Attack)
- (C) 凭据填充 (Credential Stuffing)
- (D) 密码喷洒攻击 (Password Spraying)

**解释 485. 正确答案：D. 密码喷洒攻击。** 密码喷洒是一种攻击方法，攻击者对多个账户尝试几个常用的密码，而不是对单个账户尝试多个密码。描述的场景涉及多个账户，符合这种方法。

**选项 A 错误。** 暴力破解攻击涉及对特定账户尝试可能的密码组合。场景描述的是常用密码。

**选项 B 错误。** 字典攻击涉及从字典或常用密码列表中提取可能的密码，并对单个账户进行尝试。重点是多个账户。

**选项 C 错误。** 凭据填充涉及使用泄露的用户名和密码对获取未经授权的访问。重点是已知凭据，而不是常用密码。

## 问题 486。
一位项目经理正在负责新产品的发布，她的本地计算机上有包含敏感预测的文档。她经常通过电子邮件与董事成员共享这些文档。虽然她希望保护财务文档，但不想加密电脑上的所有数据。她应该利用哪种加密方法？

- (A) 全盘加密
- (B) 传输层加密
- (C) 文件级加密
- (D) 分区加密

**解释 486. 正确答案：C. 文件级加密。** 文件级加密允许对单个文件或文件夹进行加密。在这种场景中，项目经理可以加密敏感的财务文档，从而在安全共享它们的同时保持其他数据不加密。

**选项 A 错误。** 全盘加密将加密整个硬盘，这超出了需求。

**选项 B 错误。** 传输层加密保护传输中的数据，但并不专门针对存储和共享的单个文件进行加密。

**选项 D 错误。** 分区加密加密整个分区或卷，这在场景中并不是必需的。

## 问题 487。
一家金融机构正寻求为其交易采用一种加密算法，由于其密钥较长，该算法被认为非常安全，与旧的 标准。哪种加密算法最符合这一描述？

- (A) DES
- (B) Blowfish
- (C) RSA
- (D) AES-256

**解析 487。正确答案：D. AES-256.** AES-256 是高级加密标准 (AES) 家族的一部分，使用 256 位的密钥长度。这种扩展的密钥长度提供了更高的安全性，在得得当的情况下，被认为能够抵抗所有知的实际攻击。
