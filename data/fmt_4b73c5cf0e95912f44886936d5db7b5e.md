
由于其特性，机器学习经常引发伦理问题。用于处理你收集的数据的训练系统将根据所使用的示例产生偏差，而这些示例是数字化的。因此，来自数据的数据责任是机器学习的重要部分。由于你在处理机器学习时使用的语言，你将使用经过训练的机器。神经网络是受生物学启发的范式，使计算机能够从观察到的数据中学习。`神经网络`和`深度学习`将为你处理图像、语音和自然语言时所遇到的任何问题提供最佳解决方案。人类系统是复杂的，也是你可以研究的最有趣的事情之一，因为你永远无法完全理解它的运作方式。

## 神经网络与感知机

人类系统是复杂的，也是你可以研究的最有趣的事情之一，因为你永远无法完全理解它是如何工作的。例如，识别手写体时，很多人能够识别出手写的内容，但这并不容易，你的大脑已经适应了这一点。我们并不经常花时间去思考复杂的系统是如何运作的。由于识别模式是困难的，计算机不会产生这些问题。然而，这与我们的做法不同，你如何让计算机识别出手写的内容？你将不得不创建规则和例外。

神经网络方法将以不同的方式看待问题。它将处理大量经过训练的手写示例，以便能够执行大脑所做的事情。本质上，神经网络将使用数据内部的示例来推断。你为程序添加的训练示例越多，网络就越能学习更多选项以提高准确率。

神经网络与一种名为`感知机（perceptron）`的人工神经元工作，这是罗森布特（Rosenblatt）在 60 年代开发的。但当我们今天观察它时，它被作为其他人工神经元模型使用。你的主神经元将被称为`sigmoid 神经元`。为了理解`sigmoid 神经元`，必须理解`感知机`。感知机将接受多个输入并给你一个二元结果。罗森布特提出了一种规则，将在处理感知机的输出时使用。这里`权重（weights）`介入了，作为一种表示实数的方式，并带来输入和输出。神经元的输出将是 0 或 1，取决于和小于或大于`阈值（threshold）`。你的阈值值将是一个实数。

将`感知机`看作通过权衡证据来做出决策的设备。例如，如果你想参加活动，有几点你需要查看：

1. 对于每个人来说是否足够大？
2. 天气好吗？
3. 你参加活动需要多少时间？

每个因素都可以由一个二元变量表示。通过查看`权重`和你的问题`阈值`，你可以创建不同的决策过程模型。你的`感知机`将决定你是否参加活动。当你丢弃阈值时，它最有可能发生。请记住，你的`感知机`并不是人类可以执行的决策过程的完整模型。然而，如果你对权重进行任何更改，你的`感知机`可能会由于该变化而完全翻转。这种变化将导致整个网络的行为变为更复杂的行为。

所以，当你的数字之一被正确分类时，你的网络以一种难以控制的方式运行。你的网络的新行为使得难以看到修改`权重`和`偏置（biases）`。因此，必须有一种聪明的方法来解决这个可能并不明显的问题：引入一种新的神经元，即`sigmoid 神经元`。这些神经元类似于`感知机`，但它们经过了修改，使得当你进行微小更改时，只会给你的输出产生微小变化，而不是改变你的输出。这至关重要，`sigmoid 神经元`能够学习网络的行为。`sigmoid 神经元`的输入类似于`感知机`，但它能够接受 0 到 1 之间的任何值。

`sigmoid 表达式`由以下方程定义：

```
σ(z) = 1 / (1 + e^-z)
```

另一种观察方式是带有输入的`sigmoid 神经元`：

```
σ(z) = 1 / (1 + exp(-∑xj-b))
```

其中`z = w·x + b`，有一个很大的正数。这意味着`e^-z ≈ 0` 和`σ(z) ≈ 1`是相等的。现在设想如果你正在处理负数，那么你的`sigmoid`行为将与`感知机`相同。你看到的与`感知机`模型的偏差只是中等规模。但你的`σ`的数学形式是什么？事实是，这个变量的精确形式没有影响，因为我们将关注表达式的形状。如果这个函数是一个阶跃表达式（step expression），那么你的`sigmoid 神经元`最终将是一个`感知机`，因为结果取决于你的方程给出的是正结果还是负结果。当你使用`σ`的函数时，你将得到一个平滑的`感知机`。然而，你的表达式有多平滑并不是你需要花费太多时间的事情。平滑性仅仅会修改权重和偏置，从而改变你的`sigmoid 神经元`的输出。得益于微积分，你的输出将由这个方程预测：

```
Δoutcome = ∂outcome/∂wj + ∂outcome/∂b
```

你的和是在所有权重上找到的，你的输出将显示相对于权重所需的输出偏导数。如果你发现自己不熟悉偏导数，不要太担心。你上面的表达式由于其中的偏导数而看起来很复杂，网络输入将是扫描的像素数据，以便网络可以学习`权重`和`偏置`以正确分类输出。如果你对网络中的权重进行任何更改，你的输出将与你所做的更改对应。然而，`感知机`的现实是，当权重发生变化时，`感知机`可能会完全翻转。这种变化将导致你的网络的行为变为更复杂的行为。

所以，当你的数字之一被正确分类时，你的网络以一种难以控制的方式运行。你的网络的行为使得难以看到修改`权重`和`偏置`。因此，必须有一种聪明的方法来解决这个可能并不明显的问题：引入一种新的神经元，即`sigmoid 神经元`。这些神经元类似于`感知机`，但它们经过了修改，使得当你进行微小更改时，只会给你的输出产生微小变化，而不是改变你的输出。这至关重要，`sigmoid 神经元`能够学习网络的行为。`sigmoid 神经元`的输入类似于`感知机`，但它能够接受 0 到 1 之间的任何值。

你的假设需要是可测试的，以判断是否提供了足够的数据。

## 机器学习与机器人

既然你已经了解了什么是机器学习，那么这个术语对机器人领域兴趣的激发以及在过去几年中没有太大变化应该并不让你意外。但机器学习与机器人之间有什么关系呢？机器人领域只有少数项发展导致了其他发展，包括机器学习。以下是机器人领域中常见的五种机器学习应用：

### 1. 计算机视觉

有些人会认为“机器人视觉”或“机器视觉”才是正确的术语，因为“机器人视觉”涉及的不仅仅是计算机算法。机器人专家和工程师研究了什么类型的摄像头硬件可以让机器人处理周围的物理数据。机器人视觉和机器视觉密切相关。它们的出现可以归功于自动检测系统的创建和机器人引导。两者在应用于机器人视觉的运动学上仅有微小区别，这涵盖了坐标系校准以及机器人物理影响其环境的能力。

大数据的涌入有助于推动计算机视觉的进步，这又进一步帮助了许多大学基于结构化预测学习技术的机器学习。

### 2. 模仿学习

模仿学习与观察性学习密切相关，这种行为在婴儿和幼儿身上可以见到。模仿学习被认为是强化学习的伞下分类，或者是让智能体在世界中行动以实现奖励最大化的挑战。这种方法具有共同特征，即概率模型和贝叶斯。最终的问题是，模仿学习是否能够用于人形机器人。

作为机器人领域的重要部分，模仿学习在搜索救援和建筑等领域具有工厂环境之外的移动性，这使得手动编写机器人解决方案具有挑战性。

### 3. 自监督学习

由于自监督学习方法，机器人将被允许生成自己的训练示例，以便提高性能。这将包括优先训练以及近距离采集的数据，这些数据将用于翻译远距离传感器数据。带有光学设备的机器人配备了此类设备，以便它们拒绝和检测物体。

康奈和斯坦福大学创建了一个名为 `Watch-Bot` 的坚实示例，它使用笔记本电脑、激光笔、3D 传感器和摄像头来寻找人类正常活动，这些模式是通过概率方法学习的。为了发出提醒，`Watch-Bot` 在物体中使用激光笔。在一次测试中，机器人几乎在 60% 的时间内提醒了人类，但机器人并不理解自己在做什么或为什么要这样做。

### 4. 医疗与辅助技术

辅助机器人是一种设备，在执行操作之前可以感知并处理感官信息，最终有利于残障人士和老年人。这些运动治疗机器人将提供治疗和诊断益处。由于它们对于国外和美国的医院来说仍然价格昂贵，它们尚未离开实验室。

辅助技术的某些早期示例是桌面职业辅助机器人或 `DeVAR`。它是斯坦福大学和帕洛奥托退伍军事务康复研究与开发中心在 20 世纪 90 年代初开发的 `DeVAR`。目前仍有基于机器学习的机器人辅助技术的研究。`MICO` 臂就是一个示例。它是一种具有自主性的辅助机器，使用 `Kinect` 传感器来观察世界。这些影响将变得复杂，但它们将为世界提供更智能、能更好地适应用户需求的辅助机器人。机器学习的进步也可以体现在医疗领域。尽管医疗机构尚未使用它，但机器人技术正在以飞速发展。

### 5. 多智能体学习

多智能体学习包含一些关键组件，即谈判与协调，这涉及到基于机器学习的机器人，其目标是寻找平衡策略并适应机器人不断变化的环境。例如，涉及加权算法的无悔学习工具包含在多智能体学习方法中，这些方法将帮助提高与基于市场的分布式控制系统中所发现的多智能体学习和规划相相关的学习成果。

在 2014 年底，麻省理工决策与信息系统实验室了一一种用于分布式机器人或智能体的更可靠的算法示例。机器人能够协作构建一个更具包容性的更好的学习模型，该模型由单个机器人完成，其基础是构建探索和房间布局，同时自主构建知识库。每台机器人都会制作目录，然后将这些目录与其他机器人的数据集合并，在构建此类知识库时，分布式算法的性能优于标准算法。这种机器学习方法虽然不是完美的系统，但将允许机器人比较目录并强化相互观察，同时纠正任何遗漏或过度泛化，这在不不不的多个机器人应用中将发挥作用。

正如你上面所看到的，机器人领域中基于机器学习的方法开始与军事创新者或赞助商（他们为大型机器人制造商甚至初创公司工作服务）所提出的挑战和合同相结合，同时汽车制造商对下一代自动驾驶汽车的投入也在增加。由于机器学习的能力，它正被用于进一步推进机器人技术，并让机器人在处理数据和解释这些数据方面变得更加复杂。

# 第 8 章：自动驾驶车辆

自动驾驶汽车也被称为机器人汽车、自主驾驶汽车甚至无人驾驶汽车。这些车辆能够感知其所处的环境，并在无需人类干预或极少人类干预的情况下移动。自动驾驶汽车将配备各种传感器，以帮助它们评估周围环境，例如惯性测量单元、GPS、里程计、声纳、计算机视觉、激光雷达和雷达。此外，还有先进的控制系统可以解释传感器信息，以识别正确的导航路径以及车辆路径上可能任何障碍物或标志。

## 自动驾驶车辆的优势

一些优点将包括提高安全性和降低成本。它们还将提高流动性、减少犯罪率并提高客户满意度。由于自动化汽车的出现，预计交通流量将会增加，同时为贫人、老年人、残障人士和儿童提供更强的移动性。它们将使旅行变得更容易，因为司机不再需要全程负责驾驶和导航，同时还能降低油耗以及对停车位的需求。

## 挑战与担忧

自动驾驶汽车面临的一些问题是安全、责任归属和技术。每当人在车内时，他们都会产生控制车辆的欲望。不仅如此，研究人员还必须通过法律框架和政府法规。此外，这会让人们觉得失去了隐私，从而导致如黑客攻击或恐怖主义等安全担忧。在此基础上，由于不再需要司机坐在方向盘后，人们可能会失去工作。这还会导致郊区化旅行增加，因为这变得更加方便。

## 半自动车辆

自动化程度是许多车辆的基础。它们可能被归类为全自动或全手动驾驶车辆。半自动车辆就是它们的统称。在技术和基础设施完全开发出全自动车辆之前，还需要一段时间，但在研究期间，车辆将根据其自动化程度不断增加。半自动车辆将比全自动车辆更具优势，因为司机仍然控制着车辆。

## 应用领域

### 自动化卡车

许多公司正在对半挂车进行自动化技术测试。2016 年，Uber 购买了一家自动驾驶卡车公司 `Otto`，在 Uber 购买之前，他们必须在公路上展示他们的卡车。随后，在 2017 年，一家位于旧金山的初创公司宣布，他们将与名为 `Peterbilt` 的卡车制造商合作，以便在 `Peterbilt` 车辆中部署和测试自动化技术。据推，Waymo 正在对卡车进行自动化技术测试，但该项目尚未提供时间表。此外，在 2018 年，位于旧金山的 `Starsky Robotics` 完成了前往佛罗里达州的 7 英里无人驾驶行程。这使他们成为公共道路上无人驾驶卡车竞争中的第一个参与者。

为自动汽车创建的交通系统开始在城市中运行，例如英国、法国、意大利和比利时的一些地区，而在荷兰、西班牙和德国，他们正在交通中进行公开测试。英国在米尔顿凯恩斯启动了自动驾驶座舱 `LUTZ Pathfinder` 的公开试验。法国政府在 2014 年夏季允许 `PSA Peugeot-Citroen` 在巴黎进行试验。这些实验计划在 2016 年扩展到斯特拉斯堡和波尔多等城市。法国公司 `Valeo` 和 `THALES` 之间的联盟也允许了自己的测试运行。

# 第 9 章：语音识别

语音识别是一门属于计算语言学的交叉学科子领域，它被用于开发各种方法和技术，帮助机器识别并会将口语语言转换为文本。这也被称为计算机语音识别、语音转文本 (`STT`) 或自动语音识别 (`ASR`)。语音识别将整合计算机科学、语言学和电气工程所需的所需的知识和研究。

某些系统可能需要进行训练，即由说话者向系统朗读词汇或文本。随后，系统将对该人的声音进行分析，并将其用于微调对该人语音的识别，有助于提高准确性。依赖说话人的系统使用训练，而独立于说话人的系统则不需要训练。

语音识别应用将包括语音拨号、呼叫路由、简单数据输入、确定说话者特征、飞机、语音转文本处理、结构化文档的准备以及家用电器控制搜索等。“语音识别”一词是指识别说话者的身份，而不是他们所说的内容。通过识别说话者，系统中的翻译任务将变得简单。

从技术角度看语音识别，它拥有悠久的历史，经历了多次创新浪潮。最近的浪潮之一得益于大数据和深度学习。这些进展不仅体现在已学术论文的激增上，还体现在全球范围内，设计和部署这些语音识别系统时对不同深度学习方法的采用上。你可以在 SoundHound、微软 (Microsoft)、IBM、亚马逊 (Amazon) 和苹果 (Apple) 等公司看到这种创新。

## 机器人中的语音识别

你曾经见过机器人说话吗？得益于语音识别，这是可能的！正如我们之前提到的，语音识别将分为两类：独立于说话人和依赖说话人。

依赖说话人的系统将由一个人进行训练，而这个人将是该系统的使用者。这些系统效率很高，可以获得高指令计数；然而，系统只会对训练过系统的人做出响应。

独立于说话人的系统将被训练为响应某个说话者的词汇。语音输入设备将安装在控制器上；因此，与运动相关的指令将通过语音给出，然后转换为数字形式。这将由模拟数字转换器完成。指令将输入到麦克风，然后电信号可以将声音转换为运动。一旦将这些数字信号给到机器人控制器，将使用过滤设备处理语音形式形式的数据。为了提高准确度和音质，将有一个转换建模过程来形成系统响应。

## 系统识别电路

要训练多达 40 个单词的电路，你可以这样考虑：你通过按下 `1` 来训练系统识别第一个单词。按下任何数字，红色 LED 都会熄灭。这些数字将显示在数字显示器上。一旦按下井号键 (#)，它将训练系统。通过按下井号键，它将向一个芯片发送信号，该芯片将听训练词并然后打开 LED。

要进行测试，下一步是说你想让系统识别的单词；此时将使用麦克风。一旦单词被接受，LED 将会闪烁。你将对所有 40 个单词执行此操作，你应该能在显示器上看到每个录的单词。

语音识别系统可以分解为四个不同的部分：

1. 语音识别将使用分离的音频。
2. 源的线性分离。
3. 从过滤后的输出中计算缺失的特征。
4. 过滤后的多通道。

一旦机器过滤了语音，机器人将执行所请求的指令。随着技术的进步，机器人不仅能够使用语音识别程序来接收指令，还能在完成任务时与人类与其他机器人进行通信。

# 第 10 章：无人机

UAV 或无人驾驶飞行器通常被称为无人机，它们是不需要人类驾驶员的飞行器。UAV 是无人飞行器系统的一部分，这些系统可以包括从地面控制的 UAV，或者两者之间运行的通信系统。UAV 的飞行方式可能基于不同程度的自主性运行，既可以通过远程控制进行操作，也可以通过机载计算机自主运行。

无人机最初用于对人类来说太危险或太肮脏的任务，主要用于军事领域，但其用途迅速扩展到商业、娱乐、科学、农业等应用领域，例如监控、产品递送、执法、维和、摄影、走私和竞速。

## 无人机与机器人机载计算机

下一代无人机和机器人将比之前的产品更智能、更快、更轻。这得益于精简的解决方案，它将多种计算功能集成到单个板上。高通无人机和机器人技术将能够在减少机载计算机体积的同时，提供强大的连接、长电池续航和先进的处理能力。由于体积更小，设计的复杂性也将降低，这意味着无人机对更广泛的受众来说将更加负担得起。

### 单板技术

得益于 `Snapdragon Flight`，无人机将变得更轻且更容易使用。这项技术将集成 4K 高分辨率摄像头支持、高精度的位置定位甚至实时飞行控制，所有这些都将安装在单板上；从而使 OEM（原始设备）的产品更小、更坚固。

### 异构平台

使用异构平台构建智能无人机和机器人组件将帮助 OEM 创建更安全、更轻的无人机和机器人，最终降低机器人成本，面向更多消费者。

### 自主飞行

得益于技术的进步，OEM 可以使其具备感知能力和自主能力。由于先进的技术平台，它将内置传感器与 3D 环境映射相结合，允许无人机自主飞行。

### 低功耗

通过在单板上组合多个组件，该板将提供低功耗轻量化的解决方案，助力呈现先进的飞行连接和控制。

### 可靠程序

`Snapdragon Navigator` 程序将提供智能导航，允许无人机在飞行过程中看到并对路径上的物体做出反应，从而提供更安全、更可靠的导航。

### 智能电机控制器

`Snapdragon flight` 将包含智能电机控制以及 500Hz 纬度处理，这将使飞行体验更稳定，同时增加电池寿命并减轻发动机的压力。
