
与所有恶意代码对象一样，逻辑炸弹形式多样。事实上，许多病毒和特洛伊木马都包含逻辑炸弹组件。著名的“米开朗基罗”病毒于 1991 年被发现时引起了媒体轰动，因为它包含一个逻辑炸弹触发器。该病毒通过共享受感染的软盘感染系统的主引导记录，然后隐藏起来，直到 3 月 6 日——著名意大利艺术家米开朗基罗·博那罗蒂的生日。到了那天，它就会发作，重新格式化受感染系统的硬盘驱动器，销毁其中包含的所有数据。

最近，2013 年 3 月，一枚逻辑炸弹针对韩国的组织。该恶意软件渗透了韩国媒体公司和金融机构的系统，导致系统瘫痪和数据丢失。在这种情况下，恶意软件攻击触发了军事警报，因为韩国政府怀疑该逻辑炸弹是朝鲜发动攻击的前奏。

### 特洛伊木马

系统管理员时刻警告计算机用户，除非绝对确定来源可信，否则不要从互联网下载和安装软件。事实上，许多公司严格禁止安装任何未经 IT 部门预先审核的软件。这些政策旨在最大限度地降低组织网络被`特洛伊木马`攻破的风险——特洛伊木马是一种表面上看似无害，实则携带恶意后台载荷的软件程序，有可能对系统或网络造成严重破坏。

特洛伊木马的功能差异很大。有些会销毁系统上存储的所有数据，试图在尽可能短的时间内造成最大程度的破坏。有些则相对无害。例如，2002 年中，互联网上出现了一系列特洛伊木马，声称能让 PC 用户在电脑上运行专为微软 Xbox 游戏系统设计的游戏。当用户运行该程序时，它根本无法工作。然而，它还会向 Windows 注册表插入一个值，导致每次计算机启动时都会打开一个特定的网页。特洛伊木马创建者希望通过 Xbox 特洛伊木马带来的大量页面浏览量产生的广告收入获利。不幸的是，防病毒专家迅速识破了他们的真实意图，该网站被关闭。

近年来对安全社区产生重大影响的一类特洛伊木马是流氓防病毒软件。这种软件通过声称自己是防病毒软件包，往往以模仿安全警报外观的弹窗广告形式，诱骗用户安装。一旦用户安装了该软件，它要么窃取个人信息，要么提示用户付费“更新”流氓防病毒软件。“更新”仅仅是禁用该特洛伊木马！

另一种变体`勒索软件`尤为阴险。勒索软件感染目标机器，然后利用加密技术，用仅恶意软件创建者知道的密钥，加密系统上存储的文档、电子表格和其他文件。用户随后无法访问其文件，并会收到一条不祥的弹窗消息，警告除非在短时间内支付赎金，否则文件将被永久删除。用户往往会支付赎金以恢复对文件的访问。最著名的勒索软件变种之一是名为 Cryptolocker 的程序。

### 蠕虫

`蠕虫`对网络安全构成重大风险。它们具有与其他恶意代码对象相同的破坏潜力，但有一个额外的特点——它们无需任何人工干预即可自我传播。

互联网蠕虫是互联网上发生的第一起重大计算机安全事件。自那时以来，数百种新蠕虫（包含数千个变种）在互联网上释放了其破坏力。以下章节将探讨一些具体的蠕虫。

#### Code Red 蠕虫

Code Red 蠕虫在 2001 年夏季因在运行未修补版本的微软 Internet Information Server (IIS) 的 Web 服务器中迅速传播而受到媒体的广泛关注。Code Red 在渗透的系统上执行了三项恶意操作：

*   它随机选择数百个互联网协议 (IP) 地址，然后探测这些地址，查看它们是否被运行易受攻击版本 IIS 的主机使用。它发现的任何系统都会被迅速攻破。这极大地扩大了 Code Red 的影响范围，因为它感染的每个主机都会寻找许多新目标。

*   它篡改了本地 Web 服务器上的 HTML 页面，将正常内容替换为以下文本：

```
Welcome to http://www.worm.com!
Hacked By Chinese!
```

*   它植入了一个逻辑炸弹，将针对 IP 地址`198.137.240.91`发起拒绝服务攻击，该地址当时属于托管白宫主页的 Web 服务器。反应迅速的政府网络管理员在攻击真正开始前更改了白宫的 IP 地址。

蠕虫的破坏力对现代互联网构成了极端风险。系统管理员必须确保在软件供应商发布安全补丁时，及时将其应用到连接互联网的系统上。一个典型的例子是，微软在 Code Red 蠕虫攻击互联网前一个多月就已提供了针对其利用的 IIS 漏洞的安全修复程序。如果安全管理员及时应用了该补丁，Code Red 将会彻底失败。

#### Stuxnet

2010 年中，一款名为 Stuxnet 的蠕虫出现在互联网上。这种高度复杂的蠕虫使用多种先进技术进行传播，包括多个此前未公开的漏洞。Stuxnet 使用以下传播技术：

*   搜索本地网络上系统的未受保护管理共享

*   利用 Windows Server 服务和 Windows 打印后台处理程序服务中的零日漏洞

*   使用默认数据库密码连接到系统

*   通过共享受感染的 USB 驱动器进行传播

虽然 Stuxnet 可以肆无忌惮地在系统间传播，但它实际上在寻找一种非常特定类型的系统——使用西门子制造的控制器、据称用于生产核武器材料的系统。当它发现此类系统时，会执行一系列旨在破坏连接到西门子控制器的离心机的操作。

Stuxnet 似乎始于中东地区，具体是伊朗境内的系统。据称它是由西方国家设计，意图破坏伊朗的核武器计划。根据《纽约时报》的一篇报道，以色列的一个设施包含用于测试该蠕虫的设备。报道称：“以色列拥有与伊朗几乎相同的核离心机”，并指出“那里的行动，以及美国的相关努力，……是该病毒被设计为美以合作项目以破坏伊朗计划的线索。”

如果这些指控属实，Stuxnet 标志着恶意代码领域的两大演变：利用蠕虫对设施造成重大物理破坏，以及在国家间战争中使用恶意代码。

#### 间谍软件和广告软件

另外两种不需要的软件会干扰你正常使用计算机的方式。`间谍软件`监视你的操作，并将重要详细信息传输给监视你活动的远程系统。例如，间谍软件可能会等待你登录银行网站，然后将你的用户名和密码传输给间谍软件的创建者。或者，它可能会等待你在电子商务网站上输入信用卡号，然后将其传输给欺诈者以便在黑市上转售。

`广告软件`虽然在形式上与间谍软件非常相似，但目的不同。它使用多种技术在受感染的计算机上显示广告。最简单形式的广告软件会在你浏览网页时在屏幕上显示弹窗广告。更恶劣的版本可能会监视你的购物行为，并将你重定向到竞争对手的网站。

#### 零日攻击

许多形式的恶意代码利用`零日漏洞`，即由黑客发现但安全社区尚未彻底解决的安全缺陷。系统受这些漏洞影响主要有两个原因：

*   发现新类型恶意代码与发布补丁和防病毒更新之间必要的延迟。这被称为`脆弱性窗口`。

*   系统管理员应用更新的迟缓

零日漏洞的存在使得采用纵深防御网络安全方法至关重要，该方法应包含一套多样化的重叠安全控制。这些控制应包括强大的补丁管理计划、最新的防病毒软件、配置管理、应用程序控制、内容过滤和其他防护措施。当这些重叠控制结合使用时，能增加至少有一个控制检测并阻止恶意软件安装尝试的可能性。

### 密码攻击

攻击者用于获取系统非法访问权限的最简单技术之一，是获取授权系统用户的用户名和密码。一旦他们以普通用户身份获得访问权，就获得了系统的立足点。此时，他们可以使用其他技术（包括自动化`Rootkit`包）来获取系统的更高访问权限（请参阅本章后面的“权限提升和 Rootkit”部分）。他们还可能将受损系统作为跳板，对同一网络上其他更有价值的目标发起攻击。

以下部分将探讨攻击者用于获取合法用户密码并访问系统的三种方法：密码猜测攻击、字典攻击和社会工程学攻击。许多此类攻击依赖于薄弱的密码存储机制。例如，网站可能会在单个文件中存储消息摘要算法 5 (MD5) 密码哈希值。如果攻击者能够操纵 Web 服务器软件或操作系统以获取该文件副本，他们就可以利用它进行攻击。

#### 密码猜测

在最基本的密码攻击类型中，攻击者只是简单地尝试猜测用户的密码。无论用户接受多少安全教育，他们往往都会使用极其薄弱的密码。如果攻击者能够获取授权系统用户列表，他们通常能迅速弄清正确的用户名。（在大多数网络中，用户名由用户名字的首字母加上姓氏的一部分组成。）有了这些信息，他们就可以开始对用户的密码进行一些有根据的猜测。最常用的密码是用户姓氏、名字或用户名的某种形式。例如，用户`mchapple`可能会使用薄弱密码`elppahcm`，因为它容易记忆。不幸的是，它也很容易被猜到。

如果尝试失败，攻击者会转向互联网上广泛可用的最常用密码列表。其中一些如“最常用密码”栏所示。

最后，对一个人稍微了解一些就能为其密码提供极好的线索。许多人使用配偶、孩子、宠物、亲戚或喜爱的艺人名字。常见密码还包括生日、纪念日、社会安全号码、电话号码和自动取款机 (ATM) 个人识别码 (PIN)。

#### 字典攻击

### Unix 密码存储与攻击

如前所述，许多 Unix 系统将用户密码的加密版本存储在所有系统用户均可访问的`/etc/shadow`文件中。为了提供一定程度的安全性，该文件不包含实际的用户密码；它包含的是通过单向哈希函数获得的哈希版本（关于哈希函数的讨论请参见第 7 章“PKI 和加密应用”）。当用户尝试登录系统时，访问验证程序使用相同的哈希函数对用户输入的密码进行哈希处理，然后将其与`/etc/shadow`文件中存储的实际密码的哈希版本进行比较。如果数值匹配，则允许用户访问。

密码攻击者使用`John the Ripper`等自动化工具运行自动化字典攻击，利用该机制中的一个简单漏洞。它们获取一个包含数千个单词的大型字典文件，然后对所有这些单词运行加密函数以获得其加密等效值。`John the Ripper`随后会在密码文件中搜索任何在加密字典中有匹配项的加密值。找到匹配项时，它会报告用户名和密码（明文），攻击者便获得了系统访问权限。

听起来简单的安全机制和教育本可防止用户使用容易被`John the Ripper`猜到的密码，但该工具在攻破实际运行的系统方面却出奇地有效。随着破解工具新版本的发布，引入了更多高级功能来击败用户用于绕过密码复杂性规则的常见技巧。其中一些列举如下：

*   重新排列字典单词的字母

*   在字典单词后附加数字

*   将字典单词中每次出现的字母`O`替换为数字`0`（或将字母`l`替换为数字`1`）

*   以某种形式组合两个字典单词

彩虹表攻击是字典攻击的一种变体，旨在减少对哈希密码进行暴力攻击所需的时间。在此攻击中，攻击者获取一份常用密码列表，然后通过系统使用的相同哈希函数运行它们，以创建这些密码的哈希版本。生成的哈希值列表称为`彩虹表`。在密码哈希的简单实现中，攻击者随后只需在哈希值列表中搜索彩虹表中包含的值，即可确定用户密码。第 7 章讨论的加盐技术解决了此问题。详情请参阅该章中的侧边栏“加盐保护密码”。

#### 社会工程学

`社会工程学`是攻击者用于获取系统访问权限的最有效工具之一。其最基本的形式，就是简单地给用户打电话并索要密码，冒充技术支持代表或其他需要立即获取该信息的权威人物。幸运的是，大多数现代计算机用户都知晓这些骗局，直接向用户索要密码的有效性在今天已有所降低。取而代之的是，这些攻击依赖于网络钓鱼邮件，提示用户使用其实际用户名和密码登录到一个伪造网站，随后攻击者捕获这些凭据并用于登录实际网站。网络钓鱼攻击通常以金融服务网站为目标，因为用户凭据可用于快速转移现金。除了诱骗用户交出密码外，网络钓鱼攻击还常被用于诱使用户安装恶意软件或提供其他敏感个人信息。

网络钓鱼消息正变得日益复杂，旨在极度类似合法通信。例如，图 21.1 所示的网络钓鱼消息被发送给数千名收件人，伪装成社会保障局的官方通信。点击链接的用户被重定向到一个恶意网站，该网站窃取了他们的敏感信息。

网络钓鱼还有许多常见变体。其中一些包括：

*   `鱼叉式网络钓鱼`攻击基于攻击者的调查研究，专门针对特定个人。它们可能包含旨在使消息显得更真实的个人信息。

*   `鲸钓`攻击是鱼叉式网络钓鱼攻击的一个子集，针对高价值目标，如高级管理人员。

*   `语音钓鱼`攻击通过语音通信（如电话）使用网络钓鱼技术。

尽管用户越来越精明，社会工程学仍对密码安全（以及网络安全整体）构成重大威胁。攻击者往往可以通过与计算机用户、爱说闲话的办公室职员和行政人员“套近乎”来获取敏感个人信息。这些信息在发起密码猜测攻击时可提供极佳的“弹药”。此外，攻击者有时还能获取敏感的网络拓扑或配置数据，这些数据在策划针对组织的其他类型电子攻击时非常有用。

`垃圾箱搜寻`是社会工程学的一种变体，攻击者字面意义上地翻找目标公司的垃圾，搜寻敏感信息。该技术很容易通过粉碎纸质文件和擦除电子介质来防范，但垃圾箱搜寻者在其努力中仍出奇地成功。

#### 对策

任何安全计划的基石都是教育。安全人员应不断提醒用户选择安全密码并保密的重要性。用户初入组织时应接受培训，并应定期接受复习培训，即使只是来自管理员提醒威胁的一封电子邮件。

为用户提供创建安全密码所需的知识。告知他们攻击者猜测密码时使用的技巧，并给出关于如何创建强密码的建议。最有效的技巧之一是使用一个非常长的短语，例如“My son Richard likes to eat four pies”（我儿子理查德喜欢吃四个馅饼），而不是短密码。如果系统不允许使用长通行短语，可考虑使用记忆辅助工具，如用一个长短语中每个单词的首字母组成密码。例如，“My son Richard likes to eat four pies”将变为`MsRlte4p`——一个极其强壮的密码。您可能还希望考虑为用户提供一个安全工具，允许存储这些强密码。`Password Safe`和`LastPass`是两个常用示例。这些工具允许用户为他们使用的每个服务创建独特、强壮的密码，而无需承担记住所有密码的负担。

过度热心的安全管理员犯的一个错误是创建一系列强密码，然后分配给用户（并阻止用户更改密码）。乍一看，这似乎是一个合理的安全策略。然而，用户收到像`1mf0A8flt`这样的密码时，第一件事就是把它写在便利贴上，贴在键盘底下。哎呀！安全就这么飞出窗外了（或藏在键盘底下）！

### 应用攻击

在第 20 章中，您了解了在开发操作系统和应用程序时利用可靠的软件工程流程的重要性。在以下章节中，您将简要了解攻击者用于利用粗糙编码实践留下的漏洞的一些具体技术。

#### 缓冲区溢出

### 缓冲区溢出漏洞

当开发人员未能正确验证用户输入以确保其大小合适时，就会存在`缓冲区溢出`漏洞。过大的输入可能会“溢出”数据结构，从而影响计算机内存中存储的其他数据。例如，如果一个 Web 表单包含一个字段，该字段关联到一个允许 10 个字符的后端变量，但表单处理器未验证输入的长度，操作系统可能会尝试直接将数据写入该变量预留内存空间的末尾之后，从而可能破坏内存中存储的其他数据。在最坏的情况下，这些数据可被用于覆盖系统命令，允许攻击者利用缓冲区溢出漏洞在服务器上执行任意命令。

在创建软件时，开发人员必须特别注意允许用户输入的变量。许多编程语言本身并不强制限制变量的大小——它们依赖程序员在代码中执行边界检查。这是一种固有的漏洞，因为许多程序员认为参数检查是一种不必要的负担，会拖慢开发进程。作为安全从业者，你有责任确保组织中的开发人员了解缓冲区溢出漏洞带来的风险，并采取适当措施保护代码免受此类攻击。

每当程序变量允许用户输入时，程序员都应采取措施确保满足以下每个条件：

*   用户无法输入长度超过将容纳该输入的任何缓冲区大小的值（例如，将一个 10 字母的单词输入到一个 5 字母的字符串变量中）。

*   用户无法输入将容纳该输入的变量类型所不允许的无效值（例如，向数字变量输入字母）。

*   用户无法输入会导致程序在其指定参数之外运行的值（例如，对一个“是”或“否”的问题回答“也许”）。

未能执行简单的检查以确保满足这些条件，可能会导致缓冲区溢出漏洞，这可能导致系统崩溃，甚至允许用户执行 Shell 命令并获取系统访问权限。缓冲区溢出漏洞在使用`Common Gateway Interface (CGI)`或其他允许非熟练程序员快速创建交互式网页的语言快速开发的 Web 代码中尤为普遍。大多数缓冲区溢出漏洞可通过软件和操作系统供应商提供的补丁来缓解，这凸显了保持系统和软件最新的重要性。

#### 检查时间到使用时间

`检查时间到使用时间 (TOCTOU or TOC/TOU)`问题是一种时序漏洞，当程序在资源请求发生前过早地检查访问权限时就会发生。例如，如果操作系统在用户登录时构建一份详尽的访问权限列表，然后在整个登录会话期间查阅该列表，则存在 TOCTOU 漏洞。如果系统管理员撤销了特定权限，该限制直到用户下次登录时才会生效。如果用户在访问权限被撤销时已登录，他们将无限期地保留对该资源的访问权。用户只需保持会话打开数天，新的限制就永远不会被应用。

#### 后门

`后门`是未记录的命令序列，允许知晓后门的人绕过正常的访问限制。它们通常在开发和调试过程中使用，以加快工作流程，避免强制开发人员持续向系统进行身份验证。有时，开发人员会在系统达到生产状态后意外地或为了能在系统处理他们本不应有权访问的敏感数据时“窥探一下”而将这些后门留在系统中。除了开发人员植入的后门外，许多类型的恶意代码会在受感染系统上创建后门，允许恶意代码的开发者远程访问受感染系统。

无论它们以何种方式出现在系统上，后门的未记录性质使其成为任何包含它们的系统安全的重大威胁。知晓后门的个人可能利用它访问系统、检索机密信息、监控用户活动或从事其他邪恶行为。

#### 权限提升和 Rootkit

一旦攻击者在系统上站稳脚跟，他们通常会迅速转向第二个目标——将访问权限从可能已被攻破的普通用户账户扩展到更全面的管理访问权限。他们通过实施`权限提升攻击`来实现这一点。

攻击者发动权限提升攻击最常见的方式之一是通过使用`Rootkit`。Rootkit 在互联网上免费提供，并利用各种操作系统中的已知漏洞。攻击者通常通过密码攻击或社会工程学获得标准系统用户账户的访问权限，然后使用 Rootkit 将其访问权限提升到 root（或管理员）级别。这种从标准权限到管理权限的访问权限增加被称为权限提升攻击。

管理员可以采取一个简单的预防措施来保护其系统免受权限提升攻击，这并非什么新鲜事。管理员必须及时了解其环境中使用的操作系统发布的新安全补丁，并始如一地应用这些补救措施。这一简单直接的步骤将使网络能够抵御几乎所有的 Rootkit 攻击以及大量其他潜在漏洞。
