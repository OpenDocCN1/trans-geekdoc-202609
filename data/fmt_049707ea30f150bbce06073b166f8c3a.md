# 20.7 非负矩阵分解

在讨论 PCA 时，已经强调了降维与低秩矩阵分解之间的紧密联系。如果保留的独立分量数量少于观测到的 `l` 个随机变量（例如，选择 `m < l` 个最非高斯的分量），ICA 也可被视为一种低秩矩阵分解。

对于前文讨论的低秩矩阵分解方案，文献 [144,145] 提出了一种替代方案，该方案保证了所得矩阵因子元素的 `nonnegativity`（非负性）。在某些应用中必须施加此类约束，因为负元素与物理现实相矛盾。例如，在图像分析中，像素的强度值不能为负。概率值也不能为负。所得的分解被称为 `nonnegative matrix factorization`（非负矩阵分解，NMF），并已成功应用于多个领域，包括文档聚类 [192]、分子模式发现 [28]、图像分析 [122]、聚类 [171]、音乐转录、乐器分类 [20,166] 以及人脸验证 [198]。

给定一个 `l × N` 矩阵 `X`，NMF 的任务在于寻找 `X` 的一个近似分解，即

`X ≈ AZ`

其中 `A` 和 `Z` 分别为 `l × m` 和 `m × N` 矩阵，`m ≤ min(N, l)`，且所有矩阵元素均为非负，即 `A(i, k) ≥ 0`，`Z(k, j) ≥ 0`，`i = 1, 2, …, l`，`k = 1, 2, …, m`，`j = 1, 2, …, N`。显然，若矩阵 `A` 和 `Z` 为低秩，则它们的乘积也是低秩的，至多为 `m`，从而构成 `X` 的一个低秩近似。上述内容的意义在于 `X` 中的每个列向量均可由以下展开式表示：

```
x_i ≈ ∑_{k=1}^m Z(k,i) a_k, i = 1,2,…,N
```

其中 `a_k, k = 1,2,…,m` 为 `A` 的列向量，构成了该展开式的基。基中向量的数量少于向量本身的维数。因此，NMF 也可被视为一种 `dimensionality reduction`（降维）方法。

为在公式 (20.75) 中获得良好的近似，可采用不同的代价函数。最常用的代价是误差矩阵的 Frobenius 范数。在此设定下，NMF 任务可表述如下：

```
min_{A,Z} ||X - AZ||_F² := ∑_{i=1}^l ∑_{j=1}^N (X(i,j) - AZ)²
```

满足 $A(i, k) \ge 0$, $Z(k, j) \ge 0$，

其中 $AZ$ 是矩阵 $AZ$ 的 $(i, j)$ 元素，且 $i, j, k$ 遍历所有可能的值。除了 Frobenius 范数，也提出了其他代价函数（参见，例如，[168]）。

一旦问题建立起来，主要问题就落在优化任务的求解上。为此，已经提出了许多算法，例如牛顿型或梯度下降型算法。此类算法问题，以及许多相关的理论问题，超出了本书的范围，感兴趣的读者可参考，例如，[54, 67, 178]。最近，也提出了正则化版本，包括促进稀疏性的正则化项（参见，例如，[55]）。

# 20.8 学习低维模型：概率视角

在本节中，重点是从贝叶斯视角审视降维任务。我们的重点将更多地放在阐述主要思想上，而较少涉及算法流程；后者取决于具体模型，并可从第 12 章和第 13 章中已介绍的算法调色板中挖掘出来。我们通往低维建模的路径源于所谓的*因子分析*。

## 20.8.1 因子分析

因子分析最初由 Charles Spearman 在其著作 [169] 中提出。Charles Spearman（1863–1945）是一位英国心理学家，对统计学做出了重要贡献。Spearman 对人类智力感兴趣，并于 1904 年开发了该方法，用于分析多项认知表现指标。他主张存在一个一般智力因素（即所谓的 g 因子），可以通过将因子分析方法应用于智力测试数据来提取。然而，这一概念也有争议，因为智力包含多种成分（参见，例如，[84]）。

设 $\mathbf{x} \in \mathbb{R}^{(l)}$。因子分析模型假设存在 $m < l$ 个潜在的（隐含的）零均值变量或*因子* $\mathbf{z} \in \mathbb{R}^{(m)}$，使得

$$

x_i - \mu_i = \sum_{j=1}^{m} a_{ij} z_j + \epsilon_i, \quad i = 1, 2, \ldots, l,

$$

或者使用向量符号紧凑地写为，

$$

\mathbf{x} - \boldsymbol{\mu} = A\mathbf{z} + \boldsymbol{\epsilon},

$$

其中 `μ` 是 `x` 的均值，`A ∈ ℝ^(l×m)` 由称为*因子载荷*的权重 `a[i][j]` 构成。变量 `z[j]`，`j = 1, 2, …, m`，有时被称为*公因子*，因为它们对所有观测变量 `x[i]` 都有贡献，而 `ϵ[i]` 则是*独特*或*特定因子*。正如我们迄今为止所做的那样，且不失一般性，我们将假设数据已中心化，即 `μ = 0`。在因子分析中，我们假设 `ϵ[i]` 均值为零且互不相关，即 `Σ[ϵ] = 𝔼[ϵϵ^T] := diag{σ[1]², σ[2]², …, σ[l]²}`。我们还假设 `z` 和 `ϵ` 相互独立。`A` 的 `m` (`< l`) 个列向量构成一个低维子空间，而 `ϵ` 是不包含在该子空间中的 `x` 的那部分。现在提出的第一个问题是，公式 (20.79) 中的模型是否与我们熟悉的回归任务有任何不同。答案是肯定的。请注意，此处矩阵 `A` 是未知的。我们仅拥有观测样本集 `x[n]`，`n = 1, 2, …, N`，我们必须求出由 `A` 描述的子空间。这基本上是本章迄今为止所考虑的同一个线性模型，区别在于现在我们引入了噪声项。一旦 `A` 已知，就可以为每个 `x[n]` 求得 `z[n]`。

从公式 (20.79) 可以很容易地看出

```
Σ[x] = 𝔼[xx^T] = A𝔼[zz^T]A^T + Σ[ϵ].
```

我们将进一步假设 `𝔼[zz^T] = I`；因此，我们可以写成

```
Σ[x] = AA^T + Σ[ϵ]. (20.80)
```

因此，*A* 成为 ($\\Sigma[x] - \\Sigma[\\epsilon]$) 的一个因子。然而，如果这种分解存在，它并不是唯一的。如果我们考虑 $\\overline{A} = AU$，其中 *U* 是一个正交矩阵，这很容易验证。那么 $\\overline{A}\\overline{A}^{T} = AA^{T}$。这在解释单个因子时给因子分析方法带来了很多争议（例如，参见 [44] 进行讨论）。为了补救这一缺点，许多作者提出了处理旋转（正交或斜交）的方法和标准，以获得对因子的改进解释 [157]。然而，从我们的角度来看，目标是在低维空间中表达问题，这不是一个问题。任何正交矩阵都在由 *A* 的列张成的子空间内施加旋转，但我们不关心坐标的确切选择，即公因子。

有不同的方法来获得 *A*（例如，参见 [64]）。一种流行的方法是假设 $p(\\mathbf{x})$ 为高斯分布，并采用最大似然法针对定义方程 (20.80) 中 $\\Sigma[x]$ 的未知参数进行优化。一旦 *A* 可用，估计因子的一种方法是进一步假设这些因子可以表示为观测值的线性组合，即

$$

\\mathbf{z} = W\\mathbf{x}.

$$

后乘以 $\\mathbf{x}$，取期望，并回顾方程 (20.79) 以及 $\\mathbb{E}[\\mathbf{z}\\mathbf{z}^{T}] = I$，我们得到

$$

\\mathbb{E}[\\mathbf{z}\\mathbf{x}^{T}] = \\mathbb{E}[\\mathbf{z}\\mathbf{z}^{T}A^{T}] + \\mathbb{E}[\\mathbf{z}\\boldsymbol{\\epsilon}^{T}] = A^{T}.

$$

此外，

$$

\\mathbb{E}[\\mathbf{z}\\mathbf{x}^{T}] = W\\mathbb{E}[\\mathbf{x}\\mathbf{x}^{T}] = W\\Sigma[x].

$$

因此，

$$

W = A^{T}\\Sigma[x]^{-1}.

$$

因此，给定一个值 $\\mathbf{x}$，对应潜在变量的值通过以下方式获得：

$$

\\mathbf{z} = A^{T}\\Sigma[x]^{-1}\\mathbf{x}.

$$

## 20.8.2 概率 PCA

通过贝叶斯基本原理，这一老问题在 20 世纪 90 年代末获得了新的启示 [154,175,176]；该任务针对特殊情况 $\Sigma[\epsilon] = \sigma² I$ 进行了处理，并被命名为*概率 PCA* (PPCA)。潜在变量 `z` 配备了高斯先验，

$p(\mathbf{z}) = \mathcal{N}(\mathbf{z}|0, I)$，

这与早先的假设 $\mathbb{E}[\mathbf{z}\mathbf{z}^T] = I$ 一致，条件 PDF 选为

$p(\mathbf{x}|\mathbf{z}) = \mathcal{N}(\mathbf{x}|A\mathbf{z}, \sigma² I)$，

为简单起见，我们假设 $\boldsymbol{\mu} = 0$（否则均值将为 $A\mathbf{z} + \boldsymbol{\mu}$）。我们现在已经非常熟悉写出

$p(\mathbf{z}|\mathbf{x}) = \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}_{z|x}, \Sigma_{z|x})$， (20.84)

和

$p(\mathbf{x}) = \mathcal{N}(\mathbf{x}|0, \Sigma_x)$， (20.85)

其中（参见第 12 章公式 (12.17)、(12.10) 和 (12.15)）

$$

\Sigma_{z|x} = \left( I + \frac{1}{\sigma^{2}}A^{T}A \right)^{-1},

$$ (20.86)

$$

\mu_{z|x} = \frac{1}{\sigma^{2}}\Sigma_{z|x}A^{T}\mathbf{x},

$$ (20.87)

$\Sigma_x = \sigma² I + A A^T$。 (20.88)

请注意，使用贝叶斯框架，给定观测值集合 `x` 对应的潜变量的计算，可以自然地通过公式 (20.84) 中的后验概率 `p(z|x)` 获得。例如，可以选取相应的均值

```
z = (1/σ²) Σ_{z|x} A^T x.
```

利用矩阵求逆引理 (习题 20.4)，结果表明公式 (20.83) 和 (20.89) 完全相同；然而，现在这是我们贝叶斯假设的一个自然推论。

计算 `A` 的一种方法是对 `∏_{n=1}^N p(x_n)` 应用最大似然法，并关于 `A` 和 `σ²`（如果 `μ ≠ 0`，则还包括 `μ`）进行最大化。结果表明，`A` 的最大似然解由文献 [175] 给出：

```
A_ML = U_m diag{λ_1−σ²,…,λ_m−σ²} R,
```

其中 `U_m` 是一个 `l × m` 矩阵，其列为 `x` 的样本协方差矩阵中最大的 `m` 个特征值 `λ_i`（`i = 1, 2, …, m`）对应的特征向量，而 `R` 是一个任意正交矩阵（`R R^T = I`）。令 `R = I`，则 `A` 的列即为第 20.3 节讨论的经典 PCA 所计算出的（缩放后的）主方向。无论如何，`A` 的列张成了标准 PCA 的主子空间。请注意，当 `σ² → 0` 时，PPCA 趋近于 PCA (习题 20.5)。此外，结果表明

```
σ_ML² = (1/(l - m)) ∑_{i=m+1}^l λ_i.
```

之前建立的与 PCA 的联系并不令人惊讶。人们早已众所周知（例如，[5]），如果在因子分析模型中假设 `Σ[ϵ] = σ²I`，那么在似然函数的平稳点处，`A` 的列是样本协方差矩阵的缩放特征向量。此外，正如公式 (20.90) 所建议的，`σ²` 是被丢弃特征值的平均值。

估计 `A` 和 `σ²` 的另一种方法是通过 EM 算法 [154,175]。之所以可行，是因为我们拥有解析形式的 `p(z|x)`。给定观测变量和潜在变量的集合 `(x[n], z[n]), n = 1, 2, …, N`，完全对数似然函数由下式给出：

```
ln p(X,Z;A,σ²) = ∑_{n=1}^{N} ( ln p(x_n|z_n;A,σ²) + ln p(z_n) ) = - ∑_{n=1}^{N} ( l/2 ln(2π) - l/2 ln β + β/2 ||x_n - A z_n||² + m/2 ln(2π) + 1/2 z_n^T z_n ),
```
