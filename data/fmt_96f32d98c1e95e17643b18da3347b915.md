
### 定理条件

- (a) *如果* 算法 6.1 生成了有限个点 `x^1, x^2, …, x^k`（对于某个 `k ∈ ℕ`），则 `∇f(x^k) = 0_{ℝ^n}`。

- (b) *如果* `f` 连续且算法 6.1 生成了序列 `(x^i)_{i∈ℕ}`，则对于该序列的每一个积累点 `~x`，`∇f(~x) = 0_{ℝ^n}`。

- (c) *如果* `∇f` 连续且算法 6.1 生成的序列 `(x^i)_{i∈ℕ}` 收敛于某些 `~x ∈ ℝ^n`，则 `∇f(~x) = 0_{ℝ^n}`。

## **证明**

- (a) 该部分的断言是显而易见的。

- (b) 令 `~x` 为序列 `(x^i)_{i∈ℕ}` 的任意积累点，即 `~x = lim_{j→∞} x^i`。假设 `∇f(~x) ≠ 0_{ℝ^n}`。对于函数 `φ: ℝ_+ → ℝ`，

我们随后得到

```
$$\lim_{\lambda\to0^+} \frac{f(\tilde{x} - \lambda\nabla f(\tilde{x})) - f(\tilde{x})}{\lambda} = \lim_{\lambda\to0^+} \frac{\varphi(\lambda) - \varphi(0)}{\lambda} = \varphi'(0)$$
```

## 6 深度学习基础

`-∇f(~x) · ∇f(~x) < 0`。

因此，存在某些 `~λ > 0` 使得

`f(~x - ~λ∇f(~x)) < f(~x).`

根据引理 6.1 且由于 `∇f` 的连续性，我们进一步得出

`f(~x) > f(~x - ~λ∇f(~x)) = f(lim_{j→∞} x^j - ~λ ∇f(lim_{j→∞} x^j)) = lim_{j→∞} f(x^{j+1}) ≥ lim_{j→∞} f(x^j) = f(~x).`

这是一个矛盾。

(c) 由于序列 `(x^k)_{k∈ℕ}` 收敛于 `~x`，点 `~x` 是该序列唯一的积累点，且 (b) 中的陈述提供了断言。

如果迭代点属于 `ℝ^n` 的闭集，则确保了定理 6.2 中点的存在。

**示例 6.2** 我们将算法 6.1 的梯度下降法应用于简单优化

`min_{(x_1,x_2)∈ℝ^2} (x_1 - 3)^2 + 2(x_2)^2`。

在这里，目标函数 `f: ℝ^2 → ℝ` 由 `f(x_1, x_2) := (x_1 - 3)^2 + 2(x_2)^2` 对于所有 `(x_1, x_2) ∈ ℝ^2`给出。显然，`~x := (3,0)` 是该无约束问题的（全局）最小解。使用起始点 `x^0 := (-2, -2)`，我们得到了表 6.1 中的迭代点。起始点和前四个迭代点如图 6.8 所示。在该图中，我们可以看到差向量之间存在 90 度角。

`x^1 - x^0, x^2 - x^1` 等，或者 `λ_0 d^0 ⊥ λ_1 d^1 ⊥ λ_2 d^2 ⊥ λ_3 d^3`，或者简单写为 `d^0 ⊥ d^1 ⊥ d^2 ⊥ d^3`。

**命题 6.2** (算法 6.1 中梯度下降法的字形行为) 设目标函数 `f : ℝ^n → ℝ` 可微，令算法 6.1 生成迭代点 `x^1, x^2, …`。对于迭代点 `x^i`（`i ∈ ℕ`），满足：

```
$\nabla f(x^i) \perp \nabla f(x^{i-1}) = 0.$
```

**证明** 令 `x^i`（`i ∈ ℕ`）为任意迭代点。如果我们定义函数 `φ : ℝ_{++} → ℝ`

```
$\varphi(\lambda) := f(x^{i-1} - \lambda \nabla f(x^{i-1}))$ 对于 $\lambda > 0$,
```

则对于最优步长 `λ_{i-1} > 0`，我们有

```
$\varphi(\lambda_{i-1}) \le \varphi(\lambda)$ 对于所有 $\lambda > 0.$
```

`λ_{i-1}` 是 `ℝ_{++}` 的极点，作为必要的最优条件，我们得到 `φ'(λ_{i-1}) = 0`。因此，我们得到

```
$0 = \varphi'(\lambda_{i-1})$
$\frac{d}{d\lambda} f(x^{i-1} - \lambda \nabla f(x^{i-1}))_{\lambda=\lambda_{i-1}} = -\nabla f(x^{i-1} - \lambda_{i-1} \nabla f(x^{i-1}))^T \nabla f(x^{i-1})$
$= x^i$
= -\nabla f(x^i) \perp \nabla f(x^{i-1}),$
```

这暗示了断言。但在实践中，我们并不使用最优步长，而是使用某些近似值，梯度 `∇f(x^i)` 和 `∇f(x^{i-1})` 通常并不正交。

**备注 6.2 (算法 6.1 中梯度下降法的缺点)** 除去其优点外，算法 6.1 中的梯度下降法也有显著的缺点。我们讨论两种重要情况：

- (a) 目标函数 `f` 的（全局）最小点位于一个“狭长山谷”中，由于一个不利的起始点 `x^0`，迭代点可能彼此靠近，尽管该点被认为远离。在这种情况下，无法观察到方法的收敛性。一个典型的例子是罗森布罗函数 [121] `f: ℝ^2 → ℝ`，

```
$f(x_1, x_2) := 100(x_2 - x_1^2)^2 + (1 - x_1)^2$ 对于所有 $(x_1, x_2) ∈ ℝ^2.$
```

`f` 的等高线如图 **6.9** 所示，`~x := (1,1)` 其中 `~x=0` 是 `f` 在 `ℝ^2` 上的（全局）最小点。

### 6.6 梯度方法

![](img/e4a2e491dbba0d9f71ab293f149cd5b_119_0.png)

**图 6.9** Rosenbrock 函数 `f: ℝ^2 → ℝ` 的等高线，对于所有 `(x_1, x_2) ∈ ℝ^2`，`f(x_1, x_2) := 100(x_2 - x_1^2)^2 + (1 - x_1)^2`。

(b) 梯度下降法基本上是确定目标函数梯度的零点。`∇f(x)=0` 是全局或局部极小点的必要条件。由于该方法属于下降类（即迭代点的函数值逐步减小，见引 6.1），梯度下降法会运行到起始位置的局部极小点。为了找到（全局）最小值，建议从不同的起点重复执行该过程，并在所有近似解中选择目标值最小的一个。一个例子是 Himmelblau 函数 [60]，`f: ℝ^2 → ℝ`

`f(x_1, x_2) := (x_1^2 + x_2 - 1)^2 + (x_1 + x_2 - 7)^2`，对于所有 `(x_1, x_2) ∈ ℝ^2`。

Himmelblau 函数由图 6.10 中的等高线所示。它有四个（全局）最小值（位于 `(3.58, -1.85)`、`(-3.78, -3.28)`、`(-2.81, 3.13)` 和 `(3, 2)`）、一个局部极大值点（位于 `(-0.27, -0.92)`）以及四个鞍点（位于 `(3.39, 0.07)`、`(-3.07, -0.08)`、`(-0.09, 2.88)` 和 `(-0.13, -1.95)`），在这些点 `∇f` 也为零。

在算法 6.1 中确定最优步长通常需要巨大的计算量，因此使用了简单的方法。我们现在考虑步长 `λ_i` 可以在某个范围内任意选择的可能性。在适当的假设下，我们可以证明改进后的算法 6.1 的线性收敛性。为此我们需要两个引理：

**引理 6.2**（变分不等式 [42]）*对于某些 `μ > 0`，令函数 `f : ℝ^n → ℝ` 是 `μ`-强凸且可微的。那么有*

`∇f(x)^T(y-x) ≥ f(x) - f(y) + μ/2 ‖x-y‖_2^2`，对于所有 `x, y ∈ ℝ^n`。

**证明** 根据命题 1.12，得到

`f(y) ≥ f(x) + ∇f(x)^T(y-x) + μ/2 ‖y-x‖_2^2`，对于所有 `x, y ∈ ℝ^n`，

这意味着：

`∇f(x)^T(x-y) ≥ f(x) - f(y) + μ/2‖x-y‖_2^2`，对于所有 `x, y ∈ ℝ^n`。

**引理 6.3（Lipschitz 连续性 [42, 2.28]）** 令函数 `f:ℝ^n → ℝ` 可微，梯度 `∇f` 是 Lipschitz 连续的，Lipschitz 常数为 `L > 0`，且 `~x ∈ ℝ^n` 是 `f` 的极点。那么有

`‖∇f(x)‖^2 ≤ 2L(f(x)-f(~x))`，对于所有 `x ∈ ℝ^n`。

**证明** 根据 Garrigos 和 [42, 2.25]，不等式

`f(y) ≤ f(x) + ∇f(x)^T(y-x) + L/2‖y-x‖_2^2`，对于所有 `x, y ∈ ℝ^n`

有效。因此，对于 `y := x-1/L ∇f(x)`

`f(x-1/L ∇f(x)) ≤ f(x)-1/L ∇f(x)^T∇f(x) + L/2‖-1/L ∇f(x)‖_2^2 = f(x)-1/L‖∇f(x)‖_2^2+1/(2L)‖∇f(x)‖_2^2 = f(x)-1/(2L)‖∇f(x)‖_2^2`，对于所有 `x ∈ ℝ^n`。

因此，我们得到

`‖∇f(x)‖^2 ≤ 2L(f(x)-f(x-1/L ∇f(x))) ≥ 2L(f(x)-f(~x))`，对于所有 `x ∈ ℝ^n`，这需要证明。

**定理 6.3（梯度方法的收敛性 [42, 3]）** 对于 `μ > 0`，令函数 `f:ℝ^n → ℝ` 是 `μ`-强凸且可微的，梯度 `∇f` 是 Lipschitz 连续的，常数为 `L`，且 `~x ∈ ℝ^n` 是 `f` 的极点。如果算法 6.1 任意选择 `λ_i ∈ (0, λ_max]`（其中 `0 < λ_i ≤ min{1/L, 1/μ}`，而不是算法 6.1 第 7 行的最优步长）生成序列 `(x^i)_{i∈ℕ}`，则

`‖x^{i+1}-~x‖_2^2 ≤ (1-λ_i μ)‖x^i-~x‖_2^2`，对于所有 `i ∈ ℕ`

且 `‖x^t-~x‖_2^2 ≤ (1-λ_i μ)^t ‖x^0-~x‖_2^2`，对于所有 `t ∈ ℕ`，其中 `1-λ_i μ ∈ (0, 1)`。

**证明** 根据引 1.1，函数 `f` 有唯一的极点 `~x`，因为 `f` 是 `μ`-强凸且连续的。对于任意 `i ∈ ℕ∪{0}`，我们得到

`‖x^{t+1}-~x‖_2^2 = ‖x^t-~x-λ_i∇f(x^t)‖_2^2`

`= (x^t-~x-λ_i∇f(x^t))^T(x^t-~x) + λ_i^2‖∇f(x^t)‖_2^2`

`= ‖x^t-~x‖_2^2 - 2λ_i∇f(x^t)^T(x^t-~x) + λ_i^2‖∇f(x^t)‖_2^2`

`≥ ‖x^t-~x‖_2^2 - 2λ_i(f(x^t)-f(~x) + μ/2‖x^t-~x‖_2^2) + λ_i^2‖∇f(x^t)‖_2^2`（由引 6.2）

`≤ (1-λ_i μ)‖x^t-~x‖_2^2 - 2λ_i(f(x^t)-f(~x)) + λ_i^2‖∇f(x^t)‖_2^2`（由引 6.3）

`≤ (1-λ_i μ)‖x^t-~x‖_2^2 - 2λ_i (1-λ_i L)/L (f(x^t)-f(~x))`

`≥ 0`（因为 `λ_i < 1/L`）

`≤ (1-λ_i μ)‖x^t-~x‖_2^2`，这证明了不等式 (6.7)。不等式 (6.8) 是不等式 (6.7) 的直接结果。结合 `λ > 0` 和 `μ < 1/L`，结论 (6.9) 立即成立。

**推论 6.1（梯度方法的线性收敛性）** 满足定理假设。那么序列 `(x^t)^{t ∈ ℕ}` 收敛于 `f` 的唯一极点 `~x`。

**证明** 从不等式 (6.8) 和条件 (6.9) 显看出，序列 `(x^t)^{t ∈ ℕ}` 收敛于 `f` 的唯一极点 `~x`。不等式 (6.7) 结合条件 (6.9) 意味着序列 `(x^t)^{t ∈ ℕ}` 是线性收敛的。
