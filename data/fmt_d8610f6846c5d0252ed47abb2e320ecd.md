
同样，被动光分用器试图分割通过光纤的光束并将一部分引导到传感器。虽然这些分用器需要额外的硬件，但如果设备故障，原始信号可能受到很大影响。然而，这种方法存在一些缺点，特别是在千兆速率线线上。千兆连接对功率非常敏感，如果安装了被动分用器，可能会出现高错误率、失真或失败。要分用千兆线路，必须使用`active` tap（主动分用器，或主动继电器）。主动分用器在分用器设备中完全终止信号，将信号副本发送到本地接口，并将原始信号移动到转发器。然后该转发器在必要时放大原始信号，并将其传递到原始目的地。这种方法对于千兆线路效果良好，但代价是在链路中增加了另一个电气设备。如果主动分用器故障，整个电路可能会保持断开状态，从而提醒管理员某些情况异常。需要注意的是，使用这些方法分用网络具有改变线路传输特性的潜力。作为安全专业人员，我们应该准备好调查功率、阻抗或错误率的突然波动，因为这些可能是线路被分用的迹象。

## 集线器 (Hubs)

另一种收集方法是直接从中间设备捕获流量。如果由于某种原因，所有主机都连接到集线器，那么只需要监控机通过网线连接到同一设备并启动捕获软件即可。因为集线器平均地共享所有接口进出的流量，它们依赖于连接的主机保持诚实并仅监听分配给它们的内容。一种聪明的技术是攻击者故意引入集线器，将其放置在网络中的瓶颈处，并在那里收集流量。集线器变得越来越罕见，即使在家庭中使用也是，已被更智能的交换机取代。

## 交换机 (Switches)

在交换环境中，数据单元（称为`frames`）只转发到它们所属的目的地。当每个帧进入交换机时，交换机会会将输入帧的物理媒体访问控制 (`MAC`) 地址与其现有的地址列表以及交换机上的匹配物理端口进行比较。当找到匹配项时，交换机会将数据转发到相应的接口，然后到达目的设备。`MAC` 地址是在制造期间分配给网卡的不可变值（尽管可以通过操作系统进行伪造），因此在正常情况下，交换机可以确定数据正发往应该去的地方。尽管流交换机的每个数据包都会受到更多的审查，但交换机仍然有数据数据的方法。

在讨论如何在交换网络上实现捕获之前，你理解地址解析协议 (`ARP`) 的工作原理非常重要。`ARP` 是网络设备确定特定`IP`地址链接到哪个`MAC`地址的方法。每个主机都维护一个`ARP`表，将`IP`和`MAC`地址相互映射。因此，每当主机需要向某个`IP`地址发送位数据时，它会在自己的表中查找相应的`MAC`地址，然后将数据转发到线路上。交换机随后接受该数据并将其转发到正确的目的接口。如果主机不知道某个`IP`地址的`MAC`地址，它将使用`ARP`请求询问整个网络，例如“谁是 10.10.10.10？”识别出该`IP`地址为它自己的机器将回复其`MAC`地址。原始发送者随后更新其`ARP`表并将数据发送到目的地。

## ARP 毒骗

在交换环境中，使用名为`ARP poisoning`的技术来嗅探流量有两种方法。第一种 ARP 毒骗方法涉及通过大量的 ARP 回应包来冲击交换机。每当交换机收到 MAC 地址的更新时，它都会调整其内部转发表以反映该变化。如果这种操作足够频繁，表就会溢出，某些交换机将无法正确转发数据，并切换到集线器模式，将所有流量广播到所有接口。

另一种方法涉及篡改网络上特定主机的`ARP`表。假设攻击者位于包含`Host A`和`Host B`的网络中，并对观察它们的对话感兴趣。通常情况下，交换机基于 MAC 的裁决不会允许这样做，因为攻击者的 MAC 地址不会参与该对话。通过记录`Host A`和`Host B`的 IP 和 MAC 地址，攻击者可以利用`ARP`固有的信任机制。攻击者的第一步是向`Host B`发送一个伪造的`ARP Reply`消息，指示`Host A`的 IP 地址现在与攻击者的 MAC 地址关联。对于`Host B`来说的是，这条未请求的信息会被视为事实并接受，`Host B`将更新其`ARP table`。攻击者随后会对`Host A`执行同样的操作，假装这次自己是`Host B`，并为未来所有与`Host B` IP 地址相关的通信提供其自己的 MAC 地址。此时，`Host A`和`Host B`的`ARP tables`都被毒化了，当它们尝试互相发送消息时，消息最终将流向攻击者。此时，攻击者可以做很多事情，例如捕获数据，甚至修改并将其转发到原始目的地。这被称为中间人攻击 (`man-in-the-middle`, MITM）。在许多情况下，攻击者进行`MITM`攻击的目标是通过插入通信会话中间并充当系统之间的代理，收集登录和身份验证数据、加密密钥或其他任何秘密信息。

## 镜像

大多数企业级交换机支持一种名为`port mirroring`的功能，它可以复制单个端口或选定范围的数据包流量，并将这些包发送到同一设备上的单独输出端口。端口镜像在网络中用于排排除网络问题或便于流量分析，但如果处理不当，即使对于授权的网络管理员，也可能产生严重的法律后果。如果攻击者获得了交换机的访问权限，他可以开启端口镜像并收集通过该交换机的每一比特数据。请注意，接收所有复制包的目标端口活动量将远高于所有其他端口，因此更有可能丢包——在最坏的情况下，可能会无法运行。

## 考试提示

除非在路由器接口上操作或使用 ARP 毒骗或端口镜像，否则通常无法捕获交换网络的所有流量。

# 无线网络注意事项

无线网络允许通过射频 (RF) 数据连接对网络进行无绳访问。它们的工作原理是在一个区域覆盖信号以增加设备连接性并降低基础设施成本，因为可能安装的网络接入点较少。它们在设计和保护网络时还引入了需要检查的新领域。由于信号一旦超出组织的物理范围就很难简单地限制，路人可以使用上述任何方法观察网络流量。因此在被动侦察方面，无线网络比其有线对应设备更安全。解决此问题的快速方法是使用安全的加密算法来保护通过网络设备之间的所有流量。这种方法的成本并不高，而且会让攻击者的工作变得困难得多，因为他无法理解任何捕获的数据。

在捕获网络流量时，你还需要额外的考虑。捕获无线流量需要理解主机与接入点之间的关系以及捕获的目标是什么。如果你已经连接到无线网络，并且只是尝试记录网络上连接设备之间的流量，`Wireshark`在这种情况下运行良好。许多无线卡支持混杂模式 (`promiscuous mode`)，就像在有线网络上一样，这种模式允许客户端看到遍历网络的所有流量，前提是客户端已经是网络的一部分。然而，如果你坐在网络外部，并试图了解哪些客户端连接到哪些接入点，你还需要多执行几步。如果客户端机器无法加入无线网络，则无线网卡必须能够在监控模式 (`monitor` mode）下运行，捕获软件才能看到`802.11`数据包。监控模式允许观察者在不关联任何接入点的情况下，监听多个通道上的所有`802.11`活动。这在收集初始化向量 (`IVs`) 时非常有用，例如在尝试破解过时的有线等效协议 (`WEP`) 时。在许多情况下，网卡可以监听许多通道，但只能在单个通道上捕获。要在多个通道上捕获则需要多张网卡。

## 虚拟化技术

虚拟化 (`Virtualization`) 是创建和使用计算机和网络资源，以便根据需要随时运行各种操作系统和应用程序实例。虚拟化技术彻底改变了 IT 操作，因为它们大大减少了提供各种和服务网络功能所需的硬件。虚拟化的持续使用使得大型企业能够在不增加显著开销的情况下，在其 IT 运营中实现极大的灵活性。对于普通用户来说，虚拟化证明是接触新软件和培训的低成本方式。虽然虚拟化从互联网早期就开始存在，但直到 2000 年才在企业和家庭计算中取得立。

## 虚拟机程序

如前所述，虚拟化通过创建逻辑存储、CPU、内存、网络和应用程序的大池并置于公共物理平台上来实现。这通常使用称为虚拟机程序的软件完成，该程序管理物理硬件并执行在多个实例之间共享这些资源所需的功能。简而言之，得益于巧妙的硬件和软件管理，一台物理机可以托管一系列不同的计算机系统，即虚拟机。虚拟机程序分为 1 类和 2 类。1 类虚拟机程序也称为裸金属虚拟机程序 (`bare-metal`)，因为虚拟机程序软件直接运行在主机计算机硬件上。1 类虚拟机程序直接访问所有硬件并管理虚拟机操作系统。今天更流行的 1 类虚拟机程序包括`VMware ESX`、`Microsoft Hyper-V`和`Kernel-based Virtual Machine (KVM)`。2 类虚拟机程序运行在已存在的操作系统内部。这些虚拟机程序就像为操作系统编写的任何其他软件一样，允许虚拟机操作系统共享虚拟机程序可以访问的资源。流行的 2 类虚拟机程序包括`VMware Player`、`VirtualBox`和`Parallels`。

随着虚拟化软件的成熟，一个名为`containers`的新分支应运而生。操作系统运行在虚拟机之上，并共享裸机提供的资源；而容器运行在操作系统之上，并共享宿主机操作系统提供的资源。容器软件并不是为客户操作系统抽象硬件，而是为运行在其之上的应用程序抽象操作系统的内核。这使得运行许多应用程序时具有极低的开销，并提高了实例部署的速度，因为不需要为每个应用程序都启动一个完整的虚拟机。相反，可以将应用程序、服务、进程、库以及任何其他依赖项封装成一个单元。此外，每个容器都运行在沙箱中，唯一的交互手段是通过用户界面或应用程序编程接口（API）调用。容器化实现了快速的开发运维，因为开发者可以更快地测试代码，只需更改容器中必要的组件然后重新部署。

## 网络功能虚拟化与软件定义网络

既然为了操作系统和应用程序而对硬件进行虚拟化是合理的，那么我们可以推论，可以用虚拟克隆来替代各种网络功能的自定义硬件。这就是网络功能虚拟化（NFV），它是大规模数据中心和云计算资源的关键组件。路由、交换、入侵防御和负载均衡等关键功能都可以由运行虚拟化设备的同一硬件提供。NFV 严重依赖于`orchestration`（编排）的概念，即虚拟资源的自动配置和管理。更进一步，这种对网络功能的管理（包括流量分析和优化）是软件定义网络（SDN）的核心。SDN 最大的特征是网络控制部分和数据部分的分离，允许网络独立于所使用的硬件进行演进。SDN 和 NFV 是互补的，并预示着网络架构和管理的重大转变。

## 安全

从安全的角度来看，虚拟机监控为企业的运营增加了多项益处。虚拟化增加了系统的深度，使得攻击者更难准确感知真实环境的状况。再加上使用虚拟工具不断更改网络拓扑的能力，这从根本上改变了对网络进行侦察的成本。这种投入的增加通常足以阻止许多攻击者，因为他们往往会选择去寻找更容易攻克的“目标”。

容器化的普及也让层 7 安全（或`application-layer`防墙）得以实际应用。传统做法的一个主要问题是，如果通过对低级协议的限制来为范围应用程序定义所有必要的规则是非常费力的，甚至是不可能的。例如，标准防火墙可以很容易配置为拦截除 HTTP 流量以外的所有内容。然而，通过 80 端口到达攻击（如 SQL 注入和跨站脚本攻击 XSS）仍然被允许，因为这些防火墙将此类恶意代码视为有效请求。由于无法从第 3 层或第 4 层轻松区分恶意和正常的应用程序数据，传统的防火墙不再适用于我们日益多样化的应用程序环境。应用层防火意味着管理员拥有更细粒度的控制权，并且允许或拒绝特定的 Web 应用程序请求。

## 云计算

`Cloud computing`（云计算）是一个用于描述由高性能、分布式计算所支持的广泛服务的术语。`on-premises`（本地部署）解决方案要求硬件和软件物理上位于组织内部，而云解决方案通常只需要与提供者建立网络连接，大部分计算和存储都在提供者处进行。在描述云提供的功能时，我们将分为三类：基础设施即服务（IaaS）、平台即服务（PaaS）和软件即服务（SaaS）。

### IaaS

基础设施即服务（IaaS）为用户提供了对云服务提供商托管的计算平台的完全管理控制权。一个示例是启动一个 Windows 2012R2 服务器实例，然后你可以按照任何你的方式对其进行配置。云计算对企业极具吸引力，因为它减少了对硬件解决方案的预投入，而这些硬件随着技术进步必须不断更换。公司现在不再按照传统的周期购买硬件，而是可以订阅 IaaS 服务来执行相同的任务，而无需担心具体如何执行。此外，公司可以更容易地进行扩展，而无需等待安装他们未计划需要的计算或存储设备。

### PaaS

在平台即服务（PaaS）中，用户可以访问一个通常构建在服务器操作系统上的计算平台。例如，你可以启动一个预配置为提供 Web 服务的 Windows Server 2012R2 实例，而不是自己构建它。然而，服务提供者通常负责配置和保护平台，因此用户通常不会获得整个平台的管理权限。这就是现代开发团队在编程项目上实时协作的方式。它包含了使用通用环境开发、测试、部署和维护应用程序所需的各种服务。在容器化等技术的推动下，PaaS 允许来自不同贡献者的开发运维工作。

### SaaS

软件即服务（SaaS）为用户提供了对服务提供者托管的特定应用程序的访问。SaaS 受欢迎的原因在于，随着用户在移动平台上生成和共享内容，将软件移动到 Web 端的需求应运而生。用户不再从本地安装的应用程序工作，软件而是从中心位置运行并在那里进行管理。用户不再负责安装、妥善执行补丁和应用更新。相反，他们只需要使用软件提供的网络界面，其他一切都在后台完成。

## 安全

云通过提高应用程序的可用性和速度增强了易用性，让普通用户更容易利用技术带来的好处。然而，由于许多资源是去中心化的，身份管理的挑战随之出现。对于访问计算机资源、应用程序和数据的身份验证（这些内容都可能是移动的）是一项挑战。

## 防御侦察

侦察无处不在，且对于攻击者来说是一项低成本活动。虽然采取负责任的网络行为至关重要，但试图完全隐藏你的公开足迹可能是不现实的，特别是当你的组织高度依赖公共形象时。因此，最佳防御是对自己的网络进行扫描。定期识别网络中的关键点，并对你的组织进行漏洞扫描，一旦发生实际事件，将产生丰厚的回。这包括定期对可疑流量进行`log reviews`（日志审计），以及检查防火墙和路由器访问控制列表（ACL）的最新性。请记住，现代网络设备可以就其观察到的活动生成海量数据，这可能导致人工审查不再一项合理的任务。日志有多种形式，是关于系统或跨网络发生某些事件的简短说明。`syslog`是一个广泛使用的报告和存储消息标准示例。根据网络流量的大小，每天可能会生成数千条 syslog，因此找到一种管理消息的方法至关重要。解决这一问题的方案是使用`security information and event management (SIEM)`系统。通过聚合设备日志，SIEM 为分析师和管理员提供了详细的监控能力、事件关联以及仪表板视图。

## 职业工具

有大量的工具可用于环境侦察。本节中的列表并非详尽，但它包含了一些你作为分析师工作时需要了解、且对于通过 CSA+ 考试非常有用的知名工具。此列表仅应作为你自学的起点。

### OWASP Zed Attack Proxy

与 Nikto 类似，开放 Web 安全项目（OWASP）的 Zed Attack Proxy（ZAP）是一个开源 Web 漏洞扫描器。`ZAP`可用于评估现有 Web 服务器，但也具有 Web 代理功能，允许用户捕获并操纵通过它的网络流量。开放安全项目（OWASP）是一个非营利组织，其目标是维护和促进 Web 应用程序部署和使用的最佳实践。作为一个社区支持的组织，OWASP 通过其网站和现场活动提供各种材料。

### Nessus

`Nessus`是一种漏洞扫描器，最初是一个免费的安全扫描器。虽然`Nessus`现在是专有软件，但其插件集非常庞大。`Nessus`由两个主要部分组成：软件守护进程和 Nessus 服务器。`Nessus`包含了基本的端口扫描功能，但其真实实力在于全面的配置检查和报告。`Nessus`将检查漏洞、常见的配置错误、默认密码的使用以及合规性水平。

### netstat

`netstat`（网络统计）存在于每个主流操作系统中，是一个命令行实用工具，用于显示网络连接、接口统计、监听端口和进程标识符。`Netstat`提供了一种快速检查给定主机上谁在与谁通信的方法。例如，命令`netstat -l`（小写字母 L）将显示所有正在监听的端口。虽然我们预期服务器会有各种此类端口，但工作站应该只有少数几个。

### Wireshark/TShark

`Wireshark`及其命令行版本`TShark`是两种网络协议分析器，或称`packet analyzers`。`Wireshark`是网络工程师、安全分析师和攻击者不可或缺的工具。该开源软件适用于 Mac OS、Linux 和 Windows，其工作方式与`tcpdump`类似，但也提供了数据包类型的图形化表示和高级过滤。`Wireshark`可以直接与某些有线和无线网卡交互，允许用户将设备设置为混杂模式以进行更完整的网络捕获。在捕获完成后，`Wireshark`提供统计分析和制图功能。
