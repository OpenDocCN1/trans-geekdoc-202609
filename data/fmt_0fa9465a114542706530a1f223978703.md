
### 构造方法

```java
public Point3D(int x, int y, int z) {
    super(x, y);
    this.z = z;
}
```

### 修改器方法

```java
public void setX(int x) {
    x = x;
}

public void setY(int y) {
    y = y;
}

public void setZ(int z) {
    z = z;
}
```

### 访问器方法

```java
public int getX() {
    return x;
}

public int getY() {
    return y;
}

public int getZ() {
    return z;
}
```
