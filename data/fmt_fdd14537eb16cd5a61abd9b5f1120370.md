
# 密码与成本

将密码作为哈希值存储的好处是为密码增加了一层防御（Gupta 等人，2015），因为如果系统被完全攻破，攻击者可以窃取密码哈希值（Gupta 等人，2015 年 5 月），但随后还面临破解哈希以还原原始密码的进一步任务（假设他们不使用本章范围之外的 `pass the hash`（SANS 2010）技术）。用户的原始密码从未存储在系统中；存储的只是代表它的哈希函数的数学输出，这使得攻击者更难利用。用户在注册后每次登录时，输入的密码会再次被哈希，输出结果与注册阶段存储的哈希值进行比较；如果匹配，则意味着输入了正确的密码。这在以下简化图中有所体现：

回到密码本身，大多数企业密码策略针对普通用户的密码长度倾向于十二个字符或更少。这就是将限制任意设定为十二个字符的原因。作者还将排除长度为空至八个字符的密码，因为如果攻击者有足够的决心，这些密码可以通过传统手段暴力破解。例如，作者的机器在没有任何额外配置或考量的情况下，能够利用其图形处理单元 (`GPU`)——该 GPU 现已六年历史——以每秒 365.1 兆（百万）次哈希 (`365.1 MH/s`) 的速度，利用 Hashcat 默认输入字符集检查 `MD5` 哈希函数所有可能的密码组合，如下两张图所示：

上图显示，即使是一台过时且未调优的系统，利用一块旧 `GPU`（NVIDIA Corporation GK106M [GeForce GTX 765M]），也能在 2 分 29 秒内检查 55,146,708,992 个密码。其总完成时间可按小时计算。

即使只有一块旧 `GPU` 的旧系统，也能在极短的时间内猜测所有可能的组合。加密货币挖矿的最新发展推动了哈希破解技术的进步；这可以从市面上可购买的 Antminer S15-28TH/s（Britain 2019）中看出，其宣称每秒可达 28 万亿次哈希检查 (`28 TH/s`)。这表明，如果能将此技术调整为检查 `MD5` 哈希（如我们的场景中有 5,533,380,698,112 个约 5.5 万亿种可能的组合需要检查），Antminer S15 将在 0.198 秒内以 `28 TH/s` 的速度完成所有可能组合的检查。正是出于这个原因，作者认为八个字符或更少的密码不再具有学术研究价值。然而，专用哈希挖矿软件的技术是相关的。

自从发现微软 LM 哈希函数的弱点以来，许多组织的最佳实践是要求密码长度为九个或更多字符。

发现 LanMan (`LM`) 哈希函数存在缺陷，表明密码实际上被分成两部分再进行哈希，这意味着可以通过实际上猜测两次四字符密码来暴力破解密码。更糟糕的是，其中一个字符是其他字符的校验和，使得这两半实际上只有四个和三个字符长。`NTLM` 哈希是 `LM` 哈希的替代品。微软在其文章“如何防止 Windows 在 Active Directory 和本地 SAM 数据库中存储你的密码的 LAN 管理器哈希”中提到了 `LM` 的弱点。对于本章而言，这些都相对无关紧要，除了进一步证明我们为何只关注九到十二个字符长的密码，因为这是一种社会和文化规范，或许是由技术发现引起的。

用户的密码或哈希值通常存储在其注册的系统上，或被推送到另一个系统（如数据库服务器）进行存储。无论存储在何处，必须攻破存储密码的系统或其通信链路，攻击者才能窃取密码或哈希值。或者，如果攻击者试图入侵的系统没有速率限制（即允许的密码尝试次数不受限制），那么密码尝试的速率将受限于系统处理这些尝试的能力。这被称为在线暴力破解攻击。此外，跨站脚本攻击（XSS）是针对 Web 应用程序的此类攻击之一，用户必须妥协其浏览器资源，而哈希可用于使系统对这类攻击具有鲁棒性（Gupta 等人，2017）。

那么，利用英国键盘创建的密码，最大可能的密码组合数是多少？以下是基于英国键盘、基于 ASCII 可打印字符为本章生成的字符集：

*   **数字**：`0123456789`
*   **小写字母**：`abcdefghijklmnopqrstuvwxyz`
*   **大写字母**：`ABCDEFGHIJKLMNOPQRSTUVWXYZ`
*   **特殊字符**：`` `~!@#$%^&*()-_=+[]\{}|;':",./<>?£ ``

如果包含空格字符，总共是 96 个可能的字符。有方法可以获得更高的数字，但作者认为这已足够，且能覆盖大多数人的使用情况。使用 Crunch¹（Kali Linux 渗透测试操作系统中包含的密码生成工具），我们可以看到每种可能组合的纯文本结果的计算输出统计数据，如下图所示：

## 密码与成本

根据微软发布的 Azure Data Lake Storage 价格表（Microsoft 2019），撰写本章时价格为 £0.001/GB/月，该列表的存储成本约为 £6,510,191.62（四舍五入到分），年成本为 £78,122,299.44。显然，这个数字超出了大多数实体的承受范围，但让我们结合英国的国防预算来考虑这个数字。

根据“UK Defence in Numbers”（Ministry of Defence UK, 2017），英国 2016/17 财年的支出为 353 亿英镑，是世界第 5 大国防预算。这还不包括国防共同既得利益与情报界及执法部门预算分配的结合。那么，一个类似英国的国家能否负担得起一个包含所有 9–12 位可能密码的数据库？答案是肯定的，即使是以最基础的原始形式，事实上，它们可能相对轻松地负担得起考虑超过 12 位密码的数据库。

那么，接下来的问题是——他们会这么做吗？从技术角度来看，答案是否定的。因为没有应用任何压缩，意味着花费的钱超过了必要数额。仅应用基本的 zip 压缩，就能大幅降低总成本。此外，我们感兴趣的实际上并非所有可能密码的列表，因为在大多数情况下，这些密码是以哈希形式存储的。因此，如果应用到上述示例中，数据集中的每个条目都需要相应的 MD5 哈希值才有用。假设一字节对应一字符，MD5 哈希有 32 字符，这会给数据集中的每个条目增加 32 字节。我们的数据集有 692,533,995,824,480,256 行，因此（`(692533995824480256 * 32 = 2.2161088e+19)`（`2.2161088e+19` 字节转换为 GB = `22161088000`）（`22161088000` GB 转换为 PB = `22161.088PB`）需要额外 22162 PB。同样基于微软发布的 Azure Data Lake 价格，这将构成每月额外 £22,161,088 或每年 £265,933,056 的成本（压缩前）。考虑到这只是单一哈希类型的成本，这是一个显著的成本增量。

仔细研究此页面时，我们也无法再回避盐值的话题。存储密码时的一个良好实践是向哈希函数引入盐值。盐值是引入数学运算的随机值，用于增加复杂性，使攻击者更难暴力破解答案。坚持我们的示例，MD5 哈希列出了七种哈希模式变体。我们已经计算了在公共云环境中存储所有可能 MD5 哈希的成本，如下表所示：

### 表 1. MD5 哈希存储成本

| Mode | Hash Type | Example Hash | Cost per Year |
| --- | --- | --- | --- |
| 0 | MD5 | `8743b52063cd84097a65d1633f5c74f5` | £265,933,056 + £78,122,299.44 |

查看 Hashcat 示例中的下一个条目，显示一个示例 MD5 及其关联的盐值为 `01dfae6e5d4d90d9892622325959afbe:7050461`，冒号后的关键数字 `7050461` 即为盐值。在此格式下，其最大值为 9,999,999。这意味着，对于原始密码列表中的每一行，我们还需要存储 9,999,999 个 32 字节的 MD5 哈希。这使得数据库成本（不压缩）约为 2.659 万亿英镑。无需进一步计算，这显然超出了单一国家的预算，实际上当考虑到下表所示的所有不同哈希类型和格式（仅针对 MD5 哈希类型）时，极有可能超出任何国家集团的预算：

## 总结与结论

### 结论

是否有人可能拥有包含世界上所有类型密码的预计算数据库？答案显而易见：没有。这将是一项毫无意义且徒劳的练习。可能性的数量惊人，相关成本更是天文数字。然而，正如本章前面所见，从 GPU 破解向专用加密货币挖矿机的进步，实际上可能正在加速密码的灭绝。

解决这一问题的一种更切合实际的方法，是考察定制版 `Antminer S15-28TH/s` 或类似专用技术解决该问题所需的时间。该设备在本章撰写时的零售价为 £772.14（$1020）。假设制造商增加了足以使其值得投入时间的利润率，我们或许可将该数字向下取整，估算批量生产成本约为 £500。鉴于这是估算值，若将单位成本翻倍以弥补估算偏差及为支持多种哈希类型、联网所需的定制和布线成本，则单节点价格约为 £1000。

现在重新审视本章前面提到的国防预算背景。若能提出合理的商业论证，在三到五年内资本化的项目，硬件成本达一亿英镑并不算过分。这意味着一个国家可负担制造十万台此类设备（基于前述单价估算），每个节点每秒潜在检查高达 28 万亿次哈希（取决于哈希类型）。此时，技术可行性层面的数学问题似乎已解决：在合理时间内核对所有可能组合是可行的。事实上，在此规模和能力下，更大的技术挑战将是功耗及相关电力成本。

鉴于以上分析，你的密码是否可能在几秒钟内仅凭当前市售组件被破解？简短回答：是的。事实上，除非密码异常长且复杂，否则对于拥有时间、资源和专业知识的实体而言，这只是微不足道的小事。
