
## 15.3 学习表达的映射机制

能力（abilities）和判别区域（discriminant regions）都包含在 `ob C` 中。判别函数（Discriminant functions）、特征向量（eigenvectors）、概率公式（probability formulae）等都包含在 `Mor C` 中。两个分类器构成了多类情况下的一个特例，可以将其定义为类别 `D`，因此 `ob C → ob D`。`C` 中的对象可以对应 `D` 中的对象，`Mor C → Mor D`，且 `C` 中的一个态射可以对应 `D` 中的一个态射。

若 `F: C → D`，且 `A, B ∈ ob C`，则 `F(A), F(B) ∈ ob D`。假设对象 `A` 是数据集 `a_1`，对象 `B` 是特征向量。同理，若 `G: C → D`，且 `A, B ∈ ob C`，则 `G(A), G(B) ∈ ob D`。此时对象 `A` 是数据集 `a_2`，对象 `B` 是特征向量。

根据函子的定义，对于函子 `F`，有 `A ↦ F(A)`；对于函子 `G`，有 `A ↦ G(A)`，数据集对象 `A_F` 和 `A_G` 之间存在某种联系。它们都遵循相同的规律，即它们都能生成多个类别。因此，存在一种构型（configuration shot）使得 `A_F → A_G`。通过这一推理，我们获得了 `F(A)` 和 `G(A)`，其中存在一个定义为 `α_A: F(A) → G(A)` 的态射。同理，也有 `α_B: F(B) → G(B)`。

`C` 中的对象 `A, B` 之间存在一个态射，记为 `f: A → B`，其过程和主要功能在于解决数据集的特征向量问题。根据函子的定义 `f ↦ F(f)`，我们可以得到 `F(f): F(A) → F(B)`。

同理，`G(f): G(A) → G(B)`。

综上所述，基于贝叶斯决策理论的两种分类器可以使用自然变换（natural transformation）。已证明自然变换理论在学习问题中具有一定的应用价值。

在学习系统中，任何学习问题的表示都由特定的表达（expression）来体现。学习系统的性质也由表达的作用所决定。长期以来，这个问题被称为系统的瓶颈问题。根据前一节的讨论，学习系统可以用范畴来表示。那么，学习系统之间的关系如何在表达范畴中表达？本节重点回答这个问题。

### 15.3.1 表达的抽象概念

表达的表示与应用是本文的重点。为了便于理解，我们需要先找到表达的共性。范畴论的初衷是将从不同数学领域中抽象出的许多具有相似特性的具体数学对象和映射整合为统一的概念。这种抽象是通过态射（morphism）实现的。例如，集合 `T` 是一个单点集，可以等价地表示为任意集合。从范畴论的观点来看，恰好存在一个映射到集合 `T`。因此，态射在范畴论中起着主要作用。事实上，学习表达的研究与应用无非是各种映射之间的关系，而态射理论能更好地反映各部分的关系。

作为一个假设，我们考虑该学习表达中的一个态射。如果任何一对平行态射中的某一对是态射，则存在一个左可消去的（left reducible），这被称为学习表达范畴的单态射（monomorphism）。假设 `C` 是一个学习表达范畴，且 `f: A → B` 是该学习表达中的一个态射。如果 `C` 中任何一对平行态射 `g, h: C → A` 满足 `fg = fh`，则 `g = h`（现在称为 `f` 左可消去），其中 `f` 被称为学习表达范畴的单态射。

同理，可以假设 `f` 是满态射（epimorphism），当且仅当任何一对平行态射 `g, h: B → C` 满足 `fg = fh`，且我们有 `g = h`（现在称为 `f` 右可消去）。

线性判别函数中表达的映射原理可以通过学习表达的单态射和满态射来研究。

**示例 15.5.** 在线性学习范畴 `C` 中，存在学习表达的满态射。

*证明.* 在线性学习范畴 `C` 中，对象 `X` 表示需要判别为权重向量对象的数据集 `W`。态射 `f: X · W → B` 是将数据集对象和权重向量对象映射到判别函数值对象，记为 `f: B(x) = W · X + w_0`，其中 `w_0` 代表变量值的阈值权重或偏差。态射 `g: B → R` 代表数据集对象的点距离到超平面的算术距离过程的映射。对象 `R` 是一个算术距离对象，它可以区分 `X` 中元素点的分类及其到超平面的距离。态射 `g` 的映射过程可以用表达式 `X = X_p + RW/||W||` 表示。

同时存在平行态射 `g` 和态射 `h: B → R`，且映射过程可以表示为 `R = B(x)/||W||`。对于态射 `f, g, h`，通过范畴论的复合运算率（compound operation rate）可得 `gf = hf`。具体过程如图 15.6 所示。

![](img/456a7a56403cbb2b5f1a261793529a51_451_0.png)

由于 `g: X = X_p + RW / ||W||`，即 `R = ||W|| / W(X - X_p)` 且 `h: R = B(x) / ||W||`，则

$$R = \frac{W \cdot X + w_0}{\|W\|} = \frac{W}{\|W\|} X + \frac{w_0}{\|W\|}\ .$$

尽管态射 `g` 和 `h` 的映射过程不同，但映射的结果和意义非常相似；因此，`g = h`。因此，在线性学习范畴 `C` 中可能存在学习表达的满态射。$\square$

在研究函子的表达之前，我们必须先理解以下假设和定理。

`C` 是一个学习表达范畴，`A ∈ ob C`；定义一个函子 `C(A, -): C → Set` 如下：

$$B \mapsto \mathscr{C}(A, B), (f: B \to C) \mapsto (c(A, f), g \mapsto fg)\ .$$

我们将 `C(A, -)` 称为在 `A` 上的同态函子（hom-functor）。我们可以定义对偶函子 `C(A, -): C^{op} → Set`。在对偶（antithesis）下，我们可以定义在 `A` 上的反变同态函子（contravariant hom-functor）。

**定理 15.3.** (*Yoneda 引理*) *`C` 是学习表达范畴 `A ∈ ob C`，`F: C → Set` 是一个函子，且 `Nat(C(A, -), F)` 表示函子 `C(A, -)` 和函子 `F` 之间的所有自然变换。那么，存在从 `Nat(C(A, -), F)` 到 `F(A)` 的映射。*

**定义 15.12.** `C` 是学习表达范畴，`F: C → Set` 是一个函子。如果 `C` 中存在一个对象 `A` 和一个自然同构 `φ: C(A, -) → F`，则我们称有序对 `(A, φ)` 为 `F` 的表示（representation）。如果存在 `F` 的表示，则 `F` 是一个可表函子（representable functor）。

在定义 15.12 中，`F` 的表示可以看作一个有序对 `(A, x)`（其中 `A ∈ ob C`，`x ∈ F(A)`）（使得与 `x` 对应的自然变换是一个自然同构，即对于任何对象 `B` 和每个 `y ∈ F(B)`，存在唯一的态射 `f: A → B` 满足 `F(f)(x) = y`）。因此，我们可以得到 `F` 的一个等价描述如下：

将所有有序对 `(A, x)` 作为对象，当态射 `f: (A, x) → (B, y)` 是满足 `F(f)(x) = y` 的态射 `f: A → B` 时，显然这可以构成一个学习表达范畴，且 `F` 的表示恰好是该范畴中的初始对象（initial object）。

**示例 15.6.** *从李群机器学习范畴 `Gp` 到集合范畴 `Set` 的遗忘函子 `U: Gp → Set` 是一个可表函子。*

*证明.* *根据函子的定义，假设函子 `U` 存在。那么，每个李群机器学习对应一个集合，且每个群同态（连续映射、环同态等）对应此函子 `U`。*

作为拓扑空间范畴 `Top` 与集范畴 `Set` 之间的一个映射，存在一个对象间的映射。同样，态射之间也存在相应的映射。因此，遗忘函子存在。

我们可以证明，在这个函子中，存在一个一对一的映射。设 `A ∈ ob Gp`，`Nat(Gp(A, -), U)` 是函子 `Gp(A, -)` 与遗忘函子 `U` 之间的所有自然变换。对于每个自然变换 `α: Gp(A, -) → U`，定义 `Θ(α) = α_A(1_A) ∈ U(A)`。对于 `x ∈ U(A)`，定义 `Φ(x): Gp(A, -) → U`。那么，`Φ(x)_B(f) = U(f)(x) ∈ U(B)`。显然，`Φ(x)` 是一个自然变换。因此，存在一个映射 `Φ: U(A) → Nat(Gp(A, -), U)`。综上所述，`Θ` 和 `Φ` 互为逆映射，从而存在从 `Nat(Gp(A, -), U)` 到 `U(A)` 的一一映射，即存在自然同构 `φ: Gp(A, -) → U`。

根据可表函子的定义，有序对 `(A, φ)` 是 `U` 的一个表示。因此，它是一个学习表达式可表函子，即从李群机器学习范畴 `Gp` 到集范畴 `Set` 的遗忘函子 `U: Gp → Set` 是一个可表函子。$\square$

## 15.3.2 表达式之间的映射机制

上一节描述了学习表达式的基本概念和抽象表示，这为研究表达式之间的映射机制提供了清晰的理论基础。本节通过一个具体实例验证学习表达式之间的映射机制，并证明了映射理论的可行性。首先，我们选择学习问题中的具体问题，并分析它们在范畴论中的存在性。然后，利用学习表达式的映射机制对现有的学习问题进行改进，并获得了更好的结果。这展示了抽象理论的实际应用，并证明了该理论的正确性和可行性。

第二节简要介绍了决策树范畴。本节将给出决策树学习算法的范畴证明。

决策树通过将从根节点（排序）到叶节点的实例排列来对实例进行分类。叶节点是实例的一种分类。树上的每个节点指定了对实例的一个属性的测试，而该节点的每个后续分支对应该属性的一个可能值。分类示例从树的根节点开始，测试该节点指定的属性，然后根据给定实例的属性值向下移动到相应的分支。然后在以新节点为根的子树上重复此过程。

决策树分类算法源于学习系统的概念。然后，经过一系列发展，我们获得了 `ID3` 和 `C4.5` 算法以及广泛的应用。在这里，我们主要讨论 `ID3` 算法。

1986 年，Quinlan 提出了 `ID3` 算法 [17]，它也是决策树算法的一个代表。它是最早且最具影响力的决策树算法。其优点包括描述简单、分类速度快。其基本理论相对清晰，学习能力强，且决策树的平均深度较小。`ID3` 算法总结于表 15.2 中。

### 表 15.2：ID3 算法总结

**输入：** `E = D_1 × D_2 × ⋯ × D_n`

**输出：** 决策树

- (1) `E = D_1 × D_2 × ⋯ × D_n` 是一个有限维向量空间，`D_j` 是一个有限的离散符号集，`E` 中的元素 `e = < v_1, v_2, …, v_n >` 称为示例，`v_j ∈ D_j, j = 1, 2, …, n`。`PE` 和 `NE` 是集合 `E` 的两个子集，分别称为正例集和反例集。

- (2) 向量空间 `E` 中 `PE` 和 `NE` 的大小分别为 `p` 和 `n`。需要满足以下两个假设：(1) 向量空间 `E` 中的正确决策树与任何实例分类的概率及正反例一致；(2) 决策树能够正确确定一个示例所需的信息量由下式给出

$$
\operatorname{Entropy}(S) = -p_+ \log_2 p_+ - p_- \log_2 p_- = -\frac{p}{p + n} \log_2 \frac{p}{p + n} - \frac{n}{p + n} \log_2 \frac{n}{p + n}
$$

- (3) 现在，以属性 `A` 作为决策树根节点，`A` 有 `m` 个值 `{v_1, v_2, …, v_m}`。它将 `E` 划分为 `m` 个子集 `{E_1, E_2, …, E_m}`。属性 `A` 对根节点的期望信息为

$$
\operatorname{Entropy}(S, A) = \sum_{i = 1}^{m} \frac{p_i + n_i}{p + n} \operatorname{Entropy}(S_i)
$$

其中 `p_i` 和 `n_i` 分别是 `E_i` 的正例和负例值，`Entropy(S_i)` 是子集 `E_i` 的期望信息。

- (4) 计算根节点 `A` 的信息增益。公式为

$$
\operatorname{Gain}(S, A) = \operatorname{Entropy}(S) - \operatorname{Entropy}(S_i, A)
$$

- (5) 选择具有最大 `Gain(S, A)` 或最小 `Entropy(S_i, A)` 的属性 `A*` 作为根节点。根据 `A*` 的不同值，对于 `E` 的子集 `E_i`，`A*` 的子节点 `B_1, B_2, …, B_v` 通过递归调用上述过程 1–4 生成。

在确定了决策树学习的流程和构建决策树的方法后，我们继续了解贝叶斯学习。偏差推理提供了一种概率推理手段，但需要满足一定条件，即待检查的量遵循概率分布。我们可以基于这些概率和观察到的数据进行推断，从而做出最优决策。偏差推理对机器学习也很重要，因为它提供了衡量多个假设置信度的指标。其次，贝叶斯推理为直接操作概率的学习算法提供了基础，并为其他算法的分析提供了理论框架。

偏差学习方法的特点可以总结为以下几点：

- (1) 每个观察到的训练示例都可以增量地减少或增加某个假设的估计概率。这提供了比其他算法更合理的学习方式。其他算法在假设与任何示例都不符时会完全排除该假设。

- (2) 先验知识可以与观察数据共同确定假设的最终概率。在贝叶斯学习中，先验知识的形式可以是：(a) 每个候选假设的先验概率；(b) 可观察数据上可能假设的每个概率分布。

- (3) 偏差方法允许做出假设以预测不确定性。

- (4) 新实例可以由多个假设进行预测，并按其概率加权。

- (5) 即使贝叶斯方法的计算复杂度较高，它们仍可作为最优决策制定的标准。

偏差理论提供了一种直接计算这种可能性的方法。更准确地说，贝叶斯公式提供了一种计算假设概率的方法。它基于假设的先验概率、在给定假设下观察到不同数据的概率以及观察到的数据本身。

偏差规则是偏差学习方法的基础，因为它提供了从先验概率 `P(h)`、`P(D|h)` 和 `P(D)` 计算后验概率 `P(h|D)` 的方法。表 15.3 列出了计算概率的基本公式。

### 表 15.3：基本概率公式

- **乘法规则：** 两个事件 `A` 和 `B` 的交集概率 `P(A ∩ B)`

$$
P(A \cap B) = P(A|B)P(B) = P(B|A)P(A)
$$

- **加法规则：** 两个事件 `A` 和 `B` 的并集概率 `P(A ∪ B)`。

$$
P(A \cup B) = P(A) + P(B) - P(A \cap B)
$$

- **贝叶斯定理：** 给定 `D` 时 `h` 的后验概率 `P(h|D)`。

$$
P(h|D) = \frac{P(D|h)P(h)}{P(D)}
$$

- **全概率公式：** 如果事件 `A_1, …, A_n` 互斥且 `∑_{i=1}^{n} P(A_i) = 1`，则

$$
P(B) = \sum_{i=1}^{n} P(B|A_i)P(A_i)
$$
