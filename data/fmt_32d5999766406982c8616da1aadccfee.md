
# 渗透测试工具参考

## Drozer

[Drozer](https://github.com/FSecureLABS/drozer) (和 [`labs.f-secure.com/tools/drozer/`](https://labs.f-secure.com/tools/drozer/)) 是一个 Android 安全评估框架，它作为一个第三方应用程序，与其他应用程序和底层操作系统的 IPC 端点进行交互。这允许你通过与目标交互（通过提供的模块）来搜索安全漏洞。额外功能在 **第 7 章** 中探讨。

## EAPHammer

[EAPHammer](https://github.com/s0lst1c3/eaphammer) 是一款渗透测试工具，旨在通过针对 WPA 和 WPA2 网络以及使用 RADIUS 的网络的邪恶双生攻击，获取无线网络的访问权限。该工具可安装在 Kali Linux 中，当你需要通过恶意 AP 窃取 RADIUS 凭据或通过恶意门户窃取 AD 凭据时非常有用。它还支持 Karma 攻击。

## Empire

[Empire](https://www.powershellempire.com/) (和 [`github.com/BC-SECURITY/Empire`](https://github.com/BC-SECURITY/Empire)) 是一个 PowerShell 利用框架，其原始作者不再提供支持。然而，由于许多工具仍然有效，它们有时会被渗透测试博客引用，且在实践中仍在使用。这些工具已变得众所周知，因此除非应用额外的隐藏方法（如使用 `PowerPick` 或混淆技术），否则更有可能在高级环境中被检测到。该框架包含许多 PowerShell 脚本和模块，旨在收集凭据（运行 `Mimikatz`）、发现与侦察、权限提升、横向移动和持久化等。一些 Empire 组件的示例在 **第 9 章** 中讨论。

## Ettercap

[Ettercap](https://www.ettercap-project.org/) 是一款用于网络流量的中间人工具。它可以执行 ARP 欺骗攻击、嗅探实时连接上的网络流量，并应用过滤器实时修改该流量。它是一个支持在 Linux、BSD 和某些版本的 macOS 上运行的命令行工具。如果你有网络访问权限，但需要拦截或修改同一子网上其他网络端点之间的流量以进一步获取访问权限，Ettercap 非常有用。示例可能包括你需要尝试窃取凭据或劫持 Web 流量的情况。

## Exploit Database

[Exploit Database](https://www.exploit-db.com/) 是一个由社区贡献的已知漏洞利用数据库，你可以搜索它以寻找用于渗透测试的概念验证和漏洞利用示例。漏洞利用代码可能需要额外修改，才能在特定渗透测试的上下文中发挥作用。

## Fern

[Fern](http://www.fern-pro.com/) (和 [`github.com/savio-code/fern-wifi-cracker`](https://github.com/savio-code/fern-wifi-cracker)) 是一款用于 Wi-Fi 安全审计和破解的 Python 工具。它可以恢复 WEP、WPA 和 WPS 密钥，以及执行多种类型的 Wi-Fi 攻击（Reaver、chopchop、碎片攻击等）。它有免费版本 (GitHub) 和付费专业版本。它需要 `aircrack-ng` 套件、Scapy 和 Reaver。

## FOCA

[FOCA (Fingerprinting Organizations with Collected Archives)](https://github.com/ElevenPaths/FOCA) 是一款从文档中挖掘元数据和其他隐藏信息的工具。这些信息在侦察和发现阶段可能很有用，为社会工程学攻击做准备。例如，这有助于提取作者信息、电子邮件地址，甚至账户信息，用于生成借口和创建目标列表。

## Frida

[Frida](https://frida.re/) 是一个移动测试工具包，允许渗透测试人员将脚本注入黑盒进程，并在移动设备安全测试期间深入了解 API、私有代码和运行中函数的操作。Frida 及其用例在 **第 7 章** 中有更深入的讨论。

## GDB

### GNU 调试器

GNU 调试器 ([`www.gnu.org/software/gdb/`](https://www.gnu.org/software/gdb/)) 是一款免费的调试器。调试器允许你在应用程序运行时与其交互，以便通过在特定断点暂停执行并分析故障或执行流变化期间发生的情况来分析其行为。调试器不会将代码从编译格式反汇编回源代码，但它们可以根据运行时注入的执行变化，让你深入了解代码是如何运行的。这些对于漏洞研究、逆向工程和漏洞利用开发非常有用。例如，如果你试图通过在调试器中手动更改从身份验证函数发送到程序其余部分的值来绕过应用程序中的身份验证。

## Gobuster

[Gobuster](https://github.com/OJ/gobuster) 可用于枚举 Amazon S3 存储桶；Web 服务器的虚拟主机名；以及使用模糊测试、过滤器、不同协议和 HTTP 方法的 DNS 条目。该工具设计为在命令行运行，通过标志在运行时修改其行为。该工具包含四种模式：`dir`（用于目录爆破）、`dns`（用于 DNS 主机名枚举）、`s3`（用于 AWS 存储桶）和 `vhost`（用于 Web 服务器）。运行时，你需要指定字典文件和输出文件位置，以及目标所需的必要信息。

## Hashcat

[Hashcat](https://hashcat.net/hashcat/) 是一个基于 GPU 的破解引擎，旨在使用规则和过滤器进行暴力破解和字典攻击。它旨在针对各种类型的密码哈希，并被认为是密码破解最快的方法。当你拥有无法利用的哈希，或者需要根据一组哈希审计密码强度时，请使用它。

## Hping

[Hping](http://www.hping.org/) 是一个用于生成 TCP/IP 数据包的命令行工具。虽然其功能已在 Nmap 中实现，但 `hping3` 可以用 Tcl 脚本语言编写脚本，并能将数据包渲染为基于字符串的、人类可读的描述，以便于编写脚本执行底层数据包操作和分析。使用 Hping，你还可以欺骗源 IP 地址并生成大量流量，以探索各种 DDoS 技术，这是渗透测试中最常见的用例。

## Hydra

[Hydra](https://github.com/vanhauser-thc/thc-hydra) 是一款针对活服务（包括 HTTP、Oracle、Cisco、POP3、VNC 等）进行密码喷射和暴力破解的工具。其高度并行化的跨多协议攻击活服务的方法（与离线密码破解相反）使其非常适合渗透测试人员评估密码安全性，以及在紫队演练中进行有效的攻击检测和缓解。它通常作为命令行工具使用，可在各种操作系统中运行，使用 `-flags` 来修改其行为。示例用法见 **第 5 章**。

## IDA

[IDA](https://hex-rays.com/ida-pro/) 有多个付费版本和一个免费版本（IDA Free）。不同版本提供的功能各异，但它是一款强大的代码反汇编和调试工具。它分析编译后的应用程序，检查 CPU 如何处理信息，并尝试根据该分析生成汇编代码，还支持各种类型模糊测试攻击的远程调试。它拥有各种插件（如 HexRays），允许你从编译后的二进制文件中提取 C 代码以进行静态代码分析。它适用于代码分析、逆向工程、漏洞研究和漏洞利用开发。

## Immunity Debugger

[Immunity Debugger](https://www.immunityinc.com/products/debugger/) 适用于漏洞利用开发、恶意软件分析和逆向工程。它允许你以图形方式渲染函数和程序流程，便于堆分析，并实现了用于脚本编写的 Python API。例如，Mona Python 插件将允许你轻松计算缓冲区溢出的偏移量，识别 ROP 链，并探索其他对利用有用的 gadget（代码片段）。

## Impacket

[Impacket](https://github.com/SecureAuthCorp/impacket) 是一个用于网络协议操作的 Python 工具套件。在渗透测试期间，Impacket 有许多合法用途，包括从 Linux 攻击平台与 Windows 主机交互。一个例子可能是使用管理员凭据从 Linux 机器对域控制器执行 `DCsync`。用法示例见 **第 9 章**。

## John the Ripper

John the Ripper (JtR) ([`www.openwall.com/john/`](https://www.openwall.com/john/)) 是一款离线密码破解工具。对于基于 CPU 的破解，JtR 是密码恢复最快的工具之一。因此，如果无法进行 GPU 破解，你会使用 JtR。然而，JtR 还实现了不同于其他破解工具的规则集，这些规则集可能在其他破解工具失败的情况下恢复密码，因此它是大型密码列表中其他破解工具的良好补充。

## Kismet

[Kismet](https://www.kismetwireless.net/) 是一款无线安全评估工具，可检测设备、嗅探无线流量并协助战争驾驶。它支持蓝牙以及传统无线网络。它最常用于无线侦察，并支持基于补充 GPS 数据的无线数据图形化映射。更多关于无线攻击的详细信息请阅读 **第 4 章**。

## Maltego

[Maltego](https://www.maltego.com/) 利用变换根据搜索种子（如电子邮件地址或域名）自动从开源和付费数据源检索侦察数据。这是一款强大的侦察工具，可以快速识别目标之间的关系，例如电子邮件、Web 服务器或其他基础设施（如 IP 范围），这些在构建和确认目标列表、构建借口以及识别其他可能有趣的目标研究领域方面非常有用。

## mdk4

[mdk4](https://github.com/aircrack-ng/mdk4) (和 [`en.kali.tools/?p=864`](https://en.kali.tools/?p=864)) 是一款无线测试工具，用于在多个操作系统上注入帧。这允许你执行多种攻击类型，包括信标泛洪、拒绝服务和解除认证攻击、SSID 探测和暴力破解、数据包模糊测试等。在无线接口 `wlan0` 上使用不可打印字符和长 SSID (`-a`) 以及根据嵌入的 OUI 数据库使用有效 MAC 地址 (`-m`) 以每秒 200 个数据包的速率 (`-s`) 执行信标泛洪攻击的示例可能如下所示：

```
$ sudo mdk4 wlan0 b -a -m -s 200
```

## Medusa

[Medusa](https://github.com/jmk-foofus/medusa) (和 [`foofus.net/goons/jmk/medusa/medusa.html`](http://foofus.net/goons/jmk/medusa/medusa.html)) 是一款类似于 Hydra 的工具，它针对活服务执行密码暴力破解攻击。它支持多种协议，并可以从字典文件并行发送请求。在渗透测试期间，你会在使用 Hydra 的相同情况下使用 Medusa，选择取决于偏好、你在环境中的性能表现和协议支持。

## Metasploit

[Metasploit](https://www.metasploit.com/) 是一个渗透测试框架，包含许多社区贡献的攻击模块。它适用于渗透测试的大多数阶段，包括侦察、漏洞识别、利用以及命令与控制。本书全文都在讨论 Metasploit，但主要是在 **第 9 章** 中后渗透的背景下进行讨论。

## Mimikatz

[Mimikatz](https://github.com/gentilkiwi/mimikatz) 是一款用于从 Windows 系统提取认证信息的工具。这包括 Kerberos 票据、明文密码、密码哈希、PIN 码等。它可以帮助渗透测试人员执行传递哈希和传递票据攻击，以及通过构建黄金票据进行 Kerberoasting 攻击。在渗透测试期间，你会在后渗透阶段使用 Mimikatz，例如当你已访问某个系统并想要收集额外凭据以进行横向移动或权限提升时。这在 **第 9 章** 中有进一步讨论。

## mitm6

[mitm6](https://github.com/dirkjanm/mitm6) 拦截选定目标的 DNS 和 DHCP 查询，并作为一个流氓 DNS/DHCP 服务器运行。这随后可用于将受害者流量重定向到其他恶意资源，或在与 Impacket 中的 `ntlmrelayx` 等工具结合使用时执行中继攻击。更多信息（包括使用示例和输出）请参阅 Fox-IT 博客文章“mitm6 – compromising IPv4 networks via IPv6”，地址为：[`blog.fox-it.com/2018/01/11/mitm6-compromising-ipv4-networks-via-ipv6/`](https://blog.fox-it.com/2018/01/11/mitm6-compromising-ipv4-networks-via-ipv6/)

## MobSF

移动安全框架 即 MobSF ([`github.com/MobSF/Mobile-Security-Framework-MobSF`](https://github.com/MobSF/Mobile-Security-Framework-MobSF)) 是一个移动渗透测试框架，可针对 Android、iOS 和 Windows 设备。它提供静态和动态代码分析工具，并在 **第 7 章** 中进一步讨论。

## Ncat

[Ncat](https://nmap.org/ncat/) 是 Nmap 的 Netcat (`nc`) 工具实现。它允许你使用命令行通过网络读取和写入数据。它可用于将 TCP 和 UDP 端口重定向到其他站点，并支持带有 SOCKS 的 SSL 和代理实现。Ncat 集成在 Nmap 中，随 Nmap 一起下载。包含示例的详细使用指南可在 Nmap 网站上找到：[`nmap.org/ncat/guide/index.html`](https://nmap.org/ncat/guide/index.html)。

## Nessus

[Nessus](https://www.tenable.com/products/nessus) 是一款漏洞扫描器。它可以使用端口扫描执行网络发现，并从已认证或未认证的上下文中枚举服务。从未认证的上下文来看，它尝试连接到暴露的服务，并利用横幅和安装信息或协议响应中的差异，尝试识别监听服务及其版本。然后，它可以将该信息与大量已知漏洞的内部数据库进行比较，以突出显示已识别服务上潜在或确认存在的漏洞。这对于识别潜在的利用路径非常有用，并且在渗透测试期间不需要隐蔽时，可快速执行大规模发现。

## Netcat

Netcat (`nc`) ([`linux.die.net/man/1/nc`](https://linux.die.net/man/1/nc)) 是一款随许多 Linux 发行版分发的工具，允许你发送和接收 TCP 和 UDP 流量、监听任意 TCP 和 UDP 端口，并使用 TCP 或 UDP 执行许多其他任务。例如，它可以使用 Bash 进行高度脚本化，并可在渗透测试期间用于向目标机器传输文件、实现绑定或反向 Shell，或使用原始连接直接测试服务。使用示例包含在 **第 11 章** 中。

## Nikto

[Nikto](https://cirt.net/Nikto2andhttps://github.com/sullo/nikto/wiki) 是一款 Web 服务器漏洞扫描器。它针对你提供的目标 Web URL 测试已知漏洞。**第 11 章** 中给出了使用 Nikto 的示例，但你可以用它来查找与过时插件版本或其他 Web 软件相关的已知漏洞，适用于不需要隐蔽的情况。

## Nmap

[Nmap](https://nmap.org/) 是一款用于网络发现和安全测试的免费渗透测试工具。它通常从命令行运行，但也存在 GUI 版本 (Zenmap)。Nmap 拥有强大的脚本引擎和大量脚本集合，可执行各种活动，包括从暴力破解和枚举到数据库哈希转储和表单模糊测试的所有内容。本书全文均引用了 Nmap。
