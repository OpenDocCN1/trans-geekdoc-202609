### 12.2 用于 3D 场景合成的神经辐射场

还有另一种称为神经辐射场的计算机视觉技术（Li *et al* 2022）（NeRF），它也可用于图像深度估计。然而，NeRF 最令人印象深刻的功能是利用围绕物体拍摄的一组 2D 图像合成物体的 3D 模型，然后该 3D 模型的数据可被其他软件（如[Meshlab](https://www.meshlab.net/)）用于 3D 打印。从高中数学知识出发，我们可以推导出公式，从相机在两个位置拍摄的两张图像中提取物体的 3D 信息。这就是为什么许多动物和昆虫在进化过程中拥有两只眼睛，以获得我们世界的立体视觉。利用相机围绕物体拍摄的 20~100 张图像，NeRF 拥有足够的数据通过智能算法合成 3D 场景。原始 NeRF 论文（Mildenhall *et al* 2020）发表于 2020 年 8 月。由于 NeRF 的模型训练时间非常慢（数小时甚至数天），近年来提出了许多基于原始 NeRF 的模型。Nvidia 的即时 NeRF（Müller *et al* 2022）可以在几秒钟内从图像合成 3D 场景。我们甚至不需要从 Nvidia 的[GitHub](https://github.com/NVlabs/instant-ngp)网站安装 Python 文件，因为 Nvidia 提供了一个可执行的二进制文件[instant-ngp.exe](https://github.com/NVlabs/instant-ngp/releases/download/continuous/Instant-NGP-for-RTX-2000.zip)供下载，用于 Windows 操作系统。按照 GitHub 网站的说明，我用手机围绕图 12.3 所示的一尊公牛和母牛雕塑拍摄了 35 张照片。为了节省计算时间，我将这些图像的分辨率从 4096×2304 调整为 843×474。使用[Colmap](https://colmap.github.io/)和[colmap2nerf.py](https://github.com/NVlabs/instant-ngp/blob/master/scripts/colmap2nerf.py)，我获得了一个关于我相机`内参`的`transforms.json`文件，如下所列。在该文件中，每张图像都有一个 4×4 的`变换矩阵`，用于将每张图像的像素坐标转换为图像中每个物体的 3D 世界坐标。

#### 12.2.1 相机内参矩阵和外参矩阵

我们在计算机视觉项目的模型训练中使用了大量来自数码相机的照片。数码相机将我们 3D 世界中的物体投影到其 2D 光子传感器（CCD 或 CMOS 阵列）上以创建数字图像。利用 NeRF 技术，我们可以利用一组图像来重建或合成 3D 世界中物体的 3D 场景。为了理解 NeRF，我们需要了解数码相机中的四个笛卡尔坐标系。如图 12.4 所示，它们分别是世界坐标系、相机坐标系、图像坐标系和传感器坐标系。在第一个坐标系中，`z[w]`轴方向向上，`x[w]`*`–y[w]`平面是水平的。相对于固定的真实世界坐标系，可移动相机坐标系的`z[c]`轴在相机移动和旋转前与`y[w]`轴平行，其`x[c]`轴可以指向任意方向。为简化起见，我将`x[c]`轴和`x[w]`轴设为相反方向。对于一个 3D 世界向量`X⃗[w]` = `[1,1,1]^(T)`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn25.gif"/，如果相机位于由真实世界向量`C⃗[w]` = `[0,−100,0]^(T)`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn27.gif"/设定的位置，我们可以确定相机坐标系中的向量为`X⃗[c]` = `[−1,1,101]^(T)`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn26.gif"/。从向量`C⃗[w]`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn28.gif"/可知，两个坐标系之间的距离为 100。这些坐标的单位可以是毫米（mm）。从图中可得一个方程，用于计算相机系统中 3D 世界点`[1,1,1]`的坐标`X⃗[c]` = `R` ⋅ (`X⃗[w]`−`C⃗[w]`) = `R` ⋅ `X⃗[w]` + `t⃗`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn29.gif"/，其中`R`是关于旋转操作的正交矩阵，`t⃗` =  − `R` ⋅ `C⃗[w]` = `[0,0,100]^(T)`inline-graphic style="height:1.375em;" xlink:href="bk978-0-7503-6244-3ch12ieqn30.gif"/是关于相机坐标系到真实世界坐标系的平移操作。从`t⃗`inline-graphic style="height:1.0625em;" xlink:href="bk978-0-7503-6244-3ch12ieqn31.gif"/的坐标可知世界坐标系原点在相机系统中的位置。我们还有`R^(−1)` = `R^(T)`inline-graphic style="height:1.0625em;" xlink:href="bk978-0-7503-6244-3ch12ieqn32.gif"/和`RR^(T)` = `R^(T)R` = 1inline-graphic style="height:1.0625em;" xlink:href="bk978-0-7503-6244-3ch12ieqn33.gif"/。

```
R = [[r_11, r_12, r_13],
     [r_21, r_21, r_23],
     [r_31, r_32, r_33]]
   = [[x_c · x_w, x_c · y_w, x_c · z_w],
      [y_c · x_w, y_c · y_w, y_c · y_w],
      [z_c · x_w, z_c · x_w, z_c · x_w]]
   = [[-1, 0, 0],
      [0, 0, 1],
      [0, 1, 0]]
```

(12.2) graphic style="width:38.8125em;" xlink:href="bk978-0-7503-6244-3ch12eqn34.gif" position="float"/

为了数学上的方便，我们使用 4D 向量来表示世界坐标系和相机坐标系中的 3D 向量：$\tilde{\chi}[w] = [x[w], y[w], z[w], 1]^{(T)}$ 和 $\tilde{\chi}[c] = [x[c], y[c], z[c], 1]^{(T)}$。4D 向量是 3D 向量的齐次表示，第四个坐标是一个不等于零的虚构数字。这两个新向量之间的关系由公式 (12.3) 确定，其中 4×4 矩阵被称为照片相机的 `Extrinsic Matrix`（外参矩阵）。

```
χ_c = [[x_c], [y_c], [z_c], [1]]
    = [[r_11, r_12, r_13, t_x],
       [r_21, r_22, r_23, t_y],
       [r_31, r_32, r_33, t_x],
       [0,    0,    0,    1]] [[x_w], [y_w], [z_w], [1]]
    = [[R_3x3, t], [0_1x3, 1]] χ_w
```

(12.3) graphic style="width:38.8125em;" xlink:href="bk978-0-7503-6244-3ch12eqn37.gif" position="float"/

向量 $\vec{X}[c]$ 随后通过相机投影到 2D 图像坐标系中，如图 12.4 所示。由于相机的焦距只有几毫米（$f \ll z[c]$），图像坐标系位于相机的焦平面上。根据光学原理，我们在图像坐标系中得到图像的坐标 $x_{i} = \frac{x_{c}}{z_{c}}f$ 和 $y_{i} = \frac{y_{c}}{z_{c}}f$。数码相机使用数百万个微小的 CCD 或 CMOS 传感器来探测光子。`u` 轴和 `v` 轴上的传感器密度分别为 `m[x]` 和 `m[y]`。传感器密度的单位是每毫米传感器的数量。`m[x]` 和 `m[y]` 可能不相同。数字图像的原点通常设置在图像的左上角（从 2D 图像传感器芯片背面观察）。在传感器坐标系中，每个像素的坐标 (`u`, `v`) 都是整数：$u = m_{x}f\frac{x_{c}}{z_{c}} + o_{u} = f_{x}\frac{x_{c}}{z_{c}} + o_{u}$，$v = m_{y}f\frac{y_{c}}{z_{c}} + o_{v} = f_{y}\frac{y_{c}}{z_{c}} + o_{v}$，其中 `f[x]`、`f[y]`、`o[u]`、`o[v]` 是相机的内参。它们具有相同的单位：像素。2D 图像传感器芯片的主点中心在传感器坐标系中的坐标为 `O(o[u], o[v])`。如果图像的分辨率是 1024×768，图像的主点中心可能是 `O(512, 384)`。

![Figure 12.4. A digital camera's four Cartesian coordinate systems for NeRF. From right to left, they are the world coordinate system, the camera coordinate system, the image coordinate system and the sensor coordinate system.](img/bk978-0-7503-6244-3ch12f4_online.jpg)

**图 12.4.** 用于 NeRF 的数码相机的四个笛卡尔坐标系。从右到左，它们分别是世界坐标系、相机坐标系、图像坐标系和传感器坐标系。

基于同样的原因，我们在公式 (12.4) 中使用 3D 齐次表示来表示 2D 传感器坐标，其中 `M[int]` 是相机的 `Intrinsic Matrix`（内参矩阵）。结合公式 (12.3) 和 (12.4)，我们得到公式 (12.5)，该公式用于将真实世界向量投影到传感器坐标系中，其中 `P` 是具有 12 个未知参数的相机 `Projection Matrix`（投影矩阵）。

```
ζ = [[u], [v], [1]]
  ≡ [[ũ], [ṽ], [w̃]]
  = [[u*z_c], [v*z_c], [z_c]]
  = [[f_x, 0,   o_u, 0],
     [0,   f_y, o_v, 0],
     [0,   0,   1,   0]] [[x_c], [y_c], [z_c], [1]]
  = M_int · χ_c
```

(12.4) graphic style="width:38.8125em;" xlink:href="bk978-0-7503-6244-3ch12eqn47.gif" position="float"/

```
ζ̃ = M_int · χ_c = M_int · M_ext · χ_w
   = [[p_11, p_12, p_13, p_14],
      [p_21, p_22, p_23, p_24],
      [p_31, p_32, p_33, p_34]] [[x_w], [y_w], [z_w], [1]]
   = P · χ_w
```

使用一个具有六个（或更多）已知真实世界坐标的物体图像，可以获得它们在传感器坐标系中的像素坐标。例如，第一个真实世界坐标 $[x[w1], y[w1], z[w1]]^{(T)}$ 被投影到传感器坐标系为 $[u[1], v[1]]^{(T)}$，并且它们是通过测量已知的。将这六个点代入公式 (12.4)，我们得到以下方程 `A ⋅ p = 0`。

```
A = [[x_w1, y_w1, z_w1, 1, 0, 0, 0, 0, -u_1*x_w1, -u_1*y_w1, -u_1*z_w1, -u_1],
     ...
```
