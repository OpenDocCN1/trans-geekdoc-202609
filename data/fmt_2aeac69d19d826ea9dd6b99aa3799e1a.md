在实践中，当涉及大型网络和数据集时，更简单的方法（如精心调整的梯度下降方案及其变体，例如第 18.4.2 节之前讨论的那些）似乎效果更好，且目前是主流趋势。更复杂的二阶技术可以在较小的网络中提供改进，特别是在回归任务的背景下。

正如我们已经评论的那样，前馈神经网络属于参数模型这一更一般的类别；因此，原则上，本书迄今为止遇到的任何损失函数都可以使用。多年来，某些损失函数在回归和分类任务的背景下变得流行。然而，在前馈多层网络的背景下，损失函数的选择与所使用的*输出*非线性类型紧密耦合。一个“错误”的*组合*会严重影响网络在训练期间的学习速度。为了理解这一论点，让我们考虑以下组合。

采用平方误差作为损失函数，采用逻辑斯蒂函数 `σ(z)` 作为输出非线性，如公式 (18.7) 所示。为简单起见，假设我们只有一个输出节点，并且省略与观测相关的索引 `n` 以及与层相关的索引 `r`。然后，如果 `y` 是目标值，`ŷ` 是估计值，则对代价函数的贡献将是

```
J = 1/2 (y - ŷ)² = 1/2 (y - σ(z))², z = θ^T y,
```

其中 `y` 是最后一隐藏层节点输出的（扩展）向量，`θ` 是连接最后一隐藏层节点到输出节点的突触权重向量。根据标准做法，偏置项已被吸收在 `θ` 中。然后，利用导数的链式法则，`J` 关于 `θ` 的梯度显然是

```
∂J/∂θ = ∂J/∂z ∂z/∂θ = δ y, δ := ∂J/∂z,
```

考虑到公式 (18.40)，我们得到

```
δ = ∂J/∂ŷ ∂ŷ/∂z = (ŷ - y) σ'(z).
```

因此，

```
∂J/∂θ = (ŷ - y) σ'(z) y.
```

上面的意思是，相对于通向输出节点的参数，成本的梯度取决于误差（$\hat{y} - y$），也取决于 logistic sigmoid 函数的导数。对误差的依赖是“良性的”。这正是我们想要的。误差越大，梯度（绝对值）越大；这将使公式 (18.10) 中的修正项变大，以应对较大的误差，或者在误差较小时使更新保持接近当前估计值。然而，对非线性函数导数的依赖则不是好消息。看 图 18.8，对于不接近零的自变量值，函数迅速饱和，其导数变得非常小。因此，尽管误差可能很大，但相应的修正量却会很小。此外，回想一下在反向传播中，相对于最后一层（输出层）参数（设为 $L$）的成本梯度被传递给前一层，即第 $L-1$ 层，并用于计算相应的梯度，以此类推。如果最后一层的梯度值很小，这将影响所有层的所有梯度，导致收敛显著减慢。

相反，很容易验证，如果输出节点是线性的，而不是 sigmoid，那么均方误差损失函数与线性输出单元的组合是一个良好的组合。由此产生的梯度与误差成正比，因为现在导数变成了常数。

## 18.6 梯度消失与梯度爆炸

我们已经讨论过，试图避免在输出端涉及那些与某些损失函数结合时会导致梯度值变小的非线性函数，这一点非常重要。现在让我们看看隐藏层中发生了什么。秘密在于反向传播算法的公式 (18.27)。让我们更深入地研究一下。正如我们在第 18.4.1 节中所见，梯度计算的核心在于以下量：

```
δ_j^r := ∂J/∂z_j^r, j = 1,2,…,k_r, r = 1,2,…,L,
```

其中，为使符号简洁，已省略索引 `n`，`r` 是表示 `L` 层网络中对应层的索引，`j` 是第 `r` 层（包含 `k_r` 个神经元）中某个神经元的索引。根据定义，`z_j^(r) := θ_j^(r^T) y^(r−1)` 是第 `j` 个神经元（关联参数向量 `θ_j^(r)`）的线性输出（非线性函数 `f` 之前的输出），而 `y^(r−1)` 是第 `(r−1)` 层的输出值向量（图 18.11）。然后，各个 `δ` 导数的传播遵循递归规则（公式 (18.27)），

### 反向传播中的梯度计算

$$

\delta_{j}^{r - 1} = \left( \sum\limits_{k = 1}^{k_{r}}\delta_{k}^{r}\theta_{kj}^{r} \right)f^{\prime}(z_{j}^{r - 1}),\quad j = 1,2,\ldots,k_{r - 1}.

$$

![Equation](img/si295.png)

用文字描述，第 `r - 1` 层的 `δ` 导数取决于上一层 `r` 相应的 `δ` 导数，以及 (a) 相应的权重和 (b) 非线性函数的**导数**，两者均以**乘法方式**起作用。为了清晰起见，让我们写出两个连续步骤的上述公式：

$$

\delta_{j}^{r - 1} = \left( \sum\limits_{k = 1}^{k_{r}}\left( \sum\limits_{i = 1}^{k_{r + 1}}\delta_{i}^{r + 1}\theta_{ik}^{r + 1} \right)f^{\prime}(z_{k}^{r})\theta_{kj}^{r} \right)f^{\prime}(z_{j}^{r - 1}),\quad j = 1,2,\ldots,k_{r - 1}.

$$

![Equation](img/si296.png)

从上述公式中需要记住的不是其确切表达，而是这样一个概念：随着反向传播算法向后流动，**非线性函数的导数**以及**权重**被**相乘**，且涉及的乘积项数量**增长**。层级越低（越接近输入层），`δ[j]^(r)` 的计算涉及的乘积项越多。实践中常会出现两种极端情况。

考虑到激活函数的导数可能小于 1（对于 Sigmoid 型非线性函数，若参数估计值不大，其导数可取极小值），代价函数关于底层参数的梯度可能变得极其微小，导致训练极其缓慢（详见文献 [78,198]）。当涉及层数很多的深层网络时，这种现象更加突出。

另一个极端是，如果参数值恰好变得很大，会导致梯度估计爆炸。结果会将参数估计推向参数空间中错误的区域，从而影响学习。

另一个相关问题是，各层的梯度可能取不同数量级的值。这意味着某些层的学习速度比其他层快。这本质上是一种不稳定性。

以上是在训练多层神经网络时遇到的一些困难，尤其是在涉及许多层时。

为了应对这些问题，已经开发出许多修改和技巧。尝试不同的代价函数是其中之一，尝试反向传播算法的不同优化变体是另一种（例如，参见[136]的讨论）。在接下来的小节中，我们将看到如何处理用于隐藏层的非线性函数，这些函数不是饱和型的；因此，它们可以“保护”我们免受导数值变小的倾向影响。

#### 18.6.1 线性修正单元

除了我们迄今为止考虑的激活函数之外，*线性修正单元*（ReLU）是最近才被提出的（参见图 18.13），其定义为：

![Equation](img/fx010.jpg)(18.46)

![Figure 18.13 The graph of ReLU. Note that for z > 0 the derivative is equal to one and for z < 0 it is equal to zero.](img/gr013.jpg)

图 18.13 ReLU 的图。注意对于`z > 0`，导数等于 1，对于`z < 0`，导数等于 0。

据报道，在深度网络的背景下，在隐藏层中使用 ReLU 非线性可以显著加快训练时间[108]。这种激活函数不受饱和影响，当神经元在其活跃区域（`z > 0`）工作时，其导数等于 1。因此，在初始化期间，希望将神经元的偏置设置为某个小的正值，例如`θ[0] = 0.1`，以增加激活函数输入为正的概率。对于负值，导数为零。在`z = 0`处导数未定义，如果这在训练期间发生，可以选择 1 或 0；对于熟悉子梯度概念（第 8 章）的人来说，这种选择是完全合理的。

因此，选择 ReLU 作为激活函数，可以绕过导数值变小时减速相关的问题。回想一下，在反向传播算法中，当计算隐藏层参数的梯度时，激活函数的导数以乘法方式进入计算。

ReLU 的一个缺点是当`z < 0`时训练会冻结。为了克服这个问题，已经提出了 ReLU 的变体。例如，可以使用：

`f(z) = max{0, z} + α min{0, z}`

![Equation](img/si302.png)

根据`α`的值，会产生不同的变体。对于`α = -1`，获得所谓的*绝对值修正*[90]。如果`α`被赋予一个固定的小值，例如 0.01，则得到的非线性被称为*泄漏*ReLU[126]。在[68]中，`α`被保留为一个在训练期间学习的参数。另一种称为*最大输出*单元的修改，采用`k`个不同的线性单元，其参数在训练期间学习，每次选择产生最大值的那个来激活相应的神经元[52]。ReLU 最初是在动态网络的背景下引入的[61]，并由生物学论据提供动机。

现在提出的问题是实际应用中具体非线性函数的选择。对此没有确定的答案，选择取决于具体应用。在本版编写时，似乎在其任何版本中使用 ReLU 是隐藏层更流行的选择。对于分类任务和输出层，Softmax 非线性结合交叉熵代价函数最常用。

## 18.7 网络正则化
