### 多层感知机分类器与网格搜索

在 `Machine_Learning` 类中，定义一个名为 `multi_layer_perceptron()` 的新方法，如下所示：

```python
def multi_layer_perceptron(self, name, X_train, X_test, y_train, y_test):
    # Define the parameter grid for the grid search
    param_grid = {
        'hidden_layer_sizes': [(50,), (100,), (50, 50), (100, 50), (100, 100)],
        'activation': ['logistic', 'relu'],
        'solver': ['adam', 'sgd'],
        'alpha': [0.0001, 0.001, 0.01],
        'learning_rate': ['constant', 'invscaling', 'adaptive'],
    }

    # Initialize the MLP Classifier
    mlp = MLPClassifier(random_state=2021)

    # Create GridSearchCV with the MLP Classifier and the parameter grid
    grid_search = GridSearchCV(mlp, param_grid, cv=3, scoring='accuracy', n_jobs=-1)

    # Train and perform grid search
    grid_search.fit(X_train, y_train)

    # Get the best MLP Classifier model from the grid search
    best_model = grid_search.best_estimator_

    # Saves model
    joblib.dump(best_model, 'MLP_Model.pkl')

    # Print the best hyperparameters found
    print(f"Best Hyperparameters for MLP:")
    print(grid_search.best_params_)

    return best_model
```

`multi_layer_perceptron()` 函数是用于训练和评估多层感知机 (MLP) 分类器的机器学习流水线的一部分。以下是该函数关键组件的细分：

#### 参数网格

你定义了一个包含用于调优 MLP 模型的各种超参数的参数网格 `param_grid`。这些超参数包括神经网络架构（隐藏层大小）、激活函数、优化算法、正则化强度 (`alpha`) 和学习率调度。

#### MLP 分类器初始化

你使用固定的随机种子 (`random_state=2021`) 初始化一个 MLP 分类器实例。MLP 分类器是一种用于分类任务的人工神经网络。

#### 网格搜索

你创建一个名为 `grid_search` 的 `GridSearchCV` 对象，它将对前面定义的超参数网格进行详尽搜索。网格搜索用于为 MLP 模型找到最佳的超参数组合。

#### 训练与网格搜索

你使用 `GridSearchCV` 对象在训练数据 (`X_train`, `y_train`) 上拟合（训练）MLP 模型。这将使用不同的超参数组合训练多个 MLP 模型，并使用交叉验证 (`cv=3`) 评估其性能。

#### 最佳模型选择

网格搜索完成后，你使用 `grid_search.best_estimator_` 从搜索结果中获得最佳 MLP 模型。

#### 模型保存

如果需要，你可以使用 `joblib` 将最佳 MLP 模型保存到名为 `'MLP_Model.pkl'` 的文件中。这使你可以在未来重用训练好的模型，而无需重新训练。

#### 打印最佳超参数

你打印出网格搜索找到的最佳超参数。此信息有助于你了解哪些超参数促成了最佳模型的性能。
