## 一维数组

一维数组是一种用于实现列表对象的数据结构，其中列表中的元素类型相同；例如，包含 25 个测试分数的班级名单、包含 100 个姓名的会员名单，或包含 500 个商品的商店库存。

对于 Java 中包含 *N* 个元素的数组，索引值（“下标”）范围从 0 到 *N* − 1。单个元素的访问方式如下：如果 `arr` 是数组名称，则元素为 `arr[0]`、`arr[1]`、...、`arr[N-1]`。如果使用负下标，或下标 *k* 满足 *k* ≥ *N*，则会抛出 `ArrayIndexOutOfBoundsException`。

### 初始化

在 Java 中，数组是一个对象；因此，创建数组时必须使用关键字 `new`。唯一的例外是初始化列表（将在下一页讨论）。数组一旦创建，其大小保持固定。然而，与 `String` 对象类似，数组引用可以重新赋值给不同大小的新数组。

#### 示例

以下所有方式均等效。每种方式都创建一个包含 25 个 `double` 值的数组，并将引用 `data` 指向该数组。

```
double[] data = new double[25];
double[] data = new double[5 * 5];
double[] data = new double[25];
```

后续语句如

```
data = new double[40];
```

将 `data` 重新赋值给一个长度为 40 的新数组。之前为 `data` 数组分配的内存将被 Java 的自动垃圾回收系统回收。

当声明数组时，元素会自动初始化为：基本数值类型（`int` 和 `double`）为零，`boolean` 变量为 `false`，对象引用为 `null`。

可以在一条语句中声明多个数组。例如，

```
int[] arr1 = new int[10], arr2 = new int[20], arr3 = new int[30];
```

### 初始化列表

值已知的小数组可以方便地使用*初始化列表*进行声明。例如，不必编写

```
int[] coins = new int[4];
coins[0] = 1;
coins[1] = 5;
coins[2] = 10;
coins[3] = 25;
```

而可以编写

```
int[] coins = {1, 5, 10, 25};
```

这种结构是创建数组时**不**需要 `new` 的唯一情况。

### 数组长度

Java 中的一维数组有一个 final 公共实例变量（即常量）`length`，当你需要数组中的元素数量时可以访问它。例如，

```
String[] names = {"Jamie", "Chris", "Alex"};
int n = names.length; // n is 3
```

```
for (int i = 0; i < names.length; i++) {
    System.out.println(names[i]);
}
```

#### 注意

1. 数组下标范围从 `0` 到 `names.length-1`；因此，`for` 循环中对 `i` 的测试条件必须**严格小于** `names.length`。
2. `length` **不是**方法，因此后面**不**跟括号。这与 `String` 对象形成对比，`String` 对象的 `length` **是**方法，**必须**后跟括号。例如，

```
int len = names.length;      // 数组：无括号
int len = names[0].length(); // String：有括号
```

### 遍历一维数组

当你需要访问数组中的每个元素，而**不**需要替换或删除任何元素，**也不**需要任何元素的位置时，请使用增强型 `for` 循环。在所有其他情况下使用 `for` 循环：访问任意元素的索引、替换或删除元素、或仅访问部分元素。

请注意，如果你有一个对象数组（而非基本类型），可以使用增强型 `for` 循环和对象的修改器方法来修改任意实例的字段（参见第 221 页 的 `shuffleAll` 方法）。

**不要**使用增强型 `for` 循环来删除或替换数组元素。

#### 示例 1

```
int[] arr = {3, 1, 4, 1, 5, 9};
for (int val : arr) {
    System.out.print(val + " ");
}
```

#### 示例 2

```
int[] arr = {3, 1, 4, 1, 5, 9};
for (int i = 0; i < arr.length; i++) {
    System.out.print(arr[i] + " ");
}
```

```
int[] arr = {3, 1, 4, 1, 5, 9};
int i = 0;
while (i < arr.length) {
    System.out.print(arr[i] + " ");
    i++;
}
```

### 数组作为参数

由于数组被视为对象，将数组作为参数传递意味着传递其对象引用。**不会**创建数组的副本。*因此，实际数组的元素可以被访问——并修改。*

#### 示例 1

访问但不修改数组元素：

```
public static void printArray(int[] arr) {
    for (int val : arr) {
        System.out.print(val + " ");
    }
    System.out.println();
}
```

调用此方法（在定义它的同一个类中）：

```
int[] nums = {1, 2, 3};
printArray(nums);
```

#### 示例 2

修改数组元素：

```
public static void doubleArray(int[] arr) {
    for (int i = 0; i < arr.length; i++) {
        arr[i] *= 2;
    }
}
```

调用此方法（在同一个类中）：

```
int[] nums = {1, 2, 3};
doubleArray(nums);
```

输出结果为

```
2 4 6
```

当数组作为参数传递时，可以改变数组的内容。

查看内存槽位以了解其发生的原因：

```
main: nums ──────┐
                 ▼
              [1, 2, 3]  ◄── doubleArray: arr
```

```
doubleArray 执行后：
main: nums ──────┐
                 ▼
              [2, 4, 6]  ◄── doubleArray: arr
```

#### 示例 3

将 `changeArray` 方法与以下尝试修改单个数组元素的代码进行对比：

```
public static void changeElement(int val) {
    val = 99;
}
```

以下是调用此方法的代码：

```
int[] nums = {1, 2, 3};
changeElement(nums[0]);
System.out.println(nums[0]);
```

与程序员的预期相反，输出为

```

```

查看内存槽位可知列表为何保持不变。

#### 示例 4

```
public static void swap(int[] arr, int i, int j) {
    int temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
```

调用 `swap` 方法：

### 洗牌

讨论了几种不同的算法用于打乱数组元素。良好洗牌的关键要素是生成随机整数。

#### 示例 6

要在数组中洗牌 52 张牌，可能需要一个 0 到 51 之间的随机 `int`：

```
int r = (int) (Math.random() * 52);
```

（回想一下，括号中的乘数是可能的随机整数的数量。）

以下用于打乱 `Type` 类型元素数组的代码经常被使用：

```
public static void shuffle(Object[] arr) {
    for (int i = arr.length - 1; i > 0; i--) {
        int r = (int) (Math.random() * (i + 1));
        Object temp = arr[i];
        arr[i] = arr[r];
        arr[r] = temp;
    }
}
```

### 类对象数组

假设一个大型纸牌锦标赛需要跟踪许多牌组。实现此功能的代码可以使用 `Deck` 数组：

```
public class ManyDecks {
    private Deck[] allDecks;
    
    public ManyDecks(int numDecks) {
        allDecks = new Deck[numDecks];
        for (int i = 0; i < numDecks; i++) {
            allDecks[i] = new Deck();
        }
    }
    
    public void shuffleAll() {
        for (Deck d : allDecks) {
            d.shuffle();
        }
    }
}
```

#### Note

1. 语句

```
Deck[] allDecks = new Deck[500];
```

创建了一个包含 500 个 `Deck` 对象的数组 `allDecks`。这些 `Deck` 对象的默认初始化值为 `null`。为了用实际的牌组对其进行初始化，必须为每个数组元素调用 `Deck` 构造器。这通过 `ManyDecks` 构造器中的 `for` 循环来实现。

2. 在 `shuffleAll` 方法中，可以使用增强型 `for` 循环，通过修改器方法 `shuffle` 来修改数组中的每个牌组。

### 分析数组算法

#### Example 1

讨论下面 `countNegs` 方法的效率。数据的最佳和最差情况配置是什么？

```
public static int countNegs(int[] arr) {
    int count = 0;
    for (int val : arr) {
        if (val < 0) {
            count++;
        }
    }
    return count;
}
```

```
最佳情况：无负元素
最差情况：全为负元素
```

##### Solution

该算法顺序检查数组中的每个元素。在最佳情况下，没有负元素，`count++` 永远不会执行。在最差情况下，所有元素均为负数，`count++` 在 `for` 循环的每次遍历中都会执行。

#### Example 2

下面的代码片段将一个值 `num` 插入到整数有序数组的正确位置。讨论该算法的效率。

```
public static void insertInOrder(int[] arr, int num) {
    int i = arr.length - 1;
    while (i >= 0 && arr[i] > num) {
        arr[i + 1] = arr[i];
        i--;
    }
    arr[i + 1] = num;
}
```

```
最佳情况：num 最大，插在末尾
最差情况：num 最小，插在开头
```

##### Solution

在最佳情况下，`num` 大于数组中的所有元素：因为它被插在列表末尾，所以无需移动任何元素来为其腾出位置。最差情况下 `num` 小于数组中的所有元素。在这种情况下，`num` 必须插在第一个位置 `arr[0]`，数组中的每个元素都必须向上移动一个位置以腾出空位。

该算法说明了数组的一个缺点：在有序列表中插入和删除元素效率低下，因为在最差情况下可能涉及移动列表中的所有元素。

## ArrayList

`ArrayList` 提供了一种存储对象列表的替代方式，与数组相比具有以下优势：

- `ArrayList` 会根据程序需要自动缩减和增长，而数组具有固定长度，在创建数组时设定。
- 在 `ArrayList list` 中，最后一个槽位始终是 `list.size()-1`，而在部分填充的数组中，程序员必须跟踪当前正在使用的最后一个槽位。
- 对于 `ArrayList`，只需一条语句即可进行插入或删除。任何元素的移动都会自动处理。然而在数组中，插入或删除需要编写移动元素的代码。
- 打印 `ArrayList` 的元素比打印数组的元素更容易。对于 `ArrayList list` 和数组 `arr`，语句

```
System.out.println(list);
```

将输出 `list` 的元素，格式美观地用方括号括起，元素之间用逗号分隔。然而，语句

```
System.out.println(arr);
```

将产生包含 `@` 符号的奇怪输出——而不是数组的元素。

### `ArrayList` 类

`ArrayList` 类是 `java.util` 包的一部分。`import` 语句使该类在程序中可用。Java 允许泛型类型 `ArrayList<E>`，其中 `E` 是 `ArrayList` 中元素的类型。声明泛型类时，类型参数将被实际对象类型替换。例如，

```
ArrayList<Clown> clowns = new ArrayList<Clown>();
```

#### Note

`clowns` 列表必须仅包含 `Clown` 对象。例如，尝试向列表中添加 `Acrobat` 将导致编译时错误。

### `ArrayList<E>` 的方法

以下是你应该了解的方法：

```
public ArrayList<E>()
```

构造器构造一个空列表。

```
public int size()
```

返回列表中的元素数量。

```
public boolean add(E obj)
```

将 `obj` 追加到列表末尾。始终返回 `true`。如果指定元素不是类型 `E`，则抛出运行时异常。

```
public void add(int index, E element)
```

在指定 `index` 处插入 `element`。位置 `index` 及之后的元素其索引加 1。列表大小加 1。

```
public E get(int index)
```

返回列表中指定 `index` 处的元素。

```
public E set(int index, E element)
```

用指定的 `element` 替换列表中指定 `index` 处的项。返回之前位于 `index` 处的元素。如果指定元素不是类型 `E`，则抛出运行时异常。

```
public E remove(int index)
```

移除并返回指定 `index` 处的元素。位置 `index` 右侧的元素其索引减 1。列表大小减 1。

#### Note

这些带有 `index` 参数的方法——`add`、`get`、`remove` 和 `set`——如果 `index` 超出范围，将抛出 `IndexOutOfBoundsException`。对于 `get`、`remove` 和 `set`，如果

```
index < 0 || index >= size()
```

则 `index` 超出范围。然而对于 `add`，在列表末尾添加元素是可以的。因此如果

```
index < 0 || index > size()
```

则 `index` 超出范围。

### 自动装箱与拆箱

`ArrayList` 不能包含像 `double` 或 `int` 这样的基本类型：它必须只包含*对象*。（实际上它包含指向这些对象的引用。）因此，数字在插入 `ArrayList` 之前必须装箱——放入 `Integer` 和 `Double` 等包装类中。

*自动装箱* 是基本类型自动包装在其包装类中的过程。（参见 p. 162。）

要检索存储在 `ArrayList` 中的 `Integer`（或 `Double`）的数值，必须调用 `intValue()`（或 `doubleValue()`）方法（拆箱）。*自动拆箱* 是包装类自动转换为其对应基本类型的过程。这意味着你不需要显式调用 `intValue()` 或 `doubleValue()` 方法。注意，如果程序尝试自动拆箱 `null`，该方法将抛出 `NullPointerException`。

请注意，虽然自动装箱和拆箱减少了代码杂乱，但这些操作在后台仍必须执行，导致运行时效率降低。在数组中赋值和访问基本类型比在 `ArrayList` 中高效得多。因此，对于操作数字序列且不需要使用对象的程序，应考虑使用数组。

#### Note

1. 自动装箱和拆箱是 AP Java 子集的一部分。
2. `List<E>` 接口和 `List<E>` 的方法不再是 AP Java 子集的一部分。

### 遍历 `ArrayList`

遍历 `ArrayList` 意味着使用迭代语句（`for` 循环、`while` 循环或增强型 `for` 循环）访问列表的所有元素。

以下是几个示例，说明不同类型的遍历。

对于简单的访问——例如打印每个元素或将每个元素加到运行总计中等——增强型 `for` 循环是一种方便的遍历方法。

#### Example 4

```
ArrayList<Integer> list = new ArrayList<Integer>();
list.add(-5);
list.add(10);
list.add(-3);
list.add(7);

for (Integer i : list) {
    if (i < 0) {
        System.out.println(i);
    }
}
```

```
-5
-3
```

#### Note

以下是该算法的思路：对于 `ArrayList list` 中的每个 `Integer i`，创建该元素的局部副本，判断它是否为负数，如果是负数则将其打印出来。

要使用特定索引访问元素——例如，替换该索引处的元素，或在该索引处插入元素——请使用索引遍历。由于 `ArrayList` 的索引从 `0` 开始，到 `list.size()-1` 结束，尝试使用超出此范围的索引值访问元素将导致抛出 `IndexOutOfBoundsException`。

#### 示例 5

```
ArrayList<String> list = new ArrayList<String>();
list.add("A");
list.add("B");
list.add("C");

for (int i = 0; i < list.size(); i++) {
    System.out.println("Index " + i + ": " + list.get(i));
}
```
