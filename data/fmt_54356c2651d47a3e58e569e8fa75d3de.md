
## 4.1.2 激活函数

### tanh 函数

$$
\begin{matrix} 
\tanh^{\prime}(x) &= \frac{[(e^{x} + e^{-x})(e^{x} + e^{-x}) - (e^{x} - e^{-x})(e^{x} - e^{-x})]}{(e^{x} + e^{-x})^{2}} \\ 
&= 1 - \frac{(e^{x} - e^{-x})^{2}}{(e^{x} + e^{-x})^{2}} = 1 - \tanh^{2}(x) 
\end{matrix}
$$

Numpy 提供了用于计算 tanh 的计算函数 `tanh()`。以下代码计算 `tanh'(x)` 并绘制 `tanh(x)` 和 `tanh'(x)` 的函数曲线：

```python
def grad_tanh(x):
    a = np.tanh(x)
    return 1 - a**2
```

```python
x = np.arange(-5.0, 5.0, 0.1)
plt.plot(x, np.tanh(x), label="tanh")
plt.plot(x, grad_tanh(x), label="derivative")
plt.legend(loc="upper right", frameon=False)
plt.show()
```

### ReLU 函数

当 `x` 大于 0 时，ReLU 函数 `f(x)` 直接输出 `x`，否则输出 0：

$$
\text{ReLU}(x) = \begin{cases} x & (x > 0) \\ 0 & (x \leq 0) \end{cases}
$$

其导数：

$$
\text{ReLU}'(x) = \begin{cases} 1 & (x > 0) \\ 0 & (x \leq 0) \end{cases}
$$

以下代码计算 `ReLU(x)`、`ReLU'(x)`，并绘制 `ReLU(x)`、`ReLU'(x)` 的函数曲线：

```python
def relu(x):
    return np.maximum(0, x)

def grad_relu(x):
    return 1. * (x > 0)

x = np.arange(-5.0, 5.0, 0.1)
plt.plot(x, relu(x), label="relu")
plt.plot(x, grad_relu(x), label="derivative")
plt.legend(loc="upper right", frameon=False)
plt.show()
```

## 4.1.3 神经网络与深度学习

1943 年，心理学家 McCulloch 和数学家 Pitts 参考生物神经元的结构，发表了抽象神经元模型 MP。1949 年，心理学家 Hebb 提出了 Hebb 学习率，认为人脑神经细胞的突触（即连接）强度是可以改变的。1957 年，计算科学家 Frank Rosenblatt 将人工神经元称为“感知机”，并提出了由两层感知机组成的多层感知机（MLP, Multilayer Perceptron）。在现代机器学习中，感知机更常被称为**神经元**，多层感知机也称为人工神经网络（ANN, Artificial Neural Network），简称**神经网络**。

神经网络由许多简单的“神经元”组成，用于表示一个复杂函数。Softmax 函数是一个多元向量值函数，它接受多个输入值并输出多个输出值，或者说该函数的输入和输出都是一个向量。例如，输入向量 $\mathbf{z} = (z_1, z_2, z_3)$ 和输出向量 $\mathbf{f} = \text{softmax}(\mathbf{z})$ 有 3 个输入值和 3 个输出值 $= (f_1, f_2, f_3)$，该函数可以看作由 3 个神经元组成（如图 4-16 所示）。

**图 4-16** Softmax 函数可以看作由 3 个特殊神经元组成的神经网络（图中右侧列的 3 个圆圈）

这 3 个神经元都接受输入向量 $\mathbf{z} = (z_1, z_2, z_3)$ 并分别生成一个输出 $f_1, f_2, f_3$，即：

$$
f_1 = \frac{e^{z_1}}{e^{z_1} + e^{z_2} + e^{z_3}}
$$

$$
f_2 = \frac{e^{z_2}}{e^{z_1} + e^{z_2} + e^{z_3}}
$$

$$
f_3 = \frac{e^{z_3}}{e^{z_1} + e^{z_2} + e^{z_3}}
$$

这 3 个神经元不同于一般神经元；它们不对输入向量 $\mathbf{z} = (z_1, z_2, z_3)$ 进行加权求和，而是根据上述公式直接输出一个结果值 $f_i$。

对于第 2.6 节螺旋数据集（图 2-6）的二维数据点，进行 3 类别的 softmax 回归，首先用 3 个神经元计算输入向量 $\mathbf{x} = (x_1, x_2)$ 的加权和 $\mathbf{z} = (z_1, z_2, z_3)$，然后将这些神经元输出的加权和 $\mathbf{z} = (z_1, z_2, z_3)$ 输入到 softmax 函数的 3 个神经元中，得到最终输出 $\mathbf{f} = (f_1, f_2, f_3)$。该 softmax 回归的假设函数可以看作由以下神经元组成。

**图 4-17** Softmax 回归的假设函数可以看作中间列的三个加权求和神经元，再结合 softmax 函数的三个神经元

在上述神经网络中，最左列的圆圈代表输入的多个特征。对于二维平面坐标点，一个样本只有 2 个特征，即其横纵坐标值 $\mathbf{x} = (x_1, x_2)$。中间列的神经元是输入数据多个特征的加权和 $z_i$，这些加权和 $\mathbf{z} = (z_1, z_2, z_3)$ 直接输出到最右列，即 softmax 函数的 3 个神经元，每个神经元产生一个输出值 $f_i$，构成了 softmax 回归的最终输出 $\mathbf{f} = (f_1, f_2, f_3)$。可以看出，数据从左侧输入，从右侧输出。左列神经元的输出是右侧神经元的输入。同一列神经元之间没有连接，右侧神经元也不会向左侧神经元输出。也就是说，这是一个数据沿“从左到右”方向推进而不回头的计算过程。这样的神经网络称为**前馈神经网络**（Feedforward Neural Network）。

前馈神经网络中每一列的所有神经元称为神经网络的一层，输入数据的特征通常称为**输入层**，产生最终输出的最后一列神经元称为**输出层**，中间每一列神经元称为**隐藏层**。在前馈神经网络中，数据从输入层开始，依次经过每个隐藏层，最后通过输出层输出神经网络函数的最终输出值。在某些书籍中，包含输入层在内的层数称为神经网络的层数。例如，上述神经网络称为 3 层神经网络；而在某些书籍中，上述神经网络称为 2 层神经网络，即不包含输入层。

如图 4-18 所示，softmax 函数可以看作一个产生多个输出的神经元，而不是看作多个神经元。

**图 4-18** 将 softmax 函数视为一个产生多个输出的单个神经元

### 神经网络结构与前向传播

上述神经网络的神经元有些特殊。其中，softmax 输出层的神经元不计算上一层输入的加权和，隐藏层直接输出加权和，而不经过非线性激活函数的变换，即隐含的 A 层神经元是一个线性回归函数。

一般神经网络隐藏层的神经元类似于逻辑回归神经元，即先计算加权和，再经过非线性激活函数变换后输出。输出层神经元可以是 softmax 神经元、线性回归神经元和逻辑回归神经元。因为 softmax 层的神经元没有权重等参数，而是一个确定的 `softmax()` 函数，所以在为多分类问题设计神经网络时，`softmax()` 函数不能作为单独的一层，而是直接将 softmax 层的上一层作为输出层。也就是说，softmax 回归可以用下面的神经网络表示（如图 4-19 所示）：

**图 4-19** Softmax 回归可能不包含 softmax，可视为仅由 3 个加权求和神经元组成的神经网络

即只有输入层和输出层，没有隐藏层。输出层的输出值代表输入数据属于各个类别的得分。这个得分再经过 `softmax()` 就可以输出数据属于各个类别的概率。也就是说，计算分类概率的 softmax 函数可以在图中省略。

实际的神经网络至少包含一个隐藏层，通常包含很多隐藏层。随着以 GPU 为代表的硬件算力的发展和大规模数据的可用，现代神经网络通常包含很多隐藏层。神经网络包含的层数称为神经网络的深度，即现代神经网络的深度可以很大，甚至包含数百个隐藏层。更深的神经网络称为**深度神经网络**，基于深度神经网络的机器学习称为**深度学习**。

无论是深度神经网络还是浅层神经网络，其工作原理都是一样的。只是深度神经网络的深度更深而已。为简单起见，下面用一个浅层神经网络为例，说明如何用神经网络进行学习。

为了对上述二维坐标点进行分类，如图 4-20 所示，可以使用一个简单的 2 层神经网络作为假设函数进行模型训练。

**图 4-20** 2 层神经网络，最左列是数据，中间列神经元构成隐藏层，最右列神经元构成输出层

隐藏层和输出层都是类似于逻辑回归函数的神经元，即每个神经元用自己的权重向量计算一个加权和 `z`，然后通过自己的激活函数产生一个输出值 `a`。

这个只有一个隐藏层的 2 层神经网络定义了一个函数 `f : R^D → R^K`。其中 `D` 是输入向量 `x` 的大小，`K` 是输出向量 `f(x)` 的大小。分别用 `l = 0,1,2` 表示每一层，对一个神经元，用 `z` 表示输入值的加权和，用 `z[i]^[l]` 表示第 `l` 层第 `i` 个神经元的加权和，`a` 表示输出值，`a[i]^[l]` 表示第 `l` 层第 `i` 个神经元的激活值。当 `l=0` 时，`a[i]^((0))` 是第 `i` 个输入特征。

假设第 1 层所有神经元的激活函数是同一个函数 `g^[1]`，每个神经元接受一个输入 `x = (x[1], x[2])` 并产生一个输出值，这些输出值（激活值）也构成一个向量 `a^[1] = (a[1]^[1], a[2]^[1], a[3]^[1], a[4]^[1])`：

```
a[1]^[1] = g^[1](z[1]^[1])
a[2]^[1] = g^[1](z[2]^[1])
a[3]^[1] = g^[1](z[3]^[1])
a[4]^[1] = g^[1](z[4]^[1])
```

用矩阵 `W^[1]`、`b^[1]` 表示这些权重和偏置向量：

```
W^[1] = [[W_11^[1], W_12^[1], W_13^[1], W_14^[1]],
         [W_21^[1], W_22^[1], W_23^[1], W_24^[1]]]

b^[1] = (b_1^[1], b_2^[1], b_3^[1], b_4^[1])
```

即每一列代表一个神经元的权重或偏置，第 1 层神经元的计算过程可以表示为：

```
a^[1] = g^[1](a^[0] * W^[1] + b^[1])
      1×4   1×2   2×4   1×4
```

假设第 2 层（输出层）所有神经元的激活函数也是同一个 `g^[2]`，它们接受来自隐藏层的这些输出值 `a^[1] = (a[1]^[1], a[2]^[1], a[3]^[1], a[4]^[1])`，最终的输出值是向量 `a^[2] = (a[1]^[2], a[2]^[2], a[3]^[2])`：

```
a_1^[2] = g^[2](z_1^[2])
a_2^[2] = g^[2](z_2^[2])
a_3^[2] = g^[2](z_3^[2])
```

用矩阵 `W^[2]`、`b^[2]` 表示这些权重和偏置向量：

```
W^[2] = [[W_11^[2], W_12^[2], W_13^[2]],
         [W_21^[2], W_22^[2], W_23^[2]],
         [W_31^[2], W_32^[2], W_33^[2]],
         [W_41^[2], W_42^[2], W_43^[2]]]

b^[2] = (b_1^[2], b_2^[2], b_3^[2])
```

第 2 层神经元的计算过程可以表示为：

```
a^[2] = g^[2](a^[1] * W^[2] + b^[2])
      1×3   1×4   4×3   1×3
```

整个神经网络函数 `f(x)` 用向量形式写出：

```
f(x) = g^[2](g^[1](x * W^[1] + b^[1]) * W^[2] + b^[2])
```

用 `a^((0))` 表示输入数据 `x`，即：

```
a^((0)) = (a_1^((0)), a_2^((0))) = x = (x_1, x_2)
```

然后输入一个 `x` 即 `a^((0))`，该神经网络的计算过程如下：

$$
\begin{matrix} 
z^{[1]} &= a^{[0]}W^{[1]} + b^{[1]} \\ 
a^{[1]} &= g^{[1]}(z^{[1]}) \\ 
z^{[2]} &= a^{[1]}W^{[2]} + b^{[2]} \\ 
f(x) &= a^{[2]} = g^{[2]}(z^{[2]}) 
\end{matrix}
$$

根据 `x` → `z`^(\[1\]) → `a`^(\[1\]) → `z`^(\[2\]) → `a`^(\[2\])，计算神经网络最终输出的过程称为**前向传播** (forward propagation) 或**前向计算**。

可以看出，第一层和第二层的加权和与激活值的计算过程完全相似。对于一般的神经网络，第 `l` 层的加权和与激活值的计算公式如下：

$$
\begin{matrix} 
z^{[l]} &= a^{[l-1]}W^{[l]} + b^{[l]} \\ 
a^{[l]} &= g^{[l]}(z^{[l]}) 
\end{matrix}
$$

第 `l` 层接收来自第 `l-1` 层的输入 `a`^(\[*l* − 1\])，并计算加权和 `z`^(\[*l*\]) = `a`^(\[*l* − 1\])\*`W`^(\[*l*\]) + `b`^(\[*l*\]), 通过激活函数 `g`^(\[*l*\]), 输出 `a`^(\[*l*\]) = `g`^(\[*l*\])(`z`^(\[*l*\])) 。
