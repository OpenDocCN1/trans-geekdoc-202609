
本书涵盖了从器件、架构、学习算法到系统视角的新兴 ReRAM 全流程内容。具体章节安排如下。

第二章介绍了可支持 IMC 的新兴存储器件，并阐述了 IMC 的必要性。此外，还对不同的 IMC 架构进行了全面的比较与分析。这些架构包括从传统 DRAM 到 ReRAM、忆阻器等新兴器件。

第三章介绍了 ReRAM 器件建模，随后阐述了主要用于 ML 应用中矩阵乘法的交叉阵列结构设计。此外，还介绍了 ReRAM 的多比特存储设计以及基于 ReRAM 的其他逻辑功能单元。

第四章提供了 ML 算法的基本信息、计算复杂度及涉及的运算类型，包括最小二乘法（支持向量机 `SVM`、极限学习机 `ELM`）和深度学习（`CNN`、`TNN`）。本章将讨论训练量化（二值、三值、八位等）。此外，本章重点关注深度 `CNN` 和 `TNN` 的训练机制，因为它们是耗时操作，且性能取决于训练效率。

最后一章总结了 ReRAM 加速器及其对 ML 应用的影响。此外，还展望了利用 ReRAM 器件进一步增强 ML 计算的未来方向。

## 第 2 章

### 存内计算的必要性

#### 2.1 简介

1974 年，Dennard 预测随着晶体管特征尺寸的缩小，开关功耗将随之降低[68]，这一趋势在 2004 年前后终止。尽管晶体管尺寸持续缩小，但由于漏电流的增加，晶体管的工作电压和电流降低陷入停滞。工作频率的提高和晶体管密度的增加进一步加剧了计算系统的功耗，产生大量热量并阻碍了能效。功耗的另一个挑战源于传统冯·诺依曼或普林斯顿计算架构中数据处理单元与存储单元之间密集的数据传输，即所谓的“存储墙”。在这种计算范式中，由于数据和指令都存储在同一存储空间，计算单元在某一时刻只能处理一个任务并等待存储器更新其结果，这极大地限制了吞吐量并导致空闲功耗。尽管缓存和分支预测等机制可以部分消除这些问题，但“存储墙”仍然是现代处理器技术中海量数据交换面临的重大挑战。

为突破“存储墙”，存内计算自 2000 年代起便被研究，并被视为减少存储器与处理单元间冗余数据移动、降低功耗的有前景途径。该概念已通过不同硬件工具实现，例如三维堆叠动态随机存取存储器（DRAM）[69]和嵌入式 FLASH[70]。剪枝、量化和混合精度拓扑等软件解决方案被实施以减少信号交换的强度。

生物神经网络（NN）在能效方面优于基于中央处理器（CPU）或图形处理器（GPU）的传统冯·诺依曼计算架构，在执行密集并行计算时，每个突触事件仅消耗 1–100 fJ [71,72]。目前，突触阻变随机存取存储器（ReRAM）已成功展现出低功耗（(<pJ)）特性[73]。然而，即使是两款最有前景的全基于 CMOS 的类脑芯片——英特尔的 Loihi 和 IBM 的 TrueNorth，在能效方面仍落后于生物神经网络，每个突触事件分别消耗 23.6 和 26 pJ [74,75]。类脑计算通过模拟器件中的突触动力学以及神经网络中的数据流/连接，实现低功耗计算。突触事件由存储器件中的离子通量直接监测并精确调节，已在基于 ReRAM 的系统中成功仿真[73]。如图 2.1 所示[77]，与传统冯·诺依曼计算架构相比，类脑计算架构拥有复杂度更低的外围驱动电路和更简单的权重修改过程（例如快速点积运算[76]）。类脑计算还强调对系统级神经架构的模仿，例如人工神经网络（ANN）[78]、卷积神经网络（CNN）[79]、脉冲神经网络（SNN）[75,80]和循环神经网络（RNN）[81]。与通用处理器不同，神经网络是为特定应用场景构建的。例如，CNN 具有分离的层和模块化的内核，可实现快速准确的特征识别；RNN 的循环输出使其适合语音识别；SNN 是一种事件驱动系统，更加灵活且容错性更强。基于专用类脑计算架构的片上系统（SoC）在功耗方面通常比基于传统冯·诺依曼架构的系统低几个数量级。例如，基于异步 SNN 的英特尔 Loihi 芯片[75]在能效和面积效率方面均比单个 CPU 高出三个数量级。

基于冯·诺依曼架构和 Si CMOS 技术的传统计算机系统，虽然数据处理速度更快、计算精度远高于人脑，但在功耗方面仍显著落后。例如，谷歌开发的有监督深度学习机器 AlphaGo，由多达 1,202 个 CPU 和 176 个 GPU 组成，击败了围棋世界冠军，但其能耗是人脑的 1,000 倍。类脑计算算法的最新进展，涉及有效解决类似人脑的复杂任务，如模式识别、数据分类和目标检测，使其接近实际应用。然而，基于 Si CMOS 技术出于并行性和权重自适应原因对这些类脑计算算法的硬件实现，在计算、存储和通信方面带来了巨大挑战，并导致高功耗。在类脑计算系统的硬件实现方面取得突破显得极为迫切。

#### 2.2 类脑计算器件

随着当今计算变得越来越数据密集，计算范式正从以计算为中心转向以数据为中心。类脑计算（例如向量矩阵乘法）要求器件具备线性对称调谐、长保持时间、低随机行为（盲更新）和低能量调谐等特性。新兴非易失性存储器（NVM）有望满足这些要求，例如瞬时写/读（~ns）、低工作电压（<1 V）和低功耗（<pJ/突触事件）[82]。此处我们简要描述 ReRAM、自旋扭矩转移磁性随机存取存储器（STT-MRAM）和相变存储器（PCM）的工作机制。

广泛使用的静态随机存取存储器（SRAM）和动态随机存取存储器（DRAM）通过电荷存储信息，需要持续的工作电压波来通过给电容充放电以维持或更新其状态。作为新兴 NVM 的 ReRAM 是非基于电荷的器件，摆脱了电容存储数据的限制。较小的工作电压（<1 V）足以驱动 ReRAM 运行，且维持状态无需后续功耗。

当今的深度学习应用需要前所未有的海量数据进行动态数据分析。传统 CPU/GPU 必须通过编程程序从缓存存储器获取数据，这通常因缺乏有用数据而导致处理器待机。由于数据交换在延迟和功耗方面代价高昂，最直接的优化方法是数据本地化，即最小化处理器与缓存之间的物理距离。ReRAM 与 CMOS 具有良好的兼容性，使其成为三维堆叠的理想选择。三维堆叠 ReRAM 可安装在处理器顶部，凭借其厚度优势缩短数据传输路径并实现高密度存储。三维堆叠 ReRAM 存储器可大幅减少数据传输、扩大数据复用，并最终提高能效。与当前主流存储器相比，STT-MRAM 在单元尺寸和能效上优于 SRAM，ReRAM 在功耗、读写速度和耐久性上优于 FLASH。在 STT-MRAM 中，保持时间与工作或开关功耗存在权衡。与其他保持时间超过 10 年的 NVM 器件不同，STT-MRAM 的保持时间与激励脉冲呈一一对应关系。作为 RAM 的替代品，STT-MRAM 的长保持时间与性能无关，因此可降低保持时间（例如至秒级）以实现更低功耗。

### 2.2 神经形态计算用非易失性存储器件

作为存储器，读/写操作对计算至关重要。与传统的状态保持单元不同，ReRAM 可以在交叉阵列中分别进行读出和调制，且具有高功率效率。因为在读/写过程中，例如一晶体管一 ReRAM (`1T1R`) 结构，只有目标单元被选中，而所有其他单元保持空闲。

#### 2.2.1 电阻式随机存取存储器

ReRAM 的电阻切换特性最早于 20 世纪 60 年代被研究 [82]。ReRAM 的器件结构是一种三明治状结构，即两个金属电极之间夹着一层绝缘材料。它包括顶电极 (`TE`)、中间的氧化物层和底电极 (`BE`)。通常，ReRAM 是两端器件，具有两种电阻状态：高电阻状态 (`HRS`，或 OFF 状态) 和低电阻状态 (`LRS`，或 ON 状态)。电阻状态通过施加的电位和刺激持续时间来控制。电阻切换机制是由于氧空位的产生和漂移，导致金属氧化物中导电丝的形成/断裂。它在 `SET`/`RESET` 过程中表现出对称行为或李萨如 `I/V` 曲线。非基于电荷的 ReRAM 具有长期可塑性特征，能在一定周期内保持权重（电导）稳定，即使没有循环工作电源。

#### 2.2.2 自旋转矩磁阻随机存取存储器

`STT-MRAM` 包含三层形成磁隧道结 (`MTJ`)：用于数据存储的自由层、用于参考的钉扎层，以及用于磁绝缘和数据读取过程的隧道势垒层 [86, 87]。隧道势垒定义了 `ON` 和 `OFF` 状态切换的能垒 (![image](img/ch02_stripin_si17.gif))。自由层的磁场方向决定了存储单元的电阻。当自由层和隧道层的磁矩平行时，`STT-MRAM` 表现为低电阻。`STT-MRAM` 在反平行构型下表现为 `HRS`。通过向自由层引入相反的磁场，`STT-MRAM` 可表现出多个电阻状态 [87]。一个绝缘畴壁被放置在两个相反的磁畴之间，并由 `STT` 现象调节。由于保持时间与 ![image](img/ch02_stripin_si18.gif) 和切换功耗相关，`STT-MRAM` 在所有 `NVM` 中具有最小的功耗，并凭借其充分利用的非易失性实现了高工作速度。

#### 2.2.3 相变存储器

在 `PCM` 中，从 `HRS` 到 `LRS` 的转变表现为切换层从非晶态到晶态的相变。在 `RESET` 过程中，晶态相变材料通过电产生的热熔化为非晶相。将相变材料 `SET` 回 `LRS` 只需要较小的电流。

与 `SRAM` 和 `FLASH` 相比，`NVM` 器件在数据存储方面表现出耐久性、功耗和速度上的巨大优势。基于 ReRAM 的混合系统可同时作为存储器和处理器工作，从而消除冗余数据移动。随着点积引擎 [76, 89] 的推动，ReRAM 阵列仅利用欧姆定律和基尔霍夫电流定律，即可在极短时间内解决某些复杂任务，例如矩阵的乘法与求和运算。

`PCM` 具有与 ReRAM 相似的突触可塑性。与其他 `NVM` 器件相比，`PCM` 具有相对较大的电阻切换范围，使其成为每个事件调制尺度为 1% 的突触模拟计算的理想选择。通过使用幅度逐渐增加和持续时间定制的刺激脉冲，据报道 `PCM` 从 `LRS` 到 `HRS` 拥有超过 200 个调节电平 [90]。如图 2.1 所示，`PCM` 的可塑性或权重更新具有时间依赖性。前/后突触事件的不同到达时间决定了调制方向。类似于神经突触，`PCM` 对一连串连续尖峰表现出累积行为，可按公式 (2.3) 描述：

### 2.3 神经形态计算用 NVM 器件的特性

用于计算的神经形态器件的理想特性包括线性/对称调谐、可扩展性、多电平电阻状态、长保持时间、随机行为和低能耗。

1. **线性/对称调谐**：由于权重更新遵循时间依赖机制，权重载体与刺激脉冲之间的线性和对称关系有助于减少计算操作和功耗。上述大多数 `NVM` 具有相对线性的 `I/V` 电学特性。例如，通过施加一串持续时间变化的脉冲，可以增强 `TaO[x]`/`TiO[2]` ReRAM 的线性度，如图 2.2 所示。

2. **可扩展性和可堆叠性**：存储器件的向下缩放实现了高密度集成。大多数 `NVM` 器件已成功制造在约 10 nm 尺度水平。为进一步提高集成密度并缩短存储与处理之间的距离，新兴 `NVM` 器件以三维 (`3D`) 堆叠方式实现并嵌入处理器中。

3. **多电平电阻状态**

由于生物突触中的权重以模拟形式处理，因此类脑器件需要多电平电阻状态。大量生物启发式算法需要多电平状态，而非推断出的 0/1 状态 [92]。

4. **长时间保持**

在计算实现过程中，权重的持续更新对保持时间的要求有限。但在操作完成后，需要 NVM 的长保持时间，以确保即使 NVM 器件切换到空闲状态（断电），存储的权重仍然保留。因此，由于基于 NVM 的系统不再需要权重的全局更新，可以节省额外的功耗。

5. **低随机隧穿**

NVM 仍然面临器件变异和切换模糊性的问题，例如 ReRAM 和 PCM 中电阻的骤降。NVM 的随机切换特性仍是一个开放的研究课题，并阻碍了商业应用。最近有一些关于神经网络 [92, 93] 的研究，显示出对器件变异的强鲁棒性。然而，此类神经网络在架构和精度上有所妥协。

### 2.4 面向机器学习的 IMC 架构

因此，针对替代性非冯·诺依曼计算机架构（如存内计算和近存计算）的研究日益增多，旨在克服传统冯·诺依曼架构面临的现有挑战 [20, 94]。IMC 或存内处理 (PIM) 通过在存储芯片内部实现处理单元，弥合了存储器与处理器之间的分离 [95, 96]。受限于存储芯片的制造工艺，这些处理元件只能实现有限的功能 [97]。然而，它们可以利用存储芯片内部的位线级并行性，构建大规模并行的单指令多数据流 (SIMD) 式处理架构，同时也享受通过存储位线实现的超高带宽和低延迟数据通信。IMC 成为实现机器学习应用的可行候选者，最重要的是 CNN 算法，因为在 GPU 和 CPU 上实现时，仅卷积操作就占据了 CNN 计算时间最大的比例 [94, 98]。IMC 架构可在 CNN/DNN 应用中实现无与伦比的能效下的显著性能优化。

过去十年间，大量研究致力于在不同存储平台上设计 CNN/DNN 推理和训练机器，包括传统的 SRAM 和 DRAM 存储平台，以及新型非易失性电阻式 RAM (ReRAM)、PCM 和 MRAM，如 STT-MRAM 和自旋轨道扭矩 MRAM (SOT-MRAM) 技术。研究发现，即使在 CNN 算法中对数据参数执行各种级别的量化/降级，仍可保持令人满意的精度水平 [93–103]。这为物联网和移动应用的高性能、低功耗 CNN 实现开辟了探索空间。IMC 范式也在利用这种数据降级技术 [94, 103–111]。

鉴于存储技术在 IMC 系统设计中的重要性，我们首先根据 IMC 所基于的存储技术对 IMC 架构进行分类。存储技术可分为传统存储器 (SRAM 和 DRAM) 和新兴存储器 (ReRAM、STT-MRAM 和 SOT-MRAM)。下文将提供基于存储技术的 IMC 相关最新工作。
