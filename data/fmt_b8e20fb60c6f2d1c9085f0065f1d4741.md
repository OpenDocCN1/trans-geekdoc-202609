## 使用 infoGAN 生成可控的假图像

在 `Cell 09` 中，噪声张量生成器函数 `noise4G_input` 对我们来说是新的。它生成三个随机张量并将它们连接成一个 $m \times 16$ 的张量 `Z`，这是该函数的第一个输出。该张量将用于生成一批假曲线。该函数的另外两个输出（`labels` 和 `con_c`）将在模型训练期间更新，并可用于调整这些假图像以达到我们期望的效果。`Cell 10` 中的 `train_D1` 函数与普通 GAN 中的一样。在 `Cell 11` 中关于名为 `train_G` 的函数，损失函数有三个部分。第一部分是用于欺骗模型 D1 的 BCE 损失；第二部分是用于建立模型 Q 的 logits 输出与潜在标签之间联系的交叉熵损失；第三部分是高斯负对数似然损失。它用于确保服从正态分布 $N(c[3]; \mu, \sigma^2)$ 的潜在代码中的风格变量，其中 `mu` 和 `var` = $\sigma^2$ 是模型 Q 的两个输出。我们使用 PyTorch 的一个名为 `nn.GaussianNLLLoss` 的类来计算损失值。

`Cell 12` 到 `14` 的代码用于训练模型并显示模型训练结果。模型训练后，生成了一条单独的假曲线，如图 6.1(F) 所示。其数据由 `Z = torch.randn(1, Z_dim)` 生成，然后通过 `Z[:,13] = 0`、`Z[:,14] = 1` 和 `Z[:,15] = -0.1` 进行设置。使用标签代码 `c[1] = 0` 和 `c[2] = 1`，infoGAN 系统生成一条最低点低于 $y = 0.5$ 的假曲线；而使用标签 `c[1] = 1` 和 `c[2] = 0`，infoGAN 系统生成一条最低点高于 $y = 0.5$ 的假曲线。风格变量 `c[3]` 可用于沿 $y$ 轴连续调整假曲线的最低点。如果 $|c[3]|$ 太大（$\gg 1$），假曲线将不平滑。基于 infoGAN 理论的额外工作赋予了我们在没有数据集标签信息的情况下调整假图像的能力。

### 6.2 MNIST 数据集中 infoGAN 的实现

### 6.4 infoGAN 在剪刀石头布数据集上的实现
