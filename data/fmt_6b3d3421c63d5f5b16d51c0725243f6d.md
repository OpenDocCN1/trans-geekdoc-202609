## 1.7 for 循环

和所有的编程语言一样，R 也有 `for` 循环来处理重复任务。通常其语法如下：

```r
for (variable in collection) { 
  # 对 variable 进行操作  
}
```

让我们来看一个例子：

```r
best_practice <- c("Let", "the", "computer", "do", "the", "work")

print_words <- function(sentence) { 
  for (word in sentence) {
    print(word)
  }
}  

print_words(best_practice)
```
```
## [1] "Let"
## [1] "the"
## [1] "computer"
## [1] "do"
## [1] "the"
## [1] "work"
```

或者另一个例子：

```r
len <- 0
vowels <- c("a", "e", "i", "o", "u")
for (v in vowels) {
  len <- len + 1 
} 
```

# 元音数量

```r
len
```
```
## [1] 5
```

## 1.8 决策判断 (if & else)

为了在 R 脚本中做出决策，R 为你提供了标准的 `if-else` 条件语句。

```r
num <- 37

if (num > 100) { 
  print("greater")
} else { 
  print("not greater") 
}
```
```
## [1] "not greater"
```

或者让我们创建一个使用条件判断的函数：

```r
sign <- function(num) { 
  if (num > 0) {
    return(1)  
  } else if (num == 0) {  
    return(0)  
  } else {  
    return(-1)  
  }  
}

sign(-3)
```
```
## [1] -1
```

你可以使用逻辑运算符来做出决策：

- 等于 (`==`)
- 大于等于 (`>=`)
- 小于等于 (`<=`)
- 不等于 (`!=`)

我们也可以组合测试。安培符号 `&` 代表逻辑“与”。竖线 `|` 代表逻辑“或”。

## 1.10 因子 (Factors)

`factor()` 命令用于在 R 中创建和修改因子：

```r
sex <- factor(c("male", "female"))
```

R 将把 1 分配给水平 `"female"`，将 2 分配给水平 `"male"`（因为按字母顺序第一个元素是 `"female"`）。你可以通过 `levels()` 检查：

```r
levels(sex)
```
```
## [1] "female" "male"
```

```r
nlevels(sex)
```
```
## [1] 2
```

有时，因子的顺序并不重要，其他时候你可能想指定顺序，因为它是有意义的（例如，“低”、“中”、“高”），或者是特定类型分析的要求。此外，指定水平顺序允许我们比较：

```r
food <- factor(c("low", "high", "medium"))
```
```
## [1] low high medium
## Levels: high low medium
```

```r
levels(food)
```
```
## [1] "high" "low" "medium"
```

```r
min(food)
```
```
## Error in Summary.factor(structure(... : 'min' not meaningful for factors
```
