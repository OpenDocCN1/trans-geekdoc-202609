
```
fmt.Println(string(65))     // "A"，而不是 "65"
fmt.Println(string(0x4eac)) // "京"
```

如果 rune 无效，则会替换为替换字符：

```
fmt.Println(string(1234567)) // "�"
```

### 3.5.4 字符串和字节切片

有四个标准包对于操作字符串尤为重要：`bytes`、`strings`、`strconv` 和 `unicode`。`strings` 包提供了许多用于搜索、替换、比较、修剪、分割和连接字符串的函数。

`bytes` 包拥有用于操作类型为 `[]byte` 的字节切片的类似函数，字节切片与字符串共享一些特性。因为字符串是不可变的，逐步构建字符串可能涉及大量的分配和复制。在这种情况下，使用 `bytes.Buffer` 类型会更高效，我们马上就会演示。

`strconv` 包提供了用于布尔值、整数和浮点数与其字符串表示之间相互转换的函数，以及用于给字符串加引号和去引号的函数。

`unicode` 包提供了诸如 `IsDigit`、`IsLetter`、`IsUpper` 和 `IsLower` 等函数，用于对 rune 进行分类。每个函数接受单个 rune 参数并返回一个布尔值。`ToUpper` 和 `ToLower` 等转换函数将 rune 转换为指定的大小写（如果它是字母的话）。所有这些函数都使用 Unicode 标准类别来处理字母、数字等。`strings` 包也有类似的函数，也叫 `ToUpper` 和 `ToLower`，它们会返回一个新字符串，其中原始字符串的每个字符都应用了指定的转换。

下面的 `basename` 函数灵感来源于同名的 Unix shell 实用工具。在我们的版本中，`basename(s)` 会移除 `s` 中看起来像文件系统路径（组件由斜杠分隔）的任何前缀，并移除看起来像文件类型的任何后缀：

```
fmt.Println(basename("a/b/c.go")) // "c"
fmt.Println(basename("c.d.go"))   // "c.d"
fmt.Println(basename("abc"))      // "abc"
```

`basename` 的第一个版本在没有库函数帮助的情况下完成所有工作：

gopl.io/ch3/basename1

```
// basename 移除目录组件和 .后缀。
// 例如：a => a, a.go => a, a/b/c.go => c, a/b.c.go => b.c
func basename(s string) string {
    // 丢弃最后一个 '/' 及其之前的所有内容。
    for i := len(s) - 1; i >= 0; i-- {
        if s[i] == '/' {
            s = s[i+1:]
            break
        }
    }
    // 保留最后一个 '.' 之前的所有内容。
    for i := len(s) - 1; i >= 0; i-- {
        if s[i] == '.' {
            s = s[:i]
            break
        }
    }
    return s
}
```

一个更简单的版本使用了 `strings.LastIndex` 库函数：

gopl.io/ch3/basename2

```
func basename(s string) string {
    slash := strings.LastIndex(s, "/") // 如果未找到 "/" 则为 -1
    s = s[slash+1:]
    if dot := strings.LastIndex(s, "."); dot >= 0 {
        s = s[:dot]
    }
    return s
}
```

`path` 和 `path/filepath` 包提供了一组更通用的函数，用于操作分层名称。`path` 包适用于任何平台上以斜杠分隔的路径。它不应用于文件名，但适用于其他领域，例如 URL 的路径组件。相比之下，`path/filepath` 使用宿主平台的规则操作文件名，例如 POSIX 上的 `/foo/bar` 或 Microsoft Windows 上的 `c:\foo\bar`。

让我们继续看另一个子字符串示例。任务是获取一个整数的字符串表示形式，例如 `"12345"`，并每三位插入一个逗号，如 `"12,345"`。此版本仅适用于整数；处理浮点数留作练习。

gopl.io/ch3/comma

```
// comma 在非负十进制整数字符串中插入逗号。
func comma(s string) string {
    n := len(s)
    if n <= 3 {
        return s
    }
    return comma(s[:n-3]) + "," + s[n-3:]
}
```

`comma` 的参数是一个字符串。如果其长度小于或等于 3，则不需要逗号。否则，`comma` 会使用一个由除最后三个字符外的所有字符组成的子字符串递归调用自身，并将逗号和最后三个字符追加到递归调用的结果中。

字符串包含一个字节数组，一旦创建便不可变。相比之下，字节切片的元素可以自由修改。

字符串可以转换为字节切片，也可以转回字符串：

```
s := "abc"
b := []byte(s)
s2 := string(b)
```

从概念上讲，`[]byte(s)` 转换会分配一个新的字节数组来保存 `s` 的字节副本，并生成一个引用该数组全部内容的切片。优化编译器在某些情况下可能会避免分配和复制，但通常需要复制以确保 `s` 的字节保持不变，即使 `b` 的字节随后被修改。使用 `string(b)` 从字节切片转回字符串也会进行复制，以确保生成的字符串 `s2` 不可变。

为了避免转换和不必要的内存分配，`bytes` 包中的许多实用函数直接对应 `strings` 包中的同类函数。例如，这里有 `strings` 包中的六个函数：

```
func Contains(s, substr string) bool
func Count(s, sep string) int
func Fields(s string) []string
func HasPrefix(s, prefix string) bool
func Index(s, sep string) int
func Join(a []string, sep string) string
```

以及 `bytes` 包中对应的函数：

```
func Contains(b, subslice []byte) bool
func Count(s, sep []byte) int
func Fields(s []byte) [][]byte
func HasPrefix(s, prefix []byte) bool
func Index(s, sep []byte) int
func Join(s [][]byte, sep []byte) []byte
```

唯一的区别在于字符串被字节切片取代了。

`bytes` 包提供了 `Buffer` 类型，用于高效操作字节切片。`Buffer` 最初为空，但随着 `string`、`byte` 和 `[]byte` 等类型的数据被写入而增长。正如下面的示例所示，`bytes.Buffer` 变量无需初始化，因为其零值可用：

gopl.io/ch3/printints

```
// intsToString 类似于 fmt.Sprint(values) 但会添加逗号。
func intsToString(values []int) string {
    var buf bytes.Buffer
    buf.WriteByte('[')
    for i, v := range values {
        if i > 0 {
            buf.WriteString(", ")
        }
        fmt.Fprintf(&buf, "%d", v)
    }
    buf.WriteByte(']')
    return buf.String()
}

func main() {
    fmt.Println(intsToString([]int{1, 2, 3})) // "[1, 2, 3]"
}
```

当将任意 rune 的 UTF-8 编码追加到 `bytes.Buffer` 时，最好使用 `bytes.Buffer` 的 `WriteRune` 方法，但对于 `'['` 和 `']'` 等 ASCII 字符，`WriteByte` 也完全可以。

`bytes.Buffer` 类型非常通用，当我们在第 7 章讨论接口时，将会看到如何将其用作文件的替代品，无论何时 I/O 函数需要一个字节接收器（`io.Writer`），就像上面的 `Fprintf` 那样，或者一个字节源（`io.Reader`）。

### 3.5.5 字符串和数字之间的转换

除了字符串、rune 和字节之间的转换之外，经常还需要在数值及其字符串表示之间进行转换。这可以通过 `strconv` 包中的函数来完成。

要将整数转换为字符串，一种选择是使用 `fmt.Sprintf`；另一种是使用函数 `strconv.Itoa`（“integer to ASCII”，整数转 ASCII）：

```
x := 123
y := fmt.Sprintf("%d", x)
fmt.Println(y, strconv.Itoa(x)) // "123 123"
```

`FormatInt` 和 `FormatUint` 可用于以不同的基数格式化数字：

```
fmt.Println(strconv.FormatInt(int64(x), 2)) // "1111011"
```

`fmt.Printf` 的动词 `%b`、`%d`、`%u` 和 `%x` 通常比 `Format` 函数更方便，特别是当我们想在数字之外包含额外信息时：

```
s := fmt.Sprintf("x=%b", x) // "x=1111011"
```

要解析表示整数的字符串，请使用 `strconv` 函数 `Atoi` 或 `ParseInt`，对于无符号整数则使用 `ParseUint`：

```
x, err := strconv.Atoi("123")             // x 是一个 int
y, err := strconv.ParseInt("123", 10, 64) // 基数 10，最多 64 位
```

`ParseInt` 的第三个参数给出了结果必须适应的整数类型的大小；例如，16 表示 `int16`，特殊值 0 表示 `int`。无论哪种情况，结果 `y` 的类型始终是 `int64`，你可以将其转换为更小的类型。

有时 `fmt.Scanf` 可用于解析由字符串和数字有序混合且全部在单行上的输入，但它可能不够灵活，特别是在处理不完整或不规则输入时。

## 3.6 常量

常量是其值在编译时已知且求值保证发生在编译时而非运行时的表达式。每个常量的底层类型都是基本类型：布尔型、字符串或数字。

`const` 声明定义了命名的值，它们在语法上看起来像变量，但其值是常量，这防止了在程序执行期间意外（或恶意）地更改。例如，常量比变量更适合用于像 `pi` 这样的数学常量，因为它的值不会改变：

```
const pi = 3.14159 // 近似值；math.Pi 是更好的近似值
```

与变量一样，一组常量可以出现在一个声明中；这适用于一组相关的值：

```
const (
    e  = 2.71828182845904523536028747135266249775724709369995957496696763
    pi = 3.14159265358979323846264338327950288419716939937510582097494459
)
```

许多常量上的计算可以在编译时完全求值，减少了运行时所需的工作并启用了其他编译器优化。通常在运行时检测到的错误，如果其操作数是常量，则可以在编译时报告，例如整数除以零、字符串索引越界，以及任何会导致非有限值的浮点运算。

应用于常量操作数的所有算术、逻辑和比较操作的结果本身也是常量，转换的结果以及对某些内置函数的调用结果也是常量，例如 `len`、`cap`、`real`、`imag`、`complex` 和 `unsafe.Sizeof`（§13.1）。

由于它们的值在编译时已知，常量表达式可以出现在类型中，具体来说是作为数组类型的长度：

```
const IPv4Len = 4

// parseIPv4 解析一个 IPv4 地址 (d.d.d.d)。
func parseIPv4(s string) IP {
    var p [IPv4Len]byte
    // ...
}
```

常量声明可以同时指定类型和值，但在没有显式类型的情况下，类型将从右侧的表达式推断得出。在下面的代码中，`time.Duration` 是一个底层类型为 `int64` 的命名类型，而 `time.Minute` 是该类型的常量。因此，下面声明的两个常量也都具有 `time.Duration` 类型，正如 `%T` 所揭示的那样：

```
const noDelay time.Duration = 0
const timeout = 5 * time.Minute
fmt.Printf("%T %[1]v\n", noDelay)     // "time.Duration 0"
fmt.Printf("%T %[1]v\n", timeout)     // "time.Duration 5m0s"
fmt.Printf("%T %[1]v\n", time.Minute) // "time.Duration 1m0s"
```

当一组常量作为一组声明时，除第一个外，其余的右侧表达式可以省略，这意味着再次使用前面的表达式及其类型。例如：

```
const (
    a = 1
    b
    c = 2
    d
)

fmt.Println(a, b, c, d) // "1 1 2 2"
```

如果隐式复制的右侧表达式总是求值为相同的东西，这不是很有用。但如果它可以变化呢？这就引出了 `iota`。

### 3.6.1 常量生成器 `iota`

`const` 声明可以使用*常量生成器* `iota`，它用于创建一系列相关的值，而无需显式地拼写每一个。在 `const` 声明中，`iota` 的值从零开始，并在序列中的每一项增加一。

这是来自 `time` 包的一个示例，它定义了类型为 `Weekday` 的命名常量来表示一周中的每一天，从零代表 `Sunday` 开始。这类类型通常称为*枚举*，简称 *enums*。

```
type Weekday int

const (
    Sunday Weekday = iota
    Monday
    Tuesday
    Wednesday
    Thursday
    Friday
    Saturday
)
```

这声明了 `Sunday` 为 0，`Monday` 为 1，依此类推。

我们也可以在更复杂的表达式中使用 `iota`，如这个来自 `net` 包的示例，其中无符号整数的最低 5 位中的每一位都被赋予了一个独特的名称和布尔解释：

```
type Flags uint

const (
    FlagUp Flags = 1 << iota // is up
    FlagBroadcast            // supports broadcast access capability
    FlagLoopback             // is a loopback interface
    FlagPointToPoint         // belongs to a point-to-point link
    FlagMulticast            // supports multicast access capability
)
```

随着 `iota` 的增加，每个常量被赋予 `1 << iota` 的值，其结果为连续的 2 的幂，每个对应单个位。我们可以在测试、设置或清除一个或多个这些位的函数中使用这些常量：

gopl.io/ch3/netflag
