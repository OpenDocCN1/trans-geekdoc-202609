### 身份验证与授权
为了使用 ML 流水线/ML 模型，我们将使用 `OAuth` 或 `JWT` 实现身份验证，以确保 API 访问的安全。如果没有授权，将无法访问 API 端点。要获取预测结果，需要使用密钥传递加密后的令牌，一旦收到请求，将使用相同的密钥对令牌进行解密。如果内容匹配，则将完成身份验证并提供预测响应。

```python
import jwt
from flask import request, jsonify

# JWT 的密钥密钥
SECRET_KEY = 'secret_key'

def token_required(f):
    def decorator(*args, **kwargs):
        token = request.headers.get('Authorization')
        if not token:
            return jsonify({'message': 'Token is missing!'}), 403
        try:
            jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
        except:
            return jsonify({'message': 'Token is invalid!'}), 403
        return f(*args, **kwargs)
    return decorator

@app.route('/predict', methods=['POST'])
@token_required
def predict():
    data = request.json
    features = np.array([data['amount'], data['transaction_frequency'], data['average_transaction_amount']]).reshape(1, -1)
    prediction = model.predict(features)
    return jsonify({'is_fraud': int(prediction[0])})

if __name__ == '__main__':
    app.run(debug=True)
```
