## 19.2 无监督特征学习与深度生成模型

在第 18 章中，我们的重点是通过神经网络架构进行**监督学习**。机器学习的另一个主要方向是**无监督学习**，在这种学习中，必须从输入数据中“学习”并揭示隐藏的潜在依赖关系和结构。聚类，正如第 12 章所介绍的（另见 [181] 以获取详尽介绍），是通过无标签数据进行学习的主要途径。另一条途径是学习显式的概率依赖关系，其最终目标是估计概率分布，这正是第 15 章和第 16 章的重点。

另一个无标签样本至关重要的方向是学习输入数据的高效表示。事实上，特征学习是数据表示的一个侧面。`CNN` 中位于全连接网络部分之前的卷积层专门用于实现这一目标，即获得输入数据的高效且信息丰富的表示。然而，在 `CNN` 的框架内，这是在特定学习任务的背景下进行的；也就是说，训练过程中也会考虑输出标签，以达到服务于当前任务需求的最优表示。

在本节中，讨论的背景是学习独立于特定目标任务的表示；目标是仅利用输入数据提取此类信息。这种关注的原因有两方面。首先，学习输入数据的模型表示随后可用于不同的任务，以促进训练。有时，这也被称为 `pretraining`（预训练），即利用无标签数据学习的参数可作为另一个监督学习参数的初始估计。当标记样本的数量不够大时，这很有用（例如，参见 [125] 的讨论）。值得注意的是，这种预训练原理具有历史意义，因为它导致了神经网络的复兴，稍后将对此进行讨论 [80]。

目前备受关注的另一条途径是利用此类学习到的表示来 `generate`（生成）新数据；回顾第 18.7 节的讨论。此类技术 `not`（不）一定要 `explicitly`（显式地）学习底层概率分布，但它们获取了必要的知识，从而能够根据“解释”数据的分布来抽取样本。

### 19.2.1 受限玻尔兹曼机

`restricted Boltzmann machine`（受限玻尔兹曼机，`RBM`）是玻尔兹曼机这一更一般类别的一种特殊类型，后者在第 15 章 [1,167] 中已介绍。图 19.1 展示了对应于 `RBM` 的概率图模型。同一层的节点之间没有连接。此外，上层包含对应隐变量的节点，下层由可见节点组成。也就是说，观测值仅施加于下层节点。深度 `RBM` 可以通过将一个 `RBM` 堆叠在另一个之上来构建。

![Figure 19.1 An RBM is an undirected graphical model with no connections among nodes of the same layer. The lower level comprises visible nodes and the upper layer consists of hidden nodes only.](img/gr001.jpg)

图 19.1 `RBM` 是一种无向图模型，同一层的节点之间没有连接。下层包含可见节点，上层仅包含隐节点。

遵循玻尔兹曼机的一般定义，所涉及随机变量的联合分布形式为

```
P(v_1,...,v_J,h_1,...,h_I) = 1/Z exp( - E(v,h) )
```

其中，我们对 `J` 个可见（`v[j]`，`j` = 1, 2, ..., `J`）和 `I` 个隐（`h[i]`，`i` = 1, 2, ..., `I`）随机变量使用了不同的符号。`energy`（能量）是用一组未知参数来定义的。^(¹²⁷)

能量函数定义为：

$$E(\mathbf{v},\mathbf{h}) = - \sum\limits_{i = 1}^{I}\sum\limits_{j = 1}^{J}\theta_{ij}h_{i}v_{j} - \sum\limits_{i = 1}^{I}b_{i}h_{i} - \sum\limits_{j = 1}^{J}c_{j}v_{j}.$$

![Equation](img/si4.png) (19.2)

归一化常数计算如下：

$$Z = \sum\limits_{\mathbf{v}}\sum\limits_{\mathbf{h}}\exp\left( - E(\mathbf{v},\mathbf{h}) \right).$$

![Equation](img/si5.png) (19.3)

我们将重点关注离散变量；因此涉及的分布为概率。更具体地说，我们将关注二元性质的随机变量，即 `v[j]`、`h[i]` ∈ {0, 1}，`j` = 1, …, `J`，`i` = 1, …, `I`。

![Equation](img/si6.png)

从公式 (19.2) 可以看出，与一般的玻尔兹曼机相反，能量项中仅存在隐变量和显变量之间的乘积。

训练 `RBM` 的目标是学习未知参数集 `θ[i j]`、`b[i]`、`c[j]`，它们将分别统称为 **Θ**、**b** 和 **c**。实现这一目的的主要途径是利用显变量的 `N` 个观测值（记为 **v[n]**，`n` = 1, 2, …, `N`）来最大化对数似然。

![Equation](img/si8.png)

其中

**v[n]** := \[`v[1n]`, …, `v[Jn]`\]^(`T`)

![Equation](img/si9.png)

是时刻 `n` 对应观测值的向量。我们将说显节点被*钳制*在相应的观测值上。相应的（平均）对数似然由下式给出

$L(\Theta,\mathbf{b},\mathbf{c}) = \frac{1}{N}\sum\limits_{n = 1}^{N}\ln P(\mathbf{v}_{n};\Theta,\mathbf{b},\mathbf{c}) = \frac{1}{N}\sum\limits_{n = 1}^{N}\ln\left( \frac{1}{Z}\sum\limits_{\mathbf{h}}\exp\left( - E(\mathbf{v}_{n},\mathbf{h};\Theta,\mathbf{b},\mathbf{c}) \right) \right) = \frac{1}{N}\sum\limits_{n = 1}^{N}\ln\left( \sum\limits_{\mathbf{h}}\exp\left( - E(\mathbf{v}_{n},\mathbf{h};\Theta,\mathbf{b},\mathbf{c}) \right) \right) - \ln\sum\limits_{\mathbf{v}}\sum\limits_{\mathbf{h}}\exp\left( - E(\mathbf{v},\mathbf{h}) \right),$

其中，能量函数中的索引 $n$ 指的是可见节点被钳制到的相应观测值，并且 $\Theta,\mathbf{b},\mathbf{c}$ 已显式地引入符号表示中。

对 $L(\Theta,\mathbf{b},\mathbf{c})$ 关于 $\theta[i j]$ 求导（关于 $b[i]$ 和 $c[j]$ 的导数情况类似）并应用导数的标准性质，不难证明（问题 19.1）可得

![Equation](img/fx001.jpg) (19.4)

其中用到了以下内容：

#### 公式推导

$$

P(\mathbf{h}|\mathbf{v}) = \frac{P(\mathbf{v},\mathbf{h})}{\sum_{\mathbf{h}^{\prime}}P(\mathbf{v},\mathbf{h}^{\prime})}.

$$

![Equation](img/si16.png)

公式 (19.4) 中的梯度包含两项。第一项可在 *P*(**h**|**v**) 可用后一次性计算。基本上，该项是 `RBM` 在钳制相位下运行时的平均**发放率**或**相关性**；通常我们称之为**正相位**，记作 <*h*[*i*]*v*[*j*]\>^+。第二项是 `RBM` 在所谓的**自由运行**或**负相位**下工作时的相应相关性，记作 <*h*[*i*]*v*[*j*]\>^−。因此，用于最大化对数似然的梯度上升方案形式如下：

```
θi j = θi j + μ(<h[i]v[j]>^+ − <h[i]v[j]>^−)
```

![Equation](img/si20.png)

让我们花一点时间来证明为什么将这两个运行阶段分别命名为正相位和负相位。这些术语出现在 Hinton 和 Sejnowski 关于玻尔兹曼机的开创性论文 [77,78] 中。第一个阶段对应钳制条件，可视为一种**赫布**学习规则。Hebb 是一位神经生物学家，他提出了第一个（就我所知）学习规则 [74]：“如果突触两侧的两个神经元同时被激活，该突触的强度会有选择地增加。”请注意，这正是正相位相关性在参数更新递归中的效果。相反，负相位相关项的效果截然相反。因此，后一项可被视为**遗忘**或**反学习**贡献；它可被视为一种纯粹“内部”性质的控制条件（注意它不依赖于观测值），相较于从环境（观测值）接收的“外部”信息。

关于对数似然优化的细节以及最终推导出的算法，可从本书网站“Additional Material”部分获取，该部分与当前章节相关联。

### 19.2.2 深度前馈网络的预训练

本小节阐述了利用 `RBM` 预训练深度前馈神经网络的基本原理。这一概念首次见于文献 [80]。尽管这种预训练方式不再广泛使用，但在标注数据不足以训练大型神经网络的情况下，它仍能提供优势。

图 19.2 展示了一个具有三个隐藏层的神经网络的框图。输入随机变量的向量表示为 `x`，与隐藏层相关的向量表示为 `h^(i)`，`i = 1, 2, 3`。输出节点的向量表示为 `y`。预训练按顺序逐层进行，从连接输入节点与第一隐藏层节点的权重开始。这可以通过最大化观测到的输入观测样本 `x` 的似然概率来实现，并将与第一层相关的变量视为隐藏变量。一旦计算出对应第一层的权重，相应的节点就被允许激活输出值，并形成一个值向量 `h¹`。这就是为什么在无监督预训练中采用生成模型（如 `RBM`）的原因，以便能够*以概率方式*在隐藏节点生成输出。这些值随后被用作下一个隐藏层预训练的观测值，以此类推。

![图 19.2 具有三个隐藏层和一个输出层的神经网络架构框图。输入层处输入随机变量的向量表示为 x。第 i 个隐藏层节点相关变量的向量表示为 hi，i = 1,2,3。输出变量表示为 y。在预训练的每个阶段，与一个隐藏层相关的权重被一次计算。对于图中包含三个隐藏层的网络，预训练包含三个无监督学习阶段。一旦隐藏单元的预训练完成，与输出节点相关的权重将通过监督学习算法进行预训练。在最终的微调期间，所有参数通过监督学习规则（如反向传播方案）进行估计，使用预训练期间获得的值作为初始值。](img/gr002.jpg)

图 19.2 具有三个隐藏层和一个输出层的神经网络架构框图。输入层处输入随机变量的向量表示为 `x`。第 `i` 个隐藏层节点相关变量的向量表示为 `h^(i)`，`i = 1,2,3`。输出变量表示为 `y`。在预训练的每个阶段，与一个隐藏层相关的权重被一次计算。对于图中包含三个隐藏层的网络，预训练包含三个无监督学习阶段。一旦隐藏单元的预训练完成，与输出节点相关的权重将通过监督学习算法进行预训练。在最终的微调期间，所有参数通过监督学习规则（如反向传播方案）进行估计，使用预训练期间获得的值作为初始值。

预训练完成后，随后采用监督学习规则（如反向传播）来获得通向输出节点的权重值，并微调与隐藏层相关的权重，使用预训练阶段获得的值作为初始权重值。
