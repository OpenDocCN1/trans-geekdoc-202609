
## 相似性计算

系统确定学生或课程之间的相似性。根据他们的活动，对于学生-学生 CF，它确定学生之间彼此的相似程度；对于课程-课程 CF，它根据 CF 行为数据检测相似的课程。

对于课程-课程 CF，系统识别与目标学生已交互过的类似的课程。在学生-学生 CF 中，它推荐与目标学生相似的学生高度评价或喜欢的课程。

## 协同过滤技术

使用诸如用户-物品矩阵分解、基于用户或基于物品的 CF，或更先进的方法，如带有奇异值分解（SVD）的矩阵分解、`SVD++` 或用于矩阵分解的交替最小二乘法。它实现了处理稀疏性以及应对新用户或新物品的技术。

## 5.2.4 混合方法

混合 RS 结合了各种推荐技术来生成输出。将混合 RS 与 CF 和 CB 系统比较时，混合系统通常表现出更高的推荐准确性。这归因于 CF 中缺乏关于领域依赖的信息，而 CB 系统中缺乏用户偏好信息。这两种方法的融合导致了共享知识的增强，从而提高了推荐的质量。这种知识增强使得探索将底层 CF 算法与内容数据以及 CB 算法与用户行为数据相结合的新方法特别有前景 [2, 61]。图 5.5 展示了 MOOC 课程推荐的混合推荐方法示例。该方法结合了基于 CF 和 CB 的技术，根据学生的兴趣向学习者推荐课程。

## 5.3 推荐系统的评估指标

RS 准确性通常通过三个主要指标进行评估 [62]。

### 5.3.1 平均绝对误差 (MAE)

MAE 是一种广泛用于计算推荐器预测的指标。MAE 使用以下公式计算（见公式 5.1）：

```
MAE = \frac{1}{\left| \hat{R} \right|}\sum\limits_{\hat{r}_{Sc}} \in \hat{R}}\left| r_{Sc} - \hat{r}_{Sc} \right|
```

考虑与 RMSE 相同的 RS。使用真实和预测评分计算 MAE@10。

```
MAE@10 = \frac{(0.2 + 0.1 + 0.2 + 0.1 + 0.2 + 0.1 + 0.2 + 0.2 + 0.1 + 0.2)}{10}
```

在这种情况下，MAE@10 为 0.14 意味着在前 10 个推荐中，预测评分与真实评分之间的平均偏差为 0.14。较低的 MAE 表示推荐平均接近真实评分，这表明模型的预测更准确。

### 5.3.2 均方误差 (MSE)

MSE 衡量统计模型的误差。它评估观测值与预测值之间的平均平方差。当模型没有误差时，MSE 等于零。随着模型误差增加，其值也会增大。MSE 也称为均方（公式 5.2）。

```
MSE = \frac{1}{\left| \hat{R} \right|}\sum\limits_{\hat{r}_{Sc}} \in \hat{R}}\left( r_{Sc} - \hat{r}_{Sc} \right)^{2}
```

假设我们有一组五个真实评分及其对应的预测评分。表 5.1 列出了真实评分和预测评分。

**TABLE 5.1** top@5 真实评分与预测评分示例

| S.NO# | 真实评分 | 预测评分 |
| --- | --- | --- |
| 1. | 4.0 | 3.8 |
| 2. | 5.0 | 4.9 |
| 3. | 3.0 | 3.2 |
| 4. | 4.5 | 4.4 |
| 5. | 2.0 | 1.8 |

计算每个预测评分与真实评分之间的平方差：

- 第一个评分：`(3.8−4.0)² = 0.04`
- 第二个评分：`(4.9−5.0)² = 0.01`
- 第三个评分：`(3.2−3.0)² = 0.04`
- 第四个评分：`(4.4−4.5)² = 0.01`
- 第五个评分：`(1.8−2.0)² = 0.04`

$$\text{MSE}@5 = \frac{0.04 + 0.01 + 0.04 + 0.01 + 0.04}{5} = \frac{0.14}{5} = 0.028$$

该示例的 MSE 为 0.028。此值代表预测评分与真实评分之间平方差的平均值，表明推荐系统（RS）的预测与用户实际偏好的匹配程度。MSE 越低，表示预测准确性越高。

### 5.3.3 均根误差 (RMSE)

RMSE 衡量统计模型预测值与实际值之间的平均差异。在数学上，它是残差的标准差，如公式 5.3 所示。

$$RMSE = \sqrt{\frac{1}{\left| \hat{R} \right|}}\sum\limits_{\hat{r_{Sc}} \in \hat{R}}\left( {r_{Sc} - {\hat{r}_{Sc}} \right)^{2}}$$

其中，符号 $\hat{R}$ 表示预测评分集合，`r[Sc]` 表示学生 `S` 对课程 `c` 的真实评分，$\hat{r}[Sc]$ 表示学生 `S` 对课程 `c` 的估计评分。

假设我们有一个向学生推荐 10 门课程的模型，并且想要计算 RMSE@10。以下是如表 5.2 所示的前 10 项推荐的真实评分和预测评分：

**表 5.2** top@10 真实评分与预测评分示例

| S.N0# | 真实评分 | 预测评分 |
| --- | --- | --- |
| 1. | 4.0 | 3.8 |
| 2. | 5.0 | 4.9 |
| 3. | 3.0 | 3.2 |
| 4. | 4.5 | 4.4 |
| 5. | 2.0 | 1.8 |
| 6. | 4.0 | 4.1 |
| 7. | 4.5 | 4.7 |
| 8. | 3.5 | 3.3 |
| 9. | 3.0 | 2.9 |
| 10. | 5.0 | 4.8 |

$$RMSE@10 = \sqrt{\frac{1}{10}\sum\limits_{i = 1}^{10}\begin{matrix} \begin{array}{l} {\left( {3.8 - 4.0} \right)^{2}},\left( {4.9 - 5.0} \right)^{\text{2}},\left( {3.2 - 3.0} \right)^{\text{2}},} \\\\ {\left( {4.4 - 4.5} \right)^{\text{2}},\left( {1.8 - 2.0} \right)^{\text{2}},\left( {4.1 - 4.0} \right)^{\text{2}},} \\\\ \end{array} \\\\ {\left( {4.7 - 4.5} \right)^{\text{2}},\left( {3.3 - 3.5} \right)^{\text{2}},\left( {2.9 - 3.0} \right)^{\text{2}},\left( {4.8 - 5.0} \right)^{\text{2}}} \\\\ \end{matrix}}$$

$$RMSE@10 = \sqrt{\frac{1}{10}\left( {0.04 + 0.01 + 0.04 + 0.01 + 0.04 + 0.01 + 0.04 + 0.04 + 0.01 + 0.04} \right)}$$

$RMSE@10 = \sqrt{\frac{0.28}{10}}$ = $\sqrt{0.028}$ ≈ 0.167

RMSE 是与 MAE 类似的指标，但它考虑了差异的平方，这会对较大的误差进行更重的惩罚。

约为 0.167 的 RMSE 意味着前 10 项推荐的预测评分与真实评分之间的平均平方差约为 0.167 个。与 MAE 类似，较低的 RMSE 也意味着推荐在平均上更接近真实评分，误差更小。

## 5.4 启示与未来方向

推荐系统的主要目标是为用户提供项目推荐，而为个人量身定制这些建议是一项重大挑战。传统的推荐系统旨在提供推荐，但为个人量身定制这些建议面临着巨大的挑战。
