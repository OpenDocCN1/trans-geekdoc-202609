
我们已经讨论了波利亚 urn 模型及相关的 CRP。*棒断表示法* 是 DP 的另一种表示方法，由文献 \[77\] 开发。该方法基于公式 (13.113)，并提出了生成 `P[i]` 以及 `θ[i]` 相应值的步骤，`i = 1, 2, …`。

考虑一根单位长度的棍子（图 13.16）。根据以下算法，该棍子被分割成一系列无限多个长度为 `P[i]`（`i = 1, 2, …`）的片段。首先，从 Beta 分布（第 2 章）中抽取一个随机变量，`β[1] ∼ Beta(β|1, α)`，并折断一段长度等于 `β[1]` 的片段；我们令 `P[1] = β[1]`。剩余片段的长度为 `1 − β[1]`。然后进行另一次抽取，`β[2] ∼ Beta(β|1, α)`，并按比例 `β[2]` 折断另一段。因此，被丢弃片段的长度等于 `β[2]`，我们令 `P[2]` 等于其长度。剩余片段的长度显然为 `(1 − β[1]) − β[2] = (1 − β[1])(1 − β[2])`。遵循这一逻辑递归地从剩余片段上折断，并从 `P[1] = β[1] ∼ Beta(β|1, α)` 开始，算法的第 `i` 步为

```
P[i] = β[i] ∏_{j=1}^{i-1} (1 − β[j]),  β[i] ∼ Beta(β|1, α)
```

利用由此产生的概率值序列 `P[i]`，根据公式 (13.113) 形成一个随机分布，其中 `θ[i]` 从 `G[0]` 中独立同分布地抽取。可以证明，由此产生的分布是一个 DP，即 `G ∼ DP(α, G[0])`。

![图 13.16 DP 的断棍构造。在每次迭代中，我们从 Beta 分布 `Beta(β|1,α)` 中采样，并按采样值的比例从剩余片段上折断一段。](img/gr016.jpg)

图 13.16 DP 的断棍构造。在每次迭代中，我们从 Beta 分布 `Beta(β|1,α)` 中采样，并按采样值的比例从剩余片段上折断一段。

请注意，随着 `i` 的增加，概率值会减小，因为剩余的棍子片段变得越来越小。因此，在公式 (13.113) 的无限可能项中，只有相对较少数量的项具有显著贡献而得以保留。此外，与这些保留项相关的概率值是最先生成的，这在实现 DP 以生成先验时（参见，例如 [60]）在实践中非常重要。

关于 DP 的简明教程也可在 [19] 中找到。那里还提供了一些公开可用的软件工具网站。

### 13.11.4 狄利克雷过程混合建模

在确立了 DP 的离散性和聚类特性之后，现在让我们看看如何将其用作先验，以对混合分布进行贝叶斯学习，例如高斯混合建模。我们的框架将是非参数设置；也就是说，混合成分的数量*不是*先验固定的。这迫使我们用*分布上的先验*来替代固定数量参数上的先验。一旦获得观测值，贝叶斯学习原理提供了将先前的*先验*信息更新为与*后验*分布相关信息的工具。

假设我们得到一组观测值，`x[n] ∈ ℝ^(l)`，`n = 1, 2, …, N`。我们假设它们中的每一个都是由相应的概率密度函数（分布）发射的，该函数由一组相应的隐变量参数化，`θ[1], θ[2], …, θ[N] ∈ Θ`。即，`x[n] ∼ p(x|θ[n])`。请注意，参数集合随着 `N` 的增长而增长，这与第 13.4 节混合建模中使用的固定数量参数形成对比。反过来，我们假设这些参数是从一个分布 `G` 中独立同分布（i.i.d.）抽取的，而 `G` 本身则是从一个 DP 中抽取的（参见，例如 [3]）。总之，根据该混合模型的数据生成过程描述如下：

![](img/fx019.jpg)

请注意，由于 `G` 是离散的且具有很强的聚类结构，许多观测样本 `x[n]` 将共享相同的隐参数，这就是 DP 先验施加混合建模的方式。

如果采用棒打破构造，上述三个基本步骤将被“重述”，数据生成机制描述如下：

1.  抽取 Beta 变量，`β[i] ∼ Beta(β|1, α)`，`i = 1, 2, …`。

2.  生成概率值，`P_i = β_i ∏_{j=1}^{i-1} (1 - β_j)`，`i = 2, 3, …`，其中 `P_1 = β_1`。

3.  从基分布中抽取相应的参数，`θ[i] ∼ G_0`，`i = 1, 2, …`。

4.  对于所有观测值 `x[n]`，`n = 1, 2, …, N`，执行：

    *   `k[n] ∼ Cat(P_1, P_2, …)`。

#### 推断

推断任务包括在给定观测值以及与潜在变量相关的先验函数形式以及涉及的（隐藏）随机（非确定性）参数的情况下，获得后验概率。在第 13.4 节中，选定的先验分别是用于均值的高斯分布和用于协方差矩阵的 Wishart 概率密度函数。正如该节末尾所评论的，概率也可以被视为随机变量，并采用狄利克雷分布作为相应的先验。

在当前设定中，由于混合数 `K` 不是预先选定的，我们将采用 DP 混合过程模型作为先验。在这种建模下，涉及以下潜在变量：

*   变量 `β[i]`，它们与概率 `P[i]` 的计算相关，`i = 1, 2, …`。

*   随机向量 `θ[i]`，它们用于在输入空间中“放置”预选的概率密度函数形式，该函数“发射”观测值 `p(x|θ)`。通常，选择该概率密度函数的函数形式是为了使其与基分布 `G[0]` 形成共轭对。

*   簇分配潜在变量 `k[n]`，`n = 1, 2, …, N`，也称为指示变量。如前所述，有时指示变量写作独热向量 `k[n]`，所有分量均为 0，除了指示第 `n` 个变量关联的混合成分编号的那个位置，其值被设为 1。

在后验的学习阶段，必须估计 (a) Beta 分布的参数 `α` 以及 (b) 定义 `G[0]` 和 `p(·|·)` 的参数。如前所述，在实践中，假设对于预选的 `T` 值，有 `P[i] = 0`，`i > T`。这被称为*截断断棒*表示。毕竟，最多只能有 `N` 个混合成分，即数据点的数量。在最坏情况下，每个点属于不同的簇。此外，我们知道簇的平均数量按 `O(α ln N)` 增长。

正如所述，通常保持在指数族范围内。用文字表述，这意味着我们为 DP 模型中涉及的 PDF 选择以下形式。

*   **对于观测值的发射 PDF**，

    `p(x|θ) = g(θ)f(x)exp(θ^(T)x)`,

    其中我们使用了第 12.8 节中定义的指数族标准形式。

*   **DP 的基分布**选择为相应的共轭函数，

    `G0 = h(λ, v)(g(θ))^(λ)exp(θ^(T)v)`。

*   除了 `α` 之外，学习过程中需要学习的参数是 `λ` 和 `v`。

我们现在准备好定义任务了。将所有随机变量收集在一起，我们形成相应的矩阵，

`W := [β, Θ, k]`，

其中 `β` 是包含所有棍棒长度的向量，`Θ` 是包含所有向量 `θ[i]`（`i = 1, 2, …, T`）的矩阵，因为我们使用截断棍棒打破表示法，而 `k` 是指示变量的 `N` 维向量。

推理任务的目标是估计联合后验 `p(W|X)`，其中 `X` 是观测值的集合，`X = {x[1], x[2], …, x[N]}`。然而，计算 `p(W|X)` 证明是难以处理的。克服相关困难的一种方法是求助于均场近似（第 13.2 节）。为此，采用了以下用于后验分布变分近似的**因子分解**族：

$$q(W) := q(\boldsymbol{\beta}, \Theta, \mathbf{k}) = \prod_{i=1}^{T-1} q_{\boldsymbol{\gamma}_i}(\beta_i) \prod_{i=1}^{T} q_{\mathbf{r}_i}(\boldsymbol{\theta}_i) \prod_{n=1}^{N} q_{\boldsymbol{\phi}_n}(k_n).$$

![Equation](img/si519.png) (13.123)

请注意，`θ[i]` 的后验 PDF 估计由变分参数 `r[i]` 控制，且属于指数族，如前所述。指示变量的后验估计被选为具有变分参数 `ϕ[n]` 的多项分布（分类分布）。Beta 变量的后验估计被选为具有变分参数 `γ[i]` 的 Beta 分布。请注意，第一个乘积包含 `T - 1` 个因子。这是由于截断以及概率之和为一的事实。这必然导致 `β[T] = 1`，因此 `q(β[T]) = 1`（问题 13.21）。

下一步是通过最大化不等式 (12.68) 中的下界来学习上述后验分布以及所涉及的参数，在我们的情况下，这变为

$$

\ln p(\mathcal{X}; \boldsymbol{\xi}) \ge \mathcal{F}(q; \boldsymbol{\xi}) = \mathbb{E}_q \left[ \ln p(W, \mathcal{X}; \boldsymbol{\xi}) \right] - \mathbb{E}_q \left[ \ln q(W) \right],

$$

![Equation](img/si527.png)

且 `ξ = [α, λ, v^(T)]^(T)`。最大化下界的算法完全遵循第 13.2 节中确立的基本原理和步骤。请注意，关于 `q` 的最大化是通过相应的变分参数进行的，这些参数定义于公式 (13.123) 中。算法细节可参见文献 [11]；另见文献 [38]。参数 `ξ` 在算法的 M 步中计算得出。另一种选择是假设参数本身也是随机实体，在这种情况下必须采用特定的先验。一旦学习阶段结束，根据训练得到的后验 `q(k[n])` 执行混合成分分配。

学习后验的另一种途径是通过蒙特卡洛采样技术，将在第 14 章中讨论。对于此类情况，CPR 模型特别适合吉布斯采样（第 14.9 节）；例如参见文献 [56]。

### 13.11.5 印度自助餐过程

我们已经讨论了 DP 的促进聚类特性，该特性在混合建模任务的背景下得到了利用。CRP 和棒打破构造是将 DP 表示为先验并在实践中实现的两条途径。

现在我们将注意力转向另一个任务，它与混合建模有着密切的亲和力。回想一下，混合建模通过将观测值分组分配给同一个混合成分，从而*在观测值上施加了一种结构*。在当前小节中，将施加另一种类型的结构。

当前任务的核心在于这样一个假设：观测值通过一组堆叠在一起形成向量的未观测*潜在*变量来*控制*，这些向量被称为特征向量。该模型的基本假设是：可用的观测值是未知潜在变量集合的*线性组合*，即

`x[n] = A z[n], x[n] ∈ ℝ^(l), z[n] ∈ ℝ^(K), n = 1, 2, …, N.`

![Equation](img/si533.png)

根据 `l` 和 `K` 的相对大小，我们用不同的名称来称呼该任务。例如，如果 `K < l`，我们称之为*降维*，因为描述 `l` 维观测值所需的变量更少。

将所有观测值汇总在一起，前面的方程可以写为

`X = AZ, X ∈ ℝ^(l×N), Z ∈ ℝ^(K×N)`

![Equation](img/si535.png) (13.124)

其中 `X = [x[1], …, x[N]]`, `Z = [z[1], …, z[N]]`。任务是在给定矩阵 `X` 的情况下计算 `A` 和 `Z`。通常，该问题存在无穷多解。在实践中，必须引入进一步的假设来限制可能的解集。第 20 章讨论了若干此类外部约束。根据施加的条件不同，该任务会被赋予不同的名称。在本小节中，我们将通过非参数贝叶斯论证来处理该任务，并将施加一个先验，它将充当额外的“某种东西”，使任务定义明确。

增加的难度在于潜变量的数量 `K` 并非先验已知。^(¹⁰²)

由于稀疏性在我们的讨论中至关重要，我们将假设 `Z` 由零和一组成。在进一步讨论之前，让我们详细阐述一下零元素的含义。以 `N = 5` 和 `K = 3` 的情况为例，并令矩阵中的某些元素为零。则公式 (13.124) 中的矩阵分解采取以下形式

```
[x₁, x₂, …, x₅] = [a₁, a₂, a₃] [z₁₁ z₁₂ z₁₃ 0 z₁₅; z₂₁ 0 0 z₂₄ z₂₅; 0 z₃₂ z₃₃ z₃₄ 0].
```

![Equation](img/si541.png)

上式意味着

#### 无限二进制矩阵先验的搜索

`x[1] = z[11]a[1] + z[21]a[2], x[5] = z[15]a[1] + z[25]a[2]`

`x[2] = z[12]a[1] + z[32]a[3], x[3] = z[13]a[1] + z[33]a[3]`

`x[4] = z[24]a[2] + z[34]a[3]`

稍加思考即可意识到，`Z` 中零元素的存在给观测值施加了一种结构。确实，`x[1]` 和 `x[5]` 位于同一个子空间中，由 `a[1]` 和 `a[2]` 张成。观测值 `x[2]` 和 `x[3]` 位于由 `a[1]` 和 `a[3]` 张成的子空间中，这与前一个子空间不同。也就是说，零元素的存在给输入数据施加了一种*聚类*结构。

因此，我们的出发点是选择一个促进 `Z` 上出现零元素的先验。此外，我们将假设 `Z` 的元素要么是 1 要么是 0，即 `z[kn] ∈ {0, 1}`，`k = 1, 2, …, K`，`n = 1, 2, …, N`。这种简化处理将揭示该方法背后的奥秘。稍后，可以推广到更实用的场景，即非零值可以取实数值。例如，可以写成 `Z′ = Z ∘ B`，其中 `∘` 表示逐元素乘法，然后在 `B` 的值上施加一个额外的先验。

我们正在寻找的先验背后的“魔法词汇”是：“它应该在数据上施加一种聚类结构。”尽管这也是混合建模的目标，但这里的问题截然不同。

*   **混合建模**：每个观测值属于（由其发射）单个混合成分。底层结构源于将观测值归入若干不同的混合成分中。被分配到同一混合成分的观测值比被分配到不同簇的观测值更“相似”。

*   **矩阵分解**：每个观测值都表示为矩阵 `A` 的若干列的线性组合。也就是说，每个观测向量都与 `A` 的若干列相关联。通过将与 `A` 的*相同*列相关联的观测值归集在一起，建立了观测值之间的相似性。

*   用略有不同的术语来说，`A` 的列被称为*特征*，如果两个观测向量由相同的列组合给出，我们就说它们*共享*相同的特征。如果 `z[kn] = 1`，我们就说第 `k` 个特征存在于第 `n` 个观测值中。

对于固定的 `K` 值，令 `P[k]`，`k = 1, 2, …, K`，为任意 `n` 值下 `z[kn] = 1` 的概率。则我们可以写为

```
P(Z|P) = ∏_{k = 1}^{K} ∏_{n = 1}^{N} P(z_{kn}|P)
```

(13.128)

```
= ∏_{k = 1}^{K} P_{k}^{m_{k}} (1 - P_{k})^{N - m_{k}},
```

(13.129)

其中 `P = [P[1], …, P[K]]^(T)` 且 `m_{k} := ∑_{n = 1}^{N} z_{kn}`。也就是说，`m[k]` 是 `Z` 第 `k` 行中非零元素的个数；其物理解释是它计算共享第 `k` 个特征的观测值的数量。显然，为了使公式 (13.129) 成立，已假设所涉变量之间相互独立。

**为概率选择先验**：作为 `P[k]`，`k = 1, 2…, K` 的先验，我们采用 Beta 分布，即

```
P[k] ~ Beta(P|a, b).
```
