### 注销功能

当用户点击注销按钮时，会话将被销毁，用户重定向到 `index.php` 并提示 "Logged out successfully"。

**注销处理代码（位于各页面顶部公共区域）：**

```php
if (isset($_REQUEST['action']) && ($_REQUEST['action'] == 'logout')) {
    unset($_SESSION['name']);
    unset($_SESSION['username']);
    session_destroy();
    header("location:index.php?msg=Logged out successfully");
}
```
