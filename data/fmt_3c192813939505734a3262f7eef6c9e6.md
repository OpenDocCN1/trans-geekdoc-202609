
新城是该国商业活动的主要枢纽。在过去的几十年，随着全球化的不断加强，新城的商业活动变得日益激烈。与此同时，大量的人来到这座城市并定居，梦想着在生活中实现职业成长。作为一个显而易见的副作用，该城市的每个角落都启动了大量的住房项目。但对公寓的需求仍然超过了供应。为了从房地产行业的繁荣中获益，Karen 成立了一家数字市场代理机构，买卖房地产（包括公寓、独立住宅、镇屋等）。最初，当业务规模较小时，她会亲自与买家和卖家互动，帮助他们达成报价——无论是出售房产（针对卖家）还是购买房产（针对买家）。她在房地产领域的丰富经验帮助她对房产的准确报价产生了直觉——考虑到某些标准参数的值，例如房产的面积（平方米）、位置、楼层、购买年限、可用设施等。然而，随着业务的急剧增长，她面临着一个巨大的挑战。她无法独自管理所有的个人互动，也无法为所有房产设定准确报价。她聘佣了一名助理来管理客户互动。但由于助理是房地产行业的新手，在报价方面非常吃力。Karen 该如何解决这个问题呢？

幸运的是，Karen 有一个朋友叫 Frank，他是一个对机器学习模型有深入了解的数据科学家。Frank 为 Karen 提供了一个解决方案。他建立了一个模型，如果具有某些标准输入（如房产面积（平方米）、位置、楼层、购买年限、可用设施等），就可以预测房产的准确价值。哇，听起来就像是 Karen 本人在做工作一样！好奇 Frank 使用了什么模型吗？是的，你猜得对。他使用回归模型来解决 Karen 的房地产价格预测问题。

所以，我们刚刚讨论了一个可以使用回归解决的问题。同样，许多与其他数值预测相关的问题也可以用回归模型解决。在回归的背景下，因变量 `Y` 是需要预测其值的变量，例如在 Karen 的问题背景下，房地产的报价。该变量被认为与一个（假设为 `X`）或多个独立的自变量（称为预测变量）具有函数关系。在 Karen 的问题背景下，Frank 将房产面积、位置、楼层等作为他建立的模型的预测变量。换句话说，因变量取决于自变量或预测变量。回归本质上是寻找因变量 `Y` 与自变量 `X` 之间的关系（或关联性），即为关联性 `Y = f(X)` 寻找函数 `f`。

## 8.3 常见回归算法

常见的回归算法有：

* 简单线性回归
* 多元线性回归
* 多项式回归
* 多变量自适应回归样条
* 逻辑回归
* 最大似然估计（最小二乘法）

### 8.3.1 简单线性回归

正如名称所示，简单线性回归是最包含一个预测变量的最简单回归模型。该模型假设因变量与预测变量之间存在线性关系，如图 8.1 所示。

![images](img/217-1.png)

**图 8.1** 简单线性回归

在 Karen 的问题背景下，如果我们以“房产价格”作为因变量并将“房产面积（平方米）”作为预测变量，可以使用简单线性回归建立一个模型。

```
Price[Property] = f(Area[Property])
```

假设存在线性关联，我们可以将模型重新表述为

```
Price[Property] = a + b. Area[Property]
```

其中 `a` 和 `b` 分别是直线的截距和斜率。

回顾一下，直线可以用斜截形式 `Y = a + bX` 定义，其中 `a` 为截距，`b` 为斜率。截距的值表示当 `X = 0` 时 `Y` 的值。它被称为“Y 截距”，因为它指定了直线交叉垂直轴或 Y 轴的位置（参见图 8.1）。

### 8.3.1.1 简单回归模型的斜率

直线的斜率代表了图中垂直方向（Y 轴）的变化相对于水平方向（X 轴）的变化的程度，如图 8.2 所示。

```
Slope = Change in Y / Change in X
```

上升（Rise）是 Y 轴的变化（`Y[2] - Y[1]`），下降（Run）是 X 轴的变化（`X[2] - X[1]`）。因此，斜率表示所示：

### 8.3.1.2 简单回归中的误差

机器学习中的回归方程模型在算法中使用了上述斜率-截距格式。向机器提供 `X` 和 `Y` 的值，它通过关联 `X` 和 `Y` 的值来识别 `a`（截距）和 `b`（斜率）的值。然而，确定 `a` 和 `b` 值的精确匹配并不总是可能的。与之相关的将会存在某些误差值（`ε`）。这种误差被称为边际误差或残差误差。

`Y = (a + bX) + ε`

现在我们已经有了简单回归模型的背景知识，让我们尝试探索一个例子，清楚地理解如何为给定问题决定模型的参数（即 `a` 和 `b` 的值）。

### 8.3.2 多线性回归

在多元回归模型中，涉及两个或多个独立变量（即预测变量）。如果我们考虑到 Karen 问题的背景，在上一节中，我们通过将物业价格作为因变量，将面积（平方米）作为预测变量，得到了简单线性回归。然而，位置、楼层、购买年限、便利设施等也是重要的预测变量，不应被忽略。因此，如果我们把物业价格（美元）视为因变量，并将面积（平方米）、位置、楼层、购买年限和便利设施视为自变量，我们可以形成如下所示的多元回归方程：

`Price[Property] = f(Area[Property], location, floor, Ageing, Amenities)`

简单线性模型和多元回归模型假设因变量是连续的。

以下表达式描述了涉及两个预测变量（即 `X[1]` 和 `X[2]`）的方程。

`Ŷ = a + b[1]X[1] + b[2]X[2]`

该模型描述了 `Ŷ`、`X[1]` 和 `X[2]` 三维空间中的一个平面。参数 `a` 是该平面的截距。参数 `b[1]` 和 `b[2]` 被称为**部分回归系数**。参数 `b[1]` 代表在保持 `X[2]` 不变的情况下，`X[1]` 每变化一个单位时平均响应的变化。参数 `b[2]` 代表在保持 `X[1]` 不变的情况下，`X[2]` 每变化一个单位时平均响应的变化。

考虑以下具有两个预测变量（即 `X[1]` 和 `X[2]`）的多元线性回归模型（参见图 8.15）。

`Ŷ = 22 + 0.3*X[1] + 1.2*X[2]`

![images](img/228-1.png)

**图 8.15** 多元回归平面

当存在 `n` 个预测变量时，多元回归的估计方程如下：

`Ŷ = a + b[1]*X[1] + b[2]*X[2] + b[3]*X[3] + … + b[n]X[n]`

在寻找最佳拟线时，我们可以拟合多项式回归或曲线回归。这些分别被称为多项式回归或曲线回归。

### 8.3.3 回归分析中的假设

1. 因变量（`Y`）可以计算/预测为特定一组自变量（`X`）的线性函数加上误差项（`ε`）。
2. 观测值数量（`n`）大于待估计的参数数量（`k`），即 `n > k`。
3. 回归决定的关系仅是基于数据集的相关关系，而不一定是所定义类别的因果关系。
4. 回归线仅在有限的数据范围内有效。如果对线进行外推（超出外推范围），可能只会导致错误的预测。
5. 如果业务情况发生变化，且回归模型底的业务假设不再有效，那么过去数据集将无法预测未来的趋势。
6. 所有 `X` 值的方差均相同（同方差性）。
7. 误差项（`ε`）呈正态分布。这也意味着误差（`ε`）的均值的期望值为 0。
8. 误差（`ε`）的值是独立的，且与任何 `X` 值均无关。这意味着特定的 `X`、`Y` 值与另一个特定的 `X`、`Y` 值之间不存在关系。

给定上述假设，OLS 估计量是**最佳线性无偏估计量 (BLUE)**，这被称为**高斯-马尔可夫定理**。

### 8.3.4 回归分析中的主要问题

在多元回归中，有两个主要问题：多共线性和异方差性。

#### 8.3.4.1 多共线性

如果两个变量之间存在精确线性关系，则它们是完全共线的。多共线性是指相关程度不仅存在因变量和自变量之间，而且存在于自变量内部。当存在多共线性时，多元回归方程可以进行良好的预测，但我们很难确定如果每次改变一个自变量，因变量将如何变化。当存在多共线性时，会增加系数的标准误差。通过过度膨胀标准误差，多共线性试图让某些本应具有统计学显著性的变量在统计上变得不显著（实际上具有较低的标准误差）。衡量多共线性的一种方法是计算方差膨胀因子 (VIF)，它评估了如果预测变量相关，估计的回归系数的方差会增加多少。如果没有因素相互相关，VIF 将等于 1。

无完全共线性的假设是指自变量之间不存在精确的线性关系。这一假设意味着了关于自变量数据的两个方面：首先，除了与截距项相关的变量外，没有任何一个自变量可以是常数。其次，`X` 的变化是必要的。通常情况下，自变量的变化越多，OLS 估计量在识别不同自变量对因变量的影响方面表现得越好。

#### 8.3.4.2 异方差性

异方差性是指误差项方差的变化。如果误差项的方差在不同数据集之间不不变，将会产生错误的预测。通常，为了使回归方程做出准确的预测，误差项应该是独立且同分布（正态）分布的 (iid)。

### 8.3.5 提高线性回归模型的准确性

在探索如何改进之前，让我们理解回归中的偏差和方差。准确性是指估计接近真实值的程度，而预测是指值的连续估计。

* 高偏差 = 低准确性
* 高方差 = 低预测
* 低偏差 = 高准确性
* 低方差 = 高预测

假设我们有一个高准确且高预测的回归模型，因此整体误差将会很低，这意味着低偏差（高准确性）和低方差（高预测）。同样，我们可以说如果方差增加（低预测），数据的分布程度就会增加。随着偏差增加（低准确性），预测值与观测值之间的误差会增大。因此，平衡偏差和准确性至关重要。

在回归中，假设观测值数量（`n`）大于参数数量（`k`），即 `n > k`，在这种情况下，最小二法估计具有低方差，因此在测试观测上表现良好。

然而，如果观测值（`n`）并不比参数（`k`）大很多，那么最小二法可能会出现高变异性，导致过拟合并产生糟糕的预测。

如果 `k > n`，则线性回归不可用。这标志着方差无限，因此无法使用该方法。

可以使用以下三种方法提高线性回归的准确性：

1. 收缩方法
2. 子集选择
3. 维度（变量）归约

#### 8.3.5.1 收缩（正则化）方法

通过限制（收缩）估计的系数，我们可以尝试在以轻微增加偏差为代价的情况下减少方差。这反过来可以大幅提高模型的准确性。

这种方法涉及拟合包含所有预测变量的模型，但估计的系数相对于最小二法估计进行了收缩。这种收缩（也称为正则化）具有减少整体方差的效果。某些系数也可能被估计为零，从而间接地执行了变量选择。将回归系数向零收缩的两种最著名的技术是：

1. 岭回归
2. Lasso（最小绝对收缩选择算子）

岭回归执行 L2 正则化，即它添加了等于系数幅度平方和的惩罚。

岭回归的最小化目标 = `LS Obj + α × (系数平方和)`

岭回归（在最终模型中包含所有 `k` 个预测变量）与最小二法非常相似，不同之处在于系数是通过通过最小化一个略有不同的值来估计的。如果 `k > n`，则最小二法估计甚至没有唯一解，而岭回归可以通过通过微小的偏差增加来换取方差的大幅降低，仍然保持良好的性能。因此，岭回归在线最小二法估计具有高方差的情况下工作效果最好。岭回归的一个缺点是它会在最终模型中包含所有 `k` 个预测变量。这对于预测准确性可能不是问题，但在变量数量 `k` 较大的情况下，会给模型解释带来挑战。当响应是许多预测变量的函数且所有系数的大小大致相等时，岭回归的表现会更好。

Lasso 回归执行 L1 正则化，即它添加了等于系数幅度绝对值的惩罚。

Lasso 回归的最小化目标 = `LS Obj + α × (系数幅度的绝对值)`

`Lasso` 通过强制某些系数变为零值克服了这一缺点。我们可以说 Lasso 产生了稀疏模型（仅涉及子集），这些模型更简单且更具解释性。在少数预测变量具有显著系数，而其余预测变量的系数非常小或等于零的情况下，预计 Lasso 的表现会更好。

### 8.3.5.2 子集选择

识别一个假设与响应相关的预测变量子集，然后使用普通最小二乘法（OLS）在选定的简化变量子集上拟合模型。选择回归子集的方法有两种方法：

1. 最佳子集选择（考虑所有可能的 `(2^k)`）
