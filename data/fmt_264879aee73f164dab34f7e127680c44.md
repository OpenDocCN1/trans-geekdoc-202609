
# VAE 与 VAE-GAN 模型详解

## 5.1 VAE 系统架构与训练

VAE 系统的架构如图 5.1(A) 所示。一个批次中带有噪声的每条真实曲线均由编码器模型 `Q` 处理，以获得多元高斯分布的两个向量：均值向量（`μ`）和标准差向量（`σ`）。然后，通过 `z = μ + σε` 为每条真实曲线生成一个潜在向量 `z`，其中 `ε` 是从标准多元正态分布 `N(0,I)` 生成的随机数。在以下项目代码中，你将看到一个技巧，展示了如何计算标准差向量（`σ`），其中每个元素必须为正数。解码器的模型 `P` 使用一批潜在向量 `Z` 来生成一批虚假图像（`X̂`）。图 5.1(A) 中显示的那些虚假曲线在模型训练开始时非常嘈杂。然后在 epoch 20,000 时，噪声被过滤掉，图 5.1(C) 中显示的虚假曲线变得平滑。

![图 5.1. (A) VAE 信息流程图（真实曲线为单元格 03 的输出）。(B 和 C) 由 beta-VAE 生成的虚假二次曲线，`β` = 0.5（单元格 07 的输出）。模型训练时间为 9 分钟。](img/bk978-0-7503-6244-3ch5uf1_pr.gif)

![图 5.1 续。](img/bk978-0-7503-6244-3ch5uf2_pr.gif)

单元格 04 中定义的编码器类使用一批真实曲线作为输入，并由一个全连接层进行处理。编码器输出一个潜在向量 `z`、一个均值（`μ`）张量和一个对数方差（`ln(σ²)`）张量。潜在向量 `z` 通过 `z = μ + σε` 从正态分布 `N(μ,σ²)` 中采样，其中 `ε` 是由标准正态分布 `∼N(0,I)` 生成的随机数。这是计算标准差（std）的技巧，标准差必须为正数。从对数方差，我们可以通过 `σ = √(e^(ln(σ²)))` 得到标准差。单元格 05 中定义的解码器 `P` 像往常一样有两个全连接层。它使用一批潜在向量作为输入。解码器的输出是一批虚假曲线。根据公式 (5.4)，损失函数在单元格 06 中定义。如果损失函数中的两部分是用 `mean` 而不是 `sum` 计算的，我们必须将 `β` 值调整为 0.01 左右。Adam 优化器用于模型训练。单元格 07 中定义的训练函数使用 pandas 数据帧来记录模型训练期间的损失值。在每个 epoch 中，生成五批真实曲线用于模型训练。每批训练数据由编码器模型 `Q` 处理。模型 `Q` 的输出 `z` 是模型 `P` 的输入，用于生成虚假曲线。然后计算损失值，并由 Adam 优化器更新两个模型的参数。损失函数曲线如图 5.2(A) 所示。

## 5.2 beta-VAE 在 MNIST 数据集上的应用

用于 MNIST 项目生成假图像的 beta-VAE 架构与上一节用于生成假二次曲线的架构几乎相同。主要区别在于编码器 `Q` 和解码器 `P` 使用了深度卷积网络。我们知道，具有两个全连接层的神经网络不足以处理 MNIST 图像。项目 5.3.1 代码生成的真实和假 MNIST 图像（图 5.3(B)）应当是一样的。我们可以看到假 MNIST 图像模糊不清，且部分数字错误。这些问题是由 Cell 02 中为数据可视化设置 `z_dim` = 2 导致的。当一张 MNIST 图像被编码器从 784 个像素压缩为仅含两个元素的潜在向量时，部分信息丢失，导致解码器无法正确恢复原始图像信息。图 5.4 展示了其他训练结果：包含潜在向量点的二维潜在空间、损失曲线，以及由 `p(x|z)` 生成、且 `z[0]`∈[−10,10] 和 `z[1]`∈[−10,10] 的假图像。通过将 `β` 值从 0 调整到 10，你可以看到潜在空间中的点会从一个巨大的不规则区域被压缩成一个半径约为 3 的圆形区域。我们的模型确实可以通过较大的 `β` 值训练，强制 `q(z|x)` 接近 `N(0, I)`，但由 `p(x|z)` 生成的假数字图像会过于模糊而无法辨认。我们需要模型训练中 Kullback-Leibler 散度的作用，但不能过度。将 Cell 01 中的 `z_dim` 从 2 改为 20，我们将获得清晰锐利的假 MNIST 图像，但图 5.4(A) 中的潜在空间将无法显示。使用 VAE，我们能够在没有标签信息的情况下从图像数据集生成所需的假图像。

## 5.3 对 MNIST、Fashion MNIST 与 Anime-Face 数据集使用 VAE-GAN

与 GAN 相比，VAE 系统更易于训练。它们可以在没有标签的情况下自动发现数据集中图像的特征。低维潜在空间中的这些图像特征可以被调整以生成新图像。然而，VAE 系统生成的假图像质量通常不如 GAN 生成的质量好。该问题源于基于逐元素误差的 VAE 重构损失函数，即公式 (5.3) 的第二部分。例如，如果一张 MNIST 图像的像素向左水平平移一个像素，VAE 的重构损失值将会很大，但肉眼看来原始图像和平移后的图像没有区别。2016 年，Larsen 及其同事发表了一篇论文（Larsen *et al* 2016），题为“利用学习到的相似度度量超越像素级自动编码”。通过 VAE 和 GAN 的混合，他们“用逐特征误差替代逐元素误差，以更好地捕捉数据分布，同时提供对平移等变换的不变性”。VAE-GAN 系统是一种生成模型，它结合了两种流行的生成系统：VAE 系统和 GAN 系统。该系统的 VAE 组件用于学习数据集的紧凑、连续表示，而 GAN 组件用于生成新的合成数据实例。利用这两个系统的优势，VAE-GAN 能够在生成高质量假图像的同时，学习数据集的紧凑、连续表示。这使得 VAE-GAN 在图像合成、无监督表征学习以及深度强化学习的数据生成等许多领域非常有用。

在图 5.5 所示的 VAE-GAN 系统中，有三个模型：编码器模型 `Q`、解码器模型 `P` 和判别器模型 `D`。前两个模型属于 VAE 系统。解码器同时也作为 GAN 系统的生成器，该 GAN 系统拥有判别器模型 `D`。数据加载器 `X` 中一个批次内的每张真实图像 (`x`) 都由编码器 `Q` 处理，在维度为 `z_dim` 的潜在空间中创建一个多元正态分布 `q(z|x)`。然后通过从这些多元正态分布中采样，生成一批潜在向量 (`Z`) 作为解码器 `P` 的输入，解码器 `P` 将这批潜在向量 `Z` 恢复为真实图像空间中的一批假图像 (`X̃`)，判别器模型 `D` 像往常一样将每张假图像压缩为范围 [0,1] 内的一个标量。这批真实图像也可以直接由模型 `D` 处理，如图 5.5 中最长的箭头所示。一批从多元标准正态分布 `N(0,I)` 中采样的噪声 (`Z_p`) 由 `P` 和 `D` 处理。模型 `D` 的三个标量批次被用来配合 BCE 损失函数计算损失值 (`L_GAN`)

```
L_GAN = ln (D(X)) + ln (1−D(X̃)) + ln (1−D(X_p))
```

(5.5)

### 5.3.1 模型 D 的额外功能

VAE-GAN 的模型 D 比普通 GAN 的模型 D 多做一项工作。从模型 D 倒数第二层神经层，VAE-GAN 的模型 D 输出两批向量。每批向量中每个向量的维度可达数千。来自真实图像的一批向量（`V[X]`）和来自假图像的一批向量（`V[X̃]`）被用来替换 VAE 系统重构损失函数中的真实图像和假图像。根据 VAE-GAN 论文，这个修改后的重构损失函数名为 `L_like^(Dis[l])`，它是解码器损失函数的一部分，也是编码器损失函数的一部分。公式 (5.7) 中的 `L_prior` 是 `q(Z|X)` 与多元标准正态分布 `N(0,I)` 之间的 Kullback-Leibler 散度。

```
L_P = L_like^(Dis[l]) - L_GAN = MSELoss(V[X], V[X̃]) - L_GAN
```

(5.6)

```
L_Q = L_like^(Dis[l]) + L_prior = MSELoss(V[X], V[X̃]) + D_KL(q(Z|X) || p(Z))
```

(5.7)

### 5.3.2 模型训练与损失函数平衡

模型 D、P 和 Q 使用各自的损失函数进行训练。这三个模型的损失函数值不在同一量级，特别是当这些值通过每批求和计算时。许多人通过每批平均损失求和来计算三个损失函数的值，并使用 `L_P = γ L_like^(Dis[l]) - L_GAN` 和/或 `L_Q = 5 L_like^(Dis[l]) + L_prior` 来平衡这些损失值，其中 `γ = 15` 或 `25`。

在后续的 VAE-GAN 项目中，损失函数值通过每批求和计算。由于 `L_GAN` 和 `L_prior` 的值与 `L_like^(Dis[l])` 相比非常小，`L_like^(Dis[l])` 前的超参数 `γ` 被设置为 `1.0`。潜在维度通过 `z_dim = 2` 设置为 2，以便我们能在图 5.7(A) 中展示潜在空间。在模型训练期间，Cell 11 每五个 epoch 会输出一批真实图像和一批假图像，如图 5.6 所示。

### 5.3.4 判别器 D 的结构差异

Cell 07 中的判别器 D 与第 3.2.2 节中 GAN 的模型 D 略有不同。它有两个输出。一个输出是一批范围在 `[0,1]` 内的标量，这与通常情况相同；另一个输出来自第 04 层的一批向量，每个向量有 1024 个元素。第二个输出用于替换图像（真实或假）以进行重构损失计算。向量的元素数量越多，模型训练所需时间越长，生成的假图像质量越好。

由于我们再次使用 GAN，我们面临着相同的问题：选择学习率以平衡图像生成器和图像判别器的“智力”。在 Cell 01 中，三个模型的初始学习率（`lr`）均设置为 `10^(-3)`。模型 Q 和 P 使用相同的学习率。在 GAN 的模型训练中，我们通常对模型 D 使用较小的学习率。但在 VAE-GAN 中，我们必须对模型 D 使用较大的学习率（`10 × lr`）以使假图像更清晰（Cell 09 第 05 行）。
