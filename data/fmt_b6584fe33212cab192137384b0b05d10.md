
有两条可能的途径来处理由未知参数值带来的不确定性。根据第一种途径，参数被视为`确定性`非随机变量。学习任务是获得其未知值的估计。对于每个参数，获得单一的值估计。另一种途径具有更强的统计风味。未知参数被视为`随机变量`，学习任务是`推断`相关的概率分布。一旦分布被学习/推断出来，就可以用它们进行预测。这两种途径均在本章中介绍，并在本书后续的各章中进行更详细的阐述。

两大主要机器学习任务——回归和分类——被呈现出来，并阐述了处理这些问题的主要方向。介绍并讨论了与参数估计任务相关的各种问题，如估计量效率、偏差-方差困境、过拟合和维度灾难。本章也可视为通往本书其余部分的路线图。然而，我们没有仅以一种相当“枯燥”的方式呈现主要思想和方向，而是选择通过采用简单的模型和技术来处理和研究相关任务，以便读者能更好地领会主题。我们努力更多地关注科学概念，而非代数操作和数学细节，后者在“润色”后续章节时不可避免地会在更大程度上被使用。

最小二乘法（LS）、最大似然法（ML）、正则化和贝叶斯推断技术被呈现并讨论。我们努力帮助读者掌握本书传达的宏观图景的信息视角。因此，本章也可作为机器学习领域参数建模任务的概览性介绍。

## 3.2 参数估计：确定论观点

估计未知参数向量`θ`的值这一任务，一直是多个应用领域关注的中心。例如，在大学早期，任何学生必须学习的最早科目之一就是所谓的曲线拟合问题。给定一组数据点，必须找到一条“拟合”数据的曲线或曲面。通常的做法是`采用`一种函数形式，如线性函数或二次函数，并尝试估计相关的未知参数，使函数图像“穿过”数据点，并尽可能紧密地跟随它们在空间中的分布。图 3.1A 和 B 即为两个此类示例。数据位于`ℝ²`空间中，以一组点`(y[n], x[n])`，`n = 1, 2, …, N`的形式给出。图 3.1A 对应曲线所采用的函数形式为

```
y = f_θ(x) = θ_0 + θ_1 x
```

(3.1)

而图 3.1B 的情况为

```
y = f_θ(x) = θ_0 + θ_1 x + θ_2 x².
```

(3.2)

未知参数向量分别为 `θ = [θ_0, θ_1]^T` 和 `θ = [θ_0, θ_1, θ_2]^T`。在这两种情况下，定义红线所绘曲线的参数值，与黑线相关的值相比，提供了好得多的拟合效果。在这两种情况下，任务均包含两个步骤：(a) 首先采用一种我们认为更适合手头数据的特定`参数函数`形式，以及 (b) 估计未知参数的值，以获得“良好”的拟合。

在更一般和正式的设定中，该任务可定义如下。给定一组数据点，`(y[n], x[n])`，`y[n] ∈ ℝ`，`x[n] ∈ ℝ^l`，`n = 1, 2, …, N`，以及一个参数函数族

```
ℱ := {f_θ: θ ∈ 𝒜 ⊆ ℝ^K},
```

(3.3)

在函数族 `ℱ` 中寻找一个函数，记为 `f(·) := f_θ*(·)`，使得给定 `x ∈ ℝ^l` 的值，`f(x)` 能够“最好地”逼近对应的值 `y ∈ ℝ`。集合 `𝒜` 是一个约束集，用于将未知的 `K` 个参数约束在 `ℝ^K` 的特定区域内。将参数约束在参数空间 `ℝ^K` 的子集内，在机器学习中几乎无处不在。我们将在本章后面（第 3.8 节）处理约束优化。我们首先考虑 `y` 为实变量 `y ∈ ℝ` 的情况，随着深入理解各种“奥秘”，我们将允许其扩展到高维空间。最优参数向量 `θ*` 是由参数估计过程得出的。图 3.1 A 和 B 中定义红色曲线的 `θ*` 值分别为：

`θ* = [−0.5, 1]^T`， `θ* = [−3, −2, 1]^T`

要决定 `ℱ` 的选择并非易事。对于图 3.1 中的数据，我们有点“幸运”。首先，数据存在于二维空间，我们拥有可视化的便利。其次，数据分布在形状对我们相当熟悉的曲线上；因此，简单的观察就为这两种情况各自建议了合适的函数族。显然，现实生活很少如此慷慨，在大多数实际应用中，数据位于高维空间和/或曲面（对于维数高于三的空间称为超曲面）的形状可能相当复杂。因此，`ℱ` 的选择（它决定了函数形式，如线性、二次等）并不容易。实践中，必须尽可能多地利用关于数据生成潜在物理机制的先验信息，并且通常尝试不同的函数族，最终保留根据选定准则表现最好的那个。

确定了参数函数族 `ℱ` 后，必须获得未知参数集的估计值。为此，必须采用一个拟合度量。更经典的方法是采用一个 `损失` 函数，它量化了测量值 `y` 与使用对应测量值 `x` 通过 `f_θ` 预测值之间的偏差/误差。更正式地说，我们采用一个 `非负` (损失) 函数：

`ℒ(·, ·) : ℝ × ℝ ↦ [0, ∞)`

并计算 `θ*` 以使所有数据点上的总损失（即所谓的 `代价函数`）最小化，即

### 参数估计的优化问题

```
f(·) := f_θ*(·):  θ* = arg min_{θ ∈ 𝒜} J(θ),
```

(3.5)

其中

```
J(θ) := Σ_{n=1}^N ℒ(y_n, f_θ(x_n)),
```

(3.6)

假设最小值存在。请注意，通常可能存在多个最优值 `θ*`，这取决于 `J(θ)` 的形状。

```

```

(3.7)

以及线性函数类。

平方误差损失函数归功于伟大的数学家卡尔·弗里德里希·高斯（1777–1855），他在 1795 年年仅 18 岁时提出了最小二乘（LS）法的基础。然而，是阿德里安-马里·勒让德（1752–1833）于 1805 年首次独立发表了该方法。高斯于 1809 年发表了该方法。当该方法被用于预测小行星谷神星的位置时，其威力得到了展示。从那时起，平方误差损失函数就“萦绕”在所有科学领域，即使不直接使用，它最常被用作衡量更现代替代方法性能的标准。这种成功归功于该损失准则所具备的一些良好特性，我们将在本书后续内容中探讨这些特性。

## 3.3 线性回归

在统计学中，`回归`一词被创造出来，用于定义这样一项任务：利用一组随机变量 `x_1`、`x_2`、…、`x_l` 来对`因`随机变量 `y` 进行建模。前者被视为系统的响应（输出），由后一组（输入）随机变量激活。输入变量将表示为等价随机向量 `x` 的分量。

```
y = θ_0 + θ_1 x_1 + ⋯ + θ_l x_l + η = θ_0 + θ^T x + η.
```

也就是说，该模型现在关于二维像 `ϕ(x)` 的分量 `ϕ_k`、`k = 1, 2` 是线性的。事实上，这一简单技巧是本书后续将要讨论的许多非线性方法的核心。毫无疑问，该过程可推广至任意数量的函数 `ϕ_k`、`k = 1, 2, …, K − 1`，除单项式外，还可使用其他类型的非线性函数，如指数函数、样条函数和小波函数。尽管输入-输出依赖建模具有非线性性质，但我们仍将此模型视为线性的，因为它保持了关于所涉及的未知参数 `θ_k`、`k = 0, 1, …, K − 1`（共 `K` 个参数）的线性。虽然为保持讨论简洁，本章其余部分将坚持使用线性函数，但一切所述均适用于此类非线性模型，即`广义线性模型`。所需做的只是将 `x` 替换为 `ϕ(x) := [ϕ_1, …, ϕ_{K−1}]^T ∈ ℝ^{K−1}`。

接下来，我们将给出两个例子，以演示参数建模的用法。这些例子具有普遍性，可代表一大类问题。

参数 `θ₀` 称为 `偏置` 或 `截距`。通常，通过将常数 1 作为 `x` 的最后一个元素添加进去，同时增加 `x` 的维度，该项会被参数向量 `θ` 吸收。确实，我们可以写成

```
θ_0 + θ^T x + η = [θ^T, θ_0] [x; 1] + η.
```

从现在开始，回归模型将写为

```
y = θ^T x + η,
```

(3.10)

除非另有说明，此符号表示偏置项已被 `θ` 吸收，且 `x` 已通过添加 1 作为额外分量而扩展。由于噪声变量是不可观测的，我们需要一个模型来 `预测` 输出值 y，给定随机向量 `x` 的观测值 `x`。

![Figure 3.2 Block diagram showing the input–output relation in a regression model.](img/gr002.jpg)

**图 3.2** 显示回归模型中输入-输出关系的框图。

在线性回归中，给定 `θ` 的估计值 `θ̂`，我们采用以下预测模型：

```
ŷ = θ̂_0 + θ̂_1 x_1 + ⋯ + θ̂_l x_l := θ̂^T x.
```

(3.11)

使用平方误差损失函数，估计值 `θ̂` 被设定为 `θ*`，它使可用观测值集合上 `ŷ[n]` 和 `y[n]` 之间的平方差最小化；即，关于 `θ` 最小化代价函数

```
J(θ) = Σ_{n=1}^N (y_n - θ^T x_n)².
```

(3.12)

我们首先考虑无约束的情况开始讨论；因此，我们设定 `𝒜 = ℝ^K`，并将在 `ℝ^K` 中寻找解，在我们当前的讨论背景下，`K = l + 1`。对 `J(θ)` 关于 `θ` 求导（梯度）（见附录 A）并令其等于零向量 `0`，我们得到（问题 3.1）

```
(Σ_{n=1}^N x_n x_n^T) θ̂ = Σ_{n=1}^N y_n x_n.
```

(3.13)

请注意，左边的求和是一个 `(l + 1) × (l + 1)` 矩阵，是 `N` 个外积向量的和，即 `x[n] x[n]^T`。根据线性代数知识，我们至少需要 `N = l + 1` 个观测向量来保证该矩阵可逆，当然这假设这些向量是线性无关的（参见例如 [35]）。

对于那些（尚未）非常熟悉向量运算的人，请注意公式 (3.13) 只是标量情况的推广。例如，在一个“标量”世界中，输入-输出对将由标量 `(y[n], x[n])` 组成，未知参数也将是一个标量 `θ`。代价函数将是 `Σ_{n=1}^N (y_n - θ x_n)²`。求导并令其等于零可得

```
(Σ_{n=1}^N x_n²) θ̂ = Σ_{n=1}^N y_n x_n,  或  θ̂ = (Σ_{n=1}^N y_n x_n) / (Σ_{n=1}^N x_n²).
```

一种更通用的书写公式 (3.13) 的方法是通过所谓的输入矩阵 `X`，它被定义为 `N × (l + 1)` 矩阵，其行是（扩展）回归向量 `x[n]^T`，`n = 1, 2, …, N`，表示为

```
X := [x_1^T; x_2^T; ...; x_N^T] = [x_11 ... x_1l 1; x_21 ... x_2l 1; ...; x_N1 ... x_Nl 1].
```

(3.14)

然后很容易看出，公式 (3.13) 可以写成

```
(X^T X) θ̂ = X^T y,
```

(3.15)

其中

`y := [y_1, y_2, …, y_N]^T`。

(3.16)

确实，

```
X^T X = [x_1, ..., x_N] [x_1^T; ...; x_N^T] = Σ_{n=1}^N x_n x_n^T
```

同理，

```
X^T y = [x_1, ..., x_N] [y_1; ...; y_N] = Σ_{n=1}^N y_n x_n
```

因此，最终最小二乘估计由下式给出

```
θ̂ = (X^T X)⁻¹ X^T y.
```

(3.17)

当然，这假设 `(X^T X)⁻¹` 存在。

换句话说，所得参数向量的估计由一组`线性方程`给出。将平方误差损失函数应用于线性模型时，这是一个主要优势。此外，只要 `(l + 1) × (l + 1)` 矩阵 `X^T X` 可逆，该解就是`唯一`的。

唯一性归因于平方误差代价函数图形的抛物线形状。图 3.3 以二维空间为例进行了说明。很容易观察到该图有一个唯一的最小值。这是平方误差代价函数是严格凸函数这一事实的结果。与损失函数凸性相关的问题将在第 8 章中更详细地讨论。

**图 3.3** 平方误差损失函数在点 `θ*` 处有一个唯一的最小值。
