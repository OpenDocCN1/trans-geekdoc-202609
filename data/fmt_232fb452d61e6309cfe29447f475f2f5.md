## 1.1 引言

学习分为两种类型，取决于数据处理方式。批量学习是分块处理数据，通常是离线的。另一种学习类型是在线学习，通常在流数据上进行。在线学习的另一个名称是增量学习。本章的重点是针对流数据进行增量学习。

数据流具有某些特性（根据 Gama, 2010）：

- 无界大小：
  - 瞬态（仅持续几秒或几分钟）；
  - 单次通过数据；
  - 只能存储摘要；
  - 实时处理（内存中）。

由于这些问题，为离线数据处理开发的传统算法并不适用于流式数据。具有增量性（incremental）的模型较少，例如 K-最近邻算法（KNN）和朴素贝叶斯（naive Bayes）。但尽管如此，这些模型无法处理流式数据中存在的所有问题。例如，如果数据中存在概念漂移（concept drift），则需要开发专门的概念漂移检测和缓解技术。许多研究人员针对流式数据提出了各种模型来解决这些问题。我们将在接下来的章节中介绍其中一些技术。

如图 1.1 所示，流处理器接收如 0, 1, 0, 1, ...... 等数据流作为输入。处理器可以从流中进行采样并在主内存中进行处理（例如在回答查询时），如果需要，可以将处理结果存储到后端（如硬盘）以供下游任务。后续章节中介绍的大多数算法将基于这一通用模型。

数据挖掘应用于多个领域，例如回答网络查询、传感器数据（Das et al., 2019; Dey et al., 2019）、网络数据包分析、患者健康监测以及监控系统等。由于该领域范围广泛，我将在章节末尾介绍该领域的一些案例研究。

本章的其余部分在第 1.2 节讨论了与流挖掘相关的研究问题。第 1.3 节阐明了流式数据中的简单问题，如过滤和计数。第 1.4 节解释了从数据流中采样，随后第 1.5 节介绍了概念漂移检测。最后，章节以第 1.6 节的讨论和开放性问题作为结束。

由于上一节提到的原因，从数据流中发现知识是一项具有挑战性的任务。最具挑战性的是流的无边界大小、低内存和快速的到达率。因此，文献中提出的技术依赖于以某种方式对数据流进行总结。以下是处理数据流时常用的技术。

## 1.3.2 统计流中元素的频率

流中的频率计数是许多任务的基础。例如，如果我们知道元素的频率，就可以计算它们的均值和方差，这些值可以进一步用于分类、聚类和相似性计算等下游任务。在此处，我将介绍一种用于统计数据流中元素频率的经典算法：计数-最小值草图（count-min sketch，Cormode and Muthukrishnan, 2004）。count-min 算法可以看作上述布隆过滤器的扩展。该算法的核心思想是使用哈希函数将流域从 [1,...,n] 映射到 [1,...,d]。

哈希值存储在一个名为 sketch（草图）的二维数组中，其宽度为 `w = [e / ε]`，高度为 `h = [log_{1/δ}]`,其中 `(e,δ)` 分别表示近似的精度和置信水平。

图 1.5 给出了 count-min 算法的一个示例。为了理解该算法，让我们来看一个例子。假设流看起来如下：

...A, B, A, C, A, A, C... (1.1)

最初，sketch 填充为 0。算法每次处理一个字母并应用哈希函数。例如，字母 "A" 通过 sketch 中的哈希函数映射到列 (0, 1, 3, 4, 2)。sketch 中对应的条目加 1。同样，所有其他字母也进行了哈希处理。在查询时，应用相同的哈希函数来生成 sketch 中的条目。该字母的频率通过取这些条目中的最小值得到。count-min sketch 保证永远不会产生假阴性（false negatives）。这意味着估计值要么是真实值，或者是过度计数（overcounts）。当两个或多个哈希函数将至少两个条目映射到完全的位置时，就会发生过度计数。这就是为什么算法的运行需要选择良好的随机哈希函数。关于更深入的讨论，读者可以参考原始文章（Cormode and Muthukrishnan, 2004）。

统计流中唯一元素的数量是一个有趣的问题。从形式上，该问题可以表述如下：假设随机变量域为 `{0, 1, …, n}`，流的形式如下：

0, 1, 0, 0, 0, 1, 2, 3, 3...

`n = 3`。平凡的解决方案是将所有新元素存储在一个哈希表中，其大小随 `O(n)` 增长。然而，我们想要一个运行时间仅 `O(log(n))` 的解决方案。Flajolet 和 Martin (FM) (1985) 提供了一个优雅的解决方案。FM 算法在算法 1.1 中给出。让我们逐步分析该算法。

- 初始化一个 BITMAP（位图）为全 0。
- 对于流中的每个元素 `x`，计算其哈希值。称为 `h(x)`。
- 哈希值的二进制表示为 `bin(h(x))`。
- 函数 `p` 给出最低有效置位的位置。如果 `p` 对 0 位返回 0，也发生这种情况。
- 最后设置 BITMAP[i] = 1。

```
Algorithm L1: Flajolet and Martin (FM) 算法
输入: 流 $M$
输出: $M$ 的基数 (Cardinality)
1 初始化：初始化为 0 的 $L$ 位 BITMAP；
2 对于 $M$ 中的每个 $x$：
  * 计算哈希函数 $h(x)$
  * 获取哈希输出的二进制表示，称为 $bin(h(x))$；
  * 计算索引 $i$，使得 $i = p(bin(h(x)))$，其中 $p$ 输出最低有效置位的位置，即 $i$；
  * 设置 BITMAP[$i] = 1；
3 结束
```
