
封装方法（wrapper methods）下最常用的技术包括：(1) 前向选择、(2) 后向选择和 (3) 双向消除（逐步选择）。我们强调上述封装方法中的这些技术。基本上，前向选择从截距项开始。对各种变量进行测试是为了检查其相关性。将“最佳”变量（其中“最佳”由某些预定义的标准确定）加入到模型中。我们继续这一过程，每次添加一个变量并在每一步中进行测试，同时模型不断改进。一旦模型停止改进，我们便停止添加更多变量。我们判断是否考虑某个变量的标准各不相同。通过寻找交叉验证中的最低分、最低 p 值或任何其他准确性测试来实现。与前向选择不同，后向选择从一个包含所有预测器的最小二乘模型开始，然后通过迭代方法逐个移除最不重要的预测器。后向选择适用于观测值多于变量数量的问题。如果出现相反的情况，我们将无法拟合最小二乘模型，但在当变量之间发现相关性时（如后向消除），在每个阶段都有检测到所选变量的可能性。它主要用于选择某些选择性子集，定义为从整个特征空间中选择某些特征的过程。文献中关于特征选择（FS）方法有许多多样化的概念。某些概念主要处理所选数据的大小，而其他概念则关于提高预测准确率。本质上，FS 构建了一个能有效代表原始数据的数据集。主要目标是在保持分类过程中较高准确率的同时，找到最数量的特征。我们的研究围绕上述领域展开，我们主要处理了在整个特征空间中选择最合适子集所面临的挑战。

## 11.4 提议模型

在本节中，将详细解释 `FSTLO` 方法的工作原理。在该方法中，算法从随机生成初始种群开始（包括教师和学生）。种群是二进制解的集合，有助于根据值 1 或 0 来选择或拒绝特征。在这里，我们将这种基于教学学习的优化技术融入封装特征选择（FS）技术的概念中。基于封装的特征子集选择的底层理念是从原始数据集的所有特征中随机选择一组特征。通过多次迭代，它会选择不同的集合并评估个体选择的适应度。选择适应度最大的一个并将其选为特征。封装选择技术有三种：前向选择、后向选择和双向消除。在结合教学学习优化实现封装选择技术后，将对性能进行评估。整体方法论包括以下步骤：

(1) 从不同来源收集数据；
(2) 这些原始数据包含许多不一致性、无关值和空值；
(3) 通过 FS 方法移除冗余数据。在这里我们使用了封装选择方法，因此将高维数据转换为低维数据并移除不必要的信息。背后的数学原理是提取与预测变量具有最大相关性的显著特征。
(4) 然后我们应用分类方法并评估准确率和精确率值。

在教师阶段，适应度最小的个体被视为教师。教师试图通过共享知识来提高学生的性能。学生的知识根据学生适应度和教师适应度之间的差异进行更新。学生的适应度更新为：

`$X_{student} = X_{student} + w \times (X_{teacher} - X_{student})$`

其中 `$w$` 是 0 到 1 之间的学习率。此过程适用于种群中的所有学生。所有学生更新后，通过选择适应度最好的学生来更新教师。此过程重复多次，直到满足停止标准。

在学生阶段，学生之间相互交互以改进知识。每个学生的知识根据其适应度另一个学生适应度之间的差异进行更新。学生的适应度更新为：

`$X_{student} = X_{student} + w \times (X_{other} - X_{student})$`

其中 `$w$` 是 0 到 1 之间的学习率。此过程适用于种群中的所有学生。所有学生更新后，通过选择适应度最好的学生来更新教师。此过程重复多次，直到满足停止标准。

同样提升了性能。首先，对原始数据进行预处理（清洗和转换数据）以使其有用。在这里，缺失值通过中位数插补法进行处理。这背后的原因是数据集中可能存在一些离群值。因此，平均值或算术平均数可能是错误的，所以我们采用了中位数，它基本上是整个总体的中心值；离群值不受其影响。由于每个观测值都有多种参数，它们的范围可能各异，导致对预测的评估不利。为了解决这个问题，使用了最小归一化（min-normalization）将数据缩放到到 0.0–1.0 的范围内。这有助于保持整个数据集的均匀性，否则在实际操作中要可视化或表示所有数据将困难得多，而且模型的比较性能将不理想。我们通过考虑到特征集可能包含某些本质上已变得冗余的特征，从而降低所用模型的效率，筛选出了最显著的特征。在将分类算法应用于原始数据之前，我们选取了与预测变量具有最大相关性或相关性的最优特征。在数据集中，通常收集数据时由多位医生进行测试并收集结果。可能会出现冗余的测试者或由两位及更多医生进行同类测试的情况。这些特征被添加到原始数据集的特征空间中，导致数据的底层分布发生失真。因此，为了改进分布，通过减少特征并从原始数据集的所有特征中选择最适合的特征集，我们利用多种优化技术开发了特征选择（FS）技术。对这些技术进行了实验和评估，以进一步提高模型的准确性。整个数据集通过十折交叉验证进行处理。许多时候，由于数据点的分布不均匀，准确率波动很大。为了对最终准确率进行评估，如果通过对多次准确率进行迭代并找到它们的平均值，就可以获得一个更好、更准确的结果，从而解决该问题。在应用分类算法后，我们评估了所有数据集在每个模型中的准确率，并得出我们提出的 `FSTLBO` 模型性能优于现有结论。

```
I(x) = J(x) * t(x) + A * (1-t(x))

其中雾图像为 `$I(x)$`，`$t(x)$` 是范围从0到1的透明度，`$A$` 是空气光，`$J(x)$` 是图像的颜色。传输因子 `$t(x)$` 随深度增加而减小，表示为：

```

其中 `$\beta$` 代表散射系数，`$d(x)$` 是场景深度。

从雾图中恢复图像的技术被称为去雾。传统的去雾技术包括两个步骤：首先消除空气光，其次恢复丢失的信息。基本上，去雾方法分为两类：多图像去雾方法和单图像去雾方法。基于机器学习的相关工作见 [4, 31, 40]。

多图像去雾方法需要多个场景图像来执行，而单图像去雾方法只需要一张图像。

多图像去雾方法可以扩展为以下类别：基于天气条件的方法 [21, 25]，它取决于在不同天气下拍摄的同一图像。虽然这种方法可以提高可见度，但并不适用于动态图像。对于偏振方法 [29, 30]，考虑了具有不同偏振滤镜的多幅图像。偏振滤镜可以通过相机上附的偏振滤镜进行调整。该方法的局限性是当雾厚或浓密运行时无法正常运行。同样对于基于地图的方法 [14, 23]，使用了一些深度信息来去雾图像。这种方法在3D模型上运行，输入的场景深度提供了并有助于消除图像中的雾。这种技术需要用户交互，即不是自动的。

为了应对多图像去雾方法的局限性，使用了单图像去雾方法：对比度最大化方法 [35]，它有助于增强输入雾图像的对比度。输出图像将具有较大的饱和度，因为所提方法仅提高了可见度而没有改善整体。
