
# Dossier Stack

Dossier Stack 是以库的形式交付的智能软件。程序调用该库来执行某些以实体为中心的操作。实体可以包括人物、地点、企业名称、别名以及其他重要标识符。Dossier Stack 使程序员能够构建主动搜索应用程序。这些应用程序可以通过监控和捕获用户的行为来学习用户需求。开发者的商业软件使得利用概率推理算法挖掘海量信息流并连接实体成为可能。程序员是 Diffeo，这是一家成立于2012 年的初创公司，吸了 MIT 和 MetaCarta 的经验。John Frank [84] 该公司的领域是爬取网络并为唯一实体创建知识图谱。其理念是以更具教养的方式精炼人、地、组织和命名事物之间的关系。Diffeo 集成了 Basis Tech 的语言工具，并使用了 SAP 的内存数据库技术。

# Formaratus

Formaratus 是一个提供网页信息的软件组件。该 Python 包判断路径是登录页、搜索框、注册、密码找回、邮件列表还是联系表单。该系统使用机器学习，因此该组件输出的精确性随时间推移而增加。Hyperion Gray 是其他 Memex 模块的程序员，包括 Frontera（一个网络爬虫程序）和 Scrapy-Docker hub，此外还有管理索引程序。

# HSPProbe

Tor 隐藏服务探测器 HSPProbe 是一个多线程 Python 应用。该软件使用了 Stem，这是一个 Tor 的 Python 控制器。Stem 允许程序使用 Tor 的控制协议对 Tor 编写脚本，或构建可以确定 Tor 隐藏服务状态并提取隐藏支持材料的组件。HSPProbe 设计用于利用协议错误代码，在无法到达覆盖的服务时决定采取什么行动。HSPProbe 测试 Tor 秘密服务（Onion 地址）是否在预定义的一系列端口上监听。

此外，程序还会确定秘密服务何时通过其他协议进行通信。程序员/用户提供待探测的 Onion 地址列表，HSPProbe 输出结果列表。由于暗网提供了加密，Tor 用户认为它比表面网更有匿名性。加密是可以被破解的。

# 网络空间中的对话

## 与 Greg Walton 的对话

Greg Walton 是牛津大学新成立的网络安全博士培训中心的 D.Phil 博士候选人，最近加入了信息学院（OII）开展他的主要研究项目。过去，Greg 调查了针对公民社会网络的复杂自适应威胁，并在南亚当地与西藏非政府组织（NGO）进行了广泛合作。Greg 曾在印度达兰姆萨拉（Dharamsala）的达赖喇办公室和西藏流亡政府协调了 GhostNet（影子网）和 ShadowNet 调查的主要实地研究；在那里，他与一个团队合作揭露了从中国运行的全球网络间谍机器人网络，这些网络渗透了联合国、北约、各国政府、外交使馆以及全球范围内公民社会的计算机。Greg 是 SecDev 基金会的研究员，曾是多伦多大学蒙克中心所在地 Citizen Lab 的 SecDev 研究员，并毕业于布拉德福德大学和平研究系（国际关系与安全研究专业）。

2018 年 5 月，我有机会在爱尔兰都林的圣三尼学院见到了 Gregory。我们简要讨论了西藏 NGO 的现状、达兰姆萨拉的情况以及 ShadowNet 的调查。以下是我们在都林会面后的一个月内通过电子邮件保留的对话记录。

**问。** 你正在与 SecDev 基金会研究中亚 NGO 的恶意软件，能向我介绍一下 SecDev 并概述一下“CyberSAR”项目吗？

**答。** SecDev 基金会是非营利“智库兼执行库”（think-do tank），致力于促进全球公民社会的数字安全和机会。

该基金会直接执行项目，支持欧亚地区、中东、北非以及东南亚的公民社会组织、妇女、青年和弱势群体。

CyberSAR 项目是这些努力之一。有趣的是，CyberSAR 项目的技术研究部分借鉴了由剑桥大学高级网络研究小组（ANRG）率先开发的跨学科方法论。ANRG 于 9/11 悲剧事件发生六个月后成立，旨在应对人们急需新方法来解决当前全球不安全局势中特征性的——不稳定性和不确定性的迫切需求。

ANRG 研究了技术网络与社会网络之间的联系，以及其对全球安全、政治、发展和冲突转型的影响。ANRG 项目共享一种共同的方法论，该方法结合了利用技术方法对网络进行审视和制图，同时在语境化、实地民族志方面培养了成熟的专业知识。

2006 年，ANRG 搬到了加拿大并成为 SecDev Group，一家数字风险咨询公司。2008 年，我在 Citizen Lab 与 SecDev Group 合作，在那里我们发现了一个运行在中国南方信号情报基地的基础间谍网络，该网络已渗透进全球联合国、北约、政府部门、外交使馆和公民社会的机器中。

2011 年，SecDev Group 联合创始人 Rafal Rohozinski 和 Deirdre Collings 成立了 SecDev 基金会，作为一个独立的非营利组织。
