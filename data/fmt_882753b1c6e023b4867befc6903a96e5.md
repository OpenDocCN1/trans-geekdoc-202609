
然而，霍夫丁不等式的一种推广称为麦克迪阿米德不等式，可用于利用这些度量做分裂决策，因为它显式地作用于数据的函数 [218]。对于信息增益 `IG`，可以证明对于任意两个属性 `A` 和 `B`：如果 `E[S][IG(S,A) − IG(S,B)] > ε`，则以概率 `1 − δ` 有 `IG(S,A) − IG(S,B) > 0`，其中 `ε = √( (ln(1/δ)) / (2n) ) * (log n_c)`，`n` 是 `S` 的大小，`n[c]` 是类别数。基尼指数的公式更简单：只需 `ε = √( (ln(1/δ)) / (2n) )` 即可。文献 [215] 给出了类似的界。错误分类率也可使用 [217]，最终给出一个与霍夫丁界非常相似的界。

请注意，我们对流式决策树工作的描述采取了历史视角。麦克迪阿米德界的使用是该特定方法的前沿成果，代表了相对较新的结果。未来霍夫丁树可能会被证明在*假设不成立*的意义上是**不正确**的，然而它们在实践中仍然非常有效，因此值得研究。

## 6.3.2 霍夫丁树

### Hoeffding 树及其扩展

#### Hoeffding 树

在数据流场景中，由于无法存储所有数据，构建决策树的主要问题是需要重复使用实例来计算最佳分裂属性。Domingos 和 Hulten [88] 提出了 Hoeffding 树，这是一种用于流数据的极快决策树算法，它不重复使用实例，而是等待新实例到达。Hoeffding 树最有趣的特性在于，它构建的树在理论上能收敛于批量学习器在拥有足够大数据时构建的树；本节稍后将给出这一等价性的更精确表述。

Hoeffding 树的伪代码如图 6.3 所示。它基于第 4.2 节讨论的 Hoeffding 界。根据该界，文献 [88] 的提议是，将节点处熵估计的置信区间选为以下值：

```
ε = √(R² ln(1/δ) / 2n)
```

其中 `R` 是随机变量的取值范围，`δ` 是估计值*不*在其期望值 `ε` 范围内的期望概率，`n` 是在该节点收集到的示例数量。对于信息增益，熵的取值范围为 `[0,…,log n[c]]`，其中 `n[c]` 为类别值的数量。尽管如前所述，在此语境下使用 Hoeffding 界在形式上是不正确的，但它仍被大多数实现所采用；它取得合理结果的原因可能在于，在大多数情况下，它给出了真实错误概率的高估。

![图 6.3 Hoeffding 树算法。](img/Fig6-3.png)

**图 6.3** Hoeffding 树算法。

Hoeffding 树算法在每个节点中维护分裂属性所需的统计信息。对于离散属性，这与计算朴素贝叶斯预测所需的信息相同：一个三维表，用于存储每个三元组 `(x[i], v[j], c)` 的计数 `n[i,j,c]`，即满足 `x[i] = v[j]` 的训练实例数量，连同一个用于 `C = c` 计数的一维表。所需内存取决于树的叶子数量，而不取决于数据流的长度。

Hoeffding 树一个具有理论吸引力的特性——其他增量决策树学习器不具备——是它拥有可靠的性能保证。文献 [88] 证明了其输出在以下意义上与使用无限多示例的非增量学习器渐近近似相同。

两棵决策树 `DT[1]` 和 `DT[2]` 之间的*内涵分歧* `Δ[i]`，是指一个示例通过 `DT[1]` 的路径与其通过 `DT[2]` 的路径在长度、测试属性或叶节点处的类别预测上出现差异的概率。文献 [88] 严格证明了以下结果：设 `HT[δ]` 为 Hoeffding 树算法以参数 `δ` 从无限示例流中产生的树，`DT` 为从无限批量数据构建的批量树，`p` 为 `DT` 中叶节点的最小概率。则有 `EΔ[i] ≤ δ/p`。

Domingos 和 Hulten [88] 将 Hoeffding 树算法改进为一种更实用的方法，称为极快决策树（VFDT），具有以下特征：

*   **平局处理**：当两个属性具有相似的分裂增益 `G` 时，改进方法会在 Hoeffding 界低于某个阈值参数 `τ` 时进行分裂。

    ```
    G_best - G_second_best < ε
    ```

*   为加快处理速度，VFDT 不在每个新实例到达时都计算最佳分裂属性，而是在每 `n_min` 个实例到达时计算一次。

*   为减少挖掘过程中的内存使用，VFDT 会停用最不具潜力的节点，即乘积 `p[l] × e[l]` 最低的节点，其中

    *   `p[l]` 是到达叶节点 `l` 的概率，且

    *   `e[l]` 是节点 `l` 中的误差。

*   该方法可从任何预先存在的决策树开始，例如，从可用的一批数据构建的树开始。Hoeffding 树生长缓慢且初期性能可能较差，因此此扩展为学习曲线提供了即时提升。

值得注意的是，关于 VFDT 方法的最后一点，研究非常少。初期学习缓慢是这些树的一个问题，通过初始决策树进行引导以创建更好的起点是合理的。

改进 Hoeffding 树分类性能的一种方法是在叶节点使用朴素贝叶斯学习器，而不是多数类分类器。Gama 和 Medas [113] 首次在 Hoeffding 树叶节点中使用朴素贝叶斯，替代了多数类分类器。然而，Holmes 等人 [135] 发现了一些情况：朴素贝叶斯方法初期优于标准 Hoeffding 树，但最终被后者超越。为了解决这个问题，他们提出了一种混合自适应方法，该方法通常在简单和复杂概念上都优于这两种原始预测方法：在对测试实例进行预测时，如果朴素贝叶斯预测的总体准确率高于多数类预测，则叶节点返回朴素贝叶斯预测，否则返回多数类预测。唯一的开销是维护两个计数器，记录每个分类器正确的次数。

## 6.3.3 CVFDT

Hulten 等人 [138] 提出了概念适应极快决策树（CVFDT）算法，作为 VFDT 的扩展以处理概念漂移，维护一个与滑动窗口中存储的实例一致的模型。遗憾的是，此类树不像 Hoeffding 树那样拥有理论保证。值得注意的是，从理论上讲，Hoeffding 树在一定程度上可以适应概念漂移，因为在平稳分布下不再生长的叶节点，如果收集到的证据表明进一步分裂能提高准确性，可能会重新开始生长。然而，这一过程在实践中太慢。

图 6.4 展示了 CVFDT 算法的代码草图；更完整的描述见上文引用。注意此处我们使用了“移除”和“遗忘”这两个看似相同的术语。它们是不同的，因为遗忘是一个复杂的过程，它从树中移除一个实例。相比之下，添加和移除实例仅适用于滑动窗口。

*   主方法维护一个包含最新实例的滑动窗口，因此它必须添加、移除和遗忘实例。

*   算法定期检查备选分支的表现是否优于原始分支树，如果是则替换原始分支，否则移除备选分支。

## 6.3.4 VFDTc 和 UFFT

VFDTc 和 UFFT 是两种将 Hoeffding 树扩展以处理数值属性和概念漂移的方法。Gama 等人 [111] 开发的 VFDTc 执行以下操作：

1.  它在叶节点保留朴素贝叶斯学习器以进行预测。

2.  它使用二叉树处理数值属性，如第 6.4.2 节所述。

3.  为处理概念漂移，它使用第 5.3.4 节所述的统计 DDM 方法。

### 超快树林（UFFT）

超快树林（UFFT）由 Gama 和 Medas [113] 开发，可生成一组二叉树，为每一对可能的类别各生成一棵。这些树在每个节点都包含一个 `Naive Bayes` 分类器，类似于 `VFDTc`。与 `VFDTc` 的主要区别在于对数值属性的处理方式。

UFFT 使用分析技术来选择分裂标准，并利用信息增益来估计每个可能分裂测试的优劣。针对多分类问题，该算法为每一对可能的类别构建一棵二叉树，从而形成一个树林，对于 *k* 分类问题，该树林包含 *k*(*k* − 1)/2 个分类器。该分析方法采用了一种修改形式的二次判别分析，以纳入两个类别上不同的方差。

## 6.3.5 Hoeffding 自适应树

*Hoeffding 自适应树* [33] 是 Hoeffding 树的一种自适应扩展，它使用 `ADWIN` 作为变化检测器和误差估计器。它具有性能方面的理论保证，且不需要与变化控制相关的参数。相比之下，`CVFDT` 没有理论保证，并且需要若干个带有默认值的参数，这些默认值可由用户更改，但在给定的执行过程中是固定的。它需要：

1.  **`W`**：样本窗口大小。

2.  **`T[0]`**：每 `T[0]` 个样本，`CVFDT` 遍历整棵决策树，并检查每个节点的分裂属性是否仍然是最佳的。如果存在更好的分裂属性，它将开始以该节点为根生长一棵备选树，并根据该节点的统计数据在当前最佳属性上进行分裂。

3.  **`T[1]`**：创建备选树后，随后的 `T[1]` 个样本用于构建该备选树。

4.  **`T[2]`**：在 `T[1]` 个样本到达后，随后的 `T[2]` 个样本用于测试备选树的准确性。如果备选树比当前树更准确，`CVFDT` 将用该备选树替换当前树（我们称备选树被“提升”了）。

默认值为 `W = 50,000`，`T[0] = 10,000`，`T[1] = 9,000` 和 `T[2] = 1,000`。我们可以将这些数字理解为：假设最近的 50,000 个样本通常是相关的；变化不太可能比每 10,000 个样本发生得更快；并且 1,000 个样本足以判断当前树和候选树中哪个更好。对于给定的数据源，这些假设可能正确，也可能不正确。此外，数据流在不同时间可能以不同方式变化，因此没有一组固定的值可能适合整个数据流的所有阶段。

Hoeffding 自适应树相对于 `CVFDT` 的主要区别在于：

*   备选树在检测到变化时立即创建，无需等待变化发生后固定数量的样本到达。此外，变化越剧烈，新备选树的创建速度就越快。

*   Hoeffding 自适应树一旦有证据表明备选树更准确，就会立即用备选树替换旧树，而不是等待另一组固定数量的样本。

这两个效应可以总结为：Hoeffding 自适应树能适应数据中时间变化的尺度，而不依赖于用户做出的先验猜测。

## 6.4 处理数值属性

在数据流分类器中处理数值属性，比在非流式环境中要困难得多。在本节中，我们将回顾在演化数据流中用于决策树和朴素贝叶斯算法*离散化*的最流行方法。我们需要考察如何管理数值属性的统计信息，以及如何确定决策树中的最佳分裂点。

我们首先提及非流式场景下的方法。在那里，主要的离散化策略有：

*   **等宽（Equal width）**：数值属性的范围被划分为固定数量的、大小相同的箱。需要最大值和最小值来计算箱的上下限。这是最简单的方法，因为它不需要对数据进行排序，但它容易受异常值和偏态分布的影响。

*   **等频（Equal frequency）**：该策略也使用固定数量的箱，但每个箱包含相同数量的元素。对于 *n* 个值和 *k* 个箱，箱的权重将是 *n/k*（四舍五入除外）。它非常适合处理异常值和偏态分布，但需要更多处理时间，因为它需要对值进行排序。

*   **Fayyad 和 Irani 方法** [98]：该方法基于使用信息增益计算最佳切分点，这正如在决策树中所用。首先，它对数据进行排序，然后选择相邻值对之间的每个点作为分裂候选。利用信息增益选择最佳切分点，然后在每个部分中递归地继续该过程。需要一个停止准则来终止递归过程。该准则基于：当区间变得纯净（仅包含单一类别的值）时停止，或者当*最小描述长度*原则估计划分数值范围不会带来进一步收益时停止。

### 6.4.1 VFML

Hulten 和 Domingos [137] 的极快机器学习（VFML）包包含了一种在 `VFDT` 和 `CVFDT` 中处理数值属性的方法。数值属性值由一组有序箱进行汇总。每个箱覆盖的值范围在创建时固定，并且不会随着更多样本的出现而改变。一个隐藏参数作为允许的箱总数上限——在 VFML 实现中，这被硬编码为最多允许 1,000 个箱。最初，每当看到一个新的唯一数值，就会创建一个新箱。一旦分配了固定数量的箱，流中随后的每个值都会更新最近箱的计数器。

本质上，该算法使用一个由最多 1,000 个箱组成的直方图来汇总数值分布。箱的边界由流中看到的前 1,000 个唯一值决定，之后静态箱的计数会增量更新。

这种方法存在两个潜在问题。显然，该方法对数据顺序敏感。如果流中看到的前 1,000 个样本碰巧偏向值总范围的一侧，那么最终的汇总就无法准确代表完整的值范围。

另一个问题是估计最佳箱数。箱太少会导致汇总虽小但不准确，而箱太多会以空间为代价换取准确性。在实验比较中，通过改变最大箱数来测试这种影响。

### 6.4.2 穷举二叉树

Gama 等人 [111] 在他们的 `VFDTc` 系统中提出了这种方法。它以存储空间为代价，旨在实现完美的准确性。所做的决策与批处理方法相同，因为本质上它*就是*一种批处理方法——除了值的顺序外，没有丢弃任何信息。

它通过在观察到值时增量构建一棵二叉树来工作。值在树中向下的路径取决于它小于、等于还是大于树中特定节点的值。随着树的构建，值被隐式地排序，每个时刻的节点数等于所见不同值的数量。如果不同值的数量很少，则可节省空间。

另一方面，只要树保持合理平衡，该结构相比将值存储在数组中能节省搜索时间。特别是，如果值按顺序到达，树将退化为一个列表，无法节省搜索时间。

### 6.4.3 Greenwald 和 Khanna 的分位数摘要

数据库研究领域也关注如何在单次遍历和有限空间下汇总大型数据集的数值分布。这种能力有助于优化海量数据库上的查询。

#### Greenwald 和 Khanna 分位数摘要

Greenwald 和 Khanna [129] 提出了一种*分位数摘要*方法，其准确性保证比以往方法更强。该方法通过维护一个有序元组集合来工作，每个元组记录输入流中的一个值，以及每个值真实秩范围的隐式边界。确切地说，元组 `t[i] = (v[i], g[i], Δ[i])` 由三个值组成：

*   迄今为止在流中见到的元素之一的值 `v[i]`，

*   值 `g[i]` 等于 `r_min(v[i]) − r_min(v[i−1])`，其中 `r_min(v)` 是 `v` 在迄今为止见到的所有值中的秩的下界，以及

*   值 `Δ[i]` 等于 `r_max(v[i]) − r_min(v[i])`，其中 `r_max(v)` 是 `v` 在迄今为止见到的所有值中的秩的上界。

注意

```
r_min(v[i]) = Σ_{j=1..i} g[j]
r_max(v[i]) = r_min(v[i]) + Δ[i]
```

分位数摘要是 `ε`-近似的，具体含义为：在看到序列的 `N` 个元素后，返回的任何分位数估计值与精确值的差异不会超过 `ε*N`。定义了一个压缩分位数摘要的操作，保证 `max(g[i] + Δ[i]) ≤ 2ε*N`，从而将摘要的误差控制在 `2ε` 以内。

已证明最坏情况下的空间需求为 `O((1/ε) log(εN))`，经验证据表明在实践中其表现甚至优于此理论界限。

### 6.4.4 高斯近似

该方法见文献 [199]，利用高斯分布或正态分布，在小的常数空间内近似数值分布。此类分布可通过仅存储三个数字来增量维护，且不敏感于数据顺序。Gama 和 Medas 在其 UFFT 系统 [113] 中描述了一种类似的方法。

对于每个数值属性，该方法为每个类别标签维护一个单独的高斯分布。可能的值被简化为一组在观测到的最小值和最大值之间等间距分布的点。评估点的数量由一个参数决定，因此对分裂点的搜索是*参数化的*，尽管底层的高斯近似不是。对于每个候选点，可以利用各自的高斯曲线近似分裂点两侧各类别值的权重，并据此计算信息增益。

该过程在图 6.5 中演示。图顶部是两条高斯曲线，每条近似某数值属性在特定类别下的值分布。每条曲线可用三个值描述：均值、方差和样本总权重。例如，在图 6.5 中，左侧所示类别的均值较低、方差较高、样本权重较高（曲线下面积较大）。曲线下方，值域被划分为十个分裂点，标记为 A 到 J。底部的垂直条显示了为每个分裂点计算出的相对信息增益量。评估显示点 E 具有最高的信息增益，因此会被选为最佳分裂点。

该方法的一个改进是同时跟踪每个类别的最小值和最大值。这需要每个类别额外存储两个计数，但它们简单且维护开销极小。在评估分裂点时，该方法利用每个类别的最小值和最大值信息，判断类别值是否完全位于分裂点的一侧，从而消除高斯曲线尾部原本存在的微小不确定性。通过各类别的最小值和最大值，可以确定整个值域的最小值和最大值，这有助于确定待评估分裂点的位置。

高斯求和近似几乎肯定无法捕捉复杂数值分布的全部细节，但该方法在计算和内存方面均高效。二叉树方法以极高的内存代价换取尽可能高的准确性，而该方法采取相反策略——使用粗略近似以占用尽可能少的内存。事实上，对数值分布的简化视图不一定会损害其生成树的准确性。在树的更深处再次分裂，仍有机会细化对特定属性的分裂决策。此外，用少数简单参数进行近似比专注于细节的复杂方法更稳健，更能抵抗噪声和离群点。

## 6.5 感知机

感知机由 Rosenblatt 于 1957 年提出，是一种线性分类器，也是最早的在线学习方法之一。因其计算成本低，文献 [37] 指出它是决策树叶节点处多数类和朴素贝叶斯分类器的有益补充。
