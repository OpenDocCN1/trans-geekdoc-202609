
# 构建图 $G = (V, E)$

其中 $V = \{v_n, n = 1, 2, \dots, N\}$ 是顶点集合，$E = \{e_{ij}\}$ 是连接顶点 $(v_i, v_j)$ 的边集合，$i, j = 1, 2, \dots, N$（另见第 15 章）。图的每个节点 $v_n$ 对应数据集 $\mathcal{X}$ 中的一个点 $\mathbf{x}_n$。

如果点 $\mathbf{x}_i, \mathbf{x}_j$ 彼此“接近”，则连接 $v_i, v_j$，即在相应节点之间插入边 $e_{ij}$。根据该方法，量化“接近”有两种方式。如果满足以下条件，则使用边连接顶点 $v_i, v_j$：

1.  $||\mathbf{x}_i - \mathbf{x}_j||^2 < \epsilon$，其中 $\epsilon$ 为用户定义的参数，$||\cdot||$ 为 $\mathbb{R}^l$ 中的欧几里得范数；
2.  $\mathbf{x}_j$ 是 $\mathbf{x}_i$ 的 $k$ 近邻之一，或 $\mathbf{x}_i$ 是 $\mathbf{x}_j$ 的 $k$ 近邻之一，其中 $k$ 为用户定义的参数，邻居根据 $\mathbb{R}^l$ 中的欧几里得距离选择。

使用欧几里得距离是合理的，因为流形的光滑性允许在局部用嵌入流形的空间中的欧几里得距离来近似流形测地线。这是微分几何中的一个已知结果。

3.  对于不熟悉这些概念的人，可以想象嵌入在三维空间中的球体。如果某人被限制生活在球面上，从一点到另一点的最短路径是这两点之间的测地线。显然这不是一条直线，而是球面上的一个弧。然而，如果这些点足够接近，它们的测地距离可以用三维空间中计算的欧几里得距离来近似。

## 步骤 2

每条边 $e_{ij}$ 都与一个权重 $W(i, j)$ 相关联。对于未连接的节点，相应的权重为零。每个权重 $W(i, j)$ 是相应邻居 $\mathbf{x}_i, \mathbf{x}_j$ “接近程度”的度量。一个典型的选择是：

$$
W(i,j) = \left\{
\begin{array}{lc}
\exp\left( - \frac{||\mathbf{x}_i - \mathbf{x}_j||^{2}}{\sigma^{2}} \right), & \text{if } v_i, v_j \text{ correspond to neighbors}, \\
0, & \text{otherwise}.
\end{array}
\right.
$$

其中 $\sigma^2$ 是一个用户定义的参数。我们构建一个 $N \times N$ 的权重矩阵 $W$，其元素为权重 $W(i, j)$。注意 $W$ 是对称且稀疏的，因为在实践中，其许多元素均为零。

$$
L\mathbf{u} = \lambda D\mathbf{u}.

拉普拉斯矩阵 `L` 是对称且半正定的。后者从公式 (20.109) 的定义中显而易见，其中 `E[L]` 始终是一个非负标量。请注意，`D[ii]` 的值越大，样本 `x_i` 就越“重要”。这是因为它意味着 `W(i, j), j = 1, 2, …, N` 具有较大的值，并在最小化过程中起主导作用。显然，`E[L]` 的最小值由平凡解 `z[i] = 0, i = 1, 2, …, N` 实现。为避免这种情况，正如此类情况的常见做法，我们将解约束为一个预设范数。因此，我们的问题现在变为

```
min_z z^T L z, s.t. z^T D z = 1.
```

虽然我们可以直接处理上述任务，但我们将对其稍作重塑，以便使用更熟悉的工具。定义

```
y = D^(1/2) z,
```

和

```
L̃ = D^(-1/2) L D^(-1/2),
```

这被称为*归一化图拉普拉斯*矩阵。现在很容易看出，我们的优化问题变为

```
min_y y^T L̃ y,
```

s.t. `y^T y = 1`。

使用拉格朗日乘数法并令拉格朗日函数的梯度为零，可得解由下式给出

```
L̃ y = λ y.
```

换句话说，计算解变得等价于求解一个特征值-特征向量问题。将公式(20.115)代入公式(20.113)中的代价函数，并考虑公式(20.114)中的约束，结果表明与最优 `y` 相关的代价值等于 `λ`。因此，解是对应于最小特征值的特征向量。然而，`L̃` 的最小特征值为零，且对应的特征向量对应于一个平凡解。确实，观察到

```
L̃ D^(1/2) 1 = D^(-1/2) L D^(-1/2) D^(1/2) 1 = D^(-1/2) (D - W) 1 = 0
```

其中 `1` 是所有元素均等于 1 的向量。换句话说，`y = D^(1/2) 1` 是对应于零特征值的特征向量，它导致平凡解 `z[i] = 1, i = 1, 2, …, N`。即所有点都被映射到实线上的同一点。为了排除这个不希望的解，回顾 `L̃` 是一个半正定矩阵，因此 0 是其最小特征值。此外，如果假设图是连通的，即存在至少一条路径（见第 15 章）连接任意一对顶点，`D^(1/2) 1` 是与零特征值 `λ[0]` 相关联的唯一特征向量 [19]。而且，由于 `L̃` 是对称矩阵，我们知道（附录 A.2）其特征向量彼此正交。接下来，我们施加一个额外约束，现在要求解与 `D^(1/2) 1` *正交*。将解约束为与对应最小（零）特征值的特征向量正交，会将解推向对应下一个最小（非零）特征值 `λ[1]` 的下一个特征向量。注意，`L̃` 的特征分解等同于我们之前在第 3 步中称为 `L` 的广义特征分解。

对于 `m > 1` 的更一般情况，我们必须计算与 `λ[1] ≤ … ≤ λ[m]` 相关联的 `m` 个特征向量。事实上，对于这种情况，约束条件防止我们映射到维度小于期望 `m` 的子空间。例如，我们不希望投影到三维空间，而点却落在二维平面或一维直线上。更多细节请参阅富有洞察力的文献 [19]。

## 局部线性嵌入 (LLE)

与拉普拉斯特征映射方法类似，*局部线性嵌入* (LLE) 假设数据点位于一个维度为 $m$ 的足够光滑的流形上，该流形嵌入在 $\mathbb{R}^l$ 空间中，且满足 $m < l$ [155]。光滑性假设使我们能进一步假设：只要数据充足且流形采样“良好”，邻近点就会位于（或接近）流形上一个“局部”*线性*区域上（另见第 20.8.3 节的相关评论）。该算法最简单的形式可总结为以下三个步骤：

### 步骤 1：最近邻搜索

对每个点 $\mathbf{x}_n, n = 1,2,\ldots,N$，搜索其最近邻。

### 步骤 2：权重计算

计算权重 $W(n, j), j = 1, 2, \ldots, N$，以便从其最近邻中最佳重构每个点 $\mathbf{x}[n]$，从而最小化代价函数

```
\arg\min_W E_W = \sum_{n=1}^N \left\| \mathbf{x}_n - \sum_{j=1}^N W(n,j)\mathbf{x}_{n_j} \right\|^2,
```

其中 $\mathbf{x}_{n_j}$ 表示第 $n$ 个点的第 $j$ 个邻居。

约束条件：

1. 对于非邻居点，权重被约束为零。
2. 权重矩阵的每行之和为一：

```
\sum_{j=1}^N W(n,j) = 1, \quad n = 1,2,\ldots,N.
```

即，所有邻居的权重之和必须等于一。

### 步骤 3：嵌入

一旦从上一步计算出权重，便利用它们获得对应的点 $\mathbf{z}_n \in \mathbb{R}^m, n = 1,2,\ldots,N$，以最小化关于未知点集 $\mathcal{Z} = \{\mathbf{z}_n, n = 1,2,\ldots,N\}$ 的代价函数。

## 等度量映射

上述最小化过程受两个约束条件限制，以避免退化解：

1.  输出以原点为中心：`∑ₙ zₙ = 0`。
2.  输出具有单位协方差矩阵 [159]。

第 1 步中的最近邻点，以与拉普拉斯特征映射方法相同的方式进行搜索。再次强调，只要搜索局限于邻域点的“局部”范围内，欧氏距离的使用就可以由流形的平滑性来证明。对于第 2 步，该方法利用了平滑流形的局部线性性质，并试图使用最小二乘法通过其邻居*线性地*预测每个点。

在 Eq. (20.117) 给出的约束条件下最小化代价函数，得到的解满足以下三个性质：

1.  旋转不变性
2.  尺度不变性
3.  平移不变性

前两个性质可以通过代价函数的形式轻松验证，第三个性质则是施加约束的结果。这意味着计算出的权重编码了每个邻域内在特征的信息，并且不依赖于特定的点。

所得权重 `W(i, j)` 反映了数据底层局部几何结构的内在属性。由于我们的目标是在映射后保留局部信息，因此这些权重被用来通过其邻居在 `ℝᵐ` 子空间中重构每个点。正如文献 [159] 精辟所述，这就像我们拿起一把剪刀，将流形切割成小的线性补丁，并将它们放置在低维子空间中。

结果表明，针对未知点 `zₙ, n = 1,2,…,N` 求解 (20.118) 等价于：

*   对矩阵 `(I − W)ᵀ(I − W)` 进行特征分解。
*   丢弃对应最小特征值的特征向量。
*   取对应次小特征值的特征向量。这些向量给出了低维潜在变量得分 `zₙ, n = 1,2,…,N`。

再次强调，涉及的矩阵 `W` 是稀疏的，如果考虑到这一点，特征值问题对于大规模数据集的扩展性相对较好，复杂度关于 `N` 为亚二次方。第 2 步的复杂度为 `O(Nk³)`，这归因于为每个点求解含有 `k` 个未知数的线性方程组。该方法需要用户提供两个参数：最近邻数 `k`（或 `ϵ`）和维度 `m`。感兴趣的读者可参考文献 [159] 了解更多关于 LLE 方法的内容。

### ISOMAP 算法

与前两种在局部基础上解析流形几何结构的方法相反，ISOMAP 算法采取的观点是：只有数据点所有配对之间的测地距离才能反映流形的真实结构。流形中各点间的欧氏距离无法恰当地表示该结构，因为按测地距离测量相距甚远的点，按欧氏距离测量时可能很近（参见 图 20.17）。ISOMAP 本质上是多维缩放（MDS）算法的一个变体，其中欧氏距离被沿流形的相应测地距离所替代。该方法的核心在于估计相距较远的点之间的测地距离。为此，采用了一个两步过程。

![图 20.17 如果按欧氏距离测量，用“星号”表示的点欺骗性地比用“方框”表示的点更靠近用“圆点”表示的点。然而，如果受限于沿螺旋线移动，测地距离才是决定亲疏的标准，此时“方框”点更靠近“星号”。](img/gr017.jpg)

图 20.17 如果按欧氏距离测量，用“星号”表示的点欺骗性地比用“方框”表示的点更靠近用“圆点”表示的点。然而，如果受限于沿螺旋线移动，测地距离才是决定亲疏的标准，此时“方框”点更靠近“星号”。

#### 步骤 1

对每个点 `x_n, n = 1,2,...,N`，计算其最近邻并构建一个图 `G(V, E)`，其顶点代表数据点，边连接最近邻。（最近邻的计算采用拉普拉斯特征映射方法中使用的两种替代方案之一。参数 `k` 或 `ϵ` 为用户定义参数。）边根据相应的欧氏距离被赋予权重（对于最近邻而言，这是相应测地距离的一个良好近似）。

#### 步骤 2

计算所有配对 `(i, j), i, j = 1, 2, …, N` 之间沿图中最短路径的成对测地距离。关键假设是：流形上任意两点之间的测地线可以用沿图 `G(V, E)` 连接这两点的*最短路径*来近似。为此，可以使用高效算法（如 Dijkstra 算法，[59]）以 `O(N²ln N + N²k)` 的复杂度来实现。当 `N` 取较大值时，此开销可能过于巨大。

估算出所有点对之间的测地线后，便调用 MDS 方法。因此，问题转化为对相应 Gram 矩阵进行特征分解，并选择 `m` 个最主要的特征向量来表示低维空间。映射后，低维子空间中点间的欧氏距离与原高维空间中流形上相应的测地距离相匹配。同 PCA 和 MDS 一样，`m` 由显著特征值的数量来估计。可以证明，ISOMAP 在渐近意义上（`N → ∞`）保证能恢复一类非线性流形的真实维数 [66,173]。

所有三种基于图的方法都共享在图中计算最近邻这一公共步骤。这是一个复杂度为 `O(N²)` 的问题，但可以通过采用特殊类型的数据结构（例如 [23]）来使用更高效的搜索技术。ISOMAP 与拉普拉斯特征映射和 LLE 方法之间的一个显著区别在于：后两种方法依赖于稀疏矩阵的特征分解，而 ISOMAP 依赖于稠密 Gram 矩阵的特征分解。这使得拉普拉斯特征映射和 LLE 技术具有计算优势。此外，ISOMAP 中最短路径的计算是另一项计算量大的任务。最后，值得注意的是：这三种基于图的技术在执行降维任务时，都试图以这样或那样的方式解析数据（近似）所依附的流形的几何属性。相比之下，核 PCA 并非如此，它对任何流形学习都不感兴趣。然而，世界很小，文献 [88] 指出，如果使用源自编码邻域信息的图的数据相关核函数来替代预定义的核函数，基于图的技术可以被视为核 PCA 的特例！

本节旨在介绍非线性降维领域中一些最基础的研究方向。除了前述基本方案外，文献中还提出了许多变体（例如，[21, 70, 163]）。在文献 [150] 和 [118]（扩散映射）中，低维嵌入的实现旨在保留反映图 `G(V, E)` 连通性的某些度量。在文献 [30, 101] 中，利用保留流形局部信息的思想来定义形式为 `z = A^T x` 的线性变换，优化目标转变为针对 `A` 的元素进行。文献 [121] 最近探讨了用于降维的增量流形学习任务。文献 [172, 184] 引入了最大方差展开方法。在图中保留邻居间（局部）距离和角度的约束下，最大化输出的方差。与 ISOMAP 类似，该方法最终需要计算 Gram 矩阵的前几个特征向量，但避免了 ISOMAP 所需的、计算量大的测地距离估计步骤。文献 [164] 提出了一个称为图嵌入的通用框架，它为理解和解释许多已知的（包括 PCA 和非线性 PCA）降维技术提供了统一视角，同时也为开发新技术提供了平台。关于该主题更详细、更深入的论述，请参阅文献 [29]。非线性降维技术的综述可参见文献 [32, 123] 等。
