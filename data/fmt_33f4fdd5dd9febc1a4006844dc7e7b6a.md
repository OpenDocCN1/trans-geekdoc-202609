## 波士顿房价数据集的归一化示例

如果你已经在第 4 章的练习中对*波士顿房价*数据集进行了数据探索，你会发现数据中的变量并非正态分布。假设我们计划使用线性回归方法分析这些数据，而该方法通常对于正态分布的数据效果最好。因此，我们决定对数据集中的所有区间变量进行归一化。

我们继续之前完成的 `Impute` 节点。使用 SAS Enterprise Miner 对数据进行归一化，我们需要使用 `Transform Variables` 节点。从 Modify 选项卡中将 `Transform Variables` 节点拖入工作区并将其连接到 `Impute` 节点（见下文）。

![](img/ufig5_16.jpg)

按照以下步骤配置 `Transform Variables` 节点。

1. 在 `Train` 属性下：
    * 将 `Interval Inputs` 设置为 `Maximum Normal`。此选项允许软件确定最佳幂变换以最大化正态性。这使得我们的任务变得更容易，因为我们不需要决定为哪些变量使用何种归一化方法。

2. 运行 `Transform Variables` 节点并打开 `Results` 窗口。

输出显示了 SAS Enterprise Miner 选择的归一化函数（表 5.11）。如所示，软件为每个变量确定了最佳的归一化函数。常用的函数包括对数函数和平方根函数。创建的新变量会在变量名加上函数。这些新变量将用于下一步的预测建模。当我们有很多变量时，这个工具对于数据挖掘非常有用。我们无法逐个检查每个变量来决定使用哪种函数进行归一化。

### 表 5.11 归一化函数

| 变量名称 | 新变量名称 | 公式 |
| --- | --- | --- |
| AgePre40 | EXP_AgePre40 | `exp(max(AgePre40-1.137, 0.0)/98.863)` |
| B | LOG_Charles_River | `log(max(Charles_River-0, 0.0) + 1)` |
| Charles_River | LOG_CrimePC | `log(max(CrimePC-0, 0.0)/9.96654 + 1)` |
| CrimePC | LOG_LogAccess | `log(max(LogAccess-1, 0.0)/665 + 1)` |
| IndustPr | LOG_LogDistance | `log(max(LogDistance-1.1296, 0.0)/22.8704 + 1)` |
| LogAccess | LOG_NiOxSQ | `log(max(NiOxSQ-0.385, 0.0)/6.583 + 1)` |
| LogDistance | LOG_PtRatio | `log(max(LogDistance-1.1296, 0.0)/22.8704 + 1)` |
| NiOxSQ | LOG_NiOxSQ | `log(max(NiOxSQ-0.385, 0.0)/6.583 + 1)` |
| PtRatio | LOG_PtRatio | `log(max(LogDistance-1.1296, 0.0)/22.8704 + 1)` |

你可能会问：为什么我们不对 `airline recommendation` 数据集中的区间变量进行归一化呢？这是一个很好的问题。让我解释一下。对于基于顺序最小二乘法（`OLS`）的方法如线性回归），正态分布是一个常见的要求。这些算法在处理归一化数据时效果最好，因为这有助于我们实现良好的模型拟合。`boston` 数据集具有区间目标变量，因此线性回归是合适的选择。这就是为什么建议对数据进行归一化的。然而，逻辑回归、决策树或随机森林等方法基于不同的基础，正态分布并不是必要要求。因此，归一化数据对这些算法可能产生优势。在 `airline recommendation` 数据集中，我们有一个二分类目标变量，这使得逻辑回归成为预测建模的正确选择。在高级机器学习方法中，神经网络也不要求正态分布的数据，但可能需要数据标准化来帮助实现更好的模型拟合。`SAS Enterprise Miner` 中的神经网络工具具有内置的数据标准化选项，允许我们以更具动态的方式尝试不同的方法。这就是为什么我们不需要对此数据集中的区间变量进行归一化。

## 总结

数据修改是数据挖掘中的一个过程，涉及更改原始数据集以提高其用于预测建模的质量、完整或兼容性。它包含多种技术，如数据清洗、数据转换和数据压缩。在本章中，我们涵盖了三种主要的数据修改技术，包括替换、插补和转换。替换允许我们对数据集进行重新编码、纠正和赋值，通常用于清理和提高数据质量。插补用估计值填充数据集中的缺失值，它为我们提供了完整的数据集并避免了信息丢失。转换是创建现有变量转换的新变量的过程。它可以用于标准化和归一化数据、转换数据或聚合数据。

在本章中，我介绍了多种插补、归一化和离散化方法。正确方法的选择取决于数据集的特定特征、机器学习方法以及数据挖掘项目的目的。这需要仔细考虑对数据产生的潜在影响，例如在插补过程中引入偏差。
