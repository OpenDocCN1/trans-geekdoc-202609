# 15 区块链即服务

Ramya Bomidi, Srija Guntupalli, Sanober Mohammed and Bhargav Putturu Theja

DOI: [10.1201/9781003211723-15](http://doi.org/10.1201/9781003211723-15)

## 摘要

本最后一章重点介绍区块链即服务应用。作为一项较新的技术，BaaS 应用是基于云的应用程序，使组织能够利用基于云的资源快速构建、实施、托管和管理各种区块链项目。在 BaaS 服务交付模型中——与其他云解决方案一样——硬件、软件采购和维护的责任转移给云服务提供商，以实现更大的便利性和更高的效率；从而使实体能够专注于区块链网络的逻辑和工作流。

本章讨论首先从云属性的总体概述开始，例如按需服务、广泛的网络访问、资源池化、快速弹性和可度量服务。接下来，将各种节省成本的特性、云部署模型（公有、私有和混合）、计算角色和服务模型（IaaS、PaaS 和 SaaS）进行解释，以使读者熟悉云计算的全部属性和能力。

本章的第二部分解释了什么是 BaaS 平台，其优势和挑战是什么，以及 BaaS 与其他计算方法（如无服务器计算和平台即服务 PaaS）有何不同。读者还将获得对 BaaS 应用程序如何运作的基本理解，以及选择 BaaS 提供商时应考虑的因素。本章还简要讨论了由 IBM 和 Oracle 等实体提供的几个流行 BaaS 平台，以及正在开发中的几个 BaaS 应用程序。

本章末尾根据框架、定价和特殊功能等因素，展示了九种 BaaS 产品的对比。此外，还简要讨论了研究人员提出的关于非商业 BaaS 平台以及 BaaS 背景下治理的研究。本节的最后一个活动旨在为有兴趣选择基于云的区块链解决方案的读者提供一些初步信息，以开展旨在在其自身组织环境中实施 BaaS 的商业案例。

## 简介

区块链技术的发展及其在商业中的应用促使许多企业尝试该技术。领先的企业和技术提供商开始提供区块链即服务，以鼓励和促进组织对该技术的采用。在深入探讨 BaaS 的细节之前，下一节将讨论云概念的初步理解，包括其特征、类型、部署模型和服务模型。以下各节提供关于区块链即服务概念的更多技术见解，包括工作模型、BaaS 服务提供商对比以及一些业务用例。

### 云计算简史

云计算的普及度逐年持续增加。美国国家标准技术研究院 (NIST) 对云计算的定义指出，该技术是“一种模型，用于实现普遍、便捷、按需的网络访问，进入可配置的计算资源共享池（例如网络、服务器、存储、应用程序和服务），这些资源可通过最少的管理工作或服务提供商交互快速配置和释放” [17]。简而言之，云计算可以粗略地描述为一种涉及互联网及其基础设施的更高效的计算使用方式 [3]。

20 世纪 60 年代，John McCarthy 首次向公众介绍了云计算的概念。然而，云计算的基本思想可以追溯到 20 世纪 20 年代最早的大型主机计算机的发明。借助大型主机计算机，用户可以通过集中式平台从任何地方访问数据和处理能力。20 世纪 90 年代，互联网的爆发式普及导致虚拟计算机广泛可用，从而形成了现代云计算基础设施。随着越来越多的企业熟悉云服务，云计算的普及度不断提高。许多组织，如 Amazon、Microsoft、IBM 和 Google，已成为云计算服务市场的主要竞争者 [3]。

## 云计算概览

云模型由五个基本属性、四种部署模型和三种服务模型组成，具体描述如下 [16, 17]。

### 云计算属性

所有云服务提供商都应提供下列云计算的五个基本属性，以提供更好的服务质量和灵活性：

*   **按需服务**：云服务设置为按需提供。因此，客户可以根据需要利用云服务，而无需直接依赖其服务提供商。

*   **广泛的网络访问**：广泛的网络访问属性使云客户能够使用云服务，而不会遇到带宽瓶颈。现代技术，如高级路由技术、负载均衡和多站点托管被用来对抗延迟。

*   **资源池化**：云的资源池化特性使云能够通过在设备上进行大量资本投资，然后利用云资产从庞大的云客户群中产生收入，从而保持财务可行性。这种安排还为各种客户提供了放弃大量资本支出、转而选择基于云的订阅的机会。因此，使用云服务可显著减少资本支出，同时增加组织的订阅费用。

*   **快速弹性**：云计算提供可扩展性，使云客户能够根据需求快速扩展或缩减。

*   **可度量服务**：云系统采用按量付费。客户仅为所使用的云资源付费，不收取任何额外费用；这与水、燃气或电力等主要公用事业的概念相似。

### 云部署类型

下文讨论的每种部署类型根据位置考量、定制能力和共享云服务，为用户提供独特的优缺点。因此，有四种基本类型的云部署模型 [36, 37]：

## 云计算部署模型

*   **公有云**：公有云平台是云计算服务最常见的形式。如前所述，所有资源（如软件、硬件、人员和设施）均由云服务供应商管理和拥有，并提供给任何愿意支付这些服务费用的人；因此得名“公有云”。在公有云供应商中，Amazon Web Services、Google 和 IBM 就是几个例子。

*   **私有云**：与传统 IT 环境类似，私有云服务由各个组织拥有和运营，供该组织的客户和/或员工专用。远程访问 Web 连接使得此类平台也可供经批准的外部用户访问。与公有云服务相比，私有云平台通常具有更高的安全措施，因为此类平台仅供组织内部的可信用户访问。使用私有模型的主要优势包括更高的数据隐私和安全性。然而，组织需要花费资金购买实施私有云所需的软件和设备。私有云应用的一个常见例子是内部托管的 SharePoint 站点。

*   **混合云**：混合云由公有云和私有云计算模型的组合构成。该模型的主要优势包括成本效益、更高的安全性和更高的部署灵活性。北美医疗保健行业是有效混合云的一个很好的例子，其中私有云解决方案提供安全性。相比之下，连接到医疗机构、保险提供商和其他相关方的公有云可以提供对潜在救命医疗数据的及时访问 [37]。

*   **社区云**：也称为“亲和云”。采用社区模型时，云平台由具有相似业务目标的亲和群体共享。服务通常主要由亲和群体内部人员或第三方管理。使用社区云模型的主要优势是较小的资本投入。主要缺点是其共享资源。社区云的一个常见实例是游戏社区，如 PlayStation Network [23, 37]。

## 云计算服务模型

除了部署模型外，云计算还通过三种不同的服务模型提供——基础设施即服务 (IaaS)、平台即服务 (PaaS) 和软件即服务 (SaaS)——以满足组织内特定的业务挑战。所有三种模型均根据按使用付费策略部署 [35]。

*   **基础设施即服务 (IaaS)**：IaaS 代表无需物理访问硬件即可托管的数字服务器实例。作为一种即用即付系统，IaaS 平台提供包括存储和虚拟服务器在内的硬件相关资源。在其服务器实例内，授予客户高级管理权限，以及设置其网络安全级别的能力。IaaS 提供使用最新技术的主要优势，从而为用户提供更快的服务访问速度。

*   **平台即服务 (PaaS)**：PaaS 模型提供通过 Web 开发应用程序所需的基础设施和服务 [35]。由于开发人员不必预先确定可扩展性需求，PaaS 模型为应用程序开发人员提供了很大的灵活性和生产力。在互联网上，PaaS 为低成本、可靠和大规模的应用程序增长提供了支持。除了优势之外，PaaS 云技术的主要缺点是用户会经历对特定 PaaS 平台的“锁定”，这使得平台过渡和变更有时变得非常具有挑战性 [38]。

*   **软件即服务 (SaaS)**：SaaS 类型提供所有 IaaS 和 PaaS 功能，以及完全或部分创建的特定软件。SaaS 主要以 Web 应用程序的形式提供，并包含一些 Web 存储或与非远程应用程序的其他网络连接。由于软件和其他组件托管在服务提供商的位置，用户可以通过 Web 浏览器访问软件服务 [35]。

*   **共享责任**：在云计算中，客户和云服务提供商在物理安全、数据安全和控制方面共享责任。共享责任通常被称为客户和提供商之间的“职责分离”，以根据服务类型或部署模型保护服务 [23]。
