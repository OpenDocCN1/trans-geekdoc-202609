### 20.10.1 矩阵补全

#### 矩阵补全

受压缩感知理论进展的启发，文献 [33] 提出了一个性质相似且对实际应用影响深远的问题。给定一个 $l_1 \times l_2$ 的矩阵 $M$，假设其仅有 $N \ll l_1 l_2$ 个条目是已知的。关于符号约定，我们用一般矩阵 $M$ 来指代，而不考虑该矩阵是如何形成的。例如，它可能对应一个图像数组。现在的问题是，能否恢复出完整的精确矩阵。该问题广为人知，称为*矩阵补全* [33]。答案虽可能令人惊讶，但在满足以下条件时，以高概率为“是”：

(a) 矩阵*结构良好*并符合特定假设，

(b) 它具有*低秩*，$r \ll l$，其中 $l = \min(l_1, l_2)$，且

(c) $N$ 足够大。

直观上这是合理的，因为一个低秩矩阵可以用参数个数（自由度）远少于其总条目数的参数来完整描述。这些参数通过其 SVD（奇异值分解）揭示：

```
M = \sum_{i = 1}^{r} \sigma_i \mathbf{u}_i \mathbf{v}_i^{T} = U
\begin{bmatrix}
\sigma_1 & & O \\
& \ddots & \\
O & & \sigma_r
\end{bmatrix}
V^{T},
``` (20.119)

其中 $r$ 为矩阵的秩，$\mathbf{u}_i \in \mathbb{R}^{(l_1)}$ 和 $\mathbf{v}_i \in \mathbb{R}^{(l_2)}$，$i = 1, 2, \dots, r$，分别为左右标准正交奇异向量，张成 $M$ 的列空间和行空间，$\sigma_i$，$i = 1, 2, \dots, r$，为对应的奇异值，$U = [\mathbf{u}_1, \mathbf{u}_2, \cdots, \mathbf{u}_r]$，$V = [\mathbf{v}_1, \mathbf{v}_2, \cdots, \mathbf{v}_r]$。

令 **σ**[*M*] 表示包含 *M* 所有奇异值的向量，即 **σ**[*M*] = [*σ*[1], *σ*[2], ⋯, *σ*[*l*]]^(*T*)。则 *r**a**n**k*(*M*) = ∥**σ**[*M*]∥[0]。统计公式 (20.119) 中与奇异值和奇异向量相关的参数，可知 *r* 秩矩阵的自由度数目等于 *d*[*M*] = *r*(*l*[1] + *l*[2]) − *r*² (问题 20.8)。当 *r* 很小时，*d*[*M*] 远小于 *l*。

令 Ω 表示 *N* 对索引 (*i*, *j*) 的集合，其中 *i* = 1, 2, …, *l*[1]，*j* = 1, 2, …, *l*[2]，这些索引对应 *M* 已知条目的位置，且均匀随机采样而得。采用与稀疏感知学习主干逻辑相似的原理，人们会尝试基于以下秩最小化问题来恢复 *M*：

```
\min\limits_{\widehat{M} \in \mathbb{R}^{l_{1} \times l_{2}}}\left\| \mathbf{\sigma}_{\widehat{M}} \right\|_{0},\text{s.t.}\widehat{M}(i,j) = M(i,j),\quad(i,j) \in \Omega.
```

(20.120)

结果表明，假设存在一个唯一的低秩矩阵，其元素为这些特定的已知条目，则 (20.120) 中的任务能得到精确解 [33]。然而，与稀疏向量的情况相比，矩阵补全问题中的唯一性问题要复杂得多。以下问题对 (20.120) 中任务的唯一性起着至关重要的作用。

1.  **1.** 如果已知条目的数量少于自由度数目，即 *N* < *d*[*M*]，那么无论怎样都无法恢复缺失条目，因为存在无限多个与 *N* 个观测条目一致的低秩矩阵。

##### 2. 即使 *N* ≥ *d*[*M*]，唯一性也无法保证

要求索引在 Ω 中的 *N* 个元素满足：每一列至少观测到一个条目，每一行至少观测到一个条目。否则，即使是秩为一的矩阵 *M* = *σ*[1]**u**[1]**v**[1]^(*T*) 也无法恢复。通过一个简单的例子就能看清这一点。假设 *M* 是一个秩为一的矩阵，且第一列和最后一行没有任何条目被观测到。那么，因为在这种情况下 *M*(*i*, *j*) = *σ*[1]*u*[1*i*]*v*[1*j*]，显然无法获得关于 **v**[1] 的第一个分量以及 **u**[1] 的最后一个分量的任何信息；因此，无论使用何种方法，都无法恢复这些奇异向量分量。结果就是矩阵无法被补全。

另一方面，如果 Ω 的元素是随机选取的，且 *N* 足够大，人们只能希望 Ω 满足上述要求，即以高概率每行每列至少观测到一个条目。事实证明，这个问题类似于概率论中著名的*优惠券收集者*问题。根据该理论，至少需要 *N* = *C*[0]*l*ln *l* 个条目，其中 *C*[0] 是一个常数 [134]。这是任意低秩矩阵精确矩阵补全 [35] 的信息论极限。

##### 3. 即使满足上述要点 (1) 和 (2)，唯一性仍无法得到保证

事实上，并非每个低秩矩阵都能被精确补全，无论观测条目的数量和位置如何。让我们通过一个例子来演示这一点。设其中一个奇异向量是稀疏的。在不失一般性的前提下，假设第三个左奇异向量 `u[3]` 是稀疏的，其稀疏度为 `k = 1`，且其非零分量为第一个分量，即 `u[31] ≠ 0`。其余的 `u[i]` 和所有的 `v[i]` 均假设为稠密向量。

让我们回到公式 (20.119) 中的 SVD 分解。观察到矩阵 `M` 被写为 `r` 个 `l[1] × l[2]` 矩阵 `σ[i] u[i] v[i]^(T)`（`i = 1, …, r`）之和。因此，在 `u[3]` 为 `k = 1`-稀疏的这一特定情况下，矩阵 `σ[3] u[3] v[3]^(T)` 除了第一行之外，其余位置全为零。换句话说，`σ[3] u[3] v[3]^(T)` 为 `M` 的形成所带来的信息仅集中在其第一行中。这一论点也可以从另一个角度来看；除第一行外，从 `M` 的任意一行获得的条目，都不提供关于自由参数 `σ[3]`、`u[3]`、`v[3]` 取值的任何有用信息。因此，在这种情况下，除非引入关于奇异向量稀疏性质的额外信息，否则缺失的第一行条目是不可恢复的，因为涉及该行的参数数量超过了可用数据的数量。

直观上讲，当一个矩阵拥有稠密奇异向量时，它更适合精确补全，因为每一个观测条目都携带了与完全描述该矩阵的全部 `d[M]` 个参数相关的信息。为此，已经建立了一些用于评估奇异向量适用性的条件。其中最简单的是以下条件 [33]：

```
\| \mathbf{u}_{i} \|_{\infty} \leq \sqrt{\frac{\mu_{B}}{l}},\quad\| \mathbf{v}_{i} \|_{\infty} \leq \sqrt{\frac{\mu_{B}}{l}},\ i = 1,\ldots,r,
```

(20.121)

其中 $\mu_B$ 是一个界参数，为简化起见，我们假设 $l_1 = l_2 = l$。实际上，$\mu_B$ 是矩阵 $U$ 连贯性的度量（$V$ 同理）(162)。

```
\mu(U) ≔ \frac{l}{r}\max\limits_{1 \leq i \leq l}\left\| P_{U}\mathbf{e}_{i} \right\|^{2},
```

(20.122)

其中 $P_U$ 定义了到子空间 $U$ 的正交投影，$\mathbf{e}_i$ 是规范基的第 $i$ 个向量。注意，当 $U$ 由 SVD 得出时，则 $\|P_U\mathbf{e}_i\|² = \|U^T\mathbf{e}_i\|²$。本质上，连贯性是一个指数，用于量化奇异向量与标准基 $\mathbf{e}_i$ ($i = 1, 2, \dots, l$) 的相关程度。$\mu_B$ 越小，奇异向量越不可能是“尖峰状”的，相应的矩阵就越适合精确补全。确实，为简化起见，假设为方阵 $M$，即 $l_1 = l_2 = l$，如果奇异向量中*任意一个*是稀疏的，仅有一个非零分量，那么考虑到 $\mathbf{u}_i^T\mathbf{u}_i = \mathbf{v}_i^T\mathbf{v}_i = 1$，该值的大小将等于 1，且界参数将取其可能的最大值，即 $\mu_B = \frac{l}{r}$。另一方面，$\mu_B$ 可能取得的最小值是 1，这发生在*所有*奇异向量的分量取相同值（在大小上）时。注意，在这种情况下，由于归一化，该公共分量值的大小为 $\frac{1}{\sqrt{l}}$。更复杂的非连贯性性质 [33,151] 和强非连贯性性质 [35] 能得出更紧的矩阵连贯性界。在所有情况下，界参数越大，所需的已知条目数就越多，以保证唯一性。在第 20.10.3 节中，将结合实际应用讨论唯一性的各个方面。

(20.120) 中表述的任务实际应用价值有限，因为它是一个 NP-hard 任务。因此，借用第 9 章使用的论据，$\ell_0$ (伪)范数被其*凸*松弛对应物所取代，即

$$

\min_{\widehat{M} \in \mathbb{R}^{l_1 \times l_2}} \left\| \mathbf{\sigma}_{\widehat{M}} \right\|_1, \quad \text{s.t.} \quad \widehat{M}(i,j) = M(i,j), \quad (i,j) \in \Omega,

$$

![Equation](img/si592.png) (20.123)

其中 $\|\mathbf{\sigma}_{\widehat{M}}\|_1$，即奇异值之和，被称为矩阵 $\widehat{M}$ 的*核范数*，通常记作 $\|\widehat{M}\|_*$。核范数最小化在文献 [74] 中被提出作为秩最小化的凸近似，可转化为半定规划任务。

##### 定理 20.1

*为简化起见，设 $M$ 为一个秩为 $r$ 的 $l \times l$ 矩阵，其中 $r$ 远小于 $l$，且满足 (20.121)。假设我们观测到 $M$ 的 $N$ 个条目，其位置均匀随机采样。则存在正常数 $C$，使得如果*

$$

N \ge C \mu_B² l \ln² l,

$$

![Equation](img/si597.png) (20.124)

*则 $M$ 以至少 $1 - l^{-3}$ 的概率是 (20.123) 中任务的唯一解。*

关于秩需要多小才能将相应矩阵表征为“低秩”矩阵，可能存在歧义。更严格地说，如果 `r = O(1)`，则称矩阵为低秩，这意味着 `r` 是一个常数，不依赖于 `l`（甚至没有对数依赖）。矩阵补全对于更一般的秩情况也是可能的，此时不再使用 (20.121) 中温和的连贯性质，而是调用非连贯性和强非连贯性质 [33,35,87,151] 以获得类似的理论保证。这些替代方案的详细阐述超出了本书的范围。事实上，定理 20.1 体现了矩阵补全任务的本质：以高概率，核范数最小化能够无误差地恢复低秩矩阵 `M` 的所有条目。更重要的是，凸松弛问题所需的条目数 `N` 仅比信息论极限大一个对数因子，如前所述，该极限等于 `C_0 * l * ln(l)`。此外，类似于压缩感知，只要将公式 (20.120) 和 (20.123) 中的要求 `M̂(i, j) = M(i, j)` 替换为 `||M̂(i, j) − M(i, j)||_2 ≤ ϵ` [34]，在噪声存在下的鲁棒矩阵补全也是可能的。此外，矩阵补全的概念也已扩展到张量（例如，[77,165]）。

### 20.10.2 鲁棒 PCA

矩阵补全理论的发展导致了另一个高度重要问题的提出与求解。为此，引入了符号 `||M||_1`，即矩阵的 `ℓ_1` 范数，定义为其条目绝对值之和，即 `||M||_1 = ∑_{i=1}^{l_1} ∑_{j=1}^{l_2} |M(i,j)|`。换句话说，它处理矩阵的方式就像处理一个长向量一样。

现在假设 `M` 表示为一个低秩矩阵 `L` 和一个稀疏矩阵 `S` 之和，即 `M = L + S`。考虑以下凸最小化任务 [36,43,187,193]，通常称为*主成分追踪*（PCP）：

```
min_{L̂,Ŝ} ||σ_M||_1 + λ||Ŝ||_1,
```

(20.125)

s.t. `L̂ + Ŝ = M`，

(20.126)

其中 `L̂` 和 `Ŝ` 均为 `l₁ × l₂` 矩阵。可以证明，求解 (20.125)–(20.126) 中的任务可根据以下定理 [36] 恢复 *L* 和 *S* 两者。

#### 定理 20.2

*PCP 以至少 `1 − c l_max^(−10)` 的概率恢复 L 和 S 两者（**l_max = max(l₁, l₂)**），其中 c 为常数，前提条件为：*

1.  **1.**  *S 的支撑集* `Ω` *在所有基数为 k 的集合中均匀分布。*

2.  **2.**  *S 的非零元素个数 k 相对较小，即* `k ≤ ρ l₁ l₂`*，其中 ρ 为充分小的正常数。*
