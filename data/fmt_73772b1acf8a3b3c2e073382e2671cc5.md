
你可能会好奇为什么在这里引入对数而不是另一个单调递增函数。事实上，为什么不直接使用似然函数本身呢？我们在不证明的情况下说明原因是，`L(y; θ_{j+1}) ≥ L(y; θ_j)`。事实上，任何其他严格凹且单调递增的函数（例如对数函数）具有这种性质。这种凹性和单调性假设意味着似然值序列至少在极限上收敛于原始似然函数的局部极大值。原则上这种收敛并不保证当 `j` 趋于无穷时序列 `θ` 收敛，但在实践中通常如此。在许多情况下，这个局部极大也是全局极大的，且收敛于 MLE。注意，如果输入参数是 MLE，那么它也是输出参数。换句话说，MLE 是函数的固定点（在 `θ_0`，`argmax_x ∫ log L(y;x;θ) f_{X|Y}(x|y=0)`）。

**备注。** 一个可能的捷径是将 (2.37) 的右侧替换为

```
$$\arg\max L(y, E(X|Y=y;_j;\theta))$$
```

这等同于将函数的期望替换为期望。这导致了一个次优解，且与原始版本相比，现在不能保证似然函数的收敛。然而，一个可能的优势是每次迭代所需的精力较少。

### 2.9.2 示例 1：截断指数数据

令 `X_i ~ exp(λ)`，`1 ≤ i ≤ n` 为 `n` 个独立随机变量。对于某些 `T > 0`，令 `Y_i = min{X_i, T}`，`1 ≤ i ≤ n`；这被称为*截断数据*。在给定 `Y_i`（`1 ≤ i ≤ n`）的情况下，假设 `T` 已知但 `X_i` 未知，`λ` 的 MLE 是什么？

```
$L(Y_1,...,Y_n;\lambda) = \prod_{i:Y_i<T} \lambda e^{-\lambda Y_i} \prod_{i:Y_i=T} e^{-\lambda T}$
```

对上述等式取对数，对 `λ` 求导，将所得导数置零，解出 `λ`，并得出 MLE 等于

```
$$\frac{\sum_{i:Y_i<T} Y_i + (n-r)T}{r} = (2.38)
```

> 感兴趣的读者可以在 [11, p. 361] 中找到证明。其中 `r` 是 `Y_i`（`1 ≤ i ≤ n`）中小于 `T` 的观测值数量。这不是典型的例子，因为在这种情况下可以推导出 `T`。然而，`θ_j` 是 `θ_{j-1}` 的函数，`θ_{j-1}` 是 `θ_{j-2}` 的函数，以此类推。对应缺失数据的变量被称为潜变量。

解决方案是使用期望极大化（EM）算法。它不是一种开箱即用的算法，因为它在潜随机变量（记作 `X`）中允许自由度。它有时更多是一个关于艺术和常识的问题，而不是科学问题。

算法本身的运行过程如下：从某个 `θ_0` 开始，生成以下序列 `θ_j, j ≥ 1`，直到实现收敛：

```
$$\theta_{j+1} = \arg max_{\theta} \int x L(y, x;\theta) f_{X|Y=y,\theta_j}(dx), \quad j \ge 0$
```

或者，换之，

```
$$\theta_{j+1} = \arg max_{\theta} E_{X|Y=y,\theta_j}(\log L(y, X;\theta)). \quad (2.37)
```

在过程中，我们在以下步骤中进行描述。首先，令 `y` 为给定数据，并假设它们在过程运行期间不改变。其次，对于参数 `θ` 的任意值，写出完全似然函数的对数。第三，这是期望部分，在给定数据和参数当前值 `θ_j` 的情况下，相对于潜变量找到该函数的期望值（同样对于参数 `θ` 的任何值）。注意，你仍然得到关于参数 `θ` 的函数。最后，这是极大化部分，推导出使该函数最大的参数值 `θ`。从而得到 `θ_{j+1}`。

你可能会好奇为什么在这里引入对数而不是另一个单调递增函数。事实上，为什么不直接使用似然函数本身呢？我们在不证明的情况下说明原因是，`L(y; θ_{j+1}) ≥ L(y; θ_j)`。事实上，任何其他严格凹且单调递增的函数（例如对数函数）具有这种性质。这种凹性和单调性假设意味着似然值序列至少在极限上收敛于原始似然函数的局部极大值。原则上这种收敛并不保证当 `j` 趋于无穷时序列 `θ` 收敛，但在实践中通常如此。在许多情况下，这个局部极大也是全局极大的，且收敛于 MLE。注意，如果输入参数是 MLE，那么它也是输出参数。换句话说，MLE 是函数的固定点（在 `θ_0`，`argmax_x ∫ log L(y;x;θ) f_{X|Y}(x|y=0)`）。

```

## 多变量无约束优化

现在我们转向极大化部分。对 `λ` 求导，令 `λ_1` 为该导数等于零的值。我们得到：

```
$$\frac{\sum_{i:Y_i<T} Y_i + (n-r)T}{r} = \lambda_1 \quad (2.40)
```

由此我们可以容易推导出 `λ_1` 是 `λ_0` 的函数，事实上 `λ_{j+1}` 是 `λ_j` 的函数。特别是：

```
$$\lambda_{j+1} = \frac{\sum_{i:Y_i<T} Y_i + (n-r)T}{r^{(j)}}$$
```

理论告诉我们，无论 `λ_0` 如何，原始似然函数具有唯一的极大值（上文已证明），并且如果保证收敛（此处未论证），那么：

```
$$\lim_{j\to\infty} \lambda_j = \frac{r}{\sum_{Y_i<T} Y_i + (n-r)T}$$
```

即 MLE。也很容易检查出，仅当 `λ_0` 允许 MLE 时 `λ_1 = λ_0`。换言之，MLE 是函数的固定点。

### 2.9.3 示例 2：分布混合

假设对于参数 `p`（`0 ≤ p ≤ 1`）以及 `λ_1, λ_2 > 0`，单个随机变量 `Y` 的密度函数为：

```
$$f_Y(y) = p\lambda_1 e^{-\lambda_1 y} + (1-p)\lambda_2 e^{-\lambda_2 y}, \quad y \ge 0$
```

这是两个指数分布的混合。推广到更多指数分布是显而易见的，为了方便起见，我们保留两个。

让我们考虑数据，使得 `n` 个独立随机变量 `I_i`（`1 ≤ i ≤ n`）满足 `I_i = 1`（如果第一个密度“中奖”决定了 `Y_i` 的来源）或 `I_i = 0`（否则）。这些是独立同分布从参数为 `p` 的伯努利分布的潜变量。

# 数据科学中的连续优化

我们实际上所说的是 `I_i` 的条件边缘分布如下：

```
$P(I_i = 1|(Y_1, \dots, Y_n)) = \frac{p\lambda_1 e^{-\lambda_1 Y_i}}{p\lambda_1 e^{-\lambda_1 Y_i} + (1 - p)\lambda_2 e^{-\lambda_2 Y_i}}, \quad 1 \le i \le n,$
```

(2.41)

`I_i` 的条件期望具有相同的表达式，`1 ≤ i ≤ n`。我们还假设所有指示变量在条件下是相互独立的。注意，条件分布仅由 `Y_i` 定义（尽管在一般情况下 `(Y_1, ..., Y_n)`）。请注意，当我们考虑混合模型时，我们先对第一类型进行采样，然后对值进行采样，但先对值进行采样再对类型进行采样也没有问题。例如，在给定值的情况下，关于类型的抽签需要按照 (2.41) 中陈述的概率进行。

对应的完全似然函数为

```
$L(Y_1, \dots, Y_n, I_1, \dots, I_n; p, \lambda_1, \lambda_2) = \prod_{I_i=1} p\lambda_1 e^{-\lambda_1 Y_i} \prod_{I_i=0} (1 - p)\lambda_2 e^{-\lambda_2 Y_i},$
(2.42)
```

据此推导出极大似然估计（MLE）。具体来说，很容易看出它等于

```
$K\log p + (n-K) \log(1-p) + K\log \lambda_1 - \lambda_1 \sum_{i:I_i=1} Y_i + (n-K) \log \lambda_2 - \lambda_2 \sum_{i:I_i=0} Y_i$,
(2.43)
```

其中 `K` 是满足 `I_i=1` 的 `I_i` 的数量。该似然函数显然在下处取得最大：

```
$p = \frac{K}{n}, \lambda_1 = \frac{K}{\sum_{i:I_i=1} Y_i}, \text{and} \lambda_2 = \frac{n-K}{\sum_{i:I_i=0} Y_i}.$
(2.44)
```

遗憾的是，这不是我们需要解决的最大化问题。然而，这表明使用 `(I_1, ..., I_n)` 作为隐变量集的选择 EM 算法是有前景的。

回想 (2.42) 中给出的完全似然函数的对数实际上是

```
$K\log p + (n-K) \log(1-p) + K\log \lambda_1 - \lambda_1 \sum_{i=1}^n I_i Y_i + (n-K) \log \lambda_2 - \lambda_2 \sum_{i=1}^n (1-I_i) Y_i. (2.45)
```

## 3.1 引言

带有一个等式约束的最简单优化问题是：

```
$$\min_{x \in R^n} \sum_{i=1}^n a_i x_i,$$
```

`st. ∑_{i=1}^n b_i x_i = c,`

`x_i ≥ 0, 1 ≤ n.`

假设 `a_i > 0, b_i > 0 (1 ≤ i ≤ n)`。将其看作一个分配问题，将 `c` 量的资源分配给 `n` 个活动。一个单位活动 `i` 消耗 `b_i` 单位资源。显而易见，尽可能增加 `i^*` 变量，受零的限制。因此，最优解为

```
$x_i = \frac{c}{b_{i^*}} \quad i \neq^*$^*$```

$$\min_{x \in R^n} \sum_{i=1}^n f_i(x_i),$$

`st. ∑_{i=1}^n b_i x_i = c,`
