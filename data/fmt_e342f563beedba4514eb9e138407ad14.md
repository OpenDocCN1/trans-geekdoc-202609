设置参数：

```python
beta = 1.4247
gamma = 0.14286
TS = 1.0
ND = 70.0
SO = 1 - 1e-6
IO = 1e-6
INPUT = (SO, IO, 0.0)
```

定义微分方程：

```python
def diff_eqs(INP, t):
    Y = np.zeros((3))
    V = INP
    Y[0] = - beta * V[0] * V[1]
    Y[1] = beta * V[0] * V[1] - gamma * V[1]
    Y[2] = gamma * V[1]
    return Y
```

```python
t_start = 0.0, t_end = ND; t_inc = TS
t_range = np.arange(t_start, t_end + t_inc, t_inc)
RES = spi.odeint(diff_eqs, INPUT, t_range)
```
