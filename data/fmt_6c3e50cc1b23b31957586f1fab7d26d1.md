## 使用带梯度惩罚的 WGAN 进行图像生成

本章介绍 Wasserstein 生成对抗网络（WGAN）和带梯度惩罚的 WGAN（WGAN-GP），旨在解决 GAN 模型训练中的模式崩塌问题。使用了二次曲线数据集、MNIST、Anime Face 和 CelebA 数据集。针对剪刀石头布数据集实现了一个条件 WGAN-GP，以根据我们的设置生成图像。虽然模型训练时间更长，但本章生成的假图像质量更高。

使用 GAN，我们可以生成逼真的假图像，但由于模型崩溃问题，训练 GAN 模型并不容易。从前几章的项目中我们知道，在大多数 GAN 中，判别器模型 `D` 通常比模型 `G` 更聪明。模型 `D` 很容易分辨出假图像和真图像的区别，而模型 `G` 的能力不足以提升其欺骗模型 `D` 的技巧。在许多 GAN 项目的模型训练中，模型 `D` 的损失函数值会在不到 20 个 epoch 内逐步降至零，而模型 `G` 的损失函数值会升至 6 以上。最终我们会在模型训练结束时遇到模型崩溃问题。通过选择具有不同初始学习率的不同学习率调度器，我们可以调整模型以防止模型崩溃。然而，为每个 GAN 项目调整模型超参数和学习率调度器需要很长时间（数小时甚至数天）。

2017 年，Martin Arjovsky（Arjovsky *et al* 2017）及其同事引入了 WGAN，以稳定模型训练并防止模型崩溃等问题。在 WGAN 中，生成器 `G` 和判别器 `D` 的使用方式与 GAN 中一致。一个区别是在 WGAN 的判别器 `D` 末尾不使用激活函数。判别器 `D` 对数据加载器中一个批次内某张图像的输出是一个实数，其范围可以从负无穷到正无穷 (−∞, +∞)。从一批真实图像 (`X`) 中，我们获得一批一维向量 `D(X)`。一批假图像 `G(Z)` 由潜在空间中维度为 `z_dim` 的一批噪声向量 (`Z`) 生成。使用这批假图像作为输入，模型 `D` 输出另一批一维向量 `D(G(Z))`。模型 `D` 的损失函数是 `D(G(Z))` 的平均值减去 `D(X)` 的平均值，如公式 (4.1) 所示，模型 `G` 的损失函数如公式 (4.2) 所示。

```
$$L_{D}\left( \theta_{d} \right) = \frac{1}{n}\sum\limits_{i = 1}^{n}{D\left( {G\left( z_{i} \right)} \right)} - \frac{1}{n}\sum\limits_{i = 1}^{n}{D\left( x_{i} \right)}$$
```

(4.1)graphic style="width:38.8125em;" xlink:href="bk978-0-7503-6244-3ch4eqn1.gif" position="float"/

```
$$L_{G}\left( \theta_{g} \right) = - \frac{1}{n}\sum\limits_{i = 1}^{n}{D\left( {G\left( z_{i} \right)} \right)}$$
```

(4.2)graphic style="width:38.8125em;" xlink:href="bk978-0-7503-6244-3ch4eqn2.gif" position="float"/

根据 WGAN 论文（Arjovsky *et al* 2017），使用上述损失函数有一个数学条件（1-利普希茨连续性）：模型 `D` 损失函数导数的绝对值应小于 1.0。该条件可以通过将模型 `D` 的权重裁剪在范围 [−0.01, 0.01] 内来满足。然而，在后续的项目 4.1.1 中，WGAN 生成的假图像质量比 DCGAN 更差，即使 WGAN 代码运行了更长时间且使用了更多 epoch。2017 年，Ishaan Gulrajani 及其同事在其论文（Gulrajani *et al* 2017）《Wasserstein GANs 的改进训练》中提出了一种新方法来改进 WGAN。该论文提出了一种替代方法，通过向模型 `D` 的损失函数添加惩罚项来强制执行 1-利普希茨连续性，如公式 (4.3) 所示。这种修改后的 WGAN 称为带梯度惩罚的 Wasserstein GAN (WGAN-GP)。

```
$$L_{D}\left( \theta_{d} \right) = \frac{1}{n}\sum\limits_{i = 1}^{n}{D\left( {\widetilde{x}}_{i} \right)} - \frac{1}{n}\sum\limits_{i = 1}^{n}{D\left( x_{i} \right)\ + \ }\frac{\lambda}{n}\sum\limits_{i = 1}^{n}\left\lbrack \left( {{\mid\mid}\nabla_{{\widehat{x}}_{i}}D{({\widehat{x}}_{i})}\mid\mid_{2} - 1} \right)^{2} \right\rbrack$$
```

(4.3)graphic style="width:38.8125em;" xlink:href="bk978-0-7503-6244-3ch4eqn3.gif" position="float"/

在该公式中，`x[i]` 是数据加载器一个批次中的真实图像，`x̃[i]` 是生成器模型 `G(z[i])` 从噪声向量 `z[i]` 生成的假图像，`x̂[i]` 是 `x[i]` 和 `x̃[i]` 之间的插值，由 `x̂[i] = εx[i] + (1−ε)x̃[i]` 给出，其中 `ε` 是在 0,1) 内均匀分布的随机数，`λ` 是惩罚系数，在 WGAN-GP 论文（Gulrajani *et al* [2017）中被设置为等于 10。在介绍 WGAN-GP 理论之前，我们需要知道如何计算 `∇[x̂[i]]D(x̂[i])`，它是标量函数对向量的梯度。假设我们有一个一维张量 `x = [0, 0.5, 1.5, 2.0]`，并定义一个标量函数 `f` 为张量元素平方和：`f(x) = x[0]² + x[1]² + x[2]² + x[3]²`。函数对向量 `x` 的梯度为 `∇f(x)`，其在 `x = [0, 0.5, 1.5, 2.0]` 处的范数 `∣∣∇f(x)∣∣[2]` 如下所示：

```
$$\nabla f\left( x \right) = \left\lbrack {\frac{\partial f}{\partial x_{0}},\frac{\partial f}{\partial x_{1}},\frac{\partial f}{\partial x_{2}},\frac{\partial f}{\partial x_{3}}} \right\rbrack = \left\lbrack {2x_{0},2x_{1},2x_{2},2x_{3}} \right\rbrack = \left\lbrack {0,1,3,4} \right\rbrack$$
```

graphic style="width:27.75em;" xlink:href="bk978-0-7503-6244-3ch4ueqn12.gif" position="float"/

`∣∣∇f(x)∣∣[2] = (0²+1²+3²+4²)^(1/2) = 5.1`

梯度范数 `∣∣∇f(x)∣∣[2]` 是梯度张量中每一行的欧几里得范数。由于上述梯度张量 `∇f(x)` 中只有一行，因此范数中只有一个元素。范数的每个元素等于该行中梯度每个元素平方和的平方根。从 PyTorch 导入的 `autograd.grad` 类可以在下面的 Extra Cell ONE 中自动完成上述工作。该类实例的输出是一个元组，其中唯一的元素是梯度张量。在类实例输出的末尾使用 `[0]`，我们从元组中提取了梯度张量。根据公式 (4.3) 的最后一部分，以下代码的梯度惩罚为：`λ(5.1−1)² = 168`。
