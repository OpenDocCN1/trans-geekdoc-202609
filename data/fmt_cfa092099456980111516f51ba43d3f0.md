
我们已经证明，自相关序列 `r(k)` 的傅里叶变换 `S(ω)` 是非负的。此外，如果序列 `r(k)` 具有非负的傅里叶变换，则它是正定的，我们总能构造一个以 `r(k)` 为其自相关序列的平稳随机过程（例如 [6, pages 410, 421]）。因此，序列成为自相关序列的充要条件是其傅里叶变换的非负性。

我们刚刚看到了一个随机过程的例子，即白噪声。现在我们将注意力转向通过适当的建模来生成 WSS 过程。通过这种方式，我们将在对应于不同时刻的变量之间引入受控的相关性。我们专注于实数数据的情况，以简化讨论。

自回归过程是最流行和最广泛使用的模型之一。`l` 阶自回归过程，记作 `AR(l)`，通过以下差分方程定义：

其中 `η[n]` 是方差为 `σ[η]²` 的白噪声过程。

与任何差分方程的情况一样，我们从某些初始条件开始，然后通过将输入序列样本代入模型来递归地生成样本。这里的输入样本对应于一个白噪声序列，初始条件设置为零，`u[−1] = … u[−l] = 0`。

无需动用数学知识就能看出，这样的过程不是平稳的。确实，时刻 `n = 0` 与其他所有时刻截然不同，因为它是施加初始条件的时刻。然而，如果相应特征多项式的所有根，

的模小于 1（无输入时对应齐次方程的解趋于零）[7]，则初始条件的影响会渐近地趋于零。此时，可以证明渐近地 `AR(l)` 变为 WSS。这是实践中通常采用的假设，本节其余部分将沿用此假设。注意该过程的均值为零（可自行验证）。

现在的目标变为计算相应的自相关序列 `r(k), k ∈ ℤ`。将方程 (2.138) 两边同乘 `u[n−k], k > 0`，并取期望，可得

```
∑_{i=0}^{l} a_i 𝔼[u_{n-i} u_{n-k}] = 𝔼[η_n u_{n-k}],  k > 0,
```

其中 `a[0] := 1`，即

$$

\sum_{i = 0}^{l} a_i r(k - i) = 0 \tag{2.139}

$$

我们利用了这样一个事实：对于 $k > 0$，有 $\mathbb{E}[\eta[n] u[n - k]] = 0$。确实，$u[n - k]$ 递归地依赖于 $\eta[n - k], \eta[n - k - 1] \dots$，由于这是一个白噪声过程，这些都与 $\eta[n]$ 不相关。请注意，方程 (2.139) 是一个差分方程，只要我们有初始条件就可以求解。为此，将方程 (2.138) 乘以 $u[n]$ 并取期望，得到

$$

\sum_{i = 0}^{l} a_i r(i) = \sigma_{\eta}² \tag{2.140}

$$

因为 $\mathbb{E}[u[n] \eta[n]] = \sigma_{\eta}²$。请注意，$u[n]$ 递归地依赖于 $\eta[n]$，这贡献了 $\sigma_{\eta}²$ 项，以及 $\eta[n - 1], \eta[n - 2] \dots$，这些都与 $\eta[n]$ 不相关。结合方程 (2.140) 和 (2.139) 可得到以下线性方程组：

## 2.5 信息论

本章迄今为止，我们已经了解了一些关于概率论和随机过程的基本定义和性质。同样地，我们现在将重点关注与信息论相关的基本定义和概念。尽管信息论最初是在通信和编码学科的背景下发展起来的，但其应用和使用现已被广泛领域所采纳，包括机器学习。信息论中的概念被用于在参数估计问题中建立用于优化的损失函数，而信息论中的概念也被用于在约束优化任务的背景下估计未知概率分布。我们将在本书后面讨论此类方法。

### 信息论之父

信息论之父是克劳德·埃尔伍德·香农（1916–2001），一位美国数学家和电气工程师。他于 1948 年在《贝尔系统技术期刊》上发表里程碑式论文“通信的数学理论”，奠基了信息论。然而，早在 1937 年，年仅 21 岁的他在麻省理工学院（MIT）攻读硕士学位时，便在其论文中证明了布尔代数的电气应用可以构建并解决任何逻辑、数值关系，从而被誉为数字电路设计理论的奠基人。因此，他也被视为数字计算机之父之一。在第二次世界大战期间，香农为国防工作做出贡献，将密码学从一门艺术转变为一门严谨的科学领域。

正如概率论一样，信息的概念也是我们日常词汇的一部分。在此语境下，如果一个事件对我们来说是未知的，或者其发生概率极低但实际却发生了，则该事件携带信息。例如，如果有人告诉我们撒哈拉沙漠夏天阳光明媚，我们会认为这种陈述相当枯燥无用。相反，如果有人带来撒哈拉沙漠夏天下雪的消息，该陈述包含大量信息，并可能引发关于气候变化的讨论。

因此，试图从数学角度形式化信息的概念，用事件概率的负对数来定义它是合理的。如果事件必然发生，其携带的信息量为零；然而，如果其发生概率很低，则其信息量具有较大的正值。

### 2.5.1 离散随机变量

#### 信息

给定一个取值于集合 `𝒳` 中的离散随机变量 `x`，与任意值 `x ∈ 𝒳` 相关联的信息记为 `I(x)`，定义为

```
I(x) = -log P(x)          (2.145)
```

可以使用任意底数的对数。若选用自然对数，信息以奈特（自然单位）度量；若采用以 2 为底的对数，信息以比特（二进制数字）度量。采用对数函数定义信息也符合常识推理：两个统计独立事件的信息量应等于它们各自单独传达的信息量之和；`I(x, y) = -log P(x, y) = -log P(x) -log P(y)`。

**示例 2.5**

给定一个二元随机变量 `x ∈ 𝒳 = {0, 1}`，假设 `P(1) = P(0) = 0.5`。我们可以将此随机变量视为一个产生并发射两个可能值的源。这两个等概率事件的信息量均为

```
I(0) = I(1) = -log₂(0.5) = 1 bit.
```

现在考虑另一个随机事件源，它生成由 `k` 个二元变量组成的码字。该源的输出可视为一个元素为二值的随机向量，`x = [x₁, …, xₖ]ᵀ`。对应的概率空间 `𝒳` 包含 `K = 2ᵏ` 个元素。如果所有可能值具有相同的概率 `1/K`，则每个可能事件的信息量等于

$I(\mathbf{x}_{i}) = - \log_{2}\frac{1}{K} = k\ \text{bits}.$

![Equation](img/si370.png)

我们观察到，在可能事件数量较大的情况下，每个单独事件的信息量（假设事件等概率）会变大。这也符合常识推理，因为如果信源能发出大量（等概率）事件，那么其中任一事件的发生所携带的信息量，就比只能发出少数可能事件的信源要多。
