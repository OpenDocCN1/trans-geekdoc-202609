
1. **Proposed 4-bit CMOS-ReRAM**: We use the ReRAM model from [272] with uniformly separated resistance values ranging from `1 kΩ` to `5 kΩ`, operating at `200MHz`.

2. **CPU**: The general-purpose processor implementation is based on Matconvnet [227], running on a computer server equipped with `32` cores at `2.4GHz` and `128GB` RAM.

3. **GPU**: The general-purpose GPU implementation is based on a CUDA-enabled graphics card [188] at `1.5GHz`.

4. **State-of-the-art ReRAM-based architectures**: Two existing ReRAM-based architectures [146, 222].

5. **Others**: Conventional CNN networks implemented on Field-Programmable Gate Array (FPGA) [273], CMOS-ASIC [230], and Micro-automata processor [274].

为了展示所提架构的强大性能，我们采用大规模 ImageNet [265] 数据集来分析所提 4 位硬件加速器的精度和性能。首先，模型将一个 `224×224×3` 的 RGB 图像作为第一卷积层的输入，该层具有 `3×3×3×64` 组量化滤波器。随后，应用 `QPooling` 为后续层准备数据。接着，第一个残差块的 `QConv` 层在输入特征与权重之间执行量化卷积，随后进行 `QPooling`。然后，在 `QConv` 后采用 `QBN` 以加速训练。同时，我们在每个 `QConv` 层后采用 `QReLUs` 以稳定流程。对于每个层堆叠，三个级联卷积层配合一个加残差操作构成一个残差块。最后，最后一个 `FC` 层的输出被送入 softmax 层，以生成 `1000` 个类别的概率分布。

# 第 8 章

## 大规模案例研究：压缩感知加速器

### 8.1 简介

用于健康远程监测 [280, 281] 和植入式生物传感器 [282, 283] 等应用的生物医学无线电路对能量敏感。为了延长其服务寿命，在获取原始数据时执行降维至关重要。压缩感知 [284] 是一种信号处理技术，它利用信号稀疏性，使信号能在低于奈奎斯特采样定理采样率的条件下重构。将压缩感知技术应用于生物医学硬件的现有工作，侧重于通过字典学习 [283, 285] 或寻找最稀疏系数的更高效算法 [280, 281, 286] 来实现高效信号重构。然而，这些工作通过改进移动/服务器节点上的重构，而非传感器节点上的数据采集，只能间接减少无线传输的样本数以降低能耗。在本工作中，我们旨在直接在传感器节点上实现高性能信号采集和低采样硬件成本。

### 8.1 简介

在压缩感知中，采样是通过将原始信号向量与线性嵌入矩阵相乘来执行的，这将高维数据向量投影到保留内在信息的低维子空间中。这种简洁的表示被称为低维嵌入。采样矩阵可以是随机的、通用优化的，也可以是针对特定数据集优化的。

随机采样矩阵，如伯努利矩阵或高斯矩阵，虽然更易于构建，但存在两大局限。首先，它们对可恢复性的保证仅是概率性的，因此可能会导致较大的恢复误差。其次，它们的构建独立于所研究的数据，因此无法利用数据集的几何信息。

通用优化采样矩阵，如里德-穆勒码 [287, 288] 或 Puffer 变换 [283]，通过构建互相干度最小化的矩阵，具有确定性的可恢复性。然而，它们仍然独立于感兴趣的数据类型，因此性能无法最大化。

另一方面，数据驱动优化嵌入可以通过额外的学习阶段，利用特定应用中数据集的几何结构，这对于目标数据类型预先确定的生物医学采样硬件尤为有益。由数据驱动优化采样矩阵进行的信号采集能保留更多原始信号的内在信息，从而确保更精确的信号重构和/或更高的压缩比。

大多数现有的数据驱动优化方法仅产生实值嵌入矩阵 [289]。然而，实值采样矩阵的硬件映射比布尔矩阵消耗更多功率。原因在于，对于实值嵌入运算，所需的硬件资源（主要是全加器）与所需精度呈二次方依赖关系，而布尔嵌入映射仅呈线性依赖。因此，布尔采样矩阵更受青睐，因为显著减少的硬件资源有助于提高能效和面积效率。

事实上，随机伯努利矩阵是现有基于 CMOS 实现中为实现低功耗而最广泛使用的采样矩阵 [283, 286, 290]。此外，交叉阵列（或交叉点）结构 [62] 中最近出现的电阻式随机存取存储器（ReRAM）[62, 291] 可为矩阵-向量乘法提供内在结构，从而可能实现线性嵌入的高能效和高面积效率硬件实现。然而，有限的 ReRAM 编程分辨率也倾向于仅将布尔嵌入矩阵映射到 ReRAM 交叉阵列结构中。

因此，采样矩阵的硬件实现面临两难境地。一方面，如果映射数据驱动优化的实值嵌入（如 NuMax [289]）以获得更好的恢复质量，将预期带来巨大的功耗开销。另一方面，如果映射非数据驱动的随机布尔嵌入或布尔里德-穆勒 [287, 288] 嵌入以获得更好的硬件能效，则无法实现高信号恢复精度。这种权衡如图 8.1 所示。图 8.1 还揭示了通过直接截断对 NuMax 进行量化仅在 16 位以上精度下有效，低于该精度将导致显著的性能下降。因此，若无数据驱动优化的布尔嵌入，无法同时实现双方的优势。执行数据驱动布尔嵌入优化的挑战在于，随着大量数据集参与采样矩阵优化，仅有基于实值优化矩阵的凸方法是可行的。
