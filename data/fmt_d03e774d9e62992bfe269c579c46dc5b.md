
考虑一个 *M* 类分类任务的 *N* 个训练点，`(y[n], x[n])`，`n = 1, 2, …, N`。该方法的核心在于一个参数 *k*，这是一个用户定义的参数。一旦选定 *k*，给定一个模式 **x**，将其分配给其 *k* 个最近邻（根据某种度量，如欧氏距离或马氏距离）在训练点中所属类别占多数的那个类别。参数 *k* 不应是 *M* 的倍数，以避免平局。该规则最简单的形式是将模式分配给其最近邻所属的类别，即 `k = 1`。

事实证明，如果 (a) `N → ∞`，(b) `k → ∞`，且 (c) `k/N → 0`，这个概念上简单的规则倾向于贝叶斯分类器。从实际角度来看，这些条件意味着 `N` 和 `k` 必须很大，但 `k` 必须相对于 `N` 相对较小。更具体地说，可以证明分类误差 `P_NN` 和 `P_kNN` 渐近地满足以下界限 [9]：

`P_B ≤ P_NN ≤ 2P_B` (7.27)

适用于 `k = 1` NN 规则，以及

`P_B ≤ P_kNN ≤ P_B + sqrt(2P_NN/k)` (7.28)

适用于更一般的 `k`-NN 版本；`P_B` 是对应于最优贝叶斯分类器的误差。这两个公式非常有趣。以 (7.27) 为例。它表明简单的 NN 规则永远不会产生比最优分类器大两倍以上的误差。如果例如 `P_B = 0.01`，那么 `P_NN ≤ 0.02`。对于这样一个简单的分类器来说，这并不坏。所有这些都在说，如果任务很简单（由 `P_B` 的极低值指示），NN 规则也能做得很好。当然，如果问题不简单且涉及较大的误差值，情况就不是这样了。(7.28) 中的界限表明，对于较大的 `k` 值（当然前提是 `N` 足够大），`k`-NN 的性能趋向于最优分类器。在实践中，必须确保 `k` 不会取接近 `N` 的值，而是保持为 `N` 相对较小的分数。

人们可能会想知道，即使在理论上和渐近意义上，如何能获得接近最优分类器的性能，因为贝叶斯分类器利用了数据分布的统计信息，而 `k`-NN 并不考虑此类信息。原因在于，如果 `N` 是一个非常大的值（因此空间被点密集填充），且 `k` 相对于 `N` 是一个相对较小的数，那么最近邻将位于非常靠近 `x` 的位置。然后，由于所涉及 PDF 的*连续性*，它们的后验概率值将接近 `P(ω_i|x)`，`i = 1, 2, …, M`。此外，对于足够大的 `k`，大多数邻居必须来自给定 `x` 条件下后验概率取最大值的那个类别。

`k`-NN 规则的一个主要缺点是，每当考虑一个新模式时，都必须计算它到所有训练点的距离，然后选择离它最近的 `k` 个点。为此，多年来提出了各种搜索技术。感兴趣的读者可参考 [38] 了解相关讨论。

## 7.6 逻辑回归

在贝叶斯分类中，将模式分配到某一类别是基于后验概率 `P(ω[i]|x)` 进行的。后验概率是通过相应的条件概率密度函数（PDF）来估计的，这通常并非易事。本节的目标是通过 *逻辑回归* 方法直接对后验概率建模。这一名称在统计学界已确立，尽管该模型指的是分类而非回归。这是判别式建模方法的一个典型例子，其中不考虑数据的分布。

此外，我们知道在上述假设下，`g(x)` 由公式 (7.20)–(7.22) 给出；因此，我们可以写出

```
ln(P(ω₁|x)/P(ω₂|x)) = (μ₁ − μ₂)ᵀ Σ⁻¹ x + constants,
```

(7.36)

其中“constants”指所有不依赖于 `x` 的项。换句话说，当描述数据的分布是具有共同协方差矩阵的高斯分布时，后验概率的对数比是一个 *线性* 函数。因此，在 logistic 回归中，我们所做的就是向前迈进一步，采用这种线性模型，而不管底层数据分布如何。

此外，即使数据服从高斯分布，采用逻辑回归公式而不是公式 (7.36) 中的公式可能仍然更可取。在后一种公式中，必须估计协方差矩阵，这相当于 `𝒪(l²/2)` 个参数。逻辑回归公式仅涉及 `l + 1` 个参数。也就是说，一旦我们知道对数比率对 `x` 的线性依赖关系，就可以利用这一先验信息来简化模型。当然，假设高斯假设成立，如果能获得协方差矩阵的良好估计，利用这一额外信息可以得到更有效的估计，即方差更低。文献 [12] 讨论了这一问题。这是很自然的，因为利用了关于数据分布的更多信息。在实践中，事实证明，总体而言，使用逻辑回归比使用线性判别分析（LDA）更稳妥。

参数向量 `θ` 是通过将最大似然（ML）方法应用于训练样本集 `(y[n], x[n])`、`n = 1, 2, …, N`、`y[n] ∈ {0, 1}` 来估计的。似然函数可以写为

```
P(y_1,...,y_N; θ) = ∏_{n=1}^N (σ(θ^T x_n))^{y_n} (1 - σ(θ^T x_n))^{1 - y_n}.  (7.37)
```

确实，如果 `x[n]` 来自类别 `ω[1]`，则 `y[n] = 1`，相应的概率由 `σ(θ^T x[n])` 给出。另一方面，如果 `x[n]` 来自 `ω[2]`，则 `y[n] = 0`，相应的概率由 `1 - σ(θ^T x[n])` 给出。假设连续观测值之间相互独立，似然函数即为相应概率的乘积。

通常，我们考虑由下式给出的负对数似然

### 对数似然代价函数

```
L(\mathbf{\theta}) = - \sum\limits_{n = 1}^{N}\left( y_{n}\ln s_{n} + (1 - y_{n})\ln(1 - s_{n}) \right), \tag{7.38}
```

其中

```
s[n] := \sigma(\mathbf{\theta}^{(T)}\mathbf{x}[n]). \tag{7.39}
```

公式 (7.38) 中的对数似然代价函数也称为**交叉熵**代价函数。通过任何迭代最小化方案（如梯度下降法或牛顿法），对`L(\mathbf{\theta})`关于`\mathbf{\theta}`进行迭代最小化。这两种方案都需要计算相应的梯度，而梯度又基于 Sigmoid 链接函数的导数（问题 7.6）：

```
\frac{d\sigma(t)}{dt} = \sigma(t)\left( 1 - \sigma(t) \right). \tag{7.40}
```

梯度由下式给出（问题 7.7）：

```
\nabla L(\mathbf{\theta}) = \sum\limits_{n = 1}^{N}(s_{n} - y_{n})\mathbf{x}_{n} = X^{T}(\mathbf{s} - \mathbf{y}), \tag{7.41}
```

其中

```
X^{(T)} = [\mathbf{x}[1], \dots, \mathbf{x}[N]],\quad \mathbf{s} := [s[1], \dots, s[N]]^{(T)},\quad \mathbf{y} = [y[1], \dots, y[N]]^{(T)}.
```

Hessian 矩阵由下式给出（问题 7.8）：

```
\nabla^{2}L(\mathbf{\theta}) = \sum\limits_{n = 1}^{N}s_{n}(1 - s_{n})\mathbf{x}_{n}\mathbf{x}_{n}^{T} = X^{T}RX,
```

![Equation](img/si174.png)(7.42)

其中

```
R := \text{diag}\{s_{1}(1-s_{1}),\dots,s_{N}(1-s_{N})\}.
```

![Equation](img/si175.png)(7.43)

注意，因为 $0 < s_{n} < 1$（根据 sigmoid 连接函数的定义），矩阵 $R$ 是正定的（见附录 A）；因此，Hessian 矩阵也是正定的（问题 7.9）。这是凸性的充要条件。^(⁴⁵)

*   **梯度下降**（第 5.2 节）

```
\mathbf{\theta}^{(i)} = \mathbf{\theta}^{(i-1)} - \mu_{i}X^{T}(\mathbf{s}^{(i-1)} - \mathbf{y}).
```

![Equation](img/si177.png)(7.44)

*   **牛顿法**（第 6.7 节）

### 迭代重加权最小二乘法 (IRLS)

```
\mathbf{\theta}^{(i)} = \mathbf{\theta}^{(i-1)} - \mu_{i}R^{(i-1)}X)^{-1}X^{T}(\mathbf{s}^{(i-1)} - \mathbf{y}) = (X^{T}R^{(i-1)}X)^{-1}X^{T}R^{(i-1)}\mathbf{z}^{(i-1)}, \tag{7.45}
```

![Equation](img/si178.png)

其中（可尝试验证）：

## 7.7 Fisher 线性判别

我们现在将重点转向设计线性分类器。换句话说，无论每个类别中的数据分布如何，我们决定利用超平面来划分空间，超平面定义为

```
g(x) = θᵀx + θ₀ = 0
```

![Equation](img/si206.png)(7.54)

我们已经在第 3 章中在 LS 方法的框架内处理了设计线性分类器的任务。在本节中，未知参数向量将通过一条路径来估计，该路径利用了许多与分类相关的重要概念。该方法称为 *Fisher 判别*，并且可以用不同的解释来包装。

因此，它的意义不仅在于其实际用途，还在于其教学价值。在介绍该方法之前，让我们先讨论一些与描述输入模式的特征选择相关的问题，以及一些可以量化所选特征集“优劣”的相关度量。

### 7.7.1 散度矩阵
