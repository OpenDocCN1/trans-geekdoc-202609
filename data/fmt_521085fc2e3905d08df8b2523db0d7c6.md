
`x`[*k*] 使用梯度下降法更新：

```
(5.22) X̃[k + 1] = X̃[k] + λ[k] r[k]
```

`f(X̃[k])` 的梯度是：

```
(5.23) ∇F(X̃) = M̃ X̃ − b̃
```

```
(5.24) -∇F(X̃) = Ỹ - M̃ X̃
```

负梯度是点 `X̃[k]` 的残差，即：

```
(5.25) r_k = Ỹ - M̃ X̃_k
```

其中 `r[k]` 是 `f(X[k])` 的方向点。

设

```
(5.26) f(X̃[k + 1]) = f(X̃[k] + λ[k] r[k])
```

```
f(x_{k + 1}) = 1/2 (X̃_k + λ_k r_k)^T M̃ (X̃_k + λ_k r_k) - (X̃_k + λ_k r_k)^T Ỹ
```

```
1/2 X̃_k^T M̃ X̃_k + λ^2/2 r_k^T M̃ r_k + λ_k X̃_k^T M̃ r_k - X̃_k^T Ỹ - λ_k Ỹ
```

当 `f'(X̃[k]) = 0` 时，关于 `X̃[k]` 和 `r[k]`，通过 (5.16) 和 (5.17)，该函数取得最小值。

```
λ_k = (r_k^T r_k) / (r_k^T A r_k), where X̃ = [x̃_1, x̃_2, ..., x̃_n]^T
```

`X̃[k]` 将作为给定线性方程组的解进行更新。

因此，`X̃[k]` 将在 `n` 次迭代内收敛。可以通过下一个定理证明误差是递减的。

## 定理 2

假设 `M` 是正定矩阵 (PDM)，则 `w[k]` 是由算法生成的误差，`η` 是 `M` 的特征值，其中 `η_max` 和 `η_min` 是最大和最小特征值。那么，使用所提算法第 `k` 次迭代满足以下条件：

(5.24) `||w_{k + 1}||_M ≤ (η_max - η_min) / (η_max + η_min) ||w_k||_M` 处有误（注：根据原文逻辑，译文在此处公式 `(5.24) -∇F(X̃) = Ỹ - M̃ X̃` 对应上下文的梯度关系）。

## 定理 3

梯度下降优化方法满足给定条件：

(5.28) `||w_{k + 1}||_M ≤ (η_max - η_min) / (η_max + η_min) ||w_k||_M`

## 定理 4 [15]

假设 `x̃[n]` 和 `ỹ[n]` 分别是 TFN 左右值的两个收敛序列，使得 `lim_{n→∞} x̃_n → ã` 和 `lim_{n→∞} ỹ_n → b̃`。

假设 `η̃[n]` 和 `ξ̃` 是 TFN 的宽度，定义为 `η̃[n] = |x̃[n] - ỹ[n]|` 和 `ξ̃ = |ã - b̃|`。那么，`lim_{n→∞} η̃_n → ξ̃`。

## 证明

给定 `lim_{n→∞} x̃_n → ã` 和 `lim_{n→∞} ỹ_n → b̃`。

存在 `ϵ > 0` 以及整数 `N[1]` 和 `N[2]`，使得：

```
d(x̃_n, ã) < ϵ/2 for n_1 > N_1 and d(ỹ_n, b̃) < ϵ/2 for n_2 > N_2.
```

那么，我们需要证明 `|d(x̃[n] - ỹ[n], ã - b̃)| < ϵ`。

利用三角不等式，

(5.29) `d(x̃[n], ỹ[n]) ≤ d(x̃[n], ã) + d(ỹ[n], b̃) + d(ã, b̃)`。

公式 (5.29) 给出：

(5.30) `d(x̃_n, ỹ_n) - d(ã, b̃) ≤ d(x̃_n, ã) + d(ỹ_n, b̃) = ϵ/2 + ϵ/2 = ϵ.`

相似地，

(5.31) `d(ã, b̃) ≤ d(x̃[n], ã) + d(ỹ[n], b̃) + d(x̃[n], ỹ[n])`。

公式 (5.31) 可以表示为：

(5.32) `d(ã, b̃) - d(x̃_n, ỹ_n) ≤ d(x̃_n, ã) + d(ỹ_n, b̃) = ϵ/2 + ϵ/2 = ϵ.`

从 (5.30) 和 (5.32)，我们得到：

(5.33) `d(x̃[n], ỹ[n]) - d(ã, b̃) ≤ d(x̃[n] - ã) + d(ỹ[n] - b̃) < ϵ ∀ n > max{N[1], N[2]}`。

这证明了：

(5.34) `d(x̃[n], ỹ[n]) - d(ã, b̃) ≤ ϵ`。

因此，我们得出 TFN 的中心和宽度均收敛。下一节讨论了示例，以演示所提算法及其有效性。
