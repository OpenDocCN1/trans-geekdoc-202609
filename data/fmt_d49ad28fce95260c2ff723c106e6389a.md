### 1.2 预序线性空间与凸锥

图 1.8 尖锥表面的部分（见 [72], 图 4.2])![](img/e4a2e491dbba0df71ab29f149cd5b_24_0.png) 和 `C := {x ∈ C[0, 1] | x(t) ≥ 0 对于所有 t ∈ [0, 1]}` 是尖锥。

凸锥可以被简单地刻画。

**命题 1.1 (见 [72], 定理 4.3])** 实线性空间中的锥 `C` 是凸的，当且仅当对于所有的 `x, y ∈ C`，都有 `x + y ∈ C`（即 `C + C = C`）。

预序与凸锥之间的核心联系在以下内容中建立：

**命题 1.2 (见 [72], 定理 D.3])** 设 `Y` 为实线性空间。

(a) 如果 `≤` 是 `Y` 上的预序，那么集合 `C := {y ∈ Y | 0 ≤ y}` 是一个凸锥。如果此外，`≤` 是偏序，则 `C` 是尖的。

(b) 如果 `C` 是 `Y` 中的凸锥，那么其二元关系 `≤ := {(x, y) ∈ Y × Y | y - x ∈ C}` 是 `Y` 上的预序。如果此外，`C` 是尖的，则 `≤` 是偏序。

图 1.9 偏序锥 `ℝ^n_+`（见 [72], 图 D.1])![](img/e4a2e491dbba0df71ab29f149cd5b_25_0.png) 图 1.10 示例 1.4 (b) 中 `x ∈ C` 的插图（见 [72], 图 D.2])![](img/e4a2e491dbba0df71ab29f149cd5b_25_1.png)

**备注 1.1** 设 `C` 是实线性空间 `Y` 中的凸锥。根据命题 1.2 (a)，对于 `Y` 上的预序 `≤`，对于所有的 `y^1, y^2 ∈ Y`，`y^1 ≤ y^2 ⇔ y^2 - y^1 ∈ C`。如果此外，`C` 是尖的，则根据命题 1.2 (b) 对于偏序也成立。

**定义 1.10** 刻画实线性空间预序的凸锥称为*预序锥*(preorder cone)（或正锥）。刻画实线性空间偏序的尖凸锥称为*偏序锥*

### 1.3 赋范空间

图 1.11 由集合 `S` 生成的锥（见 [72], 图 4.3])![](img/e4a2e491dbba0df71ab29f149cd5b_26_0.png)

**定义 1.11** 设 `S` 是实线性空间的非空子集。集合 `conc(S) := {λ s | λ ≥ 0 且 s ∈ S}` 称为由生成的锥（比较图 1.11）。

如果实线性空间是预序的，则在其对偶空间上也可以引入预序。

**定义 1.12** 设 `Y` 为具有预序锥 `C` 的实线性空间。锥 `C' := {ℓ ∈ Y' | ℓ(y) ≥ 0 对于所有 y ∈ C}` 称为 `C` 的对偶锥（此处 `Y'` 表示 `Y` 的代数对偶）。

尽管赋范空间是书中部分最重要的空间，我们首先从一般的拓扑空间开始。**定义 1.13** 设 `Y` 为非空集。

(a) `Y` 上的拓扑 `𝒯` 定义为满足以下公理的 `Y` 子集集合：

- (i) `𝒯` 中集合的并属于 `𝒯`。
- (ii) `𝒯` 中集合的有限交属于 `𝒯`。
- (iii) `∅ ∈ 𝒯`。

在这种情况下`(Y, 𝒯)` 称为拓扑空间，`𝒯` 的元素称为开集。

(b) 设 `𝒮` 和 `𝒯` 是 `Y` 两个拓扑。`𝒮` 比 `𝒯` *更细*（或称 `𝒯` 比 `𝒮` *更粗*），当且仅当每个 `𝒮`-开集都是 `𝒯`-开集。

(c) 设 `(Y, T)` 为拓扑空间，设 `S` 为 `Y` 的子集，令 `y ∈ Y` 为给定元素。`S` 称为 `y` 的邻域，当且仅当存在开集 `T` 使得 `y ∈ S`。`S` 的所有内部元素的集合称为 `S` 的内部，记为 `int(S)`。集合 `S` 称为闭集，当且仅当 `Y \ S` 是开集。`Y` 的所有与 `S` 相交的闭包元素的集合称为 `S` 的闭包，记为 `cl(S)`。

一个非空预序 `I`，其序关系具有反射性和传递性，称为是有方向的，当且仅当 `I` 中的任意两个元素在 `I` 中都有上界。从方向集 `I` 到非空集 `Y` 的映射称为网，记为 `(y_i)_{i ∈ I}`。拓扑空间 `(Y, T)` 中的网 `(y_i)_{i ∈ I}` 称为收敛于某个 `y ∈ Y`，当且仅当对于 `y` 的每个邻域 `U`，存在 `n ∈ I`，使得对于所有的 `i ≥ n`，都有 `y_i ∈ U`。拓扑空间 `(Y, T)` 中的元素 `y ∈ Y` 称为 `y` 的极限点，当且仅当对于 `y` 的每个邻域 `U` 和每个 `n ∈ I`，都一个 `i ∈ I`。

(e) 拓扑空间 `(Y, T)` 中的非空子集 `S` 称为紧的，当且仅当 `S` 中的网都有极限点。

(f) 设 `(X, S)` 和 `(Y, T)` 为两个拓扑空间。映射 `f : X → Y` 在 `x` 处连续，当且仅当对于 `f(x)` 的每个邻域 `V`，存在 `x` 的邻域 `U`，使得 `f(U) ⊆ V`。`f : X → Y` 在 `X` 上是连续的，当且仅当对于每个 `x ∈ X` 都是连续的。

接下来，我们考虑拓扑空间 `(X, T)`其中 `X` 现在是一个线性空间。在这种情况下，我们要求空间的拓扑和线性结构是兼容的。

**定义 1.14** `Y` 为实线性空间，`T` 为 `Y` 上的拓扑。

(a) `(Y, T)` 称为实线性空间，当且仅当加法和数乘是连续的，即映射 `(x, y) ↦ x + y` 对于 `x, y ∈ Y`，`(α, y) ↦ α y` 对于 `α ∈ ℝ` 和 `y ∈ Y` 分别在 `Y × Y` 和 `ℝ × Y` 上连续。在许多情况下，为了简单，我们用 `Y` 代替 `(Y, T)` 表示拓扑线性空间。

(b) 拓扑线性空间 `Y` 的子集 `S` 称为有界的，当且仅当对于 `0`-邻域 `U`，存在 `λ ∈ ℝ` 使得 `S ⊆ λ U`。

(c) 实拓扑空间 `Y` 的非空子集 `S` 称为完备的，当且仅当 `S` 中的柯西网收敛于 `y ∈ S`（即对于 `S` 中的网 `(y_i)_{i ∈ I}` 如果 `lim_{i,j∈I} (y_i - y_j) = 0`，存在 `y ∈ S` 使得 `lim_{i→∞} y_i`）。

**命题 1.3** 设 `S` 是实拓扑线性空间 `Y` 中的非空凸集。闭包 `cl(S)` 是凸的。对于 `int(S) ≠ ∅`，有：

(a) `int(S) = core(S)`。

(b) `cl(S) = S`。

如果 `S` 不是凸的，`int(S)` 和 `core(S)` 可能不等。例如，对于示例 1.1 中的非凸 `S`，我们得到 `int(S) ≠ core(S)`（比较图 1.5）。

对于适当的范 `‖·‖`（参见 [69], 引理 1.45）。我们得到

`C ⊆ {y ∈ Y | 0 ≤ y ≤ 2c} = {c} + [-c, c] = [c] + ℬ(0, 1) = ℬ(c, 1).`

因此，`ℬ(c,1) ⊆ C`，我们得出 `c ∈ int(C)`。

**定义 1.16** 令 `Y` 为实空间，`X` 为代数对偶空间 `Y'` 的非空子集。

- (a) 对于每一个 `x' ∈ X`，存在一个半范 `p : Y → ℝ`，定义为

`p(y) = |x'(y)| 对于所有 y ∈ Y.`

在 `Y` 上使所有这些线性泛函都连续的最粗拓扑是由 `X` 生成的 `Y` 上的弱拓扑，记作 `σ(Y, X)`（它是 `Y` 上使得属于 `X` 的所有线性泛函均连续的最弱拓扑）。

- (b) 如果 `Y` 带有拓扑，则所有属于 `Y^*` 的线性泛函空间 `Y^*` 称为 `Y` 的拓扑对偶空间。对于 `X = Y^*`，`σ(Y, Y^*)` 简单称为 `Y` 上的弱拓扑。

**定义 1.17** 实正规空间 `(Y, |·|)` 是反射的，如果定义的正则嵌入 `J_Y : Y → Y^{**}`（双对偶空间）是一个实巴纳空间。对于应用，以下断言是重要的（参见 Holmes [64], 第 126–127 页）：

`J_Y(y)(φ) := φ(y) 对于所有 y ∈ Y 和所有的 φ ∈ Y^*.`

反射实正规空间都是完备的，因此它是一个巴纳空间。（参见 Holmes [64], 第 126–127 页）：

**命题 1.5** 实巴纳空间 `(Y, |·|)` 是反射的，当且仅当闭单位球 `ℬ(0, 1)` 是弱紧的。

在此命题中，“弱紧”意味着相对于弱拓扑是紧的。实正规空间中的非空子集是弱紧的，当且仅当它是序列顺序收敛的。为了澄清这一点，我们回顾一下收敛性。

**定义 1.18** 令 `(Y, |·|)` 为实正规空间。`Y` 中的元素序列 `(y_n)_{n ∈ ℕ}` 称为弱收敛到 `y ∈ Y`，当且仅当对于 `Y` 上所有连续线性泛函 `ℓ`：

```
lim_{n → ∞} ℓ(y_n) = ℓ(y).
```

在这种情况下，`y` 称为序列 `(y_n)_{n ∈ ℕ}` 的弱极限。

### 1.3 范数空间

**定义 1.19** 令 `(Y, ‖·‖)` 为实范数空间。`Y` 的非空子集 `S` 称为弱序列紧的，当且仅当 `S` 中的每个序列都包含一个弱收敛子序列，且其弱极限属于 `S`。

在反射巴纳空间中，可以给出非空子集弱紧性的一个简单充分条件（例如，参见 Werner [140], 推理 6.1.9）。

**命题 1.6** 反射巴纳空间中的每个非空凸界子集都是弱序列紧的。

接下来，我们扩展凸泛函的概念。

**定义 1.20** 令 `(X, ‖·‖)` 为实范数空间，令 `S` 为 `X` 的非空凸子集，`f : S → ℝ` 为给定的泛函。如果对于每一个 `α ∈ ℝ`，下水平集 `S_α := {x ∈ S | f(x) ≤ α}` 是凸的，则该泛函 `f` 称为准凸的。

**定义 1.21** 令 `S` 为实线性空间 `X` 的非空子集，`f : S → ℝ` 为给定的泛函。元素 `̄x ∈ S` 称为 `f` 在 `S` 上的*极小点*，当且仅当：

`f(̄x) ≤ f(x) 对于所有 x ∈ S.`

在这种情况下，`̄x` 称为优化问题 `min f(x)` 的*极小解*，泛函 `f(̄x)` 称为优化问题的*极小值*。对于 `S ≠ X`，集合 `S` 称为*约束集*。此外，`̄x ∈ S` 称为优化问题 `max f(x)` 的*极大解*，当且仅当：

`f(x) ≤ f(̄x) 对于所有 x ∈ S,`

在这种情况下，`f(̄x)` 被称为该优化问题的*极大值*。

现在我们给出一个存在至少一个极小点的充分条件（参见 [72], 定理 2.1）。

**定理 1.2** 令 `S` 为反射巴纳空间中的非空凸界子集，`令 f : S → ℝ` 为连续准凸泛函。那么 `f` 在 `S` 上至少有一个一个极小点。

**命题 1.7** 令 `(Y, ‖·‖)` 为实范数空间。通过以下范数 `‖·‖^* : Y^* → ℝ` 定义：

`‖ℓ‖^* = sup_{y ∈ Y} |ℓ(y)| / ‖y‖ 对于所有 ℓ ∈ Y^*,`

`(Y^*, ‖·‖^*)` 是一个实巴纳空间。

范数空间的一大类是希尔伯特空间。

**定义 1.22** 令 `Y` 为实线性空间。

- (a) 映射 `⟨·,·⟩ : Y × Y → ℝ` 称为内积，当且满足以下条件（对于所有的 `x, y, z ∈ Y` 和所有的 `λ ∈ ℝ`）：

  (i) 当 `y ≠ 0` 时，`⟨y, y⟩ > 0`。
  (ii) `⟨x, y⟩ = ⟨y, x⟩`。
  (iii) `⟨λ x, y⟩ = λ⟨x, y⟩`。
  (iv) `⟨x+y, z⟩ = ⟨x, z⟩ + ⟨y, z⟩`。

- (b) 如果 `Y` 带有拓扑，且带有内积 `⟨·,·⟩` 的线性空间是完备的，则 `(Y, ⟨·,·⟩)` 是希尔伯特空间（其范数定义 `‖y‖ := sqrt(⟨y, y⟩)` 对于所有的 `y`）。

**例子 1.5** 对于给定的 `n`，考虑带有内积 `⟨·,·⟩` 的实线性空间 `S^n`。通过 `⟨·,·⟩` 定义的 `S^n` 上的 `⟨·,·⟩`（对于所有的 `A, B ∈ S^n`）：

`⟨A, B⟩ := trace(AB).`

`S^n` 上的对称矩阵集合 `C^n := {A ∈ S^n | A = A^T}` 是一个凸锥。对于应用，`S^n` 上的半正定锥 `C_+ := {A ∈ S^n | A 是半正定的}` 称为半正定锥。

接下来，我们回顾方向导数和子微分。

**定义 1.23** 令 `S` 为实线性空间 `X` 的非空子集，`f : S → ℝ` 为凸函数。对于 `̃x ∈ S` 和 `h ∈ X`，

`f'(̃x)(h) := lim_{λ → 0^+} f(̃x + λ h) - f(̃x).`

存在，`f'(̃x)(h)` 是 `f` 在 `̃x` 处沿 `h` 方向的方向导数。如果极限对于所有的 `h ∈ X` 都存在，则 `f` 在 `̃x` 处是方向可微的（参见图 1.12）。

在定义 1.23 中注意，对于任意序列 `(λ_n)_{n ∈ ℕ}` 且 `λ_n > 0` 对于所有的 `n`，我们有 `̃x + λ_n h ∈ S`。例如，这一性质在 `S` 等于整个空间 `X` 时满足。
