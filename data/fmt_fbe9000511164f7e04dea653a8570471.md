### 拒绝示例

在讨论字符识别问题时（第 8.1 节），建议如果支持胜出类别的证据不够充分，有时允许分类器拒绝分类某个示例。动机非常简单：在某些领域，误分类的惩罚远大于不进行任何分类的惩罚。

寻找说明例子并不困难。因此，分类器拒绝返回精确邮政值的后果是，信件去向必须由人工操作决定。可以肯定，这种手动处理比自动处理昂贵，但并没有过分。另一方面，分类器返回错误值会导致信被发送到错误的地点，这会导致严重的延迟。后者的成本通常远高于“手动”读取的成本。同样，错误的医疗诊断通常比没有诊断更高；缺乏知识可以通过额外的测试弥补，但错误的诊断可能会导致选择危害大于益的治疗方案。

这就是为什么如果支持某一类别的证据不足，分类器有时应该拒绝对某个示例进行分类。在某些机器学习范式中，“证据不足”这一术语很容易定义。例如，在 7-NN 分类器中，有四个邻居倾向于 `pos` 类，而其余三个邻居倾向于 `neg` 类。最终计数为四对三，这种情况似乎“由于太接近而难以胜负”。更一般地说，工程师可以为支持获胜类别的投票票数与支持亚军类别的投票票数之间的最小差异定义一个阈值。

在贝叶斯分类器中，这种技术也容易实现。如果两个最受支持类别的概率之差小于用户指定的最小值，则该示例将由于太模糊而无法分类而被拒绝。在神经网络中，也可以进行类似的操作：比较相应的输出神经元返回的信号——如果没有明确的获胜者，则拒绝分类。

在其他分类器（如决策树）中，拒绝机制的实现就没那么直观，只有通过实现“额外技巧”才能成为可能。

## 拒绝分类的优缺点

偶尔拒绝对示例类别做出决策的分类器，其出错的概率显然更低。难怪它的错误率会较低。事实上，拒绝的示例越多，错误率就越低。但这种谨慎不应过度。错误率降低到接近零看起来是一件好事，但如果这种低率仅通过拒绝分类几乎所有的示例来实现，那么这个分类器就变得不实用了。在这两个方面（低错误率与少数分类）中，哪一个起更重要作用取决于应用的具体情况。

## 11.2 精率和召回率

在某些应用中，负示例远多于正示例。当这种情况发生时，错误率提供的性能描述是有误导性的。要了解为什么，只需考虑所有示例中仅有 2% 是正示例的情况。

精率（Precision）：我们指的是在分类器标记为正类的所有示例中，真阳性 `NTP` 的比例。因此，该值通过以下公式获得：

```
NTP / NFP
```

(11.3) 另一种说法，精率是分类器将示例标记为正类时正确的概率。

召回率（Recall）：指的是正示例被正确识别（通过分类器）的概率。因此，该值通过将真阳性的数量 `NTP` 除以集合中正示例的数量获得：

```
NTP / NFN
```

(11.4) 注意最后两个公式仅分母不同。这是合理的。精率是在所有被分类器认为是正类的示例中真阳性的频率，而召回率是在集合中所有正示例中相同真阳性的频率。

在某些领域，精确率比召回率更重要。例如，当你从电子商务网站购买物品时，他们的推荐系统通常会返回一条这样的信息：“购买过 X 的客户也购买 Y。”其显而易见的意图是诱你也购买 Y。

推荐系统有时是借助应用于公司历史数据的机器学习技术创建的。¹ 在评估它们的性能时，工程师希望实现高精确率。客户最好对推荐商品感到满意，否则他们将来将忽略这些建议。

在这里，召回率的价值并不重要。网站提供的列表规模是有限的，因此系统只识别出客户可能喜欢的所有物品中的一小部分并没有大碍。

### ROC 曲线

在许多分类器中，调整某些参数可以修改 `NFP` 和 `NFN` 的值，从而影响（至少在某种程度上）分类器的行为，例如，以牺牲精确率为代价提高召回率，反之亦然。这种可能性在用户对这两个量中哪个更重要有想法的领域是很有用的。

读者会发现很容易提出各种进行“调整”的方法。因此，在 `k-NN` 分类器中，工程师可能会要求除非有非常强的证据支持正类标签，否则将样本标记为负类。例如，如果七个最近邻居中有四个是正类，可以指示分类器返回负类标签（尽管少数多数推荐正类）。通过这种方式，可以减少假阳性的数量，尽管这通常意味着要付出假阴性数量增加的代价。通过要求除非七个最近邻居中至少五个（或六个）是正类，否则认为任何样本均为负类，可以更进一步地减少 `NFP`（并增加 `NFN`）。

类似的方法在贝叶斯分类器和神经网络中很容易实现。想法是相同的：除非强证据表明该决策错误，否则使用首选类标记。

分类器在不同参数值下的行为可以通过所谓的 ROC 曲线来可视化，ROC 是一种图，横轴代表负类的错误率，纵轴代表正类的准确率。两个分类器 `c1` 和 `c2` 的示例 ROC 曲线如图 11.2 所示。理想情况下，我们希望到达负类错误率为零且正类准确率为百分之百左角。由于各种原因，这很少实现。

## 在 Fβ 中结合精确率和召回率

使用两个不同的（有时是相互矛盾的）性能标准可能会很别手；用一个单一数字来量化事物是符合人的本性的。特别是在精确率和召回率的情况下，人们已经尝试将两者合并为一个量。最为人知的此类公式 `Fβ` 的定义如下：

```
Fβ = (β² * Pr * Re) / (β² * Pr + Re) 
```

参数 `β` 允许用户权衡这两个标准的相对重要性。如果 `β > 1`，则赋予召回率更大的权重。如果 `β < 1`，则赋予精确率更大的权重。很容易证明，当 `β→∞` 时，`Fβ` 收敛于召回率，当 `β→0` 时，收敛于精确率。很多时候，工程师并不真正知道精确率和召回率哪一个更重要，以及重要多少。在这种情况下，她倾向于使用参数的中性值 `β=1` 进行工作。

```
Fβ = (2 * Pr * Re) / (2 * Pr + Re)
```

### 数值示例

假设对测试集上的分类器的评估结果如表 11.2 上部所示。对于这些结果，表格分别确定的精确率和召回值为 `Pr=0.40` 和 `Re=0.29`。使用这些数字，我们将针对参数的以下设置（`β=0`、`β=1` 和 `β=5`）计算 `Fβ`。

```
F0 = (0² * 0.40 * 0.29) / (0² * 0.40 + 0.29) = 0
F0.2 = (0.2² * 0.40 * 0.29) / (0.2² * 0.40 + 0.29) = 0.036
F1 = (1² * 0.40 * 0.29) / (1² * 0.40 + 0.29) = 0.33
F5 = (5² * 0.40 * 0.29) / (5² * 0.40 + 0.29) = 0.70
```

## 敏感性和特异性

具体标准的选择通常受给定应用领域的影响——其特定的需求和根深蒂固传统不应被忽视。因此，医学领域已经习惯通过敏感性（Sensitivity）和特异性（Specificity）来评估其“分类器”（不一定由机器学习开发）的性能。本质上，这些量仅仅是分别在正样本和负样本上测量的召回率。让我们更具体一点：

敏感性是在正样本上测量的召回率：

```
Se = TP / (TP + FN)
```

特异性是在负样本上测量的召回率：

```
Sp = TN / (TN + FP)
```

在机器学习的文献中，基于敏感性和特异性进行评估非常罕见，但意识到这两个标准仍然是有好的。毕竟，在将机器学习应用于医学数据时，我们可能会被要求使用它们——而且客户才是最终的老板。

## Gmean

在类别表示不平衡的领域中引入分类器时，工程师有时希望在 `pos` 和 `neg` 两个类别上实现相似的性能。在这种情况下，使用两个分类准确率（正样本上的准确率和负样本上的准确率）的几何平均值 `gmean`：

```
gmean = sqrt(accpos * accneg)
```

请注意，`gmean` 实际上是两个数字乘积的平方根：正样本上的召回率和负样本上的召回率——换句话说，就是敏感性和特异性的乘积。

`gmean` 最重要的方面可能是，它不仅取决于根号符号下两个项的具体值 `accpos` 和 `accneg`，还取决于它们之间的接近程度。

在本节中，我们将对学习成本进行一些思考——包括成功归纳所需的示例数量，以及所消耗的计算时间。另一个方面，即归出一个具有高分类性能工具的能力，将在下一节中讨论。
