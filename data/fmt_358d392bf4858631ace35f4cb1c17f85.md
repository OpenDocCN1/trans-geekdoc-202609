## 2.1 引言

对于女性来说，当今世界上常见的诊断疾病之一是乳腺癌。乳腺癌发生在乳腺细胞组织发生异常时。这些异常细胞在乳腺表面内部形成肿瘤。虽然临床乳腺检查可以检测肿瘤，但检测率往往很低，且使用传统技术发现异常区域具有很大的挑战性。因此，机器学习技术可以帮助医生发现肿瘤的存在，从而加速治疗过程。机器学习技术通过乳腺摄影图像，从可疑区域提取特征并进行疾病预测。

卷积神经网络，俗称为 `CNN` [1]，是专家们开发的对整个乳腺摄影图像进行分类以识别癌症的知名技术之一。深度 `CNN` 未开发出一种结合乳腺摄影图像的组合分类器来实现最佳性能。用于乳腺癌分类的升级版 `CNN` 技术已开发 [2]。这一升级版本在提高准确率方面有所增强。然而，在该技术中，时间复杂度完全没有降低。

另一种用于识别或挖掘乳腺癌图像特征的改进技术是卷积稀疏自编码器（`CSAE`）[3] 技术。然而，在疾病风险准确预测方面的效率尚未得到解决。此外，还引入了一种具有三个输出和 `CNN` 分割的新型混合特征提取方法 [4] 来寻找乳腺癌。但这种新设计的方法识别乳腺癌需要更多时间。

一种带有深度学习方法的多分类支持向量机（`MSVM`）被引入自动乳腺摄影检测中 [5]。该方法未能以较短的时间复杂度准确验证海量数据集。随机森林的一种分类算法被引入到 [6] 中用于预测癌症的因素，但疾病预测中的错误率并未降低。为了对与乳腺癌相关的图像进行分类，开发并引入了集成的 `CNN` 和 `LSTM` [7]。然而，这种集成设计模型在提高其分类性能方面并没有取得很大成功。多层感知器编码网络（`CNMP`）技术与深度学习方法结合 [8]，用于提取特征的医学图像分类，但这种多层技术也未能达到预期的分类准确率。

开发了一种端到端多级算法 [9] 以提高分类过程的准确率。然而，该算法在类分类过程中未能成功降低 `FPR`。因此，设计了一种新型卷积神经网络和小型 `SE-ResNet` 组件 [10] 的组合，用于进一步分类乳腺癌图像。但与上述技术类似，这种新的增强技术也未能实现训练误差最小化。

## 2.2 相关工作文献综述

一种带有弹性网络的支持向量机分类器（`EnSVM`）在 [11] 中被用于预测患者的乳腺癌风险，但并未为了准确预测进行特征提取。一种卷积方法在 [12] 中被开发，通过图像分类检测乳腺癌。在考虑大型训练样本时，乳腺癌的检测时间并未最小化。一种新方法被引入 [13] 利用局部配置模式特征从超声图像中寻找乳腺病变。该方法未能在大规模数据库中找到图像的准确分类。

离散正交 S 变换（`DOST`）创新技术被引入一种二维方法中，从数字驱动的乳腺摄影图中挖掘 [14] 特征用于乳腺癌识别。它未能减少检测乳腺癌的时间。深度学习方法在 [15] 中被开发用于乳腺癌检测。尽管学习方法提高了准确率，但时间复杂度并没有降低。

引入 [16] 的深度学习方法用于识别。尽管如此，准确率没有提高。一种堆叠稀疏自编码器（`SSAE`）被引入 [17]，利用高层特征高效检测癌症，但准确率尚未达到最低错误率。尽管卷积方法 [18] 用于识别乳腺摄影图像和乳腺癌图像，但它在最小化特征提取时间方面尚未取得预期成功。

深度卷积先进技术用于 [19] 通过深度特征识别乳腺癌。时间复杂度问题仍然存在。一种双轮廓变换和改进的 `KNN` 被开发 [20] 用于分析乳腺摄影并获得更高的乳腺癌诊断准确率。然而，其 `FPR` 未如预期那样最小化。

使用机器学习过程提取图像的技术由 Barisoni 等引入，允许通过生物学和临床同性疾病类别识别患者风险。假阳性率再次未得到解决。

通过开发一种名为 Coiflet 小波特征提取深度学习（`CWFE-DL`）的新型集成分类技术克服了现有综述的问题。下一节将介绍 `CWFE-DL` 技术的要概述及必要的图表。

## 2.3 基于 Coiflet 小波特征提取的深度学习

乳腺癌始终是一种致命疾病，准确发现可以拯救人类生命。为了预防癌症，预测正常组织以及异常或癌症组织都更为重要。因此，为了预测肿瘤等疾病，对身体这些区域成像有助于医生进行类似的预后。这种创新的机器学习方法选择特定部分并更可靠地收集它们，并预测组织的损伤。所提方法以图表形式所示图 2.1。

**图 2.1** CWFE-DL 概述.

`CWFE-DL` 方法的概述能够以更高的精度从输入图像中预测肿瘤。该技术包括三个过程，即图像采集、特征提取和分类。乳腺图像是在数字数字化乳腺摄影数据库中收集的 `i[1]`、`i[2]`、…… `i[n]`。之后，从输入图像中去除无关部分，高质量的图像即为准确分类的结果。使用 Coiflet 小波变换从输入的乳腺图像中提取尺寸、形状、纹理、颜色和边缘的特征，用于预测疾病。特征提取被用于在早期识别恶性部分。最后，使用 `DN` 对提取的特征进行分类，并以较低的复杂度进行预测。

### 2.3.1 基于 Coiflet 小波变换的特征提取

所提出的 `CWFE-DL` 技术通过特征提取，以最短的时间预测正常图像和异常图像。特征提取是一种降维技术，当图像尺寸较大时它非常有用。所提出的 `CWFE-DL` 技术使用 Coiflet 小波变换进行图像特征提取。原始图像被视为 Coiflet 小波，分解为低频（L）和高频（H）子带。Coiflet 小波变换的层级如图 2.2 所示。

**图 2.2** Coiflet 小波变换的层级

在第一级变换中，输入图像被分解为两个频率级。

```
y = x(t) * g(t−k) (2.1)
```

在方程 (2.1) 中，`y` 表示最细层变换的输出，`x(t)` 表示输入图像，`g(t)` 表示低通滤波器。在第二级变换中，图像通过 2 进行分解并获得四个子带 {`LL`、`LH`、`HL`、`HH`}。使用以下公式评估低级通过和高级通过的滤波：

```
y[L] = x(k) * g(2t−k) (2.2)
```

```
y[H] = x(k) * h(2t−k) (2.3)
```

在 (2.2) 和 (2.3) 中，`y[L]` 表示低级滤波器的输出，`y[H]` 表示高级滤波器，`g` 表示低通滤波器（即缩放函数），高通滤波器为 `h`（小波函数），`2t` 表示由 2 进行分解。在执行分解后，每个子带的小波系数行为对于在多分辨率层级上提取特征至关重要。此外，不同分解层级上每个子带中小波系数的统计行为对于特征提取是必要的。Coiflet 小波系数的数学表达式如下：

```
β[r] = (-1)^(r) * D[m−1−r] (2.4)
```

在 (2.4) 中，`β` 表示 Coiflet 小波系数，`r` 表示系数索引，`D` 表示缩放函数（即低通滤波器），`m` 表示小波索引。该系数从输入图像中提取特征，以以极低的时间复杂度进行乳腺癌预测。

**输出：** 提高分类准确率

**开始**

**特征提取与深度学习技术**

### 2.3.2 深度学习

为了检测恶性血液疾病特别是检测癌症，神经网络和机器学习技术在医疗保健领域证明了创新的性能。因此，这种新技术吸引了研究人员利用深度学习技术进行医学图像分析。在癌症相关疾病中，乳腺癌仍然是女性死亡的主要原因。尽管在美国等国家，通过乳腺摄影筛查方法减少了此类死亡，但这些死亡仍是不可避免的。在这种筛查方法中，他们发现了许多高假阳性以及高假阴性病例。通常美国这种筛查的特异性和敏感性分别为 88.9% 和 86.9%，导致预测癌症变得困难。因此，在 20 世纪 90 年代需要提高这种筛查过程的准确水平。

#### 2.3.2.1 机器学习的增强技术

`CNN` 是机器学习技术的增强版本。识别医学图像的最优方法是通过计算机视觉。这种 `CNN` 技术由不同的层组成，用于提取和处理显著特征。专家为 `CNN` 的工作制定了四个主要步骤。`CNN` 的处理如图 2.3 所示。

**图 2.3** CNN 的处理

1.  **带有卷积技术操作的 ReLU 函数激活**

    卷积操作技术旨在通过应用特征检测器来保持与像素的独特关联，从而找到怀疑图像的现有特征。在这种方法中，ReLU 函数的激活用于打破图像的线性，由于其具有高度非线性的特征，需要增强其非线性。

2.  **池化（Pooling）**

    下采样操作之一是池化技术。由于这种方法中的参数很少，该技术减少了采样的维度、计算量以及过拟合。这种方法对畸变和变化更具容忍性。

3.  **展平（Flattening）**

    展平技术用于在进一步处理之前对单维矩阵的输出进行池化。

4.  **全连接层连接**

    在第四步中，展平输出的进一步处理被馈入神经网络，这是上述层的全连接形式。这些层被进一步用于深度分类和识别此类医学图像。
