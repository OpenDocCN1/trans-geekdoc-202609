#### 对象

你编写的大多数程序至少涉及一个由程序创建或操作的事物。该事物及操作它的操作统称为**对象**。

例如，编写程序测试四位代码访问复印机的有效性，并给出有效性规则。对象是四位代码。操作该对象的操作可包括 `readNumber`、`getSeparateDigits`、`testValidity` 和 `writeNumber`。

一个程序可包含多种类型的对象。例如，维护图书馆所有书籍数据库的程序至少包含两个对象：

1. **`Book` 对象**，包含 `getTitle`、`getAuthor`、`isOnShelf`、`isFiction`、`goOutOfPrint` 等操作。
2. **`ListOfBooks` 对象**，包含 `search`、`addBook`、`removeBook`、`sortByAuthor` 等操作。

对象由其**状态**（或**属性**）和**行为**刻画。例如，书的状态由标题、作者、是否在架上等描述；行为包括去印刷等。

注意，对象是一种概念，独立于编程语言的具体细节。它对应程序所代表的现实世界对象。

所有面向对象编程语言都有在程序中将对象表示为变量的方式。在 Java 中，代表对象的变量称为**对象引用**。

#### 类

**类**是实现给定类型对象的软件蓝图。在面向对象编程中，对象是类的单个**实例**。

对象的当前状态保存在其**数据字段**或**实例变量**中，由类提供。类的**方法**提供对象展现的行为及操作对象的操作。将对象的数据和方法组合成称为类的单一单元，称为**数据封装**。

#### Public、Private 和 Static

类声明前的关键字 `public` 表示该类可被所有**客户端程序**使用——即类外部使用该类的代码片段。若类非 `public`，仅限其所在包内的类使用。在 AP Java 子集中，所有类均为 `public`。

同理，**公共方法**可被所有客户端程序访问。但客户端不知类实现细节，不可访问类的私有实例变量和私有方法。Java 使用关键字 `private` 实现访问限制。**类的私有方法和变量仅能被该类的方法访问。** 虽然 Java 允许公共实例变量，但 AP Java 子集中所有实例变量均为私有。

**静态变量**（类变量）包含由该类所有实例共享的值。“静态”意为内存仅分配一次。

静态变量典型用途：

- 记录类对象的统计信息。
- 累计总计。
- 为类的每个新对象提供新标识号。
