
```
p(yi|xi, zi = k, θ) = N(yi|w_k^T xi, σ_k²)   (11.8)
p(zi|xi, θ) = Cat(zi|S(V^T xi))   (11.9)
```

有向图模型见 Figure 11.3(a)。

该模型称为**专家混合模型**或 **MoE**（Jordan and Jacobs 1994）。其思想是每个子模型被视为输入空间某个区域的专家。函数 `p(zi|xi, θ)` 称为**门控函数**，根据输入值决定使用哪个专家。例如，Figure 11.2(b) 展示了三个专家如何划分一维输入空间，Figure 11.2(a) 展示了每个专家单独的预测（在本例中，专家只是线性回归模型），而 Figure 11.2(c) 展示了使用以下公式获得的模型总体预测：

```
p(yi|xi, θ) = ∑_{k=1}^K p(zi = k|xi, θ) p(yi|xi, zi = k, θ)   (11.10)
```

### 11.4 EM 算法

#### 11.4.1 简介

对于机器学习和统计学中的许多模型，如果我们观测到所有相关随机变量的值，即拥有**完全数据**，则计算 ML 或 MAP 参数估计很容易。然而，如果我们有缺失数据和/或潜在变量，则计算 ML/MAP 估计变得困难。一种方法是使用通用的基于梯度的优化器来寻找 `NLL(θ)` 的局部最小值。然而，我们通常必须强制执行约束，例如协方差矩阵必须是正定的、混合权重必须求和为 1 等，这可能比较棘手。在这种情况下，使用一种称为**期望最大化**的算法通常简单得多（但并不总是更快），简称 **EM**（Dempster et al. 1977; Meng and van Dyk 1997; McLachlan and Krishnan 1997）。这是一种在存在缺失或隐藏数据时计算 ML 或 MAP 估计的高效迭代算法，通常在每一步都有闭式更新。此外，该算法会自动强制执行所需的约束。有关本书中 EM 应用的总结，请参见表 11.2。

#### 11.4.2 基本思想

总之，EM 算法的伪代码如下：

EM 算法利用了这样一个事实：如果数据被完全观测，则 ML/MAP 估计很容易计算。特别是，EM 算法的每次迭代包含两个过程：**E 步**和**M 步**。

*   在 **E 步** 中，给定观测数据和当前的模型参数估计，推断缺失数据。这是通过条件期望实现的，这解释了术语的由来。
*   在 **M 步** 中，假设缺失数据已知，最大化似然函数。从 E 步推断出的缺失数据被用来代替实际的缺失数据。

令 `xi` 为情况 `i` 中的可见或观测变量，令 `zi` 为隐藏或缺失变量。目标是最大化观测数据的对数似然：

```
ℓ(θ) = log p(D|θ) = ∑_{i=1}^N log p(xi|θ) = ∑_{i=1}^N log ∑_{zi} p(xi, zi|θ)   (11.11)
```

不幸的是，这很难优化，因为对数不能推入求和内部。

EM 通过以下方式解决此问题。定义**完全数据对数似然**为：

```
ℓc(θ) = ∑_{i=1}^N log p(xi, zi|θ)   (11.12)
```

这无法计算，因为 `zi` 未知。因此让我们定义**期望完全数据对数似然**如下：

```
Q(θ, θ^{t-1}) ≜ E_{z|D,θ^{t-1}} [ℓc(θ)] = E[ℓc(θ)|D, θ^{t-1}]   (11.13)
```

其中 `t` 是当前迭代次数。`Q` 称为**辅助函数**（推导见第 11.4.9 节）。期望是针对旧参数 `θ^{t-1}` 和观测数据 `D` 计算的。**E 步**的目标是计算 `Q(θ, θ^{t-1})`，或者更确切地说，计算 MLE（或 MAP）所依赖的其中的参数；这些被称为**期望充分统计量**或 **ESS**。在 **M 步** 中，我们针对 `θ` 优化 `Q` 函数：

```
θ^t = arg max_θ Q(θ, θ^{t-1})   (11.14)
```

# EM 算法

为了执行 MAP 估计，我们按如下方式修改 M 步：

**输入**：观测数据 `D = {x1, x2, ..., xN}`，联合分布 `P(x, z | θ)`

**输出**：模型参数 `θ`

```text
// 1. 确定隐变量 z，写出对数似然函数 ℓ(x, z | θ)
θ(0) = ... // 初始化

while (!convergency) do
    // 2. E 步：代入 P(x, z | θ)，推导 Q(θ, θ^(t-1)) 的公式
    Q(θ, θ^(t-1)) = E[ℓc(θ) | D, θ^(t-1)]

    // 3. M 步：寻找使 Q(θ, θ^(t-1)) 取得最大值的 θ
    θ^t = arg max Q(θ, θ^(t-1))
          θ
end
```

**算法 3**：EM 算法

下面我们将解释如何针对几个简单模型执行 E 步和 M 步，这应该能让事情更清晰。

#### 11.4.3 高斯混合模型的 EM 算法

##### 11.4.3.1 辅助函数

```math
Q(θ, θ^(t-1)) = E_{z|D, θ^(t-1)}[ℓc(θ)]
             = E_{z|D, θ^(t-1)}[∑_{i=1}^N log p(x_i, z_i | θ)]
             = E_{z|D, θ^(t-1)}[∑_{i=1}^N log ∏_{k=1}^K (π_k p(x_i | θ_k))^{I(z_i=k)}]
             = ∑_{i=1}^N ∑_{k=1}^K E[I(z_i = k)] log[π_k p(x_i | θ_k)]
             = ∑_{i=1}^N ∑_{k=1}^K p(z_i = k | x_i, θ^(t-1)) log[π_k p(x_i | θ_k)]
             = ∑_{i=1}^N ∑_{k=1}^K r_{ik} log π_k + ∑_{i=1}^N ∑_{k=1}^K r_{ik} log p(x_i | θ_k)  (11.16)
```

其中 `r_{ik} ≜ E[I(z_i = k)] = p(z_i = k | x_i, θ^(t-1))` 是簇 `k` 对数据点 `i` 承担的**责任度**。这在下面描述的 E 步中计算。

```math
θ^t = arg max Q(θ, θ^(t-1)) + log p(θ)  (11.15)
      θ
```

##### 11.4.3.2 E 步

E 步保持不变。E 步具有以下简单形式，对于任何混合模型都相同：

```math
r_{ik} = p(z_i = k | x_i, θ^(t-1)) = \frac{p(z_i = k, x_i | θ^(t-1))}{p(x_i | θ^(t-1))}  (11.17)
       = \frac{π_k p(x_i | θ_k^(t-1))}{∑_{k'=1}^K π_{k'} p(x_i | θ_{k'}^(t-1))}
```

##### 11.4.3.3 M 步

在 M 步中，我们针对 `π` 和 `θ_k` 优化 `Q`。对于 `π`，将仅依赖于 `π` 的项归类在一起，我们发现需要最大化 `∑_{i=1}^N ∑_{k=1}^K r_{ik} log π_k`。然而，存在一个额外约束 `∑_{k=1}^K π_k = 1`，因为它们代表概率 `π_k = P(z_i = k)`。为了处理该约束，我们构建拉格朗日函数：

```math
L(π) = ∑_{i=1}^N ∑_{k=1}^K r_{ik} log π_k + β(∑_{k=1}^K π_k - 1)
```

其中 `β` 是拉格朗日乘子。求导后，我们得到：

```math
π_k = \frac{∑_{i=1}^N r_{ik}}{N}  (11.18)
```

这对任何混合模型都适用，而 `θ_k` 则取决于 `p(x | θ_k)` 的形式。

对于 `θ_k`，将概率密度函数代入公式 11.16：

```math
Q(θ, θ^(t-1)) = ∑_{i=1}^N ∑_{k=1}^K r_{ik} log π_k - \frac{1}{2} ∑_{i=1}^N ∑_{k=1}^K r_{ik} [log |Σ_k| + (x_i - μ_k)^T Σ_k^{-1} (x_i - μ_k)]
```

对 `Q` 分别求 `μ_k`、`Σ_k` 的偏导数并令其等于 0，可得：

```math
\frac{∂Q}{∂μ_k} = -\frac{1}{2} ∑_{i=1}^N r_{ik} [(Σ_k^{-1} + Σ_k^{-T})(x_i - μ_k)]
               = -[Σ_k^{-1}(x_i - μ_k)] ∑_{i=1}^N r_{ik} = 0
⇒ μ_k = \frac{∑_{i=1}^N r_{ik} x_i}{∑_{i=1}^N r_{ik}}  (11.19)
```

```math
\frac{∂Q}{∂Σ_k} = -\frac{1}{2} ∑_{i=1}^N r_{ik} [\frac{1}{Σ_k} - \frac{1}{Σ_k²} (x_i - μ_k)(x_i - μ_k)^T] = 0
⇒ Σ_k = \frac{∑_{i=1}^N r_{ik} (x_i - μ_k)(x_i - μ_k)^T}{∑_{i=1}^N r_{ik}}  (11.20)
```

```math
= \frac{∑_{i=1}^N r_{ik} x_i x_i^T}{∑_{i=1}^N r_{ik}} - μ_k μ_k^T  (11.21)
```

##### 11.4.3.4 算法伪代码

**输入**：观测数据 `D = {x1, x2, ..., xN}`，GMM

**输出**：GMM 的参数 `π, μ, Σ`

```text
// 1. 初始化
π⁰ = ...
μ⁰ = ...
Σ⁰ = ...
t = 0

while (!convergency) do
    // 2. E 步
    r̂_{ik} = \frac{π_k p(x_i | θ_k^(t-1))}{∑_{k'=1}^K π_{k'} p(x_i | μ_{k'}^(t-1), Σ_{k'}^(t-1))}

    // 3. M 步
    π̂_k = \frac{∑_{i=1}^N r̂_{ik}}{N}
    μ̂_k = \frac{∑_{i=1}^N r̂_{ik} x_i}{∑_{i=1}^N r̂_{ik}}
    Σ̂_k = \frac{∑_{i=1}^N r̂_{ik} (x_i - μ̂_k)(x_i - μ̂_k)^T}{∑_{i=1}^N r̂_{ik}}
    t++
end
```

##### 11.4.3.5 MAP 估计

和往常一样，MLE 可能会过拟合。在 GMM 的情况下，过拟合问题尤为严重。一个简单的解决方案是执行 MAP 估计。新的辅助函数是期望完全数据对数似然加上对数先验：

```math
Q(θ, θ^(t-1)) = ∑_{i=1}^N ∑_{k=1}^K r_{ik} log π_k + ∑_{i=1}^N ∑_{k=1}^K r_{ik} log p(x_i | θ_k)
              + log p(π) + ∑_{k=1}^K log p(θ_k)
```

使用共轭先验是很自然的。

```math
p(π) = Dir(π | α)
p(μ_k, Σ_k) = NIW(μ_k, Σ_k | m_0, κ_0, ν_0, S_0)
```

根据公式 3.28 和第 4.6.3 节，MAP 估计由下式给出：

```math
π_k = \frac{∑_{i=1}^N r_{ik} + α_k - 1}{N + ∑_{k=1}^K α_k - K}  (11.23)
μ_k = \frac{∑_{i=1}^N r_{ik} x_i + κ_0 m_0}{∑_{i=1}^N r_{ik} + κ_0}  (11.24)
Σ_k = \frac{\bar{S}_0 + S_k + \frac{κ_0 r_k}{κ_0 + r_k} (\bar{x}_k - m_0)(\bar{x}_k - m_0)^T}{ν_0 + r_k + D + 2}  (11.25)
```

其中 `r_k ≜ ∑_{i=1}^N r_{ik}`，`\bar{x}_k ≜ \frac{∑_{i=1}^N r_{ik} x_i}{r_k}`，`\bar{S}_k ≜ \frac{∑_{i=1}^N r_{ik} (x_i - \bar{x}_k)(x_i - \bar{x}_k)^T}{r_k}`。

#### 11.4.4 K-means 的 EM 算法

##### 11.4.4.1 表示

```math
y_j = k \text{ if } \| x_j - μ_k \|_2² \text{ is minimal}  (11.26)
```

其中 `μ_k` 是簇 `k` 的质心。

##### 11.4.4.2 评估

```math
\arg \min_{μ} ∑_{j=1}^N ∑_{k=1}^K γ_{jk} \| x_j - μ_k \|_2²  (11.27)
```

隐变量是 `γ_{jk}`，其含义为：

```math
γ_{jk} = \begin{cases}
1, & \text{if } \| x_j - μ_k \|_2² \text{ is minimal for } μ_k \\
0, & \text{otherwise}
\end{cases}
```

##### 11.4.4.3 优化

**E 步**：

```math
γ_{jk}^{(i+1)} = \begin{cases}
1, & \text{if } \| x_j - μ_k^{(i)} \|_2² \text{ is minimal for } μ_k^{(i)} \\
0, & \text{otherwise}
\end{cases}
```

**M 步**：

```math
μ_k^{(i+1)} = \frac{∑_{j=1}^N γ_{jk}^{(i+1)} x_j}{∑_{j=1}^N γ_{jk}^{(i+1)}}  (11.28)
```

##### 11.4.4.4 技巧

**选择初始质心（种子）**

1. **K-means++**。这种方法背后的直觉是：将 `k` 个初始簇中心分散开是件好事：第一个簇中心从正在聚类的数据点中均匀随机选择，之后每个后续簇中心从剩余数据点中选择，选择概率与该点到其最近的现有簇中心的平方距离成正比。具体算法如下：

   a. 从数据点中均匀随机选择一个中心。

   b. 对每个数据点 `x`，计算 `D(x)`，即 `x` 与已选最近中心之间的距离。

   c. 以加权概率分布随机选择一个新数据点作为新中心，其中点 `x` 被选中的概率与 `D(x)²` 成正比。

   d. 重复步骤 2 和 3，直到选出 `k` 个中心。

   e. 既然初始中心已选定，便使用标准 K-means 聚类继续进行。
