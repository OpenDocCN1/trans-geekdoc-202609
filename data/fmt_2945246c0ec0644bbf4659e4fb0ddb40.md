
例如，如果一个政府想确保在与另一国家发生敌对行动时拥有优势，他们可能会在为工业过程控制和公用事业市场开发的商业 SCADA 软件中植入特洛伊木马、后门或其他恶意代码。一旦敌对行动开始，嵌入软件中的攻击即可发动，从另一国家的“棋盘”上移除宝贵资产。2010 年针对伊朗核工业的 Stuxnet 攻击和 2020 年针对美国联邦机构的 SolarWinds 信息收集攻击，便是此类网络战略的典型案例。

基于此原因，每个国家（及其工业和公用事业组织）都应将任何外国生产或受外国影响的软件视为潜在的国家安全威胁。从战略上讲，这意味着每个组织的采购流程必须评估外国生产软件相关风险，并与本国开发同类产品的经济性进行权衡。

在战术层面，建议由多名程序员对所有外来软件代码进行同行评审和测试。此外，应尽可能使用多种不同的扫描工具扫描这些软件包，以查找嵌入软件中的危险或不必要代码。Microsoft 提供安全代码分析工具包，而 Snyk 在 `https://snyk.io` 提供免费源代码检查器。最后，在评估信息安全时，应强制执行行业标准，例如 ISO 15408 通用准则标准（可在 `www.iso.org/standard/50341.html` 找到）。

## 未授权访问

未授权访问被定义为：使用未获许可的访问方法（如他人账户或攻击者创建的账户），获取对资产（建筑物、办公室、机器、服务器、网站、服务、文件夹或文件）的访问权限。在网络安全术语中，这也被称为灰帽或黑帽黑客行为。

未授权访问涉及外部和内部网络攻击方法。外部攻击涉及在网络上无合法权限的个人（尽管也涉及目标网络内部用户主动或被动串通发起的攻击）。最常见的外部访问攻击基于拥有或猜测有效用户的弱凭证、被盗凭证或丢失凭证。然而，基于通过恶意软件攻击获取的凭证的攻击也相当常见。远程访问、无线连接和调制解调器拨号攻击代表了另一种常见的外部访问攻击面。

另一方面，未授权内部访问攻击由拥有一定级别合法网络访问凭证的入侵者发起。这些访问可能由未获资产权限的 IT 人员、在网络中拥有高权限的非 IT 员工，或使用他人被盗凭证的合法人员发起。

本章以下各节将描述各种未授权访问攻击方法。

### 密码攻击

密码攻击均属于密码破解、密码填充和密码重用这些统称范畴。密码破解的目标是在原本不知正确密码的情况下，成功通过密码提示进行身份验证。密码攻击可使用不同方法以多种方式执行：

* 暴力破解攻击
* 彩虹表
* 密码捕获
* 凭证填充
* 密码喷射
* 密码重用

## 密码攻击与无线攻击

### 暴力破解攻击

暴力破解攻击涉及使用工具（如 `John the Ripper`、`ophcrack` 或 `hydra`）针对用户登录运行密码列表。这些工具在企业环境中被合法用于测试员工密码，但攻击者也经常使用这些相同的工具进行同样的操作。

密码列表通常由各类安全人员生成，包含常用密码及其各种变体。在暴力破解攻击中，攻击者利用算力对提供的密码列表中的每个密码进行哈希计算。这可能耗费大量时间。因此，当预期目标使用短小、简单的密码时，这种攻击方法最为适用。

然而，彩虹表可提供一种更优雅高效的密码攻击方法。这些是预生成的表格，包含数百万个已哈希的密码。由于大多数主机系统都包含哈希密码文件，因此可以将其与彩虹表提供的哈希内容进行比对，以期找到匹配的密码。

### 密码捕获

密码捕获，有时也称为凭据收集，是一个非常直接的过程。攻击者必须以某种方式在密码发送过程中将其拦截。一种常见的实现方式是通过中间人攻击或网络钓鱼。

此类攻击最常用的工具是本章前面所述的社会工程学工具包软件。如图 5.29 所示，该软件包含多种不同的模块，可用于执行不同类型的攻击。凭据收集模块使用简单。它通过克隆一个选定的热门网站（或使用提供的网站），然后利用 `Apache` 进行托管。

![FIGURE 5.29 The Social Engineering Toolkit](img/c05f029.png)

**图 5.29 社会工程学工具包**

当受害者被引导至攻击机器的 IP 地址时，他们将看到克隆的网站并输入用户名和密码，这些信息随即会显示在 SET 终端上。随后软件会将他们重定向到实际网站，使其看起来就像只是密码输入错误。与此同时，攻击者已获取其用户名和密码，可随意利用。

要进一步升级该攻击，可将凭据收集攻击与 DNS 投毒攻击结合，将网站的 DNS 查询定向至攻击机器。这种组合攻击可使用名为 **Ettercap** 的软件工具实现。

在这种组合攻击中，受害者每当输入 `mywebsite.com`（或所用的任何网站）时，都会被定向至攻击者的网站。若不使用 Ettercap，攻击者就需要设法将攻击机器的 IP 地址提供给受害者。

### 字典攻击

字典攻击就是一种系统性的暴力破解攻击，使用字典中的每个单词作为密码。互联网上有许多预编译的字典文件和彩虹表来源，提供可用于攻击目标的用户名/密码组合。某些黑客工具（如 `Kali Linux`）也提供准备好的用户名/密码列表，可编辑后直接针对指定目标使用。

目前可用的最大此类列表是多次泄露汇编（COMB）数据库文件，包含超过 32 亿组唯一的 UN/PW 凭据。这些数据收集自全球过去的账户泄露事件，约占当前全球在线人口的 70%。当然，厂商默认的 UN/PW 组合也包含在内，且人们会在不同账户间复用相同密码。该数据库还包含用于运行攻击、查询邮箱和管理数据的 `bash` 脚本。

通过限制给定时间段内的登录尝试次数，即可轻松防御此类攻击。此外，可在该时段内禁止超过特定尝试次数的用户 IP 地址，直到管理员解除封禁。

击败字典攻击的另一种方案是强制实施严格的密码策略，要求密码不仅仅是字典单词。垃圾邮件发送者常利用此类攻击猜测电子邮件账户密码，以获取账户访问权限并用于垃圾邮件分发。

互联网上有一些公开网站（如 Cybernews 个人数据泄露检查器 `https://cybernews.com/personal-leak-check`），提供已知泄露凭据的信息。应定期查询这些网站，以确保当前使用的 UN/PW 组合未被泄露。

如前所述，会话劫持是通过窃取用户合法互联网会话中的 Cookie 来获取其计算机未授权访问权限的方法。这些 Cookie 用于向远程服务器验证计算机身份，并常规存储在用户计算机上以提供网页快速访问。

攻击者可使用数据包嗅探器捕获网络传输中的 Cookie 来窃取。若能通过欺骗手段访问受害者 PC（使其误信接收的代码来自受信服务器），也可从中窃取 Cookie 信息。一旦攻击者获得 Cookie 信息，即可访问其他特权信息。

使用多因素认证技术和工具，可确保即使攻击者持有 UN/PW 凭据也无法进入系统。此外，使用密码管理器可采用强密码凭据，从而有效管理用户。

### 无线攻击

由于通信方式的特性，无线攻击可能与有线网络攻击截然不同。用户必须将设备物理连接到网络端口才能接入有线网络，因此物理上靠近网络介质至关重要。而对于无线网络，这种物理邻近性则不那么重要。攻击者和合法用户一样，都可以坐在大楼前的停车场连接无线网络。

这种距离变量可通过各种创造性方法放大，例如使用罐天线（自制铁罐波导天线），如图 5.30 所示。该设备使无线客户端能连接到比 Wi-Fi 通信预期距离远得多的网络。攻击者可舒适地坐在车内，从安全距离发起攻击。

**图 5.30 罐天线**

正如有线网络安全一样，无线网络安全至关重要。由于无线网络更容易遭到窃听和数据包捕获，加密和安全通信的需求更为迫切。此外，利用弱加密漏洞仅需几秒钟。以下章节将深入探讨无线通信常见的被利用方式。

#### 战争驾驶

战争驾驶是在人口密集区域步行或驾车搜寻开放或弱加密无线网络的过程。这通常是道德黑客侦察阶段的首批活动之一。

许多组织不太担心无线网络信号覆盖其建筑物和园区边界之外。

## 无线网络安全

### 无线网络发现工具

有许多可用的工具来捕获无线网络信息。这些工具包括软件，如 `NetStumbler`、`inSSIDer` 和 `Kismet`，如图 5.31 所示。此类工具能够从无线网络捕获各种数据。此外，许多“寻网族”会向 `WiGLE` 等在线数据库贡献数据，这些数据库追踪并记录他们捕获的数据信息，其中最令人担忧的是某个区域内各个 `SSID` 所使用的加密类型。

跟踪无线网络在公共场合能被发现多远非常重要。不幸的是，要防止网络信号泄漏到公共区域可能非常困难。不过，根据网络需要的安全程度以及所包含的信息类型，研究限制传输距离的方法以防止无线网络辐射过远可能是值得的。

“寻网”也是完全合法的。这相当于记录门牌号或收听广播电台。在大多数情况下，监听设备不会与网络通信；它们仅收集数据。也有人认为，如果你不想让你的网络信息被收集，你大概就不应该广播它！

### 非法接入点

非法接入点可能是一个非常危险的漏洞。然而，在大多数情况下，它们并非蓄意恶意。当无线技术刚开始普及、尚不像现在这样随处可用时，非法接入点往往更为常见。

无法接入 `Ethernet` 端口（或在其位置需要多个 `Ethernet` 端口）的员工可能会被诱导设置非法接入点以方便工作，却不知应配置何种安全设置，也不知这违反了公司政策。

然而，有时非法接入点是由不法分子或渗透测试人员设置的，目的是入侵网络。例如，这些不法分子之一可能设法进入组织的空置会议室，并在他们的网络上设置一个非法接入点。然后，他们只需坐在停车场就能窥探网络、收集信息，或花时间尝试入侵工作站。

一旦攻击者进入网络，其可能性就变得无穷无尽。用户和网络都会遭到破坏，任何类型的攻击都可能发生，从 `DDoS` 攻击到利用各种漏洞。

### WPA 密钥破解

为了将无线局域网安全受损的风险降至最低，电气电子工程师学会 (`IEEE`) 组织在 `IEEE-802.xx` 旗下监督一组无线网络规范。`IEEE 802.11x`（也称为 `Wireless Fidelity` 或 `Wi-Fi`）无线标准已被广泛接受，成为企业和住宅网络应用的首选无线网络技术。

使用它们传输个人或其他敏感信息存在许多安全问题。无线网络设备的传输无法简单地局限于住宅或企业的本地环境。虽然大多数无线网络设备的范围通常限制在几百英尺内，但 `RF` 信号即使在声明的安全边界之外也很容易被拦截。任何未经授权的移动终端都可以使用 `802.11` 接收器做到这一点。

无线网络安全最广泛使用的协议是 `Wi-Fi Protected Access` (`WPA`) 标准、`WPA2` 标准 (`IEEE 802.11i`) 和 `WPA3` 标准协议。

`WPA` 协议旨在改进早期已变得易受破解攻击的 `Wi-Fi` 标准。它通过首先验证网络用户，然后提供更强大的加密技术来确保通过它传递的消息的完整性，从而实现了这一点。它是与 `802.11g` 和 `802.11i` 网络标准一起使用的协议。

`WPA` 协议可以在 `WPA-PSK` 模式（又称 `Pre-Shared Key` 或 `WPA-Personal` 模式）下运行。在个人模式下，预共享密钥或口令用于身份验证。`PSK` 选项允许 `WPA` 使用 `预共享密钥`，而不需要单独的 `证书颁发机构` (`CA`) 计算机来提供用户身份验证。`PSK` 允许在路由器上设置密码并与其他用户共享。

`WPA2` 提供了一种更强的加密方法，其中加密密钥会自动更改（称为 `重新生成密钥`），并在 `指定的一段时间后`，或在传输了指定数量的数据包后，在设备之间进行身份验证。此方法使用一个口令（也称为 `共享密钥`），必须在无线接入点/路由器和 `WPA` 客户端中输入。从技术上讲，此共享密钥长度可以在 8 到 63 个字符之间，并可以包含特殊字符和空格。

`WPA` 和 `WPA2` 都采用 `临时密钥完整性协议` (`TKIP`) 和 `IEEE 802.1x` `可扩展认证协议` (`EAP`) 进行数据加密，以为无线网络提供身份验证和安全性。此组合要求用户使用用户名和密码访问网络。用户登录后，`接入点` (`AP`) 会生成一个临时密钥，用于加密 `AP` 和客户端设备之间的数据传输。

`WPA` 和 `WPA2` 攻击基本上分三个步骤进行：嗅探、解析和凭证破解。在嗅探阶段，`Wi-Fi` 传输会由无线网络适配器已配置为混杂模式操作的设备进行扫描。在解析过程中，扫描的数据由数据包分析器（如 `Wireshark`）处理，以检查传输数据包中的数据，寻找连接握手序列，特别是寻找包含 `PTK 认证` 信息的数据包（使用 `EAPOL` 过滤器）。四次握手过程如图 5.32 所示，展示了 `PTK` 密钥的交接。

一旦找到密钥，你可以尝试解密它们，但这需要大量时间和计算能力。相反，黑客只需使用破解工具对密钥运行字典/暴力攻击。在 `Linux` 中可用的主要工具包括 `John the Ripper`、`Aircrack-ng` 或 `Pyrit/coWPAtty` 组合。在 `Microsoft Windows` 环境中，`Aircrack-ng` 和来自 `Elcomsoft` 的 `Wireless Security Auditor` 套件是领先工具，但价格可能相当昂贵。

为了缓解此类活动并保护信息免受 `WPA2` 漏洞的影响，建议采用额外的加密方法，如 `HTTPS` (`SSL` 或 `TPS`)，为传输增加一层额外的安全性。用户在使用任何公共 `Wi-Fi` 网络工作时也应使用 `VPN`。无论使用 `HTTP` 还是 `HTTPS` 协议，`VPN` 都会加密所有数据。

![FIGURE 5.32 WPA four-way handshaking](img/c05f032.png)

**图 5.32** WPA 四次握手

此外，在所有无线客户端安装并认证后，将 `服务集标识符` (`SSID`) 广播选项设置为禁用，以防止外部人员利用 `SSID` 获取接入点的地址和数据。此外，将 `SSID` 名称从默认值更改为其他值。

如果在服务器机房等安全区域内使用无线网络技术，应采取额外的 `物理加固` 措施来保护机房安全。这可能包括对机房架构进行物理加固，例如对服务器机房的天花板、地板和墙壁进行电气隔离，以防止无线信号泄漏。这通常通过某种形式的 `法拉第笼` 或 `法拉第屏蔽` 来完成。

## 最新的 WPA 版本 (WPA3)

最新的 WPA 版本 (`WPA3`) 采用了一种名为 `Device Provisioning Protocol` (`DPP`) 的高级连接协议，该协议将连接过程自动化，使其不再依赖共享密码。相反，它使用一种称为同时认证平等 (`SAE`) 的技术，取代了 PSK 模式四次握手连接中使用的共享密钥。此注册过程发送网络注册指令，而无需传输密码。这些消息可以采用二维码或 NFC 标签的形式，以认证设备并授予其网络访问权限。

WPA3 的加密方式与 WPA 和 WPA2 有很大不同，使得 KRACK 攻击和字典攻击等旧式攻击方法失效。它使用 256 位 Galois/Counter Mode Protocol (`GCMP-256`) 加密代码，将生成破解该代码所需的所有计算可能性所需的计算次数提高到超过 1 x10⁷⁷ 次。WPA3 包含 384 位哈希消息认证模式加密，用于在密钥在路由器和连接设备之间传递时对其进行加密。

## 802.11 信标泛洪

无线接入点定期广播 `beacon frames`（信标帧），让附近的客户端知道它们正在广播哪些网络。这些帧还包含无线设备连接到 AP 所需的相关信息，例如 SSID 和 `beacon intervals`（信标间隔），以及可用于将本地时钟设置为网络时间以进行认证的 `timestamps`（时间戳）。

接入点采用信标间隔来确定信标之间的时间量。增加信标间隔会减少发送的信标数量。相反，减小间隔会增加发送的信标数量。

有许多工具可供黑客利用信标及其漏洞。其中一种工具是 `MDK3`。如图 5.33 所示，该实用程序支持多种不同的攻击，包括信标泛洪和取消认证攻击，以及其他 DoS 攻击。

![FIGURE 5.33 MDK3](img/c05f033.png)

**图 5.33** MDK3

`MDK3` 可以发起信标泛洪攻击，如图 5.34 所示，通过为某个网络广播伪造的信标数据包。例如，命令：

```
mdk wlan1 b -n mynetwork -n -t -c 6 -s 70
```

将导致 `mdk3` 对 `mynetwork` 发起信标泛洪攻击（`b` 标志），该网络是一个无线 N 网络（`n` 标志），在信道 6 上使用 TKIP 安全协议（`-c 6`），并将以每秒 70 个数据包的速度发送（`-s 70`）。一旦发起攻击，尝试连接到 `mynetwork` 网络的设备将无法连接，直到攻击停止。

## 802.11 取消认证泛洪

另一种无线攻击类型是取消认证泛洪攻击，通常称为 `deauth attack`（取消认证攻击）。取消认证攻击涉及攻击者向接入点发送一个 `deauthentication packet`（取消认证数据包），进而将所有连接到该接入点的设备踢下线。有许多不同的工具可用于执行此攻击，如前所述的 `MDK3`，以及更常用的 `aireplay-ng` 工具。

如果出于任何原因想阻止客户端连接到无线接入点，取消认证攻击会很有用。例如，经验不足的系统管理员可能会尝试将加密方式更改为安全性较低的方式，希望解决接入点的问题。另一方面，他们可能只是简单地禁用 AP。

## 密码学

`Cryptography`（密码学）是一个用于描述保护信息和为数据提供不可否认性的概念和方法的术语。许多密码技术涉及密钥的使用。密钥仅仅是一个用于加密或解密信息的数据字符串。密钥的使用方式以及字符串的长度都会影响加密的强度。
