
# 术语表

## 通用术语

### A

**动态数据**
: 通过有线或无线网络传输的数据过程。

**使用中的数据**
: 正在被创建、更新、检索或删除的数据。

**死区**
: IPC 设定点上下的不活动带。也称为中性区或死区。

**取消认证洪水攻击**
: 一种网络攻击，攻击者向接入点发送取消认证数据包，进而移除所有先前已认证的连接设备。

**解密**
: 将先前加密的数据转换回其原始形式的过程。使用相关密钥将加密的密文解锁为明文以便理解的过程。

**解密密钥**
: 用于解密秘密代码的密钥。

**专用控制系统**
: 一种独立的过程控制系统类型，采用单个控制器来监控和控制单个过程或一组紧密集成的过程。

**深度包检测 (DPI)**
: 检查 TCP/IP 数据包中的实际数据，搜索病毒、垃圾邮件和其他已定义威胁的迹象，以确定是否应转发该数据包的过程。

**纵深防御**
: 一种包含多种不同重叠安全机制的防御策略，可潜在地最小化攻击者攻破单一机制造成的影响。

**分界点**
: 公共交换线路结束并连接到客户网络起始处的点。

**非军事区 (DMZ)**
: DMZ 是一个独立的边界网络，将安全的内部网与外部世界隔离开来，同时允许公众访问面向外部的专用资源。

**拒绝服务 (DoS)**
: 旨在过度使用主机、服务器或网络资源，使其功能上停止提供服务的攻击。

**微分控制**
: 一种将变化率控制因子应用于差值测量百分比变化的控制方案。

**Dynamic Host Configuration Protocol (DHCP)**
: 一种自动寻址协议，使用一系列 IP 地址，可动态租借给请求的外部设备，租期为预配置的时间长度。

**DHCP 服务器**
: 使用网络协议分发网络参数（如 IP 地址）的服务器。参见 Dynamic Host Configuration Protocol。

**DHCP Snooping**
: 内置于操作系统中的一种安全技术，用于过滤和阻止被视为不可接受的入站 DHCP 服务器消息。

### D

**dictionary attack**
: 使用字典中的每个单词作为给定用户名的密码，进行系统性的暴力破解攻击。

**digital certificates**
: 数字验证，用于确认加密消息的发送者就是其声称的身份。

**digital video recorders (DVRs)**
: 监控摄像头的首选录制系统类型（而非 VCR）。DVR 技术允许将 CCTV 图像传输到磁盘，减轻了劣质视频存储介质带来的负面影响。

**direct-attached storage**
: 一种通过 `USB` 或 `eSATA` 连接将额外的磁盘驱动存储设备直接连接到 DVR 的技术。

**directory harvest attacks (DHAs)**
: 垃圾邮件发送者猜测某域名下的电子邮件地址，然后连接到该域名的邮件服务器的过程。未被拒绝的地址被视为有效地址。

**directory traversal**
: 就攻击而言，目录遍历利用软件或 Web 应用程序访问本不应访问的文件。这是通过遍历到更高级别的文件夹或目录来完成的。

**disaster recovery plan (DRP)**
: 计划本身是为成功的灾难恢复做准备的第一要素。它应包含构成系统中每个网段的所有组件的完整清单，以及构成每台服务器和工作站的所有组件。这包括所有需要恢复的相关软件。

**discretionary access control (DAC)**
: 用户可自行决定谁有权访问其对象以及访问程度的配置。

**discretionary access control list (DACL)**
: 对象或用户对网络中特定资源拥有的权限列表。

**disk-level encryption**
: 使用技术加密整个磁盘结构的过程。该技术可保护磁盘上的所有内容免遭未经授权的访问，包括操作系统文件和结构（无论是静止状态还是传输状态）。

**distorting proxy**
: 隐藏或修改您的 IP 地址及相关信息的代理服务器。

**distributed control system (DCS)**
: 一种智能控制系统，它使用分布在整个过程中的多个自主控制器来处理许多控制回路，无需监控控制器的协调。不过，DCS 可与远程监控和监督系统协同运行。当流程过于复杂，单个控制器无法处理，或其组件在地理上分离时，就有必要将控制功能分配到多个控制器上以形成 DCS。

**distributed denial-of-service (DDoS) attacks**
: 同时使用多个远程系统对目标资源发起大规模 DoS 攻击的过程。

**Distributed Network Protocol (DNP3)**
: 一套工业通信协议，旨在为电网系统中的中央 SCADA 主站与不同类型的远程设备（控制器，如 IED、PLC 和 RTU）之间提供联网功能。

**Distributed Reflection and Amplification Denial of Service (DRDoS)**
: 一种网络攻击，攻击者利用相对较小的僵尸网络对反射服务器发起分布式攻击，反射服务器重定向接收到的查询，使其看起来像是反射服务器本身是实际攻击源。

**diversion**
: 旨在分散个人监视注意力的战术。通常制造干扰是为了让攻击者在不被发现的情况下查看敏感信息，或在不被盘问的情况下进入安全区域。

**domain**
: 一种计算机环境，网络中的所有成员共享一个通用的目录数据库，并被组织成不同的层级。域由唯一名称标识，并作为具有通用规则和程序的单一单元进行管理。

**domain controller**
: 控制域的对象、规则和程序的中心化服务器。

**Domain Name System (DNS) servers**
: 包含 DNS 数据库（`*.dns` 文件）的服务器，用于将计算机名解析为 IP 地址。这些服务器还包含完全合格域名（`www.marcraft.com`）与其所代表的 IP 地址之间的映射关系。

**double encapsulation VLAN hopping attack**
: 一种网络攻击，导致在原始帧上添加两个标头（双标记）。其中一个标记代表目标的 VLAN ID，另一个代表攻击者交换机的 VLAN ID。当数据包到达攻击者的交换机时，第一个标记被剥离，但第二个标记随数据包保留。随后数据包被转发到目标交换机，后者读取标记并将数据包转发给目标主机。

**dual-firewall DMZ**
: 一种网络配置，防火墙位于 DMZ 的两侧，用于过滤内部网与 DMZ 之间以及 DMZ 与互联网之间的流量。这些防火墙用于将公共流量路由到 DMZ，将内部网络流量路由到内部网。

**due care policy**
: 要求各级管理层采取措施，确保在整个组织中提供特定安全防护的政策。此类行动可降低设备损坏或人员及访客受伤的概率。

**dumpster diving**
: 在实体的垃圾中搜寻有用信息碎片的过程。信息包括但不限于电话记录、旧日历、组织架构图和笔记本。此行为属于网络攻击链的侦察阶段。

**dynamic ARP inspection (DAI)**
: 一种旨在阻止 MITM 攻击的配置功能。DAI 使用 DHCP Snooping 数据库来检查和验证 ARP 请求，以防止 ARP 欺骗攻击。

**Dynamic Trunking Protocol (DTP) request**
: 攻击者向网络交换机发送请求，将攻击者的端口配置为中继连接。

**dynamic variable**
: 可能因外部影响或内部影响而自发变化的物理参数。

### E

**eavesdropping**
: 未经当事人同意，秘密窃听私人对话的行为，通常是为了获取适用信息。

**eCryptfs**
: 主流 Linux 操作系统内置的软件包，提供文件系统级加密服务。此级别的加密允许将加密服务应用于单个文件或目录，而无需承担大量的磁盘管理开销。

**egress**
: 离开某地的动作，无论是物理上还是逻辑上。

**Encapsulating Security Payloads (ESP)**
: ESP 协议在 IPSec 协议套件中提供完整性、机密性和认证以及加密。ESP 在 ESP 标头中加密并封装整个 TCP/UDP 数据报，该标头不包含任何端口信息。

**Encrypting File System (EFS)**
: Microsoft Windows 的文件和文件夹级加密服务。

**encryption**
: 加密数据涉及获取数据（明文）并使用密钥代码（密码）对其进行处理，该代码定义了原始数据版本是如何被操作的（密文）。

**encryption key**
: 用于将明文转换为密文（反之亦然）的密钥或算法。

**entropy**
: 随机性的度量，或缺乏可预测性和秩序，导致一定程度的不确定性。

**entry delay**
: 安全区域可配置的延迟，给进入场所的人员留出时间，在警报激活前访问内部安全面板以解除警报。

**enumerate**
: 建立网络拓扑图，或确定可发现哪些设备和主机。

**error signals**
: 发送给最终执行元件的校正信号，用于调节被操纵变量。

**道德黑客**
: 任何用于测试或评估系统及其资源的黑客技术，前提是获得数据和网络所有者的同意，目的是评估任何弱点。由于不存在公认的道德标准，道德黑客实际上归结为合法黑客行为，即被渗透测试资产的所有者已给予测试人员合法的（合同约定的）授权以进行规定的测试。

**道德规范**
: 基于道德原则，在特定情境下判断何种行为是正确或错误的。

**Ettercap**
: 一款免费开源的软件工具，用于执行多种网络和安全分析。

**EV 证书**
: 扩展验证（EV）证书要求由证书颁发机构验证个人身份。这些证书通常用于使用 SSL/TLS 的网站。

**排除**
: 安全专业人员用于禁止、阻止或移除对被排除资产访问的方法、设备或系统。

**eXecute Disable (XD) 位**
: 内置于微处理器硬件中的一项功能，用于保护包含特定指令代码块（如内核）的特定内存区域。

**exFAT**
: 微软针对闪存设备推出的扩展文件分配表文件系统。

**退出延迟**
: 安全系统激活时的时间延迟，给予人员离开场所的时间，以免触发警报。

**漏洞利用代码/工具**
: 旨在利用计算机系统中特定漏洞或缺陷的软件程序或工具。

**出口级加密**
: 一种加密方法，其强度被设定为“足够好”但仍允许 NSA 解密美国境外的通信。NSA 在 20 世纪 90 年代末取消了这一出口限制，但这些密码套件仍保留在客户端和服务端库中。

**ext#**
: ext# 系列扩展文件系统是为 Linux 内核设计的主要文件管理系统。ext2 也广泛用于 SD 卡和其他基于闪存的存储设备。

**外联网**
: 一种授权外部用户（如企业合作伙伴）有限访问的内部网结构。换句话说，一种部分私有、部分公开的网络结构。

### F

**F2FS**
: 三星的闪存友好文件系统（版本 2）是一款面向闪存存储设备的开源 Linux 文件系统。

**故障安全/失效安全**
: 对特定类型的故障以一种将对人员或设备造成的伤害降至最低的方式进行响应的方法。也称为故障安全/失效安全。

**故障软化/失效软化**
: 当发生硬件或软件故障时，将终止任何非必要处理的模式。

**失效模式与影响分析 (FMEA)**
: 一种定性分析工具，用于评估流程以识别其可能失效的位置和方式（失效模式），并评估不同失效的相对影响。该评估可用于识别最可能失效的流程组件，从而对整个系统进行创新改进。

**假阴性**
: 导致错误拒绝合法人员的报告，从而将本应有权进入的人员拒之门外。在日志记录或取证分析中，假阴性结果是指当特定条件或属性实际存在时，却错误地指示其缺失。

**假阳性**
: 错误地认证人员身份的报告，可能导致向本不应拥有访问权限的人员提供设备或数据访问权限。在日志记录或取证分析中，假阳性结果是指当特定条件或属性实际不存在时，却错误地指示其存在。在两类认证失败中，这是最严重的，因为它可能授予恶意人员访问权限。

**故障树分析 (FTA)**
: 一种分析系统安全性和可靠性的工程工具，用于确定流程如何失效，以及如何最好地降低与这些流程相关的风险。

**反馈**
: 从流程输出回馈到控制器的路径，控制器随后对流程输入施加适当的校正动作。

**现场总线网络**
: 这是对 PLC（可编程逻辑控制器）的流程输入和输出线路的统称。

**现场设备**
: 设计用于部署在受控流程附近的工业控制器。

**视野**
: 给定监控摄像头能够看到的范围。也称为视场。

**文件和文件夹级加密**
: 应用于单个文件和文件夹的加密。文件和文件夹级加密工具允许用户使用密钥加密存储在驱动器上的文件，只有指定用户（或授权的恢复代理）才能解密。这可以防止没有密码或解密工具的人窃取数据。该技术用于保护静态数据（存储中的数据）。

**FileVault**
: Apple OS X 操作系统自带的基于磁盘级别的数据加密服务。

**火警分队/中间人劫持攻击**
: 中间人攻击通过拦截或嗅探并修改用户之间的通信来劫持会话。

**防火墙**
: 通常由硬件和软件组合而成的设备，用于保护私有网络免受来自不受信任网络（如互联网）的未授权访问。

**防火墙规则**
: 防火墙用于确定将过滤哪些通信的规则。

**固件**
: 固件是已编程到只读存储器中的永久性软件。

**鱼眼镜头**
: 一种超广角镜头，牺牲直线透视以换取更大的可视区域。鱼眼镜头拍摄的图像边缘通常会畸变。

**定焦镜头**
: 焦距固定、无法像普通变焦镜头那样调节的镜头。

**扁平网络**
: 一种网络类型，它是一个网络段，所有设备无需连接设备（路由器和交换机）即可相互通信。

**Fraggle 攻击**
: 一种拒绝服务攻击，类似于 Smurf 攻击，攻击者向网络中的广播地址发送伪造的 UDP 数据包。

### G

**增益**
: 比例控制系统中差值百分比的乘数函数。

**网关设备**
: 网关设备通常是路由器，但也可能是交换机、调制解调器、接入点，甚至是语音互联网协议 (VoIP) 适配器。

**基于 GEOM 的磁盘加密 (GBDE)**
: 一种块设备层面的磁盘级加密系统。

**玻璃破碎检测**
: 一种检测玻璃破碎的传感器；分为两种类型。振动式安装在玻璃上或附近的墙上。声学或声音鉴别器感应玻璃破碎的声音。

**灰盒测试**
: 白盒和黑盒测试的结合，灰盒渗透测试人员在测试开始前可能会获得关于网络的部分信息。

**灰帽黑客**
: 道德指南针介于利他主义和恶意之间的计算机黑客。他们的操作方式通常未获得适当权限；不过，他们可能会将发现的漏洞提供给受影响的供应商。

**灰色软件**
: 可能尚未被归类为恶意软件，但仍包含不良功能的软件应用程序。

### H

**黑客**
: 利用计算机技能获取数据和资源未授权访问权限的个人。

**加固**
: 使任何设备（硬件和软件）更安全的过程。通常涉及许多步骤和程序，同时考虑可接受的易用性。

**硬件防火墙设备**
: 专门且仅设计用于作为防火墙运行的设备。

**硬件端口**
: 各种计算机和网络设备之间的接口。

**硬件令牌**
: 可提供身份验证的物理设备。也称为安全令牌。

**哈希表**
: 使用哈希函数将键转换为哈希值，从而将键映射到值的查找表。也称为哈希映射。

**危险与可操作性研究**
: 为揭示给定过程中存在的任何危险场景而进行的研究和分析。

**分层文件系统**
: Apple 公司开发的专有文件系统，作为运行 macOS 的 Macintosh 系列计算机的主要文件系统。也用于 Apple 的 iPod 音乐设备系列。

**历史数据库**
: 以控制点（称为标签）的形式存储历史数据的数据库管理系统。

**家庭局域网**
: 由自动化电气设备控制器组成的专用局域网，通常位于住宅内或住宅附近。

**蜜罐**
: 旨在将攻击者从真实网络引开的诱饵服务器、网络设备或网段。通过为攻击者提供对网络上诱饵系统的相对容易访问权限，并隐藏真正关键的系统来实现。

**基于主机的身份验证**
: 一种依赖信息（如 MAC 地址和主机名）向网络进行身份验证的形式，而非依赖用户凭据。

**人机界面**
: 使人工操作员能够观察不同工艺的运行参数，并接管工艺以更改参数或进行纠正的界面。

**虚拟机监控程序**
: 托管其他客户操作系统的虚拟操作平台（类似于虚拟操作系统）。

### I

**Icinga**
: 一款开源网络监控应用程序。

**ICMP**
: 互联网控制报文协议，常用于测试从设备到网络的连通性。

**身份验证**
: 将特定个人与现有身份关联并验证的过程。

**身份盗窃**
: 通过欺骗手段获取他人各种身份证明文件的行为，通常为谋取经济利益。

**入侵检测系统/入侵检测与防御系统**
: 入侵检测系统或入侵检测与防御系统，旨在主要监控系统（本地计算机或网络环境），记录关键事件和策略违规，并按指示报告。入侵检测与防御系统旨在监控技术环境（计算机或网络），记录关键事件和策略违规，报告并按指示阻止它们。类型包括**基于异常的 IDS/IDPS**，即使用异常分析来检测和防止未经授权的网络访问的入侵检测系统。分布式 IDS 系统是指连接到网络的本地主机安装了自己的 IDS 模块，此外，网络服务器上还安装了 IDS 管理模块，协调信息流向各个本地 IDS 模块。**基于主机的 IDS (HBIDS)** 是安装在单个系统上并保护该系统的入侵检测系统。**基于特征的 IDS/IDPS** 是通过查找内容中的特定模式（称为特征）来工作的系统。如果检测到已知的恶意模式，则采取适当措施保护主机。
