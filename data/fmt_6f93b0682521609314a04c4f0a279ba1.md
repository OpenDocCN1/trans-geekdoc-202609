
人们不禁要问，对输入空间进行更仔细的采样是否会产生更丰富的表示，从而使对抗样例能被纳入训练集，进而让网络学习到它们。正如 [200] 所声称的，对抗负样本集的概率极低，因此在数据集中从未（或极少）被观测到，但它是稠密的（很像有理数集）；因此，它可以在几乎每个测试用例附近被找到。然而，应注意到，这种说法并未得到理论证明的证实。

## 对抗训练

### 实践防御对抗样本

在构建了对抗样本并尝试理解其存在性之后，研究的下一个前沿更多地聚焦于该现象的实践层面。尽管对抗样本似乎远非输入（训练集和测试集）数据中的常见现象，但这仍是一个相当令人不安的现象。此外，它始终可以被用来**有意地**欺骗网络。为此，已经出现了许多技术，试图使网络对对抗样本具有“鲁棒性”。

在文献 [200] 中，生成了对抗样本并将其反馈到训练集中。这是一种通过数据生成进行正则化的方法。然而，在文献 [100] 中指出，对于音乐数据，该方法并未真正提升性能。

在文献 [54] 中，损失函数 `ℒ` 被适当修改为：

```
ℒ′(θ, x, y) = αℒ(θ, x, y) + (1 − α)ℒ(θ, x + Δx, y),  0 < α < 1
```

其中

```
Δx = ε sgn ( ∂/∂x ℒ(θ, x, y) ),  ε > 0
```

被证明是对抗扰动的一个方向。`ε` 是一个足够小的数字，用于控制扰动预算，`sgn(·)` 表示符号函数。在这种情况下，代价函数变为：

```
J(θ) = Σ(x,y) ℒ′(θ, x, y).
```

公式 (18.71) 右侧第二项的关键点在于将训练样本 `x` 扰动至对抗方向。这符合使训练对对抗点的存在更具鲁棒性的目标，因为训练算法变得“警觉”于对抗方向。

在文献 [135] 中，使用了一个正则化项来促进模型分布关于输入在每个输入数据点周围的平滑性。在文献 [182] 中，提出了一种鲁棒优化方法，该方法建立在极大极小公式之上，其中代价函数针对扰动的最坏情况实现进行优化。在文献 [150] 中，提出了 `distillation`（蒸馏）技术作为应对对抗样本的一种方式。蒸馏是一种训练过程，最初设计用于迁移学习背景下的深度神经网络训练（参见第 18.16 节），例如文献 [75]。在对抗训练框架中，据称蒸馏可以将导致对抗样本生成的梯度降低数个数量级。此外，蒸馏可以显著增加创建对抗样本所需修改的特征的平均最小数量。在文献 [149] 中，提出了一种用于训练网络的贝叶斯框架，与多种最先进技术相比，该框架显著提高了对对抗样本的鲁棒性。

在文献[176]中，开发了一个理论框架。从一个属于某个类（设为`y`）的训练样本`x`出发，构建对抗样本的路径是将`x`改变为一个新点（设为`x'`），该点非常接近`x`，但模型将其分类为另一个类`y' ≠ y`。我们用来构建`x'`的模型被称为*攻击模型*。对于每个训练样本`x ∈ ℝ^l`，我们在`x`周围引入一组允许的扰动`Sx ⊆ ℝ^l`。`Sx`的一个典型选择是

```
Sx := {x + δ : ||δ||_p ≤ ε},
```

其中`||·||_p`表示`ℓ_p`范数（参见第 8.3 节），且`ε`足够小。例如，在图像分类任务中，选择`Sx`是为了捕捉图像间的感知相似性。在文献[176]中，建议将对抗训练视为一个鲁棒优化任务，并修改损失函数，从而产生以下极大极小优化问题，

```
min_θ Σ_(x,y) max_δ L(θ, x + δ, y), s.t. ||δ||_p ≤ ε.
```

(18.73)

公式(18.73)中的优化任务包含两个步骤。关于`δ`的最大化（内层最大化）旨在找到一个实现高损失的对抗版本。关于`θ`的最小化（外层最小化）旨在找到一个模型，以最小化由内层任务给出的“对抗损失”，从而构建一个鲁棒学习器。事实上，可以证明，如果我们选择`x`周围的区域`Sx`通过`ℓ_∞`范数定义（参见第 9.2 节），且最大化在一步内执行，则公式(18.72)中的`Δx`源于内层最大化。该算法也被称为*快速梯度符号法*（FGSM）。

相比之下，文献[130]建议以迭代方式求解内层最大化，即

$$ \mathbf{x}^{(i + 1)} = P_{S_{\mathbf{x}}(\epsilon)}\left( \mathbf{x}^{(i)} + \mu\ \text{sgn}\frac{\partial}{\partial\mathbf{x}}\mathcal{L}(\mathbf{\theta},\mathbf{x},y)|_{\mathbf{x} = \mathbf{x}^{(i)}} \right) $$

其中 $P_{S_{\mathbf{x}}(\epsilon)}$ 表示区域 $S_{\mathbf{x}}(\epsilon)$ 上的投影算子（参见第 8.3 节）。迭代从 $\mathbf{x}$ 开始，且 $\mu > 0$ 为相应的步长。由此产生的算法称为*投影梯度下降*（PGD）方法，据称它可以带来性能提升。

前述攻击模型被称为*白盒*攻击模型，因为梯度是已知且可用的。另一类攻击方法称为*黑盒*攻击，其中损失函数的梯度不可用，参见例如 [193]。这些模型在测试训练算法对抗对抗样本的鲁棒性时特别有用。关于对抗训练的教程综述见例如 [5]。

对抗样本具有潜在危险性。例如，考虑一名攻击者利用贴纸或油漆制造对抗性“停车”标志来针对自动驾驶汽车，导致车辆将其识别为“让行”或其他标志（参见例如 [152]）。文献 [109] 表明，将通过手机摄像头获得的对抗图像输入 ImageNet Inception 分类器时，即使通过摄像头感知，大部分对抗样本仍被错误分类。文献 [151] 提出了一种威胁模型，在对抗框架内对攻击和防御进行分类。结果表明，模型复杂性、准确性和韧性之间存在（可能不可避免的）张力，必须根据其使用环境对这些因素进行校准。

文献 [181] 讨论了尽管已提出各种防御措施来增强神经网络抵御对抗攻击的鲁棒性，但这些防御似乎很快就会被攻破。此外，该文献的理论分析表明，对于某些问题类别，对抗样本是不可避免的。

## 18.15 胶囊网络

卷积神经网络（在第 18.12 节中讨论）及其众多变体已成功应用于多个领域。然而，尽管取得了成功，CNN 仍有缺陷。训练需要大型数据集是一个主要缺陷。CNN 需要大型训练集的原因之一在于，CNN 很难学习几何关系并将其外推到新的视角。例如，在第 18.12.1 节末尾曾指出，池化引入了对小平移的不变性。然而，为了处理更一般的不变性（如缩放和旋转），必须在同一物体的不同视角上训练网络，这必然导致所需数据集规模的增加。此外，与池化相关的子采样“丢弃”了输入图像中某区域内实体位置的信息；这会影响对识别物体至关重要的精确空间关系信息。例如，眼睛、嘴巴和鼻子之间的空间关系对于识别人脸很重要。为此，已提出许多变体，旨在将仿射变换阶段嵌入网络中，这些阶段在训练过程中学习，以增强网络鲁棒性并提升其变换不变性（参见例如 [89] 及其参考文献）。

文献 [174] 引入了一种替代概念，旨在克服上述缺陷。所提架构建立在类似 CNN 的卷积概念之上，但进一步嵌入了基于*胶囊*概念的新型层。“胶囊”一词指一组标量激活值，它们共同组合形成一个*活动*向量。受 [174] 启发的图 18.40 即为这种架构的一个示例。为了掌握胶囊网络背后的主要原理，让我们逐步跟随图中的各个模块。

*   **输入**：网络的输入是来自 MNIST 数据集的 28 × 28 图像。

### 第一个卷积层

这是一个标准的卷积层。滤波器矩阵（核）为 `9 × 9`，步长为 `s = 1`，深度（通道数）为 `d = 256`。因此，第一个隐藏层的输出体积大小为 `k × k × 256`，其中 `k = ⌊(28 - 9) / 1 + 1⌋ = 20`。

### 初级胶囊

这也是一个卷积层。与前一个层的区别在于，该层会进行活动的*分组*。卷积的滤波器矩阵同样为 `9 × 9`，步长为 `s = 2`，深度为 `d = 256`。然而，输出通道以 8 个为一组进行聚类。因此，形成了 32 个体积，每个深度为 8（总计 256）（参见图 18.40）。每个体积的大小为 `k × k × 8`，其中 `k = ⌊(20 - 9) / 2 + 1⌋ = 6`。

图 18.41 说明了胶囊是如何形成的。以图中的示例为例，每个胶囊的维度为 `d = 8`。对于这 32 个体积中的每一个，都会形成 36 个（6 × 6）八维管/向量。换句话说，每个胶囊对应特征图数组中的一个特定位置。因此，胶囊中的八个维度中的每一个都*封装*了上一层体积中相应感受野内的活动（参见图 18.40）。因此，总共获得 `36 × 32 = 1152` 个胶囊，每个维度等于 8。这些向量构成了第二层的*输出*。让我们将生成的每个胶囊表示为 **u**[i]，`i = 1, 2, …, I`，其中 `I = 1152`。

### 数字胶囊

该层包含三个阶段，如图 18.42 所示。

#### 阶段 1

在此阶段，对输入（到该层）的每个胶囊执行仿射变换，即

##### 胶囊网络路由算法

###### 阶段 1：变换矩阵

从输入胶囊到预测向量的变换定义为：

```
${\\widehat{\\mathbf{u}}}\_{j|i} = W\_{ij}\\mathbf{u}\_{i},\\ i = 1,2,\\ldots,I,\\ j = 0,2,\\ldots,9,$
```

![Equation](img/si543.png)

1. 权重矩阵 `W[i*j*] ∈ ℝ^(16×8)` 将每个输入胶囊变换为*十个* 16 维向量。数字“十”对应类别的数量（每个数字一个类别）。因此，执行的变换总数为 `10*I*`。`W[i*j*]` 矩阵在训练过程中学习得到，其作用是在低层特征（如编码在输入胶囊中）和高层特征之间建立空间及其他类型的关系。简单来说，输入信息被“最优地”变换以“匹配”高层信息，在本例中即为十个类别。`W[i*j*]` 矩阵可被视为建立“部分到整体”关系的模型；类别可视为“整体”，而输入胶囊可视为“部分”，每个部分编码单个特征，例如笔画类型、粗细和宽度，这些共同构成输入图像；然而，这些图像可能经过了缩放和/或旋转，这些变换的作用正是处理此类变体。

###### 阶段 2：耦合系数加权求和

然后，对于每个类别，获得的变换胶囊通过使用*耦合系数*的加权求和组合在一起，形成十个（每类一个）向量/胶囊：

```
$\\mathbf{s}\_{j} = \\sum\\limits\_{i = 1}^{I}c\_{ij}{\\widehat{\\mathbf{u}}}\_{j|i},\\ j = 0,1,\\ldots,9.$
```

![Equation](img/si546.png) (18.74)

1. 正如我们将在第 3 阶段看到的，正是这些胶囊通过非线性函数产生最终定义获胜类别的输出。仔细观察公式 (18.74)，耦合系数 `c[i*j*]` 在计算相应的 **s**`[j*]` 时，对每个涉及的变换胶囊的重要性进行加权。非负的耦合系数具有概率解释，并且对于每个固定的 `i` 值，对 `j` 求和时它们的和为 1。正如很快将变得明显的那样，它们的计算构成了胶囊网络的关键部分。

###### 阶段 3：非线性（压缩函数）

一旦计算出 **s**`[j*]`，它们就会被“推”过非线性函数以提供输出胶囊 **v**`[j*]`，`j = 0, 1, …, 9`。

![Equation](img/si550.png)

然而，非线性函数经过精心选择，使得输出胶囊的长度（欧几里得范数）能指示输入图像的类别。例如，如果输入数字是“4”，网络经过训练使得相应胶囊 **v**[4] 的长度比其他九个竞争者最大。其理念是输出胶囊的每个维度（共 16 个）代表输入图像中存在的不同活动。因此，对于对应正确类别的胶囊，预期所有维度都“表现出”高活动性。

采用的非线性函数为

####### 公式 (18.75)

$$

\mathbf{v}_{j} = \frac{||\mathbf{s}_{j}||^{2}}{1 + ||\mathbf{s}_{j}||^{2}}\frac{\mathbf{s}_{j}}{||\mathbf{s}_{j}||},\quad j = 0,1,2,\ldots,9.

$$

1.  观察到非线性影响向量的长度但**不**影响方向。对于较小的 $||\mathbf{s}_{j}||$ 值，

    $$

    \mathbf{v}_{j} \approx ||\mathbf{s}_{j}||\mathbf{s}_{j} \Rightarrow ||\mathbf{v}_{j}|| \approx ||\mathbf{s}_{j}||^{2}.

    $$

2.  对于较大的 $||\mathbf{s}_{j}||$ 值，

    $$

    \mathbf{v}_{j} \approx \frac{\mathbf{s}_{j}}{||\mathbf{s}_{j}||} \Rightarrow ||\mathbf{v}_{j}|| \approx 1.

    $$

3.  注意，这里存在胶囊网络与更“传统”神经网络的主要区别。非线性的输入和输出均为**向量**，而非标量。激活值不仅以幅度编码，也以方向编码。

![Figure 18.42 This layer consists of three stages. In the first one, ten (one per class) affine transformations are performed on each one of the input capsules, which were formed in the previous layer. In the next stage, a weighting sum is computed, over the transformed capsules for each one of the ten classes. At the final stage, the obtained vectors are “pushed” through a squashing nonlinearity to generate the ten output capsules. **Figure 18.42** 该层包含三个阶段。在第一阶段，对上一层形成的每个输入胶囊执行十个（每类一个）仿射变换。在下一阶段，针对十个类别中的每一个，计算变换后胶囊的加权和。在最后阶段，获得的向量通过压缩非线性单元生成十个输出胶囊。输入胶囊维度为 8，输出胶囊维度为 16，使用适当维度的变换矩阵 `Wij`。

#### 训练

胶囊网络的训练阶段围绕以下相互关联的概念展开。

**损失函数** 与支持向量机上下文中使用的 hinge 损失函数（第 11.10 节）非常相似，定义如下：

##### 损失函数

$$\\mathcal{L} = \\sum\\limits\_{j = 0}^{9}\\left\\{ T\_{j}\\max\\{ 0,m^{+} - ||\\mathbf{v}\_{j}||^{2}\\} + \\lambda(1 - T\_{j})\\max\\{ 0,||\\mathbf{v}\_{j}||^{2} - m^{-}\\} \\right\\}.$$

损失函数包含两项。训练期间，如果输入数字对应第 $k$ 个胶囊，则 $T\_k = 1$，而 $T\_j = 0$（$j \\neq k$）。因此，为了使损失值最小，正确类别胶囊 $k$ 的长度将被调整为大于阈值 $m^+$（实际值设为 0.9）的值。相反，其余胶囊的长度应被“推向”小于 $m^-$（实际值设为 0.1）的长度。参数 $\\lambda$ 用于降低第二项的权重，文献 [174] 建议将其设为 1/2。损失值用于调整 $W\_{ij}$ 矩阵的值以及卷积中使用的滤波器权重。

######## 迭代动态路由算法

**迭代动态路由算法**指的是耦合系数的更新。这些系数被赋予了概率解释，由以下 softmax 操作保证：

$$c\_{ij} = \\frac{\\exp(b\_{ij})}{\\sum\_{k = 0}^{9}\\exp(b\_{ik})},\\ i = 1,2,\\ldots,I,\\ j = 0,1,\\ldots,9.$$

简而言之，$c\_{ij}$ 表示第 $i$ 个前层胶囊耦合到第 $j$ 个高层输出（类别）胶囊的概率。耦合系数的计算根据 **算法 18.4** 迭代进行。

######### 算法 18.4：动态路由算法

*   初始化 $b\_{ij} = 0$，$i = 1,2,\\ldots,I$，$j = 0,1,2,\\ldots,9$。

######## 算法流程
