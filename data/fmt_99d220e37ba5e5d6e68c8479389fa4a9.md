
虚拟专用网络（VPN）是一种用于在公共网络（如互联网）上的用户之间提供安全通信通道的结构。正如后文所述，可以使用多种技术来实例化 VPN 连接。加密技术允许对数据包数据进行加密或对整个数据包进行加密。如果仅加密数据，包头在源和目的之间仍然可以嗅探和观察，但加密保护了数据包的内容不被查看。如果加密整个数据包，它将被放入另一个数据包中，并通过隧道跨越公共网络发送。隧道可以保护通信双方的身份。

VPN 最常见的实现方式是通过 `IPsec`，这是一种用于 IP 安全的协议。`IPsec` 在 `IPv6` 中是强制性的，并可选地回溯支持到 `IPv4`。`IPsec` 可以通过硬件、软件或两者结合来实现。VPN 终止于网络中的特定点，即 VPN 集中器。VPN 集中器有多种尺寸，可以进行扩展以支持从小型网络到大型网络的 VPN 应用。VPN 集中器允许多个 VPN 连接终止于单一网络点。

## 入侵检测系统

入侵检测系统（IDS）旨在能够实时和事后检测、记录并响应未经授权的网络或主机使用。IDS 可由众多供应商提供，是网络安全中不可或缺的组成部分。这些系统通过软件实现，但在大型系统中，还需要专门的硬件。IDS 可分为两类：基于网络的系统和基于主机的系统。它们使用两种主要的检测方法：基于特征的和基于异常的：

- **基于主机的入侵检测系统（HIDS）**：检查单个系统（如邮件服务器、Web 服务器或个人 PC）上的活动。它只关注单个系统，通常对网络或周围系统的活动没有可见性。

- **基于网络的入侵检测系统（NIDS）**：检查网络本身的活动。它只能看到通过其监控的网络链路的流量，通常不知道单个系统上发生了什么。

无论是基于网络还是基于主机，IDS 通常由几个协同工作的专业化组件组成，如图 1-3 所示。这些组件通常是逻辑上和基于软件的，而不是物理的，并且会根据供应商和产品的不同而略有差异。通常，一个 IDS 具有以下逻辑组件：

- **流量收集器（或传感器）**：该组件收集 IDS 需要检查的活动/事件。在基于主机的 IDS 中，这可能是日志文件、审计日志或进入/离开特定系统的流量。在基于网络的 IDS 中，这通常是一种从网络链路复制流量的机制——基本上充当嗅探器工作。此组件通常被称为传感器。

- **分析引擎**：该组件检查收集的网络流量，并将其与特征数据库中存储的已知可疑或恶意活动模式进行比较。分析引擎是 IDS 的“大脑”。

- **特征数据库**：特征数据库是已知可疑或恶意活动的模式和定义的集合。

- **用户界面和报告**：该组件与人类元素进行交互，在适当的时候提供警报，并为用户提供与 IDS 交互和操作的手段。

大多数 IDS 都可以进行调整以适应特定的环境。可以关闭某些特征，告诉 IDS 不要查找某些类型的流量。例如，如果你在纯 `UNIX` 环境中运行，你可能不希望看到基于 Windows 的警报，因为它们不会影响你的系统。此外，可以根据你对某些类型流量的关注程度，调整警报级别的严厉程度。某些 IDS 还会允许用户从特定主机中排除某些活动模式。换句话说，你可以告诉 IDS 忽略某些系统生成看起来像恶意活动流量的事实，因为它们实际上并不是。

一些分析师还会根据 IDS 运行和检测恶意流量的方式，将 IDS 模型进一步分为四类（这些模型也适用于入侵防御系统，稍后会进行讨论）。

### 基于行为（Behavior Based）

这种模型依赖于一组收集的“正常行为”——网络上应该发生的情况，以及被认为是“正常”或“可接受”的流量。不符合“正常”活动类别或模式的行为被认为是可疑或恶意的。这种模型能够检测零日攻击或未发表的攻击，但误报率较高，因为任何新的流量模式都可以被标记为“可疑”。

### 基于特征（Signature Based）

这种模型依赖于一组预定义的模式（称为`特征`）。IDS 在识别并处理可疑或恶意流量之前，必须提前知道哪些行为被认为是“坏的”。基于特征的系统非常快速且精确，但它们依赖于事先拥有准确的特征定义。

### 基于异常（Anomaly Based）

这种模型与基于行为的方法类似。IDS 首先学习什么是“正常”流量，然后寻找与这些“正常”模式偏离的特征。异常也可以被定义，例如发送到基于 Windows 的系统的 `Linux` 命令，并通过基于人工智能的引擎实现，以扩展特定定义的实用性。

### 启发式（Heuristic）

这种模型使用人工智能来检测入侵和恶意流量。这通常通过算法实现，帮助 IDS 决定流量模式是否为恶意。例如，包含重复 10 次字符的 URL 可能被视为单个特征的“坏”流量。在启发式模型中，IDS 将理解如果 10 个重复字符是坏的，那么 11 个仍然是坏的，20 个更糟。这种模糊逻辑实现使得该模型介于基于特征和基于行为的模型之间。

### 入侵防御系统（Intrusion Prevention Systems）

入侵防御系统（`IPS`）的核心是一个入侵检测系统。然而，IDS 只能在网络流量匹配规则时发出警报，而 IPS 可以采取进一步的操作。IPS 具有 IDS 相同的两种形式：基于主机（`HIPS`）和基于网络（`NIPS`）。IPS 可以采取直接行动拦截攻击，其行动由规则支配。通过自动化响应，IPS 显著地缩短了从检测到采取行动的时间。

### 协议分析器（Protocol Analyzers）

`协议分析器`（也称为`数据嗅探器`、`网络分析器`或`网络嗅探器`）是一种捕捉和解码网络流量的软件或集成软硬件系统。几十年来，协议分析器一直受到管理员和安全专业人员的欢迎，因为它们是环境中多功能的工具。从安全角度来看，协议分析器可以用于多种活动，例如：

- 检测入侵或不受欢迎流量（IDS/IPS 必须具备某种捕捉解码能力以便查找可疑/恶意流量）
- 在事件响应或事件处理期间捕捉流量
- 寻找僵尸、木马和感染系统的证据
- 寻找异常流量或超过某些阈值的流量
- 测试系统或应用程序之间的加密

从网络管理的角度来看，协议分析器可以用于此类活动：

- 分析网络问题
- 检测配置不当或运行异常的应用程序
- 收集和报告网络使用情况及流量统计数据

## 调试客户端/服务器通信

无论预期用途如何，协议分析器都必须能够捕获网络流量以便对其进行解码。基于软件的协议分析器必须能够将其用于监控网络流量的网络接口卡（`NIC`）设置为`混杂模式`（`promiscuous mode`，有时称为 `promisc mode`）。`混杂模式`告诉 `NIC` 处理它看到的每一个网络数据包，无论其目标地址是什么。通常情况下，`NIC` 只处理`broadcast`数据包（发送给该子网上所有人的数据包）以及数据包内目标地址为该 `NIC` MAC 地址的数据包。作为嗅探器，分析器必须处理通过线路的每一个数据包，因此，将 `NIC` 置于`混杂模式`的能力至关重要。

对于较旧的网络技术（如集线器），操作协议分析器要容易得多，因为集线器无论目标为何，都会将每个数据包广播到每个接口上。随着交换机成为网络设备的标准，部署协议分析器变得更加困难，因为交换机不会在每个端口上广播每个数据包。虽然这让管理员嗅探流量变得更加困难，但也让窃听者和潜在攻击变得更难实现。

为了适应协议分析器、IDS 设备和 IPS 设备，大多数交换机制造商都支持`端口镜像`或`交换端口分析（SPAN）`端口。根据制造商和硬件的不同，镜像端口将看到通过交换机或特定 `VLAN(s)` 的所有流量，或者通过其他特定交换机端口的所有流量。网络流量实际上被复制（或镜像）到特定端口，该端口即可支持协议分析器。

一种流行的开源协议分析器是 Wireshark（[www.wireshark.org](http://www.wireshark.org)）。Wireshark 适用于 UNIX/Linux 和 Windows 操作系统，是一种基于 GUI 的协议分析器，允许用户在运行软件的系统上的任何可用网络接口（包括无线接口）上捕获并解码网络流量。Wireshark 具有一些有趣的功能，包括“跟踪 TCP 流”的能力，这允许用户选择单个 TCP 数据包，然后查看参与该 TCP 会话的所有其他数据包。

## 垃圾邮件过滤器

各地用户和系统管理员的噩梦——`spam` 本质上是未经请求或不受欢迎的批量电子信息。虽然垃圾邮件通常应用于电子邮件，但也可以通过短信发送到手机和移动设备、作为互联网论坛的帖子，以及通过其他手段发送。如果你用过电子邮件账户，很有可能你收到过垃圾邮件。

从生产力和安全角度来看，垃圾邮件每年给企业和用户造成数十亿美元的损失，它是一个如此广泛的问题，以至于美国国会通过了 2003 年的 `CAN-SPAM 法案`，授权联邦贸易委员会执行该法案，并授权司法部对垃圾邮件发送者实施刑事制裁。该法案对发送商业电子邮件的人制定了要求，规定了垃圾邮件发送者以及产品在垃圾邮件中广告的公司违法的处罚措施，并赋予消费者要求邮件发送者停止发送垃圾邮件的权利。然而，尽管我们付出了巨大努力，垃圾邮件仍然源源不断；随着停止垃圾邮件的技术和手段变得越来越先进复杂，用于发送这些未经请求消息的工具和技术也同样如此。

以下是几种用于对抗垃圾邮件泛滥的流行方法；其中大多数技术都用于过滤电子邮件，但也可以应用于其他媒介：

- **黑名单（Blacklisting）**：黑名单本质上是记录哪些域名和源地址有发送垃圾邮件的声誉，并拒绝来自这些域名和源地址的消息。这基本上是一种永久的“忽略”或“拉黑”类型的能力。几个机构和几家商业公司提供了已知垃圾邮件发送者列表。

- **内容或关键词过滤**：类似于互联网内容过滤，这种方法过滤电子邮件消息中的不受欢迎内容或垃圾邮件迹象。就像对网页内容进行过滤一样，基于关键词等内容过滤电子邮件可能会导致意料之外的结果，因为某些术语可能出现在合法邮件和垃圾邮件中。大多数内容过滤技术使用正则表达式匹配进行关键词过滤。

- **可信服务器（Trusted servers）**：与黑名单相反，可信服务器列表包含了被“信任”不会转发垃圾邮件的 `SMTP` 服务器。

- **基于延迟的过滤**：某些简单邮件传输协议（`SMTP`）服务器被配置为在建立连接后和发送 `SMTP` 服务器欢迎横幅之间插入故意暂停。某些生成垃圾邮件的程序不会等待欢迎横幅，任何在连接打开后立即开始发送数据的系统会被视为垃圾邮件生成器并被 `SMTP` 服务器丢弃。

- **PTR 和反向 DNS 检查**：某些电子邮件过滤器会检查邮件发送者的源域名。如果反向检查显示邮件来自拨号上网用户、家庭宽带或动态分配的地址，或者具有通用或缺失的域名，那么过滤器就会拒绝它，因为这些是垃圾邮件的常见来源。

- **回调验证（Callback verification）**：由于许多垃圾邮件使用伪造的“发件人”地址，某些过滤器尝试验证入站邮件的“发件人”地址。接收服务器可以联系发送服务器以尝试验证发送地址，但这并不总是有效，因为伪造地址有时是有效的电子邮件地址。

- **统计过滤（Statistical filtering）**：统计过滤非常像文档分类系统。用户将收到的消息标记为垃圾邮件或合法邮件，过滤系统从用户的输入中学习。看到并分类为垃圾邮件的消息越多，过滤软件拦截接入垃圾邮件的效果就越好。垃圾邮件发送者通过在消息中插入随机单词和字符来反制许多过滤技术，这使得识别垃圾邮件模式变得困难。

- **基于规则的过滤（Rule-based filtering）**：基于规则的过滤是一种简单的技术，仅查找匹配某些字段或关键词。例如，基于规则的过滤系统可能会查找入站邮件主题行中包含“发财”字样的任何邮件。许多流行的电子邮件客户端具有实现基于规则过滤的能力。

- **出站过滤（Egress filtering）**：某些组织也会对离开其组织的电子邮件进行垃圾邮件过滤，这被称为出站过滤。同样类型的反垃圾技术可以用于验证和过滤出站电子邮件，以对抗垃圾邮件。

- **混合过滤（Hybrid filtering）**：大多数商业反垃圾方法使用混合过滤，或结合几种不同技术来对抗垃圾邮件。例如，过滤解决方案可能会获取每条入站消息并与已知垃圾邮件发送者进行匹配，然后通过基于规则的过滤器，然后通过内容过滤器，最后通过统计过滤器。如果消息通过了所有过滤阶段，它将被视为合法消息；否则，将作为垃圾邮件被拒绝。

许多垃圾邮件过滤是在网络层或 `SMTP` 服务器级别完成的。与在整个组织的用户桌面电脑上部署单独的相比，使用集中式解决方案扫描所有入站和出站消息要高效得多。电子邮件本质上默认是一种代理服务：消息通常进入并离开组织的邮件服务器。用户通常不会连接到远程 `SMTP` 服务器来发送和接收消息，但他们可以这样做。反垃圾邮件解决方案以软件形式存在，软件既可以加载在 `SMTP` 服务器本身上，也可以加载在次要服务器上，后者在消息到达 `SMTP` 服务器之前或在 `SMTP` 服务器处理之后对其进行处理。反垃圾邮件解决方案还以硬件设备的形式存在，软件和硬件是一个集成的解决方案。许多集中式反垃圾邮件方法允许用户针对其特定的收件箱自定义垃圾邮件过滤，指定他们自己的过滤规则和评估入站邮件的标准。

垃圾邮件的核心问题在于，尽管付出了大量精力构建有效的垃圾邮件过滤程序，垃圾邮件发送者仍不断创造新方法来淹没收件箱。垃圾邮件过滤解决方案虽然很好，但远非完美，并且持续面临着允许合法信息通过的同时拦截垃圾邮件的持续挑战。对互联网流量缺乏中央控制也使得反垃圾邮件工作变得更加困难。不同国家对电子邮件的法律法规各异，从严厉到完全不存在不等。在可预见的未来，垃圾邮件将继续成为管理员和用户的负担。

## UTM 安全设备

许多安全供应商提供“合位一体安全设备”，这些设备将多种功能整合到同一硬件设备中。最常见的功能是 `firewall`、`IDS/IPS` 和反病毒软件，尽管合位一体设备也可以包含 `VPN` 网关、反垃圾邮件、恶意网页流量过滤、反间谍软件、内容过滤、流量整形等。合位一体设备的销售通常认为它们比实现合位一体设备各项功能的单独解决方案更便宜、更易管理且更高效。这些合位一体设备的常用名称是统一威胁管理（`UTM`）。使用 `UTM` 设备将安全活动简化为单一过程，并在通用的软件包下进行操作。这把学习曲线降低到单一工具，而不是一系列工具。与相互连接的工具集相比，`UTM` 设备在处理网络流量和安全事件方面具有更好的集成性和效率。

## URL 过滤器

URL 过滤器会阻止与禁止列表网站的连接。使用设备（通常由服务支持以更新禁止网站列表）提供了一种自动化手段，阻止访问被认为危险或不当的网站。由于网页内容具有高度的波动性，需要企业级的自动化保护，以确保有合理的概率拦截不当内容、恶意软件和其他恶意内容的来源。

## 内容检查

设备不仅依赖于 `URL` 来判断内容的接受性，还可以检查正在提供的实际内容。内容检查被用于过滤返回包含特定组件内容的网页请求，例如身体部位的名称、音乐或视频内容，以及其他不符合业务环境的内容。

## 恶意软件检查

恶意软件是另一项可以在网络传输过程中检测到的内容，且设备可以进行调整以检测恶意软件。基于网络的恶意软件检测的优势在于只需要更新单个系统，而不是所有机器。
