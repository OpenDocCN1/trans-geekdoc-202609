## 8.14 用于优化的近端分裂法

许多优化任务通常以单个凸函数求和的形式出现，其中一些是可微的，而另一些则是非光滑的。稀疏感知学习任务是备受关注的典型例子，其中正则化项是非光滑的，例如 `ℓ₁` 范数。

本节的目标是求解以下最小化任务：

$$

\mathbf{x}_{\ast} = \arg\min_{\mathbf{x}}\left\{ f(\mathbf{x}) + g(\mathbf{x}) \right\},

$$

其中两个涉及的函数均为凸函数，

$$

f: \mathbb{R}^{(l)} \mapsto \mathbb{R} \cup \{ +\infty \}, \quad g: \mathbb{R}^{(l)} \mapsto \mathbb{R},

$$

且假设 `g` 可微，而 `f` 非光滑。事实证明，对于适当选择的序列 `λₖ`，且在梯度连续利普希茨的条件下，即

### 快速近端梯度分裂算法

对于某个 $\gamma > 0$，有：

$$

\|\nabla g(\mathbf{x}) - \nabla g(\mathbf{y})\| \leq \gamma \|\mathbf{x} - \mathbf{y}\|

$$

可以证明，如果 $\lambda_k \in \left( 0, \frac{1}{\gamma} \right]$，则该算法以次线性速率 $\mathcal{O}(1/k)$ 收敛到一个极小值点 [8]。这类算法被称为**近端梯度**或**前向-后向分裂**算法。术语“分裂”源于将函数分解为两个（或更一般地，更多）部分。术语“近端”表明优化方案中存在 $f$ 的近端算子。迭代过程包含在光滑部分上进行的（显式）前向梯度计算步骤，以及通过非光滑部分的近端算子进行的（隐式）后向步骤。术语“前向-后向”借用自涉及离散化技术的数值分析方法 [97]。近端梯度方案可追溯至例如 [18, 54]，但它们在机器学习和信号处理中的普及发生在较晚时期 [26, 36]。

基本方案存在许多变体。一种基于 Nesterov 对梯度算法的经典修正 [65] 的版本，可达到 $\mathcal{O}(1/k²)$ 的收敛速率，总结见 [算法 8.5] [8]。在该算法中，更新被分为两部分。在近端算子中，使用通过涉及先前估计的平均获得的更平滑的估计版本。

#### 算法 8.5：快速近端梯度分裂算法

**初始化**

1. 选择 $\mathbf{x}_0$，$\mathbf{z}_1 = \mathbf{x}_0$，$t_1 = 1$。

2. 选择 $\lambda$。

**对于** $k = 1, 2, \dots$ **执行**

1. $\mathbf{y}_k = \mathbf{z}_k - \lambda \nabla g(\mathbf{z}_k)$

2. $\mathbf{x}_k = \text{Prox}_{\lambda f}(\mathbf{y}_k)$

3. $t_{k+1} = \frac{1 + \sqrt{4t_k² + 1}}{2}$

#### 算法步骤

4. $\mu_k = \frac{t_k - 1}{t_{k+1}}$

5. $\mathbf{z}[k+1] = \mathbf{x}[k] + \mu_k(\mathbf{x}[k] - \mathbf{x}[k-1])$

* **结束循环**

请注意，该算法涉及步长 $\mu_k$。变量 $t_k$ 的计算方式旨在优化收敛速度。然而，必须指出的是，一般来说，该方案的收敛性不再得到保证。

### 交替方向乘子法 (ADMM)

针对 $f$ 和 $g$ 均为非光滑的情况，近端分裂梯度算法的扩展也已开发，例如 **Douglas-Rachford** 算法 [27, 54]。此处我们重点介绍最流行的方案之一，即**交替方向乘子法** (ADMM) 算法 [40]。

ADMM 算法基于**增广拉格朗日**的概念，其核心在于拉格朗日对偶性概念（附录 C）。

目标是极小化 $f(x) + g(x)$，其中 $f$ 和 $g$ 均可为非光滑函数。这等价于写为

$$f(\mathbf{x}) + g(\mathbf{y})$$

##### 增广拉格朗日函数

增广拉格朗日函数定义为：

$$L_{\lambda}(\mathbf{x},\mathbf{y},\mathbf{z}) := f(\mathbf{x}) + g(\mathbf{y}) + \frac{1}{\lambda}\mathbf{z}^{T}(\mathbf{x} - \mathbf{y}) + \frac{1}{2\lambda}||\mathbf{x} - \mathbf{y}||^{2}$$

其中我们用 $\mathbf{z}$ 表示对应的拉格朗日乘子。

$$L_{\lambda}(\mathbf{x},\mathbf{y},\mathbf{z}) := f(\mathbf{x}) + g(\mathbf{y}) + \frac{1}{2\lambda}||\mathbf{x} - \mathbf{y} + \mathbf{z}||^{2} - \frac{1}{2\lambda}||\mathbf{z}||^{2}$$

##### Mirror descent algorithms

一类与前向-后向优化算法密切相关的算法族可以追溯到文献 [64] 的工作，称为 *mirror descent algorithms*（MDAs，镜像下降算法）。该方法经历了多个演化步骤（例如文献 [9, 66]）。我们的重点将放在采用在线方案来最小化正则化期望损失函数上：

```
J(θ) = 𝔼 [L(θ, y, x)] + ϕ(θ)
```

其中正则化函数 ϕ 被假设为凸函数，但不一定光滑。在该算法类的一个较新代表中，也称为 *regularized dual averaging*（RDA，正则化对偶平均）算法 [100]，主要迭代方程表示为：

```
θ_n = argmin_θ { ⟨L̄', θ⟩ + ϕ(θ) + μ_n ψ(θ) }
``` (8.139)

其中 `ψ` 是一个 `强凸` 辅助函数。例如，一种可能是选择 `ϕ(θ) = λ||θ||₁` 和 `ψ(θ) = ||θ||₂²` [100]。截至并包括时间瞬间 `n − 1` 时 `ℒ` 的平均次梯度记为 `${\overline{\mathcal{L}}}^{\prime}` ，即

```
${\overline{\mathcal{L}}}^{\prime} = \frac{1}{n - 1}\sum\limits_{j = 1}^{n - 1}\mathcal{L}_{j}^{\prime}(\mathbf{\theta}_{j})$
```

其中 `ℒj := ℒ(θ, y[j], x[j])`。

可以证明，如果次梯度有界，且 `μₙ = O(1/√n)`，则根据后悔分析论证可达到 `O(1/√n)` 的收敛速率。另一方面，如果正则化项是强凸的且 `μₙ = O(ln n / n)`，则可获得 `O(ln n / n)` 的速率。文献 [100] 中提出了不同的变体。其中一种基于 Nesterov 的论证，如 算法 8.5 所用，可达到 `O(1/n²)` 的收敛速率。

## 8.15 分布式优化：一些亮点

分布式优化（例如[86]）已在随机梯度下降的背景下进行过讨论，重点在于第 5 章中的 LMS 和扩散类算法，以及第 8.9 节。分布式或去中心化优化的核心在于一个代价函数，

```
$J(\\mathbf{\\theta}) = \\sum\\limits\_{k = 1}^{K}J\_{k}(\\mathbf{\\theta}),$
