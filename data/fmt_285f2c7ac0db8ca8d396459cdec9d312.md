# 简介

恭喜您购买 *AWS 认证解决方案架构师模拟测试*。本书将作为 Amazon Web Services (AWS) 认证解决方案架构师 (CSA) - 职业级考试的备考工具，同时也将助力您作为 AWS 解决方案架构师的职业发展。

本书的目标是通过解释考试中将涉及的术语和技术，帮助您通过 AWS 认证解决方案架构师 - 职业级考试。本书的主要重点是帮助您通过考试。基于这一重点，有时并不会涵盖某项 AWS 技术的方方面面，而有时又会特别强调一些非同寻常的边缘情况或细节。这些努力都是为了让您应对考试，而考试有时并不完全符合现实世界中云架构师的实用性。

话虽如此，学习这些奇特的细节和边缘情况在您的职业生涯中仍然大有裨益。考试主要基于用例，且答案选项中往往包含许多“看似正确”的答案和一个“最佳”答案。此外，这些答案通常包含无效或捏造的术语。了解 AWS 的奇特细节将帮助您识别这些不准确之处并排除无效答案。

## 认证的价值

AWS 已成为求职者最常见的要求之一。然而，随着许多组织首次迁移到 AWS 或招聘第一批 AWS 云工程师或解决方案架构师，要弄清楚值得向谁支付那些高额工程薪资并非易事。AWS 的认证往往是让您的简历、申请和经验在竞争者中脱颖而出的凭证。当您接受管理层面试和评估时，这一点尤为明显，因为认证是一个简单的区分标志。

此外，认证总体上会让您更具竞争力和就业能力。研究表明，学习技术的人更容易被录用。在入门级职位的竞争中，在学业中包含 IT 课程的高中或大学毕业生，在面试中的表现始终更好，且被录用的比例显著更高。

<https://www.aws.training/certification?src=arc-assoc>

## 参加考试

一旦您完全准备好参加考试，即可访问 AWS 认证网站进行预约和付费：

<https://www.aws.training/certification?src=arc-assoc>

AWS 与 PSI Exams (<https://candidate.psiexams.com>) 合作，因此当您预约考试时，将需要选择一个考试中心以及一个时间段。考试通常持续两小时，请相应做好计划。

考试当天，请务必提前 10 分钟到达，以防出现任何意外情况或遇到排队等候考试的人群。您还需要携带两种形式的身份证明。请记住，您不能携带笔记、电子设备（包括智能手机和手表）或其他材料进入考场。

考试中心将提供草稿纸，大多数中心还会提供耳机或耳塞，如果您觉得有助于屏蔽考试中心极小的噪音，可以使用。考试本身是在计算机上进行的，操作相当简单。

离开前请务必再次确认您已完成考试；虽然听起来很傻，但由于紧张或焦虑，很容易在考试结束时没有点击完所有提示就离开了。

## 考试目标

AWS 认证解决方案架构师 – 助理级考试将验证您在两个关键领域的技术专长：

*   接收客户需求，并运用 AWS 设计原则在架构层面定义合适的解决方案
*   基于最佳实践提供实施指导，这些实践超越了初始设计，涵盖故障排除、优化和成本考量

虽然考试指南建议具备一年的 AWS 经验，但您将从大量使用 AWS 控制台和搭建新基础设施中获益最多，特别是与计算（`EC2`）、存储（`RDS`、`DynamoDB` 和 `S3`）以及网络（`VPCs`）相关的内容。

实际考试分为五个不同的领域，每个领域侧重于一个特定目标，每个领域进一步细分为子目标：

**第 1 章，设计弹性架构（领域 1）** 选择可靠且有弹性的存储；确定如何使用 AWS 服务设计解耦机制；确定如何设计多层架构解决方案；确定如何设计高可用性和/或容错架构。

**第 2 章，定义高性能架构（领域 2）** 选择高性能存储和数据库；应用缓存以提高性能；设计弹性和可扩展性解决方案。

**第 3 章，指定安全的应用程序和架构（领域 3）** 确定如何保护应用程序层；确定如何保护数据；为单个 `VPC` 应用程序定义网络基础设施。

**第 4 章，设计成本优化架构（领域 4）** 确定如何设计成本优化存储；确定如何设计成本优化计算。

**第 5 章，定义运营卓越架构（领域 5）** 选择可实现运营卓越的解决方案设计特性。

### 复习题

1.  关于 `S3` 存储类的以下陈述哪一项是正确的？

    1.  `S3` 和 `S3-IA` 的可用性相同。
    2.  `S3` 和 `S3-IA` 的持久性相同。
    3.  `S3` 和 `Glacier` 的延迟相同。
    4.  `S3` 的延迟大于 `Glacier`。

2.  一家专门从事视频处理的小企业想要原型化云存储以降低成本。然而，管理层担心将客户文件存储在云端而不是本地。他们目前专注于成本节约和云端试验。什么解决方案最适合他们的原型？

    1.  安装 `VPN`，为最近一个月内创建的文件设置一个 `S3` 存储桶，并为较旧的文件设置一个额外的 `S3-IA` 存储桶。在 `S3` 中创建生命周期策略，每晚将超过 30 天的文件移动到 `S3-IA` 存储桶。
    2.  安装使用存储卷的 `AWS Storage Gateway`。
    3.  设置 `Direct Connect`，并每晚通过 `Direct Connect` 将所有本地硬盘备份到 `S3`。
    4.  安装使用缓存卷的 `AWS Storage Gateway`。

3.  有一组网页设计师经常将大型图片 zip 文件上传到 `S3`，文件大小经常超过 5 `GB`。最近，团队成员报告收到错误提示“您提议的上传超过了允许的最大对象大小”。应采取什么措施来解决上传问题？

    1.  增加网页设计师使用的目标 `S3` 存储桶中允许的最大对象大小。
    2.  确保网页设计师使用的应用程序或客户端利用 `Multipart Upload API`（分段上传 API）上传所有对象。
    3.  联系 `AWS` 并提交工单以增加默认 `S3` 存储桶大小；确保此设置也应用于网页设计师上传使用的目标存储桶。
    4.  登录 `AWS` 控制台，选择 `S3` 服务，找到您的存储桶。编辑存储桶属性并将最大对象大小增加到 50 `GB`。

4.  对于以下哪些 `HTTP` 方法，`S3` 具有最终一致性？（选择两项。）

    1.  新对象的 `PUT`
    2.  `UPDATE`
    3.  `DELETE`
    4.  覆盖现有对象的 `PUT`

## 12. 你在上一个 DevOps 冲刺中花费了数天时间构建了一个 AMI，开发团队的应用程序所有实例都应基于此 AMI。该应用程序将部署到多个区域并与多个 S3 存储桶交互，你现在需要在 `us-east-2` 和 `us-west-2` 中也提供该新 AMI，除了创建 AMI 的 `us-east-1` 区域外。如何使新 AMI 在 `us-east-2` 和 `us-west-2` 中可用？

1.  **将 AMI 从 `us-east-1` 复制到 `us-east-2` 和 `us-west-2`。使用复制的 AMI 启动新实例。**
2.  确保所有应用程序实例共享一个安全组。AMI 对安全组内的所有实例可用，无论 AMI 在哪个区域创建。
3.  你可以立即启动 AMI，因为所有 AMI 都通过 AWS 控制台出现在所有区域中。
4.  将 AMI 从 `us-east-1` 复制到 `us-east-2` 和 `us-west-2`。应用启动权限和 S3 存储桶权限，然后使用更新后的 AMI 启动新实例。
