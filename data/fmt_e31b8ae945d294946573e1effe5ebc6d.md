算法 4.2 中的训练流程可总结如下。在训练阶段，所有权值均以实值格式 `W` 存储，并在前向传播过程中二值化为 `W^b`（第 1—7 行）。前向传播结束后，通过将网络输出 `y` 与相应标签 `y*` 进行比较，生成误差信号 `δ`（第 9 行）。随后，误差信号 `δ` 被反向传播至各前一层，以计算权值梯度 `∂C/∂W` 和特征梯度 `∂C/∂x`（第 13—18 行）。注意，第 17 行所示，计算前一层特征梯度时，采用的是二值化权值而非实值权值 `W`。另一方面，`W` 的值在每次迭代中被约束在 `-1` 到 `+1` 的范围内，以确保收敛（第 21 行）。这不同于直接更新权值而不限制其幅度的传统更新方案。

**算法 4.2：** BNN 的训练流程。`L` 为层数，`Binarize` 定义二值化操作，`Conv` 定义二值卷积，`Norm` 定义归一化，`MaxPool` 定义 `2×2` 最大池化。

```
0: {前向传播:}

1: **for** `l = 1 to L` **do**

2: `W_l^b = Binarize(W_l)`

3: `x_l = Conv(x_{l-1}, W_l^b)`

4: `x_l = Norm(x_l)`

5: `x_l = MaxPool(x_l)`

6: `x_l = Binarize(x_l)`

7: **end for**

8: `y = x_L`

9: `δ = y - y*`

10: `δ = δ * ∂Binarize/∂x`

11: `δ = δ * ∂MaxPool/∂x`

12: {反向传播:}

13: **for** `l = L down to 1` **do**

14: `∂C/∂W_l = x_{l-1}^T * δ`

15: `δ = δ * W_l^b^T`

16: `δ = δ * ∂Norm/∂x`

17: `δ = δ * ∂Binarize/∂x`

18: **end for**

18: {权值更新:}

19: **for** `l = 1 to L` **do**

20: `W_l = W_l - η * ∂C/∂W_l`

21: `W_l = Clip(W_l, -1, +1)`

22: **end for**
```

位卷积神经网络（bitwise CNN）与直接截断 CNN（direct-truncated CNN，采用低精度位 [191]）之间的关键区别如下所述。直接截断 CNN 是在训练后阶段通过降低数值精度获得的，而此处开发的位卷积神经网络则是在二值约束下训练获得的 [188]。因此，直接截断 CNN 通常会遭受精度损失，但位卷积神经网络却能在最低精度下保留大部分精度。在推理阶段，仅保留二值化权值 `W^b`，从而实现更小的存储开销、更快的推理速度、更高的并行度以及更高的能效。

### 4.4 基于 TNN 的机器学习

前文讨论的神经网络压缩仅通过精度位截断或低秩近似 [192—195] 进行，难以在网络压缩与网络精度之间保持良好的平衡。通过利用高维空间中的自然稀疏性来表示稠密数据，张量化数据格式能够在不造成太大精度损失的情况下，显著压缩神经网络复杂度 [196]。相比之下，本节将探讨训练过程中的张量火车格式神经网络 [197]。首先介绍基于张量火车的分解与压缩。然后，基于通用神经网络的扩展，讨论张量化神经网络（TNN）。最后，进一步提出了一种采用修正交替最小二乘法（MALS）的 TNN 分层训练方法。为便于说明，我们先基于单隐藏层神经网络阐述该思路，随后将其扩展至多层神经网络。同时，还开发了一种基于张量火车的神经网络训练方法，该方法结合 MALS 方法考虑了模型压缩，并提供了复杂度分析。

#### 4.4.1 张量火车分解与压缩

张量是矩阵的自然多维推广。在此，我们将一维数据称为*向量*，记作 `x`。二维（2D）数组称为*矩阵*，记作 `X`，高维数组称为*张量*，记作如图 4.8 所示。若要从张量中引用某个特定元素，本章使用花体大写字母 `X`，其中 `N` 为张量 `X` 的维数。可将 2D 矩阵有效重塑为四维（4D）张量，如图 4.8 所示。

![image](img/PBPC0390-04-f08.jpg)

图 4.8 分块矩阵及其用 4D 张量表示

若 `N` 维 `I_1 × I_2 × ... × I_N` 张量 `X` 的张量核 `G_k` 定义为 `G_k ∈ R^{R_{k-1} × I_k × R_k}`，且每个元素定义 [197] 为

```
X(i_1, i_2, ..., i_N) = Σ_{α_0, ..., α_N} G_1(α_0, i_1, α_1) G_2(α_1, i_2, α_2) ... G_N(α_{N-1}, i_N, α_N)
```

则称该张量分解为张量火车数据格式。其中 `α_k` 为求和索引，从 1 开始至秩 `R_k` 结束。`R_0 = R_N = 1` 为边界条件，`I_k` 称为模态尺寸。此处，`R_k` 为核秩，`G_k` 为此张量分解的核。利用 `G_k(i_k)` 记法，可将上式改写为更紧凑的形式：

```
X = G_1 ×_1 G_2 ×_2 ... ×_{N-1} G_N
```

其中 `G_k(i_k)` 为 `R_{k-1} × R_k` 矩阵，即从 3D 矩阵 `G_k` 切取的一个切片。

这种表示法存储高维数据时内存效率高，因而也能显著节省能量。例如，一个 `N` 维张量需要 `Π_{k=1}^N I_k` 个参数。然而，若采用张量火车格式表示，则仅需 `Σ_{k=1}^N R_{k-1} I_k R_k` 个参数。因此，若能降低各核的秩，便可高效地以高压缩率表示数据并分布式存储。通过将神经网络权值排列为高维数据，可实现神经网络压缩。此处，若神经网络的权值可用张量火车数据格式表示，则定义为 TNN。例如，二维权值 `W ∈ R^{I × J}` 可通过分解 `I = Π_{k=1}^d n_k` 和 `J = Π_{k=1}^d m_k` 重塑为 `2d` 维张量 `W ∈ R^{n_1 × m_1 × ... × n_d × m_d}`，且该张量可分解为张量火车数据格式以节省存储空间^(1)。

#### 4.4.2 基于张量火车的神经网络

### 基于张量火车的神经网络 (TNN)

为了阐明 TNN，本节从一般的前馈神经网络入手，然后将其扩展到基于张量火车的神经网络。为了便于说明，本节以单隐藏层神经网络为例；相同的原理也可应用于多层神经网络 [199—201]。

通常，神经网络的训练是基于具有 `N` 个训练样本、`D` 维输入特征和 `C` 个类别的数据特征 `X` 和标签 `Y` 进行的。在训练过程中，需要最小化具有确定权重的误差函数：单隐藏层神经网络的 `W_in`（输入层）和 `W_out`（输出层）[2]：

```
E(W_in, W_out) = ||Y - f(X; W_in, W_out)||²
```

其中 `f` 是用于根据输入执行预测的训练模型。

本节主要讨论推理（测试）过程，稍后介绍训练过程。每一层的输出基于矩阵乘法和激活函数。例如，第一层的输出 `H` 在数学上定义为：

```
H = σ(X W_in + b_in)
```

其中 `X` 是测试数据。`W_in` 和 `b_in` 分别是输入权重和偏置。然后，单隐藏层神经网络的神经网络输出为：

```
Y_pred = H W_out + b_out
```

```
Y_pred(c) = H W_out(:, c) + b_out(c)
```

其中 `c` 表示类别索引 `c ∈ {1, ..., C}`。我们通过神经网络的输出来近似每个类别的预测概率。

## 基于张量火车的神经网络推理

对于基于张量火车的神经网络，**图 4.9** 展示了总体思路。一个二维权重被折叠成一个三维张量，然后分解为张量核 `G_k`。由于秩 `R` 的值较小，这些张量核是相对较小的矩阵，从而实现了较高的神经网络压缩率。然后，整个神经网络将在张量火车数据格式下进行训练。

![图 4.9 神经网络权重张量化并用张量火车数据格式表示以实现参数压缩（从 W_in 到 G_k）](img/PBPC0390-04-f09.jpg)

TNN 推理是张量火车矩阵乘向量运算的直接应用 [196,197]。我们将使用 `W_in` 来讨论神经网络的前向传播。首先，我们将 `X` 重排为一个 `d` 维张量 `X_tensor`，其第 `k` 维是一个长度为 `n_k` 的向量。此处，`n_k` 和 `R_k` 定义为 `n_k = n_k` 和 `R_k = R_k`。不考虑偏置 `b_in` 和激活函数的情况下，张量火车数据格式下的神经网络前向传播 `H` 为：

```
H = X_tensor ×_1 G_1 ×_2 G_2 ... ×_d G_d
```

其中 `G_k(i_k)`、`G_{k+1}(i_{k+1})` 和 `G_{k+2}(i_{k+2})` 是核的切片。我们使用一对 `(k, i_k)` 来指代向量 `X_k` 的一个索引，其中 `i_k ∈ {1, ..., n_k}`。由于全连接层是核大小为 `1×1` 的卷积层的特例，这种张量化的权重也可应用于其他卷积层。

这种张量火车矩阵乘向量乘法的复杂度为 `O(d R² n)` [196]，其中 `R` 是核 `G_k` 的最大秩，`n` 是张量 `X_tensor` 的最大模态尺寸 `n_k`。如果秩 `R` 与一般矩阵-向量乘法相比非常小，这将非常高效。由于每个核都很小且矩阵乘法满足结合律，这也有利于在 ReRAM 设备上进行分布式计算。

#### 4.4.3 TNN 训练

基于张量火车的神经网络最早由 [196] 提出，但由于张量火车数据格式下的反向传播 (BP)，其训练复杂度显著增加。逐层训练以减少的反向传播轮数提供良好的性能，从而显著减少训练时间 [200—202]。此外，为了成功映射 TNN，需要对 TNN 进行递归训练，以权衡精度和压缩率。因此，本章为 TNN 开发了一种快速逐层训练方法。

TNN 的训练过程与一般神经网络的逐层训练相同，但采用张量火车数据格式。我们首先遵循 [53] 的训练框架讨论一般训练过程，然后将其扩展到 TNN。给定一个具有随机生成的输入权重的单隐藏层，训练过程旨在最小化：

```
E = ||Y - H W_out||² + λ ||W_out||²
```

其中 `H` 是由 Sigmoid 函数激活生成的隐藏层输出矩阵，`λ` 是一个用户定义的参数，用于平衡训练误差和输出权重 [53]。输出权重 `W_out` 基于最小二乘 (LS) 问题计算：

```
W_out = H^† Y
```

其中 `H^†` 是 `H` 的伪逆，`C` 是类别数量。`H ∈ R^{N×L}` 且 `Y ∈ R^{N×C}`。

要构建多层神经网络，可以应用反向传播 [199] 或使用自编码器技术的逐层训练 [200,201]。自编码器层将单层输出 `H` 设置为与输入 `X` 相同，并找到一个最优权重来表示其自身。通过在最终决策层上堆叠自编码器层，我们可以构建多层神经网络。**算法 4.3** 总结了采用改进最小二乘求解器 (MALS) 方法的逐层训练。

### 算法 4.3：采用改进最小二乘求解器的神经网络逐层训练

**输入：** 输入集 `D = {X, Y}`，`X` 为输入数据，`Y` 为根据层架构确定的期望输出，激活函数 `σ`，隐藏神经元节点数 `L`

**输出：** `K` 层神经网络的神经网络权重 `W`

1: **for** `k = 1 to K` **do**

2: **if** `k == 1` **then**

3: 对 `X` 和 `Y` 进行因子分解（例如，`X = X_tensor` 和 `Y = Y_tensor`）。

4: 随机生成张量核 `G_1`、`G_2` 和其他张量核以表示张量 `W_in`

5: **else**

6: 按照步骤 3、4 随机生成 `W_in`

7: 基于（公式 4.8）执行张量火车矩阵乘向量乘法，这等价于 `H = f(X W_in)`

8: 执行激活函数，这等价于 `H = σ(H)`。

9: 使用 MALS 计算 `W_out`：`W_out = argmin ||Y - H W_out||² + λ ||W_out||²`。

10: 注意：{对于自编码器层，`Y` 是激活矩阵 `H` (`Y = H`)。对于决策层，`Y` 是标签矩阵 `Y`。

11: `end if`

12: `end for`

TNN 旨在开发高维权重并使用张量列车分解方法对其进行压缩。例如，一个 `M × N` 全连接层可以表示为一个 4D `I_1 × I_2 × I_3 × I_4` 张量。因此，我们不生成随机输入权重 `W_in`，而是通过指定每个核 `G_k` 的秩来生成一个低秩张量 `W_in`。然后输入权重可以通过 (4.23) 生成，其中每个核 `G_k` 都是随机生成的。
