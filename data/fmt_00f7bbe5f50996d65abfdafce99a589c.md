除非包含了冗余变量（如子量表分分和总分、年龄和出生年份），否则很难发现完全多共线性。然而，发现预测变量高度共线的情况并不稀见。在这种情况下，统计软件将执行回归，但回归系数的值可能极其不稳定。其原因是预测变量共享的 `Y` 变异性被“分配”到了这些变量之间。这种分配的性质取决于数据的具体细节，并且在不同样本之间存在很大差异，导致回归系数的标准误剧增。

### 方框 22.1 多共线性的物理演示及其后果

- 1. 在桌子上以大致三角形排列放置三个不同高度的物体，例如一个汽水罐、一瓶葡萄酒瓶和一瓶洗手消毒液。从概念上说，桌子的一个角定义了点 $(X_1 = 0, X_2 = 0)$，因此桌子的边缘定义了“物体”位置的 `X1` 和 `X2` 的值。每个 $(X_1, X_2)$ 处的 `Y` 值由每个物体的高度表示。
- 2. 放置一个平整的物体（如纸或硬装书），使其接触到三个物体的顶部。这个表面就是根据 `X1` 和 `X2` 预测的 `Y` 的最佳拟合平面。
- 3. 注意，回归平面是完美且唯一拟合的：平面的任何其他放置都会在物体顶部与其在回归表面上的预测值之间产生间隙，这就是残差。
- 4. 接下来，重新排列三个物体，使其按高度从低到高排成直线。
- 5. 通过将标记放在物体上。你会发现你可以这样做，但没有唯一解：回归平面可以绕连接三个物体顶部的直线进行旋转。这就是多共线性的物理演示，因为 `X2` 的值可以根据 `X1` 完美预测，反之亦然。
- 6. 最后，将步骤 4 中的物体线移动到桌子的一侧（称之为 `X1`）。当旋转旋转回归平面时，注意平面沿 `X1` 方向的斜率是不变的，因为它是由你所物体的相对高度决定的。相比之下，沿 `X2` 方向（桌子的垂直边）的斜率随着平面的旋转而变化：它有时为正，有时为负，偶尔为零。这是多共线性的可能后果之一：回归系数是欠定的，在某些条件下，可能会改变符号。

### 22.5.1 多共线性的衡量

有两个衡量方法对于诊断多共线性问题很有用：容度（tolerance）及其倒数——方差膨胀因子（VIF）。容度是衡量预测变量与其他预测变量之间非冗余程度的指标。只有两个预测变量时，容度为 1 减去两个预测变量之间相关的平方。一般而言，

> 第 `j` 个预测变量的容度 = `1 - Rj^2`。

`Rj^2` 是当 `Xj` 对方程中所有其他预测变量进行回归时的多元相关系数平方。换句话说，容度是衡量方程中其他预测变量对 `Xj` 预测程度的指标。

### 22.5.2 使用软件获取多共线性衡量

统计软件提供了用于判断是否存在严重多共线性问题的诊断信息。在 R 中，假设 `lm` 函数的结果存储在 `reg_out` 中。那么 `[car]` 包中的 `vif` 函数返回每个预测变量的方差膨胀因子。容度是简单的 `1 / vif(reg_out)`。在 SPSS 中，设置回归并点击 Statistics，勾选 Collinearity。生成的输出将包含每个预测变量的容度和 VIF。

### 22.5.3 处理多共线性的策略

如果我们发现数据中存在多共线性问题，建议了一些解决办法：

- 删除某些引起问题的预测变量。如果我们有同一个潜变量的多个测量，这可能是合适的。然而，如果我们有多个不同类型的高度相关测量，这种治疗可能适得其反。删除变量可能会导致设定误差，且预测变量与误差本身之间的相关可能会产生严重的后果，正如我们之前讨论过的。更好的方法可能是合并预测变量，正如我们接下来描述的。
- 将高度相关的预测变量合并为代表共同因素的新变量。合并变量应基于理论考虑。主成分分析和因子分析等程序也可以提供关于哪些变量可以合并的建议。粗来说，这些方法识别了解释 `Y` 系统变异的预测变量线性组合。通过评估预测变量的权重，这些因子可以解释为反映如“语言能力”或“自尊”等潜变量。这些方法是本书的讨论范围。

## 22.6 直接效应与中介效应的回归

自变量可以直接影响因变量，也可以通过对中介变量的影响间接影响因变量。图 22.3 提供了这种区别的插图。在面板 (a) 中，我们有一个 X 对 Y 产生直接影响的模型。这种因果影响由箭头表示，箭头的方向表示因果关系的方向。在面板 (b) 中，我们有一个展示了直接效应和中介效应的因果模型。在这种情况下，X 的变化直接影响 Y，但也会通过中介变量 `X1` 间接影响 Y。有很多变量影响工作感知例子，这些反过来影响生产力；或者父母对教育态度的变化可以改变孩子的特征，进而影响学业成绩。在心理学的许多领域，规定在自变量和因变量之间干预过程的理论都是相关的。科学引文（Web of Science）显示，关于中介效应检验的开创性论文 Baron and Kenny (1986) 已被 54,000 次引用。

当我们试图确定一个变量的重要性时，必须考虑中介的可能性。如果我们在回归方程中包含了正确的变量，且 X 与结果之间存在因果关系，那么回归系数 `by` 并不估计 X 对 Y 的总影响。相反，回归系数反映了 X 对 Y 的直接效应，即在保持方程中所有其他变量不变的情况下，Y 随 X 的变化。如果 X 的变化导致了某些其他变量的变化进而改变了 Y，那么我们就有直接效应和间接效应。在评估 X 的影响时，我们既关注直接效应也关注间接效应。给定因果结构模型，可以使用结构方程模型来评估改变一个变量的总效应。然而，如果模型中遗漏了重要变量或者模型本身无效，这些估计可能会产生误导。

再次考虑图 22.3 中的两个因果模型。在面板 (a) 中，X 变化一个单位导致 Y 变化 `c` 个单位。在面板 (b) 中，我们有一个展示了直接效应和中介效应的因果模型。其中，X 变化一个单位直接导致 Y 变化 `c'` 个单位以及 X 变化 `a` 单位。X 变化一个单位导致 Y 变化 `b` 个单位。因此，X 通过中介变量 `X2` 对 Y 的间接效应是 `ab`，`c + ab`。Baron 和 Kenny (1986) 讨论了建立数据集与中介存在一致所需的四个步骤。这些步骤翻译成我们的术语如下：

- 步骤 1。将 `Y` 对 `X1` 回归。如果系数 `by` 不为零，则与 `X1` 对 `Y` 有因果影响一致（但并非必要）。
- 步骤 2。将 `X1` 对 X 回归。如果系数 `b2` 不为零，则与 X 对中介 `X2` 有因果影响一致。
- 步骤 3。将 `Y` 同时对 `X1` 和 `X2` 回归。`X1` 的系数 `by1` 是当 X 保持不变时预测 Y 的变化率，因此根据面板 (b) 中的模型，`by1` 是 `c'` 的估计，即从 `X1` 到 `Y` 的因果路径。发现 `by1` 不为零但 `by2` 为零，与 X 对 Y 的整个效应均由中间变量 `X2` 中介的模型一致。发现 `by2` 不为零但小于 `by1`，则与 `X2` 的部分中介一致。

## 多元回归 601 中的其他主题

X 被称为中心化（centering）。如果我们从 X 的每个观测值中减去其平均值，方程 22.2 变为：

```
\hat{Y} = b0^c + b1^c(X - \bar{X}) + b2^c(X - \bar{X})^2  (22.5)
```

如果我们展开这个方程并与方程 22.2 进行逐项比较，会发现 `b2^c = b2`。也就是说，无论在执行回归前是否从 X 中减去平均值，平方项的系数都是相同的。这是一个普遍性发现。在任何类型的多项式，无论是否从 X 中减去常数，高阶项的回归系数都是相同的。我们还可以证明 `\hat{Y}` 相对于 X 的斜率为 `b1' + 2b2'(X - \bar{X})`，因此我们可以解释为 `X = \bar{X}` 处的斜率为 `b1'`。显著性检验允许我们确定斜率在 `X = \bar{X}` 处是否显著于零。

数据集中年龄 65 岁及以下且胆固醇水平女性的平均 BMI 得分为 26.599。如果我们令 `BMI = BMI - 26.599` 并对 TC 和 `BMI^c` 进行回归，我们发现：

```
\tilde{TC} = 26.047 + 2.114 \ BMI - 0.187  (22.6)
```
