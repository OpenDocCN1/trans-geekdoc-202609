# 第一部分 医疗领域深度学习的新兴技术

## 1 健康数据分析的深度学习模型

### 1.1 引言

电子健康记录（EHR）是一项重要的数据资源，它可以改善医疗决策和医疗服务交付监测，并允许开发早期风险评分模型。基于 EHR 的预测模型通过深度学习（DL）技术的使用得到了改进，这种技术在存在大量数据以及输入特征与目标预测之间可能存在复杂关系时表现出色。然而，EHR 数据具有特性，例如事件之间复杂的依赖结构、事件频率以及缺失的患者群体数据等（Lee 等，2024）。这些 EHR 数据维度导致了对 DL 方法的使用，这些方法通常不仅用于图像、语音和自然语言处理，而是专门为满足 EHR 数据分析的需求而设计的。DL 在利用 EHR 数据开发预测模型时可能特别有用，因为：

- EHR 数据内在的模式是未知的，而深度学习模型可以自动提取、学习并利用这些复杂模式；
- 预测性能通常随着标注示例的增加而显著提高，大型医疗系统可以提供大量的标注 EHR 数据；以及
- 训练最终预测模型的标注 EHR 数据可用性可能是有限的，深度学习模型可以通过半监督学习利用易获取的代理标签和额外的无标签数据首先学习模型。

然而，在开发和部署直接影响患者结果的`DL`模型时，领域专家应仔细考虑电子健康记录（EHR）数据的固有属性，以及与预测决策支持工具相关的不确定性和风险。

电子健康记录（EHR）是医生办公室纸质图表的数字化版本。它们以医疗机构管理的形式包含了个人护理的医疗和治疗历史（Qu et al., 2024）。EHR 不仅仅是患者的病史；它促进了基于证据的决策，自动化并简化了提供者相关的流程，并向不同的临床团队传递信息。EHR 数据源对于二次利用变得越来越有价值，包括当前临床研究领域，以及医疗系统评估和公共卫生的健康研究。它们对于补充其他来源的健康和非健康数据也重要，以支持新兴健康数据研究并产生医学新知识（Shafik, 2024h）。

同时，EHR 数据的复杂性也带来了与大数据相关的问题。高数据量、处理速度和多样性使得数字分析变得昂贵且难以处理，而传统的辅助统计分析方法对于快速决策来说又太慢。因此，我们正处于一场“数据驱动”运动之中，该运动通过促进 EHR 的整合以及创建供数据分析师使用和操作的数据库，提高了科学研究的统计能力（Boudali et al., 2024）。

### 1.1 EHR 的定义与重要性

EHR 指数字格式记录的患者健康信息，包括患者人口学信息、药物、病史、测试结果和影像结果，并可以在不同的医疗机构之间共享。EHR 可以包括所有临床和行政数据，如生活状况、居住地、社会护理、诊断治疗目标或计划、实验室检查结果、药物和治疗报告。在现代医疗系统中，数据的准确性和可访问性会极大影响患者护理（Feng et al., 2024）。

传统的，患者的健康记录以纸质形式保存，但这些记录容易丢失，除非患者选择这样做，否则无法复制或备份；因此，在不同医疗提供者寻求服务的患者无法轻松提供他们的病史。相比之下，EHR 以数字形式保留并具有很高的访问性。这有利于接受了这种生活方式的从业者，大型个人或团体诊所现在由于监管压力正在引入这些系统（Shafik, 2024g）。临床环境中的患者护理健康记录审查是协调进行的。以数字保留这些记录可以使用大数据和电子健康来追踪模式和疾病，为诊断治疗的新维度和新途径的巨大潜力铺了道路。

### 1.2 EHR 数据分析的挑战与机遇

EHR 也是临床证据的重要来源，因为它们提供了有关临床方案的信息。EHR 数据分析可以发现风险因素并识别相关特征，从而支持医生的决策并改善患者结果。然而，由于 EHR 数据充满了临床特定的术语、程序和活动，它们非常复杂，因此难以管理。虽然医疗保健领域的大数据分析应用前景广阔，但这些应用必须克服各种障碍。一些重大挑战包括数据的复杂性、集成问题和安全威胁（Chen & Kong, 2024）。

数据质量是实现成功数据挖掘和分析的另一个重大障碍；数据不准确是一个明显的问题，因为不准确会导致错误的结论。然而，一个更严重的问题是糟糕的洞察，即将正确的知识应用于错误的数据上。今天，只有在人口层面关于个人健康的更全面的知识，才能对国家健康活动的影响提供长期预防视角（Shafik, 2024c）。迄为止，临床研究一直是产生知识最常用的方法。与营养、农耕和食品研究一起，这些方法至关重要，但往往是不够的。这就是 EHR 系统数据库分析的巨大潜力。在数据足够的情况下，可以探索几种对改善健康有贡献的新颖方法。在国际范围内广泛使用数据，包括预测性分析和`DL`分析。在此类分析中，我们研究所有收集的特征之间的关系，以便我们说：“如果我知道特征‘A’，我就不需要特征‘a’了，因为第一个特征中包含了更多信息”（Kumar et al., 2024）。

### 1.3 深度学习基础

`DL`在处理大型复杂数据集方面取得了巨大成功，并为处理医疗数据（特别是 EHR）提供了一种强大的方法，如 图 1.1 所示的其他专家系统。从根本上说，`DL`模型类似于传统的机器学习方法，即模型为下游任务学习最佳特征。然而，`DL`比传统的机器学习方法具有更强的表示能力，并赋予研究人员更多的分析自由。与局限于从机器读输入提取特征的传统方法不同，`DL`模型可以直接在原始数据（如图像、音频和文本）上运行（Goldstein et al., 2024）。因此，高容量模型学习的特征具有各种抽象级别，从简单特征到更复杂的表示，基于这些特征的预测要准确得多。

这些表示学习方面的优势使得`DL`成为复杂模式医疗数据的合适选择。所有`DL`模型的核心都是神经网络。从概念上说，神经网络是人脑的数学表示，由互联的节点或神经元组成。节点之间的每个连接都有一个相关的权重，可以根据输入数据进行修改。当给定输入数据时，网络通过每一层执行一系列变换，其中输入数据与权重矩阵相乘，并应用非线性函数以引入非线性（Shafik, 2024e）。该过程产生一个或多个用于分类、回归或其他任务的输出。这种基本结构可以适应许多不同的神经网络架构，例如循环神经网络和卷积神经网络，每种都有其特定的应用。

#### 1.3.1 神经网络

神经网络是部分模拟动物大脑生物神经网络的计算系统，主要由神经元、突触和轴突组成。当外部输入刺激某一层中的神经元时，它们会同步放电并向层内的其他神经元传递信息。一层神经元的输出将作为下一层的输入。神经元之间的连接强度会根据`backpropagation`（反向传播）等策略进行调整，以使用标注的地面真值来最小化特定误差：这就是学习过程。一层中的所有神经元都与下一层的其他神经元连接，从而形成了类似于生物系统的多类层 (Afshar et al., 2023)。信息流的知识流动方向通常被称为前馈。

神经网络由神经元、权重和层组成；这些概念共同被用于构建各种架构。神经网络由三个关键部分组成：神经元、激活函数和层。神经元是一个计算单元，它接收多个输入，并在数学处理或使用激活函数后产生输出。每个输入都与权重相乘并求和，然后加上偏置值。神经网络架构中的激活函数是神经元的关键组件，负责产生输出 (Shafik, 2024e)。该函数根据输入的值决定是否以及传输多少信号到下一层。而层是神经元的集合，执行特定的特征变换或数据处理函数；多个层连接在一起组成一个神经网络模型。神经网络中有三种常见的层：输入层、输出层和隐藏层；这些层通过链接相互连接，代表神经元的输入和输出。当一个网络包含多个隐藏层时，它被称为深度神经网络。除了上述组件，研究人员还描述了神经网络中几种关键的先进架构，用于回答特定的健康相关问题 (Hossain et al., 2023)。在引入这些先进架构之前，我们首先介绍神经网络中的训练和学习，它们构成了核心部分。

## 1.3 医疗领域的深度学习

深度学习技术在医疗领域展现了巨大的潜力。它们能够抽象端到端训练之下复杂的编码算法，从而有助于常规流程的自动化并最终改善临床决策。深度学习增强了医疗保健和预防医学的质量，并显著降低了成本。该技术在医疗知识的许多领域已显示应用，特别是医学影像分析和内容个性化。

- 深度学习在医学图像分类方面表现良好 (Feng et al., 2024)。
- 当有大数据帮助训练系统时，医学影像分析中的深度学习变得非常有用，目前的医疗和保健图像存档及集合正在迅速增长，因此包含了大量的自动化医学影像数据集 (Shafik, 2024f)。医学影像的深度学习提高了诊断、治疗和处方的准确性；结果显示`DL`在诊断病理和预测患者预后方面达到了放射级的准确率，优于传统方法。事实上，已发现`DL`算法在自动乳腺癌摄影识别的增强临床决策支持方面，优于传统的图像解读方法。将`DL`整合到临床成像中以提供患者健康建议，在改善患者结果方面具有巨大潜力 (Ashfaq et al., 2019)。

### 1.3.1 医学影像分析

在医疗保健中，诊断、疾病监测和治疗计划长期以来依赖医学影像作为核心数据。模态的多样性是一个重大挑战。磁共振成像（`MRI`）和计算机层扫描（`CT`）使人体精细结构视觉化。超声为受影响的组织、器官提供视觉诊断，在心脏和肌肉收缩期间 (Yao et al., 2018)。

正电子发射断层和单光子发射断层扫描为癌症、心脏疾病、阿尔茨海默病和帕金森病等系统性疾病提供分子图像。自 2012 以来，用于图像的深度学习（即所谓的卷积神经网络`CNNs`）已成为视觉识别和检测的主流方法。各种医学影像深度学习模型被设计用于揭示传统经验规则容易忽略的复杂模式 (Kumar et al., 2024; Shafik, 2024a)。

医学影像深度学习模型持续表现出人类水平甚至超越人类的性能，优于设计良好的传统机器学习模型。例如，密集连接`CNN`在`CT`图像的病变检测方面优于放射科医生。`Inception CNN`和`ResNet CNN`的集成模型在通过扩散张量`MRI`识别癫痫侧方面优于放射科医生。用于乳腺摄影分类的`Xception CNN`和用于乳腺超声的`DL`都提供了高诊断准确率，减少了假阳性病例和必要的活检 (Chintala, 2024)。

医学影像中的疾病分割通过深度学习模型是可行的。例如，`PIXI-Net`在`CT`风险器官联合检测和分割方面优于结合传统级联的`U-Net`。专门设计的医学影像深度学习模型还可以结合临床数据库、大规模研究或社交媒体的电子健康记录（`EHR`）数据，辅助疾病诊断和风险分析 (Shafik, 2024a)。孪生神经网络`DL`模型在与纹理图像结合时，可以基于淀粉蛋白斑块脑图像检测阿尔茨海默病的进展，而`3D U-Net`提高了基于`MRI`的胶质母细胞瘤治疗计划的诊断准确性。

目前已提出了许多用于临床决策支持系统（CDSS）的模型。CDSS 用于检查和分析患者信息、预测患者护理需求、提供建议治疗等，基于患者数据提供基于证据的结论、建议或推荐。大多数现有基于深度学习（DL）的方法都集成了电子健康记录（EHR）库，以发现新的临床特征，或为各种任务构建不同的模型，并在每种方法中实时更新（Negro-Calduch et al., 2021）。某些模型利用智能设备提供基于证据的建议（参见图 1.3）。

与此同时，使用实时 EHR 数据的优势之一是能够探索基于时间的数据与结果之间的内在关系；也就是说，CDSS 可以预测患者可能的结果。在患者数据中捕捉关系和模式以进行智能决策，是设计基于深度学习的方法的目标。医生和管理者理解、评估和解释这些模型结果的能力对于 CDSS 的成功至关重要（Shafik, 2024b, 2024d）。这些工具最重要的方面是它们是以人为中心的，它们增强了复杂的医疗实践，并有助于临床实践的个性化和个体化。

EHR 数据库还允许对患者护理进行深度分析。患者 EHR 数据的大量和高维性使得人工智能方法成为可能，扩展了深度学习方法的效率（Boudali et al., 2024）。用户界面是医生人员接受基于深度学习的 CDSS 的关键因素。尽管模型透明度对用户来说可能并不重要，但在司法领域，维护患者信任的问题至关重要。此外，保护患者信息的机性和隐私是一个日益受到关注的问题，需要医学界的关注（Afshar et al., 2023）。

### 1.3.3 医疗保健中的自然语言处理

自然语言处理（NLP）的几个子领域对健康相关文本的分析有所贡献，包括命名实体识别、概念映射和关系提取。命名实体识别（NER）是许多 NLP 系统的核心组件，涉及识别特定类的术语，例如人名、疾病或医疗程序。在临床领域，NER 系统通常针对体征和症状、疾病、药物名称和操作。实体映射涉及将识别出的提及链接到标准术语或本体论（Gong et al., 2021）。

疾病规范化是将临床文本中识别的疾病映射到标准术语集中唯一标识符的任务。药物映射是识别临床叙述中的药物提及，然后将提及映射到传统药物名称的任务。由于药物通常以品牌名称或通用名称指代，因此 NLP 系统需要识别这些名称并将其映射到基础或通用名称，然后可以在术语中使用。最后，关系提取解决了从文本中识别涉及实体对之间关系的结构化信息的问题（Guo et al., 2020）。

传统的 NLP 方法在应用于非研究性医疗记录时确实存在局限性，因为记录中存在许多“是或否”的问题和勾选列表。传统模型对于研究论文中不可或的结构化表格和段落效果良好，但对于 EHR 文档更不规则、更专业的构成则并不那么容易。大量潜在噪声字段的存在会增加模型的复杂性，因为需要从大量字段中提取引用，而这些字段并非所有都存在，但在研究型文档中这些字段是预期的存在的。然而，需要注意的是，这些局限性源于传统的 NLP 模型，而新兴深度学习模型领域正在取得实质性改进（Guo et al., 2021）。

## 1.4 用于 EHR 数据分析的深度学习架构

如上一节所述，医疗数据量的不断增加和性质的复杂促使了许多专门为 EHR 数据定制的先进机器学习模型的发展。特别是，深度学习模型因其高层特征表示能力正引起日益增长的兴趣。

对于混合了分类和数值变量的 EHR 数据，循环神经网络（RNN）已被证明是利用 EHR 数据序列特征的有效架构。RNN 可以处理跨越时期保留并传播重要信息的序列数据特征，这对于 EHR 数据分析非常有用，因为临床数据（包括医疗代码、药物和备注）具有天然的时间序列（Alaboud et al., 2023）。具体而言，长短期记忆（LSTM）网络——一种可以处理长期依赖问题的 RNN 模型——已被广泛应用于 EHR 数据分析。这是因为它们具有处理和存储更久远过去之信息的能力，解决了 RNN 模型在通过时间反向传播优化时遭受的梯度消失问题（Si et al., 2021）。

LSTM 架构已用于各种结果分析，例如疾病和表型的分类或亚型分型、患者疾病轨迹分析、患者再入院/住院时长预测以及患者表型复审。这些结果表明了深度 EHR 架构在揭示未知的患者亚型分类和疾病进展模式方面的潜力，并可以被用于未来的临床研究和 CDSS 的开发。许多为 NLP 和其他类型数据开发的现成架构并不适用于捕捉医疗数据中的符号复杂性（Negro-Calduch et al., 2021）。因此，出现了许多针对医疗数据格式的专用深度学习架构。

### 1.4.1 RNN

EHR 具有时间序列患者数据，而 RNN 作为一种深度学习模型，能够保留它们在数据序列随时间看到的内容，例如糖尿病的进展；记忆通过层的隐藏状态维持。由于这种设计，RNN 非常适合分析如 EHR 数据之类的序列数据。即使对于长输入，RNN 也能保留序列的记忆，而用于长序列输入的标准深度学习技术并不一定在整个序列上表现良好，因为存在梯度消失问题，即在反向传播过程中，网络早层几乎没有或完全没有梯度（Chintala, 2024）。这是因为梯度在网络中层层相乘后会变得非常小。

解决此问题的方案是门控机制，允许梯度在不改变的情况下被反向传播，例如 LSTM 和门控循环单元。RNN 的一个主要优势是它们可以在不需要对齐序列的情况下学习输入之间的复杂映射。在训练期间，RNN 的输入不仅感兴趣的序列，还可以包括每个输入序列与真实数据之间的学习映射得分。使用 RNN 的主要挑战之一是，在训练具有更多 RNN 单元的深层时，速度可能会变得非常慢，因为它们必须以更复杂的计算方式学习反向传播和更新时间步（Shickel et al., 2018）。

解决这一问题的常见方案是梯度裁剪，它对最大梯度设置了阈值，并影响梯度在网络中反向传播的位置。RNN 可以被复制，使得多个 RNN 可以同时正向和反向学习序列。这增加了网络学习输入序列中新特征的表面积。这些被称为双向 RNN。堆叠 RNN 可以在粗粒度并行度和更细分辨率上对数据进行建模 (Yao et al., 2018)。图 1.4 展示了如何将 EHR 数据集成到物联网中以改善患者护理。

### 1.4.2 LSTM 网络

LSTM 网络是专门开发的特殊神经网络，用于处理长程依赖，并提高相关信息之间差异可能巨大的学习任务的性能。因此，LSTM 是专门设计的 RNN，旨在改进后者在学习包含滞后或时间间隔的序列数据时的局限性。EHR 数据从根本上依赖于时间，并且充满了可能对患者健康状况产生直接或延迟影响的事件，LSTM 是健康信息学和基于 EHR 的分析中广泛使用的深度学习架构 (Hossain et al., 2023)，因为它们能够捕捉长达几十年的患者数据。
