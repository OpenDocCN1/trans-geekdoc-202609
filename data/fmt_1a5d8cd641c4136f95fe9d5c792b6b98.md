
`d(x, y) = sqrt(sum_{i=1}^n d(xi, yi))`  (16.1)

```
其中 `d(xi, yi)` 是第 `i` 维的贡献。对于数值属性，该贡献可以使用欧欧距离公式计算 `d(xi, yi) = (xi - yi)²`；对于布尔属性和离散属性，如果 `xi = yi` 则定义 `d(xi, yi) = 0`，如果 `xi != yi` 则定义 `d(xi, yi) = 1`。
```

### 适应度函数

下一个问题是如何量化每个个体的生存概率。记住，我们希望在不损害分类准确性的情况下减少示例和属性的数量。这些需求可能相互矛盾，因为在无噪声领域，整个训练集往往比减少集具有更高的分类性能。同样，如果每个属性都提供相关信息，移除属性也无益益。

因此，涉及的权衡应该反映在适应度函数参数中，赋予用户指定具体偏好的机会。适应度函数应该能够侧重于最大化分类准确性，或者侧重于最小化保留的训练示例和属性的数量。这一需求通过公式表达式，其中 `ER` 是被给定样本分类错误的训练示例数量，`NE` 是保留的示例数量，`NA` 是保留的属性数量：

```
f = 1 / (c1 * ER + c2 * NE + c3 * NA)  (16.2)
```

注意，如果样本的错误率低、保留的示例集小、且有很多属性被消除，则该样本的适应度很高。该函数由三个用户设置参数 `c1`、`c2` 和 `c3` 控制，这些参数权衡了用户的偏好。例如，如果 `c1` 较高，则重点放在分类准确性上。如果 `c2` 或 `c3` 较高，则分别放在最小化保留示例的数量和保留属性的数量上。

### 应用遗传算子

通过概率选择父母。特别是，使用以下公式计算样本 `S'` 被选中的概率：

```
Prob(S') = f(S') / sum(f(S))  (16.3)
```
