
在材料的 3D Ising 模型中，可以证明铁磁性材料会动态地稳定在最低能量状态，而这种状态是所有磁矩对齐的状态。Hopfield 在双向连接神经元的网络中寻找类似的动力学机制。但根据我刚才描述的能量函数，具有不对称重的网络不会稳定在最低能量配置；该网络被认为是不稳定的。

随后，Hopfield 有了一个洞察。如果权重是对称的呢？比如`w12`等于`w21`，`w13`等于`w31`，以此此类推。

“一旦我采用对称连接，噢，我就知道它会起作用了，”Hopfield 告诉我，“稳定点得到了保证。”

这一切与联想记忆有什么关系？回想一下故事就是这样开始的——Hopfield 正在寻找一个可以用神经网络解决的神经生物学问题。好了，在讨论它的实际工作原理之前，让我们提前剧透一下吧。想象一种设置网络权重的方法，使得神经元给定的输出模式代表一个稳定状态，即能量最小值。（这些输出等同于自旋玻璃的自旋态。）如果网络处于这种状态，它就不会再发生任何变化。这种输出模式可以被认为是你想存储在网络中的记忆。现在，你被给出一个该记忆的损坏版本模式。几个比特位是 +1 而不是 −1，反之亦然（每个比特位都是一个神经元的输出）。让我们保持神经元的权重不变，但强制它们的输出表示这个损坏的模式。Hopfield 发现，当你这样做时，网络不再稳定，其动力学机制接了主导：每个神经元不断翻转（或不翻转），直到网络达到稳定状态。如果你强制网络进入的损坏状态与存储的记忆差异不大，网络将达到代表该记忆的稳定状态。一旦网络达到这个稳定状态，神经元的输出将不再发生翻转。你可以直接读取输出值：你已经回想了记忆。

“当我理解到我需要对称连接——而且磁性的 Ising 模型提供了很多启发——我把它们结合在一起，然后一切就变得清晰了，”Hopfield 说，“这只是坐下来苦苦钻研出来的。”

## 带我回家

理解 Hopfield 网络有许多组成部分，它们涉及到掌握不同的概念。第一，存储记忆意味着什么？（我们在上一节中窥见了答案。）第二，网络稳定意味着什么？第三，如何选择网络权重以存储记忆？第四，存储记忆和稳定状态之间有什么关系？第五，能量与这一切有什么关系？

让我们从一个简单的 3 神经元网络开始。网络的权重可以用矩阵形式表示：

通常情况下，`wij`代表从神经元`j`到神经元`i`的连接权重。这个矩阵有一些明显的特征。首先，因为神经元不会与自己通信，所以矩阵的对角线元素为零。此外，根据 Hopfield 的要求，矩阵关于对角线对称：`wij = wji`

该网络有 3 个神经元，因此有 3 个输出，我们可以存储任何 3 位模式。假设我们要存储模式“−1, 1, −1”。这意味着当神经元 1 输出“−1”、神经元 2 输出“1”、神经元 3 输出“−1”时，网络应该处于稳定状态。我们必须恰当地选择权重。选择或寻找合适的权重（无论程序如何）都类似于教网络；这个过程被称为学习。为此，Hopfield 了一个几十年前的观点，我们在第 1 章中遇到过：“一起放花的神经元会连接在一起。”在这里，“连接在一起”意味着改变两个神经元之间的权重，使得神经元的活动得到加强。为了实现这一点而选择权重被称为赫布学习。

所以，如果神经元 1 的输出为`y1`，神经元 2 的输出为`y2`，那么赫布学习认为这两个神经元之间的权重由给出：

> `w12 = w21 = y1.y2`

我们已经解决了本节开头提出的前三个问题。现在是时候处理`Hopfield`网络中的能量概念了。我们希望稳定的、存储的模式代表能量最小值。这意味着对模式的任何扰动（例如，如果神经元 1 的输出被强制从`−1`翻转为`1`）都应该增加网络的能量，从而形象地导致它滑回其最小能量状态。如果这种回到能量最小值的下降如预期那样发生，它就等同于提取一个存储的记忆。

关于为什么这种方法有效的更详细说明，请参阅第 272 页上的数学结语。以下是直观的解释。回想`Hopfield`将网络能量定义为：

![](img/p262_01.png)

事实证明，当使用`Hebbian`学习规则设置网络权重时，以下表述是成立的：

*   在代表存储记忆的稳定状态下，网络的能量（如上述方程所示）处于局部最小值。网络可以有多个局部最小值（每个最小值都可能代表一个不同的存储记忆）。在稳定状态下，神经元不再进一步翻转其输出，网络保持在该能量最小值处。

*   然而，如果你扰动了网络，例如让它存储一个略微损坏的存储记忆模式，这将导致网络能量增加。这种被扰动的状态是不稳定的，神经元将开始翻转。可以证明，当神经元翻转时，网络的总能量会降低。这种动态过程会持续到网络达到稳定状态或局部能量最小值——在那个点，动态过程停止。

*   一旦网络达到能量最小值，神经元就会停止翻转。在这个阶段，神经元的输出可能代表某些存储的记忆。所存储的记忆是否是你想要检索的某一个，取决于初始扰动——如果扰动太大，网络动态可能会将它带向与你想要检索的存储记忆不对应的另一个能量最小值。

这里是`Hopfield`网络可以实现的演示。假设你想存储一张 28×28 的黑白手写数字图像。描绘一个数字需要 784 个像素。每个像素可以是`0`或`1`。对于我们的目的，由于我们正在使用双极性神经元，我们可以认为“0”等同于“−1`”。基本上，任何图像都是一个包含 784 个元素的向量，每个元素为`−1`或`+1`。为了存储这样的向量，我们需要 784 个神经元。使用`Hebbian`规则，我们可以为任何想要存储的图像计算这 784 个神经元网络的权重。

假设`y1`代表图像 1（数字 5），`y2`代表图像 2（数字 8）。这些数字是`MNIST`手写数字数据库图像的修改版本。

要存储第一个数字，权重矩阵计算如下：

> `W1 = y1^Ty1 - I`

![](img/p264_01.png)

其中，`W1`是一个 784×784 的矩阵，`I`是一个 784×784 的单位矩阵。这一单一操作更新了网络权重，使得图像 1 成为一个存储的记忆。如果你在这一阶段读取神经元的输出，你可以重建该图像，因为每个神经元都输出相应的像素值。

但如果我们想在同一个网络中存储另一幅图像呢？要存储第二个数字，权重矩阵计算如下：

> `W2 = y2^Ty2 - I`

其中，`W2`是一个 784×784 的矩阵，`I`是一个 784×784 的单位矩阵。这一单一操作更新了网络权重，使得图像 2 成为一个存储的记忆。如果你在这一阶段读取神经元的输出，你可以重建该图像，因为每个神经元都输出相应的像素值。

然而，我们在网络中存储了两个图像，分别代表数字 5 和 8。有时，随机扰动后的图像会下降到一个能量最小值，该值代表数字 5 或其位翻转后的同类项（参见面板）。

另一种可能是，如果你获取数字 8 的图像并进行扰动，然后让网络表示该扰动后的图像，它可能会下降到一个能量最小值，导致检索出数字 5 的图像。这是因为扰动让网络落在了能量景观的某个区域，该区域相对于代表 8 的最小值，离代表 5 的最小值更近。

在采访约翰·霍普尔德（John Hopfield）时，我发现直接称呼他的同名网络为名字很尴尬。“在和你说话时称它们为‘霍普尔德网络’感觉很奇怪，但你一定一直经历着这一切，”我说。

“我已经放弃那了，”霍普尔德笑着说道。

这在现在可能已经过时，但在 1981 年霍普尔德完成他的工作时，没有人特别感兴趣去发表它。没有哪个神经生物学家会看霍普尔德写的内容，并声称它与神经生物学有任何关系。“当时没有希望把它发表在经过评审的期刊上，”霍普尔德告诉我。事实是，霍普尔德曾是美国科学院的成员，这是因为他早期在物理学方面的成就。“如果你是学院成员，基本上可以根据自己的话，每年发表几篇论文，”他说，“除非这些论文是不道德的，否则没人会批评它们。”

但在 1981-1982 年，《美国国家科学院院报》（*PNAS*）在数学或计算机科学方面几乎没有发表过东西。而这些学科正是霍普尔德论文的核心。此外，他还有最后一个问题：*PNAS* 有五页的限制。霍普尔德必须将他的工作浓缩到五页，同时希望吸引具有数学思维的计算机科学家和神经生物学家的注意。论文发表了。在论文《现在怎么办？》中回忆这一过程时，霍普尔德引用了海明威的话：

> 关于非虚构作品的写作，欧内斯特·海明威评论道：“如果一个散文作家对他正在写作的主题足够了解，他就可以省略他所知的内容，而如果作家写得足够真实，读者对这些内容的感受将就像作家直接陈述了它们一样强烈。”*PNAS* 的长度限制迫使我在叙述的内容和省略的内容上具有了高度的选择性。如果海明威是一个物理学家，他会认出这种风格。事后看之，省略那些显而易见的内容可能增加了论文的影响力。未阐述的内容成为了他人增加该主题内容的邀请，从而鼓励了一个贡献者社区研究此类网络模型。成功的科学总是一项社区事业。

霍普尔德 1982 年的 *PNAS* 论文已成为该领域的经典。它促进了人们的理解，即神经生物系统（当然包括我们的大脑）是动力学的并且可以这样进行数学建模。这是一个巨大的进步。然后是学习的问题。（毕竟，这是一本关于机器学习的书。）霍普尔德网络是所谓的“单次学习学习者”（one-shot learners）。给定一个数据实例，网络就能记住它。但我们大脑所做的绝大部分学习是增量的：给定足够的数据，我们缓慢地学习其中的模式。

增量训练是神经网络研究人员的一个关键目标。我们在第 1 章中看到了如何增量地训练单层感知器或神经网络。但此类网络有巨大的局限性。目标是转向多层神经网络，但没有人知道如何高效地训练它们。到 1986 年，随着第一篇关于反传播算法详细阐述的发表，这一切发生了不可逆转的变化。在之后的几年里，另一篇由名叫乔治·西贝科（George Cybenko）的数学家写的论文表明，多层网络可以近似任何函数。

## 数学脚注

### 收敛证明 / 霍普尔德网络

**定理**：对于`j`不等于`i`，`wij` = `yi` `yj`。如果神经元的场与其当前状态符号相反，则神经元翻转；否则不翻转。

霍普尔德用这些术语定义了网络的能量：

```
E = -1/2 \sum_{i,j} wij yi yj
```

让我们取一个 3 个神经元的网络。因此，权重为`w11`、`w12`、`w13`、`w21`、`w22`、`w23`、`w31`、`w32`和`w33`。我们知道`w11`、`w22`和`w33`为零。这里是所有项的能量：

```
E = -1/2 (w12 y1y2 + w13 y1y3 + w21 y2y1 + w23 y2y3 + w31 y3y1 + w32 y3y2)
```

这可以重新组织，重点关注神经元 1：

```
E = -1/2 (2w12 y1y2 + 2w13 y1y3 + w23 y2y3 + w32 y3y2)
```

等等，标准形式是：

```
E = -y1(w12 y2 + w13 y3) - 1/2 (w23 y2y3 + w32 y3y2)
```

实际上，让我们使用对称性`w12=w21`、`w13=w31`：

```
E = -y1(w12 y2 + w13 y3) - 1/2 (w23 y2y3 + w32 y3y2)
```

神经元 1 翻转后的能量差异为：

```
∇E = E[new] - E[old]
```

如果你在疑惑能量函数之前的 ½，这里就派上用场了。½ 抵消了求和符号前的 2。（这些就是数学家的技巧。）

所以，这就是当第`i`个神经元（在我们的例子中是 1 号神经元）状态从`+1`翻变为`-1`或反之时的能量变化。为了通用起见，我们将不再具体指定第 1 号神经元，而将第`i`个神经元称为翻转的神经元。记住 ![公式读取：从 i, j 不等于 1 的 wij yj 的求和](img/p275_02.png) 是第`i`个神经元的场。它的符号始终与`yi[old]`相反：这正是神经元发生翻转的原因。

所以，如果`yi[old]`是`+1`，那么`yi[new]`就是`-1`，因为 ![公式读取：从 i, j 不等于 1 的 wij yj 的求和](img/p275_03.png) 带有负号。

![](img/p276_01.png)

如果`yi[old]`是`-1`，那么`yi[new]`就是`+1`，因为 ![公式读取：从 i, j 不等于 1 的 wij yj 的求和](img/p275_02.png) 带有正号。

![](img/p276_02.png)

无论第`i`个神经元是从`+1`翻转到`-1`还是从`-1`翻转到`+1`，能量的变化都是负数，这意味着系统的总能量在降低。“由于可能的状态是有限的，网络*最终*达到一个能量无法进一步降低的状态，”
