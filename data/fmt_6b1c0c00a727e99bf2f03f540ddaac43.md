### 关键术语表

### A

**访问控制门室（access control vestibule）** 一个通常带有两组互锁门的小空间（其中一扇门必须在关闭后另一扇门才能打开）。以前被称为 `mantrap`（防人门）。

**账户劫持（account takeover）** 攻击者获取用户账户凭据的情况。

**主动侦察（active reconnaissance）** 一种信息收集方法，其使用的工具实际上向目标网络或系统发送探测，以触发响应，然后利用响应确定其态势。

**管理控制（administrative controls）** 为降低风险和提高安全性而设计并实施的策略、规则或培训。

**APK Studio** 一种用于 Android 逆向工程的跨平台开源工具。你可以从 [`vaibhavpandey.com/apkstudio/`](https://vaibhavpandey.com/apkstudio/) 下载 APK Studio。

**算术运算符（arithmetic operator）** 一种在两个操作数上执行计算的数学运算（如加、减、乘、除或取模）。

**ARP 缓存投毒（ARP cache poisoning）** 一种导致中间人攻击场景的攻击。它可以通过投毒连接到子网的系统的 ARP 缓存并拦截指向子网内其他主机的流量，来针对连接到第 2 网络的主机、交换机和路由器。也称为 `ARP 欺骗`。

**数组（array）** 一种可以同时存储多个值的特殊变量。

**经过验证的扫描（authenticated scan）** 一种漏洞扫描，其中用户向扫描程序提供一组具有系统根级别权限的凭据。大多数情况下，最好对目标运行此类扫描，以获取攻击面的完整图景。

**权威性（authority）** 一种社会工程技术，攻击者利用自信以及法律、组织或社会权威来说服目标泄露信息。

### B

**副本克隆攻击（badge cloning attack）** 攻击者克隆用于进入建筑的门禁或卡的攻击。这可以使用专门的软件和硬件完成。也可以在社会工程技术的帮助下，通过伪装成员工/授权用户使用简单的门禁副本进入建筑。

**Bash Shell（Bash shell）** 一种由 Brian Fox 编写的 Linux/Unix 壳和命令语言，用作 Bourne shell 的替代品。

**绑定 Shell（bind shell）** 一种攻击，攻击者在受感染的系统上打开一个端口或监听器并等待连接。这样做是为了从任何系统连接到受害者执行命令并进一步操纵受害者。

**BLE 攻击（BLE attack）** 针对低功耗蓝牙（BLE）实现的攻击。

**盲注（或推断）SQL 注入（blind (or inferential) SQL injection）** 一种攻击，攻击者不让应用程序显示或传输任何数据，而是通过发送特定语句并识别应用程序和数据库的行为来重构信息。

**BloodHound** 一个单页 JavaScript Web 应用程序，利用图论揭示 Windows Active Directory 环境中隐藏的关系。

**蓝牙劫持（Bluejacking）** 一种通过使用范围内有漏洞设备的蓝牙进行的攻击，主要作为蓝牙连接的垃圾信息形式进行。攻击者通过蓝牙向受害者发送未经请求的消息，包括一个通常在姓名字段中包含消息的联系人卡（vCard）。

**蓝牙窃取（Bluesnarfing）** 一种旨在未经授权访问启用蓝牙的设备信息的攻击。攻击者可能启动蓝牙窃取攻击，以访问受害者的日历、联系人列表、电子邮件和短信、照片或视频。

**布尔逻辑运算符（Boolean operator）** 一种评估为真或假的编程语言结构。

**布尔 SQL（Boolean SQL）** 一种通常用于盲 SQL 注入攻击的技术，通过对应用程序使用布尔查询来尝试理解错误代码。

**浏览器利用框架（Browser Exploitation Framework, BeEF）** 一个可以利用 XSS 漏洞操纵用户的工具。

**Burp Suite** 一组用于发现 Web 应用程序漏洞的工具（包含代理功能）。你可以从 [`portswigger.net/burp/communitydownload`](https://portswigger.net/burp/communitydownload) 下载 Burp Suite。

**业务逻辑漏洞（business logic flaw）** 一种入侵方式，攻击者利用应用程序的合法交易和流程，产生负面的行为或结果。

**命令注入（command injection）** 一种攻击者试图通过漏洞应用程序在系统上执行其本不被允许执行的命令的攻击。当应用程序不验证用户提供的数据（例如在 Web 表单中输入的数据、cookie、HTTP 头部和其他元素）时，就会发生命令注入攻击。漏洞系统会将这些数据传递到系统外壳（shell）。此类攻击涉及尝试发送操作系统命令，以便应用程序能够以漏洞应用程序的权限执行这些命令。

**逗号分隔值（comma-separated values, CSV）** 一种纯文本文件，包含由逗号（`,`）以及有时由制表符或其他字符（如分号 `;`）分隔的数据。

**合规性扫描（compliance scan）** 通常由该环境所服务的市场或治理驱动的扫描。例如，医疗保健实体的信息安全环境，必须遵守 HIPAA 规定的要求。

**条件（conditional）** 一种编程语言中的命令，用于处理决策。

**隐蔽通道（covert channel）** 一种对抗技术，攻击者根据安全策略，在不被允许通信的进程或系统之间传输信息对象。

**CrackMapExec** 一种后渗透工具，可用于对 Active Directory（AD）网络进行自动化评估。你可以从 [`github.com/byt3bl33d3r/CrackMapExec`](https://github.com/byt3bl33d3r/CrackMapExec) 获取关于 CrackMapExec 的更多信息。

**凭据收集（credential harvesting）** 从系统中窃取凭据的行为。

**跨站请求伪造（cross-site request forgery, CSRF/XSRF）** 一种攻击，涉及从应用程序信任的用户发送未经授权的命令。CSRF 与 XSS 的不同在于，它利用了应用程序对用户浏览器的信任。CSRF 漏洞也被“一击攻击”或“会话劫持”。CSRF 攻击通常影响依赖于用户身份的应用程序（或网站）。

**跨站脚本（cross-site scripting, XSS）** 一种常见的 Web 应用程序漏洞，可能导致恶意代码的安装或执行、账户入侵、会话 cookie 劫持、本地文件泄露或修改或网站重定向。XSS 有三种主要类型：反射型 XSS、存储型（持久性）XSS 和 DOM 型 XSS。

**高管层（C-suite）** 公司内部的高层或执行级管理人员。常见的高管人员包括首席执行官 (CEO)、首席财务官 (CFO)、首席运营官 (COO)、首席信息官 (CIO) 和首席安全官 (CSO)。

**拒绝服务攻击（denial-of-service, DoS attack）** 一种旨在破坏系统或网络并导致中断的攻击。

**依赖漏洞（dependency vulnerability）** 第三方依赖项中的漏洞。

**字典（dictionary）** 使用键值对进行排序的数据值集合。

**DirBuster** 一种 Web 应用程序目录枚举工具。

**目录遍历（directory traversal）** 一种允许攻击者访问存储 Web 根目录之外的文件和目录的漏洞。也称为 `path traversal`。

**直接源攻击（direct-to-origin attack）** 攻击者试图揭示系统的源网络或 IP 地址并直接对其进行攻击，从而绕过 CDN 实现提供的防 DDoS 缓解。

**发现扫描（discovery scan）** 一种漏洞扫描，主要用于识别目标的攻击面。端口扫描是发现扫描的主要部分。

**DNS 缓存毒（DNS cache poisoning）** 通过注入损坏的 DNS 数据来操纵 DNS 解析器缓存。这样做是为了强制 DNS 服务器向受害者发送错误的 IP 地址，将受害者重定向到攻击者的系统。

**DNS 查询（DNS lookup）** 一种用于确定 IP 地址或地址的方法。

**域名枚举（domain enumeration）** 确定目标域名及其子域的过程。它帮助渗透测试人员确定运行着哪些系统以及哪些被遗忘的子域。

**Nslookup** 用于解析 DNS 域名的工具。

### O

**OllyDbg** 一个 Windows 应用程序调试器。

**路径攻击 (on-path attack)** 攻击者将自己置于两个通信设备或个人之间的中间，以便窃听（窃取敏感数据）或操纵正在传输的数据（例如执行数据损坏或数据修改）。中间人攻击可以发生在第 2 层或第 3 层。以前被称为 `man-in-the-middle (MITM) attack`。

**开源情报 (OSINT) 收集 (open-source intelligence gathering)** 收集公开情报源的方法以便收集和分析有关目标的信息。通过 OSINT，收集信息不需要任何类型的隐蔽手段。

**开源安全测试方法论手册 (Open Source Security Testing Methodology Manual, OSSTMM)** 一份概述了重复且一致的安全测试的文档。

**Open Vulnerability Assessment Scanner (Open VAS)** 一个开源安全漏洞扫描器。

**运营控制 (operational controls)** 关注日常运营和策略的控制措施。它们由人员而非机器实施，并确保在中间级操作期间遵循管理策略。

**OWASP Zed Attack Proxy (ZAP)** 一个由 OWASP 创建的开源 Web 应用程序安全工具，用于识别 HTTP 参数污染 (HPP)漏洞。

### P

**被动侦察 (passive reconnaissance)** 一种信息收集方法，工具不直接与目标设备或网络交互。被动侦察有多种方法。某些涉及使用第三方数据库收集信息，另一些则使用工具的方式使其不会被目标发现。

**Patator** 一个多线程工具，可用于密码猜测攻击，可以从 [`github.com/lanjelot/patator`](https://github.com/lanjelot/patator) 下载。

**补丁碎片化 (patching fragmentation)** 基于 Android 的实现中面临的挑战，与不同移动设备支持或不支持的众多 Android 版本有关。攻击者可以利用这些兼容性问题。

**PCI DSS** 一项旨在安全卡支付处理的规定。

**基于角色的访问控制 (role-based access control)** 一种基于特定角色或功能的访问控制模型。管理员向角色授予访问权限和许可。用户与单个角色关联。

### S

**沙箱分析 (sandbox analysis)** 在沙箱或安全环境中对恶意软件进行分析。

**稀缺性 (scarcity)** 一种社会工程技术，攻击者通过在决策语境中营造一种高度紧迫感，来说服目标泄露信息。

**SearchSploit** 一种用于下载 Exploit-DB ([exploit-db.com](http://exploit-db.com)) 副本并搜索已下载漏洞利用工具的工具。

**安全软件开发生命周期 (secure software development life cycle, SSDLC)** 在软件开发生命周期 (SDLC) 过程中纳入安全最佳实践、策略和技术，以发现并修复漏洞的过程。OWASP 为实施 SSDLC 提供了最佳实践和指导，详见 [`owasp.org/www-project-integration-standards/writeups/owasp_in_sdlc`](https://owasp.org/www-project-integration-standards/writeups/owasp_in_sdlc)。

**敏感数据 (sensitive data)** 一旦被泄露，将对组织产生严重影响的数据。

**服务枚举 (service enumeration)** 识别远程系统上运行服务的进程。这是 `Nmap` 端口扫描的主要关注。

**服务等级协议 (service-level agreement, SLA)** 一份记录完备的预期或约束，描述了网络的一个或多个最小和/或最大性能指标（如质量、时间线/时间范围和成本）。

**会话固定 (session fixation)** 一种攻击类型，攻击者通过拦截并操纵网络流量，在受害者的 Web 浏览器中注入（或固定）会话 ID。

**Shell** 一种作为用户与操作系统（内核及其服务）之间接口的实用程序（软件）。例如，在 Linux 中有几种 shell 环境，如 `Bash`、`ksh` 和 `tcsh`。在 Windows 中，shell 是命令提示符（命令行界面）。

**Shodan** 一个连接到设备的搜索引擎，它持续扫描互联网并通过网站 [`www.shodan.io`](https://www.shodan.io) 以及 API 向用户公开其结果。攻击者可以使用此工具识别互联网上易受攻击且暴露的系统（例如配置不当的 IoT 设备和基础设施设备）。渗透测试人员可以使用它在不主动扫描受害者的情况下，收集暴露在互联网上的潜在漏洞系统的信息。

**短信钓鱼 (Short Message Service (SMS) phishing)** 一种利用短信向移动设备发送恶意软件或恶意链接的钓鱼攻击利用。

**肩窥 (shoulder surfing)** 攻击者通过窥视受害者的肩膀来获取如个人身份信息 (PII)、密码和其他机密数据的过程。

**侧信道攻击 (side-channel attack)** 一种攻击通常基于从底层计算机系统（或云环境）的实现中获得的信息，而不是实现的技术或算法的特定漏洞。攻击者旨在通过测量或利用系统或硬件的间接影响，从应用程序或系统中收集信息或对其产生影响。大多数侧信道攻击通过测量偶然的硬件发射来泄露凭据、加密密钥或任何其他敏感信息。

**社会工程工具包 (Social-Engineer Toolkit, SET)** 一个可以用于启动大量社会工程攻击的工具，还可以与 `Metasploit` 等第三方工具和框架集成。

**社会证明 (social proof)** 一种社会工程技术，目标在特定情况下或环境中无法确定恰当的行为模式。攻击者确立什么是“正常”行为，以说服目标泄露信息。

**软件开发工具包 (software development kit, SDK)** 开发者用于创建应用程序的一系列软件工具和程序。

**垃圾邮件 (spamming)** 发送未经许可邮件的行为。

**鱼叉式钓鱼 (spear phishing)** 针对特定个人或公司、精心构建的钓鱼尝试。攻击者研究受害者组织，使邮件看起来来自信任用户。

**SQL 注入 (SQL injection, SQLi)** 一种攻击类型，攻击者通过 Web 应用程序插入部分完整的 SQL 查询。通过数据平面输入执行预定义的 SQL 命令。

**SQLmap** 一种用于自动化 SQL 注入攻击的工具。

**堆叠查询 (stacked queries)** 一种可以使用任何 SQL 语句或过程攻击技术。使用这种技术指定恶意输入语句。

**工作说明书 (statement of work, SOW)** 规定渗透测试期间执行的活动的文档。

**隐蔽扫描 (stealth scan)** 在不引起目标防御位置的情况下进行的扫描。它涉及以目标难以察觉的方式实施漏洞扫描器。

**隐写术 (steganography)** 在图像或视频文件中隐藏信息或其他内容的行为。

**字符串运算符 (string operator)** 以各种方式操作变量值的 Python 结构。

**监控与数据采集系统 (supervisory control and data acquisition, SCADA)** 一套用于控制和交互传感器、泵、电机、阀等工业设备的硬件组件和软件。

**Sysinternals** 允许管理员从远程终端控制 Windows 计算机的工具套件。可以使用 `Sysinternals` 在主机上上传、执行和交互可执行文件。整个套件通过命令行界面工作，并可以编写运行有关进程的信息并停止服务的命令。

### U

**通用串行总线 (USB) 掉落攻击** 这是一种攻击者在公共场所丢弃载有恶意软件的 `USB` 闪盘的攻击，希望目标会将其捡起，并出于好奇将其插入系统以查看其中的内容。一旦其中一个驱动器被插入，恶意软件就可以自动运行并感染系统。

**未知环境测试 (unknown-environment testing)** 测试者仅被提供非常有限的信息（例如，仅提供针对特定目标范围内的域名和 `IP` 地址）。这种限制的目的是让测试者从外部攻击者可能拥有的视角开始测试。以前被称为黑-box 测试（黑盒渗透测试）。

**用户枚举 (user enumeration)** 收集有效用户列表的过程，这是破解一组凭据的第一步。获取用户名后，就可以尝试对该账户密码进行暴力破解。在进入内部网络后，会再次执行用户枚举。

### V

**垂直权限提升 (vertical privilege escalation)** 低权限用户访问专为高权限用户保留的功能（例如 `root` 或 `administrator` 访问）的情况。

**虚拟局域网 (VLAN) 跳跃 (virtual local area network hopping)** 获取通常无法访问的其他 `VLANs` 流量的方法。

**虚拟机 (VM) 逃逸 (virtual machine escape)** 攻击者访问其他 `VM` 或虚拟机程序（逃逸）以破坏这些系统的攻击。

**电话诈骗 (vishing)** 通过电话对话进行的社交工程学攻击。攻击者说服用户泄露私人财务信息，或其他个人或公司信息。全称为 `voice phishing`（语音钓鱼）。

**漏洞 (vulnerability)** 信息系统或系统安全程序、内部控制或实现中的缺陷，这些可能被威胁源利用或触发。

**漏洞扫描 (vulnerability scanning)** 用于识别主机或主机属性以及相关漏洞的技术。

### W

**w3af** 一种 Web 应用扫描器。

**水蛭攻击 (watering hole attack)** 当攻击者对目标受害者访问的网站进行画像时发生的针对攻击。

**网页枚举/Web 应用枚举 (web page enumeration/web application enumeration)** 涉及查看 Web 应用并映射攻击面的过程。

**大鱼钓鱼攻击 (whaling)** 一种与钓鱼和鱼叉式钓鱼相似的攻击，但其目标是公司的高知名业务高管和关键人物。大鱼钓鱼邮件设计得像关键业务邮件，或者看起来来自具有合法权限的人。大鱼钓鱼网页专门设计用于吸引高知名受害者。

**Whois** 用于获取域名注册信息和 `IP` 地址块所有权信息的工具。

**WinDbg** 一种基于 Windows 的调试器。

**Windows 管理实例程序 (WMI)** 用于管理 Windows 操作系统上的数据和操作的基础设施。可以编写 `WMI` 脚本或应用程序来自动化远程计算机上的管理任务。威胁者使用 `WMI` 在受感染的系统中执行不同的活动。

**Windows 远程管理 (WinRM)** 连接到 Windows 系统的合法方法，对渗透后活动也有用。
