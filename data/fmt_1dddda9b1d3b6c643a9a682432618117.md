## 创建可重用的镜像

我们已经涵盖了 docker desktop 和 hub 的安装以及账户创建部分。现在，我们将创建一个简单的镜像，并介绍构建镜像所需的几个基本命令和结构的细节。由于我们的目标是创建一个可重用的镜像并将其推送到 docker hub，我们将进行一个简单的练习，完成以下步骤：

- 创建一个 Python 脚本来统计 CSV 文件每列的空/缺失值。
- 生成一个包含列名和缺失值计数的报告。
- 将该模块容器化。
- 将输出保存在运行它的机器上。

我们将从 Python 脚本开始。该 Python 脚本接受 csv 文件作为输入，并提供一个命名的 csv 文件作为输出。该脚本将在本文末尾的 git 链接中共享。我们将 Python 文件命名为...。现在，我们将介绍用于创建镜像的 `Dockerfile` 内容。Docker 文件中的第一个命令如下：

```dockerfile
FROM python:3.7.3
```

此命令用于引用基础镜像。Docker 和许多其他供应商都提供其应用程序/软件的基础镜像，可以根据需要进行扩展。我们正在使用前面的命令执行相同的操作。我们将调用可用的 Python 3.7.3 镜像，并根据我们的需要进一步使用它。

下一个命令是使用以下命令设置工作目录：

```dockerfile
WORKDIR /usr/src/app
```

此命令将工作目录设置为指定的路径，在这种情况下，如果目录不存在，它将被创建。所有的命令将在工作目录内执行。这使得挂载外部数据变得容易，也可以在同一个 docker 中多次更改工作目录，但在本例中不需要。

下一个命令是将容器镜像所需的所有文件复制到容器中。为了这样做，我们使用 `copy` 命令。在这种情况下，我们使用以下命令：

```dockerfile
COPY ..
```

这表示将系统当前目录的内容复制到 docker 当前目录（即之前设置的工作目录）。

下一个命令是在容器内安装所有 Python 软件包，所有需要的包及其版本都在文件中提到。`RUN` 命令在构建镜像时在 docker 文件中执行其随后的命令。为了参考，命令如下：

```dockerfile
RUN pip3 install -r requirement.txt
```

最后部分是入口点（entry point）命令，这意味着只要你启动容器，就会运行该命令。在运行容器时可以覆盖它，可以在共享代码的 `README.md` 链接中检查。要执行的命令如下：

```dockerfile
ENTRYPOINT ["python","Null_Value_Modul.py"]
```

Python 脚本将执行在本节开头定义的任务，即统计每列的空值并生成 CSV 格式的报告，给定一个输入 CSV 文件。执行 `docker` 命令以及传递给它们的参数将在共享代码的 `README.md` 文件中讨论。代码链接位于参考文献中的 Docker Image Creation。

## 将镜像作为容器运行

通过这些，我们涵盖了如何创建镜像并作为容器运行。然而，当我们运行多个镜像时，特别是当我们为了扩展性训练或部署 ML 模型时，存在基础设施需求。这就是 Kubernetes (K8s) 出场的地方。我们将在接下来的部分中讨论它们，并尝试对使用它们建立理解。

## Kubernetes

Kubernetes，也称为 K8s，是一种以自动化和可扩展的方式部署和管理容器化应用的开源系统。它由 Google 的工程师创建并开源。目前，大多数组织都选择了 K8s 路线，原因如下：

- K8s 集群具有天然的可扩展性。它拥有一许多工具，允许应用程序及其所托管的基础设施根据需求、效率以及其他许多指标进行水平扩展或收缩。在训练或部署我们的 ML 模型时，我们将根据需求探索其中的一些工具。
- 无论你在何处运行集群，K8s 都非常灵活。无论是在你的私有云、公有云还是你自己的机器上，它的设计都能处理复杂的需求。
- 开源 K8s 是开源的，可以根据需要进行扩展。这为应用程序开发和部署提供了一个强大的系统，且不会被供应商锁定。

Kubernetes 的安装可能具有挑战性；但得益于 `GCP` 或 `AWS` 等公有云提供商，他们简化了 `K8s` 的安装。另一个需要记住的点是，尽管 `K8s` 有许多优势，但并不是每个组织都需要为其机器学习或数据科学实践启用这些功能。只有当机器学习实践达到成熟并有需求时，我们才应该进行。我们假设目前大多数企业都是如此；但一个值得思考的问题是，我们每周或每月将训练和部署多少模型。这个问题的重要性在于，你可以轻松地量化基础设施和运维需求。这不需要非常准确，但会给出 `K8s` 清晰的价值主张。

一旦部署了 `K8s`，我们就得到了集群。集群由称为 `nodes` 的工作机器组成。我们将在下一节中介绍构成 `K8s` 集群的所有组件。

## Google Cloud Platform (GCP)

Google 云平台，或顾名其 `GCP`，是由 Google 提供的云平台，也是与微软 `Azure` 和 `AWS` 一样最广泛使用的公有云平台之一。`GCP` 提供了多种服务，使得组织可以在一个地方处理所有的 IT 需求。`GCP` 或任何公有云提供商都能让终端用户专注于核心问题，而无需担心 IT 基础设施或平台。在高级别，`GCP` 提供以下服务：

- 存储
- 数据库

- 大数据
