# 手动测试网站的网络钓鱼风险

在本练习中，您将练习如何使用 Microsoft Edge 报告恶意网站。

1. 在 Windows 计算机上启动 Microsoft Edge 并导航至 `127.0.0.1`。
2. 在屏幕右侧，选择 `Settings and More (…) | Help and Feedback | Report Unsafe Site`。请注意，您可以报告您认为当前访问的站点是钓鱼网站或包含恶意代码。
3. 输入屏幕上显示的安全字符。
4. 通常您会选择 Submit，但我们将通过关闭浏览器标签页来关闭该页面。

## 养成良好习惯

本章主要讲述保护系统安全，其中一部分源于确保员工在使用公司系统时养成良好习惯。为帮助减少安全事件，鼓励员工在使用公司系统时遵循以下最佳实践：

### 上网冲浪

鼓励用户仅访问他们熟悉的网站，并鼓励他们将公司系统上的互联网使用限制在仅用于业务目的。良好的上网习惯会降低系统感染恶意软件的可能性。

## 设备安全与数据安全

在本节中，您将了解保护笔记本电脑、移动设备以及组织数据等系统的常见安全实践。安全防护不止于办公室内部，您还需要考虑如何保护带出组织外部的资源。

## 硬件安全

在处理交换机、路由器和笔记本电脑等硬件设备时，您应确保这些设备免遭盗窃。路由器和交换机应放置在安全的场所（如服务器机房），并对机房的访问权限进行控制。这将有助于保护路由器和交换机免遭盗窃，同时防止未经授权的人员对这些设备进行物理篡改。

任何便携式硬件设备（如笔记本电脑、液晶显示器，甚至投影仪）都应使用防盗锁线缆固定在场所内。锁线缆连接到设备上的接口，然后固定在桌子上。这可以阻止伺机行窃。请记住，防盗锁线缆并非万无一失，因为小偷可以将其剪断。

高安全级别的环境可能要求员工将未在夜间使用的可移动/便携式驱动器、笔记本电脑和其他移动设备锁在保险柜或带锁的柜子里。

## 移动设备安全

由于移动设备存储着公司邮件和公司数据的本地副本，因此它们已成为当今企业的一大安全隐患。制定强有力的政策来规范智能手机和平板电脑等移动设备的使用，并确保这些政策得到执行，这一点至关重要。

### 连接方式与接收器

手机和平板电脑连接网络和互联网的方式多种多样。以下列表概述了移动设备常用的一些连接方式：

- **蜂窝网络** 移动设备连接网络或互联网最常用的方式是通过其蜂窝网络。蜂窝网络由移动设备的服务提供商提供。
- **Wi-Fi** 移动设备可以连接到公司 Wi-Fi 网络以获取互联网连接并访问网络资源。Wi-Fi 网络进而连接到企业网络。
- **卫星通信 (SATCOM)** SATCOM 是 `satellite communication`（卫星通信）的缩写，是发送或接收少量数据（如通过销售终端系统）时的常用连接方式。
- **蓝牙** 只要设备距离足够近，移动设备就可以使用蓝牙获得与计算机或设备的连接。蓝牙使用 2.4-GHz 频率。
- **近场通信 (NFC)** 近场通信允许两个电子设备在相距两英寸范围内交换数据。您可以使用 NFC 让设备共享联系人等信息，或用于支付交易。
- **ANT** ANT 是一种无线通信协议，允许您在设备之间传输数据。ANT 像蓝牙一样使用 2.4-GHz 频率。与蓝牙不同，ANT 消耗的电池寿命较少，这使其非常适合智能设备。
- **红外** 红外线，或称 IR，是一种无线通信，依赖于通过红外光共享数据的两个设备之间的视线直达。
- **USB** 您可以使用 USB 线缆将移动设备连接到系统的 USB 端口。这常用于将视频和图片等数据传输到计算机。
- **点对点** 移动设备支持不同的协议进行点对点通信（例如，一个移动设备与另一个移动设备通信）。
- **点对多点** 移动设备还支持点对多点，这涉及同时向许多其他设备发送数据。
- **全球定位系统 (GPS)** 移动设备包含 GPS 技术，允许您使用显示位置信息的服务。
- **射频识别 (RFID)** 利用射频识别 (RFID) 技术，您可以将标签附着在物体上，并使用 RFID 来追踪这些标签。

了解可用于允许智能手机或笔记本电脑等移动设备进行通信的不同技术非常重要。从安全角度来看，您可能希望在设备上禁用这些功能。

### 移动设备管理概念

移动设备给组织带来了巨大的安全挑战，因此全面掌握如何管理设备功能及设备本身至关重要。以下是您需要管理的移动设备的一些安全方面：

- **屏幕锁定** 务必确保智能手机和笔记本电脑等移动设备的屏幕配置为在短时间无操作后自动锁定。因此，任何想要使用移动设备并访问其上数据的人都必须输入设备密码。因此，如果您丢失设备且被他人拾获，他们需要知道密码才能访问设备上的数据。
- **强密码和 PIN 码** 确保所有移动设备都配置了复杂密码以使用设备，从而访问其中的数据。对于企业设备，您可以配置策略以强制要求设备使用复杂密码。例如，您可以在 Microsoft Exchange Server 的 ActiveSync 策略中为支持 ActiveSync 的移动设备进行此项配置（请参见 图 7-13）。

![Image](img/f0296-01.jpg)

图 7-13：策略确保设备使用强密码。

- **全设备加密** 大多数移动设备支持对设备上的数据进行加密。设备加密至关重要，可确保任何能够将设备或其内存连接到计算机的人都无法读取数据。
- **远程擦除/清理** 智能手机和平板电脑等移动设备支持在设备丢失或被盗时远程擦除设备。远程擦除设备将清除其上的所有数据。
- **语音加密** 对于支持语音通信加密的任何设备，您应启用此功能，以防止任何人窃听通信。对于 IP 语音 (VoIP) 设备，您可以加密 VoIP 数据包，以防止拥有嗅探器的人捕获和分析通信。例如，Wireshark 有一个命令用于分析捕获中的 VoIP 数据包，它会组装语音数据包并允许黑客播放对话。务必加密所有流量！
- **GPS 追踪** 大多数智能手机都具备 GPS 功能，允许您追踪移动设备的位置。确保启用 GPS 功能，以便在设备丢失或被盗时利用它们定位设备。
- **电子围栏** 电子围栏是一项功能，允许软件管理员定义创建边界（或虚拟围栏）的 GPS 坐标。当运行该软件的设备超出边界时，会触发警报。
- **地理定位** 地理定位是识别移动电话等物品地理位置的术语。例如，一旦确定了移动电话的地理定位（GPS 坐标），您就可以利用地图技术将其与街道地址关联起来。

# 移动设备安全功能

## 设备保护

### 锁定

您应制定关于移动设备的严格策略，以保护设备上的敏感数据。确保设备在短时间不活动后激活屏幕锁，同时确保配置设备上的任何锁定设置（如果可用）。某些设备允许您进行配置，使其在连续三次登录尝试失败后锁定。

### 应用程序管理

在设备上实施应用程序控制，限制应用程序的操作或访问权限。

## 内容管理

查看设备上的内容过滤功能，可阻止特定类型的内容。

### 存储分段

某些设备允许您对其存储进行分段，从而控制可访问的数据。例如，移动设备可能会将企业数据与个人数据分段，允许您在公司需要时仅擦除企业数据。Microsoft 365 具备工作配置文件功能，允许您在移动设备上将个人数据存储与工作数据存储分离。

### 资产追踪

实施资产追踪功能，以便通过 GPS 定位丢失或被盗的设备。

### 清单控制

建立所有设备的清单并追踪持有者。

### 移动设备管理

使用移动设备管理软件来管理移动设备上可用的功能，并远程擦除设备。

### 设备访问控制

实施设备访问控制功能，以控制谁可以访问设备及其不同功能。

### 可移动存储

如果您的设备支持可移动存储，您可以查找禁用它的设置，以防止数据从设备复制到可移动存储介质。

### 禁用未使用的功能

就像加固计算机一样，您应禁用移动设备上不必要的功能以帮助保护其安全。

### 推送通知服务

移动设备允许您配置使用哪些推送通知服务，以将状态更新和通知发送到设备。

## 生物识别

某些设备可能允许配置生物识别功能以供使用。例如，某些设备可能会进行视网膜扫描或指纹读取以进行身份验证。

### 上下文感知身份验证

上下文感知身份验证是一种新型安全功能，允许应用程序或云服务感知您的习惯——例如，您通常从哪个位置登录，或您通常使用哪台设备登录。借助上下文感知身份验证，如果系统根据上下文以高度置信度确定确实是您在使用您的凭据，则您将获得简单的登录体验。如果系统对登录者确实是您本人的置信度较低，则会采用更复杂的登录方式，强制实施双因素身份验证等解决方案。

# 容器化

有时称为沙箱技术，您可以在设备上运行创建安全容器的软件，以防止访问存储在其中的敏感数据。

### 存储分段

存储分段是一项功能，允许您将移动设备上的存储分隔为多个隔间，以便将组织数据存储在独立于用户个人数据的区域中。

### 完全设备加密

如前所述，您应启用完全设备加密，以加密设备上的所有数据，以防设备丢失或被盗。

## 强制与监控

组织通常对其设备应如何使用以及不应如何使用有严格要求。在管理组织的移动设备时，通过监控设备的使用情况并查找策略违规行为来强制执行组织的策略非常重要。以下是强制执行的一些考量因素：

### 第三方应用商店

您的组织可能希望禁用对第三方应用商店的访问，作为控制设备上安装应用程序的一种方法。

### Root 权限获取/越狱

Root 权限获取或越狱是指设备用户能够获得设备的特权访问权限，并以他们想要的任何方式配置设备。请务必监控设备是否被越狱！

### 旁加载

旁加载是指从供方提供的应用商店以外的来源安装应用程序。许多组织试图将应用程序的旁加载限制在由公司控制的中心位置。

### 自定义固件

监控组织设备所需的固件升级，以保持设备处于最新状态。同时也要监控员工是否将自定义固件解决方案应用到设备上。

### 运营商解锁

监控设备是否被解锁。设备通常与特定运营商绑定，但如果用户想将其用于不同的运营商，设备可以被解锁。运营商通常会收取费用来解锁设备。

### 固件空中下载 (OTA) 更新

固件更新可以通过运营商的无线网络发送到移动设备和平板电脑，这被称为空中下载 (OTA) 更新。OTA 更新最初仅用于更新设备上的固件，但也可用于更新操作系统。

### 摄像头使用

您的组织应制定策略，规定员工是否被允许在工作场所使用移动设备摄像头。如果不允许使用摄像头（通常出于安全原因），您应禁用摄像头。组织可以部署要求禁用设备摄像头的设备策略。

### 短信/彩信/富媒体通信

您的组织应决定员工是否应使用移动设备的短消息服务 (SMS)、多媒体消息服务 (MMS) 和富通信服务 (RCS)。许多组织制定了政策，规定用户何时不允许发短信（例如，开车或走路时）。

## 外部介质

设备通常可以连接外部介质，如 SD 卡或 MicroSD 卡。考虑禁用这些插槽以控制连接到设备的介质。

### USB On-the-Go (OTG)

USB OTG 是一种规范，使兼容的移动设备能够连接多种不同类型的设备。例如，如果您的移动设备或平板电脑支持 USB OTG，您可以连接键盘或鼠标等通信设备，并将其与您的移动设备配合使用。

### 录音麦克风

出于隐私原因，您可以禁用组织设备上的录音麦克风。

### GPS 标记

评估设备上的 GPS 标记功能，确保设备不会标记拍摄照片的 GPS 坐标（如果允许拍照）。如果员工拍照并上传到社交媒体，这可能被用来追踪员工的位置。

### Wi-Fi Direct/Ad Hoc

您可能需要监控无线网络功能的使用方式，并控制用户是以基础设施模式连接到无线网络，还是允许以 Ad Hoc 模式连接。在基础设施模式下，管理员控制谁可以连接到网络以及启用哪些安全功能。

### 网络共享

网络共享是指将手机连接到笔记本电脑的 USB 端口，并利用手机的互联网连接让笔记本电脑上网。您可能希望限制移动设备上的网络共享功能，以防止用户以这种方式使用手机的互联网连接，因为打开此连接可能会使笔记本电脑暴露于攻击之下。

## 热点

公司可能决定禁用移动设备上的热点功能。热点功能允许您将移动设备转变为无线热点，以便其他人连接并通过您的移动设备获取互联网接入。在移动设备上开启热点可能会使您面临攻击风险。

### 支付方式

监控并控制用户如何从移动设备进行支付。借助 NFC 等技术，用户可以轻松地从移动设备完成交易。

## 部署模型

当组织决定让员工使用移动设备执行与工作相关的任务时，组织可以选择多种不同方式将移动设备集成到工作场所。以下概述了部署模型：

### 自带设备 (BYOD)

“自带设备”模型鼓励用户使用个人移动设备连接到企业网络以进行工作。虽然好处是组织可以避免采购移动设备的成本，但您需要明确政策，以及组织是否会向设备下发设置。要了解有关 BYOD 安全顾虑的更多信息，请查看本章后面标题为“BYOD 安全顾虑”的部分。

### 企业所有、个人启用 (COPE)

从安全角度来看，企业所有、个人启用 (COPE) 模型可能比 BYOD 模型效果更好，因为当公司不拥有设备时，很难对其进行控制。采用 COPE 模式，公司为用户提供设备，因此由 IT 部门进行管理，但公司也允许并鼓励设备的个人使用。

### 自选设备 (CYOD)

自选设备模型涉及组织向用户提供一份经批准的设备清单，并允许每位用户选择他们想要使用的设备。

### 企业所有

采用企业所有设备模型，公司全权管理设备，员工在使用时必须遵守公司政策。

### 虚拟桌面基础设施 (VDI)

虚拟桌面基础设施是一种模型，用户使用瘦客户端连接到运行在数据中心中的桌面环境。借助 VDI，您可以将移动设备作为瘦客户端引入，以便用户可以从任何地方访问其桌面环境。其好处是资源不在移动设备上——它只是连接到公司内部的虚拟桌面。

## 移动设备管理解决方案

由于移动设备如今常用于开展业务，因此出现了许多技术以帮助更好地管理这些设备的安全性：

### MicroSD 硬件安全模块 (HSM)

MicroSD 硬件安全模块 (HSM) 是一种以 MicroSD 卡形式存在的特殊硬件安全模块。该安全模块提供加密、数字签名、身份验证和密钥生命周期管理等安全服务。

### MDM/统一端点管理 (UEM)

组织可以使用移动设备管理 (MDM) 软件集中管理所有移动设备，并在移动设备上强制执行策略。此功能可通过统一端点管理 (UEM) 软件进行扩展，后者允许公司管理所有终端设备，包括移动设备、笔记本电脑和台式机系统。

### 移动应用程序管理 (MAM)

移动应用程序管理是指公司使用企业软件集中管理运行在移动设备上的应用程序。这包括向设备交付应用程序、更新应用程序，以及从中心点实施应用程序安全。

### SEAndroid

安全增强型 Android 是一个为 Android 操作系统添加安全增强功能的项目。这些安全增强功能旨在防止应用程序泄露数据、防止应用程序提权，并保护设备上应用程序及其数据的完整性。

# 数据安全

保护系统的很大一部分是确保系统或设备上的数据免受未经授权的个人访问。您应该通过多种不同的方式来保护数据：

## 文件权限

您可以控制谁有权访问哪些文件，以防止未经授权的个人在正常情况下访问文件。之所以提到“正常情况”，是因为我见过受权限保护的文件，其保护被通过从启动盘引导并访问数据的方式绕过了。

## 加密

为确保信息机密并受到保护免遭未经授权的使用，请对存储中的数据进行加密。如果您加密了数据，而未经授权的个人获得了文件访问权，他们将只能看到加密文本，无法解读该信息。

### 数据丢失防护 (DLP)

数据丢失防护是旨在分析离开组织的信息以确保敏感信息未被泄露的软件或硬件。DLP 可用于监控网络流量，并识别通过即时通讯、电子邮件或 HTTP、FTP 等协议发送的敏感信息。DLP 还可以分析存储中的数据，以确保敏感信息未存储在错误的位置。

## Windows 文件权限

在 Windows 操作系统中，您可以保护文件夹和文件，以便只有特定用户才能访问特定文件夹。例如，您希望确保只有会计人员能访问会计文件夹。

在 Windows 服务器上保护文件夹分两步：使用 NTFS 权限保护文件夹，然后在将文件夹共享到网络时设置共享权限。将文件夹共享到网络是您向 Windows 客户端“发布”文件夹的方式。用户只有在连接到服务器时才能连接到共享文件夹。以下列表总结了 NTFS 权限和共享：

### NTFS 权限

这些权限只能应用于 NTFS 分区。如果您未使用 NTFS，可以使用 `convert <drive_letter> /fs:ntfs` 命令从 FAT 或 FAT32 转换为 NTFS。一旦设置了 NTFS 权限，无论用户是在本地访问文件夹还是从网络上访问，这些权限都将生效。

### 共享

共享文件夹是将文件夹发布给网络客户端的方式。共享文件夹时，您也需要指定共享权限。请记住，当 NTFS 权限与共享文件夹权限发生冲突时，最严格的权限生效。例如，如果您授予了 NTFS“修改”权限和共享“读取”权限，当用户通过共享访问该文件夹时，其权限将是“读取”，因为它更严格。

## 共享文件夹权限
