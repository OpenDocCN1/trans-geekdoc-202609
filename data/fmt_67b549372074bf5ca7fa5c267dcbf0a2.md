#### 2.5.1 模型类型

![image](img/chapter_title_below.png)

不同的模型类型是通过指定模型的分布 `y` 和链接函数 `g` 获得的。这导致了一系列按响应类型分类的常见模型。

##### 尺度响应

以下选项常用：

- Linear. 指定正态分布和恒等链接函数。

- Gamma with log link. 指定伽马分布和对数链接函数。

##### 顺序响应

以下选项常用：

- Ordinal logit. 指定多项式 `ordinal` 分布和累积 logit 链接函数。

- Ordinal probit. 指定多项式 `ordinal` 分布和累积 probit 链接函数。

##### 计数

以下选项常用：

- Poisson log-linear. 指定泊松分布和对数链接函数。

- Negative binomial with log link. 指定负二项分布，辅助参数取值为 1 和对数链接函数。若要让过程计算辅助参数的值，请指定自定义模型，使用负二项分布并在参数组中选择 Estimate value。

##### 二元响应或事件/试验数据

以下选项通常使用：

- Binary logit. 指定二项分布和 logit 链接函数。

- Binary probit. 指定二项分布和 probit 链接函数。

- Interval censored survival. 指定二项分布和互补对数-对数链接函数。

##### 组合

以下选项常用：

- Tweedie with log link. 指定 Tweedie 分布和对数链接函数。

- Tweedie with identity linking. 指定 Tweedie 分布和恒等链接函数。

##### 自定义

有时会使用分布与自定义链接函数的组合。

能够指定因变量的特定分布，而不仅仅是正态分布，以及能够指定链接函数，而不仅仅是恒等链接，是广义线性模型相对于一般线性模型的主要改进。有许多可能的分布和链接函数的组合，其中几种可能适用于给定的数据集，因此其选择可能由先验理论考虑以及哪些组合效果最好来指导。

- Binomial. 该分布仅适用于表示二元响应或事件数的变量。

- Gamma. 该分布适用于具有正尺度值且偏向较大正值的变量。如果数据值小于或等于 0 或为缺失值，则相应案例不应用于分析。

#### 分布

- **逆高斯分布**。该分布适用于正尺度值且偏向较大正值的变量。如果数据值小于或等于 0 或为缺失值，则对应的案例不得用于分析。

- **负二项分布**。该分布考虑实现 k 次成功所需的尝试次数，适用于具有非负整数值的变量。如果数据值不是整数、小于 0 或为缺失值，则对应的案例不得用于分析。负二项分布的辅助参数值可以是大于或等于 0 的任意数；可以将其设为固定值或留给过程进行估计；当辅助参数设为 0 时，使用该分布等同于使用泊松分布。

- **正态分布**。适用于取值围绕中心值（均值）呈对称钟形分布的尺度变量。因变量必须是数值型。

- **泊松分布**。该分布考虑固定时间段内感兴趣事件的发生次数，适用于具有非负整数值的变量。如果数据值不是整数、小于 0 或为缺失值，则对应的案例不得用于分析。

- **Tweedie 分布**。该分布适用于可由伽马分布的泊松混合表示的变量；该分布在“混合”意义上结合了连续（取非负实数值）和离散（在单个值 0 处具有正概率质量）分布的特性。因变量必须是数值型，且数据值必须大于或等于零。如果数据值小于 0 或为缺失值，则对应的案例不得用于分析。Tweedie 分布参数的固定值可以是大于 1 且小于 2 的任意数。

- **多项分布**。该分布适用于表示有序响应的变量。因变量可以是数值型或字符串型，且必须具有至少两个不同的有效数据值。

### 2.5.2 联系函数

![image](img/chapter_title_below.png)

联系函数 `g` 是对因变量的一种变换，可实现模型的估计。常用的函数如下：

- **恒等**。`g(x)=x`。因变量不进行变换。此联系函数可与任何分布一起使用。

- **互补对数-对数**。`g(x)=log(-log(1-x))`。仅适用于二项分布。

- **累积柯西**。`g(x) = tan(π (x - 0.5))`，应用于响应每个类别的累积概率。仅适用于多项分布。

- **累积互补对数-对数**。![image](img/image111.png)，应用于响应每个类别的累积概率。仅适用于多项分布。

- **累积对数几率**。`g(x)=ln(x / (1-x))`，应用于响应每个类别的累积概率。仅适用于多项分布。

- **累积负对数-对数**。![image](img/image214.png)。应用于每个响应类别的累积概率。仅适用于多项分布。

- **累积 Probit**。![image](img/image302.png) 应用于响应每个类别的累积概率，其中 ![image](img/image286.png) 为逆标准正态累积分布函数。仅适用于多项分布。

- **对数**。![image](img/image449.png) 此联系函数可与任何分布一起使用。

- **对数补**。![image](img/image127.png) 仅适用于二项分布。

- **对数几率**。![image](img/image349.png) 仅适用于二项分布。

- **负二项**。![image](img/image470.png) 其中 `k` 为负二项分布的辅助参数。仅适用于负二项分布。

- **负对数-对数**。![image](img/image064.png) 仅适用于二项分布。

- **概率幂**。![image](img/image613.png) `α` 为所需数字规范，必须为实数。仅适用于二项分布。

- **Probit**。![image](img/image406.png)，其中 `Φ^(-1)` 为逆标准正态累积分布函数。仅适用于二项分布。

- **幂**。![image](img/image332.png) 若 `α=0`。`α` 为所需数字规范，必须为实数。此联系函数可与任何分布一起使用。
