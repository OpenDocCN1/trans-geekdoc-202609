
这可以通过顺序遍历变量并在过程中乘以 CPT 项来解释。对于每个求和，还需要遍历变量的值。该计算的结构如图13.10所示。使用图13.2中的数字，我们得到 `P(b|j,m) = α × 0.005224 × 0.01419 ≈ (0.284, 0.716)`。也就是说，在已知两者的情况下，入窃的概率约为28%。图13.11中的 `ENUMERATE-ASK` 算法从左到右深度优先评估这些树。该算法与CSP的回溯算法（图5.5）以及用于可满足性的DPLL算法（图7.7）非常相似。它的空间复杂度与变量数量成线性：算法直接求和整个分布而不构建它。遗憾的是，对于具有 `n` 个变量的查询，它的时间复杂度为 `O(2^n)`——比前面描述的 `O(n^n)` 好，但仍然很大。对于图13.9中的保险网络，典型的查询需要大约20万次算术操作。如果你仔细观察图13.10中的树，你会发现它包含重复的子表达式。`P(j|a)P(m|a)` 对于每个 `E` 的值都被计算两次。贝叶斯网络高效推理的关键是避免浪费计算。下一节描述了此的通用方法。

```
function ENUMERATE-ASK(X, e, bn) returns a distribution over
inputs: X, 查询变量
  e, 变量 E 的观测值
  bn, 带有变量 vars 的贝叶斯网络
Q(X) <- 关于 X 的分布，初始为空
for each x_i of X do
  Q(x_i) <- ENUMERATE-ALL(vars, e_i)
  where e_i 扩展了 X = x_i
return NORMALIZE(Q(X))

function ENUMERATE-ALL(vars,e) returns a number
  if EMPTY(vars) then return 1.0
  V <- FIRST(vars)
  if V 是 e 中值为 v 的证据变量
  then return P(v|parents(V)) * ENUMERATE-ALL(REST(vars),e)
  else return sum_v P(v|parents(V)) * ENUMERATE-ALL(REST(vars),e_v)
  where e_v 扩展了 V = v
```

### 13.3.2 变量消除算法

通过消除图13.10所示的重复计算可以大幅改进枚举算法。思想很简单：计算一次并保存结果以备后用。这是动态规划的一种形式。这种方法有几个版本；我们介绍最简单的变量消除算法。变量消除通过从右到左顺序评估如公式 (13.5) 的表达式（即图13.10中的自底向上）。中间结果被存储，对每个变量的求和仅针对表达式中依赖于该变量的部分。

让我们以入窃网络来说这个过程。我们评估表达式：

```
P(B|j,m) = α P(B) ∑_e1 P(e1) ∑_A f1(A,B) ∑_f4 P(j|a) ∑_f5 P(m|a)
```

注意我们为表达式的每个部分注释了相应因子的名称；每个因子都是由其参数值索引的矩阵。例如，对应于 `P(j|a)` 和 `P(m|a)` 的因子 `f4(A)` 和 `f5(A)` 只取决于 `A`，因为 `J` 和 `M` 是固定的。

### 因子上的操作

两个因子 `f` 和 `g` 的逐点乘积产生一个新因子 `h`，其变量是 `f` 和 `g` 中变量的并集，其元素由两个因子中对应元素的乘积给出。假设两个因子具有共同变量 `Y1, ..., Yk`。那么我们有 `f(X,Y1...Yk) × g(Y1...Yk,Z) = h(X,Y...Z)`。

如果所有变量都是二元的，那么 `f` 和 `g` 分别有 `2^k` 和 `2^l` 个条目，而逐点乘积有 `2^(k+l)` 个条目。例如，给定两个因子 `f(X,Y)` 和 `g(Y,Z)`，逐点乘积 `f × g = h(X,Y,Z)` 具有 `2^(1+1)=8` 个条目，如图 13.12 所示。注意，逐点乘积产生的因子可能包含比被乘的任何因子更多的变量，且因子的大小与变量数量呈指数级关系。这就是消除算法中产生空间和时间复杂度的地方。

对因子乘积进行求和是通过将感兴趣的变量固定为其每个值，然后相加形成的矩阵完成的。例如，为了从 `h(X,Y,Z)` 中求出 `X`，我们写下 `h(Y,Z) = ∑_x h(x,Y,Z) = h(t,Y,Z) + h(f,Y,Z) = [[.06, .18], [.28, .42]] + [[.24, .32]]`。唯一的技巧是注意到任何不依赖于待求变量的因子都可以移动到求和符号外部。例如，从 `f` 和 `g` 的乘积中求出 `X`，我们可以将 `g` 移出求和符号：`∑_x f(X,Y) × g(Y,Z) = g(Y,Z) × ∑_x f(X,Y)`。

通常情况下，变量消除的时间和空间需求由算法运行过程中构造的最大因子的大小决定。这取决于变量的消除顺序和网络的结构。事实证明确定最佳顺序是困难的，但有几种很好的启发式方法。一种有效的方法是贪心法：消除任何能使下一个要构造的因子大小最小的变量。

让我们考虑一个查询：`P(JohnCalls|Burgary=true)`。按照惯例（见方程 (13.5)），第一步是写出嵌套求和：`P(J|m) = α P(b) ∑_e P(a|b,e) P(j|a) ∑_m P(m|a)`。

从左到右评估这个表达式时，我们注意到：`∑_m P(m|a)` 根据定义等于 1！没有必要将其包含在第一个式中；变量 `M` 与此查询无关。另一种说法是，如果我们完全从网络中移除 `MaryCalls`，则查询 `P(JohnCalls|Burgary=true)` 的结果将保持不变。我们可以移除任何不是查询变量或证据变量的叶子节点。

## 第 13.3 节 贝叶斯网络中的精确推理

精确推理的复杂性很大程度上取决于网络的结构。图 13.2 中的入窃网络属于这样一类网络：任意两个节点之间最多只有一条路径（即忽略箭头的方向）。这些网络被称为多叉树（polytrees），它们具有良好的性质：多叉树中精确推理的时间和空间复杂度与网络的大小成线性关系。在这里，大小定义为 CPT 条目的数量；如果每个节点的父节点数量受常数限制，复杂度也与大小成线性关系。

对于多连接节点，例如图 13.9 所示的网络，在最坏情况下消除可能具有指数级的时间空间复杂度，即使每个节点的父节点数量是有界的。这并不意外，考虑到它允许将命题逻辑作为特例，贝叶斯网络的推理是 NP 难的。为了解决这个问题，我们需要研究如何将命题满足性问题编码为贝叶斯网络，以便对其运行推理可以告诉我们原始句子是否满足。事实证明图 13.14 显示了如何编码 3-SAT 问题。命题变量变成网络的根变量，每个先验概率为 0.5。下一层节点对应于子句，每个子句 `Cj` 与相应的变量通过确定性合取连接，以便仅当父节点的赋值满足该子句时，每个子句为真。`S` 是子句变量的合取。

为了确定原始句子是否满足，我们只需评估 `P(S=true)`。如果句子是可满足的，则存在某种逻辑赋值使得 `S` 为真；在贝叶斯网络中，这意味着存在一个概率非零的可能世界，根变量具有赋值，子句为真且 `S` 为真。对于满足的句子，`P(S=true)>0`。相反，对于不可满足的句子，`P(S=true)=0`。

## 13.3.4 聚类算法

变量消除算法在回答查询方面简单且高效。然而，如果我们想计算网络中所有变量的后验概率，它的效率可能会降低。在多叉树（polytree）中，需要使用 `O(n)` 次查询，每次查询耗时 `O(n)`，总时间为 `O(n²)`。通过使用聚类算法（也称为树算法），可以将时间缩短到 `O(n)`。由于这个原因，这些算法被广泛应用于复杂的贝叶斯网络。

## 13.4 贝叶斯网络的近似推理

鉴于大型网络中精确推理的不可行性，我们现在考虑推理方法。本节描述了采样算法（也称为蒙特卡洛算法），这些算法提供近似答案，其准确性取决于生成的样本数量。它们通过根据贝叶斯网络中的概率生成随机事件，并统计在随机事件中发现的不同答案。只要有足够的样本，我们可以任意选择恢复真实的概率分布——前提是贝叶斯网络没有确定性的条件分布。

### 蒙特卡洛

蒙特卡洛算法（模拟退火是第133页的一个例子）用于许多科学领域，以估计难以精确计算的量。在本节中，我们关注的是贝叶斯网络后验概率计算的采样。我们描述了两类算法：直接采样和马尔可夫链采样。近似推理的其他方法在章节末尾的注释中提及。

### 13.4.1 直接采样方法

任何采样算法的原始元素都是从已知概率分布中生成样本。例如，一个无偏硬币可以被看作取值为（*正面，反面*）的随机变量，先验分布为 `P(Coin) = (0.5, 0.5)`。从该分布中采样就像抛硬币一样：以0.5的概率返回*正面*，以0.5的概率返回*反面*。给定一个均匀分布在 `[0,1]` 范围内的随机数源 `r`，对单个变量采样任何分布（无论是离散还是连续）都是简单的。这是通过构建该变量的累积分布并返回第一个累积概率超过 `r` 的值来实现（见练习 13.PRSA）。

我们从一个没有证据的贝叶斯网络的随机采样过程开始。是按照拓扑顺序轮流采样每个变量。采样变量的概率分布取决于已采样的值（因为我们按拓扑顺序采样，所以保证了父节点有值）。该算法如图 13.16 所示。将其应用于图 13.15(a) 中的网络，顺序为 *Cloudy, Sprinkler, Rain, WetGrass*，我们可能会产生如下随机事件：
