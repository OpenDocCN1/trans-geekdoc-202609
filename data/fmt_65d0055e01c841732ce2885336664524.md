
对 $\boldsymbol{\mu}$ 求梯度，我们得到^[¹²]。

### 3.10.1 线性回归：非白高斯噪声情况

考虑线性回归模型

$$y = \boldsymbol{\theta}^T \mathbf{x} + \eta.$$

我们得到 $N$ 个训练数据点 $(y[n], \mathbf{x}[n])$，$n = 1, 2, \dots, N$。相应的（未观测到的）噪声样本 $\eta[n]$，$n = 1, \dots, N$，假设服从均值为零、协方差矩阵等于 $\boldsymbol{\Sigma}_\eta$ 的联合高斯分布。也就是说，包含所有噪声样本堆叠而成的随机向量 $\boldsymbol{\eta} = [\eta[1], \dots, \eta[N]]^T$ 服从多元高斯分布

#### 最大似然估计推导

噪声向量 $\boldsymbol{\eta}$ 的概率密度函数为：

$$

p(\boldsymbol{\eta}) = \frac{1}{(2\pi)^{N/2}|\Sigma_{\eta}|^{1/2}}\exp\left( - \frac{1}{2}\boldsymbol{\eta}^{T}\Sigma_{\eta}^{-1}\boldsymbol{\eta} \right).

$$

![Equation](img/si322.png)

我们的目标是获得参数 $\boldsymbol{\theta}$ 的最大似然估计。

将 $\boldsymbol{\eta}$ 替换为 $\mathbf{y} - X\boldsymbol{\theta}$，并取对数，参数 $\boldsymbol{\theta}$ 关于训练集的联合对数似然函数为：

$$

L(\boldsymbol{\theta}) = - \frac{N}{2}\ln(2\pi) - \frac{1}{2}\ln|\Sigma_{\eta}| - \frac{1}{2}\left( \mathbf{y} - X\boldsymbol{\theta} \right)^{T}\Sigma_{\eta}^{-1}\left( \mathbf{y} - X\boldsymbol{\theta} \right),

$$

![Equation](img/si324.png) (3.59)

其中 $\mathbf{y} := [y[1], y[2], \dots, y[N]]^{T}$，而 $X := [\mathbf{x}[1], \dots, \mathbf{x}[N]]^{T}$ 代表输入矩阵。

![Equation](img/si325.png) ![Equation](img/si326.png)

对 $\boldsymbol{\theta}$ 求梯度，得到：

$$

\frac{\partial L(\boldsymbol{\theta})}{\partial\boldsymbol{\theta}} = X^{T}\Sigma_{\eta}^{-1}\left( \mathbf{y} - X\boldsymbol{\theta} \right),

$$

![Equation](img/si327.png) (3.60)

令其等于零向量，可得：

$$

\widehat{\mathbf{\theta}}_{\text{ML}} = \left( X^{T}\Sigma_{\eta}^{- 1}X \right)^{- 1}X^{T}\Sigma_{\eta}^{- 1}\mathbf{y}.

$$

![Equation](img/si328.png)(3.61)

#### 备注 3.3

*   将公式 (3.61) 与公式 (3.17) 中给出的 LS 解进行比较。它们是不同的，除非连续噪声样本的协方差矩阵 $\Sigma[\eta]$ 是对角矩阵且形式为 $\sigma[\eta]² I$，即噪声既是高斯的又是白色的。在这种情况下，LS 解和 ML 解重合。然而，如果噪声序列是非白的，这两个估计值就会不同。此外，可以证明（问题 3.9）*在这种情况下，对于有色高斯噪声，ML 估计是有效的，并且即使 N 是有限的，它也能达到 Cramér–Rao 界*。

## 3.11 贝叶斯推断

在我们迄今为止的讨论中，我们假设与所采用模型的函数形式相关的参数是确定性常数，其值对我们是未知的。在本节中，我们将遵循一种不同的基本原理。未知参数将被视为随机变量。因此，每当我们的目标是估计它们的值时，这被视为一种努力，旨在估计与观测数据相对应的*特定*实现的值。关于贝叶斯推断基本原理的更详细讨论见第 12 章。正如“贝叶斯”这个名字所暗示的，该方法的核心在于著名的贝叶斯定理。给定两个联合分布的随机向量，设为 $\mathbf{x}$、$\boldsymbol{\theta}$，贝叶斯定理指出

$$

p(\mathbf{x}, \boldsymbol{\theta}) = p(\mathbf{x}|\boldsymbol{\theta})p(\boldsymbol{\theta}) = p(\boldsymbol{\theta}|\mathbf{x})p(\mathbf{x}).

$$

![Equation](img/si330.png)(3.62)

Thomas Bayes（1702–1761）是一位英国数学家和长老会牧师，他首创了该理论的基础。然而，是伟大的法国数学家 Pierre-Simon Laplace（1749–1827）进一步发展并推广了它。

假设 $\mathbf{x}, \boldsymbol{\theta}$ 是两个统计相关的随机向量。设 $\mathcal{X} = \{\mathbf{x}[n] \in \mathbb{R}^{(l)}, n = 1, 2, \dots, N\}$ 为由 $N$ 次连续实验产生的观测集合。则贝叶斯定理给出

$$

p(\boldsymbol{\theta}|\mathcal{X}) = \frac{p(\mathcal{X}|\boldsymbol{\theta})p(\boldsymbol{\theta})}{p(\mathcal{X})} = \frac{p(\mathcal{X}|\boldsymbol{\theta})p(\boldsymbol{\theta})}{\int p(\mathcal{X}|\boldsymbol{\theta})p(\boldsymbol{\theta})\ d\boldsymbol{\theta}}.

$$

![Equation](img/si333.png) (3.63)

显然，如果观测值是独立同分布的，那么我们可以写成

$$p(\mathcal{X}|\boldsymbol{\theta}) = \prod_{n=1}^{N} p(\mathbf{x}_n|\boldsymbol{\theta}).$$

![Equation](img/si334.png)

在上述公式中，$p(\boldsymbol{\theta})$ 是 $\boldsymbol{\theta}$ 的先验或*先验*分布，而 $p(\boldsymbol{\theta}|\mathcal{X})$ 是在获得 $N$ 个观测值集合后形成的条件或后验或*后验* PDF。先验概率密度 $p(\boldsymbol{\theta})$ 可以被视为一种约束，它*封装了我们关于 $\boldsymbol{\theta}$ 的先验知识*。毫无疑问，在接收到观测值后，我们对 $\boldsymbol{\theta}$ 的不确定性会发生改变，因为现在向我们揭示了更多信息。如果关于底层模型的采用假设是合理的，我们期望后验 PDF 能更准确地描述 $\boldsymbol{\theta}$ 的统计特性。我们将基于一组训练数据来近似随机量 PDF 的过程称为*推断*，以将其与返回每个参数/变量单一值的估计过程区分开来。因此，根据推断方法，人们试图得出关于相关变量所蕴含的随机性本质的结论。反过来，这些信息可用于进行预测和做出决策。

我们将以两种方式利用公式 (3.63)。第一种指的是我们熟悉的目标，即获得参数向量 $\boldsymbol{\theta}$ 的估计，该向量“控制”着描述我们观测值 $\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_N$ 生成机制的模型。因为 $\mathbf{x}$ 和 $\boldsymbol{\theta}$ 是两个统计相关的随机向量，根据第 3.9 节，已知 $\mathcal{X}$ 的条件下 $\boldsymbol{\theta}$ 值的 MSE 最优估计是

$$\widehat{\boldsymbol{\theta}} = \mathbb{E}[\boldsymbol{\theta}|\mathcal{X}] = \int \boldsymbol{\theta} p(\boldsymbol{\theta}|\mathcal{X}) d\boldsymbol{\theta}.$$

![Equation](img/si338.png) (3.64)

在统计推断的背景下，利用贝叶斯定理的另一个方向是获得给定观测值 $\mathcal{X}$ 条件下 $\mathbf{x}$ 的 PDF 估计。这可以通过对一个分布进行*边缘化*来完成，使用的方程是

$$p(\mathbf{x}|\mathcal{X}) = \int p(\mathbf{x}, \boldsymbol{\theta}|\mathcal{X}) d\boldsymbol{\theta} = \int p(\mathbf{x}|\boldsymbol{\theta}) p(\boldsymbol{\theta}|\mathcal{X}) d\boldsymbol{\theta},$$

![Equation](img/si339.png) (3.65)

其中利用了给定值 `θ = θ` 时 `x` 关于 `X` 的*条件独立性*，表示为 `p(x|X, θ) = p(x|θ)`。确实，如果给定了 `θ` 的值，那么条件概率 `p(x|θ)` 就完全确定了，且不依赖于 `X`。如果后者未知，`x` 对 `X` 的依赖是通过 `θ` 实现的。公式 (3.65) 通过利用所获观测值中蕴含的信息以及对参数 `θ` 所采用的函数依赖关系，提供了未知 PDF 的估计。请注意，这与我们在 ML 方法中所做的形成对比：在 ML 方法中，我们利用观测值来获得参数向量的估计；而在这里，我们假设参数是随机变量，通过 `p(θ)` 提供关于 `θ` 的先验知识，并对联合 PDF `p(x, θ|X)` 进行关于 `θ` 的积分。

一旦 `p(x|X)` 可用，即可用于预测。假设我们已获得观测值 `x[1], …, x[N]`，那么我们对下一个值 `x[N + 1]` 的估计可以通过 `p(x[N + 1]|X)` 来确定。显然，`p(x|X)` 的形式通常会随着新观测值的获得而改变，因为每当一个观测值变得可用时，我们对潜在随机性的不确定性就有一部分被消除了。

### 示例 3.8

考虑公式 (3.33) 简化的线性回归任务，并假设 `x = 1`。正如我们已经说过的，这个问题是估计埋没在噪声中的常数值。我们的方法将遵循贝叶斯哲学。假设噪声样本是从零均值、方差为 `σ[η]²` 的高斯 PDF 中独立同分布（i.i.d.）抽取的。然而，我们通过先验分布施加关于未知 `θ` 的先验知识：

```
p(θ) = N(θ|θ[0], σ[0]²).
```

(3.66)

也就是说，我们假设知道 `θ` 的值位于 `θ₀` 附近，而 `σ₀²` 量化了我们对这一先验知识的不确定程度。我们的目标首先是获得后验 PDF，给定观测值集合 `y = [y₁, …, y_N]ᵀ`，然后根据方程 (3.63) 和 (3.64) 获得 `𝔼[θ|y]`，并将它们调整以适应我们当前的符号需求。我们有

```
p(θ|y) = p(y|θ)p(θ) / p(y)
       = (1 / p(y)) (∏_{n=1}^N p(y_n|θ)) p(θ)
       = (1 / p(y)) (∏_{n=1}^N (1 / (√(2π) σ_η)) exp(-(y_n - θ)² / (2 σ_η²)))
         × (1 / (√(2π) σ_0)) exp(-(θ - θ_0)² / (2 σ_0²)).
``` (3.67)

经过对方程 (3.67) 的一些代数运算（问题 3.25），最终得到以下结果：

#### 后验分布推导

$$p(\theta|\mathbf{y}) = \frac{1}{\sqrt{2\pi}\sigma_{N}}\exp\left( - \frac{(\theta - {\overline{\theta}}_{N})^{2}}{2\sigma_{N}^{2}} \right), \tag{3.68}$$

其中

$${\overline{\theta}}_{N} = \frac{N\sigma_{0}^{2}{\overline{y}}_{N} + \sigma_{\eta}^{2}\theta_{0}}{N\sigma_{0}^{2} + \sigma_{\eta}^{2}}, \tag{3.69}$$

这里 ${\overline{y}}_{N} = \frac{1}{N}\sum_{n = 1}^{N}y_{n}$ 是观测值的样本均值，且

$$\sigma_{N}^{2} = \frac{\sigma_{\eta}^{2}\sigma_{0}^{2}}{N\sigma_{0}^{2} + \sigma_{\eta}^{2}}. \tag{3.70}$$

换句话说，如果先验和条件 PDF 都是高斯分布，则后验分布也是高斯分布。此外，后验的均值和方差分别由公式 (3.69) 和 (3.70) 给出。

观察可知，随着观测数量的增加，${\overline{\theta}}_{N}$ 趋向于观测值的样本均值；回顾一下，后者是由最大似然（ML）方法得到的估计。同时请注意，随着观测数量的增加，方差持续减小，这符合常识，因为更多的观测意味着更小的不确定性。图 3.10 说明了上述讨论。

数据样本 $y[n]$ 由高斯伪随机生成器生成，均值为 $\theta = 1$，方差为 $\sigma[\eta]^{2} = 0.1$。因此，我们未知参数的真实值等于 1。我们使用了均值为 $\theta_{0} = 2$、方差为 $\sigma_{0}^{2} = 6$ 的高斯先验 PDF。我们观察到，随着 $N$ 的增加，后验 PDF 变得更窄，其均值趋向于真实值 1。

##### 图 3.10

![Figure 3.10 In the Bayesian inference approach, note that as the number of observations increases, our uncertainty about the true value of the unknown parameter is reduced and the mean of the posterior PDF tends to the true value and the variance tends to zero.](img/gr010.jpg)

**图 3.10** 在贝叶斯推断方法中，请注意，随着观测数量的增加，我们对未知参数真值的不确定性降低，后验概率密度函数（PDF）的均值趋向于真值，方差趋向于零。

应该指出，在这个示例中，最大似然（ML）估计和最小二乘（LS）估计变得相同，即

$$\widehat{\theta} = \frac{1}{N}\sum\limits_{n = 1}^{N}y_{n} = {\overline{y}}_{N}.$$

![Equation](img/si362.png)

如果我们将 `\sigma_0²` 设得非常大，公式 (3.69) 中的均值也将如此，这种情况可能发生在我们对初始估计 `\theta_0` 没有信心，并给 `\sigma_0²` 赋予一个非常大的值时。实际上，这等同于不使用任何先验信息。

现在让我们研究一下，如果我们关于 `\theta_0` 的先验知识以约束的形式“嵌入”到最小二乘准则中会发生什么。这可以通过修改公式 (3.40) 中的约束来实现，使得

$$(\theta - \theta_0)² \le \rho,$$

![Equation](img/si364.png) (3.71)

这导致以下拉格朗日函数的等价最小化：

$$\text{minimize}\quad L(\theta,\lambda) = \sum\limits_{n = 1}^{N}{(y_n - \theta)}^{2} + \lambda\left( {(\theta - \theta_0)}^{2} - \rho \right).$$

![Equation](img/si365.png) (3.72)

对 `\theta` 求导并令其等于零，我们得到

$$\widehat{\theta} = \frac{N{\overline{y}}_{N} + \lambda\theta_0}{N + \lambda},$$

![Equation](img/si366.png)

当 `\lambda = \sigma_\eta²/\sigma_0²` 时，这变得与公式 (3.69) 相同。世界真小！之所以发生这种情况，仅仅是因为我们对条件概率密度函数和先验概率密度函数都使用了高斯分布。对于不同形式的概率密度函数，情况将不再如此。然而，这个例子表明先验知识与约束之间存在着紧密的联系。它们都试图施加先验信息。每种方法以其独特的方式，都有各自的优缺点。在第 12 章和第 13 章中，我们将对贝叶斯推断任务进行更详尽的阐述，届时我们将看到，正则化的本质——一种对抗过拟合的手段——正是贝叶斯方法的核心所在。

最后，人们可能会想知道，与确定性参数估计路径相比，贝叶斯推断是否为我们提供了更多信息。毕竟，当目标是获得未知参数的特定值时，取高斯后验分布的均值得出的解，与正则化最小二乘（LS）方法得出的结果相同。然而，即使对于这种简单的情况，贝叶斯推断也能直接提供一条额外信息；即均值周围方差的估计，这对于评估我们对恢复估计值的信任度非常有价值。当然，所有这些结论的前提是，所采用的概率密度函数（PDF）能够很好地描述当前过程的统计特性 [24]。
