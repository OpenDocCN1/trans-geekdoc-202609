
# 僵尸网络 (Botnet)

僵尸网络是由攻击者控制的计算机网络。控制数百台计算机让作恶之徒能够执行特定类型的网络攻击，包括 DDoS（见下文）。然而，购买成千上万台计算机并不划算，因此黑客会部署恶意软件来感染连接到网的任意计算机。

# 暴力破解 (Brute Force)

暴力破解攻击通常由一个自动化的尝试错误程序组成，以找到正确的密码。大多数现代加密方法使用不同的程序来减慢暴力破解攻击，这使得在合理的时间内测试所有组合变得困难或不可能。

# 破解 (Cracking)

这是一个描述未经授权进入安全系统的通用术语。黑客（Hackers）是喜欢捣乱的人；他们并不一定是坏人。而破解者（Crackers）是有恶意的。

# 加密 (Crypto)

密码学（Cryptography）的缩写，秘密通信的科学，或通过加密隐藏信息和数据的程序和过程（见下文）。

# 离线攻击 (Chip-Off)

离线攻击要求用户移除设备中的内存存储芯片，以便使用专用应用程序从从中抓取信息。这种攻击曾被执法部门用于破解受 PGP 保护的黑莓手机。

# 暗网 (Dark Web)

暗网由 Google 未被索引的网站组成，只能通过 Tor（见下文）等特殊网络访问，暗网被希望保持匿名的网站运营者使用。暗网上的一切都是深网，但深网上的并非全都是暗网。

# 分布式拒绝服务 (DDoS)

DDoS 是分布式拒绝服务攻击。这导致了目标：减慢网站速度或使其无法访问。攻击者也可以使用更简单的拒绝服务攻击，这种攻击可以从一台计算机发起。

# 深网 (Deep Web)

这个术语和“暗网”有时被互换使用，尽管它们不应该这样。深网是互联网中未被搜索引擎索引的区域。

# 数字证书 (Digital Certificate)

一种电子护照或批准印章，用于证明在线个人、网站或服务的身份。从更技术性的角度来说，数字认证证明了某人拥有特定的加密密钥，该密钥在传统上是无法伪造的。最流行的数字证书是网站的，它们保证你与它们之间的连接经过了适当的加密。这些在你的浏览器中显示为绿色锁。

# 加密 (Encryption)

扰乱消息或数据使其变得不可读且机密的过程。相反的过程是解密，即对消息进行解码。加密和解密都是密码学的行为。个人、公司以及电子安全中的客户产品使用加密。

# 端端加密 (End-to-End Encryption)

一种特定的加密类型，消息或数据在这一端（例如你的电脑或电话）被扰乱编码，并在另一端（如他人的计算机）接收并解密。

# 恶毒女仆攻击 (Evil Maid Assault)

正如名称可能暗示的那样，恶毒女仆攻击是一种需要物理访问计算机的黑客——例如，邪恶的女仆在整理她或雇主的办公室时可能拥有的那种访问。

# 利用 (Exploit)

利用是指利用计算机或程序中的漏洞或缺陷的方法或过程。并不是所有的漏洞都是利用。这样想：如果你的门有故障，它可能只是在你关门时会发出奇怪的声音，或者它的锁可以被撬开。这两种都是缺陷，但只有一种可以帮助入室者进入。犯者撬锁的方式就是利用。

# 取证 (Forensics)

在《犯罪现场调查》等剧中，法证调查涉及一系列确切的步骤，以确定犯罪期间发生了什么。然而，在黑客方面，调查人员寻找的是数字指纹而非物理指纹。这一程序通常涉及尝试从嫌疑犯罪者使用或滥用的设备（可能是手机、台式计算机或服务器）中检索消息或其他信息。

# 政府通信总部 (GCHQ)

英国相当于 NSA（美国国家安全局）的机构。该公司在其网站上说：“由于这些对手秘密操作，GCHQ 也必须如此。”

# 黑客 (Hacker)

“由于这些对手秘密操作，GCHQ 也必须如此，”该公司在其网站上说。

# 黑客主义 (Hacktivist)

一个出于政治目的进行黑客黑客。黑客主义是指为了政治目的利用技术的个人。

# 哈希 (Hashing)

哈希函数是一种为了确保数据完整性而算法。如果你使用 HTTPS，可以确保你的连接是经过加密的。

# HTTPS/SSL/TLS

HTTPS 是超文本传输协议，带有“S”代表“安全”。HTTPS 使用 SSL 和 TLS 来保护连接。

# 信息安全 (Infosec)

“信息安全”的缩写。它通常被称为网络安全。

# 越狱 (Jailbreak)

绕过设备（如 iPhone）的制造限制。

# 密钥 (Keys)

现代密码学使用数字密钥。在其他系统中，如果攻击者获得了密钥，他们可能会获得机会。

# 乐趣 (Lulz)

网络用语变体，源自“lol”（大笑），常用。

# 恶意软件 (Malware)

代表“恶意软件”。它指的是任何旨在破坏或损害目标的程序或软件。

# 中人攻击 (Man-in-the-Middle)

中人攻击或 MitM 是一种常见的攻击，攻击将自己放在双方之间冒充他们。这允许恶意攻击者被动地监听，甚至更改数据流。

# 元数据 (Metadata)

元数据就是关于数据的数据。例如，如果你发送电子邮件，你输入的文本将是该消息的内容。

# NIST

美国国家标准与技术研究院是商务部的一个机构，致力于科学和标准支持工业创新。

# 随机数 (Nonce)

“数字”和“之后”的组合词，nonce 指“仅使用一次的数字”。它是系统生成的用于识别单次使用会话的。

# 运作安全 (OpSec)

OpSec 是运作安全的缩写，它关乎保持信息的机密，无论线上还是线下。“优秀的 OpSec 将涵盖一切，从传递消息到使用数字加密。

# OTR

如果你希望进行加密对话，但它需要快速发生，该怎么办？OTR 是一种对即时消息进行加密的协议。与 PGP 不同，OTR 为每次会话使用单一临时密钥。

# 密码管理器 (Password Managers)

对所有登录（从银行账户到 Seamless 再到你的 Tinder 个人资料）使用相同的糟糕密码是一个坏主意。为每个平台记住唯一的字符字符串是令人困难的。你只想记住你的主密码来登录管理器并获取所有不同的登录。

# 渗透测试 (Penetration testing or Pentesting)

如果你为家里、办公室或工厂建立了一个安全系统，你会希望确保它免受攻击者的侵害，对吧？检查系统安全性的一种方法是雇佣人员——渗透测试人员——来破解它以故意发现弱点。渗透测试与红队对抗有关，尽管它可以通过一种更有组织性、更少竞争性的方式进行。

# PGP

“优越隐私”（Pretty Good Privacy）是一种数据加密方法，通常情况下任何截获数据的人只会看到乱码。PGP 使用非对称加密，这意味着发送消息的个人使用“公钥”加密对其进行扰乱，而接收者则使用“私钥”对其进行解码。尽管已经有了两多年的历史，PGP 仍然是一种强大的加密技术，尽管对于经验丰富的用户来说，它在实践中可能非常难使用。

# 网络钓鱼 (Phishing)

网络钓鱼更多是一种社会工程，而不是黑客攻击或破解。在网络钓鱼过程中，攻击者通常会联系受害者以提取特定信息，这些信息可用于后续攻击。例如，可能伪装成 Google、Facebook 或受者的手机号码的用户服务，要求受害者点击恶意链接——或者只是要求受害者在电子邮件中发送密码等信息。攻击者通常会发起数以千计的钓鱼行动，但偶尔也会采用更集中的攻击方式，被称为“叉式网络钓鱼”（见下文）。

# 明文 (Plaintext)

顾如其名——未经过加密扰乱的文本。这个定义可以被视为明文。你也可以听过明文被称为“清晰文本”（cleartext），因为它指的是公开的或“明文状态”的文本。

# Pwned

Pwned 是计算机术语（或“黑客语”），对应动词“own”（拥有/击败）。在视频游戏世界中，击败另一个玩家的玩家可以说他 pwned 了对方。在黑客中，这个表达有类似的含义，并不是指在比赛中击败某人，而是获得另一个用户计算机访问权的黑客可以说他 pwned 了对方。

# RAT

RAT 代表远程访问工具（Remote Access Tool）或远程访问木马。RAT 被用作恶意软件时非常可怕。成功在你的电脑上安装 RAT 的攻击者可以获得对你系统的完全控制权。RAT 也有合法的业务用途，供想要从家里访问办公室电脑的男女等。RAT 最糟糕的部分是什么？许多恶意 RAT 可以在网络地下找到甚至免费获取，因此攻击者可以完全没有技能却使用这种复杂的工具。

# 勒索软件 (Ransomware)

勒索软件是一种恶意软件，它可以保护你的个人电脑并不允许你访问文件。你会看到一条消息，告知你赎金金额以及向哪里发送付款（通常要求使用比特币）以取回你的文件。这对黑客来说是一个极佳的工具，这也是为什么许多人认为它是一种“爆发”现象，因为个人通常愿意支付几百美元来挽回自己的损失。不仅是个体。在遥过去的 2016 年，洛杉矶的好莱坞卫理公会医疗中心在遭受勒索软件攻击后支付了约 17,000 美元。

# 彩虹表 (Rainbow Table)

彩虹表是一种复杂的技术，使黑客能够简化想象“哈希”值（如前所示）背后是什么密码的过程。

# 红队 (Red Team)

为了确保计算机系统的安全并探测出任何未知的漏洞，企业可以雇佣黑客组成一个“红队”，他们能够对系统发起对等攻击并尝试完全接管它。在这些情况下，被黑入是一件好事，因为组织可以在非本籍人员入侵之前修复漏洞。红队测试是一个应用于多个领域（包括军事计划）的通用概念。

# 根 (Root)

在大多数计算机中，“root”是赋予机器最基础（因此也是最强大）的访问权限的通常名称，或者是拥有这些权限的账户名称。这意味着“root”可以安装软件、删除和创建文件。如果黑客“获得根权限”（earnings root），他们可以在受侵害的系统或计算机上任何任何想做的事。这是黑客攻击的圣杯。

# Rootkit

Rootkit 是一种特定的恶意软件，它驻留在你的系统深处，并在每当你启动它时都会被触发，甚至在操作系统启动之前。这使得 rootkit 难以检测、具有持久性，并可以捕获感染计算机上几乎所有的信息。

# 加盐 (Salting)

在保护文本或密码时，“哈希”（如前所示）是一个将明文转换为乱码的基本过程。为了让哈希更加成功，个人或公司可以在哈希处理之前在密码中添加一组随机字节，称为“盐”（salt）。这增加了一层保护。

# 脚本小子 (Script Kiddies)

这是一个对那些只有一点点计算机知识且只会利用成品工具的贬义称呼，他们只能够利用现成的应用程序来执行诸如让网站离线或在未保护的 Wi-Fi 访问点内嗅探密码等事情。这无疑是一个用来贬低自称是精通黑客的人的术语。

# Shodan

它被众所知为“黑客的 Google”和一个“令人恐惧”的搜索引擎。将其看作是 Google，但针对的是连接设备而非网站。利用 Shodan 可以发现未保护的摄像头、婴儿监视器、打印机、医疗设备、加油泵，甚至是风力涡轮机。虽然这听起来很可怕，但 Shodan 的价值恰在于它帮助研究人员定位这些设备并提醒所有者以便他们进行安全防护。

# 签名 (Signature)

PGP 的另一个用途是你结合你的加密密钥对消息进行“签名”。因为这个密钥只有个人知道，并存储在他们的计算机上而不是其他地方，所以加密签名应该确认你认为正在交谈的人正是那个人。这是在网络上证明你的身份的极佳方式。

# 侧信道攻击 (Side Channel Attack)

你的计算机硬件始终发射连续的难以察觉的电信号。侧信道攻击试图识别这些信号中的模式，以了解机器正在执行哪些计算。例如，黑客通过“监听”正在创建密钥密钥的硬盘，可能重建该密钥，从而在你的不知情的情况下窃取它。

# 嗅探 (Sniffing)

嗅探是一种在不被察觉的情况下拦截网络传输数据的手段。一旦收集到信息，黑客可以对其进行筛选以寻找有用信息，如密码。它被认为是一种特别危险的攻击，因为可以在网络内部或外部进行。

# 社会工程学 (Social Engineering)

并不是所有的攻击都是通过盯着像黑客帝国绿色文字显示来执行的。有时，进入受保护的系统只需拨打电话或发送电子邮件并伪装成其他人——特别是经常访问该系统但忘记了密码的人。

# 叉式网络钓鱼 (Spear-Phishing)

网络钓鱼和叉式网络钓鱼经常被混用，但后者是一种更简单、更有针对性的网络钓鱼（如前所示），黑客试图欺骗受害者点击恶意附件或链接，伪装成发送者，例如社交网络或公司。如果操作当，叉式网络钓鱼可能非常有用且强大。

# 伪装 (Spoofing)

黑客可以通过操纵电子邮件地址等方式欺骗人们落入钓鱼攻击（前文提到），使其看起来像是目标所理解的人说话。这就是伪装。它也可以用于电话诈骗，或制作假的网站地址。

# 间谍软件 (Spyware)

一种特殊的恶意软件，旨在监视、跟踪和窃取目标信息。

# 国家级攻击者 (State Actor)

国家级攻击者是由政府支持的黑客或黑客群体，可能是美国、俄罗斯或中国。这些黑客通常是最强大的，因为他们拥有国家提供的几乎无限的法律和财政资源作为支持。例如，国家级攻击者也可能是获得政府默许支持（或至少对公众隐藏的支持）的黑客群体，如叙利亚电子军。

# 威胁模型 (Threat Model)

想象一场国际象棋游戏。现在轮到你了，你正在思考对手可能采取的所有潜在移动，尽可能地考虑后几步。你是否让你的皇后处于无保护状态？你的王是否被逼入死角将死？这种思考方式正是安全研究人员在设计威胁模型时所做的。它是一个统术语，用于描述你需要防范的敌人能力。如果你是一个试图抵御国家支持的黑客集团的活动人士，那么你的威胁模型最好足够稳健。如果你只是想加固你位于偏远地区的小木屋的网络呢？可能没那么需要担心。

# 令牌 (Token)

一种微小的物理设备，允许所有者登录或对服务进行身份验证。例如，令牌可以作为密码之外的额外安全层。其点在于，即使密码或密钥被盗取，黑客也需要真实的物理令牌才能滥用。

# Tor

Tor 是“洋葱路由”（The Onion Router）的缩写。它最初由美国海军研究实验室开发，现在被用于坏分子（黑客、网络犯罪分子）以及活动人士或记者用于匿名其在线行为。其基本思想是全球范围内有一个计算机网络——由大学、个人或政府运营——这些网络将以拜庭的方式路由你的访问请求，以隐藏你的实际位置。Tor 系统就是这些由志愿者运行的计算机集合。Tor 项目是维护 Tor 软件的非营利组织。Tor 浏览器是一个完全免费的软件，让你可以使用 Tor。Tor 隐藏服务是只能通过 Tor 访问的网站。

# Tails

Tails 代表“遗忘性匿名现场运行系统”（The Amnesic Incognito Live System）。如果你认真对待电子安全，这是一个由……支持的操作系统

# 验证（丢弃） (Verification (Ditch))

记者和安全研究人员对被黑数据进行审查并确保其真实程序。这种做法对于确保信息的真实性以及匿名黑客的指控是否准确至关重要，而不是仅仅为了获得名声或在暗网上诈骗人们来骗钱。

# VPN

VPN 代表“虚拟专用网络”（Virtual Private Network）。VPN 使用加密技术，当你处于一个你不信任的网络时（例如星巴克或 Airbnb 的 Wi-Fi）时，创建一个个人且安全的通道连接到。将 VPN 想象成一根通往目的地的隧道，挖掘在标准互联网之下。VPN 让员工远程连接到公司网络成为可能，并帮助普通个人保护他们的连接。VPN 还允许用户通过世界不同地区的服务器进行中转，让他们看起来像是从其他地方连接的。这让他们有机会绕过审查（例如中国的“长墙”），或者在加拿大观看 Netflix 的美国内容。VPN 有无限种，这使得几乎不可能选出哪些是最好的。

# 病毒 (Virus)

计算机病毒是一种恶意软件，通常隐藏嵌入在文件或程序中。与蠕虫（见下文）不同，它需要人类操作来传播（例如，个人转发受病毒感染的附件，或下载恶意软件）。病毒可以感染计算机并盗取数据、删除数据、加密数据或以几乎任何其他方式对其进行破坏。

# 漏洞 (Vuln)

“vulnerability”（漏洞）的缩写。另一种指代可能被黑客利用的 Bug 或软件缺陷的表达方式。

# 盗版 (Warez)

发音类似于“where is”的缩写，Warez 指的是通常通过 BitTorrent 和 Usenet 等技术分发的盗版软件。Warez 有时充斥恶意软件，利用人们对免费软件的渴望。

# 白帽 (White Hat)

白帽黑客是指以修复和保护系统为目标进行黑客的人。与黑帽黑客（如前所示）不同，他们不是利用发现的攻击或 Bug 非法获利，而是提醒公司甚至修复这些问题。

# 蠕虫 (Worm)

一种特殊的恶意软件，能够自我传播和复制，从计算机扩散到计算机。互联网的历史充满了蠕虫，从第一种此类病毒的莫里斯蠕虫，到著名的 Samy 蠕虫。

# 零日漏洞 (Zero-Day)

零日漏洞是指软件供应商尚未知的漏洞。它是黑客可能利用的 Bug 或软件缺陷的另一种表达方式。
