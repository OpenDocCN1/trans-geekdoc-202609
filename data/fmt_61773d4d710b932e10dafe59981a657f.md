
$$ \rho(f) = E_{p(y|x)}[L(y, f(x))] = \sum_y L[y, f(x)] p(y|x) = \int L[y, f(x)] p(y|x) dy \tag{5.28} $$

因此，贝叶斯估计量，也称为贝叶斯决策规则，由下式给出：

$$ \delta(x) = \arg \min_f \rho(f) \tag{5.29} $$

$$ \rho(f) = \int L[y, f(x)] p(y|x) dy = \int [y - f(x)]^2 p(y|x) dy \tag{5.30} $$

$$ = \int [y^2 - 2y f(x) + f(x)^2] p(y|x) dy $$

因此，最优估计是后验均值：

$$ \frac{\partial \rho}{\partial f} = \int [-2y + 2f(x)] p(y|x) dy = 0 $$

$$ \int y p(y|x) dy = \int f(x) p(y|x) dy $$

$$ f(x) \int p(y|x) dy = E_{p(y|x)}[y] $$

$$ f(x) = E_{p(y|x)}[y] \tag{5.31} $$

这通常称为最小均方误差估计或 `MMSE` 估计。

# 线性回归

### 7.1 简介

线性回归是统计学和（监督）机器学习的主力模型。当结合基函数或其他形式的基函数扩展时，它还可以建模非线性关系。此外，当高斯输出被伯努利或多努利分布替代时，它可用于分类，正如我们将在下文看到的。因此，详细研究这一模型大有裨益。

### 7.2 表示

```
p(y|x, θ) = N(y | w^T x, σ²)
```

(7.1)

其中 `w` 和 `x` 是增广向量，`x = (1, x)`，`w = (b, w)`。通过用输入的某个非线性函数 `ϕ(x)` 替换 `x`，线性回归可以用于建模非线性关系：

```
p(y|x, θ) = N(y | w^T ϕ(x), σ²)
```

(7.2)

这被称为基函数扩展。（注意模型在参数 `w` 上仍然是线性的，因此仍称为线性回归；其意义将在下文变得清晰。）一个简单的例子是多项式基函数，此时模型形式为：

```

```

(7.3)

我们不最大化对数似然，而是等价地最小化负对数似然或 `NLL`：

```
NLL(θ) = −ℓ(θ) = −log p(D|θ)
```

(7.4)

`NLL` 形式有时更方便，因为许多优化软件包旨在寻找函数的最小值而非最大值。现在让我们将 `MLE` 方法应用于线性回归设定。将高斯定义代入上式，可得对数似然为：

```

```

(7.5)

```

```

(7.6)

`RSS` 代表残差平方和，定义为：


(7.7)

我们看到 `w` 的 `MLE` 是使 `RSS` 最小化的那个，因此该方法称为最小二乘法。

(7.8)

最小化 `NLL(w)` 有两种方法。

`ML` 估计的一个问题是它可能导致过拟合。在本节中，我们讨论一种通过使用带有高斯先验的 `MAP` 估计来改善此问题的方法。

#### 7.4.1 基本思想

我们可以通过使用零均值高斯先验来敦促参数变小，从而产生更平滑的曲线：

```
p(w) = ∏ N(wⱼ | 0, τ²)
      j
```

其中 `1/τ²` 控制先验的强度。相应的 `MAP` 估计问题变为

```
arg max ∑ log N(yᵢ | w₀ + wᵀxᵢ, σ²) + ∑ log N(wⱼ | 0, τ²)
      w i=1       j=1
```

在拥有大量数据的领域，简单的方法也能效果很好 (Halevy et al. 2009)。然而，仍然有理由研究更复杂的学习策略，因为总会存在我们只有少量数据的问题。例如，即使在网络搜索这样数据丰富的领域，当我们需要开始个性化结果时，对于任意给定用户可用的数据量相对于问题的复杂性再次变得很小。

这是一个基本练习，可以证明这等价于最小化以下目标

```
J(w) = (1/Nσ²) ∑ (yᵢ - (w₀ + wᵀxᵢ))² + λ ||w||², λ ≜ 1/τ²
        i=1
```

这里第一项当然是 `MSE`/`NLL`，第二项 `λ ≥ 0` 是一个复杂度惩罚。相应的解由下式给出

```
ŵ_ridge = (λI_D + XᵀX)⁻¹Xᵀy
```

此方法称为岭回归，或惩罚最小二乘法。通常，给模型参数添加高斯先验以敦促它们变小被称为 `ℓ₂` 正则化或权重衰减。请注意，偏移项 `w₀` 未被正则化，因为这只影响函数的高度，而不影响其复杂度。我们将在本书中考虑各种先验。每一种都对应一种不同形式的正则化。此策略广泛用于防止过拟合。
