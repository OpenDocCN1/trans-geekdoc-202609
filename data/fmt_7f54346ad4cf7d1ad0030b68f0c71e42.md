# 17.1. 删除 Cookie 并注销用户

我们需要添加一个控制器来处理用户注销。这是通过删除用户的会话 Cookie 实现的，这实际上意味着告诉浏览器使其过期。为了保险起见，我们还会更新用户的记忆令牌（remember token），这样即使 Cookie 被留着，它也将不再具有有效的令牌。

```
// atom controllers/users.go
```

```go
// Logout 用于删除用户的会话 Cookie
// 并使他们当前的记忆令牌失效，这将
// 注销当前用户。
// POST /logout
func (u *Users) Logout(w http.ResponseWriter, r *http.Request) {
    // 首先让 cookie 过期
    cookie := http.Cookie{
        Name:    "session_token",
        Value:   "",
        Expires: time.Now(),
        Path:    "/",
    }
    http.SetCookie(w, &cookie)
    // 然后我们更新记忆令牌
    token, err := r.Cookie("remember_token")
    if err == nil {
        u.InvalidRememberToken(token.Value)
    }
    // 最后我们重定向到首页
    http.Redirect(w, r, "/", http.StatusSeeOther)
}
```

最后，我们需要在 `main.go` 中添加路由。

```
$ atom main.go
```

```

让我们从持久化提示的函数开始。

```
$ atom views/data.go
```

```go
import (
  // 添加两个导入
  "net/http"
  "time"
)

type Alert struct {
    Level   string
    Message string
}

func persistAlert(w http.ResponseWriter, alert Alert) {
    // 我们不希望提示在几天后出现。如果用户
    // 希望在 5 分钟后跳转，我们将
    // 让它过期。
    expiresAt := time.Now().Add(5 * time.Minute)
    lvl := http.Cookie{
        Name:    "alert_level",
        Value:   alert.Level,
        Expires: expiresAt,
        HttpOnly: true,
        Path:    "/",
    }
    msg := http.Cookie{
        Name:    "alert_message",
        Value:   alert.Message,
        Expires: expiresAt,
        HttpOnly: true,
        Path:    "/",
    }
    http.SetCookie(w, &lvl)
    http.SetCookie(w, &msg)
}
```

接下来我们需要一种清除这些提示的方法。最简单的方法通常是将过期日期设置为当前时间，这样 Cookie 会立即过期。

```go
func clearAlert(w http.ResponseWriter) {
    lvl := http.Cookie{
        Name:    "alert_level",
        Value:   "",
        Expires: time.Now(),
        HttpOnly: true,
        Path:    "/",
    }
    msg := http.Cookie{
        Name:    "alert_message",
        Value:   "",
        Expires: time.Now(),
        HttpOnly: true,
        Path:    "/",
    }
    http.SetCookie(w, &lvl)
    http.SetCookie(w, &msg)
}
```

最后，我们可能想要能够获取已经持久化的提示，因此我们将为之添加一个函数。

## 17.2. 使用 ALERTS 重定向

```go
func getAlert(r *http.Request) *Alert {
  // 如果 cookie 缺失，我们将认为 alert
  // 是无效的并返回 nil
  lvl, err := r.Cookie("alert_level")
  if err != nil {
    return nil
  }
  msg, err := r.Cookie("alert_message")
  if err != nil {
    return nil
  }
  alert := &Alert{
    Level: lvl.Value,
    Message: msg.Value,
  }
  return alert
}
```

## 重定向函数

为了在带有 alert 的情况下重定向用户，我们需要先持久化 alert，然后重定向用户。与其在控制器中手动输入这些代码，我们将编写一个函数来为我们处理这两个标准步骤。

```go
// Redirect 接收 http.Redirect 的所有标准参数
// 它执行重定向，但只有在提供的 alert 持久化到 cookie
// 之后，这样在加载新页面时就可以显示它。
func RedirectAlert(w http.ResponseWriter, r *http.Request, urlStr string, code int, alert Alert) {
  persistAlert(w, alert)
  http.Redirect(w, r, urlStr, code)
}
```

每当我们想要带有 alert 地重定向用户时，可以调用 `RedirectAlert` 函数，而不是 `http.Redirect` 函数。

```go
alert := views.Alert{
  Level: views.AlertLvlSuccess,
  Message: "Welcome to LensLocked!",
}
views.RedirectAlert(w, r, "/galleries", http.StatusFound, alert)
```
