
自闭症谱系障碍（ASD）是一种基于遗传关联和其他原因导致的社交沟通或感觉-运动功能缺陷[21]。这种遗传关联得到了 Tick 等人对双生胎遗传率数据分析的支持[28]，该分析确定了 ASD 的遗传率范围在 64% 到 91% 之间。Tick 等人还指出遗传学与神经发育障碍之间存在 0.98 的相关性。新发突变进一步表达了遗传继承对 ASD 的影响，因为这些遗传突变特异性地发生在家庭（父亲、母亲和孩子）中干细胞分裂和女性配子成熟的过程中[26]。这些遗传突变基于家庭成员之间发现的突变，从而决定了携带 Tick 等人分析中所示的高遗传率的新发突变[11, 15, 29]。在《临床神经病学手册》[25]中，ASD 的联系与根据染色体位置（位点）和可能的遗传风险之间的遗传连锁所确定的约 1,000 个基因有关。Alarcón 等人[2]对染色体区域 7q 和 17q 进行了全面研究，发现 7q2-35 区域与 ASD 存在强关联性，同时注意到其他区域（如染色体 3q）也可能与 ASD 关联。拷贝数变异（CNV）是添加、删除或复制脱氧核糖核酸（DNA）部分的过程[27]。CNV 显示了位点之间的确切联系。另一种遗传关联是常见变异，它显著影响 ASD。Grove 等人[4]使用了全基因组研究来确定风险。常见变异在大多数疾病中都具有重要意义，因为它们与 90% 的个体差异有关[7]。从个体角度来看，常见变异意义有限，但通过将所有变异整合在一起，我们可以确定风险[3]。常见变异在评估 ASD 时占了风险因素的 40%-60%[17]。在所有变异和遗传突变之间，我们看到这些突变在网络中连接。Kolchan 等人将基因网络描述为以协调方式的一的一基因[10]。可见，常见变异、新发变异和 CNV 都是基因协同作用的产物，这种功能产生了具有高 ASD 风险的变异。这些变异结合形成了一个连接整体的基因网络，向我们展示了基因的关联或非关联性[24]。我们提出的实验使用这些基因网络和图神经网络来确定基因是否与 ASD 相关。我们使用的特定图神经网络模型是`GraphSAGE`和`GCN`[13, 16]。在该实验中，我们将根据基因与自闭症风险相关的概率来确定基因是否与 ASD 相关。

本章描述了发现自闭症风险基因的方法和模型。7.2 节包含了自闭症风险分类现状的文献综述。预处理和模型结构见 7.3 节。7.4 节概述了为了测试模型而进行的实验。7.6 节在自闭症风险分类的背景下讨论了结果。我们在 7.7 节进行总结，重申本项研究的重要发现和意义。

## 7.2 相关工作

该领域的最先进技术包含多种方法。

### 全基因组关联研究 (GWAS)

这是一种用于寻找与特定疾病或性状相关的遗传变异的方法。它通过比较患有该疾病或性状的人的 DNA 与不患有该疾病或性状的人的 DNA 来实现。Bralten 等 [6] 使用`GWAS`发现了自闭症谱系障碍（ASD）之间的遗传共享与“儿童行为”、“刻板行为”和“关注细节”等自闭症特征之间的联系。Grove 等 [4] 利用该技术发现了五个与自闭症风险相关的全基因组显著位点。

### 基于网络的机器学习 (NBML)

NBML 是一种机器学习方法，它利用基因网络的拓扑结构来预测自闭症风险。NBML 模型学习网络中基因之间的关系，并利用这些信息预测哪些基因对自闭症风险重要。这种方法的背后逻辑是：赋予 ASD 风险的基因可能在功能上是相关的，因此它们会汇聚到涉及疾病的分子网络和生物通路中 [9]。进一步，Krumm 等 [18] 显示，具有新发突变的 ASD 基因汇聚在与染色质重塑和突触功能相关的通路上。后的一些研究表明，使用蛋白质-蛋白质相互作用（PPI）网络整合已知风险基因，可以识别参与 ASD 的新基因 [14, 20]。在机器学习中，许多技术已用于通过基因网络预测疾病、ASD 风险评估以及整体疾病风险发现。首先是 Fenq 等在 PPI 网络中进行的相互作用发现，他们发现利用组学数据可以确定这些相互作用网络中的新连接 [8]。Wang 等 [31] 使用基于注意力的图神经网络根据脑部扫描中的活动来识别 ASD。Beyreli 等 [5] 创建了`DeepND`，这是一个多任务 GCN，它使用自闭症网络和智力障碍网络来确定两者的风险。Uddin 和 Lu [22] 使用图神经网络和患者网络来分类患者是否患有慢性疾病。Wang 和 Avillach [30] 使用`DeepAutism`，这是一种根据高风险基因变异的存在诊断 ASD 的卷积网络。Motsinger 同事 [23] 使用基因-基因相互作用网络和神经网络来分类人们携带的帕金森病风险。Laksshman 等创建了`deep bipolar`，专门识别基因突变以确定某人是否有双相情感障碍 [19]。

## 7.3 方法

### 7.3.1 数据集

这些实验使用的数据集是 Sfari 数据集 [1] 以及蛋白质相互作用网络 (PIN) 数据 [24]。Sfari 数据集包含了我们所有数据集的基因关联和排名。这些排名遵循多个参数，基因与 ASD 关联的置信度范围为 1-3（1 代表显著相关，3 代表轻微相关）。Sfari 数据集还包含该特定基因的染色体带位置。PIN 数据集包含了所有与 ASD 相关和不相关的 PPI。关联性根据该基因是否在 Sfari 数据上有评分来确定。1 到 3 之间的任何值都被认为与 ASD 相关，而任何其他基因被认为没有关联。

### 7.3.2 预处理

第一个预处理步骤是过滤掉 PIN 数据集中所有未指定为人类基因相互作用的内容。接下来，我们添加了排名和染色体带。

GraphSAGE 几乎是相反的方法；相反，我们对网络中所有邻居节点进行聚合。GraphSAGE 背后的过程是一个归纳框架，利用邻居方法来导出节点特征。GraphSAGE 操作定义在公式 (7.3) 中，其中`l`：GraphSAGE 操作的层。`h[v]^((l))`：第`l`层中节点`v`的特征向量。`N(v)`：节点`v`的邻居节点集。`W^((l))`：第`l`权重矩阵。`AGGREGATE`：聚合函数（例如平均、求和或基于 LSTM 的聚合）。`σ`：激活函数（例如`ReLU`）：

```
(7.3)h[v]^((l+1)) = \sigma(W^((l)) \cdot AGGREGATE(h[u]^((l)), \forall u \in N(v)))
```

本次实验采用了均值聚合以减少结果的复杂性。将聚合后的特征拼接在一起，为特征矩阵中的每个节点创建新特征。该模型推断邻居节点之间的连接。这种连接创建了另一种方法，但它是解释图网络的重要方法。它没有使用像 GCN 那种宽泛的视角，而是采用邻居方法，从而推断不仅是当前节点与其邻居节点之间的特征关系连接。

### 7.3.4 评估技术

实验通过特异性（Specificity）、灵敏度（Sensitivity）、ROC 曲线下面积（AUC）和准确率（Accuracy）进行。这样做是为了衡量我们的准确性并量化假阳性和假阴性。通过减少假阳性和假阴性，我们可以得出一个更精确的基因列表，在减少误诊数量的同时，捕捉到之前未被检测到的诊断。在这里，我们进一步详细阐述这些指标。

#### 7.3.4.1 特异性

特异性是二分类问题中真负性预测与实际负性实例总数之比。它量化了模型正确识别不属于正类的实例的能力。高特异性表明模型的假阳性错误率低，有效区分负性实例和正性实例。

在数学上，特异性可以定义为：

```
Specificity = true_negatives / (true_negatives + false_positives)
```

#### 7.3.4.2 灵敏度

灵敏度是二分类问题中真正性预测与实际正性实例总数之比。它量化了模型捕捉并正确识别属于正类的实例的能力。高灵敏度表明模型能够有效识别正性实例，且假阴性错误率较低。

在数学上，灵敏度可以定义为：

```
Sensitivity = true_positives / (true_positives + false_negatives)
```

#### 7.3.4.3 ROC 曲线下面积

AUC 是一个标量值，代表接收者工作特征（ROC）曲线下的面积，ROC 曲线是一种说明二分类模型在不同概率阈值下性能的图表。ROC 曲线通过在不同阈值下绘制真正性率（灵敏度）相对于假阳性率（1 – 特异性）来创建。

AUC 范围从 0 到 1，其中：

* `AUC = 0` 表示模型的预测完全错误。
* `AUC = 1` 表示模型的预测是完美的。

较高的 AUC 值表示模型具有更好的判别能力，意味着它更有能力区分正类和负类。换句话说，它衡量了模型根据预测概率将正性实例排名高于负性实例的能力。

一个没有判别能力的随机二分类模型 AUC 为 0.5，这等同于随机产生的预期性能。

#### 7.3.4.4 准确率

准确率是分类问题中正确预测的实例与实例总数之比。它衡量了模型预测的整体正确性。较高的准确率表示模型正在做出更多正确的预测，而较低的准确率则表明模型正在做出更多的错误预测。

在数学上，准确率可以定义为：

```
Accuracy = correctly_predicted_instances / total_instances
```

#### 7.3.4.5 消融实验

为了测试图结构是否提供相关信息的假设，我们使用了一个基模型。该模型仅使用染色体位置。为了测试染色体带特征是否有助于自闭症风险的假设，我们测试了带有和不带特征的图神经网络的性能。
