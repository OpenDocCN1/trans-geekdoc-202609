
# 天体粒子物理实验中的数据摘要与自编码器

天体粒子物理实验自然地处理多年连续观测测量的大量数据。随着时间的推移，测量会受到自然概念漂移的影响，例如传感器损坏、环境变化或望远镜操作模式的变化。因此，必须密切监控健康状态和实际观测，以便尽早发现变化和有趣的事件。

虽然存在许多概念漂移检测机制，但它们无法通过表征发生的概念漂移类型等方式直接向操作员提供反馈。可视化大量数据和可能的概念漂移的一种方法是向人工操作员提供一份小而全面的测量摘要。这样，操作员可以通过查看数据摘要与数据交互，并直接推断数据或探测器中可能发生的变化。

亚模优化已成为机器学习和数据挖掘中的宝贵工具。亚模函数奖励向较小集合添加新元素的程度高于向较大集合添加同一元素的程度。这使它们成为解决数据摘要任务的理想选择，在这些任务中，亚模集合函数 `f` 为摘要 `S` 分配一个效用分数 `f(S)`。然后，利用亚模最大化，可以选择最优摘要。为数据摘要设计的亚模函数利用两个观测值 `x[i]` 和 `x[j]` 之间的距离概念。不幸的是，随着维度的增加，距离度量会失去其表达力，因此随着维度数量的增加，通过亚模优化进行数据摘要变得越来越困难 [[82]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_082)。

规避这一问题的一种方法是将高维数据嵌入到低维嵌入空间中。为此，我们可以使用一种称为自编码器的专用深度学习架构（参见第 9 章），它由两部分组成，即编码器和解码器。编码器尝试将数据编码到低维空间，而解码器尝试从编码器的输出中重构原始数据。这两部分以端到端的方式联合训练，以便编码器尝试将关于数据的大部分信息编码到低维空间中。相比之下，解码器尝试尽可能多地重构原始数据（参见 [[183]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_183)，第 14 章）。自编码器及其变体已被广泛研究，在嵌入任务中取得了巨大的实际成功。不幸的是，虽然自编码器表现良好，但无法保证嵌入空间保留与原始数据空间相同的相似性概念。简单来说，无法保证在原始空间中接近的对象在嵌入空间中仍然彼此接近，这使得它们难以与数据摘要技术一起使用。

在本节中，我们将讨论如何应用自编码器进行后续的数据摘要。首先，我们在下一节介绍亚模函数的框架。然后，我们一般性地讨论自编码器及其在聚类分析相关任务中的应用。从这些聚类自编码器中，我们推导出专门针对数据摘要任务的亚模自编码器。最后，我们展示 FACT 数据的实验摘要并结束本节。

## 7.4.2 亚模函数数据摘要

亚模优化提供了一个成熟的数学框架，可在线性时间内为各种任务选择小而全面的摘要。形式上，我们考虑从基础集 `V` 中选择 `K` 个代表性元素到摘要集 `S ⊆ V` 中的问题。为此，我们最大化一个非负、单调的亚模集合函数 `f : 2^V → ℝ[+]`，该函数为每个子集分配一个效用分数：

```
f(S) = max_{S ⊆ V, |S| ≤ K} f(S)
```

对于空集，我们假设效用为零 `f(∅) = 0`。我们用 `OPT = f(S*)` 表示 `f` 的最大值。集合函数可以与边际增益相关联，边际增益表示将元素 `x ∈ V` 添加到 `S` 时 `f(S)` 的增加量：

```
Δf(x | S) = f(S ∪ {x}) - f(S)
```

当且仅当对于所有 `A ⊆ B ⊆ V` 都成立以下条件时，我们称 `f` 为亚模：

(7.10) `Δf(x | A) ≥ Δf(x | B)`

当且仅当对于所有 `x ∈ V` 和所有 `S ⊆ V` 都成立 `Δf(x | S) ≥ 0` 时，函数 `f` 称为单调。一般来说，亚模集合函数的最大化是 NP-hard [[160]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_160) 的，这使得求解公式 7.8 变得困难。因此，一种自然的方法是寻找近似解。Nemhauser 等人在 [[164]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_164) 中提出了一种简单的 `(1 − (1/exp(1))) ≈ 63%` 贪心近似算法，称为 Greedy，用于求解公式 7.8，该算法在线性时间内运行并需要固定的内存预算。Greedy 提供了一个常数近似保证，且仅需要 `𝒪(K)` 内存。顾名思义，它以贪心方式工作。从空摘要开始，它计算基础集中每个元素的边际增益 `Δf`，并选择增益最大的那个。此过程重复 `K` 次，直到摘要填满。该算法如算法 7.1 所示。

**算法 7.1：** 贪心算法。

```
1 S ← ∅
2 for 1, ..., K do
3     x = arg max{Δf(x | S) | x ∈ V}
4     S ← S ∪ {x}
5 end
6 return S
```

贪心算法的缺点在于它需要对整个数据集进行 `K` 次迭代，如果基础集合非常大，这将耗费巨大。相比之下，子模块流式最大化算法（概述请参见第 1 卷中的 3.1 节）仅检查数据集中的每个项目一次，并即时决定是否应将新项目添加到摘要中，将总运行时间从 `𝒪(NK)` 降低到 `𝒪(N)`。作为一个例子，请考虑第 1 卷 3.1 节 中介绍的 ThreeSieves 算法。该算法的主要思想是，如果我们将整个数据集的 `K` 个副本堆叠在一起并逐个处理，就可以模拟贪心算法。如果我们预先知道摘要中每个项目的增益（即贪心算法将选择的元素的增益），那么我们就可以检查堆叠数据集中的每个项目，并将其与最优增益进行比较，以决定是否应将其添加到摘要中。当然，预先知道确切的增益是不可能的，事实上，这正是我们想要解决的问题的一部分。子模块性允许我们估计最优增益应位于区间 `[m, K · m]` 内，其中 `m = max_{x∈V} f({x})` 是最大单例元素。给定这个区间，我们可以从中采样不同的阈值到集合 `O` 中，并希望其中一个阈值足够接近真实增益。现在的问题变成了从这个集合 `O` 中选择哪个阈值来比较各个增益。请注意，如果阈值太大，我们将永远不会选择任何项目；如果太小，我们将很快用次优项目填满摘要。正如所述，我们无法绝对确定地判断给定阈值是否被超越。然而，我们可以以高概率做到这一点。

更正式地说，我们旨在估计对于给定摘要 `S` 和函数 `f`，找到一个增益超过 `v` 的项目 `x` 的概率 `p(f | x, S, v)`。一旦 `p` 低于用户定义的确定性边界 `τ`，我们就选择 `O` 中下一个最小的阈值并重复该过程。对 `p(x | f, S, v)` 的估计是直接的，因为我们观察每个项目时，无论它是否超过当前阈值。然而，这种估计本身带有不确定性，因此我们需要估计其置信区间以做出可靠的决策。估计概率的置信区间是统计学中的一个著名问题。假设我们从 `O` 中最大的阈值开始。在这种情况下，大多数项目的增益不会超过阈值，所以我们拒绝该项目。在这种情况下，我们得到一个严重偏态的二项分布，概率接近 0。我们可以使用“三数法则”来估计这类分布的置信区间。它指出，在观察到 `T` 个事件后，`p(x | f, S, v)` 的置信区间为 `⌈0, -ln(α)/T⌉`。例如，以 95% 的确定性，`p(x | f, S, v)` 的置信区间为 `[0, -ln(0.05)/T]`，大约为 `[0, 3/T]`，因此得名“三数法则” [[218]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_218)。我们可以利用三数法则量化这样的确定性：以高概率，在观察到 `T` 个项目后，数据流中不会出现新项目。一旦 ThreeSieves 以足够的可信度确定当前阈值不太可能被超越，它就会选择下一个最小的阈值并继续估计。完整算法如算法 7.2 所示。

**算法 7.2：** ThreeSieves 算法。

```
1 O ← {v_1, ..., v_M}  // 阈值集合
2 v ← max(O)
3 S ← ∅; t ← 0
4 for next item x do
5     if Δ_f(x | S) ≥ (v/2 - f(S)) / (K - |S|) and |S| < K then
6         S ← S ∪ {x}; t ← 0
7     else
8         t ← t + 1
9         if t ≥ -ln(α) / v then
10            v ← max(O); O ← O \ {max(O)}; t ← 0
11        end
12    end
13 end
14 return S
```

(7.11) `k(x_i, x_j) = exp(-1/(2l^2) * ||x_i - x_j||_2^2)`  (7.11)

其中 `l ∈ ℝ` 是一个缩放常数，`||·||_2` 表示欧几里得范数。核函数生成核矩阵 `Σ[S] = [k(x_i, x_j)]_ij`，其中包含 `S` 中所有点的所有相似度对。该矩阵在对角线上具有最大值，因为项目与自身最相似。相比之下，非对角线上的值表示不同元素之间的相似度，因此通常较小。由于我们寻求一个全面的摘要，我们对 `Σ[S]` 非对角线上值接近 0 的那些对更感兴趣。这种直觉已在信息向量机（IVM）[[197]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_197) 的背景下得到形式化处理。IVM 是一种高斯过程（GP）[[322]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_322)，它贪婪地选择数据点的一个子集并跟踪 GP 的后验分布。基于多样性论证，作者提出迭代地选择最能覆盖训练数据的点。这种直觉可以形式化为最大化核矩阵的对数行列式：

`f(S) = 1/2 log det(I + a Σ_S)`  (7.12)

其中 `a ∈ ℝ[+]` 是用于数值稳健性的缩放参数，`I` 是 `K × K` 单位矩阵。

在文献 [[345]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_345) 中，该函数被证明是子模块的。其函数值不依赖于 `V`，而仅依赖于核函数 `k` 的选择和摘要大小 `K`。这使其成为流式设置下数据摘要的理想候选者。在文献 [[108]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_108) 中，证明了 `m = max_{x∈V} f({x}) = 1 + aK` 且对于满足 `k(·,·) ≤ 1` 的核，`OPT ≤ K log(1 + a)`。通过归一化 [[185]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_185)，这一性质可被强制应用于每一个正定核。

## 7.4.3 使用自编码器进行降维

### 子模自编码器

子模函数为选择精心挑选的数据摘要提供了一个极佳的框架。公式 7.12 中的对数行列式是一个子模函数，它侧重于一组多样化的候选项，使其成为监控任务的理想选择。然而，该函数需要使用一个必须适合当前任务的相似度核。虽然子模函数保证了摘要问题在数学上合理的解，但核编码了项目之间的相似度，因此决定了数据摘要在实践中有多大价值。

针对不同应用场景的不同核函数已在文献中得到广泛研究。然而，对于图像或时间序列等高维、非结构化数据，它们有时会产生次优结果。在这些情况下，基于深度学习的方法通常表现出更好的效果。最近，结合这两种方法的方式也已被成功探索 [[219]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_219), [[236]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_236)。结合这两种方法的一种途径是，首先通过深度自编码器将原始数据投影到一个低维的 `embedding`（嵌入）空间，然后将这些嵌入作为核的输入来计算实际相似度。这样，嵌入可能能够捕捉数据点之间的高层交互，而核则提供了一种数学上可证明的表达相似度的方式。自编码器是一种特殊的神经网络架构，旨在将输入编码为压缩的 `embedding`，然后用该嵌入来解码重构原始输入。图 7.7 给出了自编码器通用结构的概览，其中 `w ≪ r` 为嵌入大小，`r` 为原始数据的维度。形式上，我们联合训练编码器 `e: ℝ^r → ℝ^w` 和解码器 `d: ℝ^w → ℝ^r`，使得重构损失 `ℓ: ℝ^r × ℝ^r → ℝ` 最小化：

(7.13) `L(e,d) = (1/N) Σ_{i=1}^N ℓ(x_i, d(e(x_i)))`  (7.13)

其中 `x_1, x_2, ..., x_N` 是从数据分布 `D` 中抽取的样本。在实践中，`e` 是期望的编码架构，通常 `d` 以相反的顺序镜像 `e`。两者通过随机梯度下降联合训练。

自编码器是一种简单的无监督方法，可以降低运行时间，并改进后续使用嵌入而非非结构化输入数据的摘要方法的效果。然而，数据摘要中的一个基本假设是相似事件具有相似的特征表示。虽然这对于原始数据可能成立，但对于潜在嵌入空间则不一定成立。换句话说，不能保证相似的观测值位于潜在空间的同一区域，从而拥有相似的嵌入。聚类任务与数据摘要任务密切相关，在聚类任务中我们想要找到数据的簇。两者的主要区别在于：在聚类中，人工质心代表一簇数据；而在数据摘要中，报告的是实际的观测值。这使得数据摘要更具挑战性，因为我们不能像在聚类中那样自由优化质心来改进摘要。然而，我们仍然可以从聚类嵌入中借鉴一些见解，用于我们期望的摘要嵌入。

![Fig. 7.7: An overview of the autoencoder architecture. The encoder e receives the original data as an input and embeds it in a lower-dimensional space. Then the decoder d uses this embedding to reconstruct the original input.](img/b_9783110785968-007_fig_007.png)

**图 7.7：** 自编码器架构概览。编码器 `e` 接收原始数据作为输入并将其嵌入到低维空间中。然后解码器 `d` 利用该嵌入来重构原始输入。

聚类嵌入是专门为后续聚类分析而训练的嵌入 [[394]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_394)。主要思想是：一旦具有足够重构能力的自编码器训练完成，我们就可以对其进行细化以用于聚类分析。对于聚类而言，一个点到簇质心的距离大致服从学生 t 分布可能是理想的，即一个质心非常近，而其他质心很远 [[376]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_376)。给定质心的初始猜测 `S = {μ_j | j = 1, ..., K}`，文献 [[394]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_394) 的作者使用软簇分配，并测量嵌入点 `e(x) = z ∈ ℝ^w` 与质心 `μ ∈ ℝ^w` 之间的距离：

(7.14) `q(z, μ) = (1 + ||z - μ||²/α)^{-(α+1)/2} / Σ_{i=1}^K (1 + ||z - μ_i||²/α)^{-(α+1)/2}`  (7.14)

此处 `α` 是学生 t 分布的自由度，`q(z, μ)` 可解释为将样本 `x` 分配给簇 `μ` 的概率。给定这些分配，作者提出最小化这些分配与目标学生 t 分布 `p` 之间的 KL 散度：

(7.15) `KL(P(S,e) || Q(S,e)) = Σ_{i=1}^N Σ_{j=1}^K p(z_i, μ_j) log(p(z_i, μ_j) / q(z_i, μ_j))`  (7.15)

其中 `S` 是选定簇的集合，`p(z_i, μ_j)` 由下式给出：

```
p(z_i, μ_j) = (q(z_i, μ_j)² / c_i) / Σ_{k=1}^K q(z_i, μ_k)² / c_k, with c_j = Σ_{i=1}^N q(z_i, μ_j)
c(x) = argmin_{μ ∈ S} ||x - μ||_2²
```

为距离 `x` 最近的簇中心。聚类嵌入遵循三步过程：

(7.17) `e, d = argmin_{e,d} L(e,d)`  (7.17)
(7.18) `S = argmin_{S ⊆ ℝ^w, |S|=K} Σ_{j=1}^N ||x - μ_{c(x)}||_2²`  (7.18)
(7.19) `e, S = argmin_{e,S} KL(P(S,e) || Q(S,e))`  (7.19)

在第一个优化步骤中，通过随机梯度下降训练编码器/解码器对。然后，获得 k-means 聚类（例如通过 Lloyd 算法 [[253]](#9783110785951_034588.xhtml#b_9783110785968-011_ref_253)）。最后，再次通过随机梯度下降细化编码器。注意，在初始编码器/解码器对训练完成后，解码器*不再*改变。

## 7.4.4 子模自编码器

聚类嵌入在已经存在一个优秀的自编码器且仅需对其进行细化以用于后续聚类分析的情况下效果很好。然而，它们有四个独立的缺点，我们现在将详细解决这些问题。

### 选择有意义的代表元

最后优化步骤中对 `S` 和 `e` 的联合优化可能导致聚类中心与数据分布中的实际测量值不对应。换句话说，`μ_k` 可能是优化步骤（例如 k-means 中的平均操作）的结果——一旦解码，这在原始数据分布中永远不会出现。数据摘要提供了一种从数据集中选择有意义代表元的方法，这自然避免了这一问题。初始聚类分配可以直接由数据摘要算法（如通过贪心算法最大化子模函数）来替代。在这种情况下，最后的优化步骤不应改变选定的质心，从而得到：
