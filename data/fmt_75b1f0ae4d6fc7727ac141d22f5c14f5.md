
分别对应这两种情况。图 3.4A 和 B 展示了恢复的平面。观察可知，在图 3.4A 的情况下，对应于方差较小的噪声变量，所得平面比图 3.4B 更贴近数据点。

### 备注 3.1

*   点集 $(\hat{y}[n], x[n1], \dots, x[nl])$，$n = 1, 2, \dots, N$，位于 $\mathbb{R}^{l+1}$ 空间中的一个*超平面*上。等价地说，它们位于一个穿过原点的超平面上，因此，正如之前所解释的，当将 $\theta[0]$ 吸收进 $\boldsymbol{\theta}$ 时，它在扩展空间 $\mathbb{R}^{l+2}$ 中是一个线性子空间。
*   请注意，即使真实系统结构不遵循公式 (3.9) 中的线性模型，公式 (3.11) 中的预测模型仍可使用。例如，$y$ 和 $\mathbf{x}$ 之间的真实依赖关系可能是非线性的。在这种情况下，基于公式 (3.11) 模型对 $y$ 的预测可能并不令人满意。这完全取决于我们采用的模型与生成数据的真实系统结构之间的偏差程度。
*   模型的预测性能还取决于噪声变量的统计特性。这是一个重要问题。稍后我们将看到，取决于噪声变量的统计特性，某些损失函数和方法可能比其他方法更合适。
*   前两条备注表明，为了量化估计器的性能，需要一些相关准则。在第 3.9 节中，我们将介绍一些理论分析，以阐明与估计器性能相关的某些方面。

## 3.4 分类

### 分类

**分类** 是预测对象（称为 **模式**）所属类别的任务。假设模式仅属于若干先验已知类别中的一个且仅属于一个。每个模式由一组值唯一表示，称为 **特征**。设计分类系统的早期阶段之一是选择一组合适的特征变量。这些变量应尽可能多地“编码”类别判别信息，以便通过测量给定模式的这些值，我们能以足够高的概率预测该模式的类别。为每个问题选择合适的特征集并非易事，它构成了 **模式识别** 领域中最重要的领域之一（参见例如 [12, 37]）。

选定 `l` 个特征（随机）变量 `x[1], x[2], …, x[l]` 后，我们将它们堆叠为所谓的 **特征向量** `x ∈ ℝ^(l)` 的分量。目标是设计一个 **分类器**，例如一个函数^8。

### 数学表述

为了用数学术语表述该任务，每个类别由 **类别标签** 变量 `y` 表示。对于简单的二分类任务，根据类别不同，它可以取两个值中的任意一个（例如 `1, -1` 或 `1, 0` 等）。然后，给定对应于特定模式的 `x` 值，根据以下规则预测其类别标签：

```
ŷ = ϕ(f(x))
```

其中 `ϕ(·)` 是一个非线性函数，指示 `x` 位于决策面 `f(x) = 0` 的哪一侧。例如，如果类别标签为 `±1`，则选择非线性函数为符号函数，即 `ϕ(·) = sgn(·)`。现在清楚的是，前一节所述内容可迁移至此，任务变为基于一组训练点 `(y[n], x[n]) ∈ D × ℝ^(l)`，`n = 1, 2, …, N` 来估计函数 `f(·)`，其中 `D` 表示 `y` 所在的离散集合。函数 `f(·)` 被选定为属于特定参数函数类 `ℱ`，目标再次是估计参数，使得根据预选准则，真实类别标签 `y[n]` 与预测标签 `ŷ[n]` 之间的偏差最小。那么，分类与回归任务有何不同？

### 分类与回归

上一问题的答案是：尽管它们可能有一些相似之处，但两者是不同的。注意，在分类任务中，因变量具有 **离散** 性质，这与回归中因变量位于一个区间内形成对比。这表明，通常必须采用不同的技术来优化参数。例如，分类任务中准则最明显的选择是错误概率。然而，在许多情况下，可以使用同类损失函数来处理这两个任务，正如我们在本节中将要做的那样；即使采用这种方法，尽管它们在数学形式上有相似性，但这两个任务的目标仍然不同。

### 分类与回归（对比）

在回归任务中，函数 `f(·)` 必须“解释”数据生成机制。`(y, x)` 空间 `ℝ^(l+1)` 中对应的曲面应当形成形状，以尽可能紧密地跟随数据在空间中的分布。相反，在分类中，目标是在 `ℝ^l` 中放置对应的曲面 `f(x) = 0`，以尽可能将属于不同类别的数据分开。分类器的目标是将特征向量所在的空间*划分*为若干区域，并将每个区域与一个类别关联。图 3.5 展示了分类任务的两种情况。第一种是两个线性可分类别的示例，其中一条直线可以将两个类别分开；第二种情况是两个非线性可分类别的示例，此时使用线性分类器将无法将两个类别分开。

![图 3.5 两类分类任务示例。(A) 线性可分分类任务。(B) 非线性可分分类任务。分类器的目标是将空间划分为区域并将每个区域与一个类别关联。](img/gr005.jpg)

### 设计线性分类器

现在让我们使上述论述更加具体。我们得到一组训练模式，`x[n] ∈ ℝ^l`，`n = 1, 2, …, N`，它们属于两个类别中的任意一个，假设为 `ω[1]` 和 `ω[2]`。目标是设计一个超平面：

```
f(x) = θ[0] + θ[1]x[1] + ⋯ + θ[l]x[l] = θ^(T)x = 0,
```

其中我们已将偏置 `θ[0]` 吸收进 `θ` 中，并按前述方式扩展了 `x` 的维度。我们的目标是将该超平面置于两个类别之间。显然，位于该超平面上的任意点得分为零，即 `f(x) = 0`；而位于超平面两侧的点得分则为正值（`f(x) > 0`）或负值（`f(x) < 0`），具体取决于它们位于超平面的哪一侧。因此，我们应训练分类器，使得来自某一类别的点得分为正值，而来自另一类别的点得分为负值。例如，可通过将类别 `ω[1]` 中的所有点标记为 `y[n] = 1`，`∀n : x[n] ∈ ω[1]`，将类别 `ω[2]` 中的所有点标记为 `y[n] = −1`，`∀n : x[n] ∈ ω[2]` 来实现。随后引入平方误差来计算 `θ` 以最小化代价，即：

```
J(θ) = ∑_{n=1}^{N} (y_n - θ^T x_n)².
```

其解与公式 (3.13) 完全相同。图 3.6 展示了两种数据情况下的 LS 分类器结果。观察可知，在图 3.6B 的情况下，得到的分类器无法正确分类所有数据点。我们希望将源自某一类别的所有数据置于一侧、其余数据置于另一侧的愿望无法得到满足。LS 分类器所能做的仅是放置超平面，使得期望（真实）标签值 `y[n]` 与预测输出值 `θ^T x[n]` 之间的平方误差之和最小。主要正是针对重叠类别这类在实践中常遇到的情况，人们才不得不寻找平方误差准则和方法的替代方案，以更好地服务于分类任务的需求与目标。例如，一个合理的最优性准则是将错误概率最小化，即真实标签 `y[n]` 与分类器预测标签 `ŷ[n]` 不同的点所占的百分比。第 7 章介绍了适用于分类任务的方法与损失函数。第 11 章讨论了支持向量机，第 18 章和第 19 章则介绍了神经网络与深度学习方法。这些目前均属于解决分类问题最强大的技术之一。

### 生成式学习与判别式学习

我们为引入分类任务所采取的路径，是考虑输出变量（标签）`y` 与输入变量（特征）`x` 之间的函数依赖关系。相关参数是针对代价函数进行优化的。这种建模路径也被称为*判别式学习*。我们并不关心将这两组变量联系在一起的依赖关系的统计本质。在更一般的设定中，判别式学习一词也用于涵盖那些直接对给定特征向量 `x` 的类别后验概率（由其标签 `y` 表示）建模的方法，即 `P(y|x)`。所有这些方法的共同特点是，它们绕过了显式建模输入数据分布的必要性。从统计学角度来看，判别式学习的合理性如下。

利用概率乘法法则，输入数据及其相应标签之间的联合分布可以写为

`p(y, x) = P(y|x)p(x)`。

在判别式学习中，仅考虑乘积中的第一项；采用一种函数形式并将其适当参数化为 `P(y|x; θ)`。然后通过优化代价函数来估计参数。输入数据的分布被忽略。这种方法的优势在于可以使用更简单的模型，特别是当输入数据由形式复杂的联合概率密度函数（PDF）描述时。其劣势在于忽略了输入数据分布，尽管它可能包含重要信息，本可用于提升整体性能。

相比之下，另一种被称为*生成式学习*的路径，则利用输入数据分布。再次利用乘法法则，我们有

`p(y, x) = p(x|y)P(y)`，

其中 `P(y)` 是关于类别的概率，`p(x|y)` 是给定类别标签下的输入分布。采用这种方法，我们最终会得到每个类别对应的一个分布，这些分布需要被学习。在参数化建模中，一组参数与这些条件分布中的每一个相关联。一旦学习了输入-输出联合分布，未知模式 `x` 的类别标签预测就基于后验概率来执行，即

```
P(y|x) = \frac{p(y,x)}{p(x)} = \frac{p(y,x)}{\sum_{y}p(y,x)}.
```

我们将在第 7 章中更详细地回到这些问题。

## 3.5 有偏估计与无偏估计

### 监督学习中的估计器性能分析

在监督学习中，我们获得一组训练点 $(y[n], \mathbf{x}[n])$，$n = 1, 2, \dots, N$，并返回未知参数向量的估计值，记为 $\widehat{\mathbf{\theta}}$。然而，训练点本身是随机变量。如果我们获得同一组随机变量的另一组 $N$ 个观测值，这些值将会不同，显然由此产生的估计值也会不同。换句话说，改变训练数据会导致不同的估计结果。因此，我们可以假设固定但未知参数的估计结果本身是一个随机变量。这进而引出了一个问题：估计器有多好？毫无疑问，每次获得的估计值都相对于采用的损失函数*和*所使用的特定训练集是最优的。然而，谁能保证这些估计值“接近”真实值（假设真实值存在）？在本节中，我们将尝试解决这一任务，并阐明一些相关的理论方面。请注意，我们已经用术语“估计器”代替了“估计值”。在展示更多细节之前，让我们详细阐述一下它们的区别。

#### 估计值与估计器

估计值（如 $\widehat{\mathbf{\theta}}$）具有特定的数值，它是函数作用于一组观测值的结果，我们选择的估计值依赖于这些观测值（参见公式 (3.17)）。一般来说，我们可以推广公式 (3.17) 并写为：

```
\widehat{\mathbf{\theta}} = g(\mathbf{y}, X).
```

然而，一旦我们允许观测值集合随机变化，估计值本身就成为一个随机变量，我们用相应的随机变量重写前面的方程，即：

```
\widehat{\mathbf{\theta}} = g(\mathbf{y}, X),
```

我们将这种函数依赖关系称为未知向量 $\boldsymbol{\theta}$ 的**估计器**。

#### 均方误差（MSE）分析

为了简化分析并专注于方法背后的洞见，我们假设参数空间为实数集 $\mathbb{R}$。我们还假设我们采用的用于建模数据的模型（即函数集 $\mathcal{F}$）是正确的，并且相关真实参数的（未知）值等于 $\theta_o$。

我们采用均方误差（MSE）作为评价标准：

```
\text{MSE} = \mathbb{E} \left[ (\hat{\theta} - \theta_o)² \right], \tag{3.21}
```

其中均值 $\mathbb{E}$ 是针对*所有*大小为 $N$ 的可能训练数据集计算的。如果 MSE 很小，则我们期望平均而言，估计值接近真实值。请注意，虽然 $\theta_o$ 未知，但研究 MSE 如何依赖于各个项仍将帮助我们了解如何在实践中操作，并揭示获得良好估计器的可能途径。

确实，这个简单且“自然”的标准给我们带来了一些有趣的惊喜。让我们将 $\hat{\theta}$ 的均值 $\mathbb{E}[\hat{\theta}]$ 代入公式 (3.21)。我们得到

##### MSE 分解公式

```
\text{MSE} = \mathbb{E}\left\lbrack \left\{ \left( \widehat{\theta} - \mathbb{E}[\widehat{\theta}] \right) + \left( \mathbb{E}[\widehat{\theta}] - \theta_{o} \right) \right\}^{2} \right\rbrack = \underbrace{\mathbb{E}\left\lbrack \left( \widehat{\theta} - \mathbb{E}[\widehat{\theta}] \right)^{2} \right\rbrack}_{\text{Variance}} + \underbrace{\left( \mathbb{E}[\widehat{\theta}] - \theta_{o} \right)^{2}}_{\text{Bias}^{2}}
```

![Equation](img/si125.png)(3.22)

对于第二个等式，我们考虑到两个相关项乘积的均值为零（这很容易验证）。公式 (3.22) 表明 MSE 由两项组成。第一项是围绕均值的方差，第二项源于偏差，即估计量均值与真实值的偏离。

##### 3.5.1 有偏还是无偏估计量？

人们可能天真地认为，选择一个无偏估计量（即 $\mathbb{E}[\widehat{\theta}] = \theta_{o}$），使公式 (3.22) 中的第二项变为零，是一个合理的选择。采用无偏估计量从以下角度看也颇具吸引力。

假设我们有 $L$ 个不同的训练集，每个包含 $N$ 个点。用 $\mathcal{D}_{i}$ 表示每个数据集（$i = 1, 2, \dots, L$）。对每一个数据集，都会得到一个估计值 $\widehat{\theta}_{i}$（$i = 1, 2, \dots, L$）。然后，我们通过取平均值构造一个新的估计量：

```
\widehat{\theta}^{(L)} := \frac{1}{L}\sum_{i=1}^{L}\widehat{\theta}_{i}.
```

![Equation](img/si130.png)

这也是一个无偏估计量，因为

```
\mathbb{E}\left[{\widehat{\theta}}^{(L)}\right] = \frac{1}{L}\sum_{i = 1}^{L}\mathbb{E}\left[{\widehat{\theta}}_{i}\right] = \theta_{o}.
```

![Equation](img/si131.png)

此外，假设所涉及的估计量相互不相关，即

```
\mathbb{E}\left[({\widehat{\theta}}_{i}-\theta_{o})({\widehat{\theta}}_{j}-\theta_{o})\right] = 0,
```

![Equation](img/si132.png)

且具有相同的方差 $\sigma^{2}$。

![Equation](img/si133.png)

新估计量的方差现在小得多（问题 3.2），即

```
\sigma_{{\widehat{\theta}}^{(L)}}^{2} = \mathbb{E} \left[ \left( {\widehat{\theta}}^{(L)} - \theta_{o} \right)^{2} \right] = \frac{\sigma^{2}}{L}.
```

![Equation](img/si134.png)

因此，通过对大量此类无偏估计量进行平均，我们期望得到一个接近真实值的估计。然而，在实践中，数据是一种并不总是丰富的商品。事实上，情况往往恰恰相反，人们必须非常小心地利用它们。在无法负担获取并平均大量估计量的情况下，无偏估计量未必是最佳选择。回到公式 (3.22)，没有理由表明通过使第二项等于零，MSE（毕竟这是我们感兴趣的量）就会变得最小。确实，让我们从一个略微不同的角度来看公式 (3.22)。我们不计算给定估计量的 MSE，而是在公式 (3.22) 中用 $\theta$ 替换 $\widehat{\theta}$，并计算一个直接关于 $\theta$ 使 MSE 最小化的估计量。在这种情况下，专注于无偏估计量，即 $\mathbb{E}[\theta] = \theta_{o}$，

![Equation](img/si135.png)

给使 MSE 最小化的任务引入了一个约束，众所周知，无约束最小化问题产生的损失函数值总是小于或等于其有约束对应问题产生的任何值。

```
\min_{\theta}\text{MSE}(\theta) \leqslant \min_{\theta:\ \mathbb{E}[\theta] = \theta_{o}}\text{MSE}(\theta),
```

其中，公式 (3.23) 中 MSE 对估计量 $\theta$ 的依赖关系被显式地标记出来。
