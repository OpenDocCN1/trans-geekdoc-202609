### B.3 模型训练

#### B.3.1 留出（Holdout）

在开始建模之前的第一步（如果是监督学习），是加载输入数据，留出部分输入数据作为测试数据，将其部分作为训练数据以构建模型。以下是实现此操作的标准方法。Scikit-learn 提供了一个函数将输入数据集划分为训练集和测试集。

```python
import pandas as pd
data = pd.read_csv("btissue.csv")
from sklearn.model_selection import train_test_split
data.shape
(106, 10)
data_train, data_test = train_test_split(data, test_size = 0.3, random_state = 123) # 参数 test_size 将测试数据与输入数据的比例设为 0.3 或 30%，random_state 设置随机数生成器的种子
len(data_train)
74
len(data_test)
32
```

#### 注意

当我们进行数据留出时（即把输入数据划分为训练集和测试集），每个集合所选的记录是随机抽取的。因此，显而易见，执行相同的代码可能会导致不同的训练集。因此，训练出的模型也会有所不同。在 Python Scikit 函数 `train_test_split` 中，参数 `random_state` 设置了内部用于选取记录的随机数生成器的起点。这确保了每次都使用特定序列的随机数，因此每次都会选取相同的记录（即具有相同序列号的记录），并以相同的方式训练模型。这对于结果的可重复性至关重要，即每次运行同一个机器学习程序都会生成同一组结果。

```python
from sklearn.cross_validation import KFold
```

#### 方案 2

```python
from sklearn.model_selection import KFold
```
