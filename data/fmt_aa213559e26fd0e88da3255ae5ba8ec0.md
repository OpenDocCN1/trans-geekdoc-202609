### 4.9.1 高斯-马尔可夫定理

我们现在将注意力转向回归模型中 `θ` 被视为（未知）常数而非随机向量的情况。因此，线性模型现在写为

```
y = Xθ + η
```

而 `y` 的随机性完全归因于 `η`，假设其均值为零，协方差矩阵为 `Σ[η]`。目标是设计一个*无偏线性*估计量来估计 `θ`，使均方误差（MSE）最小化，即

```
θ̂ = Hy
```

并选择 `H` 使得

从公式 (4.94) 和 (4.95) 可得：

```
$\mathbb{E}[\widehat{\mathbf{\theta}}] = H\mathbb{E}[\mathbf{y}] = H\mathbb{E} \left[ (X\mathbf{\theta} + \mathbf{\eta}) \right] = HX\mathbf{\theta}$
```

这意味着无偏约束等价于：

```
*H**X* = *I*
```

利用公式 (4.95)，误差向量变为：

```
$\mathbf{\epsilon} = \mathbf{\theta} - \widehat{\mathbf{\theta}} = \mathbf{\theta} - H\mathbf{y} = \mathbf{\theta} - H(X\mathbf{\theta} + \mathbf{\eta}) = - H\mathbf{\eta}$
```

因此，公式 (4.96) 中的约束最小化问题可重写为：

```
$H_{\ast} = \text{arg}\min\limits_{H}\{\text{trace}\{ H\Sigma_{\eta}H^{T}\},\text{s.t.}\quad HX = I$
```
