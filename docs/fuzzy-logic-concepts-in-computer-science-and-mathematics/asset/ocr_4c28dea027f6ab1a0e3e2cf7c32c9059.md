# #### 9.4.4 TFN

Definition: Triangular Fuzzy Number $A_{TFN} = \{(a, b, c), \mu_{\bar{A}}(x)\}$
*is defined as Triangular Fuzzy Number if it satisfies the following properties:*

+   a. $\mu_{\bar{A}}(x)$ *is zero when* $x \leq a$
b. $\mu_{\bar{A}}(x)$ *is strictly increasing continous function when* $a < x \leq b$
c. $\mu_{\bar{A}}(x)$ *has the maximum value, that is,* 1 *at* $x = b$
d. $\mu_{\bar{A}}(x)$ *is strictly decreasing continous function in* $b < x \leq c$
e. $\mu_{\bar{A}}(x)$ *is again zero when* $x \geq c$

# #### 9.4.5 THE MEMBERSHIP FUNCTION OF A SYMMETRIC AND LINEAR TFN

$\mu_{\bar{A}}(x) = \begin{cases} 0; x \leq a \\ \frac{x - a}{b - a}; a < x \leq b \\ 1; x = b \\ \frac{c - x}{c - b}; b < x \leq c \\ 0; x \geq c \end{cases}$

# #### 9.4.7 ARITHMETIC OPERATIONS OF TFN

Let $E = (e_1, e_2, e_3)$ and $F = (f_1, f_2, f_3)$ be two different TFN.

+   1. *Addition:*
    $(E + F) = (e_1 + f_1, e_2 + f_2, e_3 + f_3)$
2. *Subtraction:*
    $E - F = (e_1 + f_3, e_2 - f_2, e_3 + f_1)$
