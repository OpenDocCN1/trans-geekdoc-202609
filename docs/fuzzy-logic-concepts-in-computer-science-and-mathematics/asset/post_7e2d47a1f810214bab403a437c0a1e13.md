
## 5.2 Preliminaries

**Definition 5.2.1.** The intuitionistic fuzzy threshold hypergraph (IFTHG) is denoted by $\mathbb{H}_G = (U, E; s_1, s_2)$ where,

- 1. $U = \{u_1, u_2, \dots, u_n\}$ is a finite set of intuitionistic fuzzy vertices,
- 2. $E = \{E_1, E_2, \dots, E_m\}$ is a family of crisp subsets of $U$,
- 3. $E_j = \{ (\mu_j^j(u_i), \nu_j^j(u_i)) \mid 0 \le \mu_j^j(u_i) + \nu_j^j(u_i) \le 1 \}, j = 1, 2, \dots, m$
- 4. $E_j \neq \varnothing, j = 1, 2, \dots, m$
- 5. $\bigcup_{j=1}^m E_j = U$
- 6. An independent set $V \subseteq U$ is the set of all different combinations of non-adjacent vertices in $\mathbb{H}_G$ if there exist $s_1$ and $s_2 > 0$ such that $\sum_{u_i \in V} \mu_j^j(u_i) \le s_1$ and $\sum_{u_i \in V}(1 - \nu_j^j(u_i)) \le s_2$

Where the hyperedges of $E_j$ are crisp sets of intuitionistic fuzzy vertices, $\mu_i(u_i)$ and $\nu_i(u_i)$ represent the membership and non-membership degrees of a vertex $u_i$ to a hyperedge $e_j$.

**Definition 5.2.2.** Let $\mathbb{H}_G = (U, E; s_1, s_2)$ be an IFTHG. If an independent set $V \subseteq U$, then the height of $\mathbb{H}_G$ is named as $H_u(\mathbb{H}_G) = \{ \max(\min(\mu_i)), \max(\max(\nu_i)) \}$ for which $\sum_{u_i \in V} \mu_i^j(u_i) \le s_1$ and $\sum_{u_i \in V}(1 - \nu_i^j(u_i)) \le s_2$ for all $i = 1, 2, \dots, m$ and $j = 1, 2, \dots, n$, where $\mu_i^j$ and $\nu_i^j$ are the membership and non-membership values of the $j$-th hyperedge in the $i$-th vertex, respectively.

**Definition 5.2.3.** Let $\mathbb{H}_G = (U, E; s_1, s_2)$ be an IFTHG and an independent set $V \subseteq U$ exist, if $e_j \times e_k \in E$ and $0 < \alpha, \beta < 1$. Then, the $(\alpha, \beta)$-level is defined by $(e_j \times e_k)^{\alpha, \beta} = \{ u_i \mid u_i \in U \mid \min((\mu_i^j)^\alpha(u_i)) \ge \alpha, \max((\nu_i^k)^\beta(u_i)) \le \beta \}$ for which $\sum_{u_i \in V} \mu_j^j(u_i) \le s_1$ and $\sum_{u_i \in V}(1 - \nu_j^j(u_i)) \le s_2$.

**Definition 5.2.4.** Let $\mathbb{H}_G = (U, E; s_1, s_2)$ be an IFTHG, there exists an independent set $V \subseteq U$ such that $\mathbb{H}_G^{(y_i, z_i)} = (U^{(y_i, z_i)}, E^{(y_i, z_i)})$ be the $(y_i, z_i)$-level of $\mathbb{H}_G$. The sequence of real numbers $\{ y_1, y_2, \dots, y_n; z_1, z_2, \dots, z_n \}$ in $0 \le y_i \le H_u(\mathbb{H}_G)$ and $0 \le z_i \le H_v(\mathbb{H}_G)$, satisfying the following conditions:

- 1. If $y_1 < \alpha < 1$ and $0 < \beta < z_1 \Rightarrow E^{\alpha, \beta} = \varnothing$;
- 2. If $y_{i+1} \le \alpha \le y_i; z_i \le \beta \le z_{i+1} \Rightarrow E^{\alpha, \beta} = E^{(y_i, z_i)}$; and
- 3. $E^{(y_i, z_i)} \subset E^{(y_{i+1}, z_{i+1})}$

for which $\sum_{u_i \in V} \mu_i^j(u_i) \le s_1$ and $\sum_{u_i \in V}(1 - \nu_i^j(u_i)) \le s_2$ is known as *fundamental sequence* of $\mathbb{H}_G$ and is represented by $F(\mathbb{H}_G)$.

**Definition 5.2.5.** Let $\mathbb{H}_G = (U, E; s_1, s_2)$ be an IFTHG, also an independent set $V \subseteq U$ exist. Then, the *core set* of $\mathbb{H}_G$ is noted as $C(\mathbb{H}_G)$ for $0 < (y_i, z_i) \le H_u(\mathbb{H}_G)$, and is defined by $C(\mathbb{H}_G) = \{\mathbb{H}_{G}^{(y_1, z_1)}, \mathbb{H}_{G}^{(y_2, z_2)}, \dots, \mathbb{H}_{G}^{(y_n, z_n)}\}$. The corresponding set of $(y_n, z_n)$-level hypergraphs is $\mathbb{H}_{G}^{(y_1, z_1)} \subset \mathbb{H}_{G}^{(y_2, z_2)} \subset \dots \subset \mathbb{H}_{G}^{(y_n, z_n)}$ for which $\sum_{u_i \in V} \mu_y(u_i) \leq s_1$ and $\sum_{u_i \in V}(1 - \nu_y(u_i)) \leq s_2$ called the $\mathbb{H}_G$-induced fundamental sequence and is noted as $I(\mathbb{H}_G)$. The $(y_r, z_r)$-level is said to be a support level of $\mathbb{H}_G$ and the $\mathbb{H}_{G}^{(y_r, z_n)}$ is known as the support of $\mathbb{H}_G$.

**Definition 5.2.6.** Suppose $\mathbb{H}_G = (U, \mathcal{E}, s_1, s_2)$ and $\mathbb{H}_G^{\prime} = (U^{\prime}, \mathcal{E}^{\prime}, s_1^{\prime}, s_2^{\prime})$ are IFTHGs, $\mathbb{H}_G$ is called a *partial IFTHG* of $\mathbb{H}_G^{\prime}$ and an independent set $V \subseteq U$ such that

$$u^{\prime} = \begin{cases} \min(\supp(\mu_y)) \text{ and } \sum_{u_j \in V^{\prime}} \mu_y(u_j) \leq s_1 \mid \mu_y \in \mathcal{E}^{\prime} \\ \max(\supp(\nu_y)) \text{ and } \sum_{u_j \in V^{\prime}} (1 - \nu_y(u_i)) \leq s_2 \mid \nu_y \in \mathcal{E}^{\prime} \end{cases}$$

The partial IFTHG generated by $\mathcal{E}^{\prime}$ is represented by $\mathbb{H}_G \subseteq \mathbb{H}_G^{\prime}$. Then we write $\mathbb{H}_G \subset \mathbb{H}_G^{\prime}$ if $\mathbb{H}_G \subseteq \mathbb{H}_G^{\prime}$ and $\mathbb{H}_G \neq \mathbb{H}_G^{\prime}$.

**Definition 5.2.7.** Let $\mathbb{H}_G = (U, \mathcal{E}, s_1, s_2)$ be an IFTHG, there exists an independent set $V \subseteq U$ such that $C(\mathbb{H}_G) = \{\mathbb{H}_G^{(y_1, z_1)}, \mathbb{H}_G^{(y_2, z_2)}, \dots, \mathbb{H}_G^{(y_n, z_n)}\}$ for which $\sum_{u_i \in V} \mu_y(u_i) \leq s_1$ and $\sum_{u_i \in V}(1 - \nu_y(u_i)) \leq s_2$, $\mathbb{H}_G$ is said to be *ordered* if $C(\mathbb{H}_G)$ is ordered. That is $\mathbb{H}_G^{(y_1, z_1)} \subset \mathbb{H}_G^{(y_2, z_2)} \subset \dots \subset \mathbb{H}_G^{(y_n, z_n)}$ for which $\sum_{u_i \in V} \mu_y(u_i) \leq s_1$ and $\sum_{u_i \in V}(1 - \nu_y(u_i)) \leq s_2$. The IFTHG is known as *simply ordered* if $\{\mathbb{H}_G^{(y_j, z_j)} \mid j = 1, 2, \dots, n\}$ is simply ordered, i.e., if it is ordered and if $\mathcal{E} \in \mathbb{H}_G^{(y_{j+1}, z_{j+1})} \setminus \mathbb{H}_G^{(y_j, z_j)}$ then $\mathcal{E} \not\subseteq \mathbb{H}_G^{(y_j, z_j)}$.

## 5.3 Notations

- $\mathbb{H}_G = (U, \mathcal{E}; s_1, s_2)$: IFTHG with hyperedge set $\mathcal{E}$, vertex set $U$ and $s_1$, $s_2$ are threshold values.
- $\mathcal{H}_t(\mathbb{H}_G)$: Height of IFTHG.
- $\mathcal{F}_t(\mathbb{H}_G)$: Fundamental sequence of IFTHG.
- $C(\mathbb{H}_G)$: Core set of IFTHG.
- $I(\mathbb{H}_G)$: Induced fundamental sequence of IFTHG.
- $\mathbb{H}_G^{(y_j, z_j)}$: $(y_j, z_j)$-level of $\mathbb{H}_G$.
- $(y_j, z_j)$: Hyperedge membership and non-membership values.
- $T_G(\mathbb{H}_G)$: Minimal intuitionistic fuzzy transversal (IFT) of IFTHG.

## 5.4 Main Results

**Definition 5.4.1.** Assume an IFTHG $\mathbb{H}_G = (U, \mathcal{E}; s_1, s_2)$. An IFT $T$ of IFTHG is an intuitionistic fuzzy subset of $U$ with $T^{\langle e_j, e_k \rangle} \cap A^{\langle e_j, e_k \rangle} \neq \varnothing$ $\forall A \in \mathcal{E}$ where $e_j = \bigwedge (u_{ij})$ and $e_k = \bigvee(v_{ij})$ for which $\sum_{u_i \in V} \mu_{ij}(u_i) \leq s_1$ and $\sum_{u_i \in V} (1 - \nu_{ij}(u_i)) \leq s_2$, $\forall 1 \leq i \leq m, 1 \leq j \leq n$. Also $\mu_{ij}$ and $\nu_{ij}$ are the membership and non-membership values of the $i$-th vertex of the $j$-th hyperedge.

**Definition 5.4.2.** A minimal IFT $T$ for IFTHG is a transversal of $\mathbb{H}_G$, which satisfies the condition that if $T_1 \subset T$, then $T_1$ is not an IFT of $\mathbb{H}_G$.

**Note:** The set of all minimal IFTs of IFTHG is represented by $\mathcal{T}\sigma(\mathbb{H}_G)$. Always $\mathcal{T}\sigma(\mathbb{H}_G) \neq \varnothing$.

**Definition 5.4.4.** If $T$ is an intuitionistic fuzzy set with $(v_i, z_j)$ as a minimal IFT of $\mathbb{H}_{G}^{(v_i, z_j)}$ and $\forall(v_{i}, z_{j}) \in(0,1)$ for which $\sum_{u_{i} \in V} \mu_{y}(u_{i}) \leq s_{1}$ and $\sum_{u_{i} \in V}(1 - \nu_{i}(u_{i})) \leq s_{2}$ and $\forall 1 \leq i \leq m, 1 \leq j \leq n$ implies $T$ is known as locally minimal IFT of IFTHG. The set containing locally minimal IFTs of IFTHG is denoted as $\mathcal{T} \times^{\prime}(\mathbb{H}_{G})$.

**Theorem 5.4.5.** If $T$ is an IFT of IFTHG $\mathbb{H}_{G}=(U, \mathcal{E}, s_{1}, s_{2})$, then $\mathscr{A}_{T}\left(T_{e}\right) \supseteq \mathscr{A}_{T}\left(e_{j}\right)$ for $e_{j} \in \mathcal{E}$. And, if $T$ is a minimal IFT of IFTHG, it implies $\mathscr{A}_{T}(T)=\left\{\max \left(\min \left(\mu_{y}\right)\right), \max \left(\max \left(\nu_{y}\right)\right) \mid \mu_{y}, \nu_{y} \in \mathcal{E}\right\}=\mathscr{A}_{T}\left(\mathbb{H}_{G}\right)$.

**Theorem 5.4.6.** Each IFTHG has a non-empty IFT.

**Note:** Each IFT of IFTHG contains a minimal IFT. (i.e.) $\mathcal{T}^{X}\left(\mathbb{H}_{G}\right) \subseteq T\left(\mathbb{H}_{G}\right)$.
