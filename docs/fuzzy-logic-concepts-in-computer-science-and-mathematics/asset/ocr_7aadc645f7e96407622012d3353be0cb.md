The speed produced by the “From” block must be assigned, similar to the “Goto” block, which records the output speed of the DCM. This ensures consistent data flow and synchronization between the generated speed data and the recorded motor speed output.

There are three gains in the system: the first is set to 1/1750 to ensure error normalization, the second is set to 30/π to convert speed from RPM to radians per second, and the third gain is adjusted to transform the speed from radians per second back to RPM.
