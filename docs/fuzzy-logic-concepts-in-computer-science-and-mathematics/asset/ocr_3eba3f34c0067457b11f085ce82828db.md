These degrees of membership are defined in large part by membership functions. These functions indicate how much a particular element belongs to the fuzzy set by mapping the input values to a range between 0 and 1. The fuzzy set's properties are determined by the membership function's form, and it can take a variety of forms such as triangular, trapezoidal, Gaussian, or more complex shapes as shown in Figure 8.4.

For example, in modeling the linguistic variable "temperature" in a fuzzy set "warm," the membership function might assign a high degree of membership (close to 1) to temperatures around 25°C, and this degree gradually decreases as the temperature deviates from this central value. This allows fuzzy logic to represent and manipulate linguistic terms and human-like reasoning in decision-making processes where precise, binary distinctions are inadequate. Fuzzy sets and membership functions are crucial components in constructing rule-based systems that emulate human decision-making in complex and uncertain environments.
