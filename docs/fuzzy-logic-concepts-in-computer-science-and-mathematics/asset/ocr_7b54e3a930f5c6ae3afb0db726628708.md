**Step III:** Determine IF positive and negative ideals: IFPIS($\Phi^{+}$) and IFNIS ($\Phi^{-}$) from the alternatives $\theta_{i}$ as

```
$$
\delta(\theta_{i}, \Phi_{i}^{+}) = \sum_{j=1}^{m} \omega_{j} \delta\left(r_{ij}, \Phi_{i}^{+}\right) = \sum_{j=1}^{m} \omega_{j}\left(1-\phi_{ij}\right)
$$

$
\delta\left(\theta_{i}, \Phi_{i}^{-}\right) = \sum_{j=1}^{m} \omega_{j} \delta\left(r_{ij}, \Phi_{i}^{-}\right) = \sum_{j=1}^{m} \omega_{j}\left(1-\psi_{ij}\right)
$
```

where, $r_{ij} = \left(\phi_{ij}, \psi_{ij}, \pi_{ij}\right)$

**Step IV:** Calculate the closeness coefficient of each alternative:

```
$
C(\theta_{i}) = \frac{\delta(\theta_{i}, \Phi_{i}^{-})}{\delta(\theta_{i}, \Phi_{i}^{+}) + \delta(\theta_{i}, \Phi_{i}^{-})}
$

Since, $\delta(\theta_{i}, \Phi_{i}^{+}) + \delta(\theta_{i}, \Phi_{i}^{-}) = \sum_{j=1}^{m} \omega_{j}(1+\pi_{ij})$
```

```
$
\therefore \quad C(\theta_{i}) = \frac{\sum_{j=1}^{m} \omega_{j}(1-\psi_{ij})}{\sum_{j=1}^{m} \omega_{j}(1+\pi_{ij})}
$
```

**Step V:** On the basis of closeness coefficients $C(\theta_{i})$, rank the alternative $\theta_{i}$. Greater the $C(\theta_{i})$, better the alternative.

**Step VI:** End.
