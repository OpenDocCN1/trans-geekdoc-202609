# **5.2  PRELIMINARIES**

**Definition 5.2.1.** The intuitionistic fuzzy threshold hypergraph (IFTHG) is denoted by H_G = (U, E; s_1, s_2) where,

+   1.  U = {u_1, u_2, ..., u_n} is finite set of intuitionistic fuzzy vertices,
2.  E = {E_1, E_2, ..., E_m} is a family of crisp subsets of U,
3.  E_j = { (u_j, u_j^j(u_i), v_j^j(u_i)) | 0 <= u_j^j(u_i) + v_j^j(u_i) <= 1 }, j = 1, 2, ..., m
4.  E_j != varnothing, j = 1, 2, ..., m
5.  U_j sup(E_j) = U, j = 1, 2, ..., m
6.  An independent set V ⊆ U be set of all different combinations of a nonadjacent vertices in H_G if there exist s_1 and s_2 > 0 such that sum_{u_i in V} u_j^j(u_i) <= s_1 and sum_{u_i in V}(1 - v_j^j(u_i)) <= s_2

Where the hyperedges of E_j are crisp sets of intuitionistic fuzzy vertices, mu_i(u_i) and nu_i(u_i) represent the membership and nonmembership degrees of a vertex u_i to an hyperedge e_j.

**Definition 5.2.2.** Let H_G = (U, E; s_1, s_2) be an IFTHG. If an independent set V ⊆ U, then the height of H_G is named as H_u(H_G) = { max(min(mu_i)), max(max(nu_i)) } for which sum_{u_i in V} u_i^j(u_i) <= s_1 and sum_{u_i in V}(1 - nu_i^j(u_i)) <= s_2 for all i = 1, 2, ..., m and j = 1, 2, ..., n, where u_i^j and nu_i^j is the membership and nonmembership value of jth hyperedge in ith vertex, respectively.

**Definition 5.2.3.** Let H_G = (U, E; s_1, s_2) be an IFTHG and an independent set V ⊆ U exist, if e_j times e_k in E and 0 < alpha, beta < 1. Then, the (alpha, beta)-level is defined by (e_j times e_k)^{alpha, beta} = { u_i | u_i in U | min((mu_i^j)^alpha(u_i)) >= alpha, max((nu_i^k)^beta(u_i)) <= beta } for which sum_{u_i in V} u_j^j(u_i) <= s_1 and sum_{u_i in V}(1 - nu_j^j(u_i)) <= s_2.

**Definition 5.2.4.** Let H_G = (U, E; s_1, s_2) be an IFTHG, there exists an independent set V ⊆ U such that H_G^{(y_i, z_i)} = (U^{(y_i, z_i)}, E^{(y_i, z_i)}) be the (y_i, z_i)-level of H_G. The sequence of real numbers { y_1, y_2, ..., y_n; z_1, z_2, ..., z_n } in 0 <= y_i <= H_u(H_G) and 0 <= z_i <= H_v(H_G), satisfying the following conditions:

+   1.  If y_1 < alpha < 1 and 0 < beta < z_1 => E^{alpha, beta} = varnothing;
2.  If y_{i+1} <= alpha <= y_i; z_i <= beta <= z_{i+1} => E^{alpha, beta} = E^{(y_i, z_i)}; and
3.  E^{(y_i, z_i)} subset E^{(y_{i+1}, z_{i+1})}

for which sum_{u_i in V} u_i^j(u_i) <= s_1 and sum_{u_i in V}(1 - nu_i^j(u_i)) <= s_2 is known as *fundamental sequence* of H_G and is represented by F(H_G)
