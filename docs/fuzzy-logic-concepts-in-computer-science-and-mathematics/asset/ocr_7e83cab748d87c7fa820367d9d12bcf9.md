# 5.4 MAIN RESULTS

**Definition 5.4.1.** Assume an IFTHG $\mathbb{H}_G = (U, \mathcal{E}; s_1, s_2)$. An IFT $T$ of IFTHG is an IF subset of $U$ with $\mathbb{T}^{\langle e_j, e_k \rangle} \cap \mathcal{A}^{\langle e_j, e_k \rangle} \neq \varphi$ $\forall \mathcal{A} \in \mathcal{E}$ where $e_j = \bigwedge (u_{ij})$ and $e_k = \bigvee(v_{ij})$ for which $\sum_{u_i \in V} \mu_{ij}(u_i) \leq s_1$ and $\sum_{u_i \in V} (1 - v_{ij}(u_i)) \leq s_2$, $\forall 1 \leq i \leq m, 1 \leq j \leq n$. Also $\mu_{ij}$ and $v_{ij}$ is the membership and nonmembership value of $i^{th}$ vertex of $j^{th}$ hyperedge.

**Definition 5.4.2.** A minimal IFT $T$ for IFTHG is a transversal of $\mathbb{H}_G$, which satisfies the condition that if $T_1 \subset T$, then $T_1$ is not an IFT of $\mathbb{H}_G$.

**Note:** The set of all minimal IFT of IFTHG is represented by $\mathcal{T}\sigma(\mathbb{H}_G)$. Always $\mathcal{T}\sigma(\mathbb{H}_G) \neq \varphi$.
