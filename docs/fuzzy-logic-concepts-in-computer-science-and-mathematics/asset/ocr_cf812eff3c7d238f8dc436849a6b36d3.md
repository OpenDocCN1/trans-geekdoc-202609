# 6.5.4 CONTROL SYSTEMS

IFL and IFSs are significantly useful in control systems for handling imprecise or uncertain data. Figure 6.5 presents some applications of IFS in control systems.

Some other applications of IFS and IFL in risk assessment are as follows:

+   1) Fuzzy logic control: IFSs can handle more complex uncertainty in fuzzy logic control systems. A domain expert often provides the inference rules employed in a fuzzy logic controller. However, in systems that utilize IFSs, these rules are automatically induced as fuzzy association rules based on a training set [24].
