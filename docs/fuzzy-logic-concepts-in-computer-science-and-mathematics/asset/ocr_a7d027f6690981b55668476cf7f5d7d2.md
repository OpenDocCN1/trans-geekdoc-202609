and is defined by $C(\mathbb{H}_G) = \{\mathbb{H}_{G}^{(y_1, z_1)}, \mathbb{H}_{G}^{(y_2, z_2)}, \dots, \mathbb{H}_{G}^{(y_n, z_n)}\}$. The corresponding set of $(y_n, z_n)$-level hypergraphs is $\mathbb{H}_{G}^{(y_1, z_1)} \subset \mathbb{H}_{G}^{(y_2, z_2)} \subset \dots \subset \mathbb{H}_{G}^{(y_n, z_n)}$ for which $\sum_{u_i \in V} \mu_y(u_i) \leq s_1$ and $\sum_{u_i \in V}(1 - \nu_y(u_i)) \leq s_2$ called the $\mathbb{H}_G$-induced fundamental sequence and is noted as $I(\mathbb{H}_G)$. The $(y_r, z_r)$-level is said to be a support level of $\mathbb{H}_G$ and the $\mathbb{H}_G^{(y_r, z_n)}$ is known as the support of $\mathbb{H}_G$.

**Definition 5.2.6.** Suppose $\mathbb{H}_G = (U, \mathcal{E}, s_1, s_2)$ and $\mathbb{H}_G^{\prime} = (U^{\prime}, \mathcal{E}^{\prime}, s_1^{\prime}, s_2^{\prime})$ are IFT HGs, $\mathbb{H}_G$ is called a *partial IFT HG* of $\mathbb{H}_G^{\prime}$ and an independent set $V \subseteq U$ such that

$u^{\prime} = \begin{cases} \min(\supp(\mu_y)) \text{ and } \sum_{u_j \in V^{\prime}} \mu_y(u_j) \leq s_1 \mid \mu_y \in \mathcal{E}^{\prime} \\ \max(\supp(\nu_y)) \text{ and } \sum_{u_j \in V^{\prime}} (1 - \nu_y(u_i)) \leq s_2 \mid \nu_y \in \mathcal{E}^{\prime} \end{cases}$

the partial IFT HG generated by $\mathcal{E}^{\prime}$ and is represented by $\mathbb{H}_G \subseteq \mathbb{H}_G^{\prime}$. Then we write $\mathbb{H}_G \subset \mathbb{H}_G^{\prime}$ if $\mathbb{H}_G \subseteq \mathbb{H}_G^{\prime}$ and $\mathbb{H}_G \neq \mathbb{H}_G^{\prime}$.

**Definition 5.2.7.** Let $\mathbb{H}_G = (U, \mathcal{E}, s_1, s_2)$ be an IFT HG, there exists an independent set $V \subseteq U$ such that $C(\mathbb{H}_G) = \{\mathbb{H}_G^{(y_1, z_1)}, \mathbb{H}_G^{(y_2, z_2)}, \dots, \mathbb{H}_G^{(y_n, z_n)}\}$ for which $\sum_{u_i \in V} \mu_y(u_i) \leq s_1$ and $\sum_{u_i \in V}(1 - \nu_y(u_i)) \leq s_2$, $\mathbb{H}_G$ is said to be *ordered* if $C(\mathbb{H}_G)$ is ordered. That is $\mathbb{H}_G^{(y_1, z_1)} \subset \mathbb{H}_G^{(y_2, z_2)} \subset \dots \subset \mathbb{H}_G^{(y_n, z_n)}$ for which $\sum_{u_i \in V} \mu_y(u_i) \leq s_1$ and $\sum_{u_i \in V}(1 - \nu_y(u_i)) \leq s_2$. The IFT HG is known as *simply ordered* if $\{\mathbb{H}_G^{(y_j, z_j)} \mid \mathrm{j} = 1, 2, \dots, n\}$ is simply ordered, (i.e.) if it is ordered and if $\mathcal{E} \in \mathbb{H}_G^{(y_{j+1}, z_{j+1})} \setminus \mathbb{H}_G^{(y_j, z_j)}$ then $\mathcal{E} \not\subseteq \mathbb{H}_G^{(y_j, z_j)}$
