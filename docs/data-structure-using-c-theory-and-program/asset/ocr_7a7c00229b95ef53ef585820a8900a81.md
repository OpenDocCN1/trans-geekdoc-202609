# Big-Oh Notation

We use O-Notation to give an upper bound on a function, to within constant
factor. For a given function f(n), we denote it by O(g(n)).

```
O(g(n)) = {f(n): there exists positive constant c and n_0 such that: O ≤ f(n) =
c(n) for all n ≥ n_0}
```

# Example

Suppose f(n) = 2n² + 3n + 5. We want to express f(n) as the upper bound of
some other function.

We can proceed as follows.

```
f(n) = 2n² + 3n + 5
≤ 2n² + 3n² + 5n²
≤ 10n²
```

Thus, f(n) = O(n²), here g(n) = n²
where c = 10 and n ≥ 1

# Note:

f(n) = O(n²) implies that f(n) = O(n³)
for all x ≥ 2

f(n) = c where c is a positive constant,
then f(n) can be expressed with
Ω-notation as f(n) = Ω(1)

# Omega (Ω) Notation

This is almost the same definition as
Big-Oh except that “f(n) ≥ g(n)\”.
makes g(n) a lower bound function
instead of an upper bound function.
For a given function g(n), Ω(g(n)) =
{f(n): there exists positive constant
and n_0 such that: O ≤ cg(n) ≤ f(n) for
n all ≥ n_0}

# Example

f(n) = n³ + n² + n + 1 and g(n) = 3n²
+ 2n + 1

since, f(n) ≥ g(n) for all n ≥ 3
hence, we have f(n) = Ω(g(n)
