3. Average Case: The average case is that in which the element is found in comparisons more than best case but less than worst.

# 8.2 LINEAR OR SEQUENTIAL SEARCHING

Suppose DATA is a linear array with n elements. Given the most intuitive way to search for a given ITEM in DATA is to compare ITEM with each element of DATA one-by-one. That is, we test whether DATA (1) = ITEM, and then test whether DATA (2) = ITEM, and so on. This method traverses DATA sequentially to locate ITEM, is called linear search or sequence search. Each element of an array is read one-by-one sequentially and it is compared with the desired element. A search will be unsuccessful if all the elements are read and the desired element is not found. Linear search is the least efficient search technique among the quantity dependent search techniques. This technique should be chosen for searching the records when the records are stored without considering the order or when the storage medium lacks the direct access facility. Important points are:

+   - It is the simplest way for finding an element in a list.
- It searches the element sequentially in a list, no matter whether list is sorted or unsorted.
- In case of sorted list the search is started from 1st element and continue until the desired element is found or the element whose value is smaller than the value being searched.
- If the list is unsorted searching starting from 1st location and continued until the element is found or the end of the list is reached.
