# Algorithm to implement a double ended queue

Steps

+   1. Start
2. Initialise and declare the variable
3. Enter your choice
4. If choice is ENQUEUE at FRONT
(i) Check if dequeue is full.
(ii) Else check for FRONT at first position.
(iii) Else decrement the FRONT position.
5. If choice is ENQUEUE at REAR
(i) Check if dequeue is full
(ii) Else check for REAR at last position.
(iii) Else increment the REAR position.
6. If choice is DEQUEUE at FRONT
(i) Check if dequeue is empty.
(ii) Else check for dequeue contains only one element
(iii) Else increment the FRONT position.
7. If choice is DEQUEUE at REAR
(i) Check if dequeue is empty.
(ii) Else check for dequeue contains only one element.
(iii) Else decrement the REAR position.
8. Stop
