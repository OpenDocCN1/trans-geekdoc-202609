# Chapter 9 Hashing Techniques

A potential disadvantage of the division method is due to the property that consecutive keys map to the inverse of hash values:

```
h(i) = i
 h(i+1) = i+1 (mod M)
 h(i+2) = i+2 (mod M)
```

While this ensures that consecutive keys do not collide, it does mean consecutive array locations will be occupied. We will see that in certain implementations this can lead to degradation in performance. In the following sections we consider hashing methods that tend to scatter consecutive keys. In the division method for creating hash maps, we make a k into one of m slots by taking the remainder of k divided by m. Then, the hash function is:

```
h (k) = k mod m or h(k) = k mod +1
```

For example, if the hash table has size m =11 and the key k = 90, then h(k) = 2, since it requires only a single division operation, hashing by division is quite fast.

# 2. Multiplication Method

A simple variation of the middle-square method that alleviates its deficiencies is the so-called, multiplication hashing method. Instead of multiplying the key x by itself, we multiply by a carefully chosen a, and then extract the k bits from the result. In this, the hash function is

```
h(x) = [M/W](ax mod W)
```

What is a suitable choice for the constant a? If we want to avoid the problems the middle-square method encounters with keys having a large number of leading or trailing zeros, we should choose a that has neither leading nor trailing 0s.

Furthermore, if we choose an a that is relatively prime to W, then there exists another number a' such that aa'=1 (mod W). In other words, a' is the inverse of a modulo W, since the product of a and its inverse is one. Such a number has the property that if we take a key x, and multiply it by a to get ax, we can recover the original key by multiplying the product by a', since ax=aax=1.

There are many possible constants with the desired properties. One possibility which is suited for 32-bit arithmetic (i.e., W = 2^32) is a = 2654435769. The binary representation of a is

```
100111100110101111101011011101
```

This number has no leading nor trailing zeros. Also, this value of a and W = 2^32 are relatively prime and the inverse of a modulo W is =340573321.
