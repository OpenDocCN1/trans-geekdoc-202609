# 7.11 SHORTEST PATHS (DIJKSTRA’S ALGORITHM)

A path from source vertex s is shortest path s t if there is path from s to t with lower weights. In a shortest paths problem, we are given a weighted directed graph G = (V, E) with E→R mapping edges to real valued weights. The weight of path p < V₀, V₁, ..., Vₘ m is the sum of the weights of its constituent edges.

```
w(p) = \sum_{i=1}^{k} w(V_{i+1}, V_i)
```

We define the shortest path from u to v by
\nδ(u,v) = min w(p): u→v

# Dijkstra's algorithm

Dijkstra's algorithm, named after its discover, Dutch computer scientist Edsger Dijkstra, is a greedy algorithm that solves the single-source shortest path problem for a directed graph G = (V,E) with non-negative edge weights, i.e., we assume w(u,v) ≥ each edge (u,v).

Dijkstra's algorithm maintains a set S of vertices whose final path weights from source have already been determined. Then, for all v ES we have d[v] = (s,v). The algorithm repeatedly selects the vertex u V-S with the minimum weight - estimate, insert u S, and relaxes all edges leaving u. We maintain a priority queue Q that contains all the vertices in v -s, keyed by their d values. Graph G is represented by adjacency lists.

+   1. INITIALIZE - SINGLE - SOURCE (G, s)
2. S - 0
3. Q - V[G]
4. While Q = 0
5. du - EXTRACT - MIN (Q)
6. S - S ∪ {u}
7. for each vertex vAdj [u]
8. do RELAX (u, v, w)
