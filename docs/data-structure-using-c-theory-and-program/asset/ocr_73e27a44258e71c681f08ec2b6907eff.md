# 1. Creation of binary tree from pre-order and in-order traversal.

The general rule for creating a binary tree is as follows:

**Rule 1:** scan the pre-order traversal from left to right

**Rule 2:** for each node scanned, locate its position in in-order traversal. Assume the scanned node be X.

**Rule 3:** the node X preceding X inorder from its left sub-tree and nodes succeeding it from right sub-tree.

**Rule 4:** repeat rule 1 for each symbol in the pre-order.

**Example:** Draw a binary tree of the following given orders

Pre-order: A B D H E C F G

In-order: D H B E A F C G

# **Solution:**

Pre-order: A B D H E A F G

In-order: D H B E A F G
