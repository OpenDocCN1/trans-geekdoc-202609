# Algorithm

Steps

+   1. Start
2. Holds the address of the first node
3. Set node = start
4. Repeat steps 5 to 14 while next [node] ≠ NULL
5. Set ptr = next [node]
6. Repeat steps 7 to 12 while ptr ≠ NULL
7. If info [node] > info [ptr] then
8. Set temp = info [node]
9. Set info [node] = info [ptr]
10. Set info [ptr] = temp
11. End of step 7 if structure
12. Set ptr = next [ptr]
13. End of step 6 loop
14. Set node = next [node]
15. End of step 4 loop
16. Stop
