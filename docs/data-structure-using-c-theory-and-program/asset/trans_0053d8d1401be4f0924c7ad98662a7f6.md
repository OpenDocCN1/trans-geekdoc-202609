- 1. 开始
2. 如果 first=NULLthen
3. 打印消息“UNDERFLOW（上空）”然后
4. 停止
5. ptr<-leftptr (first)
6. currptr<-leftptr
7. leftptr<-currptr
8. rightptr (currptr) <-first
9. leftptr<-avail
10. rightptr<-avail
11. avail<-ptr
12. stop

```c
struct node *deleteatend(struct node *start)
{
  struct node *tmp;
  tmp=start;
  while(tmp->next)!=start)
    tmp=tmp->next;
  tmp->next=start;
  start->prev=tmp;
  free(tmp);
  return start;
}
```
