# 5.7 DIFFERENCE BETWEEN STACK AND QUEUE

| SNo | Stack | Queue |
|---|---|---|
| 1 | Stack is an ordered list where insertions and deletions are performed at one end called | Queue is an ordered list where insertion are performed at rear side and deletion is performed at front |n| 2 | Stack follow FIFO rule | Queue follow FIFO rule |
| 3 | Stack is full when top = MAXSIZE - 1 | Queue is full when rear = MAXSIZE - 1 |
| 4 | Stack is empty when top = -1 | Queue is empty when front ==1 |
| 5 | To insert an element into stack; top is increment by 1. i.e. top = top + 1 | To insert an element from the queue; rear is increment by 1. i.e. rear = rear + 1 |
| 6 | To delete an element from stack; top is decrement by 1. i.e. top = top - 1 | To delete an element from the queue; front is decrement by 1. i.e. front = front + 1 |

+   2. The elements in a queue are added at one end called the rear and removed from the other end called the front.

+   3. In the computer memory, queues can be implemented using arrays and linked list.

+   4. In a circular queue, the first index comes after the last index.

+   5. A priority queue is a data structure in which each element is assigned a priority. The priority of the elements will be used to determine the order in which the elements are processed.

+   6. A de-queue is a list in which elements can be inserted or deleted at either end. It is also known as a head-tail linked list because elements can be added to or removed from the front (head) or back (tail).
