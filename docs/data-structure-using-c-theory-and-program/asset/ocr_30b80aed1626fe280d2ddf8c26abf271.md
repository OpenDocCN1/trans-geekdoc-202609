# 3.6 OPERATIONS IN A CIRCULAR LINKED LIST

There are various operations possible on a Circular Linked List.

+   (a) Creation of a circular linked list.

+   (b) Insertion of a node

+   (c) Deletion of a node

# Creation of Circular Linked List

Creation of Circular Linked List is same as Single Linked List. Only one thing is needed that here last node will always point to first node instead of NULL.
