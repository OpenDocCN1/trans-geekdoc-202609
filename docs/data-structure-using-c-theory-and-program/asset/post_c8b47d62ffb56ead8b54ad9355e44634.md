                pri_que[j] = pri_que[j - 1];

            pri_que[i] = data;
            return;
        }
    }
}

# 5.6 APPLICATIONS OF QUEUES

Some of the applications of queues are as follows:

- 1. There are several algorithms that use queues to solve problems easily. For example, BFS traversing of a binary tree.
- 2. Round-robin technique for processor scheduling is implemented using queues.
- 3. When the jobs are submitted to a network printer, they are arranged in order of arrival. i.e., jobs sent to a printer are placed on a queue.
- 4. Every real-life line is queue. For example, lines at ticket counters at cinema halls, railway stations, bus stands etc., are queues because the service is i.e. ticket is provided on first first served (FIFO) basis.

# 5.7 DIFFERENCE BETWEEN STACK AND QUEUE

| SNo | Stack | Queue |
|---|---|---|
| 1 | Stack is an ordered list where insertions and deletions are performed at one end called | Queue is an ordered list where insertion are performed at rear side and deletion is performed at front |
| 2 | Stack follow FIFO rule | Queue follow FIFO rule |
| 3 | Stack is full when top = MAXSIZE - 1 | Queue is full when rear = MAXSIZE - 1 |
| 4 | Stack is empty when top = -1 | Queue is empty when front = -1 |
| 5 | To insert into stack, top is incremented. | To insert into queue, rear is incremented. |
| 6 | To delete from stack, top is decremented. | To delete from queue, rear is decremented. |

# 5.6 APPLICATIONS OF QUEUES

Some of the applications of queues are as follows:

- 1. There are several algorithms that use queues to solve problems easily. For example, BFS traversing of a binary tree.
- 2. Round-robin technique for processor scheduling is implemented using queues.
- 3. When the jobs are submitted to a network printer, they are arranged in order of arrival. i.e., jobs sent to a printer are placed on a queue.
- 4. Every real-life line is queue. For example, lines at ticket counters at cinema halls, railway stations, bus stands etc., are queues because the service is i.e. ticket is provided on first first served (FIFO) basis.

# 5.7 DIFFERENCE BETWEEN STACK AND QUEUE

| SNo | Stack | Queue |
|---|---|---|
| 1 | Stack is an ordered list where insertions and deletions are performed at one end called | Queue is an ordered list where insertion are performed at rear side and deletion is performed at front |
| 2 | Stack follow FIFO rule | Queue follow FIFO rule |
| 3 | Stack is full when top = MAXSIZE - 1 | Queue is full when rear = MAXSIZE - 1 |
| 4 | Stack is empty when top = -1 | Queue is empty when front = -1 |
| 5 | To insert into stack, top is incremented. | To insert into queue, rear is incremented. |
| 6 | To delete from stack, top is decremented. | To delete from queue, rear is decremented. |
