# Definition

A stack is an ordered collection of homogeneous data elements where the insertion and deletion occur at only one end. This end is often known as top of the stack. Here, the last element inserted will be top of the stack. Since deletion is done from the same end, last element will be the first to be removed from the stack and so on. That is why the stack is also called Last-in-First-Out (LIFO).

Initially, when stack is created using arrays the size is fixed while the stack top increase the position. So, most frequently accessible element in the stack is the top and the last accessible elements are the bottom of the stack.

# 4.2 OPERATIONS ON THE STACK

A stack is generally implemented with two basic operations such as PUSH and POP.

+   1. PUSH Operation
2. POP Operation

# 1. PUSH Operation

The process of adding a new element to the top of the stack is called push operation. Pushing an element in the stack invoke adding of element at the top. Suppose, after inserting an element max size is reached, i.e., stack is full. This situation is called the stack overflow condition. At this point the stack is present at the highest location of the stack. Initially the stack is empty and it has one pointer i.e., TOP.
