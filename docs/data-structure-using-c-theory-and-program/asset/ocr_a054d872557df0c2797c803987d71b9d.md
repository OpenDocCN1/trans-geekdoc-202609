# 3.9 CIRCULAR DOUBLE LINKED LIST

The main motive for consideration to implement a circular double linked list is to
simple the insertion and deletion operations performed. In this list, the left
link of the left most node contains the address of the right most node and the
right link of the right most node contains the address of the left most node.
