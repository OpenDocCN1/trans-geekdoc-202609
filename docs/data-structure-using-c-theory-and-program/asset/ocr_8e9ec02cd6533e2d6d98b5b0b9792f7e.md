# Algorithm

Steps

+   1. Start
2. Holds the address of the first node
3. Set temp = start
4. If start = NULL then
5. Write “UNDERFLOW” and
6. Exit
7. Set start = next [start]
8. Set prev [start] = NULL
9. Free the space allocated with temp
10. Stop
