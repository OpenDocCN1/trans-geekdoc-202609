Where B=base address

U1=upper bound of a row

Q1. A 2-D array defined as A[4....6, 1....4] required 4 bytes of storage space for each element. If the array is stored in column major, then calculate the address of element at location A[5,2]. Base address is 100.

Solution: Apply the formula
Address of element a[i][j]=B+ W ( m (j - L2)+(i-L1))
B=100,w=4, m=3, i=5, j=2, L1=4, L2=1
m=U1-L1+1
=6-4+1
=3

Address of element of A [5][2] = 100 + 4 ( 2 - 1 ) + (5 - 4)
=100 + 4 * 4
=100 + 16
=116

Q2. Calculate the address of Y [4,3] in a 2-D array Y[-1....6, -1....5] stored in column major order in the main memory. Suppose the base address to be 200 and each element required 4 bytes of storage.

Solution: Apply the formula
Address of element Y[i][j]=B+ W ( m (j - L2)+(i-L1))
B=200,w=4, m=7, i=4, j=3, L1=-1, L2=-1
m=U1-L1+1
=6-(-1)+1
=7

Address of element Y [4][3] = 200 + 4 ( 7 - (-1) ) ( 4 - (-1)))
=200 + 4 * 33
=200 + 132
332
