# 8.3 BINARY SEARCH

If we place our items in an array and sort those in either ascending or descending order. Then we can obtain much better performance with an algorithm called binary Search.

# General Idea about Binary Search Algorithm

+   1. Find the middle element of the array.
2. Compare the middle element with the data to be searched, and then there are following three cases.
   (a) If it is a desired element, search is successful.
   (b) If it is less than desired data, search only the first half of the array, i.e., the elements which come to the left side of the middle element.
   (c) If it is greater than the desired data, search only the second half of the array, i.e., the elements which come to the right side of the middle element.

# Algorithm

+   1. Input an array A of elements and “data” to be searched.
2. LB = 0, UB=n; mid = int (LB + UB)/2
3. Repeat steps 4 and 5 while (LB<= UB) and (A [mid] != data)
4. If (data < A [mid])
   UB = mid-1
Else
   LB = mid+1
