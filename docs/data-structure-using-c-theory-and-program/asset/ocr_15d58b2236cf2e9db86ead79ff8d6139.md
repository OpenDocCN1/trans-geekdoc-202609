First observe that the matrix P_0=A, the adjacency matrix of G. Furthermore, since G has only n nodes, the last matrix P_n =P, the path matrix of G.

Warshall observed that P_k[i][j] = 1 can occur only if one of the following two cases occurs:

+   1. There is a simple path from V_i to V_j which does not use any other nodes except V_1, V_2,...,V_{k-1}; hence P_{k-1}[i][j] = 1
V_i →······ V_j

+   2. There is a simple path from V_i to V_j, and a simple path from V_k to V_j where each path does not use other nodes except V_1, V_2,...,V_{k-1}; hence P_{k-1}[i][j] = 1 and P_{k-1}[k][j] = 1
V_i →······ V_k →······→ V_j

Accordingly, the elements of the matrix P_k can be obtained by P_k[i][j] = P_{k-1}[i][j] ∧ P_{k-1}[k][j]]

Where we use the logical operations ∧ (AND) and ∨ (OR). In other words, we can obtain each entry in the matrix P_k' by looking at only three entries in the matrix P_{k-1}. Marshall's algorithm is as follows:

# Algorithm

A directed graph G with n nodes is maintained in memory by its adjacency matrix A. This algorithm finds the Boolean path P of the graph G.

+   1. Repeat steps 2 and 3 for i, j = 0, 1, ...... n-1 //initializes P
2. If A[i][j] = 0 set P[i][j] = 0
3. Else set P[i][j]
4. End of step 1 loop
5. Repeat steps 6 to 8 for k = 0, 1, ...... n-1 //updates P
6. Repeat steps 7 to 8 for i = 0, 1, ...... n-1
7. Repeat steps 8 for j = 0, 1, ...... n-1
8. Set P[i][j] = P[i][j] ∨ (P[i][k] ∧ P[k][j])
9. End of step 5 loop
10. End of step 3 loop
11. End of step 2 loop
12. Stop
