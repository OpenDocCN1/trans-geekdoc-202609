# 2.2 ONE-DIMENSIONAL ARRAY

This type of array represents and stores data in linear form. It is also called single dimensional array. One-dimensional array is a set of ‘n’ finite number of similar/homogenous data elements. The elements of the array are referred respectively by an index set consisting of ‘n’ consecutive memory locations. The elements of the array are stored respectively in memory locations. Sets of ‘n’ numbers are called the length or size of an array. The elements of array “arr” can be denoted in C Programming language as: A[0], A[1], A[2], A[3],......A[n-1]. The number ‘n’ in A[n] is called a subscript or an index and A[n] is called a subscript variable. If ‘n’ is 8, then the array elements are stored in memory A[0], A[1], A[2], A[3], A[4], A[5], A[6], A[7].
