- * 以表格形式将中缀表达式转换为后缀表达式
将中缀表达式转换为后缀表达式的步骤如下

- 1. 向栈中加入唯一符号“#”。
- 2. 从左到右逐扫描数组 `infix` 中的符号。
- 3. 如果符号是左括号“("，则将其入栈。
- 4. 如果符号是操作数，则加入数组 `postfix`。
- 5. 如果符号是运算符，则弹出与当前运算符优先级相同或更高的运算符。
- 6. 将弹出的运算符加入数组 `postfix`。
- 7. 将扫描到的符号运算符存入栈。
- 8. 如果符号是右括号“”,则从栈中弹出所有运算符，直到栈中出现左括号“(".
- 9. 从栈中移除左括号“(".
- 10. 如果符号是“#”，则从栈中弹出所有符号并加入数组 `postfix`（“#”除外）。
- 11. 重复上述步骤，直到在扫描数组 `infix` 时遇到“#”。

# 算法

中缀表达式。使用了两个栈，push(stk, x) 表示将元素 x 入栈，pop(stk) 表示从栈中移除顶部元素。

步骤：

- 1. 开始
- 2. infix_to_prefix(Expression)
- 3. 在在中缀表达式开头添加左括号 '('
- 4. push(stk, ')')
- 5. 设置 item = Expression.scan_ch() // 从右到左扫描表达式
- 6. 当 stk1 不空时，重复步骤 7 到 28
- 7. 如果 item = 操作数
- 8. push(stk2, item)
- 9. 步骤 7 结束
- 10. 如果 item = '('
- 11. push(stk1, item)
- 12. 步骤 10 结束
- 13. 如果 item = 运算符
- 14. 设置 x = pop(stk1)
- 15. 如果 precedence(x) > precedence(item)
- 16. 当 precedence(x) > precedence(item) 时重复步骤 17 和 18
- 17. push(stk2, x)
- 18. 设置 x = pop(stk1)
- 19. 步骤 16 循环结束
- 20. 步骤 15 结束
- 21. push(stk1, x)
- 22. push(stk1, item)
- 23. 步骤 13 结束
- 24. 如果 item = '('
- 25. 设置 x = pop(stk1)
- 26. 当 x != '(' 时重复步骤 27 和 28
- 27. push(stk2, x)
- 28. 设置 x = pop(stk1)

void prefix(char a)
{
    switch(a)
    {
        case ')':
            sym[++top] = a;
            break;
        default:
            if(a == '(')
            {
                while(sym[top] != ')')
                    pre[++top] = sym[top--];
                top--;
            }
            else if(a == ')')
                sym[++top] = a;
            else if(p(a) > p(sym[top]))
                sym[++top] = a;
            else
            {
                while(p(a) < p(sym[top]))
                    pre[++top] = sym[top--];
                sym[++top] = a;
            }
    }
}

# 输出

将中缀转换为前缀表达式
输入中缀表达式:- a+b-c*/d
前缀表达式:- -+ab/*cde

以表格形式将中缀转换为前缀表达式
将中缀表达式转换为前缀表达式的步骤如下
1. 反转输入字符串。
2. 检查输入中的下一个元素。
3. 如果是运算符，将其加入输出字符串。
4. 如果是右括号，将其入栈。
5. 如果是运算符，则：
   (a) 如果栈为空，将运算符入栈。
   (b) 如果栈顶是右括号，将运算符入栈。
   (c) 如果它的优先级与栈顶相同或更高，将运算符入栈。
   (d) 否则，从栈中弹出运算符并加入输出字符串。
6. 如果是左括号，从栈中弹出运算符并加入输出字符串，直到遇到右括号。弹出并丢弃右括号。
7. 如果没有输入，则到步骤 2。
8. 如果没有更多输入，将剩余运算符入栈并加入输出字符串。
9. 反转输出字符串。
