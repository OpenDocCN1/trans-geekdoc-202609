# 3. Left-to-Right rotation (LR Rotation)

In this, unbalanced occurred during the insertion in the right sub-tree of the left child of the root node. So, this is known as left insertion. LR rotation involves two rotations for the manipulation in pointers. In other words, it is used when the new node is inserted in the right sub-tree of left sub-tree of a node A.
