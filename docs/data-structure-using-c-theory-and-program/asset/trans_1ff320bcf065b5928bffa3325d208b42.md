## 链表中的节点删除

删除操作用于从单链表中删除元素，遵循如下：
- 如果链表为空，则无法删除。
- 如果链表仅包含一个节点，删除后链表将为空。
- 如果删除了节点，被删除节点的内存空间将被释放。
- 如果删除的是头部节点，start 应自动指向下一个节点。

### 头部删除

#### 算法
1. 开始
2. 持有第一个节点的地址
3. 设置 temp = start
4. 如果 start = NULL 则
5. 写入“UNDERFLOW”（上溢）并
6. 退出
7. 设置 start = next
8. 释放与 temp 关联的空间
9. 设置 next = NULL
10. 重复步骤
11. 停止
