# 1. Left-to-Left rotation (LL Rotation)

The new node x is inserted in the left sub-tree of left sub-tree of A whose balance factor becomes + 2 after insertion. To rebalance the search tree, it is rotated to left.

# 2. Right-to-Right rotation (RR Rotation)

The new node x is inserted in the right sub-tree of right sub-tree of A whose balance factor becomes + 2 after insertion. To rebalance the search tree, it is rotated.
