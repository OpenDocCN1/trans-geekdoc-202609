# 7.13 MODIFIED WARSHALL’S ALGORITHM (SHORTEST PATH)

Let G be a directed graph with nodes $V_0, V_1, ..., V_{n-1}$, suppose G is weighted; that is, suppose each edge $e$ in $G$ is assigned a non-negative number $w(e)$ called the weighted or length of the edge. Then it may be maintained in memory by its weight matrix $W=[W_{ij}]$, defined as follows:

```
W_{ij}=\begin{cases} w(e) & \text{if there is an edge from } V_i \text{ to } V_j \\ 0 & \text{if there is no edge from } V_i \text{ to } V_j \end{cases}
```

The path matrix $P$ tells us whether or not there are path between nodes. Now we want to find a matrix $Q$ which will tell the lengths of the shortest paths between the nodes or, more exactly, a matrix $Q=[q_{ij}]$ where $q_{ij}=length of a shortest path from $V_i$ to $V_j$

Next we describe a method of Marshall’s algorithm which finds the matrix $Q$. Here we define a sequence of matrices $Q_0, Q_1, ..., Q_n$ (the described matrices $P_0, P_1, ..., P_n$ whose entries are defined as follows:

# Chapter 7 Graphs

$Q_k[i][j] = the smaller of the length of the preceding path from $V_i$ to $V_j$ or the sum of lengths of preceding paths from $V_i$ to $V_k$ and $V_k$ to $V_j$. More exactly, $Q_k[i][j] = \min(Q_{k-1}[i][j], Q_{k-1}[i][k] + Q_{k-1}[k][j])$. The initial matrix $Q_0$ is the same as weight matrix $W$ except that each 0 in $W$ is replaced by $\infty$ or a very large number. The final matrix $Q_n$ will be the desired matrix $Q$.
