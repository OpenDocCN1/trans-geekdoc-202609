# Algorithm

Steps

+   1. Start
2. Holds the address of the first node
3. Create a new node named as temp/node
4. If node = NULL then
5. Write "out of memory space" and
6. Exit
7. Set info [node] = x //copies new data into new node
8. Set next [node] = NULL
9. Set curr = start
10. Repeat steps 11 and 12 while curr ≠ NULL
11. Set prev = curr
12. Set curr = next [curr]
13. End of step 10 loop
14. Set next [prev] = node
15. Set prev [node] = prev
16. Stop
