# 2. Inorder Traversal using stack

+   The procedure for traversing a tree in in-order non-recursively is as follows:
Steps:
(i) repeat step while stack is not empty or pointer (ptr) ≠ NULL
(ii) if ptr ≠ NULL
(a) PUSH ptr on the stack
(b) ptr=left (ptr)
(iii) If ptr = NULL
(a) POP the element from the stack
(b) traverse the node
(c) ptr=right (ptr)
