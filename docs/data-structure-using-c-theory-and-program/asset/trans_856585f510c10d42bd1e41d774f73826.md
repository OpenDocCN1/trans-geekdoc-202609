## 图的分类

有几种常见的图类型：

- 有权或无权图
- 有向或无向图
- 有环或无环图

根据问题需求并由数据决定所需的类型。我们在下面对每种类型进行检查。

### 图的类型：有权与无权图

- 图可以根据边是否有权重进行分类。
- **有权图**：边具有权重
    - 权重通常表示遍历的代价
    - 示例：权重为城市之间的距离
- **无权图**：边没有权重
    - 边仅表示连接关系
    - 示例：课程先修关系

### 图的类型：有向与无向图

- 图可以根据边是否有方向进行分类。
- **无向图**：每条边都可以向**任意方向**遍历
- **有向图**：每条边**只能按指定的方向**遍历

## 无向图

- **无向图**：节点之间的边没有隐含的方向性。

## 有向图

- **有向图 (Digraph)**：边是有向的图（即有方向）
    - 边画成箭头
    - 边只能沿着箭头的方向遍历
    - 示例：$E = \{(A,B), (A,C), (A,D), (B,C), (D,C)\}$
    - 示例：课程与先修关系、程序调用图

- 在有向图中，边是一个**有序**对
    - 因此：(u,v) 和 (v,u) 不是同一条边
    - 在示例中，(D,C) ∈ E，(C,D) ∉ E
    - 边 (B,A) 看起来是什么样？记住 (A,B) ≠ (B,A)

- 节点可以有指向自身的边（例如 (A,A) 是合法的）。

## 子图

- 如果图 $G=(V, E)$
    - 如果 $V' \subseteq V$ 且 $E' \subseteq E$，则图 $G'=(V',E')$ 是 $G$ 的**子图**

## 节点的度

- 节点的**度 (degree)** 是用于定义该节点的边数量。
- 也可以定义**入度**和**出度**
    - 入度：指向节点**的**边数量
    - 出度：从节点出发的边数量

## 图：涉及路径的术语

- 路径 (Path)：顶点序列，其中每对相邻的顶点都由一条边连接。
- 环 (Cycle)：起点和终点在同一个顶点路径。
- 简单路径 (Simple path)：不自交的路径。
    - 即没有顶点重复（第一个和最后一个除外）
    - 简单路径不能包含环。
    - 路径长度：边的数量。

## 环图与无环图

- 环图 (Cyclic)：包含环的图。
    - 无环图 (Acyclic)：不包含环的图。
    - 示例：无环。

## 通连图与不连通图

- 通连图 (Connected)：任意两个顶点之间都有路径的图。
- 不连通图 (Unconnected)：不存在某些顶点之间路径的图。
    - 连通分量 (Connected Components)：不连通图分解后的连通部分。

## 树与最小生成树

- 树 (Tree)：连通且无环的图（无向图）。
    - 生成树 (Spanning Tree)：包含图中所有顶点的树。
    - 最小生成树 (MST)：在有权图中权重之和最小的生成树。
- 算法：Prim 算法和 Kruskal 算法。
