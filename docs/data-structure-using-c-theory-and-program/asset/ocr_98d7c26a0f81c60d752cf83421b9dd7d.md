# 6.13 APPLICATIONS OF HUFFMAN'S TREE

The Huffman algorithm is used to perform the encoding and decoding of a long message consisting of a set of symbols. Suppose, we want to send a message that there are two options either it sends data as fixed size or to send it as variable length size. Assume a collection of data items A1, A2, A3...........are be coded by means of strings of bits. One way to do this is to code each item by an r-bit string where, 2^r-1 < n ≤ 2^r for an example 48 character set is frequently coded in memory using 6-bit strings. One cannot use 5-bit strings since 2^5<48<2^6. Now, we discuss a coding technique using variable-length string that is based on the Huffman tree for weighted data item.

# Huffman coding

Huffman follows a bottom-up approach. Procedure is as follows:

+   1. Form the frequency list of all the symbols in the descending order.
2. Locate the two symbols in the list with the lowest frequencies. Frequencies referred as as weights.
3. Create a parent node for these two nodes whose weight is equal to the sum of weights of two child nodes.
4. Remove the two children from the list and add newly created parent node of the list along with its weight.

Example:

| Symbol | Weight |
| A | 19 |
| E | 11 |
| I | 9 |
| O | 7 |
| U | 7 |
