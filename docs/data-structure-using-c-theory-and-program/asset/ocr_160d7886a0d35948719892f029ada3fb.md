# Tree

A tree is a non linear data structure. A tree is a finite
set of one or more nodes such that:

+   There is a specially designated node called the root.

+   The remaining nodes are partitioned into n>=0
disjoint sets T1......Tn where each of these sets
is a tree. T1......Tn are called sub-tree of the root.

# Graphs

Graph is a general tree with no parent child relationship. In general, a graph
may be defined as a finite set V of vertices and a E of edge pair of connected
vertices. The notation used is as follows: graph G = (V, E).
