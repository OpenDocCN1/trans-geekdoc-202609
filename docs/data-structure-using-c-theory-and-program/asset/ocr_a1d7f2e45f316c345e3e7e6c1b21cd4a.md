# 4. Folding Method

In this method the key is interpreted as an integer using radix (say 10). The integer is divided into segments, each segment except the last having the same number of digits. These segments are added to obtain the home address.

As an example, consider the key 7612345100124. Assume we are dividing keys into segments of size 3 digits. The segments for our key are 761, 234, 510, 012, and 14. The home bucket is 761 + 234 + 510 + 012 + 14 = 1531.

In a variant of the scheme, the digit reversal are reversed before adding. This variant is called **folding at the boundaries** and the original version is called **shift folding**. Applying the folding at the boundaries method to the above example, the segments are reversed to 761, 432, 210, and 14; the home bucket is 761 + 432 + 510 + 210 + 14 = 1927.

# Hash Function for strings

Most of the strings are used as keys. It can be alphabetic or alphanumeric. Best example is the English word dictionary. Every character has some ASCII value that can be used for calculation in generating hash key value and that value can be used with modulus operation for mapping with hash table. Suppose key has alphabetic character. Let us take table size is M (95) and keys is “haram”. We add the ASCII value of each character and then apply modulus operation on this value:

```
haram = a + r + h + a + m
= 97+114+104+97+109
= 521
```

H(haram) = 521% 95 = 46

So the key “haram” can be mapped on the 46th position in the hash table. Second method we can apply, multiply each ASCII value by 127 and add all the values then de modulus operation. Let us take the key “haram” and add table size 995.

```
haram = a x 127 + r x 127 + h x 127 + a x 127 + m x 127
= 97 x 127 + 114 x 127 + 104 x 127 + 97 x 127 + 109 x 127
```
