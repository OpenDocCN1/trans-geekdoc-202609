
Figure (a) is not an almost complete binary tree because it leaves nodes at level 1, 2 and 3. So, it is violating rule 1. Figure (b) satisfies rule 1, since every leaf is either at level 2 or at level 3. However, rule 2 is violating. A has a right descendant at level 3 (J) but has a left descendant that is a leaf at level 2 (E). Figure (c) satisfies both rule 1 and 2 and is therefore an almost complete binary tree.

An almost strictly binary tree with n leaves has 2n-1 nodes and an almost complete binary tree with leaves has 2n nodes. There are two distinct almost complete binary trees with n leaves, one of which is strictly binary and one of which is not. A complete binary tree of depth d is intermediate between the complete binary tree of depth d-1 which contains $2^{d-1}-1$ nodes and the complete binary tree of depth d, which contains $2^d-1$ nodes.

## 6.7 REPRESENTATION OF A BINARY TREE

Binary trees can also be implemented in two ways: one is array and the other is linked list.

### 1. Array Representation of Binary Tree

This is also called sequential representation or linear representation or contiguous representation based on binary trees. We'll use one-dimensional array to maintain the nodes of the binary tree. We'll store the nodes in the array tree from index 1 onwards. If a node is numbered k then the data of node is stored in tree[k]. The root node is stored in tree[1] and it's left and right children in tree[2] and tree[3] and so on. We have left the index 0 empty for some other purpose.

### 2. Linked List Representation of Binary Tree

The binary tree can be represented using dynamic memory allocation of a node in a linked list form. In a linked list allocation technique a node in a tree contains three fields:

- (i) Data: left link: it contains the info value.
- (ii) Left link: it contains address of the left sub-tree.
- (iii) Right link: it contains address of the right sub-tree.

When a node has no children, the corresponding pointer fields are NULL. Here, first member data is for information field of node, second member is for left child of node which points to the structure itself; and it contains the address of left child. If node has no left child then it should be NULL. Third member is for right child of node which also points to the address of right child. If node has no right child then it should be NULL. This type of representation is dynamic block of memory. They are allocated only on demand.

## 6.8 TRAVERSING A BINARY TREE

Traversing a binary tree is the process of visiting each node in the tree exactly once in a systematic way. Unlike linear data structures in which the elements are traversed sequentially, tree is a non-linear data structure in which the elements can be traversed in many different ways. There are different algorithms for tree traversals. These algorithms differ in the order in which the nodes are visited.

### 1. Pre-order Traversal (NLR)

1. Visiting the root node.
2. Traversing the left sub-tree of root.
3. Traversing the right sub-tree of root.

### 2. In-order Traversal (LNR)

1. Traversing the left sub-tree of root.
2. Visiting the root node.
3. Traversing the right sub-tree of root.

### 3. Post-order Traversal (LRN)

1. Traversing the left sub-tree of root.
2. Traversing the right sub-tree of root.
3. Visiting the root node.

### 4. Level-order Traversal

In-order traversal, all the nodes at a level are accessed before going to the next level. This algorithm is also called as the traversal algorithm.
