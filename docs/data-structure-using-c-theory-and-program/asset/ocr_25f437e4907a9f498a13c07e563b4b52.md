Example: Suppose an array A [7] whose elements are

| 5 | 8 | 15 | 25 | 30 | 40 | 55 |
| 0 | 1 | 2 | 3 | 4 | 5 | 6 |

Suppose data = 30

Solution: Following steps are used if we use binary search to search a data = 30 in the above array.

Here n = 6

So, LB = 0, UB = 6
mid = (0+6) = 3 i.e., A[mid] = A[3] = 25

Since, A[3] < data i.e., 25 < 30.

So, reinitialise the variable LB as LB = mid +1

i.e.,nLB=3+1 =4
mid = 4+6 = 5

Now,
A[mid] = A [5] = 40

Now, < A [mid] i.e., 30 < 40

So reinitialise the variable UB = mid -1 = 5-1 =4

Now, LB =4 and UB =5
So, mid = 4+5 = 9 = 4 i.e., A[4] = 30

Since (A[mid] = data) i.e., 30 = 30

Thus searching is successful and 30 is found in the given array
