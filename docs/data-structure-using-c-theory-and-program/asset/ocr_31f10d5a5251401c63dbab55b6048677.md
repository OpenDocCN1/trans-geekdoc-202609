$a[i][j] = 1$ if $v_i$ is adjacent to $v_j$, that is, if there is an edge between $v_i$ and $v_j$ 0 if there is no edge between $v_i$ and $v_j$

Example:

Let us take a directed graph

![](bbox=[0.375, 0.243, 0.624, 0.363])

The corresponding adjacency matrix for this directed graph will be:

| v1 | v2 | v3 | v4 |
|---|---|---|--|
| 0 | 1 | 0 | 1 |
| 1 | 0 | 1 | 1 |
| 0 | 0 | 0 | 1 |
| 1 | 0 | 1 | 0 |

Let us take an undirected graph

![](bbox=[0.375, 0.543, 0.624, 0.663])

The corresponding adjacency matrix for this graph will be:

| v1 | v2 | v3 | v4 |
|---|---|---|--|
| 0 | 1 | 1 | 1 |
| 1 | 0 | 1 | 1 |
| 1 | 1 | 0 | 1 |
| 1 | 1 | 1 | 0 |

The matrix contains only of 0 and 1, so the matrix is called a bit matrix or Boolean matrix. When constructing an adjacency matrix for a graph, one must follow the following points:

+   (a) Adjacency matrix A does not depend on the ordering of the vertex of a graph G, that is, different ordering of the vertices may result in a different adjacency matrix. One can obtain the same matrix by interchanging rows and columns.
