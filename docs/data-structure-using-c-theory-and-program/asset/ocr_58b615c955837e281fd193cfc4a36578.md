# Hashing with Double Hashing

Double hashing uses the idea of applying a second hash function to the key when a collision occurs. The result of the second hash function will be the number of positions from the point of collision to insert.

There are a couple of requirements for the second function:

+   - it never evaluate to 0
- must make sure that all cells can be probed

A popular hash function is: Hash2(key) = R - ( key % R ) where R is a prime number that is smaller than the size of the table.

# 9.10 HASHING WITH REHASHING

Once the hash table gets too full, the running time for operations start to take too long and may fail. To solve this problem, a table at least twice the size of the original will be built and the elements will be transferred to the new table.

The new size of the hash table:

+   - should be prime
- will be used to calculate the new insertion spot (and the name rehashing) This is a very expensive operation! O (N) since there are N elements to rehash and the table size is roughly 2N. This is ok though it doesn't happen often.
