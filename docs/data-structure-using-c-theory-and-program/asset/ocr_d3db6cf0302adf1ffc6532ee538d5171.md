# c. Deleting a node into the linked list

The deletion operation is used to delete an element from a single linked list, one should remember the following points.

+   * If the list is empty, deletion is not possible.
* If the list contains only one node, after deletion the list will be empty.
* If the node is deleted, the memory space for the deleted node is de-allocated.
* If beginning node is deleted start should point to the next node automatically.
