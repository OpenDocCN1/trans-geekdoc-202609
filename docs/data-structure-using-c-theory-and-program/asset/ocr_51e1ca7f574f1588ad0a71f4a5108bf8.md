The first collision occurs when 49 hashes to the same location as 9. Since 89 occupies the A[9], we need to place 49 to the next available position. Considering the array as circular, the next available position is 0. That is (9+1) 10. So we place 49 in A[0]. Several more collisions occur in this simple example and in each case we keep looking to find the next available location in the array to place the element. However, if we need to find the element, for example, 49, we first compute hash code of 79 = 9. We probe in A[9], A(9+1)%10=A[0], A(9+2)%10=A[1], A(9+3)%10=A[2], A(9+4)%10=A[3]. Since A[3]=null, we know that 79 could not exist in the set.

# 2. Quadratic probing

Although linear probing is a simple process where it is easier to compute the next location, linear probing also leads to clustering when keys are computed to closer values. Therefore, we define a new process of Quadratic probing that provides a better distribution of keys when collisions occur. In quadratic probing, if the hash value is K, then the next location is computed using the sequence K + 1, K + 4, K + 9 ..
