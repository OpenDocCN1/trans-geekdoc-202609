# Algorithm

Steps

+   1. Start
2. Holds the address of the first node.
3. Set node = start
4. Set temp = start
5. If node = NULL then
6. Write “UNDERFLOW” and
7. Exit
8. Set i = 1
9. Read loc
10. Repeat steps 11 to 13 while node ≠ NULL and i < loc
11. Set temp = node
12. Set node = next [node]
13. Set i = i+1
14. End of step 10 loop
15. If node = NULL then
16. Write “position not found” and
17. Exit
18. Set next [temp] = next [node]
19. Free the space associated with node
20. Stop
