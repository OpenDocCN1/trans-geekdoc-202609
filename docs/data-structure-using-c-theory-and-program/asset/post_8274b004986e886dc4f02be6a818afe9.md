## Deleting a node into linked list

The deletion operation is used to delete an element from a single linked list, following:
- If the list is empty, deletion is not possible.
- If the list contains only one node, after deletion the list will be empty.
- If the node is deleted, the memory space for the deleted node is deallocated.
- If beginning node is deleted, start should point to the next node automatically.

### Deletion at beginning

#### Algorithm
1. Start
2. Holds address of the first node.
3. Set temp = start
4. If start = NULL then
5. Write "UNDERFLOW" and
6. Exit
7. Set start = next
8. Free the space associated with temp
9. Set next = NULL
10. Repeat steps
11. Stop
