# 2. Pre-order traversal in Threaded Binary Tree:

In-order traversal we will start traversing from the left child of the header node. If the node has a left child then left child will be traversed, otherwise if the node has a right child, then right child will be traversed. If the node has neither left nor right child then with the help of right threads we will reach that in-order successor of the node which has a right sub-tree. Now, this sub-tree will be traversed as pre-order.
