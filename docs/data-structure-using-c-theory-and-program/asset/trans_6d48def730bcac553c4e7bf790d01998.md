

# 定义

栈（Stack）是一种同质数据元素的有序集合，插入和删除只发生在其中一端。这一端通常被称为栈顶（top of the stack）。在这里，最后插入的元素将是栈顶。由于删除是从同一个端进行的，因此最后一个元素将是第一个从栈中移除的，依此类推。这就是为什么栈也被称为后进先出（LIFO）。

最初，使用数组创建栈时，其大小是固定的，而栈顶的位置会增加。因此，栈中最频繁访问的元素是栈顶，而最后访问的元素是栈底。

# 4.2 栈的操作

栈通常通过两个基本操作来实现，如 PUSH（入栈）和 POP（出栈）。

- 1. PUSH 操作
- 2. POP 操作

# 1. PUSH 操作

向栈顶添加新元素的过程称为 push 操作。在栈中推入一个元素会触发在栈顶添加该元素的操作。假设在插入一个元素后达到了最大尺寸，即栈已满。这种情况被称为栈溢出（stack overflow）。此时，栈处于栈最高的位置。初始时栈是空的，它有一个指针即 TOP。

# PUSH 操作算法

步骤：
1. 开始
2. 如果 top=maxsize-1 则
3. 打印消息“栈溢出（OVERFLOW）”然后
4. 停止
5. 读取数据
6. top=top+1

- 7. stack[top]=data

# 2. POP 操作

从栈顶删除元素的过程称为 pop 操作。每次 pop 操作后，栈的大小减 1。最后，当所有元素都被删除后，top 指向栈底。当栈空时，无法删除任何元素，这种情况被称为栈下空（stack underflow）。因此，如果 POP 操作栈上没有元素且执行了 Pop 操作，将导致：

- 1) 弹出 'A'
- 2) 推入 'H'

# 栈下空（UNDERFLOW）状态。

| 4-Top | 'H' |
|---|---|
| A | 4 |
| H | 3-Top |
| L | 2 |
| L | 2-Top |
| A | 1 |
| T | 0 |

| Top-1 | Top-1 |
|---|---|
| =4-1 | =3-1 |
| =3 | =2 |
| =2 | =1 |

步骤：
- 1. 开始
- 2. 如果 top==1 则
- 3. 打印消息“栈空（UNDERFLOW）”然后
- 3) 推入 'L'
- 4) 推入 'A'
- 5) 推入 'T'

|---|---|---|
| T | 3 | 3 |

|---|---|---|

# 4.3 栈的实现

栈可以用数组或链表实现。

# 数组实现

栈是同质元素的有序集合。C语言已经包含了同质元素的有序集合类型。数组中的元素数量是固定的。另一方面，栈是一个动态对象，其尺寸随着元素的推入和弹出不断变化。然而，数组可以实现栈。

使用数组实现栈的操作程序：

```
#include<stdio.h>
#include<stdlib.h>
#define MAX_SIZE 5
int stack[MAX_SIZE];
int top = -1;

void push(int value);
int pop();
void traverse();
int is_empty();
int top_element();

void main()
{
    int element, choice;
    while(1)
    {
        printf("栈操作。\n");
        printf("1. 入栈（Push 操作）。\n");
        printf("2. 出栈（Pop 操作）。\n");
        printf("3. 打印栈顶元素。\n");
        printf("4. 检查栈是否为空。\n");
        printf("5. 遍历栈。\n");
        printf("6. 退出。\n");
        printf("输入您的选择：\n");
        scanf("%d",&choice);
        switch ( choice )
        {
            case 1:
            if ( top == MAX_SIZE - 1 )
                printf("溢出\n");
            else
            {
                printf("要插入的值：\n");
                scanf("%d",&element);
                push(element);
            }
            break;
            case 2:
            if ( top == -1 )
                printf("下空\n");
            else
            {
                element = pop();
                printf("从栈移除的元素是: %d\n", element);
            }
            break;
            case 3:
            if(!is_empty())
            {
                element = top_element();
                printf("栈顶元素是: %d\n", element);
            } else
                printf("栈为空。\n");
            break;
            case 4:
            if(is_empty())
                printf("栈为空。\n");
            else
                printf("栈不为空。\n");
            break;
            case 5:
            traverse();
            break;
            case 6:
            exit(0);
        }
    }
}
void push(int value)
{
  top++;
  stack[top] = value;
}
int pop() 
{
  int element;
  if ( top == -1 )
    return -1;
  element = stack[top];
  top--;
  return element;
}
void traverse() {
  if ( top == -1 ) {
    printf("栈为空。\n");
    return;
  }
  printf("栈中有 %d 个元素。\n", top+1);
  for (int d = top ; d >= 0 ; d--) {
    printf("%d\n", stack[d]);
  }
  printf("\n");
}
int is_empty() {
  if ( top == -1 ) {
    return 1;
  } else {
    return 0;
  }
}
int top_element() {
  return stack[top];
}
```
