# 8.10 HEAP SORT

Heap sort was invented by John Williams and uses the approach opposite to selection sort. The selection sorts the smallest element among n elements, then the smallest element among n-1 elements and so on, until the end of the array where heap sort finds the largest element and puts it at the end of the array, the second largest item is found and this process is repeated for all other elements. Before discussing heap sort, we will begin by defining a new structure, the heap. We can define minimum heap and maximum heap. A **max (or min) heap** is a complete binary tree with the property that the value at each node is at least large as (or as small as) the values of its children (if they exist).
