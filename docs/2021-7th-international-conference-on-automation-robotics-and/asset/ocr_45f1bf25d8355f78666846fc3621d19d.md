predicted distances to find the intersection points and used the Geometric median of these points as the final location estimation. Our system does not require any kind of grid in the indoor space layout and it is shown to achieve an average error of 69.58cm. Overall the user position was estimated with a localization error below 1m in 80,55% of all cases.

# VIII. FUTURE WORK

Our next steps will be to test our model in a larger area with a more complex environment and with more Bluetooth beacons. A potential approach to increase scalability would be to extend our system by adding a phase before phase one. In this new phase (phase zero) the system will read the RSSI values from all Bluetooth Beacons and will decide which Beacons to use in phase one.
