# 31 引言

**统计机器学习** 指的是一组强大的自动化算法，用于基于多个预测变量预测结果变量。算法通过从数据中“学习”自动提高性能，即它们是数据驱动的，不寻求对数据施加线性或其他整体结构（P. Bruce and Bruce [2017](#text00039.html#ref-bruce2017)）。这意味着它们是非参数的。

不同的机器学习方法可用于以下两种情况：

*   **分类**，其中结果变量是分类变量，例如阳性 vs 阴性
*   以及 **回归**，其中结果变量是连续变量。

在本部分中，我们将介绍以下方法：

*   **K-最近邻**，它将新观测值 `x` 的结果预测为与 `x` 最相似的 `k` 个观测值的平均结果（第 [32](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章）。
*   **决策树**，它构建描述预测变量与结果之间关系的决策规则集。这些规则用于预测新观测值的结果（第 [33](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章）。
*   **集成学习**，包括 **装袋**、**随机森林** 和 **提升**。这些机器学习算法基于决策树。它们从训练数据集中生成许多树模型，并使用平均值作为预测模型。这导致了顶级的预测建模技术。参见第 [34](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章和 [35](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX)。

# 32 KNN - k-最近邻

## 32.1 引言

**k-最近邻**（**KNN**）算法是一种简单的 *机器学习* 方法，可用于分类和回归。kNN 算法通过将其与训练数据集中 `k` 个相似案例进行比较来预测新观测值的结果，其中 `k` 由分析师定义。

在本章中，我们首先介绍 KNN 算法在分类和回归设置中的基础知识。接下来，我们提供在 *R* 中准备数据和计算 KNN 模型的实际示例。

此外，你将学习如何进行预测并评估所构建模型在预测新测试观测值结果方面的性能。

## 32.2 KNN 算法

*   **分类的 KNN 算法**：

为了对给定的新观测值（`new_obs`）进行分类，k-最近邻方法首先识别与我们的 `new_obs` 最相似的 `k` 个训练观测值（即邻居），然后将 `new_obs` 分配给其邻居占多数的类别。

*   **回归的 KNN 算法**：

同样，为了预测给定新观测值（`new_obs`）的连续结果值，KNN 算法计算与 `new_obs` 最相似的 `k` 个训练观测值的平均结果值，并将该值作为 `new_obs` 的预测结果值返回。

*   **相似性度量**：
