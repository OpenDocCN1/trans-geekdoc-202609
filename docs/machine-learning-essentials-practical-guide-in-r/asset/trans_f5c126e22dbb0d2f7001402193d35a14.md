# 3 引言

`Regression analysis`（或 `regression model`）由一组 *machine learning* 方法组成，允许我们基于一个或多个预测变量（`x`）的值来预测连续结果变量（`y`）。

简而言之，回归模型的目的是建立一个数学方程，将 `y` 定义为 `x` 变量的函数。接下来，该方程可用于基于预测变量（`x`）的新值来预测结果（`y`）。

`Linear regression` 是预测连续变量最简单、最流行的技术。它假设结果与预测变量之间存在线性关系。参见第 [4](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章。

线性回归方程可以写成 `y = b0 + b*x`，其中：

*   `b0` 是截距，
*   `b` 是与预测变量 `x` 相关的回归权重或系数。

从技术上讲，线性回归系数是这样确定的，使得预测结果值的误差最小化。这种计算 beta 系数的方法称为 `Ordinary Least Squares` 方法。

当你有多个预测变量时，例如 `x1` 和 `x2`，回归方程可以写成 `y = b0 + b1*x1 + b2*x2`。在某些情况下，一些预测变量之间可能存在 `interaction effect`，也就是说，例如，增加预测变量 `x1` 的值可能会提高预测变量 `x2` 在解释结果变量变化方面的有效性。参见第 [5](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章。

还要注意，线性回归模型可以同时包含连续和 `categorical predictor variables`。参见第 [6](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章。

当你构建线性回归模型时，你需要 `diagnostic` 线性模型是否适合你的数据。参见第 [9](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章。

在某些情况下，结果与预测变量之间的关系不是线性的。在这些情况下，你需要构建 `non-linear regression`，例如 *polynomial and spline regression*。参见第 [7](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章。

当回归模型中有多个预测变量时，你可能希望选择最佳的预测变量组合来构建最佳预测模型。此过程称为 `model selection`，包括比较包含不同预测变量集的多个模型，以便选择性能最佳且预测误差最小的模型。线性模型选择方法包括 `best subsets regression`（第 [17](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章）和 `stepwise regression`（第 [18](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章）

在某些情况下，例如在基因组学领域，你可能拥有包含一些相关预测变量的大型多变量数据集。在这种情况下，原始数据集中的信息可以汇总为少数新变量（称为主成分），它们是原始变量的线性组合。这些少数主成分可用于构建线性模型，这可能对你的数据更有效。这种方法被称为 `principal component-based methods`（第 [20](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章），其中包括：`principal component regression` 和 `partial least squares regression`。

简化大型多变量模型的另一种方法是使用 `penalized regression`（第 [19](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章），它对模型拥有过多变量进行惩罚。最著名的惩罚回归包括 `ridge regression` 和 `lasso regression`。

你可以将所有这些不同的回归模型应用于你的数据，比较模型并最终选择解释数据良好的最佳方法。为此，你需要一些统计指标来比较不同模型在解释数据和预测新测试数据结果方面的性能。
