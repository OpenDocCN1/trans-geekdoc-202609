# 16 引言

当预测模型中存在许多预测变量时，`model selection` 方法允许自动选择构建最优预测模型的预测变量的最佳组合。

去除不相关的变量会使模型更易解释且更简单。在性能相同的情况下，应始终优先使用更简单的模型而不是更复杂的模型。

此外，在某些情况下，使用模型选择方法至关重要，此时你拥有包含许多预测变量的大型多变量数据集。这在基因组学领域经常出现，其中一个重大挑战在于基因组变量的数量（`p`）通常远大于个体数量（`n`）（即 `p >> n`）（Bovelstad et al. [2007](#text00039.html#ref-bovelstad2007) ）。

众所周知，当 `p >> n` 时，很容易找到在拟合数据上表现优异但在外部验证中失败的预测因子，从而导致预测规则不佳。此外，最小二乘拟合中可能存在大量变异，导致过拟合，从而对未用于模型训练的未来观测产生较差的预测（James et al. [2014](#text00039.html#ref-james2014) ）。

一种可能的策略是对预测因子的所有可能组合进行测试，然后选择最佳模型。该方法称为 `best subsets regression`（第 [17](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章），计算成本高昂，对于具有大量变量的大型数据集变得不可行。

比最佳子集回归更好的替代方法是使用 `stepwise regression`（第 [18](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章）方法，该方法通过添加和删除预测因子来寻找具有减少变量集的最佳性能模型。

用于高维数据、包含多个预测变量的其他方法包括 `penalized regression`（岭回归和套索回归，第 [19](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章）和 `principal components-based regression methods`（PCR 和 PLS，第 [20](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章）。

在本部分，我们将介绍三种不同类别的方法，用于为大型多变量数据选择最优线性模型。这些包括：

* Best subsets selection (Chapter [17](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) )
* Stepwise selection (Chapter [18](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) )
* Penalized regression (or shrinkage methods) (Chapter [19](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) )

## 17.5 选择最优模型

要回答这个问题，你需要一些统计指标或策略来比较模型的整体性能并选择最佳模型。你需要估计每个模型的预测误差并选择预测误差较低的模型。

### 17.5.1 模型选择标准：Adjusted R2、Cp 和 BIC

`summary()` 函数返回一些指标 - Adjusted R2、Cp 和 BIC（见第 [13](XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX) 章） - 允许我们识别整体最佳模型，其中最佳定义为使调整后 R2 最大化并使预测误差（RSS、cp 和 BIC）最小化的模型。

调整后 R2 表示结果变异中由预测变量值变异解释的比例。调整后 R2 越高，模型越好。
