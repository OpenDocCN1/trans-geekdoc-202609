# 7.2. Evaluation metrics

The $R^2$, MAE, and MSE were used to evaluate the Transformer performance for $PM_{2.5}$ concentration prediction. The $R^2$ and $R'$ values are in the range of [0, 1] and serve as metrics on the regression model's performance in explaining the data variance. The closer the metrics are to 1, the better the model performance in explaining the variance of the $PM_{2.5}$ concentration among different air pollution and meteorological conditions, i.e., the smaller the metrics, the worse the model performance. These metrics are calculated as follows:

```
$explained\variance(y, \hat{y}) = \frac{Var(\hat{y})}{Var(y)} - 1$
```

```
$R^2 = \frac{\sum_{i=1}^{n} (y_i - \hat{y}_i)^2}{\sum_{i=1}^{n} (y_i - \bar{y})^2}$
```

where $\hat{y}$ is a y-estimated output, and $Var$ is the variance. The closer the value is to the optimal score of 1, the more accurate the prediction.

Regarding MAE and MSE, they are used to assess the degree of closeness to the predicted data, which is used to calculate the value of the sum of errors between the fitted data and theing data. The smaller of the two values, the better the prediction result. These two metrics are calculated as follows:

```
$MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$
```

```
$MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$
```

# 3. Results and discussion

# 3.1. Training and results

The parameters of the Transformer and CNN-LSTM models were determined through several rounds of training. (1) For the Transformer, the number of layers is 5, hidden heads 9, hidden units 6, and dropout 0.1. (2) For the CNN-LSTM model, it was constructed using parallel stacking of a CNN unit, an attention unit, and an LSTM unit with a hidden size of 3 and 5 depth of each, the LSTM unit having a step size of 5. A mean-squared-error loss function was used for the output layer of the model, and the Adam optimizer with a learning rate of 0.003 was used to calculate the loss and optimization. The learning rate of the model was decayed during the training process, to ensure that the learning rate is promptly reduced when the model no longer improves its access to the loss function.
