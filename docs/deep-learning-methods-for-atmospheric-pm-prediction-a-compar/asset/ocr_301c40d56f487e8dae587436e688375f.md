# 2.5.1. Positional encoding

A Transformer differs from convolutional and recurrent NNs in that it uses a novel positional encoding mechanism to capture the time series information of the input data. Sine and cosine functions of various frequencies are embedded into the normalized input sequences for encoding:

```
$Attention(Q, K, V) = softmax(\frac{QK^T}{\sqrt{d_k}})V$ (5)
```

Next, Q and K are used to compute the vector dot product, $QK^T$, where $d_k$ is the dimension of the key (K). The input sequence is down-sampled using the embedding layers to obtain $(a_1, a_2, ..., a_n)$, which are multiplied by $W^Q, W^K, W^V$ to obtain $q_1, q_2, ..., q_n$, $k_1, k_2, ..., k_n$, and $v_1, v_2, ..., v_n$.
