# I. 引言

电力调度调控系统是指基于计算机和技术，基于通信和数据网络，用于监控电力生产和供应的业务系统智能化设备。理论 [2] 定义为：整体安全水平由网络防护水平决定。电力调度调控系统的安全防护非常有必要，以防止黑客利用各种工具利用噪声漏洞并恶意入侵企业系统，实施攻击和破坏，从而从根本上导致电力调度调控系统故障，并损害电网的运行和生产。网络安全防护系统已建立；安全防护；应急备份措施和全面安全管理 [3] 在过去的几十年里，从静态部署向动态控制的转变得到了不断改进。

应急备份措施从冗余备份和应急调度两个方面采取。当电网中的电力调度调控系统遇到异常或非法攻击或网络攻击时，监控系统将向上级调度监管单位报告，并采取应急措施进行处置，从外部到内部形成多线防御。

全面安全维度包括人员安全管理、设备安全管理、管理制度安全管理。通过这种全面的安全防护和管理，形成了一个覆盖广泛的安全防护体系，其管理体系、技术体系和应急响应系统协同工作。

## A. 安全分析与发展现状

电力调度调控系统对于电力供应的稳定安全运行至关重要。随着网络规模的快速扩大和网络安全的融合，电力调度调控系统的网络管理和控制变得更加复杂。从国际角度来看，全球发生的网络战争日益增加，来自网络空间的对抗和网络攻击愈发频繁。这些攻击使用了多种隐蔽手段和获取证据的战术，会影响企业的声誉、生产和经营，甚至对国家安全产生重大影响。随着电网的发展，以及伊朗核电站的瘫痪一直是网络战争的重要目标，一直处于网络攻击和破坏的最前沿。

安全技术维度包括基础设施安全、系统结构安全、本体安全和安全免疫。首先，从机房、电源、通信、屏蔽和认证等方面确保基础安全。其次，基于安全网络防护策略，通过专用化、横向隔离 [4] 和垂直加密，保证系统结构的安全。第三，实现

国家电网公司根据“安全分区、组网防御、横向隔离、认证加密”的总体策略，在五级电力调度站、各变电站和电厂建立了全面的电力调度防护系统。从安全技术、应急备份等方面，构建了安全防护体系，取得了良好的防护效果。

国家电网公司自主开发了电力调度网络安全管理系统，实现了安全漏洞的自动化检测和主动防护，但仍需手动或定期触发进行安全检查。该安全防护系统在调度站上方实现了实时监控网络安全告警，平台构建了感知、决策和控制的三层逻辑结构。

# II. 当前主要问题

+ 1. 告警有效性令人担忧，平台功能存在
现有的网络管理功能处于碎片化状态，特别是告警平台，难以快速定位问题值，安全管理人员需要单独查看数据来判断形势。

+ 2) 自感知：实现对安全数据的网络监控。

+ 3) 分布式采集：利用监控设备实现对调度站、电厂、配电网以及通信交互设备的网络采集；管理平台实现了监控、审计和验证等功能的集成。安全监控功能可以实时监控主机和其他设备的运行状态、用户登录、操作和管理。安全告警、照明等方法监控网络安全威胁和安全告警事件，如不符合安全操作的登录行为；安全主要分析安全指标。

+ B. 需要全面的数据分析和处理能力
安全监控数据量日益增长。平台难以有效存储和整合各设备产生的异构信息，导致分析数据来源单一，大规模数据关联效率低。难以快速发现全局和局部信息。因此，无法满足安全态势感知的需求，智能化告警分析和过滤决策辅助程度不高。

+ C. 缺乏智能学习和决策辅助功能
在网络异常时，平台缺乏特征识别和自主学习能力，无法有效直观地展示现状，无法在大范围内检测和防御零日漏洞和APT攻击，维持访问和安全

当发生重大安全事件时，人员难以依靠技术管理和控制手段对会话、主机甚至整个中心网络进行多级处理拦截。需要手动组织设备进行相关操作。无法满足快速隔离威胁和遏制扩散的应急需求。





# III. 智能化分析管理控制策略

## A. 资产评估评分

利用现有网络安全平台获取和收集的数据资源，通过对资产的运行状态、漏洞扫描、弱密码检查、当前威胁和异常行为进行全面分析并进行评估评分。为网络安全和运维人员提供关键信息，以实现威胁评估和安全有效控制的目标。

通过综合静态评估和动态评估两条路径，对全网空间的所有资产进行评分，结合资产分配和控制系统，可以对整个网络空间进行整体评估。

评分关系是指通过不同的因素和静态信息（如资产漏洞、基线配置和密码扫描）进行考虑和权重。为了建立完整的库，定期进行审计和配置实施，实施扣分制度，根据资产的权重和漏洞、人工评估、实际情况，解决问题规模难以区分的问题，并灵活地进行安全加固。在漏洞收集方面，通过互联网上的各种开源组织和商业机构（天翼用城、Webhh Online、FutureHub 等）以及国外权威（CVE、CND、CNNVD）收集外部情报。内部情报则是国家防御系统发布的各种预警指令。基于知识库，可以预测漏洞的危害，并提出通用的管理解决方案。

## B. 攻击分析模型

集成已部署的安全设备收集攻击相关信息，通过关联分析、行为关联分析、动态基线、分析等方法处理攻击信息，获取攻击程度、攻击方法和攻击范围。同时，基于知识信息，处置人员可以获得攻击处理建议，作为加固策略、软件补丁升级，并指出应急方案相应的场景和解决方案。
