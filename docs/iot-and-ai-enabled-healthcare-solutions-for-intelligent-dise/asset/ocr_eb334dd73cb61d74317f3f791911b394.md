# ## 4.3 Evaluation Metrics

The accuracy of the proposed method is evaluated using three metrics: accuracy, sensitivity, and specificity. Their respective formulas are given in Equations 1–3.

Accuracy = \frac{True Positive + True Negative}{True Positive + True Negative + False Positive + False Negative} (1)

Sensitivity = \frac{True Positive}{True Positive + False Positive} (2)

Specificity = \frac{True Negative}{True Negative + False Positive} (3)
