# 15.4.3 CLEFIA

CLEFIA is an example of efficient and highly secure block cipher developed by SONY. It delivers advanced copyright protection and authentication. CLEFIA has a block size of 128 bits and key sizes of 128 bits, 192 bits, or 256 bits. Figure 15.4 describes the entire working procedure of a CLEFIA cipher. CLEFIA maintains a high-level security in implementation strategy of both world-leading hardware and software. It gives the highest hardware gate efficiency when it is implemented in hardware.
