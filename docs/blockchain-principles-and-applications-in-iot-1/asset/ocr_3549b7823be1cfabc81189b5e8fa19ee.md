# 7.7 Challenges and Scope for Future Work

Using blockchain opens up new opportunities in the field of IoT, but such systems have their own challenges.

+   1. Storage Space: Storage space is a big concern when it comes to IoT setups. Because of the nature of the blockchain, the total storage needed to store the entire blockchain always increases. If the entire blockchain is to be stored in each IoT device acting as a node, it is feasible because the limited amount of storage space available for IoT devices. There is a need for a smarter solution wherein it is possible to access the data stored in the blockchain without using excessive storage space.
