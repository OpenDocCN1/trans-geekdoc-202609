# 15.7.2 CoAP

An application layer protocol, CoAP (constrained application protocol) is treated as the base of data communication for the World Wide Web. It is a specialized web transfer protocol applicable to both constrained nodes and networks in IoT with low bandwidth and low availability. Internet Engineering Task Force designed the protocol.
