# 6.6 物联网的功能视图

物联网系统由几个协同工作以提供所需功能的层组成。层包括：

- 感知层：该层由与物理环境交互的传感器和执行器组成。
- 网络层：负责将感知层收集的数据传输到应用层。
- 应用层：该层为终端用户提供服务。

这些层之间的交互对于物联网系统的正常运行至关重要。例如，当感知层检测到环境变化时，它将数据发送到网络层，然后将数据转发到应用层。应用层随后处理数据并向用户提供相应的响应。

物联网系统的安全性也是一个主要关注的问题。由于 IoT 设备连接到互联网，它们容易受到各种攻击。实施健壮的安全措施来保护数据和设备是非常重要的。这些措施包括：

- 加密保护数据免受未经的访问。
- 验证确保只有授权用户可以访问系统。
- 入检测和防御以识别并响应潜在攻击。

- 信息违规的访问控制。这是用途调控，根据预定义的原则确保特定数据的正确使用，允许访问数据 [7]。

网络层负责将感知层收集的数据传输到应用层。这可以使用各种通信技术实现，如 Wi-Fi、蓝牙和蜂窝网络。

用户的响应。这些层之间的交互对于物联网系统的正常运行至关重要。物联网系统的安全性也是一个主要关注的问题。例如：

1. 货物质量：对容器开启、振动、冲击或任何损坏进行监控。
2. NFC 支付：通过提供基于位置或时间的商家银行或收单机构链接，使商户能够在线获得贷记支付，完成公共交通、博物馆、画廊等活动。
3. 物体定位：在仓库或港口等大型位置搜索单个物体。
4. 监控车队车辆和资产活动：珠宝、药品或危险材料等关键资产的路线控制。
5. 存储无冲突发现：警报排放易燃材料且靠近持有爆炸物的容器。
6. 汽车管理：汽车共享组织使用手机运行车辆，每辆车没有固定连接。
7. 自动车辆诊断：从 CAN 总线收集数据以向立即风险发送实时警报，或向驾驶车辆的人员提供建议（图 6.8）。
