

## 轻量级加密与协议

## 15.3 工作动机

今天，我们的世界正在快速向智能化和快速化的时代转变。在这个智能世界中，海量的智能设备连接在一起，以实现人与机或人与人之间的通信，从而更快速、更安全地传输数据。但智能环境的限制强化了另一个理念，即轻量级加密的概念。美国国家标准与技术研究院（NIST）和国际标准化组织/国际电工委员会（ISO/IEC）针对物联网领域标准化了多种轻量级加密方法。为了在考虑所有限制的情况下维持安全性，各种轻量级原语和协议应运而生。

在轻量级加密方面，ISO/IEC 29192-5:2016 将 PHOTON 和 SPONGENT 标准为标准哈希方法，ISO/IEC 29192-2:2012 将 PRESENT 和 CLEFIA 为标准块加密方法。流密码 Trivium 被 ISO/IEC 29192-3:2012 选中。本文讨论了这些标准方法。其他方法根据其在行业内的广泛认可而被选取。三种轻量级协议的选择是基于瞬时数据传输的强度、行业使用的变异性或对多播的支持程度。

## 15.4 轻量级块加密

重要的轻量级加密原语之一是轻量级块加密。轻量级块加密属于对称加密分类，在固定长度的位上操作。该原语包含简单的操作。使用两种网络来实现此类加密算法：一种是代换-置换网络（SPN），另一种是 Feistel 网络。SPN 在每轮中使用代换盒（S-盒）和置换盒（P-盒）来实现网络。通过与密钥的某些数学运算可以将一个明文块转换为密文块。Feistel 加密的优势在于其对称结构。在这里，加密函数和解密函数除了密钥调度方法外几乎相同。在这里，为了实现低延迟，实现代码可以减少 50%。下面讨论了部分流行的轻量级块加密。

### 15.4.1 PRESENT

一种超轻量级块加密 PRESENT [9] 基于代换-置换网络（SPN）结构。它包含 31 轮迭代，包括 64 位的块大小。PRESENT 支持 80 位和 128 位密钥变体。该加密算法每轮有三个不同的层。图 15.2 显示了 PRESENT 加密的框图（包括各层）。

代换层：这第一层由 16 个 S 盒组成，每个 S 盒有 4 位输入和 4 位输出；在这里执行了 16 次并行的 4 位 S 盒应用。

![](img/accfea9a01c34cc061afd3c9ae34e481_294_0.png)

图 15.2
PRESENT 块加密的框图。

置换层：这是 PRESENT 轮的第二层。它执行 64 位的逐位置换。这是一种简单且涉及位规则变换的传输技术。根据置换层表，每个位被传输到固定位置。
加轮密钥：加法层是 PRESENT 加密的最后一层。在这一层中，轮密钥与 64 位输入文本进行异或（XOR）运算。它涉及对 80 位密钥寄存器进行 61 位左移。然后向 S 盒加载四个重要位。最后，最后一轮与 K 的位（K19 K18 K17 K16 K15）进行异或运算。因此，在每个加密过程中，加轮层使用更新后的密钥。

使 PRESENT 在硬件实现中更快、更紧凑的三大要素是：1) 4 位 S 盒，2) 逐位置换，以及 3) 异或（XOR）运算。

### 15.4.2 TEA

TEA加密算法正如其名是一种简单、安全且快速的块加密。它是保护加密所需的存储空间最小。TEA 表现出良好的差分分析。经过几轮后，它实现了完全扩散。TEA 使用 64 位块作为输入和128 位密钥。它执行 32 轮操作。图 15.3 显示了 TEA 加密的流程：

- i. 该加密将 64 位输入数据分为两个 32 位块。
- ii. 接下来，将 128 位密钥分为四个32 位的子密钥 K[i]，其中 0 < i = 3。它使用整数常量 delta（$2^{32}$/黄金比例）。在这里，取 128 位密钥作为输入。每次迭代使用 delta 的倍数（mod $2^{32}$）和加法运算。
- iii. 首先，右半执行 4 位左移并与 K[0] 相加。

![](img/accfea9a01c34cc061afd3c9ae34e481_295_0.png)

图 15.3
单轮 TEA 加密的框图。

再次，右半加 delta。右半再次执行 5 位右移并与 K[1] 相加。然后将这些操作的输出加到 L（L−1）。相同的操作重复用于下一半 L[i−1]。

### 15.4.3 CLEFIA

CLEFIA 是 Sony 开发的一种高效且高安全的块加密示例。它提供了高级保护和认证。CLEFIA 的块大小为 128 位，密钥大小为 128 位、192 位或 256 位。图 15.4 描述了 CLEFIA 加密的工作流程。CLEFIA 在硬件和软件实现中均能维持高水平安全性。

## 15.5 轻量级流加密

另一种轻量级原语是轻量级流加密。这种类型的加密密钥与数据相当。欧洲密码学组织了 eSTREAM 竞赛，寻找适用于广泛采用的新加密算法。在流加密中，明文、初始化向量和密钥共同执行异或以生成加密。这种位操作流加密可能更紧凑。流加密的硬件实现比块加密简单得多。流加密通常使用两种移位器：一种是线性反馈移位器（LFSR），另一种是非反馈移位器（NLFSR）。流加密原语广泛用于手机、无线通信等。本文讨论了三种流行的加密算法：GRAIN、TRIVIUM 和 MICKEY。GRAIN 系列加密被广泛使用并具有更大的实现灵活性。GRAIN-128 AEAD 版本支持认证。TRIVIUM [10] 也很流行，但它仅支持 80 位密钥。MICKEY [11,12] 相比 GRAIN 和 TRIVIUM 较少。由于不规则时钟，它的实现灵活性较低。

### 15.5.1 GRAIN V1

GRAIN 加密体的框图。

GRAIN v1，密钥大小 = 80 位，m = 64。LFSR 多项式 f1(m) 为：

$f1(m) = 1 + m^{18} + m^{29} + m^{42} + m^{57} + m^{67} + m^{80}$ (15.1)

NFSR 的反馈多项式函数 g1(m) 定义为：

$g(m) = 1 + m^{18} + m^{20} + m^{28} + m^{35} + m^{43} + m^{47} + m^{52} + m^{59} + m^{71} + m^{80} + m^{17}m^{20} + m^{43}m^{47} + m^{65}m^{71} + m^{20}m^{28}m^{35} + m^{47}m^{52}m^{59} + m^{17}m^{35}m^{71} + m^{20}m^{28}m^{43} + m^{47}m^{20}m^{55} + m^{17}m^{20}m^{28}m^{35} + m^{47}m^{28}m^{35}m^{43} + m^{28}m^{35}m^{43}m^{47}m^{52}m^{59}$。(15.2)

GRAIN V1 的滤波函数是 h1(m0, ..., m4)，与 h0 (m0, ..., m4) 相同，但输出位 Ct1 导出为：

$Ct1 = \sum i A_1 + 1 + h1(St + 3; St + 25; St + 46; St + 64; Bt + 63)$ (15.3)

其中 $A_1 = f1[1, 2, 4, 10, 31, 43, 56]$。

### 15.5.2 MICKEY

MICKEY 的全称是不规则时钟密钥流生成器。该加密的原版本是 MICKEY 1.0，它容易受到统计攻击。后来，MICKEY 1.0 版本更新为 MICKEY 2.0。新变体在不改变安全性的情况下减少了门等（GE）和功耗。这是一种适用于硬件软件实现的轻量级流加密。更多细节可见 [11]。

MICKEY 2.0 加密包含两个用于密钥流生成的寄存器。图 15.6 显示一个是线性寄存器 R，另一个是非寄存器 S。这些寄存器决定了密钥流中任意位位置的值（0 或 1）。MICKEY 2.0 使用的密钥和初始化向量（IV）均为 80 位。这些密钥和 IV 合并以初始化 R 和 S 寄存器，所有位值均设为零。
