+   1. Preimage Resistance: When the output $y$ is known, finding an input $x$ such that $h(x) = y$ should be infeasible.

+   2. Second Preimage Resistance: When an input $x_1$ and the output $y$ is known where $h(x_1) = y$, finding $x_2$ such that $h(x_2) = y$, where $x_1 
eq x_2$, should be infeasible.

+   3. Collision Resistance: Without any condition on the output $y$, finding any different $x_1$ and $x_2$ such that $h(x_1) = y$ and $h(x_2) = y$ should be infeasible.

Although it is not included in the definition, we message digest appear random. This property is necessary for hash puzzles. For an n-bit message digest size, a brute force collision attack would require $2^{n/2}$ hash calculations due to the birthday paradox. However, brute force attacks for finding a preimage or a second preimage require around $2^{n/2}$ hash calculations. Although collision resistance and second preimage resistance look similar, an input is fixed in second preimage resistance which makes it harder for the attacker. However, using a hash function that is not collision resistant is suggested as it reduces the trust in the digest. Moreover, attacks get better and a collision might lead to a second preimage attack in the future.

Many hash functions like MD4, MD5, RIPEMD, SHA-2, and SHA-1 use Merkle-Damgard construction converts a collision-resistant one hash function. As shown in Figure 13.1, firstly a padding is added to the input M in Merkle-Damgard construction and then it is divided into $t$ blocks $M_i$. At the $i$-th step, the compression function $f$ produces $h_i$, from the inputs $h_{i-1}$ and $M_i$. An initialization vector (IV) is used as $h_0$. A finalization function is generally applied to the final output $h_t$ to produce message digest.

It was shown MD4 and MD5, which are designed by Rivest, are not collision resistant and many collisions can be produced in milliseconds. However, these designs influenced many hash functions like SHA-2, RIPEMD, and SHA-1.

SHA-1 was developed by NSA in 1993 and a small modification was made in 1995 with a single bitwise rotation is added. The initial version was generally referred to as SHA-0. SHA-1 has a block size of 512 bits and a message digest size of 160 bits. It has 80 rounds and its type is Merkle-Damgard. Although a theoretical collision attack on SHA-1 was provided in [2] as early 2004, or in 2017 that a practical collision was obtained [4]. Note that a collision attack on a hash function only affects scenarios where collision resistance is required. However, chosen-prefix collisions on SHA-1 are provided in [3]. This new attack is more threatening for real protocols because it allows building two messages with arbitrary prefixes that have the same hash value. As an example, the authors of [3] provided a PGP/GnuPG attack. This should be avoided at all costs.
