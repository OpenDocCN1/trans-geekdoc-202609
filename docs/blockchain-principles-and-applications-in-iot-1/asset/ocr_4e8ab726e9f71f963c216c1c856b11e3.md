# 5.3.2 Concept of Consensus Algorithm

Pahlajani, Kishirsagar, and Pagchhare [16] narrated that the consensus algorithm or layer can be considered the critical aspect in the blockchain architecture. This particular algorithm governs protocols for deciding of adding a new block in the blockchain. Moreover, the consensus algorithm resolves the issue of trust in the technology. However, it can also be referred to as a specific process that allows all the blockchain network participants to reach a shared agreement regarding the current state of the distributed ledger. Therefore, a consensus algorithm aims to find a joint agreement that is acceptable to the entire network. In this manner, the algorithm helps to acquire high reliability in the network and ensures the increase of trust among participants in the distributed environment.

Additionally, the consensus protocol further ensures that each added block in the blockchain is the sole version of the truth accepted by all the technology nodes. In addition, Nguyen and Kim [17] stated in a study that "Voting-consensus" is considered the first class that helps blockchain network nodes broadcast their outcomes regarding transaction or mining a new block before adding it in the blockchain. Moreover, the second class is "proof-based consensus" that allows nodes joining in the network to solve a mathematical puzzle for showcasing they are more effective than the other nodes for doing the work.

As opined by Mingxiao et al. [18], different types of consensus algorithms are mainly used in blockchain. PoW is a popular algorithm that helps in selecting a miner rewarding the next block creation. Bitcoin uses this consensus algorithm. The central notion behind this algorithm is to resolve complex mathematical riddles and provide a solution quickly.
