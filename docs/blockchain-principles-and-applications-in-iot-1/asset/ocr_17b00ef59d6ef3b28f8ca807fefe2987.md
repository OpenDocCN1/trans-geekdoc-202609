# 6.6 Functional View of IoT

The IoT system indicates to uniquely discoverable devices with their visual presentations in a structure such as the Internet and IoT problem solving that include many elements, for example:

+   1. IoT local device communication model (a small distance wireless network can be contacted, for instance, installed on a mobile phone or situated in the surroundings of a consumer, etc.). This model is responsible for acquiring, monitoring, and transmitting to remote servers for perpetual storage and research.
2. Local research model and observation processing obtained by IoT nodes.
3. Model to communicate with remote IoT nodes, directly on the Internet or possibly by proxy. This model is in charge of overseeing acquired and transmission to remote servers for perpetual storage and research.
4. Data analytics applications work on an application server that serves all customers. It takes demands from the web and mobile customers as well as appropriate IoT views as input, implements relevant information executing algorithms, and provides output based on skills that will be provided to consumers.
5. Consumer interface (mobile or web): measurements of the visual representation in the given circumstances and consumer communication, e.g. description of customer enquiries.
