# 14.4.1 Structure of the Blockchain

Blockchain is simply a data structure offering several features such as immutability, decentralization, and pseudo-anonymity (users’ identities are preserved but their identifiers are traceable). The structure of the blockchain is shown in Figure 14.2. This structure however isn’t computationally followed by all blockchain implementations. Some implementations have additional information stored like state, code, etc. This section dives deeper into the workings of the blockchain that facilitate these features.

+   1. Blockchain Nodes: Nodes of a blockchain refer the computing devices that store the blockchain and perform the functions critical to its working. However, not all nodes perform the same functions. Nodes are often classified as full and lightweight nodes. Full nodes store the entire blockchain and are used for the distributed consensus protocol to publish the new block. A full node that publishes the block is called the publishing node or the mining node in the case of Bitcoin. A lightweight node however does not store the complete copy of the blockchain and it must send its transactions to a full node to be accepted into the system [18,19].n2. Cryptographic Methods: The working of the blockchain to provide a tamper-proof, secure, and authenticated storage is mainly attributed to the extensive use of cryptographic approaches in its design. Some of the cryptographic techniques used in this data structure include hashing, digital signatures, and asymmetric encryption.

Hashing is an one-way cryptographic function produces a fixed length output from any given input. Additionally, given a hashed output, it is not possible to figure out correctly the corresponding input and it is not feasible to obtain two input values hashing to the same output value [18].
