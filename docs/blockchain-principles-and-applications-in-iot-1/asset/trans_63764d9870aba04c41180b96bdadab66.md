
# 区块链中基于 ASIC 的矿系统

![](img/accfea9a01c34cc061afd3c9ae34e481_123_0.png)

**图 7.1**

区块链的结构。

如图所示，区块链中的每个区块大部分由以下部分组成：

- 1. 区块数据 (Block Data)：包含了要存储在区块链中的主要数据。
- 2. 前一个哈希 (Prev Hash)：该字段存储链中上一个区块的哈希值。
- 3. 随机数 (Nonce)：随机数是一个在区块挖矿过程中使用的特殊值。
- 4. 区块哈希 (Block Hash)：该字段存储区块链中定义的所有字段的组合哈希值。组合哈希值由所有数据的 Merkle 根（Merkle Root）、前一个哈希以及任何存在的额外数据组成。

由于每个区块都存储了前一个区块的哈希，且该区块的哈希值直接取决于前一个哈希字段，如果链中的任何区块被更改或修改，该区块的哈希值将自动改变，导致其后的任何区块变得无效。由于区块链的这一特性，即使某个区块中的数据被篡改，也可以被检测到，系统会防止任何更改的发生。要使更改持续，必须修改所有后续区块，这会变得非常消耗资源。随着越来越多的区块添加到链中，进行此类更改所需的计算量会呈指数级增长。

这种区块链也被称为账本（ledger）。账本分布在网络中的每个节点之间，即每个节点都维护一份账本的最新副本。增加的冗余确保了如果某个节点上的某条链被破坏或向其添加了任何恶意数据，其他节点可以轻松检测到并将其丢弃。在这种情况下，带有恶意数据的链将被丢弃。因此，如果有人想添加恶意数据并破坏账本，至少需要有 51% 的节点被破坏。这被称为 51% 攻击。鉴于更改区块所需的计算量，对于具有多个节点的区块链来说，这种攻击是不可能实现的。

# 7.3.1 区块产生/区块挖矿

区块产生/区块挖矿是创建新区块的过程。由于区块链基于去中心化系统，每个节点并行工作，且没有节点优于另一个节点，因此它变成了一个共享账本，用来决定哪个节点产生下一个区块。由于所有节点都有共享账本，一个节点产生的区块必须传播到网络的其余部分。为了解决这个问题，引入了各种被称为共识算法（consensus algorithms）的算法。

这些算法定义了节点之间如何就哪个节点应该产生下一个区块达成“共识”或一致意见。一些流行的共识算法包括：

- 1. 工作量证明 (PoW)
- 2. 权益证明 (PoS)
- 3. 委托权益证明 (DPoS)

还有许多其他共识机制 [3,4]，并为了构建更优秀、更高效的共识模型开展了新的研究。在提到的模型中，PoW 是最流行的 [5]，因为它被比特币使用。在这种共识机制中，每个节点竞争求解一个密码谜题，第一个解题的节点产生新区块。尽管与其他模型相比，这种模型非常消耗资源，但它是去中心化最高的方法。在 PoS 中，每个节点都质押一定数量的加密货币。质押最高的节点产生新区块。在 PoS 中，每个节点通过质押加密货币来“委托”或投票选出哪个节点被选为区块产生者。生成的加密货币数量最多的节点将产生区块。如果某个人持有极大量的加密货币，PoS 和 DPoS 都可以被单个账户或利益相关者中心化。此类个人在加密货币领域被称为“巨鲸”（whales） [6]。

我们将在实现中使用 PoW 共识算法，因为它具有去中心化的特质。在 PoW 共识机制中，会生成一个名为 nonce 的随机数。只有当生成区块哈希时，且该值满足区块链创世区块（genesis block）中定义的标准时，特定的 nonce 值才会被接受。每个与挖矿相关的节点将递归地不断尝试一个随机值，直到获得所需的结果为止。

# 7.3.1.1 工作量证明共识机制的优势

与其他机制不同，在工作量证明中，所有节点被真正认为是平等的。没有预设的方法来寻找网络中的哪个节点将产生新区块，它是随机的；因此，无法通过破解节点来产生恶意区块数据。

# 7.3.1.2 基于硬件的区块产生

ASIC，或应用专用集成电路，是为执行特定任务而设计的定制集成电路。这些是高度优化的电路，可以设计成以最小的消耗产生最大的吞吐量。ASIC [7] 可用于设计矿机，这些矿机在产生新区块的过程中非常高效（图 7.2）。

# 区块链中基于 ASIC 的矿系统

![](img/accfea9a01c34cc061afd3c9ae34e481_123_0.png)

**图 7.1**

区块链的结构。

如图所示，区块链中的每个区块大部分由以下部分组成：

- 1. 区块数据 (Block Data)：包含了要存储在区块链中的主要数据。
- 2. 前一个哈希 (Prev Hash)：该字段存储链中上一个区块的哈希值。
- 3. 随机数 (Nonce)：随机数是一个在区块挖矿过程中使用的特殊值。
- 4. 区块哈希 (Block Hash)：该字段存储区块链中定义的所有字段的组合哈希值。组合哈希值由所有数据的 Merkle 根（Merkle Root）、前一个哈希以及任何存在的额外数据组成。

由于每个区块都存储了前一个区块的哈希，且该区块的哈希值直接取决于前一个哈希字段，如果链中的任何区块被更改或修改，该区块的哈希值将自动改变，导致其后的任何区块变得无效。由于区块链的这一特性，即使某个区块中的数据被篡改，也可以被检测到，系统会防止任何更改的发生。要使更改持续，必须修改所有后续区块，这会变得非常消耗资源。随着越来越多的区块添加到链中，进行此类更改所需的计算量会呈指数级增长。

这种区块链也被称为账本（ledger）。账本分布在网络中的每个节点之间，即每个节点都维护一份账本的最新副本。增加的冗余确保了如果某个节点上的某条链被破坏或向其添加了任何恶意数据，其他节点可以轻松检测到并将其丢弃。在这种情况下，带有恶意数据的链将被丢弃。因此，如果有人想添加恶意数据并破坏账本，至少需要有 51% 的节点被破坏。这被称为 51% 攻击。鉴于更改区块所需的计算量，对于具有多个节点的区块链来说，这种攻击是不可能实现的。

# 7.3.1 区块产生/区块挖矿

区块产生/区块挖矿是创建新区块的过程。由于区块链基于去中心化系统，每个节点并行工作，且没有节点优于另一个节点，因此它变成了一个共享账本，用来决定哪个节点产生下一个区块。由于所有节点都有共享账本，一个节点产生的区块必须传播到网络的其余部分。为了解决这个问题，引入了各种被称为共识算法（consensus algorithms）的算法。

这些算法定义了节点之间如何就哪个节点应该产生下一个区块达成“共识”或一致意见。一些流行的共识算法包括：

- 1. 工作量证明 (PoW)
- 2. 权益证明 (PoS)
- 3. 委托权益证明 (DPoS)

还有许多其他共识机制 [3,4]，并为了构建更优秀、更高效的共识模型开展了新的研究。在提到的模型中，PoW 是最流行的 [5]，因为它被比特币使用。在这种共识机制中，每个节点竞争求解一个密码谜题，第一个解题的节点产生新区块。尽管与其他模型相比，这种模型非常消耗资源，但它是去中心化最高的方法。在 PoS 中，每个节点都质押一定数量的加密货币。质押最高的节点产生新区块。在 PoS 中，每个节点通过质押加密货币来“委托”或投票选出哪个节点被选为区块产生者。生成的加密货币数量最多的节点将产生区块。如果某个人持有极大量的加密货币，PoS 和 DPoS 都可以被单个账户或利益相关者中心化。此类个人在加密货币领域被称为“巨鲸”（whales） [6]。

我们将在实现中使用 PoW 共识算法，因为它具有去中心化的特质。在 PoW 共识机制中，会生成一个名为 nonce 的随机数。只有当生成区块哈希时，且该值满足区块链创世区块（genesis block）中定义的标准时，特定的 nonce 值才会被接受。每个与挖矿相关的节点将递归地不断尝试一个随机值，直到获得所需的结果为止。

# 7.3.1.1 工作量证明共识机制的优势

与其他机制不同，在工作量证明中，所有节点被真正认为是平等的。没有预设的方法来寻找网络中的哪个节点将产生新区块，它是随机的；因此，无法通过破解节点来产生恶意区块数据。

# 7.3.1.2 基于硬件的区块产生
