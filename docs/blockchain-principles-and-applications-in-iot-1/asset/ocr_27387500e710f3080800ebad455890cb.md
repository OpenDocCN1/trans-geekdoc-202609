RIPEMD-160 hash function [16] is also a Merkle-Damgard construction. It has a block size of 512 bits and consists of 80 steps. One step of RIPEMD-160 is 32-bit provided in Figure 13.2 where K[i] represents round constants and Xfir[i] represents a 32-bit part of the message block. RIPEMD-160 a good candidate for applications where small SHA-1 and small hash sizes are not being broken. Moreover, unlike SHA-1, RIPEMD-160 was designed by academians.
SHA-2 was designed by NSA and first published in 2001. The digest length can be 224, 256, 384, or 512 bits, depending on the message digest. Generally, this number is used with the algorithm name. For example, SHA-256 is SHA-2 with 256-bit digest size. The number of rounds is either 64 or 80, which also depends on the message digest. It is a Merkle-Damgard-type hash function. The design is similar to its predecessors SHA-1, MD5, and MD4.
Although SHA-2 is not broken, its predecessors SHA-1, MD5, and MD4 are broken. For this reason, NIST (National Institute of Standards and Technology) announced a SHA-3 Competition that took place between 2007 and 2012. This competition received 64 submissions and the winner KECCAK became SHA-3. Its digest sizes are the same as SHA-2 to allow transition from SHA-2 to SHA-3 if necessary. The block sizes are 1,152, 1,088, 832, and 576 bits corresponding to 224, 256, 384, and 512-bit digest sizes. The number of rounds is 64 or 80. Unlike SHA-2 is a sponge construction. Sponge functions have relatively large internal states and a permutation that modifies this internal state at each step. A small part of the state is used for producing output.
It is a common mistake to indicate that a hash function can be anything or its input space is infinite because designs generally limit the input size by 2n bits. However, such a limit allows 2 to the power of 2^n different input, which is virtually infinite.
Cryptographic hash functions have many different use cases in a blockchain network such as address derivation, securing the block header, securing block data, creating identifiers, and creating cryptographic puzzles.
