# 用于物联网访问的敏感信息存储

首先，我们将检查用于注册用户的代码：

```solidity
function register(string memory name,string memory passwd_biometric) public {
  users.push(User(nextid,name,passwd_biometric));
  nextid++;
}
```

在此函数中，我们使用用户名和生物识别详情作为密码。我们将其推入并生成一个序列号。这将创建一个用户。在这里，我们以二进制块（blobs）的形式存储位置数据所在的哈希值。我们可以使用 IPFS（星际文件系统），它用于在分布式文件系统中存储和共享数据。我们可以将文件存储在对等服务器上，并返回存储图像的哈希值，然后存储该哈希值以供以后使用或用于去中心化应用（D-apps）。然后我们定义了一个函数，管理员可以通过提供序列号来读取用户的详情：

```solidity
function getUserByById(uint id) view public returns(uint, string memory,string memory) {
  uint i = checkUserxists(id);
  return(users[i].id,users[i].name,users[i].passwd_biometric);
}
```

在这里我们将 ID 作为参数传递以获取关于用户的所有详情。然后我们将定义一个函数来更新生物识别等用户详情。

```solidity
function updateById(uint id, string memory name,string memory passwd_biometric) {
  uint i = checkUserxists(id);
  users[i].name = name;
  users[i].passwd_biometric = passwd_biometric;
}
```

传递后，将传递需要更新的字段，然后将进行相应更新。此外有一个删除或移除用户的函数。

```solidity
function destroyById(uint id) public {
  uint i = checkUserxists(id);
  delete users[i];
}
```

# 12.6 结论

尽管对区块链、智能合约、访问管理系统的研究仍处于早期并需要解决许多缺点，但在安全性和信任方面，它们在许多用例中确实优于许多现有技术，正如我们在市场价值 1.5 万亿美元的加密货币案例所示。这些技术具有巨大的潜力，许多财富500 强科技企业正在对其投资，这将铺辟新的道路。在本文中，我们讨论了区块链和物联网世界的现状及其优势和挑战。我们提出了一种模型，利用免费的开源资源来保护敏感的访问控制数据。通过在物联网设备中应用区块链技术（安全存储），该模型在安全性方面变得健壮。尽管代码已通过测试并发现运行正常，但由于缺乏资源和持续的疫情，尚未在真实环境中（连接带有适当管理员面板的生物识别访问控制物联网设备）进行测试。

未来，我们可以检查该架构的可扩展性、成本、复杂性以及与其他现有技术的比较。虽然目前进行实际实现可能具有挑战性，但这是一个极具前景的研究领域，进一步的研究将解决许多缺点并降低复杂性和成本。
