
多次执行哈希函数。哈希率高的矿工可以获得更多加密货币。为了防止为挖掘设计定制 ASIC，采用了诸如 script、X11 或 X16 这样的内存密集型算法。然而，在许多情况下，人们为最初具有抗 ASIC 特性的算法制造了 ASIC。在某些情况下，它们被用于对相关加密货币进行 51% 攻击。在任何节点都可以提议新区块的无许可区块链中，添加新区块的预期时间通常是预定的，以避免网络延迟可能引起的问题。在加密货币中，这通常由区块难度决定，并根据网络的区块添加速度进行更新。目前在比特币中，区块链区块难度的设定是预计每 10 分钟向区块链中添加一个区块。比特币的难度每 2016 个区块重新计算一次，大约每 2 周发生一次。在以太坊中，难度的设定是每 1 分钟添加新区块。请注意，区块添加预期时间的改变会导致区块链的硬分叉。

比特币需要对区块应用 SHA-256 以获得一个小于当前难度的哈希值。因此，矿工的目标是获得一个开头带有大量零位的哈希值。为了成功，矿工可以更改 32 位的 nonce 值（随机数）， coinbase 交易中的字段被用于奖励解决此哈希谜题的矿工。例如，coin 交易可以使用 256 位的之前的交易哈希字段作为 nonce，因为 coinbase 交易没有之前的交易。虽然寻找哈希谜题的解是困难的，但验证解很快，这正是区块链能够正常运行的原因。

最初，比特币矿工使用 CPU，然后转向 GPU。然而，今天使用 CPU、GPU 或 FPGA 挖掘比特币几乎是不可能的，因为 ASIC 在比特币挖掘中的性能优于这些设备。这在某种程度上违背了比特币背后的去中心化理念——只有拥有特殊设备的节点现在拥有网络的控制权。由于这个原因，许多加密货币尝试获取抗 ASIC 特性的哈希。初始设计如 script [17] 关注于需要大量内存的谜题，认为这会降低 ASIC 的速度。script 要求矿工在内存中存储连续的哈希值。Litecoin 是使用 script 的加密货币示例，它的目标是抗 ASIC 的。然而，过去已经生产了许多 script ASIC，它们的性能优于 GPU 矿工。为了抗 ASIC，可以增加 script 算法的要求，但这会降低哈希谜题解的验证，导致区块链变得不可用。

实践中使用的另一种方法是连续使用不同的哈希函数，而不是像比特币 SHA-256 谜题那样使用单一哈希函数。在没有理论的情况下，这种方法被认为是抗 ASIC 的。在这方面，许多加密货币使用了 X11，它是 SHA-3 竞赛中 11 种哈希算法的连续组合。同样，X16 算法使用了 16 不同的哈希函数，使得 ASIC 设计高效硬件变得困难。

具有抗 ASIC 的哈希函数对于密码哈希来说也是必要的。因为减慢密码哈希也会减慢暴力破解密码的攻击。许多之前的密码哈希解决方案都是权宜之计，没有针对密码哈希的专门设计。密码哈希竞赛（PHC）从 2013 年运行到 2015 年。这次竞赛收到了 2 个候选者，胜出的是 Argon2。然而，其他候选者如 Lyra2 及其变体被加密货币设计者采用，并被用于各种加密货币的哈希谜题中。

# 密码学基础

在它的工作量算法 ethash 中，以太坊使用了 Keccak，但需要注意的是它与 Keccak 的标准版本即 SHA-3 旧有不同。SHA-3 标准化过程的后期变化导致了填充方式与 ethash 使用方式的不同。因此，ethash 中的哈希算法有时被称为 Keccak-256 和 Keccak-512，而不是 SHA-256 和 SHA-512。

以太坊和比特币工作量算法之间的区别不在于使用的哈希算法。Ethash 基于 Dagger-Hashimoto，以成为内存困难算法。Ethash 从从之前的区块头部获取的种子生成 16-MB 的伪随机代码。轻节点只存储这条链。然而，全节点和矿工每个生成 1-GB 的数据集。数据集的大小随时间线性增加。该数据集实际上是一个有向无环图（DAG），每个 epoch 创建一次（目前为每 30000 个区块）。2021 年初，ethash DAG 超过了 4 GB，阻止了旧的 GPU 和 ASIC 继续挖掘。

在目前为止考虑的所有哈希谜题中，矿工的目标都是获得一个开头带有许多零位的哈希值。因此，哈希谜题中使用的哈希函数必须是抗原像。由于只有哈希值的前几位固定为零，我们实际上需要一种近原像抗哈希函数（即只有部分哈希输出被固定）。因此，一个拥有快速方法获取小哈希值的对手可以主导区块链。比网络其他部分更快解决哈希谜题将使对手获得对区块链的完全控制权。到目前为止，对于标准化或用于哈希谜题的哈希函数尚未发现近原像攻击。

# 13.4 公钥密码学

在公钥加密和数字签名算法中，用户生成私公钥对。在区块链中，公钥密码学通过数字签名提供身份验证。它可以验证签名交易的人是否拥有向他人转移价值的私钥。因此，交易通过私钥进行数字签名，签名可以通过公钥进行验证。此外，公钥被用作身份。

公钥密码学为加密、密钥交换和数字签名提供了不同的算法。这些算法取决于某些数学问题的不可解性，例如离散对数或整数分解：

**定义 2（整数分解问题）：** 设 $p, q \in \mathbb{Z}^+$。给定 $n = pq$，找到 $q$ 或 $p$ 称为 IFP（整数分解问题）。注意，当已知 $p$ 和 $q$ 时，计算 $n$ 是容易的，但寻找质数的已知算法需要多得线性时间。RSA 公钥加密算法的安全性取决于该问题的不可解性。目前知的分解算法表明，为了达到 128 位安全，需要 3072 位的 RSA 模数 $n$。

**定义 3（群）：** 代数中的群 $G$ 是一个元素集合，加上一个二元运算，该运算结合 $G$ 中的两个元素并产生 $G$ 中的第三个元素，且满足结合律、单位元和逆元群的公理。在群中 $a(bc) = (ab)c$

存在一个单位元，且每个元素对于群运算都有逆元。当在 R 或 C 中考虑时，群有很多。对于奇素数 $p > 3$，有限域上的椭圆曲线定义为 $y^2 = x^3 + ax + b$，其中 $4a^3 + 27b^2 \neq 0 \pmod p$。集合 $E(F_p)$ 由所有满足椭圆曲线方程的点 $(x, y)$ 其中 $x, y \in F_p$ 以及一个称为无穷特殊点 O 作为单位元组成。

**定义 4（离散对数问题）：** 设 $g$ 为群的生成元。给定 $b = g^a$，找到 $a$ 是离散对数问题（DLP）。DLP 的处理性取决于群 $G$。在加法群中，$a$ 表示为 $ag$。同样，在乘法群中，$a$ 表示为 $g^a$。

椭圆线上点 $Q$ 和 $P$ 的加提供了输出 $R$，其中加法定义为通过 $P$ 和 $Q$ 的直线并取该直线与椭圆曲线交点的第三点的负。

**定义 5（椭圆曲线离散对数问题）：** 设 $E$ 为有限域 $Fq$ 上的椭圆曲线。设 $N$ 为群 $E(Fq)$ 的阶，$P \in E(Fq)$。给定 $j = \text{ord}(P)$ 和 $Q \in \langle P \rangle$，寻找唯一的 $m \in \{0, 1, 2, \dots j-1\}$ 使得 $Q = mP$ 是椭圆曲线离散对数问题（ECDLP）。当我们使用椭圆曲线点作为群 $G$ 的元素时，这个问题变得更加困难。这就是 ECDLP。

数字签名算法（DSA）及其椭圆曲线模拟 ECDSA（椭圆曲线数字签名算法）主要用于签名交易。

DSA 参数生成：

- 1. 选择一个 SHA-2、SHA-3 的良好函数 $H(\cdot)$
2. 选择密钥长度 $L$ 和 $N$ ( (3072,256))
3. 选择 $N$ 位质数 $q$，使得 $p-1$ 是 $q$ 的倍数
4. 选择 $g$（其模 $p$ 乘群阶为 $q$）

DSA 用户密钥生成：

- 1. 随机选择 $x$，使得 $0 < x < q$
2. 计算 $y = g^x \pmod p$

$x$ 是密钥，$y$ 是公钥。
