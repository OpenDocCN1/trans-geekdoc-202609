# Cryptographic Foundations

DSA Signing:

+   1. Randomly choose $k$ per message $m$ where $0 < k < q
2. Calculate $s = k^{-1}(H(m) + xr) \mod q$ where $r = (g^k \mod p) \mod q$

The signature is the pair $(r, s)$.

DSA Verification:

+   1. Calculate $v = (g^{u1}y^{u2} \mod p)$ where $u2 = rw 	ext{ mod } q, u1 = H(m)w 	ext{ mod } q$, and $w = s^{-1}	ext{mod } q$

If $r = v$, then the signature is verified.

The security of the digital signature algorithm also depends on DLP. Unlike the ordinary DLP and IFP, subexponential-time algorithm is found so far for ECDLP. Thus, algorithms using elliptic curves have greater strength-per-key-bit and therefore signatures using elliptic curves result in shorter keys. Note that the Bitcoin uses ECDSA. Known attacks on the ECDLP force us to carefully select the elliptic curve parameters:

+   1. To avoid the Pohlig-Hellman [19] attacks and Pollard's Rho [20,21] attacks, j should be a large prime of at least 224 bits because they have a time complexity of $O(\sqrt{j})$.

+   2. The MOV [22] and Frey-Ruck [23] attacks reduce the ECDLP on $E(F_q)$ to the DLP in $F_t$, where $t = q^l$ using a Weil pairing $E[l]$. When $\gcd(l, q) = 1$, this reduction is polynomial in terms of the number of operations in $F_t$. To avoid the MOV attack, $j$ should not divide $q^i - 1$ for $1 \le i \le C$ where $C=20$ is sufficient. This required property of $j$ cannot be obtained when the curve is supersingular.

+   3. When $q$ is prime, the elliptic curves whose trace of Frobenius $t$ is $1$ and $q=N$ are called anomalous curves. These curves resist the MOV attack. However, using $q$-adic logarithm [24] or considering the $q$-primary part of the subgroup generated by $P[26]$, one can gain a linear time method to solve the ECDLP. To avoid these attacks, N should be different from $q$.

Known techniques like GHS' Weil Descent [27] can break ECDLP on elliptic curves faster than Pollard's Rho method but it was shown in [28] that this attack is ineffective against Koblitz curves which are elliptic curves defined over $F_2$ and for elliptic curves against NIST's recommended fields.

Therefore, in practice, we need non-anomalous ($i 
eq q$) elliptic curves with group order divisible by a large prime of at least 224 bits. In practice an elliptic curve is selected randomly and kept if it satisfies these conditions. Determining the order of the group $E(F_q)$, which is also known as the point counting, is critical of importance in elliptic curve cryptography. Schoof's point counting algorithm [29,30] solves this problem efficiently. Although working with random curves is not as efficient as working with special curves like Koblitz curves [31], it is practical. Therefore, it is a natural question to ask if the ECDLP is equally hard for every elliptic curve over a finite field having the same number of points. This problem is answered in terms of random self-reducibility.
