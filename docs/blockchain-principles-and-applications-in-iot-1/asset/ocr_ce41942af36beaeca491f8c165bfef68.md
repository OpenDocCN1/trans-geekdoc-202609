# 1.9 Privacy and Security Requirements

The security and privacy of any information system are critical requirements. We use concepts like integrity, availability, and confidentiality to describe safety. To ensure security, most people utilize a mix of authentication, authorization, and identification.

+   **1. Integrity:** It's the guarantee that the data hasn't been changed by anyone other than those with the right to do so. Integrity ensures that transactions on the blockchain remain immutable. Integrity is routinely verified using cryptographic processes.

+   **2. Availability:** It ensures system users have access to it whenever they need it. In other words, when a legitimate user wants the service, it is always available, which means the communication infrastructure and database. The block-chain achieves this purpose by allowing users to communicate with one another and store blocks in a distributed manner.

+   **3. Confidentiality:** It ensures that unapproved individuals do not gain access to all the information. That is, only with the necessary rights and obligations will be able to access the data, whether it is being processed or transported. To ensure this concept, the blockchain makes use of pseudo-anonymization technologies such as hash functions, which hide the identity of users [40].

+   **4. Authorization, Authentication, and Auditing:** This tries to identify the person, who is performing a function in a system, as well as determine privileges that person has and track their usage statistics. The blockchain's structure ensures all three purposes because only users with private keys can make transactions, and all transactions are public and auditable.

+   **5. Non-Repudiation:** It assures that no one can deny the operation of a system. Non-Repudiation proves that a user did something specific, give money, authorize a transaction, or send a communication. A user can't claim he didn't do something because all transactions are signed. The right to privacy refers to a person's ability to share personal information with others.
