# 6.6 Functional View of IoT

The IoT system consists of several layers that work together to provide the required functionality. The layers include:

- Perception layer: This layer consists of sensors and actuators that interact with the physical environment.
- Network layer: This layer is responsible for transmitting data collected by the perception layer to the application layer.
- Application layer: This layer provides services to the end-users.

The interaction between these layers is crucial for the proper operation of the IoT system. For example, when the perception layer detects a change in the environment, it sends data to the network layer, which then forwards the data to the application layer. The application layer then processes the data and provides the appropriate response to the user.

The security of IoT systems is also a major concern. Since IoT devices are connected to the internet, they are vulnerable to various types of attacks. It is important to implement robust security measures to protect the data and the devices. These measures include:

- Encryption to protect data from unauthorized access.
- Authentication to ensure that only authorized users can access the system.
- Intrusion detection and prevention to identify and respond to potential attacks.

- Access control to information violations. This is usage regulation, which is the procedure of guaranteeing the proper use of specific data according to a pre-defined principle, after which the access to data is allowed [7].
