# 6.1 物联网概述

物联网已成为一种营销趋势。此外，物联网作为一种强大的技术出现，源于传感器网络、嵌入式系统和泛在计算。许多物联网设备相互连接以开发特定的方案。

# 区块链

![](img/accfea9a01c34cc061afd3c9ae34e81_102.png)
图 6.1 物联网架构 [2]。

物联网节点是包含传感器的硬件，通过互联网向用户或其他任何设备发送信息。物联网的顶级案例包括连接智慧城市、智慧工业、智慧交通、智慧建筑 [1]、智慧能源、智慧制造、智慧环境监测、智慧生活、智慧健康和智慧食品。图 6.1 显示了物联网架构。该架构包含了用于感知温度、湿度压力的许多传感器。感知后，这些数据通过物联网网关传输到云服务器。
