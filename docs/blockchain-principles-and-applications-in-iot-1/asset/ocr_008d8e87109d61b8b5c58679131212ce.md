The incentive layer has features that specify what kind of rewards the network offers, when and how nodes can receive incentives, and the minimum transaction fees required to perform functions on the blockchain. In essence, the incentive layer responds to the challenge of crowd-sourcing among distributed nodes. +   - Contract Layer The contract layer comprises smart contracts for managing data such as money or asset records, etc. Smart contracts reduce the number of midd-lemen. The contract code is kept in script file of the transaction, and after the transaction is published to the block, the code will continue to execute permanently. The contract logic will be verified by all blockchain verification nodes, and the execution outcome will be written to the blockchain [8–10].
