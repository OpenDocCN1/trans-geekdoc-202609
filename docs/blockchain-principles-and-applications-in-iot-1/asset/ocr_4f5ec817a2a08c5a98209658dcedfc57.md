# 13.8 Conclusion

Since the introduction of Bitcoin in 2008, cryptographic hash functions and digital signatures have played an important role in the security of blockchains. We require preimage and second preimage resistant hash functions for blockchain security and near-collision resistant hash functions for cryptographic puzzles. Broken hash functions like SHA-1, MD4, and MD5 should be avoided in blockchains. Moreover, lightweight hash functions might be beneficial for blockchains designed for IoT.

The choice of elliptic curve for elliptic curve digital signatures and Schnorr signatures is very important and using standard elliptic curves can prevent attacks on elliptic curves. Moreover, randomness is vital for signature schemes and users must be sure that they have good randomness/entropy source. Randomness of IT RNGs must be checked and designers should pay attention to error codes that can be generated by hardware Ranges. Instead of using an entropy source output directly as random numbers, they should be fed to cryptographically secure pseudorandom number generators.

Development of a large quantum computer could solve intractable problems like ECDLP, DLP, and IFP on a quantum computer in polynomial-time. Although current technology does not allow building a quantum computer and we do not know if such a computer will ever be built, blockchains should consider including quantum-secure digital signature algorithms in their set of available cryptographic algorithms to be future-proof.

There are many different IoT devices with different capabilities and in blockchains that require encryption, a lightweight encryption algorithm should be chosen according to the needs of these devices that are going to be used in the blockchain network. Although there are ISO/IEC standards for 80-bit secret keys, secret keys should be at least 112 bits to resist exhaustive key search attacks.

Use of zero-knowledge protocols for anonymity in blockchains shows that cryptographic algorithms might find themselves in blockchains in the future to solve different problems.
