# Blockchain

+   1. A shared and consistent data store is needed

Blockchain networks can be categorized in two models: permission-less and permitted.
Permission-less networks are open to anybody who want to participate. Without any authorization, anyone can read the data on the blockchain and write to the blockchain. When publishing to blocks, a consensus algorithm requires users to maintain or expend resources like solving cryptographic puzzles to prevent malicious users or double spending of cryptocurrencies. Systems generally reward the publisher of the block. Bitcoin and other cryptocurrencies use permission-less networks.

In permitted blockchain networks, some authority authorizes so that they can publish blocks. Thus, permitted blockchain networks have limited participation and finer-grained controls.

A blockchain is a distributed ledger of blocks that contain cryptographically signed transactions. Each block consists of data and a block header. A header contains metadata about the block and a cryptographic hash link to the previous block's header except for the first block which is referred referred to as the genesis block of a blockchain. Each transaction is signed by the blockchain network user or users who are involved in the transaction. Block data contains signed transactions and other related data. The integrity provided by the cryptographic hash functions makes this process tamper evident. Moreover, blockchain becomes resistant as new blocks are added because it becomes harder to order older blocks of the blockchain.

A blockchain network generally does not need a trusted intermediary. The trust within a blockchain network is obtained by having a shared ledger that is secured by cryptographic algorithms and distributed among the nodes of the blockchain network [14]. When adding a new block, any conflicts among the nodes are automatically resolved based on pre-defined rules.

Unlike relational databases, blockchain technology uses ledgers that append only. Thus, a written value is never deleted or changed but a transaction affecting the value is added to the ledger, providing full transactional history that stays in transparency. Distributed ownership of ledgers has advantages over centralized ownership of ledgers. The centrally owned systems might be insecure because a weakness in the network or computer systems might leak personal information. Moreover, it is assured that the best security measures are taken and security patches are installed regularly.

A disadvantage of distributed ledgers is conflicts published around the same time and some nodes in the network might have different versions of the blockchain. Conflicts might be resolved for the consistency of the blockchain and generally they are solved in a short time. In conflict, the blockchain that becomes longer is generally considered as the correct version.
