# 14.1 Introduction

The most important power in today's world is information and de-identified as possible. Machine learning has enabled computers to learn from large amounts of data. The world is increasingly moving towards decentralized. Due to the various issues of security, privacy, single points of failures and monopoly of data in centralized systems, the term “centralized” in our context does not refer to a single computer but rather to a single organization. Blockchain is a technology that has been leading the front in this area since advent. It all began with the success of the first blockchain-based cryptocurrency, Bitcoin [1], which allowed users to transact between peers without the involvement of a trusted party. This paved way by achieving an immutable ledger. Ethereum was the first successful implementation of a blockchain that provides a built-in Turing-programming language used to create contracts allowing to define state transition functions [2]. This paved the way for an increasing number of blockchain-based applications.

The following paper aims to describe the application of blockchain in the domain of access control. The following section details a description of the survey methodology and the research questions. The second section begins with an introduction of access control. This section details requirements of an access control system, current methods employed and limitations that need to be addressed. The next section describes the blockchain in detail, with its structure, types, and characteristics. The sections after this provide the answer to the research questions formulated. Towards the conclusion of the paper, we also address the drawbacks of our survey and the efforts made to tackle these.
