# 14.1 引言

当世界最重要的力量是尽可能去标识化的信息。机器学习使得计算机能够从海量数据中学习。世界正日益转向去中心化。由于安全、隐私、单点故障以及中心化系统中数据垄断等问题，我们语境中的“中心化”指的是不是单一计算机，而是单一机构。区块链技术自出现以来一直是该领域的前沿。这一切始于第一种区块链加密货币比特币[1]的成功，它允许用户在没有信任第三方参与的情况下进行点对点交易。这通过实现不可篡的账本铺平了道路。以太坊是第一个内置图灵编程语言以创建合约的区块链实现[2]，这为越来越多的区块链应用铺平了道路。

本文旨在描述区块链在访问控制领域的应用。接下来的章节详细说明了调查方法论和研究问题。第二部分从介绍访问控制开始。该节详细介绍了访问控制的需求、当前采用的方法以及需要解决的问题。下一节详细介绍了区块链，包括其结构、类型和特征。后续章节提供了对研究问题的回答。在论文结论处，我们还了调查的局限性以及针对这些问题所做的努力。
