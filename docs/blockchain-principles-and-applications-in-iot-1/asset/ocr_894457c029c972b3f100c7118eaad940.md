# 9.8.2 Health Monitoring System Using IoT and Cloud Services

This is the second module of our system that is used to monitor vitals of the patients and send them to the cloud for storage. The workings of this module are given below.

The patient will be fitted with the IoT sensors like (ECG, blood pressure monitor, glucose meter, body temperature thermometer, etc.) and these will be used to collect biological data. The IoT sensors which are fitted to the patients will be connected to their mobile device wirelessly and will be used to process the data and generate aggregate (like avg, min, max, etc.) of the whole data for fixed periods and then sent to the cloud. The mobile device will be receiving data from IoT sensors in real time and if it receives values that are below or above the set threshold for specific value, it will send immediately to the cloud and the cloud will send a notification to the doctor. The doctor can only view this data if they are allowed by the patient and can only do by transacting on the blockchain. This way, the patient can see accessed data and they can control the access to data and not the doctor. After the patient gets data, they can remove the access of the particular doctor to their sensor’s biological data so that the doctor can no longer view it.
