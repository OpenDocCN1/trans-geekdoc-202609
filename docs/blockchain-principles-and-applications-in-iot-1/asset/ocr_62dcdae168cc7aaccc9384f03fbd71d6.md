# 1.4.1 User Privacy and Data Protection

The Internet of Things (IoT) system is based on transmitting and exchanging information/data among various smart devices via various channels. Users’ personal information, such as their personality and behavior, may be included in the data set [12]. The Internet of Things technology, as previously said, allow any device or person to be automatically identified.

Consumer data can be obtained from their linked objects, which are stored in the system or exchanged across smart objects via various channels. All of a user’s sensitive information is subject to the most dangerous attacks and risks if there are no authentication processes in place. # 1.4.2 End-to-End Security

There are billions of smart objects, each of which transmits a huge amount of data to other objects. A smart object should be authenticated and have security processes in place to protect people, devices, and services. Simultaneously, security solutions are used to safeguard data and security against threats and attacks. This activity is referred as “end-to-end security.”

A smart object can connect to the cloud right. The cloud is in charge of authentication and message control between smart devices [14]. After authentication and control mechanisms have been performed, a smart object connects to the Internet through the gateway. The encryption technology is used to encrypt messages sent between smart devices.
