
# 大语言模型时代的科学产出

随着生产过程迅速演变，科学政策必须考虑机构如何演进

尽管人们对生成式人工智能（Gen AI）在所有学术学科中的快速采用既兴奋又担忧，但经验证据仍然零散，对大型语言模型（LLMs）在各科学领域影响的系统性理解有限。我们分析了来自三个主要预印本库的大规模数据，以表明使用 LLMs 加速了手稿产出，降低了非英语母语者的障碍，并使先前文献的发现多样化。然而，随着科学工作量的上升，传统的科学质量信号，如语言复杂性，正变得不可靠的价值指标。随着人工智能系统的进步，它们将挑战我们关于研究质量、学术交流以及智力劳动本质的基本假设。科学政策制定者必须考虑如何使我们的科学机构演进，以适应快速变化的科学生产过程。

> ...LLM 采用与研究人员科学产出的大幅增加相关...

科学事业与技术创新密切相关。例如，显微镜、计算技术的进步以及下一代测序仪推动了研究的边界。研究人员已在许多具体的科学背景下证明了人工智能的价值（1，2），例如蛋白质结构预测和材料发现。大型语言模型的最新进展使其在自然科学（3）和社会科学（4）中的广泛任务中得到应用。这项工作突出了 LLMs 在特定科学任务中的巨大潜力，提出了一个开放性问题：LLMs 对科学事业的宏观层面的影响是什么？

为了解决这个问题，我们收集了来自三个预印本库的大规模数据[涵盖 2018 年 1 月至 2024 年 6 月，详见补充材料（SM）S1.1 至 S1.3]：arXiv（1.2 million preprints），包括数学、物理、计算机科学、电气工程、定量生物学、统计学和经济学；bioRxiv（221,000 preprints），涵盖生物学和生命科学的广泛子领域；以及 Social Science Research Network（SSRN; 676,000 preprints），一个托管社会科学、法律和人文学科手稿的工作论文库。每个数据集在其领域内代表最大规模。总体而言，它们为检验 LLMs 对众多科学领域科学生产力实践的部分影响提供了前所未有的经验证据基础。

为了识别 LLMs 在科学手稿创作中的使用，我们对数据中的所有摘要应用了基于文本的 AI 检测算法（5）。我们使用了 2023 年之前提交的论文的摘要——ChatGPT 时代之前——来估计人类撰写文本的 `token`（word）分布。然后我们提示 OpenAI 的 `GPT-3.5turbo0125` 模型重写这些摘要，生成 LLM 撰写文本的 `token` 分布，并进行比较。这使我们能够量化 LLM 辅助写作与人类写作之间词分布的差异，并识别 ChatGPT 发布后可能由 LLM 辅助撰写的摘要。有关模型训练、验证、潜在局限性以及 LLM 检测的替代方法的进一步细节已提供（见 SM S2.1、S4 和 S5）。

## LLM 使用与科学生产力

我们预测采用 LLMs 的作者将经历生产力提升（6，7）。为了将 LLMs 的一般生产力效应与人工智能研究快速增长区分开来，我们首先从样本中排除核心 AI 子学科的手稿（见 SM S1.1 和 S5.7）。然后我们将作者首次采用 LLMs 识别为第一个表现出 LLM 辅助统计特征（`α`）的手稿（`m_i`）所标记，使得 `α(m_i) > τ`，其中 `τ` 为检测阈值。作者的采用状态在首次检测使用后的任何月份从 0 变为 1。基于这一衡量标准，我们在作者层面固定效应事件模型中（见 SM S3.1）检查了采用前和采用后 LLM 采用者与相似非采用者之间手稿提交率的变化（见 SM S2.2 至 S2.4）。

## 生产力与发表

2022 年 1 月至 2024 年 7 月之间，一旦作者在其写作中采用了 LLMs，arXiv 预印本的月度发表数量相对于非采用者增加了 36.2%（上图）。自 2023 年以来，对于 LLM 辅助的手稿，arXiv 手稿的写作复杂性越高，被发表的概率越低。非 LLM 辅助手稿的关系则相反（下图）。

我们表明，LLM 采用与三个预印本库中研究人员科学产出的大幅增加相关。arXiv（见第一图，上图）、bioRxiv 和 SSRN（见 fig. S1）的估计系数分别为 36.2、52.9 和 59.8%，表明 LLM 使用与生产力的显著提升相关。尽管估计系数因用于识别 LLM 采用的检测方法和阈值而异，但敏感性分析（见 SM S5.3 至 S5.6）表明，正相关在分析选择中是稳健的。

生产力跃升可能源于 Gen AI 在多个研究任务中的使用，包括创意生成、文献发现、编码、数据收集或分析。但迄今为止，LLMs 可能在写作方面产生了最大影响。为了创造独特的科学作品，研究人员必须提出有说服力的书面论点；将手稿的论点、方法与结果与先前文献联系起来；详细说明并 contextualize 最重要的发现；并阐明可以从文本中学到什么。这些复杂的写作任务耗时，尤其对于使用非母语进行交流的研究人员而言。因此我们询问 LLM 采用的生产力影响是否因作者的母语熟练程度而异。因为大多数高影响力研究发表在英语期刊和会议论文集中，母语使用者在科学交流中具有显著优势。LLMs 可以缓解英语流利度的差异，这应不对称地降低科学家语言背景的写作成本。

为了检验生产力变化的异质性，我们根据作者姓名及其所属机构近似估计作者为英语母语者的可能性（见 SM S2.5 至 S2.6）。系数按研究人员的种族和居住地理位置细分（见 fig. S2）。效应在所有组中均保持统计显著，但亚裔姓名的学者从 LLM 采用中获得了最大的生产力提升。在 bioRxiv 和 SSRN 中，对于具有亚裔姓名且机构隶属于亚洲的学者，效应更为明显，其中 bioRxiv 显示亚裔机构的亚裔姓名学者（相对于美国、英国、加拿大和澳大利亚机构的学者）具有统计显著的额外生产力增益。对于隶属于亚洲机构的亚裔姓名学者，估计的与 LLM 相关的生产力增益从 arXiv 的 43.0% 低到 bioRxiv 的 89.3% 和 SSRN 的 88.9%。隶属于英语国家机构的白人姓名研究人员经历了更为适中但仍显著的生产力增益，从 23.7%（arXiv）到 46.2%（SSRN）。

我们得出结论，即使是上一代 LLMs 的使用——即手稿在我们数据集中起草时学者可用的模型——也与生产力增益相关，特别是对于面临更高写作成本的研究人员。这些发现与表明 LLMs 缓解技能差异影响的工作一致，在本例中是通过降低第二语言写作成本（8）。鉴于当前一代 LLMs 写作能力的显著进步以及这些系统的更广泛可用性，我们估计的生产力效应可能足以暗示科学生产的市场份额向非英语母语地区学者转移。

## LLM 使用、科学写作与发表结果

LLMs 可能在生产力效应之外重塑科学生产。高质量的写作通常被视为科学价值的信号（9）。语言清晰但复杂的论文被认为更强，且被引用的频率更高。因为科学进步是多年知识精炼的产物，精确阐述科学发现的能力是对科学团队工作期间所付出的谨慎程度的（非常不完美的）代理指标。LLMs 几乎毫不费力地就能生成描述任何科学主题的精炼、专业的文本这一事实提出了一个重要问题：LLM 使用是揭示还是掩盖了基础研究的质量？

为评估这一问题，我们研究了写作复杂性如何与研究质量相关，以及 LLM 采用是否改变了写作复杂性在科学交流中的信号作用。我们用 Flesch 阅读易懂度分数的加性逆来衡量写作复杂性（见 SM S2.7）。该指标将文本复杂性量化为平均句长和每词音节数的综合，分数越高表示文本越复杂。作为质量的代理，我们随后创建了一个二元结果，定义为在观察窗口结束时（2024 年 6 月）自 2023 年以来所有预印本发表于同行评审期刊或会议（见 SM S2.8 和 S5.9）。

当我们将 Flesch 分数的加性逆与发表结果相关联时，出现了三种模式。首先，与三个档案库中用自然语言撰写的论文相比，LLM 辅助手稿的写作复杂性分数显著更高（P < 0.001，所有存储库，双尾 t 检验）（见 fig. S3，A to C）。这凸显了 LLMs 生成复杂科学写作的卓越能力（7）。其次，在非 LLM 辅助论文中

我们从bioRxiv和SSRN获取了1.016亿条对先前文献的引用，并将其与OpenAlex和Semantic Scholar两个大规模引文数据库进行对照（见补充材料S1.6）。随后，我们采用事件研究法（见第一图），比较了作者在采用LLM前后相对于未使用者的对照组（见补充材料S3.3）的引用行为变化。我们的分析考察了被引文献的三个特征：出版形式（对书籍的引用）、时间滞后（中位参考文献年龄）以及被引文献的影响力（被引文献的平均对数引用次数）。

我们发现，使用LLM改变了作者的引用行为，似乎引导他们走向更加多样化的知识基础（见图S4）。总体而言，LLM采用者引用书籍的可能性增加了11.9%（见图S4D），但在其中一个档案库SSRN中，该效应在统计上并不显著。采用者引用的文献平均年轻0.379年（见图S4E），且其累积被引次数较少（引用影响力降低2.34%；见图S4F）。尽管这些效应的大小因预印本库而异，但总体模式大致一致（见图S4，G至I）。

我们提供了一致的证据，表明人工智能辅助将学者引向更广泛的知识体系（见第二图和图S4）。研究人员面临时间和注意力的限制，这制约了他们处理不断扩大的研究领域的能力（14）。LLM似乎有助于研究人员克服在发现相关文献方面的障碍。

这些发现表明，虽然LLM可能模糊了作者努力的信号，但它们拓宽了知识发现的路径。人们普遍担心人工智能辅助搜索可能会强化现有的科学经典。然而，我们发现LLM的采用产生了相反的效果。人工智能辅助的搜索行为和作者引用模式都显示出向更加多样化知识基础的重大转变，这种知识基础包括更多的书籍，以及更年轻和被引用较少的学术成果。这种注意力的拓宽表明，LLM帮助研究人员克服了限制其参与不断扩展的科学文献领域的认知约束。

# 局限、影响与未来方向

在这项研究中，我们探讨了LLM对科学产出的影响，但我们的发现受到若干局限性制约，这些局限性为未来研究提供了方向（见补充材料S4和S5）。首先，将估计的效应解释为因果效应需要满足一些难以满足的假设，因为研究“野外”LLM存在固有的数据局限性。我们的人工智能检测方法并不完美，容易受到若干挑战的影响（见补充材料S5.1至S5.4）：它依赖摘要而非全文（见补充材料S5.5），无法确切识别团队中哪位合著者使用了LLM（S5.6），并且几乎肯定会漏掉那些重度编辑LLM辅助文本的作者。此外，生成式人工智能工具的非随机采用可能产生自选择偏差，而我们关注已发布的预印本意味着“采用时间”可能与生产力内生相关。补充材料中包含许多额外分析来评估这些问题的范围，尽管我们的结果似乎稳健，但未来的工作必须继续寻找应对这些挑战的方法论策略。

其次，我们的发现只是快速发展的技术的一个快照。我们的分析基于更先进的推理模型和深度研究能力出现之前产生的数据。随着模型的改进和科学家发现将其融入工作的新方法，这些技术未来的影响可能会使我们在此强调的效应相形见绌。这为未来研究提出了一个关键方向：持续追踪科学事业如何吸纳相继几代人工智能模型。随着这些更强大的工具被整合到科学工作流程中，研究需要检验我们所记录的效应是被放大、改变，还是甚至逆转。

未来研究有许多方向。一个主要途径是更细致地探讨LLM如何影响科学实践。科学的进步长期以来一直受到非正式资源和知识获取的限制。一种假设是，LLM为这种非正式知识提供了可扩展的替代品，从实验设计到应对一个领域的隐性规则，提供全方位指导，从而为科学竞争创造公平环境。未来研究的另一个有趣途径是LLM超越学科边界的潜力。随着时间的推移，各学科发展出深厚的知识基础，而这些知识通常通过学科特有的术语来交流。如果LLM帮助局外人克服这一障碍，各自为政的学科之间可能会更有成效地互动。

我们的发现表明，LLM已经开始重塑科学产出。这些变化预示着研究格局将不断演变：英语流利程度的价值将减弱，而稳健的质量评估框架和深入的方法学审查的重要性将变得至关重要。对于同行评审员和期刊编辑，以及更广泛的创造、消费和应用这项工作的社群来说，这是一个重大问题。作为筛选科学研究的一种（不完美的）捷径，写作特征正迅速失去信息价值，与此同时科学交流的数量激增。随着传统启发式方法的失效，编辑和评审员可能越来越依赖作者背景和机构归属等地位标志作为质量信号，这反而抵消了LLM对科学产出的民主化效应。

一种可能的应对措施是利用同样的技术来协助评估稿件。专门的“评审智能体”可以标记方法上的不一致、核实声明，甚至评估新颖性。这种可扩展的方法是否能帮助编辑和评审员关注实质而非表面信号，或者给科学过程带来新的、不可预见的挑战，是一个关键的不确定性。
