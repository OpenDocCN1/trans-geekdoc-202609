
In the succeeding category, the approaches are developed for purely categorical data, although they have been applied to mixed data by transforming numerical types to categorical ones via a discretization scheme. This category of approach naturally aims to achieve the clustering of categorical data based on the measure of closeness, graph partitioning, or information entropy. For example, ROCK algorithm [58] is an agglomerative hierarchical clustering system based on the notion of closeness-based neighbors and links. Likewise, CLICK algorithm [59] discovers feature space clusters for categorical data by representing the data set as a graph with weights. Besides, the COOLCAT algorithm, an entropy-based method introduced in [60], uses data entropy to measure the closeness between instances and aims to find a structure to achieve a clustering by reducing the expected entropy of clusters. Furthermore, a method for categorical data clustering called LIMBO [61], which is based on data block organization [62], introduces the idea of mutual information to determine a clustering by minimizing the expected data cost. In general, all of the aforementioned methods can be applied to mixed data via a discretization scheme, which might incur a loss of information, e.g., the distinction between numerical values.

In the third category, a general clustering framework for mixed types is suggested. For example, the SBAC system [13] uses the Goodall similarity measure [63] to compute the similarity between data instances for mixed types. He et al. [17] proposed a USM-Squeezer scheme to cluster mixed types which is an extension of Squeezer clustering. In [18], research based on the spectral clustering method has been applied for mixed types clustering by incorporating the statistical similarity measure into the spectral clustering framework. In recent times, a clustering approach based on object-cluster similarity measure has been recommended; a unified similarity measure for both categorical and numerical types has been presented [20]. Moreover, a clustering model within the Bayesian statistical perspective has also been presented for mixed types [64], in which clustering results depend on successive partitions of quantized data and the final partition is obtained via a greedy methodology. Furthermore, to address the clustering problem in large-scale mixed data, Sangam and Om [65] recommended a mixture similarity measure to determine the correspondence between data instances and a cluster, by which a mixture data clustering system was also presented to assign proper cluster labels to the data instances that are not verified. Among this category of approaches, the prevalent one is centered on distance-based methodology, which defines similarity or dissimilarity measures for categorical data and then applies k-means approach for clustering analysis. In the K-prototype system [16], the similarity between instances is calculated with Hamming distance measure. Other similarity measures available in the related works include the distance measure based on association, Ahmad’s similarity measure, similarity measure based on perspective, and similarity measure proposed in [19].

K-prototypes algorithm [16] is a partition-based clustering algorithm that combines K-means [66] and K-modes [67] for handling mixed datasets. The algorithm depends on the concept of the K-means algorithm and it eliminates the numeric data constraint of that algorithm. The data instances are clustered against K-prototype and dynamically change the K-prototype so as to maximize the within-cluster similarity of instances. Initially, K instances are chosen for k clusters from the given dataset. Each instance is allocated to a group whose prototype is closest according to the dissimilarity metric. After the allocation of each instance, the cluster prototype is modified. Then computation of instance similarity measure is performed again. If any instance is closer to another cluster, then it is moved to that cluster. The process of computing similarity measures is repeated until there is no change in the clusters. An evolutionary methodology with a k-prototype scheme named Evolutionary K-Prototype (EKP) [68] is introduced for mixed features that performs better than a k-prototype system. Kullback-Leibler Fuzzy C-Means Gaussian Mixture Models (KL-FCM-GM) algorithm [69] is a fuzzy clustering algorithm for handling mixed datasets effectively. The algorithm makes use of probabilistic dissimilarity function for mixed datasets. The algorithm uses a fuzzy objective function normalized by Kullback-Leibler divergence and expressed on the basis of a set of likelihood assumptions concerning the process of inherited clusters. The given objective function is optimized over fuzzy membership functions, parameters, and the weight of clusters. Fuzzy K-prototype algorithm [70] is a fuzzy clustering algorithm and used to represent cluster prototypes by combining mean and fuzzy centroid. The data and features are grouped into different clusters with various membership functions. Initially, the algorithm takes input as number of clusters, maximum iterations, and the threshold value. The cluster prototype is divided into two parts. The first part computes the mean for numerical features, whereas the second part computes the fuzzy centroid for categorical features. The dissimilarity measure between two objects is computed and similar data objects are grouped into a single cluster. The clustering process is repeated until maximum iterations or stopping criterion is reached. Iterative clustering learning based on Object-Cluster similarity (OCIL) algorithm [71] describes an integrated similarity metric for mixed features based on the concept of instance similarity; and a parameter-free clustering scheme

K-Means Clustering for Mixed Datasets (KMCMD) algorithm [19] is a partition-based clustering algorithm that removes numeric data constraints of the K-means algorithm and overcomes the complexity of the K-prototypes algorithm. A similarity measure and the cost function is proposed depending on the co-occurrence of data features. The algorithm randomly assigns a cluster number to all the instances. Moreover, the cluster center is computed and allocates each instance to the nearest cluster. The cluster center is computed every time whenever a new instance is included. Assignment of instances and computation of cluster centers are repeated until the instances do not change in their clusters. Unlike the K-prototypes algorithm, the significance of the feature is computed by discretizing the numeric features. The contribution of numeric or categorical feature is computed from the similarity measure rather than defined by the user. The algorithm will work for pure numerical, pure categorical, and mixed features.

K-Harmonic Means type Clustering algorithm for Mixed Datasets (KHMCMD) algorithm [72] is an extension of K-Harmonic Means (KHM) algorithm [73]. KMCMD algorithm suffers from the initialization of centroid in a cluster. The result of the clustering algorithm depends only on the initial selection of centroid in a cluster. Random initialization of centroid in a cluster is a standard method. However, the results of the clustering algorithm are not robust to different initialization of centroid in a cluster. This issue is solved in the KHM algorithm for numeric features only. KHMCMD algorithm is used to solve the issue of initialization of centroid in a cluster of mixed datasets. Initially, the numeric data features are discretized to make categorical features. The dissimilarity measure computes the cost function in the fuzzy scenario for mixed datasets. Each instance is assigned to the cluster until no data points change the cluster membership or maximum iterations are reached. Khan and Amir [74] proposed a cluster center initialization algorithm. The algorithm computes multiple clustering of the data based on feature information in different features and produces deterministic modes that are to be used as initial cluster centers. Moreover, the algorithm selects the most relevant features and compares them with existing approaches to find significant features and perform multiple clustering of data to find initial cluster centers. Liang Bai et al. [75] proposed an initialization method for categorical features which is implemented to the k-modes algorithm. The method combines similarity and density to choose the initial cluster centers.
