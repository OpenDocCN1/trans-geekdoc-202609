## ABSTRACT

Clustering algorithms have attracted significant attention in machine learning applications owing to their great capability. Nevertheless, the existing algorithms still have some problems that need to be further addressed. For example, most existing algorithms transform one type of feature into another type, which disregards the explicit properties of information. In addition, most of them consider whole features, which may lead to difficulty in calculation and result in sub-optimal performance. To address the above difficulties, this paper proposes a novel technique for clustering categorical and numerical features based on feature space clustering of mixed data with missing information (FSCMMI). The procedure involves three stages. Initially, FSCMMI divides the given dataset depending on missing information in instances and features types. The second stage uses the decision-tree procedure to identify the association between instances. Finally, the third stage is used for computing the closeness measure for numerical features and categorical features. Meanwhile, we propose a new training algorithm to cluster mixed datasets. Extensive experimental results on benchmark datasets show that the proposed FSCMMI outperforms several state-of-the-art clustering methods in terms of accuracy and efficiency.

## 1. Introduction

With the ability to intelligently discover useful information from data in an unsupervised learning setting, clustering is regarded as an important process in the data mining field and has been widely applied to a variety of scientific areas, such as chemoinformatics, bioinformatics, and so on [1-6]. Therefore, some clustering methods are being proposed often for solving complex and real-world problems in diverse fields.

In general, compared to the development of classification in supervised learning [7-9], the clustering study requires data instances to be described by a set of related features that describe the properties of the instances that are useful for the learning task. Through the ever-increasing demands of clustering, two main challenges have emerged. The first, most of the existing clustering methods accept the data features only in numerical form [10-13]. However, as comprehensive measurements need to be collected from health, commercial, industrial, and public sectors, we usually need to deal with unconventional nominal features that are minimal valued, such as gender, blood pressure, sugar level, and type of disease [13]. In the existing clustering processes, this category of feature is referred to as categorical features. Consequently, data containing both numerical and categorical features is called mixed features.

To address mixed feature issues, the most straightforward method is to transform one type of feature into another. That is either convert the numerical system into a categorical system through the discretization procedure or a categorical system into a numerical system by using the encoding procedure. Nevertheless, transforming the structure will lose the similarity information contained in the original feature values, and, hence, cannot accurately reveal the structure of the data sets [13,14]. Besides, researchers have extensively examined state-of-the-art processes for clustering study of mixed data and some procedures have been suggested in [13] and [15-20]. However, as all these procedures handle information in the same way during the clustering practice, they create the additional problem that irrelevant features may have different contributions to the discovery of true clusters from the actual data. For example, if we aim to group patients by types of illnesses, gender data will be an important feature under different conditions, though unimportant for others. More precisely, feature space clustering is a promising approach for solving this problem [21].

This kind of clustering system aims to partition the data instances into clusters based on the feature spaces of data rather than the entire data sets. Despite the fact that intelligent systems such as dimensionality reduction lead to correlated measures, in feature space clustering, multiple clusters are usually learned from different feature subsets. In practice, if the actual dataset is very large during the clustering process, then the preprocessing phase is used for reducing the dimensionality of the instances using dimensionality reduction methods [22-26].

The effect of the constellation in the feature space clustering process is enhanced by using dimensionality reduction. Based on several approaches of groups that are stable, the feature space clustering practice can be distributed into two sets. In the beginning, a hard feature space clustering algorithm is used for searching the actual feature subsets for true clusters. Standard forms include [27-34]. The second category is soft feature space clustering, which trains the data set from the complete dataset, however, assigns different weights to each feature during the clustering process to control its effect on the discovery of different clusters. Classic methods are suggested in [35-40]. Nonetheless, all the aforementioned feature space clustering processes are used for grouping numerical types only, which limits the practical applications where categorical types exist. Likewise, few former researchers have focused on the feature space clustering of instances only with categorical features. One example contains the hard feature space clustering algorithm for categorical features presented in [41-44] and the soft feature space algorithm presented in [45-47]. Conversely, the research on feature space clustering of mixed features is still limited in scope.

More precisely, almost all existing clustering methods need input of the cluster number. Unfortunately, this vital information is not always available from the application point of view. Therefore, how to perform clustering tasks without knowing the actual cluster numbers is also an important issue in the clustering field [48]. To address this difficulty, numerous methods have been proposed that can estimate the cluster number for numerical or categorical instances [49-53]. Nevertheless, how to automatically select the number of clusters for mixed features during clustering has been rarely considered. Moreover, this problem becomes more complex in feature space clustering due to the largest feature sub-group and number of clusters being combined, i.e., different clustering results affect different feature subgroups [54].

Thus, this proposed process will focus on the clustering of mixed data without the number of clusters. Besides, a feature-weighted learning model is suggested and an innovative feature weighting method is presented along with the instance-cluster closeness metric clustering algorithm. These feature weights measure the effect of various numerical and categorical types on the discovery of true clusters. The feature weight of a specific cluster is determined by two characteristics. The primary characteristic is the inter-cluster closeness measure, which reflects the ability of the feature of a specific cluster to be distinguished from other clusters. The subsequent characteristic is the intra-cluster closeness measure, which measures the degree of similarity within a cluster. This incremental method is consistent with the basic idea of the clustering process. For example, unified principles are used to quantify the inter-cluster difference and intra-cluster similarity for numerical and categorical types; hence the proposed system can be applied to mixed features, numerical features, and categorical features. Moreover, an effective penalized competitive training procedure is also incorporated into the proposed feature space clustering process to enable it to learn the number of clusters automatically during the clustering assignment. Subsequently, the feature space cluster association and the optimal number of clusters can be obtained simultaneously from a single learning model. Moreover, the clustering effect achieved using random initialization in the k-means system remains unstable and an improved initialization technique for mixed types has not been considered in related works, we also introduce a technique for initialization that offers a significant clustering effect and improves the performance of k-means-type methods on mixed, categorical and numerical types. The effectiveness of the proposed methods has been experimentally verified on various benchmark data sets in comparison with existing methods.

The main contributions of this work can be summarized as follows:
- We propose a novel clustering process that utilizes the benefit of missing information to enhance the quality of clustering results. Initially, the proposed algorithm divides the given dataset depending on missing information in instances and features types. Moreover, the algorithm uses a decision-tree procedure to identify the association between instances.
- We propose a feature-weighted clustering process with missing information based on the instance cluster closeness metric for feature space clustering. This process is suitable for the three different types of features with missing information: such as pure numerical features, pure categorical features, or mixed data features.
- An innovative feature weighting scheme is introduced for mixed features, which adopts a unified measure to calculate the impact of different categorical or numerical features on the detection of every single cluster. This weighting scheme is the first one that simultaneously reflects the cluster separability and intra-cluster density of different types based on the likelihood distribution model.
- We introduce a novel penalized competition-based process within the proposed clustering process. The penalized competition process is used to determine the number of clusters automatically.
- Subsequently, an initialization-oriented procedure, which is beneficial to mixed types, numerical or categorical types is introduced. This method can improve the stability and accuracy of the k-means-type clustering system on various types of data sets.
- We demonstrate our algorithm achieved comparable or even better performance compared to the state-of-the-art on benchmark datasets.

## 2. Related works

### 2.1. Exploration of clustering using categorical and mixed features

The existing methods for clustering mixed types can be divided into three categories. Initially, common methods have been used to transform categorical types into numerical ones so that general methods for numerical types can be applied directly. For example, the encoding method proposed in [55] converts categorical types into vectors, where 1 in a specific position denotes the feature value and the remaining vector elements are 0. The density-based logistic regression method [56] converts all categorical types using the histogram associated with class labels. Moreover, Zhang et al. [57] introduced a diversified transitive distance learning and embedding framework to learn the pairwise dissimilarity between categorical feature values. As a result, each categorical instance can be represented by a numerical indicator using various learning techniques.
