# 7.4. The complexity of the proposed algorithm

The complexity of both the FSCMMI algorithm & RP-FSCMMI algorithm is O(TkFN), where T is the number of training steps, k is the total number of clusters, F is the total number of features and N is the number of instances. The time complexity of the IA-FSCMMI algorithm is O(kNF + (1/2)k²NF_NF), where k is the total number of clusters, F is the total number of features, F_NF is the number of numerical features and N is the number of instances. The space complexity of all the three algorithms requires O(k(F_NF + N + FM - F_NF M) + FN) where k is the number of clusters, F is the total number of features, F_NF are the numerical features, M is the maximal categories, and N is the number of data instances.

# 8. Conclusion

In this paper, we propose a novel clustering process that utilizes the benefit of missing information to enhance the feature of clustering outcomes. Initially, the proposed algorithm divides the given dataset depending on missing information in instances and features types. Moreover, the algorithm uses a decision-tree procedure to identify the association between instances. We propose a feature-weighted clustering process with missing information prepared on the prototypical of the instance cluster closeness metric is accessible for feature space clustering. This process is suitable for the three different types of features with missing information: such as pure numerical features, pure categorical features, or mixed data features. An innovative feature weighting organization is familiarized for mixed features, which agrees on a unified measure to calculate the impact of distinct categorical or numerical features on the detection of every single cluster. This weighting structure is the major one that simultaneously reflects the cluster characteristic competence and intra-cluster density of miscellaneous types made on the likelihood distribution model. We introduce a remarkable penalized competition-based process within the suggested grouping process. The remarkable penalized competition process is used to compute the number of clusters inevitably. Subsequently, an initialization-oriented procedure, which is beneficial to mixed types, numerical or categorical types is familiarized. This classification can grow the firmness and accuracy of the k-means-type clustering system on miscellaneous types of data sets. We demonstrate our algorithm achieved comparable or even better performance compared to the state-of-the-art on benchmark datasets.
