However, for the storage-chooser library, it should be noted that it is added as a dependency rather than as a "jar file. The procedure is shown through the following steps:

+   1. The build.gradle (Module: app) file can be found under Gradle Scripts, "Android" is selected on the project pane, as in Figure 4.9.

![](bbox=[0.297, 0.212, 0.705, 0.506])

Figure 4.9. Adding a dependency to Gradle.

2. Storage-chooser is then added to the project using the "implementation" tag, under "dependencies", as shown by the list in Listing 4.1. Upon changing this particular file, Android Studio will display a "sync" button as a notification, when clicked on, downloads the necessary files, and adds the library to the project.

# Listing 4.1. Adding dependencies to the project

```
dependencies {
implementation fileTree(include: ["*.jar"], dir: 'libs')
implementation 'android.appcompat:appcompat:1.1.0'
implementation 'android.constraint:constraintlayout:1.1.3'
implementation files('libs\CloudantManager.jar')
implementation files('libs\opencv-2.2.jar')

testImplementation 'junit:4.12'
androidTestImplementation 'android.test.ext:junit:1.1.1'
androidTestImplementation 'android.test.espresso:espresso-core:3.2.0'
implementation 'com.github.kodeix:storage-chooser:2.0.4.4'
}
```
