The inputs to the function are described below:

**Mdl:** Linear regression model.
**X:** Predictor data to be classified.

The function outputs array **ypred** which contains the predicted response for input **X.**

A demonstration of how the regression in the short-hand example may be implemented in MATLAB is given below,

The dataset is first loaded to MATLAB's workspace and the **fitlm** function is used to fit the car mileages with their corresponding car weights using the codes given in Listing 3.15.

# Listing 3.15. Simple linear regression- Load dataset

```
X = [1835 1970 2372 3086 3504 4341]; % Array with car weights
y = [26 31 24 14 18 15]; %Array with car mileages
l = fitlm(X,y); % Fit the simple linear model
```

To visualise the best-fit line alongside the training data, the simple regression model is used to predict the mileage for all car weights in array X, which are now treated as test data, by using the codes in Listing 3.16. The visualisation is in Figure 3.11.

# Listing 3.16. Simple linear regression - Visualise best-fit line

```
ypred = predict(mdl,X); %Predict mileage for car weights in X
plot(X,y,'o',X,ypred,'x') %Plot training dataset alongside predicted data
xlabel('Weight')\ylabel('Mileage')
legend('Data','Predictions')
```

Furthermore, the mileage for a car weight of 3000 pounds, which is not part of the training dataset can be predicted using the line of code given in Listing 3.17:

# Listing 3.17. Simple linear regression- Predict mileage

ynewpred = predict(mdl,3000) %Predict mileage for car of 3000 pounds
