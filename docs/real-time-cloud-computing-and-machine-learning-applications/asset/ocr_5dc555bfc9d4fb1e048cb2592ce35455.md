# 6.1.2. Related Works

This section focuses on the work that has been done on weather forecasting using different machine learning algorithms and the results obtained compared to traditional techniques.
The most common environmental conditions measured are temperature, precipitation, relative humidity, light intensity, and CO2 level. The main concepts of the architectures consist of an array of sensors connected to a microcontroller platform such as Arduino or Raspberry Pi where the data are sent to a computer or cloud computing platform for storage and processing. In [4], IoT proof of concept device was developed for remote weather monitoring. The authors used Twitter as a platform to disseminate the information collected by the different sensors. In [5], a flash floods warning system was developed based on the increasing water level and speed. The authors used Regression analysis to compute the predicted risk of a flood occurring on the current water speed and level. If the predicted risk exceeded a threshold, the threatened population and concerned authorities were alerted using an SMS system. In [6], the authors presented CloudCast, a mobile application that provides personalized short-term weather forecasting. The CloudCast architecture consists of linking weather radars to cloud resources and a Nowcasting algorithm based on the Nowcasting system operating in the CASA (Collaborative Adaptive Sensing of the Atmosphere) generates accurate short-term weather forecasts.
