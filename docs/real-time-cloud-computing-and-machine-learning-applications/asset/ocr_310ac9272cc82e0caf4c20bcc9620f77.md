# # 7.3. SERVLET PROGRAM FOR WEATHER FORECASTING AND DATA RETRIEVAL

In this section, a Java servlet is developed which presents the users with a webpage where they can perform the following actions:

+   - Perform prediction on the cloud and get the results on their device.
- Download weather data for a specific date or download only the last weather observations.
- Observe the variation of the weather parameters in a graph updated every 15 minutes. The update interval is chosen as 15 minutes because the values from the OpenWeather API are refreshed in the same interval.

The servlet is developed in Eclipse IDE which supports deployment on multiple servers such as a local Apache server or a predefined Cloudant server. The version of Eclipse IDE used “Eclipse EE IDE for Web Developers” available at https://www.eclipse.org/downloads/packages/. The version of the “Eclipse Tools for Cloud Foundry” plugin can be downloaded from the Eclipse Marketplace at https://marketplace.eclipse.org/. The plugin is used to interact with the IBM Cloud platform from the Eclipse IDE.
