The local server application makes use of two Java classes, called LocServer.java and localhostDatabase.java which can be portrayed through the methods in Table 5.2.

# Table 5.2. Main methods in LocServer.java

| Methods | Description |
| --- | --- |
| LocServer() | Is the constructor of that class initialises all components onto the GUI and creates the createGraphSpace() method which programmatically adds the live graph to it |
| createGraphSpace() | Allocates space for the live graph on the GUI by adding a chart onto a JPanel using the JFreechart chart |
| getNumberOfItems (Thread) | Retrieves the last index of records stored on the Cloud database before pushing values so that they can be entered in an orderly fashion. Uses the CloudClient and Database objects with varying database credentials depending on the device selected |
| launchMonitor ActionPerformed() | Uses the Server and Socket classes to create a server that receives connection from either the PC or Android device and prints the values into a live graph. Also adds the values to the Cloud database or localhost |
| launchLocalServer ActionPerformed() | Uses a Runnable thread named asLocalServer to download and analytics functionalities when an edge device connects to it via the PC's IP address. It works through the receipt of request codes, where each one denotes a particular function |
| stopMonitor ActionPerformed() | Stops the fetching process by interrupting the thread |
