The roundOutput(float[]) method takes input as an array of float and returns a array with every value rounded to one decimal place. It is given in listing Listing 7.27.

# Listing 7.27. roundOutput(float[]) method to round a float array to one decimal place

```
public static float[] roundOutput(float[] array) {
    DecimalFormat df = new DecimalFormat("###.##");
    df.setRoundingMode(RoundingMode.HALF_UP);
    for (int i = 0; i < array.length; i++) {
        array[i] = Float.parseFloat(df.format(array[i]));
    }
    return array;
}
```
