+   - Performing analytics involving both regression and classification using values from either the Cloudant database or the locally hosted databases.

The local server also has the possibility of pushing the received values to the Cloudant database or localhost via radio buttons. NetBeans IDE is used to create the interface for this application before implementing the back-end.
This section, therefore, entails the description of the local server software, running on a PC. Since both classification and regression are included in the analytics part, separate databases are created as shown in Section 4.5 to accommodate different inputs to the algorithms. The table names are given in Table 5.1 and the algorithmic processes involved are described below.

+   - Regression: The edges are made to stream videos, e.g., on the Twitch platform and only streaming values are pushed to a specific database on IBM Cloud and localhost. This eases the process of prediction since only one type of traffic is used and network parameters vary significantly with respect to time. This type of algorithm aims to predict the value of a variable at a time specified by the GUI.
- Classification: A different type of database is used for classification, which takes as input, the network parameters as well as a manually-entered description of the traffic being inserted, which includes the "idle,"browsing" and "streaming" states. This is performed so that upon retrieval, the algorithms used can be trained using the pre-labelled data. Classification algorithms refer to the categorisation of the parameters such that the type of traffic of user-input data is determined.

Table 5.1 shows the different algorithms to be used in this software, as well as the databases that they act upon. The Cloudant databases are filled and accessed for retrieval via their username, password and database name, while the localhost ones are accessed using their database and table names.
