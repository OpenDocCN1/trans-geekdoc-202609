# 6.4.4. The MainFrame Class

The MainFrame class is the main class responsible for displaying the GUI of the application, updating with the new incoming data from the API, and requesting the Java servlet for future forecasts. The forecasts are then displayed in the result JTextArea. The results contain the output of the algorithms implemented on the Java Servlet.
