# 6.4.4.6. The sendData ( l ) Method

This method is used to save a JSONObject to a Cloudant database. It accepts a JSONObject as an argument. The method works by first connecting to the Cloudant platform using a URL endpoint, username, and a password. The connection is made using a CloudClient object. A connection to a database in the platform is made using the database (String db, boolean create) method of the CloudantClient. Then, a query is formulated to select all the data in the database and sort in descending order. The last value of idx is obtained. The value of idx is incremented by one and added to the JSONObject.
