The dataset for the CNN network is generated using the generateMultiVarDataset () method of the DataSetIterator object. The CNN network is created using the ConvolutionalNetwork.builder() function. The CNN network consists of four layers that need to be configured. The configuration of the four layers is given the Table 7.20.

# Table 7.20. CNN Layers [4][5]

| Layer | Function |
| --- | --- |
| Input Layer | Hold the raw values of the dataset with only 1 channel. |
| Convolutional Layer | convolution is performed on the input data by the use of a filter or kernel (these terms are used interchangeably) to produce a feature map |
| Max Pooling Layer | Calculates the maximum, or largest, value in each patch of each feature map. |
