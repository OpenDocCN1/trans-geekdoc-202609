## 2.4.2. Service Classes

The National Institute of Standards and Technology (NIST) defines three service models, namely SaaS, PaaS and IaaS as shown in Table 2.1 [12].

Table 2.1. Cloud computing service classes

| Service Class | User Type | Resources Managed | Examples |
|---|---|---|---|
| SaaS | Business users | Business Applications, Web Services, Multimedia. | Google Apps, Facebook, Youtube, Salesforce.com |
| PaaS | Developers, Architects, Deployers | Software framework (Java, Net Storage, Databases, Runtimes.) | Microsoft, Google App Engine |
| IaaS | System Administrators | Virtual Machines, CPU, Memory, Bandwidth. | Amazon EC2, GoGrid, Flexiscale, Data Centers |

The NIST defines the three basic service classes as follows [12]:

- (i) Software as a Service (SaaS): In this class, the applications running on a cloud infrastructure owned by the Cloud Service Provider (CSP) are leased to the Cloud Service Customer (CSC). The applications can be accessed through different types of client systems which can be a 'thin' client terminal as a common web-browser, a dedicated programming interface or even an Integrated Development Environment (IDE). The CSC does not manage or control the underlying cloud infrastructure including network, servers, operating systems, storage, or even individual application capabilities. With the possible exception of some restricted user-defined configurations and settings for the application, which can be set by the CSC, the core cloud infrastructure includes the network, servers, processors and operating systems are fully managed by the CSC [12].

- (ii) Platform as a Service (PaaS): In this service class instance of the platform owned by the CSC is leased to the CSCs who can deploy the applications that they have been developed using their own programming applications, over the CSP's platform. Apart from the deployed applications and restricted user-defined configurations and settings for the application, which can be set by the CSC, the core cloud infrastructure which includes the network, servers, processors and operating systems are fully managed by the CSP [12].

- (iii) Infrastructure as a Service (IaaS): In this service, an instance of the infrastructure (typically virtualized processing, storage and other resources) owned by the CSC is made available to the CSC. The CSC can deploy and execute different types of software such as operating systems and programming environments, on that leased infrastructure remains under full control of the CSP, but the CSC can control all the applications that it has deployed on the CSP's infrastructure including security and network settings that are specific to the host device [12]. Cloud service classes have also evolved and more specific service classes include Analytics as a Service (AaaS), Network as a Service (NaaS), Mobile Backend as a Service (MBaaS), Mobile Network-as-a-Service (MNaaS), and Communications as a Service (CaaS).

## 2.5. INTRODUCTION TO THE FIREBASE PLATFORM

Firebase is a mobile and web application development platform. It offers a wide spectrum of technologies and services to assist them in the development of sophisticated apps, to expand their customer pool and become more profitable. Initially, in 2011, Firebase was a startup named Envolve, which enabled developers to integrate online cloud capability into their website via an API [13].

In addition to chat messages, other forms of application data could be passed by Envolve. For example, application data such as a game state, could be synched in real time between users by the developers of Envolve. Subsequently, the chat system was separated from the real-time architecture by the founders of Envolve. In April 2012, Firebase was set up as a distinct company that offered Backend-as-a-Service (BaaS) with real-time capability. Firebase then quickly developed into a multi-functional mobile and web platform, following its acquisition by Google in 2014 [14]. Firebase is a comprehensive mobile/web development platform with the following features [15]:

- Build better apps: Cloud Firestore, Machine Learning Kit, Cloud Functions, Authentication, Hosting, Cloud Storage, Realtime Database.
- Improve app quality: Crashlytics, Performance Monitoring, Test Lab.
- Grow your business: Google Analytics, Predictions, A/B Testing, Cloud Messaging, Remote Config, Dynamic Links, App Indexing.
