## 7.1.4.4. The w_varActionPerformed() Method

The variable on the graph can be changed by selecting another variable in the JComboBox. The w_varActionPerformed() method is bounded to the JComboBox. In the method, after the user has selected a new item, a check is performed to know whether a new item has been selected and so, the following actions are performed:

- The value of the parameter is updated with the new value
- The XYSeries is cleared of any data
- The counter is reset to zero
- The key for the XYSeries is set to the new parameter
- The chart is informed of change with the fireChartChanged() method.

The codes for clearing the graph are given in Listing 7.4 below.

## Listing 7.4. Clearing the graph

```java
private void w_varActionPerformed(java.awt.event.Event event) {
  //GEN-FIRST:event_w_varActionPerformed
  /*After interaction with the JComboBox*/
  //get the currently selected item of the JComboBox
  String temp = (String) w_var.getSelectedItem();
  if (!temp.equals(parameter)) {
    //update the value of w_param *
    parameter = temp;
    //clear the XYSeries of any values
    xy_series.clear();
    //reset the counter to zero
    x = 0;
    //set the key of the series to the newly selected item
    xy_series.setKey(parameter);
    //informs all listeners of a change in the chart
    chart.fireChartChanged();
  }
}
```

## 7.1.5.2. The fetchLastName() Method

This method is used to fetch the last N records from the local database. The following steps are performed to fetch the last N records:

- A Statement object for sending SQL statements to the database is created.
- A query to select the last N records is formed and executed to obtain a result set
- The result is iterated one result at a time and the timestamps are extracted and stored in a string array and the weather parameters are stored in a double array.
- An object array is created to return multiple types of arrays into a single array.

The codes are given in Listing 7.9.

## Listing 7.9. fetchLastN method

```java
public Object[][] fetchLastN(int N) {
  double[] result = new double[N][7];
  String[][] timestamps = new String[N];

  try {
    //Creates a Statement object from mysqlconnector library for sending SQL
    //statements to the database.
    Statement stmt = conn.createStatement();
    //Executes the given SQL statement, which returns a single ResultSet object.
    ResultSet resultSet = stmt.executeQuery("SELECT * FROM weather_params ORDER BY id DESC LIMIT " + N);

    // Iterate through the ResultSet and fill the array from the end since the data
    // is in reversed order
    int j = N - 1;
    //While resultset.hasRecord() ...
    while (resultSet.next()) {
      timestamps[j] = resultSet.getString(2);
      //fetches the weather parameters starting from column 3 and store them in
      // a column in result
      for (int i = 0; i < 7; i++) {
        result[j][i] = resultSet.getDouble(i + 3);
      }
      j--;
    }
  } catch (SQLException ex) {
    Logger.getLogger(SQLConnector.class.getName()).log(Level.SEVERE, null, ex);
    //Creates an array to return multiple types of arrays into a single array
    return new Object[][]{timestamps, result};
  }
}
```

## 7.1.5.3. The fetchForDate() Method

This method is used to fetch all the records for a specific date from the local database. The following steps are carried out to the last N records:

- A Statement object for sending SQL statements to the database is created.
- A query to select all the records for a specific date is formed and executed to obtain a result set
- The result set is iterated once to get the size of the result set to initialize the arrays.
- The query is re-executed and the data is stored in the appropriate arrays.
- An object array is created to return multiple types of arrays into a single array.

The codes are given in Listing 7.10.

## Listing 7.10. The fetchForDate Method

```java
public Object[][] fetchForDate(String date) {
  double[] result = null;
  String[] timestamps = null;
  try {
    //Creates a Statement for sending SQL statements to the database.
    Statement stmt = conn.createStatement();
    //Executes the SQL query, returns a single ResultSet object.
    ResultSet resultSet = stmt.executeQuery("SELECT * FROM weather_params WHERE Timestamp LIKE '" + date + "%'");
    //iterate through the result_set to find the number of records
    int N = 0;
    while (resultSet.next()) {
      N++;
    }
    //Execute the query once we have the size, so that we initialize the array
    resultSet = stmt.executeQuery("SELECT * FROM weather_params WHERE TIMESTAMP LIKE '" + date + "%'");
    result = new double[N][7];
    timestamps = new String[N];
    //Iter through the ResultSet and fill the data and timestamps array.
    int j = 0;
    while (resultSet.next()) {
      timestamps[j] = resultSet.getString(2);
      // fetches the weather parameters starting from column 3 and store it
      for (int i = 0; i < 7; i++) {
        result[j][i] = resultSet.getDouble(i + 3);
      }
      j++;
    }
  } catch (SQLException ex) {
    Logger.getLogger(SQLConnector.class.getName()).log(Level.SEVERE, null, ex);
  }
  return new Object[][][]{timestamps, result};
}
```
