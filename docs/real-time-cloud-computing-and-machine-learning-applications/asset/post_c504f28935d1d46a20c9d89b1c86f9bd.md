## 7.1.15. Rounding the Output to Decimal Field

To round the output to one decimal, the roundOutput() method in MainFrame class is used. This method uses DecimalFormat class which has a variety of features designed to make it possible to parse and format numbers in any locale. The code for the method is shown in Listing 7.20.

# Listing 7.20. output to 1 decimal

```java
/**
 * @param array An of values that need to be rounded off to 1 dp
 * @return array rounded values to 1dp
 */
public static float[] roundOutput(float[] array) {
  DecimalFormat df = new DecimalFormat("#.#");
  df.setRoundingMode(RoundingMode.HALF_UP);
  for (int i = 0; i < array.length; i++) {
    array[i] = Float.parseFloat(df.format(array[i]));
  }
  return array;
}
```

## 7.1.16. Converting a Double Array to Float

Since the neural network accepts data in float type and the Retriever Class returns a two-dimensional array of double, the convertToFloat() method is used to convert the double array to float array by casting every element to float. The codes are given in Listing 7.21.

# Listing 7.21. Convert double array to float

```java
private static float[][] convertToFloat(double[][] array) {
  int col = array[0].length;
  int row = array.length;
  float[][] data = new float[row][col];
  for (int i = 0; i < row; i++) {
    for (int j = 0; j < col; j++) {
      data[i][j] = (float) array[i][j];
    }
  }
  return data;
}
```
