2. The live graph is automatically started upon the loading of the web page through the window.onload function, detailed in Listing 5.56, which performs the following functions:

- Fetches the selected parameter from the "Select" component.
- Creates an array denoted as dataPoints which holds the values to be printed on the graph.
- Initialises the Chart container by specifying details for the graph, such as its title in which case is the selected parameter stored in the variable "selectedParameter."
- The nested function updateData() is then called. It fetches the last set of values from the livegraph.javascript server, using the "livegraph" mapping.
- The variables are extracted from the JSON response before being stored into a set of variables of type var.
- The function addData() pushes the values onto the live graph. Since the default parameter on the "Select" component on the web page is "Download Speed," the latter is used for the window.onload function.
- The setInterval() method is set to update the live graph at a rate of five seconds, which means it calls the updateData() method after every five seconds. The logic thus resembles an ongoing loop.

3. The refresh() method is invoked whenever a change occurs on the "Select" components and functions using the same principles in the previous step. This means that either the parameter selection or the data source selection components trigger this method. The printing of all the values is accommodated for using a series of "if" statements in the addData() method, which pushes the values on the live graph. Therefore, the selected parameter can be printed on the graph depending on the choice of the user. The title of the y-axis is also changed dynamically. This is shown in Listing 5.57.

Listing 5.57. Refreshing the live graph when the selected parameter or data source is changed

```javascript
function refreshGraph(parameterSelection) {
  // Variable to store the fetched variables
  var downloadSpeed;
  var uploadSpeed;
  var packetsReceived;
  var packetsSent;
  var yAxisUnit;
  // Variable to store the
  var ipAddress;
  // Variable to store the selected
  var selectedParameter = parameterSelection.options[parameterSelection.selectedIndex].innerHTML;
  // Detecting which item is selected
  // display on the "Select" component
  var selectedSource = sourceSelection.options[sourceSelection.selectedIndex].innerHTML;
  // Variable to hold the
  var dataPoints = [];
  // Initialising the
  var chart = new CanvasJS.Chart("chartContainer", {
    theme: "light2",
    title: {
      text: selectedParameter
    },
    xAxis: {
      title: "Time/s"
    },
    axisY: {
      title: yAxisUnit
    },
    data: {
      type: "line",
      dataPoints: dataPoints
    }
  });
  // Updating the graph
  updateData();
  // Initial values
  var xValue = 0;
  var yValue = 0;
  var newDataCount = 1;
  function updateData() {
    // Fetching from the
    var queryLive;
    if(selectedSource === "Cloud") {
      // Fetching from cloud database
      queryLive = "https://networkcloud-gb.mybluemix.net/livegraph?source=1";
    } else if(selectedSource === "Local") {
      // Fetching from local server on port 8080
      queryLive = "http://" + ipAddress + ":8080/livegraph?source=2";
    }
    // Fetching the last set of values
    fetch(queryLive).then(function(response) {
      return response.json();
    }).then(function(data) {
      console.log(data);
      // Retrieving the values from the JSON response into variables
      downloadSpeed = data.downloadSpeed;
      uploadSpeed = data.uploadSpeed;
      packetsReceived = data.packetsReceived;
      packetsSent = data.packetsSent;
    }).catch(function(e) {
      console.log("Error in retrieving");
    });
  }
  function addData(data) {
    // Creating a variable to hold the particular parameter to be pushed
    var valuePush;
    // Detecting the selected parameter comparing with the String set
    // display on the "Select" component
    if(selectedParameter === "Download Speed") {
      valuePush = downloadSpeed;
      yAxisUnit = "Kbps";
    } else if(selectedParameter === "Upload Speed") {
      valuePush = uploadSpeed;
      yAxisUnit = "Kbps";
    } else if(selectedParameter === "Packets Received") {
      valuePush = packetsReceived;
      yAxisUnit = "Packets";
    } else if(selectedParameter === "Packets Sent") {
      valuePush = packetsSent;
      yAxisUnit = "Packets";
    }
    // Pushing the required value on the graph
    dataPoints.push(x: xValue, y: valuePush);
    // Iterating the timestep by 5 seconds
    xValue = xValue + 5;
    yValue++;
    newDataCount = 1;
    chart.render();
  }
  // Updating the live graph every 5 seconds
  setTimeout(updateData, 5000);
}
```
