+   $eta_1 X^1$ - the regression coefficient ($eta_1$) of the independent variable ($X^1$) raised to the first degree
$eta_i X^i$ - the regression coefficient of the independent variable raised to the $i^{th}$ degree
$\epsilon$-model error i.e., variation in the estimate of y.

The polynomial regression model can be represented in matrix form in terms of a model matrix $\mathbf{X}$, a response vector $y$, a regression coefficients $eta$ and a vector of errors $\epsilon$. The model can then be expressed as a system of linear equations as follows [1]:

```
$$\begin{matrix} y_1 & x_1 & x_1^2 & \dots & x_1^m & eta_1 \ y_2 & x_2 & x_2^2 & \dots & x_2^m & eta_2 \ y_3 & x_3 & x_3^2 & \dots & x_3^m & eta_3 \ \vdots & \vdots & \vdots & \ddots & \vdots & \vdots \ y_i & x_i & x_i^2 & \dots & x_i^m & eta_i \end{matrix} (7.7)$
```

The vector of estimated coefficients $eta$ can be estimated using the Ordinary Least Squares method by QR decomposition. The equation below shows the polynomial regression equation for any weather parameter, V1:

```
$V_{1t+n} = eta_0 + eta_1 t_1^{(t+n)} + eta_2 t_2^{(t+n)} + eta_3 t_3^{(t+n)} (7.8)$
```

For a polynomial regression model, the following steps are followed:

+   1. The design matrix $\mathbf{X}$ is generated from the first independent variable array (double [] var1) with a column consisting of ones for the Y-intercept according to Equation (7.7).
2. The response array, $y$, is created from the second independent variable (double [] var2).
3. An OMLinearRegression model is created using the design matrix $\mathbf{X}$ and output vector $y$.
4. The regression coefficient is calculated using the least square solution, evaluated using the QR-decomposition as per Equation (7.4).
5. The predicted value is calculated using Equation (7.8) using Horner’s method.
