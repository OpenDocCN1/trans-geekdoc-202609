# 6.4.4.2. Global Variables

The MainFrame class nine global private variables. The functions and variable names of each variable are summarized in Table 6.7. The declarations for the global variables are given in Listing 6.24.

# Table 6.7. MainFrame Class Global Variables

| No. | Variable Name | Variable Type | Function |
|---|---|---|---|
| 1 | URL | String | A string of the URL endpoint for requesting data from the OpenWeather API |
| 2 | chart | JFreeChart | A Chart GUI implemented using the Java 2 APIs |
| 3 | xy_series | XYSeries | Represents a sequence of zeros or more data items in the form (x, y). |
| 4 | parameter | String | String value of the variable being displayed |
| 5 | timer | Timer | A class to schedule for future execution in a background thread. Used to periodically fetch data from the API. |
| 6 | x | int | Counter for XYSeries collection |
| 7 | monitoring | boolean | Used to determine whether the monitoring process has started or not. |
| 8 | fetchdate | boolean | Boolean that indicates whether to download from the cloud |
| 9 | src_local | boolean | Boolean that indicates whether to download from the cloud or local server |
