Similar to the desktop application the jsoup-1.13.jar file [37] will have to be added to the libs file of the project and as a dependency in the gradle.build. The main class of this application is the CalculateArea.java file given in Listing 2.12 However, it is to be noted that another class called QueryServer extends the AsyncTask class [40] has been incorporated into the CalculateArea.java class to handle the query and response part of the application. In fact the AsyncTask is an abstract class that allows heavy tasks to be performed in the background and makes the application more responsive by minimizing the workload on the UI thread. Android applications can become non-responsive when running on one thread started. Consequently, the application can have a higher execution delay, hence more time to respond. The AsyncTask can solve this by executing the time-consuming tasks on a separate thread and transferring the results back to the UI thread. It is therefore convenient to use it for the query and response part of the application. The two main methods associated with the AsyncTask used in this project are as follows:

doInBackground(): This method contains the code which needs to be executed in the background. To notify that the background processing has been completed a return statement is used.

onPostExecute(): This method is called after the doInBackground method completes processing. The result from the doInBackground method is passed to the method.
