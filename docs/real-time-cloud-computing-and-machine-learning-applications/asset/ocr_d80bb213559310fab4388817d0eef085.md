+   * Gets the regression window size from the "window_size" textField
* Gets the prediction time from the "prediction_time" textfield
* Forms the request URL using the formRequestURL() method
* Appends the servlet name, window size, prediction time, and data source to the URL
* Using the global "fetch()" method that provides an easy, logical way to fetch resources asynchronously across the internet, a connection to the URL is opened. * Extract the results from JSONObject returned and display it in the result TextArea.

The codes are given in Listing 7.34.

# Listing 7.34. getAnalytics () Result

```
function getAnalytics() {

//Get the regression window size
var window_s = document.getElementById("window_size").value;
//Get the prediction time
var pred_time = document.getElementById("prediction_time").value;
//Get the request URL
var query = formRequestURL();
var request = query.URL + "Forecaster?window_size=" + window_s + 
"&prediction_time=" + pred_time + "&data_src=" + 
query.data_src;

fetch(request)
  .then((res) => res.JSON())
  .then((out) => {
    document.getElementById("results").value = out.results;
  }).catch((err) => console.error(err));

}
```
