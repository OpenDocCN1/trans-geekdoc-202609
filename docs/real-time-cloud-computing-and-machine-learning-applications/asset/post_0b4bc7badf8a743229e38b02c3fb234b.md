
## 7.4. WEB CLIENT APPLICATION FOR WEATHER FORECASTING AND ANALYTICS

This section describes the steps followed to create a web client application that interacts with the java servlet hosted on the cloud to provide users with analytics results, weather data download and a graph that shows a live feed of the variation in the weather parameters.

### 7.4.1. HTML Page for User Interaction

When users connect to the servlet, they are presented with an HTML page where they can interact to obtain predictions, download weather observations, or observe the variation of the different weather parameters in real-time. Figure 7.36 and Figure 7.37 show the user interface of the HTML Page and function of each element. The HTML page is added in the "WebContent" folder of the WeatherForeaster Project.
