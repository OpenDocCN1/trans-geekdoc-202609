# 7.1.5.1. SQLConnector() Constructor

This is the main constructor of the class. It first loads the class using the Class.forName() method. Then, a Connection to the database is established using the DriverManager.getConnection() method. The default MySQL server is hosted on port 3306 and the root user does not require a password to log in. This method requires the following parameters:

+   - MySQL server URL – "jdbc:mysql://localhost:3306/weather_data"
- User – "root"
- Password – ""

The codes are shown in Listing 7.8.

# Listing 7.8. SQLConnector Constructor

```
public SQLConnector() {
    //Used to load the class dynamically
    Class.forName("com.mysql.jdbc.Driver");
    //Attempts to establish a connection to the given database URL.
    Connection con = DriverManager.getConnection("jdbc:mysql://localhost:3306/weather_data",
    "root", "");
} catch (ClassNotFoundException ex) {
    Logger.getLogger(SQLConnector.class.getName()).log(Level.SEVERE, null, ex);
}
```

# 7.1.5.2. The fetchLastName() Method

This method is used to fetch the last N records from the local database. The following steps are performed to fetch the last N records:

+   - A Statement object for sending SQL statements to the database is created.
- A query to select the last N records is formed and executed to obtain a result set
- The result is iterated one result at a time and the timestamps are extracted and stored in a string array and the weather parameters are stored in a double array.
- An object array is created to return multiple types of arrays into a single array.
