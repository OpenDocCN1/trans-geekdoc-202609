Multiple output models are more complex as they can learn the structure between inputs and outputs as well as outputs. Being more complex may mean that they are slower to train and require more data to avoid overfitting the problem. To train such a model, the input data needs to be formatted in the appropriate format. The following shows an example where the next two temperature values are predicted using the previous six readings of the data in Table 7.14.

# Table 7.16. Data format for Multivariate Output Method

| Input | | | | | | | Output |
| 20 | 19.9 | 19.8 | 19.7 | 19.6 | 19.5 | 19.4 | 19.3 |
| 19.9 | 19.8 | 19.7 | 19.6 | 19.5 | 19.4 | 19.3 | 19.2 |
| 19.8 | 19.7 | 19.6 | 19.5 | 19.4 | 19.3 | 19.2 | 19.1 |
| 19.7 | 19.6 | 19.5 | 19.4 | 19.3 | 19.2 | 19.2 | 19.1 |
| 19.6 | 19.5 | 19.4 | 19.3 | 19.2 | 19.1 | 19 | |

A window of six values is used to obtain the input and the output is the next two values that come after. The window is moved by one sample and the operation is repeated until one of inputs and outputs is obtained.
