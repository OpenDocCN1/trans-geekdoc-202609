# 7.1.12.4. CNN Model Creation, Training & Prediction

The CNN model is used to build a model for a multivariate prediction for all the weather parameters. Training data consisted of the previous week's weather observations and using a time step of one day (9 samples) to predict for the next 15 minutes. The CNN model is a feedforward network with an input and output layer. The class CNNRegression contains the code for the creation, training, and prediction using CNN. The codes are given in Listing 7.17.

# Listing 7.17. CNNRegression Class

```
package NeuralNetwork;
//Imports the ConvolutionalNetwork Class to create a CNN Network
import deennets.FeedForwardNetwork;
//Class used to set the activation function of the hidden layers
import deennets.layers.activation.ActivationType;
//Used to set the LossType of the network -> evaluates the performance
import deennets.loss.LossType;
//Backpropagation training algorithm for feedforward and convolutional neural networks.
import deennets.train.BackpropagationTrainer;
//Class used to store data in multidimensional arrays
import deennets.util.Tensor;
//Java to manipulate arrays
import java.util.Arrays;
public class CNNRegression {
private DataSetIterator dataset;
private ConvolutionalNetwork network;
// ConvolutionalNetwork class from the DeepNets Library
public CNNRegression(float[] data, int tf, int tn) {
//Create a new DataSetIterator object using the weather data
dataset = new DataSetIterator(data, tf, tn);
//reshape the data for the CNN Network
dataset.generateMultVarDataset();
//get the number of variables to be predicted
int col = data[length];
//Create a new Convolutional Network for regression
network = ConvolutionalNetwork.builder()
.addInputLayer(col, tf, 1)
.addConvolutionalLayer((col, 1, 1)
.addMaxPoolingLayer(1, 1, 1)
.addOutputLayer((col * tn, ActivationType.TANH)
hiddenActivationFunction(ActivationType.TANH)
.lossFunction(LossType.MEAN_SQUARED_ERROR)
.randomSeed(123)
```
