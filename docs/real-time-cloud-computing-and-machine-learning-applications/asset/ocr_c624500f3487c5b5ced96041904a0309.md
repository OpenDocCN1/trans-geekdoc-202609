For a given input, the denominator remains constant for the conditional probabilities calculated in each class. Hence the equation can be simplified as follows:

```
$: P(C|X_1, X_2, \dots, X_n) \propto P(C) \prod_{i=1}^{n} P(X_i|C) \quad (3.19)$
```

Equation (3.19) is the classifier model which will be used to classify new data. The conditional probabilities $P(X_i|C)$ and $P(C)$ in equation (3.19) are pre-calculated using the training dataset and will be used in the calculation of the conditional probabilities of each class given features of new data.
