#  4.3.11.4. Download Last N Samples Button

Defined inside onCreate(), this button has the following functionalities:

+   * Determining the selection option on the number of values to be printed
* Creating an automatic file name based on the radio button, and the source selected on the radio button, i.e., either "Cloudant" or "Local.\n* Creating two threads with the Runnable class whereby one caters for the fetching process from the Cloudant database, and the other, from the local server.

The "download" Runnable thread can be described as follows:

+   * Uses the List object to store the variables to be sent via a for loop encompassing the last "N" number of records by converting the variables of type to String
* Uses the CSVWriter class from the OpenCSV library [14] to write the List object to the destination previously.

On the other hand, the "downloadlocalhost" Runnable thread bears the following properties:

+   * Fetches the IP address entered by the user on the GUI.
* Contacts the local server on NetBeans via a Socket connection using a JSONObject with a request code of "one" as an integer.
* Uses a BufferedReader object to receive the output from the local server via an input stream from the Socket object.
* Writes the values to the application into a .csv file at the location chosen using the "Browse" button, using a PrintWriter object.
