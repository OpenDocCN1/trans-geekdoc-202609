The first six rows are used as input to the network while the following two rows are used as output. However, the output needs to be flattened since the output layer is a fully connected layer. Then, the window is moved one row downwards and the process is repeated until the end of all the observations is reached. However, in transforming the training data into an input/output sample, some values will be discarded where there are no values for the output. For example, if the window starts at observation number 4, the window will end at observation number 9 while there will be only input for the sample and no output data.

This means that for $N$ observations with $t_i$ input time steps and $t_n$ output time steps, there will be $N-t_n$ used observations. Hence, the size of the input and output timesteps determine how much of the training data is used.

The class DataSetSetter contains the code for the generation of the training dataset. This class extends the TabularDataSet class which is a class that represents basic data in tabular form. It is used for neural networks in Deep Nets. By extending this class, it is possible to create a custom TabularDataSet class that generates a dataset for both, the MLP and CNN network.

This class is used to generate a training dataset. The class is responsible for the following function:

+   * Normalises the observations array within the range $0 < X < 1$
* Generates a dataset for the MLP network
* Generates a dataset for the CNN network
* Fetches the last $t_f$ values of a weather parameter for input to the MLP network
* Fetches the last $t_f$ weather observations for input to the CNN network
* Denormalises the output of the MLP network (float value representing a single parameter)
* Denormalises the output of the CNN network (float array containing the seven parameters)
