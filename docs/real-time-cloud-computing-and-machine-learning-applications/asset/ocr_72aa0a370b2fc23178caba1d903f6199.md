# 3.4.2.2. Convolutional Neural Network

Convolutional Neural Networks (CNNs) are advanced neural networks that can learn without the need for manual feature extraction and are widely used in object recognition applications [44]. A CNN is composed of an input layer, multiple hidden layers and an output layer (similar structure to MLPs). The neurons in a CNN layer are high-dimensional filters that are connected with the input of the layer. The CNN perform data classification based on multiple abstract feature representations obtained from the input [45]. This concept is illustrated in Figure 3.24.
