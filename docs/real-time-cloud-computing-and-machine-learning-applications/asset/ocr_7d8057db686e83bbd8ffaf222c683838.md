# 7.1.7. Regression Class

This class is responsible for creating either a Linear Regression or Polynomial Regression model for prediction. To use the class, a Regression object is created first. The type of regression is specified by a String using the setType() method. If a polynomial regression model is needed, the degree of the model is specified using the setDegree() method. Then, the window size is set using the setWindow() method. Finally, prediction is done using the predict() method. Method takes as input two arrays and an integer representing the prediction time, then, outputs the predicted value. The methods of the class are given in Table 7.7 along with a description of what function they achieve.

# Table 7.7. Regression Methods

| Method | Description |
| --- | --- |
| setType (String type) | Sets the type of regression model that is needed according to the String type.
"Polynomial" – Polynomial Regression model
Linear" – MLR model |
| setDegree (int degree) | Sets the degree of the regression model. |
| setWindow (int window) | Sets the window size of the regression model. |
| predict(double[] var1,double[] var2,int time) | Predicts the next value at time using the two arrays as data for input and output. |
