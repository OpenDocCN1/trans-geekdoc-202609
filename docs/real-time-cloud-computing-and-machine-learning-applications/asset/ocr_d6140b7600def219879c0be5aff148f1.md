# 6.3.27.2. getNoRows() Method

This method is used to find the total number of records in the cloud database. Each record contains a key labelled "idx" which is used as the primary key. Each new time record is added, the value of "idx" is incremented by one. To find the last value of "idx", a query is formulated that selects all the data in the database and sorts them in descending order. The codes for the process are given in List 6.21.

# List 6.21. getNoRows Function

```
private double getNoOfRow() {
//Expression from CloudantClient used to represent the evaluation (idx > 0)
Expression selector = gt("idx", 0);
//Construct a query using the expression and sort by descending order
QueryBuilder query = new QueryBuilder(selector).sort(Sort.desc("idx"));
//Query the database using the constructed QueryBuilder
QueryResult-LinkedTreeMap result = db.query(query.build());
LinkedTreeMap class;
//Get a list of document matching the search
List-LinkedTreeMap resultList = result.getDocs();
//return the maximum value of idx -> first result
return (resultList.size() > 0) ? (double) resultList.get(0).get("idx") : 0;
}
```
