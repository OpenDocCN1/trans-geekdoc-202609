# 4.3.10.2. The “Classify” Button

This button queries the servlet or the local server, for classification analytics through the use of real-time values from MainActivity.java that can the current activity status of the device is obtained. In this case, the code automatically detects if the user is using Wi-Fi or LTE values by detecting if LTE values are above zero. This alerts the URL that queries the servlet, through the specification of the “device” variable, which is 2 for Wi-Fi values and 3 for LTE values. The “action” in this case is specified as 1 for classification analytics, as explained in Table 5-18 from Section 5.3. As for the local analytics, the request codes are as per Table 4.3.
