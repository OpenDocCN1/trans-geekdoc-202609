# Introduction

## 1.4. BOOK OVERVIEW

This book is structured into seven chapters. In the first i.e. the current chapter, an overview of cloud computing and machine learning applications and benefits has been provided. The chapters which follow provide a more in-depth treatment on these paradigms. A brief outline of these chapters is as follows.

Chapter 2 deals with the fundamental concepts of cloud computing such as its terminologies, paradigms, architectures and service classes. It introduces the Firebase cloud platform with a detailed treatment on how to host a mobile and web application on the Firebase cloud platform. It also introduces the IBM cloud platform and demonstrates the hosting of a mobile and desktop application as well as a servlet on this platform.

Chapter 3 gives an in-depth review of machine learning algorithms. Detailed shorthand examples as well as Matlab have been provided to fully explain the operation of the algorithms. Moreover, at the end of the chapter, a web application to perform simple machine learning tasks is developed and hosted on the Firebase cloud platform as a simple illustration of combining machine learning with cloud computing.

Chapter 4 shows how the client side and data capture architecture of a real time network monitoring and analytics system can be developed. The data capture application was developed for both mobile and desktop platforms. The setting up of the cloud database for the network data has also been explained in details.

Chapter 5 describes the development of a local server as well as a Servlet to perform real-time analytics on the network data received from the data capture applications developed in Chapter 4. The Servlet was also hosted on the IBM cloud platform to benefit from its computing resources and hosting facilities. Moreover, a web client was developed for easier deployment.

Chapter 6 describes how the client side and data capture architecture of a real time weather forecasting and analytics system can be developed. The data capture application was developed for both mobile and desktop platforms. The setting up of the cloud database for the weather data has also been explained in this chapter.

Chapter 7 describes the development of a local server as well as a Servlet to perform real-time analytics on the weather received from the data capture applications developed in Chapter 6. A web client was also developed for easier deployment.
