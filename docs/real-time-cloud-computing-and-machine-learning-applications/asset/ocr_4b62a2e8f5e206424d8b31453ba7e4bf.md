# Listing 32. K-Means clustering- Cluster data

| X=[Weight Mileage]; % Combine data |
| [idx,C] = kmeans(X,2); % Perform K-Means clustering |

The cluster indices of data elements are output in array idx and the coordinates of the centroids of each cluster are output in array C as shown in Figure 3.3.

Finally, the data elements are plotted such that each point representing a data element is given a specific colour based on its cluster index using the codes in Listing 3.3. The centroids of the clusters are also plotted as black crosses.
