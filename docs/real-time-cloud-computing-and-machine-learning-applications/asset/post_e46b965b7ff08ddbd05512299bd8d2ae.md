## Data Capture and Client Architecture for a Cloud-Based Real-Time ... 623

This class is used to perform the following functions:
- Displays the UI to the user using the activity_data layout.
- Fetches data from the Cloud database using an inner AsyncTask, QueryCloud, to perform the networking on a background thread.
- Fetches data from Local Server using an inner AsyncTask, QueryLocal, to perform the networking on a background thread.
- After getting the data from the cloud, the data is converted into CSV file and saved to internal storage.
