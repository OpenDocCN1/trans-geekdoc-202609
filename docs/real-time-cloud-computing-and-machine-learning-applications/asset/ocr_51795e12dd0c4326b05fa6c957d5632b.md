Step 2- The slope of the best fit line is calculated as follows:
$$m = \frac{\sum_{i=1}^{n}(x_i - ar{X})(y_i - ar{Y})}{\sum_{i=1}^{n}(x_i - ar{X})^2} = \frac{(-1016.3)(4.7) + (-88.3)(9.7) + (-432.4)(1.2) + (-479.3)(2.7) + (234.7)(-7.3) + (652.7)(-6.3)}{(-1016.3)^2 + (-88.3)^2 + (-432.4)^2 + (-479.3)^2 + (234.7)^2 + (652.7)^2} = -0.007743$

Step 3- The y-intercept of the best fit line is calculated as follows:
$$b = \bar{Y} - m\bar{X} = 21.3 - (-0.00774)(2851.3) = 43.26$$

Hence the equation of the line of best fit is:

$y = 43.26 - 0.0077x$$

This equation of the best-fit line can can be used to perform simple linear regression to estimate the mileage of a car of a given weight. For example, a car of weight 3000 pounds ($x =3000$), its mileage is estimated as follows:

$Y = 43.26 - 0.0077(3000) = 20.16 MPG$$
