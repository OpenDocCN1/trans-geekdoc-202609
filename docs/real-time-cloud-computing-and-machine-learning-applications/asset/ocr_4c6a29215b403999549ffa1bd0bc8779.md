# 5.1.11.2. Retrieving Pre-Labelled Values from Cloudant Database or Localhost

After using the local server to save values on IBM Cloud, they need to be retrieved for the local analytics process before being fed into their respective algorithms for classification. This is known as the training dataset. Values can also be retrieved from the localhost databases if the "Use Localhost Values" toggle is enabled. The following points summarise the steps performed in this method called fetchClassificationValues() defined in LocalServer.java:

+   Using an instance to determine whether the "Use Localhost Values" toggle is enabled. Likewise, a check is performed for local analytics or downloading functionalities using the Booleans declared as global variables in Listing 5.1.

+   Making a connection to the localhost on port 3036 by specifying the database and table names using the MySQL connector and creating queries of type String depending on the selection of devices.

+   Setting Cloudant credentials depending on the device selected on the analysisDeviceComboBox.

+   Connecting to the corresponding database using the set credentials.

+   Getting the total number of rows in the database.

+   Initialising the aldata 2D array to hold the four variables as well as the numerical label as the last column.

+   The getClass() method specifies that the last column is the classification column. This is done after allocating the different attributes.

+   Adding the "NoSupportForMissingValuesException" to the method to handle any errors ongoing filling the Weka object.
