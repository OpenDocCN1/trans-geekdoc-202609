# 4.4.2. Desktop Application Layout

4.4.2.1. Visual Outlook on Final Application

Building GUI applications with Swing consists of several components known as containers which hold other components and as a whole, make a complete and interactive UI. For this application, a single-window is built consisting of several components that facilitate the interaction of the user to the back-end processes. This includes fields to accommodate for parameter values, two toggles to push to the cloud and the local server, a pair of buttons to either start or end the monitoring process, a field to hold the IP address and a drop-down menu to provide for the selection of parameters to be displayed on the live graph. Components for analysis resemble that of the Android application with buttons for both prediction and classification as well as input fields for prediction time and window size.
