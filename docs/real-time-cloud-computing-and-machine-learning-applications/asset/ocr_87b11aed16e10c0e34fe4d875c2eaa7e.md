The creation of the dynamic web project is performed through the following steps:

+   1. To create a new project, "New" is selected under the "File" tab, before clicking on "Dynamic Web Project" as shown in Figure 5.47.

![](bbox=[0.135, 0.212, 0.725, 0.335])

Figure 5.47. Creating a new Dynamic Web Project in Eclipse IDE.

+   2. This is followed by adding a name under the "Project name" entry and selecting the default location for the project. The target runtime can also be set. In this case, the user can choose "IBM Bluemix Runtime" such that the servlet is deployed on the configured Cloud server when run. The "Finish" button is then clicked as in Figure 5.48.
