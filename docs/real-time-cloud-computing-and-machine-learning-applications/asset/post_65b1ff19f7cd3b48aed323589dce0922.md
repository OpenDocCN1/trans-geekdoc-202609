# PREFACE

Real time applications which require data being captured etc processed under stringent time constraints are becoming increasingly popular with the advent of the Internet of Things and advances in mobile communications brought about by the 4G and 5G standards. Along with ultra-reliable and low latency communication computing and machine learning-driven, two of the most important enablers of real-time applications are cloud computing and machine learning algorithms. Cloud computing has become a viable technological means to provide a scalable, demand-driven, and a ubiquitous computing infrastructure for many applications. Cloud computing also brings about major evolutionary technical developments, and it is already a fact that it is changing the information technology world and the IT marketplace.

Along with cloud computing, Machine Learning and AI are becoming very appealing and impactful in several applications such as the Internet of Things, Power Grid, Telecommunications, medicine, business analytics etc. However, one of the issues with machine learning is the computational complexity and processing power required for running machine learning algorithms as well the storage requirements, particularly where huge amounts of data are captured in real-time. These requirements make it even more challenging to deploy machine learning algorithms for real-time applications. This is why it is becoming a common strategy to use cloud computing for deploying machine learning and AI applications. The purpose of this book fundamentally is to demonstrate how these two emerging fields which are dominating the IT landscape can be combined to provide powerful solutions for realtime applications. A lot of focus has been placed on developing and deploying these applications to provide a full hands on experience to readers.

Chapter 1 of the book gives an introduction on the applications of cloud computing and machine learning as well as real-time applications where these two IT technologies are combined.

Chapter 2 provides the fundamental concepts, paradigms and architectures of cloud computing. The hosting of simple mobile, desktop and web applications on the Firebase and IBM cloud platforms have also been described in this chapter.

A comprehensive overview of machine learning algorithms is given in Chapter 3. The cloud based deployment of simple machine learning algorithms with detailed explanations on the codes used and cloud configurations required are also provided.

Chapter 4 and Chapter 5 present a detailed treatment on the development of a real-time cloud based network analytics system with all necessary explanations on the programs used to set up the servers, mobile applications and cloud platforms. Chapter 4 deals with the client and data capture architectures while Chapter 5 describes the server and servlet architectures of the system.

A similar treatment for a real-time weather forecasting system is presented in Chapter 6 and Chapter 7 respectively.
