2. The live graph is automatically started upon the loading of the web page through the window.onload function, detailed in Listing 5.56, which performs the following functions:

+   - Fetches the selected parameter from the "Select" component.
- Creates an array denoted as dataPoints which holds the values to be printed on the graph.
- Initialises the Chart container by specifying details for the graph, such as its title in which case is the selected parameter stored in the variable "selectedParameter."
- The nested function updateData() is then called. It fetches the last set of values from the livegraph.javascript server, using the "livegraph" mapping.
- The variables are extracted from the JSON response before being stored into a set of variables of type var.
- The function addData() pushes the values onto the live graph. Since the default parameter on the "Select" component on the web page is "Download Speed," the latter is used for the window.onload function.
- The setInterval() method is set to update the live graph at a rate of five seconds, which means it calls the updateData() method after every five seconds. The logic thus resembles an ongoing loop.
