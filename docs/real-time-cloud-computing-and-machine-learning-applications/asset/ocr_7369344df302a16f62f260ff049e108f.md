# 4.3.7.2. Getting Packet Data

The number of packets sent and received is obtained using the same logic of subtracting the previous value from the current one, i.e., after one second has elapsed. The variable RXPackets represents the number of packets received per second while TXPackets is the number of packets sent per second. Listing 4.24 illustrates the functions.

# Listing 4.24. Getting packet data

```
// Getting number of sent and received number of packets per second for either Wi-Fi or LTE, depending on which function is active
public void getPackets() {
// Getting the current number of packets registered
current_RXPackets = TrafficStats.getTotalRxPackets();
current_TXPackets = TrafficStats.getTotalTxPackets();
// Subtracting the previously registered number of packets, 1 second ago
RXPackets = (current_RXPackets - initRXPackets);
TXPackets = (current_TXPackets - initTXPackets);
}
```
