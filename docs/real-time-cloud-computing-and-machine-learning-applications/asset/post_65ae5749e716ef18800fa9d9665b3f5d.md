## 5.1.8. Local Monitoring Server Implementation

The local monitoring server performs the following functions for both devices:

- Create a ServerSocket connection using a specific port number.
- Receive data through an input stream in a JSONObject using the accept() method.
- Printing the values onto the graph based on the selection of the parameter from selection JComboBox.
- If the "Push to Cloud" toggle is activated, a connection is made to the respective Cloudant database for the device and the values are pushed using the same principles explained in Section 4.4.8.6.
- If the "Push to localhost" toggle is activated, a connection is made to the respective localhost database for the device and the values are pushed accordingly.

The local server is launched by clicking on the “Launch Monitor” button and stopped using the “Stop Monitor” button. To bind an event to launch the server, the corresponding button is right-clicked and the actionPerformed operation is chosen.

localserverAndroid = new Runnable() {
    @Override
    public void run() {
        try {
            ServerSocket ss = new ServerSocket(port);
            System.out.println("Waiting for connection...");
            while (true) {
                Socket socket = ss.accept();
                // Reading the message using BufferedReader
                BufferedReader br = new BufferedReader(new InputStreamReader(socket.getInputStream()));
                String str;
                while ((str = br.readLine()) != null) {
                    // Converting the String into JSONObject
                    JSONObject readings = new JSONObject(str);
                    // Extracting values from JSON
                    time = readings.getString("Timestamp");
                    totaldownload = readings.getDouble("DownloadSpeed");
                    totalupload = readings.getDouble("UploadSpeed");
                    mobileownload = readings.getDouble("MobileDownloadSpeed");
                    mobileupload = readings.getDouble("MobileUploadSpeed");
                    packetsreceived = readings.getLong("PacketsReceived");
                    packetsent = readings.getLong("PacketsSent");
                    wifi_strength = readings.getDouble("WifiStrength");

                    // Printing the index and the variables on the console
                    System.out.println("Index: " + idx);
                    System.out.println("Time: " + time);
                    System.out.println("Total Download Speed: " + totaldownload);
                    System.out.println("Total Upload Speed: " + totalupload);
                    System.out.println("Mobile Download Speed: " + mobileownload);
                    System.out.println("Mobile Upload Speed: " + mobileupload);
                    System.out.println("Packets Received: " + packetsreceived);
                    System.out.println("Packets Sent: " + packetsent);
                    System.out.println("Wifi Strength: " + wifi_strength);
                }
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
};
