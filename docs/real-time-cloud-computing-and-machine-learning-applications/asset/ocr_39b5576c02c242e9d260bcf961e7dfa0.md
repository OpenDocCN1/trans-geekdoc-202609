Moreover, compared to a base station with on-processing, remote radio terminals have a much smaller footprint, which leads to less complex and economical network densification [9].

The rationale of C-RAN is to split the functions of the base stations by separating the base station into a Baseband Unit (BBU) and a Remote Radio Head (RRH). After that, using cloud computing and virtualization techniques, the BBUs from several sites are centralized into a common geographical location such as a data center. BBUs are responsible for Baseband signal processing BBUs, while signal amplification and modulation are performed by RRHs. A front haul link connects the BBU pool to the RRHs that are deployed at the cell site an antenna. Hence adaptation to random traffic and effective utilization of the resources becomes possible. The same BBU pool can be shared by several operators, by leasing it as a cloud service. Additionally, with a reduction in the handover delay, an improvement in network performance is achieved. The centralization of the BBUs at a single site leads to a reduction in the running cost. Furthermore, in contrast to conventional RAN, the addition and upgrade of new BBU is much simpler. To raise the network capacity, only the installation of an RRH is required by MNOs. The network costs are further decreased as the C-RAN leads to a reduction in power and energy consumption [10].

# 1.1.2.4. Big Data Analytics

Big Data is associated with massive volumes of data generated by operational systems such as Enterprise Planning (ERP), User customer relationship (CRM), Supply Chain Management (SCM) systems well as IoT sensors and mobile traffic. This huge dataset which a combination of both structured and unstructured data is termed as Big data in conventional data structures. The main characteristics of Big Data can be described by Vs namely Volume, Velocity, Variety and Variety [11]. The analysis of big data leads to valuable insights which can be in the form of pattern identification, interpretations, guidelines for decision making and subsequently the ability to provide intelligent responses to different situations. A plethora of quantitative techniques such as AI, machine learning, deep learning, statistics and numerical methods are used for data mining and pattern discovery in big data. These techniques are required to deal with the voluminous and heterogeneous nature of big data.

By providing flexible and efficient access to data as well as enhanced communication of insights, cloud computing can significantly promote the capacity of scalable analytics solutions. However, a generic solution to all organisations cannot be obtained from cloud-based big data. Different models exist for organizations that use cloud computing to benefit from Analytics as a Service (AaaS).
