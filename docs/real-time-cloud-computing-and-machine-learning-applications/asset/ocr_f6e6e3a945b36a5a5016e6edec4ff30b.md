# 6.4.5. Testing the Desktop Application

This section shows screen captures of the expected operations of the desktop application.

# 6.4.5.1. Live Monitoring is launched, the GUI shown in Figure 6.44 is displayed to the user.

+   1. When the application is launched, the GUI shown in Figure 6.44 is displayed to the user.

+   2. To send data to the local server, the user needs to choose “Local” in the Source JComboBox. The IP address of the local server running is then entered into the “Local Server IP” field, before clicking “Monitor” to start the weather monitoring thread.

+   3. To send data to the Cloudant database, the user needs to choose “Cloud” in the Source JComboBox before clicking on “Monitor” to start the weather monitoring thread. When the monitoring process starts, the graph will be updated with the new values from the API as shown in Figure 6.45.
