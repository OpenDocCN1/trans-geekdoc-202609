# 4.4.9. Stop Button

As the name suggests, this button caters for the stopping of the thread, thereby closing all processes and bringing the monitoring to an end. The stop() method is used with the Thread object and the fields are emptied. The graph is cleared at the same time.

# Listing 4.64. Populating the stop button

```
// Stopping the monitoring process
private void stopMonitoringActionPerformed(java.awt.event.ActionEvent evt) {

// Stopping the thread
onitorThread.stop();
// Emptying the fields on the GUI
dLoad.setText("");
uLoad.setText("");
}
```
