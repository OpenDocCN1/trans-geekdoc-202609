The function outputs the trained k-NN classifier model, Mdl. 

The predict function from MATLAB's Statistics and Machine Learning Toolbox can be used to predict labels using a k-NN model [30]. The syntax of the function is as follows:

```
label= predict(Mdl,X)
```

The inputs to the function are described below:

Mdl: K-NN classifier model
X: Predictor data to be classified
The function outputs array label which consists of the predicted class for input X.

A demonstration of how the classification performed in the short-hand example may be implemented in MATLAB using the codes in Listing 3.26. The weights and mileage of cars that have already been grouped first loaded in the workspace for training the classifier model. A k-NN classifier for three nearest neighbours is then trained using data in X and Y. Finally, the classifier is then used to classify a car of 3000 pounds and 22 MPG.

# Listing 3.26. K-Nearest Neighbor – MATLAB codes

```
Weight=[1835 1970 2372 3806 4354]; % Matrix with car weight information
Mileage = [26 31 24 14 18]; X = [Weight,Mileage]; % Matrix with car information
Y=[X';X';X';Y';Y';Y']; % Matrix with Group information of each car in matrix X
mdl = fitknn(X,Y,NumNeighbors,3); % Train k-NN classifier
Xnew = [3000 22]; Define new car's information
group = predict(mdl,Xnew)
```
