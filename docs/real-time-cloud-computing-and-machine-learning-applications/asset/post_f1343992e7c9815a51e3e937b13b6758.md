The "@WebServlet" annotation defines a servlet component in a web application. A URL pattern is also defined in the annotation. The line "@WebServlet("/forecaster") indicates that the servlet can be contacted on the URL http://localhost:8080/Network/Forecaster. The servlet is generated with a Constructor, the doGet() method, and the doPost() method. In doGet(), the parameters are appended to the URL and sent with header information. This does not happen in the case of doPost(). In doPost(), the parameters are sent separately. Since most of the web servers support only a limited amount of information to be attached to the headers, the size of this header should not exceed 1024 bytes. However, doPost() does not have this constraint.

## 7.3.5. The "Forecaster" Servlet

This servlet is responsible for serving requests of the weather forecast for the requested time. The servlet performs predictions using the four algorithms discussed in Section 7.1. It then returns the result in a JSON object to the user.

The doGet (HttpRequest, HttpServletResponse response) is the main method that is triggered when a user calls the servlet. It is responsible for obtaining the "prediction time," "window size" parameter, and "data source" from the request. It then invokes the response ( ) method to obtain the weather forecast for the request in a JSON format. Finally, the JSON object is formatted into a more readable format using the formatData ( ) method before being sent to the user. Finally, the connection is closed. The codes for the method are given in Listing 7.25.

## Listing 7.25. doGet ( ) method for Forecaster

```java
protected void doGet(HttpRequest, HttpServletResponse response)
throws ServletException, IOException {
    // Get a PrintWriter object from the HttpServletResponse
    PrintWriter out = response.getWriter();
    // Content Type is set to JSON as we are returning a JSON Object.
    response.setContentType("application/JSON");
    // Set character encoding to UTF-8
    response.setCharacterEncoding("UTF-8");
    // Fetch the prediction time and window size from the HttpServletRequest
    int ptime = Integer.parseInt(request.getParameter("prediction_time"));
    int window = Integer.parseInt(request.getParameter("window_size"));
    // Get the data source which to use
    String source = request.getParameter("data_src");

    // Obtain the prediction result from the response() method
    JSONObject analytics = response(window, ptime, source);
    JSONObject results = new JSONObject();
    results.put("results", formatData(analytics.toString()));

    // Send the result to the user and close the connection
    out.print(results.toString());
    out.flush();
    out.close();
}
```

# Listing 7.27. roundOutput(float[]) method to round a float array to one decimal place

```java
public static float[] roundOutput(float[] array) {
    DecimalFormat df = new DecimalFormat("###.##");
    df.setRoundingMode(RoundingMode.HALF_UP);
    for (int i = 0; i < array.length; i++) {
        array[i] = Float.parseFloat(df.format(array[i]));
    }
    return array;
}
```
