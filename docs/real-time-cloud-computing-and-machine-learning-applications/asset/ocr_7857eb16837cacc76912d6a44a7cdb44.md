The Node.js Package Manager (npm) offers two key functions [17, 18]:

+   1. Searchable online repositories for node.js packages/modules which can be searched on search.nodejs.org.
2. Command line utility which can be used for installing Node.js packages, as well as managing the versions and dependencies of Node.js packages.

The npm is integrated along with the Node.js installation files in versions v0.6.3. The version can be checked with the command npm version.
