# Listing 3.43. Q-Learning – Start training

```
trainStats = train(qAgent,env,trainOpts); % Start training
```

This opens MATLAB’s Episode Manager window, shown in Figure 3.27, which displays the progress of the training.

![](bbox=[0.133, 0.297, 0.866, 0.603])

The training is stopped after the training termination criterion has been met. Before starting a simulation with the trained agent, a visualisation of the environment is set up using the MATLAB codes in Listing 3.44 so that the actions taken by the agent can be observed:

# Listing 3.44. Q-Learning – Visualise environment

```
plot(env) % Plot the Basic Grid World
env.Model.Viewer.ShowTrace = true; % Show path taken
env.Model.Viewer.clearTrace; % Clear any trace
```

In Listing 3.45, the sim function is used to simulate the agent in the environment.

# Listing 3.45. Q-Learning – Simulate the agent in the environment

```
sim(qAgent,env) % Simulate agent in the environment
```
