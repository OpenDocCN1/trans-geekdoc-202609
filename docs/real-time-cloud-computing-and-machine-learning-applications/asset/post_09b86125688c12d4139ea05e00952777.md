## 5.2.2. Downloading Functionalities

- 1. The data source of values to be downloaded, i.e., for either the PC or Android, is first chosen from the drop-down menu, as portrayed in Figure 5.28.

![](img/2b52fde0e707e8c2f05a10309c3f8982_524_0.png)

Figure 5.28. Selecting the data source for downloading.

- 2. To download values from the Cloudant database, the “Localhost values” toggle is left unchecked. However, for those from a hosted database on localhost such as XAMPP, this toggle is checked as in Figure 5.29.

![](img/2b52fde0e707e8c2f05a10309c3f8982_524_1.png)

Figure 5.29. Selecting localhost values with the toggle.
