The function performs K-Means clustering using squared Euclidean metric and returns the cluster assignment for each input data element provided in **X**, in array **idx** and the centroids of each cluster are returned in array **C**.

A MATLAB simulation demonstrating the use of the **kmeans** function to perform the clustering in the short-hand example is described next. First, the data to be clustered is loaded into the MATLAB workspace and a plot of the data elements generated using codes in Listing 3.1.

Weight=[1835 4341 2372 3086 3504 1970]; % Matrix with car weight information
