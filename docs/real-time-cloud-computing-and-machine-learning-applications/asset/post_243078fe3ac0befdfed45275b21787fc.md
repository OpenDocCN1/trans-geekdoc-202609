### 2.6.1. Node.js Overview and Installation

Node.js is a platform developed on the JavaScript runtime of Google Chrome. It simplifies application development and allows fast implementation of scalable network applications. In order to make it suitable for data-intensive real-time applications running over distributed devices, an event-driven non-blocking I/O model has been used which also makes it lightweight [17, 18]. The development of web applications is greatly facilitated due to the useful library of several JavaScript modules it provides. Many of the basic modules of Node.js are coded in JavaScript and it is mostly used to run real-time server applications. Some of the most important parts of Node.js are as follows:
