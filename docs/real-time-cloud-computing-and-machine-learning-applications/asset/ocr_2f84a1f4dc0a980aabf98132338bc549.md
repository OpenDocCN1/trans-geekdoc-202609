# Chapter 4

# DATA CAPTURE AND CLIENT ARCHITECTURE
FOR A CLOUD-BASED REAL-TIME NETWORK
ANALYTICS SYSTEM

Over the years, analytics have always propelled the human race an edge closer to anticipation and identification of key factors that can be optimised to better the service being dealt with. In the wireless oasis whereby wireless network manufacturers are being actively encouraged to turn towards Artificial Intelligence (AI), the partnership of Machine Learning (ML) algorithms and captured network data can provide insights on the behaviour of a network, paving the way to technology such as self-organising networks. As the Internet expands in magnitude and intricacy, network traffic, generally defined as the volume of data transmitted over a network at a given time, is growing at a sky-rocking pace [1]. In other words, there is a constant need to monitor and manage networks in terms of resources, security and performance [2]. In this chapter, Section 4.1 gives a general overview of the machine learning algorithms used for network analytics. The systems described in Sections 4.2 to 4.5 aim to fully collect network parameters in different scenarios whereby the information is segregated into databases, allowing analytics to be performed in real-time. Sections 4.2 to 4.4 elaborate on the data capture and edge-device interfaces while Section 4.5 describes the cloud database configurations, made to store the retrieved parameters.
