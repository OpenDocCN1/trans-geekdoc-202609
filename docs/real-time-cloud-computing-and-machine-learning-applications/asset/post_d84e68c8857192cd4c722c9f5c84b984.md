# 4.3.11. Downloading to .csv Files

When the user clicks on "Go to Download" from the Network Monitoring Menu, which is the MainActivity.java class, the menu switches to the Download Menu, as shown in Figure 4.12. This window uses the Download class which is visually built using the csvdownload.xml layout file. The download operation can be broken down into the use of three buttons whose functionalities are follows:

- Browse: Makes a directory chooser using the Storage Chooser library [13] to allow the user to select the folder to store the .csv file to be created. After obtaining the selection, the path is obtained in a String object which
