## 4.3.11.6. Issuing the Directory Picker

Using the storage-chooser library [13], the StorageChooser class is used to initialise a dialogue, which takes as input the context of the class and sets the type of selection which can be either file selection or directory selection. This is followed by registering a listener using setOnClickListener on the StorageChooser, such that the path selected is returned. The latter is a String object which is allocated to a global variable.

### Listing 4.47. Invoke the directory picker

```java
public void showDirectoryPicker() {
  // Initialise the dialogue
  final StorageChooser chooser = new StorageChooser.Builder()
  // Specify context of the dialogue
  .withActivity(Download.this)
  .withFragmentManager(getFragmentManager())
  .withMemory(true)
  .allowCustomPath(true)
  // Define the name as THE FOLDER/DIRECTORY CHOSER
  .setType(StorageChooser.DIRECTORY_CHOOSER)
  .build();

  // Is triggered when the user makes selection
  chooser.setOnClickListener(new StorageChooser.OnOnClickListener() {
    @Override
    public void onSelect(String path) {
      // e.g /storage/emulated/0/Documents
      System.out.println("The path chosen is: " + path);
      miniPath = path;
      // Enable the download buttons since the path has been registered:
      downloadButton.setEnabled(true);
      downloadDateButton.setEnabled(true);
    }
  });

  // Display the file selector:
  chooser.show();
}
```
