This section entails the procedure to create Cloudant databases to store network parameters. In terms of IBM resources, storing data in Cloudant databases belongs to the "Services" category.

# 4.5.1. Creating a Cloudant Database to Store Network Data

As mentioned before, the edge devices, i.e., the Android phone and Desktop applications, push data to the cloud every second. After creating an account the steps in Chapter 2, databases can be created, which contain several tables to receive data from the devices. The following steps are taken:

+   1. On the Dashboard, "Cloudant" is entered in the search bar. This service relates to the Cloudant databases to be created.
