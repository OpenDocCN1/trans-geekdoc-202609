# 4.3.6.3. Monitor Button

The implementation for the triggering of any button is placed inside the onCreate() method and the button is referenced by calling the OnClickListener method as shown in Listing 4.19. With the permissions defined in Section 4.3.12 in the manifest, they are checked and accepted when the monitoring process is started, so that the user agrees to the necessary permissions to monitor the network parameters. This is carried out when the monitorButton is pressed, which first triggers the permission detection followed by the start of a thread, mRunnable, defined later in Section 4.3.8, which takes care of the parameter fetching. m Handler is used to do so when specifying a period of one second.
