# 3.4.1.5. K-Nearest Neighbor

K-Nearest Neighbour (k-NN) is a well-known simple supervised learning algorithm that is useful in identifying and classifying similar objects. It may be used for both classification and regression. It is widely used in recommender systems that identify users' preferences and then suggest similar products which may interest users [34]. In k-NN classification, an object is classified into the most common class assigned to its k nearest neighbours in a feature space, where k is a positive integer [24]. An appropriate distance metric is used to calculate the distances between the objects to determine their k nearest neighbours. Euclidean distance is one of the commonly used distance metrics. The Euclidean distance between two objects is given by equation (3.20) [35]:

$$d(x,y) = \sqrt{\sum_{i=1}^{n}(x_i - y_i)^2} \quad (3.20)$

Where,

+   - n - Total number of features
- $x_i$ - Features of first object
- $y_i$ - Features of second object
