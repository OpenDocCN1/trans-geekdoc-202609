### 6.3.17. Sending the Data to a Local Server or Cloud Database

To send the data to the local or a cloud server, the values have be stored in a JSONObject. So, a JSONObject is first created using the JSONObject() constructor. Then, the values are added using the put (String key, Object value) function specifying a String as a key. A timestamp is also added to the JSONObject to mark the creation time.

After creating the JSONObject to be sent, the cloud switch is checked whether it is enabled or not. If it is enabled, the data is sent directly to the cloud else the data is sent to the local server whose IP address has been entered by the user.

To send the data to the cloud, a CloudClient object is first created which is the main object that is used to gain access to the Cloud API.
