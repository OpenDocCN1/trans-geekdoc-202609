Due to the inclusion of a live graph, to actively listen for incoming parameters, an object from the LineChart class, available from the imported libraries in Section 4.3.2, is used to print live values onto the graph. This process is started by having the MainActivity.java class implement a listener from the MPAndroidChart library, called the OnChartValueSelectedListener, which registers call-backs when selecting values on the graph, i.e., when a data point is clicked on. Therefore, the default MainActivity.java class is modified in Listing 4.2, as shown in Listing 4.12.

# Listing 4.12. Implementing the OnChartValueSelectedListener

```
public class MainActivity AppCompatActivity implements
OnChartValueSelectedListener {
```

2. The two following methods are invoked automatically when the project is synced upon including the listener, as shown by the “implements” keyword in Listing 4.12.

+   - onValueSelected(): Called when a value has been selected inside the chart and is used to display values on the graph.
- onNothingSelected(): Called when nothing has been selected or an “un-select” has been made.

3. In doing so, the project is synced again and the two methods described above are automatically created. It should be noted that in this case, the onValueSelected() method has been modified such that a Toast is invoked whenever a data point is clicked on. This piece of code returns the coordinates of the selected point, i.e., the data registered with respect to time as shown in Listing 4.13. The onNothingSelected() method is left empty in this case.

# Listing 4.13. Invoking Toast when value is selected

```
// Display selected values on the graph
@Override
public void onValueSelected(Entry e, Highlight h) {
Toast.makeText(MainActivity.this, e.toString(),
Toast.LENGTH_SHORT).show();
Log.d("on", e.toString() + " : " + e.toString());
System.out.println("A value has been selected.");
}
@Override
public void onNothingSelected() {
}
```
