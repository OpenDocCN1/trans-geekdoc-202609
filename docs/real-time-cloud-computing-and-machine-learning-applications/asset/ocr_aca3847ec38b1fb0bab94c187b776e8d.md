# 5.3. SERVLET PROGRAM FOR NETWORK ANALYTICS, MONITORING AND DATA RETRIEVAL

This section entails the development of a Java Servlet, as a dynamic web project using Eclipse IDE, by hosting the functions defined in Section 5.1, which:

+   * Displaying a live graph of the latest values being recorded on either the Cloudant database or a local MySQL database, such as XAMPP.
* Downloading the last "N" of values to .csv files.
* Downloading by a particular date to .csv files.
* Performing regression and classification analytics.

This means the listed functions are triggered via response-request mechanisms where specific URLs are defined and used to trigger certain functions. Additionally, the user is presented with web pages that allow him to interact with a live graph, as well as perform the same functions as the local server, without having a dedicated application. The pages can then be accessed through a browser and provide the ability to select between the Cloudant database as the source, or a MySQL database at localhost.
