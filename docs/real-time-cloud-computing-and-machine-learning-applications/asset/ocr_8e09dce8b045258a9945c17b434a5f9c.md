# Short-hand Example 3

In this example, the weight and the mileage of a set of six cars are related to each other using linear regression. Then the mileage for a car of a user-defined weight is predicted using the regression model. The recorded data is given in Table 3.9:

# Table 3.9. Simple linear regression-Recorded data

| Weight (Pounds), x | Mileage (Miles per Gallon), y |
|---|---|
| 1835 | 26 |
| 1970 | 31 |
| 2372 | 24 |
| 3086 | 14 |
| 3504 | 18 |
| 4341 | 15 |

The best-fit line can be obtained using the least square method described next.

Step 1 - The means of the X and Y values are calculated as follows:

```
$\bar{X} = \frac{\sum_{i=1}^{n}x_i}{n} = \frac{1835 + 1970 + 2372 + 3086 + 3504 + 4341}{6} = 2851.3$$
$$\bar{Y} = \frac{\sum_{i=1}^{n}Y_i}{n} = \frac{26 + 31 + 24 + 14 + 18 + 15}{6} = 21.3$$
```
