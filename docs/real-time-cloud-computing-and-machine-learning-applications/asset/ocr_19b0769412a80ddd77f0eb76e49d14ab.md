The Q-learning agent is created by first specifying its options in an rlAgentObject. This allows options such as the discount rate, sample time and options for epsilon greedy exploration [53] to be defined. In this example, the probability threshold for epsilon greedy exploration is set to 0.05.

# Listing 3.41. Q-Learning – Create Q-Learning agent

```
agentOpts = rlAgentOptions; % Create rlAgentOptions object
agentOpts.EpsilonGreedyExploration.Epsilon = 0.05; % Set probability threshold
value
qAgent = rlAgent(qRepresentation,agentOpts); % Create Q-learning agent
```

The created agent can now be trained. Training parameters are configured in rlTrainingOptionsObject. In this example, the training parameters are set as follows:

+   1. Maximum time step for each episode: 50
2. Maximum number of episodes: 300
3. Training termination criterion: Stop when the average reward is greater than 10 over 20 consecutive episodes

The MATLAB codes for setting up the training parameters are given in Listing 3.42:

# Listing 3.42. Q-Learning – Define training parameters

```
trainOpts = rlTrainingOptions; % For defining training parameters
trainOpts.MaxStepsPerEpisode = 50; % Specify maximum time step for each episode
trainOpts.MaxEpisodes = 300; % Specify maximum number of training episodes
trainOpts.StopTrainingCriteria = "AverageReward"; % Specify the criterion for ending the training
trainOpts.StopTrainingValue = 11; % Training termination criterion
trainOpts.ScoreAveragingWindowLength = 20;
```
