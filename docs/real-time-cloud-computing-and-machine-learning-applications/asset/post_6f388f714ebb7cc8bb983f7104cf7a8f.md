Depending on the data required, the appropriate Selector object is created. Using the QueryBuilder object, the appropriate query is created. This query is executed using the query ( ) method of the Database instance. This method takes as a String representation of the query and the class of objects returned by the query. The query ( ) method returns an object of QueryResult contains details about the result of the query as a list of records matching the query criteria, warning, bookmark, and execution stats.

Using the getDocs() method of the QueryResult object, the list of records is obtained and stored in a List of LinkedTreeMap. Each item in the list is iterated one at a time. The values are extracted and type-cast to double the get (String key) method of the LinkedTreeMap object. The weather parameters are stored in the 2D array "db.data". The timestamp value is extracted and type-cast to String and stored in the double array "timestamps". public Object[] getDatabaseArray(String date, int size) {
    // Create a Selector and QueryBuilder to form the request
    Selector selector;
    // check whether we need for a specific date or the N samples
    if (date.length() < 1) {
        // we need N samples (gt-greater than)
        selector = gt("idx", row_count - size);
    } else {
        // if we need a specific date, use a regex find a matching date
        selector = regex("Time", date);
    }
    // Construct the query
    QueryBuilder query = new QueryBuilder(selector).sort(Sort.asc("idx"));
    QueryResult<LinkedTreeMap> result = db.query(query.build(), LinkedTreeMap.class);
    List<LinkedTreeMap> resultList = result.getDocs();
    double[][] db_data = new double[resultList.size()][7];
    String[] timestamps = new String[resultList.size()];
    for (int i = 0; i < resultList.size(); i++) {
        LinkedTreeMap result = resultList.get(i);
        double temperature = (double)result.get("Temperature");
        double wind_speed = (double)result.get("WindSpeed");
        double wind_direction = (double)result.get("WindDirection");
        double pressure = (double)result.get("Pressure");
        double visibility = (double)result.get("Visibility");
        double humidity = (double)result.get("Humidity");
        double cloudiness = (double) result.get("Cloudiness");
        timestamps[i] = (String) result.get("Time");
        db_data[i][0] = temperature;
        db_data[i][1] = wind_speed;
        db_data[i][2] = wind_direction;
        db_data[i][3] = pressure;
        db_data[i][4] = visibility;
        db_data[i][5] = humidity;
        db_data[i][6] = cloudiness;
    }
    return new Object[][]{db_data, timestamps};
}
