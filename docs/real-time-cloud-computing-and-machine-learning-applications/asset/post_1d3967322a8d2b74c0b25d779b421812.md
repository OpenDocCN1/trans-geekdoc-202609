The convertToFloat(double[]) array method converts a two-dimensional array to a two-dimensional float array. The float array is then used as input to the Neural Network. It is given in Listing 7.28.

## Listing 7.28. convertToFloat()[] Method

```
private static float[][] convertToFloat(double[][] array) {
    int col = array[0].length;
    int row = array.length;
    float[][] data = new float[row][col];
    for (int i = 0; i < row; i++) {
        for (int j = 0; j < col; j++) {
            data[i][j] = (float) array[i][j];
        }
    }
    return data;
}
```

### 7.3.6. The "Downloader" Servlet

The "Downloader" servlet is responsible for responding to queries from mobile and pc users to provide weather observations for a specific date or only the last N observations. The functions performed by the class are as follows:

- In the doPost() method, the date or Number of observations, d_size, that the user has requested is extracted using the getParameter() method.
- The source from which to fetch the data is also included in the request by "data_src" parameter.
- If the user requests the last N observations, it converts the variable d_size into its equivalent.
- The response() method is invoked, it is responsible for fetching the required data from either the Cloudant database or the local database. After that, the data is converted into a CSV String. The codes for converting the array of values into a CSV file are already explained in Section 6.3.26.
- A PrintWriter object is obtained from the HttpServletResponse.
- A JSONObject is created and the CSV string is stored in it.
- Finally, the JSONObject is sent to the user and the connection is closed.

The codes for this servlet are given in Listing 7.29.

## Listing 7.29. Downloader Servlet

```java
import java.io.IOException;
import java.io.PrintWriter;

import javax.servlet.ServletException;
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;

import org.json.JSONObject;

import org.database.DataRetriever;
import org.database.SQLConnector;

@WebServlet("Downloader")
public class Downloader extends HttpServlet {
    private static final long serialVersionUID = 1L;

    public Downloader() {
        super();
        // Auto-generated constructor
    }

    protected void doGet(HttpServletRequest request, HttpServletResponse response)
        throws ServletException, IOException {
        doPost(request, response);
    }

    protected void doPost(HttpServletRequest request, HttpServletResponse response)
        throws ServletException, IOException {
        System.out.println("Data sent");

        // Get the date or Number of observation that the user has requested
        String d_time = request.getParameter("date");
        String d_size = request.getParameter("n");
        // Get the data source to use
        String source = request.getParameter("data_src");
        int window_size = 0;
        // if d_size parameter exist then convert to integer
        if (d_size != null && d_size.length() > 0) {
            window_size = Integer.parseInt(d_size);
        }

        // obtain the CSV String from the response
        String CSV = response(d_time, window_size, source);
        // Get a PrintWriter from the HttpServletResponse
        PrintWriter out = response.getWriter();
        // Create a JSONObject to hold the data
        JSONObject result = new JSONObject();
        result.put("CSV", CSV);
        // send data to the Client
        out.print(result);
        out.flush();
        out.close();
    }

    public String response(String date, int size, String source) throws IOException {
        // Create a DataRetriever Object to fetch data from the cloud

            } else {
                databaseArray = dataRetriever.getDatabaseArray(date, 0);
            }
        } else {
            if (size > 0) {
                databaseArray = sqlConn.fetchLastN(size);

                databaseArray = sqlConn.fetchForDate(date);
```

### 7.3.7. The "graphUpdater" Servlet

The "graphUpdater" servlet is responsible for fetching the latest observation from the Cloudant database and returning it to the user. The returned value is used to update the graph on the HTML page. The servlet performs the following functions:

- The weather parameter which the user has requested is obtained from the URL using the getParameter() function.
- The source from fetch the data is also obtained from the request by the "source" parameter.
- The last observation is fetched from either the Cloudant database or the local database.
- A switch statement is used to determine which parameter is needed to be sent to the user.
- A JSON object is created and the value is stored.
- A PrintWriter object is created and obtained from the HttpServletResponse.
- The content type is set to JSON since a JSON file is being sent.
- Finally, the String equivalent of the JSON object is sent to the user and the connection is closed.

The codes for this servlet are given in Listing 7.30.
