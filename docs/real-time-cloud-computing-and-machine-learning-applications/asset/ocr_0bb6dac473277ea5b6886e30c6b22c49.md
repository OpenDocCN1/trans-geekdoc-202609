# Listing 4.37. Setting the options and colours of the graph

```
// Setting printing options/colours
private LineDataSet SetDataSet() {
// Creating object to modify each data point:
LineDataSet set = new LineDataSet(null, netparams);
// Setting the flow of the graph, i.e. values starting from the left:
setAxisDependency(AxisDependency.LEFT);
// Setting the colour of the line to blue:
setsetColor(Color.rgb(0, 0, 215));
// Setting the outline of the data point to black:
setCircleColor(Color.BLACK);
// Setting width, radius and colours:
setLineWidth(3f);
setCircleRadius(5f);
setFillAlpha(75);
setFillColor(ColorTemplate.getHoloBlue());
setHighLightColor(Color.rgb(245, 118, 118));
setValueTextColor(Color.BLACK);
setValueSize(10f);
setDrawValues(false);
return set;
}
```

The addEntry(Entry()) method on the LineData object, data, is filled with arguments according to the following syntax, which is further explained below.

data.addEntry(new Entry(x, y), yourDataSetIndex)

+   - newEntry() takes as input the x and y values that are to be printed on the graph.
- The second argument represents the index of the data set.
