# 2.7.1. IBM Cloud Database Configurations

In this section an IBM Cloud database will be configured and applications that can carry out the following tasks will be developed:

+   I. Send and receive data from an Android App to the IBM Bluemix cloudant database
II. Send and receive data from a Desktop App to the IBM Bluemix cloudant database
III. Send and receive data from a Web App to the IBM Bluemix cloudant database.
