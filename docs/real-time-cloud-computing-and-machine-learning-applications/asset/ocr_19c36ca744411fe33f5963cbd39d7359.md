# 4.3.6.5. Go to Analysis Button

To switch to the prediction.java class and make predictions or classifications, this button uses use of an Intent object, while specifying the class. It makes use of the startActivity() method.

# Listing 42.21. Go to Analysis Button

```
// Button to move to the activity/window
algoButton.OnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View v) {
        Intent i = new Intent(getApplicationContext(), Prediction.class);
        startActivity(i);
    }
});
```

+   - getTotalSpeeds(): Finding the total download and upload speeds consist of a combination of traffic from the Wi-Fi as well as mobile data, in kilobytes per second (kB/s).
- getMobileSpeeds(): Calculating the mobile/cellular download and upload speeds, in kilobytes per second (kB/s).
- getPackets():(): Getting the number of packets sent and received per second.
