# 6.4.4.11. The download_dateActionPerformed () Method

This method is responsible for downloading the records for a specific date from either the cloud database or the local Java server. The value of the boolean "fetchdate" is set to true first. If the value of "src_local" is set to true, analytics is fetched from the local server else the servlet hosted in the cloud is contacted for the results. Then, based on value of "data_src", each `requestDataLocal()` or `requestDataCloud()` is invoked. The codes for the method are given in Listing 6.32.

# Listing 6.32. download_dateActionPerformed () method

```
private void download_dateActionPerformed(java.awt.event.ActionEvent evt) {
  //set fetchdate to true to indicate data for a specific date
  fetchdate = true;
  //check whether we fetch data from cloud or local server
  src_local = (data_src.getSelectedIndex() == 0);
  //fetch the data accordingly
  if (src_local) {
    requestDataLocal();
  } else {
    requestDataCloud();
  }
}
```
