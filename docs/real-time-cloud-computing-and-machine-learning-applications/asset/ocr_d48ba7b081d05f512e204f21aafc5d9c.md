# 3.4.1.4. Naïve Bayes

Naïve Bayes classifiers are data classifiers that use the Naïve Bayes theorem of probabilities given in equation (3.16) to arrange data into appropriate classes [31]. The Naïve Bayes classifier assumes that the values of every feature are independent of each other. Compared to other data classifiers, they are relatively fast and so they can be used to perform real-time predictions.

$P(B|A) = \frac{P(B|A) * P(A)}{P(B)}$ (3.16)

Where,

+   $P(A|B)$ - Conditional probability of event A to occur given that B is true.
$P(B|A)$ - Conditional probability of event B to occur given that A is true.
$P(A)$ - Probability of event A to occur.
$P(B)$ - Probability of event B to occur.

In data classification, equation (3.16) can be rewritten in terms of a predictor (feature) X and a class C:

$P(C|X) = \frac{P(X|C) * P(C)}{P(X)}$ (3.17)

In the case where $n$ predictors are observed, equation (3.17) can be rewritten as follows:

$P(C|X_1, X_2, ..., X_n) = \frac{P(X_1|C) * P(X_2|C) * ... * P(X_n|C) * P(C)}{P(X_1) * P(X_2) * ... * P(X_n)}$ (3.18)
