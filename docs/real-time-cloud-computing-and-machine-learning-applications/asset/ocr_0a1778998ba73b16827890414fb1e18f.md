# 6.4.4.7. The requestAnalyticsCloud() Method

To query the java servlet for forecast result, the window size and prediction time need to be entered in the respective JTextField. Then, the predict button is pressed and the predictActionPerformed() method is invoked. If the value of "src-local" is set to true, analytics is fetched from the local server, else the servlet hosted in the cloud is contacted for results.

Querying the Java servlet for forecasting results follows the same methods as explained in Section 6.3.15. A connection to the Java servlet URL is made using the SOAP class. The connection timeout is set to two minutes to wait for the servlet to process the data in the cloud. In the URL, a query consisting of the targeted prediction time and window size needs to be formed. The window size is obtained from the window_s JTextField using the getText() method. It is then converted to an Integer using the Integer.parseInt(String function). The prediction time is obtained from the JTextField and the same operation is done to convert it to integer. These values are appended to the query part of the URL. After querying the servlet, the result is displayed in the TextArea for the user. The codes for this operation are shown in Listing 6.28.

# Listing 6.28. Querying Java Servlet

```
public void requestAnalyticsCloud() {
    //Starts anonymous Thread to request analytics from Cloud Servlet
    new Thread(() -> {
        ///the URL to connect to the Java Servlet
        String host = "https://weathercaster.eu-gb.myuemuemix.net/Forecaster?"
            + "&prediction_time=" + ptime.getText()
            + "&window_size=" + window_s.getText()
            + "&data_src-cloud=";

        ///Connect to the URL and get the JSON data returned by the servlet
        Document doc = Jsoup.connect(host).ignoreContentType(true)
            .timeout(4 * 60 * 1000).get();
        ///Extract the data in text format from the URL
        String analytics = doc.text();
        ///Display formatted data in the TextArea
        result.setText(formatData(analytics));
    } catch (IOException e) {
        ///prints the trace of the error that occurred
        System.out.println(e);
    }).start();
}
```
