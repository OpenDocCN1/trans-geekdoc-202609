Using the model above, a list of seven equations was obtained. For example, the MLR equation to predict the temperature value for time $t + n$ is as follows:

$T_{t+n} = \beta_0 + \beta_1 H_{t+n-1} + \beta_2 T_{t+n-1} \quad (7.2)$

The value of temperature for the time interval $t + 1$ is calculated from the previous temperature value $T_t$ and previous humidity value $H_t$. The coefficients $\beta_0, \beta_1 & & \beta_2$ are obtained from a Multiple Linear Regression model using a training window of $W$.
