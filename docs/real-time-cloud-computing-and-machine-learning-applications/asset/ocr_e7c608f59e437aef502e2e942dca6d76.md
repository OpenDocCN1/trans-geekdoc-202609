# 5.1.11.4. Performing K-Nearest Neighbour (KNN)

This section discusses the KNN classification of values for both the Android and PC devices and is called just after the fetching process in Section 5.1.11.2. The algorithm makes use of the five closest neighbours as declared by the global variable k, in Listing 5.1. It takes as input, values from the GUI for the classification process.

+   1. This process is performed using the KNNClassification() method which is summarised through the following points, in a step-wise manner:

+   - Fetch values to be classified in a double [] array.
- Set the values in a double.
- Check if the set has missing values so that the training process does not crash.
- Create the respective Instance object for the specific set of values.
- Check if the specified values field has missing values to prevent crashing.
- Initialise the distance values both to 0.
- Compute the Euclidean distance from the current value to the closest 5 classes based on the number of neighbours set using k = 5 as specified by the global variable, k.
- Create a Hashtable object to store all classes and the number of votes obtained
- Create a counter to determine the highest number of votes in the table.
- Calculate the highest number of votes by enumerating throughout the Hashtable created.

The codes for KNN classification are given in Listing 5.13 where the inner class DoublePair() is first described. The classes and objects instantiated for the model are from the Weka library [7].
