# Listing 3.33. Convolutional neural network- Load dataset

```
digitDatasetPath = fullfile(matlabroot,'toolbox','nnet','nndmos'), ...
'ndatasets','DigitDataset'; % Obtain full path to Digit Dataset files
imds = imageDatastore(digitDatasetPath, ...
'IncludeSubfolders',true, ...
'LabelSource','foldnames'); %Load Digit Dataset
```

The dataset is then divided into training and testing datasets by the code in Listing 3.34:

# Listing 3.34. Convolutional neural network- Divide dataset

```
numTrainFiles = 800; %Training set will include 800 images. The remaining images will be for testing.
[imdsTrain,imdsValidation] = splitEachLabel(imds,numTrainFiles,'randomize'); % Split dataset
```

The images size (28x28x1 pixels) and the number of classes (10 classes because of 10 digits) are defined along layer details of the CNN by using the codes in Listing 3.35:

# Listing 3.35. Convolutional neural network- Define image size, classes number and CNN layer details

```
inputSize = [28 28 1]; % Image size
numClasses = 10; % Number of classes (digits)
% Apply CNN layers
layers = [
InputLayer(inputSize) % Inputs image and applies normalization
convolution2DLayer(5,20) % Applying sliding filters
batchNormalizationLayer % Normalizes a small batch of data across all observations for each channel independently
reluLayer % Sets all values less than zero to zero
fullyConnectedLayer(numClasses) % Multiplies the input by a weight matrix and adds a bias vector
softmaxLayer % Outputs a vector that represents the probability distributions of a list of potential outcomes.
classificationLayer]; % Computes the cross-entropy loss for classification and weighted classification tasks with mutually exclusive classes
```
