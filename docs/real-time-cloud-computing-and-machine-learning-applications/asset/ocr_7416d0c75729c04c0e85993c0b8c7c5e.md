# Short-hand Example 11

The Q-Learning short-hand example is repeated using SARSA. SARSA is used to train a SARSA agent to find the best state transitions with the highest rewards to a goal state. The environment is a 1×4 grid world as follows:

| W | X | Y | Z |
|---|---|---|--|
| | | | |

The rules used in the short-hand example for Q-Learning are kept unchanged in this example:

+   1. The agent is initially placed in cell W.
2. The two possible actions which the agent can take are to move forward or move backwards.
3. Moving forward takes the agent to one cell to the right.
4. Moving backwards takes the agent back to cell W.

The results which are unknown to the agent as follows:

+   1. A +10 reward is given if cell Z is reached.
2. A +1 reward is given if the agent returns to cell W from any other cell.

The experiment is terminated in the following scenarios:

+   1. If the agent obtains any of the 2 available rewards.
2. If the agent tries to move backwards from cell W.
3. If the agent moves forward from cell Z.

Initially, all cells in the Q-table are initialized with a zero value:

| Action/ State | W | X | Y | Z |
|---|---|---|---|--|
| FORWARD (F) | 0 | 0 | 0 | 0 |
| BACKWARD (B) | 0 | 0 | 0 | 0 |

To train the SARSA agent a series of training episodes in which the agent is allowed to take random actions to update the Q-table described below. The discount rate is set to 0.9 and the learning rate is set to 0.2.
