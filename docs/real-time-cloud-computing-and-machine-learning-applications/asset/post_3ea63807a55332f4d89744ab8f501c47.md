## 3.5.2. SARSA

State–action–state–action (SARSA) is a machine learning algorithm in which the action taken by the agent affects the behaviour policy. Hence SARSA is categorised as an on-policy learning algorithm. In contrast, Q-learning is an off-policy learning algorithm. This implies that in Q-learning, the action taken in the next state is not determined by the behaviour policy.

Compared to Q-learning in which Q-value updates are performed to favour the actions with the highest rewards, the SARSA algorithm updates Q-values based on the next action to be taken from the new state by referring to the behaviour policy [54].

The Q-value in SARSA is updated using equation (3.25). As specified by its name, the SARSA algorithm updates the Q-value using the current state $s_t$, the chosen action $a_t$, the reward $r_t$, the next state $s_{t+1}$ and the next action $a_{t+1}$. A discount factor $\gamma$ and a learning rate $\alpha$ are also included during the update [55].

```
$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha[r_{t+1} + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t)] \quad (3.25)$
```
