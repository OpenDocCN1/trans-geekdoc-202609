## 3.4.1.2. Multiple Regression

Multiple linear regression is used when more than one variable is involved in determining a response. The multiple regression model can be derived by modifying the simple regression model to include additional predictors as follows:

$y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \cdots + \beta_kx_k + \varepsilon \quad (3.14)$

Where,
- $y$ - Response variable
- $k$ - Total number of predictors
- $\beta_0, \beta_1, \beta_2, \dots, \beta_k$ - Regression coefficients
- $x$ - Predictor variable
- $\varepsilon$ - Error

### Short-hand Example 4

In this example, the weight, horsepower and acceleration of a set of six cars are related to their mileage using multiple regression. The recorded data is given in Table 3.10:

### Table 3.10. Multiple linear regression - Recorded data

| Weight (Pounds), $x_1$ | Horsepower (hp), $x_2$ | Acceleration (m/s$^2$), $x_3$ | Mileage (Miles per Gallon), $y$ |
| :--- | :--- | :--- | :--- |
| 1835 | 46 | 20.5 | 26 |
| 1970 | 68 | 17.6 | 31 |
| 2372 | 95 | 15 | 24 |
| 3086 | 225 | 10 | 14 |
| 3504 | 130 | 12 | 18 |
| 4341 | 198 | 10 | 15 |

The least-squares method is used to obtain the equation of the regression. For this purpose, the multiple regression model can be initially written as:

$y_i = \beta_0 + \beta_1x_{i1} + \beta_2x_{i2} + \beta_3x_{i3} + \varepsilon_i$

The model can also be written in the following matrix form:

$y = X\beta + \varepsilon$

Where $\beta = {\beta_0, \beta_1, \dots, \beta_{k-1}\}'$

The design matrix $X$ in the following form is built: Where $n$ is the total observation and is equal to 6 in this example. In this case, $X$ is as follows:

| 1 | 1835 | 46 | 20.5 |
| 1 | 1970 | 68 | 17.6 |
| 1 | 2372 | 95 | 15 |
| 1 | 3086 | 225 | 10 |
| 1 | 3504 | 130 | 12 |
| 1 | 4341 | 198 | 10 |

An estimate of the matrix $\hat{\beta}$, can be obtained using the following equation:

$\hat{\beta} = (X'X)^{-1}X'y$

In this example:

| 1 | 1835 | 46 | 20.5 |
| 1 | 1970 | 68 | 17.6 |
| 1 | 2372 | 95 | 15 |
| 1 | 3086 | 225 | 10 |
| 1 | 3504 | 130 | 12 |
| 1 | 4341 | 198 | 10 |

Hence the linear model can be written as:

$y = 42.30 - 0.0027x_1 - 0.073x_2 - 0.29x_3$

The mileage of a car of 4000 pounds having 153 hp having an acceleration of 11 $m/s^2$ can be estimated using the multiple regression model as:

$Y = 42.30 - 0.0027(4000) - 0.073(153) - 0.29(11) = 17.14$ MPG

In MATLAB, multiple linear regression can be performed using the `fitlm` function from MATLAB's Statistics and Machine Learning Toolbox for simple regression with changes in the function's inputs. The syntax of the function for performing multiple regression is as follows:

```matlab
mdl = fitlm(X,Y)
```

The inputs to the function follow:

**X:** A matrix of predictor variables where each row represents one observation and each column represents one predictor variable.
**Y:** Response variable.

The predict function from MATLAB's Statistics and Machine Learning Toolbox can be used to predict the response for an untested predictor. A MATLAB simulation for performing the regression in the short-hand example is demonstrated below. The training dataset is first loaded into MATLAB's workspace and the regression model is then fitted using the codes in Listing 3.18.

### Listing 3.18. Multiple linear regression- Fit regression model
```matlab
Weight=[1835 1970 2372 3086 3504 4341]; % Matrix with car weight information
Horsepower=[46 68 95 225 130 198]; % Matrix with car horsepower information
Acceleration=[20.5 17 15 12 10]; % Matrix with car acceleration information
X =[Weight,Horsepower,Acceleration]; % Matrix with car information

y = [26 31 24 14 18 15]; % Matrix with miles information
mdl = fitlm(X,y); % Fit the regression model
```

By setting the weight to a random constant value of 1900 pounds, the fitted multiple regression line can be illustrated in a 3-D plot using the codes in Listing 3.19.
