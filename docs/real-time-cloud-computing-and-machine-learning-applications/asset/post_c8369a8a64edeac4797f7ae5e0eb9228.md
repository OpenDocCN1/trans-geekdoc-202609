## 3.3.1.2. Hierarchical Clustering

Hierarchical clustering groups elements by initially treating each data element as part of an individual cluster and then merging the closest clusters iteratively based on a linkage method (such as single linkage and complete linkage) until a specified number of clusters is obtained [15]. The single linkage method uses the distances between the closest data elements between two clusters, which is calculated using equation (3.3), to merge clusters [16].

```
$d(r,s) = \min(dist(x_{ri},x_{sj})), i \in (i,...,n_r), j \in (j,...,n_s) \quad (3.3)$
```

Where,

- $d(r,s)$ - distance between clusters $r$ and $s$.
- $x_{ri} - $i^{th}$ object in cluster $r$
- $x_{sj} - $j^{th}$ object in cluster $s$
- $n_r$ - number of data elements in cluster $r$
- $n_s$ - number of data elements in cluster $s$

The complete linkage method uses the distances between the furthest elements between two clusters, which is calculated using equation (3.4), to merge clusters [16].

```
$d(r,s) = \max(dist(x_{ri},x_{sj})), i \in (i,...,n_r), j \in (j,...,n_s) \quad (3.4)$
```

Where,

- $d(r,s)$ - distance between clusters $r$ and $s$.
- $x_{ri} - $i^{th}$ object in cluster $r$
- $x_{sj} - $j^{th}$ object in cluster $s$
- $n_r$ - number of data elements in cluster $r$
- $n_s$ - number of data elements in cluster $s$

The distances are calculated using a distance metric such as the Euclidean distance. The Hierarchical clustering algorithm constitutes of the following steps:

- 1. Each data element is considered as part of its own cluster.
2. The two closest clusters are merged to form a single cluster using the appropriate linkage method.
3. Step 2 is repeated until the required number of clusters are remaining.

# Short-hand Example 2

In this example, Hierarchical clustering with the single linkage method is used to group a set of 6 cars into 2 clusters based on their weights and miles. The weights and miles of the cars are given in Table 3.8:

# Table 3.8. Hierarchical clustering- Car details

| Car | Weight (Pounds) | Mileage (Miles per Gallon) |
|---|---|---|
| A | 1835 | 26 |
| B | 3600 | 15 |
| C | 2372 | 24 |
| D | 3086 | 14 |
| E | 3504 | 18 |
| F | 1970 | 31 |

Initially, each car is considered to be part of its own cluster. In this example, a cluster pooling of cars A, B and C will be labelled as $C_{ABC}$. The distances between the clusters are calculated using the Euclidean distances between the data element. For example, the Euclidean distance between clusters $C_A$ and $C_B$ is calculated:

```
$d(C_A,C_B) = \sqrt{(1835-3600)^2 + (26-15)^2} = 1765.0$
```

Similarly, the Euclidean distances between all clusters are listed in the distance matrix:

| Distance | $C_A$ | $C_B$ | $C_C$ | $C_D$ | $C_E$ | $C_F$ |
|---|---|---|---|---|---|---|
| $C_A$ | 0 | 1765.0 | 537.5 | 1251.0 | 1670.0 | 35.0 |
| $C_B$ | 1765.0 | 0 | 1233.0 | 525.0 | 103.0 | 1801.0 |
| $C_C$ | 537.5 | 1233.0 | 0 | 714.0 | 1234.0 | 502.0 |
| $C_D$ | 1251.0 | 525.0 | 714.0 | 0 | 434.0 | 1116.0 |
| $C_E$ | 1670.0 | 103.0 | 1234.0 | 434.0 | 0 | 1533.0 |
| $C_F$ | 35.0 | 1801.0 | 502.0 | 1116.0 | 1533.0 | 0 |

In each iteration, the closest clusters are $C_A$ and $C_F$ (distance 35.0). They are merged into a cluster $C_{AF}$. The distance matrix is updated:

| Distance | $C_{AF}$ | $C_B$ | $C_C$ | $C_D$ | $C_E$ |
|---|---|---|---|---|---|
| $C_{AF}$ | 0 | 1801.0 | 502.0 | 1116.0 | 1533.0 |
| $C_B$ | 1801.0 | 0 | 1233.0 | 525.0 | 103.0 |
| $C_C$ | 502.0 | 1233.0 | 0 | 714.0 | 1234.0 |
| $C_D$ | 1116.0 | 525.0 | 714.0 | 0 | 434.0 |
| $C_E$ | 1533.0 | 103.0 | 1234.0 | 434.0 | 0 |

Next, the closest clusters are $C_B$ and $C_E$ (distance 103.0). They are merged into $C_{BE}$. The distance matrix is updated:

| Distance | $C_{AF}$ | $C_{BE}$ | $C_C$ | $C_D$ |
|---|---|---|---|---|
| $C_{AF}$ | 0 | 1533.0 | 502.0 | 1116.0 |
| $C_{BE}$ | 1533.0 | 0 | 1234.0 | 434.0 |
| $C_C$ | 502.0 | 1234.0 | 0 | 714.0 |
| $C_D$ | 1116.0 | 434.0 | 714.0 | 0 |

Next, the closest clusters are $C_{BE}$ and $C_D$ (distance 434.0). They are merged into $C_{BED}$. The distance matrix is updated:

| Distance | $C_{AF}$ | $C_{BED}$ | $C_C$ |
|---|---|---|---|
| $C_{AF}$ | 0 | 1116.0 | 502.0 |
| $C_{BED}$ | 1116.0 | 0 | 714.0 |
| $C_C$ | 502.0 | 714.0 | 0 |

Finally, the closest clusters are $C_{AF}$ and $C_C$ (distance 502.0). They are merged into $C_{AFC}$. The process stops as we have 2 clusters: $C_{AFC}$ and $C_{BED}$.

The final clusters are:
- Cluster 1: {Car A, Car C, Car F}
- Cluster 2: {Car B, Car D, Car E}
