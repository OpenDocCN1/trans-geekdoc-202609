## 6.4.4.6. The sendData() Method

This method is used to save a JSONObject to a Cloudant database. It accepts a JSONObject as an argument. The method works by first connecting to the Cloudant platform using a URL endpoint, username, and a password. The connection is made using a CloudClient object. A connection to a database in the platform is made using the `database(String db, boolean create)` method of the CloudantClient. Then, a query is formulated to select all the data in the database and sort in descending order. The last value of idx is obtained. The value of idx is incremented by one and added to the JSONObject. ### 6.4.4.7. The analyticsCloud() Method

To query the java server for results, the window size and prediction time need to be entered in the JTextField. Then, the predict button is pressed and the `ActionPerformed()` method is invoked. If the value of "src_cloud" is true, analytics is fetched from the cloud else the servlet hosted in the client is contacted.

To query the Local server for forecasting results, a Socket connection is first open to the IP address entered by the user on port 1111. A JSONObject is created to store the request type, window size, and prediction time entered by the user. The JSONObject is sent to the server. The server processes the request and returns the analytics results in a JSONObject. The data is extracted from the JSONObject, formatted into a readable format using the `getData()` method and displayed in the TextView.
