# 6.3.24.3. writeToFileStorage Method

This method accepts a String representation of a CSV file and writes it to the application default download location. The download location is automatically generated by the application if it is not already present. A unique identifier based on the current timestamp is generated and appended to the file name. A file is created in the download location and a BufferedWriter is used to write the CSV data to the File. The codes for the function are listed in Listing 6.16.

# Listing 6.16. Saving File to Internal Storage of Application

```java
public void writeToFileStorage(String data) {
    //get the absolute pathname of the download folder.
    String absolutePath = String.valueOf(getExternalFilesDir(Environment.DIRECTORY_DOWNLOADS));
    //Create a String of the current timestamp
    String timestamp = new SimpleDateFormat("yyyyMMMddHHmm", Locale.ENGLISH).format(new Date());
    // Create a new file saved in the selected directory and the timestamp as a unique identifier appended to the filename /
    File file = new File(absolutePath + "/Weather_Data_" + timestamp + "_dateT.CSV");
    //Create a new BufferedWriter from the file object
    try (BufferedWriter br = new BufferedWriter(new FileWriter(file))) {
        br.write(data);
        //flush any remaining data to the File
        br.flush();
    } catch (IOException e) {
        e.printStackTrace();
    }
}
```
