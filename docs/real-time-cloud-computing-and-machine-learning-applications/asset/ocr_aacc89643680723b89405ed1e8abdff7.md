# 6.3.5. MainActivity

When the user first starts the application, the Mainactivity is started and the Mainactivity.java file defines the purpose of that activity. For this application, the main activity will be responsible for displaying the graph and query weather API every N minutes sending the results to either a local server or directly to the cloud.
