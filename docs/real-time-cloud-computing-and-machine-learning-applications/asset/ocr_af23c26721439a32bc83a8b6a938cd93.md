+   - MLPRegression(float[]) data, int tf, int tn

This is the main constructor of the class. It accepts a 2D float array where each row represents a weather observation. It also takes as input two integer values $t_f$ - the number of input samples and $t_n$ - the number of timesteps to predict. A DataSetIterator object is used to generate a training dataset for the network. Then, a FeedForwardNetwork Object is created. This object represents a Feedforward neural network architecture, also known as Multi-Layer Perceptron. The input size of the network is the number of samples in one day, that is 24 * 4 samples. The output size is the number of timesteps to predict.

+   - trainModel(int epoch)

This method is used to train the network over the training dataset generated in the constructor. A BackpropagationTrainer object is created to implement a backpropagation algorithm. Backpropagation is a supervised machine learning algorithm that iteratively reduces prediction error, by looking for the minimum loss function. max error, learning rate, and momentum values are obtained using trial by error. The network was trained on model data using different values for the hyperparameters until an acceptable error was obtained. The number of epochs is a hyperparameter of gradient descent that controls the number of complete passes through the dataset. The required parameters are as per Table 79.
