Moreover, compared to a base station with on-processing, remote radio terminals have a much smaller footprint, which leads to less complex and economical network densification [9].

The rationale of C-RAN is to split the functions of the base stations by separating the base station into a Baseband Unit (BBU) and a Remote Radio Head (RRH). After that, using cloud computing and virtualization techniques, the BBUs from several sites are centralized into a common geographical location such as a data center. BBUs are responsible for Baseband signal processing, while signal amplification and modulation are performed by RRHs. A front haul link connects the BBU pool to the RRHs that are deployed at the cell site and an antenna. Hence adaptation to random traffic and effective utilization of the resources becomes possible. The same BBU pool can be shared by several operators, by leasing it as a cloud service. Additionally, with a reduction in the handover delay, an improvement in network performance is achieved. The centralization of the BBUs at a single site leads to a reduction in the running cost. Furthermore, in contrast to conventional RAN, the addition and upgrade of new BBU is much simpler. To raise the network capacity, only the installation of an RRH is required by MNOs. The network costs are further decreased as the C-RAN leads to a reduction in power and energy consumption [10].

# 1.1.2.4. Big Data Analytics

Big Data is associated with massive volumes of data generated by operational systems such as Enterprise Planning (ERP), User customer relationship (CRM), Supply Chain Management (SCM) systems well as IoT sensors and mobile traffic. This huge dataset which is a combination of both structured and unstructured data is termed as Big data in conventional data structures. The main characteristics of Big Data can be described by Vs namely Volume, Velocity, Variety and Variety [11]. The analysis of big data leads to valuable insights which can be in the form of pattern identification, interpretations, guidelines for decision making and subsequently the ability to provide intelligent responses to different situations. A plethora of quantitative techniques such as AI, machine learning, deep learning, statistics and numerical methods are used for data mining and pattern discovery in big data. These techniques are required to deal with the voluminous and heterogeneous nature of big data.

By providing flexible and efficient access to data as well as enhanced communication of insights, cloud computing can significantly promote the capacity of scalable analytics solutions. However, a generic solution to all organisations cannot be obtained from cloud-based big data. Different models exist for organizations that use cloud computing to benefit from Analytics as a Service (AaaS). To provide security for sensitive and confidential data, one possibility is to use a private cloud for better control. A public cloud platform is used for analytic services and enhanced scalability. It is also possible to obtain the benefits of both security and scalability by implementing a hybrid public and private cloud model [12]. The following main benefits are obtained from an AaS model:

- Structured and unstructured data can be extracted from reliable sources and the most relevant parts of the data can be identified and retained for the amount of time required.
- Data can be managed and controlled by conforming to industrial specifications and following a standard policy and set of rules applicable for the whole organization.
- Timely information can be delivered at the required location by integrating, transforming, analyzing and visualizing the data.

# Cloud Private Branch Exchange (PBX)

A low cost, scalable, secure and reliable office phone system can be obtained via an internet connection by using a cloud or virtual PBX. A PBX system (branch exchange) is a private phone system deployed inside a company or organization. New business phone systems have shifted away from conventional phone systems which are now being replaced by PBX systems that make use of an internet connection. By connecting IP phones to a PBX server, major cost savings and enhanced phone features are obtained. In contrast, a cloud phone system is hosted on a cloud server although it operates in a similar fashion. Given the availability of efficient network connectivity in most organizations, the cloud PBX has become a viable option. The main advantages of a cloud PBX over conventional phone systems are as follows:

- Maintenance free — The interfaces provide a simpler management of the server and since the cloud PBX is hosted by the provider, there is no maintenance or administration responsibilities on the part of the client.
- Lower costs — the pay-as-you-go policy ensures significant cost savings to cloud PBX users are as the case for other cloud services.
- Simplified installation — Minimal server-side knowledge is required as most cloud phone systems have user friendly installation applications [13].

Machine learning, which allows machines to learn from previous data or processes without the need of explicit programming, is in turn a subfield of artificial intelligence. Machine Learning is a modeling technique that infers data or more precisely it the "model" out of "data." Information such as documents, audio, images, etc., are considered to be data elements in this case. The final outcome of Machine Learning is the "model." Machine learning provides a computer system with the ability to predict and be involved in decision making processes using past data. The need for explicit programming is also eliminated. In order to produce results and predictions with high accuracy, a large amount of structured and semi-structured data are required by machine learning [15, 16].
