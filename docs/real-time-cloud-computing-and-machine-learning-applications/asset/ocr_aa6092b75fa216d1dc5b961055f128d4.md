# Listing 5.3. Implementing the space for the live graph

```
// Allocating specific space for graph upon creation
public void createGraphSpace() {
    // Creating a series called "Parameter" to hold data items
    series = new XYSeries("Parameter");
    // Passing the series created into a particular dataset
    XYSeriesCollection dataset = new XYSeriesCollection(series);
    // Initialising the JFreeChart variable and passing the dataset
    chart = ChartFactory.createXYChart("Press button to start monitoring", "Time (seconds)", "Value", dataset);

    // Creating a chartPanel object to hold the created chart
    final ChartPanel chartPanel = new ChartPanel(chart);
    // Setting the dimensions manually for the panel
    chartPanel.setPreferredSize(new Dimension(475, 265));
```
