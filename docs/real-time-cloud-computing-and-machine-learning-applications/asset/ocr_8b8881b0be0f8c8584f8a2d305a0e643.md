After this episode, the Q-value, $Q(X,B)$, can be updated using equation (3.24):

```
$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha [r_{t+1} + \gamma \max Q(s_{t+1}, a_t) - Q(s_t, a_t)]$
```

At the instance where the agent was in state X (i.e., $s_t = X$), going backwards (i.e., $a_t = B$), the reward obtained was +1 (i.e., $r_{t+1} = 1$) and the Q-value from the Q-table for the next state, W, with the action leading to the maximum Q-value is zero.

```
$Q(X,B) \leftarrow Q(X,B) + \alpha[r_{t+1} + \gamma \max(Q(W,F), Q(W,B)) - Q(X,B)]$\n$Q(X,B) = 0 + 0.2[1 + 0.9 \times \max(0,0) - 0] = +0.2$
```

The updated Q-table is as follows:

| Action/State | W | X | Y | Z |
|---|---|---|---|--|
| FORWARD (F) | 0 | 0 | 0 | 0 |
| BACKWARD (B) | 0 | +0.2 | 0 | 0 |
