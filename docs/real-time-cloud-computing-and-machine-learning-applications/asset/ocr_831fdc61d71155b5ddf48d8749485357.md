# 7.1.12.1. Normalization of the Data

For a neural network, the input data needs to be normalized before being speeds up the network for training. Normalizing the data reduces the convergence time in one order of magnitude [2][3]. For normalizing the data, the Min-max normalization is used to scale the data between 0 and 1 using the following equation:

> $normalised = \frac{X-X_{min}}{X_{max}-X_{min}} (7.19)$
