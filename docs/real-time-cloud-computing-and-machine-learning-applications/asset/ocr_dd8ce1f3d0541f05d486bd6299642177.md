The rlSARSAAAgent function from MATLAB’s Reinforcement Learning Toolbox can be used to create a SARSA agent [56]. The syntax of the function is as follows:

```
agent= rlSARSAAAgent(critic,agentOption)
```

The inputs to the function are described below:

**critic**: Critic network representation (Q-table).

**agentOption**: Object created from the rlSARSAAAgentOptions function from MATLAB’s Reinforcement Learning Toolbox which specifies the agent’s configuration.
