The regression line can be obtained using the least square method which solving a system of linear equations in the form $Ma = b$ as follows [29]:

```
$$\begin{bmatrix} \sum_{i=1}^{N} x_i & \sum_{i=1}^{N} x_i^2 & \dots & \sum_{i=1}^{N} x_i^k \\ \sum_{i=1}^{N} 1 & \sum_{i=1}^{N} x_i & \dots & \sum_{i=1}^{N} x_i^k \\ \vdots \\ \sum_{i=1}^{N} x_i^k & \sum_{i=1}^{N} x_i^{k+1} & \dots & \sum_{i=1}^{N} x_i^{2k} \end{bmatrix} \begin{bmatrix} \beta_0 \\ \beta_1 \\ \vdots \\ \beta_k \end{bmatrix} = \begin{bmatrix} y_i \\ y_i \\ \vdots \\ y_i \end{bmatrix}$$
```

## Machine Learning Algorithms

The linear system in this example is as follows:

```
$$\begin{bmatrix} 6 & 1.71 \times 10^4 & 5.35 \times 10^7 \\ 1.71 \times 10^4 & 5.35 \times 10^7 & 1.81 \times 10^{11} \\ 5.35 \times 10^7 & 1.81 \times 10^{11} & 6.54 \times 10^{14} \end{bmatrix} \beta_0 = \begin{bmatrix} 128 \\ 3.37 \times 10^5 \\ 9.79 \times 10^8 \end{bmatrix}$$
```

Each of the coefficients may then be calculated using determinants as follows:

```
$$\beta_i = \frac{det(M_i)}{det(M)}$$
```

Where, $M_i$ is built by replacing the $i^{th}$ column in matrix $M$ with the column vector $b$. In this, $M_0, M_1$ and $M_2$ are as follows:

```
$M_0 = \begin{bmatrix} 128 & 1.71 \times 10^4 & 5.35 \times 10^7 \\ 3.37 \times 10^5 & 5.35 \times 10^7 & 1.81 \times 10^{11} \\ 9.79 \times 10^8 & 1.81 \times 10^{11} & 6.54 \times 10^{14} \end{bmatrix}$
$M_1 = \begin{bmatrix} 6 & 128 \\ 1.71 \times 10^4 & 3.37 \times 10^5 & 5.35 \times 10^7 & 1.81 \times 10^{11} \\ 5.35 \times 10^7 & 9.79 \times 10^8 & 6.54 \times 10^{14} \end{bmatrix}$
$M_2 = \begin{bmatrix} 6 & 128 \\ 1.71 \times 10^4 & 5.35 \times 10^7 \\ 3.37 \times 10^5 & 5.35 \times 10^7 & 1.81 \times 10^{11} & 9.79 \times 10^8 \end{bmatrix}$
```

Using the determinants of the above matrices, the coefficients are calculated as follows:

```
$\beta_0 = \frac{det(M_0)}{det(M)} = \frac{7.68 \times 10^{21}}{1.77 \times 10^{20}} = 43.33$
$\beta_1 = \frac{det(M_1)}{det(M)} = \frac{-1.73 \times 10^{18}}{1.77 \times 10^{20}} = -0.0098$
$\beta_2 = \frac{det(M_2)}{det(M)} = \frac{1.16 \times 10^{14}}{1.77 \times 10^{20}} = 6.59 \times 10^{-7}$
```

Hence the polynomial model can be written as:

```
$y = 43.33 - 0.0098x + (6.59 \times 10^{-7})x^2$
```

The mileage of a car with 3000 pounds ($x=3000$) can be estimated as follows:

```
$Y = 43.33 - 0.0098(3000) + (6.59 \times 10^{-7})(3000)^2 = 19.86$ MPG
```

The fitlm function from MATLAB's Statistics and Machine Learning Toolbox can be used to fit a polynomial regression model. The syntax of the function for polynomial regression is as follows:

```
mdl= fitlm(X,Y,modelspec)
```

The inputs to the function are described below:

- X: Predictors variable.
- Y: Response variable.
- modelspec: Model specification. Should be set to 'polyijk' for polynomial regression, where i, j and k take the value of the highest degrees of the first, second and third predictors. In single predictor is used, the value i should be set. For example, 'poly3' is used for regression in a single-predictor scenario having the highest degree of 3. ## 3.4.1.4. Naïve Bayes

Naïve Bayes classifiers are data classifiers that use the Naïve Bayes theorem of probabilities given in equation (3.16) to arrange data into appropriate classes [31]. The Naïve Bayes classifier assumes that the values of every feature are independent of each other. Compared to other data classifiers, they are relatively fast and so they can be used to perform real-time predictions.

$P(B|A) = \frac{P(A \cap B)}{P(A)}$

Where,

- $P(B|A)$ - Conditional probability of B occurring given A is true.
- $P(A|B)$ - Conditional probability of A occurring given B is true.
- $P(A)$ - Probability of event A.
- $P(B)$ - Probability of event B.

In data classification, equation (3.16) can be rewritten in terms of a predictor (X) and class C:

$P(C|X) = \frac{P(X|C)P(C)}{P(X)}$

Where,

- $P(C|X)$ - Conditional probability of class C given X is true.
- $P(X|C)$ - Conditional probability of X occurring given class C is true.
- $P(C)$ - Probability of class C.
- $P(X)$ - Probability of predictor X.

In the case where $n$ predictors are observed, equation (3.17) can be rewritten as follows:

$P(C|X_1, X_2, \dots, X_n) = \frac{P(X_1, X_2, \dots, X_n|C)P(C)}{P(X_1, X_2, \dots, X_n)}$ (3.18)

For a given input, the denominator remains constant for the conditional probabilities calculated each class. Hence the equation can be simplified as:

```
$: P(C|X_1, X_2, \dots, X_n) \propto P(C) \prod_{i=1}^{n} P(X_i|C)$
```
