2. Thus, a total of five values, which is the total of the batch of window size, is taken as inputs while the successive value just after the prediction time is taken as the model output. The two values representing the ptime are discarded. The inputs and output values for the first three windows are demonstrated in Table 5.15.

# Table 5.15. Inputs and output logic for MLP regression

| Input values | Output value |
| 1 | 792, 1512, 1094, 1216, 1204 | 1179 |
| 2 | 1512, 1094, 1216, 1204, 1239 | 1189 |
| 3 | 1094, 1216, 1204, 1239, 1210 | 1316 |

3. In other words, Table 5.16 represents the trend as well as the general notion of how the inputs and output values are taken, with sliding windows.

# Table 5.16. General notion of sliding windows for MLP regression

| Start of inputs | End of inputs | Output |
| P_1 | P_w | P(w+1) |
| P_2 | P_{w-1} | P(w+2) |
| P_3 | P_{w-2} | P(w+3) |
| P_{n-(w+1)} | P_n | P_{n+p} |

Where:

+   - P: Packets received
- w: Window size
- p: Prediction time
- P_n: Last value in the dataset
- P_{n+p}: Value to be predicted
