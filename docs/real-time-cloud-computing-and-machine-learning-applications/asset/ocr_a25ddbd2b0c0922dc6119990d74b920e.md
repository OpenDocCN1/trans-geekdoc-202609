b) Update the graph with the incoming data
To update the graph with the weather readings obtained, the string response needs to be converted to a JSONObject first. This is done using the **new JSONObject (String JSON)** constructor which accepts a valid string representation of a JSONObject. After creating the JSONObject, the required values are extracted using the same method as in 6.3.16. After extracting the required values, a new JSONObject is created and filled with the extracted values. A new timestamp is added to the JSONObject to mark its creation time. To update the graph, the required reading from the newly JSONObject is obtained using the **getDouble (String key)** method. The currently selected variable is added to the XYSeries array with the counter incremented by one using the **add (double x, double y)** method.

c) Send the data to the Cloud database or the local server
After getting the data from the API, the data needs to be sent to either a local server or directly to the Cloud database. An **if-else** statement is used to check whether the **cloud_save** checkbox has been selected. If it is selected, the data is sent to the cloud. To send the data to the cloud database, the **sendData(JSONObject JSON)** method is invoked and passes as an argument the newly created JSONObject. If the checkbox has not been checked, the data is sent to a local server using a socket connection with the IP address entered in the **address_f** J JTextField.
