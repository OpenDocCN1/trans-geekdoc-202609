# 6.3.26. QueryDateLocalTask

This class is responsible to download weather data from a Local Java Server. This class is used to perform the associated networking operations on a background thread. The constructor of this class accepts a boolean "date" that indicates whether data for a specific date has to be fetched or only the last N samples. To connect to the local java server, a socket connection is opened using the IP entered on port 11111.

A JSONObject is created to store the request type and based on the value of "date", either the data or sample size is stored. The value of the "date" boolean is checked, if it is true, this means data for a specific date is being requested. So, the date entered is stored in the JSON Object. If the value of the date is false, this means data for a fixed sample size is being requested, and the sample size entered is stored in the JSON Object.

The JSONObject is sent to the server. The server processes the request and returns the CSV file in a JSONObject. The CSV String is extracted from the JSONObject, displayed in the TextView and saved to the internal storage. The codes for the QueryDateLocal Class are given in Listing 6.18.
