# 7.1.9.1. Regression using MLR Model

The steps followed for prediction using a Multiple Linear Regression are given below.

+   1. Reshaping data as per equation (7.3)

Equation (7.3) describes an MLR model as a system of linear equations in matrix notation that can be solved using OLS to obtain the regression coefficients. The first step is to reshape the data into its matrix form. An array that contains the response variable is generated and a two-dimensional array that follows the design matrix as in equation (7.9) is also generated. The formal parameters for the predict () method consist of two double arrays that represent the independent variable. For temperature, these two variables are temperature and humidity.
