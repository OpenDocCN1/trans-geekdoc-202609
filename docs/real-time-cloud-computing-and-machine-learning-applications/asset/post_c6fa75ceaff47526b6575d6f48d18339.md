## 7.4.1.3. Performing Prediction

First, the user must choose a data source from the Combo Box. Data can either be loaded from the Cloudant database or a local server. The user can then fill in the window size for the regression algorithms and the prediction time for which prediction is required. After filling in these values, the user clicks on the “Submit” button to trigger the getAnalytics () function. The following steps are performed by the function:

- Gets the regression window size from the "window_size" textField
- Gets the prediction time from the "prediction_time" textfield
- Forms the request URL using the formRequestURL() method
- Appends the servlet name, window size, prediction time, and data source to the URL
- Using the global "fetch()" method that provides an easy, logical way to fetch resources asynchronously across the internet, a connection to the URL is opened. The link is specified in the "fetch()" method. The "Forecaster" servlet will evaluate the query and return a JSON object containing the analytics results.
- Extract the results from JSONObject returned and display it in the result TextArea.

The codes are given in Listing 7.34.

### Listing 7.34. getAnalytics () Result

```javascript
function getAnalytics() {

//Get the regression window size
var window_s = document.getElementById("window_size").value;
//Get the prediction time
var pred_time = document.getElementById("prediction_time").value;
//Get the request URL
var query = formRequestURL();
var request = query.URL + "Forecaster?window_size=" + window_s + 
"&prediction_time=" + pred_time + "&data_src=" + 
query.data_src;

fetch(request)
  .then((res) => res.JSON())
  .then((out) => {
    document.getElementById("results").value = out.results;
  }).catch((err) => console.error(err));

}
```

## 7.4.1.4. Download Weather Data

To download weather, the user has the choice between downloading data for a specific date or only the last N samples. To download for a specific date, the user must enter the date for which data is required in the following format "MM/DD/YYYY" and click on the "Download" button. However, if only the last N samples are required, the user must enter the number of weather observations needed in the second input and then click on the "Download" button. when the download button is clicked, getCSVData() function is triggered. The function performs the following steps:

- Gets the date entered by the user from the "date_t" textbox
- Gets the number of samples entered from the "samp_n" textbox
- Forms the request URL using the formRequestURL ( ) method
- Appends the servlet name to contact, date, sample size, and data source to the URL
- Using the global "fetch ()" connection to the URL is opened. The link is specified in the "fetch ()" method. The "Downloader" servlet will evaluate the query and return a JSON object containing the CSV string to be saved.
- A new hidden link is created on the page
- The link to which the link goes specified.
- The target to "_blank" to prevent opening a new tab.
- Specifies the target to be downloaded using the "download" attribute of the link.
- Finally, a click on the link is simulated to trigger the download link and download the file.

The codes are given in Listing 7.35.

### Listing 7.35. - getCSVData()

```javascript
function getCSVData() {
// Get the date entered by the user
var date_t = document.getElementById("date_t").value;
// Get the number of samples entered by the user
var samp_n = document.getElementById("samp_n").value;
// Get the request URL
var query = formRequestURL();
// Form the full URL
var request = query.URL + "Downloader?date_t=" + date_t + "&down_n=" +
samp_n +
    "data_src=" + query.data_src;

console.log("Request: " + request);
fetch(request)
.then(res => res.JSON())
.then(out => {
    var CSV_dat = out.CSV;
//creates a new link
var hiddenElement = document.createElement('a');
//link the CSV data to the link
hiddenElement.href = 'data:text/csv;charset=utf-8,' +
encodeURI(CSV_dat);
// set target to prevent opening a new tab
hiddenElement.target = '_blank';
// specifies that to be downloaded
hiddenElement.download = 'weather_data.CSV';
// simulates a click on the link to trigger the download link
hiddenElement.click();
}).catch(err => console.error(err));
```

## 7.4.2. Hosting the Java Servlet on IBM Cloud

3. Enter the IBM Bluix login details and click Validate as shown in Figure 7.40![](img/2b52fde0e707e8c2f05a10309c3f8982_788_1.png) Figure 7.40. Validating IBM Cloud.

4. Eclipse will then show the User's Organization and Spaces. Click on Next as shown in Figure 7.41![](img/2b52fde0e707e8c2f05a10309c3f8982_789_0.png) Figure 7.41. User Space in Bluemix.

5. A window with the available resources will be shown. Any resource move to the right will be deployed to the Bluemix Server.
