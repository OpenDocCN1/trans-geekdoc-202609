## 3.5. REINFORCEMENT LEARNING ALGORITHMS

### 3.5.1. Q-Learning

Q-learning is a method of learning in which the system relies on interactions with the environment to determine value functions. The Q-learning agent does not utilise a model of the environment as a reference and is thus recognised as a model-free algorithm. The role of the agent is to decide on the optimal action to take from its current state.

The equation for Q-learning is given by (3.24) [50]. The equation relies on the current state and the chosen action to calculate a Q-value. Q-values are stored in a Q-table, which is also referred as as the critic. The Q-table is updated during the learning process. The total long-term rewards are determined upon the execution of actions and the actions leading to the highest reward identified. The Q-learning agent uses an exploration process to identify the highest rewards rewards. Exploration is the act of taking an action other than the one that the system knows will lead to the currently known highest Q-values, in an attempt of achieving an even Q-value [50].

```
$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + a[r_{t+1} + \gamma \max Q(s_{t+1}, a_t) - Q(s_t, a_t)] \quad (3.24)$
```

Where,

- $s_t$ - Current state
- $a_t$ - Selected action
- $Q(s_t, a_t)$ - Q-value for current state with selected action from the current state
- $\max_a Q(s_{t+1}, a_t)$ - Q-value for next state with action leading to the maximum Q-value
- $\alpha$ - Learning rate
- $\gamma$ - Discount rate
- $r_{t+1}$ - Reward received while moving to $s_{t+1}$
