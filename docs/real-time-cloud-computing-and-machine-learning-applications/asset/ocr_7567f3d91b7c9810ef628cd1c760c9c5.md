# 3.1.2. Artificial General Intelligence (AGI)

AGI is the form of AI which has the same understanding and learning capabilities as a human being. An AGI system should be able to have human-like sensory-perception capabilities, good motor skills, natural language understanding and social skills. It should also be capable of autonomously navigate through complex environments and should exhibit human-level creativity [3].

# 3.1.3. Artificial Super Intelligence (ASI)

ASI system is a hypothetical self-aware system with intelligence and abilities surpassing those of humans. Such a system is expected to help humans better understand the universe and will be able to execute complex tasks without human intervention [4].

ML is the process of learning through the automatic detection of meaningful patterns in data. ML is an appropriate mechanism for solving problems that have high complexities and a need for adaptivity [5]. The learning procedure in ML can be described as the optimization of a model's parameters based on training data. The optimized/trained model can then be used to make predictions, perform classification, or even gain more knowledge from new data. The mathematical models of ML algorithms are mainly derived from statistics theories [6]. ML has obtained significant attention for the past few years since computers have become powerful enough to run algorithms over large datasets which would otherwise be tedious for humans to manually process [7].

DL is a specialized form of machine learning. It is a learning process in which a machine learns from experience rather than a human operator.
