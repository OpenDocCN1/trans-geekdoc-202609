## 6.4.4.4. Timer & TimerTask

- Timer Class:
This class is a facility for threads to schedule tasks for future execution in a background thread. Tasks may be scheduled for one-time execution or repeated execution at regular intervals. Timer tasks should complete quickly. If a task takes excessive execution to complete, it "hogs" the timer's task execution thread. For this program, the schedule(TimerTask task, long delay, long period) method is used. It schedules the specified task for fixed-delay execution, beginning after the specified delay. The timer can be terminated using the cancel() method which discarding any scheduled tasks.

- TimerTask Class:
This class represents a class that defines a task that can be scheduled for one-time or repeated execution by a Timer. The TimerTask can be cancelled using the cancel() method. The task to be performed is implemented in the abstract run() method of the TimerTask object.
