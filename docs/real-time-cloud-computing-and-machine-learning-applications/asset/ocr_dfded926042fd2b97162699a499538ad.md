Depending on the data required, the appropriate Selector object is created. Using the QueryBuilder object, the appropriate query is created. This query is executed using the query ( ) method of the Database instance. This method takes as a String representation of the query and the class of objects returned by the query. In this case, the return data type is LinkedTreeMap, which is a map of comparable keys to values. The query ( ) method returns an object of QueryResult contains details about the result of the query as a list of records matching the query criteria, warning, bookmark, and execution stats.

Using the getDocs() method of the QueryResult object, the list of records is obtained and stored in a List of LinkedTreeMap. Each item in the list is iterated one at a time. The values are extracted and type-cast to double the get (String key) method of the LinkedTreeMap object. The weather parameters are stored in the 2D array "db.data". The timestamp value is extracted and type-cast to String and stored in the double array "timestamps". Finally, an Object is created to store the double array and string array and the Object is returned. The codes for the method are given in Listing 6.2.
