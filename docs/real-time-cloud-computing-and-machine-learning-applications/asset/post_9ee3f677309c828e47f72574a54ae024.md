## Server and Servlet Architectures for a Cloud-Based Real-Time

- 4. The next step is to fetch the values from either the Cloudant database or localhost and use the OpenCSV library to prepare the data to be saved in the .csv file.
- Determine which device is selected for download by the user.
- Fetch "N" from the GUI.
- If the "Localhost Values" toggle is unselected, use the "download" Runnable thread to fetch all the records from the Cloudant database using the retrieving methods explained in Section 5.1.12.3.
- If the "Localhost Values" toggle is selected, use the "downloadLocalHost" Runnable thread to fetch all records from localhost.
- Create a List object with String variables.
- Add a header record with the parameter names.
- Use the List object to store the variables via a loop encompassing the last "N" number of records by converting the variables of type double to String.
- Use the CSVWriter class to write the List object to the destination previously set.

Listing 5.23 is also incorporated under the downloadButtonActionPerformed method. The "download" Runnable thread is then started using the Thread class after defined.

## Listing 5.23. Thread to download last N samples from Cloudant database

```java
Runable download = new Runnable() {
    @Override
    public void run() {
        try {
            // If the selected device is the PC device
            if (downloadDevice.getSelectedItem().toString().equals("PC")) {
                // Fetch from GUI
                double length = Double.parseDouble(lastN.getText().toString());
                // Fetch all from cloud database for PC
                fetchRegressionValues();
                // Make the list that contains the String arrays
                List<String[]> records = new ArrayList<>();
                // Adding header record
                records.add(new String[]{"Download Speed", "Upload Speed", "Packet Rec", "Packet Sent", "Timestamp"});

                // Calculating initial value so only the last N parameters
                int initial = (int) (numitems - length);
                // For loop for last N parameters
                for (int i = initial; i < numitems; i++) {
                    records.add(new String[]{
                        String.valueOf(downspeed[i]),
                        String.valueOf(upspeed[i]),
                        String.valueOf(pacRec[i]),
                        String.valueOf(pacSent[i]),
                        String.valueOf(timestamp[i])
                    });

                    fetchArea.append(String.valueOf(timestamp[i]) + ", " +
                    String.valueOf(downspeed[i]) + ", " +
                    String.valueOf(upspeed[i]) + ", " +
                    String.valueOf(pacRec[i]) + ", " +
                    String.valueOf(pacSent[i]) + "\n");
                }
                // Writing the list to the destination chosen
                CSVWriter csvWriter = new CSVWriter(new FileWriter(filepath));
                csvWriter.writeAll(records); // Writing the records
                csvWriter.close(); // Closing the stream
                csvWriter.flush(); // Flushing the stream
            }

            // If the selected device is the Android device
            if (androidDevice.getSelectedItem().toString().equals("Android")) {
                // Getting N from GUI
                double length = Double.parseDouble(lastN.getText().toString());
                // Fetch all values from cloud database
                fetchRegressionValues(Android());
                // Make the list that contains the String arrays
                List<String> records = new ArrayList<>();
                // Adding header record
                records.add(new String[]{"Upload Speed", "Packet Received", "Packet Sent", "Download Speed", "Upload Speed", "Timestamp"});
            }
        } catch (Exception e) {
            // Handle exception
        }
    }
};
```
