The local monitoring server performs the following functions for both devices:

* Receive data through an input stream in a JSONObject using the accept() method
* Printing the values onto the graph based on the selection of the parameter fromSelection JComboBox
* If the "Push to Cloud" toggle is activated, a connection is made to the respective Cloudant database for the device and the values are pushed using the same principles explained in Section 4.4.8.6.
