* NetInterfaceConfig: Getting configuration information such as the hardware address, of the interface, passed.
The sig object is first used to retrieve a list of network interfaces present on the desktop PC via a loop. By iterating through the list, Listing 4.57 aims to identify the interface used for communication processes as download and upload. This is performed by comparing a String object, defined as "null", with the returned object from the getThwaddr() method which essentially returns the hardware address of the network interface. Therefore, an interface that is in use will not return "null". Moreover, since the process is ongoing, it is bounded by a loop set to true, which is an infinite loop.
