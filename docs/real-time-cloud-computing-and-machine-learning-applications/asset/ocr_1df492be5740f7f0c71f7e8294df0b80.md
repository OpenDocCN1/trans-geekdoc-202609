The kmeans function from MATLAB's Statistics and Machine Learning Toolbox can be used to perform K-Means clustering [14]. The syntax of the function is as follows:

```
[idx,C] = kmeans(X,k)
```

The inputs to the function are described below:

+   **X**: Data to be clustered.

+   **k**: Number of clusters.
