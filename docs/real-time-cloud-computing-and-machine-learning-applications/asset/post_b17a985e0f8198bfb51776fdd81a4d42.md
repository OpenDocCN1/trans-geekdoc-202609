### 5.3.7.3. Adding JavaScript Methods for index1.js

As mentioned previously, JavaScript caters for the display of values fetched from the servlet, as well as the latter to perform analytics. JavaScript codes are included in the "index1.js" file. Table 5.20 shows the methods defined:

# Table 5.20. Description of JavaScript methods for index1.js

| Methods | Description |
| :--- | :--- |
| classification(n) | Queries the servlet or localhost when the "Classify" button is pressed to return analytical values for KNN and MLP classification. |
| regression() | Queries the servlet or localhost when the "Predict" button is pressed to return analytical values for MLP and MLP regression. |
| window.onload | Is called as soon as the whole page loads, which denotes the start of the line graph that fetches the last set of values stored in the Cloudant or MySQL database, every five seconds. |
| refreshGraph() | Called when the parameter selection for the line graph is altered, such that the selected parameter is displayed on the graph. |
| downloadLast(N) | Queries the servlet or localhost when the "Download" button is clicked after entering a number of samples to be downloaded, to return a JSONObject containing a String parameter used to parse the .csv file. |
| downloadByDate() | Queries the servlet or localhost when the "Download" button is clicked after entering a specific date for samples to be downloaded. A .csv file with the returned encapsulated String parameter in the JSONObject. |

It should be noted that all the methods mentioned in Table 5.20 make use of the Fetch API, available in JavaScript, to query the servlet upon the clicking of the respective buttons.

The methods in Table 5.20, are elaborated and coded in the following steps:

- 1. The classification() and regression() methods called by the "Classify" and "Predict" buttons are built by Listing 5.55, where the Fetch API is used to query the servlet, or a local server such as Apache Tomcat [21], which can be set up on Eclipse itself. The response is obtained in a JSON object using the json() method. The particular results, as by the servlet are been retrieved into variables by specifying the String by which they are referred to, before printing the results on the page.

# Listing 5.55. Analytics methods for index1.js

```javascript
function classification() {
  // Setting a notice on the display box
  document.getElementById("withNC").value = "Please wait...";
  document.getElementById("withPC").value = "Please wait...";

  // Retrieving values from the page
  var downloadSpeed = document.getElementById("downloadSpeed").value;
  var uploadSpeed = document.getElementById("uploadSpeed").value;
  var packetsReceived = document.getElementById("packetsReceived").value;
  var packetsSent = document.getElementById("packetsSent").value;
  // Fetching the selected source from Cloud or Localhost
  var selectedSource = sourceSelection.options[sourceSelection.selectedIndex].innerHTML;
  // Fetching the ip address of the localhost if the toggle is selected
  var ipAddress = "" + document.getElementById("serverAddress").value;

  var query;
  // Selecting the source as "Cloudant database"
  if(selectedSource === "Cloudant database") {
    query = "https://networkcloud.eu-gb.bluemix.net/ml?downloadSpeed=" + downloadSpeed + "&uploadSpeed=" + uploadSpeed + "&packetsReceived=" + packetsReceived + "&packetsSent=" + packetsSent + "&predictionTime=10&windowSize=20&device=1&action=2&source=1";
  }
  // Selecting the source as "Local host"
  if(selectedSource === "Local host") {
    query = "http://" + ipAddress + ":8080/NetworkCloud/ml?downloadSpeed=" + downloadSpeed + "&uploadSpeed=" + uploadSpeed + "&packetsReceived=" + packetsReceived + "&packetsSent=" + packetsSent + "&predictionTime=10&windowSize=20&device=1&action=2&source=2";
  }
}

// Using the Fetch API to query the "networkCloudServlet"
fetch(query).then(function(response) {
  return response.json();
}).then(function(data) {
  console.log(data);
  // Fetching the variables from the JSON response
  var knnResult = data.knnClassification;
  console.log("KNN RESULT: " + knnResult);

  var mlpResult = data.mlpClassification;
  console.log("MLP RESULT: " + mlpResult);

  // Printing the variables on the page, in appropriate result boxes
  document.getElementById("withNC").value = knnResult;
  document.getElementById("withPC").value = mlpResult;
}).catch(function(error) {
  console.log("Error in retrieving");
});
```
