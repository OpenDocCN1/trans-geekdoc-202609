# 4.4.4. Adding Libraries

The building of this application is facilitated through the use of several libraries whose functionalities can be described as Table 4.6. Since "jar" files are used to import these libraries into the project, they first need to be downloaded. The download links are also included in the table.

# Table 4.6. Description and references of libraries used for desktop application

|---|---|---|---|--|
| Sigar | Using the Wi-Fi interface to get network provisions | [16] | [17] | sigar.jar |
| JFreeChart | Provision of a chart area whereby a live graph can be implemented with values added second | [18] | [19] | freechart-1.0.19-swt.jar freechart-1.0.19.jar common-1.0.23.jar |
| CloudantManager | Client-server interactions with the Cloudant database to either push or retrieve values | [11] | [12] | CloudantManager.jar |
