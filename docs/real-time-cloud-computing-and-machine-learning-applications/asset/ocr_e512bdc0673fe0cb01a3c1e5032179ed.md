# 4.4.2.3. Adding Components to JFrame

As mentioned before, the components integrated into this window are all added via the drag and drop facility available in Net itself, therefore not requiring intervention through code. The palette on the right side of the software is used to select Swing controls as depicted by the following steps.

+   1. Descriptive components are first added to the window. The "Label" tag is therefore dragged and dropped onto the JFrame area. It is then edited by being right-clicked as shown in Figure 4.52 to show "Download Speed."

![](bbox=[0.268, 0.503, 0.731, 0.765])

Figure 4.52. GUI components.

+   2. A "Text Field" component is then chosen from the components and added to the space next to the newly added label. The component is right-clicked as in the previous step with its contents cleared since this is the box that bears the parameters to be updated every second. Another label with the unit for the download speed is then added for convenience and presentation.
