# 4.3.7.1. Getting Speed Data

To find the download speed at a particular point in time, the number of currently downloaded bytes is used to subtract the previously stored number of bytes, which is preceded by exactly one second, as previously specified by the Handler, divided by the number of seconds. This is shown in Equation 4.1.

| Current number of bytes - Previous number of bytes |
| Download Speed = (kB/s) (4.1) |
| 1 second |

This means that to get any speed, it only suffices to subtract the previous number of bytes from the current one. With the appropriate conversion to kilobytes per second (KB/s) through a division by 1000 ms, the calculation of the speeds of four variables is performed the same way. These are the total download and upload speeds as well as the cellular/mobile download and upload speeds. Listing 4.23 gives the codes for these functions.
