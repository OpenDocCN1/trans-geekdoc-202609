# 4.4. DESKTOP APPLICATION FOR NETWORK DATA CAPTURE AND ANALYTICS

Along with the Android phone used as an edge device, the second machine used in this architecture for parameter monitoring is the desktop PC. It is one of the most popular devices on the planet and consists of an integral part of network monitoring with most data traffic involving a PC in networking systems.

As observed with the Android device, particular classes are used to retrieve network parameters. Likewise, for the desktop PC, network data is exploited exploited using the Sigar library available at [16]. The NetBeans IDE is used for designing this Java application whereby the integrated Swing Graphical User Interface (GUI) is firstly used to create the layout for the application.
