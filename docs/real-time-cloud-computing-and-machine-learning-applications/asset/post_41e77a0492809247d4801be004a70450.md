## 5.3.4.1. Getting Network Parameters from the URL

This is performed in the doGet() method whose functionalities are summarised as follows:

- Fetch the parameters from the URL.
- Convert the parameters into objects of type double.
- Convert the "device," "action" and "source" variables from int to String objects.
- Call the respective analytical methods, while having the same parameters defined in Section 5.1.5, as global variables.
- Send out the results from the analytics, as JSONObject objects, as a response, using a PrintWriter object to write on the page.
