4. Upon clicking on the “Finish” button, the application will be automatically built using Gradle, in turn producing 3 main files whose functions can be described as follows:

+   - MainActivity.java: It is the java class that contains the codes that cater for the operation of the application, i.e., the back-end of the program whereby the functionalities of the components involved are detailed.
- activity_main.xml: It is a plain text file that bears the structural definition and layout of the program such as the placement of components and their colours and indentations.
- AndroidManifest.xml: As well as specifying the name of the application, it acts as a unique identifier and is mainly concerned with the processes and permissions involved. This means that the particular permissions required to access protected parts of the Android API depending on the functionality of the application should be incorporated in this file.
