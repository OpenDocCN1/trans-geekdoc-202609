Gibb Sampling can be performed from the model's distribution because unbiased sample of $\langle v_{ij}h_j \rangle_{model}$ is complex to obtain [21]. Thus, the states of visible units are to a training vector to obtain a reconstruction, $\langle v_{ij}h_j \rangle_{recon}$, instead [21]. The learning rule therefore becomes:

```
$$\Delta w_{ij} = \alpha(\langle v_{ij}h_j \rangle_{data} - \langle v_{ij}h_j \rangle_{recon}) \quad (3.12)$
```

RBMs can be implemented in MATLAB using the package from [22]. The package contains a folder with the training set consisting of sample images, user-defined functions for implementing the RBM, and an image script for testing the RBM. The RBM aims to identify patterns in a dataset by reconstructing the inputs. The visible layer encodes the input into a set of numbers. This set of numbers is used to regenerate the input through the backward pass from the hidden layer to the visible layer [22].

At the start of the main script in Listing 3.10, the user-defined functions are added to the search path and the folder containing the training set is specified. The images in the training set are then set to equal sizes to improve the accuracy of the training process. The system is also simplified by converting the coloured photos to grayscale:
