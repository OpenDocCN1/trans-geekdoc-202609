# Cloud Computing Fundamentals

The project will have to import several API packages as summarized in Table 2.4.

# Table 2.4. Imports and corresponding classes required by the project

| Import | Purpose |
| --- | --- |
| java.util.* | This package provides access to a collection framework, collection classes, related to date and time, and miscellaneous utility classes [21]. |
| org.json.JSONObject | The package allows the implementation of JSON encoders and decoders [22]. |
| java.io.IOException | Used to handle errors due to input and output operations querying the database in the context of this project [23]. |
| com.cloudantclient.api.ClientBuilder | Provides access to the CloudBuilder class for creating the cloudant client instance [24]. |
| com.cloudantclient.api.CloudantClient | This import provides access to the CloudClient class which creates the main object used to gain access to the Cloudant APIs. Instances of CloudClient are created by calling the CloudBuilder class [24]. |
| com.cloudantclient.api.Database | This import provides the Database class which allows a Database object to be created using the client object and the database() method. |
| com.cloudantclient.api.query.Expression | Allows the Expression class to be imported which provides the eq() method used for checking the field which is equal to the one found in the query string by the client [26]. |
| com.cloudantclient.api.query.QueryBuilder | Imports the QueryBuilder class which is a helper for building query selector strings for specific queries to the cloudant database [27]. |
| com.cloudantclient.api.query.QueryResult | This import provides the QueryResult class which represents a single query result produced by an ExpressionEngine. This instance is obtained by calling the query method from the database object [28]. |
| com.cloudantclient.api.query.Selector | Imports the Selector that identifies all Operations and Expressions that can form the basis of a selector. In this program it will be used together with the eq() method [29]. |
| com.google.gson.Gson | Imports the Gson Java library that transforms Java Objects into a JSON format. The conversion from a JSON string to an equivalent Java object can be performed [30]. |
| java.net.URL | Imports the URL class which represents a representation of a Resource Locator (URL). In this case the URL will represent the URL of the cloudant database [31]. |
| java.util.List | Imports the List interface which represents a structured sequence of elements. The elements are accessed and searched via an index and can also be inserted and deleted. In this application it will be used to store the data retrieved from the database [32]. |
| javax.swing.* | Provides the GUI components such as the JButton, JLabel and JTextField that are required in this application. |
| Interface Map<X,Y> | An interface that creates an object which maps keys to values. X represents the type of keys maintained in the map and Y represents the type of the mapped values. In this application it will of type String and Y Object [33]. |
| public class HashMap<K,V> extends AbstractMap<K,V> implements Map<K,V>, | A Hash table based implementation of the Map interface with all available map options are provided by this class [34]. |
