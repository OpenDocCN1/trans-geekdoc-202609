# 4.3.11.3. Browse Button

This button performs the selection of a directory by the user, to store the .csv
file to be downloaded. It makes use of a method created, denoted as
showDirectoryPicker(), by firstly verifying the necessary permissions for reading and
writing to the external storage. The hasPermissions() method performs this check
in and turn triggers the directory chooser.

# Listing 4.44. Implementing browsing functionality

```
// Actions when the "Browse" button is clicked:
browseButton.setOnClickListener(new View.OnClickListener() {
@Override
public void onClick(View v) {
    // Creating an array to hold the required permissions as String objects:
    String[] PERMISSIONS = {
        android.Manifest.permission.READ_EXTERNAL_STORAGE,
        android.Manifest.permission.WRITE_EXTERNAL_STORAGE
    };
    // Checking if these permissions have been accepted:
    if (hasPermissions(Download.this, PERMISSIONS)) {
        // Calling the method that issues the directory selection:
        showDirectoryPicker();
    } else {
        // Presenting the user with the option to allow the necessary
        permissions if they have not been accepted:
        ContextCompat.requestPermissions(Download.this, PERMISSIONS,
        FOLDERPICKER_PERMISSIONS);
    }
}
});
```
