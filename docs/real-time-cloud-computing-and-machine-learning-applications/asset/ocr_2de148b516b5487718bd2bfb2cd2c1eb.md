For a Multiple Linear Regression model, the following steps are performed:

+   1. The design matrix $ar{X}$ is generated from the two-independent variables array with a column consisting of ones the Y-intercept according to the following equation:

```
$egin{pmatrix} y_1 \ y_2 \ y_3 \ \vdots \ y_n \end{pmatrix} = egin{pmatrix} 1 & x_{11} & x_{12} & \dots & x_{1n} \ 1 & x_{21} & x_{22} & \dots & x_{2n} \ 1 & x_{31} & x_{32} & \dots & x_{3n} \ \vdots & \vdots & \vdots & \ddots & \vdots \ 1 & x_{m1} & x_{m2} & \dots & x_{mn} \end{pmatrix} egin{pmatrix} eta_1 \ eta_2 \ eta_3 \ \vdots \ eta_n \end{pmatrix} + egin{pmatrix} \epsilon_1 \ \epsilon_2 \ \epsilon_3 \ \vdots \ \epsilon_n \end{pmatrix} (7.3)$
```

Where,

+   * $y_n$ - dependant variables
* $x_{mn}$ - independent variables
* $eta_n$ regression coefficient
* $\epsilon_n$ - error term

+   2. The response array, $y$, is created from the second independent variable (double [] var2).

+   3. An OLMMultipleLinearRegression model is created using the design matrix $ar{X}$ and output vector $y$.

+   4. The regression coefficient is calculated using the least square solution, evaluated using the QR-decomposition as the following equation [1]:

```
$eta = (X^T X)^{-1}(X^T y) = ((QR)^T (QR))^{-1}((QR)^T y) = (Q^T R^T Q R)^{-1}(Q^T R^T y) = (R^T R)^{-1}Q^T Q^T R^T y = R^{-1}Q^T y$ (7.4)$
```

Where,

+   * Q - Orthogonal Matrix of X
* R - Upper Triangular Matrix of X
* X - Design Matrix
* y - Output vector

+   5. The values of each independent variables, $Vx_t$, at time interval $t+n-1$ is obtained using a simple linear regression model.
