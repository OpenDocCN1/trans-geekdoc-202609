The steps below are followed to place components from the editor onto the XML file to render its appearance as in Figure 4.10. Each component is given a specific "id", which acts as a unique identifier when referencing it in the MainActivity.java class.

+   1. With the project being created automatically using a layout constraint, the latter is modified to a linear layout since components can then be organised in either a horizontal or vertical fashion. This means that each component automatically aligns below the previous one if the linear layout is set to a vertical. The modified snippet for the layout is in Listing 4.3, with the orientation defined as vertical.

# Listing 4.3. Setting layout to linear and vertical for the Network Monitor Menu

```
<xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    xmlns:tools="http://schemas.android.com/tools"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    tools:context=".MainActivity">
</LinearLayout>
```

2. A "Text" component is first selected from the palette and dropped onto the screen layout. It will automatically stick to the top of the area, being the first added component. The XML codes representing this text component are detailed in Listing 4.4.

# Listing 4.4. Adding an "EditText" component to XML file

```
<EditText
    android:id="@id/EditText1"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:ems="10"
    android:hint="Enter IP address:"
    android:inputType="textPersonName" />
```

The "hint" represents a sort of guide for the user to know what to enter in the particular field. It disappears as soon as the user starts typing. The palette area after adding Listing 4.4, is as shown in Figure 4.15.
