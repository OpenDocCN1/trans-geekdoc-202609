# 6.3.24.1. onCreate() Method

The onCreate method is invoked when the activity is first launched. It is responsible for initializing the global variables and setting the listeners for the buttons. The codes for the onCreate method are given in 6.14.

# Listing 6.14. DownloadData class onCreate Method
