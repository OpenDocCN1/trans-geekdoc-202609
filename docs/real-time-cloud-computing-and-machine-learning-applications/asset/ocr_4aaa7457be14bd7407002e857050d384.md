# 7.1.5.4. The insertIntoDatabase() Method

This method is used to insert a new record in the local database. It accepts input a JSONObject coming from the edge device. The individual parameters from the JSONObject are extracted from the insert query. To insert a new record, the following steps are:

+   - The weather parameters are extracted.
- A statement is created from the Connection object
- A query to insert the data is formed and executed using the executeUpdate() method.
