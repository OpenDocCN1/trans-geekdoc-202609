## 5.1.8.5. 将 Android 值上传到云端

Android 网络监控包括来自 Wi-Fi 和移动数据服务的下载和上传参数。反，如果手机被用于注册移动数据值，则需要关闭手机的 Wi-Fi 服务。结果是为了连接到本地服务器，无法简单使用本地网关的 IP 地址来路由从 Android 手机到本地服务器的流量。
