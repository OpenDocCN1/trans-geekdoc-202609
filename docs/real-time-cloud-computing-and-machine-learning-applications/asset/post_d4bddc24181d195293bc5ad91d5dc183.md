## 7.5. TESTING THE WEB CLIENT

This section shows a captures of the expected operations of the web client application.

### 7.5.1. Live Monitoring

1. When the application is launched, the screen in Figure 7.49 is shown to the user.
2. To connect to the Java Servlet hosted on the cloud platform, the user must choose "Cloudant Server" in the Data Source dropdown menu. This ensures that analytics results, weather observations, and graph values are updated using the cloud-hosted servlet as the endpoint.
3. The user also has the option to connect to a Servlet hosted on a Local Machine. To connect to that Servlet, the user has to put the global IP address of the machine on which the servlet is hosted and choose “Local Server” from the Data Source dropdown.

![](img/2b52fde0e707e8c2f05a10309c3f8982_793_0.png)

Figure 7.49. Webpage displayed to Users.

4. To start monitoring the weather condition, choose a weather parameter from the Combo Box. A graph will be shown with the readings updating.

![](img/2b52fde0e707e8c2f05a10309c3f8982_793_1.png)

Figure 7.50. Graph Updating.

### 7.5.2. Downloading Weather Data

1. To download the last N weather samples, first, the number of samples is entered in the “Download Last N data” TextBox. Then, the “Download” button is pressed. The webpage will contact the “Downloader” servlet for a CSV file. After the server returns the CSV file, the user can download it.

2. To download weather observation for a specific date, the required data is entered in the “Download Data for:” TextBox as shown in Figure 7.53. Then, the “Download” button is pressed. The webpage will contact the servlet for a CSV file. After the server returns the CSV file, the user can download it as shown in Figure 7.54.
