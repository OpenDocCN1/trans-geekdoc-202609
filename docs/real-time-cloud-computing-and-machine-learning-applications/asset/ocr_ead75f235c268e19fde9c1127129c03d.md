The Desktop Application makes use of a single Java class, named netmonitor.java, whose methods can be described in Table 4.4.

# Table 4.4. Complete program structure for netmonitor.java

| Methods | Description |
| --- | --- |
| netmonitor() | Is the constructor of the class that initialises all components onto the GUI and calls the createGraphSpace() method which programmatically adds the graph to it. |
| createGraphSpace() | Allocates space for the graph on the GUI by adding a chart onto the canvas amounts the existing JFrame using the JFreeChart class. |
| getNumberOfItems(Thread) | Retrieves the list of records stored from the Cloudant database before pushing values so that they can be entered in an orderly fashion. Uses the CloudClient and Database objects. |
| startMonitoringActionPerformed() | Starts the parameter fetching process as well as pushing to the server or the Cloudant database on active radio buttons. |
| stopMonitoringActionPerformed() | Makes of the Thread object. |
| parameterSelectionActionPerformed() | Clears the drop-down menu for parameter selection is altered. |
| predictButtonActionPerformed() | Requests data from the servlet by taking the parameters entered by the user on the GUI for local prediction using a URLConnection. Also creates a thread for local prediction that connects the local server running on PC using an IP address from the GUI. |
| classifyButtonActionPerformed() | Requests data from the servlet by making a URL involving current network parameters for classification. Also performs local classification using a Socket client-server mechanism with the local server. |
| initialFields() | Printing values onto the console and updating GUI when the application is first started. |
| setFields() | Updating the GUI every second using the fetched parameters. |
| explorerchooserActionPerformed() | Gets the path of the selected directory upon opening the explorer frame. |
| browseButtonActionPerformed() | Opens the explorer frame bearing the file chooser. |
| downloadActionPerformed() | Fetches all the parameters from the cloud and saves the "N" number of records using the OpenCSV library. |
| downloadDateActionPerformed() | Fetches all the parameters from the cloud and saves the specific date entered on the GUI by the user, using the OpenCSV library. |
| fetchRegressionValuesPC() | Connects to the Cloudant database using the CloudClient object to fill series arrays of type double bearing PC values and their timestamps.
