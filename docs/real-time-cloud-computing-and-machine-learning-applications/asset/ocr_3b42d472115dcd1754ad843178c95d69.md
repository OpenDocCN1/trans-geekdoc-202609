# SERVER AND SERVLET ARCHITECTURES
FOR A CLOUD-BASED REAL-TIME WEATHER
FORECASTING SYSTEM

This chapter discusses the architectures for a local java server and java servlet hosted on the cloud for real-time weather forecasting. Section 7 discusses the local java server implementation for weather data capture and forecasting. It also explains the implementation of machine learning algorithms for weather forecasting along with an example including regression for forecasting. Testing of the local server is discussed in section 7.2. The servlet program for weather forecasting and data retrieval is discussed in section 7.3. Section 7.4 discusses the web application for weather forecasting analytics and data download. Finally, Section 7.5 discusses the testing of the servlet program and web application hosted on the cloud for weather forecasting and data retrieval.

# 7.1. LOCAL SERVER IMPLEMENTATION FOR WEATHER
DATA CAPTURE AND FORECASTING

In this section, a Local Server is developed in Java which captures data coming from the edge device (android device), displays the reading specified in real-time, and makes use of four machine learning algorithms for forecasting future weather conditions. The application is developed in NetBeans IDE which supports a drag-and-drop feature for building GUIs. The algorithms used for prediction are as follows:

+   - Multiple Linear Regression
- Polynomial Regression
- Multilayer Perceptron
- Convolution Neural Network
