# Listing 7.14. MinMax-Normalizer

```java
package NeuralNetwork;

import java.util.Arrays;

public class MinMaxNorm {
    // 2D array to store values
    private final float[][] data_o;
    //Array to store minimum & maximum value of each column
    private float[] min, max;

    /**
     * Main Constructor that accepts a 2D array and finds the minimum
     * & maximum of each column
     * @param data_o 2D array to be normalized
     */
    public MinMaxNorm(float[][] data_o) {
        // gets the number of columns
        int col = data_o[0].length;
        this.data_o = data_o;
        // creates a minimum & maximum array the same size as the number of columns
        this.min = new float[col];
        this.max = new float[col];
        //Sorts the array and finds the minimum and maximum value for each column
        for (int i = 0; i < col; i++) {
            //fetch a specific column
            float[] col_n = DataSetIterator.Col(data_o, i);
            // sorts in ascending order
            Arrays.sort(col_n);
            //gets min value - first
            min[i] = col_n[0];
            //gets max value - last
            max[i] = col_n[col_n.length - 1];
        }
    }

    /**
     * Normalises the 2D array using the min-max method
     * @return a 2D array normalized of normalized value
     */
    public float[][] normalize() {
        // gets the number of column and from the original array
        int col = data_o[0].length;
        int row = data_o.length;
        //creates a new array to store the normalized value
        float[][] normalized = new float[row][col];
        //normalize every column in the array
        for (int i = 0; i < row; i++) {
          for (int j = 0; j < col; j++) {
            normalized[i][j] = (data_o[i][j] - min[j]) / (max[j] - min[j]);
          }
        }
        //returns the normalized value
        return normalized;
    }

    /**
     * Denormalizes an array of values
     * @param norm array of the normalized value
     * @return float array-denormalized of denormalized value.
     */
    public float[] denormalize(float[] norm) {
      int col = norm.length;
      //create an array to store denormalized
      float[] denormalized = new float[col];
      //denormalizes each value
      for (int i = 0; i < col; i++) {
        denormalized[i] = (norm[i] * (max[i] - min[i])) + min[i];
      }
      //returns denormalized value
      return denormalized;
    }

    /**
     * Denormalizes a single value given the variable index
     * @param norm normalized value
     * @param var index of min & max value
     * @return denormalized value
     */
    public float denormalize(float norm, int var) {
      //returns denormalized value
      return (norm * (max[var] - min[var])) + min[var];
    }
}
```

For predicting multiple timesteps, the multiple output strategy is used. This is a supervised learning method instead of predicting a single output as compared to normal regression, involves developing one model that is capable of outputting multiple variables for each prediction. In the case of predicting the temperature for the next N minutes, the model is developed and is used to predict the next two days as one operation as:

```
$Pred_{t+1},Pred_{t+2} = model(O_{t-1}, O_{t-2}, \dots, O_{t-n})$
```

Where,

- $Pred_{t+1}$ - prediction at $t = t + 1$
- $Pred_{t+2}$ - prediction at $t = t + 2$
- $O_{t-1}$ - observation at time $t = t + 1$
- $O_{t-n}$ - observation at time $t = t + n$

Multiple output models are more complex as they can learn the structure between inputs and outputs as well as outputs. Being more complex may mean that they are slower to train and require more data to avoid overfitting the problem. To train such a model, the input data needs to be formatted in the appropriate format. The following shows an example where the next two temperature values are predicted using the previous six readings of the data in Table 7.14.
