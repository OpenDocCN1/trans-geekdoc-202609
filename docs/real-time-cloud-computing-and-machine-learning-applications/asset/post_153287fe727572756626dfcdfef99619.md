5. This step involves adding the space for the graph and the parameter selection, known as the spinner. The purpose of this live monitoring graph is to provide the user with a view of the variations of the parameters being calculated since previous records are also displayed on the graph, as opposed to changing values in the TextView fields. These values are key to the analytics that have been carried out since they show major changes after activities performed by the user. The graph can be added to the activity_main.xml file, using the com.github.mikephil.charting.charts.LineChart now available with the previously added AndroidChart library [10], as shown in Section 4.3.2. The dimensions and placement are also specified and can be adjusted by preference. A Spinner object, which relates to the selection of the attribute to be displayed by the graph, is also invoked.
