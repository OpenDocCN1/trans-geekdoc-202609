# Short-hand Example 2

In this example, Hierarchical clustering with the single linkage method is used to group a set of 6 cars into 2 clusters based on their weights and miles. The weights and miles of the cars are given in Table 3.8:

# Table 3.8. Hierarchical clustering- Car details

| Car | Weight (Pounds) | Mileage (Miles per Gallon) |
|---|---|---|
| A | 1835 | 26 |
| B | 3600 | 15 |
| C | 2372 | 24 |
| D | 3086 | 14 |
| E | 3504 | 18 |
| F | 1970 | 31 |

Initially, each car is considered to be part of its own cluster. In this example, a cluster pooling of cars A, B and C will be labelled as $C_{ABC}$. The distances between the clusters are calculated using the Euclidean distances between the data element. For example, the Euclidean distance between clusters $C_A$ and $C_B$ is calculated as:

```
$d(C_A, C_B) = \sqrt{(1835 - 4341)^2 + (26 - 15)^2} = 2506.0$
```
