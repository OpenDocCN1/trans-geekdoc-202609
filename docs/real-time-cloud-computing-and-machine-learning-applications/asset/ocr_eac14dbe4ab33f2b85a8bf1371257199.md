# 7.1.4.4. The w_varActionPerformed() Method

The variable being on the graph can be changed by selecting another variable in the JComboBox. The w_varActionPerformed() method is bounded to the JComboBox. In the method, after the user has selected a new item, a check is performed to know whether a new item has been selected and so, the following actions are performed:

+   - The value of the parameter is updated with the new value
- The XYSeries is cleared of any data
- The counter is reset to zero
- The key for the XYSeries is set to the new parameter
- The chart is informed of change with the fireChartChanged() method.
