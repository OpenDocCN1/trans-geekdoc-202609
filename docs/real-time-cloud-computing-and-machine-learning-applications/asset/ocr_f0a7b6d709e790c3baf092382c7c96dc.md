The SARSA-learning agent is created using the codes given in Listing 3.49. The agent’s options are specified in rlSARSAAgentOptions object. # Listing 3.49. SARSA– Create SARSA agent object

```
agentOpts = rlSARSAAgentOptions; % Create rlSARSAAgentOptions object

sarsaAgent = rlSARSAAgent(qRepresentation,agentOpts); % Create SARSA-learning
agent
```
