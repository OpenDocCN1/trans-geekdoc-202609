# 6.2.3. Mobile and Desktop Application

This block represents the mobile and desktop application responsible for collecting data from the OpenWeather API and sending it to either the Cloudant database or a local server. The local server stores the data in a MySQL database. The mobile and desktop applications can also request data for download from either the local server or directly from the Cloudant database. The mobile client is explained in detail in Section 6.4 and the desktop application is explained in detail in Section 6.3.

# 6.2.4. Cloudant Database

The Cloudant database is a service offered by the IBM cloud platform. It is used in the system to store weather data in the cloud so that the data is accessible globally. Section 6.6 describes how to set up the Cloudant database. Section 6.3.30 to 6.3.33 describes the “DataRetriever” class which is responsible for communicating with the Cloudant database.

# 6.2.5. Cloud Hosted Servlet

The cloud-hosted servlet main function is to serve requests coming from users that visit the webpage. The servlet is responsible for the following functions:

+   1. Updating the live graph on the webpage presented to the user
2. Serving requested weather data to the user by fetching data from the Cloudant database
3. Performing analytics and returning the result to the user.

More information is given in section 7.4 of chapter 7 that details how the servlet works.
