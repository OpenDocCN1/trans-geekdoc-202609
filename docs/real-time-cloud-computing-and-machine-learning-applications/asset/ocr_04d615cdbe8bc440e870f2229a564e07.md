Finally, Layer 4 the hardware layer consists of the actual hardware resources. For both a public or private cloud, a data center can be used in the back end.

A data center, is typically a large group of interconnected hardware components such as storage racks, CPUs, memories and servers. It can be present at a predefined place or reside on a high configuration system.

There are several enabler of cloud computing. The main enabling technologies are described as follows:

+   (i) Virtualisation The primary function of virtualization is to enable cloud service providers to reduce the amount of actual hardware and even software resources required. Virtualization tools consist of virtual machine technologies for e.g. VMware and Xen, and virtual networks, such as VPN. Virtualisation can take several forms such as application virtualization, desktop virtualization, storage virtualization, server virtualization and network virtualization [5, 6, 7].

+   (ii) Web Service, Service Oriented Architecture (SOA) and Service Oriented Computing (SOC) – Web Services and SOA represent the base technologies for cloud computing. Cloud services are typically designed as Web services, which follow industry standards including Web Services Description Language (WSDL), Simple Object Access Protocol (SOAP), Universal Description Discovery and Integration (UDDI). The SOA organizes manages Web services within clouds and also provide a series of cloud services, which can be accessed from distributed platforms. To develop interoperable distributed applications quickly at minimum costs in varying environments, these services are utilized by the Service-Oriented Computing (SOC) paradigm. It is possible to combine various protocols and specifications of platform-independent components using the SOC paradigm in which self-sufficient services are present. The creation collaborating services that are combined in a flexible way is made possible with SOC. Moreover, on heterogeneous computing platforms, these services can further be used to produce scalable business applications and responsive applications. SOC leverages on the services architectural model of SOC [5, 6, 7].

+   (iii) Multi-Tenancy – In computing, multi-tenancy is a process by which different customers from around the world can independently access the same computing services provided by a cloud operator. Although the customers share the same cloud resources, their data and operations performed on the cloud are kept confidential and distinct from each other. Cloud computing is rendered much more practical with the multi-tenancy as cloud operators have to handle a single infrastructure for multiple customers. This is a common feature in public computing providing IaaS, PaaS and SaaS [5, 6, 7].
