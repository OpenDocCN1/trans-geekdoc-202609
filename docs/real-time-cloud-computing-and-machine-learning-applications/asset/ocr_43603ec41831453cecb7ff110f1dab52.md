Then, a connection to the “weather_data” database is opening using the **connect ()** method of the Cloudant Client. This method takes a String representing the database name and a boolean for create flag that creates the database in the case does not exist. The create flag is set to false in this case since the database has already been created.

A query to fetch all the data in the database is then formed. The results are then sorted in descending order to find the latest data. The value of id is fetched for the latest data and is incremented by one for the next data to be added. To save the data to the database, the JSONObject is converted to a Map Object first where each key has a value. This is done by the **Gson** class which allows the conversion of a **JSONObject** to a **HashMap**. The **save (Object data)** method is called passing the HashMap as argument and then the connection is shut down by calling the **shutdown ()** method.

If the data is needed to be sent to a local server, the IP address of the server is first fetched by getting the text from the **IP_address** EditText by calling the **getText ()** method and chaining the toString() method to get the String value of the data entered. After getting the IP address, a socket is open to that address on port 6000 and the data is sent using a **PrintWriter**. After sending the data, the socket is closed.
