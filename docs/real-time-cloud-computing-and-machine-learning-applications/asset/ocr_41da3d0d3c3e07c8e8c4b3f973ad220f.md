public Object[][] fetchLastN(int N) {
    double[] result = new double[N][7];
    String[][] timestamps = new String[N];

    try {
        //Creates a Statement object from mysqlconnector library for sending SQL
        //statements to the database.
        Statement stmt = conn.createStatement();
        //Executes the given SQL statement, which returns a single ResultSet object.
        ResultSet resultSet = stmt.executeQuery("SELECT * FROM weather_params ORDER BY id DESC LIMIT " + N + ");

        // Iterate through the ResultSet and fill the array from the end since the data
        // is in reversed order
        int j = N - 1;
        //While resultset.hasRecord() ...
        while (resultSet.next()) {
            timestamps[j] = resultSet.getString(2);
            //fetches the weather parameters starting from column 3 and store them in
            a column in result
            for (int i = 0; i < 7; i++) {
                result[j][i] = resultSet.getDouble(i + 3);
            }
            j--;
        }
    } catch (SQLException ex) {
        Logger.getLogger(SQLConnector.class.getName()).log(Level.SEVERE, null, ex);
        //Creates an array to return multiple types of arrays into a single array
        return new Object[][]{timestamps, result};
    }

7.1.5.3. The fetchForDate () Method
This method is used to fetch all the records for a specific date from the local database. The following steps are carried out to the last N records:

+   - A Statement object for sending SQL statements to the database is created.
- A query to select all the records for a specific date is formed and executed to obtain a result set
- The result set is iterated once to get the size of the result set to initialize the arrays.
- The query is re-executed and the data is stored in the appropriate arrays.
