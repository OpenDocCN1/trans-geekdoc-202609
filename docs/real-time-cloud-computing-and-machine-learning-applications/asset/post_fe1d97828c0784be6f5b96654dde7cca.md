# 2.7. INTRODUCTION TO IBM CLOUD PLATFORM

The IBM Cloud is a public cloud platform built on Cloud Foundry open source technology with a fully loaded stack consisting of several products in its catalog. Several services and solutions such as the conventional computing, storage and network services are included in it. Moreover, it provides end-to-end application development frameworks, facilities to set-ups and ease deployment, management services for security, databases which can be either or conventional, and cloud-native services. It also simplifies application development with Platform as a Service (PaaS) and offers integrated Mobile Back end as a Service (MaaS) potential. To make internal development easily scalable, services that are available for direct usage along with hosting functionalities are provided so that applications can be quickly deployed. More details on the architecture and characteristics of this cloud platform can be obtained from [19] and [20].

In this section the focus will be on developing mobile and desktop applications that can send and receive data to the IBM Cloud database as well as send queries and receive responses from a servlet hosted on the IBM Cloud.
