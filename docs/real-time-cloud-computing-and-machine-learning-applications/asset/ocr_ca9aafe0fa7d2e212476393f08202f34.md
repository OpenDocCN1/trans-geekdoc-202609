The architecture of the MLP used in this example is given in Figure 3.20 [39]:

| Input Layer | Hidden Layer 1 | Hidden Layer 2 | Output Layer |
| --- | --- | --- | --- |
| x1 | w1 | Σ | T | γ |
| x2 | w2 | | |

Figure 3.20. Multi-layered Perceptrons example's architecture.

Initially, the connection weights $w_1$ and $w_2$ are both randomly set to 0.8. Each row from the truth table is considered as one dataset for training the MLP. The first dataset ($x_1=0$ and $x_2=0$) is fed to the MLP. The neuron in the first hidden layer performs the following calculation:

```
$\Sigma = x_1w_1 + x_2w_2 = (0)(0.8) + (0)(0.8) = 0$
```

The value of $\Sigma$ is fed to the second hidden layer which compares it to an activation threshold that is equal to 0.5 in this example. If $\Sigma$ is above 0.5, the neuron in the second layer, called the activation neuron, outputs a '1' to the output layer. Otherwise, it outputs a '0'.
For the above calculated $\Sigma$, the activation neuron sends a '0' to the output layer because $\Sigma$ is less than 0.5. Therefore, there is no weight update required because the predicted output is similar to the expected output.

The second dataset ($x_1=0$ and $x_2=1$) is fed to the MLP and $\Sigma$ is calculated:

```
$\Sigma = x_1w_1 + x_2w_2 = (0)(0.8) + (1)(0.8) = 0.8$
```

As $\Sigma$ is above 0.5, the activation neuron sends a '1' to the output layer which is an incorrect output for this dataset. Hence a weight update is required. The error is calculated as follows:

```
$\epsilon = 	ext{expected output} - 	ext{predicted output} = 0 - 1 = -1$
```
