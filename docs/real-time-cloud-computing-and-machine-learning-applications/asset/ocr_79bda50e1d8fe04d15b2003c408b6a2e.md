# Introduction

Reinforcement learning, deep learning and neural networks are some of the machine learning algorithms used in AI systems [14].

Machine learning, which allows machines to learn from previous data or processes without the need of explicit programming, is in turn a subfield of artificial intelligence. Machine Learning is a modeling technique that infers data or more precisely it the "model" out of "data." Information such as documents, audio, images, etc., are considered to be data elements in this case. The final outcome of Machine Learning is the "model." Machine learning provides a computer system with the ability to predict and be involved in decision making processes using past data. The need for explicit programming is also eliminated altogether. In order to produce results and predictions with high accuracy, a large amount of structured and semi-structured data are required by machine learning [15, 16].

# 1.2.1. Benefits of Machine Learning and AI

+   i. Autonomous operation – With ML and AI, applications and projects don't need to be provided instructions stepwise and constantly. Since machines are equipped with the ability to learn, they can independently make predictions and adapt their algorithms to new situations. A common example of this is anti-virus softwares; they learn to filter new threats as they are recognized. ML is also good at recognizing spam.

+   ii. Error reduction and continuous enhancement – Computers do not make mistakes if they are programmed properly. With ML and AI, the decisions are taken from the previously gathered information applying a certain set of algorithms. Errors are reduced and there is a higher probability of obtaining better accuracy. Moreover, as algorithms gain experience, they can make better decisions. For example in a weather forecasting model, as the amount of data increases, the algorithms learn to make more accurate predictions faster.
