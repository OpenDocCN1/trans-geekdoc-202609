Physical layer signal processing – The signal processing blocks of a mobile communication system includes several components such as modulation, channel coding, channel estimation, equalization, Orthogonal Frequency Division Multiplexing (OFDM) and Multiple Input Output (MIMO) based antenna diversity schemes. ML algorithms as Deep Neural Networks (DNN), Convolutional Neural Networks (CNN) and Recurrent Neural Networks (RNN) can be effectively employed to enhance the encoding and decoding of codes such as Polar codes and Low Density Parity Check codes in 5G systems. Additionally, supervised learning schemes can be used to enhance MIMO detectors, Neural Networks can effectively be employed in channel equalization and reinforcement learning can be used in adaptive modulation and coding [27].

+   b) Coverage and capacity enhancement – To enhance the coverage and data rates, the application of machine learning in beam-forming, has become a crucial technique adopted by next generation communication systems. Multiple beams are generated simultaneously by a base station with multiple antennas [28, 29]. Since the quality of a beam serving a user can degrade, another beam from the same BS or a neighboring BS that can also serve the user, has to be chosen. The selection of the best beam to serve the user can be made using machine learning. In order to minimize the energy consumption and interference levels, machine learning algorithms can also adaptively enable or disable the beams based on traffic profiles and subscriber profiles. Machine learning coupled with data analytics and holographic beam forming [30] can extend the coverage as per requirements to enable the use of different usage patterns by performing adaptive traffic redirection and allowing dynamic access to adjacent cells.

Massive MIMO is an important technique in 5G communications. For massive MIMO channels, the beam-forming mechanism must satisfy two conditions. Firstly it should adapt to the cell user distribution and secondly maintain the interference from broadcast channels of adjacent cells, to a minimum. When these two conditions are met, the communication system is able to obtain maximum benefits from massive MIMO sites, satisfy the coverage requirements and optimize the user experience.

A crucial factor that controls the beam-forming effect for a massive MIMO site is the weight setting. The weight setting of the massive MIMO site has a significant impact on enhancing coverage quality and efficiency in different coverage areas and scenarios.
