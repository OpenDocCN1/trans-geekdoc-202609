## 4.3.5. Retrieving the Last Index from the Cloud

After pushing data to the cloud directly using the switch, data must be sorted one after the other with respect to time. This is why a "Key" needs to be added to the data being registered, i.e., in a JSONObject, before it is pushed to the cloud. This is however depicted later in the documentation, in Section 4.5.2. Since the Cloudant database might already contain values before the data is pushed, the "Key" value should be retrieved prior to sending the next value to the database. The successive parameters be indexed with the successive value of the "Key." To do so, a thread is created in MainActivity.java with the following functions:

- Make a connection to the Cloudant database.
- Use a String object to specify a query to the database in MongoDB.
- Retrieve the "Key" values in descending order so that the first result bears the last index which is also the number of items in the database.
