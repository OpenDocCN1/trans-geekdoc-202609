## 7.3.3. Creating a Dynamic Project

To create a web project in Eclipse, the following steps are followed:

- 1. The application is launched and clicking "File" then "New" then choose "Dynamic Project".
- 2. A new window will pop up with the project name and the "Target Runtime" can be set as shown in Figure.
- 3. After creating the dynamic web project, the necessary folders will be created automatically.
- 4. To import the libraries into the project, open the project properties by clicking "Alt + Enter". Then, click on "Java Build Path" and click on "Libraries" tab. The window will pop up.
- 5. Click on "Add External Libraries" as shown in and locate the libraries that are needed and add them to the project. The process and download link of the libraries are already explained in section 7.1.2. After importing the libraries, click on the "Order and Export" tab and select all and click "Apply.". Then, click on "Apply and Close" to apply the changes and close the window.
