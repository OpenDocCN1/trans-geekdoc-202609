
# Short-hand Example 11

The Q-Learning short-hand example is repeated using SARSA. SARSA is used to train a SARSA agent to find the best state transitions with the highest rewards to a goal state. The environment is a 1×4 grid world as follows:

| W | X | Y | Z |
|---|---|---|---|
| | | | |

The rules used in the short-hand example for Q-Learning are kept unchanged in this example:

- 1. The agent is initially placed in cell W.
- 2. The two possible actions which the agent can take are to move forward or move backwards.
- 3. Moving forward takes the agent to one cell to the right.
- 4. Moving backwards takes the agent back to cell W.

The results which are unknown to the agent as follows:

- 1. A +10 reward is given if cell Z is reached.
- 2. A +1 reward is given if the agent returns to cell W from any other cell.

The experiment is terminated in the following scenarios:

- 1. If the agent obtains any of the 2 available rewards.
- 2. If the agent tries to move backwards from cell W.
- 3. If the agent moves forward from cell Z.

Initially, all cells in the Q-table are initialized with a zero value:

| Action/ State | W | X | Y | Z |
|---|---|---|---|---|
| FORWARD (F) | 0 | 0 | 0 | 0 |
| BACKWARD (B) | 0 | 0 | 0 | 0 |

To train the SARSA agent a series of training episodes in which the agent is allowed to take random actions to update the Q-table described below. The discount rate is set to 0.9 and the learning rate is set to 0.2.

The agent is represented by a ball, the next randomly chosen state is represented by a blue arrow and any reward obtained from the next state is indicated on the arrow.

# Episode 1:

| W | X | Y | Z |
|---|---|---|---|
| | 🟡 | | |
| W | X | Y | Z |
| | 🟡 | | |
| W | X | Y | Z |
| | | | |

At the instance where the agent was in state $X$ (i.e., $s_t = X$), going backwards (i.e., $a_t = B$), the reward obtained was +1 (i.e., $r_{t+1} = 1$). The next state was W (i.e., $s_{t+1} = W$) where the agent moved backwards again (i.e., $a_{t+1} = B$). After this episode, the Q-value, $Q(X,B)$, can therefore be updated using equation (3.25):

```
$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha[r_{t+1} + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t)]$
$Q(X,B) \leftarrow Q(X,B) + \alpha[r_{t+1} + \gamma Q(W,B) - Q(X,B)]$
$Q(X,B) = 0 + 0.2[1+(0.9 \times 0) - 0] = +0.2$
```

The updated Q-table is follows:

| Action/State | W | X | Y | Z |
|---|---|---|---|---|
| FORWARD (F) | 0 | 0 | 0 | 0 |
| BACKWARD (B) | 0 | +0.2 | 0 | 0 |

# Episode 2:

| W | X | Y | Z |
|---|---|---|---|
| | 🟡 | | |
| W | X | Y | Z |
| | | 🟡 | | |
| W | X | Y | Z |
| | 🟡 | | |
| W | X | Y | Z |
| | 🟡 | | |

After this episode, $Q(Y, B)$, can be updated:

$Q(Y,B) \leftarrow Q(Y,B) + \alpha[R_{t+1} + \gamma Q(W,B) - Q(Y,B)]$
$Q(Y,B) = 0 + 0.2[1 + (0.9 \times 0)] = +0.2$

The updated Q-table is as follows:

| Action/State | W | X | Y | Z |
|---|---|---|---|---|
| FORWARD (F) | 0 | 0 | 0 | 0 |
| BACKWARD (B) | 0 | +0.2 | +0.2 | 0 |

After this episode, $Q(Y, B)$, can be updated:

$Q(Y,F) \leftarrow Q(Y,F) + \alpha[R_{t+1} + \gamma Q(Z,F) - Q(Y,F)]$
$Q(Y,F) = 0 + 0.2[10 + (0.9 \times 0) - 0] = +2.0$

The updated Q-table is as follows:

| Action/State | W | X | Y | Z |
|---|---|---|---|---|
| FORWARD (F) | 0 | 0 | +2 | 0 |
| BACKWARD (B) | 0 | +0.2 | +0.2 | 0 |

# Episode 4:

| W | X | Y | Z |
|---|---|---|---|
| | 🟠 | | | |
| W | X | Y | Z |
| | 🟠 | | | |
| W | X | Y | Z |
| | | | +10 |

After this episode, the Q-value, $Q(X,F)$, can be updated:

```
$Q(X,F) \leftarrow Q(X,F) + \alpha[R_{t+1} + \gamma Q(Y,F) - Q(X,F)]$
$Q(X,F) = 0 + 0.2[0 + (0.9 \times 2) - 0] = +0.36$
```

The updated Q-table is as follows:

| Action/State | W | X | Y | Z |
|---|---|---|---|---|
| FORWARD (F) | 0 | +0.36 | +1 | 0 |
| BACKWARD (B) | 0 | +0.2 | +0.2 | 0 |

$Q(X,F) = 0 + 0.2[0 + (0.9 \times 0.36) - 0] = +0.072$
