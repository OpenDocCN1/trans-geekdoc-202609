# 4.4.8.3. Getting Initial Parameters

After identifying the currently communicating interface, the computations for fetching network data can be inserted in this specific statement. The NetInterface object, netStat is used along with the following methods:

+   * getRxBytes(): Returns the number of bytes received at the current time.
* getTxBytes(): Returns the number of bytes sent at the current time.
* getRxPackets(): Returns the number of packets received at the current time.
* getTxPackets(): Returns the number of packets sent at the current time.

These parameters are obtained using the same subtraction principles from the implementation on Android Studio whereby at a particular point in time, the number of data is retrieved using the above methods. The thread is paused for one second, after which the methods are called to get the amount of data one second later. The change can therefore be calculated. The below snippet, Listing 4.58 depicts how this operation takes place.

# Listing 4.58. Retrieving the network parameters

```
// Get the download/upload speeds and as packets received/sent
currentDownload = netStat.getRxBytes(); // Number of bytes received currently
currentUpload = netStat.getTxBytes(); // Number of bytes sent currently
currentReceived = netStat.getRxPackets(); // Number of packets received currently
currentSent = netStat.getTxPackets(); // Number of packets sent currently
// Skipping the first set of values since it is not obtained directly, i.e. it can only be
obtained by subtraction

at the next instant
    previousDownload = currentDownload;
    previousUpload = currentUpload;
    previousReceived = currentReceived;
    previousSent = currentSent;
}
```
