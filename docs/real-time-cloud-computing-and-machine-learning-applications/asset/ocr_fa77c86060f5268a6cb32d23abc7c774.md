# 7.1.16. Converting a Double Array to Float

Since the neural network accepts data in the float data type and the Retriever Class returns a two-dimensional array of double, the convertToFloat () method is used to convert the double array to float array by typecasting every element to float. The codes are given in Listing 7.21.

# Listing 7.21. Convert double array to float

```
private static float convertToFloat(double[][] array) {
  int col = array[0].length;
  int row = array.length;
  float[][] data = new float[row][col];
  for (int i = 0; i < row; i++) {
    for (int j = 0; j < col; j++) {
      data[i][j] = (float) array[i][j];
    }
  }
  return data;

```
