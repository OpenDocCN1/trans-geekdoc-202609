## 5.1.12. Regression

This section pertains to the regression algorithms namely Linear Regression (MLR) and Multilayer Perceptron (MLP) regression that are used for both the PC and Android devices. The main aim of regression analysis is to predict the outcome of a particular variable at a desired time using a specific window size. Therefore

Network parameters vary largely during different activities performed by the user. For example, if the user is watching YouTube, the buffering system operates in a way where the download speed reaches to the maximum speed allocated to the device so that the video is downloaded for the next few seconds. This is followed by a drastic decrease in the download speed which causes regression algorithms to fail due to the random nature of network usage. For this reason, the “streaming” activity is selected to record regression parameters where the Twitch platform is used.
