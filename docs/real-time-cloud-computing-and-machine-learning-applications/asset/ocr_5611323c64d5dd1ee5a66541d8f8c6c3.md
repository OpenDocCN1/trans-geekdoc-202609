# 4.1.1. Classification of Network Data

Classification revolves around the automated labelling of a set of data based on a pre-trained model. Some recent publications concerning the use of such algorithms for network and Internet traffic are given next.

In [3], Dixit et al. analysed the common types of Internet traffic using the KNN and Naive Bayes algorithms based on statistical network parameters such as packet arrival time, time to live (TTL) and packet count. With the steady towards protecting user’s privacy, it yielded an accuracy of 85.3% for a train-split ratio of 70:30; with KNN and 54.2% with Naive Bayes. KNN achieved an optimum accuracy with eight neighbours. This encourages the use of KNN when it comes to classifying network-related activities using parameters similar properties.

In [4], Mahmoud et al. employed Deep Learning (DL) algorithms for Network Traffic Monitoring and Analysis (NTMA) applications to build classifiers and prediction models for network traffic. Among the algorithms were MLP, convolutional networks (CNN), recurrent neural networks (RNN) for sequential data and long short term memory (LSTM). With DL algorithms previously targeting the exploitation of port-based, packet-based and flow-based network traffic classification techniques, new classification methods were proposed and developed.

Likewise, in [5], Guezzaz et al. investigated the usage of an MLP classifier for monitoring network traffic using three layers. They proposed an effective training method to have optimum weights as well as a detection method to substantiate the model. Most classifiers do not fare well when it comes to large data, thus affecting the classification process. The MLP classifier, however, is revealed to act as a perceptual analysis layer that has the potential of being employed in network monitoring systems to increase the reliability of data flow.
