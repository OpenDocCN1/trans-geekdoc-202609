## 6.3.4. Building the Main Activity Layout

First, the layout of the application needs to be modified by adding the required components in the activity_main.xml file. Figure 6.12 shows the component tree of the application that displays a hierarchical view of the design for the main activity.

![](img/2b52fde0e707e8c2f05a10309c3f8982_602_0.png)

Figure 6.12. main_activity.xml component tree.

The layout consists of a ConstraintLayout which is fixed to the screen on which a LinearLayout is used to place the elements by row.

On the first row, an EditText is placed for the user to input the IP address of a local server, a switch that toggles to determine whether to send data directly to the cloud, and a Button labelled Monitor that starts the monitoring process.

The second row consists of a spinner that is used to switch the variable being monitored and a GraphView that is obtained from the MPAndroidChart library.

The third row consists of a button labelled Analyze which when clicked, starts the Analysis Activity for forecasting. The Analysis activity is described later in this section.
