Table 5.18 details the variables to be used in this query.

# Table 5.18. Variables appended to the URL query

| Variable | Description |
| - | - |
| downloadSpeed | Either download speed, or LTE speed, as specified by the dedicated applications or the webpage. |
| uploadSpeed | Either upload speed, or LTE speed, as specified by the dedicated applications or the webpage. |
| packetsReceived | The number of packets received. |
| packetsSent | The number of packets sent. |
| predictionTime | Time after which prediction is to be made, in seconds. |
| windowSize | Window size for regression analytics. |
| device | Indicates the device for which analytics are indexed, as per the following:
1: PC values
2: Android Wi-Fi values
3: Android LTE values |
| action | Indicates the type of analytics to be performed as the following notation:
1: Classification (KNN and MLP)
2: Regression (MLR and MLP) |
| source | Indicates the source of data to be used for analytics and live graph, on the webpages as per the following notation:
1: Cloudant database
2: Localhost, e.g., XAMPPs MySQL database |

This means that the device making the query to the servlet indicates both its identity, i.e., either Desktop PC or Android device, as well as the desired sort of analytics, from either regression or classification.
