Layer 2 which is the Network Layer establishes the connection between the users and the cloud. All the services are delivered to the customers via this connection and hence the cloud infrastructure is highly reliant on it. For the case of a public cloud, this layer is essentially the Internet. The public cloud is normally located at a place which is unknown to the user but has worldwide access via the internet. Private clouds on the other hand can be connected to users via a Local Area Network (LAN).

Layer 3 which with cloud management is responsible for all the entities that are associated with the cloud. These include the users and access control, data, applications, and services. This layer also influences the service level agreements between the user and the cloud operator. The allocation of its components to users determine the service models such as Software as a Service (SaaS), Platform as a Service (PaaS) and Infrastructure as a Service (IaaS). It holds software that cater for cloud management. This software normally permits resource control such as scheduling and provisioning, optimization at the level of the server and workload, well as in cloud governance within the organisation. More specifically the components of this layer can be classified into six sublayers [5, 6, 7]:

+   (i) The Applications sub-layer where different types of applications are software as run and provisioned.
(ii) Data can be in any form whether structured or unstructured depending on the client's requirements.
(iii) The runtime which provides the runtime and execution environments to the virtual machines.
(iv) Middleware is a software that offers services and features beyond the regular functionalities provided by the Operating System (OS) to applications. Examples of services that are usually handled by middleware include data management, application services, messaging, authentication, and API management.
(v) Operating System (OS) – The software which handles all the fundamental jobs such as file management, memory management, process management, input and output control, and management of peripheral devices such as disk drives and printers.
(vi) Virtualization – This is the creation of a virtual abstraction rather than actual version of a hardware or software resource such as an OS, a server, a storage device or network.
