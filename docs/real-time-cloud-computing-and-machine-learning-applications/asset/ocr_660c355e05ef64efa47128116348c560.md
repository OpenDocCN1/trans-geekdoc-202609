The predict function from MATLAB's Statistics and Machine Learning Toolbox can be used to predict the response for an untested predictor [27]. A MATLAB simulation for performing the regression in the short-hand example is demonstrated below. The training dataset is first loaded into MATLAB's workspace and the polynomial regression model is then fitted using the codes in Listing 3.18.

# Listing 3.18. Multiple linear regression- Fit regression model

| Weight=[1835 1970 2372 3086 3504 4341]; % Matrix with car weight information |
| Horsepower=[46 68 95 225 130 198]; % Matrix with car horsepower information |
| Acceleration=[20.5 17 15 12 10]; % Matrix with car acceleration information |
| X =[Weight,Horsepower,Acceleration]; % Matrix with car information |

y = [26 31 24 14 18 15]; % Matrix with miles information
mdl = fitm(X,y); % Fit the polynomial regression model

By setting the weight to a random constant value of 1900 pounds, the fitted multiple linear regression line can be illustrated in a 3-D plot using the codes in Listing 3.19. Furthermore, the prediction made in the short-hand example of the mileage of a car 4000 pounds with 153 hp having an acceleration of 11 m/s is repeated using the regression model trained on MATLAB.
