## 7.1.8.1. Multiple Linear Regression Models for Weather Data

This section discusses the MLR equation for each of the variables to be predicted. The equation involves a generic variable V1 to be predicted at time t + n with respect to the previously recorded value of V1 at time t and another related parameter Vx. The equation is formulated as per the following generic combination:

$V_{t+n} = \beta_0 + \beta_1 V_{t+n-1} + \beta_2 Vx_{t+n-1} \quad (7.1)$

Where,

- $Vx_t$ denotes another related parameter that influences the value of $V1_t$.
- $\beta_0, \beta_1, \beta_2$ are coefficients determined for a training window of size W that was kept at 12 hours. These coefficients are calculated every 12 hours to recalibrate the model by the newly recorded values.

Using the model above, a list of seven equations was obtained. For example, the MLR equation to predict the temperature value for time $t + n$ is as follows:

$T_{t+n} = \beta_0 + \beta_1 H_{t+n-1} + \beta_2 T_{t+n-1} \quad (7.2)$

The value of temperature for the time interval $t + 1$ is calculated from the previous temperature value $T_t$ and previous humidity value $H_t$. The coefficients $\beta_0, \beta_1 \& \beta_2$ are obtained from a Multiple Linear Regression model using a training window of $W$. ## 7.1.8.2. Polynomial Regression Models for Weather Data

Polynomial Regression models are used when the relationship between the dependent variable and explanatory variable is curvilinear and can be represented by an $i^{th}$ degree polynomial. The $i^{th}$ order polynomial for a single variable can be expressed as:

```
$y = \beta_0 + \beta_1X^1 + \beta_2X^2 + \dots + \beta_iX^i + \epsilon \quad (7.6)$
```

Where,

- $y$ - the predicted value of the dependent variable
- $\beta_0$ - the y-intercept (value of $y$ when all other parameters are set to zero)
