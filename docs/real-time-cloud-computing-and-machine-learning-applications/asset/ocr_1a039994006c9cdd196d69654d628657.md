# 6.4.1. Creating the Desktop Application in NetBeans

To create a Java Swing application in NetBeans, the following steps are followed.

+   1. The NetBeans application is launched and a new project is created by click on "File" and then "New Project" or alternatively pressing Ctrl + Shift + N.

![](bbox=[0.104, 0.233, 0.896, 0.453])

Figure 6.33. Creating a New Project.

+   2. The next step is to choose the type of project needed. For this purpose, the category "Java with Ant" is chosen to use the ANT build tool that is responsible for compiling the java classes, and the project type is a "Java Application" as shown in Figure 6.34. The "Next" button is then clicked.
