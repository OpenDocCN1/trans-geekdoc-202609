## 3.7. DEPLOYING JAVASCRIPT MACHINE LEARNING ALGORITHMS ON FIREBASE

This section demonstrates the hosting of machine learning algorithms using the Firebase cloud platform. A Node.js Web Application that consists of three JavaScript machine learning algorithms has been developed in Netbeans. The application which will be hosted to make it publicly deployable by Firebase. The structure of the application is as shown in Table 3.20.
