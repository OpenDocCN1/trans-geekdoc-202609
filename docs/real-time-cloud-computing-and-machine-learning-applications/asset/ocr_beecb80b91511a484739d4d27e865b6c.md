# 5.3.7.1. Creating index1.html and index1.js

This step follows the creation of the "NetworkCloud" dynamic web project created in Section 5.3.1. To create a new HTML file into the dynamic web project, the "WebContent" folder is right-clicked on, and a new HTML file is selected as shown in Figure 5.58. This ensures that this file is accessible without any pattern mapping along with the hosted URL on IBM Bluemix.
