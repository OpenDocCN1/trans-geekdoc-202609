## 5.1.9. Filling Localhost Databases

As mentioned in Table 5.6, the `localhostDatabase.java` class is responsible for firstly making a connection to the localhost database, before inserting values in the respective tables, based on the selection of devices made on the GUI, as handled by the server threads in Sections 5.1.8.2 and 5.1.8.3, where the `insertAndroid` and `insert` methods are called. The class performs its functions as follows:

- Check the identifier specified where an integer value of "1" denies access being requested to the "laptopression" table and that of "2" represents access to the "androidregression" table.
- Specify the username and passwords of each table in their respective statements.
- Use the `Connection` class to make a connection to the database, using the `getConnection()` method.
- Pass the created MySQL statement, held by a String object, into a variable of type `PreparedStatement`, denoted as `insertReadings`. This object is responsible for holding the values to be inserted into the tables.
- The `insertPC()` and `insertAndroid()` methods, called by the server threads, fill the `insertReadings`, with the respective values obtained on the running server, according to the indexes they bear on the localhost database.

Listing 5.9 shows the `localhostDatabase.java` class.

### Listing 5.9. localhostDatabase.java class

```java
import com.mysql.jdbc.Connection;
import com.mysql.jdbc.PreparedStatement;
import java.sql.DriverManager;
import java.sql.SQLException;

public class localhostDatabase {

    // Initialising variables for making connection to localhost
    static Connection c = null;
    static PreparedStatement insertReadings = null;
    static String sql = null;

    public void localhost(int identifier) {
        // If the identifier equals 1, the PC is being accessed
        if (identifier == 1) {
            // Creating MySQL statement to insert values by specifying table name
            sql = "INSERT INTO regression(DownloadSpeed,UploadSpeed,PacketsReceived,PacketsSent) VALUES (?,?,?,?,?)";
            try {
                Class.forName("com.mysql.jdbc.Driver");
                // Using port 3306 for localhost
                // Opening the table using a Connection object and specified database name, username and password
                c = (Connection) DriverManager.getConnection("jdbc:mysql://localhost:3306/network", "root", "");
                // Using the Statement to insert the readings
                insertReadings = (PreparedStatement)c.prepareStatement(sql);
                System.out.println("OPENED DATABASE SUCCESSFULLY.");
            } catch (ClassNotFoundException | SQLException e) {
                System.out.println("DB ERROR: " + e);
            }
        }

        // If the identifier equals 2, the android is being accessed
        if (identifier == 2) {
            // Creating MySQL statement to insert values into database
            sql = "INSERT INTO androidression(DownloadSpeed,UploadSpeed,MobileDownloadSpeed,MobileUploadSpeed,PacketsReceived,PacketsSent,WifiStrength) VALUES (?,?,?,?)";
            try {
                Class.forName("com.mysql.jdbc.Driver");
                // Opening the table using a Connection object and specified database name, username and password
                c = (Connection) DriverManager.getConnection("jdbc:mysql://localhost:3306/network", "root", "");
                // Using the Statement object to insert the readings
                insertReadings = (PreparedStatement)c.prepareStatement(sql);
                System.out.println("OPENED DATABASE SUCCESSFULLY.");
            } catch (ClassNotFoundException | SQLException e) {
                System.out.println("DB ERROR: " + e);
            }
        }
    }

    // Method called when values fetched from the PC are being inserted into the localhost database
    public static void insertPC(Double DownloadSpeed, Double UploadSpeed, Double PacketsReceived, Double PacketsSent) {
        try {
            // Using the PreparedStatement class to insert values into database
            // Allocating values to particular rows, depending on order created in localhost
            insertReadings.setDouble(1, DownloadSpeed);
            insertReadings.setDouble(2, UploadSpeed);
            insertReadings.setDouble(3, PacketsReceived);
            insertReadings.setDouble(4, PacketsSent);
            insertReadings.execute(); // executing the statement
        } catch (Exception e) {
            System.out.println("INSERT ERROR: " + e);
        }
    }

    // Method called when values fetched from the Android device are being inserted into the localhost database
    public static void insertAndroid(Double DownloadSpeed, Double UploadSpeed, Double MobileDownloadSpeed, Double MobileUploadSpeed, Double PacketsReceived, Double PacketsSent, Double WifiStrength) {
        // Using the PreparedStatement class to insert values into database
        try {
            // Allocating values to particular rows, depending on order created in localhost
            insertReadings.setDouble(1, DownloadSpeed);
            insertReadings.setDouble(2, UploadSpeed);
            insertReadings.setDouble(3, MobileDownloadSpeed);
            insertReadings.setDouble(4, MobileUploadSpeed);
            insertReadings.setDouble(5, PacketsReceived);
            insertReadings.setDouble(6, PacketsSent);
            insertReadings.setDouble(7, WifiStrength);
            insertReadings.execute(); // executing the statement
        } catch (Exception e) {
            System.out.println("INSERT ERROR: " + e);
        }
    }
}
```
