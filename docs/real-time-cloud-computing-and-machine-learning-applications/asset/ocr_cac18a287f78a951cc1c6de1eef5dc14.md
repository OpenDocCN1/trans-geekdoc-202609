The sixth phase which is termed utility computing is the packaging of computer resources, such as computation, storage and services, as a metered service. It represents the payment model that service provider typically uses to charge consumers for the services required.

Software as a Service (SaaS) computing is what is now known as SaaS, represents the one aspect of cloud computing which includes providing software applications to users as a service. Typical applications include analytics, invoices, project management, email marketing, etc. This represents phase 7.

Finally, phase 8, cloud computing allows additional sharing of resources on the Internet in a flexible and user-friendly manner [6].

Layer 1 is referred to the cloud infrastructure and is also considered as the front end. All the users or clients are represented by this layer. It is from this point the client/user triggers the connection to the cloud. The client can be any device ranging from a totally dependent terminal to a self-sufficient PC with adequate computing power. This layer provides the Graphical User Interface to interact with the cloud which in most cases is a simple web browser.
