## DATA CAPTURE AND ARCHITECTURE FOR A CLOUD-BASED REAL-TIME NETWORK ANALYTICS SYSTEM

Over the years, analytics have always propelled the human race towards anticipation and identification of key factors that can be optimised to better the service being dealt with whereby network manufacturers are being encouraged to turn towards Artificial Intelligence (AI), the partnership of Machine Learning (ML) algorithms and captured network data can provide insights on the behaviour of a network, paving the way to technology such as self-organising networks. As the Internet expands in magnitude and intric, network traffic, generally defined as the volume of data transmitted over a network at a given time, is growing at rocking pace [1]. In other words, there is a constant need to monitor and manage networks in terms of resources, security and performance [2]. In this chapter, Section 4.1 gives a general overview of the machine learning algorithms used for network analytics. The systems described in Sections 4.2 to 4.5 aim to fully collect network parameters in different scenarios whereby the information is segregated into databases, allowing analytics to be performed in real-time. Sections 4.2 to 4.4 elaborate on the data capture and device interfaces while Section 4.5 describes the cloud database configurations made to store the retrieved parameters.

## 4.1. OVERVIEW OF MACHINE LEARNING ALGORITHMS FOR NETWORK ANALYTICS

The introduction of ML to analytics has been revolutionary due to the ability to break down categories of data into either supervised or unsupervised learning. The network analytics system in Chapters 4 and 5 focuses on the implementation of four ML algorithms to identify the status of a device with respect to its network activity as well as predict the number of packets received at a particular time. The algorithms are as follows:

- K-nearest neighbour (KNN)
- Multilayer perceptron (MLP) classification
- Multiple linear regression (MLR)
- Multilayer perceptron (MLP) regression

### 4.1.1. Classification of Network Data

Classification revolves around the automated labelling of a set of data based on a pre-trained model. Some recent publications concerning the use of such algorithms for network and Internet traffic are given next.

In [3], Dixit et al. analysed the common types of Internet traffic using the KNN and Naive Bayes algorithms based on statistical network parameters such as packet arrival time, time to live (TTL) and packet count. With the steady towards protecting user’s privacy, it yielded an accuracy of 85.3% for a train-split ratio of 70:30 with KNN and 54.2% with Naive Bayes. KNN achieved an optimum accuracy with eight neighbours. This encourages the use of KNN when it comes to classifying network-related activities using similar properties.

In [4], Mahmoud et al. employed Deep Learning (DL) algorithms for Network Traffic Monitoring and Analysis (NTMA) applications to build classifiers and prediction models for network traffic. Among the algorithms were MLP, convolutional networks (CNN), recurrent neural networks (RNN) for sequential data and long short term memory (LSTM). With DL algorithms previously targeting the exploitation of port-based, packet-based and flow-based network traffic classification techniques, new classification methods were proposed and developed.

Likewise, in [5], Guezzaz et al. investigated the usage of an MLP classifier for monitoring network traffic using three layers. They proposed an effective training method to have optimum weights as well as a detection method to substantiate the model. Most classifiers do not fare well when it comes to large data, thus affecting the classification process. The MLP classifier, however, is revealed to act as a perceptual analysis layer that has the potential of being employed in network monitoring systems to increase the reliability of data flow.
