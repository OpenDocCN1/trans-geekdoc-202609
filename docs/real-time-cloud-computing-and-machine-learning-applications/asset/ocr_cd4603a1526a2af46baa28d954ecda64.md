# Listing 3.11. Restricted Boltzmann Machine- Define training parameters

| %% Training Options |
| Options.max_iter=200; | % maximum number of learning iterations |
| Options.N_gs=100; | % number of Gibbs sampling steps |
| Options.Nneurons-gamma(1); | % number of neurons in the hidden layer |
| Options.eps=0.01; | % learning rate |
| Options.Sz_mb=10; | % size if mini-batch of data |

Training of the RBM is initiated using the codes given in Listing 3.12:

# Listing 3.12. Restricted Boltzmann Machine-Train RBM

| %% Training process |
| net=RBM_TB(xtr,Options); % train RBM using training set and user-defined parameters |

The RBM can then be tested by regenerating the test image (Test.jpg) by using the codes in Listing 3.13. The test image must also be set to the same size and colour as the training set images for the RBM to work accurately:

# Listing 3.13. Restricted Boltzmann Machine-Test RBM

| %% Prediction |
| xp=imread('Test.jpg'); |
| xp=resize(xp,gamma); |
| xp1=rgb2gray(xp); |
| xp=double(xp1); |
| [y]=RBM_RECONSTRUCT(net,xp); |
