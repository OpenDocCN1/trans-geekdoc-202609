## 4.3.10.2. The “Classify” Button

This button queries the servlet or the local server, for classification analytics through the use of real-time values from MainActivity.java that can the current activity status of the device is obtained. This alerts the URL that queries the servlet, through the specification of the “device” variable, which is 2 for Wi-Fi values and 3 for LTE values.
