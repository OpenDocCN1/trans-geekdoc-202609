Download functionalities are also provided whereby the user can select the parameters to be downloaded into .csv files by either specifying a desired number of samples or searching by date. The application also provides the ability to choose from the “Cloudant” or “Local” databases. To summarise, buttons placed on the GUI using the XML files are mapped to the respective above actions.
