The rlQAgent function from MATLAB's Reinforcement Learning Toolbox be used to create a Q-learning agent [51]. The syntax of the function is as follows:

```
agent:= rlQAgent(critic,agentOption)
```

The inputs to the function are described below:

critic: Critic network representation (Q-table).

agentOption: Object created from the rlQAgentOptions function from MATLAB's Reinforcement Learning Toolbox which specifies the agent's configuration such as sample time and discount rate.
