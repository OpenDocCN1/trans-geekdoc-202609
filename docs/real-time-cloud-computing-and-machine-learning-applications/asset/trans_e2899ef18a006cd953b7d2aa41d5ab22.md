上述的每个类在获取参数、将其上传到 Cloudant 数据库以及执行分析方面都有特定的用途。还提供了下载功能，用户可以通过指定所需的样本数量或按日期搜索来选择下载到 .csv 文件中的参数。应用程序提供了从“Cloudant”或“Local”数据库中选择的能力。总之，使用 XML 文件放置在 GUI 上的按钮映射到上述相应的操作。这导致在点击按钮时创建不同的线程。实现线程允许应用程序同时执行各种任务。（注：原文此处存在大量重复句，翻译已按要求去重）。
