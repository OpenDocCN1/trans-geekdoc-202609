```
$$(v,h) = \sum_{i\in visible} a_{iv}v_i - \sum_{j\in hidden} b_{hj}h_j - \sum_{l,j} v_{lj}h_jw_{ij} \quad (3.6)$
```

Where,

+   $v_i$ - Binary state of visible unit $i$
$h_j$ - Binary state of hidden unit $j$
$a_i$ - Bias of visible unit $i$
$b_j$ - Bias of hidden unit $j$
$w_{ij}$ - Weight between visible unit $i$ and hidden unit $j$

The neural network assigns a probability to every combination of visible and hidden vectors using the following energy function:

```
$$p(v,h) = \frac{1}{Z}e^{-E(v,h)} \quad (3.7)$
```

$Z$ is called the partition function and is obtained by adding up every combination of visible and hidden vectors:

```
$$Z = \sum_{v,h} e^{-E(v,h)} \quad (3.8)$
```

The neural network assigns a probability to visible vector $v$ by summing over all possible hidden vectors:

```
$$p(v) = \frac{1}{Z}\sum_{h} e^{-E(v,h)} \quad (3.9)$
```

The derivative of the log probability of a training vector with respect to weight is given by:

```
$$\frac{\partial \log p(v)}{\partial w_{ij}} = \langle v_{lj}h_j\rangle_{data} - \langle v_{lj}h_j\rangle_{model} \quad (3.10)$
```

The angle brackets denote the expectation under the distribution specified by the subscript that follows.
Hence the learning rule for performing stochastic steepest ascent in the probability of the training dataset is as follows:

```
$$\Delta w_{ij} = \alpha(\langle v_{lj}h_j\rangle_{data} - \langle v_{lj}h_j\rangle_{model}) \quad (3.11)$
```
