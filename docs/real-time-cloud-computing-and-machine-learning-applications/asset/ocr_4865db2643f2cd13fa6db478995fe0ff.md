# 7.1.8.2. Polynomial Regression Models for Weather Data

Polynomial Regression models are used when the relationship between the dependent variable and explanatory variable is curvilinear and can be represented by an $i^{th}$ degree polynomial. Figure 7.9 shows the temperature reading for a 12hr time period represented by a black line and the red dotted line represents a cubic regression line ($i=3$) that can be used for forecasting the next temperature reading. The equation of the polynomial regression line and the coefficient of determination are also shown on the graph in Figure 7.9.

![](bbox=[0.117, 0.383, 0.882, 0.00715])

Figure 7.9. Polynomial Regression on Temperature.

The $i^{th}$ order polynomial for a single variable can be expressed as:

```
$y = \beta_0 + \beta_1X^1 + \beta_2X^2 + \dots + \beta_iX^i + \epsilon \quad (7.6)$
```

Where,

+   * $y$ - the predicted value of the dependent variable
* $\beta0$ - the y-intercept (value of $y$ when all other parameters are set to zero)
