# 2.1. DEFINITIONS OF CLOUD COMPUTING

Cloud computing has been referred to as a paradigm that encompasses a class of advanced computational facilities primarily provided on an on-demand basis by common providers, such as Amazon, Google, and Microsoft. It can be considered as a model which provides a powerful scalable computing system framework as a “cloud,” which provides applications and services on an demand basis with worldwide outreach to organisations and personal users [1]. The fundamental basis of this paradigm is the delivery of three main types of services which are processing power, storage, and software. The term 'cloud computing' and its specific characteristics have been defined by several researchers and professionals. Some of the most common definitions are quoted next [2].

The National Institute of Standards and Technology (NIST) [3] characterizes cloud computing as a “pay-per-use model for enabling available, convenient, on-demand network access to a shared pool of configurable computing resources (e.g. networks, servers, storage, applications, services) that can be rapidly provided and released with minimal management effort or service provider.”
