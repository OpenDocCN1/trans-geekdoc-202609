This means that the URL mapping can also be changed. If the server was configured to run on the localhost, it could then be accessed via the URL: http://localhost:8080/CalculateArea/ where the part before the / denotes the link for the project. Since the servlet will be launched on the IBM cloud platform it will have the URL: single servlet in the project, no other identifiers have been added after the /. Alternatively if there were two servlets, there could be two links for identifying the servlets for example: https://calcularea.eu-gb.myblueix.net/s1 and https://calcularea.eu-gb.myblueix.net/s2. These mappings would be made on line 13 for each Servlet in Figure 2.115 or at the time of creating each servlet in Figure 2.114. The purpose of the doGet() and doPost() methods are summarized as follows:

- doGet(): Parameters can be fetched from a plaintext URL where they are appended to the URL using particular notation normally as a query string ie. after the question mark character in the URL (?). They are then sent with the header information in the server itself. Most of the web servers support only a limited amount of information to be attached to the headers, the size of this header should not exceed 1024 bytes.
- doPost(): Parameters are sent separately. The number of parameters sent along a doPost()request is unlimited in contrast with the doGet() method which has limit of 1024 bytes.

# Listing 2.9. doGet method of the CalculateAreaServlet

```
protected void doGet(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException {
    // Declare the variables used by the Servlet.
    int length;
    int width;

    /* The request contains the client. A check is made to see if the "length" parameter in the request is not null */
    if(request.getParameter("length")!=null){
        /* If length is not null, extract the value of the length and width from the request and convert them to integer */
        length=Integer.parseInt(request.getParameter("length"));
        width=Integer.parseInt(request.getParameter("width"));
    } else {
        /* If the length is null set both length and width to 1. */
        length = 1;
        width = 1;
    }

    /* Calculate the area and return the response. */
    int area = length*width;

    response.getWriter().println("The area is:" + area);
}
```
