# Machine Learning Algorithms

net= feedforwardnet(hiddenSizes)

The input to the function is described below:

**hiddenSizes**: Size of the hidden layers given in a row vector in which each column corresponds to a hidden layer and the value in each column gives the number of neurons in that layer.

The function outputs **net** which is the feed-forward network in a network object form.
The **train** function from the Deep Learning Toolbox can be used to train feed-forward networks having a single hidden layer [41]. The syntax of the function is as follows:

**TrainedNet= train(net, X, T)

The input to the function is described below:

+   **net**: Feed-forward network object.
**X**: Network inputs (predictors).
**T**: Network targets (expected response).

For feed-forward networks with more than one hidden layer, the **trainNetwork** function from the Deep Learning Toolbox can be used [42]. A MATLAB simulation demonstrating the creation and testing of an MLP for regression is described below [41].
