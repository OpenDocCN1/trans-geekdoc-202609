The patternert function is used to create an MLP with a hidden layer having 10 neurons and the MLP is then trained using the predictors and responses from matrices x and t.

Listing 3.31. Multi-layered perceptrons classification-: Create and train MLP

```
net = patternet(10); % Create pattern recognition feedforward network
net = train(net,x,t); % Train the network
```

Using the codes in Listing 3.32, the training predictors are then used as test predictors to generate responses which can be compared with the actual responses to evaluate the performance of the MLP. The class index for each iris is output in an array labelled classes. A confusion chart is also generated to illustrate the accuracy of the MLP classifier.

Listing 3.32. Multi-layered perceptrons classification-: Test MLP

```
y = new(x); % Test network using training inputs
classes = vec2ind(y); % Output classes details
% Reformat predictor matrix to use confusion chart
tnew=-t;
tnew(2,:)=new(2,:)*2;
tnew(3,:)=new(3,:)*3;
tnew-sum=sum(tnew,1);
confusionchart(tnew,classes) % Build confusion chart
```
