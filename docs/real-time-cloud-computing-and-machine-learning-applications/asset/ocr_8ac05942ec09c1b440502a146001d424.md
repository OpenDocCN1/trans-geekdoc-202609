# 4.3.2. Adding Libraries

The coding of the Android application is made easier with the usage of several libraries whose functionalities can be described as per Table 4.2. These libraries are in the form of "jar" files which first need to be downloaded. The purpose, as well as download links, are included in the table.

Table 4.2. Description and references of libraries used for Android application

| Library | Purpose | Repository | Download link | Jar file |
|---|---|---|---||}{
| MPAndroidChart | Provision of a chart area whereby a graph can be implemented with values added every second. | [10] | | MPAndroidChart-v3.0.1.jar |
| CloudantManager | Client-server interactions with the Cloud database to push or retrieve values. | [11] | [12] | CloudantManager.jar |
| Storage-chooser | Provides a file picker to select a folder destination for the .csv files to be written. | [13] | | Added as a dependency instead of "jar" file |
| OpenCV | Creates .csv files from plain text using the appropriate syntax. Used in the downloading functionality | [14] | [15] | opencv-2.2.jar |
