+   (iii) Infrastructure as a Service (IaaS): In this service, an instance of the infrastructure (typically virtualized processing, storage and other resources) owned by the CSC is made available to the CSC. The CSC can deploy and execute different types of software such as operating systems and programming environments, on that leased infrastructure remains under full control of the CSP, but the CSC can control all the applications that it has deployed on the CSP's infrastructure including security and network settings that are specific to the host device [12]. Cloud service classes have also evolved and more specific service classes include Analytics as a Service (AaaS), Network as a Service (NaaS), Mobile Backend as a Service (MBaaS), Mobile Network-as-a-Service (MNaaS), and Communications as a Service (CaaS).
