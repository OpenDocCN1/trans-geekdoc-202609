# 4.3.10.1. The “Predict” Button

This button is coded inside onCreate() by adopting the following principles:

+   - Determining option between “Cloudant” or “Local” is selected on the GUI.
- Creating two different threads where:
  - predictThread: Caters for prediction using the Cloudant database.
  - predictThreadhost: Makes prediction using locally hosted databases, via connection to the local server.
- Creating mentioned threads to handle the query-response process.
- Creating an object of type URL to hold the query for the servlet.
- Using a URLConnection to make a connection to the servlet and wait for a response, using the time and window size from the UI.
- Using a series of readers to obtain the response in JSON format.
- Retrieving the required predictions for MLR and MLP regression from the JSON response.
- Updating the UI with the output.

It should be noted that the cloud servlet is queried through a constructed URL, based on the principles provided in Section 5.3 and Table 5-18, in Chapter 5. Listing 4.40 depicts the implementation for the “Predict” button.
