## 5.1.12.5. Performing Multiple Linear Regression (MLR)

Using the principles for the sliding window explained in Section 5.1.12.1, the Regression() method performs the following steps. The logic explained in the previous section is also used.

- Obtain the values for "Window Size" and "Prediction Time" from the GUI int objects.
- Initialising arrays to store individual errors for both SLR and MLR.
- Creating an int variable that iterates the sliding window by 1 each time.
- Creating the sliding windows with counter i.
- Filling arrays for SLR in the x, y and z [] objects.
- Filling arrays for MLR, with the independent variables stored in a three-column array.
- Initialising variables for the sum of the values as well as the mean window.
- Calculating the sum per window for each variable as well as time.
- Calculating the respective averages for each variable.
- Initialising variables to calculate the sum of squared deviates for Xi values.
- Initialising variables for the Pearson product-moment correlation coefficient, r.
- Using the sum of squared deviates formula to calculate the latter for each variable.
- Calculating the coefficients for both SLR and MLR.
- Finding the individual errors by comparing the predicted value to the actual using a created counter.
- Finding the prediction by the user by making use of the last possible window for prediction. This makes use of all the steps mentioned above without the for loop to iterate through the whole dataset, i.e., uses only the last possible window.

The method is implemented per Listing 5.17, with the comments depicting the function of each block of code.

  sxx += (x[n] - xmean) * (x[n] - xmean);
  ssy += (y[n] - ymean) * (y[n] - ymean);
  sst += (time[n] - tmean) * (time[n] - tmean);

  sctx += (x[n] - xmean) * (time[n] - tmean);
  sctz += (z[n] - zmean) * (time[n] - tmean);
}
