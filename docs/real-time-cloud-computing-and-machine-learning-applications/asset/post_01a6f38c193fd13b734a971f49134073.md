```math
$$(v,h) = \sum_{i\in visible} a_{iv}v_i - \sum_{j\in hidden} b_{hj}h_j - \sum_{l,j} v_{lj}h_jw_{ij} \quad (3.6)$$
```

Where,

- $v_i$ - Binary state of visible unit $i$
- $h_j$ - Binary state of hidden unit $j$
- $a_i$ - Bias of visible unit $i$
- $b_j$ - Bias of hidden unit $j$
- $w_{ij}$ - Weight between visible unit $i$ and hidden unit $j$

The neural network assigns a probability to every combination of visible and hidden vectors using the following energy function:

```math
$$p(v,h) = \frac{1}{Z}e^{-E(v,h)} \quad (3.7)$$
```

$Z$ is called the partition function and is obtained by adding up every combination of visible and hidden vectors:

```math
$$Z = \sum_{v,h} e^{-E(v,h)} \quad (3.8)$$
```

The neural network assigns a probability to visible vector $v$ by summing over all possible hidden vectors:

```math
$$p(v) = \frac{1}{Z}\sum_{h} e^{-E(v,h)} \quad (3.9)$$
```

The derivative of the log probability of a training vector with respect to weight is given by:

```math
$$\frac{\partial \log p(v)}{\partial w_{ij}} = \langle v_{lj}h_j\rangle_{data} - \langle v_{lj}h_j\rangle_{model} \quad (3.10)$$
```

The angle brackets denote the expectation under the distribution specified by the subscript that follows.
Hence the learning rule for performing stochastic steepest ascent in the probability of the training dataset is as follows:

```math
$$\Delta w_{ij} = \alpha(\langle v_{lj}h_j\rangle_{data} - \langle v_{lj}h_j\rangle_{model}) \quad (3.11)$$
```

## Machine Learning Algorithms

Where,

$\alpha$ - Learning rate

Gibb Sampling can be performed from the model's distribution because unbiased sample of $\langle v_{ij}h_j \rangle_{model}$ is complex to obtain [21]. Thus, the states of visible units are to a training vector to obtain a reconstruction, $\langle v_{ij}h_j \rangle_{recon}$, instead [21]. The learning rule therefore becomes:

```math
$$\Delta w_{ij} = \alpha(\langle v_{ij}h_j \rangle_{data} - \langle v_{ij}h_j \rangle_{recon}) \quad (3.12)$$
```

RBMs can be implemented in MATLAB using the package from [22]. The package contains a folder with the training set consisting of sample images, user-defined functions for implementing the RBM, and an image script for testing the RBM. The RBM aims to identify patterns in a dataset by reconstructing the inputs. The visible layer encodes the input into a set of numbers. This set of numbers is used to regenerate the input through the backward pass from the hidden layer to the visible layer [22].

At the start of the main script in Listing 3.10, the user-defined functions are added to the search path and the folder containing the training set is specified. The images in the training set are then set to equal sizes to improve the accuracy of the training process. The system is also simplified by converting the coloured photos to grayscale:

### Listing 3.10: Restricted Boltzmann Machine-RBM: Load training data

```matlab
addpath('RBM'); % Add RBM folder containing user-defined functions to search
pathname= uigetdir; % Select folder containing the training set
allfiles= dir(fullfile(pathname,'*.jpg'));
tr=[];
gamma=[70];size of each image is defined
for i=1:size(allfiles,1)
x=imread(fullfile(pathname,allfiles(i).name));
x=resize(x,gamma); % resize training set to a uniform size
x=rgb2gray(x); % convert coloured images to grayscale
x=double(x);
tr=[tr; x];% training set building
end
```
