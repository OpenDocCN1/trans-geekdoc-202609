# 7.5.2. Downloading Weather Data

+   1. To download the last N weather samples, first, the number of samples is entered in the “Download Last N data” TextBox. Then, the “Download” button is pressed. The webpage will contact the “Downloader” servlet for a CSV file. After the server returns the CSV file, the user can download it.
