# 6.4.13. The w_varActionPerformed () Method

This method is responsible for clearing the graph and displaying data for the newly selected weather parameter. First, the graph is cleared. Then, the counter is reset to zero. The key for the graph is updated to the new weather parameter and the fireChartChanged() of the chart object is invoked to inform the graph of the changes. The codes are given in Listing 6.34.

# Listing 6.34. Clearing graph to show data for new parameters
