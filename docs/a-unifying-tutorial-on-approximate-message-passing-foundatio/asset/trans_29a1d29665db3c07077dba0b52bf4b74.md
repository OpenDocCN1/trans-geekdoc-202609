
现在对界 (B.9) 进行积分，可以看出

```
\(\mathbb{E}(\vartheta_\beta(|X_i|/\theta_i)) = \int_0^\infty \mathbb{P}(\vartheta_\beta(|X_i|/\theta_i) \ge t) \, dt = \int_0^\infty \mathbb{P}(|X_i| \ge \theta_i \vartheta_\beta^{-1}(t)) \, dt\)
\(= \int_0^\infty \mathbb{P}(|X_i| \ge 2(r+1)^{r/2} L_i \{4 \log(1+t)\}^{1/\beta}) \, dt\)
\(\le \int_0^\infty e(1+t)^{-4} \, dt = e/3 < 1,\) (B.10)
```

因此 \(\Xi_{\vartheta_\beta}(X_i) \le \theta_i = 2\{4(r+1)\}^{r/2} L_i < \infty\)。这表明 \(X_1,\dots,X_n\) 是阶数为 \(\beta = 2/r\) 的独立、中心化 _sub-Weibull_ 随机变量，意义与 Kuchibhotla and Chakrabortty (2018) 中的定义 2.2 一致。然后按照 Kuchibhotla and Chakrabortty (2018, Theorem 3.1)，取 \(a = (1/n,\dots,1/n) \in \mathbb{R}^n\) 及 \(b := (\Xi_{\vartheta_\beta}(X_1)/n,\dots,\Xi_{\vartheta_\beta}(X_n)/n)\)（按其记法），由 (B.10) 推出

```
\(\Xi_{\vartheta_\beta, \lambda_\beta} \left( \frac{1}{n} \sum_{i=1}^n X_i \right) \le 2 e C_\beta \|b\|_2, \quad \text{where}\)
\(\left\{ \begin{array}{l} C_\beta := (2e^{2/e}/\beta)^{1/\beta}(128\pi)^{1/4} e^{3+\frac{1}{24}} \\ \lambda_\beta := (4^{1/\beta}/\sqrt{2}) \, \|b\|_\infty / \|b\|_2. \end{array}\right.\) (B.11)
```

随后由 Kuchibhotla and Chakrabortty (2018) 中的提议 A.3 可知

```
\(\mathbb{P} \left( \left| \frac{1}{n} \sum_{i=1}^n X_i \right| \ge 4 e C_\beta \|b\|_2 \max(s^{1/2}, \lambda_\beta s^{1/\beta}) \right) \le e^{1-s}\)
```

对所有 \(s \ge 0\) 均成立，因此

```
\(\mathbb{P} \left( \left| \frac{1}{n} \sum_{i=1}^n X_i \right| \ge t \right) \le \exp \left( 1 - \min \left\{ \left( \frac{t}{4 e C_\beta \|b\|_2} \right)^2, \left( \frac{t}{4 e C'_\beta \|b\|_\infty} \right)^\beta \right\} \right)\)
```

对所有 \(t \ge 0\) 均成立，其中 \(C'_\beta := (4^{1/\beta}/\sqrt{2}) C_\beta\)。由于 \(\beta = 2/r\) 且对 \(1 \le i \le n\) 有 \(\Xi_{\vartheta_\beta}(X_i) \le 2\{4(r+1)\}^{r/2} L_i\)，可得

```
\(n \|b\|_p = \| (\Xi_{\vartheta_\beta}(X_1), \dots, \Xi_{\vartheta_\beta}(X_n)) \|_p \le 2\{4(r+1)\}^{r/2} \|L\|_p\)
```

对 \(p \in \{2, \infty\}\) 均成立。此外，\(2\{4(r+1)\}^{r/2} C_\beta \le 2\{4(r+1)\}^{r/2} C'_\beta \lesssim \{4e^{1/e}(r+1)\}^r\)，因此我们确实可以在 (B.6) 中找到合适的通用常数 \(C > 0\)，使得对于所有 \(n \in \mathbb{N}\)、\(r \ge 2\)、\(L \equiv (L_1, \dots, L_n) \in (0, \infty)^n\) 和 \(t \ge 0\)，所需结论均成立，如要求所示。

注释 B.13. 当 $r > 2$、$f \in \text{PL}_1(r)$ 且 $Z \sim N(0, 1)$ 时，若 $f(Z)$ 的尾部比指数随机变量更重，则 $f(Z)$ 的矩生成函数除在 0 处外可能无处有限（例如当 $f(z) = \text{sgn}(z)|z|^r$ 对 $z \in \mathbb{R}$ 时）。在这些情况下，标准的 Chernoff 方法失效，这正是我们采用能够处理一般 sub-Weibull 随机变量的不同技术的原因。

虽然在提议 A.16 的证明中我们主要关注 $r \ge 2$ 的情况，但当 $r \in [1, 2)$ 时，(B.6) 存在类似公式，即

```
\(\mathbb{P}\left(\left|\frac{1}{n} \sum_{i=1}^n \{f_i(Z_i) - \mathbb{E}(f_i(Z_i))\}\right| \ge t\right)\)
\(\le \exp\left(1 - \min \left\{ \left(\frac{nt}{C\|L\|_2}\right)^2, \left(\frac{nt}{C\|L\|_{\bar{r}}}\right)^{2/\bar{r}} \right\}\right),\)
(B.12)
```

其中 $C > 0$ 是合适的通用常数，$\bar{r} := 2/(2-r) \in [2, \infty)$ 是 $2/r$ 的 Hölder 共轭。这可以通过 Chernoff 界（如 Boucheron et al., 2013, Exercise 2.27）来证明，或者也可以再次使用 Kuchibhotla and Chakrabortty (2018, Theorem 3.1)，此时我们取 $\beta := 2/r$，$C_\beta := 4e + 2(2 \log 2)^{r/2}$ 并在 (B.11) 中取 $\lambda_\beta := (4^{1+1/\beta} C_\beta^{-1} e / \sqrt{2}) \|b\|_{\bar{r}} / \|b\|_2$。

提议 A.16(g) 的证明使用了弱收敛定义的以下直接推论。

**引理 B.14.** 在欧氏空间 $E$ 上，若 $(\mu_n)$ 是弱收敛于某 博雷尔 概率测度 $\mu$ 的 博雷尔 概率测度序列，则对任意有限 博雷尔 可测函数 $g: E \to \mathbb{R}$（其在 $\mu$-几乎处处连续，意即 $g$ 的不连续点集 $\mu$-测度为 0），均有 $\int_E g \, d\mu_n \to \int_E g \, d\mu$。

_证明._ 记 $A \subseteq E$ 为 $g$ 的不连续点集，根据假设有 $\mu(A) = 0$。由 Skorokhod 表示定理（如 Kallenberg, 1997, Theorem 3.30），存在定义在共同概率空间上的随机变量 $X, X_1, X_2, \dots$，使得 $X \sim \mu$，对所有 $n$ 均有 $X_n \sim \mu_n$，且 $X_n \to X$ 几乎处处收敛。则在事件 $\{X \in A^c\}$ 上，$g(X_n) \to g(X)$ 几乎处处成立，该事件概率为 $\mu(A^c) = 1$，因此应用主导（或有界）收敛定理即可得 \(\int_E g \, d\mu_n = \mathbb{E}(g(X_n)) \to \mathbb{E}(g(X)) = \int_E g \, d\mu\)，如所要求。\(\square\)

**注释 B.15.** 对于 AMP 递推 (2.1) 中的每个 Lipschitz 函数 \( f_k: \mathbb{R}^2 \rightarrow \mathbb{R} \)，我们在 (A5) 中假设存在某个 \( f'_k \)，其满足上述 引理 B.14 的假设条件且 \(\mu = \lambda \otimes \pi\)；请回顾，\(\lambda\) 表示 \(\mathbb{R}\) 上的 勒贝格 测度，概率分布 \(\pi\) 如 (A1) 中所示。为了说明 (A5) 为何是非空（尽管非常温和）的条件，考虑 \(\mathbb{R}^D\) 上形式为 \(\mu = \lambda \otimes \nu\) 的 博雷尔 概率测度，其中 \(D \ge 2\) 且 \(\nu\) 为 \(\mathbb{R}^{D-1}\) 上的某个概率测度。我们将给出一个 Lipschitz 函数 \( G: \mathbb{R}^D \rightarrow \mathbb{R} \) 的示例，其偏导数 \( \frac{\partial G}{\partial x_1} \) 无法超出其定义域扩展为一个函数 \( g: \mathbb{R}^D \rightarrow \mathbb{R} \)，使得该函数对上述形式的任意 \(\mu\) 均为 \(\mu\)-几乎处处连续。

记 \( C \subseteq [0, 1] \) 为 *肥康托集*（如 Aliprantis and Burkinshaw, 1998, pp. 140–141），其性质为：对所有 \( x \in C \) 和 \( \varepsilon > 0\)，\( (x - \varepsilon, x + \varepsilon) \cap C \) 与 \( (x - \varepsilon, x + \varepsilon) \cap C^c \) 均具有正勒贝格测度。

因此，对任何 \( f: \mathbb{R} \rightarrow \mathbb{R} \) 且 \( f = \mathbb{1}_C \) 几乎处处成立于 勒贝格 测度意义下的情形，对所有 \( x \in C \) 和 \( \varepsilon > 0\)，均有 \( \{f(u) : u \in (x - \varepsilon, x + \varepsilon)\} = \{0, 1\} \)，故 \( f \) 在 \( C \) 上不连续，而 \( C \) 的 勒贝格 测度为 \( 1/2 > 0 \)。注意，\( F: x \mapsto \int_{-\infty}^x \mathbb{1}_C(t) dt \) 是 \(\mathbb{R}\) 上的 Lipschitz 函数，且对 \(\mathbb{R}\) 上几乎处处的 \( x \)，有 \( F'(x) = \mathbb{1}_C(x) \)。因此，对一般的 \( D \in \mathbb{N}\)，函数 \( G: (x_1, \dots, x_D) \mapsto F(x_1) \) 在 \(\mathbb{R}^D\) 上为 Lipschitz。此外，若 \( g: \mathbb{R}^D \rightarrow \mathbb{R}\) 在 \(\frac{\partial G}{\partial x_1}\) 定义的各处与其一致，则 \( g \) 在 \( C \times \mathbb{R}^{D-1} \) 上不连续，而当 \(\mu = \lambda \otimes \nu\)（如上所述）时，该集合具有严格正的 \(\mu\)-测度。
