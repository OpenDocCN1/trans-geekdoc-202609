As a first step towards the proof of Theorem B.17, it is helpful to establish the following.

**Proposition B.16.** There exists a countable set \(T'_r\) of bounded Lipschitz functions on \(\mathbb{R}^D\) with the property that \(\tilde{d}_r(P, Q) = \sup_{\psi \in T'_r} | \int_{\mathbb{R}^D} \psi dP - \int_{\mathbb{R}^D} \psi dQ | \in [0, \infty)\) for all \(P, Q \in \mathcal{P}(r)\).

A key property of the set \(T'_r\) we construct is that for any \(\psi \in \text{PL}_D(r)\), there exists a sequence \((\psi_\ell)\) in \(T'_r\) that converges uniformly to \(\psi\) on compact subsets of \(\mathbb{R}^D\). In subsequent proofs, we will write \(Q(f)\) as shorthand for \(\int_{\mathbb{R}^D} f dQ\) when \(Q\) is a signed Borel measure on \(\mathbb{R}^D\) and \(f : \mathbb{R}^D \to \mathbb{R}\) is a \(Q\)-integrable function.

**Proof.** For \(N \in \mathbb{N}\), let \(B_N \equiv \bar{B}_D(0, N) := \{ x \in \mathbb{R}^D : \|x\| \le N \}\) and define \(f_N(x) := (N - \|x\|) \vee 0 \wedge 1\) for \(x \in \mathbb{R}^D\), so that \(f_N\) is 1-Lipschitz on \(\mathbb{R}^D\), \(f_N = 1\) on \(B_{N-1}\) and \(f_N = 0\) on \(B_N^c\). In the argument below (and in the proof of Theorem B.17), we will use \(f_N\) as a substitute for the (discontinuous) indicator function \(\mathbb{1}_{B_N}\) in several places. Note in particular that if \(\bar{g} : B_N \to \mathbb{R}\) is Lipschitz on \(B_N\), then the function \(g : \mathbb{R}^D \to \mathbb{R}\) defined by \(g(x) := \bar{g}(x)f_N(x)\) is Lipschitz and supported on the compact set \(B_N\).

Recalling the definitions of \(\tilde{d}_r, \mathcal{P}(r)\) from (1.4) and writing \(\widetilde{\text{PL}}_D(r, 1)\) for the set of all \(\phi \in \text{PL}_D(r, 1)\) satisfying \(\phi(0) = 0\), we see from (1.3) that

\(\begin{aligned} \tilde{d}_r(P, Q) &= \sup_{\phi \in \widetilde{\text{PL}}_D(r, 1)} |(P - Q)(\phi)| \le \sup_{\phi \in \widetilde{\text{PL}}_D(r, 1)} (P + Q)(|\phi|) \\ &\le \int_{\mathbb{R}^D} (\|x\| + \|x\|^r) d(P + Q)(x) < \infty \end{aligned} \quad \text{(B.13)}\)

for all \(P, Q \in \mathcal{P}(r)\). If \(\phi \in \widetilde{\text{PL}}_D(r, 1)\), then

\(|\phi(x) - \phi(y)| \le \|x - y\|(1 + \|x\|^{r-1} + \|y\|^{r-1}) \le (1 + 2N^{r-1})\|x - y\|\)

for all \(x, y \in B_N\), so \(\phi|_{B_N}\) belongs to the set of \((1 + 2N^{r-1})\)-Lipschitz functions \(g : B_N \to \mathbb{R}\) satisfying \(g(0) = 0\), which we denote by \(\mathcal{G}_N\).
