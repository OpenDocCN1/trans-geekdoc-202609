

- (B2) \(\sqrt{p/n} \|m^0\|_p \equiv (n^{-1} \sum_{j=1}^p |m_j^0|^2)^{1/2} \xrightarrow{\mathcal{L}} \sigma_0\) 且 \(\|m^0\|_{p,r} \equiv (p^{-1} \cdot \sum_{j=1}^p |m_j^0|^r)^{1/r} = O_c(1)\).

- (B3) 存在一个 Lipschitz 函数 \(F_0: \mathbb{R} \to \mathbb{R}\)，使得当取 \(\bar{\beta} \sim \pi_{\bar{\beta}}\) 时，有 \(\mathbb{E}(F_0(\bar{\beta})^2) \le \sigma_0^2\) 且 \(\langle m^0, \phi(\beta) \rangle_p = p^{-1} \sum_{j=1}^p f_0(h_j^0, \beta_j) \phi(\beta_j) \xrightarrow{\mathcal{L}} \mathbb{E}(F_0(\bar{\beta})\phi(\bar{\beta}))\) 对所有 Lipschitz 函数 \(\phi: \mathbb{R} \to \mathbb{R}\) 成立。

- (B4) 对每个 \(k \in \mathbb{N}_0\)，有 \(\pi_{\bar{\gamma}}(\{y \in \mathbb{R}: x \mapsto g_k(x,y) \text{ 非常数}\}) > 0\) 且 \(\pi_{\bar{\beta}}(\{y \in \mathbb{R}: x \mapsto f_{k+1}(x,y) \text{ 非常数}\}) > 0\).

- (B5) 对每个 \(k \in \mathbb{N}_0\)，记 \(D_k, C_{k+1}\) 分别为 \(g'_k, f'_{k+1}\) 的不连续点集，则有 \((\lambda \otimes \pi_{\bar{\gamma}})(D_k) = (\lambda \otimes \pi_{\bar{\beta}})(C_{k+1}) = 0\)，其中 \(\lambda\) 表示 \(\mathbb{R}\) 上的勒贝格测度。

**状态演化:** 与上文一样，取 \(\sigma_0 > 0\)，归纳定义

\[
\tau_{k+1}^2 := \mathbb{E}(g_k(G_k^\sigma, \bar{\gamma})^2) \quad \text{和} \quad \sigma_{k+1}^2 := \delta^{-1} \mathbb{E}(f_{k+1}(G_{k+1}^\tau, \bar{\beta})^2)
\]

对 \(k \in \mathbb{N}_0\)，其中取 \(G_k^\sigma \sim N(0, \sigma_k^2)\) 与 \(\bar{\beta} \sim \pi_{\bar{\beta}}\) 独立，且取 \(G_{k+1}^\tau \sim N(0, \tau_{k+1}^2)\) 与 \(\bar{\gamma} \sim \pi_{\bar{\gamma}}\) 独立。

**极限协方差结构:** 记 \(\bar{\Sigma}^{[1]} \equiv \bar{\Sigma}_{0,0} := \sigma_0^2\) 且 \(\bar{T}^{[1]} \equiv \bar{T}_{1,1} := \tau_1^2\)，并且对一般的 \(k \in \mathbb{N}\)，归纳假设我们已经定义了半正定矩阵 \(\bar{\Sigma}^{[k]}, \bar{T}^{[k]} \in \mathbb{R}^{k \times k}\)，其元素为 \(\bar{\Sigma}_{ij}^{[k]} = \bar{\Sigma}_{i-1,j-1}^{[k]}\) 和 \(\bar{T}_{ij}^{[k]} = \bar{T}_{i,j}\)（\(1 \le i, j \le k\)）。然后令

\[
\bar{\Sigma}_{k,\ell} = \bar{\Sigma}_{\ell,k} := \begin{cases} \delta^{-1} \mathbb{E}(F_0(\bar{\beta}) \cdot f_k(G_k^\tau, \bar{\beta})) & \text{当 } \ell = 0 \\ \delta^{-1} \mathbb{E}(f_\ell(G_\ell^\tau, \bar{\beta}) \cdot f_k(G_k^\tau, \bar{\beta})) & \text{当 } \ell = 1, \dots, k, \end{cases}
\]

其中 \((G_1^\tau, \dots, G_k^\tau) \sim N_k(0, \bar{T}^{[k]})\) 与 \(\bar{\gamma} \sim \pi_{\bar{\gamma}}\) 独立，并通过 \(\bar{\Sigma}_{ij}^{[k+1]} := \bar{\Sigma}_{i-1,j-1}^{[k+1]}\)（\(1 \le i, j \le k+1\)）定义 \(\bar{\Sigma}^{[k+1]} \in \mathbb{R}^{(k+1) \times (k+1)}\)。如 (2.7) 中所述，容易验证 \(\bar{\Sigma}^{[k+1]}\) 是半正定的。此外，令

\[
\bar{T}_{k+1,\ell} = \bar{T}_{\ell, k+1} := \mathbb{E}(g_{\ell-1}(G_{\ell-1}^\sigma, \bar{\gamma}) \cdot g_k(G_k^\sigma, \bar{\gamma})) \quad \text{当 } \ell = 1, \dots, k+1,
\]

其中 \((G_0^\sigma, \dots, G_k^\sigma) \sim N_{k+1}(0, \bar{\Sigma}^{[k+1]})\) 与 \(\bar{\beta} \sim \pi_{\bar{\beta}}\) 独立，并通过 \(\bar{T}_{ij}^{[k+1]} := \bar{T}_{i,j}\)（\(1 \le i, j \le k+1\)）定义，使得得到的矩阵

\(\bar{T}^{[k+1]} \in \mathbb{R}^{(k+1)\times(k+1)}\) 同样是半正定的。在 (B4) 下，如引理 2.2 所示，可以证得对所有 \(k \in \mathbb{N}\)，\(\bar{\Sigma}^{[k]}, \bar{T}^{[k]}\) 都是正定的，并且 (2.12)-(2.13) 扩展了 (2.11)，其中对所有 \(k\)，\(\sigma_{k-1}^2 = \bar{\Sigma}_{k-1, k-1} > 0\) 且 \(\tau_k^2 = \bar{T}_{k, k} > 0\)。

## 定理 2.5.

假设 (B0)-(B5) 对于由 \(n \in \mathbb{N}\) 和 \(p \equiv p_n\) 索引、且 \(n/p \to \delta \in (0, \infty)\) 的非对称 AMP 递归 (2.10) 序列成立。那么对每个固定的 \(k \in \mathbb{N}_0\)，有

\[
\tilde{d}_r(\nu_n(e^k, \gamma), N(0, \sigma_k^2) \otimes \pi_{\bar{\gamma}})
= \sup_{\psi \in \mathrm{PL}_2(r, 1)} \left| \frac{1}{n} \sum_{i=1}^n \psi(e_i^k, \gamma_i) - \mathbb{E}(\psi(G_k^\sigma, \bar{\gamma})) \right| \xrightarrow{\mathrm{p}} 0, \quad (2.14)
\]

\[
\tilde{d}_r(\nu_p(h^{k+1}, \beta), N(0, \tau_{k+1}^2) \otimes \pi_{\bar{\beta}})
= \sup_{\psi \in \mathrm{PL}_2(r, 1)} \left| \frac{1}{p} \sum_{j=1}^p \psi(h_j^{k+1}, \beta_j) - \mathbb{E}(\psi(G_{k+1}^\tau, \bar{\beta})) \right| \xrightarrow{\mathrm{p}} 0,
\]

\[
\tilde{d}_r(\nu_n(e^0, \dots, e^k, \gamma), N_{k+1}(0, \bar{\Sigma}^{[k+1]}) \otimes \pi_{\bar{\gamma}})
= \sup_{\psi \in \mathrm{PL}_{k+2}(r, 1)} \left| \frac{1}{n} \sum_{i=1}^n \psi(e_i^0, \dots, e_i^k, \gamma_i) - \mathbb{E}(\psi(G_0^\sigma, \dots, G_k^\sigma, \bar{\gamma})) \right| \xrightarrow{\mathrm{p}} 0, \quad (2.15)
\]

\[
\tilde{d}_r(\nu_p(h^1, \dots, h^{k+1}, \beta), N_{k+1}(0, \bar{T}^{[k+1]}) \otimes \pi_{\bar{\beta}})
= \sup_{\psi \in \mathrm{PL}_{k+2}(r, 1)} \left| \frac{1}{p} \sum_{j=1}^p \psi(h_j^1, \dots, h_j^{k+1}, \beta_j) - \mathbb{E}(\psi(G_1^\tau, \dots, G_{k+1}^\tau, \bar{\beta})) \right| \xrightarrow{\mathrm{p}} 0
\]

当 \(n \to \infty\) 时。用 \(d_r\) 替代 \(\tilde{d}_r\) 时，等价结论同样成立。

结合第 2.1 节的主定理，定理 2.5 可推广到带有矩阵值迭代的抽象 AMP 递归；参见第 A.7 节。

类似于定理 2.1 之后的讨论，可以论证：对每个 \(k \in \mathbb{N}_0\)，(2.14) 中的高斯分布 \(N(0, \sigma_k^2)\) 和 \(N(0, \tau_{k+1}^2)\) 分别是玩具递归中 \(\breve{e}^k \in \mathbb{R}^n\) 和 \(\breve{h}^{k+1} \in \mathbb{R}^p\) 的元素经验分布的 \(d_r\) 极限

\[
\breve{e}^0 := \tilde{W}^0 m^0, \qquad \breve{h}^{k+1} := \tilde{W}^k g_k(\breve{e}^k, \gamma),
\]
\[
\breve{e}^{k+1} := \tilde{W}^{k+1} f_k(\breve{h}^{k+1}, \beta) \qquad \text{for } k \in \mathbb{N}_0 \quad (2.16)
\]

当 \(n, p \to \infty\) 且 \(n/p \to \delta\) 时。这里，每次迭代都包含一个新矩阵，其元素为 i.i.d. \(N(0, 1/n)\)，且与迄今为止的一切独立。在原始抽象迭代 (2.10) 中，整个过程中使用相同的高斯矩阵 \(W\)。Onsager 修正项 \(-b_k q^{k-1}\) 和 \(-c_k m^k\) 的设计是为了确保 \(e^k \in \mathbb{R}^n\) 和 \(h^{k+1} \in \mathbb{R}^p\) 分别与 \(\breve{e}^k\) 和 \(\breve{h}^{k+1}\) 具有相同的极限行为。然而，我们注意到 (2.15) 中的渐近联合经验分布通常与 (2.16) 中的不同。确实，(2.16) 中的极限协方差矩阵是对角矩阵，而 (2.12)-(2.13) 中的 \(\tilde{\Sigma}\) 和 \(\tilde{T}\) 通常不是对角矩阵：有关对称递归 (2.1) 和 (2.5) 的类似比较，请参见第 2.1 节末尾。

建立定理 2.5 的一种方法是直接分析非对称递归 (2.10)，通过调整对称迭代 (2.1) 的定理 2.3 证明中的技术和论证。一个重要的第一步是获得命题 A.11 的类比，以表征给定输入 \(m^0, \beta, \gamma\) 和所有先前迭代时，(2.10) 中每个迭代的条件分布。然后这为沿着命题 A.16 (Bayati 和 Montanari, 2011) 的思路进行归纳证明奠定了基础。Rush 和 Venkataramanan (2018) 在其假设的有限样本类比下建立了定理 2.5 的有限样本版本（参见备注 A.3）。

建立定理 2.5 的另一种推导方法是首先将 (2.10) 嵌入到合适的对称递归中（包含 GOE(\(n+p\)) 矩阵），其在 \(k \in \mathbb{N}_0\) 次迭代时的输出在 \(k = 2\ell\) 时包含 \(h^\ell\)，在 \(k = 2\ell + 1\) 时包含 \(e^k\)（Javanmard 和 Montanari, 2013; Berthier 等人, 2020）。该增广递归的构建基于原始对称迭代 (2.1) 的一个略微更一般的版本，该版本提供了额外的灵活性，可以对每个 AMP 迭代的不同分量应用（两个）不同的 Lipschitz 函数。
