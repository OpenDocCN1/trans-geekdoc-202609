
## Complete convergence:

(ii) \(\Rightarrow\) (iii) \(\Rightarrow\) (i): As above, we can argue along subsequences of \((P_n)\) and then appeal directly to the corresponding implications in (a).

(i) \(\Rightarrow\) (ii): Suppose that \(P_n(\psi) \xrightarrow{c} P(\psi)\) for every \(\psi \in \text{PL}_D(r)\). In view of Definition 1.1 of complete convergence, it suffices to show that if \((\beta_n)\) is any sequence of random variables with \(\beta_n \stackrel{d}{=} \tilde{d}_r(P_n, P)\) for each \(n\), then \(\beta_n \xrightarrow{a.s.} 0\). For any such sequence \((\beta_n)\), we first seek to construct a sequence \((\tilde{P}_n)\) of random elements \(\tilde{P}_n : \Omega \to (\mathcal{P}(r), \tilde{d}_r)\) such that \(\tilde{P}_n \stackrel{d}{=} P_n\) on \((\mathcal{P}(r), \mathcal{B}_r)\) for each \(n\) and \((\tilde{d}_r(\tilde{P}_n, P) : n \in \mathbb{N}) = (\beta_n : n \in \mathbb{N})\) almost surely as random sequences. Since \((\mathcal{P}(r), \tilde{d}_r)\) is a Polish space, a suitable \((\tilde{P}_n)\) can be obtained by applying Lemma B.10, where for each \(n\), we take \(g_n : (\mathcal{P}(r), \tilde{d}_r) \to \mathbb{R}\) to be the 1-Lipschitz (and hence Borel measurable) function \(Q \mapsto \tilde{d}_r(P, Q)\).

For each \(\psi \in \text{PL}_D(r)\), we see from the definition of \(\tilde{d}_r\) in (1.4) that \(Q \mapsto Q(\psi) = \int_{\mathbb{R}^D} \psi \, dQ\) is also a 1-Lipschitz (and hence Borel measurable) function from \((\mathcal{P}(r), \tilde{d}_r)\) to \(\mathbb{R}\), so \(\tilde{P}_n(\psi) : \Omega \to \mathbb{R}\) is measurable (i.e. a random variable). Now \(\tilde{P}_n \stackrel{d}{=} P_n\) for each \(n\) by construction, so for every \(\psi \in \text{PL}_D(r)\), it follows that \(\tilde{P}_n(\psi) \stackrel{d}{=} P_n(\psi)\) for each \(n\) and hence that \(\tilde{P}_n(\psi) \xrightarrow{a.s.} P(\psi)\). Thus, by the implication (i) \(\Rightarrow\) (ii) in (a) above, we conclude that \(\beta_n = \tilde{d}_r(\tilde{P}_n, P) \to 0\) almost surely, as required.

(ii) \(\Rightarrow\) (iii) \(\Rightarrow\) (i): To establish these remaining implications, observe that it suffices to show the following: if \(F_n, G_n : \mathcal{P}(r) \to \mathbb{R}\) are Borel measurable functions for which it is known from (a) that \(F_n(P_n) \xrightarrow{a.s.} 0\) implies \(G_n(P_n) \xrightarrow{a.s.} 0\), then \(F_n(P_n) \xrightarrow{c} 0\) implies \(G_n(P_n) \xrightarrow{c} 0\). To prove this, we can proceed as in the argument for (i) \(\Rightarrow\) (ii): given any random sequence \((\beta_n)\) such that \(\beta_n \stackrel{d}{=} G_n(P_n)\) for each \(n\), Lemma B.10 yields a sequence \((\tilde{P}_n)\) of random elements \(\tilde{P}_n : \Omega \to \mathcal{P}(r)\) such that \(F_n(\tilde{P}_n) \stackrel{d}{=} F_n(P_n)\) and \(\beta_n = G_n(\tilde{P}_n)\) almost surely for each \(n\). Then \(F_n(\tilde{P}_n) \xrightarrow{a.s.} 0\), so (a) implies that \(\beta_n = G_n(\tilde{P}_n) \to 0\) almost surely. This completes the proof. \(\square\)

We conclude this subsection with some straightforward results on pseudo-Lipschitz functions.

### **Lemma B.22.** For \(D \in \mathbb{N}\), if \(f \in \text{PL}_D(r)\) and \(g \in \text{PL}_D(s)\) for some \(r, s \ge 1\), then \(fg \in \text{PL}_D(r + s)\) and \(|f|^p \in \text{PL}_D(pr)\) for all \(p \ge 1\).

**Proof.** There exists \(L > 0\) such that \(f \in \text{PL}_D(r, L)\) and \(g \in \text{PL}_D(s, L)\). Letting \(L' := L \vee |f(0)| \vee |g(0)|\), we have

$$
\begin{aligned}
|f(x)| &\le |f(0)| + |f(x) - f(0)| \le L'(1 + \|x\| + \|x\|^r) \le 2L'(1 + \|x\|^r)\\
|g(x)| &\le |g(0)| + |g(x) - g(0)| \le L'(1 + \|x\| + \|x\|^s) \le 2L'(1 + \|x\|^s)
\end{aligned}
\tag{B.19}
$$

for all \(x \in \mathbb{R}^D\). Therefore, fixing arbitrary \(x, y \in \mathbb{R}^D\) and setting \(a := \|x\| \vee \|y\|\), we see that

$$
\begin{aligned}
|f(x)g(x) - f(y)g(y)|
&\le |f(x)| \, |g(x) - g(y)| + |g(x)| \, |f(x) - f(y)|\\
&\le 2L' L \|x - y\| \{ (1 + \|x\|^r)(1 + \|x\|^{s-1} + \|y\|^{s-1})\\
&\qquad + (1 + \|x\|^s)(1 + \|x\|^{r-1} + \|y\|^{r-1}) \}\\
&\le 2L' L \|x - y\| (2 + 2a^{r-1} + a^r + 2a^{s-1} + a^s + 4a^{r+s-1})\\
&\le 20 L' L \|x - y\| (1 + a^{r+s-1})\\
&\le 20 L' L \|x - y\| (1 + \|x\|^{r+s-1} + \|y\|^{r+s-1}).
\end{aligned}
$$

This shows that \(fg \in \text{PL}_D(r + s)\). For \(p \ge 1\), we have \((a + b)^{p-1} \le (1 \vee 2^{p-2})(a^{p-1} + b^{p-1})\) for \(a, b \ge 0\), and it follows from Lemma B.20 and (B.19) that

$$
\begin{aligned}
\bigl||f(x)|^p - |f(y)|^p\bigr|
&\le \frac{p \vee 2}{2} |f(x) - f(y)| (|f(x)|^{p-1} + |f(y)|^{p-1})\\
&\le \frac{L(2L')^{p-1}(p \vee 2)}{2} \|x - y\| (1 + \|x\|^r + \|y\|^r)\\
&\qquad \cdot \bigl((1 + \|x\|^r)^{p-1} + (1 + \|y\|^r)^{p-1}\bigr)\\
&\lesssim_p L(L')^{p-1} \|x - y\| (1 + \|x\|^r + \|y\|^r)(1 + \|x\|^{(p-1)r} + \|y\|^{(p-1)r})\\
&\lesssim_p L(L')^{p-1} \|x - y\| (1 + \|x\|^{pr} + \|y\|^{pr})
\end{aligned}
$$

for all \(x, y \in \mathbb{R}^D\). Thus, \(|f|^p \in \text{PL}_D(pr)\), as required.

### **Lemma B.23.** Let \(\psi \in \text{PL}_{D+1}(r, L)\) for some \(D \in \mathbb{N}\), \(r \ge 1\) and \(L > 0\).
Fix \(c \equiv (c_1, \dots, c_D) \in \mathbb{R}^D\) and \(\tau > 0\).

- (a) For fixed \(x \equiv (x_1, \dots, x_D) \in \mathbb{R}^D\), define \(\psi_x: \mathbb{R} \to \mathbb{R}\) by \(\psi_x(z) := \psi(x_1, \dots, x_D, \sum_{\ell=1}^D c_\ell x_\ell + \tau z)\). Then \(\psi_x \in \text{PL}_1(r, L_{\|x\|, \tau})\), where \(L_{a, \tau} := L \tau \max\{1 + (2 \lor 2^{r-1})(1 + \|c\|)^{r-1} a^{r-1}, (1 \lor 2^{r-2})\tau^{r-1}\}\) for \(a \ge 0\).

- (b) Let \(Z \sim N(0,1)\) and define \(\Psi: \mathbb{R}^D \to \mathbb{R}\) by \(\Psi(x_1, \dots, x_D) := \mathbb{E}\{\psi(x_1, \dots, x_D, \sum_{\ell=1}^D c_\ell x_\ell + \tau Z)\}\). Then \(\Psi \in \text{PL}_D(r, L_\tau)\), where \(L_\tau := L(1 + \|c\|) \max\{1 + (2 \lor 2^{r-1}) \mathbb{E}(|\tau Z|^{r-1}), (1 \lor 2^{r-2})(1 + \|c\|)^{r-1}\}\).

**Proof.** For \(x \equiv (x_1, \dots, x_D) \in \mathbb{R}^D\) and \(z \in \mathbb{R}\), note first that

$$
\begin{aligned}
\bigl\|(x_1, \dots, x_D, \sum_{\ell=1}^D c_\ell x_\ell + \tau z)\bigr\|^{r-1}
&\le (\|x\| + |\sum_{\ell=1}^D c_\ell x_\ell| + \tau |z|)^{r-1}\\
&\le \{(1 + \|c\|)\|x\| + \tau |z|\}^{r-1}\\
&\le (1 \lor 2^{r-2}) \{(1 + \|c\|)^{r-1} \|x\|^{r-1} + \tau^{r-1} |z|^{r-1}\},
\end{aligned}
$$

where the three bounds above are obtained using the triangle inequality, the Cauchy–Schwarz inequality and the fact that \((a + b)^{r-1} \le (1 \lor 2^{r-2})(a^{r-1} + b^{r-1})\) for \(a, b \ge 0\).

- (a) For \(z, z' \in \mathbb{R}\), we have

$$
\begin{aligned}
|\psi_x(z) - \psi_x(z')|
&= |\psi(x_1, \dots, x_D, \sum_{\ell=1}^D c_\ell x_\ell + \tau z) - \psi(x_1, \dots, x_D, \sum_{\ell=1}^D c_\ell x_\ell + \tau z')|\\
&\le L \tau |z - z'| \{1 + 2(1 \lor 2^{r-2})(1 + \|c\|)^{r-1} \|x\|^{r-1}\\
&\qquad + (1 \lor 2^{r-2}) \tau^{r-1} (|z|^{r-1} + |z'|^{r-1})\}\\
&\le L_{\|x\|, \tau} |z - z'| (1 + |z|^{r-1} + |z'|^{r-1}),
\end{aligned}
$$

where the first bound follows from (B.21) and the fact that \(\psi \in \text{PL}_{D+1}(r, L)\).

- (b) For \(x, y \in \mathbb{R}^D\), we have

$$
\begin{aligned}
|\Psi(x) - \Psi(y)|
&\le \mathbb{E}\bigl[|\psi(x_1, \dots, x_D, \sum_{\ell=1}^D c_\ell x_\ell + \tau Z)\\
&\qquad - \psi(y_1, \dots, y_D, \sum_{\ell=1}^D c_\ell y_\ell + \tau Z)|\bigr]\\
&\le L(1 + \|c\|)\|x - y\| \{1 + 2(1 \vee 2^{r-2}) \mathbb{E}(|\tau Z|^{r-1})\\
&\qquad + (1 \vee 2^{r-2})(1 + \|c\|)^{r-1}(\|x\|^{r-1} + \|y\|^{r-1})\}\\
&\le L_\tau\|x - y\| (1 + \|x\|^{r-1} + \|y\|^{r-1}),
\end{aligned}
$$

where the second bound again follows from (B.20), (B.21) and the fact that \(\psi \in \text{PL}_{D+1}(r, L)\).

### **Lemma B.24.** Suppose that \(\psi \in \text{PL}_D(r, L)\) for some \(D \in \mathbb{N}\), \(r \in [2, \infty)\) and \(L > 0\). Then for any \(n \in \mathbb{N}\) and vectors \(x^\ell \equiv (x_1^\ell, \dots, x_n^\ell)\) and \(y^\ell \equiv (y_1^\ell, \dots, y_n^\ell)\) for \(1 \le \ell \le D\), we have

$$
\frac{1}{n} \sum_{i=1}^n |\psi(x_i^1, \dots, x_i^D) - \psi(y_i^1, \dots, y_i^D)|
\le LD^{\frac{r}{2}-1} \left( \sum_{\ell=1}^D \|x^\ell - y^\ell\|_{n,r}^r \right)^{1/r} \left( 1 + \sum_{\ell=1}^D (\|x^\ell\|_{n,r}^{r-1} + \|y^\ell\|_{n,r}^{r-1}) \right).
$$

**Proof.** For \(1 \le i \le n\), define \(X^{(i)} := (x_i^1, \dots, x_i^D)\) and \(Y^{(i)} := (y_i^1, \dots, y_i^D)\), and let \(r' := r/(r-1) \in (1, 2]\) be the Hölder conjugate of \(r\), so that \(1/r + 1/r' = 1\). Then since \(\psi \in \text{PL}_D(r, L)\), an application of Hölder's inequality yields the bound

$$
\begin{aligned}
\frac{1}{n} \sum_{i=1}^n |\psi(x_i^1, \dots, x_i^D) - \psi(y_i^1, \dots, y_i^D)|
&= \frac{1}{n} \sum_{i=1}^n |\psi(X^{(i)}) - \psi(Y^{(i)})|\\
&\le \frac{1}{n} \sum_{i=1}^n L\|X^{(i)} - Y^{(i)}\| (1 + \|X^{(i)}\|^{r-1} + \|Y^{(i)}\|^{r-1})\\
&\le L \left( \frac{1}{n} \sum_{i=1}^n \|X^{(i)} - Y^{(i)}\|^r \right)^{1/r} \left( \frac{1}{n} \sum_{i=1}^n (1 + \|X^{(i)}\|^{r-1} + \|Y^{(i)}\|^{r-1})^{r'} \right)^{1/r'}.
\end{aligned}
$$
