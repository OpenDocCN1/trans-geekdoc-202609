

独立高斯变量伪李普希茨函数和的浓度结果（Lemma B.12），随后我们重新引入 \(\gamma, m^0, h^1, \dots, h^k\) 中的随机性，并应用归纳假设 \(\mathcal{H}_k(c)\) 来解释这一点。 \(\mathcal{H}_{k+1}(c)\) 右侧新出现的极限高斯变量 \(\bar{G}_{k+1}\)（除了来自 \(\mathcal{H}_k(c)\) 的现有 \(\bar{G}_1, \dots, \bar{G}_k\) 之外）可以通过其在 (A.16) 中的定义来解释，该定义与 \(\tilde{h}^{k+1}\) 的定义 (A.21) 以及我们刚刚概述的两阶段论证完美匹配；参见证明中的 (A.40) 和 (A.41)。

\(\mathcal{H}_{k+1}(d)\): 此证明的思路与 \(\mathcal{H}_{k+1}(c)\) 类似，只不过还用到了条件 (A3)。还需注意，\(\mathcal{H}_{k+1}(d)\) 仅适用于 Lipschitz \(\phi: \mathbb{R}^{k+2} \rightarrow \mathbb{R}\)，而非一般 \(\phi \in \text{PL}_{k+2}(r)\)，但这对于后续 \(\mathcal{H}_{k+1}(e, f)\) 的证明已足够。

我们针对 \(\mathcal{H}_{k+1}(c, d)\) 给出的证明结合了现有 AMP 文献中渐近论证与有限样本论证的要点（参见 Remark A.3）。Fan (2022) 中的 Proposition E.1 为另一种渐近方法提供了基础，其细节我们略去不表。

## A.5 第 2.1 节和第 A.1 节的证明

*Proposition A.16 的证明。* 由于我们进行的是渐近分析，在每个 \(k \in \mathbb{N}\) 的 \(\mathcal{H}_k(a, \dots, i)\) 证明中，可以不失一般性地假设 \(n > k\)；这使我们能够应用第 A.2 节关于条件分布的结果。还需注意，我们在证明的不同部分使用 \(T_n, T_{n1}, T'_{n1}, T_{n2}\) 来指代不同感兴趣的量。在 Lemma B.2 和 Remark B.3 中，我们给出了关于完全收敛的连续映射定理和 Slutsky 引理的版本，以及 \(o_c\) 和 \(O_c\) 符号的“运算规则”。我们将在下面的论证中反复应用这些结果，通常不作进一步说明或解释。

首先，我们证明 \(\mathcal{H}_1(a, b, c, d)\)，它们构成了归纳的基础情形。

\(\mathcal{H}_1(a)\): 根据 (A.20)，\(\Delta^1 \equiv \Delta^1(n) = (\|m^0\|_n - \tau_1)\tilde{Z}^1 + \tilde{\zeta}^1 m^0\)，其中对于每个 \(n\)，\((\tilde{Z}^1, \tilde{\zeta}^1) \equiv (\tilde{Z}^1(n), \tilde{\zeta}^1(n)) \sim N_n(0, I_n) \otimes N(0, 1/n)\)。取 \(\zeta \sim N(0, 1)\)，根据 Example 1(a)，我们有 \(|\tilde{\zeta}^1| \stackrel{d}{=} n^{-1/2} |\zeta| \rightarrow^p 0\)，根据 Lemma B.12 和 Proposition 1.2，\(\|\tilde{Z}^1\|_{n,r} = (n^{-1} \sum_{i=1}^n |\tilde{Z}_i^1|^r)^{1/r} \xrightarrow{\mathcal{D}} \mathbb{E}(|\zeta|^r)^{1/r} \in (0, \infty)\)。此外，根据 (A2)，\(\|m^0\|_n - \tau_1 \xrightarrow{p} 0\) 且 \(\|m^0\|_{n,r} = O_c(1)\)。将一切结合起来，我们从 Remark B.3 中回忆起 \(o_c\) 和 \(O_c\) 符号的“运算规则” (B.1)，并利用 \(\|\cdot\|_{n,r}\) 的三角不等式得出：

```
\(\|\Delta^1\|_{n,r} \le \| \|m^0\|_n - \tau_1 \| \|\tilde{Z}^1\|_{n,r} + |\tilde{\zeta}^1| \|m^0\|_{n,r}\)
\(= o_c(1) O_c(1) + o_c(1) O_c(1) = o_c(1)\).
```

\(\mathcal{H}_1(b)\): 回顾 Proposition A.11 中的 (A.5) 和 (A.20)，对于每个 \(n \in \mathbb{N}\)，有

```
\(h^1 \equiv h^1(n) \stackrel{d}{=} |\mathcal{S}_0| \tilde{h}^1(n) + \Delta^1(n) = h^{1,0}(n) \equiv h^{1,0}\) (A.23)
```

对于每个 \(n \in \mathbb{N}\)，其中 \(\tilde{h}^1 \equiv \tilde{h}^1(n) = \tau_1 \tilde{Z}^1\)，且 \(\tilde{Z}^1 \sim N_n(0, I_n)\) 独立于 \(\mathcal{S}_0 = \sigma(\gamma, m^0)\)。那么根据 \(\mathcal{H}_1(a)\)，\(\|\Delta^1\|_{n,r} = o_c(1)\)，且与 \(\mathcal{H}_1(a)\) 的证明类似，\(\|\tilde{h}^1\|_{n,r} = \tau_1 \|\tilde{Z}^1\|_{n,r} = O_c(1)\)，因此

```
\(\|h^1\|_{n,r} \stackrel{d}{=} \|h^{1,0}\|_{n,r} \le \|\tilde{h}^1\|_{n,r} + \|\Delta^1\|_{n,r} = O_c(1) + o_c(1) = O_c(1)\).
```

根据 (A2)，我们已有 \(\|m^0\|_{n,r} = O_c(1)\)。此外，根据 (A1)，\(\|\gamma\|_{n,r} = (n^{-1} \sum_{i=1}^n |\gamma_i|^r)^{1/r} \xrightarrow{\mathcal{D}} \mathbb{E}(|\bar{\gamma}|^r)^{1/r}\)，因此 \(\|\gamma\|_{n,r} = O_c(1)\)。令 \(L' > 0\) 使得 AMP 递推 (2.1) 中的函数 \(f_1\) 属于 \(\text{PL}_2(1, L')\)，则对所有 \((x, y) \in \mathbb{R}^2\)，有 \(|f_1(x, y)| \le |f_1(0, 0)| + L'(|x| + |y|)\)，因此我们可以对 \(\|\cdot\|_{n,r}\) 应用三角不等式来推断：

```
\(\|m^1\|_{n,r} = \|f_1(h^1, \gamma)\|_{n,r} \le |f_1(0, 0)| \|\mathbf{1}_n\|_{n,r} + L'(\|h^1\|_{n,r} + \|\gamma\|_{n,r}) = O_c(1)\).
```

\(\mathcal{H}_1(c)\): 对于每个 \(n\)，根据 (A.23) 和 Lemma B.6(c)，注意到 \((\gamma, h^1) \stackrel{d}{=} |\mathcal{S}_0| (\gamma, h^{1,0})\)。因此，对每个固定的 \(\psi \in \text{PL}_2(r)\)，对于每个 \(n\)，都有 \(n^{-1} \cdot \sum_{i=1}^n \psi(h_i^1, \gamma_i) \stackrel{d}{=} n^{-1} \sum_{i=1}^n \psi(h_i^{1,0}, \gamma_i) =: T_n\)，因此根据 Remark A.1 中的第三点，只需证明当 \(n \to \infty\) 时 \(T_n \xrightarrow{\mathcal{D}} \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma}))\)。为此，我们写

```
\(T_n = \frac{1}{n} \sum_{i=1}^n \psi(\tilde{h}_i^1, \gamma_i) + \frac{1}{n} \sum_{i=1}^n \{ \psi(h_i^{1,0}, \gamma_i) - \psi(\tilde{h}_i^1, \gamma_i) \} =: T_{n1} + T_{n2}\)
```

对于每个 \(n\)，并旨在证明 \(T_{n1} \xrightarrow{\mathcal{D}} \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma}))\) 且 \(T_{n2} \xrightarrow{p} 0$，这两者共同蕴含所需结论。

在继续之前，我们简要描述用于确定 \((T_{n1})\) 极限的技术，以及稍后用于证明 \(\mathcal{H}_1(d)\) 和 \(\mathcal{H}_{k+1}(c,d)\) 的技术。考虑以下两个特例是有启发性的，在这些特例中结论更容易建立。如果 \(\psi\) 仅取决于其第一个参数，那么由于对每个 \(n\) 都有 \(h^l(n) = \tau_1 \bar{Z}^1(n)\) 且 \(\bar{Z}^1(n) \sim N_n(0, I_n)\)，结果很容易从 Lemma B.12 中的浓度不等式 (B.6) 和 Proposition 1.2 中的完全收敛刻画得出。另一方面，如果 \(\psi\) 仅取决于其第二个参数，那么由于假设 \((\gamma \equiv \gamma(n) : n \in \mathbb{N})\) 满足 (A1)，我们可以直接引用 Corollary B.21(b)。

对一般 \(\psi \in \text{PL}_2(r)\)，我们试图结合这两种不同的推理思路，利用每个 \(n\) 中 \(\tilde{h}^1(n)\) 与 \(\mathcal{S}_0 \equiv \mathcal{S}_0(n) = \sigma(\gamma, m^0)\) 的独立性。这使得我们在分别用 (A.24) 和 (A.25) 将 \(T_{n1}\) 分解为 \(\mathbb{E}(T_{n1} | \mathcal{S}_0)\) 与 \(T_{n1} - \mathbb{E}(T_{n1} | \mathcal{S}_0)\) 的和时，可以在很大程度上分别处理 \(\gamma(n)\) 和 \(\tilde{h}^1(n)\)。对于后者，在对高斯变量 \(\tilde{h}^1\) 应用 Lemma B.12 时，首先将 \(\gamma(n)\) 视为固定是有帮助的，随后再利用 (A1) 来处理 \(\gamma(n)\) 的随机性。

定义 \(\Psi: \mathbb{R} \to \mathbb{R}\) 为 \(\Psi(y) := \mathbb{E}(\psi(\tau_1 Z, y))\)，其中 \(Z \sim N(0,1)\)。对于每个 \(n\)，由于 \(\tilde{Z}^1 \equiv \tilde{Z}^1(n) \sim N_n(0, I_n)\) 独立于 \(\mathcal{S}_0 \equiv \mathcal{S}_0(n) = \sigma(\gamma, m^0)\)，根据 Lemma B.7，对每个 \(1 \le i \le n\)，几乎必有 \(\mathbb{E}(\psi(\tilde{h}_i^1, \gamma_i) | \mathcal{S}_0) = \mathbb{E}(\psi(\tau_1 \bar{Z}_i^1, \gamma_i) | \mathcal{S}_0) = \Psi(\gamma_i)\)。由于根据 Lemma B.23(b) 有 \(\Psi \in \text{PL}_1(r)\)，根据 (A1) 和 Corollary B.21(b)，当 \(n \to \infty\) 时 \(n^{-1} \sum_{i=1}^n \Psi(\gamma_i) \xrightarrow{c} \mathbb{E}(\Psi(\bar{\gamma}))\)，其中 \(\bar{\gamma} \sim \pi\)。再次应用 Lemma B.7 表明，如果 \(\bar{G}_1 \sim N(0, \tau^2)\) 独立于 \(\bar{\gamma}\)，则 \(\mathbb{E}(\Psi(\bar{\gamma})) = \mathbb{E}(\mathbb{E}\{\psi(\bar{G}_1, \bar{\gamma}) | \bar{\gamma}\}) = \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma}))\)，因此总结起来，我们有

```
\(\frac{1}{n} \sum_{i=1}^n \mathbb{E}(\psi(\tilde{h}_i^1, \gamma_i) | \mathcal{S}_0) = \frac{1}{n} \sum_{i=1}^n \Psi(\gamma_i) \xrightarrow{c} \mathbb{E}(\Psi(\bar{\gamma})) = \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma})).\) (A.24)
```

为了完成 \(T_{n1} \xrightarrow{c} \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma}))\) 的证明，因此我们必须证明

```
\(T'_{n1} := \frac{1}{n} \sum_{i=1}^n \{ \psi(\tilde{h}_i^1, \gamma_i) - \mathbb{E}(\psi(\tilde{h}_i^1, \gamma_i) | \mathcal{S}_0) \} \xrightarrow{c} 0\) (A.25)
```
