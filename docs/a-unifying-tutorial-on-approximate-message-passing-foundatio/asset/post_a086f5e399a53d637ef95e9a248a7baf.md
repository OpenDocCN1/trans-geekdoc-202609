
now integrate up the bound (B.9) to see that

```
\(\mathbb{E}(\vartheta_\beta(|X_i|/\theta_i)) = \int_0^\infty \mathbb{P}(\vartheta_\beta(|X_i|/\theta_i) \ge t) \, dt = \int_0^\infty \mathbb{P}(|X_i| \ge \theta_i \vartheta_\beta^{-1}(t)) \, dt\)
\(= \int_0^\infty \mathbb{P}(|X_i| \ge 2(r+1)^{r/2} L_i \{4 \log(1+t)\}^{1/\beta}) \, dt\)
\(\le \int_0^\infty e(1+t)^{-4} \, dt = e/3 < 1,\) (B.10)
```

whence \(\Xi_{\vartheta_\beta}(X_i) \le \theta_i = 2\{4(r+1)\}^{r/2} L_i < \infty\). This shows that \(X_1,\dots,X_n\) are independent, centred _sub-Weibull_ random variables of order \(\beta = 2/r\), in the sense of Definition 2.2 in Kuchibhotla and Chakrabortty (2018). Then applying Kuchibhotla and Chakrabortty (2018, Theorem 3.1) with \(a = (1/n,\dots,1/n) \in \mathbb{R}^n\) and \(b := (\Xi_{\vartheta_\beta}(X_1)/n,\dots,\Xi_{\vartheta_\beta}(X_n)/n)\) in their notation, we deduce from (B.10) that

```
\(\Xi_{\vartheta_\beta, \lambda_\beta} \left( \frac{1}{n} \sum_{i=1}^n X_i \right) \le 2 e C_\beta \|b\|_2, \quad \text{where}\)
\(\left\{ \begin{array}{l} C_\beta := (2e^{2/e}/\beta)^{1/\beta}(128\pi)^{1/4} e^{3+\frac{1}{24}} \\ \lambda_\beta := (4^{1/\beta}/\sqrt{2}) \, \|b\|_\infty / \|b\|_2. \end{array}\right.\) (B.11)
```

It then follows from Proposition A.3 in Kuchibhotla and Chakrabortty (2018) that

```
\(\mathbb{P} \left( \left| \frac{1}{n} \sum_{i=1}^n X_i \right| \ge 4 e C_\beta \|b\|_2 \max(s^{1/2}, \lambda_\beta s^{1/\beta}) \right) \le e^{1-s}\)
```

for all \(s \ge 0\), and hence that

```
\(\mathbb{P} \left( \left| \frac{1}{n} \sum_{i=1}^n X_i \right| \ge t \right) \le \exp \left( 1 - \min \left\{ \left( \frac{t}{4 e C_\beta \|b\|_2} \right)^2, \left( \frac{t}{4 e C'_\beta \|b\|_\infty} \right)^\beta \right\} \right)\)
```

for all \(t \ge 0\), where \(C'_\beta := (4^{1/\beta}/\sqrt{2}) C_\beta\). Since \(\beta = 2/r\) and \(\Xi_{\vartheta_\beta}(X_i) \le 2\{4(r+1)\}^{r/2} L_i\) for \(1 \le i \le n\), we have

```
\(n \|b\|_p = \| (\Xi_{\vartheta_\beta}(X_1), \dots, \Xi_{\vartheta_\beta}(X_n)) \|_p \le 2\{4(r+1)\}^{r/2} \|L\|_p\)
```

for \(p \in \{2, \infty\}\). Moreover, \(2\{4(r+1)\}^{r/2} C_\beta \le 2\{4(r+1)\}^{r/2} C'_\beta \lesssim \{4e^{1/e}(r+1)\}^r\), so we can indeed find a suitable universal constant \(C > 0\) in (B.6) such that the desired conclusion holds for all \(n \in \mathbb{N}\), \(r \ge 2\), \(L \equiv (L_1, \dots, L_n) \in (0, \infty)^n\) and \(t \ge 0\), as required.

Remark B.13. When $r > 2$, $f \in \text{PL}_1(r)$ and $Z \sim N(0, 1)$, the moment generating function of $f(Z)$ may not be finite anywhere except at 0 if $f(Z)$ has heavier tails than an exponential random variable (for example when $f(z) = \text{sgn}(z)|z|^r$ for $z \in \mathbb{R}$). In these situations, the standard Chernoff method fails, which is why we apply different techniques that can handle general sub-Weibull random variables.

While we are primarily concerned with the case $r \ge 2$ in the proof of Proposition A.16, there is an analogue of (B.6) when $r \in [1, 2)$, namely

```
\(\mathbb{P}\left(\left|\frac{1}{n} \sum_{i=1}^n \{f_i(Z_i) - \mathbb{E}(f_i(Z_i))\}\right| \ge t\right)\)
\(\le \exp\left(1 - \min \left\{ \left(\frac{nt}{C\|L\|_2}\right)^2, \left(\frac{nt}{C\|L\|_{\bar{r}}}\right)^{2/\bar{r}} \right\}\right),\)
(B.12)
```

where $C > 0$ is a suitable universal constant and $\bar{r} := 2/(2-r) \in [2, \infty)$ is the Hölder conjugate of $2/r$. This can be proved using a Chernoff bound (e.g., Boucheron et al., 2013, Exercise 2.27), or alternatively using Kuchibhotla and Chakrabortty (2018, Theorem 3.1) once again, where we instead take $\beta := 2/r$, $C_\beta := 4e + 2(2 \log 2)^{r/2}$ and $\lambda_\beta := (4^{1+1/\beta} C_\beta^{-1} e / \sqrt{2}) \|b\|_{\bar{r}} / \|b\|_2$ in (B.11).

The proof of Proposition A.16(g) makes use of the following straightforward consequence of the definition of weak convergence.

**Lemma B.14.** On a Euclidean space $E$, if $(\mu_n)$ is a sequence of Borel probability measures that converges weakly to a Borel probability measure $\mu$, then $\int_E g \, d\mu_n \to \int_E g \, d\mu$ for any bounded, Borel measurable $g: E \to \mathbb{R}$ that is continuous $\mu$-almost everywhere (in the sense that the set of discontinuities of $g$ has $\mu$-measure 0).

_Proof._ Writing $A \subseteq E$ for the set of discontinuities of $g$, we have $\mu(A) = 0$ by assumption. By Skorokhod's representation theorem (e.g. Kallenberg, 1997, Theorem 3.30), there exist random variables $X, X_1, X_2, \dots$ defined on a common probability space such that $X \sim \mu$, $X_n \sim \mu_n$ for all $n$ and $X_n \to X$ almost surely. Then $g(X_n) \to g(X)$ almost surely on the event $\{X \in A^c\}$, which has probability $\mu(A^c) = 1$, so an application of the dominated (or bounded) convergence theorem shows that \(\int_E g \, d\mu_n = \mathbb{E}(g(X_n)) \to \mathbb{E}(g(X)) = \int_E g \, d\mu\), as required. \(\square\)

**Remark B.15.** For each Lipschitz function \( f_k: \mathbb{R}^2 \rightarrow \mathbb{R} \) in the AMP recursion (2.1), we assume in (A5) that there exists some \( f'_k \) that satisfies the hypotheses of Lemma B.14 above with \( \mu = \lambda \otimes \pi \); recall that \( \lambda \) denotes Lebesgue measure on \( \mathbb{R} \) and the probability distribution \( \pi \) is as in (A1). To see why (A5) is a non-vacuous (albeit very mild) condition, consider Borel probability measures on \( \mathbb{R}^D \) of the form \( \mu = \lambda \otimes \nu \), where \( D \ge 2 \) and \( \nu \) is some probability measure on \( \mathbb{R}^{D-1} \). We will now give an example of a Lipschitz function \( G: \mathbb{R}^D \rightarrow \mathbb{R} \) whose partial derivative \( \frac{\partial G}{\partial x_1} \) cannot be extended beyond its domain of definition to a function \( g: \mathbb{R}^D \rightarrow \mathbb{R} \) that is continuous \( \mu \)-almost everywhere, for any \( \mu \) of the above form.

Denote by \( C \subseteq [0, 1] \) the *fat Cantor set* (e.g. Aliprantis and Burkinshaw, 1998, pp. 140–141), which has the property that for all \( x \in C \) and \( \varepsilon > 0 \), both \( (x - \varepsilon, x + \varepsilon) \cap C \) and \( (x - \varepsilon, x + \varepsilon) \cap C^c \) have positive Lebesgue measure. Then for any \( f: \mathbb{R} \rightarrow \mathbb{R} \) with \( f = \mathbb{1}_C \) Lebesgue almost everywhere, we have \( \{f(u) : u \in (x - \varepsilon, x + \varepsilon)\} = \{0, 1\} \) for all \( x \in C \) and \( \varepsilon > 0 \), so \( f \) is discontinuous on \( C \), which has Lebesgue measure \( 1/2 > 0 \). Note that \( F: x \mapsto \int_{-\infty}^x \mathbb{1}_C(t) dt \) is a Lipschitz function on \( \mathbb{R} \) with \( F'(x) = \mathbb{1}_C(x) \) for Lebesgue almost every \( x \in \mathbb{R} \). Thus, for general \( D \in \mathbb{N} \), the function \( G: (x_1, \dots, x_D) \mapsto F(x_1) \) is Lipschitz on \( \mathbb{R}^D \). Moreover, if \( g: \mathbb{R}^D \rightarrow \mathbb{R} \) agrees with \( \frac{\partial G}{\partial x_1} \) wherever the latter is defined, then \( g \) is discontinuous on \( C \times \mathbb{R}^{D-1} \), which has strictly positive \( \mu \)-measure when \( \mu = \lambda \otimes \nu \) as above.
