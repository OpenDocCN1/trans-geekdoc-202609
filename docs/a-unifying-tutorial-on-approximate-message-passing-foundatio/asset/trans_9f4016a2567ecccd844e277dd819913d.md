置信区间和 \(p\) 值：对于固定的 \(k\) 和足够大的 \(n\)，定理 4.2 告诉我们，\(\{(\beta_i^k - \mu_k \beta_i) / \sigma_k : 1 \le i \le n\}\) 的行为近似于来自 \(N(0, 1)\) 分布的大小为 \(n\) 的独立同分布样本。因此，为了对 \(\beta\) 进行推断，我们可以类似于第 3.4 节的做法进行，相关细节请读者参考该节。我们在此指出，如果状态演化参数 \(\mu_k, \sigma_k\) 未知，则在 \(\mathbb{E}(\bar{\beta}^2) > 0\) 已知的前提下，它们可以分别由 \(\hat{\mu}_k := (\|\beta^k\|_p^2 - \|\hat{r}^{k-1}\|_n^2)^{1/2} / \mathbb{E}(\bar{\beta}^2)^{1/2}\) 和 \(\hat{\sigma}_k := \|\hat{r}^{k-1}\|_n\) 一致估计。确实，根据 (4.10) 和 (4.11) 分别，

```
\(\|\beta^k\|_p^2 \xrightarrow{p} \mathbb{E}((\mu_k \bar{\beta} + \sigma_k G_k)^2) = \mathbb{E}(\bar{\beta}^2)\mu_k^2 + \sigma_k^2,\)
\(\|\hat{r}^{k-1}\|_n^2 = \|g_{k-1}(\theta^{k-1}, y)\|_n^2 = \|\bar{g}_{k-1}(\theta, \theta^{k-1}, \varepsilon)\| \xrightarrow{} \mathbb{E}(\bar{g}_{k-1}(Z, Z_k, \bar{\varepsilon})^2)\)
\(= \mathbb{E}(g_{k-1}(Z_k, Y)^2) = \sigma_k^2\)
```

对每个 \(k \in \mathbb{N}\)，当 \(n, p \to \infty\) 且 \(n/p \to \delta\) 时成立。

## 4.3 线性模型的 AMP

AMP 的早期工作大部分（例如，Bayati 和 Montanari, 2011, 2012; Donoho 等人, 2009; Krzakala 等人, 2012）都集中在标准线性模型上

```
\(y = X\beta + \varepsilon,\)
```

其中 \(\varepsilon_1, \dots, \varepsilon_n \stackrel{\text{iid}}{\sim} P_\varepsilon\) 的二阶矩为 \(\sigma^2 > 0\)，且对某些 \(r \in [2, \infty)\) 具有有限的 \(r\) 阶矩（或者更一般地，经验分布 \(\nu_n(\varepsilon) = n^{-1} \sum_{i=1}^n \delta_{\varepsilon_i}\) 在 \(n \to \infty\) 时在 \(d_r\) 中完全收敛到 \(P_\varepsilon\)）。这是模型 (4.1) 的一个特例，其中 \(h(z, v) = z + v\)。

给定 \(\hat{r}^{-1} = 0 \in \mathbb{R}^n\)、\(b_0 \in \mathbb{R}\) 和初始估计器 \(\hat{\beta}^0 \in \mathbb{R}^p\)，通过在 GAMP 递推 (4.4) 中对 \(u, v \in \mathbb{R}\) 设置 \(g_k(u, v) := v - u\)，可以恢复 Donoho 等人 (2009) 和 Bayati 与 Montanari (2011) 的原始 AMP 算法，从而 \(c_k = \langle g'_k(\theta^k, y) \rangle_n = -1\) 且

```
\(\hat{r}^k = y - X\hat{\beta}^k + b_k\hat{r}^{k-1}, \qquad \hat{\beta}^{k+1} = f_{k+1}(X^\top\hat{r}^k + \hat{\beta}^k),\)
\( b_{k+1} = \frac{1}{n} \sum_{j=1}^p f'_{k+1}(\beta_j^{k+1}) \quad (4.19) \)
```

对 \(k \in \mathbb{N}_0\)。在此，\(\hat{r}^k = g_k(\theta^k, y) = y - \theta^k = y - X\hat{\beta}^k + b_k\hat{r}^{k-1}\) 是迭代 \(k\) 的“校正”残差，而 \(\beta^{k+1} = X^\top\hat{r}^k + \hat{\beta}^k\) 是有效观测值。

### 状态演化

GAMP 状态演化方程 (4.6)–(4.7) 简化为递推

```
\(\mu_k \equiv 1, \qquad \sigma_1^2 = \sigma^2 + \mathbb{E}((Z - Z_0)^2),\)
\(\sigma_{k+1}^2 = \sigma^2 + \frac{1}{\delta} \mathbb{E}\{(\bar{\beta} - f_k(\bar{\beta} + \sigma_k G_k))^2\} \quad (4.20)\)
```

对 \(k \in \mathbb{N}\)，其中 \((Z, Z_0) \sim N_2(0, \Sigma_0)\)，且 \(\bar{\beta} \sim \pi_{\bar{\beta}}\) 与 \(G_k \sim N(0, 1)\) 独立。注意，根据 (G2)，\(\sigma_1^2 = \sigma^2 + \text{c-lim}_{n\to\infty} n^{-1} \|\beta - \hat{\beta}^0\|^2\)，并且如果对每个 \(p \equiv p_n\) 将 \(\beta \in \mathbb{R}^p\) 的初步估计取为 \(\hat{\beta}^0 = 0 \in \mathbb{R}^p\)，则 \(Z_0 \equiv 0\) 且 \(\sigma_1^2 = \sigma^2 + \mathbb{E}(Z^2) = \sigma^2 + \delta^{-1}\mathbb{E}(\bar{\beta}^2)\)。

### 渐近估计误差

在 (G0)–(G5) 且 \(r \in [2, \infty)\) 下，Bayati 和 Montanari (2011, 定理 1) 关于 (4.19) 中估计器 \(\hat{\beta}^k\) 的渐近性能的主要结果可以表述为

```
\(\sup_{\psi \in \text{PL}_2(r,1)} \left| \frac{1}{p} \sum_{j=1}^p \psi(\hat{\beta}_j^k, \beta_j) - \mathbb{E}\{\psi(f_k(\bar{\beta} + \sigma_k G_k), \bar{\beta})\} \right| \xrightarrow{\mathcal{L}} 0\)
\(\text{as } n, p \to \infty \text{ with } n/p \to \delta, \quad (4.21)\)
```

对每个 \(k \in \mathbb{N}\)，其中 \(\sigma_k\) 如 (4.20) 所示。这可以作为定理 4.2 和 (4.15) 的一个特例得到。或者，(4.21) 可以通过直接归约为第 2.2 节类型的抽象非对称 AMP 递推来建立；参见 Bayati 和 Montanari (2011, 第 3.3 节)。这涉及用 \(e^k := \varepsilon - \hat{r}^k\) 和 \(h^{k+1} := \beta^{k+1} - \beta\) 来表示 (4.19)，它们分别被发现是 \(\hat{r}^k\) 和 \(\beta^{k+1}\) 渐近高斯的“噪声”分量。

最初，$d_r$ 收敛结果 (4.21) 在 (G1) 的更强版本下推导，该版本假设收敛到具有有限 \((2r-2)\) 阶矩的极限分布 \(\pi_{\bar{\beta}}, P_{\bar{\varepsilon}}\)。在 (G1) 中，我们将其放宽为更自然的 \(d_r\) 条件，在此条件下结论仍然成立；参见备注 A.4 的第一部分。我们还提到，在上述条件的适当有限样本类似条件下，Rush 和 Venkataramanan (2018) 在 \(r=2\) 的情况下建立了 (4.21) 的一个互补有限样本版本；参见备注 A.3。

### 与 Bayes-GAMP 的联系

如果极限先验分布 \(\pi_{\bar{\beta}}\) 已知，那么为了最小化有效噪声方差 \(\sigma_{k+1}^2\)，我们可以将 (4.19) 中的 \(f_k\) 取为来自 (4.17) 的 Bayes 最优 \(f_k^*\)。一般来说，\(g_k : (u, v) \mapsto v - u\) 不与 (4.16) 中的 \(g_k^*\) 重合。但是，当 \(P_{\bar{\varepsilon}} = N(0, \sigma^2)\) 且 \(\sigma^2 > 0\)，对于每个 \(n\) 有 \(\hat{\beta}^0 \equiv \hat{\beta}^0(n) = 0\)，且对每个 \(k \in \mathbb{N}\) 有 \(f_k = f_k^*\) 时，结果表明 (4.19) 是一种 Bayes-GAMP 过程（其中 \(g_k \propto g_k^*\)）的一个实例，该过程在每次迭代中最大化有效信噪比 \(\rho_k = (\mu_k/\sigma_k)^2\) 和 \(\rho_{Z,k} = (\mu_{Z,k}/\sigma_{Z,k})^2\)。确实，在此特例中，可以通过直接计算验证

```
$g_k^*(u, v) = c_k\left(\frac{\Sigma_{21}}{\Sigma_{22}}u - v\right) = c_k(u - v) = -c_kg_k(u, v)$
```

对每个 \(k \in \mathbb{N}_0\)，其中 \(\Sigma \equiv \Sigma_k \in \mathbb{R}^{2\times 2}\) 如 (4.7) 所示，当 \(k=0\) 时有 \(\Sigma_{21} = \Sigma_{22} = 0 < \Sigma_{11}\)，而当 \(k \in \mathbb{N}\) 时，根据 (4.17) 有 \(\Sigma_{21} = \delta^{-1}\mathbb{E}(\bar{\beta}f_k^*(\mu_k\bar{\beta} + \sigma_kG_k)) = \delta^{-1}\mathbb{E}(f_k^*(\mu_k\bar{\beta} + \sigma_kG_k)^2) = \Sigma_{22} < \Sigma_{11} = \delta^{-1}\mathbb{E}(\bar{\beta}^2)\)，以及

```
$c_k = -\frac{\Sigma_{11} - \Sigma_{22}}{\Sigma_{11} - \Sigma_{22} + \sigma^2} < 0$
```

是确定的。在此，\(\delta(\Sigma_{11} - \Sigma_{22}) = \mathbb{E}\{(\bar{\beta} - \mathbb{E}(\bar{\beta}|\mu_k\bar{\beta} + \sigma_kG_k))^2\}\) 是基于 \(\mu_k\bar{\beta} + \sigma_kG_k\) 估计 \(\bar{\beta}\) 问题的最小均方误差。
