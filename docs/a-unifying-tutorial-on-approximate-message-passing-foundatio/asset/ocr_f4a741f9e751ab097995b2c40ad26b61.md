where \(\bar{\ell}(\tilde{\theta}, y) := \sum_{i=1}^n \ell(\tilde{\theta}_i, y_i)\). Thus, for all \((\tilde{\beta}, \tilde{\theta}) \in \mathbb{R}^p \times \mathbb{R}^n\) with \(\tilde{\theta} = X\tilde{\beta}\), we have

\(\begin{aligned} \bar{J}(\tilde{\beta}) + \bar{\ell}(\tilde{\theta}, y) &= (\bar{J}(\tilde{\beta}) - (X\tilde{\beta})^\top \hat{s}^*) + (\bar{\ell}(\tilde{\theta}, y) + \tilde{\theta}^\top \hat{s}^*) \\ \ge &\ (\bar{J}(\hat{\beta}^*) - (X\hat{\beta}^*)^\top \hat{s}^*) + (\bar{\ell}(\hat{\theta}^*, y) + (\hat{\theta}^*)^\top \hat{s}^*) \\ &= \bar{J}(\hat{\beta}^*) + \bar{\ell}(\hat{\theta}^*, y), \end{aligned}\)

so \((\hat{\beta}^*, \hat{\theta}^*)\) is a solution to the optimisation problem (4.22), as required.
