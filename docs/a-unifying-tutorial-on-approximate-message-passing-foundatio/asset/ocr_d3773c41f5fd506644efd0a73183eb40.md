definition in (3.31). Therefore, \(V \perp\!\!\!\perp cU \mid (\mu_1^* V + \sigma_1^* G_1)\), which verifies (A.65) when \(k=1\).

For a general \(k \ge 2\) and \(1 \le \ell \le k\), it follows from (3.31) and (3.33) that

```
\(\begin{aligned}
\bar{\Sigma}_{k,\ell} &= \mathbb{E}(\boldsymbol{g}_{\ell-1}^*(\boldsymbol{\mu}_{\ell-1}^* V + \bar{\boldsymbol{G}}_{\ell-1}^*) \cdot \boldsymbol{g}_{k-1}^*(\boldsymbol{\mu}_{k-1}^* V + \bar{\boldsymbol{G}}_{k-1}^*)) \\
&= \mathbb{E}(\mathbb{E}(V \mid \boldsymbol{\mu}_{\ell-1}^* V + \bar{\boldsymbol{G}}_{\ell-1}^*) \cdot \mathbb{E}(V \mid \boldsymbol{\mu}_{k-1}^* V + \bar{\boldsymbol{G}}_{k-1}^*)) \\
&= \mathbb{E}(V \mathbb{E}(V \mid \boldsymbol{\mu}_{\ell-1}^* V + \bar{\boldsymbol{G}}_{\ell-1}^*)) = \mu_\ell^*/\lambda \\
&= \mathbb{E}(\mathbb{E}(V \mid \boldsymbol{\mu}_{\ell-1}^* V + \bar{\boldsymbol{G}}_{\ell-1}^*)^2) = (\sigma_\ell^*)^2,
\end{aligned}\)
(A.66)
```

where we have used the tower property of conditional expectation to obtain the last two equalities above. Thus, \(\rho_k^* = (\mu_k^*/\sigma_k^*)^2 = \lambda \mu_k^*\) and

```
\(\text{Cov}\left( \frac{\sigma_k^* G_k}{\mu_k^*}, \frac{\sigma_\ell^* G_\ell}{\mu_\ell^*} \right) = \frac{\bar{\Sigma}_{k,\ell}}{\mu_k^* \mu_\ell^*} = \frac{1}{\lambda \mu_k^*} = \frac{1}{\rho_k^*}.\)
(A.67)
```

Now for \(1 \le \ell \le k\), let \(Z_\ell := \sigma_\ell^* G_\ell / \mu_\ell^*\) and \(\zeta_\ell := Z_\ell - Z_k\), so that \(\text{Cov}(\zeta_\ell, Z_k) = 0\) by (A.67). Since \((\zeta_1, \dots, \zeta_{k-1}, Z_k)\) is a Gaussian random vector that is independent of \((U, V)\), it follows that \((\zeta_1, \dots, \zeta_{k-1}), Z_k, U\) and \(V\) are mutually independent, whence \(V \perp\!\!\!\perp (cU, \zeta_1, \dots, \zeta_{k-1}, V + Z_k) \mid (V + Z_k)\) by Lemma B.8. Writing \(\mu_\ell^* V + \sigma_\ell^* G_\ell = \mu_\ell^*(V + Z_\ell) = \mu_\ell^*((V + Z_k) + \zeta_\ell)\) for \(1 \le \ell \le k\), we deduce that

```
\(V \perp\!\!\!\perp (cU, \mu_1^* V + \sigma_1^* G_1, \dots, \mu_{k-1}^* V + \sigma_{k-1}^* G_{k-1}) \mid (\mu_k^* V + \sigma_k^* G_k),\)
```

which completes the inductive step for (A.65). An immediate consequence of this conditional independence is (3.34), which implies that \(\boldsymbol{g}_k^*\) depends only its last argument and \(b_{kj}^* = \langle \partial_j \boldsymbol{g}_k^*(v^0, \dots, v^k) \rangle_n = 0\) for \(1 \le j \le k-1\). Thus, with the denoising functions \(\boldsymbol{g}_k^*\) given by (3.34), we see by induction that the state evolution recursion (3.31) reduces to that in (3.20), and hence that (3.30) coincides with the Bayes-AMP iteration (\(v^{k,\text{B}} \equiv v^{k,\text{B}}(n) : k, n \in \mathbb{N}\)) in Section 3.3.
