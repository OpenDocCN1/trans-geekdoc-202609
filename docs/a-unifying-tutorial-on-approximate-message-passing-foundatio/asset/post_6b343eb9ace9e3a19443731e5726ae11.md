## A.5 Proofs for Sections 2.1 and A.1

*Proof of Proposition A.16.* Since we are carrying out an asymptotic analysis, we may assume without loss of generality that \(n > k\) in the proofs of \(\mathcal{H}_k(a, \dots, i)\) for each \(k \in \mathbb{N}\); this enables us to apply the results on conditional distributions from Section A.2. Note also that we use \(T_n, T_{n1}, T'_{n1}, T_{n2}\) to refer to different quantities of interest in different parts of the proof. In Lemma B.2 and Remark B.3, we state versions of the continuous mapping theorem and Slutsky's lemma for complete convergence, as well the ‘arithmetic rules’ for \(o_c\) and \(O_c\) symbols. We will apply these repeatedly in the arguments below, often without further comment or explanation.

First, we prove \(\mathcal{H}_1(a, b, c, d)\), which form the base case for the induction.

\(\mathcal{H}_1(a)\): By (A.20), \(\Delta^1 \equiv \Delta^1(n) = (\|m^0\|_n - \tau_1)\tilde{Z}^1 + \tilde{\zeta}^1 m^0\), where \((\tilde{Z}^1, \tilde{\zeta}^1) \equiv (\tilde{Z}^1(n), \tilde{\zeta}^1(n)) \sim N_n(0, I_n) \otimes N(0, 1/n)\) for each \(n\). Taking \(\zeta \sim N(0, 1)\), we have \(|\tilde{\zeta}^1| \stackrel{d}{=} n^{-1/2} |\zeta| \rightarrow^p 0\) by Example 1(a), and \(\|\tilde{Z}^1\|_{n,r} = (n^{-1} \sum_{i=1}^n |\tilde{Z}_i^1|^r)^{1/r} \xrightarrow{\mathcal{D}} \mathbb{E}(|\zeta|^r)^{1/r} \in (0, \infty)\) by Lemma B.12 and Proposition 1.2. Moreover, \(\|m^0\|_n - \tau_1 \xrightarrow{p} 0\) and \(\|m^0\|_{n,r} = O_c(1)\) by (A2). Putting everything together, we recall from Remark B.3 the 'arithmetic rules' (B.1) for \(o_c\) and \(O_c\) symbols, and conclude using the triangle inequality for \(\|\cdot\|_{n,r}\) that

```
\(\|\Delta^1\|_{n,r} \le \| \|m^0\|_n - \tau_1 \| \|\tilde{Z}^1\|_{n,r} + |\tilde{\zeta}^1| \|m^0\|_{n,r}\)
\(= o_c(1) O_c(1) + o_c(1) O_c(1) = o_c(1)\).
```

\(\mathcal{H}_1(b)\): Recall from (A.5) in Proposition A.11 and (A.20) that

```
\(h^1 \equiv h^1(n) \stackrel{d}{=} |\mathcal{S}_0| \tilde{h}^1(n) + \Delta^1(n) = h^{1,0}(n) \equiv h^{1,0}\) (A.23)
```

for each \(n \in \mathbb{N}\), where \(\tilde{h}^1 \equiv \tilde{h}^1(n) = \tau_1 \tilde{Z}^1\) and \(\tilde{Z}^1 \sim N_n(0, I_n)\) is independent of \(\mathcal{S}_0 = \sigma(\gamma, m^0)\). Then \(\|\Delta^1\|_{n,r} = o_c(1)\) by \(\mathcal{H}_1(a)\) and \(\|\tilde{h}^1\|_{n,r} = \tau_1 \|\tilde{Z}^1\|_{n,r} = O_c(1)\) as in the proof of \(\mathcal{H}_1(a)\), so

```
\(\|h^1\|_{n,r} \stackrel{d}{=} \|h^{1,0}\|_{n,r} \le \|\tilde{h}^1\|_{n,r} + \|\Delta^1\|_{n,r} = O_c(1) + o_c(1) = O_c(1)\).
```

We already have \(\|m^0\|_{n,r} = O_c(1)\) by (A2). In addition, \(\|\gamma\|_{n,r} = (n^{-1} \sum_{i=1}^n |\gamma_i|^r)^{1/r} \xrightarrow{\mathcal{D}} \mathbb{E}(|\bar{\gamma}|^r)^{1/r}\) by (A1), so \(\|\gamma\|_{n,r} = O_c(1)\). Letting \(L' > 0\) be such that the function \(f_1\) in the AMP recursion (2.1) lies in \(\text{PL}_2(1, L')\), we have \(|f_1(x, y)| \le |f_1(0, 0)| + L'(|x| + |y|)\) for all \((x, y) \in \mathbb{R}^2\), so we can apply the triangle inequality for \(\|\cdot\|_{n,r}\) to deduce that

```
\(\|m^1\|_{n,r} = \|f_1(h^1, \gamma)\|_{n,r} \le |f_1(0, 0)| \|\mathbf{1}_n\|_{n,r} + L'(\|h^1\|_{n,r} + \|\gamma\|_{n,r}) = O_c(1)\).
```

\(\mathcal{H}_1(c)\): For each \(n\), note that \((\gamma, h^1) \stackrel{d}{=} |\mathcal{S}_0| (\gamma, h^{1,0})\) by (A.23) and Lemma B.6(c). Thus, for each fixed \(\psi \in \text{PL}_2(r)\), it follows that \(n^{-1} \cdot \sum_{i=1}^n \psi(h_i^1, \gamma_i) \stackrel{d}{=} n^{-1} \sum_{i=1}^n \psi(h_i^{1,0}, \gamma_i) =: T_n\) for each \(n\), so in view of the third bullet point in Remark A.1, it is enough to show that \(T_n \xrightarrow{\mathcal{D}} \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma}))\) as \(n \to \infty\). To this end, we write

```
\(T_n = \frac{1}{n} \sum_{i=1}^n \psi(\tilde{h}_i^1, \gamma_i) + \frac{1}{n} \sum_{i=1}^n \{ \psi(h_i^{1,0}, \gamma_i) - \psi(\tilde{h}_i^1, \gamma_i) \} =: T_{n1} + T_{n2}\)
```

for each \(n\), and aim to prove that \(T_{n1} \xrightarrow{\mathcal{D}} \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma}))\) and \(T_{n2} \xrightarrow{p} 0\), which together imply the desired conclusion.

Before proceeding, we briefly describe the techniques that we use to determine the limit of \((T_{n1})\) and also to prove \(\mathcal{H}_1(d)\) and \(\mathcal{H}_{k+1}(c,d)\) later on. It is instructive to consider the following two special cases where the claim is easier to establish. If \(\psi\) depends only on its first argument, then since \(h^l(n) = \tau_1 \bar{Z}^1(n)\) and \(\bar{Z}^1(n) \sim N_n(0, I_n)\) for each \(n\), the result follows readily from the concentration inequality (B.6) in Lemma B.12 and the characterisation of complete convergence in Proposition 1.2. On the other hand, if \(\psi\) depends only on its second argument, then since \((\gamma \equiv \gamma(n) : n \in \mathbb{N})\) satisfies (A1) by assumption, we can appeal directly to Corollary B.21(b).

For general \(\psi \in \text{PL}_2(r)\), we seek to combine these two different lines of reasoning by exploiting the independence of \(\tilde{h}^1(n)\) and \(\mathcal{S}_0 \equiv \mathcal{S}_0(n) = \sigma(\gamma, m^0)\) for each \(n\). This allows \(\gamma(n)\) and \(\tilde{h}^1(n)\) to be handled separately (to a large extent) when we decompose \(T_{n1}\) as a sum of \(\mathbb{E}(T_{n1} | \mathcal{S}_0)\) and \(T_{n1} - \mathbb{E}(T_{n1} | \mathcal{S}_0)\) in (A.24) and (A.25) respectively. For the latter, it is helpful to first think of \(\gamma(n)\) as being fixed when applying Lemma B.12 to the Gaussian \(\tilde{h}^1\), before subsequently accounting for the randomness of \(\gamma(n)\) using (A1).

Define \(\Psi: \mathbb{R} \to \mathbb{R}\) by \(\Psi(y) := \mathbb{E}(\psi(\tau_1 Z, y))\) with \(Z \sim N(0,1)\). For each \(n\), since \(\tilde{Z}^1 \equiv \tilde{Z}^1(n) \sim N_n(0, I_n)\) is independent of \(\mathcal{S}_0 \equiv \mathcal{S}_0(n) = \sigma(\gamma, m^0)\), we deduce from Lemma B.7 that \(\mathbb{E}(\psi(\tilde{h}_i^1, \gamma_i) | \mathcal{S}_0) = \mathbb{E}(\psi(\tau_1 \bar{Z}_i^1, \gamma_i) | \mathcal{S}_0) = \Psi(\gamma_i)\) almost surely, for every \(1 \le i \le n\). Since \(\Psi \in \text{PL}_1(r)\) by Lemma B.23(b), it follows from (A1) and Corollary B.21(b) that \(n^{-1} \sum_{i=1}^n \Psi(\gamma_i) \xrightarrow{c} \mathbb{E}(\Psi(\bar{\gamma}))\) as \(n \to \infty\), where \(\bar{\gamma} \sim \pi\). A further application of Lemma B.7 shows that if \(\bar{G}_1 \sim N(0, \tau^2)\) is independent of \(\bar{\gamma}\), then \(\mathbb{E}(\Psi(\bar{\gamma})) = \mathbb{E}(\mathbb{E}\{\psi(\bar{G}_1, \bar{\gamma}) | \bar{\gamma}\}) = \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma}))\), so in summary, we have

```
\(\frac{1}{n} \sum_{i=1}^n \mathbb{E}(\psi(\tilde{h}_i^1, \gamma_i) | \mathcal{S}_0) = \frac{1}{n} \sum_{i=1}^n \Psi(\gamma_i) \xrightarrow{c} \mathbb{E}(\Psi(\bar{\gamma})) = \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma})).\) (A.24)
```

To complete the proof that \(T_{n1} \xrightarrow{c} \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma}))\), we must therefore show that

```
\(T'_{n1} := \frac{1}{n} \sum_{i=1}^n \{ \psi(\tilde{h}_i^1, \gamma_i) - \mathbb{E}(\psi(\tilde{h}_i^1, \gamma_i) | \mathcal{S}_0) \} \xrightarrow{c} 0\) (A.25)
```
