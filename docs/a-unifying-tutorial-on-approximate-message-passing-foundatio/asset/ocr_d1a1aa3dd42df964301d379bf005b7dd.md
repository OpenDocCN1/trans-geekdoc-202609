\(\|\tilde{Z}^1\|_{n,r} = (n^{-1} \sum_{i=1}^n |\tilde{Z}_i^1|^r)^{1/r} \xrightarrow{\mathcal{D}} \mathbb{E}(|\zeta|^r)^{1/r} \in (0, \infty)\) by Lemma B.12 and Proposition 1.2. Putting everything together, we recall from Remark B.3 the 'arithmetic rules' (B.1) for \(o_c\) and \(O_c\) symbols, and conclude using the triangle inequality for \(\|\cdot\|_{n,r}\) that

\(= o_c(1) O_c(1) + o_c(1) O_c(1) = o_c(1)\).
```

\(\mathcal{H}_1(b)\): Recall from (A.5) in Proposition A.11 and (A.20) that

We already have \(\|m^0\|_{n,r} = O_c(1)\) by (A2). \(\mathcal{H}_1(c)\): For each \(n\), note that \((\gamma, h^1) \stackrel{d}{=} |\mathcal{S}_0| (\gamma, h^{1,0})\) by (A.23) and Lemma B.6(c). Thus, for each fixed \(\psi \in \text{PL}_2(r)\), it follows that \(n^{-1} \cdot \sum_{i=1}^n \psi(h_i^1, \gamma_i) \stackrel{d}{=} n^{-1} \sum_{i=1}^n \psi(h_i^{1,0}, \gamma_i) =: T_n\) for each \(n\), so in view of the third bullet point in Remark A.1, it is enough to show that \(T_n \xrightarrow{\mathcal{D}} \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma}))\) as \(n \to \infty\). To this end, we write

```

for each \(n\), and aim to prove that \(T_{n1} \xrightarrow{\mathcal{D}} \mathbb{E}(\psi(\bar{G}_1, \bar{\gamma}))\) and \(T_{n2} \xrightarrow{p} 0\), which together imply the desired conclusion.
