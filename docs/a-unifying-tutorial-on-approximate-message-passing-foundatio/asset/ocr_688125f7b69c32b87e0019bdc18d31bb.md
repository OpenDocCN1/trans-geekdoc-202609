H_{k+1}(b): By the inductive hypothesis H_k(b), we have \|h^j\|_{n,r} = O_c(1) for all 1 \le j \le k and \|m^j\|_{n,r} = O_c(1) for all 0 \le j \le k. Now let j = k+1. For each integer n > k, recall from (A.7) in Proposition A.11 and (A.21) that

```
h^{k+1}(n) \stackrel{d}{=}|_{\mathcal{S}_k} h^{k+1,k}(n) = \tilde{h}^{k+1}(n) + \Delta^{k+1}(n)
= \sum_{\ell=1}^k \bar{\alpha}_\ell^k h^\ell(n) + \bar{\tau}_{k+1} \tilde{Z}^{k+1}(n) + \Delta^{k+1}(n), \quad \text{(A.38)}
```

where the deterministic \bar{\alpha}^k \in \mathbb{R}^k is taken from (A.14) and \tilde{Z}^{k+1} \equiv \tilde{Z}^{k+1}(n) \sim N_n(0, I_n) is independent of \mathcal{S}_k \equiv \mathcal{S}_k(n) = \sigma(\gamma, m^0, h^1, \dots, h^k). Then \|\Delta^{k+1}\|_{n,r} = o_c(1) by \mathcal{H}_{k+1}(a) and \|\tilde{Z}^{k+1}\|_{n,r} = O_c(1), as in the last part of the proof of \mathcal{H}_{k+1}(a) above. It follows from this and \mathcal{H}_k(b) that

```
\|h^{k+1}\|_{n,r} \stackrel{d}{=} \|h^{k+1,k}\|_{n,r} \le \sum_{\ell=1}^k |\bar{\alpha}_\ell^k| \|h^\ell\|_{n,r} + \|\Delta^{k+1}\|_{n,r}
= O_c(1) + o_c(1) = O_c(1).
```

In addition, letting L' > 0 be such that f_{k+1} is L'-Lipschitz, we can argue as in the proof of \mathcal{H}_1(b) to deduce that

```
\|m^{k+1}\|_{n,r} = \|f_{k+1}(h^{k+1}, \gamma)\|_{n,r} \le |f_{k+1}(0,0)|
+ L'(\|h^{k+1}\|_{n,r} + \|\gamma\|_{n,r}) = O_c(1).
```

\mathcal{H}_{k+1}(c): We again make use of the distributional equality (A.38), which together with Lemma B.6(c) implies that (\gamma, h^1, \dots, h^k, h^{k+1}) \stackrel{d}{=}|_{\mathcal{S}_k} (\gamma, h^1, \dots, h^k, h^{k+1,k}) for each integer n > k. Thus, for any fixed \psi \in \text{PL}_{k+2}(r), it follows that n^{-1} \sum_{i=1}^n \psi(h_i^1, \dots, h_i^k, h_i^{k+1}, \gamma_i) \stackrel{d}{=} n^{-1} \cdot \sum_{i=1}^n \psi(h_i^1, \dots, h_i^k, h_i^{k+1,k}, \gamma_i) =: T_n for each such n, so it suffices to show that T_n \rightarrow^\mathcal{C} \mathbb{E}(\psi(\bar{G}_1, \dots, \bar{G}_k, \bar{G}_{k+1}, \bar{\gamma})). We decompose T_n as

```
\frac{1}{n} \sum_{i=1}^n \psi(h_i^1, \dots, h_i^k, \tilde{h}_i^{k+1}, \gamma_i) + \frac{1}{n} \sum_{i=1}^n \{ \psi(h_i^1, \dots, h_i^k, h_i^{k+1,k}, \gamma_i)
- \psi(h_i^1, \dots, h_i^k, \tilde{h}_i^{k+1}, \gamma_i) \} =: T_{n1} + T_{n2} \quad \text{(A.39)}
```

for each n > k, and seek to establish that T_{n1} \rightarrow^\mathcal{C} \mathbb{E}(\psi(\bar{G}_1, \dots, \bar{G}_k, \bar{G}_{k+1}, \bar{\gamma})) and T_{n2} \rightarrow^\mathcal{C} 0 by imitating and extending the analogous arguments in the proof of \mathcal{H}_1(c).
