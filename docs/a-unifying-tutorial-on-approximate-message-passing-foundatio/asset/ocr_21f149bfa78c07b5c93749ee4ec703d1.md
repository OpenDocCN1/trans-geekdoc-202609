$\mathcal{H}_k(f)$: This proof is very similar to that of $\mathcal{H}_k(e)$. First fix \(1 \le j, \ell \le k\). By Lemma B.22, the function \((x_1, \dots, x_k, y) \mapsto x_j f_\ell(x_\ell, y)\) lies in \(\text{PL}_{k+1}(2) \subseteq \text{PL}_{k+1}(r)\), so by applying $\mathcal{H}_k(c)$ again, we deduce that

\(\langle h^j, m^\ell \rangle_n = \frac{1}{n} \sum_{i=1}^n h_i^j f_\ell(h_i^\ell, \gamma_i) \xrightarrow{\text{Law}} \mathbb{E}(\bar{G}_j f_\ell(\bar{G}_\ell, \bar{\gamma})) = \mathbb{E}(f'_\ell(\bar{G}_\ell, \bar{\gamma})) \mathbb{E}(\bar{G}_j \bar{G}_\ell) = \bar{b}_\ell \bar{T}_{j,\ell},\)

where the final equalities are taken from (A.19). For the second part of $\mathcal{H}_k(f)$, we fix \(1 \le j \le k\) and apply $\mathcal{H}_k(d)$ with the \(\text{PL}_{k+1}(1)\) function \((x_1, \dots, x_k, y) \mapsto x_j\) to see that

\(\langle h^j, m^0 \rangle_n = \frac{1}{n} \sum_{i=1}^n m_i^0 h_i^j \xrightarrow{\text{Law}} \mathbb{E}(F_0(\bar{\gamma}) \bar{G}_j) = 0\)

by the independence of \(\bar{G}_j \sim N(0, \tau_j^2)\) and \(\bar{\gamma} \sim \pi\).

$\mathcal{H}_k(g)$: In view of Definition 1.1 of complete convergence, it suffices to show that if \((\beta_n)\) is any sequence of random variables with \(\beta_n \overset{d}{=} \langle f'_k(h^k, \gamma) \rangle_n\) for each \(n\), then \(\beta_n \xrightarrow{a.s.} \mathbb{E}(f'_k(\bar{G}_k, \bar{\gamma}))\). For any such sequence \((\beta_n)\), we first seek to construct a random sequence \(((\eta_n, \theta_n) \in \mathbb{R}^n \times \mathbb{R}^n : n \in \mathbb{N})\) such that \((\eta_n, \theta_n) \overset{d}{=} (h^k(n), \gamma(n))\) for each \(n\), and \(((f'_k(\eta_n, \theta_n))_n : n \in \mathbb{N}) = (\beta_n : n \in \mathbb{N})\) almost surely as random sequences. This can be done by applying Lemma B.10, where we take \(g_n : \mathbb{R}^n \times \mathbb{R}^n \to \mathbb{R}\) to be the measurable function \((x, y) \mapsto \langle f'_k(x, y) \rangle_n = n^{-1} \sum_{i=1}^n f'_k(x_i, y_i)\) for each \(n\).

Since \((\eta_n, \theta_n) \overset{d}{=} (h^k(n), \gamma(n))\) for each \(n\) by construction, it follows from the inductive hypothesis $\mathcal{H}_k(c)$ that \(n^{-1} \sum_{i=1}^n \varphi(\eta_{mi}, \theta_{ni}) \overset{d}{=} n^{-1} \sum_{i=1}^n \varphi(h_i^k, \gamma_i) \xrightarrow{\text{Law}} \mathbb{E}(\varphi(\bar{G}_k, \bar{\gamma}))\) for every \(\varphi \in \text{PL}_2(r)\), where \((\bar{G}_k, \bar{\gamma}) \sim N(0, \tau_k^2) \otimes \pi =: \bar{\mu}^k\). Consequently, denoting by \(\hat{\mu}_n^k := \nu_n(\eta_n, \theta_n) = n^{-1} \sum_{i=1}^n \delta_{(\eta_{ni}, \theta_{ni})}\) the joint empirical distribution of the components of \(\eta_n\) and \(\theta_n\) for each \(n\), we deduce using Corollary B.21(a) that \(d_r(\hat{\mu}_n^k, \bar{\mu}^k) \xrightarrow{a.s.} 0\), and hence that \((\hat{\mu}_n^k)\) converges weakly to \(\bar{\mu}^k\) with probability 1. By (A5), \(f'_k\) is bounded, Borel measurable and continuous \(\bar{\mu}^k\)-almost everywhere, so we may now apply Lemma B.14 to conclude that \(\beta_n = \langle f'_k(\eta_n, \theta_n) \rangle_n = \int_{\mathbb{R}^2} f'_k \, d\hat{\mu}_n^k \to \int_{\mathbb{R}^2} f'_k \, d\bar{\mu}^k = \mathbb{E}(f'_k(\bar{G}_k, \bar{\gamma}))\) almost surely. This completes the proof of $\mathcal{H}_k(g)$.
