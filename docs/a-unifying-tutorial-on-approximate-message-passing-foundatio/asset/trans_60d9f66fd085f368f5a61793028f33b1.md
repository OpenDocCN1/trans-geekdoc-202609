### 引理 3.8 的证明。

令 \mu \neq 0 \text{ 且 } \sigma > 0, \text{ 并令 } V \sim \pi \text{ 和 } G \sim N(0, 1) \text{ 相互独立。则 } \mu V + \sigma G \text{ 具有勒贝格密度 } y \mapsto p(y) := \int_{\mathbb{R}} \phi_\sigma(y - \mu x) d\pi(x) > 0, \text{ 其中 } \phi_\sigma: z \mapsto (\sqrt{2\pi}\sigma)^{-1} e^{-z^2/(2\sigma^2)} \text{ 是 } \sigma G \sim N(0, \sigma^2) \text{ 的密度。而且，由于 } \phi_\sigma \text{ 的所有导数在 } \mathbb{R} \text{ 上有界，我们可以在积分符号下反复求导，以看出 } p^{(j)}(y) = \int_{\mathbb{R}} \phi_\sigma^{(j)}(y - \mu x) d\pi(x) \text{ 对所有 } y \text{ 和 } j \in \mathbb{N}_0 \text{ 成立，因此 } p \text{ 是 } \mathbb{R} \text{ 上的光滑函数。对每个 } y \in \mathbb{R}, \text{ 定义 } \pi_y \text{ 为 } \mathbb{R} \text{ 上具有密度（即 Radon-Nikodym 导数）的分布}

\frac{d\pi_y}{d\pi}: x \mapsto \frac{\phi_\sigma(y - \mu x)}{\int_{\mathbb{R}} \phi_\sigma(y - \mu x') d\pi(x')} = \frac{\phi_\sigma(y - \mu x)}{p(y)} \quad \text{(A.59)} 相对于 \(\pi\)。

可以轻易验证，\(\pi_y\) 是 “给定 \(\mu V + \sigma G = y\) 时 \(V\) 的条件分布”，从 Remark B.5(II) 的意义上正式成立。根据这一点以及 Dudley (2002, Theorem 10.2.5)，取 \(V_y \sim \pi_y\) 并对 \(y \in \mathbb{R}\) 定义 \(g(y) := \mathbb{E}(V_y) = \int_{\mathbb{R}} x \, d\pi_y(x)\)，则有 \(\mathbb{E}(V \mid \mu V + \sigma G) = g(\mu V + \sigma G)\)。对每个 \(y\)，注意

\(g(y) = \frac{\int_{\mathbb{R}} x \phi_\sigma(y - \mu x) \, d\pi(x)}{\int_{\mathbb{R}} \phi_\sigma(y - \mu x) \, d\pi(x)} = \frac{\int_{\mathbb{R}} \mu^{-1} (y \phi_\sigma(y - \mu x) + \phi'_\sigma(y - \mu x)) \, d\pi(x)}{\int_{\mathbb{R}} \phi_\sigma(y - \mu x) \, d\pi(x)} = \frac{y + \sigma^2(\log p)'(y)}{\mu},\)
(A.60)

因此 (3.17) 成立，且 \(g\) 在 \(\mathbb{R}\) 上无限可微，通过类似的计算，

\(g'(y) = \frac{1 + \sigma^2(\log p)''(y)}{\mu} = \frac{\mu \, \sigma^2(1 + \sigma^2(\log p)''(y))}{\sigma^2 \, \mu^2} = \frac{\mu}{\sigma^2}\text{Var}(V_y) \ge 0.\)

我们现在逐一考虑引理陈述中关于 \(\pi\) 的两个条件。

- (i) 若 \(V \sim \pi\) 具有对数凹密度，则 \(\mu V + \sigma G\) 的密度 \(p\) 也是对数凹的 (Prékopa, 1980)，因此 \((\log p)'' \le 0\) 在 \(\mathbb{R}\) 上成立。故在 \(\mathbb{R}\) 上 \(0 \le g' \le |\mu|^{-1}\)，所以 \(g\) 是利普希茨连续的，常数为 \(|\mu|^{-1}\)。

- (ii) 首先假设 \(\pi\) 支持于紧区间 \([a, b]\)。那么对每个 \(y \in \mathbb{R}\)，分布 \(\pi_y\) 相对于 \(\pi\) 具有密度（按定义），因此它也支持于 \([a, b]\)。故对所有 \(y\)，\(\text{Var}(V_y) \le \mathbb{E}\{ (V_y - (a+b)/2)^2 \} \le (b-a)^2/4\)，由此 \(g\) 是利普希茨连续的，常数为 \(|\mu|(b-a)^2/(4\sigma^2)\)，且

\(-1 \le \sigma^2(\log p)''(y) \le \frac{\mu^2(b-a)^2}{4\sigma^2} - 1.\) (A.61)

更一般地，假设 \(\pi\) 是 \(U_0 + V_0\) 的分布，其中 \(U_0 \sim N(0, \sigma_0^2)\) 且 \(\sigma_0 \ge 0\)，而 \(V_0 \sim \pi_0\) 与 \(U_0\) 独立且支持于某个紧区间 \([a, b]\)。那么 \(p\) 是 \(\mu V + \sigma G \stackrel{d}{=} \mu U_0 + \sqrt{\sigma^2 + \mu^2 \sigma_0^2} G\) 的密度，因此由 (A.60) 和 (A.61) 得出

```
\frac{1}{|\mu|} \left( 1 - \frac{\sigma^2}{\sigma^2 + \mu^2 \sigma_0^2} \right) \le |g'| \le \frac{1}{|\mu|} \left\{ 1 + \frac{\sigma^2}{\sigma^2 + \mu^2 \sigma_0^2} \left( \frac{\mu^2(b-a)^2}{4(\sigma^2 + \mu^2 \sigma_0^2)} - 1 \right) \right\}
```

在 \(\mathbb{R}\) 上。因此，右边的表达式是 \(g\) 的一个利普希茨常数。

### 引理 3.7 的证明。

令 \(\psi: \mathbb{R}^2 \to [0, \infty)\) 为任意可测损失函数，并固定 \(s_1, s_2 \in (0, \infty)\) 且 \(s_1 > s_2\)。取 \(G' \sim N(0, s_1^2 - s_2^2)\)、\(V \sim \pi\) 和 \(G \sim N(0, 1)\) 联合独立，我们首先声明

```
R_{\pi, \psi}(s_2^{-2}) = \inf_g \mathbb{E}\{\psi(g(V + s_2G), V)\} = \inf_{\tilde{g}} \mathbb{E}\{\psi(\tilde{g}(V + s_2G, G'), V)\}, \tag{A.62}
```

其中下确界分别对所有可测的 \(g: \mathbb{R} \to \mathbb{R}\) 和 \(\tilde{g}: \mathbb{R}^2 \to \mathbb{R}\) 取。确实，第一个等式成立是因为当 \(\rho = s_2^{-2}\) 时 \(V + s_2G = s_2(\sqrt{\rho}V + G)\)，且中间表达式显然不低于最后一个表达式，因此只需证明反向不等式。对于任何固定的 \(\tilde{g}: \mathbb{R}^2 \to \mathbb{R}\)，我们有

```
\tilde{\Psi}(a) := \mathbb{E}\{\psi(\tilde{g}(V + s_2G, a), V)\} \ge \inf_g \mathbb{E}\{\psi(g(V + s_2G), V)\} = R_{\pi, \psi}(s_2^{-2})
```

对所有 \(a \in \mathbb{R}\)，因此由引理 B.7 可知 \(\mathbb{E}\{\psi(\tilde{g}(V + s_2G, G'), V)\} = \mathbb{E}(\tilde{\Psi}(G')) \ge R_{\pi, \psi}(s_2^{-2})\)，故 (A.62) 成立。由于 \((V, V + s_2G + G') \stackrel{d}{=} (V, V + s_1G)\)，我们推断出

```
R_{\pi, \psi}(s_2^{-2}) = \inf_{\tilde{g}} \mathbb{E}\{\psi(\tilde{g}(V + s_2G, G'), V)\} \le \inf_g \mathbb{E}\{\psi(g(V + s_2G + G'), V)\} = \inf_g \mathbb{E}\{\psi(g(V + s_1G), V)\} = R_{\pi, \psi}(s_1^{-2}).
```

此外，如同上面为 (A.62) 所论证的，我们有

```
R_{\pi, \psi}(s_1^{-2}) = \inf_g \mathbb{E}\{\psi(g(V + s_1G), V)\} \le \inf_{a \in \mathbb{R}} \mathbb{E}\{\psi(a, V)\} = \inf_g \mathbb{E}\{\psi(g(G), V)\} = R_{\pi, \psi}(0).
```

因此，\(\rho \mapsto R_{\pi, \psi}(\rho)\) 在 \([0, \infty)\) 上是非增的。最后，固定 \(\rho \in (0, \infty)\)，并对每个 \(y \in \mathbb{R}\)，令 \(V_y \sim \pi_y\) 为一个随机变量，其相对于 \(\pi\) 的密度由 (A.59) 给出，其中 \(\mu = \sqrt{\rho}\) 和 \(\sigma = 1\)，因此 \(\pi_y\) 是给定 \(\sqrt{\rho}V + G = y\) 时 \(V\) 的条件（即后验）分布。根据 Brown and Purves (1973, Theorem 3)，若后验风险函数

\(r_y: a \mapsto \mathbb{E}(\psi(a, V_y))\)

在勒贝格几乎处处 \(y \in \mathbb{R}\) 上于 \(\mathbb{R}\) 上取得其下确界，则存在可测的 \(g^* \equiv g^*: \mathbb{R} \rightarrow \mathbb{R}\)，使得对勒贝格几乎处处 \(y \in \mathbb{R}\) 有 \(g^*(y) \in \argmin_{a \in \mathbb{R}} \mathbb{E}(\psi(a, V_y))\)，故 \(R_{\pi, \psi}(\rho) = \mathbb{E}\{\psi(g^*(\sqrt{\rho}V + G), V)\}\)。若对某个凸函数 \(\Psi\) 有 \(\psi(x, y) = \Psi(x - y)\) 且 \(\Psi(u) \rightarrow \infty\) 当 \(|u| \rightarrow \infty\)，则此情况成立（对每个 \(\rho\)），此时对每个 \(y \in \mathbb{R}\)，\(r_y: a \mapsto \mathbb{E}(\psi(V_y, a))\) 是凸的且 \(r_y(a) \rightarrow \infty\) 当 \(|a| \rightarrow \infty\)。\(\square\)

### 推论 A.19。

给定独立随机变量 \(V \sim \pi\) 和 \(G \sim N(0, 1)\)，函数 \(\rho \mapsto \text{mmse}(\rho) := \mathbb{E}\{(V - \mathbb{E}(V \mid \sqrt{\rho}V + G))^2\}\) 在 \([0, \infty)\) 上是非增的。此外，若 \(V\) 满足引理 3.8 中的条件之一，则 \(\rho \mapsto \text{mmse}(\rho)\) 在 \((0, \infty)\) 上也是连续的。
