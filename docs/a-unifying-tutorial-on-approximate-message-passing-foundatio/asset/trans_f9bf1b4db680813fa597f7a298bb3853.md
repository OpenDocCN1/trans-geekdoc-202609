### 3.3 选择函数 \(g_k\)

回顾，我们的目标是将通用AMP算法(3.3)特化，以产生\(v\)的估计\(\hat{v}^k = g_k(v^k)$，这些估计利用来自(M1)的极限前验分布\(\pi$的全部或部分知识。推论3.2表明，我们应致力于选择一系列利普希茨“去噪”函数\(g_k: \mathbb{R} \to \mathbb{R}\)，使得每个\(g_k(\mu_k V + \sigma_k G_k)$在限制性单变量问题中作为\(V \sim \pi$的估计器表现良好，其中\(G_k \sim N(0, 1)$对\(k \in \mathbb{N}\)与\(V\)独立。更准确地说，确保每个\(k$的有效信噪比\(\rho_k = (\mu_k / \sigma_k)^2$较大将是可取的，因为(3.11)告诉我们，\(\hat{v}^k$和\(v$之间的渐近经验相关性由\(\sqrt{\rho_{k+1}} / \lambda\)给出。实际上，下面的引理3.7的含义是，实现高有效信噪比应是我们的首要任务，即使最终目标是\(\hat{v}^k = g_k(v^k)$相对于某个特定损失函数\(\psi \in PL_2(2)$具有低渐近估计误差\(\mathbb{E}\{\psi(g_k(\mu_k V + \sigma_k G_k), V)\}\)。

### Lemma 3.7.
设\(G \sim N(0, 1)$与\(V \sim \pi\)独立。那么对于任何博雷尔可测损失函数\(\psi: \mathbb{R}^2 \rightarrow [0, \infty)\)，

$$
\rho \mapsto \inf_g \mathbb{E}\{\psi(g(\sqrt{\rho}V + G), V)\} =: R_{\pi, \psi}(\rho)
$$

在\([0, \infty)$上是单调非递增的，其中下确界取遍所有博雷尔可测函数\(g: \mathbb{R} \to \mathbb{R}\)。如果例如\(\psi(x, y) = \Psi(x - y)$对某个凸函数\(\Psi$且\(\Psi(u) \rightarrow \infty$当\(|u| \rightarrow \infty$，则该下确界对所有\(\rho \in [0, \infty)$都可达成。

此结果背后的直觉很简单：要共同最小化\(\mathbb{E}\{\psi(g(\sqrt{\rho}V + G), V)\}$在\(\rho$（属于给定范围）和所有可测函数\(g$上，我们应始终首先取最大可能的\(\rho$（即最少噪声的\(\sqrt{\rho}V + G$），随后再优化\(g\)。引理3.7的正式证明推迟到第A.8节。该节中的论证还表明，如果下确界仅取遍利普希茨函数（这些函数与AMP设置更相关），则引理的第一个断言依然成立。

注意，对于（已知的）\(\mu, \sigma \in \mathbb{R}$且\((\mu/\sigma)^2 = \rho\)，量\(R_{\pi, \psi}(\rho)$是在贝叶斯均值估计问题中的\(\pi$-贝叶斯风险，相对于\(\psi$，其中我们在\(V$上放置一个前验\(\pi$并观察\(Y = \mu V + \sigma G$（如上一段所述），即\(Y|V \sim N(\mu V, \sigma^2)$。如果存在一个博雷尔可测函数\(g^*: \mathbb{R} \to \mathbb{R}$达成\(R_{\pi, \psi}(\rho)\)定义中的下确界，那么\(g^*(Y)$是基于\(Y$的\(V$的\(\pi$-贝叶斯估计器（相对于\(\psi$）。
