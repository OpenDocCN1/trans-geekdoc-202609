### Proof of Lemma 3.8.

Fix \mu \neq 0 \text{ and } \sigma > 0, \text{ and let } V \sim \pi \text{ and } G \sim N(0, 1) \text{ be independent. Then } \mu V + \sigma G \text{ has Lebesgue density } y \mapsto p(y) := \int_{\mathbb{R}} \phi_\sigma(y - \mu x) d\pi(x) > 0, \text{ where } \phi_\sigma: z \mapsto (\sqrt{2\pi}\sigma)^{-1} e^{-z^2/(2\sigma^2)} \text{ is the density of } \sigma G \sim N(0, \sigma^2). \text{ Moreover, since all the derivatives of } \phi_\sigma \text{ are bounded on } \mathbb{R}, \text{ we can differentiate repeatedly under the integral sign to see that } p^{(j)}(y) = \int_{\mathbb{R}} \phi_\sigma^{(j)}(y - \mu x) d\pi(x) \text{ for all } y \text{ and } j \in \mathbb{N}_0, \text{ so } p \text{ is a smooth function on } \mathbb{R}. \text{ For each } y \in \mathbb{R}, \text{ define } \pi_y \text{ to be the distribution on } \mathbb{R} \text{ with density (i.e. Radon-Nikodym derivative)}

\frac{d\pi_y}{d\pi}: x \mapsto \frac{\phi_\sigma(y - \mu x)}{\int_{\mathbb{R}} \phi_\sigma(y - \mu x') d\pi(x')} = \frac{\phi_\sigma(y - \mu x)}{p(y)} \quad \text{(A.59)} with respect to \(\pi\). It is easily verified that \(\pi_y\) is the “conditional distribution of \(V\) given \(\mu V + \sigma G = y\)”, formally in the sense of Remark B.5(II). It follows from this and Dudley (2002, Theorem 10.2.5) that taking \(V_y \sim \pi_y\) and defining \(g(y) := \mathbb{E}(V_y) = \int_{\mathbb{R}} x \, d\pi_y(x)\) for \(y \in \mathbb{R}\), we have \(\mathbb{E}(V \mid \mu V + \sigma G) = g(\mu V + \sigma G)\). For each \(y\), note that

\(g(y) = \frac{\int_{\mathbb{R}} x \phi_\sigma(y - \mu x) \, d\pi(x)}{\int_{\mathbb{R}} \phi_\sigma(y - \mu x) \, d\pi(x)} = \frac{\int_{\mathbb{R}} \mu^{-1} (y \phi_\sigma(y - \mu x) + \phi'_\sigma(y - \mu x)) \, d\pi(x)}{\int_{\mathbb{R}} \phi_\sigma(y - \mu x) \, d\pi(x)} = \frac{y + \sigma^2(\log p)'(y)}{\mu},\)
(A.60)

so (3.17) holds and \(g\) is infinitely differentiable on \(\mathbb{R}\), and by similar calculations,

\(g'(y) = \frac{1 + \sigma^2(\log p)''(y)}{\mu} = \frac{\mu \, \sigma^2(1 + \sigma^2(\log p)''(y))}{\sigma^2 \, \mu^2} = \frac{\mu}{\sigma^2}\text{Var}(V_y) \ge 0.\)

We now consider in turn the two conditions on \(\pi\) in the statement of the lemma.

- (i) If \(V \sim \pi\) has a log-concave density, then the density \(p\) of \(\mu V + \sigma G\) is also log-concave (Prékopa, 1980), so \((\log p)'' \le 0\) on \(\mathbb{R}\). Thus, \(0 \le g' \le |\mu|^{-1}\) on \(\mathbb{R}\), so \(g\) is Lipschitz with constant \(|\mu|^{-1}\).

- (ii) Suppose first that \(\pi\) is supported on a compact interval \([a, b]\). Then for each \(y \in \mathbb{R}\), the distribution \(\pi_y\) has a density with respect to \(\pi\) (by definition), so it is also supported on \([a, b]\). Thus, \(\text{Var}(V_y) \le \mathbb{E}\{ (V_y - (a+b)/2)^2 \} \le (b-a)^2/4\) for all \(y\), whence \(g\) is Lipschitz with constant \(|\mu|(b-a)^2/(4\sigma^2)\), and

\(-1 \le \sigma^2(\log p)''(y) \le \frac{\mu^2(b-a)^2}{4\sigma^2} - 1.\) (A.61)

More generally, suppose that \(\pi\) is the distribution of \(U_0 + V_0\), where \(U_0 \sim N(0, \sigma_0^2)\) with \(\sigma_0 \ge 0\), and \(V_0 \sim \pi_0\) is independent of \(U_0\) and supported on some compact interval \([a, b]\). Then \(p\) is the density of \(\mu V + \sigma G \stackrel{d}{=} \mu U_0 + \sqrt{\sigma^2 + \mu^2 \sigma_0^2} G\), so it follows from (A.60) and (A.61) that

```
\frac{1}{|\mu|} \left( 1 - \frac{\sigma^2}{\sigma^2 + \mu^2 \sigma_0^2} \right) \le |g'| \le \frac{1}{|\mu|} \left\{ 1 + \frac{\sigma^2}{\sigma^2 + \mu^2 \sigma_0^2} \left( \frac{\mu^2(b-a)^2}{4(\sigma^2 + \mu^2 \sigma_0^2)} - 1 \right) \right\}
```

on R. The expression on the right hand side is therefore a Lipschitz constant for g.

### Proof of Lemma 3.7.

Let \(\psi: \mathbb{R}^2 \to [0, \infty)\) be any measurable loss function, and fix \(s_1, s_2 \in (0, \infty)\) with \(s_1 > s_2\). Taking \(G' \sim N(0, s_1^2 - s_2^2)\), \(V \sim \pi\) and \(G \sim N(0, 1)\) to be jointly independent, we first claim that

```
R_{\pi, \psi}(s_2^{-2}) = \inf_g \mathbb{E}\{\psi(g(V + s_2G), V)\} = \inf_{\tilde{g}} \mathbb{E}\{\psi(\tilde{g}(V + s_2G, G'), V)\}, \tag{A.62}
```

where the infima are taken over all measurable \(g: \mathbb{R} \to \mathbb{R}\) and \(\tilde{g}: \mathbb{R}^2 \to \mathbb{R}\) respectively. Indeed, the first equality holds since \(V + s_2G = s_2(\sqrt{\rho}V + G)\) when \(\rho = s_2^{-2}\), and the middle expression is clearly bounded below by the final one, so it remains to prove the reverse inequality. For any fixed \(\tilde{g}: \mathbb{R}^2 \to \mathbb{R}\), we have

```
\tilde{\Psi}(a) := \mathbb{E}\{\psi(\tilde{g}(V + s_2G, a), V)\} \ge \inf_g \mathbb{E}\{\psi(g(V + s_2G), V)\} = R_{\pi, \psi}(s_2^{-2})
```

for all \(a \in \mathbb{R}\), so it follows from Lemma B.7 that \(\mathbb{E}\{\psi(\tilde{g}(V + s_2G, G'), V)\} = \mathbb{E}(\tilde{\Psi}(G')) \ge R_{\pi, \psi}(s_2^{-2})\), and hence that (A.62) holds. Since \((V, V + s_2G + G') \stackrel{d}{=} (V, V + s_1G)\), we deduce that

```
R_{\pi, \psi}(s_2^{-2}) = \inf_{\tilde{g}} \mathbb{E}\{\psi(\tilde{g}(V + s_2G, G'), V)\} \le \inf_g \mathbb{E}\{\psi(g(V + s_2G + G'), V)\} = \inf_g \mathbb{E}\{\psi(g(V + s_1G), V)\} = R_{\pi, \psi}(s_1^{-2}).
```

In addition, arguing as above for (A.62), we have

```
R_{\pi, \psi}(s_1^{-2}) = \inf_g \mathbb{E}\{\psi(g(V + s_1G), V)\} \le \inf_{a \in \mathbb{R}} \mathbb{E}\{\psi(a, V)\} = \inf_g \mathbb{E}\{\psi(g(G), V)\} = R_{\pi, \psi}(0).
```

Thus, \(\rho \mapsto R_{\pi, \psi}(\rho)\) is non-increasing on \([0, \infty)\). Finally, fix \(\rho \in (0, \infty)\) and for each \(y \in \mathbb{R}\), let \(V_y \sim \pi_y\) be a random variable whose density with respect to \(\pi\) is given by (A.59) with \(\mu = \sqrt{\rho}\) and \(\sigma = 1\), so that \(\pi_y\) is the conditional (i.e. posterior) distribution of \(V\) given \(\sqrt{\rho}V + G = y\). It follows from Brown and Purves (1973, Theorem 3) that if the posterior risk function

\(r_y: a \mapsto \mathbb{E}(\psi(a, V_y))\)

attains its infimum on \(\mathbb{R}\) for Lebesgue almost every \(y \in \mathbb{R}\), then there exists a measurable \(g^* \equiv g^*: \mathbb{R} \rightarrow \mathbb{R}\) with \(g^*(y) \in \argmin_{a \in \mathbb{R}} \mathbb{E}(\psi(a, V_y))\) for Lebesgue almost every \(y \in \mathbb{R}\), whence \(R_{\pi, \psi}(\rho) = \mathbb{E}\{\psi(g^*(\sqrt{\rho}V + G), V)\}\). This is the case (for every \(\rho\)) if \(\psi(x, y) = \Psi(x - y)\) for some convex function \(\Psi\) with \(\Psi(u) \rightarrow \infty\) as \(|u| \rightarrow \infty\), in which case \(r_y: a \mapsto \mathbb{E}(\psi(V_y, a))\) is convex with \(r_y(a) \rightarrow \infty\) as \(|a| \rightarrow \infty\), for each \(y \in \mathbb{R}\). \(\square\)
