

总而言之，AMP算法（3.3）的状态演化刻画使我们能够以一种有依据的方式选择函数 \(g_k\)，具体取决于关于信号 \(v\) 的可用先验信息。对 \((g_k)\) 的糟糕选择会导致较低的有效信噪比 \(\rho_k = (\mu_k/\sigma_k)^2\)，但只要满足定理 3.1 或 3.5 的假设，渐近收敛结果（3.8）-（3.11）仍将成立。

AMP框架的一个关键优势在于它赋予我们选择非线性函数 \(g_k\) 的灵活性，例如上面的软阈值函数。请注意，（3.16）中的MMSE去噪函数 \(g_k^*\) 除特殊情况外均为非线性（例如，当 \(V\) 服从高斯分布时）。尽管如此，使用线性 \(g_k\) 的迭代有时可以作为一种理论工具，用于获取谱估计器的分布信息，如以下示例所示；另请参见 Mondelli and Venkataramanan (2020) 和 Mondelli et al. (2021)。

**与功率迭代法的联系**：假设我们用 \(\hat{v}^0 \equiv \hat{v}^0(n) := \mu_0 v + \xi\) 初始化（3.3），其中 \(\mu_0 \neq 0\) 且 \(\xi \equiv \xi(n) \sim N_n(0, I_n)\)，并定义

\(\beta_k := \sqrt{1+\mu_k^2}, \qquad g_k(x) := \frac{x}{\beta_k} \quad \text{for } x \in \mathbb{R},\)

\(\mu_{k+1} := \frac{\lambda}{\sqrt{1+\mu_k^{-2}}} \quad \text{for } k \in \mathbb{N}_0.\)

(3.27)

这些函数 \(g_k\) 的构造方式使得相应的状态演化公式（3.6）对每个 \(k\) 都给出 \(\sigma_k^2 = 1\)，且参数 \(\mu_k\) 与（3.27）中定义的完全一致。现在观察，与（3.27）对应的AMP迭代（3.3）产生 \((\hat{v}^k \equiv \hat{v}^k(n): k \in \mathbb{N})\)，满足 \(\beta_0 \hat{v}^1 = v^1 = A\hat{v}^0\) 以及

\(\left(\beta_k + \frac{1}{\beta_{k-1}}\right)\hat{v}^{k+1} - \frac{1}{\beta_{k-1}}(\hat{v}^{k+1} - \hat{v}^{k-1}) = A\hat{v}^k \quad \text{for } k \in \mathbb{N}.\)

(3.28)

对（3.28）进行理论分析的关键步骤可总结如下：

- (i) 当 \(\lambda > 1\) 时，一些初等分析（例如，基于压缩映射定理）表明 \(\sqrt{\lambda^2-1}\) 是（3.27）中 \((\mu_k)\) 的确定性递归的一个稳定不动点，因此当 \(k \to \infty\) 时有 \(\beta_k \to \lambda\)。
- (ii) 使用定理 3.1 和（3.7）中定义的协方差矩阵，我们可以获取当 \(n \to \infty\) 时，\(\hat{v}^{k+1} \equiv \hat{v}^{k+1}(n)\) 和 \(\hat{v}^{k-1} \equiv \hat{v}^{k-1}(n)\) 的分量的联合经验分布的 \(d_2\) 极限；特别是，\(\|\hat{v}^{k+1}\|_n \xrightarrow{c} 1\)。然后从 (i) 和常规论证中可得出 \(\lim_{k \to \infty} \text{c-lim}_{n \to \infty} \|\hat{v}^{k+1} - \hat{v}^{k-1}\|_n = 0\)。换句话说，对于每个固定的 \(k\)，\(\|\hat{v}^{k+1} - \hat{v}^{k-1}\|_n\) 在 \(n \to \infty\) 时完全收敛到某个确定性极限 \(\ell_k\)，且当 \(k \to \infty\) 时有 \(\ell_k \to 0\)。
- (iii) 因此，将（3.28）写成 \(A\hat{v}^k = (\lambda + \lambda^{-1})\hat{v}^{k+1} + \vartheta_k\) 的形式，其中 \(k, n \in \mathbb{N}\)，且

\(\vartheta_k \equiv \vartheta_k(n) := \left\{ \left( \beta_k + \frac{1}{\beta_{k-1}} \right) - \left( \lambda + \frac{1}{\lambda} \right) \right\} \hat{v}^{k+1} - \frac{1}{\beta_{k-1}} (\hat{v}^{k+1} - \hat{v}^{k-1}),\)

我们从 (i) 和 (ii) 推断出 \(\lim_{k \to \infty} \text{c-lim}_{n \to \infty} \|\vartheta_k\|_n = 0\)。

利用这些成分以及 \(A \equiv A(n)\) 的极限谱间隙在 \(\lambda > 1\) 时严格为正这一事实，可以建立

\(\lim_{k \to \infty} \text{c-lim}_{n \to \infty} \frac{|\langle \hat{v}^k, \hat{\varphi} \rangle_n|}{\|\hat{v}^k\|_n} = 1.\)

这表明AMP迭代的特定实例（3.28）在渐近意义上等价于用于近似 \(\hat{\varphi}\) 的广为人知的功率迭代法，尽管 \(\hat{v}^0\) 对未知 \(v\) 的依赖意味着我们无法在实践中将（3.28）作为算法使用。尽管如此，这种渐近等价性确保我们可以应用定理 3.1 来获取 \(\hat{\varphi}\) 和信号 \(v\) 的分量联合经验分布中提议 3.4 的 \(d_2\) 收敛结果。

## 3.4 置信区间和 p 值

作为定理 3.1 的结果，请回顾推论 3.2 之后的讨论：对于固定的 \(k\) 和足够大的 \(n\)，通用过程（3.3）中的AMP迭代（即有效观测）\(v^k \equiv v^k(n)\) 具有如下性质：\(\{(v_i^k - \mu_k v_i)/\sigma_k: 1 \le i \le n\}\) 表现得大约来自 \(N(0, 1)\) 分布的大小为 \(n\) 的独立同分布样本。因此，对于给定的 \(\alpha \in [0, 1]\)，我们预计这些分量中大约有 \(n(1 - \alpha)\) 个的绝对值不超过 \(z_{\alpha/2} := \Phi^{-1}(1 - \alpha/2)\)，其中 \(\Phi^{-1}\) 表示 \(N(0, 1)\) 分布的分位数函数。基于这一观察，我们将简要说明如何为 \(v \equiv v(n)\) 的元素及相关 \(p\)-值构建置信区间。根据注 3.3，（可能未知的）状态演化参数 \(\mu_k, \sigma_k\) 可以分别由 \(\hat{\mu}_k \equiv \hat{\mu}_k(n) = (\|v^k\|_n^2 - \|v^{k-1}\|_n^2)^{1/2}\) 和 \(\hat{\sigma}_k \equiv \hat{\sigma}_k(n) = \|v^{k-1}\|_n\) 对每个 \(k \in \mathbb{N}\) 一致估计，因此我们定义

\(\hat{J}_i^k(n, \alpha) := \left[ \frac{v_i^k - z_{\alpha/2} \hat{\sigma}_k}{\hat{\mu}_k}, \frac{v_i^k + z_{\alpha/2} \hat{\sigma}_k}{\hat{\mu}_k} \right] \text{ and } p_i^k \equiv p_i^k(n) = 2 \left\{ 1 - \Phi \left( \frac{|v_i^k|}{\hat{\sigma}_k} \right) \right\}\)
(3.29)

for \(k, n \in \mathbb{N}\), \(1 \le i \le n\) 和 \(\alpha \in [0, 1]\)。Montanari and Venkataramana (2021, Corollary 3.1) 表明，对于固定的 \(k \in \mathbb{N}\) 和 \(\alpha \in [0, 1]\)，置信区间 \(\hat{J}_1^k(n, \alpha), \dots, \hat{J}_n^k(n, \alpha)\) 具有渐近平均覆盖水平 \(1 - \alpha\)；具体地，

\(\text{c-}\lim_{n \to \infty} \frac{1}{n} \sum_{i=1}^n \mathbb{1}_{\{v_i(n) \in \hat{J}_i^k(n, \alpha)\}} = 1 - \alpha = \lim_{n \to \infty} \frac{1}{n} \sum_{i=1}^n \mathbb{P}(v_i(n) \in \hat{J}_i^k(n, \alpha)).\)

上述第一个极限可以通过考虑区间指示函数的 Lipschitz 近似，并诉诸定理 3.1 或 3.5（分别用于非谱初始化和谱初始化）来建立。然后可以应用主导收敛定理从第一个等式推导出第二个等式。请注意，对于固定的 \(k, \alpha\)，每个 \(\hat{J}_i^k(n, \alpha)\) 的渐近宽度为 \(2z_{\alpha/2}/\rho_k\)，当使用经验贝叶斯-AMP 迭代来构建这些区间时，该宽度最小。

此外，假设当 \(n \to \infty\) 时，尖峰 \(v \equiv v(n)\) 中非零元素的比例趋于 \(\delta \in (0, 1)\)。那么上述结果断言，（3.29）中定义的 \(p\)-值对零假设 \(\mathcal{N}_n := \{1 \le i \le n: v_i \equiv v_i(n) = 0\}\) 在渐近意义上是有效的，具体而言：对于任何索引序列 \((i_0(n) \in \mathcal{N}_n; n \in \mathbb{N})\) 和所有固定的 \(k \in \mathbb{N}\) 及 \(\alpha \in [0, 1]\)，有 \(\lim_{n \to \infty} \mathbb{P}(p_{i_0(n)}^k \le \alpha) = \alpha\)。

## 3.5 用于更一般低秩矩阵估计问题的AMP

多变量去噪函数：迄今为止，我们仅基于单个AMP迭代 \(v^k\) 研究了信号 \(v\) 的估计器 \(\hat{v}^k = g_k(v^k)\)。人们可以尝试通过设计同时利用所有先前迭代的估计器 \(g_k(v^0, \dots, v^k)\) 来提高估计精度，其中 \(g_k: \mathbb{R}^{k+1} \to \mathbb{R}\) 是一个Lipschitz函数，按行应用于 \((v^0 \dots v^k)\)。在高斯尖峰模型（3.1）中，考虑一种更一般的AMP算法，它使用与第3.1节或3.2节相同的初始值 \(\hat{v}^{-1}, v^0 \in \mathbb{R}^n\)，但迭代由以下方式归纳定义

\(\hat{v}^k := g_k(v^0, v^1, \dots, v^k),\)
\(b_{kj} := \langle \partial_j g_k(v^0, \dots, v^k) \rangle_n\)
\(= n^{-1} \sum_{i=1}^n \partial_j g_k(v_i^0, \dots, v_i^k) \quad \text{for } 1 \le j \le k\) (3.30)
\(v^{k+1} := A\hat{v}^k - \sum_{j=0}^k b_{kj} \hat{v}^{j-1}\)

for \(k \in \mathbb{N}_0\)。这里，\(\partial_j g_k\) 是Lipschitz函数 \((x_0, x_1 \dots, x_k) \mapsto g_k(x_0, x_1 \dots, x_k)\) 关于 \(x_j\)（\(0 \le j \le k\)）的弱导数。在第3.1节的设置中，状态演化参数 \(\mu_k, \sigma_k, \bar{\Sigma}^{[k]}\) 的递推（3.6）-（3.7）变为

\(\mu_{k+1} := \lambda \mathbb{E}(V g_k(\mu_k V + \bar{G}_k)), \quad \sigma_{k+1}^2 := \mathbb{E}(g_k(\mu_k V + \bar{G}_k)^2),\)
\(\bar{\Sigma}_{k, \ell} = \bar{\Sigma}_{\ell, k} := \mathbb{E}(g_{\ell-1}(\mu_{\ell-1} V + \bar{G}_{\ell-1}) \cdot g_{k-1}(\mu_{k-1} V + \bar{G}_{k-1}))\) (3.31)

for \(1 \le \ell \le k\)。这里，\(\mu_\ell := (\mu_0, \dots, \mu_\ell)\) 和 \(\bar{G}_\ell := (\sigma_0 U, \sigma_1 G_1, \dots, \sigma_\ell G_\ell)\) 是 \(0 \le \ell \le k\) 时的 \((\ell+1)\) 维随机向量，其中 \((\sigma_1 G_1, \dots, \sigma_k G_k) \sim N_k(0, \bar{\Sigma}^{[k]})\) 与 (M1) 中的 \((U, V)\) 独立。在谱初始化的情况下，\(\bar{\Sigma}^{[k]}\) 的递推（3.15）以类似方式推广。通过对定理 2.3 和推论 3.2 证明的相对直接的扩展，可得出

\(\frac{1}{n} \sum_{i=1}^n \psi(\hat{v}_i^k, v_i) \xrightarrow{C} \mathbb{E}\{\psi(g_k(\mu_k V + \bar{G}_k), V)\},\) (3.32)

前提是满足定理 3.1 或 3.5 的假设。因此，限制的单变量问题是基于 \(\mu_k V + \bar{G}_k = (\mu_0 V + \sigma_0 U, \mu_1 V + \sigma_1 G_1, \dots, \mu_k V + \sigma_k G_k)\) 来估计 \(V \sim \pi\)。
