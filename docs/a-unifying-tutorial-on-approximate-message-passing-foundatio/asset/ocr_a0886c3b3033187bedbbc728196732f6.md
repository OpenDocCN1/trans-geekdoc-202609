# **Theorem B.17.** Let \(P \in \mathcal{P}_D(r)\) and let \((P_n)\) be a sequence of probability measures in \(\mathcal{P}_D(r)\). Then there exists a countable set \(T_r \subseteq \text{PL}_D(r)\) such that the following are equivalent:

+   (i) \(\int_{\mathbb{R}^D} \psi \, dP_n \rightarrow \int_{\mathbb{R}^D} \psi \, dP\) for all \(\psi \in T_r\);

+   (ii) \(\tilde{d}_r(P_n, P) \rightarrow 0\);

+   (iii) \(d_r(P_n, P) \rightarrow 0\).

A suitable set \(T_r \subseteq \text{PL}_D(r)\) can be constructed by enlarging the set \(T'_r\) of bounded Lipschitz functions defined in (the proof of) Proposition B.16.

# **Remark B.18.** Using Theorem B.17, we can verify that \(\tilde{d}_r\) is a metric on \(\mathcal{P}(r) \equiv \mathcal{P}_D(r)\) that generates the same topology as \(d_r\). Indeed, it is clear from (1.4) and (B.13) that \(\tilde{d}_r\) takes values in \([0, \infty)\) and satisfies the triangle inequality on \(\mathcal{P}(r)\). In addition, if \(P, Q \in \mathcal{P}(r)\) are such that \(\tilde{d}_r(P, Q) = 0\), then by taking \(P_n = Q\) for all \(n\) in (ii) above, we deduce that \(d_r(P, Q) = 0\). Since \(d_r\) is a metric on \(\mathcal{P}(r)\) (e.g. Villani, 2003, Theorem 7.3), this yields \(P = Q\), as required. In fact, \((\mathcal{P}(r), d_r)\) is a separable, complete metric space (e.g. Panaretos and Zemel, 2020, Theorem 2.2.7 and Proposition 2.2.8), so by the equivalence (ii) \(\Leftrightarrow\) (iii) in Theorem B.17, the same is true of \((\mathcal{P}(r), \tilde{d}_r)\).
