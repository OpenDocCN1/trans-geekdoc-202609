
最小化 \(\sum_{i=1}^n \ell(\tilde{\theta}_i, y_i) + \sum_{j=1}^p J(\tilde{\beta}_j) \quad \text{over } (\tilde{\beta}, \tilde{\theta}) \in \mathbb{R}^p \times \mathbb{R}^n \text{ with } \tilde{\theta} = X \tilde{\beta},\) (4.22)

其中 \(\ell: \mathbb{R}^2 \rightarrow \mathbb{R}\) 是损失函数，\(J: \mathbb{R} \rightarrow \mathbb{R}\) 是惩罚函数。特别是，考虑形式为 (4.2) 的 GLM，其中 \(y_i | (x_i, \beta) \sim q(\cdot | x_i^\top \beta)\) 对 \(1 \le i \le n\) 成立，其中 \(q(\cdot | z)\) 是每个 \(z \in \mathbb{R}\) 上 \(\mathbb{R}\) 的勒贝格密度。那么 \(\beta\) 和 \(\theta = X\beta\) 的最大似然估计器（MLEs）由以下给出

\((\hat{\beta}^{MLE}, \hat{\theta}^{MLE}) := \underset{(\tilde{\beta}, \tilde{\theta}) \in \mathbb{R}^p \times \mathbb{R}^n}{\text{argmin}} \sum_{i=1}^n - \log q(y_i | \tilde{\theta}_i) \quad \tilde{\theta} = X\tilde{\beta}\)

如果此外 \(\beta_1, \dots, \beta_p \sim^{iid} p_{\bar{\beta}}\) 对某些先验密度 \(p_{\bar{\beta}}\)，那么 \(\beta\) 和 \(\theta\) 的最大后验（MAP）估计为

\((\hat{\beta}^{MAP}, \hat{\theta}^{MAP}) := \underset{(\tilde{\beta}, \tilde{\theta}) \in \mathbb{R}^p \times \mathbb{R}^n}{\text{argmin}} \left( \sum_{i=1}^n - \log q(y_i | \tilde{\theta}_i) + \sum_{j=1}^p - \log p_{\bar{\beta}}(\tilde{\beta}_j) \right). \quad \tilde{\theta} = X\tilde{\beta}\)

假设今后 \(\ell\) 和 \(J\) 在其第一个自变量上均为凸函数，我们将设计一个 GAMP 迭代 (4.29)，其固定点即为相关优化问题 (4.22) 的解；见下文提议 4.4。通过利用这一联系并应用第 4.1 节的 GAMP 理论，我们将稍后解释如何以精确高维渐近的形式获得统计收益，适用于由 (4.22) 定义的估计器。

为开始构造，固定两个确定性标量序列 \(\bar{b}_k > 0\) 和 \(\bar{c}_k < 0\) 对 \(k \in \mathbb{N}_0\)。这些序列将在下文 (4.29) 中被赋予适当值，但目前我们将它们视为通用常数。对于 \(k \in \mathbb{N}_0\)，定义 \(\bar{g}_k\)

\(\bar{g}_k(u, v) := \underset{z \in \mathbb{R}}{\text{argmin}} \left\{ \ell(z, v) + \frac{1}{2\bar{b}_k}(z-u)^2 \right\}, \quad g_k(u, v) := \frac{\bar{g}_k(u, v) - u}{\bar{b}_k},\) (4.23)

\(f_{k+1}(w) := \underset{z \in \mathbb{R}}{\text{argmin}} \left\{ J(z) - \frac{\bar{c}_k}{2} \left( z + \frac{w}{\bar{c}_k} \right)^2 \right\}.\) (4.24)

注意，由于假设 \(\ell\) 和 \(J\) 在其第一个自变量上是凸的，\(\bar{g}_k(u, v)\) 和 \(f_{k+1}(w)\) 作为强凸函数的唯一极小值是定义良好的。这种对 \(g_k, f_{k+1}\) 的特定选择的相关性将通过下文提议 4.4 及其证明变得明显。此时，有必要回顾，对于凸函数 \(\mathrm{M}: \mathbb{R} \rightarrow \mathbb{R}\) 和 \(\eta > 0\)，相关的 *近端算子* \(\text{prox}_{\eta \mathrm{M}}: \mathbb{R} \rightarrow \mathbb{R}\) 由以下给出：

```
\(\text{prox}_{\eta \mathrm{M}}(z) := \underset{t \in \mathbb{R}}{\mathrm{argmin}} \left\{ \eta \mathrm{M}(t) + \frac{1}{2}(t - z)^2 \right\}, \quad (4.25)\)
```

并且 \(\text{prox}_{\eta \mathrm{M}}\) 始终是非递减且 1-Lipschitz 的（参见 Parikh and Boyd, 2013，第 2.3 和 3.1 节）。我们可以看到，对于 \(u, v, w \in \mathbb{R}\)，有 \(\bar{g}_k(u, v) = \text{prox}_{b_k \ell(\cdot, v)}(u)\) 且 \(f_{k+1}(w) = \text{prox}_{-J/\bar{c}_k}(-w/\bar{c}_k)\)，因此 \(\bar{g}_k, g_k, f_{k+1}\) 都是 Lipschitz 连续的，其 Lipschitz 常数分别为 \(1, \bar{b}_k^{-1}\) 和 \(|\bar{c}_k|^{-1}\)，从而对其第一个自变量弱可微。将 \(\bar{g}'_k, g'_k, f'_{k+1}\) 写为相应的弱导数，我们有

```
\(f'_{k+1}(w) \ge 0, \quad \bar{g}'_k(u, v) \le 1 \quad \text{and hence} \quad g'_k(u, v) \le 0 \quad (4.26)\)
```

对所有 \(u, v, w\) 成立。如果此外 \(\ell\) 和 \(J\) 是二阶连续可微的，那么对于每个 \(w\)，都有 \(J'(f_{k+1}(w)) - (\bar{c}_k f_{k+1}(w) + w) = 0\)，因此根据隐函数定理可得

```
\(f'_{k+1}(w) = (J''(f_{k+1}(w)) - \bar{c}_k)^{-1} \quad \text{and similarly} \quad \bar{g}'_k(u, v) = (\bar{b}_k \ell''(f_{k+1}(w)) + 1)^{-1} \quad (4.27)\)
```

对所有 \(u, v, w\) 成立，其中 \(\ell''\) 表示 \(\ell\) 关于其第一个自变量的二阶偏导数。

我们将定义一个形式为 (4.4) 的 GAMP 递归，作为随后将用于分析优化问题 (4.22) 的解的统计特性的迭代 (4.29) 的前身。给定 \(\hat{s}^{-1} := 0 \in \mathbb{R}^n\)，一个固定的 \(b_0 > 0\) 和一个初始化器 \(\hat{\beta}^0 \in \mathbb{R}^p\)，递归定义

```
\(\theta^k := X \hat{\beta}^k - b_k \hat{s}^{k-1}, \qquad \hat{\theta}^k := \bar{g}_k(\theta^k, y),\)
\(c_k := n^{-1} \sum_{i=1}^n g'_k(\theta_i^k, y_i), \qquad \hat{s}^k := g_k(\theta^k, y),\)
\(\beta^{k+1} := X^\top \hat{s}^k - c_k \hat{\beta}^k, \qquad \hat{\beta}^{k+1} := f_{k+1}(\beta^{k+1}),\)
\(b_{k+1} := n^{-1} \sum_{j=1}^p f'_{k+1}(\beta_j^{k+1}) \quad (4.28)\)
```

对 \(k \in \mathbb{N}_0\) 成立。注意 \(\hat{s}^k = (\hat{\theta}^k - \theta^k)/\bar{b}_k\)，并且如果 \(\ell\) 和 \(J\) 关于其第一个自变量是凸且二阶连续可微的，那么 (4.27) 得出

\( c_k = \frac{1}{\bar{b}_k}\Big(\frac{1}{n}\sum_{i=1}^n \bar{g}'_k(\theta_i^k, y_i) - 1\Big) = -\frac{1}{n}\sum_{i=1}^n \frac{\ell''(\hat{\theta}_i^k, y_i)}{\bar{b}_k \ell''(\hat{\theta}_i^k, y_i) + 1},\)

\( b_{k+1} = \frac{1}{n}\sum_{j=1}^p \frac{1}{J''(\hat{\beta}_j^{k+1}) - \bar{c}_k}.\)

如果由一系列递归 (4.28) 满足定理 4.2 的假设，那么其中迭代的极限经验分布由相关状态演化参数 \((\mu_k, \sigma_k, \Sigma_k : k \in \mathbb{N})\) 刻画，这些参数通过 (4.6)-(4.7) 定义。此外，对于每个固定的 \( k \)，与 \((Z, Z_k) \sim N_2(0, \Sigma_k)\) 和 \(Y = h(Z, \bar{\varepsilon})\) 如引理 4.1 中所述，回顾从 (4.12) 得知 \( b_k \xrightarrow{c} \delta^{-1}\mathbb{E}(f'_k(\mu_k\bar{\beta} + \sigma_k G_k)) \) 和 \( c_k \xrightarrow{c} \mathbb{E}(g'_k(Z_k, Y)) \) 当 \( n, p \to \infty \) 且 \( n/p \to \delta \in (0, \infty) \) 时成立。

基于这一观察，我们将定义上述的 \(\bar{b}_k\) 和 \(\bar{c}_k\) 以与这些极限值一致，并用这些确定量替换 (4.28) 中的随机 \( b_k, c_k \) 以获得以下修改后的递归。与之前一样，我们从 \(\hat{s}^{-1} := 0 \in \mathbb{R}^n\)、\(\bar{b}_0 > 0\)、\(\hat{\beta}^0 \in \mathbb{R}^p\) 以及像 (G2) 中那样的正定矩阵 \(\Sigma_0 \in \mathbb{R}^{2 \times 2}\) 开始。给定 \(\hat{\beta}^k\)、\(\hat{s}^{k-1}\) 和对一般 \(k \in \mathbb{N}_0\) 的 \(\bar{b}_k, \Sigma_k\)，我们像在 (4.23) 中那样递归定义 \(\bar{g}_k, g_k\)，并伴随

\(\theta^k := X\hat{\beta}^k - \bar{b}_k\hat{s}^{k-1}, \qquad \hat{\theta}^k := \bar{g}_k(\theta^k, y),\)

\(\bar{c}_k := \mathbb{E}(g'_k(Z_k, Y)), \qquad \hat{s}^k := g_k(\theta^k, y),\)

\(\beta^{k+1} := X^\top \hat{s}^k - \bar{c}_k\hat{\beta}^k, \qquad \hat{\beta}^{k+1} := f_{k+1}(\beta^{k+1}),\)

\(\bar{b}_{k+1} := \delta^{-1}\mathbb{E}(f'_{k+1}(\mu_{k+1}\bar{\beta} + \sigma_{k+1}G_{k+1})).\)

(4.29)

在 (4.29) 中，我们取 \((Z, Z_k) \sim N_2(0, \Sigma_k)\) 和 \(Y = h(Z, \bar{\varepsilon})\) 如上述，并根据 \( g_k \) 如 (4.6) 中所述定义状态演化参数 \(\mu_{k+1}, \sigma_{k+1}\)，同时使用 \(\bar{c}_k\) 和 (4.24) 来指定 \( f_{k+1} \)。最后，根据 (4.7) 用 \( f_{k+1}, \mu_{k+1}, \sigma_{k+1} \) 定义 \(\Sigma_{k+1}\)。我们强调，函数 \(\bar{g}_k, f_{k+1}\) 对所有 \( k \) 确实通过 (4.23)-(4.24) 定义良好，因为根据 (4.26) 有 \(\bar{b}_k > 0 > \bar{c}_k\)，并且对于任何凸函数 \(\text{M}: \mathbb{R} \to \mathbb{R}\)，\(\text{prox}_{\text{M}}\) 都是非常数的。
