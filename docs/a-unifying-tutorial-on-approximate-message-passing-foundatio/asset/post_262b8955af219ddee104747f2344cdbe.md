### Lemma A.14. If \(W \sim \text{GOE}(n)\) and \(u \in \mathbb{R}^n\) is fixed, then \(Wu \stackrel{d}{=} \|u\|_n Z + \zeta u\), where \(Z \sim N_n(0, I_n)\) and \(\zeta \sim N(0, 1/n)\) are independent.

Proof of Lemma A.14. The result holds trivially when \(u = 0\), and is also true when \(u = e_1\) since \(We_1 \sim N_n(0, \text{diag}(2/n, 1/n, \dots, 1/n)\). as required, where we have used the orthogonal invariance of \(W \sim \text{GOE}(n)\), the result for \(e_1\) and the orthogonal invariance of \(Z \sim N_n(0, I_n)\) respectively to obtain the distributional equalities above.
