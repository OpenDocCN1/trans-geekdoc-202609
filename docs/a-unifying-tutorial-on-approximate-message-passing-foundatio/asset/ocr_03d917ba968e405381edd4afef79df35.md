Suppose that we observe $(x_1, y_1), \dots, (x_n, y_n) \in \mathbb{R}^p \times \{0, 1\}$ with

\(\mathbb{P}(y_i = 1 | x_i^\top \beta) = \frac{e^{x_i^\top \beta}}{1 + e^{x_i^\top \beta}} = \zeta'(x_i^\top \beta), \quad \text{where } \zeta(z) := \log(1 + e^z)\) (4.63)

for \(1 \le i \le n\). Equivalently, we may view this as an instance of the model (4.1) with \(\varepsilon_1, \dots, \varepsilon_n \stackrel{\mathrm{iid}}{\sim} U[0, 1]\) and \(h(z, v) = \mathbb{1}_{\{v \le \zeta'(z)\}}\), so that \(y_i = h(x_i^\top \beta, \varepsilon_i) = \mathbb{1}_{\{\varepsilon_i \le \zeta'(x_i^\top \beta)\}}\) for each \(i\), and seek to estimate \(\beta \in \mathbb{R}^p\) by maximum likelihood via

\(\hat{\beta}^{\mathrm{MLE}} \in \operatorname{argmin}_{\tilde{\beta} \in \mathbb{R}^p} \sum_{i=1}^n \{ \zeta(x_i^\top \tilde{\beta}) - y_i x_i^\top \tilde{\beta} \},\) (4.64)

where the objective function in (4.64) is the negative log-likelihood. Albert and Anderson (1984) showed that this MLE exists if and only if \(\mathcal{X}_0 := \{x_i: 1 \le i \le n, y_i = 0\}\) and \(\mathcal{X}_1 := \{x_i: 1 \le i \le n, y_i = 1\}\) are not (strongly) linearly separable, i.e., for any \(\tilde{\beta} \neq 0\), there either exists \(x_{i_0} \in \mathcal{X}_0\) with \(x_{i_0}^\top \tilde{\beta} > 0\) or \(x_{i_1} \in \mathcal{X}_1\) with \(x_{i_1}^\top \tilde{\beta} < 0\). In the random design setting of (G0) where \(x_1, \dots, x_n \stackrel{\mathrm{iid}}{\sim} N_p(0, I_p/n)\) for each \(n\) and \(p \equiv p_n\), Candès and Sur (2020) established a sharp phase transition for the existence of \(\hat{\beta}^{\mathrm{MLE}}\). Specifically, they proved that there exists a decreasing function \(s_\mathrm{MLE} : (0, \infty) \to [0, \infty)\) with the following property: if the signals \(\beta \in \mathbb{R}^p\) are such that \(n^{-1/2} \|\beta\| \to^\mathrm{p} \kappa \in (0, \infty)\) as \(n, p \to \infty\) with \(n/p \to \delta \in (1, \infty)\), then \(\hat{\beta}^{\mathrm{MLE}}\) exists with probability tending to 0 if \(\kappa > s_\mathrm{MLE}(1/\delta)\), and exists with probability tending to 1 if \(\kappa < s_\mathrm{MLE}(1/\delta)\).

Henceforth, we will restrict attention to the latter regime, and use the GAMP formalism in Sections 4.1 and 4.4 to explain how to derive a result of Sur and Candès (2019a and b) on the high-dimensional asymptotics of \(\hat{\beta}^{\mathrm{MLE}}\), which is formally stated as Theorem 4.8 below. Recall from (4.5) that for a sequence of logistic regression models (4.63) satisfying (G1), the asymptotic signal strength \(\kappa^2 = c\text{-}\lim_{n \to \infty} \|\beta\|^2/n\) is equal to \(\mathbb{E}(\hat{\beta}^2)/\delta\).
