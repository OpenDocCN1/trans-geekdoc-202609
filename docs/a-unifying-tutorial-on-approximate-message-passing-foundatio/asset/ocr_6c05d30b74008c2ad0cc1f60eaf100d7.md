Property (i) is immediate from (B.5) and the fact that \(\pi_{n+1}(B \times E'_n) = \pi_n(B)\) for all \(B \in \otimes_{j=1}^n \mathcal{B}'_j\). To verify (ii), observe that

\(\pi'_n(\prod_{j=1}^{n-1} E_j \times A_n) = \int_{\prod_{j=1}^n E'_j} \int_{E_n} \mathbb{1}_{A_n}(x_n) dQ_{y_n}^n(x_n) d\pi_n(y_1, \dots, y_n) = \int_{E'_n} Q_{y_n}^n(A_n) d\mu_n(y_n) = \mathbb{P}(X_n \in A_n),\)

where the final equality is obtained from Remark B.5(II) as above. As for (iii), fix \(B_j \in \mathcal{B}'_j\) for \(1 \le j \le n\) and note that by (B.4) and (B.5), we have

\(\pi'_n(\prod_{j=1}^n g_j^{-1}(B_j)) = \int_{\prod_{j=1}^n E'_j} Q_{y_1}^1(g_1^{-1}(B_1)) \cdots Q_{y_n}^n(g_n^{-1}(B_n)) d\pi_n(y_1, \dots, y_n) = \int_{\prod_{j=1}^n E'_j} \mathbb{1}_{B_1}(y_1) \cdots \mathbb{1}_{B_n}(y_n) d\pi_n(y_1, \dots, y_n) = \pi_n(\prod_{j=1}^n B_j).\)

This means that \(\pi_n\) and \(\pi'_n \circ (g_1, \dots, g_n)^{-1}\) agree on \(\{ \prod_{j=1}^n B_j : B_j \in \mathcal{B}'_j \text{ for all } 1 \le j \le n \}\), a \(\pi\)-system that generates \(\otimes_{j=1}^n \mathcal{B}_j\), so (iii) holds.

Since the distributions \(\pi'_1, \pi'_2, \dots\) on the Polish spaces \(E_1, E_1 \times E_2, \dots\) satisfy the consistency condition (i), we deduce from the Daniell-Kolmogorov extension theorem (Kallenberg, 1997, Theorem 5.14) and Remark B.11 that exists a sequence \((X'_n)_{n \in \mathbb{N}}\) of random elements \(X'_n : \Omega \to E_n\) such that \((X'_1, \dots, X'_n) \sim \pi'_n\) on \(\prod_{j=1}^n E_j\) for each \(n\). Then by (ii) and (iii) above, we have \(X'_n \overset{d}{=} X_n\) and \((g_1(X'_1), \dots, g_n(X'_n)) \sim \pi'_n \circ (g_1, \dots, g_n)^{-1} = \pi_n\) for each \(n\), where \(\pi_n\) was defined to be the distribution of \((Y_1, \dots, Y_n)\). Thus, the sequences \((g_n(X'_n))\) and \((Y_n)\) have the same finite-dimensional distributions; in other words, their distributions agree on \(\{ \prod_{j=1}^N B_j \times \prod_{j=N+1}^\infty E'_j : N \in \mathbb{N}, B_j \in \mathcal{B}'_j \text{ for all } 1 \le j \le N \}\), a collection of cylindrical sets that generate the cylindrical \(\sigma\)-algebra \(\mathcal{B}'\) of \(\prod_{n=1}^\infty E'_n\). (By Kallenberg (1997, Lemma 1.2), \(\mathcal{B}'\) is the Borel \(\sigma\)-algebra of \(\prod_{n=1}^\infty E'_n\).) We conclude that \((g_1(X'_1), g_2(X'_2), \dots) \overset{d}{=} (Y_1, Y_2, \dots)\) as random sequences taking values in \((\prod_{n=1}^\infty E'_n, \mathcal{B}')\).
