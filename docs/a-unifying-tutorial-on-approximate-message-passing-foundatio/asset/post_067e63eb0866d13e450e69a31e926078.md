As a first step towards the proof of Theorem B.17, it is helpful to establish the following.

### Proposition B.16.
There exists a countable set \(T'_r\) of bounded Lipschitz functions on \(\mathbb{R}^D\) with the property that \(\tilde{d}_r(P, Q) = \sup_{\psi \in T'_r} | \int_{\mathbb{R}^D} \psi dP - \int_{\mathbb{R}^D} \psi dQ | \in [0, \infty)\) for all \(P, Q \in \mathcal{P}(r)\).

A key property of the set \(T'_r\) we construct is that for any \(\psi \in \text{PL}_D(r)\), there exists a sequence \((\psi_\ell)\) in \(T'_r\) that converges uniformly to \(\psi\) on compact subsets of \(\mathbb{R}^D\). In subsequent proofs, we will write \(Q(f)\) as shorthand for \(\int_{\mathbb{R}^D} f dQ\) when \(Q\) is a signed Borel measure on \(\mathbb{R}^D\) and \(f : \mathbb{R}^D \to \mathbb{R}\) is a \(Q\)-integrable function.

**Proof.** For \(N \in \mathbb{N}\), let \(B_N \equiv \bar{B}_D(0, N) := \{ x \in \mathbb{R}^D : \|x\| \le N \}\) and define \(f_N(x) := (N - \|x\|) \vee 0 \wedge 1\) for \(x \in \mathbb{R}^D\), so that \(f_N\) is 1-Lipschitz on \(\mathbb{R}^D\), \(f_N = 1\) on \(B_{N-1}\) and \(f_N = 0\) on \(B_N^c\). In the argument below (and in the proof of Theorem B.17), we will use \(f_N\) as a substitute for the (discontinuous) indicator function \(\mathbb{1}_{B_N}\) in several places. Note in particular that if \(\bar{g} : B_N \to \mathbb{R}\) is Lipschitz on \(B_N\), then the function \(g : \mathbb{R}^D \to \mathbb{R}\) defined by \(g(x) := \bar{g}(x)f_N(x)\) is Lipschitz and supported on the compact set \(B_N\).

Recalling the definitions of \(\tilde{d}_r, \mathcal{P}(r)\) from (1.4) and writing \(\widetilde{\text{PL}}_D(r, 1)\) for the set of all \(\phi \in \text{PL}_D(r, 1)\) satisfying \(\phi(0) = 0\), we see from (1.3) that

\(\begin{aligned} \tilde{d}_r(P, Q) &= \sup_{\phi \in \widetilde{\text{PL}}_D(r, 1)} |(P - Q)(\phi)| \le \sup_{\phi \in \widetilde{\text{PL}}_D(r, 1)} (P + Q)(|\phi|) \\ &\le \int_{\mathbb{R}^D} (\|x\| + \|x\|^r) d(P + Q)(x) < \infty \end{aligned} \quad \text{(B.13)}\)

for all \(P, Q \in \mathcal{P}(r)\). If \(\phi \in \widetilde{\text{PL}}_D(r, 1)\), then

\(|\phi(x) - \phi(y)| \le \|x - y\|(1 + \|x\|^{r-1} + \|y\|^{r-1}) \le (1 + 2N^{r-1})\|x - y\|\)

for all \(x, y \in B_N\), so \(\phi|_{B_N}\) belongs to the set of \((1 + 2N^{r-1})\)-Lipschitz functions \(g : B_N \to \mathbb{R}\) satisfying \(g(0) = 0\), which we denote by \(\mathcal{G}_N\).

Since \(B_N\) is compact and \(\mathcal{G}_N\) is uniformly bounded and equicontinuous,

\(\mathcal{G}_N\) is therefore compact for the supremum norm on \(B_N\) by the Arzelà-Ascoli theorem (e.g. Dudley, 2002, Theorem 2.4.7). It is therefore totally bounded, so for each \(m \in \mathbb{N}\), we can find a finite subset \(\tilde{\mathcal{H}}_{N,m} \subseteq \mathcal{G}_N\) such that for any \(g \in \mathcal{G}_N\), there exists \(\tilde{h} \in \tilde{\mathcal{H}}_{N,m}\) with \(\sup_{x \in B_N} |g(x) - \tilde{h}(x)| < 1/m\). Each \(\tilde{h} \in \tilde{\mathcal{H}}_{N,m}\) can be associated with a function \(h: \mathbb{R}^D \to \mathbb{R}\) defined by \(h(x) := \tilde{h}(x)f_N(x)\). By the reasoning in the previous paragraph, the collection \(\mathcal{H}_{N,m}\) of all such \(h\) is a finite set of bounded Lipschitz functions supported on \(B_N\).

Consequently, \(T'_r := \bigcup_{N,m \in \mathbb{N}} \mathcal{H}_{N,m}\) is a countable set of bounded Lipschitz functions on \(\mathbb{R}^D\), and we claim that this has the desired property that \(\tilde{d}_r(P, Q) = \sup_{\psi \in T'_r} |(P-Q)(\psi)|\) for any two probability measures \(P, Q \in \mathcal{P}(r)\). Indeed, for fixed \(P, Q \in \mathcal{P}(r)\), the function \(\psi_r: x \mapsto \|x\| + \|x\|^r\) is integrable with respect to both \(P\) and \(Q\) on \(\mathbb{R}^D\), so by the dominated convergence theorem, we have \(P(\psi_r \mathbf{1}_{B_{N-1}^c}) \to 0\) and \(Q(\psi_r \mathbf{1}_{B_{N-1}^c}) \to 0\) as \(N \to \infty\). Thus, for an arbitrary \(\varepsilon > 0\), there exists a sufficiently large \(N \equiv N_{\varepsilon, r} \in \mathbb{N}\) such that \(P(\psi_r \mathbf{1}_{B_{N-1}^c}) < \varepsilon/4\) and \(Q(\psi_r \mathbf{1}_{B_{N-1}^c}) < \varepsilon/4\). Choosing \(m \equiv m_{\varepsilon} \in \mathbb{N}\) such that \(1/m < \varepsilon/4\), we deduce from the previous paragraph that for any \(\phi \in \widetilde{\text{PL}}_D(r, 1)\), there exists \(\tilde{h} \in \tilde{\mathcal{H}}_{N,m}\) such that \(\sup_{x \in B_N} |\phi(x) - \tilde{h}(x)| < 1/m < \varepsilon/4\). Letting \(h\) be the corresponding function in \(\mathcal{H}_{N,m} \subseteq T'_r\), we have

\[
\begin{aligned}
|(P-Q)(\phi)| &\le |(P-Q)(\phi(1 - f_N))| + |(P-Q)(\phi f_N - h)| + |(P-Q)(h)| \\
&\le (P + Q)(|\phi|(1 - f_N)) + (P + Q)(|\phi f_N - h|) + \sup_{\psi \in T'_r}|(P-Q)(\psi)| \tag{B.14}
\end{aligned}
\]

by the triangle inequality. Since \(\phi \in \widetilde{\text{PL}}_D(r, 1)\), we have \(|\phi(x)| = |\phi(x) - \phi(0)| \le \|x\| + \|x\|^r = \psi_r(x)\) for all \(x \in \mathbb{R}^D\), whence

\[
\begin{aligned}
(P+Q)(|\phi|(1 - f_N)) &\le (P+Q)(|\phi| \mathbf{1}_{B_{N-1}^c}) \\
&\le (P+Q)(\psi_r \mathbf{1}_{B_{N-1}^c}) < \varepsilon/2
\end{aligned}
\]

by our choice of \(N\) and the fact that \(0 \le 1 - f_N \le \mathbf{1}_{B_{N-1}^c}\). Moreover,

\[
\begin{aligned}
(P+Q)(|\phi f_N - h|) &\le 2 \sup_{x \in B_N} |\phi(x)f_N(x) - h(x)| \\
&\le 2 \sup_{x \in B_N} |\phi(x) - \tilde{h}(x)| < 2/m < \varepsilon/2
\end{aligned}
\]

by our choice of \(h\), so it follows from (B.14) that \(|(P - Q)(\phi)| < \varepsilon + \sup_{\psi \in T'_r} |(P - Q)(\psi)|\). Since this holds for every \(\phi \in \widetilde{\text{PL}}_D(r, 1)\) and all \(\varepsilon > 0\), the result follows.

### Theorem B.17.
Let \(P \in \mathcal{P}_D(r)\) and let \((P_n)\) be a sequence of probability measures in \(\mathcal{P}_D(r)\). Then there exists a countable set \(T_r \subseteq \text{PL}_D(r)\) such that the following are equivalent:

- (i) \(\int_{\mathbb{R}^D} \psi \, dP_n \rightarrow \int_{\mathbb{R}^D} \psi \, dP\) for all \(\psi \in T_r\);
- (ii) \(\tilde{d}_r(P_n, P) \rightarrow 0\);
- (iii) \(d_r(P_n, P) \rightarrow 0\).

A suitable set \(T_r \subseteq \text{PL}_D(r)\) can be constructed by enlarging the set \(T'_r\) of bounded Lipschitz functions defined in (the proof of) Proposition B.16.

### Remark B.18.
Using Theorem B.17, we can verify that \(\tilde{d}_r\) is a metric on \(\mathcal{P}(r) \equiv \mathcal{P}_D(r)\) that generates the same topology as \(d_r\). Indeed, it is clear from (1.4) and (B.13) that \(\tilde{d}_r\) takes values in \([0, \infty)\) and satisfies the triangle inequality on \(\mathcal{P}(r)\). In addition, if \(P, Q \in \mathcal{P}(r)\) are such that \(\tilde{d}_r(P, Q) = 0\), then by taking \(P_n = Q\) for all \(n\) in (ii) above, we deduce that \(d_r(P, Q) = 0\). Since \(d_r\) is a metric on \(\mathcal{P}(r)\) (e.g. Villani, 2003, Theorem 7.3), this yields \(P = Q\), as required. In fact, \((\mathcal{P}(r), d_r)\) is a separable, complete metric space (e.g. Panaretos and Zemel, 2020, Theorem 2.2.7 and Proposition 2.2.8), so by the equivalence (ii) \(\Leftrightarrow\) (iii) in Theorem B.17, the same is true of \((\mathcal{P}(r), \tilde{d}_r)\).
