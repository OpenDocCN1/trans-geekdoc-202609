**Lemma A.12.** Let \(\mathcal{G} \subseteq \mathcal{F}\) be a sub-\(\sigma\)-algebra and let \(X : (\Omega, \mathcal{F}, \mathbb{P}) \to \sqcup_{k=1}^n \mathbb{R}^{k \times k}\) be a measurable function. Suppose that there is a partition of \(\Omega\) into disjoint events \(\Omega_1, \dots, \Omega_m \in \mathcal{G}\) such that for each \(k = 1, \dots, m\), the map \(X\) takes values in \(\mathbb{R}^{n_k \times n_k}\) on \(\Omega_k\) and has conditional distribution \(\text{GOE}(n_k)\) given \(\mathcal{G}\) on \(\Omega_k\), for some (deterministic) \(n_k \in \{1, \dots, n\}\). Moreover, let \(Q = (Q_1 \ Q_2) : (\Omega, \mathcal{F}, \mathbb{P}) \to \sqcup_{k=1}^n \mathbb{O}_k\) be a \(\mathcal{G}\)-measurable function such that on each event \(\Omega_k\), the map \(Q\) takes values in \(\mathbb{O}_{n_k}\), and \(Q_1, Q_2\) have \(\ell_k\) and \(n_k - \ell_k\) columns respectively, for some (deterministic) \(\ell_k \in \{1, \dots, n_k - 1\}\). Then, given \(\mathcal{G}\), we have the following:

+   (a) \(Q^\top X Q\) has conditional distribution \(\text{GOE}(n_k)\) on \(\Omega_k\) for every \(k = 1, \dots, m\);
+   
+   (b) \(Q_2^\top X Q_2\) has conditional distribution \(\text{GOE}(n_k - \ell_k)\) on \(\Omega_k\) for every \(k = 1, \dots, m\);
+   
+   (c) \(Q^\top X Q_1\) and \(Q_2^\top X Q_2\) are conditionally independent.

**Remark A.13.** Note that if \(n_1 = \dots = n_m = n\), then under the first condition of the lemma, it follows from Remark B.4 that \(X\) has unconditional distribution \(\text{GOE}(n)\) and is independent of \(\mathcal{G}\). Thus, in the instructive special case where \(m=1\) and \(1 \le \ell_1 < n = n_1\), the result above simplifies to the following: suppose that \(X \sim \text{GOE}(n)\), and is independent of \(\mathcal{G}\), and moreover that \(Q = (Q_1 \ Q_2) : (\Omega, \mathcal{F}, \mathbb{P}) \to \mathbb{O}_n\) is a \(\mathcal{G}\)-measurable map such that \(Q_1, Q_2\) have \(\ell_1\) and \(n - \ell_1\) columns respectively. Then

+   (a) \(Q^\top X Q \sim \text{GOE}(n)\) and is independent of \(\mathcal{G}\);
+   
+   (b) \(Q_2^\top X Q_2 \sim \text{GOE}(n - \ell_1)\) and is independent of \(\mathcal{G}\);
+   
+   (c) \(Q^\top X Q_1\) and \(Q_2^\top X Q_2\) are independent, and also conditionally independent given \(\mathcal{G}\).
