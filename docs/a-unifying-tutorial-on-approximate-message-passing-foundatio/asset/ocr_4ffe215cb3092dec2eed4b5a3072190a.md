\(\breve{L}_k(n) := \|\breve{L}(v_k^{(1)}, \dots, v_k^{(n)})\|_{n, r'} \le L\left(1 + \frac{1}{n}\sum_{i=1}^n \|v_k^{(i)}\|^r\right)^{1/r'}\)
