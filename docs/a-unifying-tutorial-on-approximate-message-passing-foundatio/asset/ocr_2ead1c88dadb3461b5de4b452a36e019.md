# **Remark B.1.** For a random sequence $(X_n)$ taking values in a Euclidean space $(E, \|\cdot\|_E)$, it can be seen from Definition 1.1 and Proposition 1.2 that complete convergence (to a degenerate limit) is a property of the marginal distributions of the random elements $X_1, X_2, \dots$ and not of their joint dependence structure (i.e. the specific coupling between them), so $X_1, X_2, \dots$ need not be defined on the same probability space. Thus, just as for weak convergence or convergence in probability to a degenerate limit (but not almost sure convergence), there is a meaningful notion of complete convergence for sequences $(\mu_n)$ of Borel probability measures on $E$: defining $ar{B}(x, \varepsilon) := \{x' \in E : \|x' - x\|_E \le \varepsilon\}$ for $\varepsilon > 0$, we write $\mu_n 	o^\mathfrak{c} \delta_x$ if $\sum_n \mu_n(ar{B}(x, \varepsilon)^c) < \infty$ for all $\varepsilon > 0$.

# **Example 1.** Let $(X_n)$ be any sequence of random variables for which there exist $c_1, c_2, eta > 0$ such that $\mathbb{P}(|X_n| > t) \le c_1 \exp(-c_2 t^eta)$ for all $t > 0$ and $n \in \mathbb{N}$. Let $(a_n)$ be a deterministic sequence of real numbers. If $a_n = o(1)$, then clearly $a_n X_n = o_p(1)$, and if $a_n = O(1)$, then $a_n X_n = O_p(1)$. Moreover:

+   (a) If $|a_n|^eta \log n 	o 0$, then for every $t > 0$, there exists $N \in \mathbb{N}$ such that $c_2(t/|a_n|)^eta \ge 2 \log n$ for all $n > N$, so $\sum_n \mathbb{P}(|a_n X_n| > t) \le N + \sum_{n>N} c_1 e^{-2 \log n} < \infty$. Thus, $a_n X_n = o_c(1)$ by Proposition 1.2(a).

+   (b) If $\limsup_{n	o\infty} |a_n|^eta \log n < \infty$, then there exists $t > 0$ and $N \in \mathbb{N}$ such that $c_2(t/|a_n|)^eta \ge 2 \log n$ for all $n > N$, so $\sum_n \mathbb{P}(|a_n X_n| > t) < \infty$ as in (i). Thus, $a_n X_n = O_c(1)$ by Proposition 1.2(b). Suppose in addition that there exist $c'_1, c'_2, eta' > 0$ such that $\mathbb{P}(|X_n| > t) \ge c'_1 \exp(-c'_2 t^{eta'})$ for all $t > 0$ and $n \in \mathbb{N}$. 

+   (c) If $\liminf_{n	o\infty} |a_n|^{eta'} \log n > 0$, then there exist $t > 0$ and $N \in \mathbb{N}$ such that $c'_2(t/|a_n|)^{eta'} \le \log n$ for all $n > N$, so $\sum_n \mathbb{P}(|a_n X_n| > t) \ge \sum_{n\ge N} c_1 e^{-\log n} = \infty$. Thus, $(a_n X_n)$ is not $o_c(1)$ in view of Proposition 1.2(a).

+   (d) If $|a_n|^{eta'} \log n 	o \infty$, then for every $t > 0$, there exists $N \in \mathbb{N}$ such that $c'_2(t/|a_n|)^{eta'} \le \log n$ for all $n > N$, so $\sum_n \mathbb{P}(|a_n X_n| > t) = \infty$ as in (iii). Thus, $(a_n X_n)$ is not $O_c(1)$ in view of Proposition 1.2(b).
