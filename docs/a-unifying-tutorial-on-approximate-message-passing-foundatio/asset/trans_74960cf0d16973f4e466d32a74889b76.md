

通过去除 $\breve{U}$ 的第一列 $\breve{U}e_1$ 得到的 $\mathcal{S}_{k-1}$-可测的 $n \times (n - r_{k-1} - 1)$ 矩阵，因此我们在 $E$ 上有 $\breve{U}_k = \breve{U}$，在 $E^c$ 上也有 $\breve{U}_k = \breve{U}$。现在 $\breve{U}, \breve{U}_{k-1}$ 具有跨越 $V_{k-1}$ 的标准正交列，所以 $Q := \breve{U}_{k-1}^\top \breve{U}$ 是一个 $\mathcal{S}_{k-1}$-可测的正交 $(n - r_{k-1}) \times (n - r_{k-1})$ 矩阵，使得 $\breve{U}^\top W \breve{U} = Q^\top (\breve{U}_{k-1}^\top W \breve{U}_{k-1}) Q$。根据归纳假设，$\breve{U}_{k-1}^\top W \breve{U}_{k-1}$ 在给定 $\mathcal{S}_{k-1}$ 时具有条件分布 $\text{GOE}(n - r_{k-1})$，因此根据引理 A.12 的 (a) 和 (b) 部分（其中 $\ell \equiv 1$ 且 $N = n - r_{k-1} \ge 2$），$\breve{U}_{k-1}^\top W \breve{U}_{k-1}$ 和 $\breve{U}^\top W \breve{U}$ 在给定 $\mathcal{S}_{k-1}$ 时分别具有条件分布 $\text{GOE}(n - r_{k-1})$ 和 $\text{GOE}(n - r_{k-1} - 1)$。由于在 $E^c = \{r_k = r_{k-1}\} \in \mathcal{S}_{k-1}$ 上有 $\breve{U}_k^\top W \breve{U}_k = \breve{U}_{k-1}^\top W \breve{U}_{k-1}$，在 $E = \{r_k = r_{k-1} + 1\} \in \mathcal{S}_{k-1}$ 上有 $\breve{U}_k^\top W \breve{U}_k = \breve{U}^\top W \breve{U}$，根据引理 B.6(a)，我们推断 $\breve{U}_k^\top W \breve{U}_k$ 在给定 $\mathcal{S}_{k-1}$ 时具有条件分布 $\text{GOE}(n - r_k)$，正如所要求的。

此外，$0$ 和 $\breve{U}^\top W \breve{U}$ 在给定 $\mathcal{S}_{k-1}$ 时显然是条件独立的，引理 A.12(c) 表明 $\breve{U}^\top W (\breve{U}e_1) = Q^\top (\breve{U}_{k-1}^\top W \breve{U}_{k-1}) Q e_1$ 和 $\breve{U}^\top W \breve{U}$ 同样在给定 $\mathcal{S}_{k-1}$ 时条件独立。由于在 $E^c$ 上有 $W \breve{m}^{k-1} = 0$，在 $E$ 上有 $\breve{U}e_1 = \breve{m}^{k-1}$，根据引理 B.9(a) 可知 $\breve{U}^\top W \breve{m}^{k-1}$（因此根据引理 B.8，$\sigma(\mathcal{S}_{k-1}, \breve{U}^\top W \breve{m}^{k-1})$ 也是）在给定 $\mathcal{S}_{k-1}$ 时与 $\breve{U}_k^\top W \breve{U}_k$ 条件独立。而且，$W P_{k-1} = W M_{k-1} M_{k-1}^+ = Y_{k-1} M_{k-1}^+$、$\breve{m}^{k-1}$、$\breve{U}$ 和 $P_{k-1}^\perp = \breve{U}\breve{U}^\top$ 都是 $\mathcal{S}_{k-1}$-可测的，所以

```
y^{k-1} = W(P_{k-1} + P_{k-1}^\perp)m^{k-1}
= (W P_{k-1})m^{k-1} + (P_{k-1} + P_{k-1}^\perp)^\top W \breve{m}^{k-1}
= (W P_{k-1})m^{k-1} + (W P_{k-1})^\top \breve{m}^{k-1} + \breve{U}(\breve{U}^\top W \breve{m}^{k-1}) (A.10)
```

是 $\sigma(\mathcal{S}_{k-1}, \breve{U}^\top W \breve{m}^{k-1})$ 可测的。因此，在给定 $\mathcal{S}_{k-1}$ 时，我们得出结论：$\breve{U}_k^\top W \breve{U}_k$ 与 $y^{k-1}$ 条件独立，进而根据引理 B.8 和 (A.3)，它与 $S_k = \sigma(\mathcal{S}_{k-1}, y^{k-1})$ 也条件独立。因此，由于 $\breve{U}_k^\top W \breve{U}_k$ 在给定 $\mathcal{S}_{k-1}$ 时具有条件分布 $\text{GOE}(n - r_k)$，它在给定 $\sigma(\mathcal{S}_{k-1}, S_k) = S_k$ 时也具有条件分布 $\text{GOE}(n - r_k)$。

最后，只需证明：若 $\tilde{W} \sim \text{GOE}(n)$ 与 $\mathcal{S}_k$ 独立，则 $\breve{U}_k^\top \tilde{W} \breve{U}_k$ 在给定 $\mathcal{S}_k$ 时也具有条件分布 $\text{GOE}(n - r_k)$。为此，令 $\breve{m}^1, \dots, \breve{m}^{r_k}$ 成为 $\text{Im}(M_k)$ 的一个 $\mathcal{S}_k$-可测标准正交基，例如通过对 \(m^0, \dots, m^{k-1}\) 应用格拉姆-施密特过程得到，如上文注释 A.10 所述。然后取 \(Q_1 = (\tilde{m}^1 \cdots \tilde{m}^{r_k})\) 和 \(Q_2 = \tilde{U}_k\)，可见 \(Q = (Q_1 Q_2)\) 满足引理 A.12 的假设，其中 \(\Omega_j = \{r_k = j\} \in \mathcal{S}_k\) 且 \(\ell_j = j \le n = n_j\) 对 \(j = 1, \dots, k\) 成立。所需结论现在直接从引理 A.12(b) 得出，由此完成归纳步骤。

如上文所述，命题 A.11 的证明在很大程度上依赖于命题 A.8 中的最后一个断言。为了得到 (A.5) 和 (A.7) 中的条件分布等式，我们还将应用以下基本事实。

### 引理 A.14. 若 \(W \sim \text{GOE}(n)\) 且 \(u \in \mathbb{R}^n\) 固定，则 \(Wu \stackrel{d}{=} \|u\|_n Z + \zeta u\)，其中 \(Z \sim N_n(0, I_n)\) 和 \(\zeta \sim N(0, 1/n)\) 独立。

引理 A.14 的证明。当 \(u = 0\) 时结果显然成立，当 \(u = e_1\) 时也成立，因为 \(We_1 \sim N_n(0, \text{diag}(2/n, 1/n, \dots, 1/n)\)。对一般 \(u \in \mathbb{R}^n \setminus \{0\}\)，设 \(Q \in \mathbb{R}^{n \times n}\) 为满足 \(Qe_1 = u/\|u\|\) 的正交矩阵，则 \(Q^\top u = \|u\|e_1\)。于是

\(Wu \stackrel{d}{=} QWQ^\top u = Q(We_1)\|u\| \stackrel{d}{=} Q(\|e_1\|_n Z + \zeta e_1)\|u\| \stackrel{d}{=} \|u\|_n Z + \zeta u\),

如所需，其中我们分别使用了 \(W \sim \text{GOE}(n)\) 的正交不变性、\(e_1\) 的结果以及 \(Z \sim N_n(0, I_n)\) 的正交不变性来得到上述分布等式。

命题 A.11 的证明。我们首先对每个 \(k \in \{0, 1, \dots, n-1\}\) 证明 (A.6)。设 \(\tilde{U}_k\) 为任意一个 $\mathcal{S}_{k-1}$-可测的 \(n \times (n-r_k)\) 矩阵，其列构成 \(V_k\) 的一组标准正交基；\(\tilde{U}_k\) 的具体构造见注释 A.10。类似于命题 A.8 证明中的 (A.10)，我们可以写

```
W = WP_k + (P_k + P_k^\perp)^\top WP_k^\perp
= WP_k + (WP_k)^\top P_k^\perp + P_k^\perp WP_k^\perp
= WP_k + (WP_k)^\top P_k^\perp + \tilde{U}_k(\tilde{U}_k^\top W\tilde{U}_k)\tilde{U}_k^\top
\stackrel{d}{=} |_{S_k} WP_k + (WP_k)^\top P_k^\perp + \tilde{U}_k(\tilde{U}_k^\top \tilde{W}^k \tilde{U}_k)\tilde{U}_k^\top
= WP_k + (WP_k)^\top P_k^\perp + P_k^\perp \tilde{W}^k P_k^\perp,
```

其中 \(\breve{W}^k \sim \text{GOE}(n)\) 与 \(\mathcal{S}_k\) 独立。为了证明 (A.11) 后的关键分布等式，我们可以应用引理 B.6(c)；确实，注意到 \(WP_k = Y_k M_k^+\)、\(\breve{U}_k\) 和 \(P_k^\perp = \breve{U}_k \breve{U}_k^\top\) 都是 \(\mathcal{S}_k\)-可测的，并且根据命题 A.8 的最后一个断言，\(\breve{U}_k^\top W \breve{U}_k \stackrel{d}{=} |_{\mathcal{S}_k} \breve{U}_k^\top W \breve{U}_k \breve{U}_k\)。通过在上述显示公式中将 \(WP_k\) 替换为 \(Y_k M_k^+\)，我们对每个 \(k \in \{0, 1, \dots, n-1\}\) 得到了 (A.6)，正如所期望的。由于 \(I - P_0 = P_0^\perp = I_n\)，当 \(k=0\) 时，这特化为 \(W \stackrel{d}{=} |_{\mathcal{S}_0} \breve{W}^0\)，这是 (A.5) 的第一部分。

利用 (A.6)，我们现在推导对 \(k \in \{0, 1, \dots, n-1\}\) 在给定 \(\mathcal{S}_k\) 时 \(h^{k+1}\) 的条件分布。当 \(k=0\) 时，有 \(h^1 = W m^0\)，因此 (A.5) 中对应的恒等式直接从 (A.5) 的第一部分、引理 A.14 和引理 B.6(c) 得出。现在转到 \(k \ge 1\) 的 (A.7)，我们有 \(h^{k+1} = W m^k - b_k m^{k-1}\)，其中 \(b_k, m^{k-1}\) 是 \(\mathcal{S}_k\)-可测的，因此可以从 (A.6) 和引理 B.6(c) 推出

\(\begin{aligned} h^{k+1} \stackrel{d}{=} |_{\mathcal{S}_k} & Y_k M_k^+ m^k + (Y_k M_k^+)^\top P_k^\perp m^k + P_k^\perp \breve{W}^k P_k^\perp m^k - b_k m^{k-1} \\ = & Y_k \alpha^k + (Y_k M_k^+)^\top \breve{m}^k + P_k^\perp (\breve{W}^k \breve{m}^k) - b_k m^{k-1} \\ = & H_k \alpha^k + (0 \, M_{k-1}) B_k \alpha^k + (H_k M_k^+)^\top \breve{m}^k + P_k^\perp (\breve{W}^k \breve{m}^k) - b_k m^{k-1}. \end{aligned}\) (A.12)

确实，要得到上述最后一个等式，注意到 \(Y_k = H_k + (0 \, M_{k-1}) B_k\) 且 \(B_k^\top (0 \, M_{k-1})^\top \breve{m}^k = B_k^\top (0 \, M_{k-1})^\top P_k^\perp m^k = 0\)，这是基于 \(P_k^\perp M_{k-1} = 0\) 的事实。由于 \(\breve{m}^k\) 是 \(\mathcal{S}_k\)-可测的，且 \(\breve{W}^k \sim \text{GOE}(n)\) 与 \(\mathcal{S}_k\) 独立（因此在给定 \(\mathcal{S}_k\) 时具有条件分布 GOE(n)），根据引理 A.14 和引理 B.6(b)，可得 \(\breve{W}^k \breve{m}^k \stackrel{d}{=} |_{\mathcal{S}_k} \| \breve{m}^k \|_n \breve{Z}^{k+1} + \breve{\zeta}^{k+1} \breve{m}^k\)。现在，由于 \(P_k^\perp\) 和 (A.12) 中的所有其他项都是 \(\mathcal{S}_k\)-可测的，进一步应用引理 B.6(c) 表明 (A.12) 中的随机变量和

\(\begin{aligned} & H_k \alpha^k + P_k^\perp (\| \breve{m}^k \|_n \breve{Z}^{k+1} + \breve{\zeta}^{k+1} \breve{m}^k) + (H_k M_k^+)^\top \breve{m}^k \\ & - \{ b_k m^{k-1} - (0 \, M_{k-1}) B_k \alpha^k \} \\ = & \sum_{\ell=1}^k \alpha_\ell^k h^\ell + P_k^\perp (\| \breve{m}^k \|_n \breve{Z}^{k+1} + \breve{\zeta}^{k+1} \breve{m}^k) + (H_k M_k^+)^\top \breve{m}^k \\ & - \left( b_k m^{k-1} - \sum_{\ell=1}^k \alpha_\ell^k b_{\ell-1} m^{\ell-2} \right) \end{aligned}\) (A.13)
