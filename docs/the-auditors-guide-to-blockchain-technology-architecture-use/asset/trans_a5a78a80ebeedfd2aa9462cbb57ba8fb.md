
# 前言

2021年1月，我组建了一个研究团队，成员来自我们信息系统安全与保障硕士项目的二年级研究生，他们当时正修读研究方法课程。作为我们最终的小组研究项目，我起草了一份关于区块链技术审计的书籍目录初稿；在那个时候，这一主题几乎未受到任何关注。随后，我将我的53名研究生分成每组两到四人的小团队，并为每组分配了一个章节主题。在接下来的两个学期（共26周）里，在我的密切指导和监督下，每个团队研究并撰写了分配给他们的章节。大致在同一时期，当我的学生们忙于阅读、理解和分析与其分配章节相关的参考资料时，我开始围绕我们的新研究项目创建一份全面的书籍出版建议书。在撰写建议书的调研过程中，我很快发现，虽然互联网上有大量与区块链相关的资料，但专门聚焦于区块链技术的研究论文和出版书籍相对较少，尽管我找到了大量专注于各种加密货币（尤其是比特币）的书籍。我关于区块链审计书籍的建议书随后提交给CRC Press进行审核，令我欣喜的是，几个月后我收到了CRC Press的批准！

您正在阅读的这本书就是这一努力的成果。当您研读本书各章节时，会看到每章作者的姓名；共有53名聪慧且极具动力的研究生，他们来自加拿大阿尔伯塔省爱德蒙顿协和大学的信息系统安全与保障项目。

## 谁应该阅读本书？

这项工作的初衷是为对新兴技术知之甚少的IT保障专家创建一份全面的学习和参考指南。因此，本书可能极大地引起以下读者的兴趣：

*   对深入了解区块链的类型、组件、挑战及潜在用例感兴趣的IT和业务读者；
*   为研究目的而有兴趣了解区块链技术的本科生和研究生；
*   为评估和/或实施目的，有兴趣深入了解这一新兴技术各个方面的各类业务领导者；
*   寻求采用一本全面的教材用于区块链技术相关课程的本科和/或研究生级IT教师；
*   寻求加深对该技术及其在商业、会计和审计领域潜在用例理解的会计师和外部审计师；
*   寻求获得区块链胜任能力的内部和信息系统审计师；
*   寻找一本简明而全面的区块链参考书的个人；
*   寻求高效学习区块链技术所有要点，作为进入利润丰厚的区块链相关就业市场第一步的个人。

## 本书如何惠及审计专业人士？

正如书名明确所示，本书主要面向保障专业人士设计。它不仅为审计师理解区块链技术的机制和主要组件奠定了坚实基础，还探讨了这一新兴且具有潜在颠覆性技术的现状挑战，如其风险、漏洞和实施障碍。此外，本书还讨论了供应链管理、金融服务以及会计/审计等领域的多个潜在用例。目前还有许多其他潜在用例，特别是在政府领域，正在被调查研究中。然而，作为研究项目的顾问和监督者，我决定将我们的用例研究限制在我拥有先前非学术工作经验的领域和部门。因此，我真诚地相信，外部和内部审计师都能极大地扩展其区块链知识库，并将更高的有效性融入涉及这一快速发展技术的审计计划中。

## 如何阅读本书

本书旨在既作为区块链技术的全面读物，也作为IT和保障专业人士的宝贵参考工具。虽然本书可以以很大的灵活性进行阅读或学习，但所有读者都必须从按顺序研读本书前三章开始。在网络和网络安全方面拥有丰富知识和经验的IT专业人士，会认为前三章中讨论的至少一些概念是复习性质的。然而，正如我总是提醒我的信息系统安全与保障学生的那样，成为某一领域专家的首要条件是扎实掌握其基础。一旦打下坚实基础，在此基础上构建将不再是一项过于困难的任务！

研读完前三章后，读者可以选择挑选其余最感兴趣和最有用的章节。快速浏览本书的目录应能让读者意识到，除了涵盖区块链基础知识外，本书还讨论了架构、安全方面、若干潜在用例和实施考量，以及若干区块链专用的审计工具和清单。

## 本书如何组织？

本书每一章都遵循相似的整体组织结构，如下所示：

*   每章作者/研究人员的姓名在其分配的章节开头披露。在研究项目的第一阶段，这些人员负责为每章搜索、汇编和分析数十篇参考文献。在研究项目的后期阶段，团队负责在我的编辑协助以及我的两位得力研究生助教Aman Dev Singh先生和Yetunde Akinsanmi女士的校编支持下撰写章节内容。2021年春季学期在爱德蒙顿协和大学结束后，我花费数月时间对每章进行最终深度编辑，随后在妻子Susan的协助下，手稿最终准备好提交给CRC编辑。

*   每章均以简短的*摘要*开始。类似于其在研究论文中的用途，摘要使读者在深入阅读前能快速了解每章的内容和范围。这样做的理由是让读者有选择地跳过可能不感兴趣的章节。例如，一些读者可能希望跳过技术性较强的章节，而技术导向较强的读者可能希望主要关注此类章节并跳过侧重某些用例的章节。如前所述，虽然[第1章](#ch09.xhtml#c1)至[第3章](#ch11.xhtml#c3)应由所有读者阅读，但其余章节可按任意顺序学习，甚至某些读者可跳过某些章节。

*   虽然所有章节都以摘要部分开始，但每章也以两个部分结尾，分别题为*总结与结论*，随后列出*核心概念*。包含这两个部分的理由有二：(a) 它使对章节内容已有足够知识的读者能够放弃阅读整章，转而快速回顾其核心概念；(b) 这些部分可帮助读者根据需要快速回顾和记忆一些更重要的章节概念。
