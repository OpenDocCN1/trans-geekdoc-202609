
# 区块链在供应链中的优势

## 可追溯性

*Traceability* 是区块链的另一个重要组成部分。区块链通过使数据永久化且易于追踪，提高了供应链中数据的可追溯性。客户可以轻松找到他们购买产品的详细信息，例如成分、包装日期、制造规格或运输条件 [[21](#ch14.xhtml#r253)]。这实现了卖方和买方之间的完全透明，从而在双方之间建立了牢固的关系。一个例子是柔性标签数据记录器（FTD），可用于酒瓶。FTD 有助于识别温度和湿度水平，直到瓶装商品到达超市或酒类商店。存储在 FTD 中的数据随后可以使用智能手机读取，以帮助确定葡萄酒的安全性和/或质量状态 [[1](#ch14.xhtml#r233), [3](#ch14.xhtml#r235)]。

## 数字化

区块链中的 *Digitalization* 允许数据存储在防篡改的数字环境中，这反过来有助于降低会计和文书工作相关成本，从而减少因手动记录错误信息而可能产生的问题和争议 [[21](#ch14.xhtml#r253)]。

## 成本节约

通过消除存储所有记录物理副本的需求，实现了 *Cost-saving*。区块链技术在供应链管理中的一个重要优势是将旧式的纸质工作转变为数字化工作。由于数据由供应链中涉及的每一方验证，数据的更新副本被发送给所有利益相关者。因此，可以得出结论：区块链减少了人为错误，并提高了管理的灵活性和效率 [[14](#ch14.xhtml#r246), [34](#ch14.xhtml#r266)]。

## 安全性增强

供应链管理中也实现了 *Enhanced security*。许多利益相关者参与链条的不同部分，使得跨供应网络的连接过程变得繁琐。区块链确保利益相关者之间的安全性，以便交换信息。无需持续的人工干预来管理属于流程各个渠道的所有节点，区块链自动确保每个人对其行为和后续结果负责，同时使工作对所有相关方透明，从而大大减少了欺诈活动的机会 [[21](#ch14.xhtml#r253)]。

# Walmart 的供应链区块链

Walmart (WMT) 是世界上最大的零售商，拥有数千家实体店和显著的在线业务。Walmart 的“日常低价”策略因吸引具有不同商品需求的消费者而备受赞誉，包括家庭用品、服装、电子产品、食品杂货等。零售巨头 Walmart 目前正在使用区块链技术来应对全球食品安全丑闻。在两个区块链试点项目中，Walmart 正在利用 IBM 的 `Hyperledger Fabric` 平台追踪中国的猪肉和美洲的芒果。WMT 基于区块链的追踪系统将追踪芒果来源的时间从七天缩短到了 2.2 秒，使该连锁企业能够为其客户群提供额外的透明度。IBM 称之为“完整的端到端可追溯性” [[7](#ch14.xhtml#r239)]。

2011 年面临的问题包括中国发生大规模猪肉标签错误丑闻和驴肉产品因由狐狸肉制成而被召回。2013 年，由于不法分子用马肉替代羊肉和牛肉，欧盟供应链受到破坏。不同的记录保存方法是导致难以追踪产品通过供应链的原因。普遍接受的“一上一下”方法（仅了解食品的直接供应商和客户）已不再足够。中国进口了世界近一半的猪肉，并生产了近一半。购买决策越来越多地基于信任，因为食品安全和质量已成为重中之重。中国政府正在投入大量资金，通过增加检查点、更密切地监控生产流程和供应链，以及与零售巨头合作，进一步提高食品安全 [[12](#ch14.xhtml#r244)]。

Walmart 的区块链技术集成到了即插即用功能中，提供共识和成员服务。在其区块链平台上，为产品创建永久电子证书，包括农业处理、识别号、制造商、已知安全问题、授予的权限、遵循的安全协议，以及设备更新和完成的审计程序。

Walmart 正在投资食品相关技术，以监测和检测包装食品中的病原体。猪肉在猪圈处被智能标记上条形码，流程从那里跟踪猪肉直到包装厂。猪的移动也通过安装在屠宰场的射频识别和摄像头进行追踪。运输卡车配备了温度传感器和 GPS 标签，以便肉类产品能安全到达零售目的地。如果集装箱中的条件超过既定阈值，会提示警报以采取所需的纠正措施。区块链技术允许采购经理远程跟踪大量信息，从保质期到仓库温度。产品包装可以链接到包含所有相关信息评论和详细信息的二维码，这些信息可以上传到电子证书。随之而来的结果是在农场和商店之间的信息交换中速度和准确性的提高，从而改善了食品安全，提高了公众对产品的信心。

Walmart 还在使用 IBM 的 `Hyperledger Blockchain` 来追踪全球运输的切片芒果。随着芒果的生产，热带水果可能会遭受腐烂、表面缺陷、内部降解、冷害、成熟期障碍等。Walmart 从“树到市场”全程跟踪供应链中的质量。

区块链可追溯性的未来为 Walmart 的供应链参与者提供了重要优势。透明的记录保存使零售商能够享受更低的召回成本，同时增加利润并降低风险敞口。Walmart 的区块链试点项目将能够记录供应链低效及其累积损失。这种数字追踪必将显著提高食品安全，并通过减少食品变质来提高供应链效率。Walmart 可以使用 IBM 的 `Hyperledger` 结合现有技术来改善供应链可追溯性。在供应链生态系统内建立联盟，以更广泛地探索区块链的用途，使 Walmart 能够扩展、实验和学习 [[12](#ch14.xhtml#r244)]。

## Maersk

作为一家集装箱物流一体化公司，Moller-Maersk 是 *AP Moller Group* 的一部分。其公司口号“All the Way”旨在通过连接和简化贸易，帮助客户成长和繁荣。Maersk 拥有超过 80,000 名专职团队成员，在 130 个国家开展业务，支持全球贸易。IBM 公司和全球航运巨头 Moller-Maersk 推出了 *TradeLens*，允许公司追踪和更好地管理其供应链。Maersk 和 IBM 之间的合作伙伴关系于 2017 年 3 月签署。航运和 IT 巨头创建了一个联盟，基于 `Hyperledger Fabric` 商业化航运和集装箱管理解决方案 [[7](#ch14.xhtml#r239)]。
