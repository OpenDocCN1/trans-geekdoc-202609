
# 第一阶段：驱动因素是什么？

本阶段识别变革驱动因素。变革驱动因素可定义为暗示需要变革的考量因素。变革驱动因素的例子包括行业趋势、绩效不足、组织目标或软件实施。

第一阶段的目的是了解拟议改进的范围，即区块链的实施，并了解区块链系统如何影响各利益相关者，以及采用该技术的就绪程度。[表 11.1](#ch19.xhtml#t21) 和 [11.2](#ch19.xhtml#t22) 描述了本阶段各利益相关者及其角色和职责。

## 表 11.1 第一阶段：目标、描述、任务、输入、资源与输出

| **第一阶段描述 – 驱动因素是什么？** |
| :--- |
| **阶段目标** | 了解区块链的目标及其在当前治理方法下的背景。获得所有利益相关者的承诺。 |
| **阶段描述** | 描述在组织中实施区块链解决方案的必要性。界定区块链在当前治理方法下的背景。此外，获得利益相关者的承诺和预算。 |
| **持续改进 (CI) 任务** | 1. 识别当前的治理方法和 IT 痛点，这些痛点要求实施区块链平台。 2. 识别通过实施区块链来改进企业 IT 治理 (EGIT) 的驱动因素和合规要求。 3. 识别组织内 IT 领域直接影响区块链实施的当前业务优先事项。 4. 确保执行董事会批准高层方法并接受不采取适当行动的风险。 |
| **变革赋能 (CE) 任务** | *建立实施区块链解决方案的意愿：* 1. 将区块链的实施与组织内的企业变革赋能计划相结合。 2. 分析将实施区块链的当前环境。例如，管理风格、文化和态度。 3. 确定会阻碍区块链技术实施的其他正在进行的举措。 4. 了解实施区块链技术的影响。 5. 识别来自整个组织的区块链实施项目利益相关者，如业务、开发、审计等部门。 6. 确定利益相关者的承诺程度及其贡献带来的变革影响。 7. 利用痛点，I&T 治理董事会应在所有利益相关者中推广和传播原则和目标。 8. 灌输向区块链环境变革的必要性。 |
| **项目管理 (PM) 任务** | *启动实施：* 1. 遵循 I&T 治理董事会，设定高层战略方向和目标。 2. 定义并分配所有利益相关者在实施项目中的适当角色。 3. 制定区块链业务案例大纲，包含成功因素，以便检查绩效监控并报告改进。获得利益相关者的财务承诺。 |
| **输入** | 1. 企业政策、战略、治理、审计报告和业务计划。 2. 企业内正在进行/计划中的举措可能会造成阻碍。 3. 指出现有痛点的 I&T 治理董事会绩效报告。 4. 有用的行业概览、案例研究和成功案例。 5. 企业愿景和使命声明、市场定位和服务战略。 |
| **输出** | 1. 区块链业务案例大纲。 2. 利益相关者的高层角色和职责。 3. 利益相关者的财务承诺。 4. 所有利益相关者之间的沟通，并确立实施区块链的必要性。 |

# 第二阶段：我们目前处于什么状况？

第二阶段将区块链目标与企业的目标和战略相协调。它还对正在进行的项目进行优先级排序，以更好地与治理和管理目标保持一致。根据协调目标，应确定治理和管理目标具备产生预期结果的适当能力。管理层应通过对当前系统执行流程能力评估来识别任何不足。

应组建一支高效的区块链实施团队，配备合适的技能组合。团队成员应具备足够的专业知识和经验，并配备合适的内部和外部资源组合。区块链团队应为项目定义并承诺一个清晰的愿景。此外，应主动识别并解决实施区块链项目时可能引起摩擦的问题（[表 11.3](#ch19.xhtml#t23) 和 [11.4](#ch19.xhtml#t24)）。

## 表 11.3 第二阶段：目标、描述、任务、输入、资源与输出

| **第二阶段描述 – 我们目前处于什么状况？** |
| :--- |
| **阶段目标** | 确保项目团队了解企业目标和 IT 职能，以从实施区块链中交付价值。识别实施区块链时可能涉及的关键流程。了解企业当前和未来的风险态度，以及 IT 风险状况对区块链实施的影响。确定当前的实施能力和企业的变革能力。 |
| **阶段描述** | 识别并分析 I&T 在实施区块链的同时如何实现业务转型，并仍满足治理相关要求，如管理风险、安全顾虑、遵守法律法规要求。了解业务和治理驱动因素对风险评估的影响，这些影响源于在关键流程上实施区块链技术，同时确保业务/IT 目标协调一致。应利用政策、标准和程序建立治理目标的绩效水平。 |
