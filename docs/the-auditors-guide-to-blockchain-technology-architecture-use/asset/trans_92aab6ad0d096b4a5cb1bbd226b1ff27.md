

# Corda 隐私保护方法

Corda 采用多种方法来提升用户隐私，优于其他分布式账本系统。在 Corda 中，交易不会像许多其他区块链系统那样全局广播。此外，Merkle 树被用于构建交易结构，并且可以向已经知道 Merkle 根哈希的各方揭示单个子组件。此外，各方可以在无法看到交易全貌的情况下对其进行签名 [[4](#ch15.xhtml#r270), [10](#ch15.xhtml#r276)]。节点上的密钥管理服务生成并使用与身份无关的随机密钥。涉及流动性资产的大型交易图可以通过要求资产发行方使用新的引用字段在账本上重新发行资产来进行“修剪”。虽然这不是一个原子操作，但它有效地将资产的新旧版本解耦，这意味着节点在验证期间不会尝试探索原始的依赖图 [[6](#ch15.xhtml#r272)]。

Corda 的隐私保护侧重于利用安全硬件飞地对整个账本进行加密和验证。在发生故障时，它可以提供同态加密和零知识证明的优势，而无需牺牲可扩展性或可审计性。

## Corda 的局限性

Corda Network Foundation 为使业务网络能够注册而收取的高昂实施和运营成本，是阻碍全球 Corda 网络（网络的网络）自然和加速增长的关键障碍。虽然大型金融机构不会反对这些费用，但许多较小的业务网络可能会拒绝加入，因为成本将超过使用 Corda DLT 技术的收益。因此，采用全球 Corda 网络的成本可能会限制其未来增长。此外，这些成本壁垒可能导致使用 Corda 开源版本的商业网络与使用企业版本的商业网络之间产生无法弥合的鸿沟 [[9](#ch15.xhtml#r275)]。

# 总结与结论

实施区块链的理念已从现代数字加密货币的底层技术演变为一类新的分布式和去中心化应用，它们能在无信任的点对点环境中有效运行。无信任、去中心化账本支持历史不可变性的特性，已成为许多行业实现安全和保障的日益流行的理念。

本章旨在简要介绍三种当前流行的区块链框架，即 Ethereum、Hyperledger 和 Corda。这些框架将区块链技术的优势应用于银行业、网络安全、审计、医疗保健、供应链管理、通信系统和物联网等当前业务流程中。如果有效利用，这些框架可以支持在数据分布式且去中心化的无信任环境中，保护网络、通信和数据的现有努力。要将这些区块链框架实施到任何特定的业务用例中，首先必须了解实施安全区块链网络的底层及相关机制和技术。

值得注意的是，这些框架在拥有所有隐私和安全特性的同时，也存在相关的漏洞和局限性。在考虑将本章讨论的任何框架应用于业务流程之前，必须研究其可行性。涉及信任、共识和不可变性顾虑的用例应探索区块链技术作为有前景的解决方案。否则，其他替代方案（如使用数据库技术）通常将证明更具成本效益。
