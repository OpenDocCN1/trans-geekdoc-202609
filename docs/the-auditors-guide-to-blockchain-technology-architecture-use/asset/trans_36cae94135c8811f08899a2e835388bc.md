

# 区块链治理与分叉

本书前三章旨在为读者提供对区块链技术各种属性和组件的基本理解。对于许多公有区块链实现而言，代币或加密货币的使用构成了一大优势。因此，本章旨在首先让读者熟悉各种区块链治理类型及考量因素，以便解释区块链中“分叉”的概念。同样重要的是要注意，永久性或硬性区块链分叉往往会导致一种新型加密货币的诞生。本章提供了此类事件的若干示例。

本章还讨论了各种区块链代币类型，如权益型代币和实用型代币，以及当前的代币标准，如 `ERC 20`、`223` 和 `721`。本章最后一个主要部分为读者概述了一些更流行的加密货币类型，如 `Bitcoin`、`Ether`、`Ripple`、`Litecoin` 和 `Monero` 等。最后，还简要讨论了一些主要的当前加密货币交易平台，如 `Bittrex`、`Coinbase` 和 `Bitfinex`。

正如章节中所述，截至 2020 年 2 月，已创建近 5,400 种加密货币，总市值超过 2 亿美元。尽管目前市场上大多数加密货币的长期表现和可持续性仍高度不确定，但审计师和有志于成为区块链专业人士的人士熟悉本章讨论的较流行加密货币的基本属性非常重要。

## 区块链治理

正如前几章所讨论的，区块链技术在满足客户需求方面为其提供了重要的优势和控制权。组织治理被定义为组织据以达成并实施与追求其目标相关决策的制度。治理结构被所有参与者或用户所接受并遵循。尽管治理机构通常具有中心化性质，但区块链是一个点对点的去中心化系统，会随着时间的推移和需求不断演进。

区块链治理是区块链适应不断变化的环境和需求的制度。适应性和可升级性构成了区块链治理的关键特征。广义上讲，区块链治理通常涉及以下四个核心主体：

*   **核心开发者** 负责维护支持区块链的基础代码。
*   **节点运营商** 是持有区块链完整记录副本的一组运营商。代码开发者依赖节点运营商接受他们提供的功能。节点运营商做出与在节点上实施代码开发者提供的功能相关的决策。
*   **代币持有者** 包括区块链代币的客户/用户。投资者构成了这一利益相关者群体的主要部分，他们拥有就功能实施、升级等进行投票的权利。
*   **区块链团队** 由主要负责筹资和项目开发任务的公司或非政府组织（NGO）组成。这些团队主要由投资者和支持者组成，他们与节点运营商和代码开发者就区块链的运行进行协商 [[31]](#ch11.xhtml#r158)。

### 流行的区块链治理策略

**链下治理** 在用户、矿工和组织之间保持平衡。该治理体系具有中心化性质，由开发区块链的核心各方做出各种治理相关决策。未参与区块链核心开发的各方缺乏做出治理相关决策的知识和专长；因此，该技术遵循直接治理方法，即每个人对每项决策直接投票。`Bitcoin` 和 `Ethereum` 是这些治理技术的示例。为了弥补链下治理的缺点，后来开发了链上治理系统中讨论的新技术。

**终身仁慈独裁者** 是最简单的治理策略，其中单个人（原始创建者/首席开发者）的垄断地位在区块链治理决策方面占据主导地位，例如 `Ethereum` 的创建者 `Vitalik Buterin`。

**核心开发团队治理** 常用于最著名的核心开发者负责做出决策和区块链结构规划的情况。尽管任何客户都有权请求功能，但最终决定权仍掌握在核心开发者手中。

**开放治理** 是 `Hyperledger` 和 `Corda` 采用的一种技术，其中团队由客户社区通过民主方式共同选举产生。该当选团队负责做出各种区块链治理相关决策。

**链上治理** 可能在基于区块链的系统中更受青睐，以帮助确保没有用户或用户群体能够将其意志强加于区块链。用户之间的交互规则在此类治理中被定义。交互完全基于区块链基础设施的规则，称为“代码即规则”。规则集可以分层，一个规则集可以作为其他规则的基础。当规则和决策过程被编码进区块链系统的基础设施中时，该治理模型被称为链上治理。在链上治理中，共识通过直接投票方案达成。投票结果按算法计算并根据区块链协议运行 [[28]](#ch11.xhtml#r155)。不需要节点用户的参与，因为该过程遵循链上流程。这导致决策更加有效，从而降低了硬分叉的可能性。链上治理也存在一些挑战，如可扩展性。随着区块链网络的持续增长，以有效且高效的方式执行治理规则将变得越来越困难 [[31]](#ch11.xhtml#r158)。

## 区块链分叉

区块链分叉可能对加密货币产生重大影响。事实上，永久性分叉可能成为新加密货币诞生的原因。例如，2017 年 8 月，`Bitcoin` 社区出现分歧，导致 `Bitcoin` 区块链上发生 `Bitcoin Cash` 分叉。2016 年 7 月，`Ethereum` 社区的大部分成员作为对 `DAO` 攻击的回应修改了共识规则，导致出现两条链和两种加密货币；一种是 `Ethereum Classic`，另一种是 `Ether`。分叉可被定义为共识规则的修改，这可能导致也可能不导致区块链网络分裂和新版本区块链的出现。去中心化是区块链的显著特征之一。区块链分叉是去中心化的含义之一（[图 3.1](#ch11.xhtml#f17)）[[33]](#ch11.xhtml#r160)。

### 分叉发生的原因

由于部分用户对现有区块链存在分歧，区块链分裂为不同的实例。偶尔，当不同时间生成不同区块时，会观察到短期的不确定性。其他时候，则表现为共识规则的修改，这可能导致区块链的新版本出现。分叉可能为新型攻击铺平道路，并通过跨链分析威胁数据保护。总体而言，任何后续分叉都会损害信任并引发不确定性 [[33]](#ch11.xhtml#r160)。
