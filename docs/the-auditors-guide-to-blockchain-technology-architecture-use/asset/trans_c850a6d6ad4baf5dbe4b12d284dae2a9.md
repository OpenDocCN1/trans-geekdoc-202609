

# 雀巢与 Amazon Managed Blockchain

与协作数据相关的主要挑战之一是零售商与客户之间的时间滞后。雀巢利用 AWS 通过实施 **Amazon Managed Blockchain (AMB)** 来避免时间滞后，以此作为邀请供应商协作实现供应链透明化的一种手段。雀巢快速构建原型，并与 Amazon Web Services 共同出资，为溯源打造了一个概念验证，以高效加速其创新。

从农场到消费者的溯源链包含五个层级的信息流：

1.  咖啡在农场经过处理后被运送至分级设施。
2.  咖啡在烘焙前移交给经纪人，此时将确定烘焙程度。
3.  当产品在包装设施完成包装时，烘焙过程结束，此时会记录包装供应商和制造信息。
4.  包装完成后，产品被运输给承运商，承运商存储分销商和零售商的信息。
5.  流程结束时，完成客户补充环节，其中记录了与产品销售相关的所有信息。

在 **Amazon Managed Blockchain Services** [[36](#ch23.xhtml#r555)] 的帮助下，雀巢得以简化公司使用的技术基础设施，从而专注于为业务增值、支持农民和烘焙商，并为消费者提供卓越的口味体验。在雀巢实施 **Amazon Managed Blockchain** 有助于改善其咖啡口味和可及性，并帮助消费者了解其购买产品的来源。雀巢选择 **Amazon Managed Blockchain** 的主要原因在于其低成本、易用性、与其他 AWS 组件的集成能力，以及支持 **Hyperledger Fabric**。实时数据协作使雀巢能够通过将消费者与咖啡工艺相连接，从而提供优质的咖啡体验。通过 **Amazon Managed Blockchain**，客户可以在区块链上追踪其产品从农场到消费者的全过程 [[14](#ch23.xhtml#r533)]。

使用 **Amazon Managed Blockchain**，所有交易都以透明、不可篡改和可验证的方式存储，使各方能够以更受信任、更高效的方式进行交互，无论是否存在中心化权威。在供应链中使用这项技术最重要的优势之一，是能够立即检测到错误、渎职或任何篡改行为，并在必要时解决问题。雀巢跨其各个品牌采用区块链验证作为解决方案。由于其不可篡改性，区块链可用于验证食品溯源及其生产环境 [[36](#ch23.xhtml#r555)]。

# 利用 Azure Blockchain Service 管理发行商版税信息

视频游戏行业近年来经历了快速扩张。除了编程，视频游戏还需要音乐、特效和图形。为便于提供版税信息，实施了一个基于区块链的解决方案。客户获取账单的时间已从 45 天缩短至几分钟。尽管视频游戏经历了快速增长，但用于补偿游戏发行商的财务报告系统依然依赖一种老派的会计模型，即使用电子表格来计算和核对游戏版税。Xbox 财务部门于 2018 年采用区块链技术，以消除处理游戏发行商版税的耗时流程，并使版税信息更易获取。随着区块链技术的出现，数字账本现在可以更轻松地连接。

得益于其防篡改的特性，数字账本通过提高透明度和使系统更易用，便利了交易记录。基于区块链的解决方案支持智能数字合约，它们在交易发生时自动执行，将复杂的版税协议逻辑编码化。嵌入式逻辑增强了所有人对公平、准确付款的信心 [[25](#ch23.xhtml#r544)]。通过利用 **Azure blockchain service**，Xbox 团队能够轻松管理智能合约并管控与不同游戏发行商的版税关系。该服务简化了发行商备注管理并监控网络健康状况。与非托管账本相比，**Azure blockchain service** 显著减少了基础设施安全和维护所涉及的工作量，实现了更高的支付效率。得益于这项技术的实施，发行商获取游戏销售数据变得轻而易举，且获取数据的等待时间大幅缩短。从 **Azure blockchain service** 检索到的信息涉及哪些游戏销售良好，以及哪些游戏目前在市场上处于流行趋势。

利用 **Microsoft Azure Blockchain** 技术，**Blockchain-as-a-Service (BaaS)** 服务构建在 **Microsoft Azure** 平台之上。凭借这些功能，设置权限、监控和维护网络，以及管理成员凭证变得更加容易。在智能合约的帮助下，通过应用编码逻辑，可以获取数字内容并即时计算版税 [[25](#ch23.xhtml#r544)]。因此，财务交易可以定期追踪，使预测和报告更加有效，并让消费者能够专注于其核心竞争力。企业资源规划会计分录现在可以直接从区块链生成。此外，人工智能技术被集成到合约创建过程中，并托管在 **Microsoft Azure** 上 [[7](#ch23.xhtml#r526)]。

# 全球航运商业网络 Oracle Blockchain-as-a-Service：CargoSmart

**CargoSmart** —— 一个全球运输管理系统 —— 开始尝试区块链解决方案，以改进复杂的供应链流程，在物流行业创建数字货运单据。通过使用该平台，发货人和海关办事处可以更高效地协作，构建一个低延迟的不可篡改审计追踪。处理单据涉及多个流程和程序，包括过时的纸质流程、广泛的技术能力范围，以及通过 **electronic data interchange (EDI)** 和电子邮件等不同格式共享单据。

**CargoSmart 区块链平台** 旨在简化货运单据流程，最大限度地减少冲突，缩短单据准备时间，并避免额外的海关罚款。因此，消除了整合、验证和管理在各种单据中重复的航运信息所需的时间，从而使物流流程更加高效和准确。通过与 **Oracle Blockchain Cloud Services** 合作，**CargoSmart** 创建了 **Global Shipping Business Network (GSBN)**，帮助公司高效创建区块链网络，以进行更可靠、更安全的交易 [[8](#ch23.xhtml#r527)]。据 **CargoSmart** 首席执行官 Steve Siu 表示：“区块链倡导联盟概念，因此我们邀请发货人、货代、承运人和码头参与” [[16](#ch23.xhtml#r535)]。凭借去中心化治理、互操作性和企业级架构，该平台适合监控全球货运，并在所有利益相关者之间进行组织和追踪 [[8](#ch23.xhtml#r527)]。

**GSBN 平台** 为航运行业提供单一信息来源，具有以下特征：

*   **开放且可扩展**：合作网络可开发软件并连接到联盟网络，以增强数据互操作性和业务效率。
