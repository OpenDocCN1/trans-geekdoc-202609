硬件钱包通常是最安全的。因此，在被没收的情况下，需要所有者的配合才能解锁。然而，在丢失 PIN 码或设备的情况下，可以使用恢复功能。如果调查人员了解恢复步骤，则无需恢复 PIN 码即可访问币。

### 冷钱包或冷存储

冷存储是指保持离线状态的任何密钥。它可以位于 USB 密钥、纸条或硬件钱包上。虽然可能存在存储在离线状态的密钥，并且需要将其导入钱包以转出资金，但离线钱包仍然能够从发送方接收币。这是因为币从未被“接收”，它仅在区块链上引用该地址。因此，存放在保险箱中的一张纸片上的地址及其私钥或备份，在完全离线的情况下仍然可以变得更“富有”（接收更多币）。

设置纸钱包非常简单。私钥可以写在一张纸上并存放在安全的地方，如银行保管箱。公钥/私钥地址对也可以在不联网的情况下生成。纸钱包非常安全，因为密钥对可以生成，且私钥永远不需要出现在钱包或计算机上，直到需要将接收到的资金转移到公钥地址为止。

### 密钥如何存储在钱包中？

钱包以多种方式存储密钥。这些方法描述了从单个或多个私钥创建公钥的方式。理解密钥如何创建非常重要，因为它有助于追踪具有复杂交易需求的个人或组织使用的钱包。这些方法分为三大类：

*   **非确定性**：也称为类型 0 或*只是一堆密钥*（JBOK）。非确定性密钥以公钥/私钥对的简单列表形式存储。这种方法意味着有大量的密钥需要管理。这也意味着需要备份或妥善保管大量数据。

*   **确定性**：也称为类型 1或种子钱包。在确定性钱包中，所有私钥都从基于随机数的单个种子获取。这种方法好得多，因为只需存储和备份种子即可恢复所有生成的私钥。这使得管理钱包变得容易得多。

*   **分层确定性**：也称为 HD 钱包。这是目前使用的最新钱包协议，并于 2016 年在 Bitcoin Core 中实现。与确定性钱包一样，所有私钥都从单个种子获取，但 HD 钱包中的密钥可以按层级结构生成自己的私钥和公钥。此外，种子可以备份，备份的种子可用于恢复整棵树的结构。种子通常由一系列 12 到 24 个单词表示 [[34](#ch10.xhtml#r077)]。

## 星际文件系统

星际文件系统（IPFS）是一种协议，允许媒体存储在分布式文件系统上 [[40](#ch10.xhtml#r083)]。当文件被添加时，它会生成一个唯一的指纹（哈希值），并在网络中移除重复文件 [[17](#ch10.xhtml#r060)]。

IPFS 是一种去中心化文件系统，其核心功能是通过应用分布式哈希表（DHT）和 Merkle 有向无环图（DAG）数据结构创建的 [[40](#ch10.xhtml#r083)]。

IPFS 本质上是一个去中心化的点对点共享应用程序，因为系统中没有上级节点，并且与典型的去中心化文件系统会保存文件直到用户删除不同，IPFS 仅保存正在使用的文件并确保它们保持不可变 [[62](#ch10.xhtml#r105)]。因此，不常用的文件会自动从网络中删除。IPFS 的这一属性是其网络上似乎不可能发动成功的分布式拒绝服务攻击的主要原因 [[56](#ch10.xhtml#r099)]。

IPFS 的子协议如下：

*   **身份**确保处理节点的身份被生成并验证为真实。
*   **网络**确保与其他网络的无缝连接，并可选择性地检查网络中发送消息的完整性。
*   **路由**确保网络中信息准确传递给预期接收者。
*   **交换**确保数据分发无缝进行。*BitSwap* 用作节点获取所需区块的媒介。
*   **对象**用于表示网络中的数据结构和通信层级。
*   **文件**确保文件系统中存在清晰的层级结构。
*   **命名**确保使用自我认证的可变名称系统 [[17](#ch10.xhtml#r060)]。

IPFS 有一个名为*星际命名系统*（IPNS）的名称服务。IPNS 允许通过用户易于识别和理解的名称来标识 IPFS 文件。这有助于用户在更新发生后轻松识别要下载的文件。

IPFS 的一项高级功能是它支持使用类似 GIT 的数据结构进行文件版本控制，GIT 是一种用于识别和跟踪文件中任何变更的软件，也用于增强多人软件开发过程中的协调工作。IPFS 还利用目录和文件，通过称为用户空间文件系统（FUSE）的可挂载文件系统 [[62](#ch10.xhtml#r105)]。

IPFS 文件有以下四种类型：

*   **Blob** 是存储在 IPFS 中的文件主要部分的表示。
*   **List** 是由 Blob 和其他 List 组合而成的完整文件的表示，旨在压缩网络中的数据。
*   **Tree** 是目录的表示。它包含 Blob、List、Tree 和 Commit 的组合。
*   **Commit** 是网络上任何文件历史的快照。

由于网络中的每个文件都由其哈希值标识，因此需要类别的哈希值以下载任何文件。例如，要下载文件的快照，需要 IPFS Commit 的哈希值 [[40](#ch10.xhtml#r083)]。

## 智能合约

Nick Szabo 在 20 世纪 90 年代末在一篇题为《在公共网络上形式化和保护合作伙伴关系》的文章中提出了智能合约。智能合约是运行在区块链之上的安全且去中心化的程序。它代表了一种协议，当满足特定条件时，该协议可自动执行和强制执行。智能合约是一个去中心化框架。区块链机制的主要隐私优势使区块链成为智能合约的标准去中心化模型 [[14](#ch10.xhtml#r057)]。
