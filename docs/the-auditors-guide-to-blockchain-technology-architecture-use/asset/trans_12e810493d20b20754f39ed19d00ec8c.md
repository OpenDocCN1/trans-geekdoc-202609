

# BaaS 解决方案概览

## Oracle BaaS

Oracle 提供的 BaaS 解决方案具有两大核心能力：开箱即用的沙箱环境和独立软件供应商。开箱即用的沙箱环境面向开发者。独立软件供应商 (ISV) 使区块链技术的部署变得简单，无论是在入网引导还是智能合约生成方面，且不受供应商限制 [[27](#ch23.xhtml#r546)]。平台采用基于组合的架构，这意味着所有系统和流程均设计为支持 API 启用。Oracle 区块链云服务运行在一个验证节点和账本的区块链网络上，通过执行代表业务逻辑的智能合约来响应查询。外部应用程序可通过客户端 SDK 或 REST API 调用交易或运行查询。达成共识后，交易将被添加到区块中。交易透明且共享，但可根据其等级限制访问权限。此前，排序节点由一组 Kafka 和 Zookeeper 机器集群管理。然而，该架构在应用于云环境时日益显得资源密集。因此，推出了共识插件 RAFT 来管理排序服务，并使其做好面向企业级生产网络的准备。借助 RAFT，一组排序节点协同工作，基于动态领导者模型创建排序区块。因此，成员组织的参与最为公平和统一，即使节点数量庞大亦是如此。此外，Oracle 还提供更优质的加密服务以保护敏感信息 [12, [16](#ch23.xhtml#r535)]。

## Microsoft Azure BaaS

作为与 Consensys（一家领先的云计算服务提供商）合作的一部分，Microsoft 也于 2015 年底在其 Azure 平台上提供了以太坊区块链即服务 (EBaaS)。Azure BaaS 支持 Ethereum、Corda、Quorum 和 Hyperledger Fabric [[27](#ch23.xhtml#r546)]。借助 Azure BaaS，客户还可部署带有分布式账本的企业级模板，且无需承担费用。然而，当在区块链上构建应用程序时，客户需自行负责开发和成本。Microsoft Azure 在 BaaS 方面提供三种产品：Azure 区块链服务、Azure 区块链工作台和 Azure 区块链开发工具包 [[12](#ch23.xhtml#r531)]。

### Azure 区块链服务

Azure 区块链服务是一项完全托管的区块链服务，允许客户在几分钟内创建和运行区块链网络。Azure 以简化的形式为基础设施管理和网络治理提供完整的端到端解决方案，并内置联盟网络。Azure 区块链服务支持 Ethereum Quorum 账本，采用伊斯坦布尔拜占庭容错共识机制。客户无需关心底层基础设施，可专注于应用开发和业务逻辑。作为其退役计划的一部分，Azure 区块链服务将于 2021 年 9 月由 Consensys 的 Quorum 区块链服务取代 [[28](#ch23.xhtml#r547)]。

### Azure 区块链工作台 (ABW)

Azure 区块链工作台是一组 Azure 服务，允许企业开发和管理区块链应用程序，并将其业务流程跨组织传递。Microsoft 的 Azure 区块链工作台促进了区块链应用程序的开发，使开发人员能将精力集中在构建业务逻辑和智能合约上。Azure 区块链工作台因其集成能力而广受欢迎，这些能力利用工作台的 Web 应用程序和 REST API 简化了区块链应用程序的创建。通过这些 API，客户可以替换不同的分布式账本技术、存储产品和数据库。此外，ABW 可与所有主流 Microsoft 产品集成，包括 Excel、SharePoint、Office 365 等。

### Azure 区块链开发工具包 (ABDK)

区块链开发工具包包含代码示例，是一个旨在与 Azure 服务集成的 GitHub 存储库。作为 Azure 平台的一部分，Microsoft 提供了一个基于 Microsoft 无服务器技术并与 Microsoft 及第三方 SaaS 集成的区块链开发工具包。除了能够连接到多个数据源外，Azure 区块链开发工具包还可与遗留应用程序和协议集成，例如 Excel、Office 365 等。借助 Azure 区块链工作台和 Azure 区块链开发工具包提供的 RESTful API，与区块链节点交互从未如此简单和安全 [[12](#ch23.xhtml#r531)]。

## Amazon AWS BaaS

借助 Amazon Managed Blockchain，AWS 提供了一个完全托管的平台即服务，用于利用开源分布式账本技术（如 Ethereum 或 Hyperledger Fabric）构建和部署区块链网络。该平台为客户提供多种实例类型选择，具有可定制的计算和内存容量，以适应其区块链应用程序需求。网络启动通过 AWS 区块链模板执行。网络可用后，Managed Blockchain 的投票 API 将允许成员就网络参与进行投票。随着新成员的加入，Managed Blockchain 提供启动和配置多个对等区块链的能力，这些节点将处理交易请求并存储账本副本。作为托管区块链生态系统的一部分，AWS 密钥管理服务充当证书颁发机构。因此，加入 Managed Blockchain 的新用户无需设置硬件安全模块。凭借网络可扩展性，网络可适应增加的交易量和负载。此外，新成员无需特殊硬件即可加入云端。Amazon Managed Blockchain 作为 Hyperledger Fabric 框架的一部分，用于增强“排序服务”，从而在区块链网络间建立信任。量子账本数据库 (QLDB) 记录区块链上所有未提交的交易，确保透明且安全的排序服务 [[12](#ch23.xhtml#r531)]。

## Alibaba BaaS

Alibaba Cloud 是当今市场上最著名且专利最丰富的供应商之一。其 BaaS 平台基于 Alibaba Cloud 容器服务的 Kubernetes 集群构建，支持 Hyperledger Fabric、Ethereum 和金融级区块链技术蚂蚁链。除了支持公有部署外，该基础设施还支持私有部署。借助 Alibaba Cloud 区块链即服务，用户可创建生产级区块链环境，并可图形化管理运维操作。

得益于其分布式数据中心，Alibaba BaaS 在全球范围内提供服务。由于联盟区块链网络建立在多租户隔离原则之上，每个参与者均可独立管理其资源。此外，部署简单易行，易于与其他云服务和产品集成，并拥有灵活的生态系统，可支持广泛的应用程序和插件。Alibaba Cloud 区块链即服务包含默认的 Anti-DDoS 基础防护服务。供应商提供的额外服务包括产品溯源、供应链金融和数据资产追踪，以跟踪数据所有权。该供应商提供的服务可定制以满足特定业务需求，同时保持先进的安全性和隐私保护 [[1](#ch23.xhtml#r520)]。
