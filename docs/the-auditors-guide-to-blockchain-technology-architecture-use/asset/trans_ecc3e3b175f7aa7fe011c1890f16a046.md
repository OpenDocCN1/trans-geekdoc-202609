# 7 以太坊、Hyperledger 和 Corda：针对开发各类业务用例的能力与约束的并列对比

Manroop Kaur 和 Navjot Lnu

DOI： [10.1201/9781003211723-7](http://doi.org/10.1201/9781003211723-7)

## 摘要

本章深入探讨了三种当前流行的区块链框架，即以太坊、Hyperledger 和 Corda。

以太坊讨论部分首先介绍了以太坊的各个组件，这是一个拥有自身加密货币（以太币）的公有链。从历史上看，以太坊是第一个引入智能合约概念的区块链框架——这改变了区块链技术的游戏规则。本章第一部分还包含了以太坊智能合约和共识机制的特性与局限性，以及以太坊在医疗保健和供应链管理领域多个用例的简要讨论。

本章第二部分讨论了多个 Hyperledger 框架，如 Hyperledger Burrow、Fabric、Indy、Iroha 和 Sawtooth，旨在让读者更好地了解这些不同的私有、许可制 Hyperledger “变体”。此外，还介绍并讨论了多个 Hyperledger 相关工具。这些包括 Hyperledger Caliper、Composer、Cello、Explore 和 Quilt。

本章第三部分重点关注 Corda 框架，这是银行和金融服务行业流行的区块链框架。Corda 的各个组件也被介绍和讨论。本节还简要讨论了 Corda 智能合约、共识机制的特性，以及 Corda 在医疗保健、建筑和金融领域的多个用例。关于 Corda 网络中的用户隐私和 Corda 的局限性的简要讨论也包含在本章第三部分中。

最后，本章以这三个框架的并列对比作为结尾，采用易于参考的格式，并附带一个决策树，可作为决定采用最合适框架的第一步，具体取决于组织设想的用例。

## 以太坊

以太坊项目是一个开源项目，最初由其创始人、俄裔加拿大人 Vitalik Buterin 于 2013 年提出，并于 2015 年正式启动。以太坊项目旨在提供一种替代协议，专门设计用于让人们构建去中心化应用。该项目的主要目标之一是，通过使用一种加载且无歧义的语言定义状态变更系统，并设计一种能够自主应用此类协议的系统，赋予自愿的个人在无信任环境中与其他自愿个人进行交易的能力。缺乏信任可能源于地理隔离、接口挑战，或者现有法定系统的不兼容、无能、不情愿、成本、风险、不便或腐败，而以太坊致力于为这些问题提供可行的解决方案。

以太坊是一个无许可、开放的区块链，集成了图灵完备编程语言，用于创建智能合约。作为一个具有内置编程语言的通用区块链，以太坊允许其用户将区块链用于他们想要创建的任何去中心化应用。术语 `图灵完备编程语言` 意味着以太坊可以支持所有类型的计算 [[18](#ch15.xhtml#r284)]。以太坊通过允许用户制定其个性化的所有权规则集、状态转移函数和交易格式，赋予用户编写定制智能合约和去中心化应用的能力。换句话说，以太坊提供了一个通用的可编程区块链，封装在一个人人可用的开放客户端中。例如，以太坊可以构建完全值得信赖且透明的金融应用，因为它们运行在区块链上，并使用可以用数学方式定义的智能合约或交易类型。以太坊合约是用以太坊虚拟机代码（即 EVM 代码）编写的；一种低级的、基于栈的字节码语言。

以太坊还拥有一种虚拟货币 `Ether`，也称为 ETH，用于支付区块链相关的交易费用。`Wei` 是最小的以太币子面额，所有货币整数值均以此计数。1 个以太币等于 10^(18) Wei [[7](#ch15.xhtml#r273), [19](#ch15.xhtml#r285)]。

从根本上说，以太坊的设计旨在做到简单、通用、模块化、敏捷、非歧视性和非审查性 [[17](#ch15.xhtml#r283)]。除非能提供有价值的优势，否则以太坊协议倾向于不包含任何复杂的优化，从而保持其易于实现。此外，其内置的图灵完备脚本语言使用户能够使用可以用数学方式定义的智能合约或交易类型；从而使以太坊与所有类型的计算具有通用兼容性。再者，由于以太坊采用模块化设计，各部分可分离，因此允许用户在一处进行微小的协议修改，而不妨碍应用其余部分的运行。此外，以太坊协议具有灵活性，因为它们开放给可以显著增强以太坊可扩展性或安全性的修改。此外，以太坊协议力求不主动限制或约束明确的使用划分。协议的调节机制力求不针对特定的不受欢迎的应用，而是直接管理危害，从而避免歧视和审查 [[17](#ch15.xhtml#r283)]。

`世界状态` 是 160 位地址与账户状态之间的映射。维护此映射的数据库后端称为 `状态数据库`。每个账户状态都有一个 20 字节的地址和一个状态转移，可直接在账户间转移价值和数据。账户状态包含以下四个字段：

*   `Nonce`（随机数/交易计数）：一个标量值，表示从特定地址发送的交易数量，或特定以太坊账户创建的合约数量（带有关联代码）。它确保每笔交易仅被处理一次。

*   `Balance`（余额）：一个标量值，表示以太坊账户地址拥有的以太币数量。
