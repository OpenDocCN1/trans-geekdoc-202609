
*   **预言机**：这些链下数据存储库充当区块链与外部世界之间的桥梁。链下数据对区块链和智能合约不可见；然而，为了执行特定的合约安排，拥有来自外部世界的相关细节至关重要。这就是区块链预言机发挥作用的地方，因为它们提供了链下和链上信息之间的连接。预言机在区块链生态系统中很重要，因为它们扩展了可使用的智能合约的范围。通常，如果没有预言机提供的更新且独立的数据，智能合约将毫无用处。区块链预言机是一个层，它在中继信息之前查询、验证和认证外部数据源。价格详情、支付的有效完成或传感器测量的温度都是由预言机传输的数据示例。必须调用智能合约并消耗网络资源，才能从外部世界调用数据。除了将信息中继给智能合约外，某些预言机还可能将信息发送回外部源。

工具使开发区块链应用的过程更容易，并有助于软件应用的创建。因此，它们促进了我们区块链认知的扩展 [[30](#ch17.xhtml#r343), [38](#ch17.xhtml#r351)]。

## 集成开发环境

根据 Lyn 的说法，集成开发环境 (IDE) 是一种应用软件，为应用开发人员提供一个单一平台来设计、测试和调试计算机程序。消除错误或缺陷的过程称为调试，借助调试工具来实现。调试创造了一种环境，使创建或开发卓越的软件应用变得容易。文本编辑器、终端、调试工具和代码片段是集成开发环境中通常包含的工具 [[29](#ch17.xhtml#r342)]。

IDE 甚至可以使用编译或解释工具，或两者兼用，从而提供一个有利于软件开发的氛围。现代 IDE 配备了对象浏览器、类浏览器和类层次结构图功能 [[9](#ch17.xhtml#r322)]。

一些 IDE 在 JavaScript 或 Python 平台上运行 [[45](#ch17.xhtml#r358)]。IDE 是一个单一的图形用户界面，以调试器、本地构建自动化和源代码编辑器为支柱。供开发人员使用，本地构建自动化利用简单的冗余任务。凭借语法高亮等广泛功能，源代码编辑器有助于软件代码的创建 [[19](#ch17.xhtml#r332)]。

IDE 工具提高了生产力和执行持续编译、自动化测试、集成调试、重构和类间导航等任务的能力。Eclipse 和 Visual Studio 也可与 IDE 配合使用。在使用 Visual Basic 时，IDE 开发人员可以在代码行旁设置或清除断点。此外，在 IDE 底部的“即时窗口”中，开发人员可以使用 Visual Basic 语句。因此，IDE 的重点是为软件程序员在软件应用开发中提供全面的设施 [[41](#ch17.xhtml#r354)]。

## 区块链开发的良好实践

*   **谨慎调用外部合约，优先使用自有合约**：强烈建议尽可能优先使用内部合约而非第三方创建的合约。换句话说，所有内部开发的合约都已经过与解决方案其余部分相同级别的安全性、审查、测试和验收标准的约束，因此它们将符合为解决方案其余组件设定的相同质量和安全标准。应分配足够的审计和测试时间及精力，以仔细审查任何外部合约的源代码。使用第三方合约时，必须确保不存在由第三方造成的固有安全缺陷。

*   **处理所有错误；捕获外部调用中的所有异常**：在智能合约中，函数必须被 `try/catch` 语句包围，并且必须显式处理每一个异常，无论其看起来多么不可能发生。所有未被显式捕获和管理的异常都应被抛出，并将异常上抛至其调用函数或合约。合约应尝试妥善处理异常，并尝试在无需用户干预的情况下继续执行。如果无法做到这一点，应发送一条错误消息，并附带关于如何解决该错误的建议。如前所述，在处理外部合约时，不应假设另一位开发人员已采取相同的预防措施。如果用户收到任何意外或晦涩难懂的错误，他们会认为该应用程序存在缺陷 [[8](#ch17.xhtml#r321)]。

*   **推送支付与拉取支付**：基于推送的金融交易是指卖方使用自动交易从客户账户中电子扣除或添加资金。执行自动每月或每年扣款的订阅或公用事业付款计划是基于推送的金融交易的一个例子。在区块链环境中，拉取支付提供了一项重要优势。进一步解释，拉取支付应将支付过程分为两个阶段。第一步应是一条通知，告知用户有可用资金等待从智能合约中拉取。在第二步中，收款人应根据通知采取行动，将可用资金从收款人的正确钱包地址中拉出。与传统银行交易不同，这种方法将有助于避免资金被发送到无法撤销的错误钱包地址的问题 [[7](#ch17.xhtml#r320), [12](#ch17.xhtml#r325), [32](#ch17.xhtml#r345), [35](#ch17.xhtml#r348), [43](#ch17.xhtml#r356)]（[图 9.1](#ch17.xhtml#f22) 和 [9.2](#ch17.xhtml#f23)）。
