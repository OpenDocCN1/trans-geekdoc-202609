

### 控制活动
控制活动在政策、程序和标准中进行描述，这些文件帮助各级管理层缓解已识别的风险，以实现组织目标。控制活动的性质可以是预防性的，也可以是检查性的，具体取决于环境。

### 信息与沟通
实体在履行职责和执行目标时，需要适当的信息流。管理层利用来自内部和外部来源的重要信息，以支持内部环境中其他组成部分的运作，而沟通则是分享必要信息所必需的。

### 监控活动
监控活动是独立的、持续的评估，旨在核实内部控制的五个组成部分，包括影响每个组成部分内原则的控制措施。持续评估建立在实体不同层级的业务流程之上，能提供及时信息。独立评估则根据风险评估的结果定期进行 [[17](#ch20.xhtml#r440)]。

[表 12.3](#ch20.xhtml#t37) 列出了 COSO 内部控制的五个组成部分，并细分为十七项原则 [[17](#ch20.xhtml#r440)]。

[表 12.3](#ch20.xhtml#t37b) 内部控制的五个组成部分与十七项原则

| **组成部分** | **原则** |
| --- | --- |
| **控制环境** | 1. 表现出对诚信和道德价值观的承诺。 2. 行使监督责任。 3. 建立结构、权限和责任。 4. 表现出对胜任能力的承诺。 5. 强制问责 |
| **风险评估** | 6. 明确合适的目标。 7. 识别和分析风险。 8. 评估舞弊风险。 9. 识别和分析重大变化。 |
| **控制活动** | 10. 选择和开发控制活动。 11. 选择和开发针对技术的通用控制。 12. 通过政策和程序部署控制活动。 |
| **信息与沟通** | 13. 使用相关信息。 14. 内部沟通。 15. 外部沟通 |
| **监控活动** | 16. 实施持续和/或独立评估。 17. 评估并沟通缺陷。 |
