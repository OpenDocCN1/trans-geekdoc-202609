

# 区块链中的嵌入式监管原则

区块链中的嵌入式监管原则强调了在金融服务领域实施区块链时，使用全面监管框架的重要性。嵌入式监管原则可在与分布式账本交互时自动部署。共有四项嵌入式监管原则。

首先，监管框架必须由有效的法律体系颁布，并由行业领先机构推广，以保障合法运营。

其次，嵌入式监管可应用于根据经济终局性原则被视为最终的交易（即撤销交易将不再获利）。

再次，嵌入式监管必须应用于所有各方参与并遵守精简监管的共识模型之上。

最后，嵌入式监管应以尽可能低的成本促进稳定性、高质量和验证流程 [[20](#ch13.xhtml#r224)]。

# 区块链在交易所中的应用

股票市场使上市公司能够为扩张目的筹集资金，同时为投资者提供流动性并消除对手方风险。这些金融交易活动通过制度化的公开正式市场进行，并在严格监管下运行。全球存在多个证券交易市场。全球前十大证券交易市场包括：纽约证券交易所（25.5万亿美元）、纳斯达克（11.2万亿美元），紧随其后的是日本交易所集团（11.2万亿美元）、上海证券交易所（4.6万亿美元）、香港交易所（4.23万亿美元）和深圳证券交易所（3.2万亿美元）、泛欧交易所（3.6万亿美元）、伦敦证券交易所（2.9万亿美元）、加拿大多伦多证券交易所集团（1.75万亿美元）和孟买证券交易所（1.51万亿美元） [[25](#ch13.xhtml#r229)]。

纳斯达克和纽约证券交易所是全球最大的证券交易市场；这些交易所多年来也一直在投资区块链技术计划。其中一项计划是 `tZero.com`，它推出了首个1.34亿美元的私人数字证券代币发行。这些代币将面向符合美国证券交易委员会（SEC）规定的参与者在市场上提供。tZero计划的开发符合SEC规则，其代币被视为证券市场的先驱。

与区块链计划相关的SEC规则旨在减轻对股票市场的增量冲击和干扰。例如，SEC发布的`DAO报告`，是对一个虚拟且去中心化自治实体的调查。DAO报告的调查重点是利用基于区块链的代币作为加密货币进行的证券发行。该报告提供了指导方针，以区分数字证券和加密货币，从而界定对美国证券法的合规性。根据SEC规则，使用代币作为加密货币的数字证券必须在受监管的替代交易系统（ATS）下运营。后续报告披露了针对该发行运营所在区块链的网络攻击。报告结论指出，利用去中心化和自治原则进行的证券发行应在SEC监管下运营，无论其底层技术为何 [[7](#ch13.xhtml#r211)]。

## 基于区块链的交易清算与结算

传统上，必须经过一系列验证和确认流程，才能在市场交易所清算和结算交易。以当前技术，市场交易所通常需要三天或更长时间才能实现终局性。相比之下，区块链技术可通过消除对中介机构的需求，实时简化清算和结算流程。区块链在改善证券发行周期方面具有巨大潜力；从发行到转让、结算和跟踪流程，包括各种合规相关任务。

tZero的计划是区块链为市场交易所带来的效率的一个良好范例。该计划由一个公共区块链组成，市场交易所通过替代交易系统（ATS）使用代币进行运营。ATS平台并非基于区块链技术；而是作为一种变通方式集成到基于区块链的数字证券中。清算和结算流程由带有智能合约的以太坊区块链提供支持 [[7](#ch13.xhtml#r211)]。

## 投资管理领域（共同基金）

投资管理是管理金融资产和投资（如证券、债券、股权、共同基金和其他金融工具）的统称。资产管理包括在股票、债券、房地产和大宗商品之间分散资金的决策和策略，以最大化这些资产产生的利润。管理至少2500万美元资产或向提供共同基金的公司提供建议的投资管理公司，必须注册为注册投资顾问（RIAs）。RIAs需要向证券交易委员会（SEC）和州证券管理机构注册为注册顾问。

区块链和智能合约可通过自动化金融流程（如开设新账户、文档记录保存、自动付款和证券转让）彻底变革投资管理领域。基于区块链的投资管理建立在与客户财务记录和交易历史关联的数字身份之上。一般来说，区块链技术分为四层；即（自上而下）应用层、服务层、网络层、协议层和基础设施层。区块链的底层基础设施层（包括数据存储和网络挖矿）与标准传统方法的工作方式完全不同。区块链通过设计，基于网络共识为既定数据提供加密和验证。在投资管理中实施区块链基础设施，更适合其价值链功能，这些功能包括多方授权批准、法律与合规执行、审计、跟踪与报告、投资组合管理和客户交互等活动 [[6](#ch13.xhtml#r210)]。
