

## 云角色

*   **云客户**：云客户可以是购买或租赁各种云服务的个人或组织 [[23](#ch23.xhtml#r542)]。

*   **云用户**：云用户通常指随时随地在线使用计算服务的用户或企业。值得注意的是，“云用户”一词主要指应用程序的最终用户；而云客户则是购买并支付云服务费用的一方。例如，当一个组织购买 Office 365 订阅供使用时，该组织扮演客户角色，而使用该服务的用户则是云用户 [[21](#ch23.xhtml#r540), [23](#ch23.xhtml#r542)]。

*   **云访问安全代理 (CASB)**：CASB 是一个安全执行点，位于最终用户和云之间，充当独立的第三方身份和访问管理执行者。CASB 作为监控和管理云资源访问的中心点 [[10](#ch23.xhtml#r529)]。

*   **监管机构**：除了确保组织遵守其监管授权外，监管机构还维护组织的完整性。组织会接受监管机构在安全性和性能方面的审查 [[23](#ch23.xhtml#r542)]。

## 云计算的优势

云计算为组织提供了许多好处。其中，成本降低是组织实施云存储解决方案所获得的主要收益，因为这些组织只需为所使用的服务付费。此外，云计算还能降低前期 IT 成本，并消除对负责维护服务器和本地基础设施的技术人员的需求。

多租户的概念是云计算的另一个方面，涉及多个用户共享服务器和应用程序。以分布式和共享的方式使用云，不同的用户和应用程序可以更高效地协同工作，并通过共享通用基础设施来降低成本。

由于数据和应用程序不再存储在本地，即使失去对台式机或笔记本电脑的访问权限，数据也将始终可用。此外，即使发生服务故障，数据也不会丢失，因为云服务提供商会有备份 [[26](#ch23.xhtml#r545)]。

## 什么是 BaaS？

得益于区块链的分布式、不可篡改和透明特性，开发区块链应用程序的趋势近年来日益流行。作为引入 IT 行业的各种创新之一，区块链即服务 旨在支持云平台上的区块链功能。BaaS 概念是指一种基于云的“即服务”解决方案，旨在促进区块链平台的实施，允许用户从中央云构建、托管和管理区块链应用程序 [[40](#ch23.xhtml#r559)]。

区块链即服务提供运营支持能力，就像 IaaS、PaaS 和 SaaS 云模型一样。BaaS 被视为区块链市场的一个重要里程碑，为分布式账本技术在商业世界的普及提供了强有力的机遇。此外，BaaS 的概念模型源自 SaaS 云计算模型 [[32](#ch23.xhtml#r551)]。

通过采用 BaaS 模型，客户可以专注于业务网络的逻辑和工作流，从幕后硬件、软件和专业知识的责任中解脱出来，并将这些责任转移给服务提供商 [[20](#ch23.xhtml#r539)]。目前市场上有多家 BaaS 服务提供商，如 IBM、Oracle 和 Microsoft，它们提供开箱即用或基于平台的 BaaS 解决方案。开箱即用的 BaaS 解决方案类似于可定制的 SaaS 解决方案，而基于平台的解决方案则允许客户自行管理和构建应用程序 [[11](#ch23.xhtml#r530)]。一般来说，大多数大型公司提供的 BaaS 实现都使用开源项目，如以太坊、Hyperledger Fabric、Quorum 和 R3 Corda [[20](#ch23.xhtml#r539)]。

### BaaS 模型如何工作？

要建立 BaaS 平台，组织需向服务提供商订阅区块链服务。区块链基础设施将按照客户需求进行设计，并由服务级别协议提供支持。该协议定义了带宽、监控、安全控制和基础设施维护的条款。根据客户的业务需求，服务提供商可基于任何分布式账本（如以太坊、Hyperledger Fabric、R3 Corda、Chain Core 或 Quorum）配置区块链网络。服务提供商随后代表客户实施必要资源并支持所需技术。因此，客户可以专注于业务，而非性能和网络问题 [[32](#ch23.xhtml#r551)]。

在许多方面，Web 托管服务提供商和 BaaS 很相似。因为网站每天都会被许多用户访问，维护和基础设施问题可以由 Web 托管服务提供商（如 Amazon Web Services (AWS)、Microsoft Azure 或 Google）处理。同样，BaaS 使客户免于管理区块链应用程序的框架 [[4](#ch23.xhtml#r523)]。

### BaaS 的优势

采用 BaaS 模型，公司无需投资在本地开发区块链平台，即可获得多项优势。这些优势将在下文讨论：

*   **成本与时间节约**：在本地实施区块链技术可能涉及大量的前期资本投资。即使投资后，如果结果不符合预期，组织可能会遭受资本损失 [[29](#ch23.xhtml#r548)]。然而，在 BaaS 模式下，由于基础设施是外包的，公司无需投资进一步扩展组织 IT 基础设施。因此，客户无需在本地构建、管理和维护平台，从而节省了时间和金钱 [[20](#ch23.xhtml#r539)]。

*   **人员成本降低**：由于实施 BaaS 架构所需的本地 IT 服务有限，客户的人员将不参与实施区块链所需的设备、电力和制冷管理。因此，招聘和培训员工的相关成本大幅降低，使组织现有的 IT 员工能够专注于业务需求。

*   **易用性**：BaaS 提供对可定制模板的快速访问，可轻松集成到现有应用程序中，无需从头构建架构 [[32](#ch23.xhtml#r551)]。因此，即使不需要任何技术专长，也能更轻松地管理和操作平台 [[27](#ch23.xhtml#r546)]。

*   **定价与客户支持**：通常，BaaS 服务提供商提供基于订阅的服务 [[32](#ch23.xhtml#r551)]。因此，客户可以根据需求扩大或缩减服务级别，降低与按使用付费模型相关的风险。此外，BaaS 提供商为客户提供全方位的支持服务，包括系统的补丁管理、监控和升级 [[20](#ch23.xhtml#r539)]。

### BaaS 面临的挑战

尽管 BaaS 在成本、人员和易用性方面具有诸多优势，但 BaaS 的采用也可能给组织带来挑战。
