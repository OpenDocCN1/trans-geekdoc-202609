
渐进式 Web 应用（PWA）是一种现代网站，它通过浏览器提供原生应用的交互体验。即使计算机未连接互联网，PWA 也能正常工作。为了实现丰富的基于 Web 的交互，PWA 使用了推送通知、缓存和稳定连接等现代 Web 功能。应用设计中的 PWA 功能需要更长的设计时间。在短时间内设计具有额外功能的应用程序可能会产生问题。原生应用可直接访问设备硬件。与原生应用不同，Web 无法完全访问设备的硬件功能。手机上可以实现硬件的完整功能，尽管由于 JavaScript 相关的限制，Web 浏览器上并不总是能使用这些功能。进一步解释说，JavaScript 是单线程程序；这意味着在执行一个操作时，必须延迟另一个操作。在这种情况下，使用 `C` 语言或其他提供同时运行多条命令能力的编程语言编写的原生代码将是可行的 [[23](#ch16.xhtml#r310)]。

任何用户的首要任务都是以最小的干扰，有效且高效地使用应用程序。应用程序必须简单、直接且易于用户理解。用户界面是使应用程序简单化的第一步，但这种简洁性并不单纯取决于用户界面。此外，应用程序必须符合用户需求，并应专注于使 DApp 独具特色的不同功能。因此，应用程序功能和设计的大多数属性应当功能精简 [[22](#ch16.xhtml#r309)]。

## 协作与安全，哪个更重要？

协作在建立和执行协作流程方面可带来显著的成本和时间节省，尤其是在参与协作的第三方之间存在信任问题时。协作流程可通过依赖受信任的第三方合作伙伴来执行 [[7](#ch16.xhtml#r294)]。

### 为安全与隐私而设计

由于区块链应用连接到没有中央权威的公共或私有网络，因此安全性和隐私性是在设计区块链应用时最基本的考量。除政府机密网络外，区块链应用像其他网络一样通常连接到互联网。因此，公司必须妥善实施安全和隐私措施。

区块链应用与其他基于互联网的应用类似，这就是为什么数据泄露被视为其主要风险之一。在区块链中，数字身份是一个有助于数据隐私的概念。使用唯一的数字身份有助于开发企业级区块链安全措施。通过使用智能合约，可以在 DApp 中增加一层额外的安全性。进一步解释说，智能合约是一种算法，负责确保如果用户请求满足某些条件，则将执行特定功能——如区块链交易、资金转账和消息触发 [[10](#ch16.xhtml#r297)]。

## 应用将保持一致性还是专业化？

一致性是指始终以一致的方式行事或表现，或始终以相似方式执行的价值 [[26](#ch16.xhtml#r313)]。一致性等同于统一性。这意味着一致的事物被认为是可靠的、井井有条的，并遵循特定的规则或假设 [[20](#ch16.xhtml#r307)]。

保持一致性是区块链技术的重要原则之一。通过进行更改或添加新功能，区块链的一致性性能可能会受到影响，从而导致利益相关者不满。因此，在设计区块链应用时，质量应保持在恒定水平，尤其是因为视觉质量仍是客户体验的主要组成部分 [[1](#ch16.xhtml#r288)]。

此外，当 DApp 中的相似元素具有标准化的外观并以相似方式运作时，可访问性和可学习性会提高。当设计保持一致时，用户可以将体验适应新情境，并快速发现新事物。这样，用户将专注于完成任务，而不是每次切换情境时都去理解产品用户界面的功能 [[17](#ch16.xhtml#r304)]。

作为一项新兴技术，区块链通过提供一致性来维护用户信任；因此，根据客户的偏好和厌恶做出设计决策，将有助于创建一个更一致、Bug 更少的应用程序 [[1](#ch16.xhtml#r288)]。对于新用户来说，界面变得更容易学习。用户困惑减少，从而减少用户错误。一致性降低设计复杂性，节省用户时间和精力。此外，一致性有助于为任何应用程序建立清晰的形象 [[26](#ch16.xhtml#r313)]。

一致性有以下几种类型：

*   **视觉一致性** 专注于使相似对象保持一致；它关乎颜色、形状、图标、字体和其他基本信息。视觉一致性对于创建强有力的视觉层级以及在各元素间建立关系也很重要 [[26](#ch16.xhtml#r313)]。DApp 中包含的元素必须极其注重细节地制作。这些元素包括排版、符号、形状等 [[20](#ch16.xhtml#r307)]。
*   **功能一致性** 确保相同的结构以相同的方式表现。用户可以预测点击按钮会发生什么并执行特定功能 [[26](#ch16.xhtml#r313)]。
*   **内部一致性** 将视觉和功能一致性结合起来，以确保应用程序易用且易学 [[20](#ch16.xhtml#r307)]。内部一致性适用于界面或品牌的各个方面，使它们在外观和行为上看起来像属于同一个系统。DApp 中新增的功能应与 DApp 中已有的功能完全兼容 [[26](#ch16.xhtml#r313)]。
*   **外部一致性** 确保用户无论在哪个平台或系统上运行应用程序，都能获得相同的体验。例如，亚马逊用户同时使用亚马逊的移动应用和 Web 平台进行购买，因此亚马逊在两个平台上提供相同的用户体验 [[20](#ch16.xhtml#r307)]。

## 支持将是中心化还是去中心化？

去中心化网络没有控制和管理整个网络的中央权威，这就是为什么利益相关者需要其他网络用户的许可才能制定或更改任何规则。然而，Facebook、Uber 和 Instagram 等主要服务仍然是中心化的，因为用户无法修改预定义的规则。例如，Facebook 拥有更改其规则的完全权力，其用户必须遵守。读者应注意，中心化系统中始终存在单点故障风险。由于不存在单点故障，区块链为利益相关者提供了高水平的安全性 [[9](#ch16.xhtml#r296)]。
