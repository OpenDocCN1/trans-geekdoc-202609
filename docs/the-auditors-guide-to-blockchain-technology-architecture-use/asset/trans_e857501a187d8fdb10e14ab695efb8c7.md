

## 共识

**共识**是各方对共享状态获得确定性的过程。适用于 Corda 的共识机制有两个方面，即验证共识和唯一性共识。

## 公证服务

**公证服务**提供事件的可靠证据，类似于传统的公证人服务。简单来说，公证人维护一份关键的映射表，记录其输入状态及其交易。公证服务无需知晓状态和交易的内容。公证服务对交易唯一需要做的就是可靠地识别它。当节点将交易发送给公证服务时，可能发生两种情况之一。如果公证人的映射表包含任意一条状态，公证人将抛出异常。如果没有任何状态输入已被认定为已使用，公证人会将每条信息添加到映射表中，并对拟议交易进行签名。此过程提供了唯一性共识。可以要求公证人验证交易，以防止攻击者提交虚假交易发起可能的 DoS 攻击。在这种情况下，只有当其智能合约接受该交易时，公证人才会将其视为常规节点处理。

## 预言机

**预言机**是关于外部世界的可信信息来源。为了确立一种货币，各方可能同意使用第三方报价。该第三方被称为预言机。预言机通过其签名有效担保交易中包含的信息。它还可应请求提供有效信息，从而使节点更容易构建经预言机批准的交易。此外，为了增加隐私，可以使用默克尔树和默克尔证明仅向预言机传输所需的最少信息。这被称为**交易撕离** [[6](#ch15.xhtml#r272), [10](#ch15.xhtml#r276)]。

## Corda 智能合约

作为 CorDApps 合约代码的一部分，智能合约逻辑确保状态转换在约定规则下是有效的。在 Corda 中，智能合约是一个纯函数，用于接受或拒绝拟议交易，并由更具体、可复用的函数组成。对于拟议交易中的每种状态类型，这些函数中的一个都将针对每笔拟议交易执行，所有各方有义务同意——根据每种状态的规则——拟议交易是允许的。因此，只有当包含的状态在所有合约代码上达成一致时，交易才有效。交易提议者负责生成满足每个包含的状态对象约束条件的交易。

Corda 使用一种名为 **Kotlin** 的编程语言来编写其智能合约。Kotlin 是一种通用的、静态类型的编程语言，具有跨平台实现和类型推断功能。Kotlin 旨在完全兼容 Java，且基于 JVM 的 Kotlin 标准库版本即 Java 类库。同时，类型推断允许语法更加简洁。它主要为 JVM 设计，但也可编译为 JavaScript 或原生代码。得益于 JVM（Java 虚拟机）丰富的现有库和广泛的专业知识基础，以及行业标准的复用，金融机构能够在合约中复用其现有代码。标准化字节码使用户能够根据偏好，在合约语言设计中创新或复用知名语言 [[6](#ch15.xhtml#r272), [10](#ch15.xhtml#r276)]。

## Corda 的共识机制

Corda 中的共识有两个方面，如下所示：

*   共识的**交易有效性**方面确保各方能够确定拟议的定义输出状态的更新交易是有效的，方法是确保相关合约代码（必须是确定性的）通过拥有所有必需签名而成功验证。
*   共识的**交易唯一性**方面确保交易参与者能够确定正在考虑的交易是交易中输入的所有状态的唯一消费者。此外，它还确保不存在先前已达成一致的、使用了相同任何状态的其他交易。

然而，两笔有效交易可能同时存在，因此参与者需要一种方法来选择优先考虑哪笔交易。为此，在一组相互不信任的公证人参与者中需要一个观察者。许多人可以在同一网络中参与，同时拥有不同的特征和协议，这是 Corda 设计的一个独特功能。单个服务可以由许多相互不信任的节点通过拜占庭容错算法协调组成。

重要的是要注意，此类唯一性服务只能确认之前的状态是否被消耗；在这种情况下，它们不应证明交易的有效性 [[4](#ch15.xhtml#r270), [6](#ch15.xhtml#r272), [10](#ch15.xhtml#r276)]。

## Corda 用例

随着区块链行业的快速扩展，企业对区块链在性能、安全性和用户友好性方面有更高的期望。Corda 是被认为能满足所有这些需求的平台之一。下一节讨论 Corda 的三个用例。所有这些用例都展示了 Corda 解决各种挑战的能力。

一个著名的 Corda 应用是在**医疗保健行业**。医疗保健行业认识到对区块链的需求，因为即使是最好的医疗系统也可能变得碎片化。欺诈增加、理赔处理延迟和患者护理不令人满意都是碎片化的后果。

医疗保健系统已将使用电子健康记录（EHR）作为重中之重。Corda 区块链将允许系统之间相互通信，并提供全面的患者健康历史，而无需第三方验证服务。医疗保健可将每条记录保存在带时间戳、可审计且不可篡改的账本中。

Corda 也常用于**建筑业务**，因为其身份识别、隐私和工作流特性使其成为此类操作的理想选择。在建筑领域，承包商定期将工作转包给分包商。Corda 调整网络上数据分布的能力对于创建最适合行业现有参与者的区块链解决方案至关重要。Corda 允许房地产开发商和承包商保存与其达成协议从事各项工作的对手方记录，并允许及时补偿这些方。Corda 还允许项目成员以统一且易访问的方式查看项目进度和达成的里程碑。此外，Corda 的状态和合约框架有助于定义共享规则和数据结构，以及这些数据结构将如何随时间演变。这将有助于防止参与者产生分歧和/或犯错。即使参与者通过同一网络连接，Corda 的按需知情数据分发也能防止其他方发现项目的具体细节 [[18](#ch15.xhtml#r284)]。

Corda 区块链的分布式账本和透明度还可以帮助**金融公司**高效可靠地获取最新的消费者数据。因此，组织绩效、非自动化数据收集、运营费用和处理时间均有所降低，而机构信任度得到提高。交易终局性、可扩展性、隐私、法律认可的参与方、开发人员生产力和企业集成是 Corda 为金融机构提供的一些优势。
