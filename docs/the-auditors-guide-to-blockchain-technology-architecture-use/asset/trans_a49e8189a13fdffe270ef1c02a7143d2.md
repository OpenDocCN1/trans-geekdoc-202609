

# 供应链风险与欺诈

供应链风险（SCR）可定义为可能导致品牌受损、重大资金损失、数据和安全漏洞，并最终导致企业倒闭的潜在负面未来事件 [[6](#ch14.xhtml#r238)]。欺诈始终是故意的，不能被归类为错误、巧合或不幸，因为欺诈行为会为实施者带来经济利益。由于大多数供应链是涉及大量利益相关者、流程和技术的复杂、多阶段、多层面的系统，管理其风险也复杂且充满挑战。供应链威胁不仅源于直接供应商；供应链沿线的各种承包商和分包商也会给其流程带来风险。根据注册舞弊审查师协会（ACFE）的数据，七分之一遭遇欺诈的企业将永远无法完全恢复。根据德勤的一项调查，组织可能直到遭受重大财务损失时才会注意到自己已成为供应链欺诈的受害者。同一调查还显示，供应链取证与分析的投入从 2014 年的 25% 增加到了 2017 年的 35%。德勤还提到，供应链取证与分析技术的使用增加，清楚地表明组织已将供应链欺诈视为对企业最重大的威胁之一 [[22](#ch14.xhtml#r254)]。

## 供应链中的常见欺诈计划

### 假冒商品

假冒商品是一个严重的全球性经济问题，近年来急剧增加。通常情况下，假冒商品由质量较低的零部件、原材料制成，工艺粗糙，旨在以低于原品牌的价格出售。在世界大多数地区，假冒被视为非法行为；然而，由于各国法律和执法政策各异，这一现象依然猖獗。因此，在许多方面，销售假冒商品比贩毒风险更低。在发展中国家购买假冒商品的现象与美国、欧洲和澳大利亚等发达国家一样普遍。仅在 2013 年，美国国土安全部就查获了价值超过 17 亿美元的假冒商品。在发达国家，消费者购买假冒商品是为了在其社会阶层中树立富裕形象 [[5](#ch14.xhtml#r237)]。

### 虚假账单

虚假账单，也称为不当账单或余额账单，是指开具欺诈性发票或向消费者多收商品或服务费用的行为。受虚假账单计划影响的主要领域包括医疗保健行业、律师服务和食品供应链。根据 2020 年发布的一篇新闻文章，美国司法部在 2019 年因针对政府的欺诈性和虚假索赔获得了超过 30 亿美元的和解金。在这 30 亿美元的总和解金中，26 亿美元来自各类医院、药房、医疗器械供应商、医生和实验室实施的医疗保健欺诈。这些医疗欺诈涉及 Medicaid（医疗补助）、Medicare（医疗保障）或 Tricare（军人医疗计划）等联邦医疗项目，导致医疗成本上升，并使患者健康面临风险 [[11](#ch14.xhtml#r243)]。

### 资产挪用

将组织或客户的资产用于个人用途或谋取私利可视为资产挪用。例如，将办公用品带回家用或用于副业属于资产挪用，将公司车辆用于个人交通或其他未经授权的用途也是如此。会计部门人员有时会犯资产挪用欺诈，因为他们通常有权接触组织资金，且处于更有利的位置实施财务欺诈并掩盖踪迹——至少在短期内如此。根据*舞弊三角理论*，机会、动机和合理化是导致职业欺诈的三大主要因素。进一步解释：掌握大量企业库存现金或能轻松个人接触其他公司资产可视为机会；组织与员工关系紧张或员工个人财务问题可导致动机；最后，自我合理化的过程帮助实施者为其欺诈行为辩解，以逃避愧疚或悔恨 [[16](#ch14.xhtml#r248)]。

## 食品欺诈

在食品行业中，欺骗消费者、供应商、零售商和制造商，或操纵配料的过程可视为食品欺诈。食品欺诈可能源于操纵制造或加工标准，或操纵所需的食品安全协议，以增加利润。

除了前文讨论的职业欺诈计划外，以下是一些常见的食品欺诈计划示例：

*   **食品替换** 涉及更改或降低食品商品的质量或数量，目前是食品行业最大的问题之一。在一起案例中，爱尔兰食品安全局（FSIA）于 2012 年发现马肉被以牛肉标签出售。FSIA 从都柏林市中心的多家杂货店、汉堡店和餐馆取样，并在私人实验室对取样肉类进行检测。检测证明样本中存在猪、牛和马的 DNA，表明牛肉中混入了马肉 [[23](#ch14.xhtml#r255)]。

*   **掺假或经济动机掺假（EMA）** 被描述为“在产品中故意替代或添加其他物质，以提高产品的表观价值或降低其生产成本，从而获取经济利益”。使用未经批准的增强剂、廉价配料、隐瞒损坏或未披露真实配料也属于食品掺假。食品掺假的例子有很多，例如在牛奶中掺水、在红辣椒粉中掺砖粉、在植物油中添加奶脂或在姜黄粉中掺铬酸铅（因颜色相同） [[18](#ch14.xhtml#r250)]。

*   **虚假宣称** 可定义为在食品标签上印制误导性信息。如今，杂货店、美食广场、餐馆等场所有数百万种产品，消费者根据标签信息信任各类食品。已有大量事件报道，组织因在食品标签上提供虚假营养信息而失去客户信任，例如宣称某食品不含防腐剂，但产品实际含有防腐剂甚至危险化学品。美国食品药品监督管理局（FDA）于 2012 年起诉美国冰淇淋制造商 *Ben & Jerry*，因其产品标签标注“全天然”却含有人工香料。另一案例中，*Cadbury Schweppes* 因宣称软饮料 *7UP* 为“天然”而被 FDA 起诉，因该产品含有高果糖玉米糖浆（HFCS）。另一案例涉及婴儿食品制造商 *Gerber* 的包装水果标签宣称“全真果、全天然成分”，而该机构实际使用玉米糖浆代替真糖 [[15](#ch14.xhtml#r247)]。
