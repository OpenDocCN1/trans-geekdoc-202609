
## 区块链实施考量

*   **培训考量**：在部署区块链解决方案之前，员工必须接受充分培训以使用适当的区块链框架。管理层应优先考虑从实施团队向员工的知识转移。这确保了新工作流投入使用后不会出现重大问题。有时，培训成本和流程未得到充分考虑，这反过来会减缓对变革的适应 [\[27\]](#ch19.xhtml#r418)。

*   **易用性缺失**：如果提议的区块链解决方案不充分且与当前整体工作流不兼容，它很可能会产生易用性差距，从而给最终用户带来新的挑战。如前所述，此类问题可能导致对变革的抵制或新技术的严重使用不足。此处的最佳建议是确保在实施的每个阶段都仔细考虑最终用户的顾虑、反馈和建议。

*   **数据隐私**：在实施期间和实施后，确保数据不暴露于潜在泄露风险中是一项重大责任。利益相关者可能会表达担忧，例如实施区块链等新 IT 解决方案导致网络安全威胁的可能性增加。此类担忧需要在规划和实施阶段得到充分讨论和解决。

*   **数据迁移**：采用区块链等新解决方案时，一个主要关注点是数据迁移能否成功。数据迁移是一项全面且细致的任务，涉及将海量数据（包括纸质数据）从遗留系统或基础设施迁移到基于区块链的系统。因此，数据迁移阶段需要周密的规划和审慎的方法。

*   **技术资源有限**：技术资源限制是 IT 预算和组织规模的函数。缺乏技术资源意味着基于区块链的技术实施可能会受到限制。这些技术资源由负责区块链实施的团队以及实施工具组成。由于区块链是一项新兴技术，并非所有组织都拥有能够成功实施区块链的内部团队。大多数情况下，这项任务通常涉及将实施过程外包给第三方供应商。

*   **互操作性**：在区块链解决方案的实施过程中，应仔细考虑互操作性问题，因为该过程涉及跨多个平台的信息流，并结合其他工具和技术。区块链解决方案应能轻松适应这些变化，以确保日常业务无故障运行 [\[27\]](#ch19.xhtml#r418)。

当将现有的传统系统迁移到基于区块链的基础设施时，应通过适当的规划制定全面、系统的方法，以确保平稳过渡。这就是为什么我们建议使用公认的实施方法，例如下一节概述的方法。所有参与方之间的透明度和沟通也很重要。这确保了所有参与方对项目的全面承诺。

## 使用 COBIT 2019 方法进行区块链实施

在企业内根据行业标准实施解决方案时，建立和维护企业信息与技术治理（EGIT）的适当环境至关重要。EGIT 实施需要在管理层的正确指导、支持和监督下进行良好的治理和管理。利益相关者不当且不充分的支持可能会因缺乏问责制、责任和所有权的政策和程序而使 EGIT 计划脱轨。因此，由于上一节讨论的一些因素，这些改进可能无法成为既定的业务实践。因此，这些改进将缺乏角色和职责、持续运营以及符合监控等管理结构参数 [\[28\]](#ch19.xhtml#r419)。

**COBIT 2019 实施的必要性**：《COBIT 2019 实施指南》确立了创建适当环境以促进 EGIT 实施的必要性，将其作为企业整体治理方法的一部分。适当的治理结构应由高层管理驱动。无论计划的性质如何——大规模或小规模——结构、程序、流程和实践都必须符合良好的治理原则，以协助高层管理确保更好的决策和授权模型，从而做出明智的决策。

下文讨论了在企业中首次实施基于区块链的基础设施的 COBIT 2019 方法。

### 三层实施方法

COBIT 2019 生命周期有三个组成部分：**项目管理**、**变革赋能**和**持续改进**。这三个组成部分不是孤立的，而是相互依赖且并发的。每个组成部分都有助于为上述 EGIT 计划创建适当的环境。一旦项目或改进计划成功融入企业的日常运营，该周期即可完成或退出。

项目管理包含与区块链实施相关的任务。它包括定义挑战和机遇、定义实施路线图、开发和执行区块链项目以及实现和审查其有效性等任务。

变革赋能是指一种整体且有条理的过程，旨在确保利益相关者做好准备并致力于将当前状态转变为未来的期望状态。它包含以下活动：（a）评估拟议变革对企业环境（包括员工和利益相关者）的影响；（b）定义未来状态愿景；（c）构建变革响应计划；以及（d）衡量因改进计划而产生的变革进度。

持续改进方法包含旨在改进企业产品、服务和流程的持续活动。这些活动是连续的，包括识别变革需求、评估当前和目标状态、构建改进、监控以及在整个实施周期中评估改进等任务 [\[28\]](#ch19.xhtml#r419)（**图 11.3**）。
