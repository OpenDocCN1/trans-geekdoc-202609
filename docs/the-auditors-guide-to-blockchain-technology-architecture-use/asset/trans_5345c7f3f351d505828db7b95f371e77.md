

## 私有与开放平台

私有与开放平台允许所有人读取数据，但只有获许可的个人可以在私有与开放区块链上写入数据。它通常用于供应链场景，其中只有供应商可以将供应状态写入区块链，而任何私有区块链用户都可以监控存储在区块链上的状态和数据。

## 私有与封闭平台

私有与封闭平台仅授予认证成员区块链数据的读写权限，因为其中可能包含私密或敏感信息，例如健康相关、金融或敏感政府记录。

表 2.1 总结了各类区块链的读写权限。

### 表 2.1 区块链类型间的读写权限

| 公有与开放 | 公有与封闭 |
| --- | --- |
| 所有人可读取数据。所有人可写入数据。示例：加密货币平台、博彩或视频游戏。 | 仅允许的参与者可读取数据。所有人可写入数据。示例：投票平台/记录或举报平台。 |

| 私有与开放 | 私有与封闭 |
| --- | --- |
| 所有人可读取数据。仅管理员可写入数据。示例：供应链监控，如沃尔玛的 DL Asset Track。 | 仅允许的参与者可读取数据。仅允许的参与者可写入数据。示例：军事或执法用例及金融记录。 |

## 共识

简单来说，“共识”是指“普遍达成的协议”。与其通用含义相似，区块链的共识机制是整个系统的核心。共识驱动区块链应用基础设施，并管理处理节点间交易的信任以及整体区块链技术 [[10]](#ch10.xhtml#r053)，[[79]](#ch10.xhtml#r122)。它帮助处理节点维护区块链交易数据的一致性，并确保区块链副本包含相同的信息 [[38]](#ch10.xhtml#r081)。

### 共识算法

区块链网络采用多种算法。这些算法决定了区块链的速度、可靠性和可扩展性。这些算法包括但不限于以下内容：

#### 工作量证明

**工作量证明** 是第一个，也是所有共识模型中最安全、最受信任的。它稳定且具有确保交易链不间断的强大能力。工作量证明的概念简单来说是：在处理节点能将交易添加到区块链网络之前，该节点必须证明它已经完成了一些工作，这主要包括利用算力解决数学难题。解决这些难题始终很困难，但验证其他处理节点完成的工作相对容易。PoW 依赖于在提出接受值之前对已消耗资源的证明 [[15]](#ch10.xhtml#r058)。工作量证明是一个难以解决的问题，因为如前所述，它需要解决一个数学难题，这在图 2.1 中有进一步解释。简而言之，PoW 类似于试图用一盒各式钥匙中的钥匙打开一扇锁着的门；然而，一旦通过试错过程找到了能开门的钥匙，其他人就很容易确认开锁所需的钥匙。

![Figure 2.1 Illustration explaining a nonce derivation for PoW.](html/images/9781032078243_C002_001.jpg)

**图 2.1** 解释 PoW 的 nonce 派生过程。

基于哈希要求派生 nonce 值是工作量证明共识算法的基础。进一步解释，nonce 应产生一个在开头带有规定数量零的哈希输出（例如：四个零）。工作的难度在于派生 nonce 值有多难，而验证则相对容易，因为结果透明且易于被其他节点验证。然而，这一过程并不会让区块在添加到区块链后变得更安全。该算法的一个主要缺点是能源消耗率增加，对环境和交易验证时间产生不利影响。区块链网络中的这一验证过程需要多台服务器验证区块链上的交易；例如，进行支付的用户和接收支付的用户。据称，验证交易过程中的高能耗高达许多小国的总能耗 [[83]](#ch10.xhtml#r126)。该算法在小型公有区块链中也极易受到攻击 [[50]](#ch10.xhtml#r093)。

图 2.1 展示了 nonce 与生成哈希之间的直接关系。可以看出，虽然找到正确的 nonce 非常困难（解谜的唯一策略是试错过程），但只需输入派生出的 nonce 即可轻松确认和验证哈希，只需确认所需的哈希结果（要求前四位数字为零）。

#### 权益证明

**权益证明** 是指一种负责证明节点在系统中拥有足够权益的机制。权益证明算法的创建是为了解决工作量证明算法的一些感知不足。权益证明算法通过要求验证者（矿工）质押加密货币作为参与前提，然后允许验证者向区块链网络添加区块以赚取交易费来运作。如果不诚实的验证者将无效交易添加到区块链网络，其质押的权益将作为惩罚而损失。权益证明作为工作量证明算法的一种替代方案 [[79]](#ch10.xhtml#r122)。与工作量证明算法不同，PoS 的能源效率显著更高。然而，持币较少的人可能无法频繁参与区块创建过程。换句话说，在网络中持有的权益越高，被选中在网络中验证区块的概率就越高 [[15]](#ch10.xhtml#r058)。

#### 委托权益证明

**委托权益证明** 算法是权益证明算法的进阶形式。详细来说，持有代币的参与者可以为“生产者”投票，得票最高的生产者将被允许生产区块。委托权益证明比权益证明更具优势，因为它确保了参与者与生产者之间的关注点分离，并确保网络内的适当治理 [[50]](#ch10.xhtml#r093)。委托权益证明高度依赖于区块链投票社区中的活跃用户 [[79]](#ch10.xhtml#r122)。

#### 燃烧证明

**燃烧证明** 常用于启动新项目时，以维持初始代币分配的公平性。燃烧证明是工作量证明算法的一种替代方案，但不浪费能源。将原生货币或另一条区块链的货币发送到一个钱包地址。然后区块链矿工可以获得其所在区块链等量的货币 [[27]](#ch10.xhtml#r070)。

#### 经过时间证明

**经过时间证明** 算法利用可信执行环境，通过保证的等待时间提供随机性和安全性。节点根据自上次获得创建区块机会以来等待了多久来被允许验证交易 [[79]](#ch10.xhtml#r122)。经过时间证明依赖于一种称为软件保护扩展 (SGX) 的专用硬件，它允许应用程序在受保护的运行时环境中运行可信代码。它支持用户级代码分配飞地（内存私有区域），并保护这些代码免受高权限进程的侵害。
