
# 非对称密码学

非对称密码学也称为公钥密码学。这种革命性的密码学思想由 Whitfield Diffie 和 Martin Hellman 于 20 世纪 70 年代提出。Diffie 和 Hellman 认为，可能存在开发一种密码系统的可能性，其中包含两个不同的密钥。公钥用于明文的加密，而私钥用于将密文解密为明文 [[73](#ch10.xhtml#r116)]。在这种技术中，发送方（Alice）使用接收方（Bob）的公钥加密秘密消息，接收方使用其私钥解密消息。公钥可以为所有人所知，但私钥仅为接收方所知，并需要受到保护。密钥通过数字签名进行认证。只要私钥保持完好，非对称密码学既方便又提供更高的安全性。Diffie-Hellman 密钥交换是最流行的密钥分发方法之一 [[58](#ch10.xhtml#r101)]。

## Rivest Adi Adleman (RSA) 算法

`Rivest Adi Adleman (RSA)` 算法由 Ron Rivest、Adi Shamir 和 Leonard Adleman 于 1978 年发明。RSA 作为一种密码算法被引入，取代了安全性较低的美国国家标准局（NBS）算法。RSA 算法基于因式分解问题，该问题在于将两个大素数的乘积进行因式分解在实际中具有困难性 [[58](#ch10.xhtml#r101)]。也使用不同的加密密钥；即公钥（非对称密钥）和私钥（对称密钥）。RSA 算法涉及三个步骤，即密钥生成、加密和解密。

## Elgamal 加密

`Elgamal` 加密由 Taher Elgamal 于 1984 年开发。非对称密钥加密是基于 Diffie-Hellman 密钥交换原理建立的。与 Diffie-Hellman 算法不同，Elgamal 密码系统是一个完整的加密和解密系统，依赖于离散对数问题。Elgamal 算法由三个组件组成：密钥生成器、加密和解密 [[58](#ch10.xhtml#r101)]。

## 背包算法

`Knapsack algorithm` 是最早的公钥密码系统之一，由 Ralph Merkle 和 Martin Hellman 于 1978 年发明。在背包密码系统中，也执行三个过程：密钥生成、加密和解密。一些公钥密码系统是基于背包（或子集和）问题提出的 [[58](#ch10.xhtml#r101)]。由于其 NP（非确定性多项式时间）完全性的性质以及加密和解密过程的高速度，背包密码系统曾被认为是最有前途的密码系统之一。然而，大多数基于背包的密码系统被认为是不安全的，因为这些密码系统中的加密函数本质上是线性的。

## 混合密码学

非对称密码学有一个主要缺点；它比对称密码系统慢得多。因此，非对称密码系统主要用于加密少量数据，例如信用卡号。幸运的是，有一种更好的方法可以结合对称和非对称密码学，以获得两者的优势。所使用的技术称为混合密码学。假设发送方（Alice）想要在没有预先共享的密钥的情况下加密并发送一条长消息给接收方（Bob）。Alice 使用一种（快速的）对称密码系统来选择一个随机密钥并加密明文。然后 Alice 使用 Bob 的公钥加密这个密钥。Alice 将密文和加密后的密钥发送给 Bob。Bob 使用他的私有解密密钥解密该密钥，然后使用解密后的密钥解密密文。非对称密钥用于加密短密钥，而速度快得多的对称密钥用于加密较长的明文。因此，混合密码学（几乎）实现了对称密钥密码学的效率。在发送方和接收方之间没有预定密钥的情况下，可以使用混合密码学 [[73](#ch10.xhtml#r116)]。
