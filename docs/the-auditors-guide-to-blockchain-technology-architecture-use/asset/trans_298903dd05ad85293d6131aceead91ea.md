

# 区块链应用设计步骤

1.  **识别问题**：贵组织是否存在可用区块链应用解决的问题？请通过简述问题来构建问题陈述，并描述该问题如何通过区块链应用解决。请注意，问题陈述不必仅用一句话描述，但一个简短的段落足以构建有效的问题陈述。以下视频将为感兴趣的读者提供关于问题陈述制定的更多信息。标题：*Identify the Problem* [https://www.youtube.com/watch?v=FPfEciCFtPc&ab_channel=GreggU](https://www.youtube.com)

2.  **梳理设计考量**：阅读章节 *Blockchain Design Guiding Principles and Considerations*（区块链设计指导原则与考量），列出与区块链应用设计相关的考量因素。在贵企业中，讨论的哪些考量因素应优先考虑？

3.  **定义用户角色与故事**：承接上述步骤，开发用户角色和用户故事，作为区块链应用设计的第一步。

4.  **制定需求**：接下来，尝试在团队环境中制定区块链应用设计的功能性和技术性需求。

5.  **定义任务**：定义协助满足技术需求的任务。

6.  **评估设计方法**：评估本章讨论的设计方法。哪一种（或哪几种）最适合已识别的用例？

7.  **参考案例研究**：参考区块链案例研究，以更好地理解组织对区块链应用的需求。
