

# DL 的治理

DL 治理的一个关键方面是由谁决定其运作方式。BaaS 由多方组成——包括服务提供商和租户——每一方都有不同的利益和激励。类似于 BaaS 服务的 SaaS 服务涉及 BaaS 提供商在建立 DLT 基础设施方面发挥更大的作用。BaaS 租户可能需要考虑提供商是否可以单方面更改软件；客户复刻提供商软件以供重用的能力；租户、提供商或其他参与者如何更改账本；最后，提供商是否提供运行在另一个社区运行的区块链之上的分布式账本。一般来说，当租户的情况类似于 PaaS [[30]](#ch23.xhtml#r549) 时，他们将对其 DLT 基础设施拥有更大的控制权。

# 总结与结论

本章介绍了云计算概念，旨在使读者能够更深入地了解区块链即服务的云基础设施。IBM、微软、亚马逊、SAP 和甲骨文等许多大型实体为组织提供了在云端开发区块链应用程序的能力。因此，部署 BaaS 不需要大量的技术知识和基础设施，并且随着业务增长可实现可扩展性。简要讨论了金融和供应链领域的几个业务用例，以帮助读者更好地理解某些商业 BaaS 平台的底层架构。

# 核心概念

*   云计算描述了互联网及其基础设施的使用。云计算包含五个关键属性、四种部署模型和三种服务模型。
*   云计算的五个基本特征是——按需服务、广泛的网络访问、资源池化、快速弹性和可度量服务。云系统是一种按使用付费的系统。云计算使客户能够根据需求自动快速地向上或向下扩展。广泛的网络访问使云客户能够在不遇到带宽瓶颈的情况下使用云服务。资源池化使云能够通过大量的资本投入和来自庞大客户群的收入保持财务上的可行性。
*   云部署模型可分为四类——公有云、私有云、混合云和社区云模型。公有云是指所有主要资源均可供愿意为服务付费的公众使用的云，而私有云则供某个组织专用。混合云是私有云和公有云的混合。社区云或亲和云平台通常由具有相似业务目标的社区群体共享。
*   根据客户需求，云计算提供基础设施即服务、平台即服务和软件即服务。提供 IaaS 的云服务提供商提供硬件相关资源，客户最终负责逻辑资源。PaaS 模型为客户构建应用程序提供平台。SaaS 模型提供所有 IaaS 和 PaaS 功能，以及完全或部分创建的特定软件。
*   云服务提供商、客户、用户、访问安全代理和监管机构在云计算中发挥着至关重要的作用。云计算解决方案的优势包括节省成本、减少前期 IT 开支、提供防止数据丢失的备份服务，以及其对多租户的支持使得在多个用户之间共享服务器和应用程序变得容易。
*   BaaS 概念指的是一种基于云的“即服务”解决方案，旨在促进区块链平台的实施，允许用户从中央云托管和管理区块链应用程序。
*   组织可以通过订阅服务提供商基于任何分布式账本技术（如以太坊、Hyperledger Fabric、R3 Corda、Chain Core 或 Quorum）提供的区块链服务来建立 BaaS 平台。应建立服务级别协议，以确保区块链基础设施按照客户的规格进行开发。
*   BaaS 提供多项优势，包括节省成本和时间、降低人员成本、易用性、定价和客户支持。隐私和数据合规性、选项有限以及资源匮乏是 BaaS 目前面临的一些挑战。
*   区块链即服务架构分为四层——应用层、中间件、框架和基础设施层。BaaS 服务通常实现崩溃容错 (CFT) 或拜占庭容错 (BFT) 共识机制。
*   目前市场上有多家 BaaS 提供商。一些可与企业集成的最流行的商业 BaaS 提供商包括 IBM BaaS、甲骨文、微软 Azure BaaS、亚马逊 AWS BaaS、阿里巴巴、埃森哲、百度和华为。选择 BaaS 服务提供商时，应考虑以下因素：过往经验、易用性、质量承诺、集成和流程控制。
*   区块链技术研究人员正在提出多个非商业 BaaS 平台，即功能型 BaaS、NutBaaS、全谱 BaaS、新型 BaaS、统一 BaaS 和公共 BaaS，以保持区块链的不可篡改性、去中心化、持久性和可审计性等关键属性。
*   BaaS 治理指导参与 BaaS 平台的参与者。涉及的主要有两类参与方——许可链或私有链以及链下控制。
