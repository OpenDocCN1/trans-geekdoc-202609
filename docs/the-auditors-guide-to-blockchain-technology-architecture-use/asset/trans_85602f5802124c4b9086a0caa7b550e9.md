

## 云计算部署模型

*   **公有云**：公有云平台是云计算服务最常见的形式。如前所述，所有资源（如软件、硬件、人员和设施）均由云服务供应商管理和拥有，并提供给任何愿意支付这些服务费用的人；因此得名“公有云”。在公有云供应商中，Amazon Web Services、Google 和 IBM 就是几个例子。

*   **私有云**：与传统 IT 环境类似，私有云服务由各个组织拥有和运营，供该组织的客户和/或员工专用。远程访问 Web 连接使得此类平台也可供经批准的外部用户访问。与公有云服务相比，私有云平台通常具有更高的安全措施，因为此类平台仅供组织内部的可信用户访问。使用私有模型的主要优势包括更高的数据隐私和安全性。然而，组织需要花费资金购买实施私有云所需的软件和设备。私有云应用的一个常见例子是内部托管的 SharePoint 站点。

*   **混合云**：混合云由公有云和私有云计算模型的组合构成。该模型的主要优势包括成本效益、更高的安全性和更高的部署灵活性。北美医疗保健行业是有效混合云的一个很好的例子，其中私有云解决方案提供安全性。相比之下，连接到医疗机构、保险提供商和其他相关方的公有云可以提供对潜在救命医疗数据的及时访问 [[37](#ch23.xhtml#r556)]。

*   **社区云**：也称为“亲和云”。采用社区模型时，云平台由具有相似业务目标的亲和群体共享。服务通常主要由亲和群体内部人员或第三方管理。使用社区云模型的主要优势是较小的资本投入。主要缺点是其共享资源。社区云的一个常见实例是游戏社区，如 PlayStation Network [[23](#ch23.xhtml#r542), [37](#ch23.xhtml#r556)]。

## 云计算服务模型

除了部署模型外，云计算还通过三种不同的服务模型提供——基础设施即服务 (IaaS)、平台即服务 (PaaS) 和软件即服务 (SaaS)——以满足组织内特定的业务挑战。所有三种模型均根据按使用付费策略部署 [[35](#ch23.xhtml#r554)]。

*   **基础设施即服务 (IaaS)**：IaaS 代表无需物理访问硬件即可托管的数字服务器实例。作为一种即用即付系统，IaaS 平台提供包括存储和虚拟服务器在内的硬件相关资源。在其服务器实例内，授予客户高级管理权限，以及设置其网络安全级别的能力。IaaS 提供使用最新技术的主要优势，从而为用户提供更快的服务访问速度。

*   **平台即服务 (PaaS)**：PaaS 模型提供通过 Web 开发应用程序所需的基础设施和服务 [[35](#ch23.xhtml#r554)]。由于开发人员不必预先确定可扩展性需求，PaaS 模型为应用程序开发人员提供了很大的灵活性和生产力。在互联网上，PaaS 为低成本、可靠和大规模的应用程序增长提供了支持。除了优势之外，PaaS 云技术的主要缺点是用户会经历对特定 PaaS 平台的“锁定”，这使得平台过渡和变更有时变得非常具有挑战性 [[38](#ch23.xhtml#r557)]。

*   **软件即服务 (SaaS)**：SaaS 类型提供所有 IaaS 和 PaaS 功能，以及完全或部分创建的特定软件。SaaS 主要以 Web 应用程序的形式提供，并包含一些 Web 存储或与非远程应用程序的其他网络连接。由于软件和其他组件托管在服务提供商的位置，用户可以通过 Web 浏览器访问软件服务 [[35](#ch23.xhtml#r554)]。

*   **共享责任**：在云计算中，客户和云服务提供商在物理安全、数据安全和控制方面共享责任。共享责任通常被称为客户和提供商之间的“职责分离”，以根据服务类型或部署模型保护服务 [[23](#ch23.xhtml#r542)]。

[表 15.1](#ch23.xhtml#t56) 概述了基于各种云部署方案的客户与云服务提供商之间的共享责任。

### 共享责任矩阵

| 责任 | 基础设施即服务 (IaaS) | 平台即服务 (PaaS) | 软件即服务 (SaaS) |
| --- | --- | --- | --- |
| 治理、风险与合规 | 客户 | 客户 | 客户 |
| 数据安全 | 客户 | 客户 | 客户 |
| 应用安全 | 客户 | 客户 | 客户/服务提供商 |
| 平台安全 | 客户 | 客户/服务提供商 | 服务提供商 |
| 基础设施安全 | 客户/服务提供商 | 服务提供商 | 服务提供商 |
| 物理安全 | 服务提供商 | 服务提供商 | 服务提供商 |

*   **企业/客户责任**：云客户始终最终负责数据保护和账户访问控制 [[23](#ch23.xhtml#r542)]。满足合规标准的要求对云服务提供商来说通常是一个挑战，因为他们必须遵守多项 IT 流程管理要求。重要的是要重申，云客户始终最终对适用的合规授令负责 [[24](#ch23.xhtml#r543)]。

*   **云服务责任 (CSR)**：无论服务类型如何，云提供商始终负责保护数据中心所在的物理设施 [[23](#ch23.xhtml#r542)]。

*   **按服务类型划分的责任**：监控和审计对于确保平台安全非常重要。IaaS 服务提供商仅管理设施；因此，客户负责实施必要的保护措施，以保护应用程序、虚拟机和数据。

尽管 PaaS 模型构建在 IaaS 模型之上，但云服务提供商负责操作系统 (OS) 维护，而客户负责数据和应用安全。在 PaaS 和 SaaS 模型中，当客户更新其安装的软件时，服务提供商共同承担更新硬件和确保适用安全控制的责任 [[23](#ch23.xhtml#r542), [24](#ch23.xhtml#r543)]。

## 云计算角色与职责

此外，了解云计算的各种属性和模型是必要的；但了解其主要角色和职责同样必要，如下所述 [[21](#ch23.xhtml#r540)]。

*   **云服务提供商 (CSPs)**：云提供商是提供云服务的供应商。如前所述，此类实体拥有云计算数据中心，并管理其各种硬件、软件和人力资源，此外还负责监控服务提供和保障平台安全。云数据中心使云提供商能够构建、配置、部署和运营云服务 [[21](#ch23.xhtml#r540)]。
