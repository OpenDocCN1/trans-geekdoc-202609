

## 流行的加密货币交易所

以下部分简要讨论了几个较受欢迎的加密货币交易所。

*   **Bittrex** 是一个加密货币交易平台。总部位于瑞士苏黎世，Bittrex 旨在提供一种安全的加密货币交换方式。

*   **Poloniex** 是由 Tristan D’Agosta 于 2014 年建立的加密货币交易平台。总部位于特拉华州，Poloniex 曾在 2014 年遭遇黑客攻击。平台上托管的比特币被黑客窃取。据估计，12.5% 的比特币供应量被盗。为避免未来发生此类情况，Poloniex 已转向冷存储以保管资金。此外，它要求用户使用双因素认证 [[6](#ch11.xhtml#r133)]。按日交易量计算，Poloniex 目前是最大的山寨币交易所 [[11](#ch11.xhtml#r138)]。

*   **Kraken** 自 2011 年以来一直是最古老、最大的比特币交易平台。它通过旨在通过增加加密货币采用来提供金融自由而声名鹊起。Kraken 提供的 API 具有通用性。其 API 的作用是在无需共享登录信息的情况下提供对 Kraken 账户的访问。这些 API 仅提供有限且受控的访问权限，通常由经验丰富的交易者用于其机器人与 Kraken 账户通信 [[39](#ch11.xhtml#r166)]。

*   **Coinbase** 的目标是根据公司说法，自 2012 年成立以来，开发一个高效、公平且可访问的透明金融系统。其独特功能包括可以说是最受信任，以及最易于使用。Coinbase 触达超过 7000 家机构，包括超过 4300 万经过验证的用户，以及在 100 多个国家拥有超过 115,000 个生态系统合作伙伴。Coinbase 于 2021 年上市 [[2](#ch11.xhtml#r129)]。

*   **Bitfinex** 的独特功能包括点对点融资、保证金交易和场外交易（OTC）选项。Bitfinex 拥有自己的代币 UNUS SED LEO，提供多种福利，包括 P2P 借贷费用减免以及交易手续费折扣。它提供最先进的数字资产交易服务和全球流动性提供商 [[1](#ch11.xhtml#r128)]。

*   **Binance** 于 2017 年在中国成立，但后来迁至开曼群岛。2021 年，按日交易量计算，Binance 被视为世界上最大的加密货币交易所。Binance 由高频交易软件创造者 Changpeng Zhao 创立。撰写本文时，Binance 正接受美国司法部和国税局的调查 [[35](#ch11.xhtml#r162)]。

## 总结与结论

区块链技术有潜力将整个行业从中心化文化转变为去中心化结构。为了制约这一特性，开发了不同的治理系统，并且正在开发更多系统。多年来开发了不同的代币，并有不同的标准管理它们，其中目前 ERC-20 最为突出。

加密货币的引入是为了促进在各种区块链平台上进行去中心化金融交易。示例包括以太币、比特币、门罗币、狗狗币等。本章最后几节为读者提供了一些流行加密货币和加密货币交易所的快速概览。

## 核心概念

*   **区块链治理** 是区块链适应不断变化的时代和需求的系统。区块链治理的主要特征是适应性和可升级性。通常有四个关键主体参与区块链治理，即核心开发者、节点运营者、代币持有者和区块链团队。

*   **分叉** 是生成新加密货币的原因。由于部分用户对当前区块链存在分歧，区块链分裂为独立的数据库实例。这导致新加密货币的演变，而部分用户选择继续沿用旧区块链，部分用户决定跟随新分叉。

*   **加密代币** 与 **加密货币** 的主要区别在于，货币拥有自己的区块链，而代币没有，因为代币是在已有的区块链上创建的。根据预期用途，代币可分为多种类型，其中一些包括证券型、支付型、实用型和权益型代币。

*   **代币标准** 可被视为创建、转移和执行代币操作的接口。最被广泛接受的代币标准是 ERC-20、ERC-223 和 ERC-721，其中 ERC-721 是唯一的非同质化标准。

*   **Gas** 是以太坊交易结构中收取的交易费。2021 年，随着 EIP-1559 的引入，飙升的 Gas 费用得到了改革。为了加快以太坊上紧急交易的速度，用户可以包含小费。

*   **以太坊** 是仅次于比特币的最著名加密货币。GHOST 协议构成了以太坊链的基础。以太坊与比特币的主要区别在于，以太坊是一个平台，而非货币。以太币是以太坊的货币。

*   基于可追溯性属性，加密货币可分为公开型和私有型。公开型加密货币实现匿名性但仍可追踪（例如：比特币），而私有型加密货币被设计为不可追踪。

*   存在许多交易平台，包括 Bittrex、Coinbase 和 Poloniex。2021 年，许多加密货币和交易所正接受各种政府实体的调查或严格审查，例如美国证券交易委员会、美国司法部和国税局。
