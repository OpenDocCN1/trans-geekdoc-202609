# 区块链应用的层级架构

区块链平台包含分层的数据共享架构。该架构基于功能概览、设计原则和分层协作。设计原则包括高安全性、高可扩展性、去中心化和高可用性等特性 [[40]](#ch17.xhtml#r353)。

作为软件系统，区块链由两层组成：**应用层**和**实现层**。应用层负责面向用户的组件，而实现层包含协议和代码，基本上是让应用程序“活”起来的一切。区块链中的这两个主要层级可能包含其他次要层级。区块链的第 0 层到第 1 层应包含支持加密货币所需的物理基础设施。另一方面，第 2 层及以上是第二实现层，可能包含闪电网络层，能够以极快的速度（闪电般的速度）处理大量交易 [[5]](#ch17.xhtml#r318)。

区块链技术共有五层，如下所示：

*   **应用层**：该第一层包括 DApps（去中心化应用）、DApp 浏览器、用户界面和应用托管。用户可通过 DApp 浏览器浏览去中心化应用。因此，用户可以看到完全不同的用户界面。该层的应用托管允许用户运行所有去中心化应用。没有此组件，任何 DApps 都无法在互联网上上线。当然，托管协议将完全去中心化。此外，运行这些托管服务器的风险极小。

*   **服务层**：该层位于应用层之后，旨在提供访问用户创建和运行 DApps 层所需的所有资源。该层适配各种治理实现、链下计算、状态通道、支持侧链和数据馈送。

*   **语义层**：该层包含参与要求、虚拟机和共识算法，后者是所有节点就账本细节达成一致的必要程序。参与要求是帮助网络确定谁有资格进入系统、谁没有资格的主要规则。此外，此功能主要用于私有区块链技术。虚拟机为所有网络活动提供安全高效的平台。

*   **网络层**：该层位于语义层之后。它包含可信执行环境（`TEE`），有助于架构解决可扩展性问题。它不仅帮助网络克服这一问题，还提高了其安全性。`TEE` 还有助于将数据存储在主网络之外。网络层还包含 `RLPX`；一种网络套件，可促进两个对等节点之间的数据传输。`RLPX` 提供用户界面以辅助区块链网络内的通信。区块分发网络是一种网络类型，如果用户请求，它将发送网页内容或页面。事实上，这在典型的互联网架构中也可见一斑。网络层允许用户遵循 `Roll Your Own Mechanism` 协议，可在需要时随时定制，使协议更具适应性。

*   **基础设施层**：这是最后一层，包含代币等特性，有助于以更安全的方式维护生态系统和网络的去中心化存储 [[1]](#ch17.xhtml#r314)。

# 区块链应用工具

区块链工具的主要目的是在创建区块链应用的各个阶段，相对轻松高效地解决出现的众多需求。此类工具还有助于提高对该技术的认知和实践经验。精通以下区块链工具且拥有深厚知识和经验的区块链专业人士目前在区块链就业市场上需求量很大 [[25]](#ch17.xhtml#r338)。以下是一些主要区块链开发工具和技术的简要说明：

*   **Solidity**：这是一种基于以太坊的编程语言，由英国软件开发者 `Gavin Wood` 于 2014 年提出。`Solidity` 是一种用于创建智能合约的高级面向对象语言。开发 `Solidity` 的主要目的是需要创建一种易于学习的编程语言。因此，`Solidity` 基于变量、字符串操作、类、算术运算和函数等通用编程概念。此外，它还借鉴了 `C++`、`Python`、`PowerShell` 和 `JavaScript` 等高级编程语言。`Solidity` 还拥有一个编译器，可将高级代码分解为简单指令 [[6]](#ch17.xhtml#r319)。

*   **Truffle**：创建此工具的目的是为开发和测试区块链智能合约提供一个精简高效的平台。它使用 `Ethereum Virtual Machine` 创建一个高度有用的开发环境和测试框架。`Truffle` 套件由 `Truffle`、`Ganache` 和 `Drizzle` 组成 [[37]](#ch17.xhtml#r350)。`Truffle` 还附带大量自定义部署库，有助于创建新的智能合约和解决区块链开发问题 [[25]](#ch17.xhtml#r338)。`Truffle` 也非常适合开发复杂的以太坊去中心化应用 [[38]](#ch17.xhtml#r351)。自动合约检查是 `Truffle` 作为区块链工具的另一个关键功能。对于自动合约检查，`Truffle` 可能会使用 `Mocha` 和 `Chai`。此外，`Truffle` 将协助智能合约的创建、链接、编译和部署。最重要的是，`Truffle` 包含一个可定制的构建流水线，确保遵循特定的开发方法 [[25]](#ch17.xhtml#r338)。
