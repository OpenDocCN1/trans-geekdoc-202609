

# 网络犯罪分子开发虚假加密货币应用程序

根据安全公司 `Intezer Labs` 的说法，网络犯罪分子开发虚假加密货币应用程序，旨在诱骗用户在其计算机上下载一种新型恶意软件，最终目的是窃取受害者的资金。这些虚假应用程序被称为 `Jamm`、`eTrade/Kintum` 和 `DaoPoker`。这些应用程序分别在名为 `jamm.to`、`kintum.io` 和 `daopker.com` 的专用网站上展示。前两个应用程序似乎是一个简单的加密货币交易平台，而第三个则是一个加密货币游戏应用程序。根据 Intezer 研究人员的说法，这些应用程序还包含一个惊喜，即一种名为 `ElectroRAT` 的新型恶意软件，它隐藏在应用程序中，具备记录按键、截屏、从存储上传文件、导入文件以及在受害者控制台执行命令等能力。该恶意软件旨在捕获加密货币钱包密钥，随后耗尽受害者的资金。已安装木马化应用程序的用户应尽快卸载进程并删除所有相关文件，将剩余资金转移到新的加密钱包，并更新密码 [[8](#ch21.xhtml#r454)]。

## PCASTLE

`Trend Micro` 首先注意到一波使用 `PCASTLE` 的攻击，这是一种混淆的 PowerShell 脚本，主要针对中国境内的系统。`XMRig` 是一种加密货币挖矿恶意软件，曾在 2018 年的多次攻击中被使用。据该安全公司称，在此之后，该活动达到高峰然后趋于平稳 [[5](#ch21.xhtml#r451)]。在其最基本的形式中，PCASTLE 恶意软件是一种加密货币挖矿木马。当 PCASTLE 木马到达服务器时，它会启动 XMRig 挖矿工具并开始挖掘 `Monero`（门罗币），这是其首选的加密货币。所有获得的代币都会被转发到攻击者的加密货币钱包。拥有中国 IP 地址的机器占 PCASTLE 攻击的 92% [[15](#ch21.xhtml#r461)]。当一种传播方法成功时，第一层 PowerShell 脚本会通过计划任务或 `RunOnce` 注册表键下载。第一层的 PowerShell 脚本将尝试获取脚本中包含的 URL 列表。PowerShell 命令将被下载、执行并保存为新的计划任务。作为计划任务的一部分，将运行一个 PowerShell 脚本，该脚本将下载并运行第二层 PowerShell 脚本。下载并执行第三层 PowerShell 脚本后，恶意软件会将设备信息发送到其命令与控制 (C&C) 服务器。基于上述系统信息，第三层 PowerShell 脚本将下载加密货币挖矿包，并将其加载到自己的 PowerShell 进程中。它还将下载 PCASTLE 脚本部分，该部分负责其他任务，如传播。该活动采用的传播技术与之前的活动类似，但都在单个 PowerShell 脚本 (PCASTLE) 中，还采用了 `EternalBlue`（永恒之蓝）漏洞利用，以及暴力破解和哈希传递方法。只要存在可感染的系统，感染循环就会持续。例如，该活动利用了一个已修补漏洞的利用代码。因此，在遗留或嵌入式系统中使用虚拟补丁是个好主意。此外，应实施有效的多层防御策略。例如，应实施额外的保护协议，如活动检测，以检测和防止异常例程、未经授权的程序或脚本的执行。

沙箱通过包含不受信任的数据和 Shellcode，有助于防止与恶意软件相关的流量，而防火墙和入侵防御系统可以阻止与恶意软件相关的流量。身份验证和加密机制有助于避免目标应用程序被未经授权地篡改。更强健的账户凭证可以有效减少暴力破解和字典攻击。系统的适当修补和更新非常重要。具有行为监控功能的 Trend Micro 端点安全解决方案，如 `Smart Protection Suites` 和 `Worry-Free Business Security` 解决方案，就是可以帮助保护用户和企业免受这些挑战的工具示例，它们通过检测恶意文件、脚本和消息，以及封锁所有相关的恶意 URL 来实现防护 [[3](#ch21.xhtml#r449)]。

## Lemon Duck

根据 `Cisco Talos` 的说法，Lemon Duck 加密货币挖矿恶意软件最近加大了其运营力度，并采用了许多可能被恶意软件检测软件检测到，但对最终用户不明显的技术。Lemon Duck 漏洞利用包含加密货币挖矿载荷，它利用计算机资源来挖掘 Monero 虚拟货币。为了在网络中传播，该恶意软件使用多种方法，包括发送受感染的 RTF 文件、`psexec`、`WMI` 和 `SMB` 漏洞利用，包括臭名昭著的 `Eternal Blue`（永恒之蓝）和 `SMBGhost` 威胁，这些威胁会损害 Windows 10 设备。某些版本还支持远程桌面协议 (RDP) 暴力破解。该恶意软件还使用 `Mimikatz` 等工具，帮助僵尸网络增加其挖矿池中的系统数量。PowerShell 加载脚本用于传播病毒，该病毒通过 SMB、电子邮件或外部 USB 驱动器从其他受感染系统复制而来。利用 BlueKeep 漏洞的代码也通常存在。该恶意软件拥有由主模块下载和控制的可执行模块，主模块通过 HTTP 与 C2 服务器交互。挖掘加密货币的恶意软件在被盗计算周期和电力消耗方面代价高昂。虽然组织应专注于保护其最重要的资产，但不应忽视那些不专门针对其基础设施的风险。为了识别诸如加密货币挖矿程序等新的资源窃取威胁，防御者必须持续保持警惕，并跟踪其网络内系统的活动 [[36](#ch21.xhtml#r482)]。

## 勒索软件

勒索恶意软件，通常称为勒索软件，是一种阻止个人使用网络或访问文件的恶意软件，要求支付赎金以便用户重新获得对数据库和系统的访问权限。换句话说，勒索软件通常通过加密并冻结受害者的计算机系统来工作，然后索要赎金以解锁。不遵守要求会导致数据永久丢失。网络钓鱼邮件附件、损坏的软件应用、损坏的外部介质和被攻陷的网站都是勒索软件传播的途径。在某些情况下，黑客利用了远程桌面协议和其他不需要任何用户参与的方法。

2019 年 5 月 7 日，美国巴尔的摩市发现其联邦系统遭到了 `RobbinHood` 勒索软件的攻击，该软件锁定了大量关键文件。该市被迫关闭其系统以防止勒索软件扩散，但在那之前，勒索软件已感染了语音信箱、电子邮件和停车费数据库。根据电脑勒索信的打印件，该市只能以每个系统 3 个比特币或总共 13 个比特币的价格找回被劫持的数据。初始攻击的后果预计将使该市损失 1000 万美元，此外还因无法处理支付而损失了 800 万美元 [[38](#ch21.xhtml#r484)]。
