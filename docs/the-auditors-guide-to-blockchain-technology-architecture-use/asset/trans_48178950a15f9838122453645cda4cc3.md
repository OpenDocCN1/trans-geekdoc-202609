

# Accenture BaaS 产品

在 `Accenture` 的 BaaS 产品方面，与市场上的其他提供商相比，该组织提供了不同的视角。公司的咨询服务旨在帮助组织清晰地理解并选择合适的 BaaS 解决方案。Accenture 的市场策略涵盖咨询、战略和实施。关于 BaaS 解决方案，Accenture 通过提供问卷和详尽的服务简报做出贡献，随后根据业务需求提供平台的设计和实施模型，以及平台的部署环境。此外，供应商还为开发人员提供高级培训以达成其目标 [[2](#ch23.xhtml#r521)]。

## 百度

`Baidu`，中国流行的网络搜索引擎，推出了“超级链”区块链平台，现正为企业提供“百度可信” BaaS 平台 [[2](#ch23.xhtml#r521)]。与微软不同，百度可信是一个自研平台。该服务利用分布式账本技术促进交易及其追踪。将构建进企业基础设施的区块链的每个组件都可以灵活地进行定制和配置。一个利用区块链技术的百度可信资产支持证券交易产品在中国诞生，并在资产证券化和资产交易业务中取得了成功 [[13](#ch23.xhtml#r532)]。

## 华为

早在 2018 年初，`Huawei` 就推出了一个区块链即服务平台，称为区块链云服务（BCS）。借助华为 BCS，区块链连接的管理和部署变得更加容易，降低了区块链技术采用的门槛。BCS 提供全生命周期管理和基于 GUI 的智能合约创建、部署与调试。通过将行业特定的区块链应用与区块链平台集成，确保了数据的完整性和准确性，保障了数据的可靠性和安全性。区块链网络可通过软件开发工具包（SDK）或 RESTful（表述性状态传递）API 访问，并可利用与区块链云服务关联的监控平台实时监控数据和资源，并在必要时发送通知。得益于华为云的高性能，区块链账本可高效且及时地存储。华为 BCS 的显著特点在于其降低故障风险和无供应商锁定的能力 [[6](#ch23.xhtml#r525)]。

## SAP BaaS

`SAP 区块链服务`主要分为两大类：`SAP Cloud Platform` 和 `SAP HANA Blockchain Services`。

### SAP Cloud Platform 区块链服务 (SCP)

使用 `SAP Cloud Platform (SCP) 区块链服务`，可以在云平台上快速高效地开发基于区块链的应用程序，且在与 SAP 环境集成时风险极低。SCP 区块链服务支持 Hyperledger Fabric 和 MultiChain。

### SAP HANA

`SAP HANA` 本身不运行在区块链上，而是配置连接的属性。与区块链平台不同，SAP HANA 区块链服务不是一个区块链平台，而是将现有区块链平台连接到数据库的一种手段。SAP HANA 旨在利用 SAP 系统中的交易数据进行分析。SAP HANA 平台可通过使用 SCP 区块链服务连接到分布式账本技术。借助 HANA 数据库，可使用 SQL 查询访问区块链数据。分析需要数据整合。因此，需要 SAP HANA 区块链服务 [[15](#ch23.xhtml#r534)]。

# BaaS 业务用例

企业发现，订阅服务而非自建平台，是利用技术的一种更具成本效益且通常更有效的方式。同样，BaaS 使项目能够快速从概念验证阶段扩展到全面生产阶段。以下是一些值得注意的 BaaS 解决方案用例，展示了该解决方案为何既通用又宝贵：

## 利用 Amazon Managed Blockchain 实现食品溯源：雀巢

雀巢是世界上最大的食品饮料公司之一，也是世界上最大的咖啡生产商，其分销网络覆盖 190 多个国家。供应链透明度对消费者至关重要，因为他们有兴趣了解食品的生产和加工地点。在比较消费者价值和行业需求时，利用实时数据收集查看从农场到包装的整个过程，以及共享咖啡品鉴的不同属性（如产地、种植园类型、咖啡种类、烘焙程度等）变得越来越重要。
