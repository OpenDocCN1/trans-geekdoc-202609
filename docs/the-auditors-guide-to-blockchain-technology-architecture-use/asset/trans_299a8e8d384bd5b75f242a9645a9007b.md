# 前言

在企业严重依赖信息技术 (IT) 和数据的世界里，信息安全和保证专业人员的作用日益增强，这已不是秘密。埃德蒙顿协和大学 (CUE) 的信息系统保证管理硕士 (MISAM) 专注于 IT 的业务层面，即财务和技术相关审计。该课程遵循信息系统审计与控制协会的模范课程，因此 CUE MISAM 毕业生在技术和会计/金融方面均具备出色技能。MISAM 学生在 CUE 完成学业的同时，通常还会攻读注册信息系统审计师 (CISA)、注册信息安全经理 (CISM) 或注册信息系统安全专家 (CISSP) 认证。在 MISAM 课程中，研究生在实践中学习，本书即是该教育环境的成果。

本书是 CUE 教授 Shaun Aghili 博士在 CUE MISAM 课程中创新教学的成果。Shaun 在《本书背后的故事》中阐述了他编写此书的个人动机。让 48 名研究生从事项目工作，不仅提供区块链主题的背景知识，还在更多应用场景中进行探索，这值得关注。书中涵盖的主题广泛，使读者能够了解各个领域，无论是初学者还是该领域的专家都会感兴趣。Shaun 依靠学生在完成学业时研究他们的课题。他还得到了研究生助教 Aman Dev Singh 先生和 Yetunde Akinsanmi 女士的编辑支持。本书是团队合作的成果，我向 Shaun 以及以各种方式为本书做出贡献的所有人表示赞赏。知识旨在被讨论和分享；这本关于区块链的书因将课堂讨论分享给加拿大阿尔伯塔省埃德蒙顿大学校园之外的更广泛受众而引人注目。愿阅读本书能加深并巩固您对区块链的理解。

# 序言

## 本书背后的故事

约在 2018 年，我研读了一些关于支持比特币和其他加密货币交易的分布式、去中心化、点对点网络的文章。虽然当时我对比特币价值的大幅上涨及其未来的可持续性（以及当时涌现的大量其他加密货币）持一定怀疑态度，但支持比特币的网络基础设施迅速成为我的研究兴趣领域。这种被称为区块链的网络结构，因其不可篡改、加密安全和去中心化的特性，正被许多研究人员和组织视为潜在的颠覆性创新。事实上，一些评论员预测，在未来十年或左右，区块链技术作为一种消费者友好、透明且去中心化的工具被纳入应用，很可能会以 1990 年代互联网普及的方式影响信息技术领域。

对区块链技术的初步研究促使我决定进一步深入了解它。我花费了接下来的一年时间参加在线区块链相关课程，并备考几个全新的区块链认证考试，涉及区块链基础、用例、架构和安全考量。这一举措使我对这项技术的现状、局限性和问题，以及其在供应链管理、去中心化金融、会计和审计、政府运营等领域的潜在用例有了更好的了解（仅举几例）。
