
# 区块链的分布式账本技术拥有多种解决方案，可适应资产管理行业快速而剧烈的变化，具体如下：

*   **实现开放协作**：区块链允许创建一个涉及第三方（如服务或解决方案提供商）的系统，从而进一步促进资产管理的开放协作活动。简而言之，区块链技术使添加新业务合作伙伴的任务变得更加容易。

*   **交易透明性与不可篡改性**：由于区块链交易不可变且防篡改，资产管理数据可在保持数据完整性的同时安全、透明地共享。

*   **通过共识提高一致性**：区块链的分布式账本确保不存在不一致的记录，因为所有数据块都必须由所有处理节点根据商定的共识方法进行验证 [[21](#ch19.xhtml#r412)]。

*   **提高运营效率**：区块链技术的分布式结构为资产管理行业内的 B2B 交易提供了显著的效率提升。考量运营效率提升的主要因素是区块链基础设施本身。组织无需彼此持续发送信息，区块链参与者只需更新其当前的区块链状态，即可获取最新的区块链交易更新 [[22](#ch19.xhtml#r413)]。

*   **面向金融服务提供商的客户准入与了解你的客户 (KYC) 活动**：客户身份核查和准入活动可以说是在高度监管的资产管理行业中耗时最长的任务。验证新客户的身份、资产所有权、资金来源、国籍和风险概况以及投资适配性信息可能需要数天甚至数周。区块链还能促进更快的信息共享。由于区块链节点分布在不同组织中，KYC 活动注定会像当前的消费者或企业信用检查一样普遍 [[22](#ch19.xhtml#r413)]。区块链为金融服务提供商组织带来的其他益处可能包括更快的交易清算和证券交易结算、更有效的经纪商/交易商合规，以及通过智能合约大幅降低客户和资产管理实体的交易费用。[第 5 章](#ch13.xhtml#c5)将更详细地讨论这些问题。

## 区块链在数据控制、安全、法律合规与保证中的应用

除了区块链在各个领域提供的各种益处外，还有其他值得讨论的优势。区块链提供的一些关键特性包括数据控制、安全、法律合规和保证（审计）。这些益处将在下文讨论。

### 数据控制

企业处理大量数据，如客户记录，包括个人身份信息 (PII) 或公司的内部和/或专有信息，这些通常是各类信息泄露的主要目标。当信息在组织的多个组织层级和系统层级间流动时，可能会“从缝隙中渗漏”。Facebook、Google 或 Amazon 等中心化组织对消费者数据拥有相当大的控制权。这种控制权不在实际用户手中，而在组织手中，公司可随意利用。当第三方供应商创建拥有此类敏感信息间接访问权限的服务时，隐私、安全和透明度问题会加剧。这些公司与其关联方的运营不透明，让客户蒙在鼓里。区块链提供了一种去中心化解决方案，可对第三方身份进行加密验证。这最终将控制权交还给用户，因为它消除了授权或认证特定主体所需的中介 [[23](#ch19.xhtml#r414)]。

### 安全

区块链有助于修复一些安全漏洞，通过提高弹性、加密、审计和透明度，从而解决信息安全的 CIA 三要素。区块链的全面加密确保数据无法被未授权方访问；这是中间人攻击的完美解决方案。区块链还可用作即时通讯应用和社交媒体平台中端到端加密的替代方案，通过保护用户的元数据来实现数据安全。这些元数据随机分布在网络中，避免了所有数据在单一点积累。围绕安全通讯的安全性仍在探索中，未来可能会取得重大进展 [[24](#ch19.xhtml#r415)]。

### 法律合规

智能合约可编写特定条件，当满足其预定义标准时可自动执行。这消除了中介审查和执行合同的需求。区块链可用于土地登记程序，其中土地契约信息可在所有各方均已预先认证的账本上访问。人口普查报告、死亡记录或犯罪活动等公共记录也可通过区块链进行维护。

区块链提供了一个安全且防篡改的数据库。这有助于减少欺诈和洗钱等犯罪，而这些犯罪的防范对 KYC 和反洗钱 (AML) 至关重要。智能合约可自动化 AML 监控流程并提供实时更新 [[25](#ch19.xhtml#r416)]。

### 保证

区块链有助于提供保证基线，可大幅减少传统审计任务。完整的交易历史或数字资产交换记录实时更新，并透明地提供给所有各方，形成有条理的可审计记录。由于交易通过前一个区块的哈希值相互链接，篡改几乎是不可能的。区块链的不可篡改特性确保欺诈和洗钱活动得到遏制 [[26](#ch19.xhtml#r417)]。

## 区块链实施挑战

在探讨了区块链为日常生活做出贡献的几种方式后，很自然会问：“我们如何实施区块链技术？”。然而，答案并不那么简单。区块链已成为关注焦点，尤其是随着比特币和以太坊等加密货币的当前流行。尽管如此，区块链技术仍处于起步阶段。因此，区块链尚未在 IT 行业得到广泛采用。原因如下：

*   **实施成本**：对于任何组织迁移到新技术解决方案，首要考虑的是实施成本。新区块链解决方案相关的费用是否会干扰组织内为其他 IT 项目分配的预算？是否会阻碍任何正在进行的项目？实施过程中是否存在隐性成本？在向区块链解决方案过渡时，确保资金充足至关重要。合适区块链解决方案的选择、实施和优化应经过周密规划，以避免过高的实施成本。

*   **组织内部的变革阻力**：高层管理批准和利益相关者对新 IT 项目的接受并非易事，因此需要所有利益相关者都支持实施区块链解决方案的计划。利益相关者可能因对实施后区块链收益能否实现存疑而反对实施区块链技术。如果想法被接受，另一个考量因素是组织最终用户对从“我们现在的做事方式”向增强版“区块链做事方式”过渡的反应。
