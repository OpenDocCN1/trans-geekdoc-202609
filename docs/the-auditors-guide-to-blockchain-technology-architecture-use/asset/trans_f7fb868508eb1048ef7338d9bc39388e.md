

以下部分提供了上一节介绍的各类测试/审计方法所用工具的基本相关信息。

### 控制流分析工具

#### McCabe IQ

可利用流程图和带注释的源代码清单，对攻击图中的每个特性进行详细审查。路径信息会经过测试，以确保所显示的控制流路径准确、稳定且符合规范 [[31](#ch22.xhtml#r515)]。

McCabe IQ 的数据字典功能是另一种策略，可用于更彻底地调查程序代码中使用的禁用函数。用户可在数据字典中扫描数据元素和函数调用，并对包含这些调用的函数内的路径进行分类 [[31](#ch22.xhtml#r515)]。该工具可在 GitHub 上获取：[https://github.com/PyCQA/mccabe](https://github.com/PyCQA/mccabe)。

#### 以太坊虚拟机

EVM 由一个建立在具有自定义指令格式的栈上的单一虚拟机组成。每条指令均表现为一个单字节操作码。在数据栈上传递参数。用于将常量压入栈的 push 指令是唯一例外。这些常量直接转换为指令的字节。由于 EVM 具有用于简单块入口的显式标记，因此检索基本块边界是可行的 [[30](#ch22.xhtml#r514)]。该工具可在 GitHub 上获取：[https://github.com/exthereum/evm](https://github.com/exthereum/evm)。

### 污点分析工具

#### TAJ

Java 污点分析 (TAJ) 是一种旨在以足够可靠性生成低误报率，并具有足够通用性以允许评估大型应用程序的方法。TAJ 提供了一系列策略，可在极大型程序上产生实际效果，尽管它们受限于给定的时间或内存预算。当实现极其庞大且最终用户仍希望分析在有限时间内终止或保持在指定内存使用水平内时，TAJ 主张采用优先级方法，将研究重点放在可能参与污点传播的 Web 应用程序部分上 [[27](#ch22.xhtml#r511)]。该工具可在 GitHub 上获取：[https://github.com/TJAndHisStudents/TaintFlowAnalysis](https://github.com/TJAndHisStudents/TaintFlowAnalysis)。

#### DYTAN

动态污点分析因数据流和控制流而能充分管理程序内的知识流，并支持在不同维度上定制分析。通过动态污点技术可避免 SQL 注入攻击，攻击者会向 Web 服务器发送恶意构造的字符串以进入底层数据库。大多数基于动态污点的 SQL 注入防范方法通过污染和监控来自用户的不安全输入文件来工作。一旦查询字符串提交给数据库，就会对其进行审查，以确保该字符串或其片段未使用任何已损坏的数据生成 [[28](#ch22.xhtml#r512)]。该工具可在 GitHub 上获取：[https://github.com/behzad-a/Dytan](https://github.com/behzad-a/Dytan)。

### 动态代码分析工具

#### MAIAN

动态工具 MAIAN 考虑智能合约的执行轨迹，即在区块链上运行合约时记录的序列。MAIAN 还结合漏洞类别考虑执行轨迹。每次交易都会请求智能合约运行一个函数，从而导致针对给定输入的执行路径被利用。因此，执行轨迹可能具有连锁效应。因此，为在智能合约的指定执行轨迹上查找漏洞利用，MAIAN 工具使用系统化技术。MAIAN 由两大主要组件组成，即符号分析和具体验证。符号分析组件的输入为合约字节码、分析规范及漏洞类别。MAIAN 持续执行直到到达具有漏洞属性集的不确定轨迹。所有执行均在 EVM 上进行，这将简化智能合约字节码的符号执行。每条执行轨迹均以符号变量作为输入，以便符号分析组件在合约暴露出漏洞时返回给定符号变量的具体值。具体验证的作用是验证符号分析的结果，并确认在智能合约中发现的 Bug 的准确性。分析期间，MAIAN 不会影响主以太坊区块链上合约的状态 [[8](#ch22.xhtml#r492)]。该工具自 2018 年 3 月起已在 GitHub 上以 MIT 许可证提供 [[21](#ch22.xhtml#r505)]。

#### ContractLarva

该工具用于智能合约的运行时验证。用户可使用动态事件自动机 (DEA) —— ContractLarva 使用的一种规范语言 —— 来证明给定智能合约的属性。该工具通过接收给定合约的规范作为输入来生成一个新的 Solidity 合约。新合约的功能与原始合约相同，但向合约中添加了代码以检查运行时验证，并在观察到任何违规时做出相应反应。尽管 ContractLarva 已在许多智能合约上实现以部署运行时验证和恢复，但它面临许多需要解决的挑战 [[27](#ch22.xhtml#r511)]。该工具可在 GitHub 上以 Apache-2.0 许可证获取 [[21](#ch22.xhtml#r505)]。

### 基于漏洞的扫描工具

#### Mythril

一款用于分析智能合约的自动化工具。分析基于字节码。它使用污点分析和控制流分析来查找漏洞。Mythril 使用命令行作为界面 [[22](#ch22.xhtml#r506)]。通过该工具发现的漏洞均有详细记录和文档说明。ConsenSys 于 2017 年 9 月在 GitHub 上开发并维护 Mythril，采用 MIT 许可证 [[21](#ch22.xhtml#r505)]。

#### Securify

另一款基于用户界面的自动化安全分析工具，用于基于字节码的以太坊智能合约，可检测重入、输入验证等漏洞 [[22](#ch22.xhtml#r506)]。如果检测到某种模式，该工具可提供额外保证，即合约代码具备相应的安全属性。该工具采用 Java 编写，自 2018 年起已在 GitHub 上以 Apache 2.0 许可证提供 [[21](#ch22.xhtml#r505)]。

#### SmartCheck

一款开源、基于用户界面的自动化工具，可运行 Solidity 源代码并检查漏洞及其他安全问题 [[22](#ch22.xhtml#r506)]。SmartCheck 将代码转换为可扩展标记语言 (XML) 语法，并将漏洞指定为 XQuery 路径表达式，用于在 XML 树中搜索模式。该工具的最新版本为闭源，其漏洞检查模式数量是之前的两倍。该工具采用 Java 编写，可通过 SmartCheck 公司网站访问 [[21](#ch22.xhtml#r505)]。

### 符号执行工具

#### DART

符号执行领域较早的工具之一，能够通过动态分析执行随机测试，以查找由库函数引起的 Bug。DART 使用单路径测试输入（不采用路径选择机制）来检查违规、断言、崩溃和非终止等标准错误 [[20](#ch22.xhtml#r504)]。该工具在 GitHub 上公开可用。DART 软件开发工具包包含 VM、dart2js、核心库等。

#### Manticore
