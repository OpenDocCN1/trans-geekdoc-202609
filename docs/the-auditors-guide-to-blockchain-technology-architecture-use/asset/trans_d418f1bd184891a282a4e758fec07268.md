

# 区块链网络攻击

在区块链网络中，处理节点负责交易处理，并提供区块创建、账本管理等不同服务。矿工将已批准的交易添加到区块中，节点发送和接收这些已批准的交易。攻击者试图在网络中寻找缺陷加以利用，并用于发起各种网络层面的攻击。以下章节将讨论各种网络层面的攻击，包括多数派（51%）攻击、自私挖矿、DDoS 及其他攻击，并探讨相应的攻击缓解技术。

## 成员服务安全

为了在成员服务中增加一层安全防护，`Intel SGX Technology`（英特尔 SGX 技术）大有裨益。英特尔软件防护扩展（SGX）的远程佐证功能有助于识别区块链上的可信节点。支持 SGX 的成员服务还可改善隐私保护和抵御恶意攻击的防御能力。最后，采用这种硬件辅助技术也可能有助于实现问责制。然而，由于硬件成本高昂，这种方法并不适用于所有成员服务应用 [[13](#ch21.xhtml#r459)]。

另一种方法是将疑似恶意节点列入黑名单。通常，黑名单上的节点被用作僵尸网络大军的一部分来发动攻击。然而，由于此类恶意节点的数量通常相当庞大，可以考虑采用白名单机制，尽管由于涉及的节点数量往往很大，扩展该过程可能颇具挑战。当物联网服务与设备之间存在隐性信任时，白名单系统将具有可扩展性。受信任的实体通过这种方法在智能合约层面被添加到受信任列表中。因此，任何时候网络上只允许最值得信任的用户。建议的信任方法利用隐性区块链共识过程来建立信任，从而消除了对第三方在两个通信方之间建立信任的需求。该信任范式很简单。它通过将白名单或黑名单 IP 地址放在公共以太坊区块链上，然后将其传播给其他节点，来宣告 DDoS 攻击 [[34](#ch21.xhtml#r480)]。

## 网络设计缺陷

区块链网络可以运行在公司的内部网络基础设施上，甚至可以运行在互联网上。使用该基础设施的区块链网络应以满足区块链用户需求的方式进行设计。需要更大的带宽来减少或避免点对点通信的延迟。例如，区块链的设计初衷是允许节点以点对点的方式通信。如果节点位于具有不同安全级别的网络段中，这可能会违反组织的网络安全协议。这可能导致通信重复，或通信被阻断而无法到达其某些对等节点。因此，必须妥善设置网络基础设施，从而保护区块链免受某些攻击 [[17](#ch21.xhtml#r463)]。

## 整体网络安全薄弱

区块链网络通过常规网络基础设施进行交互，这意味着区块链的防护取决于底层网络的安全性。因此，即使是针对网络基础设施的物理攻击也可能危及区块链的防护。拥有通信链路或网络组件访问权限的攻击者可能会破坏区块链的运行，从而降低其安全性。组织通信基础设施的物理安全应得到有效保护。网络薄弱的逻辑安全也会影响区块链。私有链可能依赖底层网络的安全控制（防火墙、分段等），并可能变得容易受到攻击者绕过这些控制的攻击。对防火墙和其他组件的控制也可能允许攻击者对区块链网络进行分段，使其容易受到攻击 [[17](#ch21.xhtml#r463)]。

## 51% 攻击与双重支付攻击

在该类攻击中，有一组矿工获得了网络大部分的 `hash rate`（算力）。该算力是指区块链网络处理能力的度量单位，进而可能实现区块链操纵，例如阻止交易被验证，从而使其无效。利用这种攻击模式，一条分离链被引入网络，从而使其看起来像一条合法链。此时便启用了 `double-spending`（双重支付）攻击。双重支付是指恶意用户发送交易的副本使其看起来合法，从而使数字代币能够被花费多次。如前所述，在区块链策略中，适用最长链规则。如果恶意用户在网络中拥有超过 50% 的总算力，恶意用户将能够在区块链网络中运行最长链，这正是 51% 攻击所需的比例 [[30](#ch21.xhtml#r476)]。

51% 攻击还能使攻击者通过限制交易和/或取消区块来控制加密货币的价格。过去几年中发生过多起此类攻击事件。2016 年，一个名为 `GHash.IO` 的比特币矿池曾获得超过 51% 的总算力控制权。在另一事件中，一个名为 `51 crew` 的攻击者团伙使用相同的攻击方法劫持了两条以太坊区块链。2018 年 5 月，恶意矿工获得了 `Bitcoin Gold`（比特黄金）超过 51% 的算力控制权。最后，2018 年 6 月，一些区块链货币也遭到了攻击，其中包括 `Monacoin`、`Zencash`、`Verge` 和 `Litecoin Cash` [[29](#ch21.xhtml#r475)]。

针对这类攻击，有多种缓解技术，其中一些包括延迟区块提交惩罚、PirlGuard 和合并挖矿。以下各节将简要解释这些缓解技术。

### 延迟区块提交惩罚系统

`A penalty system for delayed block submissions`（延迟区块提交惩罚系统）是 Horizen（2018 年）提出的一种安全概念，旨在修改中本聪提出的共识，以保护网络免受 51% 攻击。中本聪共识是一组规则，它结合了拜占庭容错点对点网络上的工作量证明共识算法，以验证区块链网络的真实性。惩罚系统提议大幅增加攻击成本，以阻止潜在攻击者或节点的欺骗行为。因此，根据区块对区块链网络隐藏的时间长度施加惩罚。时间是根据区块之间的间隔长度计算的。在向整个网络通报持续分叉期间，矿工、参与者和交易所被限制执行欺诈性交易，直到延迟被消除。这种方法的主要关注点在于私有挖掘的链，而不关心正遭受分叉困扰的网络 [[30](#ch21.xhtml#r476)]。
