

# 区块链在金融服务中的应用

## NASDAQ Linq 和特拉华区块链倡议

2013年，美国全国证券交易商协会自动报价系统（NASDAQ）开发了一个名为 `Linq` 的区块链网络，用于存储和管理私营公司的股份，即私募证券。NASDAQ 认为，金融市场发展的关键因素包括安全且有据可查的监管链，以及确保资产流动性和可扩展性的记录保存。Linq 平台目前提供股份交易、法规执行和报告功能，服务于 chain.com 等小型私营企业，以在监管机构参与区块链赋能的商业解决方案的同时，将风险范围降至最低。`特拉华区块链倡议` (DBI) 是另一个区块链用例，旨在进一步促进涉及大型商业交易的法律和运营挑战的解决。该平台不提供纸质所有权的数字副本；而是提供公司的合法电子所有权。DBI 为公共档案创建了一个电子数据库，包括出生和死亡证明、商业法典、以分布式账本形式存储的土地所有权，并利用智能合约实现访问和控制的自动化。DBI 通过创建包含数字记录的证券主文件，使法律程序明确了区块链上记录的数字状态，从而允许通过智能合约转移证券。DBI 的另一个组成部分是利用智能合约和区块链保存州公司文件记录，包含从新记录到过期流程通知的所有细节 [[6](#ch13.xhtml#r210)]。

## 了解你的客户 (KYC) 考量

金融业深受反洗钱 (AML) 和 `了解你的客户` (KYC) 法规的影响，旨在防止洗钱、恐怖主义融资和欺诈。金融机构必须采取预防措施和控制手段来缓解这些威胁，并遵守现有的 KYC 相关法规。了解你的客户概念是指客户识别、验证和认证流程。一组缓解控制措施被用于避免与涉及腐败、洗钱或恐怖主义的个人或组织开展业务。KYC 流程包括验证程序，旨在在授予潜在客户金融产品或服务准入之前，确定其身份是否真实。KYC 策略和 AML 法规至关重要且维持成本高昂，因为它们需要专门的资源和复杂的迭代流程。金融机构与其他第三方服务提供商之间也存在高度的工作重复。区块链技术有望使 KYC 成为一种更可行的工具，能够通过基于固有安全性和不可篡改性特征提供更有效的前进路径，从而有效缓解洗钱和恐怖主义风险，这些特征为数据提供了更高的完整性和信任度 [[13](#ch13.xhtml#r217)]。

### 简化合规并避免流程重复

监管机构和金融机构可以通过最小化人工输入和推动标准化来降低监管风险并实施更严格的控制。在这方面，直接从权威来源获取金融机构的档案资料，在降低欺诈风险和人为错误范围方面发挥着关键作用，而不必依赖客户输入的数据字段或纸质文件。因此，银行和其他金融服务提供商可以自动化流程，通过更客观有效的标准分配 AML 风险评级，以避免监管罚款。此外，KYC 流程可为监管机构提供关于交易、参与方及底层信息的证据 [[5](#ch13.xhtml#r209)]。

因此，监管机构将更好地了解客户活动，因为区块链技术将有助于记录和追踪所有金融机构和客户的活动，并定期监控数据活动和趋势。从客户角度来看，金融机构利用 KYC 工具进一步改善客户体验，使流程日益高效和及时。尽管客户可能因 KYC 法规要求共享其敏感财务和个人数据而存在隐私顾虑，但区块链技术赋予客户批准可访问其信息的机构类型及访问条件的权力。数字化集成使此类审批流程变得简单，例如向客户手机推送带有一次性密码 (OTP) 的同意申请以获取授权。智能数字签名或面部扫描等选项也能增强客户的身份自主权，从而消除客户对共享敏感数据的顾虑。最后，在可协调的情况下，KYC 工作流路由和控制可编码为智能合约并例行执行。同样，更高程度的数字化也有望通过智能合约和翻译工具促成多语言解决方案 [[8](#ch13.xhtml#r212)]。

### 区块链作为防洗钱工具

区块链的去中心化、加密安全性和不可篡改性特性可即时高效地检测可疑交易。利用智能合约的基于分布式区块链的系统，使金融机构能够通过区块链技术的反洗钱“引擎”安全地分发数据，该引擎能够识别欺诈交易并发出警报和/或异常报告。在这方面，KYC 在防范洗钱和恐怖主义方面发挥着关键作用，而区块链可被设计为高效、有效 KYC 运营背后的引擎 [[5](#ch13.xhtml#r209)]。

## 区块链与消费者信贷

消费者和商业信贷领域是另一个适合实施区块链的候选者，特别是因为数据安全和隐私也是借贷交易的重要方面。该技术通过加密分布式账本提供交易的实时验证，无需第三方干预，从而促进安全、快速的支付处理服务。此外，没有第三方参与提高了支付交易速度，因为该技术使直接管理各种信用卡支付清算流程变得更加容易。例如，MasterCard 已申请基于区块链的支付系统专利，使该公司能够向商家提供即时支付、安全支付验证和快速客户通道 [[24](#ch13.xhtml#r228)]。同样，区块链技术促进了点对点转账，因为它没有地理限制。该技术在全球几乎无处不在，使得全球范围内的点对点转账成为可能 [[28](#ch13.xhtml#r232)]。

### 持卡人身份与验证流程

区块链技术以不可篡改的方式安全存储信息的能力，简化了信用卡公司验证个人身份的流程。例如，得益于这项技术，消费者可以使用移动应用程序为信用卡公司的新服务验证身份，而无需亲自提供身份证明或签署额外文件。此外，借助金融科技中的区块链，用户有自由决定如何被识别以及与谁共享其身份 [[28](#ch13.xhtml#r232)]。虽然用户必须在区块链上注册其身份，但前提是其他此类服务提供商也由区块链技术驱动，他们无需完成每个信用卡发行机构的初始注册流程 [[24](#ch13.xhtml#r228)]。
