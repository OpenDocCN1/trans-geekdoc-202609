

### 第二阶段：我们现在处于什么位置？

#### 持续改进 (CI) 任务

*评估当前状态：*

1. 确立 I&T 对企业实施区块链目标的贡献重要性。
2. 识别实施区块链后，当前及未来解决方案相关的治理问题和弱点。
3. 识别并选择治理和管理目标以实施区块链。
4. 评估实施过程中产生的价值实现、实施项目交付和运营风险。
5. 识别目标以确保实施风险被规避，或风险接受立场已被定义。
6. 定义执行评估的方法，并记录对当前管理和治理目标如何应对实践的理解。

#### 变革赋能 (CE) 任务

*组建区块链实施团队：*

1. 从业务和 IT 部门组建一支拥有扎实知识、经验、公信力和权威以实施区块链的团队。团队成员可包括区块链架构师、区块链网络管理员、质量分析师、风险与合规、安全经理、CIO 和治理委员会。
2. 识别一名能够领导团队的区块链项目经理。
3. 识别潜在的既得利益相关方以建立信任和适当的工作环境。
4. 在团队内创建共同愿景，以授权实施区块链的变革。

#### 项目管理 (PM) 任务

*定义问题和机会：*

1. 审查并评估区块链用例、可行性及投资回报率 (ROI)。
2. 向所有利益相关方分配角色和职责，并确保其承诺。
3. 识别执行这些任务时的挑战。

#### 输入

1. 区块链业务大纲。
2. 高层角色和职责。
3. 项目启动沟通。
4. IT 流程描述、策略和标准。
5. BC 实施的 BCP、影响分析、法规要求、SLA 和 OLA。
6. 审计报告、风险管理策略、绩效报告。

#### 输出

1. 经商定的对齐目标及对 I&T 的影响。
2. 当前绩效水平和能力水平。
3. 风险接受立场和风险概况。
4. 实施团队的组建。
5. 经评估的区块链用例。
6. 对实施导致的问题和挑战的理解。

### 第三阶段：我们想要达到什么位置？

本阶段评估当前企业环境，作为实施区块链解决方案的一个步骤。它设定改进目标并执行差距分析，以识别潜在区块链解决方案的价值。应在本阶段制定适合区块链项目的高层变革赋能计划。还应创建有效的沟通策略，以解决各个群体对愿景、收益、影响、目的和利益相关方参与的关切。

应制定区块链路线图以实现实施愿景。应记录来自各团队成员的反馈并采取适当行动（参见 **表 11.5** 和 **表 11.6**）。

#### 持续改进 (CI) 任务

*定义改进目标：*

1. 基于企业绩效和合规性，决定实施过程中流程的目标能力水平。
2. 内部基准测试以识别可采用的最佳实践。
3. 对目标水平进行合理性检查，判断什么是可取的/可实现的，以创造积极影响。

*分析差距：*

1. 将当前能力水平与目标能力水平进行比较。
2. 寻找模式以识别可通过区块链实施解决的改进根本原因。

*识别潜在改进：*

1. 汇总实施过程中当前状态与拟议未来状态之间的差距。
2. 识别通过区块链实施可能产生的风险，并确保其被接受在一定水平内。

#### 变革赋能 (CE) 任务

*描述并沟通成果：*

1. 确保利益相关方有参与的意愿。
2. 制定沟通策略以优化变革认知度。
3. 强调实施区块链的愿景和收益。
4. 在沟通中将计划目标与其实施实现方式联系起来。

#### 项目管理 (PM) 任务

1. 设定项目方向，以及实施区块链的方向范围。
2. 识别因实施可能产生的风险。将范围调整至最优水平。
3. 考虑因该变革赋能可能产生的影响。
4. 确保预算并定义角色和职责。

#### 输入

1. 经商定的目标及对对齐目标的影响。
2. 风险接受和风险概况。
3. 利益相关方分析。
4. 内部和外部能力基准。
5. 核心团队已组建并分配了角色和职责。
6. 挑战和成功因素。

#### 输出

1. 改进机会描述。
2. 高层项目计划。
3. 跟踪项目和绩效的指标。
4. 详细业务案例。
