

# 三式记账与区块链技术

*   本章讨论了会计分录的历史，从印度Chanakya发起的单式记账系统，到15世纪意大利经济学家Luca Pacioli开创的复式记账系统。三式记账最初由会计学者Yuji和金融密码学家Ian Grigg构想。除了借方和贷方分录外，Yuji建议引入第三层分录，并配合一套新的账户集合，以进一步说明收入的变化。

*   实施基于区块链的会计系统，将复式记账和分布式记录转化为去中心化的公共记录，可为被审计实体记录的完整性提供高度的确定性。Ian Grigg开发了一种新理论——**“收据即交易”**，旨在防止交易欺诈并最大限度地减少内部文档中的无意错误。双方之间由金融密码支持的数字授权收据，可通过共同的第三方分录进行解读。

*   三式记账有助于确保源单据的真实性，可能会为具备区块链技能的会计师增加未来的就业机会。

*   区块链技术凭借其不可篡改性、去中心化、分布式账本、共识机制和增强的安全性，有助于缓解ACFE欺诈分类中的各类欺诈手段，如财务报表欺诈、挪用现金欺诈、现金盗窃、登记付款计划、支票篡改、账单计划、薪资计划、费用报销计划、库存挪用及库存盗窃。

*   由于区块链的可追溯性特征，采购交易丢失的顾虑可轻松解决；在区块链网络上执行三式记账将有助于减少审计和采购周期中所用的时间和步骤。
