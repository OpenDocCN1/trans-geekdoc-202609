To this end, Beck has introduced the sequential function specification method (FSFM) in 1968 [16], then he described it in detail in 1985 [4]. The sequential function specification algorithm was also applied in the research of Huang et al. [17] to reconstruct the temporal and spatial related heat flux by assuming that variants are linear during every time step. It is noted that the sensitivity coefficients were acquired by the finite element method (FEM). The SFSM presumes a specified formula for the heat flux and predicted the current unknown heat flux by future-time measurements. By this method is

```
$$J_p = \sum_{n=0}^{r-1} \sum_{m=1}^{M} [T(r_m, t^{p+n}) - \tilde{T}(r_m, t^{p+n})]^2$$
```

Assuming that the heat flux in the selected time window is linear, the heat flux estimate of the $[i+1]$-th iteration is

```
$$Q_{i+1}^p = Q_i^p - \frac{\sum_{n=0}^{r-1} \sum_{m=1}^{M} [T(r_m, t^{p+n}) - \tilde{T}(r_m, t^{p+n})] \frac{\partial G_n}{\partial Q^p}}{\sum_{n=0}^{r-1} \sum_{m=1}^{M} [\frac{\partial G_n}{\partial Q^p}]^2}$$
```

where $\partial T/\partial Q^p$ is the heat flux at $G_n$, which is recorded as $G_n$. It satisfies:

```
$$p C_p \frac{\partial G_n}{\partial t} = n\nabla^2 G_n, t \in [t^{p-1}, t^{p+r-1}]$$
```

```
$$\kappa \frac{\partial G_n}{\partial t^{p+n}} = -n + 1$$
```

During the calculation, the temperature history $T(r_m, t^{1+n}), (n = 0, \dots, r-1)$ can be calculated measuring each point from the full field heat distribution at the initial time and the preliminary estimated $Q_i^p (n = 0, \dots, r-1)$ using the heat conduction equation, and the sensitivity $G_n^p$ by applying Equation 3.8. After that, it is feasible to use $Q_1$ and $T(r_m, t^{2+n}), (n = 0, \dots, r-1)$ to reconstruct $Q_2$ by the time step following the same method.
