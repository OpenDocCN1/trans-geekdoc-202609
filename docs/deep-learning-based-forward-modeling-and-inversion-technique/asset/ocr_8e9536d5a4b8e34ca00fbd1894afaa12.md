# 4.5 Inversion Process

After removing the noise, the time domain temperature profile is utilized to recover the thermal conductivity. In fact, the inversion problem is able to be treated as an optimization task whose target functional $F(k)$

```
$F(k) = \sum_{i=1}^{N_d} \sum_{j=1}^{N_t} |T_j(k) - T_{ij}^{mea}\|^2, \quad (4.34)$
```

where $N_d$ and $N_t$ are number of space and time domain sampling points. $T_j(k)$ and $T_{ij}^{mea}$ indicate the computed temperature (assuming that the thermal conductivity is $k$) and the measured temperature, respectively. It is feasible to acquire the best estimation of the thermal conductivity $k$ by iterations and forward computations:

```
$k^{(n+1)} = k^{(n)}+\beta(n)p(n), \quad (4.35)$
```

```
$p(n) = \nabla F(n) + \gamma(n)p(n-1), \quad (4.36)$
```

where $\beta, \gamma, P$ are the step size, updating coefficient and searching direction, respectively. The superscript $(n)$ indicates the iteration times. However, implementing the iteration algorithm to obtain a stable convergence needs a lot of computing resources and time. Therefore, it is urgent to bring out a substitution approach.
