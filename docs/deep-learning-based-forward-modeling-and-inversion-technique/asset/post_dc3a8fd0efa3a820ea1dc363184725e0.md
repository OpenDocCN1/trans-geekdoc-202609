## 2.3.3 Architecture of the Network

After building the dataset, an efficient neural network is indispensable for training. The proposed framework is mainly based on the U-net [33], which was first introduced into medical image segmentation by researchers. It was widely adopted for various problems with close spatial connections between the input and output. Figure 2.12 shows the structure of the classic U-net, which is composed of fully convolutional networks. Since it does not contain any fully connected structure, the U-net can process data with high resolution without reduced GPU resources. The entire architecture is composed of the symmetric contraction and expansion path, which resembles a T, and hereby marked for U-net.

In the heat problem investigated in this chapter, the input and output are a three-dimensional matrix with the dimension of $32 \times 32 \times 32$, while the input matrix represents the geometry and thermophysical properties of the object while the output matrix represents the steady-state temperature field distribution. The specific structure of the proposed network is displayed in Figure 2.13. Considering that the Laplace equation involved in this study is three-dimensional, the convolution kernel is set to be $3 \times 3 \times 3$. Similar to Figure 2.12, the proposed framework also includes a contracting path and an expansion path. The contracting path includes four sub-modules, and each consists of two $3 \times 3 \times 3$ convolution layers, in which one has a stride of two while the other has one. After each downsampling, the number of output channels is doubled and the input size reduces to 1/8 of the original. For the expansion path, it is also composed of four sub-modules, and each composed of an up-sampling structure and a transpose convolution structure. After each upsampling, the number of output channels halves and the input size rises to 8 times. In order to increase the nonlinearity of the network, a ReLU activation function is added after each convolution or transpose convolution. At the lowest point of the network, an additional block containing a $3 \times 3 \times 3$ convolutional layer with a stride of one is introduced to link the contraction path and expansion path. In addition, a skip connection is in the corresponding downsampling and upsampling layers to enhance the stability of the training process.

Compared with traditional convolution network, the proposed work is appropriately modified to adapt to complex three-dimensional problems. First of all, mean pooling rather than max pooling is utilized to implement downsampling. This is because average pooling concentrates more on overall thermophysical parameters, while maximum pooling tends to focus on feature textures (e.g., interfaces of mediums). As shown in Figure 2.14, average pooling extracts the average value of all elements in the current window during each operation.

In addition, the network also introduces a residual module (shown in Figure 2.15) to eliminate precision saturation. As well-known, deep neural networks often suffer from degradation problems. With the increase network depth, precision gets saturated and then degrades rapidly. Surprisingly, this degradation is not caused by overfitting, and introduction of residual structure can alleviate this phenomenon. Assuming that the final function to be fitted is $\mathcal{H}(x)$, and the network first fits $\mathcal{F}(x) = \mathcal{H}(x)-x$. Then the original $\mathcal{H}(x)$ can be expressed by $\mathcal{F}(x)+x$. Related research has demonstrated that fitting identical mapping is much easier than direct fitting functions. Besides, the operator $\mathcal{F}(x)+x$ can be conveniently achieved by skip connection, greatly enhancing the practicality of residual structure. Consequently, it is possible to construct deep networks with more than 100 layers.

## 2.3.4 Loss Functions

For supervised learning, the loss function is a nonnegative real value $f$ selected from hypothesis space $\mathcal{F}$ to measure predicting error. During network training, the direction of optimization is determined by gradient of loss function, hence an appropriate loss function is significant in training. Several commonly used loss functions are listed below:

- A. 0-1 loss function

0-1 loss function is the simplest loss function, which can be defined as

```
$L(y, f(x)) = \begin{cases} 1 & y \neq f(x) \\ 0 & y = f(x) \end{cases} \quad (2.37)$
```

0-1 loss function is easy to calculate and hence commonly used in perceptrons. However, since it is not a convex function, it cannot be used directly in machine learning.

- B. Cross-entropy loss function

Cross entropy loss function is the most commonly used loss function in binary classification, which is defined

```
$L(y, f(x)) = \sum_{i=1}^{n} y_i \log(f(x_i)) + (1 - y_i) \log(1 - f(x_i)) \quad (2.38)$
```

This function is often combined with Sigmoid activation function to solve the gradient saturation problem.

- C. Hinge loss function

The standard form of the Hinge loss function is as follows

```
$L(y, f(x)) = \max(0, 1 - y(x)) \quad (2.39)$
```

This function has good robustness and is insensitive to outliers and noise. However, the defect is the lack of theoretical support from probability.

- D. Exponential loss function

The definition of the exponential loss function is as follows

```
$L(y, f(x)) = \sum_{i=1}^{n} e^{-y_i f(x_i)} \quad (2.40)$
```

This function is adopted in Adaaboost. From the perspective of training, the function will be inclined to punish outliers and endow them with greater weight, which is at the expense of prediction effect of normal data points and may reduce the overall performance of the model or reduce the robustness.
