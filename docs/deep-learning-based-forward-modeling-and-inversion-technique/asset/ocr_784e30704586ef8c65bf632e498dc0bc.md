# ### 1.2.3 Recurrent Neural Network

The recurrent neural network [31] is devised for sequences, which input and output are both time steps. The RNN generally introduces a loop structure that enables information to pass from one time step of the framework to the following by applying a recurrence relation at each step. Supposing the input and output of the RNN can be represented as $X$ and $Y$, where

$X=egin{bmatrix} x_1 \ x_2 \ \vdots \ x_T \end{bmatrix}, Y=egin{bmatrix} y_1 \ y_2 \ \vdots \ y_T \end{bmatrix} \quad (1.35)$
