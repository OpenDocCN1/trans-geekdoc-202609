+   B. Stochastic Gradient Descent

Different from the BGD, the stochastic gradient descent (SGD) only performs the parameter updating for a randomly chosen training example $x^{(i)}$ and $y^{(i)}$.

```
$$\theta = \theta - \eta \cdot \nabla_{\theta} J(\theta; x^{(i)}, y^{(i)})$ (2.53)
```

Since the SGD does not need to calculate the gradient of all data set, it is usually much faster and can be used for online learning. However, a fast updating rate also results in several fluctuations in the loss function. With a slow learning rate decay, SGD can yield almost the same convergence as BGD.

+   C. Adagrad

Compared with the SGD algorithm, the parameter updating of the Adagrad does not directly adapt the gradient but uses the cumulative square gradient. Suppose $g_t$ is the gradient of the loss function, namely

```
$g_t = \nabla_{\theta} J(\theta_t)$ (2.54)
```

The cumulative square gradient $r_t$ is defined as

```
$r_t = r_t + g_t \odot g_t$ (2.55)
```

Finally, the parameter is able to update $r_t$:

```
$$\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{r_t + \epsilon}} \odot g_t$ (2.56)
```

where $\epsilon$ is a smoothing factor that avoids division by zero. It can be found that the optimizer adopts different learning rates at each step, which results in a faster convergence. In fact, one of the merits of this optimizer is that it eliminates the need to manually tune the learning rate. However, as the number of iterations increasing, the denominator of Equation 2.56 becomes larger and larger, and the learning rate gradually declines. After a period, the learning rate eventually becomes infinitesimally small, at which point the Adag is no longer able to exert its influence.

+   D. RMSProp

RMSProp is an improved version of AdaGrad, and the difference between the two is the cumulative square gradient. Unlike AdaGrad, it adds an attentuation coefficient to control the weight of historical information:

```
$$\r_t = \rho r_t + (1 - \rho) g_t \odot g_t$ (2.57)
```

where $\ho$ generally takes 0.9. RMSProp works well in non-convex cases and is therefore suitable for more general cases.
