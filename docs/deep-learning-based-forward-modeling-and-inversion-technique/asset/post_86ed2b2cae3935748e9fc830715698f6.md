The physical field is obtained by using the given boundary conditions and initial conditions. The second problem is parameter extraction, which mainly involves the inversion of various constitutive parameters. ### 1.2.1 Fully Connected Neural Network

The fully connected neural network [19], or FCN for short, is the most basic type of deep learning (DL) network (shown in Figure 1.4). Generally speaking, the network consists of three parts, the input layer, the hidden layers, and the output layer. Supposing that the input of the $i$-th and $i+1$ layer of the network are represented as $X_i$ and $X_{i+1}$, respectively:

```
$X_{i+1} = (W_{i+1}X_i + b_{i+1})$
```

where $W_{i+1}, b_{i+1}$ are the matrix and bias vector of the $i+1$ layer and $\sigma$ denotes the nonlinear activation function. The goal of the FCN is to fit some unknown function. In 1991, Leshno [20] proved that an FCN with a hidden layer can approximate any continuous function $f(x)$ uniformly on a compact set with a non-polynomial activation (such as Tanh, logistic, and ReLU). Mathematically, it can be termed as $\forall \epsilon > 0$, there exists an integer $N$ (the total number of hidden units), as well as parameters $\phi_i, b_i \in \mathbb{R}$ such that the function

```
$F(x) = \sum_{i=1}^N \nu_i(w_i^T x + b_i)$
```

Complies with $|F(x) - f(x)| < \epsilon$ for all $x$. This theorem lays a solid foundation for implementing the network to approximate the unknown functions.

## 1.2.2 Convolutional Neural Network

The CNN is on the basis of the convolutional operator [23, 24], instead of the matrix-vector multiplication of FCNN. A convolution is an operation performed on two vectors, matrices, or even higher-order tensors. This operation originates in signal processing, where the operation of any linear time-invariant (LTI) system on an input can be equivalent to a convolution with

```
$y(t) = x(t) \otimes h(t) = \int_{-\infty}^{\infty} x(\tau)h(t-\tau)d\tau$
```

In signal processing, the convolutions are specified manually, while for the neural networks, the task is to automatically learn parameters of the convolutional kernel and utilize them in conjunction with activation functions. It is noted that the convolution supplies interactions and parameter sharing between neurons in the adjacent layers. For a typical CNN, assuming that the input of the $i$-th and $i+1$-th layer of the network are represented as $X_i$ and $X_{i+1}$, respectively, it has

```
$X_{i+1} = \sigma(\mathbb{P}(X_i \otimes K_{i+1}) + b_{i+1}))$
```

where $\sigma$, $\mathbb{P}$, and $\otimes$ denote the activation function, the pooling, and convolution while $b$ is the bias vector. The 2D convolution is further

### 1.2.3 Recurrent Neural Network

The recurrent neural network [31] is devised for sequences, which input and output are time steps. The RNN generally introduces a loop structure that enables information to pass from one time step of the framework to the following by applying a recurrence relation at each step.
