# 2.3.5.2 Learning Rate

In deep learning, a learning rate $\alpha$ is an important hyperparameter that determines the updating rates of the parameters $	heta$ while moving towards the minimum of the loss function $L(	heta)$. The learning rate satisfies

```
$$\theta = \theta - \alpha \frac{\partial L(\theta)}{\partial \theta}$
```

In fact, it is tough to configure a suitable learning rate since a too-large learning rate jumps over the minima while a too-small one may spend a long time to reach convergence or be trapped in a local minimum. Selecting an appropriate learning rate usually requires multiple pre-experiments.
