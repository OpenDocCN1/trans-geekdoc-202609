# 2.1.2 Numerical Methods

For objects with irregular geometry, numerical methods such as the finite difference method (FDM) [12, 13], the finite element method (FEM) [14, 15, 16, 17] and the finite volume method (FVM) [18, 19] are widely used to solve the heat conduction equation. These methods discretize the domain into non-overlapping elements and establish the corresponding systematic algebraic equations, which can be solved either directly or iteratively. In this section, FDM and FVM are mainly discussed.

The difference method is the most simple and intelligible algorithm whose basic idea is to difference the differential equation into difference. Applying Taylor formula at $(x_0, y_0, z_0)$:

```
$$T(x_0+\delta, y_0, z_0) = T(x_0, y_0, z_0) \pm \frac{\delta x}{2} \frac{\partial^2 T}{\partial x^2} + O(x^2), \quad (2.13)$
```

```
$$T(x_0, y_0+\delta, z_0) = T(x_0, y_0, z_0) \pm \frac{\delta y}{2} \frac{\partial^2 T}{\partial y^2} + O(y^2), \quad (2.14)$
```

```
$$T(x_0, y_0, z_0+\delta) = T(x_0, y_0, z_0) \pm \frac{\delta z}{2} \frac{\partial^2 T}{\partial z^2} + O(z^2), \quad (2.15)$
```

Ignoring the higher-order terms, it obtains that

```
$$$\frac{1}{\delta x^2}[T(x_0+\delta, y_0, z_0) + T(x_0-\delta, y_0, z_0) - 2T(x_0, y_0, z_0)] + \frac{1}{\delta y^2}[T(x_0, y_0+\delta, z_0) + T(x_0, y_0-\delta, z_0) - 2T(x_0, y_0, z_0)] + \frac{1}{\delta z^2}[T(x_0, y_0, z_0+\delta) + T(x_0, y_0, z_0-\delta) - 2T(x_0, y_0, z_0)] \\ = -\frac{\partial^2 T(x,y,z)}{\partial x^2} + \frac{\partial^2 T(x,y,z)}{\partial y^2} + \frac{\partial^2 T(x,y,z)}{\partial z^2} \quad (2.16)$
```

For the steady-state heat conduction in uniform medium, the temperature field satisfies the Poisson equation:

```
$$k\frac{\partial^2 T(x,y,z)}{\partial x^2} + k\frac{\partial^2 T(x,y,z)}{\partial y^2} + k\frac{\partial^2 T(x,y,z)}{\partial z^2} = -Q(x,y,z), \quad (2.17)$
```

where $k$ is the thermal conductivity and $Q$ is the thermal power density.
