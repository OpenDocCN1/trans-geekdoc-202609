## 5 Advanced Deep Learning Techniques in Computational Physics

Computational physics is a new discipline that uses computers and computer science as tools and approaches, applies appropriate mathematical methods, conducts numerical analysis of physical problems, and performs numerical simulation of practical processes. Traditional physics methods include finite difference method [1, 2, 3], finite element method [4, 5, 6], variational dynamics method [9, 10], Monte Carlo simulation method [11]. In recent years, with the continuous development of deep learning technology, new methods combining computational physics with various neural networks emerged. In this chapter, the applications of various deep learning technologies in computational physics are reviewed firstly, and then it will focus on the specific implementation of special methods.

## 5.1 Informed Neural Network

### 5.1.1 Fully Connected-Based PINN

The physics informed neural network uses fully connected neural networks (FCNN) as universal function approximators [13]. The core idea of the fully connected PINN is the automatic differentiation technique [14], which is utilized to differentiate the FCNN with respect to the input coordinates or parameters. An exquisitely devised loss function is employed to constrain the field quantities to respect the corresponding physical laws in the form of partial differential equations. In fact, the FCNN based PINN is able to tackle multidimensional physical problems in computational science.

First of all, it is requisite to establish a DL framework to simulate the operator equation $\mathcal{L}[u] = f$. A prototyped structure includes an input layer, several hidden layers and an output layer, each of which is followed by an activation function. The input element is a vector of $N+1$ dimension, indicating the $N$ spatial coordinates and one temporal coordinate. Next, an elaborately designed loss function [15] is constructed, which can be composed of three parts:

$$\mathcal{L} = \alpha\mathcal{L}_{pde} + \beta\mathcal{L}_b + \gamma\mathcal{L}_i$$

where $L_{pde}$, $L_b$ and $L_i$ are defined as the PDE loss, the boundary loss and the initial loss. The coefficients $\alpha$, $\beta$ and $\gamma$ are adjustable parameters in different models. The three losses are defined as:

$$L_{pde} = \sum_{i=1}^{N_f} |\mathcal{L} [\mathbf{u}(\mathbf{x}, t)] - f|^2$$

$$L_b = \sum_{i=1}^{N_b} |\mathbf{u}(\mathbf{x}_b, t) - \mathbf{u}_b|^2$$

$$L_i = \sum_{i=1}^{N_i} |\mathbf{u}(\mathbf{x}_i, t_0) - \mathbf{u}_0|^2$$

where $N_f, N_b$, and $N_i$ are the number of corresponding sampling points in the equations, boundaries and initials. In Equation 5.2, the derivatives can be derived by implementing the chain rule for differentiating functions via automatic differentiation. Among the physics-informed DL frameworks, the FCNN is the most mature one, which has already been adopted in extensive realms.
