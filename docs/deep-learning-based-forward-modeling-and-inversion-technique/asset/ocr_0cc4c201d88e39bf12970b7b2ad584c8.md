# 2.3.5.3 Dropout Ratio

In the machine learning model, if the number of parameters in the model is much larger than that of the training samples, the model is prone to overfitting. To avoid this phenomenon, the dropout mechanism is necessary, whose core idea is to ignore hidden layers by setting their weights to 0. In this section, the relationship between the dropout ratio p against the loss is investigated. During the training, the loss on the training set for each iteration are recorded and exhibited in Figure 2.21.

It is obvious that the larger the dropout ratio on the training set, the slower the convergence. In fact, researchers are more concerned about loss values on the test set. Therefore, the final convergence value of the training set and the testing set is presented in Figure 2.22.

It can be found that the dropout ratio is greater than 0.05, there is certain underfitting (the error on the test set is less than that on the training set) due to the excessive information lost by activated neurons. However, if no dropout is adopted, the network will overfit (the error on the test set is greater than that on the training set). Ultimately, the dropout ratio on the network is set to 0.05.
