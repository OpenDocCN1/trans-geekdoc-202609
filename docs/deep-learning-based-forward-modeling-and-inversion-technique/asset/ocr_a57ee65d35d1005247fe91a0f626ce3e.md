For instance, in the cylindrical coordinate system, if there is a parallel plate capacitor with internal boundary $r_i = 1$, $V_i = 1V$ and external boundary $V_e = 0V$, respectively the potential satisfies:

> $$\mathcal{L}_i = \sum_{i=1}^N ||u(x_i, t_i) - \mathbf{u}_0||^2$$

Therefore, the equation can be altered to

```
def loss_p(self, x):
    u = self.net(x)
    u_g = gradients(u, x) [0]
    u_rf = u_g[:, 0], u_g[:, 1]
    u_rr = gradients(u_f, x) [:, 0]
    u_ff = gradients(u_f, x) [:, 1]
    loss = u.sum(u.rr+u.ff/(x[:]**2)*2)+u.r/x[:],:0])
    return (loss**2).mean(:)
```
