## 4.5.2.4 Generalization Ability

Generalization ability is a term which describe a DL model's capability to react to new data after being trained on a given training set. In other words, whether a model can digest new examples and make reasonable predictions.

As the samples in the curated dataset have different variation trends with temperature or related materials models, this part merely concentrates on the space-related cases. Here, 1000 specimens with completely diverse samples from the original data set are employed to assess the generalization ability. In order to simulate the inversion of practical products, the data contains specimens with discrete conductivity.

## 4.6 Conclusion

In this chapter, a DL-based thermal conductivity reconstruction model is developed. This network adopts deep learning frameworks to finish the entire process, which is composed of data generation, noise reduction, and thermal conductivity reconstruction. For data generation, the two-dimensional data adopts the method of external commercial software, while the three-dimensional data construction is accomplished by PINN. In virtue of the preponderance of GPU parallel capability, PINN is able to achieve calculation accurately depending on mesh density. For the measurement error, the calculation results of PINN is added with white noise and sent to U-net for denoising. It is noted that the denoising U-net is able to elevate the input of the last module, which is employed to reconstruct the thermal conductivity. The inversion utilized diverse frameworks for 2D and 3D. For 2D cases, the classic fully connected network is introduced, while the nonlinear mapping model is applied in 3D scenarios. The inversion result has promising future of deep learning in the retrieval of parameters. Moreover, as the presented network can attain the inversion procedure in 0.1s, it is confident that this architecture can be broadly applied in real-time scenarios.
