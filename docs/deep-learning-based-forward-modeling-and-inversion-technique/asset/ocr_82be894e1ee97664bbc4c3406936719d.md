# 5.3.2.2 Statistical Analysis

All the three aforementioned researches depicted the predicting capability of the frameworks from the perspective of qualitative analysis. To measure the performance of the framework quantitatively, statistics analyzes are provided. Here, the average relative error is defined as

```
$$Err = \frac{1}{N} \sum_{i=1}^{N} \left| \frac{u_r(i) - u_p(i)}{u_r(i)} \right| \quad (5.55)$
```
