```

In the region, the Laplace equation is satisfied:

$$\nabla^2 U = \frac{1}{r^2} \frac{\partial}{\partial r}(r^2 \frac{\partial U}{\partial r}) + \frac{1}{r^2 \sin \theta} \frac{\partial}{\partial \theta}(\sin \theta \frac{\partial U}{\partial \theta}) + \frac{1}{r^2 \sin^2 \theta} \frac{\partial^2 U}{\partial \phi^2} = 0$$

The analytical solution can be obtained by separating variables:
$$U = \frac{1}{\sqrt{3}} \sin 2\theta \sin \phi$$

### 5.1.1.3 Parabolic Coordinate System

Finally, an uncommon PDE in parabolic coordinates is considered here. The relationship between parabolic coordinate system and rectangular coordinate system:

$$\xi = r(1 + \cos \theta) = \sqrt{x^2 + y^2} + z$$
$$\eta = r(1 - \cos \theta) = \sqrt{x^2 + y^2} - z$$
$$\phi = \arctan(y/x)$$

The Laplace operator is defined as:
```

\frac{\partial^2u}{\partial\xi^2} + \frac{\partial^2u}{\partial\eta^2} + \frac{2}{\xi}\frac{\partial u}{\partial\xi} + \frac{2}{\eta}\frac{\partial u}{\partial\eta}-0.01(\xi+\eta)=0

### 5.1.2 Convolutional-Based PINN

Recently, the convolutional PINN [24, 25] is progressively becoming prevalent for the merits of parameter sharing kernels, spatial feature extraction, and light network weights. Diverse from the FCNN based PINN, the CNN based framework does not fit differential operators, but approximate differential to difference. In a sense, it is similar to the finite difference method. Compared with PINN, the CNN architecture has smaller volume and better generalization performance.

The CNN based PINN consists of two parts, and the parameters of the corresponding kernel are trainable and fixed, respectively. The trainable convolution kernel is the same as the traditional supervised learning, while the fixed convolution kernel is used to calculate the PDE solution. Taking the two-dimensional Laplace operator as an example, the corresponding convolution kernels of different orders are displayed in Table 5.1.

Similar to the network FCNN, the convolution-based loss function can also include two parts, supervision loss and the PDE loss. The supervision loss is the MSE error between the field value of the known space point and the output of the network, while the equation loss is defined as the 2-norm of the convolution of the output physical field and the fixed operator. The total training loss can be defined as the weighted sum of the two:

```math
$$\mathcal{L} = \lambda_1\mathcal{L}_{pde} + \lambda_2\mathcal{L}_{data} \quad (5.20)$$
$$\mathcal{L}_{pde} = ||\mathbf{u} \otimes \mathbf{K}||^2 \quad (5.21)$$
$$\mathcal{L}_{data} = \sum_{i,j}^{N_s, N_t} |u(i,j) - u_0(i,j)|^2 \quad (5.22)$$
```
