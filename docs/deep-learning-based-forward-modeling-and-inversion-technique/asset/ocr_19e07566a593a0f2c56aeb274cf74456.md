Let $x_0 = i\delta, y_0 = j\delta, k_0 = k\delta$, then Equation 2.16 can be simplified to

```
$6T(i, j, k) = T(i+1, j, k) + T(i-1, j, k) + T(i, j+1, k) + \nT(i, j-1, k) + T(i, j, k+1) - \frac{\delta^2 Q(i, j, k)}{k}$  (2.18)
```

In each iteration, each point (except for the boundary points) is represented by the arithmetic average of the six points around it. As the proceeds, the temperature finally reaches convergence. Although the finite difference method is intuitive and easy to program, it is not suitable for engineering problems with complex boundary conditions. Hence it is seldom used in commercial software.

Another commonly used numerical algorithm is the finite element method (FEM), Firstly, the whole space is discretized into $E$ elements, each of which contains $p$ nodes. Then the temperature at any point in the solving region can be expressed by the temperature interpolation at these nodes:

```
$T = \sum_{i=1}^{p} N_i(x, y, z) T_i^e = [N]\{T\}^{(e)}$  (2.19)
```

where $N_i$ is the weight of each node. Applying the variational principle, solving the unknown temperature field is equivalent to solving the extremum of the functional II:

```
$\Pi = \sum_{e=1}^{E} \Pi^{(e)}$  (2.20)
```

where

```
$\Pi^{(e)} = \frac{k}{V(e)} \iiint \left[ \left(\frac{\partial T^{(e)}}{\partial x}\right)^2+\left(\frac{\partial T^{(e)}}{\partial y}\right)^2+\left(\frac{\partial T^{(e)}}{\partial z}\right)^2-2qT^{(e)}ight] dV$  (2.21)
```

Introducing the necessary conditions of extremum:

```
$\frac{\partial \Pi}{\partial T_i} = \sum_{e=1}^{E} \frac{\partial \Pi^{(e)}}{\partial T_i} = 0, (i=1, 2, 3, \cdots, K)$  (2.22)
```

where $K$ is the total number of node temperature unknowns. Applying Equation 2.19 and considering all the nodes, it can be assured that

```

```
