### 3.3.3.2 Recurrent Neural Network

The temperature at the sampling is affected by the heat flux at times and locations during the whole heat transfer process of the experiment. The influence of two characteristics of time and space on the temperature should be taken into account when building the neural network, so the neural network used should contain two characteristics at the same time. Since the inverse heat problem to be solved in this experiment can be considered an evolutionary inverse problem of a dynamic problem, the RNN is a potential solution.

The classical RNN [23] is a kind of neural network used to process sequence data. Time series data refers to the data collected at different time points, and there is a logical relationship between the early and late data. For a standard RNN, with forward propagation algorithm is quite clear. The formula can be expressed in the following form:

$h(t) = \phi(Uz(t) + Wh(t) + b)$

$o(t) = Vh(t) + c$

$y(t) = \sigma(o(t))$

where $\phi$ and $\sigma$ are activation functions, $U, W$ and $V$ are weights, while $b$ and $c$ are offsets. The classical RNN structure is prone to suffer from the vanishing problem, so it is difficult to solve the long-term memory problem. In order to solve this problem, researchers have constructed a long-term memory network (LSTM) [24]. There are three gates in a single neuron of LSTM to protect and control the cell state: the first is called the forget gate, which will read two kinds of information $h_{t-1}$ and $x_t$ from the previous step, and output a value of 0-1 to the cell state $C_{t-1}$ to influence the influence of the previous cell state on the subsequent state. The formula can be written as:

$f_t = \sigma(W_f[h_{t-1}, x_t] + b_f)$

Next, an update gate determines the new memory stored in the cell state, which represents the selective forgetting of information. Finally, an output gate uses the activation function to generate a new candidate vector. The expression of these gate structures can be expressed

$i_t = \sigma(W_i \cdot h_{t-1}, x_t + b_i)$

$\hat{C}_t = \tanh(W_c \cdot [h_{t-1}, x_t]) + b_c$

Through the control of these two gates, the change of state $\hat{C}_t$ in LSTM neuron as follows:

$C_t = f_t \circ C_{t-1} + i_t \circ \hat{C}_t$

The final output $h_t$ of the network will be to set the output and the next neuron, respectively to participate in controlling the forgetting gate. Therefore, $h_t$ and $o_t$ meet the following expressions:

$H_t = o_t \circ \tanh(C_t)$

$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$

### 3.3.3.3 Convolutional LSTM

Shi et al. ConvLSTM [25], which has incorporated the convolution structure in the transition from the input state to output state. By coding multiple ConvLSTM layers and adding LSTM and fully connected layers, a network model can be established for IHCP in 3D case. The main disadvantage of classical FC-LSTM in processing spatial-temporal data is it does not encode spatial information. To overcome this, the input $x_1, \dots, x_t$, cell state $C_1, \dots, C_t$, hidden state $H_1, \dots, H_t$ and gate structure $i_t, f_t, o_t$ of ConvLSTM are all 3D tensors, and the first two dimensions of them are spatial dimensions (row and column). Therefore, it can store different spatial information in different channels, which can be achieved by using convolution operators in transformation. The core formula of ConvLSTM can be written in the following forms, where “$\circ$” represents the convolution operator and “$\cdot$” represents the Hadamard product:

$i_t = \sigma(W_{xi} \cdot x_t + W_{hi} \cdot H_{t-1} + W_{ci} \circ C_{t-1} + b_i)$

$f_t = \sigma(W_{xf} \cdot x_t + W_{hf} \cdot H_{t-1} + W_{cf} \circ C_{t-1} + b_f)$

$C_t = f_t \circ C_{t-1} + i_t \circ \tanh(W_{xc} \cdot x_t + W_{hc} \cdot h_{t-1} + b_c)$

$o_t = \sigma(W_{xo} \cdot x_t + W_{ho} \cdot H_{t-1} + W_{co} \circ C_t + b_o)$

$H_t = o_t \circ \tanh(C_t)$

If the state is regarded as the extraction of moving objects, the ConvLSTM with a larger kernel should be able to capture faster motion, while the one with a smaller kernel can capture slower motion. Similarly, FC-LSTM can be seen as special case of ConvLSTM, that is, the row and column to 1 to change the input tensor to a one-dimensional entity.

ConvLSTM can be used as the layer structure of a more complex framework, so for the spatial-temporal sequence IHCP, the network shown in Figure 3.8 is used. The architecture consists of three layers of ConvLSTM, two layers of FC-LSTM and one layer of fully connected layer. In order to capture the spatial features with less iterations, the convolution kernel of the network gradually decreases from the first to the last. Therefore, the framework can collect spatial information of different scales. Due to the change of depth, the thinner position will get more heat flux from the outer surface, while the thicker position. The first layer sets two filters to receive space information and heat flux respectively, with the size of 4x4. The second ConvLSTM layer attends to collecting the results of the two filters. By minimizing the filter and unifying the two channels, its output can be considered as a combination of spatial information and heat flux. Therefore, the input of LSTM layer can be considered as an unbiased 3D heat flux after preprocessing. With, the difficulty of capturing time information and establishing the relationship between heat flux and temperature is reduced. The first layer of LSTM is set as the sequence returned by each time step, because it will help to find the relationship between temperature and heat flux accurately. At the last layer, LSTM attends to a sensitivity coefficient for each time step to ensure that the temperature at different times has an appropriate impact on the heat flux at a given time.
