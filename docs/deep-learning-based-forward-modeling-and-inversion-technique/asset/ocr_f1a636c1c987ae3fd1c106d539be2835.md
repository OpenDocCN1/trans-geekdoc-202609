+   E. Softsign function

Softsign is an activation function commonly used to substitute tanh whose' expression is :

```
softsign(x) = \frac{x}{1+|x|} \quad (2.49)
```

As displayed in Figure 2.18 (e), like tanh, this function is also monotone increasing and maps $(-\infty, \infty)$ to $(0, 1)$. However, an important advantage is that it is less prone to saturation than tanh.
