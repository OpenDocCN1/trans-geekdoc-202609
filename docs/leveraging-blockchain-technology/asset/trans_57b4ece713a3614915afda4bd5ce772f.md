# 第 3 章 区块链技术中的运营风险

Aditya Jayeshkumar Bhatt and Kesha Sisodia

DOI: [10.1201/9781003462033-4](https://dx.doi.org/10.1201/9781003462033-4)

## 背景

区块链已显著扩展超出其加密货币根源，渗透到各个企业。众多行业，包括金融、医疗保健、制造业和教育，都使用区块链应用来利用该技术的独特特性。使用区块链，数据存储在分布式账本中。由于区块链技术提供的完整性和可用性，区块链网络中的参与者可以创建、读取和验证存储在分布式账本中的交易 [[1](#ch3.xhtml#ref3_1)]。另一方面，区块链禁止删除和修改其账本中保存的任何交易或其他数据。数字签名、哈希函数以及各种加密映射和协议有助于维护和保护区块链系统。哈希函数和数字签名确保添加到账本中的交易不可否认、真实且完整受保护。此外，作为一个分布式网络，区块链技术还需要一种共识机制，本质上是一套指导方针，允许所有成员就单一记录达成一致 [[2](#ch3.xhtml#ref3_2)]。区块链安全值得进一步研究，因为它在不涉及第三方的情况下实现去中心化，并且需要在无信任架构中建立信任。区块链具有影响组织能力的特定运营挑战 [[3](#ch3.xhtml#ref3_3), [4](#ch3.xhtml#ref3_4)]。

## Discussion

*运营风险* 是指因人员、内部系统和流程不足或失效，或无法控制的外部事件而遭受损失的风险。每项新技术都有利有弊，必须加以识别和控制。当技术代表组织底层 IT 基础设施的基本组成部分，而不仅仅是覆盖层应用程序时尤其如此，而区块链经常就是这种情况 [[5](#ch3.xhtml#ref3_5)]。实施基于区块链的应用需要处理多种运营风险，包括人员-流程-系统风险。

### 区块链技术中的人员风险
