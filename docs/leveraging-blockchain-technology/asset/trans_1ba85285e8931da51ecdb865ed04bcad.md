
# DDoS 和 DoS 攻击

*DDoS攻击* 发生在多个系统协同对单个目标发起同步的 *DoS攻击* 时。该攻击是对目标服务器、服务或网络进行恶意破坏的尝试，通过向目标发送过量的流量来淹没目标。DDoS攻击是利用互联网连接的设备网络进行的。这些网络由计算机和其他设备组成，例如已被恶意软件感染的物联网（IoT）设备，使攻击者能够远程管理这些设备 \[[42](#ch5.xhtml#ref5_42)\]。DDoS攻击与DoS攻击的主要区别在于目标是从多个位置同时受到攻击，而非单一位置。DoS攻击旨在关闭计算机系统或网络，使预期用户无法访问文件和数据。DoS攻击通过向目标系统或网络发送过量的流量或信息导致崩溃，从而实现系统关闭。DoS攻击拒绝了合法用户（如员工、成员或账户持有人）所期望的服务或资源。执行DoS攻击使用两种方法。这些方法是对服务进行泛洪攻击或导致服务崩溃。泛洪攻击发生在系统接收到的流量超过服务器缓冲能力时，导致系统变慢并停止。DoS攻击的一种类型是DDoS攻击 \[[43](#ch5.xhtml#ref5_43)\]。2017年，全球最大的加密货币交易所之一的 *Bitfinex* 遭受了DDoS攻击。该攻击是不到一周内的第二次尝试。结果，比特币价格下跌2%，跌至7,373.47美元。该攻击仅影响交易操作，用户账户及相关资金/余额在攻击期间未受风险。*Bitfinex* 于2012年在香港成立，起初是一个点对点比特币交易所。该公司后来增加了对其他加密货币的支持 \[[44](#ch5.xhtml#ref5_44)\]。

## 系统级攻击

系统级攻击包括自私挖矿攻击、贿赂攻击、加密劫持攻击、扣留后分叉攻击和恶意软件攻击。*自私挖矿攻击*（也称为 *区块扣留攻击*）发生在恶意矿工扣留新挖出的区块时。攻击者（矿工）通过不向网络广播已挖出的区块来增加奖励份额。相反，矿工将区块保密并在网络上开始创建自己的分支。矿工随后一次性发布多个区块，导致其他矿工失去原本发布的区块。恶意矿工通过发布区块获得不公平的收入。矿工专注于三区块策略以使攻击成功。在私有分支上继续挖矿，直到私有分支比主分支长三个区块。当用户（矿工）找到下一个区块时，攻击者立即发布私有分支。攻击者随后可以依据PoW协议成功领取奖励。用户的计算能力被浪费，且没有收入或投资回报 \[[45](#ch5.xhtml#ref5_45)\]。2018年，名为 *Monacoin* 的日本加密货币遭受了自私挖矿攻击。该攻击造成约90,000美元的损失。该攻击被认定为自私挖矿攻击，其中一名矿工成功在区块链上挖出一个区块但未向其他矿工广播该新区块。如果找到第二个区块，秘密矿工可以成功创建一条比常规链更长的分支。根据大多数区块链协议，区块最多的链被视为正确的链，因为它是拥有最多PoW的链。当最长的链公开时，其他矿工发现的所有其他区块都会失效。在 *Monacoin* 的案例中，攻击者将加密货币发送到国外的其他交易所。提供的例子是 *Livecoin*。该攻击的目的是在隐藏的链公开之前用其他货币交换加密货币。该矿工拥有执行攻击所需的计算能力，并在某一时刻占据了超过57%的算力。攻击者（矿工）一直在试图利用 *Monacoin* 调整其难度的方式中的缺陷 \[[46](#ch5.xhtml#ref5_46)\]。

*贿赂攻击* 发生在攻击者以大约的成本租用一定空间时。假设每挖出一个区块的成本为 `B`，其中 `B` 是一个区块的挖矿奖励。攻击者在区块 `B` 中发布交易 `T`，并等待其他区块发布，以便因 `T` 而采取不可逆的操作，然后引入一个包含冲突交易 `T` 的新区块 `B`。攻击者随后租用足够的算力来扩展包含 `B` 的分支，直到它成为最长的分支。最终结果是攻击者对交易 `T` 中的资金进行了双重花费，并且可以获得等于 `T` 价值的利润 \[[47](#ch5.xhtml#ref5_47)\]。

*加密劫持攻击* 是一种顶级攻击，发生在攻击者未经授权访问并滥用用户设备的计算能力来挖矿加密货币时。该攻击以感染用于挖矿的设备的恶意软件形式传播。目标可以是任何设备：计算机、智能手机或云服务器。当设备被恶意软件感染时，它会控制设备的计算能力并控制其中一部分来挖矿特定加密货币。挖出的币最终会被发送到攻击者的钱包。该攻击的动机是盈利，但它专门设计为对用户保持隐藏 \[[48](#ch5.xhtml#ref5_48)\]。Crypto-jacking攻击发生的一个例子是在2018年。*Tesla* 的云系统被攻击者劫持，用于挖矿加密货币。攻击者能够渗透Kubernetes管理控制台，因为它未受密码保护。*Kubernetes* 是一个 *Google设计的* 系统，用于优化云应用程序。公司 *亚马逊网络服务 (AWS)* 账户的访问凭证被泄露，攻击者部署了 *Stratum*，一种加密挖矿软件，利用云的计算能力挖矿加密货币 \[[49](#ch5.xhtml#ref5_49)\]。
