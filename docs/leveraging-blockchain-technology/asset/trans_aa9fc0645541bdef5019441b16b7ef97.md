
多个国家尚未建立监管框架以采用加密货币。例如，在印度，像比特币这样的虚拟货币不被接受为法定货币 [[7](#ch6.xhtml#ref6_7)]。另一个被确定的缺点是加密货币在全球范围内的法律可接受性和监管。加密货币在当前状态下不太可能稳定到足以用作货币。加密货币估值困难，原因在于缺乏可比交易、买卖订单之间的价格差异以及用于交易的交易所 [[8](#ch6.xhtml#ref6_8)]。

## 非同质化代币的属性

`NFTs` 是非货币数字资产，通常使用与加密货币相同的编程开发，与其他加密资产不同，它们不能相互交易或交换 [[9](#ch6.xhtml#ref6_9)]。NFT 是一种在区块链上运行的加密资产类型，为每个收集的对象分配唯一的标识。由于标识无法复制，数字资产的所有者得以确定 [[9](#ch6.xhtml#ref6_9)]。由于 NFT 的独特数据，确认所有权和在所有者之间转移代币变得简单 [[9](#ch6.xhtml#ref6_9)]。能够公开验证相关代币元数据的能力最能描述 NFT 的特性 [[10](#ch6.xhtml#ref6_10)]。因此，NFT 是只能由一个人拥有的独占资产 [[9](#ch6.xhtml#ref6_9)]。购买、出售和铸造 NFT 以透明的方式向公众开放。由于系统没有停机时间，已发行的 NFT 和代币可供买卖，因此可用性得以保证。NFT 也具有防篡改性，因为数据无法被操纵，并且它们可以自由交易和交换 [[10](#ch6.xhtml#ref6_10)]。此外，NFT 被设计为不可分割以最大化利用率。NFT 价值的基础理念之一是稀缺性。因此，NFT 生产者可以制造大量 NFT，但设有上限以确保稀缺性 [[11](#ch6.xhtml#ref6_11)]。简而言之，NFT 是以密码学安全的方式确立底层资产所有权的代币。此外，NFT 促进包容性增长，因为它们支持公平增长，NFT 将来自各行业的內容生产者连接在一个生态系统中，从而实现对所有参与者公平的增长 [[12](#ch6.xhtml#ref6_12)]。

## NFT 的局限性

目前，NFT 的价值完全取决于其视觉和情感吸引力。由于无法将其估值作为长期投资，它目前仅仅是一种高度投机的资产。一些 NFT 安全漏洞已经发生，主要是黑客所为，因为许多交易所采用了低效或过时的安全机制。区块链交易除了 NFT 的创建和销售外，还消耗大量算力。据一些科学家称，NFT 市场的增长可能会进一步损害正在迅速枯竭的环境 [[13](#ch6.xhtml#ref6_13)]。Lidén 报告称，NFT 当前的共识方法（工作量证明）消耗大量能源并造成负面环境影响 [[14](#ch6.xhtml#ref6_14)]。原始 NFT 的所有权无法控制原始 NFT 在各平台上的分发或复制 [[13](#ch6.xhtml#ref6_13)]。由于 NFT 的不可变性，在欧盟的 GDPR（通用数据保护条例）等数据保护法规方面存在一些担忧。遵守“被遗忘权”具有挑战性，因为无法删除保存在区块链上的潜在用户数据 [[14](#ch6.xhtml#ref6_14)]。此外，由于 NFT 的匿名性以及需要在不同司法管辖区遵守现有法律合同框架，通过所有权验证在法律上执行智能合约可能具有挑战性 [[14](#ch6.xhtml#ref6_14)]。

## NFT 估值与财务报告

知识产权问题是 NFT 风险和挑战清单上的下一个关键问题。因此，当 NFT 被收购时，所有者获得的仅仅是使用权，而非知识产权。据 Rehman 等人（2021）报道，随着数字世界的扩展和 NFT 交易的增加，网络安全和欺诈风险正在增加。提及智能合约风险和 NFT 维护的挑战也是当前 NFT 领域的主要关注点之一。智能合约开发和安全是 NFT 环境中的其他关键问题。此外，智能合约交易和代码都是不可变的，这意味着程序员有责任确保代码的安全，并且交易无法被更改。没有为开发人员在整个项目中应遵循的智能合约设计定义标准程序 [[15](#ch6.xhtml#ref6_15)]。根据 101 Blockchains 的说法，市场上提供的绝大多数 NFT 均作为证券出售。然而，NFT 现在已被纳入最高法院对投资合同的定义中。为了证明 NFT 作为证券的资格，它们必须遵守 Howey 测试的独特要求。此外，由于 NFT 的去中心化性质以及缺乏中央权威监督和司法管辖挑战，可能出现 AML（反洗钱）和 CFT（打击恐怖主义融资）问题 [[16](#ch6.xhtml#ref6_16)]。

## NFT 与加密货币的相似之处和差异

如前所述，加密货币和 NFT 之间的相似之处在于两者都是存在于区块链上的数字资产，可以买卖。区块链记录所有交易，使得确认 NFT 或代币的合法性变得简单。根本区别在于，加密货币的价值完全由其作为货币或投资的经济功能决定。另一方面，NFT 具有经济和非经济价值。例如，艺术家可以使用 NFT 分享、推广甚至签署他们的作品，然后投资者或收藏家可以用比特币购买。互换性方面是最显著的区别，其中加密币是可互换的或相互可替代的，而 NFT 具有独特价值。加密币投入流通的方式是另一个区别，因为 NFT 是铸造的，而币是挖矿产生的 [[17](#ch6.xhtml#ref6_17)]。
