
# 身份管理模型

## 集中式 IDM 模型

集中式 `IDM` 模型在 1990 年至 2000 年间出现，当时在线服务成为数字身份的签发者和保管者。 
证书颁发机构开始签发官方数字证书以建立对在线服务的信任。 
然而，数据的控制权和所有权仍保留在在线服务提供商手中，而非用户 \[[2](#ch7.xhtml#ref7_2)\]。 
集中式身份模型，也称为基于账户的身份，代表了数字身份的原始形式。 
它适用于各种身份和凭证，包括政府身份证号码、护照、身份证、驾驶执照、发票、Facebook 登录名和 Twitter 账号。 
在网站、服务或应用程序上建立在线身份涉及使用用户名和密码创建账户 \[[3](#ch7.xhtml#ref7_3)\]。 
在集中式 `IDM` 模型中，组织向用户提供凭证，通常以用户名和密码的形式，使其能够访问其服务。 
组织存储和管理用户的个人信息，信任关系依赖于共享密钥。 
该模型要求用户希望访问的每个组织或系统都使用单独的凭证 \[[4](#ch7.xhtml#ref7_4), [7](#ch7.xhtml#ref7_7)\]。 
该 `IDM` 模型的例子是企业在 `Windows Server 2003` 之前使用的传统 `Microsoft Active Directory Domain` (`ADDS`)。

## 联邦身份管理模型 (IDM 2.0)

联邦身份模型在 2000 年至 2008 年间盛行，允许用户在多个服务中使用单一登录以获得无缝的客户体验。 
与集中式数字身份的主要区别在于能够将数字身份从一个在线服务迁移到另一个 \[[2](#ch7.xhtml#ref7_2)\]。 
作为对集中式身份带来的挑战的回应，联邦身份模型被开发出来。 
该模型涉及用户、身份提供者 (`IDP`) 和依赖方或组织之间的三方关系。 
通过该模型，用户可以利用单一身份账户登录并与使用 `IDP` 的任何应用程序、服务或网站共享必要的身份信息 \[[3](#ch7.xhtml#ref7_3)\]。 
*Naik and Jenkins* \[[7](#ch7.xhtml#ref7_7)\] 指出，联邦身份管理 (`FIDM`) 为传统集中式身份管理 (`IDM`) 系统中遇到的挑战提供了解决方案。 
`FIDM` 的主要好处包括组织能够将身份管理委托给第三方 `IDPs`，这些提供者不仅保护凭证和身份信息，还能简化业务运营。 
用户可以通过单点登录 (`SSO`) 使用单一身份凭证访问多个系统，从而享受便利。 
`IDP` 持有并控制用户的个人信息。 
`FIDM` 的常用示例是 `Microsoft Azure Active Directory` (`AzureAD`)，在企业环境中用于企业对企业 (`B2B`) 和企业对客户 (`B2C`) 身份验证，`IDPs` 如 Facebook 和 Google \[[4](#ch7.xhtml#ref7_4)\]。

## 自主式身份管理模型

随着区块链技术的出现，第三类数字身份 – `SSI` – 已出现。 
近年来，围绕 `SSI` 的学术和政治辩论日益增多，其设想了一种独立的公民身份。 
关于 `SSI` 的讨论相对较新，对该领域研究的科学贡献有限。 
然而，它为在公共部门身份方案中实施 `SSI` 系统提供了机会和先决条件 \[[8](#ch7.xhtml#ref7_8)\]。 
简而言之，`SSI` 指的是一种数字身份类型，用户对其信息可以被谁访问以及在何种情况下访问拥有完全控制权和决策权 \[[5](#ch7.xhtml#ref7_5)\]。 
换句话说，`SSI` 基于用户拥有的身份，使其能够控制自己的数据。 
鉴于常用物理和数字 ID 相关的可用性、信任和隐私问题，`SSI` 变得越来越必要 \[[1](#ch7.xhtml#ref7_1)\]。 
它提供了一种手段，用于向需要安全连接以访问或保护敏感信息的网站、服务和应用程序验证我们的身份。 
`SSI` 依赖于密码学、分布式网络、云计算和智能手机等前沿技术和标准，预示着数字身份的新时代。 
尽管 `SSI` 的具体细节仍在演变，但其设计良好且连贯的特性已获得广泛认可 \[[3](#ch7.xhtml#ref7_3)\]。 
本质上，`SSI` 可被视为一种数字身份框架，将个人或企业置于控制中心，使其能够决定其身份和信息如何被使用和共享。 
尽管 `SSI` 并非独立技术，而是常在区块链技术的背景下讨论，但爱好者正在积极探索其实施 \[[8](#ch7.xhtml#ref7_8)\]。 
区块链技术的去中心化特性被利用于 `SSI` 系统的数字点对点平台中，该平台建立在信任三角的基础之上 \[[5](#ch7.xhtml#ref7_5)\]。 
`SSI` 的出现代表了互联网上数字身份的革命性转变。

## 讨论

### SSI 的机制

如前所述，`SSI` 是一种不依赖于或受制于其他权力或国家的个人身份。 
`SSI` 并非指自我断言的身份，相反，因为个人的身份信息来自可信来源，其他方愿意并能够依赖它。 
`SSI` 不仅仅关乎人们的隐私、安全和个人数据控制；它适用于互联网上需要身份的任何组织或事物。 
`SSI` 不仅有助于解决互联网身份层问题，还将控制权从集中式或联邦实体转移到个人用户 \[[3](#ch7.xhtml#ref7_3)\]。 
根据 Naik 和 Jenkins 的说法，自主 `IDM` 模型通过允许用户与组织之间直接连接改进了联邦 `IDM` 模型。 
数字钱包的使用解决了用户管理其与身份相关的个人信息的问题。 
数字钱包保留这些数据，这些数据由用户在其设备上拥有和监管。 
在其生态系统中，`SSI` 承担三个主要功能：`Issuer`、`Holder` 和 `Verifier`。 
持有者从签发者处接收凭证并保存，在必要时与验证者共享。 
验证者接收并检查持有者提供的凭证。 
为了建立一个密码学安全且数字可验证的身份，且完全由其所有者控制，`SSI` 的实施利用了新标准，包括可验证凭证 (`VC`) 和去中心化标识符 (`DIDs`)。 
`DID` 是一种独特且持久的标识符，不能从其持有者处被夺走，这与域名、IP地址或手机号码等临时标识符不同 ([表 7.1](#ch7.xhtml#table7_1)) \[[7](#ch7.xhtml#ref7_7)\]。
