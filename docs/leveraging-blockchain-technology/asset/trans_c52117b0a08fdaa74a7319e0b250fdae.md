
# 区块链治理

在去中心化的区块链网络中，节点之间达成共识对于数据的验证和安全至关重要。同样，改变利益相关者组织网络中的规章制度和流程需要这些利益相关者之间达成共识。去中心化网络和平台内的治理机制不断演进，以在公平和包容的方式促进对更新、路线图和争议解决的决策，因为这些过程没有中央权威进行监督。区块链治理模型在定义项目的去中心化程度、可访问性、公平性以及平衡不同利益相关者利益的能力方面发挥着关键作用。

了解区块链治理的运作方式涉及探索各种治理模型。这些模型揭示了去中心化系统内部决策的复杂动态。一些最受欢迎的治理模型包括 \[[1](#ch2.xhtml#ref2_1)\]：
*   *利益相关者共识*：一种普遍的做法是在利益相关者网络中达成共识。该模型强调集体协议在实施变更或解决区块链网络内的争议方面的重要性。
*   *去中心化决策*：区块链治理的一个关键方面是缺乏中央权威。决策通过去中心化的流程集体做出，确保了管理网络的分布式和包容性方法。
*   *平衡利益相关者利益*：成功的区块链治理模型在不同利益相关者的利益之间取得微妙平衡。这涉及考虑参与者的多样化需求和偏好，以确保公平和可持续的系统。
*   *更新的适应性机制*：区块链技术不断发展的特性需要适应性治理机制。这些机制使网络能够有效地纳入更新和变更，确保其随着时间的推移保持韧性和相关性。

如前所述，区块链网络采用的治理策略对其功能、安全性和可持续性至关重要。通过理解塑造决策过程的多样化模型，利益相关者可以积极促进去中心化系统的演进。

## 链下治理机制

链下治理机制通常被认为是非正式和谨慎的，在普通用户、矿工、商业实体和其他社区利益相关者等各种终端用户之间保持平衡。这种治理方法依赖于区块链生态系统内所有相关方对必要更新和实施的集体认可和同时执行 \[[20](#ch2.xhtml#ref2_20)\]。它使未被协议本身授权的外部实体能够干预区块链协议。在无法达成共识的情况下，网络可能会发生分叉，导致使用不同软件版本的两条链，拥有最高交易算力的链被视为原链的继承者 \[[2](#ch2.xhtml#ref2_2)\]。

在链下模型中，协议开发在各种论坛中进行，例如会议、互联网论坛和邮件列表。审视影响决策的非正式链下流程揭示了这些程序有时存在问题。一个值得注意的例子是比特币社区内的区块大小辩论，其核心问题是是否增加区块大小以提高交易处理能力。这场辩论在各种链下平台和活动中展开，涉及协议、争论、会议上的面对面讨论以及区块链分叉的威胁和执行。这场辩论的一个典型结果是 *比特币现金* 作为一条独立的区块链出现，其代码几乎相同，已与主比特币区块链失去共识 \[[14](#ch2.xhtml#ref2_14)\]。

尽管有其优点，链下治理有两个明显的缺点。首先，登记单个用户的意见可能具有挑战性；其次，变更的实施可能缓慢生效 \[[14](#ch2.xhtml#ref2_14)\]。这些缺点凸显了需要仔细考虑和完善链下治理机制以应对潜在挑战并提高整体有效性的必要性。

## 链下治理的参与者

链下治理涉及一系列步骤，从核心开发者通过官方渠道提出对协议的修改开始，例如 *比特币改进提案 (BIPs)* 和 *以太坊改进提案 (EIPs)*。这些提案通常记录在项目的官方存储库中，通常托管在平台如 *GitHub* 或 *Microsoft* 上。利益相关者，包括核心开发者、矿工和其他感兴趣的各方，参与私人和公开讨论以表达对拟议改进的赞成或批评。

随后，核心开发者评估节点所有者和矿工采用拟议软件更新的意愿。在理想情况下，会达成一致同意，代码变更的实施将顺利进行。通过提前宣布变更实现的透明沟通，在整个过程中让利益相关者充分了解情况方面发挥着至关重要的作用。

当利益相关者无法达成共识时，他们面临两个选择。最初，他们可能会尝试说服其他相关方支持其观点。如果共识仍然难以实现，另一种选择是启动协议的 *硬分叉*。这使利益相关者能够维护或更改他们认为必不可少的特性，导致区块链分裂为两条独立的路径 \[[21](#ch2.xhtml#ref2_21)\]。

总之，链下治理的关键参与者包括核心开发者、表达意见的利益相关者以及在拟议协议变更的实施中发挥关键作用的节点所有者和矿工。链下治理的成功依赖于有效的沟通、共识建设努力；以及在必要时驾驭和管理协议分叉的能力。

## 链下治理的类型

在 PoW 区块链系统领域，比特币和以太坊都采用链下治理机制。值得注意的是，比特币协议的重要更新会在相关各方之间进行积极的在线讨论。比特币核心开发团队定期举行开放公众的在线会议，在会上讨论重要事项。虽然持有比特币在链下讨论中提供发言权，但由于比特币缺乏治理代币，因此不赋予投票权。因此，比特币网络中的所有通信和投票流程均在链下进行。

需要注意的是，尽管比特币中大型矿池的算力与感知到的政治影响相关，矿工并不拥有独特的治理权利。他们的角色仅限于批准或否决交易区块，比特币算力的分配并不等同于治理权力的分配。

同样，以太坊的治理结构与比特币非常相似，强调链下沟通和决策 \[[21](#ch2.xhtml#ref2_21)\]。这两个区块链系统都依赖于开放讨论和利益相关者的集体输入，体现了对去中心化治理原则的共同承诺。
