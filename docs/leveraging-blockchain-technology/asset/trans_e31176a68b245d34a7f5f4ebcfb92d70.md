
区块链技术被视为微型金融机构实现其金融发展承诺的潜在解决方案。其消除中介的能力为难以获得传统金融服务的人群提供了经济自主权。在巴西，三分之一的人口面临受限的金融获取渠道和高利率，基于区块链的初创公司 `Moeda` 与当地信用合作社合作，将负担得起的服务扩展到农村地区 \[[11](#ch11.xhtml#ref11_11)\]。

正如 `Sweet Bridge` 首席执行官 Scott Nelson 所强调的，区块链的关键优势之一是其能够利用现有的亲和网络来建立和验证借款人身份 \[[11](#ch11.xhtml#ref11_11)\]。这尤其重要，因为全球约有 17 亿人由于身份识别不足而无法获得银行账户 \[[12](#ch11.xhtml#ref11_12)\]。区块链被认为是可以解决身份问题的首选技术，并为个人提供必要的数字身份识别，即数字 ID，以便获取银行、政府福利和教育等基本服务 \[[13](#ch11.xhtml#ref11_13)\]。

设计有效的数字 ID 项目需要仔细考虑基础设施、治理以及法规合规性。数据隐私政策对于确保个人对其数据的控制以及机构对其的负责任处理至关重要。数字 ID 可用于遵守要求金融服务身份识别的法规，但必须努力避免排除没有数字 ID 的个人或选择不使用数字 ID 的个人 \[[14](#ch11.xhtml#ref11_14)\]。

世界各地的政府正努力通过各种数字举措将人口纳入正规经济。例如，中国依赖国内科技公司和与金融机构账户关联的智能手机应用程序进行金融交易。印度已成功实施了全球最大的数字生物识别 ID 项目，而肯尼亚以其移动货币模式而闻名，通过移动账户提供定制化金融服务 \[[13](#ch11.xhtml#ref11_13)\]。

`Kiva Protocol` 是塞拉利昂政府与微型贷款初创公司 Kiva 之间的合作，是解决金融获取障碍的公私合作伙伴关系的范例。该协议建立了一个数字基础设施，允许金融机构、客户和政府机构之间进行安全的数据交换。它解决了合法身份识别和经验证的信用历史的缺乏问题，使塞拉利昂人能够使用指纹开设银行账户，并整合生物识别和分布式账本技术。该项目旨在鼓励银行向此前被忽视的、没有信用历史的个人提供贷款 \[[12](#ch11.xhtml#ref11_12), [15](#ch11.xhtml#ref11_15)\]。

通过利用区块链技术和数字 ID 系统，微型金融机构和政府可以克服金融包容性的障碍，赋能个人并促进经济发展。这些举措展示了区块链革新金融服务获取潜力的能力，尤其针对服务不足的人群。

`BanQu` 是一种开创性解决方案，利用区块链技术创建经济身份并促进金融包容。它为没有官方凭证或信用记录的个人提供数字身份。用户可以使用任何手机并以任何语言在 BanQu 上创建账户。平台上的交易记录在区块链上，确保安全性和不可篡改性。诸如土地所有权、疫苗记录、汇款收入和微型贷款历史等可信度证明可以整合以获取微型贷款 \[[16](#ch11.xhtml#ref11_16)\]。区块链的去中心化特性确保所有交易合作伙伴对个人数据拥有平等的访问权和所有权，有助于形成个人的经济身份 \[[16](#ch11.xhtml#ref11_16)\]。

印度政府推出了 `Aadhaar`，这是一个数字 ID 项目，为个人分配 12 位个人识别号码并将其与其指纹和虹膜扫描关联。Aadhaar 与 Kiva Protocol 类似，旨在提供可靠的身份识别系统 \[[12](#ch11.xhtml#ref11_12)\]。

`Colendi` 是另一个基于区块链的微型信贷平台，使用各种数据源，包括智能手机数据、社交媒体活动和交易历史，来生成准确的信用评分并为无银行账户的个人和企业提供包容性金融服务。Colendi ID 和 Colendi Score 是该平台的两个主要产品，而以太坊区块链上的去中心化数据存储确保了透明度和隐私 \[[17](#ch11.xhtml#ref11_17)\]。

`AID Tech` 是一个组织，利用区块链技术和数字 ID 平台为低收入少数群体在援助、捐款、电子健康、灾难救助、汇款和社会福利等领域提供快速便捷的支付服务。其平台已在乌干达、埃及、摩洛哥、约旦和印度等国家成功实施 \[[18](#ch11.xhtml#ref11_18)\]。

这些例子突出了区块链技术和数字 ID 平台在促进金融包容性和为服务不足的人群提供替代金融服务方面的变革潜力。通过利用去中心化技术，这些举措旨在克服障碍并赋予个人更大的金融机会获取能力。

## 利用数字平台实现非传统服务的包容性

非传统金融服务提供商（如金融科技公司）的兴起给银行业以及银行与客户互动的方式带来了重大变化。这些传统银行的替代方案旨在简化客户获取贷款和储蓄服务的流程 \[[4](#ch11.xhtml#ref11_4), [19](#ch11.xhtml#ref11_19)\]。

数字平台对金融服务影响的一个显著例子是非洲撒哈拉以南地区的移动货币革命，其中肯尼亚的 `M-PESA` 是一个突出的案例研究。`M-PESA` 由 `Safaricom` 于 2007 年推出，是一个移动钱包和支付平台，与银行、非政府组织和微型信贷组织合作，将无银行账户客户连接到正规金融服务。它使客户能够通过短信廉价、安全地发送和接收付款，并使其能够在全国各地的零售网点存钱和取款 \[[20](#ch11.xhtml#ref11_20)\]。

利用数字平台接触无法获得传统银行服务的人群提供了多项益处：

*   `Wider Reach to the Underserved`: 当代支付方式和数字银行服务提高了经合组织国家金融服务的可用性。随着区块链技术的整合，项目和微型信贷业务将进一步扩展，赋能没有标准银行服务的个人 \[[3](#ch11.xhtml#ref11_3), [21](#ch11.xhtml#ref11_21)\].

*   `Reduction of Transaction Administrative Costs`: 与传统银行通常具有高行政成本不同，区块链技术允许直接点对点交易而无需中介。这使得资金能够在跨境或进入受自然灾害影响的地区时即时流动，显著降低行政费用 \[[9](#ch11.xhtml#ref11_9), [22](#ch11.xhtml#ref11_22)\].
