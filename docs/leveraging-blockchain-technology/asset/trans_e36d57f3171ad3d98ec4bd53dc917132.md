
所提出的去中心化投票系统由多个关键组件组成：一个 Web 应用程序、一个活动管理服务器、智能合约、一个 SMS 网关以及一个移动应用程序。采用了两种类型的智能合约：用于安全用户注册和身份验证的注册合约，以及为特定投票活动部署的多个投票合约，每个合约具有不同的问题和答案。SMS 网关在用户身份验证中发挥着关键作用，通过向用户的电话号码发送 `SMS` 消息。选民利用移动应用程序进行注册、投票以及查看实时投票结果，通过集成的 `Ethereum` 轻客户端连接到区块链网络。要成为合格选民，用户必须通过移动应用程序向系统注册。应用程序从用户的 `SIM` 卡中检索用户的电话号码并生成一个空的 `Ethereum` 钱包，用户必须为其充值足够的 `Ether` 余额。智能合约促进了安全且自动化的注册流程。用户输入信息后，合约会生成唯一的个人识别号码（`PIN`）代码并通过 `SMS` 消息发送到用户的手机。用户随后将 `PIN` 输入应用程序以完成注册流程。使用 Web 应用程序，活动组织者输入必要信息以创建投票活动。智能合约确保重复投票被拒绝，允许每个电话号码仅投票一次。组织者可以监控正在进行的活动统计数据的实时更新和可视化表示。

所提平台的有效性通过利用各种技术进行了评估。`Solidity` 用于编写智能合约，而 `NodeJS` 则促进了活动管理服务器中的服务器端脚本编写。`Web3js` 用于与 `Ethereum` 轻客户端接口，移动应用程序使用 `HTML5` 开发并使用 `Apache Cordova` 编译。`Ropsten Testnet` 模拟了 `Ethereum` 网络，而 `Twilio` 则作为 `SMS` 网关 API。用户注册过程通常需要两到四分钟，主要在初始设置期间，而投票行为大约需要 40 秒到两分钟每次投票 \[[13](#ch8.xhtml#ref8_13)\]。

## Conclusions and recommendations

技术进步显著改善了人类生活的各个方面，包括投票和电子投票系统。然而，电子投票系统的安全性和完整性仍然是一个关键问题。保密性、完整性和可用性是必须确保的三个关键方面，以维持电子投票系统的有效性。

近年来，多个国家经历了选民参与度的下降，主要是由于投票过程缺乏完整性。这种信任的侵蚀进一步被极端意识形态的兴起所加剧，如美国国会山袭击事件所示。此类事件凸显了加强选举过程完整性并解决导致极端意识形态兴起的根本问题的迫切需要。

区块链技术已成为增强电子投票系统安全性和完整性的潜在解决方案。其去中心化和透明的特性使得恶意行为者难以操纵投票过程。通过整合生物识别身份验证系统并利用共享的不可变账本，电子投票系统可以变得更安全。然而，在电子投票系统中实施区块链技术时，需要考虑某些因素。与其他方法相比，处理时间通常更长，并且区块链操作所需的高计算能力可能导致电力消耗增加。这些问题需要得到解决，以确保基于区块链的电子投票系统的效率和可持续性。

简而言之，电子投票技术领域的持续研究与开发，特别是与区块链的整合，有望改善投票系统的安全性、透明度和可信度。必须优先增强电子投票系统中的保密性、完整性和可用性，以保障民主进程并恢复公众对选举的信任。

### Best practices for e-voting

根据上述讨论，以下建议作为最佳实践，可帮助任何私营或政府实体使用区块链技术实施透明的电子投票框架。

*   `Authentication Methods`: 选民身份验证是电子投票的关键方面，因为它确保了远程环境中选民的身份。传统方法是在注册阶段向选民提供 `username` 和 `password`，然后在投票时需要使用。然而，这种方法并不安全，因为存储在投票服务器中的凭证可能被外部攻击者窃取或篡改以冒充有效选民。它们还容易受到窃听攻击，这些攻击会拦截提交的 `password`s。为解决这些安全问题，可以使用一次性密码或数字证书等强身份验证方法。一次性密码每次选民身份验证时都会更改，使被拦截的凭证变得无用。数字证书提供了最稳健的解决方案，因为它们通过数字签名投票提供访问和数据身份验证。投票在签名前会被加密，以防止数字签名被用于将选民与其投票关联。在选民没有数字证书的情况下，可以使用密钥漫游机制为他们提供证书，该证书受选民已知 `PIN` 或 `password` 保护，不存储在远程数据库中，也无法用于冒充选民。

*   `Vote Encryption`: 在电子投票平台中，投票的保密性在传输和存储过程中可能受到损害。为了确保投票隐私，投票时进行投票加密至关重要。一些投票系统在网络层应用加密，使用选民计算机与投票服务器之间的 `SSL` 连接。然而，这种方法不足以保护端到端选民隐私，因为投票在离开传输通道时未被加密，并以明文形式到达投票服务器，使其容易受到获得服务器系统访问权限的任何攻击者的攻击。为克服此问题，建议在数据层使用选举 `public key` 对选票进行加密。这样，即使攻击者获得投票服务器的访问权限，选民隐私仍然保持完整，因为选票在离开传输通道后仍保持加密状态。

*   `Protection of the Election Private Key`: 为了保护选民的隐私并保持中间结果的保密性，非对称加密算法通常用于投票过程。这些算法允许使用 `public key` 对选票进行加密，并且只能使用相应的 `private key` 解密。为了确保个人无法滥用 `private key`，应使用阈值密码学将其拆分为多个份额，每个份额交给不同的选举委员会成员。这确保了必须有最少数量的委员会成员共同合作才能恢复 `private key` 并解密选票。使用阈值方案对于防止一个份额的丢失导致无法解密选票至关重要。
