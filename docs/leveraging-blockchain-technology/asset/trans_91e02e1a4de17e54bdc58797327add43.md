
# 链上区块链治理

链上区块链治理直接发生在区块链协议内部，需要将拟议的修改或决策过程整合到网络代码中。在这种治理模式下，项目开发者或节点控制者拥有推动组织决策并对新举措进行投票的权力。与每个节点拥有一票的传统系统不同，链上治理通常根据每个节点持有的原生代币数量分配投票权。这种集体决策方法与去中心化治理模式一致，消除了对单一中央管理机构的需求。

最终用户通常在项目管理中缺乏直接发言权，因为开发者和节点因参与区块链投票程序而获得奖励。虽然不同项目的投票资格标准可能有所不同，但涉及相关利益相关者的基于代码的系统仍然是一个常见特征。链上治理的优势在于决策迅速，因为拟议的变更会及时导入项目代码；并且开发者有投票激励，尤其是在有投票和实施截止日期支持的情况下。

然而，也存在挑战，例如某些节点选择不投票时可能出现的投票率低和非民主决策。在这种情况下，持有更多货币的节点对项目的未来发展轨迹拥有不成比例的影响力 \[[22](#ch2.xhtml#ref2_22)\]。尽管存在这些挑战，链上治理扩大了区块链治理流程的贡献者范围，这降低了链分裂和分叉的风险，并允许用户提交他们的意见。

虽然链上治理带来了透明度和包容性，但决策的某些方面仍可能发生在区块链之外。提案通常会在各种论坛、博客文章和社交媒体平台上进行讨论，然后才接受正式的投票程序，即使最终决策可能被编码到智能合约中。尽管链上治理有潜力重振系统管理的概念，但治理模型的开发可能耗时，尤其是在引入新工具时 \[[14](#ch2.xhtml#ref2_14)\]。

## 链上治理的参与者

链上治理系统完全在线运行，这将其与涉及离线协作和在线代码修改以实施变更的非正式治理系统区分开来。在链上治理中，代码更新作为对区块链的修改提案，要求开发者在变更应用前提交改进请求。协调和共识建立的责任由一个核心团队承担，主要由开发者组成。链上治理的关键参与者通常包括：

*   *矿工*：负责运行节点并在区块链上验证交易。
*   *开发者*：负责基础区块链算法，通常在各种加密货币中担任用户或投资者的角色。
*   *用户或参与者*：投资并使用不同加密货币的个人。

鼓励参与该过程涉及向参与者提供经济奖励。例如，节点可能会因其投票活动而获得整体交易费用的份额，开发者可能会通过额外的资金来源获得补偿。需要注意的是，并非每个节点的影响力都相等；持有更多代币的节点比持有较少代币的节点拥有更大的投票权。

建议的变更会经过投票程序，参与者或节点决定是否接受或拒绝拟议的修改。如果获得批准，该变更将被整合到区块链中。相反，如果拟议的变更不成功，更新后的代码可能会回滚到基线之前的版本。这种动态反映了链上治理实施中节点之间的影响力差异。简而言之，链上治理的参与者在决策过程中发挥着不同的作用，影响力的分配通常与每个节点持有的加密货币数量相关 \[[23](#ch2.xhtml#ref2_23)\]。

## 链上治理的类型

各种区块链以不同的方式实施链上管理，展示了去中心化决策的多样化模型。两个值得注意的例子是 Tezos 和 DFINITY：

*   *Tezos*：采用自修改区块链，其中对区块链的拟议修改首先在测试版本中实施。如果变更被证明有效，它们将被整合到区块链的生产版本中；否则将被回滚。Tezos 还强调确定变更通过所需的精确票数的重要性。值得注意的是，该网络允许对投票过程本身进行投票，提供了一种独特的方法来解决由主导利益相关者和低投票参与率引起的不效率 \[[23](#ch2.xhtml#ref2_23)\] \[[22](#ch2.xhtml#ref2_22)\]。
*   *DFINITY* 通过其 *区块链神经系统*（BNS）采用算法治理方法。*神经元* 作为 BNS 的基本单位，充当网络的投票单位。神经元必须在提交修正提案之前选择一个提案类别，类别基于经济、政策或代码方面的考虑。每个提案提交都会产生费用，作为对无关或无关紧要提交的自然质量检查。然而，这一费用要求引发了潜在的付费即玩问题的担忧，即资源更多的利益相关者可能仅基于其财富不成比例地影响决策。此外，DFINITY 治理结构包括自动投票机制，允许神经元复制其他人的投票 \[[22](#ch2.xhtml#ref2_22)\]。

这些例子有助于突出链上治理的多样化方法，每种方法都有其独特的功能和考虑因素。如前所述，虽然 Tezos 专注于自修改和迭代变更，但 DFINITY 采用算法模型，具有特定的投票单位，提出了一种独特的分类和处理修正案的方式。

## 分叉和区块链治理变更

许多区块链运行在开源代码上，允许感兴趣的各方进行审查。在重大决策分裂社区或有人具有创新概念的情况下，个人可以选择分叉项目。*分叉* 涉及利用原始项目的代码创建新事物，使用户能够建立竞争、拒绝以前的项目或通过这种类型的治理实施重大变更。当共识协议验证交易时，用户积极参与管理，允许矿工和利益相关者影响交易和协议更新的批准。

分叉是链下和链上治理的核心，分为两种类型：

*   *硬分叉*：对区块链网络协议的根本性修订，使先前有效的区块和交易无效，反之亦然。这种重大的协议变更导致网络分裂为两个分支——一个遵循旧协议，另一个遵循新协议。开发者可能出于解决关键安全漏洞、引入新功能或回滚交易等原因实施硬分叉。无论加密货币平台如何，硬分叉都会发生在任何使用密码学的网络上。矿工，即制定网络记忆规则的人，需要就合法区块的新规则和标准达成一致，从而提示“分叉”以表示对协议的修改或偏离 \[[12](#ch2.xhtml#ref2_12)\]。
