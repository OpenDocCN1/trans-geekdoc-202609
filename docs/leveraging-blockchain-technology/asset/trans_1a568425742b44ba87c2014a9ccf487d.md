
在 COVID-19 大流行期间，欧洲联盟（EU）和四个联合国组织——即 *世界卫生组织*（WHO）、*联合国人口基金*（UNFPA）、*联合国儿童基金会*（UNICEF）和 *联合国项目事务办公室*（UNOPS）——与国内流离失所者部携手启动了一项数字健康倡议。*国内流离失所者部* 是一个负责解决因冲突、自然灾害或其他原因在本国境内被迫逃离家园的个人或群体需求和关切的实体或部门。该倡议的目标是最大程度减少大流行对国内流离失所者的影响并为其提供必要的医疗服务 作为努力的一部分，200 个农村设施将获得必要的设备，而另外 50 个将配备远程医疗技术。同时，将提供常规儿科医疗服务，新设备将确保患有慢性疾病的人持续获得医疗服务。通过让医疗保健提供者参与在线培训，该倡议旨在加强和扩大高质量初级医疗保健服务的提供。此外，该项目旨在通过支持法律和监管框架、临床指南以及针对医疗人员的特定培训计划的制定，建立数字健康和远程医疗的强大可持续基础。此外，它还寻求在医疗保健提供者和公众中推广远程医疗服务的使用 \[[10](#ch10.xhtml#ref10_10)\]。

*联合国儿童基金会风险投资基金* 重点介绍了名为 *Portal Telemedicina* 的一家巴西初创公司，该公司开发了一个平台，在 300 多个城市提供快速、可靠且价格合理的诊断服务。该平台整合人工智能技术，为医疗保健提供者提供医学见解，并使医生能够进行在线诊断。Portal Telemedicina 充当远程医疗和人群健康管理平台，连接医疗设备和记录，传输数据以便医生访问患者档案并进行远程咨询。经过数百万次检查训练的人工智能模型被用于识别异常情况并优先处理紧急情况。Portal Telemedicina 开发的技术专注于儿童发展领域的人群健康管理，创建了一个针对儿童、青少年以及孕产妇和产后女性的需求量身定制的平台。该平台旨在整合各种数据集，涵盖儿童发展的健康、教育和社会经济方面，以提供对孕妇和儿童健康的全面视角。这将使公共管理者能够就纠正和预防措施做出明智的决策。该平台包括一个人工智能模块，可根据儿童发展的关键指标生成见解和警报。中央数据库确保统一且可访问的数据用于智能数据分析，算法促进数据清洗、丰富和去重。可扩展的数据库设计允许未来扩展和增加用户容量。与儿童发展的不同领域相关的数据库的整合被证明特别有价值。用于警报的人工智能层能够与数据库集成进行深入分析 \[[11](#ch10.xhtml#ref10_11)\]。

## 红十字会与 Teladoc 合作：弥合灾难医疗保健的差距
红十字会已与 *Teladoc* 这一总部位于德克萨斯州的公司联手，为灾难受害者建立数字医疗连接。通过这一合作，受害者可使用专用应用程序访问 Teladoc 的电话和基于网络的服务。这使他们能够在事件期间和之后与 Teladoc 医生进行沟通。一份新闻稿强调，远程医疗预计将在未来灾难风险减少中发挥重要作用。这两个组织之间的合作旨在解决在事件期间出现并在随后的数小时、数天和数周内持续的服务差距。Teladoc 只是众多利用移动健康技术提供急救和分诊护理的组织之一。通常，这涉及为急救人员配备通过应用程序或远程医疗链接与医疗专业人员连接的能力 \[[12](#ch10.xhtml#ref10_12)\]。

## 远程医疗中区块链技术的优势
如 [表10.1](#ch10.xhtml#table10_1) 所示，区块链技术为远程医疗领域带来了多项优势，包括患者对个人信息的控制、简化患者识别以及医疗保健提供者之间改善的协作。

[表10.1 区块链在医疗保健中的优势和劣势摘要](#ch10.xhtml#R_table10_1) \[[4](#ch10.xhtml#ref10_4), [13](#ch10.xhtml#ref10_13)\]

| 实体 || 优势/劣势 |
| --- | --- |
| 医疗保健组织 || 改善决策，使多位医生能够实时从不同地点查看同一记录。医疗记录防篡改，因为它们被转变为去中心化系统。快速的资质认证流程。 |
| --- | --- |
| 患者 || 区块链使患者能够拥有其信息的所有权。共识机制禁止医疗人员在未经许可或知情的情况下访问记录。患者可以参与研究研究，并且来自不同设备的数据收集和存储是安全的。 |
| 制药 || 使用区块链技术可实现临床试验人员的招募。通过不可变记录和假药检测实现可靠且可审计的文档。随着药品在全国范围内运输，建立分布式账本以保持透明度。 |
| 保险 || 客户确认流程更快。索赔的自动付款。公司与保险公司之间自动核实承保范围。行政成本更低。智能合约可以管理不同各方之间的协议。 |
| 医疗保健组织、患者、制药、保险 || 随着添加到链中的区块数量增加，交易时间增加导致延迟。医疗记录无法永久删除。添加新区块以表示现有区块的无效。大型文件存在问题，例如 MRI 扫描。使用区块链技术时开发和维护成本更高。 |

*   *信息控制*：借助区块链，患者对其医疗记录和个人信息有更大的控制权。这些记录安全地存储在区块链上，并在需要时虚拟共享给医疗保健提供者。每当记录更新时，网络上所有注册设备都会收到更新版本。这使患者能够管理其健康信息并确保其准确性和完整性。
*   *简化患者识别*：区块链技术简化了患者识别过程，特别是在其个人信息发生变化时。无论是姓名、电话号码、地址或医疗提供者的变更，区块链都确保患者数据保持安全且未受损害。通过消除患者记录中的重复、删除和不一致，区块链提高了患者识别的效率和准确性。
