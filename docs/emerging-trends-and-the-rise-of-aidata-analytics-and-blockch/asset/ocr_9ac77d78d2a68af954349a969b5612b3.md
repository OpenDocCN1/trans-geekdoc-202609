# 6.3 Blockchain as a security solution to IoT security threats

# 6.3.1 RQ3: What are the security mechanisms provided by blockchain that provide an increased security level of IoT than traditional mechanisms?

Blockchain embodies features that are distinctive from the established IoT networked architectures. Some of its main distinguishing features include a ledger-based database, a decentralized architecture, ability to auto-execute smart-contracts, embedded cryptographic algorithms, immutable datastore, (Pseudo) anonymity and a participatory consensus mechanism. Indicatively, those traits address a large number of security threats (see Table 5). We identified 17 blockchain features from the select literature out of which 12 were retained as unique to blockchain. Blockchain aspects scalability and traffic flow analyzer were discarded since they can be adapted to non-blockchain based IoT ecosystems. The remaining features were then shared with two blockchain developers along with the identified IoT threats and relevant descriptions. The developers were asked to classify the features according to the threats they address. After two rounds of card sorting, the developers achieved a 94% inter-rater agreement. Table 5 lists blockchain features and explains how these features are used in addressing different security threats.

The reviewed literature provides convincing explanation pertaining to blockchain's superiority in securing IoT vis-à-vis confidentiality, data integrity, auditability and authentication (Milne et al., 2020). Some features that are explicit to blockchain were found to address existing threats more securely than conventional mechanisms. For instance, blockchain's distributed ledger-based database circumvents DoS/DDoS attacks (Kumar and Mallick, 2018; Lee et al., 2020). On the other hand, smart contracts can replace existing IoT programs and avoid different types of attacks such as phishing, code injection, data tampering, Sybil and selfish attacks (Zhu and Badr, 2018; Wang et al., 2019; Alotaibi, 2019).

In some privacy-preserving scenarios such as military IoT ecosystems, data is treated as sensitive, and its confidentiality should be ensured during transmission (Hong et al., 2019). Accordingly, blockchain provides an enhanced level of privacy by implementing trust and anonymity such as in the case of PrivySharing, a blockchain-based secure framework for protecting IoT devices (Makdhoom et al., 2020). Blockchain also involves asymmetric cryptography, which uniquely authenticates the transactions and guarantees integrity since the transaction cannot be decrypted if there exists an error during data transmission (Fernández-Caramés and Fraga-lamas, 2018).
