The design of this distributed identity system based on blockchain is significant in the following ways: First, it supports API and business logic development for this mobile identity project through the API Gateway module application. In authentication/issuance and identity verification, a convenient and stable development environment has been established for API authentication and authorization processing, logging processing and traffic management that involves linking a micro service. Second, when connecting with other systems, such as in an external linkage (e.g. with a police agency or a road transportation corporation), the interface specifications – such as HTTP and HTTPS, the application method, component, database, etc. – of the target system are applied for integration with other systems. Third, Hyperledger Fabric is used to develop the blockchain client server. Specifically, we apply Hyperledger Fabric V1.0 to create a blockchain client server. Hyperledger Fabric is used to support systems requiring high levels of privacy, because it allows members to enroll via a trusted membership service provider. Thus, this distributed ledger platform provides resiliency, scalability, flexibility and confidentiality (Alessandro, 2020). This blockchain-based mobile identification service is also implemented through storage selection (PostgreSQL, MySQL and LDAP) for the storage of user information and the development of Fabric CA Client and REST API. Fourth, Hyperledger’s chain code development secures the flexibility and reliability of the data. Hyperledger chain code is applied with KVS-style LevelDB or CouchDB, which registers data in pairs of keys and values as databases.

The development of personal information inquiry and verification apps requires the design of UI/UX with services according to the specific purposes of the users and verifiers. The goal is to increase user convenience by implementing a modern UI/UX and design optimized for mobile app/Web environments. In addition, to avoid the challenges involved in contradictory design requirements (Dhamija and Dusseault, 2008), infographics and design are actively used to improve readability of identification/verification apps and strengthen their brand identity. The focus is on implementing user-centered user apps by providing a service planning and design guide based on the particular service requirements. As illustrated in Figure 3, the verification app provides functions such as identification, qualification and certification history. The features presented include the registration/deletion of mobile identification cards (using OCR) along with preview screens, notification of mobile authentication history changes, ID card status values and Quick Response (QR) code security.
