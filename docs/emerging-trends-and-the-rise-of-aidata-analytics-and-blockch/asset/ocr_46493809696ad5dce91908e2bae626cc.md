# Appendix 3
Results of variants of GRU model

We have computed the confusion matrix and ROC curve for all the variants of GRU model, namely GRU model with GloVe embedding, Bi-directional GRU model and GRU model with an attention layer.

The results of GRU model with GloVe embedding can been seen in Figure A5.

From Figure A5, it can be seen that the joy class has been classified correctly to the level of 79.27% accuracy such that 88 out of 111 test examples has been classified accurately. However, we find that the class anger, disgust classes has not been so accurately classified as the confusion matrix shows the accuracy of anger class is 54.54 and 57.14% for disgust class. After that, we applied the third variant of the GRU model called Bi-directional GRU. The confusion matrix and ROC curve of the Bi-directional GRU-Model can be seen in Figure A6.

From Figure A6, it can be seen that the joy class has been classified correctly to the level of 72.97% accuracy such that 81 out of 111 test examples has been classified accurately. However, we find that the disgust class and shame classes have not been so accurately classified as the confusion matrix shows the accuracy of disgust class is 41.90 and 42.85% for shame class. Next, we applied the fourth variant of the GRU model, where an attention layer is used. The confusion matrix and ROC curve of the GRU-Model with an attention layer can be seen in Figure A7.

From Figure A7, it can be seen that the joy class has been classified correctly to the level of 75.67% accuracy such that 84 out of 111 test examples has been classified accurately. However, we find that the disgust class and shame classes have not been so accurately classified as the confusion matrix shows the accuracy of disgust class is 47.61 and 48.57% for shame class.
