# Table 4. Security countermeasures within IoT layers

| IoT Layers | Countermeasures | Countermeasure Description | Security Threats | Reference |
|---|---|---|---|---|
| Perception Layer | Physical security design | It involves designing devices which are physically secure to resolve the threats. The design of such components should not be changeable | Node capturing attacks, False data injection attack, Side-channel attacks (SCA) | Ahmed et al. (2017), Noor and Hassan (2019) |
| | Secure booting | Secure booting is achieved by cryptographic hash algorithm that uses digital signature to check software on the devices | Booting vulnerabilities, Malicious node injection attacks | Ahmed et al. (2017) |
| | Encryption | Symmetric and asymmetric encryption function like DSA ensures data privacy by preventing the attacker from accessing essential data | WSN node jamming, Node tampering | Ahmed et al. (2017), Hassija et al. (2019), Mendez et al. (2017), Noor and Hassan (2019), Kouicem et al. (2018), Hong et al. (2019) |
| | Authentication | Authentication through Identity Management (IdM) provides resource control and helps to delivery auditing, accounting and access control. Any new node should authenticate itself before joining the network. Without authenticating a node cannot send or receive data from other nodes in the IoT network | Sleep deprivation attacks | Mendez et al. (2017), Ahmed et al. (2017), Ababa et al. (2017), Noor and Hassan (2019), Kouicem et al. (2018), Hong et al. (2019) |
| | Risk evaluation | Risk analysis and assessment technique provides confidentiality of data and avoids security breaches in IoT networks | (1) Physical destruction, (2) Firmware replacement attack | Ahmed et al. (2017), Wei et al. (2019) |
| Network layer | State detection scheme | Scheme such as anomaly mining algorithm is believed to detect anomalies in the data of perception layer | | |
| | Data recovery mechanism | Hashed Based Security ensures recovery of message content that has been changed by the attacker | Security awareness sessions are added to prevent threats in the IoT network | Ahmed et al. (2017) |
| | Security awareness | Security awareness sessions are added to prevent threats in the IoT network | It provides security such as anti-spyware to ensure confidentiality and integrity in IoT | Ahmed et al. (2017), Hassija et al. (2019) |
| | Anti-spam | It provides security such as anti-spyware to ensure confidentiality and integrity in IoT | It blocks the unwanted packets in the IoT network | Ahmed et al. (2017), Hassija et al. (2019) |
| | Firewalls | It blocks the unwanted packets in the IoT network | The solution objective is to detect DoS attacks in early stages before the disruption of normal network operations | Ahmed et al. (2017), Kouicem et al. (2018) |
| | Intrusion Detection System (IDS) | The solution objective is to detect DoS attacks in early stages before the disruption of normal network operations | This helps to halt any attacks inside the network. It prevents the inside attacks of the network of IoT | Mendez et al. (2017), Kouicem et al. (2018), Hassija et al. (2019), Hassan and Noor (2019), Tariq and Ahmed (2019) |
| | Ad hoc routing | This helps to halt any attacks inside the network. It prevents the inside attacks of the network of IoT | | Ahmed et al. (2017), Wang et al. (2019) |
