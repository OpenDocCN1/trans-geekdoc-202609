Transfer learning is another significant advancement in deep learning models. It focuses on a method where the knowledge from one domain (source) is leveraged to improve the sentiment classification in a different domain (target). Transfer learning has been widely used in the medical field, where the data training for one disease could be helpful in another condition (Hermessi et al., 2019). For instance, researchers like Soudani and Barhoumi (2019) have also used transfer learning and crowdsourcing for skin lesion extraction. # 2.2 Image-based affective computing

Image-based affective computing can be categorized into studies based on the feature extraction method and studies based on the image background. Over the past years, deep learning has increasingly become a hot topic of research and has obtained cutting-edge performance in several domains, including facial expression recognition. Deep learning demonstrates high-level abstractions of various nonlinear transformations and representations through hierarchical architectures.

2.2.1 Feature extraction method. Some of the researchers, like Ghani and Krema (2014), have analyzed the sentiment of the images by the feature extraction method. Researchers have proposed several approaches for extracting emotions from sequences and frames, including hand-crafted features and learned feature-based models. Hand-crafted features make use of a predesigned appearance or any geometrical features (Pantic and Patras, 2006) on the face to infer the facial information. Other hand-crafted features include Local Binary Pattern (LBP) (Valstar et al., 2012), Scale Invariant Feature Transform (SIFT) (Hu et al., 2008) and Histogram of Oriented Gradients (HOG) (Dahmane and Meunier, 2011). Researchers like Renda et al. (2019) have also used ensemble strategies for deep learning to identify facial expression recognition in literature. Deep learning techniques were also used for biological-image classification using CNN in combination with texture-based feature extraction methods (Affonso et al., 2017).

2.2.2 Background of the image method. Some researchers like Machajdik and Hanbury (2010) have used the background and color to classify the emotions depicted in the image. Recognition of facial expressions and emotions is a very challenging problem in the real world because there is a significant difference in intra-class distance measure and great similarity in inter-classes distance measure. CNN's can produce comparable representations for pictures containing distinct features for a single individual. On the other hand, the learned features of any images with the same or similar expression may differ in the different results because of the above challenges. Scholars like Meng et al. (2017) have proposed an Identity-Aware CNN called IACNN, which can reduce the differences by including personal features. The IACNN was focused on personal features, using both an identity-sensitive and an expression-sensitive contrastive loss. Still, they have not considered other variables such as illumination and head-pose.
