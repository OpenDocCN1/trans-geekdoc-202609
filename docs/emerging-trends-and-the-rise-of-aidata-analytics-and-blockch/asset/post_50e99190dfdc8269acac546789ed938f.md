## Methodology

Several MGARCH models were employed to investigate the co-movements between financial assets, cryptocurrencies and other variables. For instance, the constant conditional correlation (CCC) approach utilized by Bollerslev (1990) is employed to model the static conditional correlation matrix. CCC between variables is not a realistic assumption in most empirical cases. As a result, the new generation of the CCC-MGARCH model is proposed independently by Engle (2002) and Tse and Tsui (2002). In this new form of MGARCH modeling, the conditional correlation is considered dynamic; accordingly, these models are called dynamic conditional correlation MGARCH.

DCC-GARCH modeling has several advantages. First, the model can detect possible changes in conditional correlation over time and capture dynamic responses between time series (Celik, 2012). Second, DCC-GARCH modeling accounts for heteroskedasticity directly by estimating correlation coefficients of the standardized residuals (Chiang et al., 2007).

Third, DCC-GARCH continually modifies the correlation for the time-varying volatility. DCC-MGARCH proposes a better method for measuring correlation (Cho and Parhizgari, 2009). Fourth, as the procedure modifies the volatility, the dynamic correlation is not biased from volatility (Celik, 2012). Lastly, it is possible to calculate large correlation matrices in DCC-MGARCH because the estimated correlation is independent of the number of correlated series (Lee et al., 2006).

In fact, in DCC-GARCH modeling, conditional correlation is parameterized directly and is estimated in two steps: first, the univariate GARCH model is estimated, and then the conditional correlations are estimated. It is carried out by transforming residuals by their standard deviation obtained in the first stage to estimate the parameters for the time-varying correlation. DCC-MGARCH model can be defined as follows:

```
\begin{cases}
x_t = \mu_t + r_t \\
r_t = H_t^{1/2} z_t \\
H_t = D_t R_t D_t \\
D_t = diag \left( h_{11t}^{1/2} \dots h_{nnt}^{1/2} \right) \\
R_t = \{ diag (Q_t)^{-1/2} \} Q_t \{ diag (Q_t)^{-1/2} \}
\end{cases}
```

where $x_t$ is the vector of the observations, $H_t$ is the multivariate conditional variance, $\mu_t$ is the vector of conditional returns, $z_t$ is the vector of identically independently distributed errors with the expected value of zero and $E(z_t z'_t) = I$. $R_t$ is a symmetric time-varying correlation matrix, and $D_t$ is a diagonal matrix of conditional standard deviations for return series, which is derived from estimating a univariate GARCH model with $\sqrt{h_{jjt}}$. On the $j$th diagonal, $j = 1, 2, ....N$.

Also, $Q_t = (q_{ijt})$ is the $n \times n$ symmetric positive definite matrix defined as follows:

```
Q_t = (1 - \vartheta - \rho)\overline{Q} + \vartheta u_{t-1} u'_{t-1} + \rho Q_{t-1}
```

$\vartheta$ and $\rho$ are more prominent than zero, and if $\rho + \vartheta$ is smaller than one, the model is going to be mean-reverting. If $\rho + \vartheta$ is equal to one, the model is integrated. If it is more significant than one, the model is explosive.

$u_{t-1}u'_{t-1}$ is the lagged function of the standardized residuals, which is equal to $u_t = \frac{z_t}{\sqrt{h_{it}}} \overline{Q}$ is the $n \times n$ matrix of unconditional covariance of $u_{j,t}$ and $u_{i,t}$ and $Q_t$ is the unconditional variance between returns $i$ and $j$. The conditional covariance between return series $i$ and $j$. The conditional covariance is equal to

```
h_{ijt} = \frac{q_{ijt} \sqrt{h_{iit} * h_{jjt}}}{\sqrt{q_{iit} * q_{jjt}}}, \text{ and } h_{ijt} = \delta_i \theta_t \epsilon_{t-1}^2 \beta_1 h_{ijt-1}
```

### The asymmetric form of the DCC model

```
$$Q_t = (1 - \vartheta - \rho)\overline{Q} + \vartheta u_{t-1}u'_{t-1} + \rho Q_{t-1} + \gamma\overline{N} + \gamma n_{t-1}n'_{t-1}$$
$$
\overline{N} = T^{-1} \sum_{t=1}^T n_t n'_t, \quad n_t = I[u_t < 0] \circ u_t, \quad \vartheta + \rho + \alpha \gamma < 1 \quad (4)$$
```

\(\alpha\) is the maximum eigenvalue of \([\overline{Q}^{-1/2}N\overline{Q}^{-1/2}]\), \(I\) is \(k \times 1\) indicator function. If \(u_t < 0\) is true, then \(I\) equals one; otherwise, it will be zero. "\(\circ\)" is pointwise operations notation. The impact of previous innovations and previous time-varying conditional correlations on the current dynamic conditional correlations are measured by \(\vartheta\) and \(\rho\) (Katzke, 2013; Qian and Diaz, 2017).

The maximum likelihood (Nelson et al., 2010) approach is commonly used to route estimate parameters in multivariate GARCH models. The conditional likelihood function is indicated as follows for sample observation of \(x = (x_1, \dots, x_n)\):

```
$$l(\tau) = \prod_{t=1}^n |H_t|^{-1/2} p_\epsilon \left( H_t^{-1/2} x_t \right) = \prod_{t=1}^n \left[ \prod_{i=1}^k h_{n,t,i}^{-1/2} \right] |R_t|^{-1/2} p_\epsilon \left( (D_t R_t D_t)^{-1/2} y_t \right)$$
$$
p(\epsilon_t) = \frac{\Gamma((v+k)/2)}{\Gamma(v/2)[\pi(v-2)]^{k/2}} \left[ 1 + \frac{\epsilon'_t \epsilon_t}{v-2} \right]^{-(v+k)/2} \quad (5)$$
```

\(p_\epsilon\) is the joint density function for \(\epsilon\), either the standardized multivariate normal distribution or multivariate Student-t distribution. It depends on the one best fitted for error distribution. The multivariate Student-t distribution is used for financial asset returns (Fioruci et al., 2014). \(\tau\) is the set of all model parameters to be estimated. \(\Gamma(.)\) is gamma function and \(\epsilon_t\) is multivariate Student-t distribution, which has an additional degree of freedom \(v\), and it is assumed to be larger than two because in this case \(H_t\) is always interpreted as a conditional covariance matrix (Fioruci et al., 2014).

In total, four criteria, such as AIC [5], BIC [6], DIC [7] and wDIC [8], were utilized to compare different estimated Bayesian DCC-MGARCH models. Models that have smaller values of EAIC, DIC and EBIC are suggested. The models were fitted with three shock distributions: mvn [9], mvt [10] and mvGED [11].

It is also assumed that the distributions of error terms have a skewed distribution. In this respect, we must use asymmetric densities instead of symmetric density to improve financial modeling (Bauwens and Laurent, 2005). Therefore, error terms follow a skew-mvt or a skew-mvGED. For instance, the skew-mvt can address the excess kurtosis and skewness in cryptocurrencies and the return of stock indices of blockchain-based technology companies. We are going to use the following density functions of multivariate skew distributions that are proposed by Bauwens and Laurent (2005):

```
$$s(y|\gamma) = 2^k \left( \prod_{i=1}^k \frac{\gamma_i}{1 + \gamma_i^2} \right) f(y^*), \quad i = 1 \dots k \quad (6)$$
```

\(f(.)\) is symmetric multivariate density. If \(y_i\) is larger than or equal to zero, then \(y^* = y_i/\gamma_i\), otherwise \(y^* = y_i\gamma_i\). The parameters \(\gamma_i\) control the degree of skewness. If \(\gamma_i\) is greater than one, then there is a right skewness, and the value smaller than one shows a left skewness.
