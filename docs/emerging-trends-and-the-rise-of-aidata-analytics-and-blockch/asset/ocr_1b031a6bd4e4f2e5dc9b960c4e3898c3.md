A CNN generally consists of three types of heterogeneous layers: convolutional layers, pooling layers and fully connected layers. The convolutional layer has a set of learnable filters to convolve through the entire input image and generate different kinds of activation feature maps. The pooling layer follows the convolution layer and is used to decrease the feature maps spatial size and the network's computational cost. The fully connected layer is generally included at the end of the network to ensure that all neurons in the layer are completely connected to prior layer activations and allow 2D feature maps to be transformed into 1D feature maps for further representation of features and classification. We have used CNN for text-based affective computing. We have used only two variants of CNN models, i.e. CNN model with randomly initialized embeddings and CNN model with GloVe embeddings. The bi-directional CNN and attention layer in CNN is not possible because Bi-directional CNN gives the same output as that of CNN because the entire thing is taken as an input in one instance.

# 4.2.2 Transfer learning with VGG-19 model.

Transfer learning is a machine learning method in which a previously trained model which performs well on one task is used with some modification to perform well on another similar kind of task (Hermessi et al, 2019). The benefit of transfer learning is that it could speed up the time it takes to develop and train a model by reusing the previously trained models. Transfer learning also helps in achieving good results with a lesser amount of data. One of the latest studies has used transfer learning for the identification of human activities (Zhu et al, 2020).

Visual Geometry Group (VGG) of Oxford developed a deep learning architecture for the classification of images into 1,000 classes called the VGG-19 model. The model was trained on a very large dataset called ImageNet which contained images of dimension 224px * 224px * 3 (RGB images). As the name of VGG-19 suggests, it contained a total of 16 convolution layers and three fully connected layers (He et al, 2016). The layer has a kernel size of (3, 3) and a max-pool layer of patch size (2, 2) throughout the network. Before training the model, a preprocessing of the images are done by subtracting the mean RGB value from each pixel. The image is then passed through a stack of convolutional layers with a small receptive field of 3 x 3 size with 1px. The spatial padding of convolutional layer input is such that the spatial resolution is preserved after convolution, i.e. the padding is 1 pixel for 3 x 3 convolutional layers. A stack of convolutional layers is followed by three Fully-Connected (FC) layers which contains the first two activation function as Rectified Linear Unit (ReLU) activation function and third with softmax. The first two have 4,096 channels each, the third performs 1,000-way classification and thus contains 1,000 channels (one for each class). The final layer is the soft-max layer.
