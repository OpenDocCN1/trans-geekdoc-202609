# Results of variants of LSTM Model

We have computed the confusion matrix and ROC curve for all the variants of LSTM model, namely LSTM model with GloVe embedding Bi-directional LSTM model and LSTM model with an attention layer.

The results of LSTM model with GloVe embedding can be seen in Figure A2. From Figure A2, it can be seen that the joy class has been classified correctly to the level of 84.68% accuracy such that 94 out of 111 test examples has been classified accurately. However, the classes anger and disgust again have not been classified so accurately because the confusion matrix shows the accuracy of anger class as 55.45% and the accuracy of disgust class as 57.14%. Next, we applied the bi-directional LSTM on PsychExp dataset, and the confusion matrix and ROC curve of the same can be seen in Figure A3.

From Figure A3, it can be seen that the joy class has been classified with an accuracy of 70.27%, such that 78 out of 111 test examples has been classified accurately. However, we again found that the anger class and disgust class have not been accurately classified because the confusion matrix shows the accuracy of anger class as 47.27% and the accuracy of disgust class as 48.57%. Next, we applied the fourth variant of the LSTM model, where an attention layer is used. The confusion matrix and ROC curve of the LSTM-Model with an attention layer can be seen in Figure A4.

From Figure A4, it can be seen that the joy class has been classified correctly to the level of 69.36% accuracy such that 77 out of 111 test examples has been classified accurately. However, we find that the class guilt and class shame have not been so accurately classified as the confusion matrix shows the accuracy of shame class as 53.33% and the accuracy of guilt class as 51.45%.
