# 3. Data collection and framework

This section describes the data collection method and the framework used in the study.

# 3.1 Data

We have conducted affective computing by taking both text and images data for analysis. For text data, we have used four standard datasets, i.e. PsychExp dataset (Wallbott and Scherer, 1986), ISEAR dataset (Wallbott and Scherer, 1986), Literary Tales dataset (Alm, 2008) and Headlines dataset (Strapparava and Mihalcea, 2007). PsychExp dataset consists of 7,840 records belonging to six classes, i.e. joy, fear, anger, sadness, disgust, shame and guilt. The ISEAR dataset is a similar dataset and consists of records of self-report of experiences. Headlines dataset is also known as SemEval-2007 dataset and consists of annotated headlines. Literary Tales is a larger dataset consisting of affect labelled literary tales.

The affective computing for images was carried out on images extracted from Instagram. Images from Instagram were extracted using the Application Program Interface (API) of Instagram. The images obtained from Instagram are then classified into two classes of sentiments, namely, happy class and sad class, based on their facial expressions. We have used hashtags like #laughingfaces, #happy for happy class, and #crying, #depressed, #sad for sad classes to get data from Instagram API. The details of the hashtags used on Instagram for getting images are shown in Table 1. A total of 28,148 images were collected using these tags. After that, we filtered images containing human face through OpenCV in python. After filtering and manually removing all outliers from the dataset, a corpus of 7,638 images was obtained, which was our final dataset used in the analysis. Then we cropped all the human faces present in the images in python. Along with the image data from Instagram, we have also collected user's text posts.
