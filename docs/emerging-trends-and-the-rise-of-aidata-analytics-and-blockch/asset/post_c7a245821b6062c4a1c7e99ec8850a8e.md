### 4.1.1 Long Short-term memory (LSTM)

Long short-term memory (LSTM) is one of the popular deep learning techniques used in image recognition, video to text generation, handwriting recognition and speech recognition (Hochreiter and Schmidhuber, 1997). LSTM consists of gates such as input, output, forget gates which gives an LSTM cell ability to read, write and delete information in its memory. LSTM is a type of recurrent neural networks (RNN). RNN has the problem of vanishing gradient, which can be solved through LSTM cells, because it keeps gradients steep enough and thereby keeping training relatively short and accuracy high. We have used four variants of LSTM as models. The first model used in the study was simple LSTM with random embeddings, the second model was LSTM with GloVe embeddings, the third model was bi-directional LSTM, and the fourth model was the LSTM model with an attention layer.

The second model was the LSTM model with GloVe embeddings. Embeddings, in general, are learned continuous vector representation or the mapping of distinct objects to the vectors. Global Vectors (GloVe) for word embeddings is an unsupervised learning algorithm for obtaining vector representations for words (Pennington et al., 2014). In this model, training is performed on the aggregated global word-word co-occurrence statistics from a corpus. The resulting representations showcase an interesting linear substructure of the word vector space. We have used pre-trained word embeddings from GloVe for the models and then freezing the weights of the embedding layer.

The third model was the Bi-directional LSTM model, which was created by taking input in both directions, i.e. one from past to future and another from future to past. Bi-directional LSTM finds its application in various places such as those of handwriting recognition, the performance of the LSTM model can be enhanced by knowing the letters located before and after the current letter. Thus, bi-directional LSTM is better than LSTM.

The fourth model was the LSTM model with an attention layer. The central idea behind utilizing the attention layer is not to throw away any of those intermediate hidden states but to utilize all the states to predict the better sentiment of the text (Yang et al., 2017). In the traditional model, we discard all the intermediate states of the output and use only its final states. Here, we use those intermediate states in the model. The applications of LSTM with attention layer includes multiple object recognition, spatial transformer networks and neural machine translation with attention. We have used the attention layer to compute the soft alignment score, corresponding to each of the hidden states and the last hidden state of the LSTM. We have used a torch.bmm for the batch matrix multiplication. The details of the LSTM model with an attention layer can be seen in Appendix 1.

### 4.1.2 Gated Recurrent Unit (GRU)

Gated Recurrent Unit (GRU) is the newer generation of RNN and is similar to LSTM with fewer gates (Cho et al., 2014). GRU consists of only two gates, i.e. update gate and forget gate. GRU does not have the cell state which is present in the LSTM cell. The update gate works similar to the input gate and forget gate combined together in the LSTM model, and the reset gate is used to decide how much past information should be remembered and how much to forget. Similar to LSTM, we have used four models for GRU as well. The first model used in GRU was a simple GRU model with random embeddings, the second model was GRU with GloVe embeddings, the third model was bi-directional GRU, and the fourth model was GRU model with an attention layer.

### 4.1.3 Convolutional neural networks (CNN)

Convolutional neural networks (CNNs) are a special kind of neural network that applies a linear operation known as convolution instead of general matrix multiplication in at least one of its layers. CNN's are designed to process data that has a grid or array-like structure/topology. For example, time-series data which resembles a 1D array-like structure, image data or audio spectrogram, which has a 2D grid of pixels data, or 3D data, like-colored images/videos data. The applications of CNN's includes image recognition, natural language processing, including sentiment analysis, video analysis, drug discovery and so on. A CNN generally consists of three types of heterogeneous layers: convolutional layers, pooling layers and fully connected layers. The convolutional layer has a set of learnable filters to convolve through the entire input image and generate different kinds of activation feature maps. The pooling layer follows the convolution layer and is used to decrease the feature maps spatial size and the network's computational cost. The fully connected layer is generally included at the end of the network to ensure that all neurons in the layer are completely connected to prior layer activations and allow 2D feature maps to be transformed into 1D feature maps for further representation of features and classification. We have used CNN for text-based affective computing. We have used only two variants of CNN models, i.e. CNN model with randomly initialized embeddings and CNN model with GloVe embeddings. The bi-directional CNN and attention layer in CNN is not possible because Bi-directional CNN gives the same output as that of CNN because the entire thing is taken as an input in one instance.

## 4.2 Affective computing for images

The affective computing for image data was analyzed using three deep learning models, namely, customized CNN for image, transfer learning with VGG-19 model and transfer learning with ResNet-18 model.

### 4.2.1 CNN with image

The CNN was used not only for text-based affective computing but it can also be used for image-based affective computing. Here too, there are three layers for CNN, namely, convolutional layers, pooling layers, and fully connected layers. The CNN model extracts the significant features of the image as the kernel (convolutional filter) moves through the image. We have used the custom CNN where concatenation between convolutional layers is done to achieve the image-based affective computing.

### 4.2.2 Transfer learning with VGG-19 model

Transfer learning is a machine learning method in which a previously trained model which performs well on one task is used with some modification to perform well on another similar kind of task (Hermessi et al, 2019). The benefit of transfer learning is that it could speed up the time it takes to develop and train a model by reusing the previously trained models. Transfer learning also helps in achieving good results with a lesser amount of data. One of the latest studies has used transfer learning for the identification of human activities (Zhu et al, 2020).

Visual Geometry Group (VGG) of Oxford developed a deep learning architecture for the classification of images into 1,000 classes called the VGG-19 model. The model was trained on a very large dataset called ImageNet which contained images of dimension 224px * 224px * 3 (RGB images). As the name of VGG-19 suggests, it contained a total of 16 convolution layers and three fully connected layers (He et al, 2016). The layer has a kernel size of (3, 3) and a max-pool layer of patch size (2, 2) throughout the network. Before training the model, a preprocessing of the images are done by subtracting the mean RGB value from each pixel. The image is then passed through a stack of convolutional layers with a small receptive field of 3 x 3 size with 1px. The spatial padding of convolutional layer input is such that the spatial resolution is preserved after convolution, i.e. the padding is 1 pixel for 3 x 3 convolutional layers. A stack of convolutional layers is followed by three Fully-Connected (FC) layers which contains the first two activation function as Rectified Linear Unit (ReLU) activation function and third with softmax. The first two have 4,096 channels each, the third performs 1,000-way classification and thus contains 1,000 channels (one for each class). The final layer is the soft-max layer.
