Notwithstanding the value of the extant reviews on blockchain-based IoT security, we contend that no single survey covers the full IoT security spectrum and addressed the five goals of security in a comprehensive manner (see Table 1). Moreover, we observed that little attention was paid to the architectural layer in which the threat can persist. Lastly, it is not clear from those reviews whether blockchain can replace conventional security mechanisms or complement them. A thorough review of all IoT security threats affecting any of the five security goals on all IoT architectural layers is necessary. It is also necessary to identify the current mechanisms that are put in place to counter those threats. Once we arrive at such a comprehensive view of the current state of IoT security, an adequate evaluation of blockchain applicability can be assessed.

# 3. Research goals

The overarching goal of our systematic literature review is to elucidate the role of blockchain in securing IoT ecosystems. IoT security research is extensive investigating abundant security threats and mechanisms to address them. To this end, our first goal is to organize the relevant literature on IoTs security threats and how these threats are addressed using conventional mechanisms. More importantly, we investigate whether blockchain help improve the current state of IoT security or adds more vulnerability to an already fragile ecosystem. In order to achieve those objectives, we organized the existing literature according to (1) the five security goals put forward by Alaba et al. (2017) and Jesus et al. (2018) and (2) the four-layer IoT architecture specified by Sengupta et al. (2020). The conclusion of this work aims to answer one overarching question pertaining to the suitability of blockchain as a security solution for IoT ecosystems.
