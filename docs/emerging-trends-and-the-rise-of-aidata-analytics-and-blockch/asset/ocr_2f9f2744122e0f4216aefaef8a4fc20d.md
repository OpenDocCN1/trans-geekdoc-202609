# 6.4 Novel IoT security threats as a result of blockchain

# 6.4.1 RQ4: Does blockchain pose novel security threats when implemented to safeguard IoT ecosystems?.

The review of the literature did not reveal new security threats when implementing blockchain in IoT, except for only one threat that is uniquely identified as blockchain triggered (see Moin et al., 2019). The large amount of data generated by IoT devices presents the most significant vulnerability. Since blockchain requires time to process transaction, a large amount of data can slow down its performance. With many heterogeneous devices, security measures might not be adequate enough to handle a large scale blockchain. This poses security threats such as malware injection and backdoor installations when security software for different data is inappropriately designed.

# 7. Discussion

Our systematic review of the literature provides evidence of blockchain's superiority to conventional and centralized IoT infrastructure and handling security. Blockchain, with its intrinsic design features, is found capable of addressing the IoT security threats that were identified in the literature (see Table 5). Perhaps more importantly, it provides a supercharged level of security that cannot be achieved with the established IoT security approaches. Indeed, as Table 5 shows, security is achieved at the four different layers of IoT devices and, according to the extant literature (see Section 6.3), at a much-improved security level. The distinctive architectural features of blockchain, combined with cryptography and other borrowed security principles provide a sturdier security platform for IoT ecosystems. Nevertheless, the elevated security standard achieved with blockchain technology comes at a cost. Our focus in this paper was to provide a comprehensive view of IoT threats so as to identify and compare the conventional threat countermeasures with blockchain-based security countermeasures. While attempting to answer the question of novel threats that stem from adopting blockchain technology to manage IoT security, a number of authors highlight major hurdles facing industry wide acceptance. According to Jesus et al. (2018), IoT devices are low-power and low-computing technologies. Accordingly, very few resources are dedicated to ensuring their security (Jesus et al., 2018). Due to its ledger based, decentralization and inherent security principles, blockchain has prospects to becoming the main infrastructure for IoT. But blockchain, in its current format, is a heavy technology. It is time consuming, energy inefficient, requires excessive storage and generates large bandwidth. Those traits are conflicting with low-resource technologies such as IoTs.
