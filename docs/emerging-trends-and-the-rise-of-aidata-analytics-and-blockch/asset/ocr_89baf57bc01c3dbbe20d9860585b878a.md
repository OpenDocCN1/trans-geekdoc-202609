# 4.1.1 Long Short-term memory (LSTM).

Long short-term memory (LSTM) is one of the popular deep learning techniques used in image recognition, video to text generation, handwriting recognition and speech recognition (Hochreiter and Schmidhuber, 1997). LSTM consists of gates such as input, output, forget gates which gives an LSTM cell ability to read, write and delete information in its memory. LSTM is a type of recurrent neural networks (RNN). RNN has the problem of vanishing gradient, which can be solved through LSTM cells, because it keeps gradients steep enough and thereby keeping training relatively short and accuracy high. We have used four variants of LSTM as models. The first model used in the study was simple LSTM with random embeddings, the second model was LSTM with GloVe embeddings, the third model was bi-directional LSTM, and the fourth model was the LSTM model with an attention layer.

The second model was the LSTM model with GloVe embeddings. Embeddings, in general, are learned continuous vector representation or the mapping of distinct objects to the vectors. Global Vectors (GloVe) for word embeddings is an unsupervised learning algorithm for obtaining vector representations for words (Pennington et al., 2014). In this model, training is performed on the aggregated global word-word co-occurrence statistics from a corpus. The resulting representations showcase an interesting linear substructure of the word vector space. We have used pre-trained word embeddings from GloVe for the models and then freezing the weights of the embedding layer.

The third model was the Bi-directional LSTM model, which was created by taking input in both directions, i.e. one from past to future and another from future to past. Bi-directional LSTM finds its application in various places such as those of handwriting recognition, the performance of the LSTM model can be enhanced by knowing the letters located before and after the current letter. Thus, bi-directional LSTM is better than LSTM.

The fourth model was the LSTM model with an attention layer. The central idea behind utilizing the attention layer is not to throw away any of those intermediate hidden states but to utilize all the states to predict the better sentiment of the text (Yang et al., 2017). In the traditional model, we discard all the intermediate states of the output and use only its final states. Here, we use those intermediate states in the model. The applications of LSTM with attention layer includes multiple object recognition, spatial transformer networks and neural machine translation with attention. We have used the attention layer to compute the soft alignment score, corresponding to each of the hidden states and the last hidden state of the LSTM. We have used a torch.bmm for the batch matrix multiplication. The details of the LSTM model with an attention layer can be seen in Appendix 1.

# 4.1.2 Gated Recurrent Unit (GRU).

Gated Recurrent Unit (GRU) is the newer generation of RNN and is similar to LSTM with fewer gates (Cho et al., 2014). GRU consists of only two gates, i.e. update gate and forget gate. GRU does not have the cell state which is present in the LSTM cell. The update gate works similar to the input gate and forget gate combined together in the LSTM model, and the reset gate is used to decide how much past information should be remembered and how much to forget. Similar to LSTM, we have used four models for GRU as well. The first model used in GRU was a simple GRU model with random embeddings, the second model was GRU with GloVe embeddings, the third model was bi-directional GRU, and the fourth model was GRU model with an attention layer.
