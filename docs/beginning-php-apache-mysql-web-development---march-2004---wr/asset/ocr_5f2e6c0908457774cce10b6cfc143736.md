# Appendix C

| Function | Description |
| --- | --- |
| strlen(string) | Returns the length of the named string. |
| strncasecmp(string1, string2) | Using "natural order," compares two named strings (case-insensitive). |
| strcmp(string1, string2, n) | Compares first n characters of two strings. |
| strpos(string, exp) | Returns numerical position of first occurrence of named expression in named string. |
| strrchr(string, exp) | Locates the last occurrence of named expression in named string. |
| strrev(string) | Reverses the order of named string. |
| strrpos(string, exp) | Returns numerical position of last occurrence of named expression in named string. |
| strspn(string1, string2) | Returns the number of characters at the beginning of one string that match string2, opposite of strcspn. |
| strstr(string, exp) | Finds all occurrences of a named expression in a named string (case-sensitive). |
| strtok(string1, string2) | Tokenizes named string based on named parameter, string2. |
| strtolower(string) | Converts named string to lowercase characters. |
| strtoupper(string) | Converts named string to uppercase characters. |
| strtr(string, expl, exp2) | Translates characters based on the named parameters. |
| substr(string, start[, num_char]) | Returns the number of characters from the start position in named string. |
| substr_count(string, exp) | Returns the number of occurrences of named expression in the named string. |
| substr_replace(string, replacement, start[, num_char]) | Replaces text within named string based on named parameters. |
| trim(string) | Deletes extra space at the beginning and end of the named string. |
| ucffirst(string) | Converts the first character to uppercase. |
| uwords(string) | Converts the first character of each word to uppercase. |
| vprintf(format, arguments) | Displays a formatted string. |
| vsprintf(format, arguments) | Returns a formatted string as an array. |
| wordwrap(string[, width, break, cut]) | Using the named break character, this will wrap the string based on the named parameters. |
