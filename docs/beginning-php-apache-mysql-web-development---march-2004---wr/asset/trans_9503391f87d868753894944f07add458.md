

# 表单元素：让用户处理数据

```php
<?php echo $_POST['Submit'] == "Search" ? "for " : "";?>
```

这些元素的工作方式非常简单，可以将其与 if-else 结构相比较：

```
[表达式]?[如果为真]: [执行假]
```

三元运算符是一个为人知的维护性隐患。使用该运算符会降低你代码的可读性，并可能在维护阶段导致错误。
