# null/not null

Your MySQL also allows to know whether or not the field can be empty. You do this with the null or not null option. null tells MySQL that it is okay if nothing is stored in the field, and not tells MySQL to require something, anything, to be stored. If a field has been defined as not null and nothing is entered by the user, error pops up.

Don't forget that a null zero is different from a null entry.
