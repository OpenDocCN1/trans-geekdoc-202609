# Building Content Management System

The following is the search form, displayed on every page. We did not discuss this functionality earlier; we hope you discovered this little gem in your explorations of the application. Now you get to see how it works. Note that there really isn't anything going on here; it is a standard form that posts the keywords field to search.php. If there are keywords in the URL, they will be prefilled in the keywords field. We look for the search results a little later.

```
<form method="get" action="search.php">
<p class="head">
<p>
<input id="searchkeywords" type="text" name="keywords">
<?php
if (isset($_GET['keywords'])) {
echo ' ' . htmlspecialchars($_GET['keywords']) . ' ';
}
?>

<input id="searchbutton" class="submit" type="submit"
value="Search" />
</p>
</form>
```

In most cases, there are three values you save as session variables: the user's name, login ID, and access level. You use these values to determine what menu items to display. Here are the options:

+   - Article: All users
- Login: All users not logged in
- Compose: All logged in
- Review: All logged in users with access level 2 or more
- Admin: All logged in users with access level 3 or more
- Control Panel: All logged in users
- Logout: All logged in users

```
echo ' <a href="index.php">Articles</a>';
if (isset($_SESSION['user_id'])) {
echo ' |<a href="login.php">Login</a>';
}
echo ' |<a href="compose.php">Compose</a>';

if ($_SESSION['access_lvl'] > 1) {
echo ' |<a href="pending.php">Review</a>';
}

if ($_SESSION['access_lvl'] > 2) {
echo ' |<a href="admin.php">Admin</a>';
}
echo ' |<a href="cpanel.php">Control Panel</a>';
echo ' |<a href="transact-user.php?action=Logout">Logout</a>';
```
