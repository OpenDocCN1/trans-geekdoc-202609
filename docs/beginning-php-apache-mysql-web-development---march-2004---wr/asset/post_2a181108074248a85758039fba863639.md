### Checking for Format

Checking for errors in data or formatted data is required in most systems because users are not guided in their input. At this point, we need powerful regular expressions. The regular expressions allow us to define a pattern and check if it can be applied to our data. It's very useful to check for dates, numbers, and any data that has to respect a predefined set of format. It helps to always indicate the format in the source field.
