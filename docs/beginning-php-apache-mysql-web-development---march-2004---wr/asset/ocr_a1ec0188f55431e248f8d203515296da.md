A short sweet PHP ends the part of the if statement and adds an else clause. This is a very flexible way of using if...else commands with standard HTML. Because you can enter and exit PHP at any time, your pages are very flexible and easy to read.

The rest of this code is loaded if you are not an admin type.

```

```

If you are not an admin, you must be here to create a new account. Therefore, it asks you for your password:
