## powerededit.php

You will see this on every page, but we will mention it one time only. We include the config.php file that contains the constants used in the next couple of lines. By putting these constants in an included file, we can make any required changes in one place. We use the require command instead of include because of the way PHP works: An included file will not stop the processing of the rest of the page, whereas a required file, if not found, would immediately stop processing.

```php
require('config.php');
```

Next, a connection to the server is made, and the appropriate database is selected. Notice the use of the constants we define in config.php.

```php
$conn = mysql_connect(SQL_HOST, SQL_USER, SQL_PASS)
or die("Could not connect to MySQL database: " . mysql_error());
mysql_select_db($db, $conn);
```

What follows is a somewhat simple SQL statement. It is grabbing the id and power columns from char_power table, sorting them by power. This way we iterate through them later and put the data on the Web page, they will be in alphabetical order.

```php
$sql = "SELECT id, power FROM char_power ORDER BY power";
```

This executes the SQL statement and throws an error if there are any problems:

```php
$result = mysql_query($sql) or die(mysql_error());
```

![](img/7b817c5b51395b5dcaba58e6a2bc6daa_289_0.png)

We check to make sure at least one row was returned. If so, we iterate through each row, building an array of powers, using the id as the array key. Note the use of mysql_fetch_assoc. Other options are mysql_fetch_row and mysql_fetch_array. We only need an associative array which uses fields names instead of a numerical index, mysql_fetch_assoc works nicely.

```php
if (mysql_num_rows($result) > 0) {
    while ($row = mysql_fetch_assoc($result)) {
        $powers[$row['id']] = $row['power'];
    }
}
```

When retrieving data from the database, we will usually retrieve appropriate ids so that we can later insert or update the record. In this case, the id serves as the key to the array, making it easy to retrieve the values. We could certainly have used a multi-value array, but that gets a little confusing and its not necessary here. Be sure you understand that many times in this application (and many apps using relational databases) you use the id as key.

Now we are going to do a little tricky. Because our list of powers could get quite large, we want to distribute them across multiple columns. However we would like to distribute them evenly. The following lines of code do this (if you don't want to know how this part of the code works, skip this section). First, we get the count of powers in our array. Next, we set the threshold to 5, and a maximum of columns (in this case 3).

```php
$numvar = count($powers);
$thresh = 5;
$maxcols = 3;
```

Next, we determine how many columns to create. Let's assume there are 7 powers to display. First we divide the count by the threshold (7/5), which gives us 1.4. Next we use ceil() to round up to the nearest integer (ceil(1.4)=2). Then we take the smaller of the two values (3 and 2), and store it in the $cols variable. In this example, $cols would create two columns, with powers in each column (the last column will contain the remainder of powers if there are less than four).

```php
$cols = min($maxcols, ceil(count($powers)/$thresh));
$powerch = '';
```

$powerch is a string that will contain each power, with a checkbox attached to it. For now we initialize it to an empty string. Now we loop through each element of the $powers array, which contains the id as the key, and in each loop, we add the <input> tag to create the checkbox, the id as the value, and the name of the power as the label. When our counter reaches a value that is divisible by $percol, we add a close table and start a new column.

```php
$i = 0;
foreach($powers as $id => $p) {
  if ($i > 0 && $i % $percol == 0) {
    $powerch = "</td valign='top'>";
  }
  $powerch = "<input type='checkbox' name='powers[]' value='$id' <br />" . $powerch;
}
```

In our example, $i increments 0, 1, 2, and 3 in the first column. When $i reaches 4 (the value of $percol), we start a new column. If this is confusing, don't worry. You can play around with it by changing $thresh and $maxcols values, and adding a bunch of random power values to see how the table is built. For now let's check out the rest of the code.

This is the result of our loop. If there is even one power, a row is created that contains a delete button. If not, we create a row that simply states that no powers have been created.

```php
$debutton = " <tr>
<td cols='6' color='#CCCCF' align='center'>
<input type='submit' name='action' value='Delete Powers'>
<font size='2' color='#990000'><br /> <br />
deleting will remove all powers
<br />from characters as well - select wisely</font>
</td>
</tr>";
} else {
$powerch = `<div style='text-align:center;width:300;font-family:Tahoma,Verdana, Arial;'>No Powers entered...</div>`;
}
?>
```

We have left off the HTML. We assume you know HTML well enough that we don't need to explain it. As you can see in the <form> tag, when the user clicks the Add Power or Delete buttons, we'll be sending values to char_transact.php.

```php
<form action='char_transact.php' method='post' name='form'>
```

At this point, $powerch either contains the No Powers display, or the built up columns. Either way, we insert $powerch into the table. Note the open and close definitions (td valign='top'> and </td). We didn't add them to $powerch earlier, but we did the internal close/open definitions to create the classes.

```html
<table border='0' padding='5'>
<tr bgcolor='#FFCCC0'>
<td valign='top'><php echo $powerch; ?></td>
</table>
```

In the following, $debutton either contains the row with the delete button (if powers were found), or it's blank. That is how we use PHP to control when it is, how it shows up, and where it's inserted into the table.

```php
<?php echo $debutton; ?>
```
