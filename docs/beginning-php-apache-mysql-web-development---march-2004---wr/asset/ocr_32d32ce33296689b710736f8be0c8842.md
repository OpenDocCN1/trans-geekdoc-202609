Now we move to sendconf.php. Much of it is similar to pc_sendmail.php, so we'll just touch on some of the important points:

```
if (!empty($_POST["postcard\])) {
    foreach($_POST["postcard"] as $value) {
        $postcard = $value;
    }
}
```

Remember, $postcard is another simpler method of getting the value of the postcard would have been to use the 0 key of the $postcard array:

```
$postcard = $_POST["postcard"][0];
```

However, to get the first value in the $postcard array regardless of the key you use, the foreach() loop. must use the if statement if there is no $postcard array, foreach() returns an "invalid argument". Yes, we know currently that a postcard value is always posted to the sendconf.php, but if you make a change to postcard.php (for instance, to make the postcard image optional), you don't want sendconf.php to break, right?
