# How It Works

Our change.php file updates the quantity of whatever line is clicked with these lines:

```
$query = "UPDATE carttemp
SET quan = '$qty';
WHERE hidden = '$hidden';"
```

Likewise, with the delete.php file, the items are deleted with this line:

```
$query = "DELETE FROM carttemp WHERE hidden = '$hidden';"
```

In each of the files, we display the cart once so that our customers can see their cart currently contains.
