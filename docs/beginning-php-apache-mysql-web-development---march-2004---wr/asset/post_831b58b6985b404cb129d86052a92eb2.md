
# URL Functions

The functions in the table that allow you to handle URLs within your PHP code.

| Function | Description |
| --- | --- |
| base64_decode(string) | Decodes an encoded string, opposite of base64_encode. |
| base64_encode(string) | Encodes a string, opposite of base64_decode. |
| parse_url(url) | Parses the URL into components. |
| urldecode(string) | Decodes an encoded string, opposite of urlencode. |
| urlencode(string) | Encodes a string, opposite of urldecode. |

# MySQL Data Types

See the table that follows for the potential data or field types in MySQL.

| MySQL Field Type | Description |
| --- | --- |
| bigint (length) | Numeric field that stores integers from -922337203685475808 to 922337203685475807. (Adding the unsigned parameter allows storage of 0 to 18446744073709551615.) The parameter length limits the number of characters to be displayed. |
| bit | Equal to tinyint field. |
| blob | Equal to a text field, except it is case-sensitive when sorting and comparing. Stores up to 65535 characters. |
| bool | Equal to tinyint field. |
| boolean | Equal to tinyint field. |
| char (length) | Any characters can be in this field, but the field will have a fixed length. |
| date | Stores a date as yyyy-mm-dd. |
| datetime | Stores date and time as yyyy-mm-dd hh:mm:ss. |
| dec(length,dec) | Equal to decimal field. |
| decimal(length,dec) | Numeric field that store decimals. Length limits the number of characters that will be displayed, and the dec parameter limits the number of decimal places that can be stored. A price field that would store prices up to 999.99, for example, would be defined as decimal(6,2). |

# MySQL Quick Reference

In this appendix we have listed some quick reference notes for your use. These topics are covered in more depth in Chapter 3 and on the MySQL Web site at www.mysql.com.

## Database Manipulation Commands

| Command | What it does |
| --- | --- |
| CREATE databasename | Creates the database |
| CREATE tablename (field1, field2, field3, and so on PRIMARY KEY(field)) | Creates a new table |
| ALTER TABLE tablename WHERE | Modifies the table in the database |
| RENAME TABLE oldtablename TO newtablename | Renames a table in the database |
| INSERT INTO tablename (field1, field2, ...) VALUES ("value", ...)) | Inserts information into the table |
| UPDATE tablename SET field1=value, field2=value2... WHERE condition | Changes information already stored in the table |
| DROP tablename | Deletes the table |
| DROP database | Deletes the table |
| LOAD DATA INFILE "filename" INTO TABLE tablename | Loads a large quantity of data into the database |
