Typically, user.php loads empty, without any extra data. Occasionally, you may return to this page from elsewhere, and will have the user id of person loading the page. In this case, you tack on u=x to the end of the URL (x is the user id, such as 3). This bit of code detects the presence of value:


and puts it into a variable:


### user_transact.php

This is where the action happens, for the most part. Let's take a look, shall we?

First, make the connection to the server, and select the database:

```php
$conn = mysqli_connect(SQL_HOST, SQL_USER, SQL_PASS);
or die("not connect to MySQL database. " . mysql_error());

mysqli_select_db($ML_DB, $conn);
```

You will be the e-mail sender. The parameter $headers will be the fourth parameter of the mail() function, and you will insert an Address from the e-mail.

```php
$headers = "From: " . ADMIN_E_MAIL . "\r\n";
```

For more information about headers, see Chapter 10. When loading user_transact.php, you either clicked a button 'action' (POST), or action is in the URL as action=xyz (GET). Because it come across as a POST or a GET, you use $_REQUEST to get the value. The variable $_REQUEST your "catch-all" predefined variable, which contains an associative array of $_GET, $_POST, and $_COOKIE variables.

```php
}
```
