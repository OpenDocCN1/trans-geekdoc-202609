## How It Works

This requires some explaining. First, let's look into the type validating functions.

In the commit.php code, we use the is_numeric() function. This function returns a Boolean TRUE if the value is indeed numeric and FALSE if not. There are more of these validating functions, including:

- is_string, which checks to see if the value is of the string format
- is_bool, which checks for Boolean type (TRUE, FALSE, 0 or 1)
- is_array, which tells you if the variable holds an array
- is_object, which determines if the variable stores an object (remember this one when you try coding using PHP; it is very useful)

```php
$movie_release = trim($_POST['movie_release']);
if (!preg_match('/([0-9]{2})-([0-9]{2})-([0-9]{4})/', $movie_release, $redatepart) ||
empty($movie_release)) {
    $Error = "Please+enter+a+date+with+the+dd-mm-yyyy+format+%21%0D%0A";
} else {
    $movie_release = mktime(0, 0, 0, $redatepart[2], $redatepart[1], $redatepart[3]);

```

As you can see, this first use the `trim()` function to clear all leading and trailing spaces in the received string to make sure our user enters something other than just space.

> The string manipulation functions are found at the PHP site at www.php.net/strings. You can find them very useful there.

The next statement contains two tests for a regular expression match. The regular expression is '/([0-9]{2})-([0-9]{2})-([0-9]{4})/. What does this do? [0-9]{2} specifies that we want to check for numbers between 0 and 9 with two occurrences. For example 02 matches but not 2. The same logic applies to the [0-9]{4} statement: the only difference is that we are expecting four digits in our number. These four digits are the year part of the date.

So, in English, it means: I want to start with a number with two digits, followed by a hyphen (-), another group of two digits, and a hyphen (-), and finish with a four-digit number.

```php

```

Now, this is not exactly what our regular expression says. It says that if it matches, we will split it into three chunks, each chunk delimited by the parentheses. This cutting is performed by the `preg_match` function. If the $movie_release string matches the pattern, preg will cut the string into parts and store each part as an element of the $releasepart array in our example.

Be sure to read the PHP manual about regular expressions at www.php.net/regex and consult a few tutorials to learn the power of using regular expressions. (A starting tutorial can be found at www.phpbuilder.com/columns/dario19990616.php)

If our date was 02-03-2003, the array would be as follows:

- [0] => 02-03-2003
- [1] => 02
- [2] => 03
- [3] => 2003

As you can see here, the first index holds the whole string, and each chunk holds a cut-off part of the string, delimited by the parentheses.

Now that we have our data in an understandable format, we can change it into a timestamp using the mktime() function, which allows you to create a timestamp from chunks of dates. It is also a very useful function to manipulate dates.

```php
$movie_release = mktime (0, 0, 0, $relatepart[2], $relatepart[1], $relatepart[3]);
```

This code stores a timestamp from the day, month, and year information fed to the system in the $movie_release variable. The format is mktime (int hour, int minute, int second, int month, int day, int year). The returned value is the number of seconds since January 1, 1970, and the specified date. See documentation at www.php/mktime for additional information regarding optional parameters such as daylight saving.

If mktime fails to create a timestamp from the date you passed to, it will return -1. This happens when the input is invalid, although it matches the regular expression. To be sure that the date is valid, we will test the value for mktime and return accordingly.

```php
if ($movie_release == '-1') {

```

In this case, false date entry triggers an error message asking for a valid date.
