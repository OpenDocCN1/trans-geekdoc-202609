### 检查格式

在大多数系统中，都需要对数据或格式化数据进行检查，因为用户在输入时没有得到引导。在此阶段，我们需要强大的正则表达式。正则表达式允许我们定义一个模式并检查它是否可以应用于我们的数据。对于检查日期、数字以及任何必须遵守预定义格式集的数据非常有用。这有助于在源字段中始终标明格式。
