# # Appendix C

| Function | Description |
| --- | --- |
| get_class_vars(class_name) | Returns the properties for the specified class, in an array format. |
| get_declared_classes() | Returns all the classes that have been defined, in an array format. |
| get_defined_functions() | Returns all the functions that have been defined, in an array format. |
| get_object_vars(object_name) | Returns the properties for the specified object, in an array format. |
| get_parent_class(object_name) | Returns the name of the specified object's parent class. |

| register_tick_function(function) | Registers a function for execution every tick. |
| unregister_tick_function(function) | Unregisters a function previously registered using register_tick_function. |

# # Directory and File Functions

These functions can modify your directory settings and allow you to work with files through your PHP script.

| Function | Description |
| --- | --- |
| basename(path) | Returns the filename listed in name path. |
| chdir(directory) | Makes the named directory the current one. |
| chgrp(filename, group) | Assigns the name file to the named group. |
| chroot(directory) | Makes the named directory the root directory. |
| chmod(filename, mode) | Changes the mode of the named file. |
| chown(filename, owner) | Changes the owner of the named file. |
| clearstatcacheache() | Clears the file stat cache. |
| closedir(directory) | Closes the named directory. |
