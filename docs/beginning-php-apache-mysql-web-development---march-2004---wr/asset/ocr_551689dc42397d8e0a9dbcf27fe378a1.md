# Letting the User Edit the Database

```
$movie_name = $row['movie_name'];
$movie_type = $row['movie_type'];
$movie_year = $row['movie_year'];
$movie_leaderactor = $row['movie_leaderactor'];
$movie_director = $row['movie_director'];
break;
default:
$movie_name = "";
$movie_type = "";
$movie_year = "";
$movie_leaderactor = "";
$movie_director = "";
break;
?>
```

The variables set in the preceding code are used to set the default value of the form fields. Each field has a known value if you are editing a record and has a void value if you are creating a record.

```
<tr>
<td bgcolor="#ffffff" width="30%">
Movie Name
</td>
<td bgcolor="#ffffff" width="70%">
<input type="text" name="$movie_name" value="<??=$movie_name?>">
</td>
</tr>
```

In this example, the movie_name field takes the $movie_name variable content as a default value. This allows us to reload the data from the record to edit it.

Editing a text field is pretty straightforward. Editing a value in a list is another story. You can't just display the list and hope it will reset to the original when he or she edits the record. You need to reload the whole list and make the previously set value as a default in the list so the user can just forget it if he or she doesn't want to edit.

How do you do this? The script holds the solution:
