# Alternates to the echo Command

You already got a taste of `print_r()`, but you can also use the `print()` to display text or variable values in your page. The difference between `echo()` and `print()` is that when using `print()`, a value of 1 or 0 will also be returned upon the success or failure of the print command. In other words, you would be able to tell if something didn't print using the `print()` command, `echo()` just does what it's without letting you know whether or not it worked properly. For all other intents and purposes, the two are equal.
