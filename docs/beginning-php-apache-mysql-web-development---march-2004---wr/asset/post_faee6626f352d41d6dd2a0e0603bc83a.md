## Using Log Files to Improve Your Site

### Now That I Know and Where They Are, What do I Do with Them?

There are numerous software programs out there to help you take this gobbledyg-gook and make sense out of it. Note that most of these programs are used for analyzing Web server activity, and not MySQL or PHP.

### Webizer

Webizer can be found at www.webizer.com and is a proud part of the wonderful open source community we talked about in Chapter 1. It provides reports in an easy-to-read HTML format with pretty charts and can be read by just anyone, including the higher-ups. Its main purpose is to spit out on server activity, specifically Apache. It is meant for use on UNIX systems, and thus far, isn't compatible with Windows. If you set your Apache config files to DNS server lookups, your reports with Webizer will show those simple IP addresses. This program is also known for its incredible speed, as it can process 10,000 records in a matter of two seconds.

You can see a screenshot in Figure 16-2, also available at the Webizer site.

![](img/7b817c5b51395b5dcaba58e6a2bc6daa_601_0.png)

### Analog

Another open source contender for helping you make sense of your log files is Analog, which you can find at www.analog.cx. While it's a little rough around the edges, it's still a powerful tool that can be customized to show what you want to see. By using the add-on, Report Magic (available at www.reportmagic.org), you can generate all kinds of fancy 3-D charts and graphs and really impress your superiors (or if you're a one-man or one-woman show).

You can see screenshots in Figures 16-3, 16-4, and 16-5, also available at the Analog Web site.

### WebTrends

If you've got money to throw around, WebTrends (with www.analytics.com) is another good log analyzer program. It works on numerous platforms, including Apache, and is really given a lot of control over what your output looks like. We recommend this software if you have a high-powered server and are a high-powered client who wants fancy stuff like his own. The customization is really a great feature. This also allows to track specific things about your site with the use of client-side tags in your HTML. This bypasses the "log" step and sends the info to WebTrends. It can even perform DNS lookup if you forget to enable this in your config files, or if you want to reduce server activity. Again, this powerful software is not for the faint of heart and reserved for the heavy-duty users. You can see a screenshot—provided by the Web site—in Figure 16-6.

### AWStats

Another of our focus builds, AWStats can be found at http://awstats.sourceforge.net/. Don't be fooled by its price tag—this free software provides numerous features offered by the big guys. Unlike some of the other open source stats programs, AWStats can track the unique number of visitors; entry and exit pages; engines and keywords used to find the site; and browser details of each visitor, as version and screen size.

AWStats also allows the administrator to use customized reports for tracking something of interest for him or her specific needs, which is a welcome addition to this software package. You can see a screenshot in Figure 16-7, also available at the AWStats Web.

![](img/7b817c5b51395b5dcaba58e6a2bc6daa_605_0.png)

### HTTP Analyze

One more programs for you to investigate can be found at http://http-analyze.org. Another open source favorite, which works on any log file that is the N Common Log Format or W3C Extended File Format, and thus works great with Apache. It should be noted that HTTP Analyze is supported by both UNIX and Windows systems. It also provides several options for viewing data, all in HTML and easy-to-read formats.

You can see a screenshot in Figure 16-8, also available at the HTTP Analyze site.
