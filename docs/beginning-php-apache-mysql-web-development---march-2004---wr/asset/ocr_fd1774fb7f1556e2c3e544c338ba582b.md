Throw an echo there to see where your problems are. Don't give up at the first sign of defeat: you exhaust all of your programming resources before you go for help else.

# Parse Errors

A parse error is another main error type. Parse errors occur when you forget a semicolon; when curly braces are mismatched, when square brackets aren't used properly, and so on. These errors usually don't have to do with a condition statement; they mainly syntax errors that will cause the script to halt execution. Parse errors are worse than fatal errors because they won't even let the script run at all; they merely give you the error information.
