We check to make sure at least one row was returned. If so, we iterate through each row, building an array of powers, using the power id as the array key. Note the use of mysql_fetch_assoc. Other options are mysql_fetch_row and mysql_fetch_array. We only need an associative array which uses fields names as keys instead of a numerical index, mysql_fetch_assoc works nicely.

```
if ($mysql_num_rows($result) > 0) {
    While ($row = mysql_fetch_assoc($result)) {
        $pwrlist[$row['id']] = $row['power'];
    }
}
```
