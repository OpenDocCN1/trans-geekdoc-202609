# Dynamic Page Title

This code is rather simple to understand: You don't start output as soon as you start executing the PHP script. What often happens is at the start of the scripts there will be a check for intrusion and context verification. In this instance, you dynamically set the page title using the action type and item type you will to handle the page.

```
$title = $_POST['Submit']*".*$_POST['type']*".*$_POST['Name'];\n?>
<html>
<head>
<TITLE><?php echo $title?></TITLE>
...
```

# Manipulating a String as an Array to Change the Case of the First Character

Single string characters can be accessed through a very simple syntax that is similar to array index access. Specify the index of the character you want to access voilà! To change the case of a character or an entire string, use the strtolower() function:

```
$name = $_POST['Name'];
$name[0] = strtolower($name[0]);
...
```

We could have used the ucfirst() function (which essentially does what the code explained previously), but by a bit of creativity couldn't hurt.
