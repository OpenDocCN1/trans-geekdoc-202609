# WHERE, or oh WHERE

The beast clause WHERE deserves its own little section because it's really the meat of the query. (No
ofense to the other guys, but they are pretty much “no brains”) WHERE is like a cool big brother that
 do some interesting stuff:

+   - Comparison options are the heart of the WHERE clause, and they include the following:
- =, >, <=, != =
- LIKE and %: Oh we like LIKE. LIKE lets you compare a piece of text or number
gives you the % as a wildcard.
Example:

```
SELECT * products WHERE description LIKE "%shirt%"
```

This gives you records that have the word or text pattern of “shirt” in the descrip-
tion Fabulous. (Like, totally).

+   - Logical operators are also accepted in the WHERE clause:

```
SELECT * products WHERE description LIKE "%shirt%" AND price < 25
```

This gives you all the products that have the word or text pattern of “shirt” in the description
dan have a price of less than $25.
