If a character id is found, attempt to pull the data from the database. This SQL statement is a JOIN, although the JOIN key is not used. You can identify this as JOIN because there are two or more tables, and the WHERE key is matching columns from each of the tables. The JOIN in this case is once the tables are joined, all appropriate fields are pulled as long as the character in the character table matches $char. If there is no match, no record will be returned. If there is a match, one record is returned and stored in $char.
