This lets us know that the MySQL server started successfully, what version is currently running, and what socket and port it is configured for. It also gives the date and time that the server began running (in the first line). It should also be noted that this log cannot be accessed while the server is running; you need to stop the server to open this file.

MySQL allows you to see every query that is sent to the server. Where the general query log is located, you type the following command when starting the MySQL server:

```
mysqld --log=[file]
```

Again, by default, this file will be stored in the “data” directory with the name hostname.log file, unless you specify otherwise. An entry in the general query log looks like this:

If you are interested in seeing only the queries that changed data, you should view the binary log file instead of the general query file. With previous versions of PHP you would have used the update log, but it is highly recommended that you begin using the binary log index.

> The update log will be phased out with the release of PHP 5.0.

This file is also saved by default in the “data” directory, with the filename of hostname-bin unless you specify otherwise. You activate this log by typing the following at the command prompt:

```
mysqld --log-bin=[file_name]
```
