Let's take a look at how we paginate a page of posts. Most of the code can be located in functions.php.

In viewtopic.php, you can see that we create a variable called $limit and that it is grabbed from the $admin array that sets limit in config.php:

```
$limit = $admin['pageLimit']['value'];
```

Now we take a look at showTopic() in functions.php. We will list the rows relevant to pagination only:

```
global $limit;

if (isset($_GET['page'])) {
    $page = $_GET['page'];
} else {
    $page = 1;
}
if ($limit == "") $limit = 25;
$start = ($page - 1) * $limit;
```

Declaring $limit makes the variable in viewtopic.php available to the function. If we don't pass $page to the Web page, we assume we are on page 1. Otherwise, we set $page to the value passed to us in the URL. By knowing the page, and limit (number of posts per page), we can calculate our $start (which will be used by the LIMIT statement in the SQL to retrieve rows). For example, if we are on page 3, and limit is 25 posts per page, then the third page will display rows 51 through 75.

Here is the SQL statement for returning posts. It is long, but not overly complex. It is four tables joined by JOIN statement. Please note the first line and the last line of the SQL statement:

```
SELECT SQL_CALC_FOUND_ROWS *
    p.id, p.body, p.date_posted,
    p.date_updated, u.name as author_name, u.id as author_id, 
    u.signature as sig, c.postcount as postcount,
    f.forum_id as forum_id, f.forum_moderator as mod,
    p.update_id, u2.name as updated_by
FROM forum f
JOIN forum_posts p
    ON f.id = p.forum_id
JOIN forum_users u
    ON u.id = p.author_id
LEFT JOIN forum_users u2
    ON u2.id = p.update_id
LEFT JOIN forum_postcount c
    ON u.id = c.user_id
WHERE (p.topic_id = $topicid OR p.id = $topicid)
ORDER BY p.topic_id, p.date_posted
```

This query will return a maximum of the number of rows in limit. The problem is, we need to know how many rows would have returned if LIMIT had not been used. Fortunately, MySQL provides a means for us to find out.

In the first line, we are using the SQL SQL_CALC_FOUND_ROWS. This doesn't do anything to the query directly. It slows it down slightly, but it allows us to run the following SQL command:

```
$sql = SELECT FOUND_ROWS();
```

This command, when run, returns the number of rows that SQL_CALC_FOUND_ROWS found. Although SQL_CALC_FOUND_ROWS makes the query take a little longer, it is still more efficient than running the query second time with COUNT(*). Okay. We have our numbers to create the page links.

```
function paginate($limit=10) {
  global admin;

  $sql = SELECT FOUND_ROWS();
  $result = mysql_query($sql) or die(mysql_error());
  $row = mysql_fetch_array($result);
  $numrows = $row[0];
  $pagelinks = "<div class='pagelinks'>";
  if ($numrows > $limit) {
    if (isset($_GET['page'])) {
      $page = $_GET['page'];
    } else {
      $page = 1;
    }
  } else {
    $pagelinks .= "<span class='pagedead'>&lt; PREV</span>&nbsp;&nbsp;";
  }
  // ... logic continues
  return $pagelinks;
}
```

Our function takes one parameter, $limit. If $limit is not passed in the function, we set limit to a default value of 10. Because our focus is now in a function, in order to access admin variables (range and limit), $admin must be declared global. As you can see, by using FOUND_ROWS(), $numrows contains the number of rows your query returns. As long as the number of rows is larger than our limit, we'll generate pagination links. Otherwise, we'll just display inactive links.

Next, we grab the page variable if is set. If not, we set $page to 1. Our next step is to determine whether the PREV link be activated. Obviously, if we are on page 1, there is no previous page. Otherwise, the previous page is the current page minus 1:

```
if($page == 1) {
  $pagelinks .= '<span class="pageprev">&lt; PREV</span>&gt; ';
} else {
  $page = $page - 1;
  $pagelinks .= '<a class="pageprevlink" href="$currpage.php?page=$page">...</a>';
}
```

The next bit of code does a bit of math. We are defining a few things in this code block. The number of pages is determined by dividing the total number of rows returned by our FOUND_ROWS() query by the number of pages per page ($limit) and rounding up. Next, the range is grabbed from global $admin['pagerange']. If not available, $range defaults to 7. This value determines how many pages are accessible via a link at the bottom of the page. For example, if the range is 5, there are 13 pages, and we are currently viewing page 6, we will have access to pages 4, 5, 6, 7, and 8:

```
$numpages = ceil($numrows / $limit);
$range = $admin['pagerange']['value'];
if ($range == "" or $range == 0) $range = 7;
```

The next few lines determine range of pages to show you. In the example, if the $range is 5, you are viewing page 2 of 13 pages, the code should be smart enough to allow access to pages 1 through 5. As you can see, if you are viewing page 2, you can get to pages 1 through 7, and there are more pages past 5. The logic determines which pages are accessible is the following:

```
$range = max(1, $page-$range-1)/2);
$rrange = min($numpages, $page+($range-1)/2);
if (($rrange - $range) < ($page - 1)) {
  if ($range == 1) {
    $rrange = min($range + ($range-1), $numpages);
  } else {
    $range = max($range - ($range-1), 0);
  }
}
```

Next renders the space between PREV and NEXT. If the lower range is higher than 1, put "..." to show by clicking PREV. Then, use the $range values to build the page number links. If the link corresponds to the current page, don't make it link. Next, if the high end of the range of pages is lower than the total number of pages available, put in "..." to show there are more pages by clicking NEXT:

```
if ($range < 1) {
    $pagelinks = ".";
} else {
    $pagelinks = "&nbsp;&nbsp;";
}
for($i=1; $i <= $numpages; $i++) {
    if($i == $page) {
        $pagelinks = "<span class="pagenumdead">$i</span>";
    } else {
        if ($range <= $i && $i <= $range) {
            $pagelinks .= "<a class="pagenumlink" href="$currpage.php?page=$i/"></a>";
        }
    }
}
if ($range < $numpages) {
    $pagelinks .= ".";
} else {
    $pagelinks = "&nbsp;&nbsp;";
}
```

The last part is to render NEXT as clickable or not, depending on whether or not you are looking at the last page of the thread. Doing this is relatively simple:

```
if(($numrows - ($limit + $page)) > 0) {
    $pagenext = "<a class="pagenextlink" href="$currpage.php?page=" . ($page+1) . "\">NEXT</a>";
} else {
    $pagenext = "<span class="pagenextdead">NEXT &gt;/</span>";
}
```

You may notice that this code generates simple text links for the pages. This is true. However, each element is surrounded by <span> tags, which allows us to use style sheets to easily modify the look of these links.

Voila! You have a terrific, customizable, dynamically builtin function.
