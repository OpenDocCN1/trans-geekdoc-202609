# E-mailing with PHP

Finally, the following sends the e-mail. Don't be confused by the variable $from. That actually controls who this e-mail is being sent to. That's the whole idea behind sending out this confirmation-email.

```
$mailsent = mail($from, $confirmsubject, $message, $headers);
```

When the receiver receives the confirmation-email, there is a link at the bottom:

```
$confirmmessage =
```

When user clicks the link, confirmmail.php is loaded in her browser, with ?id plus the unique validation ID. This is used within confirmmail.php to access the proper postcard in the database, compose the e-mail, and send it on its way. A quick reminder: If you set your variables like this, you never have to worry about the register_globals setting in your php.ini file.

```
$id = $_GET['id'];
```

The following gets all postcards that match your ID. Of course, there should always be one match, because id is unique.

```
$sql = "SELECT * FROM confirm WHERE validator = '$id";
```

The array $pcarry contains all of the postcard data you need to send the postcard to its intended recipient:

```
$query = mysql_query($sql, $conn) or die(mysql_error());
$pcarry = mysql_fetch_array($query);
```

Here's a little to make sure you don't try to send a postcard if no postcard data exists. Of course, you will find a much more elegant error message, won't you?) This might be a good place for the PHP header () to redirect the user to a "more information" error page.

```
if (is_array($pcarry)) {
  echo "Oops! Nothing to confirm. Please contact your administrator";
  exit;
}
```

The following lines are not entirely necessary. They do make life easier, if you have to refer to the multiple times. It is good to have your variables in a centralized location; if something goes wrong, you have one place to look.

```
$to = $pcarry['to-e-mail'];
$toname = $pcarry['toname'];
$from = $pcarry['from-e-mail'];
$fname = $pcarry['fname'];
$bcc = $pcarry['bcc-e-mail'];

$postcard = $pcarry['postcard'];

```
