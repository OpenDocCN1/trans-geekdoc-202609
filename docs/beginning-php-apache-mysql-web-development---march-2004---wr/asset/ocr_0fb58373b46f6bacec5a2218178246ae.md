As long as you have keywords, you do a search. In the following SQL statement, you'll notice the MATCH and AGAINST keywords. This is the syntax used to do a text search in those fields. They must be full-text indexed fields in order to perform this search. Visit www.mysql.com/doc/en/fulltext_html for more information on full-text indexed.

```
$result = NULL;
if (isset($_GET['keywords'])) {
  $sql = "SELECT article_id FROM cms_articles *\n  WHERE MATCH (title,body) \
  AGAINST ('*" . $_GET['keywords'] . '\*\') \
  ORDER BY MATCH (title,body) \
  AGAINST ('*" . $_GET['keywords'] . '\*\') DESC";
```

```
$result = mysql_query($sql, $conn)
or die("Could not perform search: " . $mysql_error());
```

If you didn't find a match, so:

```
echo "<h1>Search Results</h1>";

if (!$result || mysql_num_rows($result)) {
  echo "<p>No articles found that match the search terms.</p>"\n";
```

Otherwise, loop the results and display them as snippets on the screen:

```
} else {

    outputStory($row['article_id'],TRUE);
  }
}
```
