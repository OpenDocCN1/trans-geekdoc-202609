# How It Works

You can see that several things are accomplished in this script. We now have a new database called “ecommerce” with four tables in it. The first table is named products and contains the list of products available.

| Fieldname | Type | Description of What It Stores |
| --- | --- | --- |
| prodnum | CHAR (5) | The individual product number assigned to each product. |
| name | VARCHAR(20) | A brief title for the product, such as “CBA Logo T-shirt.” |
| proddesc | TEXT | A longer description we can use on the individual page for that product. May contain HTML code. |
| price | DEC (6,2) | Price of the product up to 999.99. |
| dateadded | DATE | Date the product was added to the site. |

The next table is named customers and contains the list of customers and their information.

| Fieldname | Type | Description of What It Stores |
| --- | --- | --- |
| custnum | INT (6) | The individual customer number assigned to each customer. This will increment. |
| firstname | VARCHAR(15) | Customer’s first name. |
| lastname | VARCHAR(50) | Customer’s last name. |
| add1 | VARCHAR(50) | Customer’s address: line 1. |
| add2 | VARCHAR(50) | Customer’s address: line 2 (can be null). |
| city | VARCHAR(50) | Customer’s city. |
| state | CHAR (2) | Customer’s state. |
| zip | CHAR (5) | Customer’s zip code. |
| phone | CHAR (12) | Customer’s phone number (in xxx-xxx-xxxx format). |
| fax | CHAR (12) | Customer’s fax number (same format as phone number, can be null). |
| email | VARCHAR(50) | Customer’s e-mail address. |
