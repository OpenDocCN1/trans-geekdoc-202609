# Online Selling: A Quick Way to E-Commerce

# How It Works

We must call the session_id() function before the session_start() function so session_id value doesn't get overwritten and the current session ID is maintained. The session_id() function simply returns the current session ID (assigned by the browser) and lets us use its value later in the script (which, conveniently we did, through the $_sess variable).

We again rename POST variables for simplicity's sake in our queries and then run insert query to put the information we have collected in the temporary table.

The next to last line is we include our shopping cart, so the customer can see that, yes, the product was successfully added to the cart, and he or she can view all the products there.
