## How It Works

When PHP comes across an include line in a script, it stops working on the current program and immediately shifts over to whatever file it's told to include. The server parses that second file and carries the results back to the original file, where the parsing continues from where it left off.

Suppose we decided we didn't really want the date to be shown with the trailing zeros. Luckily, PHP has a solution for when formatting the date function. Make the following change to your header.php file and see what happens:

```php
<div align="center"><FONT SIZE="4">Welcome to my movie review site!</font>
<br>
<?php

echo "Today is ";
echo date("F j");
echo " ";
echo date("Y"); 
</div>
?>
```

Your problem is fixed, and it's fixed in all the pages in your site, in one fell swoop.

## Using Functions for Efficient Code

With includes, using functions makes your code (and your typing) more efficient and easier to debug.

Functions are blocks of code that can be called from anywhere in your program. They enable you execute lines of code without having to rethink every time you want to use them. Functions can help set or update variables, and can be nested. You can also set a function to execute only if a certain criterion has been fulfilled.

Functions are mini-programs within themselves. They don't know about any variables around unless you let the other variables access the function through a door called "global." We use the global $varname command to make an variable's value accessible to the function. This does not apply to any variables passed with any variables that are global by default, as $_POST, $_GET, and so on.

Your function can be located anywhere within your program and can be called from anywhere your program (is a change from PHP3). Therefore, you can list all your commonly used functions at the top of your program, and they can be kept for easier debugging. Better yet, you can put all your functions in a file and include them in your program. We're rolling!

PHP provides you with a comprehensive set of built-functions (which can be found in Appendix C), but sometimes you need to create your own customized functions.
