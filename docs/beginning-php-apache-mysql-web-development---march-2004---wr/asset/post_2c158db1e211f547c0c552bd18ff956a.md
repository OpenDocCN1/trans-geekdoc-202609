Directory > Computers and Internet > Software > Internet > World Web > Servers > Server Side Scripting > PHP

It is a map of subdirectories telling you exactly to the category you are looking at. (probably a fan of gingerbread houses, but don't quote me on that) said "map" and decided to call it a breadcrumb list. The name stuck.

The truth is, breadcrumbs are very helpful, and they make a lot of sense for a bulletin board forum. They can give you a map from the page you are reading, to the thread it was in, to the forum it was in, to the category it was in. Perhaps like this:

Home > Comic Book Movies > Spider-Man > This movie rocked! > I agree

By allowing you to click on any part of the breadcrumb, you can easily navigate to another part of the site.

# Afterthoughts

Congratulations! You have just completed the creation of a fully functioning bulletin board system. It is more powerful than some of the simpler ones you'll find, but it is not the most complex. There are many things you could still do to this application that could make it really, if you were so inclined.

What else could you add to this application? Perhaps have a few ideas already, based on what you have seen on other forums. If you need some ideas, here is a short list to get you started:

- Avatars: Allow your users to upload (or choose from yours) a small image that can be placed under it or her username.
- Smiles!: Most forums will replace replicas with a graphical representation of some sort. Create some smileys yourself (find good ones on the Internet that are not copyrighted), store them in an images folder on your Web site, and use regular expressions to replace smileys with the appropriate images.
- User profiles: Allow users to add more information to their profiles, such as hobbies, location, age, sex and so on. Also allow them to add their AIM, Yahoo!, and MSN IDs. Make sure their usernames into a link that allows users to contact them via e-mail or Instant Messenger. Make sure you include a checkbox to allow users to hide their e-mail address, if they want to.
- Quoting: What is a forum without the ability to quote relevant text? Allow users to quote all or part of a post. We leave it to you to figure out how to implement it.
- Polls: A very popular option, polls users to post a short questionnaire for their peers to answer. Install a poll when posting a new topic, and display a graph of the results at the top of the thread.

That should keep you busy for a while. Good luck!
