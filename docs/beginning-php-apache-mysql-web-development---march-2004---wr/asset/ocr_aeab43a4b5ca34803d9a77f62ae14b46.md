First, you display the title of the page, and then use the outputStory() function to display the article on the page.

```
<form method="post" action="transact-article.php">
<h2>Article Review</h2>
<?php
outputStory($_GET['article']);
?>
```

It is important to note that we passed only one variable to the function outputStory(), even though outputStory() takes two arguments. The second argument is $only_snippet, which defaults to FALSE. Because we did not use the second parameter, PHP automatically uses its default value. If there were no default value assigned, attempting to call outputStory() with only one argument would result in a PHP warning telling us that we are missing an argument. This allows for more flexible functions.
