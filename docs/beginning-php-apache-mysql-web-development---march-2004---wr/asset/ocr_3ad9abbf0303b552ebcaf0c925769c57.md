Here is our first query, and incidentally, the only one we use in the extent. The it is fairly similar to INSERT and SELECT queries, with the exception of the SET keyword. The SET keyword tells MySQL what columns to set, and what values to set them. The old values are in reverse order. This is a JOIN query because there is more than one table. The WHERE query specifies the linking column (char_id) and the condition that only runs for this character

```
$sql = "UPDATE char_1, char_main m SET 1.zip_id='$zip',\n1.lair_address='$address', alias='$alias', real_name='$name',\nalign='$align' WHERE m.id = $cid AND m.lair_id = 1.id";
$result = mysql_query($sql) or die(mysql_error());
```

Because the power_link table does not have an automatically incremented column as the primary key, we don't have to update the table. An update is possible, but it is much easier to simply delete all the old links of character to power, and insert new link rows. In some cases, we may be deleting and inserting the same data (for instance, we may be flying as a power, but invisibility will still be deleted and reinserted). When updating data in a M/N relationship, you usually delete the old data, and insert the updated/new data.

```
$sql = "DELETE FROM power_link WHERE char_id = $cid";
$result = mysql_query($sql) or die(mysql_error());
```
