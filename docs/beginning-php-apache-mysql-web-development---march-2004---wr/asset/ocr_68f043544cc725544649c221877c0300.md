# User Administration

Users require a similar treatment, although this treatment is a bit different from the $admin array.

The first thing we need is to gather all of the access levels, along with their names. That is done with the following code, which results in a numerical array of Access Levels:

```
$sql = 'SELECT access_lvl, access_name FROM forum_access_levels *\nORDER BY access_lvl DESC;
$result = mysql_query($sql) or die(mysql_error());\nwhile ($row = mysql_fetch_array($result)) {
  $users[$row['access_lvl']] = $row['access_name'];
}
```

Next, we create an HTML select field, dynamically building it up with the options. Using the access level we've created, we can also use the optgroup tag to categorize the select list by access level. (Aren't we clever?)

```
<select id='userlist' name='userlist'>
<?php
foreach ($users as $key => $value) {
  echo '<optgroup label=\'. $value. '\>\n';
  userOptionList($key);
  echo '</optgroup>\n';
}\n?>
</select>
```
