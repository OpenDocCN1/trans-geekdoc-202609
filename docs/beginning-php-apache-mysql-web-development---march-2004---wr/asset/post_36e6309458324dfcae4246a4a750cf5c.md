## How It Works

We've changed the name of $query to $movie_query, and also changed $result to $movie_result. This was done to ensure that we do not confuse ourselves when accessing the relevant results returned from a SQL query. There is also an "order by" clause, which ensures that the most recent reviews are at the top of the page.

A fundamental mistake that lot of beginners make is to use the same variable names when creating SQL queries (for example, $query = "SELECT ..."). Let's assume that we simply copied and pasted, and then modified the movie query and result when it was called query. We'd have two SQL queries called and two results called $result. When the first result ran it would produce the expected results, as the second one. However, if we ever wanted to refer to the results set that was returned from the first SQL, we'd have a big problem.

Why? The first results would have been overwritten by the results of the second SQL query. For this reason, always ensure that you use different names for additional SQL queries and results sets returned from the query.

### How It Works

The generate_ratings function is fairly straightforward. You send it the value that is in the ratings field for a movie and it creates a "rating" image for the movie and returns it. Notice that we are using <<= (which is similar to .=). This ensures that movies with a rating of more than 1 will get additional images added to the single rating image.

The review_table_headings variable contains the table headings for the reviews that we have just pulled out via the previous SQL query. This uses exactly the same concept as the movie table headings in the previous example. Now so we have all the review headings in a list, neat and ready.

While the script is collecting rows of reviews, if there are any reviews for the movie, you set a flag using the $review_flag variable. The code creates arrays to hold the variables that will be returned. Why are we putting them into arrays and not just ordinary variables? This is because we are dealing with multiple rows and we need to store each piece of data separately before we output them.
