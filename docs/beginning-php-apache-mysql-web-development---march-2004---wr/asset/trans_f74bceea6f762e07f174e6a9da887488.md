## char_transact.php

最后，进入字符应用的核心：char_transact.php。这个页面看起来发生了很多操作，但并不复杂。仅仅是根据数据到达这里的方式，此页面执行了许多任务。让我们打开看看它是如何运行的。

在许多 PHP 服务器上，`php.ini` 选项 `register_globals` 被开启。这会将所有 `$_REQUEST` 变量（POST, GET 和 COOKIE）注册为全局变量。换句话说，如果你使用 post 方法提交一个名为 `username` 的字段，那么此页面可以通过 `$_POST['username']` 中的 `$username` 来访问它。我们不会深入讨论设置 `register_globals = ON` 可能会带来的安全问题。但是，如果你有它的控制权，我们将其设置为 OFF。事实上，在 PHP 4.2.0 版本中它默认设置为 OFF。（如果你想了解更多相关信息，请访问 www.php.net/register_globals）。

你应该始终假设 `register_globals` 是关闭的，以便你的应用程序具有可移植性，由于这个原因，我们假设通过 `$_POST` 数组访问提交的变量。我们正在的是遍历 `$_POST` 并将每个变量作为用户名 设置为 `$_POST['username']`，这样现在无论 `register_globals` 如何设置，都可以作为 `$username` 访问。

```php
foreach($_POST as $key => $value) {
  $key = $value;
}
```

`switch` 是提供多重选择的一种方便方式。比复杂的 `if...else` 语句更容易读。你需要注意的是在每个 case 的末尾使用 `break;` 以防止后续 case 块执行。

接下来的 INSERT 查询相对简单。用白话来说：“将 $zip, $city 和 $state 插入到 char_zipcode 的 id, city 和 state 列中。”`IGNORE` 关键字是一个很酷的选项，允许你在无需通过 SELECT 查看数据是否存在的情况下进行插入。在这种情况下，你知道可能已经存在该 zip code 的记录。所以，IGNORE 告诉你如果你在数据库中使用该 zip code，不要插入。”

```php
case Create Character:
  $sql = "INSERT IGNORE INTO char_zipcode (id, city, state)
  VALUES ('$zip', '$city', '$state');";
  $result = mysql_query($sql) or die(mysql_error());
```

注意 IG 语句只比较主键。然而，如果数据库中有任何相同的 zip code，INSERT 仍然会发生。主键自动递增没有影响；在这种情况下 INSERT 总是发生的。

在接下来的 INSERT 中，你对第一个值使用了 NULL。当你向列插入 NULL 时，MySQL 处理以下情况：如果该列允许 NULL 值，它会将 NULL 设置为默认值。如果没有确定默认值，则插入数据类型的标准默认值（var/char 为空，整数为 0，依此类推）。如果是这里的情况，该列被设置为自动递增，然后插入该列的下一个可用整数。在我们的案例中，它是主键，这就是我们希望发生的。

```php
$sql = "INSERT INTO char_lair (id, zip_id, lair_addr)
VALUES (NULL, '$zip', '$address');";
$result = mysql_query($sql) or die(mysql_error());
```
