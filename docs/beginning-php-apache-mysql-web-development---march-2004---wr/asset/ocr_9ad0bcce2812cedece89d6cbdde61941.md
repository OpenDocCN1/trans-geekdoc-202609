# # How It Works

Inserting data is always easier when you have an actual method to insert (remember these wise words).
We generally use HTML forms.

HTML forms allow us to drive the way the user enters the data. Once submitted, the form sends the
server information that PHP can use to generate and run the SQL INSERT statement.

As you see in the movie insertion form in movie.php, we have four combo boxes and a text field.
The text field content is left to your discretion, but the combos are quite directive. Let's review the content of
the combos generated from the database contents.
