# Chapter 10

If you are in a *NIX (Unix, Linux, and so) environment, you will most likely have sendmail installed on your server. If you are using a hosting service, check with your service provider to make sure send-mail or some equivalent is being used.

If you are not using sendmail, or you have Apache installed on a Windows server, you have a couple of choices. You can use your SMTP (Simple Mail Transport Protocol) server, or install a mail server as Mailtrap on your computer. If you have questions or concerns about setting up or using a mail server, there are many resources available to help you. We suggest using a search engine.

Once you have your mail server squared away, you'll need to modify your php.ini. There are a couple of parameters you need to set. Of course, if you are using a hosting service, they should already have these parameters set.

+   - SMTP: Set this to the IP address or name of your SMTP server. For example, if you have a mail server installed on the same server as your PHP server, you should be able to set SMTP to localhost. This applies to Windows installations only.
- smt_port: Set this to the port PHP uses to connect to the SMTP server. This applies to Windows installations only, and is valid for PHP 4.3 and above.
- sendmail_from: The From address used by the PHP mail().
- sendmail_path: The path to the sendmail program (*NIX servers only). For most servers, this is /usr/bin/sendmail.

That's all there is setting up PHP for e-mail. We will test to make sure it works correctly in the next section, "Sending an E-mail."

More information about setting up PHP for mail can be found at http://us3.php.net/manual/en/ref.mail.php.

# Sending an E-mail

The actual method of sending an e-mail is quite simple. Of course, it can be made much more complex with the addition of headers, sending HTML and images. However, we are going to start with something simple.

> Try It Out Sending a Simple E-mail

This example is just the simplest code you can write to send an e-mail. Of course, it's not flexible, but it demonstrates the mail() function well.

+   1. Start your favorite text/PHP/HTML editor. Notepad works just fine.
2. Enter the following code. Make sure you put your e-mail address in as the first parameter:

```
<?php
mail("your@e-mailaddress.com","Hello World","Hi, world. Prepare for our arrival.\nWe're starving!");
?>
```
