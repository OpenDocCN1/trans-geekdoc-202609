Again, to retrieve or set session variables, you must first use the command session_start(). Once you do, you set three variables to be used throughout the application: user ID, access level, and name:

```
session_start();
$_SESSION['user_id'] = $row['user_id'];
$_SESSION['access_lvl'] = $row['access_lvl'];
$_SESSION['name'] = $row['name'];
}
```

Next, redirect the user back to the home page (index.php). The break function is required at the end of each case statement. Otherwise, the code in the next case runs as, and you don't want that because it logs the user out!

```
redirect('index.php');
break;
```

Logout is quite simple. If no session variables exist with the user ID, access level, and user name, then the application knows you are not logged in. Therefore, you use session_start() to tell PHP you are accessing session variables. Then, unset the session, which clears all the session variables, and finally you destroy the session, which destroys all of the data registered to a session. session_unset() and session_destroy() are used to completely remove all data.

```
case 'Logout':
    session_start();
    session_unset();
    session_destroy();
```

break;
