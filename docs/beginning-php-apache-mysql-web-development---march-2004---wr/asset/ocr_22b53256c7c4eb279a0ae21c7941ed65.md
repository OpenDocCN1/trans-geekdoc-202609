
The dealing with the add button. Notice that it is called 'action' and that has a value of Add Power. When submitting, PHP passes these values to the next page. Because we are using the post method on our, we will use a S_POST variable called 'action' that contains the value of the button. Because of this, and because of all our forms load char_transact.php, all of our buttons are named 'action', and have different values so that we can determine what to do with the data that is sent.
