As you can see here, the first index holds the whole string, and each chunk holds a cut-off part of the string, delimited by the parentheses.

Now that we have our data in an understandable format, we can change it into a timestamp using the mktime() function, which allows you to create a timestamp from chunks of dates. It is also a very useful function to manipulate dates.

```
$movie_release = mktime (0, 0, 0, $relatepart['2'], $relatepart['1']
$relatepart['3']);
```

This code stores a timestamp from the day, month, and year information fed to the system in the $movie_release variable. The format is mktime (int hour, int minute, int second, int month, int day, int year). The returned value is the number of seconds since January 1, 1970, and the specified date.

See documentation at www.php.net/mktime for additional information regarding optional parameters such as daylight saving.

If mktime fails to create a timestamp from the date you passed to, it will return -1. This happens when the input is invalid, although it matches the regular expression (example 99-99-9999 will pass the regular expression test, but is obviously not a valid date). To be sure that the date is valid, we will test the value for mktime and return accordingly.

```
if ( $movie_release == '-1') {

```
