# Chapter 2

+   1. Go back to your date.php file and instead of displaying only the number of days in the current month, add a few lines that say:

The month is ________.
There are _________ days in this month.
There are _________ months left in the current year.

A: Your date.php file should look something like this:

```
<html>
<head>
<title>How many days in this month?</title>
</head>
<body>
<?php

$month = date("F");
echo "The month is: ";
echo $month;
echo "<br>";

echo "There are ";
$month=date("31");
if ($month=1) echo "31";
if ($month=2) echo "28 (unless it's a leap year)";  
```
