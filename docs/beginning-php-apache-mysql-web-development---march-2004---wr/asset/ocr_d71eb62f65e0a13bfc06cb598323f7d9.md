# Online Selling: A Quick Way to E-Commerce

The next table you create is called ordemain and contains the main order information.

| Fieldname | Type | Description of What It Stores |
| --- | --- | --- |
| ordernum | INT (6) | The individual number assigned to each order. This will auto-increment and is the primary key. |
| orderdate | DATE | Date the order was placed. |
| custname | INT (6) | Number of the customer who placed the order. |
| subtotal | DEC (7,2) | Subtotal of the order before tax and shipping, up to 9999.99. |
| shipping | DEC (6,2) | Shipping costs for the order, up to 999.99. |
| tax | DEC (6,2) | Tax on the order, up to 999.99. |
| total | DEC (7,2) | Total of the order, up to 9999.99. |
| shipfirst | VARCHAR (15) | First name of the shipping contact for this order. |
| shiplast | VARCHAR (50) | Last name of the shipping contact. |
| shipaddl | VARCHAR (50) | Shipping contact's address: line 1. |
| shipadd2 | VARCHAR (50) | Shipping contact's address: line 2 (can be null). |
| shipcity | VARCHAR (50) | Shipping contact's city. |
| shipstate | CHAR (2) | Shipping contact's state. |
| shipzip | CHAR (5) | Shipping contact's zip code. |
| shipphone | CHAR (12) | Shipping contact's phone number (in xxx-xxx-xxxx format). |
| shipmail | VARCHAR (50) | Shipping contact's e-mail address. |

The fourth and final name is called orderdet and contains a detailed list of the products in each order.

| Fieldname | Type | Description of What It Stores |
| --- | --- | --- |
| ordernum | INT (6) | The order number (note this is designated a “key” and not “primary key”). |
| qty | INT (3) | How many of the item the customer wants. |
| productname | CHAR (5) | The product associated with this order. |

We now have a mechanism set up so that we can store all our products, all our customers, and all the information associated with the orders they place.
