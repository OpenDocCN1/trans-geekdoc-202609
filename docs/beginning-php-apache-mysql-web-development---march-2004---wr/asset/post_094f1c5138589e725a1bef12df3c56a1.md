## What Do You Want to Send Today?

The first question is what you will send. You may already have some ideas. Maybe not. Suffice to say there are many different reasons to send out bulk messages. Here are a few:

- Web site notifications: These are important tidbits of information about your Web site. You will want to let your users know you've improved the level of security for online transactions on your site, for example.
- Newspapers: If you have a family Web site, for example, and wanted to tell your whole family know about the new addition to your family, you could send them a newsletter.
- Important announcements: "Our site will be down for 5 days. We'll let you know when it is back up." (Oooh ... an opportunity for two mail!)
- Advertising: Perhaps you've partnered with an online comic book store to offer deals on comics to your members, for example.

We are going out send two different e-mails: Web site change notifications and a newsletter. The first will be sent to all members of the Web. The latter will be sent to those who subscribe to the newsletter only.

We are going to use HTML in our e-mail, of course. Because Chapter 10 taught you how to send HTML in an e-mail, this should pose no problem at all. You can also e-mail links to an online version of the HTML you are sending, so that those with text-email clients can see your hard work, as well.

## Try It Out Mailing List Administration

First, you're going to create the file that will hold the server, username, password, and database values:

- 1. Open your favorite text editor, and edit the following code, making sure you use the proper values for your server:

```php
<?php
define('SQL_HOST','yourhost');
define('SQL_USER','joouser');
define('SQL_PASS','yourpass');
define('SQL_DB','yourdatabase');
define('ADMIN_E_MAIL','your@e-mailaddress.com');

?>
```

- 2. Save the file as config.php.

- 3. Now you're going to create the tables. You can create them with your MySQL tool (such as PHPMyAdmin), or you can simply enter the following code, save it as sql.php on your server, and load it in your browser:

```php
<?php
require('config.php');

$conn = mysql_connect(SQL_HOST, SQL_USER, SQL_PASS)
or die('Could not connect to MySQL database. ' . mysql_error());

$sql = "CREATE DATABASE IF NOT EXISTS " . SQL_DB . " ";

$res = mysql_query($sql) or die(mysql_error());

mysql_select_db($SQL_DB, $conn);

$sql1 = <<EOS
CREATE TABLE IF NOT EXISTS ml_lists (
ml_id int(11) NOT NULL auto_increment,
lastname varchar(255) NOT NULL default '',
PRIMARY KEY (ml_id)
) TYPE=MyISAM;
EOS

$sql2 = <<EOS
CREATE TABLE IF NOT EXISTS ml_subscriptions (
ml_id int(11) NOT NULL default '0',
user_id int(11) NOT NULL default '0',
pending tinyint(1) NOT NULL default '1',
PRIMARY KEY (ml_id,user_id)
) TYPE=MyISAM;
EOS

$sql3 = <<EOS
CREATE TABLE IF NOT EXISTS ml_users (
user_id int(11) NOT NULL auto_increment,
firstname varchar(255) default '',
lastname varchar(255) default '',
e-mail varchar(255) NOT NULL default '',
PRIMARY KEY (user_id)
) TYPE=MyISAM;
EOS

$res = mysql_query($sql1) or die(mysql_error());
$res = mysql_query($sql2) or die(mysql_error());
$res = mysql_query($sql3) or die(mysql_error());
echo "Done.";
?>
```

- 6. Okay, one more script. When the administrator clicks a button, you need to have a page that handles the transactions. Enter the following, and save it as admin_transact.php:

```php
<?php
require('config.php');

if (isset($_POST['action'])) {
    switch ($_POST['action']) {
        case 'Add New Mailing List':
            if (isset($_POST['name'])) {
                $sql = "INSERT INTO ml_lists (lastname) VALUES ('" . mysql_escape_string($_POST['name']) . "')";
                mysql_query($sql) or die('Could not add mailing list: ' . mysql_error());
            }
            break;
        case 'Delete Mailing List':
            if (isset($_POST['ml_id'])) {
                $sql = "DELETE FROM ml_lists WHERE ml_id=" . (int)$_POST['ml_id'];
                mysql_query($sql) or die('Could not delete mailing list: ' . mysql_error());
            }
            break;
        case 'Send Message':
            if (isset($_POST['ml_id']) && isset($_POST['msg'])) {
                $sql = "SELECT listname FROM ml_lists WHERE ml_id=" . (int)$_POST['ml_id'];
                $result = mysql_query($sql) or die('Could not get listname: ' . mysql_error());
                $row = mysql_fetch_row($result);
                $listname = $row['listname'];

                $sql = "SELECT DISTINCT usr.email, usr.firstname, usr.user_id
                        FROM ml_users usr
                        INNER JOIN ml_subscriptions mls ON usr.user_id = mls.user_id
                        WHERE mls.pending=0";
                if ($_POST['ml_id'] != 'all') {
                    $sql .= " AND mls.ml_id=" . (int)$_POST['ml_id'];
                }
                $result = mysql_query($sql) or die("Could not get e-mail addresses. " . mysql_error());

                $headers = "From: " . ADMIN_E_MAIL . "\r\n";
                while ($row = mysql_fetch_array($result)) {
                    if (is_numeric($_POST['ml_id'])) {
                        $ft = " You are receiving this message as a member of the ";
                        $ft .= $listname . " in mailing list. If you have received:\n";
                        $ft .= " this-mail in error, or would like to remove your\n";
                        $ft .= $row['firstname'] . " from our mailing list, please visit the:\n";
                        $ft .= " http://" . $_SERVER['HTTP_HOST'] .
                               dirname($_SERVER['PHP_SELF']) . "/remove.php?u=" .
                               $row['user_id'] . "&ml_id=" . $_POST['ml_id'] . ";";
                    } else {
                        $ft = " You are receiving this e-mail because you subscribed\n";
                        $ft .= "to one or more mailing lists. Visit the following:\n";
                        $ft .= " URL to change your subscriptions:\n";
                        $ft .= " http://" . $_SERVER['HTTP_HOST'] .
                               dirname($_SERVER['PHP_SELF']) . "/user.php?u=" .
                               $row['user_id'] . ";";
                    }

                    $msg = stripsslashes($_POST['msg']) . "\n\n";
                    $msg .= $ft . "\n\n";

                    mail($row['email'],
                          stripsslashes($_POST['subject']),
                          $msg, $headers) or die("Could not send e-mail.");
                }
                break;
            }
    }
}

header('Location: admin.php');
?>
```
