Now we will explain what we just did. The output that you see in the browser will be the same as we saw before, but behind the scenes, we used the mail() function to send an e-mail to the administrator. We also used other PHP functions, such as getdate(), to note the day and the error that occurred. We threw in some function practice for you to get the hang of sending variables parameters to and from functions. Now the administrator or Webmaster will be getting an HTML-formatted e-mail concerning the error message that they received when he or she happened to go to that page.

That’s it: You just used Apache’s Document Directive to maintain your server.
