You will notice the <span> and &lt;div&gt; tags, as well. These are not currently being used, but they will allow you to use CSS (cascading style sheets) to change how your pages are displayed. You may include a CSS file or on the Web site to demonstrate this, but for now, describing CSS is beyond the scope of this book.

```
echo "<span class=\commentName\">\n"
    htmlspecialchars($row['name']) .
    "</span class=\commentDate\"> .
    date("1 F J Y H:i:s",strtotime($row['comment_date'])) .
    "</span>\n";
echo "<p class=\commentText\">\n"
    nl2br(htmlspecialchars($row['comment']));
    "</p>\n";

}
```

Again, notice the use of htmlspecialchars() and nl2br in the previous code. If you wanted to use them, they are very important for converting text in a text box into readable text on an HTML page.

The function gives you powerful ability to take the standard date value in a datetime field in MySQL and format it in many ways. In this case, the datetime of 2003-09-19 17:39:22 will be displayed as Friday September 19, 2003 17:39. There are many options for displaying dates. For more information about this, visit www.php.net/date.

The Functions.php file is included on each page that needs one of its functions. If you have other functions that you might want to add to your application, simply add it to this page, and make sure file is included in the page.

Two additional files are included on every page that provides information on the Web: header.php and footer.php. (We won't look at header.php or footer.php, which should be self-evident.)

This is the very line of our page, and a very important one. Login information is stored using sessions. Sessions allow you to store values to be used elsewhere on the site. This makes using session_start() at the beginning of your page, you are telling the application to allow access to $_SESSION variables. You can set and retrieve session variables.

For a more detailed discussion of sessions, visit www.php.net/session.

Here's our first example of session variables. Once session_start() has been initialized, the $_SESSION['name'] should be available, as long as the user has logged in. So, if isset($_SESSION['name']) you know the user is not logged in.

```
if (isset($_SESSION['name'])) {
    echo "<div id=\lowegomecontent\">\n"
    echo "Currently logged in: ' . \$_SESSION['name'];\n"
    echo "</div>";
}
```
