## Try It Out Sorting Arrays

Before we go further, let's do a quick test on sorting arrays so you can see how the array acts when it is sorted. Type the following program in your text editor and call it sorting.php.


## foreach Constructs

There exists a foreach command that will apply a set of statements for each value in an array. An appropriate name, eh? It works on arrays, however, and will give you a big error if you try to use it with another type of variable.

Your syntax for the foreach command looks like this:

```php
<?php
$flavor[] = "blue raspberry";
$flavor[] = "root bear";
$flavor[] = "pineapple";
echo "My favorite flavors are:<br>";
foreach($flavor as $currentvalue) {
  //these lines will execute as long as there is a value in $currentvalue
  echo $currentvalue . "<br>\n";
}
?>
```

## While You’re Here . . .

If you’ve had any background in programming, you’ve undoubtedly had some experience with a while-do function. Just in case you’ve never heard of this (and maybe have been living on Mars or something), let’s give a brief synopsis of this concept. A while simply tells the server to execute a command or block of commands repeatedly, as long as the given condition equals “true.”

while checks for the condition at the beginning of the block of code, do/while checks for the condition at the end of the block, guaranteeing that the block executes at least once.

The following is an example of the while and do/while commands:

```php
$num = 1;
while ($num <= 5) {
  echo $num;
  echo "<br>";
}
```

Both of the preceding code snippets print the numbers 1 through 5, each on a separate line.
