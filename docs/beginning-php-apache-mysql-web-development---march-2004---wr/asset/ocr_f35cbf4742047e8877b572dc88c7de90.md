You should see the same results before, except that there is now no difference between the elements. Pretty sneaky, huh? Because mysql_fetch_array returns two sets of arrays (with associative indices, with number indices), you see duplicate values if you use this function without clarifying. You can either use mysql_fetch_array(MYSQL_ASSOC) or mysql_fetch_assoc to perform the same thing and return only one array at a time. We still need to use the while function to proceed through the selected rows one at a time, but you can see that foreach applies the same set of commands to each value in the array regardless of context.

Sometimes you will need to have more control over a specific value, and can't apply the same formatting rules to each value in the array, but the foreach function can also be handy when using formatting functions as creating tables.
