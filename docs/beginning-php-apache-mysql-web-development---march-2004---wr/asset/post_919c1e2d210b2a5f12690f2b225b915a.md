## How It Works

Hey, guess what? You're right: How to "hold" the connection again. Then we create a temporary table that will "hold" the items while the customer continues browsing and before they check out. We didn't want to publish the other tables with this information yet because our customers may decide not to go with the order and we would have order numbers for orders that never sent. This can really mess your accounting and tracking systems.

To keep each separate, we create a hidden field that will simply act as a primary key and allow to later delete only one row from our shopping cart. The sess field is used to temporarily store our session ID (which is assigned by the browser) to allow us to link the information from this particular shopping session, and keep it all together.
