# How It Works

The Mail() function automatically sends an e-mail, using the following format:

```
Mail(to, subject, message, other_parameters)
```

The headers and other_parameters are optional. If you want to send a message to multiple recipients, their addresses must be separated with a comma in the to parameter:

```
Mail(first@mail.com, second@mail.com, "Hi", "Whazzup??")
```

We will cover the headers parameter soon. The other_parameters are beyond the scope of this book, but if you want more information about the mail() function, point your browser to www.php.net/manual/en/function.mail.php.

# How It Works

We are going to assume that you know HTML well that we don't have to explain postcard.php in great detail. Just remember that if your sendmail.php is not in the same folder as postcard.php, you have to provide the correct path:

```html
<form name="theform" method="post" action="yourdir/sendmail.php">
```

Once the user presses the Send button, sendmail.php is loaded. The first step in your PHP code assigns all the fields from postcard.php. This step is not necessary if register_globals is set to On in php.ini, but I strongly recommend you use this code, in case register_globals is turned Off:

```php
$to = $_POST['to'];
$from = $_POST['from'];
$subject = $_POST['subject'];
$message = $_POST['message'];
```

In order to specify from whom the e-mail is coming, use the optional parameter for the mail() function, headers. We explain headers in more detail in the section “Sending HTML,” later in this chapter.

```php
$headers = $from . "\r\n";
```

The mail() returns a value of True if it is successful and False if it fails. You will use this function to make your application user-friendly:

```php
$mailsent = mail($to, $subject, $message, $headers);
if ($mailsent) {
    echo "Congrats! The following message has been sent:<br>";
    echo "<b>To:</b>" . $to . "<br>";
    echo "<b>From:</b>" . $from . "<br>";
    echo "<b>Message:</b>" . $message . "<br>";
    echo $message;
} else {
    echo "There was an error...";
}
```

Of course, you can modify this to handle errors more elegantly. Use the knowledge you acquired in Chapter 8 to do so.

# How It Works

Perhaps saying this would be “How It Doesn’t Work.” Because your e mail client does not know that it has received HTML. Why? Because you didn’t tell it! In order for any HTML-capable client to display HTML, the client needs to be told that the incoming e-mail is going to have some HTML tags on it. Only then will it know how to properly display your message.

# Try It Out Sending HTML by Headers

You need a way for e-mail to tell the client it contains HTML. This is accomplished by using headers. You already saw how we include a “From:” parameter. Now you are going to use a similar header to tell the client that the pc_email message contains HTML.

- 1. Edit your copy of pc_sendmail.php in your favorite text editor. Back up pc_sendmail.php before making changes if you want to keep the old version.

- 2. Make the following modifications to this file. Modifications are shown in bold:

```html
<html>
<head>
<title>HTML Sent!</title>
</head>
<body>
<?php
$to = $_POST["to"];
$from = $_POST["from"];
$subject = $_POST["subject"];
$message = $_POST["message"];
$headers = "MIME-Version: 1.0\r\n";
```

```php
$headers = "Content-type: text/html; charset=iso-8859-1\r\n";
$headers .= "Content-Transfer-Encoding: 7bit\r\n";
$headers .= "From: " . $from . "\r\n";
$mail = mail($to, $subject, $message, $headers);
if ($mail) {
    echo "Congrats! The following message has been sent:<br>";
    echo "<To:$to<br>";
    echo "<From:$from<br>";
    echo "<Message:$message<br>";
    echo $message;
} else {
    echo 'There was an error...';
}
?>
</body>
</html>
```

- 3. Save the file.
