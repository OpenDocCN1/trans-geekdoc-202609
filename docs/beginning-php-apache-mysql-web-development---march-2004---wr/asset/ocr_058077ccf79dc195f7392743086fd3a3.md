# How It Works

Perhaps saying this would be “How It Doesn’t Work.” Because your e-mail client does not know that it has received HTML. Why? Because you didn’t tell it! In order for any HTML-capable client to display HTML, the client needs to be told that the incoming e-mail is going to have some HTML tags on it. Only then will it know how to properly display your message.

# Try It Out Sending HTML by Using Headers

You need a way for e-mail to tell the client it contains HTML. This is accomplished by using headers. You already saw how we headers to include a “From:” parameter. Now you are going to use a similar header to tell the client that the pc_email message contains HTML.
