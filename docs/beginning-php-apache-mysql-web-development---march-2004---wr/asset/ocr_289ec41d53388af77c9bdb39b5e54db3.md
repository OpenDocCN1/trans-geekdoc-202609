# Using Log Files to Improve Your Site

%u(george): The username of the client. This is set if the page is using HTTP User Authentication. Otherwise, you see a hyphen (-).

%t (29/Aug/2003:13:55:36 -0500): The date/time client accessed your server.

+   - The format for this is as follows: [day/month/year:hour:minute:second]
- day = 2 digits
- month = 3 letters
- year = 4 digits
- hour = 2 digits
- minute = 2 digits
- second = 2 digits
- zone = ('+' | '-') 4 digits

"GET /index.php?xyz=123 HTTP/1.0": The request line from the client. This is wrapped in quotes, which have to be escaped. This is actually multiple information, which could be built using other parameters:

+   - %m (request method), in this case, GET
- %U (URL), in this case, /index.php
- %q (query string), in this case, ?xyz=123
- %H (protocol), in this case, HTTP/1.0
- "%m %U %H" is the functional equivalent of "%r\r"

%s (=200): The status code can tell the client. In this case, because it knew as a successful request.

%b (2326): The size of the object returned to the client in bytes (not headers). If no content is returned, the value is hyphen (-), or "0" if %B is used.

"%Referer" ("http://www.yourserver.com/cms/index.php"): The address of the client came from. This is useful for compiling information about where your users heard about your web site.

"%User-agent" ("Mozilla/4.08 (Windows;;1,Nav)\): User-Agent HTTP request information. This is the client's browser sends about itself. This is very useful for determining how many people are using browsers, such as Internet Explorer.

If the preceding information looks like Greek to you, don't worry. There are ways to get the information without understanding any programming, and methods of reading the information to build statistics, charts, graphs, and other things that are much easier to read. We share those methods with you shortly.
