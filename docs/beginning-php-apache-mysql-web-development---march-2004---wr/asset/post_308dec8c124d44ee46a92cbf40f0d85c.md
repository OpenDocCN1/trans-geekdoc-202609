## Your First Form

As a wise once said, every journey starts with a single step. To start this particular journey, we will focus on a very simple form. It will include only a text field and a submit button in a table layout. The processing script will display only the value entered in the text field.

## Try It Out Say My Name

In this exercise, you are going to get PHP to respond to a name entered in a form. This is a simple variation of the "hello world," allowing you to take your first step into interactivity.

- 1. Create a text file form1.html and open it in your favorite text editor.
- 2. Enter the following code:

```

Name
</td>
<td bgcolor="#ffffff" width="50%">
<INPUT type="TEXT" name="Name"><br />
</td>

</td>
</tr>

</form>
```

## How It Works

As with any recipe, it's a good idea to start working on forms by understanding the ingredients. To familiarize yourself with forms, you'll need some background information about HTML form elements and a few new PHP functions.

Let's start with the HTML form.

> HTML references can be found at the World Wide Web Consortium site at www.w3.org/Markup.

## FORM Element

First, we will introduce the first HTML element you'll need: FORM. It delimits the form area in the page and the fields that you hold your Web site users to fill in.

```
<form action="formprocess1.php" method="post">
<!-- controls here-->
</form>
```

## Form Elements: Letting the User Work with Data

Notice that the FORM element has an ending tag and attributes.

- The first attribute (action) is the recipient page address (the form processing script).
- The second attribute (method) is the way in which you will send the data to the recipient. There are two separate ways of sending a form to its processing script: the POST and the GET methods.
- The POST method (see Figure 5-3) takes the data from the form fields and sends it through an HTTP header. In this case, the data cannot be seen in the URL.

![](img/7b817c5b51395b5dcaba58e6a2bc6daa_161_0.png)

The GET method gets the data from the form fields, encodes it, and adds it to the destination URL, as shown here:

As you can see, the field names and their values are easy to read inside the script.

```
http://localhost/formprocess1.php?field1=value&field2=value%20b
```

## INPUT Element

The new HTML element included here is INPUT. This is the basis of most forms and can be used in many ways to gather many different types of information.

In this case we use two different types of INPUT: the text and submit types.

Here is the INPUT text type:

```
<INPUT type='TEXT' name="Name">
```

The INPUT text type is a standard, single-line text box. As all form controls, it needs a name so that the processing script can access its content using the following syntax:

```
<?php
echo $_POST['Name']; // will display the value typed in
?>
```

And here's the INPUT type:

```
<INPUT type="SUBMIT" name="SUBMIT" value="Submit">
```

As its name clearly hints, the submit element displays a button that, when pressed, submits the form. The button text is set through the value attribute. As mentioned for the text INPUT, this form control needs a name for a processing reference.

## Processing the Form

In this script, you may have noticed a few new functions and syntaxes, and you are probably curious about them.

The first form processing script is an interactive variation of the famous "hello world," but in this case displays "hello" and the name you type in the text box.

To make this happen, you need to print the value of the text you filled in on the form. You know the echo command, so let's move on to the other piece, $_POST['Name'].

The $_POST global array contains all data submitted with the POST method. The array index of the field is its name. See the next item for hints on checking the content of your $_POST array using the print_r() function.

```
<?php
echo "Hello " . $_POST['Name'];
?>
```

In this example, $_POST['name'] displays what you entered in the "Name" box.

Hello test

(A debugging tip: print_r($_) dumps the global arrays.)

You might wonder what print_r($_) does. It simply dumps the whole contents of the super global $_POST array to the output. This is a great way to debug your forms, as you will see.

The $_POST array, as with all arrays, has case-sensitive indexes. Use this tip to check for and display the state of your objects when building a script.

## Driving the User Input

The form in this example allows you to lead the user to choose values from a set of values. Defining a value set is done through the use of specific HTML elements, such as list boxes, radio buttons, and checkboxes.

Two kinds of predefined user input are in HTML forms. The first kind allows you to choose one item from the available options; the second allows you to choose multiple items. Drop-down list boxes and radio buttons for one selection only. Checkboxes and multiline list boxes provide for multiple choices.
