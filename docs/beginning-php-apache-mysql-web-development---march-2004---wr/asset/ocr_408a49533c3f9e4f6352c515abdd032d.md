The rest of the function is fairly straightforward. It combines the data retrieved from the database with HTML to format it for the story. There are a few things we want to point out, however:

First, we will notice that we use the trimBody() function we just created, but only if we in the second parameter of the outputStory() function. Second, we use the htmlspecialchars() PHP function to convert any text in our article that might cause HTML problems (like <, >, &, and, so on) to their entity equivalents (&lt; &gt; &amp; respectively, and so on). Third, newline characters in HTML are essentially ignored. In order for HTML to properly display text with newlines, you need to insert <br /> for every neat line in the text. The PHP provides a function to do this: nl2br(), which we use:

```
if ($only_snippet) {
    echo nl2br(htmlspecialchars(trimBody($row['body'])));

} else {
    echo nl2br(htmlspecialchars($row['body']));
}
```
