## How It Works

By now, you should be familiar with using PHP to access MySQL. The application is still basic. Here is the SQL statement you would use:

```sql
CREATE TABLE confirm (
    id INT PRIMARY KEY AUTO_INCREMENT,
    validator VARCHAR(32) NOT NULL,
    to_e_mail VARCHAR(100) NOT NULL,
    toname VARCHAR(50) NOT NULL,
    from_e_mail VARCHAR(100) NOT NULL,
    fromname VARCHAR(50) NOT NULL,
    bcc_e_mail VARCHAR(100),
    cc_e_mail VARCHAR(100),
    subject VARCHAR(255),
    postcard TEXT,
    message TEXT
);
```
