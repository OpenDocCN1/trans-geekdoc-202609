# An Introduction to PEAR

If you load this in your browser, you will see the following on the screen:

Average Man (Bill Smith) is a member of the Dynamic Dudes League.
Thea (Tom Jacobi) is a member of the Dynamic Dudes League.
Albino Duke (George White) is a member of the Amazing People League.
Amazing Woman (Mary Jones) is a member of the Stupendous Seven League.

The PEAR method takes more lines, and the syntax is a little different (which can be especially difficult if you are not familiar with objects). So why would you use PEAR?

Remember that PEAR DB acts as an abstraction layer to help interface with your database. If you look closely at the PEAR code, you'll notice that none of the functions refer to the type of database you are using. In fact, they are quite generic. In contrast, the first code snippet uses mysql throughout the code. That's not a problem, as long as you always use MySQL.

Remember your IT manager's passing comment? Your company has decided to switch from MySQL to Oracle. Which one of these small code segments would you prefer to modify? Okay, perhaps the MySQL code would only take a couple of minutes, but try to imagine this on a scale. Also remember that Oracle commands differ—you must pass the SQL statement to the server and commit it. MySQL doesn't work that way.

Now you see the benefits of using PEAR's abstraction layer. By keeping the $db_type variable (or an SQL_DB_TYPE constant) in an included file, you will have to make your entire work with the new database change the $db_type variable from mysql to oci—oretically, of course. This assumes that every SQL statement is compatible with both MySQL and Oracle (which is doubtful) and every PEAR DB function you used for MySQL is compatible with Oracle (which also doubtful). But at least you will have a lot of less to do.

There are definite benefits to using PEAR. For example PEAR DB:

+   - Enables you to easily change your code to work with any database backend supported by PEAR.

+   - Provides built-in error checking and error handling.
