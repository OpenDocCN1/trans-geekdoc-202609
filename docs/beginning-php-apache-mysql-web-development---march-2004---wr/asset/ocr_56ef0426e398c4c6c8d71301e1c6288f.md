# char_transact.php

And so finally, to the wellknown of the character database application: char_transact.php. It looks like a lot happening on this page, but it's not complicated. There are simply many tasks that are performed by this page, depending on how the data got here. Let's open up and see what makes her tick.

On many PHP servers, the php.ini option register_globals is set to ON. That registers all $_REQUEST variables (POST, GET, and COOKIE) as global variables. In other words, if you post a field called username using the post method, then this page could access it as $username in $_POST['username']. We're not going to go into security problems you might have by setting register_globals = ON. However, we do set it to OFF if you have control over that. In fact, it is set to OFF by default in PHP versions 4.2.0. (If you would like more information about this, visit www.php.net/register_globals).
