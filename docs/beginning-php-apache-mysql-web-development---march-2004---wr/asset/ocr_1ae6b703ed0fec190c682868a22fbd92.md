# Appendix C

| Function | Description |
| --- | --- |
| is_float(var) | Verifies whether or not the variable is the float. |
| is_int(var) | Equal to is_integer and is_long, verifies whether or not the variable is an integer. |
| is_integer(var) | Equal to is_int and is_long, verifies whether or not the variable is an integer. |
| is_long(var) | Equal to is_int and is_integer, verifies whether or not the variable is an integer. |
| is_null(var) | Verifies whether or not the variable is null. |
| is_numeric(var) | Verifies whether or not the variable is a number or numeric string. |
| is_object(var) | Verifies whether or not the variable is an object. |
| is_real(var) | Verifies whether or not the variable is a real number. |
| is_resource(var) | Verifies whether or not the variable is a resource. |
| is_string(var) | Verifies whether or not the variable is a string. |
| isset(var) | Verifies whether or not the variable has been assigned a value. |
| print_r(exp[, return) | Displays readable information about a variable. |
| serialize(value) | Generates a storable version of variable. |
| settype(var, type) | Sets the named variable to the named type. |
| strval(var) | Returns the string value of the named variable. |
| unserialize(string) | Generates a PHP value from a stored version. |
| unset(var) | Deletes the named variable. |
| var_dump(exp) | Displays information about the named expression. |
| var_export(exp) | Outputs a string representation of the variable. |
