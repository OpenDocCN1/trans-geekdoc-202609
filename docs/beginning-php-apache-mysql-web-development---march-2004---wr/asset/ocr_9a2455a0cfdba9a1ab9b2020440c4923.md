```
function bbcode($data) {
  $sql = 'SELECT * FROM forum_table\';
  $result = mysql_query($sql);
  if (mysql_num_rows($result) > 0) {
    while($row = mysql_fetch_array($result)) {
      $bbcode['tpl'][] = '*' . html_entity_decode($row['template'], ENT_QUOTES) . ' *';
      $bbcode['rep'][] = html_entity_decode($row['replacement'], ENT_QUOTES);
    }

  $data = preg_replace($bbcode['tpl'], $bbcode['rep'], $data);
  $count = 1;
  while ($data != $data && ($count < 4)) {
    $data = $data;
    $count++;
  }
  $data = preg_replace($bbcode['tpl'], $bbcode['rep'], $data);

  return $data;
}
```

Because regex uses many characters in the pattern, before storing the data in our table MySQL can safely store. For that reason, when retrieving the data, we must perform html_entity_decode(). Note the use of the $ character as a delimiter because it is not used in regex patterns, a perfect delimiter. To use the character, make sure your num is enabled, hold down Alt key, and type 067. Alternatively, you could use a different non-alphanumeric character as your delimiter.

Also note the use of the / modifier after the right-hand modifier. This specifies that we do not care about upper or lower case. If you want to use case matching, free to remove from this modifier.

As you can see from the code, $row['template'] contains the regex pattern. The array variable $row['replacement'] contains the replacement pattern. Now, let's look at some of the pattern/replacement pairs you entered earlier:

| Pattern | Replacement | Explanation |
| very hard | cats and dogs | This is a very simple replacement, using a literal pattern. It replaces the "very hard" with "cats and dogs" in any post or signature. You saw evidence of this in one of your posts. |
| \/url\| | <a> | Replaces any instance of [url] in the body with <a> tags. Note that the opening and closing square brackets must be delimited if you want to match them literally. |
| \[b\](.+)?\[/b\] | <b>$1</b> | Now we are getting into some interesting stuff. This pattern matches [b]some text here[/b] and replaces it with <b>some text here</b>. |
