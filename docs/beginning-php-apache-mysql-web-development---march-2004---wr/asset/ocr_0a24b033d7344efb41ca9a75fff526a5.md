# Checklist for Choosing the Right Field Type

Although you won't actually be creating a database from scratch yet, it's important to understand how to figure out what field type will best serve your needs. We put together a list of questions about fields that you can ask yourself before your database tables have been created. As you answer each of these questions, keep in mind the potential values that could exist for the future you're setting up.

Will the field contain letters and numbers?

+   - Yes (look at char, varchar, text, tinytext, mediumtext, longtext, blob, tinyblob, mediumblob, longblob).
- Less than 255 characters, fixed length: Use char.
- 1-255 characters, variable length: Use varchar if you want to delete any trailing spaces, or if you want to set a default value. Use tinytext if you don't care about trailing spaces or a default value or if your text does not need to be case-sensitive. Use tinyblob if you don't care about trailing spaces or a default value, but your text does to be case-sensitive.
- 256-65536 characters: Use text if your text does not need to be case-sensitive in searches, sorts, or comparisons, use blob if your text is case-sensitive.
