# Online Selling: A Quick Way to E-Commerce

# How It Works

The following is step that asks for our customer's billing and shipping information. We start with a little intro, and we let the customer know what he or she is currently on. Then we set up the form that will collect all the information and submit it to the next page of the checkout process:

```
<form method="post" action="checkout2.php">
```

The rest is pretty no-brainer type stuff, just getting the variables and passing them along to checkout2.php.
