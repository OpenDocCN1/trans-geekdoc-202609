## Chapter 14

### How It Works
The following is step that asks for our customer's billing and shipping information. We start with a little intro, and we let the customer know he or she is currently on. Then we set up the form that will collect all the information and submit it to the next page of the checkout process: rest is pretty no-brainer stuff, just getting the variables and passing them along to checkout2.php.

### Checking Out: .php
Let's complete checkout2.php customers can verify that all the information is accurate, and to give customers a chance to make any last minute changes.

```php
<?php
session_id();
session_start();
//connect to the database
$connect = mysql_connect('localhost', 'root', 'mysqlpass') or
die("Hey, check your server connection.");
mysql_select_db('same', 'ecommerce');
if ($_POST['shipfirst'] == 'on') {
    $_POST['shipfirst'] = $_POST['firstname'];
    $_POST['shiplast'] = $_POST['lastname'];
    $_POST['shipadd1'] = $_POST['add1'];
    $_POST['shipadd2'] = $_POST['add2'];
    $_POST['city'] = $_POST['city'];
    $_POST['shipstate'] = $_POST['state'];
    $_POST['shipzip'] = $_POST['zip'];
    $_POST['shipphone'] = $_POST['phone'];
    $_POST['shipemail'] = $_POST['email'];
}
?>
<HTML>
<HEAD>
<TITLE>Step 2 of 3 - Verify Order Accuracy</TITLE>
</HEAD>
<body>
Step 1 Please Enter Billing and Shipping Information<br>
<strong>Step 2 Please Verify Accuracy and Make Any Necessary Changes</strong><br>
Step 3 - Order Confirmation and Receipt<br>

<form method="post" action="checkout3.php">
```
