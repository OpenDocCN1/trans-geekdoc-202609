# Chapter 6

exercises. Create a new database in phpMyAdmin named chapter6. In the new-born database, execute chapter6.mysql script, which holds the database definition and its start data.

Then you're ready to go.

# Try It Out Setting Up the Environment

First, you need a start page. Follow these steps to create one:

+   1. Create a new directory called chap6 under your htdocs (or create an alias, if you wish).

+   2. Create an index.php script and enter the following code:

```
$php
$link = mysqli_connect('localhost', 'root', '');
or die("Could not connect: " . mysqli_error());
mysqli_select_db('chapter6', $link) or die ( mysqli_error());
?>
<html>
<head>
<TITLE>Move database</TITLE>
</head>
<body>
<table border="0" width="600" cellspacing="3" bgcolor="#353535" align="center">
<td bgcolor="#ffffff" colspan=2 align="center">
Movies <a href="movie.php?action=add&id=[]">[ADD]</a>
</td>
</table>
<?php
$movies = "SELECT
FROM
'movie'
";

or die("Invalid query: " . mysqli_error());
```
