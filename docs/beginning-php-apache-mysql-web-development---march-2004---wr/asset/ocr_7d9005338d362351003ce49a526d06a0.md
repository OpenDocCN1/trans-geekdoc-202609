POSIX stands for Portable Operating System Interface (don't ask about the X; we think geeks just to use X however they can). POSIX is a set of standard operating interfaces based on the UNIX operating system. The POSIX term, does not actually refer to the regular expressions themselves, but describes the source of the regular syntax. It is more proper to refer to them as POSIX-style regular expressions. POSIX-style regular expressions are implemented in PHP using the ere() functions, such as ere_match() and preg_replace(), and ere_replace().

PCRE stands for Perl Compatible Regular Expressions. They are usually faster than POSIX-style regular expressions, and for reason along with the fact that PCRE regular expressions are usually more powerful, most developers choose to use PCRE functions as preg_match() and preg_replace().

Chapter 7 briefly introduced you to a POSIX-style regular expression. Here we show PCRE. It is ultimately up to you which one to choose. However, for a thorough understanding of both styles, make sure you read the PHP manual.

# How to write a PCRE regex

So, does a regex look like we? We will demonstrate different regex patterns using the preg_replace() function takes three arguments: the needle, the replacement pattern, and the text to be searched (the haystack). The regex pattern is contained in :needle:

```
$result = preg_replace($needle, $replacement, $haystack);
```

When creating your regex pattern, you must use delimiters to define the boundaries of your regex. The delimiters can be any character alphanumeric. Use the forward slash character (/). This is not a requirement; use any character you are comfortable with. Just remember that if you use the same character within your pattern, it must be escaped by a preceding backpack (\).

There are many ways to designate search patterns in your regex. The simplest is the literal: What you are looking for is literally entered in your pattern, unless between:

```
preg_replace('/goose/', 'pinch', 'Do not goose me, please');
```

If you are looking for one of a group of patterns, separate them with the pipe (|):

To look for specific, put them in square brackets. All of the following are legal regex expressions:

| /[abc]/ | Matches the letter a, b, or c |
| /[a-z]/ | Matches any lowercase letter |
| /[a-zA-Z0-9]/ | Matches any alphanumeric character |
| /[^aeiou]/ | Matches any consonant (^ means "not") |
