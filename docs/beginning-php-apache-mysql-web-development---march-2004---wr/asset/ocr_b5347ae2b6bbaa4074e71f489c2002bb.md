What follows is more complicated SQL statement that you've written thus far, but not too difficult. What's happening here is that you are grabbing the e-mails, name, and user id from the ml_users table where the mailing list id (ml_id) matches their user id in the ml_subscriptions table. This is done by using the INNER JOIN command as are awaiting subscription confirmation, so select only those where pending = 0 or false. If pending = 1 (true), then that is ignored.

```
$sql = 'SELECT DISTINCT user.e-mail, user.username, user.user_id '
'FROM ml_users user * '
'INNER JOIN ml_subscriptions mls * '
'ON user.user_id = mls.user_id '
'WHERE mls.pending=0';
```
