# Appendix D

| MySQL Field Type | Description |
| --- | --- |
| double (length, dec) | A medium-sized floating point number that stores values from -1.797693148623157E+308 to -2.250735885072014E-308, 0, and 2.250735885072014E-308 to 1.797693148623157E+308. Length parameter determines how many characters are displayed; dec determines how many decimal places are displayed. (Adding the unsigned parameter allows only positive numbers to be stored). |
| enum("option1", "option2",...) | Allows only certain values to be stored in this field, such as true and false, or a list of strings. 65535 different options can be allowed. |
| fixed (length, dec) | Equal to decimal. |
| float (length, dec) | A small floating point number that stores values from -3.40282346E+38 to -1.175494315E-38, 0, and 1.175494315E-38 to 3.40282346E+38. Length parameter determines how many characters are displayed; dec determines how many decimal places are displayed. (Adding the unsigned parameter allows only positive numbers to be stored). |
| float (precision) | Equal to float(length, dec) except length and dec parameters are undefined. Can be used with a three floating point number. (Adding the unsigned parameter allows only positive numbers to be stored.) |
| int (length) | Numeric field that stores integers from -2147483648 to +2147483647, but can be limited with the length parameter. Length limits the number of characters that can be shown, not value. Mathematical functions can be performed on data in this field. Signifying the unsigned parameter permits positive integers (and zero) up to |
| longblob | Equal to text except it is case-sensitive when sorting and comparing. |
| longtext | Allows storage up to 4294967295 characters. |
| mediumblob | Equal to mediumtext except it is case-sensitive when sorting and comparing. |
| mediumint (length) | Numeric field that stores integers from -8388608 to 8388607. (Adding the unsigned parameter allows storage of 0 to 16777215) Length limits the number of characters to be displayed.
