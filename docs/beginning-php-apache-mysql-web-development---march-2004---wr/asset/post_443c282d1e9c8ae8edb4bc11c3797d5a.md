## How It Works

Nineteen files make up this CMS application. An additional file is used once to create the tables, making 20 files in all. That may seem like a lot to you, but the use of transaction pages and include files increases the number substantially. If you did not have the application broken out into separate files, you would have fewer files, but each file would be much larger. Our primary purpose in separating the application into many files is to reduce redundancy.

## Connect to the Data Source

Your first step in creating this application is to connect to the database. Most of your pages will require this connection, so putting it in a separate included file is the best solution. File is `conn.php`:

```php
define('SQL_HOST', 'yourhost');
define('SQL_USER', 'jouser');
define('SQL_PASS', 'yourpassword');
define('SQL_DB', 'yourdatabase');

$conn = mysqli_connect(SQL_HOST, SQL_USER, SQL_PASSWORD);
```

## Create the Database Tables

Once conn.php is created, you can create your database tables. Do this with CMStables.php.

First, connect to the database.

```php
require_once 'conn.php';
```

Next, create the table needed for access levels. All of the fields, their datatypes, and other parameters are defined in this SQL statement. We use NOT EXISTS SO THAT the CREATE command does not if the table already exists. If you wanted CMStables.php to create a new, clean version of the app, then you could use IF EXISTS and run the SQL command DROP TABLE filename before re-creating the table.

```php
$sql = <<EOS
CREATE TABLE IF NOT EXISTS cms_access_levels (
access_lvl int(4) NOT NULL auto_increment,
access_name varchar(50) NOT NULL default '',
PRIMARY KEY (access_lvl)
)EOS;
$result = mysql_query($sql) or die($mysql_error());
```

The next lines insert data into your created cms_access_levels table. These access levels are used throughout the CMS application to determine which users have access to.

```php
$sql = "INSERT IGNORE INTO cms_access_levels VALUES (1, 'User');";
$result = mysql_query($sql) or die($mysql_error());
```

We won't include every SQL statement from CMStables.php. If you are knowledgeable enough to read this book, then you can figure out the rest.

## Reusable Functions

```php
/**
 * Trims a string to a specified length and adds ellipses.
 *
 * @param string $theText The text to be trimmed.
 * @param int $len The maximum length of the string.
 * @param string $schar The character to search for.
 * @param int $scnt The number of times to search for the character.
 * @return string The trimmed text.
 */
function trimBody($theText, $len=500, $schar="\n", $scnt=2) {
  // Initialize the variables
  $pos = 0;
  $trimmed = FALSE;

  // If the text is too long, loop through $scnt times to find the n-th occurrence
  for ($i = 1; $i <= $scnt; $i++) {
    if ($tmp = strpos($theText, $schar, $pos)) {
      $pos = $tmp;
      $trimmed = TRUE;
    } else {
      $pos = strlen($theText) - 1;
      $trimmed = FALSE;
      break;
    }
  }

  // Trim the text to the found position
  $theText = substr($theText, 0, $pos);

  // If the returned string is longer than your limit, trim it to the exact length
  if (strlen($theText) > $len) {
    $theText = substr($theText, 0, $len);
  }

  // After this, you might have cut off a word. Trim back to the last space
  if ($trimmed) {
    $theText = substr($theText, 0, strpos($theText, ' '));
    $trimmed = TRUE;
  }

  // If you have trimmed the text at all, add all the ellipses
  if ($trimmed) {
    $theText .= '...';
  }

  return $theText;
}
```
