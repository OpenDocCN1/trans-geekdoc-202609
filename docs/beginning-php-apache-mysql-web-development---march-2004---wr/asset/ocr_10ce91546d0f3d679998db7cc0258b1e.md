# A Tale of Two Tables

The preceding code is all nice and neat and pretty, but it doesn't do you a whole lot of good if you don't have a secret decoder ring to tell you that cyclic "movie type" numbers correspond to plain English. Information is all stored in a separate table, the movietype table. So how do we get this information?

There are two ways to get information from more than one table:

+   - Reference the individual tables in your query
- Join the individual tables in your query

Let's try out these methods and then about each of them in more detail.

# Try It Out Referencing Individual Tables

You can distinguish between two tables in your database by referencing them in the SELECT statement as follows:

```
$query = 'SELECT table1.field1, table2.field2
FROM table1, table2
WHERE table1.field1 = table2.field3'
```
