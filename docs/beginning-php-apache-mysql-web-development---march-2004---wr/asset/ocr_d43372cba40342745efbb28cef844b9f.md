# Building Content Management System

The first parameter, $theText, is the text you trimmed. The second parameter ($lmt) is the absolute longest string you returned, expressed in number of characters. The default value, if none is supplied, is 500. The third parameter ($s_char) is the "stop character." We will trim the document to this character. The default value is a newline(\n). The last parameter is $s_cnt, or "stop count". Given the stop character (in this case $lmt), we will trim after the number designated by $s_cnt. In this case default to 2, so we will trim the text after the second newline.

You first initialize the variables. The variable $pos keeps track of the current position of the character you are executing. The variable $trimmed tells you whether or not the text has been trimmed.

```
$pos = 0;
$s_cnt = FALSE;
```

You then loop through the $s_cnt times. If you find the character within the text on the last loop through, $trimmed will be true, and $theText will be trimmed to that character. If not, $trimmed will be false, and $theText will contain the full text. (This might happen if you were trimming the string to the new length and it were two paragraphs long, for example.)

```
for ($i = 1; $i <= $s_cnt; $i++) {
  if ($tmp = strpos($theText,$s_char,$pos)) {
    $pos = $tmp;
    $trimmed = TRUE;
  } else {
    $pos = strlen($theText) - 1;
    $trimmed = FALSE;
    break;
  }
}
$theText = substr($theText,0,$pos);
```

If the returned string is longer than your limit, you trim it to the exact length of the limit.

```
if (strlen($theText) > $lmt)
$theText = substr($theText,0,$lmt);
```

After this, you might have cut off a word. In the interest of keeping your trimmed text clean, trim back to the last space, and then set $trimmed = true.

```
$theText = substr($theText,0,strpos($theText,' '));
$trimmed = TRUE;
```

If you have trimmed the text at all, add all the ellipses, and return the trimmed text back to where the function was called.

```
if ($trimmed) $theText = '...';
return $theText;
}
```
