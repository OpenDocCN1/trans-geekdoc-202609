# # Program Execution Functions

The functions in the table that follows allow PHP code to execute commands directly from the script.

| Function | Description |
| --- | --- |
| escapeshellarg(arg) | Escapes a string to be used as a shell argument. |
| escapeshellcmd(cmd) | Escapes shell metacharacters in the named command. |
| exec(command[, array], return_var]) | Executes the named command and returns last line of results. |
| passthru(command[, return_var]) | Executes the named command and returns the output. |
| system(command[, return_var]) | Executes the named command and returns all output. |

# # Spelling Functions

You can PHP perform spell checks for you, as long as you supply a reference it can use.

| Function | Description |
| --- | --- |
| aspell_check(link, word) | Using the named link as a reference, it will check the spelling of the named word. |
| aspell_check-raw(link, word) | Using the named link as a reference, it will check the spelling of the named word without changing the case or trimming the word. |
