# # Using PHP with MySQL

| MySQL Field Type | Description | Example |
|---|---|---|
| int(length) unsigned | Numeric field that stores positive integers (and zero) up to 4294967295. The length parameter limits the number of characters that can be displayed. Mathematical functions can be performed on data in this field. | Customer ID (if entirely numerical). |
| text | Any character can be in this field, and the maximum size of the data is 65536 characters. | Comments field allows longer text to be stored, without limiting field to 255 characters. |
| decimal(length, dec) | Numeric field that can store decimals. The length parameter limits the number of characters that will be displayed, and the dec decimal places that can be stored. For example, a price field that would store up to 999.99 would be defined as decimal(6,2). | Prices |
| enum("option1","option2",...) | Allows only certain values to be stored in this field, as "true" and "false" or a list of. 65535 different options are allowed. | Gender field for your users will have a value of "male" or "female". |
| date | Stores a date as yyyy-mm-dd. | Date of order, birthday, date joined as a registered. |
| time | Stores time as hh:mm:ss. | Time a news article was added to the Web site. |
| datetime | Multipurpose field that stores date and time as yyyy-mm-dd hh:mm:ss. | Last date and time a user visited your Web page.

While the preceding field types should suffice for most needs, we've listed some perhaps-less-used types in the table that follows.

| MySQL Field Type | Description |
|---|---|
| tinyint(length) | Numeric field that stores integers from -128 to 127. (Adding the unsigned parameter allows storage of 0 to 255). |
| smallint(length) | Numeric field that stores integers from -32768 to 32767. (Adding the unsigned parameter allows storage of 0 to 65535). |
| mediumint(length) | Numeric field that stores integers from -8388608 to 8388607. (Adding the unsigned parameter allows storage of 0 to 16777215).
