# PHP Functions

| Function | Description |
| --- | --- |
| soundex(string) | Determines soundex key of the named string. |
| split(exp, string[,, limit]) | Splits the named string using the named expression. |
| spliti(exp, string[,, limit]) | Splits the named string using the named expression (case-insensitive). |
| sprintf(format[,, arg1, arg2...]) | Displays the formatted string based on the named parameters. |
| sql_regcase(string) | Searches named string (case-insensitive) and returns a regular expression |
| scanf(format[,, var2...]) | Parses input from the named string based on named parameters. |
| str_replace(oldexp, newexp, string) | Similar to str_replace except it is case-insensitive. |
| str_pad(string, length[,, pad_type]) | Pads the named string to the length with another string. |
| str_repeat(string, number) | Repeats a named string a number of times. |
| str_replace(oldexp, newexp, string) | Replaces one expression with another named string. |
| strrot13(string) | Performs the ROT13 on the named string. |
| str_shuffle(string) | Randomly shuffles the string. |
| str_word_count(string[,, format]) | Counts the number of words in the string. |
| strcasecmp(string1, string2) | Compares two named strings, case-insensitive. |
| strchr(string, exp) | Locates named expression in string. |
| strcmp(string1, string2) | Similar to strcasecmp, except comparison is case-sensitive. |
| strcoll(string1, string2) | Compares the two strings based on locale. |
| strcspn(string1, string2) | Returns the number of characters at the beginning of string1 that do not match string2, opposite of strcspn. |
| strip_tags(string) | Removes HTML and PHP tags from the named string. |
| strpcslashes(string) | Removes C slashes from the named string. |
| stripslashes(string) | Removes escape slashes from the named string. |
| strstr(string, exp) | Finds all occurrences of a named expression in a named string (case-insensitive). |
