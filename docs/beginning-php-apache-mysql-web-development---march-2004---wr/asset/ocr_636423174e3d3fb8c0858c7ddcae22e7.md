# How It Works

Multipart messages are not that complicated. You must tell the e-mail client data that is coming in multiple parts—in instance, plain text and HTML. This is how to do the header:

```
$headers .= "Content-type: multipart/alternative";
boundary="\$boundary\r\n";
```

This tells the e-mail client to look for additional "Content-type" information in the message, which includes boundary information. The boundary is what separates the multiple parts of the message. It begins with dashes (--), and at the beginning of the message, between each part, and at the end. There is no significance to the content of this boundary. The key here is to make it as unique as possible that it likely is not a value that would be repeated anywhere within the message. You can use symbols, numbers, and letters in any combination. Many people choose to use a random number generator or an md5() hash. The method you use is entirely up to you.
