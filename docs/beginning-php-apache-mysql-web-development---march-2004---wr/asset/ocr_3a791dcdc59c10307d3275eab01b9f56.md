# Apache's ErrorDocument: Advanced Custom Error Page

Up until this point, we've been showing you a custom error message only. You can do countless other things, such as e-mailing the administrator or Webmaster of the site so or she can look into the issue should there be a problem with certain pages. This is a great way for you to keep track of your pages without having to check on the server periodically. More likely than ever, if you haven't received any error-mails, there haven't been problems with your server.

Now we generate an automatic e-mail that tells the administrator what time the error occurred, on what day, what error was, what page generated the error, and what error message was displayed to the user who navigated to page. We will be adding this functionality to the same error.php file, so if you wish to keep them separate, name the original page error_old.php or whatever you prefer.
