# PHP Functions

| Function | Description |
| --- | --- |
| chop(string) | Deletes trailing spaces from the named string. |
| chr(ascii) | Returns the character based on the named ASCII code. |
| chunk_split(string[, length, div]) | Divides named string by inserting the named character by every length characters. |
| convert_cyr_string(string, from, to) | Converts named string from one Cyrillic character set to another. |

| crc32(string) | Calculates the crc32 of 32-bit lengths of string. |

| echo(string) | Displays the named string. |
| preg(exp, string[, array]) | Searches the named string for the named expression and stores the results in the named array. |

| get_html_translation_table(table[, quote_styles]) | Returns named translation table. |
| get_meta_tags(filename[, path]) | Returns meta tag information from named file. |
| hebre(text[, max_chars_per_line]) | Converts Hebrew text to visual text. |
| hebrevc(text[, max_chars_per_line]) | Converts Hebrew text to visual with newlines. |
| htmlentities(string[, quote_style]) | Converts characters from named string into HTML entities. |
| htmlspecialchars(string[, quote_style]) | Converts special characters from named string into HTML entities. |
| implode(delimiter, array_name) | Opposite of explode, this combines bits of the named array together using the named delimiter, equal to join. |
