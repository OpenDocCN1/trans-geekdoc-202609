We build the table in HTML, and insert values into the appropriate places as defaults. This is how we fill the fields with character data. Note the use of the PHP tag. We don't recommend using the shortcut <?$variable?> because some servers don't have PHP tags. The full syntax guarantees your code will work, regardless of whatever server it is.

Now we build the Powers select. As we loop through each power in the $powers array (which contains all powers), we concatenate the $powers value for power that "selected". If power's key (from $powerlist) doesn't exist in the $powers array, $powers[$key] will simply be blank instead of "selected". In this way, we build a field of powers where the character's powers are selected in the list. Neato?

Note the [] in the select name attribute. It is necessary for PHP to recognize the variable as an array when it gets POSTED to the next page. This is a requirement for any field that might post with multiple values.
