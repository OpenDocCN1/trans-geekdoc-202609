## cpanel.php

Now let's take a look at our first actual page, cpanel.php. The Control Panel page cpanel.php is used to allow users to change their user names and e-mail addresses. They can also see all of the articles they have written, categorizing by Pending and Published articles.

As always, you need to connect to the database. And, as always, conn.php takes care of that. This time, we are displaying a Web page header.php, which is our standard header for all Web pages.

We first query the database and get the user's name and e-mail address.

```php
$sql = "SELECT name,e-mail FROM cms_users WHERE user_id = $_SESSION['user_id'];";
$result = mysqli_query($sql,$conn)
or (!$result) die('Could not look up user data: ' . mysqli_error($conn));
$user = mysqli_fetch_array($result);
```

You will be editing and exiting PHP file in this one and in other Web pages. This gives you flexibility and makes the page lot easier to read. The next lines exit PHP code:

```php
?>
```

The following forms use the post method. Notice the action. You already created that file. You know when a submit button is clicked on this page, transact-user.php loads, the appropriate code runs, and the user is redirected to the control panel.

```html
<form method="post" action="transact-user.php">
```

Note the use of htmlspecialchars(). This prevents strange characters such as < > from messing up page. Characters Name: will be displayed using their entity equivalents (such as &lt; and &gt;).

```html
<p>Name:<br />
<input type="text" id="name" name="name" value="<?php echo htmlspecialchars($user['name']); ?>"></p>
```
