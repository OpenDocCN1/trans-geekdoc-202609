## Looking at a Ready-Made Database

Let's create the database that you will be using for your movie site. It consists of three tables:

- movie table, which stores the names of the movies and information about them
- movietable, which stores the different categories of movies
- people table, which stores the names of actors and directors in the movies

## Try It Out: Creating a Database

Perform the following steps to create the database and tables:

1. Open your browser and type the following code. This creates our database and the tables you need to hold the data.

```php
<?php
// connect to MySQL: note've used our own parameters - you should use
// your own for hostname, user, and password
$connect = mysql_connect("localhost", "root", "mysqlpass") or
die("Hey loser, check your server connection.");

// create the main database
mysql_create_db("wiley")
or die(mysql_error());

// make sure that our recently created database is the active one
mysql_select_db("wiley");

// create "movie" table
$movie = "CREATE TABLE movie (
movie_id int(11) NOT NULL AUTO_increment,
movie_name varchar(255) NOT NULL,
movie_type tinyint(2) NOT NULL default 0,
movie_year int(4) NOT NULL default 0,
movie_actor int(11) NOT NULL default 0,
movie_director int(11) NOT NULL default 0,
PRIMARY KEY (movie_type,movie_year)
) TYPE=MyISAM AUTO_INCREMENT=4 *;";

$results = mysql_query($movie)
or die (mysql_error());

//// create 'movietype' table
$movietype="CREATE TABLE movietype (
mietype_id int(11) NOT NULL auto_increment,
mietype_label varchar(100) NOT NULL,
PRIMARY KEY (movietype_id)
) TYPE=MyISAM AUTO_INCREMENT=9";

$results = mysql_query($movietype)
or die (mysql_error());

// create 'people' table
$people="CREATE TABLE people (
people_id int(11) NOT NULL auto_increment,
people_fullname varchar(255) NOT NULL,
people_isactor tinyint(1) NOT NULL default 0,
people_isdirector tinyint(1) NOT NULL default 0,
PRIMARY KEY (people_id)
) TYPE=MyISAM AUTO_INCREMENT=7";

$results = mysql_query($people)
or die (mysql_error());

echo "Movie Database successfully created!";

?>
```

## How It Works

We hope you didn't have many errors when running the previous files and you saw the "success" statements. Although we tried to insert comments throughout the code, let's dissect this thing one at a time.

First, we connected to the MySQL server that we could begin sending commands and working with the database and tables. We also wanted to be told if there was an error, and we wanted to immediately stop. We did this in the first few lines of code:

```php
<?php
// connect to MySQL; we've used our own parameters - you should use
// your hostname, user, and password
$connect = mysql_connect('localhost', 'root', 'mysqlpass')
or die("Hey loser, check your server connection.");
```

Then we actually created the database, and if some reason the database could not be created, we told the server to stop and show what the problem was:

```php
// create the main database
mysql_create_db("wiley")
or die(mysql_error());
```

We also made sure to select our database so the server would know which database we would working with:

```php
// make sure our recently created database is the active one
mysql_select_db("wiley");
```

Then we began making our tables, starting with the movie table. We defined the individual field names and set their parameters. We also set the database auto-incrementing of the movie_id at 4 because we will be entering records 1-3 with moviedata.php. We discuss more about this feature later in this chapter, but this will give you a glimpse of what to come:

```php
// create 'movie' table
$movie = "CREATE TABLE movie (
movie_id int(11) NOT NULL auto_increment,
movie_name varchar(255) NOT NULL,
movie_type tinyint(2) NOT NULL default 0,
movie_year int(4) NOT NULL default 0,
movie_actor int(11) NOT NULL default 0,
movie_director int(11) NOT NULL default 0,
PRIMARY KEY (movie_type,movie_year)
TYPE=MyISAM AUTO_INCREMENT=4;";
```

Once we had our MySQL statement ready to go, we just had to send it to the server with the mysql_query command. Again, we told the server to stop executing the program and let know what the error was, if there was one:

```php
$results = mysql_query($movie)
or die(mysql_error());
```

We also created the movie type and people tables in the same way:

