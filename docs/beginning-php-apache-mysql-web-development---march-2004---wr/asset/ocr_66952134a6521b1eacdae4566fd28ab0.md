# Installation Configuration of PHP

Once PHP has been installed on your computer, you can customize it to fit your needs. Some of the configuration settings deal with how the information is shown through the browser, a great many of the settings relate to how the server handles errors and how those errors are displayed to you and your users. You will also be able to have some control over how PHP interacts with MySQL.
