5. In the program you created in Step 4, allow the users the option of saving the information for the next time they visit, and if they choose "yes", save the information in a cookie.

A: You would add a line to the end of your font preference form, wherever you stored it:

Do you want to save these preferences for the next time you log in?
<input type="checkbox" name="pref" value="y">

```
At then the beginning of your moviel.php script (or, wherever that script is processing the form variables) you would add a statement that looks something like this:
if ($_POST['font']=='y') {
  setcookie('font', $_POST['font'], time()+60);
  setcookie('size', $_POST['size'], time()+60);
  setcookie('color', $_POST['color'], time()+60);
}
```

Then instead of accessing those variables through the session, you could access them through the cookie like this:
echo $COOKIE['font'];
