# Creating a Bulletin Board System

As you can see from the last line of the SQL query, we create a Fulltext index with the subject and body columns. This allows us to quickly find the records we are searching for.

Let's take a look at the SQL statement that does the actual search. Let's assume you are looking for the word "Board".

```
SELECT *, MATCH (subject,body) AGAINST ('Board') AS score
FROM forum_posts
WHERE MATCH(subject,body) AGAINST ('Board')
ORDER BY score DESC
```

In order to understand how this returns records, you must understand the MATCH command. MATCH returns a value that rates how well the match was for each row. According to the MySQL method, it is based on the "number of words in the row; the number of unique words in that row, the total number of words in the collection, and the number of documents (rows) that contain a particular word.

Note that the MATCH command is used twice. Frankly, the MySQL optimizer caches the results of the MATCH command the first time it runs, and will not run it twice. Because the MATCH command returns a zero (0) for rows that do not match, putting MATCH in the WHERE clause prevents those rows from returning. If you do not put in the WHERE clause, all rows will be the returned, and they will not be sorted.

Using MATCH in the WHERE clause causes the rows to be returned by relevance. This is not intuitive to all users, however, so we like to put in ORDER BY score DESC for good measure, although it is not required.

For more information on Fulltext Indexes, visit www.mysql.com/doc/en/Fulltext_Search.html.
