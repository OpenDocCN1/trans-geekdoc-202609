## 数学函数

这些函数允许你在 PHP 代码中直接对数据进行数学计算。

| 函数 | 描述 |
| --- | --- |
| abs (number) | 计算数字的绝对值。 |
| acos (argument) | 以弧度计算反余弦。 |
| asin (argument) | 以弧度计算反正弦。 |
| atan (argument) | 以弧度计算反正切。 |
| atan2 (x, y) | 计算 x 和 y 的反正正切。 |
| base_convert (number, startbase, embedbase) | 根据命名参数转换数字。 |
| bindec (binary_string) | 将二进制字符串转换为十进制，与 decbin 相反。 |
| ceil (number) | 将小数四舍五入到下一个整数。 |
| cos (argument) | 以弧度计算余弦。 |
| decbin (number) | 将十进制转换为二进制字符串，与 decbin 相反。 |
| dehex (number) | 将十进制转换为十六进制，与 hexdec 相反。 |
| decoct (number) | 将十进制转换为八进制，与 octdec 相反。 |
| deg2rad (number) | 将角度转换为弧度，与 rad2deg 相反。 |
| exp (argument) | 计算 e 的幂次方。 |
| floor (number) | 将小数向下取整到下一个最小整数。 |
| getrandmax () | 计算 rand 函数产生的最大随机值。 |
| hexdec (hex_string) | 将十六进制转换为十进制，与 dechex 相反。 |
| lcg_value () | 计算 0 到 1 之间的伪随机数。 |
| log (argument) | 计算自然对数。 |
| log10 (argument) | 计算以10为底的对数。 |
| max (num1, num2, ... ) | 计算列表中值的最大值。 |
| min (num1, num2, ... ) | 计算列表中值的最小值。 |
| mt_getrandmax () | 计算 mt_rand 函数产生的最大随机值。 |
| mt_rand ([min, max]) | 生成梅森扭变算法随机值。 |
| mt_srand (seed) | 为梅森扭变随机生成器设置种子。 |
| 函数 | 描述 |
| --- | --- |
| number_format(number, dec_places, dec_point, thousands) | 根据命名参数格式化数字。 |
| octdec(octal_string) | 将八进制转换为十进制，与 decoct 相反。 |
| pi() | 返回 pi。 |
| pow(number, exp) | 计算指定数字的指数幂次方。 |
| rad2deg(number) | 将弧度转换为角度，与 deg2rad 相反。 |
| rand([min, max]) | 在适用的情况下，根据命名参数生成随机整数。 |
| round(number, [precision]) | 将指定数字四舍五入到最近的整数。 |
| sin(argument) | 以弧度计算正弦。 |
| sqrt(argument) | 计算平方根。 |
| srand() | 为随机数生成器设置种子。 |
| tan(argument) | 以弧度计算正切。 |

## MySQL 函数

下表列出了可以在 MySQL 服务器上使用的 PHP 函数，用于为 PHP 脚本添加额外功能。

| 函数 | 描述 |
|---||---|
| mysql_affected_rows([link_id]) | 返回受上一个命令影响的行数。 |
| mysql_change_user(user, pass[, database, link]) | 更改用户。 |
| mysql_close([link_id]) | 关闭连接。 |
| mysql_connect(hostname, username, password, database) | 打开连接。 |
| mysql_create_db(database) | 创建数据库。 |
| mysql_data_result(result) | 获取数据。 |
| mysql_query(query[, link_id]) | 执行查询。 |
| mysql_drop_db(database) | 删除数据库。 |
| mysql_error([link_id]) | 显示错误消息。 |
| mysql_escape_string(string[, link_id]) | 转义字符串以用于查询。 |
| mysql_fetch_array(result) | 获取数组。 |
| mysql_fetch_field(result, field]) | 获取字段。 |
| mysql_fetch_object(result) | 获取对象。 |
| mysql_fetch_row(result) | 获取行。 |
| mysql_field_flags(result) | 显示标志。 |
| mysql_field_len(result) | 返回字段长度。 |
| mysql_field_name(result, index) | 返回字段名。 |
| mysql_field_seek(result, offset) | 移动结果指针。 |
| mysql_field_type(result) | 显示字段类型。 |
| mysql_free_result(result) | 释放结果占内存。 |
| mysql_client_info() | 返回客户端信息。 |
| mysql_get_host_info([link_id]) | 返回主机信息。 |
| mysql_get_proto_info([link_id]) | 返回协议。 |
| mysql_get_server_info([link_id]) | 返回服务器信息。 |
| mysql_info([link_id]) | 获取上一个查询的信息。 |
| mysql_insert_id([link_id]) | 返回插入的自增 ID。 |
| mysql_list_dbs([link_id]) | 列出服务器上的数据库。 |
