Include config.php in each file that requires access to MySQL like so:

```
require('config.php');
```

You require instead of include() because the file is not loaded, you want to halt loading of the page. Another option would be to include(), and then immediately test for the existence of one of the constants. If it does not exist, you could then redirect the user to another page, which makes for a more user-friendly experience.

As you can see here, the constants from config.php are used to make your connection:

```
$conn = mysql_connect(SQL_HOST, SQL_USER, SQL_PASS) 
d die(\'Could not connect to MySQL database. ' . mysql_error());
```

```
$sql = "CREATE DATABASE IF NOT EXISTS SQL_DB ";";
```

```
$res = mysql_query($sql) or die(mysql_error());
```
