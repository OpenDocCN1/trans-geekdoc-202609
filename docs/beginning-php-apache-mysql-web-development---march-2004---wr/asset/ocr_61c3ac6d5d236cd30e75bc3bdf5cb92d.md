# Appendix C

| Function | Description |
| --- | --- |
| fileperms(filename) | Returns the permissions associated with the named file. |
| filesize(filename) | Returns the size of the named file. |
| filetype(filename) | Returns the type of the named file. |
| flock(file_pointer, operation, wouldblock]) | Locks or unlocks the named file. |
| fnmatch(pattern, exp) | Searches for a filename that matches the parameters. |
| fopen(filename, mode[, usepath]) | Opens the named file. |
| fpassthru(file_pointer) | Returns all remaining data in the named file. |
| fputs(file_pointer, string[length]) | Equal to fputs, writes the named string to the named file. |
| fread(file_pointer, length) | Reads the named file up to the length. |
| scancf(handle, format[, vari, var2...]) | Parses input based on the named format from the named file. |
| fseek(file_pointer, offset[,start]) | Moves the file pointer in the named file by offset spaces from start. |
| fstat(file_pointer) | Returns information about named file. |
| ftell(file_pointer) | Returns the position of the file pointer in the named file. |
| ftruncate(file_pointer, size) | Truncates the named file to the named size. |
| fwrite(file_pointer, strength[length]) | Equal to fputs, writes the named string to the named file. |
| glob(string) | Finds pathnames that match the named string. |
| is_dir(filename) | Verifies whether or not the named file is a directory. |
| is_executable(filename) | Verifies whether or not the named file is an executable. |
| is_file(filename) | Verifies whether or not the named file is a file. |
| is_link(filename) | Verifies whether or not the named file is a link. |
| is_readable(filename) | Verifies whether or not the named file is readable. |
| is_writeable(filename) | Verifies whether or not the named file is writeable. |
| is_uploaded_file(filename) | Verifies whether or not the named file has been uploaded using HTTP POST. |
| link(target, link) | Creates a new link. |
