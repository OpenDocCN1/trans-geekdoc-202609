# The Skeleton Script

The Skeleton here is the form4.php script. It all revolves around a use of a switch case structure. It starts with a function definition for the debug display (which now holds the display of the $_GET global array).

The trick resides in the fact that the forms will use the POST methods and thus transmit their information through the $_POST array; the actual page content switching will be made through query strings passed through the $_GET array.

Each step in the building of the data is guided by the $_GET['step'] index value. It holds the informa-tion passed by the ?step=1 part of the URL.

Each value of the script has a specific script attached to it.

# Default Response

What happens when you call the first time and the step URL parameter is not set? Logically it evaluates the switch condition and finds that it doesn't match any of the specified cases, so it executes the default behavior:

```
switch($_GET['step']) {
    default:
        require('startform.php');
        break;
}
```

The require() function gets the content of the file that is specified and includes it in the script at inter-pretation time. The require() function differs from the include() function that it triggers a fatal error instead of a warning if the file is not found. In this instance, having the form would lightly reduce our script's functionality, so we want to know if it doesn't find the file.
