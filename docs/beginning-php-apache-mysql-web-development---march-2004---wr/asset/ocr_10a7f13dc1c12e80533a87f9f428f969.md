# How It Works

Now to test of these, open your browser and type http://localhost/asdf/qwerty/page.html, or any other page you know for certain doesn't reside on your server, into the address bar. You should see the "Page Not Found" message on the screen similar to the message shown in Figure 8-1.

Another way to test or simulate the error messages is that you can ensure the code correctly is to supply it with query string information via the browser. For example, if you want to simulate an "Internal Server Error" error message, type http://localhost/error.php?500 into your address bar.
