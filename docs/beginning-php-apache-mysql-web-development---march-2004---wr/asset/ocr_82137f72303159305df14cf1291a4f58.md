# Where Go for Help

Fortunately, the PHP community is growing. There are numerous sources online to help you through the murky waters should the going tough. We have mentioned these numerous times in this book, but here they are again, one more time.

# wrox.com

This book is specifically designed to help online in a companion Web site, so if you encounter trouble, we strongly encourage you to check out the book's sister site at www.wrox.com.

# PHPBuilder

There are many PHP Web sites out there, but our personal favorite to be PHPBuilder.com. You can find numerous articles, archives, snippets of code, and most importantly a well-developed and very helpful online community of fellow coders all over the world with all levels of competency to assist you as quickly as they can. We have yet to find such a tight-knit and friendly community elsewhere, and we encourage you to post your questions in their forums.

If you are lucky, you might find one of the authors of this book lurking around at PHPBuilder.com. We are all regular contributors, and we are some of moderators. (Hint: check the Echo Lounge.)

# Source Web Sites

You will see this and time again, but like the other advice, we can't stress it. If you have a question about virtually anything, the answer can be found at a source Web site. Each of these Web sites provides a very comprehensive manual that encompasses basically all known knowledge-edge software at hard.

To refresh your memory, here they are:

+   - PHP: www.php.net (Useful hint: If you are looking for help with a function, such as echo, you can simply type www.php.net/echo in your browser and it will take you directly to the echo page. How nifty is that?)
- PHP also provides the manual in a Microsoft Windows Help format (CHM), which is very useful for Windows users. You can download the manual from the php.net Web site and install it on your local machine.
- Apache: www.apache.org
- MySQL: www.mysql.com

# Search and Rescue

If you're experiencing problems with a script, chances are not the first to experience the same obstacles. Use your favorite search engine (such as Google.com) to scour the Internet for articles, discussion forum posts, tutorials, or anything that discusses the problems you're having. This can be a very quick and easy way to keep from reinventing the wheel.
