

## PHP 函数

| 函数 | 描述 |
|---|---|
| debugger_off() | 关闭 PHP 调试器。 |
| debugger_on(server) | 开启 PHP 调试器并将其连接到指定的服务器。 |
| define_syslog_variables() | 初始化 syslog 常量。 |
| dns_check_record(host[, type]) | 等于 checkdnrr，根据命名参数搜索 DNS 记录。 |
| dns_get_mxr(host, hosts[], weight]) | 等于 getmxr，根据命名的主机返回 MX 记录。 |
| fsockopen([hostname, port, errno, errstr, timeout]) | 根据命名参数打开套接连接。 |
| gethostbyaddr(ip) | 根据 IP 地址返回主机名。 |
| gethostbyname(host) | 根据指定的主机名返回 IP 地址。 |
| gethostnames(host) | 根据指定的主机名返回多个 IP 地址。 |
| getmxr(host, mxhosts[], weight]) | 等于 get_mxr，根据命名的主机返回 MX 记录。 |
| getprotobname(name) | 根据命名的协议返回协议号。 |
| getprotobynumber(number) | 根据命名的协议号返回协议名。 |
| getservbyname(service, protocol) | 根据命名参数返回端口号。 |
| getservbyport(port, protocol) | 根据命名参数返回服务。 |
| ip2long(ip) | 将包含 IP 地址的字符串转换为整数。 |
| long2ip(proper_address) | 将整数地址转换为点点表示格式的 IP 地址。 |
| openlog(ident, option, facility) | 打开系统日志连接，与 closelog 相反。 |
| fsockopen([hostname, port, errno, errstr, timeout]) | 根据命名参数打开持久套接连接。 |
| socket_set_blocking(socket, mode) | 确定指定套接字的阻塞模式。 |
| socket_set_timeout(socket, seconds, microseconds) | 确定套接字的超时时间。 |
| syslog(priority, message) | 将指定的消息写入系统日志。 |

### 输出缓冲区函数

表中的函数允许你从 PHP 控制输出缓冲区。

| 函数 | 描述 |
| --- | --- |
| flush() | 刷新输出缓冲区。 |
| ob_start() | 启用输出缓冲。 |
| ob_get_contents() | 获取输出缓冲区的内容。 |
| ob_get_length() | 获取输出缓冲区的长度。 |
| ob_end_flush() | 发送输出缓冲区内容并禁用缓冲。 |
| ob_end_clean() | 删除输出缓冲区内容并禁用缓冲。 |
| ob_implicit_flush() | 切换隐式刷新的开启状态。 |

| get_cfg_var(var) | 返回命名的配置值。 |
| get_current_user() | 返回 PHP 脚本的所有者。 |
| get_defined_constants() | 返回包含所有已定义常量和值的数组。 |
| get_extension_funcs(module_name) | 返回指定模块中的函数。 |
| get_include_path() | 返回当前的 include_path 配置选项。 |
| get_included_files() | 返回一个包含使用 `include_once()` 函数包含的文件名的数组。 |

## 拼写检查函数

只要你提供引用，PHP 就可以进行拼写检查。

| 函数 | 描述 |
| --- | --- |
| aspell_check(link, word) | 使用命名的链接作为引用，检查单词的拼写。 |
| aspell_check_raw(link, word) | 使用命名的链接作为引用，在不改变大小写或修剪的情况下检查单词拼写。 |

| 函数 | 描述 |
| --- | --- |
| aspell_new(master, individual) | 加载指定的母字典并返回链接。 |
| aspell_suggest(link, word) | 使用命名的链接作为引用，为单词提供建议并以数组返回。 |
| pspell_add_to_personal(link, word) | 将指定的单词添加到个人字典。 |
| pspell_add_to_session(link, word) | 将指定的单词添加到会话列表。 |
| pspell_clear_session | 删除当前的会话列表。 |
| pspell_config_create(language, spelling, jargon, encoding) | 配置打开字典的选项。 |
| pspell_config_ignore(link, n) | 配置拼写忽略少于 n 个字符的单词。 |
| pspell_config_mode(link, word) | 更改提供的建议数量。 |
| pspell_config_personal(link, file) | 设置包含个人字典的文件。 |
| pspell_config_repl(link, file) | 设置包含替换项的文件。 |
| pspell_config_runtogether(link, flag) | 决定连词是否有效。 |
| pspell_config_save_repl(link, flag) | 决定是否将替换对与个人单词列表一起保存。 |
| pspell_save_wordlist(link) | 保存链接的个人列表。 |
| pspell_store_replacement(link, misspelled, correct) | 为单词存储替换对。 |
