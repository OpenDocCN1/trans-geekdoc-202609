# Unsupervised Machine Learning

Unsupervised ML describes a class of ML techniques that seek to analyze and identify patterns in unlabeled data sets. Unlike supervised learning algorithms, which require labeled data, unsupervised learning algorithms are used to identify hidden patterns or clusters without the need for an explicit data labeling process. Two of the main techniques in unsupervised learning are clustering and dimensionality reduction [2], as illustrated in figure 4.6.
