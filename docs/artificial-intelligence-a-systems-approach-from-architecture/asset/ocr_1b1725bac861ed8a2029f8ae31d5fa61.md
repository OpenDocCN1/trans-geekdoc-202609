By doing so, we can measure the change of $C$ in relation to a particular weight $w^{(L)}$. More formally, we use the chain rule to compute the derivative of $C$ with respect to $w^{(L)}$:

```
$\frac{dC}{dw^{(L)}} = rac{dC}{da^{(L)}} \frac{da^{(L)}}{dz^{(L)}} \frac{dz^{(L)}}{dw^{(L)}}$
```

Multiplying these three ratios gives the sensitivity of $C$ to changes in $w^{(L)}$. Note that we must modify only slightly the partial derivative here to get the sensitivity of $C$ to changes in $b^{(L)}$:

```
$\frac{dC}{db^{(L)}} = rac{dC}{da^{(L)}} \frac{da^{(L)}}{dz^{(L)}} \frac{dz^{(L)}}{db^{(L)}}$
```

While we can't directly influence activations, we can slightly modify the partial derivative to get the sensitivity of $C$ to changes in the previous activations of our network $a^{(L-1)}$:

```
$\frac{dC}{da^{(L-1)}} = rac{dC}{da^{(L)}} \frac{da^{(L)}}{dz^{(L)}} \frac{dz^{(L)}}{da^{(L-1)}}$
```

However, what we have demonstrated in this example takes only layer $L$ into consideration, indicating the list of updates that we want to happen to weights, biases, and activations of the previous layer. Once we have those, we simply recursively apply the same backpropagation process to the relevant weights and biases that determine those activations for the previous layer until the first layer is reached. We do this by chaining more partial derivatives to find the weights and biases for those layers, moving backward through each layer of the network. So, to calculate the derivative of the cost function with respect to the hidden layer $L-1$, we must build on the predictions for layer $L$:

```
$\frac{dC}{da^{(L-1)}} = \frac{dC}{da^{(L)}} \frac{da^{(L)}}{dz^{(L)}} \frac{dz^{(L)}}{dw^{(L)}} \frac{dw^{(L)}}{da^{(L-1)}} \frac{da^{(L-1)}}{dz^{(L-1)}}$
```

Now we continue this process, working backward through the network and adding more partial derivatives for each extra layer.

Note that thus for now, we have only computed the derivative of $C$ with respect to $w$ for just one training example.
