Recall that when training, we are seeking to minimize some predefined loss function, which represents the cost of a wrong prediction [16]. In this section, we discuss the backpropagation algorithm, a key process step that is used to train neural networks by minimizing the loss function by efficiently updating the network's weights and biases.

Backpropagation was notably popularized in a 1986 paper in Nature titled "Learning Representations by Back-propagating Errors," by Rumelhart et al. [9]. At a high level, the backpropagation algorithm identifies how a model should update its internal parameters (weights and biases), which are used to compute the representation in each layer based on the representation in the previous layer [8]. This algorithm is the worthwhile behind DNNs learn and discover intricate structures in large datasets.

Our goal with backpropagation is simple—to adjust the weights and biases of our network by minimizing our loss. By computing the gradient of the loss function with respect to the weights of the network and then using the gradient to update the weights in a way that reduces the loss. We describe some of the key elements of the backpropagation algorithm using a simple network with only one neuron per layer.

We start by describing some relevant equations. First, we define the activation, $a^{(L)}$, of the neuron at the final output layer $L$. The activation is computed by feeding $z^{(L)}$, the weighted sum of all input activations plus a bias term, into an activation function $F_a$:

```
$z^{(L)} = w^{(L)} \cdot a^{(L-1)} + b
$a^{(L)} = F(z^{(L)})$
```

For a predicted output and its associated true value $y$, we compute the cost, or loss, of our prediction with respect to the predefined cost function $F_c$:

```
$C = F_c(a^{(L)}, y)$
```

Given the cost function, the task is to understand how sensitive the cost function is to the different weights and biases in the network. Our goal during training is to minimize the cost of the network's predictions. A better understanding of the relationship between different components of the network and the overall cost will allow us to effectively identify and update the weights and biases that will minimize the cost.

Formally, we will need to compute the derivative of $C$ with respect to $u^{(L)}$. Note that since $u^{(L)}$ is not directly found in the cost function, we start by considering the change

By doing so, we can measure the change of $C$ in relation to a particular weight $w^{(L)}$. More formally, we use the chain rule to compute the derivative of $C$ with respect to $w^{(L)}$:

```
$\frac{dC}{dw^{(L)}} = \frac{dC}{da^{(L)}} \frac{da^{(L)}}{dz^{(L)}} \frac{dz^{(L)}}{dw^{(L)}}$
```

Multiplying these three ratios gives the sensitivity of $C$ to changes in $w^{(L)}$. Note that we must modify only slightly the partial derivative here to get the sensitivity of $C$ to changes in $b^{(L)}$:

```
$\frac{dC}{db^{(L)}} = \frac{dC}{da^{(L)}} \frac{da^{(L)}}{dz^{(L)}} \frac{dz^{(L)}}{db^{(L)}}$
```

While we can't directly influence activations, we can slightly modify the partial derivative to get the sensitivity of $C$ to changes in the previous activations of our network $a^{(L-1)}$:

```
$\frac{dC}{da^{(L-1)}} = \frac{dC}{da^{(L)}} \frac{da^{(L)}}{dz^{(L)}} \frac{dz^{(L)}}{da^{(L-1)}}$
```

However, what we have demonstrated in this example takes only layer $L$ into consideration, indicating the list of updates that we want to happen to weights, biases, and activations of the network. We do this by chaining the partial derivatives to the previous layer. So, to calculate the derivative of $C$ with respect to $w^{(L)}$, we must:

```
$\frac{dC}{da^{(L-1)}} = \frac{dC}{da^{(L)}} \frac{da^{(L)}}{dz^{(L)}} \frac{dz^{(L)}}{w^{(L)}}
```
