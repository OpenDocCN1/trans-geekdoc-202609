The first-generation TPU (TPUv1) had dedicated local memory that was to size of the arithmetic precision being used [60]. The TPUv1 was designed for very fast inference operations, the computations were done in a large matrix unit of size 256 × 256 and 8 bits multiply-accumulators. The multiply-add or multiply-accumulate (MAC) was implemented using a systolic array architecture. With a systolic architecture, simultaneous multiply-add operations are executed in one clock cycle (to maximize throughput without additional overhead when accessing memory).

A systolic array architecture is very well matched to simple linear algebra operations—for example, in signal processing applications—where real-time performance is key [61, 62]. For instance, in adaptive array beamforming, a large number of multiply-add operations must be performed in real time with low latency. A systolic array architecture enables fast processing using simple hardware (to minimize power and cost). Using this as an analogy (i.e., needing high throughput at low power), similar requirements demand the drive for TPUs.

In a TPU, the instructions were fetched from a hot CPU via a PCIe bus to an instruction buffer. The implementation of the DNN algorithms was done using TensorFlow, as the domain-specific language, which enables portability.
