## A Multilayer Perceptron

In this appendix, we walk through a hands-on exercise using a Jupyter notebook to implement an MLP using the MNIST data set.

### MNIST Data Set and MLP Review

The MNIST data set used in this exercise consists of 70,000 images. Each image is a 28×28 grayscale image associated with a label from one of the following classes:

- 0: T-shirt/top
- 1: Trouser
- 2: Pullover
- 3: Dress
- 4: Coat
- 5: Sandal
- 6: Shirt
- 7: Sneaker
- 8: Bag
- 9: Ankle boot

Each image is represented as a 784-dimension feature vector from 0 (white) to 255 (black), labeled with the digit that it represents. An MLP is a fully connected feedforward artificial neural network (ANN). It consists of three types of layers: the input layer, hidden layers, and the output layer. The input layer receives the signal to be processed. The processing is done at the hidden layers, which serves as the computational engine of the network. A final classification is generated at the output layer.

We begin by reviewing some useful definitions throughout this section. We also encourage you to refer to chapter 4 for a deep dive into some of these concepts if you want more information:

- **Hyperparameter**: Tunable “knobs” available to the designer. This includes things like number of layers, number of nodes, type of activation function, learning rate, epochs, and batch size. These values are not learned by the algorithm itself (unlike parameters), and thus are defined by the designer.
- **Learning rate**: The rate at which gradient descent searches for a global minimum.
- **Epoch**: A pass through the full training/validation data forward and backward.
- **Batch size**: A subset of the training/validation set passed through the network in one iteration. The larger the batch size, the more processing can be done in parallel with GPUs.
- **Iteration**: The number of batches needed to complete one epoch.

As discussed in section 4.4 of chapter 4, backpropagation is the engine behind the training of every neural network. Through the process of backpropagation, the weights and biases defining the connections between neurons get adjusted to minimize the loss function, which captures the difference between the output of the neural network and the desired target value during training.

## Implementing an MLP Classifier

We will begin by launching the Jupyter notebook for this exercise. In the first segment of the notebook, we begin by importing a few common modules (sklearn, keras, numpy, tensorflow, matplotlib), and ensuring that we are running the most recent version of Python.

Next, we define utility functions for the various types of activation functions and their derivatives, which we will refer to later when designing our neural network. We then fetch the MNIST Fashion data set, already split between a training set (60,000) and a test set (10,000 images).

```python
fashion_mnist = keras.datasets.fashion_mnist
(X_train, y_train_full), (X_test, y_test) = fashion_mnist.load_data()
```

We further split our training set to get a validation set of 5,000 samples. We also proceed to scale down the pixel intensities from 0–255 down to the 0–1 range and convert them to floats by dividing by 255:

```python
X_valid, X_train = X_train_full[:5000] / 255, X_train_full[5000:] / 255
y_valid, y_train = y_train_full[:5000], y_train_full[5000:]
X_test = X_test / 255
```

Our model is built using the Sequential API:

```python
model = keras.models.Sequential([
    keras.layers.Flatten(input_shape=(28, 28)),
    keras.layers.Dense(368, activation="relu"),
    keras.layers.Dropout(0.2),
    keras.layers.Dense(10, activation="softmax"),
])
```

Before we train, we must compile the model with an optimizer and a loss function:

```python
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
```

Now we proceed with training our model. It's important to note that our training (up to 25 epochs) may take a couple of minutes to complete:

```python
history = model.fit(X_train, y_train, epochs=25, validation_data=(X_valid, y_valid))
```

Each line in the output shows the results from 1 epoch. The cross-entropy training loss and accuracy, as well as the validation loss and accuracy, are logged. The metrics in the final epoch (25/25) denote the cross-entropy loss and accuracy of the final model. We can plot the performance of training- and validation (loss and accuracy) as a function of epoch:

```python
import matplotlib.pyplot as plt

loss = history.history['loss']
val_loss = history.history['val_loss']
acc = history.history['accuracy']
val_acc = history.history['val_accuracy']
epochs = range(1, len(loss) + 1)

plt.figure(figsize=(10, 5))
plt.subplot(1, 2, 1)
plt.plot(epochs, loss, 'r='loss')
plt.plot(epochs, val_loss, 'b=val_loss')
plt.title('Model Loss')
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.legend()

plt.subplot(1, 2, 2)
plt.plot(epochs, acc, 'r=acc')
plt.plot(epochs, val_acc, 'b=val_acc')
plt.title('Model Accuracy')
plt.xlabel('Epoch')
plt.ylabel('Accuracy')
plt.legend()
plt.show()
```

Finally, we can now evaluate the performance on the test set:

```python
model.evaluate(X_test, y_test)
```

We can now use MLP to predict the performance on the first three instances of the test data and compare against the graphical display of the samples:

```python
import numpy as np

predictions = model.predict(X_test[:3])
predicted_classes = np.argmax(predictions, axis=1)
actual_classes = y_test[:3]

print(predicted_classes)
print(actual_classes)
```

The cross-entropy loss function is a common choice for classification tasks. It is formulated using probabilities as $H(p, q) = -\sum p(x)\log(q(x))$, where $p(x)$ is the true class probability and $q(x)$ is the predicted probability. The negative sign is needed to make the cross-entropy loss positive since we are taking the log of numbers smaller than 1. Our model is built using the Sequential API:
