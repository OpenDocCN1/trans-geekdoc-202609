# Activation functions

Rectified linear unit (ReLU):

f(x) = max(0,x)

![](bbox=[0.393, 0.123, 0.686, 0.246])

Sigmoid function:

f(x) = \frac{1}{1 + e^{-x}}

![](bbox=[0.373, 0.271, 0.686, 0.423])

Tanh function:

f(x) = tanh(x)

![](bbox=[0.363, 0.458, 0.686, 0.61])

Step function:

f(x) = \begin{cases} 0, x < 0 \ 1, x \geq 0 \end{cases}

![](bbox=[0.353, 0.642, 0.686, 0.815])
