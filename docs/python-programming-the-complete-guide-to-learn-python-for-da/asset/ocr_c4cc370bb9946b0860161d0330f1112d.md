# Sample programs with conditional statements if ...

Let's see an example. The following program asks the user for a positive number and stores the response in the "number" variable. Then check if the number is negative. If it is, the program warns that that was not what was requested. Finally, the program always prints the value entered by the user. Below you can see two step-by-step executions of that program. In the first one, the user writes a negative value and in the second the user writes a positive value:

# Example of "if" ... 1

```
number = int(input("Enter a positive number: "))
if number < 0:
    print ("¡I told you to write a positive number!")
print (f" You have written the number {number }")
```
