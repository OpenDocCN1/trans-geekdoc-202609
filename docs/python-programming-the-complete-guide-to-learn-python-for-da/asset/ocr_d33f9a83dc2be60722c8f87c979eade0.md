The 7.0 = x statement is a syntax error in programming, although it is valid in mathematics. But x = x + 3 would be absurd in mathematics, but in programming languages it means adding to the variable x the value 3 and then the result of that expression then assigning it to the same variable x.

Python allows multiple assignments of the type

```
>>> x, y, z = 7, 8.2, 9
```

The variable y is real of value 8.2, x is an integer of value 7 and z integer of value 9. To the right of the assignment, a compound data, a tuple in Python, has been written, which is assigned to the tuple formed by the three variables.

In summary: in Python, a variable is not stored directly in memory; an object is created (whose position in memory is called identity), and the identifier of the variable is associated with the identity of that object.
