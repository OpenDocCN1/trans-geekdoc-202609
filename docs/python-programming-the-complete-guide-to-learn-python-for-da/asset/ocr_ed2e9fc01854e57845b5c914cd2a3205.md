analogously to strings. Let's look at several examples:

>>> t = ('the', 'tuples', 'are', 'immutable')

The static or immutable characteristic of the tuples is observed, as are the
strings. We can include tuples within tuples and concatenate and repeat them,
such as string,

```
>>> b = (3, 4, 5, 'a')
>>> c = (b, 2)
>>> b + c
(3, 4, 5, 'a', (3, 4, 5, 'a'), 2)
>>> 3*b
(3, 4, 5, 'a', 3, 4, 5, 'a', 3, 4, 5, 'a')
```

including tuples:

>>> games = ('tennis', 'baseball', 'football', 'voleyball', 'swimming')
>>> for sport in games:

tenis
