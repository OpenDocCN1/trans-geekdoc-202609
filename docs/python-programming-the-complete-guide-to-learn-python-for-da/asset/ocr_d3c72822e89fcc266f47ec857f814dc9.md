First, the sqrt function of the math module must be imported (abs does not need to be imported as it is an internal function). What is between the parentheses of abs and sqrt (the value -9 and the variable x, respectively) is the argument of the function. These functions return a value (return value) after being called. The abs function is called within an arithmetic expression, the value that it returns happens to replace it in the expression and is added to 3. Then, this new value is assigned to the variable x. Care must be taken that the type of data returned by the function is compatible with the operation to be performed. The arguments of the functions may be expressions, including expressions that include calls to other functions, as noted below,

```
y = sqrt(4 + x**2)
z = sqrt(abs(-40))
```

The round or randint functions require two arguments and return a value:

```
from random import randint
n = randint(10, 100)/3.2567
print(n, round(n,2))
```
