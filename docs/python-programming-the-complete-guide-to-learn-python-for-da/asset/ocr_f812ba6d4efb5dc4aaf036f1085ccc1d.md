# 27. What does this mean? * args, ** kwargs? And why would we use it?

Answer :

* Args is used when you are unsure of how many arguments are going to be passed to a function, or if you want to pass a list or tuple of saved arguments to a function.

** kwargs is used when we don't know how many keyword arguments are going to pass to a function, or it is used to pass the values of a dictionary as the keyword argument. The identifiers args and kwargs are a convention, you can also use * bob and ** billy but it would not be prudent.
