The sentences or instructions are the basic units of the programs (also called in the slang of the programmers, codes) that produces an action, such as assigning a value to a variable, displaying a result, etc. The Python interpreter executes each statement producing the given action.

```
>>> y = x/2 + 3
>>> print(y)
8.0
```

```
>>> 1.5*3/2
2.25
>>> print (_)
2.25
```

The first sentence in the box on the left calculates the expression x / 2 + 3 and the result assigns it to the variable y. The second statement shows the value of y. But, the expression in the box on the right 1.5 * 3/2, whose calculation is not assigned to any variable, its result is saved associated with a variable called “ _”.
