The use of module functions can be done in 2 ways. So far, we have imported the function or value we need and apply it directly in the instruction. We can also import multiple module functions:

```
from math import sqrt, log10
x = sqrt (10)
dB = log10(x/2)
```

Alternatively, you can import the math module and use the separate module functions with a dot:

```
import math
x = math.sqrt (10)
dB = math.log10(x/2)
```

In this case, the module name can be abbreviated:

```
import math as m
x = m.sqrt (10)
dB = m.log10(x/2)
```
