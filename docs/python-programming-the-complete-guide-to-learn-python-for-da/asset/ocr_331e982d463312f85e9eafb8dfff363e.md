# Sample programs with conditional statements if ... else ...

Let's see an example. The following program asks the user for age and stores the answer in the "age" variable. Then check if the age is less than 18 years. If this comparison is true, the program writes that it is a minor and if it is false write that it is of legal age. Finally, the program always says goodbye, since the last instruction is out of any block and therefore is always executed. Below you can see two step-by-step executions of that program:

# Example of "if" ... "else" ... 1

```
age = int(input("How old are you? "))
if age < 18:
    print ("Are you a minor")
else :
    print ("Are you of legal age")
print ("iGoodbye!")
```

# Example of "if" ... "else" ... 2

age = int(input("How old are you? "))
