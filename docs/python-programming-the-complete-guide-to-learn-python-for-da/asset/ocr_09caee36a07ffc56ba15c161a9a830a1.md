# 25. What is the use of the help () and dir () functions in Python?

Answer :

Help () and dir () are two functions accessible from the Python interpreter and are used to view a consolidated dump of built-in functions.

Help (): The help () function is used to present the documentation chain and makes it easy for you to see help related to modules, attributes, and keywords, etc.

Dir (): The dir () function is used to view the defined symbols.
