def words(document):
    collection = set()
    for line in document:
        for word in line.split():
            if word not in collection:

    return collection

ABC was developed in the early 80s as an alternative to BASIC, it was designed for beginners for its ease of learning and use. His code was compact but readable.

The project did not transcend as the hardware available at the time made its use difficult. So, Van Rossum gave it a second life creating Python.
