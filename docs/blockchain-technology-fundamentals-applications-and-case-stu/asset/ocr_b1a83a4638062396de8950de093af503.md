# 11.6 BLOCKCHAIN-BASED SUPPLY CHAIN MANAGEMENT

Generally, blockchain is based on three techniques: public, private, and consortium. Open model is transparent to every user in the network. If any block in the network updates its transaction, it will be visible to every other in the system and at any time the new block will join to permission-less model; if new block is requested to join in the network, it will join quickly without any permission. Another technique is based on a private model where new block requires permission from a single owner, and the network updates its node only if it gets permission from an owner. The third technique is the consortium model, which is also similar to the private model, and the difference is it contains several owners instead of the single owner.
