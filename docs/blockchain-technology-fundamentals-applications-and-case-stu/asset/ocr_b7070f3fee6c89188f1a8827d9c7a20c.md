# 2.5 CONCLUSION

This chapter covered the blockchain standards and blockchain protocols like Hyperledger Fabric, Symbient, R3Corda, blockchain, Ripple, and Ethereum. In addition, this chapter reviewed and categorized the popular protocols used for networking, communication, and management. The chapter focused on analyzing consensus protocols, their feasibility, efficiency, and characteristics. A good consensus protocol must be developed by considering fault tolerance and proper application scenario. The chapter finally concluded that Hyperledger outperforms Ethereum and ripple. Ethereum is more flexible than node failures, but they are prone to security attacks. Ethereum requires more memory and data usage than other protocols. Hyperledger uses low-level data model, and its elasticity enables modified optimization for queries.
