# Ether

It is a token used in the Ethereum network, which is denoted as “ETH” during the exchange of cryptocurrency at the time of making the payment for transaction fees, computational, and for gas.

# Gas

It acts as an intermediate token during the transaction to calculate the computational power needed to run the smart contract of this transaction. Before the payment is done by Ether, Gas measures the unit of the computational power and based on that Ether is paid for this transaction (Figure 8.10).

# Smart Contracts

The smart contract is the agreement done in the blockchain network to do the exchange data or money. This third-party application agent mentions the legal terms and conditions that have to be followed during the transaction.
