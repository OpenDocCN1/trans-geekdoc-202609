The transaction steps are given below:

+   Step i: The EOA sender initiates the transaction and signs it digitally.
Step ii: The sender sends the transaction to the Ethereum client.
Step iii: The next process by the client is to validate the arrived transaction, and after the validation, it is broadcasted to the decentralized peer-to-peer Ethereum network.
Step iv: The miner inserts the newly arrived transaction into the transaction pool.
Step v: the miner chooses a transaction from the transaction pool in a sequence and creates the modifies the state of the blockchain based on the type of transaction. If the transaction is EOA, the specified value is forwarded from the sender's EOA to the receiver's EOA. If the transaction is contract account, the contract is created and the bytecode is modified and loaded in the EVM.
Step vi: Unlike bitcoin, which uses PoW, Ethereum miner uses the PoS to do the verification with the help of the puzzle, and the voter's strength is identified based on the value stored in the block.
Step vii: Once the new block is created, it is broadcasted in the decentralized peer-to-peer Ethereum network by the miner, and the other participants validate it.
Step viii: Once the validation process is complete, the client appends the block into the Ethereum blockchain.
