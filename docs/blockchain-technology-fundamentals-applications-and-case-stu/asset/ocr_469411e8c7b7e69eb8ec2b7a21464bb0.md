# 10.8 RESULTS

Hypothesis

$H_0$: Whether the observed value of digital linked information system meets the expected value of any business organization?

In order to prove that hypothesis to check the proposed information system based on blockchain technology fits in any organization, we deployed test of goodness-of-fit since we had one nominal variable and small sample size; we would like to understand whether the number of observations in each classification fits a hypothetical expectation.

The table (Table 10.1) was created with the bar plot format in the R Graphics Package to produce a meek plot. The observed proportions were first calculated and then results were copied into a matrix format that was produced by above or plotting. We labeled that matrix as ISM, often called an “R × C table”, where R is the number of rows and C is the number of columns.

The graph is shown in Figure 10.5. It shows the package ggplot2, and uses a data frame instead of a matrix. For the defined data frame, the code actually calculates confidence intervals, which will be added to the data frame. This can be garbled if the values are determined and can be inserted into a data frame named Fitness from which the plot could be generated. Sometimes it is that factors needs to be in level of order, which should be specified for ggplot2 or will alphabet levels. The expected value for all null hypothesis is within a range 0.5–0.6, our hypothesis is accepted as defined conditions met.

Figure 10.5 shows a bar plot of Fitness for Organization versus. Information Systems. Error bars indicate 95% confidence intervals for each observed proportion.
