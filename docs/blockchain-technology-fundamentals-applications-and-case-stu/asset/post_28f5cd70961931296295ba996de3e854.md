## 4.1.1 IoT Architecture

The IoT architecture comprises four components (Figure 4.2). They are as follows:

- 1. **Sensor nodes:**
  - Sensor node is a component that can work as an individual device or as a group of nodes together. It helps to receive signals from the environment that can be converted to human understandable data. Other sensor nodes, some of the IoT devices include RFID tags and readers, thermal and smart cameras, accelerometers, and GPS.
- 2. **Gateway/sink:**
  - Raw data that are collected by the sensor nodes are moved to the processing unit storage through the gateway. Here, the gateways can be a wireless medium (Wi-Fi, ZigBee) or a wired network. It acts as an interface between the nodes and the server.
