Bitcoin protocol supports crypto payment transactions over distributed network. Bitcoins are virtual currency, also called as cryptocurrency. Bitcoin includes crypto-hash function and consensus algorithm. This protocol prevents duplication of payments and data fiction.

# 2.2.2.1.1 Bitcoin Transactions

A bitcoin transaction requires a unique transaction ID, bitcoin addresses as the input, number of bitcoins to be transferred, and the receiver's bitcoin address.
