The basic requirements for blockchain are as follows:

+   - Protocols for commitment
There should be a proper mechanism to ensure that every valid transaction from the clients is committed and included in the blockchain within a finite time. +   - Consensus
There should be a mechanism to ensure that the local copies of the public ledger are consistent and updated.

+   - Security
When one party broadcasts the information, other parties involved should be able to validate that the information is tamperproof. If a client acts maliciously or if a client is compromised, it should be identified by the other parties immediately.

+   - Privacy and authentication\As a number of parties are involved in a blockchain, authenticity and privacy of the data should be maintained.

According to Iansiti and Lakhani (2017), blockchain can be defined as “an open distributed/decentralized ledger that can record transactions between the parties efficiently and in a verifiable and permanent way”. The public ledger is accessible to all and is not controlled by a single party. The transactions between the parties should be fast and scalable, and everyone involved check the validity of information. They have also briefed the working of blockchain. The cryptographic primitive used to build the blockchain is a hash function. Every block stores the hash value of the previous block and thus the hash function acts as a link to the chain of blocks, resulting in a blockchain. This type of using values to form a chain of blocks is derived from Harber and Stometta (1990). The Merkle trees used by Merkel, developed in 1979 (Merkle, 1982), is combined with the work of Harber and Stometta (1990) to develop efficient time sampling of documents to form one block (Bayer et al., 1993). This invention led to the discovery of bitcoin by Nakamoto (2008), which is built on the foundation of blockchain technology.

Bitcoin is a completely decentralized peer-to-peer cryptocurrency. As it is permissionless, anyone without any identity or login credentials can use it anywhere, without any access control. This leads to legal issues in many countries, the technology behind it, blockchain, can be used for a number of useful applications. Blockchain technology can be used not only in the financial sector but in almost all the distributed, decentralized applications. Governments, industries, academia, and agriculture domain are moving towards blockchain, and this revolution is called Blockchain 2.0.
