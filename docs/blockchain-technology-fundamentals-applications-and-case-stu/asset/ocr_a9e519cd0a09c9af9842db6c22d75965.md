# The elements of PKI are

+   1. Certificate authorities: CA issues digital certificates to parties and authenticate the parties with exchange with their environment.
2. CA's certificate revocation list (CRL): Revoked certificate lists are listed in CRL [8]. It creates a reference for the revoked certificate which are no longer used. Cancelation of a certificate can done for many reasons. For example, a certificate may be revoked because the cryptographic key has been compromised.

BC network also relies on the PKI standard to guarantee secure point to point communication between various network, It confirms communication messages posted on the BC are authenticated.

There are four key elements to PKI:

+   * Digital certificates
* Public and private keys
* Certificate authorities
* Certificate revocation lists
