Smart meter is used to drop out the energy and currency after verification of the usage of the prosumers [11]. Figure 1.3 shows four prosumers. Each prosumer has an Energy Trading and Security Enhancement (ETSE) software, a BC node, and a local smart meter. The software ETSE is installed inside each prosumer. A blockchain node is deployed using ETSE in each prosumer. An interaction that was done through the BC node was secured with special functionalities, and it was mentioned using dotted lines. The three different layers of the prosumers premises (ETSE module) are shown in Figure 1.4. They are the Policy Management Layer (PML), the Energy Trading Layer (EL) and the Security Enhancement Layer (SEL). PML is nothing but a set of rules. Using these rules should be exchanged between the prosumers. Each prosumer has separate rules, and each follows them separately. ETSE manages and controls the smart meters from vulnerability. The local smart meters transfer energy by contract. SEL is used for security purpose. It gets energy from the previous layer EL verifies the energy; if it is vulnerable, will violate it. Usually, SEL keeps on updating its security storage if there is any solution to solve the particular vulnerability. It stores and sorts it in a knowledge base [12]. Alternating Direction Method of Multipliers (ADMM) is an algorithm; it is also another method of smart energy consumption that decomposes a problem into subproblems, and it secures the transactions of energy naturally [13].
