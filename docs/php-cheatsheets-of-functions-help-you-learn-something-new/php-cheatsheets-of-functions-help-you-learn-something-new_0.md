## PHP 日期格式


## PHP 日期格式：主要提示

- 此 `date()` 函数用于在代码中格式化日期和时间。
- 有特殊的格式化字符：PHP 年、周、日等。
- 你可以使用它让 PHP 自动获取时间戳并更新你网站上的版权日期。

## 语法规则解释

输入日期的语法规则相当简单：

```
date(format, timestamp)
```

`timestamp` 部分描述一个整数 Unix 时间戳。输入它是可选的——如果你不输入，它将导致 PHP 自动获取时间戳并显示当前本地时间 (`time()`）。

现在，对于 `format` 部分，就是另一回事了。它是必要的，因为你需要通过它来指定你的 PHP 日期格式的外观。

## 常用格式化字符

在 PHP 中，年、月、日通常使用特殊符号来引用。PHP 日期函数中最常用的四个字符是：
- `d` (01-31) 代表日期数字。
- `m` (01-12) 代表月份数字。
- `Y`（四位数）代表年份。
- `l`（小写 'L'）表示星期几。

可以添加更多符号（`/`、`.`、`-`）用于额外的 PHP 格式化。在下方的代码示例中，你可以看到创建 PHP 日期的四种不同方法：

```php
<?php
 echo "Today is " . date("Y/m/d") . "<br>";
 echo "Today is " . date("Y.m.d") . "<br>";
 echo "Today is " . date("Y-m-d") . "<br>";
 echo "Today is " . date("l");
?>
```

## PHP 数组函数


## PHP 数组函数：主要提示

- 引入于 PHP 4，它根据指定的参数创建一个数组。
- PHP 数组是包含多个值的变量。
- PHP 数组有三种类型：索引（数字索引）、关联（命名键）和多维（嵌套数组）。

## `array()` 的用法

`array()` 是所有 PHP 数组函数的基础。简单来说，它用于创建数组。让我们来看一个简单的示例：

```php
<?php
  $food = ['IceCream', 'Pizza', 'Burger'];
  echo "I like " . $food[0] . ", " . $food[1] . " and " . $food[2] . ".";
?>
```
（注：此处保留图片位置）

## 正确语法

你可能知道编码时注意正确的语法至关重要，使用 PHP 数组函数也是如此。让我们看看索引数组应该编写：

```
array(value1,value2,value3);
```

现在，关联数组的 PHP 语法有点不同。它们通过键值对来定义。注意，数字或字符串都可以表示键：

```
array(key=>value,key=>value,key=>value);
```

在两种使用 PHP 数组函数的情况下，`value` 元素定义了数组包含的每个值以便 PHP 创建数组。在 PHP 5.4 引入的数组快捷语法中，`array()` 可以被替换为 `[]`。例如，与其写 `$food=array("IceCream","Pizza");`，你只需输入 `$food=["IceCream","Pizza"]` 即可让 PHP 创建数组。这不会改变新数组函数的方式。

## 练习：代码示例

下面的示例代码创建了一个 PHP 脚本引用的关联数组 `$age`：

```php
<?php
  $age = [
    'Drago' => 69,
    'Mark' => 32,
    'Luke' => 35
  ];
  echo "Mark is " . $age['Mark'] . " years old.";
?>
```



如果我们想执行一个 PHP 关联数组循环并打印它的值，我们的代码将如下：

```php
<?php
  $food = [
    'Pizza' => 5.90,
    'IceCream' => 1.90,
    'Burger' => 2.90
  ];
  foreach($food as $z => $z_value) {
    echo "Key=" . $z . ", Value=" . $z_value;
    echo "<br>";
  }
?>
```
