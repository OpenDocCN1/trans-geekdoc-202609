# Algorithm 7.3 Case-specific random forest algorithm.

+   1) Grow an ordinary RF of size B to the training data d_trn.
+   
+   2) For each observation in the test set, say x0, do the following:
+   
+   a) Compute the proximities between x0 and each observation in d_trn using the initial RF from Step 1); let {prox_i(x0)}^N_{i=1} be the proximities between x0 and each case from d_trn; that is, the fraction of times x0 cohabitates with each training instance across the B trees in the initial RF.
+   
+   b) Define the case weight for training case i relative to x0 as w*_i = prox_i(x0) / sum_{i=1}^N prox_i(x0).
+   
+   c) Predict x0 with a new RF grown to d_trn using case weights {w*_i}^N_{i=1}.
