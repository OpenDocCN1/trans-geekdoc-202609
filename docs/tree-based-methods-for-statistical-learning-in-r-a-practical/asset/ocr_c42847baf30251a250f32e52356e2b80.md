Let \( X_c \) be the subset of numeric/continuous features from the full feature set \( X \). In a random rotation forest, before fitting the \( b \)-th tree, the numeric features are randomly transformed using \( X_{c,b} = X_c R_b \) (for \( b = 1, 2, \dots, B \)), where \( R_b \) is a randomly generated rotation matrix of dimension equal to the number of columns of \( X_c \).
