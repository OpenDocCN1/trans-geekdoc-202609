# 1.3.1 No really, why R?

I grew up on R (and SAS), but I've chosen it for this book primarily for one reason: it currently provides the best support and access to a wide range of tree-based methods (both classic and modern-day)n. For example, I'm not aware of any non-R open source implementation of tree-based methods that provides full support for nominal categorical variables without requiring them to be encoded numericallyo. Another good example is conditional inference trees [Hothorn et al., 2006c], the topic of Chapter 3, which are only implemented in R (as far as I'm aware). Nonetheless, there is at least one Python example included in this book!

nThis book was also written in R (and LaTeX) using the wonderful knitr package Xie [2021].
