## R 中统计学习的基于树的方法

本书对大多数思想和数学概念都配有 R 统计语言中的基于代码的示例；重点是尽可能少地使用外部包。例如，用户将接触到使用简单的 for 循环和基本树拟合软件（如 **rpart** 和 **party/partykit**）编写自己的随机森林和梯度树提升函数，等等。核心章节还以关于 R 及其他开源替代方案（例如，Python、Spark 和 Julia）的相关软件的详细部分以及真实数据集上的示例用法结束。虽然本书大多使用 R，但其初衷是对非 R 程序员同样易于访问和有用。

本书的读者将获得对基于树的方法及其如何用于解决数据科学家在应用工作中经常面临的实际问题和挑战的扎实基础（和欣赏）。

特色：

- 从基础开始全面覆盖基于树的方法（例如，CART、条件推断树、袋装法、提升法和随机森林）。
- 一个配套网站，包含额外的补充材料以及复现书中每个示例和图表的代码。
- 一个名为 **treemisc** 的配套 R 包，其中包含书中使用的多个数据集和函数（例如，包含使用 LAD 损失的梯度树提升实现，展示如何通过更新拟合 **rpart** 树的终端节点估计值来逐步执行线搜索步骤）。
- 具有实用价值的有趣示例；例如，如何从 Spark MLlib 中的拟合模型构建部分依赖图（仅使用 Spark 操作），或通过 LASSO 对树集成进行后处理，以减少树的数量，同时保持甚至提高性能。

## 查普曼与霍尔/CRC 数据科学系列

反映该领域的跨学科性质，该图书系列汇集了来自统计学、计算机科学、机器学习和分析领域的研究人员、从业者和教师。该系列将出版数据科学领域的前沿研究、行业应用和教科书。

强烈鼓励包含具体示例、应用和方法。该系列的范围包括机器学习、模式识别、预测分析、商业分析、大数据、可视化、编程、软件、学习分析、数据整理、交互式图形和可重复研究等领域的书名。
