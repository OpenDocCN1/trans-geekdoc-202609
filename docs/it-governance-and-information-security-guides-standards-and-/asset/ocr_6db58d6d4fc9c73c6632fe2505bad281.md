# # 7.3.5 Developing Improvement Action Plans

The output from the framework's assessment supports understanding the actions to drive improvement and enables the organization to transition from its current to target maturity systematically. This is achieved by implementing a series of industry-validated practices that allow organizations to improve incrementally and monitor track progress over time using a number of industry-validated metrics. Table 7.4 includes sample practices and metrics for the five SPOs highlighted for prioritized improvement in . For each of these SPOs, the figure outlines the currently reported maturity and the practices required to transition to the next maturity state. Note that additional practices are available to support transitioning to the desired maturity state.
