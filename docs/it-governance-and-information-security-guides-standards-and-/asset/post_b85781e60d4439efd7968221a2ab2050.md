## 5. Cloud Computing as a Key Pillar for Agile

### 5.1 INTRODUCTION

In the world of development, cloud computing is increasingly common. This allows for the iterative development cycle. Cloud computing provides tools for the development, which is an agile process.

Cloud computing reflects the convergence of IT performance and market agility. This results from scalable hardware and software resources (Zhang et al., 2020).

Although there are still unanswered questions about cloud computing, the organizations cannot risk stability, efficiency, and flexibility (Yang et al., 2013).

Based on these studies, our chapter seeks to theorize and empirically validate the model through the following research questions:

- What are the reasons behind the use of cloud computing?
- How will cloud computing increase agility?

### 5.2 LITERATURE REVIEW

This literature review synthesizes current studies from an operational perspective. We organized the deductions according to the following aspects:

- Properties of cloud computing
- Features of implementation
- Governance mechanisms
- The effect on agility

While this is not fully modern, there is no standardized or traditional description of cloud computing. The ‘cloud’ term refers to the universal development and connectivity of computing services. Through cloud applications, businesses and customers can conveniently access large amounts of computing performance at a marginal cost.

We noticed that research encouraging or discouraging cloud technology is a recent and relatively new topic (Adamson et al., 2017). Cloud computing brings competitive and financial benefits that companies should certainly not ignore (Chemjor & Lagat, 2017).
