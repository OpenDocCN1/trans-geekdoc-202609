# 7.3.1 Data Collection

The questionnaire was carried out in several stages. A first version has been developed to take into account the different theoretical assumptions. This first version has been tested with IT service managers and consultants. This pre-test rephrasing questions to improve the questionnaire's comprehension and improve the quality of the given answers. In the end, the questionnaire consists of 100 questions divided into different objectives and controls.
