A process is a set of activities, from one or more inputs, produces one or more outcomes representing value to an internal or external client (Hammer et al., 1993). Referring to Hammer's definition of processes, the IS development process is a set of activities coordinated and executed by a system engineer to produce the governance of IS. The result is a decision support and assistance system (DIS) whose use and utility must be measured.

Two approaches are distinguished in building decision support systems. (i) Collaborative approach in which the engineer progressively defines the steps of the 'fly'. (ii) The development of the system can follow a set of activities known in advance. For each system creation or maintenance process, the engineer will follow predefined steps.
