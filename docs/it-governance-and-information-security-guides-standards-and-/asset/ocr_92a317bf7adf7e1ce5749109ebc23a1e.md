# 7.1 INTRODUCTION

Many organizations today face a global governance revolution that could directly impact their information management practices. Information security has become an integral part of daily life, and organizations must ensure that their information security systems are an integral part of everyday life.

In a distributed and dynamic services environment, security must not be limited to providing a strategy taking into account business, organizational, and technical dimensions (Nassar et al., 2009). Besides, security must be seen as an ongoing process that aims to optimize security investments and ensure the sustainability of the security measures implemented (Lomas, 2010). However, reference service domain models and architectures have underestimated the definition of security needs, the assets to be protected, and the identification of these assets (Huang et al., 2006; Williams, 2007). We propose approaching the problem of security by a practical approach of governance, allowing us to identify the various aspects of IT security and propose adequate security measures to the context. However, IT security governance is a real challenge in an open collaborative service environment (Maleh et al., 2018). Improving security has emerged as one of the IT priorities across all business lines.
