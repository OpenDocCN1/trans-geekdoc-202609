# 8.1 INTRODUCTION

Information systems (IS) is an integral part of the functioning of public administrations and bodies, the activity of businesses, and the way of life of citizens. The security of these information systems has become a significant issue for all public or private sectors, which would be very seriously affected in the event of serious malfunctions (Paliszkiewicz, 2019).

Information security policy is the general term to describe any document that transmits an element of the security program to ensure compliance with organization's security goals and objectives. Since this definition covers a wide range of security policies, it is helpful to describe the various types of information security policies that an organization may use. The terms used later to describe these types of information security policies are generally used in the security industry and will be used consistently throughout this chapter (Ifinedo, 2014). However, its not unusual for a government organization or agency to have different names for the use of information security policies. For example, in many organizations and certainly in government departments, the word ‘policy’ is closely associated with laws and regulations (Rees et al., 2003). In these cases, a limited number of individuals (e.g., the legislature) have the power to create a policy, so that an information security policy is generally referred to by other names such as ‘information security statement’, or ‘information security document’ or other terms avoiding the use of the word ‘policy’.
