We note here the choice of coding (0,1), which is traditionally retained for dichotomous models. Indeed, it allows defining the probability of occurrence of the event as the expectation of the variable $yi$; since dichotomous models admit for variable explained that the probability of occurrence of this event is conditional on the exogenous variables. The model takes the following form:

```
$pi=Prob(yi=1|xi)=F'(xi\beta)$
```

where the function $F()$ denotes a distribution function, $xi$ denotes the explanatory variables, and $eta$ is the vector of the parameters to be estimated.
If $yi^*$ is a latent (unobservable) variable that depends on the explanatory variables $xi$, the vector of the parameters to be determined (noted $eta$) and the error term (noted $\varepsilon$), then the probabilistic decision rule is:

```
$Prob(yi=1)=Prob(yi^*>0)=1-F(-eta\xi)=F(\beta\xi)$
```

```
$Prob(yi=0)=Prob(yi^*\le0)=F(-eta\xi)=1-F(\beta\xi)$
```

where $eta$ is the vector of estimated coefficients and $F()$ is the distribution function.
The distribution function $F()$ can be of two types: either a logistic law (Logit model) or a regular centered reduced likelihood (Probit model). The results obtained from the Logit and Probit models are relatively similar (Kahn & Morrinnon, 1979; Davidson & MacKinnon, 1984). For our estimates, we will retain a Logit model when the estimation of the model's parameters is carried out by the method of maximum likelihood.
