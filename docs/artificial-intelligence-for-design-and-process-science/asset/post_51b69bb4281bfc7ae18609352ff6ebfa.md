## 3 Methodology

### 3.1 Data Collection

A specialized dataset was crafted, aimed at enhancing question-answering models focused on computer science education and career-related inquiries. The dataset compilation process involved gathering questions and answers through two primary methods as shown in Fig. 1. Firstly, surveys were conducted among university students, resulting in the collection of 8500 questions. Additionally, through an AI model, OpenAI's ChatGPT, 10,000 questions and answers were generated. Subsequently, a meticulous filtering process was employed to eliminate irrelevant or redundant questions, resulting in a refined repository of pertinent questions.

Following the filtration phase, a comprehensive curation process ensured, where 2163 questions and answers were carefully selected based on relevance to computer science education and career exploration. This curated subset was formed into structured JSON format to facilitate seamless integration into the model training pipeline. The resulting dataset comprising high-quality and domain-specific questions and answers is embedded into the model to train it.

To facilitate model training, a sentence embedding model is utilizing the conversion of textual input into vectorized representations. The PyTorch backend neural network consists of an input layer matching the sentence embedding's vector size, a hidden layer, and an output layer representing the unique tags assigned to each question. The model is trained using the Adam optimizer with a cross-entropy loss function.

### 3.2 Integration of Transformative Encoding and Neural Network

The chatbot collects input from users and utilizes the sentence transformer, specifically the "all-MiniLM-L6-v2" model to encode the input sentences into a 384-dimensional vector. This model undergoes several key steps to process the input and generate meaningful representations:

- (a) Word embedding: The first step involves converting input words into numerical vectors. This process is known as word embedding and helps the model represent words in a format suitable for mathematical operations.
- (b) Positional encoding: To capture the sequential relationships in a sentence, positional encoding is introduced. Since traditional embeddings don't convey word order information, positional encoding adds positional information to the word vectors. This ensures that the model understands the sequential structure of the input.

Example of 384-dimensional vector

| How | Are | You |
|---|---|---|
| Word embedding | [0.2, 0.3, 0.5, ... ] | [0.1, 0.4, 0.6, ... ] | [0.3, 0.2, 0.7, ...] |
| Positional encoding | [0.2, 0.3, 0.5, ...] + [0.1, 0.2, -0.3, ...] = [0.3, 0.5, 0.2, ...] ] | [0.1, 0.4, 0.6, ...] + [-0.1, 0.3, 0.2, ...] = [0.5, 0.7, 0.8, ...] | [0.3, 0.2, 0.7, ...] + [-0.2, -0.1, 0.4, ...] = [0.5, 0.1, 1.1, ...] |
| Self-attention | [0.3, 0.5, 0.2, ...] | [0.2, 0.8, 0.1, ...] | [0.5, 0.2, 0.3, ...] |
| FFNN | [0.4, -0.1, 0.6, ...] | [-0.6, 0.2, 0.4, ...] | [-0.3, 0.7, 1.1, ...] |
| Add and norm | [0.3, 0.5, 0.2, ...] + [0.4, -0.1, 0.6, ...] = [0.7, 0.4, 0.8, ...] | [0.0, 0.7, 0.8, ...] + [0.2, 0.8, 0.1, ...] = [-0.6, -0.2, 0.4, ...] = [0.8, 1.3, 1.3, ...] | [0.5, 0.2, 0.3, ...] + [-0.3, 0.7, 0.1, ...] = [0.7, 1.0, 1.5, ...] |

- (c) Self-attention: Self-attention is a mechanism where how much attention in the input sentence decides how much attention to give to other words. This attention mechanism allows the model to focus on different parts of the input when encoding, enabling it to capture dependencies and relationships between words effectively.

- (d) Feedforward neural network: Following self-attention, the output is processed through a feedforward neural network. This network consists of six linear layers, each followed by a Rectified Linear Unit (ReLU) activation function. The purpose of the feedforward network is to capture complex relationships within the data by transforming the representations learned from self-attention.

- (e) Add and norm: After passing through the feedforward network, the output is combined with the original information using an "add" operation. Residual connection helps in mitigating vanishing gradient problems during training. The combined output is then normalized to ensure that the information is in a suitable state. This step, known as normalization, stabilizes the output.

The sentence transformer utilizes the processed information to encode the input sentences into a 384-dimensional vector. This vector serves as a meaningful representation for example, let's consider the sentence "How are you?". The process can be elaborated by the aforementioned five steps and is shown in Table 1 and depicted in the Fig. 2.

The 384-dimensional vector output from the sentence transformer is fed into a simple feedforward neural network. This network processes the vector through multiple layers, and it generates a vector representing the predicted output at the final layer (output layer). The predicted output is then passed through a SoftMax activation function which converts the raw output into a probability distribution assigning probabilities to different classes. This is crucial for identifying the most likely class or response. The class with the highest probability in the distribution is identified as the predicted class. This class corresponds to a specific response in the dataset. Finally, the response associated with the identified class is retrieved from the dataset. This response is generated as the output in the user interface providing a seamless and contextually appropriate interaction experience for users interacting with the chatbot system.
