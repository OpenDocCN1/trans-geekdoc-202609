# ## 3 Methodology

# ### 3.1 Data Collection

A specialized dataset was crafted, aimed at enhancing question-answering models focused on computer science education and career-related inquiries. The dataset compilation process involved gathering questions and answers through two primary methods as shown in Fig. 1. Firstly, surveys were conducted among university students, resulting in the collection of 8500 questions. Additionally, through an AI model, OpenAI's ChatGPT, 10,000 questions and answers were generated. Subsequently, a meticulous filtering process was employed to eliminate irrelevant or redundant questions, resulting in a refined repository of pertinent questions.

Following the filtration phase, a comprehensive curation process ensured, where 2163 questions and answers were carefully selected based on relevance to computer science education and career exploration. This curated subset was formed into structured JSON format to facilitate seamless integration into the model training pipeline. The resulting dataset comprising high-quality and domain-specific questions and answers is embedded into the model to train it.

To facilitate model training, a sentence embedding model is utilizing the conversion of textual input into vectorized representations. The PyTorchback neural network consists of an input layer matching the sentence embedding's vector size, a hidden layer, and an output layer representing the unique tags assigned to each question. The model is trained using the Adam optimizer with a cross-entropy loss function.
