A Fourier series representation of this error content graph can be expressed as [3]:

```
$u_{n,a}(p,t) = \sum_{l=-p}^{p} e^{l(a+nl)t}
```

where $a$ is the jump speed and jump speed $p$ determines the number of vertices. In other words, $n$ determines the number of vertices of the polygon, $l$ determines the interval $I$ $[-p, p]$ in which the Fourier series will be calculated, and $p$ is the resolution parameter.

Following [4], $\chi_{n,a}(\text{id}[p], t)$ denotes an irregular-shaped error content graph that has $n$ vertices, where the jump speed $a$ is not a constant, but is a vector that has $n$ elements. Moreover, $[p]$ does not have to be constant for each side of the irregular-shaped error content graph. The resolution parameter $p$ is used to represent some parameter in the system being modeled. For example, let $a=[d, c, e, \dots, a, d]$ where each distinct element of $a$ corresponds to a different jump speed.

The length of jump vector $a$ is $n$, the number of vertices, revealing the fact that the irregular-shaped error content graph $\chi_{n,a}(\text{id}[p], t)$ is composed of pieces out of the regular-shaped error content graphs. Since the error content graphs can be represented as Fourier series, then a communication channel can be represented with a Fourier series [5]:

```
$U(n,p,q) = \sum_{i=-p}^{p} \sum_{l=0}^{2\pi} e^{l(q+nl)t}
```

# Electron Orbitals as Communication Channels

We can build communication channel representation and atoms. To accommodate quantum numbers (Table 1), we introduced minor modifications to our notation. We can start by considering periodic functions. A periodic function $f(t)$ with $w_0=1$ can be represented by complex exponential form of the Fourier series where:

```
$f(t) = \sum_{k=-\infty}^{\infty} c_k e^{ikt}
```

with $|c_k e^{ikt}| = |c_k|$. The Fourier series of a uniform polygon is given as:

```
$f_n(t) = \sum_{k=-p}^p \frac{e^{ikt}}{k^2}
```

where $k = q+n\ell$ and the following-up parameters are defined to represent the polygon with the Fourier series:
- $q \in Z^*$ corresponds to the jump value of uniform polygon;
- $n \in Z^*$ corresponds to the number of vertices of uniform polygon;
- $\ell \in Z^*$ determines the interval $[-p, p]$, in which the Fourier series will be calculated;
- $N \in Z^*$ is the sampling factor for $t \in [t_0, 2\pi]$.

Including all of parameters, the new equation is:

```
$u(\ell, t) = \frac{e^{i(q+n\ell)t}}{(q+n\ell)^2}
```

where $t_r = t_0, t_1, \dots, t_{N-1} = (2\pi + t_0)$ and $\ell = -p, \dots -p+1, \dots, 0, \dots, p-1, p$. Since the resulting Fourier series calculation is the sum of each term at time $t_0$, we can rewrite the equation for $u(\ell, t)$ as:

```
$u(\ell, t) = \sum_{\ell=-p}^p \frac{e^{i(q+n\ell)t}}{(q+n\ell)^2}
```

By observing the quantum numbers in Table 1 and the parameters of our equation, we produced our new equation (Eq. 8). After replacing $n, p,$ and $\ell$ parameters in (Eq. 8) with principal quantum number $n$, azimuthal quantum number $\ell$, and magnetic quantum number $m_l$, respectively, our Fourier series becomes:

```
$u'_l(t) = \sum_{m_l=-\ell}^{\ell} \frac{e^{i(q+lm_l)t}}{(q/n+lm_l)^2}
```

An obvious interpretation of this equation would suggest that it represents a subshell depending on the value of $\ell$. Note that each matrix component corresponds to a $m_{\ell}$ value. If we continue with our interpretation, each of these components would represent an electron orbital. We then name these components as $u_{m_{\ell}}(t)$:

```
$u_{m_{\ell}}(t) := \frac{e^{\ell(q+Im_{\ell})t}}{(q/n + Im_{\ell})^2}
```

By extending the analogy, we can represent the $n$th summation over $\ell$, from $0$ to $n-1$. Then, this U-matrix could be shown:

```
$u'_{n}(t) = \sum_{\ell=0}^{n-1} \sum_{m_{\ell}}=-\ell}^{\ell} \frac{e^{\ell(q+Im_{\ell})t}}{(q/n + Im_{\ell})^2}
```

In order to incorporate the effect of nuclei on electrons, Eq. (8) is further modified by introducing atomic number (A) (number of protons in the nuclei) and **q = 1 for nonradioactive isotopes**, and as a period number:

```
$u'_{\ell}(t) = \sum_{m_{\ell}}=-\ell}^{\ell} \frac{2 \cdot n \cdot n \cdot y \cdot e^{\ell(A+Im_{\ell})t}}{(A + Im_{\ell})^2}
```

y is the row of the periodic table, A is the atomic number, and $n$ is the principal quantum number.
