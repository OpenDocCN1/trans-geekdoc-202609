A Fourier series representation of this error content graph can be expressed as [3]:

```
$u_{n,a}(p,t) = \sum_{l=-p}^{p} e^{l(a+nl)t}$$
```

where $a$ is the jump speed and jump speed $p$ determines the number of vertices. In other words, $n$ determines number of vertices of the polygon, $l$ determines the interval $I$ $[-p, p]$ in which the Fourier series will be calculated, and $p$ is the resolution parameter.
Following [4], $\chi_{n,a}(\text{id}[p], t)$ denote an irregular-shaped error content graph that has $n$ vertices, where the jump speed $a$ is not a constant, but is a vector that has $n$ elements. Moreover, $[p]$ does not have to be constant for each side of the irregular-shaped error content graph. The resolution parameter $p$ is used to represent some parameter in the system being modeled. For example, let $a=[d, c, e, \dots, a, d]$ where each distinct element of $a$ corresponds to a different jump speed.
The length of jump vector $a$ is $n$, the number of vertices, revealing the fact that the irregular-shaped error content graph $\chi_{n,a}(\text{id}[p], t)$ is composed of pieces out of the regular-shaped error content graphs. Since the error content graphs can be represented as Fourier series, then a communication channel can be represented with a Fourier series [5]:

```
$U(n,p,q) = \sum_{i=-p}^{p} \sum_{l=0}^{2\pi} e^{l(q+nl)t}$$
```
