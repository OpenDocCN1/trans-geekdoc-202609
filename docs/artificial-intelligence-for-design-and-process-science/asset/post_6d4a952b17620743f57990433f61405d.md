
## 3.1 Embedding Space

Network architecture optimization needs to represent the space of applicable networks, and if using RL, an action space of network modifications. To efficiently represent the set of networks for a deep learning system, like Luo [18], we map a network description language into an embedding space using an encoder-decoder component. This lower-dimensional latent embedding also defines a continuous action space as displacement vectors in the embedding space. The embedding vector, augmented with a feature vector encoding the problem for which the network architecture is to be optimized, provides the states for the RL problem, while displacements in the embedding space provide the RL learner's action space.

One problem with such a derived embedding space is that it can fracture the space of legal network embeddings into disconnected regions.

While this does not affect local optimization using gradient ascent as in [18], it makes RL policies for optimization more difficult as they need to cross regions of the embedding space that do not validate network architectures. To address this and condense the space of legal networks, a Siamese neural network (SNN) [b31] is used here in the encoder structure to organize the embedding space into coherent legal network regions.

## 3.2 Reinforcement Learning

RL [25] is used here as it allows to learn from quantitative feedback and thus addresses the problem in network architecture optimization that optimal network embedding configurations for the target problems generally are not known. Utilizing the network embedding space, RL operates here by executing actions in embedding space to modify the network architecture and observing resulting reward in the form of changes in actual or predicted network performance. Based on this, a value function is estimated, and a policy learns optimizes the rewards. Figure 1 shows this basic operation of the RL learning agent.

- 1. Value function: The Q-Value estimates performance as the expected utility of the learning agent in state when performing action a and thereafter following policy ($\pi$). This value function not only considers immediate reward feedback, $r(s,a)$ but takes into account future payoffs.

$$Q_x(s,a) = \sum_{s'} P_{ss'}^a r(s,a) + \gamma \sum_{a'} \pi(a'|s')Q_x(s',a')$$

The Bellman equation \cite{b14} provides the basis for performance estimation and policy learning.

The state is provided by concatenating the embedding vector (representing the current network architecture) and a problem specific feature vector (capturing problem complexity related information), while possible actions are continuous displacement vectors in the embedding space. - 2. **Policy learning:** As we use a continuous embedding space augmented with a continuous action space in the form of embedding space displacement vectors, the approach presented here utilizes an actor-critic RL approach [26, 27] to perform policy and value function learning.

## 3.3 Actor-Critic Methods and Policy Gradient

In the used actor-critic approach, the Q value is learned by the “critic network,” which estimates the value function in form of the state-value Eq. (2) and the action-value Eq. (3).

The “actor network” updates the policy distribution in the direction suggested by the “critic network” using policy gradients. For this, both critic and actor functions are parameterized with neural networks over the augmented embedding space.

$$V_{\pi}(s) = \sum_{a} \pi(a|s) \sum_{s'} P^{sa}(r(s,a) + \gamma V_{\pi}(s'))$$

$$Q_{\pi}(s,a) = \sum_{s'} P^{sa}(r(s,a) + \gamma \sum_{a'} \pi(a'|s') Q_{\pi}(s',a'))$$

Policy gradients [28] are used to optimize the actor's probability distribution of embedding space displacement amounts. The goal is to learn a policy ($\pi$) that maximizes the cumulative future reward from current time t to terminal time T. If $r(t+1)$ is the reward for performing action $a(t)$ at state $s(t)$,

$$r(t+1) = R(s(t), a(t))$$

- 1. Reward and performance prediction: To learn the incremental improvement achieved when modifying the network. A target domain of supervised classification, a direct way to capture reward is in terms of the expected accuracy of the target network after modification. To reduce the need for re-training target networks and to allow planning, the architecture includes a performance prediction [20] component that predicts network performance using previously trained problems. To limit task-specific training, the input to this network again contains, besides the network embedding, problem specific features to facilitate generalization across tasks.

## 3.4 Twin-Delayed Deep Deterministic Policy Gradient (TD3)

The twin-delayed deterministic policy gradient (TD3, [5]) algorithm is a model-free, off-policy algorithm. It is an extension of DDPG (Deep Deterministic Policy Gradient) that uses two Q-critics to address overestimation bias, delayed policy updates to reduce variance, and target policy smoothing to prevent overfitting.

## 4. Approach and Implementation

The “encoder” model transforms the network description into an embedding space, with the problem description, serves as input to the “accuracy” prediction, “actor,” and “critic” networks. The “decoder” model is used to translate the embedding back to a network architecture for the target task. To improve the organization of the embedding space, this autoencoder is augmented with lost terms from the “accuracy prediction” network and arranged in a Siamese network to co-locate embeddings that decode into legal network descriptions.
