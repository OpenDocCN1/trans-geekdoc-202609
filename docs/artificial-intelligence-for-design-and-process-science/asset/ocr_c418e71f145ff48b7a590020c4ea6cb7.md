A sequence of architectures defines an architecture of a neural network, whose performance is used as the reward. Many of these techniques use a small, pre-defined set of architecture modifications [15, 17], which limits their applicability to specific architecture types. One approach to attempt to address this is the use of an architecture embedding space to permit a general, continuous action space [18, 19]. However, target performance over this embedding space tends to be highly non-convex and leads to many local extrema, limiting the optimization in this approach to several problems, requiring retraining for each target problem and extensive evaluation training for each individual architecture optimization.

Generalization over target problems has been the focus of Bose [15], where a generic policy for network optimization is learned. This approach, however, is limited by its simple action space with ensembles of fully connected networks and cannot be applied to the wider range of problems.

In this chapter, an approach is proposed that combines the concepts of a network embedding space with the learning of a transferable policy to allow for more general architecture search and to limit the need for extensive retraining for new problem. To address the challenges of complex dynamics of network performance under architecture transformations in an embedding space, the approach condenses and organizes network embeddings using Siamese networks and utilizes a reinforcement learning framework for complex policy formation that permits the system to more reliably achieve high-performing final architectures in the presence of significant local extrema for task performance. Taking inspiration from previous work using network embeddings [15, 18, 19, 22] and various approaches to network architecture search [14, 17, 23, 24], we propose an architecture that provides the promise to extend to various network types as well as to transfer optimization strategies across problems.

# 3 Background

We are presenting an approach that uses reinforcement learning on a network embedding space to learn a policy that can yield optimized network architecture. The embedding space here converts the space of network architectures into a lower-dimensional continuous space and defines a continuous action space for the RL agent. To permit generalization across target problems and to facilitate planning, the system also utilizes a feature vector encoding target problem complexity and a derived performance prediction [20] component.
