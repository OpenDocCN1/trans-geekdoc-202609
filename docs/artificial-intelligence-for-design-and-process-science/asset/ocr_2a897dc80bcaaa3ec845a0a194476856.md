Blueprint assemblies use a “compose” operator to connect a set of compatible blueprints to end to (e.g., product-to-product or service-to-service combinations). In particular:

retrieve(A) returns all blueprints that satisfy the criteria/conditions in predicate A two instances of the same type and returns a new blueprint instance pq. compare(p, q) compares two blueprint instances p, q of the same type and returns T if the two are equivalent and F, otherwise. Two blueprints are equivalent if their components, parts, characteristics, and materials are identical. diff(p,q) returns the difference between two blueprints of the same type p, q.
