$r_n = n^2 a_0$

$E = -\frac{13.6Z^2}{n^2}$

$a_0 = 0.0529\text{ nm}$ is Bohr's radius and $Z$ is the number of protons in an atom (in this case 1).

Bohr's model is only successful in describing hydrogen-like atoms but fails in all other elements. It also fails to describe many quantum mechanics features of atoms and electrons. The current quantum mechanics description of atomic orbital generally operates the Schrödinger equation using wave functions. The Schrödinger equation (Eq. (14)) is an eigenvalue equation. For example, the Hamiltonian operator ($H$) operates on a function $(\Psi$, a wave function) and the result equals to a real number ($E$, energy) times the same function. The scalar number is called the eigenvalue; the function is an eigenfunction of that. For hydrogen atom, the atomic orbital can be described by spherical polar coordinates in the form of a radial function $R_{nl}$ with a radial variable $r$ and a spherical harmonic function $Y_{l,m}$, with angular variables $\theta$ and $\phi$ [10]:

$H\Psi = E\Psi$

$\varphi_{n,l,m} = R_{nl}Y_{l,m}$

The wave functions of all hydrogen orbitals ($Z = 1$) can be found here: The expectation value of the orbit radius $<r\rangle$ is used to describe the average of radial probability, which resembles the probabilistic expected value of the result (measurement) from an experiment as:

$<r\rangle = \int \varphi_{n,l,m}^* \ r \varphi_{n,l,m} \ dV$

$dV$ is the spherical polar coordinate that contains the following:

$dV = r^2 \sin\theta dr\theta d\phi$

For example, for 1s orbital, the solution $<r\rangle = \frac{3a_0}{Z}$. This also explains why heavier atom has smaller core orbital (1 s) when $Z$ increases, the $<r\rangle$ of 1s orbital becomes more compact.
