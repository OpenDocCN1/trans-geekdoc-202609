## 4.2 Accuracy Model

As accuracy prediction is problem specific, the accuracy model’s input is comprised of the concatenation of the embedding and a “problem description” feature vector. Using this, it predicts a performance measure for the network for the target problem as well as whether the embedding space corresponds to a legal architecture. It serves to help organize the embedding space and to generate simulated rewards in order to minimize the amount of network training. The example layered architecture used in the experiments later is shown in Fig. 7.

During the first training phase, encoder-decoder and accuracy models are trained together using a loss function that includes reconstruction loss as MSE, embedding consistency loss from the Siamese network, as well as accuracy prediction and legal network identification losses.

## 4.3 TD3-Based Actor-Critic

For RL, a TD3 based learner is used, as indicated in Fig. 3, utilizes delayed actor updates, and advantage values, two critic networks with a common target, and action noise regularization.

- 1. Actor Model: The augmented embedding state also feeds to the “actor” model to learn the policy. Shown as the rightmost output in Fig. 4, the “actor network” provides the policy to optimize a target network. It computes the policy $(\pi)$ used to select the next step (action “a”) in the embedding space to obtain the embedding of the new, modified network.
- 2. Critic Model: The “critic” model evaluates actions by the actor in the context of the augmented embedding state and learns the utility to output state values, $V(s)$, and advantage $A(s,a)=Q(s,a)-V(s)$. Internally, this critic maintains two value function estimates for both utility functions and a common target network that achieves an action update and function smoothing. The actor critic component, the reward function is derived as the actual (for online learning) or predicted (for planning) improvement of the performance prediction of the “accuracy” model, leading to policy trajectories as shown in Fig. 8.

To train the actor and critic components, the system generates new embedding space trajectories, which serve as training data together with the reward extracted from the network’s performance predictions. As the policy changes over time, it is essential that old trajectories are discounted and ones generated continuously.

## 5 Training and Results

The NOA architecture in [18], the initial training here was focused on small, fully connected networks, along with some performance data (network accuracy) and network status (legal/illegal) to help construct a simpler modification space. To perform initial proof-of-concept experiments, this resulted in defining the network space as fully connected networks with up to two hidden layers and at 24 units per hidden layer and a target problem space of 12 classification problems from the UCI dataset [31]. This permits the network specification to be supplied in terms of layers and unit numbers per provides an easy means of generating initial training data by training 300 random networks [32], on each of the 12 target problems. Since the network architecture input formulation allows illegal inputs, an additional 30 illegal network descriptions were generated and assigned accuracy values of 0 to allow the system to learn the demarcations of the embedding space. To evaluate the ability of the network to generalize, the set of classification problems was divided into a training set consisting of nine and a test set with the remaining three problems, and only data from training problems was used during all stages of the training process.

To characterize the complexity of target problems, a problem description vector with 13 attributes was designed. Apart from “No of Classes,” “Data Size,” “Attribute Type,” it includes Entropy of dataset labels, average Entropy of dataset features, as well as the accuracy for three baseline architectures. The resulting feature vectors for the used problems are shown in Fig. 9.
