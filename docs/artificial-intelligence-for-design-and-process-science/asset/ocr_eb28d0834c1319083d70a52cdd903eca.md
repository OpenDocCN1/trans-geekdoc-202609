# 5.1 Siamese Network Encoder-Decoder-Accuracy Training

+   1. Encoder-decoder design: Encoder and decoder models are designed with four dense layers as shown in Fig. 10. The use of a tanh activation function at the encoder output yields a size-limited embedding space, which is easier to organize as an unlimited space.
The encoder and decoder models are trained together with the accuracy and legal prediction model to better organize the embedding space. To achieve, the encoder-decoder-accuracy architecture is organized in a Siamese network that attempts to co-locate legal networks and separate legal and illegal embeddings.
2. Accuracy/legal model design: The chosen architecture for the accuracy model was nine dense layers and two output layers sigmoid activation function to output accuracy and status (legal/illegal) of the network.
Since the accuracy predictions depend on the target problem, this model uses the augmented embedding, which combines the network embedding with the target problem feature vector. As the number of target problems in the training set is relatively small here, it is important to address overfitting. For this, the problem feature vector was transformed into a compressed, lossy embedding using Gaussian Noise, a dense layer of size 6, and a dropout layer with 20% dropout, to obtain noisy problem feature vectors of size 6 during training.
