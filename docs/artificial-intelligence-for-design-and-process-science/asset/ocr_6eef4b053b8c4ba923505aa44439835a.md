# 3.2 Integration of Transformative Encoding and Neural Network

The chatbot collects input from users and utilizes the sentence transformer, specifically the "all-MiniLM-L6-v2" model to encode the input sentences into a 384-dimensional vector. This model undergoes several key steps to process the input and generate meaningful representations:

+   (a) Word embedding: The first step involves converting input words into numerical vectors. This process is known as word embedding and helps the model represent words in a format suitable for mathematical operations.
(b) Positional encoding: To capture the sequential relationships in a sentence, positional encoding is introduced. Since traditional embeddings don't convey word order information, positional encoding adds positional information to the word vectors. This ensures that the model understands the sequential structure of the input.
