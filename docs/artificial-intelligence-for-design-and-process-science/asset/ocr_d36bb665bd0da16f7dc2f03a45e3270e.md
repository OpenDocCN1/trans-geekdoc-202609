Python 3.11.2 was used with Microsoft's Visual Studio Code as the programming language and in code IDE, respectively. The key libraries employed include:

+   - PyTorch 2.1.0 for building, training neural network models, loading, and making predictions
- TQDM 4.65.0 to display progress during the creation of vectorized training data
- scikit-learn's Joblib 1.2.0 for saving and loading vectorized data

The CSACbot employs a two-step process integrating sentence embedding and a neural network architecture. The transformer library using the "all-MiniLM-L6-v2" pre-trained models capture semantic information by encoding sentences into high-dimensional vectors of size 384. The NeuralNet architecture consists of six fully connected layers with ReLU activation to process embedded features and predict responses. The SoftMax function is applied to the output layer for probability distributions over potential responses.

A curated dataset covering diverse computer science queries and corresponding responses was utilized for training and evaluation. The model parameters were optimized using the cross-entropy loss function and the Adam optimizer. Training involved 100 epochs with a batch size of 8. Evaluation was conducted on a separate test set to assess generalization capabilities. The training process involved two steps: sentence embedding using the sentence embedding class and neural network training using the NeuralNet class. The dataset was vectorized and backpropagation was employed to optimize parameters with the Adam optimizer and cross-entropy loss.

The chatbot was implemented in the "Chat.py" script facilitating real-time interaction. Users provide input queries for the model to generate predicted responses based on confidence thresholds as shown in Fig. 3. CSACbot is initiated by user questions related to computer science education and careers. The bot will respond with the answers with relevant information.
