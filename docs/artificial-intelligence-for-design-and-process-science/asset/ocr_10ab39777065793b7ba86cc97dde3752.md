# 4 Approach and Implementation

To address automatic network optimization, the approach in this chapter utilizes reinforcement learning on top of a network embedding space. The embedding space is learned using an encoder-decoder network and provides a compact representation of all network architectures for the problem task as fixed-dimensional, continuous network modification action space. To further organize the embedding space, it adds a Siamese network [30] to co-locate embeddings of valid network architectures and adds a loss term representing the precision of target problem accuracy prediction. To allow generalization across both the reinforcement learning components and the accuracy prediction vector that abstracts the complexity of the target problem is utilized.

For learning the network architecture modification policy, TD3 actor-critic networks are used. To further reduce the need for target network retraining and facilitate learning, the RL approach uses the上面的 accuracy prediction network to generate reward predictions. The accuracy prediction network uses the network embedding as well as the target problem feature vector to predict the achievable classification accuracy for the problem task as well whether the embedding corresponds to a legal decoded network.

The architecture diagram in Fig. 4 takes the “network architecture description” and the “problem description” as input. The former represents the network characteristics, such as number of layers and nodes, and the latter represents features reflecting the complexity of the target problem, such as dimensionality, data size, feature correlations, or accuracy achieved by baseline architectures.
