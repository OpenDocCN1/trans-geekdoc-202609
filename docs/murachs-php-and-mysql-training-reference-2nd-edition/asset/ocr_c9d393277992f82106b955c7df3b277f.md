# The URL for downloading the Chrome browser

www.google.com/chrome/

# How to install Chrome on Fedora

+   1. Go to the website address above
+   2. Click on the Download Chrome button
+   3. Select one of the versions for Fedora, depending on whether you have a 32-bit or 64-bit version of Fedora. Review the terms of service and click the Accept and Install button.
+   4. Respond to the resulting dialog boxes.
+   5. A progress dialog should open as Chrome installs. This dialog should close automatically when the installation is finished. This is the only way you know the installation has completed.
+   6. The first time you start Chrome, it asks you if you want to make it your default browser. We recommend that you do for doing the exercises in this book.
