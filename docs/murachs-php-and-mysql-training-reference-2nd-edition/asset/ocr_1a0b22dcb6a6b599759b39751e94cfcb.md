# How to enable or disable cookies in Chrome 37

+   1. Open the Tools menu and select the Settings command.
+   2. Scroll down and click on the “Show advanced settings...” link.
+   3. In the Privacy section, click on the Content Settings button.
+   4. Select the “Allow local data to be set” option to enable cookies, or the “Block sites from setting any data” to disable cookies. Then, click the Done button.

# How to enable or disable cookies in Internet Explorer 11

+   1. Open the Tools menu and select the Internet Options command.
+   2. Click the Privacy tab.
+   3. Use the slider control to enable or disable cookies, or click on the Advanced button, check the “Override automatic cookie handling” checkbox, configure cookies, and click the OK button.
+   4. To undo changes made with the slider control or in the Advanced section, click the Default button to return to default privacy settings.

# How to reset default security settings in Internet Explorer 11

+   1. Open the Tools menu and select the Internet Options command.
+   2. Click the Security tab.
+   3. If not disabled, click the “Reset all zones to default level” button.

# Description

+   • To test how your application behaves if a user has cookies disabled, you can disable cookies in your browser.
+   • To test how your application behaves under normal circumstances, you can enable cookies in your browser.
+   • In IE 11, you may need to reset the security settings to their default levels to block cookies from the web server running on your computer.
+   • For other web browsers, use the browser’s documentation or search the Internet to find instructions for enabling and disabling cookies.
