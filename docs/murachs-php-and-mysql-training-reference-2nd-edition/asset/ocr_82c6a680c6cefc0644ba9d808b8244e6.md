The next example shows how to create and execute a prepared INSERT statement. In general, this works like creating and executing a prepared SELECT statement. However, when you execute this statement, it doesn’t create a result set. Instead, it updates the data. Then, you can use the properties of the mysqli object to get the number of affected rows, error messages, and so on just as you do with dynamic SQL statements. Although this figure doesn’t show how to work with prepared UPDATE and DELETE statements, the principles are the same as working with a prepared INSERT statement.

Since this example uses four question mark parameters, it clearly shows how the first argument of the bind_param function works. In this example, the format string uses a value of “issd” to indicate that the SQL statement contains four parameters: an integer, a string, another string, and a double.
