# How to install the Chrome browser on Fedora

Figure C-2 shows how to install the Chrome browser on Fedora. You’ll need to select which version you want as shown in the figure, depending on whether you have a 32-bit or 64-bit version of Fedora. If you aren’t sure, you can check the name of the kernel on the boot menu when your system starts. If it contains the string x86-64, you have a 64-bit version. If not, you have a 32-bit version.
