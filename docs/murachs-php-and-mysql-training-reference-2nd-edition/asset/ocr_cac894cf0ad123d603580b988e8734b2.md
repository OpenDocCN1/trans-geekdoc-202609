# How to create a database

```
```sql
CREATE DATABASE my_guitar_shop2;
```
```

# How to create a database only if it does not exist

```
```sql
CREATE DATABASE IF NOT EXISTS my_guitar_shop2;
```
```

# How to select a database

```
```sql
USE my_guitar_shop2;
```
```

# How to drop a database

```
```sql
DROP DATABASE my_guitar_shop2;
```
```

# How to drop a database only if it exists

```
```sql
DROP DATABASE IF EXISTS my_guitar_shop2;
```
```

# Description

+   - You can use the CREATE DATABASE statement to create a database.
+   - You can use the USE statement to select a database.
+   - You can use the DROP DATABASE statement to drop a database.

# Warning

+   - You should never drop a production database without first consulting the DBA. In most cases, though, you won't have the privilege to do that (see figure 17-10).
