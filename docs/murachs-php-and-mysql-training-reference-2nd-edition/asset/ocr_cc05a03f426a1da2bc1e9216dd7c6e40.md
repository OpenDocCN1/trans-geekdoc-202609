# How to download and install the source code

+   1. Go to www.murach.com, and go to the page for *Murach’s PHP and MySQL (2nd Edition)*.
+   2. Click the “FREE Downloads” tab.
+   3. Select the “All Book Files” link for the regular zip file, and respond to the resulting pages and dialog boxes. This will download a file named jsp3_allfiles.zip onto your hard drive.
+   4. Use the Finder to browse to this file and double-click on it to unzip it. This creates the book_apps, ex_starts, and ex_solutions folders.
+   5. Use the Finder to move these three folders into the htdocs folder.
