# Description

+   - To execute a SQL statement, select a database and click the SQL tab. Then, enter the SQL statement and click the Go button. To execute multiple SQL statements, include a semicolon (`;`) at the end of each SQL statement.
+   - On Unix systems, the column and table names are case-sensitive.
