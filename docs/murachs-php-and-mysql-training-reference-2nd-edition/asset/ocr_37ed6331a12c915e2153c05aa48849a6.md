`http://netbeans.org`

# How to install NetBeans

+   1. Go to the NetBeans website.
+   2. Download the disk image (dmg) file for the NetBeans IDE that supports PHP. This file should be under the heading HTML 5 and PHP, and should be named something like `netbeans-8.0-php-macosx.dmg`.
+   3. Double-click the disk image file and respond to the resulting dialog boxes.

# How to install xDebug and configure it for PHP

+   1. Use the Finder to search the Application/XAMPP folder for the xdebug.so file.
+   2. Use the Finder to copy the xdebug.so file into the xamppfiles/lib folder.
+   3. Use TextWrangler to open the php.ini file shown above. Scroll down to the end of this file and add these lines:
+   
+   ```ini
+   [xdebug]
+   zend_extension = /Applications/XAMPP/xamppfiles/lib/xdebug.so
+   xdebug.remote_enable=on
+   xdebug.remote_host=localhost
+   xdebug.remote_handler=dbgp
+   xdebug.remote_port=9000
+   ```
+   
+   4. Save your changes.
+   5. Stop and restart Apache.
