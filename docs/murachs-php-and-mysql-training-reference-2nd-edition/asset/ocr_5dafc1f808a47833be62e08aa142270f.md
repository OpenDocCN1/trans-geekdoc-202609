# How to install the book applications
and databases

To get the most from this book, you need to run the applications that it presents and do the exercises at the ends of the chapters. To do that, you need to download the book applications and exercise starts from our website and you need to run a script that installs the databases that the applications use.

# How to install the source code for this book

Figure B-5 shows how to download and install the source code for this book. This includes the source code for the applications that are presented in this book and the source code for the exercise starts and solutions.

When you finish this procedure, the book applications, exercise starts, and exercise solutions should be in the directories shown in this figure. Then, you’ll be ready to do the exercises in this book.
