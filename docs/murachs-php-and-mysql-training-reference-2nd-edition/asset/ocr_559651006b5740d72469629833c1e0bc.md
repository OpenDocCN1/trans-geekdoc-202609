# ## Terms

+   - prototype
+   - prototyping
+   - stepwise refinement

# ## Summary

+   - A *prototype* is a working model of a website or portion of a website. *Stepwise refinement* refers to the process of making step-by-step improvements to the prototype with review and evaluation after each step.
+   - The primary benefit of *prototyping* is that you detect problems early in the development cycle when they cost less to fix.
