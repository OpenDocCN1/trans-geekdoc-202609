# Appendix C

# How to set up Linux
for this book

This appendix shows how to install and configure the software that we recommend for developing PHP applications on Linux. This software includes the XAMPP package, the NetBeans IDE, and Google Chrome as your default browser. This appendix also shows how to install the sample applications and exercises for this book.

Some of the installation procedures in this appendix vary slightly depending on which distribution of Linux you are running. This appendix covers the two most popular distributions: Ubuntu, and Fedora. However, these instructions should work for any Linux distribution that’s based on Ubuntu, Red Hat, or Fedora. Where necessary, we point out the differences between the installation procedures for Ubuntu and Fedora. For other Linux distributions, you may need to refer to the documentation for your Linux distribution. Regardless of your distribution, this appendix assumes that you have some familiarity with the Linux command line.

As you read this appendix, please remember that most websites are continually updated. As a result, some of the procedures in this appendix may have changed since this book was published. If there are significant changes to these setup instructions, we will post updates on our website (www.murach.com).
