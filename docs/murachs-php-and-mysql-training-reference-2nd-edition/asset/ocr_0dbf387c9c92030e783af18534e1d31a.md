# How to select data

Figure 19-8 shows how to use mysqli to execute a dynamic SELECT statement. To start, it’s generally considered a best practice to escape special characters in any parameters that are passed to the SQL statement. This helps guard against SQL injection attacks. In this figure, for example, the first statement uses the escape_string method to escape any special characters in the category ID parameter. However, this statement could have used the real_escape_string method to do the same thing.

Unlike the PDO quote method, the mysqli escape_string method doesn’t automatically add single quotes around the parameter. Since surrounding a parameter with single quotes helps to guard against SQL injection attacks, it’s generally considered a good practice to do that. That’s why the code in this example includes single quotes around the category ID parameter.

After you have escaped the parameters and added single quotes around them, you can use the query method of the mysqli object to return a result set. This result set is actually a mysqli_resultset object.

If the result set contains a FALSE value, an error occurred. In that case, you can handle the error. In this figure, for example, the code uses the error property of the mysqli object to get an error message, it displays the error message, and it exits the script.

If the result set doesn’t contain a FALSE value, you can use the num_rows property of the result set object to get the number of rows in the result set. Then, you can loop through each row in the result set. Within that loop, you can use the fetch_assoc method to get the current row.

When you’re done using the result set, you can free the resources used by the result set by calling the free method of the result set object. Then, if you’re done using the database connection, you can free the resources used by that object by calling the close method of the mysqli object.
