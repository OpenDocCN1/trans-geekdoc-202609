# # The Chrome / Chromium browser

As you do the exercises and work with the applications in this book, we recommend that you use Google Chrome to test your applications. On Linux, there are two versions of Chrome that you can install. The first is the commercial version of Chrome that you can download from Google’s website. The second is the open-source version, which is named Chromium. Effectively, these two browsers are the same, except Chromium is open-source software.

If you are using Ubuntu, we recommend that you install Chromium instead of Chrome as shown in figure C-1. This is because Chromium integrates better with Ubuntu’s desktop look and feel. For example, it displays the Close, Maximize, and Minimize buttons where you would expect them to be.

Fedora, however, does not have a Chromium package available. As a result, for Fedora, we recommend you use the commercial version of Chrome available from Google as shown in figure C-2.

When you perform software installations like these, your system may prompt you for a password. To continue, you can enter the password for the root user. Or, if you are an administrator with appropriate permissions, you can enter your password.
