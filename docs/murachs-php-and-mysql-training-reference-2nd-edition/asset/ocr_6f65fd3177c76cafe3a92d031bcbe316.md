# # How to send email and access other websites

When you create a web application, you often need to send email to your users. For example, when a user makes a purchase from an eCommerce site, the application usually sends an email that confirms the order.

Some web applications also need to get data from other websites. To facilitate that, many major websites such as Google, Yahoo, and YouTube provide a way for other web applications to get data from their web servers.

In this chapter, you’ll first learn how to send email and get data from other web servers. Then, the application at the end of the chapter will show you how to combine the two skills in a useful application.
