# How to read and write images

Figure 23-8 shows how to read and write images. To start, you can create an image from a file by using one of the imagecreatefromxxx functions such as the imagecreatefromgif, imagecreatefromjpeg, and imagecreatefrompng functions. Then, if necessary, you can use the imagesx and imagesy functions to get the width and height of the image, and you can do any processing on the image that you need to do.

When you’re done processing an image, you can write the image to a file by using one of the imagexxx functions such as the imagegif, imagejpeg, and imagepng functions. Finally, since images take a substantial amount of memory, you can use the imagedestroy function to free the image from memory when you’re done working with the image.
