# Appendix B

# How to set up Mac OS X
for this book

This appendix shows how to install and configure the software that we recommend for developing PHP applications on Mac OS X. This software includes the XAMPP package, the NetBeans IDE, Google Chrome as your default browser, and TextWrangler as your text editor. This appendix also shows how to install the sample applications and exercises for this book.

As you read this appendix, please remember that most websites are continually updated. As a result, some of the procedures in this appendix may have changed since this book was published. Nevertheless, these procedures should still be good guides to installing the software. And if there are significant changes to these setup instructions, we will post updates on our website (www.murach.com).
