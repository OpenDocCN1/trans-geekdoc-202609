## How to install Chrome and TextWrangler

As you do the exercises and work with the applications in this book, we recommend that you use Google Chrome to test your applications. In addition, we recommend that you use TextWrangler as your text editor. Both of these applications are free, and they don’t take long to install.

### How to install the Chrome browser

Figure B-1 shows how to download and install Chrome. As you respond to the dialog boxes for the installer, we recommend that you make Chrome your default browser.

### How to install TextWrangler

Figure B-1 also shows how to download and install TextWrangler.

### The URL for downloading Chrome

[www.google.com/chrome/](http://www.google.com/chrome/)

### How to install Chrome

1. Go to the website address above.
2. Click on the Download Chrome button.
3. Review the terms of service, leave the Set Google Chrome as my default browser checkbox checked, and click the Accept and Install button. This will save the disk image (dmg) file to your hard drive.
4. If the Chrome disk window doesn’t appear, double-click the disk image file to open the disk window.
5. In the Chrome disk window, drag the Chrome icon on top of the Applications folder icon. Then, close the Chrome window.
6. Open the Applications folder and double-click the Chrome icon to start Chrome.

### The website address for downloading TextWrangler

[www.barebones.com/products/textwrangler](http://www.barebones.com/products/textwrangler)

### How to install TextWrangler

1. Go to the website address above.
2. Click the Download Now button. Click the Download link for the disk image (dmg), and save the disk image file to your hard drive.
3. If the TextWrangler disk window doesn’t open, double-click the TextWrangler disk image file to open the TextWrangler disk window.
4. In the TextWrangler disk window, drag the TextWrangler icon on top of the Applications folder icon. Then, close the TextWrangler window.
5. Open the Applications folder and double-click the TextWrangler icon to start TextWrangler.

## How to install and configure XAMPP

Before you can develop database-driven PHP applications, you need to install and configure a web server, a database server, and an interpreter for the PHP language. For this book, we recommend the Apache web server and the MySQL database server. Although you can install and configure these components individually, that can be tedious and error prone. As a result, we recommend using the XAMPP package to simplify the installation of Apache, MySQL, and PHP.

Be aware that the installation of XAMPP is not secure by default. As a result, it should not be used as a production server until it is properly secured. As you progress through this book, you’ll learn more about securing the XAMPP installation.

### How to install XAMPP

Figure B-2 shows a procedure for installing XAMPP 1.8.3, which includes PHP 5.5. When you use this procedure, the Apache Friends website links to the SourceForge website to provide the download for the installer file for XAMPP.

At the time of this writing, the latest version of XAMPP for Mac OS X is XAMPP 1.8.3 (PHP 5.5). If you find a newer version when you install XAMPP, we recommend that you install XAMPP 1.8.3 (PHP 5.5) rather than the newer version. That way, your computer should work as described in this book. When newer versions of XAMPP become available, you should be able to find the older versions of XAMPP on the SourceForge website.

Once you’ve completed the basic installation, you can test that installation by starting and stopping the Apache and MySQL servers as described in this figure.

Once you’ve started the Apache server, you can test it by starting a web browser and navigating to this directory:

```
http://localhost/xampp
```

If this URL displays a web page, you have successfully installed and started the Apache server.

### The website address for downloading XAMPP 1.8.3 for Mac OS X

http://sourceforge.net/projects/xampp/files/

### How to install XAMPP 1.8.3 for Mac OS X

1. Go to the website address above.
2. Click the Download button.
3. Save the disk image (dmg) file to your hard drive.
4. Use the Finder to locate the disk image (dmg) file and double-click on it to open the installer window. You will need to enter your system password.
5. Follow the instructions in the XAMPP Setup Wizard.

### How to configure phpMyAdmin

XAMPP includes a web-based tool for working with MySQL named phpMyAdmin. By default, phpMyAdmin stores the username and password for MySQL’s root user in its configuration file, which is a plain text file. Since this isn’t secure, it’s generally considered a good practice to modify these default settings.

We recommend changing the authentication type for phpMyAdmin from ‘config’ to ‘cookie’ as shown in figure B-3. When you use the ‘cookie’ authentication type, phpMyAdmin does not store any usernames or passwords in its configuration file. Instead, it prompts the user for a username and password when it starts, and it stores the username and password in a cookie in the user’s browser.

Once you’ve modified the configuration file for phpMyAdmin, you can use the second procedure in this figure to make sure the MySQL server is working correctly and to make sure that phpMyAdmin is configured correctly.
