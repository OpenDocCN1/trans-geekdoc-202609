# How to test a PHP page for the first time

+   1. Make sure the Apache and MySQL servers are running.
+   2. Start a web browser and enter the URL for the application as shown in the last figure.
+   3. Test the page by entering both valid and invalid data, clicking on all links, and so on.

# How to retest a PHP page after you change the source code

+   - Click the Reload or Refresh button in the browser. Then, test the page again.

# Description

+   - If you get an error message, read the message to help determine the cause of the error. Then, modify the PHP code and retest the page.
+   - If you discover other types of errors that don’t lead to error messages, you also modify the code and retest the page.
+   - In chapter 6, you’ll learn more about finding errors (*bugs*) and fixing them (*debugging*).
