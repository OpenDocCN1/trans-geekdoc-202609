# The URL for downloading Chrome

[www.google.com/chrome/](http://www.google.com/chrome/)

# How to install Chrome

+   1. Go to the website address above.
+   2. Click on the Download Chrome button.
+   3. Review the terms of service, leave the Set Google Chrome as my default browser checkbox checked, and click the Accept and Install button. This will save the disk image (dmg) file to your hard drive.
+   4. If the Chrome disk window doesn’t appear, double-click the disk image file to open the disk window.
+   5. In the Chrome disk window, drag the Chrome icon on top of the Applications folder icon. Then, close the Chrome window.
+   6. Open the Applications folder and double-click the Chrome icon to start Chrome.

# The website address for downloading TextWrangler

[www.barebones.com/products/textwrangler](http://www.barebones.com/products/textwrangler)

# How to install TextWrangler

+   1. Go to the website address above.
+   2. Click the Download Now button. Click the Download link for the disk image (dmg), and save the disk image file to your hard drive.
+   3. If the TextWrangler disk window doesn’t open, double-click the TextWrangler disk image file to open the TextWrangler disk window.
+   4. In the TextWrangler disk window, drag the TextWrangler icon on top of the Applications folder icon. Then, close the TextWrangler window.
+   5. Open the Applications folder and double-click the TextWrangler icon to start TextWrangler.
