# How to import and run a SQL script

+   1. Click the Import tab, go to the “File to Import” section, click the Browse button, and select the file that contains the script.
+   2. Click the Go button. This runs the script that’s in the file.

# The script for creating the databases used by this book

```
\xampp\htdocs\book_apps\_create_db\create_db.sql
```

# Description

+   - A SQL script consists of one or more SQL statements that are stored in a file. A SQL script can include all of the SQL statements for creating a database, creating its tables, and adding data to those tables.
+   - Run the script that’s shown above to create the databases used by this book.
