
The HTML code for this file just uses echo statements to display the formatted user entries and the future value within `<span>` tags. Since all of the numbers for these user entries have been validated earlier in the PHP file, it isn’t necessary to escape this output as these variables aren’t susceptible to an XSS attack.

Now, if you understand the PHP and HTML for this file, you’re ready to write some applications of your own. However, you should be aware that this application can be improved in several ways that would make it more realistic.

For example, the data validation could be improved. For instance, you could check to make sure that the interest rate is less than 15. This type of data validation is common to all production applications.

Beyond that, you could add features that would make the application easier to use. For instance, you could add a Return button or link to the second page that would make it easier to get back to the first page. As it is, the user has to click on the Back button to do that. The good news is that you already have the skills for making enhancements like this.
