
## How to fix a possible problem with the time zone

When you install XAMPP, it usually sets the time zone that’s used by PHP correctly. However, in some cases, XAMPP doesn’t set the time zone correctly. If that happens, you’ll get an error when you try to use PHP to get the current date and time.

To check whether the time zone is set correctly on your system, you can use the first procedure in figure B-7 to run the specified application. If you don’t see an error on the first page of this application, the time zone is set correctly. As a result, you don’t need to take any further action.

However, if the first page of this application displays an error, you need to set the time zone as shown in the second procedure. To do that, you need to open the php.ini file in a text editor such as TextWrangler and set the time zone. For a list of supported time zones, you can view the PHP documentation that’s available from the URL specified in this figure.

### The Chrome / Chromium browser

As you do the exercises and work with the applications in this book, we recommend that you use Google Chrome to test your applications. On Linux, there are two versions of Chrome that you can install. The first is the commercial version of Chrome that you can download from Google’s website. The second is the open-source version, which is named Chromium. Effectively, these two browsers are the same, except Chromium is open-source software.

If you are using Ubuntu, we recommend that you install Chromium instead of Chrome as shown in figure C-1. This is because Chromium integrates better with Ubuntu’s desktop look and feel. For example, it displays the Close, Maximize, and Minimize buttons where you would expect them to be.

Fedora, however, does not have a Chromium package available. As a result, for Fedora, we recommend you use the commercial version of Chrome available from Google as shown in figure C-2.

When you perform software installations like these, your system may prompt you for a password. To continue, you can enter the password for the root user. Or, if you are an administrator with appropriate permissions, you can enter your password.

#### How to install Chromium on Ubuntu

1. Open a terminal. To do that, click on the Ubuntu icon in the top left corner of the screen below the menu bar, type “terminal” in the text box, and press the Enter key.
2. Update your system’s package list. To do that, you can enter an apt-get command like this:

    ```bash
    sudo apt-get update
    ```

3. Enter the password for the root user.
4. Install Chromium. To do that, you can enter an apt-get command like this:

    ```bash
    sudo apt-get install chromium-browser
    ```

5. If necessary, enter the password for the root user. This should display a list of other suggested packages that you might want to install with Chromium.
6. Type “y” and press Enter to begin installing Chromium without the other suggested packages.

#### How to create a Chromium shortcut on the Launcher

1. Display the icon for Chromium. To do that, click on the Ubuntu icon in the top left corner of the screen and type “chromium” in the text box. The icon for launching Chromium should appear below the text box.
2. Hold down the right mouse button and drag the Chromium icon onto the Launcher.

#### How to install XAMPP 1.8.3 for Linux

1. Go to the website address above.
2. Click the Download button.
3. Save the installer (.run) file to your hard drive.
4. Open a terminal window. On Ubuntu, use the procedure in figure C-1. On Fedora, click on Activities at the top left of the screen, type “terminal” and press Enter.
5. Change the directory to the Downloads directory. To do that, you can enter the following command:

    ```
    cd Downloads
    ```

6. List the files in this directory. To do that, you can enter the following command:

    ```
    ls
    ```

7. Find the name of the file. It should be something like “xampp-linux-x64-1.8.3-5-installer.run”, but it might be slightly different.
8. Make the file executable. To do that, you can enter the following command:

    ```
    chmod u+x xampp-linux-x64-1.8.3-5-installer.run
    ```

   Of course, if necessary, replace the filename shown here with the filename that’s on your system.
9. Run the file. To do that, you can enter the following command:

    ```
    sudo ./xampp-linux-x64-1.8.3-5-installer.run
    ```

10. Enter the root password when prompted and follow the instructions in the XAMPP Setup Wizard.
