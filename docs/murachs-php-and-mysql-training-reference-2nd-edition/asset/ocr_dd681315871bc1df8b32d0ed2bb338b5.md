# # The Image Upload application

To show you how the skills that you’ve just learned can be used in an application, figure 23-11 presents an Image Upload application. This application lets the user upload an image file from the client to the server. Then, if necessary, this application creates two smaller versions of the image. This application also lets the user view these images or delete them.

# ## The user interface

The first page in the user interface starts with a form that lets the user upload a file. This form begins with a Choose File button. This button lets the user select the file. When it’s first displayed, this button is followed by a message that says, “No File Chosen”. Then, after the user selects a file, this button is followed by the name of the selected file.

After the Choose File button, this form includes an Upload button. This button lets the user upload the selected file.

After the form, this page displays a list of files that are already in the images directory. In this example, a user has already uploaded a file named gibson_sg.png, and the application has already generated two files from it. The first file is named “gibson_sg_100.png” and it has a maximum width of 100 pixels. The second file is named “gibson_sg_400.png” and it has a maximum width of 400 pixels.

In this list of images, the user can click on the delete icon to the left of the image to delete the image. Or, the user can click on the name of the image to view the image as shown by the second page of this application.
