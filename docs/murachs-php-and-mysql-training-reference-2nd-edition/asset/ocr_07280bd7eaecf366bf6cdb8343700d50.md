# ## How to create a Chromium shortcut on the Launcher

+   1. Display the icon for Chromium. To do that, click on the Ubuntu icon in the top left corner of the screen and type “chromium” in the text box. The icon for launching Chromium should appear below the text box.
+   2. Hold down the right mouse button and drag the Chromium icon onto the Launcher.
