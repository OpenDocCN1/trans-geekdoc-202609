# # How to start and stop the Apache and MySQL servers

Once you’ve completed the basic installation, you can test that installation by starting and stopping the Apache and MySQL servers as described in part 2 of figure C-3.

Once you’ve started the Apache server, you can test it by starting a web browser and navigating to this directory:

```
```text
http://localhost/xampp
```
```

If this URL displays a web page, you have successfully installed and started the Apache server.

# # How to change ownership of the htdocs directory

Part 2 of figure C-3 also shows you how to change the ownership of the htdocs directory so it is owned by your user account. We recommend doing this because it makes working with the book applications and exercises much easier.
