# The software for this book

+   - XAMPP 1.8.3
+     - Apache 2.4
+     - MySQL 5.6
+     - PHP 5.5
+     - phpMyAdmin 4.2
+   - NetBeans 8.0.
+   - Google Chrome.
+   - A good text editor for your operating system.
+   - You can download this software for free and install it as described in appendix A (Windows), B (Mac OS X), or C (Linux).

# The downloadable source code for this book

+   - Complete source code for the applications presented in this book, so you can view the code and run the applications as you read each chapter.
+   - Starting points for the exercises that are presented at the end of each chapter, so you can get more practice in less time.
+   - Solutions to the exercises, so you can check your work.
+   - All source code is compatible with the NetBeans IDE, but this code can also be edited with a text editor or imported into other IDEs.

# How to download the source code for this book

+   1. Go to murach.com.
+   2. Go to the page for *Murach’s PHP and MySQL (2nd Edition)*.
+   3. Follow the instructions there to download the zip file that contains the source code for this book.
+   4. Unzip all files into XAMPP’s htdocs directory. This creates these three subdirectories: book_apps, ex_starts, and ex_solutions.
+   5. Use phpMyAdmin to run the create_db.sql script that’s in the book_apps/_create_db directory.

For more information, please see appendix A (Windows), B (Mac OS X), or C (Linux).
