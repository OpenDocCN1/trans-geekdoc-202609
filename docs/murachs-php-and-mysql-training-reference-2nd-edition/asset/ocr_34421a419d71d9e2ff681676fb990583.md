# Retrieve three columns and sort them by price

```
```sql
SELECT productID, productName, listPrice
FROM products
ORDER BY listPrice

# Retrieve rows in the specified price range

```
```sql
SELECT productID, productName, listPrice
FROM products
WHERE listPrice < 450
ORDER BY listPrice
```
```

| productID | productName | listPrice |
|---:|---|---:|

# Retrieve an empty result set

```
```sql
