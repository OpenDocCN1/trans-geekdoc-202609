# Two more functions for working with regular expressions

| Function | Description |
|---|---|
| `preg_replace($pattern, $new, $string)` | Returns a string that’s created by replacing the specified pattern in the specified string with a new substring. |
| `preg_split($pattern, $string)` | Returns an array of strings that’s created by splitting the specified string on the specified pattern. |

# How to use the preg_replace function to replace a pattern with a string

```
```php
$items = 'MBT-6745 MBS-5729';
$items = preg_replace('/MB[ST]/', 'ITEM', $items);

echo $items;      // Displays ITEM-6745 ITEM-5729
```
```

# How to use the preg_split function to split a string on a pattern

```
```php
$items = 'MBT-6745 MBS-5729, MBT-6824, and MBS-5214';
$pattern = '/[, ]+(and[ ]*)?/';
$items = preg_split($pattern, $items);

// $items contains: 'MBT-6745', 'MBS-5729', 'MBT-6824', 'MBS-5214'

foreach ($items as $item) {
    echo '<li>' . $item . '</li>';
}
```
```
