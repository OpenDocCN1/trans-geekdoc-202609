# Functions for working with the include path

| Function | Description |
|---|---|
| `get_include_path()` | Gets a string that contains the current include path. |
| `set_include_path($path)` | Sets the include path. |

# The default include path

**Windows**

`.;C:\xampp\php\PEAR`

**Mac OS X**

`.:/Applications/XAMPP/xamppfiles/lib/php`

**Linux**

`.:/opt/lampp/lib/php`

# How to get the include path

```
```php
$include_path = get_include_path();
```
```

# How to set the include path

**Windows**

```
```php
set_include_path($include_path . ';C:\xampp\htdocs\book_apps\lib');
```
```

**Mac OS X**

```
```php
set_include_path($include_path .
                 ':/Applications/XAMPP/htdocs/book_apps/lib');
```
```

**Linux**

```
```php
set_include_path($include_path .
                 ':/opt/lampp/htdocs/book_apps/lib');
```
```

# How to include a file after the include path has been set

```
```php
require_once cart.php;
```
```

# Description

+   - The *include path* specifies the directories that are searched for included files. By default, the include path specifies the current directory (a dot), followed by any system specific directories (such as the PEAR libraries).
+   - If you want to add a directory to the include path, you can use the `get_include_path` and `set_include_path` functions. To separate the directories of the include path, you should use semicolons for Windows and colons for Mac and Linux.
