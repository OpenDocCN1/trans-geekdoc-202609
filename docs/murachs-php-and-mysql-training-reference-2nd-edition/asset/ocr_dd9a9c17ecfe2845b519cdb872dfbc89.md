# The website address for downloading XAMPP 1.8.3 for Linux

```
http://sourceforge.net/projects/xampp/files/
```

# How to install XAMPP 1.8.3 for Linux

+   1. Go to the website address above.
+   2. Click the Download button.
+   3. Save the installer (.run) file to your hard drive.
+   4. Open a terminal window. On Ubuntu, use the procedure in figure C-1. On Fedora, click on Activities at the top left of the screen, type “terminal” and press Enter.
+   5. Change the directory to the Downloads directory. To do that, you can enter the following command:
+      ```
+      cd Downloads
+      ```
+   6. List the files in this directory. To do that, you can enter the following command:
+      ```
+      ls
+      ```
+   7. Find the name of the file. It should be something like “xampp-linux-x64-1.8.3-5-installer.run”, but it might be slightly different.
+   8. Make the file executable. To do that, you can enter the following command:
+      ```
+      chmod u+x xampp-linux-x64-1.8.3-5-installer.run
+      ```
+      Of course, if necessary, replace the filename shown here with the filename that’s on your system.
+   9. Run the file. To do that, you can enter the following command:
+      ```
+      sudo ./xampp-linux-x64-1.8.3-5-installer.run
+      ```
+   10. Enter the root password when prompted and follow the instructions in the XAMPP Setup Wizard.
