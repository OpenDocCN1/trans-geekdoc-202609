# The website address for downloading XAMPP 1.8.3 for Mac OS X

http://sourceforge.net/projects/xampp/files/

# How to install XAMPP 1.8.3 for Mac OS X

+   1. Go to the website address above.
+   2. Click the Download button.
+   3. Save the disk image (dmg) file to your hard drive.
+   4. Use the Finder to locate the disk image (dmg) file and double-click on it to open the installer window. You will need to enter your system password.
+   5. Follow the instructions in the XAMPP Setup Wizard.

# How to start and stop the Apache and MySQL servers

+   1. Open the Applications folder and open the XAMPP folder.
+   2. Double-click the manager-osx application. This will start the XAMPP Control Panel.
+   3. Click on the Manage Servers button to start or stop a server by clicking on its Start or Stop button.

# A URL you can use to test the Apache server

http://localhost/xampp

# Description

+   - The XAMPP package includes the Apache web server, the MySQL database server, the PHP interpreter, and other software that’s useful for developing PHP applications.
+   - Once you start Apache and MySQL on Mac OS X, they may stop when you log out or restart your computer. In that case, you may need to restart Apache and MySQL before you do any PHP development.
