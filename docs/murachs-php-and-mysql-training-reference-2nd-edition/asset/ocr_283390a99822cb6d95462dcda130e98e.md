# How to start and stop the Apache and MySQL servers

+   1. Open a terminal and change to the opt/lampp directory by typing this command:
+      `cd /opt/lampp`
+   2. Start the XAMPP manager. For 64-bit versions of Linux, you can enter this command:
+      `sudo ./manager-linux-x64.run`
+      For 32-bit versions of Linux, you can enter this command:
+      `sudo ./manager-linux-x86.run`
+   3. Enter the root password when prompted.
+   4. Click on the Manage Servers button.
+   5. Use the Start and Stop buttons to start or stop the corresponding servers.

# A URL you can use to test the Apache server

```
http://localhost/xampp
```

# To change the ownership of the htdocs directory

+   1. Open a terminal and change to the /opt/lampp directory.
+   2. Enter the following command, replacing your_username with your Linux login name:
+      `sudo chown your_username htdocs`
+   3. If necessary, enter the root password.

# Note

+   - Once you start Apache and MySQL on Linux, they may stop when you restart your computer. In that case, you may need to restart Apache and MySQL before you do any PHP development.
