# For Windows

# The PHP initialization file

```
c:\xampp\php\php.ini
```

# The procedure

+   1. Open the php.ini file in a text editor.
+   2. Find the line that contains the text “php_curl.dll”.
+   3. If necessary, remove the semicolon from the beginning of the line. It should read as follows:
+      `extension=php_curl.dll`
+   4. Restart the Apache web server as described in the appendix.

```
extension=php_curl.dll
```

# Description

+   - The cURL library lets you connect to other servers on the web. It supports protocols such as HTTP, FTP, IMAP, POP3, and SMTP.
+   - By default, cURL is installed with XAMPP. However, it might not be enabled on some systems.
