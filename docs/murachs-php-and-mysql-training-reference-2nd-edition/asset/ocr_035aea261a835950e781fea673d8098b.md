# Functions for modifying arrays

| Function | Description |
|---|---|
| `array_unique($array[, $compare])` | Returns `$array` with duplicate values removed. The `$compare` property works the same as it does for the sort function except that `SORT_STRING` is the default. |
| `array_reverse($array [, $keys])` | Returns `$array` with the elements in the reverse order. If `keys` is `FALSE` (the default value), the elements are reindexed. Otherwise, the original keys are used. |
| `shuffle($array)` | Shuffles the values in `$array` in a random order. The elements are reindexed. |
| `array_rand($array [, $count])` | Returns a random key from `$array`. If `$count` is greater than one, it returns an array of `$count` random keys from `$array`. |

# How to modify an array

```
```php
$names = array('Mike', 'Mike', 'Mike', 'Anne', 'Joel', 'Joel');
$names = array_unique($names);                 // Mike, Anne, Joel
$names = array_reverse($names);                // Joel, Anne, Mike
shuffle($names);                               // Mike, Joel, Anne (for example)
```
```

# How to modify an associative array

```
```php
$tax_rates = array('NC' => 7.75, 'NY' => 8.875, 'CA' => 8.25);
$tax_rates = array_reverse($tax_rates, true);
```

# How to shuffle and deal a deck of cards

```
```php
// Create the deck of cards
$faces = array('2', '3', '4', '5', '6', '7', '8',
               '9', 'T', 'J', 'Q', 'K', 'A');
$suits = array('h', 'd', 'c', 's');
$cards = array();
foreach($faces as $face) {
    foreach($suits as $suit) {
        $cards[] = $face . $suit;
    }
}

// Shuffle the deck and deal the cards
shuffle($cards);
$hand = array();
for ($i = 0; $i < 5; $i++) {
    $hand[] = array_pop($cards);
}
echo implode(',', $hand);                     // 9c,6d,Ks,4c,7h (for example)
```
