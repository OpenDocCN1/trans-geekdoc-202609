# How to use phpMyAdmin to load data from a text file

+   1. Start phpMyAdmin, select the database, select the table, and click on the Import tab.
+   2. Select the file to import.
+   3. Set the options for the import and click the Go button. If you get an error, you can modify the import options and try again.

# How to use the Windows command prompt to load data from a text file

```
cd \xampp\mysql\bin
mysql -u root -p
Enter password: ******
use my_guitar_shop2;
load data local infile "c:/murach/products.txt" into table products;
exit;
```

# Description

+   You can use phpMyAdmin or the LOAD command to load data into a MySQL database from a text file.
