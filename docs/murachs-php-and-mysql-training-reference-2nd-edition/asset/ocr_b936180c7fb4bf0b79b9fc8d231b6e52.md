# The command for installing Java (only Ubuntu)

+   1. Open a terminal and enter the following command:

```
sudo apt-get install default-jre
```

# How to install NetBeans

+   1. Go to the NetBeans website.
+   
+   2. Download the installer (.sh) file for the NetBeans IDE that supports PHP. This file should be under the heading HTML5 and PHP and should be named something like `netbeans-8.0.1-php-linux.sh`.
+   
+   3. Open a terminal and change to the Downloads directory.
+   
+   4. Make the file executable. To do that, you can enter:
+   
+   5. Run the file. To do that, enter:
+   
+   6. Follow the instructions in the NetBeans setup wizard.

```
chmod u+x netbeans-8.0.1-php-linux.sh
```

As usual, if necessary, replace the filename shown here with the filename that’s on your system.

```
sudo ./netbeans-8.0.1-php-linux.sh
```
