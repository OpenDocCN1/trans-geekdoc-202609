## How to configure phpMyAdmin

XAMPP includes a web-based tool for working with MySQL named phpMyAdmin. By default, phpMyAdmin stores the username and password for MySQL’s root user in its configuration file, which is a plain text file. Since this isn’t secure, it’s generally considered a good practice to modify these default settings.

We recommend changing the authentication type for phpMyAdmin from ‘config’ to ‘cookie’ as shown in figure C-4. When you use the ‘cookie’ authentication type, phpMyAdmin does not store any usernames or passwords in its configuration file. Instead, it prompts the user for a username and password when it starts, and it stores the username and password in a cookie in the user’s browser.

Once you’ve modified the configuration file for phpMyAdmin, you can use the second procedure in this figure to make sure the MySQL server is working correctly and to make sure that phpMyAdmin is configured correctly.

## The default location of the config file for phpMyAdmin

```
/opt/lampp/phpmyadmin/config.inc.php
```

## How to configure authentication for phpMyAdmin

- 1. Open a terminal and change to the `/opt/lampp/phpmyadmin` directory.
- 2. Open the `config.inc.php` file for editing by typing the following command:
- ```bash
sudo gedit config.inc.php
```
- 3. Set the ‘blowfish_secret’ option to a random string up to 46 characters. This specifies the encryption key for the cookie.
- 4. Set the ‘auth_type’ option to a value of ‘cookie’.
- 5. Set the ‘user’ and ‘password’ options to empty strings.
- 6. Save your changes.

## The default settings

```php
$cfg['blowfish_secret'] = 'xampp'; /* YOU SHOULD CHANGE THIS FOR A MORE
SECURE COOKIE AUTH! */

/* Authentication type and info */
$cfg['Servers'][$i]['auth_type']      = 'config';
$cfg['Servers'][$i]['user']           = 'root';
$cfg['Servers'][$i]['password']       = '';
```

## The settings after phpMyAdmin has been configured for authentication

```php
$cfg['blowfish_secret'] = 'd2k0vc93ms28si29';

/* Authentication type and info */

```

## How to build and configure xDebug

We recommend that you use the xDebug debugger with NetBeans because it makes it easier to debug your PHP applications. The source code for xDebug is included as part of the XAMPP installation. However, to get it to work with NetBeans, you must build the xDebug source code and configure xDebug to work with NetBeans.

Before you can build xDebug, you need to install a few build tools including the C compiler and the autoconf tool. To do this, open a terminal, and enter the commands shown in figure C-6 that correspond with your Linux distribution.

Once the build tools have installed, you can build and configure xDebug using the procedure shown in the second part of the figure. After you do that, the xDebug debugger should work as described in chapter 6.

## How to build and configure xDebug

- 1. Open a terminal and change to the /opt/lampp directory.
- 2. Build the xDebug file. To do that, enter:
- ```bash
sudo bin/pecl install xdebug
```
- This should build xDebug. When it’s done, the command prompt should return.
- 3. Change to the /opt/lampp/lib/php/extensions directory and find the xdebug.so file. It is usually stored in a directory with a long name such as no-debug-non-zts-20121212. Note the name of the directory as it may be slightly different on your system.
- 4. Change back to the /opt/lampp directory.
- 5. Open the php.ini file for editing. To do that, enter:
- ```bash
sudo gedit etc/php.ini
```
- 6. Scroll down to the end of this file and add these lines:
- ```ini
[xdebug]
zend_extension = /opt/lampp/lib/php/extensions/no-debug-non-zts-20121212/xdebug.so
xdebug.remote_enable=on
xdebug.remote_host=localhost
xdebug.remote_handler=dbgp
xdebug.remote_port=9000
```
- 7. Save your changes.
- 8. Stop and restart Apache.
