# 49 语言冗余、信息熵与数字通信中的成本效率

Amrita Pratap^([^(48)](#fn48))

DOI: [10.1201/9781003534136-49](https://dx.doi.org/10.1201/9781003534136-49)

## 摘要

数字通信的经济学在很大程度上依赖于文件压缩，而文件压缩受两个关键因素的影响：语言冗余和有效沟通。语言冗余是指语言的固有属性，由信息熵及其最大值决定。有效沟通取决于传达者技能和知识，以最大限度地减少多余信息。本文提出了一种估计英语语言冗余的新模型，并讨论了避免使用多余信息的重要性。我们的模型得出信息熵为每字母0.895比特，最大值为2.37，对应的语言冗余为62.3%，这表明数据文件可以压缩至原始大小的62.3%。该值与 `WAV` 和 `ZIP` 文件格式提供的无损压缩相当。此外，与香农的方法相比，我们的模型不需要英语文本的测试样本，也不会受到人类受试者变异性的影响。

**关键词:** 文件压缩, 语言冗余, 信息介绍, 成本效率, 数字通信

## 引言

自数字通信开始以来，其发展势头迅速，如今几乎已成为企业通信的生命线，而企业通信最常使用英语进行。企业领导者至关重要地依赖数字通信（在线和离线）与分布在全球各地的团队、投资者和其他利益相关者保持密切和持续的互动。

实现数据压缩的软件工具利用语言冗余，即所涉语言的固有属性。当系统按照一套规则和约束运行 时，它更有序、更有组织，因此其行为更可预测。有趣的是，英语的系统格式、句法结构和语法规则构建了语言冗余，有助于预测或猜测印刷文本中缺失或难以辨认的部分，以及嘈杂背景下口头交流中断的片段。语言冗余被用于数据文件的压缩，这可以由训练有素的软件完成。英语字母中的一个字母包含多少比特信息，以及英语中的冗余有多大，由克劳德·E·香农 [[1](#ch49.xhtml#ref49_1)] 研究并解释，他首次创造并定义了“信息熵”和“语言冗余”这两个术语，并制定了根据概率确定其值的方程。

## 信息熵的概念发展

为了理解经典热力学熵概念如何扩展到数字通信领域，需要了解熵、概率和信息之间的相互关系。我们将逐步介绍这些术语，并在不涉及数学细节的情况下对其进行定性理解。如果特定构型的系统的熵与其假设该构型的概率相互关联，并且所指构型的概率与其附加的信息价值相互关联，那么根据简单的逻辑，熵和信息也必须相互关联 [[2](#ch49.xhtml#ref49_2), [3](#ch49.xhtml#ref49_3)]。

“熵”一词最初由鲁道夫·克劳修斯在其关于热力学第二定律的工作中引入 [[4](#ch49.xhtml#ref49_4), [5](#ch49.xhtml#ref49_5)]。热力学熵是热力学系统中不可用于做有用功的热能量的度量。系统的熵变可以计算为系统热含量变化除以对系统做功或由系统做功时的绝对温度。

在随后的几年里，路德维希·玻尔兹曼 [[6](#ch49.xhtml#ref49_6)] 给出了以下熵方程：

(1)

```
S = K(B) log W(E)
```

其中 `S` 是熵，`K(B)` 是玻尔兹曼常数，而 `W` 是所有可能构型（微态）或排列的数量，在所有构型等概率且与具有总能量含量 `E` 的系统的可观测宏观态一致的条件下，系统的所有组成成分（分子）可以在这些排列中以不同方式分布。

J.W. 吉布斯后来推广了玻尔兹曼的观点，并用不同的概率表征了不同的构型（微态） [[7](#ch49.xhtml#ref49_7), [8](#ch49.xhtml#ref49_8)]。重新表述的玻尔兹曼方程为：

(2)

```
S = - K(B) Sum(i = 1 to n)( pi log pi )
```

其中求和是对所有构型/微态进行的，`pi` 是构型 ‘`i`’ 的概率，而 `K(B)` 是玻尔兹曼常数。Janes [[7](#ch49.xhtml#ref49_7)] 说，“无序是系统可能具有的微态数量庞大的表现。微态的选择越大，系统的可预测性或有序程度就越低。”换句话说，定义系统参数的确定性越低，系统中存在的无序性就越多。
