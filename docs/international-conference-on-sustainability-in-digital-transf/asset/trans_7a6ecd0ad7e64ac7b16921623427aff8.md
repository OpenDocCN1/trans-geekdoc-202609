
# 引言

糖尿病患者血糖水平升高，糖尿病是一组由胰岛素合成不足或对内源性胰岛素分泌细胞反应性差引起的代谢性疾病。糖尿病视网膜病变是与糖尿病相关的常见病症 \[[1](#ch29.xhtml#ref29_1)\]。所讨论的病症是一种高度流行且严重的眼部疾病。该病症会导致视网膜微血管受损，导致视力受损。发生糖尿病视网膜病变的可能性与年龄增长呈正相关，因此表明中年及老年人群中的糖尿病患者更容易患此病。非增殖性糖尿病视网膜病变（NPDR）是糖尿病视网膜病变的初始阶段 \[[2](#ch29.xhtml#ref29_2)\]。在此特定阶段，会出现视网膜内微小血管发生血液或体液渗漏的现象。眼内结构中渗漏液体的存在会导致视网膜水肿或形成称为渗出物的沉积物。增殖性糖尿病视网膜病变（PDR）的特征是眼睛对视网膜血液供应广泛闭塞的反应，其中它会启动视网膜内新血管的生长或补充 \[[3](#ch29.xhtml#ref29_3)\]。遗憾的是，新形成的不正常血管并不能有效恢复视网膜的正常血液循环。相反，它们很容易出血，并且经常伴有疤痕组织，这可能导致视网膜皱缩或脱离。各种体格检查可用于识别糖尿病视网膜病变的存在，包括瞳孔扩张、视力评估和光学相干断层扫描等。然而，需要注意的是，这些程序可能相当耗时，患者可能会感到明显不适。本研究集中于利用机器学习分类器进行糖尿病视网膜病变的自动计算机辅助识别。具体而言，渗血、微动脉瘤和渗出物的特征被提取和分析。

“本文档按以下章节组织。第 2 节提供了关于糖尿病分类和诊断的研究文献综述。第 3 节讨论了所提方法的 methodology。它涉及视网膜病变图像的预处理、分割、特征提取和分类。第 4 节展示了结果和分析，随后是结论和参考文献。”

## 文献综述

使用 MESSIDOR 数据集，\[[4](#ch29.xhtml#ref29_4)\] 的作者提出了一种基于分形分析和随机森林的糖尿病视网膜病变分级方法。分形维数被计算为特征并用于系统的图像分割。他们无法区分轻度和重度糖尿病视网膜病变。糖尿病视网膜病变和健康的视网膜图像可以利用并行神经网络（CNN）和支持向量机（SVM）自动分类，如 \[[5](#ch29.xhtml#ref29_5)\] 所建议。特征包括渗出物、出血和微动脉瘤。基于神经网络的特征提取器和基于 SVM 的分类器构成了作者建议系统的两个部分。使用面积和数量提取，\[[6](#ch29.xhtml#ref29_6)\] 的作者提出了一种利用数据集中彩色眼底图像更好地诊断微动脉瘤性糖尿病视网膜病变的技术。眼底图像在预处理中经历了绿色通道提取、直方图均衡化和形态学技术。微动脉瘤使用主成分分析（PCA）、限制性自适应直方图均衡化（LAHE）、形态学过程和平均滤波器进行检测，并使用 SVM 进行分类。参考文献 \[[7](#ch29.xhtml#ref29_7)\] 中作者提出的技术旨在通过使用多种纹理特征和机器学习分类算法来识别糖尿病视网膜病变病例。基于局部能量的形状直方图用于提取两种不同的特征，即出血和渗出物。SVM 通常用于通过特征向量学习和分类检索到的直方图。在他们的研究中，作者提出了一个新颖的系统（参考文献为 \[[8](#ch29.xhtml#ref29_8)\]），解决了糖尿病视网膜病变分类问题。所建议的系统采用模糊 C 方法进行特征提取，并利用 SVM 进行分类。血管的提取是通过使用顶帽滤波器和数学形态学技术完成的。选定的分析特征包括视网膜血管密度和渗出物。渗出物的提取过程是通过模糊 C 均值分割完成的。参考文献 \[[9](#ch29.xhtml#ref29_9)\] 中展示的工作概述了一种使用基于形态学技术在彩色眼底图像中检测渗出物的方法。所提出的模型采用灰度转换、直方图均衡化、逻辑与运算和分水岭变换。该技术生成输出，其中包括糖尿病视网膜病变病例中渗出物的影响范围。\[[10](#ch29.xhtml#ref29_10)\] 中作者提出的技术涉及使用软间隔 SVM 对非增殖性糖尿病视网膜病变进行分类。在视网膜眼底图像中观察到的硬性渗出物的利用可作为对非增殖性糖尿病视网膜病变病例严重程度进行分类的手段。然而，需要注意的是，该方法缺乏将微动脉瘤和出血作为可识别特征的包含。在他们的研究中，\[[11](#ch29.xhtml#ref29_11)\] 及同事提出了一种硬性渗出物的自动识别方法。该方法利用两种不同的属性，即尖锐边缘和颜色高光。检测技术涵盖了多种方法，包括基于颜色的分类、尖锐边缘检测和视盘提取。训练和测试程序使用 DRIVE 数据集进行。系统的图形用户界面使用 MATLAB 实现。

## 拟议方法

### A. 数据集图像采集

本研究利用 Kaggle 上公开可访问的数据集用于检测糖尿病视网膜病变 \[[12](#ch29.xhtml#ref29_12)\]。该数据集使用来自视网膜病变检测公开数据集的图像编译而成。在 Kaggle 数据集中，存在一组同时表现出糖尿病视网膜病变存在和不存在的图像。其中一部分图像，包括患有糖尿病视网膜病变的图像以及正常图像，被选用于分析。所选异常图像包括渗出物、出血和微动脉瘤的实例。

### B. 图像预处理

为了识别与眼底成像相关的异常，有必要对照片进行预处理。此预处理旨在纠正输入图像中不均匀的照明，从而消除渗出物与图像背景像素之间的对比度和噪声。预处理技术包括自适应直方图均衡化（AHE）和离散小波变换（DWT） [图 29.1](#ch29.xhtml#fig29_1) 和 [图 29.2](#ch29.xhtml#fig29_2) 已附上以提供图像预处理的示例。
