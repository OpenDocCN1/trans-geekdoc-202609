
图像模糊集（`PFSs`）最初由 Cuong 和 Kreinovich 提出，比直觉模糊集（`IFSs`）更有效地处理现实问题中的不确定性。本文介绍了 `PFSs` 之间的距离测度。本研究的目的是提出一种针对 `PFSs` 的距离测度并确认其有效性，并讨论其关键特性。所提出的距离测度还用于机器学习决策过程，如多属性决策。数值示例展示了所开发方法解决实际问题的有效性。

**关键词：** 距离测度，模糊集，劣化比率方法 和 `MADM`，直觉模糊集，图像模糊集

## 引言

为了应对与图像处理、机器学习、模式识别和决策等相关的各种现实世界问题，需要从不同角度对两个不同的对象进行分析。不同研究根据问题类型使用了不同的对比度量。“相似性测度”、“距离测度”、“相关性测度”等术语在兼容性和可比性研究中常用。由于 `PFS` 是 `FS` 和 `IFS` 的改进，因此讨论关于 `FSs` 和 `IFSs` 的进展和应用的重要研究是很重要的。Zadeh \[[11](#ch3.xhtml#ref3_11)\] 最先提出了模糊集（`FS`）理论。模糊集理论处理隶属度，其取值介于零和一之间。Atanassov \[[1](#ch3.xhtml#ref3_1)\] 提出了 `IFSs`，它同时度量隶属度和非隶属度。然而，`IFSs` 不处理中性度。让我们考察一个现实世界的情况。在投票期间，存在支持、反对或对任何决策保持中立的社会群体。然而，社会中仍有一部分人弃权不投票。为了解决这类问题，Cuong 和 Kreinovich \[[2](#ch3.xhtml#ref3_2)\] 提出了 `PFSs` 的概念，它处理隶属度、非隶属度和中性度，且这些度之和应小于或等于一。

为了取得新的成果，本文提出了图像模糊集（`PFSs`）的距离测度。距离测度和相似性测度都是解决现实问题（如决策）的重要概念 \[[3](#ch3.xhtml#ref3_3), [4](#ch3.xhtml#ref3_4), [5](#ch3.xhtml#ref3_5), [6](#ch3.xhtml#ref3_6), [7](#ch3.xhtml#ref3_7), [8](#ch3.xhtml#ref3_8), [9](#ch3.xhtml#ref3_9) and [10](#ch3.xhtml#ref3_10)\]。`TOPSIS` 技术建议最终方案应既远离负理想解（`NIS`），又最接近正理想解（`PIS`）。`TOPSIS` 由 Chen \[[3](#ch3.xhtml#ref3_3)\] 扩展到模糊环境。`MADM` 技术用于从多个决策方案中找出最佳方案。Zhang 等 \[[10](#ch3.xhtml#ref3_10)\] 在 `PF` 领域提出了 `MADM` 的 `EDAS` 技术。Jana 等 \[[4](#ch3.xhtml#ref3_4)\] 在 `PF` 环境中提出了 Dombi 聚合算子及其在 `MADM` 中的应用。Singh 和 Kumar \[[12](#ch3.xhtml#ref3_12)\] 开发了用于解决 `MADM` 的 `VIKOR` 方法。

当前工作与 `PF` 距离测度的研究相关。本文的主要贡献如下：

为了解决 `MADM` 问题，我们提出了图像模糊集的距离测度。利用 `PF` 距离测度，我们基于 `TOPSIS` 技术引入了一种图像模糊劣化比率方法。一些数值示例用于展示所建议的 `MADM` 技术，以克服 `PFSs` 领域中现有 `TOPSIS` 方法的不足。我们在劣化比率方法的意义上扩展了 `TOPSIS` 方法。

本文其余部分结构如下：

第 2 节介绍了 `FSs`、`IFSs` 和 `PFSs` 的一些基本基础。第 3 节介绍了距离测度并描述了其特性。在第 4 节，我们说明了 `MADM` 方法。还展示了比较分析以说明所建议测度的有效性。第 5 节涵盖结论和未来展望。

## 预备知识

**定义 2.1** (Zadeh \[[11](#ch3.xhtml#ref3_11)\])。有限论域集 `K` = {`m`[1], `m`[2],..., `m`[q] } 中的一个 `FS` `Q` 定义为：

(2.1)

`Q` = {(`m`[`z`], `s`[`Q`](`m`[`z`])) | `m`[`z`] ∈ `K`}, `z` = 1, 2, …, `q`,

其中 `S[Q]` (`m[z]`) ∈ [0,1] 是元素 `m[z]` 在集合 `Q` 中的隶属度。为方便起见，Zadeh \[[11](#ch3.xhtml#ref3_11)\] 将 `S[Q]`(`m[z]`) 称为模糊数（`FN`），记为 `l` = (`S[l]`)。

**定义 2.2** (Atanassov \[[1](#ch3.xhtml#ref3_1)\])。有限论域集 `K` = {`m`[1], `m`[2],..., `m`[q]} 中的一个 `IFS` `B` 定义为：

(2.2)

`B` = {(`m`[`z`], `s`[`I`](`m`[`z`]), `e`[`I`](`m`[`z`])) | `m`[`z`] ∈ `K`}, `z` = 1, 2, …, `q`

其中 `S[Q]` (`m[z]`) ∈ [0,1] 是隶属度，`e[B]`(`m[z]`) ∈ [0,1] 是元素 `m[z]` 在集合 `B` 中的非隶属度。这里，对所有 `m[z]` ∈ `K`，有 0 ≤ `S[B]`(`m[z]`) + `e[B]`(`m[z]`) ≤ 1。对于 `m[z]` ∈ `K`，`ϒ[Q]` (`m[z]`) = 1 - `S[B]` (`m[z]`) - `e[B]`(`m[z]`) 定义为 `m[z]` 在 `B` 中的犹豫度。为方便起见，Atanassov \[[1](#ch3.xhtml#ref3_1)\] 将 (`S[B]` (`m[z]`), `e[B]`(`m[z]`)) 称为直觉模糊数（`IFN`），记为 `t` = (`s[t]`, `e[t]`)。

**定义 2.3** (Cuong and Kreinovich \[[2](#ch3.xhtml#ref3_2)\])。有限论域集 `K` = {`m`[1], `m`[2],..., `m`[q]} 中的一个图像模糊集 `I` 定义为：

(2.3)

`I` = {(`m`[`z`], `s`[`I`](`m`[`z`]), `g`[`I`](`m`[`z`]), `e`[`I`](`m`[`z`])) | `m`[`z`] ∈ `K`}, `z` = 1, 2, …, `q`,

其中 `S[I]` (`m[z]`) ∈ [0,1] 是隶属度，`g[I]` (`m[z]`) ∈ [0,1] 是中性度，`e[I]`(`m[z]`) ∈ [0,1] 是元素 `m[z]` 在集合 `I` 中的非隶属度，这里 0 ≤ `S[I]` (`m[z]`) + `e[I]`(`m[z]`) - `g[I]`(`m[z]`) ≤ 1。

对于 `m[z]` ∈ `K`，`κ[I]`(`m[z]`) = 1 – `s[I]` (`m[z]`) – `g[I]` (`m[z]`) – `e[I]` (`m[z]`) 定义为 `m[z]` 在 `I` 中的拒绝度。如果 `κ[I]` 值较小，则对 `m[z]` 的了解更确定。另一方面，如果 `κ[I]` 值较大，则对 `m[z]` 的了解更不确定。为方便起见，Cuong 和 Kreinovich \[[2](#ch3.xhtml#ref3_2)\] 将 (`s[I]` (`m[z]`), `g[I]` (`m[z]`), `e[I]` (`m[z]`)) 称为图像模糊数（`PFN`），记为 `i` = (`s[i]`, `g[i]`, `e[i]`)。

如果中性度（`g[I]`）等于零，则 `PFS` 变为 `IFS`；当非隶属度（`e[I]`）和中性度（`g[I]`）都等于零时，则 `PFS` 变为 `FS`。中性度 `g[I]` 的整合能更精确地确定对象的细节并提高结果的质量和有效性（Son \[[6](#ch3.xhtml#ref3_6)\]）。

**定义 2.4** (Cuong and Kreinovich \[[2](#ch3.xhtml#ref3_2)\])。如果 `K` 包含两个图像模糊集 `I` 和 `W`，则不同的运算定义如下：

1.

`I`^(c) = {(`m`[`z`], `e`[`I`](`m`[`z`]), `g`[`I`](`m`[`z`]), `s`[`I`](`m`[`z`])) | `m`[`z`] ∈ `K`}, `z` = 1, 2, .. `q`.

2.

`I` ⊆ `W`, if `s`[`I`](`m`[`z`]) ≤ `s`[`W`](`m`[`z`]), `g`[`I`](`m`[`z`]) ≤ `g`[`W`](`m`[`z`]), `e`[`I`](`m`[`z`]) ≥ `e`[`W`](`m`[`z`]), ∀ `m`[`z`] ∈ `K`.

3.

`I` ∪ `W` = {(`m`[`z`], max(`s`[`I`](`m`[`z`]), `s`[`W`](`m`[`z`])), min(`g`[`I`](`m`[`z`]), `g`[`W`](`m`[`z`])), min(`e`[`I`](`m`[`z`]), `e`[`W`](`m`[`z`])) ) | `m`[`z`] ∈ `K`}

4.

`I` ∩ `W` = {(`m`[`z`], min(`s`[`I`](`m`[`z`]), `s`[`W`](`m`[`z`])), min(`g`[`I`](`m`[`z`]), `g`[`W`](`m`[`z`])), max(`e`[`I`](`m`[`z`]), `e`[`W`](`m`[`z`])) ) | `m`[`z`] ∈ `K`}

**定义 2.5** (Son \[[6](#ch3.xhtml#ref3_6)\])。函数 `DM` : `PFS`(`K`) × `PFS`(`K`) → [0,1]，其中 `I, W` 和 `Q` ∈ `PFS`(`K`)，如果满足以下准则，则定义为距离测度：

1. 0 ≤ `DM`(`I, W`) ≤ 1.

2. `DM`(`I, W`) = `DM`(`W, I`).

3. `DM`(`I, I`) = 0.
