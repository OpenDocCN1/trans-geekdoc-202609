# 31 使用 MLP 和卷积神经网络 (CNN) 进行与皮肤病感染相关的决策

Neha Chauhan^([^(30)](#fn30))

DOI: [10.1201/9781003534136-31](https://dx.doi.org/10.1201/9781003534136-31)

## Abstract

皮肤病影响了很大比例的生物。 监测和识别皮肤疾病对于医学界来说是一项艰巨的任务。 感染会在人们的皮肤上留下几乎可见的痕迹，但由于人们肤色差异很大，确定确切的类型可能很困难。 这就是为什么皮肤病的早期诊断和治疗如此至关重要。 近年来，`AI` 在医疗保健领域的使用有所增加。 在大多数情况下，深度学习 (`DL`) 和机器学习 (`ML`) 方法被用于诊断。 这些方法既增强了诊断程序，又加快了其速度。 本研究的目的是通过创建 `DL` 和 `ML` 的混合方法来推进皮肤病分类。 卷积神经网络 (`CNN`) 模型用于特征提取和分类，利用诸如支持向量机 (`SVM`) 和多层感知器 (`MLP`) 等 `ML` 模型。 为了确定最有效的预测模型，进行了比较分析，结果显示 `CNN` 与 `MLP` 结合的混合方法达到了 96.06% 的最高准确率

**关键词：** `CNN`, 深度学习, `MLP`, 皮肤病, 支持向量机

## Introduction

表皮是人体最大且最可见的皮肤层，在体温调节和热冷感觉的激活中发挥着至关重要的作用，从而保护众多内脏器官免受外部伤害和感染。 然而，皮肤容易受到环境和遗传因素的影响而发生变化。 皮肤疾病在人类群体中相当普遍。 传染性皮肤疾病、细菌性皮肤疾病和接触性皮炎疾病是最常见的皮肤问题形式。 各种皮肤状况会改变皮肤的质地或色调。 皮肤疾病通常无法治愈，容易从人传人，甚至可能致癌。 如果及早发现并治疗，真菌和过敏性疾病是非常简单的医学状况。 然而，在处理病毒性疾病时，及时诊断至关重要。 近年来，临床领域利用人工智能 (`AI`) 模型、机器学习 (`ML`) [[1](#ch31.xhtml#ref31_1), [2](#ch31.xhtml#ref31_2)] 和深度学习 (`DL`) [[3](#ch31.xhtml#ref31_3), [4](#ch31.xhtml#ref31_4)] 取得了快速进展。 改进的皮肤病预测一直是几种基于集成机器学习 [[5](#ch31.xhtml#ref31_5)] 和人工神经网络 [[6](#ch31.xhtml#ref31_6)] 的技术的重点。 在这项工作中，皮肤疾病是使用结合 `ML` 和 `DL` 模型的方法进行分类的。 两种 `ML` 模型——`SVM` 和 `MLP`——被用于创建分类器。 卷积神经网络 (`CNN`) 用于特征提取。 最后，进行了大量测试以确定哪些预测模型表现最佳。 本文分为以下几个部分。第 2 节提供了关于皮肤疾病识别和诊断的研究文献综述。第 3 节讨论了所提方法的 methodology。第 4 节展示了实验结果，随后是结论和参考文献。
