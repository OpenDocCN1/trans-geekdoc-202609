

近年来，自然灾害如气候变化、生态系统转变、珊瑚礁死亡、洪水、海平面上升和冰川融化有所增加。这可归因于能源危机和环境污染的恶化。据科学家称，近90%的全球气候变化是由人类造成的 \[[1](#ch6.xhtml#ref6_1)\]。我们过去一个世纪一直用石油化工燃料满足能源需求，导致温室气体排放增加，如二氧化碳，温室效应加剧以及气候异常。人为过程如畜牧业、农业、为交通开采化石燃料以及制冷剂制造都促进了气候变化的加速 \[[2](#ch6.xhtml#ref6_2), [3](#ch6.xhtml#ref6_3) and [4](#ch6.xhtml#ref6_4)\]。全球正在努力寻找解决能源和污染问题的方案。令人担忧的趋势是流通中的汽车数量呈指数级增长，导致涉及碳氢化合物 (`HC`)、铅 (`Pb`)、硫氧化物 (`SOx`)、氮氧化物 (`NOx`) 和一氧化碳 (`CO`) 的污染问题 \[[5](#ch6.xhtml#ref6_5)\]。逻辑上，`HEV`s 通过减少石油消耗和排放——环境退化和能源危机的两个主要原因——为环境可持续性做出贡献。`HEV`s 利用电能和机械能为推进循环提供动力，前者来自电动机，后者来自内燃机 \[[6](#ch6.xhtml#ref6_6)\]。这种配置使 `HEV`s 具有极高的技术先进性。

控制机制已到位，以调节必须储存的能量和 `HEV`s 的功耗，以确保能量得到适当分配。通过实施精心选择的控制系统，可以通过减少排放和石油消耗来优化经济性。在追求最大效率的同时，车辆的功效必须保持不受损害 \[[7](#ch6.xhtml#ref6_7), [8](#ch6.xhtml#ref6_8) and [9](#ch6.xhtml#ref6_9)\]。

通过分析车辆的燃油消耗、排放和动态性能，所提出的算法将确定控制策略的最佳参数值 \[[10](#ch6.xhtml#ref6_10)\]。车辆的驾驶性能使用软件 `ADVISOR` 进行模拟，配置由控制参数修改 \[[11](#ch6.xhtml#ref6_11)\]。模拟利用两个独立的人口和迭代执行，并且控制参数使用 `MA` 建立。本研究中车辆的性能标准被视为约束条件，并且惩罚函数对其进行核算。此外，通过实施电动辅助策略优化了 `UDDS` 驾驶循环 \[[12](#ch6.xhtml#ref6_12), [13](#ch6.xhtml#ref6_13) and [14](#ch6.xhtml#ref6_14)\]。模拟结果表明，与 `ADVISOR` 中指定的预设并联 `HEV` 相比，车辆性能保持一致，而 `FC` 和排放得到改善。

## Methodology

### The HEV control strategy

IC 发动机和电动机是为并联混合动力电动汽车提供动力的两个驱动装置。对于此操作，功率必须在 IC 发动机和电动机之间分配，并且相应地，在示例控制方法的帮助下进行扭矩分配。有许多此类控制过程的方法，但最常用的是电动辅助。

在此策略中，ICE 发动机是主要来源，电动机是辅助供应来源。如果由于需求功率 IC 发动机无法提供有效能量或超过最大允许扭矩范围，则该电动辅助方法已使用电动机 \[[15](#ch6.xhtml#ref6_15)\]。电池的充电状态值决定了作为发电机的电机操作，并且额外扭矩用于电池的充电操作。

```
x = SOC_L, SOC_H, T_ch, T_min, T_off, E_LSL, E_LSH, D_ch
```

`SOC[L]`、`SOC[H]` 表示下阶段和上阶段的充电状态值。上述表达式显示了在此策略中用于优化控制参数的变量。

### Designing Objective Function

本研究的 `HEV` 控制技术旨在同时实现多个目标，包括在保持车辆性能的同时减少 `FC` 和废气排放 (`HC`、`CO` 和 `NOx`)。因此，主要目标是降低 `FC` 和废气排放（即 `CO`、`HC` 和 `NOx`）。目标函数如下列出：（2）。

```
min Obj(x) = NOX + FC + CO + HC
```

其中 `x` 表示其中一个解，即 `MO` 编码的染色体，而 `X` 表示解空间。氮氧化物缩写为 `NOx`，燃油消耗缩写为 `FC`，一氧化碳为 `CO`，碳氢化合物为 `HC`。

### Apply MA to design the appropriate HEV control strategy

该算法基于达尔文生存和适者生存，与遗传算法 (`GA`) 相当。为了产生更优秀的后代，所选物种的优选物种彼此之间进行随机交换遗传信息。该过程重复进行，直到创建出最适应物种。流程图在 [图1](#ch6.xhtml#fig6_1) 中显示了构成 `MO` 算法的迭代过程。

对于初始种群生成，首先生成数十到数百个染色体而不重复，该初始种群由 (1) 表示。
* 进行局部搜索。

为了获得更好的染色体，在原始染色体附近的区域进行局部搜索。在每次迭代中，所有后代都将参与局部搜索，确保染色体的每个部分的最佳解决方案始终保留，并最终确定最佳解决方案。
* 计算适应度值。

适应度函数可以检测染色体是优秀还是较差，并计算每个染色体的全局最优值。

当算法被使用时，车辆性能标准被定义为约束条件。为了验证优化过程中车辆性能未下降，本工作采用了 `PNGV` 乘用车限制。因此，适应度函数如下：

```
f(x) = \frac{1}{\left\lbrack {Obj.(x) + {\sum\limits_{i = 1}^{n}y_{i}} + P_{i}(x)} \right\rbrack}
```
* 决定算法终止

本研究提出的方法的目标是以最多 1000 次迭代完成算法运行。
* 选择

鉴于适应度选择是自然选择的真正目的，后代的特征将受到所选结果的影响。为了改善后代的产生，用于交叉目的的训练语料库中物种的选择可能会受到物种适应度水平的影响。本研究使用竞争选择作为其主要方法，选择两个染色体进行后续筛选。
