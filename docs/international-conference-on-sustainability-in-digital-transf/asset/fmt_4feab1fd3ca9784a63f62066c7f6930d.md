
Recall is another name for true positive rate (`TPR`). It demonstrates our classifier’s proficiency in identifying malicious software. It’s a result of:

(5)

`TPR = TP/(TP + FN)`

False positive rate (`FPR`): The frequency with which innocuous files are incorrectly identified as malicious.

(6)

`FPR = FP/(FP + FN)`

`Precision` measures how often a positive result is anticipated accurately relative to the total number of positive results predicted. `Recall` quantifies an algorithm’s ability to find all positive samples. `Precision` and `recall` are averaged in order to form the `F1 Score`.

(7)

`Precision = TP/(TP + FP)`

(8)

`Recall = TP/(TP + FN)`

(9)

`F1-score = 2(Precision * recall)/(precision + recall)`

(10)

`Accuracy score = (TP + TN)/(TP + TN + FP + FN)`
