设想的太阳能电池板清洁方法中使用的两步清洁工艺。首先，排气扇尽力清除面板表面的污垢。作为污垢，采用了四种主要类型的沙子 [[19](#ch5.xhtml#ref5_19)]。然后用由软布制成的刮水器轻轻擦拭。因此，系统可以在不需要水的情况下进行清洁。此功能可防止太阳能电池板受损 [[20](#ch5.xhtml#ref5_20)]。

本研究提出了一种可以编程擦拭太阳能电池板的装置。建议的研究项目利用了物联网，并且框架由微控制器和 Android 设备管理 [[21](#ch5.xhtml#ref5_21)]。该技术具有灵活性，因此可在任何地方使用 [[22](#ch5.xhtml#ref5_22)]。通过与其连接的太阳能电池板的使用，电池可以在此充电。使用 Android 应用控制减少了对人工劳动的需求。

除了价格低廉、功耗极低和集成 Wi-Fi 功能外，ESP8266 是物联网项目的绝佳选择。Arduino IDE 使编程变得简单，使其成为新手的合适选择。其紧凑的尺寸使其具有适应性，并能够集成到各种设备中。它可以用作其他微控制器的 Wi-Fi 模块或作为独立微控制器 [[23](#ch5.xhtml#ref5_23), [24](#ch5.xhtml#ref5_24)]。

使用 Arduino IDE 创建程序。配置的上传速度设置为 9600，并且设置 ID 连接到 ESP8266 板的 COM5 端口。作为微控制器，采用了 Node MCU。它是开发开源软件和硬件的平台。在此，使用了 ESP-8266 Wi-Fi 模块。编程使用非常基础的语言进行。基于物联网的 SPCM 的逐步操作在 [图 5.3](#ch5.xhtml#fig5_3) 的流程图中显示。

## 结论

太阳能电池板所暴露的太阳能量的多少决定了其效率，这就是为什么它们直接受天气影响的原因。将太阳能转化为电能的低转换率是阻碍太阳能电站广泛使用的关键问题之一。灰尘和其他颗粒的滞留会降低太阳能电池板的转换效率。由于技术进步，面板现在可以定期清洁。不同的清洁方法及其优缺点一起被评估。
