## Evaluation Metrics

Using the following criteria, we compared the effectiveness of our proposed ontologically-based strategy to that of the current technique \[[15](#ch21.xhtml#ref21_15)\].

Accuracy is defined as the percentage of predictions that turned out to be true within a given sample of predictions. How well an algorithm can locate all positive samples is measured by its `recall`. The `F1 score` takes into account both accuracy and recall.

(3)

`Precision = TP/(TP + FP)`

(4)

`Recall = TP/(TP + FN)`

(5)

`F1 - score = 2 (Precision * recall)/(precision+recall)`

(6)

`Accuracy score = (TP + TN)/(TP + TN + FP + FN)`

Where `TP` denotes true positive, `TN` denotes true negative, `FP` denotes false positives and `FN` denotes false negatives.
