## Abstract

在本手稿中，我们必须定义当故障率恒定时，组件在整个过程中必须保持恒定。仅测试一个可修复的组件，以便在每次故障后程序可以继续。故障率和单位小时数与直线程序时间相符，并定义一个结构，使得可靠性（不可靠性）必须同时下降或必须在整个过程中保持恒定。

**关键词：** 随机变量，概率，平均故障间隔时间，故障率，故障密度

## 1 Introduction

当组件的预测故障率在同等长度的运行周期内保持恒定 [[6](#ch46.xhtml#ref46_6)]，且组件仅易受随机故障影响时，其可靠性为：

`R(t) = exp(−λt)`

其中 `λ` 为常数，称为故障率，`t` 为运行时间。故障率通常以 `t` 小时表示，且使用相同的时间单位。我们常用的故障率的倒数值是平均故障间隔时间，或 `m`。

MTBF 为 `m = 1/λ`

可靠性函数可写为 `R(t) = exp(−t/λ)`

如 Reddy [[1](#ch46.xhtml#ref46_1)] 所讨论，组件的可靠性可以通过将通过测试的组件比例与过程开始时的总组件数进行比较来确定。如果测试固定数量 `n[0]` 的组件，则在时间 `t` 后，将有 `n[S](t)` 个组件存活于该程序，以及 `n[f](t)` 个失效组件 [[3](#ch46.xhtml#ref46_3)]。

因此，`n[0] = n[S](t) + n[f](t)` 在整个过程中是恒定的（[Tyagi et al., 2015](#ch46.xhtml#ref46_11)）。在程序过程中任一时间 `t` 以分数形式表示的可靠性为：

$$R(t) = \\frac{n\_{S}(\\mathbf{t})}{n\_{0}} = \\frac{n\_{S}(t)}{n\_{S}(t) + n\_{f}(t)}$$

根据 Sharma et al. [[4](#ch46.xhtml#ref46_4)]，失效概率（或不可靠性）`Q` 为

$$Q(t) = \\frac{n\_{f}(t)}{n\_{0}} = \\frac{n\_{F}(t)}{n\_{S}(t) + n\_{f}(t)}$$

显而易见，在任一时间 `t`，`R(t) + Q(t) = 1`

### Working Analysis of Failure Data

寿命试验的结果涉及测试大量模型直至失效并随时间监测故障率特征，可用于理解故障过程 [[5](#ch46.xhtml#ref46_5), [9](#ch46.xhtml#ref46_9)]。因此，是将可靠性与实验或现场故障数据联系起来 [[[8](#ch46.xhtml#ref46_8)]] 在时间 `t[1]`、`t[2]`、`t[3]`、…等对系统进行观察。然后我们可以定义故障密度函数如下：

(2.1)

$$f(t) = \\frac{n\_{S}\\left( t\_{i} \\right) - n\_{S}\\left( t\_{i + 1} \\right)}{n\_{0}\\left( {t\_{i + 1} - t\_{i}} \\right)};t\_{i} < t \\leq t\_{i + 1}$$

Zhou and Han [[7](#ch46.xhtml#ref46_7)] 和 Wenjuan [[10](#ch46.xhtml#ref46_10)] 显示，在区间 `t[i] < t ≤ t[i][+1]` 上的故障率定义为该时间间隔内发生的故障数与时间间隔开始时存活数之比，除以时间间隔长度。它被确定为该间隔内发生的故障数与原始总体规模之比除以间隔长度。

(2.2)

$$\\lambda(t) = \\frac{n\_{S}\\left( t\_{i} \\right) - n\_{S}\\left( t\_{i + 1} \\right)}{n\_{S}\\left( t\_{i} \\right)\\left( {t\_{i + 1} - t\_{i}} \\right)};t\_{i} < t < t\_{i + 1}$$

而 `λ(t)` 衡量故障的瞬时速度，故障密度函数 `f(t)` 衡量故障发生的总体速度。

## Conclusion and Future Work

我们必须方便地测量组件总体的恒定故障率，测量恒定故障率的方法是通过立即用好的组件替换失效组件来保持程序中的组件数量恒定，并且存活组件的数量 `N[S](t)` 然后在整个过程中等于 `N[0]`。当然，确定故障率的该程序仅在 `λ` 为常数时才可应用。
