
医疗专家应能够解释为何做出最终的医疗决策。描述在人工神经网络评估后采用了多种指标，包括文本陈述、视觉陈述、部分陈述、通过示例的陈述、通过简化的陈述以及功能相关陈述。视觉陈述是向不了解神经网络的人解释模型内部复杂交互的最佳方法。`XAI`，如 `LIME`，通常被用作视觉陈述方法。此类发现对于识别项目很有用，但对于分析特定模式的医疗系统来说帮助不大。`LIME` 的基本概念在本工作中得到补充，其功能形式也得到扩展。主要思想是按位置反转 X 射线输入值的图像，并应用一种技术来识别神经网络输出节点的变化。视觉描述方法用于以图像形式向专家提供检测结果。为此，首先创建 `ResNet` 结构，然后进行学习过程 \[[19](#ch67.xhtml#ref67_19)\]。完成学习的神经网络会被提供一张需要诊断的 X 射线图片。对 `MaxN` 的值进行验证，`MaxN` 是最终输出节点中值最高的节点。然后按顺序反转图像的像素，并评估 `MaxM` 的调整，`MaxM` 为输出节点的最大值。计算像素 P 的正向因子值的公式如下：`PF = Relu(Max N Max M)`。反转输入图片的像素集后的最高范围是 `MaxM`，而具有先前最大值的节点的值是 `MaxN`。`PF` 表示像素对疾病评估的积极影响。当输入值小于 0 时，`Relu` 即修正线性单元被传输为 0，而当输入范围大于 0 时，则按原样传递。该公式可用于表示图片上作为诊断病情依据的位置。通过图片形状，医疗专业人员可以直观地把握与疾病发生相关的形态。

## Result
总体而言，配置层的形式、特定函数的选择、学习率以及其他因素都会影响人工神经网络的评估结果。因此，必须更改、建模、评估和测试内部配置。使用此方法设计一个表现出最佳精度的模型是可行的。此外，基于 `CNN` 的图像分析模型可执行的运算数量会随着模式类型中使用的节点数量而迅速增加。因此，在规定的学习时间内完成教学过程至关重要。因此，必须设置一种操作数量与卓越精度之比充足的形式。

### Evaluation of Result Based on Accuracy
已建立的神经网络的功能正确性被评估。`AdaGrad`、`SGD`、`Adam` 函数以及 `RMSProp` 被采用，并使用 `Accuracy` 函数来评估确定性。可靠性与总测试结果的正确响应率相关，并且由于其明显，它是最广泛使用的术语。精度计算如下：

$$Accuracy = \frac{TP + TN}{TP + TN + \mid FP + FN}$$

`AdaGrad`、`SGD`、`RMSProp` 和 `Adam` 用于评估正确性。在 160 个 epoch 后，准确率和过拟合问题的发生率得以证实。图 68.5 描述了涉及 `SGD` 和 `Adam` 的评估结果。

在 50 个 epoch 后，`SGD` 和 `Adam` 的结果均接近 80%。在 100 个 epoch 后，未取得性能提升。过拟合似乎在 `Adam` 的情况下尤其发生。[图 68.1](#ch68.xhtml#fig68_1) 描述了结合 `AdaGrad` 和 `RSM Promp` 的性能评估结果。

在 100 个 epoch 后，`RMSProp` 和 `AdaGrad` 均显示结果约为 75%，但在 100 个 epoch 后，性能的改善微乎其微。由于 `RMSProp` 的整体表现不稳定，似乎将其投入实际使用需要谨慎。
