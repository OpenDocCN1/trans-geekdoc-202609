
这本书涵盖了准备 Amazon Web Services (AWS) 认证云基础设施 (AWS Certified Cloud Practitioner Study Guide) 考试所需的知识点：

# 第 1 章：云

本章描述了云环境的核心特性，区别于传统数据中心的运营方式。它讨论了云平台如何提供更高的可用性、可扩展性和弹性，以及虚拟化和自动化计费等技术所起的作用。

# 第 2 章：了解您的 AWS 账户

本章将介绍 AWS 计费结构、规划和监控部署成本的方法，以及如何使用免费层（Free Tier）在未来一年内免费或低成本试用几乎任何 AWS 服务进行实际操作。

# 第 3 章：在 AWS 上获得支持

本章重点介绍在遇到需要解决的问题或在选择复杂选项时，如何在 AWS 上获取支持。您将了解免费基础支持计划（Basic Support）与开发者（Developer）、企业（Business）和企业级（Enterprise）计划的区别。

# 第 4 章：了解 AWS 环境

本章讨论了为增强安全性和可用性，Amazon 如何在地理区域（regions）和可用区（Availability Zones）中组织其资源。您还将了解 Amazon 全球边缘位置（edge locations）网络，该网络旨在为您的应用程序提供更优的网络性能。

# 第 5 章：保护您的 AWS 资源

本章聚焦于安全性。您将学习如何通过身份（identities）、身份验证和角色（roles）来控制对 AWS 资源的访问。您还将了解数据加密以及 AWS 如何简化合规性要求。

# 第 6 章：使用您的 AWS 资源

本章探讨团队如何访问 AWS 资源以便有效管理它们。您将了解 AWS 管理控制台（Management Console）、AWS 命令行接口（CLI）、软件开发工具包（SDKs）以及各种基础设施监控工具。

# 第 7 章：核心计算服务

本章提供了传统物理计算服务的替代方案。我们将讨论 Amazon Elastic Compute Cloud（EC2）、Lightsail 和 Elastic Beanstalk 服务，并快速浏览多种无服务器工作负载模型。

# 第 8 章：核心存储服务

本章探索 Amazon 的对象存储服务，包括简单存储服务（S3）和 Glacier，用于低成本且高度可访问的存储；以及 Storage Gateway 和 Snowball，用于与本地资源集成。

# 第 9 章：核心数据库服务

本章介绍 AWS 上大规模数据管理的方法，涵盖关系型数据库服务（RDS，兼容 SQL）、NoSQL DynamoDB 平台以及用于大容量数据仓库的 Redshift。

# 第 10 章：核心网络服务

AWS 通过虚拟私有云（VPC）、虚拟私有网络（VPN）、通过 Route 53 服务的 DNS 路由以及 CloudFront 的网络缓存，让您控制对资源的网络访问。本章专注于这些服务。

# 第 11 章：自动化您的 AWS 工作负载

本章介绍旨在实现自动化部署并实现 DevOps 集成的 AWS 服务，连接您的开发流程与 Amazon 基础设施中的应用程序环境。

# 第 12 章：常见使用案例场景

本章展示了一些真实的、云优化的部署架构，帮助您了解在 AWS 上可以构建的各种应用程序环境。

## 考试目标

根据 *AWS Certified Cloud Practitioner Exam Guide*（版本 1.4），AWS Certified Cloud Practitioner（CLF-C01）考试“旨在评估具有展示对 AWS Cloud 整体理解能力的个人，与其他 AWS 认证（如解决方案架构师或系统管理员）所针对的具体技术角色无关”。

要取得成功，您需要能够描述以下内容：

*   AWS Cloud 及其基本的全局基础设施

*   AWS Cloud 的架构原则

*   AWS Cloud 的价值主张

*   关键 AWS 服务及其常见用例（例如，高可用性的 Web 应用或数据分析）

*   与 AWS 平台相关的基本安全与合规实践以及共享安全模型

*   AWS 计费、账户管理和定价模型

*   文档和技术支持资源

*   在 AWS Cloud 中部署和运营的基本特性

*   AWS 建议候选人至少在 AWS Cloud 中的任何角色（包括技术、管理、销售、采购或财务）中拥有至少六个月的经验。此外，您应具备信息技术和应用服务器的基础知识及其在 AWS Cloud 中的用途。
