# 介绍

准备任何认证考试都需要决定学习多少实践经验和多少死记硬背的知识点。在我们之间，我们已经参加了 20 多个 IT 认证考试，深知合理利用学习时间的重要性。我们设计了本书，帮助您发现在 AWS 平台上的优势和劣势，以便您能够有针对性地集中精力。无论您已经使用 AWS 多长时间，还是相对新手，我们都建议您从头到尾仔细阅读本书。

通过 AWS Certified Cloud Practitioner 考试不需要您了解如何部署和启动复杂的多层云部署。但您需要对一系列 AWS 服务的工作原理有广泛的了解。本书中的所有内容都将涵盖这些知识点，但您可能会对细节产生好奇。请随时利用 Amazon 官方文档，该文档通常以 HTML、PDF 和 Kindle 格式提供。

尽管 *AWS Certified Cloud Practitioner Study Guide CLF-C01 Exam* 偏向理论，比其他 AWS 认证更侧重概念，但完成每章的实践练习仍然具有巨大价值。这些练习的目的不是让您成为了解“如何”操作的解决架构师，而是帮助您理解“为何”它们如此重要。

请记住，部分练习和图表依赖于 AWS Management Console，该界面不断更新。因此，练习的截图和步骤细节可能会发生变化。如果您在 Management Console 中看到的内容与本书描述不符，请将其作为深入 AWS 在线文档或自行实验的机会。

每章末尾都包含复习题，用于全面测试您对所学服务的理解。我们设计这些题目能够真实反映您的理解程度和考试准备情况。虽然题目难度各不相同，但您可以确信没有“废话”。完成章节评估后，请参阅附录 A 获取正确答案和详细解释。

本书还附带一份包含 25 道题的自评考试，两份包含 100 道题的模拟考试，以及用于帮助您学习和记忆考试关键事实的闪卡。

由于 AWS 服务经常变动，您可能会发现本书中的某些信息会滞后。为帮助您保持更新，我们创建了一个专门的渠道，用于发布相关更新，并让您能够告知我们在使用过程中遇到的问题。请定期访问此资源 [https://awsccp.github.io/](https://awsccp.github.io/)。
