
# 2020 跨岸无线科学与无线技术会议 (CSRSWTC)（中国福州 2020.12.13-2020.12.16）

**摘要**——为了同时识别室内人数和动作，提出了一种基于 WiFi 信号信道状态信息（CSI）的深度学习人类计数与动作识别系统。针对原始 CSI 提出了一种相位差修正算法，并利用深度神经网络提取分类特征。实验结果显示，人数识别准确率达到 99%，双人动作识别的平均准确率为 95.5%，具有良好的识别效果。

*索引词*——人类计数，动作识别，深度学习，信道状态。

针对原始 CSI 提出了一种相位差修正算法，然后将修正后的差值输入深度神经网络，对人数不超过 2 人的室内人数及其动作进行识别。

## I. 引言

随着 WiFi 设备的应用，基于 WiFi 的人体感知技术近年来逐渐成为研究焦点。`CARM*` 系统利用信道状态信息（CSI）的相位信息提取人体的速度和特征，利用 `KNN` 算法识别隐马尔可夫模型来检测行走、跑步、挥手以及通过 CSI 对三种动作进行分类。然而，这些系统需要精确的特征提取和数据处理，导致它们变得复杂且低效。

为了解决这个问题，文献 [4] 提出了一种用于多用户活动识别的 15 层深度网络。然而，由于简单地在深度网络中添加层，作为梯度下降或梯度学习算法的结果，这会导致相位偏移。文献 [4] 中的 `Wispy` 系统通过提取 CSI 幅度并使用机器学习算法来检测移动物体的数量。总而言之，可以看出上述方法只能对动作进行分类或仅计算人数，无法同时检测人数和动作，这限制了它们在安全监控应用领域的发展。

为了解决这一问题，本文提出了一种基于深度学习网络的系统，利用 WiFi 信号的 CSI 进行人类计数和动作识别。

### A. 相位差修正

根据文献 [5]，CSI 的相位差等于两个相邻天线之间差值的相位，因此人体动作受相位差的影响。图 2 (a) 显示了单个人执行坐下动作时的相位差。可以看到，波形稳定后相位差波动时间超过 2 秒，这显示了人类活动的特征。然而，如图 2 (b) 所示，采样期间提取的相位差可能会受相位偏移的影响。为了解决这个问题，本文提出了一种相位差修正算法。

该算法的主要思想如下：首先，考虑到两个相邻数据包之间的差异较小，使用阈值来寻找转换点。相位差超过阈值的数据包被记录为跳点，如图 2 (b) 中的 $I_1$ 和 $I_2$ 所示。其次，将数据包分为若干段，即跳点之间的段以及 $I_2$ 之后的周期。每个段的相位差减去其平均相位差，最终获得连续的相位差。图 2 (c) 显示了相位差修正。可以看到修正后的相位差与图 2 (b) 中的原始相位差几乎相同。所提方法可以有效消除相位偏移。

### B. Resnet-11 网络框架的设计

图 3 显示了 `Resnet-11` 中基础残差块（`RB`）的网络结构，$x$ 是基础残差的输入，残差映射函数 $F(x)$ 由二维卷积形成，输出 $H(x)$ 是恒等映射。残差网络的核心思想是通过快捷连接（即图 3）寻找残差映射函数，并让差异 $F(x)$ 从输出和输入中学习，导致 $F(x)$ 趋于 0，然后实现恒等映射 $H(x)=x$。结果，随着网络深度的增加，梯度消失问题将解决。

相位差修正的核心公式如下：

```
ΔH_{k,n}^i = ΔH_{k,n}^{i-1} + ΔH_{k,n}  （标记为非跳点）

φ_k^i = ΔL_k - (t_i - t_1) / (t_2 - t_1) * ΔH_k^i,  i = t_1, t_2, ..., t_n

φ_k^j = ΔL_k - (t_2 - t_j) / (t_2 - t_1) * ΔH_k^j,  j = t_1, ..., t_2
```
