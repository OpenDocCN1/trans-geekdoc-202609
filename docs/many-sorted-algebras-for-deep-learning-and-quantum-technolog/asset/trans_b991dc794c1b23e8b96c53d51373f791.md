
函数 `f` 将被证明是一个同胚。它是双射的，因为它是满射且一一对应的。满射性可通过选取 `S¹` 中的任意点得到；其形式为 `(sin(2*π*t′), cos(2*π*t′))`。这里使用的 `t′` 的值是 `R` 中的点 `t′`。然而，`Y` 中的 `[t′]` 对应于 `R` 中所有的点 `t′ + n`，其中 `n` 在 `Z` 中，这表明 `f` 是满射的。对于一一对应，若 `[t[1]]` 不等于 `[t[2]]`，则 `t[1]` 不等于 `t[2] + n`，其中 `n` 为整数。因此，`sin(2*π*t[1])` 不等于 `sin(2*π*(t[2] + n))`=`sin(2*π*t[2])`；相应地，`f([t[1]])` 不等于 `f([t[2]])`。接下来，由于 `p` 是商映射，故它是连续的。此外，`f′` 是连续的，因此对开集 `U`，`f′^(−1)(U)` 是开集。由于 `f′^(−1)`=`(f(p))^(−1)`=`p^(−1)(f^(−1))`，将其应用于 `S¹` 中的开集 `U`，`f′^(−1)(U)`=`p^(−1)(f^(−1))(U))` 是开集，这意味着 `f^(−1)(U)` 是开集，因为 `U` 在 `Y` 中是开的当且仅当 `p^(−1)(U)` 在 `X` 中是开的；这表明 `f` 是连续的。对于同胚，唯一剩下的要证明的是 `f` 是开映射。然而，这确实成立，因为 `f′` 是开映射。由于 `f(.)`=`f′(p^(−1)(.))`，将此映射应用于 `Y` 中的开集 `U`。则 `f(U)`=`f′(p^(−1)(U))`，这是开映射，因为 `p` 是连续的，且 `f′` 是开映射。因此，`Y` 与 `S¹` 的同胚关系得以建立。

### Example 10.3

考虑单位区间 `X`=`[0, 1]` 带有由实线诱导的子集拓扑 `Tx`。在 `X` 上使用等价关系 `0~1`。这意味着 `0` 和 `1` 被粘合在一起。设 `q`: `X`→`[0, 1]/~`=`Y` 为典范投影映射。这里，`[0, 1]/~` ={{`0, 1`}, `{t`}}，且 `{t}` 对于 `(0, 1)` 中的每个 `t` 都是单点集。相应地，对于 `(0, 1)` 中的任意 `t`，`q(t)`=`[t]`，但对于 `0` 或 `1`，`q(0)`=`q(1)`=`[0]`=`[1]`。采用商拓扑；这里，`U` 在 `Y` 中是开的当且仅当 `q^(−1)(U)` 在 `X` 中是开的。由于 `0` 和 `1` 相同，似乎该结构像一个圆。事实上，`Y` 也与 `S¹` 同胚。为此，首先设 `f′`: `X`→`S¹`，其中 `f′(t)`=`(sin(2*π*t), cos(2*π*t))`；它是连续映射。定义 `f`，其中 `f([t])`=`f′(t)`，对 `t` 在 `(0, 1)` 中，且 `f([0])`=`f′(0)`=`f′(1)`。参见 [图 10.3](#Ch010_171-188_B9780443136979000047.xhtml#f0020)。

为了证明 `f`: `Y`→`S¹` 是满射，取 `S¹` 中的一个特定点，设 `c`=`(sin(2*π*t′), cos(2*π*t′))`，则 `X` 中的点 `t′` 满足 `f′(t′)`=`c`。这意味着 `Y` 中的 `[t′]` 满足 `f([t′])`=`c`。为了看出 `f` 是 1–1，若 `[t[1]]` 不等于 `[t[2]]`，则 `t[1]` 与 `t[2]` 不同，且 `sin(2*π*t[1])` 不等于 `sin(2*π*t[2])`，因为它们相等仅当 `t[1]` 与 `t[2]` 相差一个整数，即在 `[0, 1]` 的端点处。由于它们在等价类 `Y` 中相同，故 1–1 得证。`f` 的同胚性可通过使用拓扑学中的一个定理得到 ([Dugundji, 1975](#Ch010_171-188_B9780443136979000047.xhtml#bib3))。这里，从紧空间 `Y` 到 Hausdorff 空间的连续双射函数 `f` 是一个同胚。请注意 `S¹` 是 Hausdorff 空间，因为 `R²` 是 Hausdorff 空间。商空间 `Y`=`R/~` 是紧的。这可以看出，因为它是紧集的连续像的满射，即 `X` 是紧的，且同胚已得到证明。

### Example 10.4

映射 `q`: `(0, 1]`→`S¹`，其中 `q(t)`=`(sin(2*π*t), cos(2*π*t))` 不是同胚，因为 `q^(−1)` 不是连续的。为了证明这一点，考虑 `R²` 中点 `(0, 1)` 与 `(sin(2*π*t), cos(2*π*t))` 之间的距离。它是 `[sin(2*π*t)² + (1 − cos(2*π*t))²]` 的平方根 =`2 (1 −cos(2*π*t))`。因此对于 `2 (1 − cos(2*π*t))` 小于 delta，当 `t` 接近零时，这应意味着 `|t−1|` 小于 epsilon，但 `t` 与 1 之间存在间隙。更简洁地，要证明它们不同胚，可利用 `S¹` 是紧的，但 `(0, 1]` 在 `R` 中不是紧的这一事实。

## 10.3 Basic topological and manifold concepts

流形 `M` 总是 Hausdorff 型特殊拓扑空间。这些空间具有任意两个不同点必须各自包含在彼此不相交的不同开集中的性质。此外，Hausdorff 空间必须处处局部同胚于 `R^(*n*)`。因此，这意味着它在局部看起来像欧几里得空间，即使整体结构可能高度非线性。同胚映射是双连续、一一对应且保持结构的满射映射。最后，大多数情况下，`M` 是第二可数的，这意味着存在一个可数基，它是开集的可数并集。从此以后假设具有此特征。第二可数蕴含第一可数；后者拓扑空间只需要具有局部可数基。非第一可数空间的例证见于 [图 10.4](#Ch010_171-188_B9780443136979000047.xhtml#f0025)。此例是病态的；此外，欧几里得空间既是 Hausdorff 空间也是第二可数空间。

流形 `M` 总是与一个图册 `A` 相关联。这是一组称为图的开集，用 `Ua` 表示。这些图描述流形内的区域。此外，它们的并集覆盖 `M`。因此在图册中流形的每一点必须在某个图内具有坐标。伴随图册中的这些图始终存在函数 `fa`。这些函数满足 `fa`: `M`→`R^(*n*)`，其中 `fa` 和 `fa^(−1)` 是同胚。图称为坐标域，`fa` 称为坐标映射。通常当 `fbfa^(−1)` 具有 `k` 个连续导数，`k`=`1, 2, …` 时，图册连同相应的流形称为光滑的。据此，它们属于 `C^(*k*)`。更常见的是，光滑意味着无限可微。在图内，各种群结构将被视为具有局部坐标的 `n` 维向量空间。对于局部坐标系，恒等式在后续章节中将发挥特殊作用。通常，整个流形的全局坐标系是不可行的。例如，使用球面，只能展示局部表示。
