
在整个量子领域中，使用了极其广泛的代数结构，从最基本的正则对易关系（`CCR`）到求解椭圆曲线密码学的方法以及构建量子卷积神经网络的方法。本文的目的是提供嵌入这些代数结构中的底层原理的统一。实现这一统一的机制是多排序代数（`MSA`）（[Goguen 和 Thetcler, 1973](#Ch001_1-19_B9780443136979000199.xhtml#bib7)）。`MSA` 可被视为通用代数的扩展，如 [Gratzer (1969)](#Ch001_1-19_B9780443136979000199.xhtml#bib8) 所示。在这里，代数结构的各种类型以最一般化的方式描述，并通过态射显示对象之间的对应关系。量子学科中多排序或多种类型的代数概念的底层特征在 `MSA` 中通过严格规范以及复数图同时得到捕捉。本文受 [Birkhoff 和 Lipson (1970)](#Ch001_1-19_B9780443136979000199.xhtml#bib1) 及其异构代数的启发，以及 ([Goguen 和 Meseguer, 1986](#Ch001_1-19_B9780443136979000199.xhtml#bib6)) 对 `MSA` 的评述。

采用 `MSA` 呈现了全局层面和局部层面的精确规范。`MSA` 对于更好地理解量子及其与机器学习和量子神经网络技术的关系至关重要。从基本公理开始的希尔伯特空间概念以精确但高层次的方式详细说明（[Halmos, 1958](#Ch001_1-19_B9780443136979000199.xhtml#bib9)），而量子和机器学习的底层域则非常具体。在量子中，该域几乎总是复数；有时使用实数甚至四元数。然而，在机器学习中，主要使用的是实数域。这在支持向量机应用中尤其如此。

一般而言，量子希尔伯特空间可能是有限维的，可能由 ket 和 bra 组成，并且可能是相似希尔伯特空间的张量积，或如 `L²` 或 `l²` 那样的无限维（[Halmos, 1957](#Ch001_1-19_B9780443136979000199.xhtml#bib13)）。所有这些结构都将在局部层面得到精确探讨。这在指定将 `C*` 代数与希尔伯特空间联系起来的 Gelfand-Naimark-Segal（`GNS`）构造时再次显而易见（[Gelfand 和 Naimark, 1943](#Ch001_1-19_B9780443136979000199.xhtml#bib4)；[Segal, 1947](#Ch001_1-19_B9780443136979000199.xhtml#bib12)）。从实际观点来看，用于量子计算机的量子比特的希尔伯特空间被描述（[Feynman, 1986](#Ch001_1-19_B9780443136979000199.xhtml#bib3)）。其他应用包括量子神经网络和量子机器学习中的量子比特。

### 1.1.2 多排序代数方法论

为了开始描述 `MSA` 方法论，必须指定对象的排序集合。例如，术语 `scalar` 可能是该集合的一个元素。尽管术语 `scalar` 是通用的，它可能指的是来自实数或复数等域的元素。然而，它也可能代表四元数，即来自斜域或非交换域的元素。重要的是，对于每个排序，都有载体集合。正是这些集合唯一标识了所讨论元素的精确类型。例如，实域、复域、有理域或密码学中使用的有限域使用非常不同的载体集合。

一旦声明了排序，还必须给出操作符号。它们作为特定签名集合中的元素进行组织。这些集合用于识别符号之间的共同属性，如其 `arity`。操作符号表示诸如对称化、湮灭、产生等跨排序和内排序映射，以及基本运算：加法、乘法、求逆等等。

这些映射中实际使用的算子涉及与排序相对应的指定载体集合。这是在更低的视角下进行的。每个算子在定义域中使用来自指定载体集合的元素作为操作数。其值域也是如此。签名集合中的算子名称连同它们必须遵守的代数定律、规则、等式恒等式或关系一起列举。定律或等式恒等式包括对易规则、结合律、分配律、幂零规则，以及严格规范所必需的各种其他附加条件或关系。

使用由具有多尾有向箭头的节点组成的复数图，给出了涉及 `MSA` 的有用全局视图（[Goguen 和 Meseguer, 1986](#Ch001_1-19_B9780443136979000199.xhtml#bib6)）。箭头的全部实体都被标记。每个节点由一个圈注特定排序的圆圈表示。箭头附有算子名称，并如其签名集合中所声明的那样。箭头中尾部的数量对应于所讨论算子的 `arity`。`arity` 为零的算子没有尾部，并使用该排序的特殊元素的名称进行标记。这些包括 `zero`、`one` 和 `identity element`，以及 `top` 或 `bottom`。箭头的尾部从适当的签名集合中指定的定义域排序发出。箭头的单个头部指向算子的值域排序。简而言之，复数图提供了描述代数结构所需闭包运算的视觉描述。

`MSA` 中包含偏算子。这与在偏通用代数中所做的工作类似。然而，对于未在整个所表示的定义域排序上定义的运算，采用了特殊符号。其中大部分符号将在后面给出。包含依赖于定义域的算子在量子中至关重要，因为即使位置和动量算子也是无界的。无限维希尔伯特空间需要显式的定义域声明以及闭包条件。现在将给出一个算子未完全定义的更基本实例。在这里，域中的乘法逆元对除 `zero` 之外的所有值都有定义，因此它是一个偏算子。然而，该算子存在于 `MSA` 中。此外，在这种情况下，复数图描述中使用了带单个尾部的虚线箭头。

### 1.1.3 全局域结构

对应于域结构，只需要单一排序 `SCALAR`。存在多个签名集合。它们按 `arity` 组织。`Arity` 指的是给定签名集合中算子的操作数或参数的数量。`Arity` 也指复数箭头的尾部数量。对于二元算子，除非另有说明，否则它们应以任意顺序使用两个参数。对哪个参数先出现没有限制。

$\\begin{array}{l} \\left. {Binary}{operation}:{\\left\\{ {{ADD},{MULT}} \\right\\}}{each}{maps}{SCALAR} \\times {SCALAR}\\rightarrow{SCALAR} \\right. \\\\ \\left. {Unary}{operation}:{\\left\\{ {{MINUS},{INV}} \\right\\}}{each}{maps}{SCALAR}\\rightarrow{SCALAR} \\right. \\\\ {{Zero} - {ary}{operation}:{\\left\\{ {{ZERO},{ONE}} \\right\\}}{these}{are}{special}{elements}{of}{the}{sort}{SCALAR}.} \\\\ \\end{array}$
