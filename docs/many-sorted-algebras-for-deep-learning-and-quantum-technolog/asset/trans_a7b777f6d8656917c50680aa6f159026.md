## 1.1.9 有限时信号作为内积空间

考虑所有实值数字有限时信号或函数 `f`，其位于 `R^(Z)` 的子集中。这是对应于 `VECTOR` 的载体集合，而 `R^(Z)` 意味着这些函数定义域等于所有整数且结果为实值，`f: Z → R`。有限时意味着 `f` 只能在整数 `Z` 的某个有限子集上具有非零值。这些函数具有有限支撑，所有这些函数的空间将记为 `A`。请注意，`V-ZERO` 对应于 `A` 中的 0 向量。卷积神经网络（`CNNs`）采用有限时信号，既作为原始数据流，也作为滤波信号。应用包括一维声音、文本、数据、时间序列，以及 EKG 和 ECG 信号分类（[Ribeiro et al., 2020](#Ch001_1-19_B9780443136979000199.xhtml#bib11)）。

有界向量是 `A` 中 `f` 的便捷表示（[Giardina, 1991](#Ch001_1-19_B9780443136979000199.xhtml#bib5)）。`A` 中任何非零信号将在最小整数 `n` 处非零。在这种情况下，函数 `f` 的表示为 `(f(n) f(n+1) … f(n+k))[n]`，其中 `f(n+k)` 是 `f` 非零的最终值。有界向量可以全为零，但从实际观点看，`ZERO` 元素 `0` 将始终被采用。根据定义，此处的约定是 `k` 为非负整数。下标 `n` 是指向 `N` 中 `f` 第一个非零元素的指针。有界向量的通常逐点加法对应于名称 `V-ADD`。加号 `+` 以及 `V-ADD` 本身也将用于实际的逐点加法。如前所述，`V-ZERO` 表示 `A` 中的有界向量 `0`。对于前面提到的 `f`，有 `0 + f = f + 0 = f`。
