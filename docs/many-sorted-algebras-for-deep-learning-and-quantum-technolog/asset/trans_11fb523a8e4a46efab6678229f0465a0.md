
为了确定伴随算子是什么，在 *l*² 中取 `w`![方程](Images/F000138si169.png)。取 `<w, Tv>=w0∗v0+w1∗ 0+w2∗v1+w3∗ 0+w4∗v2+….` 该表达式等于 `<T∗w, v>=w′0∗v0+w′1∗v1+w′2∗ v2+w′3∗v3+w′4∗ 0+w′5∗v2+….` 使 `vk` 的元组系数相等，其中 `k=0, 1, 2, ….` 这意味着 `T∗(v0, v1, v2, …)=(v0, v2, v4, …)`。任意满足 `|c|<1` 的 `c` 都是 `T∗` 的特征值。为了看到这一点，使用 $v\\left( c \\right) = {sum},\\sum\_{k = 0}^{\\infty}{c^{k}v2^{k}}$![方程](Images/F000138si170.png)；然后 `T∗v(c)=T∗v1+the sum`，$\\sum\_{k = 1}^{\\infty}{c^{k}T \\ast v2^{k}}$![方程](Images/F000138si171.png)。首先，`T∗v1=0`，因为 1 是奇数。$T \\ast v(c) = {sum},\\sum\_{k = 1}^{\\infty}{c^{k}v2^{k - 1})} = {cv}(c)$![方程](Images/F000138si172.png)。由此可知 `c` 是 `T∗` 的特征值。因此，对于每一个满足 `|c|<1` 的 `c`，该值都是特征值。但是，由于谱总是闭的并且 `‖T∗‖=1`，因此 `sp(T∗)=sp(T)=闭单位圆盘`。

对于 `H` 上任意闭算子 `T`，`T∗` 的谱是集合 `{c∗, such that c is in spT}`；此外算子 `T∗` 在 `c` 处的预解算子满足 `Rz(c∗)=Rz (c)∗`。其中 `T` 在 `c` 处的预解算子为 `Rz (c)`。该结果类似于 `Lumer-Phillips` 结果。

## 13.8 自伴、正则和紧算子的谱

已知对于 `B(H)` 中的自伴算子，不存在剩余谱，而且谱总是实数。`B(H)` 中算子的近似特征值满足：对于任意 *ϵ*![方程](Images/F000138si173.png)\> 0，存在 `H` 中的单位向量 `v`，使得 `‖Tv−λv‖<ϵ`![方程](Images/F000138si174.png)。将 `v` 替换为 `w /‖w‖`（`w` 不为零），等价条件如下：对于任意 *ϵ*![方程](Images/F000138si175.png)\> 0，存在 `H` 中的非零向量 `w`，使得 `‖Tw−λw‖<![ε](Images/epsi_1013.png)‖w‖`；则 `λ`![方程](Images/F000138si176.png) 是 `T` 的近似特征值。所有这样的 `λ`![方程](Images/F000138si177.png) 的集合称为 `T` 的近似谱。记为 `A(T)`。如果 `T` 有特征值，则它属于 `A(T)`，因为 `Tv−λv` 恒等于零。此外，`A(T)` 是一个真正的谱，因为 `A(T)` 是 `spT` 的子集。该结果可由反证法得到。如果 `λ`![方程](Images/F000138si178.png) 不在 `spT` 中，则 `T−λI` 可逆。这意味着 `∥v∥=∥(T−λI)^(−1)`![方程](Images/F000138si179.png) `(T−λI) v∥` 小于或等于 `∥(T−λI)^(−1)∥∥Tv−λv∥`![方程](Images/F000138si180.png)，对每个向量 `v` 成立，即 `∥Tv−λv∥`![方程](Images/F000138si181.png) 大于或等于 `1/∥(T−λI)^(−1)∥∥v∥`![方程](Images/F000138si182.png)。令 `ϵ=1/∥(T−λI)^(−1)`![方程](Images/F000138si183.png)‖ 可知 `‖Tv−λ`![方程](Images/F000138si184.png) `v‖` 有下界，因此 `λ`![方程](Images/F000138si185.png) 不在 `A(T)` 中，这是一个矛盾。所以结论是 `A(T)` 总是 `spT` 的子集。

对于有界正规算子，除了前面提到的结果之外，还有更多结论成立；这里 `spT=A(T)`，这之前已提到。也就是说，对于正规算子 `T`，所有特征值都是近似的。需要证明的是 `spT` 是 `A(T)` 的子集。再次使用反证法。先假设 `spT` 中存在特征值 `λ`![方程](Images/F000138si186.png)，它不在 `A(T)` 中。那么对于某个 `ϵ`![方程](Images/F000138si187.png)\> 0，该特征值满足对所有非零 `v`，`‖Tw−λw‖` 大于或等于 ![ε](Images/epsi_1013.png)‖w‖。由于 `T` 是正规的，可知 `‖T∗w−λ∗w‖` 大于或等于 ![ε](Images/epsi_1013.png)‖w‖ 对所有非零 `v` 成立。因此 `‖Tw−λw‖` 和 `‖T∗w−λ∗w‖` 都有下界，见 [第13.1节](#Ch013_231-253_B9780443136979000138.xhtml#s0010)。如果能证明它们的值域是稠密的，则会产生矛盾，因为特别地，`Tw−λw` 将是可逆的。而不是证明值域稠密，等价于证明值域的正交补是 `{0}`。这因为 `ran(u)^⊥=ker(u*)`![方程](Images/F000138si188.png)，或 `ker(u*)^⊥=clos(ran(u))`![方程](Images/F000138si189.png)。所以如果 `v` 与 `Tw−λw` 正交，即 `<v, Tw−λw>=0` 对所有 `w` 成立，利用伴随算子，这等价于 `<T∗v- λ∗v, w>=0` 对所有 `w` 成立。后一个等式意味着 `T∗w−λ∗w=0`。然而，利用之前的有下界性质 `∥T∗w−λ∗w∥`![方程](Images/F000138si190.png) 大于或等于 `ϵ`![方程](Images/F000138si191.png)‖w‖ 可知 `w=0`。

对于正规算子，`T` 与 `T∗` 的特征值之间的关系很容易证明。下面的例子说明了这一事实

### 例 13.24

对于 `B(H)` 中的正规算子 `T`，如果 `T v = λ v`![方程](Images/F000138si192.png) 对 `H` 中的非零 `v` 成立，则 `T∗ v = λ∗ v`![方程](Images/F000138si193.png)。这可通过令 `A` 由 `T` 的所有特征向量组成，其中 `λ`![方程](Images/F000138si194.png) 是特征值来得到。然后由于 `T(T∗v)=T∗(Tv)=T∗ (λ v)=λ (T∗v)`，可知 `T∗v` 在 `A` 中。考虑内积 `<u, T∗v−λ∗v>`，假设 `u` 也在 `A` 中。由此可得 `<u, T∗v−λ∗v>=<u, T∗v>−<u, λ∗v>=<T u, v>−λ∗<u, v>=<λ u, v>−<λ u, v>=<T u−λ u, v>=0`。由于 `T∗v` 在 `A` 中，以及 `v` 的任意非零常数倍，可知 `T∗v−λ∗v` 在 `A` 中。进而可得 `T∗v=λ∗v`。

对于希尔伯特空间 `H` 上的紧自伴算子 `T`，其谱是实值的点谱，最多例外为零。零点可能是聚点，因此可能不在点谱中。在这种情况下，它属于连续谱。再次，算子 `T` 可表示为向特征子空间 `{an, such that Tv=an, for v nonzero in H}` 的投影的收敛和。也就是说，`Pn` 是向该特征子空间和 `an` 的投影，且 `T` 是和 `∑`![方程](Images/F000138si195.png) `(an Pn)`。另外，对于 `H` 中的任意 `w`，有 `Tw` 等于和 `∑`![方程](Images/F000138si196.png) `(an Pn(w))`。

### 例 13.25

考虑希尔伯特空间 `H` 上的紧自伴算子 `T`。这种算子可能只有点谱，且特征值为 0。因此，在这种情况下，0 不是聚点；它是孤立点。根据正规紧算子的投影定理，`perp(ker(T))` 不能是无限的。因为如果它有一个无限的 `ON` 基 `{ek}` 且 `Tek=ck ek`，并且 `ck→0`，则 0 不是孤立的（[Conway, 1990](#Ch013_231-253_B9780443136979000138.xhtml#bib2)）。因此，`perp(ker(T))` 是有限的，所以 `Ker(T)=0` 有无限维。并且可知存在可数无限个向量，它们的特征值都为 0。

如果 `T` 和 `S` 是 `H` 上的紧算子，则乘积 `TS` 和 `ST` 是紧的，伴随算子 `S∗` 和 `T∗` 也是紧的。此外，`T∗T` 是自伴且正的；因此它有非负特征值 `an`。当 `T` 的一范数有限时，紧算子 `T` 称为迹类算子。一范数是 `‖T‖`，它满足 `T∗T` 的特征值 `an` 的平方根之和是有限的。

对于迹类算子 `T`，迹定义如前：`Tr (T)` 是内积之和：`<en, T en>`，其中 `en` 是 `H` 上的 `ON` 基。此外，该级数必须绝对收敛且与所用的 `ON` 基无关。当 `T` 也是自伴时，则 `Tr (T)=T 的实特征值之和`。另外，对于 `H` 上的酉算子 `U`，有迹：`Tr(T)=Tr(U^(−1)T U)`![方程](Images/F000138si197.png)。见 [第7.5节](#Ch007_131-144_B9780443136979000205.xhtml#s0030)。
