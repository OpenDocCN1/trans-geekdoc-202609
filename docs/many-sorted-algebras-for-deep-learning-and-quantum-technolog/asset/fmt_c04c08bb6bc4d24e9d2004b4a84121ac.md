When the gap is large, the adiabatic process prevails and there is no change of trajectories. When the gap is small, say near zero, then the Rabi frequency `w[12]=|H[12]|/h` occurs in the rectangle, and a nonadiabatic process happens. Berry phase, `v[k]`![Equation](Images/F000217si160.png), is understood as a geometrical phase, whereas `θ[k]`![Equation](Images/F000217si161.png) is as usual a time-varying function. It is understood that the Berry phase describes a geometric path and only depends on evolution of space, but not on time. As a consequence, this leads to the Berry connection `A[k](R)=i<Ψ[k](R) |Δ[R] |Ψ[k](R)>`. Here, `R` is a vector in configuration space with `N` components, namely `R` is a vector in `R^(N)`![Equation](Images/F000217si162.png) and `Δ` is the gradient operation. Eigenvectors are not unique; any nonzero scalar times an eigenvector is also an eigenvector. However, states are of norm one. This implies that `Ψ[k]`![Equation](Images/F000217si163.png)(R)′=`e`^(−`i``b(R)`)`Ψ[k]`![Equation](Images/F000217si164.png)(R) is also an eigenvector provided that the quantity `b(R)` is real valued. Use the Berry connection with respect to the new eigenstate. Substituting in and using the gradient operation results in `A[k]`![Equation](Images/F000217si165.png)(R)′=`i<Ψ[k]`![Equation](Images/F000217si166.png)(R)`e`^( `i``b(R)` )![Equation](Images/F000217si167.png) |`Δ[R]`![Equation](Images/F000217si168.png) |`e`^(−`i``b(R)` )![Equation](Images/F000217si169.png) `Ψ[k]`![Equation](Images/F000217si170.png)(R)>=`A[k]`![Equation](Images/F000217si171.png)(R) + `Δ[R]`![Equation](Images/F000217si172.png)`b(R)`. This is the gauge transform under gauge connections. Intuitively, a gauge transform changes the scale, and it is the gauge connection, which provides the compensation between the original and new scale. Gauge transformation applied to the Berry phase is not gauge invariant. Because `γ[k]`![Equation](Images/F000217si173.png)(t)=∫[0]^(t)`v[k]`![Equation](Images/F000217si174.png)(t′)dt′,it can also be written only involving the geometric path in `R^(N)`![Equation](Images/F000217si175.png). This shows that the Berry phase cannot be observed unless the motion in the configuration space is a loop.
