## 15.1 Fock空间内的粒子和Fock空间结构
Fock空间是希尔伯特空间张量积的直和。它用于表示全同粒子希尔伯特空间`H`的各种态。在固定的Fock空间中，所有元素彼此不可区分。Fock空间中描述的主要粒子类型是玻色子和费米子。其他粒子，如带负电的离子，像任意子粒子，在此空间中未被描述。对于玻色子，采用了`n`个单粒子希尔伯特空间的对称化张量积之和。零粒子态、单粒子态、双粒子态，……。这些都是`H`与其自身的张量积。所有这些乘积都存在于Fock空间中。玻色子Fock空间是Weyl代数的一种表示。对于费米子，使用了单粒子希尔伯特空间的反对称化张量积。费米子Fock空间为Clifford代数提供表示。在这两种情况下，形成这些张量积的直和时都使用了希尔伯特空间完备化。Fock空间中元素的内积定义为各个希尔伯特空间内积的和与积。

### 例 15.1
对于希尔伯特空间`H1`中的向量`v1`和`w1`以及希尔伯特空间`H2`中的向量`v2`和`w2`，张量积`H1⊗H2`中向量的内积由`<v1⊗v2, w1⊗w2>=<v1, w1> <v2, w2>`给出。这是从各个希尔伯特空间相乘得到的内积，如[第7.4节](#Ch007_131-144_B9780443136979000205.xhtml#s0025)所示。#

一般而言，Fock空间的形式为`F`=直和，$\\sum\_{n = 0}^{\\infty}\\left\\lbrack {S\\left( {\\otimes H} \\right)^{n}} \\right\\rbrack$![Equation](Images/F000291si1.png)。这里，`S`是一个函数，根据它们是玻色子还是费米子，对张量执行对称或反对称操作。量`(⊗ H)^(*n*)`是`H`的张量积，`n`次。简言之，Fock空间`F`在本节中将以以下方式书写：它是`F`=(+) \[`S` (⊗ `H`)^(*n*)\]。这里，`n`=0, 1, 2,…, 且算符 (+) 表示从0到无穷的直和。因此，将上述表达式更详细地展开得到`F`=`C`+`H`+`S` (`H`⊗`H`)+`S` (`H`⊗`H`⊗`H`)+…. 在此表示中，`+`用于两个单独项的直和。量`C`是表示真空态的复数域，缩写为`vac`。`Vac`是不含粒子的态。希尔伯特空间`H`是单粒子的态，而`S` (`H`⊗`H`)描述两个全同粒子的态。两个全同粒子态也用`S` `H2`表示。类似地，`S` (`H`⊗`H`⊗`H`)描述三个全同粒子的态，将被记为`S` `H3`，以此类推。

需要上述代数直和的希尔伯特空间完备化。在此方向上，(+) `Hn`={(x0, x1, x2, …)}，其中`xj`在`Hj`中。此外，和`x0`+`x1`+`x2`+…必须满足和$\\sum\_{n = 0}^{\\infty}\\left\\| {xn} \\right\\|^{2} =$![Equation](Images/F000291si2.png) 和$\\sum\_{n = 0}^{\\infty}\\left\\langle {{xn},{xn}} \\right\\rangle,$![Equation](Images/F000291si3.png)，且该和小于无穷。最后，用第j个元组(0, 0,…, 0, `v`, 0, …)来识别`Hj`中的向量`v`，并使用记号`v`=`vj`。此外，当`j`不等于整数值`i`时，空间`Hj`与空间`Hi`正交。后一陈述意味着不同`n`值的`n`粒子子空间是正交的。

提供Fock空间态的额外但相关的概念是有用的。从对称Fock空间开始；它必须始终是无限维的。对于有限维希尔伯特空间`H1`，考虑具有特征向量`|ej>`、`j`=1, 2,…, `n`的可观测量，以及相应的特征值`aj`。当单个粒子占据第k个态时，这意味着特征态ket，`|ek>`=`|0, 0,…, 0, 1, 0, … 0>`，且1出现在第k个位置。相应地，在类似假设下，双粒子空间`H2`可能有两个粒子处于同一态，或一个粒子处于`n`个态中的两个不同态。例如，在玻色子Fock空间中，两个粒子处于同一态的可能性是两者都在第一态，`|2, 0,…, 0>`，或两者都在第二态，`|0, 2, 0,…, 0>`，依此类推到最后态`|0,…, 0, 2>`。此外，在任何Fock空间中，两个粒子可以分离：`|1, 1, 0 …, 0>`、`|1, 0, 1, 0,…, 0>`、…、`|0, … 0, 1, 1>`。这些都是两个粒子的所有可能态占据。需要认识到的重要一点是`H2`不是`H1`和`H1`的张量积。它同构于张量积的对称化直和，即`H`=`S` (`H1`⊗ `H1`)。简言之，在此情况下，`S` (`ha`⊗`hb`)=(`ha`⊗`hb`)+(`hb`⊗`ha`)。类似地，在`H3`中将有三个阶乘张量积的直和，即六种可能性。乘积态的线性组合是Fock空间中的一般态。

### 例 15.2
考虑`H2`；这是使用不同ket `{|0>, |0′>}`的双粒子希尔伯特空间。如前所述，涉及这两个ket的四个可能态存在；这些不同态由 `{|0 0>, |0 0′>, |0′ 0′>, |0′ 0>}`给出。每个态都有相等的被组装但未被观测的概率。存在三个对称可观测态和一个反对称态。按顺序为`|0 0>`、`|0′ 0′>`、`|0 0′>+|0′ 0>`，以及`|0 0′>−|0′ 0>`。前三个是玻色子态；它们类似于形式，`S` (`ha`⊗`hb`)=(`ha`⊗`hb`)+(`hb`⊗`ha`)。最后一个表达式将被证明是费米子态。#

## 15.2 玻色子占据数和梯子算符
在Fock空间中，不同粒子数子空间之间存在粒子跃迁。因此，粒子数不被保持；粒子可以被产生或湮灭，即被湮灭。这些元素可以从任何给定能量态中添加或移除。对应于这些功能的算符称为梯子操作。这些算符的实例见于[第14.8节](#Ch014_255-270_B978044313697900028X.xhtml#s0045)。在量子力学中，由梯子算符引起的这些跃迁被称为第二量子化，涉及希尔伯特子空间`Hn`和`H(n+−1)`的混合。梯子算符用于物理学的多个领域中提高和降低能量特征函数，以及改变角动量数的单位。算符的参数是像光子或准粒子像声子那样的粒子。
