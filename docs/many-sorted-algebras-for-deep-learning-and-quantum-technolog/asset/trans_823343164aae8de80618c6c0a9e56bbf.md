
为了证明自反性，即 `f` 在同伦方块中与自身同伦，令 `H(0, s)=H(1, s)=f(s)`，但也令 `H(t, s)=f(s)` 对所有 `t` 在 \[0, 1\]。这是一个常值映射，它以 `f(s)` 开始，并且当 `t: 0→1` 时，它保持在 `f(s)` 并最终到达 `f(s)`。接下来，为了证明对称性，如果 `f` 与 `g` 同伦，则存在一个同伦映射 `H(t, s)`。为了证明 `g` 与 `f` 相关，使用 `H(1−t, s)`。相应地，当 `t: 0→1` 时，`H(1, s)=g` 变为 `H(0, s)`，即为 `f`。最后，为了证明传递性，设 `F(t, s)` 提供从 `f(s)` 到 `g(s)` 的同伦。另设 `G(t, s)` 在 `g(s)` 与 `h(s)` 之间给出一个同伦。那么 `H(t, s)` 将在 `f(s)` 与 `h(s)` 之间给出一个同伦，当 `H(t, s)=F(2t, s)` 对 `t` 在 \[0, 1/2\] 时，且 `H(t, s)=G(2t−1, s)` 对 `t` 在 \[1/2, 1\] 时。注意在 `t=1/2` 时，`F(1, s)=G(0, s)`，它表示相同的点 `xo`。下一个例子将说明同伦的等价类。

### 示例 12.3

考虑 `R²` 中的 `x`、`y` 平面，但在 `(0, 0)` 处有一个针孔。这可以建模为原点处存在一根柱子，并使用绳子创建环。见 [图 12.3](#Ch012_217-230_B9780443136979000254.xhtml#f0020)。使用与 `(0, 0)` 不同的任意点 `xo` 作为起点和终点。不包围针孔的环与 `xo` 同伦；这起到了恒等的作用。这些环彼此同伦并形成一个记为 `\[I\]` 的等价类。稍后这个陪集将采用零的陪集代表元。属于 `\[I\]` 的环可以沿正方向，即逆时针，或沿反方向，即顺时针追踪。对于这个陪集，这并不重要；这些环都是等价的。所有这样的环都与 `xo` 同伦。这是因为所有这些环都可以连续收缩到 `xo`。与恒等不等价的环必须再次以 `xo` 为起点和终点，但现在还必须包围针孔。这些环与 `\[I\]` 中的环不同伦。从 `xo` 开始和结束并包围针孔的绳子的连续收紧永远不可能完全变形为点 `xo`，因为原点处的柱子在其内部。

![图 12.3 环的等价类。](Images/F000254f12-03-9780443136979.jpg)

图 12.3 环的等价类。

环包围针孔的次数存在不同的等价类。针孔从水平表面向上指向。对于逆时针包围，这些等价类用 `\[1\]`、`\[2\]`、`\[3\]`、… 表示，表示环完全包围或完全绕过针孔的次数。因此存在无限多个等价类。此外，这里方向很重要。因此，如果环 `g` 顺时针绕行且仅包围针孔一次，它不能属于 `\[1\]`，因为在 `\[1\]` 中的 `f` 与 `g` 之间找不到同伦。在这种情况下，`g` 属于 `\[−1\]`。类似地，如果一个环顺时针包围针孔 `n` 次，则它属于等价类 `\[−n\]`。这在 [图 12.3](#Ch012_217-230_B9780443136979000254.xhtml#f0020) 中有所说明。结果是每个整数都存在一个等价类，其中整数 0 对应于 `\[I\]` 中的 `I`。

所有环的等价类集合在函数的拼接下形成一个群。对于道路连通空间，环不必出现在同一点 `xo`；在这里，起点不同的环是同伦的。在这种情况下，同伦是通过以两种方式遍历连接不同初始点的路径来显示的。[图 12.4](#Ch012_217-230_B9780443136979000254.xhtml#f0025) 说明了该过程。在此图中，从初始点 `x1` 到 `xo` 的路径由 `h` 遍历，而从 `xo` 返回到 `xo` 的环由 `f` 遍历。然后轨迹使用函数 `h^(−1)` 返回到点 `x1`。通过让 `x1` 连续接近 `xo` 可得到同伦。总路径由 `h x (f x h^(−1))` 或 `(h x f) x h^(−1)` 给出。利用群的结合性，这些路径在同伦意义下相同。结合律稍后证明。

## 12.3 MSA 对基本群的描述

在 MSA 描述中，单一类型 `ELEMENT` 的载体集合是所有环的等价类集合。等价类应写为 `\[f\]`，表示与 `f` 同伦的所有环，但在本节中并非如此。应理解等价类在没有通常记号的情况下使用，即只使用 `f` 而不是 `\[f\]`。另外在图中，环及其定义函数均由表示连续函数 `f` 和 `g` 的符号表示，从而创建这些环。符号 `~` 用于表示等价。`MULT` 这里是拼接而不是函数的复合。因此，二元情况下的操作顺序是先使用左环或操作数；然后在 `MULT` 中使用右参数。多态图在 [图 12.5](#Ch012_217-230_B9780443136979000254.xhtml#f0030) 是提醒二元运算顺序的采用。如常，多态箭头的尾部对第一个操作数有一个单破折号。`MULT` 在多态箭头中的第二个尾部用两个斜线标记第二个操作数。签名集合内的所有群运算名称如下：

* `MULT(f, g)`: \[0, 1\] x \[0, 1\]→`T`，其中 `T` 是一个拓扑空间。
* `MULT(f, g)(s)=f(2 s)` 当 `s` 在 \[0, 1/2\] 时且 `=g(2 s -1)` 当 `s` 在 \[1/2, 1\] 时。
* `INV`: `f^(−1) (s)=f(1−s)` 当 `s` 在 \[0, 1\] 时。
* `IDENTITY`: `e(s)=xo` 对所有 `s` 在 \[0, 1\]。

![图 12.5 基本群的多态图。](Images/F000254f12-05-9780443136979.jpg)

图 12.5 基本群的多态图。

通常的等式恒等式必须对群结构成立。这里，为方便起见，替换或使用：

* `ELEMENT` 用 `A`、`B`、`C` 代替。
* `MULT(A,B)` 用 `A x B` 代替。
* `IDENTITY` 用 `I` 代替。
* `INV(A)` 用 `A^(−1)` 代替。

等式恒等式以下写为严格恒等式，但它们实际上在涉及等价类的同伦下成立；除非巧合，否则它们不逐点成立：

1. 1) 结合律：`(A x (B x C))=((A x B) x C)`.
2. 2) 恒等条件：`I x A=A x I=A`.
3. 3) 逆元：`A^(−1) x A=I` 是左逆元，且 `A x A^(−1)=I` 是右逆元；两者都必须对群结构成立。

多态图在 [图 12.5](#Ch012_217-230_B9780443136979000254.xhtml#f0030) 说明了同伦中使用的运算符名称。

[图 12.6](#Ch012_217-230_B9780443136979000254.xhtml#f0035) 说明了如果 `f~f′` 且 `g~g′`，则 `MULT(f, g)(s)~MULT(f′, g′)(s)`。在此图中，有一个道路连通的拓扑空间 `T`，具有同等环 `f` 和 `f′` 与同伦 `H`，以及同等环 `g` 和 `g′` 与同伦 `K`。此外在此图中是同伦方块，`K` 在内部上方，位于 `s=1/2` 上方，而 `H` 在同伦方块内部的下半部分。左侧是上方为 `g` 下方为 `f`。右侧是上方为 `g′` 下方为 `f′`。这里，`MULT(f, g)(s)=f(2 s)` 当 `s` 在 \[0, 1/2\] 时，且 `=g(2 s −1)` 当 `s` 在 \[1/2, 1\] 时。这本质上表明对于等价类，拼接类型的乘法是良定义的。注意在 `s=1/2` 时，`f(1)` 等于 `g(0)`；这表明它们相等，事实上等于 `xo`。
