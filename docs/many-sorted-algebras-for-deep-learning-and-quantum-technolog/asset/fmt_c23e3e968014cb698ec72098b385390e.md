
Recently, there has been a surge of papers and articles on quantum versions of CNN, QCNN ([Hur et al., 2022](#Ch018_327-348_B9780443136979000163.xhtml#bib6)). They are used in classical machine learning classification contexts and exploit entanglement. QCNNs are also employed in conventional image processing applications such as spatial filtering, edge detection, as well as handwritten symbol recognition ([Wei et al., 2022](#Ch018_327-348_B9780443136979000163.xhtml#bib14)). As in the past, research continues using machine learning devices to classify high-energy events in physics. An instance of this research is the article [Chen et al., (2022)](#Ch018_327-348_B9780443136979000163.xhtml#bib3). Another instance of this type of application can be found in [Hermann et al. (2022)](#Ch018_327-348_B9780443136979000163.xhtml#bib5). In this report, QCNNs are utilized on a superconducting quantum processor for recognizing quantum phases. Some papers explain how QCNNs can be implemented using quantum circuits ([Zheng et al., 2022](#Ch018_327-348_B9780443136979000163.xhtml#bib17)). In this article, a universal QCNN model is proposed consisting of all three: the convolutional layer, the pooling layer, and a fully connected NN layer. Several papers have emerged on medical-type applications using QCNNs ([Magallanes et al., 2022](#Ch018_327-348_B9780443136979000163.xhtml#bib8)).

## Reproducing kernel and other Hilbert spaces

### Abstract
The chapter begins with an algebraic solution to the harmonic oscillator. The key to the solution is the creation ladder operator cyclic property. This leads to the Hermite polynomial solution. Section 19.2 begins the description of the reproducing Hilbert space over the complex field. The Hardy disk algebra is also introduced in this section, as well as the Bargmann kernel and the Jordan algebra. The following section illustrates the reproducing Hilbert space over the real field. The next section is dedicated to Mercer’s theorem along with examples of Fredholm-type integral equations of the second kind. The spectral theorem involving projective-valued measures is described in the next section. Following this is the Riesz-Markov theorem. The next section provides examples of nonseparable Hilbert spaces. In particular, the nonseparable Hilbert space of almost periodic functions is illustrated. The chapter ends with proof that all separable Hilbert spaces are isometrically isomorphic To `l²`.
