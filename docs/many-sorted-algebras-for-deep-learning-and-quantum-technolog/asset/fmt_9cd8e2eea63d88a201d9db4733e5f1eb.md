
In [Section 6.1](#Ch006_103-128_B9780443136979000217.xhtml#s0010), the ground-state solution to the harmonic oscillator is shown to be equal to `Ψ[0]` = (`m w[0]`/(`π h`))^(1/4) `e`^(− `m w[0] x²`/(2 `h`))![Equation](Images/F000278si1.png). The solution was obtained by solving a first-order differential equation and normalizing a Gaussian-type kernel. The normalization involved finding `N`=`(m w[0]/(π h))^(1/4)`. For the general quantum harmonic oscillator, the time-independent Schrodinger equation is as follows: − `h`²/(2 `m`)∂² `Ψ`(`x`)/∂ `x`∂ `x` + 1/2 `m w[0]² x² Ψ(x)` = `E Ψ(x)`![Equation](Images/F000278si2.png). The objective is to find the allowed energy states `E`, as eigenvalues and their corresponding eigenfunctions, `Ψ`![Equation](Images/F000278si3.png) (`x`). These functions should be normalized and either symmetric or antisymmetric about `x`=0. Moreover, the probability density function, |`Ψ(x)`|²![Equation](Images/F000278si4.png), must be finite over the interval (−∞, ∞).

Following the excellent presentation provided in [Hall (2013)](#Ch019_349-364_B9780443136979000278.xhtml#bib5), the solutions for higher energy, that is, the solutions for excited state levels, will be found in a purely algebraic manner. In the referenced text, one can find important domain issues concerning the unbounded creation and annihilation operators used in this development. From an algebraic viewpoint, the key identities involve the ground state, `Ψ[0]`![Equation](Images/F000278si5.png). First, using the annihilation operation `a` yields `a |Ψ[0]> = 0`![Equation](Images/F000278si6.png). Second, there exist cyclic properties for the creation operation `a†`:(`a†`)^(`n`) |`Ψ[0]`> = `Ψ[n]`![Equation](Images/F000278si7.png), where `n` is a nonnegative integer. See [Section 15.2](#Ch015_271-288_B9780443136979000291.xhtml#s0015) for details on the cyclic property of `a†`. A result of the cyclic property is that the excited state `Ψ[n] = H[n] Ψ[0]`![Equation](Images/F000278si8.png). Here, `H[n]`![Equation](Images/F000278si9.png) is a polynomial of degree `n`, and it can be found using induction, starting with `H[0] = 1`![Equation](Images/F000278si10.png). Additionally, these polynomials are called the Hermite polynomials. They are orthogonal on (−∞, ∞), a consequence of being solutions to a Sturm-Liouville differential equation. See Appendix A.7. Using the Rodrigues formula for Hermite polynomials: `H[n] = (−1)^(n) e^(x²) d^(n) e^(− x²)/d x^(n)`![Equation](Images/F000278si11.png), `n`=0, 1, 2, … gives, for instance, `H[0]=1`, `H[1]=2 x`, `H[2]=4 x²–2`, and `H[3]=8 x³–12 x`, …

Accordingly, the wave function solutions are `Ψ[n] = N H[n](b x) e^(− (b x)²/2)`![Equation](Images/F000278si12.png), where `b = [(m w[0])/h]^(1/2)`![Equation](Images/F000278si13.png). These solutions have corresponding eigenvalues given by allowable discrete energy levels `E[n] = (2 n+1) h w[0]/2`, `n = 0, 1, 2, …`![Equation](Images/F000278si14.png) [Fig. 19.1](#Ch019_349-364_B9780443136979000278.xhtml#f0010) illustrates the even symmetry for even-numbered wave functions and odd symmetry for the odd-numbered wave functions. Moreover, when the horizontal coordinate is zero, there is either an extreme point or a zero crossing for each wave function. The zero crossings occur mod2, starting with `Ψ[0]`, and local maxima occur mod4, and so do the local minima.

## 19.2 Reproducing kernel Hilbert space over C and the disk algebra

To begin, a useful and intuitive definition of `H` being a reproducing kernel Hilbert space (RKHS) over `X` means that `H` is a Hilbert space of complex-valued continuous functions over the nonempty set `X`. So, `H` is a subset of `C^(X)`![Equation](Images/F000278si15.png). Also, for all functions or vectors, `f` and `g` in `H`, and `ϵ`![Equation](Images/F000278si16.png)> 0, there exists a `δ`![Equation](Images/F000278si17.png)> 0, such that if ‖`f−g`‖<`δ`![Equation](Images/F000278si18.png), then |`f(x)−g(x)`|<`ϵ`![Equation](Images/F000278si19.png). Accordingly, this means that the functions are point-wise continuous. Using RKHS, boundedness and continuity are not related. To see that this is a subtle requirement, consider the following illustration.

### Example 19.1

Let `H` be the Hilbert space of complex-valued absolute squared functions, on [0, 1]. Consider the two functions `f=t` on this closed interval and `g=t` on [0, 1) and `g(1)=4 + 3i`. In this case, ‖`f−g`‖=0; however, sup |`f−g`|=5. These functions are bounded, but not continuous.#

In the previous example, it was shown that boundedness in the Hilbert space plays no role in point-wise calculations as far as continuity is concerned. A function `K`: `X²→C` is called a reproducing kernel of `H`, whenever `H` contains all unary functions for `x` in `X`, where `K[x]` (`y`)=`K` (`x`, `y`), and for every `x` in `X` and `f` in `H`, then `f` (`x`)=<`f`, `K[x]`>. The last property is the actual reproducing property.

The key to a rigorous approach for creating a RKHS and relating it to the reproducing property is the Riesz representation theorem (`RRT`): For a Hilbert space `H`, with inner product <·,·>: `H x H→C` and any continuous linear functional `ϕ`![Equation](Images/F000278si20.png) in `H*`, there exists a unique vector `f[ϕ]`![Equation](Images/F000278si21.png) in `H` such that `ϕ(v) = < v, f[ϕ] >`![Equation](Images/F000278si22.png), for all `v` in `H`. Additionally, the norms are equal, that is, ∥`f[ϕ]`∥ = ∥`ϕ`∥![Equation](Images/F000278si23.png). The first norm is in `H`, and the second norm is in `H*`, where‖`ϕ`![Equation](Images/F000278si24.png)‖=inf {`C`> 0 such that |`ϕ`![Equation](Images/F000278si25.png) (`v`)|< `C`‖`v`‖ for all `v` in `H`}.

Getting back to the RKHS, there is a linear evaluation functional `E[x]:H→C`![Equation](Images/F000278si26.png) (or `R` in the next section), such that `E[x](f) = f(x)`![Equation](Images/F000278si27.png) is bounded. By the `RRT`, every bounded linear functional is given by an inner product with a unique vector in `H`; thus for every `x` in `X`, there is a unique function `K[x]`![Equation](Images/F000278si28.png) in `H` such that for all `g` in `H`, `g(x) = < g, K[x] >`![Equation](Images/F000278si29.png). Following [Putnam (2019)](#Ch019_349-364_B9780443136979000278.xhtml#bib9), `K[x]`![Equation](Images/F000278si30.png) is called the reproducing kernel at the point `x`. The reproducing kernel for `H` is `K`: `X x X→H`, and it is defined by `K(x,y) = < k[y], k[x] >`![Equation](Images/F000278si31.png). Also, |`E[x]`|² = < `k[x]`, `k[x]` > = ∥`k[x]`∥² = `K(x,x)`![Equation](Images/F000278si32.png). So a reproducing Hilbert space `H`, over `C`, contains a reproducing kernel `K`, having the reproducing property, <`K(., x)`, `f`>=`f(x)`, for all `x` in `X` and `f` in `H`. Additionally, if there exists a reproducing kernel, then `H` is a RKHS. That is, the linear evaluation function `E[x]`![Equation](Images/F000278si33.png) is bounded. Here, `E[x](f) = < K(.,x), f > = f(x)`![Equation](Images/F000278si34.png), and so by the CBS inequality, it follows that |`E[x](f)`|![Equation](Images/F000278si35.png) is less than or equal to ∥`K(.,x)`∥∥`f`∥ = < `K(.,x)`, `K(.,x)` >^(1/2)∥`f`∥ = `K(x,x)^(1/2)`![Equation](Images/F000278si36.png)‖`f`‖, and so `E[x](f)`![Equation](Images/F000278si37.png) is bounded and |`E[x]`|![Equation](Images/F000278si38.png) is less than or equal to `K(x,x)^(1/2)`![Equation](Images/F000278si39.png).
