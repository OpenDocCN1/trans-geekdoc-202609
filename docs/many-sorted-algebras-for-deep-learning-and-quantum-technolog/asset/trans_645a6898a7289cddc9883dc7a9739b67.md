
`T` 的图是 `graph(T)={(v, Tv) such that v is in domT}`。映射 `T: A → B` 在图 `A×B` 中是闭的，当且仅当它是具有 `Tychonoff` 拓扑的乘积空间 `A×B` 的闭子集。等价地，假设 `v[n] → v`，对于所有 `v[n]` 和 `v` 在 `A` 中，并且也假设 `T v[n] → w`，对于所有 `T v[n]` 和 `w` 在 `B` 中，若 `Tv=w`，则 `T` 有界。

### Sturm–Liouville 微分方程及其推论
Sturm–Liouville 方程是一个二阶线性微分方程（DE），涉及函数 `p`、`q` 和 `r` 以及参数 `λ`![Equation](Images/F000102si1.png)。该 DE 由 `(p(x)y')' + (q(x) + λ r(x)) y = 0` 给出。撇号表示导数。Sturm–Liouville 问题由上述 DE 以及一个定义域组成，例如区间 `(a, b)`。它还包含该区间闭包端点处的边界条件。此外，假设 `p`、`p'`、`q` 和 `r` 在定义域上连续，其中 `p'` 表示 `p` 的导数，且函数 `p > 0`，在该定义域上。函数 `r` 通常表示为 `w` 并称为权重。参数 `λ`![Equation](Images/F000102si3.png) 并非先验指定。它作为非平凡解的一部分被找到，在这种情况下称为特征值。DE 的解称为对应于特征值的特征向量或特征函数。

DE 可以重构为函数希尔伯特空间 `H` 中的自伴算子。`H` 中的内积定义如下：`< f , g > = ∫[a]^[b] f* g dx`![Equation](Images/F000102si4.png)。主要参考文献是 [Bochner (1929)](#AppendixG_387-389_B9780443136979000102.xhtml#bib2) 和 [Birkhoff and Rota (1978)](#AppendixG_387-389_B9780443136979000102.xhtml#bib1)。Sturm–Liouville DE 的解在各种边界条件下存在，特别是当它们被称为可分离时。在这种情况下，存在实值标量 `c[1]`、`c[2]`、`d[1]` 和 `d[2]`，使得 `c[1]^2 + c[2]^2 > 0`![Equation](Images/F000102si5.png)，且 `d[1]^2 + d[2]^2 > 0`![Equation](Images/F000102si6.png)，其中边界条件成立：`c[1] y(a) + c[2] y'(a) = 0` 且 `d[1] y(b) + d[2] y'(b) = 0`。Sturm–Liouville DE 连同上述边界值（BVs）构成一个系统，其中 DE 和 BV 具有

1. 解，由区间 `(a, b)` 中的特征函数 `y[n](x)` 组成。它们在标量倍数意义下唯一。区间可能在一个或两个方向上延伸到无穷大。相应的特征函数在此区间内有 `n-1` 个零点。
2. 特征值；每个特征函数都有一个唯一的实特征值，并且它们按顺序排列 `λ[1] < λ[2] < λ[3] < …`
3. 加权希尔伯特空间。归一化特征函数构成加权 L² 希尔伯特空间中函数的 ON 基。内积 `<y[n], y[m]>` 由加权积分给出：`∫[a]^[b] y[n](x) y[m](x) u(x) dx = zero`![Equation](Images/F000102si7.png)，除非 `n = m`，此时积分在归一化后等于一。

从实际角度来看，找到权重 `u(x)` 是最重要的标准，因为它定义了 L² 中希尔伯特空间的内积。简而言之，对于线性算子：`L(y) = a y'' + b y' + c y`，权重函数为 `u = e^(∫ (b - a')/a dx)`![Equation](Images/F000102si8.png)。下面将对此进行说明，针对几个重要的多项式类。在开发所有权重函数之后，Hermite 多项式和 Laguerre 多项式将详细介绍。

#### 示例 G.1
Legendre 多项式：`L(y) = (1 - x^2) y'' - 2x = λ y`。则 `u = e^(∫ (b - a')/a dx) = e^0 = 1`![Equation](Images/F000102si9.png)。对于区间 `[-1, 1]` 上的这些函数，使 `L` 自伴不需要边界条件。Legendre 多项式 `y[n]` 构成一个 ON 基，内积为 `∫[-1]^1 y[n](x) y[m](x) dx = zero`![Equation](Images/F000102si10.png)，除非 `n = m`；此时积分可以归一化为一。将特征值代入后的 DE 为 `(1 - x^2) y'' - 2x - n (n+1) = 0`。

#### 示例 G.2
Hermite 多项式：`H(y) = y'' - 2x y' = -λ y`。则 `u = e^(∫ (b - a')/a dx) = e^(∫ (-2x) dx) = e^(-x^2)`![Equation](Images/F000102si11.png)。对于 `(-∞, ∞)` 上的这些函数，Hermite 多项式构成一个 ON 基 `∫[-∞]^∞ y[n](x) y[m](x) e^(-x^2) dx = zero`![Equation](Images/F000102si12.png)，除非 `n = m`；此时积分可以归一化为一。

#### 示例 G.3
Laguerre 多项式：`L(y) = x y'' + (1 - x) y' = -λ y` 在 `[0, ∞)` 上。则 `u = e^(∫ (b - a')/a dx) = e^(∫ (-1) dx) = e^(-x)`![Equation](Images/F000102si13.png)。它们构成一个 ON 基 `∫[0]^∞ y[n](x) y[m](x) e^(-x) dx = zero`![Equation](Images/F000102si14.png)，除非 `n = m`；此时积分可以归一化为一。

#### 示例 G.4
谐振子：`H(y) = 1/2 (-h^2/m y'' + m (w[0] x)^2) y = λ y`。则解构成一个 ON 集。权重 `u = e^(∫ (b - a')/a dx) = e^0 = 1`![Equation](Images/F000102si15.png)。在这种情况下，特征函数在 L² 中。因此，在这种情况下权重函数为一。

#### 示例 G.5
合流超几何方程：`L(y) = x y'' + (c - x) y' = λ y`。权重为 `u = e^(∫ (b - a')/a dx) = e^(∫ (c - x - 1)/x dx) = |x|^(c - 1) e^(-x)`![Equation](Images/F000102si16.png)。DE 为 `x y'' + (c - x) y' + n y = 0`。

#### 示例 G.6
Chebyshev 多项式：`L(y) = (1 - x^2) y'' - x y' = λ y`，`L(y) = (1 - x^2) y'' - 3 x y' = λ y`。首先，它在 `[-1, 1]` 上是自伴的。权重 `u = e^(∫ (b - a')/a dx) = e^(∫ x/(1 - x^2) dx) = 1/(1 - x^2)^(1/2)`![Equation](Images/F000102si17.png)。`∫[-1]^1 y[n](x) y[m](x) / (1 - x^2)^(1/2)`![Equation](Images/F000102si18.png) `dx = zero`，除非 `n = m`；此时积分可以归一化为一。将特征值代入 DE 后的 DE 为 `(1 - x^2) y'' - x y' + n^2 y = 0`。

#### 示例 G.7
Jacobi 多项式：`L(y) = (1 - x^2) y'' + (e x + g) y' = λ y`，在 `[-1, 1]` 上。权重 `u = e^(∫ (b - a')/a dx) = e^(∫ (e x + g - 2x)/(1 - x^2) dx)`![Equation](Images/F000102si19.png)。对于 `g = -1, -2, -3` 且 `e = 0`，Jacobi 多项式分别变为 Legendre 和 Chebyshev 多项式。如果 `-e < g < e`，则 DE 为 `(1 - x^2) y'' + (e x + g) y' + [n (n - 1) - n e] y = 0`。

许多特殊函数类可以用几种不同的方式定义或描述。对于 Hermite 多项式，它们满足以下条件：

1. 微分方程：`h'' - 2 x h' + 2 n h = 0`，或以 Sturm–Liouville 微分方程形式，`e^(-x^2) h'' - 2 x e h' + 2 n e^(-x^2) h = 0`
2. Rodrigues 公式：`h_n = (-1)^n e^(x^2) d^n e^(-x^2) / dx^n`，`n = 0, 1, 2, …`。
3. 差分方程：`h(n+1) - 2 x h_n + 2 n h(n-1) = 0`
