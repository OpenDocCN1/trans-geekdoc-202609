

一般线性群 `GL(2, R)` 是一个四维的光滑流形；它是 `R⁴` 的一个非紧开子集。如前所述，该李群由 2×2 实值矩阵表示，其行列式非零。它是不连通的，并且有两个对应于行列式符号的连通分支。行列式为正的元素称为正分支，并包含 `IDENTITY`。它本身也是一个李群，记为 `GL+(2, R)`。`GL(2, R)` 和 `GL+(2, R)` 具有相同的李代数 `m(2, R)`。`m(2, R)` 中的李括号是代数乘法 \[A, B\]，其等于 `AxB−BxA`，例如当 `A=I` 时可以等于零。因此，李代数不是除法代数。`GL(2, R)` 的极大紧子群是 `O(2, R)`，即正交李群，其在后续章节中详细描述。对于 `GL+(2, R)`，极大紧子群是特殊正交群 `SO(2)` ([Jacobson, 1979](#Ch011_191-216_B9780443136979000126.xhtml#bib11))。这些子群将在随后讨论。

拓扑空间 `T` 当它是道路连通的，并且 `T` 中的每条环路都可以连续收缩到一点时，称为单连通。严格来说，它是描述 `T` 中环路的两个连续函数 `f` 和 `g` 之间的同伦。设 `f: [0, 1] → T`，`g: [0, 1] → T`，`f(0)=g(0)`，`f(1)=g(1)`。那么，这两条路径定义了一个环路。环路的性质将在第 12 章中更详细地解释，其中同伦是主要概念。

李第三定理指出，每个有限维实李代数都是一个单连通李群的李代数。本质上，单连通性将是建立实情形下李群与李代数之间一一对应关系的判据。最后，当李群是连通的、非阿贝尔的，并且所有闭连通子群都是平凡的，即它们等于单位元或整个空间时，称其为单李群。

下图 [图 11.3](#Ch011_191-216_B9780443136979000126.xhtml#f0020) 展示了两条连续路径。这显示了道路连通性，但从分析或实际观点来看，单连通性是有问题的。这里设 `f(t)=t sin(π /(2t))` 对 `t` 在 `(0, 1]`，且 `f(0)=0`。那么 `f` 在区间 `[0, 1]` 中是连续的，因为它在原点满足条件 `|f(t)|` 小于或等于 `|t|`。因此 Lipschitz 条件对 `f` 在原点成立。另外，设 `g(t)=2t – t²`。由于 `f(0)=g(0)` 且 `g(1)=f(1)`，它们一起形成一个环路。然而，将此环路收缩到一点，例如零，需要做很多工作，因为函数 `f` 不是有界变差的。`[0, 1]` 中的总变差等于求和，$\\sum\_{n = 0}^{\\infty}{\\left( {1/\\left( {2n + 1} \\right)} \\right) = \\infty}$![方程](Images/F000126si8.png)。因此，对应于该函数的曲线不可求长，直观上其弧长是无限的。

### 例 11.9

特殊李群 `SL(2, R)` 是 `GL(2, R)` 的子群。该子群 `SL(2, R)` 由所有行列式等于一的 2×2 矩阵组成。它是连通的、非紧的，并且是单群。`SL(2, R)` 不是单连通的；然而，`SL(2, C)`，即复特殊群，后续将被证明是单连通的。`SL(2, R)` 的维数是三，因为行列式的约束。极坐标形式参数化，及其他参数化，可以用于该群的元素。事实上，`SL(2, R)` 的元素可以写成正交旋转矩阵与具有正特征值和单位行列式的对称矩阵的乘积。相应的李代数 `sl(2, R)` 由所有实数上的迹为零的 2×2 矩阵 `A` 和 `B` 组成。二元运算通常是李括号交换子。因此，\[A, B\]=`AxB−BxA`。

涉及 `SL(2, R)` 中元素的众多应用之一是利用修正的偏心率参数 `e` 对圆锥曲线进行分类，参见 (SL[2](R), 维基百科)。这涉及 Cayley-Hamilton 方程。每个矩阵都满足其特征方程。因此，对于 `SL(2, R)` 中的 `A`，`A` 的特征方程为 `x²−tr(A) x + det(A)=0`，并且由于 `det(A)=1`，特征方程变为 `x² −tr(A) x + 1=0`。二次公式给出特征方程的解 `x`：

*x* = (*t**r*(*A*)+−(*t**r*(*A*)²−4)^(1/2))/2.*L**e**t**t**i**n**g**e* = |*t**r*(*A*)|/2*t**h**e**n*:

![方程](Images/F000126si9.png)

*   对于 `e <1`，`A` 是椭圆的，具有复数、单位和共轭特征值，用于旋转。

*   对于 `e=1`，`A` 是抛物线的，具有单个特征值 +1 和 −1，用于剪切操作。

*   对于 `e> 1`，`A` 是双曲的，具有实数倒数特征值，用于挤压操作。

前一示例中提到的双曲情形算子也来自射影线性李群 `PSL(2, R)`。它们在闵可夫斯基空间中用作洛伦兹提升。在此情形中采用双曲函数 `sinh` 和 `cosh`，提供了对称双曲空间。后一性质意味着 `cosh²–sinh²=1` ([Bargmann, 1947](#Ch011_191-216_B9780443136979000126.xhtml#bib1))。
