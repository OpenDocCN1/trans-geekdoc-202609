## Operators on Hilbert space
### Abstract
The first section provides an MSA view of the vector space consisting of all linear operators from a vector space into another vector space. The inner product is shown to be a nonlinear operation. Also included in this section is the definition of the numerical range along with examples. Closed operators are described in the next section, and this is followed by the most important class of functions, the bounded functions in a Hilbert space, `H`. The bounded functions are shown to be equivalent to the continuous functions on `H`. Pure states and pure tensors are given along with the density operator. A more rigorous description of entanglement is also provided. Section 7.5 introduces the trace class operators. The next section describes the Hilbert-Schmidt class of operators, and of extreme importance, the Cauchy-Bunyakovsky-Schwarz inequality is given with illustrations. The final section of the chapter provides a description of the class of compact operators.

#### Keywords
Endomorphism; automorphism; closed operators; bounded operators; pure tensor; pure state; entanglement; trace class; Hilbert-Schmidt operators; compact operators

### 7.1 Linear operators, a MSA view
Among the most fundamental operators employed in quantum technologies are the linear maps. All operators in this document will be linear unless specified otherwise. They satisfy the linearity condition mentioned later. Numerous examples of these maps have been seen before; they include linear maps that are linear in both arguments. Also included are multilinear operations and tensor maps. Both of which are linear in all their operands. However, conjugation is not linear, and so the inner product is also nonlinear; it is only linear in the second argument. This type of nonlinearity, being conjugate linear only in the first argument and linear in the second argument, is called sesquilinear. The set of all linear maps involving vector spaces `V` and `W` over the complex field `C` or `R` itself forms a vector space. In this description utilizing the `MSA`, it follows that there are four sorts: `V-VECTOR`, `W-VECTOR`, `C-SCALAR`, and `L-VECTOR` all using suggestive notation. In particular, the last sort denotes the sort of all linear maps, `L(V,W)` from vector space `V` into vector space `W`.

All the signature sets for the vector space structures and field structure are as before and will not be repeated. However, a new signature set containing a unary operator name `LIN` exists and is such that:

`LIN`: `V-VECTOR` → `W-VECTOR`

Additionally, to be linear, there is a single constraint that must be satisfied. It involves vector spaces with sorts `V-VECTOR` and `W-VECTOR` along with corresponding scalar multiplication and vector addition operational names. To see this, first, replace all names with suggestive symbols, that is,

* `LIN` by `T`
* `V-VECTOR` by `u`, `v`
* `Vv-ADD` by `+`
* `Sv-MULT` by `·`
* `W-VECTOR` by `w`
* `Vw-ADD` by `+[2]`
* `Sw-MULT` by `·[2]`
* `C-SCALAR` by `a`

The linearity condition is as follows:

1. 1) Linear: `T (a · u + v)=a ·[2] T (u) +[2] T (v)`

As previously mentioned, the set of all linear maps from `V` to `W` is denoted by the name `L(V,W)`. It itself becomes a vector space when point-wise addition and scalar multiplication are defined in `L(V,W)`. Additionally, for this fourth sort, that is, `L-VECTOR` also needed is the corresponding equational identity to ensure that `L(V,W)` is a true vector space. As before, the signature sets associated with `L-VECTOR` involve scalar multiplication, `SL-MULT`, and vector addition `VL-ADD`.

So represent as follows:

* `L-VECTOR` by `S`, `T`
* `VL-ADD` by `+[3]`
* `SL-MULT` by `·[3]`

Actually, `S` and `T` mentioned earlier are themselves linear mappings from vector space `V` into vector space `W`.

The vector space condition needed for maps in `L(V,W)` is as follows:

1. 2) Linearity: `((a ·[3] S) +[3] T) (v)=a ·[2] (S (v)) +[2] T (v)`
