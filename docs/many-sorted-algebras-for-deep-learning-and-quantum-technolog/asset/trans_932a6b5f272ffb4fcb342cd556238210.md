## 14.8 Stone-von Neumann 与量子力学等价性
Stone-von Neumann 定理在证明海森堡量子力学表述与薛定谔表述之间的等价性方面很重要。特别地，海森堡表述保持态矢量不随时间变化，而可观测量和其他算符是时间相关的。薛定谔表述的特点是态矢量随时间演化。幺正算符 `U(t, to)` 产生从时间 `to` 到稍后时间 `t` 的态矢 `|v(to)>` 的时间演化。它使用跃迁操作发生：`|v(t)>=U(t, to)|v(t)>`。薛定谔方程涉及哈密顿量 `H`，为 `i h∂|v>/∂t`，即 `ih∂ (| v(t)>)/∂t=H |v(t)>`。当存在时间无关性时，`H` 对 `t` 的偏导数为零。时间演化算符 `U(t)` 必须满足 `ih∂(|U(t))/∂t=HU(t)`。由于 `P` 和 `Q` 是无界的，因此必须陈述域问题，因此将更深入地描述 `CCR` 的薛定谔表述。Stone 和 von Neumann 都证明了该表述在幺正等价意义下是唯一的（[Hall, 2013](#Ch014_255-270_B978044313697900028X.xhtml#bib3)）。
在薛定谔表述中，函数 `f` 的域为 `S`，它是 `L²(R)` 的一个子空间，由快速衰减函数组成，例如 Schwarz 函数 `S(R)`。它也可以是具有连续 n 阶导数的函数，`C^(n)`![方程](Images/F00028Xsi56.png)，甚至是绝对连续函数 `AC`。例如，对于动量算符 `P`，`P: S →`![方程](Images/F00028Xsi57.png)` S`，绝对连续性已足够，且几乎处处存在的导数也在 `L²`![方程](Images/F00028Xsi58.png) 中。`P` 的另一个域是 `Dp`，它是 `L²(R)` 中所有函数 `p(x)` 的集合，使得 `wF(p)(w)` 在 `L²(R)`![方程](Images/F00028Xsi59.png) 中，其中 `F(p)(w)` 是 `p(x)` 的傅里叶变换。此外，对于位置算符 `Q`，`Q: S →`![方程](Images/F00028Xsi60.png)` S`，还需要乘法运算 `t f(t)` 在 `L²`![方程](Images/F00028Xsi61.png) 中。因此，同时处理这两个算符时，必须采用这些类型域的交集 `D`。此外，假设 `Q` 和 `P` 在该域闭包上是自伴的或只是本质自伴的。算符 `P` 和 `Q` 在该域上满足 `CCR`，即 `[P, Q] (f)=−if` 在 `D` 上成立。此外，`[P, P]=[Q, Q]=0`。

真空态 `|0>` 是能量最低的态。它也被称为基态或零点场。这里，湮灭操作在此态中的期望值为零。电场和磁场以及矢势也是如此；它们的期望值为零。然而，场算符平方的期望值不为零。在场论中，真空是没有粒子的矢量。此外，在 Garding-Wightman 公理中，真空态被假设为唯一的、Poincare 不变态（[Wightman, 1976](#Ch014_255-270_B978044313697900028X.xhtml#bib11)）。此外，真空被假设为循环矢量。真空态是一个相干态；这意味着它是湮灭操作 `a` 的唯一本征态，对应的本征值为 `a^`，即 `a^|a> = a|a>`。换句话说，相干态在场效应的湮灭下保持不变。

## 14.9 辛向量空间——多类型代数方法
辛向量空间是具有额外二元运算 `SKEW` 的实向量空间或复向量空间。域和向量空间的所有其他算符和等式恒等式仍然成立。新的算符是双线性的，且满足：
`SKEW: VECTOR x VECTOR → SCALAR`.
![方程](Images/F00028Xsi65.png)
该结构的多项图在 [图 14.4](#Ch014_255-270_B978044313697900028X.xhtml#f0025) 中给出，其中仅说明了涉及类型 `VECTOR` 的箭头。附加的等式恒等式首先通过替换给出：
* `VECTOR` 用 `u, v` 替换。
* `SKEW` 用 `S` 替换。
![图 14.4 辛向量空间的多项图。](Images/F00028Xf14-04-9780443136979.jpg)
[图 14.4](#Ch014_255-270_B978044313697900028X.xhtml#Bf0025) 辛向量空间的多项图。
恒等式如下：
1. 1) 交替 `S (u, u)=0`。
2. 2) 非退化 `S (u, v)=0`，对所有 `v` 成立则推出 `u=0`。
注意 `S (u, v)=− S (v, u)`。这可通过使用 `S (u+v, u+ v)=S (u, u) + S (u, v)+S (v, u)+S (v, v)=0` 得到，所以 `S (u, v)+S (v, u)=0`。

### Example 14.15
可从辛向量空间 `V` 形成海森堡群的抽象。这里，对于实值向量空间，乘积空间 `V x R` 是定义域。对于 `V` 中的 `v` 和 `w` 以及 `R` 中的 `t` 和 `r`，群律为 `(v, t) x (w, r)=(v+w, t+r+S (v, w)/2)`，其中 `S` 是对应于 `SKEW` 的运算。根据 MSA 表征：
`IDENTITY = (0,0)`
![方程](Images/F00028Xsi66.png)
`INVERSE (v, t)=(−v,−t)`，因为 `S (v,−v)=− S (v, v)=0`，这是双线性性的结果。
`MULT ((v, t), (w, r))=(v+w, t+r+S (v, w)/2)`，注意 `MULT ((v, t), (−v,−t))=(v−w, t−t+S (v, −v)/2)=(0, 0)`。
作为载体集，考虑类型 `VECTOR` 为 `V=R²`，具有对应于向量空间签名集的通常运算。此外，假设与 `SKEW` 相关的运算为 `S (v, w)=v′ H w`。这里，`v` 和 `w` 是 2×1 实向量，`v′` 是 `v` 的转置，而 `H` 是主对角线元素为零的斜对称 2×2 矩阵；因此 `H′=−H`。
