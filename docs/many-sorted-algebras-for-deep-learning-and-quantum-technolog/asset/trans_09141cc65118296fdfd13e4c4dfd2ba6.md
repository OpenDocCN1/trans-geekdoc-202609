
## 椭圆曲线点运算

虽然 `ECC` 的阿贝尔群结构和群运算是最重要的，但在 `ECC` 中有两种在应用中占主导地位的运算。这些是点或弦加法和点倍加运算。两种方法都源于使用基本微积分技术来描述几何方法。对于点加法，使用两个点 `(x1, y1)` 和 `(x2, y2)`，两者都在 `EC` 上并由 `EC` 上的一条直线非垂直线连接。然后，第三个点 `(x3, −y3)` 位于同一条直线上，并且也在 `EC` 上。当该点关于 x 轴反射时，结果 `(x3, y3)` 被称为前两个点的点加法。接下来，点上的倍加运算是通过找到 `EC` 上一点 `(x1, y1)` 的一条非垂直切线来实现的。该线将与 `EC` 相交于一点，其关于 x 轴的反射产生 `(x3, y3)`。结果称为原切点的倍加。点加法和倍加运算在附录 A.3 中有详细图形描述。现在这些运算可从基本微积分中得出，并相对于 `EC` 的短 Weierstrass 标准形式 `y²=x³+ax+b` 在代数上给出。

对于弦加法或两点加法：
* 斜率为 `s=(y2−y1)/(x2−x1)`。
* x 坐标为 `x3=s²−x1−x2`。
* y 坐标为 `y3=s(x1−x3)−y1`。

对于倍加或双切线方法：
* 斜率为 `s=(3x1²+a)/(2y1)`。
* x 坐标为 `x3=s²−x1−x1`。
* y 坐标为 `y3=s(x1−x3)−y1`。

一个示例将说明这些方程的使用。

### 示例 17.13

考虑 `EC` `y²=x³+6x+2` 在 `F[7]` 上。这里，`a=6`，且 `b=2`。首先，注意 `4a³+27b²=864+108=972`。现在将该数量除以 7 并保留最小非负余数得到 `F[7]` 中的 6，因此它不为零，且 `EC` 不是奇异的。首先将采用两点弦方法。使用 `(0, 3)` 和 `(1, 3)` 作为要相加的两个不同的点对。这些点在 `EC` 上。使用 `(0, 3)` 并代入 `EC` 可知 `y²=2`。该平方有解 `y=3`，以及 `y=4`，因为将两者平方都得到 2，从而提供载体集 `F[7]` ![方程](Images/F000023si129.png) 中的唯一数字。在任何情况下，使用这两个点，即 `(0, 3)` 和 `(1, 3)`，得到斜率 `s=0`，`x3=−1=6`，`y3=−3`。因此，点加法得到 `(6, −3)`，该点在曲线上。代入 `EC` 得到 `(−3)²=2`，且 `y²=6³+6·6+2=216+36+2=254=36·7+4=2`。接下来，将使用 `EC` 上的点 `(2, 1)` 说明切线倍加方法。快速代入 `EC` 可知 `1²=2³+6·2+2=22=1`。斜率为 `s=(3·2²+6)/(2)=9=2`。因此，x 坐标为 `x3=2²−2−2=0`。y 坐标为 `y3=2(2−0)−1=3`。因此，新的点为 `(0, 3)`。如前所述，该点在 `EC` 上。此示例中的 `EC` 如 [图 17.6B](#Ch017_307-325_B9780443136979000023.xhtml#f0035) 所示。这里，点加法和切点倍加的相应过程大致以图形方式说明。

在一般情况下，其中 `EC` 为 `y²=x³+ax+b`，接下来将描述一些未被上述方程涵盖的代数计算。对于点加法，使用两个点 `(x1, y1)` 和 `(x2, y2)` 由一条直线连接，该直线在 `EC` 上为垂直线，结果为无穷远处的单位元 `∞` ![方程](Images/F000023si130.png)。这也可以看出，因为在这种情况下，`(x2, y2)=−(x1, y1)=(x2, −y2)`，导致单位元，第三个点 `(x3, y3)` 为 `∞` ![方程](Images/F000023si131.png)。对于切线倍加方法也是如此：如果切线是垂直的，第三个点为 `∞` ![方程](Images/F000023si132.png)。最后，如前所述，当点 `∞` ![方程](Images/F000023si133.png) 加到 `EC` 上的任何其他点 `z` 上，包括其自身，结果为 `z`。

### 示例 17.14

再次考虑 `EC` `y²=x³+6x+2` 在 `F[7]` 上。参考 [图 17.6B](#Ch017_307-325_B9780443136979000023.xhtml#f0035) 给出的图表。在该图表中，两个点 `(1, 3)` 和 `(1, −3)=−(1, 3)=(1, 4)` 被说明，并且穿过这两个点的垂直线得到点 `∞` ![方程](Images/F000023si134.png)。

对于具有伽罗瓦域 `F[p]` ![方程](Images/F000023si135.png) 的 `EC` `E`，元素形成一个阿贝尔群。群的阶，即其基数 `#E`，必须被精确知道，在 `ECC` 中就是这种情况。然而，一般情况下，模 `p` 上的 Hasse 定理为 `#E` 提供了界限（[Cassels, 1991](#Ch017_307-325_B9780443136979000023.xhtml#bib3)）。这些是下界和上界；具体来说，`p+1−2p^(1/2)` ![方程](Images/F000023si136.png) 小于或等于 `#E`，而 `#E` 又小于或等于 `p+1+2p^(1/2)` ![方程](Images/F000023si137.png)。这些界限将通过一个示例来说明。

### 示例 17.15

考虑 `EC` `E: y²=x³+1`，使用伽罗瓦域 `F[11]` ![方程](Images/F000023si138.png)。由于 `p=11`，Hasse 定理表明 `E` 的基数 `#E` 是位于区间 `[11+1−2·11^(1/2), 11+1+2·11^(1/2)]=[5.4, 18.6]` 中的整数。对于该曲线，载体集为 `E={∞` ![方程](Images/F000023si139.png)`, (10, 0), (0,10), (0, 1), (9, 2), (9,9), (6, 3), (6, 8), (8,4), (8, 7), (3, 5), (3, 6)}`。实际基数为 `#E=12`。为了验证点 `(0, 10)`，即验证该点是否在 `E` 中，注意当 `x=0` 时 `y²=1`。如果 `y=10`，`y²=100`，并且当该数除以 11 时，最小的正余数为 1；注意 `−10=1`。

回到 `ECC`，称为 `ECDLP` 的离散对数问题利用具有本原元素 `a` 的 `EC`，即 `EC` 上的点对 `(x, y)`。该元素使用点加法和切线倍加运算生成 `EC` 上的所有点。特别地，点 `t=c+c+…+c` 是 `EC` 上 `n` 次跳跃。起始点 `c` 是公钥 `c`，是 `EC` 上的点对。整数 `n` 是秘密或私钥；它是整数且未知。然而，`n` 与 `c` 的乘积，即 `t`，为所有用户所知。在区块链等实际应用中，使用的大素数非常大，如前所述。`E` 的载体集的基数 `#E` 非常大，`n` 也是如此。由于 `n` 仅为私有用户所知，值 `n·c` 可使用下面指定的算法有效地求出。然而，已知 `c` 和 `n·c`，几乎不可能找到 `n`。如 [第 17.9 节](#Ch017_307-325_B9780443136979000023.xhtml#s0050) 中所述量子计算机的使用使破解代码变得更简单。

快速算法来求 `n·c` 需要正整数 `n` 的二进制表示。这里，最左边的位是最重要的且为 1。从下一个最重要的位开始并工作到最低有效位，如果出现 1，则首先对 `c` 执行倍加切线运算；然后随后执行两点加法运算。如果二进制表示中出现 0，则仅采用倍加切线运算。一个示例将说明该方法。

### 示例 17.16

由于 `n` 为私有用户所知，`n·c` 可由上述算法确定。这里假设 `n=1·2⁵+1·2⁴+1·2¹+1=51`，且其二进制表示为 `(1 1 0 0 1 1)`。从 `EC` 上的点对 `c` 开始，倍加得到 `2·c`，随后点加法得到 `3·c`。下一个二进制数字为零，因此仅使用倍加，得到 `6·c`。再次，下一个数字为倍加，因此结果为 `12·c`。下一个数字为一，因此必须执行两个 `EC` 运算。首先倍加得到 `24·c`，随后点加法得到 `25·c`。最后一位为一，因此倍加提供 `50·c`，点加法给出最终结果 `51·c`。
