
Shor 的贡献（[Shor, 1997](#Ch017_307-325_B9780443136979000023.xhtml#bib10)）主要在于将此因式分解问题转化为在循环群中寻找生成元周期的一个问题。周期的值也称为群的阶。在前一节中，循环群 `Z[n]`![Equation](Images/F000023si89.png) 已在环绕信号的上下文中引入。现在，它将在介绍 Shor 周期性问题的方向上更正式地描述。以下内容刻意避免使用等价类，直到本节末尾描述划分为止。代数和数论背景将现在概述。从正整数 `N > 1` 开始，欧拉 totient 函数 `ϕ(N)` ([Landau, 1966](#Ch017_307-325_B9780443136979000023.xhtml#bib14)) 是介于 1 和 `N` 之间（含）且与 `N` 互质或相对素数的全部整数集合的基数。重要情况是当 `N` 是两个素数 `p` 和 `q` 的乘积时，即 `N = p·q`。欧拉 phi totient 集合将使用载体集描述，`Φ(N) = {n, such that n is an integer less than or equal to N, n > 0, gcd(n, N) = 1}`。通常，`gcd` 是最大公约数，且该集合由与 `N` 互质或互素的整数 `n` 组成。

重要的是，`Φ(N)` 中的元素集合在模 `N` 乘法下形成阿贝尔群型代数结构。以下呈现中称其为欧拉 totient 群。对于 `Φ(N)` 中的 `x` 和 `y`，`x·y` 也在 `Φ(N)` 中，因为 `gcd(x·y, N) = 1`，因此模 `N` 的乘法运算满足闭包。结合律和交换律源于整数的类似性质。数字 1 是 `Φ(N)` 中的单位元，且 `x` mod `N` 的乘法逆元是 `Φ(N)` 中的整数 `y`，使得 `x·y = 1 mod N`。逆元性质的证明依赖于 Bezout 引理 ([Ore, 1948](#Ch017_307-325_B9780443136979000023.xhtml#bib12))。由 `ϕ(N)` 推导出的一个重要结果是 `Φ(N)` 的基数，即欧拉 totient 群的基数，是 `(p−1)(q−1)` 的乘积，其中 `p·q = N`，且 `p` 和 `q` 为素数。

### 示例 17.4
如果 `N = 14`，则载体集由 `Φ(14) = {1, 3, 5, 9, 11, 13}` 给出。注意 9 在 `Φ(14)` 中，因为同时整除 9 和 14 的最大整数是 1，而 8 不在此集合中，因为 `gcd(8, 14) = 2`。此外，说明阿贝尔乘法群结构，观察到 `9·3 mod 14 = 13`，因为 27 除以 14 的余数为 13。还有，`1/11 mod 14` 等同于求解问题 `11·? = 1 mod 14`，其中“？”必须在载体集 `Φ(14)` 中。解为 `1/11 = ? = 9`，因为 `9·11 = 99`，除以 14 后余数为 1。该阿贝尔群的单位元是 1。最后，`Φ(14)` 中元素的个数是 `(7−1)(2−1) = six`，这是 totient 函数的值。

所需且前面提到的循环群是 `Φ(N)` 的一个子群 `G[a]`![Equation](Images/F000023si90.png)。循环群由欧拉 totient 群中的元素 `a` 生成。循环群在模 `N` 下是乘法的，由 `{1, a¹, a², …, a^(r)}` 组成。使 `a^(r) = 1`![Equation](Images/F000023si91.png) 成立的最小正整数 `r` 最为重要，因为 `r` 称为 `a` 的周期，或循环子群的阶。值 `a` 称为循环群 `G[a]`![Equation](Images/F000023si92.png) 的生成元。最无聊的情况是如果 `a = 1`，则默认周期为 `r = 0`。

### 示例 17.5
对于 `N = 15`，欧拉 totient 群 `Φ(15) = {1, 2, 4, 7, 8, 11, 13, 14}`。这是一个非常重要的例子，因为它首次被用于用量子技术实验性地求解 Shor 问题 ([Vandersypen et al., 2001](#Ch017_307-325_B9780443136979000023.xhtml#bib6))。为说明周期性，令 `a = 4`，则 `G[4] = {1,4}`![Equation](Images/F000023si93.png)，且 `a` 的周期为二，因为 `4² = 16`，但此值 mod 15 为 1，因为 16 除以 15 的余数为 1。考虑 `G[7] = {1, 7, 4, 13}`。在这种情况下，周期为四。它是 `Φ(15)` 的该子群中元素的个数。

为说明周期性，如余弦波或正弦波的图像，考虑函数 `f: Z[+] → G[a]`，对于 `Φ(N)` 中某个非单位元 `a`。这里，`Z[+]` 是所有非负整数，且 `f(n) = a^(n)`。绘制 `n` 与 `f(n)` 的关系图会很有用。

## 17.9 Shor 问题 的 解法
涉及整数因式分解的密码学问题由 Shor 用量子计算在多项式时间内解决。如前所述，这比传统解法快指数级。过程大致分为两个阶段：首先，类似于 Deutsch-Jozsa 算法，利用量子并行性和建设性干涉来确定函数的周期性，而不是看其是否平衡。接下来，使用 `QFT` 找到循环群生成元 `a` 的周期。从工程角度看，`QFT` 用于确定频率 = 1/周期。无论如何，正是后一个过程在使用 Shor 算法时产生了指数级加速。此外，实际上采用了量子相位估计与幺正操作。随机选择这些算子的本征值可导致确定所需的周期 `r`。

Shor 提出用于确定 `N` 的因子 `p` 或 `q` 的实际步骤总结如下。它们将以欧拉 totient 群 `Φ(N)` 的术语描述；因此，所有计算均在模 `N` 下进行，`N` 为非常大的正整数。另为设定密码学类型操作的背景，假设 `N = p·q`，其中 `p` 和 `q` 为素数。按顺序执行步骤：

1. 1) 选择 `(1, N)` 中的随机整数 `a`；幸运的猜测是该值不属于欧拉 totient 群 `Φ(N)`。
2. 2) 计算 `k = gcd(a, N)`；欧几里得算法是标准程序。
3. 3) 如果 `k` 不同于一，则它必须是 `p` 或 `q`，搜索结束，否则继续。
4. 4) 找到所选值 `a` 的周期 `r`，即找到循环群 `G[a]`![Equation](Images/F000023si95.png) 的阶。
5. 5) 如果 `r` 为奇数，选择区间 `(1, N)` 中的不同元素 `a`，并从步骤 2) 的计算开始重复步骤，否则继续。
6. 6) 乘积 `(a^(r/2) + 1)·(a^(r/2) − 1) = 0`，因此 `N` 的因子是 `gcd(a^(r/2) + 1, N)` 和 `gcd(a^(r/2) − 1, N)`。这两个数可能是 `p` 和 `q`，但以低概率它们可能是 1 和 `N`。这些是因子。然而，如果后者发生，则从步骤 1) 开始并重复该过程。

