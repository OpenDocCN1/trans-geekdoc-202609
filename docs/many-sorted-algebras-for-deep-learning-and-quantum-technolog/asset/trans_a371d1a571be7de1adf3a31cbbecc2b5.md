
## 8.1

考虑空间 `B=C([0, 1])`，其中 `B` 中 `g` 的范数由 `‖g‖=max |g(x)|` 给出，`x` 在 `[0, 1]` 中，如 [示例 8.1](#Ch008_145-164_B9780443136979000059.xhtml#enun1) 中所用。这次，我们证明该赋范向量空间不是内积空间。因此，它也是一个巴拿赫空间的例证，该空间不能成为希尔伯特空间。所采用的主要工具是平行四边形法则。首先，设 `f` 也是 `B` 中的一个向量。平行四边形法则不成立，因为恒等式 `‖f+g‖²+‖f−g‖²=‖f‖²+‖g‖²` 不成立。取 `f=g=x`，则 `‖g‖=max |g|=‖f‖=max|f|` 对 `x` 在 `[0, 1]` 中为一，但 `‖f+g‖²=4`。

从巴拿赫空间 `B1` 到巴拿赫空间 `B2` 的算子 `T` 被称为有限秩是指 `T` 的像是一个 `B2` 的有限维子空间。`B (B1, B2)` 中的任意算子是指 `T` 是从 `B1` 到 `B2` 的线性有界算子。如果它也是有限秩的，则 `T` 是紧算子。这里，`T` 的像是位于 `B2` 中以 `0` 为中心、半径为 `‖T‖` 的开球内。更一般地，从 `B1` 到 `B2` 的所有紧算子的集合本身是 `B (B1, B2)` 的一个向量空间子空间。此外，如果 `B (B1, B2)` 中有限秩算子的序列 `T0, T1, T2,…` 收敛于 `T`，则 `T` 是紧算子（[Conway, 1990](#Ch008_145-164_B9780443136979000059.xhtml#bib4)）。

特别地，当 `B (B1, B2)` 中的 `T` 为秩一时，则存在 `B1` 中范数为一的向量 `v`，使得存在唯一的泛函 `f (w)`，其中对所有 `w` 在 `B1` 中有 `T w=f (w) v`。`T` 的线性性表明 `f` 是线性的，并且 `|f (w) |=‖T w ‖` 小于或等于 `‖T‖ ‖w‖`，表明 `f` 有界。如果这也是一个希尔伯特空间 `H`，则由 RRT，即由里斯表示定理，该有界线性泛函也是一个内积；因此，对某个 `u` 在 `H` 中有 `f (w)=<u, w>`，从而 `T w=<u, w> v`。一般地，对于秩为 `n` 的有限算子 `T`，可使用 ON 集 `{v1, v2,…, vn}`，以及相应的泛函得到 `$T w = \\sum\_{k = 1}^{n}{< {uk},w > {vk}}$`![方程](Images/F000059si3.png)。下面有一个非常有趣的例子。它表明在巴拿赫空间中存在有限秩的无界算子（[Lacey, 1973](#Ch008_145-164_B9780443136979000059.xhtml#bib9)）。

### 示例 8.3

设 `B1` 为 `C` 上的无限维巴拿赫空间。将给出一个无界算子 `T` 的例子，该算子具有有限秩。设 `M` 是 `B1` 的 Hamel 基。该基通过选择公理的应用总是存在，并且是不可数的。设 `L` 是 `M` 的一个可数无限子集 `{e[n], n=1, 2,…}`。设 `T: L→C`，其中 `T(e[n])=n·e[n]`，并且对所有 `v` 在 `M−L` 中有 `T(v)=0`。`(M−vL)` 的维数至少等于连续统。`T` 的值域维数为 1，因此是有限秩的但不是有界算子。

## 8.2 可交换与不可交换巴拿赫代数

尽管所有巴拿赫代数具有相同的整体 MSA 结构，但在这些代数的载体集合上出现了很大的差异。其中最大的区别因素之一是它们是否可交换。这由众多例子说明。

### 示例 8.4

设 `VECTOR` 的载体集合为所有 `n` 阶 `n` 复矩阵，`A`。它是复数域上的一个不可交换巴拿赫代数。设 `NORM` 利用该载体集合以及由复数组成的相应载体集合，以及所有通常的复矩阵运算。这里，设 `NORM` 的运算为 `A` 的所有绝对平方项之和的平方根。这就是 Frobenius 或 Hilbert-Schmidt 范数。另见 [第 7.6 节](#Ch007_131-144_B9780443136979000205.xhtml#s0035)。Frobenius 范数满足范数的四个约束方程。为此，首先替换：

* `MATRIX` 为 `A`, `B`
* `SCALAR` 为 `a`
* `C-MULT` 为 `x`
* `V-ONE` 为：`I`
* `BINE` 为 `·`
* `NORM` 为 `‖‖`

1. 1) 正定性：`‖A ‖> 0`，且 `‖A‖=0` 当且仅当 `A=0`。
2. 2) 齐次性：`‖a A‖=|a|‖A‖`
3. 3) 三角不等式：`‖A+B ‖` 小于或等于 `‖A‖+‖B‖`
4. 4) 三角乘积不等式：`‖A·B ‖` 小于或等于 `‖A ‖‖B‖`。

当 (4) 成立时，范数被称为次乘性的。

为看出 (4) 成立，使用 Frobenius 范数，设 `D=A·B` 在 `C^(n)` 中。则 `D` 中的典型元素为 `$d\_{ij} = \\sum\_{k = 1}^{n}a\_{ik} \\cdot b\_{kj}$`![方程](Images/F000059si4.png)。另外，`${|d\_{ij}|}^{2} = {|{\\sum\_{k = 1}^{n}a\_{ik} \\cdot b\_{kj}}|}^{2}$`![方程](Images/F000059si5.png) 由 CBS 不等式；结果是 `|d[i j]|`![方程](Images/F000059si6.png)|² 小于或等于 `$\\left\\lbrack {\\left( {\\sum\_{k = 1}^{n}{|a\_{ik}|}^{2}} \\right) \\cdot \\left( {\\sum\_{k = 1}^{n}{|b\_{kj}|}^{2}} \\right)} \\right\\rbrack$`![方程](Images/F000059si7.png)。因此，`‖D‖²=‖A·B‖²` 小于或等于 `$\\sum\_{i = 1}^{n}{\\sum\_{j = 1}^{n}{\\sum\_{m = 1}^{n}{\\sum\_{k = 1}^{n}{|a\_{im}|}^{2} \\cdot}}{|b\_{kj}|}^{2}) = \\left( {\\sum\_{i = 1}^{n}{\\sum\_{m = 1}^{n}{|a\_{im}|}^{2}}} \\right)} \\cdot \\left( {\\sum\_{j = 1}^{n}{\\sum\_{k = 1}^{n}{|b\_{kj}|}^{2}}} \\right) = \\left\\| A \\right\\|^{2} \\cdot \\left\\| B \\right\\|^{2}$`![方程](Images/F000059si8.png)。

### 示例 8.5

一个重要结果是，对于 `B(H)` 中的 `T` 以及 `H` 中的单位向量 `v` 和 `u`，则有 `‖T‖=sup |<Tu, v>|`。该结果源于前一个例子，即将使用示例 7.14。在那里，证明了 `‖w‖=sup |<w, v>|` 其中 `‖v‖=1`。

因此通过注意到 `Tu` 是 `H` 中的一个向量来使用所引用的例子。相应地，设 `w=Tu`；则从前述例子可得，`‖Tu‖=sup|<Tu, v>|`，因为 `‖v‖=1`。使用算子范数 `‖T‖=sup|Tu|`，当 `‖u‖=1` 时。因此，通过回溯代入，`‖T‖=sup|sup|<Tu, v>||=sup|<Tu, v>|`，如所愿。

### 示例 8.6

一个可交换巴拿赫代数的简单例子涉及复平面上非空子集 `S` 中所有有界函数的载体集合。它记为 `A`。对于 `A` 中的任意函数 `f` 和 `g`，逐点加法运算 `(f+g) (z)=f (z)+g (z)` 是封闭的。标量乘法也是如此，其中标量 `a` 在 `C` 中，`a (f (z))=af (z)`。此外，所有等式恒等式对向量空间结构成立。此外，它是一个含幺结合代数，即 `f·g` 在 `A` 中。这是因为 `(f g) (z)=f (z) g(z)`，`V-ONE` 为 `1`，且 `|1|=1`。最后，它是使用范数 `‖f‖=sup|f (z)|` 的巴拿赫代数，`z` 在 `S` 中，并注意到三角乘积不等式平凡成立。事实上，它是等式，`|f·g|=|f|·|g|`。此外如同在 `C*` 代数中，`|f·g*|=|f|·|g*|`。

### 示例 8.7

位置 `P` 与动量 `M` 算子不可交换。以下仅是对结果的正式表述。参见后面提到的参考文献。`P` 与 `M` 的不可交换性可通过交换子运算 `[P, M|=P M −M P]` 看出，这是李代数的基础。可交换意味着该李括号为零。然而，它等于 `i` 乘以普朗克常数 `h` 再乘以恒等式 `I` 的运算。该结果通过取任意连续可微的 `f`，以及绝对平方可积函数希尔伯特空间 `L2` 中的 `x f` 得到。然后使用动量算子 `P` 和乘法算子 `M`。这里，`P` 使用 `Pf=−ihd(f(x))/dx` 定义，而乘法算子为 `Mf=xf(x)`。因此根据求导乘积法则，`PMf(x)=−ihd(x f(x))/dx=−ih(f(x))+x d(f(x))/dx=−hif+MPf(x)`，因此恒等式 `[P, M]= −ihI` 或 `[M, P]=ihI` 成立。该恒等式通常称为正则对易关系 (CCRs)（[McCoy, 1929](#Ch008_145-164_B9780443136979000059.xhtml#bib10)）。
