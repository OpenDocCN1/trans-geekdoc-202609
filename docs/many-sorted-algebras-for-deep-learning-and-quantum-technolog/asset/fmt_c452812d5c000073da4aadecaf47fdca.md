## 3.10 Complex-valued wraparound digital signals
It is instructive to illustrate the use of the complex field structure before quantum applications are provided. In this direction, consider `C^(*Zn*)`; these are bound signals with complex entries, and they too form a Banach\* algebra, as well as a Hilbert space; for the proof, see Appendix A.1. The conjugation operation for Banach\* and C\* algebras is more important in this instance. The following example illustrates the conjugation operation in the inner product operations. The convolution of functions is also found along with the convolution involving conjugate functions. The results can be compared to illustrate the five equational identities needed to describe a Banach\* algebra.
### Example 3.16
Consider the two bound vectors `f` and `g` in `C^(*Zn*)` with `i=$\\sqrt{- 1}$`![Equation](`Images/F000175si75.png`), `f=(2 0 3i 2+i 0)[0]^(*W*5)`, and `g=(2i 0 3+2i 0 i)[0]^(*W*5)`. In order to find `f ⋆`![Equation](`Images/F000175si76.png`) `g`, the same parallel algorithm can again be used. Indeed, `f ⋆`![Equation](`Images/F000175si77.png`) `g`=`g ⋆`![Equation](`Images/F000175si78.png`) `f`=`2TRAN(g; 0) + 3i TRAN(g; 2) + (2 + i) TRAN(g; 3)`=`(4i 0 6+4i 0 2i)[0]^(*W*5) + (0–3 −6 0–6+9i)[0]^(*W*5) + (4+7i 0 –1+2i −2+4i 0)[0]^(*W*5)`=`(4+11i −3 –1+6i −2+4i −6+11i)[0]^(*W*5)`. Now the conjugate of the convolution `f ⋆`![Equation](`Images/F000175si79.png`) `g` is `(f ⋆`![Equation](`Images/F000175si80.png`) `g)\*`=`(4–11i −3–1–6i −2–4i -6–11i)[0]^(*W*5)`.
Next the convolution of `f\*` and `g\*` will be determined. First, `f\*`=`(2 0–3i 2−i 0)[0]^(*W*5)` and `g\*`=`(−2i 0 3–2i 0 −i)[0]^(*W*5)`; then, `f\*⋆`![Equation](`Images/F000175si81.png`) `g\*`=`−2j TRAN(f\*;0) + (3–2i) TRAN(f\*;2) - i TRAN(f\*;4)`=`( −4i 0–6 −2–4i 0)[0]^(*W*5)+(4–7i 0 6–4i 0–6–9i)[0]^(*W*5) + (0–3 −1–2i 0–2i)[0]^(*W*5)`=`(4–11i −3–1–6i −2–4i -6–11i)[0]^(*W*5)`. So, `(f ⋆`![Equation](`Images/F000175si82.png`) `g)\*`=`f\*⋆`![Equation](`Images/F000175si83.png`) `g\*`, which illustrates property #4 from a Banach\* algebra.
Next the inner product for a complex Hilbert space will be found, along with other norm calculations. First, it follows that `<f, g>`=`<(2 0 3i 2+i 0)[0]^(*W*5), (2i 0 3+2i 0 i)[0]^(*W*5)>`=`4i + (−3i) (3+2i)`=`4i −9i + 6`=`6–5i`. Finally, `f ⋆`![Equation](`Images/F000175si84.png`) `f\*`=`2 f − 3i (2+i 0 2 0 3i)[0]^(*W*5) + (2−i) (3i 2+i 0 2 0)[0]^(*W*5)`=`(4 0 6i 4+2i 0)[0]^(*W*5) + (3–6i 0–6i 0 9)[0]^(*W*5)`\+ `(3+6i 5 0 4–2i 0)[0]^(*W*5)`=`(10 5 0 8 9)[0]^(*W*5)`. So, `‖f ⋆`![Equation](`Images/F000175si85.png`) `f\*‖[1]`=`32` and `‖f‖[1]²`=`(5 + 5^(1/2))²`. This illustrates that the triangle product inequality property number (4) for a Banach algebra holds. It also shows that the C\* algebra property number (6) does not hold.
In `C^(*Zn*)`, the triangle product inequality for a Banach algebra holds in general, as before. Additionally, the transpose property holds in general for a Banach\* algebra. This is property number (4), [Section 3.7](#Ch003_41-55_B9780443136979000175.xhtml#s0040), accordingly: `(f ⋆`![Equation](`Images/F000175si86.png`) `g)\*`=`[$\\sum\\limits\_{n}$`![Equation](`Images/F000175si87.png`)(f ⋆`![Equation](`Images/F000175si88.png`) `g)(n)`]`\*`=`[$\\sum\\limits\_{n}$`![Equation](`Images/F000175si89.png`)(g ⋆`![Equation](`Images/F000175si90.png`) `f)(n)`]`\*`=`$\\sum\\limits\_{n}$`![Equation](`Images/F000175si91.png`)(g\*⋆`![Equation](`Images/F000175si92.png`) `f\*)(n)`=`g\*⋆`![Equation](`Images/F000175si93.png`) `f\*`. As a consequence, `C^(*Zn*)` is a Banach\* algebra, but not a C\* algebra.

# Quantum Hilbert spaces and their creation
## Abstract
In the following sections, numerous examples and methods are provided for creating specific Hilbert spaces. These include complexification, dual space, and outer product, as well as tensor product. These structures are described using the many-sorted algebra (MSA) and, in particular, illustrated with polyadic graphs. These graphs specify the closure properties involving operational names. A wide variety of examples are also provided to reinforce the concepts. Multilinear forms and interior products are later introduced. A description of MSA for tensor vector spaces, along with MSA for tensor algebras, is also given. This is followed in Section 4.10 with MSA for the tensor product of Hilbert spaces. Also, several definitions of states and rays are introduced in modified Hilbert spaces. The chapter ends with a description of projective spaces, as well as a brief description of antiunitary operators.

Complexification; outer product; dual space; double dual space; multilinear form; alternating form; tensor product; tensor space; projective space
