
RBF 模型建立在利用空间中点与点之间的距离之上。如果数据由对 (`x[*n*]`, `y[*n*]`) 组成，则它基于 `‖x−x[*n*]‖` 影响 `h(x)`。标准形式为 $h\\left( x \\right) = \\sum\_{n = 1}^{N}{w\_{n}e^{- \\gamma{\\|{x - x\_{n}}\\|}^{2}}}$![方程](Images/F000163si161.png)。该表达式是假设的函数形式。在大多数情况下，目标是基于数据 `D=(x[*n*], y[*n*])` 找到由元组 `w[*n*]` 组成的 `w`，其中 `n=1, 2,… N`。为求解 `w`：$\\overset{N}{\\underset{n = 1}{\\sum^{}}}w\_{n}e^{- \\gamma||x - x\_{n}||^{2}} = y\_{m}$![方程](Images/F000163si162.png) 对于 `x` = `x[*m*]`![方程](Images/F000163si163.png)′。因此 `Φ`![方程](Images/F000163si164.png) `w`=`y`。解为 `w` = `Φ`^( − 1)`y`![方程](Images/F000163si165.png)，类似于回归。对于分类，使用 $h\\left( x \\right) = {sgn}{({\\overset{N}{\\underset{n = 1}{\\sum^{}}}w\_{n}e^{- \\gamma||x - x\_{n}||^{2}}})}$![方程](Images/F000163si166.png)。令 $s = \\overset{N}{\\underset{n = 1}{\\sum^{}}}w\_{n}e^{- \\gamma||x - x\_{n}||^{2}}$![方程](Images/F000163si167.png)。

## 18.11 有界矩阵

类似于第 1.9 节中描述的时限信号，二维时限矩阵构成一个内积空间（[Alotto et al., 1998](#Ch018_327-348_B9780443136979000163.xhtml#bib19); [Dougherty and Giardina, 1987](#Ch018_327-348_B9780443136979000163.xhtml#bib20)）。这些是具有有限支撑的实值函数 `f`，位于 `R`^( `Z` `x` `Z` )![方程](Images/F000163si168.png)。这是对应于 `VECTOR` 的载体集合，而对于 `SCALAR`，则采用实数。函数 `f` 在 `R`^( `Z` `x` `Z` )![方程](Images/F000163si169.png) 中意味着 `f`: `Z` x `Z`→`R`，但所有这些由有界矩阵描述的函数在有限的格点子集上具有非零值。它们将用 `A` 表示。请注意 `V-ZERO` 对应于 `A` 中的 0 实体。`A` 中的信号或函数使用逐点运算构成实值向量空间。与所引用的章节一样，`A` 也构成一个内积空间，使用这些矩阵交集上的点积，但同样，它不是希尔伯特空间。此外，对于 `A` 中的 `f`，零的补集、非零集记为 `COZ(f)`。该有限集合由所有格点 (`n`, `m`) 组成，`n`, `m` 在 `Z` x `Z` 中，其中 `f` (`n`, `m`) 与 `V-ZERO` 不同。

对于 `A` 中任意信号 `f`，且 `COZ(f)` 非空的一种方便表示，类似于第 15.7 节中的 Young 图。事实上，关键格点 (`p`, `q`) 是包围 `f` 所有非零值的任意矩阵的最左、上元素的位置。例如，找到点 (`p`, `q`) 等于最小值 `n`，使得 `f` (`n`, ·) 非零的位置，并且最大 `m` 值，使得 `f` (·, `m`) 非零的位置。接下来，采用一种矩阵型结构来包围 `f` 的所有非零值以及 (`p`, `q`)。后一点本身可能是零。这类似于最小包围矩形，尽管矩阵不必是最小的。然而，一般来说，矩阵中必须至少有一个非零值，且外部没有非零值。一旦确定最左坐标 `p` 和最上值坐标 `q`，值 (`p`, `q`) 将用作矩阵右下侧的指针。这种数据结构称为有界矩阵。在整个过程中，至少最初假设非零集是非空的。一个例子可能有所帮助。

### 示例 18.12
