## 3.10 复值环绕数字信号
在提供量子应用之前，说明复数域结构的使用是很有启发性的。 在此方向上，考虑 `C^(*Zn*)`；这些是具有复数项的有界信号，它们也形成 Banach\* 代数，以及希尔伯特空间；证明见附录 A.1。 对于 Banach\* 和 C\* 代数，共轭运算在此实例中更为重要。 下一个例子说明了内积运算中的共轭运算。 函数的卷积也在其中找到，以及涉及共轭函数的卷积。 结果可以进行比较，以说明描述 Banach\* 代数所需的五个等式恒等式。
### 示例 3.16
考虑 `C^(*Zn*)` 中的两个有界向量 `f` 和 `g`，其中 `i=$\\sqrt{- 1}$`![方程](`Images/F000175si75.png`)，`f=(2 0 3i 2+i 0)[0]^(*W*5)`，且 `g=(2i 0 3+2i 0 i)[0]^(*W*5)`。 为了求 `f ⋆`![方程](`Images/F000175si76.png`) `g`，相同的并行算法再次可以使用。 确实，`f ⋆`![方程](`Images/F000175si77.png`) `g`=`g ⋆`![方程](`Images/F000175si78.png`) `f`=`2TRAN(g; 0) + 3i TRAN(g; 2) + (2 + i) TRAN(g; 3)`=`(4i 0 6+4i 0 2i)[0]^(*W*5) + (0–3 −6 0–6+9i)[0]^(*W*5) + (4+7i 0 –1+2i −2+4i 0)[0]^(*W*5)`=`(4+11i −3 –1+6i −2+4i −6+11i)[0]^(*W*5)`。 现在卷积 `f ⋆`![方程](`Images/F000175si79.png`) `g` 的共轭是 `(f ⋆`![方程](`Images/F000175si80.png`) `g)\*`=`(4–11i −3–1–6i −2–4i -6–11i)[0]^(*W*5)`。
接下来将确定 `f\*` 和 `g\*` 的卷积。 首先，`f\*`=`(2 0–3i 2−i 0)[0]^(*W*5)` 且 `g\*`=`(−2i 0 3–2i 0 −i)[0]^(*W*5)`；然后，`f\*⋆`![方程](`Images/F000175si81.png`) `g\*`=`−2j TRAN(f\*;0) + (3–2i) TRAN(f\*;2) - i TRAN(f\*;4)`=`( −4i 0–6 −2–4i 0)[0]^(*W*5)+(4–7i 0 6–4i 0–6–9i)[0]^(*W*5) + (0–3 −1–2i 0–2i)[0]^(*W*5)`=`(4–11i −3–1–6i −2–4i -6–11i)[0]^(*W*5)`。 所以，`(f ⋆`![方程](`Images/F000175si82.png`) `g)\*`=`f\*⋆`![方程](`Images/F000175si83.png`) `g\*`，这说明了 Banach\* 代数中的性质 #4。
接下来将求出复希尔伯特空间的内积，以及其他范数计算。 首先可知 `<f, g>`=`<(2 0 3i 2+i 0)[0]^(*W*5), (2i 0 3+2i 0 i)[0]^(*W*5)>`=`4i + (−3i) (3+2i)`=`4i −9i + 6`=`6–5i`。 最后，`f ⋆`![方程](`Images/F000175si84.png`) `f\*`=`2 f − 3i (2+i 0 2 0 3i)[0]^(*W*5) + (2−i) (3i 2+i 0 2 0)[0]^(*W*5)`=`(4 0 6i 4+2i 0)[0]^(*W*5) + (3–6i 0–6i 0 9)[0]^(*W*5)`\+ `(3+6i 5 0 4–2i 0)[0]^(*W*5)`=`(10 5 0 8 9)[0]^(*W*5)`。 所以，`‖f ⋆`![方程](`Images/F000175si85.png`) `f\*‖[1]`=`32` 且 `‖f‖[1]²`=`(5 + 5^(1/2))²`。 这说明了 Banach 代数的三角乘积不等式性质编号 (4) 成立。 它还表明 C\* 代数性质编号 (6) 不成立。
在 `C^(*Zn*)` 中，Banach 代数的三角乘积不等式一般成立，如前所述。 此外，Banach\* 代数的转置性质一般成立。 这是性质编号 (4)，[第 3.7 节](#Ch003_41-55_B9780443136979000175.xhtml#s0040)，相应地：`(f ⋆`![方程](`Images/F000175si86.png`) `g)\*`=`[$\\sum\\limits\_{n}$`![方程](`Images/F000175si87.png`)(f ⋆`![方程](`Images/F000175si88.png`) `g)(n)`]`\*`=`[$\\sum\\limits\_{n}$`![方程](`Images/F000175si89.png`)(g ⋆`![方程](`Images/F000175si90.png`) `f)(n)`]`\*`=`$\\sum\\limits\_{n}$`![方程](`Images/F000175si91.png`)(g\*⋆`![方程](`Images/F000175si92.png`) `f\*)(n)`=`g\*⋆`![方程](`Images/F000175si93.png`) `f\*`。 作为结果，`C^(*Zn*)` 是一个 Banach\* 代数，但不是 C\* 代数。
