
The `SK` 逼近中接近性的判据与逼近算子串长度的增加成反比。群交换子 \[U, V\][*G*]\=UVU\*V\* 在 `SK` 的证明中被采用。它用于确定幺正算子与恒等算子 `I` 的接近程度。群交换子与 `SU(2, C)` 中 `U`、`V` 的通常李括号有关，如下：\[U, V\]=0，则 \[U, V\][*G*]\=I。这是因为 \[U,V\]=0，这意味着 `UV=VU`；然后在群交换子中，\[U, V\][*G*]\=UVU\*V\*，用 `VU` 替换 `UV` 得到 \[U, V\][*G*]\=VUU\*V\*，这就是恒等式。

因此，群交换子接近恒等式当且仅当两个算子可交换。反复应用此交换子关系使得可以对恒等元做出 ![ent](`Images/epsi_1013.png`)net 逼近。最后通过平移，可以看出该逼近对 `SU(2, C)` 中的任意幺正算子都成立。`SK` 定理的大多数证明采用收缩引理，指定使用更长串获得恒等式的更好逼近。对恒等式的邻域做出越来越小的 ![ent](`Images/epsi_1013.png`)net 逼近。证明的最后一步是利用距离的双不变性将 ![ent](`Images/epsi_1013.png`)nets 平移到逼近 `SU(2, C)` 中的其他元素。深入的细节在 [Zarapico (2018](#Ch016_291-305_B9780443136979000060.xhtml#bib7)) 中提供。对于具有代数项的 `UQGS` 中的 `S` 且 ![ent](`Images/epsi_1013.png`) > 0，`n` 可以选择为 `n=0(log^(*c*) (1/![ent](`Images/epsi_1013.png`)))`，其中 `c=1` ([Holevo, 2003](#Ch016_291-305_B9780443136979000060.xhtml#bib10); [Bourgian and Gamburd, 2001](#Ch016_291-305_B9780443136979000060.xhtml#bib1))。

## 16.9 量子傅里叶变换与相位估计

量子傅里叶变换 (`QFT`) 用 `F` 表示，将复希尔伯特空间 `C^(*N*)` 中的向量映射回 `C^(*N*)`，其中通常 `N` 是正整数 `2^(*n*)`。具体而言，对于 ${|{x > = \\sum\_{j = 0}^{N - 1}x\_{j}}|}j >$![Equation](`Images/F000060si84.png`)，`QFT`，$F\\left( {|{x >}} \\right) = \\sum\_{j = 0}^{N - 1}y\_{j}{|j} >$![Equation](`Images/F000060si85.png`)，其中 $y\_{j} = 1/N^{1/2}\\sum\_{k = 0}^{N - 1}{x\_{k}\\left( w\_{N} \\right)^{km}}$![Equation](`Images/F000060si86.png`)，对于 m=0, 1, 2, …, N−1。另有，*w*[*N*] = *e*^((2*i**π*)/*N*)![Equation](`Images/F000060si87.png`)。逆 `QFT` 也有类似定义。它同样将复希尔伯特空间 *C*^(*N*)![Equation](`Images/F000060si88.png`) 中的向量映射回 *C*^(*N*)![Equation](`Images/F000060si89.png`)。在这种情况下，$x\_{j} = 1/N^{1/2}\\sum\_{k = 0}^{N - 1}{y\_{k}\\left( w\_{N} \\right)^{- km}}$![Equation](`Images/F000060si90.png`)，对于 m=0, 1, 2, …, N−1。`QFT` 及其逆可以作为幺正矩阵 *U*[*N*]![Equation](`Images/F000060si91.png`) 实现，作用于量子态向量。

### 示例 16.15

在希尔伯特空间 `C²` 中，`QFT`，`F=H`，即哈达玛变换。这是因为 *w*[*N*] = *e*^((2*i**π*)/*N*) = *w*[2] = *e*^((2*i**π*)/2) =  − 1![Equation](`Images/F000060si92.png`)。因此，${|{x > =}}\\sum\_{j = 0}^{1}x\_{j}{|j} > ,F\\left( {|{x >}} \\right) = \\sum\_{j = 0}^{1}{y\_{j}{|j}} >$![Equation](`Images/F000060si93.png`)，其中 $y\_{j} = 1/2^{1/2}\\sum\_{k = 0}^{1}{x\_{k}\\left( w\_{2} \\right)^{km}}$![Equation](`Images/F000060si94.png`)，对于 m=0, 1。*F*(|*x*\>) = 1/2^(1/2)\[*x*[0](*w*[2])⁰+*x*[1](*w*[2])⁰\]|0 >  + 1/2^(1/2)\[*x*[0](*w*[2])⁰+*x*[1](*w*[2])¹\]|1 >  = 1/2^(1/2)\[*x*[0]+*x*[1]\]|0 >  + 1/2^(1/2)\[*x*[0]−*x*[1]\]|1>![Equation](`Images/F000060si95.png`)。因此可得 `F` (|x>)=`H` (x[0] x[1])′.#

## 16.10 均匀叠加与振幅放大

在量子算法中，哈达玛门的重要应用之一是对几乎每个输入都使用它。通常，输入的数量为 `n`，并且全部是|0> 量子位。在这种情况下，该操作称为扩散操作。假设哈达玛算子并行应用于每个输入，它表示为 $H^{@n}\\left( {|{0 >^{@n}}} \\right) = 1/2^{n/2}\\sum\_{x = 0}^{N - 1}{{|x} >}$![Equation](`Images/F000060si105.png`)，其中 *N* = 2^(*n*)![Equation](`Images/F000060si106.png`)，张量积用 @ 表示。因此，均匀叠加中任何向量|x> 的相关概率为 1/2^(*n*)![Equation](`Images/F000060si107.png`)。由于所有振幅相同，任何|x> 的平均高度也为 1/2^(*n*)![Equation](`Images/F000060si108.png`)。

### 示例 16.17

考虑双输入系统，$H^{@2}\\left( {|{0 >^{@2}}} \\right) = 1/2\\sum\_{x = 0}^{3}{{|x} >}$![Equation](`Images/F000060si109.png`)。从数学上讲，这是因为 *H*|0 >  = 1/2^(1/2)(|0>+|1>) = | + >![Equation](`Images/F000060si110.png`)，并且由于有两个并行的哈达玛门，计算为 *H*^(@2)(|0>^(@2))![Equation](`Images/F000060si111.png`)。因此形成 |+> 与自身的张量积，即给出 |+> @|+>=1/2 \[|0 0>+|0 1>+|1 0>+|1 1>\]。将每个 ket |x> 按二进制解释，提供相同的结果，即 $1/2\\sum\_{x = 0}^{3}{{|x} >}$![Equation](`Images/F000060si112.png`)。简单的计算表明，均匀叠加中的这些向量各自长度为单位且彼此正交。最后这一性质最好通过 *C*⁴![Equation](`Images/F000060si113.png`) 中的表示来看。在这种情况下，每个 ket 由一个四乘一向量表示。每个向量包含除不同位置的单个一之外的所有零值元组。#
