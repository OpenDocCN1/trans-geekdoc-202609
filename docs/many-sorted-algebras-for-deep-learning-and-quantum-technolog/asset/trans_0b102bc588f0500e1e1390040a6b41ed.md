
标量与四元数可交换。据说实四元数组成四元数代数的中心。因此 `R` 也是核。接下来，形成商李代数 `LQ/R`。取李括号 `[p, q]`，其中 `v` 和 `w` 分别为 `p` 和 `q` 的向量部分。因此 `p q − q p = (po qo − <v, w>) + (po w + qo v + v x w) − (qo po − <v, w>) − (qo v + po w + w x v)`。注意实部等于零，以及除叉积项外的所有向量部分。结果为 `2 (v x w) = v x w − w x v`，如前例所述。

## 10.11 具有 Bloch 球 S² 的 Hopf 纤维化，一量子比特底

本演示完全基于[Mosseri 和 Dandoloff (2001)](#Ch010_171-188_B9780443136979000047.xhtml#bib7)。它涉及映射 `S¹→S³→S²`。具体而言，以底 `B=S²` 为基础的 Hopf 纤维化是非平凡纤维化最重要的例子之一。在此结构中，`E=S³` 由大圆纤维化，`F=S¹`。由于非平凡性，`E` 不等于 `B x F` 处处成立，通常它们仅在局部相等。就量子比特而言，纤维与一般量子比特 `e^(iϕ) |q>` 的不确定整体相位 `ϕ` 相对应。底可以被认为是 Bloch 球，其中纯量子比特占据其表面，而混合量子比特位于内部。如前所述，纤维化将使用复值 `u` 和 `v` 在 `C` 中实现，其中 `u=x + iy` 且 `v=z + it`，`x, y, z,` 和 `t` 为实值。由于 `S³` 定义为 `x² + y² + z² + t²=1`，它可以用 `u` 和 `v` 表示为 `|u|² + |v|²=1`。在这种情况下，Hopf 纤维化将使用两个映射 `H` 后接 `K` 的复合来描述。第一个映射将 `S³` 送入扩展平面 `R²` 并集 `{∞}`。第二个映射使用逆立体投影将该扩展平面送入 `S²`。具体而言，这些映射为：

`H(u,v) = (u v^(−1))*`

`K((u v^(−1))*) = (X,Y,Z), X² + Y² + Z² = 1`

`S³` 中参数化为 `ϕ` 的大圆 `(u e^(i ϕ), v e^(i ϕ))` 被映射为单点，即 `H(u e^(i ϕ), v e^(i ϕ)) = (u v^(−1))*`。

代入第一个映射 `H (u, v) = (u v^(−1))* = (x − i y)/(z − i t) = [(x z + y t) + i (x t − y z)]/(z² + t²)`。

## 10.12 具有球面 S⁴ 的 Hopf 纤维化，两量子比特底

本演示完全基于[Mosseri 和 Dandoloff (2001)](#Ch010_171-188_B9780443136979000047.xhtml#bib7)。涉及球面 `E=S⁷`、纤维 `F=S³` 和底 `S⁴` 的 Hopf 纤维化与 `S¹→S³→S²` 类似地发展。取而代之的是使用四元数。整个处理与[第10.11节](#Ch010_171-188_B9780443136979000047.xhtml#s0060)中给出的纤维化平行。在这种情况下，纤维化 `S³→S⁷→S⁴` 将被说明。该程序遵循所引用论文的方法。对于复数，`u[p] = x[p] + i y[p]`，且 `v[p] = z[p] + i t[p]`，其中 `x[p], y[p], z[p],` 和 `t[p]` 为实值，`p=1 or 2`；四元数 `q[p] = u[p] + v[p] j` 将用于 Hopf 纤维化。此外，`|q[1]|² + |q[2]|² = 1`，因此 `x[1]² + y[1]² + z[1]² + t[1]² + x[2]² + y[2]² + z[2]² + t[2]² = 1`，表明四元数对 `q[1]` 和 `q[2]` 表示位于 `S⁷` 表面上的状态。

在这种情况下，Hopf 纤维化仍将使用两个映射 `H` 后接 `K` 的复合来描述。第一个映射将 `S⁷` 送入扩展曲面 `R⁴` 并集 `{∞}`。第二个映射使用逆立体投影将该扩展曲面送入 `S⁴`。如前所述，该方法几乎 100% 与复数情况平行。主要区别在于本例中的维数更大，更重要的是，四元数形成一种非交换的域型结构。这两个映射如下：

`H(q[1], q[2]) = (q[1] q[2]^(−1))*`

`K((q[1] q[2]^(−1))*) = (X,Y,Z,U,V), X² + Y² + Z² + U² + V² = 1`
