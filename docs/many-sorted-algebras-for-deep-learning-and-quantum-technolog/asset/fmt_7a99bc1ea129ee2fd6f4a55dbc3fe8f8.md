
### Example 19.13
This is probably the most important example of Mercer’s theorem. For real-valued functions `f(x)` periodic, of period 2π, with basic domain \[−`π`, `π`\], the Fourier series will extend this function to the whole real line. In this case, $f\\left( x \\right) = \\overset{\\infty}{\\underset{k = - \\infty}{\\sum^{}}}f\_{k}e^{ikx}$![Equation](`Images/F000278si214.png`) where `f`[`k`]![Equation](`Images/F000278si215.png`) are the Fourier coefficients. Integrating: ${\\int^{}}\_{- \\pi}^{\\pi}f\\left( x \\right)e^{- inx}{dx} = {\\int^{}}\_{- \\pi}^{\\pi}\\overset{\\infty}{\\underset{k = - \\infty}{\\sum^{}}}f\_{k}e^{ikx}e^{- inx}{dx}$![Equation](`Images/F000278si216.png`), interchanging the sum and the integral, this gives $\\overset{\\infty}{\\underset{k = - \\infty}{\\sum^{}}}f\_{k}{\\int^{}}\_{- \\pi}^{\\pi}e^{ikx}e^{- inx}{dx} = \\overset{\\infty}{\\underset{k = - \\infty}{\\sum^{}}}f\_{k}{\\int^{}}\_{- \\pi}^{\\pi}e^{ix(k - n)}{dx} = 2\\pi f\_{k}$![Equation](`Images/F000278si217.png`) whenever n=k, and zero otherwise. Therefore, `f`[`k`] = 1/(2`π`)∫^()[ − `π`]^(`π`)`f`(`x`)`e`^( − `i``k``x`)`d``x`![Equation](`Images/F000278si218.png`). The exponentials form an ON basis on \[−`π`, `π`\]. Since `f(x)` is real, the Fourier coefficients are conjugate symmetric, `f`[`k`] \*  = `f`[ − `k`]![Equation](`Images/F000278si219.png`). If it is assumed that `f(x)` is an even function, then `f`[`k`] = `f`[ − `k`]![Equation](`Images/F000278si220.png`). Also assume that the kernel is of the form `K(x, y)`=`K(x−y)` and has the aforementioned properties. Let the Fourier representation of the kernel be $K\\left( x \\right) = \\sum\_{k = - \\infty}^{\\infty}{k\_{k}e^{ikx}}$![Equation](`Images/F000278si221.png`).
Now consider the `L²`![Equation](`Images/F000278si222.png`) inner product of $f\\left( x \\right) = \\overset{\\infty}{\\underset{k = - \\infty}{\\sum^{}}}f\_{k}e^{ikx}$![Equation](`Images/F000278si223.png`) and $g\\left( x \\right) = \\overset{\\infty}{\\underset{k = - \\infty}{\\sum^{}}}g\_{k}e^{ikx}$![Equation](`Images/F000278si224.png`); then $< f,g > = < \\overset{\\infty}{\\underset{n = - \\infty}{\\sum^{}}}f\_{n}^{\*}e^{- inx},\\overset{\\infty}{\\underset{k = - \\infty}{\\sum^{}}}g\_{k}e^{ikx} > = \\overset{\\infty}{\\underset{n = - \\infty}{\\sum^{}}}f\_{n}^{\*}g\_{n}$![Equation](`Images/F000278si225.png`). Next a subspace `H` of `L²`![Equation](`Images/F000278si226.png`) will be a RKHS by defining an inner product $< f,g >\_{H} = \\overset{\\infty}{\\underset{n = - \\infty}{\\sum^{}}}\\left( {f\_{n}^{\*}g\_{n}} \\right)/k\_{n}$![Equation](`Images/F000278si227.png`). The induced norm in `H` is $\\left. \\left\\| f \\right\\| H = < f,f >\_{H} = \\overset{\\infty}{\\underset{n = - \\infty}{\\sum^{}}}\\left( {f\_{n}^{\*}f\_{n}} \\right)/k\_{n} = \\overset{\\infty}{\\underset{n = - \\infty}{\\sum^{}}} \\middle| f\_{n}|^{2}/k\_{n} \\right.$![Equation](`Images/F000278si228.png`). So in this RKHS `H`, it must be that $\\left. \\overset{\\infty}{\\underset{n = - \\infty}{\\sum^{}}} \\middle| f\_{n}|^{2} \\right.$![Equation](`Images/F000278si229.png`) is convergent. The reproducing property must be shown using $K\\left( x \\right) = \\overset{\\infty}{\\underset{k = - \\infty}{\\sum^{}}}k\_{k}e^{ikx}$![Equation](`Images/F000278si230.png`), so $K{({x - y})} = \\overset{\\infty}{\\underset{k = - \\infty}{\\sum^{}}}k\_{k}e^{ik{({x - y})}}$![Equation](`Images/F000278si231.png`). For a function `f` in `H`, <K(, y), $f >\_{H} = \\overset{\\infty}{\\underset{n = - \\infty}{\\sum^{}}}{({k\_{n}e^{- iny}})}{\\ast f}\_{n})/k\_{n} = \\overset{\\infty}{\\underset{n = - \\infty}{\\sum^{}}}f\_{n}e^{iny} = f{(y)}$![Equation](`Images/F000278si232.png`).

## 19.5 Spectral theorems
It was seen in [Section 13.1](#Ch013_231-253_B9780443136979000138.xhtml#s0010) that bounded operators have a nonempty compact spectrum consisting of an eigenvalue spectra, continuous spectra, or residual spectra. In finite dimensions `n`, every matrix has only an eigenvalue spectrum, and its cardinality is between one and `n`. This is a result of the fundamental theorem of algebra. In this case, the characteristic equation always has complex roots. Among the main results from [Chapter 13](#Ch013_231-253_B9780443136979000138.xhtml#Ch013_231-253_B9780443136979000138) is that for a self-adjoint operator `T`, in `B(H,H)`, then the eigenvalues are all real. Eigenvectors corresponding to distinct eigenvalues are always orthogonal. Finally, the eigenvalues lie in the interval [`m`, `M`] of `R`. Moreover, from the numerical range development, `m`=inf <v, `T` v> and `M`=sup <v, `T`v>, both over‖v‖=1, v in `H`. Finally the residual spectrum, `sprt` is empty; additionally, the residual spectrum is empty for the larger class of operators, the normal operators.
