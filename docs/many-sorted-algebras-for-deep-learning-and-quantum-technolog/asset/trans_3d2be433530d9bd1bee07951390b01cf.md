
The kernel is self-reproducing and positive semidefinite. Use `<K(., x), K(., y)> = K(y, x) = <K(., y), K(., x)>*`. To see that the property, positive semidefiniteness holds, let `i` and `j` be in any finite set of positive integers. Then $\\left. \\left. {\\sum\\limits\_{i,j}a\_{i}^{\*}}a\_{j}K{({x\_{i},x\_{j}})} = {\\sum\\limits\_{i}a\_{i}^{\*}} < K\\left( {.,x\_{i}} \\right),{\\sum\\limits\_{j}{a\_{j}K{({.,x\_{j}})} > = < {\\sum a\_{i}^{\*}}K\\left( {.,x\_{i}} \\right)}},{\\sum\\limits\_{j}{a\_{j}K{({.,x\_{j}})}}} > = \\right\\|{\\sum\\limits\_{j}{a\_{j}K{({.,x\_{j}})}}} \\middle| |^{2} \\right.$![方程](Images/F000278si40.png) which is greater than or equal to zero. This holds for all `a[i]`![方程](Images/F000278si41.png) in `C` and `x[i]`![方程](Images/F000278si42.png) in `X`. Kernels having these properties are sometimes called Mercer kernels. There is a converse to this result. It says whenever a symmetric positive semidefinite kernel `K` on a set `X` exists, then there is a unique Hilbert space `H` for which `K` produces a `RKHS`. This theorem is due to Moore-Aronszajn ([Aronszajn, 1950](#Ch019_349-364_B9780443136979000278.xhtml#bib1)). An outline of the results from this paper follows. For any `x` in `X`, let `K(x,.)` be an operator `K[x]`![方程](Images/F000278si43.png). Define the set of all `K[x]`![方程](Images/F000278si44.png) as `a`, the linear span for a vector space comprised of all linear combinations of such operators over `C`. An inner product can be defined for two such linear combinations as $< \\overset{n}{\\underset{i = 1}{\\sum^{}}}a\_{i}K\_{xi},\\overset{m}{\\underset{j = 1}{\\sum^{}}}a\_{j}K\_{yj} > = \\overset{n}{\\underset{i = 1}{\\sum^{}}}\\overset{m}{\\underset{j = 1}{\\sum^{}}}a\_{j}a\_{i}^{\*}K(x\_{i},x\_{j})$![方程](Images/F000278si45.png). The properties of an inner product hold since the kernel is symmetric and positive definite. Let `H` be the completion of this inner product space. This shows that `H` consists of functions $f(x) = \\overset{n}{\\underset{i = 1}{\\sum^{}}}a\_{i}K\_{xi}(x)$![方程](Images/F000278si46.png) such that the limit supremum as n goes to infinity and positive nonzero m> n, $\\left\\| \\overset{n + m}{\\underset{i = n}{\\sum^{}}}a\_{i}K\_{xi} \\right\\| = 0$![方程](Images/F000278si47.png).

To see that the reproducing property holds, <f, $K\_{x} > = < \\sum\_{i = 1}^{n}{a\_{i}K\_{xi}\\left( x \\right),K\_{x} > = \\sum\_{i = 1}^{n}{a\_{i} < K\_{xi},K\_{x} > = \\sum\_{i = 1}^{n}{a\_{i}K\\left( {x\_{xi},x} \\right) = f\\left( x \\right)}}}$![方程](Images/F000278si48.png). In order to determine that the Hilbert space is unique, let `H!` be another Hilbert space of functions having `K` as a reproducing kernel; then for every `x` and `y` in `X`, this other Hilbert space would have inner product  < `K[x i]`![方程](Images/F000278si49.png), `K[x]`\>![方程](Images/F000278si50.png), which again is `K(x[x i],x)`![方程](Images/F000278si51.png). Using linearity, both inner products are the same on the span using all `K[x]`![方程](Images/F000278si52.png). Also assume that the completion is performed as before, but for `H!`. This shows that `H` is a closed subset of `H!`. To prove that the inclusion goes the other way, use `f` in `H!`, and write `f` = `f[H]` + `f[H]^⊥`![方程](Images/F000278si53.png), where `f[H]`![方程](Images/F000278si54.png) is in `H` and `f[H]^⊥`![方程](Images/F000278si55.png) is in `H^⊥`![方程](Images/F000278si56.png). Because `K` is the reproducing kernel for both `H` and `H!`, it follows using inner products in `H!` that `f(x)` =  < `K[x]`![方程](Images/F000278si57.png), `f` >  =  < `K[x]`![方程](Images/F000278si58.png), `f[H]` >  +  < `K[x]`![方程](Images/F000278si59.png), `f[H]^⊥` >  =  < `K[x]`![方程](Images/F000278si60.png), `f[H]`\>![方程](Images/F000278si61.png). Because,  < `K[x]`![方程](Images/F000278si62.png), `f[H]^⊥`![方程](Images/F000278si63.png)\>=0 and since `K[x]`![方程](Images/F000278si64.png) is in `H`, it follows that the inner product of `K[x]`![方程](Images/F000278si65.png) with `f[H]^⊥`![方程](Images/F000278si66.png) in `H!` is zero. Therefore, the inner product in `H!` equals the inner product in `H`, showing that  < `K[x]`![方程](Images/F000278si67.png), `f[H]` >  = `f[H]`![方程](Images/F000278si68.png), and so `H=H!`.

If `H` is the space of functions from `X` to `C`, then a functional on this space can be found for `x` in `X`; write `E[x]f` = `f(x)`![方程](Images/F000278si69.png). Given a set `X`, a `RKHS` `H` is the space of functions from `X` to `C`; the evaluation functionals for each `x` in `X`, `E[x]`![方程](Images/F000278si70.png): `H→C`, are bounded, as originally stated.

## Example 19.2

The Hardy space is a Hilbert space, `H^∞`![方程](Images/F000278si71.png); it consists of all analytic functions `f`, on the open unit disk, `D` in `C`. The mean square value of these functions on any circle of radius `r` is bounded as `r` approaches one from the interior. That is, ∥`f`∥²\=sup\[1/(2*π*)∫[0]^(2*π*)|*f*(*r**e*^(*i**θ*)|²*d**θ*\]<∞![方程](Images/F000278si72.png), where the supremum is taken over all 0 <r <1 ([Katznelson, 1976](#Ch019_349-364_B9780443136979000278.xhtml#bib7)). As a result of Fatou’s theorem ([Krantz, 2007](#Ch019_349-364_B9780443136979000278.xhtml#bib8)), the analytic function can be extended to a function in `L^2`![方程](Images/F000278si73.png) on the boundary of the disk. It becomes the point-wise limit almost everywhere. The limit is always taken from the interior and never a tangential limit. Also, using the uniform norm for `f`, that is,‖`f`‖=max {`f` (z) such that z is in clos(`D`)}, `H^∞`![方程](Images/F000278si74.png) is a commutative Banach algebra. For `f(z)` in `H^∞`![方程](Images/F000278si75.png), $f\\left( z \\right) = \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}}a\_{n}z^{n}$![方程](Images/F000278si76.png) analytic in unit disk `D`, and such that $\\left. \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}} \\middle| a\_{n}|^{2} < \\infty \\right.$![方程](Images/F000278si77.png). This is called the disk algebra.
