
# 椭圆曲线加法

### 图 C.1 椭圆曲线加法

![图 C.1 椭圆曲线加法。](Images/F000114bm01-9780443136979.jpg)

图 C.1 椭圆曲线加法。

参照图，直线 `y=2x+1` 经过 `(0,1)` 和 `(−1,−1)` 并与椭圆曲线相交于 `(2,5)`。相应地，`(2,-5)` 也是曲线上的一个点。反射点是解，被称为 `(0,1)` 和 `(−1,−1)` 的加法。因此 `(0,1)` 与 `(−1,−1)` 的和为 `(2,−5)`（参见 [图 C.1](#FigureC1_373-376_B9780443136979000114.xhtml#f0010)）。这次，通过 `(0,1)` 和 `(2,−5)` 的直线给出 `y=−3x+1`，求交点得到 `(1/4,1/4)`。因此点 `(1/4.−1/4)` 是解。于是 `(0,1)` 加上 `(2,−5)=(1/4.−1/4)`。继续，直线 `y=x` 经过 `(−1,−1)` 和 `(1,1)` 并如前所述得到 `(1/4.1/4)`。

椭圆曲线阿贝尔群结构的机制如下：曲线上两点的和是通过利用经过这两点的直线的方程来找到的，然后找到它再次与曲线相交的位置，从而确定该直线上第三个点，最后将该找到的点关于 `x`-轴反射。如果两点连线是垂直的，则第三点为 `∞`![方程](Images/F000114si1.png)，而无穷远点因此是和。因此，通过包含无穷远点，结构是一个点集。对曲线的切线以类似方式处理；在此情况下，切点被自身相加。如果切线第三次与曲线相交，则和为该点应用负纵坐标值。当与曲线没有交点时，使用无穷远点 `∞`![方程](Images/F000114si2.png)。在此二元运算下点的集合目前是一个群胚（参见 [图 C.2](#FigureC1_373-376_B9780443136979000114.xhtml#f0015)）。

### 图 C.2 椭圆曲线上垂直点的加法

![图 C.2 椭圆曲线上垂直点的加法。](Images/F000114bm02-9780443136979.jpg)

[图 C.2](#FigureC1_373-376_B9780443136979000114.xhtml#Bf0015) 椭圆曲线上垂直点的加法。

要证明它是半群，必须满足结合律。这里，回到射影直线和射影空间，应用一个定理（[Cassels, 1991](#FigureC1_373-376_B9780443136979000114.xhtml#bib1)）：每当一个三次曲线经过与另外两个三次曲线相交的九个交点中的八个时，则必须包含第九个交点。这通常被称为九点引理或 Cayley–Bacharach 定理。结合律的证明源于这一结果（[Cayley, 1889](#FigureC1_373-376_B9780443136979000114.xhtml#bib2)）（参见 [图 C.3](#FigureC1_373-376_B9780443136979000114.xhtml#f0020)）。

### 图 C.3 结合律的证明

![图 C.3 结合律的证明。](Images/F000114bm03-9780443136979.jpg)

[图 C.3](#FigureC1_373-376_B9780443136979000114.xhtml#Bf0020) 结合律的证明。

基本思想是找到两个曲线 `C1` 和 `C2`，它们与给定曲线 `C` 共享八个不同的点，然后证明这些曲线是三次的且不等于 `C`，然后应用上述定理说明第九个点同时在 `C1` 和 `C2` 中。通过审慎地以战略模式配置八个点，第九点的包含将证明结合律。在此图中，符号 (?) 应该是第九个点。所有六条直线共有的八个点是：`A`、`P`、`Q`、`R`、`B`、`Q+R`、`Z` 和 `P+Q`。直线上的点表示仿射空间中的直线。总体目标是证明 `(P+Q)+R=P+(Q+R)`；这将成立因为直线 `L2` 和直线 `M2` 在 `?` 处相交。三条直线 `L1`、`L2` 和 `L3` 各自可以用一次齐次多项式给出：`|1 = |2 = |3 = 0`![方程](Images/F000114si3.png)。在此情况下，`C1 = |1|2|3`![方程](Images/F000114si4.png) 描述了一个退化的三次曲线。类似地令 `C2=m1m2m3`，其中 `m1=m2=m3=0` 是描述 `M1`、`M2` 和 `M3` 的一次齐次多项式。因此给定椭圆曲线 `C`，包括这八个点，应用 Cayley–Bacharach 定理表明第九个点 (?) 被包含并且在 `L2` 与 `M2` 的交点中。这表明结构是一个半群。接下来证明结构是一个幺半群。

必须找到一个 ZERO 并证明它满足零律以得到一个幺半群。零是无穷远点 `∞`![方程](Images/F000114si5.png)。它满足零律，因为如果你取任意一个点 `p`，则 `p+Z` 的和是通过取垂直线并连接这两个点找到的。然后对于一个非切点 `p`，在此同一条直线上存在第三个点 `q`，因此和为 `−q`。然而 `−q` 是 `p`。当 `p` 是一个切点且切线是垂直的时，则 `p+Z=p`。接下来要证明的是该结构是一个群。对于一个群，需要一个 MINUS，且必须满足负逆恒等式。然而对于点 `p=(a, b)`，`MINUS(p)=(a, −b)` 简记为 `−p`。此外，当这两个点用直线连接时，直线总是垂直的，所以 `p+(−p)=∞`![方程](Images/F000114si6.png) 如所期望。由于只有一个无穷远点，`MINUS(Z)=∞`![方程](Images/F000114si7.png)。最后，群是阿贝尔的，因为选择两点 `p` 和 `q` 在一条线上的顺序不会改变同一条线上得到的第三点 `r`，该点被反射从而 `p+q=−r=q+p`。

最后，Mordell 的一个定理规定了有理系数椭圆曲线上有理解的群结构。它断言只要它是非奇异的，即具有不同的根，它就是一个有限生成的阿贝尔群（[Silverman, 1986](#FigureC1_373-376_B9780443136979000114.xhtml#bib5)）。因此根据该定理，存在该群中有限个点 `Pj`，使得该群中每一个点 `P` 都可以表示为 `P=summation j=1 to n of nj Pj`，其中 `nj` 在 `Z` 中。此外，该群的结构已被 Mazur 证明（[Dumber, 2019](#FigureC1_373-376_B9780443136979000114.xhtml#bib3)）为 `T x Z x Z x … x Z` 的形式，其中 `T` 是一个挠子群，其阶数至多为 16，且 `T` 总是十五种可能之一中的一种。此外，上面有 `r` 个 `Z` 的拷贝，它被称为秩。最后，对于椭圆曲线 `y²\=x³\+ ax+b`，其中 `a` 和 `b` 在 `Z` 中，Siegel ([Lang, 1978](#FigureC1_373-376_B9780443136979000114.xhtml#bib4)) 表明相关联的群具有有限个整数坐标的点。
