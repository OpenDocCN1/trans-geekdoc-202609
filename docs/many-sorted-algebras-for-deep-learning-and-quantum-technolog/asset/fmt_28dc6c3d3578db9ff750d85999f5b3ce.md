
# Amplitude Amplification

Letting `|w>` be the uniform superposition of `N` = 2^(`n`) ![Equation](Images/F000060si114.png) states ${|{w > = 1/2^{n/2}}}\\sum\_{x = 0}^{N - 1}{{|x} >}$ ![Equation](Images/F000060si115.png). Then these vectors are often illustrated in a bar-type graph with `N` vertical line segment entries on the abscissa all of height 1/2^(`n`/2) ![Equation](Images/F000060si116.png). See [Fig. 16.4A](#Ch016_291-305_B9780443136979000060.xhtml#f0025). Uniform superposition is usually the initial state for an amplitude amplification algorithm. As a prime example is the Grover search, described in the next chapter. In its simplest form, this search utilizes the pair {`R[W]`, `U[f]`}, consisting of two reflection operators to find a single vector `|x*>` within `|w>`. An application of the first reflection `U[f]` negates the value of `|x*>` or reflects it about the abscissa. That is, it becomes −`|`x*>`, or graphically it reflects the state `|x*>` in the line segment graph; see [Fig. 16.4B](#Ch016_291-305_B9780443136979000060.xhtml#f0025). This operator is also called an oracle. In this diagram, a dashed horizontal line indicates the new lower average value `u`, of all probability amplitudes for states in `U[f]|w>`. The overall lower average or the overall lower mean value of the probability amplitudes occurs because the application of `U[f]` kept all states invariant but it negated `|x*>`. So this single negation pulls the overall average amplitude down slightly. The average has nothing to do with the true average involving the actual probability. This follows since the actual probabilities of `|x*>` and −`|`x*>` are the same. The absolute amplitude squared gives the true probability, and therefore, this quantity does not change.

![Figure 16.4 Trace of amplitude amplification. (A) Uniform superposition, (B) Reflection of the state|x*>, (C) Amplitude amplification, (D) One and a half reflection pairs applied again, (E) Two refection pairs applied/.](Images/F000060f16-04-9780443136979.jpg)

Figure 16.4 Trace of amplitude amplification. (A) Uniform superposition, (B) Reflection of the state `|x*>`, (C) Amplitude amplification, (D) One and a half reflection pairs applied again, (E) Two refection pairs applied/.

The next reflection operation `R[W]` is defined herein to be a reflection of the mean or actually, the average value `u` of the amplitude. Accordingly, for any vector `a[y]|y>` with `|y>` in {0, 1}^(`n`), the reflection operation about this mean `u` is such that `R[W] (a[y]|y>) = (2 u - a[y])|y>`. This equation is shown to hold by subtracting `u` from height `a[y]`, obtaining (`a[y] - u`). Then reflect this quantity about the x-axis as in an application of `U[f]`. This operation only negates the quantity. Accordingly, the result is (`u - a[y]`), and finally lifting, that is adding `u` again provides the desired result.

Since the mean is smaller for all vectors `U[f]|x>` in `U[f]|w>`, except for `U[f]|x*>`, applying the operator `R[W]` will make these amplitudes smaller yet. However, the amplitude of `R[W] U[f]|x*>` will become about three times its original value. See [Fig. 16.4C](#Ch016_291-305_B9780443136979000060.xhtml#f0025), which is not to scale. Amplitude amplification is the name given to the process of utilizing a pair of reflections such as `R[W]` and `U[f]` in succession. If the pair of reflections were applied again, then first, `U[f] R[W] U[f]|w>` is illustrated in [Fig. 16.4D](#Ch016_291-305_B9780443136979000060.xhtml#f0025), and `R[W] U[f] R[W] U[f]|w>` is illustrated in [Fig. 16.4E](#Ch016_291-305_B9780443136979000060.xhtml#f0025). In any case, repetitive applications of the reflection pair produce a decreasing average value of all state amplitudes while increasing the probability amplitude of the desired state. This beneficial increase occurs provided that `π`/4`N`^(1/2) ![Equation](Images/F000060si117.png) applications of `R[W]U[f]` ![Equation](Images/F000060si118.png) are not exceeded.

These reflections are the corner stone for the Grover search. This search is useful for logistic applications like finding the most efficient path and similar optimization problems. It is also used in machine learning algorithms, in particular, classification problems. Also, one-way functions that are hard to calculate, but easy to verify provide good results with the Grover search method.

## 16.11 Reflections

Reflections in the finite Hilbert space `H = C²` have a precise meaning. Reflections are used as a linear operator `R[W]`, `R[W]`: `H` → `H`. The operator is always applied to a nonzero vector `|v>`. By doing so, it reflects this vector `|v>` about a specified nonzero vector `|w>`. See [Fig. 16.5A](#Ch016_291-305_B9780443136979000060.xhtml#f0030), where `|v>` and `|w>` are illustrated along with the reflected ket, `R[W]|v>`. The end result is written with a dashed line. A most simple instance of this is when `|w> = |0> = (1 0)'` in the computational basis, and `|v> = (a b)'`. Then `R[W]|v> = (2|0><0| - I)|v> = (a -b)'`. This operation is also called a Householder reflection ([Householder, 1958](#Ch016_291-305_B9780443136979000060.xhtml#bib3)). As in the last section, use the diffusion operator to represent `|w> = H^(@n) (|0>^(@n))`. Then `R[W]|v> = H^(@n) [2|0^(@n)><0^(@n)| - I] H^(@n)|v> = (2|w><w| - I)|v>`.

![Figure 16.5 Reflection operation.: (A) Two vectors and reflection ket, (B) Result of reflection operation.](Images/F000060f16-05-9780443136979.jpg)

Figure 16.5 Reflection operation.: (A) Two vectors and reflection ket, (B) Result of reflection operation.

Accordingly, the operator performing the reflection about `w` is given by `R[W] = (2|w><w| - I)`, where `I` is the identity operation.

### Example 16.18

Let `|w> = |0>` be the simple vector about which a reflection is performed. If the vector to be reflected is `|v> = (3/5)^(1/2)|0> + (4/5)^(1/2)|1> = ((3/5)^(1/2)(4/5)^(1/2))` ![Equation](Images/F000060si119.png)′ in `C²` ![Equation](Images/F000060si120.png), the operator to perform the reflection involves twice the pure density function `|w><w|`, along with the negative of the identity function. Thus `R[W] =` ![Equation](Images/F000060si121.png)

$\\begin{matrix} {|1} & {0|} \\\\ {|0} & {{{- 1}|}.} \\\\ \\end{matrix}$

![Equation](Images/F000060si122.png)

An application of this operator upon the vector `|v>` gives `R[W]|v> = (3/5)^(1/2)|0> - (4/5)^(1/2)|1> = ((3/5)^(1/2) - (4/5)^(1/2)))` ![Equation](Images/F000060si123.png)′ in `C²` ![Equation](Images/F000060si124.png). See [Fig. 16.5B](#Ch016_291-305_B9780443136979000060.xhtml#f0030).#

The reflection operator is a key operation in the Grover search methodology. This operator is performed over and over again along with a sign alternating operation to perform this search.
