
每当 `Re <v, Tv>` 非负，且 `‖v‖ = 1` 时，`T` 被称为增算子。关于这些算子以及耗散算子的应用在于构造一参数半群，很像 Stone 定理中的情况。在本例中，当利用耗散算子时，半群由 Banach 空间中形式为 `e^(t T)` ![方程](Images/F000138si122.png) 的算子组成。当生成元是增算子 `T` 时，Banach 空间中相应的算子形式为 `e^(-t T)` ![方程](Images/F000138si123.png)。然而，其中许多算子是部分定义的（[Delaubenfels, 1988](#Ch013_231-253_B9780443136979000138.xhtml#bib3)）。

## 13.5 自伴算子

如前所述，本节和下一节提供了与自伴算子相关的概念的回顾以及扩展。在量子学科中最为重要的是，可观测量是 C∗ 代数 `A` 中的算子。它们是自伴算子 `T`，使得 `T = T∗`。此外，这些算子是可测的，并通过 `RRT` 定义，类似于寻找对偶空间的过程。该方法与之前考虑 `T: H → H` 情形时伴随 `T∗` 的构造非常相似。

假设 `T: H1 → H2`，其中 `H1` 和 `H2` 是希尔伯特空间。此外暂时假设 `T` 有界，即 `T` 在 `B(H1, H2)` 中。如对偶空间的构造一样，将定义一个泛函 `f`。它满足对于 `H2` 中固定的 `w`，`f: H1 → C`，其中对于 `H1` 中任意的 `v` 有 `f(v) = <w, T v>`。该泛函是线性的且有界的，因为 `T` 有界且 `|f(v)|` 小于或等于 `‖w‖ ‖T v‖`。该不等式是 `CBS` 不等式的直接结果。此外，由于 `T` 有界，最后的表达式小于或等于 `‖w‖ ‖T‖ ‖v‖`。而且 `f` 在 `H1` 的对偶空间中。

使用 `RRT`，对于 `H2` 中的每一个 `w`，存在唯一的 `u` 在 `H1` 中使得 `f(v) = <u, v>` 对所有 `v` 在 `H1` 成立。这定义了一个映射：`T∗: H2 → H1`，它被称为 `T` 的伴随算子，在上一节中已提及。映射 `T∗` 由 `T∗(w) = u` 给出。简而言之，`T∗` 的定义性质是 `<w, T v> = <T∗ w, v>`，对所有 `v` 在 `H1` 和 `w` 在 `H2` 成立。前面提到的第一个内积在 `H2` 中，第二个在 `H1` 中。由于假设 `T` 有界，可知 `T∗` 也是线性的且有界的，即 `T∗` 在 `B(H2, H1)` 中。此外，`T` 和 `T∗` 满足以下性质。

1. 范数相等：`‖T∗‖ = ‖T‖`。
2. 对合：`(T∗)∗ = T`。
3. 交换范数：`‖T T∗‖ = ‖T∗ T‖ = ‖T‖²` ![方程](Images/F000138si124.png)。
4. 逆：若 `T` 可逆，则 `T∗` 亦可逆且 `(T^(-1))∗ = (T∗)^(-1)`。
5. 可加性：`(S + T)∗ = S∗ + T∗`，其中 `S` 也在 `B(H1, H2)` 中。
6. 反交换：`S∗ T∗ = (T S)∗`。

对于有界算子 `T` 可以做出涉及自伴算子的唯一表示。设 `Q` 和 `S` 是 C∗ 代数 `A` 中的自伴算子；则 `T` 可表示为 `T = Q + i S`。因此 `T∗ = Q - i S`。将 `T` 加上 `T∗` 然后用 `T` 减去 `T∗` 得到 `Q = (T + T∗)/2` 且 `S = (T - T∗)/(2i)`。算子 `Q` 和 `S` 可被视为 `T` 的实部和虚部，按此顺序。

若 `K` 是 `H` 的闭子空间，则 `K` 本身就是一个希尔伯特空间。在此情况下，`H` 中任意向量 `v` 可写成 `u + w`，其中 `<u, w> = 0` 且 `u` 在 `K` 中。与 `K` 中向量正交的所有向量的空间称为 `K perp`，即写成 `perp(K)` 或 `K^⊥` ![方程](Images/F000138si125.png)。可将投影算子 `P` 与此过程关联。事实上，设 `P: H → K`，其中 `P(v) = u`。这样的运算既是幂等的又是自伴的。注意 `(I - P)(v) = w`。如果还有 `v' = u' + w'` 且 `u'` 在 `K` 中而 `w'` 在 `perp(K)` 中，则 `<P(v), v'> = <u, u'> = <v, u'> = <v, P(v')>`。此外，`<u, w> = <P(v), (I - P)(v)> = <v, P(I - P)(v)> = 0`。当 `K` 是 `H` 的闭子空间时，`perp(K)` 也是闭的。希尔伯特空间 `H` 的向量子空间 `K` 的一个重要性质是 `K` 的闭包等于 `perp(perp(K))`。如果 `K` 是 `H` 的闭子空间，则再次有 `K = perp(perp(K))`。而且，`K` 是闭的当且仅当 `K = (K^⊥)^⊥` ![方程](Images/F000138si126.png)。为此，首先假设 `K = (K^⊥)^⊥` ![方程](Images/F000138si127.png)。然后选取一个序列 `v[n] → v` ![方程](Images/F000138si128.png)，其中 `v[n]` ![方程](Images/F000138si129.png) 在 `K` 中而 `v` 在 `H` 中。将证明 `v` 在 `K` 中。取 `w` 在 `K^⊥` ![方程](Images/F000138si130.png) 中，则 `<w, v[n]> = 0` ![方程](Images/F000138si131.png) 对所有 n 成立，然后利用内积的连续性：`lim[n → ∞] <w, v[n]> = <w, lim[n → ∞] v[n]> = <w, v> = 0`。这表明 `v` 在 `K = (K^⊥)^⊥` ![方程](Images/F000138si135.png) 中，因此 `K` 是闭的。

反之，若 `K` 是 `H` 的闭子空间，则将证明 `K = (K^⊥)^⊥` ![方程](Images/F000138si136.png) 将被证明。取 `K` 中的 `v` 与 `K^⊥` ![方程](Images/F000138si137.png) 中的任意 `w` 的内积得到 `<v, w> = <w, v>∗ = 0`，从而表明 `v` 也在 `(K^⊥)^⊥` ![方程](Images/F000138si138.png) 中。因此 `K` 是 `(K^⊥)^⊥` ![方程](Images/F000138si139.png) 的子集。为看相反的集合包含，设 `v` 在 `(K^⊥)^⊥` ![方程](Images/F000138si140.png) 中。然后表示 `v = w + z`，其中 `w` 在 `K` 中且 `z` 在 `K^⊥` ![方程](Images/F000138si141.png) 中。利用线性性，`0 = <v, z> = <w, z> + <z, z> = 0 + <z, z> = ‖z‖²`，这意味着 `z = 0`。相应地，`v = w`，因此 `(K^⊥)^⊥` ![方程](Images/F000138si142.png) 是 `K` 的子集，因而它们相等。

当 `T` 有界时，核与伴随运算的像之间存在关系，即 `Ker(T) = perp(Im(T∗))` 且 `Im(T∗)` 的闭包 `= perp(ker(T))`。此外，若 `K` 是闭的，则 `perp(K) = perp(closure(K)) = closure(perp(K))`。另外，`perp(perp(K)) = closure(K)`。对于闭子空间 `K`，可得 `perp(perp(K)) = K`。而且，利用 `w = u + v`，则对于 `P` 在 `B(H)` 中且 `P(w) = u`，有 `‖P(w)‖² = ‖w‖² - ‖w - u‖²` ![方程](Images/F000138si143.png)；这是因为 `w - u = v` 且 `<u, v> = 0`。因此，`‖u‖² = ‖w - v‖² = ‖w‖² - ‖v‖²` ![方程](Images/F000138si144.png)。

伴随算子与核之间的关系如下：

1. `Ker(T∗) = perp(ran(T))`.
2. `Perp(ker(T∗)) = clos(ran(T))`.

将给出一个例子，使用动量算子的基，即微分运算。它将说明希尔伯特空间子空间上的闭算子，其中该算子不是有界的。

### 示例 13.18

考虑 `[0, 1]` 上平方绝对值可积的复值函数的勒贝格空间。它记为 `L[2]` ![方程](Images/F000138si145.png) `[0, 1]`。再次设无界动量型算子 `T` 被采用，其中 `T = d/dx`。则 `T` 的定义域为 `D(T)`，其中 `D(T) = { f in L[2]` ![方程](Images/F000138si146.png) `[0, 1]`，使得 `f` 绝对连续，其中 `d f/dx` 在 `L[2]` ![方程](Images/F000138si147.png) `[0, 1]` 中且 `f(0) = 0}`。则 `T` 在 `D(T)` 中是闭的（[Park, 2013](#Ch013_231-253_B9780443136979000138.xhtml#bib11)）。它在 Banach 空间 `C[0, 1]` 中不是闭的。即它在定义域 `{ f in C[0, 1]` 中不是闭的，使得 `d f/dx` 在 `C [0, 1]` 中且 `f(0) = 0}`。详见示例 8.1。
