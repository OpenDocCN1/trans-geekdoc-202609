
张量和只能在具有相同平衡性的张量之间找到。而张量积则可以应用于任意张量。在此情况下，`MSA` 描述中有四种类型，它们是 `SCALAR`、`VECTOR1`、`VECTOR2` 和 `VECTOR12`。第一种类型如前所述表示复数域中的标量。接下来的三种类型再次表示向量空间中的向量；在此情况下，向量实际上是张量。张量积将利用来自张量空间 `VECTOR1` 和 `VECTOR2` 的张量，从而得到 `VECTOR12` 中的张量。

除了向量空间和域之前的所有签名集之外，还有一个额外的签名集。它有一个运算符名称，实际上是张量积；它是 `T-MULT`，元数为二。[图 4.7](#Ch004_57-81_B9780443136979000011.xhtml#f0040) 说明了此运算。`SCALAR` 的载体集由所有复数组成。`VECTOR1` 的载体集是 `Vpq` 中所有 `Tpq` 向量的集合，而 `VECTOR2` 的载体集是 `Vrs` 中所有张量 `Trs` 的集合。所有这些张量的向量空间是一个幺元结合的交换代数。在此情况下，`V-ADD` 运算用于具有完全相同平衡性的两个张量的加法。

## 4.10 希尔伯特空间张量积的多类代数
接下来从高层视角给出希尔伯特空间 `H1` 与希尔伯特空间 `H2` 的张量积的 `MSA` 描述。它也是一个希尔伯特空间。类型以显而易见的方式给出；它们是 `SCALAR`、`VECTOR1`、`VECTOR2` 和 `VECTOR12`。签名集与希尔伯特空间的完全相同，只是需要一个额外的签名集来提供张量乘法。该签名集有一个名为 `T-MULT` 的二元运算符名称。它满足：

* `T-MULT`: `VECTOR1 x VECTOR2 → VECTOR12`.

与之前的 `MSA` 高层表示一样，记作：

* `V-ADD` by `+`
* `S-MULT` by `x`
* `T-MULT` by `⊗`![方程](Images/F000011si144.png)
* `SCALAR` by `c`
* `VECTOR1` by `v1, w1`
* `VECTOR2` by `v2, w2`

此外，希尔伯特空间的所有等式恒等式在此结构中均成立，并附带额外的等式约束：

1. 1) 线性：`c x (v1 ⊗ v2)=(c x v1) ⊗ v2=v1 ⊗ (c x v2)`.
2. 2) 分配律：`(v1 + w1) ⊗ w2=v1 ⊗ w2 + w1 ⊗ v2`.
3. 3) 分配律：`v1 ⊗ (v2 + w2)=v1 ⊗ v2 + v1 ⊗ w2`.
4. 4) 内积：`<v1 ⊗ v2, w1 ⊗ w2>=< v1, w1> <v2, w2>`.

在这些约束下，`VECTOR12` 成为由 `H12` 表示的希尔伯特空间。多值图 [图 4.8](#Ch004_57-81_B9780443136979000011.xhtml#f0045) 说明了产生 `VECTOR12` 的运算 `T-MULT`。同样，类型 `SCALAR` 未显示，也没有涉及希尔伯特空间的任何运算名称，除了 `T-MULT`。此外，类型 `VECTOR1` 和 `VECTOR 2` 分别用 `H1` 和 `H2` 表示。
