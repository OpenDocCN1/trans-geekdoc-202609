
## 4.3 共轭线性映射

一个自然的共轭线性映射由 `K` 给出，从 kets 的希尔伯特空间到 bras 的希尔伯特空间。这里，`K(|v> + |w>)=<v| + <w|`，且 `K(a·|v>)=a*·<v|`，对于任意复标量 `a`，其中 `a*` 是 `a` 的共轭。另外，往另一个方向，映射 `B` 从 bras 的对偶空间到原始希尔伯特空间满足 `B(<f| + <g|)=|f> + |g>` 且 `B(a<f|)=a*|f>`。算子 `B` 和 `K` 是 `V` 与其对偶空间之间的 1–1、满、等距共轭映射。因为范数得以保持，所以它是等距映射。简而言之，`‖|f>‖=‖<f|‖`。等距映射也称为等距变换，详见后章。

该结果推广到任意具有 kets 和 bras 的有限维希尔伯特空间，特别是到一个 `n` 量子能级系统，即 `n` 维希尔伯特空间 `C^(n)`。此外，它以操作方式用于无限维拓扑对偶希尔伯特空间，以及巴拿赫空间。[图 4.3](#Ch004_57-81_B9780443136979000011.xhtml#f0020) 说明了使用运算 `B` 和 `K` 在 `V` 与其对偶空间 `Vd` 之间的共轭线性及等距映射。

## 4.4 双对偶希尔伯特空间

双对偶空间 `Vdd` 是 `V` 的 `Vd` 的对偶。因此，`Vdd=Hom(Vd, C)`；它是 `Vd` 到 `C` 的所有线性映射的集合。通过将 `Vd` 与 `V` 关联可知，两个空间 `Vdd` 和 `Vd` 之间也存在共轭线性、1–1、满、等距映射从 `Vdd` 到 `Vd`。可以说双对偶希尔伯特空间 `Vdd` 与 `V` 相同（[哈尔莫斯, 1958](#Ch004_57-81_B9780443136979000011.xhtml#bib3)）。双重共轭导致恒等映射。存在一个从 `Vdd` 到 `V` 的规范映射，给出在下一段中，并由 [图 4.4](#Ch004_57-81_B9780443136979000011.xhtml#f0025) 说明。稍后会给出更多细节。

![图 4.4 双对偶的规范同构映射。](Images/F000011f04-04-9780443136979.jpg)

图 4.4 双对偶的规范同构映射。

设 `g` 在 `Vdd` 中，即 `g: Vd → C`。这是一个线性映射。将会证明 `g` 实际上将 `V` 中的向量 `v` 映射到 `C`。在上一节中，已看到当使用 `V` 的基向量集合 `E={e[1], e[2], …, e[N]}` 时，对应有一个集合 `F={f[1], f[2], …, f[N]}`，它是 `Vd` 中协向量的基。重要的是 `Vd` 中的每一个协向量 `h` 都可以用来自 `E` 的向量以及来自 `F` 的基元素表示为线性表达式。这在二维向量空间中于 [例 4.5](#Ch004_57-81_B9780443136979000011.xhtml#enun5) 中有所说明。一般表示如下：

对于 `h in Vd`，`h = h(e[1])f[1] + h(e[2])f[2] + … + h(e[N])f[N]`。

![方程](Images/F000011si16.png)

接下来，由于 `g` 在 `Vdd` 中，将 `g` 应用于 `Vd` 中的 `h`：

`g(h) = g[h(e[1])f[1] + h(e[2])f[2] + … + h(e[N])f[N]]`。

![方程](Images/F000011si17.png)

利用 `g` 的线性以及 `h(e[j])` 是 `C` 中的标量这一事实；则：

`g(h) = (h(e[1])g(f[1]) + h(e[2])g(f[2]) + … + h(e[N])g(f[N]))`。

![方程](Images/F000011si18.png)

注意该和也在 `C` 中；即它是标量的和。因此用标量 `aj` 替换每个 `g(fj)` 并写成如下形式：

`g(h) = h(e[1])a[1] + h(e[2])a[2] + … + h(e[N])a[N]`。

![方程](Images/F000011si19.png)

由于 `h` 是线性的，可知 `g(h)` 可写为 `g(h)=h(a[1]e[1] + a[2]e[2] + … + a[N]e[N])`。然而和 `a[1]e[1] + a[2]e[2] + … + a[N]e[N]` 是一个唯一元素 `v`，其中 `v` 在 `V` 中。可知通过取 `Vdd` 中的任意 `g`，协向量的求值产生 `V` 中的唯一元素 `v`。它满足 `g(h)=h(v)`；该映射由 [图 4.4](#Ch004_57-81_B9780443136979000011.xhtml#f0025) 说明。对于 `Vdd` 中每一个不同的 `g`，将对应一个不同的 `v` 在 `V` 中，反之亦然。这称为 `V` 与 `Vdd` 之间的规范同构映射。

原始空间 `V` 可与 `Hom(Vd, C)` 识别，因为通过取 `V` 中的任意向量 `v` 我们可以将其与 `Vdd` 中的线性求值映射 `gv` 关联。设 `gv: Vd → C` 且 `gv` 线性。因此，对于 `Vd` 中的 `h`，定义 `gv(h)=h(v)`，类似于前面使用 `g` 的情况。为了说明其线性，使用 `Vd` 中的 `h[1]` 和 `h[2]` 以及 `C` 中的 `a`；则有：

`gv(h[1]+h[2]) = (h[1] + h[2])(v) = h[1](v) + h[2](v) = gv(h[1]) + gv(h[2])`

![方程](Images/F000011si20.png)

且

`gv(a h) = (a h)(v) = a (h)(v) = a gv(h)`。

![方程](Images/F000011si21.png)

为证明代数同构，考虑 `F: Vdd → V`，其中 `F(g[1])=v[1]`，`F(g[2])=v[2]`，且 `F(g)=v`，使用 `Vd` 中的 `h`。

则 `(g[1] + g[2])(h)=g[1](h) + g[2](h)=h(v[1]) + h(v[2])=h(v[1] + v[2])`。

另外 `(a g)(h)=a(g)(h)=a h(v)=h(a v)`。`V` 的自然同构元素可视为从 `Vdd` 到 `C` 的线性映射。

## 4.5 外积

向量与协向量的外积在量子研究中至关重要。该运算通常称为纯或简单张量。在有限维情况下，结果将是一个矩阵。将会看到 kets 和 bras 在描述该运算时很有用。首先，将在 MSA 中从有限维希尔伯特空间的全局层面给出外积的严格规范。

首先回顾，对于固定的 `n`，所有 `n` by `n`、`n=1, 2, 3, …` 矩阵的集合构成复数域上的结合幺代数。在此观点下，与 `VECTOR` 关联的载体集合是 `n` by `n` 矩阵的集合。所有通常的矩阵运算——标量乘法、矩阵乘法、矩阵加法、矩阵减法、矩阵偏逆、矩阵零、矩阵恒等——均源于签名集合内的运算名称：相应地，名称为 `S-MULT`、`BINE`、`V-ADD`、`V-MINUS`、`V-INVERSE` 和 `V-ZERO`，并且如前所述，单位矩阵由 `V-ONE` 得到。此外，所有结合幺代数的等式恒等式均成立。为描述外积，有用的是定义第三个排序 `MATRIX`。关联的载体集合是所有 `n` by `n` 矩阵的集合，所有通常的矩阵运算均源于结合幺代数构造。参见第 3.1 节，[图 3.1](#Ch003_41-55_B9780443136979000175.xhtml#f0010)。

描述外积的排序为 `VECTOR`、`SCALAR` 和 `MATRIX`。适用于希尔伯特空间、复数域和结合幺代数结构的全部签名集合及其所有附加条件均被假定成立。然而，存在一个包含单个算子名 `OUTER` 的额外签名集合。它是二元的且满足：

`OUTER: VECTOR x VECTOR -> MATRIX`。

![方程](Images/F000011si22.png)

除希尔伯特空间、复数域和结合幺代数的约束外，还需要若干等式约束。

这里，排序的表示如下：

* `VECTOR` 用 `u`、`v` 和 `w` 表示。
* `SCALAR` 用 `c` 表示。
* `MATRIX` 用 `M` 表示。

签名集合的代表元素以建议符号给出：

* `V-ADD` 用 `+` 表示。
* `S-MULT` 用 `·` 表示。
* `OUTER` 用 `⊗` 表示。

附加约束如下：

1. 线性：`c·(v ⊗ u) = (c·v) ⊗ u = v ⊗ (c·u)`。
2. 分配律：`(v + w) ⊗ u = v ⊗ u + w ⊗ u`。
3. 分配律：`u ⊗ (v + w) = u ⊗ v + u ⊗ w`。
