
不同类型的数字信号会产生载体集合，对于这些信号，相比于 `A` 中的那些信号，会应用更深层的结构。回想一下，`A` 由 `R^(*z*)` 中紧支撑的所有数字信号组成。现在，环绕数字信号将用环绕卷积来描述。该结构构成一个希尔伯特空间，以及一个结合的、交换的、含幺的代数。在这种情况下，类型 `SCALAR` 再次表示实数域。而 `VECTOR` 象征 `R^(*Zn*)` 中的有界向量 `f`，这里 `f`: `*Z**n*`![Equation](Images/F000175si38.png)→`R`，其中 `*Z**n*`![Equation](Images/F000175si39.png) 是由 {0, 1, 2, …, n-1} 组成的循环群，`n`> 1。可以认为这组整数位于一个圆上，因此 `n−1` 的后继是 0。0 的后继是 1，1 的后继是 2，等等。本文中循环群的最早实例见于示例 1.1。在这种情况下，伽罗瓦域中的加法群为模三。
在此环境中，有界向量始终写为 `f=(a b c … d)[*k*]^(*Wn*)`，其中 `a`、`b`、… `d` 是 `n` 个实数。因此，`V-ZERO=(0 0 … 0)[*k*]^(*Wn*)`。对于环绕有界向量，零向量始终以这种方式指定。此外，`*W**n*`![Equation](Images/F000175si40.png) 表示该向量是 `R^(*Zn*)` 中的环绕有界向量，且 `k` 是 0 到 `n−1` 之间的整数。使用逐点加法，以及作为这些类型有界向量乘法的卷积，会得到一个含幺的、交换的和结合的代数结构。含幺有界向量 `V-ONE` 在 `R^(*Zn*)` 中为 `(1 0 … 0)[0]^(*Wn*)`。`R^(*Zn*)` 中有界向量的卷积基本上与先前对 `R^(*Z*)` 中有界向量描述的算法相同：与往常一样，与零向量的卷积产生零向量。因此，下面假设有界向量是非零的。
逐点卷积由下式给出：
$\\left( {f \\star g} \\right)\\left( n \\right) = {\\sum\\limits\_{k \\in COZ{(f)},{({n - k})} \\in COZ{(g)}}{f\\left( k \\right)g\\left( {n - k} \\right)}}$
![Equation](Images/F000175si41.png)
环绕卷积是一种全卷积形式，其中 resulting 卷积与输入信号大小相同。先前描述的时限数字信号卷积可能称为扩展卷积。图 3.2 中所示的相同并行算法可以在 `R^(*Zn*)` 中使用。这里操作的名称相同，但由于载体集合不同，实际操作是不同的。接下来给出一个使之更清晰的例子。循环群使用 `TRAN` 对向量空间结构进行作用，就像向量在仿射空间中对仿射元素的作用一样。同样，由于 `MSA` 全局视图与 `R^(*Z*)` 中的相同，实际的低级操作是不同的。

向量空间 `R^(*Zn*)` 也构成一个内积空间，同样使用非空零点集交集上的点积。否则为零。第 1.9 节提供了公理，且 [图 1.3](#Ch001_1-19_B9780443136979000199.xhtml#f0020) 说明了该结构的 `MSA` 表示的拟多项式图。`f=(a b c … d)[*k*]^(*Wn*)` 与 `g=(e h … m)[*k*]^(*Wn*)` 的内积，如常，显示所有 `n` 个条目时为=`a·e + b·h + … + d·m`。内积再次由 `<f, g>` 或 `<f|g>` 表示。如果使用复数域代替实数域，则在计算内积时值 `a`、`b`、…、`d` 需要取共轭。这是量子物理中使用的约定，并在第 1.8 节中说明。`R^(*Zn*)` 中的内积诱导出前面提到的二范数。该范数可由公式 `‖f ‖²\=<f|f>` 找到。在此范数下，`R^(*Zn*)` 是一个完备的内积空间，因此是希尔伯特空间；参见附录 A.1 证明。`R^(*Zn*)` 中有界向量序列的收敛与 `R^(*n*)` 中的收敛相似。
## 3.6 Banach 空间的多类代数描述
Banach 空间是定义在复数或实数域上的带范数的向量空间。一些范数已经说明过。二范数由内积诱导，见第 1.8 节。此外，一范数在第 2.1 节示例 2.1 中的 k-means 无监督学习技术中使用。Banach 空间与希尔伯特空间相似，因为它对范数也是完备的。如常，范数是一种平移不变型距离函数。然而，与希尔伯特空间不同，可分性不足以保证 Schauder 基的存在 ([Enflo, 1973](#Ch003_41-55_B9780443136979000175.xhtml#bib1))。因此，在无限维 Banach 空间中工作时将假设存在 Schauder 基。否则，如一般拓扑向量空间中，需要采用无条件基。接下来将给出 Banach 空间的 `MSA` 全局视图。
在 `MSA` 描述中，Banach 空间实体由两种类型组成，它们是 `SCALAR` 和 `VECTOR`。与 `SCALAR` 关联的所有签名集合与实数或复数域结构相同。`VECTOR` 类型的签名集合与向量空间完全相同，只是存在一个额外的 unary 操作名：`NORM`，在其自己的签名集合中。据此，Banach 空间的元数序列为 `(1, 2(1 1), 2(1 1))`。[图 3.3](#Ch003_41-55_B9780443136979000175.xhtml#f0020) 说明了 Banach 空间中使用的 `NORM` 操作名，以及签名集合中的常用向量空间操作名。仅与 `SCALAR` 关联的操作名被省略。`NORM` 满足：
`NORM:VECTOR→SCALAR`

如常，`S-MULT` 操作必须允许标量在乘法操作中位于向量的两侧。
`NORM` 必须满足三个条件。为此，首先替换：
* `SCALAR` 为 `a`
* `VECTOR` 为 `u`, `v`, `w`
* `S-MULT` 为 `·`
* `V-ADD` 为 `+`
* `NORM` 为 `‖‖`
`NORM` 需满足的条件如下：
1. 1) 正定性：`‖u‖> 0`，且 `‖u‖=0` 当且仅当 `u=0`。
2. 2) 齐次性：`‖a·u‖=| a|‖u‖=‖u·a‖`。
3. 3) 三角不等式：`‖u + v‖` 小于或等于 `‖ u ‖ + ‖ v ‖`。
