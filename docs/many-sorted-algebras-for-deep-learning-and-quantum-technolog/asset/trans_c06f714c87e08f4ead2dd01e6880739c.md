
结合律在 [图 12.7](#Ch012_217-230_B9780443136979000254.xhtml#f0040) 中得到证明。在此图中，存在一个拓扑空间 `T`，包含三个回路。这些实际上是等价类。连续函数 `f`、`g` 和 `h` 表示这些回路。在此情况下，`f(0)=f(1)=g(0)=g(1)=h(0)=h(1)`。观察同伦方形的两个不同的垂直边。在方形的左侧，`t=0`，乘积 `f x (g x h)` 被示出。在此侧，令 `H=f(2 s)` 对于 `s` 在 [0, 1/2] 中，`H=g (4 s − 2)` 对于 `s` 在 [1/2, 3/4] 中，且 `H=h(4 s − 3)` 对于 `s` 在 [3/4, 1] 中。在右侧，乘积 `(f x g) x h` 给出。这里，`K=f (4 s)` 对于 `s` 在 [0, 1/4] 中，`K=g(4 s − 1)` 对于 `s` 在 [1/4, 1/2] 中，且 `K=h (2 s − 1)` 对于 `s` 在 [1/2, 1] 中。再次，结合律对等价类成立，而不对单个函数 `f`、`g` 和 `h` 成立。它在同伦下成立，而非逐点成立。如果在 [0, 1] 中选取任意点 `t`，则该点决定构成同伦的具体函数。请注意，存在直线段分隔 `f`、`g` 和 `h`，它们是根据 `s` 和 `t` 定义的。此外，这些函数的自变量在很大程度上是非线性的。

在 `t=0` 时，在同伦方形的左侧，所示函数的求值与前面给出的 `H` 一致。右侧在 `t=1` 时同样如此；求值给出 `K`。此外，对于 (0, 1) 中的任意点 `t`，同伦存在，因为过渡是连续的。例如，如同伦方形所示，在 `t=1/3` 时，存在一条虚线垂直线。在这条虚线上，随着 `s` 从零垂直增加到一，存在三个不同的定义域范围。每个 `f`、`g` 和 `h` 各有一个定义域，使用自变量 `s`。对于 `f`，定义域为 [0, 5/12]。对于 `g`，定义域为 [5/12, 8/12]，对于 `h`，定义域为 [8/12, 1]。这些函数 `f`、`g` 和 `h` 的求值，当然是连接回路的等价类的代表，将显示同伦。在下倾斜线段上，且在 `t=1/3` 时，这里 `s=5/12`，求值 `f` 给出 `f((20/12)/(2–1/3))=f (1)`。对于同一点 (`t`, `s`)，求值 `g` 得到 `g(20/12 + 1/3–2)=g(0)`。请注意，`f(1)=g(0)` 在同伦意义下相等；它们代表最终点和初始点的相等。也就是说，它们表示 `T` 中同一点 `xo`。类似地，在 `t=1/3` 的上倾斜线段上，`s=8/12`。在此点，函数 `f` 和 `g` 的求值均给出 `g(1)=h(0)`。

等价类上恒等条件成立的证明在 [图 12.8](#Ch012_217-230_B9780443136979000254.xhtml#f0045) 中给出。图中仅显示了该恒等的一个部分，`f x I=f`。另一部分 (`I x f=f`) 以类似方式证明。图中示出的是同伦方形。左侧为 `f x I`，右侧仅为 `f(s)`。同伦首先通过考虑左侧获得，即 `t=0`。这里，`H=f(2 s)` 对于 `s` 在 [0, 1/2] 中，且 `H=f(1)`；也就是说，它对于 `s` 在 [1/2, 1] 中是常数。右侧为单独的 `f(s)`。对于 0 与 1 之间的任意 `t`，`f` 的下部区域的上边界等于倾斜线段，`s=(1 + t)/2`。在此区域，`f` 的自变量为 `2 s/(t +1)`；因此，对于任意 `t` 和倾斜线上的对应 `s`，`f` 的上边界值一致；它是 `f(1)`。这与倾斜线之上相同。

[图 12.9](#Ch012_217-230_B9780443136979000254.xhtml#f0050) 涉及 `f` 的逆函数。该图的目的是说明事实 `MULT(f, INV(f))=IDENTITY`。这是右侧恒等。左侧恒等关系可以以类似方式显示。拓扑图中的恒等是点 `xo`。该图中的任何回路都可以从 `xo` 完全到达 `xo`，然后解开并返回，表明逆函数。然而，这仅在 `t=0` 时发生。在所有其他情况下，路径将从 `xo` 开始，但会停滞。它本质上会停止，然后转身返回，再次到达 `xo`。这确实是 [图 12.9](#Ch012_217-230_B9780443136979000254.xhtml#f0050) 下图所示的情况。请注意，逆时针运动归因于 `f`，顺时针运动归因于 `INV(f)`。在左上角，小图说明了从 `xo` 到 `xo` 的完整旋转。其后是逆完整旋转。这仅与同伦方形的左边界 `t=0` 相关，且之前已解释。部分旋转在该图左上角下方示出。请注意，在此应用中 `INV(f)(s)=f(2–2 s)`。

同伦方形 `H` 也在图中给出。`H` 的左侧为 `f` 和 `f^(-1)`。具体而言，对于 `s` 在 [0, 1/2] 中，应用 `f(2 s)`。在区间 [1/2, 1] 中，使用 `f(2–2 s)`。同伦方形的右侧为 `f(0)`，表示恒等函数。对于 `t` 在 [0, 1] 中，存在倾斜线段 `s=1/2 + t/2` 和 `s=1/2 − t/2`，`s` 在 [0, 1] 中。这些线段为同伦函数 `f` 的自变量提供边界。对于固定的 `t`，`s` 在 [0, 1] 中的值导致 `f` 的回路或部分回路。特别地，在方形的极端处，左侧当 `s: 0→1/2` 时，`f` 逆时针做出从 `xo` 到 `xo` 的完整回路。对于 `s: 1/2→1`，回路以顺时针方式在其自身上回溯。这在同伦方形左侧的最上方图中示出。同伦方形的右侧边界为恒等，其中对于 `s` 在 [0, 1] 中，没有运动发生，回路保持在点 `xo`，对于所有 `s` 在 [0, 1] 中。然而，对于 `t` 在 (0, 1) 中，所有情况下都会发生运动。然而，它不会逆时针做出完整回路，运动会停滞并顺时针返回到 `xo`。

例如，在 `t=1/3` 时，图中有一条虚线垂直线。该线在两点处与 v 型倾斜线相交。在下倾斜线段上，相交点给出 `s=1/3`。在下部区域对 `s=1/3` 处函数 `f` 的求值给出 `f(2/3)`。再次求值，这次在中心区域对 `s=1/3`，得到 `f(1–1/3)=f(2/3)`，再次是相同的值。这对于连续性是必须的。在此情况下，未达到回路。随着 `s` 向上变化，没有运动，直到遇到上倾斜线段；也就是说，随着 `s` 增加，`s: 1/3→2/3`。在最上部区域，运动再次开始但为顺时针。它从点 (1/3, 2/3) 开始，提供值 `f(2–4/3)=f(2/3)`，与 v 形区域内 `f` 的值一致。在上部区域，逆时针运动占主导，最终 `f` 在 `f(1)` 处结束，即恒等。随着 `t: 0→1`，回路的创建发生连续变化，从完整回路及其撤销不断变化到仅一点。序列在 [图 12.9](#Ch012_217-230_B9780443136979000254.xhtml#f0050) 中的同伦方形极左处示出。
