
## 量子数和电子构型

量子数允许唯一识别特定电子。这些是按顺序给出的，`n`、`L`、`m[L]` 和 `m[s]`![方程](Images/F000217si106.png)，分别代表能量、角动量、磁动量和角动量。主量子数是 `n`；它标识电子距离原子核的距离以及能量。轨道角动量量子数是 `L`；它标识轨道的形状。磁量子数是 `m[L]`，描述轨道的取向。电子自旋量子数是 `m[s]`![方程](Images/F000217si107.png)；它表示顺时针或逆时针旋转。相应的自旋表示为 `1/2` 或 `−1/2`，也分别称为自旋下或自旋上。如前所述，同一轨道最多可容纳两个电子；此时一个自旋向上，另一个自旋向下。这是由泡利不相容原理导致的，该原理是费米子Fock空间中[第15.3节](#Ch015_271-288_B9780443136979000291.xhtml#s0020)的一个基本概念。

电子构型还使用亚壳层标记。它指定主量子数 `n`，标识电子壳层。其后跟字母 `S`、`P`、`D` 或 `F`，表示亚壳层内的轨道类型。最后有一个上标表示亚壳层内的电子数。电子先填充较低的壳层，然后再填充较高的壳层。这被称为构造原理或 Aufbau 原理（[Scerri, 2013](#Ch006_103-128_B9780443136979000217.xhtml#bib24)）。

失去或获得电子的原子称为离子。当原子失去外层电子时，原子带正电，称为阳离子或正离子。当原子获得电子时，它变成负离子，也称为阴离子。

接下来给出在囚禁离子量子比特制备中使用的离子示例。然而必须提到，在离子阱量子制造中，扩展量子比特数量是困难的。

### Example 6.8

`Ca+` 离子是钙离子。它由钙原子失去其第四壳层、价壳层的 一个或两个电子而产生。核内存在20个质子，表示原子序数。该离子用于囚禁离子量子比特制备。该离子的电子构型为 `1s² 2s² 2p⁶ 3s² 3p⁶`。指数表示每个亚壳层的电子数。简而言之，它是2、8、8，因为 `1s²` 表示两个电子，`2s² 2p⁶` 显示八个电子，而 `3s² 3p⁶` 再次显示八个电子。因此该离子带正电，因为 `Ca²+` 中只有18个电子。如果价轨道只失去一个电子，则电子构型为 `1s² 2s² 2p⁶ 3s² 3p⁶ 4s¹`，即2、8、8、1.#

### Example 6.9

镱 `Yb` 离子也用于囚禁离子量子比特制备。在那里它被称为 `Yb 171`，由于其质量数，它是一种具有101个中子的同位素。`Yb` 有70个质子和103个中子。`Yb` 本身具有轨道结构，2、3、28、32、8、2。`Yb` 离子失去一个或两个价电子并带正电。#

自从使用囚禁离子制造量子比特以来，早在1990年代，主要的想法是利用它们制造通用计算机。在这一方向上，许多公司遵循了 DiVincenzo 关于如何构建量子计算机的标准（[DiVincenzo, 2013](#Ch006_103-128_B9780443136979000217.xhtml#bib8)）。这些计算机通常不是用于专门用途，如主要用于优化目的的 QAC。它们用于通用计算机，这里称为门定向计算机。DiVincenzo 标准共有七条，五条涉及计算机，两条涉及信息传输和量子信道的需求。这些标准通常被称为构建量子计算机的黄金标准。DiVincenzo 标准的第一条是获得具有明确定义的量子比特的可扩展系统。下一个基准是确保设备可以初始化为初始基准态，例如 `|0000000>`。至关重要的是量子比特具有较长的退相干时间。即需要在完成计算所需的时间内保持状态。拥有用于执行计算的通用量子门集以及基础门也是必须的。最后，对于计算机而言，必须具备测量能力。其他标准涉及通信。

类似的一套准则被用于半导体型量子比特，以用于量子门计算机。早期的量子点量子比特采用了 `Ga` 和 `As`。其后，`Si` 和 `Ge` 在量子点型量子比特的创建中取代了它们的位置。

### Example 6.10

下面给出了一些最著名的半导体材料的电子结构：

硅 `Si` 是原子序数为14的中性原子。其电子构型为 `1s² 2s² 2p⁶ 3s² 3p²`。

锗 `Ge` 是一种化学元素，原子序数为32。其电子构型为 `1s² 2s² 2p⁶ 3s² 3p⁶ 3d^(10) 4s² 4p²`。简而言之，电子分布为2、8、18、4。

镓 `Ga` 的原子序数为31。电子构型为 `1s² 2s² 2p⁶ 3s² 3p⁶ 3d^(10) 4s² 4p¹`。它可以以离子形式存在；此时为 `Ga+`，电子构型为 `1s² 2s² 2p⁶ 3s² 3p⁶ 3d^(10) 4s²`。它也可以构型为离子 `Ga+³`![方程](Images/F000217si108.png)，电子构型为 `1s² 2s² 2p⁶ 3s² 3p⁶ 3d^(10)`。

砷 `As` 的原子序数为33。其电子构型为 `1s² 2s² 2p⁶ 3s² 3p⁶ 3d^(10) 4s² 4p³`。#

## 6.6 Overview of qubit fabrication

量子比特本质上以两种不同的方式构建：有非固态平台，如囚禁离子和光子方法。第二种方式是使用固态器件。在固态情况下，最重要的方法是超导体。其次最重要的是量子点方法。最后，还有利用原子内缺陷的方法，例如金刚石中的 `NV` 中心。

*   • 囚禁离子是创建量子比特的原始方法之一。这些量子比特用于生产通用、门定向量子计算机。如前所述，离子是带电粒子；通常它是失去一个或多个电子的原子。中期九十年代的第一个量子比特由单个铍囚禁离子制成。激光控制剩余电子的离散能级。通常，这些能级用 `0` 或 `1` 表示。电磁场确保电子保持有序，以便可以识别它们。激光和无线电波用于切换量子比特的 `0` 或 `1` 属性。退相干对囚禁离子不是严重问题，因为它们未暴露于环境中。这些量子比特通过保持在黑暗真空中而得到保护。囚禁离子量子比特的问题在于难以制造大量，如前一节所述。然而，在[第6.7节](#Ch006_103-128_B9780443136979000217.xhtml#s0040)中，提供了这种类型量子比特制备的更详细描述。一台门定向40量子比特计算机最近被报道（[IonQ Staff, 2023](#Ch006_103-128_B9780443136979000217.xhtml#bib32)）。

*   • 中性原子是正负电荷相等的原子。这些实体与囚禁离子相似，但使用光来捕获原子并将其保持在位置。如常，量子比特被创建并进入叠加态。使用中性原子还允许更灵活的二维构型，因为不会限制原子之间的可能连接。这导致了创建量子比特之间纠缠的更简单方法。
