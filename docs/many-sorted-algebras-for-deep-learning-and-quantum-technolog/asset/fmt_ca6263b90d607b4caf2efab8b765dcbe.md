## 13.8 Spectra for self-adjoint, normal, and compact operators

It was seen that for a self-adjoint operator in `B(H)`, there is no residual spectrum, and moreover, the spectrum is always real. Approximate eigenvalues of an operator in `B(H)` are such that for any *ϵ*![Equation](Images/F000138si173.png)\> 0, there exists a unit vector `v` in `H`, such that `‖Tv−λv‖<ϵ`![Equation](Images/F000138si174.png). Replacing `v` by `w /‖w‖` for `w` not zero, the equivalent condition is as follows: For any *ϵ*![Equation](Images/F000138si175.png)\> 0, there exists a nonzero vector `w` in `H`, such that `‖Tw−λw‖<![ent](Images/epsi_1013.png)‖w‖`; then `λ`![Equation](Images/F000138si176.png) is an approximate eigenvalue for `T`. The set of all such `λ`![Equation](Images/F000138si177.png) for `T` is called the approximate spectrum of `T`. It will be denoted by `A(T)`. If `T` has an eigenvalue, then it is in `A(T)` since `Tv−λv` is identically zero. Additionally, `A(T)` is a true spectrum since `A(T)` is a subset of `spT`. The result follows by contradiction. If `λ`![Equation](Images/F000138si178.png) is not in `spT`, then `T−λI` is invertible. This implies that `∥v∥=∥(T−λI)^(−1)`![Equation](Images/F000138si179.png) `(T−λI) v∥` is less than or equal to `∥(T−λI)^(−1)∥∥Tv−λv∥`![Equation](Images/F000138si180.png) for every vector `v`, that is, `∥Tv−λv∥`![Equation](Images/F000138si181.png) is greater than or equal to `1/∥(T−λI)^(−1)∥∥v∥`![Equation](Images/F000138si182.png). Letting `ϵ=1/∥(T−λI)^(−1)`![Equation](Images/F000138si183.png)‖ shows that `‖Tv−λ`![Equation](Images/F000138si184.png) `v‖` is bounded below, and therefore `λ`![Equation](Images/F000138si185.png) is not in `A(T)`, which is a contradiction. So the conclusion is that `A(T)` is always a subset of `spT`.

For bounded normal operators, even more is true besides the result mentioned earlier; here, `spT=A(T)`, this was mentioned previously. That is, for a normal operator `T`, all eigenvalues are approximate. What must be shown is that `spT` is a subset of `A(T)`. Again contradiction will be employed. First say that there is an eigenvalue `λ`![Equation](Images/F000138si186.png) in `spT`, which is not in `A(T)`. Then for some `ϵ`![Equation](Images/F000138si187.png)\> 0, this eigenvalue is such that `‖Tw−λw‖` is greater or equal to ![ent](Images/epsi_1013.png)‖w‖ for all `v` nonzero. Since `T` is normal, it follows that `‖T∗w−λ∗w‖` is greater or equal to ![ent](Images/epsi_1013.png)‖w‖ for all `v` nonzero. So both `‖Tw−λw‖` and `‖T∗w−λ∗w‖` are bounded below, see [Section 13.1](#Ch013_231-253_B9780443136979000138.xhtml#s0010). If it can be shown that their ranges are dense, then a contradiction occurs, because then, in particular, `Tw−λw` would be invertible. Instead of showing the range to be dense, it is equivalent, showing that the orthogonal complement of the range is `{0}`. This follows since `ran(u)^⊥=ker(u*)`![Equation](Images/F000138si188.png), or `ker(u*)^⊥=clos(ran(u))`![Equation](Images/F000138si189.png). So if `v` is orthogonal to `Tw−λw`, that is, `<v, Tw−λw>=0` for all `w`, using the adjoint, this is the same as `<T∗v- λ∗v, w>=0` for all `w`. The latter equation implies that `T∗w−λ∗w=0`. However, using the previous bounded below property `∥T∗w−λ∗w∥`![Equation](Images/F000138si190.png) is greater than or equal to `ϵ`![Equation](Images/F000138si191.png)‖w‖ shows that `w=0`.

For normal operators, it is easy to show the relationship between eigenvalues of `T` and of `T∗`. The example below illustrates this fact

### Example 13.24

For `T`, a normal operator in `B(H)`, if `T v = λ v`![Equation](Images/F000138si192.png) for nonzero `v` in `H`, then `T∗ v = λ∗ v`![Equation](Images/F000138si193.png). This follows by letting `A` consist of all eigenvectors of `T` for which `λ`![Equation](Images/F000138si194.png) is an eigenvalue. Then since `T(T∗v)=T∗(Tv)=T∗ (λ v)=λ (T∗v)`, it follows that `T∗v` is in `A`. Consider the inner product, `<u, T∗v−λ∗v>` with the assumption that `u` is also in `A`. It follows that `<u, T∗v−λ∗v>=<u, T∗v>−<u, λ∗v>=<T u, v>−λ∗<u, v>=<T u, v>−<λ u, v>=<T u−λ u, v>=0`. Since `T∗v` is in `A`, as well as any nonzero constant times `v`, it shows that `T∗v−λ∗v` is in `A`. In turn, this implies that `T∗v=λ∗v`.

For compact self-adjoint operators `T`, on a Hilbert space `H`, the spectrum is a real-valued point spectrum with the possible exception of zero. The point zero might be an accumulation point, and therefore it might not be in the point spectrum. In this case, it is in the continuous spectrum. Again, the operator `T` can be represented as a converging sum of projections onto the eigenspace `{an, such that Tv=an, for v nonzero in H}`. That is, `Pn` is the projection onto this eigenspace and `an`, and `T` is the sum, `∑`![Equation](Images/F000138si195.png) `(an Pn)`. Also, for any `w` in `H`, it follows that `Tw` is equal to the sum, `∑`![Equation](Images/F000138si196.png) `(an Pn(w))`.

### Example 13.25

Consider a compact self-adjoint operator `T` on a Hilbert space `H`. It is possible that such an operator only has a point spectrum with eigenvalue 0. Accordingly, in this situation, 0 is not a point of accumulation; it is an isolated point. By the projection theorem for normal compact operators, `perp(ker(T))` cannot be infinite. For if it had an infinite `ON` basis `{ek}` with `Tek=ck ek`, and `ck→0`, then 0 is not isolated ([Conway, 1990](#Ch013_231-253_B9780443136979000138.xhtml#bib2)). Therefore, `perp(ker(T))` is finite and so `Ker(T)=0` has infinite dimension. It also follows that there exist countable infinite vectors, all with 0 as their eigenvalue.

If `T` and `S` are compact operators on `H`, the product `TS` and `ST` are compact, as well as the adjoint `S∗` and `T∗`. Moreover, `T∗T` is self-adjoint and positive; as such, it has nonnegative eigenvalues `an`. A compact operator `T` is said to be of trace class whenever the one norm of `T` is finite. The one norm is `‖T‖` and is such that the summation of the square root of each `an`, the eigenvalues of `T∗T`, is finite.

For a trace class operator `T`, the trace is defined as before: `Tr (T)` is the sum of the inner products: `<en, T en>`, where `en` is an `ON` basis on `H`. Additionally, the series must converge absolutely and independently of the `ON` basis employed. When `T` is also self-adjoint, then `Tr (T)=sum of the real eigenvalues of T`. Also, for a unitary operator `U` on `H`, it follows that the trace: `Tr(T)=Tr(U^(−1)T U)`![Equation](Images/F000138si197.png). See [Section 7.5](#Ch007_131-144_B9780443136979000205.xhtml#s0030).
