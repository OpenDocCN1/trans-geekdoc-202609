
当数据不是线性可分时，通常引入松弛变量以使约束方程不那么严格。约束现在变为如下：`y[i] (<w, v[i]>+b)` 大于或等于一减去松弛值 `s[i]`，通常取为非负的。因此，目标再次是最小化 `min ‖w‖²/2`，但 `s[i]`![方程](Images/F000163si88.png) 不能过大。提出了一个修正的拉格朗日问题：`min[‖w‖²/2 + C/n ∑ s[i]]`，其中最小化针对 `w`、`b` 和 `s[i]`。常数 `C` 是一个正参数，`n` 是数据点的数量，且求和从 1 到 `n`。值 `C` 在正则化的重要性和正确匹配训练集的重要性之间取得平衡。当 `C` 过大时，训练集匹配良好；如果 `C` 过小，则有利于过拟合。在后一种情况下，这对训练可能有好处，但对未见的真实数据可能就不太好。`C` 被称为误分类的惩罚参数。

利用约束方程得到 `L` 的公式，其中 `a[i]`![方程](Images/F000163si90.png) 和 `c[i]`![方程](Images/F000163si91.png) 是拉格朗日乘子。`L = ‖w‖²/2 + C/n ∑ s[i] + ∑ a[i] (1 - s[i] - y[i] (<w, v[i]>+b)) - ∑ s[i] c[i]`。如前所述，对 `L` 关于 `w`、`b` 和 `s[i]` 求偏导数或梯度，并令其等于零得到 `∂L/∂w = w - ∑ a[i] y[i] v[i] = 0`；`∂L/∂b = - ∑ a[i] y[i] = 0`；`∂L/∂s[i] = C/n - a[i] - c[i] = 0`。与严格间隔分类器类似，将这些偏导数代入 `L` 得到下面的对偶目标函数，因此需要最大化它或最小化其负值。因此，约束最小化为：`min 1/2 ∑∑ a[i] a[j] y[j] y[i] <v[i], v[j]> - ∑ a[j]`，最小化针对 `a[i]`![方程](Images/F000163si98.png)，约束为 `∑ a[i] y[i] = 0`，且 `a[i]` 大于或等于零，但小于或等于 `C/n`。这是 `C/n - a[i] - c[i] = 0` 且 `c[i]` 大于或等于零的结果。

如前所述，解涉及一个二次规划问题。与前述示例不同，Gram 矩阵 `G` 不会被显式使用。这里将使用一个 `n`×`n` 矩阵 `H`，其元素为 `H[i j] = y[j] y[i] <v, c, v[j]>`![方程](Images/F000163si100.png)。请注意，如果采用向量矩阵记号，则二次最小化为 `min 1/2 a' H a - a' I`。其满足 `a' y = 0`，且 `0` 小于或等于 `a[i]`![方程](Images/F000163si101.png) 小于或等于 `C/n`。在这种情况下，`a` 是 `a[i]`![方程](Images/F000163si102.png) 的向量，`y` 是 `y[i]`![方程](Images/F000163si103.png) 的向量，且 `I` 是单位向量。

## 18.9 核方法

本节是第 1.10 节和第 5.7 节的延续。回顾一下，在机器学习算法中，核被直接使用，而无需计算特征变换 `Φ`![方程](Images/F000163si104.png)，它将原始空间中的向量映射。这里利用了恒等式 `K(v,w) = < Φ(v), Φ(w)> = (<v, w>) ^(d)`。一个有趣的应用，未曾展示过，涉及非齐次多项式核。具体而言，`K(v,w) = (<v, w> + a)^(d)`，其中 `a` 是一个实数。根据二项式展开：`(<v,w> + a)^d = ∑_{k = 0}^{d} d!/(k! (d - k)!) <v,w>^k a^{d - k}`![方程](Images/F000163si105.png)。下面给出一个说明该核的例子。

### 例 18.9

设 `v` 和 `w` 在 `R²`![方程](Images/F000163si106.png) 中且 `a` 在 `R` 中；则令 `A = (<v,w>+a)² = (v[1]² w[1]² + 2 v[1] v[2] w[1] w[2] + w[2]² v[2]²) + 2 a (v[1] w[1] + w[2] v[2]) + a²`![方程](Images/F000163si107.png)。重新排列：`A = (v₁² w₁² + w₂² v₂²) + 2 (v₁ v₂ w₁ w₂) + a (v₁ w₁ + w₂ v₂) + a² = ∑_{i=1}^{2} v_i² w_i² + ∑_{i=1}^{2} ∑_{j=1}^{i-1} (2^{1/2} v_i v_j) (2^{1/2} w_i w_j) + ∑_{i=1}^{2} (2a)^{1/2} v_i (2a)^{1/2} w_i + a².`![方程](Images/F000163si108.png)![方程](Images/F000163si108a.png) 该表示很重要，因为它可以很容易地推广到更高维度。它还将使 `Φ`![方程](Images/F000163si109.png) 能够被找到。这里，核 = `< Φ(v), Φ(w)>`。内积中的两个自变量相同，因此因式分解将得到 `Φ(v)`。

因此，在本例中采用映射 `Φ : R² → R⁶`![方程](Images/F000163si110.png)。特征映射 `Φ`![方程](Images/F000163si111.png) 使用 `v = (v[1] v[2])'` 的两个元组，在 `R²`![方程](Images/F000163si113.png) 中。它将它们映射到所有可能的二阶、`d=2`、非齐次单项式，得到 `Φ(v) = (v[1]² v[1]² 2^{1/2} v[1] v[2] (2a)^{1/2} v[1] (2a)^{1/2} v[2] a)'`![方程](Images/F000163si114.png)′。请注意，这里交换律无关紧要。然而，如果采用与齐次情形相同的协议，则映射为 `Φ : R² → R⁷`![方程](Images/F000163si115.png)，其中不同的标记很重要，即尽管 `v[1] v[2] = v[2] v[1]`![方程](Images/F000163si116.png)，每个都占据一个不同的元组。因此：`Φ(v) = (v[1]² v[1]² v[1] v[2] v[2] v[1] (2a)^{1/2} v[1] (2a)^{1/2} v[2] a)'`![方程](Images/F000163si117.png)′。

回顾一下，核是一个涉及非空集合 `X` 的函数，使得 `K: X x X → R`。它与映射相关：`Φ: X → H`，其中 `H` 是实数上的希尔伯特空间。此外，对于 `x` 和 `y` 在 `X` 中，且 `K` 由内积定义：`K(x,y) = < Φ(x), Φ(y)>`，函数 `Φ` 被称为特征映射。此外，`K` 被称为特征核，而 `H` 有时被称为特征空间。`H` 不必是 RKHS。另一方面，RKHS 中的核也是特征核。特征核是对称且半正定的：设 `i` 和 `j` 在任意有限正整数集合中，且 `x[i]`![方程](Images/F000163si118.png)、`x[j]`![方程](Images/F000163si119.png) 在 `X` 中且 `a[i] a[j]`![方程](Images/F000163si120.png) 为实值，则 `∑_{i,j} a_i a_j K(x_i,x_j) = ∑_i ∑_j a_i a_j < Φ(x_i), Φ(x_j)> = ∑_i a_i < Φ(x_i), ∑_j a_j Φ(x_j)> = < ∑_i a_i Φ(x_i), ∑_j a_j Φ(x_j)> = || ∑_j a_j Φ(x_j) ||²`![方程](Images/F000163si121.png) 大于或等于零。用向量表示，`a' K a` 大于或等于零，其中 `a` 是由所有 `a[i]`![方程](Images/F000163si122.png) 组成的列向量，`a'` 是 `a[i]`![方程](Images/F000163si123.png) 的行向量，且 `K` 是 Gram 矩阵。
