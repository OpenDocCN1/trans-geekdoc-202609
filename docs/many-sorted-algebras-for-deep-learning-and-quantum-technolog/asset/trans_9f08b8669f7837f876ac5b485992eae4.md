
考虑 [图 18.3](#Ch018_327-348_B9780443136979000163.xhtml#f0020) 所示的数据。这里有 `N=6` 个数据点：标签为 0 的正方形和标签为 1 的三角形。原点处是待分类的项目 `x`。距离 `|x−x[*i*]|`，`i=1, 2, …, 6`，被计算并按从小到大的距离列出，同时给出其二元组向量表示。由于此情况下 `K=3`，仅检查排序表中的前三个条目以确定出现次数最多的标签。由于有两个 1 和一个 0，众数是 1。因此未知项被分类为三角形。误差在于，在 `K=3` 个最近距离中，只有其中一项未被归入已分类的条目中。

使用较小的 `K` 值会使 `KNN` 技术不稳定，即可能出现误分类。另一方面，更大的 `K` 值会因多数投票协议，即使用众数，而使方法更稳定。通常该方法先使用相对较小的 `K` 值进行，然后逐渐增大 `K` 的值。当与已分类项不同的项目数量变得过大时，这种增加就会停止。该方法很容易扩展到二元分类以外的分类。此外，该过程适用于 `n` 维的数据集，即每个向量中有 `n+1` 个元组。最后一个元组再次是一个分类标签。它可以是二元的、三元的等。

## 18.6 K 近邻回归

`KNN` 回归与 `KNN` 分类在许多方面不同。首先，它用于向量 (`x[*i*]`, `y[*i*]`)，其中标签 `y[*i*]` 可以取连续值，例如在 `R` 中。此外，首先假设数据集 {`x[*i*]`} 为实值且单调，`x[*i*]` < `x[*i* + 1]`![Equation](Images/F000163si23.png)，对于 `i=1, 2, …, N`。而且，对于每个 `x[*i*]`![Equation](Images/F000163si24.png)，关联一个正整数 `m[*i*]`![Equation](Images/F000163si25.png)，即标签数。因此存在 (`x[i]`, `y[*i*[1]]`)![Equation](Images/F000163si26.png)、(`x[*i*]`, `y[*i*[2]]`)![Equation](Images/F000163si27.png)、…、(`x[*i*]`, `y[*i*[*m[*i*]]]`)![Equation](Images/F000163si28.png) 向量。实际的回归过程相当于在数据集 {`x[*i*]`}![Equation](Images/F000163si29.png) 上形成一个函数 `f`。它满足 `f` : {`x[*i*]`}→`R`![Equation](Images/F000163si30.png)，其中使用经验均值估计量，$\\left. f \\right.\\hat{}\\left( x\_{i} \\right) = 1/K\\overset{K}{\\underset{j = 1}{\\sum^{}}}y\_{i\_{j}}$![Equation](Images/F000163si31.png)。此外，在求和中使用的 `K` 个值 `y[*i*[*j*]]`![Equation](Images/F000163si32.png) 使用某种度量或聚类算法彼此最接近。或者，为每个 `x[*i*]`![Equation](Images/F000163si34.png) 选择一个名义的、测试值 `y[*i*]`![Equation](Images/F000163si33.png)，并使用 `K` 个 `y[*i*[*j*]]`![Equation](Images/F000163si35.png) 值在平均值中使用，所有这些值都最接近 `y[*i*]`![Equation](Images/F000163si36.png)。

值 `K` 必须小于 `m[*i*]`![Equation](Images/F000163si37.png)。在任何情况下，`K` 始终可以等于一，但在这种情况下回归会过拟合。 resulting function would be very good for the trained data, but not so good using different data. 一般来说，标签非常丰富，在这种情况下，`K` 可以设为所有 `m[*i*]`![Equation](Images/F000163si38.png) 的最小值或更小。与分类 `KNN` 类似，使用不同的 `K` 值来确定最佳拟合函数。
