
# 等距同构证明

## 1) 由于 `H` 可分，它具有 Schauder 基：`{e[n]}` ![方程](Images/F000278si353.png)，`n`=1, 2, ….

## 2) 对于 `H` 中的 `v` 以及满足 `T`: `H` → `l²` ![方程](Images/F000278si354.png) 的 `T`，令 `T(v)` 为 `v` 与正交归一基 `{e[n]}` ![方程](Images/F000278si355.png) 的内积构成的序列。记该序列为 `(e[n])` ![方程](Images/F000278si356.png)。于是，`T(v)` = < `v`, `e[1]` >, < `v`, `e[2]` >, … = (< `v`, `e[n]` >) ![方程](Images/F000278si357.png)。

## 8) 最后，利用有界逆定理，参见附录 A.6。也就是说，如果 `A`: `X` → ![方程](Images/F000278si382.png) `Y`，其中 `X` 和 `Y` 为 Banach 空间且 `A` 为 1–1 且满射，则 `A^(-1)`: `Y` → ![方程](Images/F000278si383.png) `X` 也是有界的。由于所有这些条件都适用，`T` 具有有界逆。因此，`T` 是 `H` 与 `l²` 之间的等距同构。

## 附录 A

### 环绕数字信号的希尔伯特空间

所有环绕数字有界向量和有界矩阵的集合都构成希尔伯特空间。内积在它们零集的交集上求值。对于空交集，该积为零。完备性利用 Cauchy 序列 (`CSs`) 得出。在这些情况下，已证明它们形成有界向量或有界矩阵 `f[n]` 的 `CSs`。目标是证明 `f[n]` 收敛，设收敛到 `f`，在一范数下；其他范数以相同方式得出。首先要注意的是，如果 `f[n]` → `f`，则 `f[n]` 内的每个元素 `v[n]` 将收敛到设为 `v`。元素 `v[n]` 是有界向量内的元组，或有界矩阵 `f[n]` 内的矩阵项 `v[n]`。这种收敛成立是因为 || `f[n]` − `f` || 大于或等于特定项值差 | `v[n]` − `v` |。反之，如果每个元组元素都收敛，这意味着 `f[n]` 收敛，因为构成有界向量或有界矩阵结构的有元组数量是固定的有限数。如前所述，以下将采用一范数，但结果对任意范数均成立。事实序列已证明（[Apostle, 1974](#AppendixA_365-367_B978044313697900014X.xhtml#fur1); [Rudin, 1987](#AppendixA_365-367_B978044313697900014X.xhtml#fur2)）：
1. 每个实数序列都有单调子序列。
2. 每个 `CS` 都有界。
3. 有界实数单调序列总是收敛。
4. 每个实数 `CS` 都收敛。
5. 环绕有界向量和矩阵的空间是完备的，因此构成 Banach 空间也是希尔伯特空间。
6. 每个实数序列 `v[n]` 都有单调子序列。这一结果通过使用峰值得出。峰值 `v[m]` 是序列中的一个元素，使得 `v[m]` 大于序列中 `n` > `m` 的所有元素 `v[n]`。如果存在无限多个峰值，则这是一个由峰值组成的子序列且严格递减。另一方面，假设仅存在有限个峰值。令 `v[m]` 为最后一个峰值。然后从第 `m+1` 个值 `v[m+1]` ![方程](Images/F00014Xsi1.png) 开始在序列中。该值必须小于或等于序列中以下所有值，除了有限个，否则它也将是一个峰值。利用归纳法，令 `v[k]` 为序列中 `k` > `m+1` 的成员，且 `v[k]` 大于或等于 `v[m+1]` ![方程](Images/F00014Xsi2.png)。现在 `v[k]` 不是峰值，因此存在值 `p` > `k` 使得 `v[p]` 大于或等于 `v[k]`。继续这样，序列：`v[m+1]` ![方程](Images/F00014Xsi3.png) `v[k]` `v[p]` … 形成 `v[n]` 的子序列，且单调递增。

例 A.1
序列：1 0 1/2 0 1/3 0 1/4 …。该序列在每个奇数位置都有峰值，因此得到单调递减子序列，1 1/2 1/3 1/4 …。
