
# 振幅放大

设 `|w>` 为 `N` = 2^(`n`) ![Equation](Images/F000060si114.png) 个态 ${|{w > = 1/2^{n/2}}}\\sum\_{x = 0}^{N - 1}{{|x} >}$ ![Equation](Images/F000060si115.png) 的均匀叠加。 然后这些向量通常在条形图中表示，横坐标上有 `N` 个垂直线段条目，高度均为 1/2^(`n`/2) ![Equation](Images/F000060si116.png)。 见 [图 16.4A](#Ch016_291-305_B9780443136979000060.xhtml#f0025)。 均匀叠加通常是振幅放大算法的初始态。 其典型例子是 Grover 搜索，描述在下一章中。 在最简单的形式中，该搜索利用对 {`R[W]`, `U[f]`}，由两个反射算符组成，用于在 `|w>` 中找到单个向量 `|x*>`。 第一个反射 `U[f]` 的一次应用否定 `|x*>` 的值或将其关于横坐标反射。 也就是说，它变为 −`|`x*>`，或图形上它在线段图中反射态 `|x*>`；见 [图 16.4B](#Ch016_291-305_B9780443136979000060.xhtml#f0025)。 该算符也称为预言机。 在此图中，一条虚水平线表示 `U[f]|w>` 中所有态的概率振幅的新较低平均值 `u`。 概率振幅的整体较低平均值或整体较低均值出现的原因是 `U[f]` 的应用保持所有态不变但它否定了 `|x*>`。 因此这种单一否定会略微拉低整体平均振幅。 该平均值与涉及实际概率的真实平均值无关。 这是因为 `|x*>` 和 −`|`x*>` 的实际概率相同。 振幅的绝对值平方给出真实概率，因此该量不变。

下一个反射操作 `R[W]` 在此定义为均值的反射，或实际上是振幅的平均值 `u`。 因此，对于任意向量 `a[y]|y>`，其中 `|y>` 在 {0, 1}^(`n`) 中，关于该均值 `u` 的反射操作满足 `R[W] (a[y]|y>) = (2 u - a[y])|y>`。 通过从高度 `a[y]` 中减去 `u`，得到 (`a[y] - u`) 来证明该等式成立。 然后将该量关于 x 轴反射，如同 `U[f]` 的一次应用。 该操作仅否定该量。 因此结果为 (`u - a[y]`)，最后抬升，即再次加上 `u` 提供所需结果。

由于对于 `U[f]|w>` 中的所有向量 `U[f]|x>`，均值较小，除了 `U[f]|x*>`，应用算符 `R[W]` 会使这些振幅变得更小。 然而，`R[W] U[f]|x*>` 的振幅将变为其原始值的约三倍。 见 [图 16.4C](#Ch016_291-305_B9780443136979000060.xhtml#f0025)，图示并非按比例。 振幅放大是指利用一对反射算符如 `R[W]` 和 `U[f]` 连续应用的过程。 如果再次应用反射对，则首先，`U[f] R[W] U[f]|w>` 如 [图 16.4D](#Ch016_291-305_B9780443136979000060.xhtml#f0025) 所示，而 `R[W] U[f] R[W] U[f]|w>` 如 [图 16.4E](#Ch016_291-305_B9780443136979000060.xhtml#f0025) 所示。 无论如何，反射对的重复应用会产生所有态振幅的递减平均值，同时增加期望态的概率振幅。 这种有益的增加前提是 `π`/4`N`^(1/2) ![Equation](Images/F000060si117.png) 次 `R[W]U[f]` ![Equation](Images/F000060si118.png) 的应用未被超过。

这些反射是 Grover 搜索的基石。 该搜索对于诸如寻找最有效路径和类似优化问题等物流应用很有用。 它也用于机器学习算法，特别是分类问题。 此外，难以计算但易于验证的单向函数使用 Grover 搜索方法可提供良好结果。

## 16.11 反射

在有限希尔伯特空间 `H = C²` 中，反射具有精确的含义。 反射被用作线性算符 `R[W]`，`R[W]`: `H` → `H`。 该算符始终应用于非零向量 `|v>`。 通过这样做，它将该向量 `|v>` 关于指定的非零向量 `|w>` 反射。 见 [图 16.5A](#Ch016_291-305_B9780443136979000060.xhtml#f0030)，其中 `|v>` 和 `|w>` 连同反射的 ket `R[W]|v>` 一并示出。 最终结果用虚线书写。 其最简单的实例是当 `|w> = |0> = (1 0)'` 在计算基中，且 `|v> = (a b)'` 时。 那么 `R[W]|v> = (2|0><0| - I)|v> = (a -b)'`。 该操作也称为 Householder 反射 ([Householder, 1958](#Ch016_291-305_B9780443136979000060.xhtml#bib3))。 如上一节所述，使用扩散算符表示 `|w> = H^(@n) (|0>^(@n))`。 那么 `R[W]|v> = H^(@n) [2|0^(@n)><0^(@n)| - I] H^(@n)|v> = (2|w><w| - I)|v>`。

![图 16.5 反射操作。: (A) 两个向量和反射 ket，(B) 反射操作的结果。](Images/F000060f16-05-9780443136979.jpg)

图 16.5 反射操作。: (A) 两个向量和反射 ket，(B) 反射操作的结果。

因此，关于 `w` 执行反射的算符由 `R[W] = (2|w><w| - I)` 给出，其中 `I` 是恒等操作。

### 示例 16.18

设 `|w> = |0>` 为执行反射的简单向量。 如果待反射的向量为 `|v> = (3/5)^(1/2)|0> + (4/5)^(1/2)|1> = ((3/5)^(1/2)(4/5)^(1/2))` ![Equation](Images/F000060si119.png)′ 在 `C²` ![Equation](Images/F000060si120.png) 中，则执行反射的算符涉及纯密度函数 `|w><w|` 的两倍，以及恒等函数的负值。 因此 `R[W] =` ![Equation](Images/F000060si121.png)

$\\begin{matrix} {|1} & {0|} \\\\ {|0} & {{{- 1}|}.} \\\\ \\end{matrix}$

![Equation](Images/F000060si122.png)

将该算符应用于向量 `|v>` 给出 `R[W]|v> = (3/5)^(1/2)|0> - (4/5)^(1/2)|1> = ((3/5)^(1/2) - (4/5)^(1/2)))` ![Equation](Images/F000060si123.png)′ 在 `C²` ![Equation](Images/F000060si124.png) 中。 见 [图 16.5B](#Ch016_291-305_B9780443136979000060.xhtml#f0030)。#

反射算符是 Grover 搜索方法中的关键操作。 该算符与符号交替操作一起反复执行以执行该搜索。
