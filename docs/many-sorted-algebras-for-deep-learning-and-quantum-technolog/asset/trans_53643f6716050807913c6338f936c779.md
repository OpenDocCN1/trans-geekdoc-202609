
# 谱定理

再次为了激励涉及 `T` 的谱定理，`T` 是 `B(H,H)` 中的自伴算子，考虑载体集 `R^n`![Equation](Images/F000278si239.png)。另外，让 `T` 是 `H` 上的矩阵，具有不同的特征值，即 `T` 具有非退化的离散谱。假设 `sppT` 中的值是有序的，即 `m = λ[1] < λ[2] < … < λ[n] = M`。相应的特征向量应被归一化，从而形成一个 `ON` 基。定义投影算子 `P[j]`![Equation](Images/F000278si240.png)，使得 `P[j] v = < v[j], v > v[j] = a[j] v[j]`![Equation](Images/F000278si241.png)，其中 `v[j]`![Equation](Images/F000278si242.png) 是 `T` 的第 j 个特征向量且 `a[j]`![Equation](Images/F000278si243.png) 在 `R` 中。由于 `H` 中的任意向量都是基元素的叠加，则 $v = \\overset{n}{\\underset{j = 1}{\\sum^{}}}a\_{j}v\_{j}$![Equation](Images/F000278si244.png)，于是 $v = \\overset{n}{\\underset{j = 1}{\\sum^{}}}P\_{j}v$![Equation](Images/F000278si245.png)。作为结果，$\\overset{n}{\\underset{j = 1}{\\sum^{}}}P\_{j}$![Equation](Images/F000278si246.png) 可以被认为等于恒等元 `I`。这种情况下投影之和通常称为恒等式的分解。运算 `T v` 可以写成 ${Tv} = \\overset{n}{\\underset{j = 1}{\\sum^{}}}\\lambda\_{j}P\_{j}v$![Equation](Images/F000278si247.png)。相应地，当 `v` 非零时，算子 $T = \\overset{n}{\\underset{j = 1}{\\sum^{}}}\\lambda\_{j}P\_{j}$![Equation](Images/F000278si248.png)。

在此阶段，是时候从工程角度提供谱理论的本质了。基本上在这种情况下，将解释在谱 `spT` 上积分的含义是什么。首先暂时忘掉投影，并考虑位于每个特征值处的 delta 函数，`δ(t−λ[j])` 对于 `j=1, 2,…, n`。对于实数线上的连续函数 `f`，`f` 的一种谱积分是 $\\int\_{- \\infty}^{\\infty}{f\\left( t \\right)\\sum\_{j = 1}^{n}{\\delta{({t - \\lambda\_{j}})}}}{dt}$![Equation](Images/F000278si249.png)。这里积分从负无穷到正无穷。它也可以只到有限的上界，例如 `R` 中的 `x`。在这种情况下，只有小于或等于 `x` 的特征值才会被包含在积分中。该积分运算从实数映射到实数；具体来说，它将 `T` 的谱映射到 `R`。

首先，`P[1]`![Equation](Images/F000278si254.png) 将被确定。但首先，只会找到该矩阵的顶行 `x` 和 `y`。将 `P[1] v`![Equation](Images/F000278si255.png) 的第一个分量 `[x a + y b]` 设等于第一个特征向量与向量 `v` 的内积，全部乘以第一个特征向量的第一个分量，`1/13^(1/2)`![Equation](Images/F000278si256.png) `[(−3 2) (a b)′]` `(-3/13^(1/2))`。形成上述内积并使 `a` 和 `b` 的系数相等，其中 `[x a + y b]= -3/13 [−3 a + 2 b]`。最后求解 `x` 和 `y` 得到 `x=9/13` 和 `y=−6/13`。该计算提供了 `P[1]`![Equation](Images/F000278si257.png) 的第一行。

继续投影算子，这些算子用于将 `T` 的谱映射到 `B(H,H)`。考虑由投影之和构成的阶梯型函数，$E\_{\\lambda} = \\underset{\\lambda > = \\lambda\_{j}}{\\sum^{}}P\_{j}$![Equation](Images/F000278si262.png)。注意 `E[λ]=0` 对于 `λ < λ[1]`，并且对于 `λ`![Equation](Images/F000278si263.png) 在区间 `[λ[1],λ[2])` 中，`E[λ] = P[1]`![Equation](Images/F000278si264.png)；另外对于 `λ`![Equation](Images/F000278si265.png) 在区间 `[λ[2], λ[3])` 中，`E[λ] = P[1] + P[2]`![Equation](Images/F000278si266.png)。依此类推，直到 `λ`![Equation](Images/F000278si267.png) 的值大于或等于 `λ[n]`![Equation](Images/F000278si268.png)；然后 `E[λ] = I`![Equation](Images/F000278si269.png)。算子 `E[λ]`![Equation](Images/F000278si270.png) 可以被认为是一个阶梯型函数，在每个特征值处从右连续且具有 saltus `s[j]`![Equation](Images/F000278si271.png)。也就是说，在每个特征值 `λ[j]`![Equation](Images/F000278si272.png) 处，当 `λ = λ[j]`![Equation](Images/F000278si273.png) 时，跳跃值是 `P[j] − P[j − 1] = s[j]`![Equation](Images/F000278si274.png)。一般来说，`s[j] = E[λ[j]] − E[λ[j−]]`![Equation](Images/F000278si275.png)，其中 `E[λ[j−]]=limit as λ→λ[j]`![Equation](Images/F000278si276.png)，从左侧。
