
The ground state of zero can be algebraically explained using the ladder operators using the fact that the operators `a` and `a†` ![Equation](Images/F000291si32.png) are mutually adjoint. Here, for the annihilation operation energy, eigenstates can only be lowered to zero, and never less than this amount. To see that the minimum eigen number is zero, consider `N` = `a†a` ![Equation](Images/F000291si33.png), and `N phi[n] = n phi[n]`. Then `<phi[n]|N phi[n]> = <phi[n]|a†` ![Equation](Images/F000291si34.png) `a phi[n]> = <a phi[n]|a phi[n]> = , ||a|phi[n]>||²`, which is nonnegative and equals zero iff `a |phi[n]> = 0`, and so for `n = 0`, again, it is shown that `a |phi[0]> = 0`.

Basic Fock states with `n` bosons are given by the cyclic property of the creation operation: (`a†`)^(`n`) |0> ![Equation](Images/F000291si35.png), where `n` is a positive integer. These Fock states usually do not contain any information as to the phase. However, the bosonic coherent state `v` is in essence a Gaussian wave packet. It is a special bosonic state and involves the annihilation operator `a`. Specifically, it is the eigenstate of `a`. So, `a v = r v`, where `r` is the eigenvalue and since `v` is a state; it is assumed that `||v|| = 1`. Coherent states have dynamics similar to classical oscillatory trajectories and are related to the quantum harmonic oscillations ([Gazeau, 2009](#Ch015_271-288_B9780443136979000291.xhtml#bib4)).

The coherent state is given by an infinite sum involving the occupation numbers. It is defined as $v = e^{- {1/2}{|r|}^{2}}\\sum\_{n = 0}^{\\infty}{{{r^{n}/{({n!}^{1/2})}}|}n > ,}$ ![Equation](Images/F000291si36.png) where |n> is the number operation. To see this, let `v = the sum`, $\\sum\_{n = 0}^{\\infty}{{{cn}|}n >}$ ![Equation](Images/F000291si37.png), where `cn` are complex scalars. Then using the annihilation operation on `v`, `a v = the sum`, $\\sum\_{n = 1}^{\\infty}{{{{cn} a}|}n > =}$ ![Equation](Images/F000291si38.png) the sum, $\\sum\_{n = 1}^{\\infty}{{{{cn} n^{1/2}}|}n - 1 > =}$ ![Equation](Images/F000291si39.png) the sum, $\\sum\_{n = 0}^{\\infty}{{{c\\left( {n + 1} \\right)\\left( {n + 1} \\right)^{1/2}}|}n >}$ ![Equation](Images/F000291si40.png). Using the definition of `v` above, set `r v` equal to the sum, $\\sum\_{n = 0}^{\\infty}{{{{cn} r}|}n >}$ ![Equation](Images/F000291si41.png). Form the inner product of both of these quantities with the bra number operator `<n |`. Then use the orthogonality condition `<n, n′> = 0`, except when `n = n′`; in this case, the result is one. It follows that `c(n+1) (n+1)^(1/2) = cn r` or `c(n+1) = cn r / (n+1)^(1/2)`. Employing successive substitution to this difference equation yields `cn = c(n−1) r / n^(1/2)` and so `c(n−1) = c(n−2) r / (n−1)^(1/2)`; substituting gives `cn = c(n−2) r² / (n (n−1))^(1/2) = c(n−3) r³ / (n (n−1) (n−2))^(1/2) = … = co r^(n) / n!^(1/2)`. Thus, `v = the sum`, $\\sum\_{n = 0}^{\\infty}{{{cn}|}n >} =$ ![Equation](Images/F000291si43.png) the sum, $\\sum\_{n = 0}^{\\infty}{\\left( {{{{co} r^{n}}/{n!}^{1/2}}|} \\right.n >}$ ![Equation](Images/F000291si44.png). Since `||v|| = 1`, then `<v, v> = 1`. Forming this inner product gives `v = the sum`, $\\sum\_{n = 0}^{\\infty}{({{{|{co}|}^{2}{|r|}^{2n}}/{n!}})}$ ![Equation](Images/F000291si45.png); this follows because `<n, n′> = 0`, when `n, n′` differ. Therefore, `⟨v, v⟩ = |co|² e^(|r|²)` ![Equation](Images/F000291si46.png). Setting this quantity equal to one gives `|co|² = e^(−|r|²), or co = e^(−1/2|r|²)` ![Equation](Images/F000291si47.png). This shows that the coherent state `v = e^{- {1/2}{|r|}^{2}}\\sum\_{n = 0}^{\\infty}{r^{n}/{\\left( {n!}^{1/2} \\right){|{n >}}}}$ ![Equation](Images/F000291si48.png).

### Example 15.5

Consider two coherent states `v` and `w`, where `v` is given by the aforementioned expression and `w` is given in an identical manner as `v`, for instance, `w = e^(−1/2|s|²)` ![Equation](Images/F000291si49.png) $\\sum\_{n' = 0}^{\\infty}{\\left( {s^{n'}/\\left( {n'!}^{1/2} \\right)} \\right){|{n' >}}}$ ![Equation](Images/F000291si50.png). Then `⟨w, v⟩ = e^(−1/2|r|²) e^(−1/2|s|²) e^(r s*)` ![Equation](Images/F000291si51.png). This expression follows by substituting into the inner product for both `w` and `v`. Then, the only term needed to show is `e^(r s*)` ![Equation](Images/F000291si52.png), because the other terms are scalars. The last term follows by Taylor series expansions for both `w` and `v`. Then noticing that `<n′, n> = 0` except when `n′ = n`, here it is one. This reduces the double sum to a single sum. In this situation, the expansion becomes the sum, $\\sum\_{n = 0}^{\\infty}{\\left( {r s \\ast} \\right)^{n}/{n!}}$ ![Equation](Images/F000291si53.png), which in conclusion is formally given by `e^(r s*)` ![Equation](Images/F000291si54.png). Special cases arise: For `r = s`, then `<w, v> = 1`. Also, for `r = −s`, then `⟨−w, v⟩ = e^(−2|r|²)` ![Equation](Images/F000291si55.png). For larger `|r|`, `v` and `w` become close to orthogonal.

Now, the solution for defining the difference equation for the adjoint operator will be found. Recall `a† |n − 1> / n^(1/2) = |n>` ![Equation](Images/F000291si56.png), and the solution is not a surprise that any occupation number can be found from the vacuum state. Thus, `|n> = a^(† n) / n!^(1/2) |0>` ![Equation](Images/F000291si57.png). To see this, as before, iterate `a† |n − 2> / (n−1)^(1/2) = |n − 1>` ![Equation](Images/F000291si58.png); then substituting for `|n−1>` into the equation, `a† |n − 1> / n^(1/2) = |n>` ![Equation](Images/F000291si59.png), gives `a^(† 2) |n − 2> / (n (n−1)^(1/2))` ![Equation](Images/F000291si60.png). Continuing to iterate and substitute provides the desired results via induction.

## 15.3 The fermionic Fock space and the fermionic ladder operators

The occupation number in the case of fermionic Fock space is trivial because `N` can only be zero or one. Either there exists a particle in a given state or there is none. The occupation operator is a binary function in the fermionic Fock space. The ladder operators `a†` ![Equation](Images/F000291si61.png) and `a` in the fermionic Fock space are similar to those in the bosonic Fock space. Intuitively, as before, the creation operator `a†` ![Equation](Images/F000291si62.png) adds a particle to a state, but in this space the state must have to be empty. The annihilation operator removes a particle from a state, provided there is a single particle to be annihilated. This is also illustrated in [Fig. 15.1B](#Ch015_271-288_B9780443136979000291.xhtml#f0010). The anticommunication relations providing the fermionic Fock space algebra are given by the Poisson bracket: `{ai, aj} = ai aj + aj ai = 0`, for all states `i` and `j`, also `{a_i†, a_j†} = 0` ![Equation](Images/F000291si63.png), and finally, `{a_i, a_j†} = 0` ![Equation](Images/F000291si64.png), except that it equals one when `i = j`. As a consequence of the first two identities, it follows that `a a = a† a† = 0` ![Equation](Images/F000291si65.png). The number operator as in the bosonic case is given by `N = a† a` ![Equation](Images/F000291si66.png). However, since `{a a† + a† a} = 1` ![Equation](Images/F000291si67.png), then `a a† = 1 − N` ![Equation](Images/F000291si68.png). From this, `N (1 − N) = a† a a a† = 0` ![Equation](Images/F000291si69.png). So the eigenvalues for `N` are either zero or one. This confirms the Pauli principle that the occupation number is zero or one. It can be seen that the eigenstates of `N` are `a†` ![Equation](Images/F000291si70.png) `|0>` and `a |1>` with corresponding eigenvalues 1 and 0, respectively. These results follow since `(1 − N) a† |0> = a a† a† |0> = 0`, as well as `N a |1> = a† a a |1> = 0`.
