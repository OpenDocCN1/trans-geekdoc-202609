
4. 生成函数：`e^((2*x*t - t^2))` ![方程](Images/F000102si24.png) 乘以和 ∑ ![方程](Images/F000102si25.png) `(t^(k) / k! Hk)`，k=0, 1, 2, …

当它们被归一化时，它们用 `Hn` 表示，成为 `L2` 的一个 ON 基（非加权且不再是多项式），并且由 `Hn = e^(-1/2*x^2) h_n / (2^(n) n! (pi)^(1/2))^(1/2)` ![方程](Images/F000102si26.png) 给出。这些被称为 Hermite ON 函数。

对于拉盖尔多项式，`y = Ln(x)`，它们满足以下条件：

1. 微分方程：`x y'' + (1 - x) y' + n y = 0`，x 在 `[0, infinity)` 中，或用 Sturm–Liouville 表示 `(e^(-x) x y')' + n e^(-x) y = 0`。

2. 罗德里格斯公式：`Ln(x) = [(d/dx - 1)^(n)] x^(n) / n!`。

3. 差分方程：`L(n+1)(x) = [(2 n + 1 - x) Ln(x) - n L(n - 1)(x)] / (n + 1)`，对于 n=1, 2, 3, 4, …

4. 生成函数：和，`∑ t^(n) L_n(x) = (1 - t)^(-1) e^(-t x / (1 - t))` ![方程](Images/F000102si27.png)，n=0, 1, 2, …

二阶线性齐次微分方程可以通过定义积分因子 `p` 表示为 Sturm–Liouville 微分方程。方法如下所述，更为严格。对于线性算子，`L(y) = a y'' + b y' + c y`，如果 `p = e^(∫ (b - a') / a dx)` ![方程](Images/F000102si28.png) 在区间 `I` 上有限，并且 `V` 是函数向量空间，使得

1. `V` 在 `L` 下是不变的。
2. 对于 `V` 中的每个 `y`，`p y^2` 在 `I` 上的积分是有限的。
3. 对于 `V` 中的 `u` 和 `y`，`p a (u' y - u y') = p a (u' y - u y')` 在 `I` 的端点处求值的差为零，则 `L` 关于内积 `<y, u> = ∫ p y u dx` 是自伴的。
