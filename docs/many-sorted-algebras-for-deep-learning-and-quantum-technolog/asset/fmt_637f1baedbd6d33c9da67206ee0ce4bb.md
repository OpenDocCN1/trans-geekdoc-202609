
Consider the data illustrated in [Fig. 18.3](#Ch018_327-348_B9780443136979000163.xhtml#f0020). Here there are `N=6` data points: squares with label 0 and triangles with label one. At the origin is the item `x`, to be classified. The distance, `|x−x[*i*]|`, `i=1, 2, …, 6`, is calculated and listed from smallest to largest distance, along with their two-tuple vector representation. Since `K=3` in this situation, only the first three entries in the ordering table are examined for the largest number of common labels. Since there are two 1 s and one 0, the mode is 1. So the unknown is classified as a triangle. The error is that among the `K=3` closest distances, only one item was not among the classified entries.

Using a small value for `K` makes the `KNN` technique unstable, that is, it might misclassify. On the other hand, larger values of `K` make the method more stable due to the majority voting protocol, that is, using the mode. Usually the method is conducted with a relatively small value of `K` and then gradually increasing the values of `K`. This increase is halted once the number of items distinct from those classified becomes too large. The method is easily extended for other than binary classification. Additionally, the procedure works for data sets in `n` dimensions, that is, `n+1` tuples in each vector. The last tuple is again a categorical label. It can be binary, trinary, etc.

## 18.6 K-nearest neighbor regression

`KNN` regression is different from `KNN` classification in numerous ways. First of all, it is employed on vectors (`x[*i*]`, `y[*i*]`), for which the labels `y[*i*]` can take on continuous values, say in `R`. Additionally, to begin, it is assumed that the data set, {`x[*i*]`}, is real valued and monotonic, `x[*i*]` < `x[*i* + 1]`![Equation](Images/F000163si23.png), for `i=1, 2, …, N`. Moreover, for each `x[*i*]`![Equation](Images/F000163si24.png) a positive integer `m[*i*]`![Equation](Images/F000163si25.png), number of labels, is associated. Thus, there exist (`x[i]`, `y[*i*[1]]`)![Equation](Images/F000163si26.png), (`x[*i*]`, `y[*i*[2]]`)![Equation](Images/F000163si27.png), …, (`x[*i*]`, `y[*i*[*m[*i*]]]`)![Equation](Images/F000163si28.png) vectors. The actual regression process amounts to forming a function `f`, defined on the data set {`x[*i*]`}![Equation](Images/F000163si29.png). It is such that `f` : {`x[*i*]`}→`R`![Equation](Images/F000163si30.png), where the empirical mean estimator is used, $\\left. f \\right.\\hat{}\\left( x\_{i} \\right) = 1/K\\overset{K}{\\underset{j = 1}{\\sum^{}}}y\_{i\_{j}}$![Equation](Images/F000163si31.png). Furthermore, the `K` values `y[*i*[*j*]]`![Equation](Images/F000163si32.png) that are employed in the sum are closest to each other using some metric, or clustering algorithm. Alternatively, a nominal, test value `y[*i*]`![Equation](Images/F000163si33.png) is chosen for each `x[*i*]`![Equation](Images/F000163si34.png), and `K` values of `y[*i*[*j*]]`![Equation](Images/F000163si35.png) are utilized in the average, all of which are closest to `y[*i*]`![Equation](Images/F000163si36.png).

The value `K` must be less than `m[*i*]`![Equation](Images/F000163si37.png). In any case, `K` always could be equal to one, but in this situation the regression is an overfit. The resulting function would be very good for the trained data, but not so good using different data. In general, there is an abundance of labels, and in this situation, `K` could be set equal to or less than the minimum of all the `m[*i*]`![Equation](Images/F000163si38.png). Similar to the classification `KNN`, different values of `K` are used to determine the best fitting function.

### Example 18.7

Suppose it is thought that the data set {`x[*i*]`}![Equation](Images/F000163si39.png) has labels that approximately follow a square law path, that is, `f`(`x[*i*]`) = `y[*i*]` = `x[*i*]`²![Equation](Images/F000163si40.png). If a data point say `x[*i*]` = 1![Equation](Images/F000163si41.png) is chosen along with its labels, the vectors are (`x[*i*]`, `y[*i*[1]]`)![Equation](Images/F000163si42.png), (`x[*i*]`, `y[*i*[2]]`)![Equation](Images/F000163si44.png), …, (`x[*i*]`, `y[*i*[*m[*i*]]]`)![Equation](Images/F000163si46.png). Assume that these vectors are (1, 1.3), (1, 0.7), (1, 0.3), (1, 1.4), (1, 1.2). Here, `m[*i*]` = 5![Equation](Images/F000163si47.png), and say that `K=3`. Then since, `y[*i*]` = `x[*i*]`² = 1![Equation](Images/F000163si48.png), in this example the distance from 1 to all five labels must be found as in usual `KNN` methods. Again, only the closest three are chosen. In this case, the three vectors are (1, 1.3), (1, 0.7), and (1, 1.2). It is the labels in the second tuple that are used in forming the average. Thus, $f^{˄}\\left( x\_{i} \\right) = 1/K\\overset{K}{\\underset{j = 1}{\\sum^{}}}y\_{i\_{j}} = f^{˄}\\left( 1 \\right) = 1/3\\overset{3}{\\underset{j = 1}{\\sum^{}}}y\_{i\_{j}} = 1/3\\left( {1.3 + .7 + 1.2} \\right) = 1.06$![Equation](Images/F000163si49.png).

`KNN` regression can be performed using `n`-dimensional data sets, where again it is assumed that there is a strict order in the data, and the labels are from a continuous sort.

## 18.7 Quantum K-means applications

Several recent articles have appeared involving quantum `K-means` applications. For instance, [Kavitha and Kaulgud (2022)](#Ch018_327-348_B9780443136979000163.xhtml#bib03) employ unsupervised training methods for data mining and machine learning in determining heart disease using quantum circuits. A brief description is provided in the next paragraph. Quantum techniques have shown to perform better than classical techniques in several areas such as classification, detection, and tacking, as well as in optimization ([Shah and Gorard, 2019](#Ch018_327-348_B9780443136979000163.xhtml#bib06)). A somewhat related work was performed by [Singh and Bose (2021)](#Ch018_327-348_B9780443136979000163.xhtml#bib07); here a quantum optimization scheme was employed in a `K-means` algorithm for use in CT chest images. A quantum approach for solving mean clustering using `QUBO` model is explained in [Date et al. (2021)](#Ch018_327-348_B9780443136979000163.xhtml#bib01). Additionally, [Khan (2019)](#Ch018_327-348_B9780443136979000163.xhtml#bib04) used quantum and destructive interference along with rotations to implement `K-means` clustering. Although Grover’s search provides a speedup relative to classical techniques, it is not able to increase the ability to form clusters ([Flick et al., 2017](#Ch018_327-348_B9780443136979000163.xhtml#bib02)).

In the first referenced paper, for quantum `K-means` clustering, [Kavitha and Kaulgud (2022)](#Ch018_327-348_B9780443136979000163.xhtml#bib03) employed data preprocessing for quantum that involves the `PCA` along with outlier rejection techniques. Quantum circuits are created for centroid and distance calculation methods. Centroid and cluster updates are performed in an iterative fashion until convergence is achieved. Quantum processing to form clusters is shown to be the paramount improvement area in speed. Prior to performing the `K-means` clustering, data was converted into quantum states using the method given in [Benlamine et al. (2020)](#Ch018_327-348_B9780443136979000163.xhtml#bib2). The quantum `K-means` clustering is achieved using three subroutines. First, a swap test gate is employed to calculate the distance between a centroid cluster `|ϕ>` and a data point `|Ψ>`; this is followed by cluster updates and centroid updates.
