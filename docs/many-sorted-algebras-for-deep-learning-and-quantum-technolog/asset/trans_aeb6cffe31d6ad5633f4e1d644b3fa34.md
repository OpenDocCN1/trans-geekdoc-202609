
## 部分等距与多元图

![图14.3 部分等距 \[U, U\*\] 的多元图非零。](Images/F00028Xf14-03-9780443136979.jpg)

图14.3 部分等距 [`U`, `U*`] 的多元图非零。

就本情况而言，当对二元算子 `MULT` 的第一个操作数或参数进行应用时，该操作没有限制。假设在此情况下，多元箭头的尾部有一个单划线。然而，多元箭头的第二个尾部用两条斜线标记。然而，在当前情况下，用于的操作数存在限制。为了解释这一点，必须确定单一类型载体集 `STRING`。`STRING` 为 {`U`, `U*`}! 并定义为包含 `U` 或 `U*` 的所有字符串的集合，其长度为任意有限非零，但字符串内不包含两个或更多相邻的相同元素。因此，带星号的元素与不带星号的元素必须交替出现。它们在任何字符串中都不能相邻。例如，`UU*UU*` 是允许的；它是一个长度为四的交替字符串。字符串的后部 `b` 是最左边的元素；然而，在函数复合中它是最后应用的。字符串的前部 `f` 是字符串的最右边元素。对于长度为二的字符串，它在函数复合中首先被应用。该结构使用字符串的连接二元运算构成一个半群。然而，即使在此代数中乘法是算子本身的连接，如前所述，当应用于希尔伯特空间中的元素时，它们被用于函数复合。从右到左，而不是从左到右。这种顺序与之前描述的基本群不同。参见 [第12.4节](#Ch012_217-230_B9780443136979000254.xhtml#s0025)。

部分等距是一个幂等元，使用一元运算名称伴随 `ADJ`，以及后面给出的三个等式约束。首先，描述使字符串有效的原因。

`MULT:STRINGxSTRING→STRING`

![方程](Images/F00028Xsi19.png)

`ADJ:STRING→STRING`

![方程](Images/F00028Xsi20.png)

以下记号：
* `Mult` 为 `·`
* `ADJ` 为 `*`
* `STRING` 为由 {`U`, `U*`}! 中的元素连接而成。再次说明，这是由一个或多个 `U` 或 `U*` 组成且始终交替的集合。

二元运算是部分的，因为第二个输入字符串的前部必须是第一个输入字符串的后部的伴随。形式上：`f2=(b1)*`。这防止了两个或更多相同的元素 `U` 相互相邻。`U*` 亦然。例如，假设第一个参数为 →`U*UU*UU*`；则 `b1` 为 `U*`，箭头指向它。因此，第二个参数必须具有前项 `U`，且无 `*`。于是假设第二个输入为 `U*U`，这是一个有效输入；那么 `MULT` 操作的结果为 `U*U·U*UU*UU*=U*UU*UU*UU*`，是一个长度为七的字符串。更一般地，存在的一个有效字符串例如记作 `T=u.v.w.y.z`，其中 `z` 为第一个字符串。它之所以有效，是因为 `y` 中的前项等于 `z` 中最后一项的伴随。这表示为 `fy=bz*`。因此，由于单个字符串 `y` 和 `z` 相乘得到新字符串 `yz`，`T=u·v·w·yz`，然后乘法确保 `w` 的前部具有字符串 `yz` 的后部的伴随值。符号上，`fw=b(yz)*=b(y)*z`，得到 `T=u·v·wyz`；再次，`fv=b(wyz)*=b(w)*yz` 因此 `T=u·vwyz`；最后，`fu=b(vwyz)*=b(v)*wyz` 给出 `T=uvwyz`。

对于多元图，第二个输入不仅被双斜线标记，而且在其旁边还有伴随符号 `*`。这是提醒第二个参数必须是一个字符串，其第一个符号是第一个参数的最后一个符号的伴随。作为另一个提醒，第一个参数位于第二个参数的右侧，如函数复合中那样，而不是连接。[图14.3](#Ch014_255-270_B978044313697900028X.xhtml#f0020) 说明了其中许多事实。幂等半群的等式约束如下：
1. 1) 幂等伴随：(`U*`)*=`U`。
2. 2) 幂等：(`UU*`)² = `UU*·UU*` = `UU*` ![方程](Images/F00028Xsi21.png)。
3. 3) 结合律：(`x·(y·z)`)=`((x·y)·z)`；这将在下文证明。

使用正式但具有启发性的记号：从3)的左边开始，(`x·(y·z)`)。如前所述，令 `f` 表示第二个输入的前部，`b` 表示第一个输入字符串的后部。则 `fy=(bz)*`，`fx=(byz)*`，这与 `fx=b(y)*z` 完全相同。这是由于 `yz` 的后部与 `y` 的后部相同。因此，(`x·(y·z)`)=`xyz`。反过来 (`(x·y)·z`)，由于 `fx=(by)*`，现在 `f(xy)=x f y=(bz)*` 给出 (`(x·y)·z`)=`xyz`。因此，结合律成立；因此，该结构不仅仅是一个群胚；它是一个幂等半群。

希尔伯特空间上的幂部分等距是 `U`，使得对于所有正整数 `U^(n)` ![方程](Images/F00028Xsi22.png) 它也是一个部分等距。所有等距及其伴随都是幂等距。非等距幂部分等距的一个重要例子是下一个示例中的截断移位运算。

### 示例 14.9

截断移位 `T_n : C^(n) → C^(n)` ![方程](Images/F00028Xsi23.png)，其中当 `j < n` 时 `T_n(e_j)=e(j+1)`，否则为零。这里，`{e1, e2,…, en}` 是 `C^(n)` ![方程](Images/F00028Xsi24.png) 的基集。因此，例如，若 `n=3`，则 `T3(e1)=e2`。此外，(`T3`)²(`e1`) = `e3`，(`T3`)³(`e1`) = `0` ![方程](Images/F00028Xsi25.png)。在所有情况下，`perp(ker(T))=ran(T)`。

一般而言，部分等距的复合很少本身是部分等距。已证明如果 `S` 和 `T` 是部分等距，则 `ST` 也是部分等距，当且仅当 `SS*` 和 `TT*` 交换。此外，即使对于幂部分等距，它们也与酉算子的直和酉等价。这些是 `l²` 上的单边移位 `S` 及其伴随的拷贝。此外，还有前一示例中给出的截断移位 `T_n` 的拷贝，但对于所有正整数 `n`（[Hoover and Lambert, 1974](#Ch014_255-270_B978044313697900028X.xhtml#bib4)）。

## 14.5 Stone定理

简而言之，Stone定理在希尔伯特空间 `H` 中的自伴算子与一参数酉算子族之间建立了一一对应关系。一参数酉算子族构成一个群。这些算子 `U` 依赖于一个实参数，且对于 `R` 中的 0、`s` 和 `t`。
1. 1) 恒等 `U(0)=I`
2. 2) 转移 `U(s+t)=U(s)+U(t)`。

该定理中的一参数群在 `H` 中是强连续的。这是 SOT，意味着当 `s→t` 时，极限 `‖U(s)v−U(t)v‖=0`，对所有 `H` 中的向量 `v` 和 `R` 中的 `t` 成立。由于本文档中的希尔伯特空间是可分的，除非另有说明，弱连续就足够了。即 WOT 且当 `s→t` 时极限 `<(U(s)−U(t))v, v>=0`，对所有 `H` 中的向量 `v` 和 `R` 中的 `t` 成立。在 [第9.1节](#Ch009_165-169_B9780443136979000242.xhtml#s0010) 中，提供了 SOT 和 WOT 的描述及示例。不可分希尔伯特空间将在后续章节中考虑。参见 [第9.1节](#Ch009_165-169_B9780443136979000242.xhtml#s0010)，其中涉及算子拓扑。在引用的章节中提供了 SOT 和 WOT 的示例以及反例。

最重要的是，Stone定理建立了希尔伯特空间 `H` 中具有稠密定义域的非有界自伴算子 `T` 生成一参数连续酉算子群：`U(t)=e^(i t T)` ![方程](Images/F00028Xsi26.png)。此外，所有这些酉群都是以这种方式生成的。即存在 `H` 上稠密定义的自伴算子 `T`，使得 `U(t)=e^(i t T)` ![方程](Images/F00028Xsi27.png)。对于 `R` 中的 `t′` 和 `H` 中的 `v`，极限 `t→t′` 时 `U(t)v=U(t′)v`。此外 `U(t+t′)=U(t)U(t′)`。
