
# Hardy RKHS Construction

To construct the Hardy RKHS, let `L`: `H`^∞→`l`²![Equation](Images/F000278si78.png), where `L`(`f`) = (`a`[0] `a`[1]…)![Equation](Images/F000278si79.png). The Hardy space `H`^∞![Equation](Images/F000278si80.png) is identified with `l`²![Equation](Images/F000278si81.png). Because `L` is linear and is an isometric isomorphism between `H`^∞![Equation](Images/F000278si82.png) and `l`²![Equation](Images/F000278si83.png), this implies that `H`^∞![Equation](Images/F000278si84.png) is a Hilbert space. Using the formal power series inner product, let $f\\left( z \\right) = \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}}a\_{n}z^{n}$![Equation](Images/F000278si85.png) and $g\\left( z \\right) = \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}}b\_{n}z^{n}$![Equation](Images/F000278si86.png) be analytic in the unit disk `D`. The inner product is $< f,g > = \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}}a\_{n}^{\*}b\_{n}$![Equation](Images/F000278si87.png). All sums are from zero to infinity from here on. By the CBS inequality, |∑^()``a``[`k`]^(\*)*b*[*k*]|²![Equation](Images/F000278si88.png) is less than or equal to ∑|``a``[`k`]|²∑|``b``[`k`]|²![Equation](Images/F000278si89.png). So for every `z`[0]![Equation](Images/F000278si90.png) in `D`, `g`[`z`[`o`]](`z`) = ∑`z`[0]\*^(`n`)`z`^(`n`) = 1/(1−`z`[0]\*`z`)![Equation](Images/F000278si91.png). Note that <f, `g`[`z`[`o`]] >  = ∑`a`[`k`]`z`[0]\*^(`n`) = `f`(`z`[0])![Equation](Images/F000278si92.png), and |<f, `g`[`z`[`o`]]![Equation](Images/F000278si93.png)\>| is less than or equal to ∥`f`∥∥`g`[`z`[`o`]]∥![Equation](Images/F000278si94.png). The results will lead to an evaluation functional. The induced norm is $\\left\\| f \\middle| |^{2} = \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}} \\middle| a\_{n}|^{2} \\right.$![Equation](Images/F000278si95.png). To see that each power series converges to a function on `D`, simultaneously, consider the evaluation functional `E`[`z`](`f`)![Equation](Images/F000278si96.png). The objective then is to show that it is bounded, for z in `D`, so let $E\_{z}\\left( f \\right) = \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}}a\_{n}z^{n}$![Equation](Images/F000278si97.png). This is a complex number, so `E`[`z`]![Equation](Images/F000278si98.png) is a functional. The absolute value $\\left| E\_{z}\\left( f \\right) \\middle| = \\middle| \\sum\_{n = 0}^{\\infty}{a\_{n}z^{n}} \\right.$![Equation](Images/F000278si99.png) | is less than or equal to $\\left. \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}} \\middle| a\_{n} \\right\\| z|^{n}$![Equation](Images/F000278si100.png) is less than or equal to $\\left\\lbrack \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}} \\middle| a\_{n}|^{2}\\overset{\\infty}{\\underset{n = 0}{\\sum^{}}} \\middle| z|^{2n} \\right\\rbrack^{1/2}$![Equation](Images/F000278si101.png) that is less than or equal to ‖f‖ \[1/(1−|z|²)\]^(1/2). Accordingly, ‖E[`Z`]‖ is bounded by \[1/(1−|z|²)\]^(1/2), and `H`^∞![Equation](Images/F000278si102.png) is a RKHS over `X`=`D`. The kernel for a point w in `D`, in this case, is the Szego kernel: `K`(`z`,`w`) = `K`[`w`](`z`) = 1/(1+`w`*`z`)![Equation](Images/F000278si103.png). To see this, use the definition of the inner product for $g\\left( z \\right) = \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}}w^{n\_{\\ast}}z^{n}$![Equation](Images/F000278si104.png) and $f\\left( z \\right) = \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}}a\_{n}z^{n}$![Equation](Images/F000278si105.png), both in `H`^∞![Equation](Images/F000278si106.png). Here $< g,f > = \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}}w^{n}a\_{n} = f\\left( w \\right)$![Equation](Images/F000278si107.png). This means that g is a reproducing kernel for w in `X`=`D`, and therefore, summing the series for $g = \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}}w^{n\_{\\ast}}z^{n}$![Equation](Images/F000278si108.png) gives the Szego kernel K(w, z)=1/(1−w\*z). Also, ‖E[`Z`]‖²\=K(z, z)=1/(1−z\*z)=1/(1−|z|²).

For every x in `X`, there is a `K`[`x`]![Equation](Images/F000278si109.png) in H such that for all f in H <f, `K`[`x`]![Equation](Images/F000278si110.png)\>=f(x). ### Example 19.4

The Mittag-Leffler real-valued RKHS of order q> 0 consists of functions in $F = \\left\\{ f\\left( z \\right) = \\sum\_{n = 0}^{\\infty}{a\_{n} z^{qn}} \\right.$![Equation](Images/F000278si121.png), such that $\\sum\_{n = 0}^{\\infty}\\left. {|a\_{n}|}^{2}\\Gamma\\left( {{qn} + 1} \\right) < \\infty \\right\\}$![Equation](Images/F000278si122.png), where the gamma function is *Γ*(*z*) = ∫[0]^∞*t*^(*z* − 1)*e*^( − *t*)*d**t*![Equation](Images/F000278si123.png). The kernel is given by the Mittag-Leffler function: `K`[`q`](*λ*, *t*) = `E`[`q`](*λ*^(`q*), *t*^(`q*))![Equation](Images/F000278si124.png), where $E\_{q}\\left( z \\right) = \\overset{\\infty}{\\underset{n = 0}{\\sum^{}}}z^{n}/{\\lbrack{\\Gamma{({{qn} + 1})}}\\rbrack}$![Equation](Images/F000278si125.png). This function is entire and generalizes the exponential function. When q=1, `E`[1](*z*) = *e*^(*z*)![Equation](Images/F000278si126.png); moreover, when the Bargmann-Fock space is restricted to the positive x-axis, the Mittag-Leffler real-valued RKHS is a consequence. On the other hand, a complexification of the Mittag-Leffler real-valued RKHS will yield a Mittag-Leffler space of entire functions generalizing the Bargmann-Fock space ([Rosenfeld et al., 2018](#Ch019_349-364_B9780443136979000278.xhtml#bib10)).
