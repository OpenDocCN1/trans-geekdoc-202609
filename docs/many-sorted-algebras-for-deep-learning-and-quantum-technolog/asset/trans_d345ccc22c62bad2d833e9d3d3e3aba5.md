

受时间无关薛定谔方程启发，`H(t) |ψ[k](t)> = E[k](t) |ψ[k](t)>`，`k = 1, 2, …`。绝热条件为含时薛定谔方程提供了一个近似解。该解涉及瞬时本征值和涉及哈密顿量的本征态方程。在这种情况下，必须在过程中能量缓慢变化。还假设所有能级相距甚远，即 `E[k](t)` 与所有其他离散能级明显分离。此外，假设相邻能级之间满足以下不等式，`E[k−1](t) < E[k](t) < E[k+1](t)`。绝热定理为真实态 `|Ψ[k](t)>` 提供了近似。它说 `|Ψ[k](t)>` 大致等于 `e^(iθ[k]) e^(iγ[k]) |ψ[k](t)>`。另一个必要条件是初始条件的相等，即 `|Ψ[k](0)> = |ψ[k](0)>`。这里，薛定谔方程在零时刻的近似解等于零时刻的瞬时能量本征态解。近似中的指数将在下一段中描述，以下分析仅为形式上的。

实值量 `θ[k]` 是能量本征态的动力学相位。动态相位由 `θ[k](t) = −1/h ∫[0]^(t) E[k](t′) dt′` 给出。另一个实值量是 Berry 相位 `v[k]`；它也是实值的。Berry 相位由近似波函数与其导数的内积给出。该内积为 `v[k] = i <ψ[k](t), dψ[k](t)/dt>`。此外，令 `γ[k](t) = ∫[0]^(t) v[k](t′) dt′`。接下来，将研究一个类似于 Berry 相位的量。它被称为耦合项，并涉及不同的能量态。目标是了解耦合项如何与哈密顿量相关，以及耦合项在多大程度上影响绝热过程。

要了解耦合项 `<ψ[n](t), dψ[k](t)/dt>` 如何与哈密顿量相关，首先考虑 k 与 n 不同时的瞬时本征函数条件，`H(t) |ψ[k](t)> = E[k](t) |ψ[k](t)>`。对该本征函数方程求微分得到 `dH/dt |ψ[k]> + H |dψ[k]/dt> = dE[k]/dt |ψ[k]> + E[k] |dψ[k]/dt>`。这里，最后一个恒等式只是两次使用了本征函数方程。接下来，在最后一个恒等式的两边左侧应用 bra 运算 `<ψ[n](t)|`。该运算将前一方程中的项夹在中间。这样得到 `<ψ[n](t) | dH/dt |ψ[k]> + <ψ[n](t) | H | dψ[k]/dt> = <ψ[n](t) | dE[k]/dt |ψ[k]> + <ψ[n](t) | E[k] | dψ[k]/dt>`。再次使用本征函数方程 `H |ψ[n](t)> = E[n] |ψ[n](t)>` 并将其转换为涉及 bras 的方程。为了做到这一点，使用共轭并记住标量场是实数；因此，`<ψ[n](t) | H = E[n] <ψ[n](t) |`。此外，注意当 k 和 n 不同时 `<ψ[n](t) | dE[k]/dt = 0`。把这些全部放在一起得到 `<ψ[n](t) | dH/dt |ψ[k]> + E[n] <ψ(t) | dψ[k]/dt> = E[k] <ψ[n](t) | dψ[k]/dt>`。注意最后两项有一个共同的内积，这正是耦合项。求解该项可得 `<ψ[n](t) | dψ[k]/dt> = <ψ[n](t) | dH/dt |ψ[k]> / (E[k] − E[n])`。最终结果是 `<ψ[n](t) | dψ[k]/dt> = (dH/dt)_{n,k} / (E[k] − E[n])`，其中如前所述 `E[k]` 和 `E[n]` 不同。量 `(dH/dt)^{(n,k)}` 是哈密顿量矩阵导数中的 n,k 项。结论是耦合项会破坏绝热近似。每当哈密顿量导数中的 n,k 项很小时，就会发生这种情况。以下示例序列遵循 ([兹维巴赫，2018](#Ch006_103-128_B9780443136979000217.xhtml#bib31))。

### 示例 6.13

这是一个说明绝热近似误差的例子。它表明随着时间 T 增大，误差按 1/T 减小。考虑一个哈密顿量 `H(t) = H[0]` 当 `t < 0` 时，`H[0] + H[1] t/T`，当 t 在 `[0, T]` 内时，以及 `H[0] + H[1]`，当 `t > T` 时。这里，`0 < T` 且 `0 < H[0] < H[1]`。参见 [图 6.4A](#Ch006_103-128_B9780443136979000217.xhtml#f0025)。对于 `t` 在 `[0, T]` 内，`dH/dt = H[1]/T`。近似中的所有误差都像 `1/T` 一样消失。

Landau-Zener 转变描述了本征函数 `ψ[1](x,R)` 和 `ψ[2](x,R)` 的绝热以及可能的非绝热变化。它们代表了分子在固定核的情况下的两种不同的电子排列，使得它们相距 R。 在 [图 6.4B](#Ch006_103-128_B9780443136979000217.xhtml#f0025) 中，给出了与相应本征函数相关的能量的示意图。例如，在此图中，`E[1](R)` 可能是基态中本征态波的能量，而 `E[2](R)` 是激发态的能量。在此图中，具有非极性和极性区域的两个能量函数作为横坐标上的 R 的函数出现。这里假设态在 `R = R[0]` 处改变特性。对于本征函数 `ψ[1](x,R)`，它在 `R[0]` 处从极性转变为非极性。对于第二个本征函数 `Ψ[2](x,R)`，则相反。如果 R 快速增加，则 `ψ[1](x,R) → ψ[2](x,R)`。这是非绝热变化发生，但如果 R 缓慢变化，则本征函数将保持在其原始轨迹上。

哈密顿量方程为 `H(R) ψ[i](x,R) = E[i](R) ψ[i](x,R)`，`i = 1, 2`。如果对所有 R 求解，则瞬时能量本征态如绝热定理所述找到。假设 R 是时间 t 的函数，则哈密顿量 `H(R(t))` 也是如此。相应的本征函数方程变为 `H(R(t)) ψ[i](x,R(t)) = E[i](R(t)) ψ[i](x,R(t))`，`i = 1, 2`。如果对所有 R 求解上部方程，则含时方程对所有 t 也成立。因此，瞬时能量本征态和本征值可从上面给出的上部方程得知。
