
# 抽象海森堡代数

抽象海森堡代数可以由辛向量空间 `V` 形成。这里，对于实值向量空间，乘积空间 `V` x′ `R` 是定义域，其中 x′ 表示直积。对于 `V` 中的 `v` 和 `w` 以及 `R` 中的 `t` 和 `r`，换位律为 `[(v, t), (w, r)]=(0, S(v, w))`，其中 `S` 是辛向量空间 `SKEW` 中二元运算对应的运算。

强算子拓扑在海森堡群的表示中起着重要作用；参见[第9.1节](#Ch006_103-128_B9780443136979000217.xhtml#s0010)。该表示从海森堡群连续到希尔伯特空间 `H` 上的酉算子拓扑群。薛定谔表示构成海森堡群的一族不可约无限维表示。对于海森堡代数，表示是涉及希尔伯特空间 `H` 的稠密子空间的斜对称自同态的李代数同态。当 `H` 不为 `{0}` 且 `H` 的所有不变闭子空间都是 `H` 或 `{0}` 子空间时，表示是不可约的。海森堡群和代数的全部薛定谔表示都是不可约的（[Hall, 2013](#Ch014_255-270_B978044313697900028X.xhtml#bib3)）。

## 14.10 Weyl 正则对易关系 C∗ 代数

Weyl 算子决定了称为 Weyl CCR C∗ 代数的 C∗ 代数；它涉及实辛希尔伯特空间 `H`，由元素 `{W(f)|f is in H}` 生成且满足以下等式恒等式：

1. `W(0)=1`.
2. `W(f)` unitary.
3. `W*(f)=W(- f)`, `f` in `H`.
4. `W(f)W(g)=e^((-i Im(<f, g>)/2))W(f+g)` ![方程](Images/F00028Xsi67.png), `g` 也在 `H` 中。注意 `S(f, g)=(-i Im(<f, g>)/2)` 是一个辛双线性形式。例如，由于 `<f, f>=||f||²` ![方程](Images/F00028Xsi68.png) 为实数，虚部等于零。此外，当 `<f, g>=0` 对 `H` 中所有 `g` 成立时，则 `f` 也必须等于零。

Weyl 版本的 CCR C∗ 代数在 ∗ 同构意义下是唯一的（[Slawny, 1972](#Ch014_255-270_B978044313697900028X.xhtml#bib10)）。此外，已证明对于 `f` 不等于 `g`，`||W(f)-W(g)||` 大于或等于 `2^(1/2)` ![方程](Images/F00028Xsi69.png)。因此这里的酉群不能是范数连续的，且 C∗ 代数不可分。该 C∗ 代数在对称福克空间上忠实表示。该空间有一个称为真空向量的 distinguished 向量。如前所述，它被湮灭算子操作所湮灭，并且相对于产生算子是循环的。回顾在此上下文中循环性质意味着产生算子的连续应用会产生所有态。玻色福克空间在下一章中描述。

Weyl 用酉运算和酉群重写了 CCR。回顾薛定谔表示。对于位置算子 `Q(f)=t f`，以及动量 `P(f)=-i f'`，它们都在 `H` 中定义域 `D` 的闭包上本质自伴。相应的有界酉算子为 `U(t)=e^(i t P)` ![方程](Images/F00028Xsi70.png) 和 `V(s)=e^(i Q s)` ![方程](Images/F00028Xsi71.png)。涉及有界酉算子的关键关系为 `(U(t)f)(x)=f(x+t), and (V(s)f)(x)=e^(i s x)f(x)` ![方程](Images/F00028Xsi72.png)。这些恒等式可以通过在原点处使用泰勒级数形式验证。进行此操作，并使用 `O` 表示假设为小的项的余项，得到以下结果：首先，`(U(t)f)(x)=[1+i t P+O]f(x)=[f(x)+t f'(x)+O]=f(x+t)=[f(x)+f'(x)t/1!+O]`；其次，`V(s)f)(x)=[1+i Q s+O]f(x)=[f(x)+i s x f(x)]=e^(i s x)f(x)=[1+i s x+O]f(x)` ![方程](Images/F00028Xsi73.png)。

应用前面找到的两个恒等式。使用 `V` 对第一个近似值进行操作可得 `(V(s)U(t)f)(x)=(V(s)f)(x+t)=e^(i s (x+t))f(x+t)` ![方程](Images/F00028Xsi74.png)。接下来对前面提到的第二个近似值应用 `U` 得到 `(U(t)V(s)f)(x)=e^(i s x)(U(t)f)(x)=e^(i s x)f(x+t)` ![方程](Images/F00028Xsi75.png)。比较这两个结果得到期望的结论：`e^(i s t)V(s)U(t)=U(t)V(s)` ![方程](Images/F00028Xsi76.png)，即 CCR 的 Weyl 关系。这种形式发展归因于薛定谔。

Weyl 关系是在希尔伯特空间上的强连续酉群；表示是不可约的且在酉等价意义下唯一。这意味着在 `H` 中不存在子希尔伯特空间 `K` 具有以下性质：这里 `K` 非零，不等于 `H`；`U(t)K` 是 `H` 的子空间；且对所有实数 `s` 和 `t`，`V(s)K` 是 `H` 的子空间。当基发生变化时，在 `H'` 上形成新的表示 (`U'`, `V'`)。但由于酉等价，存在酉算子 `W`，`W: H→H'` 使得 `U(t)=W* U'(t) W` 且 `V(s)=W* V'(s) W`。CCR 的所有 Weyl 关系表示都酉等价于薛定谔表示的至多可数直和。Weyl 关系的不可约表示酉等价于薛定谔表示（[Slawny, 1972](#Ch014_255-270_B978044313697900028X.xhtml#bib10)）。

Weyl CCR C∗ 代数通常记为 `CCR(H)` 或 `CCR(H, s)`，其中 `H` 表示希尔伯特空间，`s` 表示辛空间，`Im(<f, g>)`。`CCR(H)` 是一个单 C∗ 代数，即它没有双边理想。此外，设 `T` 为等距映射使得 `T: H→H`，并假设它保持辛结构。即 `s(T f, T g)=s(f, g)`，对 `H` 中的 `f` 和 `g` 成立。在这些条件下，`T` 可以实现为从 `CCR(H)` 到 `CCR(H)` 的星自同构 `A`。此外，存在唯一的自同构 `B`，从 `CCR(H)` 到 `CCR(H)` 使得 `B(W(f))=B(W(T f))`。
