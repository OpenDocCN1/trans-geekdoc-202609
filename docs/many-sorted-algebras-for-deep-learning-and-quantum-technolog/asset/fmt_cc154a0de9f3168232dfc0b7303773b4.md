
When the data is not linearly separable, slack variables are often introduced to make the constraining equations less rigid. The constraints now become as follows: `y[i] (<w, v[i]>+b)` is greater than or equal to one minus slack values `s[i]`, usually taken to be nonnegative. So again, the object is to minimize `min ‖w‖²/2`, but the `s[i]`![Equation](Images/F000163si88.png) cannot be made too large. A modified Lagrangian problem is formulated: `min[‖w‖²/2 + C/n ∑ s[i]]`, where the minimization is for `w`, `b`, and `s[i]`. The constant `C` is a positive parameter, `n` is the number of data points, and the sum is from 1 to `n`. The value `C` balances the importance of regularization and the importance of matching the training set correctly. When `C` is too large, the training set is matched well; if `C` is too small, this benefits overfitting. In the latter case, this might be good for training, but maybe not so good for unseen real data. `C` is called the penalty parameter for miss-classification.

Using the constraining equation gives the formula for `L`, where `a[i]`![Equation](Images/F000163si90.png) and `c[i]`![Equation](Images/F000163si91.png) are Lagrange multipliers. `L = ‖w‖²/2 + C/n ∑ s[i] + ∑ a[i] (1 - s[i] - y[i] (<w, v[i]>+b)) - ∑ s[i] c[i]`. As before, taking the partial derivatives or gradient of `L`, with respect to `w`, `b`, and `s[i]`, and setting them equal to zero gives `∂L/∂w = w - ∑ a[i] y[i] v[i] = 0`; `∂L/∂b = - ∑ a[i] y[i] = 0`; `∂L/∂s[i] = C/n - a[i] - c[i] = 0`. As in the strict margin classifier, substituting these partials into `L` winds up with the dual objective function below, and as such it needs to be maximized or its negative minimized. Accordingly, the constraint minimization occurs: `min 1/2 ∑∑ a[i] a[j] y[j] y[i] <v[i], v[j]> - ∑ a[j]`, with minimization over `a[i]`![Equation](Images/F000163si98.png), and constraints `∑ a[i] y[i] = 0`, and `a[i]` greater than or equal to zero, but less than or equal to `C/n`. This is a consequence of `C/n - a[i] - c[i] = 0` and having `c[i]` greater than or equal to zero.

As mentioned previously, the solution involves a quadratic program. Unlike the aforementioned example, the Gram matrix `G` will not be used explicitly. Here, an `n` by `n` matrix `H` with entries `H[i j] = y[j] y[i] <v, c, v[j]>`![Equation](Images/F000163si100.png) will be utilized. Note that if vector matrix notation is employed then the quadratic minimization is `min 1/2 a' H a - a' I`. It is such that `a' y = 0`, with `0` less than or equal to `a[i]`![Equation](Images/F000163si101.png) less than or equal to `C/n`. In this case, `a` is the vector of `a[i]`![Equation](Images/F000163si102.png), `y` is the vector of `y[i]`![Equation](Images/F000163si103.png), and `I` is the identity vector.

## 18.9 Kernel methods

This section is a continuation of Sections 1.10 and 5.7. Recall, in machine learning algorithms, the kernel is employed directly without computing the feature transformation, `Φ`![Equation](Images/F000163si104.png) mapping vectors in the original space. Here, the identity is exploited, `K(v,w) = < Φ(v), Φ(w)> = (<v, w>) ^(d)`. An interesting application, not previously illustrated, involves the nonhomogeneous polynomial kernel. Specifically, `K(v,w) = (<v, w> + a)^(d)`, where `a` is a real number. By the binomial expansion: `(<v,w> + a)^d = ∑_{k = 0}^{d} d!/(k! (d - k)!) <v,w>^k a^{d - k}`![Equation](Images/F000163si105.png). An example illustrating this kernel follows.

### Example 18.9

Let `v` and `w` be in `R²`![Equation](Images/F000163si106.png) and `a` in `R`; then let `A = (<v,w>+a)² = (v[1]² w[1]² + 2 v[1] v[2] w[1] w[2] + w[2]² v[2]²) + 2 a (v[1] w[1] + w[2] v[2]) + a²`![Equation](Images/F000163si107.png). Rearranging: `A = (v₁² w₁² + w₂² v₂²) + 2 (v₁ v₂ w₁ w₂) + a (v₁ w₁ + w₂ v₂) + a² = ∑_{i=1}^{2} v_i² w_i² + ∑_{i=1}^{2} ∑_{j=1}^{i-1} (2^{1/2} v_i v_j) (2^{1/2} w_i w_j) + ∑_{i=1}^{2} (2a)^{1/2} v_i (2a)^{1/2} w_i + a².`![Equation](Images/F000163si108.png)![Equation](Images/F000163si108a.png) This representation is important because it can generalize easily into higher dimensions. Also it will enable `Φ`![Equation](Images/F000163si109.png) to be found. Here, the kernel = `< Φ(v), Φ(w)>`. Both arguments within the inner product are the same, so factoring would yield `Φ(v)`.

Accordingly, the mapping `Φ : R² → R⁶`![Equation](Images/F000163si110.png) is being employed in this example. The feature map `Φ`![Equation](Images/F000163si111.png) employs the two tuples of `v = (v[1] v[2])'` , in `R²`![Equation](Images/F000163si113.png). It maps them into all possible second, `d=2`, degree nonhomogeneous monomials, resulting in `Φ(v) = (v[1]² v[1]² 2^{1/2} v[1] v[2] (2a)^{1/2} v[1] (2a)^{1/2} v[2] a)'`![Equation](Images/F000163si114.png)′. Note here that commutativity does not matter. However, by using the same protocol as in the homogeneous case, then the mapping is `Φ : R² → R⁷`![Equation](Images/F000163si115.png), where distinct labeling does matter, that is, even though `v[1] v[2] = v[2] v[1]`![Equation](Images/F000163si116.png), each one occupies a distinct tuple. Thus: `Φ(v) = (v[1]² v[1]² v[1] v[2] v[2] v[1] (2a)^{1/2} v[1] (2a)^{1/2} v[2] a)'`![Equation](Images/F000163si117.png)′.

Recall that a kernel is a function involving a nonempty set `X`, such that `K: X x X → R`. It is linked to a map: `Φ: X → H`, where `H` is a Hilbert space over the reals. Additionally, for `x` and `y` are in `X`, and `K` defined by the inner product: `K(x,y) = < Φ(x), Φ(y)>`, the function `Φ` is called the feature map. Also, `K` is called the feature kernel, and `H` is sometimes called the feature space. `H` need not be a RKHS. On the other hand, a kernel in a RKHS is also a feature kernel. Feature kernels are symmetric and positive semidefinite: Let `i` and `j` be in any finite set of positive integers, and `x[i]`![Equation](Images/F000163si118.png), `x[j]`![Equation](Images/F000163si119.png) in `X` and `a[i] a[j]`![Equation](Images/F000163si120.png) real valued, then `∑_{i,j} a_i a_j K(x_i,x_j) = ∑_i ∑_j a_i a_j < Φ(x_i), Φ(x_j)> = ∑_i a_i < Φ(x_i), ∑_j a_j Φ(x_j)> = < ∑_i a_i Φ(x_i), ∑_j a_j Φ(x_j)> = || ∑_j a_j Φ(x_j) ||²`![Equation](Images/F000163si121.png) which is greater than or equal to zero. In terms of vectors, `a' K a` is greater than or equal to zero, where `a` is a column vector consisting of all the `a[i]`![Equation](Images/F000163si122.png), `a'` is a row vector of `a[i]`![Equation](Images/F000163si123.png), and `K` is a Gram matrix.
