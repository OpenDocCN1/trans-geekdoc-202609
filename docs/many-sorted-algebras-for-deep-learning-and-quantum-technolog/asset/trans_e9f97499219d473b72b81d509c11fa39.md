### 例 13.4
考虑所有绝对可求和的复值序列 `v`=(v1, v2, …) 的 Banach 空间 `l¹`。设 `L` 为左移算子 `L` (`v`)=(v2, v3, …)。对偶算子记为 `L∗`，而非记为 `L′` 以提高可读性。它在对偶空间 `I^∞` 中作用，该空间是有界序列 `w`=(w1, w2, …) 的空间。尽管内积不适用，但它将被用作运算演算工具以快速求伴随算子。因此形式上，取内积 <`w`, `L` (`v`)>=w1∗v2+w2∗v3+…. 接下来，为求 `L∗`，使用 <`L∗` (`w`), `v`> 并将该结果与前面写出的和相等，即 <`L∗` (`w`), `v`>=w1′∗v1+w2′∗v2+w3′∗v3+…，其中撇号，即 wn′∗，表示 `L∗`(`w`) 的第 n 个分量。令涉及 <`L∗` (`w`), `v`> 和 <`w`, `L` (`v`)> 的 `vk` 系数相等，并求解 wk′∗，得到 w1′∗=0, w2′∗=w1∗, w3′∗=w2∗, …. 这表明对偶算子 `L∗` (`w`)=(0, w1, w2, …)。所得运算为右移。

注意 ∥`L`^(`n`)∥ = ∥(`L*`)^(`n`)∥ = 1![Equation](Images/F000138si33.png)，且范数对 `L` 和 `L∗` 均等于谱半径。来自 [第 8.10 节](#Ch008_145-164_B9780443136979000059.xhtml#s0055) 的 Gelfand 公式表明了这一点。这里极限 `n`→∞，∥`L`^(`n`)∥^(1/`n`)\=*r*(`L`)=1=*l**i**m**i**t* `n`→∞![Equation](Images/F000138si34.png)，∥(`L*`)^(`n`)∥^(1/`n`) = *r*(`L*`) = 1![Equation](Images/F000138si35.png)。由于该结果，`L` 和 `L∗` 的谱位于以原点为中心、半径为一的开球的闭包中。该球记为 `clos(O(0,1))`。其中 `clos` 表示闭包运算。开球的所有点都是特征值，即 `O(0,1)` 是 `sppL` 的子集。若 `v`=(1, 0, 0, …)，则 `v` 是 `L` 的特征向量，`c`=0 为特征值，因为 `L`(`v`)=0 `v`。`O(0,1)` 中的其他点 `c` 也在 `sppL` 中。为此，设 `v` = (1,`c`,`c`²,…)![Equation](Images/F000138si36.png) 则 `L`(`v`) = (`c`,`c`²,`c`³,…) = `c`(1,`c`,…) = `c` `v`![Equation](Images/F000138si37.png)。相应地，以上所述结果表明开单位球由 `L` 的特征值组成。*

### 例 13.5
再次考虑 Banach 空间 `l¹`，如 [例 13.4](#Ch013_231-253_B9780443136979000138.xhtml#enun4) 所示。该空间由所有绝对可求和的复值序列 `v`=(x1, x2, …) 组成，其中 `L` 为左移算子 `L` (`v`)=(x2, x3, …)。在该例中已看到对偶算子 `L∗` 在对偶空间 `l^∞`![Equation](Images/F000138si38.png) 中作用，该空间是有界序列 `w`=(y1, y2, …) 的空间。此外，对偶算子 `L∗` (`w`)=(0, y1, y2, …) 为右移算子。已看到 `L` 和 `L∗` 的谱位于以原点为中心半径为一的开球的闭包中，`clos(O(0,1))`。包含关系成立：`O(0,1)` 包含于 `sppL` 中，后者包含于 `spL` 中，而 `spL` 包含于 `clos(O(0,1))` 中。然后，由于 `spL` 是紧的，根据 Lume-Phillips 定理，`spL`=`clos(O(0,1))`=`spL∗`。在 [例 13.4](#Ch013_231-253_B9780443136979000138.xhtml#enun4) 中，证明了 `O(0,1)` 是 `sppL` 的子集。最终将看到 `O(0,1)`=`sppL`，即开单位球是 `L` 的点谱。

首先注意 `O(0,1)` 的边界不在 `sppL` 中。即边界点不是特征值。边界由 {`c`，满足|`c`|=`1`} 组成。设 `c` 在 `ker(c−L)` 中且不等于 {0}。这是反证法。设 `v`=(x1, x2, …)，则 (`c`−`L`) `v`=0。即 (`c` x1, `c` x2, …)=(x2, x3, …)。该恒等式的推论是一组递推方程。具体地，递推必须成立，x(n+1)=`c` xn，`n`=1, 2,…. 通过反向代入求解，得到 `v` = `c` `x`1(1,`c`,`c`²,…)![Equation](Images/F000138si39.png)。由于|`c`|=`1`，`v` 不在 `I¹`![Equation](Images/F000138si40.png) 中，除非 x1 为零。由此可知边界不在 `sppL` 中，因此整个点谱为 `sppL`=`O(0,1)`。

接下来将看到 `L∗` 的点谱为空。再次假设不成立，即存在复值 `c` 使得 (`c`−`L∗`) `w`=0 对向量 `w`=(y1, y2, …) 在 `l^∞`![Equation](Images/F000138si41.png) 中成立。即 (`c` y1, `c` y2, …)=(0, y1, y2, …)；这也导致一组方程，即：`c` y1=0，`c` yk=y(k-1)，`k`=2, 3, …. 当 `c`=0 时，则 `w`=0 且不能为特征向量。否则，当 `c` 不为零时，由上述方程可得 y1=0，然后通过递推，yk=0 对所有 `k`=2, 3, … 成立。这意味着 `w`=0，且它不能为特征向量。因此，`sppL∗` 为空，迄今为止所知的是对伴随算子；以原点为中心的闭球是 `L` 的谱。*
