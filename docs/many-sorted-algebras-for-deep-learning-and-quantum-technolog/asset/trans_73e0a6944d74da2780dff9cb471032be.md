
对于任意 Banach 代数 `A`，在 `C` 上，令 `Δ` 为 `A` 上所有乘性线性泛函的空间。这些也称为 `A` 的特征。其含义是线性泛函 `T` 是一个非平凡的代数同态，`T: A → C`。它具有性质 `T(v · w) = T(v) T(w)`，对于 `A` 中所有 `v` 和 `w`。`A` 上所有这些乘性线性泛函的集合在弱 * 拓扑中形成一个局部紧 Hausdorff 空间。此外，该集合是紧的，因为假设恒等元 `I` 在 `A` 中。紧 Hausdorff 空间 `Δ(A)` 称为特征空间。令 `C(Δ(A))` 为 `Δ` 中所有复值连续函数的代数。Gelfand 变换是 `G: A → C(Δ)`，其中 `v → G(v)`，`G(v)` 在 `C(Δ)` 中且定义为 `G(v) = v̂`![方程](Images/F000242si14.png)，其中 `x̂(T) = T(v)`![方程](Images/F000242si15.png)，对于 `Δ` 中所有 `T`。

在 `Δ` 中消失于无穷远的复值连续函数代数是 `C(Δ)` 的子代数，记为 `C[0](Δ)`。Gelfand 变换的像包含在 `C[0](Δ)` 中。GNS 构造在第 8.8 节中引入。它借助 Gelfand 公式推广到所有在 `C` 上的可交换 `C*` 代数 `A`。在这种情况下，`A` 与某个紧 Hausdorff 空间 `X` 的 `C[0](X)` * 同构。此外，Gelfand 变换 `G` 是 `A` 与 `C[0](Δ)` 之间的 * 同构。当 `C*` 代数中没有恒等元时，Hausdorff 空间只需局部紧。这是由 Banach-Alaoglu 定理的结果（[Narici 和 Beckenstein, 2011](#Ch009_165-169_B9780443136979000242.xhtml#bib2)）。Gelfand 变换是涉及绝对可积函数的众多变换方法的基础。以下是几个例子。

### 示例 9.8
考虑集合 `A`，它由实数线上的所有绝对可积函数组成。积分关于 Lebesgue 测度。该空间记为 `L¹(R)`。使用逐点加法和涉及卷积运算的乘法，`A` 成为没有恒等函数的 `C*` 代数。在任何情况下，它也称为群代数。卷积运算与使用有界矩阵定义的运算非常相似；然而，在当前情况下积分取代了求和符号。对于 `L¹(R)` 中的 `f` 和 `g`，乘法为 `f ⊛ g(t) = ∫[x = -∞]^∞ f(x) g(t - x) dx`。在这种情况下的 Gelfand 变换是傅里叶变换。对于 `L¹(R)` 中的 `f`，该变换产生一个复值函数 `F(ω)`，即 `F(ω) = ∫[x = -∞]^∞ f(x) e^(-i x ω) dx` 它是一致连续的并且具有 Riemann-Lebesgue 性质，即 `F(ω) → 0` 当 `|ω| → ∞`。这与 Gelfand 变换产生 `C[0](X)` 中的函数一致。也就是说，当自变量趋于正无穷或负无穷时趋于零的连续函数。

傅里叶变换及其性质的更深入处理在示例 19.10 中给出，在再生核希尔伯特空间的背景下。

### 示例 9.9
设 `A` 由非负实数线上的所有绝对可积函数组成。再次，积分关于 Lebesgue 测度。该空间记为 `L¹(R+)`。使用逐点加法和乘法为卷积运算，`A` 再次成为没有恒等函数的 `C*` 代数。该空间中两个函数的卷积为 `f ⊛ g(t) = ∫[x = 0]^∞ f(x) g(t - x) dx`。在这种情况下的 Gelfand 变换是涉及变量 `s` 的拉普拉斯变换。该标量是复值的，其实部大于或等于零。这里，`L(s) = ∫[t = 0]^∞ f(x) e^(-s t) dx`。结果是在绝对收敛区域内的解析函数。

### 10.1 代数商空间的 MSA
在代数商空间的 MSA 描述中，存在四种类型；它们是 `VECT`、`SUBV`、`SCALAR` 和 `COSET`。通常，`SCALAR` 指代域，例如实数或复数以及四元数斜域。`VECT` 指代向量空间，`SUBV` 表示 `VECT` 内的固定子空间。最后，`COSET` 是商空间内所有向量的名称。实际上，`COSET` 中的向量 `v` 将由等价类组成并表示为 `[v]`。括号内的量 `v` 可视为陪集代表，将在后面更详细地描述。实际的签名集与描述向量空间和标量时完全相同。此外，向量空间的所有等式恒等式也必须成立。为了压缩记号，表示类型：
* `VECTOR` 用 `V` 表示
* `SCALAR` 用 `S` 表示
* `SUBV` 用 `N` 表示

利用表示算子名称的符号：
* `V-ADD` 用 `+` 表示
* `V-MINUS` 用 `−` 表示，在以下内容中，`−` 用作二元运算而不是写成 `+ (−)`。

如前几章所述的等价关系是一个 RST 关系。这里它在 `V` 上定义为说当 `v−w` 在 `V` 的子空间 `N` 中时 `v` 与 `w` 相关。子空间 `N` 是任意的且非空。该关系也可以如下描述：当 `v = w + n`，其中 `n` 在 `N` 中时，`v` 等价于 `w`。它用等价符号表示，`v~w`。这促使了陪集的记号，`[v] = {v + n where n is in N}`，并且在这种情况下，由上可知 `[v] = [w]`。而且，`[0] = {n is in N}`。因此，`N` 中的所有向量都像 `ZERO` 一样起作用。商空间 `V/N` 定义为由 `V` 上的关系 `~` 引起的全部等价类的集合。它也是由全部陪集组成的空间，即 `V/~`。当加法和标量乘法按下面给出定义时，商空间本身就是一个向量空间（[Halmos, 1974](#Ch010_171-188_B9780443136979000047.xhtml#bib4)）。然而，首先通过让以下内容进行记号滥用：
* 对于 `COSET`，使用 `[v]`、`[w]`。
* 对于 `SCALAR`，使用 `S` 中的 `a`。
