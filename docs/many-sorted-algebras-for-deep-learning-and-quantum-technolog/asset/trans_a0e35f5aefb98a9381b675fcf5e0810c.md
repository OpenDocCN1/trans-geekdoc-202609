
动量算子也是无界的，但在 `H` = `L²(R)` 中它也是自伴的![Equation](Images/F000138si96.png)。这种情况下的内积是 `<f, -i d/dx g>`；它是积分 `∫[-∞]^∞`![Equation](Images/F000138si97.png) `f*·(-i d/dx g) dx`。这里假定导数是可积的。现在分部积分得到 `(f*·g)` 在负无穷到正无穷之间求值，以及积分 `∫[-∞]^∞`![Equation](Images/F000138si98.png) `(i d/dx f*)·g dx`。假设乘积 `(f*·g)` 趋于零；那么用内积表示的结果是 `<-i d/dx f, g>`，从而表明该算子也是自伴的。

## 13.4 有界算子与数值域

如在 [第 7.1 节](#Ch007_131-144_B9780443136979000205.xhtml#s0010) 中提到，数值域在刻画 Hilbert 空间上有界算子所关联的谱类型方面非常有用。为了说明这一点，考虑 Banach 空间或实际上 C∗ 代数 `B(H)` 中的算子 `T`。算子 `T` 的数值域为 `sup[‖v‖=1]`![Equation](Images/F000138si99.png) `<v, T v>`。假设 `cI - T` 不是可逆的，甚至不是单射的。那么在 `H` 中存在非零的 `v` 使得 `(T - I c) v = 0`。利用该恒等式 `T v = c v`，并与 `v` 形成内积，`<v, T v> = c <v, v>`，其中 `‖v‖ = 1`。这表明特征值 `c` 在数值域中。因此，点谱 `sppT` 是数值域的子集。

现在假设 `(c - T)` 的值域在 `H` 中不是稠密的；这意味着闭包 `clos(c - T)` 是 `H` 的真子集 `A`。那么在 `A^⊥`![Equation](Images/F000138si100.png) 中存在单位向量 `w`，使得内积 `<w, (T - c) w> = 0`，即 `<w, T w> = c`。所以再次 `c` 在数值域中。因此，剩余谱 `sprT` 是 `T` 的数值域的一部分。

最后，假设 `(T - c)` 的值域在 `H` 中稠密，但不等于 `H`。在这种情况下，存在归一化向量序列 `w[n]`![Equation](Images/F000138si101.png) 在 `H` 中使得 `(T - c) w[n] → 0`![Equation](Images/F000138si102.png)。必须存在一个趋于零的序列。否则，`(T - c)` 将是有界下方的，如在 [第 7.6 节](#Ch007_131-144_B9780443136979000205.xhtml#s0035) 中所见以及本章前面所述，稠密且有界下方意味着 `(T - c)` 是可逆的。利用序列 `w[n]`![Equation](Images/F000138si103.png) 与其内积给出 `<w[n]`![Equation](Images/F000138si104.png), `(T - c) w[n]>` = `<w[n]`![Equation](Images/F000138si105.png), `T w[n]`![Equation](Images/F000138si106.png) > − `c` < `w[n]`![Equation](Images/F000138si107.png), `w[n]` > → 0![Equation](Images/F000138si108.png)。因此，这次 `c` 在数值域的闭包中。在这种情况下，连续谱 `spcT` 是数值域闭包的子集。

数值域 `W(T)` 对于 `n` 阶 `n` 复值矩阵的性质列表如下提供（[Gustafson 和 Rao, 1997](#Ch013_231-253_B9780443136979000138.xhtml#bib5)）：
1. `W(T)` 是 `C` 的紧子集。
2. `W(T)` 是 `C` 中的凸集，由 Hausdorff-Toeplitz 定理得出。
3. `W(T)` 包含 `T` 的谱。
4. 如果 `T = T*`，则 `W(T)` 是实数线上的闭区间。此外，它由两个特征值构成的端点组成。

下一个例子说明了使用特征值来求数值域。 它还说明了性质 4)。 这个相同的例子在 Example 7.3 中已通过数值模拟求解，其中最一般的 `C²`![Equation](Images/F000138si109.png) 中的量子比特被代入数值域公式。

### Example 13.14

自伴矩阵 `T =` 的特征值
```
\begin{matrix}
{|2} & {i|} \\
{|{- i}} & {1|} \\
\end{matrix}
```
![Equation](Images/F000138si110.png)
是从特征方程的解得到的：`t² − 3t + 1 = 0`![Equation](Images/F000138si111.png)。特征值是 `(3 + -5^(1/2))/2. = .382, 2.618`![Equation](Images/F000138si112.png)。数值域是 `W(T) = [.382, 2.618]`。

更一般地，对于 Hilbert 空间 `H` 上的算子 `T`，数值域还有若干其他性质（[Shapiro, 2004](#Ch013_231-253_B9780443136979000138.xhtml#bib15)）。
1. `W(T)` 在酉相似下不变。
2. `W(T)` 位于以原点为中心、半径为 `‖T‖` 的闭圆盘中。
3. `W(T*) = {c* for all c in W(T)}`。
4. `W(I) = {1}`。
5. 对于 `a, b` 在 `C` 中，且 `T` 在 `B(H)` 中，`W(a T + b I) = a W(T) + b`。
6. 如果 `T` 是幂零的，即 `T^(n+1) = 0`![Equation](Images/F000138si113.png)，则 `T` 的谱为零在 `clos W(T)` 中。

### Example 13.15

以 2×2 复值矩阵 `T` 的代数作为载体集。如果 `T` 是除第一行第二列项外全为零的矩阵，这里令项 `T[1,2]`![Equation](Images/F000138si114.png) 等于一，`T =`
```
\begin{matrix}
{|0} & {1|} \\
{|0} & {0|} \\
\end{matrix}
```
![Equation](Images/F000138si115.png)
则 `sp(T) = 0` 且 `‖T‖ = 1`。此外，`T` 是二阶幂零的，因为 `T² = 0`。

对于无界算子，谱与数值域之间的关系如下：（[StackExchange, 2015](#Ch013_231-253_B9780443136979000138.xhtml#bib16)）。
1. 如果 `T` 是正规的，则 `T` 的整个谱位于 `clos W(T*)` 中。
2. 如果 `T` 是对称的，包含于 `clos T` 包含于 `T*`，则谱不一定是实的，但 `clos W(T)` 是 `R` 的子集。
3. 如果 `T` 不是闭算子，且 `T` 是 `clos T = T**` 的子集，则谱是复的并且包含 `clos W(T)`。

对于 `H` 上的自伴有界算子 `T`，数值域 `W(T)` 与 `T` 的特征值之间存在关系。当 `a = inf <v, T v>` 对所有 `‖v‖ = 1` 时，则 `a` 在 `sp T` 中（[Gustafson 和 Rao, 1997](#Ch013_231-253_B9780443136979000138.xhtml#bib5)）。

如前所述，Hilbert 空间 `H` 中耗散算子 `T` 的实部是这样的，对于 `H` 中所有 `v`，数值域的实部为非正。也就是说，`Re <v, T v>` 为非正，其中 `‖v‖ = 1`。接下来的几个例子将说明这一概念。

### Example 13.16

设 Hilbert 空间的载体集为 `H = R^(n)`![Equation](Images/F000138si116.png)，具有通常的内积，如果 `T = -I`，即对角单位矩阵的负值；那么对于 `H` 中所有 `v`，`<v, T v> = -‖v‖²`![Equation](Images/F000138si117.png)，因此 `T` 是耗散的。

### Example 13.17

另一个耗散算子 `T` 的实例，这次在 `L²(R)`![Equation](Images/F000138si118.png) 与 `C_o¹(R)`![Equation](Images/F000138si119.png) 相交。这是由具有紧支集的光滑可微函数组成的空间，它们是绝对平方可积的。令 `T` 为动量型算子，`T = d/dt`。

则 `<T f, f> = integral, ∫[t = -∞]^∞`![Equation](Images/F000138si120.png) `f′* f dt`，其中撇号表示导数。现在分部积分得到 `<T f, f> = ∫[t = -∞]^∞`![Equation](Images/F000138si121.png) `-f* f′ dt = - <f, T f> = - <T f, f> *`。所以 `<T f, f>` 的实部为 0，因为当 `z = - z*` 时，`z` 为纯虚数。因此 `T` 是耗散的。

在 Banach 空间 `A` 中，算子 `T` 为耗散的定义被推广，因为不一定存在内积。在这种情况下，如果对于所有 `c > 0` 和所有 `v` 在 `dom(T)` 中，`‖(c - T) v‖` 大于或等于 `c ‖v‖`；则 `T` 是耗散的。Banach 空间中耗散算子的相当完整的汇编见 [Lumer 和 Philips (1961)](#Ch013_231-253_B9780443136979000138.xhtml#bib9) 和 [Engel 和 Nangel (2000)](#Ch013_231-253_B9780443136979000138.xhtml#bib4)。这些性质在证明先前提到的 Lumer-Phillips 定理时是必需的，该定理将算子的谱与其对偶算子的谱联系起来。
