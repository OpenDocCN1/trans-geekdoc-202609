
## Drury-Arveson Space

The Drury-Arveson space is `H[n]²`![Equation](Images/F000278si127.png), with `B` the open unit ball in `C^(n)`![Equation](Images/F000278si128.png) for `n` larger or equal to two. When `n=2`, this space is a Hilbert space of analytic functions on `B` with a reproducing kernel `K[Z](w)=1/(1−<z, w>)`. It is a RKHS with inner product $< f,g > = {\\sum\\limits\_{ainZ\_{+}^{n}}{\\left( {a!/{|a|}!} \\right)b\_{a}c\_{a}}}$![Equation](Images/F000278si129.png),* where $f\\left( z \\right) = \\underset{ainZ\_{+}^{n}}{\\sum^{}}b\_{a}z^{a},g\\left( z \\right) = \\underset{ainZ\_{+}^{n}}{\\sum^{}}c\_{a}z^{a}$![Equation](Images/F000278si130.png). This is a generalization of the Hardy RKHS ([Jury and Martin, 2018](#Ch019_349-364_B9780443136979000278.xhtml#bib6)).

In the second reference mentioned above, Jordan algebras are used in exploring Fock space as well as Bargmann transforms. In that reference, the algebra involved real-valued symmetric matrices. It is interesting to mention that in the present text, in Example 3.3), a Jordan-type algebra results. This occurs when the subalgebra of real-valued symmetric matrices is employed in that example. In general, a Jordan algebra is a unital, commutative, and usually nonassociative algebra obeying an additional constraint, besides those MSA identities provided in [Section 3.1.](#Ch003_41-55_B9780443136979000175.xhtml#s0010). This equational constraint involves multiplication using `BINE` or·. It is given by

```
Jordan identity: BINE (u, BINE (BINE (u, u), v))=BINE (BINE (u, u), BINE (u, v)).
```

Again, the Jordan identity: `u·(u²·v)=u²·(u·v)`. The more succinct notation may be more understandable. The constraint is a sort of associative type law.

## 19.3 Reproducing kernel Hilbert space over R

The function `k: X x X→R` is a kernel iff there exists a Hilbert space `H` and a map `Φ: X→H` such that `<Φ(x), Φ(y)>`. Given are `X` and a kernel function, a scalar product, and a mapping `Φ: X→H` such that `k(x,y)=<Φ(x), Φ(y)>`. To see this, given `X` and `k` there exists a mapping, `Φ: X→H` where `k(x,y)=<Φ(x), Φ(y)>`. This exists for all `x` and `y` in `X`. The RKHS is a space of functions. For any `x` in `X`, use `k[x]=Φ(x)=k(x,·)`, where we use `x` as a parameter, and let `k[x]: X→R`, so `k[x]` is a functional. However, every point in `X` gets mapped into a function. Let `S` be the range or image of {`k[x]`, such that `x` is in `X`}. Take the set of all linear combinations, that is, the span of these functions makes `S` become a vector space. Define the inner product `<k*x*, k[y]>=<k(x,·), k(y,·)>=k(x, y)`. This inner product can be extended for arbitrary functions `f` and `g`, where `f=$\\sum\\limits\_{i}$![Equation](Images/F000278si139.png) a[i] k(x[i],·)` and `g=$\\sum\\limits\_{j}$![Equation](Images/F000278si140.png) b[j] k(y[j],·)`. Here, `< f,g > = \\underset{i,j}{\\sum^{}}a\_{i}b\_{j}k{({x\_{i},y\_{j},})}$![Equation](Images/F000278si141.png), and let `S′` be the resulting inner product space. If the completion is performed making every Cauchy sequence converge by adding limit points, a RKHS `H` is obtained.

The kernel is self-reproducing and positive semidefinite. Use `<K(., x), K(., y)>=K(y, x)=<K(., y), K(., x)>*`. Thus for the real case, the kernel is symmetric.

### Example 19.9

One of the simplest examples of a RKHS is `l²`![Equation](Images/F000278si142.png). Here, these are all functions from the positive integers `N` into the reals and are square summable. These functions form a vector space and a Hilbert space with induced norm squared `∥f∥²=∑|f(n)|²`![Equation](Images/F000278si143.png). An evaluation functional `E[n]: l²→R`![Equation](Images/F000278si144.png), for each `n` in `N`, is `E[n](f)=f(n)=<f, e[n]>`![Equation](Images/F000278si145.png), where `e[n]`![Equation](Images/F000278si146.png) in `l²`![Equation](Images/F000278si147.png) is such that `e[n](n)=1`![Equation](Images/F000278si148.png), and for all other values in `N`, `e[n](m)=0`![Equation](Images/F000278si149.png). Moreover, `|E[n](f)|`![Equation](Images/F000278si150.png) is less than or equal to `‖f‖`, so it is a bounded functional. As an instance, let `f (n)=1/n`; then `f` is in `l²`![Equation](Images/F000278si151.png). As an evaluation functional, notice that `E[3]=1/3,a n d‖f‖=π/6^(1/2)`![Equation](Images/F000278si152.png).
