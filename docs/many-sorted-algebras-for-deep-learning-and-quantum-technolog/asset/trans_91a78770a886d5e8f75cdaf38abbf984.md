
核由 `l²` 中的序列定义![Equation](Images/F000163si124.png)。核方法为涉及支持向量型分类的机器学习提供了坚实的基础。在这种分类中，通常在二分类中使用超平面。这些平面用于分离两个不同的数据类或对象。事实上，这些平面通常不通过原点，并且是仿射变换的实例。此类变换保持直线并保持平行线平行。此外，它们还保持凸性以及极值点。它们不保持距离或角度。在机器学习中，它们也很有用，因为它们是仿射空间的自同构；它们保持维度和子空间。要分为两组的数据首先假定是线性可分的。这预设存在一个超平面可以将数据分为两部分。对于数据非线性可分的情况给出软分类。软分类是指数据是边缘不可分的，即存在偶发异常值。此外，核在回归分析中也有应用。在这里，参数设置被确定以最小化回归曲线对数据的过拟合或欠拟合。

某些特征映射的组合也是特征映射。特别是，特征映射的和与积连同非负标量积也是特征映射。然而，两个特征映射之差可能不是特征映射。这些性质在后面描述的构造中使用。

考虑一个非空集合 `X`，以及一个序列 `Φ[1]`![Equation](Images/F000163si125.png)，`Φ[2]`![Equation](Images/F000163si126.png)，`Φ[3]`…![Equation](Images/F000163si127.png)，为 `l²`![Equation](Images/F000163si128.png) 函数，使得 `Φ[i]`![Equation](Images/F000163si129.png)：`X`→`R`。那么 `Φ(x)` = (`Φ[1]Φ[2]Φ[3]…`)![Equation](Images/F000163si130.png) 是特征映射，且 $K\\left( {x,y} \\right) = \\overset{\\infty}{\\underset{i = 1}{\\sum^{}}}\\Phi\_{i}\\left( x \\right)\\Phi\_{i}\\left( y \\right)$![Equation](Images/F000163si131.png) 是 `X` 上的核。这可由 CBS 不等式得出，即 $\\left| K\\left( {x,y} \\right) \\middle| = \\middle| \\overset{\\infty}{\\underset{i = 1}{\\sum^{}}}\\Phi\_{i}\\left( x \\right)\\Phi\_{i}\\left( y \\right) \\right|$![Equation](Images/F000163si132.png) 小于或等于 $\\left. \\overset{\\infty}{\\underset{i = 1}{\\sum^{}}} \\middle| \\Phi\_{i}\\left( x \\right)|^{2}\\overset{\\infty}{\\underset{i = 1}{\\sum^{}}} \\middle| \\Phi\_{i}\\left( y \\right)|^{2} \\right.$![Equation](Images/F000163si133.png)。

超平面 `A` 将在此处在有限实内积空间 `H` = `R`^(`n`)![Equation](Images/F000163si134.png) 中描述。这些平面将是 `H` 的度小于 `n` 的仿射子集。对于 `R` 中的 `b`，以及 `H` 中的 `w`，`A`={ `v` in `H`, such that <`w`, `v`>+`b`=0}。

### 示例 18.10

设 `H` = `R`²![Equation](Images/F000163si135.png)，对于 `b`=2，且 `w`=(1 4)′ 在 `H` 中，`A` = {`v`=(`v[1]v[2]`)![Equation](Images/F000163si136.png)′ 在 `H` 中，使得  < (14)′, (`v[1]v[2]`)′>+2=0}![Equation](Images/F000163si137.png)。相应地，`A` 是直线仿射线：`v[1]` + 4`v[2]` =  − 2![Equation](Images/F000163si138.png)。

支持向量机是监督学习，需要训练数据。核技巧将数据变换到更高维度，进行分类，然后再变换回来。空间中的点具有称为特征的元组。超平面将 `H` 分成两个半平面：`A^+`![Equation](Images/F000163si139.png)\={ `v` in `H`|<`w`, `v`>+`b` 大于或等于 0} 和 `A^-`![Equation](Images/F000163si140.png)\={ `v` in `H`|<`w`, `v`>+`b` <0}，从而使超平面成为二分类的决策边界。`H` 是度量空间，因为它是内积空间，因此它也是赋范向量空间。事实上，内积提供了一个自然度量 `d`。`H` 中 `v` 与 `w` 之间的距离是 `d(v,w)` =  < `v` − `w`, `v` − `w`\>^(1/2) = ∥`v` − `w`∥![Equation](Images/F000163si141.png)。最后一个量是由内积诱导的范数。对于向量集合，`X` = {`v[1]`, `v[2]`, …, `v[n]`}![Equation](Images/F000163si142.png) 在 `H` 中，集合中单个点 `v[i]`![Equation](Images/F000163si143.png) 到仿射分类器 `A` 的距离由 | < `w`, `v[i]` >  + `b`|/∥`w`∥![Equation](Images/F000163si144.png) 给出。`X` 中向量到 `A` 的最小距离由最小化该表达式给出。乘以常数的仿射空间，即将 `w` 和 `b` 乘以相同的常数，不会改变空间 `A`；实际上这两个空间是等价的。因此最小距离可以通过 min (|<`w`,`v[i]`\>+`b`|)![Equation](Images/F000163si145.png) 对于 `i`=1, 2, …, `n` 找到。参见涉及仿射空间的第 2.9 节。

## 18.10 径向基函数核

径向基函数（RBF）核使用，例如 `v`=(x y)′ 在 `R`²![Equation](Images/F000163si152.png) 中，以及映射 `ϕ`![Equation](Images/F000163si153.png)(`v`) 提供无限维向量 `Φ(v)` = (1*x* *y* *x*y* *y*x* *x²*y²*x²*y*y²*x*…)![Equation](Images/F000163si154.png)′。核方法避免计算 `Φ`![Equation](Images/F000163si155.png)(`v`)，它产生 `v` 的元组之间的单次、双次、三次交互等。相反，内积在 `R²` 中执行，然后是核：`k(v,w)` =  < `Φ(v)`, `Φ(w)` >  = `e`^( − 1/2*∥*`v` − `w`*|*|²)![Equation](Images/F000163si156.png)。为了形式上证明这是一个内积核，写 `e`^( − 1/2*∥*`v` − `w`*|*|²) = `e`^( − 1/2\[(`v` − `w`)^′(`v` − `w`)\]) = `e`^( − 1/2\[`v`^′`v` − 2`v`^′`w` + `w`^′`w`\]) = `e`^( − 1/2\[`v`^′`v` + `w`^′`w`\])*`e`^(`v`^′`w`)![Equation](Images/F000163si157.png)。令 `C` = `e`^( − 1/2\[`v`^′`v` + `w`^′`w`\])![Equation](Images/F000163si158.png)。那么 `e`^( − 1/2*∥*`v` − `w`*|*|²) = `C`*`e`^(`v`^′`w`) = `C`*`e`^(`v`^′`w` + 1)*`e`^( − 1) = `C′`*`e`^(`v`^′`w` + 1)![Equation](Images/F000163si159.png) 其中 `C′` 是新常数。于是 $e^{- 1/2{\\|{v - w}\\|}^{2}} = \\sum\_{n = 0}^{\\infty}{\\left( {1 + \\left. {v'w} \\right\\}} \\right.^{n}/n!}$![Equation](Images/F000163si160.png) 这表明 RBF 核包含所有非齐次多项式核。该核投影到无限维空间。它在数据之间执行无限多次交互。
