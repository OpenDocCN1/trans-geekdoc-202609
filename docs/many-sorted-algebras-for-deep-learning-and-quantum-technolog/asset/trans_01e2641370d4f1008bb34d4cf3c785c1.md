
## 纠缠
纠缠是与两个量子比特或两个以上量子比特相关的属性。它总是意味着量子比特之间存在非常高的关联。通过观测单个纠缠量子比特，其他量子比特的属性也随之可知。从稍微更严格的观点来看，假设有两个量子比特 `|v>` 和 `|w>`，每个都在 `C²` 中。由 `|v>` 和 `|w>` 构成的量子比特 `|q>` 如果在 `C⁴`=`C²`⊗![Equation](Images/F000217si27.png) `C²` 中，`|q>`；然而，该量子比特本身不能写成简单的张量积，`|v>` ⊗![Equation](Images/F000217si28.png) `|w>`。在后续章节中，将从密度算符的角度给出更深入的解释。

一个在 `C⁴` 中纠缠的 `C²` 中两个向量的例子涉及 `|0>` 和 `|1>`。在 `C⁴` 中，考虑 `|q> = 1/2 (|0> ⊗ |1>) + 3^(1/2)/2 (|1> ⊗ |0>) = 1/2 (|0 1> + 3^(1/2)/2 |1 0>)`。如前所述，后续章节将说明纠缠张量具有这样的性质：乘积 `a11 a22` 不等于乘积 `a12 a21`，其中 `|q> = a11 |0 0> + a12 |0 1> + a21 |1 0> + a22 |1 1> = 1/2 (|0 1> + 3^(1/2)/2 |1 0>)`。该判据在第7.4节中描述。在当前情况下，对于 `|q>`，`a11 = 0`，`a12 = 1/2`，`a21 = 3^(1/2)/2`，最后 `a22 = 0`。所以 `a11 a22 = 0`，但 `a12 a21 = 3^(1/2)/4`，因此存在纠缠。

## 绝热量子计算
绝热量子计算可以执行量子退火 (`QA`)，并提供一种利用幺正门的量子计算替代方法。`AQC` 已被证明等价于量子计算的标准幺正门模型 ([Aharonov 等，2014](#Ch006_103-128_B9780443136979000217.xhtml#bib1))。然而，这些方法非常不同。`AQC` 方法的目标是在绝热条件下找到全局最小值 ([Krauss，2013](#Ch006_103-128_B9780443136979000217.xhtml#bib17))。从状态 `|ψ>` 的初始条件开始，薛定谔方程的连续时间演化被用于寻找最终观测值。这就是 `AQC` 的全部内容。如果环境控制不当，最终状态可能只是一个局部最小值。通常，薛定谔方程为 `iħ ∂|ψ>/∂t = H(t) |ψ>`。它在哈密顿量 `H` 的绝热条件下演化，`t` 在 `[0, T]` 中，其中 `T` 是总演化时间。
如前所述，绝热条件保证了哈密顿量的本征态不变。这里假设存在缓慢的时间演化。此外，假设被占据的本征态与其他所有激发能量态之间的能量间隙不会太小。该间隙决定了 `AQC` 的计算复杂度。较小的间隙导致更长的计算时间。`AQC` 已知在寻找最优解方面比传统算法提供二次加速。此外，它保持量子比特相干性，并提供比其他量子计算模型更好的抗噪声能力 ([Childs 等，2001a](#Ch006_103-128_B9780443136979000217.xhtml#bib5),[b](#Ch006_103-128_B9780443136979000217.xhtml#bib6))。
基本上，控制退火过程有两种方法：准静态控制和相干控制。准静态控制的退火时间大于热弛豫时间，导致在大部分演化过程中达到热平衡。在相干控制中，退火时间小于弛豫或退相干时间；此时薛定谔方程占主导。
超导电子学是实现 `AQC` 和 `QA` 的方法之一 ([Wendin，2017](#Ch006_103-128_B9780443136979000217.xhtml#bib27))；在这种情况下，利用了约瑟夫森结。它利用隧道效应。囚禁离子技术也用于 `AQC` ([Zhang 等，2018](#Ch006_103-128_B9780443136979000217.xhtml#bib28))。
这些输入被转换为电电流、电电压和磁场。电磁源控制量子比特，它们总是以叠加态开始。随着退火过程的进行，量子比特自旋演化以试图确定最低能量态。该过程利用了如前所述的量子干涉、叠加和纠缠。此外，这些量子比特采用 [第6.3节](#Ch006_103-128_B9780443136979000217.xhtml#s0020) 中描述的隧道方法。
对于任意粒子、量子比特或波函数 `Ψ`，概率幅为值 `Ψ`。此外，当 `Ψ` 被观测时，Born 规则被用于定义实际概率密度；它为 `P(ψ) = ‖Ψ‖²`。

## 6.3 δ函数势阱与隧道效应
本节的主要内容是隧道效应。简而言之，粒子可以走捷径并穿过势垒，而不是越过势垒。厚度无关紧要；粒子可以通过物质的速度比光在真空中传播的速度更快。本节存在两种情况。如果 `E < V` 状态，δ函数势会出现束缚态，而当不等式反转时，隧道效应发生。在后一种情况下，称存在自由粒子。它们通常不可归一化，因为它们一般不是平方可积的。此外，由于态未被束缚，能谱通常是连续的。本节基于优秀的来源 ([Carson，2014](#Ch006_103-128_B9780443136979000217.xhtml#bib4))。
当 `|x|` 趋于无穷时，束缚态趋于零，并且它们是可归一化的。此外，它们具有通常量子化和离散的能级。这是使用定态薛定谔方程的边界条件的結果。从某种意义上说，束缚态的概念与发生隧道效应的散射态相反。在束缚态中，粒子在该态中的能量小于无穷远处的势能。此外，束缚态函数是驻波。有界态的能谱总是离散的。此外，对应的本征函数在 `|x|` 较大时呈指数衰减。这些概念将在后面通过束缚态的例子以及态的散射来描述。
定态薛定谔方程的解在分段解的边界处必须匹配。一般来说，波函数 `ψ` 必须连续。当没有δ函数时，导数 `dψ/dx` 也必须连续。然而，如果在某个离散点 `x[0]` 导数不存在，则如果 `V(x[0]) → ∞`，积分将导致解 ([Zwiebach，2017](#Ch006_103-128_B9780443136979000217.xhtml#bib33))。
