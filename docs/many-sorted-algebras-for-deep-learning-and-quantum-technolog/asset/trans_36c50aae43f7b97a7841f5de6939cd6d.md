
`M=aX1 + bX2 + cX3`，或用爱因斯坦型记号表示 `M=aj Xj`。注意在此例中 `a1=a`、`a2=b` 且 `a3=c`。利用李括号得到 `\[Xi, Xj\]=−Eijk Xk`，其中再次使用了 Levi-Civita 符号。对于 `SO(3, R)`，行列式必须为一。取 `det(I + M)`，将其设为一并保留至线性项，仅得到一。因此不需要其他约束。再次使用爱因斯坦记号，利用指数得到一个实际的群元素，`e^(ajXj)`![方程](`Images/F000126si44.png`)。在展开之前，采用特征方程的 Cayley-Hamilton 形式得到 `M³ + d² M=0`，其中 `d²=(a² + b² +c²)`。与前一个问题类似，`M³=−d² M` 用于更快地对指数的级数求和。再次，对 `e^(ajXj)`![方程](`Images/F000126si45.png`) 的级数使用偶项和奇项。持续将 `–d² M` 代替 `M³`。可利用简单的幂级数近似来证明 `e^(ajXj)=I + ajXj sin(d) + (ajXj)²(1−cos(d))`。现在，代入基元素 `Xj`，记住 `ajXj=a X1 + b X2 + c X3`，且 `d²=(a² + b² + c²)`，最后对 `ajXj` 平方并代入得到 `e^(ajXj)`![方程](`Images/F000126si46.png`) 作为如下三乘三矩阵：
```
$\\begin{array}{lll} {|{1 - \\left( {b^{2} + c^{2}} \\right)\\left( {1 - \\cos\\left( d \\right)} \\right)}} & {{ab}\\left( {1 - \\cos\\left( d \\right)} \\right) + d^{3}\\sin\\left( d \\right)} & {{{ac}\\left( {1 - \\cos\\left( d \\right)} \\right) - d^{2}\\sin\\left( d \\right)}|} \\\\ {|{{ab}\\left( {1 - \\cos\\left( d \\right)} \\right) - d^{3}\\sin\\left( d \\right)}} & {1 - \\left( {a^{2} + c^{2}} \\right)\\left( {1 - \\cos\\left( d \\right)} \\right)} & {{{cb}\\left( {1 - \\cos\\left( d \\right)} \\right) + {dsin}\\left( d \\right)}|} \\\\ {|{{ac}\\left( {1 - \\cos\\left( d \\right)} \\right) + d^{2}\\sin\\left( d \\right)}} & {{cb}\\left( {1 - \\cos\\left( d \\right)} \\right) + {dsin}\\left( d \\right)} & {{ 1 + \\left( {b^{2} + a^{2}} \\right)\\left( {1 - \\cos\\left( d \\right)} \\right)}|} \\\\ \\end{array}$
```
![方程](`Images/F000126si47.png`)
这是 `SO(3, R)` 的一个一般元素。这里注意，当 `d=0` 时，得到单位矩阵 `I`。这对应于三维流形表示的原点。当 `d=π` 时，`e^(ajXj)=`

![方程](`Images/F000126si48.png`)
该矩阵对流形中的对径点也成立。在此情况下，`d=π`，且坐标变量 `a`、`b` 和 `c` 现在均为负值。在这些条件下，当 `a`、`b` 和 `c` 为正时得到完全相同的矩阵。任何穿过原点的直线段都在半径为 `π` 的球面上与两个相反点相交。这些是对径点，且在这两个点处的矩阵 `e^(ajXj)`![方程](`Images/F000126si49.png`) 相同。此外，该李群是紧致的，因为一般矩阵的所有可能取值都可在该半径为 `π` 的闭球中得到。

## 11.9 李代数的复化
曾看到实向量空间可通过复化变为复向量空间。事实上，类型 SCALAR 的载体集合已从实数交换为复数。相应地，复数域被用于代替实数域。同时，类型 VECTOR 的载体集合被调整以包含虚部。来自签名集合中名为 S-MULT 和 V-ADD 的算子被用于根据其定义映射新元素。简而言之，标量乘法和向量加法在复运算下是封闭的。由于切空间是向量空间，向量空间复化适用。类似于希尔伯特空间的情况，tensor 积 `Hc=Hr ⊗ C` 适用。
对于李代数，李括号也必须被复化。在此情况下，对于李代数 `g` 中的 `A`、`B`、`D` 和 `E`，李括号的复化由类似于极化恒等式的形式给出：`\[A + i B, D + i E\]=[A, D]−[B, E] + i[A, E] + i[B, D]`（[Humphreys, 1997](#Ch011_191-216_B9780443136979000126.xhtml#bib10)）。最后，注意到矩阵 `A + Bi` 是 `A⊗1 + B⊗i` 的简写，其中 `⊗` 为张量积。因此，复化类似于仅对向量空间的复化。下面给出一个优秀的例子，使用一个被错误地假设为复代数的李代数。
