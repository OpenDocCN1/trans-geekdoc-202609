
请注意 `MINUS(1)=−1`，`MINUS(−1)=1`，且 `MINUS(0)=0`。此外，2) 成立是因为 `ZERO` 加到任何东西上都是那个东西。此外，3) 成立，因为例如 `1+(−1)={0, −1, 1}`，而 `0` 在此集合中。与常规群不同，`ZERO` 元素必须位于 `1+(−1)` 所在集合中，但它不必是 `{0}`。最后，请注意 4) 成立；例如，`x=1` 在集合 `{1+1}` 中，参照 4)，`y=1` 且 `z=1`；因此，`z` 在 `{x−y}`=`{1−MINUS(1)}`=`{1+1}`=`{1}` 中。

## 14.3 部分等距
对于 `H` 上的有界算子，部分等距 `U` 指的是当 `U` 限制在 `perp(ker(U))` 上时 `U` 是等距的。也就是说，`U`：`perp(ker(U))`→ `U` 的值域。为了对部分等距算子 `U` 获得一些直观认识，最好将其视为从 `H` 中的闭子空间 `A` 到 `H` 的另一个闭子空间 `B` 的映射。通常，在这种情况下，`A` 被称为初始空间，而 `B` 被称为终空间。`A` 是通过取核的正交补得到的，而 `B` 是通过取值域得到的。参见 [图 14.2](#Ch014_255-270_B978044313697900028X.xhtml#f0015)。同时，伴随算子 `U*` 执行相反的映射。它将子空间 `B` 映射到子空间 `A`。此外，有用的是认为在域 `A` 和 `B` 的补集中，所有值都等于零。`U*U` 是子空间 `A` 上的投影，也称为初始投影，而 `UU*` 是子空间 `B` 上的投影，称为值域投影。这些映射用于判断对称算子是否存在自伴扩张。此外，如果存在扩张，这些映射对于确定这些扩张很有用。

### 示例 14.7
设 `L` 为 *l*^(*p*)![方程](Images/F00028Xsi10.png) 中的左移算子，其中 `L(v1, v2,…)=(v2, v3,…)`, 则 `L` 是部分等距。因为 `ker(L)={(v1, 0, 0, 0,…)}`, 它由所有映射为零的 *l*^(*p*)![方程](Images/F00028Xsi11.png) 中的向量组成。`Perp(ker(L))={(v2, v3,…)}=ran(L)`。

### 示例 14.8
设 `VECTOR` 排序的载体集合为二维复值域。因此，这里在希尔伯特空间 `H`= `C`²![方程](Images/F00028Xsi12.png) 中，考虑部分等距 `Ua`=

```
\begin{matrix} {|0} & {1|} \\\\ {|0} & {0|} \\\\ \\end{matrix}
```

![方程](Images/F00028Xsi13.png)

然后，`Ua` 的初始空间为 `A`= `C` 与 `{0}` 的直和。这是因为 `ker(Ua)`=所有列向量 `(z 0)′` 的集合，其中 `z` 是任意复数。`Ua` 乘以该向量得到零。因此初始空间由所有二乘一列向量组成，第一元组在 `C` 中，第二元组为零。`Perp(ker(Ua))`=所有形如 `(0 w)′` 的向量的集合，其中 `w` 是任意复数。这也是 `Ua` 的值域。终空间 `B` 是 `{0}` 与 `C` 的直和。

参照 `H` 中从子空间 `A` 到 `B` 的部分等距。记 `Ua` 为从 `A` 到 `B` 的部分等距。`Ua` 的亏指数分别由 `perp(A)` 和 `perp(B)` 的维数给出。只有当这些指数相等时，`Ua` 才能扩展为 `H` 上的酉算子。首先，当这些指数相等时，将证明 `U` 是到整个 `H` 的扩张。`U` 将等于 `Ua` 与 `Up` 的直和，其中 `Up` 是从 `perp(A)` 到 `perp(B)` 的酉算子。该算子将 `H` 映射到自身，其定义域等于 `A` 与 `perp(A)` 的直和，值域为 `B` 与 `perp(B)` 的直和。由于两个希尔伯特空间当且仅当它们具有相同维数时同构，这表明 `U` 是一个扩张。另一方面，如果 `U` 扩展 `Ua`，则 `U(perp(A))=perp(U(A))=perp(Ua(A))=perp(B)`；由于 `U` 是酉的，`dim(perp(A))=dim(perp(B))` 且指数相等。

在 [示例 14.4](#Ch014_255-270_B978044313697900028X.xhtml#enun4) 中提到的 Cayley 变换在 `T` 为闭且对称算子时在 `H` 中提供了 `ran(T+iI)` 与 `ran(T−iI)` 之间的部分等距。此外，在这些条件下，该变换在 `H` 上是酉的当且仅当 `T` 是自伴的。von Neumann 的一个定理指出，对于闭且对称的 `T`，`T` 具有自伴扩张当且仅当其 Cayley 变换的亏指数相等。此外，`T` 具有自伴扩张当且仅当 `ker(T*−iI)` 和 `ker(T*+iI)`，或 `ran(T+iI)` 和 `ran(T−iI)`，具有相同的维数（[Conway, 1999](#Ch014_255-270_B978044313697900028X.xhtml#bib1)）。

在希尔伯特空间中，部分等距与投影之间存在密切关系。有界算子 `U` 在 `UU*` 是有界投影时称为部分等距。此外，当 `U=UU*U` 时，或当 `U*` 是部分等距且全部属于 `B(H)` 时，它也称为部分等距。前面提到的第一个恒等式与伪逆运算有关。这些关系将在下一节中得到验证。此外，伪逆运算在第 18.4 节的机器学习环境中得到说明，即回归应用。之前提到过，但不是以相同的方式，使用函数复合，如果 `Ua`: `A→B`，则 `Ua*`: `B→A` 然后 `Ua*Ua=I` 在 `A` 上，即它是希尔伯特空间 `A` 上的恒等算子。类似地，`UaUa*=I` 在 `B` 上，是 `B` 上的恒等算子。部分等距与生成 von Neumann 代数以及证明希尔伯特空间中有界算子的酉等价性内在相关（[Pearcy, 1964](#Ch014_255-270_B978044313697900028X.xhtml#bib7)）。

## 14.4 部分等距的多排序代数
`C*` 代数中提到的 `B(H)` 算子的部分等距可以用几种等价方式描述：

1. 1) 幂等：若 `v=UU*`，则 `v²=v`![方程](Images/F00028Xsi14.png)。
2. 2) 伪逆：`UU*U=U`。
3. 3) 伪逆：`U*UU*=U*`。
4. 4) 幂等：若 `w=U*U`，则 `w²=w`![方程](Images/F00028Xsi15.png)。

为证明 (1)→(2)，设 `u=U−UU*U` 然后计算 `uu*=(U−UU*U)(U*−U*UU*)`=`UU*−UU*UU*−UU*UU*+UU*UU*UU*`=`v−v²−v²+v³`=0。因为 `v³=v²v=v²`，且 `uu*=‖u‖²`。接下来，为证明 (2)→(3)，取伴随。为证明 (3)→(4) 由于 `U*UU*=U*` 且 `w=U*U`，将方程 `U*UU*=U*` 在右侧乘以 `U` 可得 `w²=w`![方程](Images/F00028Xsi16.png)。最后，为证明 (4)→(1)，设 `u=U*−U*UU*`；接下来在左侧乘以 `U` 得到 `v²=v`![方程](Images/F00028Xsi17.png)。接下来将看到在 `MSA` 中，部分等距的高层观点是幂等半群。

在本文件中多次看到并非所有算子都在其定义域上完全定义。例如，在域中对逆运算给予了特别注意和记号，对于希尔伯特空间上的动量和距离算子也是如此。将零元素的逆包含在域中会使定义域扩大以包含无穷远点。这导致一个有尖点的集合，并产生一种新的代数结构，但它不是域。在函数复合下，部分等距 `U` 通常不能跟随自身。也就是说，`U²`![方程](Images/F00028Xsi18.png) 除非 `U*U=UU*` 否则未定义，且 `U*` 也是如此（[Paterson, 1999](#Ch014_255-270_B978044313697900028X.xhtml#bib6)）。因此，乘法二元运算，实际上是函数复合，在 `MSA` 中被修改以容纳这类部分等距。此外，与之前结构一样，这些算子可以执行的顺序存在。参数不一定可交换。对于这些情况，如前所述，多元图具有斜线，表示从指定排序中参数利用的顺序。在本应用中也是如此，并带有稍后描述的额外限制；另见 [图 14.3](#Ch014_255-270_B978044313697900028X.xhtml#f0020)。
