### 3.1 从向量空间到代数
在 MSA 中引用任意向量和希尔伯特空间表示将允许以高层或全局视角描述这些结构的推广。首先，配备双线性运算的向量空间在满足若干等式恒等式时称为代数（[Gratzer, 1969](#Ch003_41-55_B9780443136979000175.xhtml#bib3)）。双线性运算通常定义为将两个向量相乘得到另一个向量。这种乘法可以根据被操作对象的载体集采取多种形式。载体集可能导致涉及函数空间中逐点类型乘法的签名集。它可以是算子的复合，即函数的函数。它可以是同伦中由路径组成的等价集的连接。此外，它可以是卷积或通常所称的群乘法。最后一种乘法是卷积神经网络（CNN）中采用的主要运算。与乘法类型无关，MSA 全局视图丰富了所有这些表示。

更精确地说，描述代数的类型包括 `VECTOR` 和 `SCALAR`，如同向量空间结构。在这种情况下，向量空间和域结构的所有相应签名集必须成立。然而，还包括一个额外的运算符名称。它是一个二元运算名称，并且完全涉及类型 `VECTOR`。该元素命名为 `BINE`，表示它是一个二元运算，并且满足如下条件。

`BINE` 映射 `VECTOR` x `VECTOR`→`VECTOR`；通常，相乘的运算元的顺序无关紧要。两个运算元在相乘时可以位于左侧或右侧。

当 `BINE` 包含在向量空间结构的签名集中时，代数的算子序列为 (1, 1, 3 (2, 1))。这里，排除内积后又有三个二元运算。其中三个运算中的两个属于同一个签名集，其算子名称的元数为二；它们是 `V-ADD` 和 `BINE`。另一个二元运算名称在它自己的签名集中；它是 `S-MULT`。有一个单一的一元运算符名称 `V-MINUS`，和一个单一的零元名称 `V-ZERO`。

在代数中，除向量空间和域结构外，还必须满足三个额外的约束方程。这些约束如下给出。为了更简洁地描述这些约束，记为：
* `SCALAR` 为：`a`, `b`
* `VECTOR` 为：`u`, `v`, `w`
* `V-ADD` 为 `+`
* `S-MULT` 为 `×`
* `BINE` 为 `·`

代数的等式恒等式如下：
1. 分配律：`(u + v)·w = u·w + v·w`。
2. 分配律：`w·(u + v) = w·u + w·v`。
3. 乘性齐次性：`a b × (u·v) = (a × u)·(b × v)`。
当满足额外约束 (4) 时，代数称为结合的：
4. 结合律：`((u·v)·w) = (u·(v·w))`。
此外，当与 `V-ZERO` 一起存在 `V-ONE` 时，代数称为幺半的，两者都属于 `VECTOR` 的零元签名集。而且，这些元素必须彼此不同，如多项式图中的单独箭头所示（[图 3.1](#Ch003_41-55_B9780443136979000175.xhtml#f0010)）。因此，幺半代数的算子序列为 (2, 1, 3 (2, 1))。这里，等式恒等式 (1)、(2)、(3) 和下面给出的 (5) 必须成立。为了方便，将 `V-ONE` 替换为 `I`，
5. `V-ONE` 律：`I·v = v·I = v`。
具有幺半元素的结合代数是满足上述所有恒等式的幺半结合代数。此外，当 (6) 成立时，代数也称为可交换或阿贝尔的。
6. 交换律：`v·w = w·v`。

当所有等式恒等式都成立时，幺半代数称为结合可交换幺半代数。所有非零元素都可逆的幺半结合代数称为除法代数。再次，幺半代数的多项式图在 [图 3.1](#Ch003_41-55_B9780443136979000175.xhtml#f0010) 中给出。在该图中，未显示仅涉及 `SCALAR` 的多类型多项式箭头。此外，如同向量空间或 R-模，`VECTOR` 与 `SCALAR` 之间的唯一联系或连接是通过 `S-MULT`。而且，`S-MULT` 运算应使用标量和向量以任意顺序使用。因此，该运算在某种程度上是可交换的，结果必须相同。

#### Example 3.1
设类型 `VECTOR` 的载体集为所有复值整函数的集合。整函数的许多等价刻画之一是它们具有无限收敛半径的幂级数表示。使用通常的逐点复加法和乘法提供了一个幺半可交换结合代数的例子。该代数对于全纯泛函演算的发展很重要，后者在后面的章节中提到的谱理论中有用。

整函数在处处解析，因此它们的和与积也是如此。一般而言，对于非零标量，它们的倒数是整的。幺半元素 `V-ONE` 是数 1。该代数包含所有多项式、`sin(z)`、`cos(z)`，以及双曲正弦和余弦，以及它们的和与积。例如，不包含在 `C` 中有极点的有理函数、在 `C` 原点有分支点的 `z^(1/2)`、在 `C` 中有本性奇点的 `exp(1/z)`，最后任何使用共轭 `z*` 的函数。然而，仅具有可去奇点的函数属于该幺半可交换代数。例如，`sin(z)/z` 在 0 处有奇点，可以去掉。
