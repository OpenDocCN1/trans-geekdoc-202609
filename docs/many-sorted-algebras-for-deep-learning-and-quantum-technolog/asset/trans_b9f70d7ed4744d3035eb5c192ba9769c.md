## 16.1 量子计算和量子电路
量子计算可以像涉及输入和输出的电路的常规计算一样进行。它也可以作为一种专门的优化类型，即绝热计算进行。在任何情况下，本章或以下章节中提到的所有方法都具有大于常规计算机的加速。然而，量子计算相对于阶为 `N` 的常规计算的加速永远不会超过二次方。已证明 [(Bennett et al., 1997)](#Ch016_291-305_B9780443136979000060.xhtml#bib8) 量子计算的阶为 `N` 平方根是尽可能最优的。量子电路型计算机和常规计算机在某些方面相似；然而，它们在许多方面也不同。
关于量子电路最根本的是输入必须是从某个希尔伯特空间的量子位。此外，这些电路的描述类似于工程学科中的输入-输出块型图示。在工程中，不同的输入通常彼此不相关；它们之间没有关系。然而在量子中，这些图示通常表示张量在一起的输入量子位，并且它们进入电路，通常以这种结构方式链接。此外，量子电路的输出数量始终等于输入数量。通常，计算以测量多个输出量子位的张量积结束。结果是波函数的坍缩。这将在后面描述的所有量子算法中都是如此。此外，对量子位执行的所有操作 `T` 必须是线性么正操作。后一要求为 `T T* = T* T = I`。将量子位的希尔伯特空间映射到自身的全部么正算符集合形成一个群，称为 `Hilbert group`。`Hilbert group` 的 MSA 描述在 [图 16.1](#Ch016_291-305_B9780443136979000060.xhtml#f0010) 中给出。这里，如通常一样，多元图说明了来自签名集的闭包操作。附带有一份等式恒等式的列表，用于严格指定群。
![Figure 16.1 Hilbert group.](Images/F000060f16-01-9780443136979.jpg)

在量子电路中证明算符 `T` 为么正的最简单方法是证明矩阵与其伴随的乘积为单位矩阵。`T` 为么正算符的一个充分条件是它既是对合又是正规的。即分别证明 `T² = I` 和 `T T* = T* T`。这一结果是有限维正规算符谱定理的推论。如果 `T` 是正规的，则 `T = A D A*`，其中 `D` 是由 `T` 的特征值组成的对角矩阵，重复多次，`A` 为么正。如果 `T` 是对合，则 `D² = I`，因此所有特征值都是正负一。这表明 `D` 既是自伴又是么正的，因为 `T = A D A*` 且 `A` 为么正表明 `T` 也是么正的。ket 表示为布洛赫球上的唯一点。
