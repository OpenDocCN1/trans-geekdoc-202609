
使用量子退火，量子比特穿过势垒试图找到最低能量态。退火周期在求解优化类问题时约为一微秒。目标函数可以写成一个最小化问题，即最小化 `w = ∑ a[i] v[i] + ∑_{i < j} b[j,k] v[j] v[k]`。量 `a[i]` ![方程](Images/F000217si129.png) 位于 `Q` 的主对角线上，被称为权重。值 `b[j,k]` ![方程](Images/F000217si130.png) 被称为强度，位于 `Q` 的非对角线条目上。量子比特最终会稳定到两种最终态之一：{0, 1}。对 `v[j]` ![方程](Images/F000217si131.png) `v[k]` ![方程](Images/F000217si132.png) 被称为耦合器；它允许一个量子比特在纠缠中影响另一个量子比特。值 `a[i]` ![方程](Images/F000217si133.png) 和 `b[j,k]` ![方程](Images/F000217si134.png) 被映射为电压、电流和磁场，以便操纵量子比特以发现全局最小值。

量子隧穿 D-wave 芯片从基态的哈密顿量开始。该态与其它的激发态之间存在最小能隙。能隙的大小恰好使能量不足以跃迁到更高态。该过程进行得非常缓慢。D-wave 构建了一款芯片用于在最近邻模型下进行优化。在芯片上，QUBO 问题将被映射为二次优化问题。该架构使用集成电路的交叉开关技术。接下来，给出一个示例来说明 D-wave 使用的仿射目标函数。它还强调了 QUBO 软件中使用的幂等运算（[O’Malley et al., 2017](#Ch006_103-128_B9780443136979000217.xhtml#bib38)）。

### 示例 6.11

对于二维示例，使用涉及仿射表示的记号，`w = v' Q v + d`，其中 `v = (x y)'`，而 `Q` 是下面给出的上三角 2×2 矩阵，后跟 2×1 向量 `Qv`，

$\\begin{matrix} \\begin{matrix} \\left| a \\right. & \\left. c \\right| \\\\ \\left| 0 \\right. & \\left. b \\right| \\\\ \\end{matrix} & \\begin{matrix} \\left| {ax} + {cy} \\right| \\\\ \\left| by \\middle| . \\right. \\\\ \\end{matrix} \\\\ \\end{matrix}$

![方程](Images/F000217si135.png)

量 `w = v' Q v = a x² + c x y + b y² + d`。但是，由于在 QUBO 中幂运算是幂等的，这意味着 `x² = x` 且 `y² = y`。因此可得 `w = a x + b y + c x y + d`，这在 QUBO 中被称为谱。

### 示例 6.12

这里有一个简单的例子，`x` 和 `y` 的取值在 {0, 1} 中。目标是找到 `z = (x + y) = 0 mod 2`。这是 `x` 和 `y` 相等的情况，也是逻辑中的等价运算。将构造一个真值表。在 Spectrum 列中，当逻辑运算为真时，该列放置零。零表示获得最低能量的目标，0 < 1。

$\\begin{matrix} x & y & {{Spectrum} = w} & \\\\ 0 & 0 & 0 & {{Lowest}{energy}} \\\\ 0 & 1 & 1 & \\\\ 1 & 0 & 1 & \\\\ 1 & 1 & 0 & {{Lowest}{energy}} \\\\ \\end{matrix}$

![方程](Images/F000217si136.png)

浏览上方的真值表可得出解 `y = x`。利用前一个示例的结果，可以构造仿射映射。

在这种情况下，谱值由前一个示例得出，`w = a x + b y + c x y + d`。必须找到 `Q` 和 `d`。为此，按行遍历真值表。代入 `x` 和 `y` 的值并使用谱值 `w`。对于第一行，所有值 `x`、`y` 和 `w` 均为零。因此，`0 = w = a 0 + b 0 + c 0` 得出 `d = 0`。从第二行，`1 = w = a 0 + b 1 + c 0` 显示 `b = 1`。使用第三行 `1 = w = a 1 + c 0` 推导出 `a = 1`。最后，最后一行 `0 = w = a 1 + b 1 + c 1 1` 得到 `c = -2`。因此，`w = x + y - 2 x y`。作为结果，`d = 0` 且 `Q =`

$\\begin{array}{ll} {|1} & {{- 2}|} \\\\ {|0} & {{\\mspace{22mu} 1|}.\\#} \\\\ \\end{array}$

![方程](Images/F000217si137.png)

使用 AQC 时，必须指定一个目标函数，为某些变量提供能量水平。当这些变量达到该能量水平时，就会出现解。它对应于低能量态或以高概率出现的最低能量态。量子比特的最终态代表解。

D-wave 编程模型：
* 量子比特，`v[i]`：该值参与退火过程并在 {0, 1} 中达到最终态。量子比特通常利用量子叠加发生干涉。
* 耦合器，`v[i]`，`v[j]`：该对允许单个量子比特影响另一个量子比特，从而产生纠缠。
* 权重 `a[i]`：权重是分配给每个量子比特的实标量。它影响量子比特坍缩为最终态。这些量是矩阵 `Q` 中的对角元素。
* 强度，`b[i j]` ![方程](Images/F000217si138.png)：这是分配给每个耦合器的实标量。它影响一个量子比特对另一个量子比特的控制。这些是 `Q` 的非对角元素。
* 目标，`Obj` 成本函数，在退火周期中被最小化。这就是 `w`。

## 6.11 绝热定理

绝热过程是一种缓慢而渐进的变化事件，其中量子系统避免跃迁态或改变量子数。绝热不变量 `I` 是能量除以频率的商，`E / w`。作为绝热过程的一个实例，考虑谐振子。在 [示例 6.1](#Ch006_103-128_B9780443136979000217.xhtml#enun1) 中，能级被表述为 `E[n] = h w (2n + 1)/2`。由于谐振子情况下的绝热不变量涉及整数，连续变化是不可能的。该过程必须在变化中进行离散或量子跃迁。大量其他量子系统具有离散谱，它们对应的能级在数值上会跃迁。在这些情况下，尤其是在缓慢变化条件下，会避免变化。另一个主要例子是 Bohr-Sommerfield ([Hall, 2013](#Ch006_103-128_B9780443136979000217.xhtml#bib13)) 的微型太阳系量子模型。在这种情况下，存在量子化条件，使得量子数在缓慢变化条件下不希望改变。对绝热过程及其与 Berry’s phase 关系的最好读解释，后者将在后面介绍，见 [Zwanziger et al. (1990)](#Ch006_103-128_B9780443136979000217.xhtml#bib30)。

本文所述的绝热定理以正式形式给出。它遵循 [Zwiebach (2018](#Ch006_103-128_B9780443136979000217.xhtml#bib31)) 的优秀阐述。具体而言，证明了使状态为真的薛定谔解 `Ψ(t)` 与瞬时本征态 `ψ(t)` 之差的误差为 `O(1/T)` 量级。该关系在持续时间为 `T` 的绝热过程中成立。符号上，`‖Ψ(t) - ψ(t)‖` 为 `O(1/T)` 量级，`t` 在 `[0, T]` 中。时间长度 `T` 是绝热过程的持续时间。哈密顿量的瞬时本征态 `ψ(t)` 是一个波函数 `ψ(t)`，具有性质 `H(t) |ψ(t)> = E(t) |ψ(t)>`。这里，`H` 是哈密顿量，`E(t)` 是能量本征值。如前所述，在缓慢变化的过程中很难进行量子跃迁，因为能级通常是离散的。绝热定理的正式说明如下。
