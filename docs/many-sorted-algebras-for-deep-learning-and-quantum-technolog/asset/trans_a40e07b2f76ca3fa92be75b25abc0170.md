
# 玻色 Fock 空间代数

玻色 Fock 空间代数在希尔伯特空间 `H` 上允许所有态被 `n` 占据，其中 `n` 是任意有限的粒子数。也就是说，`n=0, 1, …`。在此空间中，数算符 `Nj` 给出第 `j` 个本征态的粒子数计数。该算符追踪位于每个态中的粒子数量。对于可观测量 `A`，占据数 `nj` 具有非负整数本征值，使得 `Nj (|n0, n1, n2,…, nj,…, nk>)=nj |n0, n1,…, nj,…, nk>`。相应地，对于算符 `Nj`，本征矢量是 `|n0, n1, n2,…, nj,…, nk>`，而对应的本征值是占据数 `nj`。可观测量 `A` 可以写成和，$\\sum\\limits\_{j}{({{cj}{Nj}})}$![方程](Images/F000291si4.png)，其中 `cj` 为标量。

在 Fock 空间中采用产生操作来在规定的量子态 `j` 中添加一个粒子。该算符记为 `a_j^\dagger`![方程](Images/F000291si5.png)；它仅关注第 `j` 个态并将该态的占据数增加一。对量子态的此操作是外积或对称乘法。具体而言，`a_j^\dagger`![方程](Images/F000291si6.png) (`|…, nj, …>`) = `(nj+1)^(1/2) (|…, nj+1, …>)`。在下文中，这些算符的括号通常会被省略。与产生算符相反的是湮灭算符 `a_j`。CCR 中使用了这两个算符的例子。参见[第 14.8 节](#Ch014_255-270_B978044313697900028X.xhtml#s0045)。在那里，产生算符由 `a^\dagger=(Q−iP)/2^(1/2)` 给出，涉及位置算符 `Q` 和动量算符 `P`。类似地，湮灭算符 `a` 由 `a=(Q+iP)/2^(1/2)` 给出。

一般而言，产生算符无论粒子是否存在都会添加一个粒子。对于非空态，湮灭会使占据数减少一。然而，当第 `j` 个态为空时，对该态执行湮灭算符将得到零。当湮灭算符作用于真空态 `C`，即 `vac` 时，结果也为零。湮灭算符执行的操作是对态的一种内积型操作。综上所述，对于非空态，`a_j |…, nj, …>=n_j^(1/2)`![方程](Images/F000291si7.png) `|…, nj−1,…,>`，当 `nj` 为正时，否则得到零。[图 15.1A](#Ch015_271-288_B9780443136979000291.xhtml#f0010) 说明了玻色 Fock 空间中的阶梯算符。

### Example 15.3

这是使用前面提到的矩阵来找到从指定态产生和湮灭粒子的标量倍数的应用。假设产生算符是 `a_2^\dagger`![方程](Images/F000291si12.png)，即态二要增加一个额外粒子。转到上面的第二列并到前面提到的右侧矩阵的第三行，找到标量项 `3^(1/2)`![方程](Images/F000291si13.png)。例如，在应用操作之前，假设空间占据为 `ϕ=|3, 0, 6, 4, 0,…, nk>`；则 `a_2^\dagger`![方程](Images/F000291si14.png)(`ϕ`)=`3^(1/2) |3, 0, 7, 4, 0,…, nk>`。接下来，假设要对涉及 `ϕ`![方程](Images/F000291si15.png) 的第三态执行湮灭操作。要找到 `a_3(ϕ)`，使用前面提到的第一个矩阵的第三列第二行得到 `3^(1/2)`![方程](Images/F000291si16.png)，所以 `a_3(ϕ)=3^(1/2) |3, 0, 6, 3, 0,…, nk>`。如果需要 `a_1(ϕ)`，则答案为零，因为在 `ϕ` 中没有粒子可以从态一取走。

前面提到的矩阵可以用数基本征矢量 `ψ[i]`![方程](Images/F000291si17.png) 和 `ψ[j]`![方程](Images/F000291si18.png) 使用。这将在[第 19.1 节](#Ch019_349-364_B9780443136979000278.xhtml#s0010) 中出现，在那里对所有能量值描述了谐振子解。在任何情况下，以下恒等式成立：`a[i,j]=<ψ[i]`![方程](Images/F000291si19.png) `|a |ψ[j]`![方程](Images/F000291si20.png)`>` 和 `a[i,j]^\dagger=<ψ[i]`![方程](Images/F000291si21.png) `|a^\dagger`![方程](Images/F000291si22.png) `|ψ[j]`![方程](Images/F000291si23.png)`>`。

产生算符 `a^\dagger`![方程](Images/F000291si24.png)、湮灭算符 `a` 和数算符 `N` 之间存在众多关系。其中一些关系已在上一节中说明。在确定额外关系之前，将假设产生操作和湮灭操作互为伴随算符。也就是说，`a^\dagger=a*` 且 `(a^\dagger)*=a`。这些事实在玻色 Fock 空间的 Banach 空间完备化的 C* 代数中得到证明（[Townsend, 2000](#Ch015_271-288_B9780443136979000291.xhtml#bib10)）。现在使用具有 `n` 个粒子的非真空且占据的态。这里，`a^\dagger a |n> = n^(1/2) a^\dagger |n−1> = n^(1/2) n^(1/2) |n> = N |n>`![方程](Images/F000291si25.png)。因此，数算符与产生和湮灭操作之间的等同是 `N = a^\dagger a`![方程](Images/F000291si26.png)。类似地，`a a^\dagger |n> = (n+1)^(1/2) a |n+1> = (n+1)^(1/2) (n+1)^(1/2) |n> = (n+1) |n>`![方程](Images/F000291si27.png)。由此可知 `a a^\dagger`![方程](Images/F000291si28.png) 像 `(N+I)` 一样作用。这是数算符加上恒等映射。交换关系是前面给出的恒等式的推论。换位子，`[a,a^\dagger]=a a^\dagger − a^\dagger a = (N+I) − N = I`![方程](Images/F000291si29.png)。此外，`[N,a^\dagger]=N a^\dagger − a^\dagger N = a^\dagger a a^\dagger − a^\dagger a^\dagger a = a^\dagger (a a^\dagger − a^\dagger a) = a^\dagger (I) = a^\dagger`![方程](Images/F000291si30.png)。类似地，`[N,a]=N a − a N = a^\dagger a a − a a^\dagger a = (a^\dagger a − a a^\dagger) a = − a`![方程](Images/F000291si31.png)。
