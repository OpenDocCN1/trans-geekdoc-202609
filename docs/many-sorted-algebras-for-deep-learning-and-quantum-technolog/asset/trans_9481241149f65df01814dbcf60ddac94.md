## 19.4 Mercer 定理

对于 `K`，在 `L²` ![Equation](Images/F000278si174.png) 中，`K`: X x X→R 被称为正定核，前提是 `K` 是对称的。 即，`K(x, y)` = `K(y, x)`，且它是半正定的；这意味着对于 `L²` ![Equation](Images/F000278si175.png) 中任意非零函数 `f`，有 ∫∫ ![Equation](Images/F000278si176.png) `f(x)` `K(x,y)` `f(y)` dx dy 大于或等于零。 当 ∫∫ ![Equation](Images/F000278si177.png) `f(x)` `K(x,y)` `f(y)` dx dy > 0 时它是正定的。 将假设 `K` 具有有限迹性质；这里 `K` 是连续的，并且积分 ∫∫ `K(x,y)²` ![Equation](Images/F000278si178.png) dx dy 是有限的。

特征值和特征函数出现的情形与 Fredholm 型积分方程类似。 具体来说，`ϕ` ![Equation](Images/F000278si179.png) 是核 `K` 的特征函数，如果 ∫ ![Equation](Images/F000278si180.png) `K(x,y)` `ϕ(y)` dx = `λ ϕ(x)`。 这里，`λ` ![Equation](Images/F000278si181.png) 是特征值。 该方程记为内积：`<K, ϕ>` = `λ ϕ`。 特征值和特征函数为学习机器中出现的误差提供估计。

Mercer 的一个定理指出，如果 `K` 是一个具有有限迹的正定核，则存在一个可数无限的特征函数集合，{`ϕ[i]`}，其对应的特征值为 `λ[i]` ![Equation](Images/F000278si182.png)，其中 `λ[1]` ![Equation](Images/F000278si183.png) 大于或等于 `λ[2]` ![Equation](Images/F000278si184.png)，而 `λ[2]` 大于或等于 `λ[3]` ![Equation](Images/F000278si185.png) … 大于零。 最后，`K(x,y)` = Σ_{n=1}^{∞} `λ_n` `ϕ_n(x)` `ϕ_n(y)` ![Equation](Images/F000278si186.png)，并且可以证明收敛是绝对且一致的。 对于 `L²` 中的 `f`，![Equation](Images/F000278si187.png) 特征函数可以被运用，其方式与傅里叶级数计算非常相似。 这里，∫ `f(y)` `ϕ[n](y)` `d x` = < `f`, `ϕ[n]` > = `f[n]` ![Equation](Images/F000278si188.png)，其中 `ϕ[n]` ![Equation](Images/F000278si189.png) 是与核 `K` 相关联的特征向量，而 `λ[n]` ![Equation](Images/F000278si190.png) 是对应的特征值。 在这种情况下，可以在核空间中创建涉及函数 `f` 和 `g` 的内积；该内积定义如下：`< f,g >` = Σ_{n=1}^{∞} (`f_n` ⋅ `g_n`) / `λ_n` ![Equation](Images/F000278si191.png)。

特征映射可以通过 Mercer 定理的帮助创建。 这里，特征空间是 `l²` ![Equation](Images/F000278si192.png)，并且特征映射：`X` → `l²` ![Equation](Images/F000278si193.png)，且 `Φ(x)` = `λ^(1/2)` (`ϕ[1](x)`, `ϕ[2](x)`,…) ![Equation](Images/F000278si194.png)。

只要且仅当 N 个特征值为正时，特征映射：`X` → `R^(N)` ![Equation](Images/F000278si195.png)。 形成 `l²` ![Equation](Images/F000278si196.png) 内积将提供核的公式，`< Φ(x),Φ(y) >` = Σ_{n=1}^{∞} (`λ_n^(1/2) ϕ_n(x)`) (`λ_n^(1/2) ϕ_n(y)`) = Σ_{n=1}^{∞} `λ_n ϕ_n(x) ϕ_n(y)` = `K(x,y)` ![Equation](Images/F000278si197.png)。
