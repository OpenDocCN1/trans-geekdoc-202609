
## 谱类型

### 1) 点谱
对于 `sppT`，`Ker(λ I−T)` 不是 `{0}`；必须存在 `X` 中的非零向量 `f` 使得 `T f = λ f`，`f → (T−λ I)f`。该映射在 `X` 中不是一一对应的；`f` 的任意非零倍数都满足此条件，因为特征向量的任意非零标量倍仍是特征向量。在复 n 维空间中，`dim(Ran(T)) + dim(Ker(T)) = n`。此外，`X` 中的 `f` 称为特征向量，而 `λ` 称为特征值。在有限维希尔伯特空间中，仅存在这种点谱。点谱的若干例子已在有限维 Banach 或希尔伯特空间的矩阵运算中得到说明。无限维空间中点谱的最简单说明见示例 8.16。无限维希尔伯特空间中具有点谱的额外例子见 [示例 13.1](#Ch013_231-253_B9780443136979000138.xhtml#enun1) 和 [13.2](#Ch013_231-253_B9780443136979000138.xhtml#enun2)。

### 2) 连续谱
对于 `spcT`，`Ker(λ I−T)` 为 `{0}`，且 `λ I−T` 的像在 `H` 中稠密，但 `Im(λ I−T)` 不等于 `X`。等价地，`λ I−T` 在 `H` 中稠密当且仅当 `ker(λ I−T)* = {0}`。由于 `Ker(λ I−T)` 为 `{0}`，`(λ I−T)(f[1] – f[2]) = 0`；这意味着 `f[1] = f[2]`，因此 `(T−λ I)` 在 `X` 上是一一对应的。它不是满射，因为如果它是满射则 `Im(λ I−T) = X`。该谱的实例见示例 8.17 和 8.18。

### 3) 剩余谱
`Ker(λ I−T)` 为 `{0}`，`λ I−T` 的像在 `H` 中不稠密，且 `Im(λ I−T)` 不等于 `H`；则 `λ` 属于剩余谱。这意味着具有剩余谱的算子 `T` 与满射相去甚远。相关谱记为 `sprT`。非空剩余谱的例子见 [示例 13.3](#Ch013_231-253_B9780443136979000138.xhtml#enun3)（[Stack Exchange，2016](#Ch013_231-253_B9780443136979000138.xhtml#bib13)）。

### 示例 13.1
考虑 `l^(p)`，其中 `p` 在 `[1, ∞)` 中，标量在 `C` 中。对于 `C` 中有界的 `λ[1]`、`λ[2]`、`λ[3]`、…，即 `sup|λ[n]| < ∞`。设 `T` 为无限标量矩阵 `T: l^(p) → l^(p)`，`T` 在主对角线上按顺序取 `λ[n]` 的值。利用标准基可得 `T v[n] = λ[n] v[n]`，其中特征向量为 `v[n] = (0 0 … 0 1 0…)`，且 1 位于第 n 个分量位置。因此 `sppT` 是集合 `spT` 的子集。也就是说，`v[n]` 是对应于特征值 `λ[n]` 的特征向量。

在所有特征值的集合的闭包中，可能存在 `C` 中的点 `c`，且该点属于谱。如果对于所有 `λ[n]` 的集合存在极限点 `c`，则 `c` 不能在 `sppT` 中，但 `c` 在 `spT` 中。这将在所有特征值集合的闭包中发生。例如，若 `λ[n] = 1/n`，则 `0` 将属于 `T` 的谱，即它是 `sprT` 或 `spcT`。

### 示例 13.2
设 `T: l² → l²` 在复数域上。对于 `l²` 中的任意 `v`，有 `T(v1, v2, v3, …) = (v1, v2/2, v3/3, …)`。点谱为 `{1, 1/2, 1/3, …}`。这可通过写出主对角线上取值为 `1/n` 的无限标量矩阵轻松看出。利用标准基可得 `T v[n] = λ[n] v[n]`，其中特征向量为 `v[n] = (0 0 … 0 1 0…)`，且 1 的值位于第 n 个分量位置。因此 `sppT` 是集合 `spT` 的子集。也就是说，`v[n]` 是对应于特征值 `λ[n]` 的特征向量。零是特征值的极限点。因此零也属于 `spT`。

### 示例 13.3
这是一个剩余谱非空的例子。设希尔伯特空间 `H` 的载体集为 `l²`，即所有具有复数项的平方绝对可和序列的空间。对于 `T: l² → l²`，考虑 `T(v1, v2, v3, …) = (0, v1, v2/2, v3/3, …)`。这是一个右移操作。`Ker(c I - T) = {0}`。`T v1 = 0`，`T v2 = v1`，`T v3 = v2/2` …. 因此谱不为空，且零是谱点，因为不可逆准则。`T` 不是满射，因为值域中的第一个分量是固定的。若 `vn` 是第 n 个位置为 1，其余位置为 0 的单位向量，则 `T vn ---> 0`。见 [Stack Exchange（2016）](#Ch013_231-253_B9780443136979000138.xhtml#bib13)。注意对偶算子 `T*` 满足 `<T* w, v> = <w, T v>`。由于 `T(v1, v2, v3, …) = (0, v1, v2/2, v3/3, …)`，将其代入左侧内积得 `w1' * v1 + w2' * v2 + w3' * v3 + … = w1 ·` 接下来展开另一个内积得到 `0 + w2 v1 + w3 v2/2 + …`。这里，`wj' * = T* wj`。接下来令 `vj` 的系数相等可得 `w1' * = w2`，`w2' * = w3/2`，…. 因此，`T* (w1, w2, w3, …) = (w2, w3/2, …)`。这是一种左移型操作。

## 13.2 Banach 空间上算子的谱
当伴随算子存在时，其谱通常与原算子的谱相关。`Lumer-Phillips` 定理是确定希尔伯特和 Banach 空间中伴随算子谱的有用工具（[Lumer 和 Philips，1961](#Ch013_231-253_B9780443136979000138.xhtml#bib9)）。该定理在 [He’lein（2014）](#Ch013_231-253_B9780443136979000138.xhtml#bib21) 中被用来说明 Banach 空间中有界算子的不同谱类型。以下各节中重复了许多相同的例子。然而，首先，`Lumer-Phillips` 定理指出，在 Banach 空间 `A` 中，`T'` 为 `A` 中 `T` 的对偶算子时，谱 `spT = spT'`。此外，对于 resolvent 集 `Rs(T)` 中的 `c`，resolvent 算子 `Rc(T)' = Rc(T')`。另外，对于具有伴随 `T*` 的希尔伯特空间中的 `T`，可得 `spT* = (spT)* = {c* | c in the spectrum of T, that is, c in spT}`。最后，对于 resolvent 集 `Rs(T)` 中的 `c`，resolvent 算子：`Rc*(T*) = (Rc(T))*`。
