## 19.4 Mercer’s theorem

For `K`, in `L²` ![Equation](Images/F000278si174.png), `K`: X x X→R is called a positive definite kernel provided that `K` is symmetric. That is, `K(x, y)` = `K(y, x)`, and it is positive semidefinite; this means that for any nonzero function `f` in `L²` ![Equation](Images/F000278si175.png) it follows that ∫∫ ![Equation](Images/F000278si176.png) `f(x)` `K(x,y)` `f(y)` dx dy is greater than or equal to zero. It is positive definite when ∫∫ ![Equation](Images/F000278si177.png) `f(x)` `K(x,y)` `f(y)` dx dy > 0. It will be assumed that `K` has the finite trace property; here `K` is continuous and also the integral ∫∫ `K(x,y)²` ![Equation](Images/F000278si178.png) dx dy is finite.

Eigenvalues and eigenfunctions arise similar to those in Fredholm-type integral equations. Specifically, `ϕ` ![Equation](Images/F000278si179.png) is an eigenfunction for the kernel `K` if ∫ ![Equation](Images/F000278si180.png) `K(x,y)` `ϕ(y)` dx = `λ ϕ(x)`. Here, `λ` ![Equation](Images/F000278si181.png) is an eigenvalue. This equation is denoted as an inner product: `<K, ϕ>` = `λ ϕ`. Eigenvalues and eigenfunctions provide estimates on errors occurring in learning machines.

A theorem of Mercer states that if `K` is a positive definite kernel with finite trace, then there exists a countably infinite set of eigenfunctions, {`ϕ[i]`} with corresponding eigenvalues `λ[i]` ![Equation](Images/F000278si182.png) where `λ[1]` ![Equation](Images/F000278si183.png) is greater than or equal to `λ[2]` ![Equation](Images/F000278si184.png) that is greater than or equal to `λ[3]` ![Equation](Images/F000278si185.png) … is greater than zero. Finally, `K(x,y)` = Σ_{n=1}^{∞} `λ_n` `ϕ_n(x)` `ϕ_n(y)` ![Equation](Images/F000278si186.png), and the convergence can be shown to be absolute and uniform. For `f` in `L²`, ![Equation](Images/F000278si187.png) the eigenfunctions can be employed very similar to Fourier series computations. Here, ∫ `f(y)` `ϕ[n](y)` `d x` = < `f`, `ϕ[n]` > = `f[n]` ![Equation](Images/F000278si188.png), where `ϕ[n]` ![Equation](Images/F000278si189.png) is an eigenvector associated with the kernel `K`, and `λ[n]` ![Equation](Images/F000278si190.png) is the corresponding eigenvalue. In this case, an inner product can be created in the kernel space involving functions `f` and `g`; this inner product is defined as follows: `< f,g >` = Σ_{n=1}^{∞} (`f_n` ⋅ `g_n`) / `λ_n` ![Equation](Images/F000278si191.png).

Feature maps can be created with the help of Mercer’s theorem. Here, the feature space is `l²` ![Equation](Images/F000278si192.png), and the feature map: `X` → `l²` ![Equation](Images/F000278si193.png), and `Φ(x)` = `λ^(1/2)` (`ϕ[1](x)`, `ϕ[2](x)`,…) ![Equation](Images/F000278si194.png).

Whenever and if only N of the eigenvalues are positive, then the feature map: `X` → `R^(N)` ![Equation](Images/F000278si195.png). Forming the `l²` ![Equation](Images/F000278si196.png) inner product will provide the formula for the kernel, `< Φ(x),Φ(y) >` = Σ_{n=1}^{∞} (`λ_n^(1/2) ϕ_n(x)`) (`λ_n^(1/2) ϕ_n(y)`) = Σ_{n=1}^{∞} `λ_n ϕ_n(x) ϕ_n(y)` = `K(x,y)` ![Equation](Images/F000278si197.png).
