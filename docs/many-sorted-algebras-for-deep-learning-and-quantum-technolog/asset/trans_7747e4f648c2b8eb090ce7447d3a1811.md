
对于 `B` 中任意点 `x`，`p^(−1)(x)` 必须与纤维 `F` 微分同胚。一般而言，局部平凡化对 `E` 中的任意 `u` 发生；这始于投影 `p(u)=x`，其中 `u` 是位于 `x` 上方纤维的元素。纤维丛是一组覆盖基流形的平凡化。可以利用映射 `h(u)=(x, f)`，其中对于 `B` 中任意开集 `U`，`h: p^(−1)(U)→U x F`。设 `h′` 为另一个平凡化：`h′(u)=(x, f′)`，其中 `h′: p^(−1)(U)→U x F`。当这两个平凡化重叠时，`h` 和 `h′` 与基于 `x` 的转移函数相关。此实例在 [图 10.9](#Ch010_171-188_B9780443136979000047.xhtml#f0050) 中有所说明。对于重叠部分，纤维丛的结构群 `G` 具有元素 `g`，取决于 `x`，使得 `f′=g f`。这是 `G` 对 `F` 的光滑左作用。转移函数将纤维映射到纤维中并且是微分同胚；它们属于结构群。该群是 `F` 上所有微分同胚的子集。回想一下，平凡纤维丛是纤维丛，其中处处 `E=B x F`。在这种情况下只需要一个丛图。

## 10.5 纤维丛中的截面

纤维丛的截面是从 `B` 到 `E` 的一种恒等型映射。截面包含位于基 `B` 中点 `x` 上方的 `F` 中的点，投影 `p` 应用于截面中的点时恢复原始基点 `x`。

### 例 10.6

参见上文给出的莫比乌斯纤维丛，特别是 [图 10.7](#Ch010_171-188_B9780443136979000047.xhtml#f0040)。`u` 在 `[0, 2π)` 中的传输中的整个连续路径是一个截面。在这种情况下，假设路径中没有间隙，使得路径中每一点的投影恢复整个基 `S¹`。在图中，起始位置显示在条带的远端，而终点在条带背面顶部以极限的方式逼近。

### 例 10.7

与莫比乌斯纤维丛相比，这是一个更简单的平凡纤维丛的例子。将 `R²` 视为总空间 `E`。设基 `B` 仅为直线 `R¹`，即 `x` 轴。还设纤维为 `F=R¹`，其放置正交于原始直线 `B`，彼此平行，并构成一个平面。这是一个平凡丛，即 `E=B x F`。直观上将基视为 `x` 轴，纤维是沿 `y` 轴且全部平行的线条。此外，如果 `g: B→F`，其中 `g(x)=x³`，则 `g` 是一个截面。因此，投影映射 `p(g)(x)` 给出 `B` 上的所有点。这在 [图 10.8](#Ch010_171-188_B9780443136979000047.xhtml#f0045) 中有所说明。

## 10.6 线丛和向量丛

一般而言，丛由覆盖纤维丛中基流形的平凡化集合组成。平凡化利用转移函数创建丛。线丛或秩一的向量丛具有一维复或实向量空间的纤维。此外，结构群在线性空间上线性作用。严格来说，它们是通过令 `L` 和 `B` 均为光滑流形且具有光滑满射投影 `p: L→B` 来定义的。对于 `B` 中的每个 `x`，`L` 在 `x` 上的纤维 `F`，即 `p^(−1)({x})`，是一个一维复向量空间。如前所述，对每个 `x` 存在一个平凡化。存在 `x` 的一个开邻域 `U`，使得微分同胚 `h: p^(−1)(U)→U x C`。此外，对于投影 `p1: U x C→U` 和 `p2: U x C→C`，首先令 `p(u)=p1(h(u))` 对所有 `U` 中的 `x` 成立。在这种情况下，`p2(h(u))` 是 `p^(−1)({x})` 与 `C` 的向量空间同构。[图 10.9](#Ch010_171-188_B9780443136979000047.xhtml#f0050) 说明了这些概念中的一些。

向量丛具有实或复 `n` 维向量空间的纤维。此外，结构群在线性空间上线性作用。转移函数也在纤维上进行 `n` 维运算。这些函数属于 `GL(n, R)` 或 `GL(n, C)` 中的子群；这两个群都是一般线性群，并在下一章中详细描述。

## 10.7 解析向量丛

设 `B` 为 `C` 上的复流形。秩为 `n` 的解析向量丛是全纯映射 `p: E→B`，使得对于 `B` 中任意点 `x`，原像 `Ex=p^(−1)(x)` 具有 `n` 维复向量空间结构。这里，`Ex` 是纤维。此外，映射 `p` 是局部平凡的。这意味着对于基 `B` 中任意点 `x`，存在一个开邻域 `Uj`，其中包含 `x` 以及一个双全纯映射 `fj: p^(−1)(Uj)→Uj x C^(n)`，其中投影 `p1: Uj x C^(n)→Uj=p(p^(−1)(Uj))`。此外，`fj` 是从 `Ex` 到 `{x} x C^(n)` 的同构映射，对 `Uj` 中每个 `x` 成立，也称为 `E` 在 `U` 上的平凡化。如前所述，一般线性群参与其中。对于任意一对平凡化 `fi` 和 `gj`，映射 `hij: Ui intersects Vj→GL(n, C)`，其中 `hij(x)=fi(gj^(−1))`，但 `gj` 的定义域限制为 `{x} x C^(n)`。该映射是全纯的，称为相对于平凡化 `fi` 和 `gj` 的 `E` 的转移函数。转移函数满足恒等式：

1. 逆：`hij(x) hji(x)=I` 对所有 `x` 在 `Ui intersect Uj` 中。

2. 上循环条件：`hij(x) hjk(x) hki(x)=I` 对所有 `x` 在 `Ui`、`Uj` 和 `Uk` 的交集中。

向量丛 `E` 可以使用转移函数 `hij: Ui intersect Uj→GL(n, C)` 创建，其中 `{Uk}` 是 `B` 的一个开覆盖。这采用了使用所有 `I` 的 `Ui X C^(n)` 的粘合构造，从而得到 `E=the disjoint union of (Ui x C^(n))/~`。这里，`~` 指等价类 `(x, v)~(x, hij(x)(v))`，对所有 `x` 在 `Ui intersect Uj` 中且 `v` 在 `C^(n)` 中。

### 例 10.8

秩为 `n` 的平凡解析向量丛使用投影映射 `p1: B x C^(n)→B`。对于 `B` 上的向量丛 `E`，设 `hij` 为转移函数，`{Uj}` 为 `B` 的一个开覆盖。对偶丛为 `E*`，由转移函数 `gij(x)=hij^(−1)(x)` 定义，对所有 `x` 在 `Ui intersect Uj` 中。对于 `B` 中的开集 `U`，`U` 上的全纯截面 `s` 为 `s: U→E`，且 `p(s(U))=U`。`E` 的整体截面是 `U=B` 的全纯截面。在这种情况下，所有此类整体截面形成一个向量空间，记为 `Ho(B, E)` ([Chern, 1979](#Ch010_171-188_B9780443136979000047.xhtml#bib1))。

## 10.8 `C` 上的椭圆曲线

椭圆曲线在多个不同的域上定义。这些载体集合包括实数、有理数和伽罗瓦域，以及当前应用的复域。附录 A3 提供了关于涉及实域的椭圆曲线的加法群结构的 MSA 的介绍。后续章节将利用伽罗瓦域上的椭圆曲线用于加密目的。

对于 `C` 上的椭圆曲线 `E`，总存在一个格 `L`，是 `C` 的一个子集，在缩放或相似变换下是唯一的。相似变换保持关于中心的伸缩和收缩。对于每个格，都存在一个椭圆曲线。更具体地说，椭圆曲线是 `C` 对格的商空间。反之，`C` 对格的任何商空间都是椭圆曲线。此外，存在一个复分析和同构 `g`，`g: C/L→E` ([Silverman, 2009](#Ch010_171-188_B9780443136979000047.xhtml#bib12))。这是复平面上椭圆曲线上的点集。它是李群的同构。均匀化定理提供了 `C` 上的椭圆曲线与格之间的联系。

### 例 10.9

椭圆曲线是三次曲线 `y²=x³ + a x + b`，其中 `a` 和 `b` 现在是复数。此外，`4 a³ + 27 b²` 不为零，使得曲线光滑。设 `E={(x, y), 其中 x 和 y 在 C 中且是椭圆曲线上的点}` 并上无穷远点 `∞`。在射影空间中，`∞=(0: 1: 0)` ([Coxeter, 1989](#Ch010_171-188_B9780443136979000047.xhtml#bib2))。
