## 19.2 复数域上关于 C 的再生核希尔伯特空间和圆盘代数

首先，`H` 是 `X` 上的再生核希尔伯特空间（RKHS）的一个有用且直观的定义意味着 `H` 是非空集合 `X` 上复值连续函数的希尔伯特空间。因此，`H` 是 `C^(X)`![Equation](Images/F000278si15.png) 的子集。此外，对于 `H` 中的所有函数或向量，`f` 和 `g`，以及 `ϵ`![Equation](Images/F000278si16.png)> 0，存在一个 `δ`![Equation](Images/F000278si17.png)> 0，使得如果 ‖`f−g`‖<`δ`![Equation](Images/F000278si18.png)，则 |`f(x)−g(x)`|<`ϵ`![Equation](Images/F000278si19.png)。相应地，这意味着函数是逐点连续的。使用 RKHS，有界性和连续性无关。为了说明这是微妙的要求，请考虑以下示例。

### 示例 19.1

设 `H` 为 [0, 1] 上复值绝对平方函数的希尔伯特空间。考虑该闭区间上的两个函数 `f=t` 以及 [0, 1) 上的 `g=t` 且 `g(1)=4 + 3i`。在这种情况下，‖`f−g`‖=0；然而，sup |`f−g`|=5。这些函数是有界的，但不连续。#

在前面的例子中，表明希尔伯特空间中的有界性在逐点计算中对于连续性而言不起作用。函数 `K`: `X²→C` 被称为 `H` 的再生核，只要 `H` 包含 `X` 中 `x` 的所有一元函数，其中 `K[x]` (`y`)=`K` (`x`, `y`)，并且对于 `X` 中的每个 `x` 和 `H` 中的 `f`，则 `f` (`x`)=<`f`, `K[x]`>。最后一个性质是实际的再生性质。

构建 RKHS 并将其与再生性质联系起来的严格方法的关键是 Riesz 表示定理（`RRT`）：对于具有内积 <·,·>: `H x H→C` 的希尔伯特空间 `H` 和 `H*` 中的任意连续线性泛函 `ϕ`![Equation](Images/F000278si20.png)，存在 `H` 中唯一的向量 `f[ϕ]`![Equation](Images/F000278si21.png) 使得 `ϕ(v) = < v, f[ϕ] >`![Equation](Images/F000278si22.png)，对所有 `v` ∈ `H` 成立。此外，范数相等，即 ∥`f[ϕ]`∥ = ∥`ϕ`∥![Equation](Images/F000278si23.png)。第一个范数在 `H` 中，第二个范数在 `H*` 中，其中‖`ϕ`![Equation](Images/F000278si24.png)‖=inf {`C`> 0 使得 |`ϕ`![Equation](Images/F000278si25.png) (`v`)|< `C`‖`v`‖ 对所有 `v` ∈ `H` 成立}。

回到 RKHS，存在线性求值泛函 `E[x]:H→C`![Equation](Images/F000278si26.png)（或下一节中的 `R`），使得 `E[x](f) = f(x)`![Equation](Images/F000278si27.png) 有界。根据 `RRT`，每个有界线性泛函都由与 `H` 中唯一向量的内积给出；因此对于 `X` 中的每个 `x`，存在 `H` 中唯一的函数 `K[x]`![Equation](Images/F000278si28.png) 使得对所有 `g` ∈ `H`，`g(x) = < g, K[x] >`![Equation](Images/F000278si29.png)。根据 [Putnam (2019)](#Ch019_349-364_B9780443136979000278.xhtml#bib9)，`K[x]`![Equation](Images/F000278si30.png) 被称为点 `x` 处的再生核。`H` 的再生核为 `K`: `X x X→H`，定义为 `K(x,y) = < k[y], k[x] >`![Equation](Images/F000278si31.png)。此外，|`E[x]`|² = < `k[x]`, `k[x]` > = ∥`k[x]`∥² = `K(x,x)`![Equation](Images/F000278si32.png)。因此，复数域上的再生希尔伯特空间 `H` 包含再生核 `K`，具有再生性质，<`K(., x)`, `f`>=`f(x)`，对所有 `x` ∈ `X` 和 `f` ∈ `H` 成立。此外，如果存在再生核，则 `H` 为 RKHS。即线性求值函数 `E[x]`![Equation](Images/F000278si33.png) 有界。这里，`E[x](f) = < K(.,x), f > = f(x)`![Equation](Images/F000278si34.png)，因此根据 CBS 不等式，可得 |`E[x](f)`|![Equation](Images/F000278si35.png) 小于或等于 ∥`K(.,x)`∥∥`f`∥ = < `K(.,x)`, `K(.,x)` >^(1/2)∥`f`∥ = `K(x,x)^(1/2)`![Equation](Images/F000278si36.png)‖`f`‖，因此 `E[x](f)`![Equation](Images/F000278si37.png) 有界且 |`E[x]`|![Equation](Images/F000278si38.png) 小于或等于 `K(x,x)^(1/2)`![Equation](Images/F000278si39.png)。
