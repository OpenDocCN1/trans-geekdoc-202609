
强收敛并不蕴含范数收敛。为说明这一点，令载体集再次为希尔伯特空间，`H`=`l²`。还使用投影算子 `P[*n*]`，它只是将 `l²` 中任意向量 `w` 的前 `n` 个元组替换为零。即，`P[*n*] (w[0], w[1], w[2], …)=(0, 0, … 0, w[*n*], w[*n*+1], …)`。`‖P[*n*] w‖² → 0`, as `n → ∞`![方程](Images/F000242si5.png)，因为 $\\sum\_{k = n}^{\\infty}\\left. w\_{k}^{2}\\rightarrow 0 \\right.$![方程](Images/F000242si6.png)。这表明 `SOT`。在这种情况下，不存在范数收敛。对于任意 `m > n`，考虑 (`P[*n*] − P[*m*]`) (`w[0], w[1], w[2], …`) = (0, 0, … 0, `w[*n*]`, `w[*n*+1]`, … `w[*m*]`, 0, 0, …)。然后，存在 `l²` 中的向量 `u`，使得 (`P[*n*] − P[*m*]`) `u`=`u`。因此，`‖P[*n*] − P[*m*]‖=1`，因此 `P[*n*]` 不是 `CS`，因而它在范数下不收敛。

## 9.2 两个基本的 von Neumann 代数
von Neumann 代数通常记为 `W*` 代数。它是希尔伯特空间上有界算子的星代数，在 `WOT` 下封闭且包含恒等算子。`W*` 代数的两个著名例子是本质有界可测函数环，`L^∞(R)`。它是一个交换的 von Neumann 代数，由在 `L²` 函数的希尔伯特空间上作为逐点乘法的元素组成。第二個例子由维数大于一的希尔伯特空间上的所有有界算子组成。该代数是非交换的。这些的证明可在 [Jones (2010)](#Ch009_165-169_B9780443136979000242.xhtml#bib4) 中找到，另见 [Nelson (2017)](#Ch009_165-169_B9780443136979000242.xhtml#bib3)。仅给出简要说明，以阐释前面提到的第一个结果证明中所需的某些概念。该证明表明该结构是一个 von Neumann 空间。首先，证明中假设了一个 σ 有限测度 (`X, Ω, μ`)。该结构在附录 A.2 中定义。还需要集合 `M=L^∞(R)`，它是 `R` 上本质有界可测函数的赋范向量空间，具有本质上确界范数 `‖f‖[∞]`。该范数等于 inf {`N`，非负 `N`，使得 | `f(x)` | 小于或等于 `N`，除了 `X` 中测度为零的集合 `A` 之外，即 `μ(A)` 为零}。以下是该范数的例子。

## 9.3 von Neumann 代数中的换位子
von Neumann 代数 `A` 由希尔伯特空间中有界算子的酉星子代数组成。因此，`I` 总在 `A` 中，连同 `A` 中任意元素的伴随。von Neumann 代数在弱算子拓扑下封闭。这与 `C*` 代数不同。`C*` 代数在范数拓扑下封闭。换位子 `A’` 也是一个 von Neumann 代数。换位子 `A’` 已在涉及矩阵的前一节中描述并举例说明。这里，`A’={v in B(H), such that v w=w v for all w in A}`。此外，`A` 与 `A’` 的交集 `Z(A)` 是称为 `A` 中心的 von Neumann 代数。每当 `Z(A)=A` 时，`A` 称为阿贝尔。双换位子是 `A’’=(A’)’`。对于希尔伯特空间 `H` 中的有界算子 `T`，双换位子可由生成集 `{T, T*}^(n)`，`n=0, 1, 2,…` 得到。这是 `C*` 代数 `A` 的子集 `S`，包含恒等式 `T⁰=I`。它是包含 `S` 的最小 `C*` 代数，可通过取 `T` 和 `T*` 的标量积、和、积以及积的和得到。有关生成集的例子见第 8.9 节。von Neumann 双对易子定理指出，当 `A` 是 `B(H)` 的子集，且是酉的并且是 `B(H)` 的星子代数时，则 `A` 在 `A″` 中强稠密 ([Dixmier, 1981](#Ch009_165-169_B9780443136979000242.xhtml#bib1))。
