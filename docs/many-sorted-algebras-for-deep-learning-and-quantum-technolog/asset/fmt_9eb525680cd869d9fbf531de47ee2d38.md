
Kernels are defined in terms of sequences in `l²`![Equation](Images/F000163si124.png). Kernel methods form a firm foundation for machine learning involving support vector-type classification. In this type of classification, hyperplanes are utilized usually in binary categorization. These planes are employed in separating two distinct data classes or objects. Indeed, these planes normally do not pass through the origin and are instances of an affine transformation. Such transformations preserve lines and keep parallels parallel. Additionally, they preserve convexity as well as extreme points. They do not preserve distance or angles. In machine learning, they are also useful because they are an automorphism of affine spaces; they preserve dimension and subspaces. The data to be categorized into two groups is first assumed to be linearly separable. This preassumes that there exists a hyperplane that can separate the data into two parts. Soft categorization is given for which the data is nonlinear separable. Soft categorization refers to the fact that data is marginally nonseparable, that is, there are occasional outliers. Also, applications of kernels in regression analysis exist. Here, parameter settings are determined that minimize overfitting or under fitting of the data by regressed curves.

Some combinations of feature maps are also feature maps. In particular, the sum and the product of feature maps is a feature map along with nonnegative scalar products. However, the difference of two feature maps might not be a feature map. These properties are used in the construction described later.

Consider a nonempty set `X`, and a sequence `Φ[1]`![Equation](Images/F000163si125.png), `Φ[2]`![Equation](Images/F000163si126.png), `Φ[3]`…![Equation](Images/F000163si127.png), of `l²`![Equation](Images/F000163si128.png) functions such that `Φ[i]`![Equation](Images/F000163si129.png): `X`→`R`. Then `Φ(x)` = (`Φ[1]Φ[2]Φ[3]…`)![Equation](Images/F000163si130.png) is the feature map, and $K\\left( {x,y} \\right) = \\overset{\\infty}{\\underset{i = 1}{\\sum^{}}}\\Phi\_{i}\\left( x \\right)\\Phi\_{i}\\left( y \\right)$![Equation](Images/F000163si131.png) is a kernel on `X`. This follows using the CBS inequality, that is, $\\left| K\\left( {x,y} \\right) \\middle| = \\middle| \\overset{\\infty}{\\underset{i = 1}{\\sum^{}}}\\Phi\_{i}\\left( x \\right)\\Phi\_{i}\\left( y \\right) \\right|$![Equation](Images/F000163si132.png) is less than or equal to $\\left. \\overset{\\infty}{\\underset{i = 1}{\\sum^{}}} \\middle| \\Phi\_{i}\\left( x \\right)|^{2}\\overset{\\infty}{\\underset{i = 1}{\\sum^{}}} \\middle| \\Phi\_{i}\\left( y \\right)|^{2} \\right.$![Equation](Images/F000163si133.png).

Hyperplane `A` will be described herein in finite real inner product spaces `H` = `R`^(`n`)![Equation](Images/F000163si134.png). These planes will be an affine subset of `H` of degree less than `n`. For `b` in `R`, and for `w` in `H`, `A`={ `v` in `H`, such that <`w`, `v`>+`b`=0}.

### Example 18.10

Let `H` = `R`²![Equation](Images/F000163si135.png), for `b`=2, and `w`=(1 4)′ in `H`, `A` = {`v`=(`v[1]v[2]`)![Equation](Images/F000163si136.png)′ in `H`, such that  < (14)′, (`v[1]v[2]`)′>+2=0}![Equation](Images/F000163si137.png). Accordingly, `A` is the straight affine line: `v[1]` + 4`v[2]` =  − 2![Equation](Images/F000163si138.png).

Support vector machine is supervised learning and needs training data. The kernel trick transforms data to a higher dimension, performs classification, and then transforms back. Points in space have tuples that are called features. The hyperplane partitions `H` into two half planes: `A^+`![Equation](Images/F000163si139.png)\={ `v` in `H`|<`w`, `v`>+`b` greater than or equal to 0} and `A^-`![Equation](Images/F000163si140.png)\={ `v` in `H`|<`w`, `v`>+`b` <0}, thus giving the hyperplane the decision boundary for binary classification. `H` is a metric space because it is an inner product space and therefore it is also a normed vector space. Indeed, the inner product provides a natural metric `d`. The distance between `v` and `w` in `H` is `d(v,w)` =  < `v` − `w`, `v` − `w`\>^(1/2) = ∥`v` − `w`∥![Equation](Images/F000163si141.png). The last quantity is the norm induced by the inner product. For a set of vectors, `X` = {`v[1]`, `v[2]`, …, `v[n]`}![Equation](Images/F000163si142.png) in `H`, the distance from a single point `v[i]`![Equation](Images/F000163si143.png) in this set to the affine classifier `A` is given by | < `w`, `v[i]` >  + `b`|/∥`w`∥![Equation](Images/F000163si144.png). This smallest distance from a vector in `X` to `A` is given by minimizing this expression. Multiplying an affine space by constant, that is, multiplying `w` and `b` by the same constant, does not change the space `A`; actually the two spaces are equivalent. Thus the minimum distance can be found by min (|<`w`,`v[i]`\>+`b`|)![Equation](Images/F000163si145.png) for `i`=1, 2, …, `n`. See Section 2.9, involving affine spaces.

## 18.10 Radial basis function kernel

Radial basis function (RBF) kernel uses, for instance, `v`=(x y)′ in `R`²![Equation](Images/F000163si152.png), and the mapping `ϕ`![Equation](Images/F000163si153.png)(`v`) provides an infinite-dimensional vector `Φ(v)` = (1*x* *y* *x*y* *y*x* *x²*y²*x²*y*y²*x*…)![Equation](Images/F000163si154.png)′. The kernel method avoids calculating `Φ`![Equation](Images/F000163si155.png)(`v`), which produces the single, the double, the triple interactions, etc., between the tuples of `v`. Instead the inner product is performed in `R²`, and then the kernel: `k(v,w)` =  < `Φ(v)`, `Φ(w)` >  = `e`^( − 1/2*∥*`v` − `w`*|*|²)![Equation](Images/F000163si156.png). To show formally that this is an inner product kernel, write `e`^( − 1/2*∥*`v` − `w`*|*|²) = `e`^( − 1/2\[(`v` − `w`)^′(`v` − `w`)\]) = `e`^( − 1/2\[`v`^′`v` − 2`v`^′`w` + `w`^′`w`\]) = `e`^( − 1/2\[`v`^′`v` + `w`^′`w`\])*`e`^(`v`^′`w`)![Equation](Images/F000163si157.png). Let `C` = `e`^( − 1/2\[`v`^′`v` + `w`^′`w`\])![Equation](Images/F000163si158.png). Then `e`^( − 1/2*∥*`v` − `w`*|*|²) = `C`*`e`^(`v`^′`w`) = `C`*`e`^(`v`^′`w` + 1)*`e`^( − 1) = `C′`*`e`^(`v`^′`w` + 1)![Equation](Images/F000163si159.png) where `C′` is a new constant. Thus $e^{- 1/2{\\|{v - w}\\|}^{2}} = \\sum\_{n = 0}^{\\infty}{\\left( {1 + \\left. {v'w} \\right\\}} \\right.^{n}/n!}$![Equation](Images/F000163si160.png) This shows that the RBF kernel makes all nonhomogeneous polynomial kernels. This kernel projects into infinite-dimensional space. It performs an infinite number of interactions between data.
