
如前所述，最简单且最重要的混合态示例是最大线性态，`|v> = 1/2 |0> + 1/2 |1> = 1/2 I`。就布洛赫球而言，前文已指出 `|v>` 位于该球的中心。在此情况下，`r = 0`，因为 `ρ = |v><v| = 1/2 I` 且 `ρ = (I + < r, s>)/2`，见 [示例 5.4](#Ch005_83-101_B9780443136979000084.xhtml#enun4)。

## 5.3 布洛赫球的复数表示

纯量子比特可以用 `C` 中的 `u` 和 `v` 表示为 `|q> = u |0> + v |1>`，其中 `|u|² + |v|² = 1`。该表示有时会代替前几节中给出的更流行的表示而使用：`|q> = (cos (t/2) |0> + e^(i p) sin (t/2) |1>`，`p` 在 `[0, 2π)` 中，且 `t` 在 `[0, π]` 中。这里忽略了整体相位，`ϕ` 在 `[0, 2π)` 中，因此量子比特的完整描述为 `e^(i ϕ) |q>`。在布洛赫球表示中，`e^(i ϕ) |q>` 映射到 `R³` 中球面 `S²` 上的一个点。相位 `ϕ` 在布洛赫球上不出现。该点的坐标由先前描述的球坐标向量给出。现在它进一步用复系数 `u` 和 `v` 描述，

```
\begin{array}{l}
{X = \sin\left( t \right)\cos\left( p \right) = 2{Re}\left( {u \ast v} \right)}
{Y = \sin\left( t \right)\sin\left( p \right) = 2\text{Im}\left( {u \ast v} \right)}
{Z = \cos\left( t \right) = {|u|}^{2} - {|v|}^{2}}
\end{array}
```

![Equation](Images/F000084si32.png)

将 `u` 与 `cos(t/2)` 相对应，将 `v` 与 `e^(i p) sin (t/2)` 相对应，可为 `X`、`Y` 和 `Z` 恒等式提供依据。使用前面给出的 ket 的密度矩阵为 `ρ = |q><q| = (u |0> + v |1>) * (u |0> + v |1>) = |u|² |0><0| + |v|² |1><1| + u* v |0><1| + v* u |1><0|`。因此密度矩阵 `ρ =`

```
\begin{matrix}
{|{|u|}^{2}} & {{u \ast v}|}
{|{v \ast u}} & {{{|v|}^{2}|}.}
\end{matrix}
```

![Equation](Images/F000084si33.png)

该矩阵的非对角项通常称为相干项。利用变换消除这些项的过程称为退相干。

令 `u = x + i y` 且 `v = z + i t`，其中 `x`、`y`、`z` 和 `t` 为实值，则球面 `S³` 定义如下：`x² + y² + z² + t² = 1`。等价地，`S³` 也可以用两个复数来定义，即使用 `u` 和 `v`，其中 `|u|² + |v|² = 1`。这表明单量子比特希尔伯特空间为 `S³`。在此空间中，`e^(i ϕ) |q>` 是参数 `ϕ` 在 `[0, 2π)` 中的圆的方程。布洛赫球与射影空间 `CP¹` 或 `S²` 相对应。

最后，使用外积或投影运算：`|q><q|`，得到纯态密度矩阵的 2×2 矩阵表示，`ρ =`

```
\begin{array}{ll}
{|{\cos^{2}\left( {t/2} \right)}} & {{\sin\left( {t/2} \right)\cos\left( {t/2} \right)e^{- ip}}|}
{|{\sin\left( {t/2} \right)\cos\left( {t/2} \right)e^{ip}}} & {{~\sin^{2}\left( {t/2} \right)}|}
\end{array}
```

![Equation](Images/F000084si36.png)

布洛赫矢量可以写成密度矩阵；也就是说，`ρ` 也可以再次用球坐标表示为 `2 ρ =`

```
\begin{matrix}
{|{ 1 + Z}} & {{X - {iY}}|}
{|{X + {iY}}} & {{{1 - Z}|}.}
\end{matrix}
```

![Equation](Images/F000084si37.png)

如前所述，证明归结为代入。例如，对于矩阵项 `ρ`，使用 `Z = cos(t)`，`1 + Z = 1 + cos(t) = cos² (t/2)/2`。

## 5.4 内导数、外导数和李导数

本节是 [第 4.6 节](#Ch004_57-81_B9780443136979000011.xhtml#s0035) 的延续。本节的主要内容是对李导数的描述。然而，首先将回顾内导数。之前未提及，内导数始终相对于向量场 `X` 指定。对于任意 `n` 形式 `w`，`n > 0`，`(l[X] w) (X2, X3, … Xn) = w(X, X2, … Xn)`。该运算作用于向量场序列 `X2, X3, … Xn`。这与内积相同。结果是一个 `n−1` 形式。对于函数，即零形式，内导数为零。

### 示例 5.10

设 `w` 为 `R²` 对偶空间上的二形式，其中 `w = e¹ ∧ e²`，且设 `X = e[2]`。内积 `(l[X] w) (v) = w (X, v) = (e¹ ∧ e²) (e[2], v) = e¹ (e[2]) e² (v) − e¹ (v) e² (e[2]) = 0 − e¹ (v) 1 = − e¹ (v)`。因此注意到将内导数应用于二形式的结果是一个一形式。

注意，外积，即前一章中描述的楔积，[第 4.6 节](#Ch004_57-81_B9780443136979000011.xhtml#s0035)，与外导数不同，外导数只是 `d` 运算。`n` 形式 `w` 的外导数 `d` 使次数增加一。对于次数分别为 `n` 和 `m` 的二形式 `v` 和 `u`，`w = v ∧ u` 的外导数为 `d w = (d v) ∧ u + (−1)^n v ∧ d(u)`。然而，内导数与外导数之间存在密切关系，下文将描述该关系。

外导数与内导数之间的对偶性由 Cartan 魔法公式 `L[X] w` 给出，其中 `L[X] w = d(l[X] w) + l[X] d w`（[Zubelevich, 2012](#Ch005_83-101_B9780443136979000084.xhtml#bib11)）。在该公式中，`X` 是向量场，`l[X]` 是内导数，`L[X]` 是李导数，`d` 是外导数。最后，对于 `w`，一个 `n` 形式，Cartan 公式可写为 `L[X] w = {d, l[X]} w`。括号 `{A, B}` 是泊松括号。回忆这些括号满足 `{A, B} = A B + B A`。该魔法公式通常用作微分形式空间上李导数 `L[X] w` 的定义。

对于向量场 `X` 上的函数 `f`，李导数是方向导数，`L[X] f = d f · X = X [f]`。沿 `X` 的向量场 `Y` 的李导数满足 `L[Y] X = [X, Y]`，因为 `[X, Y][f] = X [Y [f]] - Y [X [f]]`。此外，它是外导数与 `X` 的收缩，即 `L[X] w = I[X] d w + d(I[X] w)`，这再次是 Cartan 公式。注意李导数也满足莱布尼茨法则：对于 `w = v ∧ u` 且 `X` 为向量场，`L[X] w = (L[X] v) ∧ u + v ∧ (L[X] u)`。
