
一般而言，未来数据与训练数据集相关但有所区别。训练集始终存在；然而，其使用程度可概括为监督学习与无监督学习。监督学习利用训练数据来改进和确定训练算法中的参数。监督学习的一个常见属性是数据附带标签。这些标签通常根据预定特征对数据进行划分。利用监督学习的机器学习两大主要方法是神经网络和支持向量机。它们既用于检测也用于估计。支持向量机在 `Section 1.10` 中被提及，其中给出了核函数的介绍。这些机器将在后面的章节中详细介绍。神经网络通常被称为深度学习机器，是本章的主要主题。卷积神经网络（`CNNs`）也在本章中简要介绍。它们将在后面的章节中结合成像技术进行描述和说明。其他类型的神经网络也存在。特别是，后面的一节中将举例说明几种类型的循环神经网络（`RNNs`）。

无监督学习是一种算法自主地从数据中确定结构的技术。机器学习中这类技术众多。无监督学习始终采用领域知识和大量启发式参数设置。它们范围从诸如 `k-means` 或 `k-median` 技术等聚类的初级方法，到其他计算密集型的源编码特征值方法。特征值公式中包括主成分变换（`PCT`）和奇异值分解（`SVD`）。这些技术以及量子版本也是后面章节的主题。稍后将使用 `k-means` 举例说明无监督学习的一个简单过程。用于数据挖掘目的的该算法的量子版本将在后面的章节中给出（[Kavitha 和 Kaulgud, 2022](#Ch002_21-40_B9780443136979000266.xhtml#bib1111)）。

`k-means` 方法是一种聚类技术。当应用于 `R^n` 中有限有序集合 `X` 的向量时，该过程形成 `X` 的一个划分。`k-medians` 方法几乎相同，其中采用数据的中值而不是均值或平均值。划分中子集的数量 `m`，`m>0`，是一个启发式参数，由领域知识决定且必须事先指定。每个有序子集 `S[i]`，`i=1, 2, …, m`，非空且包含一个子集领导者 `L[i]`。该值是子集中所有点的平均值。值 `L[i]` 本身通常不是 `S[i]` 中的元素。为开始该过程，在采用初始条件后计算此平均值。这些初始条件涉及初步猜测，以确定 `X` 的哪些元素是构成划分的子集的成员。

在此之后，递归步骤开始。

递归步骤首先为每个子集计算实际的平均值。具体而言，为每个子集 `S[i]` 找到均值 `L[i]`。请注意，每个 `L[i]` 通常是一个具有 n 个元组的向量，因为平均值是在每个元组中求得并记录的。然后在所有元素 `X` 与每个子集领导者 `L[i]` 之间找到一范数距离 `d[i]`。因此，对于 `X` 中每个定位的向量 `v`，对每个 `i=1, 2, …, m` 执行距离计算 `‖v−L[i]‖`。该计算也对 `X` 中的每个 `v` 执行，`v=(v[1] v[2] … v[n])′`，`‖v−L[i]‖[1]=|v[1]−L[i1]|+|v[2]−L[i2]|+ …+|v[n]−L[in]|`。该计算得到的值按向量位置输入到 `d[i]` 中。每个 `d[i]` 具有相同数量的条目，即 `X` 的基数。在一范数计算之后，对所有距离向量 `d[i]` 执行逐元组比较。找到最小距离的位置，并据此使用 `X` 中的元素和相同的值 `m` 执行聚类或重新分组。每个可能的新子集是通过使用最接近子集领导者的元素创建的。这些步骤反复进行，直到采用停止条件。停止条件是在执行完整递归步骤后划分不再发生变化时。

### 示例 2.1

例如，`X` 是 `R¹` 的一个子集，其中 `X=(1, 2, 3, 4, 7, 8, 9)`。该集合以这种方式书写，因为数据可以重复。为了开始，设 `m=2`，即只有两个集合构成划分。初始猜测的划分是 `S[1]=(1, 2, 3)`，且 `T[1]=(4, 7, 8, 9)`。下一步迭代开始时，计算这些预定分组的平均值作为子集领导者。这些值是实标量，因为集合 `X` 由实值元素组成。这些平均值分别为 `L[S[1]] = 2`，![方程](Images/F000266si1.png) 和 `L[T[1]] = 7`。![方程](Images/F000266si2.png) 接下来，必须找到 `X` 中每个点到两个子集领导者的 1 范数距离。在此情况下，1 范数就是绝对值。这些距离以有序元组给出 `d[S[1]] = (1,0,1,2,5,6,7)`，![方程](Images/F000266si3.png) 和 `d[T[1]] = (6,5,4,3,0,1,2)`。![方程](Images/F000266si4.png) 请注意，这与 `X` 中的数据顺序完全相同。执行逐元组比较以找到最小值，比较对象为 `d[S[1]]`![方程](Images/F000266si5.png) 和 `d[T[1]]`![方程](Images/F000266si6.png)。因此，首先，由于 `d[S[1]]`![方程](Images/F000266si7.png) 中的数字 1 小于 `d[T[1]]`![方程](Images/F000266si8.png) 中的数字 6，聚类 `S[1]` 将采用第一个元素。

此外，`d[S[1]]`![方程](Images/F000266si9.png) 的第 2、第 3 和第 4 个元组也是最小的。然而，`d[T[1]]`![方程](Images/F000266si10.png) 中的其他元组是最小的。现在利用这些信息，重新聚类开始，通过仍使用 `m=2` 创建新的划分。将最接近子集领导者的点分配到一个聚类中。新的划分是 `S[2]=(1, 2, 3, 4)` 和 `T[2]=(7, 8, 9)`，可以看出，这种新的聚类与之前的划分不同。

因此，必须执行该过程的另一个递归步骤。所以再次，对应的领导者，即平均值，这次是 `L[S[2]] = 2.5`，![方程](Images/F000266si11.png) 和 `L[T[2]] = 8`。![方程](Images/F000266si12.png) 接下来，再次计算 `X` 中所有点到每个子集领导者的距离。结果为 `d[S[2]] = (1.5,.5,.5,1.5,2.5,3.5,4.5)`，![方程](Images/F000266si13.png) 和 `d[T[2]] = (7,6,5,4,1,0,1)`。![方程](Images/F000266si14.png) 逐元组比较与之前类似执行；这次比较 `d[S[2]]`![方程](Images/F000266si15.png) 和 `d[T[2]]`![方程](Images/F000266si16.png)。这里可以看到，`d[S[2]]`![方程](Images/F000266si17.png) 的第 1、第 2、第 3 和第 4 个元组是最小的，但 `d[T[2]]`![方程](Images/F000266si18.png) 中的其他元组是最小的。重新聚类在这种情况下给出相同的划分。因此，由于 `S[3]=S[2]=(1, 2, 3, 4)` 且 `T[3]=T[2]=(7, 8, 9)`，采用停止条件。结果是 k-mean 划分。
