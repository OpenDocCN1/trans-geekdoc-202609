
接下来给出的记号是对类型 `VECTOR` 的重新命名。当使用张量代替 `VECTOR` 时，所有 `p + q` 元张量的集合的更常见名称由一个非常长的表示给出，它是 `V ⊗ V ⊗ … ⊗ V x V* ⊗ V* ⊗….⊗ V*`。无论如何，该类型的相应载体集合为 `{T|T is a (p, q) tensor, and it is also a multilinear form}`。上述集合的名称现在将因其长度而缩写为 `Y` 表示。在集合的名称 `Y` 中，有 `p` 个 `V` 的拷贝和 `q` 个 `V*` 的拷贝。使用此记号 `Y` 的思想是 `V*` 的 `p` 个元素应用于 `V` 的 `p` 个元素。此外，`V` 的 `q` 个元素应用于 `V*` 的 `q` 个元素，从而得到一个复数。再次，这意味着当使用载体集合时，实际映射到标量域为 `T: V* x V* x … x V* x V x V x….x V. → C`。记号上的差异在 `MSA` 中使用，以强调使用 `x` 表示张量积名称，而 `⊗`![方程](`Images/F000011si125.png`) 作为实际运算。

如果该张量集合配备逐点加法，`(+)`，和标量乘法，`(.)`，则该集合在复数域上成为一个向量空间。复数域的所有算符名称和方程恒等式保持不变。然而，在此 `MSA` 对向量空间结构的描述中需要一个额外的签名集合。新的签名集合具有元数为 1 的元素并命名为 `TEN`，对应于实际的多线性算符 `T`，表示一个张量。向量空间结构签名集合中的所有其他元素仍然成立，其中一些名称定义得更具启发性。相关的签名集合的元素如下给出。在下面：`T-ADD` 表示张量加法；`ST-MULT` 表示张量与标量的乘法；`TEN` 表示张量乘法。

### 示例 4.13

在有限维向量空间中，可知 `V10` 是所有向量的向量空间，即 `V10=V`。这源于 `V` 与 `V**` 之间的同构。也就是说，该空间由从 `V*` 到 `C` 的所有线性映射组成，因此它是 `V`。向量空间 `V11={T11: V* x V → C}=End (V*)`。实际的张量为 `T11={v ⊗`![方程](`Images/F000011si130.png`) `f, such that v is in V and f is in V*}`。

表达式 `End (V*)` 是 `V*` 上的自同态集合。在有限维向量空间中，也成立 `End (V*)=End (V)′`，其中撇号表示自同态代数在转置方面相同。因此，`V` 中的列向量对应于 `V*` 中的行向量。对于矩阵算符 `M` 和 `N`，注意数量 `(M N)*=N* M*`。另外如果 `M: V → C`，使得 `M v=w`，则 `v′ M′=w′` 因此 `M′: V* → C`。

### 示例 4.14

平衡为 `(0, 2)` 的张量 `f` 和 `g` 的例子通常被视为内积。对于 `V*` 中的 `f` 和 `g`，`f ⊗`![方程](`Images/F000011si131.png`) `g: V x V → C`。因此对于 `V` 中的 `v` 和 `w`，`f ⊗`![方程](`Images/F000011si132.png`) `g (v, w)=f(v)·g (w)`。后者乘积类似于点积。此外，该乘积不必是正定的。

此外，该张量是度量张量，它定义在流形或曲面上。它使得可以在这些结构上定义距离和角度。([Lee, 1997](#Ch004_57-81_B9780443136979000011.xhtml#bib5))。度量张量具有如下性质：

1. 1) 对称：`g (u, v)=g (v, u)`。
2. 2) 正半定：`g (u, u)> 0` 且 `g (u, u)=0` 当且仅当 `u=0`。

度量张量是在切空间流形上定义的一类张量。这些张量形成一个张量丛。

具有平衡 `(0, N)` 且向量空间维数为 `N` 的张量被称为 `N` 形式。它也称为顶形式、体积形式或行列式。这在下一节中描述。

## 4.8 行列式

行列式定义为 `N` 维向量空间上的自同态([Lang, 2002](#Ch004_57-81_B9780443136979000011.xhtml#bib4))。为了得到行列式，需要一个顶形式，下面定义它。首先，`n` 形式 `f` 是 `T0N` 张量且全反对称。这里，`n` 是整数且在 `[0, N]` 中。如果 `n=0`，则得到 `T00` 张量，即标量。否则，对于元素 `vi` 和 `vj` 的任意换位，`f (v1, v2, …, vn)` 的符号（正或负）发生变化。对于偶数次换位，用加 1 乘以 `f`；否则使用 −1。如果考虑 `k> N` 的 `k` 形式，它们为零。因此非平凡的 `k` 形式存在于 `k` 小于或等于 `N` 时。当 `k=N` 时，得到顶次形式。

顶形式是 `T0n` 形式，其中 `n=N`。当此条件成立时，存在非零的 `f` 和 `g`，两者均为顶形式；则存在标量 `c` 使得 `g=c f`。这成为一个等价类。选择这样一个顶形式 `f` 称为 `V0N` 上的体积。具有选定顶形式的向量空间称为具有体积的向量空间。当 `v1, v2, …, vN` 是 `V0N` 中的 `N` 个向量时，据定义，这些向量张成的体积为 `vol (v1, …, vN)=f (v1, …, vN)`。

行列式取自同态 `A` 并得到一个标量。它利用 `V0N` 的基底，例如 `e1, e2, … eN`，以及 `V0N` 上的某个体积形式 `f`。它定义为 `det A=f (A (e1), A (e2), …, A (eN))/ f (e1, e2, …, eN)`。([Lee, 1997](#Ch004_57-81_B9780443136979000011.xhtml#bib5); [Sakai, 1995](#Ch004_57-81_B9780443136979000011.xhtml#bib7))

考虑自同态 `A: C² → C²`，使用对角矩阵 `D` 定义，主对角线上有一个非零标量 `c`，随后为 1。所以 `D=`

```
$|\\begin{matrix} c & 0 \\\\ \\end{matrix}|$
```


因此，这是一个向量空间自同态。行列式提供在基底变化下不变的结果。在这种情况下，对于酉矩阵 `U`，当它被使用且满足 `U U*=U*U=I` 时，`D` 的行列式为 `c=det(U D U*)`。
