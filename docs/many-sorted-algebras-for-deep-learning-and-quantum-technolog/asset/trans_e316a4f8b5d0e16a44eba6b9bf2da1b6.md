`Sn` 的不可约表示与 Young 图之间存在一一对应。Young 图能够简单地识别不可约表示的乘积。为了更好地用这些图识别表示，使用了 Young 表。这是一个 Young 图，其 `n` 个格子唯一地填入整数 1, 2, …, `n`。对于这样的表，存在 `n!` 种编号格子的方法。当编号按行从左到右递增，继续到下一行时，这称为正规表。当数字在行或列中仅递增时，这称为标准 Young 表。标准 Young 表由使用置换的正规表得到。

## 泛函分析中的基本定理

下面提供了泛函分析的基本定理列表。连同这些定理，还有与定理本身相关的几个定义（[Apostle, 1974](#AppendixF_383-385_B9780443136979000229.xhtml#bib6)；[Narici & Beckenstein, 2011](#AppendixF_383-385_B9780443136979000229.xhtml#bib8)；[Rudin, 1973](#AppendixF_383-385_B9780443136979000229.xhtml#bib9)）。

### 魏尔斯特拉斯逼近定理

任何定义在 `R` 的紧区间 [`a`, `b`] 上的连续函数 `f`，都可以用多项式 `p` 在任意 *ϵ*![方程](Images/F000229si1.png)，*ϵ*![方程](Images/F000229si2.png)>0 的范围内一致逼近。一致逼近意味着 `sup[x] | f(x) - p(x) | < ϵ`![方程](Images/F000229si3.png)。使用 Bernstein 多项式可以在 [Achieser (1956)](#AppendixF_383-385_B9780443136979000229.xhtml#bib1) 和 [Narici (2004)](#AppendixF_383-385_B9780443136979000229.xhtml#bib3) 中找到一个最优雅的证明。

### 斯通-魏尔斯特拉斯定理

设 `X` 为局部紧 Hausdorff 空间，且 `A` 为 Banach 代数 `C[0](X)` 的子代数，具有上确界范数。这里，`C[0](X)` 由 `X` 上的连续实值函数 `f(x)` 组成，当 | `x` | → ∞![方程](Images/F000229si4.png) 时趋于零。然后如果它分离点且处处不消失，则 `A` 在 `C[0]` 中稠密。

函数集 `S` 的 `f: A → B` 在 `A` 中被称为分离点，当且仅当 `S` 中存在至少一个函数 `h` 是单射，即它是 1–1。对所有 `x`、`y` 在 `A` 中，`x` 不同于 `y`，这意味着 `h(x)` 不同于 `h(y)`。函数集被称为处处不消失或在 `A` 的任意点都不消失，这意味着对于 `A` 的每一点 `x`，都存在 `S` 中的函数 `f` 使得 `f(x)` 非零。

## 例 F.1

函数集：`S[1]`={ `f(x)=1`, `g(x)=x²` } 在定义域 `A`=[-2, 2] 上不分离点，因为在 `x`=1 和 `x`=-1 时，`f=g`。然而，`S[2]`={ `f(x)=1`, `g(x)=x²`, `h(x)=x` } 确实分离 `A` 中的点，因为 `S[2]` 包含一个函数 `h`，它在 `A` 上是 1–1。

## 例 F.2

函数集：`S[1]`={ `f(x)=1`, `g(x)=x²` } 在定义域 `A`=[-2, 2] 上确实处处不消失。然而，`S[3]`={ `g(x)=x²`, `h(x)=x` } 在此定义域上不处处不消失，因为在零点该集合中没有函数是非零的。

### 斯通-魏尔斯特拉斯定理

对于任意紧集 `K`，设 `A` 为连续函数 `f: K → C` 的可能非么、结合自伴代数，它在 `K` 中分离点。如果此外 `A` 在 `K` 的任意点都不消失，或 `A` 是么，则 `A` 在 `C(K)` 中关于一致范数稠密。

### 阿泽拉-阿斯科利定理

设 `{f[n]}`，`n`=0, 1, 2, … 为 `R` 中紧集 [`a`, `b`] 上的实值函数序列。如果该序列既一致有界又等度连续，则存在子序列 `{f[n[k]]}`![方程](Images/F000229si5.png)，它在 [`a`, `b`] 上一致收敛。当 `{f[n]}` 的每个子序列都在 [`a`, `b`] 上一致收敛时，则 `{f[n]}` 既一致有界又等度连续。

当存在常数 `M`>0，使得对于 [`a`, `b`] 中的所有 `x` 和所有非负整数 `n`，满足 | `f[n]` | < `M`，则连续函数序列 `f[n]` 称为一致有界。

序列 `{f[n]}` 在 `ϵ`![方程](Images/F000229si6.png) > 0 时，对所有 `x` 和 `y` 在 [`a`, `b`] 中，以及非负 `n`，存在 `δ`![方程](Images/F000229si7.png)>0，使得如果 | `x−y` | < `δ`![方程](Images/F000229si8.png)，则 | `f[n](x)−f[n](y)` | < `ϵ`![方程](Images/F000229si9.png) 时，称为一致等度连续。

### 哈恩-巴拿赫定理

设 `f` 为赋范向量空间 `X` 的向量子空间 `M` 上的连续线性泛函。在这种情况下，`f` 具有到整个 `X` 的连续线性扩张 `F`，而且 `|| f ||`=`|| F ||`。在 [Narici (2004)](#AppendixF_383-385_B9780443136979000229.xhtml#bib3) 的研究中出现了出色的历史记述。

### 开映射定理

对于满、连续、线性算子 `T`，`T: A—->B`，其中 `A` 和 `B` 为 Banach 空间；则 `T` 是开映射。因此，对于 `A` 中的任意开集 `U`，`T(U)` 是 `B` 中的开集。

### 一致有界性原理

设 `B(X,Y)` 为从 Banach 空间 `X` 到赋范向量空间 `Y` 的所有有界算子的空间，并设 `F` 为 `B(X,Y)` 的子集。如果 `sup[TinF]||T(x)|| < ∞`![方程](Images/F000229si10.png) 对所有 `x` 在 `X` 中成立，则令 `c`= `sup[TinF]||T(x)||` 当 `|| x ||`=1 时，可得 `c`= `sup[TinF]|| T ||`。

### 有界逆定理

对于 `X` 和 `Y` 为 Banach 空间，如果 `T: X → Y` 有界且可逆，则 `T^(-1)` 也是有界的。

### 巴雷尔纲定理

拓扑空间 `T` 的子集 `S` 是第二纲的，如果 `S` 不能写成 `T` 中无处稠密集的可数并。这意味着并集中的至少一个集合的闭包具有非空内部。

### 巴拿赫-斯坦豪斯定理

设 `X` 和 `Y` 均为拓扑向量空间，且 `Γ`={ `T[a]` }`ainR`，其中 `T[a]` 是从 `X` 到 `Y` 的连续线性映射。设 `B` 表示 `X` 中所有轨道 `Γ(x)`={ `T[a](x)`，使得 `T[a]` 在 `Γ` 中 } 在 `Y` 中有界的点 `x` 的集合。如果 `B` 在 `X` 中是第二纲的，则 `B`= `X`，且函数集合 `Γ`![方程](Images/F000229si11.png) 是等度连续的。由 [Stover (2023)](#AppendixF_383-385_B9780443136979000229.xhtml#bib7) 提供了出色的阐述。

### 闭图定理

对于线性算子 `T`，`T: A → B`，其中 `A` 和 `B` 为 Banach 空间，则 `T` 有界当且仅当 `T` 的图是闭的。等价地，当给定 `v[n] → v`，全部在 `A` 中，且也给定 `T v[n] → w`，全部在 `B` 中，如果 `Tv=w`，则 `T` 有界。

笛卡尔积 `A×B` 称为乘积空间。它具有乘积拓扑，也称为 Tychonoff 拓扑或最粗拓扑。它是使用连续投影 `p[a]` 和 `p[b]` 时包含最少开集的拓扑，其中 `p[a]: A×B → A` 且 `p[b]: A×B → B`。
