## 18.4 回归

Ridge 回归是一种最小二乘技术，主要用于变量被认为高度相关时。 在这种情况下，当使用 Ridge 回归而不是通常的最小二乘时，方差或最小二乘误差有时会更小。 在超定系统的通常线性最小二乘回归中，伪逆提供了解。 见 [第 14.3 节](#Ch014_255-270_B978044313697900028X.xhtml#s0020)，14.4，其中描述了偏等距。 在此方法中，观测到的 `k·1` 向量 `y` 被投影到 `k·n` 设计矩阵 `H` 上，其中 `k> n` 或 `k=n`，且为满秩。 期望形式为 `x = B y` 的估计量，其中模型方程为 `y = H x + u`，而 `u` 是由噪声或松弛变量组成的向量。 此外，假设对向量 `u` 一无所知，只是它被用来使方程自洽。 通过投影方法，或通过对最小二乘损失求微分，估计量为伪逆：`x = (H′H)^(−1) H′ y`。 撇号表示转置运算。 如果已知 `u` 的更多信息，可以采用更好的估计量。

当 `H` 的列相关时，由于多重共线性，逆可能不准确，这会影响矩阵 `H′H` 的条件数。 在这种情况下，通常使用 Ridge 回归。 它也是一个线性估计量； 这里：`x = (H′H + λ I)^(−1) H′ y`。

值 `λ > 0` 通常很小； 它是启发式确定的。 此外，单位矩阵 `I` 为 `n·n`。 一个简单的例子用于说明该技术。

## 18.5 K-最近邻分类

机器学习最基础的例子之一是 `KNN`，类似于第 2.1 节中描述的 `K-means` 方法。 `KNN` 也是分类和聚类的技术。 它通常用作批学习的例子。 该方法涉及设置和实现阶段。 为了使用 `KNN`，必须存在整数 `N > 0` 的元组对 `(x[i], y[i])`，并且目标是在观察 `x` 值数据集时实时估计 `y[i]`。 该数据集是预训练的，其标签 `y` 假定为分类且二值，取值为 `{0, 1}`。 值 `K = 1, 2, …, N` 事先选择。 它指的是数据集中用于对查询或测试值 `x` 的距离做出决策的点的数量。 距离函数也必须在实现前选择。 应选择一种范数，并且在随后的示例中将使用一范数距离。

该方法是计算所有 `N` 个点 `x[i]` 到 `x` 的距离。 然后按距离升序对这些距离以及相应的元组值进行排序。 接下来选择前 `K` 个条目。 分类是通过使用 `K` 个条目的标签的众数值来执行的。 该方法的一些实际方面如下。 通常 `K` 取为奇整数。 而且它通常远小于 `N`。 另外，通常会使用多个 `K` 值，并尝试找到最佳 `K`。 这里，度量可能涉及成功分类的条目数作为 `K` 的函数。 对于由两个元组组成的小问题，将未知测试点置于图的原点，数据集的元素在其周围，这很有用，可以制作可视化图。 这在 [图 18.3](#Ch018_327-348_B9780443136979000163.xhtml#f0020) 中有所说明。
