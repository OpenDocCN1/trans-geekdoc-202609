
零的基态可利用梯子算符在算符 `a` 和 `a†` ![Equation](Images/F000291si32.png) 互为伴随这一事实下进行代数解释。 这里，对于湮灭操作的能量，特征态只能降低到零，且永远不会小于此值。 要看到最小本征数为零，考虑 `N` = `a†a` ![Equation](Images/F000291si33.png)，且 `N phi[n] = n phi[n]`。 则 `<phi[n]|N phi[n]> = <phi[n]|a†` ![Equation](Images/F000291si34.png) `a phi[n]> = <a phi[n]|a phi[n]> = , ||a|phi[n]>||²`，它是非负的，且当且仅当 `a |phi[n]> = 0` 时等于零，因此对于 `n = 0`，再次证明 `a |phi[0]> = 0`。

含 `n` 个玻色子的基本 Fock 态由产生操作的循环性质给出：(`a†`)^(`n`) |0> ![Equation](Images/F000291si35.png)，其中 `n` 为正整数。 这些 Fock 态通常不包含关于相位的任何信息。 然而，玻色相干态 `v` 本质上是一个高斯波包。 它是一种特殊的玻色态，涉及湮灭算符 `a`。 具体来说，它是 `a` 的本征态。 因此，`a v = r v`，其中 `r` 是本征值，且由于 `v` 是一个态；假定 `||v|| = 1`。 相干态具有与经典振荡轨迹相似的动力学，并与量子谐振荡相关 ([Gazeau, 2009](#Ch015_271-288_B9780443136979000291.xhtml#bib4))。

相干态由涉及占据数的无限求和给出。 它定义为 $v = e^{- {1/2}{|r|}^{2}}\\sum\_{n = 0}^{\\infty}{{{r^{n}/{({n!}^{1/2})}}|}n > ,}$ ![Equation](Images/F000291si36.png)，其中 |n> 是数算符。 为此，令 `v = the sum`，$\\sum\_{n = 0}^{\\infty}{{{cn}|}n >}$ ![Equation](Images/F000291si37.png)，其中 `cn` 为复标量。 然后对 `v` 使用湮灭操作，`a v = the sum`，$\\sum\_{n = 1}^{\\infty}{{{{cn} a}|}n > =}$ ![Equation](Images/F000291si38.png) 求和，$\\sum\_{n = 1}^{\\infty}{{{{cn} n^{1/2}}|}n - 1 > =}$ ![Equation](Images/F000291si39.png) 求和，$\\sum\_{n = 0}^{\\infty}{{{c\\left( {n + 1} \\right)\\left( {n + 1} \\right)^{1/2}}|}n >}$ ![Equation](Images/F000291si40.png)。 使用上文对 `v` 的定义，将 `r v` 设等于求和，$\\sum\_{n = 0}^{\\infty}{{{{cn} r}|}n >}$ ![Equation](Images/F000291si41.png)。 用 bra 数算符 `<n |` 对这两个量形成内积。 然后使用正交性条件 `<n, n′> = 0`，除非 `n = n′`；在这种情况下，结果为一。 由此可得 `c(n+1) (n+1)^(1/2) = cn r` 或 `c(n+1) = cn r / (n+1)^(1/2)`。 对该差分方程采用逐次代入可得 `cn = c(n−1) r / n^(1/2)`，于是 `c(n−1) = c(n−2) r / (n−1)^(1/2)`；代入得 `cn = c(n−2) r² / (n (n−1))^(1/2) = c(n−3) r³ / (n (n−1) (n−2))^(1/2) = … = co r^(n) / n!^(1/2)`。 因此，`v = the sum`，$\\sum\_{n = 0}^{\\infty}{{{cn}|}n >} =$ ![Equation](Images/F000291si43.png) 求和，$\\sum\_{n = 0}^{\\infty}{\\left( {{{{co} r^{n}}/{n!}^{1/2}}|} \\right.n >}$ ![Equation](Images/F000291si44.png)。 由于 `||v|| = 1`，则 `<v, v> = 1`。 形成此内积得到 `v = the sum`，$\\sum\_{n = 0}^{\\infty}{({{{|{co}|}^{2}{|r|}^{2n}}/{n!}})}$ ![Equation](Images/F000291si45.png)；这是因为当 `n, n′` 不同时 `<n, n′> = 0`。 因此，`⟨v, v⟩ = |co|² e^(|r|²)` ![Equation](Images/F000291si46.png)。 将该量设为一得到 `|co|² = e^(−|r|²), or co = e^(−1/2|r|²)` ![Equation](Images/F000291si47.png)。 这表明相干态 `v = e^{- {1/2}{|r|}^{2}}\\sum\_{n = 0}^{\\infty}{r^{n}/{\\left( {n!}^{1/2} \\right){|{n >}}}}$ ![Equation](Images/F000291si48.png)。

考虑两个相干态 `v` 和 `w`，其中 `v` 由上述表达式给出，而 `w` 以与 `v` 相同的方式给出，例如，`w = e^(−1/2|s|²)` ![Equation](Images/F000291si49.png) $\\sum\_{n' = 0}^{\\infty}{\\left( {s^{n'}/\\left( {n'!}^{1/2} \\right)} \\right){|{n' >}}}$ ![Equation](Images/F000291si50.png)。 则 `⟨w, v⟩ = e^(−1/2|r|²) e^(−1/2|s|²) e^(r s*)` ![Equation](Images/F000291si51.png)。 该表达式通过将 `w` 和 `v` 代入内积得到。 然后，唯一需要证明的项是 `e^(r s*)` ![Equation](Images/F000291si52.png)，因为其他项是标量。 最后一项由 `w` 和 `v` 的泰勒级数展开得出。 然后注意到 `<n′, n> = 0`，除非 `n′ = n`，此时为一。 这将双重求和化为单重求和。 在这种情况下，展开式变为求和，$\\sum\_{n = 0}^{\\infty}{\\left( {r s \\ast} \\right)^{n}/{n!}}$ ![Equation](Images/F000291si53.png)，最终形式上由 `e^(r s*)` ![Equation](Images/F000291si54.png) 给出。 出现特殊情况：对于 `r = s`，则 `<w, v> = 1`。 另外，对于 `r = −s`，则 `⟨−w, v⟩ = e^(−2|r|²)` ![Equation](Images/F000291si55.png)。 对于更大的 `|r|`，`v` 和 `w` 变得接近正交。

现在，将求出伴随算符差分方程的解。 回想 `a† |n − 1> / n^(1/2) = |n>` ![Equation](Images/F000291si56.png)，并且从真空态可以找到任意占据数的解并不令人惊讶。 因此，`|n> = a^(† n) / n!^(1/2) |0>` ![Equation](Images/F000291si57.png)。 为此，如前所述，迭代 `a† |n − 2> / (n−1)^(1/2) = |n − 1>` ![Equation](Images/F000291si58.png)；然后将 `|n−1>` 代入方程 `a† |n − 1> / n^(1/2) = |n>` ![Equation](Images/F000291si59.png)，得到 `a^(† 2) |n − 2> / (n (n−1)^(1/2))` ![Equation](Images/F000291si60.png)。 继续迭代和代入可通过归纳法得到所需结果。

## 15.3 The fermionic Fock space and the fermionic ladder operators

## 15.3 费米子 Fock 空间和费米子梯子算符

在费米子 Fock 空间的情况下，占据数是平凡的，因为 `N` 只能为零或一。 要么在给定态中存在粒子，要么不存在。 占据算符在费米子 Fock 空间中是一个二元函数。 费米子 Fock 空间中的梯子算符 `a†` ![Equation](Images/F000291si61.png) 和 `a` 与玻色子 Fock 空间中的类似。 直观上，如前所述，产生算符 `a†` ![Equation](Images/F000291si62.png) 向一个态添加一个粒子，但在该空间中该态必须为空。 湮灭算符从一个态中移除一个粒子，前提是存在一个待湮灭的粒子。 这也在 [图 15.1B](#Ch015_271-288_B9780443136979000291.xhtml#f0010) 中有所说明。 提供费米子 Fock 空间代数的反交换关系由泊松括号给出：`{ai, aj} = ai aj + aj ai = 0`，对所有态 `i` 和 `j` 成立，此外 `{a_i†, a_j†} = 0` ![Equation](Images/F000291si63.png)，最后，`{a_i, a_j†} = 0` ![Equation](Images/F000291si64.png)，除非 `i = j` 时等于一。 作为前两个恒等式的推论，可得 `a a = a† a† = 0` ![Equation](Images/F000291si65.png)。 与玻色情况一样，数算符由 `N = a† a` ![Equation](Images/F000291si66.png) 给出。 然而，由于 `{a a† + a† a} = 1` ![Equation](Images/F000291si67.png)，则 `a a† = 1 − N` ![Equation](Images/F000291si68.png)。 由此，`N (1 − N) = a† a a a† = 0` ![Equation](Images/F000291si69.png)。 因此 `N` 的本征值要么为零要么为一。 这证实了泡利原理，即占据数为零或一。 可以看出，`N` 的本征态为 `a†` ![Equation](Images/F000291si70.png) `|0>` 和 `a |1>`，其对应本征值分别为 1 和 0。 这些结果源于 `(1 − N) a† |0> = a a† a† |0> = 0`，以及 `N a |1> = a† a a |1> = 0`。
