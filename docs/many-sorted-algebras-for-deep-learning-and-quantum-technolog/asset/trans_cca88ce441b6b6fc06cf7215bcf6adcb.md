
对于任意 `C*` 代数，若 `T` 是自伴的，则谱半径 `r(T)` = lim [`n` → ∞] ‖`T`^(2^( `n` ))‖^(2^(− `n` )) ![方程](Images/F000059si41.png)。 这可由自伴性质推出，‖`T`²‖=‖`T* T`‖=‖`T`‖²。 然后通过数学归纳法，对任意正整数 `n`，可得 ‖`T`^(2^( `n` ))‖ = ‖`T`‖^(2^( `n` )) ![方程](Images/F000059si42.png)，于是 ‖`T`^(2^( `n` )) ![方程](Images/F000059si43.png) ‖^(2^(− `n` )) = (‖`T`‖^(2^( `n` )))^(2^(− `n` )) ![方程](Images/F000059si44.png) = ‖`T`‖。 该结果可用于证明 `C*` 代数中的范数必须是唯一的（[阿尔维森, 1976](#Ch008_145-164_B9780443136979000059.xhtml#bib1)）。
结论结构是一个 Banach 代数。如前所述，除非另有说明，本文档中 Banach 代数被理解为幺元且结合的。这是 Banach 代数没有单位元的一个著名例子。

# 第 9 章
## 冯·诺依曼代数
### 摘要
本章首先对算子拓扑进行描述。 特别是，给出了范数收敛、强算子收敛和弱算子收敛的概念。 其后是这些收敛过程之间的关系。 下一节引入冯·诺依曼代数并描述了该代数的两个非常重要的实例。 W\* 代数是希尔伯特空间上有界算子的 \* 代数，其在弱算子拓扑（WOT）下封闭并包含恒等算子。 W\* 代数的另一个实例是本质有界可测函数环，`L^∞(R)` ![方程](Images/F000242si1.png)。 它是一个交换的冯·诺依曼代数，由在 `L²` ![方程](Images/F000242si2.png) 函数的希尔伯特空间上作为逐点乘法的元素组成。 第 9.3 节陈述了双交换子定理。 双交换子使用与生成 C\* 代数时所采用的类似准则来说明。 接下来，格尔范德变换被描述为从交换 C\* 代数到 C(Δ(A)) 的映射，其中 C(Δ) 是 A 上所有复值连续泛函的代数。

#### 关键词
范数收敛; 强算子收敛; 弱算子收敛; 冯·诺依曼代数; 双交换子; 算子拓扑; 特征函数; 测度; σ-有限; 本质有界; 格尔范德变换

### 9.1 算子拓扑
弱算子拓扑（WOT）： 对所有 `v`、`w` 在 `H` 中，`Tk` → `T`，k=1, 2, … WOT 意味着收敛是相对于内积定义的，即当 k 趋于无穷时，`<v, Tk w>` → `<v, T w>`。 另一方面，强算子拓扑（SOT），SOT：`Tk` → `T`，意味着对所有 `v` 在 `H` 中，即当 k 趋于无穷时，范数 ‖`Tk v` − `T v`‖ → 0。 这种收敛类似于函数空间中的逐点收敛。 最强的收敛是在范数拓扑中：`Tk` → `T`，这意味着当 k 趋于无穷时算子范数 ‖`Tk` − `T`‖ → 0。 这种收敛类似于函数空间中的一致收敛。 范数收敛蕴含强算子收敛，而强算子收敛本身蕴含弱算子收敛。 对于 `T` 和 `T[n]` ![方程](Images/F000242si3.png) 在 B(`H`) 中，对于 n=0, 1, 2, …，不等式序列成立； |<v, (`T[n]` − `T`) w>| 小于或等于 ‖(`T[n]` − `T`) w‖ ‖v‖，而后者小于或等于 ‖`T[n]` − `T`‖ ‖w‖ ‖v‖。 这表明范数收敛蕴含 SOT，而 SOT 又蕴含 WOT 收敛。 这些陈述的逆命题是错误的，并在接下来的几个例子中加以说明。

#### 示例 9.1
考虑希尔伯特空间，`H`=l²。 设等距 `T[n]` 将序列 (`v[0]`, `v[1]`, `v[2]`, …) 映射为新序列，前 n 个元组为零，并从第 n+1 个元组开始向右移动原始元组。 即，`T[n]`(`v[0]`, `v[1]`, `v[2]`, …)=(0, 0, … 0, `v[0]`, `v[1]`, `v[2]`, …)。 还考虑投影算子 `P[n]`，它只是用零替换 l² 中任意向量 `w` 的前 n 个元组。 即，`P[n]`(`w[0]`, `w[1]`, `w[2]`, …)=(0, 0, … 0, `w[n]`, `w[n+1]`, …)。 然后使用 l² 中的任意向量 `w` 和 `v`，绝对内积 |<w, `T[n]`v>|=|<`P[n]` w, `T[n]`v>|。 但该量小于或等于 ‖`P[n]` w‖ ‖`T[n]`v‖=‖`P[n]` w‖ ‖v‖ → 0，当 n → ∞ 时，因为 $\\left\\| {P\_{n}w} \\right\\|^{2} = \\sum\_{k = n}^{\\infty}\\left. {|w\_{k}|}^{2}\\rightarrow 0 \\right.$ ![方程](Images/F000242si4.png) 当 k → ∞ 时。 因此 `T[n]` 在 WOT 中收敛于零。 然而，如前所述算子 `T` 是等距的，‖`T[n]`v‖=‖v‖，对所有 n 和 `H` 中的任意 v 成立，因此它在 SOT 中不收敛。 一般而言，弱收敛并不蕴含强收敛。
