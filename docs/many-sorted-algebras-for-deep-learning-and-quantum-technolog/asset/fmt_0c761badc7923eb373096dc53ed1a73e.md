
Whenever `Re <v, Tv>` is nonnegative, with `‖v‖ = 1`, `T` is called an accretive operator. Applications to these, as well as dissipative operators, are in creating one-parameter semigroups, much like in Stone’s theorem. In the present case, the semigroup consists of operators in a Banach space of the form, `e^(t T)` ![Equation](Images/F000138si122.png), when a dissipative operator is utilized. The corresponding operators in a Banach space are of the form `e^(-t T)` ![Equation](Images/F000138si123.png) whenever the generator is an accretive operator `T`. However, many of these operators are partially defined ([Delaubenfels, 1988](#Ch013_231-253_B9780443136979000138.xhtml#bib3)).

## 13.5 Self-adjoint operators

As previously mentioned, this and the next section provide a review as well as an extension of concepts related to self-adjoint operators. Of most importance, in quantum disciplines, observables are operators in a C∗ algebra, `A`. They are self-adjoint operators `T`, such that `T = T∗`. Moreover, these operators are measurable and defined via `RRT`, similar to the procedure of finding the dual space. The method is very similar to the creation of the adjoint `T∗`, for the case where `T: H → H` was considered previously.

Suppose that `T: H1 → H2`, where `H1` and `H2` are Hilbert spaces. Additionaly assume for now that `T` is bounded, that is, `T` is in `B(H1, H2)`. As in the dual space development, a functional `f` will be defined. It is such that for fixed `w` in `H2`, `f: H1 → C`, where for any `v` in `H1` it follows that `f(v) = <w, T v>`. The functional is linear and bounded since `T` is bounded and also `|f(v)|` is less than or equal to `‖w‖ ‖T v‖`. This inequality is a direct result of the `CBS` inequality. Additionally, the last expression is less than or equal to `‖w‖ ‖T‖ ‖v‖` since `T` is bounded. Moreover `f` is in the dual space of `H1`.

Using `RRT`, for every `w` in `H2`, there is a unique `u` in `H1` such that `f(v) = <u, v>`, holding for all `v` in `H1`. This defines a mapping: `T∗: H2 → H1`, which is called the adjoint of `T`, mentioned previously in the last section. The mapping `T∗` is given by `T∗(w) = u`. In short, the defining property of `T∗` is `<w, T v> = <T∗ w, v>`, for all `v` in `H1` and `w` in `H2`. The first inner product mentioned earlier is in `H2`, and the second is in `H1`. Since `T` is assumed to be bounded, it follows that `T∗` is also linear and bounded, that is, `T∗` is in `B(H2, H1)`. In addition, the following holds for `T` and `T∗`.

1. Norm equality: `‖T∗‖ = ‖T‖`.
2. Involution: `(T∗)∗ = T`.
3. Commuting norm: `‖T T∗‖ = ‖T∗ T‖ = ‖T‖²` ![Equation](Images/F000138si124.png).
4. Inverse: If `T` is invertible, then so is `T∗` and `(T^(-1))∗ = (T∗)^(-1)`.
5. Additive: `(S + T)∗ = S∗ + T∗`, where `S` is also in `B(H1, H2)`.
6. Anticommutative: `S∗ T∗ = (T S)∗`.

A unique representation involving self-adjoint operators can be made for a bounded operator `T`. Let `Q` and `S` be self-adjoint operators in the C∗ algebra `A`; then `T` can be represented as `T = Q + i S`. Therefore `T∗ = Q - i S`. Adding `T` plus `T∗` and then subtracting `T∗` from `T` gives `Q = (T + T∗)/2` and `S = (T - T∗)/(2i)`, respectively. The operators `Q` and `S` can be thought to be the real and imaginary parts of `T`, in that order.

If `K` is a closed subspace of `H`, then `K` is itself a Hilbert space. In this case, any vector `v` in `H` can be written as `u + w`, where `<u, w> = 0` and `u` is in `K`. The space of all those vectors orthogonal to vectors in `K` is called `K perp`, that is, write it as `perp(K)` or `K^⊥` ![Equation](Images/F000138si125.png). A projection operator `P` can be associated with this procedure. Indeed, let `P: H → K`, where `P(v) = u`. Such an operation is both idempotent and self-adjoint. Note that `(I - P)(v) = w`. If also `v' = u' + w'` with `u'` in `K` and `w'` in `perp(K)`, then `<P(v), v'> = <u, u'> = <v, u'> = <v, P(v')>`. Furthermore, `<u, w> = <P(v), (I - P)(v)> = <v, P(I - P)(v)> = 0`. When `K` is a closed subspace of `H`, then `perp(K)` is also closed. An important property of a vector subspace `K` of a Hilbert space `H` is that the closure of `K` equals `perp(perp(K))`. If `K` is a closed subspace of `H`, then again `K = perp(perp(K))`. Moreover, `K` is closed iff `K = (K^⊥)^⊥` ![Equation](Images/F000138si126.png). To see this, first assume that `K = (K^⊥)^⊥` ![Equation](Images/F000138si127.png). Then choose a sequence `v[n] → v` ![Equation](Images/F000138si128.png), where `v[n]` ![Equation](Images/F000138si129.png) is in `K` and `v` is in `H`. It will be shown that `v` is in `K`. Take `w` in `K^⊥` ![Equation](Images/F000138si130.png), then `<w, v[n]> = 0` ![Equation](Images/F000138si131.png) for all n, and then using the continuity of an inner product: `lim[n → ∞] <w, v[n]> = <w, lim[n → ∞] v[n]> = <w, v> = 0`. This shows that `v` is in `K = (K^⊥)^⊥` ![Equation](Images/F000138si135.png), and so `K` is closed.

Going the other way, if `K` is a closed subspace of `H`, then `K = (K^⊥)^⊥` ![Equation](Images/F000138si136.png) will be shown. Taking the inner product of `v` in `K` and any `w` in `K^⊥` ![Equation](Images/F000138si137.png) gives `<v, w> = <w, v>∗ = 0`, thus showing `v` is also in `(K^⊥)^⊥` ![Equation](Images/F000138si138.png). So `K` is a subset of `(K^⊥)^⊥` ![Equation](Images/F000138si139.png). To see the opposite set inclusion, let `v` be in `(K^⊥)^⊥` ![Equation](Images/F000138si140.png). Then represent `v = w + z`, where `w` is in `K` and `z` is in `K^⊥` ![Equation](Images/F000138si141.png). Using linearity, `0 = <v, z> = <w, z> + <z, z> = 0 + <z, z> = ‖z‖²`, which implies that `z = 0`. Accordingly, `v = w` and so `(K^⊥)^⊥` ![Equation](Images/F000138si142.png) is a subset of `K`, and therefore they are equal.

When `T` is bounded, there is a relation between the kernel and the image of the adjoint operation, namely `Ker(T) = perp(Im(T∗))` and also that the closure of `Im(T∗) = perp(ker(T))`. Additionally, if `K` is closed, then `perp(K) = perp(closure(K)) = closure(perp(K))`. Also, `perp(perp(K)) = closure(K)`. For a closed subspace `K`, it follows that `perp(perp(K)) = K`. Moreover, using `w = u + v`, then for `P` in `B(H)` and `P(w) = u`, `‖P(w)‖² = ‖w‖² - ‖w - u‖²` ![Equation](Images/F000138si143.png); this follows, because `w - u = v` and `<u, v> = 0`. So, `‖u‖² = ‖w - v‖² = ‖w‖² - ‖v‖²` ![Equation](Images/F000138si144.png).

Relations between the adjoint and the kernel are as follows:

1. `Ker(T∗) = perp(ran(T))`.
2. `Perp(ker(T∗)) = clos(ran(T))`.

An example will be given using the basis for a momentum operator, the derivative operation. It will illustrate a closed operator on a subspace of a Hilbert space, where this operator is not bounded.

### Example 13.18

Again, let the unbounded momentum type operator `T` be employed where `T = d/dx`. Then, the domain of `T` is `D(T)` where `D(T) = { f in L[2]` ![Equation](Images/F000138si146.png) `[0, 1]`, such that `f` is absolutely continuous, where `d f/dx` is in `L[2]` ![Equation](Images/F000138si147.png) `[0, 1]` with `f(0) = 0}`. Then `T` is closed in `D(T)` ([Park, 2013](#Ch013_231-253_B9780443136979000138.xhtml#bib11)). It is not closed in the Banach space `C[0, 1]`. That is, it is not closed in the domain `{ f in C[0, 1]`, such that `d f/dx` is in `C [0, 1]` with `f(0) = 0}`. See Example 8.1 for details.
