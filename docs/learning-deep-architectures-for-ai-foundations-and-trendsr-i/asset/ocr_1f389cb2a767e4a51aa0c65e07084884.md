Although depth depends on the choice of allowed computations for each element, graphs associated with one set can often be converted to graphs associated with another by graph transformation in a way that multiplies depth. Theoretical results suggest that it is not the absolute number of levels that matters, but the number of levels relative to how many are required to represent efficiently the target function (with some choice of set of computational elements).

# 2.1 Computational Complexity

The most formal arguments about the power of deep architectures come from investigations into computational complexity of circuits. The basic conclusion that these results suggest that when a function can be compactly represented by a deep architecture, it might need a very large architecture to be represented by an insufficiently deep one.
