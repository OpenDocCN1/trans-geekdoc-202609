Figure 4.4 Graphical model of a Deep Belief Network with observed vector x and hidden layers h¹, h², ... Notation is similar as in Figure 4.3. The structure is similar to a sigmoid belief network, except for the top layers. Instead of having a factorized prior for $P(h^3)$, the joint of the top two layers, $P(h^2, h^1)$, is a Restricted Boltzmann Machine. The model is mixed, with double arrows on the arcs between the top two layers because an RBM is an undirected graphical model rather than a directed one.
