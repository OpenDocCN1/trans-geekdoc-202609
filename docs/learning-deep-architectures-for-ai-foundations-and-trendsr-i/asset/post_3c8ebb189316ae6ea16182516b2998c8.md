## 7.3 Lateral Connections

The RBM can be made slightly less restricted by introducing interaction terms or "lateral connections" between visible units. Sampling $\mathbf{h}$ from $P(h|x)$ is still easy but sampling $\mathbf{x}$ from $P(x|h)$ is now generally more difficult, and unlike sampling from a Markov Random Field which is also a fully observed Boltzmann machine, in which the offsets are dependent on the value of. [141] propose such a model for capturing image statistics and their results suggest that Deep Belief Nets (DBNs) based on ordinary RBMs generate more realistic images than DBNs. Their results also show that the resulting distribution has marginal and pairwise statistics for pixel intensities that are similar to those observed on real image patches.

These lateral connections capture pairwise dependencies that can be more easily captured by using hidden units, saving the hidden units for capturing higher-order dependencies. In the case of the first layer, it can be seen that this amounts to a form of whitening, which has been found useful as a preprocessing step in image processing systems [139]. The idea proposed by [141] is to use lateral connections at all levels of a DBN (which can now be seen as a hierarchy of Markov random fields). The generic advantage of this type of approach would be that the higher level factors represented by the hidden units do not have to encode all the local "details" that the lateral connections at the levels below can capture. For example, when generating an image of a face, the mouth and nose must be specified at a high level whereas their location could be selected in order to satisfy the pairwise preferences encoded in the lateral connections at a lower level. This appears to yield generated images with sharper edges and generally more accuracy in the relative locations of parts, without having to expand a large number of higher-level units.

In order to sample from $P(x|h)$, we can start a Markov chain in the current example (presumably already has pixel co-dependencies similar to those represented by the model, so that convergence should be quick) and only run a short chain on the $\mathbf{x}$'s (keeping $\mathbf{h}$ fixed). ## 7.4 Conditional RBMs and Temporal RBMs

To reduce sampling variance in CD for this model, [141] used five damped mean-field steps instead of an ordinary Gibbs chain on the $\mathbf{x}$'s: $\mathbf{x}_t = \mathbf{x}_{t-1} + (1-\alpha)\text{sign}(\mathbf{b} + \mathbf{Ux}_{t-1} + \mathbf{W}')$, with $\alpha \in (0,1)$.

A Conditional RBM is an RBM where some of the parameters are not free but are instead parametrized functions of a random variable. For example, consider an RBM for the joint distribution $P(x,h)$ between observed vector $\mathbf{x}$ and hidden vector $\mathbf{h}$, with parameters $(\mathbf{b},\mathbf{c})$ as per Equation (5.15), for input offsets hidden units offsets $\mathbf{c}$, and the weight matrix $\mathbf{W}$. This idea has been introduced by [182, 183] for context-dependent RBMs in which the hidden units $\mathbf{c}$ are affine functions of a context variable $\mathbf{z}$. Hence the RBM represents $P(x,h|z)$, or marginalizing over $\mathbf{h}$, $P(x)$. In the general parameters $\theta=(\mathbf{b},\mathbf{W})$ of an RBM can be written as a parametrized $\theta=f(x,z)$, i.e., the free parameters of the conditional RBM with conditioning variable $\mathbf{z}$ are denoted $\omega$. Generalizing RBMs to conditional RBMs allows building deep architectures in which the hidden variables at each level can be conditioned on the value of other variables (typically representing some form of context).

The Contrastive Divergence algorithm for RBMs can be easily generalized to the case of Conditional RBMs. The CD gradient estimator $\Delta\theta$ on a parameter $\theta$ can simply be back-propagated to obtain a gradient estimator on $\omega$:

```
$\Delta\omega = \Delta\theta \frac{\partial\theta}{\partial\omega}$.
```

In the affine case $\mathbf{c} = \beta + \mathbf{Mz}$ (with $\mathbf{c}, \beta$ and $\mathbf{z}$ column vectors) studied by [183], the CD update on the conditional parameters is simply

```
$\Delta\beta = \Delta\mathbf{c},$
$\Delta\mathbf{M} = \Delta\mathbf{c}\mathbf{z}'$.
```

where the last multiplication is an outer product (applying the chain rule on derivatives), and $\Delta\mathbf{c}$ is the update given by CD-$k$ on hidden units offsets.

This idea has been successfully applied to model conditional distributions $P(\mathbf{x}_t|\mathbf{x}_{t-1}, \mathbf{x}_{t-2}, \mathbf{x}_{t-3})$ in sequential data of human motion [183], where $\mathbf{x}_t$ is a vector of joint angles and other geometric features computed from motion capture data of human movements as walking and running. Interestingly, this allows *generating* realistic human motion *sequences*, by successively sampling the $t$-th frame given the previously sampled $k$ frames, i.e., approximating

```
$P(\mathbf{x}_1, \dots, \mathbf{x}_t) \approx P(\mathbf{x}_1, \dots, \mathbf{x}_k) \prod_{t=k+1}^T P(\mathbf{x}_t|\mathbf{x}_{t-1}, \dots, \mathbf{x}_{t-k})$.
```

## 7.4 Conditional RBMs and Temporal RBMs

A Conditional RBM is an RBM where some of the parameters are not free but are instead parametrized functions of a random variable. For example, consider an RBM for the joint distribution $P(x,h)$ between observed vector $\mathbf{x}$ and hidden vector $\mathbf{h}$, with parameters $(\mathbf{b},\mathbf{c})$ as per Equation (5.15), for input offsets hidden units offsets $\mathbf{c}$, and the weight matrix $\mathbf{W}$. This idea has been introduced by [182, 183] for context-dependent RBMs in which the hidden units $\mathbf{c}$ are affine functions of a context variable $\mathbf{z}$. Hence the RBM represents $P(x,h|z)$, or marginalizing over $\mathbf{h}$, $P(x)$. In the general parameters $\theta=(\mathbf{b},\mathbf{W})$ of an RBM can be written as a parametrized $\theta=f(x,z)$, i.e., the free parameters of the conditional RBM with conditioning variable $\mathbf{z}$ are denoted $\omega$. Generalizing RBMs to conditional RBMs allows building deep architectures in which the hidden variables at each level can be conditioned on the value of other variables (typically representing some form of context).

The Contrastive Divergence algorithm for RBMs can be easily generalized to the case of Conditional RBMs. The CD gradient estimator $\Delta\theta$ on a parameter $\theta$ can simply be back-propagated to obtain a gradient estimator on $\omega$:

```
$\Delta\omega = \Delta\theta \frac{\partial\theta}{\partial\omega}$.
```

In the affine case $\mathbf{c} = \beta + \mathbf{Mz}$ (with $\mathbf{c}, \beta$ and $\mathbf{z}$ column vectors) studied by [183], the CD update on the conditional parameters is simply

```
$\Delta\beta = \Delta\mathbf{c},$
$\Delta\mathbf{M} = \Delta\mathbf{c}\mathbf{z}'$.
```

where the last multiplication is an outer product (applying the chain rule on derivatives), and $\Delta\mathbf{c}$ is the update given by CD-$k$ on hidden units offsets.

This idea has been successfully applied to model conditional distributions $P(\mathbf{x}_t|\mathbf{x}_{t-1}, \mathbf{x}_{t-2}, \mathbf{x}_{t-3})$ in sequential data of human motion [183], where $\mathbf{x}_t$ is a vector of joint angles and other geometric features computed from motion capture data of human movements as walking and running. Interestingly, this allows *generating* realistic human motion *sequences*, by successively sampling the $t$-th frame given the previously sampled $k$ frames, i.e., approximating

```
$P(\mathbf{x}_1, \dots, \mathbf{x}_t) \approx P(\mathbf{x}_1, \dots, \mathbf{x}_k) \prod_{t=k+1}^T P(\mathbf{x}_t|\mathbf{x}_{t-1}, \dots, \mathbf{x}_{t-k})$.
```
