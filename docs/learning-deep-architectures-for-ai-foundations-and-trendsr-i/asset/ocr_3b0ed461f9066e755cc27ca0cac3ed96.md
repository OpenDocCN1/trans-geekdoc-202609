If the energy can be written as a sum of terms associated with at most one hidden unit

```
$Energy(\mathbf{x},\mathbf{h}) =-\beta(\mathbf{x}) + \sum_i \gamma_i(\mathbf{x},\mathbf{h}),$\n(5.11)$
```

a condition satisfied in the case of the RBM, the free energy and numerator of the likelihood can be computed tractable (even though it involves a sum with an exponential number of terms):

```
$P(\mathbf{x}) = \frac{1}{Z}e^{-\text{FreeEnergy}(\mathbf{x})} = \frac{1}{Z}\sum_{\mathbf{h}}e^{-\text{Energy}(\mathbf{x},\mathbf{h})}\n= \frac{1}{Z}\sum_{h_1}\sum_{h_2}...\sum_{h_k}e^{\beta(\mathbf{x})-\sum_i \gamma_i(\mathbf{x},\mathbf{h})}\n= \frac{1}{Z}\sum_{h_1}\sum_{h_2}...\sum_{h_k}e^{\beta(\mathbf{x})}\prod_i e^{-\gamma_i(\mathbf{x},h_i)}\n= \frac{1}{Z}\sum_{h_1}e^{-\gamma_1(\mathbf{x},h_1)}\sum_{h_2}e^{-\gamma_2(\mathbf{x},h_2)}...\sum_{h_k}e^{-\gamma_k(\mathbf{x},h_k)}
= \frac{1}{Z}e^{\beta(\mathbf{x})}\prod_i\sum_{h_i}e^{-\gamma_i(\mathbf{x},h_i)}$$\n(5.12)$
```

In the above, sum $\sum h_i$ is a sum over all the values that $\mathbf{h}$ can take (e.g., two values in the usual binomial case); note how sum is much easier to carry out than the sum $\sum h_h$ over all values of $\mathbf{h}$. Note that all sums can be replaced by integrals if $\mathbf{h}$ is continuous, and the same principles apply.
