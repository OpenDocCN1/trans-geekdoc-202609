This idea has been successfully applied to model conditional distributions $P(\mathbf{x}_t|mathbf{x}_{t-1}, \mathbf{x}_{t-2}, \mathbf{x}_{t-3})$ in sequential data of human motion [183], where $\mathbf{x}_t$ is a vector of joint angles and other geometric features computed from motion capture data of human movements as walking and running. Interestingly, this allows *generating* realistic human motion *sequences*, by successively sampling the $t$-th frame given the previously sampled $k$ frames, i.e., approximating

```
$P(\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_k) \approx P(\mathbf{x}_1, \dots, \mathbf{x}_{k}) \prod_{t=k+1}^T P(\mathbf{x}_t|\mathbf{x}_{t-1}, \dots, \mathbf{x}_k). \quad (7.5)$
```

The initial frames can be generated by using null values as context or using a separate model for $P(\mathbf{x}_1, \dots, \mathbf{x}_k)$.

As demonstrated by [126], it can be useful to not just make the offsets but also the weights conditional on a context variable. In that, we greatly increase the number of degrees of freedom, introducing the capability to model three-way interactions between an input $\mathbf{x}_t$, using a hidden $\mathbf{h}_t$, and a context unit $\mathbf{z}_t$ through interaction parameters $\zeta_{tk}$. This approach has been used with $\mathbf{x}$ an image and $\mathbf{z}$ the previous image in a video, and the model learns to capture *flow fields* [126].

Probabilistic sequences of data with hidden variables $\mathbf{h}$ (*state*) can gain a lot by capturing the temporal dependencies between the hidden states at different times $t$ in the sequence. This is what allows *Hidden Markov Models* (HMMs) [147] to capture dependencies in a long sequence $\mathbf{x}_1, \mathbf{x}_2,\dots$ even if the model only considers the hidden state sequence $\mathbf{h}_1, \mathbf{h}_2,\dots$ to be a Markov chain of order 1 (where the direct dependency is only between $\mathbf{h}_t$ and $\mathbf{h}_{t+1}$).\nWhereas the hidden state representation $\mathbf{h}$ in HMMs is *local* (all the possible values of $\mathbf{h}$ are enumerated and specific parameters associated with each of these values), *Temporal RBMs* have been proposed [180] to construct a distributed representation of the state. The idea is an extension of the Conditional RBM proposed above, where the context includes not only past inputs but also past values of the state, e.g., we build a model of

```
$P(\mathbf{h}_t, \mathbf{x}_t|\mathbf{h}_{t-1}, \dots, \mathbf{h}_{t-k}, \mathbf{x}_{t-k}), \quad (7.6)$
```
