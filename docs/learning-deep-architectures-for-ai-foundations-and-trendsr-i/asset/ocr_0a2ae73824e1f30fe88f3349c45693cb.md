```
$Energy(\mathbf{x}, \mathbf{h}) = -\mathbf{b}'\mathbf{x} - \mathbf{c}'\mathbf{h} - \mathbf{h}'\mathbf{Wx} \quad (5.20)$
```

and the factorization of the free energy of the input, introduced with Equations (5.11) and (5.13) can be applied with $\beta(\mathbf{x})=\mathbf{b}'\mathbf{x}$ and $\gamma_i(\mathbf{x},\mathbf{h})=-h_i(c_i + W_ix)$, where $W_i$ is the row vector corresponding to the $i$-th row of $\mathbf{W}$. Therefore the free energy of the input (i.e., its unnormalized log-probability) can be computed efficiently:

```
$FreeEnergy(\mathbf{x}) = -\sum_{i} \log \sum_{h_i} e^{h_i(c_i + W_ix)} \quad (5.21)$
```

Using the same factorization technique (in Equation (5.12)) due to the affine form of $Energy(\mathbf{x},\mathbf{h})$ with respect to $\mathbf{h}$, we readily obtain a tractable expression for the conditional probability $P(\mathbf{h}|\mathbf{x})$:

```
$P(\mathbf{h}|\mathbf{x}) = \frac{\exp(\mathbf{b}'\mathbf{x} + \mathbf{c}'\mathbf{h} + \mathbf{h}'\mathbf{Wx})}{\sum_{\mathbf{h}} \exp(\mathbf{b}'\mathbf{x} + \mathbf{c}'\mathbf{h} + \mathbf{h}'\mathbf{Wx})} = \frac{\prod_i \sum_{h_i} \exp(c_ih_i + W_ix)}{\prod_i \sum_{h_i} \exp(h_i(c_i + W_ix))} = \prod_i P(h_i|\mathbf{x}).\.$
```

In the common case where $h_i \in \{0,1\}$, we obtain the usual neuron equation for a neuron's output given:

```
$P(h_i|\mathbf{x}) = \frac{e^{c_i+W_ix}}{1 + e^{c_i+W_ix}} = sign(c_i + W_ix). \quad (5.22)$
```

Since $\mathbf{x}$ and $\mathbf{h}$ play a symmetric role in the energy function, a similar derivation allows to efficiently compute and sample $P(\mathbf{x}|\mathbf{h})$:

```
$P(\mathbf{x}|\mathbf{h}) = \prod_i P(x_i|\mathbf{h}) \quad (5.23)$
```
