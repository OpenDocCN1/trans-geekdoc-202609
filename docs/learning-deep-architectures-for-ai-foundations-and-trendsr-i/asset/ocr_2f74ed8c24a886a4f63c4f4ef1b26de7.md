Here, we argue that training an energy-model can be achieved by solving a series of classification problems in which one tries to discriminate training examples from samples generated by the model. In the Boltzmann machine learning algorithms, as well as Contrastive Divergence, an important element is the ability to sample from the model, maybe approximately. An elegant way to understand the value of these samples in improving the log-likelihood was introduced in [201], using a connection with boosting. We start by explaining the idea and then formalize it, justifying algorithms based on training the generative model with a classification criterion separating model from training examples.
