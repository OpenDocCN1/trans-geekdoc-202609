We will use $Q(h^k|h^{k-1})$ as an approximation of $P(h^k|h^{k-1})$, because it is easy to compute and sample from $Q(h^k|h^{k-1})$ (which factorizes), and not from $P(h^k|h^{k-1})$ (which does not). These $Q(h^k|h^{k-1})$ can also be used to construct a representation of the input vector $x$. To obtain an approximate posture or representation for all the levels, we use the following procedure. First sample $h^1 \sim Q(h^1|x)$ from the first-level RBM, alternatively with a mean-field approach $h^1 = E[h^1|x]$ instead of a sample of $h^1$, where the expectation is over the RBM distribution $Q(h^1|x)$ the hidden units, in the common case where they are binomial units: $h^1 = 	ext{sig}(b^1 + W^1x)$. Taking either the mean-field vector $h^1$ as input for the second-level RBM, compute $h^2$ or the sample $h^2$, until the last layer. Once a DBN is trained as per Algorithm 2, the parameters $W^l$ (RBM weights) and $c^l$ (RBM hidden unit offsets) for each layer can be used to initialize a deep multi-layer neural network. These parameters can then be fine-tuned with another criterion (typically a supervised learning criterion).
