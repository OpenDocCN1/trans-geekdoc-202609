The bottom layer generates a vector $\mathbf{x}$ in the input space, and we would like to give high probability to the training data. Considering multiple levels, the generative model is this decomposed as:

```python
$P(\mathbf{x}, \mathbf{h}^1, \dots, \mathbf{h}^l) = P(\mathbf{h}^l) \left( \prod_{k=1}^{l-1} P(\mathbf{h}^k|\mathbf{h}^{k+1}) \right) P(\mathbf{x}|\mathbf{h}^1) \quad (4.4)$
```

and marginalization yields $P(\mathbf{x})$, but this is intractable in practice except for tiny models. In a sigmoid belief network, the top level $P(\mathbf{h}^l)$ is generally chosen to be factorized, i.e., very simple: $P(\mathbf{h}^l) = \prod P(\mathbf{h}^l)$, and a single Bernoulli parameter is required for each $P(\mathbf{h}^l = 1)$ in the case of binary units.

Deep Belief Networks are similar to sigmoid belief networks, but with a slightly different parametrization for the top layers, as illustrated in Figure 4.4:

```python
$P(\mathbf{x}, \mathbf{h}^1, \dots, \mathbf{h}^l) = P(\mathbf{h}^{l-1}, \mathbf{h}^l) \left( \prod_{k=1}^{l-2} P(\mathbf{h}^k|\mathbf{h}^{k+1}) \right) P(\mathbf{x}|\mathbf{h}^1) \quad (4.5)$
```

Fukushima's Neocitron [54] introduced translational invariance. The architecture of the Neocitron was based on local connectivities, which allowed for the recognition of features regardless of their position. This idea was later adopted by modern convolutional neural networks, which have achieved state-of-the-art performance on various tasks like image classification and object detection.

The use of convolutional layers allows for the processing of high-dimensional data, such as images, with a much smaller number of parameters compared to fully connected networks. This is because the filters are shared across the entire input, which means the network learns to detect features that are useful at all locations.

The hierarchical structure of convolutional neural networks allows them to learn increasingly abstract representations of the input, from simple edges to more complex parts and whole objects. This is inspired by the way the visual system processes information.
