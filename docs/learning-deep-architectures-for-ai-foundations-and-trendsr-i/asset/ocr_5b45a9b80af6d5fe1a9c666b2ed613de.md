Well-known examples of kernel machines include not only Support Vector Machines (SVMs) [24, 39] and Gaussian processes [203] for classification and regression, but also classical non-parametric algorithms for classification, regression and density estimation, such as the $k$-nearest neighbor algorithm, Nadaraya-Watson or Parzen windows, etc. Below, we discuss *manifold learning algorithms* and LLE which can also be seen as local kernel machines, as well as semi-supervised learning algorithms based on the construction of a *neighborhood graph* (with one node per example and edges between neighboring examples).

Kernel machines with a local kernel yield generalization by what could be called the *smoothness prior*: the assumption that the target function is smooth or can be well approximated with a smooth function. In supervised learning, if we train an example $(\mathbf{x}_i, y_i)$, then it makes sense to construct a predictor $f(\mathbf{x})$ which will output something close to $y_i$ when $\mathbf{x}$ is close to $\mathbf{x}_i$. Note how this prior requires defining a notion of proximity in input space. This is a useful prior, but one of the claims made [13] and [19] is that such a prior is insufficient to generalize when the target function is highly varying in input space.

The limitations of a fixed kernel such as the Gaussian kernel have motivated a lot of research in *designing kernels* based on prior knowledge about the task [38, 56, 89, 171]. However, if we lack sufficient prior knowledge for designing an appropriate kernel, can we learn it? This also motivated much research [40, 96, 196], and deep architectures can be viewed as a promising development in this direction.
