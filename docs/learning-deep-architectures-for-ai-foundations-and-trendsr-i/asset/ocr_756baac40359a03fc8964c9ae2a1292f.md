# 7.4 Conditional RBMs and Temporal RBMs

A Conditional RBM is an RBM where some of the parameters are not free but are instead parametrized functions of a random variable. For example, consider an RBM for the joint distribution $P(x,h)$ between observed vector $\mathbf{x}$ and hidden vector $\mathbf{h}$, with parameters $(\mathbf{b},\mathbf{c})$ as per Equation (5.15), for input offsets hidden units offsets $\mathbf{c}$, and the weight matrix $\mathbf{W}$. This idea has been introduced by [182, 183] for context-dependent RBMs in which the hidden units $\mathbf{c}$ are affine functions of a context variable $\mathbf{z}$. Hence the RBM represents $P(x,h|z)$, or marginalizing over $\mathbf{h}$, $P(x)$. In the general parameters $	heta=(\mathbf{b},\mathbf{W})$ of an RBM can be written as a parametrized $	heta=f(x,z)$, i.e., the free parameters of the conditional RBM with conditioning variable $\mathbf{z}$ are denoted $\omega$. Generalizing RBMs to conditional RBMs allows building deep architectures in which the hidden variables at each level can be conditioned on the value of other variables (typically representing some form of context).

The Contrastive Divergence algorithm for RBMs can be easily generalized to the case of Conditional RBMs. The CD gradient estimator $\Delta	heta$ on a parameter $	heta$ can simply be back-propagated to obtain a gradient estimator on $\omega$:

```
$\Delta\omega = \Delta\theta \frac{\partial\theta}{\partial\omega}$.
```

In the affine case $\mathbf{c} = oldsymbol{eta} + \mathbf{Mz}$ (with $\mathbf{c}, eta$ and $\mathbf{z}$ column vectors) studied by [183], the CD update on the conditional parameters is simply

```
$\Delta\beta = \Delta\mathbf{c},\n$\Delta\mathbf{M} = \Delta\mathbf{c}\mathbf{z}'$.
```

where the last multiplication is an outer product (applying the chain rule on derivatives), and $\Delta\mathbf{c}$ is the update given by CD-$k$ on hidden units offsets.
