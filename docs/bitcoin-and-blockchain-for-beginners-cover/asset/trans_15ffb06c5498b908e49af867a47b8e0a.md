# 什么让比特币独特？

比特币的最大入门障碍之一是，许多人对非实物货币的概念感到不适。当我们想到传统货币（有时被称为“法币”），例如美元或欧元时，我们经常会想到纸币。我们大多数人习惯于将金钱视为现金——一种我们随身携带的真实物品。

实际上，然而，大多数人并不携带笔袋装满现金。

我们大部分的金钱存放在银行中。为什么会是这样？

纸币已经使用很长时间，但并不实用。它容易丢失、被盗或损坏。此外，没有任何东西能将特定的纸币与某个人绑定。

如果你把一生的积蓄藏在床垫下，并且被抢劫，钱里没有任何东西可以用来证明你是所有者。除非小偷被警方抓获，否则这笔钱很可能永远无法追回。由于这种脆弱性，我们依赖银行来保管我们大部分的金钱。

![](Images/image00069.jpeg)

银行通过收取费用和对我们银行账户中的资金进行一定程度的控制，提供安全保障。历史上，银行几乎是消费者唯一能够将货币安全存储在受保障的集中位置的选择。但银行真的是解决资金存储问题的最佳方案吗？

银行可以根据各种变量限制、限制并管理我们对自己资金的访问权限。例如，我们可能随时被禁止超过特定金额的取款。要在我们的账户之间转账，我们可能需要支付高额交易费用。由于所有数据都存储在单一的中心数据库中，如果银行被黑客攻击，数以百万计的账户可能受到影响。尽管有诸多缺点，我们大多数人仍然把钱存入银行，因为没有更好的选择。我们别无选择，只能信任这些机构，或者冒着把钱藏在床垫下的风险。

比特币是一个可行的选择。比特币不同于传统货币，它是去中心化的。交易是点对点进行的，消除了银行、政府机构或其他第三方实体作为“中间人”的需求。因此，比特币和许多其他加密货币常被称为“信任无关”，这意味着我们可以在不向交易对象或金融机构信任的情况下进行交易。

如果你不熟悉比特币，你可能会想知道它是如何工作的。为了揭示这个领域的内部运作，让我们稍微后退一步，暂时把比特币视为一种技术。

# 区块链技术概述

当你开始探索加密货币的世界时，你首先会遇到的术语之一是“区块链”。理解区块链技术的基础对于理解比特币、加密货币整体以及去中心化计算的未来至关重要。那么，区块链到底是什么，为什么它如此重要？

区块链是比特币和许多其他加密货币及新兴技术运行的框架或“协议”。区块链本质上是一个分布在全球众多计算机上的公共账本。每一笔比特币交易都会被记录并添加到区块链作为一个新的“区块”，并且它通过特定的时间戳与前一笔交易相链接，就像一条漫长“链”中的一个链接。

区块链由一个去中心化的点对点网络控制，这意味着它会在全球许多不同的计算机上不断保存和更新。任何人都可以运行程序，将他们的计算机作为这个庞大网络中的“节点”，为交易记录的持续进行做出贡献。由于这种分布式特性，全球各地存在着无数种不同的区块链版本，使得在记录后修改交易信息几乎变得不可能。

# 设计上安全

为了更清晰地可视化区块链，可以考虑金库（Fort Knox）。金库以在其内部深处储存美国金条储备而闻名。金库内部储存着大量的金条。金库采用武装警卫、防爆金库以及多种额外的现场安保措施来保护这些金条的安全。如果金条需要移动，我们可以想象装甲车和持枪的士兵在金条搬运时进行看守。对于犯罪分子来说，入侵金库并偷走金条将是一件极其困难的事，不仅因为设施的防御严密，而且因为金条是重物，难以转移。

在资产保护方面，银行（以及许多其他机构）传统上遵循类似的模式，将所有资产集中存储在依赖多层安全机制的地点。然而，在当今世界，绝大部分财务信息以数字形式存在，即以数据的形式。我们相信银行有足够的资金来支撑我们银行账户中的数字，但对于绝大多数人来说，这些数字仅仅是价值的记录，而非存放在金库中的实物现金。

![](Images/image00071.jpeg)

与物理金库不同，我们的财务资产主要以银行服务器的“数字金库”中保存的财务数据形式存在。银行试图将这些服务器转变为数字金库，但事实上，这种集中化的架构并不适应数字交易的新环境。与入侵金库并偷走金条需要炸药、特殊设备、逃跑车辆以及类似《奥cean's 11》的精巧不同，黑客可以仅用电脑就轻易进入银行服务器并窃取财务信息。信用卡欺诈、身份盗窃和数据泄露是金融机构每天面临的真实风险。

银行继续在其“数字金库”周围安装新的安全层，但黑客仍然频繁地突破它们。金库非常适合存储实物金条，但当我们尝试将其应用于数字领域的数据时，它就失效了。如果我们退一步思考问题，我们可以开始询问：在数字信息存储和数字交易领域，是否存在比继续试图锁定单一服务器更好的模式？这就是区块链技术发挥作用的地方。

区块链中的每一个区块都与前一个区块相链接，并通过全球众多节点公开记录。与其在单一中心服务器中输入并窃取或修改数据不同，黑客必须在全球多数持有该链的机器上同时修改整个区块链上的信息，这将是一项几乎不可能的任务。
