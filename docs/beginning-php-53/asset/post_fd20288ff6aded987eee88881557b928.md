### Exercise 2 Solution

The structure of the recursive function to produce the factorial of an integer is similar to that of the fibonacci() function shown earlier in the chapter. First you implement the base case:

```php
if ( $n == 0 ) return 1;
```

Then you implement the recursive case:

```php
return factorial( $n-1 ) * $n;
```

So the entire factorial() function looks like this:

```php
function factorial( $n ) {
  if ( $n == 0 ) return 1;
  return factorial( $n-1 ) * $n;
}
```
