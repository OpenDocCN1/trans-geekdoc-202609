# Try It Out Read an XML Document using the DOM

Previously you used the XML Parser extension to read in and parse an XML document, displaying each element, attribute, and text item within the document. In this example, you get to do much the same thing using the DOM extension instead.

Here's the script. Save it as dom_read_document.php in your document root. Make sure the stock_list.xml file from the previous Try It Out example is in the same folder; if not, create it as explained earlier.
