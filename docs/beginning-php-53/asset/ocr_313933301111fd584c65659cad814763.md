array_splice() lets you remove a range of elements in an array and replace them with the elements from another array. Both the removal and the replacement are optional, meaning you can just remove elements without adding new ones, or just insert new elements without removing any.

Here’s how it works. array_splice() takes the array to be manipulated, and the position of the first element (counting from zero) to start the splice operation. (Remember that all arrays, even associative arrays, have a concept of element positioning.) Next, you pass in an optional argument that specifies how many elements to remove; if omitted, the function removes all elements from the start point to the end of the array. Finally, you can pass another optional argument, which is the array of elements to insert.

array_splice() returns an array containing the extracted elements (if any).
