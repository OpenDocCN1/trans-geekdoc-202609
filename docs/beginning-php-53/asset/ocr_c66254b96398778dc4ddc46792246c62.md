# ## Arithmetic Operators

In PHP, the arithmetic operators (plus, minus, and so on) work much as you would expect, enabling you to write expressions as though they were simple equations. For example, $c = $a + $b adds $a and $b and assigns the result to $c. Here’s a full list of PHP’s arithmetic operators:

| Operator | Example Equation |
| --- | --- |
| + (addition) | 6 + 3 = 9 |
| - (subtraction) | 6 - 3 = 3 |
| * (multiplication) | 6 * 3 = 18 |
| / (division) | 6 / 3 = 2 |
| % (modulus) | 6 % 3 = 0 (the remainder of 6/3) |

# ## Assignment Operators

You’ve already seen how the basic assignment operator (=) can be used to assign a value to a variable:

```
`$test_var = 8.23;`
```

It’s also worth noting that the preceding expression evaluates to the value of the assignment: 8.23. This is because the assignment operator, like most operators in PHP, produces a value as well as carrying out the assignment operation. This means that you can write code such as:

```
`$another_var = $test_var = 8.23;`
```
