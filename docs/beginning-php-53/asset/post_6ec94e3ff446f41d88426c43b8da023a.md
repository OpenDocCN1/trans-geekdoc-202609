$st->bindValue( ":otherInterests", $this->data["otherInterests"],
PDO::PARAM_STR );

parent::disconnect( $conn );

If you’ve worked through the previous chapter and this chapter so far, there should be no surprises here. insert() builds an SQL statement to insert the data stored in the current Member object into the database. If there were any problems with the insertion, the exception is caught and displayed and the application exits.
