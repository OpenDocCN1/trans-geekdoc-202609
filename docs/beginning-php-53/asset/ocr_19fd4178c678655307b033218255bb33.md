The script uses the HTML_QuickForm and HTML_QuickForm_Renderer_Tableless PEAR packages to display and handle the contact form, so if you haven’t already done so, you’ll need to install these two packages before you run the script. You can find instructions for this in Chapter 15.

Now run the script by visiting its URL in your Web browser. You should see a form like the one shown in Figure 16-4. Enter your details into the form, along with a message subject and a message itself, and then click the Send Message button to send the email.
