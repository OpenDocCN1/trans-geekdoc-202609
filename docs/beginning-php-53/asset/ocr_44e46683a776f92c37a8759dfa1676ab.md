# ## How It Works

After displaying the XHTML page header, the script calls `displayForm()` to display a simple form requesting a URL to scan. If the form has already been submitted, it is processed by calling `processForm()`:

```
displayForm();

if ( isset( $_POST["submitted"] ) ) {
    processForm();
}
```
