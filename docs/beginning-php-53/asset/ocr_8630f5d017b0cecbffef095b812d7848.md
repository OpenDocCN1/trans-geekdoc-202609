To control the warp drive, the script creates a `ChiefEngineer` class. This class contains a single method,
`doWarp()`, that expects a warp factor. It then creates a new `WarpDrive` object and attempts to set the
correct speed.

In this example situation, the `ChiefEngineer` is a bit of a “yes man.” He just takes his order — the
required warp factor — and passes it straight to a new `WarpDrive` object via its `setWarpFactor()`
method. He doesn’t do any checking of the requested speed, nor does he attempt to catch any exceptions
that might be thrown by the `WarpDrive` object:

```
class ChiefEngineer {
public function doWarp( $factor ) {
$wd = new WarpDrive;
```
