preg_replace() supports two more optional arguments. The first argument, an integer, lets you restrict how many times the pattern (or patterns) is replaced in the target string (or strings):

```
```php
// Displays "71%, 83%"
echo preg_replace( "/\d+%(, | )*/", "", "14%, 59%, 71%, 83%", 2 );
```
```

This pattern replaces a percentage figure (followed optionally by commas and spaces) with an empty string. Because a limit argument of 2 was supplied, only the first two matches are replaced.

The second optional argument is a variable to hold the number of replacements performed. (If you want to use this argument but you don't want to limit the number of replacements, pass -1 for the previous argument.) The following example replaces the character '%' with the string "percent" four times, and displays the number of replacements:

```
```php
preg_replace( "/\%/", " percent", "14%, 59%, 71%, 83%", -1, $count );
echo $count; // Displays "4"
```
```

The number stored in $count is the total number of replacements performed. So if you pass an array of 10 target strings and text is replaced once in five of them, then $count equals 5.
