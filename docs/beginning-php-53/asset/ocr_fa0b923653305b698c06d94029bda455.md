# Changing Nodes and Attributes

Say there's a beetroot sale on, and you want to change the unit price of beetroot from $1.39 to $0.79. How would you go about this?

As you've already seen, the unitPrice elements are represented as DOMElement objects in the DOM, and their text nodes are represented as child DOMText objects. The DOMText class has various methods that allow you to manipulate the node's content, including appendData() to add text to the end of the existing text string, deleteData() to remove one or more characters from the string, insertData() to add new text at a given point in the string, replaceData() to replace text at a given point, and substringData() to extract a substring from the text.
