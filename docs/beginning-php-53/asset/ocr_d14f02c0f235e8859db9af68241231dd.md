# ## Exercise 1 Solution

In order to extract the total number of page views made by male and female visitors, you need to join the members table with the accessLog table. You can then use the sum() function to total the numVisits column, and group the results by gender using a GROUP BY clause. Using table and column aliases helps to keep the query and result set readable:

```
mysql> SELECT m.gender, sum( al.numVisits ) AS totalPageViews FROM members m,
accessLog al WHERE m.id = al.memberId GROUP BY m.gender;
+--------+---------------+
| gender | totalPageViews |
+--------+---------------+
| m | 6 |
| f | 3 |
+--------+---------------+
2 rows in set (0.00 sec)
```
