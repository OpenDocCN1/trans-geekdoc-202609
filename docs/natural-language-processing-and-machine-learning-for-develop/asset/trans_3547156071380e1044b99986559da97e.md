## **Matplotlib 中的水平线**

[Listing F.1](#appF.xhtml#listF.1) 显示了 `hlines1.py` 的内容，该文件说明如何使用 `Matplotlib` 绘制水平线。请回顾，平面中非垂直直线的方程是 y = m*x + b，其中 m 为斜率，b 为 y 截距。

***LISTING F.1: hlines1.py***

```python
import numpy as np
import matplotlib.pyplot as plt  # top line
x1 = np.linspace(-5,5,num=200)
y1 = 4 + 0*x1  # middle line
x2 = np.linspace(-5,5,num=200)
y2 = 0 + 0*x2  # bottom line
x3 = np.linspace(-5,5,num=200)
y3 = -3 + 0*x3
plt.axis([-5, 5, -5, 5])
plt.plot(x1, y1)
plt.plot(x2, y2)
plt.plot(x3, y3)
plt.show()
```

[Listing F.1](#appF.xhtml#listF.1) 使用 `np.linspace()` API 生成 200 个在 -5 到 5 之间均匀分布的数值作为横轴。变量 y1、y2、y3 分别通过 x1、x2、x3 定义，代表三条水平线。

[Figure F.1](#appF.xhtml#figF.1) 显示了三条水平线段，其方程在 [Listing F.1](#appF.xhtml#listF.1) 中。

## **Matplotlib 中的倾斜线**

[Listing F.2](#appF.xhtml#listF.2) 显示了 `diagonallines.py` 的内容，说明如何绘制倾斜线。

***LISTING F.2: diagonallines.py***

```python
import matplotlib.pyplot as plt
import numpy as np
x1 = np.linspace(-5,5,num=200)
y1 = x1
x2 = np.linspace(-5,5,num=200)
y2 = -x2
plt.axis([-5, 5, -5, 5])
plt.plot(x1, y1)
plt.plot(x2, y2)
plt.show()
```

[Listing F.2](#appF.xhtml#listF.2) 使用与 [Listing F.1](#appF.xhtml#listF.1) 相同的技术，定义 y1 = x1 和 y2 = -x2，从而产生倾斜线。

[Figure F.2](#appF.xhtml#figF.2) 显示了两条倾斜线段，其方程在 [Listing F.2](#appF.xhtml#listF.2) 中。

## **Matplotlib 中的平行倾斜线**

如果两条在欧几里得平面中的直线具有相同的斜率，则它们是平行的。[Listing F.3](#appF.xhtml#listF.3) 显示了 `parallellines1.py` 的内容，说明如何绘制平行倾斜线。

***LISTING F.3: parallellines1.py***

```python
import matplotlib.pyplot as plt
import numpy as np
# lower line
x1 = np.linspace(-5,5,num=200)
y1 = 2*x1
# upper line
x2 = np.linspace(-5,5,num=200)
y2 = 2*x2 + 3
# horizontal axis
x3 = np.linspace(-5,5,num=200)
y3 = 0*x3 + 0
# vertical axis
plt.axvline(x=0.0)
plt.axis([-5, 5, -10, 10])
plt.plot(x1, y1)
plt.plot(x2, y2)
plt.plot(x3, y3)
plt.show()
```

[Listing F.3](#appF.xhtml#listF.3) 使用与 [Listing F.1](#appF.xhtml#listF.1) 相同的技术，定义了三条斜线，它们彼此平行。

[Figure F.3](#appF.xhtml#figF.3) 显示了两条平行且倾斜的线段，其方程在 [Listing F.3](#appF.xhtml#listF.3) 中。

## **Matplotlib 中的点阵网格**

[Listing F.4](#appF.xhtml#listF.4) 显示了 `plotgrid.py` 的内容，说明如何绘制简单的网格。

***LISTING F.4: plotgrid.py***

```python
import numpy as np
from itertools import product
import matplotlib.pyplot as plt
points = np.array(list(product(range(3), range(4))))
plt.plot(points[:,0], points[:,1], 'ro')
plt.show()
```

[Listing F.4](#appF.xhtml#listF.4) 定义了 NumPy 变量 `points`，该变量包含 3 行 4 列的二维点列表。Pyplot API `plot()` 使用 `points` 变量绘制网格状图案。

[Figure F.4](#appF.xhtml#figF.4) 显示了如 [Listing F.4](#appF.xhtml#listF.4) 所示的点网格。

## **Matplotlib 中的点状网格**

[Listing F.5](#appF.xhtml#listF.5) 显示了 `plotdottedgrid1.py` 的内容，说明如何绘制“点状”网格图案。

***LISTING F.5: plotdottedgrid1.py***

```python
import numpy as np
import pylab
from itertools import product
import matplotlib.pyplot as plt
fig = pylab.figure()
ax = fig.add_subplot(1,1,1)
ax.grid(which='major', axis='both', linestyle='--')
[line.set_zorder(3) for line in ax.lines]
fig.show()  # to update
plt.gca().xaxis.grid(True)
plt.show()
```

[Listing F.5](#appF.xhtml#listF.5) 与 [Listing F.5](#appF.xhtml#listF.5) 类似，都绘制网格状图案；前者渲染“点状”网格，后者通过在 linestyle 参数中指定 '--' 实现“点状”网格。
