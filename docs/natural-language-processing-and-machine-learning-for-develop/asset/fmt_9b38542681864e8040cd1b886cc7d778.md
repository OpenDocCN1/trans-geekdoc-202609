## **What is Matplotlib?**

`Matplotlib` is a plotting library that supports `NumPy`, `SciPy`, and toolkits such as `wxPython` (among others). `Matplotlib` supports only version 3 of Python: support for version 2 of Python was available only through 2020. `Matplotlib` is a multiplatform library that is built on `NumPy` arrays.

You can use the `plt.style` directive to specify a style for figures. The following code snippet specifies the classic style of `Matplotlib`:

`plt.style.use('classic')`

The plotting-related code samples in this appendix use `pyplot`, which is a `Matplotlib` module that provides a MATLAB‑like interface. Here is an example of using `pyplot` to plot a smooth curve based on negative powers of Euler’s constant e:

```python
import matplotlib.pyplot as plt
import numpy as np
num_list = np.linspace(0, 10, 100)
exp_num_list = np.exp(-num_list)
plt.plot(num_list, exp_num_list)
plt.show()
```

## **Horizontal Lines in Matplotlib**

[Listing F.1](#appF.xhtml#listF.1) displays the contents of `hlines1.py` that illustrates how to plot horizontal lines using `Matplotlib`. Recall that the equation of a nonvertical line in the 2D plane is y = m*x + b, where m is the slope of the line and b is the y-intercept of the line.

***LISTING F.1: hlines1.py***

```python
import numpy as np
import matplotlib.pyplot as plt  # top line
x1 = np.linspace(-5,5,num=200)
y1 = 4 + 0*x1  # middle line
x2 = np.linspace(-5,5,num=200)
y2 = 0 + 0*x2  # bottom line
x3 = np.linspace(-5,5,num=200)
y3 = -3 + 0*x3
plt.axis([-5, 5, -5, 5])
plt.plot(x1, y1)
plt.plot(x2, y2)
plt.plot(x3, y3)
plt.show()
```

[Listing F.1](#appF.xhtml#listF.1) uses the `np.linspace()` API in order to generate a list of 200 equally spaced numbers for the horizontal axis, all of which are between -5 and 5. The three lines defined via the variables y1, y2, and y3, are defined in terms of the variables x1, x2, and x3, respectively.

[Figure F.1](#appF.xhtml#figF.1) displays three horizontal line segments whose equations are contained in [Listing F.1](#appF.xhtml#listF.1).

## **Slanted Lines in Matplotlib**

[Listing F.2](#appF.xhtml#listF.2) displays the contents of `diagonallines.py` that illustrates how to plot slanted lines.

***LISTING F.2: diagonallines.py***

```python
import matplotlib.pyplot as plt
import numpy as np
x1 = np.linspace(-5,5,num=200)
y1 = x1
x2 = np.linspace(-5,5,num=200)
y2 = -x2
plt.axis([-5, 5, -5, 5])
plt.plot(x1, y1)
plt.plot(x2, y2)
plt.show()
```

[Listing F.2](#appF.xhtml#listF.2) defines two lines using the technique that you saw in [Listing F.1](#appF.xhtml#listF.1), except that these two lines define y1 = x1 and y2 = -x2, which produces slanted lines instead of horizontal lines.

[Figure F.2](#appF.xhtml#figF.2) displays two slanted line segments whose equations are defined in [Listing F.2](#appF.xhtml#listF.2).

## **Parallel Slanted Lines in Matplotlib**

If two lines in the Euclidean plane have the same slope then they are parallel. [Listing F.3](#appF.xhtml#listF.3) displays the contents of `parallellines1.py` that illustrates how to plot parallel slanted lines.

***LISTING F.3: parallellines1.py***

```python
import matplotlib.pyplot as plt
import numpy as np
# lower line
x1 = np.linspace(-5,5,num=200)
y1 = 2*x1
# upper line
x2 = np.linspace(-5,5,num=200)
y2 = 2*x2 + 3
# horizontal axis
x3 = np.linspace(-5,5,num=200)
y3 = 0*x3 + 0
# vertical axis
plt.axvline(x=0.0)
plt.axis([-5, 5, -10, 10])
plt.plot(x1, y1)
plt.plot(x2, y2)
plt.plot(x3, y3)
plt.show()
```

[Listing F.3](#appF.xhtml#listF.3) defines three lines using the technique that you saw in [Listing F.1](#appF.xhtml#listF.1), where these three lines are slanted and also parallel to each other.

[Figure F.3](#appF.xhtml#figF.3) displays two slanted and also parallel line segments whose equations are defined in [Listing F.3](#appF.xhtml#listF.3).

## **A Grid of Points in Matplotlib**

[Listing F.4](#appF.xhtml#listF.4) displays the contents of `plotgrid.py` that illustrates how to plot a simple grid.

***LISTING F.4: plotgrid.py***

```python
import numpy as np
from itertools import product
import matplotlib.pyplot as plt
points = np.array(list(product(range(3), range(4))))
plt.plot(points[:,0], points[:,1], 'ro')
plt.show()
```

[Listing F.4](#appF.xhtml#listF.4) defines the NumPy variable `points` that defines a 2D list of points with three rows and four columns. The Pyplot API `plot()` uses the `points` variable to display a grid-like pattern.

[Figure F.4](#appF.xhtml#figF.4) displays a grid of points as defined in [Listing F.4](#appF.xhtml#listF.4).

## **A Dotted Grid in Matplotlib**

[Listing F.5](#appF.xhtml#listF.5) displays the contents of `plotdottedgrid1.py` that illustrates how to plot a “dotted” grid pattern.

***LISTING F.5: plotdottedgrid1.py***

```python
import numpy as np
import pylab
from itertools import product
import matplotlib.pyplot as plt
fig = pylab.figure()
ax = fig.add_subplot(1,1,1)
ax.grid(which='major', axis='both', linestyle='--')
[line.set_zorder(3) for line in ax.lines]
fig.show()  # to update
plt.gca().xaxis.grid(True)
plt.show()
```

[Listing F.5](#appF.xhtml#listF.5) is similar to the code in [Listing F.5](#appF.xhtml#listF.5) in that both of them plot a grid-like pattern; however, the former renders a “dotted” grid pattern whereas the latter renders a “dotted” grid pattern by specifying the value '--' for the linestyle parameter.
