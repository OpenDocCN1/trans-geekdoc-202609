### **异常处理**

与 JavaScript 不同，Python 不能直接将数字与字符串相加。不过，你可以使用 try/except 构造来检测非法操作，该构造与 JavaScript、Java 等语言中的 try/catch 类似。

下面是一个 try/except 代码块的示例：

```python
try:
    x = 4
    y = 'abc'
    z = x + y
except:
    print 'cannot add incompatible types:', x, y
```

运行上述代码后，由于变量 x 和 y 类型不兼容，except 代码块中的 print 语句会被执行。

在前面的附录中，你也看到过，减去两个字符串会抛出异常：

```python
>>> 'a' - 'b'
Traceback (most recent call last):
    File "<stdin>", line 1, in <module>
TypeError: unsupported operand type(s) for -: ‘str’ and ‘str’
```

处理这种情况的简单方法是使用 try/except 块：

```python
try:
    print('a' - 'b')
except TypeError:
    print('TypeError exception while trying to subtract two strings')
except:
    print('Exception while trying to subtract two strings')
```

上述代码块的输出如下：

TypeError exception while trying to subtract two strings 

如上所示，代码块首先指定更细粒度的异常类型 TypeError，随后使用通用的 except 语句捕获其他可能在 Python 代码执行过程中出现的异常。这种写法与 Java 代码的异常处理类似。

[Listing B.10](#appB.xhtml#listB.10) 显示 Exception1.py 的内容，演示了如何处理各种类型的异常。

***LISTING B.10: Exception1.py***

```python
import sys
try:
    f = open('myfile.txt')
    s = f.readline()
    i = int(s.strip())
except IOError as err:
    print("I/O error: {0}".format(err))
except ValueError:
    print("Could not convert data to an integer.")
except:
    print("Unexpected error:", sys.exc_info()[0])
    raise
```

[Listing B.10](#appB.xhtml#listB.10) 包含一个 try 语句块和三个 except 语句。如果 try 语句块中出现错误，则会先与第一个 except 语句中的异常类型进行比对。如果匹配成功，则执行随后的 print() 语句，并终止程序。如果不匹配，则会对第二个 except 语句进行类似的匹配测试。如果两个 except 语句都不匹配，则第三个 except 语句会捕获异常，打印信息并“抛出”异常。

你也可以在单个 except 语句中指定多种异常类型，如下所示：

except (NameError, RuntimeError, TypeError):
    print('One of three error types occurred')

上述代码块更为简洁，但无法确定发生了哪种异常。Python 允许你自定义异常，但此书的范围超出了该主题。

### **处理用户输入**

Python 可以通过 input() 或 raw_input() 函数从命令行读取用户输入。通常将用户输入的内容赋值给变量，该变量会包含用户从键盘输入的所有字符。用户输入在按下 <return> 关键键（该键会随输入字符一起被包含）时结束。[Listing B.11](#appB.xhtml#listB.11) 显示 UserInput1.py 的内容，该脚本提示用户输入姓名，然后使用插值输出回复。

***LISTING B.11: UserInput1.py***

```python
userInput = input("Enter your name: ")
print("Hello %s, my name is Python" % userInput)
```

[Listing B.11](#appB.xhtml#listB.11) 的输出如下（假设用户输入了 "Dave"）：

Hello Dave, my name is Python 

[Listing B.11](#appB.xhtml#listB.11) 中的 print() 语句使用 %s 进行字符串插值，该插值会在运行时替换 % 符号后面的变量值。这种功能在需要在运行时指定内容时非常有用。

用户输入可能会导致异常（取决于代码执行的操作），因此在代码中加入异常处理代码非常重要。

[Listing B.12](#appB.xhtml#listB.12) 显示 UserInput2.py 的内容，该脚本提示用户输入字符串，并尝试在 try/except 块中将字符串转换为数字。

***LISTING B.12: UserInput2.py***

```python
userInput = input("Enter something: ")
try:
    x = 0 + eval(userInput)
    print('you entered the number:', userInput)
except:
    print(userInput, 'is a string')
```

[Listing B.12](#appB.12) 在用户输入后加上 0，对转换结果进行数值运算。如果转换成功，则显示包含用户输入的消息；如果转换失败，则 except 代码块会打印提示信息，表明输入是字符串。

[Listing B.13](#appB.xhtml#listB.13) 显示 UserInput3.py 的内容，该脚本提示用户输入两个数字，并尝试在两个 try/except 块中计算它们的和。

***LISTING B.13: UserInput3.py***

```python
sum = 0
msg = 'Enter a number:'
val1 = input(msg)
try:
    sum = sum + eval(val1)
except:
    print(val1, 'is a string')
msg = 'Enter a number:'
val2 = input(msg)
try:
    sum = sum + eval(val2)
except:
    print(val2, 'is a string')

```
