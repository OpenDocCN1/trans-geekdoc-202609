
## 数据操作与 Pandas 数据框 (1)

作为一个简单的示例，假设我们有一家由两人组成的公司，用季度为单位跟踪收入和支出，我们希望计算每个季度的盈亏，以及整体的盈亏。

[Listing 2.16](#ch02.xhtml#list2.16) 显示了 pandas_quarterly_df1.py 的内容，该文件演示了如何定义一个包含收入相关数值的 Pandas 数据框。

***LISTING 2.16: pandas_quarterly_df1.py***

import pandas as pd
summary = { 'Quarter': ['Q1', 'Q2', 'Q3', 'Q4'], 'Cost': [23500, 34000, 57000, 32000], 'Revenue': [40000, 40000, 40000, 40000] }
df = pd.DataFrame(summary)
print("Entire Dataset:\\n",df)
print("Quarter:\\n",df.Quarter)
print("Cost:\\n",df.Cost)
print("Revenue:\\n",df.Revenue)

[Listing 2.16](#ch02.xhtml#list2.16) 定义了变量 summary，其中包含公司两人在各季度的成本和收入的硬编码信息。通常这些硬编码值会被从其他来源（如 CSV 文件）读取，因此本代码示例可视为展示 Pandas 数据框部分功能的简化方式。

变量 df 是基于 summary 变量数据的 Pandas 数据框。下面的三个 print 语句分别显示季度、每季度的成本和每季度的收入。[Listing 2.16](#ch02.xhtml#list2.16) 的输出如下：

在本节中，我们假设一家由两人组成的公司跟踪季度的收入和支出，并希望计算每个季度的盈亏以及整体的盈亏。

[Listing 2.17](#ch02.xhtml#list2.17) 显示了 pandas_quarterly_df2.py 的内容，演示了如何定义一个包含收入相关数值的 Pandas 数据框。

print("First Dataset:\\n",df)
df['Total'] = df.sum(axis=1)

## 数据操作与 Pandas 数据框 (3)

我们沿用上一节的假设：一家由两人组成的公司跟踪季度的收入和支出，并希望计算每个季度的盈亏以及整体的盈亏。此外，我们还希望计算列总计和行总计。

[Listing 2.18](#ch02.xhtml#list2.18) 显示了 pandas_quarterly_df3.py 的内容，演示了如何定义一个包含收入相关数值的 Pandas 数据框。

***LISTING 2.18: pandas_quarterly_df3.py***

import pandas as pd
summary = { 'Quarter': ['Q1', 'Q2', 'Q3', 'Q4'], 'Cost': [-23500, -34000, -57000, -32000], 'Revenue': [40000, 40000, 40000, 40000] }
df = pd.DataFrame(summary)
print("First Dataset:\\n",df)
df['Total'] = df.sum(axis=1)
df.loc['Sum'] = df.sum()
print("Second Dataset:\\n",df)  # or df.loc['avg'] / 3 #df.loc['avg'] = df[:3].mean() #print("Third Dataset:\\n",df)

## Pandas 数据框与 CSV 文件

前几个章节的代码示例中，硬编码数据直接写在 Python 脚本中。但读取 CSV 文件的情况也非常常见。可以使用 Python 的 csv.reader() 函数、NumPy 的 loadtxt() 函数，或 Pandas 的 read_csv() 函数（本节所示）来读取 CSV 文件内容。

[Listing 2.19](#ch02.xhtml#list2.19) 显示了 weather_data.py 的内容，演示了如何读取 CSV 文件，用其内容初始化 Pandas 数据框，并显示数据框的各个子集。

***LISTING 2.19: weather_data.py***

import pandas as pd
df = pd.read_csv("weather_data.csv")
print(df)
print(df.shape)  # rows, columns
print(df.head())  # df.head(3)
print(df.tail())
print(df[1:3])
print(df.columns)
print(type(df['day']))
print(df[['day','temperature']])
print(df['temperature'].max())

[Listing 2.19](#ch02.xhtml#list2.19) 调用了 Pandas 的 read_csv() 函数读取 weather_data.csv 文件，随后一系列 print() 语句显示 CSV 文件的不同部分。[Listing 2.19](#ch02.xhtml#list2.19) 的输出如下：
