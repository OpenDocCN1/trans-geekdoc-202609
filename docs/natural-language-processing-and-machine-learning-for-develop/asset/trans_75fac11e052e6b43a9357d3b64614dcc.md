
You可以修改Pandas中环境变量的默认值，示例如下：

```python
import pandas as pd
display_settings = {
    'max_columns': 8,
    'expand_frame_repr': True,
    # Wrap to multiple pages
    'max_rows': 20,
    'precision': 3,
    'show_dimensions': True
}
for op, value in display_settings.items():
    pd.set_option("display.{}".format(op), value)
```

如果你想让Pandas显示最多20行和8列，并且以3位小数显示浮点数，请包含前面的代码块。如果你想让输出“换行”到多页，请将`expand_frame_repr`设置为`True`。前面的for循环遍历`display_settings`并将选项设置为对应的值。

此外，下面的代码片段会显示所有Pandas选项及其当前值：

```python
print(pd.describe_option())
```

你可以使用选项和它们的值执行各种其他操作（例如`pd.reset()`方法用于重置值），如Pandas用户指南所述：

### **Pandas Data Frames**

简化而言，Pandas数据框是一个二维数据结构，方便以行为和列的方式来思考数据结构。数据框可以标记（行和列），列可以包含不同的数据类型。Pandas数据框的数据来源可以是数据文件、数据库表、Web服务等。Pandas数据框的特点包括：

*   数据框方法

*   数据框统计

*   分组、透视和重塑

*   处理缺失数据

*   连接数据框

本章中的Pandas代码示例展示了上述特点中的几乎所有功能。

*   显示数据框顶部

*   显示列数据类型

*   遍历列

*   对每列进行统计

*   查找缺失值

*   统计缺失值总数

*   计算缺失值百分比

*   排序表格值

*   打印摘要信息

*   缺失值超过50%的列

*   重命名列

本章包含了许多步骤的演示。

### **Pandas的替代方案**
