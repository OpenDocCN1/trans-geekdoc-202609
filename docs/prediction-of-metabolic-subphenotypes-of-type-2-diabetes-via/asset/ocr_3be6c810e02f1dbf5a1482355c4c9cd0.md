# # Data availability

The de-identified glucose values from CGM and venous, along with other data types used in this study, can be downloaded from the study data repository at https://storage.googleapis.com/gbsc-gcp-project-ipop_public/metabolic_subphenotype_db/metabolic_subphenotypes_db.zip.

# # Code availability

Codes used in this study are publicly available in GitHub at https://github.com/aametwally/Metabolic_Subphenotype_Predictor (ref. 64).
