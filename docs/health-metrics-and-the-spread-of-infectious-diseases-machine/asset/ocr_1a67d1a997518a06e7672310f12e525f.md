# Example: Modelling the Spread of COVID-19

We start by splitting the data into training and testing sets using the initial_split() function from the {sample} package. The training set will be used to train the models, while testing set will be used to evaluate the models' performance.

```
set.seed(10011)
# Split the data into training and testing sets
cv_split <- initial_split(cv19_data, prop = 0.8)
cv_train <- training(cv_split)
cv_test <- testing(cv_split)
```

Create a vfold_object for cross-validation with 10 folds. This object will be used to evaluate the models' performance during training.

```
set.seed(1001)
cv_folds <- vfold_cv(cv_train, v = 10)
```

We also define a recipe to preprocess the data, including log transformation and dummy encoding of categorical variables. The recipe is then used to create a workflow that combines the preprocessing steps with the model specifications.

```
cv_recipe <- recipe(~ , data = cv_train) %>%
step_all(all_numeric(), -all_outcomes()) %>%
step_dummy(all_nominal(), -all_outcomes) %>%
```
