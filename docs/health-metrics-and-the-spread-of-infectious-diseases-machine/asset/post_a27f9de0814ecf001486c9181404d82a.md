Data are aggregated to show the total population for all ages. Here, in particular, we show the use of geomtextpath::geom_sunline to add a label to the World line plot. `geomtextpath` is a nice R-package which allows you to add text along a path.

```r
all_ages <- popAgeId %>%
  group_by(year, name) %>%
  reframe(tot_pop=sum(pop))

all_ages %>%
  filter(name == "World") %>%
  ggplot(aes(x = year, y = tot_pop, group = name)) +
  geom_line(color = "grey", linewidth = all_ages %>% filter(name == "World")) +
  geomtextpath::geom_sunline(data = all_ages %>% filter(
    aes(label=name),
    color = "red", linewidth = 1) + 
  labs(title = "United Nations World Population Prospects [1949 - 2021]",
       x = "Year", y = "Population in thousands",
  caption = "Data Source: UN World Pop 2022 | Graphic: @fgazzelloni")
```

## Example: Pyramid Plot

Data are transformed to a long format to create a pyramid plot. We select the columns name, year, age, popF, and popM and pivot the data to a long format using the pivot_longer() function. We then create a new column value that contains positive values for male population and negative values for females.

```r
data <- popAge %>%
  select(name, year, age, popF, popM) %>%
  pivot_longer(cols = c(popF, popM),
              names_to = "sex",
              values_to = "population") %>%
  mutate(value = ifelse(as.integer(population * -1), as.integer(population))) %>%
  data %>% head()
```
