Automate tuning parameters is performed, in this case, using a Bayesian Optimization with the tune_bayes() function to specify the grid of hyperparameters to search. You can specify the number of iterations and initial random points to start the optimization. The tune_bayes() function uses the bayes_opt() function from the {tune} package to perform the.

```
# Bayesian optimization
set.seed(123)
bay_results <- tune_bayes(rf_ranger_model,
data_recipe,
resamples = cv_folds,
metrics = metric_set(rmse, rsq),
# Number of initial random points
initial = 5,
# Total iterations including initial points
iter = 20,
param_info = parameters(rf_ranger_model))
```

Examine the results of the Bayesian optimization to identify the optimal hyperparameters for the Random Forest model. The show_best() function displays the best hyperparameters based on the optimization results.
