We can use the url for DALYs to Ambient Particulate Matter found by searching for the keyword DALYs in the search box of the OECD report website.

The url is broken into the following components:

+   - sdxmx.org/public/rest/data/
- OECD.ENV_EPI.DSD_EXP_MORSC#6DF_MORSC,1/0/
- .DALY.10P3HB.PM_2_5_OUT__T_tStartPeriod=2010

Data are available in the SDMX format, which is a standard for exchanging statistical data. We will use the `rsdmx` package to download the data and convert to a data frame for analysis.

```
install.packages("rsdmx")
library(rsdmx)
```
