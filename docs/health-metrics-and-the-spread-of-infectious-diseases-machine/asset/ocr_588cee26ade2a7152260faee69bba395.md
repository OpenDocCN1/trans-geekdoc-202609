# 9.2 Example: Dengue Test Predictions for 2017-2021

Predictive modelling is a powerful tool for forecasting future trends. Here we test the Dengue's model made with `mlr3 meta-package in Chapter 8. The model was trained on data from 1990 to 2016 and now tested for 2017 to 2021.

First we load the original data and name it old_data.

```
library(tidyverse)
library(data.table)
```

```
old_data <- hmsidWR::infectious_diseases %>%%
arrange(year) %>%%
filter(case_name == "Dengue",\year==2017,
!location_name %in% c("Eswatini", "Lesotho")) %>%%
drop_na() %>%%
group_by(location_id) %>%%
select(-location_name, -case_name)
```

Then, we load Dengue data from 2017 to 2021 and name it new_data.

```
new_data <- hmsidWR::infectious_diseases %>%%
arrange(year) %>%%
filter(case_name == "Dengue",
year==2017,
!location_name %in% c("Eswatini", "Lesotho")) %>%%
drop_na() %>%%
group_by(location_id) %>%%
select(-location_name, -case_name)
```

In the next step, we use the trained models from Chapter 8 to make predictions on the new data. The predictions are stored in `new_pred_regr.cv_glmnet` and `new_pred_regr.cv.xgboost`. The resampling results: `r1$learners` and `r2$learners`, contain the trained models, in particular the first of 5 folds cross validation sample is used for the predictions.

```
new_pred_regr.cv_glmnet <-
r1$learners[[1]]$predictnewata(new_data,
task = r1$task)
```

This object contains the predictions for the new data, and we can access the response data by:

```
new_pred_regr.cv_glmnet$data$response
```

With the support of `data.table::as.table()` we create a new column ape to evaluate the Absolute Percentage Error (APE). Here are the first 6 rows of the data:

```
data.table::as.table(new_pred_regr.cv_glmnet) %>%%
mutate(ape = round(abs(truth - response)/truth*100) %>%%
head()
```
