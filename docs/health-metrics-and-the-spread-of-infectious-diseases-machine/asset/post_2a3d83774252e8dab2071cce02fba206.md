
 208 Spatial Data Modelling and Visualisation

For example, the application of Kriging used to predict the spatial distribution of Dengue outbreaks in regions like Khyber Pakhtunkhwa, Pakistan.⁶ Similarly, during the COVID-19 pandemic, Empirical Bayesian Kriging (EBK) was used to estimate the spatial distribution of COVID-19 cases in sub-Saharan Africa. This approach combined series of data with socio-economic indicators to create detailed spatial risk maps, aiding in understanding and controlling the outbreak.

Particularly useful for visualising the spatial dynamics of disease spread, while considering the impact of environmental factors such as temperature, or humidity on disease transmission: Kriging requires an estimation of the variance of points locations.

For estimating the variance, a variogram model is fit to the observed data. The variogram is a function of the distance $h$ that describes the degree of spatial dependence of a random field or stochastic process. It takes consideration of the spatial auto-correlation of the data. For instance, the number of cases observed in one location are supposed to be correlated with the number of cases observed nearby locations. This also considers environmental variables that interact with the disease transmission.

The variogram model:

```
$$\gamma(h) = \frac{1}{2N(h)} \sum_{i=1}^{N(h)} (Z(x_i) - Z(x_i + h))^2$$ (12.3)
```

Where: $\gamma(h)$ is the semivariance, $N(h)$ is the number of pairs of points separated by a distance $h$, $Z(x_i)$ is the value of variable at location $x_i$, and $Z(x_i + h)$ is the value of the variable at location $x_i + h$.

We use the gstat package to perform Kriging with `variogram()`.⁸,⁹ and gstat functions to perform Universal Kriging, a kriging method that allows to incorporate an external drift, such as temperature. The predictions are visualised on the grid of points generated earlier, with warmer colours indicating higher predicted values.

Or, just use the `kbitfit()` function¹⁰ which tries initial values and models to find the best fit for the variogram, the function can be used directly from the book package hmsidwr:`kbitfit()`.

Then, the Kriging technique is applied by using the `gstat:gstat()` function,¹¹ to predict the number of infected individuals at unobserved locations, based on the best variogram model.

Kriging Model Formula:

$Z(u) = \sum_{i=1}^{n} \lambda_i Z(x_i) \quad (12.4)$

Where: $Z(u)$ is the predicted value at location $u$, $\lambda_i$ is the weight assigned to each observed $Z(x_i)$, and $n$ is the number of observed values.

The predictions are visualised on the grid of points generated earlier, with warmer colours highlighting predicted values. The predictions are stored in the kpred red object, which contains the predicted values and the variance of the predictions.

```r
# Perform Kriging
k <- gstat::gstat(formula = presence - temperature, 
                  data = df_sf,
                  model = v_model)
```

```r
kpred <- predict(k, newdata = ctr_africa_grid_sf)
```
