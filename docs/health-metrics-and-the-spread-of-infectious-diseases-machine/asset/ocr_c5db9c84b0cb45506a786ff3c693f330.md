The center of mass is the average of the latitude and longitude of the infected individuals, weighted by the number of infected individuals at each location.

```
center_of_mass <- function(df) {
  longitude <- sum(df$cases * df$longitude) / sum(df$cases)
  latitude <- sum(df$cases * df$latitude) / sum(df$cases)
  c(longitude, latitude)
}
```

latitude = center_of_mass(df) [2])

Finally, plot the infections on the map of the Central African Republic, with the temperature data as a raster layer. The temperature data are displayed as a heatmap, warmer colours indicating higher temperatures. The infections are shown as points in the map, with different colours representing infected and non-infected locations.

Note, here a new package is used, the `ggscale` package, which is a package that allows you to add multiple colour to a single plot. This is useful when you want to visualise different variables with different colour in the same plot.
