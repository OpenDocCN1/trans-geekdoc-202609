# 12.4.6 Grid of Points

To create a grid of points we transform the df data as a features object with the st_as_sf() function from the {sf} package, specifying the longitude and latitude columns as the coordinates and the CRS as 4326³. Then, intersect the data with st_intersection(ctr_africa) to keep only the points within the country. Finally, select the relevant contours for the analysis.

```
df <- df %>%%
st_as_sf(coords = c("longitude", "latitude"),
# or use crs = 4326
crs = "proj+longlat +datum=WGS84") %>%%
st_intersection(ctr_africa) %>%%
st_make_valid()
```


To generate the grid of points to cover all Central African Republic we can also use the expand_grid() function from the {tidyr} package, which generates a series of points within specified bounding box, and the point in polygon (PtInPoly()) function from the {DescTools} package. The pip vector carries the information if the point is inside the polygon or not.
