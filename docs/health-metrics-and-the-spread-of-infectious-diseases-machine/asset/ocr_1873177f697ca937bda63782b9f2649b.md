To setup the SEIR compartments we start by defining the differential equations built by considering the rates of change of each compartment (S, E, I, R), the parameters (β, σ, γ), the initial state of the population (N = 1000), and the length of time in days (t = 160). Finally the ode() function is used to solve the differential equations and provide the output dataset.

```
SEIR <- function(time, state, parameters) {
  with(as.list(c(state, parameters)), {
    # Differential equations
    dS <- -beta * S * I / N
    dE <- beta * S * I / N - sigma * E
    dI <- sigma * E - gamma * I
    dR <- gamma * I
    # Return the rates of change
    list(c(dS, dE, dI, DR))
  })
}
```
