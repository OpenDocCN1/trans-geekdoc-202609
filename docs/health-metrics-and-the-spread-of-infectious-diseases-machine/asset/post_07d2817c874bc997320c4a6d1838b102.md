If we calculate the YLDs with the incidence of prevalence, we get the same results, because the incidence is the number of new cases in a given period, while the prevalence is the number of cases in a given period. So, we should consider the cumulative number of cases to calculate the prevalence. In order to calculate the cumulative number of cases, we need to group the data by year and month cycle.

And plot the YLDs by country and month cycle, with the x axis representing the YLDs formatted in millions.

```r
COVID19_dally %>%
filter(year %in% c(2020, 2021)) %>%
ggplot() + 
geom_col(aes(x = month_cycle, y = ylds,
         fill = country_region)) + 
scale_y_continuous(
  labels = scales::unit_format(unit = "M",
                               scale = 1e-6)) + 
scale_fill_grey(start = 0.2, end = 0.8) + 
labs(title = "YLDs by Country and Month Cycle",
     fill = "Country",
     x = "4-Month Cycle", y = "YLDs") + 
facet_wrap(~year) + 
theme(axis.text.x = element_text(angle = 45, hjust = 1))
```

We can see that the YLDs are highest in the United Kingdom, followed by the US, Canada, and China. The YLDs are highest in the first 4-month cycle (Jan-Apr) and decrease in the following cycles.

### 16.1 Epidemiology

**Malaria** is a mosquito-borne infectious disease that affects humans and animals. It is caused by parasitic protozoa belonging to the *Plasmodium* type. The symptoms of malaria typically include fever, vomiting, and headaches. If untreated, malaria can be fatal. Malaria is a major health concern in many tropical and subtropical regions, particularly Africa. Malaria dynamics are influenced by various factors, including prevalence, density of mosquito vectors, and environmental conditions. Transmission occurs when a mosquito bites a human, injecting parasites into the bloodstream. The parasites then multiply within the host's red cells, being transmitted back to mosquitoes, completing the cycle.

### 16.2 Mapping Malaria Outbreaks

Mapping outbreaks is essential for locating high-risk areas and guiding effective health interventions. Geographic Information Systems (GIS) enable the visualisation of malaria's spatial distribution, revealing hotspots. The analysis of malaria cases alongside environmental factors such as temperature, humidity, and vegetation cover allows the identification and development of targeted control strategies. In this example, we will use the `malariaAtlas` package to download data for Nigeria and visualise the distribution of cases in the country.

```r
# Load necessary libraries
library(malariaAtlas)
library(tidyverse)
library(sf)
library(naturalearth)

tidyverse_conflicts()
```

To download malaria data we can use the `getPR()` function, it requires the country and species. In this example, we will download data for Nigeria and the *Plasmodium falciparum* species.

```r
nigeria_data <- getPR(country = "Nigeria",
                          species = "Pf")
```

Data contains cases for 23 years spanning from 1985 to 2018. We can extract the relevant information (year_start, longitude, latitude, and number of cases) and convert the data to a spatial object using the `st_as_sf()` function from the `sf` package.

```r
nigeria_data %>%
arrange(year_start) %>%
select(year_start,longitude,positive) %>%
filter(!is.na(longitude) & !is.na(year_start))
```

```r
nigeria_data_sf <- nigeria_data %>%
st_as_sf(coords = c("longitude", "latitude"),
         crs = 4326)
```

## Mapping Malaria Outbreaks

And finally plot the malaria hotspots on a map of Nigeria to visualise the distribution of malaria cases in the country.

```r
# Plot Malaria Hotspots with expanded spatial data range
ggplot(
geom_sf(data = nigeria_sf,
  fill = "gray90",
  color = "white") +
geom_sf(data = nigeria_data_sf,
  aes(size=positive, color = positive),
  alpha=0.5))+
scale_color_viridis_c(option = "plasma", name = "Malaria Cases") +
guides(size = "none")
labs(title = "Malaria Hotspots in Nigeria",
  subtitle = "1985-2018",
  caption = "Source: Malaria Atlas Project | @fgazzelloni")
theme(legend.position = "right")
```
