Where, $p$ is the probability of the incidence of the disease, $\frac{p}{1-p}$ is the log-odds (logit) of the disease incidence, $eta_0$ is the intercept term, $eta_1, eta_2, \dots, eta_k$ are the coefficients of the predictor variables, and $X_2, \dots, X_k$ are other potential predictors that influence the disease incidence.

To convert the log-odds back to the **probability of disease incidence** given the value of SDI:

```
$p = \frac{1}{1+e^{-(\beta_0+\beta_1\times SDI)}} \quad (9.4)$

# 9.4.1 SDI Data and Packages

In this example we use the SDI data from 1990 to 2019, for 3 locations the Global region and evaluate the difference in SDI average across the time.

We start by loading the data and required libraries. We use the `hmsidWR` package, which contains the SDI data from 1990 to 2019, the data is available in the `sdi90_19` object, and the `fp33` package for time series analysis mentioned in Section 8.2.3. We also show how to use the `|>` native pipe operator to filter and manipulate the data, instead of the `%>%` pipe operator from `dplyr` package.

```
library(tidyverse)
library(hmsidWR)
library(fp33)

hmsidWR::sdi90_19 |> head()
# # A tibble: 6 x 3
# #   location  value
# # <chr>    <dbl> <dbl>
# # 1 Global  1990 0.511
# # 2 Global  1991 0.516
# # 3 Global  1992 0.521
# # 4 Global  1993 0.525
# # 5 Global  1994 0.529
# # 6 Global  1995 0.534

sdi90_19 |>
  filter(location %in% c("Global", "Italy"
    "France", "Germany")) |>
  ggplot(aes(x = year, y = location),
    linetype =) +
  geomtextpath(geom_textline(label = location),
    hjust = 0, vjust = 0) +
  labs(title = "Social Demographic Index (SDI) from 1990 to 2019") +
  theme(legend.position = "none")
