# 6.4.1.1 Regression Loss Functions

Regression loss functions are for regression tasks where the prediction involves continuous numbers, and include:

- - Mean Squared Error (MSE): MSE calculates the average of the squares of the errors, i.e., the average squared between the estimated values and the actual value. Its loss function is sensitive to outliers as it weights errors before averaging.

```
MSE = \frac{1}{n} \sum_{i=1}^{n}(\hat{Y}_i - Y_i)^2
```

- - Mean Absolute Error (MAE): MAE measures the average magnitude of the errors in a set of predictions, without considering their direction (i.e., it averages the differences between predictions and actual outcomes). Unlike MSE, MAE is not overly sensitive to outliers, making it suitable for datasets with.

```
MAE = \frac{1}{n} \sum_{i=1}^{n}|\hat{Y}_i - Y_i|
```

- - Mean Squared Logarithmic Error (MSLE): MSLE is used when the data is exponential, MSLE transforms the target to.

```
MSLE = \frac{1}{n} \sum_{i=1}^{n}(\log(\hat{Y}_i + 1) - \log(Y_i + 1))^2
```

# 6.4.1.2 Classification Loss Functions

Classification loss functions are for classification tasks, where the output is categorical, typical loss functions include:

- - Binary Cross-Entropy: Also known as log, this function measures the performance. It is particularly useful for binary.

```
CrossEntropy = -\frac{1}{n} \sum_{i=1}^{n}[y_i \log(\hat{y}_i) + (1-y_i) \log(1-\hat{y}_i)]
```

- - Hinge Loss: Often used with Support Vector Machines (SVM), hinge evaluates the margin for.

```
HingeLoss = \frac{1}{n} \sum_{i=1}^{n}\max(0, 1 - y_i\hat{y}_i)
```
