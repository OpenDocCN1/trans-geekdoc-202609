Our specific task is to calculate the Years of Life Lost (YLLs) attributable to stroke in the year 2019 for the Global region. We filter the location to be "Global" and the cause to be "Stroke". The use of str_detect() is to match the cause of death containing a specific word, it is very useful when the cause of death is not exactly containing one word.

```
deaths_stroke <- hmsidWR::deaths2019 %>%
arrange(age) %>%
filter(location == "Global",
       str_detect(cause, "Stroke")) %>%
select(-location, -cause, -upper, -lower)
```
