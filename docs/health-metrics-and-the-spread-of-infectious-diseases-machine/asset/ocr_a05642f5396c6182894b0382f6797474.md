And this is explained by the variation of the predictors in time, the calculation is a derivative.
Recall that the derivative of a constant is 0, in our case $\beta_0$ is the constant.

```
$$\frac{dy}{dt} = \frac{d(\beta_0 + \beta_1x)}{dt} = \beta_1\frac{dx}{dt}$
(6.11)
```

This equation describes how $y$ changes with respect to time $t$, taking into account the rate of change of $x$ with respect to time $t$, and the constant slope $eta_1$ of the line.

```
$y' = \beta_1\frac{dx}{dt}$
(6.12)
```

The Equation 6.12 will be used in the model to describe how individuals move between compartments over time.
