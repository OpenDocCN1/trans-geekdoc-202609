## 6.3.2.3 Optimization with Tidymodels

Random Forest is a powerful machine learning algorithm that can be tuned to improve its performance. The tuning process involves selecting the optimal values for the hyperparameters of the model, as in the case of a random forest, the number of trees, the number of variables to consider at each split, and the minimum number of data points required to split a node. These hyperparameters can significantly impact the model's performance, and tuning them can help improve the model's accuracy and generalisation to new data.

For this task we use the {tidymodels} package, a collection of packages for modelling and machine learning using the tidy principles. The {tidymodels} package provides a consistent interface for modelling tasks, making it easier to build, tune, and evaluate machine learning models.

```r
library(tidymodels)
library(dials)
tidymodels::prefer()
```

```r
# Spending data
set.seed(1231) # Set seed for reproducibility
```

```r
# Split the data into training and testing sets
split <- initial_split(simulated_data, prop = 0.8)
train_data <- training(split)
test_data <- testing(split)
```

```r
# Create a resampling scheme: 5-fold cross-validation
cv_folds <- vfold_cv(train_data, v = 5)
```

```r
# Create a recipe for data preprocessing
data_recipe <- recipe(I ~ ., data = train_data) %>%
  step_nz(all_predictors()) %>%
  step_normalize(all_numeric())
```

```r
# Define the Random Forest model
rf_ranger_model <-
  random_forest(trees = tune(), min_n = tune()) %>%
    set_engine("ranger") %>%
    set_mode("regression")
```

Automate tuning parameters is performed, in this case, using a Bayesian Optimization with the tune_bayes() function to specify the grid of hyperparameters to search. You can specify the number of iterations and initial random points to start the optimization. The tune_bayes() function uses the bayes_opt() function from the {tune} package to perform the.

```r
# Bayesian optimization
set.seed(123)
bay_results <- tune_bayes(
  rf_ranger_model,
  data_recipe,
  resamples = cv_folds,
  metrics = metric_set(rmse, rsq),
  # Number of initial random points
  initial = 5,
  # Total iterations including initial points
  iter = 20,
  param_info = parameters(rf_ranger_model)
)
```

Examine the results of the Bayesian optimization to identify the optimal hyperparameters for the Random Forest model. The show_best() function displays the best hyperparameters based on the optimization results.

```r
# Summarise the tuning results
show_best(bay_results, type = "rds")
# A tibble: 5 x 6
# .metric .estimator .rmse .rsq .trees .min_n
# <chr>     <dbl>    <dbl>   <dbl>   <int>  <int>
# 1 rmse     5.4194   0.9821  500    10
```

Finally, we can use the hyperparameters to train the Random Forest model.

```r
# Finalize the model
best_params <- collect_best(bay_results, metric = "rmse")
final_model <- finalize_model(rf_ranger_model, best_params)

# Fit the model
final_fit <- fit(final_model, data_recipe, data = train_data)

# Predict and evaluate on test data
predictions <- predict(final_fit, new_data = test_data)
augmented <- augment(final_fit, new_data = test_data)
eval_metrics <- metrics(augmented, truth = I)
# A tibble: 3 x 3
# .metric .estimator .std
# <chr>     <dbl>    <dbl>
# 1 rmse     5.4194   0.34
# 2 rsq      0.9821   0.01
# 3 mae      2.34      0.15

# Calculate Root Mean Squared Error (RMSE)
err <- (test_data$I - predictions$.pred)^2
rmse <- sqrt(mean(err, na.rm = T))
paste("RMSE", rmse)
# [1] "RMSE": 5.4194
```

### 6.3.3.1 INLA: An Empirical Bayes Approach to GAMs

In this example is a simulation of an epidemic in 100 days based on temperature level and number of cases simulated with a random poisson distribution.

The model uses the INLA - nested Laplace approximation⁸ model, an excellent choice for applications requiring repeated model fitting. The INLA approach is particularly useful for fitting complex models, as Generalised additive models (GAMs), which involve non-linear relationships between predictors and the response variable.
