# Let's start constructing a life table

The Global Life Tables are included in the {hmsidwR} package as gho_lifetables dataset. This dataset has been released by the WHO, and contains various indicators.

The construction of the Global Life Tables takes consideration of age-specific mortality patterns, which are the main improvements made on life tables construction since the first set of model tables published by the United Nations in 1955, see² for more information about a detailed procedure.

To have a look at the package documentation for this dataset, use:

```

library(tidyverse)
```

The indicator of interest for re-building a life table is:

+   - 1lx - number of people left alive at age x
- age

These two elements are crucial for building the life tables.

```
lx <- hmsidwR::gho_lifetables %>%%
distinct() %>%%
filter(
  indicator == "lx",n  year == "2019"
)
```

```
x <- 1lx %>%%
filter(sex == "female") %>%%
select(x = age)
```
