In this example we consider the number of DALYs per 100,000 inhabitants due to rabies in Asia and the Global region, our response variable, the dataset is made available in the {hmidwR} package. It is composed of 240 observations and 7 variables: measure, location, cause, year, upper, lower.

```
library(tidyverse)
hmidwR::rabies %%
filter(year >= 1990 & year <= 2019) %%
select(-upper, -lower) %%
head()
```

Selecting only the cause == **Rabies**, the first thing to notice is that deaths rates and DALYs are on different units, rates and years respectively.

```
library(tidyverse)
hmidwR::rabies %%
filter(year >= 1990 & year <= 2019) %%
select(-upper, -lower) %%
pivot_wider(names_from = measure, values_from = val) %%
filter(cause == "Rabies") %%
rename(dx_rabies = Deaths, dalys_rabies = DALYs) %%
select(-cause))
```

It can be seen that the number of deaths to rabies is much lower than the number of DALYs. This difference in scale can affect the model's ability to learn from the data. To address this issue, we can scale and centre the numeric variables to make them more comparable.

```
p1 <- rabies %%
gplot(aes(x = year, group = location, linetype = location)) +
geom_line(aes(y = dx_rabies),
  linewidth = 1) + 
geom_line(aes(y = dalys_rabies))
```
