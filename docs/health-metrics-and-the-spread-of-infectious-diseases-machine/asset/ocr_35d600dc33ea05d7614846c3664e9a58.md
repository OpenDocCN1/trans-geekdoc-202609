```
# (Intercept) Prevalence year

```

Considering only the fixed effects the model function becomes:

```
$YLDs = 67.79889 + 0.00016 * Prevalence - 0.03364 * year  (9.12)
```

In particular prevalence, a coefficient of 0.00016 means that for each unit in prevalence, YLDs increase by 0.00016, while a year coefficient of -0.03364 means that for each unit in year, YLDs decrease by 0.03364.

Looking at the random effects, we can see how the model accounts for the variability across different locations.
