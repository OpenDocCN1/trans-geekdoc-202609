The summary of this model shows the intercept value to be the estimated average of the death rates. We can look at the distribution of the death rates with a histogram:

```
hist1 <- meningitis %>%
gplot(aes(x = deaths)) +
  geom_histogram(bins = 10,
                 fill = "grey70", color = "grey40") +
  geom_vline(aes(intercept = mean(deaths)),
             color = "black",
             size = 2,
             linetype = "dashed") +
  labs(title = "Histogram of Death Rates due to Meningitis",
       x = "Death Rates", y = "Count") +
  theme(legend.position = "bottom",
        legend.title = element_blank())
```

To investigate the non linear relationship between the number of deaths and the two risk factors, we can use a Generalized Additive Model (GAM) with s() function from the {mgcv}. The s() function is used to fit smooth curves to the model, which allows us to capture non-linear relationships between the predictors and the response variable.

```
library(mgcv)
mod1 <- gam(deaths ~ s(smoking), data = meningitis)
mod2 <- gam(deaths ~ s(smoking) + s(pm25),
            data = meningitis)
```
