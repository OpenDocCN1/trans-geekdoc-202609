The social media data is simulated and consists of 100 individuals (n) over 10 (p) days, with an infection vector, and 10 features (xi), including social distancing adherence, mask usage (always, sometimes, never), hygiene practices (times per day washing or sanitizing), work or study environment (remote in-person), participation in gatherings (number of others attended), and contacting status (to a confirmed case). All values are standardized obtained from a normal distribution.

```
set.seed(123)
n <- 1000 # number of samples
p <- 10 # number of features
# Generate random features and labels
social_features <- matrix(rnorm(n * p),
                           row = n, ncol = p)
infection_labels <- sample(0:1, n, replace = TRUE)
# Combine into a data frame
social_data <- data.frame(social_features,
social_data$infection <- infection_labels
```

Define the model using the keras_sequential() function, and add layers with the layer_dense() and layer_activation() functions. Each layer model will apply a transformation to the input data, and the activation function will introduce non-linearity to the model.

Here we use a simple model with two layers and a ReLU and a Sigmoid as activation functions. These functions have specific shapes that allow the model to learn complex patterns in the data. Any time layer is done the output is passed to the next layer.

Although the layer_dropout() is not actually used in this application, it could be added to the model as a layer that drops out results under specified requirements. The function is used to prevent overfitting by randomly setting a fraction of units to zero during training.

The model concludes with one more layer_dense() with activation used to finally activate the output with a trained function. In this case a sigmoid, but also a softmax function could be used.
