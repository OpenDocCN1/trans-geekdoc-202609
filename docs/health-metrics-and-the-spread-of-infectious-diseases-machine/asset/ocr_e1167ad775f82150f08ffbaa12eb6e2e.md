# Example: Pyramid Plot

```
library(gganimate)
pyramid_gif <- pyramid + 
  transition_states(year,
                    transition_length = 1,
                    state_length = 2) +
  enter_fade() + 
  exit_fade() + 
  ease_aes("cubic-in-out")

animate(pyramid_gif,
  fps = 72, duration = 6,
  width = 1200, height = 1400, res = 180,
  renderer = gifski_renderer("images/12_unp_pyramid.gif"))
```
