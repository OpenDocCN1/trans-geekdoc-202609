## 16.4 Model Refinement

To improve the model's performance, we can refine the model by adjusting parameters such as 'mtry' in Random Forest. For example, increase the number of folds in cross-validation, adjust the tuning caret, or add additional features to improve the model's performance.

```r
# Increase the number of folds in cross-validation
train_control <- trainControl(method = "cv",
number = 10)

# Scaling data in caret
rf_model2 <- train(
  positive = year + lag_1 + lag_2 + lag_3,
  data = train,
  method = "rf",
  trControl = train_control,
  tuneGrid = expand.grid(mtry = 2:4),
  preProcess = c("center", "scale"))
```
