Here we can see how COVID-19 cases and deaths are distributed along the years with a simple line:

```
COVID19 %>%
gplot(aes(x = date, y = cases,
  group = country_region)) +
  geom_line(color = "grey"),
  linewidth = 0.2) +
  geomtextpath::geom_textline(
  data = COVID19_countries,
  aes(label = country_region),
  show.legend = F) +
  scale_y_log10() +
  labs(title = "COVID-19 Cases by Country",
  x = "Date",
  y = "Cases") %>%
```
