Another way to extract the ROC curve is to use the pROC package and the roc() function. The roc() function takes the observed values and the predicted probabilities as arguments and returns an object containing the ROC curve.

```
roc_obj <- pROC::roc(rf_preds$Stroke,
                    rf_preds$pred_N)

roc_obj%%%
proC::auc()%%%%%
round(2)
# [1] 0.68
```

The roc_obj object provides information about the area under the ROC curve. In this case we have an AUC of 0.68. The AUC is a measure of the model's performance, values closer to 1 indicate better performance.
