## 案例研究：分析血铅水平与高血压

在本章中，我们使用第4章中看到的NHANESsample数据集。该样本包含来自NHANES 1999-2018的铅、血压、BMI、吸烟状况、饮酒情况和人口统计学变量。我们进行了变量选择和特征工程，以复现Huang (2022)所做的预处理。我们将在第13章进一步复现Huang (2022)的回归分析。使用帮助运算符?NHANESsample查看变量描述。请注意，在此分析中我们忽略了调查权重。

```r
library(HDSinRdata)
library(tidyverse)
library(gt)
library(gtsummary)

data("NHANESsample")
```

我们的分析重点是通过假设检验来考察不同性别下高血压与血铅水平之间的关联。我们首先选择了一些我们认为可能相关的人口统计学和临床变量，包括年龄、性别、种族、体质指数和吸烟状况。我们进行了完整案例分析，并删除了任何存在缺失数据的观察对象。

```r
NHANESsample <- NHANESsample %>%
  select("AGE", "SEX", "RACE", "SMOKE", "LEAD", "BMI_CAT",
         "HYP", "ALC") %>%
  na.omit()
```

我们首先按高血压状态分层生成汇总表。不出所料，两组在所有纳入变量上均存在统计学显著差异。我们还观察到，高血压患者的血铅水平更高，且男性参与者比例更高。

### 13.1 简单线性回归

在第4章中，我们对该数据进行了初步探索性分析。在本章中，我们使用线性回归来理解血铅水平与收缩压之间的关联，并调整可能的混杂因素。复现Huang (2022)的分析时，我们为收缩压和舒张压创建了汇总列。如果一个观察对象只有一次血压读数，则使用该值。如果有多次血压读数，则删除第一次读数并对其余读数取平均值。我们通过删除任何含NA值的观察对象进行完整案例分析。最终得到30,405个观察对象。

```r
NHANESsample$SBP <- apply(NHANESsample[,c("SBP1", "SBP2", "SBP3",
                                      "SBP4")], 1,
                         function(x) case_when(sum(!is.na(x)) == 0 ~ NA,
                                               sum(!is.na(x)) == 1 ~ sum(x, na.rm = TRUE),
                                               sum(!is.na(x)) > 1 ~ mean(x[-1],
                                                                         na.rm = TRUE)))
NHANESsample$DBP <- apply(NHANESsample[,c("DBP1", "DBP2", "DBP3",
                                      "DBP4")], 1,
                         function(x) case_when(sum(!is.na(x)) == 0 ~ NA,
                                               sum(!is.na(x)) == 1 ~ sum(x, na.rm = TRUE),
                                               sum(!is.na(x)) > 1 ~ mean(x[-1],
                                                                         na.rm = TRUE)))
nhanes_df <- na.omit(subset(NHANESsample,
                            select=-c(SBP1, SBP2, SBP3, SBP4, DBP1,
                                      DBP2, DBP3, DBP4)))

dim(nhanes_df)
#> [1] 30405    15
```
