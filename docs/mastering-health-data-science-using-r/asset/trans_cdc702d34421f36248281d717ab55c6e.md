## 2.5 数据框

矩阵可以存储像降雨量数据那样所有元素类型都相同的数据。然而，如果我们要记录更复杂的数据记录，还需要允许不同的测量类型：这正是数据框的用武之地。数据框类似于矩阵，因为数据框也是二维的，但与矩阵不同的是，数据框允许每一列具有不同的类型（见图 2.4）。在这种情况下，每一行对应一条数据记录（或一个观测值），每一列对应一个不同的变量。

| 姓名  | 访问次数 | 会员 |
|---|---:|---|
| Alice | 368 | TRUE |
| Bob | 47 | FALSE |
| Carol | 3 | TRUE |
| Devon | 65 | FALSE |
| Eve | 2 | FALSE |

图 2.4：数据框示例。

例如，假设在一项研究中，我们想记录每天的温度、降雨量和星期几。温度和降雨量可以是数值类型，但星期几是字符类型。我们使用 `data.frame()` 函数创建一个数据框。请注意，我为每个向量（列）都提供了列名。

`head()` 函数打印数据框的前六行（以避免打印非常大的数据集）。在我们的例子中，由于只创建了四行，所以显示了全部数据。列名及其类型也会显示出来。相比之下，`tail()` 函数打印数据框的最后六行。

```r
weather_data <- data.frame(day_of_week = c("Monday", "Tuesday",
                                      "Wednesday", "Monday"),
                           temp = c(70, 62, 75, 50),
                           rain = c(5, 0.1, 0.0, 0.5))
head(weather_data)
#>    day_of_week temp rain
#> 1       Monday  70  5.0
#> 2      Tuesday  62  0.1
#> 3    Wednesday  75  0.0
#> 4       Monday  50  0.5
```

dim()、nrow() 和 ncol() 函数分别返回数据框的维度、行数和列数。

```r
dim(weather_data)
#> [1] 4 3
nrow(weather_data)
#> [1] 4
ncol(weather_data)
#> [1] 3
```

可以使用 colnames() 或 names() 函数查找（或赋值）列名。这些在我创建数据时就已经指定了。另一方面，当前的行名是索引。

```r
colnames(weather_data)
#> [1] "day_of_week" "temp"        "rain"
rownames(weather_data)
#> [1] "1" "2" "3" "4"
names(weather_data)
#> [1] "day_of_week" "temp"        "rain"
```

与矩阵一样，我们使用 rownames() 函数将行名更新为更具信息性的名称。

```r
rownames(weather_data) <- c("6/1", "6/2", "6/3", "6/8")
head(weather_data)
#>    day_of_week temp rain
#> 6/1      Monday  70  5.0
#> 6/2     Tuesday  62  0.1
#> 6/3   Wednesday  75  0.0
#> 6/8      Monday  50  0.5
```

### 2.5.1 索引数据框

我们可以像对矩阵那样，使用索引来选择数据框中的元素。在接下来的代码中，我们先访问单个值，然后访问数据框的一个子集。返回的子集本身也是一个数据框。注意第二行返回的是一个数据框。

```r
weather_data[1, 2]
#> [1] 70
weather_data[1, c("day_of_week", "temp")]
#>   day_of_week temp
#> 6/1    Monday   70
```

另一种访问数据框列的实用方法是使用 $ 访问器加列名。

```r
weather_data$day_of_week
#> [1] "Monday"   "Tuesday"  "Wednesday" "Monday"
weather_data$temp
#> [1] 70 62 75 50
```

day_of_week 列是一个类别型列，它只能取有限数量的值。对于这类列，像之前那样将其转换为因子（factor）通常会很有用。

```r
weather_data$day_of_week <- factor(weather_data$day_of_week)
levels(weather_data$day_of_week)
#> [1] "Monday"   "Tuesday"  "Wednesday"
```

### 2.5.2 修改数据框

与矩阵一样，我们可以通过索引条目来更改数据框中的值。

```r
weather_data[1, "rain"] <- 2.2
weather_data
#>   day_of_week temp rain
#> 6/1    Monday   70 2.2
#> 6/2   Tuesday   62 0.1
#> 6/3 Wednesday   75 0.0
#> 6/8    Monday   50 0.5
```

rbind() 和 cbind() 函数对数据框的作用方式与对矩阵相同。不过，添加列的另一种方式是直接使用 $ 访问器。我们添加一个名为 aq_warning 的类别型列，用于指示当天是否有空气质量警告。

```r
weather_data$aq_warning <- as.factor(c(1, 0, 0, 0))
```

## 2.6 列表

数据框实际上是另一种称为列表（list）的数据结构的特殊类型。列表是在同一个名称下的一组对象的集合。这些对象可以是向量、矩阵、数据框，甚至是其他列表！列表中的不同成员之间在大小、类型或其他属性上不必有任何关联。我们使用 list() 函数创建一个示例列表，该函数接受一系列对象。下面列表中每个元素的类型是什么？

```r
ex_list <- list("John", c("ibuprofen", "metformin"),
                c(136, 142, 159))
print(ex_list)
#> [[1]]
#> [1] "John"
#>
#> [[2]]
#> [1] "ibuprofen" "metformin"
#>
#> [[3]]
#> [1] 136 142 159
```

我们可以使用索引访问每个元素。注意，与向量索引不同，使用单括号会返回另一个列表，该列表是包含该索引处对象的子列表。

```r
print(class(ex_list[2]))
#> [1] "list"
ex_list[2]
#> [[1]]
#> [1] "ibuprofen" "metformin"
```

我们可以使用双括号访问该索引处实际的数值向量。

```r
ex_list[[2]]
#> [1] "ibuprofen" "metformin"
```

不过，更常见的做法是为列表的元素命名，以便于访问。让我们重新创建这个列表，但这次为每个对象指定名称。

```r
ex_list <- list(name="John",
                medications = c("ibuprofen", "metformin"),
                past_weights = c(136, 142, 159))
print(ex_list)
#> $name
#> [1] "John"
#>
#> $medications
```
