### 14.2.1 受试者工作特征曲线

我们现在绘制受试者工作特征（ROC）曲线，并计算曲线下面积（AUC）。pROC 包中的 roc() 函数用于构建 ROC 曲线。该函数有几种指定响应变量和预测变量的方式。例如，我们可以指定响应向量 response 和预测向量 predictor。默认情况下，对于 0/1 结果，roc() 函数假设类别 0 为对照组，类别 1 为病例组。我们也可以在 levels 参数中分别指定对照组和病例组的响应值。此外，该函数假设预测向量指定的是类别 1 的预测概率。如果相反，我们可以更改参数 direction = ">"。我们可以通过调用 plot() 函数来绘制 ROC 曲线。通过添加 AUC（print.auc = TRUE）和最大化灵敏度 + 特异度的阈值（print.thres = TRUE），我们可以添加一些额外信息。

```r
roc_mod <- roc(predictor = pred_probs,
   response = as.factor(mod_start$y),
   levels = c(0,1), direction = "<")
plot(roc_mod, print.auc = TRUE, print.thres = TRUE)
```

![](img/58a554e865d49ca347d9a3f76f8f0812_242_0.png)

如果我们想更详细地了解这条曲线，可以使用 coords() 函数来查找用于创建曲线的每个阈值的坐标。参数 x = "all" 表示我们希望找出所有阈值，但我们也可以指定仅返回局部最大值。

```r
roc_vals <- coords(roc = roc_mod, x = "all")
```

### 14.2.2 校准图

另一个有用的图是校准图。这种图按估计概率对数据进行分组，并将平均概率与类别 1 中观测值的实际比例进行比较。它直观地展示了估计分布与真实分布之间的接近程度。有几个包可以创建校准图，但我们演示如何使用 **ggplot2** 包来实现。首先，我们创建一个包含预测概率和结果变量的数据框。然后，我们使用 `cut()` 函数根据预测概率将这些数据划分为 `num_cuts` 组。在每个组内，我们计算模型的预测均值，以及观测比例和估计标准误差。
