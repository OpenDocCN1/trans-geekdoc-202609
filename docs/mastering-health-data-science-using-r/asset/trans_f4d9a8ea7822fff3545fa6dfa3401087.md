## R 中的数据结构

在本章中，我们演示 R 中关键的**数据结构**。数据结构即信息在 R 中的存储方式，指的是我们可以在 R 中创建的对象的类型。我们使用的数据结构会告知 R 如何解释我们的代码。任何**对象**都是数据结构的一个具名实例。例如，对象 `ex_num` 是一个数值型的向量。

```
ex_num <- 4
```

R 中的主要数据结构包括**向量**、**因子**、**矩阵**、**数组**、**列表**和**数据框**。这些结构根据其维度和存储的数据类型来区分。例如，我们可能有一个包含所有数值的一维向量，或者有一个包含行和列、其中一列是数值而另一列是字符的二维数据框。在图 2.1 中，上方是两个不同类型的向量（字符型与数值型），下方是一个矩阵和一个数据框。在本章中，我们将介绍除数组之外的所有数据结构。数组是矩阵的扩展，支持超过二维的数据，但本书涉及的应用不需要用到数组。

### 2.1 数据类型

R 中的每个值都有一个类型：**逻辑型**、**整数型**、**双精度型**或**字符型**。我们可以将它们视为所有数据结构的构建块。我们使用 `typeof()` 函数来查找向量 `ex_num` 的类型，结果显示 `ex_num` 的值是**双精度型**。双精度型是带有存储小数的数值。

```
typeof(ex_num)
#> [1] "double"
```

另一方面，**整数型**是不包含小数的整数。

```
```r
TRUE + FALSE + TRUE
#> [1] 2
```
```

为了创建所有这些对象，我们使用了第 1 章中讨论的赋值运算符 <-。您可能在其他代码中看到使用 = 代替。虽然 = 也可以用于赋值，但更标准的做法是使用 <-。

创建包含多个值的向量的一种方法是使用组合函数 `c()`。在下面的代码中，我们创建了两个向量：一个包含一周中的各天，另一个包含每天的降雨量。第一个向量全是字符值，第二个全是数值。

```
```

记住，向量只能存储相同类型的值。因此，在下面的代码中，为了将这些值一起存储在向量中，R 会自动将数值转换为字符。

```
c("Monday", 5)
#> [1] "Monday" "5"
```

`class()` 函数返回对象的数据结构。如果我们使用 `class()` 函数检查这两个对象的类别，会看到 R 告诉我们第一个是字符向量，第二个是数值向量。这在本例中与数据类型一致。

```

#> [1] "character"

#> [1] "numeric"
```

当我们创建一个空向量时会发生什么？该向量的类别是什么？

```
ex_empty <- c()
class(ex_empty)
#> [1] "NULL"
```

在这种情况下，还没有指定类型。如果我们想要指定类型，可以使用 `vector()` 函数创建一个空向量。

```
ex_empty <- vector(mode = "numeric")
class(ex_empty)
#> [1] "numeric"
```

创建向量的另一种方法是使用 `rep()` 或 `seq()` 函数。第一个函数 `rep(x, times)` 接收一个向量 `x` 和一个次数，并输出 `x` 重复该次数后的结果。让我们用一个单一值来尝试。第二个函数 `seq(from, to, step)` 接收一个数值起始值 `from`、结束值 `to` 和步长 `step`，并返回一个从 `from` 开始、按 `step` 递增、直到达到最大值 `to` 的序列。

```
rep(0, 5)
#> [1] 0 0 0 0 0
rep("Monday", 4)
#> [1] "Monday" "Monday" "Monday" "Monday"
```

```
seq(1, 5, 1)
#> [1] 1 2 3 4 5
seq(0, -10, -2)
#> [1] 0 -2 -4 -6 -8 -10
```

### 2.2.1 向量索引

一旦我们有了一个向量，我们可能想要访问该向量中存储的某些值。为此，我们根据每个值的位置索引向量：向量中的第一个值索引为 1，第二个值索引为 2，以此类推。当我们说向量是一维的，是说可以通过单一索引来定义每个值的位置。索引用方括号 `[]` 紧跟在向量名之后，并提供位置。我们使用这些索引来查找索引 1 和索引 4 处的值。

```
days[1]
#> [1] "Monday"
days[4]
#> [1] "Thursday"
```

我们可以访问单个值，也可以通过一个索引向量访问值的子集。让我们看看使用索引向量 `c(1,4)` 时会发生什么，然后尝试使用 `-c(1,4)` 看看会怎样。在第一种情况下，我们得到索引 1 和索引 4 处的值。在第二种情况下，我们得到除这些索引之外的所有值。`-` 表示我们要移除而不是选择这些索引。

```
days[c(1, 4)]
#> [1] "Monday" "Thursday"
days[-c(1, 4)]
#> [1] "Tuesday" "Wednesday" "Friday"
```

然而，总按索引值来索引有时可能困难或低效。向量有一个额外的特性：我们可以为每个值关联一个名称。在下面的代码中，我们将向量 `rain` 的名称更新为一周中的各天，然后通过名称索引来查找星期五的降雨量。

```
names(rain) <- days
print(rain)
#> Monday Tuesday Wednesday Thursday Friday
#>      5.0      0.1      0.0      0.0      0.4
rain["Friday"]
#> Friday
#>    0.4
```

索引向量的最后一种方式是使用 TRUE 和 FALSE 值。如果我们有一个与原始向量长度相同的布尔向量，那么它会返回所有对应为 TRUE 的值。例如，用逻辑向量 `ind_bools` 索引 `days` 向量会返回它的第一个和第四个值。我们稍后会更详细地了解如何使用逻辑来访问特定值。

```
ind_bools <- c(TRUE, FALSE, FALSE, TRUE, FALSE)
days[ind_bools]
#> [1] "Monday"   "Thursday"
```

### 2.2.2 修改向量与计算

我们在上一章看到的数学运算符（`+`、`-`、`*`、`/`、`^`、`%%`）都可以应用于数值向量，并且是按元素进行运算。也就是说，在代码示例中，两个向量按索引相加。这对一些内置数学函数同样成立：

- `exp()` - 指数
- `log()` - 对数
- `sqrt()` - 平方根
- `abs()` - 绝对值
- `round()` - 四舍五入到最近的整数
- `ceiling()` - 向上取整到最近的整数
- `floor()` - 向下取整到最近的整数
- `signif(, dig)` - 四舍五入到 `dig` 位有效数字

```
c(1, 2, 3) + c(1, 1, 1)
#> [1] 2 3 4
c(1, 2, 3) + 1 # equivalent to the code above
#> [1] 2 3 4
sqrt(c(1, 4, 16))
#> [1] 1 2 4
signif(c(0.23, 0.19), dig = 1)
#> [1] 0.2 0.2
