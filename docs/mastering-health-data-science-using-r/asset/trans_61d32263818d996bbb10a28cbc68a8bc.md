## 2.2.4 常用向量函数

以下列表包含 base R 中一些最常见的向量函数。所有这些函数都假定向量是数值型的。如果我们向函数传递逻辑向量，R 会首先将其转换为 0/1，如果我们向函数传递字符向量，R 会给出错误消息。

- `sum()` - 求和
- `median()` - 中位数
- `mean()` - 平均值
- `sd()` - 标准差
- `var()` - 方差
- `max()` - 最大值
- `which.max()` - 具有最大值的第一个元素的索引
- `min()` - 最小值
- `which.min()` - 具有最小值的第一个元素的索引

使用向量 `rain` 试试这些函数。请注意，R 区分大小写 - `Mean()` 被视为与 `mean()` 不同，因此如果我们输入 `Mean(rain)`，R 会告诉我们无法找到该函数。

```r
mean(rain)
#> [1] 0.8
min(rain)
#> [1] 0
which.min(rain)
#> Wednesday
#> 3
```

我们可能还对值的顺序感兴趣。`sort()` 函数对向量的值进行排序，而 `order()` 函数返回元素的排列顺序以使其按排序顺序排列。以下代码的最后一行按降雨值从小到大对一周中的天数进行排序。

```r
rain
#>    Monday   Tuesday Wednesday Thursday    Friday Saturday Sunday
#>       5.0       0.1       0.0       0.0      0.5      0.0     0.0
order(rain)
#> [1] 3 4 6 7 2 5 1
days[order(rain)]
#> [1] "Wednesday" "Thursday"  "Saturday"  "Sunday"    "Tuesday"
#> [6] "Friday"    "Monday"
```

这两个函数都有一个额外的可选参数 `decreasing`，其默认值为 `FALSE`。我们可以将其指定为 `TRUE`，以找到按降雨量从大到小排序的一周中的天数。请注意，在并列的情况下，先出现的元素排名更高。

```r
days[order(rain, decreasing=TRUE)]
#> [1] "Monday"    "Friday"    "Tuesday"   "Wednesday" "Thursday"
#> [6] "Saturday"  "Sunday"
```

## 2.3 因子

因子是一种特殊的向量，其行为类似于普通向量，但它表示来自某个类别的值。具体来说，因子会跟踪该类别的所有可能值，这些值称为因子的水平。当我们开始进行数据分析并拥有分类列时，因子尤其有用。`as.factor()` 函数将向量转换为因子。

```r
days <- c("Monday", "Tuesday", "Wednesday", "Monday",
          "Thursday", "Wednesday")
days_fct <- as.factor(days)

class(days_fct)
#> [1] "factor"
levels(days_fct)
#> [1] "Monday"    "Thursday"  "Tuesday"   "Wednesday"
```

在前面的示例中，我们没有指定列的可能水平。相反，R 找到了向量 `days` 中的所有值，并将这些值设置为因子的水平。因此，如果我们尝试将其中一个水平更改为 “Friday”，就会收到错误。取消注释以下行以查看错误消息。

```r
#days_fct[2] <- "Friday"
```

我们可以通过使用 `factor()` 函数而不是 `as.factor()` 函数来指定水平，从而避免此错误。

```r
days <- c("Monday", "Tuesday", "Wednesday", "Monday", "Thursday",
          "Wednesday")
days_fct <- factor(days,
                  levels = c("Monday", "Tuesday", "Wednesday",
                             "Thursday", "Friday", "Saturday", "Sunday"))

class(days_fct)
#> [1] "factor"
levels(days_fct)
#> [1] "Monday"    "Tuesday"   "Wednesday" "Thursday"  "Friday"
#> [6] "Saturday"  "Sunday"
days_fct[2] <- "Friday"
```

因子也可以用于数值向量。例如，我们可能有一个 0/1 的向量，表示某一天是否为周末。这也只能取某些值（0 或 1）。

```r
weekend <- as.factor(c(1, 0, 0, 0, 1, 1))
levels(weekend)
#> [1] "0" "1"
```

矩阵与向量类似，因为它们存储相同类型的数据。然而，矩阵是二维的，由行和列组成（见图 2.3），而向量是一维的。

**图 2.3：** 矩阵示例。

在以下代码中，我们创建了一个报告多周每日降雨量的矩阵。我们可以使用 `matrix(data, nrow, ncol, byrow)` 函数创建矩阵。这将从向量 `data` 的值创建一个 nrow 行 ncol 列的矩阵，如果 `byrow` 为 `TRUE`，则按行填充，否则按列填充。运行代码。然后，将最后一个参数改为 `byrow=FALSE`，看看值会发生什么变化。

```r
rainfall <- matrix(c(5, 6, 0.1, 3, 0, 1, 0, 1, 0.4, 0.2,
                     0.5, 0.3, 0, 0),
                   ncol = 7, nrow = 2, byrow = TRUE)
rainfall
#>      [,1] [,2] [,3] [,4] [,5] [,6] [,7]

#> [2,]    1  0.4  0.2  0.5  0.3    0    0
```

我们可以使用 `nrow()`、`ncol()` 或 `dim()` 函数找到矩阵的维度，这些函数分别返回行数、列数以及行数和列数。

```r
nrow(rainfall)
#> [1] 2
ncol(rainfall)
#> [1] 7
dim(rainfall)
#> [1] 2 7
```

### 2.4.1 矩阵索引

由于矩阵是二维的，单个值由其行号和列号共同索引。这意味着要访问矩阵中值的子集，我们需要提供行和列索引。在随后的代码中，我们访问第一行第四列中的单个值。第一个值始终是行索引，第二个值始终是列索引。

```r
rainfall[1, 4]
#> [1] 3
```

和之前一样，我们也可以提供多个索引来获取多个值。在随后的示例中，我们选择多列，但我们也可以选择多行（或多行和多列）。

```r
rainfall[1, c(4, 5, 7)]
#> [1] 3 0 0
```

与向量一样，我们也可以使用布尔值对矩阵进行索引，方法是提供行和/或列的布尔值。请注意，在以下示例中，我们为行索引提供了一个向量，而为列没有提供值。由于我们没有指定任何列索引，这将选择所有列。

```r
rainfall[c(FALSE, TRUE), ]
#> [1] 1.0 0.4 0.2 0.5 0.3 0.0 0.0
```

让我们做相反的操作，选择一些列和所有行。

```r
rainfall[, c(TRUE, TRUE, FALSE, FALSE, FALSE, FALSE, FALSE)]
#>       [,1] [,2]
#> [1,]    5   6.0
#> [2,]    1   0.4
```

与向量一样，我们可以指定行名和列名来访问条目，而不是使用索引。`colnames()` 和 `rownames()` 函数允许我们分别指定列名和行名。

```r
colnames(rainfall) <- c("Monday", "Tuesday", "Wednesday", "Thursday",
                       "Friday", "Saturday", "Sunday")
rownames(rainfall) <- c("Week1", "Week2")
rainfall["Week1", c("Friday", "Saturday")]
#>      Friday Saturday
#>          0        1
```

### 2.4.2 修改矩阵

如果我们想要更改矩阵中的值，我们需要首先索引这些值，然后为它们分配新值。在随后的代码块中，我们将单个条目更改为 3，然后将几个值更新为全部为 0。请注意，我们在右侧没有提供多个 0，因为 R 会推断所有值都应设置为 0。

```r
rainfall["Week1", "Friday"] <- 3
```

```r
rainfall["Week1", c("Monday", "Tuesday")] <- 0
print(rainfall)
#>       Monday Tuesday Wednesday Thursday Friday Saturday Sunday
#> Week1       0     0.0       0.1      3.0    3.0        1      0
#> Week2       1     0.4       0.2      0.5    0.3        0      0
```

此外，我们可以通过 `rbind()` 和 `cbind()` 函数添加行或列来向矩阵追加值。第一个函数向矩阵追加一行（或多行），第二个函数追加一列（或多列）。请注意，在以下示例中，我在传入额外数据时提供了行名和列名。如果我没有指定这些名称，那么那些行和列将不会被命名。
