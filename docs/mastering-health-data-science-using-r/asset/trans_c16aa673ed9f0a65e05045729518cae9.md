在 R 中，我们也可以使用函数 `pivot_wider()` 将数据向相反方向转换（即从长格式转为宽格式，而不是从宽格式转为长格式）。该函数同样首先接收一个数据表，但现在我们指定参数 `names_from` 和 `values_from`。前者指示 R 从哪个列获取新的列名，后者指示行值应从哪里获取。例如，为了在以下代码中将我们的封锁数据转回宽格式，我们指定 `names_from` 为封锁事件，`values_from` 为日期本身。现在我们又回到了之前的格式！

```
lockdown_wide <- pivot_wider(lockdown_long,
                                     names_from = Lockdown_Event,
                                     values_from = Date)
head(lockdown_wide)
```

这里有另一个例子：假设我想创建一个数据框，其中列对应新英格兰各州的病例数，行对应编号的月份。首先，我需要将数据筛选到新英格兰，然后汇总数据以找出每月的病例数。我使用 `month()` 函数来按月份和州进行分组。此外，你可以看到我在末尾添加了 `ungroup()`。当我们对按多个变量分组的数据进行汇总时，汇总后的输出仍然是分组的。在这种情况下，警告消息指出数据仍然按州分组。

```
ne_cases <- covidcases %>%
  filter(state %in% c("Maine", "Vermont", "New Hampshire",
                      "Connecticut", "Rhode Island",
                      "Massachusetts")) %>%
  mutate(month = month(date)) %>%
  group_by(state, month) %>%
  summarize(total_cases = sum(weekly_cases)) %>%
  ungroup()
head(ne_cases)

## 4 Connecticut   6      2913
## 5 Connecticut   7      3062
```

目前为止看到的透视操作相对简单，因为我们只对一组值进行了透视（例如，封锁日期、COVID-19 病例）。tidyr 包提供了更复杂透视的示例，你可能希望将其应用到自己的数据中（Wickham, Vaughan, and Girlich 2023）。

## 连接类型：

- left_join(table1, table2, by): 将 table1 的每一行与 table2 中的所有匹配项连接。
- right_join(table1, table2, by): 将 table2 的每一行与 table1 中的所有匹配项连接（与左连接相反）。
- inner_join(table1, table2, by): 查找 table1 和 table2 之间行的所有匹配项。找不到匹配项的行将被删除。
- full_join(table1, table2, by): 保留两个表中的所有行并连接匹配的行。找不到匹配项的行将用 NA 值填充。
- semi_join(table1, table2, by): 保留 table1 中在 table2 中有匹配项的所有行，但不连接 table2 中的任何信息。
- anti_join(table1, table2, by): 保留 table1 中在 table2 中没有匹配项的所有行，但不连接 table2 中的任何信息。这是半连接的相反操作。

我们首先使用 `left_join()` 函数演示左连接。该函数接收两个数据表（table1 和 table2）以及用于匹配行的列。在左连接中，对于 table1 的每一行，我们查找 table2 中的所有匹配行，并添加任何未用于匹配的列。因此，table1 中的每一行在结果表中至少对应一个条目，但如果有多个匹配项，则可能对应更多。在随后的代码块中，我们使用左连接将封锁信息添加到我们的 covidcases 数据中。在此例中，第一个表是 covidcases，我们按 state 进行匹配。由于两个数据框中的 state 列名称略有不同（covidcases 中为 "state"，lockdowndates 中为 "State"），我们在 by 参数中指定 state 等效于 State。

```
covidcases_full <- left_join(covidcases, lockdowndates,
by = c("state" = "State"))
```

现在我们想添加流动性数据。在之前的连接中，我们希望保留 covidcases 中的任何观测值，无论它是否在 lockdowndates 数据框中。因此，我们使用了左连接。在此例中，我们只想保留在每个日期都有该州流动性数据的观测值。这表明我们想要使用内连接。函数 `inner_join()` 接收两个数据表（table1 和 table2）以及用于匹配行的列。该函数仅保留 table1 中与 table2 中某行匹配的行。同样，table2 中未用于与 table1 匹配的列将被添加到结果中。在此例中，我们同时按 state 和 date 进行匹配。
