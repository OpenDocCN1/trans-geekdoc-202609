在前面的代码块中，我们看到 kable() 在编译后的 PDF 中生成了一个更漂亮的表格，更适合数据分析报告。在第 4 章中，我们还介绍了 gt 包。这个包是 kableExtra 的替代包，允许你格式化表格的每个部分，并包含格式化列、添加页脚或副标题、或对表格进行分组的选项。有关此包的更多详细信息，请参阅[包介绍]⁵。以下代码和输出中给出了一个 gt 表示例。请注意，对于表格，我们希望标签以 tbl- 开头，并可以使用 tbl-cap 选项包含标题。以下代码块生成的表格显示在图 22.7 中。

⁵ https://gt.rstudio.com/articles/intro-creating-gt-tables.html

```{r}
#| label: tbl-gt-ex
#| tbl-cap: "Head of the NHANES Sample Data"

NHANESsample %>%
  select(AGE, SEX, EDUCATION, INCOME, LEAD) %>%
  head() %>%
  gt() %>%
  tab_header(title = "Head of the NHANES Sample Data") %>%
  cols_label(AGE ~ "Age",
    SEX ~ "Sex",
    EDUCATION ~ "Education Level",
    INCOME ~ "Poverty Income Ratio",
    LEAD ~ "Lead Level")
```

## 22.3.1 使用引用

Quarto 会自动为报告中的图表和表格添加编号。通过使用标签选项，我们也可以使用它们的名称轻松引用图表：@fig-figname 或 @tab-tablename。编译后的 PDF 会将相应的图表或表格编号替换到你的文本中。此外，我们可以通过在节标题中添加标签来引用节。例如，我们为以下文本中的节添加了标签 #sec-awesome，现在可以使用 @sec-awesome 引用它。

```
## Awesome Stuff {#sec-awesome}
```

## 22.4 添加方程

Markdown 中另一个有用的选项是添加数学方程。如果要插入数学方程，可以通过编写 LaTeX 表达式来实现。要编写行内数学方程，在方程两侧各放一个美元符号 $；要编写独占一行的数学方程，在方程两侧各放两个美元符号 $$，如下所示：

以下是与文本行内的一个方程：$5x^2 + 9x^3$ 生成 $5x^2 + 9x^3$。另一方面，以下是独占一行的一个方程：$$5x^2 + 9x^3$$ 生成

$5x^2 + 9x^3$

以下是编写常见方程所需了解的一些其他 LaTeX 表示法：

- 要创建分数，请键入 \frac{numerator}{denominator}。例如，\frac{2}{3} 生成 2/3。
- 要创建下标，请键入 _。例如，x_{2} 生成 x_2。
- 要创建上标，请键入 ^。例如，x^{2} 生成 x^2。

如果要了解有关如何编写 LaTeX 的更多信息，Art of Problem Solving⁶ 为 LaTeX 符号提供了一个很好的参考，Overleaf⁷ 提供了 LaTeX 的一般有用介绍。
