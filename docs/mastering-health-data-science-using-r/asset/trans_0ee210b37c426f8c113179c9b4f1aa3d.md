有些县的人口规模非常小，我们可能需要考虑将其从分析中剔除。尤其是，在这些小县中，Loving县和Terrell县的流产率高得足以让我们将其视为离群值。不过，在本次单样本分析中，我们不会移除它们。如果我们想估计各县的平均流产率\(\mu\)，只需使用`mean()`函数即可。作为参考，美国疾病控制与预防中心估计2020年全国流产率为每1000名15-44岁女性中11.2例（Kortsmit 2023）。

```
mean(county_rates_2021, na.rm = TRUE)
#> [1] 5.17
```

在R中，我们还可以计算该均值的置信区间。回顾一下，均值的\((1 - \alpha)\%\)置信区间由公式\(\hat{\mu} \pm z_{1-\alpha/2} \cdot \frac{\hat{\sigma}}{\sqrt{n}}\)给出，其中\(\hat{\mu}\)是样本均值，\(\hat{\sigma}^2\)是样本方差，\(n\)是观测值数量。

在接下来的代码块中，我们使用该公式计算各县平均流产率的95%置信区间：

```
est_mean <- mean(county_rates_2021, na.rm = TRUE)
est_sd <- sd(county_rates_2021)
z_alpha <- dnorm(1 - 0.05 / 2)
n <- length(county_rates_2021)
c(est_mean - z_alpha * est_sd / sqrt(n),
  est_mean + z_alpha * est_sd / sqrt(n))
#> [1] 5.04 5.29
```

如果我们想更美观地显示结果，可以使用`round()`函数来指定要显示的小数位数，以及`paste()`函数将多个输入合并为单个字符串。

```
lower <- round(est_mean - z_alpha*est_sd/sqrt(n), 3)
upper <- round(est_mean + z_alpha*est_sd/sqrt(n), 3)
paste("Confidence Interval: ( ", lower, ",", upper, ")")
#> [1] "Confidence Interval: ( 5.044 , 5.289 )"
```

假设我们想运行一个假设检验来将均值与某个预先确定的值进行比较。特别是，德克萨斯州心跳法案（Texas Heartbeat Act）于2021年出台，大幅减少了符合条件的流产数量。我们可以使用单侧t检验来检验2021年的流产数量是否显著少于2020年。我们的原假设是\(\mu \ge 6.23\)，即2020年的平均流产率。要运行此假设检验，我们使用`t.test()`函数。对于单样本t检验，我们需要指定样本x、备择假设`alternative`（默认为双侧检验）、均值的真实值`mu`（默认为0）以及置信水平`conf.level`（默认为0.95）。在下面的代码中，我们运行此t检验，从结果中可以看出，我们在0.05的显著性水平下拒绝了原假设，并观察到2021年流产率出现了统计学上显著的下降。

```
t.test(county_rates_2021, alternative = "less", mu = 6.23,
       conf.level=0.95)
#>
#> One Sample t-test
#>
#> data:  county_rates_2021
#> t = -2, df = 253, p-value = 0.02
#> alternative hypothesis: true mean is less than 6.23
#> 95 percent confidence interval:
#>  -Inf 5.98
#> sample estimates:
#> mean of x
#>   5.17
```

该检验的结果会直接打印出来。如果我们想要引用这些值，就需要将结果保存下来。对象`t_test_res`是一个列表，其中包含统计量、p值、置信区间等信息。输出列表与其他检验对象类似，因此通过阅读检验文档（`?t.test`）来了解每个对象包含的内容会很有帮助。我们可以从`t_test_res`中获取p值。

```
t_test_res <- t.test(county_rates_2021, alternative = "less",
                     mu = 6.23, conf.level = 0.95)
names(t_test_res)
#> [1] "statistic"   "parameter"   "p.value"     "conf.int"
#> [5] "estimate"    "null.value"  "stderr"      "alternative"
#> [9] "method"      "data.name"

t_test_res$p.value
#> [1] 0.0161
```

需要注意的一点是，t.test()函数假设样本x来自正态分布。单样本Wilcoxon符号秩检验是单样本t检验的一种非参数替代方法，可用于将样本的中位数与某个理论值进行比较，而无需假设数据呈正态分布。该检验可以使用wilcox.test()函数执行，其参数与t.test()函数相同。在下面的输出中，我们可以看到，我们再次在0.05的显著性水平下拒绝了原假设，并得出结论：2021年流产率的中位数显著低于2020年的中位数5.14。

```
wilcox_res <- wilcox.test(county_rates_2021, alternative = "less",
                              mu = 5.14, conf.level = 0.95)
wilcox_res
#>
#> Wilcoxon signed rank test with continuity correction
#>
#> data:  county_rates_2021
#> V = 12807, p-value = 0.002
#> alternative hypothesis: true location is less than 5.14
wilcox_res$p.value
#> [1] 0.00193
```
