### 13.3.4 杠杆与影响

我们也可能关注每个观测值如何影响模型。杠杆值衡量单个观测值的 y 值在多大程度上影响其自身的预测值，并指示观测值相对于其余数据是否具有极端的预测值。杠杆值范围从 0 到 1，且总和等于估计系数的数量。高杠杆观测值有可能显著影响估计的回归系数和模型的整体拟合。因此，检查杠杆值有助于识别可能具有影响力或为异常值的观测值。在以下代码块中，我们找出十个最高的杠杆值，然后在数据中找到这些观测值。

## 13.4 交互作用与转换

我们现在尝试改进模型。首先，我们查看因变量的潜在转换。我们对因变量（收缩压）和感兴趣的预测变量（血铅水平）都考虑对数转换。这两个变量的分布都相当偏态，可能从这种转换中受益。在以下代码中，您可以看到转换后的变量具有更对称的分布。

```r
par(mfrow=c(2,2))

     main = "")

     main = "")
hist(log(nhanes_df$LEAD), xlab = "Log Blood Lead Level",
     main = "")
```

要向模型添加转换，可以直接在 lm() 的公式中应用转换。我们为每个潜在模型计算调整后的 R 平方以比较其拟合优度，同时绘制四个 Q-Q 图。两者都表明，具有 log-log 转换（即对 SBP 和 LEAD 变量都应用对数转换）的模型拟合效果最好，尽管仅对 SBP 进行对数转换的模型具有相似的 Q-Q 图。

```r
model_nlog_nlog <- lm(SBP ~ LEAD + AGE + SEX, data = nhanes_df)
model_log_nlog <- lm(log(SBP) ~ LEAD + AGE + SEX, data = nhanes_df)
model_nlog_log <- lm(SBP ~ log(LEAD) + AGE + SEX, data = nhanes_df)
model_log_log <- lm(log(SBP) ~ log(LEAD) + AGE + SEX,
                     data = nhanes_df)
```
