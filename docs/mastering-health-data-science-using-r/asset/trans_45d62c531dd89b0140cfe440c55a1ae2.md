

## 18.1 函数的组成

要开始存储函数，我们需要给它们命名，并定义它们的输入（参数）和输出（返回值）。为此，我们将函数名赋给一个函数对象，如下面的代码所示。这个示例函数有两个参数 `arg1` 和 `arg2`，并返回输出。

```
function_name <- function(arg1, arg2){
  code to compute output from arguments
  return(output)
}
```

看一下下面这个简单函数。这个函数的名字是 `say_hello`，它没有输入（参数）或输出（返回值）。相反，它只是打印出一条问候语句。

```
say_hello <- function(){
  print("Hello!")
}
```

运行上述代码会创建一个名为 `say_hello` 的 `function` 类对象。我们可以通过使用空括号调用它来运行这个函数（因为没有输入参数）。

```
class(say_hello)
#> [1] "function"
```

```
say_hello()
#> [1] "Hello!"
```

我们可以通过添加第一个参数 `name`（一个字符串），然后打印“Hello, [name]!”来扩展这个函数。在下一个代码块中，我们使用 `paste0()` 函数将字符串参数拼接成单个字符串。

```
say_hello <- function(name){
  print(paste0("Hello, ", name, "!"))
}
say_hello("Weici")
#> [1] "Hello, Weici!"
```

### 18.1.1 参数

参数是传递给函数的输入，以便函数完成所需的计算。我们也可以为这些参数设置默认值。在这种情况下，调用函数时不必指定这些参数。例如，`rnorm(10)` 使用 `mean` 的默认值来确定我们想使用的分布。在下面的函数中，我们计算给定 (x,y,z) 坐标到原点 (0,0,0) 的欧几里得距离，所有值的默认值为零。

```
dist_to_origin <- function(x = 0, y = 0, z = 0){
return(((x - 0)^2 + (y - 0)^2 + (z - 0)^2)^(0.5))
}
```

如果我们不带任何参数调用此函数，它将使用所有默认值。

```
dist_to_origin()
#> [1] 0
```

但是，如果我们用一个参数调用该函数，函数会假定这第一个参数是 `x`。类似地，它会假定第二个值是 `y`，第三个值是 `z`。如果我们想在不考虑顺序的情况下给出参数，我们可以使用它们的名称来指定它们（参见下面代码块中的最后一行）。

```
dist_to_origin(1)
#> [1] 1
dist_to_origin(1, 2)
#> [1] 2.24
dist_to_origin(1, 2, 3)
#> [1] 3.74
dist_to_origin(y = 2, z = 3)
#> [1] 3.61
```

除了传入数值、字符串、数据框、列表或向量之外，我们还可以将其他类型的对象作为参数传递给函数。例如，我们可以将另一个函数作为参数。在下一个示例中，我们创建两个函数。第一个函数计算两个点之间的欧几里得距离。第二个函数计算给定点到原点的距离。请注意，这个更新后的“到原点距离”函数更加灵活，并且写法也更简洁。首先，它允许我们输入任意长度的点。其次，它允许我们指定所使用的距离函数。这也演示了在另一个函数内部调用函数。尝试用不同的值调用 `euclidean_dist()` 和 `dist_to_origin()`。

```
euclidean_dist <- function(pt1, pt2){
# Finds the Euclidean distance from pt1 to pt2
return(sqrt(sum((pt1- pt2)^2)))
}

dist_to_origin <- function(pt1, dist_func = euclidean_dist){
# Finds the distance from pt1 to the origin
origin <- rep(0, length(pt1))
return(dist_func(pt1, origin))
}

dist_to_origin(c(1,1))
#> [1] 1.41
```

### 18.1.3 返回值

如果我们通过调用 `?lm` 阅读 `lm()` 的文档，我们可以看到它有很多带有默认值的参数。关于 `lm` 的文档，另一件需要注意的事情是它返回了多个值。事实上，返回的对象类型是一个列表，包含我们想了解的有关结果的所有不同信息，例如系数。

```
simp_model <- lm(y ~ x)
simp_model$coefficients
#> (Intercept) x
#> 0.0671 0.9946
```

由于 R 只允许你返回一个对象，将返回值打包成列表是从函数返回多个输出的有用方法。在下面的示例中，我们创建了一个函数 `coin_flips()`，它接受一个概率 `prob` 和一个迭代次数 `n`（默认值为 10），并模拟 `n` 次硬币抛掷，其中硬币正面朝上的概率为 `prob`。该函数返回正面朝上的试验百分比以及硬币抛掷的结果。我们可以通过使用名称 `percent_heads` 和 `results` 来访问这些返回值中的每一个。

```
coin_flips <- function(prob, n = 10){
# Flips a coin with probability prob of heads for n trials

results <- rbinom(n = n, size = 1, prob = prob)
return(list(percent_heads = sum(results)/n, results = results))
}
trial <- coin_flips(0.6)
trial$percent_heads
#> [1] 0.5
trial$results
#> [1] 0 0 0 1 1 1 0 1 0 1
```

关于 R 和返回值，有一件重要的事情需要了解：如果你没有指定返回语句，但将函数的输出赋值给一个对象，它将默认把最后计算的对象的值赋给它。在下面的代码中，返回的值是 3。为了避免意外行为，请始终使用 `return()` 函数。

```
ex_return <- function(){
  x <- 2
  y <- 3
}
result <- ex_return()
result
#> [1] 3
```

### 18.1.4 对象的作用域

在函数内部工作并调用函数时，我们要记住对象的作用域。*全局对象*是在函数外部定义的对象。这些值也可以在函数外部或内部访问。例如，对象 `y` 是在函数外部定义的，因此它是一个全局对象，这意味着我们可以在函数内部使用它的值。

```
y <- "Cassandra"

ex_scope <- function(){
  return(paste("Hey,", y))
}

ex_scope()
#> [1] "Hey, Cassandra"
```

然而，如果我们改变函数内部全局对象的值，它并不会更新函数外部的值。在接下来的代码块中，我们在函数内部给 `y` 加 1，但这并不会在函数执行完后改变 `y` 的值。每次我们运行一个函数时，R 都会在内部创建一个新的子环境，这个子环境可以访问全局对象的值，但也会创建它自己的*局部对象*。在这种情况下，函数创建了自己的对象 `y`，它是原始对象的一个副本的局部对象。

作为另一个示例，该函数还创建了一个名为 `z` 的局部对象，在我们运行该函数后，`z` 就不再存在。如果我们尝试在最后一行打印 `z`，我们会收到一个错误，提示找不到 `z`。函数内部创建的所有对象都只存在于该子环境中，当我们不再处于该函数中时，它们就会被清除。因此，我们要确保返回任何我们想要存储的值。

```
y <- 5
```

```
ex_local <- function(x){
  y <- y + 1
  z <- x * y
  return(y + z)
}

ex_local(2)
#> [1] 18
y
#> [1] 5
```

要在函数内部更新全局对象，可以使用 `<<-` 运算符（全局赋值运算符）。它会在全局环境中查找一个对象并更新其值（如果找不到，则创建一个具有该值的对象）。例如，下面的函数更新了全局对象 `y` 的值。作为一种通用实践，我们应该谨慎地在函数内部使用全局对象，而使用输入参数和返回值通常更安全。

```
y <- 5

ex_update_global <- function(x){
  y <<- y + 1
  return(y + x)
}

ex_update_global(2)
#> [1] 8
y
#> [1] 6
```
