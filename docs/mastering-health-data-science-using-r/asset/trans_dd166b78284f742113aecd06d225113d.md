## 使用 ggplot2 进行可视化

包 **ggplot2**（Wickham 2016）是 **tidyverse** 中另一个有用的包，它使统计学家能够通过可视化以引人入胜的格式传达关键发现和结果。在本章中，我们学习 ggplot 对象的三个主要组成部分，然后通过了解可用于创建各种图形的不同图层来进一步扩展该格式。与 **dplyr** 函数一样，有许多函数需要介绍，而且它们相互依赖。

本章使用的三个包是 **tidyverse**、**HDSinRdata** 和 **patchwork**（Pedersen 2022），其中最后一个包可以很好地将多个图形组合成单一图片。我们使用 **第 3 章** 中介绍的匹兹堡疼痛门诊（Alter et al. 2021）的数据来创建可视化。你可以通过阅读数据文档来回忆这些数据。为了本章的目的，我们抽取了 5,000 名基线时具有完整病例数据的患者作为样本，以减少显示每个图形所需的计算时间。你可以忽略用于获取该样本的代码是如何工作的。

```r
library(tidyverse)
library(HDSinRdata)
library(patchwork)
data(pain)

# sampling data
set.seed(5)
pain_df_sub <- subset(pain,
                      select = -c(PAIN_INTENSITY_AVERAGE,FOLLOW_UP))
pain_df <- pain[complete.cases(pain_df_sub), ]
pain_df <- pain_df[sample(1:nrow(pain_df), 5000, replace = FALSE),]
```

## 8.1 ggplot 简介

我们将首先演示如何在 ggplot2 中创建散点图，以介绍 ggplot2 对象的三个关键元素。具体来说，我们创建一个患者抑郁评分与焦虑评分的散点图。要开始绘图，我们可以使用 `ggplot()` 函数创建一个 ggplot 对象，如下面的代码所示。注意，这会显示一个灰色框；这是我们构建图形的基础。

```r
ggplot()
```

![](img/58a554e865d49ca347d9a3f76f8f0812_136_0.png)

接下来，我们可以开始向 ggplot 对象添加图层。其中一种图层是 geom，它创建几何对象。在下一个代码块中，我们使用 `geom_point()` 函数添加散点图图层。对于该函数，我们首先需要指定要使用的数据，然后需要使用 `aes()` 函数告诉 R 如何利用这些数据创建散点图，`aes()` 函数会创建映射（aesthetic）。对于散点图，我们至少需要在映射中指定 x 轴和 y 轴。数据和映射既可以在初始的 `ggplot()` 函数中指定（该函数会将此信息传递给所有后续图层），也可以在 `geom_point()` 函数本身中指定。在下面的代码中，我们在 geom 函数中指定了映射，但在随后的代码块中还包含了两种用代码生成相同图像的替代方式。最终图形显示焦虑与抑郁之间存在相当线性的关系。

```r
ggplot(pain_df) + geom_point(aes(x=PROMIS_ANXIETY,
 y = PROMIS_DEPRESSION))
```

![](img/58a554e865d49ca347d9a3f76f8f0812_137_0.png)

```r
# Alternative 1:
ggplot(pain_df, aes(x = PROMIS_ANXIETY, y = PROMIS_DEPRESSION)) +
geom_point()
# Alternative 2:
ggplot() +
geom_point(data = pain_df, aes(x = PROMIS_ANXIETY,
 y = PROMIS_DEPRESSION))
```

如果我们想改进图形，可能会想要添加不同的标签和标题。为此，我们使用 `labs()` 函数添加一个图层，在该图层中可以指定所有标签。此外，我还通过改变点的颜色、大小和形状，向几何图层传递了更多信息。这些属性在 `aes()` 函数之外指定，因为它们并非来自数据；在本例中，每个点都具有相同的颜色、大小和形状。

```r
ggplot(pain_df)+
geom_point(aes(x = PROMIS_ANXIETY, y = PROMIS_DEPRESSION),
 color = "blue", size = 2, shape = 5) +
labs(x = "PROMIS Anxiety Score", y = "PROMIS Depression Score",
 title = "Depression vs Anxiety Scores")
```

![](img/58a554e865d49ca347d9a3f76f8f0812_138_0.png)

让我们再创建一个示例。这一次，我为初始记录的疼痛水平创建直方图。要找到我们想要创建的图形类型对应的 geom，可以使用 Posit[^1] 提供的数据可视化速查表。第一页列出了所有可用的 geom 选项，以及我们可以为每个选项设置的映射。例如，这里我们感兴趣的是绘制一个连续变量的分布，在 `geom_histogram()` 函数下，我们可以看到可以指定 x（我们要绘制其分布的变量）以及 binwidth、alpha、color、fill、linetype、size 和 weight。默认情况下，直方图中的 y 值是每个 bin 的计数。

```r
ggplot(pain_df)+
  geom_histogram(aes(x = PAIN_INTENSITY_AVERAGE), color = "violetred",
                 fill = "lightblue", alpha = 0.5, bins = 11) +
  labs(x = "Patient Reported Pain Intensity", y = "Count")+
  theme_minimal()
```
