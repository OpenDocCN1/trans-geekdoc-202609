## 案例研究：设计模拟研究

模拟研究是利用函数的理想场景。在进行模拟研究时，我们通常需要生成数据、运行统计方法并收集结果，并且需要针对大量模拟重复这一过程。函数将确保我们能够编写更简洁、可重现的代码。在本案例研究中，我们将为一项基于 Hastie、Tibshirani 和 Tibshirani（2020）分析的模拟研究编写代码，该研究比较了不同的稀疏回归方法。出于我们的目的，我们将重点比较第 15 章中介绍的最小绝对收缩和选择算子（lasso）回归与岭回归。

我们的目标是理解这两种模型在不同数据设置下的预测能力。我们将使用以下数据生成机制生成训练数据和测试数据，该机制依赖于观测值数量 \(n\)、预测变量数量 \(p\)、稀疏度 \(s \le p\)、预测变量相关水平 \(\rho\) 以及信噪比 \(\nu\)。

1. 我们定义一个系数向量 \(\beta \in \mathbb{R}^p\)，其前 \(s\) 个分量等于 1，其余分量等于 0。请注意，我们的模型不包含截距。

2. 我们从多元正态分布 \(N_p(0, \Sigma)\) 中抽取预测变量矩阵 \(X \in \mathbb{R}^{n \times p}\) 的各行，其中 \(\Sigma \in \mathbb{R}^{p \times p}\) 的第 (i, j) 个元素等于 \(\rho^{|i - j|}\)。

3. 我们从正态分布 \(N(X\beta, \sigma^2 I)\) 中抽取结果 \(y \in \mathbb{R}^n\)，其中 \(\sigma^2 = \frac{\beta^T \Sigma \beta}{\nu}\)。这确保了数据的信噪比（定义为 \(\text{Var}(x^T \beta) / \text{Var}(\sigma^2)\)）等于 \(\nu\)。

生成数据后，我们将使用 5 折交叉验证在训练数据上拟合最小绝对收缩和选择算子（lasso）或岭回归模型，以获得估计系数 \(\hat{\beta}\)。最后，我们将对保留的测试集进行预测。我们感兴趣的评估指标是拟合模型所需的时间（以秒为单位）、相对测试误差

\[
\text{RTE} = \frac{(\hat{\beta} - \beta)^T \Sigma (\hat{\beta} - \beta) + \sigma^2}{\sigma^2},
\]

以及解释方差比例

\[
PVE = 1 - \frac{(\hat{\beta} - \beta)^T \Sigma (\hat{\beta} - \beta) + \sigma^2}{\beta^T \Sigma \beta + \sigma^2}
\]

在 Hastie、Tibshirani 和 Tibshirani（2020）的研究中，他们改变了所有五个参数 \(n\)、\(p\)、\(s\)、\(\rho\) 和 \(\nu\)，以观察数据生成方式如何影响这些指标。

我们首先编写生成数据的函数。这里的输入是参数 n、p、s、rho 和 nu，输出是一个列表。

```r
#' 模拟数据
#'
#' @param n 观测值数量
#' @param p 变量数量
#' @param s 稀疏水平（非零系数的数量）
#' @param snr 信噪比
#' @param rho 预测变量相关水平
#' @return 包含模拟协变量矩阵 `X`、
#' 结果向量 `y`、真实系数向量 `beta`、
#' 协变量矩阵 `Sigma` 和 y 的方差 `sigma` 的列表
simulate_data <- function(n, p, s, snr, rho) {

  # 生成协方差矩阵
  cov_mat = matrix(0, nrow = p, ncol = p)
  for (row in 1:p) {
    for (col in 1:p) {
      cov_mat[row, col] = rho^abs(row-col)
    }
  }

  # 生成 X
  x <- mvrnorm(n=n, mu=rep(0,p), Sigma = cov_mat)

  # 生成 beta 值
  b <- rep(0, p)
  b[1:s] <- 1

  # 找到值
  mu <- x %*% b
  intercept <- -mean(mu)

  # 计算方差
  var <- as.numeric((t(b) %*% cov_mat %*% b)/snr)

  # 生成 y 值
  y <- mvrnorm(mu = mu, Sigma = var*diag(n))

  return(list(X = x, y = y, beta = b, Sigma = cov_mat, sigma = var))
}
```

接下来，我们将编写一个用于模型指标的函数。我们从模型需要的唯一输入是估计系数。否则，所有信息都来自我们刚刚编写的函数生成的数据。我们将利用这个列表格式来提取公式所需的值。

```r
#' 返回模型指标
#'
#' @param coef_est 包含估计系数的向量
#' @param test_data 包含测试集（`simulate_data()` 输出）
#' @return 包含相对测试误差（RTE）和解释方差
#' 比例（PVE）的向量。
get_metrics <- function(coef_est, test_data) {

  # 提取所需值
  coef_true <- test_data$beta
  Sigma <- test_data$Sigma
  var_y <- test_data$sigma

  # 计算相对测试误差
  RTE <- (t(coef_est - coef_true) %*% Sigma %*%
           (coef_est - coef_true) + var_y) /
    var_y

  # 计算 PVE
  # 解释方差比例
  PVE <- 1 - (t(coef_est - coef_true) %*% Sigma %*%
               (coef_est - coef_true) + var_y) /
    (var_y + t(coef_true %*% Sigma %*% coef_true))

  return(c(RTE = RTE, PVE = PVE))
}
```
