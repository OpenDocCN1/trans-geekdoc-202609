## 13.5 评估指标

除了调整后的 R 平方之外，还有几个其他指标可以帮助我们了解模型拟合数据的程度，也可用于模型选择。`AIC()` 和 `BIC()` 函数分别计算赤池信息量准则（AIC）和贝叶斯信息量准则（BIC）值。AIC 和 BIC 都在模型复杂度与拟合优度之间取得平衡。AIC 同时考虑拟合优度（由模型的似然度捕获）和模型复杂度（由所使用的参数数量捕获）。较低的 AIC 值更可取。BIC 与 AIC 类似，但相比 AIC 对模型复杂度有更强的惩罚。两种措施都表明倾向于保留交互项。

```
AIC(model_log_log)
#> [1] -38610
AIC(model_interaction)
#> [1] -38760
```

```
BIC(model_log_log)
#> [1] -38569
BIC(model_interaction)
#> [1] -38710
```

`predict()` 函数允许我们计算预测的 y 值。当在未指定数据的模型上调用时，它返回训练数据的预测值。我们也可以使用 `newdata` 参数指定新数据。提供的新数据必须包含模型公式中给出的列。我们使用 `predict()` 函数从模型中查找预测值，然后计算模型的平均绝对误差（MAE）和平均平方误差（MSE）。与 MSE 相比，MAE 对异常值不那么敏感。MAE 表明，我们的模型平均残差相当高。虽然此模型有助于理解血铅水平与收缩压之间的关系，但作为预测后者的工具，它并不十分有用。

## 13.6 逐步选择

到目前为止，我们已忽略数据框中的其他变量。在进行变量选择时，有多种方法可用。本章通过演示如何在 R 中实现此类方法之一 **逐步选择** 来结束。第 15 章通过展示如何在 R 中实现正则化模型，进一步阐述了这种模型选择技术。

`step()` 函数接收一个初始模型，以及一个方向（“forward”、“backward”或“both”）和一个范围（scope）。范围指定要考虑的下限和上限模型公式。在以下示例中，我们使用前向选择，因此下限公式是当前模型的公式，而上限公式包含我们考虑添加的其他协变量。这两个公式必须是嵌套的，即下限公式中的所有项都必须包含在上限公式中。

默认情况下，`step()` 函数会打印过程中的每个步骤，并使用 AIC 来指导其决策。我们可以设置 trace=0 来避免打印行为，并将参数 k 更新为 log(n) 以使用 BIC，其中 n 是观测值的数量。在输出中，我们看到算法首先添加 race，然后是 BMI，接着是 income，然后是 education，最后是 smoking status。事实上，所有变量都已添加到模型中！最终输出是一个 lm 对象，我们可以像本章前面使用的那样使用它。我们得到最终模型的摘要，并看到调整后的 R 平方已提高到 0.2479。
