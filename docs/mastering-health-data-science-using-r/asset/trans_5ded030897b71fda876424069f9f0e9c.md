### 14.1 R 中的广义线性模型

R 中的 glm(formula, data, family) 函数用于拟合广义线性模型。我们必须指定给该函数的三个主要参数是：

- formula - 自变量与感兴趣结果之间的关系，
- data - 用于训练模型的数据集，以及
- family - 模型中使用的误差分布和链接函数的描述。

在二元逻辑回归中，我们假设二项分布结果并使用 logit 链接函数。我们可以通过设置 family = binomial 来指定这一点。默认情况下，这假设链接函数是 logit 函数。请注意，我们甚至可以通过设置 family = gaussian 来使用 glm() 函数实现线性回归。使用第 13 章中的示例，运行 glm(SBP ~ LEAD, data = nhanes_df, family = gaussian) 将等同于 lm(SBP ~ LEAD, data = nhanes_df)。

我们感兴趣的结果是当前电子烟使用情况，e_cig_use，因此我们需要从数据中当前存在的变量创建此变量。如果受访者回答过去 30 天内未使用过电子烟，则将 e_cig_use 设置为 0，否则设置为 1。我们可以看到，只有 1,435 名受访者报告了电子烟使用情况。这占总样本的比例较低，可能会影响我们的结果。

```
nyts$e_cig_use <- as.factor(ifelse(nyts$num_e_cigs == 0, "0", "1"))
table(nyts$e_cig_use)
#>
#>   0   1
#> 18683 1435
```
