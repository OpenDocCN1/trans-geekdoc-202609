## 使用 R 掌握健康数据科学

本书提供了一本实用、应用驱动的指南，介绍如何使用 R 进行公共卫生和健康数据科学分析，适合初学者和具有一定编程经验的读者。每个模块都以数据作为分析的驱动力开始，然后逐步介绍和拆解进行分析所需的编程概念。本书旨在为健康相关领域的读者提供一本实用且易于上手的编程指南。超越简单的 R 示例，所培养的编程原则和技能将使读者能够将 R 技能应用于自己的研究需求。全书贯穿公共卫生领域的实用案例研究，以加强学习。

主题包括 R 中的数据结构、探索性分析、分布、假设检验、回归分析，以及使用函数和控制流进行大规模编程。本书的呈现重点在于 R 的实现，并假设读者已有概率、统计推断和回归分析的基础知识。

主要特点：

- 包含实用案例研究。
- 解释如何编写大型程序。
- 包含关于 Quarto 的补充信息。

艾丽丝·保罗是生物统计学助理教授兼教学学者，拥有康奈尔大学运筹学博士学位。拥有 6 年本科、硕士和博士层次的教学经验，她在布朗大学和奥林工学院教授过包括生物统计学、工程学、计算机科学和数据科学在内的多个领域的学生。
