### 17.1 逻辑与条件表达式

您可能记得我们在第 3 章中介绍了逻辑运算符。我们通过条件表达式使用这些运算符，例如在索引数据框或使用 `ifelse()` 或 `case_when()` 函数时。例如，在以下代码中，我们有收缩压和舒张压血压测量值的向量，并编写逻辑运算符来检查至少一个收缩压测量值是否高于 140 或至少一个舒张压测量值是否高于 90。

```r
sbp_measurements <- c(131, 110, 125, 145, NA, 130)
dbp_measurements <- c(70, NA, 80)
any(sbp_measurements > 140, na.rm = TRUE) |
any(dbp_measurements > 90, na.rm = TRUE)
#> [1] TRUE
```

让我们看另一个示例。假设这些血压测量值是连续采集的，但可能存在缺失值。我们想要创建一个单一值来总结患者的血压。如果只有一个血压读数，则使用该值。但是，如果有多个血压读数，则删除第一个观测值并对其余值求平均。我们假设并非所有值都是 NA。以下代码使用 ifelse() 函数来实现这一点，首先检查是否只有一个读数。如果是，则计算去除 NA 值后的总和以找到该值。否则，我们找到所有非 NA 值，删除第一个，然后求平均。

```r
sbp_measurements <- c(131, 110, 125, 145, NA, 130)
ifelse(sum(!is.na(sbp_measurements)) == 1,
       sum(sbp_measurements, na.rm = TRUE),
       mean(sbp_measurements[!is.na(sbp_measurements)][-1]))
#> [1] 128
```

我们也可以使用称为 if-else 语句的控制流来完成同样的事情。if-else 语句遵循以下结构。首先，我们有一个条件语句。如果条件语句为真，则运行 if 语句中的代码（即第一组花括号内的代码）。如果不为真，则运行 else 语句中的代码。通过这种方式，控制流控制代码的执行方式。

```
if (conditional statement){
block of code if the statement is TRUE
} else{
block of code if the statement is FALSE
}
```

下一个代码块显示了一个示例，其中条件语句与之前相同。请注意，由于 if 或 else 语句中的代码总会有一个被执行，因此对象 avg_val 始终已定义。

```r
sbp_measurements <- c(131, 110, 125, 145, NA, 130)
if(sum(!is.na(sbp_measurements)) == 1){
  avg_val <- sum(sbp_measurements, na.rm = TRUE)
} else{
  avg_val <- mean(sbp_measurements[!is.na(sbp_measurements)][-1])
}
avg_val
#> [1] 128
```

需要注意的是，if 语句只能接受单个布尔值。它不能像 ifelse() 和 case_when() 函数那样接受布尔值向量。因此，ifelse() 函数很有用，因为它可以应用于多个实例，但如果您希望根据逻辑语句运行多行代码，它就不够灵活，因为它不允许您包含代码块。
