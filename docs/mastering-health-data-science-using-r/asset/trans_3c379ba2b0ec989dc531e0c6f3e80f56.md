另一个有用的函数允许我们对矩阵或数据框的行或列进行计算，即 `apply(X, MARGIN, FUN)` 函数，它接受三个参数。第一个参数是数据框或矩阵 `X`，第二个参数 `MARGIN` 指示是对行（1）还是列（2）进行计算，最后一个参数是要跨该边应用的函数 `FUN`。后续代码查找数据框 `pain_body_map` 中每行的最大值。取行最大值的最小值显示，每位患者至少选择了一个身体图区域。

```r
any_selected <- apply(pain_body_map, 1, max)
min(any_selected, na.rm=TRUE)
#> [1] 1
```

在第二个示例中，我们查找列上身体疼痛区域的总和，这与之前使用 `colSums()` 的示例等效。在此情况下，我们添加了 `na.rm=TRUE` 参数。`apply()` 函数将任何其他参数传递给函数 `FUN`。

```r
perc_patients <- apply(pain_body_map, 2, sum, na.rm=TRUE) /

summary(perc_patients)
```

## 3.2.5 缺失值、无穷值和 NaN 值

如我们所见，此数据包含一些缺失值，在 R 中表示为 `NA`。R 将这些值视为未知，这就是为什么我们必须向 `sum()` 和 `max()` 等函数添加 `na.rm=TRUE` 参数。在以下示例中，我们可以看到 R 发现 1 加上一个未知数也是未知的！

```r
NA+1
#> [1] NA
```

我们可以使用函数 `is.na()` 来确定一个值是否缺失。如果值为 NA，该函数返回 `TRUE`，否则返回 `FALSE`。然后我们可以对单个列求和这些值，因为每个 `TRUE` 值对应值为 1，每个 `FALSE` 值对应值为 0。我们观察到列 `PATIENT_NUM`（即患者 ID 编号）中有一个 NA 值。

```r
sum(is.na(pain$PATIENT_NUM))
#> [1] 1
```

如果我们想要计算每个列（而不仅仅是单个列）的 NA 值总和，可以使用 `apply()` 函数。由于我们希望对列应用此计算，第二个参数的值为 2。请记住，最后一个参数是我们要为每个列调用的函数。在此情况下，我们想要应用 `sum()` 和 `is.na()` 函数的组合。为此，我们必须自己指定此函数。这称为 **匿名函数**，因为它没有名称。

```r
num_missing_col <- apply(pain, 2, function(x) sum(is.na(x)))
min(num_missing_col)
#> [1] 1
```

有趣的是，我们可以看到每个列中至少有一个缺失值。可能存在一行全为 NA 值的情况。让我们按行应用相同的函数。取最大值，我们可以看到第 11749 行全为 NA 值。

```r
num_missing_row <- apply(pain, 1, function(x) sum(is.na(x)))
max(num_missing_row)
#> [1] 94
which.max(num_missing_row)
#> [1] 11749
```

我们删除该行，然后按列查找缺失值的百分比。我们可以看到，缺失值百分比最高的列是随访时的疼痛强度。事实上，只有 33% 的患者有记录的随访就诊。
