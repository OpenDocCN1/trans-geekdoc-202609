### 3.3.2 其他选择函数

在前面的代码中，我们使用 TRUE/FALSE 布尔值选择行。其实，我们也可以使用 `which()` 函数。该函数接受 TRUE/FALSE 值，并返回所有 TRUE 值的索引值。我们用它来将那些种族为 `DECLINED` 的观测视为未指定。

```
pain$PAT_RACE[which(pain$PAT_RACE == "DECLINED")] <- "NOT SPECIFIED"
```
