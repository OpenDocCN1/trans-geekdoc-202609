However, **tidyverse** packages also work with another data structure called a **tibble**. A **tibble** has all the properties of data frames that we have learned so far, but they are a more modern version of a data frame. To convert our data to this data structure, we use the `as_tibble()` function. In practice, there are only very slight differences between the two data structures, and you generally do not need to convert data frames to tibbles.
