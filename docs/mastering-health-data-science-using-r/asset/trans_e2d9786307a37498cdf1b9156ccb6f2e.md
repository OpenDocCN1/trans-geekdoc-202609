如所示，吸烟状态已被编码为三个类别：“NeverSmoke”、“QuitSmoke”和“StillSmoke”。我们想创建一个新列来表示某人是否曾经吸烟。为此，我们使用 `ifelse()` 函数，该函数允许我们使用逻辑来创建新向量。此函数捕获的逻辑是：如果满足某个条件，我们使用一个值；如果不满足条件，则使用第二个值。第一个参数是表示条件的 TRUE/FALSE 向量，下一个参数是满足条件时要使用的值或向量，最后一个参数是其他情况下要使用的值或向量。我们用此函数创建一个新向量 `EVER_SMOKE`，对于仍在吸烟或已戒烟的人，它等于“Yes”，否则等于“No”。

```
nhanes_df$EVER_SMOKE <- ifelse(nhanes_df$SMOKE %in% c("QuitSmoke",
"StillSmoke"),
"Yes", "No")
table(nhanes_df$EVER_SMOKE)

#> No Yes
#> 1411 1173

```
ifelse(nhanes_df$SMOKE %in% c("QuitSmoke", "StillSmoke"),
"Yes", "No") |>
table()
#>
#> No Yes
#> 1411 1173

## 4.2 双变量分布

现在我们将注意力转向多列之间的关系。当拥有两个分类列时，我们可以使用 `table()` 函数查找所有组合中的计数。例如，我们查看按性别分层的吸烟状态分布。我们观察到，更高比例的女性参与者从未吸烟。

![](img/58a554e865d49ca347d9a3f76f8f0812_83_0.png)

```
table(nhanes_df$SMOKE, nhanes_df$SEX)
#>
#>           Male Female
#> NeverSmoke   596    815
#> QuitSmoke    390    241
#> StillSmoke   324    218
#>
```

为了查看按分类列分层的连续列的样本分布，我们可以对数据的每个子集调用 `summary()` 函数。在后续代码中，我们查看按性别分层的血铅水平分布，并观察到男性观测值中的血铅水平更高。

```
summary(nhanes_df$LEAD[nhanes_df$SEX == "Female"])
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max.
#>  0.100   0.470   0.770   0.980   1.210   8.670
summary(nhanes_df$LEAD[nhanes_df$SEX == "Male"])
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max.
#>  0.050   0.700   1.090   1.460   1.660  22.010
```

我们还可以通过箱线图直观地观察到这一点。当给定一个分类列和一个连续列时，`plot()` 函数会创建一个箱线图。默认情况下，第一个参数是 x 轴，第二个参数是 y 轴。

```
plot(nhanes_df$SEX, log(nhanes_df$LEAD), ylab = "Log Blood Lead
    ~ Level",
    xlab = "Sex")
```

![](img/58a554e865d49ca347d9a3f76f8f0812_84_0.png)

或者，我们可以使用 `boxplot()` 函数，该函数可以接受公式。公式是数据分组方式的字符串表示，其中左侧是连续列，右侧是一个或多个用于分组的分类列。在以下示例中，我们按多个列 `SEX` 和 `EVER_SMOKE` 分组，因此公式为 `log(LEAD) ~ SEX + EVER_SMOKE`。函数的第二个参数指定数据。我们指定列颜色以显示所示箱线图之间的联系。

```
boxplot(log(LEAD) ~ SEX + EVER_SMOKE, data = nhanes_df,
    col=c("orange", "blue", "orange", "blue"),
    xlab = "Sex : Ever Smoked", ylab = "Log Blood Lead Level")
```

这两种血压测量值看起来高度相关。我们可以使用 `cor()` 函数计算它们的 Pearson 和 Spearman 相关性。默认方法是 Pearson 相关性，但我们也可以通过指定方法来计算 Kendall 或 Spearman 相关性。

```
cor(nhanes_df$SBP1, nhanes_df$DBP1)
#> [1] 0.417
cor(nhanes_df$SBP1, nhanes_df$DBP1, method = "spearman")
#> [1] 0.471
```

我们可能还想在绘图上添加一些额外信息。这次，我们不手动指定颜色，而是使用 `hyp` 列（高血压指示变量）来指定颜色。我们必须确保该向量是因子，以便 R 按组着色。此外，我们使用 `abline()` 函数添加一条蓝色的垂直线和水平线，以标记高血压的截断值。尽管此函数是在 `plot()` 之后调用的，线条仍会自动添加到当前绘图中。我们可以看到，大多数高血压患者的收缩压或舒张压测量值都高于该阈值。

```
plot(nhanes_df$SBP1, nhanes_df$DBP1, col = as.factor(nhanes_df$HYP),
 xlab = "Systolic Blood Pressure",
 ylab = "Diastolic Blood Pressure")
abline(v = 130, col = "blue")
abline(h = 80, col = "blue")
