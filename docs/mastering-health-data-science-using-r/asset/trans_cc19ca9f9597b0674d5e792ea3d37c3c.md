### 15.3 最佳子集

我们在本章介绍的第二个包允许我们拟合带有 L0 惩罚项的模型。**L0learn** 包考虑以下形式的惩罚：

- 仅 L0: λ‖β‖₀
- L0L1: λ‖β‖₀ + γ‖β‖₁
- L0L2: λ‖β‖₀ + γ‖β‖₂²

为了拟合带有 L0 惩罚项的模型，我们使用 `L0learn.fit()` 函数。与 `glmnet()` 类似，我们需要指定输入矩阵 x、响应向量 y，并通过 `penalty` 参数指定我们的惩罚项。我们还可以通过 `nLambda` 指定要考虑的 λ 值数量，并通过损失函数 `loss` 指定模型族。

```r
mod_l0 <- L0learn.fit(x, y, penalty = "L0", loss = "SquaredError",
                     nLambda = 20)
```

绘制返回对象还会显示每个变量的系数如何随惩罚项变化；在本例中，惩罚项以支撑集大小（即非零系数数量）表示。我们还可以打印返回对象，以查看所使用的不同 λ 值以及对应的包含变量数量。

```r
plot(mod_l0)
```
