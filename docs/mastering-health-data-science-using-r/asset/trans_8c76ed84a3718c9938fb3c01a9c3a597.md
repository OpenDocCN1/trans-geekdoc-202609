## 1 使用 R 入门

本章将向您介绍 R 作为一种编程语言，并展示我们可以以两种不同方式使用这种语言：直接通过 R 控制台，以及使用 RStudio 开发环境。要开始，您需要下载 R[^1] 和 RStudio[^2]。

### 1.1 为什么选择 R？

使用 R 有哪些好处？

- R 是为统计学家和数据分析师构建的。
- R 是开源的。
- R 提供了大部分最新的统计方法。
- R 灵活。

由于 R 是为统计学家设计的，它在构建时就以数据为中心。当我们希望简化数据处理和分析方式时，这非常有用。这也意味着许多从事新方法研究的统计学家正在 R 中发布用户创建的包，因此 R 用户可以使用大部分感兴趣的方法。R 也是一种解释型语言，这意味着我们不需要先将代码编译成机器语言；这使得编写代码时语法更简单、灵活性更高，也使其成为学习的绝佳第一门编程语言。

Python 是另一种常用于数据分析的解释型语言。两种语言都具有简单灵活的语法，但 Python 更广泛地开发用于数据科学和统计分析之外的用途，而 R 是健康数据科学领域人士的绝佳编程语言。我两种语言都使用，并发现在这两者之间切换很直接，但我确实更偏好 R 用于任何与数据或统计分析相关的工作。

[^1]: https://cran.rstudio.com/
[^2]: https://posit.co/download/rstudio-desktop/

### 1.1.1 安装 R 和 RStudio

要在计算机上运行 R，您需要下载并安装 R。这使您可以打开 R 应用程序并交互式运行 R 代码。但是，为了充分利用 R 编程，您应该安装 RStudio，它是 R 的集成开发环境（IDE）。RStudio 为编写、编辑、运行和调试 R 代码提供了良好的环境。

本书的每一章都作为 Quarto 文档编写，也可以下载为 Jupyter 笔记本。您可以在 RStudio 中打开 Quarto 文件，以便在阅读时运行代码并完成练习题和习题。

### 1.2.1 基本计算和对象

在前面的示例中，我们编写了一个简单的加法。尝试使用以下运算符进行一些其他基本计算：

- 加法：5+6
- 减法：7-2
- 乘法：2*3
- 除法：6/3
- 幂运算：4^2
- 取模：100 %% 4

例如，使用取模运算符来查找 100 mod 4 是多少。它应该返回 0，因为 100 可以被 4 整除。

如果我们想保存任何计算的结果，需要创建一个对象来存储我们感兴趣的值。对象只是一个命名的数据结构，允许我们引用该数据结构。对象也通常称为 **变量**。在以下代码中，我们创建一个对象 x，使用赋值运算符 <- 存储值 5。赋值运算符将运算符右侧的内容赋给左侧的名称。我们现在可以通过调用其名称来引用 x。此外，我们可以通过加 1 来更新其值。在第二行代码中，计算机首先通过查找 x 的当前值来确定右侧的值，然后加 1 并将其重新赋给 x。

```r
x <- 2+3
x <- x+1
x
#> [1] 6
```

我们可以通过使用不同的名称来创建和存储多个对象。以下代码创建一个新对象 y，其值比 x 大 1。我们可以看到，运行此代码后 x 的值仍然是 5。

```r
x <- 2+3
y <- x
```

```r
y <- y + 1
x
#> [1] 5
```

### 1.2.2 命名约定

当我们开始创建对象时，我们希望确保使用良好的对象名称。以下是有效命名对象的一些技巧：

- 坚持使用单一格式。我们使用 **snake_case**，即单词之间使用下划线（例如，`my_var`、`class_year`）。
- 使您的名称有用。尽量避免使用过长的名称（例如，`which_day_of_the_week`）或不包含足够信息的名称（例如，`x1`、`x2`、`x3`）。
- 使用命名对象替代未解释的数值。例如，如果您需要使用 100 作为参与者数量进行一些计算，请创建一个值为 100 的对象 `n_part`，而不是反复使用该数字。这使代码易于更新，并帮助用户避免可能的错误。

### 1.3 RStudio 和 Quarto

如果我们在控制台中输入的代码出现错误，就必须从头重新输入所有内容。但是，当我们编写代码时，通常希望能够多次运行它并分阶段开发。R 脚本和 R Markdown 文件允许我们将所有 R 代码保存在可以更新和重新运行的文件中，从而创建可重复且易于共享的分析。我们现在转到 RStudio 作为开发环境来演示创建 R 脚本。打开 RStudio 时，会有多个窗口。首先通过 文件 → 新建文件 → R 脚本 打开一个新的 R 文件。您现在应该能看到图 1.2 中概述的几个窗口。

### 1.3.1 窗格

默认情况下显示四个窗格：

- **源代码窗格** - 用于编辑 R 脚本或 Quarto 文档等代码文件。

![](img/58a554e865d49ca347d9a3f76f8f0812_21_0.png)

图 1.2：RStudio 布局和窗格。

- **控制台窗格** - 用于显示实时 R 会话。
- **环境窗格** - 包含环境和历史记录选项卡，用于跟踪当前状态。
- **输出窗格** - 包含图表和包选项卡。

源代码窗格是左上角的代码编辑器窗口。这显示您当前空白的 R 脚本。将以下代码添加到您的 .R 文件中，并将文件保存为“test.R”。请注意，这里我们使用 snake_case 来命名对象！

```r
# Calculate primary care physician to specialist ratio
pcp_phys <- c(6300, 1080, 9297, 16433)
spec_phys <- c(6750, 837, 10517, 22984)
pcp_spec_ratio <- 1000 * pcp_phys / spec_phys
```

第一行以 # 开头且不包含任何代码。这是一行注释，允许我们添加上下文、意图或额外信息，以帮助读者理解我们的代码。一个好的经验法则是，我们希望编写足够的注释，以便在 6 个月后打开代码并能够理解我们当时在做什么。随着我们开发更长的代码块，这将变得更加重要。

与在控制台中输入代码不同，我们可以在 R 脚本中编写多行代码而不运行它们。为了运行脚本中的代码，我们需要告诉 RStudio 我们已准备好运行。要运行单行代码，可以在该行按 Ctrl+Enter，也可以点击源代码窗格右上角的运行按钮。这会将代码复制到 R 控制台。尝试运行定义 pcp_phys 的第一行代码。您可以看到该行代码已在控制台窗格中运行。现在检查您的环境窗格。您应该能看到有一个新对象，代表我们刚刚创建的对象。此窗格跟踪所有当前对象。运行第二行代码并查看环境如何更新。如果查看此窗格中的历史记录选项卡，您会看到已运行的 R 命令历史记录。

如果我们想运行脚本中的所有代码行，可以使用源按钮。在这样做之前，我们将清除环境。您可以通过点击环境窗格中的扫帚图标来完成此操作，它会删除环境中的所有对象。或者，您可以进入主菜单中的 会话 -> 重新启动 R，这将重新启动整个 R 会话。清除环境后，点击源按钮。您会看到在 R 控制台中显示它已源此文件。这意味着它运行该文件中的所有代码行。您可以看到我们的对象已重新添加到环境中。

```r
source("test.R")
```

现在假设我们想通过添加图表来更新脚本。复制后续代码块中的代码，保存更新后的文件，然后源您的文件。您将看到生成的图表将出现在输出窗格中。

```r
plot(spec_phys, pcp_phys)
```
