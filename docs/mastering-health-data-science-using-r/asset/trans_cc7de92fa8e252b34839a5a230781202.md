## 10 R 中的概率分布

在本章中，我们介绍如何在 R 中从已知概率分布和经验分布生成随机样本。基础 R 为所有常见概率分布提供了一组四个函数。这些函数可用于生成随机样本，并计算与该分布对应的密度、分位数和累积函数。

```r
library(tidyverse)
library(HDSinRdata)

```

在下面的代码中，我们演示一个抽取随机样本的示例。每当我们执行 R 中结果带有随机性的操作时，底层使用的都是 R 的随机数生成器。这意味着每次运行代码，结果都会发生变化。为了保证代码的可复现性，我们必须设置一个随机种子，这样每次得到的结果才会相同。`set.seed()` 函数接受一个数值型种子值，你可以使用任何数字作为种子。在下一个代码块中，我们首先在没有设置种子的情况下从 1 到 10 中随机抽取一个值。请注意，每次运行该代码块，输出都可能不同。然而，在接下来的代码块中我们设置了种子，这意味着结果始终是相同的（在本例中，结果等于 2）。

```r
sample(1:10, 1)
#> [1] 1
```

```r
set.seed(5)
sample(1:10, 1)
#> [1] 2
```

### 10.1 概率分布函数

所有常见的离散概率分布（如伯努利分布、二项分布）和连续概率分布（如正态分布、均匀分布、指数分布、泊松分布）在 R 中都有对应的函数。这些分布中的每一种都有四个可用的函数：

- `r[dist]()`：给定分布的随机样本函数（例如 `rnorm()`、`runif()`）
- `d[dist]()`：该分布的密度函数（例如 `dnorm()`、`dunif()`）
- `p[dist]()`：该分布的累积分布函数（例如 `pnorm()`、`punif()`）
- `q[dist]()`：该分布的分位数函数（例如 `qnorm()`、`qunif()`）

让我们以正态分布和二项分布为例，看看这些函数的实际用法。

#### 10.1.1 随机样本

下面的代码生成 100 个服从均值为 5、标准差为 1 的正态分布的随机数。如你所见，该函数接受 n（观测值数量）、mean（均值，默认值为 0）和 sd（标准差，默认值为 1）。直方图（使用内置的 hist() 函数）显示生成的值大致呈正态分布。

```r
x <- rnorm(n = 100, mean = 5, sd = 1)
hist(x)
```

对于二项分布，区别在于我们需要指定概率 p 和试验次数 size（而不是正态分布中的 mean 和 sd）来确定分布。在下面的代码中，我们生成 100 个服从试验次数为 10、概率为 0.5 的二项分布的随机数。

```r
x <- rbinom(n = 100, p = 0.5, size = 10)
hist(x)
```

#### 10.1.2 密度函数

接下来，我们来看密度函数。回顾一下，均值为 \(\mu\)、标准差为 \(\sigma\) 的正态分布的概率密度函数由以下公式给出。

\(f_X(x) = \frac{1}{\sigma\sqrt{2\pi}} \exp \left( -\frac{1}{2} \left( \frac{x-\mu}{\sigma} \right)^2 \right)\)

使用下面的代码，我们可以将 `dnorm()` 函数的一些值与这个方程进行比较，发现它们实际上是相等的。我们也可以在这个函数中指定均值和标准差，但这里我们选择使用默认值（mean = 0，sd = 1）。

```r
dnorm(0) == 1/sqrt(2*pi)
#> [1] TRUE
dnorm(1) == exp(-1/2)/sqrt(2*pi)
#> [1] TRUE
dnorm(2) == exp(-1/2*2^2)/sqrt(2*pi)
#> [1] TRUE
```
