## 前言

本书旨在为公共卫生与健康数据科学学生提供 R 语言的交互式入门。主题涵盖 R 中的数据结构、探索性分析、分布、假设检验、回归分析，以及涉及函数和控制流的更大规模编程。本书假设读者已具备相关方法论知识，重点在于如何使用 R 来实施你的分析。

本书使用 Quarto Book 编写。你可以从 GitHub 仓库[^1]下载用于生成本书的 Quarto 文件或相应的 Jupyter Notebook。GitHub 仓库中还包含一些速查表[^2]。
