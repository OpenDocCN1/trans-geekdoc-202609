### 9.1 预处理

我们首先清理和合并数据。`covidcases`数据包含2020年州和县一级每周确诊的COVID-19病例和死亡数。如数据描述所述，由于累计计数数据存在差异，其中一些值可能为负。`mobility`数据包含各州的每日流动统计数据。

```r
# Read in data
data(covidcases)
data(mobility)
```

首先，我们查看数据中的列。我们使用`as.Date()`函数将`mobility`数据中的日期列转换为可识别的日期。`covidcases`数据包含2020年的周数。我们为`mobility`数据创建一个类似的列。

```r
# Convert to date format and find week
mobility$date <- as.Date(mobility$date, format = "%Y-%m-%d")
mobility$week <- week(mobility$date)
```

这使我们能够汇总每个州每周的流动情况。

```r
# Find average mobility for week
mobility_week <- mobility %>%
  group_by(state, week) %>%
  summarize(m50 = mean(m50, na.rm = TRUE), .groups = "drop")
head(mobility_week)
```

检查州和周的列格式后，我们现在可以合并数据。在这种情况下，我们希望将mobility数据添加到病例数据中，并使用`left_join()`。

```r
# Join cases and mobility data
covid <- left_join(covidcases, mobility_week, by = c("state", "week"))
```

接下来，我们想获取数据中连续变量的一些简单信息。我们观察到两个关键点。首先，我们看到了数据描述中警告的负值，其次，没有缺失数据。

```r
summary(covid[, c("weekly_cases", "weekly_deaths", "m50")])
```

这些负数明显是数据差异。在我们的探索性分析中展示病例分布时，我们可以选择将这些值编码为0或NA。我们决定将这些负值重新编码为NA。

```r
# Set negative counts to NA
covid$weekly_cases <- replace(covid$weekly_cases,
                              which(covid$weekly_cases < 0),
                              NA)

covid$weekly_deaths <- replace(covid$weekly_deaths,
                               which(covid$weekly_deaths < 0),
                               NA)
```

作为预处理的最后一步，我们使用R中可用的`state.name`和`state.region`向量为每个州添加州缩写和地区。我们将D.C.编码为与马里兰州和弗吉尼亚州相同的地区。

```r
# Add region and abbreviation and remove county
region_key <- data.frame(state = c(state.name,
                                   "District of Columbia"),
                         state_abb = c(state.abb, "DC"),
                         region = c(as.character(state.region),
                                    "South"))

covid <- covid %>%
    left_join(region_key, by = c("state"))

head(covid)
```
