### 4.3 自动生成的图形

例如 `ggpairs()` 函数。`ggpairs()` 函数将数据作为其第一个参数。默认情况下，它会绘制所有列的成对分布，但我们也可以使用 `columns` 参数指定仅选择部分列。在下面的示例中，您可以看到它为每个单变量样本分布绘制了条形图和密度图。然后，它绘制双变量分布，并计算所有连续列对的 Pearson 相关系数。这些信息相当丰富！

```
ggpairs(nhanes_df, columns = c("SEX", "AGE", "LEAD", "SBP1", "DBP1"))
```

![](img/58a554e865d49ca347d9a3f76f8f0812_89_0.png)

该包中另一个有用的函数是 `ggcorr()` 函数。此函数接受一个仅包含数值列的数据框，并显示所有列对之间的相关性，其中每个网格单元的颜色表示相关性的强度。额外参数 `label=TRUE` 会在每个网格单元上打印实际的相关系数值。这是识别强相关列对的有效方法。请注意，我们再次使用管道运算符来计算连续列的相关性，而无需保存该数据子集。

```
nhanes_df[, c("AGE", "LEAD", "SBP1", "DBP1")] |>
ggcorr(label = TRUE)
```

### 4.4 表格
