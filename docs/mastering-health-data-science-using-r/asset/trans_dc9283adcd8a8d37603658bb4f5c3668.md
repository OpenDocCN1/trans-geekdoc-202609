### 1.3.2 调用函数

当我们使用 R 时，我们可以使用基础 R 中所有可用的函数。一个**函数**接收一个或多个输入，并返回一个单一的输出对象。让我们先使用简单的函数 `exp()`。这个指数函数接收一个（或多个）数值输入，并对它们进行指数运算。以下代码计算 $e^3$。

```
exp(3)
#> [1] 20.1
```

下面展示了一些其他简单函数，它们都将数值输入转换为整数值。`ceiling()` 和 `floor()` 函数分别返回输入的向上取整和向下取整结果，`round()` 函数将输入四舍五入到最接近的整数。请注意，`round()` 函数会将结尾为 0.5 的数字四舍五入到最接近的偶数。

```
ceiling(3.7)
#> [1] 4
```

```
floor(3.7)
#> [1] 3
```

```
round(2.5)
#> [1] 2
round(3.5)
#> [1] 4
```

如果我们想了解某个函数，可以使用帮助运算符 `?`，将其放在感兴趣的函数前面：这会调出该特定函数的文档。这些文档通常会告诉你函数的用法、参数（对象输入）和返回值（关于返回对象的信息），并给出一些如何使用该函数的示例。例如，如果我们想理解 `floor()` 和 `ceiling()` 之间的区别，可以调用 `?floor` 和 `?ceiling`。这应该会在帮助窗口中调出文档。然后我们可以读到，`floor()` 函数将数值输入向下舍入到最接近的整数，而 `ceiling()` 函数将数值输入向上舍入到最接近的整数。

### 1.3.4 安装和加载包

在处理数据框时，我们经常使用 tidyverse 包（Wickham 2023），它实际上是一组用于数据科学应用的 R 包的集合。R 包是一组函数和/或示例数据的集合，使我们能够扩展 R 超出基础函数的功能。你可以通过转到 RStudio 输出窗格中的“包”选项卡来检查是否已安装 tidyverse 包，或者运行以下命令，该命令会显示所有已安装的包。

```
installed.packages()
```

如果你还没有安装某个包，可以使用 `install.packages()` 函数进行安装。请注意，使用此函数时，包名必须用单引号或双引号括起来。每个包只需安装一次。

```
install.packages('tidyverse')
```

函数 `read_csv()` 是另一个读取逗号分隔文件的函数，它属于 tidyverse 中的 readr 包（Wickham, Hester, and Bryan 2023）。然而，如果我们尝试使用这个函数加载数据，会收到找不到该函数的错误。这是因为我们还没有加载这个包。要加载它，我们使用 `library()` 函数。与 `install.packages()` 函数不同，在调用 `library()` 函数时，我们不必在包名周围使用引号。当我们加载一个包时，会看到一些消息。例如，在以下输出中，我们看到该包包含 `filter()` 和 `lag()` 函数，这些函数在基础 R 中也存在。在后续章节中，我们会隐藏这些消息，以使章节呈现更美观。加载 **tidyverse** 包后，我们现在就可以使用 `read_csv()` 函数了。

```
library(tidyverse)
```

```
df <- read_csv("data/fake_names.csv", show_col_types=FALSE)
df

##   Name    Age DOB       City         State

```

或者，我们也可以通过添加 `readr::` 来告诉 R 函数所在的位置。这会告诉 R 在 **readr** 包中查找 `read_csv()` 函数。即使我们已经加载了该包，这样做也很有帮助，因为有时多个包中的函数同名。

```
df <- readr::read_csv("data/fake_names.csv", show_col_types = FALSE)
```

### 1.4 RStudio 项目与 RStudio 全局选项

现在你已经对 RStudio 有了基本的了解。关闭 RStudio 时，你可以选择是否存储当前的 R 环境。我们强烈建议你更新 RStudio 选项，使其在退出时不保存工作空间，在启动时不加载工作空间。这可以确保每次打开 RStudio 时都有一个全新的环境，并帮助你编写完全可重现的代码，避免可能出现的错误或混淆（图 1.4）。

现在，当你重新打开 RStudio 时，它会打开之前打开过的文件并保留你的命令历史。当你处理不同文件时，这可能会变得混乱。RStudio 项目允许我们创建一个与单个项目关联的文件夹。这意味着当我们打开项目时，它会自动设置适当的工作目录，并且只打开与该项目相关的文件。要创建新的 R 项目，例如与本书关联的项目，可以转到“文件 -> 新建项目”。然后，你可以选择创建新目录或使用现有目录，再选择创建空项目，如图 1.5 所示。在此目录中，你应该会看到一个 .RProj 文件，它允许你重新打开项目。
