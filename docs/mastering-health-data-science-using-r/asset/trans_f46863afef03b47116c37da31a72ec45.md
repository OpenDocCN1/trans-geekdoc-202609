## 15 模型选择

在第 13 章和第 14 章中，我们介绍了一种简单的模型选择方法：逐步选择。本章通过聚焦正则化回归，扩展了 R 中的模型选择工具。我们介绍的两个包是 **glmnet** (Friedman, Tibshirani, and Hastie 2010) 和 **L0Learn** (Hazimeh, Mazumder, and Nonet 2023)。这两个包侧重于不同类型的模型正则化。

```r
library(HDSinRdata)
library(tidyverse)
library(glmnet)
library(L0Learn)
```

为演示这些包，我们使用与第 13 章相同的激励示例。回顾，NHANESsample 数据集包含来自 NHANES 1999-2018 的铅、血压、BMI、吸烟状态、饮酒情况和人口统计变量。我们关注血铅水平与收缩压之间的关联。我们首先通过对所有测量值取平均来创建单一的收缩压。在删除我们希望从分析中排除的变量之前，我们还对铅进行了对数变换。

```r
# load in data
data(NHANESsample)

# transform SBP and lead

  rowMeans(NHANESsample[c("SBP1", "SBP2", "SBP3", "SBP4")],

na.omit()

nhanes$RACE <- factor(nhanes$RACE)
nhanes$EDUCATION <- factor(nhanes$EDUCATION)
nhanes$BMI_CAT <- factor(nhanes$BMI_CAT)
nhanes$ALC <- factor(nhanes$ALC)
```

### 15.1 正则化回归

假设我们有一个数值数据矩阵 \(X \in \mathbb{R}^{n \times p}\) 和结果向量 \(y \in \mathbb{R}^n\)。我们令 \(x_i\) 表示 \(X\) 第 \(i\) 行的向量。这对应于第 \(i\) 个观测值。当我们提到正则化回归时，指的是求解以下最小化平均损失加上惩罚项的优化问题。

\(\min_{(\beta_0, \beta) \in \mathbb{R}^{p+1}} \frac{1}{n} \sum_{i=1}^n l(y_i, \beta_0 + \beta^T x_i) + \text{Pen}(\beta) \tag{15.1}\)

函数 \(l(y_i, \beta_0 + \beta^T x_i)\) 表示损失函数。对于线性回归，这对应于平方误差 \((y_i - \beta_0 - \beta^T x_i)^2\)。对于逻辑回归，该损失对应于逻辑损失函数。

我们实现的惩罚项包括以下内容：

- *L0 范数：* \(||\beta||_0 = \sum_{j=1}^p 1(\beta_j \neq 0)\)，非零系数的数量，

- *L1 范数：* \(||\beta||_1 = \sum_{j=1}^p |\beta_j|\)，系数绝对值之和，以及

- *平方 L2 范数：* \(||\beta||_2^2 = \sum_{j=1}^p \beta_j^2\)，平方系数之和。

### 15.2 弹性网

我们首先考虑 L1 和 L2 正则化。特别是，考虑以下惩罚项，称为弹性网正则化，

\(\lambda \left[ \alpha ||\beta||_1 + (1 - \alpha) ||\beta||_2^2 \right],\)

其中 λ 是复杂度参数，α 控制两个范数之间的平衡。仅具有 L1 正则化（α = 1）的模型对应于 Lasso 回归，而仅具有 L2 正则化（α = 0）的模型对应于岭回归。请注意，惩罚项取决于 X 的尺度，我们通常假设每一列都已标准化。

**glmnet** 包实现了弹性网正则化。它假设我们的数据采用之前描述的形式。因此，我们首先创建数值数据矩阵 x 和输出向量 y。我们的一些变量是分类变量，因此为了创建数值矩阵，我们需要对它们进行独热编码。我们可以使用 `model.matrix()` 函数来实现这一点，该函数接受一个公式和一个数据框，并创建相应的设计矩阵，包括从因子变量创建虚拟变量并实现任何变换。请注意，我们删除第一个生成的列，该列对应于截距。对结果变量的变换不影响结果。

我们的结果向量对应于对数变换后的收缩压。

```r
y <- log(nhanes$SBP)
```

glmnet() 函数拟合弹性网回归模型。这要求我们指定输入矩阵 x 和响应变量 y。此外，我们可以使用 family 参数指定 y 的假设分布。在随后的示例中，我们使用 α = 1 和 25 个不同的 λ 值拟合此模型。默认情况下，glmnet() 将 α 设置为 1 并创建 100 个不同 lambda 值的网格。默认也会对 x 进行标准化，我们可以通过在函数调用中指定 standardize = FALSE 来关闭它。

```r
mod_lasso <- glmnet(x, y, family = "gaussian", alpha = 1,
                   nlambda = 25)
```

如果绘制结果对象，我们可以通过绘制每个变量的系数如何随 λ 值变化，来查看每个结果模型的模型系数。plot() 函数默认将这些与惩罚项绘制在一起，但我们也可以指定在 log 尺度上针对 λ 值进行绘制。label 参数为每条线添加标签，但这些标签通常难以读取。图表顶部的数字指示不同 λ 值下模型中包含的非零系数数量。阅读文档 ?glmnet 以查看其他可能的输入，包括 penalty.factor 和 weights 参数。

```r
plot(mod_lasso, xvar = "lambda", label = TRUE)
```
