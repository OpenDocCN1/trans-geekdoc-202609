在百分比变化的汇总中，我们可以看到最大值是 Inf。这是 R 对无穷大的表示。之所以出现这种情况，是因为一些患者的初始疼痛评分为 0，当我们通过该值进行除法以计算百分比变化时，会产生无穷大值。我们可以使用 `is.infinite()` 或 `is.finite()` 函数来测试某个值是否为无穷大。这表明有三名患者的值为无穷大。值 -Inf 用于表示负无穷大。

```r
sum(is.infinite(pain$PERC_PAIN_CHANGE))
#> [1] 3
```

R 中的另一个特殊值是 NaN，它代表“不是一个数字”（Not a Number）。例如，0/0 的结果是一个 NaN 值。我们可以使用 `is.nan()` 函数来测试 NaN 值。

```r
0/0
#> [1] NaN
```

回顾缺失值，有两个有用的函数可用于选择数据框中的完整案例。`na.omit()` 函数返回移除了不完整案例的数据框，而 `complete.cases()` 为每一行返回 TRUE/FALSE 值，指示每一行是否完整，我们可以随后使用这些值来选择值为 TRUE 的行。在以下代码中，我们可以看到两种方法选择的行数相同。

```r
pain_sub1 <- na.omit(pain)
pain_sub2 <- pain[complete.cases(pain), ]
```

### 3.2.6 R 中的日期

`pain` 数据中的列包含字符和数值。一种不存在的特殊字符列类型是对应日期或日期时间的列。默认情况下，`read.csv()` 将这些列读取为字符列，而 **tidyverse** 家族中 **readr** 包的 `read_csv()` 函数能识别常见的日期格式。如果我们有一个字符列，可以使用 `as.Date()` 转换为日期列，使用 `as.POSIXct()` 转换为日期时间列。对于只有时间而没有日期的列，可以添加一个日期或使用 **hms** 包（Müller 2023），此处不作演示。这些函数会自动尝试检测输入字符串的格式，但提供 `format` 和时区 `tz` 通常很有帮助。要输入我们的格式，我们使用以下键。

| 符号 | 说明 |
| :--- | :--- |
| `%Y` | 四位年份。 |
| `%y` | 两位年份。 |
| `%m` | 数字月份。 |
| `%b` | 月份的缩写名称。 |
| `%B` | 月份的全称。 |
| `%d` | 月份中的数字日期。 |
| `%H` | 军用时间小时（24 小时制）。 |
| `%I` | 12 小时制小时（12 小时）。 |
| `%M` | 分钟。 |
| `%S` | 秒。 |
| `%p` | 上午/下午。 |

```r
date_example <- data.frame(x = c("2020-01-15", "2021-11-16",
                                     "2019-08-01"),
                               y = c("2020-01-15 3:14 PM",
                                     "2021-11-16 5:00 AM",
                                     "2019-08-01 3:00 PM"),
                               z = c("04:10:00", "11:35:11", "18:00:45"))
# Convert date and date times using formats
date_example$x <- as.Date(date_example$x, format = "%Y-%m-%d",
                              tz = "EST")
date_example$y <- as.POSIXct(date_example$y,
                                 format = "%Y-%m-%d %I:%M %p")
# Add date to z and convert
date_example$z <- paste("2024-06-24", date_example$z)
date_example$z <- as.POSIXct(date_example$z,
                                 format = "%Y-%m-%d %H:%M:%S")
date_example
#>         x                   y                   z
#> 1 2020-01-15 2020-01-15 15:14:00 2024-06-24 04:10:00
#> 2 2021-11-16 2021-11-16 05:00:00 2024-06-24 11:35:11
#> 3 2019-08-01 2019-08-01 15:00:00 2024-06-24 18:00:45
```

通过将这些列识别为日期，我们可以使用 `difftime()` 函数计算两个日期之间的时间。该函数接收两个时间 time1 和 time2，并计算给定单位下的差值 time1 - time2。

```r
difftime(date_example$x[2], date_example$x[1], units = "days")
#> Time difference of 671 days
```

此外，我们可以使用 `seq()` 函数通过为 `by` 指定单位来添加或减去时间。

```r
seq(date_example$x[1], by = "month", length = 3)
#> [1] "2020-01-15" "2020-02-15" "2020-03-15"
```

对于有兴趣进行更多日期操作的读者，tidyverse 中的 lubridate 包（Spinu, Grolemund, and Wickham 2023）扩展了 R 用于处理日期的基础功能。该包使用其自己的日期时间类，并包含用于轻松从日期中提取信息和操作日期的函数。

## 3.3 使用逻辑进行子集化、汇总和转换

我们已经了解如何使用 TRUE/FALSE 值来选择数据框中的行。R 中的以下逻辑运算符使我们能够扩展此功能，以编写更复杂的逻辑。

- `<` 小于
- `<=` 小于或等于
- `>` 大于
- `>=` 大于或等于
- `==` 等于
- `!=` 不等于
- `a %in% b` a 的值在值向量 b 中

前六个运算符是两个值之间的直接比较。

```r
2 < 2
#> [1] FALSE
2 <= 2
#> [1] TRUE
3 > 2
#> [1] TRUE
3 >= 2
#> [1] TRUE
"A" == "B"
#> [1] FALSE
"A" != "B"
#> [1] TRUE
```

这些运算符假设值之间存在自然顺序或比较。例如，对于字符串，顺序是字母顺序；对于逻辑运算符，我们使用它们的数值解释（TRUE == 1，FALSE == 0）。

```r
"A" < "B"
#> [1] TRUE
TRUE < FALSE
#> [1] FALSE
```

`%in%` 运算略有不同。该运算符检查一个值是否在一组可能的值中。例如，我们可以检查值是否在集合 c(4, 1, 2) 中。

```r
1 %in% c(4, 1, 2)
#> [1] TRUE
c(0, 1, 5) %in% c(4, 1, 2)
#> [1] FALSE TRUE FALSE
```

此外，我们可以使用以下运算符，它们允许我们否定或组合逻辑运算符。

- `!x` - 非运算符 `!` 反转 TRUE/FALSE 值
- `x | y` - 或运算符 `|` 检查 x 或 y 是否其中之一等于 TRUE
- `x & y` - 与运算符 `&` 检查 x 和 y 是否都等于 TRUE
- `xor(x, y)` - xor 函数检查 x 或 y 是否恰好有一个等于 TRUE（称为异或）
- `any(x)` - any 函数检查 x 中是否有任何值为 TRUE（等同于在所有值之间使用或运算符 `|`）
- `all(x)` - all 函数检查 x 中是否所有值都为 TRUE（等同于在所有值之间使用与运算符 `&`）

以下代码块给出了每个运算符的一些简单示例。

```r
!(2 < 3)
#> [1] FALSE
("Alice" < "Bob") | ("Alice" < "Aaron")
#> [1] TRUE
("Alice" < "Bob") & ("Alice" < "Aaron")
#> [1] FALSE
xor(TRUE, FALSE)
#> [1] TRUE
any(c(FALSE, TRUE, TRUE))
#> [1] TRUE
all(c(FALSE, TRUE, TRUE))
#> [1] FALSE
```

让我们在 pain 数据上演示这些运算符。我们首先通过使字符值更具信息性来更新 Medicaid 列。左侧的逻辑选择有或没有 Medicaid 的人，然后将这些值分配给新值。

```r
pain$MEDICAID_BIN[pain$MEDICAID_BIN == "no"] <- "No Medicaid"
pain$MEDICAID_BIN[pain$MEDICAID_BIN == "yes"] <- "Medicaid"
table(pain$MEDICAID_BIN)
#>
#>
#> Medicaid No Medicaid
#> 4601 16757
```

此外，我们可以将数据子集化为仅包含有随访记录的人。非运算符 `!` 反转 `is.na()` 函数返回的 TRUE/FALSE 值。因此，如果随访值不是 NA，则新值为 TRUE。

```r
pain_follow_up <- pain[!is.na(pain$PAIN_INTENSITY_AVERAGE.FOLLOW_UP),
                           ]
```

此前，我们创建了一个指示患者是否患有腰痛的列。现在我们使用 `any()` 函数来检查患者是否患有一般性背痛。如果这些值中至少有一个等于 1，则函数返回 TRUE。如果我们改用 `all()` 函数，则会检查所有值是否都等于 1，表明患者整个背部都有疼痛。

```r
pain$BACK <- any(pain$X208==1, pain$X209==1, pain$X212==1,
                     pain$X213==1, pain$X218==1, pain$X219==1)
```
