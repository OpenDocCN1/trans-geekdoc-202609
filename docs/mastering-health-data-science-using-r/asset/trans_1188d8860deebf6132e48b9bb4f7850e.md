## 8.2 调整坐标轴和美学元素

我们可以使用 scale 函数进一步控制每个美学元素的显示方式。例如，假设我想更新之前的图表。特别是，我首先想将 x 轴更新为显示 0 到 10 的所有值，而不是 0、2.5、5 等。要更新 x 轴，我需要找到适用于连续值的 x 的相应 scale 函数。该函数是 `scale_x_continuous()`，它允许我指定限制（`limits`）、断点（`breaks`）和标签（`labels`）。scale 函数可以在速查表的第二张表中找到。在此示例中，我只想将断点更新为 0 到 10 的所有整数值。

```r
ggplot(pain_df)+
geom_histogram(aes(x = PAIN_INTENSITY_AVERAGE), color = "violetred",
fill = "lightblue", alpha = 0.5, bins = 11) +
labs(x = "Patient Reported Pain Intensity", y = "Count")+
scale_x_continuous(breaks = 0:10)+
theme_minimal()
```

现在，让我们来看一个更复杂的示例。下图显示了每位患者报告的睡眠障碍与身体功能的对比，并按其报告的疼痛强度为每个点着色。由于某些点的值可能重叠，我们向 `geom_point()` 函数添加了 `position = "jitter"` 来对点进行抖动，这相当于在每个点的位置上添加一些随机噪声。如所示，该图表难以解读。例如，疼痛强度的颜色使得难以看出疼痛如何变化，且图例标题需要更简洁。

```r
ggplot(pain_df)+
geom_point(aes(x = PROMIS_PHYSICAL_FUNCTION,
 y = PROMIS_SLEEP_DISTURB_V1_0,
 color = PAIN_INTENSITY_AVERAGE), position="jitter")
```

![](img/58a554e865d49ca347d9a3f76f8f0812_141_0.png)

假设我们想要可视化身体功能低于平均水平的患者的疼痛强度和睡眠障碍。请注意，睡眠障碍和身体功能均以 T-Score 报告，这意味着原始分数已在总体中转换为均值为 50、标准差为 10 的标准化分数。我们可以使用 scale 函数来更新坐标轴和标签，以反映此信息。与之前一样，我们需要使用 `scale_x_continuous()` 函数来更新连续变量的 x 轴。在此示例中，我们更新限制（以限制为低于平均水平的身体功能）、断点和标签。我们同样更新 y 轴。

最后，假设我们想要更新颜色美学。与之前一样，此美学对应一个连续变量。速查表提供了几种可能的 scale 函数，具体取决于我们希望如何指定颜色渐变。我们选择 `scale_color_gradient()` 函数，因为它允许我们指定低端和高端颜色。我们还可以像为 x 轴和 y 轴指定断点一样，为图例值指定断点。`name` 参数还允许我们重命名此图例。调色板随后将其转换为连续颜色渐变。请注意，与我们为本示例选择的 `scale_color_gradient()` 函数相反，函数 `scale_color_gradient2()` 和 `scale_color_gradientn()` 允许您在渐变中指定更多颜色点，而不仅仅是两个极端颜色。

我们可以观察到，身体功能下降与更高的睡眠障碍相关，且身体功能较差和睡眠障碍较严重的患者往往报告更高的疼痛。请注意，这次我们收到一条警告消息，这是因为我们的坐标轴限制截断了一些点。为了避免此消息，我们可以使用函数 `coord_cartesian()` 来指定限制，它会裁剪值而不是移除限制之外的点。

```r
ggplot(pain_df)+
  geom_point(aes(x = PROMIS_PHYSICAL_FUNCTION,
                 y = PROMIS_SLEEP_DISTURB_V1_0,
                 color = PAIN_INTENSITY_AVERAGE),
             position = "jitter", alpha = 0.5) +
  scale_x_continuous(limits = c(15,50), breaks = c(20, 30, 40, 50),
                     labels = c("-3 SD", "-2 SD", "-1 SD",
                                "Pop Mean")) +
  scale_y_continuous(breaks = c(40, 50, 60, 70, 80),
                     labels = c("-1 SD", "Pop Mean", "+1 SD", "+2 SD",
                                "+3 SD")) +
  scale_color_gradient(breaks = seq(0,10,2), low = "green",
                       high = "red", "Reported Pain") +
  labs(x = "PROMIS Physical Function T-Score",
       y = "PROMIS Sleep Disturbance T-Score") +
  theme_minimal()
#> Warning: Removed 121 rows containing missing values or values outside the scale range
#> ('geom_point()').
```

以下是使用 scale 函数的另一个示例；请查看下一个图表示例。我们使用了两个 `geom_histogram()` 调用（图层）来绘制基线和随访时疼痛的直方图。这使我们能够可视化随访时的疼痛往往低于基线。

我们还在美学中指定填充为“基线”和“随访”，尽管这不是数据中的一列：这是一种手动为柱子着色的方式。我们使用 `scale_fill_manual()` 函数，然后使用 values 参数指定我们想要用于这两个类别的颜色。创建此图表时我们收到了三个警告！这是因为随访有许多 NA 值，并且我们没有为任一直方图指定箱大小。C’est la vie。

```r
ggplot(pain_df)+
geom_histogram(aes(x = PAIN_INTENSITY_AVERAGE, fill = "Baseline")) +
geom_histogram(aes(x = PAIN_INTENSITY_AVERAGE.FOLLOW_UP,
fill = "Follow-Up")) +
scale_x_continuous(breaks = c(0:10)) +
scale_fill_manual(values = c("violetred", "pink"),
name = "Measurement") +
labs(x = "Reported Pain Intensity", y = "Count") +
theme_minimal()
#> Warning: Removed 3604 rows containing non-finite values outside the scale range
#> ('stat_bin()').
```

## 8.3 添加分组

在之前的示例中，我们使用两次 `geom_histogram()` 函数调用创建了两个直方图。但是，当您希望根据变量分离 geom 图层时，还有另一种创建多个图层的方法。例如，假设我们想要可视化根据某人是否有随访信息而划分的身体功能分布。在以下代码中，我们在使用 `geom_density()` 的美学中创建变量 HAS_FOLLOW_UP，并将其同时用作颜色和分组。事实上，我们不必添加 group 参数，因为一旦我们向 `ggplot` 指定希望按此变量为密度图着色，它就会创建分组。最后，我们使用 `scale_color_discrete()` 函数更新此分组的图例，因为离散变量 HAS_FOLLOW_UP 决定颜色。
