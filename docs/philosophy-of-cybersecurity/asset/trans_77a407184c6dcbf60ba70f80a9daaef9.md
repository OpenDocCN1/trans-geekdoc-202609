

# 网络钓鱼也可以是定向的

假设目标是公司的一名员工。我们可以找出这样一位公司员工。我们可以确定他/她的工作内容、兴趣所在、与谁共事、谁是他的/她的上司、他的/她的家庭状况如何。这样，我们就可以挑选发送给此人的信息，以赢得此人的信任。而该人（目标）随后可能会更容易采取对自己不利的行动。当攻击瞄准公司董事或其他决策者时，情况尤为危险。在这种情况下，值得回顾一下[第2章](#ch2.xhtml)中提到的BEC变体。当公司决策者成为目标时，可能导致数百万的损失。

## 3.3 铁律

### 3.3.1 技术是为人服务的

首先要明确，我们不应害怕技术。它是为人服务的。并非它对一切和所有人都是威胁。如今使用的许多技术都已相当成熟。毕竟，Android或iOS内部存在生态系统。它们是连接到软件的各种设备（硬件）。这些可以是智能手机、笔记本电脑、手表或智能手表等设备。其制造商已投入时间确保产品安全。

因此，这里的问题是如何在这样的生态系统中保护自己。首先，有必要了解默认设置是否正确且适合我们。除非我们假设确实如此。如今，就拥有高安全级别的自律生态系统而言，这种假设通常是可以成立的；如果你使用某些大厂商的硬件或软件，安全级别很可能很高，且得到妥善监控。过去这并不那么显而易见和清晰，但此后系统在这一方面已显著改进。

然而，我们必须重申，在本章中，我们关注的是用户可控的事物。而主要是他们对自己行为的控制。显而易见，用户无法影响底层漏洞、其引入或解决，而这些漏洞可能导致操作系统被黑客攻破。他们不创建所使用的系统，通常也不修改它们。我们不会指望用户编辑（在“拆解”后）底层软件组件、重新构建软件等。同样，我们也不指望任何人从新购买的智能手机上物理移除麦克风或摄像头。然而，此类事情确实会发生。

### 3.3.2 厂商应负责基础安全——生态系统的重要性

公认的是，至少网络安全水平是体面生态系统运营商（Apple、Google等）的责任，且他们对此非常重视。如果仅仅因为网络安全是当今几乎所有人都关心的事情——从普通用户到监管机构。毕竟，新的法律法规不断出现，要求保护个人数据（如《通用数据保护条例》，GDPR）或各类系统的网络安全水平。

### 3.3.3 风险面

首先要明确，基础本身并非非常技术化，这确实是好事，因为技术变革的速度快于更通用的规则。关键在于弄清你自己使用计算机、互联网或技术的总体方式，以识别风险点。这种分析不仅可以在专业环境中进行，也可以为自己进行。我们谈论的是所谓的`risk surface`（风险面/攻击面）。简而言之，我们为潜在攻击提供的风险点越多，“风险面”，即可被攻击的“脆弱区域”就越大。什么可以等同于这样的表面、这样的风险点？例如，接入点——可能导致网络威胁产生的事物，即网络犯罪分子或其他人会利用的事物。这些可以是与我们使用的软件或系统类型相关的点。

例如，使用过时、未更新的软件浏览器版本浏览网页会增加风险。而更新非常简单。通常你也可以开启自动更新设置（如果它不是默认开启的），这样做是值得的，因为这是一种非常简单快捷的降低风险的方法。那么为什么不做呢？

另一个例子如下。如果我们在计算机或智能手机上安装了大量程序，对于想要破坏我们系统安全的人来说，只需在这些程序中的某一个中识别出一个入口点即可。因此，拥有许多程序/应用程序，且可能未更新，会增加危险。因此，减少此类风险的一种方法是减少这个可用的风险面。我们需要减少潜在漏洞，这可以通过减少利用我们所用事物中漏洞的机会来实现。在这种情况下，这可以非常容易地完成——例如，卸载我们不使用的程序，并确保所有其他程序都具有带有最新安全补丁的当前软件版本。这样一个示范性（模型）风险面定义在[图3.1](#ch3.xhtml#fig3_1)中。

在[图3.1](#ch3.xhtml#fig3_1)中，我们看到了一些大致轮廓——与我们使用的硬件和软件相关的表面。我们想要减少这样的风险面（这就是重点，使这样的风险可控）。例如，我们有区域A，在调整配置后将减少风险面，例如，启用多因素认证。区域B从风险图中消失，因为我们卸载了不必要的程序。区域C将在安装软件补丁后消失。当区域A、B、C从图景中移除时——风险面被减少、降低。为了说明威胁，我们保留了区域D，不幸的是，在我们使用的系统或软件中发现了漏洞，且有人想利用它对付我们。但我们能控制的，我们做对了。这就是关键所在。

#### 3.3.3.1 绘制使用方式图

用户使用计算机、智能手机、硬件和软件的总体方式也可以写在一张纸上或某个程序中，识别技术的使用方式。

然后我们检查：

*   浏览网页的过程，即网站，以及正在使用的方法，例如在特定情况下我们是使用这一款还是那一款网页浏览器，这一个还是那个浏览器扩展；
*   我们使用什么应用程序看电影，从哪里获取这些电影；
*   我们使用什么图形程序，从哪里获取图形素材；
*   我们是否移动性地使用计算机，在外出时使用，如果是，我们是否有锁屏功能，在一段时间不活动后锁定屏幕（这将是安全方法之一）；
*   我们是否经常在无法看管的情况下离开计算机，或者是否在公共场所这样做（例如，去咖啡厅洗手间时）；
*   我们是否连接外部存储设备（U盘）或其他外设，如麦克风，或USB连接的熔岩灯——这不是玩笑，因为谷歌研究人员曾一度将其演示为接管计算机控制权的一种方式；
*   我们是否安装来源不明的程序；我们甚至知道什么是不明来源吗（例如，来自应用商店之外的应用程序；例如，我们对智能手机进行了“越狱”，以非标准方式安装程序，这可能会显著降低安全级别）。

当我们了解如何使用硬件和软件以及用它们做什么时，将有助于以知情的方式选择适当的安全措施。
