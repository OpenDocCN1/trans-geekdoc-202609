# 9.1.2 POST

Sending a POST follows the same principles of GET requests. However, we are expected to send a body with the request and set the Content-type attribute in the header. Again, Go has a Post function that simplifies this operation as in Example 9.2. Notice that the POST body is expected to be an `io.Reader`. In this example, we send a JSON body to https://httpbin.org/post which simply returns the body we have sent. Notice that the second argument of `http.Post` indicates the content-type and the format or our body. Accessing the fields from the `Response` type can be done as explained in the previous example.
