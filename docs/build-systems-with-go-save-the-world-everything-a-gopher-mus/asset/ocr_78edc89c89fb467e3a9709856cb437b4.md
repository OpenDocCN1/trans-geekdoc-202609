```
var ages map[string]int
fmt.Println(ages)

// This fails, ages was not initialized
// ages["Jesus"] = 33

ages = make(map[string]int,5)
// Now it works because it was initialized
ages["Jesus"] = 33

ages = map[string]int{
    "Jesus": 33,
    "Mathusalem": 969,
}
fmt.Println(ages)
```

Items from a map can be retrieved using any key value like appears in Example 3.7 (birthdays["Jesus"]). Actually, this operation returns two items, with the expected value and true if the item was found. In the case, the value was not found, the value would be nil.

# Example 3.7: map access operations.

```
package main

import "fmt"

func main() {
    birthdays := map[string]string{
        "Jesus": "12-25-0000",
        "Budha": "563 BEC",
    }
    fmt.Println(birthdays, len(birthdays))

    xmas, found := birthdays["Jesus"]
    fmt.Println(xmas, found)

    delete(birthdays, "Jesus")
    fmt.Println(birthdays, len(birthdays))

    found = birthdays["Jesus"]
    fmt.Println("Did we find when it Xmas?", found)

    birthdays["Jesus"] = "12-25-0000"
    fmt.Println(birthdays)
}
```

New items can be added like in birthdays["Jesus"]="12-25-0000". Additionally, items can be removed using the built-in function delete.
