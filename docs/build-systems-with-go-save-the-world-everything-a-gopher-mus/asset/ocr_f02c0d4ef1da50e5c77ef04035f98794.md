package example_01

import "testing"

func TestOptions(t *testing.T) {
    Periods(333)
}

Go tools to get deeper insights into coverage tests. The output from the test can be exported to an intermediate file using the -coverprofile=filepath. The information dumped to the chosen file can be used to print additional information using go tool. For example, go tool cover -func=filepath -html=filepath prints the coverage of every function. A more visual approach can be done with go tool cover -html. This option opens up a browser and shows the coverage for code regions shown in Figure 11.1 which is clear that only one branch was tested.

```
package example_01
func Periods(year int) {
    switch {
    case year < -3000:
        return "Copper Age"
    case year < -1200:
        return "Bronze Age"
    case year < -1000:
        return "Iron Age"
    case year < 0:
        return "Classic Age"
    case year < 500:
        return "Roman Age"
    case year < 1500:
        return "Middle Age"
    case year < 2000:
        return "Modern Age"
    default:
        return "unknown"
    }
}
```
