# 4.1 STRUCTS

If you are familiar with languages like C/C++ you will find structs relatively known construct. In a few words, a struct is a sequence of named fields. Each field has a name and a type.

In Example 4.1 we have a named Rectangle which represents the geometric form with Height and width fields. A struct can be instantiated in different ways. Not passing any argument (line 11) initializes every field in the struct with the zero value. Initial values can be set as them in the order they were defined (line 14). Additionally, we can set what value corresponds to what field using the field name (line 17). In this way, we do not need to set all the fields (line 20). Missing fields are set to their default value.
