# 18.2.3 Relationships

GORM maps relationships between SQL entities using struct fields and some additional field tags. The schema migration generates the corresponding foreign keys and tables required to support these relationships. We explore four potential relationships.

# **Belongs-to**

This relationship sets an entity to belong to another entity. This is a one-to-one relationship. For example, a user belongs to a group. In GORM we can represent this relationship indicating the foreign key and the entity. In the Entity below a User belongs to one Group. This is indicated with the GroupID field which points to the corresponding entity group in the database, and the field Group.

# Example 18.8: Belongs to relationship.

```
1 type User struct {
2 ID uint
3 Name string
4 Email string
5 GroupID uint
6 Group Group
7 }
8
9 type Group struct {
10 ID uint
11 Name string
12 }
```

GORM analyzes field names to find relationships and set foreign key names and target entities. The default behaviour has to be changed, this can be done using field tags.

# Example 18.9: Belongs to relationship with custom foreign key.

```
1 type User struct {
2 ID uint
3 Name string
4 Email string
5 Ref uint
6 Group Group `gorm:foreignKey:Ref'`
7 }
8
9 type Group struct {
10 ID uint
11 Name string
12 }
```
