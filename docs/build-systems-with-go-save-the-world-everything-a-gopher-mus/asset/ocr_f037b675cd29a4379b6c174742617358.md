# Notes to this version

The reception of version v0.1.0 exceeded all my expectations. The book was #1 for one month in the category of new releases. This is an amazing achievement for a single-person-published book. Thank you all for your exceptional support, comments, and suggestions. Version v0.2.0 is the first revision after the initial release. Many explanations have been revisited for a trade-off between conciseness and utility. Extra figures have been added, and a new chapter about Cgo has been included.
