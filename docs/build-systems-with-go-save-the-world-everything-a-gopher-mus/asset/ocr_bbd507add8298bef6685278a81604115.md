We have already defined our messages and services. Now we have to create the corresponding stubs to use the services and specifications in our Go code. For this, we need the protoc command-line tool with the gRPC plugin. Be sure, you have already installed the protoc tool (see 14.1). The gRPC plugin works with the protoc tool to generate the corresponding clients and users using the specifications from the .proto file. You can get the gRPC plugin running 30.

```
>>> export GOMOD1MODULE=on # Enable module mode
>>> go get google.golang.org/protobuf/cmd/prot-gen-go \
	google.golang.org/grpc/cmd/prot-gen-go-grpc
```

Make sure that protoc can find the plugins:

```
>>> export PATH=$PATH:$(go env GOPATH)/bin
```

If the environment is correct, now we can execute protoc and generate the gRPC stubs.

```
>>> protoc -I. --go_out=$GOPATH/src --go_grpc_out=$GOPATH/src .proto
```

The -go-grpc_out argument indicates the path for the go stubs. Remember that the generated code must be accessible to the go package and match the value set in the go_package. After a successful execution we have two files: user.pb.go and user_grpc.pb.go. The first one contains the definition of the messages as described in Chapter 14. The second one contains all the code generated to support clients and servers that derive from our gRPC definitions in the .proto file.
