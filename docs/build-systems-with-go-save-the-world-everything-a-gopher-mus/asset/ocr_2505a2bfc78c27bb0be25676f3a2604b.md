# 5.2.1 Setting values

Using reflect.value we can set values on run-time. Every value has methods SetInt32, SetFloat32, SetString, etc. that set the field to a int32, float32, string, etc. value. Example 5.8 sets the string fields from struct to uppercase.

# Example 5.8: Setting values using reflection.

```
package main

import (
	"fmt"
	"reflect"
	"strings"
)

type T struct {
	A string
	B int32
	C string
}

func main() {
	t := T("Hello", "42")
	fmt.Println(t)

	valueT := reflect.ValueOf(&t).Elem()
	for i:=0;i<valueT.NumField();i++ {
		f := valueT.Field(i)
		if f.Kind() == reflect.String {
			current := f.String()
			f.SetString(strings.ToUpper(current))
	}
}
	fmt.Println(valueT)
}
```
