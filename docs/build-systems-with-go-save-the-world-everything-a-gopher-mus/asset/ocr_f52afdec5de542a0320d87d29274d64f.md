# # 11. COVERAGE

Test coverage involves measuring what percentage of the code has been tested. Any Go test can be executed with the -cover flag to activate coverage metrics.

To run coverage tests we have to write tests and the code to be tested in different files. We measure the coverage of Example 11.9 with Example 11.10. We can expect poor coverage because we only explore one of the branches in the switch statement. We only get 22.2% of coverage.
