# 3.2.2 Iteration

The most common operation you can find in a slice is the iteration through its items. Any for loop is a good candidate to this. Go simplifies iterations through collections with the range clause.

Example 3.5: slice iteration using the range clause.

```
package main
import "fmt"
func main() {
	names := []string{
	"Jeremy", "John", "Joseph"
	}
	for i := 0; i < len(names); i++ {
	fmt.Println(names[i])
	}
	for position, name := range names {
	fmt.Println(position,name)
	}
}
```
