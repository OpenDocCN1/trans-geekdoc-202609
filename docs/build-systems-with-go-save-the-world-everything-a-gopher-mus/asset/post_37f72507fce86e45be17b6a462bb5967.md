# 9.2 HTTP SERVER

The net/http package provides a ServerMux type that implements an HTTP multiplexer. The server matches URL requests with a list of configured patterns. These patterns have an associated handler that is invoked to serve the request.

Example 9.5 registers the function info as the handler for the /info URL. Any function to be registered as a handler must follow the `func(http.ResponseWriter, *http.Request)` signature. To serve requests, the http.ListenAndServe function blocks the execution flow and waits for incoming requests.

The `http.HandleFunc` registers handlers to a URI. We can directly set a handler to be invoked independently of the URI. This forces the handler to be invoked in every request. However, this can be useful depending on the use-case.

Example 9.6 implements a Handler type with struct `MyHandler`. To implement the Handler interface `ServeHTTP` has to be defined. Any request will be sent to this handler, therefore we can do things like URI selection. In the example /hello and /goodbye return different messages.

# Example 9.6: HTTP server and handler.

```go
package main

import "net/http"

type MyHandler struct{}

func (c *MyHandler) ServeHTTP(w http.ResponseWriter, r *http.Request) {
    switch r.RequestURI {
    case "/hello":
        w.WriteHeader(http.StatusOK)
        w.Write([]byte("goodbye\n"))
    }
}

func main() {
    handler := MyHandler()
    http.ListenAndServe(":8080", &handler)
}
```

```bash

>>> curl http://localhost:8080/hello
```

# 9.3 COOKIES

The Cookie type is a representation of the cookies you can find in a Set-Cookie header. They can be added to a Request and extracted from a Response type.

Example 9.7 instantiates a server that accepts a cookie with a counter. The value received in the cookie is sent when the client sends requests to the server. After instantiating the cookie, we add it to the current request with `req.AddCookie(c)`. Cookies are accessible in key-value pairs at both requests and responses. On the server-side, the function `r.Cookie("counter")` gets cookie from the request if it was found. Similarly, we can set the cookie in the response using the http.SetCookie function. In the output, we capture the headers from the response and the response. The response contains the Set-Cookie header with the new value for the counter.

Example 9.7: Adding cookies to requests and responses.

```go
package main

import (
    "fmt"
    "net/http"
    "strconv"
    "time"
)

func cookieSetter(w http.ResponseWriter, r *http.Request) {
	counter, err := r.Cookie("counter")
	if err != nil {
		w.WriteHeader(http.StatusNotFound)
		return
	}

	value, err := strconv.Atoi(counter.Value)
	if err != nil {
		w.WriteHeader(http.StatusBadRequest)
		return
	}

	value = value + 1
	newCookie := &http.Cookie{
		Name:  "counter",
		Value: strconv.Itoa(value),
		Path:  "/",
		Expires: time.Now().Add(1 * time.Hour),
	}
	http.SetCookie(w, newCookie)
	fmt.Printf("Counter value: %d\n", value)
}

func main() {
	http.HandleFunc("/cookie", cookieSetter)
	http.ListenAndServe(":8080", nil)
}
```
