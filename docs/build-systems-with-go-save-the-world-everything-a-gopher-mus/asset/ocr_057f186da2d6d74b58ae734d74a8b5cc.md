Using low-level functions have better control of read and write operations. For example, we can read and write portion of files using the Seek method from the File type. This method indicates the offset to be used when writing or reading a file. In Example 7.5 Seek is used to modify given certain positions in the content of a file and then reads the modified content. After using Seek, we have to set the pointer to the first position of the file with file.Seek(0,0), otherwise the read count would start at the last position.

package main

import (

	"os"
