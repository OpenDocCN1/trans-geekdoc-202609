# 5.4 TAGS

Go provides powerful and versatile structs enrichment using these tags. These tags can be interpreted on run-time reflection which adds valuable information that can be employed for different purposes.

```
type User struct {
UserId string `tagA:valueA1` tagB:valueA2`
Email string `tagB:value`
Password string `tagC: v1 v2`
Others string `something a b`
}
```

The struct declares four fields with different tags. Every tag becomes an attribute of the field that can be accessed. Go permits tags to declare string literals like "something a b". However, by convention follow a key-value schema separated by spaces. For example, the string tag `tagA:valueA1tagB:valueA2`, declares two tags tagA and tagB with values valueA1 and valueA2 respectively.

Example 5.11 uses reflect.TypeOf to access all the fields of the struct. The type returned by Type has functions to check the name, number of fields, size, etc. Field information is stored in a type StructField that can be accessed using Field() and FieldByName() functions. For every StructField tags are stored in a StructTag (fieldUserIdTag). A StructTag contains all the available tags of a field.
