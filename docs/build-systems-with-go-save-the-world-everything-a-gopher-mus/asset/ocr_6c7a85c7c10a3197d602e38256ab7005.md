If the operation is not valid, the operation will panic. For example, setting fields to a different type or trying to set unset fields. In Example 5.9, the field c is unexported. Additional checking must be done using the canSet() method. Using this method we can skip unexported fields. Observe that the output has not modified c value.

# Example 5.9: Setting values using reflection considering unexported fields.

```
package main

import (
	"fmt"
	"reflect"
	"strings"
)

type T struct {
	A string
	B int32
	C string
}

func main() {
	t := T{"Hello", 42}

	valueOff := reflect.ValueOf(&t).Elem()
	for i := 0; i < valueOff.NumField(); i++ {
		f := valueOff.Field(i)
		if f.Kind() == reflect.String {
			if f.CanSet() {
				current := f.String()
				f.SetString(strings.ToUpper(current))
		}
		}
	}
		fmt.Println(t)
}
```
