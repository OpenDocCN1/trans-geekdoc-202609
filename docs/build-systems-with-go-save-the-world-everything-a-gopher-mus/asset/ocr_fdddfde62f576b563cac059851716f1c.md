```
func main() {
    var aBool bool = true
    var aString string = "xxxx"
    var aComplex complex64 = 51
    var aRune rune = '€'

    fmt.Println(aBool)
    fmt.Println(aString)
    fmt.Println(aComplex)
    fmt.Println(aRune)
    fmt.Printf("%#U\n", aRune)
    fmt.Printf("%#u\n", aRune)
}
```

2.3 shows how variables from different types are declared, assigned and printed. Running the code the rune type requires special attention. By simply printing the variable we get the value 8364. However, the UTF-8 representation is U+20AC (format using \u). A printable representation of the Euro symbol (€) is obtained with the \U format.

# 2.2.3 Constants

A constant is a value defined at compilation time that cannot be changed. Apart from the impossibility of setting new values, constants are similar to variables.

# Example 2.4: Constants declaration

```
package main

import (
    "fmt"
    "reflect"
)

const (
    PI = 3.14
    Avogadro float32 = 6.022e+23
)

func main() {
    fmt.Println("What is the value of PI? PI is", PI)
    fmt.Println(reflect.TypeOf(PI))
    fmt.Println("Avogadro's Number value is", Avogadro)
    fmt.Println(reflect.TypeOf(Avogadro))
}
```
