By default, benchmark iterations are executed sequentially. In certain scenarios, particularly in those with shared resources, executing these iterations in parallel may be more valuable. RunParallel allows the number of goroutines to be set with the -cpu flag in go test. The available testing goroutines. The Next() function indicates if more iterations have been executed.

```
func BenchmarkSumParallel(b *testing.B) {
	b.RunParallel(func(pb *testing.PB) {
		for pb.Next() {
			// do something
		}
	})
}
```
