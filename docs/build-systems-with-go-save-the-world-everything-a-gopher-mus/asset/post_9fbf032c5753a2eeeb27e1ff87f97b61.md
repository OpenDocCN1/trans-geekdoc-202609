## 17.4.1 Custom help and usage

Cobra automatically generates help and usage messages. However, it is possible to define our own solutions with SetHelpCommand, SetHelpFunc, and SetUsageFunc. Example 17.10 defines custom help.

```go
package main

import (
	"errors"
	"fmt"
	"github.com/spf13/cobra"
	"os"
)

var RootCmd = &cobra.Command{
	Use: "main",
	Short: "short message",
}

var ActionCmd = &cobra.Command{
	Use:  "action",
	Args: cobra.MinimumArgs(2),
	Run: func(cmd *cobra.Command, args []string) {
		fmt.Println("Do something with %v", args)
	},
}

func helper(cmd *cobra.Command, args []string) {
	fmt.Printf("You entered command %s\n", cmd.Name())
	fmt.Println("And that is all the help we have :")
}

func usage(cmd *cobra.Command) error {
	fmt.Printf("You entered command %s\n", cmd.Name())
	fmt.Println("And you do not know how it works :")
	return errors.New("Something went wrong : ")
}

func main() {
	RootCmd.AddCommand(ActionCmd)
	RootCmd.SetHelpFunc(helper)
	RootCmd.SetUsageFunc(usage)

	ActionCmd.Flags().Bool("now", false, "Do it now")

	if err := RootCmd.Execute(); err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
}
```

Observe that the help is overwritten by the helper function returning a different message the name of the requested command. If we misspell the flag now, Cobra launches the usage function below.

And that is all the help we have :)
>>> ./main action -now

You entered command action
And you do not know how it works :

exit status 1
