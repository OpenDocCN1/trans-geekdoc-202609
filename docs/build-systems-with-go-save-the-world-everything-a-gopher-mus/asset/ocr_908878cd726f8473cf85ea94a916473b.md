# 6.6.3 WithDeadline

Similar to a timeout, kind of context has an absolute termination time set. When the deadline is reached, the context is finished. 6.17 uses various goroutines to modify a shared variable. The context is set to expire after three seconds. Notice that this is similar to use a context with a timeout. We block the execution until the context is done (ctx.Done()). From the output, we can observe how the goroutines are informed about the context termination. Not all the messages are printed because the program terminates before the goroutines have time to print the message.

# Example 6.17: Context WithDeadline.

```
package main

import (
    "context"
    "fmt"
    "sync/atomic"
    "time"
)

func accum(c uint32, ctx context.Context) {
    t := time.NewTicker(time.Millisecond*250)
    for {
        select {
            case <- <-t.C:
                atomic.AddUint32(&c, 1)
            case <- ctx.Done():
                fmt.Println("Done context")
                return
        }
    }
}

func main() {
    d := time.Now().Add(time.Second*3)
    ctx, cancel := context.WithDeadline(context.Background(), d)
    defer cancel()

    var counter uint32 = 0

    for i:=0;i<5;i++ {
        go accum(&counter, ctx)
    }
```
