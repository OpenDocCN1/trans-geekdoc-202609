other words, a slice is a reference to an array. The slice itself does not store any data but offers a view of it. Table 3.1 describes available ways to select slices.

| Index | Selected element(s) |
|---|---|
| a[] | Element at position 0
| a[3:5] | Elements from position 3 to 4
| a[3:] | All the elements starting at position 3
| a[:2] | All the elements from the start till position 2
| a[:] | All the elements |
