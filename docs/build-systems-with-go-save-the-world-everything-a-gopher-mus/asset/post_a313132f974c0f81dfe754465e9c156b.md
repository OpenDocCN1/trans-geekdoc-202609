## 3.1 ARRAYS

By definition, an array is an indexed sequence of elements with a given length. Like any other Go variable, arrays are typed and their size is fixed.

## 3.2 SLICES

We have said that arrays have a fixed size. This makes them not very flexible in certain scenarios. Go offers a type called slice defined as a "descriptor" for a contiguous segment of an underlying array and provides access to a numbered sequence elements from that array*.

In other words, a slice is a reference to an array. The slice itself does not store any data but offers a view of it. Table 3.1 describes available ways to select slices.

| a[3:5] | Elements from position 3 to 4 |
| a[3:] | All the elements starting at position 3 |
| a[:2] | All the elements from the start till position 2 |
| a[:] | All the elements |

## 3.2.2 Iteration

The most common operation you can find in a slice is the iteration through its items. Any for loop is a good candidate to this. Go simplifies iterations through collections with the range clause.

## Example 3.5: slice iteration using the range clause.

```go
package main
import "fmt"
func main() {
	names := []string{
	"Jeremy", "John", "Joseph"
	}
	for i := 0; i < len(names); i++ {
	fmt.Println(names[i])
	}
	for position, name := range names {
	fmt.Println(position,name)
	}
}
```

Example 3.5 prints all the items of a collection of strings using two approaches. The first one (line 10), declares an index variable i to increment the index of the item to be retrieved.
