# 16.3 Multi-logger

It is common to separate logs depending on the log level, the message final output (file, standard output). The MultilevelWriter aggregates several loggers making it possible for a single log message to be written to different destinations with different formats. Example 16.11 defines a multi-logger that simultaneously sends every message to a file, the standard output, and ConsoleWriter. The output shows the content from the two loggers dumping messages to the logs. Additional customizations such as setting log level to have specialized loggers can be done. This is a common approach to separate errors into specific logs.
