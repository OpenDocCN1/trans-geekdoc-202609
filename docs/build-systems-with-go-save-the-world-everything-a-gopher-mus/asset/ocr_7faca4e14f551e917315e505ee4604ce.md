The basic construction of a variable is formed by the reserved word var followed by the variable name and its type. For example, var a declares variable a of type int. Notice that this declares a variable with no value. The type and the value can be set in one line as shown in the example with var a := 10. Similarly using := we can declare and assign a value to the variable; the type will be inferred by the compiler. In our example, b := -42 has type int while c := "this is string" is a string. Finally, we can declare and assign values to several variables in one line like in r, g := true, false.

# 2.2.2 Basic types

Go comes with the set of basic types described in Table 2.1.

| Type | Description |
|---|---|
| | Boolean |
| string | String of characters |
| int, int8, int16, int32, int64 | Signed integers |
| uint, uint8, uint16, uint32, uint64, uintptr | Unsigned integers |
| byte | Byte, similar to uint |
| rune | Unicode code point |
| float32, float64 | Floating numbers |
| complex64, complex128 | Complex numbers |

Table 2.1: Basic types

Integer int and uint are platform-dependant and may vary from 32 to 64 bits. Using types such as uint or int set the variable size. For floating and complex numbers it is required to set the type size.

If you are familiar with other languages you may find the rune something weird. This type is a simple character represented by UTF-8 which requires 32 bits instead of the classic 8 bits used in ASCII. Actually, rune is simply an alias for int32.
