The server implementation in Example 15.6 generates n random numbers for the given range. Notice that the signature function implement differs from using rpc methods. The server implements the remote procedure Rnd which receives a request and a type that encapsulates a stream type. This stream type is the communication channel the client opened when invoking this procedure. Our server uses the stream.Send to send new responses to the client. When we are finished, returning nil is enough to close the channel and send an EOF (End Of File) informing the client that the communication is finished.
