# 17.4.1 Custom help and usage

Cobra automatically generates help and usage messages for a CLI. However it is possible to define our own solutions with SetHelpCommand, SetHelpFunc, and SetHelpTemplate methods from the command type. For the usage message, there are similar methods. Example 17.10 defines the action command with the flag now. We replace the default help and usage with functions helper and usage. By setting these functions in the root command we change the whole CLI behaviour. However, this could be changed only for specific commands.
