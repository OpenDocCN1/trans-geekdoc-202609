testing requirements may change depending on factors such as timing. Sometimes depending on the stage time rest restrictions may appear. Tests can be skipped using t.Skip(). This can be used with the testing.Short() function that returns true when the -short param is set in the go test command to avoid exhaustive testing. Example 11.3 shows how to skip a test when the duration of an iteration goes before a given time. If the -short flat is set, test skipping will be automatically done.

# Example 11.3: Test skipping.

```
package example_03

import (
    "fmt"
    "math"
    "testing"
    "time"
)

func Sum(n int64, done chan bool) {
    var result int64 = 0
    var i int64
    for i = 0; i<n; i++ {
        result = result + i
    }
    done <- true
}

func TestSum(t *testing.T) {
    var i int64
    done := make(chan bool)
    for i = 0; i<math.Max64; i+=100000 {
        go Sum(i, done)
        timeout := time.NewTimer(time.Millisecond)
        select {
        case <-timeout.C:
            t.Skip(fmt.Sprintf("%d took longer than 1 millisecond",i))
        case <-done:
        }
    }
}
```
