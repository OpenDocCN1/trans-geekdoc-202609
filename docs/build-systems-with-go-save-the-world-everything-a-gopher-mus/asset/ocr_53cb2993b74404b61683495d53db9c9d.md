in the middle of a loop. The first deferred function is executed from something, then main(). Observe that the panic message is printed in the last step and the last statement from main is never reached.

# Example 2.19: panic.

```
package main

import "fmt"

func something() {
	defer fmt.Println("closed something")
	for i:=0;i<5;i++ {
		fmt.Println(i)
		if i > 2 {
			panic("Panic was called")
		}
	}

func main() {
	defer fmt.Println("closed main")
	something()
	fmt.Println("Something was finished")
}
```

It may occur under certain conditions when panic is invoked, the control flow can be restored. The recover built-in function used inside a deferred function can be used to resume normal execution. The scenario presented in Example 2.20 recovers execution after the panic inside function something. Calling panic(i) executes the deferred function where the recover is deferred from nil. The returned value is the parameter of the panic function. Observe that in this case main function finished and we could print the final message.

# Example 2.20: recover.

```
package main

import "fmt"

func something() {
	defer func() {
		r := recover()
		if r != nil {
			fmt.Println("No need to panic if i=%v",r)
		}
	}
	for i:=0;i<5;i++ {
		fmt.Println(i)
		if i > 2 {
		panic(i)
	}
}
```
