# 3.3 MAPS

A map is a construct that maps a key to a value. Keys are intended to be unique and can be of any type that implements == and != operators.

Example 3.6 shows how to instantiate a map that stores string keys and integer values. Maps are defined by map[k]v where k is the key and v is the value type. By default, uninitialized maps are nil.

Notice that the statement map["Jesus"] = 33 (line 10) is intended to set the value 33 for the key "Jesus" to fail. This is because any map needs to be instantiated. This can be done using the make built-in function (line 12). For map the make function returns the map type (map[k]v) and optionally an initial size. This size is optional as the size can be modified during runtime. Maps can also be initialized by indicating key-value pairs as shown in line 16.

Example 3.6: map Creation.

```go

    map := make(map[string]bool)
    map["Jesus"] = false
    map["Jesus"] = 33

var ages map[string]int
fmt.Println(ages)

// This fails, ages was not initialized
// ages["Jesus"] = 33

ages = make(map[string]int,5)
// Now it works because it was initialized

    "Jesus": 33,
```

Items from a map can be retrieved using any key value like in Example 3.7 (birthdays["Jesus"]). Actually, this operation returns two items, with the expected value and true if the item was found. In the case, the value would be nil.

Example 3.7: map operations.

```go
package main

import "fmt"

func main() {
    birthdays := map[string]string{
        "Jesus": "January",
        "Bud": "February",
    }
    fmt.Println(birthdays, len(birthdays))

    name, found := birthdays["Jesus"]
    fmt.Println(name, found)

    fmt.Println(birthdays, len(birthdays))

}
```

New items can be added like birthdays["Jesus"]="March". Additionally, items can be removed using the built-in function delete.

# 3.3.1 Iteration

To iterate a map would require the collection of keys. Fortunately, the range built-in function offers a simple solution to iterate through all key-value pair of any map. The rules explained for slices apply in the case of maps. For every iteration range returns the current key and value.

Example 3.8: map iteration using range.

```go
package main

	sales := map[string]int{
		"Jan": 45,
		"Feb": 23,
```

# 4.1 STRUCTS

If you are familiar with languages like C/C you will find structs relatively known. In a few words, a struct is a sequence of named fields. Each field has a name and a type.

In Example 4.1 we have a named Rectangle which represents the geometric form with Height and width fields. A struct can be instantiated in different ways. Not passing any argument (line 11) initializes every field in the struct with the zero value. Initial values can be set in the order they were defined (line 14). Additionally, we can set what value corresponds to what field using the field name (line 17). In this way, we do not need to set all the fields (line 20). Missing fields are set to their default value.

Example 4.1: Structure definition for a rectangle.

```go
package main

import "fmt"

type Rectangle struct{
    Height int
    Width int
}

func main() {
    a := Rectangle()
    fmt.Println(a)

    b := Rectangle(4, 4)
    fmt.Println(b)

    c := Rectangle(Width: 18, Height: 3)
    fmt.Println(c)

    d := Rectangle(Width: 7)
    fmt.Println(d)
}
```

This flexibility creating structs can be inconvenient. In Example 4.2, there is a rectangle with no width field value. In this case, it does not make any sense to a rectangle with a width of zero. One possible solution to define a NewRectangle function that requires all the necessary arguments to create this struct. Notice, that this function returns a pointer to the struct instead of a value.

# Example 4.2: Struct constructor.

```go
package main

import "fmt"

type Rectangle struct {
	Height int
	Width int
}

func NewRectangle(height, width int) *Rectangle {
	return &Rectangle{height, width}
}

func main() {
	a := Rectangle{Height: 7}
	fmt.Println(a)

	r := NewRectangle(2, 3)
	fmt.Println(r)
	fmt.Println(*r)
}
```

> In Go does not exist the concept of a constructor like in other languages. A struct is a very flexible construct that can be defined in many ways. When working with structs it is very important to take into consideration fields zero values and how these values may impact the code. In many cases, it is a good practice to define constructors, especially when certain values are not valid.

# 4.1.1 Anonymous structs

Go permits the definition of anonymous structs like the one shown in Example 4.3. Compared with a regular struct like Circle printing the struct brings a similar result. However, we cannot print its name as we do with circle. The fields from the anonymous function can be modified like done with regular structs.

# Example 4.3: Anonymous struct.

```go
package main

import (
	"fmt"
	"reflect"
)

type Circle struct {
	x int
	y int
	radius int
}

func main() {
	ac := struct{x int; y int; radius int}{1, 2, 3}
	c := Circle{10, 10, 3}
	fmt.Printf("%v+%v\n", ac)
	fmt.Println(reflect.TypeOf(ac))
	fmt.Printf("%v+%v\n", c)
	fmt.Println(reflect.TypeOf(c))

	ac.x=3
	c = c
	fmt.Printf("%v+%v\n", ac)
	fmt.Println(reflect.TypeOf(c))
}
```
