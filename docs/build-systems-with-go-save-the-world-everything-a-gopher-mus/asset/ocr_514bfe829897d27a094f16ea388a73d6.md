CQL can execute insert, update, and delete queries in batches. Batches ensure atomicity and can improve performance. 19.11 uses a batch to insert a new user and modify her email. A Batch type is obtained from the current session with a given context using the NewBatch method. This batch has a collection of BatchEntry representing queries. The collection of queries is executed as a whole using the ExecuteBatch from the current session.
