Another use case is iteration through a collection of items. We can call a range iterator as we would do in a Go loop. The statement {{range .}}{{print .{end}} iterates through a collection and prints every item. The statement 10.4 uses this action to print the content of a string array containing the name of the musketeers.

# Example 10.4: Template range iteration.

