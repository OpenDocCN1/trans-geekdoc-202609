# 5.2 REFLECT.VALUE

We have seen how reflect.Type permits code introspection. However, the reflect.Type type cannot access fields. This functionality is reserved to the reflect.Value type. Actually, from a reflect.Value type we can access its reflect.Type type. Example 5.5 uses the same variables in Example 5.1. Notice that in this case we can print the current value.
