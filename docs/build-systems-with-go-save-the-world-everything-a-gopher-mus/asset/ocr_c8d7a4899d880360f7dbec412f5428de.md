# 14.2 COMPLEX MESSAGES

PB facilitates the definition of complex message structures with sophisticated types. We extend our user message example to demonstrate how to use other types such as enumerations and repeated fields.

Example 14.3 defines a message that represents a group of users. Every group has an id, a category, a certain score, and a list of users that belong to the group. Notice that the user category is an enumerated value. Enumerated values are defined with the reserved word enum. For every item of the enumeration, we use the name and the associated value. Do not confuse this value with the field tag. The category field in Group is defined as type Category. For the list of users, we indicate that a field can appear several times with the reserved word repeated. This list of users has no size limit and can be empty.
