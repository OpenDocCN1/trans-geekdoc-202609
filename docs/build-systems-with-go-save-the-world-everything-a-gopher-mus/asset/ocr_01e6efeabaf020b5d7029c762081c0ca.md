# 16.3.1 Write logs to a file

Logs in the standard output are not always the best solution, especially in unsupervised scenarios. Writing logs to a file not permits to a non-volatile version, it additionally facilitates concurrency and can be used for feeding analytical systems. A file logger can be created using the New function which receives an io.Writer. Example 16.9 creates a logger which dumps all the messages to a temporary file.

Example 16.9: Stack trace logging.

```
package main

import (
	"io/ioutil"
	"os"
	"fmt"
	"github.com/rs/zerolog/log"
	"github.com/rs/zerolog"
)

func main() {
	tempFile, err := ioutil.TempFile(os.TempDir(),"deleteme")
	if err != nil {
		// Can we log an error before we have our logger? :)
		log.Error().Err(err).
		Msg("there was an error creating a temporary file for our log")
}
```
