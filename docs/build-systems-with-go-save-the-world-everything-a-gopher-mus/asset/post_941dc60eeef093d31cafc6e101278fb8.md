One of the foundations of software development is code reuse. If a piece of software does the job, the wisest decision is to reuse it. Unfortunately, this is not always possible. It is common to find that the software we are looking for is written in a different programming language, or simply there is no way we can use it without over-engineering. With Cgo, we can interact with code written in C. This enables Go to access a large number of existing solutions. In this Chapter, we explore how to use Cgo to interact with C programs and libraries.

## 13.1 USE CGO FROM GO

Using Cgo, we can call code from Go. More precisely, we can use functions and structs defined in C. This can be done with the pseudopackage that combines programming sources into the same Go package. For example, let's assume that we have to execute the following `func_in_c` function written in C.

```c
#include <stdio.h>
void func_in_c() {
    printf("printed with C\n");
}
```

We integrate this C code into our Go code like shown in Example 13.1. Observe that the code is added in a commented region before the import "c" statement. This informs the Go compiler that there is C to be linked. Alternatively, the `/* ... */` comment delimiters can be used like shown in Example 13.2. This permits including comments inside the C preamble.

### Example 13.1: C function called from Go.

```go
package main
// #include <stdio.h>
// void func_in_c() {
    printf("printed with C\n");
}

import "C"
// import "fmt"

func main() {
    C.func_in_c()
    fmt.Println("printed with Go code")
}
```

### Example 13.2: C function called from Go with comments.

```go
package main

/*
#include <stdio.h>
// This is a comment
void func_in_c() {
    printf("printed with C code\n");
}
*/

import "C"
import "fmt"

func main() {
    C.func_in_c()
    fmt.Println("printed with Go code")
}
```

The pseudopackage `c` makes accessible all the functions, structs, and variables from linked C code. To invoke our function, we only have to invoke it like `c.func_in_c()`.

> You may find interesting that there are other Go compilers apart from the one maintained by Google. For example, gccgcop [5] is maintained by GNU under a General Public License and GopherJS [7] compiles Go into pure Javascript.

## 13.2 EXCHANGING VARIABLES

When exchanging variables between Go and C, we must be aware that data types may not be defined in the same way. For example, the Go `int` type can be 32 or 64 bits depending on the architecture. However, C typed variables are 16 or 32 bits long. Obviously, types must match between both languages to work correctly. Fortunately, the `c` pseudopackage offers functions to deal with these situations.

Example 13.3 defines a C function that sums two integers passed by argument. If the function is called using native Go integers as parameters, the compilation will fail with a message like `cannot use a (type int) as type _ctype_int in argument to _Cfunc_sum`. Using C `int` we can convert from Go native `int` to C to follow the signature of the target function.

### Example 13.3: C function with arguments called from Go.

```go
package main

int sum(int a, int b) {
    return a + b
}

import "C"
import "fmt"
```

![](img/c7dcb4df7215ed1d3fb76d25373be6c7_166_0.png)

```go
func main() {
    a := 1
    b := 1
    c := C.sum(C.int(a), C.int(b))
    fmt.Printf("%d %d = %d\n", a, b, c)
}
```

Some data types offered by C have similar types in Go, and the other around. For example, Go has no `short` type but the `int16` type can be considered to be similar. Other types like `char` are not available in Go, the `byte` type has same size and range.

Example 13.4 shows some examples of type conversions and how they are used in C. Notice that the printed output depends on string formatter character from the `printf`.

### Example 13.4: Casting types between Go and C.

```c
#include <stdio.h>
void f_char(char in) {
    printf("%c\n", in);
}
void f_short(signed char in) {
    printf("%d\n", in);
}
void f_uchar(unsigned char in) {
    printf("%u\n", in);
}
void f_short_long(short in) {
    printf("%d\n", in);
}
void f_ushort(unsigned short in) {
    printf("%u\n", in);
}
void f_int(int in) {
    printf("%d\n", in);
}
void f_uint(unsigned int in) {
    printf("%u\n", in);
}
void f_long(long in) {
    printf("%ld\n", in);
}
void f_ulong(unsigned long in) {
    printf("%lu\n", in);
}
void f_longlong(long long in) {
    printf("%lld\n", in);
}
void f_ulongong(unsigned long long in) {
    printf("unsigned long long %X\n", in);
}
void f_float(float in) {
    printf("float %e\n", in);
}
void f_double(double in) {
    printf("float %e\n", in);
}
```

| Type | Example Value/Output |
| :--- | :--- |
| signed char | FFFFFFD6 |
| unsigned char | * |
| short | -42 |
| unsigned short | 42 |
| int | * |
| unsigned int | 2147483647 |
| long | FFFFFFFF |
| unsigned long | FFFFFFFF |
| unsigned long long | FFFFFFFFFFFF |
| float | -9223372036854775808 |
| float | 1.7976931e+38 |

```go
package main
import "C"
import "math"

func main() {
    C.f_char(C.char(42))
    C.f_short(C.short(-42))
    C.f_uchar(C.uchar(42))

    C.f_short(C.short(-42))
    C.f_ushort(C.ushort(42))

    C.f_int(C.int(-42))
    C.f_uint(C.uint(math.MaxInt32))

    C.f_long(C.long(-42))
    C.f_ulong(C.ulong(math.MaxInt32))
    C.f_longlong(C.longlong(-42))
    C.f_float(C.float(-42))
    C.f_double(C.double(1.7976931e+38))
}
```
