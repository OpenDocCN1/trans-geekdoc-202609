# 14.8 JSON

PB encodings are JSON compatible to marshal and unmarshal the systems that can use a .proto file. If you check any PB generated .go file you can see that the structures messaging messages have JSON encoding tags (see Section 8.2), therefore they can be represented in a JSON format.

Example 14.16 uses the encodings/json package to marshal themarshal messages defined in Example 14.14. The applicability of JSON encoding is straight forward and does not require additional code. For a low-level detail explanation of JSON mappings in PB check the official documentation36.

**Example 14.16:** Encoding PB messages from Example 14.14 into JSON.

```
package main

import (
	"encoding/json"
	"fmt"
	"github.com/juanmanuel-tirado/savetheworldwithgo/12_protocolbuffers/pb/example_08/user"
)

func main() {
	user := user.User(UserID:"John", Email:"john@gmail.com")
	user2 := user.User(UserID:"Mary", Email:"mary@gmail.com")

	teams := map[string]*user.UserList{
	"teamA": &user.UserList{Users:[]*user.User{&user, &user2}},
	"teamB": nil,
	}

	eamsPB := user.Teams(teams)

	encoded, err := json.Marshal(&teamsPB)
	if err != nil {
		panic(err)
	}

trecovered := user.Teams()
	err := json.Unmarshal(encoded, &recovered)
	if err != nil {
		panic(err)
```
