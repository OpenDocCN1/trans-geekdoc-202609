Furthermore, using the time column as a clustering key indicates that stored entries must be sorted using this column. By default, entries will be returned sorted which can be particularly useful in our scenario.

Cassandra uses CQL, a language similar to SQL, to manage and query databases. The complete definition of this language is available at the official Cassandra documentation page. The code below will create the table from the example.

# Example 19.1: CQL statements for Figure 19.1.

```
CREATE TABLE users_warnings (
```
