```
func encodeField(f reflect.StructField, v reflect.Value) (string, error) {
    if f.PkgPath() == "" {
        return "", nil
    }

    if f.Type.Kind() != reflect.String {
        return "", nil
    }

    tag, found := f.Tag.Lookup("pretty")
    if !found {
        return "", nil
    }

    result := f.Name + ":"
    var err error = nil
    switch tag {
    case "upper":
        result = result + strings.ToUpper(v.String())
    case "lower":
        result = result + strings.ToLower(v.String())
    default:
        err = errors.New("invalid tag value")
    }

    if err != nil {
        return "", err
    }

    return result, nil
}
```

The encodeField function uses the reflect package to inspect the tags and field values. If we find the pretty tag and one of them, we return the encoded value of the field. To do this there are some checks. The function `f.PkgPath` is empty for exported fields, therefore if this is not empty field must not. With `f.Type.Kind()` we check the field type. `f.Tag.Lookup("pretty")` checks if this field has a pretty tag. Finally, a switch statement transforms the field value according to its tag value.
