# 4.2 METHODS

In the object-oriented world, a method is defined as a procedure associated with a class. In Go there is not such a thing as classes. However, Go defines methods as a special function with a receiver. The receiver sets the type that can invoke that function.

Assume we have the Rectangle type and want to add some operations such as computing the surface. In Example 4.6, the method Surface() is a function with the receiver (r Rectangle). This means that any rectangle can invoke this method. Inside the method, the fields Height and Width from the current instance r are accessible.

Example 4.6: Definition of methods for a Rectangle type.

```
package main

import "fmt"

type Rectangle struct {
Height int
Width int
}

func (r Rectangle) Surface() int {
return r.Height * r.Width
}

func main() {
r := Rectangle(2,3)
fmt.Printf("rectangle %v has surface %d\n", r, r.Surface())
}
```
