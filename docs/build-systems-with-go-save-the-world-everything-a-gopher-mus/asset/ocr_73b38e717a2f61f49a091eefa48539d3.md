# 6.2.1 Buffered channels

Channels can be buffered or unbuffered. The statement make(chan int) generates an unbuffered channel. Buffered channels have capacity, this makes both sides of the channel must be ready to send and receive data. On the other side, buffered channels can be declared with make(chan int, n) where n is the buffer size. In this case, the channel can store values independently of the reader and receiver.

In Example 6.5, two functions and the main send data to the same. Due to the code workflow, the main writes to the channel when nobody is listening which triggers the error fatal error: all goroutines are asleep deadlock!. In this case, a buffered channel can store messages until the receiver are ready to consume the messages. This example only needs one-element buffer. However, you can check how removing the size value in the make statement returns an unbuffered channel.
