# 2.4 POINTERS

Go works with arguments as values or references. When working with references we talk about pointers. A pointer addresses a memory location τ instead of a value. In Go pointers are identified following the C notation with a star. For example, * indicates a pointer to a value of type τ.

Example 2.11 has two functions a and b that set an incoming argument to zero. The code in the main function declares a variable x and call these functions. Notice that a does not change x because receives values as arguments. This is with a copy of variable x. However, b sets x to zero because it receives a pointer to the value. The operator & returns the pointer to the variable, which is of type *int. See how this operator returns the memory address of variable x with fmt.Println(&x).
