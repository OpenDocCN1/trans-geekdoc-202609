Errors are very important in logs. Understanding where errors occur in a program runtime is a crucial task for any developer. The error type is available as a context type like shown in Example 16.7.

# Example 16.7: Single error logging.

```
package main

import (
    "errors"
    "github.com/rs/zerolog/log"
)

func main() {
    err := errors.New("there is an error")
    log.Error(err).Msg("this is the way to log errors")
}
```

The point in the code where an error occurred may not always be enough. Errors can be triggered by the propagation of previous mistakes. In these cases, the full stack trace can be more useful to detect where errors come from. The stack trace can be obtained as shown in Example 16.8. Setting the ErrorStackMarshaler to the implementation offered at pkggerrors permits the context stack() to capture complete execution stack. The log output contains the list of invoked functions until the error was found.

# Example 16.8: Stack trace logging.

```
package main

import (
    "github.com/pkg/errors"
    "github.com/rs/zerolog/log"
    "github.com/rs/zerolog"
    "github.com/rs/zerolog/pkggerrors"
)

func failA(err error) error {
    return failB(err)
}

func failB(err error) error {
    return failC(err)
}
```
