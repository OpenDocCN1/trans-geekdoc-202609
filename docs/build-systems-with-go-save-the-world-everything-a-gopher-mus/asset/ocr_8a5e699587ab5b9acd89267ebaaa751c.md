# ## 18.2 GORM

GORM is an Object-relational mapping (ORM) library for Go. Like any other ORM, GORM offers an abstraction layer that translates operations on structs to SQL. MySQL, PostgreSQL, SQLite, SQL Server, and Clickhouse.

# ### 18.2.1 Basics

GORM provides its own database drivers to be used. For simplicity, the examples use the SQLite driver available at package gorm.io/driver/sqlite. For information about other supported databases check the documentation. First, we have to initialize an instance of connections represented by * db.
