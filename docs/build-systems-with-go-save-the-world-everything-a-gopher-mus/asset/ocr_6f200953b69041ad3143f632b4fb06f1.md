CGO

One of the foundations of software development is code reuse. If a piece of software does the job, the wisest decision is to reuse it. Unfortunately, this is not always possible. It is common to find that the software we are looking for is written in a different programming language, or simply there is no way we can use it without over-engineering. With Cgo, we can interact with code written in C. This enables Go to access a large number of existing solutions. In this Chapter, we explore how to use Cgo to interact with C programs and libraries.

# 13.1 USE CGO FROM GO

Using Cgo we can call code from Go. More precisely, we can use functions and structs defined in C. This can be done with the pseudopackage that combines programming sources into the same Go package. For example, let's assume that we have to execute the following func_in_c function written in C.

```
#include <stdio.h>
void func_in_c() {
    printf("printed with C\n");
}
```

We integrate this C code into our Go code like shown in Example 13.1. Observe that the code is added in a commented region before the import "c" statement. This informs the Go compiler that there is C to be linked. Alternatively, the /* ... */ comment delimiters can be used like shown in Example 13.2. This permits to include comments inside the C preamble.

# Example 13.1: C function called from Go.

```
package main
// #include <stdio.h>
// void func_in_c() {
    printf("printed with C\n");
}

import "C"
// import "fmt"

func main() {
    C.func_in_c()
    fmt.Println("printed with Go code")
}
```
