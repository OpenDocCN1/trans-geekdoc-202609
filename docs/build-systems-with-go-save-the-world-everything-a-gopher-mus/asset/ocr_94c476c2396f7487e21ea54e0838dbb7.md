Figure 15.4: Client-server communication in a bidirectional streaming scenario.

The client implementation from Example 15.12 sends a chat message until the server stats informs that the number of characters is greater than a limit. Because the two actions are asynchronous we use two goroutines: one to send messages and other to monitor chat stats. The ChatServiceClient has methods for both sending and receiving data. The stats function receives stats from the server and closes the stream (line 36).
