# 15.3 CREATING A SERVER

Once the gRPC server is generated, we can import the corresponding package into our code. This code provides us with the skeleton of the Go functions we have to implement in our .proto file. Note that right now we have only defined the signature of the remote functions, not the logic itself. This has to be done on a server. We can consider three steps prior to having a server up and running: the server implementation, the service registration, and the server waiting for incoming requests.
