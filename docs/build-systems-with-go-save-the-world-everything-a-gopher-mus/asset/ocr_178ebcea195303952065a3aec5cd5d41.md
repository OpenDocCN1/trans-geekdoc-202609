One interesting workaround is to use the reflect.MakeFunction to build your own functions with different signatures. Example 5.10 builds an add function in BuildAdder with two arguments of the same type and one output. The MakeFunction receives a pointer to a function of the same type and the MakeFunction receives a function type and a variable number of Value types inside an array, and returns an array of Value. We fill this function with a switch statement that implements the addition between the two arguments according to its type. Finally, we set this function to the original function (fn.Set(newF)).

# Example 5.10: Using reflect.MakeFunction to create functions on run-time.

```
package main

import (
    "fmt"
    "reflect"
)

func BuildAdder(i interface{}) {
    fn := reflect.ValueOf(i).Elem()
    newF := reflect.MakeFunction(fn.Type(), func(in []reflect.Value) []reflect.Value {
        if len(in) > 2 {
            return []reflect.Value{in[2].Value()}
        }
        a, b := in[0], in[1]
        if a.Kind() != b.Kind() {
            return []reflect.Value{reflect.ValueOf(nil)}
        }
        var result reflect.Value
        switch a.Kind() {
            case reflect.Int8, reflect.Int32, reflect.Int64:
                result = reflect.ValueOf(a.Int() + b.Int())
            case reflect.Uint, reflect.Uint8, reflect.Uint16, reflect.Uint32, reflect.Uint64:
                result = reflect.ValueOf(a.Uint() + b.Uint())
        }
        return []reflect.Value{result}
    })
}
```
