# 6.1 GOUTINES

A Goroutine is a lightweight thread managed by the Go runtime. Goroutines are declared using the go statement followed by the execution. Example 6.1 launches the Showit function that runs concurrently with the main function. Both functions print a message after sleeping (time.Sleep). The main function sleeps the time of Showit that is why we have a ratio of two messages from one function versus the other. It is important to notice that the loop in Showit is endless, the program execution terminates when the main function finishes. Goroutines will remain running when the main function finishes.

# Example 6.1: Creation of goroutines.

```

2
3 import (
4    "fmt"
5    "time"
6 )
7
8 func Showit() {
9    for {
10        time.Sleep(time.Millisecond * 100)
11        fmt.Println("Here is it!!!")
12    }
13 }
14
15 func main() {
16
17    go Showit()
18
19    for i := 0; i < 5; i++ {
20        time.Sleep(time.Millisecond * 50)
21        fmt.Println("Where is it?")
22    }
23 }
```
