# 前言

欢迎并感谢阅读。

从我开始学习 Go 编程以来，我一直喜欢它对简单性的非凡追求。很难找到另一种语言能让事情变得如此容易。这就是这门语言的魅力所在。时光流逝，Go 不再是新秀，它已经成为一门由丰富的库、项目和工具生态系统包围的成熟语言。谈论 Go 不再是谈论那种让你的生活更简单的花哨语言。Go 是由致力于投入的开发者社区维护的不断增长的卓越解决方案生态系统的优雅体现。

Go 最初的设计是为了简化复杂系统的构建。然而，当开发者决定进一步学习 Go，探索 Go 生态系统中的工具、库和项目时，本书将简单解释这门语言。本书可以用于构建生产级系统。一本书涵盖了 gopher 必须了解的一切。

我希望这本书是有帮助的。

# 谁应该读这本书？

本书面向 Go 新手以及具有其他语言编程经验的开发者。本书书的第一部分涵盖了 Go 语言从基础到更高级的概念。第二部分假设读者已经熟悉这些概念，并探索如何将它们与其他工具结合构建系统。如果你是 Go 新手，可以从头开始。但是，如果你已经有一定的经验，可以从第二部分开始，并在需要时回顾任何基础概念。或者你可以根据方便查看各个章节。

# 本书的结构

本书的结构设计便于你找到那些可能对你的工作更有趣的部分。然而，如果你是完全的初学者，或者对书中解释的所有概念感到不适应，可以从头开始。无论你的用例是什么，这些都是本书的内容。

- **第一部分：Go 语言**
第一部分从最基础到标准库提供的高级工具探索该语言。

- **第 1 章：Go 初步**
本章专门为写，旨在激励新手运行他们的第一个 Go 程序。

- **第 2 章：基础知识**
本章解释了所有的 Go 基础知识，包括变量、类型、指针、函数。

- **第 3 章：数组、切片和映射**
本章解释了 Go 的基础，包括数组、切片和映射。

- **第 4 章：结构体、方法和接口**
本章描述了 结构体、方法和接口。

- **第 5 章：反射**
通过探索反射，读者可以理解 Go。

- **第 6 章：并发**
并发并不是一个简单的课题。然而，本章介绍了 goroutine、通道（channel）等。

- **第 7 章：输入/输出**
本章解释了 Go 提供的 I/O 支持。

- **第 8 章：编码**
本章介绍了如 CSV、JSON 或 XML 等编码。

- **第 9 章：HTTP**
本章解释了我们如何实现 HTTP 客户端和服务器。

- **第 10 章：模板**
模板是可以通过程序填充的片段。本章介绍了如何自定义使用它们。

- **第 11 章：测试**
本章将展示如何在 Go 中运行测试和基准测试（benchmark）。

- **第 12 章：模块与文档**
本章解释了如何管理依赖以及编写文档。

- **第 13 章：Cgo**
Go 可以使用 Cgo 调用 C 代码。

- **第二部分：构建系统**
本书的第二部分面向那些熟悉该语言并希望探索 Go 生态系统以构建复杂系统的读者。

- **第 14 章：协议传输缓冲区**
本章回顾了 protocol buffer 序列化格式以及如何在 Go 中使用它。

- **第 15 章：gRPC**
本章解释了如何定义服务、服务器、客户端、流以及拦截器。

- **第 16 章：使用 Zerolog日志**
本章向读者展示如何使用强大的 Zerolog 库记录日志。

- **第 17 章：命令行界面**
复杂的程序需要命令行界面。本章向开发者展示如何在项目中集成 Cobra 库，以获得专业的 CLI。

- **第 18 章：关系型数据库**
本章介绍了如何使用标准库操作和查询 SQL 数据库。此外，它探索了如何使用 GORM 库进行 ORM 方案。

- **第 19 章：NoSQL 数据库**
NoSQL 数据库解决方案非常常见，Go 生态系统提供了解决方案。本章解释了如何使用 GoCQL 操作 Cassandra。

- **第 20 章：Kafka**
本章回顾了 Apache Kafka 的基础，并概述了与该流平台交互的三种不同解决方案。

# 规范

本书围绕自包含的示例构建。这些示例是极简的代码片段，帮助读者熟悉所解释的概念。示例足够小，让读者对真实程序的形式有一个直。。某些示例可能会打印内容以帮助读者，在这种情况下，将显示预期输出以便读者阅读。
