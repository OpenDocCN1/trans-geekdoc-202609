
```go
func updater(monitor atomic.Value, m *sync.Mutex) {
	for {
		time.Sleep(time.Millisecond * 500)
		m.Lock()
		current := monitor.Load().(*Monitor)
		current.ActiveUsers += 100
		current.Requests += 30
		monitor.Store(current)
		m.Unlock()
	}
}
```

```go
func observe(monitor atomic.Value) {
	for {
		time.Sleep(time.Second)
		current := monitor.Load()

	}
}
```

## 7.1 READERS AND WRITERS

I/O operations can be summarized by readers and writers. Go defines the Reader and Writer interfaces in the io package. A Reader must implement a read operation that receives a target byte array where the data is stored, it returns the number of bytes read and error if any. Writer takes a byte array to be written and returns the number of written bytes and error if any.

```go
type Reader interface {
	Read(p []byte) (n int, err error)
}
```

```go
type Writer interface {
	Write(p []byte) (n int, err error)
}
```

Example 7.1 shows a Reader implementation for strings. This reader fills the array p with many characters as len(p) starting from the last position read from. The first part in the Read method adds some error control. If all the characters from the string were processed, returns err to indicate that no more characters are available. Notice that the target array is reused in so iterations where the number of characters is smaller than the length of the array it it will contain characters from previous calls.

Example 7.1: Implementation of a Reader interface.

```go
package main

import (
	"errors"
	"fmt"
	"io"
)

type MyReader struct {
	data string
	from int
}

func (r *MyReader) Read(p []byte) (int, error) {
	if p == nil {
		return -1, errors.New("nil target array")
	}
	if len(r.data) <= 0 || r.from == len(r.data) {
		return 0, io.EOF
	}
	n := len(r.data) - r.from
	if len(p) < n {
		n = len(p)
	}
	for i := 0; i < n; i++ {
		b := byte(r.data[r.from])
		p[i] = b
		r.from++
	}
	if r.from == len(r.data) {
		return n, io.EOF
	}
	return n, nil
}

func main() {
	target := make([]byte, 5)
	empty := MyReader(target)
	n, err := empty.Read(target)
	fmt.Printf("Read %d: Error: %v\n", n, err)
	mr := MyReader("Save the world with Go!!!")
	n, err = mr.Read(target)
	if err != nil {
		fmt.Printf("Read %d: Error: %v\n", n, err)
	}
	fmt.Printf("Read %d: Error: %v%s\n", n, err)
}
```

Implementing a writer is similar to implementing a reader. Example 7.2 implements a writer designed with a limiting number of bytes to be written in each call. It specifies that the number of written bytes is smaller than the size of p an error must be filled. Additionally, we consider that an empty p corresponds to an EOF. Our writer will add the content of p to the current data string in batches. Observe that all iterations except the last one return an error due to the size limit.

# Example 7.2: Implementation of a Writer interface.

```go
package main

import (
	"io"
	"fmt"
	"errors"
)

type MyWriter struct {
	data string
	size int
}

func (mw *MyWriter) Write(p []byte) (int, error) {
	if len(p) == 0 {
		return 0, io.EOF
	}
	n := mw.size
	var err error = nil
	if len(p) < mw.size {
		n = len(p)
	} else {
		err = errors.New("p larger than size")
	}
	mw.data = mw.data + string(p[0:n])

	return n, err
}

func main() {
	msg := []byte("the world with Go!!!\n")
	mw := &MyWriter{data: "Save", size: 11}
	i := 0
	var err error
	for err == nil && i < len(msg) {
		n, err := mw.Write(msg[i:])
		fmt.Printf("Written %d: Error: %v\n", n, err)
		i += n
	}
}
```
