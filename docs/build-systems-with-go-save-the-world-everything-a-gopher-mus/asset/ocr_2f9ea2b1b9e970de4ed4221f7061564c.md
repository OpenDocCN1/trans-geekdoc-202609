#  10.4 HTML

Templates are particularly useful to serve HTML content. However, due to safety reasons and potential code injection attacks, Go provides a specific package for HTML templates in html/template. The different functions and methods from this package are fairly similar to those already explained for text/template.

In Example 10.8 we populate a web page with a collection of items. As you can see, we generate the output in the same way we did for templates. Notice that the output follows the HTML specification automatically escaping characters when needed.

Example 10.8: HTML list with a template.

```
package main

import (
    "html/template"
    "os"
)

const Page = `
<head>
<title>{{.Name}} Languages</title>
</head>
<body>
<ul>
{{range .Languages}}<li>{{print .}}</li>{{end}}
</ul>
</body>
</html>`

type UserExperience struct {
    Name string
    Languages []string
}

func main() {
    languages := []string{"Go", "C++", "Ca"}
    u := UserExperience{"John", languages}

    t := template.Must(template.New("web").Parse(Page))

    err := t.Execute(os.Stdout, u)
```
