# 2.8 DEFER, PANIC, AND RECOVER

The defer statement pushes a function to a list. This list of functions is executed when the surrounding function ends. This statement is specially designed to ensure the correctness of the execution after the function ends. In particular, defer is useful to clean up resources allocated to a function.

# Example 2.18: defer.

```
package main

import "fmt"

func CloseMsg() {
	fmt.Println("Closed!!")
}

func main() {
	defer CloseMsg()
	fmt.Println("Doing something...")
	defer fmt.Println("Certainly closed!!")
	fmt.Println("Doing something...")
}
```

| Doing something...
| Doing something else.
| Certainly closed!!
| Closed!! |

The built-in panic stops the execution flow, executes deferred functions and returns control to the calling function. This occurs for all functions until the control of the program. Example 2.19, calls panic indicates a situation that goes beyond the control of the program.
