# 16.2 ZEROLOG BASICS

The Previous Section explored how to use the basic logging features provided within the log package. The limitations of this package in terms of customization, efficiency, and adaptability made third-party developers write their own logging solutions. A remarkable solution is Zerolog45 which provides JSON oriented logging using zero-allocation.

The simplest Zerolog message defines a logging level and a message string. The generated output is a JSON object with the level, time, and the message. There are seven log levels shown in Example 16.3 from panic (level 5) to trace (level -1).

> Example 16.3: Logging messages in zerolog.

```
package main

import(
    "github.com/rs/zerolog/log"
)

func main() {
    // Panic or fatal messages stop the execution flow
    // log.Panic().MMsg("This is a panic message")
    // log.Fatal().MMsg("This is a fatal message")
    log.Error().MMsg("This is an error message")
    log.Warn().MMsg("This is a warning message")
    log.Info().MMsg("This is an information message")
    log.Debug().MMsg("This is a debug message")
    log.Trace().MMsg("This is a trace message")
}
```
