The server implementation from Example 15.10 is mostly contained in an example for loop. When the sum is invoked, the server checks the input stream until the EOF or an error occurs. If no error or EOF is found, the server accumulates the incoming values (line 28) otherwise, the server invokes SendAndClose sending the accumulated value to the client.
