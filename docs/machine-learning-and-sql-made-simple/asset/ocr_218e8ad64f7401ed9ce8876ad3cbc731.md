```
AS
SELECT column1, column2, ...
FROM table
WHERE condition;
```

Example:

```
```sql
ALTER VIEW customers_usa
AS
SELECT customer_name, email, phone, address
FROM customers
WHERE country = 'USA';
```
```

In this example, we modify the "customers_usa" view to include the "address" column in addition to the existing columns. The underlying query and the filtering condition remain the same.
