1.3 Data Abstraction: Views provide a way to abstract the underlying structure of the data. You can present a simplified view of the data to users, hiding the complexities of table relationships and joins.

Example:

```
```sql
CREATE VIEW sales_view AS
SELECT product_name, SUM(quantity) AS total_quantity, SUM(amount) AS total_amount
FROM sales
GROUP BY product_name;
```
```

In this example, we create a view called sales_view that summarizes sales data by product name. The view aggregates the quantity and amount columns from the sales table, providing a simplified view of the data.
