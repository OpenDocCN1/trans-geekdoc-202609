4.3 Data Synchronization: Triggers can be used to synchronize data between tables or perform additional actions when certain database events occur. For example, a trigger can update a corresponding table when a related table is modified.

Example:

```
```sql
CREATE TRIGGER update_stock AFTER INSERT ON sales

FOR EACH ROW

BEGIN

    UPDATE inventory

    SET quantity = quantity - NEW.quantity

    WHERE product_id = NEW.product_id;

END;
```
```

In this example, we create a trigger called update_stock. Whenever a new row is inserted into the sales table, the trigger will automatically execute and update the quantity in the inventory table based on the quantity sold.
