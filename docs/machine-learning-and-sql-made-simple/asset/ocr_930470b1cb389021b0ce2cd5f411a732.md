extract information, perform calculations, and manipulate date and time values. Let's explore some commonly used date and time functions:

+   - 4.1 CURRENT_DATE: Returns the current date.
- 4.2 CURRENT_TIME: Returns the current time.
- 4.3 EXTRACT: Extracts a specific component (year, month, day, etc.) from a date or time value.
- 4.4 DATE_ADD: Adds a specified interval to a date or time value.
- 4.5 DATE_DIFF: Calculates the difference between two dates or time values.

Example:

```
```sql
SELECT order_date,
    EXTRACT(YEAR FROM order_date) AS order_year,
    EXTRACT(MONTH FROM order_date) AS order_month,
    DATE_ADD(order_date, INTERVAL 7 DAY) AS delivery_date,
    DATE_DIFF(delivery_date, order_date) AS delivery_duration
FROM orders;
```
