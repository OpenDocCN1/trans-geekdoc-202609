# 3.2 Subqueries with EXISTS Operator:

```
```sql
SELECT department_name
FROM departments d
WHERE EXISTS (SELECT * FROM employees e WHERE e.department_id = d.department_id);
```
```

In this example, the subquery `(SELECT * FROM employees e WHERE e.department_id = d.department_id)` checks if there are any employees in each department. The outer query retrieves the department names for departments that have at least one employee.

# 3.3 Subqueries with IN Operator:

```
```sql
SELECT product_name
FROM products
WHERE product_id IN (SELECT product_id FROM orders WHERE order_date >= '2023-01-01');
```
```
