# 2.1 String Functions:

+   - CONCAT: Concatenates two or more strings together.
- LENGTH: Returns the length of a string.
- UPPER: Converts a string to uppercase.
- LOWER: Converts a string to lowercase.
- SUBSTRING: Extracts a substring from a string based on a specified starting position and length.

Example:

```
```sql
SELECT CONCAT(first_name,' ',last_name) AS full_name,
  LENGTH(email) AS email_length,
  UPPER(city) AS capital_city,
  LOWER(address) AS lowercase_address,
  SUBSTRING(description, 1, 50) AS short_description
FROM customers;
```
