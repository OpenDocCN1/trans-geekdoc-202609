
### 第 6 节：GROUP BY

GROUP BY 子句用于基于一个或多个列对数据进行分组。它允许您在每个组内聚合和汇总数据。以下是语法：

```sql
SELECT column1, column2, ..., aggregate_function(column)
FROM table
GROUP BY column1, column2, ...;
```

示例：

```sql
SELECT category, COUNT(*)
FROM products
GROUP BY category;
```

在此示例中，我们按产品类别对产品进行分组，并计算每个类别中的产品数量。

### 第 7 节：HAVING

HAVING 子句用于根据特定条件过滤组。它的工作原理与 WHERE 子句类似，但作用于分组后的数据。以下是语法：

```sql
SELECT column1, column2, ..., aggregate_function(column)
FROM table
GROUP BY column1, column2, ...
HAVING condition;
```

示例：

```sql
SELECT category, AVG(price)
FROM products
GROUP BY category
HAVING AVG(price) > 1000;
```

在此示例中，我们按类别对产品进行分组，计算每个类别内的平均价格，并仅检索平均价格高于 1000 的类别

在本章中，我们探索了 SQL 中聚合函数的强大功能。我们学习了如何使用 COUNT、SUM、AVG、MAX 和 MIN 对数值数据进行计算并获得有用的汇总。此外，我们发现了 GROUP BY 子句，它允许我们基于特定列对数据进行分组，并在每个组内应用聚合函数。HAVING 子句进一步使我们能够根据条件过滤组。

通过利用聚合函数和对数据进行分组，您可以获得有价值的见解，并以更有意义的方式分析数据。这些技术在处理大型数据集以及需要对数据子集进行计算时特别有用。

## 第 7 章：SQL 中的数据操作

在前几章中，我们专注于从数据库表中检索和分析数据。在本章中，我们将探讨 SQL 数据操作的核心方面。数据操作涉及在数据库表中插入、更新和删除记录。了解这些操作对于有效地维护和修改数据至关重要。到本章结束时，您将对如何使用 SQL 语句操作数据有扎实的理解。

### 第 1 节：插入数据

INSERT 语句用于向表中添加新记录。它允许您为每个列指定值或从另一个表插入数据。以下是基本语法：

```sql
INSERT INTO table (column1, column2, ...)
VALUES (value1, value2, ...);
```

示例 1：

```sql
INSERT INTO customers (customer_name, email, phone)
VALUES ('John Smith','john@example.com','555-1234');
```

在此示例中，我们向“customers”表插入一条新记录，并为“customer_name”、“email”和“phone”列指定值。

### 示例 2：

```sql
INSERT INTO customers (customer_name, email, phone)
SELECT name, email, phone
FROM old_customers;
```

在此示例中，我们通过从“old_customers”表选择数据向“customers”表插入记录。SELECT 语句中的列名应与目标表的列名匹配。

### 第 2 节：更新数据

UPDATE 语句用于修改表中的现有记录。它允许您同时更新特定列或多个列。以下是基本语法：

```sql
UPDATE table
SET column1 = value1, column2 = value2, ...
WHERE condition;
```

示例：

```sql
UPDATE employees
SET salary = salary * 1.1
WHERE department = 'Sales';
```

在此示例中，我们通过将工资提高 10% 来更新“Sales”部门员工的“salary”列。

### 第 3 节：删除数据

DELETE 语句用于从表中删除记录。它允许您指定条件以删除特定行或从表中删除所有行。以下是基本语法：

```sql
DELETE FROM table
WHERE condition;
```

示例 1：

```sql
DELETE FROM customers
WHERE customer_id = 5;
```

在此示例中，我们删除“customers”表中“customer_id”等于 5 的记录。

示例 2：

```sql
DELETE FROM orders
WHERE order_date < '2022-01-01';
```

在此示例中，我们删除“orders”表中“order_date”早于 2022 年 1 月 1 日的所有记录。

### 第 4 节：事务管理

事务允许您将多个 SQL 语句组合成一个工作单元。它通过提交所有更改或在发生错误时回滚来确保您的数据完整性和一致性。事务具有四个主要属性，称为 ACID：原子性、一致性、隔离性和持久性。

```sql
BEGIN TRANSACTION;
```

-- SQL 语句

```sql
COMMIT;
```

在此示例中，我们使用 BEGIN TRANSACTION 语句开始一个事务。我们在事务中执行多个 SQL 语句，并使用 COMMIT 语句提交更改。如果发生任何错误或我们想丢弃更改，我们可以使用 ROLLBACK 语句。

### 第 5 节：用于数据操作效率的索引

索引是数据库结构，可提高数据检索和操作操作的性能。通过在列上创建索引，您可以加快搜索和数据操作任务。索引在处理大型表或频繁更新的表时特别有用。以下是有关索引的几个关键点：

- 索引是使用 CREATE INDEX 语句创建的，指定表名、要索引的列（s）和可选的索引名。
- 索引可以显著提高 SELECT、UPDATE、DELETE 甚至 INSERT 操作的性能。
- 然而，索引会带来一些开销，因为它们需要额外的存储空间并影响数据修改操作（INSERT、UPDATE、DELETE）的速度。
- 根据搜索和连接操作中使用频率仔细选择要索引的列非常重要。
- 建议定期维护索引以确保最佳性能，因为索引会随着时间的推移而变得碎片化或过时。

示例：

```sql
CREATE INDEX idx_customers_email ON customers (email);
```

在此示例中，我们在“customers”表的“email”列上创建名为“idx_customers_email”的索引。此索引可以在查询中使用“email”列时加快搜索速度并提高数据操作性能。

### 第 6 节：数据操作的最佳实践

执行数据操作时，遵循一些最佳实践以确保数据完整性和效率非常重要：

- 在执行任何数据操作操作之前，始终备份您的数据，尤其是在处理更新或删除时。
- 在进行多次更改时使用事务以保持数据一致性并确保出现错误时可以回滚。
- 编写高效且具体的 WHERE 子句以限制更新和删除的范围并避免意外更改。
- 考虑数据操作对索引的影响，并在必要时计划索引维护或重新组织。
- 在将数据操作应用于大型数据集之前，先在小规模上测试它们以避免意外后果。

通过遵循这些最佳实践，您可以在保持数据完整性的同时自信地操作数据并优化性能。
