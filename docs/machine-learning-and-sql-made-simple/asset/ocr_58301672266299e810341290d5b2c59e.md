# Example:

```
```sql
CREATE VIEW customers_usa AS
SELECT customer_name, email, phone
FROM customers
WHERE country = 'USA';
```
```

In this example, we create a view named "customers_usa" that includes the "customer_name," "email," and "phone" columns from the "customers" table. Only customers from the USA are included in the view based on the specified condition.
