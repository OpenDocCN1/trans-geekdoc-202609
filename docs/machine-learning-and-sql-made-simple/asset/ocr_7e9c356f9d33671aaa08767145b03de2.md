# c) Handling Inconsistent Formats:

Data collected from various sources may have inconsistent formats or units. For example, one source may represent dates as "DD-MM-YYYY," while another uses "YYYY-MM-DD." Inconsistent formats can lead to errors and misinterpretations. To address this, we can standardize the data by converting it to a consistent format.

# 2. Feature Engineering:

Feature engineering involves creating new features or transforming existing features to make them more informative and representative of the problem at hand. Well-designed features can significantly improve the performance of machine learning models.
