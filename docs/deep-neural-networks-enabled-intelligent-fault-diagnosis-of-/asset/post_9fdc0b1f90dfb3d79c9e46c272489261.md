## Result Comparison

Additional experiments are carried out to compare the fault classification performances between the proposed DL method and traditional machine learning method. Results are listed in Table 6.4, which prove that the proposed DCNN method outperforms traditional fault diagnosis methods and the multi-signal DCNN model using time-frequency images achieve the best classification accuracy. In traditional methods, one essential step in realizing fault diagnosis is preprocessing original signal to extract and select proper features to differentiate working states that require prior knowledge. Therefore, when using original data without feature selection, traditional methods cannot get an accurate classification. For deep architecture, it can learn from original data and using the training set to adjust model parameters to automatically select features that contribute to classification accuracy where convolution operation can extract features from the input image and different convolution kernel can learn different discrimin features. Compared with our previous works, the proposed method improves the classification accuracy for induction motor fault diagnosis. The proposed method overcomes the limitation caused by the single-sensor signal and enlarges the feature space based on multiple signals.

Different from the single-signal model, the multi-signal model is able to analyze multiple types of sensor data simultaneously and finally realize accurate fault classification based on the fused features. Each type of sensor signal contains specific information related to working condition. For example, the current signal has been widely used in the diagnosis of stator faults and rotor faults, while many bearing fault diagnosis methods are performed by analyzing vibration signals. Thus, combining these signals and analyzing them together is an effective alternative to realize multi-fault diagnosis even under complex conditions. This chapter introduces a methodology on building multi-signal deep learning architecture to learn representations from different scales.

## Measurement Uncertainty

Due to measurement uncertainty, sensor data vary from each other, and using different training samples to train deep architecture may produce various performances. For experimental verification, the acquired sensor data contain noise and may have measurement error in certain samples. To investigate the influence caused by measurement uncertainty, confidence interval estimation for the classification accuracy is performed using the bootstrap method (Deutsch and He 2017). The bootstrap method is a random sampling in statistical analysis for uncertainty (Endo, Watanabe, and Yamamoto 2015). For the model performance evaluation, the main procedure is followed:

Initially, a resample of the original training data is generated by bootstrap procedure. The dataset is sampled with replacement, which means each sample can be selected more than once. The size of resample is the same as that of the original dataset, and the samples that are not selected are out-of-bag samples.

Then, the proposed model is trained using the resample data and is evaluated on out-of-bag samples. For each bootstrap iteration, a performance statistic can be obtained.

The bootstrap procedure is repeated for a number of times and a number of different resamples are generated. Repeating training and evaluation procedure, a performance statistics are achieved. Based on these performance statistics, a confidence interval for the designed model can be calculated.

As the number of bootstrap iterations increases, the confidence interval becomes. In this section, considering the number of original data and computation costs, 500 bootstrap iterations are adapted to generate classification accuracy confidence interval for the proposed multi-signal framework. The results are reported in Table 6.5 and Figure 6.11. In Figure 6.11, the color bars represent the model classification accuracy across bootstrap samples, and the black lines denote the confidence interval. Based on estimation results of confidence interval for classification accuracy, the proposed multi-signal DCNN has relatively stable performance and different resamples have limited influence on model performance. For the merged model, there is a 95% likelihood that the range between 99.89% and 99.93% covers the model skill of fault classification. For multi-channel model, there is a 95% likelihood that the range between 99.21% and 99.29% covers its skill. Compared with the multi-channel model, the merged model has more accurate prediction and shows better capability in model robustness.

## CONCLUSION

This chapter proposes a DCNN-based multi-signal fault diagnosis framework with its application on induction motors, where TFDs of sensor signals are utilized as the input images. CNN is utilized as the building block for the multi-signal, which shows the capability to learn discriminative features automatically from TFD images and produce accurate fault classification. Both vibration and current signals are utilized to verify the performance of the presented framework. Two different DCNN-based multi-signal architectures are designed and their performances are explored through experiments, where the merged model has achieved the best performance. Furthermore, the influence of measurement uncertainty is discussed based on the statistical analysis.

Future study can be conducted aimed at improving the performance of DCNN by tuning hyperparameters and network architecture. To overcome the problem of limited training data for a deep architecture, data augmentation can be performed to enlarge the dataset. In addition, existing pre-trained models for fault diagnosis can be further investigated.
