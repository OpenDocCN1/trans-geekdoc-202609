# Scale Mixture Prior

In the implementation of DARTS, each row of the sampling matrix A is constrained by the Softmax normalization, leading to the winner-takes-all evaluation. In order to overcome this phenomenon, a soft constraint based on the MAP is given to replace Softmax, which assumes each point of the matrix A obeys a bimodal distribution:

```
$$A^{MAP} = \arg min_A - \log P(A|D)\n=\arg min_A - \log P(D|A) - \log P(A)$ \quad (8.7)$
```

Note that the parameters in Eq. (8.7) are points other than distributions. This is a coincidence that the regularization $- \log P(A)$ is an instance of the second item $- \log P((\Lambda/j)^{k=1})$ in Eq. (8.5) when $(\Lambda/j)^{k=1}$ is just the mean of the posterior distribution. Therefore, provided the prior $P(\Lambda)$ is a bimodal distribution, this soft constraint on the sampling distribution group can be implemented in a broader sense. The prior is set to:

```
$$P(\Lambda) = \prod_{j=1}^8 \lambda N((\Lambda/j)^{k=1} |\mu_1, \sigma_1^2) + (1-\lambda) N((\Lambda/j)^{k=1} |\mu_2, \sigma_2^2)$ \quad (8.8)$$
```

$(\Lambda/j)^{k=1}$ is a sample point from the posterior distribution in the group, $N((\Lambda/j)^{k=1} |\mu, \sigma^2)$ is the Gaussian density evaluated at $(\Lambda/j)^{k=1}$ with mean $\mu$ and variance $\sigma^2$, $\lambda$ is a hyperparameter of the ratio scaling two Gaussian peaks. As shown in Figure 8.2, our prior is a bimodal distribution, then the group $\Lambda$ can be divided into two peaks, and $\lambda$ determines the proportion of allocation.
