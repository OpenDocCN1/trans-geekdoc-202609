# Deep Neural Networks-Enabled Intelligent Fault Diagnosis of Mechanical Systems

Deep Q Network

Deep Q network (DQN), as a representative achievement of DRL, has achieved salient performance in practice when playing Atari games. It mainly integrates deep neural network (DNN) with Q-learning algorithm for autonomously learning the behavior policy $\pi_	heta$ by interaction with the environment, which maps a given state $s\in S$ to an action $a\in A$ such that $a=\pi_	heta(s)$. In the interactive process, the agent is to maximize the cumulated reward $R_t$ at time $t$, which is discounted by a factor of $\gamma$ per time-step and defined as:

```
$R_t = \sum_{t'=t}^{T}\gamma^{t'-t}r_{t'}$
```

where $T$ indicates the terminated time step, $\gamma$ is the discount factor. The smaller the value of $\gamma$ is, the more the agent focuses on the current reward.

For the Q-learning algorithm, its action-value function $Q^\pi(s,a)$ under the policy $\pi$ is defined as

```
$Q^*(s,a)=\mathbb{E}_\pi[R_t|s=s,a_t=a;\pi]$
```

where $\mathbb{E}_\pi$ is the expected return under the policy $\pi$. The temporal-difference updating of Q-learning is expressed by:

```
$Q(s,a)\leftarrow Q(s,a)+\alpha(r+\gamma\max_{a'}Q(s',a')-Q(s,a))$
```

where $Q(s,a)$ indicates the action-value function and $\alpha$ is the learning rate. The optimal action-value function $Q^*(s,a)=\max_\pi Q^*(s,a)$ obeys the Bellman equation and is written as:

```
$Q^*(s,a)=\mathbb{E}[r+\gamma\max_{a'}Q^*(s',a')|s,a]$$
```

In DQN, DNN is used to approximate the action-value function $Q^*(s,a)$ in the policy $\pi$

```
$Q(s,a;\theta)=Q^*(s,a)$
```

where $	heta$ is the parameters of the DNN model.

In the process of the agent's interaction with the environment, $\epsilon$-greedy algorithm, is used to balance "exploration" (random action $a\in A$) and "exploitation" (action $a$ with $arg\max_aQ(s,a;\theta)$ and generate a series of experiences defined as $e=(s,r,s')$. These experience samples are stored in ER buffer $B$. Then, ER is utilized to sample experience samples from the ER buffer randomly, thereby updating the DNN model.
