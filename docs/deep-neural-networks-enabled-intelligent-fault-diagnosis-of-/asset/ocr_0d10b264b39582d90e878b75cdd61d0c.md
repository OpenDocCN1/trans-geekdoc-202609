# Space A

A contains all types of recognition action, and A $a_i \in A$ corresponds to a fault label $l_i \in L$. Based on it, A is set to $A=\{0,1,2,...,K-1\}$, where $K$ is the total health status of the planetary gearbox.

# Transition P

$P: S \times A \rightarrow S$ is the transition model. In this guessing game, state transition probability $p(s_{i+1}|s_i, a_i)$ in CMDP is deterministic. After guessing the current question (sample $x_i$) relating to the state $s_i$, the agent will receive the next question (the next sample $x_{i+1}$) matching the next state $s_{i+1} \in S$ according to the order of samples in $D$. After that all samples in $D$ are guessed sequentially one round game is terminated.

# Reward R

$R: S \times A \rightarrow R$ denotes a reward $r_i$, obtained by the agent for executing action at the state $s_i$. The reward function is used to evaluate the success or failure of the agent's actions, guiding the agent to learn the policy $\pi_i$ so that it can make relevant actions in given states. In this work, when the agent correctly recognizes a sample $x_i$, a positive reward is received from the environment, the other agent obtains a negative reward. Thus, the reward function is designed as:

> $R(s_i, a_i, l_i) = \begin{cases} 1, & \text{if } a_i = l_i \ -1, & \text{otherwise} \end{cases} \quad (10.1)$

Based on the definitions, the fault diagnosis problem is formally formulated as a sequential decision-making problem in CMDP, and the objective is to find an optimal recognition policy $\pi_i: S \rightarrow A$ to maximize accumulated rewards in CMDP. Thus it can be solved by DRL. Vibration in signal operation often offers strong noise and nonlinearity because of poor working conditions, which leads to low recognition accuracy if the raw signal is used as the state input directly.
