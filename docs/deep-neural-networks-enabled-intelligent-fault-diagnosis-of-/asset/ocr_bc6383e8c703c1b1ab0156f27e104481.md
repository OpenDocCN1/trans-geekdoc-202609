DBN Architecture

DBN model is a deep network architecture with multiple hidden layers which contain many nonlinear representations. It is a probabilistic generative model and can be formed by multiple RBMs as shown in Figure 3.3. It illustrates the nature of stacking RBM on top of another. DBN architecture can be built by stacking RBMs one by one to form a deep network architecture.

As DBN has multiple layers, it can learn from the input data and extract hierarchical representation corresponding to each hidden layer. Joint distribution between visible layer $v$ and $h^k$ can be calculated mathematically from conditional distribution $P(h^{k-1}|h^k)$ for the $(k-1)$ th layer conditioned on the $k$-th layer and visible-hidden joint distribution $P(h^{n-1}, h^n)$

```
$P(v,h^1,...,h^n) = \prod_{k=1}^{n-1} P(h^{k-1}|h^k) p(h^{n-1},h^n)$
```

For deep networks, learning such of parameters using traditional supervised training strategy is impractical because errors transferred to low layer levels will faint through several hidden layers and the ability to adjust the parameters is weak for traditional backpropagation method. It is difficult for the network to generate globally optimal parameters. Here the greedy layer-by-layer unsupervised pre-training method is used for training DBNs. This procedure is illustrated as follows: The first step is to train the input units ($v$) and the first hidden layer ($h_1$) using RBM rule (denoted as RBM1). Next, the first hidden layer ($h_1$) and the second hidden layer ($h_2$) are trained as an RBM (denoted as RBM2) where the output of RBM1 is used as the input for RBM2.
