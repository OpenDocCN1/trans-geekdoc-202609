# Supervised Learning

Given the insufficient labeled dataset $D_i = \{(x_i, y_i) | x_i \in R^{1\times L\times N_i}\}$ a backbone encoder $E_{	heta}(\cdot)$ takes each sample as input to extract its high-semantic feature. After that, the hidden features are fed into a classification head $H_{\phi}(\cdot)$ and output a probability distribution vector $p_i^{op} = H_{\phi}(z_i)$, which indicates the predicted state. Finally, the prediction result $p_i^{op}$ and label $y_i$ are combined to compute the cross-entropy (CE) loss $L_i$, which is formulated as:

```
$L_i = -\sum_{j=1}^{N_i} y_j \cdot \log(p_j^{op})$ (9.2)
```

# UnSupervised Learning
Inter-Instance Relation Mining

The inter-instance relation mining module aims to discern the relationship between different samples. It follows the pipeline of instance discrimination-based methods in feature extraction. Formally, for a batch of samples $\{x_i | x_i \in R^{1\times L}\}^B$ where $B$ denotes the batch size, each sample is transformed by TAD, which generates a new set of signal instances $\{x_{i,j} | x_{i,j} \in R^{1\times L}, i=1,2,...,B, j=1,2,...,M\}$. Based on the fact that instances generated from the same sample are similar while those from different samples differ markedly, given an anchor instance $x_{s,i}$, those instances $x_{s,j}^+ \in\{x_{i,j} | x_{i,j}, j=1,2,...,M\\}$ are considered as its positive features, and others $x_{i,j}^- \in\{x_{i,j} | x_{i,j} \in R^{1\times L}, i \neq s, j=1,2,...,M\}$ are its negative pairs. Then all instances are fed into the backbone encoder $E_{	heta}(\cdot)$ to extract the corresponding anchor hidden feature $z_{s,i} = E_{	heta}(x_{s,i})$, positive hidden feature $z_{s,j}^+ = E_{	heta}(x_{s,j}^+)$ and negative hidden feature $z_{s,j}^- = E_{	heta}(x_{s,j}^-)$, respectively. To keep all relation, we concatenate the features to input an instance relation head $H_{\psi}(\cdot)$ to predict whether they are positive or negative, rather than using the InfoNCE loss like other contrastive learning methods (e.g., MoCo (He et al. 2020), SimCLR (Chen et al. 2020)). This relation prediction avoids the task of maximizing negative samples in contrastive learning. The pseudo label on whether it is a positive or negative pair can be defined as:

```
$\tilde{y}_i = \begin{cases} 1 & \text{if } p_i^{op} = H_{\psi}(z_{i,j}, z_{i,j}^+) \ 0 & \text{if } p_i^{op} = H_{\psi}(z_{i,j}, z_{i,j}^-) \end{cases}$ (9.3)
```
