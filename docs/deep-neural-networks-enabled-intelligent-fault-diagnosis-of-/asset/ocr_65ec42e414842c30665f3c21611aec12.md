# Multi-signal Fault Diagnosis

For multi-signal fault diagnosis, one different architectures are investigated to explore the optimal performance. One is to combine different signals to form a multi-channel input, which is used as the input of the DCNN that can learn features from various types of signals simultaneously, as in Figure 6.8(a). The other is to separate DCNN without fully connected layers using each of signals, and then these networks are merged in higher layers to perform final classification, as in Figure 6.8(b). The same dataset is used in both architectures to compare their performances.

**Architecture 1-Multi-channel Model:** Multiple signals are combined in the data processing, where two different time-frequency images from vibration signals and current signals are joined to form a two-channel image with each channel representing one type of signal. As a result, each sample has the size of 2 × 128 × 128, and the combined dataset is used as the input of the deep model which contains 3D convolutional layers with kernel sizes 6, 8, and 6, and filter numbers 12, 24, and 24, respectively, followed by max-pooling operation with pool size as 2 × 2, and stride length as 2. After flattened, the model is followed by a fully connected layer that has 1024 units. ReLUs are utilized as the activation function in convolutional layers and fully connected layers. The output layer has six units corresponding to six different labels, which is the same as the one used in single-sensor signal model.

**Architecture 2-Merged Model:** Two separate convolutional networks are used to analyze different sensors, and the separate networks are merged in fully connected layers and contribute together to the output of label prediction. Input image of these two networks have the same size, 1 × 128 × 128. One network is responsible for learning from vibration signals and the other learns representations from current signals. The learned fault signatures from separate networks are flattened and merged to one fully connected layer with 1024 ReLUs. The output layer for predicting state label is the same as the one in architecture 1.
