$L(X, X')$ is the reconstruction error. The reconstructed matrix $X'$ can be obtained by minimizing function (2.9) using a stochastic gradient descent approach.

Specifically, to implement the denoising coding, some of the input X are randomly set to zero for generating the corrupted $\chi$ to a hidden representation $y$, where $y = f(X) = sigmoid(WX+b)$ with $	heta = \{W,b\}$, from which $X'$ can be reconstructed as $X' = g(y) = Sigmoid(W_y+b_y)$. The reconstruction error $L(X,X')$ is computed from the difference between $X'$ and $\chi$, and can be minimized by solving the cost function (2.9).

It should be noted that the motivation behind the corruption of the values of some components in $\chi$ shares the same idea as "salt noise" in image processing. Because unsupervised initialization of layers with an explicit denoising criterion can help capture meaningful structure in the input distribution, the learned intermediate representations can contribute to the subsequent learning such as classification and clustering. Furthermore, it was indicated that denoising tasks can improve the robustness of features and the sparsity of weights, thus making the discovery of interesting and prominent patterns (Cao, Huang, and Sun 2016).
