# Unsupervised Deep Transfer Learning for Fault Diagnosis

### INTRODUCTION

Intelligent fault diagnosis (IFD) is becoming an essential branch among prognostic and health management (PHM) systems. While, with the increment of available data, data-driven methods with representation learning ability are also becoming more important. Thus, deep learning (DL), which can extract useful features automatically from original signals, becomes a hot research topic for many fields as well as PHM.

Behind the effectiveness of DL-based IFD, there exist two necessary assumptions:

1. Samples from the training dataset (source domain) should have the same distribution as the test dataset (target domain).
2. Plenty of labeled data are available during the training phase.

Although the labeled data might be generated by dynamic simulations or fault experiments, the generated data are not strictly consistent with the test data in the real scenario. That is, DL models based on training dataset possess a weak generalization ability when deployed to test dataset from real applications. In addition, rotating machinery operates with varying working conditions, as loads and speeds, which also requires that trained models using the dataset from one working condition can successfully transfer to the test dataset from another working condition. In short, these factors trained in the source domain should be generalized or transferred to the target domain directly.

Shared features existing in these two domains due to the intrinsic similarity in different application scenarios or different working conditions allow this domain shift manageable.

Hence, let DL models trained in the source domain be able to be transferred well to the target domain, a new paradigm called deep transfer learning (DTL) should be introduced to IFD. One of the effective and direct DTL is to fine-tune DL models with a few labeled data in the target domain, and the fine-tuned model can be used to diagnose the test samples. Directly, the newly collected data or the data under working conditions are mostly unlabeled and it is sometimes very difficult, or even impossible to label these data. Therefore, this chapter introduces the unsupervised version of DTL, called unsupervised transfer learning (UDTL-based) IFD, which is to make predictions for unlabeled data on a target domain given labeled data on a source domain. It is worth mentioning that UDTL is sometimes called unsupervised adaptation, and this chapter does not make a strict distinction between two concepts.

In this chapter, commonly used UDTL-based settings and algorithms are discussed and a taxonomy of UDTL-based IFD is constructed. In each separate category, this chapter gives a review about recent definition of UDTL-based IFD. Some typical methods are integrated into a unified framework, which is tested on two datasets. With this comparative study, this chapter tries to give a depth discussion (it is worth mentioning that results are just a lower bound of the accuracy) of current algorithms and attempt to discuss the core that determines the transfer performance.

The rest of this chapter is organized as follows: Section 7.2 provides background and definition of UDTL-based IFD. Basic concepts, evaluation algorithms and a brief review of UDTL-based IFD are introduced in Section 7.3. After that, in Section 7.4, datasets, evaluation results, and further discussions are provided.

### Definition of UDTL

To briefly describe the definition of UDTL, this section first introduces some symbols. It is assumed that labels in the source domain are all available, and the source domain can be defined as:

$$\mathcal{D}_s = \{(x_i, y_i)\}_{i=1}^{n_s}, x_i \in X, y_i \in Y_s, \quad (7.1)$$

where $\mathcal{D}_s$ represents the source domain, $x_i \in \mathbb{R}^d$ is the $i$-th sample, $X$ is the union of all samples, $y_i$ is the $i$-th label of the $i$-th sample, $Y_s$ is the union of all different labels, and $n_s$, means the total number of source samples. Besides, it is assumed that labels in the target domain are unavailable, and thus the target domain can be defined as:

$$\mathcal{D}_t = \{(x_i')\}_{i=1}^{n_t}, x_i' \in X, \quad (7.2)$$
