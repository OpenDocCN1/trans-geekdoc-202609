Therefore, the proposed CDF utilizes BPNN as a discriminative learning method to learn the parameters of the convolutional layer. Due to the discriminative pre-training, a fast and effective convolutional pooling architecture can be performed to learn discriminative and invariant features automatically from raw vibration data of the induction motor, which does not require large-scale training samples.

To transfer the parameters of BPNN to the parameters of the convolutional pooling architecture, the structure of BPNN is designed as follows: BPNN consists of input layer, hidden layer, and output layer. Sigmoid functions are used as the activation functions for both the hidden and output layers. The sizes of BPNN’s input layer and hidden layer are set to be the local filters’ window size N and the number of filters K, respectively. After training, the parameters between the input layer and hidden layer of the BPNN can be directly used as convolutional layer. The learned transformation in BPNN can be denoted as W with a size of N × K. Then, each element in the matrix W can be regarded as one filter’s weight.

To train the specifically structured BPNN, the templates of vibration signals x' and the labels y, should be constructed as follows: Xo=(x', y)i,x' ∈ R^N, i=1,2,...,M, where M is the number of the templates samples to train BPNN and the length of each data sample is N corresponding to the input layer size of the BPNN. Since each x' is subsampled from the original sequential data, its label yi is set to be the same as the original sequential data. Since M usually exceeds the size of original training data samples, this framework can be regarded as a kind of data augmentation, which can relieve overfitting problem (Gan et al. 2015).

In the case of multi-class predictions, a one-against-one strategy where multiple binary classifiers are trained using the data from two classes is adopted. The trained classifier then applied to the dataset to predict their fault categories.

The LIBSVM tools are used for the implementation of the SVM classification (Chang and Lin 2011), where the regularization term C that controls norms of model parameters and the Gaussian kernel parameter $\sigma$ of the RBF-based SVM classifier are determined by cross-validation.
