Inspired by the prior research, this chapter presents a deep learning model based on DBN for induction motor fault diagnosis. The deep model is built on restricted Boltzmann machine (RBM) which is the building unit of a DBN and by stacking RBMs one by one, the deep network architecture can be constructed. It can learn high-level features from frequency distribution of measured signals for diagnosis tasks. Including this section, this chapter is organized in five sections. Section 3.2 presents theoretical background of the deep learning algorithm. Section 3.5 summarizes the whole study and gives directions.

## THEORETICAL FRAMEWORK

DBN is a deep architecture with multiple hidden layers that has the capability to learn hierarchical representations automatically in an unsupervised and perform classification at the same time. In order to accurately structure the model, it contains unsupervised pre-training and supervised fine-tuning. Generally, it is difficult to learn a large number of parameters in a deep architecture which has multiple hidden layers due to the vanishing gradient problem. To address this issue, an effective training algorithm, which learns one layer at a time and each pair of layers is seen as one RBM model, proposed which was introduced by Mohamed, Yu, and Deng (2010) and Chen and Lin (2014). As DBN is formed by units of RBM, the basic unit of DBN, i.e., RBM, is introduced first.

## Architecture of RBM

RBM is a commonly used mathematical model in probability statistics and follows the theory of log-linear Markov random field (MRF) (Tran, Al'Thobiani, and Ball (2014)) which has several special forms and is one of them. An RBM model contains two layers: One layer is the input layer which is also called visible layer, and the other layer is the output layer also called hidden layer. RBM can be represented as a bipartite undirected graphical model. All the visible units of the RBM are fully connected to hidden units, units within one layer do not have any connections between each other. That is to say, there are no connection between visible units or between hidden units. The architecture of a RBM is shown in Figure 3.1.

Figure 3.1, $v$ represents the visible layer, $i$ is the $i$-th visible unit, $h$ is the hidden layer, and $j$ is the $j$-th hidden unit. Connections between these two units are undirected. An energy function is proposed to describe the joint configuration $(v, h)$ between them, which is expressed as:

$$E(v,h) = \sum_{i\text{visible}} a_i v_i - \sum_{j\text{hidden}} b_j h_j - \sum_{i,j} v_i h_j w_{ij}. \quad (3.1)$$

Here, $v_i$, and $h_j$ represent the visible unit $i$ and hidden unit $j$, respectively; $a$ and $b_j$ are their biases. $w_{ij}$ denotes the weight between these two units. Therefore, the joint distribution of this pair can be obtained using the energy function where $\theta$ is the model parameter set containing $a, b$, and $w$:

$$p(v,h) = \frac{1}{Z(\theta)} \exp(-E(v,h)), \quad (3.2)$$

$$Z(\theta) = \sum_{v} \sum_{h} \exp(-E(v,h)). \quad (3.3)$$

Due to the particular connections in RBM model, it satisfies conditional independence. Therefore, conditional probability of this pair of layers can be written as:

$$p(h|v) = \prod_i p(h_i|v), \quad (3.4)$$

$$p(v|h) = \prod_j p(v_j|h). \quad (3.5)$$

Mathematically,

$$p(h_j=1|v) = \sigma(b_j + \sum_i v_i w_{ij}), \quad (3.6)$$

$$p(v_i=1|h) = \sigma(a_i + \sum_j h_j w_{ij}), \quad (3.7)$$

where $\sigma(x)$ is the activation function. Generally, $\sigma(x) = 1/(1 + \exp(-x))$ is adopted.

### Training Strategy of RBM

In order to set the model parameters, RBM needs to be trained using training dataset. In the procedure of training an RBM model, the learning rule of stochastic gradient descent is adopted. The log-likelihood probability of the training data is calculated, and its derivative with respect to the weights is seen as the gradient, in Eq. (3.8). The goal of this training procedure is to update network parameters in order to obtain a convergence model.

$$\frac{\partial \log p(v)}{\partial w} = \langle v h \rangle_{data} - \langle v \rangle_{model} \quad (3.8)$$

$$\Delta w_{ij} = \varepsilon(\langle v h \rangle_{data} - \langle v \rangle_{model}) \quad (3.9)$$

where $\varepsilon$ is the learning rate, $\langle v h \rangle_{data}$ is the expectation from the data, while $\langle v \rangle_{model}$ is the expectation from the model.

$$p(v_i=1|h) = \sigma(a_i + \sum_j h_j w_{ij}), \quad (3.7)$$

where $\sigma(x)$ is the activation function. Generally, $\sigma(x) = 1/(1 + \exp(-x))$ is adopted.

### Training Strategy of RBM

In order to set the model parameters, RBM needs to be trained using training dataset. In the procedure of training an RBM model, the learning rule of stochastic gradient descent is adopted. The log-likelihood probability of the training data is calculated, and its derivative with respect to the weights is seen as the gradient, in Eq. (3.8). The goal of this training procedure is to update network parameters in order to obtain a convergence model.

$$\frac{\partial \log p(v)}{\partial w} = \langle v h \rangle_{data} - \langle v \rangle_{model} \quad (3.8)$$

$$\Delta w_{ij} = \varepsilon(\langle v h \rangle_{data} - \langle v \rangle_{model}) \quad (3.9)$$

where $\varepsilon$ is the learning rate, $\langle v h \rangle_{data}$ is the expectation from the data, while $\langle v \rangle_{model}$ is the expectation from the model.

$$\Delta w_{ij} = \varepsilon(\langle v h \rangle_{data} - \langle v \rangle_{model}) \quad (3.10)$$

DBN is a deep architecture with multiple hidden layers that has the capability to learn hierarchical representations automatically in an unsupervised and perform classification at the same time. In order to accurately structure the model, it contains unsupervised pre-training and supervised fine-tuning. Generally, it is difficult to learn a large number of parameters in a deep architecture which has multiple hidden layers due to the vanishing gradient problem. To address this issue, an effective training algorithm, which learns one layer at a time and each pair of layers is seen as one RBM model, proposed which was introduced by Mohamed, Yu, and Deng (2010) and Chen and Lin (2014). As DBN is formed by units of RBM, the basic unit of DBN, i.e., RBM, is introduced first.

RBM is a commonly used mathematical model in probability statistics and follows the theory of log-linear Markov random field (MRF) (Tran, Al'Thobiani, and Ball (2014)) which has several special forms and is one of them. An RBM model contains two layers: One layer is the input layer which is also called visible layer, and the other layer is the output layer also called hidden layer. RBM can be represented as a bipartite undirected graphical model. All the visible units of the RBM are fully connected to hidden units, units within one layer do not have any connections between each other. That is to say, there are no connection between visible units or between hidden units. The architecture of a RBM is shown in Figure 3.1.

$$E(v,h) = \sum_{i\text{visible}} a_i v_i - \sum_{j\text{hidden}} b_j h_j - \sum_{i,j} v_i h_j w_{ij}. \quad (3.1)$$
