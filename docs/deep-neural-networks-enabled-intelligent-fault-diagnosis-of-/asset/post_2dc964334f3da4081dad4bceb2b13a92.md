## Data Description

In this chapter, three diagnostic subtasks of planetary gearbox, including the fault diagnosis of bearing, gear, and bearing-gear mixture, are carried out. The first two tasks can be regarded as the 5-pattern guessing game, and the last one can be deemed a 9-pattern guessing game. Each subtask is carried out in three speed-load operating conditions, i.e. 20_0, 30_2, 40_0. Thus, there are nine diagnostic tasks in single-work conditions. In each operating condition, vibration signals of each state are put into 2000 samples in the way depicted in Figure 10.2, where the first 1000 samples are used to train and the last 1000 samples are used to test, and each sample contains 1280 data points. Thus, the first two tasks have 10,000 samples, and the last task has 18,000 samples.

According to the framework depicted in Figure 10.3, the virtual signal is converted to TF image. As shown in Figure 10.7, a set of TF images of bearing-gear states are set under the condition of a 30_2 speed-load situation. From Figure 10.7, these TF maps can characterize different states of the gearbox to some extent. Then, TF image as the observation in the environment compels the agent to learn a series of recognition policies, thereby completing the above diagnostic tasks.

## Evaluation Indicator and System Configuration

To quantitatively evaluate the diagnostic performance of the proposed approach, we first adopt overall accuracy (OA) to be an evaluation metric. OA denotes the OA for all classes and is defined as:

$$OA = \frac{\sum_{i=1}^M X_{test,correct}^{(i)}}{N} \quad (10.17)$$

where $X_{test,correct}^{(i)}$ is the correctly classified size of the $i$-th category sample and $N$ is the total number of testing samples.

![](img/f29ba72c43f26af4667e705f2_196_1.png)

FIGURE 10.7 TF images of bearing-gear states obtained by STT.

Also, the Kappa coefficient is regarded as a statistic of classification testing (Huang, Nie, and Luo 2019). To further analyze the recognition conformance of the proposed method on each state, the Kappa coefficient (Eugenio and Glass 2004), here $k$, is also used as an evaluation metric in this chapter. It is defined as:

$$k = 1 - \frac{\sum_{i=1}^{M} X_{test,correct}^{(i)} \sum_{i=1}^{M} X_{test,actual}^{(i)} \times X_{test,predicted}^{(i)}}{\sum_{i=1}^{M} (X_{test,actual}^{(i)})^2} \quad (10.18)$$

where $X_{test,actual}^{(i)}$ is the actual number of the $i$-th category sample and $X_{test,predicted}^{(i)}$ is the predicted number of parameters of the model mainly located on C-layer and FC-layer operations, and the number of parameters (Num) (Chen et al. 2021) is related to diagnostic time. Thus, the model's trainable Num is used to measure its complexity.

## Hyper-parameters Effect on Diagnosis Result

### Node Change of FC1 Layer

An appropriate model should have little model complexity as possible while ensuring a certain recognition accuracy. In the designed model described in Figure 10.3, its trainable Num is mainly located in the FC1 layer. The effect of the node number of the FC1 layer on the recognition rate is analyzed. The number of FC1-layer nodes is 32, 64, 128, 256, 512, and 1024, respectively. Besides the above changes, setting is the same as described in Section 10.4.
