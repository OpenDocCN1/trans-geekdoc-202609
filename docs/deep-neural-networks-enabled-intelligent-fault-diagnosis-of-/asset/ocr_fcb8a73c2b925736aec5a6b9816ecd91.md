Most classifiers apply *Softmax* function directly, but sometimes scaling the original vector $v$ with a positive random variable $\sigma$ before *Softmax* would accelerate the convergence of losses, formulated as

```
$p(y|x,\sigma) = \text{Softmax}\left(\frac{1}{\sigma^2}f^w(x)\right) \quad (9.9)$
```

where the variance $\sigma^2$ is a probability parameter in Gibbs distribution, which determines the flatness of the final distribution. The fluctuation of $\sigma$ influences the learning difficulty of each loss and reflects the task-specific uncertainty. Following the principled suppose (Kendall, Gal, and Cipola 2018), we introduce three learnable standard deviations $\sigma_{sup}$, $\sigma_{ins}$ and $\sigma_{tem}$ to control the uncertainty of supervised classification task, inter-relation prediction task and intra-temporal relation prediction task, respectively. Additionally, Loss of each $L(W)$ can be inferred as:

```
$L(W) = -\log p(y=c|x,\sigma)$\
=-\frac{1}{\sigma^2}f^w(x) + \log\sigma\exp\left(\frac{1}{c}f^w(x)\right)$\
\n=-\frac{1}{\sigma^2}\log p(y|f^w(x)) - \log\sum_{c'}\exp\left(\frac{1}{c'}f^{w'}(x)\right)$\
\n=-\frac{1}{\sigma^2}\log p(y|f^w(x)) + \log\sigma \quad (9.10)$
```

where we assume that $(\sum_{c'}\exp(\frac{1}{c'}f^w(x)))^{\sigma^2} = \frac{1}{\sigma}\sum_{c'}\exp(\frac{1}{\sigma^2}f^w(x))$ when $\sigma \to 1$, $f_c^w(x)$ denotes the $c$'th element of $f^w(x)$. According to mean theory, the total conditional probability is equal to the product of the conditional probability of each task:

```
$p(y_{sup}, y_{ins}|f^w(x),\sigma_{sup},\sigma_{ins},\sigma_{tem}) = \prod_{i=sup,ins,tem} p(y_i|f^w(x),\sigma_i) \quad (9.11)$
```

Based on (9.10) and (9.11), the dynamic weighted loss is obtained:

```
$L(W) = \frac{1}{\sigma_{sup}^2}L_{sup}(W) + \frac{1}{\sigma_{ins}^2}L_{ins}(W) + \frac{1}{\sigma_{tem}^2}L_{tem}(W) + \log\sigma_{sup}\sigma_{ins}\sigma_{tem} \quad (9.12)$
```
