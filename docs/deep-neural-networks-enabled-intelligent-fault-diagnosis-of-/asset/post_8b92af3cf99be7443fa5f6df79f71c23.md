this chapter regards the planetary gearbox's fault diagnosis as a guessing game. Also, a game emulator where fault diagnosis is transformed into a sequential decision-making problem is built, thereby realizing it by DRL successfully. The training dataset that is deemed as a guessing repertory is $D_{train} = \{(x_1, l_1), (x_2, l_2), ..., (x_n, l_n)\}$ where $x_i \in X$ is the $i$-th sample and $l_i \in L$ is the $i$-th label corresponding to the sample $x_i$, in each round processes $T$ questions matching training data $D_{train} = \{(x_1, l_1), (x_2, l_2), ..., (x_n, l_n)\}$ that are generated from the training dataset $D_{train}$, and then agent guesses these questions sequentially according to the order of samples in D.

In this game, the agent observes a sample at each time and guesses (classifies) its category. Subsequently, the environment returns an agent immediate reward and the next guessing question (i.e., the next sample), as depicted in Figure 10.1. The game's reward mechanism is defined as that if the agent guesses the category of the sample correctly, a positive reward is awarded; otherwise, a negative reward is given to the agent. The objective of the agent is to maximize accumulated rewards in this game under an optimal behavior policy that is learned from its continual interaction with the environment.

## Classification Markov Decision Process

To play the above guessing game with DRL easily, we define this game in a CMDP framework with the tuple $\{S, A, P, R\}$, and form the fault diagnosis problem as a sequential decision-making problem, where $S, A, P, R$ are the state, action space, transition probability, and reward function, respectively. Considering the overall process of CMDP is shown in Figure 10.1, each element is described as follows in detail.

### State Space S

S consists of all guessing questions in the environment and is determined by training samples. When an episode begins, the agent receives the first sample $x_i \in X$ as its initial state $s_i \in S$. Similarly, the state $s_i$ of the environment at each time step matches the sample $x_i$. After that, when a new episode begins, the environment shuffles the order of samples in $D_{train}$ and generates $T$ samples forming ordinal training data $D$.

### Space A

A contains all types of recognition action, and $A a_i \in A$ corresponds to a fault label $l_i \in L$. Based on it, A is set to $A=\{0,1,2,...,K-1\}$, where $K$ is the total health status of the planetary gearbox.

### Transition P

$P: S \times A \rightarrow S$ is the transition model. In this guessing game, state transition probability $p(s_{i+1}|s_i, a_i)$ in CMDP is deterministic. After guessing the current question (sample $x_i$) relating to the state $s_i$, the agent will receive the next question (the next sample $x_{i+1}$) matching the next state $s_{i+1} \in S$ according to the order of samples in $D$. After that all samples in $D$ are guessed sequentially one round game is terminated.

### Reward R

$R: S \times A \rightarrow R$ denotes a reward $r_i$, obtained by the agent for executing action at the state $s_i$. The reward function is used to evaluate the success or failure of the agent's actions, guiding the agent to learn the policy $\pi_i$ so that it can make relevant actions in given states. In this work, when the agent correctly recognizes a sample $x_i$, a positive reward is received from the environment, the other agent obtains a negative reward. Thus, the reward function is designed as:

$R(s_i, a_i, l_i) = \begin{cases} 1, & \text{if } a_i = l_i \\ -1, & \text{otherwise} \end{cases} \quad (10.1)$

Based on the definitions, the fault diagnosis problem is formally formulated as a sequential decision-making problem in CMDP, and the objective is to find an optimal recognition policy $\pi_i: S \rightarrow A$ to maximize accumulated rewards in CMDP. Thus it can be solved by DRL. Vibration in signal operation often offers strong noise and nonlinearity because of poor working conditions, which leads to low recognition accuracy if the raw signal is used as the state input directly.

## METHODOLOGY

This section is going to introduce the preliminary knowledge of synchro-extracting transform (SET) and DQN, which are utilized in the proposed method based on time-frequency representation (TFR) and DRL.

## Synchro-Extracting Transform

SET as a post-processing step of STFT, only extracts the TF coefficients at the instantaneous frequency (IF) positions to obtain TF maps with more concentrated energy and clear IF curve, thereby enhancing the robustness. Moreover, it outperforms the reassignment method, synchroqueezing transform (SST), etc., and has low time complexity. Thus, SET is a powerful tool for characterizing inherent features of time-varying signal in the time domain and frequency domain. This work utilizes SET to transform one-dimensional (1D) fault signals into 2D TF maps suitable for deep neural network (DCNN) and improve diagnostic accuracy, especially for harsh working conditions. SET comprises the following steps:

For a signal $x(u)$, its regular STFT is defined as

$G_x(\tau,w) = \int_{-\infty}^{+\infty} x(u) g(u-\tau) e^{-iw\tau} du \quad (10.2)$

$g(u-\tau)$ indicates a window function (WF) with center at $\tau$, $w$ is the frequency, $u$ and $\tau$ denote time parameter. Considering phase shift $e^{iw\tau}$, Eq. (10.2) is rewritten as:

$G_x(\tau,w) = \int_{-\infty}^{+\infty} x(u) g(u-\tau) e^{-iw(u-\tau)} du \quad (10.3)$

According to the derivative of $G_x(\tau,w)$, the intrinsic IF $v_G(\tau,w)$ at each TF position be obtained:

$v_G(\tau,w) = \frac{\partial}{\partial\tau} \text{arg}(G_x(\tau,w)) = G_x^{-1}(\tau,w) \cdot G_x'(\tau,w) \quad (10.4)$

where $g'$ is the derivative of WF $g(u-\tau)$ regarding time. A new TF plane reconstructed by TF coefficients of $G_x(\tau,w)$ at IF positions is expressed as:

$SET_r(\tau,w) = G_r(\tau,w) \cdot \delta(w-v_G(\tau,w)) \quad (10.5)$

where $SET_r(\tau,w)$ are TF results of SET, $\delta(\cdot)$ is the Dirac function, and $\delta(w-v_G(\tau,w))$ denotes the synchro-extracting operator (SEO). Considering that SEO's real part is utilized in practice, $SEO(\tau,w)$ is rewritten as:

$SEO(\tau,w) = \begin{cases} 1, & \text{Re}[G_r^{-1}(\tau,w) \cdot G_r'(\tau,w)] < \Delta w/2 \\ 0, & \text{otherwise} \end{cases} \quad (10.6)$

where $\Delta w$ is frequency interval and it can adjust the SET's frequency resolution, $Re(\cdot)$ indicates taking the real part. In this chapter, $\Delta w$ is set to 1, and $g(u-\tau)$ is a Gaussian WF with a window length of 128. After the above set, the 1D time-domain signal is converted to 2D TFR, which will be used as the input of the subsequent model.

## Deep Neural Networks-Enabled Intelligent Fault Diagnosis of Mechanical Systems

Deep Q Network

Deep Q network (DQN), as a representative achievement of DRL, has achieved salient performance in practice when playing Atari games. It mainly integrates deep neural network (DNN) with Q-learning algorithm for autonomously learning the behavior policy $\pi_\theta$ by interaction with the environment, which maps a given state $s\in S$ to an action $a\in A$ such that $a=\pi_\theta(s)$. In the interactive process, the agent is to maximize the accumulated reward $R_t$ at time $t$, which is discounted by a factor of $\gamma$ per time-step and defined as:

$R_t = \sum_{t'=t}^{T}\gamma^{t'-t}r_{t'}$

where $T$ indicates the terminated time step, $\gamma$ is the discount factor. The smaller the value of $\gamma$ is, the more the agent focuses on the current reward.

For the Q-learning algorithm, its action-value function $Q^\pi(s,a)$ under the policy $\pi$ is defined as

$Q^*(s,a)=\mathbb{E}_\pi[R_t|s=s,a_t=a;\pi]$

where $\mathbb{E}_\pi$ is the expected return under the policy $\pi$. The temporal-difference updating of Q-learning is expressed by:

$Q(s,a)\leftarrow Q(s,a)+\alpha(r+\gamma\max_{a'}Q(s',a')-Q(s,a))$

where $Q(s,a)$ indicates the action-value function and $\alpha$ is the learning rate. The optimal action-value function $Q^*(s,a)=\max_\pi Q^*(s,a)$ obeys the Bellman equation and is written as:

$Q^*(s,a)=\mathbb{E}[r+\gamma\max_{a'}Q^*(s',a')|s,a]$

In DQN, DNN is used to approximate the action-value function $Q^*(s,a)$ in the policy $\pi$

$Q(s,a;\theta)=Q^*(s,a)$

where $\theta$ is the parameters of the DNN model.

In the process of the agent's interaction with the environment, $\epsilon$-greedy algorithm is used to balance "exploration" (random action $a\in A$) and "exploitation" (action $a$ with $arg\max_aQ(s,a;\theta)$) and generate a series of experiences defined as $e=(s,r,s')$. These experience samples are stored in ER buffer $B$. Then, ER is utilized to sample experience samples from the ER buffer randomly, thereby updating the DNN model.
