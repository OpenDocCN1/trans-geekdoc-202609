The training algorithm of a neural network is designed to adjust the weights of the neurons to their optimum, in order to achieve the best performance for the network.

Assuming $a_0, a_2$ and $a_1$ are inputs, $w_1, w_2, w_3$ and $b$ represent weights, $z$ is the linear combination of inputs and weights, and $a_{out}$ is the result of $z$ after being activated by the function $g()$.

It can be expressed in formula: $z = a_1w_1 + a_2w_2 + a_3w_3 + b$, $\hat{y} = a_{out} = sigmoid(z) = \frac{1}{1+e^{-z}}$

The function $g()$ is here known as an activation function, which is a nonlinear function. Its purpose is to introduce nonlinearity to the output of the neuron. Since real-world data is inherently nonlinear, we use neurons to be learn these neural representations. Here are commonly used activation functions:

+   - Sigmoid: The output range is [0,1]. It has a S-shaped curve and maps inputs outputs to the range of 0 to 1. As the input becomes extremely positive or negative, the output approaches the corresponding bounds (0 or 1).

```
$\sigma(x) = \frac{1}{1+e^{-x}}$
```

+   - tanh: The output range is [-1,1]. The tanh function is similar to the sigmoid function but maps inputs to outputs in the range of -1 to 1. It has an S-shaped curve like the sigmoid function, but the center is at 0.

```
$	anh(x) = \frac{e^x-e^{-x}}{e^x+e^{-x}} = 2\sigma(2x)-1$
```
