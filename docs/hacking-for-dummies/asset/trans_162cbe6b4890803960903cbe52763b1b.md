
![remember](images/remember.png)虽然后续版本的 Windows 比其前身更安全，但不要误以为 Windows 环境万无一失。我无法告诉你有多少次在 Windows 环境中，看似安全的 Windows 安装被修改以满足某个应用程序或业务需求，而这些需求本身却便利了攻击者。

### Mapping

针对每一台 Windows 计算机，按照以下步骤进行 null session 的映射：

1. **格式化基本的 `net` 命令，例如：**  

    `net use \\host_name_or_IP_address\ipc$ "" "/user:"`

    映射 null session 的 `net` 命令需要以下参数：

    *   `net`（Windows 内置的 *network* 命令）后跟 `use` 选项。

    *   目标系统的 IP 地址或主机名。

    *   空白密码和用户名。

    ![technicalstuff](images/technicalstuff.png)空白是 *null* 连接之所以得名的原因。

2. **按回车键建立连接。**

    [Figure 12-6](#c12.xhtml#c12-fig-0006) 显示了完整命令的示例，用于映射 null session。映射完成后，应看到 `The command completed successfully` 的提示信息。

![ FIGURE 12-6:  Mapping a null session to a vulnerable Windows system](images/9781119485476-fg1206.png)

 [FIGURE 12-6:](#c12.xhtml#rc12-fig-0006)  Mapping a null session to a vulnerable Windows system

![tip](images/tip.png)为确认会话已映射，请在命令行中输入：

`net use`

如 [Figure 12-6](#c12.xhtml#c12-fig-0006) 所示，你会在每个已连接的计算机上看到指向 IPC$ 共享的映射。

### 获取信息

通过 null‑session 连接，你可以使用其他实用工具远程获取关键的 Windows 信息。数十种工具可以完成此类信息的枚举。

像黑客一样，你可以将这些枚举程序的输出用于（作为未授权用户）尝试以下操作：

*   破解你发现的用户密码。（详见 [第 8 章](#c08.xhtml)）

*   映射到每台计算机的网络共享驱动器。

下面列出的应用程序可用于对 Windows 服务器版本早于 Server 2003 以及 Windows XP 的系统进行枚举。别笑——我仍然看到这些古老版本的 Windows 在运行。

#### net view

`net view` 命令（见 [Figure 12-7](#c12.xhtml#c12-fig-0007)）显示 Windows 主机上可用的共享。你可以利用该程序的输出，查看服务器向外部广告的信息以及可利用的内容，包括：

*   攻击者可以利用的共享信息，如映射驱动器和共享密码破解。

*   可能需要移除的共享权限，例如在老式 Windows 2000 系统中，Everyone 组的读取权限，以便至少能够查看共享。

![ FIGURE 12-7:  net view displays drive shares on a remote Windows host.](images/9781119485476-fg1207.png)

### 防御 null‑session 黑客

![tip](images/tip.png)如果在业务上合理且时机合适，升级到更安全的 Windows Server 2016、Windows Server 2019、Windows 8.1 或 Windows 10，这些版本不存在文中所述的漏洞。

你可以通过实施以下安全措施轻易防止 null‑session 连接攻击：

*   在 Windows 服务器上阻止 NetBIOS，方法是阻止以下 TCP 端口通过网络防火墙或个人防火墙通行：

    *   139（NetBIOS 会话服务）

    *   445（直接在 TCP/IP 上运行 SMB，无需 NetBIOS）

*   对不需要的系统，在网络连接属性的“共享”选项卡中禁用“文件和打印共享 for Microsoft Networks”。

*   限制匿名连接。如果你仍在环境中保留 Windows NT 或 Windows 2000 系统（希望没有），可以将 `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\LSA\RestrictAnonymous` 设置为下列 DWORD 值之一：

    *   *None*：默认设置。

    *   *Rely on Default Permissions (Setting 0)*：允许默认的 null‑session 连接。

    *   *Do Not Allow Enumeration of SAM Accounts and Shares (Setting 1)*：中等安全级别，仍允许映射到 IPC$，从而让诸如 Walksam 之类的工具获取系统信息。

    *   *No Access without Explicit Anonymous Permissions (Setting 2)*：高安全级别，阻止 null‑session 连接并禁止系统枚举。

    ![warning](images/warning.png)Setting 2（No Access without Explicit Anonymous Permissions）可能会影响域控制器通信和网络浏览，使用时需谨慎，以免导致网络功能受损。

对于较新版本的 Windows，从 Windows Server 2008 R2 及 Windows 7 开始，请确保本地或组安全策略中的“网络访问匿名组件”设置如 [Figure 12-8](#c12.xhtml#c12-fig-0008) 所示配置。
