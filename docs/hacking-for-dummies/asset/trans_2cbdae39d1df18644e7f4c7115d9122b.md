## Scanning, Poking, and Prodding the Network

在下面的章节中描述的安全测试需要在您的网络基础设施上执行，基本的黑客步骤如下：

1.  **收集信息并映射您的网络。**

2.  **扫描系统，查看哪些系统是可用的。**

3.  **确定您发现的系统上运行的服务。**

4.  **尝试渗透您发现的系统（如果您选择这么做）。**

![tip](images/tip.png)每种网络卡驱动以及大多数操作系统（包括 Windows、Linux，甚至您的防火墙和路由器）实现的 TCP/IP 都有其特有的 quirks，导致扫描、探测和敲击系统时表现不同。这些不同的表现会导致系统返回的各种响应，从伪正（false-positive）到拒绝服务（DoS）条件不等。请参阅管理员指南或供应商网站，获取已知问题及相应补丁的详细信息。如果您已经为所有系统打补丁，理论上不应出现问题；但切记，任何情况皆有可能。

### Scanning ports

一个 *port scanner* 通过扫描网络，查看哪些主机和服务正在运行，从而展示网络的状态。端口扫描仪提供基本的网络布局视图，帮助您发现未授权的主机或应用，以及可能导致严重安全漏洞的主机配置错误。

端口扫描的宏观视图常常会暴露那些可能被忽视的安全问题。端口扫描仪易于使用，可在任何操作系统和应用上对目标主机进行测试。您通常可以快速完成测试，而无需直接触碰每个网络主机（这将是一件非常麻烦的事）。

评估整体网络安全的关键在于解读端口扫描结果。例如，您可能会出现开放端口的假阳性，需要进一步深入检查。User Datagram Protocol（UDP）扫描，与 UDP 本身一样，可靠性低于 Transmission Control Protocol（TCP）扫描，经常产生假阳性，因为许多应用程序不知道如何响应随机的 UDP 请求。

像 Nexpose 这样功能丰富的扫描器可以在一步内识别端口并显示其运行的服务。

![warning](images/warning.png)端口扫描的运行时间取决于目标主机数量、扫描端口数量、所用工具、测试系统的处理能力以及网络链路的速度。

![remember](images/remember.png)一个重要的原则是：不要只扫描重要主机，要“遍历每一块石头”——即使第一次没有发现，也要持之以恒。其他系统如果被忽略，往往会在以后给您造成麻烦。此外，使用不同的工具重复执行相同的测试，看看结果是否一致。并非所有工具都能发现相同的开放端口和漏洞，这虽然令人遗憾，却是漏洞和渗透测试的现实。

如果您使用不同工具运行测试后结果不一致，可能需要进一步调查。如果出现异常，例如一组奇怪的开放端口，那很可能不是误报，需要再次确认；若有疑虑，请使用另一工具从不同角度观察。

![tip](images/tip.png)如果可能，建议为您发现的每个网络主机扫描全部 65,534 个 TCP 端口。如果发现可疑端口，请查找该应用的文档，确认其为已知且受许可的。扫描全部 65,534 个 UDP 端口也不失为明智之举。请注意，这一过程可能会显著增加扫描时间。
