
如果你的服务器不需要运行特定的电子邮件服务（SMTP、POP3 和 IMAP），请立即禁用它们。

对于基于 Web 的电子邮件服务，例如 Microsoft 的 Outlook Web Access（OWA），请通过本书中提到的测试技术和硬化资源，正确测试并保护你的 Web 服务器应用程序和操作系统。

强制使用强密码。对于独立账户以及域级 Exchange 或类似账户，网络中的任何密码弱点都会传递到电子邮件，并被通过 Outlook Web Access 或 POP3 利用。我在 [第 8 章](#c08.xhtml) 中介绍了密码破解。

请确保在你的漏洞扫描和渗透测试中包含邮件服务器。

如果你运行的是 sendmail（尤其是旧版本），请不要使用它。考虑改用安全的替代方案，例如 Postfix（[www.postfix.org](http://www.postfix.org)）或 qmail（[www.qmail.org](http://www.qmail.org)）。

## 了解 VoIP

当今企业中广泛使用的技术是 Voice over Internet Protocol（VoIP）。内部 VoIP 系统、远程用户系统、VoIP 服务器、软电话以及相关组件都有各自的安全漏洞。与大多数安全相关事务一样，许多人并未考虑到 voice conversations 通过网络或 Internet 传输时的安全问题，但这些问题必须列入你的视野。别担心——这还来得及纠正。只要记住，即使已有防护措施，VoIP 系统仍需在你的整体安全测试策略中持续纳入。

### VoIP 漏洞

正如任何技术或网络协议集合一样，坏人总会找到办法进入系统。VoIP 也不例外。事实上，考虑到电话通话和系统可用性的重要性，你损失的潜在风险更大。

VoIP 相关系统的安全性与其他常见计算机系统并无明显差异。原因在于：VoIP 系统拥有自己的操作系统，拥有 IP 地址，并且可在网络中访问。更糟的是，许多 VoIP 系统包含更多“智能”（即更多可能出错的内容），这使得 VoIP 网络更容易被攻击。

![tip](images/tip.png)如果你想了解 VoIP 的工作原理，这将有助于你发现漏洞，请参考 *VoIP For Dummies*，作者 Timothy V. Kelly（John Wiley & Sons, Inc.）。

一方面，VoIP 系统的漏洞与本书其他系统相似，包括默认设置、缺失补丁和弱密码。因此，使用本文中介绍的标准漏洞扫描工具至关重要。[图 14-12](#c14.xhtml#c14-fig-0012) 展示了 VoIP 适配器 Web 界面认证机制的多种漏洞。

![ FIGURE 14-12:  A WebInspect scan of a VoIP network adapter showing several weaknesses.](images/9781119485476-fg1412.png)

[FIGURE 14-12:](#c14.xhtml#rc14-fig-0012)  A WebInspect scan of a VoIP network adapter showing several weaknesses.

观察这些结果，你可能会认为该设备是基础的 Web 服务器。这正是我的要点：VoIP 系统不过是网络化的计算机系统，拥有可被利用的漏洞。

另一方面，两大与 VoIP 相关的安全弱点：

*   **电话服务中断**：是的，VoIP 易受 DoS 攻击，和任何其他系统或应用一样。由于人们对音质的容忍度极低（手机除外），VoIP 与时敏感型应用一样脆弱。

*   **缺乏加密**：VoIP 的另一大弱点是通话通常不加密，导致可被拦截和录制。想象一下，坏人可以录下对话并进行勒索。这种攻击在未保护的无线网络上极易实施，但如我在即将到来的章节“[捕获和录制声音流量](#c14.xhtml#c14-sec-0034)”中所示，有线网络同样容易受到影响。

![warning](images/warning.png)如果 VoIP 网络未通过网络分段（如 VLAN）进行保护，声音网络将特别容易窃听、DoS 及其他攻击。但 VLAN 防线在许多环境中可被称为 VoIP Hopper（[http://voiphopper.sourceforge.net](http://voiphopper.sourceforge.net)）所突破。当你以为声音系统已安全时，这类工具会出现，它们虽旧，但仍可用于此类测试。

与常规计算机安全漏洞不同，VoIP 问题并非仅靠简单的软件补丁即可解决。它们根植于 Session Initiation Protocol（SIP）和 Real-Time Transport Protocol（RTP），VoIP 用于通信的两种协议。下面的章节将介绍两项专注于 VoIP 的测试方法，帮助你评估声音系统的安全性。

![tip](images/tip.png)需要注意的是，尽管 SIP 是最常用的 VoIP 协议，H.323 也存在，因此如果使用的是 H.323，请不要浪费时间测试 SIP 漏洞。请参阅 [www.packetizer.comi/ipmc/h323_vs_sip](http://www.packetizer.comi/ipmc/h323_vs_sip) 获取 H.323 与 SIP 的详细对比。

#### 漏洞扫描

除基本的网络、操作系统和 Web 应用漏洞外，使用合适的工具可以发现 VoIP 问题。好消息是，你很可能已经拥有这些工具——网络漏洞扫描仪如 Nexpose（[https://www.rapid7.com/products/nexpose](https://www.rapid7.com/products/nexpose)），以及 Web 漏洞扫描仪如 Netsparker（[https://www.netsparker.com](https://www.netsparker.com)）。VoIP 呼叫管理器和电话中常见的弱密码、跨站脚本以及未打补丁的漏洞，可利用 Metasploit 等工具进行利用。

![tip](images/tip.png)Kali Linux 内置了多种 VoIP 工具，位于 Applications/Vulnerability Analysis/VoIP Tools。其他免费的 SIP 流量分析工具包括 PROTOS（[www.ee.oulu.fi/research/ouspg/protos/testing/c07/sip/index.html](http://www.ee.oulu.fi/research/ouspg/protos/testing/c07/sip/index.html)）和 sipsak（[https://www.voip-info.org/wiki/view/Sipsak](https://www.voip-info.org/wiki/view/Sipsak)）。一个汇总了大量 VoIP 相关工具的网站是 [www.voipsa.org/Resources/tools.php](http://www.voipsa.org/Resources/tools.php)。

#### 捕获和录制声音流量

如果你能访问有线或无线网络，轻松捕获 VoIP 对话，这能有效证明网络及 VoIP 部署的漏洞。

2. **点击带有核废料标志的 Start/Stop APR 图标。** ARP poison routing 过程开始并启用内置嗅探器。

3. **点击蓝色加号（+）图标，添加用于 ARP 中毒的主机。**
