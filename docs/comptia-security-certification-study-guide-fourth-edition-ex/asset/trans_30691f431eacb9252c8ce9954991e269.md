

### 电子邮件和 Web
如果您在线收集敏感信息，请务必使用 `HTTPS` 而不是 `HTTP`。对于需要加密电子邮件的组织，可以使用 `S/MIME` 进行电子邮件加密。

### 文件传输
通过互联网下载文件时，您需要加密通信以维护机密性——请务必使用 `SFTP` 或 `SCP` 来保护您的文件传输通信。

### 目录服务
访问目录服务（如 `Active Directory`）时，请使用 `LDAPS` 加密客户端与服务器之间的通信。

### 远程访问
当您需要授予用户对网络的远程访问权限时，请寻找用于远程访问的 `VPN` 解决方案，并使用 `SSTP` 或 `L2TP` 等协议来加密 `VPN` 流量。

### 域名解析
在保护 `DNS` 环境方面，请考虑使用 `DNSSEC` 为其增加完整性。如今，黑客入侵您的 `DNS` 环境，然后更改 `DNS` 记录使其指向黑客的系统，这种情况很常见。`DNSSEC` 可以为您的 `DNS` 记录增加完整性。

### 路由和交换
对于您的路由器和交换机，请使用 `SSH` 代替 `Telnet` 进行远程访问；如果您打算在设备上运行 `SNMP`，请使用 `SNMPv3`，因为它是最安全的 `SNMP` 版本。

### 网络地址分配
您可以配置设备在网络上分配 `IP` 地址。请务必仅分配所需数量的地址。

### 订阅服务
许多设备都提供可订阅的服务以增强安全性。例如，您可能可以订阅防病毒服务或 `DDoS` 防护服务。

### 密码套件和完美前向保密

近年来，出现了许多有助于提高安全性并防止针对加密技术攻击的技术。加密技术的一个弱点是使用相同的密钥加密通信；一旦黑客知道了密钥，他们就能破解所有消息。以下安全概念是 `Security+` 考试目标中的新内容，您应该熟悉这些术语：

#### 临时密钥
一种临时密钥，通常用于加密通信中的单条消息，而不是使用同一个密钥加密通信中的所有消息。

#### 完美前向保密
用于描述一种为每个会话生成随机公钥（临时密钥）的系统，以便在通信过程中进行密钥交换。

#### 密钥延伸
也称为密钥强化，这是一种用于确保弱密钥（如密码）不成为暴力攻击受害者的技术。通过密钥延伸，使用特殊算法将弱密码转换为更强的密钥。用于强化密钥的两种常见算法是 `PBKDF2` 和 `Bcrypt`。

*密码套件* 是一组安全算法，用于提供身份验证、加密和消息认证码功能。密码套件用于在 `SSL` 和 `TLS` 通信中协商安全设置。

密码套件中可使用许多不同的算法，按其功能分组如下：

- 密钥交换算法，如 `RSA`、`Diffie-Hellman` 和 `ECDH`
- 身份验证算法，如 `RSA`、`DSA` 和 `ECDSA`
- 加密算法，如 `RC4`、`3DES` 和 `AES`
- 消息认证算法，如 `MD5` 或 `SHA`

请注意，`TLS` 使用的两种密钥协商协议是 `Diffie-Hellman Ephemeral (DHE)` 和 `Elliptic Curve Diffie-Hellman Ephemeral (ECDHE)`。`DHE` 和 `ECDHE` 均旨在为 `TLS` 通信提供完美前向保密。此外，请注意某些密码比其他密码更强，您可以通过所用协议和密钥的位长度来判断。例如，`DES` 是 56 位加密，而 `AES` 是 128 位、256 位或 512 位加密——这意味着 `AES` 比较弱的 `DES` 是更强的密码。

值得注意的是，`Diffie-Hellman (DH)` 使用称为 `DH Groups` 的组来定义密钥交换通信的密钥强度。组号越高越安全，但资源消耗也越大。以下列表列出了部分 `DH Groups`：

- **DH Group 1** 768-bit
- **DH Group 2** 1024-bit
- **DH Group 14** 2048-bit

许多不同的网络设备，如 `WatchGuard` 防火墙和 `Cisco` 设备，允许您指定应使用的 `DH Group`。

### 使用 VPN 保护通信

当公司决定希望通过互联网传输机密信息时，会寻求虚拟专用网络 (`VPN`) 解决方案。`VPN` 旨在在不受信任的网络（如互联网）上建立一条安全（加密）的隧道，用于加密穿越该不受信任网络的流量。

以下是用于保护 `VPN` 流量的三种常见协议：

#### 点对点隧道协议 (PPTP)
`PPTP` 是一种较旧的 `VPN` 协议，用于加密 `PPP` 流量，在 Microsoft 环境中很常见。`PPTP` 使用通用路由封装 (`GRE`) 协议传输 `PPP` 数据包，但使用 Microsoft 点对点加密 (`MPPE`) 协议加密流量。要允许 `PPTP` 流量通过防火墙，您需要在防火墙上打开 `TCP` 端口 `1723`（控制端口）和协议 ID `47`（承载数据）。

#### 第 2 层隧道协议 (L2TP)
`L2TP` 是一种较新的 `VPN` 协议，使用更安全的 `IPSec` 进行流量加密，而不是 `MPPE`。要允许 `L2TP` 流量通过防火墙，您需要在防火墙上打开 `UDP` 端口 `500`（用于密钥交换）、`UDP` 端口 `5500`（用于 `IPSec NAT`）和 `UDP` 端口 `1701`。

#### 安全套接字传输协议 (SSTP)
`SSTP` 是这三种 `VPN` 协议中最新的一种，使用 `SSL` 加密 `VPN` 流量。使用 `SSL` 的 `VPN` 协议的优势在于防火墙上的配置较少；您无需在防火墙上打开端口以允许 `PPTP` 或 `L2TP` 通信，只需在防火墙上打开端口 `443`（`HTTPS` 使用的端口），而这通常已经完成。

### 使用 PGP

一种常用于使用非对称通信加密信息的应用程序是 Pretty Good Privacy (`PGP`)。`PGP` 允许您生成密钥，并通过电子邮件以安全的方式与他人共享您的公钥。

`PGP` 允许您加密电子邮件消息和文件，以及对消息进行数字签名，以便收件人确信消息来自您。

请注意，虽然 `PGP` 已在 `Windows` 平台上使用，但 `GNU` 系统有一个替代品，称为 GNU Privacy Guard (`GnuPG`)，简称 `GPG`。

### 理解隐写术

*隐写术* 是一种加密概念，涉及将数据隐藏在其他文件中，如图形文件、音频文件或视频文件中。例如，隐写术应用程序可用于修改图形文件并在其中隐藏文本文档。`Windows` 版 `JPHS` 就是一个例子，如 [图 12-7](#ch12.xhtml#ch12fig7) 所示。
