

## 中间人攻击

一种非常重要的网络攻击类型是中间人攻击，也称为中间人攻击。在中间人攻击中，黑客将自己插入到两个正在通信的系统之间。如[图 4-6](#ch04.xhtml#ch4fig6)所示，黑客将自己置于两个通信方之间后，便在两者之间来回传递信息。例如，当用户 1 向用户 2 发送数据时，信息实际上首先发送给黑客，然后由黑客转发给用户 2。

**图 4-6**

中间人攻击的一种变体是*浏览器中间人攻击*，此时浏览器包含一个特洛伊木马，该木马通过加载加载项或在浏览器内执行脚本被植入。此时，该特洛伊木马可以拦截用户输入到浏览器中的任何数据，并在将其发送到目标服务器之前对其进行篡改。MITB 特洛伊木马的例子包括 Zeus 和 SpyEye。

## 第 2 层攻击

有许多不同类型的第 2 层网络攻击会影响第 2 层网络设备（如交换机），或第 2 层组件和协议（如 MAC 地址和 ARP）。

### ARP 投毒

根据[第 1 章](#ch01.xhtml#ch1)的内容，ARP 是一种将 IP 地址转换为 MAC 地址，然后将 IP 和对应的 MAC 地址存储在系统内存中的协议。这块内存区域称为 ARP 缓存（参见[图 4-7](#ch04.xhtml#ch4fig7)）。

![Image](f0154-01.jpg)

**图 4-7**  
查看系统上的 ARP 缓存

ARP 投毒涉及黑客篡改一台或一组系统上的 ARP 缓存，使所有系统在 ARP 缓存中为特定 IP 地址（可能是默认网关的地址）存储了错误的 MAC 地址。通常，黑客会投毒 ARP 缓存，使默认网关 IP 地址（您路由器的 IP 地址）指向黑客的 MAC 地址。这将确保每当系统尝试向路由器发送数据时，它会从本地 ARP 缓存中检索黑客的 MAC 地址，然后将数据发送到黑客的系统，而不是路由器。这就是黑客通常在有线网络或无线网络上执行 MITM 攻击的方式。这还允许黑客捕获所有网络流量，即使在交换环境中也是如此。黑客只需在其系统上启用路由功能，以便所有数据随后传递给路由器并流向互联网，同时黑客已捕获每一条流向互联网的数据。

### MAC 泛洪

MAC 泛洪是指攻击者向交换机发送大量帧，导致其填满 MAC 地址表，并因此移除旧的有效 MAC 地址，但添加新的伪造 MAC 地址。这将导致交换机将来自网络上有效系统的所有帧进行泛洪。泛洪的帧会发送到交换机的每个端口，从而允许攻击者捕获并查看它们。

### MAC 克隆

MAC 克隆是指攻击者复制另一台系统的 MAC 地址并将其用于网络通信。这可用于绕过访问控制列表，其中仅允许来自特定 MAC 地址的流量进入网络。

## 域名系统攻击

域名系统 (DNS) 是一种名称解析技术，可将完全限定域名（如 `www.gleneclarke.com`）转换为 IP 地址。DNS 对网络通信至关重要，因为客户端使用系统的 DNS 名称，而在后台它会被转换为该系统的 IP 地址，客户端随后与该 IP 地址通信。让我们来看看针对 DNS 的一些攻击。

### DNS 投毒

在计算机中，投毒是指某人进入一个环境并故意在其中放置不正确的设置，以破坏该环境。您需要为 Security+ 认证考试熟悉的两个常见投毒示例是 DNS 投毒和 ARP 投毒。

DNS 投毒是指黑客攻破 DNS 服务器，并通过让 DNS 名称指向不正确的 IP 地址来投毒 DNS 条目。通常，黑客会修改 DNS 记录使其指向黑客的系统；这将强制该 DNS 名称的所有流量流向黑客的系统。

DNS 投毒也是篡改位于公司本地 DNS 服务器上的 DNS 缓存。DNS 缓存存储员工已访问过的网站名称及这些网站的 IP 地址（参见[图 4-8](#ch04.xhtml#ch4fig8)）。缓存位于您的 DNS 服务器上，以便当另一位员工浏览同一网站时，DNS 服务器已经有该网站的 IP 地址，无需将查询转发到互联网。您本地办公室的 DNS 服务器只需将存储在 DNS 缓存中的 IP 地址发送给客户端。黑客有可能投毒 DNS 缓存，导致您的用户被发送到错误的网站。

![Image](f0155-01.jpg)

**图 4-8**  
查看 DNS 服务器上的 DNS 缓存

黑客将您引导至错误网站的另一种常用技术是修改驻留在每个系统上的 hosts 文件。hosts 文件用于将域名解析为 IP 地址，如果在本地 hosts 文件中找到条目，则系统将不会查询 DNS。*域名劫持* 是指通过修改 DNS 或 hosts 文件将某人引导至错误网站的术语。

### 考试内幕

#### 你的系统上没有任何有价值的东西？

在课堂上与学生讨论安全性时，我通常会讨论保护家庭网络和家用计算机的重要性。我通常会得到一名学生的回应：“我的系统上没有任何有价值的东西，所以如果黑客想浪费时间攻击我的系统，那就随他们去吧！”

问题在于，即使您的系统上没有任何有价值的东西（例如信用卡号），黑客仍然可以更改您的系统设置，诱使您泄露私人信息。例如，黑客可以修改您系统上的 hosts 文件，以便当您输入银行网站地址时，您会被引导至黑客制作的假冒银行网站。当您输入帐号和密码时，黑客会将信息记录到数据库中——后果不堪设想！

对于 Security+ 考试，请记住黑客可以通过投毒 DNS 缓存或在攻破系统后修改 hosts 文件，将您引导至错误的网站。这被称为域名劫持！
