### 基于云与本地部署的漏洞

本章包含的漏洞大多是考虑到本地部署网络进行讨论的，这意味着这些是你会在局域网内的系统和设备上发现的漏洞。

许多常见漏洞也可能存在于云环境中，其中大多数与配置错误有关：

- **开放端口** 确保不要在云资源（如虚拟机 (VM) 或应用程序）上打开不必要的端口。例如，许多 IT 管理员会创建一个 Azure VM，然后打开远程桌面协议 (RDP) 端口以远程连接到该 VM。在这种情况下，Azure 提供了堡垒主机选项，因此你无需在每个 VM 上打开 RDP 端口。

- **身份验证方法** 由于云应用程序可从世界任何地方访问，你应该配置多因素身份验证 (MFA)，以便当你或其他人尝试使用你的帐户登录时，会向你的手机发送一个需要输入以进行身份验证的身份验证代码。

- **条件访问策略** 你可以使用条件访问策略来帮助提高安全性，并保护资源免受弱密码或弱身份验证的侵害。条件访问策略允许你在用户访问云资源时实施限制。例如，你可以让策略应用于用户、组、设备，甚至他们的 IP 位置。

- **权限过多** 留意用户在云环境中被授予过多权限的情况（例如，将不必要的用户添加到全局管理员组）。

### 识别物理威胁

在深入探讨不同类型的恶意软件之前，我想让你熟悉一下企业在现实世界中遇到的一些常见物理威胁。在本节中，我将讨论一些针对系统和设备的常见物理威胁类型，并讨论如何将针对公司资产的威胁降至最低。

#### 窥探

在[第 4 章](#ch04.xhtml#ch4)中，你了解了垃圾箱搜寻的概念，这涉及黑客翻阅你的垃圾并拿走可能有助于攻击的机密文件。黑客不仅可能对你的企业进行垃圾箱搜寻，你的员工也可能窥探他人桌面上的文件，甚至翻阅他们的文件柜查看与他们无关的文档。

为防止此类窥探攻击导致信息泄露，请务必在企业内实施清洁桌面政策。`clean desk policy` 规定敏感文件不得随意摆放在外，不用时必须归档保存。

你还必须保护存放在文件柜中的信息，确保文件柜位于安全区域并上锁，以防止未经授权的人员访问信息。

![Image](exam.jpg)

**你应该知道，所有文件在处置前都应粉碎，以防止窥探或垃圾箱搜寻。**

教育企业中的所有员工，确保他们粉碎所有待丢弃的文件，不要将未粉碎的文件直接扔进垃圾桶或回收箱。所有待处理的公司文件都必须先经过碎纸机处理！

#### 资产盗窃与丢失

许多物理安全威胁来自设备的丢失或被盗，例如笔记本电脑或移动设备（智能手机、平板电脑等）。许多公司都有规定：如果员工将公司笔记本电脑或移动设备留在汽车内，不得将其放在显眼处，以防止砸窗抢夺式盗窃。在这种情况下，一些公司在政策中规定由员工负责赔偿笔记本电脑或电子设备。鼓励员工将所有电子设备锁在汽车后备箱中，而不是将其可见地放在副驾驶座位或后排座位上。值得注意的是，一些组织可能会因员工不遵守此类政策而对其进行训斥，以确保员工认识到妥善处理公司资产、做出负责任决策的价值。

在办公室内，你可以通过使用防盗锁线缆来帮助阻止笔记本电脑、平板显示器、投影仪甚至台式计算机等设备被盗。`lockdown cable` 是一种连接并锁定在设备上的小型线缆，用于将设备固定在桌面上。这些防盗锁线缆无法阻止心存不轨的小偷偷窃设备，但能起到威慑作用，防止路人顺手牵羊。[图 5-1](#ch05.xhtml#ch5fig1) 显示了一个防盗锁线缆。

##### 远程擦除设备

确保员工了解立即报告移动设备丢失或被盗的重要性，以便你能尽快远程擦除这些设备。擦除设备会从服务器向设备发送信号，以擦除其所有数据及配置。这可确保丢失或被盗的移动设备上不包含敏感信息。

##### 设备上的安全防护措施

在移动设备上实施安全防护措施非常重要，这样如果设备被盗或丢失，你可以让他人尽可能难以使用该设备。

大多数设备支持设置某种形式的密码或 PIN 码，这样如果有人偷走了设备，他们就需要知道访问代码才能使用它。大多数移动设备（如 iPhone 和 Android 手机）支持在一段时间不使用后锁定设备（称为自动锁定）。此锁定功能意味着如果设备丢失或被盗，发现或偷窃设备的人将需要知道解锁码才能访问它。你可能还想启用设备支持的任何设备追踪功能，以便在设备丢失或被盗时定位设备。

对于笔记本电脑，请务必在设备上设置 BIOS 开机密码，并更改笔记本电脑的启动顺序，以防止他人在偷走设备后从 CD-ROM 启动并安装他们自己的操作系统。请务必设置 BIOS 管理员密码，以防止他人进入 BIOS 并进行更改，例如更改启动顺序。

如果无法在 BIOS 中设置启动密码，请考虑使用 BitLocker 等工具进行全盘加密。BitLocker 是内置于 Windows 系统中的驱动器加密功能，它不仅加密驱动器内容，还充当启动密码。

##### 数据加密

在[第 12 章](#ch12.xhtml#ch12)中，你将了解加密知识，但重要的是要注意，保护笔记本电脑或移动设备上机密数据的一个重要步骤是对该数据进行加密，以防设备丢失或被盗。如果数据已加密，那么即使设备丢失或被盗，你也能确保公司数据的安全。同样，可用于加密整个磁盘的技术的一个好例子是 BitLocker。
