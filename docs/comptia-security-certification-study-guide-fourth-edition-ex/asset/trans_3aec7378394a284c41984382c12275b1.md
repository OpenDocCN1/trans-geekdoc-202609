
Linux 使用 `syslogd` 守护进程来审核活动（守护进程是一种始终在主机上运行的计算机程序，即使没有用户登录也会运行——类似于 Windows 服务）。`syslogd` 从 `/etc/syslog.conf` 读取其配置，以确定审核内容以及是否向管理员通报可疑活动。Linux 管理员还拥有大量操作系统命令；例如，`last` 列出当前已登录的用户，`lastlog` 列出所有用户的上次登录时间。以下是 Linux 中一些常用的日志文件：

- **`/var/log/faillog`** 显示用户账户的失败登录尝试。您可以在大多数 Linux 发行版上使用 `faillog` 命令来查看失败的登录记录。
- **`/var/log/lastlog`** 显示用户列表及其上次登录时间。使用 `lastlog` 命令可显示该日志的输出。
- **`/var/log/wtmp`** 显示已登录系统的用户。使用 `last` 命令可显示该日志文件的内容。
- **`/var/log/messages`** 包含有关系统相关事件的信息。
- **`/var/log/auth.log`** 某些 Linux 发行版使用此文件记录认证尝试和认证事件的信息。

您可以使用任何文本编辑器打开大多数这些 Linux 日志文件，或者在某些 Linux 发行版中，您可以使用系统日志查看器来显示常用日志文件的内容。要在 Linux 中查看系统日志查看器（参见[图 19-8](#ch19.xhtml#ch19fig8)），请选择“系统”菜单，然后选择“管理 | 系统日志”。

### 其他日志

在监控系统或设备并寻找安全事件时，您可能需要检查各种日志，因为存在许多不同类型的系统和设备。以下概述了审核活动时可能会查看的一些常用日志系统：

- **事件日志** 在 Windows 系统上，请查看事件查看器中与安全事件相关的条目。
- **审核日志** 如果已启用审核，请查看应用程序、系统或设备的审核日志以发现可疑活动。
- **安全日志** 如果设备有安全日志，请检查其中与安全相关的信息。
- **访问日志** 大多数服务器和设备都有访问日志，可让您查看谁获得了对资源的访问权限。就物理安全而言，电子锁通常具有访问日志，以便您查看谁在不同时间获得了进入设施的权限。

**在 Windows 中实施审核**

在本练习中，您将在 Windows 系统上实施审核。

1. 确保您正在运行 Windows 10 VM、Linux VM 和 ServerA VM。
2. 确保您正在使用 ServerA VM。要为所有域控制器启用审核，请单击“开始 | 服务器管理器”，然后选择“工具 | 组策略管理”。
3. 在组策略管理控制台中，在左侧展开 `certworld.loc` 林，展开“域”，然后展开 `certworld.loc`。您现在应该能看到“组策略对象”文件夹。展开“组策略对象”文件夹，然后右键单击“默认域控制器策略”并选择“编辑”。
4. 展开“计算机配置 | 策略 | Windows 设置 | 安全设置 | 本地策略”，然后选择“审核策略”。
5. 执行以下操作以配置审核：
   a. 双击“审核账户登录事件”并选择“失败”。
   b. 双击“审核账户管理”并选择“成功”。
   c. 确保禁用所有其他审核。
6. 配置完审核后，可以关闭“组策略管理编辑器”窗口，然后关闭“组策略管理”控制台。
7. 启动 Windows 命令提示符，并务必以管理员身份运行。
8. 输入 `gpupdate /force` 以强制刷新策略。
9. 尝试使用错误的用户名和密码登录系统。然后以管理员身份登录，并从服务器管理器的“工具”菜单中启动“Active Directory 用户和计算机”。
10. 使用“Active Directory 用户和计算机”工具在 Active Directory 中创建一个新用户账户。
11. 要查看审核数据，请切换到服务器管理器，然后选择“工具 | 事件查看器”。
12. 查看安全日志中的失败登录记录（应带有锁图标）以及账户创建成功的记录。

**在 IIS 中配置日志记录**

在本练习中，您将验证 IIS 服务器上 Web 站点的日志记录是否已配置。您将配置 Web 站点，但可以遵循相同的步骤为 FTP 站点配置日志记录。

1. 确保 ServerA VM 正在运行，且您已以管理员身份登录。
2. 单击任务栏中的“服务器管理器”图标。
3. 选择“工具 | Internet Information Services (IIS) 管理器”。随即显示 IIS 管理器。
4. 在左侧展开 `ServerA` 以查看代表您的 Web 站点和 FTP 站点的文件夹。
5. 选择左侧“站点”文件夹下的“默认网站”。双击右侧的“日志记录”图标以启用 Web 站点的日志记录。
6. 在“日志记录”屏幕中，请注意右侧“操作”窗格中有一个“禁用”链接。这可用于禁用 Web 站点的日志记录。由于存在“禁用”链接，这意味着日志记录默认已启用。单击“禁用”链接以禁用日志记录；请注意链接变为“启用”。因为我们希望启用日志记录，所以选择“启用”链接。
7. 请注意，日志文件位置默认设置为 `%SystemDrive%\\inetpub\\logs\\LogFiles` 文件夹。另请注意，系统会按天创建新的日志文件（“计划”选项）。
