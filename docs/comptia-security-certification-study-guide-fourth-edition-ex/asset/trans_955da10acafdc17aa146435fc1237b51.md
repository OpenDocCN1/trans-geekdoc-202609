
许多组织使用虚拟化技术来创建虚拟机（VM），在网络上运行其服务器。借助虚拟化软件，您可以创建虚拟机的快照，这本质上是对其状态和配置的快速备份。随后，您可以稍后快速还原到该备份。还原到快照的缺点之一是您将丢失自该快照以来的所有更改，因此您必须确定确实要执行该操作。

就备份而言，快照是磁盘或一组磁盘在某一时间点的副本。例如，卷影复制服务（VSS），也称为影子副本，等解决方案允许供应商制作磁盘的快照备份。备份开始时，它会备份快照，允许用户在备份进行时更改磁盘上的文件，因为从技术上讲它正在备份快照。备份运行期间发生的任何文件更改都会被捕获并在事后应用。

#### 计划备份

大多数网络管理员宁愿在深夜备份操作执行时待在家里。这就是为什么他们要计划备份操作，以便不必在深夜留在办公室启动它。大多数备份软件支持备份操作的计划，这绝对是在选择备份软件时要寻找的功能之一。

在计划备份操作时，您需要制定备份计划。备份计划包含每次备份操作将备份的数据列表，以及发生的备份类型（增量、差异或完整）。您还应确保备份计划包含在该计划中。

例如，您可能决定每周六凌晨 12 点对数据文件和电子邮件数据执行完整备份。在该备份计划中，通常还会安排每天凌晨 12 点对相同的数据文件和电子邮件服务器执行增量备份。要还原任何损坏的数据，您需要还原最近一次完整备份，然后在其基础上应用最近一次差异备份。这将把您的数据更新到最近一次差异备份的时间点。

在制定备份计划时，应详细规划服务器上的哪些资源（如文件夹、数据库或邮件存储）将被备份及其内容。还要规划这些项目需要备份的频率。此备份计划将作为极佳的文档，纳入您的“网络文档”手册中，该手册用于保存网络拓扑图、防火墙规则、服务器配置等资料。

要在 Windows 系统上拥有执行备份的权限，您需要成为 `Administrators` 组或 `Backup Operators` 组的成员。您也可以分配给用户“备份文件和目录”用户权利，以便他们可以执行备份。

#### 练习 18-1

**在 Windows Server 上备份和还原数据**

在本练习中，您将学习如何使用 Windows 备份软件备份 Windows Server 上的文件，以及如何在文件被意外删除后将其还原。请务必查看随附此书的在线资源中包含的本练习视频。

1. 切换到 `ServerA` VM。在服务器管理器中，通过选择 `管理 | 添加角色和功能` 来安装 Windows Server 备份功能。继续向导并安装 Windows Server 备份功能。

2. 安装 Windows Server 备份软件后，确保您仍在服务器管理器中，然后选择 `工具 | Windows Server 备份`。

3. 在左侧选择 `本地备份`。

![Image](f0713-01.jpg)

4. 要备份 `LabFiles\PacketCaptures` 文件夹，请在右侧“操作”窗格中选择 `一次备份` 选项。

5. 选择 `不同选项` 以指定备份设置，然后单击“下一步”。

6. 选择 `自定义` 以选择要备份的文件，然后单击“下一步”。

7. 单击 `添加项` 以添加要备份的项目。通过选择 `+` 号展开 `C:` 驱动器的内容，然后展开 `LabFiles` 文件夹。

8. 勾选 `PacketCaptures` 文件夹旁边的复选框以备份该文件夹，然后单击“确定”。

9. 单击“下一步”。选择 `本地驱动器` 以备份到另一磁盘上的文件，然后单击“下一步”。

10. 单击 `备份` 按钮执行备份。这应该只需一分钟。

##### 执行已删除文件的还原

11. 双击 `计算机 | C: 驱动器 | labfiles | PacketCaptures`。

12. 在 `PacketCaptures` 文件夹中，通过右键单击名为 `httptraffic.cap` 的文件并选择“删除”来删除该文件。

13. 单击“是”确认要删除该文件。

14. 关闭所有窗口。

15. 要还原已删除的文件，请启动服务器管理器，然后选择 `工具 | Windows Server 备份`。

16. 在右侧“操作”窗格中选择 `恢复` 链接。

17. 选择 `此服务器` 以指定备份存储在本地服务器上，然后单击“下一步”。

18. 确保选中今天的日期作为执行备份的日期，然后单击“下一步”。

19. 选择 `文件和文件夹` 以从备份中还原单个文件，然后单击“下一步”。

20. 在左侧，单击加号 (`+`) 以展开备份的文件夹结构，您将在其中找到 `PacketCaptures` 文件夹。在左侧选择 `PacketCaptures` 文件夹以显示该文件夹中的文件。

21. 在右侧选择 `HTTPTraffic.cap` 文件以还原该文件。

22. 单击“下一步”。

23. 在恢复选项中，选择 `原始位置` 将文件还原到其最初备份的位置。请注意 ACL（权限）也将被还原。单击“下一步”。

24. 单击 `恢复` 以开始还原操作。

25. 还原操作完成后，单击“关闭”，然后关闭备份软件。验证文件现在是否存在于 `C:\labfiles\PacketCaptures` 中。

#### 地理因素考量

在整体规划备份和灾难恢复时，您需要考虑关于物理位置的许多地理因素：

- **异地存储** 请务必在另一位置存储备份副本，以防火灾、洪水或地震等灾难。
- **距离考量** 您希望异地备份足够近，以便在需要时能快速获取，但同时它应足够远，以免受到影响您当前位置的任何灾难的波及。
- **地点选择** 请务必选择一个能获得消防部门等应急服务快速响应的地点。您还应确保该地点能获得电力公司等公用事业服务的快速响应。此外，请审查周边区域，确保您不在洪水区或高犯罪率区域内。
- **法律影响** 在为您的站点和磁带备份选择物理位置时，请务必了解该国家或州的任何法律，这些法律可能会影响您的数据如何被访问或管理。
- **数据主权** 与上一点相关，请务必了解谁拥有数据并对数据拥有完全的权利和控制权。通过将数据存储在特定国家或州，您是否隐性地赋予了第三方访问数据的权利？对于云存储，您可能需要了解云提供商的服务器位于何处，并确保您的数据放置在您所在的国家内，以便您国家的法律管辖该数据。
