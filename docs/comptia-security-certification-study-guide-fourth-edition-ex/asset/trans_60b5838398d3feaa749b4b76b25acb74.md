
# 操作系统类型与安全加固

根据您所审查的操作系统类型，您需要优化将系统置于安全状态所采取的步骤。以下是您可能遇到的一些常见操作系统类型：

- **网络操作系统** 网络操作系统设计用于在服务器上运行。请务必仅加载网络操作系统所需的服务，以帮助减少暴露的漏洞数量。
- **服务器操作系统** 服务器操作系统旨在为客户端提供资源，如文件和打印机。通过仅安装所需的软件并及时应用补丁来锁定每台服务器。
- **工作站** 工作站是用户用来访问网络资源的设备。请务必安装反恶意软件并保持客户端处于最新状态。
- **设备** 设备是指用户使用的任何装置。请务必调查设备上运行的任何服务或协议，以便在需要时将其禁用。
- **信息亭** 信息亭是位于公共场所（如大楼前厅）的计算机系统，供人们出于特定目的使用。请务必锁定信息亭并限制其上可运行的应用程序。

正如您所了解的，有许多不同类型的恶意软件需要防范。以下是恶意软件防护功能列表：

- **防病毒** 安装防病毒软件并保持病毒定义库为最新。
- **反垃圾邮件** 确保电子邮件软件已启用反垃圾邮件功能，以减少到达用户的未经请求的电子邮件。
- **反间谍软件** 确保已安装反间谍软件，以防止软件监视您的活动。
- **弹出窗口拦截器** 确保已安装广告软件拦截器和弹出窗口拦截器，以防止弹出窗口的出现。

## 软件安全与移动操作系统安全

您可以采取许多步骤来保护计算机系统和移动操作系统。以下列表概述了实施软件安全的常用技术：

- **补丁管理** 请务必修补所有系统，包括为移动设备及其应用程序应用更新。
- **禁用不必要的端口和服务** 始终检查设备上运行的默认软件，并禁用任何不必要的开放端口和正在运行的不必要服务。
- **最小功能性** 在处理移动设备等设备时，请查看设备提供的功能，并禁用您不打算使用的任何功能。
- **安全配置** 请务必审查系统或设备的配置并启用任何安全功能。例如，移动设备应启用自动锁定功能。
- **应用程序白名单/黑名单** 您可以使用白名单限制系统上允许运行的软件，或使用黑名单阻止软件运行。
- **可信操作系统** 使用实现多层安全（如身份验证和授权）的可信操作系统，以确定谁可以访问系统以及他们可以执行什么操作。
- **基于主机的防火墙** 实施基于主机的防火墙以控制允许到达系统的流量。如果用户将笔记本电脑带出办公室并将其连接到不受信任的网络（如家庭或酒店网络），基于主机的防火墙至关重要。
- **基于主机的入侵检测** 实施基于主机的入侵检测系统以监控系统上的可疑活动。
- **主机软件基线化** 使用基线化软件确保系统处于安全状态并已完成加固。
- **禁用默认账户/密码** 禁用任何现有的默认账户，并使用强密码创建您自己的替代账户。

## 物理安全

您可以采取许多步骤来帮助保护资产，这与物理安全相关：

- **线缆锁** 对笔记本电脑和投影仪等较小的设备使用线缆锁，以防止他人轻易窃取这些设备。
- **保险柜** 为员工提供保险柜以存放敏感文档。
- **锁柜** 提供可上锁的柜子，用于存放移动硬盘、移动设备以及任何其他不使用时可能包含敏感数据的设备。

## 外设安全

保护系统的另一个方面是确保外设处于安全状态。以下是保护外设的一些注意事项：

- **无线键盘/鼠标** 使用无线键盘（或鼠标）会使您的系统面临来自不需要来源的通信风险。接收传输的 USB 接收器可能被黑客劫持，从而允许黑客在您的系统上输入命令。请保持系统打有最新补丁以帮助防止漏洞利用，但也请勿在高安全环境中使用无线键盘和鼠标。
- **显示器** 为保护显示器，请务必在显示器上安装防窥片，以帮助防止他人从用户肩后窃听并查看敏感信息。
- **支持 Wi-Fi 的 MicroSD 卡** 支持 Wi-Fi 的 MicroSD 卡是内置无线芯片的 SD 卡，允许它们从相机等设备远程接收数据。
- **打印机/多功能设备** 对于打印机和其他多功能设备，您应首先禁用任何未使用的功能，例如无线功能或内置 Web 服务器（如适用）。在处置打印机之前，请检查打印机中是否有用于排队打印作业的驱动器，因为这可能成为他人在您处置打印机后访问数据的途径。处置打印机时请务必销毁该驱动器。
- **外部存储设备** 允许用户将外部存储设备连接到系统，可能会使该系统暴露于存在于外部或可移动驱动器上的蠕虫病毒。此外，允许他人连接外部驱动器可让他们轻松复制数据并带走。为帮助保护系统，请限制外部存储设备的使用并实施 DLP 以防止数据泄露。
- **数码相机** 请注意相机内置的任何技术，例如无线通信和存储，并务必禁用您不使用的功能。例如，如果您不使用相机的无线功能，请禁用无线以防止黑客通过无线方式利用该设备。

## 安全预演部署

在实施系统时，遵循组织制定的任何变更管理流程，以安全的方式部署系统至关重要。请务必将用于开发解决方案的系统、用于测试解决方案的系统以及用于运行解决方案生产版本的系统分开。以下是应用程序和系统安全部署的一些关键点：

- **沙箱** 沙箱是为应用程序创建单独运行环境并确保限制这些运行环境之间通信的过程。
- **环境** 您应为部署的不同阶段创建不同的环境。以下是您应具备的四种环境：
  - **开发** 开发系统用于开发或创建解决方案的设计。
  - **测试** 设计创建完成后，将在测试系统上对其进行测试。
  - **预演** 完成解决方案的初步测试后，将解决方案移至预演环境，在那里执行更接近生产环境的验证，以确保解决方案正常工作。
  - **生产** 预演完成后，将解决方案投入生产环境。
