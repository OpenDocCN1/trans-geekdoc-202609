##### 信息安全的目标

![Image](boxsq.jpg) 信息安全的目标是机密性、完整性和可用性（CIA）。

![Image](boxsq.jpg) 机密性涉及将数据和通信保密给相关各方。实现机密性最流行的方法是加密，但你也可以通过使用权限来帮助维护机密性。

![Image](boxsq.jpg) 完整性意味着确保数据保持其原始状态且未被修改。通常，数据完整性通过哈希算法来维护，哈希算法是对数据执行的一种数学运算，用于生成一个结果（哈希值）。当你想要验证数据的完整性时，会将此哈希值进行比对。

![Image](boxsq.jpg) 可用性涉及确保在需要时数据可用。有助于可用性的技术常见示例包括备份、RAID 和集群技术。

![Image](boxsq.jpg) 问责制已成为信息安全的一个重要目标，它涉及能够让用户对其行为负责。你可以通过在环境中使用日志记录和审计来实现问责制。

##### 理解认证和授权

![Image](boxsq.jpg) 在任何环境中获取资源访问权限的过程是：识别、认证，然后授权。

![Image](boxsq.jpg) 识别涉及网络上的用户首先识别自己——通常通过用户名，但他们也可以使用 ID 徽章。

![Image](boxsq.jpg) 一旦用户向系统或网络标识了身份，他们随后通过提供用户名和密码进行认证。然后将用户名和密码与认证服务器进行比较，以验证所提供的凭据是否正确。

![Image](boxsq.jpg) 用户通过认证后，授权随即生效。通过授权，根据与资源关联的访问控制列表（ACL），允许或不允许用户访问资源。ACL 的一个示例是文件夹上的权限列表。

##### 理解安全原则和术语

![Image](boxsq.jpg) 不同类型的安全包括物理安全、通信安全、计算机安全和网络安全。

![Image](boxsq.jpg) 物理安全涉及控制谁可以获得对系统或设施的物理访问。通信安全涉及保护传输中的数据——通常通过加密通信。计算机安全涉及实施控制以保护系统，而网络安全涉及实施控制以保护网络。

![Image](boxsq.jpg) 为了考试，请务必熟悉最小权限、职责分离和职责轮换的概念。最小权限的概念是确保你仅授予执行任务所需的最低特权。职责分离原则是确保所有关键任务被划分为多个工作，并且每个工作由不同的人执行。职责轮换是通过定期轮换不同员工担任该职位，以保持员工在其活动中的诚实性。

![Image](boxsq.jpg) 需知原则的概念是确保信息仅提供给并可被那些需要知道该信息的人获取。

![Image](boxsq.jpg) 信息安全的一个重要方面是确保你采取分层方法，通过实施不同的安全控制来保护你的环境。例如，请务必不仅仅使用防火墙——你需要使用防火墙、防病毒解决方案、认证、权限和入侵检测系统，仅举几层而言。

![Image](boxsq.jpg) 导致软件漏洞的原因有很多，例如不当的输入处理、不当的错误处理和软件的错误配置。如果编码不当，你的软件也可能容易受到内存泄漏或缓冲区溢出的影响，这可能导致对系统的未授权访问。

![Image](boxsq.jpg) 有许多不同的威胁行为体（可能造成威胁的人）需要注意。请注意不同类型的黑客，同时也要知道你需要保护公司资产免受内部威胁（如不满的员工）和外部威胁（如脚本小子、黑帽黑客，甚至是恶意的商业竞争对手）的侵害。

##### 查看安全角色和职责

![Image](boxsq.jpg) 请知道，组织内用于识别员工安全角色的术语各不相同。

![Image](boxsq.jpg) 系统或数据的所有者最终对该资产的安全负责，通常是高层管理人员。所有者确定资产的价值，也确定资产所需的保护级别。

![Image](boxsq.jpg) 保管人是负责实施所有者确定的安全控制的 IT 人员。保管人执行配置权限和防火墙以及执行备份等任务。

![Image](boxsq.jpg) 用户是组织中任何将作为其工作角色一部分每天访问资产的个人。

![Image](boxsq.jpg) 安全官被指派负责确保所有者确定的安全级别实际上正由保管人实施。安全官将充当所有者和保管人之间的联络人。
