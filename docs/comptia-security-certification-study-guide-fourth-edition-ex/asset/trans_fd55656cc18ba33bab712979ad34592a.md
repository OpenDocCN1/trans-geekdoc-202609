# 自测答案

## 理解无线网络

**1.** ![Image](boxt.jpg) **B.** 临时模式是指两台笔记本电脑通过无线连接直接连接在一起。

![Image](boxx.jpg) **A、C** 和 **D** 不正确。基础设施模式是另一种无线拓扑，涉及无线客户端连接到接入点。笔记本和企业不是有效的无线模式。

**2.** ![Image](boxt.jpg) **D.** 802.11a 标准是在 Wi-Fi 标准创建之前创建的，并在 5-GHz 频率下运行。802.11b/g/n 标准都在 2.4-GHz 频率范围内运行。

![Image](boxx.jpg) **A、B** 和 **C** 不正确。802.11b/g/n 标准都是 Wi-Fi 标准的一部分，并且彼此兼容。

**3.** ![Image](boxt.jpg) **C.** 802.11g 标准以 54 Mbps 运行，并在 2.4-GHz 范围内。

![Image](boxx.jpg) **A、B** 和 **D** 不正确。802.11n 标准支持大于 54 Mbps 的速度，而 802.11b 仅支持 11 Mbps。802.11a 标准支持 54 Mbps，但在 5-GHz 频率范围内运行。

**4.** ![Image](boxt.jpg) **A.** 802.11n 标准是一种支持高达 600 Mbps 传输速率的无线标准。

![Image](boxx.jpg) **B、C** 和 **D** 不正确。802.11a 标准支持 54 Mbps 的传输速率，802.11b 支持 11 Mbps 的传输速率，802.11g 支持 54 Mbps 的传输速率。

**5.** ![Image](boxt.jpg) **B.** WPA 使用临时密钥完整性协议 (TKIP) 定期更改用于保护无线网络的密钥。

![Image](boxx.jpg) **A、C** 和 **D** 不正确。WEP 配置了静态密钥，而 WEP2 和 WPA5 不存在。

**6.** ![Image](boxt.jpg) **D.** WPA2 使用 CCMP 和 AES 对称加密算法来执行加密。

![Image](boxx.jpg) **A、B** 和 **C** 不正确。WEP 配置了静态密钥，WPA 使用 TKIP 定期更改用于保护无线网络的密钥，并且不存在 WEP2 这种东西。
