# 扫描和枚举

在配置文件阶段收集 IP 地址后，黑客进入扫描阶段。黑客现在正在进行侦察，但这被视为*主动侦察*，因为他们实际上正在向组织的系统发送流量。

扫描阶段的目标是通过查明系统上开放的端口号，来找出系统上运行的服务。一旦黑客发现开放的端口号，他们将对系统进行*横幅抓取*，这会报告在该端口上运行的软件版本。黑客想知道软件版本的原因是为了研究如何利用该软件。

为了找出系统上运行的服务，黑客将对系统进行端口扫描，这会报告哪些端口是开放的。要进行端口扫描，黑客将使用像 `nmap`（命令行）这样的程序。例如，你可以使用 `nmap -sT 10.0.0.1` 对 10.0.0.1 系统进行端口扫描。[图 20-6](#ch20.xhtml#ch20fig6) 显示了 `nmap` 命令的输出。你将在“用于评估安全的工具”部分进一步了解端口扫描。

在黑客过程的这一阶段，黑客还可能尝试*枚举*系统，这意味着收集关于系统的更多信息。黑客可能试图识别计算机名称、用户名，甚至从系统获取组列表。诸如 nmap 之类的工具可用于枚举系统。

网络映射软件也可用于识别已连接到网络的无效系统。这被称为*流氓系统检测*。

网络应用程序（如 Web 服务器、FTP 服务器，甚至启用了远程桌面的系统）使用客户端连接的端口号。作为安全专业人员，你可以通过对具有这些开放端口的系统进行*端口扫描*来在网络上定位这些系统。端口扫描的结果将告诉你哪些系统上有哪些端口开放，这应该有助于你评估黑客可能以何种方式攻破系统，因为每个应用程序都有不同的针对性漏洞利用。

- **SYN 扫描（半开放）**  
  因为 TCP 连接扫描执行完整的三次握手，所以它产生的流量多于必要量。你可以执行 SYN 扫描，也称为半开放扫描或隐身扫描，因为它不完成完整的三次握手。扫描软件向端口发送 SYN 消息，如果目标系统以 SYN-ACK 回复，则连接被丢弃。这里的思路是收到了回复，所以端口很可能是开放的，并且无需发送三次握手的最终 ACK 消息。这种扫描也称为*隐身扫描*，因为它产生的流量较少，希望避免被检测到，并且你没有完全打开与端口的连接。以下命令显示了如何使用 nmap 进行 SYN 扫描：

- **逆向扫描**  
  逆向扫描之所以得名，是因为它以与你预期相反的方式响应。使用逆向扫描时，如果端口是开放的，则不发送回复；但如果端口是关闭的，则发回一个复位（RST）（参见[图 20-8](#ch20.xhtml#ch20fig8)）。不同类型的逆向扫描包括*空*扫描，它向端口发送一个未设置标志的数据包，以及*XMAS*扫描，它发送一个设置了 PSH、URG 和 FIN 标志的数据包。*FIN*扫描发送一个仅设置了 FIN 标志的数据包。请注意，扫描的名称来自数据包中设置的标志。以下命令显示了 nmap 使用的 FIN 扫描和 XMAS 扫描：
