### 主机和应用程序安全解决方案

Security+ 考试的一个重点是了解不同系统面临的风险以及如何缓解这些风险。例如，公司可能担心敏感公司数据泄露或被盗，并寻求您提供降低该风险的解决方案。在这种情况下，您会建议在计算机上禁用 USB 端口，以便无法将可移动驱动器连接到系统，并使用 `数据丢失防护 (DLP)` 解决方案阻止敏感数据类型通过电子邮件发送。

在本节中，您将学习如何通过使用常见的安全解决方案（如端点防护、启动完整性和数据安全功能）在系统（称为主机）以及运行在该系统上的应用程序上实施安全防护。

#### 端点防护

`端点防护`，也称为 `端点安全`，是指可用于保护客户端设备（如台式机、笔记本电脑、平板电脑和移动设备——这些统称为端点）的技术术语。以下是您应实施以帮助保护端点的技术列表：

- **防病毒** 您在 [第 5 章](#ch05.xhtml#ch5) 中了解了恶意软件和病毒。为了防范不同类型的病毒，请务必在端点（客户端）上安装防病毒软件，并保持病毒定义为最新，以最大程度地提高防护能力。
- **反恶意软件** 为了防范其他形式的恶意软件，您应该安装反恶意软件。大多数情况下，反恶意软件也是您的防病毒软件。
- **端点检测和响应 (EDR)** `端点检测和响应` 是一种安全技术，用于监控端点设备上的活动和事件，将从端点设备收集的数据发送到中央数据库，分析收集的数据，并从数据中识别任何潜在的网络安全威胁。当 `EDR` 软件识别到威胁时，它会通知客户端采取何种行动来缓解威胁。
- **DLP** 您在 [第 5 章](#ch05.xhtml#ch5) 中了解了 `数据丢失防护 (DLP)`，简而言之，`DLP` 是一种可实施的解决方案，它将监控敏感数据向组织外部的泄露并防止其发生。例如，您可以在电子邮件软件中实施 `DLP` 解决方案，防止员工在电子邮件地址中共享信用卡号码（或其他敏感数据）。
- **基于主机的防火墙** `基于主机的防火墙` 是安装或启用在计算机系统上的防火墙软件，旨在控制哪些流量可以到达该系统。例如，如果您网络上有一台旨在向客户端提供网页的内部网服务器，您可以在该系统上启用 `基于主机的防火墙`，仅允许 `HTTP` 或 `HTTPS` 流量到达该系统。这是一种保护该系统免受恶意流量侵害的方法，例如黑客进入网络，或者网络上存在恶意软件。另一个应使用 `基于主机的防火墙` 的示例是将笔记本电脑连接到不受信任的网络（如无线网络或酒店网络）时。例如，如果您有出差住酒店的员工，您希望在该员工的笔记本电脑上启用 `基于主机的防火墙`，因为酒店网络被视为不受信任的网络。
- **基于主机的入侵检测系统 (HIDS)** `基于主机的入侵检测系统` 通过查看系统上的日志和事件来确定该系统是否遭受攻击。入侵检测系统会发出潜在入侵发生的通知，但不会尝试纠正问题。
- **基于主机的入侵防御系统 (HIPS)** `基于主机的入侵防御系统` 类似于 `HIDS`，因为它能检测系统上的潜在攻击，但它可以采取纠正措施，例如阻止来自导致可疑流量的 IP 地址的连接。您将在本章后面了解更多关于 `HIDS` 和 `HIPS` 的信息。
- **下一代防火墙 (NGFW)** `下一代防火墙` 是一种常规防火墙，它能过滤流量，并执行深度包检测（检查数据包的有效载荷），还包含类似于 `IPS` 中的入侵防御功能。

#### 启动完整性

攻击者获取敏感公司数据的常见方式是找到丢失的笔记本电脑或窃取笔记本电脑，然后从位于可启动介质（如可启动 USB 驱动器或 DVD 驱动器）上的其他操作系统启动。一旦启动到他们自己的操作系统，黑客就可以浏览随笔记本电脑附带的驱动器上的文件（假设未加密）。为了帮助防止此类攻击，您应该使用全盘加密，但也可以使用系统的启动完整性功能来验证启动环境未发生变化（从 USB/光盘启动即是改变启动环境）。以下是一些可用于确保启动完整性的解决方案：

- **启动安全/统一可扩展固件接口 (UEFI)** `安全启动` 是 `UEFI` 类型 BIOS 系统的一项功能，可检测启动环境是否发生变化。如果启动环境已更改，`安全启动` 功能将停止启动过程。启动环境通过存储启动文件的哈希值并在启动时验证这些值来进行验证。
- **度量启动** `度量启动` 与 `安全启动` 类似，它在允许系统启动前验证启动环境的完整性。`度量启动` 通过将启动文件的哈希值存储在系统上的 `可信平台模块 (TPM)` 芯片中来实现这一点。
- **启动证明** `启动证明` 是指系统向远程系统证明在该系统上运行的软件的可信度。请注意，这与 `安全启动` 或 `度量启动` 略有不同，因为软件已经在运行并已通过验证，系统正在证明该验证。
