

另一个你应该了解的针对系统的重要物理安全威胁是人为错误。例如，一名试图对系统执行升级的员工——可能是增加内存或更换硬盘——可能会通过`静电放电 (ESD)`烧毁系统的主板。ESD 是静电在你身上积累，当你触摸另一个物体（如计算机组件）时转移到该物体上。这种静电转移足以损毁或严重损坏计算机组件。

为防止此类情况发生，应对桌面支持团队进行 ESD 方面的教育，并指导他们使用防静电腕带，以便在维修系统前始终将自己接地。

#### 破坏

针对系统的另一个常见威胁是破坏，这通常（但不总是）是由不满的员工造成的。识别公司资产容易遭受破坏的情况非常重要。在我的安全课程中，我太多次听到学员讲述公司数据库被不满员工篡改的事件。

你需要识别易受破坏的系统，并确保为这些系统制定了恢复计划。`恢复计划`包含恢复系统的分步程序，但也确保你在机房货架上备有充足的备件。

### 认证目标 5.03

### 审视恶意软件

现在你已经了解了一些针对系统的常见物理威胁，让我们来看看当今对系统构成威胁的几种恶意软件类型。恶意软件是指任何损害或滥用系统的软件，包括从系统中删除文件、监控系统上的活动，甚至仅仅是降低系统运行速度这样简单的行为。

#### 权限提升

权限提升是指黑客发现操作系统或安装在系统上的某个软件中的缺陷，利用该缺陷可将黑客的权限从普通用户权限提升为管理员访问权限。一旦黑客获得了对系统的管理员访问权限，他们就可以对系统进行任何想要的更改，包括为未来的访问植入后门。

权限提升有三种类型：

- **垂直权限提升** 普通用户访问者能够将其权限提升为管理员访问权限
- **水平权限提升** 保持相同的访问级别，但访问的资源不同
- **权限降级** 管理员访问者能够降低其权限级别，以便访问特定用户可访问的数据

#### 病毒

安全领域最大的关注点之一是系统被病毒攻陷。病毒是一种感染系统（如计算机、平板电脑或智能手机）的恶意软件。感染可能会破坏系统上的数据、阻止系统启动，或仅仅是占用系统资源，导致系统变慢。本节讨论常见的病毒类型。

##### 可执行文件病毒

早期的病毒是可执行文件病毒，病毒附着在可执行文件上，但在你运行该文件之前不会被激活。这种病毒通常通过用户共享文件（通过软盘、闪存驱动器或网络驱动器）在系统间传播。

##### 引导扇区病毒

引导扇区病毒是一种严重的病毒，它攻击引导扇区代码并将其覆盖。引导扇区是磁盘上的第一个扇区，包含启动引导序列的操作系统加载器代码。当引导扇区病毒覆盖此扇区时，会阻止系统从受感染的磁盘启动。

##### 宏病毒

如今大多数应用程序都支持宏，宏是一种在软件应用程序中实现任务自动化的方式。例如，借助 Microsoft Office 套件，我们能够使用 Visual Basic for Applications (VBA) 创建宏，VBA 是一种功能强大的编程语言，可以操作应用程序和操作系统。

宏病毒是使用宏语言编写的代码，执行删除文件或向通讯录中的所有人发送电子邮件等恶意操作。宏通常在文件中创建，并在有人打开该文件时自动触发。

##### 逻辑炸弹病毒

逻辑炸弹是一种病毒，当你安装包含逻辑炸弹的软件时，它会被植入系统。你安装的软件应用程序会按预期运行，直到发生特定事件（如特定日期）。当你运行该软件时，它总是会检查那个特定日期，如果在该日期运行软件，它就会执行其恶意行为。离职或被解雇的不满员工常用这种方法在特定日期删除数据来破坏公司数据。他们对软件进行编程（正常运行时表现正常），使其在特定日期删除数据。

##### 蠕虫病毒

蠕虫病毒是当今有害且常见的病毒。蠕虫病毒是一种可怕的病毒类型，因为它具有无需用户激活即可自我复制的独特特征。蠕虫病毒可以通过多种方式自我复制：

- **网络协议** 蠕虫病毒可以通过使用标准网络协议在网络上自动自我复制，并通过利用系统上运行的网络应用程序中的漏洞来攻陷系统。一个很好的例子是 2003 年的 Blaster 蠕虫，它通过 RPC 端口（端口 135）进行复制。谁能忘记 2003 年的 SQL Slammer 蠕虫病毒，它在 10 分钟内感染了互联网上约 75,000 个系统？SQL Slammer 利用 SQL Server 上已知的缓冲区溢出漏洞，通过 UDP 端口 1434 连接到未打补丁的 SQL Server。
- **电子邮件** 蠕虫病毒可以通过电子邮件自动传播。病毒随电子邮件发送给用户，当用户打开邮件时，病毒代码执行并遍历用户的联系人列表，将邮件发送给所有联系人。臭名昭著的电子邮件病毒例子包括 2000 年的 ILOVEYOU 病毒和 2010 年主题为“Here you have”的病毒。
- **闪存驱动器** 新一波蠕虫病毒通过闪存驱动器（U 盘）复制来感染系统。一旦蠕虫病毒进入系统，它会等待有人将闪存驱动器插入该系统，然后蠕虫病毒复制到 U 盘。用户将 U 盘带到另一个系统，一旦驱动器连接到 USB 端口，病毒就会从 U 盘复制到系统。Conficker 就是一种可以通过 USB U 盘复制传播的蠕虫病毒。

##### 特洛伊木马病毒

特洛伊木马病毒是一种用户被欺骗安装的程序，因为它看起来有用，但实际上它是一种感染系统的病毒。特洛伊木马病毒通常通过在系统上打开一个 TCP/IP 端口来修改系统，这允许黑客连接到系统并控制它。

值得注意的是，特洛伊木马病毒的功能不止于在系统上打开端口，而且由于大多数人现在都有防火墙来阻止对特洛伊木马打开的端口的访问，你可能会发现特洛伊木马病毒会在系统上植入广告软件或键盘记录器。
