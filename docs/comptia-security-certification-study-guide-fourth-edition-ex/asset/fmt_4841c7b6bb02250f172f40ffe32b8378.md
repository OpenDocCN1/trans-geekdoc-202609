
# 网络安全评估工具与技术

## 蜜罐

另一种流行的安全评估方法是在网络上设置蜜罐。**蜜罐**是放置在网络上的系统，旨在吸引黑客攻击，而不是让黑客入侵您的生产系统。蜜罐的主要目标是为您争取时间，以便在黑客获得网络访问权限时进行应对。

必须像配置其他系统一样配置蜜罐，并务必遵循安全最佳实践来加固和保护系统。一些 IT 专业人员认为蜜罐应该容易被攻破，但如果太容易，黑客会怀疑这是一个蜜罐。您也希望蜜罐难以破解，因为这会让黑客花费更长时间来入侵，从而给您更多时间来检测入侵者！

确保蜜罐启用了高级别的审核和日志记录，以便捕获黑客执行的所有活动。为了保护日志，请将其写入始终受保护的远程系统。

![Image](exam.jpg)

> **蜜罐是了解零日漏洞利用的绝佳方式。** 零日漏洞利用是指未知且难以防范的漏洞利用，因为您不知道该漏洞利用的存在。当您设置蜜罐且黑客使用零日漏洞利用时，蜜罐上的日志文件会让您了解相关情况。

**蜜罐网络**与蜜罐非常相似，因为它旨在引诱黑客，但蜜罐网络是一个由伪造系统组成的完整网络，用于跟踪黑客的活动。

**蜜饵文件**是您留在系统上以诱使攻击者打开的文件。例如，您可以在桌面上放置一个名为 `password.txt` 的文本文件。如果系统被攻破且攻击者打开了该文件，则会发送警报，告知您有人打开了该文件。

![Image](exam.jpg)

> **针对 Security+ 考试，请记住蜜饵文件是设计用来诱使攻击者打开的文件。这会触发警报，表明有人在系统上。**

## 其他网络工具

渗透测试人员可能会不时使用许多不同的网络工具。以下是一些更常见的网络工具：

- **`netcat`**  
  用于在系统上打开端口并让进程在该端口上运行。渗透测试人员通常使用它在已被利用的系统上打开后门。

- **`ARP`**  
  用于显示和管理本地系统上 ARP 缓存的内容。

- **`route`**  
  `route` 命令用于修改系统的路由表。

- **`cURL`**  
  客户端 URL（cURL）是一种工具，用于使用 URL 和 HTTP、HTTPS、FTP、FTPS 等互联网协议在不同系统之间传输文件。

- **`sn1per`**  
  Sn1per 是一种用于扫描系统漏洞的工具。它结合了 whois、ping、nmap 以及针对系统的漏洞利用等功能。

- **`scanless`**  
  一种匿名端口扫描器，可以从许多不同的扫描站点为您执行端口扫描。运行命令时指定要使用的扫描器名称（例如 `scanless -s pingeu -t 192.168.1.1`）。您可以使用 `scanless -l` 查看扫描器列表。

- **`dnsenum`**  
  用于收集特定 DNS 区域的 DNS 记录。

- **`Cuckoo`**  
  一种沙箱环境，允许您运行恶意软件。Cuckoo 会向您报告恶意软件在系统上采取的操作。

## 文件操作

由于大多数安全测试工具和框架都在 Linux 上运行，渗透测试人员需要知道用于执行基本文件操作的工具。以下是 Linux 中一些常见的文件操作工具：

- **`head`**  
  一种 Linux 命令，用于报告文件的开头内容（默认前十行）。

- **`tail`**  
  类似于 `head` 命令，但此 Linux 命令用于在屏幕上打印最后十行。

- **`cat`**  
  用于在 Linux 中显示一个或多个文本文件的内容。

- **`grep`**  
  用于在文件中搜索特定字符串。

- **`chmod`**  
  用于更改文件的权限。

- **`logger`**  
  允许您向 `/var/log/syslog` 文件添加日志条目。

## Shell 和脚本环境

作为渗透测试人员，您可能需要创建自己的脚本来自动化渗透测试期间执行的任务。以下是渗透测试人员使用的一些脚本环境。

- **`SSH`**  
  一种安全 Shell 环境，用于通过安全通道获得对系统的远程访问。

- **`PowerShell`**  
  Windows 中的一种脚本环境，可用于创建脚本以自动化常见任务。

- **`Python`**  
  另一种在安全领域非常流行的脚本环境。许多安全工具（如 `sn1per`）都是用于在渗透测试期间自动化任务的 Python 脚本。

- **`OpenSSL`**  
  一种安全库，应用程序可用它通过网络建立安全通信通道。

## 数据包捕获与重放

数据包捕获软件或嗅探程序的目的是**被动地**捕获网络上传输的流量，以便查看或分析该流量。在执行安全评估时使用嗅探器的目的是查看是否可以捕获以明文形式在网络上发送的敏感信息。如果您发现数据包捕获中包含密码和其他敏感信息（如图 20-11 所示），则应建议组织加密网络流量。

> **多年前，当我在一家大型全国性公司工作时，员工被告知他们的电子邮件在网络上是加密的。几年后，我们发现我们的电子邮件实际上并未加密——服务器管理员以为他们启用了加密，但不知何故并未启用，且从未验证过。我们之所以发现这一点，只是因为一些正在学习如何监控流量的培训人员发现了正在传输的公司经理的电子邮件。使用数据包嗅探器是验证数据在传输过程中是否真正加密的好方法。**

以下是一些可用于捕获网络数据包的常用工具：

- **`Wireshark`**  
  可能是最常用的数据包捕获工具，可从 [wireshark.org](http://wireshark.org) 免费下载。您可以捕获网络上的数据包、过滤数据包并对其进行分析，以确定网络上的活动。

- **`tcpdump`**  
  一种用于捕获流量的 Linux 命令。例如，您可以使用以下命令在屏幕上显示捕获的数据包：`tcpdump -i eth0`，其中 `-i eth0` 是用于捕获流量的接口。

- **`tcpreplay`**  
  一种用于在网络上重放捕获流量的 Linux 命令。流量首先使用 `tcpdump` 捕获，然后可以使用 `tcpreplay` 在网络上重新发送。

## 其他常用工具

Security+ 考试目标提到了您应该了解的其他一些常用工具和框架：

- **漏洞利用框架**  
  渗透测试人员常用的评估工具是漏洞利用框架，它包含许多用于利用不同产品缺陷的工具。常见的漏洞利用框架示例包括 Web 应用程序攻击和审计框架（`w3af`）和 `Metasploit`。

- **密码破解工具**  
  您可以找到各种密码破解工具。例如，您可以使用 John the Ripper、Medusa、Hydra 和 `hashcat` 等工具破解密码。所有这些工具都随 `Kali Linux` 提供。

- **数据清理**  
  您可以使用数据清理工具确保所有数据从驱动器中安全擦除。在处置驱动器或将驱动器用作取证镜像的目标时，这是一个重要步骤。
