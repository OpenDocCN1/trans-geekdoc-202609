

# SIEM 仪表板

您可以从安全信息和事件管理 (SIEM) 仪表板收集信息，这是一个使用传感器的核心工具，用于收集网络上设备和应用程序生成的安全事件和警报。SIEM 系统将事件与安全趋势相关联，并允许您调整警报系统的灵敏度。

## 日志文件

日志文件是了解安全事件期间发生了什么的重要信息来源。以下是响应事件时应查找的常见日志：

- **网络** 网络日志来自路由器和交换机等网络设备。这些设备允许您将记录的消息转发到中央 syslog 服务器，以便于查看。
- **系统** Windows 系统上的系统日志包含操作系统相关信息，例如驱动程序无法启动或系统关闭。
- **应用程序** Windows 上的应用程序日志是应用程序记录事件的位置。
- **安全** Windows 中的安全日志存储任何与安全相关的事件。例如，如果用户账户登录失败，该信息将存储在安全日志中。
- **Web** Web 日志存储关于 Web 和 FTP 服务请求的信息。
- **DNS** DNS 日志将显示关于 DNS 服务的信息，包括已发生的区域传输。
- **身份验证** 身份验证日志将显示关于身份验证成功和失败的信息。
- **转储文件** 当系统崩溃时，转储文件存储内存的内容。
- **VoIP 和呼叫管理器** VoIP 和呼叫管理器存储已发生的 IP 语音通话信息。
- **会话发起协议 (SIP) 流量** SIP 流量可用于识别网络上发生的 VoIP 通话和通信类型。

## 元数据

您可以从元数据获取信息，元数据是描述数据的数据。例如，当您用手机拍照时，照片会自动存储元数据，例如拍摄日期和时间、使用的相机类型，以及可能的拍摄地点 GPS 坐标。您可以查看照片、电子邮件、文件以及其他移动和 Web 数据的属性以查看元数据。

## NetFlow/sFlow

NetFlow 是思科路由器的一项功能，允许您收集并显示进入或离开接口的数据包。NetFlow 用于监控网络流量并识别潜在入侵。虽然 NetFlow 是思科专有的网络监控工具，但互联网协议流信息导出 (IPFIX) 是一种由许多供应商支持的 RFC 标准。sFlow 是一种行业标准协议，得到许多网络设备和监控软件供应商的支持，它允许对数据包进行采样并连同接口计数器一起导出。

# 作为事件响应的缓解技术

Security+ 考试要求您了解针对安全事件应实施的缓解技术。在本节中，您将了解缓解安全事件的常用方法。

## 重新配置端点安全解决方案

如果您发现客户端系统或服务器在安全事件期间遭到入侵，应考虑实施以下策略以防止事件再次发生：

- **应用程序批准列表** 作为安全策略的一部分，您应该有一份允许在客户端系统和服务器上使用的授权应用程序列表。然后您应实施应用程序批准列表（以前称为应用程序白名单），仅允许这些应用程序运行。
- **应用程序阻止列表/拒绝列表** 您应实施应用程序阻止列表或拒绝列表，以阻止特定应用程序运行。这以前称为应用程序黑名单。
- **隔离** 您应使用恶意软件防护软件的隔离功能，保护系统免受可疑软件的侵害。请务必定期检查隔离区并删除任何受感染的文件。

## 配置更改

可以进行多项配置更改，以提高基础设施及其系统的整体安全性：

- **防火墙规则** 考虑修改防火墙规则，以阻止来自可疑流量源的流量，甚至阻止可疑流量使用的特定端口号。
- **MDM** 使用 `移动设备管理 (MDM)` 产品帮助集中管理智能手机、平板电脑和笔记本电脑的安全性。借助 MDM，您可以强制执行策略（例如确保设备上的密码要求）、批准用于使用的应用程序、在设备丢失或被盗时加入远程擦除功能，并远程锁定设备。
- **DLP** `数据丢失防护 (DLP)` 在本书的几个章节中均有提及，且对 Security+ 考试很重要。借助 DLP，您可以通过防止敏感数据通过电子邮件发送到公司外部，或防止敏感数据存储在 USB 驱动器上，来防止数据泄露。
- **内容过滤器/URL 过滤器** 您可以实施内容过滤器来检查网站或电子邮件的内容，然后阻止恶意内容。您也可以使用 URL 过滤器阻止用户访问网络上的特定网站。
- **更新或吊销证书** 如果数字证书已过期，则需要在应用程序信任该证书之前进行续订。此外，如果证书已被泄露，您将需要在证书颁发机构 (CA) 吊销它。

## 其他缓解策略

您可以使用许多其他缓解策略来帮助保护系统：

- **隔离** 您可以将高度安全的系统与网络的其余部分隔离，从而消除网络通信对这些系统的风险。
- **遏制** 您应隔离任何受损系统，以遏制安全事件扩散到其他系统或网络区域。例如，如果系统感染了恶意软件，请务必立即将该系统从网络断开以遏制恶意软件。
- **分段** 根据网络不同区域的安全要求创建不同的网段。使用防火墙和访问控制列表控制一个网段到另一个网段的流量。
- **安全编排、自动化和响应 (SOAR)** SOAR 是一种威胁管理解决方案，允许您跨网络自动化安全运营并响应安全事件。SOAR 使用 `运行手册`，即包含如何执行 IT 任务的程序文档，以及 `剧本`，即发生安全事件时应采取的行动。
