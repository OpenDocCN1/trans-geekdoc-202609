
# 典型无线客户端 VPN 解决方案

在典型的无线客户端 VPN 解决方案中，无线客户端首先连接到无线网络。无线网络可能已实施前文讨论的一些安全预防措施，例如禁用 SSID 广播、启用 WPA2 或配置 MAC 过滤。关键在于，如果授权无线客户端连接到无线网络，它们仍然无法访问公司资源，因为它们尚未通过 VPN 连接。在连接到无线网络并获取 IP 地址后，无线客户端将通过 VPN 软件访问网络。VPN 软件将对用户进行身份验证，并创建一条加密隧道，以保护从客户端传输到企业网络的数据。

## 考试内幕

### 保护无线网络

Security+ 认证考试要求你了解无线网络和安全最佳实践。保护无线网络至关重要，因为未经授权的个人无需亲身进入你的大楼即可访问网络。未经授权的人员可能坐在大楼外的车里，甚至在隔壁的办公大楼里。

以下是保护无线网络时需要记住的要点：

- 为管理员账户设置密码。
- 更改 SSID。
- 禁用 SSID 广播。
- 使用 MAC 过滤。
- 使用 WPA2 或 WPA3 配置加密。
- 将接入点放置在大楼中心位置。
- 降低功率电平以控制无线信号传播距离。
- 在高安全环境中使用 VPN 解决方案。

#### 无线网络漏洞

现在你已经了解了一些保护无线网络的常见做法，我想讨论一下黑客在无线攻击中利用的无线网络常见漏洞。以下是现实世界中需要记住的一些关键漏洞，同时也是 Security+ 认证考试的重点。

##### 数据泄漏、干扰/阻塞和数据包嗅探

由于无线网络流量通过空气传输，因此容易受到干扰和数据包嗅探。以下是关于无线漏洞的注意事项：

- **数据泄漏** 电子元件始终会释放辐射，有人可能会收集电气元件的辐射并将其拼凑成可读数据。
- **干扰/阻塞** 如前所述，你可能会因无绳电话等设备而遇到无线网络干扰。这是一个安全问题，因为干扰可能导致无线网络瘫痪，这违反了可用性（还记得[第 2 章](#ch02.xhtml#ch2)中关于 CIA 的讨论吗）。
- **数据包嗅探** 任何拥有无线网卡和嗅探器的人都可以轻松捕获无线数据。请务必加密所有无线通信以保护机密数据。

> **针对 Security+ 考试，请记住无线网络面临的风险包括数据泄漏、干扰和阻塞以及数据包嗅探。你可以通过实施法拉第笼或 TEMPEST 系统来缓解这些风险。两者均用于阻止信号传出特定区域。**

##### 网络寻踪和网络标记

无线网络的另一个常见漏洞是网络寻踪，即有人开着车带着笔记本电脑四处游荡，试图定位可连接的无线网络。

另一个你应该了解的与网络寻踪相关的术语是*网络标记*。在网络标记中，当有人发现无线网络时，他们会在建筑物外用粉笔画上符号，通知网络寻踪社区的其他成员该建筑内存在无线网络。通过网络标记，不同的符号代表所发现无线网络的配置。例如，[图 9-8](#ch09.xhtml#ch9fig8) 显示了三种不同的符号：开放网络（允许任何人连接）、带有 SSID 的封闭网络，以及使用 WEP 的安全网络。每个符号上方标注 SSID，下方标注带宽。

##### SSID 广播

我们讨论的另一个常见漏洞是 SSID 广播。启用 SSID 广播后，人们很容易找到你的无线网络并尝试连接。将 SSID 更改为一个与网络用途不明显相关的名称，并在无线路由器上禁用 SSID 广播。

##### WPS 攻击和重放攻击

对于无线网络，还有两种需要熟悉的攻击类型：WPS 攻击和重放攻击。以下概述了这两种不同类型的攻击：

- **WPS 攻击** Wi-Fi Protected Setup（WPS，Wi-Fi 保护设置）是几年前推出的一项无线安全功能，允许用户输入 PIN 码（位于无线路由器背面）以连接到无线网络。使用 PIN 码后，SSID 和 WPA2 加密密钥将自动配置。创建此安全功能是为了让对无线网络知之甚少的家庭用户能够轻松创建和加入其无线网络。2011 年，WPS 中发现了一个漏洞，允许攻击者对 WPS PIN 码执行暴力破解攻击。
- **重放攻击** 重放攻击是无线网络中常见的一种攻击类型，黑客试图破解加密密钥。为了破解加密密钥，黑客必须产生足够的流量，以便破解工具执行破解。黑客不必等待无线接收点接收足够的流量，而是可以使用嗅探器捕获流量并重新发送或重放该流量。

##### 蓝牙劫持和蓝牙窃取

在[第 5 章](#ch05.xhtml#ch5)中，我们讨论了蓝牙设备的漏洞。两种常见的漏洞是蓝牙劫持和蓝牙窃取：

- **蓝牙劫持** 利用蓝牙无线协议向其他支持蓝牙的设备（如手机和平板电脑）发送未经请求的消息
- **蓝牙窃取** 通过从支持蓝牙的设备复制数据来利用该设备

##### 非法接入点和邪恶双生子

非法接入点是组织面临的严重漏洞，也是你需要为 Security+ 认证考试熟悉的内容。场景是这样的：你已经保护了网络环境，但网络安全很容易被员工连接无线路由器到网络从而破坏，以便他们在公司食堂吃午餐时能连接网络并访问互联网。

在此示例中，员工没有意识到他们通过将无线路由器连接到网络而给公司资产带来了风险。这被视为网络的非法接入点，因为它是网络管理员不知情的未授权设备。

![Image](exam.jpg)

> **针对考试，请记住非法接入点是网络的巨大漏洞。你应该使用 `Acrylic WiFi`、`Cain & Abel` 或 `Kismet` 等软件定期执行无线扫描，以定位任何非法无线接入点。**

值得注意的是，在企业网络中，无线控制器用于集中配置整个网络中的无线接入点。它们也可用于检测和阻止网络上的非法接入点。
