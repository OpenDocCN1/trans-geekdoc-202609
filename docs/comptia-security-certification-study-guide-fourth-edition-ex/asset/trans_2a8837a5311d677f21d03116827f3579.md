

# 误报与漏报

在评估 IDS 时，请务必与产品供应商核实误报和漏报的可能性。如果某 IDS 产生大量误报，那可是坏消息，因为这意味着 IDS 会在不该触发警报时触发，或在该触发警报时却不触发。请为 Security+ 考试了解以下误报结果：

- **误报** 误报是指 IDS 报告存在可疑活动（阳性），但实际上并不存在（错误的假设）。简单来说，IDS 报告了可疑活动，但该活动并未发生。
- **漏报** 漏报是指 IDS 未发现任何可疑活动，但这同样是错误的——实际上确实发生了可疑活动！简单来说，IDS 未能检测到实际发生的可疑活动，因此也未进行报告。

## 欺骗与干扰

检测入侵的另一种方法是使用一些诱饵，抓住攻击者的现行，收集关于他们的信息，并减缓他们对生产系统的攻击。你可以结合使用蜜罐、蜜网和蜜文件等技术，吸引黑客的注意力，将他们引入陷阱！

### 蜜罐与蜜网

`蜜罐` 是一种放置在专用网络或 DMZ 中的系统，旨在将黑客从生产系统引开，转向蜜罐。黑客会花费时间尝试入侵蜜罐，而与此同时，你正在记录其活动，并让安装在蜜罐上的基于主机的 IDS 向你发送关于黑客存在的通知。

大多数公司都会犯一个错误，即不保护蜜罐，因为他们希望黑客能入侵它，但如果你让黑客太容易就攻破了蜜罐，黑客可能会察觉到陷阱而离开。至关重要的是，你要通过加固蜜罐来挑战黑客，并实施安全控制，使该系统看起来似乎具有价值。

另一个常见的安全术语是 `蜜网`，它是一个完整的网络，旨在伪装成生产网络，但其唯一目的就是将黑客从真正的生产网络中引开。

### 蜜文件

`蜜文件` 是放置在系统上的文件，用于诱使黑客打开它。当文件被打开时，你可以触发发送警报，通知你这一事实，从而让你知道系统上有人。例如，你可以在桌面上放置一个名为 `passwords.txt` 的文件，诱使攻击者以为你有一个包含所有密码的文件。当黑客打开该文件时，会发出警报，通知你该文件已被打开。

### DNS 污水池

`DNS 污水池` 是指 DNS 服务器针对已知恶意的 URL 或域名，响应虚假的 IP 地址信息。这些虚假 IP 地址被发送给客户端，使客户端无法连接到已知的恶意地址。

### 虚假遥测

`遥测` 是为监控目的而收集的数据。某些应用程序允许你生成虚假遥测数据，这些数据可能是关于基础设施、服务器和客户端的信息。可以生成虚假遥测数据，以测试使用遥测数据的解决方案。
