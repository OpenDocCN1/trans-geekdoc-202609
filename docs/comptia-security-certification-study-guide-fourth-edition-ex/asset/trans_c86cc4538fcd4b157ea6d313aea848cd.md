
一旦认证器获得了认证信息，它会将该信息封装在 IP 数据包中，通过 RADIUS 协议传送给认证服务器。如果认证服务器回复指示凭据有效，认证器将允许申请者访问网络（交换机或无线接入点）。

## 802.1X 通信阶段

在备考 Security+ 认证考试时，了解 802.1X 通信的各个阶段以及每个阶段使用的协议非常重要。[图 10-5](#ch10.xhtml#ch10fig5) 描绘了 802.1X 组件之间通信的以下阶段：

![Image](f0458-01.jpg)

**图 10-5：802.1X 通信阶段**

1. **EAPOL 启动** 通信由客户端（即申请者）发送 EAPOL 启动消息开始。这是一个请求访问交换机或无线接入点的二层帧。

2. **EAPOL 身份请求** 交换机或无线接入点（也称为认证器）向申请者回送一个 EAPOL 帧，请求申请者标识其身份。

3. **EAPOL 身份响应** 申请者发送一个包含其认证信息的 EAPOL 响应消息。这可能是用户名和密码，也可能是证书。

4. **发送凭据** 认证器使用 RADIUS 发送一个包含凭据的 IP 数据包给认证服务器。

5. **RADIUS 访问：接受/拒绝** 认证服务器向认证器回送一个 RADIUS 访问消息，其中包含接受或拒绝状态。如果凭据经验证有效，则发送访问接受消息；如果凭据不正确，则发送访问拒绝消息。

6. **EAPOL 成功/失败** 最后，认证器向申请者发送一个带有成功或失败状态的 EAPOL 消息。收到成功消息后，客户端系统将被授予网络访问权限。

## 基于声明的认证/联合服务

联合服务是当今的一个重要话题，也是 Security+ 认证考试要求掌握的内容。联合服务提供了单点登录（SSO）的能力，（如前所述）这意味着一旦你登录并获得令牌，就可以使用该令牌访问不同的环境。联合服务负责基于互联网技术和标准格式生成访问令牌，以便该令牌可以在互联网的任何地方使用。

让我们看一个例子。假设 Bob 是你公司的员工，他想访问一个第三方网站或 Web 应用程序。你的公司与该第三方网站在互联网上的 Web 应用程序与你公司的联合服务器之间建立了一种信任关系，联合服务器负责以 SAML 格式生成基于声明的令牌。SAML 正如本章前面所介绍的，是一种基于 XML 的标准，用于描述安全令牌及其内容。安全令牌的内容由声明组成。`声明` 是描述 Bob 的一条信息，存储在令牌内部。这可能包括 Bob 的用户名、组成员身份、所属部门、电子邮件地址，甚至他来自的城市。存储在 SAML 令牌中的信息基于联合服务器的配置。

查看[图 10-6](#ch10.xhtml#ch10fig6)，让我们回顾一下使用联合服务器进行认证的步骤：

![Image](f0459-01.jpg)

**图 10-6：联合服务示意图**

1. Bob 尝试连接到第三方 Web 应用程序，该应用程序被称为**信赖方**，因为它依赖联合服务器生成的令牌。

2. 第三方 Web 应用程序将 Bob 重定向到联合服务器以获取访问令牌。

3. Bob 向联合服务器提供登录凭据，联合服务器被称为**声明提供者**或**身份提供者**。

4. 联合服务器在后台将请求转发给认证服务器以验证凭据。

5. 认证服务器针对登录尝试返回成功或失败消息。

6. 如果凭据正确，联合服务器生成一个包含声明信息的 SAML 令牌。

7. SAML 令牌被提交给 Web 应用程序，后者使用声明信息（如部门或城市）来决定是否授予用户访问权限。

![Image](exam.jpg)

# 认证总结

在本章中，你学习了认证的基础知识。备考 Security+ 考试时，请务必记住关于认证的以下要点：

- 向系统进行认证的不同方法包括：你知道的某事（密码）、你拥有的某物（访问卡）或你本身的特征（生物识别）。
- 考试一定会涉及多因素认证，如双因素或三因素认证。请记住，`多因素` 意味着你必须结合使用前面列出的两种或更多种认证因素。
- 基本认证和 PAP 以明文传输认证信息（用户名和密码），而 CHAP、MS-CHAP 和 Kerberos 等认证协议则不会。
- 请记住 RADIUS、DIAMETER 和 TACACS+ 等协议提供 AAA 服务。

通过深入理解本章呈现的材料，你将不会在 Security+ 认证考试中遇到任何与认证相关的问题。此处呈现的材料不仅对考试很重要，而且在你通过考试并继续从事网络专业职业后也将很重要。

## ✓ 两分钟演练

### 识别认证模型

- 认证因素的类型包括：你知道的某事、你拥有的某物、你本身的特征、你所在的位置和你的行为模式。
- 多因素认证涉及结合两种或更多种认证因素，以创建双因素认证或三因素认证。一种常见的双因素认证使用智能卡（你拥有的某物），它需要 PIN 码（你知道的某事）。
- 单点登录（SSO）是一种常见的认证原则，允许用户仅通过一次认证即可访问多个系统，而无需对每个访问的系统分别进行认证。

### 认证协议

- Microsoft 产品中常见的认证协议包括匿名认证、基本认证和集成 Windows 认证。
- RAS 和 VPN 服务器常用的远程访问协议包括 PAP、CHAP 和 MS-CHAPv2 等。
- 请记住 Kerberos 是一种相互认证协议，它使用密钥分发中心（KDC）向想要访问网络服务的客户端分发票据。
- 许多网络环境正在实施 AAA 服务，如 RADIUS，它是一个中心认证服务器，其他系统和设备可用其进行认证。

### 实施认证

- 当将认证模型建立在用户名和密码基础上时，请务必制定强密码策略和账户锁定策略。
- 请记住用户名用于标识用户，而密码用于认证用户。
- 另一种常见的认证方法是包含微处理器和代表用户数据的智能卡。硬件或软件令牌也可用于认证。
