

![Image](boxsq.jpg) DNS 投毒是指黑客篡改 DNS 服务器上的 DNS 缓存，导致 DNS 服务器向客户端发送特定系统的错误 IP 地址。DNS 投毒也可能是黑客修改本地工作站上的 `hosts` 文件。

![Image](boxsq.jpg) ARP 投毒是指黑客通过在 ARP 缓存中放置错误条目来篡改 ARP 缓存。黑客通常会将自己的 MAC 地址放入 ARP 缓存中，并将其与路由器的 IP 地址关联，以便接收所有发往互联网的流量。

![Image](boxsq.jpg) 为防止网络攻击，请使用防火墙控制允许进入网络的数据，并务必通过配置交换机功能（如禁用未使用的端口和启用端口安全）来控制谁可以物理连接到网络。

### 密码攻击分析

![Image](boxsq.jpg) 字典攻击是指黑客使用一个包含字典中所有单词的单词列表文件，将这些单词作为潜在密码尝试。可以通过启用密码复杂度要求的强密码策略来防止字典攻击。

![Image](boxsq.jpg) 暴力破解攻击是指黑客使用程序通过数学计算尝试所有潜在密码。可以通过使用账户锁定策略来防范暴力破解攻击。

![Image](boxsq.jpg) 混合攻击是指使用字典列表猜测密码，并尝试对单词进行修改。例如，尝试单词 "house" 后，软件会尝试 "house1"、"house2" 等。

![Image](boxsq.jpg) 离线密码攻击是指黑客带走一份用户账户数据库副本，以便在家中破解密码。在此示例中，黑客的计算机上没有密码策略或账户锁定策略来防范密码攻击。物理安全是阻止黑客带走账户数据库副本的唯一途径。

**1.** ![Image](boxt.jpg) **B.** 用户安全意识培训是防范社会工程学攻击的唯一途径。

**2.** ![Image](boxt.jpg) **D.** 人员闸是两扇上锁门之间的区域。第二扇门在第一扇门锁定前无法打开，这有助于进入设施的员工注意到任何可能试图尾随进入的人员。

**3.** ![Image](boxt.jpg) **A.** `Whaling`（鲸钓攻击）是指将网络钓鱼攻击目标瞄准公司里的“大鱼”（高层人员）的术语。在鲸钓攻击中，电子邮件通常会通过使用该个人的姓名进行个性化定制。
