
**对于 Security+ 考试，请记住：权限是指一个人对资源的访问级别，而权利是指他们执行特定任务的特权。**

## 文件系统安全与打印机安全

您还可以控制对文件、文件夹和打印机等资源的访问。在第 7 章中，您学习了在 Windows 和 Linux 中应用权限的知识，但我们在此进行复习，因为它是访问控制的重要组成部分。

### NTFS 权限

第 7 章讨论了大量 NTFS 权限，因此我想通过采用一种配置 NTFS 权限安全性的实用方法来总结该讨论。

配置 NTFS 权限时，请考虑您只有三个权限级别可供分配：

- **读取** 我认为 `Read` 权限是我将授予的最低访问级别，它实际上包含 `Read`、`List Folder Contents` 和 `Execute` 权限。
- **修改** `Modify` 权限提供 `Read` 的所有权限，但也允许某人修改文件、删除文件，如果权限分配给文件夹，还允许创建新文件。
- **完全控制** 此权限允许用户执行 `Modify` 权限的所有任务，但也允许他们更改权限和获取文件的所有权。

您在第 7 章中了解到，可以通过右键单击文件或文件夹，然后选择 `Properties` 命令来更改 NTFS 权限。在属性对话框中，选择 `Security` 选项卡以修改权限。

## 访问控制列表

如前所述，访问控制列表 (ACL) 是控制对文件或网络等资源访问的常用方法。配置 NTFS 权限时，您实际上是在配置访问控制列表，但路由器也可以拥有访问控制列表，以指定允许哪些流量进入或离开网络。

思科路由器具有一项称为 *访问列表* 的功能，用于控制可以进入或离开网络的流量。配置访问列表时，您需要添加规则以指定允许进入或离开网络的流量，适用于数据包的第一条规则即为该数据包遵循的规则。思科路由器有两种常见类型的访问列表：标准访问列表和扩展访问列表。

## 组策略

Microsoft 环境允许您通过使用单个系统的本地安全策略来保护系统，或通过使用组策略在多个系统上配置安全设置。组策略用于配置网络中各系统的大量设置：

- **安装软件** 使用组策略，可以在客户端计算机启动时或用户登录时自动安装软件。
- **配置密码策略** 组策略允许您配置密码策略，包括密码历史记录、密码复杂度、密码长度和密码过期（称为最大密码期限）。
- **配置审核** 使用组策略，可以将审核策略部署到多个系统，以便跟踪这些系统上的事件。
- **配置用户权利** 组策略还用于配置用户权利，即执行任务的特权。
