

### B 类火灾
B 类火灾被视为液体火灾，包括气体、油类、焦油、溶剂和酒精的燃烧。对于这类火灾，不能使用水；相反，必须通过使用 `CO[2]` 或 `FM-200` 灭火器来隔绝氧气。

### C 类火灾
C 类火灾包括电气元件和设备的燃烧。过去，这些火灾使用卤代烷气体、`CO[2]` 或非导电灭火剂（如 `FM-200`）进行扑灭。不再推荐使用卤代烷，因为它会破坏臭氧层，但 `CO[2]` 和 `FM-200` 灭火器仍在使用，且可用于 B 类和 C 类火灾。

### D 类火灾
D 类火灾包括可燃金属（如镁和钠）的燃烧，需要使用干粉灭火剂进行扑灭。

**针对 Security+ 考试，请了解不同类别的火灾以及每类火灾使用的灭火方法。请记住，C 类火灾涉及电气元件，使用 `CO[2]` 或 `FM-200` 是推荐的灭火方法。**

出于安全原因，请将灭火器放置在距离电气设备 50 英尺（约 15 米）范围内、显眼且易于取用的位置。您应每年对灭火器进行四次测试，以确保其正常工作。

火灾的另一种扑灭方法是喷淋系统。但是，您必须仔细考虑喷淋系统的布局，以确保水不会接触到关键电气设备，尤其是在服务器机房中。以下概述了流行的喷淋系统类型：

### 湿式管道系统
在湿式管道系统中，管道内始终充满水，随时准备释放。这使得当温度达到一定阈值时能迅速释放水流，但缺点是管道可能会冻结。

### 干式管道系统
干式管道系统的水储存在储水罐中，而不在管道内。这允许有一段短暂的延迟，在水释放前给您关闭阀门的时间（如果需要）。由于管道内无水，这种喷淋系统适合寒冷气候，因为管道不会冻结。

### 预作用系统
在预作用系统中，喷头上的感温元件必须熔化，水才会释放。这给了您在喷淋系统启动前使用灭火器扑灭火灾的机会。

## 认证总结

在本章中，您了解到物理安全是组织安全态势的重要组成部分。物理安全包含许多组成部分——以下是一些需要记住的关键点：

- 将关键系统和网络设备锁在具有受控访问权限的房间内。
- 为员工安全配备应急照明并提供备用电源。
- 在创建屏障以保护服务器机房等区域时，墙壁应从真实天花板延伸至真实地板。
- 拥有系统物理访问权限的人可能会从其他操作系统启动并运行任意命令。请在系统上禁用从其他设备（如 DVD 和 USB 驱动器）启动。
- 围栏应高 8 英尺（约 2.4 米），顶部应有三股铁丝网，以 45 度角朝向入侵者方向。安保人员应驻守在大门处，并接受培训以监控进出设人员员。
- 访问控制系统使用邻近读卡器、访问令牌和刷卡器的组合来授予个人进入设施的权限。

通过深入理解本章呈现的材料，您将在 Security+ 考试中轻松应对任何与物理安全相关的问题。此处的材料对考试很重要，但您也可以用它来评估组织的物理安全状况。
