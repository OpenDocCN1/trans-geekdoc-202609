

### 初次会议
通过与高层管理人员会面来启动流程，以了解他们希望您执行的工作范围。此时，您应确认是否可以执行所有类型的测试，例如拒绝服务攻击、缓冲区溢出攻击和密码攻击（仅举几例）。此外，此时您应重申：无法保证拒绝服务情况不会发生。

### 起草法律文件
初次会议后，咨询律师并起草一份法律文件，声明您被授权执行渗透测试。务必让您为其执行渗透测试的组织的授权代表签署该文件。

### 制定渗透测试计划
文件签署后，规划您将执行的攻击或测试类型。制定计划的目的是使您遵守纪律、遵循方法论开展工作，而非随意地入侵他人的网络。

### 测试渗透测试计划
测试您将用于执行不同类型攻击的工具，以确保它们正常工作，并查看执行时是否会导致拒绝服务。

### 执行渗透测试
此时您已在客户现场，按照计划执行渗透测试。务必测试密码破解、无线破解和缓冲区溢出攻击。同时测试组织的物理安全要素和社会工程学攻击。务必记录您所做的一切，包括每个步骤的开始和结束时间。

### 编写发现报告
测试完成后，编写发现报告。您不必包含所有活动的日志，但应随时备查以便参考。您应包含系统上攻击成功与失败的屏幕截图，以及改进安全性的建议。

### 汇报结果
在此阶段，您将再次与高层管理人员会面，汇报发现并提交报告副本。确保客户在已完成的评估上签字确认。

### 销毁报告副本
作为最后一步，确保您不再持有任何额外的评估副本，无论是打印形式还是电子形式。

## 执行漏洞评估

您可以执行的另一种安全测试（而非渗透测试）是漏洞评估。漏洞评估被视为一种被动评估类型，因为您并非实际模拟针对系统的攻击。通过漏洞评估，您旨在识别网络及其系统配置中的任何弱点，而不关心实际测试这些弱点以查看是否能攻破系统。

当管理层要求您评估安全性，但对您将在系统上运行黑客工具感到不安时，您应执行漏洞评估。其主要优势在于这是一种安全的评估类型，不会给系统带来拒绝服务的风险。

### 执行手动评估

执行漏洞评估时，我建议首先对网络及其系统进行手动评估。通过手动评估，您本质上是在执行配置评估，验证网络、客户端、设备和服务器的配置。在此手动评估中，您将检查是否遵循了最佳实践，例如确保每个系统都有密码策略并使用了防病毒软件。请记住，在大型网络上这可能耗时很长，因此拥有一份清单以保持进度至关重要。

### 执行自动化评估

执行漏洞评估时，您极有可能使用漏洞评估软件，例如 `LANguard` 或 `Nessus`。这是两款领先的漏洞评估产品，它们绝对能为您省去大量工作！为便于讨论，我将使用 `GFI LANguard` 来演示漏洞扫描器的实用性。

#### 执行扫描
使用 `Nessus` 或 `LANguard` 等漏洞扫描器时，首先要了解的是：这些工具通过扫描多个系统并将系统配置与漏洞数据库进行比对，帮助自动化漏洞扫描流程。

执行漏洞扫描时，我建议扫描两次：一次作为空扫描（您未向网络认证，因为不知道用户名和密码），另一次作为管理员账户扫描。扫描两次的目的是：第一次扫描让您了解如果“外人”能物理连接到您的网络，他们能看到网络的哪些信息；第二次扫描允许您使用管理员账户连接到所有系统，从而获得配置的完整评估。以下练习将指导您如何使用 `Nessus` 执行扫描。

#### 使用 Nessus 执行漏洞扫描

在本练习中，您将在 Kali Linux 系统上下载、安装并运行一款名为 `Nessus` 的漏洞扫描器。该漏洞扫描器将识别现存的漏洞并提供每个漏洞的详细信息。请确保您的 Windows Server 和 Kali Linux 虚拟机正在运行，以便进行此练习。

1. 在 Kali Linux 虚拟机上启动浏览器并访问 <https://www.tenable.com/products/nessus>。
2. 选择下载 AMD64 Debian/Kali Linux 版本。

![Image](p0807-02.jpg)

6. 要使用 `Nessus`，请切换到 Web 浏览器并输入以下 URL：

7. 选择 `Nessus Essentials` 作为要使用的版本（这是免费版，允许扫描多达 16 个 IP 地址）。
8. 输入您的详细信息，然后选择 E-mail（电子邮件）。
9. 检查电子邮件以获取激活码，然后将其输入 `Nessus`。
10. 使用以下详细信息创建 `Nessus` 用户账户：

![Image](p0807-04.jpg)

11. 插件随后将在系统上下载并编译。每个插件用于检查不同类型的漏洞。此步骤将花费一些时间。
12. 插件下载并编译完成后，您将进入 `Nessus` 欢迎屏幕。选择 Close（关闭）。
13. 创建一个新的高级扫描，扫描您的 Windows Server 的 IP 地址。
14. 确保启用了所有插件。每个插件在扫描期间检查特定类型的漏洞。请注意列表底部的 Windows 插件。
15. 保存扫描设置。
16. 查看扫描列表，启动新创建的扫描。
17. 扫描将花费一些时间，完成后，查看结果以识别系统的漏洞。
