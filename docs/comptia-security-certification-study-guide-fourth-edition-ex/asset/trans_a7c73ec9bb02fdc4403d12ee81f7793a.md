

# 基于角色的培训

基于角色的培训涉及根据员工的工作角色为其设计培训计划。例如，业务用户将学习密码最佳实践、网络钓鱼攻击和安全上网习惯，而 IT 团队将学习如何配置公司防火墙。

## 用户习惯

在对员工进行安全最佳实践培训时，你应该关注多个领域。本节列出了一些你需要教育用户了解的常见要点。

### 密码行为

谈到良好的密码最佳实践时，要教育用户了解强密码的重要性，以及简单密码可能在几秒钟内被破解的事实。解释说，强密码是指至少包含八个字符、大小写字母混合，并包含数字和/或符号的密码。

确保用户不使用易于猜测的密码，也不将密码记录下来。这一点应在密码策略中明确规定。此外，确保用户不与他人共享密码，并定期更改密码，以帮助防止被盗账号被长期利用。最后，用户不应对其他账户使用相同的密码，因为如果某个账户的密码被黑客破解，黑客就能访问所有账户。这适用于用于登录网站的账户。例如，用户的银行账户、`Outlook.com`、Gmail 和 Facebook 账户不应使用相同的密码，因为一旦密码被破解，黑客就能进入所有这些账户。

### 数据处理

用户还应接受关于安全处理数据方法的教育。保存在可移动驱动器上的数据应以加密格式存储，这样如果可移动介质落入他人之手，数据也能受到保护。应制定相关策略，规定业务中允许使用哪些类型的可移动介质，以及允许在该介质上存储哪些类型的信息。你必须确保用户阅读该策略并理解此类介质的使用条款。

务必教育用户正确销毁数据。教育用户仅从驱动器中删除文件并不会从磁盘中移除数据，员工必须遵循设备安全处置策略来处理任何设备。

教育用户正确销毁数据的硬拷贝（纸质打印件），并确保所有用户都能使用碎纸机，在不再需要敏感硬拷贝文档时将其粉碎。一些公司可能会付费购买碎纸服务，公司将所有待粉碎的文件放入`安全碎纸箱`。碎纸公司会上门粉碎材料——员工只需将敏感文档放入碎纸箱即可。教育用户了解黑客会进行`垃圾箱翻找`，即他们会翻垃圾试图寻找敏感信息，这就是为什么文档需要粉碎的原因。

### 清洁桌面策略

许多组织实施`清洁桌面策略`，要求用户确保任何敏感文档始终存放在安全位置，而不留在桌面上显而易见的地方。重要的是要向员工强调不遵守清洁桌面策略的后果，并务必在晚上进行定期检查，走遍办公室查看是否有人将敏感文档遗留在显眼处。

在高安全环境中，清洁桌面策略的另一个方面是确保文档存放在上锁的柜子中，以及手机等设备在不使用时存放在上锁的抽屉或文件柜中。

### 尾随和搭便车

`尾随和搭便车`是入侵者用来绕过公司物理安全控制的方法。尾随是指入侵者等待授权人员使用刷卡或密码打开门，然后在授权人员*不知情*的情况下紧跟其后穿过敞开的门。搭便车是指入侵者在授权人员*知情*的情况下溜过门。

为帮助防止尾随，组织可以使用旋转门或`人员闸`。人员闸是两扇联锁门之间的一个区域，人员必须等待第一扇门完全关闭后，第二扇门才会打开以允许进入大楼。保安可以监控人员闸，确保每次只有一人进入。教育员工如果有人试图通过敞开的门尾随或搭便车该怎么办。大多数公司要求员工如果有人在入口处徘徊不要开门，并确保进出大楼后门完全关闭。

### 个人拥有的设备

你应确保安全策略和 AUP（可接受使用策略）涵盖公司关于将个人拥有的设备用于业务用途或在公司网络和设施内使用的政策。这被称为`自带设备 (BYOD)`策略。安全最佳实践是不允许使用个人拥有的设备，因为如果设备不属于公司，公司无权搜查或监控其活动。出于这个原因，最稳妥的做法是直接规定不允许将个人设备用于工作相关目的。

## 新威胁和安全趋势

确保你的培训和意识计划涵盖这样一个事实：每天都会出现新病毒，员工应确保其家用和工作用电脑的病毒定义始终保持最新。确保公司有办法通知员工新的病毒威胁，以便所有员工立即知晓威胁。

确保员工了解常见威胁，如网络钓鱼攻击。`网络钓鱼攻击`是指员工收到一封电子邮件，要求他们点击提供的链接访问某个网站。这通常是一封伪造的电子邮件，看起来像来自你的银行，要求你点击提供的链接以验证你的银行账户未被篡改。告知员工此类威胁，并告诉他们删除该邮件，不要点击提供的链接。

还要教育员工了解`零日漏洞利用`，这是针对新发现的、软硬件供应商尚不知情的漏洞的攻击。问题在于，如果供应商不知道漏洞利用的存在，他们就没有修复补丁。重要的是要教育用户，黑客总在想出新方法利用系统，因此用户在日常思维中需要以安全为中心。

## 社交网络和 P2P 程序的使用

关于员工日常电脑使用的主要安全顾虑之一，是他们在家里、办公室或公司笔记本电脑上的上网习惯。两个关注领域是社交网站和允许用户下载音乐、电影和软件的点对点 (P2P) 程序。社交媒体和 P2P 下载都可能成为病毒传播到用户系统的途径。

公司可能会执行`社交媒体分析`，以查看员工是否在社交媒体上泄露了关于工作的敏感信息。这可能只是简单地拍一张他们在办公桌前的照片，而桌面上打开的机密文件如果有人放大照片就能被看到。公司也可能监控社交媒体上关于公司的负面帖子。
