## 为网站启用 SSL

在本练习中，您将通过创建证书请求并将该请求提交给 Windows CA，在网站上启用 SSL。然后将证书分配给网站，以加密客户端与 Web 服务器之间的通信。

### 创建证书请求

请遵循以下步骤创建证书请求，该请求将发送给 CA：

1. 确保 Windows 10 VM 和 ServerA VM 正在运行。
2. 在 ServerA VM 上，从服务器管理器中选择“工具”|“Internet Information Services (IIS) 管理器”。
3. 在左侧选择 ServerA 节点（如果弹出询问是否开始使用 Web 平台的窗口，请选择“否”），然后在功能视图中向下滚动，直到在 IIS 部分找到“服务器证书”。双击“服务器证书”。
4. 在右侧的“操作”窗格中，选择“创建证书请求”。
5. 在“可分辨名称属性”屏幕中键入以下信息，然后单击“下一步”：
   - **常用名称** `www.certworld.loc`。注意：请务必将此名称添加到 DNS 中。常用名称应为用户在浏览器地址栏中输入以访问网站的 URL。如果用户用于访问站点的地址与此常用名称不同，用户将收到一条警告消息，提示名称不匹配。
   - **组织** Certification World Fake Company
   - **组织单位** IT Support
   - **城市/地区** Toronto
   - **州/省** ON
   - **国家/地区** CA

![Images](f0572-01.jpg)

6. 在“加密服务提供程序属性”屏幕上单击“下一步”。
7. 将 `c:\certreq.txt` 作为请求的文件名，然后单击“完成”。

### 将证书请求提交给 CA

使用以下步骤将请求提交给 CA。（在本示例中，网站和 CA 是同一系统，但在实际环境中它们将是不同的系统。）

8. 在 ServerA VM 上，启动 Web 浏览器并键入 `http://10.0.0.1/certsrv/` 以将证书请求发送给 CA。
9. 使用管理员用户名和密码登录。
10. 选择“请求证书”链接。
11. 选择“高级证书请求”链接以请求 Web 服务器证书。
12. 选择第二个链接以提交证书请求文件（标记为“使用 base-64 编码的 CMC 或 PKCS #10 文件提交证书请求，或使用 base-64 编码的 PKCS #7 文件提交续订请求”）。
13. 打开请求文件 (`c:\certreq.txt`)，复制并粘贴其内容到“已保存的请求”下方出现的文本框中。

![Images](f0573-01.jpg)

14. 在“证书模板”下拉列表中，选择“Web 服务器”。然后单击“提交”。不要关闭网页。

### 从 CA 下载已颁发的证书

单击“提交”按钮后，证书将被创建并准备好供下载。

15. 要下载证书，请单击“下载证书”链接。这是颁发给您的证书。下载后，您可以将其应用到网站。单击下载链接后，系统会提示您保存文件。正在保存的文件的扩展名是什么？ _______________
16. 将其保存到 C: 盘根目录，使用默认名称 `certnew.cer`。

### 在服务器上安装证书并将证书应用到您的网站

17. 在 ServerA VM 上，启动 Internet Information Services (IIS) 管理器，然后在左侧选择 ServerA。
18. 在右侧的功能视图中，向下滚动找到“服务器证书”图标，然后双击它以在服务器上安装证书。
19. 在右侧的“操作”窗格中，选择“完成证书请求”。
20. 在“完成证书请求”屏幕中，浏览至 `c:\certnew.cer` 作为要安装的证书的文件名。为证书指定友好名称为 `Webserver Certificate`，证书存储为 `Personal`。单击“确定”。
21. 现在要将证书与网站关联，请在左侧展开“站点”以找到“默认网站”。右键单击“默认网站”并选择“编辑绑定”。
22. 在“站点绑定”对话框中，单击“添加”以添加绑定。
23. 在“添加站点绑定”对话框中，选择 https 作为绑定类型，然后填写主机名 `www.certworld.loc`。在对话框底部，选择“Webserver Certificate”以配置 SSL。

![Images](f0574-01.jpg)

24. 单击“确定”，然后单击“关闭”。

### 强制使用 SSL

现在您已将证书应用到站点，假设用户在浏览器地址栏输入 URL 时使用 https 而不是 http，客户端和服务器之间的流量将被加密。用户仍可选择通过 HTTP 连接到站点。请遵循以下步骤配置站点，使其只能通过 HTTPS 访问：

25. 在左侧选中“默认网站”，在功能视图中双击“SSL 设置”。
26. 勾选“要求 SSL”复选框，然后单击右侧的“应用”链接。
27. 单击“确定”退出各个对话框。

## 管理 PKI

在实施和维护 PKI 环境时，您需要执行许多任务。如何执行这些任务将取决于您使用的软件。以下部分提供了执行这些管理功能的一般思路。

### 吊销证书

如前所述，在任何时间点，如果 CA 确定证书是以欺诈方式获得的，或者证书涉及安全泄露，CA 都可以吊销该证书。可以执行以下步骤来吊销证书：

1. 从服务器管理器中，选择“工具”|“证书颁发机构”。
2. 选择“已颁发证书”文件夹。
3. 右键单击要吊销的证书，然后选择“所有任务”|“吊销证书”（请参见 [图 13-5](#ch13.xhtml#ch13fig5)）。
4. 从下拉列表中选择吊销证书的原因，然后单击“是”。

![Image](f0575-01.jpg)

### 发布 CRL

证书被吊销后，CA 可以将 CRL 发布到分发点，以便应用程序检查 CRL。请遵循以下步骤将 CRL 发布到分发点：

1. 在“证书颁发机构”控制台中，右键单击“已吊销证书”，然后选择“所有任务”|“发布”。
2. 选择要发布的 CRL 类型：
   - **新 CRL** 选择此项以发布 CRL 的新完整版本。
   - **增量 CRL** 选择此项以仅发布对现有 CRL 的更新。
3. 单击“确定”。

CRL 将被发布到指定为服务器设置的分发点。请遵循以下步骤验证或修改分发点的位置：

1. 在“证书颁发机构”控制台中，右键单击服务器并选择“属性”。
2. 选择“扩展”选项卡。
