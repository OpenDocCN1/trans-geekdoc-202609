**在 Linux 中配置 TCP 包装器**

在本练习中，您将通过控制对 FTP 服务器的访问，练习在 Linux 中配置 TCP 包装器。

1.  通过输入 `ftp <IP_of_Linux>` 确保您可以连接到 Linux 上的 FTP 服务器。

2.  使用用户名 `ftp` 且无密码登录。成功登录后，输入 `quit` 退出 FTP 会话。

3.  要拒绝任何人连接到 Linux 上的 FTP 服务，请打开 `/etc/hosts.deny` 文件并添加一行新设置 `vsftpd : ALL`。尝试连接到 Linux 上 FTP 服务的每个人都应该收到“connection refused”（连接被拒绝）消息。

4.  修改 `/etc/hosts.allow` 文件，通过添加以下行将您的 IP 地址添加为可以连接到 FTP 服务的系统：`vsftpd : <your_ip>`。

5.  通过输入 `ftp <IP_of_Linux>` 并使用用户名 `ftp` 且无密码登录，确保您可以 ftp 连接到 Linux 服务器。

### 基于主机的 IDS 和基于主机的 IPS

配置系统安全的另一部分是在系统上安装并配置*基于主机的入侵检测系统 (HIDS)* 或*基于主机的入侵防御系统 (HIPS)*。基于主机的 IDS 负责监控系统上的活动，并针对任何可疑活动向您发出警报；而基于主机的 IPS 监控可疑活动，然后采取纠正措施，例如将系统锁定或禁用网络通信。关于 HIDS/HIPS 要记住的关键点是，它仅监控安装了该软件的系统上的活动。如果您想监控五个不同系统上的活动，则需要在每个系统上安装 HIDS/HIPS。

HIDS/HIPS 软件通过查看系统的不同区域来监控可疑更改。以下是 HIDS/HIPS 监控的一些关键区域：

- **内存** HIDS/HIPS 可以监控内存区域，并监视在系统上执行的可疑程序。
- **系统文件** HIDS/HIPS 可以对系统文件生成哈希值并将其存储在数据库中。当访问或执行系统文件时，HIDS/HIPS 可以计算该文件的新哈希值，并将其与数据库中存储的值进行比较，以确定文件是否被篡改。
- **日志文件** 许多应用程序将活动记录到日志文件中，HIDS/HIPS 可以读取这些文件以查找可疑活动。
- **文件系统** HIDS/HIPS 可以监控文件的多种更改，例如权限、所有者、文件大小和最后访问时间的更改。
- **连接** HIDS/HIPS 可以监控到系统的连接，并查找未经授权的连接，甚至针对系统的端口扫描。

您将在[第 19 章](#ch19.xhtml#ch19)中了解更多关于监控和审计的内容，但请理解，HIDS/HIPS 可以通过分析日志文件中发生的事件，或通过捕获正常活动的*基线*来检测可疑流量，任何异常（偏离正常活动）均被视为可疑。

### 考试内幕

**监控加密流量**

对于认证考试，请记住基于网络的 IDS (NIDS) 的一个局限性是：如果您正在加密网络流量，NIDS 将无法根据其认为可疑的内容分析该流量，因为 NIDS 无法解读该信息。

HIDS 是安装在系统上的软件，因此它可以监控涉及与该系统进行加密通信的活动。运行 HIDS 软件的系统会解密加密通信，然后记录活动；HIDS 只需查看系统上的未加密日志即可识别可疑活动。

您将在下一章了解另一种类型的入侵检测系统——基于网络的 IDS (NIDS)。NIDS 通过分析网络流量并将其与识别可疑流量的特征码进行比较，来识别可疑活动。关于 HIDS 与 NIDS 相比要记住的关键点是：如果网络流量被加密，NIDS 将无法检测可疑流量。使用 HIDS 的一个强项是，无论网络流量是否加密都无关紧要，因为 HIDS 不会查看那里来识别问题。

### 补丁管理

安装在我们计算机上的应用程序和操作系统是由人类开发的，因此极有可能在拥有优秀功能的同时，也被编程进了一些错误。这些程序代码中的错误（称为漏洞）可能被个人发现并利用，从而接管您的系统或网络。这被称为网络攻击或系统攻击，具体取决于整个网络被接管还是仅单个系统被接管。

软件和操作系统制造商始终在寻找其代码中的漏洞。他们修复这些错误，并以修复程序、补丁或更新的形式发布修正。通过此过程可以防止许多网络攻击。您通常会通过制造商的网站获取这些修复程序和更新。例如，Microsoft 操作系统具有 Windows Update 功能，该功能会访问 Microsoft 的更新网站并扫描您的系统以查找需要安装的任何更新。可以通过右键单击“开始”菜单并选择“控制面板”|“系统和安全”|“Windows Update”来运行此 Windows Update 功能。Windows Update 确定系统所需的更新后，您的系统将从 Windows Update 站点下载这些更新（请参见[图 7-9](#ch07.xhtml#ch7fig9)）。
