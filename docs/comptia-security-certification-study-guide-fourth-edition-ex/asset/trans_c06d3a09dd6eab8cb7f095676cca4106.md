

# 术语表

## A

**ARP**  
*请参阅* [地址解析协议](#ch23_glossary.xhtml#glos16)。

**arp**  
一种 TCP/IP 命令行实用程序，用于操作系统上的 ARP 缓存。

**array controller**  
一种接口卡，连接 RAID 解决方案中的所有驱动器，并提供硬件级容错能力。

**ASCII**  
*请参阅* [美国信息交换标准代码](#ch23_glossary.xhtml#glos18)。

**asymmetric encryption**  
一种加密方案，使用用户的公钥加密数据，使用用户的私钥解密数据。

**attribute-based access control (ABAC)**  
基于用户账户的特征授予访问权限。

**attributes**  
文件的特征。文件可被指定不同的文件系统属性或文件系统特征，如只读、系统、隐藏和存档。

**authentication**  
向系统证明您的身份，以便访问资源。

**authentication factor**  
代表您用于向系统进行身份验证的方法——您知道的某事、您拥有的某物、您本身的特征、您所在的位置，或您执行的某项操作。

## B

**back door**  
黑客用于获取系统未授权访问权限的方法。此后门可能因系统漏洞而存在，或因先前的攻击被植入而产生。

**backbone**  
互联网络的主干缆线。

**backup**  
将文件保存到单独位置（通常是脱机存储位置，如磁带）的过程。

**backup set**  
为单次备份操作而选定的一组文件、目录或磁盘。

**bandwidth**  
介质可传输的数据量。带宽通常以比特每秒 (bps) 为单位进行测量。

**baseline**  
系统或网络在正常运行条件下的快照，用作衡量未来异常情况的标尺。

**binary**  
用一组零和一表示的任何值。

**binding**  
将不同层级的网络组件链接起来，以实现这些组件之间的通信。例如，将协议绑定到网络适配器，允许网络适配器使用该协议进行通信。

**bit order**  
计算机跨网络传输二进制数的顺序。计算机在跨网络传输二进制数时，可以从任一端开始。

**boot partition**  
包含操作系统文件的 Windows 分区。

**bootup**  
计算机通电时执行的过程。启动过程包括初始化硬件的文件和操作系统的启动。

**bottleneck**  
导致系统性能不足的系统拥塞点。

**bridge**  
一种 OSI 第 2 层硬件设备，用于连接相同或不同拓扑结构的两个 LAN 网段。网桥检查网络数据包的目标和源 MAC 地址，并决定是否将该数据包传递给 LAN 网段。网桥可用于过滤本地子网的流量，防止其传递到不必要的 LAN 网段。

**bring your own device (BYOD)**  
一种允许员工将其个人移动设备连接到网络以执行工作职责的模式。

**broadcast**  
发送给网络上所有系统的数据包。

**broadcast domain**  
一组可以接收彼此广播消息的系统。

**broadcast storm**  
当网络上存在过多广播数据包，导致网络带宽容量接近或达到饱和时发生。

**browser**  
(1) 一种使用 HTTP 访问 URL 并下载和显示网页（通常用 HTML 编写的文档）的应用程序。(2) 一台维护网络服务器集中列表的计算机。

**buffer space**  
RAM 中预留的一部分，为传入和传出数据的存储提供空间。

**bulk encryption key**  
*请参阅* [密钥加密法](#ch23_glossary.xhtml#glos327)。

**BYOD**  
*请参阅* [自带设备](#ch23_glossary.xhtml#glos44)。

**byte order**  
计算机跨网络传输由两个或更多字节组成的较大二进制数的顺序。计算机在跨网络传输一组字节时，可以从任一端开始。*另请参阅* [位顺序](#ch23_glossary.xhtml#glos39)。

## C

**CAT3 cable**  
电话网络中使用的语音级电缆。可用于高达 10 Mbps 的网络。CAT3 是一种支持联网的电缆等级，但 CAT5 是更好的选择。CAT3 的关键在于它已存在于大多数办公楼和家庭中。

**CAT5 cable**  
一种 UTP 电缆标准，支持高达 100 Mbps 的数据传输。当今网络中的大多数 UTP 电缆均为 CAT5。

**CAT5e cable**  
一种更新型的 CAT5，传输速率可达 1 Gbps。

**CAT6 cable**  
一种更新型的 UTP 电缆，传输速率可高达 10 Gbps。

**catalog**  
描述存储在磁带上的备份集的信息集合。

**cell**  
在无线网络中，指从发射器延伸出的无线电信号覆盖范围。

**certificate revocation list (CRL)**  
由证书颁发机构 (CA) 吊销的证书列表。

**Challenge Handshake Authentication Protocol (CHAP)**  
一种使用加密算法传递身份验证数据以防止被黑客窃取的身份验证协议。由于 CHAP 比 PAP 安全得多，因此目前在 Internet 上广泛使用。*另请参阅* 密码身份验证协议。

**checksum**  
通过算法发送数据生成的结果，用于证明数据未被篡改。

**checksumming**  
一种错误检查形式，将数据通过算法运行得出一个结果（称为校验和）。校验和随数据一起发送，接收端系统用相同算法计算校验和。计算出的校验和与随数据包发送的校验和进行比较——如果两者相同，则数据未被篡改。

**class A IP address**  
支持 1600 万主机的地址类别，其第一个八位字节范围在 1 到 126 之间。

**class B IP address**  
支持 65,534 台主机的地址类别，其第一个八位字节范围在 128 到 191 之间。

**class C IP address**  
支持 254 台主机的地址类别，其第一个八位字节范围在 192 到 223 之间。

**class D IP address**  
用于多播应用程序的地址类别。D 类地址范围在 224.0.0.0 到 239.255.255.255 之间。

**class E IP address**  
保留供将来使用的实验性地址块中的地址类别。E 类地址范围在 240.0.0.0 到 254.255.255.255 之间。

**client**  
(1) 客户端/服务器模型中访问资源的工作站。(2) 为各种网络服务启用通信的软件。(3) 访问网络资源的计算机。

**coaxial (or coax) cable**  
一种电缆类型，其中央有一根芯线（实心导线），周围包裹着绝缘层。*另请参阅* [双绞线电缆](#ch23_glossary.xhtml#glos379) *和* [光纤电缆](#ch23_glossary.xhtml#glos140)。

**collision domain**  
一组其数据可能相互冲突的系统。发生冲突的数据通常因损坏而必须重传。

**command line**  
一种计算机应用程序的字符模式界面，依靠命令而非图形界面来处理信息。

**compression**  
一种分析计算机文件以将其压缩至较小尺寸的数学技术。大多数备份系统和许多文件服务器都会压缩文件，以提供更大的存储容量。

**computer virus**  
一种旨在破坏或损毁计算机或网络的计算机程序。
