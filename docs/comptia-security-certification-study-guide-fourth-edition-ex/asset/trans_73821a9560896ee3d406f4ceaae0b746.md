## 练习 17-1

### 执行定性风险分析

在本练习中，您将识别组织内的几个资产，并通过识别针对资产的示例威胁，然后基于定性方法计算风险来执行风险评估。

1. 在一张纸上，或使用您喜欢的文字处理器，识别组织内的三个不同资产。
2. 针对每个资产识别三到四个威胁。
3. 使用 [表 17-1](#ch17.xhtml#ch17tab1) 中显示的概率等级，记录每个威胁的概率值。
4. 使用 [表 17-2](#ch17.xhtml#ch17tab2) 中显示的影响等级，记录每个威胁将产生的影响。
5. 根据公式 `risk = probability × loss (impact)` 计算风险，然后根据风险最高者优先级最高来确定威胁的优先级。

## 定量

另一种风险分析类型是定量分析。定性分析的缺点是您使用别人创建的等级来判断威胁的严重性，而严重性取决于执行评估的人的观点。

通过定量分析，您可以计算每个风险的美元金额以及威胁的影响。这是一种关键的评估类型，因为高层管理人员希望看到美元数字，以证明购买安全控制措施以保护资产的成本是合理的。例如，通过定量分析，如果您说：“该威胁每年将花费我们 1,400 美元，因此我们应该购买一款每年花费 6,500 美元、为期三年的防火墙解决方案”，管理层很可能会让您寻找更便宜的解决方案。

定量分析的第一步是评估资产的价值。例如，您可能确定您的电子商务网站每天带来数千美元的收入——这将帮助您计算资产的价值。

一旦知道了资产的价值，您必须确定每个针对该资产的威胁将产生的影响。在定量分析中，影响被指定为*暴露因子 (EF)*，即如果威胁发生，资产价值损失的百分比。

一旦知道了资产的价值并为每个威胁关联了暴露因子，您就可以计算所谓的*单次损失期望值 (SLE)*，这是一个美元数字，代表公司每次威胁发生时将损失多少钱。以下是单次损失期望值的公式：

```
SLE = value ($) × EF (%)
```

例如，假设您确定电子商务网站的价值为 200,000 美元，每次 Web 服务器发生硬盘故障时，您会损失 8% 的*资产价值*。这意味着您的单次损失期望值是 200,000 美元 × .08，即 16,000 美元。因此，服务器每发生一次硬盘故障，您的业务就会损失 16,000 美元！

![Image](exam.jpg)

**针对 Security+ 考试，请记住如何计算单次损失期望值：`SLE = 资产价值 × 暴露因子`。**

一旦计算出单次损失期望值，您就可以着手计算*年化损失期望值 (ALE)*，这是计算您每年因每个威胁将损失多少钱的计算。计算年化损失期望值的公式是获取单次损失期望值并将其乘以*年化发生率 (ARO)*。年化发生率是您预计威胁一年内发生的次数。

```
ALE = SLE × ARO
```

例如，您可能预计威胁一年发生三次，或每五年发生一次。以下示例计算如果硬盘故障威胁一年发生三次的 ALE：

```
ALE = $16,000 × 3
```

这意味着基于硬盘一年故障三次的 ALE 将使公司花费 48,000 美元。您需要确保实施的保护硬盘故障的解决方案每年的成本不超过 48,000 美元。

![Image](exam.jpg)

**针对认证考试，请记住年化损失期望值是通过 `SLE × 年化发生率` 计算的。**

让我们看一个不同的 ARO。如果预计硬盘故障威胁每五年发生一次，那么您的 ARO 将是 1/5，即 .20。这意味着计算年化损失期望值的公式将是

```
ALE = $16,000 × .20
```

这导致 ALE 为 3,200 美元。因此，您需要找到一种保护资产的安全解决方案，其成本每年不超过 3,200 美元。

定量分析的优势在于您计算的是确切的美元数字，这正是管理层所喜欢的，因为很容易看出实施解决方案在财务上是否合理。定量分析的缺点是计算这些数字所需的时间；例如，给资产定价很困难，因为涉及太多变量。

![Image](exam.jpg)

**定量风险分析的优势在于您能够根据安全控制措施在财务上是否值得而做出明智的决策。**
