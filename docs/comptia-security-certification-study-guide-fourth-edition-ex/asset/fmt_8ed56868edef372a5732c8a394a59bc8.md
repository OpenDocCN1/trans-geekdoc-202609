
# 术语表

**unshielded twisted-pair (UTP)**   一种双绞线电缆，其导线与外层绝缘层之间没有任何屏蔽层。

**UPS**   *参见* [uninterruptible power supply](#ch23_glossary.xhtml#glos384)。

**URL**   *参见* [Uniform Resource Locator](#ch23_glossary.xhtml#glos383)。

**user**   访问网络的任何人员。

**user account**   代表访问计算机或网络资源的用户。用户账户不一定代表个人；也可以是服务账户，例如 SQL Server 账户。

**User Datagram Protocol (UDP)**   提供无连接的数据报服务，属于不可靠的“尽力而为”交付。UDP 不保证数据报的到达，也不保证交付的数据包顺序正确。不需要数据接收确认的应用程序使用 UDP。

**user mode**   也称为非特权处理器模式。这是运行应用程序和各种子系统的模式。用户模式旨在防止应用程序导致操作系统崩溃。

**user right**   允许用户在计算机上执行特定操作。您可以设置用户权利来控制用户或组执行的操作。某些厂商可能使用“系统特权”这一术语。

**username**   用户用于登录计算机系统的名称。

**UTP**   *参见* [unshielded twisted-pair](#ch23_glossary.xhtml#glos387)。

**virtual local area network (VLAN)**   创建一小组 PC，使它们仅在较大的网络中相互通信。这可以通过指定 PC 连接的交换机端口来实现。

**virtual machine**   由虚拟化软件（Hypervisor）提供的模拟计算机，可运行 Windows Server、Windows 客户端和 Linux 等操作系统。

**virtual memory**   由 Windows 创建，当需要更多内存时，在计算机上模拟 RAM。它通过按需使用计算机的硬盘来实现。

**virtual private network (VPN)**   通过公共网络提供隧道传输，并建立安全的通信通道。VPN 使用 L2TP 和 SSTP 等协议，在隧道创建后加密客户端与服务器之间的通信。

**virus**   对系统造成危害的恶意代码。

**virus signature file**   已知病毒的数据库，防病毒软件在扫描文件以清除病毒时会使用该数据库。病毒特征码文件必须保持最新。

**VLAN**   *参见* [virtual local area network](#ch23_glossary.xhtml#glos397)。

**volume**   物理驱动器上空间的逻辑划分，被视为单个单元处理。卷是用于存储信息的硬盘的一部分。

**volume sets**   将不同大小的空闲空间区域组合为单个卷（驱动器号），支持任何类型的硬盘（IDE、SCSI 或 ESDI）。卷集不提供任何容错或性能提升。它们仅用于将多个空闲空间区域组合为单个卷。

**VPN**   *参见* [virtual private network](#ch23_glossary.xhtml#glos400)。

**vulnerability testing**   一种安全测试，涉及运行一段软件以检查系统配置中的弱点。

**WAP**   *参见* [wireless access point](#ch23_glossary.xhtml#glos415)。

**well-known ports**   *参见* [port number](#ch23_glossary.xhtml#glos290)。

**whaling**   针对极其重要人物（如公司 CEO）的网络钓鱼攻击。

**Wi-Fi Protected Access (WPA)**   一种无线安全协议，旨在加密无线通信并提供身份验证服务。

**Wi-Fi Protected Access 2 (WPA2)**   一种取代了 WPA 的无线安全协议，旨在加密无线通信并提供身份验证服务。WPA2 改进为使用更安全的 AES 对称协议。

**Windows Update**   一项服务，您可以连接到该服务并查看系统的可用更新。您也可以从系统安装这些更新。

**Wired Equivalent Privacy (WEP)**   一种旧的无线安全协议，使用对称密钥加密无线通信。WEP 已弃用，并被 WPA2 取代。

**wireless access point (WAP)**   一种网络设备，允许无线客户端连接到无线网络。无线客户端连接到接入点，并通过接入点将数据发送给网络上的其他主机。

**wireless local area network (WLAN)**   允许系统使用无线连接进行通信的网络。

**wireless networking**   配置为使用红外线、蜂窝或微波等通信技术的网络，因此不需要电缆连接。

**workgroup**   一组计算机，其中每台计算机都单独管理。

**workstation**   用于访问网络的客户端计算机。

**zero-day exploit**   针对软件或硬件的漏洞利用，该漏洞对制造商未知，且尚不存在安全补丁。
