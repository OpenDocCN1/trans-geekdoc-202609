
# 卸载不必要的操作系统组件

卸载任何不打算使用的软件应用程序后，接下来应专注于移除不会被使用的操作系统组件。例如，在 Windows 2000 Server 时代，Microsoft 默认安装了其 Web 服务器软件 Internet Information Services (IIS)。这造成了巨大的安全问题，因为 IIS 存在多个漏洞，如目录遍历和缓冲区溢出漏洞。如果网络管理员卸载了 IIS，那些攻击就不会在该服务器上生效。

要在 Windows 客户端或 Windows Server 中卸载不使用的操作系统功能，请执行以下步骤：

1. 在 Windows 客户端系统上，在“开始”菜单中输入 `control panel`，然后从搜索结果中选择“控制面板”。
2. 在“控制面板”中，单击“程序”（请参阅 [图 6-2](#ch06.xhtml#ch6fig2)）。
3. 选择“启用或关闭 Windows 功能”。这将打开“Windows 功能”对话框，您可以在其中启用和禁用不同的 Windows 功能。
4. 要在 Windows Server 操作系统上添加/删除功能，请选择“开始”按钮并单击“服务器管理器”图标。这将启动服务器管理器。
5. 选择“管理” \| “删除角色和功能”。
6. 连续单击两次“下一步”。
7. 系统将显示已安装角色的列表。要卸载某个角色，请取消选中该角色旁边的复选标记，然后单击“下一步”。
8. 系统将显示已安装的 Windows 功能列表。要卸载某个功能，请清除其复选框，然后单击“删除”以卸载未选中的角色和功能。

## 禁用不必要的服务

卸载所有不必要的软件后，将重点转移到系统后台运行的服务或守护进程上。每个服务为操作系统提供一项功能。例如，Windows 系统上常见的服务包括：

- **Print Spooler** 该服务负责 Windows 环境中的打印功能。
- **Workstation** 该服务允许您的系统连接到另一台系统上的共享文件夹。
- **Server** 该服务允许其他系统连接到您系统上的共享文件夹。
- **Messenger** 该服务存在于旧版 Windows 中，当有人使用 `net send` 命令时，负责向其他用户或计算机发送消息。**应禁用此服务。**
- **Remote Desktop Services** 该服务允许用户远程访问计算机并对其进行控制。

关键在于，作为负责加固系统的安全专业人员，您必须获取系统上正在运行的服务列表，然后评估每个服务是否必要。如果某项服务在单台机器上不需要，则通过 Windows 的“服务”控制台禁用该服务；要为多台机器禁用服务，可使用组策略在 Active Directory 域中集中禁用。要在 Windows 中查看服务列表，请执行以下步骤：

1. 在 Windows 系统上，选择“开始” \| “管理工具” \| “服务”。
2. 右键单击要停止的服务，然后选择“停止”。
3. 为确保服务在 Windows 下次启动时不自动运行，必须将“启动类型”设置为“禁用”。右键单击该服务并选择“属性”。这将打开“属性”对话框。
4. 将“启动类型”设置更改为“禁用”，如 [图 6-3](#ch06.xhtml#ch6fig3) 所示。

## 考试重点：理解系统加固

Security+ 认证考核您对系统加固概念和程序的掌握。请记住，系统加固是指移除不必要的软件并禁用系统上不必要的服务。这些服务可能容易受到缓冲区溢出攻击，因此运行的服务越少越好！

在加固系统时，请花时间调查正在运行的服务，并确定每个服务的作用。发现某服务的用途后，您需要决定是否需要运行该服务。请确保拥有一个测试系统，以便确定禁用该服务的结果，并确保其不会对系统产生负面影响。

请注意，禁用服务通常会关闭与该服务关联的端口。端口是由正在运行的程序或服务在系统上打开的。要关闭端口，只需禁用打开该端口的服务或结束该应用程序即可。您也可以使用防火墙阻止对该端口的访问。

## 练习 6-1：禁用 Remote Desktop Services 服务

![Images](video.jpg)

在本练习中，您将调查 Windows 中运行的远程桌面服务相关的安全风险，然后禁用该服务。

1. 确保 ServerA 和 Windows 10 虚拟机正在运行。登录到每个系统。
2. 切换到 Windows 10 虚拟机，通过右键单击“开始”按钮并选择“系统” \| “远程桌面”（最右侧），确保已启用远程桌面。
3. 在 ServerA 系统上，转到“开始”菜单，输入 `mstsc`，然后按回车键。这将启动“远程桌面连接”客户端。
4. 输入 Windows 10 系统的 IP 地址，然后单击“连接”。
5. 系统提示登录。输入管理员账户的用户名和密码，然后登录。
6. 登录后，您会发现可以控制 Windows 10 系统。单击右上角的“×”按钮，断开远程桌面会话。
7. 在 Windows 10 客户端上停止 Remote Desktop Services 服务，以确保无人能远程登录您的系统。右键单击“开始”按钮，选择“控制面板” \| “管理工具” \| “服务”。
8. 右键单击“Remote Desktop Services”服务并选择“停止”。
9. 右键单击“Remote Desktop Services”服务并选择“属性”。将“启动类型”字段设置为“禁用”，以便系统重启时该服务不自动启动。

## 保护管理接口和应用程序

在保护系统时，请确保限制对管理软件（接口）的访问。原则在于：如果管理工具对某些员工不可用，他们将无法更改系统或应用程序的配置。

您可以通过多种方式限制对系统和应用程序管理接口的访问，其中最好的方法之一是使用系统提供的策略。此外，从 Windows Vista 开始，如果登录用户没有执行特定命令的权限，Microsoft 现在会限制对这些命令的访问。此功能称为用户账户控制 (UAC)。

不要依赖某人没有某个程序——恶意用户会想办法获取该程序以进行更限制用户权限和权限也很重要。

## 禁用不必要的账户

系统加固中一个常被忽视的方面是禁用未被使用的账户。您可能不想立即删除该账户，因为可能会发现公司里有人需要该账户，或者系统上运行的某个软件可能需要该账户。请注意，Administrator 账户在 Windows 10 中默认是禁用的。

要在 Windows 中禁用账户，请执行以下步骤：

1. 在 Windows 10 或 Windows Server 中，单击“开始”按钮，然后输入 `control panel`。从搜索结果中选择“控制面板”条目。
