### 补丁管理

加固系统的关键后续步骤之一是确保为系统打补丁。当你为系统打补丁时，你会将软件修复程序应用于系统上运行的软件中的已知漏洞。软件中的这些漏洞是黑客利用以获取系统访问权限的途径。如果你不定期为系统打补丁，可以肯定的是，你的系统可能会被经验丰富的黑客攻破。

Security+ 考试需要熟悉的补丁类型包括以下内容：

- **安全热修复程序** 安全热修复程序，也称为关键更新，是一种安全更新，应尽快应用到系统中，因为该漏洞会使系统面临严重的安全风险。
- **补丁** 补丁，也称为更新，是针对软件或操作系统代码中特定问题的修复，不需要立即应用，因为其安全风险不如热修复程序所解决的风险严重。
- **服务包** 服务包提供产品的所有更新，包括从产品发布之时起直到服务包发布之时的补丁和安全热修复程序。如果你安装了服务包，就不需要单独安装每个补丁，因为服务包包含了截至该时间点的所有更新。你仍需安装服务包发布后出现的补丁和安全修复程序。

要为系统打补丁，可以从“开始”菜单中运行 `Windows Update` 程序，或使用集中式补丁管理软件（如 `Windows Server Update Services (WSUS)`）一次性将补丁部署到多个系统。作为安全专业人员，重要的是要评估补丁是如何部署到系统的，并确保该策略能让系统通过安全修复程序保持最新状态。

作为补丁部署策略的一部分，请确保网络管理员在未先测试补丁的情况下不将其应用到系统。管理员应拥有一组测试系统，优先向其部署补丁，以确保补丁不会导致业务应用程序停止工作。一旦补丁在测试系统上通过验证，应将其部署到一小部分生产系统。在验证补丁未给这小部分生产系统带来问题后，即可将补丁部署到更大范围的系统。

![Image](exam.jpg)

> **及时为系统打补丁对系统安全至关重要。保持系统已打补丁状态将有助于消除软件中通常允许黑客入侵系统的漏洞。**

打补丁时的另一个考量因素是，应用系统上已安装的其他第三方软件的任何更新。当你应用操作系统更新时，其他第三方公司的软件不会被修补，因此研究如何为系统上运行的第三方软件应用更新非常重要。

你还应考虑在操作系统和系统上运行的应用程序中启用自动更新功能。如果启用自动更新，可以降低日后忘记应用更新的风险——它们将自动应用。

### 密码保护

你应纳入系统加固程序的最后一项做法是为资产设置密码保护功能。从系统角度来看，这意味着你要确保对 `CMOS` 设置程序进行了密码保护，以防止未经授权的 `CMOS` 更改。此外，确保操作系统加载时提示输入密码。如今大多数系统都会要求输入用户名和密码（这比仅要求密码更好），但关键是要确保没有系统在启动时自动登录。

考虑对其他资源（如路由器、交换机甚至打印机）进行密码保护。大多数人不会考虑为笔记本电脑或手机等移动设备使用密码——但这些设备包含敏感的公司信息，因此在系统启动时也应对其进行密码保护。

不仅系统启动时应要求输入密码，还应确保在这些设备上遵循良好的密码实践。所有密码长度应至少为八个字符，并应混合使用大小写字母、数字和符号。此外，要确保用户没有将密码记录下来，因为别人很容易找到记录密码的纸条。

### 注册表加固

在系统加固方面，你也可以对注册表进行加固。注册表是 Windows 系统所有设置的数据库。通常，你通过“控制面板”配置系统，但也可以在 Windows 中使用 `regedit.exe` 通过注册表进行更改。如果在注册表中进行了错误的更改，可能会导致系统无法正常运行，因此只有熟悉注册表时才应进入其中。

就注册表加固而言，最重要的一点是确保只有管理员拥有对注册表关键区域进行更改的权限。例如，恶意软件可能会将自身添加到注册表的“运行”部分，该部分存放自动启动的程序。你可以修改注册表“运行”区域的权限，以确保只有管理员可以修改该部分。

在讨论注册表时，我还应提到，更改注册表可用于锁定系统，因为注册表中有许多设置在“控制面板”中找不到。以下是关于使用注册表的一些要点：

- `Regedit.exe` 是我们用来修改注册表的工具。
- 你可以右键单击注册表的某个区域，然后选择“权限”命令来修改该区域的权限。
- 你可以使用 `regedit.exe /E` 命令将注册表中的设置导出到 `.reg` 文件。
- 你可以使用 `regedit.exe <filename.reg>` 命令导入注册表设置文件。这是一种确保注册表自定义设置轻松部署到多个系统的绝佳方法。

### 磁盘加密

在加固系统时，你还应考虑加固系统上的驱动器。你可以通过设置硬盘上文件和文件夹的权限来实现这一点，但据发现，如果攻击者能够启动到备用操作系统并访问驱动器，他们可以绕过这些权限。因此，你应该考虑加密硬盘。如果加密驱动器的内容，未经授权的人员无法访问文件，除非他们拥有解密密钥——即使他们启动到了备用操作系统。
