

# 基于位置的策略

基于位置的策略是根据用户的位置来控制对资源访问的规则。访问控制系统根据连接到移动网络的用户移动设备的 GPS 坐标或基站邻近度来确定位置。管理员构建基于位置的访问控制规则，以决定是否授予访问权限。基于位置的控制的另一个示例是在 Azure 中，管理员可以根据用户的 IP 地址属于某个特定国家/地区来阻止其访问，或者要求使用多因素身份验证 (MFA)。

# 访问控制方案

当你在资源上配置访问控制时，其应用方式取决于所使用的访问控制模型。在本节中，我想讨论主要的访问控制模型，例如自主访问控制、强制访问控制、基于角色的访问控制、基于规则的访问控制、基于组的访问控制，最后是基于属性的访问控制。请务必理解本节内容，因为你将在 Security+ 认证考试中接受关于访问控制模型的测试。

## 自主访问控制

自主访问控制，也称为 DAC，是一种根据 `自主访问控制列表 (DACL)` 决定谁可以访问资源的模型。DACL 是被授予资源访问权限的用户或组（称为安全主体）的列表，并且 DACL 通常决定用户拥有哪种类型的访问权限。也就是说，DACL 是分配给文件的权限。DACL 中的每个条目称为 `访问控制条目 (ACE)`，如 [图 11-1](#ch11.xhtml#ch11fig1) 所示。

![Image](f0476-01.jpg)

**图 11-1**  
ACE 是 ACL 中的单个条目。

![Image](exam.jpg)

> **针对 Security+ 认证考试，请记住自主访问控制 (DAC) 涉及在资源上配置权限。**

在 Microsoft 环境中，每个安全主体（如用户账户、计算机账户或组）都分配有一个 `安全标识符 (SID)`。当用户登录网络时，身份验证过程的一部分是为用户生成访问令牌（这称为 `逻辑令牌`）。访问令牌包含用户账户 SID，以及用户所属组的所有 SID。

当用户尝试访问资源时，访问令牌将与 DACL 进行比较，以决定用户是否应获得对资源的访问权限（请参阅 [图 11-2](#ch11.xhtml#ch11fig2)）。

## 强制访问控制

在强制访问控制 (MAC) 模型中，每个个体（称为 `主体`）被分配一个许可级别，如机密、秘密或绝密。组织中的数据和其他资产被分配分类标签，以表示信息的敏感度。分类标签的示例包括公开、机密、秘密、绝密和非密等。

![Image](exam.jpg)

> **针对考试，请记住强制访问控制涉及员工根据其许可级别和分配给资源的数据分类标签来获取资源访问权限。**

系统根据主体的许可级别与分配给资源的分类标签是否匹配来控制谁获得资源访问权限，如 [图 11-3](#ch11.xhtml#ch11fig3) 所示。重要的是要注意，如果一个人拥有较高的许可级别，他们可以访问分配了该敏感度标签或更低敏感度标签的任何信息。

![Image](f0478-01.jpg)

**图 11-3**  
使用 MAC 时，许可级别必须等于或高于敏感度标签。

在设计 MAC 系统时，数据所有者必须决定信息的敏感度，然后将分类标签分配给该信息。组织决定在何种情况下可以更改信息的分类标签或使其成为非密也很重要。例如，当公司为新产品设计计划时，可能会决定该信息属于机密，这意味着该信息未经授权不得公开发布。但一旦产品已设计完成、售出并过时，公司是否应将产品设计文档的分类标签更改为“公开”，因为设计计划不再是机密信息？

### 考场内部

#### 查看分类标签

你在 Security+ 认证考试中肯定会遇到一些关于访问控制模型的问题，其中一两个问题将集中在强制访问控制模型上。请记住，对于考试而言，MAC 将许可级别分配给主体（个人），将敏感度标签（也称为分类标签）分配给资源（例如文件）。

在 MAC 系统中，可以分配不同的敏感度标签和许可级别。以下概述了政府组织常用的敏感度级别。请记住，拥有特定许可级别的人可以访问分配了该标签及更低级别标签的信息。例如，拥有机密许可的人可以访问机密、受限和非密信息。

- **绝密** 最高敏感度标签。如果泄露给公众，被分类为绝密的信息可能会对国家安全造成*严重损害*。
- **秘密** 第二高敏感度标签。如果泄露给公众，被分类为秘密的信息可能会对国家安全造成*严重损害*。
- **机密** 第三高敏感度标签。如果泄露给公众，被分类为机密的信息可能会对国家安全造成*损害*。
- **受限** 分配此分类标签的信息如果暴露给公众可能会导致*不良后果*。
- **非密** 任何未分配分类标签的信息均视为非密，适合公开发布。

商业部门通常使用不同的分类标签来标识信息的敏感度。以下是可分配给信息的敏感度标签和可分配给人员的许可级别的示例：

- **机密** 最高敏感度标签。如果泄露给公众，被分类为机密的信息可能会对组织造成*严重损害*。
- **私密** 第二高敏感度标签。如果泄露给公众，被分类为私密的信息可能会对组织造成*严重损害*。
- **敏感** 分配此分类标签的信息如果暴露给公众可能会导致*不良后果*。
- **公开** 分配此分类标签的信息适合公开发布。

同样，这是一个层级结构，拥有机密许可的人不仅可以访问机密数据，还可以访问任何具有较低分类（如私密、敏感和公开）的数据。

## 基于角色的访问控制

`基于角色的`访问控制 (RBAC) 采用不同于 MAC 的方法来控制对资源和特权的访问：系统向不同角色授予特殊特权。`角色` 是系统中具有预定义特权的容器对象。当你将用户放入角色时，用户将获得分配给该角色的特权或访问控制权限。
