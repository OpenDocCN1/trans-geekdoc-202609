
# 术语表

## connectionless communication
一种通信形式，目标计算机在接收到信息时不会通知源计算机。这种通信被认为是不可靠的，因为没有通知指示数据已被接收。由于跟踪已发送数据和另一端已接收数据涉及的开销，无连接通信可能比面向连接的通信更快。

## connection-oriented communication
一种通信形式，通过使用序列号和确认号确保数据从发送方可靠地传送到接收方。消息中的每一段数据都被分配一个序列号，接收方使用该号码确认数据的接收。

## cookies
存储在客户端计算机上的小文件，会自动提交给 Web 服务器进行处理。

## CRC
参见 [cyclical redundancy check](#ch23_glossary.xhtml#glos80)。

## cross-site scripting
一种基于软件的攻击，黑客将恶意脚本代码输入到字段中，使其被应用程序处理。

## cryptography
提供安全服务以保护数据的机密性和完整性，服务包括加密和哈希。

## cyclical redundancy check (CRC)
一种错误检查形式，涉及将一个字节或一组字节通过数学算法运行，以产生一个位或字节来表示数据（即 CRC）。CRC 值随数据一起传输。当数据到达目的地时，接收方通过相同的数学算法运行它。结果与原始 CRC 进行比较，如果匹配，接收计算机假定数据是正确的。如果不匹配，接收方必须丢弃数据并重试。

## daily backup
复制备份执行当天已修改的所有选定文件，且不将它们标记为已备份。

## data link layer
处理网络上帧的拆卸和重组的 OSI 层。

## data loss prevention (DLP)
防止数据泄露的一组技术。

## database management system (DBMS)
一种数据库环境，用于管理数据库，包括数据库中数据的组织、存储、安全、检索和完整性。

## datagram
由用户数据报协议（UDP）使用，一种独立的、自包含的数据片段，包含足够的信息，无需源或目标计算机的帮助即可从源计算机路由到目标计算机。网络利用数据的自包含信息来确定如何发送数据报。数据报就像一封邮政邮件。你将邮件投入邮筒，邮票和地址足以让邮政服务将邮件路由给收件人。然而，邮局可能会丢失一封邮件，且无法追踪邮件何时或在何处丢失。

## DBMS
参见 [database management system](#ch23_glossary.xhtml#glos84)。

## DDoS
参见 [distributed denial of service](#ch23_glossary.xhtml#glos106)。

## default gateway
连接到本地子网的路由器（通常），使 IP 数据包能够传递到其他网段。当客户端系统需要与其自身子网外部通信时，需要默认网关。

## demilitarized zone
两个防火墙之间的区域，公共服务器（如 Web 服务器和 DNS 服务器）应出于安全原因放置于此。

## denial of service (DoS)
一种攻击类型，黑客用大量数据包使系统过载，导致系统崩溃或忙于处理这些数据包而无法服务有效请求。

## device drivers
系统用于与系统中各种硬件组件通信的小程序。

## DHCP
参见 [Dynamic Host Configuration Protocol](#ch23_glossary.xhtml#glos118)。

## differential backup
仅备份自上次完全备份或差异备份以来已更改的文件，且不修改存档位。另请参阅 [full backup](#ch23_glossary.xhtml#glos154) 和 [incremental backup](#ch23_glossary.xhtml#glos185)。

## Diffie-Hellman Ephemeral (DHE)
TLS 用于保护通信的密钥协商协议。

## directory path
文件系统上目录的路径，可能包括服务器名称、卷名以及通向该目录的其他路径名。

## directory replication
出于容错原因，将目录数据库从一个系统复制到另一个系统的过程。

## directory service
负责维护环境中对象目录的服务。Active Directory 和 eDirectory 是目录服务的示例。

## directory synchronization
将目录数据库复制或同步到远程系统的过程。

## directory tree
包括根目录下的目录和子目录布局在内的文件结构。

## discretionary access control (DAC)
创建文件或文件夹的人是所有者并负责保护它时的访问控制。

## disk duplexing
类似于磁盘镜像，不同之处在于它使用两张磁盘控制器卡——镜像集中每个驱动器一张卡。这在其中一个控制器发生故障时提供冗余。另请参阅 [disk mirroring](#ch23_glossary.xhtml#glos102)。

## disk mirroring
通过将数据从一块硬盘镜像到另一块来提供冗余。如果活动驱动器发生崩溃或其他问题，操作系统会自动开始使用备份驱动器并通知您已切换。另请参阅 [disk duplexing](#ch23_glossary.xhtml#glos101)。

## disk striping with parity
参见 [Redundant Array of Independent (or Inexpensive) Disks](#ch23_glossary.xhtml#glos304)。

## diskless workstation
没有硬盘驱动器的工作站。无盘工作站是一个存在已久的概念。专为大型环境设计，最初有两个目标。第一是通过从最终用户移除本地存储并要求所有数据和应用程序存储在服务器上来增强网络安全。通过服务器权限管理用户对该信息的访问，LAN 管理员可以更有效地控制环境。第二个目标是大容量存储的成本。通过移除本地存储成本，特别是随着工作站数量的增加，公司可以节省资金。随着大容量存储成本的下降，这已不再是一个主要问题。

## distributed applications
在网络上的计算机之间分割处理的应用程序，例如客户端/服务器应用程序，其中处理在客户端计算机和更强大的服务器计算机之间划分。通常，运行在客户端计算机上的部分称为前端，运行在服务器计算机上的部分称为后端。

## distributed denial of service (DDoS)
一种攻击类型，黑客使用多个系统作为攻击源，以产生足够的流量使受害者系统崩溃。

## DLL
参见 [dynamic link library](#ch23_glossary.xhtml#glos119)。

## DLP
参见 [data loss prevention](#ch23_glossary.xhtml#glos83)。

## DNS
参见 [Domain Name System](#ch23_glossary.xhtml#glos112)。

## domain
包含域控制器的一组计算机，它们共享账户信息并拥有一个集中的账户数据库。（不要与 Internet 域混淆，例如 `microsoft.com`。）

## domain controller
持有 Active Directory 数据库的系统。

## Domain Name System (DNS)
一种将 IP 地址映射到完全合格域名的服务。它将主机名解析为 IP 地址，反之亦然（通过反向查找）。
