### 重复密钥

您输入软件以进行加密的大多数密钥都是单词或短语，而不是简单的数字，因此让我们看一个涉及将单词作为密钥的数学运算示例。

对于此示例，假设密钥为“bad”。当消息被加密时，密钥会在消息的整个持续时间内重复。此示例中的算法将执行以下操作：

1. 根据字母在字母表中的位置，将消息中的字符转换为数字。
2. 根据密钥中字符在字母表中的位置，将其转换为数字。
3. 将这两个数字相加以获得新值。
4. 将新值转换为字母表中对应的字母（例如，3 变为 `C`）。

让我们演示一下这个加密过程的示例，使用消息“com security”。我们去掉空格并写下消息。然后在消息的整个持续时间内重复密钥“bad”：

### 其他密码学术语

对于 Security+ 认证考试，还有其他几个重要的密码学概念需要理解。以下部分介绍这些密码学术语和概念。

#### 密钥强度/密钥长度

`密钥强度`，也称为 `密钥空间` 或 `密钥长度`，是指加密密钥中有多少位。密钥空间越大，加密效果越好。这是因为更大的密钥空间具有更多可能的值，如果有人试图破解密钥，就需要计算更多的值。例如，2 位密钥空间仅允许四个值：00、01、10 和 11。计算 2 位密钥可能拥有的所有密钥几乎不需要时间。如果您增加密钥空间到 3 位，则有八个可能的值：000、001、010、011、100、101、110 和 111。

如今常见的密钥空间有 64 位、128 位、256 位，有时甚至是 512 位。

#### 工作因子

术语 `工作因子` 是指一个表示破解加密所需时间的值。工作因子通常以时间来衡量，并且随着密钥空间的增大，其值通常也会更高。

例如，破解 64 位密钥所需的时间比破解 128 位密钥少，因此破解 64 位密钥的工作因子较低。

#### 一次性密码本

`一次性密码本 (OTP)` 是一种非常安全的加密信息方法，它涉及仅使用一次密钥。该密钥是一个随机生成的值，用于加密数据，然后永不再次使用。

使用不同密钥的好处在于，黑客是通过处理用同一密钥加密的不同数据片段来破解加密，以便逆向工程该过程并破解密钥。

#### 密码套件

不同类型的密码套件包括流密码和分组密码。`流密码` 算法一次加密一位数据。明文位被转换为加密的密文位。这种方法通常不如下文讨论的分组密码技术安全，但通常执行速度更快。此外，密文始终与原始明文大小相同，且不太容易出错。如果加密过程中发生错误，通常只会影响单个位，而不是整个字符串。相反，当分组密码包含错误时，整个分组将变得不可理解。明文位通常通过使用异或 (XOR) 函数（稍后描述）与密钥的位进行加密。

`分组密码` 算法不是一次加密一位，而是以分组为单位加密数据。分组密码比流密码具有更多开销。此开销单独提供，取决于实现和可修改的分组大小（最常见的大小是 64 位）。因为分组密码在更高层级处理加密，所以通常更安全。缺点是执行时间较长。
