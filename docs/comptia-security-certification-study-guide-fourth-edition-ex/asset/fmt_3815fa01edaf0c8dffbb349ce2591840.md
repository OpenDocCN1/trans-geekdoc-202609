### SNMP

The Simple Network Management Protocol (SNMP) has been the standard management and monitoring protocol for devices for many years. It can be used to collect detailed information about a device's running status, such as memory utilization, processor utilization, and the number of users connected. It can also collect information on the configuration and settings of the device. In order to use SNMP to monitor or manage a device, the device must have SNMP support, which most routers, switches, and printers do.

Administrators use an SNMP application to connect to a device running SNMP in order to retrieve information about the device. From a security point of view, you want to ensure that you are running SNMPv3 on your devices because it is the most secure version of SNMP to date. SNMPv1 had little to no security and sent usernames and passwords in clear text. SNMPv2 improved upon the security, but SNMPv3 is the most secure with encryption of credentials and use of security models to configure policies.

### Protocol Analyzer and Sniffer

A protocol analyzer, or network sniffer, is a great network monitoring tool that allows you to capture and review the network traffic. The two are typically one and the same, except that a protocol analyzer may be geared toward a specific protocol, whereas a network sniffer analyzes all network traffic no matter the network protocol being used.

Of the network sniffers you can use, the more popular ones are Wireshark and Microsoft Network Monitor. Wireshark is a free download from [www.wireshark.org](http://www.wireshark.org) and can be installed on many different platforms (such as Windows and Linux). The last version of Network Monitor was version 3.4 before Microsoft stopped development on it.
