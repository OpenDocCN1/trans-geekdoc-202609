

# 木马病毒故障排除

在结束木马病毒话题之前，我想介绍一些常用的 Windows 命令，如果你怀疑自己已被感染，可以使用这些命令来追踪木马病毒。这里的目标是结束打开端口的程序，从而关闭该端口。

用于追踪木马病毒的第一个命令是 `netstat` 命令。如果你使用 `netstat -na` 命令，将会看到处于侦听状态的本地端口列表。*侦听* 意味着端口处于打开状态，正在等待有人连接，这与当时实际已有人连接的情况不同。

要找出是哪个程序打开了端口，可以向 `netstat` 添加 `-o` 开关，这将显示打开该端口的程序的进程 ID (PID) 编号。在 [图 5-2](#ch05.xhtml#ch5fig2) 中，请注意端口 12345（NetBus 端口）处于侦听状态，而负责打开端口 12345 的 PID 是编号 208。

![Image](f0198-01.jpg)

**图 5-2**  
使用 netstat 显示打开端口的程序的进程 ID

一旦你获得了负责打开端口的应用程序的进程 ID 编号，就可以追踪与该进程 ID 关联的 EXE 文件。如果你使用 `tasklist` 命令，将会看到在内存中运行的进程（EXE 文件）以及与每个进程关联的 PID（请参阅 [图 5-3](#ch05.xhtml#ch5fig3)）。请注意，在下面的输出中，`Patch.exe` 是与该 PID 关联的 EXE 文件，并负责打开该端口！另请注意，你可以使用管道 (`|`) 功能配合 `tasklist` 命令查找特定条目。例如，你可以使用 `tasklist | find "208"` 来在结果中查找包含 "208" 的条目。

![Image](f0199-01.jpg)

**图 5-3**  
使用 tasklist 显示在内存中运行的可执行文件

一旦你使用了 `tasklist` 命令并知晓了该进程，便可以使用 `taskkill` 命令终止该进程。通过 `taskkill` 命令，你可以指定要终止的 EXE 文件，或使用 `/PID` 开关通过 PID 进行搜索。[图 5-4](#ch05.xhtml#ch5fig4) 中所示的代码使用 `taskkill` 命令通过 PID 编号强制终止进程。

## 其他恶意软件

除了病毒之外，还有其他类型的恶意软件（称为恶意代码/恶意软件，malware），为了应对现实世界和通过 Security+ 认证考试，你需要熟悉这些类型。在本节中，你将了解间谍软件、广告软件和根工具包等，这些只是当今威胁系统的常见恶意软件类型中的一部分。

### 间谍软件

*间谍软件* 是隐藏的软件，它监视并收集关于你及你活动的信息，然后将这些信息发送到远程系统供黑客查看。例如，间谍软件可能会收集你的上网习惯信息。间谍软件不仅能监视信息，还能对系统进行更改，例如浏览器重定向（将你发送到不同的网页）和降低网络连接速度。

### 广告软件

*广告软件* 是会在屏幕上自动加载广告的软件，通常以弹出窗口的形式出现。广告旨在诱导你购买产品或订阅网站。

### 垃圾邮件

*垃圾邮件* 是指你收到的任何未经请求的商业电子邮件。这些电子邮件通常是群发的，试图让你购买产品或服务。发送垃圾邮件的人（发送垃圾邮件的人）通常在你向新闻组发布评论后，从网站或新闻组获取你的电子邮件地址，或者发送垃圾邮件的人从收集了电子邮件地址的公司在线购买电子邮件列表。

发送垃圾邮件的人使用称为 *垃圾邮件机器人 (spambots)* 的自动化程序爬取网站，收集发布在上面的任何电子邮件地址。一旦发送垃圾邮件的人收集到足够多的电子邮件地址，他们就会通过向所有地址发送消息来寻找业务机会。

公司可以通过不在网站上发布电子邮件地址来防范垃圾邮件；如果必须显示电子邮件地址，可以将其放在显示的图形文件中。垃圾邮件机器人无法从图形文件中检索电子邮件地址，因为页面上没有文本形式的地址。

你还可以通过在电子邮件服务器上配置垃圾邮件过滤器（请参阅 [图 5-6](#ch05.xhtml#ch5fig6)），或使用反垃圾邮件设备（如 Cisco IronPort）或在线反垃圾邮件服务（如 Barracuda）来保护公司免受未经请求的商业电子邮件的骚扰。大多数电子邮件服务器支持以下垃圾邮件过滤器：

![Image](f0201-01.jpg)

**图 5-6**  
查看电子邮件服务器上的垃圾邮件过滤选项

- **收件人过滤器** 收件人过滤器是一种阻止发送给指定收件人（电子邮件标题中的“收件人”行）消息的方法。
- **发件人过滤器** 发件人过滤器可以阻止来自指定发件人（电子邮件标题中的“发件人”行）的消息。
- **连接过滤器** 连接过滤器是一份被禁止连接到你的简单邮件传输协议 (SMTP) 服务器的 IP 地址列表。通常，你会将发送垃圾邮件的邮件服务器的 IP 地址（称为垃圾邮件主机）添加到连接过滤器中。
- **实时黑名单 (RBL)** 认为你可以将互联网上所有垃圾邮件主机的 IP 地址都添加到连接过滤器中是不切实际的，因此你可以订阅实时黑名单，这是一家记录互联网上所有垃圾邮件主机的公司。
- **发件人 ID 过滤器** 发件人 ID 过滤器允许你的 SMTP 服务器在 DNS 中查找发送电子邮件给你的用户的人所拥有的发件人策略框架 (SPF) 记录。你的 SMTP 服务器检查发送电子邮件的域名的 SPF 记录，如果发送方的 SMTP 服务器列在 SPF 记录中，你的邮件服务器将接受该电子邮件。

![Image](exam.jpg)

**垃圾邮件是指某人向大量收件人发送未经请求的电子邮件。你可以通过在电子邮件服务器上实施过滤器以及不在互联网上发布电子邮件地址来保护公司免受垃圾邮件骚扰。**

### 根工具包

*根工具包* 是黑客安装在系统上的软件，通常对管理员隐藏，并授予黑客对系统的特权访问。以下是根工具包的五种主要类型：

- **应用程序级** 应用程序级根工具包是一种用户模式可执行文件，授予黑客对系统的访问权限。应用程序级根工具包的例子包括木马病毒。
- **库级** 库级根工具包不是可执行文件，而是一组可由应用程序调用的代码库。库级根工具包是运行在用户模式下的 DLL 文件，通常会替换系统上的某个 DLL 以隐藏自身。
