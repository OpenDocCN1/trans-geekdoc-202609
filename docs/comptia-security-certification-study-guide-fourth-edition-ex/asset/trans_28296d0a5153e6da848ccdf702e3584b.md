## 家用路由器上的防火墙功能

大多数家庭用户和小型企业使用所谓的“家用路由器”在其网络与 Internet 之间建立高速连接。这些家用路由器的优点在于它们是多功能设备，既是 NAT 设备，也是防火墙设备，并提供 URL 过滤功能，以限制网络上的用户可以访问哪些网站。

默认情况下，家用路由器通常会阻止所有源自 Internet 的流量，因此如果你想在网络内部托管自己的网站，就必须在家用路由器的防火墙上打开其端口。以下是在我的 D-Link DIR-615 路由器上使用的步骤供参考：

1. 启动 Web 浏览器并导航到路由器的内部 IP 地址（通常为 `192.168.0.1`）。
2. 选择页面顶部的“Advanced”链接。
3. 选择屏幕左侧的“Port Forwarding”链接。
4. 进入 Port Forwarding 屏幕后，你可以在防火墙上配置规则，将目标为特定端口的数据包转发给网络内部的某个系统。要允许入站 Web 流量访问你的 Web 服务器，请将以下信息输入到相应字段中（参见 [图 8-6](#ch08.xhtml#ch8fig6)）：

![Image](f0337-01.jpg)

**图 8-6 配置端口转发规则**

- **Name:** HTTP。
- **IP Address:** `192.168.1.3`（你希望将流量转发到的内部系统的 IP 地址）。
- **TCP:** `80`（流量目标端口；如果流量基于 UDP，也可指定 UDP 端口）。

5. 输入规则的所有信息后，单击“Apply”按钮以应用更改。

## 防火墙拓扑

接下来讨论防火墙拓扑。防火墙的常见配置包括双宿主、屏蔽主机和屏蔽子网防火墙。

### 双宿主主机防火墙

双宿主主机防火墙由一台具有两个物理网络接口的计算机组成，充当两个网络之间的网关。服务器的路由功能被禁用，以便安装在系统上的防火墙软件可以处理所有流量管理。通常在此系统上运行防火墙软件或代理服务器软件，以将数据包从双宿主系统的一侧传递到另一侧。你必须小心，不要在用作双宿主系统的网络操作系统中启用路由；否则，你将绕过防火墙软件，仅仅是在路由数据。[图 8-7](#ch08.xhtml#ch8fig7) 显示了双宿主主机防火墙配置。

![Image](f0338-01.jpg)

**图 8-7 作为防火墙的双宿主系统具有两个网络接口。**

### 屏蔽主机防火墙

许多人认为屏蔽主机防火墙配置比双宿主防火墙更安全。在此配置中，你在双宿主主机和公共网络之间放置一台屏蔽路由器。这使你能在数据包到达双宿主防火墙之前提供包过滤，从而增加一层额外的网络安全。然后，双宿主系统可以运行防火墙软件或代理服务器软件，为该配置提供额外的安全性。[图 8-8](#ch08.xhtml#ch8fig8) 显示了屏蔽主机配置。

![Image](f0338-02.jpg)

**图 8-8 屏蔽主机防火墙配置通过在防火墙前添加包过滤路由器提供额外的安全层。**

### 屏蔽子网防火墙

屏蔽子网防火墙配置通过进一步将内部网络与公共网络隔离，将安全性提升到一个新的水平。在内部网络和双宿主防火墙之间放置一台额外的屏蔽路由器。这提供了两个额外的安全级别。首先，通过在内部添加屏蔽路由器，你可以保护双宿主防火墙主机免受内部来源的攻击。其次，由于攻击者必须穿越的层数增加，外部攻击变得困难得多。通常，外部屏蔽路由器将配置为将通过过滤规则的任何数据发送到双宿主防火墙，后者将对入站流量执行更多测试。入站流量通过双宿主系统执行的测试后，可能会被发送到内部屏蔽路由器，在那里对数据包执行额外的测试。内部屏蔽路由器通常配置为仅接受来自双宿主防火墙的数据，确保黑客无法跳过外部防火墙层。[图 8-9](#ch08.xhtml#ch8fig9) 显示了屏蔽子网防火墙配置。

## 安全区域

防火墙允许网络管理员将网络划分为称为*区域* 的不同网段。如 [图 8-10](#ch08.xhtml#ch8fig10) 所示，在制定防火墙计划时，通常会创建三个区域：

![Image](f0340-01.jpg)

**图 8-10 防火墙将网络划分为不同的区域。**

- **Private LAN/Intranet** 放置在私有 LAN 前面的防火墙确保没有来自任何其他网络的流量通过防火墙发送到私有 LAN。请注意，此区域可称为私有区域、私有 LAN 或内部网区域。
- **DMZ** DMZ 是两个防火墙之间的区域（通常称为外部防火墙和内部防火墙），允许来自 Internet 的选定流量通过外部防火墙进入 DMZ 内的系统。内部防火墙的目的是不允许任何源自 Internet 的流量通过它。DMZ 是放置需要公众访问的服务器的地方，如 Web 服务器、SMTP 服务器、FTP 服务器或 DNS 服务器。
- **Public zone** 公共区域是指不受网络管理员控制的任何网络。公共区域最好且最常见的例子是 Internet。作为防火墙管理员，你将控制哪些流量从公共区域进入内部网区域。
