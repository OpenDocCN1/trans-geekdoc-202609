

![Image](boxsq.jpg) 基于签名的系统只能识别其已编程签名的可疑活动，而基于异常的系统则识别任何偏离常规的活动。

![Image](boxsq.jpg) 基于异常的系统更容易产生误报，或称“虚假警报”，因为它们将任何偏离正常活动的行为视为可疑。

## 监控工具

![Image](boxsq.jpg) Windows 中的 `netstat` 和 `net session` 命令显示连接到您系统的用户。

![Image](boxsq.jpg) Windows 中的 `tasklist` 命令和 Linux 中的 `ps` 命令显示正在运行的进程。您可以在 Windows 中使用 `taskkill` 命令终止进程，在 Linux 中使用 `kill` 命令终止进程。

![Image](boxsq.jpg) Windows 中的 `net user` 命令显示现有用户账户列表，而 `net share` 命令显示共享文件夹列表。

## 实施日志记录和审核

![Image](boxsq.jpg) 审核可被视为对安全相关事件的跟踪，而日志记录负责记录所有活动——无论可疑与否。

![Image](boxsq.jpg) 要在 Windows 中配置审核，请使用安全策略，首先配置要审核的事件，然后定期在事件查看器中查看安全日志。

![Image](boxsq.jpg) 请务必为网络上的所有服务和设备启用日志记录，或至少调查其日志记录的可能性。这包括数据库和电子邮件服务器等应用环境。

## 自我测试答案

### 监控简介

[**1.**](#ch19.xhtml#rch19que1) ![Image](boxt.jpg) **B.** 基于异常的监控系统根据偏离常规的任何内容识别可疑流量，而非基于签名数据库。这意味着任何类型的攻击——无论是已知攻击还是未知攻击——都会被识别，因为其流量将偏离常规。

![Image](boxx.jpg) **A、C** 和 **D** 不正确。因为基于签名的系统使用定义文件，所以它只能检测其已编程检测的活动。基于主机的 IDS 监控单个系统上的活动，而基于网络的 IDS 监控网络流量。

[**2.**](#ch19.xhtml#rch19que2) ![Image](boxt.jpg) **C.** 基于异常的系统针对正常活动的基线进行编程，任何偏离常规的活动都被视为可疑。因此，它可以检测未知（零日）攻击。

![Image](boxx.jpg) **A、B** 和 **D** 不正确。基于异常的监控系统不使用签名数据库、日志文件或审核文件。

### 监控工具

[**3.**](#ch19.xhtml#rch19que3) ![Image](boxt.jpg) **D.** `netstat -na` 命令用于查看系统上打开端口的列表。

![Image](boxx.jpg) **A、B** 和 **C** 不正确。`nbtstat` 用于排查基于 TCP/IP 的 NetBIOS 故障，而单独使用 `netstat` 命令将仅显示当前连接，而非侦听端口。

[**4.**](#ch19.xhtml#rch19que4) ![Image](boxt.jpg) **B.** 您可以在 Windows 中使用 `taskkill` 命令终止进程，但如果您要按进程 ID 终止进程，则必须使用 `/PID` 开关。

![Image](boxx.jpg) **A、C** 和 **D** 不正确。`kill` 命令由 Linux 用于终止进程。在此示例中，`taskkill` 命令需要 `/PID` 开关。

[**5.**](#ch19.xhtml#rch19que5) ![Image](boxt.jpg) **A.** 在 Linux 中，要使用 `ls` 列出文件时查看文件权限，请使用 `-l` 开关。

![Image](boxx.jpg) **B、C** 和 **D** 不正确。`ls` 命令用于列出文件，但您需要 `-l` 开关来显示权限。

[**6.**](#ch19.xhtml#rch19que6) ![Image](boxt.jpg) **B.** 如果您已经检查了系统且一切似乎正常，没有额外的进程在运行，那么问题可能是系统因流量过大而过载。使用协议分析器或网络嗅探器将允许您查看发往该系统的流量。

![Image](boxx.jpg) **A、C** 和 **D** 不正确。性能监视器和系统监视器用于监控系统运行状况，而 `tasklist` 用于查看已运行的进程。

[**7.**](#ch19.xhtml#rch19que7) ![Image](boxt.jpg) **C.** `lastlog` 命令显示 Linux 系统上的所有用户账户及其上次登录时间。

![Image](boxx.jpg) **A、B** 和 **D** 不正确。这些命令均不显示 Linux 系统上的所有用户账户及其上次登录时间。
