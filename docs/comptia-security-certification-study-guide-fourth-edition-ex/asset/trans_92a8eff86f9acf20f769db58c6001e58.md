

# 章节总结

在本章中，你学习了密码学的基础知识。本章为下一章奠定了基础，下一章将花费更多时间介绍非对称环境。考试时应牢记以下要点：

- 密码学由三项核心服务组成：加密、哈希和认证。
- 加密分为两种类型：`symmetric encryption`（对称加密），使用相同的密钥进行加密和解密；以及 `asymmetric encryption`（非对称加密），使用一对密钥——一个用于加密，另一个用于解密。
- 哈希是一种用于确保数据完整性的方法。

考试中你肯定会遇到几道与密码学相关的问题。只要对本章呈现的材料有深入的理解，你就不会在这些问题上有任何困难。

## ✓ 两分钟演练

### 密码学服务简介

- 密码学有三项核心服务：加密、哈希和认证。
- 对称加密使用相同的密钥进行加密和解密。对称加密协议的示例有 `DES`、`3DES` 和 `AES`。
- 非对称加密使用一对密钥进行加密和解密。非对称加密算法的示例有 `RSA` 和 `Diffie-Hellman`。

### 对称加密

- 对称加密涉及使用相同的密钥来加密和解密消息。
- 对称加密速度快，但这可能使得难以安全地将密钥传达给另一方。
- 常见对称加密算法的示例有 `DES`、`3DES`、`RC4` 和 `AES`。

### 非对称加密

- 非对称加密涉及使用一对密钥来执行密码学服务。
- 这对密钥被称为 `public key`（公钥）和 `private key`（私钥）。公钥分发给所有人；私钥由用户秘密保管。
- 消息使用接收者的公钥进行加密。
- 消息由发送者的私钥签名。对消息进行签名是实现不可否认性的一种方法。

### 理解哈希

- 哈希是一种确保数据完整性的方法。
- 无论被哈希数据的大小如何，哈希都会创建一个固定大小的哈希值。
- 有许多哈希协议。`MD5` 和 `SHA-1` 是最常见的。
- `MD5` 创建 128 位哈希值。`SHA-1` 创建 160 位哈希值。

### 识别加密用途

- 至关重要的是，要确保你使用最安全的方法来存储数据，方法是加密存储中的信息。
- 传输中的信息也应加密，以防止窃听。
- 对于考试，要了解用于替代不安全同类协议的安全协议，例如以下各项：
  - 使用 `HTTPS` 代替 `HTTP`。
  - 使用 `SSH` 代替 `Telnet`。
  - 使用 `SFTP` 代替 `FTP`。
  - 对于 VPN，使用 `L2TP` 代替 `PPTP`。

### 对称加密

**[3.](#ch12.xhtml#rch12que3)** **D.** 对称加密最新且最安全的算法是 AES，而 AES256 使用 256 位加密，是所列算法中最强的。

**A、B** 和 **C** 不正确。3DES 提供 168 位加密，SHA-1 是哈希协议而非对称加密协议，DES 执行 56 位加密。

**[4.](#ch12.xhtml#rch12que4)** **C.** 对称加密最大的缺点是密钥管理，这意味着随着用户数量的增加，你需要创建太多的密钥。此外，如何安全地将密钥传达给个人？

**A、B** 和 **D** 不正确。与非对称加密相比，对称加密速度很快。冲突是两段不同数据生成相同哈希值的结果。取决于所使用的算法以及如何传达密钥，对称加密可以以安全的方式实现。
