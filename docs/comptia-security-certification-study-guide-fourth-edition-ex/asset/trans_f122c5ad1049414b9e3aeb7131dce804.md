# 自测答案

## 理解操作系统加固

### 1. 
**B.** 系统加固涉及禁用不必要的服务并从系统中卸载不必要的软件。系统加固还涉及禁用未使用的账户和修补系统。

**A、C** 和 **D** 不正确。这些都是网络加固技术，而非系统加固技术。MAC 过滤控制哪些系统可以向其他系统发送数据，端口安全通过 MAC 地址控制哪些系统可以连接到端口，而 802.1X 通过使用中央认证服务器控制谁有权访问有线或无线网络。

### 2. 
**D.** 当你通过卸载不需要的软件和禁用不必要的服务来加固系统时，你是在减少系统的攻击面。

**A、B** 和 **C** 不正确。虽然移除某些软件可能会关闭系统上的端口，但选项 D 是更好的答案。评估漏洞是识别系统上存在哪些漏洞——它并不会加固系统。模糊测试是一种软件测试程序，向应用程序输入无效数据以查看应用程序如何响应。

### 3. 
**C.** `Hotfix`（热修复）是指应立即应用于软件的更新。

**A、B** 和 **D** 不正确。补丁是对软件错误的修复，不一定需要立即应用。服务包包含自上一个服务包或软件发布以来的所有补丁和热修复。更新是将补丁应用于系统的通用术语。

### 4. 
**A.** 使用移动设备时，请确保员工为其设备设置密码保护，以便在设备丢失或被盗时，设备上的数据不易被访问。

**B、C** 和 **D** 不正确。在手机上运行移动操作系统是其运行所必需的，短信和电子邮件等功能是员工最可能使用的常用功能，因此无法禁用。

## 系统加固程序

### 5. 
**B.** 802.1X 标准通过使用 RADIUS 等中央认证服务器来控制对有线或无线网络的访问。

**A、C** 和 **D** 不正确。端口安全通过 MAC 地址控制哪些系统可以连接到端口。MAC 过滤控制哪些系统可以向其他系统发送数据，防火墙控制允许进入或离开网络的流量。

### 6. 
**D.** 端口安全通过将端口配置为特定的 MAC 地址，控制哪些系统可以连接到交换机上的端口。

**A、B** 和 **C** 不正确。802.1X 标准通过使用 RADIUS 等中央认证服务器控制对有线或无线网络的访问。MAC 过滤控制哪些系统可以向其他系统发送数据，防火墙控制允许进入或离开网络的流量。

### 7. 
**C.** 安全模板是帮助为系统创建安全基线的绝佳方法，因为你可以在安全模板文件中配置许多“策略”设置，然后将模板导入系统中。

**A、B** 和 **D** 不正确。在每个系统的本地安全策略中配置设置将花费太多时间——最好使用安全模板，然后将模板导入本地安全策略。导入注册表文件行不通，因为这些是策略设置，所以如果你想通过导入来部署，应该使用模板。宏不是系统配置的一部分。

### 8. 
**D.** 警报是一种报告方法，它通知管理员发生了安全事件，并期望立即采取行动。

**A、B** 和 **C** 不正确。警报是一种通知，可能不需要管理员采取纠正措施。趋势是在分析系统或网络活动时寻找的内容，日志可用于查看系统或应用程序上的活动。

## 服务器加固最佳实践

### 9. 
**B.** 为帮助保护 DNS 服务器，请确保区域传送仅将 DNS 区域数据传送给辅助 DNS 服务器。

**A、C** 和 **D** 不正确。总部服务器是主 DNS 服务器，因此它不接收区域传送。在这种情况下，你不能在防火墙上阻止 TCP 53 端口，因为这是区域传送运行所用的端口，你需要保持该端口开放，以便辅助服务器可以进行区域传送。阻止 UDP 53 端口也不可行，因为它用于 DNS 查询，而非区域传送。

### 10. 
**A.** 确保 SMTP 服务器不中继 SMTP 消息，因为黑客可能会将垃圾邮件发送到你的服务器，以中继至目标地址。
