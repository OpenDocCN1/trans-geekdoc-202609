
# 术语表

## A

**ARP**  
*See* [Address Resolution Protocol](#ch23_glossary.xhtml#glos16).

**arp**  
A TCP/IP command-line utility used to manipulate the ARP cache on a system.

**array controller**  
An interface card that connects to all drives in a RAID solution and provides hardware-level fault tolerance.

**ASCII**  
*See* [American Standard Code for Information Interchange](#ch23_glossary.xhtml#glos18).

**asymmetric encryption**  
An encryption scheme that uses a user’s public key to encrypt data and the user’s private key to decrypt the data.

**attribute-based access control (ABAC)**  
Access is granted based on characteristics of the user account.

**attributes**  
Characteristics of a file. A file can be designated with different file system attributes or file system characteristics, such as read-only, system, hidden, and archive.

**authentication**  
Proving your identity to the system so that you may access resources.

**authentication factor**  
Represents the method you use to authenticate to the system—something you know, something you have, something you are, somewhere you are, or something you do.

## B

**back door**  
A method a hacker uses to gain unauthorized access to a system. This back door may be available due to a vulnerability in the system or as a result of being installed during a previous attack.

**backbone**  
The main cable that interconnects networks.

**backup**  
The process of saving files to a separate location (usually an offline storage location such as tape).

**backup set**  
A group of files, directories, or disks selected for a single backup operation.

**bandwidth**  
The amount of data that the media can transfer. Bandwidth is usually measured in bits per second (bps).

**baseline**  
A snapshot of your system or network under normal operating conditions that is used as a yardstick to measure future abnormalities.

**binary**  
Any value represented with a group of zeros and ones.

**binding**  
The linking of network components on different levels to enable communication between those components. For example, binding a protocol to a network adapter allows the network adapter to communicate with that protocol.

**bit order**  
The order in which computers transmit binary numbers across a network. Computers can start at either end of a binary number when transmitting it across a network.

**boot partition**  
The partition in Windows containing the operating system files.

**bootup**  
The process a computer executes when powered up. Bootup includes the files that initialize the hardware and the starting of the operating system.

**bottleneck**  
A point of congestion in the system that causes the system to perform inadequately.

**bridge**  
An OSI layer-2 hardware device that connects two LAN segments of either the same or different topologies. Bridges look at the destination and source MAC addresses of a network packet and decide whether to pass that packet on to the LAN segment. A bridge can be used to filter out traffic for a local subnet and prevent it from being passed on to an unnecessary LAN segment.

**bring your own device (BYOD)**  
A model that allows employees to connect their own personal mobile devices to the network to perform work duties.

**broadcast**  
A packet that is sent to all systems on a network.

**broadcast domain**  
A group of systems that can receive one another’s broadcast messages.

**broadcast storm**  
Occurs when there are so many broadcast packets on the network that the capacity of the network bandwidth approaches or reaches saturation.

**browser**  
(1) An application that uses HTTP to access URLs and to download and display web pages (documents that are usually written in HTML). (2) A computer that maintains a centralized list of network servers.

**buffer space**  
A reserved portion of RAM that provides room for the storage of incoming and outgoing data.

**bulk encryption key**  
*See* [secret key cryptography](#ch23_glossary.xhtml#glos327).

**BYOD**  
*See* [bring your own device](#ch23_glossary.xhtml#glos44).

**byte order**  
The order in which computers transmit larger binary numbers, consisting of two or more bytes, across a network. Computers can start at either end of a group of bytes when transmitting it across a network. *See also* [bit order](#ch23_glossary.xhtml#glos39).

## C

**CAT3 cable**  
A voice-grade cable used in phone networks. It can be used for networking up to 10 Mbps. CAT3 is a grade of cable that enables networking, but CAT5 is the better way to go. The key thing about CAT3 is that it already exists in most office buildings and homes.

**CAT5 cable**  
A UTP cable standard that enables up to 100 Mbps data transmission. Most UTP cable in today’s networks is CAT5.

**CAT5e cable**  
A newer form of CAT5 that can reach transfer rates of 1 Gbps.

**CAT6 cable**  
A newer UTP cable type that can handle up to 10 Gbps as a transfer rate.

**catalog**  
Collection of information describing the backup sets stored on the tape.

**cell**  
In a wireless network, the range of radio signal coverage extending from the transmitters.

**certificate revocation list (CRL)**  
A list of certificates that have been revoked by the certificate authority (CA).

**Challenge Handshake Authentication Protocol (CHAP)**  
An authentication protocol that uses an encryption algorithm to pass the authentication data to protect it from hackers. Because CHAP is so much more secure than PAP, it is used widely today on the Internet. *See also* Password Authentication Protocol.

**checksum**  
A result generated by sending data through an algorithm to prove data has not been altered.

**checksumming**  
A form of error checking that runs the data through an algorithm to come up with a result (known as the checksum). The checksum is then sent with the data, and on the receiving end the receiving system runs the data through the same algorithm to calculate a checksum. The calculated checksum is then compared to the checksum sent with the packet—if they are the same, the data has not been altered.

**class A IP address**  
An address in a class that supports 16 million hosts and has a first octet that ranges between 1 and 126.

**class B IP address**  
An address in a class that supports 65,534 hosts and has a first octet ranging between 128 and 191.

**class C IP address**  
An address in a class that supports 254 hosts and has a first octet ranging between 192 and 223.

**class D IP address**  
An address in a class used for multicasting applications. Class D addresses range between 224.0.0.0 and 239.255.255.255.

**class E IP address**  
An address in an experimental address block that is reserved for future use. Class E addresses range between 240.0.0.0 and 254.255.255.255.

**client**  
(1) The workstation accessing the resources in a client/server model. (2) The software that enables communications for various network services. (3) A computer that accesses resources on a network.

**coaxial (or coax) cable**  
A cable type that has one strand (a solid-core wire) that runs down the middle of the cable, with insulation around that strand. *See also* [twisted-pair cable](#ch23_glossary.xhtml#glos379) *and* [fiber-optic cable](#ch23_glossary.xhtml#glos140).

**collision domain**  
A group of systems that can have their data collide with one another. Data that collides typically must be retransmitted due to damage.

**command line**  
A character-mode interface for computer applications that relies on commands instead of a graphical interface to process information.

**compression**  
A mathematical technique that analyzes computer files in order to compress them to a smaller size. Most backup systems, and many file servers, compress files to provide increased storage capacity.

**computer virus**  
A computer program built to sabotage or destroy a computer or network.
