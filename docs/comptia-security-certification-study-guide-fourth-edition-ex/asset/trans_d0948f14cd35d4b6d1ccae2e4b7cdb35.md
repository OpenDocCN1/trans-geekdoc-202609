
黑客不仅面临在线攻击被检测到的风险，而且通常没有足够时间在线执行完整的密码攻击，因此将账户密码的副本离线复制并在家中舒适地尝试破解，对黑客非常有利，因为不涉及时间限制。

#### 其他密码攻击术语

涉及密码攻击领域时，为了准备 Security+ 认证考试，你应该熟悉许多术语。以下是你应该了解的其他密码攻击术语：

- **重放** 密码重放攻击是指黑客窃听通信并捕获从客户端系统发送到服务器的密码哈希值。一旦黑客获得哈希值，他们就会利用它冒充原始客户端并访问服务器。

- **弱实现** 密码可以加密以保护明文值，但有时加密执行得并不完美。例如，Windows 密码在 SAM 数据库中经过哈希处理，但它们被拆分为两个七字符的哈希值。这使得黑客能非常容易地判断某人是否使用了少于八个字符的密码，因为这些密码的哈希值的最后一部分将是相同的。

#### 防止密码攻击

了解如何在你的环境中防止密码攻击，是任何安全专业人员的重要技能。

为防止针对系统的字典攻击，你必须实施强密码策略并要求用户使用复杂密码。`复杂密码`是指包含大小写字母混合、并使用数字和符号的密码。你还应确保用户创建的密码长度至少为八个字符。

实施密码复杂性无法保护系统免受暴力破解攻击，因此你必须实施账户锁定策略来防范此类攻击。如果你使用`账户锁定策略`，在发生一定次数的错误登录后，账户将被锁定，直到管理员解锁前无法使用。大多数公司实施的账户锁定策略会在第三次错误登录尝试后锁定账户。账户锁定策略消除了执行暴力破解攻击所需的时间；在第三次错误登录尝试后，账户即被锁定。

![Image](exam.jpg)

**针对 Security+ 认证考试，请记住：密码复杂性是针对字典攻击的对策，而账户锁定策略是针对暴力破解攻击的对策。**

关于密码策略和账户锁定策略，有一点必须理解：如果黑客正在执行离线密码攻击，这些策略将不起任何作用。在`离线密码攻击`中，黑客获得对系统的物理访问权限，将用户账户数据库复制到闪存驱动器，并带走数据库。随后黑客在自己的家中发起攻击，那里没有你的密码策略或账户锁定策略。黑客破解出密码后，便可使用发现的用户名和密码访问系统。

![Image](exam.jpg)

**离线密码攻击是指黑客将用户账户数据库从你的系统复制到闪存驱动器并带走，以便进行密码破解。在此示例中，密码攻击不会被阻止，因为在黑客的位置不存在密码策略或账户锁定策略。**

以下是一些流行的密码审计和破解工具：

- **LC4** 一款非常流行的密码审计工具，可用于访问 Microsoft 网络上的用户密码。它可以对密码执行字典、暴力破解和混合攻击。

- **Cain & Abel** 一款功能强大的密码破解程序。Cain & Abel 的优势在于它可免费下载，并能捕获网络上的密码，然后使用字典或暴力破解攻击破解这些密码。

- **NAT** NetBIOS 认证工具是一个小程序，允许你对 Windows 系统执行字典攻击。

- **Brutus** Brutus 的独特之处在于它可以通过不同的互联网应用程序（如 HTTP、FTP、POP3 和 Telnet 等）封装密码攻击。

- **John the Ripper** 一款非常流行的字典和暴力破解工具，可在 Windows 或 Linux 上运行。

### 认证总结

在本章中，你学习了当今计算环境中发生的不同类型的攻击。请务必为 Security+ 考试掌握这些攻击。以下列表总结了你所学的不同攻击类型：

- 不同类型的攻击包括社会工程学攻击、网络攻击、密码攻击和应用程序攻击。

- 社会工程学攻击是通过电话或电子邮件等社交联系方式发起的攻击，黑客试图诱骗你破坏安全性。

- 网络攻击涉及黑客跨越网络入侵系统。网络攻击的示例包括嗅探、DoS、DDoS 和中间人攻击（以前称为中间人攻击）。

- 三种类型的密码攻击分别是：字典攻击，使用字列表文件作为密码；暴力破解攻击，通过数学计算所有潜在密码；混合攻击，修改字列表文件中的条目。

- 保护环境免受社会工程学攻击的最佳方法是教育用户了解社会工程学，并培训他们在收到此类联系时该如何应对。

凭借对本章所呈现材料的深入理解，你将不会在考试中遇到任何与攻击相关的问题。此处呈现的材料不仅对考试很重要，在现实世界中也将价值连城，因为它能让你更加了解可能发生的各种攻击。

##### 识别网络攻击
