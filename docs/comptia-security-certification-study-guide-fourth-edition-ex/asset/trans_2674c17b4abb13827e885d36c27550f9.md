

# 术语表

## fragmentation
(1) 当文件的数据被写入磁盘的不同区域时。碎片会降低访问速度，因为系统必须从磁盘的不同区域收集文件的各个部分。(2) 网络将大块数据切分或分片为更易于管理的单元以便传输的过程。当数据被分片时，重要的是确保所有片段都能按正确顺序到达另一端。如果它们无序，有时可以将数据重新排序为正确的顺序。

## Frequently Asked Questions (FAQs)
出现在公告牌和网站的特定区域，包含有关产品或服务的常见问题解答。FAQs 用于新闻组以涵盖经常出现的问题。

## FTP
参见 [File Transfer Protocol](#ch23_glossary.xhtml#glos146)。

## full backup
备份指定卷或卷上的每个文件。应频繁运行完整备份，并且至少应将一个当前副本存储在异地。另请参见 [differential backup](#ch23_glossary.xhtml#glos93) 和 [incremental backup](#ch23_glossary.xhtml#glos185)。

## full disk encryption (FDE)
由软件或操作系统提供的一种安全功能，用于加密整个驱动器。

## full-duplex
允许设备同时发送和接收。

## fully qualified domain name (FQDN)
计算机的完整 DNS 命名空间路径。

## fuzzing
一种安全测试技术，用于验证应用程序在随机数据被输入时的反应。

## gateway
一种将数据从一种格式转换为另一种格式的设备或服务。

## gigabit network
传输速率为 1000 Mbps（即 1 Gbps）的网络。

## gigabyte (GB)
相当于 10 亿字节。

## global groups
在域控制器上创建，用于组织用户。

## group accounts
用于将执行相同功能或需要访问相同资源的用户分组的账户。如果没有组账户，您将不得不按用户逐个授予资源访问权限。

## guest account
用于为远程用户或来自其他域的用户提供有限访问权限。默认情况下处于禁用状态，来宾账户为没有自己用户账户的用户提供对计算机的低级访问权限。

## hacker
能够绕过安全控制并访问系统的个人。

## handshaking
面向连接的服务用于确保数据可靠地跨网络发送的过程。握手发生在通信会话开始时。在握手期间，两台计算机确定通信规则，例如传输速度和使用哪些端口。握手还决定了会话结束时正确的终止方式。这确保了通信以有序的方式结束。

## HIDS
参见 [host-based intrusion detection system](#ch23_glossary.xhtml#glos171)。

## home directory
用户账户的一个选项，可为用户提供一个存储文件的可访问位置。

## host
参与网络的系统或设备。

## host ID
标识 TCP/IP 网络上设备的 32 位地址部分。

## host-based intrusion detection system (HIDS)
一种用于监控系统活动并向管理员发出任何可疑活动警报的 IDS。

## hosts file
用于将完全限定域名映射到 IP 地址的文件。hosts 文件用于名称解析，每行包含一个 IP 地址及其关联的名称。

## HTTP
参见 [Hypertext Transfer Protocol](#ch23_glossary.xhtml#glos176)。

## HTTPS
参见 [Hypertext Transfer Protocol Secure](#ch23_glossary.xhtml#glos177)。

## hub
星型拓扑中用于将计算机连接到 LAN 的设备。集线器被视为不安全的网络设备，已被交换机取代。另请参见 [active hub](#ch23_glossary.xhtml#glos12)。

## Hypertext Transfer Protocol (HTTP)
互联网上使用的协议，允许客户端从 Web 服务器请求网页，并允许客户端与这些 Web 服务器进行交互。HTTP 是一种无状态协议，意味着 Web 服务器不知道客户端请求或未请求的内容，也无法跟踪请求过特定内容的用户。该系统不允许与 Web 服务器进行良好的交互，但确实允许检索存储在网站上的 HTML 页面。

## Hypertext Transfer Protocol Secure (HTTPS)
HTTP 的安全版本，允许您连接到网站并使用安全套接字层 (SSL) 以加密格式接收和发送内容。HTTPS 最常用于电子商务网站，允许您发送个人信息，而无需担心互联网黑客查看这些信息，尤其是信用卡号和其他机密数据。您可以通过网站地址以 `https://` 开头而非 `http://`（常规 HTTP 协议）来判断是否正在使用 HTTPS。HTTPS 正在使用的另一个迹象：在浏览器中，状态栏或地址栏中会出现一把锁，表示正在使用安全连接。由于加密和解密过程会降低连接速度，因此 HTTPS 不用于整个电子商务网站，只有包含个人信息的页面才使用 HTTPS。

## ICMP
参见 [Internet Control Message Protocol](#ch23_glossary.xhtml#glos191)。

## IDS
参见 [intrusion detection system](#ch23_glossary.xhtml#glos201)。

## IEEE
参见 [Institute of Electrical and Electronics Engineers](#ch23_glossary.xhtml#glos187)。

## ifconfig
一个用于查看和排查 TCP/IP 设置的 Linux 命令行工具。

## IIS
参见 [Internet Information Services](#ch23_glossary.xhtml#glos194)。

## IMAP
参见 [Internet Message Access Protocol](#ch23_glossary.xhtml#glos196)。

## impersonation
一种服务器进程访问其无权访问的对象的技术。如果客户端进程具有适当的访问权限，服务器进程会模拟客户端进程以访问该对象。

## incremental backup
备份自上次备份以来已更改的所有文件，并清除存档位。另请参见 [full backup](#ch23_glossary.xhtml#glos154) 和 [differential backup](#ch23_glossary.xhtml#glos93)。

## inherited permission
文件或文件夹从父文件夹继承的权限。

## Institute of Electrical and Electronics Engineers (IEEE)
一个大型且受人尊敬的专业组织，也活跃于标准制定领域。

## Institute of Electrical and Electronics Engineers (IEEE) 802.11
一种解决无线网络问题的标准。该标准通常包括无线客户端连接到无线接入点 (WAP) 以访问网络或互联网。

## Institute of Electrical and Electronics Engineers (IEEE) 802.1X
一种使用外部认证服务（如 RADIUS）的无线认证标准。

## interference
干扰跨网络电缆发送的电信号的噪声。

## Internet Control Message Protocol (ICMP)
TCP/IP 中使 TCP/IP 网络上的系统能够共享状态和错误信息的协议。

## Internet Engineering Task Force (IETF)
负责互联网运行、管理和演进的组织。IETF 的指导委员会称为互联网工程指导组 (IESG)。

## Internet Explorer
由 Microsoft 创建的 Web 浏览器。

## Internet Information Services (IIS)
Microsoft 的 Web 服务器产品。IIS 提供功能齐全的 SMTP 服务器、FTP 服务器和 HTTP 服务器。
