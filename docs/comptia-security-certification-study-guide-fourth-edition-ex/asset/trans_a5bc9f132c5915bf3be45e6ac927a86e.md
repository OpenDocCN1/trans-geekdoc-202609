

### 加密文件系统 (EFS)

加密文件系统 (EFS) 是 Windows 中的一项安全功能，可应用于位于 NTFS 格式驱动器上的文件。你可以转到文件的属性，然后在“常规”选项卡上，单击“高级”按钮。随后你可以将属性设置为加密该文件。默认情况下，只有加密文件的人才能解密该文件。请注意，这是一种加密单个文件而非整个硬盘驱动器的方式。

### BitLocker

BitLocker 是 Windows 中的一项驱动器加密功能，允许你加密整个驱动器。建议在笔记本电脑等移动设备上使用，这样如果笔记本电脑丢失或被盗，你可以确信硬盘驱动器已加密。

### BitLocker To Go

BitLocker To Go 是一项允许你加密 USB 驱动器的功能。由于这些是便携式驱动器，容易丢失或被盗，因此你应该使用 BitLocker To Go 对其进行加密。

### 系统加固程序

现在你已经对系统加固有了一个大致的了解，让我们来看看安全管理员用来加固网络和系统的一些常用工具。在本节中，你将了解网络加固以及所使用的一些软件工具。

#### 网络安全加固

网络加固的第一个方面是更新所有网络设备上的固件。网络设备虽然是硬件，但就它们由软件运行这一点而言，类似于计算机。运行网络设备的软件称为 `firmware`，存储在称为 EEPROM 的闪存中，EEPROM 代表 `electrically erasable programmable read-only memory`（电可擦除可编程只读存储器）。通常你可以访问设备制造商的网站，下载该设备修订后的更新版固件。该版本的固件将包含创建时所有 bug 的修复程序。

更新固件后，请务必为设备配置了密码，以便只有授权人员才能对其进行管理。如今大多数设备（如路由器和交换机）都支持 Web 管理界面，你应该对其进行密码保护，并在支持的情况下将其配置为使用 HTTPS。

在考虑加固网络时，请确保使用尽可能安全的设备。例如，使用交换机代替集线器，因为交换机具有过滤功能，可确保交换机仅将流量发送到目标系统所在的端口。这意味着很难有人在网络上放置嗅探器并捕获流量，因为流量永远不会到达执行数据包嗅探的设备。在集线器曾是流行网络设备的时候，数据包会被发送到集线器上的所有端口，任何安装了嗅探器的系统都能查看所有网络流量。

##### MAC 限制和过滤

MAC 过滤是一种流行的访问控制方法，在网络交换机和无线接入点等许多不同设备中均有实现。通过无线接入点，你可以实施 MAC 过滤来控制哪些 MAC 地址可以连接到无线网络。请注意，这也称为 `MAC limiting`，因为你是通过 MAC 地址限制哪些设备可以访问无线网络。

交换机上的 MAC 过滤含义略有不同，它允许你限制哪些系统可以向网络上的其他系统发送数据。交换机上的过滤通常与端口安全功能一起配置，允许你限制交换机上的哪些端口可以作为发往特定系统的数据的“源端口”。

##### 802.1X

加固网络的一种流行方法是确保任何连接到网络的人员，在允许网络连接之前都提供有效的凭据。这不同于正常的操作系统登录，因为当你登录系统时，系统通常已经具有网络访问权限。802.1X 标准是一种用于控制网络访问（有线和无线）的 IEEE 标准，通常称为基于端口的访问控制保护。使用 802.1X 时，在你向 802.1X 环境进行身份验证之前，不会被授予网络访问权限。

802.1X 的工作方式是：你有一个客户端，如台式机系统、笔记本电脑或网络设备，希望连接到网络交换机或无线接入点。网络交换机或无线设备称为 `authenticator`（认证器），需要在授予网络访问权限之前对连接设备进行身份验证。交换机或无线接入点向运行 RADIUS 或 DIAMETER 等协议的中央认证服务器发送认证请求（请参见 [图 6-5](#ch06.xhtml#ch6fig5)）。这些是不同类型网络环境中常见的认证服务器。
