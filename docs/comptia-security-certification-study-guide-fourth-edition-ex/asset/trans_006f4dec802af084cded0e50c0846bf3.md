

# 认证总结

在本章中，你学习了可用于帮助提高网络环境安全性的常见网络组件。请务必熟练掌握本章内容，因为在 Security+ 考试中，你一定会遇到关于防火墙、NAT、NAC 及其他安全设备的问题。以下是关于本章需要记住的一些要点：

- **DoS** 可以对网络系统和设备发起多种拒绝服务攻击。在防火墙上实施洪水防护应该能保护你的系统免受大多数 DoS 攻击，因为大多数攻击都涉及黑客试图用大量信息淹没你的系统，导致系统崩溃。洪水防护会阻止洪水消息进入你的网络。
- 了解包过滤防火墙（无状态）、状态包检测防火墙和应用层防火墙之间的区别。
- 不同的防火墙拓扑包括双宿主防火墙、屏蔽主机防火墙和屏蔽子网防火墙。你的防火墙设计应在网络中创建不同的区域，例如私有区域和公共区域。
- 代理服务器是流行的设备，允许你控制网络上的用户在访问互联网时可以使用的内容和应用程序类型。
- 了解基于主机的 IDS 和基于网络的 IDS 之间的区别。还要了解 IDS 检测入侵，而 IPS 既检测又防止入侵。
- 利用网络设计原则帮助创建安全的网络环境，例如创建多个网段并控制可从一个网段传递到另一个网段的流量。
- 不要混淆 NAT 和 NAC。NAT 是一项用于互联网访问的功能，可将私有地址信息转换为公共地址。NAC 用于检查连接到网络的系统状态，如果不满足要求，则该系统不会被连接到网络。
- 关于网络设备的常见安全实践包括确保使用复杂密码、重命名或禁用默认账户，以及通过补丁保持系统处于最新状态，仅举几例。

## ✓ 两分钟演练

### 理解防火墙

- 包过滤防火墙允许你根据第 3 层报头（IP）和第 4 层报头（TCP 或 UDP）过滤流量。状态包检测防火墙可以进行包过滤，但也了解会话的上下文。应用层防火墙可以查看数据包中的应用数据并做出决策。
- DMZ 是一个区域，允许来自互联网的选定流量到达公共服务器，如 DNS、FTP 和 HTTP 服务器。
- 代理服务器通常将防火墙功能与内容控制功能结合在一起。例如，你可以限制用户可以访问的站点或他们用于访问互联网的应用程序类型。

### 使用入侵检测系统

- 基于网络的入侵检测系统分析网络流量以识别可疑活动。
- 入侵检测系统 (IDS) 记录可疑活动并通知管理员，但入侵防御系统 (IPS) 会采取纠正措施。例如，IPS 可能会将发起可疑流量的人员从网络中断开。
- 就考试而言，要了解 IDS 可以基于特征码（基于特征码的 IDS）检测可疑流量，也可以基于流量超出正常活动的参数（基于异常的 IDS）来识别可疑流量。还要了解启发式监控涉及基于过去经验检测可疑流量。

### 网络设计和管理原则

- 通过在网络交换机上使用 VLAN 在网络内创建通信边界。
- 你也可以通过在网络上放置路由器并使用路由器上的访问控制列表控制可进入不同网段的流量来创建不同的网段（例如，将访客的无线网络与企业网络分离）。
- 数据丢失防护 (DLP) 技术可用于防止某人窃取或共享敏感公司数据。
- 网络准入控制 (NAC) 允许你在授予系统有线或无线网络访问权限之前检查系统的状态。
- 在邮件网关上实施垃圾邮件过滤功能和防病毒软件，以保持员工邮箱没有垃圾邮件和包含病毒的邮件。

### 保护设备

- 确保网络设备具有强密码。
- 务必为设备打补丁以消除其上的漏洞。
- 如果可能，重命名或禁用设备上的默认账户。
