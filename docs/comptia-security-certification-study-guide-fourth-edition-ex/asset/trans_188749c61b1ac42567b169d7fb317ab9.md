

# 监控系统和工具

你在[第 8 章](#ch08.xhtml#ch8)中了解到，诸如入侵检测系统之类的监控系统可以使用不同的方法来检测可疑活动。IDS 基于签名或活动中的异常来检测入侵。*基于签名*的监控系统捕获活动并将其与已知恶意活动的定义文件进行比较。此定义文件通常称为*签名*。例如，你可能有一个系统，当 SYN 消息在短时间内从单个 IP 地址发送到同一目标系统的多个端口时通知你，这是端口扫描的经典签名。

基于签名的系统的优点是误报很少，因为它将活动与你在系统上配置的签名进行比较。因为你在寻找特定的活动，所以误报的数量有限。

## 考试内幕

### 理解监控系统的类型

对于认证考试，请记住不同类型的监控系统。常见的监控系统类型有基于签名、基于异常和基于启发式分析。

*基于签名*的系统根据文件中的签名检测可疑活动，而*基于异常*的系统了解正常活动（基线），并将任何偏离常态的活动视为可疑。*基于启发式*的系统根据制造商将设备编程为过去导致安全问题的活动类型来识别可疑活动。基于启发式的 IDS 非常适合监控零日漏洞利用。有关这些入侵检测系统的更多信息，请查看[第 8 章](#ch08.xhtml#ch8)。

请记住，基于异常的系统非常适合检测零日漏洞利用，因为它是未知的漏洞利用，而基于签名的系统还没有该漏洞利用的签名。

*基于异常*的系统了解什么被认为是正常活动（基线），然后将任何超出该正常活动范围的行为视为“可疑”活动。基于异常的监控系统通常根据使用系统的人的行为来确定基线。这被称为基于行为的异常监控系统。

基于行为的异常系统的优点是你不需要配置已知可疑活动的定义文件；系统根据用户的活动学习什么是正常的。基于行为的系统的缺点是任何偏离常态的行为都被视为可疑，这会导致大量的误报（假阳性）。

在复习入侵检测系统的概念时，我们还应该复习蜜罐的概念。*蜜罐*是一个设置用来引诱攻击者进入的伪造系统。蜜罐系统会经过加固，使攻击者不容易轻易入侵，而在他们试图攻破系统时，高级别的日志记录和审计会跟踪攻击者。另请注意，你可以将单个文件设置为攻击者的诱人目标，称为*蜜罐文件*。例如，你可以在系统桌面上放置一个名为 `password.txt` 的文件，这样当攻击者最终进入系统时，他们会看到并打开这个文件。你将对该文本文件实施审核，以便知道何时被谁打开。

## 认证目标 19.02：监控工具

除了使用入侵检测系统外，你还可以使用工具对系统执行手动监控。随着你更多地使用系统并响应或排查潜在的安全问题，这些工具将变得越来越重要。

### 有用的系统命令

每个操作系统中都有许多命令用于帮助排查问题和处理安全事件。你在本书前面已经接触过其中一些命令，但我要在此回顾它们并包含一些新命令。

#### Windows 命令

你可以使用许多 Windows 命令来监控系统上的活动。以下是监控 Windows 系统时你应该练习并熟悉的一些常用命令。

**`netstat`**  
你应该熟悉的第一个命令是 `netstat` 命令。`netstat` 命令用于显示任何协议连接信息。例如，你可以使用 `netstat -n` 以数字格式（而不是友好名称）查看与你系统的任何 TCP 连接。你还应该定期使用 `netstat -na -o` 命令查看系统上所有监听端口的列表（`-o` 用于显示进程 ID，以便你知道是什么程序打开了该端口）。以下命令可用于查看与 TCP 相关的连接：

**`whoami`**  
如果你需要知道你以谁的身份登录到系统，可以使用 `whoami` 命令。该命令将显示当前登录的用户名。使用 `whoami` 命令时，你可以使用 `/groups` 开关列出你所属的组，或使用 `/LOGONID` 开关查看你账户的登录 ID；这两者在排查访问控制问题时都很有用。以下代码清单显示我以 administrator 身份登录到了名为 `2008R2` 的系统上：

**`net statistics`**  
Windows 中另一个很棒的监控类命令是 `net statistics server` 命令，你可以用它密切关注服务器上发生的情况。该命令将显示诸如接受的会话数、密码违规次数（登录失败次数）、权限违规次数（因无权限导致的访问失败）以及排队到系统的打印作业等信息。
