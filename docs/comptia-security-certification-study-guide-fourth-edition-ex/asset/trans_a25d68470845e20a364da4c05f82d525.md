

# 网络安全概念

## VPN 协议

- **HTML5** HTML5 VPN 基于 SSL/TLS 加密，为我们提供了一种通过 Web 浏览器使用无客户端 VPN 连接来远程访问内部网络系统的方法。
- **第二层隧道协议 (L2TP)** L2TP VPN 协议使用 IPSec 对 VPN 隧道内的数据进行加密。

## API 注意事项

*应用程序编程接口 (API)* 是一个函数库，软件开发人员可以从其应用程序中调用这些函数。安全性的一部分在于确保内部应用程序所调用的任何第三方库都遵循安全最佳实践。您可以确保开发人员遵循安全编码实践，但也应测试第三方组件。

## 网络管理原则

要创建安全的网络环境，网络管理员遵循通用的安全网络管理原则至关重要。以下概述了网络管理员在致力于创建更安全环境时应遵循和使用的一些基本原则或安全技术：

- **基于规则的管理** 使用支持基于规则管理的技术（包括路由器、防火墙和代理服务器）来实施规则。务必测试允许或拒绝流量的规则，并确保规则按预期工作。
- **防火墙规则** 管理防火墙上的规则，仅允许所需流量通过防火墙。配置防火墙默认规则为拒绝所有，然后为允许通过的流量添加例外。
- **VLAN 管理** 务必利用 VLAN 在网络上创建通信边界。默认情况下，系统只能与同一 VLAN 中的其他系统通信，除非您配置路由器在 VLAN 之间路由。
- **安全路由器配置** 确保以安全方式配置路由器。这包括创建访问控制列表、设置设备本地访问密码、设置远程访问密码，以及仅使用安全的远程访问协议（如 SSH）。
- **访问控制列表** 在可能的情况下实施 ACL。ACL 通常应用于文件和文件夹权限，以及路由器和防火墙。
- **802.1X** 实施此常见认证协议，它通过要求客户端针对中央认证数据库（如 RADIUS 服务器）进行认证，来控制谁能获得有线或无线网络的访问权限。
- **隐性拒绝** 尽可能将路由器和防火墙配置为隐性拒绝。这意味着，除非您有专门添加到设备的规则允许流量进入网络，否则路由器和防火墙将自动拒绝该流量。文件夹和文件的权限也应具有隐性拒绝规则。
- **网络分段/隔离** 如前所述，将网络划分为较小的网络段，然后控制从一个网络段到另一个网络段的流量至关重要。
- **日志分析** 定期审查日志文件是安全性中一个被忽视的方面。重要的是要确保在所有关键系统和设备上实施日志记录，并定期审查日志。
- **网桥** 网桥技术使一个网络上的系统能够连接到另一个网络上的系统。网桥的一个例子是无线网桥，两个网络通过无线链路连接在一起。从安全角度来看，要记录正在使用的任何网桥技术，以便了解存在的所有通信通道。
- **SSL 加速器/TLS 加速器** 在大量使用加密的环境中，您可以通过使用 SSL/TLS 加速器来避免拖慢系统处理器的速度，该加速器是一张安装在系统中的卡，拥有自己的处理器来处理系统的加密功能。
- **SSL 解密器** SSL 和 TLS 解密器是企业网络上的设备，用于解密消息，以便 DLP 策略可以审查内容。它们也用于让恶意软件检测功能在消息解密后对其进行扫描，或允许云监控服务扫描消息。
- **媒体网关** 媒体网关设备是一个组件，用于将数据流从一种通信形式转换为另一种。例如，媒体网关可以将网络上的数据转换为 3G 无线网络使用的格式。
- **HSM** *硬件安全模块 (HSM)* 是一种设备，通常是一张卡，可安装在服务器中，用于执行加密功能并管理这些加密功能的密钥。
- **负载均衡器** 负载均衡器是一种设备，用于将负载分摊到多台服务器上，以免单台服务器因工作过载而陷入瘫痪。
- **DDoS 缓解器** DDoS 缓解器将放置在互联网和您的公共互联网资源（如 Web 服务器和电子邮件服务器）之间。DDoS 缓解器是一种监控从互联网传入您公共服务器的网络流量的设备，可识别可能旨在使您的服务器过载的流量。缓解器检查数据包的特征，包括源 IP 地址和 HTTP 标头，以确定流量是否来自僵尸网络。如果是，缓解器将阻止该流量，使其无法到达您的公共服务器。
- **汇聚交换机** 在大多数组织中，每层楼都在布线间有一台交换机，该楼层的用户连接到这台交换机。每层楼的交换机再连接到数据中心内的汇聚交换机。该汇聚交换机充当所有交换机的连接点，但也可能是三层交换机，能够将流量路由到互联网。如果它不是三层交换机，则会连接到路由器，再由路由器连接到互联网。
- **分流器和端口镜像** 网络交换机可配置为将所有网络流量的副本发送到某个端口，您可在该端口上运行监控软件或 IDS。这至关重要，因为交换机会过滤流量，防止除目标之外的任何人看到该流量。您也可以安装网络分流器设备，它包含多个端口和一个监控端口，并接收所有流量的副本。
- **带外管理** 带外管理涉及连接到网络设备上的管理端口，以管理该设备（例如，连接到交换机上的控制台端口以配置设备）。在保护设备时，请务必通过在管理接口上配置用于认证的密码来锁定这些接口。
- **DNS** 在 DNS 服务器上实施安全性时，请务必限制哪些系统可以接收区域传输，并考虑使用 DNSSec 来保护 DNS 区域数据的完整性。
- **路由安全** 路由安全涉及保护路由设备免受攻击，包括防止黑客获得访问权限并操纵路由表。请通过限制设备上运行的协议和锁定正在运行的协议来加固路由设备。
- **服务质量** 您应监控网络性能，并衡量用户通过电话和基于云的服务所接收的服务质量 (QoS)。
- **监控服务** 务必锁定所有监控服务和协议，以免黑客访问受监控的数据。例如，确保设备使用支持数据认证和加密的 SNMP 第 3 版。
- **文件完整性监视器** 您可以实施文件完整性监视器，以监控网络上文件的更改。如果文件被更改，您可以设置发送警报给您。
