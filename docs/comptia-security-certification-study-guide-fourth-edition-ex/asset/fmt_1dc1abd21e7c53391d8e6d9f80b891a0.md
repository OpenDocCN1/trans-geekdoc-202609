
### Uninstall software
漏洞扫描器可能会在扫描后报告你安装了易受攻击的软件。如果该软件未被使用，你可以选择卸载它；如果正在使用，则应为其打补丁。

### Disable services
漏洞扫描器可能会识别出正在运行但通常不被公司使用的常见服务。在这种情况下，你需要禁用这些服务，并将其启动类型设置为“Disabled”。

### Update patches
大多数漏洞评估软件会扫描缺失的补丁。请做好准备，可能会发现缺失某些补丁，并需要测试和安装它们。

### Change settings
漏洞评估软件可能会识别出系统上的一些常见配置错误。因此，你通常需要查看设置并更改它们以提高系统安全性。

以下是关于 Security+ 认证考试中漏洞评估的一些关键点：

### Passively test security controls
与渗透测试（主动测试）不同，漏洞评估被视为被动测试，因为它不会真正尝试攻破系统。

### Identify vulnerabilities
漏洞评估将识别网络和系统中易受攻击的区域。

### Identify lack of security controls
漏洞评估将识别缺失的安全控制。例如，它会识别你是否未在文件夹上配置权限，或者系统上是否未安装防火墙。

### Identify common misconfigurations
漏洞扫描器可能识别出的最重要项目之一是系统配置错误，导致系统更容易受到攻击。

#### Network Reconnaissance and Discovery

渗透测试人员有许多工具可用于对公司进行侦察（分析）以及信息和系统发现。以下是渗透测试人员常用的一些侦察和发现工具。

##### Discovery Tools

有许多工具用于发现网络上的系统、系统的 IP 地址、网络连接以及互联网上关于公司的公开信息。以下是考试需要了解的发现工具列表。

- **tracert/traceroute**  
  用于追踪数据包在网络中采取的路径。当数据包到达路由器时，会发回响应，让你知道数据包经过了多少个路由器。示例用法：`tracert www.gleneclarke.com`。

- **nslookup/dig**  
  `DNS` 查找工具；`nslookup` 在 `Windows` 和 `Linux` 系统上都很常见，而 `dig` 则在 `Linux` 系统上。

- **ipconfig/ifconfig**  
  分别用于显示 `Windows` 系统或 `Linux` 系统上的 `TCP/IP` 设置。

- **netstat**  
  用于查看系统上打开的端口列表，或查看连接到该系统的主机。要查看所有打开的端口，请使用 `netstat -na`。

- **theHarvester**  
  一种 `OSINT` 工具，用于从公共互联网源收集员工电子邮件地址、域名、服务器名称和系统开放端口。

##### Pingers and Scanners

评估网络的一部分是定位正在运行的系统、运行系统上打开的端口以及可能存在的漏洞。以下是用于 ping 网络上的系统、进行端口扫描和漏洞扫描的工具。

- **ping/pathping**  
  `ping` 和 `pathping` 都用于测试与远程系统的连通性，但 `pathping` 会显示数据包经过的每一跳。示例用法：`ping 192.168.1.1` 和 `pathping 192.168.1.1`。

- **hping**  
  `hping` 是一种允许你构造数据包以绕过防火墙的 ping 工具。例如，如果系统阻止 `ICMP` 数据包，导致你无法 ping 通该系统，你可以使用 `hping` 并指定 `TCP` 协议和一个你认为会开放的端口，以便 ping 消息能穿过防火墙。

- **IP scanners**  
  `IP` 扫描器用于对网络执行扫描，以检测哪些系统正在运行及其 `IP` 地址。

- **nmap**  
  一种常见的网络扫描器，可以执行 ping 扫描以识别系统、端口扫描、横幅抓取和系统枚举。这是考试中必须了解的最常用工具之一！

- **Nessus**  
  `Nessus` 是一种常见的漏洞扫描器，用于扫描系统并报告任何漏洞。漏洞报告在渗透测试期间非常有用，因为它还可以让你了解漏洞的 `CVSS` 评分以及是否存在针对它的漏洞利用代码。

##### Wireless Scanner/Cracker

当今网络上常用的一组工具是无线扫描器和无线破解工具。无线扫描器是一种可用于发现范围内的无线网络及其特征的工具。例如，使用无线扫描器，你可以看到 `SSID` 名称、信道、使用的加密类型（`WEP`/`WPA2`）和信号强度。无线扫描器的例子包括 `Windows` 上的 `Acrylic Wi-Fi` 和 `Linux` 上的 `Kismet`。

无线破解工具是一种用于破解 `WEP` 或 `WPA2` 保护的无线网络加密密钥的工具。像 `Aircrack-ng` 套件这样的工具可用于捕获无线流量（`airodump-ng`），一旦捕获到足够的流量，即可破解无线加密（`aircrack-ng`）。

##### Honeypot, Honeynet, and Honeyfiles
