

### 无人机
您可以使用无人机飞越设施，拍摄土地布局和建筑物的视频录像。这有助于您了解物理安全控制中的弱点，例如了解围栏、警卫和出口的使用情况。

### 战争驾驶
战争驾驶是一种无线网络攻击技术，攻击者驾驶车辆四处移动，使用无线扫描器（如 `Kismet`）来发现无线网络及其特征，例如操作信道、频率和配置的安全协议。

### 战争飞行
战争飞行是战争驾驶的一种形式，攻击者使用低空飞行的私人飞机扫描区域以寻找无线网络。使用无线扫描器（如 `Kismet`），攻击者在 1500 英尺的高度飞行，以发现大量无线网络。

### 踩点
正如您将在本章后面了解到的，`footprinting` 是侦察的另一个术语，即发现有关预期目标的信息。您可以使用互联网资源被动地发现有关公司的信息，也可以使用扫描工具主动发现目标网络上运行的系统的信息。

### OSINT
您可以在互联网上找到大量关于公司的信息，例如电子邮件地址以及连接到互联网的服务器或设备。使用开源情报 (OSINT) 工具，您可以轻松检索公开可用的公司信息。`Maltego` 是一个 OSINT 工具的示例，它可以收集公司的电子邮件地址、文件、电话号码、DNS 记录、IP 地址和资产地理位置。

### 演练类型
在执行渗透测试时，您可以使用不同类型的测试。您可能执行渗透测试是为了尝试入侵公司资产（红队的目标），或者您的目标可能是查看防御团队（即蓝队）能否检测到攻击正在发生并将其阻止。以下是贵公司可能雇佣的不同安全团队：

#### 红队
红队是采取系统性方法攻击系统并尝试绕过安全控制的网络安全团队。他们是攻击者。

#### 蓝队
蓝队是负责检测攻击并通过在攻击初期将其阻止来保护公司资产的网络安全团队。他们是防御者。

#### 白队
网络安全中的白队是监督安全测试、记录红队和蓝队双方进度并分配分数的团队。白队还会审查红队和蓝队创建的安全报告，根据其准确性对它们进行评级。

#### 紫队
网络安全中的紫队是同时执行红队和蓝队职能的团队。

### 理解黑客攻击过程
您可以通过遵循黑客攻击过程来执行渗透测试，这是黑客在计划攻击组织时遵循的方法论。以下各节概述了黑客攻击过程的阶段。

#### 画像
黑客攻击过程的第一阶段称为侦察阶段或画像阶段。在此阶段，黑客使用互联网资源发现有关组织的信息。以下是黑客收集组织信息的一些示例方法：

##### 网站
黑客访问组织的网站以获取联系人姓名、电话号码和电子邮件地址，这些可用于社会工程学攻击。黑客还会查看招聘启事，了解组织正在运行什么软件。例如，如果组织正在寻找 Exchange Server 管理员，那么它很有可能正在运行微软的电子邮件服务器。

##### Google
黑客将花费一些时间在 Google 上搜索他们想要攻击的组织的特定信息。在此步骤中，黑客将使用被称为“Google 黑客语法”的 Google 关键字来定位有关组织的特定信息。您可以在 Google 中用于执行搜索的关键字示例包括：`site:` 用于搜索特定网站的内容，`inurl:` 用于搜索网站 URL 中的内容，以及 `filetype:` 用于搜索特定文件，如 PDF 或 Word 文件。以下是一些您可以使用的 Google 搜索示例：

##### Whois 数据库
黑客用来发现组织信息的另一种流行方法是查明组织使用的 IP 地址和 DNS 服务器。为了查找此信息，黑客可以使用 whois 数据库网站或程序对组织进行搜索，以获取 IP 地址和 DNS 服务器列表。可用于 whois 数据库搜索的网站示例是 [https://www.whois.com/whois/](https://www.whois.com/whois/)（见图 20-5），或者您可以在 Kali Linux 中使用 `whois` 命令行工具。

##### DNS 画像
一旦黑客掌握了组织购买的 IP 地址，他们就准备好进入下一阶段——扫描阶段。但在离开画像阶段之前，黑客将尝试从组织的 DNS 服务器检索信息。以下代码列表显示了黑客使用 `dig`（一种流行的 Linux 程序）查询 DNS 并从 DNS 检索信息：

*   `dig www.certworld.loc` — 此命令报告 www.certworld.loc 的 IP 地址。
*   `dig certworld.loc MX` — 此命令查找 certworld.loc 的邮件服务器。
*   `dig certworld.loc NS` — 此命令查找 certworld.loc 的 DNS 服务器。
*   `dig certworld.loc axfr` — 此命令尝试查看 certworld.loc 的所有 DNS 数据。

请注意，黑客攻击过程中 85% 的时间花在画像阶段和收集黑客可用于攻击的信息上。

![Image](exam.jpg)

**画像阶段执行的侦察被称为 `被动侦察`，因为黑客不接触组织的系统——黑客是从公开来源提取信息。**
