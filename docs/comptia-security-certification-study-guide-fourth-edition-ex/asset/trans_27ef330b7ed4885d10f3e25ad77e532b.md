

# 网络设备概述

作为安全专业人员，要执行任何工作职能，都需要熟悉许多不同的网络设备。例如，您可能会被要求在组织内执行安全审计，这涉及识别公司使用的设备，并就使用更安全的设备提出建议。

## 集线器

网络集线器是一种较旧的网络设备，用于将网络环境中的所有系统连接在一起。集线器是 OSI（开放系统互连）模型的第 1 层设备，它只是从一个系统接收信号，然后将该信号发送到集线器上的所有其他端口。例如，查看[图 1-1](#ch01.xhtml#ch1fig1)，您可以看到当计算机 A 向计算机 C 发送数据时，数据在集线器的端口 1 上接收，然后被发送到所有其他端口。

![Image](f0002-01.jpg)

**图 1-1 查看集线器的工作原理**

集线器的缺点是它通过将数据发送到集线器上的每个端口来消耗带宽。如果数据只需要发送给计算机 C，为什么要这样做？网络集线器的另一个缺点是，如果网络上的所有系统都接收到数据，这将是一个安全问题——尽管它们会忽略这些数据，因为这些数据不是发给它们的。计算机 B 和 D 将能够查看网络上的所有流量，因为这些站点也接收流量的副本。这是一个巨大的安全隐患，也是行业摒弃集线器转而使用交换机的原因之一。

## 交换机

网络交换机与网络集线器类似，都用于将网络环境中的所有系统连接在一起，但区别在于交换机是一种第 2 层设备，它通过第 2 层地址过滤流量。回想 Network+ 考试的内容，第 2 层地址称为介质访问控制地址，简称 MAC 地址。MAC 地址是由制造商分配给网卡的硬件地址，格式类似于 `3C-97-0E-E3-52-5C`。

如果查看前面计算机 A 向计算机 C 发送数据的示例，但使用的是交换机，您会注意到交换机从计算机 A 接收数据，但随后通过仅将数据发送到目标系统所在的端口（在本例中为端口 4）来过滤流量（请参阅[图 1-2](#ch01.xhtml#ch1fig2)）。

![Images](f0003-01.jpg)

**图 1-2 查看交换机如何过滤流量**

交换机之所以能过滤流量，是因为它将连接到交换机的每个系统的 MAC 地址以及该系统连接的端口存储在 MAC 地址表中。MAC 地址表是存储在交换机内存中的一个表，负责跟踪每个系统连接到哪个端口（请参阅[图 1-3](#ch01.xhtml#ch1fig3)）。

![Images](f0004-01.jpg)

**图 1-3 查看交换机上的 MAC 地址表**

### 冲突域

交换机的另一个重要功能称为**冲突域**，它是一组共享同一网段的系统，因此它们的数据可能会相互冲突。集线器上的所有端口创建单个冲突域，但交换机上的每个端口创建单独的冲突域。例如，使用网络集线器时，如果两个系统同时发送数据，将导致数据冲突。这是因为集线器创建了一个所有系统都可以访问的“共享”网段。使用交换机时，交换机上的每个端口创建一个单独的冲突域，即其自己的网段。将系统连接到交换机上的一个端口时，因为网段上没有其他系统，所以不会发生数据冲突。

![Image](exam.jpg)

> **考试提示**：对于考试，请记住交换机通过仅将流量发送到目标系统所在的端口来过滤流量，从而提供极佳的安全性。您还应该能够描述端口安全、端口镜像和禁用未使用端口的功能等特性。

### VLAN

如今，大多数交换机都支持一种称为虚拟局域网（VLAN）的功能。VLAN 的目的是在一个网络交换机内创建多个网络。实现这一点的一种方法是将交换机上的端口放入 VLAN 分组中。当系统连接到交换机上的一个端口时，它将成为该端口关联的 VLAN 的成员。重要的是，当系统是某个 VLAN 的成员时，它无法与另一个 VLAN 中的系统通信。这就像每个 VLAN 都有自己的交换机，且与其他交换机没有连接。[图 1-4](#ch01.xhtml#ch1fig4) 显示了一个配置了两个 VLAN 的交换机。在本例中，计算机 A 只能与计算机 B 通信，因为它们是 VLAN1 中唯一的系统。如果没有路由器，计算机 A 和计算机 B 无法与计算机 C 和计算机 D 通信，因为不允许跨 VLAN 通信。
