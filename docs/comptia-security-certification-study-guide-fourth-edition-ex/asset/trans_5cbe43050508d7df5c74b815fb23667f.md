

### 许多客户共享服务
如果多个客户订阅了同一项服务，一个客户是否可能访问另一个客户的数据？您需要信任提供商将客户信息与其他订阅者的信息隔离开来。这通常通过虚拟化技术来实现。

### 法律问题
在大多数情况下，如果执法部门有合法理由要求数据提供商提供对其存储信息的访问权限，提供商将不得不全面披露该信息。

### 谁来管理安全
弄清提供商提供了哪些服务，以及您是否负责系统的安全配置，这一点至关重要。大多数公有云提供商必须定期接受第三方安全审计。

在考虑部署网络服务和应用程序时，您可以选择在本地安装、由他人托管，或使用云服务。以下列表概述了这些选项中的每一个：

### 本地部署
本地部署意味着您在您站点内的服务器上安装应用程序或服务。这涉及大量的前期时间和成本，包括规划部署、购买服务器、软件和高可用性解决方案。您还负责维护服务器。

### 托管
采用托管解决方案时，您的组织仍然购买软件和许可证并维护服务器，但您需要支付费用给第三方公司，由其提供服务器和基础设施来托管应用程序。

### 云
采用云解决方案时，您支付月度订阅费，软件已安装在后台的服务器上（您无法访问这些服务器）。您可以对软件和服务进行配置更改以满足您的需求，但无需维护服务器——它们由云提供商维护。

以下是与云计算相关的一些其他术语和概念，您应为 Security+ 认证考试熟悉这些内容：

### VDI/VDE
虚拟桌面基础设施（`VDI`）和虚拟桌面环境（`VDE`）是虚拟化功能，它们在中央服务器上托管用户的桌面环境，然后将其交付给瘦客户机。用户与桌面操作系统进行交互，就像它在本地安装一样。

## 弹性与自动化
虚拟化和云服务提供了许多弹性和自动化工具及功能，可帮助降低环境中的安全风险。

### 自动化/脚本
为了帮助降低安全风险，尽可能自动化更多任务非常重要。自动化的好处在于，因为您只是日复一日地运行自动化任务或脚本，所以会犯更少的错误。更少的配置错误意味着环境中更少的漏洞。

您不仅应该拥有`自动化的处理流程`（配置步骤），还应该自动化任何`持续监控`步骤，以帮助确保不会错过任何安全警报或通知。您还希望自动化`配置验证`，即审查环境的配置设置以确保其准确性的过程。

### 模板和主镜像
基于云的环境中的`模板`允许您在创建虚拟机时向其应用标准配置设置。将这些配置设置模板与操作系统的`主镜像`相结合，可让您快速预配虚拟机，并在几分钟内让它们运行起来。

### 非持久性
在使用云解决方案或虚拟化环境时，您有多种方法可以撤销对系统所做的更改。以下列表概述了撤销更改的解决方案：

#### 创建快照
在虚拟化环境中，您可以创建快照，它们类似于配置状态的保存点。

#### 还原到已知状态
您可以将系统还原到快照，以撤销自该快照以来的更改。

#### 回滚到已知配置
某些软件会自动保存您的配置状态，并允许您回滚到其中一个已保存的配置状态。

### 弹性与可扩展性
弹性和可扩展性是任何基于云的解决方案的两个重要特征。在云计算语境中，`弹性`是指根据工作负载需求启动新服务器，然后在工作负载减少时关闭这些服务器。`可扩展性`是指确保随着您的需求增长，解决方案能与您同步增长。

### 分布式分配
许多私有云解决方案的一项出色功能是`分布式分配`，它允许您将虚拟机分布在许多主机系统上。大多数私有云解决方案会查看主机系统上的现有工作负载，并就虚拟机应在哪个主机系统上运行给出建议。

## 云功能
新的 Security+ 考试扩展了您必须理解的一些云概念，以便通过认证考试。在本节中，您将了解一些不同的云相关功能。

### 容器
正如本章前面提到的，容器是一项功能，允许您在隔离环境中运行应用程序，该环境拥有分配给它的自己的资源，非常类似于虚拟机。容器与 VM 的区别在于，容器更轻量级，因为它共享主机系统的操作系统内核。这就是为什么容器在提供 VM 隔离功能的同时，性能却优于 VM。Docker 是提供容器的软件示例，也是 Windows 10 的一项功能。

### 微服务/API
微服务是编程到应用程序编程接口（`API`）中的一项功能或组件，随后可由其他应用程序调用。微服务的好处在于，每个组件都是一个完整的工作单元，可以独立于 `API` 中的其他组件进行发布和更新。

`应用程序编程接口`是开发人员创建的一组函数，允许其他开发人员调用此功能。例如，假设我们经营一家创建防火墙产品的公司。作为防火墙设备的一部分，我们有一个 Web 界面，包含所有常见的防火墙配置选项，允许管理员对其进行配置。作为产品的创建者，我们还可以创建一个 `API`，其中包含一系列函数，这些函数是可以对设备进行的不同类型的配置更改（参见[图 16-3](#ch16.xhtml#ch16fig3)）。创建 `API` 的好处是，它允许其他开发人员创建他们自己的 Web 管理页面（如果他们不喜欢我们创建的页面）。当开发人员创建他们的 Web 页面时，只需向其中添加链接或按钮，以调用 `API` 即可。请注意，如今我们称之为“Web API”，因为它们通过 HTTP 流量进行。

### 基础设施即代码
基于云的环境和集成在云中的基础设施组件的一大好处是，我们可以利用软件定义网络和软件定义可见性等技术：

#### 软件定义网络（SDN）
`SDN` 是一种从中心点管理网络设备配置的方式。`SDN` 使用控制器应用程序和 `API` 将配置更改集中部署到网络设备。

#### 软件定义可见性（SDV）
`SDV` 是一种监控整个网络环境的方法，具备实时响应安全事件的能力。
