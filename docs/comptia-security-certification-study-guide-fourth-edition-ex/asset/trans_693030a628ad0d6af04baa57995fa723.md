

### 下一代安全 Web 网关 (SWG)

安全 Web 网关 (SWG) 是一种网关产品，所有流量都通过它进行传输，它能防止用户访问互联网或云中可能包含恶意软件的网站，这些恶意软件可能会感染其系统或内部网络/云网络。

![Image](exam.jpg)

**务必了解本节提到的云安全解决方案。特别要注意，CASB 允许您定义安全策略，这些策略应用于从当前本地环境流向云的网络流量。**

### 云环境中的防火墙考量

当您寻找适用于云环境的防火墙产品时，应考虑多个因素以辅助决策：

- **成本** 防火墙解决方案的成本。
- **分段需求** 如果您需要一种防火墙解决方案，允许您处理多个网段并控制这些网段之间的流量。
- **开放系统互连 (OSI) 层** 防火墙在 OSI 模型的哪一层运行，以及您希望按何种数据类型过滤流量。例如，如果您想要检查数据包的有效载荷，您将需要使用应用层防火墙（第 7 层），而不是包过滤防火墙（第 3 层）。

### 云原生控制与第三方解决方案

关于在云中实施安全控制，最后一点建议是：您应首先调查云解决方案自带的安全控制（原生控制），然后再寻找第三方解决方案。CSP 不断改进其云解决方案的功能，并增加内置于其产品中的安全控制数量。

## 认证总结

在本章中，您学习了云计算概念以及保护云资源应考虑的不同因素。以下是备考 Security+ 认证考试时，关于本章需要记住的一些要点：

- 虚拟化技术允许您在单台物理服务器上运行多台虚拟化计算机。
- 您可以将快照与虚拟机配合使用，作为将系统恢复到先前状态的一种方法。
- 云计算是通过互联网托管服务，为企业省钱，因为它们不必安装自己的服务器。
- 考试需了解的三种主要云模型是 SaaS、PaaS 和 IaaS。
- 容器类似于轻量级虚拟机，因为它们共享宿主系统的操作系统内核。
- 要着眼于使用云安全控制在云中实施安全。

### 两分钟演练

#### 虚拟化与虚拟化安全

![Image](boxsq.jpg) 虚拟化允许您在单台宿主计算机上运行多个操作系统。

![Image](boxsq.jpg) 确保每台虚拟机都已打补丁并受到保护。务必确保宿主计算机在物理上是安全的。

![Image](boxsq.jpg) VM 蔓延是指公司失去对组织内已创建虚拟机数量的跟踪，且没有针对虚拟机的创建、管理和退役流程。

![Image](boxsq.jpg) VM 逃逸是未打补丁的虚拟化环境面临的安全风险。VM 逃逸允许应用程序从 VM 内部访问宿主系统。考试要点：您需要为虚拟化环境打补丁，以防范 VM 逃逸。

#### 云计算概念

![Image](boxsq.jpg) 云计算允许您通过互联网使用提供商的服务来托管您的电子邮件和数据库服务器，同时您可以远程连接并管理这些服务器。

![Image](boxsq.jpg) `云服务提供商 (CSP)` 是向您提供云服务的公司。

![Image](boxsq.jpg) `托管服务提供商 (MSP)` 是为您管理云环境并处理许多 IT 职能的公司，例如预配用户、管理云服务、执行数据备份和恢复以及监控活动。

![Image](boxsq.jpg) `托管安全服务提供商 (MSSP)` 是负责处理您环境安全管理的公司。MSSP 用于云环境的安全配置、活动监控、IDS 和防火墙的管理、补丁管理、响应安全事件以及在组织内执行安全评估。

![Image](boxsq.jpg) 在软件即服务 (SaaS) 云模型中，应用程序提供给客户，而客户无需安装该应用程序（如 Hotmail、Gmail 或 Microsoft 365）。

![Image](boxsq.jpg) 使用平台即服务 (PaaS) 云模型时，CSP 提供运行时环境和开发工具，以便在云中创建应用程序。

![Image](boxsq.jpg) 使用基础设施即服务 (IaaS) 时，云服务提供商为客户提供创建虚拟数据中心的方式，包括创建虚拟网络、存储和虚拟机。

#### 云网络安全解决方案

![Image](boxsq.jpg) 您应使用权限、加密和复制技术来保护存储资源。

![Image](boxsq.jpg) 您应使用网络安全控制来创建虚拟网络、公共和私有子网以及分段功能。

![Image](boxsq.jpg) 着眼于将安全组和容器安全用于计算资源。
