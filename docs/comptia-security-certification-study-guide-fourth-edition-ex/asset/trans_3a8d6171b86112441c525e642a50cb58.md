

# 应用程序攻击与安全开发

## 常见应用程序攻击

![Image](boxsq.jpg) SQL 注入攻击是指黑客将 SQL 语句插入应用程序的表单中，以尝试控制应用程序的行为。

![Image](boxsq.jpg) 缓冲区溢出攻击是指黑客向应用程序发送过多数据，这通常会导致黑客获得具有管理员权限的系统 Shell 访问权限。

![Image](boxsq.jpg) 零日漏洞利用是指易受攻击应用程序的供应商尚不知情，但黑客社区已知晓的漏洞利用。

![Image](boxsq.jpg) 为防止应用程序攻击，开发人员必须确保在处理发送给应用程序的任何输入之前对其进行验证。网络管理员可以通过定期为所有软件和操作系统打补丁来防止应用程序攻击。

## 安全应用程序开发概念

![Image](boxsq.jpg) 请记住，应用程序应按以下顺序部署到相应环境中：`Development` → `Test` → `Staging` → `Production` → `Quality Assurance (QA)`。

![Image](boxsq.jpg) 开发人员通过实现 `try/catch` 块，在大多数编程环境中实现错误处理。

![Image](boxsq.jpg) 输入应用程序的任何数据在被处理前都应经过验证。

![Image](boxsq.jpg) 应使用存储过程来帮助防止 SQL 注入攻击。

![Image](boxsq.jpg) 在分布式应用程序中，应在客户端和服务器端实施输入验证（尤其是在服务器端）。

## 实施主机与应用程序安全

![Image](boxsq.jpg) 您可以通过使用允许列表（以前称为白名单）来控制允许在系统上运行的应用程序。

![Image](boxsq.jpg) 您可以通过使用阻止/拒绝列表（以前称为黑名单）来禁止特定应用程序在系统上运行。

![Image](boxx.jpg) **A、C** 和 **D** 不正确。缓冲区溢出攻击是指黑客向应用程序发送过多数据，导致数据存储在缓冲区区域之外。目录遍历是指黑客在 URL 中放置 `../..` 以尝试跳出网站文件夹并访问 Web 服务器上的信息。跨站脚本是指黑客找到一种方法将客户端脚本发送到服务器，以便由客户端处理，例如将脚本提交到网站的某个字段中，随后作为数据存储在网站数据库中。当访问该网站的用户显示数据时，代码会在客户端系统上执行。
