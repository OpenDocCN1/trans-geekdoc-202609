

### 透明代理
透明代理是一种代理解决方案，不需要在客户端安装任何软件或进行额外配置。例如，非透明代理解决方案要求你安装代理客户端或代理程序，并配置应用程序将出站请求指向代理服务器。使用透明代理，你无需安装或配置客户端软件；只需将 IP 默认网关设置配置为指向代理服务器即可。用户不会意识到他们已配置为使用代理；他们只会认为默认网关的 IP 地址指向的是路由器地址。

### 应用程序/多用途
代理服务器被称为应用层防火墙，可以检查数据包的许多不同区域，例如数据包的头部和数据部分。这意味着你可以像使用包过滤防火墙那样，按源和目标 IP 地址以及源和目标端口号过滤数据包，但使用应用层代理，你还可以按数据包的数据部分进行过滤。例如，代理会阻止 FTP `put` 命令，但允许 FTP `get` 命令通过代理/防火墙。

### 内容/URL 过滤
代理服务器具备根据网站的 URL 或 URL 中发现的关键字，阻止用户访问不同网站的能力。

#### 路由器和 ACL
企业级设备（如思科等厂商的路由器）内置了许多安全功能。例如，在思科路由器上，你可以创建访问控制列表 (ACL)，配置路由器在每个数据包到达时进行检查，并分析数据包中的第 3 层 (IP) 和第 4 层 (TCP/UDP) 地址，以确定是否允许其通过路由器。

路由器还内置了许多安全功能，可防范已知的安全漏洞，例如 DDoS 防护功能可阻止疑似 DDoS 攻击的流量，反欺骗功能可阻止疑似被欺骗的数据包（有人篡改了其源地址），以防止欺骗路由器允许数据包通过 ACL。

#### 其他安全设备和技术
Security+ 考试大纲要求你了解认证考试所涉及的其他类型安全设备。以下是需要熟悉的其他安全设备列表：

### Web 安全网关
Web 安全网关是一种设备或软件，可保护你的网络免受互联网上恶意内容的侵害。Web 安全网关不仅能保护员工免受网络上不当内容（如色情内容）的侵害，还能扫描内容中的恶意代码，并通过确保员工不在网络上发布敏感信息，为公司提供 `数据丢失防护 (DLP)`。

### VPN 聚合器
你可以通过让所有员工都通过 VPN 聚合器来访问网络，从而集中管理虚拟专用网络 (VPN) 访问。VPN 聚合器是配置身份验证和加密协议的地方。VPN 聚合器还支持高可用性，确保其始终可用以响应来自客户端的 VPN 请求。实施 VPN 解决方案时，你可以配置 VPN 聚合器以允许客户端远程连接到网络。或者你可以实施远程访问，使用 VPN 聚合器将一个站点连接到另一个站点（称为站点到站点 VPN），以允许整个办公室通过安全连接进行通信。在这种情况下，客户端计算机不需要像在客户端接入场景中那样手动建立 VPN 连接。

### 使用入侵检测系统
让防火墙保护网络免受不必要流量的侵害绝对是必须的，但网络安全远不止实施防火墙解决方案。你需要确保配置系统以监控内部网络活动，以便在潜在威胁失控之前识别它们。

在本节中，你将了解入侵检测系统以及如何对 Snort（一种非常流行的基于网络的入侵检测系统）进行基本配置。

#### IDS 概述
`入侵检测系统 (IDS)` 负责监控系统或网络上的活动，然后记录或通知管理员任何可疑活动。

##### 分析方法
IDS 如何确定存在可疑流量，取决于 IDS 执行的分析类型。以下部分概述了 IDS 用于确定是否存在可疑流量的不同方法。

**基于特征的系统**  
对于基于特征的 IDS，IDS 具有一个特征文件，其中列出了被视为可疑的活动。当 IDS 捕获活动时，它会将该活动与特征数据库进行比较，如果匹配，则发出入侵通知。

例如，你可能有一个系统，当在短时间内从单个 IP 地址向同一目标系统的多个端口发送大量 SYN 消息时发出通知。这是端口扫描的典型特征。

基于特征的系统的优点是误报很少——意味着极少的虚假警报——因为基于特征的系统完全基于你在系统上配置的特征。因为你在寻找特定活动，所以虚假警报的数量有限。

**基于异常的系统**  
基于异常的系统了解什么是正常活动（基线），然后将超出该正常活动范围的任何行为视为“可疑”活动。基于异常的监控系统通常根据使用系统的人的行为来确定基线。这被称为 `基于行为的异常` 监控系统。

基于行为的异常系统的优点是你不需要配置已知可疑活动的定义文件；系统根据用户的活动学习什么是正常的。基于行为的系统的缺点是任何超出常规的行为都被视为可疑，这会导致大量的虚假警报（误报）。

**启发式/行为分析**  
启发式分析是一种基于存储在数据库中的供应商生成规则来识别恶意活动的分析类型，这些规则随后被检测软件使用。供应商规则是基于过往处理恶意活动的经验创建的。启发式分析是防病毒软件常用的方法。在病毒检测中，启发式分析的目标是检测未知的新病毒。病毒防护软件通常在称为 `虚拟机 (VM)` 的隔离区域中运行程序。然后病毒防护软件分析程序执行时的所有行为，并将其与过往经验进行比较。例如，防病毒软件可能会查找文件覆盖、程序自我复制或试图隐藏自身等恶意活动迹象。
