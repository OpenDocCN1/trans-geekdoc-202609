### MAC 地址过滤

大多数无线网络允许您限制哪些无线网卡可以连接到无线接入点。您可以通过找出您想允许连接的系统的 `MAC` 地址，然后将路由器配置为拒绝除您输入的 `MAC` 地址以外的所有系统的流量，来限制哪些系统可以连接到您的无线网络。这称为 *MAC 地址过滤*。

默认情况下，无线接入点未配置 `MAC` 地址过滤，因此请务必对其进行配置。请注意，单靠 `MAC` 过滤无法阻止坚定的黑客。坚定的黑客可以监控空中的流量，查看授权客户端的 `MAC` 地址，然后欺骗该地址，使黑客的流量被允许通过。[图 9-6](#ch09.xhtml#ch9fig6) 显示了在无线接入点上配置 `MAC` 过滤的过程。

### 天线放置和功率级别

另一个重要的安全最佳实践是无线接入点的放置位置。您应将无线接入点放置在大楼的某个区域，该区域允许所有无线客户端连接，但将无线网络向场外的暴露降至最低。例如，您不应将无线接入点放置在靠近大楼外墙的位置，因为这种放置可能允许场外人员连接到无线网络。无线接入点应放置在大楼中心位置，以便大楼外部客户端的信号难以到达接入点（请参阅[图 9-7](#ch09.xhtml#ch9fig7)）。

配置无线接入点时，您可能还想调整功率级别，以控制接入点的信号强度。如果降低功率级别，无线信号的传播距离将缩短，这将再次限制来自场外人员甚至设施内其他区域人员的连接。您可以通过设备的 Web 配置界面调整大多数无线接入点的功率级别。

### 网关认证

无线热点常用的一种技术是配置 *网关认证*，它强制用户在允许访问 Internet 之前通过网页向网络进行身份验证。组织可以使用网关认证来拦截所有发往 Internet 的流量。在允许流量通过路由器之前，用户必须登录或至少接受使用条款。当您希望允许访问您设施的访客使用 Internet 时，实施网关认证是个好主意。

![Image](exam.jpg)

**针对 Security+ 考试，请记住网关认证可用于在授予无线访问权限之前，让用户接受可接受使用协议。**

### 加密无线流量

确保您正在加密从无线客户端到接入点的任何流量。虽然您可以使用 `WEP`、`WPA`、`WPA2` 或 `WPA3` 来加密流量，但请记住，您应始终使用最安全的协议——目前是 `WPA2` 或 `WPA3`。为了强调实施某种级别加密的重要性，让我们回顾一下关于无线加密协议的一些关键点。

`WEP` 是用于加密无线客户端和接入点之间内容的原始协议。配置无线加密协议时，您必须使用加密密钥配置无线接入点，然后确保每个无线客户端都使用相同的密钥。请注意，`WEP` 绝不应使用，因为 `WEP` 加密很容易被破解。我曾在三分钟内破解 128 位 `WEP` 加密。您应该使用接入点支持的最强无线加密协议，目前是 `WPA2` 或 `WPA3`。始终使用您的无线接入点和无线网卡支持的最大加密密码强度（例如，使用 128 位而非 64 位）。

关于使用无线加密协议的另一点是，它不仅能加密您的流量，而且任何想要连接到您无线网络的人都必须知道密钥，并在连接无线网络时将其无线客户端配置为使用该密钥。如果他们不知道密钥，就无法连接到无线网络！这有助于确保未获授权使用无线网络的人员无法连接到无线网络。

### VPN 解决方案

大多数公司对使用无线网络有安全顾虑，这是有充分理由的。黑客可以绕过 `MAC` 过滤，破解加密密钥，并使用 Kismet 等无线扫描程序发现无线网络，即使已禁用 `SSID` 广播。那么，如何确保无线网络的安全呢？

大多数使用无线网络且有极高安全需求的大公司会将 `VPN` 解决方案与其无线客户端配合使用。他们将无线客户端视为任何其他远程用户：“如果您不在现场但想访问网络，则需要通过 `VPN` 连接。” 这种对虚拟专用网络的高度依赖，是因为 `VPN` 解决方案提供了高级别的安全性。
