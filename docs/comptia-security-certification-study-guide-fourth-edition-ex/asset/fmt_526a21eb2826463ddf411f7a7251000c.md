
# 参加测试

要参加测试，请遵循上一节提供的说明，注册并激活您的 Total Seminars Training Hub 账户。注册后，您将被带到 Total Seminars Training Hub。从 Training Hub 主页，在页面顶部的“Study”下拉菜单中选择 **CompTIA Security+ Study Guide (SY0-601)**，或从主页的“Your Topics”列表中选择，然后点击 TotalTester 链接以启动 TotalTester。然后您可以选择自定义测验选项，并在 Practice Mode 或 Exam Mode 中开始自我测试。所有考试都提供总体成绩和按域细分的成绩。

## Pre-Assessment Test

除了考试题目外，TotalTester 还包含一项 CompTIA Security+ 预评估测试，帮助您在阅读本书之前评估对相关主题的理解程度。要启动预评估测试，请点击 **CompTIA Security+ Study Guide (SY0-601) TotalTester**。CompTIA Security+ 预评估测试包含 20 道题，并在 Exam Mode 下运行。完成测试后，您可以通过点击 **See Detailed Results** 来查看带有答案和详细解释的题目回顾。完成预评估测试后，请参阅在线 PDF “Pre-assessment Exam in TotalTester: Analyzing Your Results”（稍后在本附录中介绍），根据您的分数获取推荐的学习计划。

# Glossary

**access control entry (ACE)**   访问控制列表中的一个条目，指定安全主体（如特定用户）或用户组在对象上的审核条目或访问权限。

**access control list (ACL)**   对象的安全权限或审核设置列表。

**access permissions**   在操作系统中授予对象的各种类型的访问权限。Windows 包含多种访问权限，包括读取、执行和修改。

**account**   包含使人员能够访问和使用网络的信息，包括用户名和登录规范，如登录时间和密码。*另请参阅* [user account](#ch23_glossary.xhtml#glos391)。

**account lockout**   在一定数量的登录失败尝试后锁定账户的功能（三次失败尝试是常见选择）。通常，被锁定的账户在管理员解锁前无法使用。这有助于防止黑客入侵账户。

**account policies**   一组关于密码使用和账户锁定的规则。

**account restrictions**   确定用户何时以及如何获得网络访问权限。

**ACE**   *参见* [access control entry](#ch23_glossary.xhtml#glos1)。

**acknowledgment (ACK)**   接收方计算机发送给发送方计算机的一个信息包，用于验证传输已被接收。传输失败将生成否定确认 (NACK)。

**ACL**   *参见* [access control list](#ch23_glossary.xhtml#glos2)。

**Active Directory**   一种 Microsoft Windows 目录服务，存放网络账户、组和组策略对象。

**active hub**   星型拓扑中用于再生信号并将数据分发到连接到集线器的每个节点的集线器设备。与无源集线器不同，有源集线器需要供电。*另请参阅* [hub](#ch23_glossary.xhtml#glos175)。

**active partition**   指示系统通电时引导哪个可引导分区。

**adapter**   插入系统以提供功能的卡，如网络适配器，提供网络连接。

**address resolution**   使用另一种地址形式查找主机地址的过程。例如，当使用 IP 地址时，必须将其解析为 MAC 地址。

**Address Resolution Protocol (ARP)**   用于根据 IP 地址确定主机的 MAC 地址。为实现这一功能，ARP 会发送一条广播消息（一个包含其试图查找的系统 IP 地址的 ARP 请求包）。本地网络上的所有系统都会检测到该广播消息，拥有 ARP 正在查找的 IP 地址的系统会通过在 ARP 回复包中将其物理地址发送给源系统来进行回应。物理/IP 地址组合随后存储在源系统的 ARP 缓存中以供将来使用。*另请参阅* [Media Access Control](#ch23_glossary.xhtml#glos226)。

**administrator account**   用于管理 Windows 服务器和网络设置的账户。此账户在安装期间创建，拥有对服务器的无限访问权限。以管理员身份登录服务器时必须小心，因为管理员访问权限包括关闭服务器和擦除关键数据的能力。

**American Standard Code for Information Interchange (ASCII)**   标准字母和其他键盘字符的计算机可读二进制格式表示。

**application layer**   为应用程序发出网络请求提供一致方式的 OSI 层。应用层协议的示例包括 HTTP、SMTP 和 FTP。

**application server**   运行网络应用程序（如电子邮件或数据库应用程序）的服务器。通常，客户端从用户的桌面连接到应用程序服务器。

**archiving**   将旧文件从文件服务器移出以释放磁盘空间给新文件的过程。如果稍后需要旧文件，可以取消归档并检索它们。归档数据可以保存到 CD、DVD 或磁带。
