
# 非屏蔽双绞线

如果你曾接触过电话线，那么**UTP**线缆对你来说并不陌生。用于网络的典型双绞线包含四对导线。线缆中每一对导线的两根线相互缠绕。导线中的扭绞有助于屏蔽电磁干扰。UTP的最大传输距离为100米。

UTP线缆使用一种称为注册插孔45的小型塑料连接器，最常被称为**RJ-45**。**RJ-45**类似于电话连接器，不同之处在于家用电话系统使用四根导线，而网络**RJ-45**连接器包含八个触点，对应UTP线缆中的八根导线。

很容易将**RJ-45**连接器与**RJ-11**连接器混淆。**RJ-11**连接器是电话连接器，具有四个触点；因此，电话线缆中有四根导线。在制作**RJ-45**和**RJ-11**线缆时，你需要一种特殊的压线工具，以使连接器中的针脚与线缆内的导线接触。

UTP线缆比同轴电缆更容易安装，因为其柔韧性好、体积小，更容易绕过拐角。然而，双绞线比同轴电缆更容易受到干扰，因此不应在包含大型电气设备的环境中使用。

UTP布线有不同等级，称为级别或类别。每一类UTP布线都是为特定类型的通信或传输速率设计的。[表 1-1](#ch01.xhtml#ch1tab1) 总结了不同的UTP类别——目前最流行的是**CAT 5e**，其传输速率可达1,000 Mbps以上，即每秒1千兆位（**Gbps**）。

在使用UTP布线的网络中工作时，你会遇到用于不同目的的不同类型线缆。例如，有时你会使用直通线，有时则使用交叉线。

### 直通线

**CAT 5** UTP布线在网络发送和接收信息时通常只使用四根导线。在八根导线中被使用的四根是第1、2、3、6号线。[图 1-7](#ch01.xhtml#ch1fig7) 显示了计算机上的发送和接收针脚以及交换机上的针脚，这通常是你将计算机连接到的设备。当你将线缆两端的同一针脚配置为相同的导线时，这被称为直通线。

![Images](f0012-01.jpg)

**图 1-7：直通线针脚图**

你会在图中注意到，第1、2号线用于从计算机发送数据（**TX**），而第3、6号线用于在计算机上接收信息（**RX**）。你还会注意到，计算机上的发送针脚（**TX**）通过第1、2号线连接到交换机上的接收针脚（**RX**）。这一点很重要，因为你要确保从计算机发送的数据能被交换机接收。你也要确保从交换机发送的数据能被计算机接收，因此你会注意到交换机上的发送针脚（**TX**）通过第3、6号线连接到计算机上的接收针脚（**RX**）。这将使计算机能够接收来自交换机的信息。

关于[图 1-7](#ch01.xhtml#ch1fig7) 最后要注意的是，计算机上的针脚1通过同一根导线连接到交换机上的针脚1，因此称为*直通*。你会注意到[图 1-7](#ch01.xhtml#ch1fig7) 中所有针脚都直接对应连接到另一侧。

### 交叉线

在某些情况下，你可能需要在没有交换机的情况下将两个计算机系统直接连接在一起，即网卡直连网卡。或者你可能需要将一台交换机连接到另一台交换机。在任何连接同类设备的场景下，你都无法使用直通线，因为一端的发送针脚会连接到另一端的发送针脚，如[图 1-8](#ch01.xhtml#ch1fig8) 所示。如果数据没有发送到接收针脚，计算机如何拾取数据？既然这样行不通，你就需要将线缆的接线改为所谓的交叉线。

![Images](f0013-01.jpg)

**图 1-8：使用直通线连接两台计算机将无法工作。**

要在不使用交换机的情况下将两个系统直接连接在一起，你需要通过在线缆一端交换第1、2号线与第3、6号线来制作一根交叉线，如[图 1-9](#ch01.xhtml#ch1fig9) 所示。你会注意到，计算机A的发送针脚连接到计算机B的接收针脚，从而允许计算机A向计算机B发送数据。计算机B向计算机A发送数据同理——计算机B的第1、2针脚连接到计算机A的第3、6针脚，以便计算机A能接收来自计算机B的数据。

# 屏蔽双绞线

**STP**线缆与UTP布线非常相似，但它与UTP的区别在于，它在保护外皮内部使用了一层绝缘层，有助于保持信号质量。

# 光纤

要讨论的第二种布线类型是光纤布线。光纤布线不同于双绞线，因为双绞线使用铜线传输电信号。光纤使用光纤以调制光脉冲的形式传输数字数据信号。一根光纤由一个极细的玻璃圆柱体组成，称为纤芯，周围包裹着一层同心玻璃，称为包层。每根线缆包含两根光纤——一根用于发送，一根用于接收。纤芯也可以是光学级透明塑料，包层可以由将信号反射回光纤以减少信号损耗的凝胶构成。

光纤主要有两种类型：

- **单模光纤 (SMF)** 使用单束光（称为模式）来进行远距离传输
- **多模光纤 (MMF)** 同时使用多束光（模式），每束光以不同的反射角度运行，以进行短距离传输

![Image](exam.jpg)

> **考试请记住：光纤是一种更安全的线缆类型，因为它不传输电信号，而是以光脉冲形式传输数据。**

光纤支持多达1,000个站点，并可将信号传输至2公里及以上。光纤也高度免疫来自无线电发射机、电弧焊机、荧光灯和其他电气噪声源的外部干扰。另一方面，光纤是这些布线方法中成本最高的，小型网络不太可能需要这些特性。

光纤可以使用多种类型的连接器，如直头（**ST**）连接器、Lucent连接器（**LC**）和方形（**SC**）连接器。**ST**连接器基于BNC风格连接器，但使用光纤而非铜缆。**SC**连接器呈方形，某种程度上类似于**RJ-45**连接器，而**LC**连接器是**SC**连接器尺寸的一半，专为布线密集区域（如配线架）设计。

无论连接器类型如何，光纤的工作速度相同，通常为1,000 Mbps及以上。你唯一需要担心的是连接器必须与其连接的设备匹配，因为这两种连接器类型不能互换。
