

# 安全培训计划设计

## 基于角色的培训内容

设计安全培训计划时的第一个重大决策，是确定哪些内容适合呈现给组织内不同的员工角色或部门。由于安全是一个至关重要的概念，也是你希望在培训和意识研讨会期间吸引受众注意力的领域，因此你要确保培训内容与受众相关，并基于工作角色。例如，你不希望用防火墙如何实施的复杂讨论让业务用户昏昏欲睡，因此应将技术性安全培训留给技术团队。该职位的任何成员都将被要求参加详细的技术培训。以下是组织中不同工作角色或员工类型应接受培训内容的基本大纲：

### 业务用户
典型业务用户应接受教育的安全领域包括密码最佳实践、社会工程学、病毒防护以及物理安全的重要性。

### 技术团队
技术团队由系统管理员、网络管理员、安全管理员组成，可能还包括桌面支持团队。这些人员需要接受提供安全性的技术解决方案培训，例如入侵检测系统、防火墙和恶意软件防护解决方案。

### 管理层
你将采取完全不同的方法来对待管理团队或高管用户。管理和高管团队的成员通常更关心*为什么*要做这些事，而不是*如何*做这些事。在提高管理层的安全意识时，重点应放在为什么他们应该支持拟议的安全计划上，通过向他们提供过去企业因安全事件而损失巨额资金和/或遭受声誉损失的案例。此外，还要调查是否有任何法律法规要求组织努力保护其资产。务必将调查结果纳入培训中，或寻找并展示组织因未实施适当的安全措施保护资产而被追究法律责任的过往案例。另一个好主意是找到保险公司因公司违反保单要求（即公司未尽合理努力保护其资产）而拒绝赔付的案例。这些都是在面向管理层的安全意识研讨会上能抓住与会者注意力的信息类型示例。

### 数据所有者
数据所有者对数据负责，应接受如何保护该数据的培训。这包括培训数据所有者确定数据的分类标签、确定所需权限，以及确定是否应使用加密。

### 系统所有者
系统所有者对资产（如服务器、工作站或设备）负责。系统所有者应接受各类系统价值的培训，以及应用于保护资产的安全控制类型培训。

### 特权用户
特权用户是指被分配了额外权限以执行管理任务的人员。培训这些人员如何正确执行这些任务非常重要，因为你不希望他们犯下可能造成漏洞的配置错误。

除了接受特定工作角色的安全培训外，所有员工都应经历 `onboarding process`（入职培训流程），在该流程中他们将针对其特定工作接受适当培训，从而能够在入职培训后立即成为高效员工。

## 政策意识

在培训组织内所有人员时，请确保教育每个人了解能降低安全事件发生可能性的主题。教育员工、技术团队和管理层了解安全政策的目的以及安全政策中包含的规则类型。确保教育员工什么是个人可识别信息（PII），并举例说明贵公司存储的 PII 类型，以便员工知道不得泄露该信息，并能专注于保护该信息。

教育所有员工了解贵组织的信息分类系统和数据标签。正如本章前面所述，`data label`（数据标签）是分配给信息的分类标签，例如“绝密”。确保员工了解不同的授权级别可以访问不同的数据标签。

你还需要确保花时间教育员工了解设备安全处置政策，并确保所有员工理解销毁硬盘和清除旧设备配置的重要性。

最后，确保员工理解遵守公司所在行业法律法规的重要性。

## 培训技术的多样性

你可能希望使用多种不同的方法向员工提供意识培训，因为人们的学习方式多种多样。例如，有些人只能通过讲师主导的课程学习，而另一些人则可以通过观看视频或阅读书籍学习。你可以使用以下任何一种方法，或多种方法的组合，用于组织内的 `continuing education`（持续教育）：

### 研讨会
教育员工最流行的方法之一是举办研讨会，由安全专家向参与者讲解相关问题。这些研讨会通常为半天或全天课程。

### 午餐学习会
午餐学习会类似于研讨会，但时长约 50 分钟，旨在探讨一个特定问题。大多数公司会在员工接受安全教育时提供午餐。

### 计算机基础培训 (CBT)
CBT 是一种员工使用自学工具（如在线提供的培训视频）来学习安全知识的方法。

### 内部网站点
你可以在内部网站点上提供资源，例如描述安全最佳实践的文档。

### 点播视频
一种内部培训方法是将研讨会录制成视频，可从内部服务器下载。

### 游戏化
游戏化是将组织希望鼓励的活动变成游戏。例如，你可以向最先识别并举报内部测试钓鱼邮件的前两名员工发放礼品卡。

### 夺旗赛
夺旗赛是一种学习工具，向参与者提出许多挑战，要求他们运用技能解决比赛中的问题。随着他们解决问题，他们将获得旗帜，旗帜可在平台上兑换积分。例如，有许多夺旗比赛要求安全专业人员运用黑客技能获取旗帜。

### 钓鱼活动
公司可能会利用钓鱼活动来测定其安全培训的有效性，方法是向员工发送电子邮件，试图诱骗他们泄露信用卡号或登录凭据等敏感信息从而危害安全。在这种情况下，公司通过伪造电子邮件（使其看起来像是来自其他人）来冒充他人，要求用户点击链接，然后在一个虚假网站中输入敏感信息。

### 钓鱼模拟
在员工培训期间，你应该演示钓鱼攻击的示例或进行模拟，以便员工在钓鱼攻击发生时能识别出来。这种培训工具旨在确保员工在钓鱼攻击真正发生时知道该采取的正确行动。
