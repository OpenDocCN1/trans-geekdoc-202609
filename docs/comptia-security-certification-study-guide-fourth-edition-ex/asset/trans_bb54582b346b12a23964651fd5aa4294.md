

## 5. 选择证据源类型

系统提示选择要成像的证据源类型，例如物理驱动器（整个磁盘）、逻辑驱动器（驱动器上的分区）、镜像文件、文件夹内容或 DVD。选择 **Physical Drive**，然后选择 **Next**。

## 6. 选择 USB 驱动器

系统显示系统上的驱动器列表。选择 USB 驱动器，然后选择 **Finish**。

## 7. 指定镜像目标文件

在 **Image Destination** 字段中指定要写入的镜像文件。选择 **Add**，选择 **Raw (dd)** 作为镜像类型，然后选择 **Next**。dd 镜像是许多取证工具支持的标准镜像格式。

## 8. 输入证据信息

系统要求输入证据相关信息。输入以下信息，然后选择 **Next**：

- **Case Number:** `20210602_001`
- **Evidence Number:** `100`
- **Unique Description:** `Suspect’s USB drive`
- **Examiner:** `Bob Smith`
- **Notes:** `Suspect’s USB drive found in top desk drawer`

## 9. 设置镜像目标路径

使用以下信息设置镜像目标，然后选择 **Finish**：

- **Image Destination Folder:** `c:\forensicsimages`
- **Image Filename:** `suspect_usb_drive.dd`
- **Image Fragment Size (MB):** `0`（表示不拆分为多个镜像文件）

## 10. 开始创建取证镜像

选择 **Start** 创建 USB 驱动器的取证镜像（这将花费一些时间，具体取决于 USB 驱动器的大小）。

## 11. 完成操作

镜像完成后关闭 FTK Imager。

## 12. 验证镜像文件

验证在 Windows 的 `c:\forensicsimages` 文件夹中可以看到镜像文件。

### 使用 FTK Imager 创建内存内容镜像

在本练习中，你将学习如何使用 FTK Imager 获取 RAM 内容的镜像。RAM 包含用户最近使用或访问的数据。例如，如果嫌疑人已登录电子邮件或其他软件，你可能能够从 RAM 中捕获其密码。

1. 启动 FTK Imager。
2. 选择 **File** | **Capture Memory**。
3. 在 **Memory Capture** 对话框中，使用以下信息，然后选择 **Capture Memory**：
   - **Destination path:** `c:\forensicsimages`
   - **Destination filename:** `suspect_memdump.mem`
   - **Include page file:** `Enabled`（将页面文件名设置为 `suspect_pagefile.sys`）
4. 内存内容捕获完成后（将花费片刻时间），选择 **Close**。
5. 镜像完成后关闭 FTK Imager。
6. 验证在 Windows 的 `c:\forensicsimages` 文件夹中可以看到镜像文件。

FTK Imager 的优点是免费，并提供一些基本的调查功能，允许你查看本地驱动器的内容或已获取的取证镜像内容。在 [Exercise 21-3](#ch21.xhtml#ch21exer3) 中，你将查看嫌疑人 USB 驱动器的镜像，并使用 FTK Imager 定位已删除的文件。

## Analysis Tools

一旦获取了嫌疑人驱动器的镜像，你就可以对证据执行分析，并在嫌疑人的系统上定位任何感兴趣的文件（通过处理镜像，而非嫌疑人系统上的实际驱动器）。

### Autopsy

**Autopsy** 是一款开源的数字取证分析工具，可用于分析使用 dd 或 FTK Imager 获取的镜像。使用 Autopsy，你也可以添加本地磁盘并直接分析本地驱动器，而无需先创建驱动器镜像（这非常适合学习 Autopsy，但在调查过程中，你应始终使用驱动器的副本进行工作）。

使用 Autopsy，你可以浏览驱动器内容，查看所有文件及任何已删除的文件（参见 [Figure 21-7](#ch21.xhtml#ch21fig7)）。Autopsy 还具有提取相关信息的功能，例如系统上的用户账户、访问过的互联网站点和最近访问的文件，并以易于查找的方式显示这些信息。Autopsy 允许你标记感兴趣的文件，并生成包含标记工件的 Excel 或 HTML 格式报告。你还可以使用 Autopsy 执行关键字搜索。

### 使用 Autopsy 调查本地磁盘

在本练习中，你将使用 Autopsy 调查本地硬盘的内容，定位诸如访问过的互联网站点、用户账户等项目，并识别系统上的加密文件。

1. 从 [https://www.autopsy.com/download/](https://www.autopsy.com/download/) 下载 Autopsy 并将其安装在你的系统上。
2. 安装 Autopsy 后，右键单击桌面上的 Autopsy 图标，选择 **Run As Administrator**。在关于提升权限的用户账户控制对话框中选择 **Yes**。
3. 选择 **New Case**，输入以下信息，然后选择 **Next**：
   - `20210603_Exer21-4`
   - 保持所有其他选项默认。
4. 输入以下可选案例信息，然后选择 **Finish**：
   - **Number:** `20210603_Exer21-4`
   - **Examiner Name:** `Bob Smith`
   - **Phone:** `555-5555`
   - **Email:** `bobsmith@companyxyz.loc`
5. 当提示添加数据源时，注意默认选中 **Local Disk**。同时注意你也可以添加磁盘镜像（即你在之前的练习中创建的镜像）。在本练习中，我们将添加本地磁盘，因为它允许你查看自己系统的信息。选择 **Next**。
6. 选择 **Select Disk**，然后选择安装了 Windows 的硬盘（在我的例子中是 447GB 的 Drive 0）。选择 **OK**。
7. 选择 **Next**。
8. Autopsy 希望在驱动器上使用 ingest 模块。这些模块用于定位驱动器上的关键信息，例如访问过的网站。保持所有模块选中状态，然后选择 **Next**。注意添加驱动器将花费一些时间，因为 ingest 模块正在解析信息。
9. 本地驱动器添加到 Autopsy 后，在左侧展开 **Results**，然后展开 **Extracted Content**。这是 Autopsy 显示关于驱动器内容的通常对调查员有用的信息的地方。
10. 选择 **Encryption Suspected** 以查看硬盘上被怀疑加密的文件列表。
