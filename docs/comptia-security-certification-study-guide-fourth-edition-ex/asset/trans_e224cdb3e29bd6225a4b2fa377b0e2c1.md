# 点分十进制表示法
由四个以十进制书写的 8 位字段组成，字段之间用点（句点）分隔。每个 8 位字段由一个 0 到 255 之间的数字表示。

# 驱动程序
操作系统的一部分，使其能够与设备通信，或协调硬件与计算机之间的通信。针对调制解调器、声卡以及计算机中几乎任何其他组件，都有不同类型的驱动程序。例如，驱动程序使 LAN 适配器能够工作。

# 双工
双工将数据同时写入连接到不同磁盘控制器的两个驱动器。双工不仅确保数据的容错，也确保磁盘控制器的容错。在传统镜像中，只有一个磁盘控制器。如果控制器发生故障，服务器将瘫痪，直到更换该组件。双工为您提供了第二个控制器。每个驱动器连接到其自己的控制器。如果一个控制器发生故障，您仍拥有一个完好的配置。

# 动态主机配置协议 (DHCP)
一种可靠、灵活的手动 TCP/IP 配置替代方案，可为 PC 提供 TCP/IP 参数的自动配置，如 IP 地址、子网掩码和默认网关。

# 动态链接库 (DLL)
按需加载的可执行代码模块。DLL 是与其他应用程序共享代码的一种方式。

# 动态路由
通告其熟悉的路由并传递度量值、其他路由器数量或从其主机到达另一网络所需的跳数（无论是直接到达还是通过另一路由器间接到达）的协议。

# 电子邮件 (e-mail)
从一位网络用户电子传输至另一位网络用户，或跨越互联网传输的邮件消息。

# 封装
为跨网络传输而对数据进行编码的过程。

# 加密身份验证
不涉及以明文传递凭据的用户或其他对象的身份验证。使用加密身份验证时，用户名和密码组合将以加密格式传递给身份验证服务器。

# 加密文件系统 (EFS)
NTFS 卷的一项功能，允许用户加密文件。

# 加密
使用算法隐藏消息、其他文件或通信的内容，通过故意打乱组成该项目的元素来实现。在阅读之前，必须将该项目解密为其原始形式。

# 端到端通信
网络上的通信，仅关注对话两端直接相互交互（例如，电话通话）。

# 增强简单邮件传输协议 (ESMTP)
对原始 SMTP 协议的改进，具有增强安全性和带宽利用率的功能。

# 错误检查

# 以太网
由电气和电子工程师协会 (IEEE) 定义为 IEEE 802.3 标准的一种网络技术。由于其速度快、成本低且全球普及，该技术是最流行的数据链路层协议。

# 文件和打印服务器
控制并共享打印机及大量数据的服务器。这些服务器通常是专门为在磁盘与网络之间尽可能快速地移动文件而构建的高性能计算机。文件和打印服务器还会在允许用户访问文件或使用打印机之前，检查每个资源的访问控制列表 (ACL)。如果用户或用户所属的组未列在 ACL 中，则不允许该用户使用该资源。

# 文件服务器
运行网络操作系统并服务工作站请求的网络计算机。

# 文件系统
网络操作系统用于处理和存储文件的规则。

# 文件传输协议 (FTP)
一种主要用于跨网络传输数据的协议。FTP 既表示一种协议，也表示用于此目的的实用程序。它的创建旨在快速高效地将数据文件从一台主机传输到另一台主机，而不影响远程主机的资源。

# 防火墙
通过检查在两个网络上传输的数据包，防止未经授权的流量在两个网络之间流动的软件或硬件。防火墙查看数据包中的地址和端口信息，然后确定是否允许该类型的流量。

# 林
Active Directory 结构的顶层。林是由域组成的一个或多个树。林中的所有域共享相同的架构和全局目录。

# 四八位字节地址
32 位 IP 地址被分解为四个八位字节，可用二进制（`11010100 00001111 10000100 01110101`）或十进制（`212.15.132.117`）格式表示。
