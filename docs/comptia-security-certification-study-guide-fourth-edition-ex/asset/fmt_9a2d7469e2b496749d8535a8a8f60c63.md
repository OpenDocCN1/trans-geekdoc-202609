
# 物理安全控制

## 线缆锁

另一种类型的锁是*线缆锁*，用于锁定笔记本电脑、显示器、台式机和投影仪等设备。例如，您可以使用线缆锁将前台接待员的台式电脑和显示器固定在桌子上，这样当无人在场时，他人不易随意拿走设备。

## 访问系统

组织可以通过多种称为访问系统的方法来控制对设施的访问。本节介绍您在 Security+ 考试中可能会遇到的一些常见访问系统。

访问系统的组件可被视为故障安全型或故障保密型。两者的区别如下：

- **故障安全** 故障安全设备在发生故障时不会执行任何导致危害的操作。例如，如果锁发生故障，它默认为解锁状态，以便人员进出。这也称为*故障开放*，因为门将默认处于打开状态。
- **故障保密** 故障保密设备在发生故障时确保设备处于安全状态。例如，如果锁发生故障且为故障保密锁，它将默认为锁定状态。这也称为*故障关闭*，因为门将默认处于锁定状态且无法打开。

### ID 徽章

如前所述，在高安全环境中，员工必须佩戴显示姓名和照片的 ID 徽章。组织的安全策略还可能要求员工始终保持 ID 徽章可见，这意味着他们必须将徽章显眼地佩戴在衣服或挂绳上。

进入某些区域可能需要将 ID 徽章在读卡器上刷卡。徽章通常带有磁条，存储员工访问代码。如果员工被授权访问该物理区域，门将打开。ID 徽章还可能包含芯片，用于存储身份识别信息，例如用于控制对系统和资源访问的数字证书。

### 接近式读卡器

*接近式读卡器*是一种从令牌或卡片读取访问代码的传感器设备。主要有两种类型：用户激活式接近读卡器和系统感应式接近读卡器。使用*用户激活式*接近读卡器时，员工在传感器处输入代码或刷卡以进入设施。*系统感应式*接近读卡器持续发出询问信号，用户的访问设备通过向传感器发送访问代码来响应，从而解锁门禁。*钥匙扣*也是与接近读卡器配合使用的令牌设备。用户只需将钥匙扣在读卡器上方挥动即可进入设施。

### 人员锁

物理安全讨论若不提及人员锁（也称为*访问控制前室*）则是不完整的。人员锁或访问控制前室是两扇门之间的一个区域，第二扇门在第一扇门关闭前不会打开。这有助于防止搭便车或尾随。*搭便车*是指攻击者在员工知情的情况下，跟随该员工刷卡开门后进入设施。*尾随*是指攻击者在员工不知情的情况下跟随其进入设施。人员锁的原理是：如果有人跟随您进入人员锁区域，您不会打开第二扇门。

![Image](exam.jpg)

**人员锁通过将人员困在两扇门之间的区域来帮助防止尾随。第二扇门在第一扇门关闭前不会解锁。**

根据环境不同，人员锁区域可能设有安全窗口以便观察内部。窗口另一侧有保安监控进出设施的所有人员。

还有一种人员锁是旋转的 C 形垂直管状门。您刷卡后，C 形门的开口侧旋转以便您进入管内，随后管体旋转 180 度将您送出另一侧。管内的传感器可检测垫子上的重量点（脚印）数量；如果检测到过多（人数过多），管体将在中途停止旋转，将两人困在管内，直到保安到达。

## 其他物理安全控制

可以实施许多其他物理安全控制来提高组织的整体安全性。本节将介绍安全区域、标识和其他增强物理安全的控制措施。

### 安全区域

组织需要为不同目的设置不同的安全区域。例如，应有安全区域存放敏感文件。以下是组织常用的一些安全区域：

- **气隙** 气隙是分隔两个不同网络的区域。例如，高安全环境通常拥有与企业网络或局域网无任何连接的机密网络。这意味着机密网络与其他网络之间存在气隙。
- **金库** 金库是一个安全室，旨在确保未经授权的人员无法接触内部存放的物品。金库墙壁通常由外层钢板、中层防火板和内层钢板组成。
- **保险柜** 保险柜是存放敏感文件和小型物品的安全区域，因其体积较小且可移动，区别于金库。每个设施都应配备保险柜，用于保管重要文件和资产，防止盗窃和火灾等灾害。
- **安全柜/机柜** 许多高安全组织设有上锁的柜子，用于非工作时间存放敏感材料。例如，在高安全环境中，可移动硬盘在夜间会从工作站取出并锁在柜子里，以控制对硬盘内容的访问。
- **屏蔽子网（非军事区）** 屏蔽子网是位于两个防火墙之间的特殊网络，也称为非军事区。其目的是允许从其他网络或互联网对系统进行受控访问。

许多其他安全控制可用于协助组织的物理安全。以下列举几项：

- **标识** 在设施内设置适当的标识以标明出口、危险区域或材料，对员工安全至关重要。标识也用于告知人员禁止进入限制区域。
- **报警** 如今许多安全设备（如锁定系统、接近读卡器和视频监控设备）均可触发报警。这些报警也可作为通知推送至移动设备。
- **线缆锁** 请务必在易被盗硬件（如显示器、投影仪和笔记本电脑）上使用线缆锁（也称为防盗锁线）。
- **屏幕过滤器** 处理敏感数据（如医疗信息）的组织应在计算机显示器上安装屏幕过滤器（又称隐私过滤器），通过限制路过人员的视角，帮助保护屏幕显示信息的私密性。
