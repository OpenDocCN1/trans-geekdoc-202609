
黑客可以从笔记本电脑的无线连接安装一个流氓接入点，并使该笔记本电脑设备看起来像是一个有效的接入点。这被称为*evil twin*（邪恶双胞胎），对黑客的好处是客户端会连接到黑客的伪造接入点，以为它是一个有效的无线网络。在此无线网络上发送的所有数据都将发送到黑客的笔记本电脑，黑客可以在其中捕获并读取数据。

**为了帮助保护公司系统免受邪恶双胞胎攻击，请为所有连接到公司系统的无线客户端使用 VPN 解决方案。VPN 将通过使用加密隧道在无线客户端和公司服务器之间传输数据来保护传输安全。**

### 弱加密和 IV 攻击

无线网络的另一个漏洞是使用弱加密方法，如 WEP，甚至是弱加密密钥。WEP、WPA 和 WPA2 都已被破解，但由于无线数据包头部中重复的 24 位 IV，WEP 加密可在几分钟内被破解。请看以下练习，它破解了一个 128 位 WEP 密钥。

##### 使用 Kismet 发现网络

4. 输入 `kismet` 启动 Kismet 无线扫描器。Kismet 是一种显示无线网络列表的工具，包括禁用了 SSID 广播的无线网络。Kismet 将有一系列提示以帮助配置（请遵循接下来的几个步骤来回答提示）。
5. 当出现“Kismet Running As Root”提示时，用鼠标点击 OK。
6. 在“Start Kismet Server”提示上，点击 Yes。
7. 在下一个“Start Kismet Server”提示上，请注意有可配置的启动选项。例如，Kismet 默认启用了日志记录（所有无线活动将自动记录到文件中）。点击 Start 启动 Kismet 服务器。
8. Kismet 启动服务器，然后通知您它未配置用于捕获数据包的接口。在“No Sources”提示上选择 Yes 以添加源接口。
9. 在“Add Source”对话框中，输入您之前记录的接口 ID（对我来说是 `wlan0`）。然后点击 Add。
10. 您应该会在 Kismet 控制台上看到正在检测无线网络。我们不想使用 Kismet 控制台，而是 Kismet 工具，因此点击窗口右下角的 Close Console Window。Kismet 界面随即出现。

11. 在屏幕顶部可以看到检测到的无线网络。使用上/下箭头键浏览列表。选择一个无线网络时，您可以看到已连接客户端的 MAC 地址。要查看无线网络的信息，请点击该无线网络。
    ![Image](f0411-01.jpg)

13. 要关闭 Network View 窗口，请点击顶部的 Network View 并选择 Close Window。
14. 要查看连接到无线网络的客户端列表，只需高亮显示该无线网络，在其下方的窗口中即可看到客户端的 MAC 地址。请记住，黑客现在将拥有有效 MAC 地址列表，可用于 MAC 地址欺骗以绕过无线网络上的 MAC 过滤。
