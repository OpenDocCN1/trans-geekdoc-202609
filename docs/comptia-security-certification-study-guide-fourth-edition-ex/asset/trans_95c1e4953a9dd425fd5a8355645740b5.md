

更改 SSID 的值后，请禁用 SSID 广播，以便路由器不会向网络中广播该名称，防止任何想要连接的人都能看到。要在 D-Link 无线路由器上禁用 SSID 广播，请将可见性状态设置为“不可见”，然后单击“保存设置”。现在您已禁用 SSID 广播，想要连接到您网络的用户将无法通过 Windows 看到该无线网络，除非他们手动输入 SSID 名称。请注意，如果您更改无线网络的 SSID，任何已连接的客户端都将失去连接，这被称为 `disassociation`（取消关联）事件。黑客在攻击期间也可以取消关联您的无线连接，以便捕获重新关联流量并重放该流量，从而尝试破解加密。

在查看路由器上的无线网络设置时，请查看无线网络正在使用的信道。默认情况下，路由器通常设置为自动选择信道。如果您想更改无线网络使用的信道，请清除“启用自动信道扫描”复选框，然后选择您想要使用的信道。选择信道也称为 `band selection`（频段选择），因为该信道关联有一个频率范围（称为宽度）。

### MAC 地址过滤

帮助保护无线网络安全的下一步是启用 MAC 地址过滤。请记住，MAC 地址过滤允许您输入想要允许连接到无线网络的无线网卡的 MAC 地址。使用任何其他 MAC 地址的系统将无法连接到无线网络。

要在 D-Link DIR-615 路由器上配置 MAC 地址过滤，只需单击页面顶部的“高级”链接，然后选择左侧的“网络过滤”链接。从下拉列表中选择开启 MAC 地址过滤，然后列出允许连接到网络的 MAC 地址。

### 无线安全

作为保护无线路由器的一部分，您可能决定做的第一件事是，如果您不使用无线功能，则禁用路由器的无线功能。有些人购买了无线路由器，但当时实际上并没有任何无线客户端——在这种情况下，最好的做法是禁用无线功能，直到您需要它为止。

要禁用 D-Link 路由器上的无线功能，请转到页面顶部的“设置”链接，然后选择左侧的“无线设置”。在页面底部，单击“手动无线网络设置”。进入无线设置后（如[图 9-12](#ch09.xhtml#ch9fig12)所示），关闭“启用无线”选项。还请注意右侧的“添加新项”按钮。这允许您创建计划，指定一天中允许使用无线的时间段，如果您想控制无线可用性而不是完全禁用该功能的话。

#### 配置 WPA 和 WPA2

登录路由器后，单击页面顶部的“设置”链接，然后单击左侧的“无线设置”链接。然后向下滚动到页面底部，单击“手动无线网络设置”。

进入无线配置屏幕后，在页面底部的“安全模式”下拉列表中选择“WPA-个人版”。如果您使用中央 RADIUS 服务器进行 WPA 认证，请在“安全模式”下拉列表中选择“WPA-企业版”。

选择“WPA-个人版”后（如[图 9-13](#ch09.xhtml#ch9fig13)所示），在下方您可以选择是支持 WPA、WPA2 还是两者都支持。您还可以选择想要使用的协议，其中 AES 是最安全的加密协议。使用 WPA 时，您还可以通过“组密钥更新间隔”设置指定密钥更改的频率。

### 配置客户端

无线路由器配置完成后，您就可以将无线客户端连接到网络了。要将无线客户端连接到网络，请确保在开始之前拥有以下信息：

- **SSID 名称** 因为您很可能已禁用 SSID 广播，所以您需要知道 SSID，以便将其手动输入到客户端中。
- **WPA2 密钥** 如果您使用 WPA2 保护无线网络，则需要知道该密钥。
- **客户端的 MAC 地址** 如果您按 MAC 地址进行过滤，则需要知道每个客户端的 MAC 地址，然后将该 MAC 地址输入到路由器中。

拥有前面列表中的所有信息后，您就可以将客户端连接到无线网络了。本节将概述所需的步骤。

#### 连接 Windows 客户端

要将 Windows 客户端连接到无线网络，首先需要确保其无线网卡驱动程序已安装。安装无线网卡驱动程序后，您可以使用系统托盘中的无线网络图标连接到无线网络。单击系统托盘中的无线网络图标，查看您连接的是哪个网络。如果您想连接到其他网络，可以单击无线网络，如[图 9-16](#ch09.xhtml#ch9fig16)所示（这些是您附近网络的 SSID）。
