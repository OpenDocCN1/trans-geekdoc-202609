

### 核心概念总结

- **路由器**创建广播域，负责将数据从一个网络路由（发送）到另一个网络。
- **VLAN**（交换机的重要功能）创建通信边界。交换机上的每个 VLAN 都是一个独立的广播域，必须使用路由器才能让一个 VLAN 上的系统与另一个 VLAN 通信。
- **TCP/IP** 是一套协议；最重要的协议包括 `TCP`、`UDP`、`IP` 和 `ARP`。（Security+ 考试肯定会有几道关于这些 TCP/IP 协议族成员的题目。）
- **TCP/IP 寻址**涉及 IP 地址、子网掩码、网络类别和特殊保留地址。（考试前请背熟每个网络类别。）

深入理解本章内容后，你将轻松应对 Security+ 考试中的任何 TCP/IP 相关问题。这些知识不仅对考试至关重要，在你通过考试并成为网络专业人员后，也将在职业生涯中持续发挥作用。

##### 理解网络设备与布线

![Image](boxsq.jpg) **交换机**应取代**集线器**，因为交换机通过仅将数据发送到目标系统所在的端口来过滤流量，而集线器将数据发送到所有端口，导致所有连接的系统都能查看所有网络流量。

![Image](boxsq.jpg) 交换机具备出色的安全功能，例如**禁用未使用的端口**和**配置端口安全**，后者允许基于 MAC 地址控制哪些系统可以连接到端口。

![Image](boxsq.jpg) **路由器**是第三层设备，用于将数据从一个网络路由到另一个网络。路由器还用于将一个网络划分为多个广播域。

![Image](boxsq.jpg) **负载均衡器**用于将客户端请求分发到不同的服务器以提高性能。可使用多种技术实现负载均衡：例如**轮询**，它将请求均匀轮换分发给多台服务器；或使用**算法**决定负载均衡器中的哪台服务器应处理该请求。

![Image](boxsq.jpg) **代理服务器**代表客户端发送出站互联网请求，通常用于过滤用户可访问的网站和可用于出站通信的应用程序类型。

![Image](boxsq.jpg) **同轴电缆**和**双绞线**使用铜芯传输电信号，而**光纤**用于传输光脉冲。光纤是高安全环境的首选布线。

##### 理解 TCP/IP

![Image](boxsq.jpg) **IP 协议**负责逻辑寻址和路由。

![Image](boxsq.jpg) **TCP 协议**用于可靠传输。TCP 通信以**三次握手**开始。TCP 通过使用序列号和确认号来保证传输。

![Image](boxsq.jpg) TCP 使用**标志位**来标识重要类型的数据包。TCP 标志位包括 `SYN`、`ACK`、`FIN`、`RST`、`URG` 和 `PSH`。

![Image](boxsq.jpg) **UDP**用于无连接通信。

![Image](boxsq.jpg) `TCP` 和 `UDP` 使用**端口号**来标识数据的发送和接收应用程序。针对 Security+ 考试，请掌握本章讨论的常用端口。

![Image](boxsq.jpg) **ICMP**用于状态和错误报告。ICMP 使用**类型**和**代码**来标识不同类型的消息。类型 `8` 用于回显请求，类型 `0` 用于回显应答。

![Image](boxsq.jpg) **ARP**负责将逻辑地址（IP 地址）转换为物理地址（MAC 地址）。

![Image](boxsq.jpg) 多种**应用层协议**用于为 TCP/IP 系统提供功能。例如，`FTP` 用于文件下载，`SMTP` 用于发送邮件，`POP3` 和 `IMAP` 用于接收邮件。

![Image](boxsq.jpg) **IPv6** 是 IP 协议的最新版本，较 `IPv4` 有重大变化：地址方案扩展至 128 位、移除了广播消息、内置了 IP 安全（IPsec）。

##### 网络安全最佳实践

![Image](boxsq.jpg) 确保使用**光纤**而非双绞线，因为光纤更难被窃听，且免疫电磁干扰。

![Image](boxsq.jpg) 使用协议的**安全版本**来加密通信。安全协议示例：`SSH`、`SCP`、`HTTPS` 和 `FTPS`。

![Image](boxsq.jpg) 确保使用交换机功能（如**端口安全**）来控制哪些系统可以连接到交换机。

![Image](boxsq.jpg) **禁用交换机上所有未使用的端口。**
