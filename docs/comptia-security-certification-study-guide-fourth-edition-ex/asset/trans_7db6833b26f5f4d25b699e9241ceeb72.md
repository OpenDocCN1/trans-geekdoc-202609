

# 设备安全与数据安全

在本节中，您将了解保护笔记本电脑、移动设备以及组织数据等系统的常见安全实践。安全防护不止于办公室内部，您还需要考虑如何保护带出组织外部的资源。

## 硬件安全

在处理交换机、路由器和笔记本电脑等硬件设备时，您应确保这些设备免遭盗窃。路由器和交换机应放置在安全的场所（如服务器机房），并对机房的访问权限进行控制。这将有助于保护路由器和交换机免遭盗窃，同时防止未经授权的人员对这些设备进行物理篡改。

任何便携式硬件设备（如笔记本电脑、液晶显示器，甚至投影仪）都应使用防盗锁线缆固定在场所内。锁线缆连接到设备上的接口，然后固定在桌子上。这可以阻止伺机行窃。请记住，防盗锁线缆并非万无一失，因为小偷可以将其剪断。

高安全级别的环境可能要求员工将未在夜间使用的可移动/便携式驱动器、笔记本电脑和其他移动设备锁在保险柜或带锁的柜子里。

## 移动设备安全

由于移动设备存储着公司邮件和公司数据的本地副本，因此它们已成为当今企业的一大安全隐患。制定强有力的政策来规范智能手机和平板电脑等移动设备的使用，并确保这些政策得到执行，这一点至关重要。

### 连接方式与接收器

手机和平板电脑连接网络和互联网的方式多种多样。以下列表概述了移动设备常用的一些连接方式：

- **蜂窝网络** 移动设备连接网络或互联网最常用的方式是通过其蜂窝网络。蜂窝网络由移动设备的服务提供商提供。
- **Wi-Fi** 移动设备可以连接到公司 Wi-Fi 网络以获取互联网连接并访问网络资源。Wi-Fi 网络进而连接到企业网络。
- **卫星通信 (SATCOM)** SATCOM 是 `satellite communication`（卫星通信）的缩写，是发送或接收少量数据（如通过销售终端系统）时的常用连接方式。
- **蓝牙** 只要设备距离足够近，移动设备就可以使用蓝牙获得与计算机或设备的连接。蓝牙使用 2.4-GHz 频率。
- **近场通信 (NFC)** 近场通信允许两个电子设备在相距两英寸范围内交换数据。您可以使用 NFC 让设备共享联系人等信息，或用于支付交易。
- **ANT** ANT 是一种无线通信协议，允许您在设备之间传输数据。ANT 像蓝牙一样使用 2.4-GHz 频率。与蓝牙不同，ANT 消耗的电池寿命较少，这使其非常适合智能设备。
- **红外** 红外线，或称 IR，是一种无线通信，依赖于通过红外光共享数据的两个设备之间的视线直达。
- **USB** 您可以使用 USB 线缆将移动设备连接到系统的 USB 端口。这常用于将视频和图片等数据传输到计算机。
- **点对点** 移动设备支持不同的协议进行点对点通信（例如，一个移动设备与另一个移动设备通信）。
- **点对多点** 移动设备还支持点对多点，这涉及同时向许多其他设备发送数据。
- **全球定位系统 (GPS)** 移动设备包含 GPS 技术，允许您使用显示位置信息的服务。
- **射频识别 (RFID)** 利用射频识别 (RFID) 技术，您可以将标签附着在物体上，并使用 RFID 来追踪这些标签。

了解可用于允许智能手机或笔记本电脑等移动设备进行通信的不同技术非常重要。从安全角度来看，您可能希望在设备上禁用这些功能。

### 移动设备管理概念

移动设备给组织带来了巨大的安全挑战，因此全面掌握如何管理设备功能及设备本身至关重要。以下是您需要管理的移动设备的一些安全方面：

- **屏幕锁定** 务必确保智能手机和笔记本电脑等移动设备的屏幕配置为在短时间无操作后自动锁定。因此，任何想要使用移动设备并访问其上数据的人都必须输入设备密码。因此，如果您丢失设备且被他人拾获，他们需要知道密码才能访问设备上的数据。
- **强密码和 PIN 码** 确保所有移动设备都配置了复杂密码以使用设备，从而访问其中的数据。对于企业设备，您可以配置策略以强制要求设备使用复杂密码。例如，您可以在 Microsoft Exchange Server 的 ActiveSync 策略中为支持 ActiveSync 的移动设备进行此项配置（请参见 [图 7-13](#ch07.xhtml#ch7fig13)）。

- **全设备加密** 大多数移动设备支持对设备上的数据进行加密。设备加密至关重要，可确保任何能够将设备或其内存连接到计算机的人都无法读取数据。
- **远程擦除/清理** 智能手机和平板电脑等移动设备支持在设备丢失或被盗时远程擦除设备。远程擦除设备将清除其上的所有数据。
- **语音加密** 对于支持语音通信加密的任何设备，您应启用此功能，以防止任何人窃听通信。对于 IP 语音 (VoIP) 设备，您可以加密 VoIP 数据包，以防止拥有嗅探器的人捕获和分析通信。例如，Wireshark 有一个命令用于分析捕获中的 VoIP 数据包，它会组装语音数据包并允许黑客播放对话。务必加密所有流量！
- **GPS 追踪** 大多数智能手机都具备 GPS 功能，允许您追踪移动设备的位置。确保启用 GPS 功能，以便在设备丢失或被盗时利用它们定位设备。
- **电子围栏** 电子围栏是一项功能，允许软件管理员定义创建边界（或虚拟围栏）的 GPS 坐标。当运行该软件的设备超出边界时，会触发警报。
- **地理定位** 地理定位是识别移动电话等物品地理位置的术语。例如，一旦确定了移动电话的地理定位（GPS 坐标），您就可以利用地图技术将其与街道地址关联起来。
