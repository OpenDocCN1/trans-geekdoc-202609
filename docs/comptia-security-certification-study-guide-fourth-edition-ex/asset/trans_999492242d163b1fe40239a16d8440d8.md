

# 术语表

## NetBT
基于 TCP/IP 的 NetBIOS。一种软件标准和命名约定，用于在 TCP/IP 协议上使用 NetBIOS 服务。

## netcat
一种程序，用于在系统上打开端口并从网络另一端向该端口发送数据。

## netstat
一种 TCP/IP 命令行实用程序，用于显示协议统计信息和当前活动连接。

## network
两台或多台计算机链接在一起，以便它们可以通信。

## network access control (NAC)
一种技术，在允许系统访问网络之前评估其状态。

## network adapter
参见 [network interface card](#ch23_glossary.xhtml#glos252)。

## Network Address Translation (NAT)
一种服务，允许将来自专用地址的请求转换为公共地址，从而隐藏内部网络资源。

## Network Basic Input/Output System (NetBIOS)
PC BIOS 的网络扩展，使 I/O 请求能够从远程计算机发送和接收。通常称为应用程序编程接口 (API)。

## network infrastructure
将计算机连接到网络的物理设备。这包括电缆、集线器、路由器以及用于控制网络的软件。

## network interface card (NIC)
安装在计算机中，使其能够通过网络与其他计算机通信。NIC 将计算机内部的并行信号转换为通过网络电缆传输的串行信号。也称为适配器卡、接口卡或介质访问卡。

## network layer
OSI 模型的第 3 层，负责逻辑寻址和路由。

## network map
网络的详细图。包括机器和其他硬件的清单、电缆布局图以及记录网络的其他信息。

## Network Monitor
一种 Windows 工具，可“嗅探”网络上的数据包，并帮助诊断与协议相关的任何问题。截至 2012 年，Network Monitor 已被 Microsoft Message Analyzer 取代。

## network segmentation
一种优化网络并控制通信的方法，通过将不同类型的系统分离到网络的不同部分来实现。

## network-based intrusion detection system (NIDS)
一种用于监控网络流量并在发现可疑流量时发出警报的 IDS（不采取纠正措施）。

## network-based intrusion prevention system (NIPS)
一种用于监控网络流量并在发现可疑流量时采取纠正措施的 IPS。

## New Technology File System (NTFS)
为 Windows 开发的一种安全文件系统。NTFS 面向事务，允许将权限分配给文件和目录，并具有压缩文件的功能。

## NIC
参见 [network interface card](#ch23_glossary.xhtml#glos252)。

## NIDS
参见 [network-based intrusion detection system](#ch23_glossary.xhtml#glos257)。

## NIPS
参见 [network-based intrusion prevention system](#ch23_glossary.xhtml#glos258)。

## nmap
一种工具，用于对网络执行端口扫描，以确定系统上运行的服务。

## node
网络上的每个设备。节点可以是工作站、打印机、路由器或文件服务器。

## normal backup
也称为完全备份，复制所有选定的文件并将每个文件标记为已备份。

## nslookup
一种 TCP/IP 命令行实用程序，用于排查 DNS 名称解析问题。

## NTFS
参见 [New Technology File System](#ch23_glossary.xhtml#glos259)。

## object
在计算中，几乎所有东西都是对象。文件是对象，窗口也是对象。对象具有类型、各种属性和一组操作。它们可以是物理设备（如 COM 端口），也可以是抽象的（如线程）。

## offline backups
保持脱机状态的备份。它们从服务器操作中移除，需要加载介质（通常是磁带）才能恢复。

## offline storage
一种介质类型（如磁带），用于存储数据备份且不易访问。必须将数据从磁带复制回硬盘才能访问。

## off-site storage
一个与文件服务器分开的位置，用于存储备份磁带。完整备份应始终保存在异地。

## online backups
存储在联机状态的备份，以便立即可用。

## Open Systems Interconnection (OSI) model
这是 PC 网络中使用最常见的网络模型，由七层组成：应用层、表示层、会话层、传输层、网络层、数据链路层和物理层。

## OSI
参见 [Open Systems Interconnection](#ch23_glossary.xhtml#glos273)。

## packet
通过网络作为一个整体传输的小的、可管理的数据片段。数据包必须包含头部部分、数据部分，在大多数情况下还包含循环冗余校验 (CRC) 部分，也称为尾部。

## PAP
参见 [Password Authentication Protocol](#ch23_glossary.xhtml#glos280)。

## partition
物理磁盘的一个逻辑划分，被视为一个独立的硬盘。对硬盘进行分区后，需要决定哪个分区将作为系统分区，哪个将作为活动分区。另请参阅 [active partition](#ch23_glossary.xhtml#glos13) 和 [system partition](#ch23_glossary.xhtml#glos366)。

## pass-through authentication
当您的凭据不在本地目录服务数据库中时发生。

## password
登录期间访问网络的密钥。

## Password Authentication Protocol (PAP)
一种认证协议，客户端通过将用户名和密码传递给服务器来向其进行身份验证。然后服务器将此信息与其密码存储进行比较。由于密码以明文传递，因此在安全性受关注的环境中不建议使用。

## penetration testing
一种安全测试类型，涉及测试人员使用黑客技术攻破系统，以确定系统是否安全。

## Performance Monitor
一种实用程序，跟踪系统组件和应用程序的资源使用情况，并提供关于网络的性能信息，以帮助定位瓶颈、确定哪些资源过度紧张以及规划系统容量升级。

## permissions
分配给用户的资源（如文件或打印机）的访问权限。

## personally identifiable information (PII)
可用于识别个人身份的信息。

## phishing
一种攻击类型，涉及黑客诱骗某人点击链接，该链接指向一个看起来真实的站点，并试图从用户那里收集个人信息。

## ping
一种命令行工具，用于验证 TCP/IP 连接。

## platform
一种计算机系统类型。例如，Intel x86 和 UNIX 是平台。

## Point-to-Point Tunneling Protocol (PPTP)
一种较旧的 VPN 协议，用于加密 VPN 客户端和 VPN 服务器之间的通信。

## POP
参见 [Post Office Protocol](#ch23_glossary.xhtml#glos294)。

## port number
分配给 TCP/IP 应用程序的唯一地址。

## port security
大多数交换机上的一项功能，允许您将交换机上的端口配置为仅允许来自具有特定 MAC 地址的系统的连接。

## Portable Operating System Interface (POSIX)
电气和电子工程师协会 (IEEE) 基于 UNIX 开发的一种用于文件命名和标识的标准。为了符合 POSIX 标准，软件必须满足某些要求，例如区分大小写的文件名、硬链接和额外的时间戳。

## POSIX
参见 [Portable Operating System Interface](#ch23_glossary.xhtml#glos292)。

## Post Office Protocol (POP)
从邮件服务器向客户端下载邮件的协议。POP3 邮件服务器将邮件保存在邮件投递箱中，直到工作站准备好接收它。
