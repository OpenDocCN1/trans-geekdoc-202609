
# 对于 Security+ 考试，请记住：基于特征的系统根据文件中的特征来判断可疑活动，而这些特征需要你编程或保持最新。基于异常的系统根据活动是否异常来判断恶意活动。启发式分析监控活动，并根据过去的事件判断什么是可疑的。

## IDS 的类型

在实施入侵检测系统时，你可以选择实施基于主机的 IDS 或基于网络的 IDS。以下是这两种 IDS 类型区别的概述。

### 基于主机的 IDS

你在 [第 7 章](#ch07.xhtml#ch7) 中了解到，基于主机的 IDS (HIDS) 安装在单个系统上，并监控该系统上的活动。HIDS 通过监控内存、系统文件、日志文件和网络连接等区域（仅举几例）来识别可疑活动。

实施 HIDS 存在局限性，即它只能监控安装了该软件的系统上的活动。如果你想监控多个系统上的可疑活动，就必须在多个系统上安装 HIDS 软件。

### 基于网络的 IDS

基于网络的 IDS (NIDS) 可以作为独立的网络设备安装，也可以作为软件安装在系统上。无论哪种方式，NIDS 都会分析网络上传输的所有流量。NIDS 分析网络流量，寻找可疑活动，记录活动详情，并发送管理警报。

如 [图 8-13](#ch08.xhtml#ch8fig13) 所示，NIDS 由几个协同工作的组件组成，用于识别可疑流量：

- **传感器** 传感器是放置在每个网段上的软件或硬件，负责收集该网段的流量，然后将流量转发给分析引擎——如果你的基础设施中有收集器，则转发给收集器。收集器是一个从传感器收集所有流量并将其发送给分析引擎的组件。
- **分析引擎** 也称为 `correlation engine`（关联引擎），分析引擎负责接收来自传感器（或收集器）的数据包，然后对数据包执行分析，以确定它们是否被视为可疑。例如，如果在这种情况下 NIDS 是基于特征的 IDS，则分析引擎将数据包与已知可疑流量的数据库进行比较。
- **控制台** 控制台也称为 `administrative console`（管理控制台），通常是发送警报和通知的地方。管理员从控制台配置 NIDS。

## IDS 的类别

对于 Security+ 认证考试，你需要熟悉不同类别的 IDS。IDS 的类别指示 IDS 如何响应可疑活动——它是仅记录活动，还是也采取某种形式的纠正措施？

### 被动 IDS 与内联 IDS

被动 IDS 监控可疑活动，当它检测到认为可疑的活动时，只是将活动记录到日志文件中并向管理员发送通知。重要的是要理解，被动 IDS 不会采取任何措施来尝试保护网络免受进一步的可疑活动侵害。请注意，以这种方式配置的被动 IDS 通常连接到监控端口或网络分流器，以允许 IDS 接收所有网络流量。

内联 IDS 是放置在数据包路径中的 IDS，因此数据包必须通过 IDS 才能到达目的地。这样做的好处是 IDS 可以采取行动（从技术上讲这使它成为 `IPS`，稍后详述），例如在流量可疑时阻断流量。内联 IDS 的另一个好处是，如果 IDS 故障，在 IDS 修复之前，没有数据包能通过该系统。而对于仅接收所有数据副本并监控数据的被动 IDS，如果 IDS 故障，流量仍会到达目的地，但不会被检查。

### 主动 IDS 和 IPS

主动 IDS 监控可疑活动，当它检测到认为可疑的任何活动时，可能会将活动记录到文件中并向管理员发送通知，但它也会采取行动来保护环境。例如，如果主动 IDS 发现某系统正在执行 ping 扫描，它可能会将该系统从网络中断开，以便该可疑系统无法发送更多流量。

重要的是要注意，“主动 IDS” 这一术语已被淘汰，现在主动 IDS 被称为网络 `intrusion prevention system (IPS)`（入侵防御系统），因为它采取措施防止可疑活动继续。

> **针对 Security+ 认证考试，请了解：被动 IDS 仅发送通知或记录可疑活动，因此被视为一种检测控制。入侵防御系统 (IPS) 将采取纠正措施。例如，IPS 可能会将可疑系统从网络中断开，以防止嫌疑系统进行任何其他活动。“主动 IDS” 现在称为 IPS，并被视为一种预防控制。**

### HIPS 与 NIPS

入侵防御系统主要有两大类。`host-based intrusion prevention system (HIPS)`（基于主机的入侵防御系统）负责监控单个系统上的活动，通常通过查看日志、识别该系统上的可疑活动，然后采取纠正措施。`network-based intrusion prevention system (NIPS)`（基于网络的入侵防御系统）负责监控所有网络活动（不仅仅是单个系统上的活动），识别可疑网络流量，然后采取纠正措施。

### 带内与带外

在 IDS 和 IPS 的语境中，`in-band`（带内）是指内联放置的 IPS，这意味着流量必须通过它才能到达目标系统。这允许 IPS 不仅监控，而且在流量可疑时阻断流量。`Out-of-band`（带外）是指仅通过接收流量副本的方式监控网络中传输流量的 IDS/IPS。在这种情况下，IDS 只能触发警报或向管理员发送可疑流量通知。

### 分析

分析引擎是 IDS 中对收集到的流量进行分析的组件。分析引擎使用你在 IDS 上配置的规则来确定什么被视为可疑流量。规则中的动作告诉 IDS 如何响应可疑流量。
