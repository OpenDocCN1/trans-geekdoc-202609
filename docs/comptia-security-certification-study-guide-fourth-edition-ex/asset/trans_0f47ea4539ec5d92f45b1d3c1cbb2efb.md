
# CompTIA Security+ 认证

CompTIA Security+ 认证是一项快速发展的认证，涵盖安全的各个方面，包括物理安全、密码学、运维安全和网络安全主题。这是一个全面的认证，将测试您对安全概念的技术知识以及对安全管理的行政知识。

本简介旨在告知您如何参加 Security+ 认证考试，以及您在考试中可能遇到的题型。我们将首先探讨获得 Security+ 认证的价值，然后回顾考试结构。接下来，我们将了解如何安排考试，然后检查您可能在考试中发现的不同题型。最后，我们将介绍考试准备清单，其中列出了每个考试目标以及涵盖该目标的章节。

## Security+ 认证的价值

当今 IT 行业最热门的主题之一是安全，而 CompTIA Security+ 认证是证明您拥有扎实的安全知识和安全原则的绝佳方式。CompTIA Security+ 认证是一项与厂商无关的认证，涵盖防火墙、安全策略、入侵检测系统和安全评估等热门主题，仅举几个热门技能为例。获得 Security+ 认证是向潜在雇主展示您拥有帮助其组织创建安全环境所需技能的绝佳方式。

通过 Security+ 考试的考生证明了他们具备安全许多方面的知识。以下是 Security+ 考试将测试您的安全领域：

- **1.0 威胁、攻击和漏洞** 涵盖网络攻击类型、应用攻击、恶意软件、漏洞、威胁行为体和威胁载体以及安全评估类型等主题。
- **2.0 架构和设计** 涵盖安全网络设计、虚拟化和云计算、安全应用开发和部署、认证和授权、网络安全弹性、物理安全和密码学概念等主题。
- **3.0 实施** 涵盖实施安全协议、实施主机和应用安全、实施安全网络设计、安装和配置无线安全设置、实施安全移动和云解决方案、实施认证和授权解决方案以及实施 `PKI` 基础设施等主题。
- **4.0 运维和事件响应** 涵盖用于评估组织安全的工具、事件响应、事件发生后应用缓解技术以及数字取证等主题。
- **5.0 治理、风险和合规** 涵盖安全控制类型、法规和标准、安全策略、风险评估和数据隐私解决方案等主题。

## 考试结构和规格

Security+ 考试 (`SY0-601`) 由约 90 道题目组成，您有 90 分钟完成考试。通过考试所需的分数是 750 分，分数范围为 100 到 900 分。

通过 Security+ 考试后，您将从通过之日起获得为期三年的认证。三年后，您需要参加并通过当前版本的考试以维持您的认证。

## 题型

计算机化考试题目可以通过多种方式呈现。本节描述了一些可能的题目格式，并指出了您在 Security+ 认证考试中可能遇到的题型。

### 多项选择题

大多数 Security+ 认证题目采用多项选择格式，包含单个正确答案或多个需要您选择的正确答案。多项选择题的一个有趣变体是：对于有多个正确答案的题目，是否会告知您有多少个正确答案——您可能会被要求“选择所有适用项”。

### 性能题

Security+ 考试将包含一些性能题，旨在验证您对某个主题的理解。对于性能题，您可能会被要求在图表中标记项目、将术语框拖放到正确的定义上，甚至识别图形中的关键元素。
