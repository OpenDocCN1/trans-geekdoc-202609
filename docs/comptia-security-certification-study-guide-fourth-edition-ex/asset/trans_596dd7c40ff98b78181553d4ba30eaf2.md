### 自测答案

#### 理解防火墙

### 1.
![Image](boxt.jpg) **D.** 状态包检测防火墙了解会话的状态以及它应该期望接收的数据包。如果接收到的数据包超出了会话的上下文，则防火墙不允许该数据包通过，即使它可能是发往防火墙上打开的端口。

![Image](boxx.jpg) **A、B** 和 **C** 不正确。虽然状态包检测防火墙可以根据源/目标 IP 地址和源/目标端口号过滤流量（包过滤防火墙也可以做到这一点），但其独特之处在于理解会话的上下文。应用层防火墙可以根据应用程序数据（也称为有效载荷）过滤流量。

### 2.
![Image](boxt.jpg) **B.** 应用层防火墙可以检查应用程序数据，并允许或禁止应用程序的特定功能通过防火墙。这比单纯打开端口更高级。例如，防火墙上可能打开了 80 端口，但应用防火墙还可以限制流量，仅允许 HTTP `get` 命令，而不允许 HTTP `put` 命令。

![Image](boxx.jpg) **A、C** 和 **D** 不正确。包过滤路由器根据源/目标 IP 地址和源/目标端口号过滤流量。状态包检测防火墙可以根据 IP 地址和端口信息过滤流量，但它还能理解数据包是否在上下文之外被接收。屏蔽主机防火墙是一种拓扑结构，而不是一种防火墙类型。

### 3.
![Image](boxt.jpg) **D.** 屏蔽主机防火墙是一种防火墙，其前面放置了一个包过滤路由器，根据第 3 层报头或第 4 层报头过滤流量。通过包过滤路由器的信息随后到达防火墙，必须满足防火墙规则才能到达内部网络。

![Image](boxx.jpg) **A、B** 和 **C** 不正确。包过滤和应用层防火墙是防火墙类型，而非拓扑结构。双宿主防火墙是安装了两块网卡并在系统上安装了防火墙软件的系统。

### 4.
![Image](boxt.jpg) **B.** 为了控制发往特定系统的流量，Emily 应该使用基于主机的防火墙。基于主机的防火墙通常是安装在系统上的软件，允许您控制发往该特定系统的流量。

![Image](boxx.jpg) **A、C** 和 **D** 不正确。网络防火墙可以控制通信，但它控制的是发往网络的通信，而不是特定系统。在这种情况下，不使用 IDS 和 IPS，因为目标是控制通信，而不是监控它。

### 5.
![Image](boxt.jpg) **D.** 为了阻止 DNS 区域传输，您将拒绝 TCP 53 流量。

![Image](boxx.jpg) **A、B** 和 **C** 不正确。答案 A 是一条将阻止所有 TCP/IP 流量的规则，而答案 B 将阻止来自客户端的 DNS 查询。答案 C 将阻止 SMTP 流量。

### 6.
![Image](boxt.jpg) **B.** 在此场景中，您应该建议将无线来宾网络放置在独立的区域中，与企业网络（即内部网区域）分开。使用防火墙创建区域允许您控制两个区域之间是否可以进行通信，在本例中，您不希望它们之间发生通信。
