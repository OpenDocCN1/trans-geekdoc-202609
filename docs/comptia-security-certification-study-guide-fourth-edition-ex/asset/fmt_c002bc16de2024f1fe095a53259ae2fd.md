
![Image](boxsq.jpg) A signature-based system can identify suspicious activity only for the signatures it has been programmed for, whereas an anomaly-based system identifies any activity out of the norm.

![Image](boxsq.jpg) Anomaly-based systems are more susceptible to false positives, or “false alarms,” because they see anything out of the normal activity as being suspicious.

## Monitoring Tools

![Image](boxsq.jpg) The commands `netstat` and `net session` in Windows display who is connected to your system.

![Image](boxsq.jpg) The commands `tasklist` in Windows and `ps` in Linux display processes that are running. You can terminate a process in Windows with the `taskkill` command and in Linux with the `kill` command.

![Image](boxsq.jpg) The `net user` command in Windows displays a list of user accounts that exist, whereas the `net share` command displays a list of shared folders.

## Implementing Logging and Auditing

![Image](boxsq.jpg) Auditing can be thought of as the tracking of security-related events, while logging is responsible for logging all activity—whether suspicious or not.

![Image](boxsq.jpg) To configure auditing in Windows, use the security policies and first configure the events for auditing and then review the Security log in Event Viewer on a regular basis.

![Image](boxsq.jpg) Be sure to enable logging or at least to investigate the possibilities of logging for all services and devices on the network. This includes application environments such as database and e-mail servers.
