# 认证目标 1.02 理解 TCP/IP

既然你已经了解了网络上使用的一些不同类型的网络设备以及正在使用的电缆类型，让我们转换方向来谈谈 TCP/IP 协议。作为一名安全专业人员，你不仅要熟悉 TCP/IP 协议，还要理解通信是如何在 TCP/IP 网络上发生的，这至关重要。让我们从快速回顾协议基础开始。

## 复习 IP 寻址

TCP/IP 需要一点知识才能正确配置系统。配置 TCP/IP 时，你需要知道 IP 地址、子网掩码和默认网关的设置。让我们从 IP 地址开始。

### IP 地址

IP 地址是一个 32 位的值，用于在网络（或互联网）上唯一标识系统。IP 地址的外观类似于 `192.168.1.15`。IP 地址中的四个十进制值由小数点分隔。每个值由 8 位（1 和 0）组成，因此有四个十进制值，8 位 × 4 = 32 位地址。

由于每个十进制值都由 8 位组成（例如 192），我们将每个十进制值称为一个八位字节。一个 IP 地址中有四个八位字节。非常重要的是要理解，IP 地址中的四个八位字节分为两部分——`网络 ID` 和 `主机 ID`。子网掩码决定了组成网络 ID 的位数和组成主机 ID 的位数。让我们看看这是如何工作的。

### 子网掩码

查看子网掩码时，如果某个八位字节中有 255，则 IP 地址中对应的八位字节属于网络 ID 部分。例如，如果我有一个 IP 地址 `192.168.1.15` 和子网掩码 `255.255.255.0`，则前三个八位字节将组成网络 ID，最后一个八位字节将是主机 ID。网络 ID 为网络本身分配一个唯一地址，而主机 ID 在网络上唯一标识系统。[表 1-3](#ch01.xhtml#ch1tab3) 总结了此示例。

举另一个例子，如果你的子网掩码为 `255.0.0.0`，则意味着 IP 地址的第一个八位字节用作网络 ID 部分，而最后三个八位字节是 IP 地址的主机 ID 部分。

那么子网掩码的目的是什么？更确切地说，为什么我们要有一个将 IP 地址分解为网络 ID 和主机 ID 的子网掩码？因为当一个系统（如 `192.168.1.15`，子网掩码为 `255.255.255.0`）向 `192.198.45.10` 发送一段数据时，发送系统首先需要确定目标计算机是否存在于同一网络上。它通过比较网络 ID 来做到这一点（参见 [表 1-4](#ch01.xhtml#ch1tab4)）；如果网络 ID 相同，则两个系统存在于同一网络上，一个系统可以直接发送给另一个系统，而无需使用路由器。如果系统存在于不同的网络上，则数据需要传递给路由器，以便路由器将数据发送到另一个网络。

### 默认网关

当你的系统想要向网络上的另一个系统发送数据时，它会查看自己的网络 ID 并将其与目标系统的 IP 地址进行比较。如果它们具有相同的网络 ID，则数据会直接从你的系统发送到目标系统。如果这两个系统位于不同的网络上，你的系统必须将数据传递给路由器，以便路由器将数据发送到目标系统的路由器。

你的系统如何知道使用哪个路由器？答案是“默认网关”。默认网关是可以将数据从你的网络发送出去的路由器的 IP 地址。

要在互联网上通信，你的系统需要配置 IP 地址、子网掩码和默认网关。如果你只需要与网络上的其他系统通信，则只需要 IP 地址和子网掩码。

### 地址类别

每个 IP 地址都属于一个不同的地址类别。互联网社区定义这些类别旨在适应各种规模的网络。IP 地址所属的类别最初决定了地址的网络 ID 和主机 ID 部分，以及该网络上支持的主机数量。不同的类别地址被称为 A 类、B 类、C 类、D 类和 E 类。本节详细介绍每类地址。

#### A 类地址

A 类地址的默认子网掩码为 `255.0.0.0`，这意味着第一个八位字节是网络 ID，最后三个八位字节属于地址的主机 ID 部分。每个八位字节可以包含 256 个可能的值（0–255），因此 A 类地址支持网络上有 16,777,216 台主机（256 × 256 × 256）。实际上，每个 IP 网络上都保留了两个地址：所有主机位设为 0 的地址（网络 ID）和所有主机位设为 1 的地址（广播地址），因此只有 16,777,214 个有效地址可用于系统。所以使用 A 类地址时，你将无法将 `n.0.0.0` 或 `n.255.255.255`（其中 `n` 是你的网络 ID）分配给网络上的任何主机。

你总是可以通过第一个八位字节的值在 1 到 126 之间来识别 A 类地址。以 127 开头的地址也是 A 类地址，但你不允许使用任何以 127 开头的地址，因为它被保留用作环回地址（本章后面将详细介绍环回地址）。例如，IP 地址 `12.56.87.34` 是 A 类地址，因为第一个八位字节是 12，处于 1 到 126 的范围内。

#### B 类地址

B 类地址的默认子网掩码为 `255.255.0.0`，这意味着前两个八位字节是网络 ID，最后两个八位字节是地址的主机 ID 部分。这意味着我们可以在网络上拥有 65,536 台主机（256 × 256）。哦，但别忘了减去那两个保留地址，这样就给了我们 65,534 个可分配给网络上主机的地址。

由于 B 类地址支持的主机数量，通常会发现中型公司拥有 B 类地址。你可以通过第一个八位字节以 128 到 191 之间的数字开头来识别 B 类地址。

#### C 类地址

C 类地址的子网掩码为 `255.255.255.0`，这意味着前三个八位字节是网络 ID，最后一个八位字节是主机 ID。只有唯一的一个八位字节作为主机 ID，意味着 C 类地址只能支持网络上有 254 台主机（256 – 2）。

你可以通过第一个八位字节的值在 192 到 223 之间来识别 C 类地址。例如，IP 地址 `202.45.8.6` 是 C 类地址，因为 202 介于 192 和 223 之间。我们也知道该系统的子网掩码为 `255.255.255.0`，因为它是 C 类地址。
