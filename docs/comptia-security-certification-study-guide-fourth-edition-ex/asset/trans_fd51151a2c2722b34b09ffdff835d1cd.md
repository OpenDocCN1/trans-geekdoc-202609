## 问答自测

信息安全的很大一部分在于能够评估组织资产面临的风险，并确定使用哪些技术来缓解这些风险。在本章中，您将学习风险分析以及如何执行风险评估。透彻理解本章内容将有助于您回答 Security+ 考试中的风险评估问题。

## 风险分析简介

在本节中，您将了解风险分析的必要性，以及它从安全角度为您的组织带来的益处。您还将了解执行风险分析时应遵循的一般流程。

### 风险分析概述

具备执行风险分析或评估的知识，是安全专业人员的一项重要技能，因为许多不同的安全概念都以风险评估为起点。例如，安全评估通常始于您执行风险评估，以便识别需要安全防护的资源。此外，执行业务连续性计划涉及执行一种称为 `business impact analysis (BIA)`（业务影响分析）的风险类型分析。

风险分析的总体目的是识别组织内的资产及其价值，以便您随后识别针对这些资产的威胁。在识别威胁后，您需要确定如何针对每一种威胁采取对策（称为 `mitigating` [缓解] 威胁），同时确保您的对策成本不超过资产的价值！这是风险分析的一个关键点——花费 10,000 美元购买缓解方案来保护仅价值 2,000 美元的资产，在商业上是讲不通的。

在向您介绍风险分析流程之前，我想列出一些讨论风险分析时使用的术语。您应该熟悉以下与风险分析相关的术语，以应对 Security+ 考试：

- **资产** 您的组织运作所需的资源
- **漏洞** 硬件或软件配置中的弱点
- **威胁** 可能对资产造成损害的事件
- **威胁载体** 黑客用于利用系统弱点的工具或机制
- **威胁行为体** 使用威胁载体攻破系统的人员（黑客）
- **威胁目标** 受到攻击的系统或设备
- **风险** 当对资产的威胁可能对组织造成损害时——通常导致财务损失
- **风险分析** 识别并规划缓解技术，以降低和管理组织面临的风险

### 风险分析流程

执行风险分析时遵循既定流程非常重要，这样才能确保识别出与资产相关的所有威胁和风险。遵循风险分析流程可让您规划适当的缓解技术来降低风险。本节概述了风险分析的流程，并将该流程分解为不同的阶段。

#### 识别资产

执行风险分析（也称为风险评估）的第一阶段是识别组织内的资产及其价值。此阶段也称为 `asset identification`（资产识别）。例如，如果一家公司通过在线销售产品获取收入，则托管电子商务网站的 Web 服务器将被视为该公司的资产。

在此阶段，请务必专注于识别资产本身，而不必担心针对这些资产的威胁等问题——那将在下一阶段处理。通过仅关注资产是什么，您可以正确识别组织的*所有*资产。以下是组织常见的资产列表：

- 硬件和软件
- 组织的信息和数据
- 建筑物
- 库存和现金
- 人员
- 组织的声誉和品牌
- 计算机系统和服务

> **在识别资产时，请留意隐藏资产。例如，您每天带来数千美元收入的电子商务网站，通常有一个数据库服务器，存放着待售产品的清单及每个产品的详细信息。**

#### 识别针对每项资产的威胁（威胁评估）

一旦识别出组织中的资产，您便将重点转移到 `threat assessment`（威胁评估），这涉及识别第一阶段中所识别的每项资产面临的威胁。延续前面的例子，公司的电子商务网站面临许多潜在威胁；例如，系统可能通过缓冲区溢出漏洞利用或 SQL 注入攻击被黑客入侵。Web 服务器也可能发生硬盘故障，导致系统长时间宕机，从而造成收入损失。

执行威胁评估时，重要的是要识别来自不同来源——或不同类型 `disasters`（灾难）的威胁。存在环境威胁、人为威胁，以及内部和外部威胁。以下列出了这些不同类型的威胁，也称为 `risk types`（风险类型）：

- **环境** 环境威胁源自您的业务运营所处的环境或位置。环境威胁包括但不限于洪水、海啸、地震、火山爆发、龙卷风、暴风雪、雷暴和飓风。
- **人为** 人为威胁，也称为人造威胁，是指非自然存在、而是由人类行为（无论有意还是无意）导致的威胁。人为威胁的例子包括病毒、火灾、盗窃、破坏和蓄意破坏。
- **内部和外部** 重要的是要注意，威胁可以是内部的，也可以是外部的。`internal threat`（内部威胁）来自组织内部人员。这可能是心怀不满的员工故意删除客户数据，或员工意外删除文件等威胁。您需要防范这两类威胁。`external threat`（外部威胁）来自组织外部，例如互联网上的人试图入侵您的邮件服务器或网站。
- **遗留系统** 将遗留系统连接到网络的威胁或风险在于，该遗留系统可能不再受其硬件或软件供应商的支持。例如，供应商可能不再为遗留系统创建安全补丁，使其容易受到攻击。如果您确实需要遗留系统保持生产运行，请考虑将其放置在独立的网段上。
- **多方** 多方风险或威胁是指对多个个人或公司构成的风险。例如，如果您租赁一辆汽车，作为租赁方您会关注汽车面临的风险，但租赁公司和保险公司也同样关注。
- **知识产权盗窃** 组织面临的另一个常见威胁或风险是知识产权 (IP) 盗窃。这种威胁的一个例子可能是组织内部的内部人员有权访问机密公司数据，并在离职跳槽至竞争对手时将其带走。您可以通过实施加密和访问控制策略来缓解知识产权盗窃的风险。
- **软件合规/许可** 对组织的另一个主要风险涉及软件许可和合规性。大型组织很容易失去对所需软件许可证数量的跟踪，因此定期执行审计以确保公司符合许可要求非常重要。不符合许可要求的组织可能面临法律后果和罚款。
