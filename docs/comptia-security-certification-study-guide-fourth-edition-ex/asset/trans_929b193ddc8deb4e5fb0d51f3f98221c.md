

### 云服务提供商

**云服务提供商 (CSP)**
`cloud service provider (CSP)` 是你订阅以接收云服务的公司。例如，如果你订阅 Azure，那么微软就是云服务提供商。

**托管服务提供商 (MSP)/托管安全服务提供商 (MSSP)**
`托管服务提供商 (MSP)` 是为你管理云环境并处理许多 IT 功能的公司，例如预配用户、管理云服务、执行数据备份和恢复以及监控活动。`托管安全服务提供商 (MSSP)` 是为你的环境处理安全管理的公司。MSSP 用于云环境的安全配置、活动监控、入侵检测系统 (IDS) 和防火墙的管理、补丁管理、响应安全事件以及在组织内执行安全评估。

**本地部署 vs. 异地部署**
`On-premises`（本地部署）是我们用于安装在你办公室局域网 (LAN) 中的某个位置的系统的术语。`Off-premises`（异地部署）是用于描述可能位于备用站点的系统的术语。

**雾计算/边缘计算**
`Fog computing`（雾计算）是指你可以让边缘设备（例如驻留在网络边缘并连接到互联网的路由器和防火墙）在将数据发送到云端之前先处理数据。作为边缘计算的一个例子，设想一个网络环境，其中所有记录的数据都被发送到云端进行处理。这会浪费带宽，因为部分记录的数据并非必需。通过雾计算，处理在更靠近生成数据的用户网络处完成，然后仅将处理后的信息转发到云端进行分析，从而节省带宽。雾计算也称为 `fogging` 或 `edge computing`（边缘计算）。

**瘦客户机**
`thin client`（瘦客户机），也称为 `dumb client`（哑客户机），是一种不执行大量处理、只是连接到远程服务器或云服务以进行所有处理的系统。例如，你可以拥有一台 CPU 性能极低、内存极小且无硬盘的瘦客户机，它连接到 Microsoft 终端服务器，后者反过来将应用程序的屏幕截图发送到瘦客户机。用户可以在瘦客户机上使用鼠标点击应用程序中的选项，随后将这些点击操作发送到服务器，导致屏幕刷新。关键在于你使用的是服务器的处理能力，而不是客户端的。

**软件即服务 (SaaS)**
采用 SaaS，应用程序由云提供商提供给客户，以便客户可以从世界上任何有互联网连接的地方使用该应用程序。如果你使用免费电子邮件服务，如 Gmail 或 [Outlook.com](http://Outlook.com)，这就是 SaaS 的一个例子。更好的例子是 Microsoft 365，订阅后你可以获得 Exchange、SharePoint 和 Microsoft Office 等服务。云提供商管理应用程序基础设施并为你维护它，通过执行应用更新等任务。

**平台即服务 (PaaS)**
采用 PaaS，云提供商向云客户提供开发环境（也称为运行时环境），允许他们在云中创建应用程序。PaaS 的例子包括编程工具、代码库、Web 服务器、Web 服务和数据库环境。其好处是开发人员可以在云中使用这些功能，而无需像传统方式那样将它们作为本地服务器安装。使用 Azure SQL 数据库就是 PaaS 的一个例子。

**基础设施即服务 (IaaS)**
IaaS 是在云中创建虚拟数据中心的一种方式，因为它允许你在云中提供服务器、虚拟机、存储、网络和其他数据中心资源。当客户订阅 IaaS 时，他们仅为所用资源付费。例如，当你使用 Azure 虚拟机时，你就是在使用 IaaS。请注意，使用 IaaS 时，你仅为所用资源付费。

**一切即服务 (XaaS)**
前三种模型是最初的三种云模型，但随着时间的推移情况发生了变化，现在所有事物（或任何事物）都可作为云中的服务获得。例如，公司现在可以为云中的安全服务付费，这可能属于一切即服务类别。

### 云部署模型

实施云服务有多种不同的方式。你可以通过以下方式实施云：

**私有云**
私有云意味着你在内部为公司创建云服务，使公司能够利用弹性和自助功能等云特性。例如，你可以拥有一个私有云，允许 IT 人员根据需要启动虚拟机。私有云的关键在于数据存储在公司内部。

**公有云**
公有云由服务提供商提供，存储在云中的数据将位于该提供商的服务器上。重要的是要强调，许多组织不允许将敏感数据存储在服务器托管在国外的公有云中。值得注意的是，云提供商正在不同国家建立数据中心以解决这一顾虑。

**混合云**
混合云是公有云和私有云的组合。公司可能将非敏感数据存储在公有云中，但将敏感数据保存在私有云中。

**社区云**
这种类型的云汇集计算资源，使 IT 服务可供多个具有共同需求的组织使用，例如实时访问后端数据库。

**云存储**
云技术的一大优势是云存储的使用。用户现在能够轻松地将数据存储在云中，并从台式机、笔记本电脑、平板电脑和手机等多种不同设备访问该数据。云存储可用于存储照片和文档等个人文件，也可用于存储设备的配置设置，以便在需要擦除设备时能轻松恢复配置。

### 云计算考量

云计算的目的是为组织提供数据库、电子邮件或其他服务等功能，而无需组织自行托管这些服务。例如，要托管自己的数据库服务器或电子邮件服务器，你需要服务器硬件和软件，这需要花钱。让其他人托管这些服务（由他们购买硬件和软件），而你支付月度订阅费通过互联网访问这些服务，这可能更容易。对于许多云服务，你只需为所使用的服务和所使用的数据存储付费。
