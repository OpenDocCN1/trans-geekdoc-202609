

#### 防范恶意软件

对于 Security+ 认证考试，你需要了解不同类型的恶意软件，同时也需要知道如何防范恶意软件。以下是针对恶意软件的对策列表：

- **使用防病毒软件。** 确保在所有桌面客户端和服务器上都使用防病毒软件。确保防病毒软件支持实时保护，以便在你访问数据时扫描文件和内存中的病毒。
- **保持病毒定义库为最新。** 病毒定义数据库是已知病毒的列表，保持该数据库为最新至关重要，这样你的防病毒软件才能知晓最新的病毒。
- **密切监视监听端口。** 你可以在 Windows 和 Linux 中使用 `netstat` 命令来查看监听端口的列表。
- **密切监视运行中的进程。** 你可以在 Windows 中使用 `tasklist` 命令，或在 Linux 中使用 `ps -A` 命令来查看运行中进程的列表。密切关注后台运行的进程非常重要。
- **养成良好的上网习惯。** 教育用户远离未知网站，并且不要打开来自未知来源的电子邮件中的附件。

如果你正在寻找一些免费软件来帮助防范恶意软件，甚至清除恶意软件，可以使用以下工具：

- **Windows Defender** 这是微软在所有受支持的操作系统中内置的病毒防护、间谍软件防护和恶意软件防护软件。与其他防病毒软件一样，Windows Defender 提供针对恶意软件的实时保护。
- **Microsoft Malicious Software Removal Tool（微软恶意软件删除工具）** 如果你的系统已被感染，可以从微软下载恶意软件删除工具，该工具会定期更新。它是帮助从受感染系统中清除恶意软件的绝佳工具。

还有一点必须说明：如果你发现系统已被感染，则不能信任在该受感染系统上运行的任何软件，包括防病毒软件。在这种情况下，你需要从一个拥有自己操作系统和防病毒软件的 Live 光盘或 USB 启动盘启动系统。一旦从 Live OS 启动，你就可以从 Live OS 启动防病毒软件来扫描系统并清除病毒。

### 针对硬件的威胁

在保护系统时，你不仅需要担心恶意软件等系统威胁，还需要担心系统中应当加以保护的硬件相关特性。在本节中，你将了解用于妥善保护系统的常见硬件特性。

#### BIOS 设置

计算机中的 BIOS 芯片包含用于与系统中的硬件通信的低级代码。BIOS 代码还包含所谓的 *CMOS 设置程序*，这是一个用于配置系统硬件设置的程序，例如系统中的内存和驱动器类型、计算机的日期和时间。

就安全性而言，CMOS 设置程序（如[图 5-8](#ch05.xhtml#ch5fig8)所示）可用于控制可从哪些设备启动。一项安全最佳实践是确保系统只能从本地硬盘启动，而不能从网卡、USB 驱动器或系统上存在的光驱启动。有人使用 Live 光盘（包含可启动操作系统的 USB 驱动器或 DVD）将操作系统引导至内存以获取系统访问权限，这实在太容易了。为确保这种情况不发生，请配置 CMOS 仅允许从硬盘启动（如果可能）。

使用 CMOS 设置帮助保护系统

在 CMOS 设置程序中，你还可以设置“用户”密码，即使用系统所需的密码。不要将此密码与 Windows 密码混淆，因为 CMOS 密码出现在操作系统加载*之前*。此外，请务必设置“管理员”密码，即当有人想要更改 CMOS 设置时所需的密码。

如果你担心人们将未经授权的设备连接到计算机，并可能利用它们带走数据或通过未经授权的设备危害系统，则应确保通过 CMOS 设置程序禁用不必要的端口。

#### USB 设备

关于端口，更新安全策略并教育用户哪些类型的数据允许放置在 USB 驱动器上非常重要。因为员工很容易将数据副本保存在闪存驱动器上带走，所以安全策略必须明确规定允许将哪些数据类型放置在 USB 驱动器上。在高安全环境中，你可能会决定禁用 USB 端口，使其无法使用。

![Image](exam.jpg)

**由于蠕虫病毒已知会从拇指驱动器复制到系统，你应该考虑禁用办公室系统上的 USB 端口。**

使用 USB 闪存驱动器的一个重要风险是：员工的家庭系统可能感染了病毒，当他们将 USB 驱动器插入自家系统时，蠕虫病毒就会复制到闪存驱动器上。从商业角度来看，这一安全隐患在于：如果员工将该闪存驱动器带到办公室并连接到系统，病毒可能会复制到工作系统中。

#### 智能手机和平板电脑

智能手机和平板电脑等移动设备是当今业务运营中的关键设备。大多数员工在入职时都会获得一部手机或平板电脑，保护移动设备上的数据安全非常重要。现在的大多数手机被称为智能手机，因为它们的功能不仅限于打电话。它们存储业务联系信息和敏感文档，并拥有数据套餐，允许连接互联网以查收邮件和浏览网页。

从安全角度来看，确保员工在不使用智能手机和平板电脑时将其锁定，并对这些设备上的数据进行加密。这将防止公司机密数据在员工手机丢失或被盗时被公司外部人员查看。

作为安全专业人员，你应该研究公司员工使用的所有移动设备的漏洞。熟悉公司使用的所有设备的功能，并了解这些产品各自存在的不同漏洞，这非常重要。

由于当今大多数移动设备都使用蓝牙——一种无线技术，允许一台蓝牙设备在短距离内（最多 30 英尺）与另一台蓝牙设备通信——如果启用了蓝牙，黑客很容易与你的手机通信并窃取其中的数据。现在的手机容易受到各种攻击，包括以下几种：

- **Bluesnarfing（蓝牙窃取）** 一种蓝牙漏洞利用，允许黑客连接到启用了蓝牙的手机并从中检索数据
- **Bluejacking（蓝牙骚扰）** 从一台蓝牙设备向另一台蓝牙设备发送未经请求的消息
- **Bluebugging（蓝牙漏洞攻击/蓝牙劫持）** 一种蓝牙漏洞利用，涉及黑客获取手机访问权限并利用其全部功能，包括使用手机上的 AT 命令集拨打电话
