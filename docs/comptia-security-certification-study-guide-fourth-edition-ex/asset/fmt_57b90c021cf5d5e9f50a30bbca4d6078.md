
# DoS 攻击

DoS 攻击是指黑客用大量请求使系统过载，导致系统忙于处理黑客的请求，而无法为其他客户的合法请求提供服务（参见[图 4-2](#ch04.xhtml#ch4fig2)）。例如，黑客可能用大量网络请求使 Web 服务器过载，导致 Web 服务器无法及时向客户发送网页。这通常会导致客户转向其他站点以获得足够的服务。

![Image](f0149-01.jpg)

**图 4-2** DoS 攻击使系统过载，导致系统变慢或崩溃。

DoS 攻击可能导致目标网络性能下降，或者黑客可能使受害者的系统崩溃，导致其不可用。

## 分布式拒绝服务

分布式拒绝服务（DDoS）攻击是指黑客利用多个系统发起攻击，从而产生大量请求。在 DDoS 攻击中，黑客首先攻破并控制多个系统，然后利用这些系统协助攻击。被攻破的系统被称为“僵尸”系统，因为它们没有自己的“意识”，会执行黑客的任何指令。

多年前一个非常流行的 DDoS 攻击示例是“Smurf 攻击”，它涉及黑客向多个系统发送 ping（ICMP）消息，同时伪造数据包的源 IP 地址，使其看起来像来自预期受害者（参见[图 4-3](#ch04.xhtml#ch4fig3)）。所有系统随后会将 ICMP 回复发送给受害者系统，用流量使其过载并导致其崩溃。

![Image](f0150-01.jpg)

**图 4-3** Smurf 攻击示意图

DDoS 攻击有不同类型：

- **网络层** 基于网络的 DDoS 攻击涉及耗尽网络带宽或消耗网络设备的处理能力，使网络变得无响应或性能低下。
- **应用层** 应用层 DDoS 攻击涉及用大量请求淹没特定的软件应用程序或服务，导致其崩溃或无响应。
- **运营技术** 运营技术攻击是针对运行工业设备所需的硬件或软件的 DDoS 攻击。

## 欺骗

欺骗是一种攻击类型，黑客篡改信息的源地址，使信息看起来像是来自不同的人。欺骗有时被称为重构。以下是几种欺骗类型：

- **IP 欺骗** 篡改数据包的源 IP 地址，使其看起来像来自不同的源（参见[图 4-4](#ch04.xhtml#ch4fig4)）。

![Image](f0150-02.jpg)

**图 4-4** 伪造 IP 地址，使数据包看起来像来自其他人

- **MAC 欺骗** 篡改帧的源 MAC 地址，使其看起来像来自不同的系统或设备。
- **电子邮件欺骗** 篡改电子邮件的“发件人”地址，使电子邮件看起来像来自其他人。这通常用于社会工程学攻击。

值得注意的是，黑客可能会欺骗帧或数据包以绕过访问控制列表。例如，大多数无线网络实施 MAC 过滤，只允许特定 MAC 地址访问无线网络。一旦黑客发现网络上允许哪些 MAC 地址，他们就会伪造自己的 MAC 地址，使其看起来像其中一个允许的地址。黑客也可能欺骗 IP 地址，以绕过路由器上仅允许来自特定 IP 地址的流量通过的过滤器。

![Image](exam.jpg)

## 窃听/嗅探

一种非常流行的攻击类型是窃听攻击，也称为嗅探。在窃听攻击中，黑客捕获网络流量并能查看网络上传输的数据包内容。数据包可能包含敏感信息，如信用卡号、用户名和密码（参见[图 4-5](#ch04.xhtml#ch4fig5)）。

![Image](f0152-01.jpg)

**图 4-5** 使用网络嗅探器查看网络上的敏感信息

在第 1 章中，你了解到网络交换机会过滤流量，仅将数据发送到目标系统所在的交换机端口。这种过滤有助于防止窃听，因为它本质上剥夺了黑客捕获网络流量的机会。然而，黑客可以用虚假条目污染交换机上的 MAC 地址表，导致交换机不再信任 MAC 地址表，并开始将所有帧泛洪到所有端口——导致黑客现在能收到所有流量的副本！

## 重放

重放攻击始于嗅探攻击，因为黑客首先必须捕获他们想要重放的流量。随后，黑客稍后将流量重新提交到网络上（重放）。黑客可能先篡改流量再重放，也可能只是单纯重放流量以产生更多流量。

黑客重放流量的一个很好的例子是无线黑客攻击。为了破解无线网络的加密，黑客必须捕获大量流量。如果网络是流量不足的小型网络，黑客可以捕获一些现有流量并反复重放以生成更多流量。有关无线网络和黑客攻击的更多信息，请查看[第 9 章](#ch09.xhtml#ch9)。
