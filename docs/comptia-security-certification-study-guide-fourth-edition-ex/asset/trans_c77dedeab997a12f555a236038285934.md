

### 安全热修复

安全热修复是一项关键的安全更新，应尽快应用到您的系统中，因为该漏洞会使系统面临严重的安全风险。

### 补丁

补丁是针对软件或操作系统代码中特定问题的修复，它不会造成安全风险，但会导致系统或应用程序出现问题。

### 服务包

服务包包含产品发布之时起至服务包发布之时止的所有更新，包括补丁和安全热修复。如果您安装了服务包，就无需单独安装每个补丁，因为服务包包含了截至该时间点的所有更新。您仍需安装服务包发布后推出的补丁和安全修复。

### Windows Server 更新服务

在一台系统上运行 Windows Update 不是问题，但如果您必须管理 500 台系统，并确保每台系统都通过最新的补丁和热修复保持最新状态，该怎么办？微软创建了 **Windows Server 更新服务 (WSUS)**，它允许您创建一台 WSUS 服务器，并将更新从互联网下载到 WSUS 服务器。然后您可以在一些测试系统上测试这些更新的安装，以验证更新不会与这些系统上的任何应用程序冲突；接着您可以将更新推送到那 500 台系统。

当您向网络上的 500 台系统发送更新时，可以从一个中心点——WSUS 服务器进行操作。WSUS 服务器拥有一个基于 Web 的管理工具，允许您手动批准更新。这些更新会被下载到 WSUS 服务器。在 WSUS 中，您可以创建计算机组，然后将更新发送到网络上的不同组。未经您批准的更新不会被发送到网络上的系统。[图 7-10](#ch07.xhtml#ch7fig10) 展示了 WSUS 结构。

WSUS 有许多优势；首先，您可以从互联网将更新下载到一台中心计算机，而不必让每台系统都从互联网下载。这通过避免每个人执行下载来帮助维护可用带宽。WSUS 的另一个优势是客户端只会接收您已批准的更新。之所以会这样，是因为您会将每个客户端配置为从 WSUS 服务器检索更新，而不是从互联网检索。一旦您在 WSUS 服务器上批准了更新，客户端就会通过 WSUS 自动获取更新。网络上的客户端不会下载任何未经批准的更新。同样重要的是要注意，使用 WSUS 时，安装是由系统本身执行的，而不是由已登录的用户执行。这很重要，因为用户通常没有安装软件的权限。

您可以通过转到 **服务器管理器** 并启动 **添加角色和功能向导** 在 Windows Server 上安装 WSUS。安装 WSUS 并从微软网站下载更新后，您需要批准这些更新。下一步是将客户端配置为指向 WSUS 服务器，以便它们从 WSUS 服务器下载更新，而不是从 Windows Update 站点下载。请注意，只有微软软件的更新可以与 WSUS 配合使用。

### 将客户端配置为使用 WSUS 服务器进行更新

要将网络上的 Windows 客户端配置为使用 WSUS 服务器，您需要创建一个域策略，将域中的每个客户端配置为指向 WSUS 服务器以获取更新。如果您不在域环境中，可以通过本地策略配置客户端。要更改网络上的默认域策略，请执行以下步骤：

1. 单击 **开始** \| **管理工具** \| **组策略管理**。
2. 右键单击 **默认域策略** 并单击 **编辑**。
3. 将出现 **组策略管理编辑器**。在 **计算机配置** 部分，展开 **策略** \| **管理模板** \| **Windows 组件**，然后选择 **Windows 更新**（请参阅 [图 7-11](#ch07.xhtml#ch7fig11)）。

![Image](f0288-01.jpg)

**图 7-11**  
通过组策略配置 Windows 更新

4. 要在域中的客户端上启用自动更新，请双击 **配置自动更新**。
5. 在 **配置自动更新** 对话框中，选择 **已启用**，然后选择 “4 - 自动下载并计划安装”。为自动安装指定 “0 - 每天” 在 “03:00” (上午 3 点) 的计划（请参阅 [图 7-12](#ch07.xhtml#ch7fig12)）。

![Image](f0289-01.jpg)

**图 7-12**  
指定自动下载并安装更新

6. 单击 **确定**。
7. 双击 **指定 Intranet Microsoft 更新服务位置** 策略并启用该策略设置。在此对话框中，您将 **Intranet 服务器** 和 **统计服务器** 设置为安装了 WSUS 的服务器名称。例如，我的服务器称为 `Server2008A`，因此 Intranet 服务器和统计服务器地址均设置为 `http://Server2008A`。单击 **确定**。WSUS 中可用的报表依赖于统计服务器接收来自 WSUS 客户端的状态消息。
8. 关闭所有窗口。

现在策略已在 Active Directory 中配置完成，客户端将自动引用您的 WSUS 服务器，并安装您在 WSUS 管理站点中批准的任何更新。

### 使用防病毒和反垃圾邮件软件

抵御恶意软件的第一道防线是在系统上安装防病毒软件。至关重要的是，所有客户端系统都必须安装客户端计算机病毒防护软件，每台服务器都必须安装专为该类型服务器设计的防病毒软件。例如，如果您安装了电子邮件服务器，则必须确保已安装并配置了电子邮件服务器病毒防护，而不是典型的桌面防病毒软件。

### 配置防病毒软件

确保系统通过软件和操作系统补丁保持最新，只是您作为网络专业人员工作的一部分。考虑到通过电子邮件系统和互联网而来的威胁，制定一项防病毒策略极为关键，该策略须规定所有系统（包括客户端和服务器）均已正确安装并配置了防病毒软件。本节将向您介绍病毒与间谍软件的区别，并演示如何配置应用程序以防范恶意软件。

**病毒** 是安装在系统上的恶意软件，通常是意外安装或通过欺骗手段安装，它会损害系统并影响其正常运行。病毒已知会阻止计算机启动，并利用电子邮件程序中的通讯簿等功能向通讯簿中的所有收件人发送未经请求的电子邮件。底线是：作为网络专业人员，您需要熟悉安装防病毒软件以及如何保持其最新状态。

> **防病毒软件可以通过组策略等软件部署功能自动安装在系统上。**

在众多防病毒软件产品中，以下最为流行：

- Symantec Norton Antivirus
- McAfee Antivirus
- Bitdefender Antivirus
- Avast Antivirus
- Trend Micro Antivirus

每款防病毒产品提供的功能大同小异。防病毒产品提供的部分功能包括：

- **计划扫描** 每款产品都应提供计划功能，允许您安排病毒扫描，这是病毒防护软件的工作内容——它扫描系统以查看系统是否已感染计算机病毒。
