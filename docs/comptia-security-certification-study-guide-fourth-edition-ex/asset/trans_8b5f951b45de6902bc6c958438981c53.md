

### 集成 Windows 身份验证
您需要登录到服务器，但您的用户名和密码将以加密格式发送到服务器。如果要求用户登录，此身份验证方法比基本身份验证更安全。

### Kerberos
一种流行的相互身份验证协议，默认用于 Microsoft Active Directory 环境。Active Directory 遵循轻量级目录访问协议（`LDAP`）标准，这是用于访问和查询目录的 Internet 协议。Kerberos 使用密钥分发中心（`KDC`）服务器，该服务器负责颁发票据。客户端要从网络（称为领域）上的任何其他服务器请求服务，都需要这些票据。当客户端登录到网络时，Kerberos 过程即开始。`KDC` 有一个称为身份验证服务器（`AS`）的组件，它向客户端提供票据授予票据（`TGT`），授予客户端请求服务票据的权限。请求网络上服务器的服务需要服务票据。当客户端想要连接到网络上的特定服务器时，它必须从票据授予服务（`TGS`）请求票据，`TGS` 是 `KDC` 的另一个组件。`TGS` 向客户端授予票据，以便客户端可以访问网络上所需的服务器。

#### 常见身份验证协议
前述身份验证方法非常“以 Microsoft 为中心”，但标准协议也用于执行身份验证。这些标准身份验证协议被各种网络服务使用，例如远程访问服务（`RAS`）和虚拟专用网络（`VPN`）。

`RAS` 是一种远程访问技术，它使用点对点协议（`PPP`）作为电话应用程序（用于拨号）连接到 `RAS` 服务器的远程访问协议，支持点对点连接。`VPN` 通过不受信任的网络（如 Internet）上的安全通道连接到远程服务器（`VPN` 服务器）。无论使用带有 `RAS` 的拨号连接还是安全的 `VPN` 连接，`RAS` 和 `VPN` 都支持以下身份验证协议：

### 密码身份验证协议（`PAP`）
密码身份验证协议以明文形式发送用户的凭据，非常不安全，因为分析和解读登录流量非常容易。这是前面提到的基本身份验证方法所使用的身份验证协议。

### 质询握手身份验证协议（`CHAP`）
使用质询握手身份验证协议时，服务器向客户端发送质询，随后在身份验证过程中使用。`CHAP` 执行以下步骤：

1. 服务器向客户端发送质询（一个密钥）。
2. 客户端将质询与密码结合。用户的密码和质询都通过 `MD5` 哈希算法（一种公式）运行，生成一个哈希值（一个数学结果）。哈希值被发送到服务器进行身份验证。
3. 服务器使用相同的密钥与存储在服务器上的密码创建一个哈希值，然后将生成的值与客户端发送的哈希值进行比较。如果两个哈希值相同，则客户端提供了正确的密码。其优势在于用户的凭据根本没有通过网络传输。

### Microsoft 质询握手身份验证协议（`MS-CHAP`）
`MS-CHAP` 是 `CHAP` 的一种变体，它使用 `MD4` 作为哈希算法，而 `CHAP` 使用 `MD5`。`MS-CHAP` 还使用 Microsoft 点对点加密（`MPPE`）协议加密从客户端到服务器的所有流量。

### MS-CHAPv2
使用 `MS-CHAP` 版本 2 时，身份验证方法已扩展为对客户端和服务器进行双向身份验证。`MS-CHAPv2` 还比 `CHAP` 和 `MS-CHAP` 使用更强的加密密钥。

### 可扩展身份验证协议（`EAP`）
可扩展身份验证协议允许多种登录方法，例如智能卡登录、证书、Kerberos 和公钥身份验证。`EAP` 也经常与 `RADIUS` 一起使用，`RADIUS` 是一种中央身份验证服务，可被 `RAS`、无线和 `VPN` 解决方案使用，详见下一节。

如果您有通过 Internet 连接以访问公司资源的远程用户，您应该使用加密从用户计算机到 `VPN` 服务器通信的 `VPN`。

#### 身份验证服务
现在您已经了解了考试所需的一些不同身份验证协议，让我们继续了解身份验证服务。提到身份验证服务，我们通常会想到以下内容：

### 标识
向系统提供关于您自己的标识信息的过程。标识过程通常要求用户输入用户名，但也可能要求用户将智能卡插入读卡器，例如。

### 身份验证
身份验证服务负责验证用户提供的凭据，通常涉及拥有一个包含标准的身份验证数据库。例如，当用户使用用户名和密码登录时，该信息将针对账户数据库进行验证。

### 授权
一旦账户信息得到验证，用户即被授予网络访问权限。授权组件可能需要除账户信息以外的其他标准才能授予访问权限。例如，授权服务可能要求身份验证请求来自特定子网。

### 审计
审计处理活动日志记录。这可能是记录活动以便跟踪用户在做什么并让他们负责，也可能是跟踪服务或应用程序的使用情况，以便为不同部门使用系统的情况计费。

重要的是要注意，身份验证、授权和审计这三项身份验证服务在业界统称为 `AAA`。多年来出现了许多 `AAA` 服务，例如 `RADIUS`、`DIAMETER` 和 `TACACS+`。这些服务提供中央身份验证系统的优势，可为多种环境（如无线、`RAS` 和 `VPN`）提供身份验证、授权和审计。

##### RADIUS
远程认证拨号用户服务（`RADIUS`）是一种流行了很多年的中央身份验证服务。顾名思义，它最初用于拨号服务。需要访问网络的客户端计算机通过拨号连接到 `RAS` 服务器，或通过 Internet 连接到 `VPN` 服务器来连接网络。在这种情况下，`RAS` 或 `VPN` 服务器被称为 `RADIUS` 客户端，因为它将身份验证请求发送给在后台运行的 `RADIUS` 服务器。该 `RADIUS` 服务器验证凭据并发回回复，指示是授予还是拒绝网络客户端访问（参见[图 10-1](#ch10.xhtml#ch10fig1)）。
