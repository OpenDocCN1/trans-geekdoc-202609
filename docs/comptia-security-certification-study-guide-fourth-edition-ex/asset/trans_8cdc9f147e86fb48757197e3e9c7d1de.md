
# 虚拟化的管理优势

管理也能从虚拟化技术中受益。您可以将数十台服务器整合为仅需几台物理服务器，因为您只需在各自的虚拟机中运行每台服务器，从而减少了对物理服务器的需求。我的一位客户将 26 台服务器整合为四到五台物理服务器。结果，由于仅需维护四到五台物理服务器，该公司在硬件升级和维护方面节省了大量资金。

使用虚拟化的环境效益在于功耗更低，因为涉及的物理服务器更少。这也为组织节省了资金。我的一位客户通过虚拟化整合服务器，是因为其功耗已达到上限！

## Hypervisor（管理程序/虚拟机监视器）

系统的虚拟化由 `hypervisor`（管理程序）提供，它也被称为 `virtual machine monitor (VMM)`（虚拟机监视器），是允许您在系统上创建和运行虚拟机的软件组件。当您在系统上安装管理程序时，该系统称为 `host system`（宿主系统），而每个虚拟机称为 `guest system`（客户机系统）。

管理程序有不同类型：

*   **Type I（类型 I）** 此类管理程序是直接运行在硬件之上的软件，随后宿主操作系统作为父虚拟机运行。这使得管理程序能够控制宿主系统和客户机系统对硬件的访问。Microsoft 的 `Hyper-V` 和 VMware 的 `ESXi Server` 是类型 I 管理程序的示例。这些管理程序也被称为 `bare-metal hypervisors`（裸金属管理程序），因为它们直接运行在硬件之上。
*   **Type II（类型 II）** 类型 II 管理程序涉及先在硬件上安装操作系统，然后安装虚拟化软件来创建虚拟机。类型 II 管理程序的示例包括 `VMware Workstation` 和 `Oracle VM VirtualBox`。

以下是使用虚拟化技术和管理虚拟机时应熟悉的其他术语：

*   **Application cells/containers（应用程序单元/容器）** 应用程序容器是一项功能，允许您在一个拥有自己分配资源的隔离环境中运行应用程序。容器就像虚拟机，但它们共享宿主系统的操作系统内核，因此性能优于虚拟机（但提供了虚拟机的隔离特性）。`Docker` 是提供应用程序容器的软件示例，也是 `Windows 10` 的一项功能。
*   **VM sprawl avoidance（虚拟机蔓延防范）** 当组织创建大量虚拟机，却没有建立构建虚拟机的流程时，就会发生虚拟机蔓延。问题在于虚拟机的创建速度超过了网络管理员管理所有虚拟机的能力。到处出现无中心管理的虚拟机意味着无人能确保所有系统在需要时都能打上补丁。请记住，未打补丁的系统可能会在您的网络中造成安全漏洞。利用管理软件部署虚拟机，集中管理虚拟机宿主系统是解决虚拟机蔓延的关键。
*   **VM escape protection（虚拟机逃逸防护）** 虚拟机逃逸允许某人从虚拟机的客户机操作系统访问宿主操作系统。虚拟化厂商会为其产品中存在的任何虚拟机逃逸漏洞创建补丁，因此请务必保持虚拟化软件处于已打补丁状态。

## 虚拟化的安全问题

请记住关于虚拟化技术与安全性相关的以下要点：

*   **Less hardware to secure（需保护的硬件更少）** 虚拟化的一大优势是您将在一台物理服务器上运行多个系统，这意味着您需要保护的硬件更少。请务必遵循宿主系统的物理安全实践，但好处在于它只有一个系统。
*   **Disk space（磁盘空间）** 虚拟化技术允许您创建系统的快照，以便您随时恢复到该快照。这是一项很棒的功能，因为如果您在系统配置中犯了错，可以恢复到快照。但请记住，每个快照都会占用磁盘空间。
*   **Patching（打补丁）** 虽然所有虚拟机都运行在同一物理系统上，但给宿主系统打补丁并不会给虚拟机打补丁。您有责任为每台虚拟机打补丁。

![Image](exam.jpg)

> **考试提示：请记住，虚拟化的一个优势是您需要担心物理安全的系统更少。请确保遵循宿主系统的物理安全最佳实践，但不用担心那么多硬件确实很不错！**

如今，大多数组织都使用虚拟化软件在单台服务器上托管多台虚拟机，从而节省硬件采购成本并降低功耗。以下是关于虚拟化的一些安全最佳实践：

*   **Snapshots（快照）** 创建快照可为您提供一个还原点，以便在虚拟机出现问题时恢复。例如，如果您进行了错误的配置更改，或虚拟机遭受恶意软件攻击，您可以恢复到之前的快照以还原虚拟机的状态。
*   **Patch compatibility（补丁兼容性）** 在将补丁应用于虚拟化环境中的生产系统之前，请确保补丁经过测试且兼容。
*   **Host availability/elasticity（宿主可用性/弹性）** 请确保您已实现宿主系统的高可用性，因为如果宿主发生故障，则运行在该宿主上的所有虚拟化服务器都将不可用。虚拟化解决方案的优势之一是 `elasticity`（弹性），即启动新服务器以应对增加的负载需求，同时在负载减少时轻松减少运行中的服务器数量。弹性也是云计算的一项重要特性（下一节将详述云计算）。
*   **Security control testing（安全控制测试）** 请确保在虚拟化环境中测试所有安全控制，以确保它们按预期工作。虚拟化技术还使创建额外的测试系统以验证网络上的安全功能变得容易。
*   **Sandboxing（沙箱）** 您可以创建沙箱（受限环境）来控制虚拟机有权访问的内容。

# 云计算概念

现在您已了解虚拟化及与虚拟化相关的安全问题，让我们继续学习云计算。在本节中，您将了解云计算的优势、云模型以及与云计算相关的安全问题。

## 云计算概述

云计算已成为未来的趋势，并具有许多优缺点。在本节中，您将了解云计算并发现其中的一些优缺点。

借助云计算，您可以以极低的前期成本快速轻松地创建应用程序环境。例如，我想要一个电子邮件服务器环境，所以我创建了一个 `Microsoft 365` 订阅账户。几分钟内，我就拥有了一个启动并运行的电子邮件服务器环境（称为 `Exchange Online`），它允许我创建一些邮箱并开始发送电子邮件。这个例子最好的部分是我不必购买服务器硬件或软件，也不需要为高可用性做规划。所有这些都是云服务提供的内容！
