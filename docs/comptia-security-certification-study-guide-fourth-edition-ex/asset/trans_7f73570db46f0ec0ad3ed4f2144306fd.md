# 作者简介

**Glen E. Clarke**，持有 CCT、CCNA、MCITP、MCSE、MCSD、MCDBA、MCT、CEH、CHFI、CISSO 及 CompTIA 认证（Security+、PenTest+、Network+、A+），是 DC Advanced Technology Training (DCATT) 的所有者，该 IT 培训公司位于新斯科舍省哈利法克斯，专注于提供网络、安全和编程领域的 IT 认证培训和咨询服务。Glen 大部分时间用于讲授 Windows Server、Microsoft 365、Hyper-V、SQL Server、Exchange Server、SharePoint、Visual Basic .NET 和 [ASP.NET](http://ASP.NET) 的认证课程。Glen 还教授多门安全相关课程，涵盖道德黑客与对策、计算机取证与调查、信息系统安全官、漏洞测试、防火墙设计和数据包分析等主题。

Glen 是一位经验丰富的作者和技术编辑，其出版作品曾获 Referenceware Excellence Awards 提名。Glen 撰写了多部认证备考指南，包括《CompTIA Network+ 认证学习指南》、《CCT/CCNA 路由与交换综合考试指南》、《CompTIA PenTest+ 认证傻瓜书》以及畅销书《CompTIA A+ 认证综合傻瓜书》。

闲暇时，Glen 喜欢与妻子 Tanya 及他们的四个孩子 Sara、Brendon、Ashlyn 和 Rebecca 共度美好时光。您可以访问 [www.dcatt.ca](http://www.dcatt.ca) 在线联系 Glen，或发送邮件至 [glenclarke@dcatt.ca](mailto:glenclarke@dcatt.ca)。
