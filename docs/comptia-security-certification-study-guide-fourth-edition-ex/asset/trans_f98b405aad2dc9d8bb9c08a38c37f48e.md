

# 网络交换机安全特性

网络交换机为网络环境提供了强大的安全性。首先，网络交换机的设计初衷是过滤流量，仅将数据发送到交换机的目标端口。这意味着使用交换机可以防止他人轻松监控网络通信。交换机还有许多其他功能来增强网络安全：

### 第二层与第三层
交换机可以是第二层交换机，也可以是第三层交换机。第二层交换机不具备任何路由功能；它只是一个交换机，旨在仅将流量发送到帧的第二层头部中包含的目标 MAC 地址。这被称为*介质访问控制 (MAC) 过滤*。第三层交换机本质上是交换机和路由器的合二为一。第三层交换机上既有交换机端口，也有少量路由器端口，旨在将数据发送到另一个网络。

### 端口安全
您可以通过配置端口安全来控制哪些系统可以连接到交换机的端口。启用端口安全后，您可以将特定系统的 MAC 地址与该端口关联。只有具有该 MAC 地址的系统才能连接到该端口。

### 环路保护
环路可能导致网络崩溃，因此拥有防止网络环路的方法至关重要。路由器使用数据包的生存时间 (TTL) 值来确定何时将数据包从网络中移除。交换机通过实施环路预防协议（如生成树协议 (STP)）来防止第二层环路。当您将交换机连接在一起（这会导致网络环路）时，STP 会动态选择环路中涉及的一个端口，并将其置于阻塞状态以消除环路。

### 洪水防护
洪水防护通常是防火墙或路由器上的一项功能，允许您控制并阻断发送到您网络的恶意流量，例如洪水攻击。洪水流量的一个常见示例是 SYN 洪水攻击，黑客向您网络上的端口发送大量 SYN 报文。洪水防护会识别此类流量，阻止其进入网络，并防止拒绝服务 (DoS) 攻击。

### 广播风暴防护
使用交换机，您可以利用 VLAN 创建不同的网络段，也称为*广播域*。这样做可以限制广播风暴的影响，因为广播报文被限制在 VLAN 内。

### 网桥协议数据单元 (BPDU) 防护
交换机使用一种称为生成树协议的协议来防止网络环路。它们通过每 2 秒在网络上发送 BPDU 帧来发现可能存在的任何环路。连接到网络的黑客可能会通过发送自己的 BPDU 帧来执行中间人攻击。为了应对这种情况，您可以在端口上启用 BPDU 防护，这样如果交换机检测到 BPDU 报文，就会将该端口置于“错误禁用状态”。此功能应在所有连接用户工作站的端口上启用。

### 动态主机配置协议 (DHCP) 嗅探
DHCP 嗅探是您可以在交换机上启用的一项功能，它允许交换机检测未经授权连接到您网络的流氓 DHCP 服务器。

## 网络地址转换

网络地址转换，即 NAT，是一种沿用多年的网络技术，它允许您在网络内部使用私有地址范围，然后在 NAT 网关（参见[图 8-16](#ch08.xhtml#ch8fig16)）上将其转换为公共地址。其安全优势在于隐藏了内部系统上网所使用的内部 IP 地址，因为所有出站流量的源 IP 地址都被转换为 NAT 网关的地址。

![Image](f0362-01.jpg)

**图 8-16**  
NAT 用于隐藏内部网络并共享一个公共地址。

如前所述，内部网络通常使用所谓的私有地址范围，这些地址不能在互联网上使用。这意味着任何出站流量的数据包中的源 IP 地址都必须由 NAT 设备从私有 IP 地址转换为公共可路由地址。内部网络使用的三个私有 IP 地址范围如下：

- 10.0.0.0 至 10.255.255.255
- 172.16.0.0 至 172.31.255.255
- 192.168.0.0 至 192.168.255.255

NAT 主要有两种类型：NAT 过载和静态 NAT。使用*NAT 过载*时，网络内的所有客户端都使用分配给 NAT 设备公共接口的一个公共地址来访问互联网。NAT 设备不仅将私有 IP 地址转换为公共 IP 地址，还转换端口地址信息。这被称为*端口地址转换 (PAT)*，用于让 NAT 设备能够通过一个公共地址跟踪每个不同的客户端请求。

![Image](exam.jpg)

> **针对 Security+ 考试，请记住 NAT 用于隐藏内部 IP 地址方案，方法是让所有系统通过 NAT 设备发送流量，由 NAT 设备将数据包中的源 IP 地址替换为 NAT 设备的公共 IP 地址。**

*静态 NAT* 是指 NAT 设备上的单个公共 IP 地址映射到网络内部的单个私有地址。这通常用于处理发送给 DMZ 中服务器的入站请求，公司将这些服务器（如网站或 FTP 站点）发布到互联网。

## 网络准入控制

网络准入控制 (NAC) 是当今一项非常热门的技术，它允许您根据连接系统的状态来控制谁能获得有线或无线网络的访问权限。通过网络准入控制，您可以指定系统必须满足的条件才能获得网络访问权限。如果不满足这些条件，您可以将用户重定向到一个受限网络，以便他们修复系统。

例如，您可能要求系统要连接网络，必须安装防病毒软件，且病毒定义是最新的。您可能还要求系统启用了个人防火墙。如果不满足其中任何条件，NAC 系统会将客户端置于受限网络中，在那里他们通常可以应用补丁，或者在本例中，执行病毒定义更新。

当连接到受限网络时，客户端无法访问网络资源，因为从受限网络到私有公司网络的通信受到控制。[图 8-17](#ch08.xhtml#ch8fig17) 显示了一个网络准入控制环境。

如今有许多使用 NAC 的场景。以下是您应该熟悉的一些场景，以及为 Security+ 考试需要了解的一些 NAC 概念：

### 连接到无线网络
连接到无线网络时，NAC 系统可能会要求客户端在获得网络访问权限前接受无线网络使用条款。

### 补丁状态
当客户端尝试连接到网络（无论是本地还是通过 VPN）时，会检查其健康状况，以确保安装了防病毒软件、病毒定义是最新的、系统打好了最新补丁，然后才允许连接。
