

# 无服务器架构

无服务器架构是云计算的一大优势，因为您无需投资服务器硬件；相反，您只需在云中创建该服务的一个实例。例如，在 Azure 中，您无需安装 SQL Server 即可托管数据库；您只需直接在 Azure 中创建数据库，而在后台，云服务提供商（微软）负责管理服务器基础设施。

# 服务集成

服务集成是云计算的一种交付模型，允许本地数据与云数据进行交互。

# 资源策略

云资源策略允许您管理云中存在的资源，例如 VM、数据库和 Web 应用程序。您可以配置不同类型的策略来管理这些资源，例如成本控制策略有助于管理您每月在这些资源上的支出，卫生策略允许您随时间清理不需要的资源，合规性策略允许您实施安全控制以保护资源。

# 传输网关

传输网关是一种机制，为您提供安全的专用链接，允许您将本地网络扩展到云网络。

# 云网络安全解决方案

现在您了解了云计算的一些特性，让我们来看看可用于保护云资源（例如在云中运行的应用程序和数据）的不同安全控制。我们还将在本节介绍一些云计算的常见安全解决方案。

## 云安全控制

安全控制是一种用于保护资源的机制；因此，“云”安全控制是一种用于保护云资源的机制。有许多不同类型的云安全控制——通用安全控制、保护存储的控制、网络安全控制以及保护计算环境的控制。

### 云的通用安全控制

通用安全控制是您作为云订阅一部分所拥有的控制，不一定专门适用于存储或网络。请务必了解这些针对 Security+ 考试的通用安全控制：

- **跨区域的高可用性** 当您使用云服务提供商创建不同资源时，可以选择您想要的高可用性级别。您可以在区域内实现高可用性，也可以跨区域实现。
- **资源策略** 如前所述，您可以对资源设置策略，例如限制资源的月度成本、用于保护资源的合规性策略，以及随时间清理未使用资源的策略。
- **密钥管理** 云门户中提供了用于管理所用身份验证凭据（称为密钥）的工具，例如密码、应用程序令牌和密钥。
- **集成和审核** 您可以在资源上配置云审核，以帮助您跟踪谁在从何处使用什么资源。

### 存储安全控制

云的一大优势是您可以将数据存储在云中，然后从世界任何地方访问。这意味着您还应采取额外措施，通过实施以下不同的存储安全控制来保护这些资源：

- **权限** 您可以通过在数据上设置权限来限制对数据的访问，以控制谁可以访问它。
- **加密** 您可以对数据进行加密，以便未经授权的个人无法访问数据。确保数据在静止状态（存储中）和传输过程中均已加密。许多云服务提供商默认加密数据。
- **复制** 您可以将数据复制到另一个云区域，以便获得数据的高可用性和业务连续性（如果发生区域性中断）。
- **高可用性** 高可用性确保数据始终可用。云服务提供商在不同服务的后台实现高可用性功能，但您也可以将数据复制到另一个区域以确保高可用性。

### 网络安全控制

可以在云中实施许多安全控制，以为您的云网络环境提供安全性：

- **虚拟网络** 在云中，您可以创建多个虚拟网络并将不同的系统连接到每一个网络。例如，您可以为会计人员创建一个虚拟网络，并在该网络上运行会计服务器 VM。
- **公共和私有子网** 您可以创建多个公共和私有子网。公共子网是允许通信到 Internet 的网络（本质上是通往 Internet 的网关）。您还可以将云基础设施划分为多个没有直接 Internet 访问权限的私有子网。
- **分段** 您可以将资源分段到不同的虚拟网络中，以控制对这些资源的通信。
- **API 检查和集成** 云服务提供商提供许多 API，可用于检查云中的元素以确保合规性。例如，Google Cloud 有一个数据丢失防护 (DLP) API，可以调用它来检查存储在云中的数据，并验证其中未存储敏感数据。您也可以使用允许您检查云中网络流量的 API。

### 计算安全控制

在云环境中，计算资源是云中的虚拟机、容器或应用程序服务（如数据库服务）等资源。您可以使用许多安全控制来保护这些计算资源：

- **安全组** 您可以创建具有不同资源权限级别的不同安全组。
- **动态资源分配** 云计算的一大特性是虚拟机仅使用所需的 RAM 和磁盘空间。如果活动量大，这些资源会即时增加以处理工作负载，然后在负载减轻时再次降低。
- **实例感知** 您需要实施能够区分云中运行的应用程序服务实例的安全控制。如果您使用的安全控制不了解实例，攻击者可能会创建一个应用程序服务的流氓实例，并可能执行数据渗漏攻击。
- **虚拟私有云 (VPC) 端点** 虚拟私有云 (VPC) 是云中资源的私有网络。VPC 端点允许您通过专用地址与应用程序服务通信。
- **容器安全** 通过遵循安全最佳实践，确保您正在保护容器环境，例如锁定容器中运行的操作系统，包括保护 root 或管理员账户。

## 云安全解决方案

您可以在云中使用许多安全解决方案来实施云安全。以下是一些常见的云安全解决方案：

- **CASB** `云访问安全代理 (CASB)` 是一种安全服务，位于您的本地环境和云提供商的环境之间。CASB 允许您定义适用于从当前本地环境流向云的网络流量的安全策略。
- **应用程序安全** 寻找云中应用程序的安全解决方案。您需要使用能让您深入了解应用程序中发生的情况及其包含的数据的解决方案。您还想了解敏感数据上的访问控制设置，以便密切监控谁有权访问该数据。云服务提供商通常提供许多合规性功能，允许您监控这些要素。
