

# 演示性证据

*演示性证据*是指通过呈现实物来展示某种事件发生结果的证据。例如，在许多伤害案件中，医疗展品可用于展示医疗事故的结果。演示性证据的另一个例子可能是路口模型，其中模型车展示了原告和被告的位置。

## 收集证据

证据是任何法庭案件或企业调查的关键方面，因此必须小心处理。重要的是要限制对犯罪现场和任何数字证据的改动程度。修改现场或证据被称为*污染*，可能导致证据在法庭上不被采纳。

在到达收集证据的地点之前，重要的是您首先要熟悉情况，以便识别您要寻找的证据类型并计划如何收集。例如，您需要知道您是在寻找一台计算机、可能是一台笔记本电脑，还是一部可能包含潜在证据的智能手机。做好准备是关键！

### 保管链

收集证据时，记录并标记每件证据并将其存放在证据袋中至关重要。记录证据时，要记录物品是什么、物品在何处发现、标签 ID 号、收集证据的日期和时间，以及谁收集了证据。

为每件证据创建保管链表格至关重要，以便您随时记录证据的去向。如果授权调稿人稍后将证据从安全存储中取出，则需要在保管链中记录这一点，以便您能说明所有接触过证据的人员。

> **针对 Security+ 考试，请了解保管链是一份记录证据随时所在位置的文件。必须为证据建立保管链，以便您随时掌握证据的去向。**

### 证据保存

收集证据时，不仅要记录每件证据并创建保管链，还必须确保采取措施保存或保护证据。证据应放入安全容器，然后立即运送到安全存储地点。

对于数字证据，您需要确保证据免受磁场损坏，并防止静电放电 (ESD)。ESD 是导致计算机芯片损坏的常见方式，因此请务必保护计算机组件。

确保证据存放在安全柜中，且安全柜位于人员访问受限的安全区域。您需要证明只有授权人员才能接触证据。

![Image](exam.jpg)

> **证据应被记录并存放在人员访问受限的安全位置。**

### 记录步骤

到达现场后，记录您的所有步骤至关重要。请务必拍摄证据所在区域的照片。例如，如果您负责从嫌疑犯家中扣押计算机，请务必在接触任何东西之前拍摄计算机所在区域的照片。您还可以使用摄像机或*屏幕捕获软件*对调查步骤进行*视频录制*。如果您没有捕获视频步骤的软件，请务必对关键屏幕进行*截图*。

也要记录并拍摄连接到计算机的任何东西。例如，您可能会注意到外部驱动器连接到了系统。请务必不仅拍摄外部驱动器，还要拍摄计算机背面的连接器，以显示驱动器已连接到计算机。

在对证据执行分析时，请务必记录您执行的每一步。如果您发现了相关证据，至关重要的是您能解释您为寻找证据所采取的步骤，并且能反复重现结果。

![Images](job.jpg)

> **执行取证调查时，必须记录所有步骤，以便解释您如何发现证据并能重现结果。**

#### 事件时间线

拼凑证据时，您的目标是记录发生的事件时间线。您可以通过使用执行分析时发现的工件上的时间戳来实现这一点。分析证据（如驱动器映像）时，请确保您的取证软件具备纳入时间偏移的功能——以考虑到您的取证工作站可能配置的时区与嫌疑人数据的时区不同这一事实。因为这可能会导致时间偏差，大多数取证工具都提供了一种在分析时配置时区的方法，以便您能与证据的时区匹配。

一种有助于维护步骤日志的好方法是使用记事本创建一个文本文件，并在文本文件开头输入 `.LOG`。每次打开文件时，系统都会记录日期和时间——您只需开始记录您的步骤（请参见 [图 21-1](#ch21.xhtml#ch21fig1)）。请注意，`.LOG` 必须为大写字符。

**图 21-1**

作为取证调查员，您可能会被传唤上法庭报告调查结果。在整个调查过程中做清晰的笔记，以便您能回顾调查期间采取的步骤。

您生成的文档还有助于您在执行调查时跟踪工作工时和费用。如果您向客户提供取证服务，您将需要跟踪工时，以帮助向客户证明成本的合理性。

#### 视频和截图

作为文档记录的一部分，请务必拍摄现场视频以及嫌疑人计算机的截图。还要拍摄您在处理和分析证据时采取的步骤的视频和截图，因为如果涉及法律问题，您将需要证明您用于定位证据的步骤。

### 密码

分析证据时，您可能会发现证据受密码保护。例如，您可能会发现尝试打开的文件已加密，需要密码才能解密信息。大多数取证软件都提供了一种从注册表检索关键字并生成字典列表文件（请参见 [图 21-2](#ch21.xhtml#ch21fig2)）的方法，随后可用于尝试破解密码。

![Image](f0830-01.jpg)

**图 21-2**  
从注册表生成字典列表文件可以定位潜在密码。
