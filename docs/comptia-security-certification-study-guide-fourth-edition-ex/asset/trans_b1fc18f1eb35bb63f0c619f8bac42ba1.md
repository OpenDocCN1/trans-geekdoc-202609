

# Security+ 认证学习指南

安全是信息系统的关键组成部分，对精通安全评估和以安全方式配置系统的 IT 专业人员的需求正在不断增长。《CompTIA Security+ 认证学习指南，第四版》是一本综合性书籍，不仅旨在帮助您准备 CompTIA Security+ 考试 (SY0-601)，而且在您获得认证后还可作为实用的参考资料。

本学习指南的目标是通过让您熟悉 CompTIA 在其考试目标中确定的可能被测试的技术、任务、流程和原则，来帮助您准备 Security+ 考试。由于本书的主要重点是帮助您通过考试，因此它并不总是涵盖相关技术的各个方面。某些方面仅涵盖到帮助您理解通过考试所需知识的程度。不过，本书在您考试后也将作为宝贵的专业资源为您服务。

## 本书内容

本书的编排旨在作为 CompTIA Security+ 考试 (SY0-601) 的深度复习资料，适用于经验丰富的安全专业人士和信息系统安全领域的新手。每一章涵盖考试的一个主要方面，重点阐述“原因”以及“操作方法”，以帮助组织了解应在其环境中实施的关键安全技术。本书还帮助您了解如何评估并推荐改进组织内部安全的方法。

## 每章包含的内容

每章都包含一组组件，旨在引起您对重要项目的关注，强化重要知识点，并提供有用的应试提示。以下是每章中可能出现的组件列表：

- **认证目标**：每章以**认证目标**开头——即您为了回答考试中涉及本章主题的问题所需了解的内容。目标标题标识了章节内的目标，因此当您看到目标时，总能认出它！
- **考试聚焦**：**考试聚焦**注释提请您注意有关考试的信息和潜在陷阱。这些有用的提示由一位参加过考试并获得认证的作者编写——还有谁比他更适合告诉您该担心什么？他知道您即将经历什么！
- **分步练习**：**分步练习**穿插在各章中。这些通常设计为动手实践练习，让您获得通过考试所需的真实经验感。它们帮助您掌握考试中可能成为重点的技能。不要只是阅读练习；它们是您应该能够熟练完成的动手实践。学以致用是提高您对产品、工具或技术胜任力的有效途径。

- **实战经验**：**实战经验**注释描述了真实环境中最常出现的问题。它们为认证和产品相关主题提供了宝贵的视角。它们指出了常见错误，并解决了源自实际工作讨论和经验的问题。
- **考场内幕**：**考场内幕**侧边栏重点介绍了考生在参加实际考试时遇到的最常见和最令人困惑的问题。旨在预判考试将强调的内容，考场内幕侧边栏将帮助确保您知道通过考试所需的知识。通过重点关注这些侧边栏，您可以在如何应对那些难以理解的问题上占得先机。
- **认证总结**：**认证总结**是对本章的简明回顾，并重述了关于考试的显著要点。
- **两分钟演练**：✔ 每章末尾的**两分钟演练**是本章要点的清单。您可以将其用于考前临时复习。
- **自我测试**：问答 **自我测试**提供了类似于认证考试中所见的问题。您可以在每章末尾找到这些问题的答案以及答案解析。完成每章后参加自我测试，您将在巩固所学知识的同时熟悉考试题目的结构。

## 一些建议

读完本书后，留出一些时间进行彻底复习。您可能想多次回到本书，并利用它提供的所有复习方法：

1. **重读所有的两分钟演练**，或让他人对您进行提问。您也可以将演练作为考前突击复习的一种方式。您可能想用 3×5 索引卡制作一些抽认卡，上面写上两分钟演练的内容。
2. **重读所有的考试聚焦注释和考场内幕要素。** 请记住，这些注释是由参加过考试并通过的作者编写的。他知道您应该期待什么——以及应该警惕什么。
3. **重做自我测试。** 读完章节后立即做测试是个好主意，因为问题有助于巩固您刚学到的知识。然而，稍后再回过头来一次性做完书中所有问题，是个更好的主意。假装您正在参加实际考试。第一次做题时，您应该在另一张纸上标记答案。这样，您就可以根据需要多次练习这些问题，直到您对材料感到得心应手。
4. **完成练习。** 您在阅读每章时做练习了吗？如果没有，现在就做！这些练习旨在涵盖考试主题，没有比练习更好的方式来熟悉这些材料。请确保您理解在每个练习中执行每个步骤的原因。如果有什么不清楚的地方，请重读该章节中的相关部分。
