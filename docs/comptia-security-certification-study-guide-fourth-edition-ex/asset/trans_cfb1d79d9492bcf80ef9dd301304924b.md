

### 安全基线
安全基线是一组配置设置，可使系统处于安全状态。每个系统都应应用安全基线，以确保其满足安全要求。

### 完整性度量
计算机安全中的完整性度量是确保您知晓环境中可能发生的任何更改。为实现系统完整性，请务必使用审核功能和哈希技术来跟踪系统和文件的更改。

![Image](exam.jpg)

**针对 Security+ 考试，需了解沙箱的用途，还需了解软件安全部署不同阶段的顺序。顺序为 `development` → `testing` → `staging` → `production`。**

### 认证总结

在本章中，您学习了在系统上实施安全性的不同方法。以下列表总结了备考 Security+ 认证考试时，关于系统安全需牢记的一些要点：

- 在连接到不受信网络（如无线网络或酒店网络）的系统上实施基于主机的防火墙。
- 通过安装防病毒和反间谍软件保护系统免受恶意软件侵害。
- 大多数 Web 浏览器都内置了钓鱼过滤器，可将访问的站点与已知的钓鱼站点列表进行核对。
- 安装弹出窗口拦截器以防止弹出窗口出现。
- 移动设备应使用密码保护，且在设备空闲一段时间后应要求输入密码。数据应通过配置权限来保护，同时也应通过加密数据来保护。

##### 主机与应用安全解决方案

![Image](boxsq.jpg) 使用端点安全解决方案，如恶意软件防护、数据丢失防护（`DLP`）功能以防止数据泄露，以及基于主机的防火墙以控制与系统的通信。

![Image](boxsq.jpg) 通过实施启动完整性工具（如 `Secure Boot`、`Measured Boot` 和启动证明工具），可帮助保护系统上的敏感数据。

![Image](boxsq.jpg) `Tokenization`（令牌化）是一种涉及令牌服务的解决方案，它为敏感数据创建替代值，并存储替代值与实际数据的映射关系，以便查找。

![Image](boxsq.jpg) `Salting`（加盐）应与哈希配合使用，以帮助保护数据库中存储的密码。

##### 实施基于主机的防火墙和 HIDS

![Image](boxsq.jpg) 连接到不受信网络的任何系统都应使用基于主机的防火墙。

![Image](boxsq.jpg) Windows 和 Linux 都具有可启用以保护系统的防火墙。

![Image](boxsq.jpg) Linux 中的 `TCP wrappers`（TCP 包装器）功能允许您控制哪些系统可以连接到不同的服务。

##### 防范恶意软件

![Image](boxsq.jpg) 确保已安装病毒防护软件，且病毒定义是最新的。

![Image](boxsq.jpg) 确保服务器上安装了垃圾邮件过滤器，以防止垃圾邮件发送给用户。

![Image](boxsq.jpg) 确保已安装反间谍软件和其他反恶意软件。

##### 设备安全与数据安全

![Image](boxsq.jpg) 移动设备应配置密码，以便在设备被盗或丢失时，他人无法访问设备上存储的信息。

![Image](boxsq.jpg) 对移动设备和可移动驱动器上的数据进行加密，以保持机密性。

![Image](boxsq.jpg) `Trusted Platform Module (TPM)`（可信平台模块）是在计算机芯片上存储密钥的安全方法。

![Image](boxsq.jpg) 使用 `full disk encryption (FDE)`（全盘加密）加密移动设备上的驱动器，以便在设备丢失或被盗时帮助保护敏感数据。

![Image](boxsq.jpg) 使用应用程序白名单解决方案（控制允许运行的软件）或应用程序黑名单解决方案（控制禁止运行的软件）来限制系统上可运行的软件。

![Image](boxsq.jpg) 务必为 `development`（开发）、`testing`（测试）、`staging`（预发布）和 `production`（生产）设置不同的环境，以提高生产环境的安全性。

![Image](boxsq.jpg) 为网络上每种类型的系统创建安全基线配置，并务必将该基线应用到系统，以确保系统安全。
