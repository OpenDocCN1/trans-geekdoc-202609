### 图像文件分析工具

在分析嫌疑人的系统或设备以查找证据时，您可能会寻找图形文件等证据。如前所述，您可以通过在文件头开头定位具有 `FF D8 FF E0` 或 `FF D8 FF E1` 的文件，在十六进制编辑器中找到图形文件 (JPG)。分析图形文件时，请查看与图形文件一起存储的元数据。如今，大多数 JPG 文件都存储了关于拍摄照片的设备的 *Exchangeable Image File Format (Exif)*（可交换图像文件格式 [Exif]）元数据。例如，您可以查看所用相机的制造商和型号，以及日期和时间信息，如 [Figure 21-10](#ch21.xhtml#ch21fig10)（图 21-10）所示的示例。如果特定相机也在犯罪现场被扣押，此信息可能会很有用。许多相机和手机还存储元数据，例如拍照地点的 GPS 坐标，这对调查可能非常有用。

### INSIDE THE EXAM（考点深度解析）

**考试必知工具**

现在我们已经讨论了取证调查员使用的不同类型的工具，我想列出 Security+ 考试目标中提到的工具，以便您拥有一份必须为考试掌握的工具的集中清单：

- **`dd`** 一种常用的命令行实用程序，用于创建嫌疑人驱动器的镜像。请记住，将驱动器连接到镜像系统时要使用写保护器，并始终对镜像执行分析，而不是实际驱动器。
- **`Memdump`** 一种在系统关闭前捕获内存内容的工具。
- **`WinHex`** 一种常用的十六进制编辑器，可用于查看文件的低级内容，包括指示文件类型的文件头。
- **`FTK Imager`** AccessData 公司的一款工具，用于创建嫌疑人驱动器的镜像，随后可使用 FTK 或 Autopsy 等工具进行分析。
- **`Autopsy`** 一款取证分析工具，可用于分析镜像以定位证据。您可以在 Autopsy 中分析用 `dd` 获取的镜像。

### 内部部署与云

在执行调查时，您需要确定证据位于内部部署还是云端。本章讨论的所有内容均侧重于内部部署调查，因此以下是关于云调查您应为 Security+ 考试了解的几点注意事项：

- **Right-to-audit clauses**（审计权条款） 确保您与云服务提供商的合同规定了必须满足的安全要求，并确保您有权审计对这些要求的合规性。
- **Regulatory/jurisdiction**（法规/司法管辖区） 对于云中的数据，了解存储数据的服务器位于世界何处非常重要。对于大多数服务提供商，您可以指定数据存储的区域，以便了解适用于该数据的法规和法律。
- **Data breach notification laws**（数据泄露通知法） 确保您与提供商的合同规定，一旦发现数据泄露，您将立即收到通知，以便您随后遵守管辖贵公司的数据泄露通知法律。

## CERTIFICATION OBJECTIVE 21.03（认证目标 21.03）

## 查看事件响应

在本节中，您将了解事件响应和事件响应团队的概念。Security+ 认证考试将测试您关于如何在组织内响应安全事件的知识。

### 事件响应团队

为处理组织内的安全事件做准备的第一步是确保已建立事件响应团队（也称为 *Computer Incident Response Team* [CIRT] 或 *计算机事件响应小组*）。事件响应团队负责知道如何处理组织内发生的安全事件，并负责及时纠正和记录安全问题。

第一步是组建团队。团队将由组织内具有不同技能的不同类型的员工组成。以下是通常出现在响应团队中的一些成员的简要列表：

- **Team leader**（团队负责人） 团队负责人负责确保所有团队成员在发生安全事件时都知道自己的角色。团队负责人还负责与可能在特殊情况下被征召的外部资源建立关系。
