

### 基线偏差
安全基线是系统必须遵守的既定安全状态，不得有任何偏离。任何可能使系统暴露并降低其安全性的修改，都需要先经过审查，若实施则需密切监控。组织可以使用 `PowerShell Desired State Configuration (DSC)` 等技术来防止系统发生偏离基线的更改。

### 许可合规违规（可用性/完整性）
如果公司被发现软件许可不合规，可能面临巨额罚款。有可用的工具可让你跟踪软件安装情况，确保不超出允许的许可安装数量。

### 资产管理
系统投入生产后，你需要对其进行维护以保持其安全。集中维护系统是资产管理成功的关键。使用 `Group Policy Objects (GPOs)` 和 `Microsoft Endpoint Configuration Manager (MECM)` 等产品来管理配置、补丁、驱动程序和应用程序的部署。

### 身份验证问题
确保应用程序以最安全的方式配置身份验证，以防他人窃听身份验证流量，并利用应用程序使用的凭据获取网络访问权限。确保应用程序使用自己的账户，而非连接数据库时使用 `System` 账户或 `sa` 账户等默认账户。

## 分析和解读安全技术的输出

有许多不同的安全设备和技术会向用户显示消息或向系统管理员提供信息，使他们知晓发生的潜在安全事件。以下列表列出了你将从这些安全技术中看到的输出：

### HIDS/HIPS
基于主机的入侵检测系统 (`HIDS`) 或基于主机的入侵防御系统 (`HIPS`) 会在应用程序中显示潜在威胁的通知，或将其发送到指定的电子邮件地址。你需要查看通知事件，以识别系统上的任何可疑活动。查看输出时，请检查事件的日期和时间、事件来源（大多数 `HIDS`/`HIPS` 产品会审查来自多个来源的日志）以及导致事件发生的账户。利用这些信息，你可以决定是否需要进行配置更改。

### 杀毒软件
杀毒软件提供日志和通知。查看这些日志和通知以获取信息，例如计划扫描的结果，它将报告是否发现恶意软件，如果发现，则报告恶意软件的名称和受感染文件的名称。你还将收到有关采取的任何纠正措施的信息，例如受感染文件是否已从系统中删除或移至隔离区。

### 文件完整性检查
运行文件完整性检查工具时，它们会告知你自计算文件哈希值以来文件是否发生过更改。你可能会收到文件完整性检查的输出，例如 `hash mismatch` 或 `signature mismatch`，这两者都意味着文件已被篡改。`hash match`、`hash valid` 或 `signature verified` 等输出则表明文件未被更改。

### 基于主机的防火墙
基于主机的防火墙通常会将信息写入日志，或在因系统上配置的规则而丢弃流量时显示警报。查找包含诸如 `dropped packet src=24.35.45.3:63378 TCP dst=32.46.58.62:80 TCP` 等信息的输出。在此信息中，你应能看到源和目标 IP 地址（`24.35.45.3` 和 `32.46.58.62`）、源和目标系统使用的端口号（`:63378` 和 `:80`）以及协议（`TCP`）。

### 应用程序白名单
应用程序白名单是为系统配置一份允许使用的已批准软件列表。如果有人尝试安装或运行列表之外的应用程序，将收到一条错误消息，提示该应用程序未获授权。你可以使用 Windows 中的 `AppLocker` 创建一份获授权在系统上运行的应用程序列表。

### 可移动介质控制
可移动介质控制是指控制系统上可访问的介质，例如光驱和可移动介质（如外置 USB 驱动器）。当用户尝试连接或访问不允许使用的驱动器时，屏幕上通常会弹出一条通知，提示他们无权访问该驱动器。你可以通过 Windows 中的组策略配置可移动介质控制，如即将介绍的 [练习 5-1](#ch05.xhtml#ch5exer1) 所示。

### 高级恶意软件工具
高级恶意软件工具会通知你检测到的恶意软件，并提供关于该恶意软件的详细信息。它们还会报告恶意软件是否已成功清除或移至隔离区。

### 补丁管理工具
补丁管理工具旨在协助将补丁部署到网络上的系统。使用补丁管理工具时，你应该能看到输出，例如系统需要哪些补丁，以及向系统部署补丁时的状态更新。如果由于某些原因补丁未能应用到一个或多个系统，你也会收到通知。

### UTM
`统一威胁管理 (UTM)` 系统是一种集成了多种安全功能的设备，例如防火墙、`IDS/IPS`、网关杀毒软件和网关反垃圾邮件、内容过滤以及数据丢失防护等内置安全技术。`UTM` 系统会输出大量信息，例如可疑流量警报、被拦截的病毒和垃圾邮件数量报告，以及内容过滤违规数量摘要。

### DLP
数据丢失防护 (`DLP`) 解决方案可防止用户将敏感信息发送到公司外部。当用户尝试将数据复制到 USB 驱动器时，可能会收到来自 `DLP` 解决方案的错误消息，提示他们没有权限；或者如果用户尝试发送包含被 `DLP` 拦截的敏感信息的电子邮件，用户通常会收到一封电子邮件，提示因 `DLP` 违规，内容未发送。

### 数据执行保护
数据执行保护 (`DEP`) 是一项可启用的功能，用于防止应用程序代码在用于存储数据的内存区域（称为数据页）中执行。启用 `DEP` 后，系统会将不用于执行程序的内存块标记为不可执行页面，从而防止恶意软件在该内存块中运行。你可以通过转到命令提示符并输入 `wmic OS Get DataExecutionPrevention_SupportPolicy` 来验证系统上是否启用了 `DEP`。你将收到输出 `0`（始终关闭）、`1`（始终开启）、`2`（针对 Windows 二进制文件开启）或 `3`（针对所有程序和服务开启）。

### Web 应用程序防火墙
Web 应用程序防火墙旨在保护 Web 服务器免受恶意流量侵害，仅允许发往 Web 应用程序的流量通过防火墙。被防火墙阻止的流量会被写入日志文件，以便系统管理员查看被阻止的流量。

### 可移动介质控制

在本练习中，你将通过系统上的策略禁用对可移动介质的写入访问，然后尝试将文件保存到可移动驱动器，以查看系统提供的输出。

1. 登录到 Windows 10 VM，然后单击“开始”按钮。
2. 输入 `gpedit.msc` 并按回车键启动“本地组策略编辑器”。
3. 展开“计算机配置” | “管理模板” | “系统”，然后选择“可移动存储访问”。
4. 在这里你会看到许多用于禁用对不同类型介质的执行、读取或写入访问的策略。双击“可移动磁盘：拒绝写入访问”策略，然后选择“已启用”。
