
如果账户是为临时员工创建的，您还可以为账户实施账户过期功能。例如，一家会计事务所可能决定在报税季雇佣一名新的临时会计师，但报税季结束后该员工将离职。在网络上创建此账户时，请务必设置账户过期日期（请参阅[图 11-4](#ch11.xhtml#ch11fig4)），以便在离职当天到来时，该账户不再有效。

### 账户锁定

在实施用户账户限制时，实施账户锁定策略至关重要。账户锁定策略规定：在发生一定次数的登录失败尝试后，账户将被锁定而无法使用。在该策略中，您还需指定账户锁定的时长——您可以设置以分钟为单位的时间，或指定账户锁定直到管理员将其解锁。[图 11-6](#ch11.xhtml#ch11fig6) 显示了 Windows 中的账户锁定策略设置。

![Image](f0499-01.jpg)

**图 11-6**  
账户锁定将在发生一定次数的登录失败后锁定账户。

三个设置用于配置账户锁定策略：

- **账户锁定阈值** 指定在账户被锁定前允许发生多少次登录失败。
- **账户锁定时长** 指定锁定账户的时间长度。在 Windows 设置中，值 `0` 将配置为锁定账户直到管理员将其解锁。
- **重置账户锁定计数器** 用户登录失败后，计数器会加一，直到账户被锁定或用户成功登录。您可以配置何时将计数器重置为零。

### 账户禁用

作为安全专业人员，重要的是要向网络管理员强调，应禁用未使用的账户，使其无法被使用。这将有助于防止员工甚至黑客未经授权地使用该账户。当员工休假、被停职或离职时，请务必禁用其账户。

### 查看账户详细信息

## 账户策略实施

您应该熟悉许多与访问控制相关的概念和最佳实践。其中一些主题在本章中已经详细讨论过，但我希望创建一个在组织内实施账户策略的最佳实践摘要。

- **共享账户** 所有用户都必须拥有自己的账户，这一点至关重要，这样才能唯一地应用权限，并能审核每个人的操作。
- **凭据管理** 确保您拥有一个集中的凭据管理工具，以及一项关于用户必须多久更改一次密码的策略。
- **组策略** 应使用组策略将安全设置部署到网络上的所有服务器和客户端。
- **密码复杂性** 确保系统上的任何账户和网络访问都使用复杂密码。这些密码比非复杂密码更难破解。
- **过期** 确保密码在一段时间后过期，并且用户必须设置新密码。此外，请务必设置创建的任何临时用户账户的过期日期。
- **恢复** 确保能够恢复任何被删除的账户，或重置任何被遗忘的密码。
- **禁用** 请务必禁用任何不必要的账户，并为休假的员工禁用账户。
- **锁定** 配置账户锁定策略，以便在连续三次输入错误密码后，账户被锁定（不可用），直到管理员将其解锁。
- **密码历史记录** 一个需要配置的重要密码设置是密码历史记录选项——确保您的系统通过在历史记录中保留以前的密码，防止用户重复使用相同的密码。
- **密码重用** 确定贵组织关于重用密码的策略，并务必配置密码历史记录以强制执行该策略。
- **密码长度** 大多数组织要求最小密码长度为八个字符。
- **通用账户禁用** 与前面提到的共享账户要点类似，请确保没有为用户或系统共享而创建的通用账户，因为这会使审核操作变得困难。
- **网络位置** 您的公司可能希望实施访问控制策略，限制从特定网络位置访问特定资源。例如，要访问敏感服务器，用户必须连接到安全网络。我们之前提到的另一个示例是，在 Azure 中，您可以根据来自特定国家/地区的 IP 地址阻止访问。此外，Netflix 等流媒体服务可以根据您所在的国家/地区阻止对内容的访问。
- **地理围栏** 地理围栏是一项功能，允许软件管理员定义 GPS 坐标以创建边界（或虚拟围栏）。当运行该软件的设备超出边界时，将触发警报。
- **地理标记** 地理标记是在 Facebook 或 Instagram 等社交媒体应用的帖子中标识您的位置。作为公司策略，您可能希望限制地理标记的使用以及在社交媒体上发布公司信息。
- **地理定位** 地理定位是识别移动电话等项目地理位置的术语。例如，一旦确定了移动电话的地理定位（GPS 坐标），您就可以使用地图技术将其与街道地址关联起来。
- **基于时间的登录** 如前所述，您可以限制用户在一天中的什么时间登录系统。您可能会制定策略，限制不同职位员工的登录时间。
- **访问策略** 访问策略是定义每个用户账户对系统或信息的访问级别的策略。
- **账户权限** 您应该制定策略，规定账户对网络中系统和数据应具有的不同类型的权限。
- **账户审核** 您应该审核用户账户的活动。这包括登录活动、对敏感数据的访问以及用户权限的任何更改。
