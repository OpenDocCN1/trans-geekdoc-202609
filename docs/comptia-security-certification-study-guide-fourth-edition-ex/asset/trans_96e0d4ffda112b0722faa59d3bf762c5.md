## 自测答案

### 主机与应用安全解决方案

## 1.

![Image](boxt.jpg) **B.** 加盐是获取一个随机值并将其与待哈希的值（在本例中为密码）结合，以创建一个哈希值，该值能更好地防范通过将字典单词进行哈希运算来破解密码的密码破解工具。

![Image](boxx.jpg) **A、C** 和 **D** 不正确。加密不用于哈希；它是用来替代哈希的。令牌用于数据库中的敏感数据，如信用卡号。安全启动是一种启动完整性技术，可防止系统从经过篡改的启动状态引导。

## 2.

![Image](boxt.jpg) **C.** 令牌化是指用随机的、无关的数据替换敏感数据，并将敏感数据与替代数据的映射关系存储在令牌服务中。然后，应用程序通过提供替代数据向令牌服务发送请求以查找敏感数据。

![Image](boxx.jpg) **A、B** 和 **D** 不正确。加密用于保护数据库中的敏感数据，但令牌化常用于频繁使用的敏感数据。加盐是将随机值与数据结合，然后将两者的组合通过哈希算法运行。哈希是将数据通过哈希算法运行以创建唯一哈希值（校验和类型的值）。

## 3.

![Image](boxt.jpg) **D.** 数据丢失防护 (DLP) 是一种防止数据泄露的解决方案，例如某人在电子邮件中发送敏感信息或将数据下载到 USB 驱动器。

![Image](boxx.jpg) **A、B** 和 **C** 不正确。反恶意软件是防止系统遭受病毒感染的软件。基于主机的防火墙用于限制与系统的通信。下一代防火墙 (NGFW) 包含防火墙功能，还包括入侵防御功能以阻止攻击。

### 实施基于主机的防火墙和 HIDS

## 4.

![Image](boxt.jpg) **D.** 每当系统将要连接到不受信任的网络时，都应使用基于主机的防火墙。

![Image](boxx.jpg) **A、B** 和 **C** 不正确。这些不代表关于 Mark 笔记本电脑安全性的实施建议。

## 5.

![Image](boxt.jpg) **B.** 大多数防火墙在启用后都有一条拒绝所有流量的默认规则。

![Image](boxx.jpg) **A、C** 和 **D** 不正确。这些不代表默认规则。大多数防火墙允许您将默认规则从“拒绝所有”修改为“允许所有”。

## 6.

![Image](boxt.jpg) **C.** Linux 中的 TCP 包装器功能允许您控制哪些客户端可以连接到哪些服务。

![Image](boxx.jpg) **A、B** 和 **D** 不正确。虚拟化是在一台物理机器上的虚拟机中托管多个操作系统。云计算是由提供商为您托管服务器，而您通过 Internet 远程连接到它们以管理系统。基于主机的防火墙控制与系统的通信。

## 7.

![Image](boxt.jpg) **A.** 基于主机的 IDS 通过分析日志文件、文件属性以及连接和内存等动态数据来识别可疑活动。

![Image](boxx.jpg) **B、C** 和 **D** 不正确。网络流量和数据包分析由基于网络的入侵检测软件执行。TCP 包装器功能不查找可疑流量；它只是控制对服务的访问。

### 防范恶意软件

## 8.

![Image](boxt.jpg) **B.** Windows Server Update Services (WSUS) 是一项服务，允许您下载、审核、批准补丁并将其部署到网络上的系统组。

![Image](boxx.jpg) **A、C** 和 **D** 不正确。病毒防护和基于主机的防火墙不处理系统打补丁的问题。在每个系统上使用 Windows Update 是管理噩梦，因此应使用 WSUS。

## 9.

![Image](boxt.jpg) **D.** 安装防病毒软件后，确保病毒定义是最新的至关重要。大多数防病毒软件可以计划病毒定义的更新。

![Image](boxx.jpg) **A、B** 和 **C** 不正确。基于主机的防火墙与维护防病毒软件无关，您不应禁用病毒定义的自动更新；而应*启用*它们。您也不应禁用实时防护，因为它会在文件被访问时进行扫描。

## 10.

![Image](boxt.jpg) **C.** 无论是在网页上还是通过他人的网站提交，在 Internet 上公开电子邮件地址，都始终存在该地址可能收到未经请求的邮件的风险。

![Image](boxx.jpg) **A、B** 和 **D** 不正确。间谍软件、病毒和网络钓鱼并非提供电子邮件地址所带来的担忧。

### 设备安全与数据安全

## 11.

![Image](boxt.jpg) **B** 和 **D。** 您应确保锁定屏幕并加密移动设备上的数据，以防止未经授权的访问。

![Image](boxx.jpg) **A、C** 和 **E** 不正确。您应启用密码而非禁用它，且切勿禁用紧急呼叫，以便在手机锁定时仍可拨打 911。如果不使用蓝牙则应将其禁用，但大多数人使用蓝牙连接无线耳机。
