#### 设计评审

您可以用来评估安全性的另一个工具是在解决方案实施前后执行设计评审。从一开始就识别系统的安全顾虑也至关重要，这样您才能宣称具有“`secure by design`”（安全设计）地位（意味着从解决方案创建的始至终都将安全作为重点）。一旦解决方案完成，无论是应用程序还是网络解决方案，都要进行设计评审，确保实际实施的内容确实是作为解决方案所请求的内容。

### 执行安全评估

本节将为您提供执行优秀渗透测试所应采取步骤的良好概览。请务必严格遵循每个步骤，以保护您作为渗透测试人员的自身利益。您不希望公司或组织事后找上门来，声称他们并未要求您执行该测试。

执行安全评估时，请确保花时间规划步骤并遵循一种方法论。该方法论可以是您自己的，也可以遵循行业标准方法论（推荐）。作为安全专业人员，您应了解以下一些标准方法论：

- **OVAL** — 开放漏洞评估语言是一项用于评估系统漏洞的国际标准。OVAL 评估分三个阶段：表征系统信息、评估漏洞和报告漏洞。请访问 [http://oval.mitre.org/about/index.html](http://oval.mitre.org/about/index.html) 了解更多关于 OVAL 的信息。

- **OCTAVE** — 运营关键威胁、资产和漏洞评估是一种自我指导的安全评估方法论。“自我指导”意味着组织从自己的员工中选拔一个团队来进行安全评估。OCTAVE 包含四个阶段：(1) 制定与业务目标一致的风险管理标准，(2) 为每个信息资产创建档案以明确安全需求，(3) 识别针对这些资产的威胁，以及 (4) 识别和分析风险并开始缓解措施。请访问 [www.cert.org/octave/](http://www.cert.org/octave/) 了解更多关于 OCTAVE 的信息。

- **OWASP** — 开放 Web 应用程序安全项目是一个将 Web 应用程序安全测试流程标准化的项目。您可以访问 [www.owasp.org](http://www.owasp.org) 了解更多信息。OWASP 发布了一些关于 Web 应用程序测试和代码审查的优秀指南。

#### 威胁狩猎

*威胁狩猎* 是指在资产遭到攻击者攻击和破坏之前，识别针对公司资产的威胁这一行动的术语。威胁猎手监控网络和系统活动，以发现其环境中可能存在的潜在新威胁和漏洞。威胁猎手可能会使用多种工具，包括以下内容：

- **情报融合** — 情报融合是收集单独的“情报”流或监控数据，并将这些数据结合在一起，以获得对当前态势的完整图景。例如，在 IT 安全领域，您可以“融合”防病毒数据、网络传感器数据、服务器日志和防火墙连接信息，以证明攻击的发生及其影响范围。

- **威胁情报源** — 威胁情报源是通过网站发布和分发的威胁指标列表，用于自动共享威胁指标。威胁情报源数据库可能包含恶意 IP 地址或恶意电子邮件发件人等信息。其好处是，任何订阅该情报源的人都能在信息更新时获知这些情报。

- **通告和公告** — 可以发送安全通告和安全公告，以通知公众新的安全威胁。

- **机动** — 机动是指为获得竞争优势而进行战略性移动的概念。在威胁管理中，您的策略应具有动态性以发现新威胁（例如，在网络的特定区域部署蜜罐以检测威胁）。

#### 漏洞扫描

执行漏洞评估时，您可以使用漏洞扫描作为一种技术，以自动化识别环境中漏洞的过程。本节列出了执行漏洞扫描时应考虑的多项因素，以及识别漏洞的不同方式。

##### 漏洞扫描的注意事项

使用漏洞扫描器自动化识别漏洞的过程时，您应牢记以下要点：

- **侵入式与非侵入式** — 重要的是要了解，漏洞扫描被视为非侵入式扫描，因为您并非真正尝试入侵系统或利用漏洞（渗透测试才会尝试利用系统）。

- **有凭据与无凭据** — 执行漏洞扫描时，您应确保以未经身份验证的用户（无凭据）身份执行一次扫描，以了解向网络中未知人员暴露了哪些信息。然后您应以管理员账户登录并执行扫描，以便收集尽可能多的系统信息。

- **误报** — 与任何类型的扫描一样，密切关注误报非常重要——即被报告为漏洞但实际并非漏洞的情况。

- **漏报** — 漏报可被视为比误报更严重，因为它们是实际发生但未被系统检测到的事件。就漏洞扫描而言，漏报是指存在但未被漏洞扫描器识别出的漏洞。

##### 检查类型

正如本章前面所讨论的，漏洞扫描器可以对系统执行多种不同类型的检查：

- **配置审查** — 漏洞扫描器可以检查系统的配置，并向您报告应更改的任何脆弱设置。

- **日志审查** — 漏洞扫描器可能会审查系统上的日志文件，以识别可能被视为可疑的已发生事件。

- **应用程序** — 漏洞扫描器可能会对应用程序执行漏洞检查，并查找应用程序设计中的缺陷。

- **Web 应用程序** — 存在专门针对 Web 应用程序的漏洞扫描器，例如 `Nikto`，它们会查找网站上可能存在的常见漏洞。

- **网络** — 漏洞扫描器可能具备扫描网络上多个系统以及扫描网络设备（如交换机、路由器和打印机）的能力。
