

# 账户类型

**考试重点：务必了解这些不同类型的账户。同时请记住，由多名员工共用的共享账户会导致难以审计谁执行了操作。从审计角度来看，您应确保每位员工都拥有自己的账户。**

## 来宾账户

**来宾账户** 来宾账户是指当某人没有账户时，可用于访问系统的账户。这允许个人在无需为其创建账户的情况下获得对资源的临时访问权限。大多数操作系统都有来宾账户，但默认情况下处于禁用状态，这意味着如果有人想要访问系统，则需要为其创建一个账户。保持来宾账户处于禁用状态是一项安全最佳实践。

## 服务账户

**服务账户** 安全的操作系统（如 Windows 和 Linux）要求所有内容都向系统进行身份验证，无论是用户还是一段软件。当软件在系统上运行时，它需要作为特定用户运行，以便为该软件分配权限。您与某软件关联的用户账户称为服务账户，因为操作系统中运行的服务也会使用此功能。创建服务账户（软件应用程序将配置为使用的用户账户）时，通常会为服务账户配置强密码，并指定密码永不过期。

![Images](job.jpg)

**请确保服务账户不具备管理功能，因为否则，如果服务遭到缓冲区溢出攻击等攻击而被攻破，攻击者将拥有与该服务关联账户相同的凭据。**

## 特权账户

**特权账户** 特权账户是指拥有超出分配给普通用户权限之外的额外权限的账户。特权账户通常被授权对系统进行配置更改，或执行普通员工通常不执行的操作。

# 使用安全组

在大多数环境中，实施访问控制的首要方法是授予对安全组的访问权限。授予资源访问权限的正确方法是将用户账户放入组中，然后将权限分配给该组。这样您就可以将新用户放入该组，而无需回头去修改权限。

### 配置安全组并分配权限

在本练习中，您将在 Active Directory 中创建一个安全组，然后将一个用户账户放入该组。创建组后，您将为该组分配对文件夹的权限。

1. 在 ServerA VM 上，转到服务器管理器，然后选择 **工具** | **Active Directory 用户和计算机**。
2. 通过右键单击“用户”文件夹并选择 **新建** | **用户**，创建一个名为 **Lab11UserA** 的新用户。
3. 在名字字段中输入 **Lab11UserA**。
4. 在 **用户登录名** 字段中输入 **Lab11UserA**，然后单击 **下一步**。
5. 在 **密码** 字段和 **确认密码** 字段中输入 **P@ssw0rd**，然后取消勾选“下次登录时需更改密码”复选框。单击 **下一步**，然后单击 **完成**。
6. 要创建安全组，请右键单击“用户”文件夹并选择 **新建** | **组**。
7. 将组名输入为 **Authors**，然后单击 **确定**。
8. 要为组分配权限，请转到文件资源管理器并导航到驱动器 **C:**。右键单击驱动器 **C:**，选择 **新建** | **文件夹**，并在驱动器 **C:** 上创建一个名为 **Publications** 的文件夹。
9. 要为 Authors 组分配权限，请右键单击 Publications 文件夹并选择 **属性**。单击 **安全** 选项卡。
10. 要将 Authors 添加到权限列表中，请单击 **编辑**，然后单击 **添加**。
11. 在 **选择用户、计算机或组** 对话框中输入 **authors**。单击 **确定**。
12. 在权限列表中选择 **Authors**，然后为该组分配 **修改** 权限。
13. 连续单击两次 **确定**。

# 权利与特权

系统安全的很大一部分源于这样一个事实：只有特定的安全主体（用户或组）才能执行特定操作。例如，如果任何人都能备份系统上的任意文件，那将是一个巨大的安全隐患。在 Microsoft 环境中，只有拥有“备份文件和目录”权利的人才能执行备份。

在 Windows 系统上，通常必须以管理员身份登录才能对系统进行更改；而在 Linux 中，通常需要以 root 身份登录才能进行更改。通过授予他人正确的权利或特权，可以允许他们对系统进行更改。

Microsoft 操作系统在系统策略中设有 **用户权利分配** 部分，您可以在其中控制谁可以执行常见的管理任务，例如备份文件和目录或更改系统时间。以下概述了 Windows 中一些常见的权利：

## 常见 Windows 权利

- **从网络访问此计算机** 此权利控制允许谁通过网络连接到该系统。
- **允许本地登录** 此权利控制允许谁坐在计算机前进行登录。
- **备份文件和目录** 此权利控制谁可以在系统上执行备份。
- **更改系统时间** 此权利控制允许谁调整计算机上的时间。
- **获取文件或其他对象的所有权** 此权利控制允许谁获取文件、文件夹或打印机的所有权。资源的所有者可以随时更改该资源的权限。

在课堂讲授安全概念时，我经常纠正大家的术语——**权利** 是指某人执行任务的特权，而 **权限** 是指某人对资源的访问级别。例如，Authors 组被授予了 Publications 文件夹的 **修改** *权限*。Authors 组并未被授予 **修改** *权利*。反之亦然——Authors 组被授予了执行备份的 *权利*，而非执行备份的 *权限*！
