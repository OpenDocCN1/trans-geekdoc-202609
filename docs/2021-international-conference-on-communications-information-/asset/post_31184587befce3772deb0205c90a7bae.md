## III. SYSTEM DESIGN

### A. Overall Architecture
The framework of the CSI-based localization system is shown in Fig. 2. CSI Tools first collect the CSI samples, then the CSI is pre-processed. After that the features are extracted using DTW and fed into ELM to train the model. The test set is processed in the same way to obtain the features, and then the test results are obtained.

### B. Data Preprocessing
The raw CSI data collected contains typical errors such as useful channel state information and measurement errors and certain outliers formed by interference from equipment or uncertainties that interfere with localization using CSI. We apply a hampel filter with a sliding window on each subcarrier to remove outliers that are usually significantly different from neighboring CSI measurements. In addition, we apply a moving average filter to remove high-frequency noise.

### C. Feature Extraction
DTW is a dynamic programming algorithm that calculates the similarity of two time series, especially those of different lengths. It is mainly applied to temporal data, such as isolated word speech recognition, gesture recognition, data mining and information retrieval. In fingerprint localization, fingerprints are almost always based on individual data and rarely generate a fingerprint for localization based on a segment of data. DTW calculates the difference between the target at different reference points and the target which is not in the environment to obtain fingerprints, which effectively extracts the overall characteristics of the data.

## V. CONCLUSION
In this paper, we propose a device-free indoor localization method based on WiFi CSI, using two common commercial WiFi devices and a single receiver device to collect CSI data, pre-processing the collected CSI data to extract features using DTW, and then using ELM model for localization. The method was evaluated in a laboratory environment and experimental results showed that the method was superior to SVM and BPNN. The average distance error was 1.12m in a typical indoor environment.
