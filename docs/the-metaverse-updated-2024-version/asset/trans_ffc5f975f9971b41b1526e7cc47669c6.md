

# 智能合约与 NFT

智能合约最简单的实现是“非同质化代币”（NFT）。在这种情况下，会编写一份智能合约，将数据发布（或“铸造”）到区块链上，并将该数据的所有权分配给区块链上的某个地址（“钱包”）。这些数据可能是一条记录，表明该钱包的所有者购买了县集市的门票——也可能是该县某套房产的产权证。一旦这个 NFT 被铸造，接收地址就可以完全控制这条记录，并可以自由地将其重新分配（即出售或转让）给区块链上的任何其他地址。虽然这个 NFT“智能合约”的底层代码可以轻易复制，与之相关的数据（例如门票收据或房产契据）也可以复制，但实际的 NFT 及其记录既不能复制也不能替代——因此称为“非同质化”——因为这些是写入区块链的唯一且不可更改的标识符。因此，NFT 的支持者认为，它们可以作为一个全球性系统，无可辩驳且自动地验证虚拟和实物商品的所有权，并且可以被世界上任何应用程序或用户访问。

# 智能合约交互

智能合约也可以与其他智能合约进行交互。一份智能合约可能会被编写为识别 NFT 的所有权，以允许某些活动，例如登录仅限会员的 Discord 频道或进入当地集市。许多 NFT 包含代码，每当 NFT 被出售时，这些代码会自动激活第二个智能合约。后一个智能合约通常用于将 NFT 原始创作者（或某些其他预先指定的地址）发送部分所得款项（一种“版税”），通常在 5% 到 10% 之间，这使艺术家能够直接参与其作品的增值——这种待遇通常不提供给画家、摄影师、设计师等，而且过去更难收集、审计和执行。

# NFT 市场概览

在 2021 年和 2022 年期间，全球在 NFT 上的支出大约为 650 亿美元。^([3](#notes_split_011.xhtml#ch11fr3)) 这些购买非常多样化。Dapper Labs 的 NBA Top Shots 将各个 NBA 赛季的个别时刻转化为可收集的、类似交易卡的 NFT，这些 NFT 运行在 Dapper 自有的区块链 Flow 上。像 Damien Hirst 这样的艺术家也发布了作为 NFT 的绘画和照片（有时包含对实体作品的权利）。^([4](#notes_split_011.xhtml#ch11fr4)) Larva Labs 是一家专注于加密货币的设计工作室，发布了一个名为“Cryptopunks”的 NFT 集合，包含 10,000 个算法生成的 24x24 像素 2D 头像，许多所有者将其用作互联网上的个人资料图片。Bored Ape 是另一个头像 NFT 系列，除了为所有者提供底层艺术作品的部分 IP 权利外，还允许他们使用自己的“猿猴”来进入附属社交俱乐部——无聊猿游艇俱乐部，并拥有对艺术品的部分权利。2022 年 4 月，每周支付给 NFT 创作者的版税创下了 7800 万美元的纪录。

# 去中心化应用程序（dapps）

智能合约的集合已被用于生成去中心化应用程序（“dapps”），这些应用程序可以执行类似于传统应用程序的复杂任务。示例有助于使这一概念具体化，并展示基于区块链的应用程序的一些潜在好处。

## Uniswap

Uniswap 使用户能够与其他用户交换数百种不同的代币，而无需合同、经纪人、清算所、延迟或未交付的担忧，且费用仅为 0.3%——远低于传统银行通常要求的 1%–3% 的货币兑换点差。在其 2018 年 11 月推出后的五年里，Uniswap 处理了超过 1.5 万亿美元的交易，单月处理量高达 900 亿美元（2021 年 11 月），单日处理量高达 140 亿美元（2022 年 3 月 10 日）。^([5](#notes_split_011.xhtml#ch11fr5)) 尽管运营规模巨大，Uniswap 只有几十名员工。^([6](#notes_split_011.xhtml#ch11fr6))

## OpenSea

OpenSea 是一个专注于 NFT 交易（而非加密货币或代币）的市场，平均收取销售额的 2.5%。该平台允许用户展示自己的 NFT 收藏，以及浏览他人的收藏，并可以搜索、竞拍和购买单个 NFT，或将自己的 NFT 放售。OpenSea 的员工人数在 2022 年达到约 300 人的高峰，还提供编辑和策展功能（例如精选合集）、验证服务（确认待售 NFT 的合法性），以及阻止被盗 NFT 的销售。自 2017 年 12 月 OpenSea 推出以来的六年里，已处理了超过 350 亿美元的 NFT 销售额，峰值出现在 2022 年 1 月，交易额约为 50 亿美元。^([7](#notes_split_011.xhtml#ch11fr7))

## Mirror

Mirror 利用智能合约和代币系统重新构想了独立新闻和博客的商业模式。在该平台上，作者可以通过预售完成作品的 NFT 副本来为其研究、调查和写作融资，或者发行代币，这些代币将用于访问完成的作品，或使所有者有权获得该作品产生的部分收入。在其他情况下，一群作者发行代币为一本新杂志筹集资金，该杂志随后仅对代币持有者开放。一些作者使用智能合约自动与帮助或启发过他们的人分享小费。

## Axie Infinity 和 Zed Run

*Axie Infinity* 和 *Zed Run* 分别利用区块链构建了视频游戏 *Pokémon* 和虚拟赛车的“Web3”版本。在这两种情况下，这些游戏发行基于 NFT 的生物，这些生物可以被收集、繁殖、交易、训练、战斗、出租或用于赌博，智能合约管理利润分成和基因遗传，同时还操作游戏内的赔率和战斗。由于 NFT 是铸造到区块链上，而不是记录在其制作者的私有数据库中，外部开发者也可以访问和使用这些生物——而且不一定是为了构建游戏。2020 年，名为 Yield Guild Games (YGG) 的集体成立，主要目的是购买“Axies”，然后将其出租给 *Axie Infinity* 玩家，以换取其奖金和/或租金的一部分。换句话说，YGG 通过让 Sky Mavis 的玩家玩 Sky Mavis 的游戏来赚钱。

## Otoy 和 RNDR

在少数情况下，dapps 和智能合约被用于建立和运营大规模的去中心化基础设施网络，这些 dapps 和智能合约通常会在其运行的区块链之上发行自己的加密货币。一个领先的例子是 Otoy，一家基于云的渲染公司，于 2020 年公开推出了基于以太坊的 RNDR 网络、协议和代币。具体来说，RNDR 建立了一个基于代币的市场，其中闲置计算机可以将其 GPU 提供给需要额外计算能力的人。各方之间的所有谈判和合同都由 RNDR 的协议在几秒钟内处理；双方都不知道正在执行的任务的身份或具体细节；所有交易都使用 RNDR 加密货币代币进行。根据该公司的说法，RNDR 可以以远低于集中式数据库提供的成本执行任务，同时将全球可用计算资源的供应量提高几个数量级。^([8](#notes_split_011.xhtml#ch11fr8))
