

重要的是，这一切都没有阻止企业在互联网上获利、部署付费墙或构建专有技术。相反，互联网的“开放性”使得更多公司能够在更多领域建立起来，触达更多用户，并实现更大的利润，同时也阻止了互联网巨头（以及至关重要的电信公司）对其进行控制。开放性也是互联网在很大程度上被认为实现了信息民主化的原因，也是当今世界上大多数最有价值的上市公司是在互联网时代创立（或重生）的原因。

很容易想象，如果互联网是由跨国媒体集团创建来销售小部件、投放广告、收集用户数据以获利或控制用户端到端体验（AT&T 和 AOL 都曾尝试但未能成功），那么互联网会有多么不同。下载一张 JPG 可能需要花钱，而一张 PNG 可能要贵 50%。视频通话可能只能通过宽带运营商自己的应用程序或门户实现——并且只限于那些也拥有相同宽带提供商的人（想象一下类似“欢迎使用您的 Xfinity 浏览器™，点击此处使用 Xfinitybook™ 或由 Zoom™ 提供支持的 XfinityCalls™；抱歉，‘奶奶’不在我们的网络中，但花 2 美元您仍然可以给她打电话……”）。想象一下，如果制作一个网站需要一年或一千美元。或者如果网站只能在 Internet Explorer 或 Chrome 中运行——并且用户必须向特定浏览器支付年度费用才能使用它。或者也许用户必须向其宽带提供商支付额外费用才能阅读某些编程语言或使用特定的 Web 技术（“此网站需要 Xfinity Premium with 3D”）。当美国在 1998 年起诉微软涉嫌违反反垄断法时，其案件核心在于微软决定将其专有 Web 浏览器 Internet Explorer 与 Windows 操作系统捆绑在一起。然而，如果一家公司创建了互联网，它是否甚至会允许竞争浏览器？如果允许，它是否会允许用户在这些浏览器上随心所欲，或访问（和修改）他们选择的任何网站？

“企业互联网”是当前对元宇宙的预期。互联网的非营利性质及其早期历史源于这样一个事实：政府研究实验室和大学几乎是唯一拥有构建“网络的网络”的计算人才、资源和雄心的机构，而营利部门很少有人了解其商业潜力。在元宇宙方面，这一切都不成立。相反，它是由私营企业开发和构建的，其明确目的是商业、数据收集、广告和虚拟产品的销售。

更重要的是，元宇宙正在出现于这样一个时代：最大的垂直和水平科技平台已经对人们的生活以及现代经济的技术和商业模式建立了巨大的影响力。他们的力量由数字时代的深刻反馈循环所增强。例如，梅特卡夫定律指出，通信网络的价值与其用户数量的平方成正比，这种关系有助于大型社交网络和服务保持增长，并对初创竞争对手构成挑战。任何基于人工智能或机器学习的业务，随着其数据集的增长，都能从类似的优势中受益。互联网的主要商业模式——广告和软件销售——也是规模驱动的，因为销售另一个广告位或应用程序的公司几乎没有增量成本，而广告商和开发者主要关注消费者已经所在的地方，而不是他们可能所在的地方。

但为了巩固其用户和开发者基础，同时扩展到新领域并阻止潜在竞争对手，科技巨头在过去十年中一直在封闭其生态系统。他们通过强制捆绑其众多服务、防止用户和开发者轻松导出自己的数据、关闭各种合作伙伴计划，以及阻碍（甚至直接阻止）可能威胁其霸权的营利性甚至开放标准来实现这一点。这些举措，加上拥有相对更多用户、数据、收入、设备等所带来的反馈循环，实际上已经封闭了互联网的大部分。今天，开发者基本上必须获得许可并支付费用。用户对其在线身份、数据或权利几乎没有所有权。

正是在这里，对元宇宙反乌托邦的担忧似乎是合理的，而不是危言耸听。元宇宙的概念本身意味着，人们生活、劳动、休闲、时间、财富、幸福和关系中不断增长的份额将花费在虚拟世界中，而不仅仅是通过数字设备和软件进行扩展或辅助。对于数百万甚至数十亿人来说，它将是一个并存的存在平面，位于数字和物理经济之上，并统一两者。因此，控制这些虚拟世界及其虚拟原子的公司，可能会比当今数字经济中的领导者更具主导地位。

元宇宙还将使当今数字存在的许多棘手问题更加尖锐，例如数据权利、数据安全、错误信息和极端化、平台权力和监管、滥用以及用户幸福。因此，元宇宙时代领先公司的理念、文化和优先事项，将有助于决定未来是比当前时刻更好还是更糟，而不仅仅是更虚拟或更有回报。

随着世界上最大的公司和最雄心勃勃的初创公司追求元宇宙，我们——用户、开发者、消费者和选民——必须明白，我们对未来拥有主动权，并有能力重置现状。是的，元宇宙可能看起来令人生畏和可怕，但它也提供了一个机会，让人们更加紧密地联系在一起，转变那些长期抵制颠覆并必须发展的行业，并建立一个更平等的全球经济。一切都取决于它是如何构建的。
