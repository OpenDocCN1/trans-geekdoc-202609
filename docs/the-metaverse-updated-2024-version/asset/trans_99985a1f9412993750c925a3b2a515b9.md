

# 图形模拟与头戴式显示器的发展

随着图形模拟领域的进步，人们也致力于构建能够实现“皮格马利翁眼镜”的“头戴式显示器”。

## 1955年：莫顿·海利格与《未来电影院》

1955年，美国电影摄影师莫顿·海利格撰写了一篇著名论文《未来电影院》，宣称“混乱 \[主宰\] 了电影行业”，各工作室“仓促转向其各自的‘革命性’系统——Cinerama、Colorama、全景屏幕、Cinemascope、三维和立体声”，这些系统被用以“吸引”顾客，承诺带来“令人兴奋的新体验”。^([38](#notes_split_003.xhtml#ch3fr38)) 更糟糕的是，海利格认为，“艺术”在利用当代技术和对人类心智的研究来使其产品更加“有效”方面，已落后于“科学”和“工业”。^([39](#notes_split_003.xhtml#ch3fr39)) 在许多情况下，艺术未能从观众那里获得“积极参与”——没有它，“就不可能有意识的转移，也就没有艺术”。^([40](#notes_split_003.xhtml#ch3fr40))

海利格的补救措施是激活人类五种主要感官中的四种（视觉、听觉、嗅觉和触觉），当代研究表明这些感官“垄断了人类的注意力”，占比99%（分别为70%、20%、5%和4%，味觉占剩余的1%）。^([41](#notes_split_003.xhtml#ch3fr41)) 由于视觉所占比例，他还主张观众的整个视野都应被屏幕填充，而非当代电影院提供的5%、宽屏电影院提供的7.5%、Cinemascope提供的18%或Cinerama提供的25%。^([42](#notes_split_003.xhtml#ch3fr42)) 理想情况下，屏幕应提供“真实而非虚假的深度……人类意识的另一个基本要素”，这将通过“电子和光学手段”实现，而非偏光眼镜的把戏，偏光眼镜最早出现于19世纪末，并在1930年代普及。^([43](#notes_split_003.xhtml#ch3fr43)) 论文发表后不久，海利格便开始着手工作。

## 1960年：望远镜面罩专利

1960年，这位从电影摄影师转型为发明家的人为“望远镜面罩”申请了专利，该设备将使观众“获得完整的现实感，即可能为彩色的移动三维图像，配备100%周边视觉、双耳立体声、香气和气流”。^([44](#notes_split_003.xhtml#ch3fr44)) 该设备与现代头戴式显示器专利惊人地相似，并支持立体（3D）和宽屏电视以及真正的立体声（尽管没有动作捕捉）。^([45](#notes_split_003.xhtml#ch3fr45))

## 1962年：Sensorama体验剧院

两年后，海利格为Sensorama申请了专利，这是一个“体验剧院”，旨在充分实现他对未来电影院的愿景。^([46](#notes_split_003.xhtml#ch3fr46)) 这一次，“设备”是一个街机大小的柜子，配备了屏幕、环绕声系统、风扇、能够再现披萨和石油等气味的气味发射器，以及一把活动椅子——所有这些都与海利格制作的电影中的特定事件同步。尽管Sensorama在揭幕后数十年间被视为奇迹，但海利格，如同路德维希教授一样，未能为其开创性设备找到支持者，并于1970年代回归传统电影制作。

## 1961年：Headsight头戴式显示器

1961年，Philco电子公司开发了第一款头戴式显示器Headsight，它为每只眼睛配备了专用屏幕，并带有一个磁性运动探测器，该探测器连接到一台随用户头部移动的外部摄像头。尽管因其外形引人注目，Headsight从未意图代表虚拟现实，而是为了让军事用户能够实时、第一人称地查看那些物理上无法进入的危险区域。^([47](#notes_split_003.xhtml#ch3fr47))

## 1965年：伊万·萨瑟兰与“终极显示器”

1965年，伊万·萨瑟兰详细阐述了“终极显示器”，这是一份至今仍在指导数十年VR研究的概念文档。萨瑟兰的目标包括创建一个逼真的合成数字世界，支持3D音效，提供触觉反馈，完全交互，并超越用户在显示器内的个人体验。此外，萨瑟兰设想这个显示器将佩戴在一个与他的虚拟世界相辅相成的物理位置，并且由同一台计算机控制。正如他所写，“在这样一个房间里显示的椅子足以坐下。在这样一个房间里显示的手铐会令人束缚。”更令人震惊的是，萨瑟兰设想“在这样一个房间里显示的子弹将是致命的”，不过，“通过适当的编程”，他主张，房间和显示器配合在一起“字面上可能是爱丽丝走进的仙境”。^([48](#notes_split_003.xhtml#ch3fr48)) 到1968年，萨瑟兰已将他的理论转化为真实的头戴式显示器，通常被称为“达摩克利斯之剑”。^([¶](#chapter3.xhtml#footnote-043)) 萨瑟兰的设备无法控制物理空间，但它被认为是第一款能够通过计算机生成图像而非仅仅中继摄像头的实时视频流或播放预录制视频的头戴式显示器。可以想象，达摩克利斯之剑没有内置计算机，而是连接到一台几乎和典型美国卧室一样大的计算机。

## 1970年代至1990年代：头戴式显示器的持续进步

在1970年代和1980年代，头戴式显示器继续进步，特别是专注于为专业飞行员和其他飞行员模拟飞行。1989年，NASA创建了项目VIEW（虚拟界面环境工作站），这是一个可以显示“人工计算机生成的环境或从远程视频摄像头中继的真实环境”的头戴式显示器。^([49](#notes_split_003.xhtml#ch3fr49)) 除了显示器，操作员还会佩戴“数据手套”，它使用光纤电缆和传感器，可以在VIEW中复现他们的手，还有一个同样功能的“数据服”，也被编程为理解手势。^([50](#notes_split_003.xhtml#ch3fr50)) 1990年代，任天堂和Sego都发布了VR头显和手套，但都未取得成功。
