> 认为元宇宙主要是 AR/VR 事物的假设并不疯狂。在我的书 \[`Snow Crash`\] 中，一切都是 VR。而且我曾为一家 AR 公司 \[`Magic Leap`\] 工作——这是几家正在投入数十亿美元打造头显的公司之一。但我在写作 `Snow Crash` 时并未预见到视频游戏的到来。……多亏了游戏，数十亿人现在都能在平面 2D 屏幕上舒适地导航 3D 环境。他们掌握的 UI \[`keyboard` 和 `mouse` 用于导航和相机\] 并非大多数科幻作家所预测的那样。但这正是技术路径依赖的运作方式。我们使用为机械打字机设计的键盘，流畅地导航和交互于极其丰富的 3D 环境。这是蒸汽朋克变成现实。一个抛弃了那些用户以及构建这些体验的 \[`developers`\] 的元宇宙，将开局就错了。……我的预期是，大量元宇宙内容将为屏幕构建（因为市场在那里），同时为未来可负担头显的增长保持选择的开放性。^([10](#notes_split_002.xhtml#ch2fr10))

### 错误 #3：将元宇宙与 `Fortnite`、`Minecraft` 或 `Roblox` 等视频游戏平台混淆

与 AR/VR 类似，这个错误是可以理解的。2024 年几乎所有顶级热门多人视频游戏都是共享的、实时的且为 3D 的，并且都拥有某种形式的内部商品经济。除了这些属性之外，`Fortnite`、`Minecraft` 和 `Roblox` 各自运营着数千万个虚拟世界的网络，所有这些世界都由一个广泛的技术套件支撑，涵盖身份、虚拟形象、虚拟货币和通信，可以通过几乎每个主流计算设备全球访问，既用于工作也用于娱乐，并且拥有数百万个贡献者，作为其数十亿美元经济的一部分支持数亿用户。

尽管元宇宙与这些平台之间存在结构相似性，但将前者描述为后者，就好比说 Facebook 是万维网。是的，Facebook 是一个庞大的、与设备无关的平台，横跨数十亿个互联页面，具有标准化的标识符（账户而非 IP 地址）、格式、惯例等等。对于某些用户来说，Facebook 是他们在互联网上所做的大部分事情。然而，Facebook 仅占整个互联网的一小部分，主要以休闲为中心，并且与实际的互联网协议完全分离。`Roblox`、`Minecraft` 和 `Fortnite` 很可能是元宇宙的一部分，与其很相似，并开创其一些标准和用户行为，但它们并不是元宇宙，更不用说是元宇宙了。

### 错误 #4：将元宇宙与 Web3、区块链、加密货币或 NFT 混淆

本书的一个反复主题是，要完全区分各种技术时代、浪潮或模式是困难的。尽管如此，技术专家、社会学家和投资者通常会区分互联网的早期阶段，即所谓的“Web 1.0”，它始于 1989 年万维网的创建，以及“Web 2.0”，它始于 2004 年或 2005 年左右，在 Facebook 和 YouTube 推出之后。Web 1.0 和 Web 2.0 可以大致从内容、用户活动、平台的作用以及所使用的技术方面进行区分。

在 Web 1.0 时代，内容并不严格局限于文本，但由于宽带速度和计算机处理能力的限制，图像稀少且分辨率低，音频通常仅以片段和低质量形式提供，视频难以找到且更难观看。内容创建者通常将这些内容托管在他们自己拥有的服务器上，这些服务器运行着诸如 `Linux` 之类的开源操作系统。内容本身通常使用常见标准（例如，`JPEG`、`GIF`、`JavaScript`、`HTML`）生成或显示，并通过开放平台（万维网、网络浏览器、`Microsoft Windows`、电子邮件协议等）分发。尽管 Web 1.0 时代是大多数人首次能够广泛分发其内容——且无需经过出版商、制作商、零售商等中介——但在 Web 1.0 期间，几乎没有互联网用户创建内容。他们只是消费内容。

在 Web 2.0 期间，创建、分发和访问高质量媒体格式（包括实时视频和交互式媒体）变得普遍。数十亿用户还建立了基于互联网的综合身份（例如，`Facebook` 账户），以及他们自己的基于互联网的网络（例如，在 `Facebook` 上添加朋友）。云数据中心的出现意味着开发者或用户可以轻松雇佣 `Amazon` 或 `Microsoft` 等公司来托管和管理其网站或应用，而不是购买、设置和维护自己的服务器。`Apple`、`Google` 和 `Facebook` 等技术公司，使个人更容易创建、发现、分享或变现一段内容、页面、应用程序等等。这些诸多进步导致在线创作激增。与 Web 1.0 时代只是浏览互联网不同，Web 2.0 互联网的几乎所有用户也都为互联网做出贡献。这些贡献中的一些只是偶尔的社交媒体帖子，但数百万独立开发者和创作者现在通过他们的社交媒体页面、视频频道、应用程序和网站谋生，而数百万更多人则在数字“零工经济”中工作。

尽管有这些好处，但科技界的许多人担心 Web 2.0 的潜在权衡：虽然更加繁荣和参与性，但它也变得更加封闭和私有化。身份和网络不是建立在 `TCP/IP`（例如，`email` 或 `IP addresses`）或其他开放协议上，而是建立在私有数据库和系统上（例如，`Facebook` 登录）。如果开发者将网站发布到万维网，他们可以自由地将其从一个主机转移到另一个主机，更改域名，或将客户和邮件列表转移到不同的提供商，但在 `Facebook` 或 `YouTube` 上，用户的大部分内容、身份和粉丝都被卡住了。主要的移动操作系统也规定了可以分发哪些类型的应用程序、使用哪些技术，以及通过哪些商业模式变现——并且还抽取应用程序数字收入的 15%–30%。尽管名义上仍然是“开放”的，但万维网受到网络浏览器的中介，这些浏览器也受到移动操作系统（即 `iOS` 和 `Android`）的严格控制；一个拥有 95% 市场份额并渴望培育其生态系统、收集数据和出售广告的搜索引擎（`Google`）；以及更加不透明的算法社交信息流，代表了数十亿用户在线上花费的大部分时间（`Facebook`、`Twitter`、`TikTok` 等）。

Web3 的总体目标是继续扩大和丰富互联网的贡献者数量，同时将互联网归还其创立时的去中心化原则，并减少大型科技平台和聚合者的权力。预期的结果将是一个更“健康”的互联网，它赋予个人用户更多权利，为独立开发者提供更多利润，并减少通常位于用户和开发者之间的各种大型科技平台的影响和控制。
