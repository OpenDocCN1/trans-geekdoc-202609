

# 模拟存在理念中最重要的贡献之一来自非虚构作品

模拟存在理念中最重要的贡献之一来自非虚构作品。1981年，法国哲学家和文化理论家让·鲍德里亚在其开创性论著《拟像与仿真》中创造了“超现实”一词。鲍德里亚将超现实描述为一种状态，在这种状态下，现实与模拟被如此无缝地融合，以至于难以区分（正如温鲍姆曾想象的那样）。尽管许多人认为这一想法令人恐惧，但鲍德里亚认为重要的是个人将从何处获得更多意义和价值——并推测这将是在模拟世界中。^([17](#notes_split_001.xhtml#ch1fr17)) 虽然腾讯在揭示其“超数字现实”元宇宙愿景时未提及鲍德里亚，但这一引用很快就被注意到了。

鲍德里亚出版《拟像与仿真》的同年，科幻小说家威廉·吉布森首次朗读了他的短篇小说《燃烧的铬》，随后将其扩展为1984年著名的小说《神经漫游者》。这两部作品普及了“赛博空间”一词，该词自20世纪60年代末就已存在，但此前未与任何数字技术相关联。在《神经漫游者》中，吉布森将赛博空间定义为“数十亿合法操作员每天经历的一种共识性幻觉，遍布每个国家……一种从人体系统中每台计算机的数据库中抽象出来的数据的图形化表现。难以想象的复杂性。心智非空间中排列的光线，数据的簇和星座。如同城市灯光，渐渐远去。”^([18](#notes_split_001.xhtml#ch1fr18)) 小说早期，黑客亨利·凯斯因盗窃受雇主毒害作为惩罚，真菌毒素严重损害了他的神经系统，以至于他无法再连接到赛博空间。“对于凯斯，”吉布森写道，“他曾为赛博空间的无肉体狂喜而活，并对肉体产生了一种‘放松的满足’，他的身体现在成了一座牢笼。”^([19](#notes_split_001.xhtml#ch1fr19)) 1991年，当被问及鲍德里亚对《神经漫游者》的影响时，吉布森说“他是个酷的科幻作家。”^([20](#notes_split_001.xhtml#ch1fr20))

鲍德里亚和吉布森创作之时，华特迪士尼公司正在制作家庭级长片《电子世界争霸战》，该片于1982年上映，由史蒂文·里斯伯格和邦妮·麦克伯德编剧，里斯伯格还担任导演。《电子世界争霸战》聚焦凯文·弗林，由杰夫·布里奇斯饰演，他是一名视频游戏开发者，其心智和身体意外上传到他创建的虚拟游戏世界中。在被困在自己的世界中，弗林被迫进行生死搏斗的角斗士式战斗，并发现了有感知的生命以及一个开始挪用现实世界基础设施和程序以变得更强大的AI独裁者。

尽管弗林获胜，但他最终被困在“网格”中30年，使年幼的儿子失去了父亲。《电子世界争霸战》是最早大量使用计算机动画的电影之一，整个场景完全由数字地形、物体和事件组成，或者布里奇斯和少数几个实物物品叠加在其虚拟世界之上。该片最终获得第55届奥斯卡金像奖最佳服装设计和最佳音响奖提名，但在最佳视觉效果类别中被忽略。^([††](#chapter1.xhtml#footnote-052)) 2010年，执导当年《电子世界争霸战》续集《电子世界争霸战：继承者》的约瑟夫·科辛斯基告诉《名利场》杂志：“一个有趣的讽刺是，原版《电子世界争霸战》被取消了视觉效果类别的资格……因为\[电影艺术与科学学院成员\]认为使用计算机是作弊。这部电影超前于时代；其中的想法也超前于时代。虚拟头像的概念，一个存在于在线世界中的你自己的个性，在那个时候非常独特——那是人们当时无法完全理解但现在已成为理所当然的事情。”^([21](#notes_split_001.xhtml#ch1fr21))

《雪崩》最初设想于1989年作为图像小说，最终（且专属地）于1992年以小说形式出版。在随后的岁月里，许多人继续发展其主题。其中一个例子是1999年的电影《黑客帝国》，该片是当年全球第四高票房的电影。《黑客帝国》取名自《神经漫游者》，后者曾将赛博空间的视觉抽象称为矩阵。在由拉娜·沃卓斯基和莉莉·沃卓斯基编剧并执导的这部电影中，“矩阵”指的是对1999年地球的持续模拟，但运行于2199年。这种模拟的目的是让被囚禁和丧失能力的人类种族的头脑保持平静，以便他们的身体可以被征服了这颗星球的有感知但人造的机器用作生物电池。在沃卓斯基姐妹的原始拍摄剧本中，墨菲斯在最近“唤醒”主角尼奥脱离矩阵后，解释道“正如鲍德里亚的愿景，你的一生都在图像中度过，而不是疆域中。”^([22](#notes_split_001.xhtml#ch1fr22)) 这句话未能进入最终剪辑，尽管电影保留了一个镜头，尼奥拿起一本被挖空^([‡‡](#chapter1.xhtml#footnote-051)) 的《拟像与仿真》副本，以便更好地隐藏他（非法）黑客程序的硬盘。^([23](#notes_split_001.xhtml#ch1fr23))

另一个著名的例子出现在2011年，欧内斯特·克莱恩的《头号玩家》出版，这是一本融合了流行文化的《雪崩》版本。设定在2040年代，《头号玩家》的“现实世界”遭受着各种生态、社会经济和能源相关的危机。与吉布森和斯蒂芬森不同，克莱恩想象大部分人类已避难在他设想的“元宇宙”中，他称之为OASIS。与元宇宙一样，OASIS是一种通过VR头显和各种触觉外设组合访问的、往往充满奇幻色彩的现实数字模拟，并且运行在一种与现实世界货币同样有价值——或许更稳定——的货币上。本书的叙事涉及在所有者詹姆斯·哈里戴去世后为控制价值数万亿美元的OASIS而进行的斗争，并防止其落入IOI首席执行官诺兰·索伦托手中，IOI在OASIS内调集了看似无限数量的人类劳动者。全球电影制片公司华纳兄弟在《头号玩家》出版前一年就购买了其改编权，由史蒂文·斯皮尔伯格执导了2018年的改编版。

## 任何其他名称的元宇宙

没有答案可以说明为什么斯蒂芬森的“元宇宙”一词流行起来，而其他同样流行、有影响力和预言性的小说中的术语却没有。也许“赛博空间”在20世纪90年代首次进入流行文化词汇时，流行得太早而无法持久。虽然《电子世界争霸战》是一部邪典经典，但远非突破性的成功，限制了“网格”的影响。“矩阵”可能因沃卓斯基姐妹热门电影的R级主题以及消费者导向品牌对该术语的某种矛盾接受而受到污染（2002年，《黑客帝院》上映三年后，丰田推出了Matrix紧凑型掀背车，并生产了十多年）。“超现实”可能过于晦涩和抽象，而“OASIS”则太新。而且，目前尚不清楚——而且可能不太可能——“元宇宙”一词会持久，即使Facebook的新名称会。
