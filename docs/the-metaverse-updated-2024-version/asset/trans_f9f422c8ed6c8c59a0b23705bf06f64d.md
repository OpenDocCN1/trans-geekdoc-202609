

# 元宇宙误解的根源

元宇宙误解的根源在于一个简单的事实：该术语的创造者从未对其进行定义。“元宇宙”一词首次出现并非在计算机科学杂志、技术示意图，甚至不是商业计划书中，而是出现在1992年由尼尔·斯蒂芬森（Neal Stephenson）撰写的科幻小说《雪崩》（*Snow Crash*）中。尽管《雪崩》中的大部分情节发生在或涉及“元宇宙”，但它从未被具体解释，仅被描述——而且是从小说主人公（一名兼职黑客兼兼职为黑手党送披萨的人）的视角来描述的。

这个讽刺性命名的主人公（Hiro Protagonist）所描述的是一个持久的三维虚拟世界，它触及、与之互动并影响着人类存在的几乎每一个部分以及物理世界的大部分。它是一个用于劳动与休闲、自我实现与身体疲惫、艺术与商业并存的地方。用户主要通过虚拟现实和增强现实眼镜与元宇宙交互，此外还使用二维黑白显示器（即传统的计算机显示器），以第一人称视角体验它，并由不必与现实自我相似的虚拟形象（avatars）来代表。总的来说，斯蒂芬森小说中的元宇宙面积超过地球的2.5倍，且没有预定义的海洋或湖泊，因此形成了一个可用房地产面积超过地球8.5倍的星系。横跨整个星系的是“街道”（the Street），一条斯蒂芬森称之为“元宇宙的百老汇、香榭丽舍大街”的一百米宽道路。^([1](#notes_split_001.xhtml#ch1fr1)) 任何给定时间，街道上大约有1500万个由人类控制的虚拟形象，而“地球上最富有、最时髦、关系最广泛的一亿左右的人”会“终生每天”访问这里。^([2](#notes_split_001.xhtml#ch1fr2)) 作为对比，斯蒂芬森小说出版那一年，现实世界中的互联网总用户不足七百万，而在他开始写作时不足一百万。直到1998年，《雪崩》出版后六年，互联网才达到一亿活跃用户总数，直到下一个十年才出现一亿每日互联网用户。

## 斯蒂芬森的反乌托邦愿景

尽管斯蒂芬森的愿景生动，并且对许多人来说鼓舞人心，但它也是反乌托邦的。《雪崩》设定在21世纪初，全球经济崩溃数年后。大多数政府层级已被以盈利为目的的“特许组织准国家实体”和“郊区飞地”（burbclaves，即“suburban enclaves”的缩写）所取代。每个郊区飞地作为一个“拥有自己的宪法、边界、法律、警察、一切的城市国家”运作，^([3](#notes_split_001.xhtml#ch1fr3)) 有些甚至仅基于种族提供“公民身份”。

斯蒂芬森从未暗示元宇宙的出现导致了上述崩溃，但他确实暗示元宇宙恶化了周围的世界。是的，斯蒂芬森的元宇宙为数百万人提供了机会和逃避——它是一个“现实世界”中的零工可以成为拥有内部通道进入最热门俱乐部的天才剑客的地方——但读者留下的无疑是一种感觉：它导致进一步脱离现实世界的问题。此外，元宇宙的技术要求如此之高，以至最多只有16%的人能负担得起足以访问它的强大计算设备，更可能的是，不到二十分之一的人能做到。换句话说，元宇宙近一亿每日用户几乎都是经济或社会精英的成员。^([4](#notes_split_001.xhtml#ch1fr4)) 有些元宇宙用户选择将几乎所有清醒的时间都花在元宇宙中，将自己困在便携终端、眼镜和其他使他们随时保持连接的配件中。斯蒂芬森称这些人为“石像鬼”（gargoyles）（其中没有一人被单独命名），并写道“他们看起来毫无愚蠢之处”，他们“本质上是粗鲁的”，“令人尴尬”，“没人愿意和他们说话”，因为他们只是“假装在交谈”。^([5](#notes_split_001.xhtml#ch1fr5)) 那么，数十亿不去元宇宙的人呢？“他们中的大多数人正在制作泥砖或拆解他们的AK-47步枪。”

元宇宙本身由难以捉摸（且极其富有）的“全球多媒体协议组织”（Global Multimedia Protocols Group）管理，该组织拥有元宇宙的所有底层虚拟土地，以及使其得以存在的机器。与大多数全球通信技术一样，对元宇宙的访问由神秘的L. Bob Rife控制，许多读者认为他是对山达基教创始人L. Ron Hubbard的戏仿。

## 斯蒂芬森对技术和行业的影响

尽管斯蒂芬森从未渴望塑造全球政策或技术，但他的影响，如同万尼瓦·布什（Vannevar Bush）一样，随着时间的推移而不断增长——即使他目前且很可能长期大多不为公众所知。^([\*](#chapter1.xhtml#footnote-059)) 与斯蒂芬森的交谈帮助杰夫·贝索斯（Jeff Bezos）于2000年创立了私营航空航天制造商和亚轨道太空飞行公司蓝色起源（Blue Origin）（斯蒂芬森也是该公司的第一位员工，并在四分之一世纪后仍担任高级顾问）。截至2023年，蓝色起源是世界上第二有价值的私营航空航天公司——仅次于埃隆·马斯克（Elon Musk）的SpaceX。Keyhole的三位创始人中有两人表示，他们的愿景受到（或受到^([6](#notes_split_001.xhtml#ch1fr6))）启发，源自《雪崩》中描述的类似产品，并且他们曾试图招募斯蒂芬森加入公司（报道不一，这是作为顾问还是仅仅作为客座人员）。^([7](#notes_split_001.xhtml#ch1fr7)) 从2014年到2020年，斯蒂芬森也是魔影科技（Magic Leap）的“首席未来学家”，该公司被广泛认为是第一家寻求构建能够实现斯蒂芬森元宇宙的增强现实和虚拟现实设备的高知名度初创公司。到2021年，魔影科技已从谷歌、阿里巴巴、AT&T以及沙特阿拉伯主权财富 fund 等机构筹集了超过70亿美元，后者在2022年底收购了该公司的大部分股份。

## 文学影响与相关作品

斯蒂芬森的作品也被引用为数十个从未出现在《雪崩》中的项目和技术的灵感来源。在《雪崩》之后的七年里，有两部特别著名的小说问世。1995年出版的《钻石时代》（*Diamond Age*）设定在一个被纳米技术彻底改变的世界，运行在一个“可以匿名转移资金的\[数字\]全球网络”上，^([8](#notes_split_001.xhtml#ch1fr8)) 并围绕那些在虚拟世界中相遇，在许多情况下只知道彼此虚构身份的角色展开。然而，《钻石时代》的关键技术是一本交互式书籍（“ractive”），它利用可能相距数万公里的表演者的身体动作和语音，生成实时的CGI电影、电视剧和教学课程。直到2002年，电影《指环王：双塔奇兵》才在创建CGI角色的仍然手动过程中，实时捕捉了表演者的动作。

斯蒂芬森1999年的小说《密码学》（*Cryptonomicon》）讲述了加密货币、加密程序执行以及货币如何储存价值的故事，还讲述了由超高容量海底互联网电缆驱动的离岸数据避风港的建立。第一个主流加密货币比特币，在《密码学》出版十年后才问世。
