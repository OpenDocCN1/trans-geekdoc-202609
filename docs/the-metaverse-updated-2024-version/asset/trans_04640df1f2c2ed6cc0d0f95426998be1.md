

# 元宇宙的形成将帮助监管机构迫使主要操作系统解绑其技术栈

尽管如此，拥有这些操作系统和生态系统的公司仍将蓬勃发展，因为其解绑后的产品仍然是市场领先的，而元宇宙的出现将增加这些市场的规模和重要性。总体而言，元宇宙的结构很可能类似于当今的数字世界——少数水平和垂直整合的公司将控制数字经济的相当大份额，其影响力甚至更大。无论元宇宙是建立在集中式还是去中心化技术之上，这种结果都可能发生。万维网的基础几乎全部是去中心化的——它在人们用来访问网络的设备是“开放”的时代（例如 Windows、Mac 和 Linux PC）中迅速普及。即便如此，在 1990 年代和 2000 年代，消费者对互联网的使用迅速集中在微软、谷歌和 Facebook 的生态系统中。有许多非技术性反馈回路会集中权力，例如品牌和知识产权、用户习惯、数据中心投资、商业合作伙伴关系和姐妹产品、利润率等等。元宇宙的关键关注点不在于集中化或去中心化谁“获胜”——两者都无法获胜——而在于它处于光谱的哪个位置，以及这种位置如何随时间变化。而在这一点上，我抱有希望。

# 无论人们如何看待加密货币，对更好的用户权利和开放性都有明确的需求

元宇宙的许多早期领导者正在回应这一愿望。当马克·扎克伯格于 2021 年 10 月宣布其元宇宙战略时，他还宣布终止了一项要求 Quest 用户拥有 Facebook 账户的为期一年的政策^([7](#notes_split_012.xhtml#confr7))，并承诺支持 WebXR（一种用于基于浏览器的 AR 和 VR 应用的开源 API 集合）和 OpenXR（一种用于已安装 AR 和 VR 应用的开源 API 集合），而不是强制使用其专有替代方案。^([8](#notes_split_012.xhtml#confr8)) 扎克伯格还表示，Quest 设备将继续允许用户直接安装应用，包括第三方应用商店，并且开发者将能够选择自己的应用内支付解决方案。^([9](#notes_split_012.xhtml#confr9)) 几周后，Facebook 开放了十年前关闭的许多 API，包括那些允许用户将 Instagram 照片跨发布到 Twitter 和其他社交网络的 API。^([10](#notes_split_012.xhtml#confr10)) 在宣布收购动视暴雪一个月后，微软推出了针对其 Windows 操作系统的新 14 点政策平台，以及公司为游戏构建的“下一代市场”。这包括承诺支持第三方支付解决方案和应用商店（并且不处罚选择使用它们的开发者），用户有权将这些替代方案设置为默认选项，开发者有权直接与最终用户沟通（即使沟通的目的是告诉用户，通过绕过微软的商店或服务套件可以获得更好的价格或服务），以及微软“承诺”将这些相同的原则带到其 Xbox 游戏机（尽管未提供详细信息或时间表）。Epic Games 的生态系统和雄心仍在发展中，但其控制仍然很少，其承诺在很大程度上得到了履行，尽管成本高昂。

可以公平地认为，Facebook、微软、Epic 以及许多区块链生态系统的支持者之所以喜欢开放性，是因为他们受制于封闭的竞争对手。如果这些公司或其领导人控制着 iOS 或 Android，或者受这些平台的影响较小，他们可能会持有不同的观点。目前对开放性的支持是否能持续，也未可知。在离开 Facebook 之前，约翰·卡马克承认，Facebook 不得不提高 Quest 2 的价格，因为该设备上最受欢迎的游戏是免费游玩的作品，很少实现变现，并且由独立开发者制作。^([11](#notes_split_012.xhtml#confr11)) 当微软承诺开放 Xbox 时，它没有提供路线图或时间表，承认其商业模式目前无法支持这一点，也没有对如何实现进行探讨。Epic 提供的每一项免费服务，其事实上的控制力可能就增长一次。在 2021 年 Epic 与 Apple 的审判中，法官 Yvonne Gonzalez Rogers 似乎对 Epic 的许多论点表示同情，但也宣称：“说清楚点。Epic 之所以在这里，是因为如果获得救济，它可能将一家数十亿美元的公司变成一家数万亿美元的公司。他们并非出于好心才这么做。”^([12](#notes_split_012.xhtml#confr12))

# 元宇宙将加剧当今互联网面临的许多社会挑战

这些问题不仅会加剧，过去 20 年学到的经验也不一定总是适用。审核异步文本与实时且带有触觉集成的 3D 手势截然不同。当伊斯兰国（也称为 ISIS/ISIL）在 2000 年代中期开始使用社交媒体时，该恐怖组织希望激进化全球的穆斯林，然后招募他们前往中东部分地区接受训练。作为回应，世界各国政府限制了外国人甚至本国公民在访问各种“热点”后进入其国家的能力。当候选人通过在去中心化网络上运行的沉浸式平台接受训练时，这种方法不再适用。而且，Alexa 监听关键词触发器，远不如光学 AR 眼镜扫描、消化和模拟周围现实世界那样具有侵入性。

# 我相对较少担心虚拟孤立

这并非赞成花更多时间待在室内而少在外面活动，而是认识到我们目前如何花费时间。包括小睡和失眠发作，根据劳工统计局的数据，18 岁以上的平均每个美国人每天睡眠 8.7 小时，工作 5.6 小时。^([13](#notes_split_012.xhtml#confr13)) 在剩下的 9.7 个清醒小时中，超过一半（或总共 5-5.5 小时）用于观看电视、电影和在线用户生成视频。^([14](#notes_split_012.xhtml#confr14)) 其中一些时间用于多任务处理——观众在做饭、在跑步机上、照看孩子或上网冲浪——但至少三分之二的观看是在没有此类干扰的情况下进行的。^([15](#notes_split_012.xhtml#confr15)) 总观看时间的 60% 也是独自完成的，^([16](#notes_split_012.xhtml#confr16)) 并且近 90% 的观看是在久坐状态下进行的。^([17](#notes_split_012.xhtml#confr17)) 将其中任何时间转移到社交、互动且更具参与感的娱乐中，很可能是积极的结果，而不是消极的结果，即使我们都仍然在室内。这对于老年人尤其如此。美国的平均老年人每天花 7.5 小时看电视。我们中很少有人梦想退休并长寿，只是为了把剩下的每一天的一半时间花在看电视上。元宇宙可能无法替代在加勒比海亲自航行，但与老朋友一起驾驶一艘虚拟帆船，很可能会胜过中午的有线新闻，并且也有其自身的好处。
