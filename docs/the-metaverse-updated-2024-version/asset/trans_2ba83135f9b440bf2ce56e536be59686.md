

正是在这里，发电机类比开始失效。在大多数发达国家，家庭无需担心是否能获得所需电力，以及能否尽快获得。数据却并非如此。正如 [第 5 章](#chapter5.xhtml) 所回顾的，现代视频游戏每小时仅发送 30–300 MB 数据，许多用户无法可靠地及时接收这些数据。一款 2K 分辨率、每秒 60 帧的云端流式视频游戏每小时需 10 GB 数据，许多玩家期望 4K 分辨率和每秒 120 帧（或每小时 40 GB）；而 VR 和 VR 头显的需求则更高。^([12](#notes_split_006.xhtml#ch6fr12))

此外，远程计算尚未证明其在渲染方面更高效，在许多情况下，一般处理也是如此。这是几个相互关联问题的结果。首先，GPU 在任何给定时刻都不会渲染整个虚拟世界，甚至也不会渲染其中的大部分。相反，它只渲染给定用户在需要时所需的内容。当玩家在《塞尔达传说：荒野之息》等游戏中转身时，任天堂 Switch 的 Nvidia GPU 会有效卸载之前渲染的所有内容，以支持玩家的新视野。此过程称为“视锥剔除”。其他技术包括“遮挡”，即如果玩家视野中的物体被另一个物体遮挡，则不会加载/渲染这些物体；以及“细节层次”（LOD），即诸如桦树树皮的细腻纹理等信息，仅在玩家能够看到时才会被渲染。

剔除、遮挡和 LOD 解决方案对于实时渲染体验至关重要，因为它们使用户设备能够将处理能力集中在用户可见的内容上。但因此，其他用户无法“搭便车”利用一名玩家 GPU 的工作。一些读者可能认为这是谎言，回忆起在任天堂 64 上玩《马里奥赛车》的许多小时，该游戏允许玩家将电视屏幕“分割”为四个部分，每个车手一个。即使在今天，《堡垒之夜》也允许单台 PlayStation 或 Xbox 将屏幕一分为二，以便两名玩家同时游玩。但在这种情况下，相关 GPU 是为多个参与者（而非用户）支持同时渲染。这里的区别至关重要。每个玩家必须进入同一场比赛和同一关卡，并且不能提前离开。这是因为设备的处理器只能加载和管理有限数量的信息，其随机存取存储器系统会暂时存储各种渲染内容（例如，一棵树或一座建筑），以便每个玩家可以持续重复使用，而不是每次都从头开始渲染。每个玩家的分辨率和/或帧率也会按用户数量的比例下降。这意味着，即使使用两台电视来运行双人《马里奥赛车》，而不是将一台电视一分为二，每个玩家每秒接收的渲染像素也只有原来的一半。^([†](#chapter6.xhtml#footnote-030))

从技术上讲，GPU 渲染两个完全不同的游戏是可能的。顶级 Nvidia GPU 当然可以支持两个不同的 2D 横向卷轴《超级马里奥兄弟》模拟，或者一个版本的《超级马里奥兄弟》和另一个同样低功耗的游戏。但这并非以计算高效的方式完成。一台可能以最高渲染规格运行高端游戏 A 的 Nvidia GPU，无法以一半规格运行该游戏的两个版本——甚至连第三个都不行。它也无法像父母帮助两个孩子学习或上床睡觉一样，根据游戏的需求和时间在两个游戏之间分配其算力。即使游戏 A 永远无法使用给定 Nvidia GPU 的全部算力，这部分闲置算力也无法分配到其他地方。

GPU 不会生成可像发电厂将电力分配给多个家庭，或像 CPU 服务器为百人大逃杀游戏中的一百名玩家提供输入、位置和同步数据那样，在用户之间分配的通用渲染“算力”。相反，GPU 通常作为“锁定实例”运行，支持单个玩家的渲染。许多公司正在尝试解决高效的 GPU 分割问题，但在实现之前，设计类似于大型工业发电机、涡轮机或其他基础设施的“超级 GPU”并没有固有的效率。虽然发电机通常随着容量增加，每单位电力的成本更低，但 GPU 的情况恰恰相反。简化来说，算力是另一台 GPU 两倍的 GPU，其生产成本超过两倍。

“分割”或“共享”GPU 的困难解释了为什么微软 Xbox 的云游戏流式服务器农场实际上由一排又一排的拆壳 Xbox 组成，每台服务一名玩家。换句话说，微软的发电厂实际上只是一系列单户发电机的网络，而不是一个社区规模的发电机。微软可以使用定制的 GPU 和 CPU 硬件来支持云实例，而不是其面向消费者的 Xbox 中的 GPU 和 CPU 硬件，但这将要求每款 Xbox 游戏都开发以支持额外的“类型”Xbox。

云渲染服务器也面临利用率问题。云游戏服务可能在周日晚上 8 点需要克利夫兰地区 75,000 台专用服务器，但平均仅需 20,000 台，周一凌晨 4 点仅需 4,000 台。当消费者以游戏机或游戏 PC 的形式拥有这些服务器时，它们是否未使用或离线并不重要。相反，数据中心经济学基于优化需求。因此，租用利用率低的高端 GPU 始终是昂贵的。

这就是为什么亚马逊网络服务如果客户提前从亚马逊租用服务器（“预留实例”），会给予客户较低费率。客户保证在未来一年内可以访问，因为他们已支付服务器费用，而亚马逊则赚取成本与向客户收取的价格之间的差额（2021 年，AWS 最便宜的 Linux GPU 预留实例，相当于当时顶级的 PlayStation，一年费用超过 2,000 美元）。如果客户想在需要时访问服务器（“即席实例”），可能会发现服务器不可用，或者只有较低端的 GPU 可用。这一点至关重要：如果使远程服务器负担得起的唯一方法是使用较旧、性能较差的设备，而不是更换它们，那么计算短缺就无法解决。

改进成本模型的另一种方法是将服务器整合到更少的地点。与其在俄亥俄州、华盛顿州、伊利诺伊州和纽约州分别运营独立的云游戏流式中心，不如公司只建一两个全国性中心。随着客户数量和多样性的增加，需求趋于稳定，从而带来更高的平均利用率。但集中数据中心也意味着增加远程 GPU 与最终用户之间的距离，从而增加延迟。这就是所谓“边缘计算”的核心挑战——一种云计算模型，使用更多靠近最终用户的小型数据中心，而不是远离普通用户的大型数据中心——延迟和利用率将永远相互竞争。内容分发网络和云网络安全巨头 Cloudflare 的创始人 Matthew Prince 认为，边缘数据中心的主要作用不是以更高成本换取最小化传输时间，而是合规性。^([13](#notes_split_006.xhtml#ch6fr13)) 在许多国家，尤其是欧洲国家，政府要求消费者数据在国内存储，并禁止将此数据日常转移到国外服务器。结果是，边缘计算有时是以云为中心的处理和渲染策略的要求。
