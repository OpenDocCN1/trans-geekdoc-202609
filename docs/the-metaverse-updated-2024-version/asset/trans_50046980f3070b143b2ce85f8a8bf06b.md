虽然 Blur 常被归咎于 NFT 版税的终结，但其与 OpenSea 的争斗掩盖了其他真相。首先，没有一致的证据表明 `dapp` 对 `dapp` 的竞争总是对市场有利。为此，值得注意的是，“dapp”中的 `d` 源于它们运行在去中心化网络这一事实，而非其所有权结构是去中心化的。在大多数情况下，`dapp` 的创始人或创始团队会持有大量 `dapp` 代币，出于自然信念认为 `dapp` 将成功，其代币因此会增值。因此，这些个人可能有能力随意更改 `dapp`，或至少在其长期发展中发挥强大（且可能具有阻断作用）的作用。

关于 NFT 版税的争论也揭示了不可变性的局限性和人类商业的现实。NFT 可以被更新以禁止各种市场或交易，这证明其备受吹捧的基于代码的所有权权利比人们想象的要少，即使使用去中心化记录，客户也受制于中心化实体。这个问题有潜在的解决方案，但没有一个令人羡慕。第一个要求 NFT 铸造时没有更新（或“升级”）的功能。这种功能已经存在多年，但由于永久性的成本，很少被采用。例如，如果 NBA Top Shot 无法修改，那么捕捉到迈克尔·乔丹扣篮 2D 版本的时刻永远无法升级到 VR——只有新的 NFT 才能提供这种体验。同样，这个 NFT 也永远无法通过使用进行转换，或修改以解锁产品、体验或任何其他在铸造时尚未想象的功能。现在，这个“锁定” NFT 的所有者可以获得一个新 NFT，它基于原始 NFT 的所有权提供上述功能，但本质上是同样的问题：核心 NFT 的实用性和价值取决于中心化实体的行为。

版税强制执行面临类似的挑战。虽然市场最终可能会采用一个强制执行版税的新 NFT 标准，但变通方法总会存在。用户可以以 10 美元的价格出售价值 100 万美元的 NFT（这将产生 5 万美元的版税），以换取 999,990 美元的转账。虽然这使买家面临风险，但双方可以编写一个 `smart contract`，或成立一个 `DAO`，以达到同样的效果。

正如 `Sandbox` 和其他项目所展示的，NFT 的使用权（因此也是其价值）可能始终会被原始权利所有者修改、限制或以其他方式影响，无论是非营利性 `DAO`、营利性 Web 2.0 公司，还是 Web3 公司。同样，拥有 NBA Top Shots NFT 并不会自动赋予独立开发者将这些 NFT 纳入制作 NBA 游戏的权利（就像购买迪士尼实体服装并不赋予买家制作以钢铁侠或艾莎为主角或出现的商业电影的权利）。

所谓“真正所有权”的局限性是广泛的。`Sandbox` 的服务条款规定：“通过使用服务，您授予 TSB 一项全球性的、非独家的、免版税的、永久的、不可撤销的、可再许可的（通过多个层级）、可转让的权利和许可，用于使用、复制、公开展示、分发和改编公开共享的资产和游戏，以开发、分发、提供、改进和推广服务、我们的活动以及您公开共享的资产和游戏。您还授予 TSB 在使用您公开共享的资产和游戏时使用您的姓名和商标（如有）的权利。”简而言之，用户可能“拥有”与 `Sandbox` 项目相关的代币，但这种所有权要求用户向 `Sandbox` 提供实际上无限（且可更改）的权利，包括复制物品和宣传其“所有者”的权利，且无需付费。^([87](#notes_split_011.xhtml#ch11fr87))

加密乐观主义者认为，随着时间的推移，市场将奖励那些完全去中心化其所有权结构、向用户提供最大权利并表现出最佳行为的公司，迫使 Web 2.0 运营商转型和/或完全退出市场。这可能仍会发生。然而，目前，这些力量似乎并未发挥作用。相反，各种个人、企业和组织在法律下运作——因此有服务条款和政府注册——这对部分去中心化的目的提出了质疑。每年通过更高效且同样依赖法律进行执行的中心化数据库交换着数万亿美元的价值。
