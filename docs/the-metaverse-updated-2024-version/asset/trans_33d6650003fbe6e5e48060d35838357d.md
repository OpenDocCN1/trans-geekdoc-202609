

从身份开始。要使用 Web 2.0 应用程序，用户通常必须注册由该应用程序运营的账户，或者连接由另一个 Web 2.0 应用程序（例如 Facebook 或 Gmail）运营的账户。相比之下，Web3 用户将其加密钱包（由区块链运营且完全由用户控制）连接到 `dapp`。用户的资产（图片和视频）、社交图谱和数据（交易历史）也将存储在“链上”，用户控制这些信息何时以及如何向特定 `dapp` 公开。此外，用户与 `dapp` 的大部分交互也将存储在链上，包括他们的交易、点赞等。因此，每个 `dapp` 必须不遗余力、持之以恒地专注于提供最佳体验、价格、产品和服务阵容——否则，现有竞争对手或新进入者将会出现来抢走他们的业务。一个例子有助于将这一理论具体化。

Uniswap 是最早获得大规模采用的以太坊 `dapps` 之一，于 2018 年推出，并开创了自动做市商模型，使用户无需使用中心化交易所或银行即可交换加密货币。Uniswap 的商业模式涉及所有交易的 0.05% 分成，同时为提供流动性（可供交换的代币供应）的人提供市场汇率的 0.25% 价差。2020 年，一个名为 Sushiswap 的竞争对手出现，它复制了 Uniswap 主要开源且简单的代码。但 Sushiswap 需要的不仅仅是功能代码才能运行——它还需要加密货币所有者将其持有量提供给交易所，并且数量足以使市场提供的汇率能够与 Uniswap 竞争。削减 Uniswap 对用户的费用是不切实际的——即使 Sushiswap 免除了其 0.05% 的费用，很少有用户会注意到这种节省，而且这些节省的价值将被交易所流动性不足所导致的汇率瞬息万变的变化所掩盖。相反，Sushiswap 宣布了一项智能合约，将向任何愿意在交易所“质押”其加密货币的人发行“Sushi 代币”。这为 Sushiswap 做市商提供了两种产生利润的方式：每笔交易的交易费以及交易所本身的增值，而使用 Uniswap 时只有前者。后来，Sushiswap 宣布了一项激励措施，专门奖励将其质押代币从 Uniswap 转移到 Sushiswap 的加密货币所有者，这自然增加了其供应量，同时也减少了现有巨头可用的供应量。Uniswap 无法阻止这一有针对性的优惠，因为记录在各种区块链上公开可用，而 Sushiswap 可以轻松提供，原因相同。为了捍卫其业务，Uniswap 宣布将发行自己的代币，同时追溯性地奖励之前的提供者。

用户有益的“军备竞赛”在 `dapps` 中很常见，它们通常将产品置于渐进式去中心化的道路上，由社区拥有产品，而不仅仅是其创建者，并且确实也由社区指导。

## 展望未来

Web3 的愿景令人信服。它设想了一个互联网版本，该版本不仅在其运营和协议中是去中心化的，而且是通过同一网络实际运行的。这个互联网还使用户能够在该网络上存储其身份、付款和数据，而不是将其强制存储在由大型营利性公司控制的数据库中。通过这样做，乐观主义者认为互联网可以回归其创立时的开放原则——并永远保持这种状态。Andreessen Horowitz 的加密货币风险投资家 Chris Dixon 喜欢说，如果 Web 2.0 时代的主导理念是“不作恶”（Google 从 2000 年代初至 2015 年的事实上的座右铭），那么 Web3 时代的口号将是“不能作恶”，并补充说“你应该信任的唯一 API 是由区块链控制的 API”。

即使好处将是普遍的，重建互联网及其众多应用程序也不会容易。先例也表明，这不太可能。免费、开源和社区运营的技术已经存在数十年——它们几乎总是为开发者和用户提供更公平、更繁荣的未来。尽管如此，这些技术往往会输给付费、封闭和私有的替代方案，因为运营这些替代方案的公司可以负担得起在服务和工具、工程人才、客户获取和独家内容方面的巨额投资。此类投资会导致一种不可避免的反馈循环，即更多用户带来更多开发者，反之亦然。一旦这个反馈循环变得足够强大，开发者和用户就会在财务、创意或技术上被锁定——如果不是全部三者的话。

区块链无法拆解 Web 2.0 的飞轮，但它们确实提供了一种机制，通过该机制，重要且多样的资源（从财富到基础设施和时间）可以被独立团体轻松聚集，其规模足以与最强大的私营公司抗衡。此外，这些机制内置了经济模型，以补偿为其成功或持续运营做出贡献的人，而不是依赖他们的利他主义和同理心，正如大多数开源项目的情况一样。而且，这种补偿的确切价值并不总是已知，也从未得到保证，但它会随着任何给定项目的成功而增加。因此，早期支持者可以获得与其承担的风险相称的回报，这些回报通常与传统科技工作的高薪和确定性相竞争。到 2023 年底，新罕布什尔州、犹他州和怀俄明州都已合法化 DAO，一些技术人员将其设想为元宇宙时代的 LLC（有限责任公司）或 501(c)(3)（非营利组织）版本——一种新结构，将永久改变（并简化）资本形成，同时使数以亿计的原本被剥夺权利的个人能够参与高增长科技经济。

区块链也以非凡的规模运行。2021 年和 2022 年，比特币和以太坊区块链处理了超过 14 万亿美元的价值，是 Stripe、PayPal、Square、Shopify 和 WeChat 总和的几倍。所有这些交易都在不需要中央机构、管理合伙人甚至总部的情况下进行。此外，付款是在数十个竞争钱包之间进行的（而不是仅限于一个严格控制的网络，如 Venmo 或 PayPal 等点对点渠道的情况），可以在任何时间进行（不像自动清算所和电汇），在不到一分钟内完成（不像 ACH），并且不需要发送方或接收方建立银行账户，更不用说与任何特定区块链、区块链处理器或钱包提供商谈判长期协议了。其中许多付款被编程为自动运行应用程序、投票、借贷、资助项目、授予用户访问俱乐部的权限，或触发任何数量的其他活动。或者，付款是由这些事件引起的。出于这个原因，Web3 社区认为，所谓的“数字支付渠道”，如 PayPal、Venmo 和 WeChat，以及 Apple 的 IAP 和 Apple Pay，只不过是传统渠道的复制品。而且，与这些渠道不同，区块链不能用于控制用户、提取额外费用或强制使用其他产品。
