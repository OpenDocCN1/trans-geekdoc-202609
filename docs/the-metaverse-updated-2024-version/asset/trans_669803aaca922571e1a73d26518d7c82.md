

# HMD领域的发展与应用

经过数十年玩具制造商、发明家和公共研究实验室的无效摸索后，大型科技公司在2010年代初开始向HMD领域投入数十亿美元。2010年，Rony Abovitz（此前创立了设计和制造机械臂以辅助实时患者手术的MAKO Surgical Corp.）推出了Magic Leap，该公司设计和制造主要面向工业和政府应用的混合现实设备。到2022年沙特阿拉伯主权财富基金收购Magic Leap大部分股份时，该公司已筹集了超过40亿美元（尽管有报道称其出售价格低于该数额）。同样在2010年，Microsoft开始开发HoloLens AR平台，该平台同样专注于企业用途，首款型号于2016年发布，随后在2019年推出了后续版本；Google也启动了面向消费者用户的Google Glass智能眼镜项目。首款Google Glass Explorer于2013年发布，面向企业的设备于2019年推出，重新构思并重新品牌化的设计于2022年进行公开现场测试。Google的Cardboard VR平台于2014年推出，Google的第二个VR平台Daydream在两年后面世。Sony PlayStation于2011年开始开发其VR平台，PS VR于2016年上市。2014年，Snap收购了成立于2011年的AR眼镜初创公司Vergence Labs，后者成为Snap Spectacles的基础，Spectacles于2016年首次亮相，随后的五年间陆续推出了Spectacles 2、Spectacles 3和Spectacles 4。Amazon于2016年或2017年某个时间点开始开发基于Alexa的AR眼镜。首款Echo Frames于2019年发布；第二代产品两年后面世。

随着Magic Leap、Microsoft和Google开始设立其HMD部门，南加州大学创意技术研究所的HMD设计师Palmer Luckey开始开发一款后来被称为Oculus的VR设备。当时，Luckey被传闻拥有世界上最大的个人HMD收藏，他为Oculus设定的目标是打造一款比当时市场上任何其他设备都更强大，同时也更便宜的设备。当时，id Software创始人John Carmack也一直在研究HMD领域，并听说了Luckey的工作。在2011年底试用了一台Oculus原型机后，Carmack开始协助Luckey的研究，并在2012年洛杉矶E3电子游戏大会上，“3D图形之父”首次公开演示了Oculus（该设备明显用胶带固定），并宣布《Doom 3》将被移植到该设备上。次年，Carmack加入Oculus担任首席技术官，随后不久离开了id。又过了一年，Facebook以20亿美元收购了Oculus VR，Carmack一直留任到2022年，随后离职创立了人工智能通用初创公司Keen Technologies。

尽管到2020年中期，VR和AR HMD已投入数十亿美元，但这些设备的终身销售额合计不足3000万美元。但随后，这些投资似乎突然成熟了。

2020年6月，约翰斯·霍普金斯的神经外科医生使用经过FDA批准的AR设备，对活体患者进行了美国的第一例和第二例手术。第一例是脊柱融合手术，在患者脊柱中植入了六颗螺钉；第二例则涉及切除另一名患者脊柱上的癌性肿瘤。在这两种情况下，外科医生都使用了一款头戴式AR设备，该设备根据患者脊柱和内部骨骼结构的CT扫描渲染出3D模型，实时显示外科医生的工具和植入物，以及患者的生命体征。到2022年底，执行约翰斯·霍普金斯AR手术并担任该医院脊柱融合实验室主任的Timothy Witham博士，已使用AR设备完成了超过150例活体患者手术，美国各地还进行了数十例此类手术。

2020年9月，梅赛德斯-奔驰宣布将在其美国近400家经销商部署Microsoft的HoloLens 2 AR设备，供当地技术人员进行复杂维修。具体而言，该设备将为技术人员提供屏幕上的示意图，自动突出显示需要测试或维修的部件，并指导安装和拆卸，同时还会警示关键风险，例如烫伤的潜在可能性。技术人员还可以使用该设备与梅赛德斯的集中专家进行视频通话，专家可以通过HoloLens的前置摄像头实时观察他们的操作并进行指导。

在2020年和2021年期间，十大上游石油和天然气公司中的每一家都开始将VR设备纳入其培训计划，特别是针对那些将被派驻到石油钻井平台和平台上的人员。这些设施对大多数新员工来说完全陌生，而且位于偏远且危险的地点；在美国，石油钻井平台和平台的死亡率为每10万人中有25-30人（钻井工人为45-50人），是全国平均水平的七倍多。一位石油和天然气高管报告称，除了减少培训时间和事故率外，在职场入职培训中使用VR设备甚至导致了新的安全标志、位置和说明，因为眼动追踪显示，许多受训者在测试场景中难以找到（或否则错过了）紧急信息。

2021年3月，美国陆军宣布了一项协议，计划在未来十年内从Microsoft购买多达120,000台定制的AR HoloLens设备。这项合同价值220亿美元——每台头显近20万美元（该金额包括硬件升级、维修、定制软件和其他Azure云计算服务）。在一份新闻稿中，自陆军-Microsoft AR合作伙伴关系启动以来一直支持该合作的军士长Marc Krugh表示，该设备将使士兵能够“在更真实的场景中进行排练和训练”。陆军专用的HoloLens设备，称为IVAS（集成视觉增强系统），使用了HoloLens的技术，同时增加了热成像、额外传感器、GPS和夜视功能，为士兵提供情境输入和实时训练数据。用户可以通过“将全息图像、三维地形地图和指南针投射到他们的视野中”，看到自己在战场上的位置，以及周围有什么和谁。Microsoft吹嘘称，IVAS将使用户能够将视角转移到战斗人员的模拟“制高点”，不仅能评估成功的前景，还能评估他们可能受到日光、月光、雨水等因素的影响。陆军特别看重其最大限度降低误伤风险并提高逃离交火能力的功能。当与武器瞄准镜配对时，IVAS允许士兵像步枪一样观察，从而提供“安全地绕过角落观察”的能力。
