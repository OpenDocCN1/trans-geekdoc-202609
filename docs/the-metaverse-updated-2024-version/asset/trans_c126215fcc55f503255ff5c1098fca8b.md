

# 第9章 硬件、头戴式显示器以及我们这个时代最艰巨的技术挑战

AOUSD成立前一年，近三十家公司——包括Meta、微软、Epic Games、Unity、Adobe和Nvidia等竞争对手，以及万维网联盟和Khronos Group等组织——联合起来成立了元宇宙标准论坛，该组织旨在促进各种标准工作组（如OpenUSD）的创建。截至2023年6月成立一周年之际，MSF已汇聚超过2,400个成员组织，这让人们寄予厚望，希望皮克斯不会成为最后一家为了集体利益而放弃其专有技术控制权的公司。

对许多人来说，元宇宙最令人兴奋的方面是可用于访问、渲染和操作元宇宙的新设备。大量关注集中在头戴式显示器（HMDs）上，这些设备通常分为三类。第一类是虚拟现实（VR）头显，通常包括一对直接置于用户眼睛前方的一到两英寸的显示屏，用于显示纯合成的3D环境。为了增强沉浸感和视觉清晰度，用户的眼睛通常被头显完全包围，从而遮挡了他们对“现实世界”的周边视野。简化来说，VR设备就像在眼睛前一英寸处横向观看智能手机，同时佩戴视觉遮挡物，并利用头部、眼部及其他身体动作来操作设备，甚至可能还会使用手持控制器。VR用户在使用设备时几乎总是静止不动。虽然VR取代了“现实世界”，但增强现实（AR）则是在其之上添加信息。一个类比可能是查看带有实时数字标注的世界，例如一个虚拟路标，用于识别视野内的雕像，并允许用户按下数字按钮来播放音频录音，甚至可能播放该人物的视觉动画。AR有两种核心方法。在第一种方法中，用户通过选择性照亮以渲染AR信息的玻璃来观看（“光学AR”）。在第二种方法中，用户观看的是设备捕获并随后标注的现实世界实时视频（“透视AR”）。与VR头显类似，AR设备通常至少部分通过跟踪用户的手、眼睛或身体来控制。

最后一类HMD是混合现实（MR）设备，与AR类似，但涉及与现实世界环境更直接的交互。因此，用户可能能够与虚拟球一起玩虚拟网球，虚拟球会从现实世界的地板和附近的墙壁上弹起，或者收集程序化放置在家中各处的小精灵，它们躲在抽屉里，在家居植物周围飞来飞去。AR和MR设备旨在用于静止和移动场景。

许多AR和MR头显也可以通过填充所有可用像素且不使用来自现实世界的视觉输入来提供VR体验。然而，虽然并非全部，但大多数投资于VR、AR和MR的公司认为最终目标是一副轻量级的MR眼镜（而不是“头显”或“护目镜”），能够提供复杂的MR体验，尽管这样的设备不一定会取代专用的VR或AR设备，就像智能手机没有取代偶尔需要PC的情况一样。截至目前，这一目标进度严重滞后。

2016年，马克·扎克伯格重申了他的信念，即在十年之内，“外观正常”的AR眼镜不仅将成为日常生活的一部分，而且这些设备往往会取代智能手机在通话、分享照片和浏览网页方面的作用。^([1](#notes_split_009.xhtml#ch9fr1)) 与此同时，大屏幕电视将被一个“1美元的应用”取代，该应用会在家庭客厅墙壁上放置一个更大的AR屏幕。^([2](#notes_split_009.xhtml#ch9fr2)) 同一年，蒂姆·斯威尼预测，在五到七年内，VR设备将拥有与2016年PC相当的性能，但价格仅为其一小部分，并且缩小到Oakley太阳镜大小的眼镜中。^([3](#notes_split_009.xhtml#ch9fr3)) 当谷歌于2012年推出其Google Glass智能眼镜硬件时，该公司暗示年销量可能在2015年达到数千万，并最终吸引近80%每天佩戴眼镜的人群。^([4](#notes_split_009.xhtml#ch9fr4)) 相反，Google Glass成为了大型科技公司最臭名昭著的失败产品之一，销量未能突破10万台。类似地，大多数估计显示，自那次市场失误以来的十年里，售出的AR头显或眼镜不足一百万副。VR的表现更好，终身销量约为5000万至6000万台，^([5](#notes_split_009.xhtml#ch9fr5)) 但许多买家在购买后几周内就停止使用设备。^([6](#notes_split_009.xhtml#ch9fr6)) 2022年10月，在Quest 2发布两周年之际，《华尔街日报》报道，Facebook销售的2000万台设备中，仅有不到三分之一每月使用。^([7](#notes_split_009.xhtml#ch9fr7))

这些糟糕的结果并非缺乏努力所致。在2014年3月收购Oculus VR后的九年里，Facebook在其Reality Labs部门花费了大约530亿美元。这笔支出涵盖营销、制造和设备补贴——大多数Quest设备都低于成本价出售——但也包括对软件、研发和并购的投资，其中一些涉及尚未发布的设备、技术或体验，另一部分则涉及Facebook后来停产或关闭的产品。由此产生的收入估计为70亿美元，造成了460亿美元的终身部门亏损，在此期间大约运送了2000万台Oculus/Quest设备。2021年，Facebook与雷朋合作推出了多款联名眼镜，使用户能够从设备拍照和听音乐等功能。《华尔街日报》报道称，前十八个月售出了30万台，不到十分之一的购买者每月使用。^([8](#notes_split_009.xhtml#ch9fr8)) 2022年4月，据报道Facebook正在“赶工”以在2024年底前推出其首款AR眼镜，^([9](#notes_split_009.xhtml#ch9fr9)) 但到2023年2月，该公司已将目标发布日期推迟到2027年——距扎克伯格预测该形态将在不到十年内成为日常用品已经过去了11年。^([10](#notes_split_009.xhtml#ch9fr10))
