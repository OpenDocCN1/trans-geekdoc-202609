

在1983年，街机制造商南梦宫（Namco）向任天堂（Nintendo）提出，希望在其任天堂娱乐系统（`NES`）上发行其游戏作品（例如 `Pac-Man`）的版本。当时，`NES` 并非旨在成为一个平台，它只运行任天堂自行制作的游戏。最终，南梦宫同意向任天堂支付其所有在 `NES` 上发行的游戏作品 10% 的许可费（`Nintendo` 对每个单独的标题拥有批准权），此外还需支付另外 20% 由任天堂制造南梦宫的游戏卡带。这 30% 的费用最终成为行业标准，被 Atari、Sega 和 PlayStation 等公司效仿。^([8](#notes_split_010.xhtml#ch10fr8))

四十年后，如今很少有人再玩 `Pac-Man`，昂贵的卡带已转变为由游戏制作商制造的低成本数字光盘，以及用于数字下载的更低成本带宽（这些成本大部分由消费者通过网络费和主机硬盘承担）。与此同时，30% 的标准一直延续并扩展到所有游戏内购买项目，例如额外生命、数字背包、高级通行证、订阅、更新等（此费用还涵盖底层支付渠道（如 PayPal 或 Visa）收取的两到三个百分点）。

主机平台收取该费用的理由不仅仅是为了赚钱。最重要的是，它们如何使游戏开发者本身能够赚钱。索尼（Sony）和微软（Microsoft）通常以低于制造成本的价格出售其各自的 PlayStation 和 Xbox 主机，这使得消费者更容易获得当代游戏所需的强大 GPU 和 CPU。而这种单位亏损发生在这些平台分配用于设计主机的研发投资、说服用户购买主机的营销成本，以及独家内容（即微软和索尼的内部游戏开发工作室）之前，这些独家内容鼓励用户在主机发布时购买，而不是几年后。鉴于新主机通常能够实现新的或更好的功能，更快的采用速度应该使开发者和玩家都受益。

平台还开发和维护大量专有工具和 API，开发者需要这些工具才能使其游戏在特定主机上运行，包括 Xbox Live、Nintendo Switch Online 和 PlayStation Network 等在线多人游戏网络和服务。这些投资有助于游戏制作商，但它们促使平台试图收回并从其支出中获利——因此有了 30% 的费用。

游戏平台可能有收取 30% 费用的理由，但这并不意味着该费用是由市场决定的，也不意味着它是完全合理的。消费者被迫以低于成本的价格购买这些主机；没有购买软件价格低 30% 的更昂贵主机的选项。虽然主机必须吸引开发者，但它们并不为这些开发者而相互竞争。大多数游戏制作商将其作品发布到尽可能多的平台，以触达尽可能多的玩家。因此，没有哪个主机会从向开发者提供更好的条件中获益。Xbox 降低 15% 的费用意味着游戏发行商在 Xbox 上销售的每一份拷贝可多赚 21%，但如果他们因此选择不在 PlayStation 或 Nintendo Switch 上发布其作品，他们将错失高达 80% 的总销售额。这可能会给微软带来一些额外客户，但绝不会增加 400%，这是让发行商持平所需的数字。如果微软的举措被 PlayStation 或 Nintendo 效仿，三个平台都将损失一半的软件收入，且收益甚微。

对 30% 分成最尖锐的批评集中在主机的专有工具、API 和服务上。在许多情况下，它们给开发者增加了成本，而不是帮助他们。在其他情况下，它们产生的价值有限。在某些情况下，它们仅用于锁定客户和开发者，并对双方都不利。这一现实在三个方面表现得尤为明显：API 集合、多人游戏服务和权利管理。

为了使游戏在特定设备上运行，它需要知道如何与该设备的许多组件（例如其 GPU 或麦克风）进行通信。为了支持这种通信，主机、智能手机和 PC 操作系统会生成“软件开发工具包”（`SDK`），其中包括“API 集合”等内容。理论上，开发者可以编写自己的“驱动程序”来与这些组件通信，或使用免费开源的替代方案。OpenGL 是另一种用于从同一代码库与尽可能多的 GPU 通信的 API 集合。但在主机和 Apple 的 iPhone 上，开发者只能使用平台运营商制作的 API。Epic Games 的 `Fortnite` 必须使用微软的 DirectX^([\*](#chapter10.xhtml#footnote-013)) API 集合来与 Xbox 的 GPU 通信。`Fortnite` 的 PlayStation 版本必须使用 PlayStation 的 GNMX，而 Apple 的 iOS 需要 Metal，Nintendo Switch 需要 Nvidia 的 NVM，等等。

每个平台都认为，其专有 API 最适合其专有操作系统和/或硬件，使开发者能够制作更好的软件，从而有利于平台、开发者和用户。尽管这种优化逻辑是成立的，但当今运行的大多数虚拟世界——尤其是最受欢迎的那些——都是为了在尽可能多的平台上运行而制作的。因此，它们并未针对任何平台进行深度优化。大多数游戏也不需要每一分计算能力。

API 集合的差异以及缺乏开源替代方案，部分原因是开发者使用 Unity 和 Unreal 等跨平台游戏引擎，因为它们旨在与每个 API 集合通信。为此，一些开发者可能宁愿牺牲一点性能优化，而是通过使用 OpenGL 来优化预算，而不是向 Unity 或 Epic Games 支付费用或分享部分收入。

多人游戏的挑战有所不同。在 2000 年代中期，微软的 Xbox Live 管理了在线游戏的几乎所有“工作”：通信、匹配、服务器等。尽管这项工作困难且昂贵，但它也大大提高了玩家的参与度和幸福感，这对开发者有利。然而 20 年后，几乎所有这些成本现在都由游戏制作商承担和管理。这种转变反映了在线服务日益重要的地位，以及支持跨平台游戏的转变。大多数开发者现在希望管理自己的“实时运营”，例如内容更新、比赛、游戏内分析和用户账户，Xbox 为整合到 PlayStation、Nintendo Switch 等平台的游戏管理在线服务已不合理。但游戏开发者仍有义务向游戏平台支付全额 30% 的费用，并通过其在线账户系统工作。此外，如果 Xbox Live 网络因技术故障而离线，例如，玩家将无法访问 `Call of Duty: Modern Warfare` 的在线游戏。当然，玩家本身已经每月向微软支付 Xbox Live 订阅费，而该费用中没有一部分会流向那些证明其存在意义并支付最多服务器账单的开发者。批评者认为，平台服务的真正目的是在开发者和玩家之间制造额外的距离，将双方都锁定在基于硬件的平台上，并为平台的 30% 费用辩护。因此，当玩家从 PlayStation Store 购买 `FIFA 2017` 的数字版时，该副本将永久绑定到 PlayStation。换句话说，PlayStation 已经从 60 美元的购买中赚取了 20 美元，但如果玩家想在 Xbox 上玩该游戏，他们将不得不再花 60 美元，即使开发者愿意免费将其提供给玩家。用户向索尼等主机制造商支付的越多——索尼逐步收回设备的前期亏损——离开就越昂贵。
