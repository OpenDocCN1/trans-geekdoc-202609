### 2.2.1 Amplitude and time quantization

幅度量化将一个函数的某个值集合分解为有限数量的子集。如果所考虑的函数是标量的，则问题涉及量化区间。对于向量函数，量化概念与将其分量值集合分解为基本体积密切相关。最简单的量化类型是将模拟函数的范围 `Δϕ = ϕ[max] − ϕ[min]` 除以一个整数，并向上或向下舍入到最接近的整数。作为规则，量化以二进制代码进行。范围 `Δϕ` 被 `2^(n)` 除，其中 `n` 表示寄存器长度（或数字位数）。每个幅度由长度为 `n` 的零和一序列编码。

时间量化，进一步称为时间采样（在我们的情况下，函数的自变量是时间），是使用脉冲发生器执行的。请注意，采样率必须至少是函数频谱最大频率的两倍。

因此，模拟函数（信息、信号）的值由对应于离散时间点的二进制数字序列表示。

幅度量化是对模拟函数值的非线性变换 [[197](#refbib.xhtml#r197)]。[图 2.2](#chapter2.xhtml#f2_2) 显示了执行模拟函数幅度量化的非线性元件的特性。幅度量化可以是均匀的和非均匀的。在前一种情况下，量化步长 `h[k] = y[k + 1] − y[k]` 是一个常数 `h`。在非均匀幅度量化下，该步长取决于幅度。非均匀幅度量化降低了数字数据生成的相对误差。[图 2.3(a)](#chapter2.xhtml#f2_3)–[图 2.3(c)](#chapter2.xhtml#f2_3) 展示了具有不同舍入规则的量化器的特性：*a*—向上舍入到最接近的整数，*b*—向下舍入到最接近的整数和 *c*—舍入到基本区间的中间。

![Figure 2.2](images/fig2_2.jpg)

[Figure 2.2](#chapter2.xhtml#f2_2b)

![Figure 2.3](images/fig2_3.jpg)

[Figure 2.3](#chapter2.xhtml#f2_3b)

时间采样不会引起测量误差，而幅度量化会因舍入而伴随误差 `ε`。为了估计该误差，必须选择一个模型。考虑两种模型，即确定性和随机性。在第一种模型框架内，上述舍入规则导致最大误差

```
\begin{array}{r}
{\varepsilon_{max} = h.}
\\
\end{array}
```

(2.37)

换句话说，它与量化步长 `h` 相同。假设量化误差为随机变量，我们必须声明其概率密度函数（PDF）。例如，设该变量在区间 `[- h/2, h/2]` 上服从均匀分布，即

```
\begin{array}{r}
{p(\varepsilon) = \left\{ \begin{aligned}
\frac{1}{h} & {\text{for}\,\left| \varepsilon \middle| \leq \frac{h}{2}, \right.}
\\
0 & {\text{for}\,\left| \varepsilon \middle| > \frac{h}{2}. \right.}
\\
\end{aligned}~ \right.}
\\
\end{array}
```

(2.38)

由于 PDF 具有对称性，量化误差的均值为零，而其方差为

```
\begin{array}{r}
{\sigma^{2} = \frac{1}{h}{\int\limits_{- h/2}^{h/2}\varepsilon^{2}}d\varepsilon = \frac{h^{2}}{12}.}
\\
\end{array}
```

(2.39)

有趣的是，所得到的估计值明显小于确定性模型（2.37）的估计值。然而，请记住，该量化误差估计基于均匀分布和与模拟函数不相关的假设。

### 2.2.2 Audio data

声音信号的数字转换由 `ADC` 执行，它将模拟信号转换为数字音频数据。这些转换使用不同类型的数字调制。脉冲编码调制（`PCM`）和增量调制（`DM`）最为广泛。

`PCM` 将模拟信号 `x(t)` 的瞬时幅度序列（[图 2.4(a)](#chapter2.xhtml#f2_4)）转换为对应于离散时间 `nΔ` 的具有固定步长 `h` 的量化值（[图 2.4(b)](#chapter2.xhtml#f2_4)）。每个值 `x[PC][nΔ]` 被转换为二进制代码，如[图 2.4(c)](#chapter2.xhtml#f2_4)所示。这种调制器输出具有时间绑定的 0 和 1 的数据包。

![Figure 2.4](images/fig2_4.jpg)

[Figure 2.4](#chapter2.xhtml#f2_4b)

`PCM` 的精度取决于步长 `h` 和量化幅度数 `N`。最大量化值为 `(N − 1)h`。二进制代码组合的数量为 `n = [log[2](N − 1)h]`，其中 `[ ⋅ ]` 表示整数部分算子。

`DM` 是 `PCM` 的一种特殊类型，它也以时间离散采样和幅度量化的形式表示模拟信号。根据假设，音频信号中的采样之间存在关系。因此，可以仅使用一个数字来量化相邻采样。[图 2.5(a)](#chapter2.xhtml#f2_5)–[图 2.5(b)](#chapter2.xhtml#f2_5) 说明了增量调制器的操作。作为其输出，该调制器（见[图 2.5(a)](#chapter2.xhtml#f2_5)）生成脉冲的二进制序列，对于正差值为 `+1`，对于负差值为 `−1`。

![Figure 2.5](images/fig2_5.jpg)

[Figure 2.5](#chapter2.xhtml#f2_5b)

声音信号的数字表示有以下两种用途。首先，用于提高声音质量并进一步转换回模拟形式。其次，用于形成定量测量的属性以表征声音信号 [[124](#refbib.xhtml#r124)]。在此背景下，尤其要注意信号的频谱组成及其基本参数。

再次考虑由连续函数 `x(t)` 描述的模拟信号。设该函数在无限区间 `(−∞, +∞)` 上有定义且平方可积。那么该函数的傅里叶变换由下式给出

```
\begin{aligned}
{\Phi_{1}(\nu)} & {= {\int\limits_{- \infty}^{+ \infty}x}(t)\exp( - 2\pi\iota\nu t)dt = \Phi(2\pi\nu),}
\\
{\Phi_{2}(\omega)} & {= \frac{1}{\sqrt{2\pi}}{\int\limits_{- \infty}^{+ \infty}x}(t)\exp( - \iota\omega t)dt = \sqrt{2\pi}\Phi(\omega),}
\\
{\Phi(\omega)} & {= {\int\limits_{- \infty}^{+ \infty}x}(t)\exp( - \iota\omega t)dt.}
\\
\end{aligned}
```

(2.40)

这里 `\iota = \sqrt{- 1}`，`ν` 表示线性频率（以 Hz 为单位），而 `ω = 2πν` 是角频率（以 rad/s 为单位）。公式（2.40）包含复指数

```
\begin{array}{r}
{\exp( - \iota\omega t) = \cos(\omega t) - \iota\sin(\omega t).}
\\
\end{array}
```

(2.41)

函数 `Φ(ω)` 对于 `ω ∈ (−∞, +∞)` 是连续的。
