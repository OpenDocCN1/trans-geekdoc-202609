### 11.4.7 热喀斯特湖面积演化的随机化预测

热喀斯特湖面积的时间演化在超过可用面积和气候参数数据的时间间隔的时间间隔上进行预测。在所考虑的情况下，每个预测间隔的开始都指2008年。我们考虑以下三个时间间隔：

* —短期，2008年至2013年之间（$n = \overline{35,40}$）；
* —中期，2008年至2018年之间（$n = \overline{35,45}$）；
* —长期，2008年至2023年之间（$n = \overline{35,50}$）。

热喀斯特湖面积的时间演化使用训练好的随机化模型的组合（见 [Fig. 11.13](#chapter11.xhtml#f11_13)）在上述指定的预测间隔上进行预测。该组合中的模型以其参数的熵最优PDF、辅助随机序列和测量噪声为特征。测量噪声的PDF在训练间隔上的时间瞬间是不同的：它们取决于时间瞬间和相应的拉格朗日乘子。例如，*LDRR-LA* 的测量噪声具有PDF $Q_{n}^{\*}(\xi\lbrack n\rbrack,\theta_{n}),\, n = \overline{0,34}.$ 对于预测过程，我们应用对拉格朗日乘子取平均的PDF。

好吧，复合模型的块由以下PDF表征：

* 对于 *LDRR-LA*，$P^{*}(a)$ 和 $Q^{*}(\xi,\overline{\theta}),\,\,\overline{\theta} = \frac{1}{34 - p}{\sum\limits_{n = p}^{34}\theta_{n}}$；
* 对于 *LDRR-T*，$L^{*}(b)$，$M^{*}(\mu,\overline{\vartheta})$，和 $E^{*}(\eta,\overline{\vartheta}),\,\overline{\vartheta} = \frac{1}{34 - p}{\sum\limits_{n = p}^{34}\vartheta_{n}}$；
* 对于 *LDRR-P*，$V^{*}(c)$，$Z^{*}(\zeta,\overline{\lambda})$，和 $G^{*}(\chi,\overline{\lambda}),\,\overline{\lambda} = \frac{1}{34 - p}{\sum\limits_{n = p}^{34}\lambda_{n}}.$

这些PDF在相应的预测间隔上采样，并且通过蒙特卡洛模拟生成轨迹（湖泊面积变化）的预测集合。
