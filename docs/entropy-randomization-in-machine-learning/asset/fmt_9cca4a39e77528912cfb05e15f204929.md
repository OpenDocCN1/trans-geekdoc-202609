
$$\\begin{aligned} & {\\text{\\quad\\quad}H_{F}(\\mathbf{p},Q) = - \\left\\langle \\mathbf{p},\\mathbf{ln}\\frac{\\mathbf{p}}{\\mathbf{p}_{0}} \\right\\rangle - \\left\\langle (\\mathbf{1} - \\mathbf{p}),\\mathbf{ln}(\\mathbf{1} - \\mathbf{p}) \\right\\rangle -} \\\\ & {- {\\sum\\limits_{j = 1}^{s}\\left( {\\left\\langle \\mathbf{q}^{(j)},\\mathbf{ln}\\frac{\\mathbf{q}^{(j)}}{\\mathbf{q}_{0}^{(j)}} \\right\\rangle + \\left\\langle (\\mathbf{1} - \\mathbf{q}^{(j)}),\\mathbf{ln}(\\mathbf{1} - \\mathbf{q}^{(j)}) \\right\\rangle} \\right)},} \\\\ \\end{aligned}$$  

(6.20)

where *Q* = \[**q**^((1)), …, **q**^((*s*))\].

Clearly, the definition of this function explicitly considers the interval property of the variables. The admissible set is characterized by the balance constraints only.

*The Fermi entropy-robust estimation problem for the RPM-QuaRand model with the interval-type probabilities of belonging* can be written as follows:

*   maximize the entropy function (6.1.2)

    $$\\begin{array}{r} \\left. H_{F}(\\mathbf{p},Q)\\Rightarrow\\max_{\\mathbf{p},Q} \\right. \\\\ \\end{array}$$  

    (6.21)

*   subject to the balance constraints

    $$\\begin{array}{r} {\\mathcal{S}\\lbrack\\mathbf{x}\\lbrack j,\\tau\\rbrack,\\,\\mathbf{c}^{-} + C\\,\\mathbf{p};(j,\\tau) \\in \\mathcal{T}_{s}\\rbrack + {\\overline{\\zeta}}_{-}^{(j)} + L_{j}\\,\\mathbf{q}^{(j)} = \\mathbf{y}\\lbrack j\\rbrack,\\text{\\quad\\quad}j = \\overline{1,s}.} \\\\ \\end{array}$$  

    (6.22)

The constraints (6.22) extract an admissible set Θ from the unit nonnegative *n*\-dimensional cube ℐ.

*The Fermi entropy-robust ML algorithm for the RPM-QuaRand model with the interval-type probabilities of belonging* has the form

$$\\begin{array}{r} \\left. {(\\mathbf{p},Q)}^{*} = \\arg\\max_{(\\mathbf{p},Q)}\\lbrack H_{F},\\, \\middle| \\,(\\mathbf{p},Q) \\in \\Theta\\rbrack, \\right. \\\\ \\end{array}$$  

(6.23)

where Θ is the set defined by the balance constraints. Note that the problem (6.21, 6.22) contains (*r* + *m**s*) less constraints than the problem (6.16–6.18). Due to this feature, the computational complexity of the estimation problem (6.21, 6.22) is smaller in comparison with its counterpart (6.16–6.18).

## 6.2 Functional Description of Dynamic RPM-QuaRand Models

As established in the previous section, the estimation problems for the probabilities of belonging generally represent finite-dimensional nonlinear programming problems with entropy objective functions. The nonlinearity of these problems is caused by the nonlinearity of the functional 𝒮 that characterizes the model (6.5). Consider the models with one input and one output that are measured at discrete times from the interval 𝒯.

### 1. Dynamic models with unstructured power nonlinearities

A functional description of such a model has the following form

$$\\begin{aligned} {s\\lbrack j\\rbrack = {\\sum\\limits_{h = 1}^{R}{\\sum\\limits_{(n_{1},\\ldots,n_{h}) = 0}^{K_{h}}w_{h}}}} & {\\lbrack n_{1},\\ldots,n_{h}\\rbrack x\\lbrack j - n_{1}\\rbrack\\cdots x\\lbrack j - n_{h}\\rbrack,} \\\\ & {j \\geq maxK_{h}.} \\\\ \\end{aligned}$$  

(6.24)

(Also, see [Fig. 4.8](#chapter4.xhtml#f4_8).)

Its dynamic and nonlinear properties are reflected by the multidimensional pulse characteristics $w_{h}\\lbrack n_{1},\\ldots,n_{h}\\rbrack,\\, h = \\overline{1,R},$ with a finite “memory” *K*[*h*], i.e.,

$$\\begin{aligned} {w_{h}\\lbrack n_{1},\\ldots,n_{h}\\rbrack} & {\\neq 0,\\quad\\text{for}\\,\\, 0 \\leq (n_{1},\\ldots,n_{h}) \\leq K_{h};} \\\\ {w_{h}\\lbrack n_{1},\\ldots,n_{h}\\rbrack} & {= 0,\\quad\\text{for}\\,\\,(n_{1},\\ldots,n_{h}) > K_{h}.} \\\\ \\end{aligned}$$  

(6.25)

As the model parameters consider the ordinates of its pulse characteristics. A lexicographical ordering of the variables yields

$$\\begin{array}{r} \\left. (n_{1},\\ldots,n_{h})\\rightarrow v,\\text{\\quad\\quad}v = \\overline{1,V_{h}},\\,\\, V_{h} = (K_{h} + 1)\\, h, \\right. \\\\ \\end{array}$$  

(6.26)

Define a vector **c**^((*h*)) = {*c*[1]^((*h*)),…,*c*[*V*[*h*]]^((*h*))} composed of the ordinates of the pulse characteristic *w*[*h*]\[*n*[1], …, *n*[*h*]\]. Perform a similar operation with the products *x*\[*j* − *n*[1]\]⋯*x*\[*j* − *n*[*h*]\]. Introduce another vector

$$\\begin{array}{r} {\\mathbf{X}^{(h)}\\lbrack j\\rbrack = \\left\\{ x_{1}^{(h)}\\lbrack j\\rbrack,\\ldots,x_{V_{h}}^{(h)}\\lbrack j\\rbrack \\right\\}} \\\\ \\end{array}$$  

(6.27)

composed of the lexicographically ordered products *x*\[*j* − *n*[1]\]⋯*x*\[*j* − *n*[*h*]\]. Then the model equation (6.1.2) can be transformed into

$$\\begin{array}{r} {s\\lbrack j\\rbrack = {\\sum\\limits_{h = 1}^{R}\\left\\langle \\mathbf{c}^{(h)},\\mathbf{X}^{(h)}\\lbrack j\\rbrack \\right\\rangle}.} \\\\ \\end{array}$$  

(6.28)

As the result of all these manipulations, the original nonlinear model (6.1.2) has been reduced to its linear analog (6.28) of considerably higher dimension.

Using the probabilities of belonging **p** from [Section 6.3](#chapter6.xhtml#sec6_3), let us write the parameter vector **c**^((*h*)) as

$$\\begin{aligned} {\\mathbf{c}^{(h)} = \\mathbf{c}_{-}^{(h)} + C^{(h)}\\mathbf{p}^{(h)},\\,\\, C_{h} =} & \\left. \\text{diag}\\,\\lbrack(c_{i}^{(h, + )} - c_{i}^{(h, - )})\\, \\middle| \\, i = \\overline{1,V_{h}}\\rbrack, \\right. \\\\ & {h = \\overline{1,R}.} \\\\ \\end{aligned}$$  

(6.29)

Substituting (6.29) into (6.28) gives the equation

$$\\begin{aligned} {s\\lbrack j\\rbrack} & {= \\hat{s}\\lbrack j\\rbrack + {\\sum\\limits_{h = 1}^{R}\\left\\langle C_{h}\\,\\mathbf{p}^{(h)},\\mathbf{X}^{(h)}\\lbrack j\\rbrack \\right\\rangle},} \\\\ {.\\hat{s}\\lbrack j\\rbrack} & {= {\\sum\\limits_{h = 1}^{R}\\left\\langle \\mathbf{c}_{-}^{(h)},\\mathbf{X}^{(h)}\\lbrack j\\rbrack \\right\\rangle}.} \\\\ \\end{aligned}$$  

(6.30)

### 2. Dynamic models with structured power nonlinearities

For this class of dynamic models, a functional description has the following form:

$$\\begin{array}{r} {s\\lbrack j\\rbrack = {\\sum\\limits_{h = 1}^{R}{\\sum\\limits_{n = 0}^{K_{h}}\\left( {w_{h}\\lbrack n\\rbrack x\\lbrack j - n\\rbrack} \\right)^{h}}},\\text{\\quad\\quad}j > K.} \\\\ \\end{array}$$  

(6.31)

(Also, see [Fig. 4.11a](#chapter4.xhtml#f4_11).) Here the dynamic properties are reflected by the pulse characteristics $w_{h}\\lbrack n\\rbrack,\\, h = \\overline{1,R},$ with a finite “memory” *K*[*h*], i.e.,

$$\\begin{array}{r} {w_{h}\\lbrack n\\rbrack \\neq 0,\\quad\\text{for}\\,\\, 0 \\leq n \\leq K_{h};\\text{\\quad\\quad}r_{h}\\lbrack n\\rbrack = 0,\\quad\\text{for}\\,\\, n > K_{h}.} \\\\ \\end{array}$$  

(6.32)

As the model parameters consider the ordinates of the pulse characteristics. In other words, the parameters make the vector

$$\\begin{array}{r} {\\mathbf{c}^{(h)} = \\left\\{ c_{1}^{(h)},\\ldots,c_{K_{h}}^{(h)} \\right\\},} \\\\ \\end{array}$$  

(6.33)

where

$$\\begin{array}{r} {c_{n}^{(h)} = w_{h}\\lbrack n\\rbrack,\\text{\\quad\\quad}n = \\overline{0,K_{h}}.} \\\\ \\end{array}$$  

(6.34)

Using the probabilities of belonging **p**, write the parameter vector **c**^((*h*)) in the form (6.29). Substituting these equalities into (6.31) yields the model equation

$$\\begin{array}{r} {s\\lbrack j\\rbrack = {\\sum\\limits_{h = 1}^{R}\\left( {\\left\\langle \\mathbf{c}_{-}^{(h)},\\mathbf{x}\\lbrack j\\rbrack \\right\\rangle + \\left\\langle C_{h}\\,\\mathbf{p}^{(h)},\\mathbf{x}\\lbrack j\\rbrack \\right\\rangle} \\right)^{h}},} \\\\ \\end{array}$$  

(6.35)

where **x**\[*j*\] = {*x*\[*j*\],…,*x*\[*j*−*K*[*h*]\]}.

Thus, the relation between the model's output and parameters is essentially nonlinear (more specifically, a power function).
