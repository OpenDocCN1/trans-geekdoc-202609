# 第 8 章 在紧集上具有给定概率密度函数的随机向量的生成方法

DOI: [10.1201/9781003306566-8](https://doi.org/10.1201/9781003306566-8)

RML 过程的最后阶段是使用熵最优随机模型生成随机向量或轨迹的集合。在此至关重要的是能够生成具有任意形式给定 PDFs 的这些随机对象的方法。在一般表述中，随机序列和随机向量的生成问题对于蒙特卡洛方法来说是经典的。存在许多用于生成具有给定概率特征的“标准”随机数序列的方法，如均匀、高斯、泊松分布等 \[159, [168](#refbib.xhtml#r168)\]。然而，当涉及服从任意形式 PDFs 的序列以及高维随机向量的序列时，只能提出很少的方法。本章开始时，我们将对生成方法进行简要综述，不求详尽，但能深入了解这些方法背后的主要概念。我们的注意力将集中在一种用于生成在紧集上定义的 PDFs 的随机向量的方法上。它用 `n`\-维分段常数函数逼近给定的 PDF，其中步长取决于该 PDF 的 Lipschitz 常数。随机对象生成的一个重要方面是进行统计检验，以验证所生成对象的概率特性是否与给定的 PDF 相匹配。
