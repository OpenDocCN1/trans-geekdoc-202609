

因此，可以谈论一个整体的人口-经济（`PE`）系统，该系统由人口（`P`）子系统和经济（`E`）子系统组成，二者形成闭环，如[图 1.2(c)](#chapter1.xhtml#f1_2)所示。对该整体系统进行分析的一个重要领域涉及情势评估（状态估计）和预测，即随时间推移的演化。对每个子系统，这些问题由相应的科学研究。例如，人口的结构动态是宏观人口学的主题。一大批经济学科（政治经济学、宏观和微观经济学、数理经济学等）研究经济结构的形成和演化。注意，影响人口子系统中不同过程的经济因素在宏观人口学中被视为与元系统影响相关的外部因素。实际上，在经济学科中也出现了类似的情况。经济子系统的行为是在人口子系统再生产一定数量和结构的劳动资源这一条件下研究的。

特别地，人口学研究的一个流行方向是在给定的经济情景下预测人口状态指标，该情景以定量形式描述[[40](#refbib.xhtml#r40)]。而且，这些情景反映了某些经济目标，这些目标（通常）与预测期内人口的潜在变化无关。但这些变化会显著影响要实现经济发展的指标。上述反馈关系客观存在，试图忽视它往往会导致无法实现的预测。

另外，请注意该对象的另一个特点，该对象使用 `ML` 程序进行估计和预测。其每个部分都有内部行为（在没有元系统影响的情况下）和受扰行为（在元系统施加的某些影响下）。在此背景下，我们指的是状态（平衡、循环、吸引子等）、其稳定性和其他属性。然而，当人口和经济子系统联合成一个整体系统时，后者可能获得与这些部分初始属性不同的新属性。这种系统效应特别体现在每个子系统内部存在非线性关系的情况下，以及一个子系统影响另一个子系统的通道中存在非线性的情况下。结果，整体系统可能具有其他平衡以及其他非平衡过程。对于这样的系统，状态估计和预测实际上不是一个平凡的问题。这里由于环境的不确定性水平很高而出现了额外的困难，对于单独的子系统以及整个系统都是如此。这种不确定性的来源是个体，即两个子系统的主要组成部分，具有其动机、社会和职业特征以及行为反应。

因此，似乎这里的情况与之前的例子相似。人口-经济系统无法复制，即在该系统中运行的内部过程即使在相同的操作条件下也不会重复。该系统是自发展的，这排除了其过程的真实重复性。因此，伴随人口-经济系统运行的不确定性是通过使用可用信息进行参数估计的仿真模型再现的。

## 1.2 机器学习程序的结构

嵌入 `ML` 程序中的方法和算法相当多样。然而，它们都具有相同的 methodological 方向和结构。后者被理解为将知识转化为信息决策支持的功能阶段序列。该程序的结构如图 [图 1.3](#chapter1.xhtml#f1_3) 所示。该程序包括以下四个阶段。

第一阶段（`PM`）在于开发一个数学模型，该模型描述所研究对象的运行机制及其输入输出的测量模型。对象的数学模型将其知识转化为具有明确特征列表的结构。该阶段不能在如此一般的陈述中被形式化。然而，通常存在关于对象类别和需要使用数学框架建模的问题的先验信息。这里“类别”是指具有一组共同属性的对象或问题的集合。如果该集合已知，则可以为相应类别构建概念模型[[68](#refbib.xhtml#r68)]。这样的模型由相互关联的概念列表组成，这些概念描述了给定类别，连同这些概念的属性、特征和分类。概念建模的一个重要组成部分是反映给定类别对象内部运行过程的规律性[[16](#refbib.xhtml#r16)]。换句话说，概念模型系统化和结构化了关于所研究对象类别和问题的现有知识。形成此类类别是一个非平凡的问题，其复杂性本质上取决于其描述中的抽象程度。例如，系统总论操作抽象集合及其关系（分层系统、反馈等）[[119](#refbib.xhtml#r119)]。通过这种描述性方法产生的类别具有相当高的能力（因为它们包含了大量系统），但其概念模型通常是不可构造的。相反，任何试图向抽象类别添加特定属性的尝试都会降低新类别的能力，尽管在构造性意义上会产生更好的概念模型。一个很好的例子是受控技术系统类别[[91](#refbib.xhtml#r91)]。

在大多数情况下，概念模型表示一个图，其中节点对应于其功能元素，弧对应于它们之间的相互关系。事实上，这种对概念模型的理解首次在[[54](#refbib.xhtml#r54)]中引入。进一步复杂化和更深入地具体化不同系统类别固有的属性，勾勒出向更有效的描述的逐渐过渡，即称为本体[[169](#refbib.xhtml#r169)]的专门结构化列表。尽管如此，图形和本体对类别的描述仍保留在功能元素的水平上。这些元素使用各种数学工具进行描述，具体取决于其运行机制中嵌入的规律性以及其特征。在 `parametric characteristics` 的情况下，元素的数学模型是函数关系（用于描述静态元素）或不同类型的微分方程系统（用于描述动态元素）[[50](#refbib.xhtml#r50), [161](#refbib.xhtml#r161)]。一种相当有效的静态关系参数化方法涉及神经网络[[96](#refbib.xhtml#r96)]。这些模型的基本元素和参数调优算法的相对简单性使得神经网络能够用于高维空间。

有时，为方便起见，对象的动态使用具有 `functional characteristics` 的数学模型来描述。例如，该类别包括由积分方程或函数级数定义的模型[[111](#refbib.xhtml#r111), [137](#refbib.xhtml#r137), [146](#refbib.xhtml#r146), [152](#refbib.xhtml#r152)]。在这些模型中，函数特征由积分方程的核或函数级数扮演。
