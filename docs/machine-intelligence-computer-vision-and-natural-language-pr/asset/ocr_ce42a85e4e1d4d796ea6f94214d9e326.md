# ## 4.4 Overfitting Prevention Techniques

Overfitting occurs when your model achieves a strong match on the preparation data but fails to perform well on, hidden data. Typically, the model learns defined designs for training data that are superfluous in other data. Overfitting can be identified by looking at approval measures, which are similar to accuracy or loss. The validation metric stops working after a certain number of epochs and begins to decline later. The training metric continues to improve as the model aims for the best fit for the training data. When a model tries to predict a pattern in data that is too noisy, it is called overfitting. This is due to a model that is overly sophisticated and has a high number of boundaries. In view of the fact that the pattern does not represent the truth in the data, an overfitted model is incorrect. This can be determined if the model produces excellent results on the visible data (training set) but fails miserably on the hidden data (test set). The deep learning model’s goal is to generalize in the best possible way everything from the training data to any information the area of the problem. This is critical since we consider our model should generate predictions based on data it has never seen before [32].

In deep learning, the main criterion is that we should be able to perform effectively on previously unknown inputs which was trained. The ability to perform effectively on previously unknown data sources is referred to as generalization. A deep learning network's goal is to produce a final model that performs well on both the data we used to train and the new data on which the model can be used to make forecasts.
