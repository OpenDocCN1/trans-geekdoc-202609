# 10.2.3 Robust Lane Detection in Low Light

To remove unnecessary objects from an image, an original image needs to have a Region of Interest (ROI). That is, it should remove things like street lights, signs, the moon, etc. By cropping, the lane detection system can also be made more accurate and faster. As the image size increases, camera velocity enhancement is increased. Accuracy can be improved by nutrit objects which have the same characteristics as lanes but are located outside the ROI. As implemented, the ROI is set manually; however, camera calibration parameters could be used to automatically calculate a suitable ROI. This lane detection system only requires pre-processing of color images to create grayscale images; therefore, this step can be skipped for monochrome images. For the accessible image, the Bayer format is assumed. A pixel's color should be extracted. By contrast, shoulder lanes are generally more visible in contrast to a traffic lane because they are typically presented in the image as long, straight lines.
