# 2.7 Components of HCI

A computer interface is a medium that allows any user to communicate with a computer. HCI is made of three main components:

+   - a human
- the computer
- the interaction between them.

The interface is essential to most HCI. To create effective interfaces, users must understand the limitations and capabilities of the components.
