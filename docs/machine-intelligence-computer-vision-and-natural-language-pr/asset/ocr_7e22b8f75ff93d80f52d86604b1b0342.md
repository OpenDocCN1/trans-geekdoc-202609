# 6.4.3 DenseNet for Semantic Segmentation

The typical segmentation architecture is composed of a down-sampling path responsible for extracting coarse semantic features and an up-sampling path trained to recover the input image resolution at the output of the model. Densely Connected Convolutional Networks (DenseNets) have shown excellent results on image classification tasks. The idea of DenseNet is based on the observation that if each layer is directly connected to every other layer in a feed-forward fashion, the network will be more accurate and easier to train (Chablani, 2017). DenseNets are built from dense blocks and pooling operations, where each dense block is an iterative concatenation of the previous feature maps. This architecture can be seen as an extension of ResNets, which performs iterative summation of the previous feature maps.
