Convolutional neural networks (CNNs) are classified as deep learning networks and are commonly used to analyse and classify images. They are made up of an input and an output layer, with several layers in between. The layers are made up of a few convolutional layers that extract the various features of the images.

A CNN is represented by the following non-linear function:

```
$c_i = C(M; \theta)$
```

which transforms an image $M \in R^{W \times W}$ to a vector $W \times W$ of size $c_i = (c_1, c_2, ... c_i)^T$, where $i = 1 \dots n$. and signifies the change that the Image belongs to one of the $n$ classes: the number of $K$ parameters used to map the input image to the vector $c_i$ is $\theta = {\theta_1, \theta_2, ... \theta_k\}$.

CNN training can be viewed as a non-linear optimization problem:

```
$\hat{\theta} = arg_{min} K(k^{(1)}, k^{(2)}, \dots k^{(N)})$
```

N is the number of images used to train the CNN in this case, and

```
$K(k^{(1)}, k^{(2)}, \dots k^{(N)}) = \frac{1}{N} \sum_{j=1}^{N} D_j v e^{(j)T} log(I^{(j)}; \theta)$
```
