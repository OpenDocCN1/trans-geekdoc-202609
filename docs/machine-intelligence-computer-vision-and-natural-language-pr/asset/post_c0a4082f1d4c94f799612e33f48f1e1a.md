## 14.5 Conclusion

The total number of tweets considered for analysis is 500 (tweets from May 2021). The number of tweets after removal of duplicate tweets is 498. Textblob library of Python was considered to determine the polarity of the tweets. The number of positive tweets in the dataset is 216 and the number of negative tweets in the dataset is 79.
