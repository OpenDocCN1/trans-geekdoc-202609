### 11.2.2 Classification Techniques

Based on the existing literatures, this research also focused on classifying the gastric cancer dataset using supervised machine learning models.

#### 11.2.2.1 Logistic Regression (LR)

Logistic Regression is a supervised learning algorithm which is used to predict the dependent variable. It follows the sigmoid function to convert the values within the range of 0–1 (Brindah et al., 2021).

$S(x) = \frac{1}{1+e^{-x}}$ (11.1)

#### 11.2.2.2 Decision Tree (DT)

The decision tree is a non-parametric supervised learning algorithm which is used for classification. It is a flowchart with a tree-like structure where the internal node represents the feature, the branch represents the decision rule, and the leaf node represents the outcome. It has two popular attribute measures, such as Entropy and Gini.

$Entropy = \sum_{i=1}^{n} p(C_i)\log_2(p(C_i))$ (11.2)

$Gini = 1 - \sum_{i=1}^{n} p^2(C_i)$ (11.3)

#### 11.2.2.3 Naïve Bayes (NB)

Naïve Bayes is a probabilistic machine learning algorithm based on the Bayes Theorem that can be used in a wide variety of classification tasks. It is called Naive because it assumes that the occurrence of a certain feature is independent of the occurrences of the features. It is simple to use and does not require as much training data and it handles both continuous and categorical data. It is one of the simplest and most effective algorithms for building models that can make quick predictions (Mortezaghi et al., 2019).

$P(A|B) = \frac{P(B|A) * P(A)}{P(B)}$ (11.4)

where:
P(A|B) is posterior probability
P(B|A) is likelihood probability
P(A) is prior probability
P(B) is marginal probability

#### 11.2.2.4 K-Nearest Neighbor (KNN)

K-Nearest Neighbor is a non-parametric supervised learning algorithm which uses proximity to classify classifications or predictions about grouping of an individual data point (Li et al., 2012). It works by finding the distance between a query and all the samples in the data. In the KNN algorithm, the K value is initialized to the number of neighbors. Then, the distance between the current objects and the $k$ cluster centroids is calculated. Assign the current sample to that cluster to which it is closest. Compute the "cluster centers" of each cluster. These become the new cluster centers. These steps have to be repeated, until the convergence criterion is satisfied.
