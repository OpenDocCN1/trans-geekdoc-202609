## Conclusion

In this research, the performance of four supervised machine learning algorithms, namely Logistic Regression, Decision Tree, Naïve Bayes and K-Nearest Neighbor, were analyzed. The gastric cancer gene expression dataset was used to calculate the performance using Accuracy and Performance Metrics. From the results, it is observed that the DT algorithm performs better than the other. Out of 30 patients, 5 are identified to have diffuse gastric cancer, 17 were found to have intestinal gastric cancer, and 8 are found to be normal. In future, the DT algorithm can be modified to obtain more effective results. Also, the classification algorithms can be analyzed using other parameters such as cross-validation split.
