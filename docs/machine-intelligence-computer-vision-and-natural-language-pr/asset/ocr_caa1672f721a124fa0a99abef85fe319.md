The machine learning models used for creative purposes can be classified into two categories: (1) continuous; and (2) discrete or sequential models [7]. The continuous models are used to generate continuous artifacts as images whereas the sequential models are mainly used to generate artifacts such as text. The models or work topologies used in such application include Variational Auto-Encoders (VAE), autoregressive models, Generative Adversarial Networks (GANs), and sequence prediction models. For more technical details of these models, see [8].

These models have been successfully used to generate images from curated training data sets. Figure 1.2 is a sample image generated by the author using such program that uses text prompt to generate images and uses a second, "adversarial," to refine it [9]. The text prompt given in this case was "a cityscape in the style of Van Gogh."
