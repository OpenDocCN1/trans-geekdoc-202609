CNN [2] has several object detection algorithms, like R-CNN [3], Faster R-CNN [3], Mask R-CNN, Over Feat, Single Shot Detector (SSD), and YOLO series. YOLO is considered the best network in this chapter, because it is capable of obtaining high-accuracy detection and can run in real time. YOLO (You Only Once), as the name implies, needs only one propagation through a neural network for object detection. YOLO [3] uses CNN for object detection. This chapter adopted the YOLOv3 [4] network for work person recognition and some changes were made to apply the proposed system.

In a study [5] a pedestrian object detection system was set up YOLOv3. The YOLO algorithmic rule is trained on visualization in one category: the person category. It has achieved great precision and recall in comparison to plain YOLOv3. In a Lidar-LS-R-YOLOv4 approach, a paper used a device cloud map to measure data with deep learning to discover and section objects [6].
