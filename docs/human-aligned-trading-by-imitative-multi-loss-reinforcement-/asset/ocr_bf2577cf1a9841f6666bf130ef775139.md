# 2.2. Key model features

Since the advent of the DQN (Mnih et al., 2015), more researchers have been developing complex models by integrating individual model features for performance enhancement. Hessel et al. (2018) explored the idea of integrating some of the most prominent DQN extensions into a single model called Rainbow. They showed that such extensions were indeed largely complementary with the combined effects giving state-of-the-art results on a benchmark suite of 57 Atari 2600 games. They also found through ablation studies that prioritised replay and multi-step learning were the stand-out contributors to the final performance, a result we have taken note of. Hester et al. (2018) created a new paradigm – Deep Q-Learning from Demonstrations (DQfD) – which pre-trains a DQN by human demonstration data by minimising four sets of losses, a 1-step double Q-learning loss, an n-step double Q-learning loss, a supervised large margin classification loss, and a L2 regularisation loss, effectively ensuring that the network has an initial state bounded by the expert data. Hessel’s work helped us study closely individual modern features of DQNs and their applications whereas Hester’s work partly inspired the creation of our multi-loss function solution to align to human trading behaviours.

Learning with demonstration has long been associated with reinforcement learning. As early as in Lin (1992), Lin demonstrated that teaching his RL learner with demonstrations to play a game in a 2D dynamic environment would improve its score and help prevent the learning from falling into local minima. Modern day research saw imitation learning used in more complex settings with AlphaGo (Silver et al., 2016) probably being the most renowned one. A deep convolutional neural network within a reinforcement learning framework was trained using past games, also using supervised learning to predict the actions taken by experts, before further self-playing combined with planning rollouts. The feat was a domination over human players in the Go game. In finance, Liu et al. (2020) integrated imitation learning with a recurrent deterministic policy gradient model to balance the exploration and exploitation of the trading agent while trading intra-day stock index futures with promising results.

Another important component, multi-step learning, has been found to improve data efficiency by Yuan et al. (2019) who combined a new multi-step based return function with a classic DQN and its variants to play two Atari games. Also in the same Atari environment, Hernandez-Garcia and Sutton (2018) found – using a variety of models including DQNs – that increasing the number of steps n would consistently lead to a gain in overall performance – a result that we also observed though our own performance gain would reach saturation when n reached a certain value. Meng et al. (2021) used a policy network Deep Deterministic Policy Gradient to study both regular multi-step learning as well as a mixed multi-step learning where the Q value update is based on the average over different multi-step setups and showed that their new models addressed the overestimation problems seen in actor-critic algorithms.

# 3. Models and methods

# 3.1. Deep Q network

We follow the standard Markov Decision Process (MDP) framework (Sutton, 1988) to build our models. An MDP is defined by a tuple ⟨S, A, T, r, γ⟩, where S is a finite set of states, A is a finite set of actions, T(s, a, s′) = P[S_{t+1} = s′|S_t = s, A_t = a] is the stochastic transition function, and γ is the discount factor which we set to 0.95. Upon taking an action which is governed by a policy π, the agent receives a reward r(s, a) = 𝔼[R_{t+1}|S_t = s, A_t = a], R_{t+1} being the reward at t + 1, and reaches a new state s′. The goal of a DQN agent is to develop the optimal policy π mapping states to actions that maximises the total discounted future rewards Σ_{t=1}^{T} γ^{t-1} r_{t}, where T is the time step at which each episode completes.

While theoretically, the Q function could be learnt iteratively using the Bellman equation for each state–action pair, it is in reality estimated using a deep neural network with weights θ which is the idea behind a DQN (Mnih et al., 2015). The loss at time t as given in Eq. (1) is minimised while the network parameters are optimised by using stochastic gradient descent.

l(θ_t) = (r_t + γ_{t+1} max_a (Q(S_{t+1}, a, θ'_t)) − Q(S_t, A_t, θ_t))^2 (1)

One drawback in Eq. (1) though is the introduction of an upward bias, since the largest Q value returned by the target network is not necessarily the Q value of the best action determined by the current network, potentially leading to false positives. We therefore take the Double Q-learning approach (Hasselt, 2010) whereby a separate target network θ'_t with an identical architecture to that of the current network θ_t is used to compute the target of the loss function, whereas the current network which computes the actions is updated at every step, leading to an updated version of the loss function (2):

l(θ_t) = (r_t + γ_{t+1} Q(S_{t+1}, argmax_a Q(S_{t+1}, a, θ_t), θ'_t) − Q(S_t, A_t, θ_t))^2 (2)

After the separation, the standard procedure is to update the target network θ'_t less frequently than the current network θ_t, effectively making convergence easier (Mnih, 2013). However, we take the soft updating approach (Lillicrap et al., 2016) by having θ'_t slowly track θ_t in the learnt current network: θ'_t ← τθ_t + (1 − τ)θ'_t, where τ ≪ 1. The soft updating introduces a greater degree of stability similar to those experienced in supervised learning, while also reducing the problem of having to work with an update frequency parameter which may be given a suboptimal value as often experienced in the periodic updating approach.
