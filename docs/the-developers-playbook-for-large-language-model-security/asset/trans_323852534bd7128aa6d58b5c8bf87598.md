## 大型语言模型安全的开发者手册

大型语言模型（LLM）不仅正在塑造AI的发展轨迹，也正在开启一个全新的安全挑战时代。这本实用书籍将带你直面这些威胁的核心。作者史蒂夫·威尔逊是OWASP LLM应用Top 10项目负责人，聚焦于在使用LLM构建软件时必须处理的独特特性和漏洞。

这本面向开发者和安全团队的手册提供现实世界的指导和可操作的策略，帮助你应对LLM应用。无论你是在架构新应用还是为现有应用添加AI功能，这本书都是你掌握AI下一前沿安全格局的首选资源。

你将学习：

- 为什么LLM面临独特的安全挑战
- 如何应对使用LLM技术相关的风险
- 与LLM相关的威胁格局以及必须维护的关键信任边界
- 部署防御以防范顶级漏洞攻击的方法
- 改进软件开发流程以确保构建安全可靠AI应用的方式

史蒂夫·威尔逊是Exabeam的首席产品官，在AI和网络安全领域是公认的领导者。他拥有超过25年在Citrix、Oracle和Sun Microsystems等千亿美元科技公司构建软件平台的经验。史蒂夫是 _Java平台性能：策略与战术_ 的作者。
