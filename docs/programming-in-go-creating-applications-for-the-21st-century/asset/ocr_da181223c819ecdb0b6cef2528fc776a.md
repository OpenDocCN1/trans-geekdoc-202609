Using the strings.IndexFunc() to find the first whitespace character and slicing the string to but excluding character to get the first word is easy. When searching for the last whitespace character we must be careful because some whitespace characters are encoded as more than a single UTF-8 byte. We solve this problem by using the utf8.DecodeRuneString() function to give us the number of bytes occupied by the first character in the slice of string that starts where the last whitespace character begins. We then add this number to the last whitespace character's index position to jump over the last—so that we only slice the last character.
