The main() function begins by making sure that the Go runtime system will use all of the machine's processors. Then it creates the two channels to organize the processing. The lines channel will be sent each line from the log file and the worker goroutines will receive lines from this channel. We have given the lines channel a small buffer to reduce the likelihood of the worker goroutines being blocked waiting for lines. The done channel is used to keep track of when all the work is done, and since we only care about the occurrence of sends and receives rather than their values, we use empty structs. The done channel is buffered so that it doesn't block when a goroutine wants to announce that it has finished its work.

With the channels in place we create a new exported SafeMap is returned by the safemap.New() function as an exported SafeMap interface that can freely be passed around. We then start off the goroutine for reading lines from the files and then the goroutines for processing the lines. Then we wait for all the worker goroutines to be finished, which we can output the results.
