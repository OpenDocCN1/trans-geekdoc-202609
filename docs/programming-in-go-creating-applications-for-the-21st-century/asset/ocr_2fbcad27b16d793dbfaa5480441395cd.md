To avoid conflicts, third-party packages usually use domain names
to ensure uniqueness. For example, to use the FreeType package we would
use an import statement of "freetype.google.com/hg/freetype"
Of course, when it comes to using functions from the package, as we
only need to use the last component of the name—for example, font, err :=
type.ParseFont(fontdata). And in the unlikely event of a name collision
in the last component, we can use aliasing, for instance, import ftype
"freetype.google.com/hg/freetype", and in our code font, err :=
type.ParseFont(fontdata).

Third party packages are normally available for Go 1, but some might require a
ater version, or have multiple downloads available—for example, ones that
work with the cutting edge development versions of Go. In general, it is best
to always use a stable version of Go (e.g., Go 1), and use packages that are
compatible with it.

# 9.3. A Brief Survey of Go's Commands

Go installation for the gc compiler naturally includes compilers and linkers
(6g, l1, etc.), but also a number of other tools. The most useful of these is go,
which can be used as a build tool for our programs and packages, as a tool
for downloading and installing third-party packages and packages, as a tool
for executing unit tests and for benchmarking, as we saw earlier (§9.1.3,
414 ◀). Execute go for a full list of the commands available and go help
command for help on the specified command. There is also the godoc tool for
documentation ("The Go Documentation", 8 ◀.

In addition to the tools we have used in the book, there are several other tools\and go tool commands, a few of which we will mention here. One is vet
which does some error checking on Go programs, specifically on the fmt
package's print functions.

Another command is go fix. Sometimes a new release incorporates changes
the language—or more often, to library APIs—that invalidate existing code.

updated. We strongly recommend that go files are registered with a version
control system, and that they are all checked in, or at least backed up, before
running go fix. This will allow us to easily see what changes were applied and be
