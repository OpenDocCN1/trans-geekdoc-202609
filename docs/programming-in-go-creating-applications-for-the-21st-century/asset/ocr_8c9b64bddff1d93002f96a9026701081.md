The handleCommandHandler() function (not shown) uses the standard library’s flag
package to process command-line arguments. The pipeline works from the
inermost function call (source(files)) to the outermost (sink()). Here is the
pipeline laid out in an easy-to-understand way.

```
channel1 := source(files)
channel2 := filterSuffixes(suffixes, channel1)
channel3 := filterSize(minSize, maxSize, channel2)
sink(channel3)
```

The source() takes a slice of filenames and returns a channel of type
chan string that is assigned to the channel1 variable. The source() function sends
e filename in turn to the channel. The two filter functions take each filter
criteria and a chan string, and return their own chan string. In this example,
the first filter’s returned channel is assigned to channel2 and the second to
channel3. The filters iterate over the items in the channel they receive and send
each item that matches their criteria to the channel they have returned. The
sink() function takes a channel and iterates over its items, printing each one.
