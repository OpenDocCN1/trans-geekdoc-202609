type State struct {

The struct is similar to ones we have seen before. Note, though, that each field must begin with an uppercase letter to make it exported (public) since the json.Unmarshal() function can only populate exported fields. Also, Go's encoding/json package does not distinguish between different numeric types—it treats all JSON numbers as float64—the json.Unmarshal() function is smart enough to populate fields of other numeric types as necessary.

This method returns a State value as a JSON data string.

Most programs should not need type assertions and type switches; even when they are needed, their use should be fairly rare. One use case is where we are passing values that satisfy one interface and want to also satisfy another. (This topic is covered in Chapter 6; e.g., ➤ 6.5.289.) Another use case is when data from external sources must be converted into Go data types. For ease of maintenance, it is almost always best that such code is isolated from the rest of the program. This allows the program to work wholly in terms of Go data types and means that any maintenance needed due to changes to the format or types from external sources can be localized.
