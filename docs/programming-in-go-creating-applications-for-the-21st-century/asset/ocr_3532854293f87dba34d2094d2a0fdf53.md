The underlying value held by a reflect.Value can be changed if it is "setable". The settability can be checked by calling reflect.Value.CanSet(), which returns a bool.

```
presidents := []string{"Obama", "Bushy", "Clinton"}
liceValue := reflect.ValueOf(presidents)
value := sliceValue.Index(1)
value.SetString("Bush")
fmt.Println(presidents)
```

```
[Obama Bush Clinton]
```

Although Go strings are immutable, any item in a []string can be replaced by another string, and this is what we have done here. (Naturally, in this particular example, the easiest way to perform the change would be to use presidents[1] = "Bush", and not use introspection at all.)

It is not possible to change immutable values themselves, but we can replace an immutable value with another value if we have the original value's address.
