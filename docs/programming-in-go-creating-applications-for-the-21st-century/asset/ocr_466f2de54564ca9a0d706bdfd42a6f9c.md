# 2.2. Boolean Values and Expressions

Go provides two built-in Boolean values, true and false, both of type bool. Go
supports the logical and comparison operators, all of which produce a
 result; they are shown in Table 2.3.

Boolean values and expressions are used in statements (§5.2.1, ► 192), in the
conditions of statements (§5.2.2, ► 195), and sometimes in the conditions of
switch statements' care clauses (§5.3), as we will see in Chapter 5.

The binary logical operators (| || &&) use short-circuit logic. This means that
if we have b1 || b2 expression b1 evaluates to true, the result must be true
no what b2 is, it is returned and b2 is not evaluated. Similarly, if
have b1 && b2 and expression b1 evaluates to false, the result must be false,
false is returned and b2 is not evaluated.
