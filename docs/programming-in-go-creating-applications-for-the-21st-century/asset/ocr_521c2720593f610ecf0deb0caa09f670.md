```
attrValueRx := regexp.MustCompile(regexp.QuoteMeta(attrName)) +
  '=(?:("([^"]+)"|'([^\']+'))')
if indexes := attrValueRx.FindAllStringSubmatchIndex(attrs, -1); indexes != nil {
	for _, positions := range indexes {
	start, end := positions[2], positions[3]
	tif start == -1 {
		start, end = positions[4], positions[5]
		}
	fmt.Printf("%s\n", attrs[start:end])
	}
}
```

attrValueRx regex matches a safely-escaped आयु name followed by an equals sign and then a double or single-quoted string. The parentheses used for the alternation (|) would normally capture, but in this case we don't want them—since we do not want to capture the quotes—so we have made the parentheses noncapturing (?:). To show how it is done, instead of retrieving the matching strings we retrieve index positions. In this example there will be three pairs of ([start:end]) indices, the first pair for the whole match, the second pair for a double-quoted value, and the third for a single-quoted value. Of course, only one of the values will match, in which case the other's indices will be -1.

Just like the previous examples we have matched every nonoverlapping match in the string, and in this case we get an [1][]list of index positions (or nil). For each positions slice of ints, the whole match is the slice attrs[positions[0]:positions[1]]. The quoted string is either attrs[positions[2]:positions[3]] or attrs[positions[4]:positions[5]], depending on the type of quote used. The code begins with assertion that double quotes are used, but if this isn't the case (i.e., start = -1), then it uses the single-quote positions.

```
simplifyWhitespaceRx := regexp.MustCompile(`\s[p{L}][p{Z}]+\s*`)
text := strings.Trim(simplifyWhitespaceRx.ReplaceAllLiteralString(text, " "))
```
