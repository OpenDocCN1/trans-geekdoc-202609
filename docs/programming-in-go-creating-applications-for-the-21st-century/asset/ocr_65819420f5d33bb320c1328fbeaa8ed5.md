# 9.1. Custom Packages 417

As we mentioned in Chapter 5 ($5.6.2, 224 triangleleft), when a package is imported its init() functions are executed (if it has any). In some situations we don't want to make explicit use of a package, but do want its init() to be executed.

For example, if we are processing images we might want to register all the image formats that Go supports, but not actually use any functions from the packages that provide the formats. Here is the import statement for the imagetag1.go file (from Chapter 7's exercises).

```
import (
    "fmt"
    "image"
    "os"
    "path/filepath"
    "runtime"
    "image/gif"
    "image/jpeg"
    "image/png"
)
```

We import the image/gif, image/jpeg, and image/png packages purely to execute their init() functions (which registers their image format with the image package). Each of these packages is aliased to the blank identifier, Go will not complain about not making explicit use of any of them in code.

# 9.2. Third-Party Packages

The tool that we have used throughout the book to build programs and packages (e.g., the omap package) can also be used to download, build, and install third-party packages. (Of, this assumes that our computer is connected to the Internet.) A list of third-party packages is maintained at godboard.appspot.com/project. (An alternative approach is to download the source code—often obtained as a copy from a distributed version control system—and build the package ourselves locally).

To install one of the Go Dashboard's packages, first click its link to go to the package's home page. Wherever there be a command that shows how to download and install the package.

For example, if we were to click the Go Dashboard freetype-go.google.com/hg/freetype link, it would take you to code.google.com/p/freetype-go/ page which shows the installation command up front (at the time of this writing): get freetype-go.google.com/hg/freetype.

When it comes to third-party packages, go must, install them somewhere. By default it will use the first path listed in the GOPATH environment
