```
func FilledImage(width, height int, fill color.Color) draw.Image {
	if fill == nil { // We silently treat a nil color as black
	fill = color.Black
	}
	width = saneLength(width)
	heheight = saneLength(height)
	img := image.NewRGBA(image.Rect(0, 0, width, height))
	draw.Draw(img, img.Bounds(), &image.Uniform{fill}, image.ZP, draw.Src)
}
```

This is an convenience function that creates an image of the given size uniformly filled with the given color.

We begin by simply replacing a nil color with black, and ensuring that both dimensions are sensible. We create an image.RGBA (an image that defines its colors using red, green, blue, and alpha—transparency-values), and return it as a draw.Image, since we are only concerned with what we can do with it, not with its actual type happens to be.

The draw.Draw() function takes a destination image (of type draw.Image), a rect-angle that specifies where the drawing should be done (in this case the destination image), a source image to copy from (in this case an infinite-size image filled with the given color), the point where rectangle to be drawn in (image.ZP is the zero point, i.e., point (0, 0)), and how the drawing should be done. Here we have specified draw.Src so the function will simply copy the given color to every pixel in the target image. (The draw package also has a draw.Mask() function that supports some of the Porter-Duff operations).
