Addison-Wesley 出版的**开发者库系列**为实战型程序员提供了关于他们在日常工作中使用的最新编程语言和技术的独特、高质量的参考资料和教程。开发者库中的所有书籍均由资深技术从业者编写，他们非常擅长组织和呈现信息，使其对其他程序员具有实用价值。

开发者库的书籍涵盖了广泛的主题，从开源编程语言和数据库、Linux 编程、微软和 Java 到 Web 开发、社交网络平台、Mac/iPhone 编程以及 Android 编程。
