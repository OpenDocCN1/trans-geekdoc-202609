The americanise program's imports are from Go’s standard library. Packages can be nested inside one another without formality, as the io package's ioutil package and the path package's filepath package illustrate.

The bufio package provides functions for buffered I/O, including ones for reading and writing strings from to UTF-8 encoded text files. The io package provides low-level I/O functions—and the io.Reader and io.Writer interfaces need for the americanise() program. The io/ioutil package provides high-level file handling functions. The regexp package provides powerful regular expression support. The other packages (fmt, log, filepath, and strings) have been mentioned in earlier sections.
