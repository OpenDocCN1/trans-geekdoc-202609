# 2.3. Numeric Types

```
func n(places int) *big.Int {
    digits := big.NewInt(int64(places))
    unity := big.NewInt(0)
    ten := big.NewInt(10)
    exponent := big.NewInt(Add(digits, ten), nil)
    unity.Exp(ten, exponent, nil)
    pi := big.NewInt(4)
    left := arcot(big.NewInt(5), unity)
    left.Mul(left, big.NewInt(4))
    right := arcot(big.NewInt(239), unity)
    left.Sub(left, right)
    pi.Mul(pi, left)
    return pi.Div(pi, big.NewInt(exp, ten, nil))
}
```

The n() function computes a value for the unity variable $10^{digits+10}$ which we use as a scale factor so we can do all calculations using integers. The exponent adds ten digits to those given by the user, to round errors. We use Machin's formula with our modified arcot() function (not shown) that takes the unity variable as its second argument. Finally, we return the result divided by $10^{10}$ to reverse the effects of the unity scale factor.

To get the unity variable to hold the correct value we begin by creating four variables, all of type *big.Int (i.e., pointer to int; see §4.1, ④140). The unity and exponent variables are initialized to 0, the ten variable to 10, and the digits variable to the number of digits requested by the user. The unity computation is performed in a single line ①. The big.Int.Add() method adds to the number of digits. The big.Int.Exp() method is used to raise to the power of its second argument (digits+10). When used with a third argument—here big.Int.Exp(x, y, z) performs the computation $x^y \mod z$. Notice that we do not need to assign to unity; this is because most big.Int methods modify their receiver and return it, so, here, unity is modified to have the resultant value.

The rest of the computation follows a similar pattern. We set an initial value of pi to 4 and then compute the inner left-hand part of Machin's formula. We need to assign to left after creating it (⑥), since the big.Int.Mul() method stores the result in its receiver (i.e., in this case left variable) as well returning the result (which we can safely ignore). Next we compute the inner right-hand part and subtract the right from the left (leaving the result in left). Now we multiply pi (of value 4) by left (which holds the result of Machin's formula). The result but calculated scaled by unity. In the final line ⑤ we reverse the scaling by dividing the result (in pi) by $10^{10}$.
