This factory function requires two arguments: the name of the shape to be created and a custom option value in which optional shape-specific parameters can be specified. (The use of structs to make functions capable of handling multiple optional arguments was covered in Chapter 5: 5.6.1.3, 222 ◀) The function returns a shape that fulfills the Shaper interface, or if an invalid shape name is given, nil and an error. (Recall that the Shaper interface differs between the two packages implementations: 6.5.2.2, 294 ◀ and 6.5.2.3, 294 ◀) The particular shape created depends on the shape string that passed. There is no need to validate the color or radius since that is handled by the shapes.shapeFill() and the shapes.setRadius() function that are ultimately called by the NewRegularPolygon() and NewCircle() methods—and similarly for others.
