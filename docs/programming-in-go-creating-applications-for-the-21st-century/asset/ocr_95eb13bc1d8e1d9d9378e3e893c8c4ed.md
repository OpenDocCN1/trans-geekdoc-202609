An alternative (and slower) approach is to compare numbers as strings.

```
func EqualFloatPrec(x, y float64, decimals int) bool {
    a := fmt.Sprintf("%.*f", decimals, x)
    b := fmt.Sprintf("%.*f", decimals, y)
    return len(a) == len(b) && a == b
}
```

For this accuracy is specified as the number of digits after the dec-
point. The fmt.Sprintf()'s % formatting argument can accept a *
placeholder where it expects a number, so we create two strings based on
two given float64s, formatting each with the specified number of decimal
places. The magnitudes of the numbers differ, so will be the lengths of the
a and b strings (e.g., 592.85), which gives us a relatively fast short-circ-
ing equality test. (String formatting is covered in $3.5) ▶ 93.

```
func IntFromFloat64(x float64) int {
    if math.MinInt32 <= x <= math.MaxInt32 {
        whole, fraction := math.Modf(x)
        if fraction >= 0.5 {
            whole++
        }
        return int(whole)
    }
    panic(fmt.Sprintf("%g is out of the int32 range", x))
}
```
