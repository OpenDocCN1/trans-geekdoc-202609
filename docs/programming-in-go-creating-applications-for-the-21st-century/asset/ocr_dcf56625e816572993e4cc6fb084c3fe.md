If an .m3u file has been specified we attempt to read the entire file using the ioutil.ReadFile() function. This function returns all the file's bytes (as a []byte) and an error will be nil if the file was read without incident. If a problem occurred (e.g., the file doesn't exist or is unreadable), we use the log.Fatal() function to output the error to the console (as os.Stderr), and terminate the program with an error code of 1.

If the file is successfully read we convert its raw bytes to a string—this assumes that the bytes represent 7-bit ASCII or UTF-8 Unicode—and immediately passes the string to a custom readPlaylist() for parsing. The function returns a slice of Songs (i.e., a []Song). We then write the song data using a custom writePlaylist() function.

type Song struct {
  Title string
  Filename string
  Seconds int
}

Here we have defined a custom Song type using a struct ($6.4, 275) to provide convenient file-format-independent storage for the information about each song.

```
func readM3uPlaylist(data string) (songs []Song) {
  var song Song
  for line := range strings.Split(data, "\n") {
    line = strings.TrimSpace(line)
    if line == "" || strings.HasPrefix(line, "#EXTM3U") {
      continue
    }
    if strings.HasPrefix(line, "#EXTINT") {
      song.Title, song.Seconds = parseExtintLine(line)
    } else {
      song.Filename = strings.Map(mapPathDirSeparator, line)
    }
    if song.Filename != "" && song.Title != "" && song.Seconds != 0 {
      songs = append(songs, song)
      song = Song{}
    }
  }
  return songs
```
