```
func SaveImage(img image.Image, filename string) error {
    file, err := os.Create(filename)
    if err != nil {
        return err
    }

    defer file.Close()
    switch strings.ToLower(filepath.Ext(filename)) {
    case ".jpg", ".jpeg":
        return jpeg.Encode(file, img, nil)
    case ".png":
        return png.Encode(file, img)
    }

    return fmt.Errorf("shapes.SaveImage: %s has an unrecognized " +nn"suffix", filename)
}
```

This is the list of the exported convenience functions. Given an image that fulfills the image.Image interface—which includes any that fulfill the draw.Image interface that embeds an image. Image—the function attempts to save the image to a file with the given name. If the os.Create() call fails (e.g., due to an empty file or an I/O error), or if the filename has an unrecognized suffix, or if the image encoding fails, the function will return a non-nil error.

At the time of writing Go's standard library has support for reading and writing image formats: .png (Portable Network Graphics) and .jpg (Joint Photographic Experts Groups). Packages that support additional image formats are available from appspot.com/project. The jpeg.Encode() function has an extra parameter which can be used to fine-tune how the image is saved—we have passed nil which means the default settings will be used.
