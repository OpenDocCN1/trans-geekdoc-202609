This method creates a buffered reader for the io.Reader it is passed, and passes each line in turn to a parser function. As usual for text files, we handle io.EOF specifically, so that the last line is always read whether or not it ends with a newline. (Of course, this is rather liberal for this particular format.)

The file is read line by line using I-based line numbering, as is conventional. The first line is checked to see that it has a valid file type and hence, the line number (lino) begins at 2 when processing the actual invoice data.

Since we are working line by line and each invoice is represented by two or more lines (an invoice line or more ITEM lines), we need to keep track of the current invoice so we can add to it as each line is read. This is easily done because invoices are appended to the invoices slice, so the current invoice is always at the position invoices[len(invoices)-1].

When parseTxtLine() function parses an invoice LINE it creates a New invoice value and adds a pointer to that value to the invoices slice.

There are two techniques we can use if we want to append to a slice inside a function. The first technique is to pass a pointer to the slice and operate on the pointed-to. The second technique is to pass in the slice value and return the (possibly modified) slice back to the caller to assign to the original slice. The parseTxtLine() function uses the second technique. (We saw an example of this function earlier: $5.7, 244 ◀)

```go
func parseTxtLine(lino int, line string, invoices []*Invoice) ([]*Invoice, error) {
	var err error
	if strings.HasPrefix(line, "INVOICE") {
		var invoice *Invoice
		invoice, err = parseTxtInvoice(lino, line)
		invoices = append(invoices, invoice)
	} else if strings.HasPrefix(line, "ITEM") {
		if len(invoices) == 0 {
			err = fmt.Errorf("item outside of an invoice line %d", lino)
		} else {
			var item *Item
			item, err = parseTxtItem(lino, line)
			items := &invoices[len(invoices)-1].Items
			*items = append(*items, item)
		}
	}
	return invoices, err
}
```

This function takes a line number (lino), which is used for error reporting, the line to parse, and the slice of invoices that we want to populate.

If the line begins with the text “INVOICE”, we call the parseTxtInvoice() function to parse the line and create an Invoice value—and return a pointer to it. We then append this *Invoice to the invoices slice, and at the end return the invoices or nil or an error. Note that this point is incomplete—we only have its ID, customer ID, and due dates, whether it has been paid, and any note—but we have none of its items.

If the line begins with the text “ITEM”, we first check to see that there is a current invoice (i.e., the invoices slice is empty). If there is, we call the parseTxtItem() function to parse the line and create an Item value—and return a pointer to it. We must add the item to a pointer to the current invoice’s items and setting this pointer’s value (i.e., the [] *Item points to) to the result of appending the new *Item to of. From code invoices[len(invoices)-1].Items=append(invoices[len(invoices)-1].Items, item).

Any other lines (e.g., empty and form-free lines) are ignored. Incidentally, in this function would be faster if we made the “ITEM” case the first one since there are usually far more items than invoices or empty lines.
