Here we cast two float64s with initial values of 0. We add 0.1s to the first one and 0.2s to the second, so at the end should be number 1. However, the output shown below the code snippet illustrates, perfect accuracy for some floating-point numbers is not possible. In view of this we must be very careful when comparing floating-point numbers for equality or inequality using !=. Of course, there are cases where it is sensible to compare floating-point numbers for equality or inequality using the built-in operators—for example, when trying to avoid division by zero, as in, if y !=0.0 return x / y.

The "-%5t" format prints a bool left-aligned in a five characters wide—string formatting is covered in the next chapter: $3.5, ► 93.

```
func EqualFloat(x, y, limit float64) bool {
	if limit <= 0.0 {
		limit = math.SmallestNonzeroFloat64
	}
	return math.Abs(x-y) =
	(limit * math.Min(math.Abs(x), math.Abs(y)))
}
```

The EqualFloat() function compares two float64s to the given accuracy—or to the greatest accuracy the machine can achieve if a negative number (e.g., -1)
