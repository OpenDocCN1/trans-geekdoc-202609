Inside a template, actions are enclosed in double braces ({{). The {{range}} ...{{end}} action can be used to iterate over every item in a slice; here we have set each GIndex in the slice to the dot (.), that is to be the current item. We can use a struct's exported fields using their names, preceded, of course, with the dot to signify the current item. {{printf}} action works just like fmt.Printf() function, with spaces replacing the parentheses and argument-separating commas.

The text/template and html/template packages support a sophisticated language in their own right, with many actions, including iteration and conditional branching, support for variables and method calls, and many else besides. In addition, the html/template package is safe code injection.

# 9.4.3. Collection Packages

Slices are the most efficient collection type provided by Go, but sometimes it is useful or necessary to use a more specialized collection type. For many situations the built-in map is sufficient, but the Go standard library also provides the container package which contains various collection.

The container/heap package provides functions for manipulating a heap, where the heap must be a value of a custom type that satisfies the heap.Interface defined in the heap package. A heap (strictly speaking, a min-heap) maintains its values in an order such that the first element is always the smallest (or largest for a max-heap)—this is known as the heap property. The heap embeds the sort.Interface and adds Push() and Pop() methods. (We discussed the sort.Interface in §4.2.4, 160 ◄ and §5.7, 244 ▶)
