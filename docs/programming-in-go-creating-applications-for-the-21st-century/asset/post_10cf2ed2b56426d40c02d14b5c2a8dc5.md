```go
attrValueRx := regexp.MustCompile(regexp.QuoteMeta(attrName)) +
  '=(?:("([^"]+)"|('([^']+'))'
if indexes := attrValueRx.FindAllStringSubmatchIndex(attrs, -1); indexes != nil {
	for _, positions := range indexes {
		start, end := positions[2], positions[3]
		if start == -1 {
			start, end = positions[4], positions[5]
		}
		fmt.Printf("%s\n", attrs[start:end])
	}
}
```

attrValueRx regex matches a safely-escaped attribute name followed by an equals sign and then a double or single-quoted string. The parentheses used for the alternation (|) would normally capture, but in this case we don't want them—since we do not want to capture the quotes—so we have made the parentheses noncapturing (?:). To show how it is done, instead of retrieving the matching strings we retrieve index positions. In this example there will be three pairs of ([start:end]) indices, the first pair for the whole match, the second pair for a double-quoted value, and the third for a single-quoted value. Of course, only one of the values will match, in which case the other's indices will be -1.

Just like the previous examples we have matched every nonoverlapping match in the string, and in this case we get a []list of index positions (or nil). For each positions slice of ints, the whole match is the slice attrs[positions[0]:positions[1]]. The quoted string is either attrs[positions[2]:positions[3]] or attrs[positions[4]:positions[5]], depending on the type of quote used. The code begins with assertion that double quotes are used, but if this isn't the case (i.e., start = -1), then it uses the single-quote positions.

```go
simplifyWhitespaceRx := regexp.MustCompile(`\s[\p{L}][p{Z}]+\s*`)
```

```go
unaccentedLatin1Rx := regexp.MustCompile(
`[AAAAAAAÈÈÊIIIIÑÓÓÙÝàáççéêíïñðõøùý]+`)
unaccented := unaccentedLatin1Rx.ReplaceAllStringFunc(latin1,
	unaccentedLatin1)
```

The regexp simply matches one or more accented Latin-1 letters. The regexp.ReplaceAllStringFunc() function calls the passed as its second argument (with signature func(string) string) every time there is a match. The function gives the match's text as its argument and this text is replaced with the function returns (which can be an empty string).

```go
func UnaccentedLatin1(s string) string {
	chars := make([]rune, 0, len(s))
	for _, char := range s {
		switch char {
		case 'A', 'Á', 'Â', 'Ä', 'Ã', 'Ā':
			char = 'A'
		case 'É':
			chars = append(chars, 'A')
			char = 'E'
		case 'Ý', 'ÿ':
			char = 'y'
		}
		chars = append(chars, char)
	}
	return string(chars)
}
```

This simple function replaces the accented Latin-1 character with its unaccented cousin. It also replaces the æ ligature (which is a full character in some languages) with a and e. Of course, this example is artificial in this case we could just as easily write unaccented := UnaccentedLatin1(latin1) to perform the conversion.

## 3.7. Example: M3u2pls

In this section we will briefly review a short but complete program that reads arbitrary .m3u music playlist file given on the command line and outputs an equivalent .pls playlist file. The program makes a lot of use of the strings package and other material contained in this and previous chapters, as well as introducing a few new things among.

Here is an extract from the .m3u file:

```
[playlist]
#EXTINF:315,Space Oddity
Music/Singles.m3u
#EXTINF:-1,Changes
Music/Singles.m3u
```

The .pls format begins with the literal string [playlist]. Each song is represented by key-value entries for the filename, title and duration in seconds. The .pls format is slightly more elaborate than the .m3u format.

| Key | Value |
| :--- | :--- |
| Length | 251 |
| NumberOfEntries | 33 |
| Version | 2 |

The m3u2pls program (in file m3u2pls.go) expects to run with an .m3u file specified and writes an .pls file to os.Stdout (i.e., to the console). We can easily use redirection to send the .pls data into an actual file. Here is an example of the usage:

```
./m3u2pls Bowie-Singles.m3u > Bowie-Singles.pls
```

Here we tell the program to read the Bowie-Singles.m3u file and use console redirection to write the .pls format for the Bowie-Singles.pls. (Of course, it would be nice to be able to convert the other way too—and this is precisely what the exercise that follows this section involves)

We review almost the entire program, skipping only the imports.

```go
func main() {

	}

		log.Fatal(err)
	} else {
```
