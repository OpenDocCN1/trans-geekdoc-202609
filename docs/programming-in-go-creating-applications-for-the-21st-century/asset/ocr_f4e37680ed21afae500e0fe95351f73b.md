# 3.6. Other String-Related Packages

Table 3.9 The Strconv Package's Functions

| Syntax | Description/result |
|---|---|
| strconv.ParseBool(s) | true and nil if s is "1", "t", "T", "true", "True", or "TRUE"; false and nil if s is "0", "f", "F", "false", "False", or "FALSE"; false and an error otherwise |
| strconv.ParseFloat(s, bits) | A float64 and nil if s is parseable as a floating-point number, or an error; bits should be 64; use 32 if converting to a float32 |
| strconv.ParseInt(s, base, bits) | An int64 and nil if s is parseable as an integer, or an error; a base of means the base will be deduced from s (leading "0x" or "0X" means base 16, a leading "0" means base 8; otherwise base, or specific base (2–36) can be given; bits should be 0 if converting to an integer or the bit size fitting to a sized integer (e.g., 16 for int16) |
| strconv.ParseUint(s, base, bits) | A uint64 and nil—just the same as strconv.ParseInt() apart from being unsigned |
| strconv.Quote(s) | A string using Go’s double-quoted string syntax to represent string s; see also Table 3.1 (83) ◀ |
| strconv.QuoteRune(char) | A string using Go’s single-quoted string syntax to represent Unicode point char of rune, using an escape sequence for a non-ASCII character |
| strconv.QuoteToASCII(char) | A string using Go’s single-quoted string syntax to represent Unicode point char of type rune, using an escape sequence for a non-ASCII character |
| strconv.QuoteToASCII(s) | A string using Go’s double-quoted string syntax to represent string s, using escape sequences for non-ASCII characters |
| strconv.Unquote(s) | A string that contains the Go syntax single-quoted character or double-quoted or backtick-quoted string in s and an error |
| strconv.UnquoteChar(s, b) | A rune (the first character), a bool (whether the first character’s UTF-8 representation needs more than one byte), a string (the rest of the string), and an error; if b is set to a single or double quote that must be escaped
