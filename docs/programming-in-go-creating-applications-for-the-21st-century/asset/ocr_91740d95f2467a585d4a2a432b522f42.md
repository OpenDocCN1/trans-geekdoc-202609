An example that typically involves the use of replacements is where we have a list of names of the form forename1...forenameN surname and want to change the list to have the form surname,forename1...forenameN. Here is how we can achieve this using the regex package, with correct handling of accented and other non-English characters.

```
nameRx := regexp.Compile(`(\pL\.)?(?:\s|\pL\.)*)\s+(\pL*)`)
for i := 0; i < len(names); i++
names[i] = nameRx.ReplaceAllString(names[i], "${2}, ${1}")

```

The names variable is of type [] and initially holds the original names. Once the loop completes the names variable holds the modified names.

The regexp matches one or more whitespace-separated names(\pL) optionally followed by a period, followed by whitespace and a surname of one or more Unicode letters.
