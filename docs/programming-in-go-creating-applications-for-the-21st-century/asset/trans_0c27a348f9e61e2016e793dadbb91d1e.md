

## 1.3. 谁是谁？

我们将应用程序的功能拆分为任意数量的本地包，以保持一切的整齐模块化，我们将在第 9 章中看到这一点。

`import` 语句 (14, ➤) 从标准库导入了三个包：`fmt` 包提供了格式化文本和读取文本的函数 (3.5, ➤)，`os` 包提供了与平台相关的操作系统变量和函数，而 `strings` 包提供了处理字符串的函数 (3.6.1, ➤)。

Go 的基础类型支持常用的运算符（例如用于数值相加和字符串拼接的 `+`），而 Go 标准库通过提供一组与基础类型相关的函数包来补充了这些功能，就像这里导入的 `strings` 包一样。如此，我们也可以基于基础类型创建自定义类型，并为它们提供我们自己的方法——即自定义类型特定的函数。（我们将在 1.5, ➤ 中略微接触这一点，并在第 6 章中进行全面介绍）。

读者可能已经注意到程序没有分号；`import` 语句不是用逗号分隔的；而且语句的条件不需要括号。在 Go 中，块（包括函数和控制结构，例如 `if` 语句和 `for` 循环）使用大括号定界。缩进取代了分号；分号被放在编译器中，因此 Go 语句之间用分号分隔，除非我们想在同一行放置多个语句，否则我们不需要手动使用。分号、更少的逗号和括号让 Go 看起来更简洁，并且减少了打字量。

Go 函数和方法使用 `func` 关键字定义。`main` 包的 `main` 函数始终具有这种签名——它不接受参数也不返回结果。当 `main()` 完成时，程序将终止并向操作系统返回 0。自然地，我们可以随时根据需要退出并返回我们自己选择的值，正如我们在 (1.4, ➤) 中所示。

`main()` 函数中的第一个语句 (14, ➤, 使用 `:=` 运算符) 是 Go 术语中的短变量声明。此类语句同时声明并初始化一个变量。此外，我们不需要指定变量类型，因为 Go 可以从初始化值推断出来。在这种情况下，我们声明了一个类型为 `string` 的变量 `name`，得益于 Go 的强类型特性，我们只能给 `name` 赋值字符串。

与大多数语言一样，`if` 语句测试一个条件——在本情况下，是命令行输入了多少字符串——我们将在本章稍后部分看到更复杂的 `if` 语句语法 (1.6, ➤)，以及在后续 (5.2.1, ➤)。

`os.Args` 变量是一个切片的切片 (14, ➤)。数组、切片和其他集合数据类型将在第 4 章中介绍 (4.2, ➤)。我们只需要知道切片的长度可以使用内置函数 `len()` ，并且可以使用 Python 语法的子集通过 `[]` 运算符访问其元素。具体来说，`slice[n]` 返回切片的第 $n$ 个元素（从 0 开始计数），`slice[n:]` 返回另一个包含从第 $n$ 个元素到最后一个元素的切片。在“集合”章节中，我们将看到 Go 语法在该领域的完整通用性。在 `os.Args` 的情况下，切片在索引 0 处应该始终包含一个字符串（程序名称）。（所有索引都从 0 开始。）

如果用户输入了一个或多个命令行参数，且条件满足，我们将使用字符串 `args` 将所有参数连接成单个字符串 (14 <, ⊕)。在这种情况下我们使用赋值运算符 (`=`)，如果我们使用短变量声明运算符 (`:=`)，我们就会声明并初始化一个作用域限于 `if` 语句块的新变量 `args`。`Join()` 函数接收一个字符串切片和一个分隔符（可以是空的，即 `""`），并返回一个由切片中所有字符串组成的单个字符串，每个字符串之间用分隔符隔。在这里我们使用单个空格将它们连接起来。

最后，在最后一个语句 (14 -, ⊕) 中，我们打印 `Hello`、一个空格、变量中持字符串以及换行符。`fmt` 包有很多不同的变体，比如 `fmt.Println()` 可以整齐地打印接收到的任何内容，而其他如 `fmt.Printf()` 则使用占位符来对格式提供非常精细的控制。打印函数将在第 3 章介绍（§3.5—➢ 93）。

这里提供的 `hello` 程序展示的语言特性比传统程序多得多。随后的示例将继续这种风格，在保持示例尽可能短的同时涵盖更高级的特性。这里的想法是让人对该语言有一个基本的熟悉，并掌握构建、运行和实验简单程序，同时利用 Go 强大且新颖的特性。当然，本章介绍的所有内容将在后续章节中进行解释。

## 1.4. 大数字——二二维切片

`bigdigits` 程序（在 `bigdigits.go` 中）从命令行读取一个数字（字符串形式），并将相同的数字输出到控制台。在 20 世纪，许多用户共享一台高速打印机，每个用户的任务之前都有一个封面，显示一些细节，如用户名和正在打印的文件名。我们将分部分回顾代码：首先是 `import`，然后是静态数据，最后是处理。但现在，让我们来看一个示例运行，感受它是如何工作的。

每个数字由一个字符串切片表示，所有数字整体由一个切片的切片表示。在查看数据之前，这里是我们如何声明和初始化一维的字符串和数字切片：

```go
week := []string{"Friday", "Saturday", "Monday"}
lowPrimes := []int{2, 3, 5, 7, 11, 13, 17, 19}
```

对于字符串和数字的单维切片，我们可以使用大括号分隔的逗号列表来声明并初始化。对于 `lowPrimes`，我们可以使用相同的变量声明语法，但由于某种原因，我们使用了较长的形式来显示这种差异，这一点稍后会解释。由于切片本身可以是切片。

`bigdigits` 程序需要导入四个包。

```go
import (
	"fmt"
	"log"
	"os"
	"path/filepath"
)
```

`fmt` 包提供了格式化文本和读取文本的函数 (3.5, ➤)。`log` 包提供了日志函数。`os` 包提供了与平台相关的操作系统变量和函数，包括命令行参数的 `os.Args` (`[]string`)。而 `filepath` 包提供了处理文件名和路径的函数，可以跨平台工作。注意，对于逻辑上的包，我们在代码中访问它们时只需要指定名称（在本例 filepath）。
