Using the built-in make function or the composite literal syntax are the best ways to create slices, here we show how an approach that is not used in practice but makes the array–slice relationship obvious. The first statement creates a pointer to an array and takes a slice of the entire array. This will produce a slice with a length and capacity equal to the array's length, with every item set to its zero value, in this case an empty string. The second statement completes the setup of the slice by setting the individual items to the initial values we want, after which this slice is exactly the same as the one created in the previous snippet using the composite literal.
