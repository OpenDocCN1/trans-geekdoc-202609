The text/template and html/template packages can be used to create templates which can be used to generate textual output (e.g., HTML), based on data that is fed into them. Here is a tiny and very simple example of the text/template package in use.

```
type GIndex struct {
  Country string
  Index float64
}
gini := []GiniIndex{{"Japan", 54.7}, {"China", 55.0}, {"U.S.A.", 80.1}}
giniTable := template.New("giniTable")
giniTable.Parse(`<TABLE>
  {{range .}}\n    {{printf("<TR><td>%s</TD><td>%.1f%%</TD></TR>", .Country, .Index)}}
  {{end}}
</TABLE>`)
er := giniTable.Execute(os.Stdout, gini);
```

The template.New() function creates a new *Template with the given name. Template names are useful to identify templates that are in effect nested inside other templates. The template.Template.Parse() function parses a template (typically from an .html file), ready for use. The template.Execute() function executes the template sending the resultant output to the given io.Writer, and reading the data that should be used to populate the template from its second argument. In this example, we have output to os.Stdout and passed the gini slice of GiniIndex structs as the data. (We split the output over several lines to make it clearer).
