# Table 8.2 The Fmt Package's Scan Functions

Parameter r is an io.Reader; s is a string to read from; fs is a format string as used by the fmt package's print functions (see Table 3.4,95 ➤) args stands for one or more pointers (i.e., addresses) to populate. All scan functions return the number of items successfully parsed (i.e., populated) and either nil or an error.

| Syntax | Description |
|---|---|
| fmt.Fscan(r, args) | Reads r for successive space- or newline-separated values to populate args |
| fmt.Fscan(r, fs, args) | Reads r for successive space-separated values specified by the fs format to populate args |
| fmt.Fscanln(r, args) | Reads r for successive space-separated values to populate args and expects a newline or io.EOF at the end |
| fmt.Scan(args) | Reads os.Stdin for successive space-separated values to populate args |
| fmt.Scanf(fs, args) | Reads os.Stdin for successive space-separated values as specified by the fs format to populate args |
| fmt.Sscanln(args) | Reads os.Stdin for successive space-separated values to populate args and expects a newline or io.EOF at the end |
| fmt.Sscan(s, args) | Reads s for successive space- or newline-separated values to populate args |
| fmt.Sscanf(s, fs, args) | Reads s for successive space-separated values as specified by the fs format to populate args |
| fmt.Sscanln(s, args) | Reads s for successive space-separated values to populate args and expects a newline or io.EOF at the end |
