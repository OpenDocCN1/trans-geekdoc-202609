# Chapter 8. File Handling

The format for each invoice is an Invoice line, then one or more ITEM lines, and finally a form-feed character. Each line (whether invoices or their items) has the same essential structure: a word identifying the type of line, a sequence of space-separated key=values, and optionally, a colon-space followed by note text.

# 8.1.3.1. Writing Plain Text Files

This method begins by creating a buffered reader to operate on the file it is passed. It is essential that we defer the flushing of the buffer to guarantee that everything we write really gets written to the file (unless an error occurs).

Rather than checking every write with code of the if _, err := fmt.Fprintf(bufferedWriter, ...); err != nil { return err } we have created a function literal that provides two simplifications. First, the write() function ignores the number of bytes written by the fmt.Fprintf() function returns. Second, the function captures the bufferedWriter so we don't have to explicitly mention it in our code.
