# 3.7. Example: M3u2pls

Like most cross-platform programming languages and libraries, Go uses Unix-style directory separators internally on all platforms, even on Windows. However, for user-visible output and for human-readable data files, we prefer to use the platform-specific directory separator. To achieve this we can use the filepath.Separator which holds the / character on Unix-like systems and the \ character on Windows.

In this example we do not know whether the paths we are reading forward slashes or backslashes, so we have to cater for both. However, if we know for sure that a path uses forward slashes we can use the filepath.Slash() function on it: This will return the path unchanged on Unix-like systems, but will replace forward slashes with backslashes on Windows.

```
func writePlusPlaylist(songs [])Song {
	fmt.Println("[playlist]")
	for i, song := range songs {
		i++
		fmt.Printf("File=%d\\s\\n", i, song.Filename)
		fmt.Printf("Title=%d\\s\\n", i, song.Title)
		fmt.Printf("Length=%d\\d\\n", i, song.Seconds)
	}
	fmt.Printf("NumberOf=%d\\nVersion=2\\n", len(songs))
}
```

This function writes out the songs in .pls format. It writes the data to os.Stdout (i.e., to the console), so file redirection is used to get the output into a file.

The function begins by writing the section header ([playlist]), and for every song it writes the song's filename, title, and duration in seconds, each on their own lines. Since each key must be unique a number is appended to each line, starting from 1. And at the end the two lines of metadata are written.
