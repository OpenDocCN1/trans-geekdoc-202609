In most cases readers operate on files, so here we might imagine the reader variable was created by calling bufio.NewReader() on the reader returned by os.Open() call—everything we saw in the first character's example ($1.6, 29 ◄). However, in this case the reader was created to operate on a string:

```
reader := strings.NewReader("Café")
```

*The strings.Reader returned by strings.NewReader() offers a subset of the functionality of bufio.Reader; in particular it provides the strings.Read(), strings.Reader.ReadByte(), strings.Reader.ReadRune(), strings.Unread(), and strings.Reader.UnRune() methods. The ability to operate on values that has a particular interface (e.g., provide a ReadRune() method), rather than values of particular types, is a very powerful and flexible feature of Go, and is covered much more in Chapter 6.

# 3.6.2. The strconv Package

The strconv package provides many functions for converting strings into other types and other types. The package's functions are listed in Tables 3.8 and 3.9 ► 114–115; see also the fmt package's parse and scan functions, $3.5, $93 ◄ and $8.2, ► 383). Here we will review a few illustrative examples.

One common requirement is to convert a string representation of a true value into a bool. This can be done using the strconv.ParseBool().

```
for _, truth := range []string("1", "t", "TRUE", "false", "F", "0", "5") {
	if b, err := strconv.ParseBool(truth); err != nil {
		fmt.Printf("%v\n", err)
	} else {
		fmt.Print(b, " ")
	}
}
fmt.Println()
```
