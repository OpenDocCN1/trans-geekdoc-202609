```
return minimum
}
```

This function takes at least one value (first) and zero or more other values (rest). We use the interface{} type since that it can be used for any type in Go. We initially assume that the first value is the smallest and then iterate over the rest of the values. Whenever we find a value that is smaller than the current minimum we select the minimum to this value. And at the end we return the minimum—as an interface{}, hence the need to convert it to a built-in type at the Minimum() call using an unchecked type assertion.

We still have duplicate code—in each case's statement's block—but if there were a lot of duplicate code we simply set a Boolean in each case (e.g., change = true), and then follow the switch with an if statement that contained all the common code.

Clearly, using this Minimum() function is less efficient than type-specific minimum functions. However, it is worth knowing the technique because it is useful for cases where the testing overheads and conversion inconvenience are outweighed by the advantage of having to define the function only once.

The problem of duplicate code within a generic function isn't so easy to work around one or more of the interface{} arguments are actually slices. For example, here is a function that, given a slice and an item of the same type as the slice's items, returns the index position of the first occurrence of the item in the slice—or -1 if the item isn't in the slice.

```
func Index(xs interface{}, x interface{}) int {
switch slice := xs.(type) {
case []int:
  for i, y := range slice {
    if y == x.(int) {
      return i
    }
  }
case []string:
  for i, y := range slice {
    if y == x.(string) {
      return i
    }
  }
}
return -1
}
```
