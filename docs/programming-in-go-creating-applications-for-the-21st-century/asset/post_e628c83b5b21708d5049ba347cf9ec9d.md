When Go prints pointers to structs it prints the dereferenced struct prefixed with the & address of operator to indicate that it is a pointer. The part of the code snippet where the agnes and julia pointers are created illustrates the following equivalence when the type can be initialized using braces:

```go
new(Type) == &Type{}
```

Both these syntaxes allocate a new zeroed value of the given type and return a pointer to the value. If the Type isn't a type that can be initialized using braces we can use only the built-in new()(). And, of course, we don't have to worry about the value's lifetime or delete it, since Go's memory management system takes care of all that for us.

One advantage of using the &Type() syntax for structs is that we can specify initial fields as we did here when creating the augusta pointer. (We can specify only selected fields and leave the others at their zero values as we will see later; $6.4, ► 275.)

In addition to values and pointers, Go has reference types. (Go has interfaces, but for almost all purposes we can consider an interface to be a kind of reference; interfaces are covered later; $6.3, ► 265.) A variable of reference type refers to a hidden value in memory that stores the actual data. Variables holding reference types are cheap to pass (e.g., 16 bytes for a slice and 8 bytes for a 64-bit machines), and are used with the same syntax as a value (i.e, we don't need to take a reference type's address or dereference it).

Once we reach the stage where we need to return more than four or five values from a function or method, it is best to pass a slice if the values are homogeneous, or to use a pointer to a struct if they are heterogeneous. Passing a slice, or a pointer to a struct, is cheap, and allows us to modify the data in-place. We will look at a couple of small examples to illustrate these points.

```go
grades := []int{87, 55, 43, 71, 60, 43, 32, 19, 63}
inflate(grades, 3)
fmt.Println(grades)
```


Here we perform an operation on all the numbers in a slice of ints. Maps and slices are reference types, and any changes made to a map or a slice's—whether directly or inside a function they have been passed to—are visible to all the variables that refer to them.

## 4.1. Values, Pointers, and Reference Types

```go
func inflate(numbers []int, factor int) {
  for i := range numbers {
    numbers[i] *= factor
  }
}
```

The grades slice is passed in as the parameter numbers—but unlike we pass values, any changes applied to numbers are reflected in grades since they both refer to the same underlying slice.

Since we want to modify the slice's values in-place we have used a loop counter to access each item. We didn't use a for index, item ... loop that gets a copy of each item from the slice it operates on—would result in the copy being multiplied by the factor each time and then discarded, leaving the original unchanged. We could have used a for loop familiar in other languages (e.g., for i := 0; i < len(numbers); i++), but instead we have used the more convenient for index := range syntax. (All the loop syntaxes are covered in the next chapter; 5.3, 203.)

Let's imagine we have a rectangle that stores a rectangle position as its top-left and bottom-right x, y coordinates, and its fill color. We could represent the rectangle's data using a struct.

```go
type rectangle struct {
  x0, y0, x1, y1 int
  color.RGBA
}
```

Now we create a value of the rectangle type, print it, resize it, and then print it again.

```go
rect := rectangle{4, 8, 20, 10, color.RGBA{0xFF, 0, 0, 0xFF}}
fmt.Println(rect)
resizeRect(&rect, 5, 5)
fmt.Println(rect)
```

```go
func resizeRect(rect *rectangle, Awidth, Aheight int) {
    (*rect).x1 += Awidth // Ugly explicit dereference
    rect.y1 += Aheight // automatically dereferences structs
```

The function's statement uses an explicit dereference just to show what is happening under the hood. (*rect) refers to the actual value that the pointer points to, and the .x1 refers to the rectangle's x1 field. The second statement shows the idiomatic way to work with struct values—or pointers to structs—in the latter case relying on Go for the dereferencing for us. This works Go’s .(dot) selector operator automatically dereferences pointers to structs.

## 4.2. Arrays and Slices

An array is a fixed-length sequence of the same type. Multidimensional arrays can be created by nesting arrays.

The length of an array is given by the len() function. Since arrays of fixed size their capacity is always equal to their length, for arrays the cap() function returns the same number as the len() function.

Go guarantees that all array are initialized to their zero value if they are not explicitly initialized—or only partially initialized—when they are created, as buffer, and grid2 variables illustrate.
