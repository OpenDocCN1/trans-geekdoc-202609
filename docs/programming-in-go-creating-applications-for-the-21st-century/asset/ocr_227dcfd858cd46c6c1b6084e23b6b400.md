# Chapter 8. File Handling

```
func unpackTarFiles(reader *tar.Reader) error {
    for {
        header, err := reader.Next()
        if err != nil {
            if err == io.EOF {
                return nil // OK
            }
            return err
        }
        filename := sanitizedName(header.Name)
        switch header.Type {
        case tar.TypeDir:
            if err := os.MkdirAll(filename, 0755); err != nil {
                return err
            }
        case tar.TypeReg:
            if err := unpackTarFile(filename, header.Name, reader); err != nil {
                return err
            }
        }
        return nil
    }
}

```

The function has an infinite loop that iterates over each tarball until io.EOF is reached (or until an error occurs). The tar.Next() method returns the first—or next—tarball entry's *tar.Header, or reports an error. If the error is EOF means that we have finished so we return a nil error value.

If a *tar.Header is successfully obtained we create a sanitized filename based on the header's Name field. Then we switch declining on the entry's type flag. For this simple example we only consider directories and regular files, but in fact, tarballs can contain other entries (e.g., symbolic links).

If the entry is for a directory we create the directory just the same as we did for directories in .zip files (◄). And if the entry is for a file we pass on to the work to a helper function.
