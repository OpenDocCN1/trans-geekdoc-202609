# 4.3.3. Modifying Maps

Items, that is, key-value pairs, can be inserted into maps and deleted from maps. And any given key's value can be changed. Here are a few examples.

```
fmt.Println(len(populationCity), populationCity)
delete(populationCity, "Shanghai") // Delete
fmt.Println(len(populationCity), populationCity)
population["Karachi"] = 11620000 // Update
fmt.Println(len(populationCity), populationCity)
population["Beijing"] = 11290000 // Insert
fmt.Println(len(populationCity), populationCity)
```

| map [Shanghai:13680000 Mumbai:12690000 Istanbul:12610000 Karachi:10620000] |
| map [Mumbai:12690000 Istanbul:12610000 Karachi:10620000] |
| map [Mumbai:12690000 Istanbul:12610000 Karachi:11620000] |
| map [Mumbai:12690000 Istanbul:12610000 Karachi:11620000 Beijing:11290000] |

The syntax for inserting and updating map items is identical: If an item with the given key isn't present, a new item with the given key and value will be inserted; and if an item with the given key is present, its value will be set to the given value, and the original value will be discarded. And if we try to delete an item which isn't in the map, Go will safely do nothing.

Keys cannot be changed as such, but the effect of changing a key can be achieved like this:

```
oldKey, newKey := "Beijing", "Tokyo"
value := populationCity[oldKey]
delete(populationCity, oldKey)
populationCity[newKey] = value
fmt.Println(len(populationCity), populationCity)
```

| 4 map [Mumbai:12690000 Istanbul:12610000 Karachi:11620000 Tokyo:11290000] |

We retrieve the key's value, which has the old key, and create a new item with the new key and with the old key's value.
