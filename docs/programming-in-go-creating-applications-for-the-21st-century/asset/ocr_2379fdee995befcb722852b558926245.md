In earlier chapters we saw several examples of reading, creating, and writing text files. In this chapter we will look in more detail at Go's file handling facilities and in particular how to read and write files in standard formats (such as XML and JSON), as well as custom plain text and binary formats.

Since we have covered all of Go's language features (from creating programs with our own custom packages and with third-party packages—which is covered in the next chapter), we are free to use all the facilities that Go provides. We take advantage of this freedom and, in some cases we make more advanced use of closures ($5.6.3, 225 ➤) to avoid repetitive code, and Go's support for object orientation, in particular adding methods to functions.

This chapter's focus is on files rather than directories or the file system generally. For directories, the previous chapter's duplicates example ($7.2.5,349 ➤) shows how to iterate over the files and subdirectories of a directory using the filepath.Walk() function. In addition, the standard library's os.File provides methods for reading the names in a directory (os.File.Readdirnames()), and for retrieving os.FileInfo values for each item in a directory (os.File.Readdir()).
