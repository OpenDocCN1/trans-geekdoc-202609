# 5.5. Defer, Panic, and Recover

The defer statement is used to defer the execution of a function or method (or of an anonymous function created on the spot) until just before the enclosing function or method returns, after the return values (if any) have been evaluated. This makes it possible to modify a function’s named return values inside a deferred function (e.g., by assigning them the = assignment operator). If more than one defer statement is used in a function or method, they are executed in FIFO (Last In First Out) order.

The most common uses of a defer are to ensure that a successfully opened file is closed when we finish with it, to close channels that are no needed, or to catch panics.
