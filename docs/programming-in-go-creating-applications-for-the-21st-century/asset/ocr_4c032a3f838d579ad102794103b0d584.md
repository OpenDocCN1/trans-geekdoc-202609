# 3.6. Other String-Related Packages

Table 3.7 The Strings Package's Functions #2

Variable r of type unicode.Special Case is used to specify Unicode rules (advanced).

| Syntax | Description/result |
| --- | --- |
| strings.Replace(s, old, new, i) | A copy of s with every nonoverlapping occurrence of old string replaced by new string if i is -1, or at most i replacements otherwise |
| strings.Split(s, t) | The [string] that results in splitting s on t as many times as t occurs in s |
| strings.SplitAfter(s, t) | Works strings. Split() only the separator is kept in the resultant strings (see text) |
| strings.SplitAfterN(s, t, i) | Works strings. SplitN() only the separator is kept in the resultant strings |
| strings.Split(s, t, i) | The [string] that results in splitting s on t, i - 1 times |
| strings.Title(s) | A copy of s with the first letter of every word titlec |
| strings.ToLower(s) | A lowercased copy of s |
| strings.ToLowerSpecial(r, s) | A lowercased copy of s, prioritizing the rules in r (advanced) |
| strings.ToTitle(s) | A title-cased copy of s |
| strings.ToSpecial(r, s) | A title-cased copy of s, prioritizing the rules in r (advanced) |
| strings.ToUpper(s) | An uppercased copy of s |
| strings.ToUpper(r, s) | An uppcased copy of s, prioritizing the rules in r (advanced) |
| strings.Trim(s, t) | A copy of s with the characters in t removed from both ends |
| strings.TrimFunc(s, f) | A copy of s with the characters for f returns true from both ends |
| strings.TrimLeft(s, t) | A copy of s with the characters in t removed from the start |
| strings.TrimLeftFunc(s, f) | A copy of s with the characters for f returns true from the start |
| strings.TrimRight(s, t) | A copy of s with the characters in t removed from the end |
| strings.TrimRightFunc(s, f) | A copy of s with the characters for f returns true from the end |
| strings.TrimSpace(s) | A copy of s with whitespace removed from both ends |
