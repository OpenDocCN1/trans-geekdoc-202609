The import statement (14, ➤) imports three packages from the standard library. the fmt package provides functions for formatting text and for reading text ($3.5,  ➤), the os package provides platform-independent operating-system variables and functions, and the strings package provides functions for manipulating strings ($3.6.1,  ➤).

Go's fundamental types support the usual operators (,, + for numeric addition and string concatenation), and the Go standard library supplements these by providing packages of functions with the fundamental types, as the strings package imported here. it is also possible to create our custom types based on the fundamental types and to provide our own methods—that is, custom type-specific functions—for them. (We will get a taste of this in $1.5, ➤, with full coverage in Chapter 6).

The reader may have noticed that the program has no semicolons; the imports are not comma-separated, and that if the statement's condition does not require parentheses. In Go, blocks, including function and control structures (e.g., for if statements and for loops), are delimited using braces. Indentation is used instead of semicolons; they are put in the compiler, so Go states are separated by semicolons, we don't have to use ourselves unless we want to put multiple statements on the same line. Semicolons and fewer commas and parentheses give Go a lighter look and require less typing.

Go functions and methods are defined using the func keyword. The main package's main function always has the signature—it takes no arguments and returns nothing. When main() finishes the program will terminate and return θ to the operating system. Naturally, we can exit whenever we like and return our own choice of value, as we see ($1.4, ➤).

The first statement in the main() function (14, ➤, using the : = operator) is a short variable declaration in Go terminology. Such a statement declares and initializes a variable at the same time. Furthermore, we don't need to specify the variable type because Go can deduce from the initializing value. In this case we have declared a variable who of type string, and thanks to Go's strong typing we may only assign strings to whom.

As with most languages the if statement tests a condition—in this case, how many strings were entered on the command-line—which we will see a more sophisticated if statement syntax later in this chapter ($1.6, ➤), and further in ($5.2.1, ➤).
