# 5.2. Branching

```
case ".tgz":
    return TarFileList(file)
case ".zip":
    return ZipFileList(file)
```

This switch statement has both a statement and an expression. In this case the expression is of type string so case's expression list must contain one or more comma-separated strings to match. We have used the fallthrough statement to ensure that all tar files are processed by the function.

The suffix variable's scope extends throughout the switch statement to every case (and would extend to the default case if one was present), and at the end of the switch statement since that point the switch ceases to exist.

```
switch Suffix(file) { // Canonical ✓
    case ".gz":
        return GzipFileList(file)
    case ".tar", ".tar.gz", ".tgz":
        return TarFileList(file)
    case ".zip":
        return ZipFileList(file)
```

Here is a more compact and canonical version of the preceding switch statement: Instead of a statement and an expression we have simply used an expression: The Suffix() function (that we saw earlier; 194 ◄) returns a string. Instead of using fallthrough statements for tar files, we have used comma-separated list of all the matching suffixes as that clause's expression list.

Go's expression statements are much more versatile than those provided by C, C++, and Java, and in many cases can be used instead of—and are more compact—if statements.
