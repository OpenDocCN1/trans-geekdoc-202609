```
infoChan := make(chan fileInfo, maxGoroutines*2)

```

The main() function accepts a directory to start the processing from and orchestrates all work. It begins by creating a channel for passing fileInfo values (which we will look at shortly). We have buffered the channel because experiments showed that this consistently improved performance.

Next, the function executes the findDuplicates() function in a goroutine, and then calls the mergeResults() function that reads the infoChan channel until it is closed. Once the merge data is returned, the results are output.

The program's goroutines and flow of communications are illustrated in Figure 7.8. The figure's results channel is for values of type fileInfo; these values are sent to the infoChan by a "walker" function (of type filepath.WalkFunc) that we use the filepath.Walk(). The filepath.Walk() function is itself called by the findDuplicates() function. The results are received by the findDuplicates() function and by the walker function. The standard library's filepath.Walk() function might create its own goroutines (e.g., to process each directory), although how it actually works is an implementation detail.

```
type fileInfo struct {
shal []byte
size int64
path string
}
```

This type is used to summarize the data for each file. If two files' SHA-1s and sizes are the same they are considered duplicates—no matter what their paths or filenames are.

```
func findDuplicates(infoChan chan fileInfo, dirname string) {
waiter := &sync.WaitGroup()
filepath.Walk(dirname, makeWalkFunc(infoChan, waiter))
waiter.Wait() // Blocks until all the work is done
close(infoChan)
}
```

This function calls the filepath.Walk() function to walk the directory's tree (starting at dirname), and for every file and directory it calls the filepath.WalkFunc function it is passed as its second argument.
