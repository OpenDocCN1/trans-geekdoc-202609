This involves adding a couple more items to the statistics struct and adding two new functions to perform the calculations. A solution is in the file ans/statistics.go; this needed about 40 extra lines and made use of the built-in append() function (§4.2.3, ► 156) to add numbers to a slice.

The standard deviation is the easiest to write—just requires the use of some functions from the math package and can be done in fewer than ten lines. We use the formula $\sigma = \sqrt{\frac{\sum(x-ar{x})^2}{n-1}}$, where $x$ is each number, $ar{x}$ is the mean, and $n$ is the number of numbers.

The mode is the most frequently occurring number—or numbers, if two or more are equally the frequently occurring. However, we return no mode if all of the numbers occur with the same frequency. Mode is trickier than the standard deviation, and needs about 20 lines of code.
