```
func XMLInvoicesForInvoices(invoices []*Invoice) *XMLInvoices {
	xmlInvoices := &XMLInvoices{
		Version: version,
		Invoice: make([]*XMLInvoice, 0, len(invoices)),
	}
	for _, invoice := range invoices {
		xmlInvoices.Invoice = append(xmlInvoices.Invoice, invoice)
	}
	return xmlInvoices
}
```

This function takes an []*Invoice and returns an *XMLInvoices that has all the
data converted to *XMLItems (and containing *XMLItems rather *Items),
relying on the XMLInvoiceForInvoice() function to do all the work.

We never have to populate an xml.Name fields (unless we want to use
namespaces),so here we create the <XMLInvoices> tag we only populate the
Version field to ensure our <INVOICES> tag has a version attribute—for example-
ple, versions="100". We have also set the Invoice field to be an empty
field with sufficient capacity for all the invoices. This isn't strictly necessary, but
bis potentially more efficient than leaving the field's initial value as nil, since it
means the built-in-append() function will never have to allocate memory and copy
data to grow the slice behind the scenes.
