# Chapter 9. Packages

The exec package is used to run external programs. This can also be done using
tos.StartProcess() function, and the exec.Cmd type is much more convenient
use.

The flag package provides a command-line parser. It accepts X11-style options
(e.g,--width, GNU-style--w and --width). The package produces a very basic
usage message and does not provide any validation beyond a value's type. (So,
t package can be used to specify an in option, but not what values are acceptable.) Several alternatives are available from the Go Dashboard (godashnboard.appspot.com/project).

The log package provides logging information (by default to
stdout, and terminating the program or panicking with any io.Writer
log package's output destination can be changed to any io.Writer
using log.SetOutput() function messages are output in the format of a
timeestamp and then message; the timestamp can be eliminated by calling
log.SetFlags(0) before the first log function call. It is also possible to createcustom loggers using the log.New().

The math/rand package provides many useful pseudo-random number generator functions including rand. Int() returns a random int and rand.Intn()eturns a random int in the range [0, n). The crypto/rand package has a
unction for producing cryptographically secure-random numbers.

The regex package provides a very fast and powerful regular expression engine
the supports the RE2 engine syntax. We have used this in several of
the book's examples, although we have deliberately used simple regexps and
not used the package's full power so as to stay off-topic. The package was
introduced earlier ($3.6.5, 120 ◄)

The sort package provides convenience functions for sorting slices of ints,
float64s, and strings, and for performing fast (binary copy) searches on
slices. It also provides generic.Sort() and sort.Search() functions
hat can be used for custom data. (See, for example, §4.2.4, 160 ◄ Table 4.2,
161 and §5.6.7, 228 ◄)

The time package has functions for measuring time and parsing and for-
dating, date/time, and values. The time.After() function can be
to send the current time on the channel it returns after a specified
ofoseconds have passed, as we saw in an earlier example (332 ◄).
time.Tick() and time.Ticker functions can be used to provide a channel to
ich a “tick” is sent repeatedly at a specified interval. The time.struct has
methods for providing the current time, for formatting a date/time as a string,
an for parsing date/times. (We saw time.Time examples in Chapter 8, e.g.,
375 ◄)
