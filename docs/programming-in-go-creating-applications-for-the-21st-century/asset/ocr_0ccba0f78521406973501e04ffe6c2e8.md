# 3.6. Other String-Related Packages

Table 3.19 The *regexp.Regexp Type's Methods #2

Variable rx is of type *regexp.Regexp; s is the string to match; b is the []byte to match.

| Syntax | Description/result |
| --- | --- |
| rx.FindSubmatch(b) | A []byte with the leftmost match and captures or nil |
| rx.FindSubmatch-Index(b) | A []byte with the leftmost match and captures or nil |
| rx.LiteralPrefix(b) | The possibly empty prefix string that the regex must begin with a bool indicating whether the whole regex is a literal string |
| rx.Match(b) | true if the regex matches b |
| rx.MatchReader(r) | true if the regex matches r of type io.RuneReader |
| rx.MatchString(s) | true if the regex matches s |
| rx.NumSubexp() | How many parenthesized groups the regex has |
| rx.Replace-All(b, br) | A []byte is a copy of b with every match replaced by br of type []byte with $ replacements (see text) |
| rx.ReplaceAllFunc(b, f) | A []byte is a copy of b with every match replaced with the return value of a call to function f of type func([]byte) and whose argument is a match |
| rx.ReplaceAll-Literal(b, br) | A []byte is a copy of b with every match replaced with br of type []byte |
| rx.ReplaceAll-LiteralString(s, sr) | A string is a copy of s with every match replaced with sr of type string replacements |
| rx.ReplaceAll-String(s, sr) | A string is a copy of s with every match replaced with sr of type string $ replacements (see text) |
| rx.ReplaceAll-StringFunc(s, f) | A string is a copy of s with every match replaced with the return value of a call to function f of type func(string) string and whose argument is a match |
| rx.String() | A string containing the regex pattern |
| rx.Subexp-Names() | A []string (which must not be modified), containing the names of all the named subexpressions |
