This is the complete implementation of the custom IntOption type plus the supporting unexported name() function. Since the OptionCommon struct is embedded we can access its fields directly—as we do in the IntOption.Name() method. The IntOption satisfies the Optionier interface (it provides the Name() and Valid() methods with the correct signatures).

Although the processing done by the name() function is very simple we have chosen to use a separate function rather than implement it in the IntOption.Name() method. This makes the method very short and means we can reuse the functionality in other options. The GenericOption.Name() and StringOption.Name() methods' bodies are identical to the IntOption.Name() method's single statement body, with all three relying on the name() function to do the actual work. The StringOption's implementation is very similar to the IntOption we have not shown it. (The differences are that its Value field is of type string and its IsValid() method returns true if the Value is nonempty.) For the FloatOption we have used interface embedding, to show how it is done.
