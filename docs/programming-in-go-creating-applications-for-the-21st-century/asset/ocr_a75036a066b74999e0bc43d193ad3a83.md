The sizeFloatOption's first field is an Optioner interface, so we must supply a concrete type that satisfies this interface. Here we have created a GenericOption value for this purpose.

With three different options we can iterate over them using an []Optioner, which is a slice of values that satisfy the Optioner interface. Within the loop the option variable holds each option (of type IntOption). We can call any method specified by the Optioner interface on the option variable, and so here by calling Option.Name() and Option.IsValid().

Each option type has a Value field, but they are of different types—for example, IntOption is an int which holds StringOption. A value is a string, so to be able to access the type-specific Value fields (and similarly, any other type-specific fields or methods), we must convert the given option to the correct type. This is easily achieved using a type switch ($5.2.2.197◄). In the snippet's switch we have used a shadow variable (option) which has the correct type for the case that is executed (e.g., in the IntOption case, option is of type IntOption, etc.), and so we are able to access any type-specific fields or methods within each case.
