# Chapter 9. Packages

The exec package is used to run external programs. This can also be done using os.StartProcess() function, and the exec.Cmd type is much more convenient to use.

The flag package provides a command-line parser. It accepts X11-style options (e.g., --width), GNU-style (e.g., -w and --width). The package produces a very basic usage message and does not provide any validation beyond a value's type. (So, the package can be used to specify an in option, but not what values are acceptable.) Several alternatives are available from the Go Dashboard (godashboard.appspot.com/project).

The log package provides logging information (by default to stdout, and terminating the program or panicking with any error). The log package's output destination can be changed to any io.Writer using log.SetOutput() function; messages are output in the format of a timestamp and then message; the timestamp can be eliminated by calling log.SetFlags(0) before the first log function call. It is also possible to create custom loggers using the log.New().

The math/rand package provides many useful pseudo-random number generator functions including rand.Int() returns a random int and rand.Intn() returns a random int in the range [0, n). The crypto/rand package has a function for producing cryptographically secure-random numbers.

The regex package provides a very fast and powerful regular expression engine that supports the RE2 engine syntax. We have used this in several of the book's examples, although we have deliberately used simple regexps and not used the package's full power so as to stay off-topic. The package was introduced earlier ($3.6.5, 120 ◄).

The sort package provides convenience functions for sorting slices of ints, float64s, and strings, and for performing fast (binary copy) searches on slices. It also provides generic.Sort() and sort.Search() functions that can be used for custom data. (See, for example, §4.2.4, 160 ◄ Table 4.2, 161 and §5.6.7, 228 ◄)

The time package has functions for measuring time and parsing and formatting date/time, and values. The time.After() function can be used to send the current time on the channel it returns after a specified nanoseconds have passed, as we saw in an earlier example (332 ◄). time.Tick() and time.Ticker functions can be used to provide a channel to which a “tick” is sent repeatedly at a specified interval. The time.Time has methods for providing the current time, for formatting a date/time as a string, and for parsing date times. (We saw time.Time examples in Chapter 8, e.g., 375 ◄)

## 9.4. A Brief Survey of the Go Standard Library

### 9.4.8. Networking Packages

The Go standard library has many packages that support networking and programming. The net package provides functions and types for communicating over Unix domain and network sockets, TCP/IP, and UDP. The package provides functions for domain name resolution.

The net/http package uses many of the net package and provides for parsing HTTP requests and replies, and provides a basic HTTP client. The net/http package also includes an easy-to-extend HTTP server, as we saw in Chapter 2 ($24.4, 72 ➤) and Chapter 3's exercises. The net/url package provides URL parsing and query escaping.

Some other high-level networking packages are included in the standard library. One is the net/rpc (Remote Procedure Call) which allows a server to provide objects whose exported methods can be called by clients. Another is the net/smtp (Simple Mail Transport Protocol) package which can be used to send email.

### 9.4.9. The Reflect Package

The reflect package provides runtime reflection (also introspection), that is the ability to access and interact with values of arbitrary types at runtime.

The package also provides some utility functions such as reflect.DeepEqual() which can compare any two values—for example, slices, which aren't comparable using the == and != operators.

Every value in Go has two attributes: its actual value and its type. The reflect.TypeOf() function can tell us the type of any value.

```
x := 8.6
y := float32(2.5)
fmt.Printf("var x %v = %v\n", reflect.TypeOf(x), x)
fmt.Printf("var y %v = %v\n", reflect.TypeOf(y), y)
```

```
var x float64 = 8.6
var y float32 = 2.5
```

Here we have output two floating-point variables and their types as Go declarations using reflection.

When the reflect.ValueOf() function is called on a value it returns a reflect.Value which holds the value but uses not the value itself. If we want to access the value held we must use one of the reflect.Value methods.

```
word := "Chameleon"
value := reflect.ValueOf(word)
```

```
text := value.String()
fmt.Println(text)
Chameleon
```

The reflect.Value type has many methods for extracting the underlying type including reflect.Value.Bool(), reflect.Value.Complex(), reflect.Value.Float(), reflect.Value.Int(), and reflect.Value.String().

The reflect package can also work with collection types such as slices and maps, as well as structs; it can even access structs' tag text. (This ability is used by the json and xml encoders and decoders, as we see in Chapter 8.)

```go
type Contact struct {
  Name string "check:len(3,40)"
  Id int "check:range(1,999999)"
}
person := Contact("Bjork", 0xDEEED)
personType := reflect.TypeOf(person)
if nameField, ok := personType.FieldName("Name"); ok {
  fmt.Printf("%q %q\n", nameField.Type, nameField.Tag)
}
```

```
"string" "Name" "check:len(3,40)" 
```

The underlying value held by a reflect.Value can be changed if it is "setable". The settability can be checked by calling reflect.Value.CanSet(), which returns a bool.

```go
presidents := []string{"Obama", "Bushy", "Clinton"}
sliceValue := reflect.ValueOf(presidents)
value := sliceValue.Index(1)
value.SetString("Bush")
fmt.Println(presidents)
```

```
Obama Bush Clinton
```

Although Go strings are immutable, any item in []string can be replaced by another string, and this is what we have done. It is not possible to change immutable values, but we can use the.Value.Elem() method to retrieve a reflect.Value through which we can set pointed-to value.

```go
count := 1
value = reflect.ValueOf(&count)
if value.CanSet() {
  pointee := value.Elem()
  pointee.SetInt(2)
}
fmt.Println(count)
```

```
3
```

This snippet's output shows that if condition's evaluates to false, its body is not. Although we cannot set immutable values, we can use the reflect.Value.Elem() method to retrieve a pointed-, and this is what we do at the end of the snippet.

It is also possible to use reflection to call arbitrary functions and methods. Here is an example that calls a custom TitleCase() function (not shown) twice, once conventionally and once using reflection.

```go
caption := "greg egan's dark integers"
title := TitleCase(caption)
fmt.Println(title)

titleFuncValue := reflect.ValueOf(TitleCase)
values := titleFuncValue.Call([]reflect.Value{reflect.ValueOf(caption)})
title = values[0].String()
fmt.Println(title)
```

```
Greg Egan's Dark Integers
Greg Egan's Dark Integers
```

The reflect.Value.Call() method takes and returns a slice of []reflect.Value. In this case we pass in a single value (i.e., as a slice of length 1), and retrieve a single result value.

We can call methods similarly—and in fact, we can query to see if a method exists and call only if it does.

```go
a := list.New() // a.Len() == 0
b := list.New()
b.PushFront(1) // b.Len() == 1
c := stack.Stack()
c.Push(0.5)
c.Push(1.5) // c.Len() == 2
d := map[string]int{"A": 1, "B": 2, "C": 3} // len(d) == 3
```
