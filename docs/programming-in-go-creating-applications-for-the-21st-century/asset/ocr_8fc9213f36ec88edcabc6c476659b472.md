# 4.2. Arrays and Slices

Removing items from the start of a slice is easily achieved by reslicing.

```
s := []string("A", "B", "C", "D", "E", "F", "G")
s := s[4:] // Remove s[4:] from the end
fmt.Println(s)
```

Removing items from the end of a slice is achieved by reslicing, just as the item at the start.

```
s := []string("A", "B", "C", "D", "E", "F", "G")
s := append(s[:1], s[5:]...) // Remove s[1:5] from the middle
fmt.Println(s)
```

Retrieving items from the middle of a slice is easy—for example, to get the three middle items of slice s, we would use the expression s[2:5]. But removing items from the middle of a slice is slightly tricky. Here we have done the removal using the append() function to add the sublice of s that follows what we want to delete, to the sublice of s that precedes what we want to delete, and assigning the result slice back to s.

Clearly, using append() and assigning back to the original slice to remove items, changes. Here are some examples that a custom RemoveStringSliceCopy() function returns a copy of the slice it is given, and with the items at the end removed.

```
s := []string("A", "B", "C", "D", "E", "F", "G"
x := RemoveStringSliceCopy(s, 0, 2) // Remove s[:2] from the front
s := RemoveStringSliceCopy(s, 1, 5) // Remove s[1:5] from the middle
z := RemoveStringSliceCopy(s, 4, len(s)) // Remove s[4:] from the end
fmt.Printf("%v\n%v\n%v\n%v\n", s, x, y, z)
```
