```
func home(writer http.ResponseWriter, request *http.Request) {
  err := request.ParseForm() // Must be called before writing response
  fmt.Fprint(writer, pageTop, form)
  if err != nil {
    fmt.Fprint(writer, anError, err)
  } else {
    if numbers, message, ok := processRequest(request); ok {
      stats := getStats(numbers)
      fmt.Fprint(writer, formatStats(stats))
    } else if message != "" {
      fmt.Fprintf(writer, anError, message)
    }
    fmt.Fprint(writer, pageBottom)
  }
}
```

This function is called whenever the statistics web site is visited. The writer argument is where we response to (in HTML) and the request argument contains details of the request.

We begin by parsing the form (which will initially have an empty <input> element). We have called the text <input> element "numbers" so that we can refer to it when we process the form later. Also, the form's action is set to /, when the user presses the Calculate button the page is requested again. This means that the home function is called in all cases, and subsequent cases where no numbers have been entered or where an error has occurred. In fact, all the work is passed on to a custom processRequest() function, so it is in the function that each case is dealt with.

After the parse, we write the pageTop (not shown) and format strings. If the parse fails for any reason we write an error message; anError is a format string and err is the error value to be formatted. (Format strings are covered later; 3.5 ► 93.)

```
anError = <p class="error">%s</p>
```

If the parse succeeds (as it should), we call a custom processRequest() function to retrieve the numbers entered by the user. If the numbers are valid we compute the statistics using the getStats() function we earlier defined and wrote the formatted; otherwise we write an error message if we are given one. (When the form is shown for the first time it has no numbers, yet no error has occurred, in which case ok is false and message is empty.) And at the end we print the pageBottom constant string (not shown) which just closes the </body> and <html> tags.
