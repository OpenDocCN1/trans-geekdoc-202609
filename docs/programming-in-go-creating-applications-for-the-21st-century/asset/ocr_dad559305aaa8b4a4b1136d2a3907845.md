This function is called with both channels passed as parameters. It begins by creating a buffered reader for os.Stdin since we want to interact with the user in the console. It prints the prompt that tells the user to enter and quit. We could have made the program terminate if the user simply pressed Enter (i.e., didn't type in any numbers), rather than asking them to enter end of file. However, by requiring the use of end of file we have made polar more flexible, it is also able to read its input from an arbitrary file using file redirection (providing only that the file has two whitespace-separated numbers per line).

The function starts an infinite loop which begins by prompting the user to enter a polar coordinate (a radius and angle). After asking for the user's input the function waits for the user to type text and press Enter, or Ctrl+D (or Ctrl+Z, Enter on Windows) to signify that they have finished. We don't bother checking the error value; if it isn't nil we break out of the loop and return to the caller (main()), which in turn will return (and call its deferred statements to close the communication channels).
