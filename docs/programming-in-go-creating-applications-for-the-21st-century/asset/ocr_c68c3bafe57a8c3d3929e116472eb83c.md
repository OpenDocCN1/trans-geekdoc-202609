+   2. A program that accepts one or more filenames on the command line, and prints one to the console as an HTML tag of the form <img src="filename" width="width" height="height" />. The program should process the images concurrently using a fixed number of goroutines, and the order of output doesn't matter (so so long as each line is output complete!). Allow any files to be given on the command line, but ignore those that are not regular files or not images, and ignore all errors.

The standard library's image.DecodeConfig function retrieves an width and height from an image.Reader (returned by os.Open()), without having to read the entire image. For this function it is better to recognize various image formats (.jpg, .png, etc.), it is necessary to import the corresponding packages. However, we do not need to access these packages directly, so the Go compiler gives us "imported and not used" errors, we must import the packages to the blank identifier (e.g., _ "image/jpeg", "image/png", etc.).
