# 4.2 Arrays and Slices

A array is a fixed-length sequence of items of the same type. Multidimensional arrays can be created by using items that are themselves arrays. Array items are indexed using the [] index operator by their 0-based position, so an array's first item is array[0] and its last item is array[len(array)] - 1. Arrays are mutable, so we can use the syntax array[index] on the left of assignment
