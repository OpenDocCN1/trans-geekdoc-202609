The outer loop replaces each nil with an []int that has many items as the number of lines. So each nil gets replaced with [0 0 0 0], since Go initializes with a type's zero value.

The inner loop is used to populate the counts. For each count the number of occurrences of each separator is counted and counts is updated accordingly. strings.Count() function returns the number of occurrences of its second argument that occur in its first string argument

For example, given a tab-separated file which had some bullets, spaces, and stars in some of its files we get a counts matrix of [[3 3 3 3] [0 0 4 0] [0 0 0 0]]. Each counts is an []int which contains the counts for the corresponding separator (tab, star, bullet) for each of the five lines. In this case every line has three tabs, a couple of lines have stars (four in one, two in another), three lines have bullets, and no lines have vertical bars. To us readers it is obvious that the separator is a tab, but of course, the program must discover this for itself, and it does so using the guessSep()

```
func guessSep(counts [][]int, separators []string, linesRead int) string {
	for sepIndex := range separators {
		same := true
		count := counts[sepIndex][0]
		for lineIndex := 1; lineIndex < linesRead; lineIndex++ {
			if counts[sepIndex][lineIndex] != count {
				same = false
				break
			}
		}
		if count > 0 && same {
			return separators[sepIndex]
		}
	}
	return ""
}
```

This function's purpose is to find the first []int in the counts slices whose are all the same—and nonzero.

The function iterates over each “row” in counts (one per separator), initially assumes that all the row's counts are the same. It sets the initial first count, that is, to the number of times the separator occurs in the first line that was read. Then it iterates over the rest, that is, over the separator counts for each of the other lines that was read.
