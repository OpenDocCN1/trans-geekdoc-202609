Another subtle point is that the fmt.Println() function can print numbers without formality. (As we will see in Chapter 6 we can make our own types seamlessly cooperate with Go's print functions by providing them with a String() method.)

In general the best complex type to use is complex128 since all the functions in the math/cmpx package work in terms of complex128s. However, Go also provides the complex64 type which may be useful when memory is very tight. Since Go's complex types are sized it is always safe to read or write them or to external sources such as file or network connections.
