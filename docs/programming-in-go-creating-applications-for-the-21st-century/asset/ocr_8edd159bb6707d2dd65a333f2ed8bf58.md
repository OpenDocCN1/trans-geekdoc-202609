This function opens the given .zip file for reading. Instead of having to call os.Open() to open the file and calling zip.NewReader(), the zip package provides the zip.OpenReader() function which conveniently does both and returns a *zip.ReadCloser that it contains an exported zip.Reader struct to work with. The most important aspect of the zip.Reader struct that contains a [1]*zip.File—a slice of pointers to zip.File structs, each one representing inside the .zip file.

We iterate over each of the reader's zip.File structs and create a sanitized file or directory (using the same sanitizedName()) function as we use in the pack program; 99 �, to reduce the risk of overwriting important files.

If we have a directory (as reported by the *zip.File's os.Mode.IsDir()) we try to create the directory. The os.MkdirAll() function has the useful properties that it will create any intermediate directories that are necessary to create the specified directory, and that it safely does nothing and return nil if the directory already exists. If we have a file, we can pass on the work of unzipping it to a custom unpackZippedFile() function.

```
func unpackZippedFile(filename string, zipFile *zip.File) error {
	writer, err := os.Create(filename)
	if err != nil {
		return err
	}
	defer writer.Close()
	reader, err := zipFile.Open()
	if err != nil {
		return err
	}
	defer reader.Close()
	if _, err := io.Copy(writer, reader); err != nil {
		return err
	}
	if filename == zipFile.Name {
		fmt.Println(filename)
	} else {
		fmt.Printf("%s [%s]\n", filename, zipFile.Name)
	}
	return nil
}
```
