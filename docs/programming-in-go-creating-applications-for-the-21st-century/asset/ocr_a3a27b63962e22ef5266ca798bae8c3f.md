When we build c3 using go, on Linux machines the util_linux.go file will be compiled and the util_windows.go file will be ignored–and vice versa on Windows machines. This ensures that only one of the commandLineFiles is compiled for any particular build.

On Mac OS X and FreeBSD systems neither util_linux.go nor util_windows.go will be compiled, the build will fail. Since the shells on these-do globbing, we get either soft (symbolic) link or copy util_linux.go to util darwin.go (and similarly for any other platforms that Go supports and are required). With these lines or copies in place, the program will build on Mac OS X and FreeBSD platforms.
