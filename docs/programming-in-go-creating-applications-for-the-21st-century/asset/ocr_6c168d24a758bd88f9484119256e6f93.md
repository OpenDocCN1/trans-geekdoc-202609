# 7.2.5. Example: Find Duplicates

This chapter's final concurrency example is a program that attempts to find duplicate files using file sizes and SHA-1 values rather than filenames.

The program we will review is called findduplicates (in findduplicates/duplicates.go). The program uses the standard filepath.Walk() function to iterate over all the files and directories in a given path, including subdirectories, and subdirectories, and so on. The program uses a variable number of goroutines depending on the work it does. For each "big" file, each "small" file's SHA-1 is computed in the current goroutine.
