The optional statement is the same as in expression switches and if statements. And the case clauses work the same way as expression switches except that they list one or more comma-separated types. The optional default and fallthrough statements are just the same as for expression switches, and as usual, each block consists of zero or more statements.

The type switch guard whose result is a type. If the expression is assigned using the := operator, the variable created has the value of the value in the type switch guard, but its type depends on the case clauses: In a case clause with one type in its type list, the variable has that type in case, and in case clauses that have two or more types, the variable's type is that of the type switch guard.

The kind of type testing supported by the type switch statement is generally frowned upon by object-oriented programmers who instead prefer to rely on polymorphism. Supports a kind of polymorphism through duck typing (as we see in Chapter 6), but nonetheless there are times where explicit testing makes sense.

Here is an example of how we might call a simple type classifier function and the output produces.
