# 5.6. Custom Functions

Here are four example calls and their results.

```
xs := []int{2, 4, 6, 8}
ys := []string{"C", "B", "K", "A"}
fmt.Println(
SliceIndex(len(xs), func(i int) bool { return xs[i] == 5 }),
SliceIndex(len(xs), func(i int) bool { return xs[i] == 6 }),
SliceIndex(len(ys), func(i int) bool { return ys[i] == "Z" }),
SliceIndex(len(ys), func(i int) bool { return ys[i] == "A" })

-1 2 -1
```

The anonymous functions passed as second arguments to the SliceIndex() function are of, closures—so the slices they refer to (xs and ys) must be in scope when these functions are created. (The technique used here is the same as Go's standard library uses for the sort.Search(function()).)

In fact, the SliceIndex() function is a general-purpose function that need nothing to do with slices.

i := SliceIndex(math.Max32,
func(i int) bool { return i > 0 && i%27 == 0 && i%51 == 0 }
fmt.Println(i)
459

In this snippet we use the SliceIndex() function to find the natural number that is divisible by both 27 and 51. The way this works is slightly subtle. The SliceIndex() function iterates from 0 to the given limit (in this case math.Max32, and at each iteration it calls the anonymous function (the predicate). As the predicate returns true, the SliceIndex() function returns, passing back the index position that was reached. In this case "index position" is actually the natural number we were looking for.

In addition to searching unsorted slices it is often useful to filter them items that are no longer of interest. Here is a simple higher order filtering function in action. The function filters an [] using the function it is passed to determine which items are kept and which dropped.

```
readings := []int{4, -3, 2, -7, 8, 19, -11, 7, 18, -6}
even := IntFilter(readings, func(i int) bool { return i == 0 }
fmt.Println(even)

[4 2 8 18]
```

Here, we have filtered out odd numbers from the readings slice.
