# Chapter 1. An Overview in Five Examples

# The Go Documentation

Go's official web site is golang.org which hosts the most up-to-date documentation. The "Packages" link provides access to the documentation on all Go standard library’s packages—and their source code, which can be very helpful when the documentation is sparse. The "Commands" link leads to the documentation for the programs distributed with Go (e.g., the compilers, build tools, etc.). The "Specification" link leads to an accessible, informal, and quite thorough Go language specification, and the "Effective Go" link leads to a document that explains many best practices.

The web site also features a sandbox in which (somewhat limited) Go programs can be written, compiled, and run, all online. This is useful for beginners for checking odd bits of syntax and for learning the fmt package sophisticated formatting facilities or the regexp regular expression engine. The Go web search searches only the Go documentation; search for Go resources generally, visit go-cat-v.org/go-search.

The Go documentation can also be viewed locally, in a web browser. To do this, run godoc tool with a command-line argument that tells it to operate as a web server. Here's how to do this in a Unix console (xterm, gnome-terminal, console, Terminal.app, or similar):

```
$ godoc -http=8000
```

In a Windows console (i.e., a Command Prompt or MS-DOS Prompt window):

```
C:\godoc -http=8000
```

The number used here is arbitrary—use one different if it conflicts with an existing server. This assumes that godoc is in your PATH.

To view the served documentation, open a web browser and give it a http://localhost:8000. This will present a page that looks very similar to the golang.org web site’s front page. The "Packages" link will show the documentation for Go’s standard library, plus any third-party packages that have been installed under GOROOT. If GOPATH is defined (e.g., for local programs and packages), a link will appear beside the "Packages" link through which the relevant documentation can be accessed. (The GOROOT and GOPATH environment variables are discussed later in this chapter and in Chapter 9).

It is also possible to view the documentation for a single package or a small item in a package in the console by executing godoc on the command line. For example, executing godoc image NewRGBA will output the documentation for the image.NewRGBA() function, and executing godoc image/png will output the documentation for the entire image/png package.
