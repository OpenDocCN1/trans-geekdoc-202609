Arrays are created using the syntaxes:

```
[length]Type
[N]Type{value1, value2, ..., valueN}
[...Type{value1, value2, ..., valueN}]
```

If the ... (ellipsis) operator is used in this context, Go will calculate the array's
length for us. (The ellipsis operator is overloaded for other purposes, as we will
later in this chapter and in Chapter 5.) In all cases an array's length is fixed
and unchanging.

Here are some examples of how to create and index arrays.

```
var buffer [20]byte
var grid1 [3]int
grid1[0], grid1[1][1], grid1[2] = 8, 2
grid2 := [3]int{{4, 3}, {8, 6, 2}}
cities := [...]string{"Shanghai", "Mumbai", "Istanbul", "Beijing"}
len(cities)-1 = "Karachi"
fmt.Printf("-%T %v\n\n", Len Contents)

fmt.Printf("-%T %v\n\n", grid1, len(grid1), grid1)
fmt.Printf("-%T %v\n\n", grid2, len(grid2), grid2)
```

Go guarantees that all array are initialized to their zero value if they are
not explicitly initialized—or only partially initialized—when they are created,
as buffer, and grid2 variables illustrate.

The length of an array is given by the len() function. Since arrays of fixed
size their capacity is always equal to their length, for arrays the cap() function
returns the same number as the len() function. Arrays can be sliced using the
same syntax as strings or slices, or the result is a slice and not an array.
And just like slices, arrays can be iterated using a for ... range loop
(5.3. ➤ 203).
