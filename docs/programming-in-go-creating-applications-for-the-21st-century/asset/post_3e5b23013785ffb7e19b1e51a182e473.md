```go
func readM3uPlaylist(data string) (songs []Song) {
  var song Song
  for line := range strings.Split(data, "\n") {
    line = strings.TrimSpace(line)
    if line == "" || strings.HasPrefix(line, "#EXTM3U") {
      continue
    }
    if strings.HasPrefix(line, "#EXTINF") {
      song.Title, song.Seconds = parseExtintLine(line)
    } else {
      song.Filename = strings.Map(mapPathDirSeparator, line)
    }
    if song.Filename != "" && song.Title != "" && song.Seconds != 0 {
      songs = append(songs, song)
      song = Song{}
    }
  }
  return songs
}
```

# 3.7. Example: M3u2pls

This function accepts the contents of an .m3u file as a single string and returns a slice of all the songs it is able to parse from the string. It begins by declaring an empty Song variable called song. Thanks to Go's practice of always initializing things to their zero value, song's initial contents are empty strings and a Song. Seconds value of 0.

At the heart of the function is a for range loop ($5.3, ➤ 203). The strings.Split() function is used to split the single string that holds the entire .m3u file's data into separate lines, and the for loop iterates over each of these lines. If a line is empty or the first line (i.e., starts with the string literal "#EXTM3U", the continue statement remains; this simply passes back to the for loop to find the next iteration—or the end of the file if there are no more lines.

If the line begins with the "#EXTINF: string literal, it is passed to a custom parseExtfinLine() function for parsing: this function returns a string and an int which are immediately assigned to the current song's Title and Song.Seconds fields. Otherwise, it is assumed that the line holds the filename (including the path) of the current song.

Rather than using the filename as is, the strings.Map() function is called with a custom mapPlatformDirSeparator() function to convert directory separators into those native for the platform the program is running, and the result is stored as the current song's Song.Filename. The strings.Map() passed a mapping function with signature func(rune) rune and a string. For every character in the string mapping function is called with the character replaced by the character returned by passed-in function—which may be the same as the original one, of course. As usual with Go, a character is a rune whose value is the character's Unicode code point.

If the current song's filename and title are both nonempty, and if the song's duration isn't zero, the current song is appended to the returns value (of type []Song) and the current song is set to its zero value (empty strings and 0) by assigning any song to it.

```go
func parseExtfinLine(line string) (title string, seconds int) {
	if i := strings.Index(line, "-0123456789"); i > -1 {
		const separator = ","
		line = line[i:]
		if j := strings.Index(line, separator); j > -1 {
			title = line[j:len(separator)]
			var error
			if seconds, err := strconv.Atoi(line[j]); err != nil {
				log.Printf("failed to read the duration for '%s': %v\n", title, err)
				seconds = -1
			}
		}
	}
	return title, seconds
}
```

This function is used to parse lines of the form: #EXTINF:duration,title and where the duration is expected to be an integer, either -1 or greater than zero.

The strings.IndexAny() function is used to find the position of the first digit or the minus sign. An index position of -1 means not found; any other value is the index position of the first occurrence of any of the characters in string given as the strings.IndexAny() function's second argument, in which case variable i holds the position of the first digit of the duration (or of -).

Once we need the digits begin we slice the line to start at the digits. This effectively discards the "EXTINF: that was at the start of the string, so now the line has the form: duration,title.

The second statement uses the strings.Index() function to get the index position of the first occurrence of the "" string in the line—or -1 if there is no such occurrence.

The title is the text from the comma to the end of the line. To slice from after the comma we need the comma's starting position (j) and must add to this the number of bytes the comma occupies (len(separator)). Of course, we know that a comma is a 7-bit ASCII character and has a length of one, but the approach shown will work with any Unicode character, no matter how bytes are used to represent it.

The duration is the number whose digits go from the start of the line up to but excluding the j-th byte (where the comma is). We convert the number into an int using the strconv.Atoi() function—and if the conversion we simply set the duration to -1 which is an acceptable "unknown duration" value, and log the problem that the user is aware of.

```go
func mapMapDirSeparator(char rune) rune {
  if char == '/' || char == '\' {
    return filepath.Separator
  }
  return char
}
```

This function is called by the strings.Map() function (inside the readM3uPlay-list() function) for every character in a filename. It replaces any directory separator with the platform-specific directory separator. And any other character is returned unchanged.

# 3.7. Example: M3u2pls

Like most cross-platform programming languages and libraries, Go uses Unix-style directory separators internally on all platforms, even on Windows. However, for user-visible output and for human-readable data files, we prefer to use the platform-specific directory separator. To achieve this we can use the filepath.Separator which holds the / character on Unix-like systems and the \ character on Windows.

In this example we do not know whether the paths we are reading forward slashes or backslashes, so we have to cater for both. However, if we know for sure that a path uses forward slashes we can use the filepath.Slash() function on it: This will return the path unchanged on Unix-like systems, but will replace forward slashes with backslashes on Windows.

```go
func writePlusPlaylist(songs [])Song) {
	fmt.Println("[playlist]")
	for i, song := range songs {
		i++
		fmt.Printf("File=%d\\s\\n", i, song.Filename)
		fmt.Printf("Title=%d\\s\\n", i, song.Title)
		fmt.Printf("Length=%d\\d\\n", i, song.Seconds)
	}
	fmt.Printf("NumberOf=%d\\nVersion=2\\n", len(songs))
}
```

This function writes out the songs in .pls format. It writes the data to os.Stdout (i.e., to the console), so file redirection is used to get the output into a file.
