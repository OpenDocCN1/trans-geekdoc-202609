# 2.3.2. Floating-Point Types

Go provides types of floating-point numbers and two of complex numbers—their names and ranges are shown in Table 2.7. Floating-point numbers in Go are held in the widely used IEEE-754 format (http://en.wikipedia.org/wiki/IEEE_754-2008). This format is also the native format used by many processors and floating-point units, in most cases Go is able to take direct advantage of the hardware’s floating-point support.

| --- | --- |

| float64 | $\pm1.797693134863213708152427317017456781 \times 10^{308}$
The mantissa is reliably accurate to 15 decimal places. |
| complex64 | The real and imaginary parts are of type float32. |

Go floating-point numbers support all the arithmetic operations listed in Table 2.4 (59 $lacktriangleright$). Most of the package’s constants and all of its functions are listed in Tables 2.8 to 2.10 $lacktriangleright$-$65$lacktriangleright$.

Floating-point numbers are written with a decimal point, or using exponential notation, for example, 0.0, 3, 8.2, -7.4, -64, 1.5E-3. Computers represent floating-point numbers internally using binary—this means that decimals can be represented exactly (such as 0.5), but others only approximately (0.1 and 0.2). Furthermore, the representation uses a fixed number of bits, so there is a limit to the number of digits that can be held. This is not a Go-specific problem, but one that affects floating-point numbers in all mainstream programming languages. However, the imprecision isn’t always apparent because Go uses a smart algorithm for outputting floating-point numbers that uses the fewest possible digits consistent with maintaining accuracy.
