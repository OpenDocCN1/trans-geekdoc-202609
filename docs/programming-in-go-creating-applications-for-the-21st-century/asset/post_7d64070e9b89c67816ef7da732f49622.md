Decimal integers are output using the %d (decimal) verb. The only characters that can be used for padding are spaces and zeros, but it is easy to pad with other characters using a custom function.

```go
i = 569
fmt.Printf("%d$06d$%06d$%s\n", i, i, Pad(i, 6, '*'))

$569$000569$00569$***569
```

For the last format-at, we use the %s (string) verb to print a string since that's what our `Pad()` function returns.

```go
func Pad(number, width int, pad rune) string {
    s := fmt.Sprint(number)
    gap := width - utf8.RuneCountString(s)
    if gap > 0 {
        return strings.Repeat(string(pad), gap) + s
    }
    return s
}
```

The `utf8.RuneCountString()` function returns the number of characters in the given string; this is always less than or equal to the number of bytes. The `strings.Repeat()` takes a string and a count and returns a new string that contains the given string repeated count times. We chose to use the padding character as a rune (i.e., a Unicode code point) to avoid users of the function passing a string which might contain more than one character.

### 3.5.3. Formating Characters

Go characters are runes (i.e., int32s), and they can be output as numbers or Unicode characters.

```go
fmt.Printf("%d#04x %U %c\n", 0x3A6, 934, '\u003A6', '\u000003A6')
934 0x03A6 U+03A6 - Φ
```

Here we have output the Greek capital letter Phi ('Φ') as decimal and hexadecimal integers, as a Unicode code point using the %U (Unicode) verb, and as a Unicode character using the %c (character or code point) verb.

### 3.5.4. Formatting Floating-Point Numbers

For floating-point numbers we can specify the overall width, the number of digits after its decimal place—whether to use standard or scientific notation.

```go
for _, x := range []float64{-25.8800, 7194.84, -6089716.0218, 1.50009e-8} {
	fmt.Printf("%.20.5e %.20.5f\n\n", x, x, Humanize(x, 20, 5, '*', ''))
}
```

| -2.58000e-01 | | -0.258000 | ************0.258000 |
| :--- | :--- | :--- | :--- |
| 7.19484e+03 | | 7194.840000 | ************7194.840000 |
| -6.08972e+03 | -6089716.02180 | ***-60,897.02180 |
| | 0.000000 | ************0.000000 |

We have used a for ... range loop to iterate the numbers in a slice literal of float64 items.

The custom `Humanize()` function returns a string representation of the number it is given with grouping separators (for languages that use simple three-digit groups) and padding.

```go
func Humanize(amount float64, width, decimals int,
	pad, separator rune) string {
	dollars, cents := math.Modf(amount)
	whole := fmt.Sprintf("%+.0f", dollars)[1:] // Strip "+"
	fraction := ""
	if decimals > 0 {
		fraction = fmt.Sprintf("%*0f", decimals, cents)[2:] // Strip "0"
	}
	sep := string(separator)
	if i := len(whole) - 3; i >= 0; i -= 3 {
		whole = whole[:i] + sep + whole[i:]
	}
	if amount < 0.0 {
		whole = "-" + whole
	}
	number := whole + fraction
	gap := width - utf8.RuneCountIn(number)
	if gap > 0 {
		number = strings.Repeat(string(pad), gap) + number
	}
	return number
}
```

The `math.Modf()` function returns the whole and fractional parts of a float64 as. To get the whole part as a string we use the `fmt.Sprintf()` with a format that forces the string to be output and then we immediately slice the string to strip off the sign. We use a similar technique for the fractional part, only this time we use the .f verb specifying the number of decimal digits to use with a * placeholder. (So in this case, if decimals has the value 2 the format becomes `%.2f`) For the fractional part we strip off the leading -0 or +.

The grouping separators are inserted from right to left in the whole string and then a - is added if the number is negative. At the end we concatenate the whole and fractional parts and return the result—padding if required.

The %e, %E, %f, and %g verbs can be used with complex numbers as well as floating-point numbers. The %e and %E are scientific (exponential) verbs, %f is the floating-point verb, and %g are general floating-point verbs. One factor to keep in mind, though, is that the modifiers are applied to both the real and imaginary parts of complex numbers—for example, a format of %f will produce a result up to 20 characters if the argument is a complex number.

```go
for _, x := range []complex128{2 + 3i, 172.6-58.3i, -82.7+9.4i} {
	fmt.Printf("%15s %15f %f\n", real(x), imag(x), x, x)
}
```

| 2.000+3i | 172.600-58.300i | -82.700+9.400i | (2.000+3i) |
| :--- | :--- | :--- | :--- |
| 172.600-58.300i | (172.600-58.300i) | 172.600-58.300i | 172.600-58.300i |
| -82.700+9.400i | (-82.700+9.400i) | (-82.700+9.400i) | -82.700+9.400i |

For the first column of complex numbers, we wanted the components to have different numbers of digits after the decimal place. To achieve this we formatted the real and imaginary parts using `Sprintf()`, and then output the result as a string using a format of %15s. For the other columns we used the %f and %g verbs directly—around complex numbers.

### 3.5.5. Formatting Strings and Slices

Strings can be output with a minimum field width (which the print functions will pad with spaces if the string is too short), and with a maximum number of characters (which will result in truncation for any string too long). Strings can be output as Unicode characters, or as a sequence of code points (i.e., runes) or as UTF-8 bytes.

```go
slogan := "Überfmt"
fmt.Printf("%s\n%q\n%q\n", slogan, slogan, slogan)

Überfmt
"Überfmt"
"U\u00dcfmt"
```

The %q (quoted string) verb is used to print a string as a Go double-quoted string with printable characters printed literally, and with all other characters using escapes (see Table 3.1). If the + modifier is used, all ASCII characters (U+0020 to U+007F) are printed literally, with the rest using escapes. If the # modifier is used the output is a Go string where possible, and a double-quoted string otherwise.

Although normally the variable corresponding to a verb is a single value of a compatible type (e.g., an int for the %d or for %x verb), the variable can be a slice or a map, the map’s key and value are both compatible with the verb (e.g., both strings or numbers).

```go
chars := []rune(slogan)
fmt.Printf("%s\n%x\n%x\n", chars, chars, chars)
[85 220 98 101 114 116]
[0x55 0xdc 0x62 0x65 0x72 0x74]
```

Here we print a slice of runes—in this example, a slice of code points—as a hexadecimal number, one per code, using the %x and %X verbs. If the # modifier is used it forces a leading 0x or X to be output for each number.

For most types, slices of the type are output as a bracket enclosed sequence of space-separated items. An exception is []byte where no brackets are spaces output unless we use the %v verb.

```go
bytes := []byte(slogan)
fmt.Printf("%s\n%x\n%x\n", bytes, bytes, bytes, bytes)
Überfmt
456e6420c3a93372
```
