# 1.6. Americanise—Files, Maps, and Closures

The replacer function we want to create a string and return a corresponding string, what we need is a function that uses some kind of lookup table. Go's built-in map collection data type is ideal for this purpose ($4.3, 164). A map holds key-value pairs with very fast lookup by key. Here we will use British words as keys and the U.S. counterparts as values.

Go's map, slice, and channel types are created using the built-in make() function. This creates a value of the specified type and returns a reference to it. The reference can be passed around (e.g., to other functions) and any changes made to the referred value are visible to all the code that accesses it. Here we have created an empty map called usForBritish, with string keys and values.

With the map in place we split the file's text (which is in the form of a long string) into lines, using `strings.Split()` function. This function takes a string to split and a separator to split on and does as many splits as possible.(If we want to limit the number of splits we can use the `strings.SplitN()` function.)

The iteration over the lines uses a loop syntax that we haven't seen before, this time using a range clause. This form can be conveniently used to iterate over a map's keys and values, or a communication channel's elements, or—here—over a slice's (or array) elements. When used on a slice (or array), the index and element are returned on each iteration, starting at index 0 (if the slice is nonempty). In this example we use the loop to iterate over all lines, but since we don't care about the index of each line we assign to the blank identifier (_) which discards it.

We need to split each line into two: the original string and the replacement string. We use the `strings.Split()` function but that would require us to specify an exact separator string, say, " which might fail on a hand-edited file where sometimes users accidentally accidentally in more than one space, or sometimes uses tabs. Frankly, Go provides the `strings.Fields()` function which splits the string it is given on whitespace and is therefore much more forgiving of human-edited text.
