We created grid1 as a slice of slices with an initial length of 3 (i.e., it can contain three slices), and a capacity of 3 (since the capacity defaults to the length if it isn't specified). Then we set each of grid's outermost slices to contain their own 3-item slices. Naturally, we could have made the innermost slices have different lengths if we wanted.

# 4.2.1. Indexing and Slicing S

A slice is a reference to a hidden array and slices of slices are also references to the same hidden array. Here is an example to illustrate what this means.

```
s := []string("A", "B", "C", "D", "E", "F", "G"
t := s[2:6]
fmt.Println(t, s, "=", s[4], "+", s[4])
s[3] = "y"
t[len(t)-1] = "y"
fmt.Println(t, s, "=", s[4], "+", s[4])
```

```
[C A B C D E F G] = [A B C D] + [E F G]
[C X y G] = [A B C X] + [E y G]
```

When we change data—whether via the original slice or the t slice of the slice—same underlying array is changed, both slices are affected. The code snippet illustrates that given a slice s and an index i (@ <= i < len(s)), is equal to the concatenation of s[:i] and s[i:]. We saw a similar equality in the previous chapter in reference to strings:

```
s = s[:i] + s[i:] // s is a string; i is an int; @ <= i <= len(s)
```
