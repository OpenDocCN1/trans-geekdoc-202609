This is the complete implementation of the Circle type. Although we create concrete *Circle values, we can pass them around as interfaces, which gives us a lot of flexibility. For example, the drawShapes() function (292 ◀) accepts Shapers (or Drawers), no matter what their underlying type is.

In the hierarchical shape1 package this type satisfies the CircularShaper and Shaper interfaces. In the compositional shape2 package it satisfies the Filler, Radi, Drawer and Drawer interfaces. And in both cases the type also satisfies the fmt.String interface.

Since Go doesn't have constructors and we have unexported fields, we provide construction functions which can be explicitly explained. The Circle's construction function is NewCircle(); later on we will see that the package also has a New() function that can create a value of any of the package's shapes. The saneRadius() helper function returns the given int if it is in a specified range or a sensible value otherwise; we saw it created earlier (290 ◀).

The code for the Draw() method has been elided (although it is in the book's source code), since our concern in this chapter is with creating custom interfaces and types rather than graphics.
