2. Data, matching, and mining applications that involve people's names can produce better results by matching names by what they sound rather than how they are spelled. Many algorithms for name matching English language names are available, but the oldest and simplest is the Soundex algorithm.

The classic Soundex algorithm produces a soundex of a capital letter followed by three digits. For example, the names “Robert” and “Rupert” both have the same soundex value of “R163” according to most Soundex algorithms. However, the names “Ashcroft” and “Ashcraft” have a soundex value of “A226” according to Soundex algorithms (including the one in the exercise solution), but “A261” to others.
