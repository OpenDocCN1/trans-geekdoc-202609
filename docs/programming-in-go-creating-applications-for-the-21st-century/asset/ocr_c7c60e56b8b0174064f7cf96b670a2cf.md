```
func bisectLeft(slice []interface{
	less func(interface{}, interface{}) bool, x interface{}) int {
	right := 0, len(slice)
	for left < right {
		middle := int((left + right) / 2)
		if less(slice[middle], x) {
			left = middle + 1
		} else {
			right = middle
		}
	}
	return left
}
```

The bisectLeft() function is used in the solution and might prove useful. If it returns len(slice), the item isn't in the slice and belongs at the end. Any other value means either that the item is in the slice at the returned position, or that it isn't in the slice but belongs at the returned position.
