# 2.1.1. Enumerations

Rather than repeat the const word when we want to set multiple constants, we can group several constant declarations using the const word just once. (We used the same grouping syntax when importing packages in Chapter 1; the syntax can also be used to group variables declared by var.) For those cases where we just want constants to have distinct values and don't really care what values are, we can use Go somewhat bare-bones enumeration support.

```
const Cyan = 0
const Magenta = 1
const Yellow = 2

const (
    Cyan = iota // 0
    Magenta // 1
    Yellow // 2
)
```

These three code snippets all achieve exactly the same thing. The way a group of consts works is that the first one is set to zero unless explicitly set (either to a value or iota), and the second and subsequent ones are set to their predecessor's value—or to iota if their predecessor's value is iota. Each subsequent iota value is one more than the previous one.

On the other hand, the right-hand code snippet didn't have iota. Cyan would be set to 0 and Magenta would be set to Cyan's value and Yellow would be set to Magenta's value—so they would all end being set to 0. Similarly, if Cyan was set to 9, then they would all be set to 9; or if Magenta was set to 5, Cyan would be set to 0 (in the group and not assigned an explicit value or iota), Magenta would be 5 (explicitly set), and Yellow would be 5 (the constant's value).

It is also possible to use iota with floating-point numbers, simple expressions, and custom types.
