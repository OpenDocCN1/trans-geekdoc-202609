Of course, for a large web site with lots of page handlers, and a deferred function to catch and log panics involves a lot of code duplication and is easy to forget. This can be solved by using a wrapper function that has the code needed by each page handler. Using the wrapper we can omit the recover code from the page handlers, so long as we change the http.HandleFunc() calls.

```
http.HandleFunc("/", logPanics(homePage))
```

Here we have the original tabPage() function (i.e., one that does not have a de-ferred function that calls (recover), relying instead on the logPanics() wrapper to take care of panics.

```
func logPanics(function func(http.ResponseWriter,
	*http.Request)) func(http.ResponseWriter, *http.Request) {
	return func(writer http.ResponseWriter, request *http.Request) {
	\ldefer func() {
			if x := recover(); x != nil {
				log.Printf("%v" caught panic: %v", request.RemoteAddr, x)
		}
	()}
	function(writer, request)
	}
}
```

This function takes an HTTP handler function as its sole argument and creates returns an anonymous function that includes a deferred (anonymous anonymous function that catches and logs panics, and calls the passed-in handler func-tion. This has the same effect as adding the deferred panic catcher and logger that we saw in the modified tabPage() function, but is much more convenient since we don't have to add the deferred function to any page handler; instead we pass each page handler function to the http.HandleFunc() using the logPanics() wrapper.
