# 1.1. Getting Go

The Go compiler is called gc and its toolchain includes programs as 5g, 6g, and 8g for compiling, 5l, 6l, and 8l for linking, and godoc for viewing the Go documentation. (These are 5ge.exe, 6le.exe, etc., on Windows). The strange names follow the Plan 9 operating system's compiler naming conventions where the digit identifies the processor architecture (e.g., "5" for ARM, "6" for AMD64—including Intel 64-bit processors—and "8" for Intel 386). Fortunately, we don't need to concern ourselves with these tools, since Go provides the high-level build tool that handles the compiling and linking for.

All the examples in this book—available from www.qtrac.org/gobook—have been tested using gc on Linux, Mac OS X, and using Go 1. The developers intend to make all subsequent Go 1.x versions backward compatible with Go 1, so the book's text and examples will be valid for the entire 1.x series. (If incompatible changes occur, the book's examples will be updated by the latest Go release, so time they may differ from the code in the book.)

To download and install Go, visit golang.org/doc/install.html which provides instructions and download links. At the time of this writing, Go 1 is available in source and binary for FreeBSD 7+, Linux 2.6+, Mac OS X (Snow Leopard and Lion), and Windows 2000+, in all cases for Intel 32-bit and AMD 64-bit processor architectures. There is also support for Go on ARM processors. Prebuilt packages are available for the Ubuntu Linux distribution, and may other Linux by the time you read this. For learning to program in Go it is easier to install a binary to build Go from scratch.

Programs built with gc use a particular naming convention. This means that programs compiled with gc can be linked to external libraries that use the same naming convention—unless a suitable tool is used to bridge the difference. Go comes with support for using C code from Go programs in the form of the cgo tool (golang.org/cmd/cgo), and at least on Linux and BSD systems, with C and C++ code can be used in Go programs using the SWIG tool (www.swig.org).

In addition there is also the gccgo compiler. A Go-specific front to gcc (the GNU Compiler Collection) available for gcc from version 4.6. Like gc, gccgo may be available for some Linux distributions. Instructions for building and installing gccgo are given at golang.org/doc/gccgo_install.html.
