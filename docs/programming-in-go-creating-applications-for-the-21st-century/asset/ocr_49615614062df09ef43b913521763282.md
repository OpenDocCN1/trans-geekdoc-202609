# Chapter 3. Strings

Table 3.14 The Regexp Package’s Character Classes

| Syntax | Description |
| --- | --- |
| [chars] | Any character in chars |
| [^chars] | Any character not in chars |
| [:name:] | Any ASCII character in the name class: 
[:alnum:] = [0-9A-Za-z] [[:lower:] = [a-z]
[:alpha:] = [A-Za-z] [[:print:] = [~]
[:ascii:] = [\x00-\x7F] [[:punct:] = [!-:-@[\]`{~]
[:blank:] = [t] [[:space:] = [\t\n\f\r]
[:ctrl:] = [\x00-\x1F\x7F] [[:upper:] = [A-Z]
[:digit:] = [0-9] [[:word:] = [0-9A-Za-z_]
[:graph:] = [!] [[:xdigit:] = [0-9A-Fa-z]|

[^name:] Any ASCII character not in the name class

| | Description |
| --- | --- |
| \d | Any digit: [0-9] |
| \D | Any nondigit: [^0-9] |
| \s | Any whitespace: [ \t\n\f\r] |
| \S | Any nonwhitespace: [^\t\n\f\r] |
| \w | Any “word” character: [0-9A-Za-z_] |
| \W | Any non-“word” character: [^0-9A-Za-z_] |
| \p | Any Unicode character not in the N one-letter character class; e.g., \p to match a Unicode letter |
| \P | Any Unicode nonletter class; e.g., \P to match a Unicode nonletter |
| \p{Name} | Any character in the Name class; e.g., \p{Ll} matches lowercase letters, \p{Lu} matches uppercase letters, and \p{Greek} matches Greek characters |
| \P{Name} | Any character not in the Name class |

Table 3.15 The Regexp Package’s Zero-Width Assertions

| Syntax | Description/result |
| --- | --- |
| ^ | Start of text (or start of line if flag m is set) |
| $ | End of text (or end of line if flag m is set) |
| \A | Start of text |
| \z | End of text |
| \b | Word boundary (w followed by W or A or \z; or versa) |
| \B | Not a word boundary |
