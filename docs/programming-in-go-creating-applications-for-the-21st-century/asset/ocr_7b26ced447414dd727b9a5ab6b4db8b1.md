```
func (fuzzy *FuzzyBool) Equal(other *FuzzyBool) bool {
  return fuzzy.value == other.value
}
```

These two methods allow us to compare fuzzy Booleans in terms of the float32s they contain; both produce boolean results.

```
func (fuzzy *FuzzyBool) Bool() bool {
  return fuzzy.value >= .5
}

func (fuzzy *FuzzyBool) Float() float64 {
  return float64(fuzzy.value)
}
```

fuzzybool.New() construction function can be seen as a conversion function since given a float32, 64, int, or bool, it produces a *FuzzyBool. These two methods perform similar conversions going the other way.

The FuzzyBool type provides a complete Boolean data type that can be used like any other custom data type. So, *FuzzyBool may be stored in slices, and in maps as keys or values of both. Or, if we use *FuzzyBool as keys we will be able to store multiple fuzzy Booleans even if they have the same value because each will have a unique address. One solution is to use a value-based FuzzyBool (such as the fuzzy value example in the book's source code). Alternatively, we could use a custom collection type that stored pointers but uses their values for comparisons: The custom map can map to this, providing a suitable less than function (6.5.3, ► 302).

In addition to the fuzzy Boolean type shown in this subsection, the book examples includes three alternative fuzzy Boolean implementations for comparison: These are not shown in the book or discussed beyond this paragraph. The first alternatives are in the files fuzzybool/fuzzybool.go and fuzzy_mutable/fuzzybool.go—they have exactly the same functionality as the version described in this subsection (in file fuzzybool/fuzzy-go). The fuzzy value works in terms of Fuzzy Boolean values rather than *FuzzyBools, and the fuzzy mutable version is based directly on a float32 rather than a struct. The fuzzy mutable version's code is slightly longer and trickier than the struct-based version shown here. The third alternative provides slightly less functionality because it provides an immutable fuzzy Boolean type. Again, it is directly based on a float32; this version is in file immutable/fuzzy-bool/fuzzybool.go. It is the simplest of the three implementations.
