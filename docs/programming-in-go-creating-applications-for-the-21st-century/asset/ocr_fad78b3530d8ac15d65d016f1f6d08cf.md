+   Write a program called, my_linkcheck which accepts a single URL on the command line (with or without the http:// prefix), and checks that every link is valid. The program should work recursively, checking every linked-to page—excluding non-HTTP links, non-HTML files, and to external sites. Every page that is checked in a separate goroutine—this will result in many concurrent network accesses, which will be much faster than doing each sequentially. Normally, the same links will be present on different pages and such links should only be checked once. The program should, of course, use the my_linkutil package developed in the exercise.

A solution is given in linkcheck/linkcheck.go and is around 150 lines. To avoiding duplicate links the solution keeps a map of the URLs it has The map is kept inside a separate goroutine and three channels—one to add a URL, one to query whether a URL has been seen, and one to respond to the query. (An alternative would be to use the semap from Chapter 7.)
