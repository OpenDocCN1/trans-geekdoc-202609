One way to get started is to copy the statistics application's main(), tabPage(), and processRequest() functions, modifying them to call three new custom functions—formatQuestion(), solve(), and formatSolutions()—and heavily modifying processRequest() to read in three separate initial application of floating-point numbers. The file quadratic ans1/quadratic.go contains an initial application of about 120 lines. This version is smart enough to make by putting just one solution if both solutions are approximately equal by making use of the EqualFloat() function discussed earlier in the chapter (68).

A second application is in file quadratic2/quadratic.go, this runs to about 160 lines and is much smarter about how it formats the output. For example, it replaces “+.” with “-” and “1x” with “x”, suppresses zero components (e.g., eliminates “0x”), and formats a solution as a floating-point number if the imaginary part is approximately zero. It makes use of some math/complex package functions such as cmplx.NaN(), and more advanced string formatting ($3.5). 93.
