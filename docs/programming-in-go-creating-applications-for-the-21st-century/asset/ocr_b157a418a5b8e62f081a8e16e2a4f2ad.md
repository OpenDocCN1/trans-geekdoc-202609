# 3.8. Exercises

get the skeleton of the application up and running, and then just focus on the soundex and test page functionality.

A solution is in the file soundex/soundex.go and is about 150 lines; the soundex() function itself is 20 lines although it does rely on an int[] The solution's algorithm is based on the Python implementation shown on the Rosetta Code web site (rosettacode.org/wiki/Soundex) which produces slightly different results to the Go implementation shown on that site and from the one shown on Wikipedia (en.wikipedia.org/wiki/Soundex). The test data is in the file soundex/test-data.txt.

Naturally, readers are free to implement whichever version of the more advanced algorithm they prefer—or even implement as one of the Metaphone algorithms—and simply adjust the tests to match.
