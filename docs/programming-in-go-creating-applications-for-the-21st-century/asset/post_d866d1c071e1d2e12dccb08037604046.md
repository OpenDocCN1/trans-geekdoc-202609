The strings.FieldsFunc() function takes a string (the record variable in this example) and a reference to a function with the signature func(rune) bool. Since the function is tiny and is used only in one place, we created it as an anonymous function at the point it is. (Functions created this way are closures, in this particular case make no use of the enclosed state; 5.6.3, ➤ 225.) The strings.FieldsFunc() function iterates over every character in the string it is given and calls the function it passed as its second argument with each character. If the called function returns true a split is performed. Here we have said that the string should be split on tabs, stars, and vertical bars. (Go's switch statement is covered in 5.2.2, ➤ 195.)

We can replace occurrences of a string using the strings.Replace() function. For example:

```
names = "António\tAndré\tFriedrich\t\tjean\tÉlisabeth\tIsabella \t"
names = strings.Replace(names, "\t", " ", -1)
fmt.Printf("%s\n", names)
```

| António André Friedrich...Jean Élisabeth Isabella... |

The strings.Replace() function takes a string to work on, a replacement string, and the number of replacements to make (-1 meaning as many as possible), and returns a string with all the (nonoverlapping) replacements-performed.

When reading a string that has been entered by a human or has come from an external source we often want to normalize its whitespace: that is, to get rid of any leading and trailing whitespace and replace each internal sequence of one or more characters with a single space.

```
fmt.Printf("%s\n", SimpleSimplifyWhitespace(names))
```

|António André Friedrich Jean Élisabeth Isabella|

Here is a one-line SimpleSimplifyWhitespace() function.

```go
func SimpleSimplifyWhitespace(s string) string {
    return strings.Join(strings.Fields(strings.TrimSpace(s)), " ")
}
```

The strings.TrimSpace() function returns a copy of the string it is passed with any leading and trailing whitespace stripped off. The strings.Fields() function splits a string on any amount of whitespace and returns a []string. And the strings.Join() function takes a []string and a separator (which could be an empty string, although here we have a space), and returns a single string with all the []string's strings joined by the separator. By using these three functions in this combination we get whitespace normalization.

Of course, we can more efficiently simplify whitespace doing a single pass using bytes.Buffer.

```go
func SimplifyWhitespace(s string) string {
    var buffer bytes.Buffer
    skip := true
    for _, char := range s {
        if unicode.IsSpace(char) {
            if !skip {
                buffer.WriteRune(' ')
                skip = true
            }
        } else {
            buffer.WriteRune(char)
            skip = false
        }
    }
    s = buffer.String()
    if skip && len(s) > 0 {
        s = s[:len(s)-1]
    }
    return s
}
```

The SimplifyWhitespace() function iterates over the characters in the string it receives, skipping any leading whitespace using the unicode.IsSpace() function (Table 3.11., ➤ 119). It accumulates characters by writing them into bytes.Buffer and for any sequence of one or more internal whitespaces it writes a single space. At the end any trailing space is stripped off (the algorithm allows at most one), and the result string is returned. A simpler version using regular expressions is shown later ➤ 128.

The strings.Map() function can be used to replace or remove characters from strings. It takes two arguments, the first the mapping function and the second the string. The strings.Map() function iterates over each character in the string and calls the mapping function for each character. If the function returns a negative value, the character is dropped. If it returns a positive value, the character is replaced. If it returns the same value, the character is unchanged.

```go
result := strings.Map(func(r rune) rune {
    if r == 'a' {
        return 'A'
    }
    return r
}, "apple")
fmt.Println(result) // Apple
```

The strings.Replace() function can be used to replace all occurrences of a substring with another string. It takes the string, the substring to find, the replacement string, and the number of replacements to make. If the number is -1, all occurrences are replaced.

```go
result := strings.Replace("hello world", "world", "go", 1)
fmt.Println(result) // hello go
```

The strings.ReplaceAll() function is a convenience for replacing all occurrences of a substring with another string. It takes the string, the substring to find, and the replacement string as arguments.

```go
reader := strings.NewReader("Café")
for i := 0; i < 4; i++ {
    char, size, err := reader.ReadRune()
    if err != nil {
        if err == io.EOF {
            break
        }
        panic(err)
    }
    fmt.Printf("%U %c %d: %X\n", char, char, size, []byte(char))
}
