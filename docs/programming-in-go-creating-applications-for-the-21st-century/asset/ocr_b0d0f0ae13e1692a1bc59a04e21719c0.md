# Table 3.5 The Fmt Package's Verb Modifiers

| Modifier | Description/result |
|---|---|n| space | Makes the verb output "-" before negative numbers and a space before positive numbers between the bytes printed using the %x or %X verbs; e.g., fmt.Printf("%X", "-") outputs 82 96 |
| # | Makes the verb output an "alternative" output format:
%%o outputs octal with a leading 0
%%p outputs a pointer without the leading 0
%%q outputs a string or |byte] as a raw string (using backticks) if possible--otherwise a double-quoted string
%%v outputs a value as itself using Go syntax
%%x outputs hexadecimal with a leading 0
%%X outputs hexadecimal with a leading 0 |
| + | Makes the verb output + or - for numbers, ASCII characters (with others escaped) |
| 0 | Makes the verb left-justify the value (the default is to right-justify)
Makes the verb pad leading with os instead of spaces |
| n.m .m | For numbers, makes the verb output a floating-point or complex value using n (of type int) characters (or if necessary to avoid truncation) and with m (of type int) digits the decimal point.
For strings n specifies the minimum field width, and will result in padding if the string has too characters, and m specifies the maximum number of string's characters to use (going from left to right), and will result in the string truncated if it is too long.
Either or m and n can be replaced with * in which case their values are taken from the arguments.
Either nor .m may be omitted. |

```
type polar struct{radius, theta float64}
p := polar{8.32, .49}
fmt.Printf(-18.5, 17, "Elephant", -8.7i, 0x3C7, "\u03C7", "a", "b", p)
fmt.Println()
fmt.Println(-18.5, 17, "Elephant", -8.7i, 0x3C7, "\u03C7", "a", "b", p)
```

For the sake of clarity, particularly when multiple consecutive sequences are output, we have put a light gray character ( ) in the middle of every space shown.
