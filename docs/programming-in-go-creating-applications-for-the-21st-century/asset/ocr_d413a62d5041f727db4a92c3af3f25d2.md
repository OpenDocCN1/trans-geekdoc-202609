# 4.3. Maps

**Table 4.3** Map Operations

| Syntax | Description/result |
| --- | --- |
| m[k] = v | Assigns v to map under key k; if k is already in the map its previous value is discarded | |
| delete(m, k) | Deletes k and its associated value from map m, or safely does nothing |
| v := m[k] | Retrieves the value that corresponds to map m's key and assigns it to v; or assigns the zero value for the value's type v, if k isn't in the map |
| v, found := m[k] | Retrieves the value that corresponds to map m's key and assigns it to v and true to found; or the zero value for the value's type to v and false to found, if k isn't in the map |
| len(m) | The number of items (key–value pairs) in map m |

Maps are created using the syntaxes:

```
make(map[KeyType]ValueType, initialCapacity)
make(map[KeyType]ValueType)
map[KeyType]ValueType{key1:value1, key2:value2, ..., keyN:valueN}
```

The built-in make() function is used to create slices, maps, and channels. When used to create a map it creates an empty map, and if the optional initialCapacity is specified, the map is initialized to have enough space for number of items.
