# 2.4.2. Implementing a Basic HTTP Server

The statistics program provides a single web page on the local host. Here is its main() function.

```
func main() {
	http.HandleFunc("/
```

The http.HandleFunc() function takes two arguments: a path and a function to call when that is requested. The function must have the signature func(http.ResponseWriter, *http.Request). We can register as many path-function pairs as we like. Here we registered the path (i.e., the web application's home page) with a custom homePage() function.

The http.ListenAndServe() function starts up a web server at given TCP network address; here we used localhost and port number 9001. The local host is assumed if only the port number is given—we could as easily have used an address of "localhost:9001" or "127.0.0.1:9001". (The port number we have chosen is arbitrary—simply change the code to use a different one if it conflicts with an existing server.) The second argument is used to specify which kind of server to use—normally we pass nil to indicate that we want to use the default kind.
