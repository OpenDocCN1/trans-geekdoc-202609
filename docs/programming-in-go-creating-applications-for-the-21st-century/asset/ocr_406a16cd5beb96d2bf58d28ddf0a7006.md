The grouping separators are inserted from right to left in the whole string and then a - is added if the number is negative. At the end we concatenate the whole and fractional parts and return the result—padding if required.

The %e, %E, %f, %g, and % verbs can be used with complex numbers as well as floating-point numbers. The %e and %E are the scientific format (exponential) verbs, %f is the floating-point verb, and %g and %G are the general floating-point verbs.

One factor to keep in mind, though, is that the modifiers are applied to both the real and imaginary parts of complex numbers individually—for example, a format of %6f will produce a result occupying up to 20 characters if the argument is a complex number.

```
for _, x := range [complex128{2 + 3i, 172.6 - 58.3019i, -.827e+2 + 9.40831e-03}]
	fmt.Printf("%15s%%3f%%2f%%1e\n",
	fmt.Printf(\%%6.2f+%3f", real(x), imag(x)), x, x, x)
```

To achieve this we formatted the real and imaginary parts using fmt.Sprintf(), and then output the result formatted as a string using a format of %15s. For the other columns we used the %f and %g verbs directly—these always parenthesized around complex numbers.
