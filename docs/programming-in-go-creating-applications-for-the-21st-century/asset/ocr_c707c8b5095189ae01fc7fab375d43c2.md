# 8.1.2. Reading XML Files

Reading XML files is slightly more involved than writing, especially if we have to parse some fields (such as dates); but it isn't difficult if we use suitable XML-tagged structs.

```
func (XMLMarshaller) UnmarshalInvoices(reader io.Reader) ([]*Invoice,
error) {
xmlInvoices := &XMLInvoices{
decoder := xml.NewDecoder(reader)
if err := decoder.Decode(xmlInvoices); err != nil {
return nil, err
}
if xmlInvoices.Version > fileVersion {
return nil, fmt.Errorf("version %d is too new to read",
xmlInvoices.Version)
}
return xmlInvoices, nil
}

The method begins by creating a pointer to an empty XMLInvoices struct and an xml.Decoder for reading the io.Reader. The entire XML file is then parsed by the xml.Decoder.Decode() method, and if the parse is successful the XMLInvoices struct is populated with the XML file's data.
