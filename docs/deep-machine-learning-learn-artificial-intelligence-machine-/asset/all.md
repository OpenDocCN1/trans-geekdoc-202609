Once the feature map is created, you will be able to pass each value through the process of nonlinearity. The concept of applying this convolutional operation to the image data is nothing new for convolutional neural networks. It has already been implemented in computer vision technology. Computer vision experts design filters by hand,  which are then applied to a particular image inside of a feature map. Convolutional neural networks don’t usually learn by a single filter. Multiple features run in parallel for specific input. It is quite common for the convolutional layer to educate itself from 32 to 512 filters in parallel for a certain input. Color images consist of more than one channel for each color channel like red, blue, and green. From a data perspective, it means that a single image that is fed as input to a model is in reality a combination of three images. A filter ought to have the same number of channels as the input has. This is often referred to as the depth of the convolutional neural network. If the image you are feeding to the model as input consists of three models, then you need to apply a filter to the image that also has three channels. If a convolutional layer consists of 32 filters, they are not just 2D but they also are in 3D form. Each of these filters results in one feature map. This means that the depth of the output of a particular convolutional layer that has 32 filters is 32. Convolutional layers not only are applied to the input data but they are also applied to the output of each layer. When you stack up the layers, it shapes up a hierarchical decomposition of your input. Consider the fact that the filters will gradually learn the extraction process of features such as lines.
