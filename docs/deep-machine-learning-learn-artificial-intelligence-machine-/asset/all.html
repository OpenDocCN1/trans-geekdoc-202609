Python Classes
A class in Python acts like a prototype which helps programmers build objects from scratch. They provide the way for pairing up functionality and data. Whenever you build a new class, you are building an object which can be anything from a human to an animal and a bird or any other artificial object. I will explain in detail the concept of adding instances to a class which, in simple words, give your object a kind of spirit. Each class instance can be filled with python methods as well.
Python classes create a data structure which contains data members and different functions. You can assess them and use them by building an instance inside the class. The most important thing in classes, just like in other features of python, is that you cannot use class to name a class because it is a designated python keyword. Spare it for good. You can use different attributes that belong to classes. Each instance in a python class represents an object. You can say that a class is original while an instance is its copy but has real values.
A class object may have its unique identity. It may show some behavioral traits. When you create an object, the process is dubbed as instantiation. You can add as many instances to a Python class as you like.
You will find in the code a parameter namely self. It is an extra parameter which doesn’t need a value. Python has already defined its value, which makes it similar to other programming languages such as Java and C++.
In the next code example, you will see a class namely Peacock. The peacock is a model of a real life object. I will assign it a name and an age. You can change the name and the figure to develop a unique object of your own choice. You can even change the name of the class. For example, you can name it as a Beaver or an Eagle. My peacock will show you how to stand and fly away when fed with certain instructions. The behaviors can be anything like rolling on the ground, running in the wild or feeding itself. Deep learning educates computers to do the chores that humans do naturally. Deep learning systems stand out to be efficient because, just like humans, they learn by following an example. How Deep Learning Differs From Traditional Models
Deep learning models are considered superior because they are stacked hierarchically. On the other hand, traditional machine learning algorithms are linear. The computer programs that are backed by deep learning models go through a similar process like the one the toddler’s brain has gone through. Mathematical Terms Explained
If you want to understand deep learning techniques, you should be familiar with different mathematical concepts such as gradient descent, tensors, differentiation, and tensor operations. You must know that the data it stores is numerical.
Scaler
Some matrices are 2D tensors. A dimension is also known as an axis. If a tensor only contains one number, it is known as a scale or scaler tensor. It also is called a 0D tensor. Float 64 and float 32 in Numpy library are known as scalar tensors. A scalar tensor doesn’t have any axes. The number of axes in a tensor is also labeled as a rank.
Vectors
An array of multiple numbers is labeled as a vector. Some also call it 1D tensor. As apparent from its name, it contains a single axis. If a vector has five entries, it will be labeled as a 5-dimensional vector. Keep in mind that a 5D vector is not the same as a 5D tensor. The basic difference is that a 5D vector has five dimensions along the axis while a 5D tensor has a total of five axes. It may different number of dimensions along their axes. Dimensionality either shows the number of axes within a tensor or the number of entries about a single axis.
Matrices
An array that contains vectors is known as a matrix. Its other name is a 2D tensor. Two axes are often referred to as columns and rows and you can define the matrix as a rectangular grid of numbers. The entries in the first axis are known as rows while those in the second axis are known as columns.
3D Tensors
If you pack up different matrices in the form of a new array, you will obtain a 3D tensor, which you will be able to interpret as a cube of numbers. If you pack 3D tensors inside of an array, you will be able to create a 4D tensor. That’s how it goes on.
Three key attributes generally define a tensor. The first is the number of axes. For example, a 3D tensor might have three axes while a matrix possesses two axes. This is also known as the ndim of a tensor in Numpy. The shape of a tensor is a sort of a tuple of integers that describe how many dimensions each tensor has along a certain axis. Then there is a data type that is denoted by dtype symbol in Python libraries. This is a particular type of data that is contained in a tensor. A tensor’s type can be unit8, float64, and float32. You may also see a char tensor as well on certain occasions. You must take note that there is hardly any existence of string tensors.

Convolutional Neural Networks
Convolutional layers are considered the key building blocks of convolutional neural networks or CNN. A convolution is the simplest application of a filter to get an input that would result in a kind of activation. Recurrent application of a filter yields a map of activations that are called a feature map. This indicates the exact locations and the strengths of a certain feature in the input. This can be an image.
Why convolutional neural networks differ from simple neural networks is from the fact that they can learn by themselves about different filters that are specific to a particular training dataset within the constraints of a particular modeling problem like the classification of images. The result is highly specific features that you can detect anywhere.
A convolutional neural network is known as a specialized kind of neural network model that is specifically designed to work with two-dimensional data. However, they also can be used with three-dimensional and two-dimensional data-types. The core of a convolutional neural network is the convolutional layer which gives this network its peculiar name. This particular layer would like to perform a specific operation popularly known as a convolution.
It is a kind of linear operation that includes multiplication of weights with the input you feed to the network. Here it acts just like a traditional network. This technique was particularly designed for 2D input. The filter in the convolutional neural networks is smaller than the size of the input data. There is a dot product in convolutional neural networks which is an element-wise multiplication process between the filter and input. Their sum is drawn which always yields a single value. The full operation can be referred to as a scalar product.
If you use a filter that is smaller in size than the input, it would allow the filter to go through the process of multiplication by the input array at more than one point. The filter is systematically applied to different overlapping parts of the input data. If you have designed the filter to spot a particular feature inside the input, the application of the same filter across the input image gives filter the power to find the same feature at any point in the same image. It can be said that the filter takes that feature as a reference point to detect it at other places in the image. This makes convolutional neural networks highly precise and trustworthy. The output from the multiplication of the filter with an input array will be a single value. As the filter runs through the process of multiplication more than once, the result will be a 2D array, containing the output values. The array is also known as a feature map.
Once the feature map is created, you will be able to pass each value through the process of nonlinearity.
The concept of applying this convolutional operation to the image data is nothing new for convolutional neural networks. It has already been implemented in computer vision technology. Computer vision experts design filters by hand,  which are then applied to a particular image inside of a feature map.
Convolutional neural networks don’t usually learn by a single filter. Multiple features run in parallel for specific input. It is quite common for the convolutional layer to educate itself from 32 to 512 filters in parallel for a certain input.
Color images consist of more than one channel for each color channel like red, blue, and green. From a data perspective, it means that a single image that is fed as input to a model is in reality a combination of three images. A filter ought to have the same number of channels as the input has. This is often referred to as the depth of the convolutional neural network. If the image you are feeding to the model as input consists of three models, then you need to apply a filter to the image that also has three channels. If a convolutional layer consists of 32 filters, they are not just 2D but they also are in 3D form. Each of these filters results in one feature map. This means that the depth of the output of a particular convolutional layer that has 32 filters is 32.
Convolutional layers not only are applied to the input data but they are also applied to the output of each layer. When you stack up the layers, it shapes up a hierarchical decomposition of your input. Consider the fact that the filters will gradually learn the extraction process of features such as lines. The filters that generally operate on the output of each layer may extract different features that form the combinations of certain low-level features that contain more than one line to express different types of shapes. The process carries one until ultra-deep layers start extracting animals, faces, houses, etc.
