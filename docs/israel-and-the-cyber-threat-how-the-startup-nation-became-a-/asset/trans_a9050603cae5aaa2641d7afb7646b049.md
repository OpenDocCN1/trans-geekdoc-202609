
2013年至2017年间，伊朗黑客对320所大学的计算机系统发动了网络入侵行动，其中大部分位于美国，也包括以色列和其他国家。总体而言，黑客针对超过10万名学者的账户，其中约8000个被成功攻破，并窃取了大量数据和知识产权。[^(87)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-609) 2018年，又发现了一起针对美国、以色列及其他地区76所大学的攻击。攻击者再次试图窃取未发表的研究成果并获取知识产权。[^(88)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-610)

在始于2014年或可能早在2011年的 Thamar Reservoir 攻击中，据报道伊朗黑客使用了定向钓鱼和社会工程技术，例如伪造网站和社交媒体上的虚假消息，来诱使目标安装恶意软件。[^(89)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-611) 在此情况下，黑客试图获取退休以色列将军、国防咨询公司和学者的社交媒体和电子邮件账户访问权限，并发送伪装在 Word 和 Excel 文件中的恶意软件附件。该恶意软件包含“keyloggers”，即一种计算机代码，使黑客能够记录用户每次按键、截取屏幕截图并复制文件，而用户全然不知。[^(90)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-612)

自2014年起，Rocket Kittens 反复针对以色列学术机构、国防承包商等，以及中东其他地区的目标。在多起案例中，Rocket Kittens 冒充以色列工程师，包括一位特别知名的人物，以为攻击提供合法性并提高目标下载感染恶意软件的可能性。使用了多种技术，例如 Facebook 和 SMS 消息以及定向钓鱼电子邮件。这些攻击并不十分复杂，且包含容易识别的错误，但以其持续性著称。实际上，攻击者试图简单地用攻击淹没目标，直到有人最终犯错并下载恶意软件。[^(91)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-613)

2015年，一名身份不明的攻击者，据推测与伊朗或可能是真主党有关，向国防部官员发送了包含“keyloggers”的电子邮件。这些被感染的消息被少数员工打开，使攻击者成功访问了该部的非保密网络，但未进入其保密网络，而该部的网络安全部门能够迅速遏制攻击。[^(92)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-614)

2017年，Copy Kittens 发动了 Operation Wilted Tulip 行动，冒充总理办公室和以色列新闻网站，针对驻外以色列使馆和以色列境内的外国使馆。该组织谨慎地使用主要位于伊朗境外的基础设施，位于美国、俄罗斯和荷兰。[^(93)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-615)

2017年，Oil Rig 黑客组织伪装成一家知名以色列软件公司，并使用伪造的安全证书向120个以色列政府机构、学术机构、计算机公司和个人发送恶意电子邮件。此次钓鱼攻击利用 Microsoft Word 中的漏洞获取目标计算机网络的地址列表，随后用于进一步传播攻击。[^(94)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-616) Oil Rig 还对至少五家以色列 IT 供应商、几家金融机构和以色列邮政进行了攻击。在一例中，它设立了伪造网站，声称是牛津大学会议的注册页面和求职申请网站。在另一例中，攻击者克隆了以色列航空公司 IsraAir 的网站，并向目标发送了恶意 Excel 文件。[^(95)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-617)

据报道，2018年伊朗黑客针对以色列核科学家，试图获取敏感材料。黑客作为钓鱼诈骗的一部分，向科学家发送电子邮件，其中包含指向一个伪造的英国新闻机构的链接。[^(96)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-618) 根据另一份报告，当时有11个不同的 IRGC 黑客组织几乎每天都在对以色列核研究人员发动攻击。[^(97)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-619)

2020年，伊朗黑客冒充阿莫斯·亚德林将军，他曾任军事情报部门负责人，当时是 INSS，以色列最重要的战略事务智库的负责人。此次攻击表现为来自疑似亚德林个人 WhatsApp 号码的请求，要求另一家研究所的学者对一份尚未发表且攻击者显然已秘密获取的 INSS 研究发表评论。[^(98)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-620)

2019年，伊朗 CNE 攻击出现了危险的变化。一个由伊朗领导的、设在叙利亚的组织使用 Facebook 和消息应用程序试图在以色列招募特工，显然是在为恐怖袭击做准备。大多数以色列目标变得怀疑并切断了联系。据报道，伊朗当时也在幕后策划真主党和哈马斯利用互联网招募以色列阿拉伯人和巴勒斯坦人从事以色列境内的恐怖主义和情报收集活动。[^(99)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-621)

2021年，伊朗情报机构使用 Instagram 账户，冒充有吸引力的女性，试图诱骗以色列商人赴海外会面，名义上是商务和/或浪漫目的，实际上是设下陷阱以伤害或绑架他们。[^(100)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-622) 同年，一项与伊朗有关的行动从全球航空航天和电信公司窃取了大量关于以色列以及中东、美国、欧洲和俄罗斯其他目标的数据。这项高度针对性的行动显然至少始于三年前，通过使用一种此前未被发现的 Remote Access Trojan，该木马可规避防病毒工具和其他安全措施，从而成功地保持隐蔽。[^(101)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-623)

一名伊朗情报官员冒充“伊朗犹太人”，使用 Facebook 和 WhatsApp 招募五名贫困的、具有波斯血统的以色列妇女为伊朗完成任务以换取金钱。在其他任务中，两名妇女被指示鼓励她们的儿子加入情报部队，一名被告知收集高级国防官员的情报，还有一名被告知如何为她所联系的一名议会议员制造一个具有性 compromising 的情况。她们还被指示拍摄并收集一份目标名单的信息，这些信息可能有助于实施未来的恐怖袭击。参与该行动的部分妇女，该行动于2021年公开披露，已与她们的伊朗控制者联系多年。[^(102)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-624)
