
# 以色列的国家文化与以色列国防军网络创新

## 国家文化特征

此外，由于其早年发展的性质，以色列的国家文化历来极度非等级化且极不正式。基布兹（农业公社）和社会主义的时代可能早已过去，但创始人所确立的平等主义规范仍然保留，以色列因此被恰当地称为“ relentlessly informal nation”，或用更学术的术语来说，是“小权力距离社会”，其中正式等级制度几乎不受重视。[^(106)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-911) 这些国家属性是全球研发和高科技企业中通常所见的商业文化的特征。它们非正式、扁平的等级结构以及为实现协作目标而需要自由开放地交流思想，与基布兹文化极为相似。

以色列文化进一步将发达的群体导向和为追求集体目标而行动的意愿与强烈的个人主义结合在一起。[^(107)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-912) 与此相关，并且再次部分是由于以色列的战略环境所致，政府、私营和国防部门更愿意以比大多数其他民主国家更为紧密的合作方式共同工作。

## 以色列国防军文化与网络创新

除了前面所述的基本国家特征外，几代以色列国防军士兵都接受了以色列国防军的组织文化灌输，该文化强调在极具挑战性的期限和环境下努力工作、坚韧、奉献、专业精神和团队合作。[^(108)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-913) 与其他军队一样，以色列国防军高度以任务为导向，但在对创造力和即兴发挥的重视上有所不同，这种重视不亚于源自军衔或教育的正式权威。

以色列国防军军官甚至新兵都被鼓励创造性地思考，跳出框框思考，并即兴发挥以最好地实现目标，而不是盲目地遵循自上而下的命令，即使这意味着违反规则。至少以军事组织的标准来看，以色列国防军是非正式的、灵活的、非等级化的，对争论和冒险具有不寻常的宽容度。[^(109)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-914) 事实上，以色列国防军的传统颂扬那些主动采取行动、即兴发挥、解决问题而不是按部就班的军官。那些不善于即兴发挥的军官通常被认为缺乏主动性、自信心和决心。这种不合常规的军事文化进一步得到预备役人员无处不在的存在的强化，他们在以色列国防军各单位和各层级中几乎不尊重军衔。[^(110)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-915)

以色列国防军军官在所有层级都被期望在与上级意见不合时有力地表达自己的观点，并在最终决定作出之前继续这样做。低级军官被期望向其上级提出自己的观点，高级军官则向参谋长提出，而参谋长又被期望向总理提出自己的观点。[^(111)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-916) 下面的场景比这更好地说明了这一点，该场景发生在1993年签署奥斯陆协定前几分钟的白宫内，正如在场的美国人之一所描述的：

以色列国防军中央司令部司令伊兰·比兰进入了克林顿总统的办公室，并与拉宾总理展开了激烈的争论。司令官认为拉宾绝不能同意新的部署线……拉宾与将军展开了长时间、激烈的争论，而我们其他人，包括总统，都不得不等待……我们感到震惊。在我们最疯狂的想象中，我们也无法想象总理与其一名将军之间会发生这样的情况。而且这一切都在白宫，在总统面前发生。[^(112)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-917)

### 第8200部队与第81部队

据报道，第8200部队的组织文化类似于一家初创公司，并且鼓励挑战权威。“我们教他们如何跳出框框工作，”一位前高级军官说。[^(113)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-918) 第81部队则更为极端。该部队的大多数士兵都不穿制服，基地看起来不像军事设施，退伍军人提到了一种自由感、“balagan”（混乱），以及对知识和个人魅力的强调，而非军衔。[^(114)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-919)

第81部队本质上是情报界的承包商。分配给它的任务起初通常看起来不可能，但一些退伍军人认为它们是他们后来在民间生活中取得成功的来源。[^(115)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-920) 根据一位退伍军人的说法：

我们每次本质上所做的是建立一家初创公司……我们用有限的预算在一天中的任何时间解决问题……在人们的生命处于危险之中的理解下。你只有一次机会，不能失败……该部队的座右铭[^(§§)](#21_chapter9.xhtml#oso-9780197677711-chapter-9-note-27)听起来可能像是一句口号，但它是真实的——如果你真正理解一个问题和局限性，你就能解决任何问题。后来在商业世界中，它改变了你看待事物的方式……以及提供精确解决方案以满足需求并进行测试以确保其始终如一地发挥作用的重要性。[^(116)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-921)

以色列国家网络防御局前负责人伊加尔·乌纳强调，以色列国防军给予士兵“不仅在网络领域为国家做有趣事情的许可，而且还训练他们做到一件事：不要害怕，尝试，承担风险，经历失败。”[^(117)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-922) 以色列国防军网络防御课程负责人表示，士兵们被教导“不同地思考，寻找那些不太明显的东西，在人们通常不会寻找的地方寻找。他们必须在互联网上寻找人们极力隐藏的东西。如果我们像其他人一样搜索，我们就找不到它们。”[^(118)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-923) 第81部队前指挥官以类似的说法描述了其招募和培训计划：

当士兵被招募时，重点不一定在于他们对计算机或电子学的知识。我们正在寻找能够跳出框框思考的人，但也能与具有类似特质的人合作……我们不会要求候选人编写代码，而是给他们一个复杂的问题来解决，以便检查他们如何提出解决方案。[^(119)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-924)

### 共同的军事经历与民用高科技

共同的军事经历进一步培养了强烈的群体凝聚力以及在民间生活中继续合作的愿望，这也是以色列许多高科技公司由8200和81等部队退伍军人创立并配备的人员的原因之一。离开第81部队后，据一位退伍军人说，“你意识到到那时为止，你与最有才华的人一起做了你一生中最疯狂的事情，你希望将其延伸到民间生活。”第81部队前指挥官观察到，仍在服兵役的士兵“看到退伍军人做得很好，不想成为拿薪水的开发者，而是要开辟新道路，因为那种驱动力已经植入他们心中。”[^(120)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-925)
