
后门是指行为者通过绕过现有安全措施来获取网络或计算机访问权限的一种方式。攻击者要么发现现有代码中的漏洞从而允许未经授权的访问，要么上传创建后门的恶意软件。一旦进入内部，攻击者可以利用后门窃取信息、监视网络、向网络植入恶意软件，甚至完全控制设备。一旦攻击者发现了后门，他们通常会试图保持其存在的隐秘性，以免被察觉。[^(15)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1392)

## 跨站脚本 (XSS)

XSS 是一种脚本注入攻击形式，其中恶意脚本，通常称为恶意负载，被注入到合法的网站或 Web 应用程序中。通过网站或 Web 应用程序的漏洞，恶意负载随后可被传递到网站访客和 Web 应用程序用户的浏览器中。XSS 是最普遍的网站安全威胁之一，最广泛使用的媒介是 JavaScript，除此之外还有 VBScript、ActiveX 和 Flash。[^(16)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1393) 存在三种主要类型的 XSS 攻击。

## 密码破解

有许多方法可以让攻击者发现其受害者的密码并用其访问私人信息。其中包括：
**暴力破解攻击**，即黑客使用脚本或程序尝试常用密码，例如“password”、“Password123”等，直到有一个生效为止。
**字典攻击**，即黑客使用脚本或程序循环遍历字典中的单词组合。程序只尝试最有可能成功的组合，这种方法利用了大多数人选择短（少于 7 个字符）由一个或两个单词组成的密码这一事实。
**键盘记录攻击**是一种恶意软件，记录用户所做的每个按键并将该数据导出给攻击者。它用于窃取用户在目标机器上输入的任何信息，包括密码等。它比暴力破解或字典攻击更危险，因为更强的密码也无法防御它。[^(17)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1394)
**多因素认证（MFA，或另称 2FA——双因素认证）**是一种网络防御机制，要求用户不仅提供密码，还需提供第二重安全因素。这样的设置使入侵计算机或网络变得困难得多。

## 高级持续性威胁 (APT)

APT 攻击包括在未经受害者知晓的情况下获得对系统或网络的未经授权的访问并在其中长期潜伏。正如其名称所示，APT 通常结合多种高级攻击类型，包括本文讨论的那些，分多个阶段实施以避免被检测并最大化攻击持续时间。APT 极其危险，因为它们可以“躲避”传统网络安全措施的雷达，并在长期内窃取大量数据。
APT 攻击可以与其他类型攻击具有相同的目标。有些旨在窃取数据，有些旨在破坏正常功能和运行；甚至可能旨在破坏基础设施。主要区别在于，对于 APT 来说，其目标是在数月甚至数年的时间内实现，而不是立即实现。这加剧了这些攻击的危险，因为其影响是持续的而非时间有限的。
APT 攻击的恶意软件是针对特定目标设计和定制的。APT 攻击对企业和政府都构成巨大威胁，因为它们高度复杂，并且专门针对目标系统的安全机制进行定制（与针对多种不同目标的常见病毒相对）。[^(18)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1395)

## 零日漏洞利用

零日（或零时或零日）漏洞利用是一种网络攻击，利用计算机系统或网络中尚无补丁的安全漏洞。零日漏洞利用攻击软件或硬件开发者尚不了解的漏洞，因此尚未能够修复。因此，此类攻击极难检测。一旦漏洞或攻击被发现，开发者即可迅速修补，但在那之前，零日漏洞利用可被攻击者用来对计算机或网络造成严重损害。[^(19)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1396)
