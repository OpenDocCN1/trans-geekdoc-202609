
# 国家网络战略提案

任何领域的国家战略提案都涉及诸多潜在的考量和陷阱。首先，战略与特定的时间框架和假设相关。网络领域的变革速度极其惊人，在以色列的案例中，这一速度因中东环境持续而剧烈变化而进一步放大。在这种情况下，期望制定一个有效期远超数年的战略是不明智的。反之，一个经不起时间考验的战略几乎不能称之为战略。因此，我们建议制定一个约五年的战略，并进行定期的中期评估和校准，这适合以色列民用和国家安全网络领域的紧迫需求。

第二个考量是，所提议的战略构成了一套广泛的原则，旨在为未来的规划和决策提供指导。它不是，也并不声称是适用于所有未来情景的详细行动蓝图。正式的战略旨在利用其制定过程中的智力严谨性，以便更好地完善目标、优先事项及其实现途径，从而在适当时机丰富决策者的思考。网络领域独特、仍相对新颖且看似不透明的特性，使得制定连贯且全面的应对战略具有特别重要的意义。

第三个考量是政治可行性。如果一个战略在政治上不可行，它可能仍具有理论上的兴趣，但不能构成现实政策制定的基础。我们认为本文提出的战略并不具有政治分裂性，应为所有以色列政府所接受，无论其政治倾向如何。这并非意味着每项建议都会被接受，而是辩论应主要具有实质性，而非党派性。

第四点考量是，部分建议是有意不具原创性的，因为它们在过去已被他人提出。以色列和其他国家在网络领域面临的挑战对熟悉其变幻莫测的人来说并不陌生；各方专家已发表意见，我们很幸运能够借鉴他们的工作。正是将基于对以色列情况和需求的系统分析而形成的既有智慧，与我们自己的原创贡献相结合，才使得这些建议成为首次提出全面以色列国家网络战略的尝试。

最后，部分必要信息不可用，无论是因为其属于机密还是其他原因。这种限制是所有研究人员生活中的现实，尤其适用于军事事务。我们相信这些建议不会被认为过于不足。

## 章节结构与战略支柱

本章首先定义以色列的总体国家安全目标，作为民用和国家安全网络领域拟议目标的基础。所推荐的网络战略本身分为六个概念支柱：

1. 战略、原则与资源
2. 治理与指挥控制
3. 国家能力建设
4. 四个D：探测、威慑、防御、击败（优势）
5. 整体稳健性与系统韧性
6. 国际网络合作、影响与外交。

这些建议前附有简要背景，概括了前几章的一些要点，以帮助读者关注需要考虑的问题。我们首先简要回顾以色列的民用网络战略，定义其在国家安全领域总体以及网络领域具体的目标，并对需要防御的机构进行排序。

### 国家安全与网络目标

体现在内阁决定及后续 INCD 国家网络安全战略中的民用战略基于四个关键要素：通过旨在促进网络教育、研发、人力资源开发、企业家精神和技术创新的项目进行 *国家能力建设* ；*整体稳健性与系统韧性* ，以加强公共和私营部门抵御和遏制网络攻击、遭受攻击时继续运作、减轻成功攻击造成的损害并促进迅速恢复至先前运作水平的能力；INCD 被赋予对公共和私营部门尤其是关键基础设施和其他重要系统威胁的预防、遏制和缓解的牵头权限的 *防御战略* ；以及与世界各国进行的 *国际合作* 。

尽管该战略令人印象深刻，但仍存在一些缺陷。其中，最重要的问题是缺乏对以色列国家网络目标的明确表述，无论是在内阁决定中，还是更令人惊讶的是在 INCD 战略中，其原因在 [第7章](#20_chapter8.xhtml#oso-9780197677711-chapter-8) 中已解释。

关键国家安全目标是指一核心集合的基本且本质上不可变利益，这些利益独立于——并超越——特定威胁、机遇以及任一特定时期的在任政府。[¹](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1324) 在此背景下，以色列的关键国家安全目标是：

• 确保以色列的存在、领土完整[^‡](#26_chapter13.xhtml#oso-9780197677711-chapter-13-note-36) 以及其公民的安全。
• 维护以色列作为犹太人民民主民族国家及其民族家园的特性。
• 与以色列邻国实现并维持和平。
• 促进以色列社会的社会经济福祉、基本国家共识[^§](#26_chapter13.xhtml#oso-9780197677711-chapter-13-note-37) 以及韧性。[²](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1325)
• 维护与美国的“特殊关系”以及事实上的联盟。与美国的关系——实际上是以色列实现其目标的手段——重要性如此压倒性，以至于它更可争辩地说，也可被视为一项独立的关键目标。

此外，以色列还有各种次要但仍极其重要的国家安全目标，有些是持续性的，其他则随情况而变化。当前的例子包括阻止伊朗获取核武器并遏制其在该地区的影响力，尤其是在叙利亚和黎巴嫩，防止真主党和哈马斯的火箭袭击和其他形式的恐怖主义，打击国际去合法化努力，扩大与逊尼派国家对话与合作的新机会，等等。

基于这些关键及其他国家安全目标，我们提出以下对以色列在 *民用* 网络领域目标的定义，按重要性降序排列。还有其他目标，这些是最重要的目标。

• 确保以色列民主的持续活力，包括思想和数据的自由流动、言论自由以及选举制度的完整性。[³](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1326)
• 确保以色列关键政府机构、关键国家基础设施和其他基本系统的持续功能连续性。[⁴](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1327)
• 防止或至少最大程度减少对公共和私营部门功能连续性和活力的网络干扰。
• 促进以色列的网络生态系统成为国家经济增长的主要引擎。
• 维护以色列的技术领导地位及其作为世界领先网络强国之一的地位。[⁵](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1328)
