
# 以色列国家网络战略

## 国家安全网络领域的目标
在此基础上，我们进一步提出以色列在 *国家安全* 网络领域的目标定义，按重要性降序排列。[⁶](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1329) 再次强调，这些是至关重要的目标。
• 确保国家决策过程的完整性以及以色列领导人在没有网络干扰的情况下做出决策的能力。[⁷](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1330)
• 在所有地区对手中保持进攻性和情报网络优势，但仅对主要全球大国的网络攻击进行有效防御。
• 确保以色列国防军和国防机构能够在受争议且受干扰的网络环境中完成其任务（动能、网络及其他），范围从武装冲突门槛以下的“灰色地带”到战争。
• 防御以色列的军事能力，包括战略性能力，免受网络攻击，并在需要时支持关键国家基础设施和其他重要民用系统的防御。
• 抵御敌方网络信息战，尤其是在军事危机期间。
• 加强以色列的外交关系和国际地位。

## 需防御的优先机构和系统
以下由国家防御的机构和系统按重要性降序排列。值得注意的是，只有第一类完全属于国防机构的管辖范围，大多数其他系统由 INCD 和其他民用机构防御。
• 关键国家安全机构——包括以色列国防军、情报机构、INCD 等。这些*不是*本质上最重要的机构和系统，但其功能连续性是其他机构连续性的先决条件。
• 政府行政和立法部门——包括内阁、议会、选举委员会以及司法系统的关键部分（如最高法院）。
• 关键国家基础设施，如能源、水、交通和通信。
• 必要的政府和商业系统，例如国防部和外交部、NSS、国防工业、警察、卫生、教育和社会福利；人口、财产和土地登记；地方政府；以及金融、贸易和主要工业系统。
• 公共和私营部门组织和机构。

## 国家网络战略的六大支柱

### 支柱 1——战略、原则和资源
**建议 1：更新现有民用网络战略，制定多年工作计划**
现有的公共和私营部门网络战略基于 2011 年至 2015 年间通过的内阁决定，而新的《网络法》自 2018 年首次提出以来基本上一直处于搁置状态。期间发生了很多变化。需要考虑的领域包括但不限于监管体系、网络生态系统、系统韧性以及国际合作，而国际合作在现有战略中仅被一笔带过。如在 [第11章](#25_chapter12.xhtml#oso-9780197677711-chapter-12) 中所述，战略的主要缺陷之一是缺乏在网络领域明确定义的国家目标。
• 1.1 更新民用网络战略，明确需实现的目标定义。
1.11 制定多年工作计划并设定基准，以实施更新后的战略。
• 目标的明确定义是任何战略的核心，无论是网络还是其他。
• 如果缺乏明确定义的目标和基准，很难评估 INCD 和其他机构是否有效履职并对其进行问责。[⁸](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1331)
• 1.2 让主要利益相关方和公众参与迭代过程，就更新战略的草案征求意见，正如在拟议的《网络法》中所做的那样。

**建议 2：制定军事网络战略，纳入国家安全战略**
以色列国防军制定了作战网络原则，而非整体军事 [网络战略。2015年和2018年](#30_bibliography.xhtml#oso-9780197677711-bibliography-1-bibItem-421) 以色列国防军战略指出，以色列将在“支持”其他防御和进攻行动的情况下进行网络攻击，并且能够做到这一点而不必承担责任，使其成为战争之间战役（MABAM）的重要组成部分。以色列国防军当前的思维状态并未最大化以色列的网络能力及其与其他国家力量来源的潜在整合。
• **2**.1 制定全面的军事网络战略。
• **2**.2 将民用和军事网络能力整合到以色列国家安全战略的其他要素中。网络能力不应被视为也不应被视为独立类别。

**建议 3：确保资源与威胁和机遇相匹配**
网络既是以色列今天面临的顶级威胁之一，也是经济增长的主要引擎。[第11章](#25_chapter12.xhtml#oso-9780197677711-chapter-12) 提出了若干理由，质疑以色列分配给其民用网络战略的资源是否与威胁或机遇（社会经济、外交和国防）的规模相称。仅举一例，英国 INCD 的等价机构规模约为其两倍。即使考虑到国家规模的差异，需要填补的功能相似，而以色列面临的挑战至少同样严重。
• 3.1 确保 INCD 和其他在网络领域发挥重要作用的机构，例如 ISA 和以色列投资局，拥有与威胁和机遇*规模相称的资源（预算、人员、技术）。
• INCD 提供必要防御方案能力的当前限制，无论是预算还是其他，都不能被允许决定哪些组织被列入关键国家基础设施和其他重要实体名单，必须相应分配必要的资源。另见建议 4.3。
• 审查 INCD 资源的需求也反映了本战略中为其设想的扩大角色，包括国家能力建设、监管执行、国际合作等。
• 3.2 将网络安全成本纳入所有现有和尤其是新的政府计算机系统和网络的未来预算中。

### 支柱 2——治理和指挥控制
**建议 4：推动新网络法的快速通过**
并非所有以色列国家安全机构都以法律形式存在，但越来越多地如此，这也是理想的最终状态。[^(\*\*)](#26_chapter13.xhtml#oso-9780197677711-chapter-13-note-38) 网络仍然是一个相对较新且不断发展的领域，许多人对其理解不足；因此，特别重要的是将 INCD 和监管体系的地位以法律形式确立。议会立法是公众认可的最高形式。[⁹](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1332)
• **4**.1 推动议会快速通过经修订的 2018 年《网络法》草案。
• 政府机构和公众利益团体提出的大多数关切已在修订版中得到解决。剩余的关切应随着时间的推移得到纠正，不应构成立法的障碍。
• 4.2 采用关键基础设施系统的法定定义，并据此扩大关键国家基础设施清单。定期审查清单中包含的实体。
