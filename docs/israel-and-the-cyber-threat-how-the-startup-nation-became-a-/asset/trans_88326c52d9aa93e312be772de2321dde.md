
网络威胁始于以色列所称的红区（外国领土，无论是否友好），那里主权政府占主导地位；穿过白区（互联网），那里大型跨国公司占主导地位；然后进入蓝区，即以色列，那里公共和私营实体占主导地位。[^(103)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1203) INCD 负责为公共和私营部门实体，即蓝区内的实体，提供有关网络威胁的预警以及网络防御、稳健性和韧性的总体指导。 就蓝区内对网络威胁的实际预防和防御而言，摩萨德和以色列国防军负责防御 *敌人*，ISA 和 MALMAB 负责 *对手*。[^†](#23_chapter11.xhtml#oso-9780197677711-chapter-11-note-30) 在红区，以色列国防军和摩萨德负责防御源自 *敌人* 的网络威胁，ISA 负责 *对手*。 白区是预警方面的共同责任区，没有任何一个组织拥有单独的授权。[^(104)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1204)

没有任何机构被赋予正式责任来领导和整合以色列在网络领域的整体军事努力，无论是和平时期还是战时。[^(105)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1205) 各机构之间的非正式谅解已将以色列国防军指定为战时网络行动整体作战整合的责任方，[^(106)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1206) 如同在其他领域一样，但这并未得到政治领导层的正式批准，也未载入法律。[^‡](#23_chapter11.xhtml#oso-9780197677711-chapter-11-note-300)

在没有正式决定的情况下，ISA 近年来主持了一个非正式的跨机构协调机制，由 C4I 部门的网络防御旅、第 8200 部队、国防部（MALMAB）和 INCD 的代表组成。 在军事危机期间，网络防御旅的负责人根据上述协议担任领导。 除了各组织参与者之间持续的日常交流外，该论坛每周召开一次会议，讨论网络情报态势，制定政策，并决定是否以及如何应对攻击。 各机构为预警、预防、破坏和防御目的贡献各自独特的<|message|>能力，并据此分配任务。 该论坛始于一些官员的个人倡议，他们认为需要这种类型的跨机构论坛。 多年来据报道已被证明非常有效，[^(107)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1207) 但其半自愿的基础以及由此导致的缺乏正式结构仍然是主要弱点。 几十名来自 C4I 防御旅的以色列国防军士兵驻扎在 ISA，以促进两机构之间顺畅的沟通和网络安全合作。[^(108)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1208)

### 被归因于以色列的网络攻击

自 1990 年代初以来，美国和以色列开展了各种联合努力，外交、经济和军事，旨在防止伊朗获得核武器。 据报道，网络领域一直是这些努力的关键组成部分，其中对伊朗核离心机的 Stuxnet 攻击可能是高潮。 Stuxnet 实际上只是被称为 Olympic Games 的更广泛行动中最为人所知的部分。 尽管媒体广泛报道，甚至美国确认这是联合行动，以色列并未正式承认参与 Stuxnet。[^(109)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1209)

以色列当然也进行了独立的网络行动，以及两次针对哈马斯网络能力的动能攻击。 以下部分描述了人们所知晓的这些行动。 除 Olympic Games 外，可获得的细节有限，但清楚地表明以色列战略文化历来非常重视进攻。

#### Olympic Games

— 是一系列网络间谍和破坏攻击，旨在破坏和延缓伊朗核计划，甚至可能使其脱轨，以期实现外交解决方案。[^(110)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1210) 因此，Olympic Games 补充了美国持续进行的加大对伊朗国际外交和经济压力的努力，同时伴有始终存在的军事力量威胁，以迫使其妥协。

Olympic Games 有四个主要组成部分，其中三个实际上被执行，Flame、Duqu 和 Stuxnet，以及计划但从未执行的 Nitro Zeus。 Olympic Games 据报道于 2005 年在布什总统任期内开始，并在 2012 年被发现前一直延续到巴拉克·奥巴马总统任期内。[^(111)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1211) 主要是一项美国和以色列的行动，荷兰、德国以及可能还有法国也参与其中并做出了重要贡献。[^(112)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1212)

Olympic Games 的动机是布什和奥巴马政府对以色列可能单方面打击伊朗核计划的后果的深切担忧，他们几乎和对该计划本身一样担心。 以色列过去曾作为贝京学说的一部分轰炸过伊拉克和叙利亚的核反应堆，[^(113)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1213) 并且在布什和奥巴马政府的大部分任期内一直积极发出信号，表明如果外交失败，它可能会再次这样做。[^(114)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1214) 以色列意图的迹象之一是 2008 年请求购买高功率掩体穿透炸弹，布什拒绝了，[^(115)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1215) 以及 2010 年至 2012 年间高级以色列官员（显然包括国防部长巴拉克）发表的一系列声明。[^(116)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1216)

布什和后来的奥巴马担心以色列的攻击可能引发地区冲突，对美国利益造成严重后果，并可能迫使美国介入。 因此双方都认为，与以色列协调进行的史无前例的类型和规模的网络行动可能足以阻止以色列发动攻击的需要[^(117)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1217) 并最大限度地减少地区和国际影响。[^(118)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1218) 据说奥巴马认为，如果 Olympic Games 失败，就没有时间进行制裁或外交，以色列就会发动攻击。[^(119)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-1219)
