
# 以色列的战略文化

以色列的战略文化从根本上是防御性的，以确保国家的生存，但在作战上却是进攻性的。只有进攻性和机动性机动作战才能使以色列决定战斗的时间、节奏和地点，发挥其质量优势，并取得促进累积威慑所需的决定性成果。在早期几十年里，这种进攻性方法被转化为一种信念，即以色列必须尽可能迅速地将战斗转移到敌方领土，并且必须以以色列国防军控制的领土比开始时更多而告终。

## 进攻性机动战

进攻性机动战也被认为至关重要，目的是尽可能缩短冲突。冲突持续时间越长， additional actors 加入战斗的危险就越大；地区不稳定和全球石油供应的风险会增加，以色列经济所受的打击也会加大。旷日持久的冲突还会增加向外国保护国请求紧急补给的需求以及不利的超级大国干预的可能性。这一后者因素催生了可能独一无二的以色列“政治时间”概念，即以色列在外部干预迫使在不利条件下停火之前进行军事行动的时期。

## 防御

自1990年代以来，以色列面临的军事威胁的性质发生了变化，从主要来自阿拉伯常备军的基于国家的常规威胁，转变为与伊朗、真主党和哈马斯的不对称冲突，其中以色列的本土已成为主要的战场。威胁性质的变化导致对防御行动在以色列战略文化中的作用进行了重新评估，并采纳了新的、第四个 D，即防御。[^(29)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-684) 以色列在近几十年里在维持已控制的领土方面遇到的困难，更不用说向新领土扩张，进一步强化了这种方法转变，并导致更倾向于主要来自空中的远程作战，而不诉诸领土征服。

多年来，以色列建立了庞大的军事能力，以应对其所面临的常规军事威胁。近年来，以色列国防军的现代化计划已转向其为应对伊朗构成的威胁所需的作战能力，主要包括其导弹和潜在的核能力，以及真主党和哈马斯的火箭库。[^(30)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-685)

## 反恐

反恐——作为一种不对称战争形式，在某些方面类似于网络威胁，以色列的反恐（CT）政策对我们而言具有特别的兴趣。该政策长期以来基于一个基本假设，即恐怖主义永远无法被彻底击败，只能被最小化并降低到以色列社会能够容忍的水平。[^(31)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-686)

以色列的反恐政策采用了威慑、进攻和防御措施的结合以及国际合作。进攻性措施包括持续的反恐行动，通常全天候进行，范围从小型秘密行动到大规模进攻，包括旨在削弱恐怖组织的消耗战、拦截武器转移、暗杀高级行动人员、偶尔的惊人反恐行动等等。一个特别重要的以色列创新，至少在一定程度上也适用于网络防御，就是“情报-行动圈”。这一高度精炼的协调机制是在第二次 *因提法达* 期间发展起来的，使以色列能够在数分钟内将有关即将发生的恐怖袭击的情报传递给作战单位（空军和/或地面部队），并将其转化为可执行的拦截措施。[^(32)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-687)

防御性措施包括边境沿线的围栏、延伸至边境以外的安全区、边境巡逻等。在约旦河西岸和加沙地带，以色列有时也试图利用经济增长作为创造巴勒斯坦人对稳定利益的方式，希望从而减少恐怖主义。[^(33)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-688) 国际合作范围从非正式的临时措施到更正式的协议，包括情报共享、行动协调和培训。

以色列的反恐政策产生了各种各样的结果，有些非常成功，其他的则失败甚至适得其反。总体而言，它取得了重大成功，将威胁降低到以色列社会能够容忍甚至蓬勃发展的水平，尤其是在经济方面。[^(34)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-689) 相反，恐怖主义对公众舆论产生了重大影响，极大地影响甚至左右了许多选举结果，使公众对巴勒斯坦人的态度趋于强硬，甚至影响了以色列与其谈判的立场。以色列的一些反恐措施也对其国际地位造成了高度不利的影响。

## 火箭威胁与威慑性行动

为应对来自主要针对其平民本土的火箭的更当代的恐怖主义威胁，以色列建立了多层次的进攻和防御反应。在进攻方面，以色列已通过大规模和精确的空中力量开发出部分摧毁火箭和导弹发射器的能力。[^(35)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-690) 在防御方面，以色列部署了多种反火箭防御系统，其中最著名的是铁穹，此外还有被动防御措施，如避难所和私人住宅中的钢筋混凝土房间。这些措施已被证明在最大限度减少伤亡和减轻公众对以色列领导人采取先发制人、立即反击或发动大规模地面行动的压力方面非常有效，从而为他们提供了更大的决策空间。安全感也大大减少了公众的无助感，并增强了其长期韧性和抵御持续威胁的能力。[^(36)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-691)

然而，火箭威胁继续带来巨大的作战挑战，这一挑战因真主党和哈马斯故意将火箭部署在平民人口中和/或隐藏在地下隧道中而大大加剧，从而使寻找和摧毁它们的工作变得极其困难。即使是部分缓解火箭威胁，正如2006年以来与哈马斯和真主党的反复交锋所证明的那样，也可能需要数周的战斗，在此期间以色列平民人口仍处于持续攻击之下。

自1990年代以来，与真主党和哈马斯的所有主要交锋都是“威慑性行动”，旨在防止进一步袭击、恢复平静、显著削弱这两个组织，并尽可能长时间地阻止敌对行动的重新开始，即迫使恢复到现状之前的状态，而不指明预计持续多久。从长远来看，以色列希望这些反复的威慑性行动能够达到累积威慑的水平并导致袭击停止，但它并无意在短期内彻底解决这一问题。[^(37)](#29_Notes.xhtml#oso-9780197677711-miscMatter-11-note-692)
