\(FAC2 = \frac{N}{n} = \frac{1}{n} \sum_{i=1}^{n} N_i \#\text{with } N_i = \begin{cases} 1 \text{ for } 0.5 \le \frac{P_i}{E_i} \le 2.0 \\ 1 \text{ for } E_i \le W \text{ and } P_i \le W \\ 0 \text{ else} \end{cases}\) (11)

where \(E_i\) and \(P_i\) are experiment and predicted values of a given variable for sample \(i\), respectively; and \(N\) is the number of data points. The overbar denotes the mean of the dataset. The allowed absolute differ-
