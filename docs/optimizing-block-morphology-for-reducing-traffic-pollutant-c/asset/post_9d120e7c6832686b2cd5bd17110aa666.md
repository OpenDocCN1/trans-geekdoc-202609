### 3.5. Settings for ML model

The 35-dimensional input block layout parameter and the corresponding BH_std were used as input features for the ML model. Four average concentration values were used as labels for each case. The 1000 RANS cases were randomly split into 800 training and 200 test cases, roughly equivalent to an 80–20% split. This paper selected four machine learning models - Random Forest (RF), Gradient Boost (GB), eXtreme Gradient Boosting (XGB), and Light Gradient Boosting Machine (LGBM) – which were fine-tuned to predict pollutant concentrations in each region accurately.

The Random Forest (RF) regression model is a learning method that constructs multiple decision trees during training and outputs the mean prediction of the individual trees [67]. Gradient Boosting (GB) is a machine learning technique for regression and classification problems that produces an ensemble of weak prediction models, typically decision trees [68]. Extreme Gradient Boosting (XGB) is an ensemble method that trains small-depth trees fitted to the residuals of prior trees. The weight of each added tree is controlled by the learning rate hyperparameter [69]. Light Gradient Boosting Machine (LGBM) is a machine learning algorithm that uses gradient boosting to create an ensemble of weak prediction models, typically decision trees, for regression tasks. It is known for its speed and efficiency in handling large datasets and high-dimensional features [70].

In this study, four regression models were simultaneously trained, tuned, and compared in FLAML. Table 3 lists the parameter range explored along with the optimal parameters used for each machine learning method. The maximum time allowed for hyperparameter tuning of each machine learning model was 300 s, and each model met the convergence criterion within that time. These estimators were trained and tuned four times according to the four regions. Then one optimal model was selected from them as the corresponding average pollutant concentration prediction model for that region. Such a sub-region approach to prediction model construction can highlight the heterogeneity of block spatial effects on pollutant concentrations and improve model prediction accuracy [47].

To assess these ML models, the root mean square error (RMSE) on the testing cases and the average R<sup>2</sup> values of the testing cases were analyzed, respectively Eqs. (12) and (13):

\(RMSE = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (c_i - \widehat{c}_i)^2}\) (12)

\(R^2 = 1 - \frac{\sum (\widehat{c}_i - c_i)^2}{\sum (\overline{c_i} - c_i)^2}\) (13)

where \(\widehat{c}_i\) is the predicted concentration, \(c_i\) is the concentration obtained from simulations, and \(\overline{c_i}\) is the average concentration over the testing case.

### 3.6. Settings for optimization solvers

Table 4 lists the optimization parameters as BH_std and building locations. The optimization goal is to minimize the concentration of pollutants. The optimization goal in the single-objective optimization problem is C_pod,AES, a local metric. The multi-objective optimization problem’s objectives are the pollutant concentration in four regions containing global and local indicators.

This study employed two optimization algorithms, Genetic Algorithm (GA) for single-objective optimization and non-dominated sorting genetic algorithm II (NSGA II) for multi-objective optimization (Table 4). The GA algorithm used a population size of 50. If the goal value did not decrease within 20 generations, it was considered to have converged. The maintenance rate was 10%, and the inbreeding was 80% [71]. To ensure that the iterations of the other algorithms were consistent with GA, the population size and generations of NSGA II were limited to 50 and 100, respectively.

## 4. Result

### 4.1. CFD simulations results of sampling blocks

The simulation results for 1000 sample conditions indicate that global concentration metrics are lower than local concentration metrics. The average pollutant concentration in the podium volume is lower than in the pedestrian volume. C_pod,Block is significantly lower than C_ped,AES. Essentially the normalized average concentrations of all samples in the AES area were 1.5–2.5 times higher than in the block. Analysis of the correlation between the four pollutant concentrations of 1000 cases with the BH_std and layout parameters revealed that the linear coefficient between the BH_std and the global index was relatively high, while the correlation with the local index was low (Fig. 7). The correlation coefficient between BH_std and C_pod,Block is -0.64, indicating that BH_std has a significant negative correlation with the global pollutant concentration. The row of buildings close to the source of pollution - row E - all showed a negative correlation between building height and pollutant concentrations. The closer the building is to the downwind direction inside the block, the more positive the correlation between height and pollutant concentration. However, linear correlation coefficients between building heights in blocks and pollutant concentrations in all areas are not high. It can be assumed that building heights and layouts are not simply linearly related to the distribution of pollutant concentrations.
