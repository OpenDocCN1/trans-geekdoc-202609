# 2. Description of framework

This study proposes an optimization framework for block design using machine learning (ML) models trained on data from computational fluid dynamics (CFD) simulations. The framework consists of five steps (Fig. 2): (1) creating a parametric model based on building height standard deviation (BHstd) and block layout and sampling cases using Latin hypercube sampling (LHS); (2) running CFD simulations for the sampled cases and computing the pollutant concentration values in the target area; (3) developing a surrogate regression model for the pollutant concentration using ML techniques; (4) combining the ML models and optimization algorithms for single-objective and multi-objective optimization; and (5) validating and analyzing the optimization results using CFD simulations.

# 2.1. Step 1: parametric model development and sampling

The first step in this study was to define the physical problem under investigation and create a parametric model for the target block and background buildings. Several design parameters constrained the 3D model to avoid mesh or CFD solver failure due to incorrect or inconsistent geometries [34]. The parametric model was generated using Grasshopper, a parametric modeling platform that works with Rhino software. Grasshopper allowed users to create complex blocks and buildings using algorithms and mathematical logic. Two indices were set: building location and height in the target block to generate a block model that satisfied the urban morphological parameters. # 2.2. Step 2: CFD simulations

In this step, CFD simulations were performed for the sampling cases to analyze the concentration distribution of traffic-related air pollutants under each condition. Simultaneously the average pollutant concentration values of the four regions for each sample were calculated. The CFD simulation results served as the database of the ML model. Therefore, variables other than design parameters were excluded in the CFD simulation boundary condition setting, probe settings, and post-processing. This setup ensured that the simulated concentration results only depended on the parameters of interest. The wind environment and pollutant simulation in this study were based on the open-source CFD simulation software OpenFOAM. The software was connected to the Grasshopper platform interface to automate the process of parametric modeling, mesh generation, and CFD simulation. Specific CFD simulation settings are provided in Chapter 3, Section 2.

# 2.3. Step 3: machine learning model

This step involved using the case parameters generated in the first step and the concentration metrics obtained from the simulation as input variables and targets for the ML, respectively. The data set was split into a training set and a test set based on a specific ratio. Four models were employed to perform predictive regression and evaluate the learning efficiency of the models according to specific metrics. The model with the best regression results would be used as a surrogate model for CFD simulations. FLAML, a fast and lightweight AutoML library developed by Microsoft Research, was chosen to train these data for regression [52]. FLAML automated the selection of learners and hyperparameters. A more detailed ML setup is provided in Chapter 3, Section 3.

# 2.4. Step 4: optimization algorithms

In this step, ML was used as a surrogate model of CFD for fast traffic pollutant prediction and combined with optimization algorithms to explore block configurations that resulted in lower pollutant concentrations. The optimization objectives were chosen to compare the similarities and differences in the results obtained by focusing on different target areas. The single-objective optimization corresponded to the pollutant concentration index of a relatively local area, while the multi-objective optimization was a more global area concentration index. Grasshopper's optimization plugins, Galapagos and Wallacei, were used as the optimization platform for this paper. Both plugins could be linked with parametric modeling. A more detailed optimization setup is provided in Chapter 3, Section 3.

# 2.5. Step 5: optimal block morphology

In this step, the feasibility of the ML model in the optimization framework was verified by conducting CFD simulations for the optimal solutions obtained from both single-objective and multi-objective optimizations. The pollutant concentration performance of these optimal solutions was compared in local and global areas. The influence of block morphology corresponding to the optimization results on the dispersion of traffic-related air pollutants was also analyzed. Finally, block design strategies that facilitate the reduction of pollutant concentrations within the AES were summarized. Detailed optimal results are provided in Chapter 4.
