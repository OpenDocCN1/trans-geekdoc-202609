You should use the Bayes-optimal risk $R^*$ to lower bound the performance of any machine learning classifier that you might try for a given data distribution.^5 No matter how hard you work or how creative you are, you can never overcome the Bayes limit. So you should be happy if you get close. If the Bayes-optimal risk itself is too high, then the thing to do is to go back to the data understanding and data preparation stages of the machine learning lifecycle and get more informative data.
