

这三个性质非常直观，它们只是将我们通常所说的概率进行了形式化。一个事件的概率是一个介于0和1之间的数字。只要两个事件不包含任何相同的结果，一个事件或另一个事件发生的概率就是它们各自概率之和。

*概率质量函数*（pmf）使得描述离散样本空间中的概率更加容易。它是一个函数\(p\)，以结果\(\omega\)为输入，并为这些结果返回概率。样本空间中所有结果的pmf之和为1，\(\sum_{\omega\in\Omega} p(\omega)=1\)，这是满足概率的第二个性质所需要的。

一个事件的概率是其组成结果的pmf值之和。例如，如果就业状态的pmf为\(p(\text{受雇})=0.60\)，\(p(\text{失业})=0.05\)，\(p(\text{其他})=0.35\)，那么事件{受雇, 其他}的概率为\(P(\{\text{受雇, 其他}\})=0.60+0.35=0.95\)。这种将pmf值相加得到总概率的方式之所以有效，是因为概率的第三个性质。

*随机变量*在指定机器学习问题的安全需求时是一个非常有用的概念。当随机变量\(X\)被测量或观察时，它会取一个特定的数值\(x\)；该数值是随机的。\(X\)的所有可能值的集合是\(\mathcal{X}\)。随机变量\(X\)的概率函数记为\(P_X\)。随机变量可以是离散的或连续的。它们还可以通过将结果值映射到一个有限的数字集合来表示分类结果，例如将{受雇, 失业, 其他}映射到{0, 1, 2}。离散随机变量的pmf写作\(p_X(x)\)。

对于不可数无限样本空间，pmf并不完全适用。因此，使用*累积分布函数*（cdf）来代替。它是连续随机变量\(X\)取小于或等于某个样本点\(x\)的值的概率，即\(F_X(x)=P(X\leq x)\)。另一种表示是*概率密度函数*（pdf）\(p_X(x)=\frac{d}{dx}F_X(x)\)，它是cdf对\(x\)的导数。pdf的值不是概率，但将pdf在一个集合上积分会得到概率。

## 3.3 不确定性的汇总统计

完整的概率分布非常适合开始进行问题规范，但处理起来可能很笨拙。使用概率分布和随机变量的汇总统计量来设置问题规范更容易。

### 3.3.1 期望值和方差

最常见的统计量是随机变量的期望值。它是其分布的均值：一个典型值或长期平均结果。它的计算方式是pdf乘以随机变量的积分：

E[X] = ∫_{-∞}^{∞} x p_X(x) dx.

方程 3.4

回想前面的例子，ThriveGuild借款人的收入pdf为0.5e^{-0.5x}（x ≥ 0），其他地方为零。因此，收入的期望值为 ∫_0^∞ x0.5e^{-0.5x} dx = 2。当你从X的概率分布中抽取一组样本，记为{x_1, x_2, ..., x_n}时，可以计算期望值的经验版本，即样本均值，为 x̄ = 1/n Σ_{i=1}^n x_i。你不仅可以计算随机变量本身的期望值，还可以计算随机变量的任意函数的期望值。它就是pdf乘以该函数的积分。通过性能的期望值（也称为风险），你可以指定系统平均行为处于特定范围内，以达到安全的目的。

你应为ThriveGuild申请人计划多大的收入波动性？一个重要的期望值是方差 E[(X − E[X])^2]，它度量分布的离散程度，有助于回答这个问题。其样本版本，样本方差，计算为 1/(n−1) Σ_{j=1}^n (x_j − x̄)^2。两个随机变量X（例如收入）和Y（例如贷款批准）之间的相关性也是一个期望值，E[XY]，它告诉你两个随机变量之间是否存在某种统计关系。协方差 E[(X − E[X])(Y − E[Y])] = E[XY] − E[X]E[Y] 告诉你，如果一个随机变量增加，另一个是否也会增加，反之亦然。这些不同的期望值和汇总统计量提供了关于偶然不确定性的不同见解，这些见解需要在问题规范中加以约束。
