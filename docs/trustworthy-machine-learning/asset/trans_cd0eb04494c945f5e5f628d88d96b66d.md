
而观测数据却无法做到这一点。基于干预数据的因果建模通常直截了当，而基于观测数据的因果建模则复杂得多。

在建模阶段处理观测数据时，这两种问题表述对应两类不同的方法。因果发现（causal discovery）是学习结构因果模型，因果推断（causal inference）是估计因果效应。从观测数据中进行因果发现和因果推断的具体方法分别是8.4节和8.5节的主题。图8.2给出了这两种表述的建模方法的思维模型。

### 8.2.1 后门路径与混杂因素

重要的是要注意，平均处理效应的定义以$do(t)$为条件，而不是以$t$为条件，并且$P(Y \mid do(t))$和$P(Y \mid t)$通常不相同。具体来说，当$T$和$Y$之间存在所谓的*后门路径*时，它们就不相同。记住，路径是图中沿着边的一系列步骤，无论其方向如何。*后门路径*是从$T$到$Y$的任何路径，它（1）以一条进入$T$的边开始，并且（2）未被阻断。“后门”这个名称的原因是第一条边向后进入$T$。（前门路径的第一条边是从$T$出来的。）回忆第3章，如果路径包含以下任一情况，则该路径被阻断：

- 1. 中间节点被观测的因果链基序，即中间节点被条件化，
- 2. 中间节点被观测的公共原因基序，或
- 3. 中间节点*未被*观测的公共效应基序（这是一个对撞器）

在$T$和$Y$之间的任何位置。后门路径可以包含（1）没有观测的公共原因基序和（2）有观测的公共效应基序在$T$和$Y$之间。阻断和不阻断路径的基序如图8.3所示。

干预分布$P(Y \mid do(t))$与关联分布$P(Y \mid t)$之间的不等性被称为*混杂偏倚*。$^3$沿着后门路径的公共原因基序的任何中间节点都是*混杂变量*或*混杂因素*。混杂是当你试图在无法进行干预（你不能进行do$(t)$）的情况下推断平均处理效应时，需要克服的核心挑战。8.5节涵盖了在估计平均处理效应时如何减轻混杂。

$^3$在涉及选择偏倚的特殊情况下，可能存在没有后门路径的混杂偏倚。选择偏倚是指处理变量和另一个变量共同作为结果标签的原因。
