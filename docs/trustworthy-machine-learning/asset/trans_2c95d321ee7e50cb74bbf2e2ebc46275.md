## 7 监督学习

虚构的信息技术公司JCN Corporation正在自我转型，将重心转向人工智能和云计算。作为这次企业转型中人才管理的一部分，该公司正在开展一个机器学习项目，从多种数据源估计员工的专业技能，这些数据源包括技能自我评估、工作成果（专利、出版物、软件文档、服务索赔、销售机会等）、内部非私人社交媒体帖子，以及包含员工工龄、汇报链和薪资等级的表格式数据记录。随机抽取的一部分员工已经针对各种AI和云技能按二元是/否量表进行了明确评估，这些构成了机器学习的有标签训练数据。JCN Corporation的数据科学团队的任务是预测公司内所有其他员工的专业技能评估。为简单起见，我们只关注其中一个专业领域：无服务器架构。

假设你是JCN Corporation数据科学团队的一员，已经完成了机器学习生命周期的任务定义、数据理解和数据准备阶段，现在处于建模阶段。通过应用检测理论，你为预测员工的无服务器架构技能选择了一个合适的性能量化指标：错误率——即假阳性和假阴性成本相等时的贝叶斯风险——在第6章中介绍过。

现在是时候开始从训练数据中学习一个决策函数（分类器）了，该函数能够很好地泛化，为未标记的员工预测专业技能标签。深度学习是大家耳熟能详的一类分类器。它当然是一个选择，但还有许多其他类型的分类器。你如何评估不同的分类算法，为你的问题选择最佳的一个？

> “我在行业中的经验强烈证实，深度学习只是解决复杂自动化决策问题所需方法中的一小部分。”
> 
> —祖宾·加赫拉马尼，Uber首席科学家

在实践机器学习中一个非常重要的概念，首次在第2章中提到，是*没有免费午餐定理*。不存在一种对所有数据集都最佳的统一机器学习方法。¹ 对某个数据集来说好的选择，对另一个数据集可能并不那么理想。这完全取决于数据集的特征以及方法的*归纳偏置*：即关于分类器应如何在训练数据点之外进行*泛化*的假设。要实现良好的泛化和低错误率，挑战在于防止*过拟合*（学习到的模型过于贴近训练数据的特有个别特征）和*欠拟合*（学习到的模型未能充分捕捉训练数据中的模式）。目标是达到金发女孩式的理想点：既不太热（过拟合），也不太冷（欠拟合），而是*恰到好处*。

没有免费午餐定理的一个启示是，你必须为JCN Corporation的专业技能问题尝试几种不同的方法，并根据经验观察它们的表现，然后再决定使用哪一种。简单地蛮力测试——训练所有不同的方法并计算它们的测试错误，看看哪个最小——是一种常见做法，但你决定采取更精细的方法，分析不同分类器的归纳偏置。你的分析将确定各种分类器的*能力域*：它们在哪类数据集上表现良好，又对哪类数据集表现不佳。² 回想一下，能力或基本准确率是可信机器学习的第一属性，也是安全性的前半部分。

为什么要采取这种精细的方法，而不是简单地从scikit-learn、TensorFlow和PyTorch等软件包中应用一堆机器学习方法而不分析它们的归纳偏置呢？首先，你听取了前面章节的告诫，要注重安全，不走捷径。然而更重要的是，你知道你之后将创建尊重可信赖性第二（可靠性）和第三（交互）属性的新算法。你不仅要能够应用算法，还必须能够在创造之前分析和评估它们。现在，去分析用于盘点JCN Corporation员工专业技能的各类分类器吧。

### 7.1 能力域

不同的分类器根据数据集的特征在不同数据集上表现良好。³ 但数据集的哪些特征才是重要的？能力域的参数是什么？回答这些问题的一个关键概念是*决策边界*。在第6章中，你了解到贝叶斯最优决策函数是一个似然比检验，即一维似然比的一个阈值。如果对似然比求逆，你可以回到具有*d*个特征维度*x*^(1), …, *x*^(d)的特征空间，并描绘出该单一阈值所映射的曲面。这些曲面的集合是似然比函数的一个*水平集*，称为决策边界。想象似然比函数就像地球的地形和水深。任何在水下的东西被分类为*ŷ* = 0（员工不擅长无服务器架构），任何在水上的东西被分类为*ŷ* = 1（员工擅长无服务器架构）。海平面是阈值，海岸线是水平集或决策边界。图7.1显示了一个二维特征空间中决策边界的示例。

数据集的三个关键特征决定了分类器的归纳偏置与数据集的匹配程度：

1. 决策边界附近两个类别标签的数据点重叠程度，
2. 决策边界的线性或非线性，
3. 数据点的数量、密度以及聚类程度。

分类器的能力域根据这三个考虑来定义。⁴ 重要的是，能力域是相对概念：某一种分类算法是否比其他算法更好？⁵ 它们不是绝对概念，因为归根结底，绝对性能受到第6章定义的贝叶斯最优风险的限制。例如，你尝试的某一种分类方法可能在决策边界附近类别重叠度高、决策边界形状接近线性、且数据点不多的数据集上比其他方法表现更好。另一种分类方法可能比
