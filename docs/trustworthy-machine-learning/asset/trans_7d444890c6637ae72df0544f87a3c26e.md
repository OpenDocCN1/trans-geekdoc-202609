

要改变一个已经记录下来的事实，需要超过半数的计算机所有者共同参与，这是一项艰难的工作。区块链提供了一种分布式信任的形式。

区块链有两种类型：（1）*许可型*（也称为私有链）和（2）*非许可型*（也称为公有链）。许可型区块链仅允许那些持有凭证注册过的人读写信息和拥有机器。非许可型区块链对任何人开放，可以匿名访问。在维护事实来源并使流失预测模型更可信方面，这两种方案都可以选择。如果所有消费者都在公司内部，或是固定的监管机构群体，那么许可型区块链网络就能解决问题。如果普通公众或JCN公司之外的人是事实说明书的消费者，那么非许可型区块链是首选方案。

将事实发布到区块链解决了维护事实来源的问题，但如果事实本身的创建过程中存在篡改怎么办？例如，如果数据科学家发现特征工程代码中的一个小错误，而这个错误对模型性能影响不大，于是修复了它。重新训练整个模型需要一整夜时间，但提交事实的截止时间是在下班之前。于是数据科学家提交了来自之前训练模型的事实。这类走捷径的行为也可以用区块链技术来防止。³⁰ 由于许多机器学习模型的训练是通过迭代过程（如梯度下降）以确定性方式完成的，区块链网络中的其他计算机可以通过从数据科学家发布的迭代检查点开始，在本地重新运行计算的一小部分，从而认证并验证训练计算确实被执行过。如何使这一过程在计算和通信成本上具有可行性的细节超出了本书的范畴。

在测试中，你发现所有模型都缺乏公平性，于是你把它们送回数据科学家那里，让他们添加更好的偏见缓解措施，他们按照你的要求做到了。现在各利益相关者也满意了，因此你可以继续签署系统符合性声明，并将其推进到生命周期的部署阶段。在部署工作的同时，你还发布了一份事实说明书，供JCN公司内部负责跟进机器推荐保留行动的经理们使用。请记住，这个新机器学习系统的承诺之一是让JCN公司的雇佣更加公平，但这只有在经理们采纳系统建议的情况下才能实现。³¹ 你基于事实说明书的透明度努力已经在经理们之间建立了足够的信任，使他们愿意采纳该系统，JCN公司将在保留行动中作出更公平的决定。

## 13.5 小结

- 透明度是提高机器学习可信度第三属性（开放性和人类交互）的关键手段。
- 事实流是一种自动收集开发生命周期中定性和定量事实的机制。事实说明书是一组事实的集合，针对特定消费者进行适当呈现，从而实现透明度和符合性评估。
- 模型验证和风险管理包括在信任维度上测试模型、计算测试结果的不确定性、捕获开发生命周期的定性事实，并通过事实说明书透明地记录和传达这些内容。
- 由于测试预言问题（无法预先知道行为应该是什么），机器学习模型的测试是一项独特的工作，不同于其他软件测试。
- 可视化有助于让各种消费者角色更容易理解测试结果及其不确定性。
- 如果事实和事实说明书的来源能够被维护和验证，它们就会更可信。使用区块链网络实现的不可变账本提供了这种能力。

## 价值对齐

本书这一部分（关于交互）的前两章重点讨论从机器系统到人类消费者的通信。本章侧重于交互的另一个方向：从人类到机器系统。假设你是Alma Meadow评选委员会的主管，这是一个（虚构的）慈善组织，投资早期社会企业，并邀请那些使命驱动型组织的创始人参加为期两年的奖学金项目。Alma Meadow每年收到约三千份申请，选约三十人为奖学金获得者。作为该流程的主管，你正在考虑以某种方式使用机器学习来改进其运作。因此，在一个初生机器学习生命周期的问题规范阶段，你是问题所有者。你主要的担忧是，在选择社会影响力初创企业时，不能牺牲Alma Meadow的使命或价值观。

> “我们需要进行更多对话，在这些对话中，我们在政策、世界结果影响、我们所关心的事物，以及后端为达成这些目标而进行的所有数学、数据和技术工作之间进行转换。”
>
> ——Rayid Ghani，卡内基梅隆大学机器学习和公共政策研究员

*价值观*是指导行动的基本信念。它们表明各种事物和行动对一个人或一群人的重要性，并决定生活和行为的最佳方式。将Alma Meadow的价值观嵌入到你正在考虑的机器学习系统中，这被称为*价值对齐*，它有两个部分。¹ 第一部分是*技术性*的：如何编码和引出价值观，使机器学习系统能够获取这些价值观并据此行事。第二部分是*规范性*的：实际价值观是什么。（规范性一词指的是社会意义上的规范，而非数学意义上的规范：标准或正确行动的原则。）

¹Jason Gabriel。《人工智能、价值观与对齐》。载于 *心智与机器* 30（2020年10月），第411–437页。

本章关注的是价值对齐的第一部分：你、你的同事和其他利益相关者传达价值观（可能受法律法规影响）的技术方面。本书第六部分（也是最后一部分）关于“目的”的各章将深入探讨价值观本身。

> “可以进行科学研究，以真正理解如何从我们大家都认同的这些价值观出发，将其嵌入到与人类协作的人工智能系统中。”
>
> ——Francesca Rossi，IBM人工智能伦理全球负责人

在深入探讨价值对齐的技术细节之前，让我们先退一步，讨论表达价值观的两种方式：（1）道义论和（2）后果主义。² 简单来说，道义论价值观关注定义好的行动，而不考虑其后果；后果主义价值观则关注定义对所有人都有利的结果。例如，Alma Meadow有两条道义论价值观：每年至少有一位奖学金获得者曾是曾被监禁的人，且奖学金获得者的社会变革组织不能宣扬特定宗教信仰。这些关于颁发奖学金的明确规则或约束并不考察对任何结果的影响。相比之下，Alma Meadow的一项后果主义价值观是，从申请池中选出的奖学金获得者所领导的社会影响力初创企业，将在未来十年内最大程度地改善全球残疾调整生命年（DALY）。DALY是衡量全球疾病负担中发病率和死亡率综合情况的指标。（由于不确定性，在决策时无法完全知道哪位申请者符合这一条件，但它仍然可以作为一种价值观。）因为它以结果（DALY）来衡量，所以是一种后果主义价值观。

²Joshua Greene、Francesca Rossi、John Tasioulas、Kristen Brent Venable 和 Brian Williams。《将伦理原则嵌入集体决策支持系统》。载于 *AAAI人工智能会议论文集*。美国亚利桑那州凤凰城，2016年2月，第4147–4151页。

道义论与程序正义（见第10章）之间，以及后果主义与分配正义之间，存在一些重叠。后果主义与分配正义的一个重要区别是，在第10章中通过群体公平来操作化分配正义时，寻求良好结果的群体是受影响的用户，而且正义/公平在时间和范围上仅限于决策本身。³ 相比之下，在后果主义中，良好是针对整个更广泛社会中的所有人，关心的结果不仅包括眼前的结果，也包括长期的结果。正如第10章之所以聚焦分配正义而非程序正义，是因为它在监督分类中可以更自然地操作化；本章之所以聚焦后果主义而非道义论，原因类似。不过，应当指出，道义论价值观可以从人们那里以规则的形式引出，并作为Alma Meadow申请人筛选模型的额外约束。在某些情况下，这类约束无需重新训练即可方便地添加到模型中。⁴
