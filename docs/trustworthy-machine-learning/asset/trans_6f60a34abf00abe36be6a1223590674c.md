

## 8.4.1 一个基于条件独立检验的示例方法

最古老、最简单且至今仍常用的基于条件独立检验的因果发现方法之一是PC算法。PC算法以其提出者Peter Spirtes和Clark Glymour命名，是一种贪心算法。图8.7展示了ABC Center的一个PC算法示例，涉及工资、儿童保育、稳定住房和二手车这些节点。具体步骤如下：

- 0. PC算法的整体过程从一个完全无向图开始，该图包含所有节点对之间的边。
- 1. 第一步，算法对每一对节点进行检验；如果它们独立，则删除二者之间的边。接下来，它继续对每一对节点在越来越大的子集条件下进行条件独立检验，如果发现任何条件独立性，则删除这对节点之间的边。最终结果是因果图的无向骨架。

第一步的原因如下。节点X₁和X₂之间存在无向边，当且仅当X₁和X₂在所有其他节点的每个可能子集条件下都相关。（因此，如果图中有另外三个节点X₃、X₄和X₅，那么你需要检验X₁和X₂是否：（1）在不给定其他变量的情况下无条件相关；（2）在给定X₃时相关；（3）在给定X₄时相关；（4）在给定X₅时相关；（5）在给定X₃、X₄时相关；（6）在给定X₃、X₅时相关；（7）在给定X₄、X₅时相关；（8）在给定X₃、X₄、X₅时相关。）这些条件相关性可以通过d-separation来确定，这在第3章中已经介绍过。

- 2. 第二步尽可能多地给边加上箭头。算法对三节点链中的第一个和第三个节点进行条件独立检验。如果它们在包含中间节点的某个节点集合条件下相关，则会形成一个带有箭头的共同原因（碰撞器）结构。最终结果是一个部分有向的因果图。算法无法确定的边方向仍属未知。所有这些方向的所有选择共同构成了不同的图，这些图组成了马尔可夫等价类。

第二步的原因是，节点X₁、X₂、X₃的无向链可以变为有向的X₁ → X₂ ← X₃，当且仅当X₁和X₃在包含X₂的每个可能节点子集条件下都相关。这些条件相关性同样可以通过d-separation来确定。

在图8.7的示例结束时，马尔可夫等价类包含四个可能的图。

在第3章中，d-separation是在理想情况下介绍的，即你完全清楚每对随机变量之间的相关性和独立性。但在处理数据时，你并不拥有这种完美的知识。在数据上检验随机变量之间条件独立性的具体计算，通常基于对它们之间互信息的估计。这个看似简单的连续随机变量条件独立性检验问题，实际上包含许多行业技巧，目前仍在研究中，且超出了本书的范围。

![](img/78fc6ae0a1bc731065313dc3a5886b2f_117_0.png)

**图8.7.** *PC算法步骤的一个示例。* 无障碍说明。在第0步，存在一个完全连通的无向图，节点为儿童保育、工资、稳定住房和二手车。在第1步，儿童保育与二手车之间、稳定住房与二手车之间的边已被移除，因为它们表现出条件独立性。无向骨架保留了下来。在第2步，儿童保育与稳定住房之间的边被定向为从儿童保育指向稳定住房，工资与稳定住房之间的边被定向为从工资指向稳定住房。儿童保育与工资之间、工资与二手车之间的边仍保持无向。这就是部分有向图。有四个可能的有向图构成了马尔可夫等价类解：边从儿童保育指向工资且从二手车指向工资；边从工资指向儿童保育且从二手车指向工资；以及边从工资指向儿童保育且从工资指向二手车。

## 8.4.2 一个基于函数模型的示例方法

在基于条件独立检验的方法中，对\(P(y \mid do(t)) = f_y(t, noise_y)\)的函数形式没有做出强假设。因此，正如你在PC算法中所见，某些边的指向可能仍然存在混淆。你无法判断两个节点中哪一个是原因，哪一个是结果。基于函数模型的方法确实对\(f_y\)做出了假设，旨在避免这种混淆。在只有两个节点的情况下最容易理解，比如T和Y，或工资和焦虑。你可能认为工资的变化引起焦虑的变化（T导致Y），但也可能正好相反（Y导致T）。

在基于函数模型的因果发现方法分支中，有一种特定方法称为加性噪声模型。它要求f_Y不是线性函数，且噪声是可加的：P(Y | do(t)) = f_Y(t) + noise_Y；这里noise_Y不应依赖于t。图8.8中的图展示了一个非线性函数示例，并对函数周围的噪声进行了量化。由于噪声不依赖于t，这个噪声带在t的所有取值下高度相同。现在看看当t为纵轴、y为横轴时的情况。噪声带在函数周围对所有的y值高度都相同吗？并非如此，这就是关键观察。当原因位于横轴时，噪声在函数周围具有恒定的高度；当结果位于横轴时则不然。有多种方法可以从数据中检验这一现象，但只要你理解了图8.8所示的这个思想，你就掌握了要领。如果ABC Center想要弄清楚是焦虑的降低导致工资的增加，还是工资的增加导致焦虑的降低，你就知道该做怎样的分析了。

![](img/78fc6ae0a1bc731065313dc3a5886b2f_118_0.png)

图8.8. 使用加性噪声模型方法区分因果关系的示例。由于噪声带的高度在所有t下相同，在所有y下不同，因此t是原因，y是结果。无障碍说明。两个图显示了同一非线性函数及其周围的噪声带。第一个图y在纵轴，t在横轴；第二个图t在纵轴，y在横轴。在第一个图中，对于不同的t值，噪声带的高度始终相同。在第二个图中，对于不同的y值，噪声带的高度始终不同。

当函数是线性时，这种现象不会发生。试着在脑海中为线性函数绘制图8.8，然后作为一个思想实验将其翻转。你会看到噪声的高度在两种方向下都相同，因此你无法区分原因和结果。

## 8.5 因果推断方法

基于第8.4节，你已经掌握了估计ABC Center所收集随机变量之间因果关系结构的工具。但仅仅了解关系对主管来说还不够。他还想量化特定处理和结果标签的因果效应。具体来说，他想知道焦虑降低对稳定住房的影响。你现在转向平均处理效应估计方法，试图回答这个问题。你正在处理观测数据，因为ABC Center并未开展受控实验来厘清这种因果关系。根据图8.5，你知道儿童保育是一个混杂变量，并且由于有先见之明而没有走捷径，你已收集了相关数据。t_i值记录了那些接受焦虑降低处理的客户，x_i值记录了客户儿童保育情况和其他可能混杂因素的数据，y_i值是客户在稳定住房上的结果标签。

记住我们的常用说法：“不能实干，就要假设。”正如在因果发现中一样，从观测数据进行因果推断需要假设。因果推断中的一个基本假设类似于第3章中介绍的机器学习中的独立同分布（i.i.d.）假设。这个因果推断假设，即稳定单位处理值假设，简单来说就是：一个客户的结果只取决于对该客户所做的处理，而不会受到对其他客户处理的影响。有两个重要假设：

- 1. *无未测量混杂因素*，也称为*可忽略性*。数据集需要包含X中的所有混杂变量。
- 2. *重叠*，也称为*正性*。在给定混杂变量的情况下，处理T的概率既不能等于0，也不能等于1。它必须严格大于0且严格小于1。这个定义解释了“正性”这一名称，因为概率必须是正的，而不是恒等于零。该假设的另一个视角是，处理组X的概率分布与对照组X的概率分布应该重叠；两个分布中不应存在某个区域只被其中一个分布所支撑，而另一个分布在该区域没有支撑。图8.9用几个数据集说明了重叠及缺乏重叠的情况。

![](img/78fc6ae0a1bc731065313dc3a5886b2f_119_0.png)

图8.9. 在左侧，处理组和对照组在支撑集上有很多重叠，因此可以进行平均处理效应估计。在右侧，重叠很少，因此不应进行平均处理效应估计。无障碍说明。图中绘制了处理组和对照组的数据点，并叠加了表示其潜在分布支撑集的区域。在左图中，支撑集重叠较多，而在右图中则没有。

这两个假设合在一起称为强可忽略性。如果强可忽略性假设不成立，你就不应基于观测数据进行平均处理效应估计。为什么需要这两个假设？为什么它们很重要？如果数据包含所有可能的混杂变量，你就可以对它们进行调整，以消除可能存在的任何混杂偏倚。如果数据表现出重叠，你就可以对数据进行操作或平衡，使对照组和处理组看起来尽可能相似。
