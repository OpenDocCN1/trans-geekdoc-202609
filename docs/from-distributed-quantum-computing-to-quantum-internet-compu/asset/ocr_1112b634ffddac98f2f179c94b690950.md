+ (|000⟩ - |001⟩ - |010⟩ + |011⟩ - |100⟩ + |101⟩ + |110⟩ - |111⟩)))
= \frac{1}{2}(|000⟩ + |011⟩ + |101⟩ + |110⟩)
2. apply the operation √Z ⊗ √Z ⊗ √Z (and recalling that √Z |0⟩ = |0⟩ and √Z |1⟩ = i |1⟩): (√Z ⊗ √Z ⊗ √Z) \frac{1}{2}(|000⟩ + |011⟩ + |101⟩ + |110⟩) = \frac{1}{2}(|000⟩ + i^2 |011⟩ + i^2 |101⟩ + i^2 |110⟩), and since i^2 = -1, we get \frac{1}{2}(|000⟩ - |011⟩ - |101⟩ - |110⟩) as required.

The procedure for A, B, and C is as follows:

```
0. for each p ∈ {A, B, C}:
1. if i_p = 1 then
2. apply H to ψ_p
3. else
4. do nothing to ψ_p
5. measure ψ_p in the computational basis yielding bit o_p
6. compute o_A ⊕ o_B ⊕ o_C
```

We can show that this works – note that no communication among A, B, and C is involved in the above procedure.

When i_A i_B i_C = 000, the states are measured in the computational basis without applying any H gate, and so, we get as output bits one of {|000⟩, |011⟩, |101⟩, |110⟩}, which is in fact, by choice of our entangled 3-qubit system state we wanted A, B, and C to share (each possibility with an even number of ones), so that the o_A ⊕ o_B ⊕ o_C = 0, as required.

When i_A i_B i_C ∈ {011, 101, 110}, we apply H to exactly two of the three qubits with the effect of generating a superposition of states with an odd number of ones, e.g. when i_A i_B i_C = 011:

(I ⊗ H ⊗ H) \frac{1}{2}(|000⟩ - |011⟩ - |101⟩ - |110⟩)
= \frac{1}{2} (|0⟩ (H|0⟩ H|0⟩ - H|1⟩ H|1⟩) - |1⟩ (H|0⟩ H|1⟩ + H|1⟩ H|0⟩)))
= \frac{1}{2} (|0⟩ (|01⟩ + |10⟩) - |1⟩ (|00⟩ - |11⟩))
= \frac{1}{2} (|001⟩ + |010⟩ - |100⟩ + |111⟩)

And since there will be an odd number of ones obtained when the qubits are measured, whether we get 001, 010, 100, or 111, we have o_A ⊕ o_B ⊕ o_C = 1, as required; similarly, with i_A i_B i_C = 101 and i_A i_B i_C = 110.
