We consider the 1-2 OT protocol, using the ideas from the one presented by Vidick and Wehner.18 Below A has the items d0, d1 ∈ {0, 1}n, and B is requesting an item y ∈ {0, 1}. The aim is for the protocol to compute fB((d0, d1), y) = dy for B and fA((d0, d1), y) = ⊥ for A.

+   1. A selects a random 2n-bit string x = x1 ... x2n ∈ {0, 1}2n and a random basis string θ = θ1 ... θ2n ∈ {0, 1}2n, sends to B bits encoded in the chosen bases (similar to BB84 which we have seen) as the qubits Hθ1 |x1⟩, ... , Hθ2n |x2n⟩.

+   2. B measures each received qubit in a random basis (computational or Hadamard). The bases used by B are recorded as θ′ = θ′1 ... θ′2n. Outcomes are recorded in the string x′ = x′1 ... x′2n.

+   3. Both A and B wait for time t (which waits long enough for B’s quantum memory to “expire” (assuming it does!), so that B cannot have the received qubits before the next step – it must have measured the qubits and stored the outcomes by then – this is a security requirement since B needs to have measured its received qubits before knowing A’s encoding basis string).

+   4. After time t, A assumes that B has done the measurements and sends to B the basis string θ and B determines the set of indices where it used the same basis as A, i.e. S = {j|θj = θ′j }. B sets Sy = S and S1−y = {1, ... , 2n}\S. B sends (S0, S1) to A – we assume that |S0| = |S1| = n, for large enough n.

+   5. A sends d′0 = d0 ⊕ xS0 and d′1 = d1 ⊕ xS1 to B, where ⊕ is the bitwise addition modulo 2, and xS0 = xk1 ... xkn, where ki ∈ S0, and xS1 similarly defined. Note that d′0 and d′1 are encrypted values of d0 and d1 and B can only decrypt one of them.

+   6. A then outputs ⊥ and B outputs d′y ⊕ x′Sy .

We can see that the protocol correctly computes fA and fB above: A outputs ⊥ at the end of the protocol, and B computes what it wanted:

```
d′y ⊕ x′Sy = (dy ⊕ xSy ) ⊕ x′Sy = dy
```

since we know that xSy ⊕ x′Sy = 0, i.e. xSy = x′Sy , because S = {j|θj = θ′j }, and Sy = S from step (4) above, the same basis was used by A and B for all those bits indexed in Sy. Vidick and Wehner provide a more detailed discussion of the security properties, but we can see that in step (3), if they did not wait long enough, B could hold the qubits in memory till it received the encoding bases θ from A and then just measure all the qubits in the same bases as A, then sends (S0 = {1, ... , n}, S1 = {n + 1, ... , 2n}) to A like in step (4), and when A sends d′0 and d′1 to B like in step (5), B can compute both d0 and d1 since xSy ⊕ x′Sy = 0 for both y = 0 and y = 1!
