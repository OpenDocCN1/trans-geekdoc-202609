```

```

Then, to get (+1,+1), we need to obtain \( |0\rangle |\times\rangle \) which occurs with probability \( (\frac{1}{\sqrt{2}}cos(\frac{\pi}{8}))^2 \), to get (-1,-1), we need to obtain \( |1\rangle |-\rangle \) which occurs with probability \( (\frac{1}{\sqrt{2}}cos(\frac{\pi}{8}))^2 \), to get (+1,-1), we need to obtain \( |0\rangle |-\rangle \) which occurs with probability \( (-\frac{1}{\sqrt{2}}sin(\frac{\pi}{8}))^2 \), and to get (-1,+1), we need to obtain \( |1\rangle |\times\rangle \) which occurs with probability \( (\frac{1}{\sqrt{2}}sin(\frac{\pi}{8}))^2 \).
