> > Aside: The following observations are useful for computing the probabilities above and can be verified by the reader via calculations.
> >
> > * We note that: \(\frac{1}{\sqrt{2}}(|00\rangle + |11\rangle) = \frac{1}{\sqrt{2}}(|++\rangle + |--\rangle) = \frac{1}{\sqrt{2}}(|xx\rangle + |\dot{+}\dot{-}\rangle)\)
> > * We note the different ways of expressing one basis in terms of the other:
> >
> > \(|0\rangle = \frac{1}{\sqrt{2}}(|+\rangle + |-\rangle)\) | \(|1\rangle = \frac{1}{\sqrt{2}}(|+\rangle - |-\rangle)\)
> >
> > \(|0\rangle = cos\left(\frac{\pi}{8}\right)|x\rangle - sin\left(\frac{\pi}{8}\right)|\dot{-}\rangle\) | \(|1\rangle = sin\left(\frac{\pi}{8}\right)|x\rangle + cos\left(\frac{\pi}{8}\right)|\dot{-}\rangle\)
> >
> > \(|0\rangle = sin\left(\frac{\pi}{8}\right)|x'\rangle - cos\left(\frac{\pi}{8}\right)|\dot{-}'\rangle\) | \(|1\rangle = cos\left(\frac{\pi}{8}\right)|x'\rangle + sin\left(\frac{\pi}{8}\right)|\dot{-}'\rangle\)
> >
> > \(|x\rangle = cos\left(\frac{\pi}{8}\right)|+\rangle + sin\left(\frac{\pi}{8}\right)|-\rangle\) | \(|\dot{-}\rangle = sin\left(\frac{\pi}{8}\right)|+\rangle - cos\left(\frac{\pi}{8}\right)|-\rangle\)
> >
> > \(|x\rangle = \frac{1}{\sqrt{2}}(|x'\rangle - |\dot{-}'\rangle)\) | \(|\dot{-}\rangle = \frac{1}{\sqrt{2}}(|x'\rangle + |\dot{-}'\rangle)\)
