# Write enough code to make it pass

The `for` syntax is very unremarkable and follows most C-like languages.

```
```go
func Repeat(character string) string {
    var repeated string
    for i := 0; i < 5; i++ {
        repeated = repeated + character
    }
    return repeated
}
```
