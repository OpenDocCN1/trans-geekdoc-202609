## 重构

当你在 Go 中索引字符串时，你得到的是一个字节。这就是为什么当我们再次构建字符串时必须做类似 string([]byte{symbol}) 的事情。它重复了几次，我们只需将该功能移出，让 ValueOf 接受一些字节即可。

```
func (r RomanNumerals) ValueOf(symbols ...byte) int {
    symbol := string(symbols)
    for _, s := range r {
        if s.Symbol == symbol {
            return s.Value
        }
    }

    return 0
}
```
