## 集成测试

集成测试可用于测试系统更大范围是否工作，但你必须牢记：

- 它们更难编写
- 当它们失败时，很难知道为什么（通常是集成测试组件中的错误），因此修复起来可能更困难
- 它们有时运行速度较慢（因为它们通常使用“真实”组件，如数据库）

因此，建议你研究*测试金字塔*。
