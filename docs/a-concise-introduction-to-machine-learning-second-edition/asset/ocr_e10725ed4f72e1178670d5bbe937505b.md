We can now check whether f satisfies detailed balance. To this end,

```
$f(\mathbf{x})T(\mathbf{x}, \mathbf{x}') = \begin{aligned} &\hat{f}(\mathbf{x})g(\mathbf{x}, \mathbf{x}') \min \left(1, \frac{\hat{f}(\mathbf{x})g(\mathbf{x}, \mathbf{x}')}{f(\mathbf{x})g(\mathbf{x}, \mathbf{x}')}}\right) \&=\frac{1}{c_f} \min(f(\mathbf{x})g(\mathbf{x}, \mathbf{x}'), \hat{f}(\mathbf{x})g(\mathbf{x}, \mathbf{x}')) \&=\frac{1}{c_f} \min(f(\mathbf{x})g(\mathbf{x}, \mathbf{x}'), \hat{f}(\mathbf{x})g(\mathbf{x}, \mathbf{x}')) \&=\frac{1}{c_{f'}} g(\\mathbf{x}, \mathbf{x}') \min \left(1, \frac{f(\mathbf{x})g(\mathbf{x}, \mathbf{x}')}{\hat{f}(\mathbf{x}', \mathbf{x}')}g(\mathbf{x}', \mathbf{x}')}}\right) = \hat{f}(\mathbf{x})T(\mathbf{x}, \mathbf{x}').\end{aligned}$
```

Thus detailed balance is satisfied as required to generate approximate samples of the distribution described by $f$.

The Metropolis-Hastings algorithm is an example of a class of algorithms known as Markov Chain Monte Carlo (MCMC). In general, Monte Carlo methods rely on repeated sampling to perform calculations, where a closed solution is not possible or possibly expensive. They were first developed at the Los Alamos National Laboratory. Since the work was secret, Monte Carlo, referring to the Casino in Monte Carlo, became the code name.

Gibbs sampling is used, when it is easier to sample from the distribution of the components than from that of $\mathbf{x}$. Let $\mathbf{x} = (x_1, \dots, x_D)^T$, where $D$ is the dimension of the state space. The next element $x_{n+1}$ is constructed in $D$ steps by drawing $x_{n+1,d}$ sequentially from the conditional probability $p(x_{n+1,d}|x_1, \dots, x_{n+1,d-1}, x_d, \dots, x_D)$ for $d=1, \dots, D$. This means that a component is used in the next draw as soon as it has been drawn. Another version could to update next randomly.

The distribution described by the probability density function of $\mathbf{x}$ is invariant of the sampling steps for the following reasons. The marginal distribution of $\mathbf{x}_n = (x_1, \dots, x_{-d}, \dots, x_D)$ is invariant, since only one component changes in the $d^{th}$ step. Secondly, the $d^{th}$ component is sampled from the conditional distribution, and invariant because the joint distribution (which is the distribution of $\mathbf{x}$) is determined by each also invariant. The ergodic theorem can be applied anywhere in the state space. This generated Markov chain will produce samples from the desired distribution.

Gibbs sampling can be phrased in terms of the Metropolis-Hastings algorithm. Let the current sample be $\mathbf{x}$. Note, this could be an element of the Markov chain or one of the intermediate steps. The candidate $\mathbf{x}^*$ differs from the previous sample $\mathbfmathbf{x}$ in only one component. Let this be the $d^{th}$ component. Hence $\mathbf{x}^*_{-d} = \mathbf{x}_{-d}$. The $d^{th}$ component of $\mathbf{x}^*$ is drawn from $p(x_d^*|\mathbf{x}_{-d})$. This defines the proposal distribution

```
$g(\mathbf{x}, \mathbf{x}^*) = p(x_d^*|\mathbf{x}_{-d}).$
```
