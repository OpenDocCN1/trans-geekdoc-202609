def BoxMuller(N):
    X = np.zeros((N,2))

            # Draw two samples from the uniform distribution on (-1,1)
            z1 = 2.0 * np.random.uniform() - 1.0
            z2 = 2.0 * np.random.uniform() - 1.0
            # While loop ends, the point is within the unit circle.
            s = z1 + z2
            # Calculate radius.
            s = np.sqrt(2.0 * np.log(s)) / s
            X[n,0] = z1 * s
            X[n,1] = z2 * s
    return X

This rise to the polar form of the Box-Muller transform. First, we generate uniformly distributed numbers $z_1, z_2 \in (-1,1)$ by letting $z_i = 2y_i-1$ for variables $y_i$ uniformly distributed in $(0,1)$, until $s = z_1^2 + z_2^2 < 1$.
We then set

$$\cos \theta = \frac{z_1}{\sqrt{s}}$$\nsin \theta = \frac{z_2}{\sqrt{s}}$

The probability $p(s \le \hat{s})$ is the area of the circle with radius $\sqrt{s}$, which is $\pi s$, divided by the area of the unit circle which is $\pi$. Therefore $p(s \le \hat{s}) = s$, and $s$ follows a uniform distribution on $(0,1)$. Therefore, $s$ can be used to generate a random variable from the distribution of $r$. To summarize,
