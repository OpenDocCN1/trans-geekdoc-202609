In the following, we will first classify two species, that is, classes which we label $C_0$ and $C_1$. This is also known as binary classification. Let $N_0$ be the number of samples in class $C_0$ and $N_1$ the number of samples in class $C_1$. Hence the overall number of samples is $N = N_1 + N_2$. It is helpful to look at a visual representation of the data as in Figure 4.1 where we have chosen two features to display against each other, sepal length and sepal width. This is known as a scatter plot.

Once we developed a rule to distinguish between classes based on features, we can use it to classify future features. However, there needs to be a word of caution. Features that are not necessarily within a class might develop over time. So it needs to be monitored whether the rule continues to be adequate. Outliers also known as anomalies are features which occur away from most samples belonging to a class. These can occur as long as the probability of occurrence is nonzero. More outliers than expected can indicate that the rule needs to be updated. If an online learning technique was employed, the rule was developed iteratively with new samples arriving, this is straightforward, because the same technique can be employed. For offline techniques which consider all samples updating, the rule can be more elaborate up to running the training algorithm again, including all new samples.
