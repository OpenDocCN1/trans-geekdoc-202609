The prior assumption is that the vector $\pi =(\pi_1, \dots, \pi_K)$ follows a Dirichlet distribution with parameter $(\alpha_1, \dots, \alpha_K)$. For example, if $\alpha=(1, \dots,1)$, then the probability distribution is the uniform distribution over the simplex $\pi$. So all possibilities for $\pi$ are equally less likely. As $\alpha$ increases, the resulting Dirichlet probability density functions get more and more peaked at $\pi=(1/K, \dots,1/K)^T$ with any other vectors becoming less likely. $\alpha$ controls how different the cluster sizes are. The effect is illustrated in Figure 6.5. When $\alpha=K$ in Figures 6.5a and 6.5b, the cluster sizes can be very different. As $\alpha$ increases (Figures 6.5c and 6.5d), the clusters become similar in size. Their sizes approach $N/K$.
