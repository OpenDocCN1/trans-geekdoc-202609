# 4.6 The Support Vector Machine

Letting the learning rate α be a choice of crude. All should be determined by the data. When all samples are correctly classified, that is $c_n = sgn(\mathbf{w}^T\mathbf{v}_n)$, the $margin$ from the separation line is defined as

```
$\min_{n=1,\dots,N} \frac{\mathbf{w}^T\mathbf{v}_n}{\}{\mathbf{w}\|} > 0$
```

The Support Vector Machine (SVM) tries to maximize the margin between the two classes.

Note that the margin is independent of rescaling of $\mathbf{w}$, since we divide by the length of $\mathbf{w}$. We use the freedom to rescale $\mathbf{w}$ such that $c_n\mathbf{w}^T\mathbf{v}_n - 1 \ge 0$ for $n=1,\dots,N$ with equality for every one sample. We impose some constraints on $\mathbf{w}$. In the case of samples, where we have equality, the constraints are to be *active*. For the other samples, they are *inactive*. Subject to these constraints, maximizing the margin is equivalent to maximizing $|\mathbf{w}\|^{-1}$. Here, the equivalent problem is: *Minimize the objective function* $|\mathbf{w}\|^2/2$ subject to the constraint $c_n\mathbf{w}^T\mathbf{v}_n - 1 \ge 0$ for all $n=1,\dots,N$. This is known as a *quadratic programming problem*. For reasons which will become clear below, this is called the *primal optimization problem*.
