Using the inversion formula for a block matrix in A.1.1, the precision matrix of the distribution

```
$$\begin{aligned} C^{-1} + \frac{C^{-1}k(\mathbf{x}_i)k(\mathbf{x}_j)^T C^{-1}}{c(\mathbf{x}_i)-k(\mathbf{x}_i)^T C^{-1}k(\mathbf{x}_i)} &= \frac{-C^{-1}k(\mathbf{x}_j)}{c(\mathbf{x}_i)-k(\mathbf{x}_i)^T C^{-1}k(\mathbf{x}_i)} \ &+ \frac{k(\mathbf{x}_i)^T C^{-1}k(\mathbf{x}_j)}{c(\mathbf{x}_j)-k(\mathbf{x}_j)^T C^{-1}k(\mathbf{x}_j)} \end{aligned}$
```

We can deduce that the conditional probability of $\mathbf{t}_i$, is normal and has variance and mean

```
$$\sigma^2(\mathbf{x}_*) = c(\mathbf{x}_*) - k(\mathbf{x}_*)^T C^{-1}k(\mathbf{x}_*) = \sigma^2 + k(\mathbf{x}_*,\mathbf{x}_*)^T C^{-1}k(\mathbf{x}_*)$,
```

```
$m(\mathbf{x}_*) = k(\mathbf{x}_*)^T C^{-1}\mathbf{t}. \quad (8.12)$
```

Since $\mathbf{x}_*$ is chosen arbitrarily (excluding $\mathbf{x}_1, \dots, \mathbf{x}_N$), this specifies a distribution over functions.
