# # Clustering

So far we have looked at data which had class labels. The task was to learn the class membership from the features of each data sample, in order to classify unseen data in the future. In this chapter, we look at unlabled data. As before, we denote the vector of features by $v$. Let $v_1, \dots, v_N$ be the feature vectors of $N$ data samples. The choice of features or combination of features is important.
