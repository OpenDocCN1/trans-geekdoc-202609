
We see, the mapping $\phi$ never has to be evaluated, only the kernel $k$ rate objective function to be maximized becomes

```
$L(\alpha) = \sum_{n=1}^{N} \alpha_n - \frac{1}{2}\sum_{i=1}^{N}\sum_{j=1}^{N} \alpha_i \alpha_j c_{ij} \, (1 + k(\mathbf{v}_i, \mathbf{v}_j))$$
```

subject to $\alpha_i \ge 0, i = 1, \dots, N$. The classification is according to the sign of

```
$$-b + \sum_{n=1}^{N} \alpha_n c_n \phi(\mathbf{v}_n)^T \mathbf{v} = -b + \sum_{n=1}^{N} \alpha_n c_n k(\mathbf{v}_n, \mathbf{v})$$$
```

The kernel trick can be applied to all linear classification methods to separate data which are not linearly separable. All methods reduce evaluations of the kernel function $k$.

The kernel function was derived from a higher dimensional inner product. In the previous chapter, we viewed the inner product as a measure of the relationship between samples. For example, a new sample is classified by whether it is more related to the weighted inner product with the support vectors of one than the other. The kernel function gives a numeric value describing the relationship between two samples.

Such functions describing samples not need to be solely derived from higher dimensional inner product. A necessary and sufficient condition that such a function is suitable for our purposes is that the $N \times N$ matrix **K** with $(m,n)$ entry equal to $k(\mathbf{x}_m, \mathbf{x}_n)$ is *positive-definite* for any $N$ and for any sample $\{\mathbf{x}_1, \dots, \mathbf{x}_N\}$. This means $\mathbf{v}^T K \mathbf{v} \ge 0$ for all $\mathbf{v}$. The matrix is called *Gram* or *Gramian matrix*. The constant function $k(\mathbf{x}, \mathbf{y}) = c$ for positive $c$ is a valid kernel, then for any $\mathbf{v} = (\mathbf{v}_1, \dots, \mathbf{v}_N)$

```
$$\mathbf{v}^T K \mathbf{v} = \left(\sum_{n=1}^{N} \mathbf{v}_n\right)^2 \ge 0.$$
```

We also have positive semi-definiteness of **K**, if the kernel function is defined via an higher dimensional space, because this

```
$$\mathbf{v}^T K \mathbf{v} = \left(\sum_{m=1}^{N} \mathbf{v}_m \phi(\mathbf{x}_m) \right)^T \left(\sum_{n=1}^{N} \mathbf{v}_n \phi(\mathbf{x}_n) \right)\\
= \left(\sum_{n=1}^{N} \mathbf{v}_n \phi(\mathbf{x}_n) \right\|^2 \ge 0.$$
```

Therefore the inner product itself is a valid kernel.

# A Concise Introduction to Machine Learning

**If A** is a symmetric, positive semi-definite, $M \times M$ matrix, then the function defined by

$k(\mathbf{x}, \mathbf{y}) = \mathbf{x}^T \mathbf{y}$

is a valid kernel function, in this case

```
$$\mathbf{v}^T \mathbf{K} \mathbf{v} = \sum_{m,n}^N v_m \mathbf{x}_m^T \mathbf{A} \mathbf{x}_n = \left(\ \sum_{m=1}^N v_m \mathbf{x}_m \right)^T \mathbf{A} \left( \sum_{n=1}^N v_n \mathbf{x}_n \right) \geq 0.$$
```

Similarly, if $f: \mathbb{R}^M \to \mathbb{R}$ is any function, and $k: \mathbb{R}^M \times \mathbb{R}^M \to \mathbb{R}$ is a valid kernel, then

```
$$\sum_{m,n}^N k(\mathbf{x}_m, \mathbf{x}_n) k(\mathbf{x}_n, \mathbf{y}) v_m v_n = \mathbf{w}^T \mathbf{K} \mathbf{w} \geq 0, \eqno (5.1)$$
```

where $w=(f(\mathbf{x}_1)v_1, \dots, f(\mathbf{x}_N)v_N)^T$. Therefore, the function defined by $f(\mathbf{x})k(\mathbf{x}, \mathbf{y})f(\mathbf{y})$ is a valid kernel.

Multiplying a valid by a positive constant and the sum of two valid kernels is ever a kernel. Let $\{\mathbf{x}_1, \dots, \mathbf{x}_N\}$ be an arbitrary set. Let $\mathbf{K}$ denote the Gram matrix of the product of kernels. Since the Gram matrices of the two factors are symmetric and positive semi-definite, they can be written as $A^T A$ and $B^TB$ respectively. Thus, their $(m,n)$ entries are given by

```
$$\sum_{i=1}^N A_{mi} A_{ni} \quad \text{and} \quad \sum_{j=1}^N B_{mj} B_{nj}$$
```

respectively. For an arbitrary vector $\mathbf{v} = (v_1, \dots, v_N)^T$,

```
$$\mathbf{v}^T \mathbf{K} \mathbf{v} = \sum_{m,n}^N v_m K_{mn} v_n = \sum_{m=1}^N v_m \left(\sum_{i=1}^N A_{mi} v_i\right) \left(\sum_{j=1}^N B_{mj} v_j\right) \\
n = \sum_{m=1}^N \left(v_m \sum_{i=1}^N A_{mi} v_i\right) \left(v_m \sum_{j=1}^N B_{mj} v_j\right) \geq 0.$$
```

Here $\mathbf{K}$ is positive semi-definite, and the product of two kernels is a kernel. From this we can deduce that if $p$ is a polynomial with nonnegative coefficients, $p(k(\mathbf{x}, \mathbf{y}))$ is a valid kernel, if $k(\mathbf{x}, \mathbf{y})$ is a valid kernel. Since the positive semi-definiteness has to hold for all points, $x_1, \dots, x_N$ that is, $k(\mathbf{x}, \mathbf{y})$ is a valid kernel. Also $\exp(k(\mathbf{x}, \mathbf{y}))$ is a valid kernel as it is a polynomial with positive coefficients.

Since the positive semi-definiteness has to hold for all points, $x_1, \dots, x_N$ that is, $k(\mathbf{x}, \mathbf{y})$ is a valid kernel. Also $\exp(k(\mathbf{x}, \mathbf{y}))$ examples of kernels are:
