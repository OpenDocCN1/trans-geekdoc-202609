We can calculate the distance between **t** and **f**

```
$|\mathbf{t}-\mathbf{f}\|^2 = \mathbf{t}^T\mathbf{t} - 2\mathbf{f}^T\mathbf{t} + \mathbf{f}^T\mathbf{f}$$
$$= \mathbf{t}^T\mathbf{t} - 2\sum_{i=1}^K \frac{(Dv_i)^T\mathbf{t}}{\lambda_i} (Dv_i)$$
$$+\sum_{i,j=1}^K \frac{(Dv_i)^T\mathbf{t}}{\lambda_i}\frac{(Dv_j)^T\mathbf{f}}{\lambda_j}(T^Dv_j)$$
$$= \mathbf{t}^T\mathbf{t} - \sum_{i=1}^K \frac{((Dv_i)^T\mathbf{t})^2}{\lambda_i}=\|a\|^2$
```

where we used the fact that $(Dv_i)^Tv_j = \lambda_i$, if $i=j$ and zero otherwise. Thus the predictions are closest, all eigenvectors with nonzero eigenvalues are used. Using the decomposition of **t**, we have

```
$$(Dv_i)^T\mathbf{t} = \sum_{k=1}^K a_kv_k^TDv_k + v_k^T D^T a = a_i\lambda_i,$$
```

where we made again use of orthogonality. This introduces into the distance **t** and **f**, we obtain

```
$|\mathbf{t}-\mathbf{f}\|^2 = \mathbf{t}^T\mathbf{t} - \sum_{i=1}^K \alpha_i^2\lambda_i.$
```

If sparsity is required, not all eigenvectors can be used, those for which $\alpha_i^2\lambda_i$ is largest chosen. However, this implicitly depends on the data t via the coefficient $\alpha_i$, and can cause the model to not generalize well to unseen data. To avoid this, it is customary to choose the eigenvectors with the largest eigenvalues. Determining the eigenvectors and eigenvalues of a matrix is no trivial matter in itself, and can be computationally expensive, especially if M is large. Faul (2016) gives some iterative techniques to find the largest eigenvalues.

Note that generating regressors is equivalent to generating new features. These features are linear combinations of the original features.

Principal component regression does not address the correlation with the regression. The method presented in the next section does so.
