$v_1, \dots, v_N \in \mathbb{R}^D$, which are known as the *pre-images*. Further let $\Phi$ be the $D \times N$ matrix whose columns are the vectors $\phi(v_1), \dots, \phi(v_N)$,

> $\Phi(I - \frac{1}{N}\mathbf{E}) = (\phi(v_1) - \frac{1}{N}\sum_{n=1}^N \phi(v_n)), \dots, \phi(v_N) - \frac{1}{N}\sum_{n=1}^N \phi(v_n))$,

since, for every row of $\Phi$, we subtract the mean of that row of $\Phi$. The columns of this matrix are the shifted images.

Recall that Principal Component Analysis calculates the covariance matrix $\Sigma$ of the data samples. In this context, it means the covariance matrix of the $n^{th}$ column of the shifted images, which is the average of the outer products of the $n^{th}$ column of $\Phi(I - \frac{1}{N}\mathbf{E})$ with its transpose. This can be written as

```
$$\Sigma = \frac{1}{N} \sum_{n=1}^N \Phi(I - \frac{1}{N}\mathbf{E})e_n e_n^T (I - \frac{1}{N}\mathbf{E})\Phi^T$,
```

where $e_n$ is the standard basis vector, with all elements being equal to zero except for the $n^{th}$ column. Multiplying by $e_n$, from the right picks out the $n^{th}$ column. Now, $\Phi(I - \frac{1}{N}\mathbf{E})$ and its transpose are independent of $n$ in the summation. Summing $e_n e_n^T$ over all $n=1, \dots$ results in the identity matrix. Further, the matrix $I - \frac{1}{N}\mathbf{E}$ is *idempotent*, which means any power of it is the matrix itself, since $\mathbf{E}^2 = \mathbf{E}$ and

```
$(I - \frac{1}{N}\mathbf{E})(I - \frac{1}{N}\mathbf{E}) = I - \frac{2}{N}\mathbf{E} + \frac{1}{N^2}\mathbf{E}^2 = I - \frac{1}{N}\mathbf{E}$.
```

Therefore, the covariance matrix can be expressed as

```
$\Sigma = \frac{1}{N} \Phi(I - \frac{1}{N}\mathbf{E})\Phi^T$.
```
