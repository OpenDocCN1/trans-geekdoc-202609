Therefore, the random variables $y_1$ and $y_2$ are independent. Both are normally distributed with mean zero and standard deviation $\sqrt{2}$. Or in other words the variance is 2, which is the sum of the variances of $x_1$ and $x_2$.

More, if $y$ is a linear combination of independent normally distributed variables, i.e. $y = c_1x_1 + \dots + c_kx_k$, with $x_k \sim \mathcal{N}(\mu_k, \sigma_k^2)$, then $y$ is normally distributed with mean

```
$\mu = c_1\mu_1 + \dots + c_k\mu_k$
```

and variance

```
$\sigma^2 = c_1^2\sigma_1^2 + \dots + c_k^2\sigma_k^2$.
```

So far we have looked at probability distributions and how to derive the probability density function for functions of random variables. In the next section we will show how to link this to data.

# 2.6 Conjugate, Prior and Posterior Distributions and Maximum Likelihood

The previous sections were concerned with probabilities and how to describe them. We are interested in describing data with probabilities. To do this, let us return to the experiment of flipping a coin, or more generally an experiment with Bernoulli distribution $	ext{Bern}(x)$, where $\mu$ is unknown. Let $x_1, \dots, x_N$ be $N$ observations of the experiment. The probability to observe this data $D = \{x_1, \dots, x_N\}$ is

```
$p(D|mu) = \prod_{n=1}^N 	ext{Bern}(x_n|mu) = \prod_{n=1}^N \mu^{x_n}(1-\mu)^{1-x_n} = \mu^{\sum_{n=1}^N x_n}(1-\mu)^{\sum_{n=1}^N (1-x_n)}$
```

This is known as the likelihood of the data $D$. Now, if $m$ is the number of times we $x_n = 1$ in $N$ trials, then

```
$p(D|mu) = \mu^m(1-\mu)^{N-m}$.
```

The value of $\mu$ can be estimated by maximizing the likelihood with respect to $\mu$, since we want to choose the $\mu$ which explains the best data.

The maximization is equivalent to maximizing the logarithm, which is valid, since the logarithm is a monotonically increasing function. This is the log likelihood:

```
$\log p(D|mu) = m \log \mu + (N-m) \log(1-\mu)$.
```

The location of the maximum is where the derivative with respect to $\mu$ vanishes. The derivative is

```
$\frac{d}{d\mu}p(D|mu) = \frac{m}{\mu} - \frac{N-m}{1-\mu}$.
```
