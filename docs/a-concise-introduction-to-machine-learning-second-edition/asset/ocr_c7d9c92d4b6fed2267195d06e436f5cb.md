#  5.6 Boosting and Cascades

We distinguish between *weak* and *strong* learners. A weak learner will only be slightly better than random guessing, while a strong learner provides the right classification most of the time. In this section we consider the question, whether a set of weak learners can create a single strong learner?

To simplify things we assume that both classes are present in *parity*. That is, the number of samples in each class is the same. The goal is to generate a classifier $C$ where the sign of the output determines the class, and the absolute value of the output gives the confidence in this prediction.

The total $E$ of $C$ is defined as the sum of *exponential error* at each training sample

```
$E(C) = \sum_{i=1}^{N} \exp(-c_i C(\mathbf{v}_i))$$
```

where $c_i = \pm1$ is the class label of $\mathbf{v}_i$. If $C$ predicts the class label of $\mathbf{v}_i$ *correctly* with great confidence, then $c_i$ and $C(\mathbf{v}_i)$ will have the same sign. Great confidence means that the absolute value of $C(\mathbf{v}_i)$ is large, and hence little to the total error, since the exponent $\exp(-c_i C(\mathbf{v}_i))$ is a large negative number. If $C$ predicts the class label of $\mathbf{v}_i$ *incorrectly* with great confidence, then $\exp(-c_i C(\mathbf{v}_i))$ will contribute a lot to the total error, since $c_i$ and $C(\mathbf{v}_i)$ will have opposite sign and the exponent will be a large positive number. We consider a strong classifier $C$ that predicts correctly with great confidence, and has little error in the prediction when making errors. How can such a classifier be developed?

AdaBoost, short for *Adaptive Boosting*, iteratively generates a series of classifiers $C_m$. Each iteration improves the classifier by concentrating on the misclassified elements. Each classifier is stronger than its predecessor. It is generated as a linear combination of simple, weak classifiers $k_j$ which only return $\pm1$. The perceptron can be one of these. The coefficients in this linear combination are positive. Each coefficient gives the confidence in the weak classifier. The final classifier decides based on the linear combination of weak classifiers.

