Thus the derivative of the kernel with regards to its parameters is needed. For
the Gaussian kernel

```
$k(x, y) = \theta^2 \exp \left(-\frac{\|\mathbf{x}-\mathbf{y}\|^2}{2l^2}\right),$
```

this is for example

```
$$\frac{\partial}{\partial\theta}k(x,y) = 20\theta \exp \left(-\frac{\|\mathbf{x}-\mathbf{y}\|^2}{2l^2}\right) = \frac{2}{\theta}k(x,y),$
```

```
$$\frac{\partial}{\partial l}k(x,y) = \frac{\\|\mathbf{x}-\mathbf{y}\|^2}{l^3}\theta^2 \exp \left(-\frac{\\|\mathbf{x}-\mathbf{y}\|^2}{2l^2}\right) = \frac{\\|\mathbf{x}-\mathbf{y}\|^2}{l^3}k(x,y).$
```
