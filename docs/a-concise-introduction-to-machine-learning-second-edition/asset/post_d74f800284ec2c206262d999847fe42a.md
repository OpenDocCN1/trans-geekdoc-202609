
![](img/c6c76bf52016db7e78a5e30d4766ef81_66_0.png)

Figure 2.21: Simplex of the possible location of **x** due to the constraints on its elements.

For $\alpha_1 = \dots = \alpha_K$ the distribution is known as *symmetric Dirichlet distribution* or *flat Dirichlet distribution*. The latter naming is misleading, since it is only flat, when all concentration parameters take the value one. The Dirichlet distribution then becomes the uniform distribution over the simplex. In this case,

```
$$\text{Dir}(\mathbf{x}) = \frac{\Gamma(K)}{\Gamma(1)\cdots\Gamma(1)} \prod_{k=1}^K x_k^{0}=(K-1)!$$
```

which is the inverse of the volume of the simplex. For $K=3$, the 2-simplex has volume 1/2.

We see in [Figure 2.22] that for $\alpha=(5,5)^T$, the probability mass is concentrated in the center, while for $\alpha=(5,2)^T$, it is concentrated towards the opposite edge of the corner with the smallest concentration parameter. For $\alpha=(5,2)^T$, the probability mass is concentrated at the corner with the largest concentration parameter.

When one of the concentration parameters $\alpha_i$ is less than one, then the probability density function will tend to infinity at the corresponding edge $x_k=0$. For [Figure 2.22], this is visible for $\alpha=(0,8,0,2)^T$, but hardly visible for $\alpha=(0,8,0,2)^T$.

We calculate the expectation of the components of **x** individually. Let

```
$$\alpha_0=\sum_{k=1}^K \alpha_k$$
```

Note that the integral is over the simplex

```
$$\mathbb{E}[x_j] = \int x_j \text{Dir}(x|\alpha)dx = \frac{\Gamma(\alpha_0)}{\Gamma(\alpha_1)\cdots\Gamma(\alpha_K)} x_j^{\alpha_j} \prod_{k\neq j}^K x_k^{\alpha_k-1}dx$$
$$= \frac{\Gamma(\alpha_0)}{\Gamma(\alpha_1)\cdots\Gamma(\alpha_{j-1})\Gamma(\alpha_{j+1})\cdots\Gamma(\alpha_K)} \Gamma(\alpha_j+1)$$
$$= \int \text{Dir}(x|\alpha_1,\dots,\alpha_{j-1},\alpha_j,\alpha_{j+1},\dots,\alpha_K)dx$$
$$= \frac{\alpha_j}{\alpha_0}$$
```

where we have used the property given in 2.14 of the gamma function and the fact that the integral of any probability density function over its range is one. The variance is given by

```
var[x_j] = \frac{\alpha_j(\alpha_0 - \alpha_j)}{\alpha_0^2(\alpha_0 +1)}
```

while the covariance for $j \neq k$ is

```
cov[x_j, x_k] = \frac{-\alpha_j\alpha_k}{\alpha_0^2(\alpha_0 +1)}
```

As we have seen before with the categorical distribution, the influence is negative, since if one component increases, another has to decrease due to the constraints on $\alpha$. Looking at Figure 2.22 we see that the relative size of concentration parameters $\alpha_k$ to their sum $\alpha_0$ determines where most of the probability mass is concentrated within the simplex. Therefore, in some literature, the Dirichlet distribution are given as $\alpha$,

```
$$\alpha = \alpha_0 = \sum_{k=1}^K \alpha_k,$$
$$\mu = \left(\frac{\alpha_1}{\alpha_0}, \dots, \frac{\alpha_K}{\alpha_0}\right)^T\quad (2.16)$$
```

In this case, $\alpha$ is known as the (single) concentration parameter, where $\mu$ is the base distribution. We have already seen that, if $\alpha=1$, the Dirichlet distribution is uniform. This means all distributions $\chi$ are equally likely. If $\alpha$ tends to infinity, only distributions become nearly peaked around the uniform distribution given by $\chi=(1/K, \dots, 1/K)$. In Figure 2.22, $\alpha_0$ is large for $\alpha=(5,5,5)^T$ and the probability mass is concentrated around $(1/3, 1/3, 1/3)$, which describes the uniform distribution for three outcomes. If $\alpha$ tends to zero, let $\mu_k$ be the component which is largest, i.e. $\mu_k > \mu_j$ for all $j \neq k$, then the Dirichlet distribution tends to be peaked at this corner of the simplex. If there are several components with the same largest value, it tends to peak along these edges, while it is zero everywhere.

Both the beta distribution and the Dirichlet distribution can be illustrated by the Pollya urn model. Imagine an urn which contains balls of $K$ different colours. For the beta distribution, these are two colours. Initial proportions are given by the base distribution $\mu$.

```python
import numpy as np
import matplotlib.pyplot as plt
from copy import copy
def polya(alpha, N):
    # Initialize the urn with alpha which specifies the number of balls of different colours.
    y = copy(alpha)
    for n in range(1, N - sum(alpha)):
        # Calculate the proportions of each colour.
        p = np.divide(y, sum(y))
        # Choose a random index according to the proportions.
        idx = np.random.choice(len(p), None, True, p)
        # Add a ball of the colour indexed by the index.
        y[idx] = y[idx] + 1
    return y
# Final number of balls:
N = 100
# Number of experiments:
I = 1000
# Initializing alpha.
alpha = [2, 4]
# First experiment:
Y = polya(alpha, N)

# Further experiments:
for i in range(1, I):
    Y = polya(alpha, N)
    Y = np.stack((Y, Y))

# Plot histogram of experiment outcomes.
plt.hist(Y[:,0], bins=range(1,101)) -0.5 * np.ones(100)
plt.show()
```
