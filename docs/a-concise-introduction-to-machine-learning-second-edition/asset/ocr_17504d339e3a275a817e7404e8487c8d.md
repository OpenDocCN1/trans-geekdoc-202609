With this we can simplify the terms in $\mathcal{L}$. First,

$$\log |C| = \log |C_{-j}| + \log (1 + \sigma^{-2}\mathbf{w}_j^T\mathbf{w}_j).$\quad (7.4)$

Differentiating this with respect to $\mathbf{w}_j$ using **A2.1** gives

$$\frac{\partial}{\partial\mathbf{w}_j}\log |C| = \frac{1}{1+\sigma^{-2}\mathbf{w}_j^T\mathbf{w}_j}\sigma^{-2}\mathbf{w}_j = \frac{2}{\sigma^{-2}+\mathbf{w}_j^T\mathbf{w}_j}\mathbf{w}_j.$

On the other hand,

$tr(C^{-1}\Sigma) = tr(C_{-j}\Sigma)\frac{\sigma^{-2}}{\sigma^{-2}+\mathbf{w}_j^T\mathbf{w}_j}tr(\mathbf{w}_j^T\Sigma)$$\n= tr(C_{-j}\Sigma)\frac{\sigma^{-2}}{\sigma^{-2}+\mathbf{w}_j^T\mathbf{w}_j}\mathbf{w}_j,$

where we used the cyclic permutation property of the trace. Using the product rule, **A.2** and **A2.3**, the derivative with respect to $\mathbf{w}_j$ is

$$\frac{\partial}{\partial\mathbf{w}_j}tr(C^{-1}\Sigma) = \frac{\sigma^{-2}}{\sigma^{-2}+\mathbf{w}_j^T\mathbf{w}_j}[(\sigma^{-2}+\mathbf{w}_j^T\mathbf{w}_j)\Sigma\mathbf{w}_j - (\mathbf{w}_j^T\Sigma)2\mathbf{w}_j].$

Therefore, the derivative of the likelihood with respect to $\mathbf{w}_j$ is

$$\frac{\partial}{\partial\mathbf{w}_j}\mathcal{L} = \frac{\sigma^{-2}}{\sigma^{-2}+\mathbf{w}_j^T\mathbf{w}_j}[(\sigma^{-2}+\mathbf{w}_j^T\mathbf{w}_j)\mathbf{w}_j - \Sigma\mathbf{w}_j].$$

This vanishes, if $\mathbf{w}_j$ is an eigenvector of $\Sigma$ with eigenvalue $\lambda_j$ and the length of $\mathbf{w}_j$ is that

$$\frac{\sigma^{-2}\mathbf{w}_j}{\sigma^{-2}+\mathbf{w}_j^T\mathbf{w}_j} = \lambda_j,$

Using $\mathbf{w}_j = \lambda_j\mathbf{w}_j$, we arrive at $\mathbf{w}_j^T\mathbf{w}_j = \lambda_j$, or equivalently $\mathbf{w}_j^T\mathbf{w}_j = \lambda_j$; since $\Sigma$ has a set of mutually orthogonal eigenvectors this agrees with our assumption.

Figure 7.5 shows two-dimensional data and the principal component $\mathbf{w}_1$ is drawn as a red arrow with length $\sqrt{\lambda_1}\sigma^{-2}$ starting at the sample mean, where $\lambda_1$ is the length of the covariance matrix. In the following we will see that choosing the largest eigenvectors is the right choice to maximize the log likelihood.

Letting $\mathbf{w}_k, k=1, \dots, K$, be some eigenvectors of $\Sigma$ with squared length $\mathbf{w}_k^T\mathbf{w}_k = \lambda_k - \sigma^{-2}$ and inserting this into (7.4), we get

$$\|C| = |C_{-j}|(1+\sigma^{-2}(\lambda_j-\sigma^{-2})) = (\sigma^{-2})^{D-K}\prod_{k=1}^K |\lambda_k|^2\prod_{k=1}^K \lambda_k.$
