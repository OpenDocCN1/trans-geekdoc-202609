```
$p(v) = \sum_{z} p(v,z) = \sum_{z} p(v|z)p(z) =\sum_{k} p(v|z_k)p(z_k) = \sum_{k} \pi_k p_k(v). \quad (6.2)$
```

This is called a mixture distribution. The probabilities $\pi_k$ are known as *mixing coefficients*. For a given vector $v$, we can consider the probability that it was generated by process $k$. This is the conditional probability $p(z_k=1|v)$, whose value can be calculated using *Bayes' Rule*. This is given by

```
$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$
```

where $A$ and $B$ are events, and $P(A)$ and $P(B)$ are the probabilities of $A$ and $B$ without regard to each other, $P(A|B)$ is the *conditional probability* of $A$ given $B$ is true, and $P(B|A)$ is the conditional probability of $B$ given that $A$ is true. Applying Bayes' rule leads to

```
$p(z_k=1|v) = \frac{p(v|z_k)p(z_k)}{p(v)} = \frac{\pi_k p_k(v)}{p(v)}. \quad (6.3)$
```

We see that for particular $v$ the probability that it was generated by process $k$ is the mixing coefficient $\pi_k$, adjusted by the ratio of the probability $p_k(v)$ to the overall probability $p(v)$, $p(z_k=1|v)$ is known as the *responsibility process* $k$ for explaining the sample $v$. Using (6.2), we

```
$p(z_k=1|v) = \frac{\sum_{k} \pi_k p_k(v)}{p(v)}.$
```

Thus the responsibilities, i.e the probabilities of the processes generating a particular sample, sum to one. In particular, for the data samples $v_n, n=1,\dots,N$, we can now make assignments according to the values $p(z_k=1|v_n)$ for $k=1,\dots,K$. This is called *soft clustering*, since it is quantified by probabilities. It is possible that for a particular sample the probabilities are the same for two (or even more) values of $k$. These are samples which lie between clusters. Before we can however calculate any probabilities for cluster membership, we need to determine $\pi_k$ and $p_k(v)$ for $k=1,\dots,K$. To this we consider the joint likelihood of the data samples $v_1,\dots,v_m$ which is given by

```
$p(v_n) = \sum_{k=1}^{K} \pi_k p_k(v_n).$
```

We obtain values for $\pi_k$ and the parameters describing $p_k(\mathbf{v})$, by maximizing this likelihood, or alternatively its logarithm, known as the *log likelihood*

```
$$\mathcal{L} = \sum_{n=1}^N \log p_n(\mathbf{v}_n) = \sum_{n=1}^N \log \left( \sum_{k=1}^K \pi_k p_k(\mathbf{v}_n) \right) \quad (6.4)$$
```

When maximizing with respect to the mixing coefficients $\pi_k$, it is important to remember the constraint that they sum to one. This can be incorporated into the maximization problem using a *Lagrange multiplier* $\lambda$. That is, we maximize

```
$$\sum_{n=1}^N \sum_{k=1}^K \pi_k p_k(\mathbf{v}_n) + \lambda \left( \sum_{k=1}^K \pi_k - 1 \right) = 0$$
```

Differentiating with respect to $\pi_k$ and setting to zero gives

```
$$\sum_{n=1}^N \sum_{k=1}^K \pi_k p_k(\mathbf{v}_n) + \lambda = 0. \quad (6.5)$$
```

We first solve for $\lambda$ by multiplying through $\pi_k$ and summing over all $k$. The right hand side remains zero, while the left hand side becomes

```
$$\sum_{n=1}^N \sum_{k=1}^K \pi_k p_k(\mathbf{v}_n) + \sum_{k=1}^K \pi_k \lambda = N.$$
```

Hence, we have $\lambda = -N$. Inserting this into (6.5) and again multiplying by $\pi_k$, we have

```
$$0 = \sum_{n=1}^N \frac{\pi_k p_k(\mathbf{v}_n)}{\sum_{j=1}^K \pi_j p_j(\mathbf{v}_n)} - N\pi_k = \sum_{n=1}^N \frac{\pi_k p_k(\mathbf{v}_n)}{p(\mathbf{v}_n)} - N\pi_k$$
$$0 = \sum_{n=1}^N p(\hat{z}_{n,k}=1|\mathbf{v}_n) - N\pi_k,$$
```

We used Equation (6.3).

```
$$\pi_k = \frac{1}{N} \sum_{n=1}^N p(\hat{z}_{n,k}=1|\mathbf{v}_n) \quad (6.6)$$
```

Thus the mixing coefficient $\pi_k$ is the average responsibility that all data samples are generated by process $k$.

We need to emphasize here that the responsibilities $p(\hat{z}_{n,k}=1|\mathbf{v}_n)$ depend on $\pi_k$ itself. However, an iterative scheme can be derived from this, where the mixing coefficients $\pi_k$ and the parameters of the probabilities $p_k(\mathbf{v})$ are initially estimated, then the mixing coefficients are updated according to (6.6). The next step is to maximize with respect to the parameters. The method alternates between these two steps.

In the following sections, we will use different techniques of maximizing with respect to the parameters. A note of caution is however appropriate at this point, and this is in relation to outliers. Assume that $K=2$ and all data samples are roughly grouped together apart from outliers. In such cases, outliers can significantly shift the cluster means. If an outlier is far from both cluster centers, it may be assigned to the cluster with a higher probability, pulling that center towards itself. To mitigate this, one can use robust methods or simply identify and remove outliers before fitting the model.

### Gaussian Mixtures

It is common to use Gaussian distributions as the mixture components. In this case, the probability of a sample $v$ given process $k$ is given by:

$$p_k(v) = \frac{1}{\sqrt{(2\pi)^d |\Sigma_k|}} \exp\left(-\frac{1}{2}(v-\mu_k)^T \Sigma_k^{-1} (v-\mu_k)\right),$$

where $\mu_k$ is the mean vector and $\Sigma_k$ is the covariance matrix of cluster $k$. The mixture distribution is then:

$$p(v) = \sum_{k=1}^K \pi_k p_k(v).$$

The parameters to be estimated are now $\pi_k, \mu_k,$ and $\Sigma_k$ for $k=1,\dots,K$. The goal is to maximize the log-likelihood:

$$\mathcal{L}( \theta) = \sum_{n=1}^N \log \left( \sum_{k=1}^K \pi_k p_k(v_n | \mu_k, \Sigma_k) \right),$$

The standard algorithm for solving this is the Expectation-Maximization (EM) algorithm, which iteratively alternates between two steps:

1. **Expectation (E-step):** Calculate the responsibilities $p(z_{n,k}=1|v_n)$ using the current parameter estimates:
   $$\gamma_{nk} = \frac{\pi_k p_k(v_n | \mu_k, \Sigma_k)}{\sum_{j=1}^K \pi_j p_j(v_n | \mu_j, \Sigma_j)}$$

2. **Maximization (M-step):** Update the parameters by maximizing the expected log-likelihood:
   $$\pi_k = \frac{1}{N} \sum_{n=1}^N \gamma_{nk}$$
   $$\mu_k = \frac{\sum_{n=1}^N \gamma_{nk} v_n}{\sum_{n=1}^N \gamma_{nk}}$$
   $$\Sigma_k = \frac{\sum_{n=1}^N \gamma_{nk} (v_n - \mu_k)(v_n - \mu_k)^T}{\sum_{n=1}^N \gamma_{nk}}$$

The algorithm is repeated until the parameters converge.
