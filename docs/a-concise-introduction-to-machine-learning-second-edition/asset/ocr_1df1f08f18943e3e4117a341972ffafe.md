distribution. Then

```
$E_f[h] = \int h(x)f(x)dx = \int \frac{f(x)}{g(x)}g(x)dx\n$$E_g[hf/g] \approx \frac{1}{N} \sum_{n=1}^N f(\mathbf{x}_n)h(\mathbf{x}_n).
```

we used subscripts to indicate with respect to which probability density function expectation is taken. All generated samples, unlike rejection sampling, are used. The factors $f(\mathbf{x})/g(\mathbf{x})$ are known as importance weights. They are a correction to the wrong distribution. For example, if $g$ falls $f$ in a region, this factor is one and no correction is necessary. If however, $g$ is large in a region where $f$ is small, the contribution of evaluating $h$ needs to be reduced. On the other hand, if $g$ is small in a region where $f$ is large and we happen to sample there, the value of $h$ needs to be magnified.

In the case,

```
$f(\mathbf{x}) = \frac{1}{2}f(\mathbf{x}) \text{ and } g(\mathbf{x}) = \frac{1}{c_g}g$
```

and the normalizing constants

```
$c_f = \int f(\mathbf{x})dx \text{ and } c_g = \int g(\mathbf{x})dx$
```

we are unknown, the calculation becomes

```
$E_f[h] = \int h(\mathbf{x})f(\mathbf{x})dx = \frac{c_g}{c_f} \int \frac{f(\mathbf{x})}{g(\mathbf{x})}g(\mathbf{x})dx\n$$E_g[hf/g] \approx \frac{c_f}{c_g} \frac{1}{N} \sum_{n=1}^N f(\mathbf{x}_n)h(\mathbf{x}_n).
```

Even with the normalizing constants, we can estimate their ratio. Using $c_g = g(x)/g(x)$ where $g(x)$ is nonzero, we have

```
$\frac{c_f}{c_g} = \frac{1}{c_g} \int f(\mathbf{x})dx = E_g[f/g] \approx \frac{1}{N} \sum_{n=1}^N f(\mathbf{x}_n).
```

With this result, the expectation is estimated as

```
$E_f[h] = \frac{\frac{1}{N} \sum_{k=1}^N f(\mathbf{x}_k)h(\mathbf{x}_k)}{\frac{1}{N} \sum_{k=1}^N f(\mathbf{x}_k)}$
```

The importance weights are

```
$w_n = \frac{f(\mathbf{x}_n)/g(\mathbf{x}_n)}{\sum_{k=1}^N f(\mathbf{x}_k)/g(\mathbf{x}_k)} = \frac{\hat{f}(\mathbf{x}_n)/g(\mathbf{x}_n)}{\sum_{k=1}^N \hat{f}(\mathbf{x}_k)/g(\mathbf{x}_k)}, \quad (3.4)
```
