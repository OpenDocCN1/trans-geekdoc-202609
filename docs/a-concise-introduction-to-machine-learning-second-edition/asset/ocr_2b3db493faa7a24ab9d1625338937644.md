If the activation function in neurons is the logistic sigmoid, then the neural network is commonly known as multilayer perceptron. However, this is a misnomer, since the original perceptron uses the discontinuous step function as activation. In the section on backpropagation, we will see the advantages continuity brings. To add to the confusion, the term multilayer perceptron is now being used, when arbitrary architectures are employed, and for both classification or regression tasks. Because of this dilution of the definition, the form of the neural network cannot be deduced, the term perceptron is used.

The neural network is a function mapping the input $x = (x_1, \dots, x_D)^T$ to the output $y = (y_1, \dots, y_D)^T$. This mapping is a composition of functions with each layer being a linear function composed with an activation function. The number of layers can be hundreds or thousands giving rise to the deep learning. These many possibilities are powerful; however, there is a case for simplicity, because insight into the underlying processes can be gained.

The input passing through the network is known as forward propagation. Cycles, where information could be passed backwards, are not allowed. The architecture is strictly feed-forward.

As the latent variables can be relabeled, which means that neurons are exchanged with each other, there are $\prod_{M_l!}$ equivalent neural networks, which give the same mapping from input to output. Another equivalence arises from the activation functions of the hidden neurons being even, i.e. $h(-x) = h(x)$, or odd, i.e. $h(-x) = -h(x)$. If the weights of all synapses going into a particular hidden neuron are flipped, then the activation remains the same. On the other hand, if the activation is odd, flipping the sign for all synapses going out of this hidden neuron also keeps the same. If such flips are possible for all hidden neurons, then there are $\prod_{M_l!}$ equivalent neural networks. These are known as weight space symmetries.

Not all synapses need to be present. If the number of synapses is small, the network is known as sparse. Excluding certain synapses is a design decision. As are convolutional neural networks, if the weight of a synapse becomes zero during the learning process, that is, it does not contribute to the final output, this means that the information carried by this synapse is deemed unimportant. While the resulting mapping is the same excluding the synapse, one is by design, the other is determined from the data by learning. It is also possible for a synapse to stretch over two layers. This is known as a skip-connection.
