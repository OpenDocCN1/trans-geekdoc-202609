
If the variance is small, it indicates that at this model explains the data well. If the variance is large, the model is not adequate at this point. This can indicate that the dictionary of basis functions is unsuitable for this data and needs to be amended.

The most suitable values for the hyperparameters are found by maximizing the marginal likelihood $\mathcal{L}(\boldsymbol{\alpha}, \sigma^2)$ which is precisely the denominator of (8.5). Keeping the multiplicative constants (which were cancelled in the previous analysis), the marginal likelihood is:

$$\mathcal{L}(\boldsymbol{\alpha}, \sigma^2) = |A|^{1/2}(2\pi)^{-N/2}|\Sigma|^{1/2}\exp\left(-\frac{1}{2}\sigma^{-4}t^T t+\frac{1}{2}\boldsymbol{\mu}^T\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}\right)$$

We first consider the terms in the exponential. Inserting, (8.7), this becomes:

$$-[\sigma^{-2}t^T t-\boldsymbol{\mu}^T\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}] = -\frac{1}{2}[\sigma^{-6}t^T t-\sigma^{-4}t^T\boldsymbol{D}^T\boldsymbol{\Sigma}^{-1}\boldsymbol{D}t] = -\frac{1}{2}[\sigma^{-4}(\sigma^2)^{-1}-\sigma^{-2}(\boldsymbol{D}^T\boldsymbol{\Sigma}^{-1}\boldsymbol{D})^{-1}]t$$

where $I$ is the $N \times N$ identity matrix. Writing $\boldsymbol{\Sigma}$ as $(A+\boldsymbol{D}^T\sigma^2I^{-1}D)^{-1}$ and using the *Woodbury identity* in A.1.3, this simplifies to:

$$-\frac{1}{2}t^T(\sigma^2I+\boldsymbol{D}^T\boldsymbol{D})^{-1}t.$$

Hence the mean of the marginal likelihood is zero and its covariance matrix is:

$$\boldsymbol{C} = \sigma^2I+\boldsymbol{D}^T\boldsymbol{D}.$$

We need to check whether the multiplicative constants agree with this. To this end,

$$|\boldsymbol{\Sigma}| = |\boldsymbol{\Sigma}^{-1}|^{-1}=|A+\boldsymbol{D}^T(\sigma^2I)^{-1}\boldsymbol{D}|^{-1}.$$

Using the *matrix determinant lemma* from A.1.5, we get:

$$|\boldsymbol{\Sigma}|=|\sigma^2I+\boldsymbol{D}^T\boldsymbol{D})^{-1}|\sigma^{-2}|\boldsymbol{C}|=|\boldsymbol{C}|^{-1}|(\sigma^2)^N.$$

Combining this result with the other multiplicative constants, we see:

$$\mathcal{L}(\boldsymbol{\alpha}, \sigma^2) = (2\pi)^{-N/2}|\boldsymbol{C}|^{-1/2}\exp\left(-\frac{1}{2}t^T\boldsymbol{C}^{-1}t\right).$$

Instead of maximizing this, we maximize the logarithm of the marginal likelihood, in the following, the *log evidence*. We will denote this *objective function* by:

$$\mathcal{L}(\boldsymbol{\alpha}) =-\frac{1}{2}(N\log 2\pi + \log |\boldsymbol{C}| + t^T\boldsymbol{C}^{-1}t). \quad (8.8)$$

We want to maximize this function with respect to the hyperparameters $\alpha$. To this end, we separate the contribution of a single hyperparameter out. First note that since **A** is a diagonal matrix, **C** can be rewritten as:

$$C = \sigma^2 I + \sum_{m=1}^{M} \frac{1}{\alpha_m} d_m d_m^T$$

Let:

$$C_{-i} = \sigma^2 I + \sum_{m \neq i}^{M} \frac{1}{\alpha_m} d_m d_m^T = C - \frac{1}{\alpha_i} d_i d_i^T$$

and $\alpha_{-i} = (\alpha_1,\dots,\alpha_{i-1},\alpha_{i+1},\dots,\alpha_M)^T$. Using the Sherman-Morrison formula in A.1.4, we have:

$$C_{-i}^{-1} = C^{-1} - \frac{C^{-1} d_i d_i^T C^{-1}}{\alpha_i + d_i^T C^{-1} d_i}$$

The matrix determinant lemma in A.1.5 on the other hand gives:

$$|C| = |C_{-i}| (\alpha_i + d_i^T C_{-i}^{-1} d_i) \frac{1}{\alpha_i}$$

Combining these two, we can write:

$$\mathcal{L}(\alpha) = \frac{1}{2}(N\log(2) + \log|C_{-i}| + t^T C_{-i}^{-1} t) - \alpha_i \log \alpha_i - \frac{t^T C_{-i}^{-1} d_i d_i^T C_{-i}^{-1} t}{\alpha_i + d_i^T C_{-i}^{-1} d_i} = \mathcal{L}(\alpha_{-i}) + \frac{1}{2}\frac{\log|\alpha_i| - \log(\alpha_i + d_i^T C_{-i}^{-1} d_i)}{\alpha_i + d_i^T C_{-i}^{-1} d_i} + \frac{(d_i^T C_{-i}^{-1} t)^2}{\alpha_i + d_i^T C_{-i}^{-1} d_i} = \mathcal{L}(\alpha_{-i}) + \ell(\alpha_{-i})$$

We have separated the dependencies on $\alpha_i$ into $\ell(\alpha_{-i})$, while $\mathcal{L}(\alpha_{-i})$ contains the portion of the log independent of $\alpha_i$.

We define the quantities:

$$s_i = d_i^T C_{-i}^{-1} d_i \text{ and } q_i = d_i^T C_{-i}^{-1} t,$$

which are independent of $\alpha_i$. With this definition:

$$\ell(\alpha_i) = \frac{1}{2}\frac{1}{\alpha_i} \log(\alpha_i + s_i) + \frac{q_i^2}{\alpha_i + s_i}$$

The derivative of the log with respect to $\alpha_i$ is given:

$$\frac{\partial\ell(\alpha_i)}{\partial\alpha_i} = \frac{1}{2}\frac{-1}{\alpha_i^2} \log(\alpha_i + s_i) + \frac{1}{2}\frac{1}{\alpha_i}\frac{1}{\alpha_i + s_i} - \frac{q_i^2}{(\alpha_i + s_i)^2} = \frac{1}{2}(\alpha_i + s_i)^{-2} (s_i - q_i^2), \quad (8.9)$$

$\mathcal{L}(\alpha_{-i})$ is independent of $\alpha_i$.

Figure 10: $\ell(\alpha_i)$.
(a) $s_i - q_i^2 \geq 0$. (b) $s_i - q_i^2 < 0$.

If $s_i - q_i^2$ is nonnegative, then the derivative is always positive since $\alpha_i$ is positive. This means $\ell(\alpha_i)$ is monotonically increasing. On the other hand $s_i - q_i^2$ is negative, then equation (8.9) vanishes for:

$$\alpha_i = \frac{s_i^2}{s_i - q_i^2}, \quad (8.10)$$

where $\ell(\alpha_i)$ has a maximum. Figure 10 illustrates these two cases. Setting $\alpha_i = \infty$ in the first case and adjusting $\alpha_i$ to the value given in (8.10) in the second case increases the logarithm of the marginal likelihood. For $\alpha_i = \infty$, the probability density function for $d_i$ becomes infinitely peaked at zero. In practice, this means that $d_i$ is regarded as not contributing to the data and therefore can be excluded from the model. This sparsity is known as the *Relevance Vector Machine* (RVM).

To avoid many different matrices, it is convenient to define:

$$Q_i = d_i^T C^{-1}$$
$$S_i = d_i^T C^{-1} d_i.$$

For infinite $\alpha_i$, we have $q_i = Q_i$ and $s_i = S_i$, since in this case $C = C_{-i}$. While finite $\alpha_i$:

$$s_i = S_i + \frac{S_i^2}{\alpha_i + S_i} = \frac{\alpha_i S_i}{\alpha_i + S_i}.$$

Similarly,

$$q_i = \frac{\alpha_i Q_i}{\alpha_i + S_i}$$

Let's examine $D_i$ more closely. The matrices $\Sigma$ and $C$ are related via the Woodbury identity in A.1.3:

$$C^{-1} = (\sigma^2I+D\sigma^2D^T)^{-1} = \sigma^{-2}I - \sigma^{-2}D(I+\sigma^2D^T^2D)^{-1}D^T\sigma^{-2} = \sigma^{-2}(I - D\Sigma D^T)$$

Using this and (8.7):

$$C^{-1}t = \sigma^{-2}(t - \mu).$$

However, the mean of our predictive probability distribution for $t, C^{-1}t$ gives the difference between the target and the mean for each sample scaled by the noise. If this is small, our current model is adequate to explain the data. If not, we consider $C^{-1}t$ as an error which needs to be removed. Calculating $\alpha_i = d_i^T C^{-1}$ checks how well aligned $d_i$ is; if it is well aligned, or orthogonal, then $d_i$ will not help in removing this error. If it is well aligned, then the inclusion of $d_i$ in the model will be beneficial. Therefore $Q_i$ is the *quality factor*.

$S_i$, on the other hand is known as sparsity factor; as we will see below, it helps evaluate how collinear $d_i$ is to the other basis functions. The quantity $s_i$ is a penalty associated with the basis function $d_i$. It quantifies how well $d_i$ could be modeled by the other basis functions. On the other hand, $q_i$ is a quality term, measuring how well $d_i$ would contribute to explaining the data using the current model. Both $s_i$ and $q_i$ depend on $C^{-1}$, which in turn depends on $\alpha_*$. Thus the optimal value for $\alpha_i$ changes as the other hyperparameters $\alpha_*$ are adjusted.

The possibility to adjust hyperparameters in turn gives rise to the following algorithm which initializes the model with a single function and its optimal parameter value, and sets the hyperparameters of the other basis functions to infinity. At the start of the algorithm when only one function is in the model, $D$ has only one column, and $\Sigma$ is a $1\times1$ matrix. $\Sigma$ is the variance of that single function evaluated at the points with itself. Its inverse is easily calculated using the Sherman-Morrison formula from A.1.4. Then the basis function $d_i(x)$, setting its hyper-parameter $\alpha_i$ to its optimal value (given the current model), gives the largest increase in the marginal likelihood, is found and the model is updated accordingly.

The algorithm converges, if no significant increase in the logarithm of the marginal likelihood can be achieved anymore. Since the optimal value of $\alpha_i$ can be finite or infinite, there are three different possible updates. If $d_i(x)$ is not in the model and the optimal $\alpha_i$ is finite, it gets added to the model. If $d_i(x)$ is in the model and the optimal $\alpha_i$ is infinite, it is deleted from the model.
