A $2 \times 1$ matrix is a $2 \times 2$ matrix. The outer product is the simplest form of a *tensor product*. The use of tensors in Machine Learning is different from the use of tensors in, for example, physics. This text will continue with the use of matrices.

If $M$ is the number of features (in which example $M=2$), then $\mu_i$ is a vector with $M$ elements and the $j^{th}$ entry is the $j^{th}$ feature of samples in class $C_i$. On the other hand, $\Sigma$ is an $M \times M$ matrix. The $(j, j)$ diagonal entry is the variance of the $j^{th}$ feature of samples in class $C_i$. The variance describes how spread the values of feature are are. The $(j, k)$ off-diagonal entry is the covariance between the $j^{th}$ and $k^{th}$ feature of samples in class $C_i$. The covariance describes how much different features influence each other.
