The expectation is calculated as

```
E[x] = \int_{0}^{1} x \text{Beta}(x|\alpha,\beta)dx = \frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)} \int_{0}^{1} x^{\alpha}(1-x)^{\beta-1}dx\n= \frac{\Gamma(\alpha+1)\Gamma(\beta)}{\Gamma(\alpha+\beta+1)} \int_{0}^{1} \text{Beta}(x|\alpha+1,\beta)dx\n= \frac{\alpha}{\alpha+\beta}.
```

where we used the property given in 2.14 of the gamma function and the fact that the integral of any probability density function over its range is one. The variance is given

```
var[x] = \frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}
```

When $\alpha=eta$, the expectation is always $1/2$, while the variance is $(4(2\alpha+1))^{-1}$. Therefore, the graphs of the probability density function for these values are symmetric about $1/2$, while the graphs of the cumulative distribution function in Figure 2.20 pass through $(1/2, 1/2)$.

+   - The Beta distribution can be viewed as the distribution over the probabilities of experiments with binary outcomes, where $x$ is the probability of success and $1-x$ the probability of failure. If $x$ has the distribution $\textBeta}(x|\alpha,\beta)$, then $1-x$ has the distribution $\textBeta}(1-x|\beta,\alpha)$.
