 calculate the covariance matrix for a specific kernel.

```
% Constant kernel.
function k = Constant(x,y,param)
k = param*2 + ones(size(x,1),size(y,1));
```

```
% Linear kernel.
function k = linear(x,y,params)
% The matrix of the inner products of each row of x and each row of y
 is given by x*y'.
k = params(1)*2 + params(2)*x*y';
```

```
% Quadratic kernel.
function k = quadratic(x,y,params)
k = (params(1)*2 + params(2)*x*y')^2;
```

```
% Gaussian kernel.
function k = gaussian(x,y,params)
% Calculate squared distance as the sum of the inner product of one
 row of x with itself and one of y with itself twice the
% inner product of these two rows.
sd = repmat(dot(x,x),size(y,1),1) + 
remat(dot(y,y),1,size(x,1)) - 2*repmat(dot(x,y'),size(y,1),1);
k = params(1)*exp(-sd/(2*params(2))^2));
```
