Without loss of generality, we can ensure ||**Dz** = 1, since regressors are invariant to scaling.

Recall that **t** is the target. The matrix **$\mathbf{D^	op t t^	op D}$** is a symmetric, positive semi-definite $M 	imes M$ matrix, since

```
$|\mathbf{D^	op t t^	op D}|| = \frac{1}{||t||^2} z^	op D^	op t t^	op D \text{ and the new regressor } v^	op D^	op t t^	op D v = (v^	op D^	op t)^2 \geq 0 0.$
```

It has M nonnegative eigenvalues and corresponding orthonormal eigenvectors $\mathbf{v}_1, \dots, \mathbf{v}_M$, where the eigenvectors are ordered with regards to the eigenvalues from largest to smallest.

We set $\mathbf{z} \in \mathbb{R}^M$ and thus can be expressed as a linear combination of eigenvectors: $\mathbf{z} = z_1\mathbf{v}_1 + \dots + z_M\mathbf{v}_M$.

```
$\frac{||\mathbf{t^	op Dz}||}{||\mathbf{Dz}||^2} = \frac{1}{||t||^2} z^	op D^	op t t^	op D \mathbf{z} = \frac{1}{||t||^2}(\lambda_1\mathbf{v}_1 + \dots + \lambda_M\mathbf{v}_M).
```

This is may for $z_2 = \dots = z_M = 0$, since the length of $z$ is fixed by the condition $[||\mathbf{Dz}|| = 1]$ and $\lambda_1$ is the largest eigenvalue. We choose the normalized mapping of the eigenvector with the largest eigenvalue as the new regressor $\mathbf{w}_1 = \mathbf{Dv}/||\mathbf{Dv}||$. We know that $\mathbf{Dw}_1 \neq 0$, otherwise $\mathbf{D^	op t}$ would only have two eigenvalues.

Having weighted, we calculate

```
$$\mathbf{D}_1 = (\mathbf{I} - \mathbf{w}_1\mathbf{w}_1^	op)$$
```

Note

```
$$\mathbf{D}_1\mathbf{v}_1 = (\mathbf{I} - \mathbf{w}_1\mathbf{w}_1^	op)\mathbf{Dv}_1 = (\mathbf{I} - \mathbf{w}_1\mathbf{w}_1^	op)\mathbf{w}_1 = \mathbf{w}_1(1 - ||\mathbf{w}_1||^2)\mathbf{w}_1 = 0.$
```

This implies that the rank of $\mathbf{D}_1$ is less than the rank of $\mathbf{D}$, because a vector $(\mathbf{v}_1)$ which previously was not mapped to zero, is now mapped to zero.

Now let $|\mathbf{v}_2|| = 1$ be the eigenvector corresponding to the largest eigenvalue of $\mathbf{D^	op t D}$. The new regressor is $\mathbf{w}_2 = \mathbf{D}_1\mathbf{v}_2$ normalized such that $||\mathbf{w}_2|| = 1$. Again, the correlation remains

Next

```
$$\mathbf{D}_2 = (\mathbf{I} - \mathbf{w}_2\mathbf{w}_2^	op)\mathbf{D}_1.$
```

and the process continues until $\mathbf{D}_j$ is a null matrix, i.e. its rank is zero. $\mathbf{D}_j$ maps $\mathbf{v}_j$ to zero, nonzero, $\mathbf{v}_j$ is the eigenvector corresponding to the largest eigenvalue of $\mathbf{D}_{j-1}^	op t \mathbf{D}_{j-1}$. Hence rank($\mathbf{D}_{j-1}$) $\leq$ rank($\mathbf{D}_j$)

PLS can be used for multivariate regression, that is the regressand has multiple components and measuring at $\mathbf{x}_1, \dots, \mathbf{x}_N$ gives rise to a matrix $\mathbf{t}$ with $N$ rows and each column represents one component. However, this is beyond this text. Haenlein & Kaplan (2004) give more insight.
