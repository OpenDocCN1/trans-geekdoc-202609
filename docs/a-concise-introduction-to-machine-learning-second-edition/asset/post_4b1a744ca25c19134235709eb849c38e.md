Summing this over all samples and dividing by N gives the average squared distance by which a sample is moved, when restricting the representation to the principal subspace,

```
\sum_{n=1}^N \sum_{d=K+1}^D (v_n^T w_d)^2 = \sum_{d=K+1}^D w_d^2 \left( \frac{1}{N} \sum_{n=1}^N v_n^T v_n \right)
= \sum_{d=K+1}^D w_d^T (S + \mu\mu^T) w_d
\= \sum_{d=K+1}^D \lambda_d d + \sum_{d=K+1}^D (\mu^T w_d)^2
```

where we used Equation (2.10) as an alternative calculation of the covariance matrix. The first part is the sum over the D - K smallest eigenvalues of $\Sigma$, while the second part is the squared distance between the mean and its projection. As more eigenvectors are used as principal components, the average-squared distance between samples and their projection becomes smaller. This means the reconstructions become more accurate. We will revisit this, when covering principal component regression in Section 8.8.

The eigenvalues and eigenvectors of $\Sigma$ can be used to perform a technique as whitening or sphering the data. This transforms the data to a different feature space where the samples have zero mean and the covariance is the identity matrix. If measurements of features differ in magnitude or the variability is disparate, this can become necessary. However, after such a transformation, Principal Component Analysis and any other technique which relies on distinct eigenvectors of the covariance matrix are no longer applicable. After whitening the transformed value for $v_n$,

```
v_n = \Lambda^{-1/2}W^T(x_n - \mu)
```

where $W$ is the orthogonal matrix formed from the eigenvectors $w_d$ and $\Lambda^{-1/2}$ is the matrix with $\lambda_d$ on the diagonal. This is well-defined if $\Sigma$ has no zeros, which is the case if the samples are distinct and $N > D$. On the other hand, the covariance matrix of the transformed data is

```
\sum_{n=1}^N v_n v_n^T = \sum_{n=1}^N \Lambda^{-1/2}W^T(x_n - \mu)(x_n - \mu)^T W\Lambda^{-1/2}
```

All this relies on stable and efficient methods to find eigenvalues and eigenvectors. Faul (2016) describes some examples. It is important to keep the dimensionality and size of dataset in mind. To illustrate this,

```
p(u_k) = \pi(exp(-u_k)).
```

This distribution has a much larger kurtosis than the normal distribution, often displayed in real-world applications. Hyvärinen et al. (2001) give a thorough treatment of ICA. In this text, however, we continue to assume $u$ has a normal distribution. The linear transformation of a normally distributed variable is also normally distributed with matrix $WW^T + \sigma^2 I$. Since $\Sigma$ is symmetric, it can be diagonalized by a $K \times K$ orthogonal matrix $Q$ such that $\Sigma = QDQ^T$, where $D$ is a diagonal matrix with positive entries. If $\Sigma$ had an eigenvalue 0, the dimension of the space $u$ could be reduced further, because alone loses information. The covariance matrix can then be written as $[W^{1/2}(W^T)^{1/2}]$. Thus we can assume without loss of generality $S=I$, since this assumption results in a different $W$. Since orthogonality is preserved when multiplying by an orthogonal matrix, we continue to assume that the columns of $W$ are orthogonal. The multiplication by $D^{1/2}$ only results in a scaling and thus the columns of $W$ remain orthogonal. Equally, we can assume zero mean for $u$, since no nonzero mean can be absorbed in $m$.

```
$$\mathbf{v} \sim \mathcal{N}(\mathbf{m}, WW^T + \sigma^2 I).$$
```

Let $\mathbf{C} = WW^T + \sigma^2 I$. The likelihood of the dataset $\mathcal{D} = \{\mathbf{v}_1, \dots, \mathbf{v}_N\}$ is given

```
$$\prod_{n=1}^N \frac{1}{\sqrt{2\pi|\mathbf{C}|}} \exp\left(-\frac{1}{2}(\mathbf{v}_n - \mathbf{m})^T\mathbf{C}^{-1}(\mathbf{v}_n - \mathbf{m})\right).$$
```

```
$$\mathcal{L} = -\frac{ND}{2}\log(2\pi) - \frac{N}{2}\log|\mathbf{C}| - \sum_{n=1}^N (\mathbf{v}_n - \mathbf{m})^T\mathbf{C}^{-1}(\mathbf{v}_n - \mathbf{m}).$$
```

Using A.2.3, the derivative with respect to $\mathbf{m}$ is

```
$$\frac{\partial}{\partial\mathbf{m}}\mathcal{L} = \sum_{n=1}^N \mathbf{C}^{-1}(\mathbf{v}_n - \mathbf{m}) = \mathbf{C}^{-1}\left[\sum_{n=1}^N (\mathbf{v}_n - \mathbf{m})\right].$$
```

This can be only zero, if

```
$$\mathbf{m} = \frac{1}{N}\sum_{n=1}^N \mathbf{v}_n = \mathbf{\mu}.$$
```

Hence, the sample mean $\mathbf{\mu}$ is the Maximum-Likelihood Estimate for $\mathbf{m}$ and we insert this into the expression for $\mathcal{L}$.

Now $(\mathbf{v}_n - \mu)^T \mathbf{C}^{-1}(\mathbf{v}_n - \mu)$ is scalar and therefore equal to its trace. A trace of three-term product is invariant to cyclic permutations. Therefore,

```
$$\mathcal{L} = -\frac{ND}{2}\log(2\pi) - \frac{N}{2}\log|\mathbf{C}| - \sum_{n=1}^N (\mathbf{v}_n - \mu)^T\mathbf{C}^{-1}(\mathbf{v}_n - \mu).$$
```
