# # Exercises

**Exercise 2.1.** *A dataset of whole numbers $\mathcal{D} = \{x_1, \dots, x_N\}$ describes how often an event occurred in $N$ time intervals. We want to fit a Poisson distribution with probability mass function as given in Equation 2.8 with rate parameter $\lambda > 0$. Show that the MLE is*

$$\lambda = \frac{1}{N} \sum_{n=1}^{N} x_n.$

**Exercise 2.2.** *The dataset $\mathcal{D} = \{13, 9, 11, 24, 7, 2\}$ is given. Use numerical optimization to find the MLE iteratively.*

**Exercise 2.3.** *The dataset $\mathcal{D} = \{x_1, \dots, x_K\}$ is given. We want to fit a uniform distribution with probability density function as given in Equation 2.4 on the interval $[a, b]$. It is already known that $a = 0$. Show that the MLE for $b$ is $max_{k=1,...,K}$.*

**Exercise 2.4.** *Imagine there is a set of frogs whose populations live near each other. Let $x_1, \dots, x_K$ be the sizes of each population. In all populations, there is always a certain number of frogs with particularly small mouths. $y_1, \dots, y_K$ be the number of frogs in each population. We assume that $y_k$ follows a Poisson distribution: $y_k \sim Po(\lambda_k)$. Find the MLE for the parameter $\lambda$.*

**Exercise 2.5.** *A dataset $\mathcal{D} = \{x_1, \dots, x_K\}$ of real numbers is given. They are independent samples from a normal distribution $N(\mu, \sigma^2)$, where $\sigma$ is known, but $\mu$ is not known. A prior distribution $N(\mu_0, \sigma_0)$ for $\mu$ is given with known $\mu_0$ and $\sigma_0$. Show that the posterior distribution is proportional to*

$$\exp(- \frac{(\mu-\nu)^2}{2\tau^2})$

*and find expressions for $\nu$ and $\tau$ in terms of $\sigma, \mu_0, \sigma_0$, and \mathcal{D}$. You will need to use the technique demonstrated in Equation 2.11. With a suitable normalizing constant the posterior distribution is $N(\nu, \tau^2)$.*
