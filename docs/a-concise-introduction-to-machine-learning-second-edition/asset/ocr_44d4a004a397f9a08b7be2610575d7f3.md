```
$$p(\mathbf{x}_n) = \sum_{\mathbf{x}_{n-1}} p(\mathbf{x}_n|\mathbf{x}_{n-1})p(\mathbf{x}_{n-1}) \quad \text{or} \quad p(\mathbf{x}_n) = \int p(\mathbf{x}_n|\mathbf{x}_{n-1})d\mathbf{x}_{n-1}.$$
```

To do so the marginal probability of $\mathbf{x}_{n-1}$ needs to be known. Starting from the initial distribution $p(\mathbf{x}_1)$, all distributions can be calculated.

For a homogeneous Markov chain, the transition probabilities can be completely described by noting how $T$ acts on different elements of the state space, $T(\mathbf{x})$ for all states $\mathbf{x}$ and $\mathbf{\mathbf{x}}$.
nA Markov chain is called *irreducible*, if the probability of reaching state $\mathbf{x}$ from state $\mathbf{x}$ in a finite number of steps is nonzero for all states $\mathbf{x}$ and $\mathbf{\mathbf{x}}$. In other words, any state can be reached from any other state in a finite number of steps.

A distribution specified by the probability mass density function $f$ is called *invariant* or *stationary* with respect to the Markov chain, if $\mathbf{x}_{n-1}$ follows the distribution, then so does $\mathbf{x}_n$ for all $n$. In other words, if $f$ follows the distribution, then so does the complete chain. The distribution remains invariant with respect to a given Markov chain after each step. For example, in the degenerate case where

```
$$T(\mathbf{x},\mathbf{x}) = \begin{cases} 1 & \text{if } \mathbf{x} = \mathbf{x}, \ 0 & \text{otherwise}, \end{cases}$$$$
```

we have $\mathbf{x}_1 = \mathbf{x}_2 = \cdots = \mathbf{x}_N$. The transformation in each step is the identity.
in this case, any distribution is invariant.
For a homogeneous Markov chain, a distribution specified by $f$ is invariant,

```
$$f(\mathbf{x}) = \sum_{\mathbf{x}} T(\mathbf{x},\mathbf{x})f(\mathbf{x}) \quad \text{or} \quad f(\mathbf{x}) = \int_{\mathbf{x}} T(\mathbf{x},\mathbf{x})f(\mathbf{x})d\mathbf{x}.$$
```

where the sum or integral is over the state space.
is is possible to construct a Markov chain with transition probabilities that a given $f$ is invariant. To achieve this, the transition probabilities need to satisfy the property of *detailed balance*, for all pairs of states $\mathbf{x}$ and $\mathbf{\mathbf{x}}$.

```
$$T(\mathbf{x},\mathbf{y})f(\mathbf{y}) = T(\mathbf{y},\mathbf{x})f(\mathbf{x}).$$
```

Note that for $\mathbf{x} = \mathbf{x}$, the above equation is naturally true. If detailed balance is satisfied, the Markov chain is *reversible*. Invariance is shown by

```
$$$\sum_{\mathbf{x}} T(\mathbf{x},\mathbf{y})f(\mathbf{x}) = \sum_{\mathbf{x}} T(\mathbf{y},\mathbf{x})f(\mathbf{x}) = f(\mathbf{y}).$$
```
