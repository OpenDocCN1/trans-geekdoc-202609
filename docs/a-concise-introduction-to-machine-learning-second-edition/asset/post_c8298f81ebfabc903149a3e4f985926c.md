Comparing the graphs of the GDI, deviance and node error, nodes where the classes have similar parity are considered as more impure under GDI and deviance than under the node error. This has the effect that the node error does not result in a preference to create purer child nodes. To see this,

```
$$\Delta I = (1 - \max p_{PK}) \frac{N_L}{N_P} - (1 - \max p_{Lk}) \frac{N_{Lk}}{N_L} - (1 - \max p_{Rk}) \frac{N_R}{N_P} - (1 - \max p_{Rk}) \frac{N_{Rk}}{N_R})$$\n$= 1 - \max \frac{N_{Pk}}{N_P} - \max \frac{N_{Lk}}{N_P} + \max \frac{N_{Lk}}{N_L} - \max \frac{N_R}{N_P} - \max \frac{N_{Rk}}{N_R}$$\n$= \frac{1}{N_P}(\max N_{Lk} + N_{Rk} - \max N_{Pk})$$
```

where used $N_L + N_R = N_P$. The impurity is solely dependent on the number of the largest classes in the child nodes. This number can be kept constant for different splits, the purity of the child nodes is very different. Breiman et al. (1984) give a number example: Suppose there are two classes and the parent node have equal parity, $N_{P1} = N_{P2} = 400$. One possible split is $N_{L1} = 100, N_{L2} = 200, N_{R1} = 200, N_{R2} = 100$. Both splits result in $\Delta I = (600-400)/800 = 1/4$. However, the second split is preferable, because it split along a horizontal and thus a leaf. For the first split, child nodes are impure and need to be split.

Figure 5.10 shows our previous example where the region this is classified by a decision tree. Figure 5.11 displays the corresponding decision tree. Each node represents a split of a region. The first node splits the entire region along a vertical line at 2.5. It is advantageous in this example, one class is completely to the left of the other classes resulting in a pure node by split along a vertical line. The region to the right of this line is split along a horizontal line. The last node splits the region below this line and to the right of the first line vertically at 4.95. It can be seen that this decision tree could be improved by levelling the horizontal split slightly lower, at 1.65. This would result in the one misclassified virginica sample being classified correctly.

The depth of decision trees is controlled by three parameters:

- The number of allowed branch nodes.
- The minimum number of samples needed in a node which is split.
- The minimum number of samples per leaf.

In the example of Figure 5.10 the minimum number of samples in a leaf node was set to 2. Setting it to one, results in one further split. In fact, the last region split horizontally horizontally 1.65 which results in the misclassified virginica sample being classified correctly. This increases the depth of the decision tree. If the depth of a decision tree is not controlled, it generalizes well less to unseen data, since it is too closely fitted to the training data.

## 5.5 Neural Networks

It was already mentioned that the perceptron is in fact a simple, single layer neural network. In the following, we describe neural networks more generally. Neural networks are large systems characterized by linear and non-linear, distributed, parallel and local processing. A neural network consists of neurons known as nodes and synapses connecting the neurons. The neurons are organized into three types:

- Each feature is an input neuron.
- Hidden: Each Neuron is a (possibly complex) mathematical function creating a predictor.
- Output: The neurons gather the predictions and produce the final result.

The synapses not only connect neurons, but also store weights.

An example we consider with two features, $v_1$ and $v_2$. Recall that the perceptron classifies according to $sgn(\mathbf{w}^T\mathbf{v})$ in Equation 4.3. The corresponding neural network is ![](img/c6c76bf52016db7e78a5e30d4766ef81_161_0.png)

Note that the bias is implemented as the weight of a synapse connecting a dummy input neuron which always has the value.

There are some differences in what is considered a layer in the neural network literature. Sometimes, each set of hidden neurons is considered a layer. In this context, the above has no layers. Sometimes, the sets of input and output neurons as well as the sets of hidden neurons are counted as layers. Then the above is a two layer neural network. However, of importance are the weights of the synapses. We therefore follow the convention that a layer is the connections between two sets of neurons. With this definition, the above is a single neural network. The weights are updated by the chosen learning process. We will not go into specific learning processes in this chapter, but leave this to [Chapter 9] on feature learning where we revisit neural networks.

The output neuron

```
$$\sgn(w_1v_1 + w_2v_2 - b) = sgn(\mathbf{w}^T\mathbf{v})$$
```

consists of two elements:

- The **propagation function** given by $\mathbf{w}^T\mathbf{v}$, which passes the information in a manner wanted to the next neuron.
- The **activation function**, also called *transfer function*

$h(z) = \sgn(z).$

The propagation function maps the output from one layer to another vector space which can be smaller or larger in dimension depending on whether the number of neurons in the next layer is smaller or larger than the previous layer.
