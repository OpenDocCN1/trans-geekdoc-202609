```
$$\mathcal{L}(t\mathbf{D}, \alpha, \sigma^2) = \int p(t,\mathbf{D},\mathbf{c}|\alpha, \sigma^2)dc\mathbf{c}$$

which we aim to maximize. The Maximum-Likelihood Estimate for **$\alpha$** are the values which maximize $\mathcal{L}(t\mathbf{D}, \alpha, \sigma^2)$. In the following section we revisit a technique to find a maximum.

## 8.12 Expectation–Maximization

In the following we suppress the dependency of the model on the design matrix **D**. The *Expectation-Maximization (EM)* algorithm arrives at a maximum iteratively alternating between two steps. The derivation requires some expansion.

By the *chain rule*, also known as the *product rule*, we have

```
$p(t,\mathbf{c},\sigma^2) = p(t,\mathbf{c}|\alpha, \sigma^2)p(\mathbf{c}|\alpha, \sigma^2)$
```

Taking the logarithm on both sides results in

```
$log p(t,\mathbf{c},\sigma^2) = \log p(t,\mathbf{c}|\alpha, \sigma^2) + \log p(\mathbf{c}|\alpha, \sigma^2)$
```

Both sides can be viewed as functions of the random variable **c** and we can take the expectation with regards to any distribution $q(\mathbf{c})$

```
$$\int q(\mathbf{c}) \log p(t,\mathbf{c},\sigma^2)dc\mathbf{c} = \int q(\mathbf{c}) \log p(t,\mathbf{c}|\alpha, \sigma^2)dc\mathbf{c}$$
$$+ \int q(\mathbf{c}) \log p(t|\mathbf{c},\alpha, \sigma^2)dc\mathbf{c}$$
$$= \int q(\mathbf{c}) \log p(t,\mathbf{c}|\alpha, \sigma^2)dc\mathbf{c}$$
```

since $q(\mathbf{c})dc = 1$. Rearranging gives

```
$$\log p(t,\alpha, \sigma^2) = \mathcal{L}(t\alpha, \sigma^2) = \int q(\mathbf{c}) \log p(t,\mathbf{c}|\alpha, \sigma^2)dc\mathbf{c}$$
$$- \int q(\mathbf{c}) \log p(t,\mathbf{c}|\alpha, \sigma^2)dc\mathbf{c}$$
```

We can subtract and add the term $q(\mathbf{c})\log q(\mathbf{c})$ on the right hand side and arrive at

```
$$\log \mathcal{L}(t\alpha, \sigma^2) = \int q(\mathbf{c}) \log \frac{p(t,\mathbf{c}|\alpha, \sigma^2)}{q(\mathbf{c})}dc\mathbf{c} - \int q(\mathbf{c}) \log \frac{q(\mathbf{c})}{q(\mathbf{c})}dc\mathbf{c} (8.4)$$
```

using the properties of the logarithm. $\mathcal{L}(t\alpha, \sigma^2)$ is also known as the *log likelihood* or *log evidence*.

The second term (including the minus sign) is the Kullback-Leibler divergence (KL divergence) between the distribution q(c) and the posterior distribution p(c|t, α, σ²). It is also known as the discrimination information, information divergence and information gain, since information is obtained from observing t. For two probability density functions p and q, the KL divergence is defined as

```
$D_{KL}(p||q) = - \int p(x) \log \frac{q(x)}{p(x)} dx = \mathbb{E}_p [ -log \frac{q(x)}{p(x)} ]$
```

$\mathbb{E}_p$ denotes the expectation with respect to the distribution p. Using Jensen's inequality,

```
$D_{KL}(p||q) \geq - \mathbb{E}_p [ \log \frac{q(x)}{p(x)} ] = - \int p(x) \log \frac{q(x)}{p(x)} dx = - \int q(x) dx = 0$
```

since log 1 = 0 (Bishop (2006)) gives more details of the proof. Hence the KL divergence is always positive, zero and only if p(c|t, α, σ²) = q(c) almost everywhere.

Therefore, the first term in (8.4),

```
$\int \frac{p(t, c | α, \sigma²)}{q(c)} dc$
```

is a lower bound for log L(t|α, σ²). The maximization is done by maximizing the lower bound by alternating maximum with respect to q(c) and respect to α.

Let α^k be the current estimate of the maximal α. The lower bound is maximal in the sense that it touches the objective function with respect to q(c), if and only if q(c) = p(c|t, α^k, σ²). The next step is to find α^(k+1) by maximizing

```
$\int \frac{p(t, c | α^k, σ²)}{p(c|t, α^k, σ²)} \log \frac{p(t, c | α^k, σ²)}{p(c|t, α^k, σ²)} dc = - \int p(t, c | α^k, σ²) \log p(c|t, α^k, σ²) dc$
```

The second term is independent of α. Hence only the first term is relevant for the maximization. Note: The first term is the expectation of the logarithm of the joint probability with respect to the current estimate of the posterior distribution. Hence the name Expectation-Maximization algorithm.

## 8.13 Bayesian Learning

As a specific example, the prior distribution of c be normal with mean zero and variance α⁻¹. In other words, each weight has its own hyperparameter. Our starting point is that there is no covariance between weights. That is, the weights do not influence each other. The multivariate prior is given by

```
$p(\mathbf{c}|\alpha) = (2\pi)^{-M/2}\prod_{m=1}^M \alpha_m^{1/2}\exp\left(-\frac{\alpha_m c_m^2}{2}\right) = (2\pi)^{-M/2}|\mathbf{A}|^{1/2}\exp\left(-\frac{1}{2}\mathbf{c}^T\mathbf{Ac}\right)$
```

where $\mathbf{A}$ is a diagonal matrix with entries $A_{mm}=\alpha_m$, and $|\mathbf{A}|$ denotes the determinant. The multivariate posterior distribution $p(t,\mathbf{D},\alpha,\sigma^2)$ is given by Bayes' rule and is proportional to the product of the prior and the likelihood function:

```
$p(t,\mathbf{D},\alpha,\sigma^2) = \frac{p(\alpha)\mathcal{L}(t|\mathbf{D},\sigma^2)}{\int p(\alpha)\mathcal{L}(t|\mathbf{D},\sigma^2)d\mathbf{c}}$ (8.5)
```

Now,

```
$p(\alpha)\mathcal{L}(t|\mathbf{D},\sigma^2) = (2\pi)^{-M/2}|\mathbf{A}|^{1/2}\exp\left(-\frac{1}{2}\mathbf{c}^T\mathbf{Ac}\right) = (2\pi)^{-N/2}\exp\left(-\frac{1}{2\sigma^2}(\mathbf{t}-\mathbf{Dc})^T(\mathbf{t}-\mathbf{Dc})\right)$
```

The multiplicative constants cancel in the fraction and concentrate on the terms in the exponential:

```
$-\frac{1}{2}[\mathbf{c}^T(\mathbf{A}+\sigma^{-2}\mathbf{D}^T\mathbf{D})\mathbf{c}-\sigma^{-2}\mathbf{c}^T\mathbf{D}^T\mathbf{t}+\sigma^{-2}\mathbf{t}^T\mathbf{t}]
```

Considering the square term we see that the covariance matrix of the posterior distribution has to be

```
$\mathbf{\Sigma} = (\mathbf{A}+\sigma^{-2}\mathbf{D}^T\mathbf{D}),$ (8.6)
```

which is symmetric and positive definite. We complete the square by introducing the mean $\mu$:

```
$-\frac{1}{2}[(\mathbf{c}-\mu)^T\mathbf{\Sigma}^{-1}(\mathbf{c}-\mu)+2\mathbf{c}^T\mathbf{\Sigma}^{-1}\mu-\sigma^{-2}\mathbf{c}^T\mathbf{D}^T\mathbf{t}+\sigma^{-2}\mathbf{t}^T\mathbf{t}]
```

The linear terms in $\mathbf{c}^T$ need to cancel, that is we need $\mathbf{\Sigma}^{-1}\mu=\sigma^{-2}\mathbf{D}^T\mathbf{t}$. Hence the mean of the posterior distribution is

```
$\mu=\sigma^{-2}\mathbf{D}^T\mathbf{t}.$ (8.7)
```

All remaining terms in the exponential are constant with respect to c. Because of the exponential, they are multiplicative constants and cancel in the fraction. It remains to evaluate the denominator, which after cancellations is

```
$$\exp\left(-\frac{1}{2}(\mathbf{c}-\mu)^T\mathbf{\Sigma}^{-1}(\mathbf{c}-\mu)\right) dc$$
```

However, it is known that

```
$$(2\pi)^{-M/2}\exp\left(-\frac{1}{2}(\mathbf{c}-\mu)^T\mathbf{\Sigma}^{-1}(\mathbf{c}-\mu)\right) dc$$
```

evaluates to 1, since it is the integral of a normal probability distribution function. Then the integral of the denominator is $(2\pi)^{M/2}\Sigma^{1/2}$.

To summarize, the posterior distribution is normal with

```
$$\mu(\mathbf{t}, \mathbf{D}, \alpha, \sigma^2) \sim \mathcal{N}(\mu, \Sigma)$$
```

with $\mu$ and $\Sigma$ given by (8.7) and (8.6).

Recall that Ordinary Least Squares calculates the coefficients as

```
$$\mathbf{c} = (\mathbf{D}^T\mathbf{D})^{-1}\mathbf{D}^T\mathbf{t},$$
```

while regression determines them as

```
$$\mathbf{c} = (\mathbf{I} + \mathbf{D}^T\mathbf{D})^{-1}\mathbf{D}^T$$
```

where $\lambda$ is a parameter which needs to be suitably chosen. Inserting (8.6) into (8.7) gives

```
$$\mu =(\mathbf{A}+\sigma^{-2}\mathbf{D}^T\mathbf{D})^{-1}\sigma^{-2}\mathbf{D}^T\mathbf{t}$$
```

The addition of $\sigma^2$ $\mathbf{A}$ against $\mathbf{D}$ being possibly singular. The main distinguishing feature of Bayesian methods is firstly, learning of a specific vector of coefficients, a multivariate posterior distribution is given for $c$, from which $c$ could be derived. It is also common to let $c = \mu$. Secondly, the hyperparameters $\alpha_1, \dots, \alpha_M$ are optimized by maximizing the marginal likelihood as we will see below.

Once the posterior distribution of the coefficients is found, the measurement $t_n$, for data $\mathbf{x}_n$, can be interpreted probabilistically. When we recall that $t_n$ is generated by a process,

```
$t_n =(\mathbf{x}_n)^T\mathbf{c} + \epsilon_n,$
```

where $(\mathbf{x}_n)^T$ is the $n^{th}$ row of $\mathbf{D}$, i.e. all the basis functions evaluated at $\mathbf{x}_n$. Now, $(\mathbf{x}_n)^T\mathbf{c}$ is a linear transformation of the normally distributed variable $\mathbf{c}$ and thus is normally distributed. The other, $\epsilon_n$, is normally distributed noise with mean zero and variance $\sigma^2$. Hence, $t_n$ is the sum of two normally distributed variables. The probabilistic interpretation of $t_n$ is that it is drawn from a univariate normal distribution

```
$$\text{mean} \quad =(\mathbf{x}_n)^T\mathbf{\mu}$\n$\text{variance} \quad \sigma_n^2 =\sigma^2 +(\mathbf{x}_n)^T\Sigma\mathbf{d}(\mathbf{x}_n).$$
