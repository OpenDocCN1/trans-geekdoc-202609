
# Matern kernel $k(\mathbf{x,y}) = \frac{\sqrt{2\nu}}{\Gamma(\nu)l^{2\nu-1}} K_{\nu}\left(\frac{\sqrt{2\nu}}{l}\|\mathbf{x}-\mathbf{y}\|\right)$

where $l$ is again the length scale, $\Gamma(\cdot)$ is the gamma function and $K_{\nu}$ is a modified Bessel function. The parameter $\nu$ controls the smoothness. The smaller the $\nu$, the smoother the function. For $\nu = 3/2$, the kernel is once differentiable, and for $\nu = 5/2$ it is twice differentiable. For $\nu = 1/2$ the Matern kernel becomes:

## Exponential kernel $k(\mathbf{x,y}) = \exp\left(-\frac{\|\mathbf{x}-\mathbf{y}\|}{l}\right)$ which is not differentiable.

## Rational quadratic kernel $k(\mathbf{x,y}) = \left(1+\frac{\|\mathbf{x}-\mathbf{y}\|^2}{2l^2}\right)^{-\alpha}$ uses to be the length scale and $\alpha > 0$ a scale mixture parameter. For $\alpha = 1/2$, this kernel becomes:

## Inverse multiscale kernel $k(\mathbf{x,y}) = \left(1+\frac{\|\mathbf{x}-\mathbf{y}\|^2}{\ell^2}\right)^{-1/2}$.

All kernels also have a multiplicative parameter $\theta$ known as *standard deviation*.

As shown in Section 5.2, the sum, product or exponential of a kernel gives rise to another kernel. Applying a polynomial to a kernel is a kernel. Combinations can be built to suit the use case.

If the kernel contains a positive, additive constant, then the mean of the Gaussian process can be assumed to be zero, a positive bias corresponds to the constant basis function, also known as the *bias* being included in the model.

Listing 8.3 implements six kernel functions and illustrates how to generate draws from a Gaussian process with a given kernel. While a draw from a Gaussian process is a function, the latter generates densely spaced point values. These are draws from the distribution with the required covariance matrix, which is the Gram matrix $\mathbf{K}$ for the given points and kernels $\mathbf{x}_1,\dots,\mathbf{x}_n$. Cholesky factorization $\mathbf{K} = \mathbf{LL}^T$ is calculated. A vector $\mathbf{v}$ of length $n$ is drawn from the standard, multivariate normal distribution. We then draw from the distribution with covariance $\mathbf{K}$. The point values of $\mathbf{f}$ are plotted as functions. This conclusion of the section concludes the discussion of drawing a function from a Gaussian process. We now turn our attention to drawing a function from the posterior of a Gaussian process, once some pairs $(\mathbf{x}_1, f_1),\dots,(\mathbf{x}_n, f_n)$ have been seen. Let $\mathbf{x}_*$ be arbitrary and distinct from $\mathbf{x}_n$, $n=1,\dots,N$. Recall that the measurements we use have additive normally distributed noise with mean zero and variance $\sigma^2$, that is

$f_* = f(\mathbf{x}_*) + \epsilon_*$.

```matlab
x <- (5:0,1:5); % Each row is a sample.

k = kGaussian(x,x, [1 1]);
% Note that sometimes it is necessary to add 1e-15*eye(size(x,1))
% to ensure positive definiteness due to rounding errors.
L = chol(k, 'lower');
figure
f1 = L*normrnd(0,1,size(x,1));
plot(f1,'k--o');
f2 = L*normrnd(0,1,size(x,1));
plot(f2,'k--o');
f3 = L*normrnd(0,1,size(x,1));
plot(f3,'k--o');
```

% Each row of x and y is one data sample. The functions below
calculate the covariance matrix for a specific kernel.

```matlab
% Constant kernel.
function k = Constant(x,y,param)
k = param*2 + ones(size(x,1),size(y,1));
```

```matlab
% Linear kernel.
function k = linear(x,y,params)
% The matrix of the inner products of each row of x and each row of y
% is given by x*y'.
k = params(1)*2 + params(2)*x*y';
```

```matlab
% Quadratic kernel.
function k = quadratic(x,y,params)
k = (params(1)*2 + params(2)*x*y')^2;
```

```matlab
% Gaussian kernel.
function k = gaussian(x,y,params)
% Calculate squared distance as the sum of the inner product of one
% row of x with itself and one of y with itself twice the
% inner product of these two rows.
sd = repmat(dot(x,x),size(y,1),1) + 
remat(dot(y,y),1,size(x,1)) - 2*repmat(dot(x,y'),size(y,1),1);
k = params(1)*exp(-sd/(2*params(2))^2);
```

```matlab
% Inverse quadratic kernel.
function k = inverseQuadratic(x,y,params)

remat(dot(y,y),1,size(x,1)) - 2*repmat(dot(x,y'),size(y,1),1);
```

Figure 8.12: Four draws from a Gaussian process with different kernels. We assume that $f$ is drawn from a Gaussian process with kernel $k$ and mean zero. Therefore, the vector $(t_1, \dots, t_n, t_*)$ follows a normal distribution with mean zero and covariance matrix

$$\begin{pmatrix} C & k(\mathbf{x}_*)^T \\ c(\mathbf{x}_*) \end{pmatrix}$$

where the vector $k(\mathbf{x}_*)$ has elements $k(\mathbf{x}_n, \mathbf{x}_*)$ for $n = 1, \dots, N$, $c(\mathbf{x}_*) = k(\mathbf{x}_*, \mathbf{x}_*) + \sigma^2$, and the $(i, j)$ entry of $C$ is

$C_{ij} = k(\mathbf{x}_i, \mathbf{x}_j) + \sigma^2\delta_{ij},$

where $\delta_{ij}$ is zero for $i \neq j$ and one for $i = j$ and is known as the Kronecker delta.

Figure 8.13: Draws from the posterior Gaussian process for different kernels. Using the inversion formula for a block matrix in A.1.1, the precision matrix of the distribution

$$\begin{aligned} C^{-1} + \frac{C^{-1}k(\mathbf{x}_i)k(\mathbf{x}_j)^T C^{-1}}{c(\mathbf{x}_i)-k(\mathbf{x}_i)^T C^{-1}k(\mathbf{x}_i)} &= \frac{-C^{-1}k(\mathbf{x}_j)}{c(\mathbf{x}_i)-k(\mathbf{x}_i)^T C^{-1}k(\mathbf{x}_i)} &+ \frac{k(\mathbf{x}_i)^T C^{-1}k(\mathbf{x}_j)}{c(\mathbf{x}_j)-k(\mathbf{x}_j)^T C^{-1}k(\mathbf{x}_j)} \end{aligned}$$

We can deduce that the conditional probability of $\mathbf{t}_i$, is normal and has variance and mean

$$\sigma^2(\mathbf{x}_*) = c(\mathbf{x}_*) - k(\mathbf{x}_*)^T C^{-1}k(\mathbf{x}_*) = \sigma^2 + k(\mathbf{x}_*,\mathbf{x}_*)^T C^{-1}k(\mathbf{x}_*),$$

$m(\mathbf{x}_*) = k(\mathbf{x}_*)^T C^{-1}\mathbf{t}. \quad (8.12)$

Since $\mathbf{x}_*$ is chosen arbitrarily, the distribution of $\mathbf{t}_*$ specifies the posterior. Let $\mathbf{x}_*$ be arbitrary and distinct from $\mathbf{x}_n$, $n=1,\dots,N$.
