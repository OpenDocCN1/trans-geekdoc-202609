The calculations simplify under the assumption $\Sigma_0 = \Sigma_1 = \Sigma$. This is known as *Linear Discriminant Analysis* (LDA). The vector $w$ is set to $\Sigma^{-1}(\mu_0 - \mu_1)$, since scaling can be neglected and the separation threshold is the projection of the midpoint between the means:

```
$b = w^T\frac{1}{2}(\mu_0 + \mu_1) = \frac{1}{2}(\mu_0^T\Sigma^{-1}\mu_0 - \mu_1^T\Sigma^{-1}\mu_1)$.
```
