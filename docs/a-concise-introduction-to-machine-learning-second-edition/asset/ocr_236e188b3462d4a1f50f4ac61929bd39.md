Before considering specific choices for $\phi$, it needs to have certain properties.

+   * Zero for pure nodes: The impurity should be zero, if only one class is present. That is if $i(t) = 0$, if and only if $p_{k} = 1$ for some $k$, and zero for all others.
* Maximal for equal proportions: The impurity should be maximal, when all classes are mixed in equal proportions, i.e. $p_{t_1} = \dots = p_{t_K} = 1/K$.
* Symmetry: It should also be symmetric, if the classes are relabeled.

One popular choice for the impurity $i(t) = \phi(p_{t_1}, \dots, p_{t_K})$ is the Gini Diversity Index (GDI)

```
$i(t) = \sum_{k=1}^{K} p_{tk}(1-p_{tk}) = 1 - \sum_{k=1}^{K} p_{tk}^2,$$
```

since $\sum_{k=1}^{K} p_{tk} = 1$. It vanishes, if $p_{tk} = 1$ for some $k$, and zero for all others. Figure 5.9 shows, for two classes, $i(t)$ as a function of $p_{t_1}$ (or equivalently $p_{t_2} = 1 - p_{t_1}$).

With this choice, the change in impurity is

```
$\Delta i = \left(1 - \sum_{k=1}^{K} p_{Pk}^2ight)\frac{N_K}{N_P} - \left(1 - \sum_{k=1}^{K} p_{Lk}^2ight)\frac{N_L}{N_P} - \left(1 - \sum_{k=1}^{K} p_{Rk}^2ight)\frac{N_R}{N_P}$
$= \sum_{k=1}^{K} \frac{N_R}{N_P}p_{Rk}^2 + \frac{N_L}{N_P}\dots,$
```
