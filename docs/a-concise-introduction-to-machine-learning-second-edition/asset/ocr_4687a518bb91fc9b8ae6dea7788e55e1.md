This is called a mixture distribution. The probabilities $\pi_k$ are known as *mixing coefficients*.
For a given vector $v$, we can consider the probability that it was generated by process $k$. This is the conditional probability $p(z_k=1|v)$, whose value can be calculated using *Bayes' Rule*. This is given by

```
$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$
```

where $A$ and $B$ are events, and $P(A)$ and $P(B)$ are the probabilities of $A$ and $B$ without regard to each other, $P(A|B)$ is the *conditional probability* of $A$ given $B$ is true, and $P(B|A)$ is the conditional probability of $B$ given that $A$ is true. Applying Bayes' rule leads to

```
$p(z_k=1|v) = \frac{p(v|z_k)p(z_k)}{p(v)} = \frac{\pi_k p_k(v)}{p(v)}. \quad (6.3)$
```

We see that for particular $v$ the probability that it was generated by process $k$ is the mixing coefficient $\pi_k$, adjusted by the ratio of the probability $p_k(v)$ to the overall probability $p(v)$, $p(z_k=1|v)$ is known as the *responsibility process* $k$ for explaining the sample $v$.\nUsing (6,2), we

```
$p(z_k=1|v) = \frac{\sum_{k} \pi_k p_k(v)}{p(v)}.$
```

Thus the responsibilities, i.e the probabilities of the processes generating a particular sample, sum to one.\nIn particular, for the data samples $v_n, n=1,\dots,N$, we can now make assignments according to the values $p(z_k=1|v_n)$ for $k=1,\dots,K$. This is called *soft clustering*, since it is quantified by probabilities. It is possible that for a particular sample the probabilities are the same for two (or even more) values of $k$. These are samples which lie between clusters.\nBefore we can however calculate any probabilities for cluster membership, we need to determine $\pi_k$ and $p_k(v)$ for $k=1,\dots,K$. To this we consider the joint likelihood of the data samples $v_1,\dots,v_m$ which is given by

```
$p(v_n) = \sum_{k=1}^{K} \pi_k p_k(v_n).$
```
