The encoder function $\phi$ maps the input $x = (x_1, \dots, x_D)^T$ to the latent variables $\mathbf{x}^{(L/2)} = (x_1^{(L/2)}, \dots, x_{M_{L/2}}^{(L/2)})^T$, while the decoder function $\psi$ maps the latent variables $\mathbf{x}^{(L/2)}$ back to $x$.

While it is possible to implement the bias in each layer with a dummy neuron, which has the value $h$, it is common to denote it as $b^{(i)} = (b_1, \dots, b_{M_i})$. It signifies a shift after the linear transformation by the weights $w_{ji}^{(i)}$, where $i=1, \dots, M_{L-1}$ and $j=1, \dots, M_i$. Here $M_0 = M_L = D$. The weights of each layer are stored in the weight matrix $W^{(i)}$. The activation of $\mathbf{a}^{(i)} = (a_1, \dots, a_{M_i})^T$ is then

```
$a^{(i)} = W^{(i)}a^{(i-1)} + b^{(i)}$
```

where $x^{(0)} = x$. The notation $h^{(i)}(a^{(i)})$ is used to denote the element-wise application of the activation function $h^{(i)}$ to the entries of $\mathbf{a}^{(i)}$.

The error for the autoencoder is typically the *mean squared error*

```
$E(\mathbf{w}) = \frac{1}{N} \sum_{n=1}^N ||x_n - \psi(\phi(x_n))\|^2.$
```

There are several variants of autoencoders, which adapt the error function with a particular goal in mind.

Firstly, there is the *denoising autoencoder* (DAE), where the goal is that a good representation of the sample is still obtained, even if it is corrupted by noise. To this, the training samples $\mathbf{x}_1, \dots, \mathbf{x}_n$ first undergo a probabilistic process resulting in corrupted training samples $	ilde{\mathbf{x}}_1, \dots, 	ilde{\mathbf{x}}_n$. The autoencoder is trained using the error function

```
$E(\mathbf{w}) = \frac{1}{N} \sum_{n=1}^N ||\tilde{\mathbf{x}}_n - \psi(\phi(\tilde{\mathbf{x}}_n))\|^2.$
```

The corrupted dataset is encoded and decoded and the results compared to the corrupted data.

Secondly, we have *sparse autoencoders* (SAE). Here, the aim is that only a certain latent variables are nonzero. One possibility is to keep the largest latent variables in a particular set of hidden neurons and the others to *zero* during forward propagation. Backpropagation passes only through the hidden neurons, whose latent variables are nonzero. This is known as *k-sparse autoencoder*.

```
$p_i^{(l)} = \frac{1}{N} \sum_{n=1}^N z_i^{(l)}(\mathbf{x}_n).$
```
