We can then use (2.10) to calculate

```
$$\mathbb{E}[u_n u_n^T] = \mathbf{\Sigma}_{u_n} + \mathbb{E}[u_n]\mathbb{E}[u_n]^T = \mathbf{\Sigma}_{u_n} + \mu_{u_n}\mu_{u_n}^T. \quad (7.9)$
```

```
$$\mathcal{L} = \frac{1}{2} \sum_{n=1}^N [(K+D) \log(2r) + D \log(\sigma^2) + \text{tr}(\mathbb{E}[u_n u_n^T]\mathbf{W}^T\mathbf{W})] + \n \sigma^{-2}(\|mathbf{v}_n - \mathbf{\mu}\|^2 - 2\sigma^{-2}\mathbb{E}[u_n]\mathbf{W}^T(\mathbf{v}_n - \mathbf{\mu}) +$$
```

Now, employing the cyclic property of the trace, the formulae given in A.2.6 and A.2.9 and the symmetry of $\mathbb{E}[u_n u_n^T]$, the derivative with respect to $\mathbf{W}$

```
$$\frac{\partial\mathcal{L}}{\partial\mathbf{W}} = \frac{1}{2} \sum_{n=1}^N [-2\sigma^{-2}(\mathbf{v}_n - \mathbf{\mu})\mathbb{E}[u_n]^T + 2\sigma^{-2}\mathbb{E}[u_n u_n^T]]$
```

Setting this to zero results in an update for $\mathbf{W}$ for it,

```
$$\mathbf{W}_{new} = \left(\sum_{n=1}^N (\mathbf{v}_n - \mathbf{\mu})\mathbb{E}[u_n]^T\right) \left(\sum_{n=1}^N \mathbb{E}[u_n u_n^T]\right)^{-1} \quad (7.10)$
```

Note that this is an update formula, which depends on $\mathbf{W}$ via the conditional mean and covariance matrix in (7.6) and (7.7) via the formulae in (7.9) and (7.8).

On the other hand, differentiating with respect to $\sigma^2$ results in

```
$$\frac{\partial\mathcal{L}}{\partial\sigma^2} = -\frac{1}{2} \sum_{n=1}^N \frac{1}{(\sigma^2)^2}(\|\mathbf{v}_n - \mathbf{\mu}\|^2 - 2\sigma^{-2}\mathbb{E}[u_n]\mathbf{W}^T(\mathbf{v}_n - \mathbf{\mu}) + \text{tr}(\mathbf{W}^T\mathbf{W}\mathbb{E}[u_n u_n^T]))
```

The update formula for $\sigma^2$ follows

```
$$\sigma_{new}^2 = \frac{1}{ND} \sum_{n=1}^N [\|\|mathbf{v}_n - \mathbf{\mu}\|^2 - 2\sigma^{-2}\mathbb{E}[u_n]\mathbf{W}_{new}^T(\mathbf{v}_n - \mathbf{\mu}) + \text{tr}(\mathbf{W}_{new}^T\mathbf{W}_{new}\mathbf{\Sigma}_{u_n})] \quad (7.11)$
```
