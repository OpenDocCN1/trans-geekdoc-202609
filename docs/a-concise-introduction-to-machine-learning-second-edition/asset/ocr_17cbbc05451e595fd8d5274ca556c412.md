# 9.4 Autoencoder Example

We apply a sparse autoencoder to the MNIST dataset of handwritten digits as gathered by LeCun et al. (1998) and compare and link this method to the techniques we have already encountered. For this data, D = 784, and the components of x are the individual pixel values.

The simplest autoencoder has two layers. Schematically, it is represented as

![](bbox=[0.303, 0.303, 0.696, 0.545])

In this simple case, the encoder and decoder functions are

$\phi(\mathbf{x}) = h^{(1)}(\mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)})$ and $\psi(\mathbf{z}) = h^{(2)}(\mathbf{W}^{(2)}\mathbf{z} + \mathbf{b}^{(2)})$.

If $\mathbf{W}^{(2)}=\mathbf{W}^{(1)T}$, then the weights are tied. However, in this example we do not enforce this, let them be independent from each other.

Both $h^{(1)}$ and $h^{(2)}$ are chosen to be the logistic sigmoid elementwise. Since the output of logistic sigmoid is $[0, 1]$ and autoencoders reconstruct the pixel values of the input images needed to be scaled to lie between zero and one as a pre-processing step.
