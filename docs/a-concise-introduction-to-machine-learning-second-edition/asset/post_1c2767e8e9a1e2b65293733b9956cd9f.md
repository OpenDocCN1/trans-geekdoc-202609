
## Clustering

So far we have looked at data which had class labels. The task was to learn the class membership from the features of each data sample, in order to classify unseen data in the future. In this chapter, we look at unlabeled data. As before, we denote the vector of features by $v$. Let $v_1, \dots, v_N$ be the feature vectors of $N$ data samples. The choice of features or combination of features is important.

For example, a popular exercise for children to apply their observation and sorting skills, is to let them sort sweets. It is immediately obvious that there are numerous distinguishing features. Firstly, there is the size, then the colour, or the sweet might be multicoloured. They come in all sorts of shapes. Next, we might consider the main ingredient which may be chocolate, jelly, licorice or something completely different, or it might be a combination of different ingredients, or have a filling. The parents might be more interested in keeping the overall sugar intake, while a dentist might be interested whether the sweet sticks to the teeth or not. Depending on their tastes and preferences, different people will put different emphasis on this feature.

Clustering often is the first step when analysing a new dataset. If not much is known yet about the data, it is useful to see whether the data naturally separates into different groups. The aim is to find clusters where data samples within one cluster are more similar to each other than to samples in other clusters. We will see in the following what means for different algorithms.

There are many application areas. For example, clustering is used to find news articles with similar contents or relating to the same topic. Similarly, search engines using clustering algorithms. The suggestions we receive on streaming sites depending on our preferences are based on clusters such as. Image segmentation is another application area as is lossy data compression, where it is sufficient to represent the data by the cluster it belongs to. It is also used in bioinformatics to analyze biological data of all sorts.

$K$ clustering decides on the number of clusters denoted by $K$ and each data sample is assigned to exactly one cluster. This is known as hard clustering. The aim is to find clusters $\mu_1, \dots, \mu_K$ such that the sum of the squared distances of each data sample to its nearest centre (the one it is assigned to) is minimal. Nearest here is with respect to the Euclidean norm ($L_2$ norm). Thus the objective function is

```
J = \sum_{n=1}^N \min_{k} ||\mathbf{v}_n - \mathbf{\mu}_k\|^2.
```

This optimization problem is NP hard. That is, there is no known algorithm to solve this in polynomial time. This is because clusters move around, for each sample it changes the nearest cluster. The algorithm finds an approximate solution by separating this interdependency with the introduction of hidden (latent) variables $\mathbf{z}_n$, for each data sample $\mathbf{v}_n$. The latent variables are binary vectors, $\mathbf{z}_n \in \{0,1\}^K$, where only one entry is 1 and the others to zero. This is known as a one-of-K representation. A 1 in the $k^{th}$ entry identifies that $\mu_k$ is the nearest cluster centre to $\mathbf{v}_n$. Let $z_{n,k}$ be the $k^{th}$ component of $\mathbf{z}_n$. The objective function can be rewritten as

```
J = \sum_{n=1}^N \sum_{k=1}^K z_{n,k} ||\mathbf{v}_n - \mathbf{\mu}_k\|^2.
```

This is quadratic in $\mu_k$. The minimum is found by differentiating with respect to $\mu_k$ for each $k$ using $A.2.1$ and $A.2.2$ and setting this to zero,

```
$\sum_{n=1}^{N} z_{n,k}(v_n - \mu_k) = 0.$
```

This gives new centres for all $k$

```
$\mu_k = \frac{\sum_{n=1}^{N} z_{n,k}v_n}{\sum_{n=1}^{N} z_{n,k}}$ (6.1)
```

However, as the centres move, the indicator vectors $z_n$ have to be adjusted. This is by minimizing $J$ with respect to all $z_n$. This will cause the centres to move again. The algorithm alternates between moving the centres $\mu_k$ and recalculating $z_n$. It terminates, after moving the centres, none of the indicator vectors changes.

Looking at (6.1), note that $\sum_{n=1}^{N} z_{n,k}$ gives the number of samples for $\mu_k$ which is the closest centre, while $\sum_{n=1}^{N} z_{n,k}v_n$ is the sum of those samples. $\mu_k$ is the mean of the samples assigned to this cluster. The algorithm arrives at a local minimum of $J$. However, the solution is highly dependent on the initialization of the cluster centres. These can be the samples be randomly assigned clusters and the initial cluster centres be calculated as the mean of these random assignments. This dependency on initial values, the algorithm is run (possibly in parallel) with different initializations. After convergence, the result with the lowest value of $J$ is chosen.
