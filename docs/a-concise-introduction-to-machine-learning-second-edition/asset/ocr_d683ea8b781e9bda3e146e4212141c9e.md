This is known as the kernel trick. The features are transformed to a higher dimensional feature space where the classes are linearly separable. We will see below that this transformation is never performed.

Figure 5.2 shows artificial data, which cannot be separated by a line, and their transformation to a higher dimensional space, where they can be separated by a plane. We set $v_3 = v_1^2 + v_2^2$, and the plane lies at $v_3=1$ which is the unit circle in the $v_1, v_2$-plane.

To formalize this approach, recall that Support Vector Machine classifies according to the sign of

$$-N - b + \sum_{n=1}^N \alpha_n c_n^T v_n$$

where the bias $b$ is given by $-\sum_{n=1}^N \alpha_n c_n$ and where $c_n = \pm1$ is the class label of sample $v_n$. The $\alpha_i \geq 0$ for $i=1, \dots, N$; solve the dual maximization problem by the function

$L(\alpha) = \sum_{n=1}^N \alpha_n - \frac{1}{2} \sum_{n=1}^N \sum_{m=1}^N \alpha_n \alpha_m c_n c_m (1 + v_n^T v_m)$$

$\phi : \mathbb{R}^M \to \mathbb{R}^{\tilde{M}}$ be the mapping from the original $M$ dimensional feature space to the higher $\tilde{M}$ dimensional feature space. We now apply the support vector machine to the data in this higher dimensional space, i.e. we to maximize

$L(\alpha) = \sum_{n=1}^N \alpha_n - \frac{1}{2} \sum_{n=1}^N \sum_{m=1}^N \alpha_n \alpha_m c_n c_m (1 + \phi(v_n)^T \phi(v_m))$$

Let $k : \mathbb{R}^M \times \mathbb{R}^M \to \mathbb{R}$ be defined as

$k(x, y) = \phi(x)^T \phi(y)$$
