As an example, consider the *Weibull distribution*, $x \sim \text{Weibull}(\lambda, k)$. Its probability density function is

```
$$\text{Weibull}(x|\lambda, k) = \begin{cases} \frac{k}{\lambda}\left(\frac{x}{\lambda}\right)^{k-1}\exp\left(-\left(\frac{x}{\lambda}\right)^k\right) & \text{for } x \ge 0,\\ 0 & \text{for } x < 0.\end{cases}$$
```

where $k > 0$ is the *shape parameter* and $\lambda > 0$ is the *scale parameter*. The variance is $\lambda^2\Gamma(1 + 2/k) - (\Gamma(1 + 1/k))^2$. Figures 3.1 and 3.2 give examples of the probability density and cumulative distribution, respectively. For some choices of parameters the shape becomes close to a normal distribution.

For $k=1$, the Weibull distribution becomes the exponential distribution. The Weibull distribution is used in reliability engineering and failure analysis. The parameter $k$ is interpreted in the following way: if $k>1$, then the failure rate increases with time as parts are more likely to fail as time goes on. If $k=1$, the failure rate is constant, the system is stable and there is no aging process. If $k < 1$, the failure rate decreases with time. Colloquially, this means that if it has not failed by now, it is less likely to fail in the future. Montgomery (2020) gives a thorough introduction to statistical quality control.

Since the probability density function is only nonzero for $x \ge 0$, the lower limit of the integral is zero, when calculating the cumulative distribution

$F(x) = \exp\left(-\int_{0}^{x} \left(\frac{t}{\lambda}\right)^{k-1} dt\right) = \exp\left(-\left(\frac{x}{\lambda}\right)^{k}\right) = 1 - \exp\left(-\left(\frac{x}{\lambda}\right)^{k}\right)$.

Setting this equal to $y$ and solving for $x$ leads to

$x = \lambda [-\log(1 - y)]^{1/k}$.

which is a random variable drawn from the Weibull distribution, if $y$ is drawn from the uniform distribution over (0,1). Now, $z = 1 - y$ is equally drawn from the uniform distribution over (0,1). So the transformation is often stated as

$x = \lambda [-\log z]^{1/k}$.

This technique can be used as the cumulative distribution function is known and can be inverted. This is not always the case, the normal distribution being a prime example. In the following, we derive the *Box-Muller transform* to generate a pair of random variables following the standard normal distribution from a pair of uniformly distributed random variables.

We combine Equations (2.5) and (2.6) to arrive at

$\int_{-\infty}^{\infty}\exp\left(-\frac{x_1^2+x_2^2}{2}\right)dx_1dx_2=\int_{0}^{2\pi}r\exp\left(-\frac{r^2}{2}\right)drd\theta$

$x_1$ and $x_2$ are standard normal random variables and $x=r\cos\theta$. From the above we see that $\theta$ follows the uniform distribution on the interval $(0,2\pi)$ which is the circumference of the unit circle. On the other hand, $r$ has the probability density function $r\exp(-r^2/2)$ on the $(0,\infty)$. To generate a random variable from uniform random, we use inverse transform sampling. First, we calculate

$F(r)=\int_{0}^{r}t\exp\left(-\frac{t^2}{2}\right)dt=\left[-\exp\left(-\frac{t^2}{2}\right)\right]_{0}^{r}=1-\exp\left(-frac{r^2}{2}\right)$.

Let $q$ be a random variable drawn from the uniform distribution on $(0,1)$. Setting $F(r)=q$ and solving for $r$, gives $r=\sqrt{-2\log(1-q)}$. Since $1-q$ is also uniformly distributed on $(0,1)$, it can be rewritten as

$r=\sqrt{-2\log q}$.

Summarizing, we generate random variables $x_1$ and $x_2$ drawn from the standard normal distribution by drawing two variables $y_1$ and $y_2$ from the uniform distribution on $(0,1)$ and letting

$x_1=\sqrt{-2\log y_1}\cos(2\pi y_2)$
$x_2=\sqrt{-2\log y_1}\sin(2\pi y_2)$.

This is the *basic form* of the Box-Muller transform. To avoid the sine and cosine, we note that $\cos\theta=x_1/r$ and $\sin\theta=x_2/r$.

```python
import numpy as np
import matplotlib.pyplot as plt

def BoxMuller(N):
    X = np.zeros((N,2))
    for n in range(N):
        # Generate random number within the unit circle.
        while True:
            # Draw two samples from the uniform distribution on (-1,1)
            z1 = 2.0 * np.random.uniform() - 1.0
            z2 = 2.0 * np.random.uniform() - 1.0
            # While loop ends, the point is within the unit circle.
            s = z1**2 + z2**2
            if s < 1:
                break
        # Calculate radius.
        s = np.sqrt(-2.0 * np.log(s)) / s
        X[n,0] = z1 * s
        X[n,1] = z2 * s
    return X

# Number of samples to be drawn
N = 1000
X = BoxMuller(N)
# Scatterplot
plt.scatter(X[:,0], X[:,1])
plt.axis('equal')
plt.show()
```

This is the polar form of the Box-Muller transform. First, we generate uniformly distributed numbers $z_1, z_2 \in (-1,1)$ by letting $z_i = 2y_i-1$ for variables $y_i$ uniformly distributed in $(0,1)$, until $s = z_1^2 + z_2^2 < 1$. We then set

$$\cos \theta = \frac{z_1}{\sqrt{s}}$$
$$\sin \theta = \frac{z_2}{\sqrt{s}}$$

The probability $p(s \le \hat{s})$ is the area of the circle with radius $\sqrt{s}$, which is $\pi s$, divided by the area of the unit circle which is $\pi$. Therefore $p(s \le \hat{s}) = s$, and $s$ follows a uniform distribution on $(0,1)$. Therefore, $s$ can be used to generate a random variable from the distribution of $r$. To summarize,

$x_1 = \sqrt{-2\log s} \cos\theta = z_1 \sqrt{-2\log s/s}$
$x_2 = \sqrt{-2\log s} \sin\theta = z_2 \sqrt{-2\log s/s}$

Another way of view this technique is that a random point $(z_1, z_2)$ within the unit circle is mapped to the point $(z_1/\sqrt{s}, z_2/\sqrt{s})$ on the unit circle. This point is multiplied by a radius following the required distribution in Equation (3.2).

The advantage of this method is that the calculation of the sine and cosine is avoided. On the other hand, more random numbers need to be generated, since a fraction of samples are rejected as they lie outside the unit circle. Most software packages include implementations of random number generators for various distributions. Nevertheless, Listings 3.1 and 3.2 are example implementations.

## Rejection Sampling

We now consider the case where the probability density function $f$ is available and can be evaluated, the cumulative distribution function $F$ is not, and inverse sampling is not option. Let $g$ be a probability density function such that $f(x) \leq cg(x)$ for all $x$ for some finite $c > 1$. Let $G$ be the cumulative distribution function. We now assume that we have a method to draw samples from the distribution given by $G$. That is $g(x)$ is a simpler probability density function and $cg(x)$ is an envelope of $f(x)$. $f$ has two modes. The first choice is a uniform distribution over the support of $f$. That is the range of $x$ where $f(x)$ is nonzero. The other two, $g$ is normally distributed. For the second choice the mean of $g$ is at the same location as one of the modes of $f$, and for the third choice the mean lies between the two modes. We see that there are infinitely many possibilities for $g$.

> *Rejection sampling*, also known as the acceptance-rejection method, proceeds as:

- 1. Draw a random variable $x$ following the distribution given by $g$;
- 2. Draw a random variable $u$ from the uniform distribution over $(0,1)$;
- 3. If $u \leq \frac{f(x)}{cg(x)}$, accept $x$ as a sample from the distribution given by $f$. Otherwise return to 1.

```
$u \leq \frac{f(x)}{cg(x)} \quad (3.3)$
```

Intuitively, the method samples points from under $cg$ and discards those which fall in the shaded area between the curves of $cg$ and $f$. The $x$-position of the retained points are samples from the distribution governed by $f$. To keep the number of discarded points low, the area of the areas has to be as small as possible.
