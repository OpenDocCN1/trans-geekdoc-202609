Now $(\mathbf{v}_n - \mu)^T \mathbf{C}^{-1}(\mathbf{v}_n - \mu)$ is scalar and therefore equal to its trace. A trace of three term product is invariant to cyclic permutations. Therefore,

```
$\mathcal{L} = -\frac{ND}{2}\log(2\pi) - \frac{N}{2}\log|\mathbf{C}| - \frac{1}{2}\sum_{n=1}^N 	ext{tr}(\mathbf{C}^{-1}(\mathbf{v}_n - \mu)(\mathbf{v}_n - \mu)^T)$
$\$\mathcal{L} = -\frac{ND}{2}\log(2\pi) - \frac{N}{2}\log|\mathbf{C}| - \frac{1}{2}\sum_{n=1}^N 	ext{tr}(\mathbf{C}^{-1}(\mathbf{v}_n - \mu)(\mathbf{v}_n - \mu)^T)$
```

since the sum of traces is the trace of the sum of matrices. With the definition (7.1) for the sample covariance matrix, this becomes

```
$\mathcal{L} = -\frac{N}{2}[D(2\pi) + \log|\mathbf{C}| + 	ext{tr}(\mathbf{C}^{-1})]$
```

This needs to be maximized with respect to $\mathbf{W}$. Let $\mathbf{w}_1, \dots, \mathbf{w}_K$, then

```
$\mathbf{C} = \sigma^2\mathbf{I} + \sum_{k=1}^K \mathbf{w}_k\mathbf{w}_k^T$.
```

The inverse of $\mathbf{C}$ is

```
$\mathbf{C}^{-1} = \sigma^{-2}(I - \sum_{k=1}^K \frac{\mathbf{w}_k\mathbf{w}_k^T}{\sigma^2 + \mathbf{w}_k^T\mathbf{w}_k})$ (7.3)
```

This can easily be by multiplying the two expressions and using the fact that the columns of $\mathbf{W}$ are mutually orthogonal. We consider the derivative with respect to the $j^{th}$ column $\mathbf{w}_j$. To this end

```
$\mathbf{C}_{-j} = \sigma^2\mathbf{I} + \sum_{k=1, k
eq j}^K \mathbf{w}_k\mathbf{w}_k^T$.
```

Then $\mathbf{C} = \mathbf{C}_{-j} + \mathbf{w}_j\mathbf{w}_j^T$ and

```
$\mathbf{C}^{-1} = \mathbf{C}_{-j}^{-1} - \frac{\mathbf{C}_{-j}^{-1}\mathbf{w}_j\mathbf{w}_j^T\mathbf{C}_{-j}^{-1}}}{\sigma^2 + \mathbf{w}_j^T\mathbf{C}_{-j}^{-1}\mathbf{w}_j}$.
```

Using the matrix determinant lemma, the determinant of $\mathbf{C}$ is

```
$|\mathbf{C}| = |\mathbf{C}_{-j}|(1 + \sigma^{-2}\mathbf{w}_j^T\mathbf{C}_{-j}^{-1}\mathbf{w}_j)$.
```

The inverse of $\mathbf{C}_{-j}$ is of the same form as the inverse of $\mathbf{C}$ in (7.3) Therefore, $\mathbf{C}_{-j}^{-1} = \sigma^{-2}\mathbf{I}$, because $\mathbf{w}_j$ is orthogonal to the other column vectors. The above expression becomes

```
$|\mathbf{C}| = |\mathbf{C}_{-j}|(1 + \sigma^{-2}\mathbf{w}_j^T\mathbf{w}_j)$.
```
