This is quadratic in $\mu_k$. The minimum is found by differentiating with respect to $\mu_k$ for each $k$ using $A.2.1$ and $A.2.2$ and setting this to zero,

```
$\sum_{n=1}^{N} z_{n,k}(v_n - \mu_k) = 0.$
```

This gives new centres for all $k$

```
$\mu_k = \frac{\sum_{n=1}^{N} z_{n,k}v_n}{\sum_{n=1}^{N} z_{n,k}}$ (6.1)
```

However, as the centres move, the indicator vectors $z_n$ have to be adjusted. This is by minimizing $J$ with respect to all $z_n$. This will cause the centres to move again. The algorithm alternates between moving the centres $\mu_k$ and recalculating $z_n$. It terminates, after moving the centres, none of the indicator vectors changes.

Looking at (6.1), note that $\sum_{n=1}^{N} z_{n,k}$ gives the number of samples for $\mu_k$ which is the closest centre, while $\sum_{n=1}^{N} z_{n,k}v_n$ is the sum of those samples. $\mu_k$ is the mean of the samples assigned to this cluster. The algorithm arrives at a local minimum of $J$. However, the solution is highly dependent on the initialization of the cluster centres. These can be the samples be randomly assigned clusters and the initial cluster centres be calculated as the mean of these random assignments. This dependency on initial values, the algorithm is run (possibly in parallel) with different initializations. After convergence, the result with the lowest value of $J$ is chosen.

The algorithm can be generalized using any similarity measure between two feature vectors, as kernels were used as measures for the kernel trick described in 5.2. In this case, the method is the $K$-methods algorithm. However, the minimization with respect to $\mu_k$ might be more involved. It depends on the differentiability of the dissimilarity, and whether it is possible to find where the derivative vanishes. If this is not possible, it is common practice to require each centre to be one of the data samples. The minimization with respect to $\mu_k$ is then search among the data samples assigned to the $k^{th}$ cluster. That is the sample with the minimum aggregated distance to all other samples in cluster.

Lossy data compression is achieved by choosing a suitable number of clusters and storing the feature vectors of the centres, $\mu_k$. For each data sample only the cluster it belongs to is stored. This can be applied to images. Typically images are represented by storing three values for each pixel, with each value being one byte.
