### 3.1 Inverse Transform Sampling

We need to be generate samples of the probability density function f(x). We assume that we have an algorithm available that generates uniformly distributed numbers in (0, 1). The cumulative probability function is known and relates to the probability density function by $F(x) = \int_{-\infty}^{x} f(y)dy$.

We assume that $a$ is continuous and strictly increasing on the interval $(a, b)$ and zero for $x \leq a$ and for $x \geq b$. It takes values in $[0, 1]$. Let $y$ be drawn from the uniform distribution over $(0, 1)$. Then there exists a unique $x$ in $(a, b)$ such that $F(x) = y$, or in other words x = F^{-1}(y). Then $x$ is a continuous random variable with cumulative distribution known as $F$ and hence probability density $f(x)$. This techn is known as transform sampling. It is also known asversion inversion sampling, inverse probability integral-, and Markov sampling.

We need to show that for $x = F^{-1}(y)$, we have $p(x \leq \hat{x}) = F(\hat{x})$a a given value $\hat{x}$.

$p(x \leq \hat{x}) = p(F^{-1}(y) \leq \hat{x})$.

by the definition for $x$. Next, it follows from $F$ and subsequently $F^{-1}$ being strictly monotonically increasing that $F^{-1}(y) \leq \hat{x}$ if and only if $y \leq F(\hat{x})$. Lastly, since $y$ is from the uniform distribution on $(0, 1)$, the probability of $y$ less than or equal to $F(\hat{x})$ is in fact $F(\hat{x})$ itself and the assertion follows.
