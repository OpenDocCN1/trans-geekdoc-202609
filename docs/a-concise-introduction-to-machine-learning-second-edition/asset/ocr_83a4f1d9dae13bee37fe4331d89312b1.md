The Metropolis-Hastings algorithm extends the Metropolis method to use proposal distributions which are not symmetric. In this case, the acceptance probability of a candidate $\mathbf{x}^*$ is calculated

```
$$\min \left(1, \frac{f(\mathbf{x}^*)g(\mathbf{x}^*, \mathbf{x}_n)}{f(\mathbf{x}_n)g(\mathbf{x}_n, \mathbf{x}^*)}\right) = \min \left(1, \frac{f(\mathbf{x}^*)g(\mathbf{x}^*, \mathbf{x}_n)}{f(\mathbf{x}_n)g(\mathbf{x}_n, \mathbf{x}^*)}\right)$
```
