Decision trees are grown recursively from a training set. There are many possible ways the tree can grow. At each node, the set of training samples reached that node is split in two. Each of the subsets passed down one of the branches to the child nodes. At each node, we need to choose the feature on which base the split, and the threshold. To do so, all possible splits for every feature are considered, the optimal split is selected based on different criteria.

Before we discuss the criteria, we need to introduce some notation. Let $t = P, L$, or $R$ refer to quantities relating to the parent, left or right child node, respectively. For example, $N_P$ is the number of samples reaching the parent node, while $N_L$ and $N_R$ are the number of samples reaching the left and right child nodes. Let $N_{tk}$ be the number of samples in class $k$, where $k=1,\dots,K$. We define $p_{tk}$ as the portion of samples belonging to class $k$ That is

```
$$p_{tk} = \frac{N_{tk}}{N_t}$$
```

and we have

```
$$$\sum_{k=1}^{K} p_{tk} = 1$$
```

The proportions of a node are related to the children of the child nodes in the following:

```
$$p_{pk} = \frac{N_{Pk}}{N_P} = \frac{N_{Lk} + N_{Rk}}{N_P} = \frac{N_{PLk} + N_{PRk}}{N_P} \quad (5.2)$
```

A node is called pure, if it contains only samples of one class. However, not all leaves are pure nodes, for example where the maximum height of the tree is reached. There in a leaf with samples from a mixture of classes, some training samples will be misclassified. A tree with many samples per leaf is low, is likely to overfit the data and generalize poorly to unseen data.

We define the impurity $i(t)$ as a function of the class proportions

```
$$i(t) = \phi(p_{t1}, \dots, p_{tk})$$$
```

We will discuss later the specific choices for $\phi$. A good decision split should optimize the purity, or in other words minimize the impurity. Since the two nodes can differ in size, we define the change in impurity $\Delta i$ as the child nodes:

```
$$\Delta i = i(P) - \frac{N_L}{N_P}i(L) + \frac{N_R}{N_P}i(R)$$$
```

The best possible split maximizes the change in impurity over all possible splits for all features. If no splits, where the change is positive, are possible, the node is not split and it becomes a leaf.
