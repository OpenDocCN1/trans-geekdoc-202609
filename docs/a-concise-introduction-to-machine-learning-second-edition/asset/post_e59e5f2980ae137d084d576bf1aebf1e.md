An iteration is complete, if all samples have been considered in a random order. The process is repeated for a fixed number of iterations. Sometimes this form of Gibbs sampling is called collapsed Gibbs sampling, since the assignments of the other clusters are explicitly encoded when sampling $\mathbf{z}_n$ for $\mathbf{v}_n$. They are directly encoded in the parameters of the cluster, normal-inverse-Wishart distribution for each cluster and thereafter when calculating the cluster membership probabilities for $\mathbf{v}_n$. This reduces the parameters sampling to a multiple of $K$.

## 6.6 The Chinese Restaurant Process

In all above, the number of clusters was fixed at the start of the algorithm. This is, however, undesirable, since in general it is not known beforehand, how many clusters there are. Ideally, the number of clusters should be determined by the data. We already touched upon the difficulties others present. An algorithm which can deal with automatically is desirable. We will see below that strategies have to be managed by careful parameter choices just as we have illustrated the importance of parameters so far.

distribution for process. We now take the view that there is a chance the sample is generated by a completely new process, which is different to the processes which generated the previous samples.

When considering distributions of distributions, we imagined a distribution $G$ over the set of all possible pairs $(\mu, \Sigma)$ which can be generated from the base distribution $G_0$. Since there is only a finite number of clusters, $G$ is zero everywhere apart from the specific pairs $(\mu_k, \Sigma_k)$ where it has a point probability mass $\pi_k$. This view is now changed so that the point probability masses are situated in a set of low locality. In this sea a new probability point can appear, lowering all other probabilities.

It is more convenient to take a sequential view of the generation of samples. For the first sample, a process and its distribution are generated. The second sample can either be generated from the same distribution as the first sample or from a new process. We need to define a probability for these two cases. It is known as dispersion, concentration. Let $\alpha$ be an additional parameter governing this process strength. The probability that the second sample is generated by the first process is $1/(1+\alpha)$, while the probability that it is generated by a new process is $\alpha/(1+\alpha)$. If $\alpha = 1$, then a new process is generated, while for $\alpha < 1$ the existing process is more likely to be used. When generating the $n^{th}$ sample, it is generated by

$$\begin{aligned} k \text{ with probability} &= \frac{n_k}{n+\alpha} \\ \text{new process} &= \frac{\alpha}{n+\alpha} \end{aligned}$$

where $n_k$ denotes the number of samples assigned to cluster $k$ so far.
