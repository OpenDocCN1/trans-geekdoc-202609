
To summarize, the Gaussian mixture algorithm proceeds as follows:

- 1. Choose $K$ and convergence threshold.
- 2. Initialize means $\mu_k$, covariances $\mathbf{\Sigma}_k$, and mixing coefficients $\pi_k$ for $k = 1, \dots, K$, and calculate the initial value of the logarithm of the likelihood according to (6.4).
- 3. For $n = 1, \dots, N$ and $k = 1, \dots, K$, calculate all the responsibilities $p(z_{nk} | V_n)$.
- 4. Use these responsibilities to update means $\mu_k$, covariances $\mathbf{\Sigma}_k$, and mixing coefficients for $k = 1, \dots, K$ according to equations (6.8), (6.9) and (6.6).
- 5. Evaluate the change in the logarithm of the likelihood and terminate if it is below the convergence threshold. Otherwise return step 3.

Alternatively, the algorithm converges, the change in all parameters is below the convergence threshold. It is common to use the $K$ means algorithm to obtain good initializations. We initialize the clusters to centers obtained from the $K$ means, while the covariances are set to the sample variances of the clusters, and the mixing coefficients are initially the fractions of data samples assigned to a particular cluster.

## 6.4 Expectation-Maximization

In this section we introduce a general technique to maximize
$$ \mathcal{L} = \sum_{n=1}^N \log p(\mathbf{v}_n) = \sum_{n=1}^N \log (\sum_{k=1}^K \pi_k p_k(\mathbf{v}_n)) $$
We start by introducing the (6.8), (6.9) and (6.6) for $\mu_k, \Sigma_k$ and $\pi_k$, with respect to $\mu_k, \Sigma_k$ and $\pi_k$, we see that this is the same function. To find the parameters $\mu_k, \Sigma_k, \pi_k$, we set the derivatives to zero, using the fact that the latent variables are not given. However, the derivative of the log-likelihood is difficult to compute directly. We introduce a lower bound on the log-likelihood:
$$ \mathcal{L} \geq \sum_{n=1}^N \log \left( \sum_{k=1}^K \pi_k p_k(\mathbf{v}_n) \right) \geq \sum_{n=1}^N \log \left( \sum_{k=1}^K \pi_k p_k(\mathbf{v}_n) q(z_{nk}) \right) $$
where $q(z_{nk})$ is any distribution over the latent variables $z_{nk}$. The lower bound is given by:
$$ \mathcal{L}(q) = \sum_{n=1}^N \log \left( \sum_{k=1}^K \pi_k p_k(\mathbf{v}_n) q(z_{nk}) \right) + \sum_{n=1}^N \sum_{k=1}^K q(z_{nk}) \log \frac{\pi_k p_k(\mathbf{v}_n)}{q(z_{nk})} $$
The second term is the Kullback-Leibler divergence $D_{KL}(q(\mathbf{z}_n) || p(\mathbf{z}_n|\mathbf{v}_n))$. To maximize the lower bound, we maximize $q(z_{nk})$ for each $n, k$, which leads to
$$ q^*(z_{nk}) = \frac{\pi_k p_k(\mathbf{v}_n)}{\sum_{j=1}^K \pi_j p_j(\mathbf{v}_n)} = p(z_{nk}|\mathbf{v}_n) $$
When $q$ is the posterior distribution, the lower bound becomes exactly the log-likelihood. This leads to the EM algorithm:

- E-step: Calculate the responsibilities $z_{nk} = p(z_{nk}|\mathbf{v}_n)$ using the current parameters.
- M-step: Update the parameters $\mu_k, \mathbf{\Sigma}_k, \pi_k$ by maximizing the lower bound.

The updates are:
- $\pi_k = \frac{1}{N} \sum_{n=1}^N z_{nk}$
- $\mu_k = \frac{\sum_{n=1}^N z_{nk} \mathbf{v}_n}{\sum_{n=1}^N z_{nk}}$
- $\mathbf{\Sigma}_k = \frac{\sum_{n=1}^N z_{nk} (\mathbf{v}_n - \mu_k)(\mathbf{v}_n - \mu_k)^T}{\sum_{n=1}^N z_{nk}}$
