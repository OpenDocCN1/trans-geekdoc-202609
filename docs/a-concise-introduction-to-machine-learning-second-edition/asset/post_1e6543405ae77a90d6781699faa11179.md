
Also the conditional distribution $p(\mathbf{u})$ can be deduced from (7.5) by treating $\mathbf{v}$ as a constant. The quadratic term in $\mathbf{u}$ is

$$\frac{1}{2}\sigma^{-2}\mathbf{u}^T(\mathbf{W}^T\mathbf{W} + \sigma^2\mathbf{I})\mathbf{u}$$

and thus the covariance matrix of $p(\mathbf{u})$ is

$$\Sigma_{\mathbf{u},\mathbf{v}} = \sigma^2(\mathbf{W}^T\mathbf{W} + \sigma^2\mathbf{I}), \quad (7.6)$$

is independent of $\mathbf{v}$. The linear term in $\mathbf{u}$ is

$$\frac{1}{2}\mathbf{u}^T\Sigma_{\mathbf{u},\mathbf{v}}^{-1} = \mathbf{u}^T\sigma^{-2}\mathbf{W}^T(\mathbf{v}-\mu).$$

This needs to equal zero. Therefore, the mean of the conditional distribution

$$\mu_{\mathbf{u},\mathbf{v}} = \Sigma_{\mathbf{u},\mathbf{v}}^{-1}(\mathbf{v}-\mu) = (\sigma^2\mathbf{W}^T\mathbf{W} + \sigma^2\mathbf{I})^{-1}\mathbf{W}^T(\mathbf{v}-\mu), \quad (7.7)$$

which depends on $\mathbf{v}$. The Expectation-Maximization algorithm calculates the expectation of the logarithm of the data likelihood with respect to the conditional probability of the latent variables $\mathbf{u}_1, \dots, \mathbf{u}_N$. The logarithm of the data likelihood is

$$\mathcal{L} = \log \prod_{n=1}^N p(\mathbf{v}_n, \mathbf{u}_n) = \frac{1}{2}\sum_{n=1}^N ((K+D)\log(2\pi) + D\log(\sigma^2) + \mathbf{u}_n^T\mathbf{u}_n - \sigma^{-2}\mathbf{u}_n^T\mathbf{W}^T(\mathbf{v}_n-\mu) - 2\mathbf{u}_n^T\mathbf{W}^T\mathbf{W}\mathbf{u}_n).$$

When taking the expectation with respect to the latent variables we have

$$E[\mathbf{u}_n] = \mu_{\mathbf{u},\mathbf{v}}, \quad (7.8)$$

To find the expectation of the inner product of $\mathbf{u}_n$ with itself we use the cyclic permutation property of the trace and fact the the operations of calculating the trace and expectation continue,

$$E[\mathbf{u}_n^T\mathbf{u}_n] = E[\text{tr}(\mathbf{u}_n\mathbf{u}_n^T)] = \text{tr}(E[\mathbf{u}_n\mathbf{u}_n^T]).$$

Similarly,

$$E[\mathbf{u}_n^T\mathbf{W}^T\mathbf{W}\mathbf{u}_n] = E[\text{tr}(\mathbf{u}_n^T\mathbf{W}^T\mathbf{W}\mathbf{u}_n)] = \text{tr}(\mathbf{W}^T\mathbf{W}E[\mathbf{u}_n\mathbf{u}_n^T]).$$

We can then use (2.10) to calculate

$$\mathbb{E}[\mathbf{u}_n \mathbf{u}_n^T] = \mathbf{\Sigma}_{\mathbf{u}_n} + \mathbb{E}[\mathbf{u}_n]\mathbb{E}[\mathbf{u}_n]^T = \mathbf{\Sigma}_{\mathbf{u}_n} + \mu_{\mathbf{u}_n}\mu_{\mathbf{u}_n}^T. \quad (7.9)$$

The expectation of the logarithm of the joint data likelihood is therefore

$$\mathcal{L} = \frac{1}{2} \sum_{n=1}^N [(K+D) \log(2\pi) + D \log(\sigma^2) + \text{tr}(\mathbb{E}[\mathbf{u}_n \mathbf{u}_n^T]\mathbf{W}^T\mathbf{W}) + \sigma^{-2}(\|\mathbf{v}_n - \mathbf{\mu}\|^2 - 2\mathbb{E}[\mathbf{u}_n]^T\mathbf{W}^T(\mathbf{v}_n - \mathbf{\mu}))].$$ 

Now, employing the cyclic property of the trace, the formulae given in A.2.6 and A.2.9 and the symmetry of $\mathbb{E}[\mathbf{u}_n \mathbf{u}_n^T]$, the derivative with respect to $\mathbf{W}$

$$\frac{\partial\mathcal{L}}{\partial\mathbf{W}} = \frac{1}{2} \sum_{n=1}^N [-2\sigma^{-2}(\mathbf{v}_n - \mathbf{\mu})\mathbb{E}[\mathbf{u}_n]^T + 2\sigma^{-2}\mathbb{E}[\mathbf{u}_n \mathbf{u}_n^T]]$$

Setting this to zero results in an update for $\mathbf{W}$ for it,

$$\mathbf{W}_{new} = \left(\sum_{n=1}^N (\mathbf{v}_n - \mathbf{\mu})\mathbb{E}[\mathbf{u}_n]^T\right) \left(\sum_{n=1}^N \mathbb{E}[\mathbf{u}_n \mathbf{u}_n^T]\right)^{-1} \quad (7.10)$$

Note that this is an update formula, which depends on $\mathbf{W}$ via the conditional mean and covariance matrix in (7.6) and (7.7). On the other hand, differentiating with respect to $\sigma^2$ results in

$$\frac{\partial\mathcal{L}}{\partial\sigma^2} = -\frac{1}{2} \sum_{n=1}^N \frac{1}{\sigma^2} (\|\mathbf{v}_n - \mathbf{\mu}\|^2 - 2\sigma^{-2}\mathbb{E}[\mathbf{u}_n]^T\mathbf{W}^T(\mathbf{v}_n - \mathbf{\mu}) + 2\text{tr}(\mathbf{W}^T\mathbf{W}\mathbb{E}[\mathbf{u}_n \mathbf{u}_n^T]))$$

The update formula for $\sigma^2$ follows

$$\sigma_{new}^2 = \frac{1}{ND}\sum_{n=1}^N [\|\mathbf{v}_n - \mathbf{\mu}\|^2 - 2\sigma^{-2}\mathbb{E}[\mathbf{u}_n]^T\mathbf{W}^T(\mathbf{v}_n - \mathbf{\mu}) + 2\text{tr}(\mathbf{W}^T\mathbf{W}\mathbb{E}[\mathbf{u}_n \mathbf{u}_n^T])] \quad (7.11)$$

It is common to use the already updated value $\mathbf{W}_{new}$, when updating $\sigma^2$. Using (7.9), the update can be written as

$$\sigma_{new}^2 = \frac{1}{ND}\sum_{n=1}^N [\|\mathbf{v}_n - \mathbf{\mu}\|^2 - 2\sigma^{-2}\mathbb{E}[\mathbf{u}_n]^T\mathbf{W}_{new}^T(\mathbf{v}_n - \mathbf{\mu}) + 2\text{tr}(\mathbf{W}_{new}^T\mathbf{W}_{new}\mathbf{\Sigma}_{\mathbf{u}_n} \dots) \dots]$$

This can be interpreted as measuring how close $\mathbb{E}[\mathbf{u}_n]$ is to the sample $\mathbf{v}_n - \mu$ under the mapping given by $\mathbf{W}_{new}$ and how close $\mathbf{W}_{new}^T$ is to the inverse of the conditional covariance matrix, that is, how close it is to the precision matrix.

Another interpretation is as follows. Since the sum of traces is the trace of the sum, we can use inside the trace. Using (7.10) for $\mathbf{W}_{new}$, the sum cancels with its inverse. Further, using the cyclic permutation property of the trace and the fact the trace of a square is scalar, the formula simplifies to

$$\sigma_{new}^2 = \frac{1}{N}\sum_{n=1}^{N} \|\mathbf{v}_n - \mathbf{W}_{new}\mathbb{E}[\mathbf{u}_n]\|^2 \quad (7.12)$$ 

## 7.4 Factor Analysis

Thus noise variance is the average inner product of $\mathbf{v}_n - \mu$ with the difference $\mathbf{v}_n - \mathbf{W}_{new}\mathbb{E}[\mathbf{u}_n]$, scaled by the number of dimensions $D$. It measures how close, on average $\mathbf{W}_{new}\mathbb{E}[\mathbf{u}_n]$ is to the orthogonal projection of $\mathbf{u}_n$ onto the subspace spanned by the columns of $\mathbf{W}_{new}$.

These formulae for $\mathbf{W}_{new}$ and $\sigma_{new}^2$ form the M-step of the Expectation-Maximization algorithm. They are of length $N$, where each element in the M-step can be calculated in $O(KD)$ operations. The overall complexity of the M-step is $O(KND)$.

The E-step calculates $E[\mathbf{u}_n]$ using (7.7) and (7.8) and $E[\mathbf{u}_n \mathbf{u}_n^T]$ using (7.6) and (7.9). The E-step calculates the inverse of a matrix, but this matrix is of size $K \times K$ so this is $O(K^2)$. Calculating this matrix itself is $O(KD)$. If the inverse is found, calculating $E[\mathbf{u}_n]$ is $O(KD)$ and $E[\mathbf{u}_n \mathbf{u}_n^T]$ is $O(KD)$, where $K \leq D$. These need to be calculated for $n=1, \dots, N$ and the complexity for the E-step is $O(KND)$. However, the E-step can be done in parallel for each data point, since $E[\mathbf{u}_n]$ and $E[\mathbf{u}_n \mathbf{u}_n^T]$ can be calculated independently of each other.

While the Expectation-Maximization algorithm is an iterative procedure, the number of iteration is significantly less, if $K \ll D$. This can affect the time due to the iterations against the direct maximization of the log likelihood which has complexity $O(ND^2)$.

So far in this section, $K$ was chosen and not determined by the data. Minka (2000) employs a Bayesian treatment of Principal Component Analysis which determines $K$.

So far the noise was modelled to be that all directions are treated equally. A more suitable model would be to let the noise variance be a diagonal matrix $\mathbf{D}$ that each direction can be treated separately. The diagonal elements of $\mathbf{D}$ are known as *uniquenesses*, while the columns of $\mathbf{W}$ are known as *factor loadings*.
