over all possible solutions. This is called *marginalizing* over **c** and the result is the *marginal* likelihood

```
$$\mathcal{L}(t\mathbf{D}, \alpha, \sigma^2) = \int p(t,\mathbf{D},\mathbf{c}|\alpha, \sigma^2)dc\mathbf{c}$$
```

which we aim to maximize. The Maximum-Likelihood Estimate for **$\alpha$** are the values which maximize $\mathcal{L}(t\mathbf{D}, \alpha, \sigma^2)$. In the following section we revisit a technique to find a maximum.

# 8.12 Expectation–Maximization

In the following we suppress the dependency of the model on the design matrix **D**. The *Expectation-Maximization (EM)* algorithm arrives at a maximum iteratively alternating between two steps. The derivation requires some expansion.

By the *chain rule*, also known as the *product rule*, we have

```
$p(t,\mathbf{c},\sigma^2) = p(t,\mathbf{c}|\alpha, \sigma^2)p(\mathbf{c}|\alpha, \sigma^2)$$
```

Taking the logarithm on both sides results in

```
$log p(t,\mathbf{c},\sigma^2) = \log p(t,\mathbf{c}|\alpha, \sigma^2) + \log p(\mathbf{c}|\alpha, \sigma^2)$$
```

Both sides can be viewed as functions of the random variable **c** and we can take the expectation with regards to any distribution $q(\mathbf{c})$

```
$$\int q(\mathbf{c}) \log p(t,\mathbf{c},\sigma^2)dc\mathbf{c} = \int q(\mathbf{c}) \log p(t,\mathbf{c}|\alpha, \sigma^2)dc\mathbf{c}$$\n$+ \int q(\mathbf{c}) \log p(t|\mathbf{c},\alpha, \sigma^2)dc\mathbf{c}$$\n = \int q(\mathbf{c}) \log p(t,\mathbf{c}|\alpha, \sigma^2)dc\mathbf{c}$$
```

since $q(\mathbf{c})dc = 1$. Rearranging gives

```
$$\log p(t,\alpha, \sigma^2) = \mathcal{L}(t\alpha, \sigma^2) = \int q(\mathbf{c}) \log p(t,\mathbf{c}|\alpha, \sigma^2)dc\mathbf{c}$$\n$- \int q(\mathbf{c}) \log p(t,\mathbf{c}|\alpha, \sigma^2)dc\mathbf{c}$$
```

We can subtract and add the term $q(\mathbf{c})log q(\mathbf{c})$ on the right hand side and arrive at

```
$$\log \mathcal{L}(t\alpha, \sigma^2) = \int q(\mathbf{c}) \log \frac{p(t,\mathbf{c}|\alpha, \sigma^2)}{q(\mathbf{c})}dc\mathbf{c} - \int q(\mathbf{c}) \log \frac{q(\mathbf{c})}{q(\mathbf{c})}dc\mathbf{c} (8.4)$$
```

using the properties of the logarithm. $\mathcal{L}(t\alpha, \sigma^2)$ is also known as the *log likelihood* or *log evidence*.
