Let $x_1^*, \dots, x_{N^*}^*$, be $N^*$ points where $\mathbf{t}^* = (t_1^*, \dots, t_{N^*}^*)^T$ are to be made. The joint distribution of $(\mathbf{t}, \mathbf{t}^*)$ has covariance matrix

```
$$\begin{pmatrix} C & K \ \mathbf{K}^T & C^* \end{pmatrix}$
```

where $\mathbf{C}$ is on base, for $\mathbf{K}$ is a $N 	imes N^*$ matrix with $(n,m)$ entry given by $k(x_n, x_m^*)$ and the $(i,j)$ entry of $\mathbf{C}^*$ is $k(x_i^*, x_j^*) + \sigma^2\delta_{ij}$. The conditional probability distribution of $\mathbf{t}^*$ has mean and variance

```
$\mathbf{m}^* = \mathbf{K}^T\mathbf{C}^{-1}\mathbf{t}$,n$\Sigma^* = \mathbf{C}^* - \mathbf{K}^T\mathbf{C}^{-1}\mathbf{K}$
```

As before, we can draw point values from this distribution and as functions to illustrate draws from the posterior (Gaussian process). Figure 8.13 shows draws using kernels along with four training data points from the function $1+x$, which is shown in red. The mean of the conditional distribution is shown in blue with a band of two standard deviations in grey. The parameters were kept at $	heta=1$. The noise variance was set to 0.01. The distribution is tightened near the training data, while the uncertainty increases away from the training points. In the range between two training points the uncertainty is the largest in data. As can be seen to the right, when training the data distribution becomes the prior of the Gaussian process (as for example in Figure 8.12d (for the Gaussian kernel)) with nodes. The entries of $\mathbf{K}$ are getting close to zero as the distance between points increases, because the Gaussian, exponential and multiplicative kernels decrease as the distance between points increases.

Comparing (8.10 to (8.11)), we see the results when the kernel is chosen to be $k(\mathbf{x}, \mathbf{y})=d(\mathbf{x}, \mathbf{y})^{-1}$. In the previous section, however, the entries of $\mathbf{A}$ were determined by maximizing the log evidence given by (s.8). Similarly, the kernel parameters can be chosen by maximizing the log likelihood of the training data, which is given by

```
$\mathcal{L} = -\frac{1}{2}[log|\mathbf{C}| + \mathbf{t}^T\mathbf{C}^{-1}\mathbf{t} + N\log(2\pi)]$
```

Let $	heta$ be a generic parameter. Using the formulae in A.2.4 and A.2.7 for the derivatives of the determinant and inverse of a matrix, when the entries of the matrix depend on, we arrive at

```
$\frac{\partial}{\partial\theta}\mathcal{L}=-\frac{1}{2}[tr(\mathbf{C}^{-1}\frac{\partial\mathbf{C}}{\partial\theta})-\mathbf{t}^T\mathbf{C}^{-1}\frac{\partial\mathbf{C}}{\partial\theta}\mathbf{C}^{-1}\mathbf{t}]$
```

The $(m,n)$ entry of the derivative of $\mathbf{C}$ with respect to $	heta$ is

