Recall that the variance of *univariate distribution* of the random variable $x$ is given by $	ext{var}[x] = \mathbb{E}[(x-\mathbb{E}[x])^2] = \mathbb{E}[x^2] - \mathbb{E}[x]^2$. The multivariate equivalent is

```
$$\text{var}[\mathbf{x}] = \mathbb{E}[(\mathbf{x}-\mathbb{E}[\mathbf{x}])(\mathbf{x}-\mathbb{E}[\mathbf{x}])^T] = \mathbb{E}[\mathbf{xx}^T] - \mathbb{E}[\mathbf{x}]\mathbb{E}[\mathbf{x}]^T,$ $(2.10)$
```

```
$$\text{var}[x_k] = \text{Cat}(\mathbf{x}|\mu)\mu^T - \mu_k\mu^T = \text{diag}(\mu) - \mu_k\mu^T$
```

follows, where $\mu$ denotes the matrix, where the off-diagonal elements are zero and the diagonal is given by the entries of $\mu$.

Note that the $k^{th}$ diagonal of $	ext{var}[x_k]$ is $\mu_k - \mu_k^2 = \mu_k(1-\mu_k)$. This is the variance of a Bernoulli distribution, where success is defined as the outcome $x_k = 1$ and failure as $x_k = 0$. The $(k,l)$ off-diagonal entry is known as the *covariance* $	ext{cov}[x_k, x_l]$ between $k^{th}$ and $l^{th}$ element and this shows that $k^{th}$ and $l^{th}$ component influence each other in a negative way, if one is one, the other has to be zero.
