The predictive distribution for $t_*$ has variance and mean

```
$$\sigma_*^2 = \sigma^2 + \mathbf{d}(\mathbf{x}_*)^T\mathbf{d}(\mathbf{x}_*)$$
$\sigma_*^2 = \sigma^2 + \mathbf{d}(\mathbf{x}_*)^T(\mathbf{A}-\mathbf{A}^{-1}\mathbf{C}^T\mathbf{D}\mathbf{A}^{-1})\mathbf{d}(\mathbf{x}_*)$$$
$\sigma_*^2 = \sigma^2 + \mathbf{d}(\mathbf{x}_*)^T-\mathbf{v}^T\mathbf{C}^{-1}\mathbf{v} = v - \mathbf{v}^T\mathbf{C}^{-1}\mathbf{v}, \quad (8.11)$$$
$\m_* = \mathbf{d}(\mathbf{x}_*)^T\mu = \sigma_*^2\mathbf{d}(\mathbf{x}_*)^T\mathbf{\Sigma}Dt = \mathbf{v}^T\mathbf{C}^{-1}t,$
```

where we used the fact that $\mathbf{DA}^{-1}\mathbf{C}^T = \mathbf{C}\sigma^2$ in the calculation of the model. Thus $(\mathbf{v}^T\mathbf{C}^{-1}t - t_*^2)$ is the square of the difference of the sample measurement and its predicted by the current model.\nThus, the change in log evidence

```
$$\Delta\mathcal{L} = -\frac{1}{2}[\log 2\pi + \log\sigma_*^2 + \frac{(m_* - t_*)^2}{\sigma_*^2}]$\$
$\Delta\mathcal{L} = \log\frac{1}{\sqrt{2\pi}\sigma_*} \exp(\left(-\frac{(m_* - t_*)^2}{2\sigma_*^2}\right)$
```

Hence the change is the likelihood of the new data value $t_*$ at $\mathbf{x}_*$. given the predictive probability distribution $\mathcal{N}(m_*,\sigma_*^2)$. Since $\sigma_* \ge \sigma$, the change lies from $-\infty$ to $\log(2\pi\sigma^2)^{-1/2}$. It can be positive. In this case, the new sample samples the model. If the likelihood of the data is small, the marginal likelihood is reduced, indicating that the model could be improved. To do so, all quantities must be updated with the new data included.

**New data sample: In this case,

```
$$\Delta\mathcal{L} = \log\frac{1}{\sqrt{2\pi}\sigma_*} \exp(\left(-\frac{(m_* - t_*)^2}{2\sigma_*^2}\right)$$
$\mathbf{\Sigma} = \mathbf{\Sigma} - \frac{1}{\sigma_*^2}\mathbf{d}(\mathbf{x}_*)\mathbf{d}(\mathbf{x}_*)^T\mathbf{\Sigma}$$
$\hat{\mu} = \mu - \frac{1}{\sigma_*^2}\mathbf{d}(\mathbf{x}_*)$
```

The algorithm can continue improving the model by considering the basis functions in turn.\n$\mathcal{N}(m_*,\sigma_*^2)$ Sparse Bayesian infers a predictive distribution for $t_*$ with mean and variance as given in (8.11). This predictive distribution is heavily dependent on the model, since it depends on $\mathbf{d}(\mathbf{x}_*)$ which are the basis functions included in the model evaluated at $\mathbf{x}_*$. It is customary to choose basis functions for the dictionary which decay quickly moving away from the center, or basis functions with finite, compact support.
