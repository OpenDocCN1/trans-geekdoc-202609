The participants are not equally distributed across the age ranges. This can be visualized by plotting the histogram of the participants in the study with regards to their age groups as seen in Figure 2.1.

Ideally we would like the data to be uniformly distributed. That is, each category equally likely. When samples are taken, each category should contain approximately the same number of samples. In many practical situations, when participants are self-selecting, this is not possible. Another oddity about this data is that all ranges encompass ten years, for since the youngest age range only legal adults could take, and at the end of the range, it needs to be ensured there were enough participants in the oldest. These are just some examples of the care which needs to be taken when gathering data.
