# 5.4 Decision Trees

Another intuitive way to classify is using decision trees. These are binary trees consisting of nodes and leaves, also known as terminal nodes. Each nonterminal node has two branches. A sample enters the tree at the root node of the top. At each node, a decision is made on the value of a single feature. If the feature is continuous, the decision is based on the question of whether the value is larger or smaller than a threshold. The sample traverses the tree down to a leaf. Each leaf is associated with a class. Hence, the sample is assigned the class of the leaf it ends up in.

Decision trees are grown recursively from a training set. There are many ways the tree can grow. At each node, the set of training samples reached that node is split in two. To do so, all possible splits for every feature are considered, the optimal split is selected based on criteria. Before we discuss the criteria, we need to introduce some notation. Let $t = P, L$, or $R$ refer to the parent, left or right node, respectively. For example, $N_P$ is the number of samples reaching the parent node, while $N_L$ and $N_R$ are the number of samples reaching the left and right nodes. Let $N_{tk}$ be the number of samples in class $k$, where $k=1,\dots,K$. We define $p_{tk}$ as portion of samples belonging to class $k$ That is

$$p_{tk} = \frac{N_{tk}}{N_P}$$

and we have

$$\sum_{k=1}^{K} p_{tk} = 1$$

The proportions of a node are related to the children of the node in the following:

$$p_{pk} = \frac{N_{Pk}}{N_P} = \frac{N_{Lk} + N_{Rk}}{N_P} = \frac{N_{PLk} + N_{Rk}}{N_P} \quad (5.2)$$

A node is called pure if it contains only samples of one class. However, not all leaves are pure nodes, where the maximum height of the tree is reached in a leaf with samples from a mixture of classes, training samples will be misclassified and generalize poorly to unseen data. We define $i(t)$ as a function of class proportions. Since the two nodes can differ in size, we define the change in impurity $\Delta i$ as child nodes:

$$\Delta i = i(P) - \frac{N_L}{N_P}i(L) + \frac{N_R}{N_P}i(R)$$

The best split maximizes the change in impurity over all possible splits for all features. If no splits are possible, where the change is positive, the node is not split and becomes a leaf.

Figure 5.9: Node impurities for two classes.

Before considering specific choices for $\phi$, it needs to have certain properties:

- Zero for pure nodes: The impurity should be zero if only one class is present. That is $i(t) = 0$, if and only if $p_{k} = 1$ for some $k$, and zero for others.
- Maximal for equal proportions: The impurity should be maximal when all classes are mixed in equal proportions, i.e. $p_{t1} = \dots = p_{TK} = 1/K$.
- Symmetry: It should also be symmetric if the classes are relabeled.

One popular choice for the impurity $i(t) = \phi(p_{t1}, \dots, p_{K})$ is the Gini Diversity Index (GDI)

$$i(t) = \sum_{k=1}^{K} p_{tk}(1-p_{tk}) = 1 - \sum_{k=1}^{K} p_{tk}^2,$$

since $\sum_{k=1}^{K} p_{tk} = 1$. It vanishes, if $p_{tk} = 1$ for some $k$, and zero for all others. Figure 5.9 shows, for two classes, $i(t)$ as a function of $p_{t1}$ (or equivalently $p_{t2} = 1 - p_{t1}$).

With this choice, the change in impurity is

$$\Delta i = \left(1 - \sum_{k=1}^{K} p_{Pk}^2\right)\frac{N_K}{N_P} - \left(1 - \sum_{k=1}^{K} p_{Lk}^2\right)\frac{N_L}{N_P} - \left(1 - \sum_{k=1}^{K} p_{Rk}^2\right)\frac{N_R}{N_P}$$
$= \sum_{k=1}^{K} \frac{N_R}{N_P}p_{Rk}^2 + \frac{N_L}{N_P}\dots,$

where we used $N_L + N_R = N_P$, inserting (5.2) gives

$$\Delta i = \frac{K}{N_P}p_{PR}^2 + \frac{K}{N_P}p_{LK}^2 - \frac{(N_{PLk} + N_{RK})^2}{N_P^2}$$
$$\frac{1}{N_P^2}N_R(N_L+N_R)p_{PR}^k + N_L(N_L+N_R)p_{Lk}^2 - N_{PLk}^2 - 2N_{PLk}N_{Rk} + N_{RK}^2$$
$$\Delta i = \frac{K}{N_P}\sum_{k=1}^K(p_{PLk} - p_{Rk})^2$$

We see that, if the proportions in the child nodes are similar to each other, then the change in impurity will be small. If, however, the proportions are quite different, then $\Delta i$ will be large.

Similar to this, another possibility known as *choosing* the split which maximizes

$$\Delta i = \frac{K}{N_P}\sum_{k=1}^K(p_{PLk} - p_{Rk})^2$$

It is commonly used when there are many classes, $K$ is large. Another choice for $i(t)$ is the *deviance*, also known as *cross-entropy* or log loss,

$$i(t) = -\sum_{k=1}^K p_{tk} \log p_{tk}.$$

It is also plotted in **Figure 5.9**. In this case, we have

$$\Delta i = -\frac{K}{N_P}\sum p_{tk} \log p_{tk} - (\frac{N_L}{N_P}\sum p_{PLk} \log p_{PLk} + \frac{N_R}{N_P}\sum p_{Rk} \log p_{Rk})$$

Using $p_{tk} = N_{tk}/N_P$ and $N_{tk} = N_L + N_R$, this can be rewritten as

$$\Delta i = -\frac{1}{N_P}\sum N_{Lk} \log \frac{p_{Lk}}{p_{tk}} + N_{Rk} \log \frac{p_{Rk}}{p_{tk}}$$

If the proportions remain similar to the proportions in the parent node, then the change in impurity will be small, if the fractions are close to zero and the logarithms evaluates to zero. If, however, the proportions are dissimilar to the ones in its parent node, and especially if they are close to zero in one of the nodes, then $\Delta i$ is larger.

One might consider the node error as a possibility for $i(t)$. If a node is assigned the class with the largest proportion of training samples at that node, the node error is the fraction of misclassified samples:

$$\i(t) = 1 - \max_k p_{tk}.$$
