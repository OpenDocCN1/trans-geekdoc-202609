# 9.2 Error Backpropagation

For all networks, an error function $E(w)$ needs to be minimized. A necessary condition for a minimum is that the gradient $
abla E(w)$ vanishes, where the gradient vector is formed from the derivatives of $E(w)$ with respect to each component of $w$, that is $w_i$. Hence, one possible technique is to first calculate the gradient, set it to zero and solve for it. In most cases this is not feasible. Iterative techniques on the other hand use the fact that the gradient varies for a particular $w$ points in the direction of the steepest ascent. Thus, its negative gives the direction in the function that decreases most rapidly. The simplest iterative technique updates the current weight vector $w$ by a step along the negative gradient;

```
$w^{new} = w - \nabla E(w)$
```

where the step size $\eta > 0$ is called the learning rate. The method is also called steepest descent. There are more sophisticated methods such as *conjugate-gradients* and *quasi-Newton methods*. Optimization is, however, not the purpose of this text. Fletcher (2006) gives a thorough account on this topic.
The error functions all involve a sum over the training data, which can be written as

```
$E(w) = \sum_{n=1}^N E_n(w)$
```

Since the derivative of a sum is the sum of derivatives, it follows

```
$
abla E(w) = \sum_{n=1}^N \nabla E_n(w)$
```

There are now several possibilities to update the weight vector $w$.

+   - Calculating $
abla E_n(w)$ for all $n$ and then using $\nabla E(w)$ in the chosen optimization method, are known as *batch* methods.
