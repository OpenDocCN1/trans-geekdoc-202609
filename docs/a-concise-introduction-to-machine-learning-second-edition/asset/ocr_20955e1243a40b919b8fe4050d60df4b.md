Clustering often is the first step when analysing a new dataset. If not much is known yet about the data, it is useful to see whether the data naturally separates into different groups. The aim is to find clusters where data samples within one cluster are more similar to each other than to samples in other clusters. We will see in the following what means for different algorithms.

There are many application areas. For example, clustering is used to find news articles with similar contents or relating to the same topic. Similarly, search engines using clustering algorithms. It is also used in bioinformatics to analyse biological data of all sorts.



$K$ clustering decides on the number of clusters denoted by $K$ and each data sample is assigned to exactly one cluster. This is known as hard clustering. The aim is to find clusters $\mu_1, \dots, \mu_K$ such that the sum of the squared distances of each data sample to its nearest centre (the one it is assigned to) is minimal. Nearest here is with respect to the Euclidean norm ($L_2$ norm). Thus the objective function is

```
J = \sum_{n=1}^N \min_{k} ||\mathbf{v}_n - \mathbf{\mu}_k\|^2.
```

This optimization problem is NP hard. That is, there is no known algorithm to solve this in polynomial time. This is because clusters move around, for each sample it changes the nearest cluster. The algorithm finds an approximate solution by separating this interdependency with the introduction of hidden (latent) variables $\mathbf{z}_n$, for each data sample $\mathbf{v}_n$. The latent variables are binary vectors, $\mathbf{z}_n \in \{0,1\}^K$, where only one entry is 1 and the others to zero. This is known as a one-of-K representation. A 1 in the $k^{th}$ entry identifies that $\mu_k$ is the nearest cluster centre to $\mathbf{v}_n$. Let $z_{n,k}$ be the $k^{th}$ component of $\mathbf{z}_n$. The objective function can be rewritten as

```
J = \sum_{n=1}^N \sum_{k=1}^K z_{n,k} ||\mathbf{v}_n - \mathbf{\mu}_k\|^2.
```
