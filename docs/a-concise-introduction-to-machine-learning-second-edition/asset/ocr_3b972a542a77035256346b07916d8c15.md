Similarly, the probability distributions $p_k$ are drawn themselves from a probability distribution. It is a distribution over distributions, known as base distribution $G_0$. For example, if each process is a normal distribution with its own mean $\mu_k$ and covariance matrix $\Sigma_k$, these can be drawn from the normal-inverse-Wishart distribution, which has four parameters:

+   * The location fraction $m$ lying in the feature space.
* The mean fraction $\lambda$.
* The inverse scale matrix $\Psi$, which has to be symmetric and positive definite.
* Finally, $
u$ has to be at least the number of dimensions $d$ of the feature space and regulates the degrees of freedom.

The notation is $(\mu_k, \Sigma_k) \sim 	ext{NIW}(m, \lambda, \Psi, 
u)$.

The covariance matrices $\Sigma_k$ follow the *inverse Wishart distribution* given by $
u$ and $\Sigma_k \sim \mathcal{W}^{-1}(\Psi, 
u)$. It has the probability density function

```
$$\mathcal{W}^{-1}(\Sigma_k, \Psi) = \frac{\Psi^{\|\Psi||/2}}{2^{
u d/2}\Gamma(\nu d/2)}} \Sigma_k^{-(\nu+d+1)/2} \exp\left(-\frac{1}{2}\text{tr}(\Psi\Sigma_k^{-1})\right), \quad (6.11)$
```

where $|cdot|$ denotes the determinant and $tr(\cdot)$ denotes the trace of a matrix. $\Gamma_d$ is the multivariate gamma function

The expectation of the inverse Wishart distribution is given by

```
$E[\Sigma_k] = \frac{\Psi}{\nu-d-1}$
```
