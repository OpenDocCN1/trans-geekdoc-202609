To approximate the extremum, we set this to zero and multiply through $\mathbf{\Sigma}_k$ which is nonsingular, since it is a covariance matrix:

$$\sum_{n=1}^N p(z_{n,k}=1|\mathbf{v}_n)(\mathbf{v}_n - \mu_k) = 0.$

We define

$$\mathbf{N}_k = \frac{1}{2} \sum_{n=1}^N p(z_{n,k}=1|mathbf{v}_n),$$

which is comparable to the expected number of samples in cluster $k$. With this definition

$$\mu_k = \frac{1}{\mathbf{N}_k} \sum_{n=1}^N p(z_{n,k}=1|\mathbf{v}_n)\mathbf{v}_n. \quad (6.8)$

We see that $\mu_k$ is a weighted average of all samples in the dataset where the weights are the responsibilities that the sample was generated by process $k$. It is reminiscent of formula (4.1) for the sample mean.

To maximize with respect to the covariance $\mathbf{\Sigma}_k$, we need the derivative of $p_k(\mathbf{v})$ with respect to $\mathbf{\Sigma}_k$. Using the product and chain rule and the differentiation rules in A.2.4 and A.2.8, we have

$$\frac{\partial}{\partial\mathbf{\Sigma}_k} p_k(\mathbf{v}) = -\frac{1}{2} p_k(\mathbf{v}) [\mathbf{\Sigma}_k^{-1} - \mathbf{\Sigma}_k^{-1}(\mathbf{v} - \mu_k)^T\mathbf{\Sigma}_k^{-1}],$$

since $\mathbf{\Sigma}_k^{-1}$ is symmetric. From this we derive the derivative of the logarithm of the likelihood given in (6.4) as

$$\frac{\partial}{\partial\mathbf{\Sigma}_k} \mathcal{L} = \frac{1}{2} \sum_{n=1}^N p(z_{n,k}=1|\mathbf{v}_n) [\mathbf{\Sigma}_k^{-1} - \mathbf{\Sigma}_k^{-1}(\mathbf{v}_n - \mu_k)^T\mathbf{\Sigma}_k^{-1}],$$

As before, we approximate the extremum by setting the derivative to zero and multiplying through $\mathbf{\Sigma}_k$, but this from both sides:

$$\sum_{n=1}^N p(z_{n,k}=1|\mathbf{v}_n) [(\mathbf{v}_n - \mu_k)(\mathbf{v}_n - \mu_k)^T] = 0.$

Solving for $\mathbf{\Sigma}_k$, we arrive at

$$\mathbf{\Sigma}_k = \frac{1}{\mathbf{N}_k} \sum_{n=1}^N p(z_{n,k}=1|\mathbf{v}_n)(\mathbf{v}_n - \mu_k)^T. \quad (6.9)$

The formula is very similar to (4.2) for the sample covariance. The main difference is that we sum over all samples and that each sum is weighted by the responsibility that process $k$ generated this sample.
