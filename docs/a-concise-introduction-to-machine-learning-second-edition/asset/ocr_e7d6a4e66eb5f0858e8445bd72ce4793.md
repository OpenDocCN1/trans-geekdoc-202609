Again, integrating by substitution and differentiating with respect to $y$ gives

$f_y(y) = -f_x(g^{-1}(y))(g^{-1})'(y)$.

Since $g$ is decreasing, so $g^{-1}$ and its derivative is negative. This makes the expression overall positive.
Since the strictly increasing case the derivative of $g^{-1}(y)$ is always positive, both cases can be summarized as

$f_y(y) = f_x(g^{-1}(y)) |(g^{-1})'(y)| = f_x(g^{-1}(y)) \left|\frac{dx}{dy}\right|$ \quad (2.17)

where the last uses a common shorthand notation. This is known as change-of-variable technique, in its derivation, we change the variable in the integral. Another name is method of direct transformation.
We illustrate the case when g is not a one-to-one transformation, by an example first. Let $x$ follow the normal distribution $N(0,1)$ and let $y=x^2$. While $-\infty < x < \infty$, we have $0 \le y < \infty$. Each value of $y$ is generated by two values $x_1 = -\sqrt{y}$ and $x_2 = \sqrt{y}$. Taking the same approach as
