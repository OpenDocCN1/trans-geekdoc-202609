## 8.1 Problem description

Given scalar measurements $t_1, \dots, t_n$, each measurement depends on parameters $x_1, \dots, x_n$. In the previous example, these are the intensities of red, green, blue. These are quantities which can be measured with more or less effort. For example photocells, geophones, PET and MRI neuro-imaging, EEG technology, etc. The Machine Learning technique has to achieve in its task to create a model for the relationship between variables and colour. We assume that the measurements are the result of underlying processes following laws. In some applications, especially physical ones, these laws are known, and for example described by partial equations, but then specific parameters are not known. Sometimes nothing is known and we have to find out this. For applications, incorporate human interactions the financial markets, it is inherently difficult to infer underlying processes. For example the physics of waves are well understood. However, they depend on the mixture of media the wave travels in, their properties, as well as their interfaces.

If we had a solution to the underlying process, we could predict the measurement from a function $t(x)$

$t_n = f(x_n),$

where parameters of the function depend on the process. On the other hand, if we had a set of candidate functions $d_1(x), \dots, d_M(x)$, we could try which fits the measurements, and thus infer the underlying process. We say the functions $d_1(x), \dots, d_M(x)$ form a dictionary and let

$f(x) = \sum_{m=1}^M c_m d_m(x),$

be an approximation to $t(x)$, where $c_1, \dots, c_M$ are coefficients, and this need to be determined. The dictionary defines a model space in which ideally the true $t(x)$ lies. That the underlying process can be described entirely by the dictionary. In an ideal world, the approximation $f(x)$ obtained in the model space should be close enough to the true solution $t(x)$. We will refer to $f(x)$ as our model describing the data.

## 8.2 Linear Regression

Often the term linear regression refers to fitting a straight line to the data. More generally, however, the term linear means that the model is a sum of building blocks with suitable coefficients, a linear combination. This gives us flexibility in the choice of building blocks. They can be nonlinear functions. It also gives us flexibility in the choice of noise model and in the method to determine the coefficients.

Linear regression developed in several fields. Therefore the terminology is varied. There first is the scalar function $t$, also known as *dependent, endogenous, response, measured, criterion variable, or regressor or target*. In the previous example this is the colon:

The $d_1(x), d_m(x)$ are known as *independent, exogenous, input, explanatory variables or regressors*. Remember that $d_m$ is not a coordinate of a vector. It is a basic function.

The coefficients $c_1, \dots, c_M$ are also referred as as *parameter vector or vector of weights*, also known as *regression coefficients*. They can also be viewed as *latent variables*. Regression determines these by various techniques.

The relationship to the measurements is

$t_n = f(\mathbf{x}_n) + \epsilon_n,$

where $\epsilon_n$ is noise intrinsic to the process and assumed to be independent and identically distributed (i.i.d.) following the normal distribution $\mathcal{N}(0, \sigma^2)$. This is known as *homoscedastic*. Note that the assumption of the noise variance for each measurement might be wrong for two reasons. Firstly, there might be different sources of the noise with different effects. In this case the noise is modeled by a mixture of probability distributions. Secondly, restrictions on the data might make different noise distributions necessary. For example if it is all data samples are always positive, the noise variance for smaller values has to be smaller to ensure positive predicted values.
