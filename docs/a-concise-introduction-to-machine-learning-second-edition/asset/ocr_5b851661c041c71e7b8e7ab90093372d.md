The moments can be calculated from data samples and used to inform the choice of probability density function for the distribution of a random variable.

More generally, often the random variable itself is not of interest, but a derivation $g(x)$ of it, which in itself is a random variable. In this case, the expectation and variance are written as $E[g(x)]$ and $Var[y]$.

If there are more than one random variables, a subscript is used to indicate with respect to which variable the expectation is taken. For example,

```
$E_y[g(x, y)]$
```

the expectation is taken with respect to $y$, and the result is a function of $x$. The expectation with respect to $x$ can then be. Since the order does not matter when integrating or summing, the result is the same if the expectation with respect to $x$ is taken first and then with respect to $y$, if $x$ and $y$ are independent, that is $f(x, y) = f(x)f(y)$.

Returning to the normal distribution, we calculate the expectation (first moment) as

```
$E[X] = \int_{-\infty}^{\infty} \frac{x}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right) dx.$
```

Let $y = x - \mu$ with $dy = dx$, the result of integration with this change of variable remains as

```
$E[X] = \int_{-\infty}^{\infty} \frac{y+\mu}{\sqrt{2\pi}\sigma} \exp\left(-\frac{y^2}{2\sigma^2}\right) dy\n = \int_{-\infty}^{\infty} \frac{y}{\sqrt{2\pi}\sigma} \exp\left(-\frac{y^2}{2\sigma^2}\right) dy + \mu \int_{-\infty}^{\infty} \frac{1}{\sqrt{2\pi}\sigma} \exp\left(-\frac{y^2}{2\sigma^2}\right) dy.$
```

The integrand of the first integral is an odd function, that $f(-y)=-f(y)$. Integr of odd functions over an interval symmetric about the origin evaluate to zero. The second integral evaluates to one, since it integrates the probability density function of a normal distribution with zero mean and variance $\sigma^2$ over the entire range. For the variance we calculate

$Var[x] = $

```
$Var[x] = \int_{-\infty}^{\infty} \frac{(x-\mu)^2}{\sqrt{2\pi}\sigma} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right) dx.$
```

Again letting $y = x - \mu$ as before, we have

```
$Var[x] = \int_{-\infty}^{\infty} \frac{y^2}{\sqrt{2\pi}\sigma} \exp\left(-\frac{y^2}{2\sigma^2}\right) dy.$
```

This integral can be calculated by *integration by parts* which can be thought of as the inverse of the *product rule of differentiation* which is

```
$d(uv) = \frac{du}{dy}v + u\frac{dv}{dy}$.
```
