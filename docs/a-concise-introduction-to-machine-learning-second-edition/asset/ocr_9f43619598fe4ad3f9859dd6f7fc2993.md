this simplifies to

```
$E_n = \int p_{\phi}(\mathbf{z}^{(L/2)}|\mathbf{x}_n) \left[-log \frac{p(\mathbf{z}^{(L/2)})}{p_{\phi}(\mathbf{z}^{(L/2)}|\mathbf{x}_n)} - \log p(\mathbf{x}_n|\mathbf{z}^{(L/2)})\right] d\mathbf{z}^{(L/2)}\n= D_{KL}(p_{\phi}(\mathbf{z}^{(L/2)}|\mathbf{x}_n) || p(\mathbf{z}^{(L/2)}))\n- \int p_{\phi}(\mathbf{z}^{(L/2)}|\mathbf{x}_n) \log p(\mathbf{x}_n|\mathbf{z}^{(L/2)}) d\mathbf{z}^{(L/2)}$
```

The first term is the KL divergence between the normal distribution with $\mu(\mathbf{x}_n)$ and variance $\Sigma(\mathbf{x}_n)$ and the standard normal distribution which is the prior of $\mathbf{z}^{(L/2)}$. This is given by

```
$D_{KL}(p_{\phi}(\mathbf{z}^{(L/2)}|\mathbf{x}_n) || p(\mathbf{z}^{(L/2)})) =\n\frac{1}{2}\sum_{m=1}^2 [\text{Tr}(\Sigma(\mathbf{x}_n)) + \mu(\mathbf{x}_n)^T\mu(\mathbf{x}_n) - M_{L/2} - \log |\Sigma(\mathbf{x}_n)|]$
```

where the last equation is due to choosing the variance to have diagonal form.
The second term is the negative expectation of $\log p(\mathbf{x}_n|\mathbf{z}^{(L/2)})$ with respect to $\mathbf{z}^{(L/2)}$. $\mathbf{x}_n = \mu(\mathbf{x}_n)+\Sigma^{1/2}(\mathbf{x}_n)\eta$, where $\eta$ follows the standard normal distribution and is sampled in additional input neurons. It is therefore crucial to enrich the training with samples drawn from the standard normal distribution to arrive at new training samples $\mathbf{x}_{nk} = (\mathbf{x}_n, \eta_k)$ for $n=1,\dots,N$ and $k=1,\dots,K$ for some chosen constant. The second term is estimated as

```
$\sum_{k=1}^K \log p(\mathbf{x}_n|\mu(\mathbf{x}_n) + \Sigma^{1/2}(\mathbf{x}_n)\eta_k)$
```

Each term in the sum over $k$ is treated separately in the error function. Removing constant terms, the $nk^{th}$ term of the error function, which needs to be minimized,

```
$E_{nk} = \frac{1}{2}\sum_{m=1}^2 [\sigma_m^2(\mathbf{x}_n) + \mu_m^2(\mathbf{x}_n) - \log \sigma_m^2(\mathbf{x}_n)]\n+ \frac{1}{2}|\mathbf{x}_n - \mu(\mathbf{x}_n) + \Sigma^{1/2}(\mathbf{x}_n)\eta_k|^2.$
```

This is continuous and therefore error backpropagation be used to calculate gradients to be used in the minimization as explained in Section 9.2.
