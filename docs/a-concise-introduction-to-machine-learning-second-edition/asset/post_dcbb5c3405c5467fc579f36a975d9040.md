# 3.3 Importance Sampling

One reason for sampling is to approximate a multidimensional expectation of some function $h$ of the random variable vector $x$ by

```
$E[h] = \int h(x)f(x)dx \approx \frac{1}{N} \sum_{n=1}^{N} h(x_n),$
```

where $x \in \mathbb{R}^d$, and $x_n \in \mathbb{R}^d, n=1,\dots,N$ are drawn from the probability density function $f$. However, this is not suitable when sampling from $f$ is not possible or computationally expensive. A possible solution is not to sample, but to weigh each $h(x_n)$ by $f(x_n)$,

```
$E[h] \approx \sum_{n=1}^{N} f(x_n)h(x_n),$
```

where $x_n, n=1,\dots,N$ are selected in some way. A naive approach would be to select them uniformly. Firstly, in this case $N$ grows with the number of dimensions $d$ to achieve a good approximation. Secondly, this neglects the fact, that in many cases the regions of interest, that where the probability density function concentrates its mass, are relatively small. *Importance sampling* uses a proposal distribution $g$ which focuses attention onto regions of interest which can be easily sampled. It does not need to be an envelope of $f$. The samples $x_1,\dots,x_N$ are drawn from the proposal distribution. Then

```
$E_f[h] = \int h(x)f(x)dx = \int \frac{f(x)}{g(x)}g(x)dx$
$E_g[h] \approx \frac{1}{N} \sum_{n=1}^N h(x_n).
```

where

where we used subscripts to indicate with respect to which probability density function expectation is taken. All generated samples, unlike rejection sampling, are used. The factors $f(x_n)/g(x_n)$ are known as importance weights. They are a correction to the wrong distribution. For example, if $g$ falls $f$ in a region, this factor is one and no correction is necessary. However, if $g$ is large in a region where $f$ is small, the contribution of evaluating $h$ needs to be reduced. On the other hand, if $g$ is small in a region where $f$ is large and we happen to sample there, the value of $h$ needs to be magnified. In the case,

```
$f(x) = \frac{1}{c}f(x)$ and $g(x) = \frac{1}{c}g$
```

and the normalizing constants

```
$c_f = \int_{-\infty}^{\infty} f(x)dx$ and $c_g = \int g(x)dx$
```

are unknown, the calculation becomes

```
$E_f[h] = \int h(x)f(x)dx = \frac{c_g}{c_f} \int \frac{f(x)}{g(x)}g(x)dx$
$E_g[h] \approx \frac{c_g}{c_f} \frac{1}{N} \sum_{n=1}^N h(x_n).
```

Even with the normalizing constants, we can estimate their ratio. Using $c_g = g(x)/g(x)$ where $g(x)$ is nonzero, we have

```
$\frac{c_f}{c_g} = \frac{1}{c_g} \int f(x)dx = E_g[h] \approx \frac{1}{N} \sum_{n=1}^N h(x_n).
```

With this result, the expectation is estimated as

```
$E_f[h] = \frac{\frac{1}{N} \sum_{k=1}^N f(x_k)h(x_k)}{\frac{1}{N} \sum_{k=1}^N f(x_k)}$
```

The importance weights are

```
$w_n = \frac{f(x_n)/g(x_n)}{\sum_{k=1}^N f(x_k)/g(x_k)} = \frac{f(x_n)/g(x_n)}{\sum_{k=1}^N \hat{f}(k)}, \quad (3.4)$
```

since $f$ and $g$ only differ by a multiplicative constant. Note that if the proposal distribution coincides with $f$, then we have $w_n = 1/N$. As rejection sampling, it should be clear that the proposal distribution is crucial. Most importantly, it should not be in small regions where $f$ is large. The weighting is useless if an actual sample is drawn from a region $g$. *Sampling-importance-sampling (SIR)* combines from rejection sampling and importance sampling. $N$ samples $x_1,\dots, x_N$ are drawn from the proposal distribution $g$. Instead of rejecting $N$ samples with replacement are drawn from the discrete set $\{x_1,\dots, x_N\}$ according to the probabilities given by $w_1,\dots, w_N$. Thus a sample can feature several times in the final set, if its weight is larger than the weights of the other samples. If $g=f$, then all weights will equal $1/N$ and all samples are equally likely to be drawn.

# 3.4 Markov Chains

Markov chains are important building blocks for a class of sampling algorithms which can be applied to many different distributions and also scale with dimensionality.

*A Markov chain* is a series of random variables $x_1, \dots, x_N$ *called states*. The indices are associated with a sequence in time. A Markov chain of order $m$ satisfies the following

$p(x_n|x_{n-1}, \dots, x_1) = p(x_n|x_{n-1}, x_{n-2}, \dots, x_{n-m})$

for $n = m+1, \dots, M$. In particular, the $n^{th}$ random variable only depends on the $m$ previous variables. A first-order Markov chain satisfies

$p(x_n|x_{n-1}, x_{n-2}, \dots, x_1) = p(x_n|x_{n-1})$.

Each random variable depends only on its predecessor. We will only consider first-order Markov chains, since any Markov chain of order $m$ can be transcribed into a first-order Markov chain by the tuple $(y_n, \dots, y_{n-m+1})$, where $p(y_n|y_{n-1}, \dots, y_k) = p(y_n|y_{k-1})$.

The probability distribution of the variable $x_1$ needs to be specified. The probabilities $T_n(x_n|x_{n-1})$ are called transition probabilities from state $n-1$ to state $n$. If they are the same for all $n$, i.e. $T_n(x_n|x_{n-1}) = T(x_n|x_{n-1})$ for all, then the Markov chain is called homogeneous.
