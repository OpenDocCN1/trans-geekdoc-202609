The covariance matrix is of general *positive definite*, since

```
$$\mathbf{v}^T \mathbf{\Sigma}_{\mathbf{v}} = \frac{1}{N_i} \sum_{\mathbf{v} \in C_i} \mathbf{v}^T (\mathbf{v} - \boldsymbol{\mu}_i)(\mathbf{v} - \boldsymbol{\mu}_i)^T \mathbf{v} = \frac{1}{N_i} \sum_{\mathbf{v} \in C_i} (\mathbf{v} - \boldsymbol{\mu}_i)^T \mathbf{v}^2 \ge 0$.
```

It is unlike that the sum of squares equals zero, since this means that all samples shifted by the mean line in a space orthogonal to $\mathbf{v}$. In this case, one of the dimensions of the feature space is redundant, and *dimensionality reduction* should be performed first. Positive definiteness implies that the matrix is nonsingular and can be inverted.

Let w be the direction of projection. The location of the line of projection is neglected, since it cancels in the calculations. The mean of the projected samples in class $C_i$ is given by $\mathbf{w}^T \boldsymbol{\mu}_i$, while the variance of the projected samples in class $C_i$ is given by $\mathbf{w}^T \mathbf{\Sigma}_i \mathbf{w}$. We see that with

```
$$\mathbf{w}^T \mathbf{\Sigma}_{01} \mathbf{w}\|^2 = \mathbf{w}^T (\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)(\boldsymbol{\mu}_0 - \1)^T$.
```

is as large as possible. The projected means are as far apart as possible. This is known as the *between-class scatter* of the projected samples. At the same time, we

```
$$\mathbf{w}^T \mathbf{\Sigma}_0 \mathbf{w} + \mathbf{w}^T \mathbf{\Sigma}_1 \mathbf{w} = \mathbf{w}^T (\mathbf{\Sigma}_0 + \mathbf{\Sigma}_1) \mathbf{w}$
```

as small as possible, the projected samples are close to the projected mean. This is known as the *within-class scatter* of the projected samples. Depending on $\mathbf{w}$, Fisher (1936) defining the *separation* $\mathbf{w}$ achieves by

```
$$\mathbf{w}^T (\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)^T \mathbf{w} / \mathbf{w}^T (\mathbf{\Sigma}_0 + \mathbf{\Sigma}_1) \mathbf{w}$
```

This function to be maximized. In other words, we maximize the ratio of the between-class scatter to the within-class scatter. The gradient $\nabla_{\mathbf{w}}w$ is the vector formed by the derivatives of $w(\mathbf{w})$ with respect to each of the components. Using the quotient rule of differentiation, the formula given in [Appendix A.2] and by the symmetry of covariance matrices and outer products, the result is given by

```
$$\mathbf{w}^T (\mathbf{\Sigma}_0 + \mathbf{\Sigma}_1) \mathbf{w} (\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)^T \mathbf{w} - (\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)^T \mathbf{w}^2 (\mathbf{\Sigma}_0 + \mathbf{\Sigma}_1) \mathbf{w} / 2 = 2 \frac{\mathbf{w}^T (\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)^T \mathbf{w}}{\mathbf{w}^T (\mathbf{\Sigma}_0 + \mathbf{\Sigma}_1) \mathbf{w}} \frac{(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)^T \mathbf{w}}{\mathbf{w}^T (\mathbf{\Sigma}_0 + \mathbf{\Sigma}_1) \mathbf{w}} (\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)$.
```

Setting this to zero and rearranging, we arrive at:

```
$$\mathbf{w}^T (\mathbf{\Sigma}_0 + \mathbf{\Sigma}_1) \mathbf{w} / (\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)^T \mathbf{w} = (\mathbf{\Sigma}_0 + \mathbf{\Sigma}_1)^{-1} (\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)$.
```
