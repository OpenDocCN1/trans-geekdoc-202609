Techniques are illustrated by MATLAB^1 programming language. The main purpose is to show the inner workings of the method in order to develop an intuition. Listings are printed in the book alternating between the two languages, but all are available online at https://github.com/ACFaul/tab-repositories. The Python^2 language examples are Jupyter^3 notebooks which can be run online in Binder^4 by clicking the launch button in the repository's README. Thus, there is no need to install and get used to a development environment in order to learn.
