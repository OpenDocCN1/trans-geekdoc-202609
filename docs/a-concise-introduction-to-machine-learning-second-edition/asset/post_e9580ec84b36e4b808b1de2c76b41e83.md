The variance of each element $\Sigma_{ij}$ of $\Sigma$ is calculated as

```
$var[\Sigma_{ij}] = \frac{(u-1)\Psi_{ij} + (u-1)\Psi_{ji}}{(\nu-1)^2(\nu-3)} = var[\Sigma_{ji}],
```

where $\Psi$ is symmetric. On the diagonal, as $i = j$, this simplifies to

```
$var[\Sigma_{ii}] = \frac{2\Psi_{ii}}{(\nu-1)^2(\nu-3)}$
```

Since $\nu$ appears several times in the denominator, it controls the variability in the generated datasets and in turn the variability decreases as $\nu$ increases. Figures 6.6 and 6.7 show the differences in generated datasets for $u=2$ (the smallest possible choice), $u=10$ for constant $\lambda=1$, and $\Psi = \left(\begin{matrix} 1 & 3/2 \\ 3/2 & 1 \end{matrix}\right)$.

Looking at the axes in Figure 6.6, the generated datasets are indeed different in nature. In Figure 6.7, on the other hand, in particular, the data seem to come from the base distribution specified by $\mu$ and $\Psi$, and if we write that $\Psi$ is the conjugate prior for the covariance matrix $\Sigma$ of a multivariate distribution with a known mean.

The Wishart distribution $W(\Psi, \nu)$ is the conjugate prior for the covariance matrix $\Sigma$ of a multivariate distribution with a known mean. The least informative choice for $\nu$ in the prior is $\nu=d$. We can assume that the mean of this distribution is zero, we can recreate the data by subtracting the mean from all samples. Let $D \{\mathbf{v}_1, \dots, \mathbf{v}_N\}$ be draws from $N(\mathbf{0}, \Sigma)$. The likelihood of this data is given by

```
$$\prod_{n=1}^N \sqrt{(2\pi)^d|\Sigma|} \exp\left(-\frac{1}{2}\mathbf{v}_n^T \Sigma^{-1} \mathbf{v}_n\right) = (2\pi)^{-ND/2}|\Sigma|^{-N/2} \exp\left(-\frac{1}{2}\sum_{n=1}^N \mathbf{v}_n^T \Sigma^{-1} \mathbf{v}_n\right)$$
```

The posterior distribution of $\Sigma$ is proportional to the product of the likelihood and the prior probability density function given in (6.11) by Bayes' rule. Because of the proportionality, we drop all multiplicative constants in both. These are the factors $(2\pi)^{nd/2}$, $|\Psi|^{p/2}$, $u^{-d/2}$ and $1/\Gamma_d(u)$. Hence, the posterior is proportional to

```
$|\Sigma|^{N/2} \exp \left(-\frac{1}{2}\sum_{n=1}^N \mathbf{v}_n^T \Sigma^{-1} \mathbf{v}_n\right) |\Sigma|^{-(v+d)/2} \exp \left(-\frac{1}{2}\text{tr}(\Sigma^{-1})\right)$
```

To simplify this, we use properties of determinants and traces of matrices. The product of determinants of two matrices is the determinant of product of matrices. Therefore, $|\Sigma|^{N/2}|\Sigma|^{-(v+d)/2} = |\Sigma|^{-(N+v+d)/2}$. The expression $\sum_{n=1}^N \mathbf{v}_n^T \Sigma^{-1} \mathbf{v}_n$ is a scalar and the trace of a scalar is the scalar itself. Further the trace is invariant to a cyclic permutation of the order of multiplication. Hence, $\sum_{n=1}^N \mathbf{v}_n^T \Sigma^{-1} \mathbf{v}_n = \text{tr}(\Sigma^{-1} \sum_{n=1}^N \mathbf{v}_n \mathbf{v}_n^T)$. Using these identities, the posterior is proportional to

```
$|\Sigma|^{-(N+v+d)/2} \exp \left(-\frac{1}{2}\text{tr}\left((\mathbf{\Psi} + \sum_{n=1}^N \mathbf{v}_n \mathbf{v}_n^T\right) \Sigma^{-1}\right)\right)$
```

since the sum of traces is the trace of sum of matrices. Apart the normalizing constant, this is exactly the probability density function

```
$$\mathcal{N}\left(\mathbf{0}, \mathbf{\Psi} + \sum_{n=1}^N \mathbf{v}_n \mathbf{v}_n^T\right)$$
```

To summarize, the inverse scale matrix is updated to $\mathbf{\Psi} + \sum_{n=1}^N \mathbf{v}_n \mathbf{v}_n^T$. As this increases, the estimate for the distribution $\Sigma$ decreases, the more samples are seen. A new iterate of $\Sigma$ is drawn from this distribution with mean $\mu$ and covariance $\frac{1}{\lambda}\Sigma$. The parameter $\lambda$ controls the scaling of the generated $\mu_k$. Figure 6.8 illustrates the effect of $\lambda=1, 1/3, 1/5$ for $\alpha=10, k=2$; the clusters separate more and more. Generated by the function in Listing 6.4 to 6.8, the data is generated from following distributions:

```
$$\mathbf{v}_n | z_n=k \sim \mathcal{N}(\mu_k, \Sigma_k)$$
$$\pi \sim \text{Dir}(\alpha)$$
$$\mu_k, \Sigma_k \sim G_0 = \text{NIW}(\mathbf{m}, \lambda, \Psi, \nu)$$
```

import numpy as np
import scipy.stats as st
import matplotlib.pyplot as plt

# Function to generate samples.
def Bayesianmixture(size, n_components, alpha0, mean, lambda0, df=None):
    """
    size: number of data points,
    n_components: number of clusters
    alpha0: concentration parameter,
    mean: location vector,
    lambda0: mean fraction,
    scale: scale matrix,
    df: degrees of freedom.
    Returns
    data: data vector,
    cov: matrix which process,
    mean: array of the processes,
    cov: array of covariance matrices of processes.
    """
    # Generate mixture coefficients for cluster membership.
    alpha = alpha0 * np.ones(n_components)
    pi = np.random.dirichlet(alpha, size)
    # Generate latent variable for cluster membership.
    ida = np.random.multivariate_normal(mean, size)
# Allocate space for the parameters of the distributions.
    cov = np.eye(n_components) * lambda0
    mean = np.zeros((n_components, 2))
    # Generate data for each cluster.
    for i in range(n_components):
        cov[i], mean[i] = st.random.rvs(df, multivariate_normal(mean=mean[i], cov=cov[i], size=size))

    # Generate samples.
    for i in range(size):
        data[i] = np.random.multivariate_normal(mean=mean[ida[i]], cov=cov[ida[i]])
    return data, ida, pi, mean, cov

# Sample size:
size = 1000
# Hyperparameters:
# Change to explore how they influence the data samples.
k = 3
mean = np.array([[0, 0]])
lambda0 = 1
Psi = np.random.uniform([1, 1], [1.5, 3])

This can be viewed without involving the latent variables $\mathbf{z}_\alpha$. Imagine a distribution $G$ over the set of all possible pairs of $(\mu, \Sigma)$ which can be generated from $G_0$. Since there is only a finite number of clusters, $G$ is zero everywhere apart from the specific pairs $(\mu_k, \Sigma_k)$ where it has a point probability mass of $\pi_k$.

Using this distribution $G$, the generation of data can be described as:

```
$$\mathbf{v}_n \sim \mathcal{N}(\mu_k, \boldsymbol{\Sigma}_k)$$
$$\pi \sim \text{Dir}(\alpha)$$
$$\mu_k, \boldsymbol{\Sigma}_k \sim G$$
```
