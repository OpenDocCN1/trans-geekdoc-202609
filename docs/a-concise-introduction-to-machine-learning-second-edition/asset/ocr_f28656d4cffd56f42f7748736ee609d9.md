# # Sampling

In the previous chapter, we have seen how data is used to estimate the parameters of the assumed underlying distribution generating the data $D$ using Bayes' rule. For example, let $	heta_1$ be the vector of all parameters governing the distribution and $	heta_2$ the vector of all hyperparameters governing the prior distributions for the parameters $	heta_1$. Then the posterior is given by

```
$f(\theta_1|D, \theta_2) = \frac{p(D)f(\theta_1, \theta_2)}{\int p(D)f(\theta_1, \theta_2)d\theta_1} \quad (3.1)$
```

Unless we are with conjugate probability distributions, no closure might exist. It might not be possible to evaluate the integral in the denominator.

Note that, by the product rule, the integrand is the joint probability density of $D$ and $	heta_1$, conditioned on $	heta_2$, i.e. $f(D,\theta_1|\theta_2)$. This means the denominator is the marginal distribution $f(D|\theta_2)$, where the dependency on $	heta_1$ has been integrated out.

Another way of interpreting the integral is that it is the expectation of the function $p(D|\theta_1)$ with respect to the distribution described by the probability density function $f(\theta_1|\theta_2)$. We already encountered a similar situation in Equation (2.18), when attempting to derive the probability density of a random variable which is a function of two other random variables. The outer integral can be interpreted as the expectation of the function given by the inner integral with respect to the probability density function in the outer integral.
