## 9.5 Relationship to Other Techniques

In this section, we examine how neural networks relate to some of the techniques we have seen before. We already touched on this in Section 5.5 with regards to classification where a neural network describes different regions as sets of points lying on different sides of a set of lines.

In Chapter 8, the assumption is that all samples are generated by an underlying process of the form

```
t = Dc + \epsilon
```

where $\epsilon$ is additive Gaussian noise with zero mean and variance $\sigma^2$, the $D \times M$ matrix **D** is the design matrix, **c** is the vector of coefficients, which depends on both **D** and **t**.

Recall the prediction of the ordinary least squares solution, where **D** is chosen beforehand,

```
Dc = D(D^T D)^{-1}D^T t
```

Schematically, this can be visualized as

![](img/c6c76bf52016db7e78a5e30d4766ef81_331_0.png)

This is reminiscent of a three layer neural network with sets of hidden neurons and the linear activation function, which is the identity, each neuron. The weights of the synapses from the input to the first set of hidden neurons, the weights of the synapses from the first to the second set of hidden neurons are given by the entries of the matrix $D^T$, while the weights of the synapses from the second set of hidden neurons to the output neurons are given by the entries of the matrix $(D^T D)^{-1}$. Lastly, the weights from the second set of hidden neurons to the output neurons are given by the coefficients $c_1,\dots,c_D$. In a neural network, however, the weights of the synapses are updated iteratively in a learning process until the output is similar enough to the input. In ordinary least squares, all is entirely determined by the matrix $D$, which only depends on the basis functions. The error of sum of squares between the predictions and the input is

$$E(D) = \sum_{n=1}^{N} (t_n^T t_n - t_n^T (D^T D)^{-1} D^T t_n)^2,$$ The derivative with regards to the entry $D_{ij}$ of $D$ is

$$\frac{\partial E(D)}{\partial D_{ij}} = \sum_{n=1}^{N} ((D^T D)^{-1} D^T t_n)_j ((D^T D)^{-1} D^T t_n - t_n)_i,$$ where the subscript of the brackets denotes the component of the vector in the brackets. It is the sum over the training data of the latent variable of the $j^{th}$ neuron in the second of hidden neurons with the error in the $i^{th}$ output neuron, when the $n^{th}$ training sample passes through the network. The thus obtained gradient can be used to update the entries of **D**. Note that this means only updating the weights in the final layer since the weights of the other layers are given by $D^T$ and $(DD^T)^{-1}$. This inverse might not exist, which is an inherent problem of ordinary squares, which can be addressed by ridge regression as seen in equation 8.3. The matrix $DD^T$ is symmetric and positive semi-definite. It can be diagonalized by an orthogonal **Q** such that $DD^T = QP^T$, where $P$ is a diagonal matrix with nonnegative entries. Thus the predictions are

$$\begin{aligned} D(DD^T)^{-1}D^T &= \mathbf{D}(QP^{1/2}P^{1/2}Q^T)^{-1}\mathbf{D}^T \\ &= (\mathbf{D}P^{-1/2})(P^{1/2}Q^T\mathbf{D})\mathbf{t} \\ &= (\mathbf{D}P^{-1/2})(\mathbf{D}P^{-1/2})^T\mathbf{t} \end{aligned}$$

since the inverse of an orthogonal matrix **Q** is $Q^T$. This is a tied two-layer autoencoder with the linear function as activation function. The weights of the first layer are given by the entries of $(QP^{-1/2})^T$ and those of the weights of an autoencoder to the model space which was originally defined as columns of $D^{-1/2}$. This illustrates the link of the weights of **D** being functions evaluated at the points, where data samples are taken. The application of $P^{-1/2}$ are different scalings of the hidden variables, while **Q** is either a rotation or a reflection, since it is an orthogonal matrix.

Continuing in this vein, the mean of the predictive distribution for **t** in Section 8.13 which introduces the Relevance Vector Machine is given by

$$\mathbf{\mu} = \sigma^{-2}\mathbf{D}\Sigma\mathbf{D}^T\mathbf{t}$$
