Our starting point is that there is no covariance between different weights. That is, the weights do not influence each other. The multivariate prior is given by

```
$p(\mathbf{c}|\boldsymbol{\alpha}) = (2\pi)^{-M/2}\prod_{m=1}^M \alpha_m^{1/2}\exp\left(-\frac{\alpha_m^2}{2}\right) = (2\pi)^{-M/2}|\mathbf{A}|^{1/2}\exp\left(-\frac{1}{2}\mathbf{c}^T\mathbf{Ac}\right)$
```

where $\mathbf{A}$ is a diagonal matrix with entries $A_{mm}=\alpha_m$, and $|\mathbf{A}|$ denotes the determinant. The multivariate posterior distribution $p(\mathbf{t},\mathbf{D},\boldsymbol{\alpha},\sigma^2)$ is given by Bayes' rule and is proportional to the product of the prior and the likelihood function:

```
$p(\mathbf{t},\mathbf{D},\boldsymbol{\alpha},\sigma^2) = \frac{p(\boldsymbol{\alpha})\mathcal{L}(\mathbf{t}|\mathbf{D},\sigma^2)}{\int p(\boldsymbol{\alpha})\mathcal{L}(\mathbf{t}|\mathbf{D},\sigma^2)d\mathbf{t}}$ (8.5)
```

Now,

```
$p(\boldsymbol{\alpha})\mathcal{L}(\mathbf{t}|\mathbf{D},\sigma^2) = (2\pi)^{-M/2}|\mathbf{A}|^{1/2}\exp\left(-\frac{1}{2}\mathbf{c}^T\mathbf{Ac}\right) = (2\pi)^{-N/2}\exp\left(-\frac{1}{2\sigma^2}(\mathbf{t}-\mathbf{Dc})^T(\mathbf{t}-\mathbf{Dc})\right)$
```

The multiplicative constants cancel in the fraction and concentrate on the terms in the exponential:

```
$-\frac{1}{2}[\mathbf{c}^T(\mathbf{A}+\sigma^{-2}\mathbf{D}^T\mathbf{D})c-2\sigma^{-2}\mathbf{c}^T\mathbf{D}^T\mathbf{t}+\sigma^{-2}\mathbf{t}^T\mathbf{t}]$
```

Considering the square term we see that the covariance matrix of the posterior distribution has to be

```
$\mathbf{\Sigma} = (\mathbf{A}+\sigma^{-2}\mathbf{D}^T\mathbf{D}),$ (8.6)
```

which is symmetric and positive definite. We complete the square by introducing the mean $\mu$:

```
$-\frac{1}{2}[(\mathbf{c}-\mu)^T\mathbf{\Sigma}^{-1}(\mathbf{c}-\mu)+2\mathbf{c}^T\mathbf{\Sigma}^{-1}\mu-2\sigma^{-2}\mathbf{c}^T\mathbf{D}^T\mathbf{t}+\sigma^{-2}\mathbf{t}^T\mathbf{t}]]$
```

The linear terms in $\mathbf{c}^T$ need to cancel, that is, we need $\mathbf{\Sigma}^{-1}\mu=\sigma^{-2}\mathbf{D}^T\mathbf{t}$. Hence the mean of the posterior distribution is

```
$\mu=\sigma^{-2}\mathbf{D}^T\mathbf{t}.$ (8.7)
```
