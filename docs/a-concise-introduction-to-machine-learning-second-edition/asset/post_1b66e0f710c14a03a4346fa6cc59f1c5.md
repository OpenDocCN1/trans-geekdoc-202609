Subtracting and adding the term

$$\sum_{k=1}^{K} \sum_{n=1}^{N} q(\hat{z}_{n,k}=1) \log q(\hat{z}_{n,k}=1)$$

on the right hand side leaves the equation unchanged, and we obtain

$$\mathcal{L}=\sum_{k=1}^{K} \sum_{n=1}^{N} q(\hat{z}_{n,k}=1) \log p(\mathbf{v}_{n},\hat{z}_{n,k}=1)$$
$$\sum_{k=1}^{K} \sum_{n=1}^{N} q(\hat{z}_{n,k}=1) \log \frac{q(\hat{z}_{n,k}=1)}{p(\mathbf{v}_{n},\hat{z}_{n,k}=1)} \quad (6.10)$$

Now, in the last line sum over $k=1,\dots,K$ is the Kullback-Leibler divergence (KL divergence) from the discrete distribution $p(\mathbf{z}_{n}|\mathbf{v}_{n})$ to the discrete distribution $q(\mathbf{z}_{n})$.

More generally, given two discrete probability distributions $P$ and $Q$, the KL divergence from $Q$ to $P$ is defined as

$$D_{KL}(P||Q)=\sum_{i} P(i) \log \frac{P(i)}{Q(i)}$$

To avoid a division by zero, it is only defined if $Q(i)>0$. In this case, that particular part of the sum is interpreted as zero, since $\lim_{x\to0} x \log x=0$. If both distributions are the same, then the KL divergence is zero. It is nonnegative; if we invert the fraction and use $\log x \leq x-1$, we arrive at

$$D_{KL}(P||Q)=-\sum_{i} P(i) \log \frac{P(i)}{Q(i)} \geq-\sum_{i} P(i) \frac{Q(i)}{P(i)}$$
$$=-\sum_{i} Q(i)+\sum_{i} P(i)=0,$$

since the probabilities need to sum to 1.

The last line in (6.10) is always nonnegative, and therefore the first line is a lower bound for the logarithm of the data likelihood. We can rewrite this

lower bound as

```
$$\mathcal{L} = \sum_{k=1}^{K} \sum_{n=1}^{N} q(z_{n,k}) \log \frac{p(\mathbf{v}_n, z_{n,k}=1)}{q(z_{n,k}=1)}$$
$$= \sum_{k=1}^{K} \sum_{n=1}^{N} q(z_{n,k}) \log (p(z_{n,k}=1)p(\mathbf{v}_n|z_{n,k}=1))$$
$$= - \sum_{k=1}^{K} q(z_{n}=1) \log q(z_n).$$
```

The lower bound has the logarithm of the data likelihood $\mathcal{L}$; if $q(z_n)$ is equal to $p(z_n|\mathbf{v}_n)$, then the KL divergence is zero.
The maximum of (6.10) is estimated by alternating between the lower bound with respect to $q(z_n)$ and with respect to $\pi_k = p(z_k=1)$ and the parameters of $p_k(\mathbf{v}) = p(z_k=1|\mathbf{v})$, $k=1, \dots, K$. The former means setting $q(z_n)$ to $p(z_n|\mathbf{v}_n)$, where the responsibilities are evaluated using the current parameters of $p_k(\mathbf{v})$. With this choice for $q(z_n)$, however, the first term of the lower bound becomes $\mathcal{L}$. The second term is independent of the parameters of $p_k(\mathbf{v})$ and hence irrelevant for the maximization. The location of the maximum is the same whether maximizing $\mathcal{L}$ or $\tilde{\mathcal{L}}$.

The following idea leads us to maximize:

- 1. Initialize all parameters of $p_k(v)$
- 2. Evaluate the responsibilities $p(z_n|\mathbf{v}_n)$
- 3. Maximize:
- 4. Update the parameters
- 5. Terminate if all changes are below a threshold.

This method is known as Expectation-Maximization (EM) for short.
