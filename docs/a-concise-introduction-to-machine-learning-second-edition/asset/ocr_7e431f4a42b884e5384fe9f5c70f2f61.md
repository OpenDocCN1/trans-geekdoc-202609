We obtain values for $\pi_k$ and the parameters describing $p_k(\mathbf{v})$, by maximizing this likelihood, or alternatively its logarithm, known as the *log likelihood*

```
$$\mathcal{L} = \sum_{n=1}^N \log p_n(\mathbf{v}_n) = \sum_{n=1}^N \log \left( \sum_{k=1}^K \pi_k p_k(\mathbf{v}_n) \right)$ \quad (6.4)$
```

When maximizing with respect to the mixing coefficients $\pi_k$, it is important to remember the constraint that they sum to one. This can be incorporated into the maximization problem using a *Lagrange multiplier* $\lambda$. That is, we maximize

```
$$\sum_{n=1}^N \sum_{k=1}^K \pi_k p_k(\mathbf{v}_n) + \lambda \left( \sum_{k=1}^K \pi_k - 1 \right) = 0$
```

Differentiating with respect to $\pi_k$ and setting to zero gives

```
$$\sum_{n=1}^N \sum_{k=1}^K \pi_k p_k(\mathbf{v}_n) + \lambda = 0.$ \quad (6.5)$
```

We first solve for $\lambda$ by multiplying through $\pi_k$ and summing over all $k$. The right hand side remains zero, while the left hand side becomes

```
$$\sum_{n=1}^N \sum_{k=1}^K \pi_k p_k(\mathbf{v}_n) + \sum_{k=1}^K \pi_k \lambda = N.$
```

Hence, we have $\lambda = -N$. Inserting this into (6.5) and again multiplying by $\pi_k$, we have

```
$$\0 = \sum_{n=1}^N \frac{\pi_k p_k(\mathbf{v}_n)}{\sum_{j=1}^K \pi_j p_j(\mathbf{v}_n)} - N\pi_k = \sum_{n=1}^N \frac{\pi_k p_k(\mathbf{v}_n)}{p(\mathbf{v}_n)} - N\pi_k$\n$0 = \sum_{n=1}^N p(\hat{z}_{n,k}=1|\mathbf{v}_n) - N\pi_k,$
```

We used Equation (6.3).

```
$$\pi_k = \frac{1}{N} \sum_{n=1}^N p(\hat{z}_{n,k}=1|\mathbf{v}_n)$ \quad (6.6)$
```

Thus the mixing coefficient $\pi_k$ is the average responsibility that all data samples are generated by process $k$.

We need to emphasize here that the responsibilities $p(\hat{z}_{n,k}=1|\mathbf{v}_n)$ depend on $\pi_k$ itself. However, an iterative scheme can be derived from this, where the mixing coefficients $\pi_k$ and the parameters of the probabilities $p_k(\mathbf{v})$ are initially estimated, then the mixing coefficients are updated according to (6,6). The next step is to maximize with respect to the parameters. The method alternates between these two steps.
