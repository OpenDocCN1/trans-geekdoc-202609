
- If the network tackles $K$ separate, binary classification tasks on the same data, the error function is

```
$E(\mathbf{w}) = -\sum_{k=1}^{K} \sum_{n=1}^{N} t_{n,k} \log y_k(\mathbf{x}_n, \mathbf{w}) + (1 - t_{n,k}) \log (1 - y_k(\mathbf{x}_n, \mathbf{w}))$$
```

where $t_{n,k}$ is the $k^{th}$ component of $\mathbf{t}_n$ and $y_k(\mathbf{x}_n, \mathbf{w})$ is the output of the $K^{th}$ neuron, when $\mathbf{x}_n$ is the input. It is the sum of the errors of the $K$ individual binary classification tasks.

- For multiple classes, $y_k(\mathbf{x}_n, \mathbf{w})$ is taken as the probability of the sample with features $\mathbf{x}_n$ belonging to the $k^{th}$ class and $\mathbf{t}_n$ is a 1-of-$K$ representation. The likelihood of the data is

```
$$\mathcal{L} = \prod_{n=1}^{N} \prod_{k=1}^{K} y_k(\mathbf{x}_n, \mathbf{w})^{t_{n,k}}$$
```

As before, the negative logarithm leads to the error function

```
$E(\mathbf{w}) = -\sum_{k=1}^{K} \sum_{n=1}^{N} t_{n,k} \log y_k(\mathbf{x}_n, \mathbf{w})$$$
```

This looks very similar to the one above, but now only one of $t_{n,k}$, $k=1, \dots, K$ is nonzero.

## 9.2 Error Backpropagation

For all networks, an error function $E(w)$ needs to be minimized. A necessary condition for a minimum is that the gradient $\nabla E(w)$ vanishes. To calculate $E_n(w)$, the chain rule is used multiple times, since the output is the result of applying a chain of linear functions with activation functions.

We first consider the task of regression. In this case,

```
$E_n(w) = \frac{1}{2} ||(\mathbf{x}_n, w) - t_n||^2 = \frac{1}{2} \sum_{k=1}^K (y_k(\mathbf{x}_n, w) - t_{nk})^2$
$= \frac{1}{2} \sum_{k=1}^K (a_k^{(L)}(\mathbf{x}_n, w) - t_{nk})^2$
```

since the linear activation function is used. The dependence of the activation $a_k^{(L)}$ on $\mathbf{x}_n$ and $w$ is made explicit by writing respect to. Taking the derivative with respect to $w_{ji}$, we arrive at

```
$\frac{\partial E_n(w)}{\partial w_{ji}} = \sum_{k=1}^K (a_k^{(L)}(\mathbf{x}_n, w) - t_{nk}) \frac{\partial}{\partial w_{ji}} a_k^{(L)}(\mathbf{x}_n, w)$,
$= \sum_{k=1}^K y_k(\mathbf{x}_n, w) - t_{nk}) \frac{\partial}{\partial u_{ji}} a_k^{(L)}(\mathbf{x}_n, w)$. \quad (9.1)
```

It is the sum of errors in the output neurons, where the weights are the derivative of the corresponding activation with respect to $w_{ji}^{(i)}$. Note that in this derivative the chain rule needs to be employed, unless $t = L$,
