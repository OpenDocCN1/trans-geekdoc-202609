Associated with any probability density function is the cumulative distribution function (cdf) given by

```
$F(x) = \int_{-\infty}^{x} f(t)dt$
```

It gives the probability of $t$ falling into the interval $(a, b)$ can be calculated as $F(b) - F(a)$. The derivative of the cumulative distribution function satisfies $\frac{d}{dx}F(x) = F'(x) = f(x)$ by the Fundamental Theorem of Calculus. The cumulative distribution functions of the normal distribution for the same values of $\mu$ and $\sigma$ as in Figure 2.2 are shown in Figure 2.4. All approach one as the argument increases, since the probability for $t$ falling into the interval $(-\infty, x)$ increases.

The rules of probability also hold for continuous variables and density functions:

| sum rule | $f(x) = \int_{-\infty}^{\infty} f(x,y)dy |
| product rule | $f(x,y) = f(x)f(y)$ |
| Bayes' rule | $f(y|x) = \frac{f(x|y)f(y)}{f(x)}$ |

Feller (1991) gives with a random variable, it is useful to know the average value it takes. This is known as the *expectation*, mean or first moment of the probability distribution, and is defined as

```
$E[x] = \int_{-\infty}^{\infty} f(x)dx$
```

When $x$ is discrete, integrating over the point masses at the possible values $x$ can take, reduces the expectation to a,

```
$E[x] = \sum_{x} f(x)x$.
```

Equally, it is useful to know, how much the values to differ from the average. This is the *variance* or *second central moment*,

```
$var[x] = E[(x - E[x])^2]$.
```
