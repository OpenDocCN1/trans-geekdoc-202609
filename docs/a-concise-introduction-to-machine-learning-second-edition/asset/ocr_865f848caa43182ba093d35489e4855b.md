$d_i$ with components $d_i(x_1), \dots, d_i(x_N)$ can be decomposed uniquely into two vectors, lying in the space spanned by the columns of **D** and one lying in the orthogonal complement of this space:

```
$d_i = \mathbf{Da} + \mathbf{b},$
```

where $\mathbf{D}^T b = 0$.
If $||b|| > 0$, then $d_i$ is linearly independent of the columns of **D** and can be added to the model. We also want to avoid near linear dependency, or in other words small values of $||b||$.
Since the decomposition was orthogonal,

```
$||d_i||^2 = ||\mathbf{Da}||^2 + ||\mathbf{b}||^2$.
```

While the length of $d_i$ is known, the length of **Da** and **b**, are unknown.
Consider

```
$$\sigma^2 S_i = \sigma^2 d_i^T \mathbf{C}^T d_i = d_i^T (I - \sigma^{-2}\mathbf{D}\Sigma\mathbf{D}^T) d_i$\n = $(\mathbf{a}^T + \mathbf{b}^T) (I - \sigma^{-2}\mathbf{D}\Sigma\mathbf{D}^T) (\mathbf{Da} + \mathbf{b})$$\n = \mathbf{a}^T \mathbf{D}^T (I - \sigma^{-2}\mathbf{D}\Sigma\mathbf{D}^T) \mathbf{a} + \mathbf{b}$.$
```

due to orthogonality. using $\sigma^{-2}\Sigma = (\sigma^2\mathbf{A} + \mathbf{D}^T\mathbf{D})^{-1}$, we can simplify part
of the first term

```
$I - \sigma^{-2}\mathbf{D}^T\mathbf{D}$\n = I - $(\sigma^2\mathbf{A} + \mathbf{D}^T\mathbf{D})^{-1}(\sigma^2\mathbf{A} + \mathbf{D}^T\mathbf{D} - \sigma^2\mathbf{A})$$\n = \mathbf{\Sigma}$.$
```

Combining the last results, we get

```
$$\sigma^2 S_i = \mathbf{a}^T \mathbf{D}^T\mathbf{D}\mathbf{Aa} + ||\mathbf{b}||^2$.$
```

However, the first quantity on the right hand side is not known.
To overcome the unknowns, notice that we can scale the vector **Da** by a
actor such that

```
$||\mathbf{Da}||^2 = \alpha \mathbf{a}^T \mathbf{D}^T\Sigma\mathbf{Aa}$.$
```

Since $\mathbf{Da}$ and $\mathbf{b}$ are orthogonal, the square of the length of the vector **aDa**+**b**
isis

```
$||\mathbf{Da} + \mathbf{b}||^2 = ||\mathbf{Da}||^2 + ||\mathbf{b}||^2$\n = \mathbf{a}^T \mathbf{D}^T\Sigma\mathbf{Aa} + ||\mathbf{b}||^2 = \sigma^2 S_i$.$
```

engths geometrically. By the law of lines

```
$$\sin \theta = \frac{\sigma \sqrt{S_i}}{||d_i||} = \sigma \sqrt{\frac{d_i^T}{||d_i||^2}C^{-1} \frac{d_i}{||d_i||}$.$
```
