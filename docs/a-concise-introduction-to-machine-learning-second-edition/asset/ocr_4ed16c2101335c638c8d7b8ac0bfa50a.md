$s_i - q_i^2$ is nonnegative, then the derivative is always positive, since $\alpha_i$ is positive. This means $\ell(\alpha_i)$ is monotonically increasing. If on the other hand $s_i - q_i^2$ is negative, then equation (8.9) vanishes for

```
$$\alpha_i = \frac{s_i^2}{s_i - q_i^2}, \quad (8.10)$
```

where $\ell(\alpha_i)$ has a maximum. Figure 8.10 illustrates these two cases. Setting $\alpha_i = \infty$ in the first case and adjusting $\alpha_i$ to the value given in (8.10) in the second case increases, the logarithm of the marginal likelihood. For $\alpha_i = \infty$, the probability density function for $c_i$ becomes infinitely peaked at zero. In practice, this means that $d_i(\mathbf{x})$ is regarded as not contributing to explaining the data, and therefore can be excluded from the model. This introduced *sparsity* is known as the *Relevance Vector Machine* (RVM).

To avoid many different matrices $\mathbf{C}_{.,i}$, it is convenient to define

```
$Q_i = \mathbf{d}_i^T\mathbf{C}^{-1}$.
```

```
$S_i = \mathbf{d}_i^T\mathbf{C}^{-1}\mathbf{d}_i$.
```

For infinite $\alpha_i$, we have $q_i = Q_i$ and $s_i = S_i$, since in this case $\mathbf{C} = \mathbf{C}_{.-i}$. While finite $\alpha_i$,

```
$s_i = \mathbf{d}_i^T\mathbf{C}^{-1}\mathbf{d}_i, \quad \mathbf{d}_i^T(\mathbf{C} + (\alpha_i)^{-1}\mathbf{d}_i\mathbf{d}_i^T)^{-1}\mathbf{d}_i$.
```

```
$$\mathbf{d}_i^T[\mathbf{C}^{-1} - (\alpha_i)^{-1}\mathbf{d}_i\mathbf{d}_i^T](\alpha_i)^{-1} + \mathbf{d}_i^T\mathbf{C}^{-1}\mathbf{d}_i(\\alpha_i)^{-1}]^{-1}\mathbf{d}_i^T\mathbf{C}^{-1}]$$.
```
