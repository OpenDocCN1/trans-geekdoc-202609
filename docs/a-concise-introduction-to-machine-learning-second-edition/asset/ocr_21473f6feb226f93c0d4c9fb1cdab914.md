Both the beta distribution and the Dirichlet distribution can be illustrated by the Polya urn model. Imagine an urn which contains balls of $K$ different colours. For the beta distribution, these are two colours. Initially the urn contains $\alpha_1 = \alpha$ balls of one colour, $\alpha_2 = eta$ balls of colour two, and so on. In 2.16, the total number of balls is the concentration $\alpha$ and the initial proportions are given by the base distribution $\mu$.

```
import numpy as np
import matplotlib.pyplot as plt
from copy import copy
def polya(alpha, N):
    # Initialize the urn with alpha which specifies the\ number of balls of two different colours.
    y = copy(alpha)
    for n in range(1, N - sum(alpha)):
        # Calculate the proportions of each colour.
        p = np.divide(y, sum(y))
        # Choose a random index according to the proportions.
        idx = np.random.choice(len(p), None, True, p)
        # Add a ball of the colour indexed by the index.
        y[idx] = y[idx] + 1
    return y
# Final number of balls:
N = 100
# Number of experiments:
I = 1000
# Initializing alpha.
alpha = [2, 4]
# First experiment:
Y = polya(alpha, N)

# Further experiments:
for i in range(1, I):
    Y = polya(alpha, N)
    Y = np.stack((Y, Y))

# Plot histogram of experiment outcomes.
plt.hist(Y[:,0], bins=range(1,101)) -0.5 * np.ones(100))
plt.show()
```
