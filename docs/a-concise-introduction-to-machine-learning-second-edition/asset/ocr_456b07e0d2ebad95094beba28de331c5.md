Using the product rule and marginalizing, we obtain

```
$p(u \le \frac{f(x)}{cg(x)}) = \int_{-\infty}^{\infty} p(u \le \frac{f(x)}{cg(x)} | x = \tilde{x}) p(x = \tilde{x})d\tilde{x}\n= \int_{-\infty}^{\infty} \frac{f(x)}{cg(x)} g(\tilde{x})d\tilde{x} = \frac{1}{c}$
```

In the numerator, the joint probability distribution can be calculated as

```
$p(u \le \frac{f(x)}{cg(x)}, x \le \tilde{x}) = \int_{-\infty}^{\tilde{x}} p(u \le \frac{f(x)}{cg(x)}, x = t)dt\n= \int_{-\infty}^{\tilde{x}} \frac{f(x)}{cg(x)}g(t)dt\n= \int_{-\infty}^{\tilde{x}} \frac{f(t)}{cg(t)}g(t)dt = \frac{F(\tilde{x})}{c}$
```

where we used the product rule. In this case, we see that

```
$p(x \le \tilde{x} | \frac{f(x)}{cg(x)}) = F(\tilde{x})$
```

and the samples follow the required distribution.
How many attempts are necessary to draw a sample we accept? This is governed by the geometric distribution with $\mu = p(u \le \frac{f(x)}{cg(x)}) = 1/c$. The expectation is $1/\mu = c$, which agrees with the ratio of the areas under $cg$ and $f$. We therefore expect to draw $c$ samples from the distribution given by $g$ to generate one sample from the distribution given by $f$. In the examples of Figure 3.3, the values of $c$ are approximately 2.45, 2.09 and 1.67 from top to bottom. Therefore the envelope at the bottom is preferable over the other.
