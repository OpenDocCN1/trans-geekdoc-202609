It needs to be ensured that all samples are independent. If some are dependent,

The relative sizes of $h(x_n)$ to $f(x_n)$ can also skew the result. This happens,
for example, if $h(x_n)$ is large in areas where $f(x_n)$ is small and vice versa. Then
the expectation is dominated by the few large values of $h$, even though the
probability density is small in this region. Again, it is necessary to have a
sufficient large sample size $N$ to counteract this.

# 3.1 Inverse Transform Sampling

We need to be to generate samples of the probability density function
f(x). We assume that we have an algorithm available that generates uniformly
distributed numbers in the interval (0, 1). The cumulative probability
density function is known and relates to the probability density function by

$F(x) = \int_{-\infty}^{x} f(y)dt.

We assume that $a$ is continuous and strictly monotonically increasing on the
interval $(a, b)$ and zero for $x \leq a$ and for $x \geq b$. It takes values in the
interval $[0, 1]$. Let $y$ be drawn from the uniform distribution over $(0, 1)$. Then
there exists a unique $x$ in $(a, b)$ such that $F(x) = y$, or in other words
x = F^{-1}(y)$. Then $x$ is a continuous random variable with cumulative-
distribution known as $F$ and hence probability density function $f(x)$. This
techn is known as transform sampling. It is also known as $m-
