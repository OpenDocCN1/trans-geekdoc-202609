Equally using this in (7.3), we arrive at

```
$C^{-1} = \sigma^2 \left(I - \sum_{k=1}^{K} \frac{\mathbf{w}_k\mathbf{w}_k^T}{\lambda_k}\right),$
```

and

```
$tr(\mathbf{C}^{-1}\mathbf{\Sigma}) = \sigma^{-2} \left(tr(\mathbf{\Sigma}) - \sum_{k=1}^{K} \frac{\mathbf{w}_k^T\mathbf{\Sigma}\mathbf{w}_k}{\lambda_k}\right)$$\n= \sigma^{-2} \left(tr(\mathbf{\Sigma}) - \sum_{k=1}^{K} \lambda_k\right) + K$,
```

where we used the cyclic permutation of the trace and the fact that $\mathbf{w}_k$ is an eigenvector of $\mathbf{\Sigma}$ with squared length $\mathbf{w}_k^T\mathbf{w}_k = \lambda_k - \sigma^2$.

With these results, the expression for the log likelihood is

```
$$\mathcal{L} = -\frac{N}{2} \left[ D\log(2\pi) + (D-K)\log\sigma^2 + \sum_{k=1}^{K} \log\lambda_k + \sigma^{-2} \left( \sum_{k=K+1}^{D} \lambda_k \right) \right]$
```

since the trace of a matrix is the sum of its eigenvalues. We differentiate this with respect to $\sigma^2$ in order to optimize this with respect to the noise variance.

```
$$\frac{\partial}{\partial\sigma^2}\mathcal{L} = -\frac{N}{2} \left( (D-K)(\sigma^2)^{-1} - \sigma^{-2} \sum_{k=K+1}^{D} \lambda_k \right)$
```

This will be zero for

```
$$\sigma^2 = \frac{1}{D-K} \sum_{k=K+1}^{D} \lambda_k$.
```
