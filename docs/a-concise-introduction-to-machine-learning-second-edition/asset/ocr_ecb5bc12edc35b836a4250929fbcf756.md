one. The variance is given by

```
var[x_j] = \frac{\alpha_j(\alpha_0 - \alpha_j)}{\alpha_0^2(\alpha_0 +1)}$
```

while the covariance for $j \neq k$ is

```
cov[x_j, x_k] = \frac{-\alpha_j\alpha_k}{\alpha_0^2(\alpha_0 +1)}$
```

As we have seen before with the categorical distribution, the influence is negative, since if one component increases, another has to decrease due to the constraints on $\alpha$.

Looking at Figure 2.22, we see that the relative size of the concentration parameters $\alpha_k$ to their sum $\alpha_0$ determines, where most of the probability mass is concentrated within their simplex. Therefore, in some literature, the Dirichlet distribution are given as $\alpha,\mu$,

```
$$\alpha = \alpha_0 = \sum_{k=1}^K \alpha_k$,$
$$\$\mu = \left(\frac{\alpha_1}{\alpha_0}, \dots, \frac{\alpha_K}{\alpha_0}\right)^T$\quad (2.16)
```

In this case, $\alpha$ is known as the (single) concentration parameter, where $\mu$ is the base distribution. It is also the expectation of the distribution and satisfies the constraint

```
$$\mu_k = 1. \text{ for } k=1,\dots,K$
```

With this notation,

```
$var[x_j, x_k] = \frac{1}{\alpha+1}\mu_j(1-\\mu_j)$,$
cov[x_j, x_k] = \frac{1}{\alpha+1}\mu_j\mu_k$.
```

We have already seen that, if $\alpha=1$, the Dirichlet distribution is uniform distribution. This means all distributions $\chi$ are equally likely. If $\alpha$ tends to infinity, only distributions which are nearly uniform distributions become nearly infinitely peaked around the uniform distribution given by $\chi=(1/K, \dots, 1/K)^T$. In Figure 2.22, $\alpha_0$ is large for $\alpha=(5,5,5)^T$ and the probability mass is concentrated around $(1/3, 1/3, 1/3)$, which describes the uniform distribution for three possible outcomes.

If $\alpha$ tends to zero, let $\mu_k$ be the component which is largest, i.e. $\mu_k > \mu_j$ for all $j \neq k$, then the Dirichlet distribution tends to be peaked at this corner
