The second term (including the minus sign) is the Kullback-Leibler divergence (KL divergence) between the distribution q(c) and the posterior distribution p(c|t, α, σ²). It is also known as the discrimination information, information divergence and information gain, since information is obtained from observing t. For two probability density functions p and q, the KL divergence is defined as

```
$D_{KL}(p||q) = - \int p(x) \log \frac{q(x)}{p(x)} dx = \mathbb{E}_p [ -log \frac{q(x)}{p(x)} ]$
```

$\mathbb{E}_p$ denotes the expectation with respect to the distribution p. Using Jensen's inequality,

```
$D_{KL}(p||q) \geq - \mathbb{E}_p [ \log \frac{q(x)}{p(x)} ] = - \int p(x) \log \frac{q(x)}{p(x)} dx = - \int q(x) dx = 0$
```

since log 1 = 0 (Bishop (2006)) gives more details of the proof. Hence the KL divergence is always positive, zero and only if p(c|t, α, σ²) = q(c) almost everywhere.

Therefore, the first term in (8.4),

```
$\int \frac{p(t, c | α, \sigma²)}{q(c)} dc$
```

is a lower bound for log L(t|α, σ²). The maximization is done by maximizing the lower bound by alternating maximum with respect to q(c) and respect to α.

Let αᵏ be the current estimate of the maximal α. The lower bound is maximal in the sense that it touches the objective function with respect to q(c), if and only if q(c) = p(c|t, αᵏ, σ²). The next step is to find α^(k+1) by maximizing

```
$\int \frac{p(t, c | αᵏ, σ²)}{p(c|t, αᵏ, σ²)} \log \frac{p(t, c | αᵏ, σ²)}{p(c|t, αᵏ, σ²)} dc = - \int p(t, c | αᵏ, σ²) \log p(c|t, αᵏ, σ²) dc$
```

The second term is independent of α. Hence only the first term is relevant for
the maximization.

Note: The first term is the expectation of the logarithm of the joint probability with respect to the current estimate of the posterior distribution. Hence the name Expectation-Maximization algorithm.
