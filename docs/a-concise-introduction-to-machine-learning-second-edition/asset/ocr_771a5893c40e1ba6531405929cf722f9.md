To summarize, the Gaussian mixture algorithm proceeds as follows

+   1. Choose $K$ and convergence threshold.

+   2. Initialize means $\mu_k$, covariances $\mathbf{\Sigma}_k$, and mixing coefficients $\pi_k$ for $k = 1, \dots, K$, and calculate the initial value of the logarithm of the likelihood according to (6.4).

+   3. For $n = 1, \dots, N$ and $k = 1, \dots, K$, calculate all the responsibilities $p(z_{nk} | V_n)$.

+   4. Use these responsibilities to update means $\mu_k$, covariances $\mathbf{\Sigma}_k$, and mixing coefficients for $k = 1, \dots, K$ according to equations (6.8), (6.9) and (6.6).

+   5. Evaluate the change in the logarithm of the likelihood and terminate if it is below the convergence threshold. Otherwise return step 3.

Alternatively, the algorithm converges, the change in all parameters is below the convergence threshold. It is common to use the $K$ means algorithm to obtain good initializations. We initialize the clusters to centers obtained from the $K$ means, while the covariances are set to the sample variances of the clusters, and the mixing coefficients are initially the fractions of data samples assigned to a particular cluster.

```
# Number of samples to be generated.
N = 100;
% Array of means.
MU = [1 4~4; 1~2];
% Concatenation of co-variance matrices.
SIGMA = cat(1,[0 0 0.5]; [0.5 0.5 1]; [1 0 1]);
% Mixing coefficients.
p = [0.4 0.5 1];
% Gaussian mixture model.
GMMModel = gmmistribution(MU,SIGMA,p);
% Generate and display data.
rng(1); % for reproducibility
Id,V = random(GMMModel);
gscatter(V(:,1),V(:,2),idx,'bgr','[10 10 10]);
```
