# 8.4 Ordinary Least Squares

Recall that we assume the dictionary of basis functions is fixed. How best to solve t = Dc + ε generally? One approach is to consider the probabilistic nature of the noise. Remember, the $\epsilon_i$ are independent and identically distributed random variables with zero mean and variance $\sigma^2$. The likelihood of observing t the model specified by D, and $\sigma^2$ is

```
$\mathcal{L}(t|D, \sigma^2) = (2\pi\sigma^2)^{-N/2}\exp\left(-\frac{1}{2\sigma^2}(t-Dc)^T(t-Dc)\right).$
```

The likelihood quantifies the difference between the predictions Dc and the targets t be explained by the noise.
Since the formula involves the exponential function, it makes sense to consider the logarithm of the likelihood known as log likelihood:

```
$\log L(t|D, \sigma^2) = -\frac{N}{2}\log 2\pi\sigma^2-\frac{1}{2\sigma^2}(t-Dc)^T(t-Dc).$
```

A suitable choice for c is the one which maximizes the log likelihood. The first term is $\|c\|^2$, which is equivalent to minimizing

```
$(t-Dc)^T(t-Dc) = ||t-Dc||^2 = \sum_{n=1}^N (t_n-d(x_n)^T c)^2,$
```

since this positive is subtracted. Here $|\cdot||$ denotes the Euclidean norm or $L_2$ norm and $t_n-d(x_n)^T c$ is called the $n^{th}$ residual. It is the difference between the $n^{th}$ target and the prediction for it. Note that $d(x_n)^T$ is the $n^{th}$ row of D. Writing

```
$(t-Dc)^T(t-Dc) = D^TDc - 2c^TD^Tt + t^Tt,$
```

we can differentiate with respect to c using. A.2.3 and set to zero to find the extremum,

```
$D^TDc = D^Tt.$
```

Since $D$ is an $N 	imes M$ matrix, $D^T D$ is an $M 	imes M$ matrix. If the inverse $(D^TD)^{-1}$ exists, then the choice for c is

```
$c = (D^TD)^{-1}D^Tt.$
```
