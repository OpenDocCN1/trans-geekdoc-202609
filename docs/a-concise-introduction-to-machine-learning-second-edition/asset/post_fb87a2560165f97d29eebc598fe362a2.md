The $L_1$ regularization has the disadvantage that in the case of multicollinearity there is not a unique minimum, but a continuum of minima. If two columns $d_i$ and $d_j$ are the same $c_i$ and $c_j$ are nonzero coefficients in the minimum solution, then for any $a \in [0,1]$ replacing $c_i$ by $a(c_i+c_j)$ and replacing $c_j$ by $(1-a)(c_i+c_j)$ is also minimal.

If the columns of $D$ are orthogonal, then they are orthogonal, since we assume they are orthogonal. $D^TD$ is the identity matrix. In this case, the solution to $L_1$ regularization can be found by soft thresholding.

```
$\frac{1}{2} ||\mathbf{t} - D\mathbf{c}||_2^2 + \lambda ||\mathbf{c}||_1 = \frac{1}{2} \mathbf{c}^T D^TD\mathbf{c} - \mathbf{c}^T D^T\mathbf{t} + \lambda ||\mathbf{c}||_1.$
```

Since $\mathbf{t}$ is independent of the variables of interest, the first term can be dropped. Furthermore, let $\mathbf{c}^{OLS}$ be the Ordinary Least Squares solution

```
$\mathbf{c}^{OLS} = (D^TD)^{-1}D^T\mathbf{t}.$
```

The minimization is equivalent to minimizing

```
$-c_m c_m^{OLS} + \frac{1}{2}c_m^2 + \lambda |c_m| = \sum_{m=1}^M -c_m c_m^{OLS} + \frac{1}{2}c_m^2 + \lambda |c_m|,$
```

where each summand can be minimized individually. That is, for each $m$, we minimize

```
$-c_m c_m^{OLS} + \frac{1}{2}c_m^2 + \lambda |c_m| = -c_m c_m^{OLS} + \frac{1}{2}c_m^2 + \lambda sgn(c_m)c_m,$
```

where

```
$sgn(c_m) = \begin{cases} +1 & \text{if } c_m > 0, \ 0 & \text{if } c_m = 0, \ -1 & \text{if } c_m < 0. \end{cases}$
```

If $c_m^{OLS} = 0$, then $c_m$ is minimal. Otherwise, the minimal $c_m$ has to have the same sign as $c_m^{OLS}$, since otherwise $c_m$ could be flipped and a smaller value could be achieved. Thus, it is equivalent to minimize

$$-Cc_m^{OLS} + \frac{1}{2}c_m^2 + \lambda \text{sgn}(c_m^{OLS})c_m.$$

Differentiating with respect to $c_m$ and setting to zero, gives

$$$c_m = c_m^{OLS} - \lambda \text{sgn}(c_m^{OLS})(|c_m^{OLS}|-\lambda)_{|c_m^{OLS}|>\lambda}.$$

To ensure $c_m$ has the same sign as $c_m^{OLS}$, we set $c_m = 0$, if $|c_m^{OLS}| < \lambda$. This effectively reduces the corresponding basis function by the modulus of $|c_m^{OLS}|$ by moving $\lambda$ towards zero. For $\lambda = 0$, we recover the OLS solution. If $\lambda$ is chosen too large, all coefficients are set to zero. Hence $\lambda$ needs to be chosen carefully, which can be done with a parameter search or cross-validation

$L_2$ regularization gives us

$$$\frac{1}{2}\|t\|^2 + \lambda\|c\|^2 = \frac{1}{2}t^T t - c^T D^T t + \frac{1}{2}c^T(D^T D + \lambda I)c.$$

The gradient of this function

$$-D(D^T D + \lambda I)c.$$

Setting the gradient to zero, we have a minimum for

$$c = (D^T D + \lambda I)^{-1}D^T t,$$ \quad (S.3)$$

since the matrix $D^T D + \lambda I$ is positive definite. If $D^T D$ is close to being singular, adding $\lambda$ to each diagonal term will move it away from singularity. This ridge regression stabilizes OLS.

It is interesting to consider the case of orthonormal basis functions $(D^T D = I)$. Then $L_2$ regularization reduces each component of the OLS solution by a factor of $(1+\lambda)^{-1}$. $L_1$ regularization on the other hand moves each component toward zero if $\lambda$ is set to zero. Elastic net combines the two effects. Ridge regression is implemented in MATLAB as `ridge`, while LASSO is implemented as `lasso`. The latter also incorporates elastic net regularization since becomes LASSO for $\lambda=1$. In Python `sklearn.linear_model` has representations of these and many other methods. ## 8.1 Bayesian Regression

We have seen that finding coefficients $c$ to satisfy $\mathbf{t} = \mathbf{Dc} + \epsilon$ by minimizing $\|\mathbf{t}-\mathbf{Dc}\|^2 = \|\epsilon\|^2$ adds to the noise being modelled and overfitting. This can be mitigated by minimizing $\|\mathbf{t}-\mathbf{Dc}\|^2 + \Omega(c)$ for some penalty function $\Omega(c)$. This tweaks the model to favour less complex models. The question we are asking now is whether the tweaking can be formalized?

To this end, we utilize Bayes's rule which we recall as

$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$

Often the relationship is expressed as $P(A|B) \propto P(B|A)P(A)$ which means the two sides are proportional to each other. Thus the division by $P(B)$ is suppressed.

Applying this to the setting at hand,

```
$$p(\mathbf{c}|\mathbf{D}) = \frac{p(\mathbf{t}|\mathbf{c})p(\mathbf{c})}{p(\mathbf{t})}$$
```

In other words, we answer the question: What is the probability of the coefficients given the observed data?

Since the noise is i.i.d. with mean 0 and variance $\sigma^2$, we can write for the probability of $t$ given the design matrix $\mathbf{D}$, coefficients $\mathbf{c}$ and noise variance $\sigma^2$

```
$$p(\mathbf{c}|\mathbf{D}, \sigma^2) = (2\pi)^{-N/2}\sigma^{-N}\exp\left(-\frac{\|\mathbf{t}-\mathbf{Dc}\|^2}{2\sigma^2}\right)$$
```

We define a *prior* distribution for $c$ using all information apart from the data itself, quantifying our belief about the coefficients. For example, a simple assumption is that each coefficient $\alpha$ is *a priori* normally distributed with mean zero and variance $\alpha^{-1}$. The multivariate distribution of $c$ is given by

```
$$p(\alpha) = \frac{\alpha^{M/2}}{(2\pi)^{M/2}}\exp\left(-\frac{\alpha}{2}c^2\right)$$
```

In the absence of any other knowledge, this is one possible assumption. $\alpha$ is a *hyperparameter* and known as the *precision* of the distribution. If $\alpha$ becomes very large, the distribution becomes peaked at its mean and we have more confidence in the value than when $\alpha$ is small and the width of the distribution large.

After observing $N$ samples of the dependent variable $t$, the *posterior distribution* of the coefficients $c$ is given by

```
$$p(\mathbf{c}|\mathbf{D}, \alpha, \sigma^2) \propto p(\mathbf{t}|\mathbf{D}, \sigma^2)p(\mathbf{c})$$
```

An estimate of $c$ could be obtained by choosing the $c$ where the posterior distribution or equivalently its logarithm is maximal,

```
$$\log p(\mathbf{c}|\mathbf{D}, \sigma^2) \propto \log p(\mathbf{t}|\mathbf{D}, \sigma^2) + \log p(\mathbf{c})$$
```

The first term is exactly the log likelihood (8.1), which is maximized when $\|\mathbf{t}-\mathbf{Dc}\|^2$ is minimal. The second term is

```
$$-\frac{\alpha}{2}\|c\|^2 + \frac{M}{2}(\log \alpha - \log(2\pi))$$
```

and can be regarded as the negative of a penalty term. In fact, taking the negative logarithm of the posterior distribution and minimizing instead of maximizing, recreate regression.
