MRI neuro-imaging, EEG technology, etc. They are also known as targets
the Machine Learning technique has to achieve in its task to create a model.
In the following it is assumed that the measurements are mean centred, i.e.
1/(t_1 + ... + t_n) = 0. This eliminates the need for a bias in the model. The
bias is a constant which subtracted from all measurements makes them
centered.

The measurements also depend on parameters we do not know. Any
world application depends on factors which cannot be measured. Or these
measurements would be disproportionately difficult, costly or invasive.

We assume that the measurements are the result of underlying processes
following laws. In some applications, especially physical ones, these laws
are known, and for example described by partial equations equations, but thenspecific parameters are not known. Sometimes nothing is known and we have
to find out this. For applications, incorporate human interactions
the financial markets, it is inherently difficult to infer underlying
processes.

For example, the physics of waves are well understood. However, they
depend on the mixture of media the wave travels, in the materials and their
properties, as well as their interfaces. These are the unknown parameters of
tprocess.

If we had a solution to the underlying process, we could predict the mea-
ment from a function t(x)

t_n = t(x_n),

where parameters of the function depend on the process. On the other hand, if
had a set of candidate functions d_1(x),...,d_M(x), we could try which fits
the measurements, and thus infer the underlying process. We say the functions
d_1(x),...,d_M(x) form a dictionary and let

f(x) = \sum_{m=1}^M c_m d_m(x),

be an approximation to t(x), where c_1,...,c_M are coefficients, and this need
to be determined. The dictionary defines a model space in which ideally the
true t(x) lies. That, the underlying process can be described entirely
by the dictionary. In an ideal world, the approximation f(x) obtained in
the model space should be close enough to the true solution t(x). We will refer
to f(x) as our model describing the data.
