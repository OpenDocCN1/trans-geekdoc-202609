Since the positive semi-definiteness has to hold for all sense of points, it has also to hold for $\psi(a_1), \dots, \psi(a_N)$ where $\psi:\mathbb{R}^n \to \mathbb{R}^M$ is any mapping and $\{a_1, \dots, a_N\}$ is any set in $\mathbb{R}^n$. Therefore, if $k(\mathbf{x}, \mathbf{y})$ is a valid kernel on $\mathbb{R}^M \times \mathbb{R}^M$, so is $k(\mathbf{x}, \mathbf{y})$ on $\mathbb{R}^n \times \mathbb{R}^n$. In particular, $k$ can be the restriction to a subset of components of $\mathbf{x}$. Not necessarily to be disjoint or use all components of $\mathbf{x}$. Let $\mathbf{x}_i \in \mathbb{R}^n$ and $\mathbf{y}_j \in \mathbb{R}^n$ be such restrictions. Then $k(\mathbf{x}_i, \mathbf{y}_j)$ are the kernels obtained by the restrictions, then

```
$k(\mathbf{x}, \mathbf{y}) = k(\mathbf{x}_i, \mathbf{y}_j) + k(\mathbf{x}_0, \mathbf{y}_j) \quad \text{and} \quad k(\mathbf{x}, \mathbf{y}) = k(\mathbf{x}_i, \mathbf{y}_0) + k(\mathbf{x}_0, \mathbf{y}_0)$
```

valid kernels are on $\mathbb{R}^M \times \mathbb{R}^M$.

Thus, there is a possibility of permits to construct kernels. Some examples of kernels are:

**Linear** (trival) kernel $k(\mathbf{x}, \mathbf{y}) = \theta_2^T \mathbf{y}$.

**Quadratic** kernel $k(\mathbf{x}, \mathbf{y}) = (\theta_2 + \mathbf{x}^T \mathbf{y})^2$.

**Polynomial** kernel (of degree $d$) $k(\mathbf{x}, \mathbf{y}) = (\theta_2 + \mathbf{x}^T \mathbf{y})^d$.

**Hyperbolic tangent** (Sigmoid) kernel $k(\mathbf{x}, \mathbf{y}) = \tanh(\theta_2 + \mathbf{x}^T \mathbf{y})$.

Additive and multiplicative constants have to be positive. To ensure, squares are chosen. This also helps, when the parameters are optimized, then this is an unconstrained optimization problem, while it would be a constrained optimization problem.

Consider the inner product $\mathbf{x}^T \mathbf{y}$ for a given vector $\mathbf{x}$. Vectors lying on the line orthogonal to $\mathbf{x}$ are given the value zero for this relationship. Samples positive values on the other side of this line are given a negative value. The absolute values increase with the distance from this line. The additive constant $\theta_1$ shifts the zero line, while the multiplicative constant $\theta_2$ controls the rate of increase. For the linear kernel the shift is absorbed in the bias. Hence setting $\theta_1$ to zero in this context suffices.

The hyperbolic tangent kernel addresses the problem that absolute values of the arguments of the inner product with the distance from the zero line tend to plus or minus infinity, the result tends to +1 or -1, respectively. For small $\theta_2$, the change from -1 to +1 is less rapid. The additive and multiplicative constants are parameters which need to be optimized or tuned for the specific application.
