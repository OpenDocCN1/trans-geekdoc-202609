## 9.1 Neural Networks

As before are given data pairs $(\mathbf{x}_n, \mathbf{t}_n), \dots, (\mathbf{x}_1, \mathbf{t}_n)$, where $x_n \in \mathbb{R}^D$ and each component of $\mathbf{x}_n$ is a feature. Also $\mathbf{t}_n$ can be multidimensional, with $t_n \in \mathbb{R}^K$.

Recall that a neural network connects a set of input neurons, a set of output neurons and possibly several sets of hidden neurons. One component of $x$ is passed to one input neuron. Therefore, the number of input neurons is $D$. During training, the results of output neurons are compared to $\mathbf{t}_n$. Hence, the number of output neurons is $K$. The synapses connecting one set of neurons to another are $L$.

More specifically, let $L$ be the number of layers. This means that there are $L-1$ sets of hidden neurons. The size of the $l^{th}$ set of hidden neurons is denoted by $z_m^{(l)}, l=1,\dots,L-1, m=1,\dots,M_l$. In the $l^{th}$ layer, the weight of the synapse connecting the $i^{th}$ neuron on the left to the $j^{th}$ neuron on the right is denoted by $w_{ij}^{(l)}$. This neural network is illustrated as

The dotted connections indicate that any combination of hidden neurons and layers is possible.

For $l \neq 1$, the result of the propagation function is the activation

$$a_j^{(l)} = \sum_{i=1}^{M_{l-1}} w_{ji}^{(l)} z_i^{(l-1)}$$

This is passed to the *activation function*, also called *transfer function*, of this layer $h_i$ to generate the latent variable

$$z_i^{(l)} = h_i(a_i^{(l)}) = h_i\left(\mathbf{w}_i^{(l)})^T x^{(l-1)}\right)$$

For $l = 1$, we have

$$a_1^{(1)} = \mathbf{w}_1^{(1)T}\mathbf{x} \quad \text{and} \quad z_1^{(1)} = h_1\left(\mathbf{w}_1^{(1)})^T \mathbf{x}\right)$$

For $l = L$, the output variables $y_1, \dots, y_K$ are calculated,

$$y_L = h_L(a_L^{(L)}) = h_L\left(\mathbf{w}_L^{(L)})^T x^{(L-1)}\right)$$

A list of possible activation functions is given in Section 5.5. The choice depends on the problem at:

- **For regression**, $K = 1$ and $t_i$ takes either the value 0 or 1 depending on whether the sample with features $\mathbf{x}_i$ belongs to the negative or positive class, respectively. There is only one output neuron and the activation function is the *logistic sigmoid* function $h_L^{(L)} = (1 + \exp(-a^{(l)}))^{-1}$. The output is interpreted as the probability of the input with features $x_1, \dots, x_D$ belonging to the positive class.
- **For binary classification**, $K$ separate, **binary classification** tasks for the same data, then $\mathbf{t}_i$ is a vector of zeros and ones. The $k^{th}$ component indicates the class membership of the $k^{th}$ classification task. Each output neuron each output neuron can be linked to a binary classifier using the logistic sigmoid function.
- **For multiple classes**, $\mathbf{t}_i$ is a *1-of-K representation*. This means only one of the $K$ components of $\mathbf{t}_i$ is one and all others are zero. The sample with features $\mathbf{x}_i$ belongs to the $k^{th}$ class. The activation function is the *softmax* function which maps the $K$-dimensional vector of activations $a^{(l)} = (a_1^{(l)}, \dots, a_K^{(l)})^T$ to a $K$-dimensional vector of activations $\sigma(a^{(l)})$ with the $k^{th}$ entry of $\sigma(a^{(l)})$ being

$$\sigma(a^{(l)})_k = \frac{\exp(a_k^{(l)})}{\sum_{j=1}^K \exp(a_j^{(l)})}$$

The $k^{th}$ output is interpreted as the probability of the sample with features $\mathbf{x} = (x_1, \dots, x_D)^T$ belonging to the $k^{th}$ class. The output values sum to one as required for probabilities.

If the activation function in neurons is the logistic sigmoid, then the neural network is commonly known as multilayer perceptron. However, this is a misnomer, since the original perceptron uses the discontinuous step function as activation. In the section on backpropagation, we will see the advantages continuity brings. To add to the confusion, the term multilayer perceptron is now being used, when arbitrary architectures are employed, and for both classification or regression tasks. Because of this dilution of the definition, the form of the neural network cannot be deduced, the term perceptron is used.

The neural network is a function mapping the input $x = (x_1, \dots, x_D)^T$ to the output $y = (y_1, \dots, y_D)^T$. This mapping is a composition of functions with each layer being a linear function composed with an activation function. The number of layers can be hundreds or thousands giving rise to the deep learning. These many possibilities are powerful; however, there is a case for simplicity, because insight into the underlying processes can be gained.

The input passing through the network is known as forward propagation. Cycles, where information could be passed backwards, are not allowed. The architecture is strictly feed-forward.

As the latent variables can be relabeled, which means that neurons are exchanged with each other, there are $\prod_{M_l!}$ equivalent neural networks, which give the same mapping from input to output. Another equivalence arises from the activation functions of the hidden neurons being even, i.e. $h(-x) = h(x)$, or odd, i.e. $h(-x) = -h(x)$.
