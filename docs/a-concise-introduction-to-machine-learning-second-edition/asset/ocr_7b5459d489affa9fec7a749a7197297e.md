```
load fisheriris
# Extract two attributes.
pl = meas(1,3); % petal length
pw = meas(1,4); % petal width
X = [pl,pw]

# Create classifier.
kModel = fitcknn(X,species,
    'NumNeighbours',5, % number of neighbours
    'Standardize',true)
```

```
# Lay grid over the region.
d = grid(0:0.05:1,0:0.7:0.3)
[xGrid,yGrid] = meshgrid(d(1),d(2))
[n,n2] = size(xGrid)
```

```
# For each point calculate the cost of each class.
'predict' returns the predicted class labels corresponding to
tminimum-classification cost, the cost (posterior probability)
for each class as well as the expected classification cost for
class
[score,~] = predict(kModel,xGrid)
```

```
# Classify according the maximum score.
maxScore = max(score,[1,2])
```
