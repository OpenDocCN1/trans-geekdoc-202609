$$\text{Cat}(\mathbf{x}|\mu) = \prod_{k=1}^K \mu_k^{x_k}. \ (2.9)$

Note that all factors in the product are equal to one from which, since in $\mathbf{x}$ all entries are zero except one. The categorical distribution can be viewed as a generalization of the Bernoulli distribution. The uniform distribution is a special case of it, with $\mu_1 = ... = \mu_K = 1/K$.
Figure 2.10 illustrates the probability mass function of a categorical distribution where $\mu = (1/3, 1/3, 1/3)^T$. The cumulative distribution function is an irregular step function. Both draws with regards to the indices in $\mathbf{x}$. If the possible outcomes are ordered differently in $\mathbf{x}$, the graphs will be different.
