To differentiate with respect to **D**, we rewrite the expression for the expectation of the joint log likelihood using the cyclic permutation property of the trace,

```
$$\mathcal{L} = -\frac{1}{2} \sum_{n=1}^{N} [(K + D) \log(|\mathbf{D}|) + \text{tr}(\mathbb{E}[\mathbf{u}_n\mathbf{u}_n^T]) + \n\left[(\mathbf{v}_n - \mu)^T 2(\mathbf{v}_n - \mu)\mathbb{E}[\mathbf{u}_n]^T W^T \mathbb{E}[\mathbf{u}_n\mathbf{u}_n^T]W D^{-1}\right)]$$
```

This way we derive the formula in A.2.4, A.2.7 and A.2.10. The derivative with respect to **D** is therefore

```
$$\frac{\partial}{\partial D}\mathcal{L} = -\frac{1}{2} \sum_{n=1}^{N} \frac{1}{|\mathbf{D}|} \mathbf{D}^{-1} \text{diag}( (\mathbf{v}_n - \mu)^T (\mathbf{v}_n - \mu)) \n\-2(\mathbf{v}_n - \mu)\mathbb{E}[\mathbf{u}_n]^T W^T \mathbb{E}[\mathbf{u}_n\mathbf{u}_n^T]W^T D^{-1}$$
```

Setting this to zero, multiplying by **D** from both left and right and solving for **D**, gives the following formula

```
$$\mathbf{D}_{new} = \text{diag} \left( \frac{1}{N} \sum_{n=1}^{N} (\mathbf{v}_n - \mu)(\mathbf{v}_n - \mu)^T \n\-\frac{1}{N} \sum_{n=1}^{N} (\mathbf{v}_n - \mu)\mathbb{E}[\mathbf{u}_n]^T W^T \n+ \frac{1}{N} W \sum_{n=1}^{N} \mathbb{E}[\mathbf{u}_n\mathbf{u}_n^T] W^T \right)$$
```

It is common to use the already updated **$W_{new}$**, when inserting **$D_{new}$**. When inserting (7.13) into the left of the line, the sum over $n=1, \dots, N$, $\mathbb{E}[\mathbf{u}_n\mathbf{u}_n^T]$, cancels with its inverse and the last line combines with the one above. The update formula is

```
$$\mathbf{D}_{new} = \frac{1}{N} \sum_{n=1}^{N} \text{diag} ((\mathbf{v}_n - \mu)(\mathbf{v}_n - \mu - \mathbf{W}_{new}\mathbb{E}[\mathbf{u}_n])^T)$$
```

This can be viewed as the $D$-dimensional version of (7.12). This depends on the M-step.

These updates depend indirectly on the previous **D** and **W** via the expectations, which are calculated in the E-step. To this end, the conditional probability distribution $\pi(\mathbf{u}|\mathbf{v})$ of the latent variable **$\mathbf{u}$** has variance

```
$$\mu_{\mathbf{u}|\mathbf{v}} = (\mathbf{W}^T \mathbf{D}^{-1} \mathbf{W} + \mathbf{I})^{-1}$$
```

and mean

```
$$\mu_{\mathbf{u}|\mathbf{v}} = \sum_{\mathbf{u}} \mathbf{u}^T \mathbf{D}^{-1} \mathbf{W} + \mathbf{I},$$
```
