This can be interpreted as measuring, how close on $E[\mathbf{u}_n]$ is to the sample $v_n - \mu$ under the mapping given by $\mathbf{W}_{new}$ and how close $\mathbf{W}_{new}^T$ is to the inverse of the conditional covariance matrix, that is, how close it is to the precision matrix.

Another interpretation is as follows. Since the sum of traces is the trace of the sum, we can use inside the trace. Using (7.10) for $\mathbf{W}_{new}^T$, the sum cancels with its inverse. Further, using the cyclic permutation property of the trace and the trace of a square is scalar, the particular formula simplifies to

```
$$\sigma_{new}^2 = \frac{1}{N} \sum_{n=1}^{N} ||v_n - E[\mathbf{u}_n]||^2 \mathbf{W}_{new}^T (v_n - \mu)$$\n = \frac{1}{N} \sum_{n=1}^{N} (v_n - \mathbf{W}_{new} E[\mathbf{u}_n])^T (v_n - \mu). \quad (7.12)$
```

Thus noise variance is the average inner product of $v_n - \mu$ with the difference of $v_n - \mathbf{W}_{new}$ and the image of the expectation of $\\mathbf{u}_n$ scaled by the number of dimensions $D$. It measures, how close on average $\mathbf{W}_{new} E[\mathbf{u}_n]$ is to the orthogonal projection of $\mathbf{u}_n$ onto the subspace spanned by the columns of $v_n$.

These formulae for $\mathbf{W}_{new}$ and $\sigma_{new}^2$ form the M-step of the Expectation-Maximization algorithm. They are of length $N$, where each element in the M-step can be calculated in $O(KD)$ operations. The overall complexity of the M-step is $O(KND)$.

The E-step calculates $E[\mathbf{u}_n]$, using (7.7) and (7.8) and $E[\mathbf{u}_n, \mathbf{u}_n^T]$ using (7.6) and (7.9). The E-step calculates the inverse of a matrix, but this matrix is of size $K \times K$ so this is $O(K^2)$. Calculating this matrix itself is of $O(KD)$. If the inverse is found, calculating $E[\mathbf{u}_n]$ is $O(KD)$ and $E[\mathbf{u}_n, \mathbf{u}_n^T]$ is $O(KD)$, where $K \leq D$. These need to be calculated for $n=1, \dots, N$ and the complexity for the E-step is $O(KND)$. However, the E-step can be done in parallel for each data point, since $E[\mathbf{u}_n]$ and $E[\mathbf{u}_n, \mathbf{u}_n^T]$ can be calculated independently of each other.

While the Expectation-Maximization algorithm is an iterative procedure, the number of iteration is significantly less, if $K \ll D$. This can affect the time due to the iterations against the direct maximization of the log likelihood which has complexity $O(ND^2)$.

So far in this section, $K$ was chosen and not determined by the data. Minka (2000) employs a Bayesian treatment of Principal Component Analysis which determines $K$.
