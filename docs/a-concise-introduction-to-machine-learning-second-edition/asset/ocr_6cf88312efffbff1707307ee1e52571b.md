The last line means that $G$ is a Dirichlet process with parameters $\alpha$ and $G_0$. A Dirichlet process is a distribution of distributions. There are infinitely many possibilities for pairs $(\mu, \Sigma)$ and the vector $\pi$ is often described as infinite giving each a probability mass. Conceptually, infinity is difficult. In practice, the number of clusters $K$ is at most the number of samples $N$, every cluster contains one sample. Therefore $G$ gives a probability mass of $N_j/(N-1)$ to at most $N$ pairs $(\mu, \Sigma)$ drawn from the base distribution $G_0$, and assigns the probability of $\alpha/((N-1+\alpha)$ to the set of all other pairs. $G$ is a discrete distribution defined on a finite partition of the space of all pairs $(\mu, \Sigma)$ which is defined by $S$.

More formally, $G$ is drawn from a Dirichlet process with parameters $\alpha$, for any finite, disjoint partition $S_1, \dots, S_L$ of $S$, $L$ can be any finite number, the vector $G(S_1), \dots, G(S_L)$ follows a Dirichlet distribution with parameters $\alpha_0(S_1), \dots, \alpha_0(S_L)$. In our example,

```
$G_0(S_i) = \int_{S_i} NIW(\mu, \lambda, \Psi, \nu) \d\mu d\Sigma = \int_{S_i} N(\mu, \frac{1}{\lambda}W^{-1}(\Psi), \nu) \d\mu d\Sigma$.
```

Similarly, $G(S_i)$ can be calculated from the values $G$ takes on the partition, and we indeed have

```
$(G(S_1), \dots, G(S_L)) \sim \text{Dir}(\alpha_0(S_1), \dots, \alpha_0(S_L)).
```

The Dirichlet process infers $G$ from the data by varying the number $K$ of pairs $(\mu_k, \Sigma_k)$ and their positions. It belongs to a family of methods known as Bayesian nonparametrics which are Bayesian models operating on an infinite-dimensional parameter space. In our case, this is the space of all possible pairs $(\mu, \Sigma)$. This way, the model can be adjusted to data, for example outliers, which do not fit within the current parameters.
