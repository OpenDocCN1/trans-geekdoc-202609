We can now calculate

```
$F_y(y) = \int_{0}^{y} f_{x_1}(x_1) \int_{x_1}^{y-x_1} f_{x_2}(x_2) dx_2 dx_1,$$
```

where independent of $x_2$ lie between zero and $\infty$ and both follow the exponential distribution, $x_1, x_2 \sim \text{Exp}(\beta)$ with probability density function as defined in Equation 2.13. For simplicity we let $\beta=1$. Then

```
$F_y(y) = \int_{0}^{y} \exp(-x_1) \int_{0}^{y-x_1} \exp(-x_2) dx_2 dx_1 $$
= \int_{0}^{y} \exp(-x_1) [-\exp(-x_2)]_{0}^{y-x_1} dx_1 $$
= \int_{0}^{y} \exp(-x_1) [1-\exp(-y+x_1)] dx_1 $$
= \int_{0}^{y} [\exp(-x_1) - \exp(-y)] dx_1 $$
= [1-\exp(-y)-y\exp(-y)].$.
```

Differentiating with respect to $y$ gives

```
$f_y(y) = \exp(-y)-(\exp(-y)-y\exp(-y)) = y\exp(-y).$
```

This probability density function describes the gamma distribution for parameters $\alpha=2$ and $\beta=1$, $y \sim \text{Gamma}(\alpha, \beta)$. More generally, the probability density function of the gamma distribution is defined as

```
$$\text{Gamma}(x,\beta) = \begin{cases} \frac{1}{\Gamma(\alpha)\beta^{\alpha}}x^{\alpha-1}\exp(-\frac{x}{\beta}) & \text{for } x\geq0,\,0 & \text{for } x<0.\end{cases}$
```

The parameter $\alpha$ is known as the shape parameter, while $\beta$ and $1/\beta$ are the scale parameter and rate parameter for the exponential distribution. The mode is given by $(\alpha-1)\beta$ for $\alpha\geq1$ and for $\alpha<1$. The exponential distribution is a special case of the gamma distribution where $\alpha=1$. The $\chi^2$-distribution with $k$ degrees of freedom is a special case with $\alpha=k/2$ and $\beta=2$.
