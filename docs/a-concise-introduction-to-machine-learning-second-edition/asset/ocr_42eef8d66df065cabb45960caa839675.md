# 2.5 Functions of Continuous Random Variables

Since Machine Learning, data sometimes is a function of other data, it is important to consider functions of random variables and know the techniques to derive the probability density functions. If $x$ is a continuous random variable with probability density function $f_x(x)$, then for a continuous variable $g$, $g(x)$ is also a continuous random variable, but what is its probability density function $f_g(y)$? We include subscripts to be clear random variable the probability density function and the cumulative distribution refer

We restrict our attention to the case when $g$ is a one-to-one transformation. That each value of $g$ generates exactly one value of $y$, and each value of $y$ is generated by exactly one value of $x$. Because of this, an inverse function $g^{-1}$ exists such that $x=g^{-1}(y)$. Since $g$ is continuous, it has to be strictly decreasing or increasing.

Taking the increasing case first, we can derive the probability density function using the cumulative distribution functions $F_x$ and $F_y$. Given a $y$,

$F_y(y) = p(g(x) \le y)$.

Now, since $g$ is strictly increasing, if $g(x) \le y$, then $x \le g^{-1}(y)$ at the same time. Hence,

$F_y(y) = p(x \ge g^{-1}(y)) = F_x(g^{-1}(y)) = \int_{-\infty}^{g^{-1}(y)} f_x(x)dx$.

Using integration by substitution, setting $x=g^{-1}(t)$ the upper limit becomes $y$ and derive $dx=g^{-1}(t)dt$.

$F_y(y) = \int_{-\infty}^{y} f_x(g^{-1}(t))(g^{-1})'(t)dt$.

To find the probability density function, we differentiate with respect to $y$. By the Fundamental Theorem of Calculus

$f_y(y) = f_x(g^{-1}(y))(g^{-1})'(y)$.

The derivation for the strictly decreasing case starts off in the same way. However, $g(x)$ is less than or equal to $y$, and only if $x \ge g^{-1}(y)$, due to $g$ being decreasing.

$F_y(y) = p(x \ge g^{-1}(y)) = 1 - F_x(g^{-1}(y)) = 1 - \int_{-\infty}^{g^{-1}(y)} f_x(x)dx$.
