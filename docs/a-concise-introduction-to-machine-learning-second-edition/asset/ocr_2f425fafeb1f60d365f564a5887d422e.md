When $w$ is updated using only a subset $S$ of training data

If only one $E_i(w)$ is used, when updating $w$, the method is *online, sequential or stochastic*. The algorithm either passes through the training data several times, shuffling after each pass, or selects samples randomly with replacement. It is called *online gradient, sequential gradient descent or stochastic gradient descent*, if the optimization method is gradient descent.

Mini-batch and stochastic methods have the advantage that a local minimum of an individual $E_i(w)$ or a set $\sum_{i \in S} E_i(w)$ will generally not be a local minimum for a different choice of $n$ over $S$. Thus, it escapes from local minima. They are more efficient with duplicates in the training set, since only a selection of training data is used in each update anyway, while all training data are used, the duplicates add computational overhead as giving more weight to training data points.

To calculate $E_n(w)$, the chain rule is used multiple times, since the output is the result of applying a chain of linear propagation functions alternating with activation functions.

We first consider the task of regression. In this case,

```
$E_n(w) = \frac{1}{2} ||(\mathbf{x}_n, w) - t_n||^2 = \frac{1}{2} \sum_{k=1}^K (y_k(\mathbf{x}_n, w) - t_{nk})^2$
$= \frac{1}{2} \sum_{k=1}^K (a_k^{(L)}(\mathbf{x}_n, w) - t_{nk})^2$
```

since the linear activation function is used. The dependence of the activation $a_k^{(L)}$ on $\mathbf{x}_n$ and $w$ is made explicit by writing respect to.
Taking the derivative with respect to $w_{ji}$, we arrive at

```
$\frac{\partial E_n(w)}{\partial w_{ji}} = \sum_{k=1}^K (a_k^{(L)}(\mathbf{x}_n, w) - t_{nk}) \frac{\partial}{\partial w_{ji}} a_k^{(L)}(\mathbf{x}_n, w)$,
$= \sum_{k=1}^K y_k(\mathbf{x}_n, w) - t_{nk}) \frac{\partial}{\partial u_{ji}} a_k^{(L)}(\mathbf{x}_n, w)$. \quad (9.1)
```
