```python
def noisydata(x1, x2, N, sigma0, signal):
    # This function creates N noisy data pairs (x,y) from a function f
    # in the [x1,x2] with added noise where the noise is a
    # mixture of zero normal distributions with variances sigma0
    # and signal with probability s and l-
    rng = np.random.default_rng()
    x = np.linspace(x1,x2,N)
    t = np.zeros(N)
    for i in range(N):
        if (rng.random() < s):
            t[i] = f(x[i]) + rng.normal(loc=0, scale=sigma0)
        else:
            t[i] = f(x[i]) + rng.normal(loc=0, scale=signal)
    return x, t
```

With increasing complexity of the model, the models for different datasets become very different, showing that the models are susceptible to small changes in the training data. Too much complexity leads to overfitting and a large variance in the models. These can be separated formally.

We need to generalize to all datasets. This means looking at the expected error that a particular model space gives rise to. Given a model space, let $f(x)$ be an approximation to the underlying process generating the data $t(x)$. It is common to look at the expected squared

> $E[(t(x) - f(x))^2]$

where $t(x) = f(x) + \epsilon$.

Now $t(x)$ is a deterministic process, and $\mathbb{E}[t(x)]=t(x)$, which implies $\mathbb{E}[f(x)]=f(x)$, since the noise has zero mean. Similarly,

```
\text{var}[t] = \mathbb{E}[(\t(x) - \mathbb{E}[t(x)])])^2] \n\mathbb{E}[(f(x))^2] = \text{var}[f(x)] + \mathbb{E}[\epsilon^2] = \sigma^2.
```
