
To differentiate with respect to **D**, we rewrite the expression for the expectation of the joint log likelihood using the cyclic permutation property of the trace,

```
$$\mathcal{L} = -\frac{1}{2} \sum_{n=1}^{N} [(K + D) \log(|\mathbf{D}|) + \text{tr}(\mathbb{E}[\mathbf{u}_n\mathbf{u}_n^T]) + \left[(\mathbf{v}_n - \mu)^T 2(\mathbf{v}_n - \mu)\mathbb{E}[\mathbf{u}_n]^T W^T \mathbb{E}[\mathbf{u}_n\mathbf{u}_n^T]W D^{-1}\right)]$$
```

This way we derive the formula in A.2.4, A.2.7 and A.2.10. The derivative with respect to **D** is therefore

```
$$\frac{\partial}{\partial D}\mathcal{L} = -\frac{1}{2} \sum_{n=1}^{N} \frac{1}{|\mathbf{D}|} \mathbf{D}^{-1} \text{diag}( (\mathbf{v}_n - \mu)^T (\mathbf{v}_n - \mu)) - 2(\mathbf{v}_n - \mu)\mathbb{E}[\mathbf{u}_n]^T W^T \mathbb{E}[\mathbf{u}_n\mathbf{u}_n^T]W^T D^{-1}$$
```

Setting this to zero, multiplying by **D** from both left and right and solving for **D**, gives the following formula

```
$$\mathbf{D}_{new} = \text{diag} \left( \frac{1}{N} \sum_{n=1}^{N} (\mathbf{v}_n - \mu)(\mathbf{v}_n - \mu)^T - \frac{1}{N} \sum_{n=1}^{N} (\mathbf{v}_n - \mu)\mathbb{E}[\mathbf{u}_n]^T W^T + \frac{1}{N} W \sum_{n=1}^{N} \mathbb{E}[\mathbf{u}_n\mathbf{u}_n^T] W^T \right)$$
```

It is common to use the already updated **$W_{new}$**, when inserting **$D_{new}$**. When inserting (7.13) into the left of the line, the sum over $n=1, \dots, N$, $\mathbb{E}[\mathbf{u}_n\mathbf{u}_n^T]$, cancels with its inverse and the last line combines with the one above. The update formula is

```
$$\mathbf{D}_{new} = \frac{1}{N} \sum_{n=1}^{N} \text{diag} ((\mathbf{v}_n - \mu)(\mathbf{v}_n - \mu - \mathbf{W}_{new}\mathbb{E}[\mathbf{u}_n])^T)$$
```

This can be viewed as the $D$-dimensional version of (7.12). This depends on the M-step.

These updates depend indirectly on the previous **D** and **W** via the expectations, which are calculated in the E-step. To this end, the conditional probability distribution $\pi(\mathbf{u}|\mathbf{v})$ of the latent variable **$\mathbf{u}$** has variance

```
$$\mu_{\mathbf{u}|\mathbf{v}} = (\mathbf{W}^T \mathbf{D}^{-1} \mathbf{W} + \mathbf{I})^{-1}$$
```

and mean

```
$$\mu_{\mathbf{u}|\mathbf{v}} = \sum_{\mathbf{u}} \mathbf{u}^T \mathbf{D}^{-1} \mathbf{W} + \mathbf{I},$$
```

which depends on **v**. Therefore, the two calculations forming the E-step are

```
$$E[u_n] = \sum_{u_iv}W^T D^{-1}(v_n - \mu)$$
```

and using (2.10)

```
$$E[u_nu_n^T] = \sum_{u_iv} + E[u_n]E[u_n]^T$$
```

# 7.5 Kernel Principal Component Analysis

The previous sections relied on the assumption that the data samples are related to latent variables in a lower dimensional space via a **linear** mapping as defined in (7.2). Geometrically, this means that the dataset lies close to a plane, line or hyperplane as illustrated in Figures 7.5 and 7.6. This assumption is, however, unrealistic in many practical applications.

The data samples lie close to a *K-dimensional manifold*. A manifold is a two-dimensional manifold is the sphere. Flat-earthers succumb to the impression that locally the Earth is a sphere which represents a plane. Globally, however, it does not, because traveling continuously in one direction will return to the starting point. Figure 7.7a gives an example of data close to the unit sphere. Lighter shaded points lie beyond the surface of the sphere.

It is possible to choose a mapping $\phi: \mathbb{R}^D \to \mathbb{R}^D$ into a higher dimensional space such that the dataset then lies related to latent variables in a *K-dimensional subspace*. In Figure 7.7, the dataset was first mapped to a four-dimensional space, where the fourth component is the sum of squares of the other three. Since the dataset lies approximately on the unit sphere, the fourth component will be close to one for all data samples. Thus the dataset lies on a hyperplane. After finding the first two principal components, the dataset is projected onto the plane given by these two principal components. This is shown in Figure 7.7b. Thus the datasets are grouped towards the top or bottom, that they can be separated along one principal component.

However, like the kernel trick in Section 5.2, performing the mapping explicitly is avoided. Instead, all steps in the calculation use the *kernel function* or *kernel* for $k: \mathbb{R}^D \times \mathbb{R}^D \to \mathbb{R}$ defined as

```
$$k(x,y) = \phi(x)^T\phi(y).$$
```

Let **E** be the $N \times N$ matrix with each entry equal to the *mean center* a vector $\mathbf{a} = (a_1, \dots, a_N)$ by

```
$$\mathbf{a}^T(\mathbf{I} - \frac{1}{N}\mathbf{E}) = (a_1^T - \frac{1}{N}\sum_{n=1}^N a_n, \dots, a_N^T - \frac{1}{N}\sum_{n=1}^N a_n).$$
```

Also be used to shift data samples so that their mean is zero. Let $\phi(v_1),\dots, \phi(v_N) \in \mathbb{R}^D$ be the images under the mapping $\phi$ of the data. Let $\Phi$ be the $D \times N$ matrix whose columns are the vectors $\phi(v_1), \dots, \phi(v_N)$, which are known as *pre-images*.

Recall that Principal Component Analysis calculates the covariance matrix $\Sigma$ of the data samples. In this context, for every row of $\Phi$, we subtract the mean of that row. The columns of this matrix are the shifted images. The $n^{th}$ column of the shifted images, which is the average of the outer products of the $n^{th}$ column of $\Phi(I - \frac{1}{N}\mathbf{E})$ with its transpose. This can be written as

```
$$\Sigma = \frac{1}{N} \sum_{n=1}^N \Phi(I - \frac{1}{N}\mathbf{E})e_n e_n^T (I - \frac{1}{N}\mathbf{E})$$
```

where $e_n$ is the standard basis vector, with all elements equal to zero except for the $n^{th}$ column. Multiplying by $e_n$, from the right picks out the $n^{th}$ column. $\Phi(I - \frac{1}{N}\mathbf{E})$ and its transpose are independent of $n$. Summing $e_n e_n^T$ over all $n=1, \dots$ results in the identity matrix. Further the matrix $I - \frac{1}{N}\mathbf{E}$ is *idempotent*, which means any power of it is the itself, since $\mathbf{E}^2 = \mathbf{E}$

```
$(I - \frac{1}{N}\mathbf{E})(I - \frac{1}{N}\mathbf{E}) = I - \frac{2}{N}\mathbf{E} + \frac{1}{N^2}\mathbf{E}^2 = I - \frac{1}{N}\mathbf{E}.$$
```

Therefore, the covariance matrix can be expressed as

```
$$\Sigma = \frac{1}{N} \Phi(I - \frac{1}{N}\mathbf{E})\Phi^T.$$
```

Seek the largest $K$ eigenvalues $\lambda_k$ of $\mathbf{\Sigma}$ with corresponding eigenvectors $\mathbf{w}_k, k=1, \dots, K$. Using the above expression for $\mathbf{\Sigma}$, these vectors satisfy

```
$$\Phi(I - \frac{1}{N}\mathbf{E})\Phi^T\mathbf{w}_k = N\lambda_k\mathbf{w}_k$$
```

Multiplying through with $(I - \frac{1}{N}\mathbf{E})\Phi^T$ from the left and using the idempotence of $I - \frac{1}{N}\mathbf{E}$, this becomes

```
$(I - \frac{1}{N}\mathbf{E})\Phi^T\Phi(I - \frac{1}{N}\mathbf{E})\mathbf{w}_k = N\lambda_k(I - \frac{1}{N}\mathbf{E})\mathbf{w}_k.$$
```

Here the vector

```
$$\mathbf{w}_k = (I - \frac{1}{N}\mathbf{E})\mathbf{w}_k \quad (7.14)$$
```

is an eigenvector of $(I - \frac{1}{N}\mathbf{E})$, symmetric matrix $\mathbf{\Phi}^T\mathbf{\Phi}(I - \frac{1}{N}\mathbf{E})$ with eigenvalue $\lambda_k = N\lambda_k$. Note, that due to $I - \frac{1}{N}\mathbf{E}$ being idempotent, we have $(I - \frac{1}{N}\mathbf{E})\mathbf{w}_k = \mathbf{w}_k$. Thus, the components of the sum reduce to $(i, j)$ entry of $\mathbf{w}_k$ is the inner product

```
$$\phi(v_i)^T\phi(v_j) = k(v_i, v_j).$$
```

**K = $\mathbf{\Phi}^T\mathbf{\Phi}$ is the *kernel matrix*. *Kernel Principal Component Analysis* calculates the eigenvalues $N\lambda_k$ and eigenvectors $\mathbf{w}_k$ of $(I - \frac{1}{N}\mathbf{E})\Phi^T\mathbf{\Phi}(I - \frac{1}{N}\mathbf{E})$ from (7.14) from the left with $1/N$, gives Equation

```
$$\mathbf{w}_k = \frac{1}{N}\mathbf{\Phi}(I - \frac{1}{N}\mathbf{E})\Phi^T\mathbf{w}_k = \lambda_k\mathbf{w}_k.$$
```

Hence, $\mathbf{w}_k$ is a linear combination of the images $\phi(v_1), \dots, \phi(v_N)$,

```
$$\mathbf{w}_k = \frac{1}{N}\sum_{n=1}^N \mathbf{w}_n\phi(v_n),$
```

$\mathbf{w}_n, n=1, \dots, N$, are the coefficients of $\mathbf{w}_k$. In practice, this calculation is never done, since we are only interested in expressing any data point $v$ in the basis formed by the principal components, i.e. the value of the projections

```
$$\mathbf{w}_k^T\phi(v) = \frac{1}{N\lambda_k}\mathbf{\Phi}^T\phi(v) = \frac{1}{N\lambda_k}\phi(v_1)^T\phi(v) \dots \ \phi(v_N)^T\phi(v)$$
```

```
$$\mathbf{w}_k = \frac{1}{N\lambda_k}k(v_1, v_k) \dots \ k(v_N, v_k)$$
```

It remains to specify the length of $\mathbf{w}_k$. The principal components have length one, this translates into a condition on the length of $\mathbf{w}_k$.

```
$$\1 = \mathbf{w}_k^T\mathbf{w}_k = \frac{1}{(N\lambda_k)^2}\mathbf{w}_k^T\mathbf{\Phi}^T\mathbf{\Phi}\mathbf{w}_k,$$
```
