$$\Sigma_{\mathbf{u},\mathbf{v}} = \sigma^2(\mathbf{W}^T\mathbf{W} + \sigma^2\mathbf{I}),$ (7.6)

$$\frac{1}{2}\mathbf{u}^T\Sigma_{\mathbf{u},\mathbf{v}}^{-1} = \mathbf{u}^T\sigma^{-2}\mathbf{W}^T(\mathbf{v}-\mu).$

$$\mu_{\mathbf{u},\mathbf{v}} = \Sigma_{\mathbf{u},\mathbf{v}}^{-1}(\mathbf{v}-\mu) = (\sigma^2\mathbf{W}^T\mathbf{W} + \sigma^2\mathbf{I})^{-1}\mathbf{W}^T(\mathbf{v}-\mu),$ (7.7)

which depends on $\mathbf{v}$.nThe Expectation-Maximization algorithm calculates the expectation of the logarithm of the data likelihood with respect to the conditional probability of the latent variables $\mathbf{u}_1, \dots, \mathbf{u}_N$. The logarithm of the data likelihood is

$$\mathcal{L} = \log \prod_{n=1}^N p(\mathbf{v}_n, \mathbf{u}_n) = \frac{1}{2}\sum_{n=1}^N ((K+D)\log(2\pi) + D\log(\sigma^2) + \mathbf{u}_n^T\mathbf{u}_n - \sigma^{-2}\mathbf{u}_n^T\mu^T(\mathbf{v}_n-\\mu) - 2\mathbf{u}_n^T\mathbf{W}^T\mathbf{W}\mathbf{u}_n).$

When taking the expectation with respect to the latent variables we have

$E[\mathbf{u}_n] = \mu_{\mathbf{u},\mathbf{v}},$ (7.8)

To find the expectation of the inner product of $\mathbf{u}_n$ with itself we use the cyclic permutation property of the trace and fact the operations of calculating the trace and expect continue,

$E[\mathbf{u}_n^T\mathbf{u}_n] = E[\text{tr}(\mathbf{u}_n\mathbf{u}_n^T)] = \text{tr}(E[\mathbf{u}_n\mathbf{u}_n^T]).$

Similarly,

$E[\mathbf{u}_n^T\mathbf{W}^T\mathbf{W}\mathbf{u}_n] = E[\text{tr}(\mathbf{u}_n^T\mathbf{W}^T\mathbf{W}\mathbf{u}_n)]$

$= \text{tr}(\mathbf{W}^T\mathbf{W}E[\mathbf{u}_n\mathbf{u}_n^T]).$
