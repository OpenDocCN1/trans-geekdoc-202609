Similarly,

```
$q_i = \frac{\alpha_i Q_i}{\alpha_i - S_i}$
```

Let's examine $D_i$ more closely. The matrices $\Sigma$ and $\mathbf{C}$ are related via the Woodbury matrix identity in $\mathbf{A}_{1.1.3}$.

```
$$\mathbf{C}^{-1} = (\sigma^2\mathbf{I} - \mathbf{D}\mathbf{D}^{-1}\mathbf{D}^T)^{-1}$$
 = \sigma^{-2}\mathbf{I} - \mathbf{D}\mathbf{D}^{-1}(\mathbf{A} + \mathbf{D}^T\sigma^{-2}\mathbf{D})^{-1}\mathbf{D}^T\sigma^{-2}$
 = \sigma^{-2}(1 - \sigma^{-2}\mathbf{D}\mathbf{\Sigma}\mathbf{D}^T)$
```

Using this and (8.7),

```
$$\mathbf{C}^{-1}t = \sigma^{-2}(t - \mathbf{\mu})$$.
```

However, the mean of our predictive probability distribution for $t$, $\mathbf{C}^{-1}t$ gives the difference between the target and the mean for each sample scaled by the noise. If this is small, our current model is adequate to explain the data. If not, we consider $\mathbf{C}^{-1}t$ as an error which needs to be removed. Calculating $\alpha_i = \mathbf{d}_i^T\mathbf{C}^{-1}$ checks how well aligned $d_i$ is; if it is well aligned, or orthogonal, then $d_i$ will not help in removing this error. If it is well aligned, then the inclusion of $d_i$ in the model will be beneficial. Therefore $Q_i$ is the *quality factor*.

$S_i$, on the other hand is known as sparsity factor, as we will see below, it helps evaluate how collinear $d_i$ is to the other basis functions. The quantity $s_i$ is a penalty associated with the basis function $d_i$. It quantifies how well $d_i$ could be modeled by the other basis functions. On the other hand, $q_i$ is a quality term, measuring how well $d_i$ would contribute to explaining the data, using the current model. Both $s_i$ and $q_i$ depend on $\mathbf{C}^{-1}$, which in turn depends on $\alpha_*$. Thus the optimal value for $\alpha_i$ changes as the other hyperparameters $\alpha_*$, are adjusted.

The possibility to adjust hyperparameters in turn gives rise to the following algorithm which initializes the model with a single function and its optimal parameter value, and sets the hyperparameters of the other basis functions to infinity. At the start of the algorithm when only one function is in the model, $\mathbf{D}$ has only one column, and $\Sigma$ is a $1\times1$ matrix. $\Sigma$ is the variance of that single function evaluated at the points with itself. Its inverse is easily calculated using the Sherman-Morrison formula from $\mathbf{A}_{1.4}$. Then the basis function $d_i(\mathbf{x})$, setting its hyper-parameter $\alpha_i$ to its optimal value (given the current model), gives the largest increase in the marginal likelihood, is found and the model is updated accordingly.

The algorithm converges, if no significant increase in the logarithm of the marginal likelihood can be achieved anymore.
