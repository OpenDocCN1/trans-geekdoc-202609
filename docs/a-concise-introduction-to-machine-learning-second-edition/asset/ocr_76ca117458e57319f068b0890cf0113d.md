The other factor is the probability of $\mathbf{v}_n$ belonging to an empty cluster. Since this cluster is still empty, its distribution is completely determined by the prior.

```

```

Having calculated these $K+1$ probabilities, they are used to sample which cluster $v_n$ belongs to, either of the existing clusters or the empty cluster. If the former, the posterior normal, inverse Wishart distribution of that cluster needs to be updated and a new covariance matrix mean to be drawn from it. If the latter, this cluster may be empty and the parameters $\mathbf{m}_{k_n}, \boldsymbol{\lambda}_{k_n},$ and $oldsymbol{
u}_{k_n}$ of the posterior, normal, inverse Wishart distribution need to be calculated. Both are updated according to $K+1$. The prior gets updated to the posterior by one sample $\mathbf{v}_n$. A covariance matrix $oldsymbol{\Sigma}_{K+1}$ and mean $oldsymbol{\mu}_{K+1}$ are drawn from this distribution.

Once samples have been considered, the initialization is complete. This phase can lead to different results. In Figures 6.12a and 6.13a the initialization procedure was applied to the data from Figure 6.3b. The results are very different in Figure 6.12a clusters dominate, while in 6.13a two dominate.

After initialization, several iterations follow and in each iteration samples are considered in a random order. Let $K'$ be the current number of clusters, $N_k$ the current number of samples in cluster $k, k=1,\dots,K',$ and $\mathbf{v}_n$ be the sample under consideration. $\mathbf{v}_n$ is removed from the dataset and the cluster, it is currently assigned to, it is updated following the same steps as described for Bayesian mixtures. If this removal results in an empty cluster, this cluster is removed completely, and $K'$ becomes $K-1$.
