## 5.6 AdaBoost and Cascades

We distinguish between weak and strong learners. A weak learner will only be slightly better than random guessing, while a strong learner provides the right classification most of the time. In this section we consider whether a set of weak learners can create a single strong learner. To simplify things we assume both classes are present and the number of samples in each class is the same. The goal is to generate a classifier $C$ where the sign of the output determines the class. The total error $E$ of $C$ is defined as the sum of exponential error at each sample:

$$E(C) = \sum_{i=1}^{N} \exp(-c_i C(\mathbf{v}))$$

where $c_i = \pm1$ is the class label of $\mathbf{v}$. AdaBoost, short for Adaptive Boosting, iteratively generates a series of classifiers $C_m$. Each iteration improves the classifier by concentrating on misclassified elements. Each classifier $k_j$ which returns $\pm1$ is one of these. The coefficients in this combination are positive. Each coefficient gives the confidence in the weak classifier. The final classifier decides based on the linear combination of weak classifiers.

First, $\hat{C}_1$ is initialized to the weak classifier $k_1(\mathbf{v})$ which misclassifies the least number of training examples. Its coefficient $\alpha_1$ is chosen to minimize:

$$E(\hat{C}_1) = \sum_{i=1}^{N} \exp(-c_i k_1(\mathbf{v})) = \sum_{c_i=k_1(\mathbf{v})} \exp(-\alpha_1) + \sum_{c_i\neq k_1(\mathbf{v})} \exp(\alpha_1)$$

where we used the fact that $c_i$ and $k_1(\mathbf{v})$ only have the values $+1$ or $-1$. Differentiating with respect to $\alpha_1$ gives:

$$\frac{dE(C_1)}{d\alpha_1} = \sum_{c_i \neq k_1(v_i)} \exp(\alpha_1) - \sum_{c_i = k_1(v_i)} \exp(-\alpha_1)$$

Let $N$ be the number of samples and $N_C$ be the number of correctly classified samples. We then have:

$$\frac{dE}{d\alpha_1} = (N - N_C) \exp(\alpha_1) - N_C \exp(-\alpha_1)$$

To find the extremum, we set this to zero and solve for $\alpha_1$:

$$\exp(2\alpha_1) = \frac{N_C}{N - N_C} \implies \alpha_1 = \frac{1}{2} \log \frac{N_C}{N - N_C}$$

Thus $\alpha_1$ is half the logarithm of the ratio of the number of correctly classified samples over the number of misclassified samples. If $N_C=N/2$, then $\alpha_1=0$, which means we have no confidence in the classification, it is equal to random guessing. Note that $N_C$ cannot be less $N/2$, because the weak classifiers need to be better than random guessing *ie.* they need to classify at least more than $N/2$ samples correctly. The larger $N_C$, the higher the confidence.

In the $m^{th}$ iteration we generate $c_m = c_{m-1} + \alpha_m k_m$. The total error is:

$$\E(C_m) = \sum_{i=1}^{N} \exp(-\alpha_m c_{m-1}(v_i) + \alpha_m k_m(v_i)) = \sum_{i=1}^{N} \exp(-\alpha_m c_{m-1}(v_i)) - \exp(-\alpha_m k_m(v_i)) = \exp(-\alpha_m) \sum_{c_i=k_{m-1}(v_i)} w_{i,m} + \exp(\alpha_m) \sum_{c_i \neq k_m(v_i)} w_{i,m}, \quad (5.7)$$

where we defined the weights $w_{i,m} = \exp(-\alpha_m c_{m-1}(v_i))$. Hence the weight $w_{i,m}$ is the exponential error the current classifier makes sample $v_i$. The first sum is over all samples $k_m$ classifies correctly, while the second sum is over incorrectly classified samples. The total error can be rewritten as:

$$\E(C_m) = \sum_{i=1}^N \exp(-\alpha_m) w_{i,m} + \exp(\alpha_m) \sum_{c_i \neq k_m(v_i)} w_{i,m}.$$
