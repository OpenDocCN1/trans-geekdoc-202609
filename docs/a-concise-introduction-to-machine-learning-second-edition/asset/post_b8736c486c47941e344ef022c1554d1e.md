# Simple two layer Neural Network class.
class NeuralNetworks:
    def __init__(self,
                 output,
                 hidden,
                 tol,
                 epoch):
        # number of input neurons
        # number of output neurons
        # number of hidden neurons
        # tolerance
        # number of epochs
        # learning rate
        self.in_size = input
        self.nout = output
        self.hidden = hidden
        self.tol = tol
        self.epoch = epoch
        self.learning_rate = rate
        self.weights_in = np.random.randn(self.in_size, hidden)

        self.weights_out = np.random.randn(hidden, self.nout)

    def forward(self, X):
        # Add bias and multiply with weights
        self.weights_in += np.random.randn(*self.weights_in.shape)
        # Activation function
        Y = np.tanh(np.dot(X, self.weights_in))
        # Add bias and multiply with weights
        self.weights_out += np.random.randn(*self.weights_out.shape)
        # Activation function
        Y = np.sigmoid(np.dot(Y, self.weights_out))
        return Y

    def train(self, X, target):
        # Propagate the training data
        perm = np.random.permutation(X.shape[0])
        X = X[perm]
        target = target[perm]
        Z = np.dot(X, self.weights_in)
        Y = np.tanh(Z)
        # Activation function
        Y = np.dot(Y, self.weights_out)
        # Errors for all training samples
        errors = Y - target
        cost = 0.5 * np.sum(errors**2)
        epoch = 0
        while epoch < self.epoch and cost < self.tol:
            # Propagate errors
            # For matrix multiplication component
            # Using property of sigmoid derivative
            delta = errors * Y * (1 - Y)
            # Update weights in layer
            self.weights_out -= np.dot(Y.T, delta) * self.learning_rate
            # Update weights in layer
            delta = np.dot(delta, self.weights_out.T) * (1 - Y**2)
            self.weights_in -= np.dot(X.T, delta) * rate
            # Permute the data
            perm = np.random.permutation(X.shape[0])
            X = X[perm]
            target = target[perm]
            # Add bias, multiply with weights and apply
            Z = np.dot(X, self.weights_in)
            Y = np.tanh(Z)
            Y = np.dot(Y, self.weights_out)
            # Errors for all training samples
            errors = Y - target
            cost = 0.5 * np.sum(errors**2)
            epoch += 1
        return epoch

One possible solution is an activation function with two steps, for example

```
$h(x) = \begin{cases} 0 & x \le 0.25 \\ 1 & 0.25 < x < 0.75 \\ 0 & x \ge 0.75 \end{cases} \quad (5.3)$
```

Again, the learning process might have chosen different weights. There are many different activation functions in use. Some of these are:

- Linear:

```
$h(x) = x \quad (5.4)$
```

- Logistic sigmoid:

$$h(x) = \frac{1}{1+\exp(-a(x-c))} \quad (5.5)$$

- Hyperbolic tangent:

$$h(x) = \tanh(x)$$

- Gaussian:

$$h(x) = \exp\left(\frac{(x-c)^2}{2a^2}\right)$$

- Multiquadric:

$$h(x) = \sqrt{(x-c)^2 + a^2}$$

- Inverse multiquadric:

$$h(x) = \frac{1}{\sqrt{(x-c)^2 + a^2}}$$

The parameters $a$ and $c$ have been tuned for the task at hand. If the sign activation function in the perceptron is replaced by the logistic sigmoid function, then the output is interpreted as the probability of the sample belonging to the positive class $C_1$. The probability of belonging to the negative class $C_0$ is minus the output. This is then known as logistic regression. While it is solving a classification task, regression is part of the maine, since it is trying to model the probability of belonging to the positive class.

An activation function particularly important for classifying multiple classes is the softmax function, also known as normalized exponential function. It is different from the other activation functions in that it takes into account the result of propagation of other neurons. Let $a_j$ be $w_j^T v$. If the number of neurons is $K$, the softmax function maps $a=(a_1, \dots, a_K)$ to a $K$-dimensional vector $\sigma(a)$ with the $j^{th}$ entry of $\sigma(a)$ being

```
$$\sigma(a)_j=\frac{\exp(a_j)}{\sum_{k=1}^K \exp(a_k)} \quad (5.6)$$
```

Obviously, the elements of $\sigma(a)$ sum to one. The softmax function is often used in the final layer, where the number of synapses is the same as the number of classes. $K$ provides a probabilistic interpretation to which class the sample, which passed through the network, belong.
