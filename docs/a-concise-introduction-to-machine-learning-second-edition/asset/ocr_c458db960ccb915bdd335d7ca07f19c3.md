At the start of this section, we used the inverse of the function $g$. However, there are infinitely many possibilities to get $y$ by adding two real numbers. Even with splitting into regions it will be possible to generate an inverse. All is not lost however, if we introduce a further random variable. Let $y_1(x_1, x_2) = x_1 + x_2$ as before, and $y_2 = g_2(x_1, x_2) = x_1 - x_2$. In vector form this is

```
$y = (y_1, y_2)^T = g(x_1, x_2) = (g_1(x_1, x_2), g_2(x_1, x_2))^T$.
```

We can express $x_1$ and $x_2$ in terms of $y_1$ and $y_2$,

```
$x_1 = \frac{y_1 + y_2}{2},\nx_2 = \frac{y_1 - y_2}{2},$$ (2.19)
```

We might not have an inverse of the individual components of $\mathbf{g}$, but we have an inverse of $\mathbf{g}$, which we denote by $\mathbf{g}^{-1}$.
