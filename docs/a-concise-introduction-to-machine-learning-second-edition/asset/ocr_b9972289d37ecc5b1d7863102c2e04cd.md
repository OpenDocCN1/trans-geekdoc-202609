The expectation and the second crude moment of the Bernoulli distribution are given by

```
$E[x] = \mu \times 1 + (1 - \mu) \times 0 = \mu,
$$E[x^2] = \mu \times 1^2 + (1 - \mu) \times 0^2 = \mu.$
```

From this we can calculate the variance

```
$var[x] = E[x^2] - E[x]^2 = \mu - \mu^2 = \mu(1 - \mu).$$
```
