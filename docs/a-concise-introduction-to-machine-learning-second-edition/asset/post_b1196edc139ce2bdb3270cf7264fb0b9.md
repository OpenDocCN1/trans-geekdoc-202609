
$d_i$ with components $d_i(x_1), \dots, d_i(x_N)$ can be decomposed uniquely into two vectors, lying in the space spanned by the columns of **D** and one lying in the orthogonal complement of this space:

```
$d_i = \mathbf{Da} + \mathbf{b},$
```

where $\mathbf{D}^T b = 0$.
If $||b|| > 0$, then $d_i$ is linearly independent of the columns of **D** and can be added to the model. We also want to avoid near linear dependency, or in other words small values of $||b||$.
Since the decomposition was orthogonal,

```
$||d_i||^2 = ||\mathbf{Da}||^2 + ||\mathbf{b}||^2$.
```

While the length of $d_i$ is known, the length of **Da** and **b** are unknown.
Consider

```
$$\sigma^2 S_i = \sigma^2 d_i^T \mathbf{C}^T d_i = d_i^T (I - \sigma^{-2}\mathbf{D}\Sigma\mathbf{D}^T) d_i = (\mathbf{a}^T + \mathbf{b}^T) (I - \sigma^{-2}\mathbf{D}\Sigma\mathbf{D}^T) (\mathbf{Da} + \mathbf{b}) = \mathbf{a}^T \mathbf{D}^T (I - \sigma^{-2}\mathbf{D}\Sigma\mathbf{D}^T) \mathbf{a} + \mathbf{b}.$
```

due to orthogonality. using $\sigma^{-2}\Sigma = (\sigma^2\mathbf{A} + \mathbf{D}^T\mathbf{D})^{-1}$, we can simplify part of the first term

```
$I - \sigma^{-2}\mathbf{D}^T\mathbf{D} = I - (\sigma^2\mathbf{A} + \mathbf{D}^T\mathbf{D})^{-1}(\sigma^2\mathbf{A} + \mathbf{D}^T\mathbf{D} - \sigma^2\mathbf{A}) = \mathbf{\Sigma}.$
```

Combining the last results, we get

```
$$\sigma^2 S_i = \mathbf{a}^T \mathbf{D}^T\mathbf{D}\mathbf{Aa} + ||\mathbf{b}||^2.$
```

However, the first quantity on the right hand side is not known.
To overcome the unknowns, notice that we can scale the vector **Da** by a factor such that

```
$||\mathbf{Da}||^2 = \alpha \mathbf{a}^T \mathbf{D}^T\Sigma\mathbf{Aa}.$
```

Since $\mathbf{Da}$ and $\mathbf{b}$ are orthogonal, the square of the length of the vector **Da**+**b** is

```
$||\mathbf{Da} + \mathbf{b}||^2 = ||\mathbf{Da}||^2 + ||\mathbf{b}||^2 = \mathbf{a}^T \mathbf{D}^T\Sigma\mathbf{Aa} + ||\mathbf{b}||^2 = \sigma^2 S_i.$$
```

Figure 8.11 illustrates the relationship between the various vectors and their lengths geometrically. By the law of lines

```
$$\sin \theta = \frac{\sigma \sqrt{S_i}}{||d_i||} = \sigma \sqrt{\frac{d_i^T}{||d_i||^2}C^{-1} \frac{d_i}{||d_i||}}.$$
```

![](img/c6c76bf52016db7e78a5e30d4766ef81_288_0.png)

Figure 8.11: Geometric illustration.

Since $\phi \le 1$, $\sigma \sqrt{S_i}/||d_i||$ is an upper bound for $\theta$. If this value becomes too small, $\mathbf{d}$ is deemed to be nearly linearly dependent on the columns of $\mathbf{D}$ and $d_i(\mathbf{x})$ is not added to the model if $Q_i^2 > S_i$ indicates that augmenting the model with this function increases the logarithm of the marginal likelihood. Since $\mathbf{d}$ can be closely approximated by a linear combination of the columns of $\mathbf{D}$ a similar increase can be achieved by updating the coefficients of the model altogether.

Note that not $d_i(x)$ at this stage does not mean that it is excluded from the model altogether. Since the algorithm also deletes basis functions from the linear dependency might not be present at a later stage. 

A similar collinearity can be derived when $d_i(x)$ is already in the model and $\alpha_i$ is finite. In this case, if $s_i/||d_i||$ is small, the columns of $\mathbf{D}$ are deemed nearly linearly dependent. This collinearity is used to postpone the reconstruction of a basis function in future of updates, since the near linear dependency might be resolved in the following steps of the algorithm. This increases stability. Otherwise, the algorithm can enter a cycle of reconstructions of the basis function. The hyperparameters of these basis functions are typically small indicating a wide distribution of the coefficients of these basis functions and thus uncertainty. Other strategies could be updating a group of basis functions within one step or creating a new basis function from a group of functions.

To summarize, Bayesian learning provides a framework where the model is a vector of coefficients, a posterior distribution for $\mathbf{c}$ is obtained. This leads us to a predictive distribution for unseen data. In the case of unsampled data, the change in the log evidence can be calculated. If this change is positive, it affirms the model, otherwise it indicates that the model should be improved. This framework also gives the possibility to add new basis functions to the model on the fly, incorporating a mechanism to avoid collinearity.

## 8.4 Gaussian Process

A stochastic process is a probability distribution over functions $f(\mathbf{x})$, $\mathbf{x} \in \mathbb{R}^d$, such that when evaluated at any arbitrary set of points $\mathbf{x}_1, \dots, \mathbf{x}_N$, the values $f(\mathbf{x}_1), \dots, f(\mathbf{x}_N)$ follow a joint multivariate distribution. The aim of this section is to look for the model in the infinite space of functions. In the preceding sections, we have chosen the function space in which our model lies by specifying a finite dictionary of basis functions, and the model $f(\mathbf{x})$ being a linear combination of these basis functions. This is restrictive. Recall that so far we specified as

```
$f(\mathbf{x}) = \sum_{m=1}^{M} c_m d_m(\mathbf{x}).$
```

where $\mathbf{D}$ is the design matrix, where each column is a function evaluated at $\mathbf{x}_1, \dots, \mathbf{x}_N$ and $\mathbf{c}$ is the vector of coefficients. The assumption is that $\mathbf{c}$ is normal. Since $f$ is a linear transformation of $\mathbf{c}$, it has a normal distribution. Our models are Gaussian processes. The prior assumption is that $\mathbf{c}$ has zero mean, and hence $f$ also has zero mean. We consider the two cases where the prior covariance matrix of $\mathbf{c}$ is either $\alpha^{-1}\mathbf{I}$, that is all coefficients have the same precision $\alpha$, or the diagonal-matrix $\mathbf{A}^{-1}$, where each coefficient has its own precision. The covariance of $f$ is then

```
$\text{var}[\mathbf{f}] = \mathbf{E}[\mathbf{f}\mathbf{f}^T] = \mathbf{E}[\mathbf{D}\mathbf{c}\mathbf{c}^T\mathbf{D}^T] = \mathbf{D}\mathbf{E}[\mathbf{c}\mathbf{c}^T]\mathbf{D}^T = \begin{cases} \alpha^{-1}\mathbf{DD}^T \\ \mathbf{A}^{-1}\mathbf{DD}^T. \end{cases}$
```

Note that the covariance matrix of $f$ depends on the set $\mathbf{x}_1, \dots, \mathbf{x}_N$ via the design matrix. Different sets of points will give different multivariate distributions of $\mathbf{f}$. Defining $\mathbf{d}(\mathbf{x}_i)^T = (d_1(\mathbf{x}_i), \dots, d_M(\mathbf{x}_i))$ as the vector of all basis functions evaluated at a specific point $\mathbf{x}_i$, the $(i, j)$ entry of the covariance matrix is

$$\alpha^{-1}\mathbf{d}(\mathbf{x})^T\mathbf{d}(\mathbf{x}) \quad \quad \quad \mathbf{d}(\mathbf{x})^T\mathbf{A}^{-1}\mathbf{d}(\mathbf{x})$$

We have seen Section 5.2 that these expressions define kernels. Consider the case, in our model $d_1(\mathbf{x}) = 1$ and $d_{d+1}(\mathbf{x}) = x_d$, the $d^{th}$ component of $\mathbf{x}$ for $d=1, \dots, D$. This means the kernel is linear polynomial. In this case,

$$\alpha^{-1}\mathbf{d}(\mathbf{x})^T\mathbf{d}(\mathbf{x}) = \alpha^{-1}(1 + \mathbf{x}^T\mathbf{y})$$

Thus is this linear kernel. If we modify this

```
$$\mathbf{k}(\mathbf{x}, \mathbf{y}) = \sigma_0^2 + \mathbf{x}^T\mathbf{y}$$
```

where $\sigma_0$ controls the inhomogeneity of the kernel, we arrive at the **product kernel**. On the other hand, if the kernel is the square of the inner product,

$$\mathbf{k}(\mathbf{x}, \mathbf{y})^2 = (\mathbf{x}^T\mathbf{y})^2,$$
