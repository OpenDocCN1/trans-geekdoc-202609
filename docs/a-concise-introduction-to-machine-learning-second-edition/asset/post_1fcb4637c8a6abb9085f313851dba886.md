We can now motivate the *change-of-variables technique*. If $g : \mathbb{R}^k \to \mathbb{R}^k$ is an invertible and differentiable function, and $x \in \mathbb{R}^k$ is also a random variable with probability density function $f_x(x)$, then $y = \mathbf{g}(x) \in \mathbb{R}^k$ is also a random variable and its probability density function

$f_y(y) = f_x(g^{-1}(y))|\det g^{-1}(y)|$.

Returning to our example of $y_1 = g_1(x_1, x_2) = x_1 + x_2$ and $y_2 = g_2(x_1, x_2) = x_1 - x_2$, the inverse $g^{-1}$ is given by (2.19). The matrix of partial derivatives is

$$\begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}$$

$\mu = c_1\mu_1 + \dots + c_k\mu_k$ and variance $\sigma^2 = c_1^2\sigma_1^2 + \dots + c_k^2\sigma_k^2$.

## 2.6 Conjugate, Prior and Posterior Distributions and Maximum Likelihood

The previous sections were concerned with probabilities and how to describe them. We are interested in describing data with probabilities. To do this, let us return to the experiment of flipping a coin, or more generally an experiment with Bernoulli distribution $\text{Bern}(x)$, where $\mu$ is unknown. Let $x_1, \dots, x_N$ be $N$ observations of the experiment. The probability to observe this data $D = \{x_1, \dots, x_N\}$ is

$$p(D|\mu) = \prod_{n=1}^N \text{Bern}(x_n|\mu) = \prod_{n=1}^N \mu^{x_n}(1-\mu)^{1-x_n} = \mu^{\sum_{n=1}^N x_n}(1-\mu)^{\sum_{n=1}^N (1-x_n)}$$

This is known as the likelihood of the data $D$. Now, if $m$ is the number of times $x_n = 1$ in $N$ trials, then

$$p(D|\mu) = \mu^m(1-\mu)^{N-m}.$$

The value of $\mu$ can be estimated by maximizing the likelihood with respect to $\mu$, since we want to choose the $\mu$ which explains the best data.

The maximization is equivalent to maximizing the logarithm, which is valid, since the logarithm is a monotonically increasing function. This is the log likelihood:

$$\log p(D|\mu) = m \log \mu + (N-m) \log(1-\mu).$$

The location of the maximum is where the derivative with respect to $\mu$ vanishes. The derivative is

$$\frac{d}{d\mu}p(D|\mu) = \frac{m}{\mu} - \frac{N-m}{1-\mu}.$$

Setting to zero, multiplying by $\mu(1-\mu)$ and solving for $\mu$ gives the Maximum-Likelihood Estimate (MLE)

$$\mu_{ML} = \frac{m}{N}$$

Returning to flipping the coin, if we happen to get tails $(x_n = 0)$ three times in a row $(m=0)$, then the MLE is $\mu_{ML} = 0$. The interpretation is that in all future flips we would continue to see tails. Equally, if we happen to heads $(x_n = 1)$ three times in a row $(m=3)$, the MLE is $\mu_{ML} = 1$. Both cases are realistic, but the conclusion is not caused by a small number of trials. In general, to get a good likelihood estimate for any parameter, many observations are necessary.

However, in real applications this abundance of data might be a luxury. If we describe about $\mu$, mathematically and then use Bayes rules to modify "weak" data is necessary to estimate the parameter. It is the probability of success, and therefore $\mu \in [0, 1]$. Thus the beta distribution $\text{Beta}(\alpha, \beta)$ lends itself to describe $\mu$, where $\alpha$ and $\beta$ are known as hyperparameters and to some initial values. In the distribution, we will see how these parameters get updated with data becoming.

The joint probability density of $\mu$ and $m$ is the product of the likelihood and the prior

$$f(\mu, m, \alpha, \beta) = p(D)\text{Beta}(\mu, \beta) = \mu^{m}(1-\mu)^{N-m} \frac{\Gamma(\alpha+\beta)}{\Gamma(\alpha)\Gamma(\beta)} \mu^{\alpha-1}(1-\mu)^{\beta-1}$$

The posterior density of $f, m, \alpha, \beta$, is proportional to the joint distribution following Bayes' rules. The constant factors can be dropped when using the proportionality $\propto$ sign, and

$$f(\mu, m, \alpha, \beta) \propto \mu^{m+\alpha-1}(1-\mu)^{N-m+\beta-1}$$
