## 2.5 Functions of Continuous Random Variables

Since Machine Learning, data sometimes is a function of other data, it is important to consider functions of random variables and know the techniques to derive the probability density functions. If $x$ is a continuous random variable with probability density function $f_x(x)$, then for a continuous variable $g$, $g(x)$ is also a continuous random variable, but what is its probability density function $f_g(y)$? We include subscripts to be clear the random variable the probability density function and the cumulative distribution refer.

We restrict our attention to the case when $g$ is a one-to-one transformation. That each value of $g$ generates exactly one value of $y$, and each value of $y$ is generated by exactly one value of $x$. Because of this, an inverse function $g^{-1}$ exists such that $x=g^{-1}(y)$. Since $g$ is continuous, it has to be strictly decreasing or increasing.

Taking the increasing case first, we can derive the probability density function using the cumulative distribution functions $F_x$ and $F_y$. Given a $y$,

$F_y(y) = p(g(x) \le y)$.

Now, since $g$ is strictly increasing, if $g(x) \le y$, then $x \le g^{-1}(y)$ at the same time. Hence,

$F_y(y) = p(x \le g^{-1}(y)) = F_x(g^{-1}(y)) = \int_{-\infty}^{g^{-1}(y)} f_x(x)dx$.

Using integration by substitution, setting $x=g^{-1}(t)$ the upper limit becomes $y$ and derive $dx=(g^{-1})'(t)dt$.

$F_y(y) = \int_{-\infty}^{y} f_x(g^{-1}(t))(g^{-1})'(t)dt$.

To find the probability density function, we differentiate with respect to $y$. By the Fundamental Theorem of Calculus

$f_y(y) = f_x(g^{-1}(y))(g^{-1})'(y)$.

The derivation for the strictly decreasing case starts off in the same way. However, $g(x)$ is less than or equal to $y$, and only if $x \ge g^{-1}(y)$, due to $g$ being decreasing.

$F_y(y) = p(x \ge g^{-1}(y)) = 1 - F_x(g^{-1}(y)) = 1 - \int_{-\infty}^{g^{-1}(y)} f_x(x)dx$.

![](img/c6c76bf52016db7e78a5e30d4766ef81_73_0.png)

Figure 2:24: The $\chi^2$ probability density function for various degrees of freedom k.

Again, integrating by substitution and differentiating with respect to $y$ gives

$f_y(y) = -f_x(g^{-1}(y))(g^{-1})'(y)$.

Since $g$ is decreasing, so $g^{-1}$ and its derivative is negative. This makes the expression overall positive.
Since the strictly increasing case the derivative of $g^{-1}(y)$ is always positive, both cases can be summarized as

$f_y(y) = f_x(g^{-1}(y)) |(g^{-1})'(y)| = f_x(g^{-1}(y)) \left|\frac{dx}{dy}\right|$ \quad (2.17)

where the last uses a common shorthand notation. This is known as change-of-variable technique, in its derivation, we change the variable in the integral. Another name is method of direct transformation.
We illustrate the case when g is not a one-to-one transformation, by an example first. Let $x$ follow the normal distribution $N(0,1)$ and let $y=x^2$. While $-\infty < x < \infty$, we have $0 \le y < \infty$. Each value of $y$ is generated by two values $x_1 = -\sqrt{y}$ and $x_2 = \sqrt{y}$. Taking the same approach as

```
$F_y(y) = p(x^2 \le y) = p(-\sqrt{y} \le x \le \sqrt{y}) = F_x(\sqrt{y}) - F_x(-\sqrt{y})$
$ = \int_{-\infty}^{\sqrt{y}} f_x(x)dx - \int_{-\infty}^{-\sqrt{y}} f_x(x)dx$
$ = \int_{-\infty}^{\sqrt{y}} f_x(t)\frac{1}{2\sqrt{t}}dt - \int_{-\infty}^{-\sqrt{y}} f_x(t)\frac{-1}{2\sqrt{t}}dt$,
```

![](img/c6c76bf52016db7e78a5e30d4766ef81_74_0.png)

Figure 2:25: The $\chi^2$ cumulative distribution function for various degrees of freedom k.

where the last line is the integration by substitution, but different substitutions are used for each integral. For the first integral we substitute $x=\sqrt{t}$, and for the second $x=-\sqrt{t}$. After differentiation with respect to $y$, we have:

$$f_y(y) = \frac{1}{2\sqrt{y}} [f_x(\sqrt{y}) + f_x(-\sqrt{y})]$$

Using $f_x(x) = \exp(-x^2)/2$, we get

$$f_y(y) = \frac{1}{2\sqrt{y}} \exp(-y/2)$$

This is the chi-square distribution, also denoted as $\chi^2$-distribution, with one degree of freedom. More generally, the probability density function of $\chi^2$-distribution with $k$ degrees of freedom is given

$$\chi^2(x) = \frac{1}{2\Gamma(k/2)} x^{k/2-1} \exp(-x/2)$$

The mean lies at $k$ and the variance is $2k$. The previous result for $k=1$ follows from $\Gamma(1/2)=\sqrt{\pi}$. Figures 2.24 and 2.25 give examples of probability density function and cumulative distribution for various degrees of freedom.
If $g$ is a many-to-one mapping, that value of $y$ might be generated by several values of $x$, the general approach to find $f_g(y)$ is:

- Find all intervals $(a_1(y), b_1(y)), \dots, (a_j(y), b_j(y))$ of $x$ which cause $g(x)$ to be less than or equal to $y$ (note that $a_i$ could be $-\infty$ and $b_i$ could be $+\infty$).
- Calculate $F_y(y)$ as a sum over these intervals,

```
$F_y(y) = \sum_{i=1}^{k} \int_{-\infty}^{b_i(y)} f_x(x)dx - \int_{-\infty}^{a_i(y)} f_x(x)dx$
```
- Use integration by substitution.
- Differentiate $F_y(y)$ with respect to $y$.

In the above example, there was only one where $a_1(y) = -\sqrt{y}$ and $b_1(y) = \sqrt{y}$. This can be extended to $y$ being a function of multiple random variables $x_1, \dots, x_K$ which are summarized as $\mathbf{x} = (x_1, \dots, x_K)^T$ and follow a probability distribution $f_{\mathbf{x}}(\mathbf{x})$. The first step is to find the region $R(y)$ where $\mathbf{x} \in R(y)$ results in $g(\mathbf{x}) \le y$. Then calculate

```
$F_y(y) = \int_{R(y)} f_{\mathbf{x}}(\mathbf{x})d\mathbf{x}.$
```

with respect to $y$. However, this task might not be straightforward, found no closed solution for the integral, which is in cases. We might illustrate with some examples.

Let $y = g(x_1, x_2) = x_1 + x_2$, where $x_1$ and $x_2$ are independent variables. Because of dependence, this simplifies as $f_{\mathbf{x}}(\mathbf{x}) = f_1(x_1)f_2(x_2)$. The condition $g(x_1, x_2) = x_1 + x_2 \le y$ can be written as $x_1 \le y$ and $x_2 \le y - x_1$, where all inequalities have to hold at the same time. While the interval of $x_1$ only depends on $y$, the interval of $x_2$ depends on both $y$ and $x_1$. The shaded area in Figure 2.26 shows where $x_1$ and $x_2$ lie to have $x_1 + x_2 \le y$.

We can now calculate

```
$F_y(y) = \int_{0}^{y} f_{x_1}(x_1) \int_{x_1}^{y-x_1} f_{x_2}(x_2) dx_2 dx_1,$
```

where $x_2$ lie between zero and $\infty$ and both follow the exponential distribution, $x_1, x_2 \sim \text{Exp}(\beta)$ with probability density function as defined in Equation 2.13. For simplicity we let $\beta=1$. Then

```
$F_y(y) = \int_{0}^{y} \exp(-x_1) \int_{0}^{y-x_1} \exp(-x_2) dx_2 dx_1 $
= \int_{0}^{y} \exp(-x_1) [-\exp(-x_2)]_{0}^{y-x_1} dx_1 $
= \int_{0}^{y} \exp(-x_1) [1-\exp(-y+x_1)] dx_1 $
= [1-\exp(-y)-y\exp(-y)].$
```

Differentiating with respect to $y$ gives

```
$f_y(y) = \exp(-y)-(\exp(-y)-y\exp(-y)) = y\exp(-y).$
```

This probability density function describes the gamma distribution for parameters $\alpha=2$ and $\beta=1$. More generally, the probability density function of the gamma distribution is defined as

$$\text{Gamma}(x,\beta) = \begin{cases} \frac{1}{\Gamma(\alpha)\beta^{\alpha}}x^{\alpha-1}\exp(-\frac{x}{\beta}) & \text{for } x\geq0,\,0 & \text{for } x<0.\end{cases}$$

The parameter $\alpha$ is known as the shape parameter, while $\beta$ and $1/\beta$ are the scale parameter and rate parameter for the exponential distribution. The exponential distribution is a special case of the gamma distribution where $\alpha=1$. The $\chi^2$-distribution with $k$ degrees of freedom is a special case with $\alpha=k/2$ and $\beta=2$.

Secondly, let $x_1$ and $x_2$ lie in all $\mathbb{R}$ and both follow the standard normal distribution. Then

```
$F_y(y) = \frac{1}{2\pi}\int_{-\infty}^{y}\exp(-x_1^2/2)\int_{-\infty}^{y-x_1}\exp(-x_2^2/2)dx_2dx_1.\quad(2.18)$
```

The inner integral is the cumulative distribution $F_{x_2}(y-x_1)$, while
