We already have one of caution, when using the log-normal distribution, in assuming an underlying distribution, is a very strong assumption, which must be well justified and characterized, in new case Figure 2.14 shows the log-normal density function for expectation $E[x] = 10$ and $var[x] = 1$ on the left and the normal density function with the same expectation and variance on the right. They are essentially indistinguishable. The main difference is that a normal distribution allows negative values whereas however, while a log-normal distribution allows only positive values.

The log-normal probability density function has its only maximum at $\exp(\mu-\sigma^2)$. This is also known as mode. Both the log-normal and normal distribution are unimodal, since they have one maximum. If a probability density function has several local maxima, which can take different values, it is called multimodal. For the normal distribution the mode coincides with the mean. The log-normal probability density function is looking more and more like the normal one, the closer the mode gets to the expectation, that is the mean. Using Equations (2.12), the mode can be calculated as

```
$$\exp(\mu-\sigma^2) = \exp\left[\log\frac{E[x]}{\sqrt{1+\frac{var[x]}{E[x]^2}}} - \frac{3}{2}\right]$
$$= \left(1+\frac{var[x]}{E[x]^2}\right)^{-1}E[x]$
```

The factor by which the mode differs from the expectation is very close to one, if the variance is much smaller than the square of the expectation. In our case with $E[x] = 10$ and $var[x] = 1$, the factor is approximately 0.985.
