Let **X** be an $m 	imes n$ matrix **a** and **b** constant vectors of length $m$ and $n$, respectively. Then

```
$$\frac{\partial}{\partial X}(X^T X \mathbf{b}) = \mathbf{a}b^T$
```



Let **X** be an $m 	imes n$ matrix **a** and **b** constant vectors of length $n$ and $m$, respectively. Then

```
$$\frac{\partial}{\partial X}(\mathbf{a}^T X^T \mathbf{b}) = \mathbf{b}a^T$
```



Let **X** be an invertible matrix, where the entries depend on a variable $x$. Then

```
$$\frac{\partial}{\partial x}X^{-1} = -X^{-1}\frac{\partial X}{\partial x}X^{-1$
```



Let **X** be an invertible $n 	imes n$ matrix **a** and **b** constant vectors of length $n$, then

```
$$\frac{\partial}{\partial A}(\mathbf{a}^T X^{-1} \mathbf{b}) = -(X^{-1})^T ba^T(X^{-1})^T$
```



Let **X** be a general $m 	imes n$ matrix, **A** and **C** constant matrices of dimensions $k 	imes m$, $n 	imes n$ and $m 	imes k$, respectively. Then

```
$$\frac{\partial}{\partial X}(\mathbf{A}XB^T \mathbf{C}) = \mathbf{A}^T C^T XB^T + \mathbf{A}CB^T XB^T$
```



Let **A** be a square matrix and **X** a *diagonal* matrix of the same dimension. Then the derivative of the trace of the product is

```
$$\frac{\partial}{\partial X}tr(\mathbfmathbf{AX}) = diag(\mathbf{A})$
```

Then diag(**A**) is a diagonal matrix with the same diagonal as **A**.
