## 1. 理解 SCADA 与 ICS

学员首先将全面了解 SCADA 与 ICS，包括其功能、架构以及在管理各类基础设施组件中的关键作用。这些基础知识对于制定有效的安全策略至关重要。

## 2. 漏洞与威胁

在本部分中，学员将探究 SCADA 与 ICS 系统固有的漏洞。他们将深入研究这些系统面临的潜在威胁，包括定向网络攻击、恶意软件和内部威胁。

## 3. SCADA/ICS 的风险评估与缓解

风险评估在此占据核心地位，学员将评估与 SCADA 和 ICS 相关的独特风险。他们将学习识别这些系统特有的漏洞，并制定以业务连续性为优先的缓解策略。

## 4. 安全控制与技术

保障 SCADA 和 ICS 系统的安全通常需要专门的安全控制。学员将探讨针对关键基础设施需求量身定制的访问控制、网络分段和入侵检测系统的实施。

## 5. 合规与标准

鉴于 SCADA 和 ICS 的关键性，遵循行业特定标准至关重要。学员将深入研究诸如 `NIST SP 800-82` 和 `ISA/IEC 62443` 等标准，确保关键基础设施运营商满足严格的网络安全要求。

## 6. SCADA/ICS 的事件响应

学员将学习如何制定针对 SCADA 和 ICS 环境的事件响应计划。快速检测和响应对于将网络事件对关键操作的影响降至最低至关重要。

“SCADA 与工业控制系统 (ICS) 安全”部分为学员提供了保护管理关键基础设施的复杂系统所需的知识和技能。通过理解漏洞、实施稳健的安全控制并遵守合规标准，学员在确保 SCADA 和 ICS 系统的可靠性和韧性方面发挥着关键作用。

有效的风险评估和缓解策略是保护电网和能源系统的核心。学员将学习评估各能源特有的风险，并制定确保持续供电的缓解计划。

## 4. 电网安全控制

## 5. 法规合规与电网韧性

能源行业受制于 `NERC CIP` 等监管框架。学员将理解合规在确保电网和能源基础设施韧性方面的重要性。

## 6. 事件响应与恢复

发生网络事件时，迅速有效的响应至关重要。学员将学习如何制定针对能源行业的事件响应计划，以最大限度地减少停机时间并防止级联故障。

“电网与能源行业安全”部分为学员提供了保护能源行业并维持稳定电力供应所需的知识和技能。通过理解漏洞、实施量身定制的安全控制并遵守合规标准，学员在保障这一关键基础设施的重要组成部分方面发挥着枢纽作用。
