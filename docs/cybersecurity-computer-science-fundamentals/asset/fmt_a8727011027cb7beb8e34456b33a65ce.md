## Incident Classification: Code-Based Incident Categorization

Incident classification is a crucial step in an incident response plan. Code-based examples demonstrate how incidents can be categorized based on severity, impact, and urgency. This classification helps organizations prioritize their response efforts effectively.

### Example: Python code to classify an incident based on severity

```python
def classify_incident(severity_score):
    if severity_score >= 8:
        return "Critical"
    elif severity_score >= 4:
        return "High"
    else:
        return "Medium"
```

## File System Analysis: Code-Based Examination

Analyzing file systems is a core competency of digital forensics. Code-based file system analysis examples showcase techniques for recovering deleted files, examining file metadata, and identifying artifacts that can provide insights into user activities and system events.

### Example: Python script to recover deleted files from a Windows NTFS file system

```python
import pytsk3

# Open the disk image
img = pytsk3.Img_Info('evidence_image.dd')

# Create a file system object
fs = pytsk3.FS_Info(img)

# List deleted files
for directory in fs.open_dir(path='/'):
    for file_entry in directory:
        if file_entry.is_deleted():
            print("Recovered:", file_entry.info.name.name)
```
