
加密在确保数据机密性方面发挥着关键作用。它将明文转换为密文，使数据对未授权用户不可读。在代码中，加密和解密可以这样实现：

### 静态数据加密

```
encrypted_data = encrypt(data, encryption_key)
```

### 需要时解密数据

```
decrypted_data = decrypt(encrypted_data, decryption_key)
```
