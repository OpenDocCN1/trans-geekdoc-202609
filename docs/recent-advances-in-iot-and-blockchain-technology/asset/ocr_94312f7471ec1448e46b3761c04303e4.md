# Algorithm 2.

Forecasting health parameters & generating emergency alerts.

+   Input: Data for health parameters is taken as input. from the database.

+   Step 1. Apply times series algorithmic techniques to forecast the health parameters.

+   Step 2. Set an appropriate threshold for each health parameter.

+   Step 3. If (temperature > threshold).

+   Step 3.1. The user is critical and an emergency alert is sent to the concerned person via email.

+   Step 4. If (pulse rate > threshold).

+   Step 4.1. The user is critical and an emergency alert is sent to the concerned person via email.

+   Step 5. If (lung capacity > threshold).

+   Step 5.1. The user is critical and an emergency alert is sent to the concerned person via email.

+   Step 6. Else.

+   Step 6.1. The user is safe no alert is generated.

+   Step 7. Exit.
