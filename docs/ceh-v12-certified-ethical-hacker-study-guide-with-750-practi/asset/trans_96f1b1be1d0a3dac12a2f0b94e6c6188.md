
-   [启动扫描](https://wiki.example.org/feynmans_learning_method)时，需要查看您的任务列表，并点击类似音频或视频播放器启动按钮的绿色箭头。扫描在您点击启动后才会运行。仅创建扫描即表示您已设置其参数，并不表示已启动扫描。这里的调度功能很有用，因为 OpenVAS 会在您发出指令时自动开始扫描，而无需您手动启动。

### Scan Results

在扫描进行期间，您可以监控扫描结果。此外，您还能够回顾所有已完成的扫描以及历史漏洞。Scans dashboard 会提供图表，帮助可视化漏洞随时间的变化，从而让您判断目标系统的安全态势是否在改善。您可以在 [Figure 5.15](#c05.xhtml#c05-fig-0015) 查看仪表盘。图表主要聚焦于报告，但这些图表并未展示您所有扫描中漏洞的整体情况。在该图的底部，您可以看到本次安装中已运行的两次扫描的概览。即时扫描是通过 Task Wizard（快速启动方式）完成的。

Scans 菜单提供了多种查看结果的方式。我们首先通过 Results 页面来查看。该页面列出了所有扫描结果。您还能看到更多图表。图表和结果列表在 [Figure 5.16](#c05.xhtml#c05-fig-0016) 中。虽然图表有趣，但结果列表包含一些重要信息。第一列显示漏洞的简短名称，这应能让您大致了解漏洞的内容。至少，您能从漏洞名称中获取关于相关服务或设备的信息。

此外，您还能获得其他有用信息。在摘要之上，您会看到严重程度。严重程度包括 High、Medium、Low。在严重程度左侧是解决方案类型。示例中显示的全部是厂商补丁。您可能还会看到缓解措施（mitigation），即如果漏洞被利用，存在减轻影响的方法。也可能出现“无可用修复”情况。图 5.16 所示的全部问题是有厂商补丁的，但也存在无补丁的问题以及有缓解措施的问题。

在严重程度右侧，显示的是 QoD（质量检测度）。QoD 表示 OpenVAS 对漏洞是否为真实正例的置信度。在某些看似 macOS 漏洞中，QoD 列会出现非常高的数值。鉴于这些系统运行的是最新的 macOS 并且在扫描时已全部打补丁，这些高置信度数值具有误导性。要弄清楚 OpenVAS 依据什么判断为真实正例，需要查看关联的 NASL 文件。

在最右侧列，您可以访问操作，如 [Figure 5.17](#c05.xhtml#c05-fig-0017) 所示。由于报告会在 OpenVAS 实例存续期间保留，您可能需要对发现进行必要的修改。正如 macOS 发现的情况，我可以添加一个覆盖（override）。如前所述，并非每个发现都如 OpenVAS 所呈现。有些可能是误报，例如。您可以通过使用覆盖将发现的严重程度设置为“误报”。在 [Figure 5.17](#c05.xhtml#c05-fig-0017) 中可以看到用于设置覆盖参数的对话框，包括将严重程度设置为误报的选项。

当然，误报不是唯一可以修改严重程度的情形。您可以提高或降低严重程度。如果您比 OpenVAS 更了解情况，尤其是当您为被测试的公司工作或与其紧密合作而非作为严格对手时，您可能会发现需要调整严重程度。如果已有缓解措施，您可能希望降低严重程度。也可能有理由提高 OpenVAS 提供的严重程度，因为这是供软件厂商通用的发现。

您还可以在覆盖中设置其他参数，而不只是严重程度。如果您要修改严重程度，通常还会添加注释，说明更改的原因和目的。这让所有拥有 OpenVAS 访问权限的人员能够审查更改并了解背后的原因。除了修改严重程度等参数外，您还可以为每个发现添加注释。

通过使用注释和覆盖，OpenVAS 可被视为一种漏洞管理工具，而不只是单纯的漏洞扫描仪。您可以用它进行历史追溯、识别已知漏洞，或修改不同参数。存储的这些信息对负责保护系统和网络的任何人都非常有价值，因为他们时刻在与漏洞作斗争。历史信息，尤其是缓解措施以及已采取的 remediation 步骤，对安全专业人员非常有用。

### Nessus

Nessus 是 OpenVAS 的父项目，因此值得一看，尤其是观察其与 OpenVAS 的路径 diverged（背离）之处。虽然 Nessus 是商业产品，但提供了家庭许可证，您可以在家庭网络上使用它，与 OpenVAS 进行比较，并了解另一种漏洞扫描思路。登录后，您会进入扫描列表页面，初始时列表为空。要启动扫描，请点击 New 按钮，这将带您进入可用的扫描策略列表。您可以在 [Figure 5.18](#c05.xhtml#c05-fig-0018) 中看到部分内置扫描策略。部分策略标有 *Upgrade*，表示这些策略仅在商业版中提供，Home 许可证中不可用。

如果我们以 Basic Network Scan 为起点，即可开始选择目标并进行自定义。[Figure 5.19](#c05.xhtml#c05-fig-0019) 展示了 Basic Network Scan 的配置设置。第一屏显示您需要提供扫描的名称。请记住，您在此创建的是配置，可多次运行该配置，每次运行都会自动记录时间戳，无需您自行添加日期时间。建议为配置起一个有意义的名称，以便与其他配置区分。

例如，您可能有一个配置包含特定凭据。[Figure 5.20](#c05.xhtml#c05-fig-0020) 展示了凭据配置。您可以为主机创建 SSH 和 Windows 凭据用于身份验证。对于每种类型，您可以创建多个配置。您可以使用 SSH 密钥进行某些系统的验证，同时也可以设置用户名和密码的验证方式。根据界面说明，SSH 和 Windows 凭据数量没有上限。要创建另一组凭据，只需点击对应凭据类型行末的按钮即可。
