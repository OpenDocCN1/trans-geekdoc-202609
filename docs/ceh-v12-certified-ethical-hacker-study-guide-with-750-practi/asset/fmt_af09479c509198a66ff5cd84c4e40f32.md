
# Scanning Networks

Scanning networks is a fundamental step in reconnaissance. It involves discovering active hosts, services, and open ports on a network.

## Techniques

- **Passive scanning**: Collecting information without interacting with the target, such as using `Wireshark` to capture traffic.
- **Active scanning**: Sending probes to the target, e.g., using `nmap` to perform a SYN scan: `nmap -sS 192.168.1.0/24`.

## Tools

- `nmap`: The industry‑standard network mapper for host discovery and port scanning.
- `masscan`: A high‑speed scanner capable of scanning the entire Internet in minutes.
- `netdiscover`: Useful for quickly identifying devices on a local LAN.

## Example

```
nmap -sV -p 22,80,443 10.0.0.0/16
```

This command scans the 10.0.0.0/16 range on ports 22, 80, and 443, attempting version detection (`-sV`).

## Summary

Scanning provides the essential data needed to plan further exploitation steps, such as identifying vulnerable services or mapping the network topology.
