除了主机凭据外，你还可以为 `database`、`miscellaneous` 和 `plain text` 设置身份验证凭据。最后一类用于 `HTTP`、`FTP` 和 `SMTP` 等协议。`Miscellaneous` 提供 `VMware` 和 `Palo Alto` 防火墙的设置。这使得 Nessus 能够检查各种应用程序和设备的本地漏洞。

除了凭据，你还可以配置想要运行的插件。可以通过点击顶部的 **Plugins** 标签页进入插件设置。回顾一下 [图 5.19](#c05.xhtml#c05-fig-0019)，你会看到左侧垂直排列的一组标签页。这不仅提供了基本设置的访问，还提供了发现、评估、报告和高级配置的访问。发现标签页让你确定将在网络上进行的发现类型，即可以设置端口扫描参数。默认情况下，端口扫描会针对常用端口执行。你可以选择对所有端口进行扫描，这可能会发现额外的漏洞，或至少发现一些你可能未曾预期的端口。

评估标签页让你设置 Nessus 应针对哪些 Web 漏洞进行扫描。默认情况下，Nessus 不会扫描 Web 漏洞。你可以设置不同级别的 Web 漏洞扫描。评估标签页还有一个重要设置。默认情况下，Nessus 会限制检测到的假阳数量。需要注意的是，这里提到的所有设置均位于基础网络扫描策略中。其他扫描策略会有不同的设置，其中一些可以更改。要获取全部设置，你需要通过高级扫描，所有设置都会暴露并可供修改。

报告标签页用于调整报告的详细程度。你可能希望限制报告中提供的细节，仅保留最小信息。默认情况下，Nessus 报告相当完整。每个发现都会包含漏洞细节、严重程度、关联参考以及可能的 remediation。为确保不熟悉 Nessus 的人也能够充分理解，需要提供足够的细节，这会占用大量空间。

在扫描进行中以及扫描完成后，你可以查看结果。最初，你会在点击“My Scans” 中的扫描名称时看到所有漏洞的列表。如 [图 5.21](#c05.xhtml#c05-fig-0021) 所示，这里有一个部分列表。除了漏洞列表外，还会显示一个图表，指示哪些类别的漏洞数量最多。在所示扫描中，绝大多数为信息性消息，其次是中等严重程度的漏洞。

![图 5.21 扫描结果列表](images/c05f021.png)

[**图 5.21**](#c05.xhtml#R_c05-fig-0021) 扫描结果列表

主机列表按 Nessus 识别的问题总数排序，但并非所有发现都是漏洞，因为还有信息性项目。Nessus 在扫描时识别出了 50 台主机，IP 地址以 `.52` 结尾的主机拥有最多已知漏洞。这并不意味着没有其他漏洞，只是 Nessus 当时未能识别。还可能存在假阴，即 Nessus 未能发现已存在的漏洞。右侧列显示的百分比表示 Nessus 认为对该主机的扫描完成度。该快照在扫描中途取得。

页面顶部有三个标签页。第一个标签页是主机列表，如前所述，按漏洞总数排序。第二个标签页是漏洞数量，按发现的严重程度排序，Critical 问题位于顶部，随后是 High、Medium 等。本地网络扫描发现了两个不同的 Critical 问题。其中一个与 Mozilla Foundation 的软件有关，Nessus 显示目标主机上安装了 Mozilla Foundation 的 Thunderbird 或 Firefox，但版本已不再支持。另一个问题涉及 macOS 系统，操作系统版本比最新版本落后一版。[图 5.22](#c05.xhtml#c05-fig-0022) 展示了与 Mozilla 漏洞相关的详细信息。

在输出中，你会看到发现的描述以及解决方案，即升级到受支持的版本。下方还有指向其他站点的参考链接，提供更多关于该问题的信息。参考站点下方是扫描插件的详细信息，显示已发现的应用版本以及当前可用且受 Mozilla Foundation 支持的版本。可以看到已安装版本落后五个版本，而当时 Mozilla Foundation 提供的当前受支持版本为 61.0。输出中没有显示第二个主机的 IP 地址，仅为简 brevity 显示了一个 IP。

页面顶部还有一个标记为 **Remediations** 的标签，用于输出如何修复部分已识别的漏洞。如 [图 5.23](#c05.xhtml#c05-fig-0023) 所示，找到的四条修复措施全部与升级到最新软件版本有关，包括在一种情况下更新正在使用的操作系统版本。

如前所述，严重程度会有所不同，Nessus 认为的严重程度不一定符合你对环境的了解。你可以在 **Plugin Rules** 标签页（位于左侧导航栏）创建规则，使得针对特定主机的发现自动重新分类。[图 5.24](#c05.xhtml#c05-fig-0024) 展示了插件规则设置的对话框。你可以指定主机或留空以适用于所有主机，并指定规则适用的插件 ID。设置好所有参数后，选择想要关联的严重程度，Nessus 会自动完成后续操作。
