To successfully install Hyperledger Fabric, you should be familiar with Go and Node.js programming languages, and have the following features installed on your computer: cURL, Node.js, npm package manager, Go language, Docker, and Docker Compose.

# ## 24.2 Installing cURL

Open a terminal window: CTRL+ALT+T.

Type the following command and enter your password:

```
$ sudo apt install curl
```

To check, run the following command in your terminal/command line:

```
$ curl -V
```

# ## 24.3 Installing Docker

To install Docker CE, you need the 64-bit version of one of these Ubuntu versions:

+   - Cosmic 18.10
- Bionic 18.04 (LTS)
- Xenial 16.04 (LTS)

Docker CE is supported on x86_64 (or amd64), armhf, arm64, s390x (IBM Z), and pppc64le (IBM Power) architectures.
