# 7.1.7 Weighted Random Walk

How should we overcome the ‘Lazy Tips’ phenomenon? We might impose a rule that requires all incoming transactions to approve recent transactions. However, this coercive way is against the principles of decentralization and democracy, the core of decentralized ledger technologies. Therefore, IOTA opted for the persuasion method. It implements a built-in incentives system that rewards the participants for approving recent transactions. This method is called the weighted random walk (WRW).
