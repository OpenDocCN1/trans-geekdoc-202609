```
$ docker images
```

Note the tags for the images above boxed in red. If the Docker images are not already tagged with the latest tag, perform the following command for each of the Docker images:

```
$ docker tag hyperledger/fabric-tools:x86_64-1.0.2
hyperledger/fabric-tools:latest
```

Swap out the blue portion with your list of repositories. Also, swap out the red portion with the name of the Docker image you are switching to the tag for (e.g.: fabric-tools, fabric-ccenv, fabric-orderer, etc.). Repeat this step for all Docker images you see in the list.
