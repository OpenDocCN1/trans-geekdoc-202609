# Setting up Automotive Smart Supply Chain Management(SSCM) with Hyperledger Fabric

This Automotive Smart Supply Chain Management Application is built using Hyperledger Fabric developed by the Linux Foundation. Hyperledger Fabric is a permitted private blockchain network that provides ledger services to application clients and administrators. It allows multiple organizations to collaborate as a consortium to form the network. The permissions to join the network are determined by a set of policies that are agreed to by the consortium when the network is configured.

# 24.1 Technical Requirements

The OS is 64-bit Ubuntu 16.04 VPS, other versions might not work.

Download Ubuntu 16.04.6 LTS (Xenial Xerus) from

http://cl.releases.ubuntu.com/16.04/

Select 64-bit PC (AMD64) desktop image

Choose this if you have a computer based on the AMD64 or EM64T architecture (e.g., Athlon64, Opteron, EM64T Xeon, Core 2). If you have a non-64-bit processor made by AMD, or if you need full support for 32-bit code, use the i386 images instead. Choose this if you are at unsure.
