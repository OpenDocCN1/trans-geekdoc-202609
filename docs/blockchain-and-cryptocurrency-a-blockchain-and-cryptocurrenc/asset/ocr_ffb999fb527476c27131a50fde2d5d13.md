In the following step, the Signature Verification Algorithm will accept the request (to join the network) if the signature byte array matches a valid signature for the inputted endorsement or reject the request if not. If the user is accepted, he or she can see the transactions in the network and perform transactions with other actors in the network. On the other hand, if the user is rejected, he or she will not be able to submit transactions to the network or view any previous transactions.
