# 21.6 Start Mining

To start mining on the private network, Enter the geth console
with the following command

Geth --rpc console

In the Geth Console type
miner.()

The output is as shown in Figure 21.5

![](bbox=[0.137, 0.433, 0.881, 0.703])

Figure 21.5

Now you can see that the mining process is generating Ethers,
as as shown Figure 21.6. Bear in mind that these are fake Ethers
as and can only be used for a private test net.
