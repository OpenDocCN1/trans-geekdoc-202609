# 10.4 The Blockchain Solution

The solution is to develop a textile blockchain network hosted on a cloud server, as shown in Figure 10.7. The blockchain network architecture is based on Hyperledger Fabric Framework.

All the transactions between channel members will be recorded through channel APIs by the peer nodes. The peer nodes will then submit the data to the blockchain platform hosted on a cloud server to be validated by the validator nodes and recorded permanently on the blockchain. Smart contracts (chaincode) will be executed in between. The updated blockchain will be broadcasted to the whole Textile Blockchain Network. Every channel member will be able to trace and track their product ID by scanning the QR code that is connected to the network via the UI that is connected to the channel APIs.
