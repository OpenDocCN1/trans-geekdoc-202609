```
mapping (address => uint) public coinBalances;

// Light clients can react on changes efficiently
thanks to events.
event Sent(address from, address to, uint sum);
// The code of this constructor is run only once the
contract is created.
function myCoin() public {
    minter = msg.sender;
}
function mint(address receiver, uint sum) public{
    if (msg.sender != minter) return;
    coinBalances[receiver] += sum;
}
function send(address receiver, uint sum) public {
    if (coinBalances[msg.sender] < sum) return;
    coinBalances[msg.sender] -= sum;
    coinBalances[receiver] += sum;
    emit Sent (msg.sender, receiver, sum);
}
```

The line address public minter; declares a state variable of type address that is publicly accessible. The address type is a 160-bit value that does not allow any arithmetic operations. It is suitable for storing addresses of contracts or keypairs belonging to external persons. The keyword public automatically generates a function that allows you to access the current value
