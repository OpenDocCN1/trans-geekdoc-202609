# Directory Structure

The default Truffle directory structure contains the following\folders and files:

+   - contracts/: Contains the Solidity source files for our smart
contracts. There is an important contract in here called Migrations.sol, which we will discuss later.
- migrations/: Truffle uses a migration system to handle smart
contract deployments. Migration is an additional special\smart contract that keeps track of changes.
- test/: Contains both JavaScript and Solidity tests for our
contracts.
- Truffle.Js: Truffle Configuration File.
