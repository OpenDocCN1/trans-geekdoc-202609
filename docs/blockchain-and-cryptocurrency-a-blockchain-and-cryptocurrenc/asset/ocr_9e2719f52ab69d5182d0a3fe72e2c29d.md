```
"baseDir": ["./src", "./build/contracts"],
"open": false
},
"browser": ["chrome"]
}
```

This tells lite-server which files to include in our base directory.
We add the ./src directory for our website files and ./build/contracts directory for the contract artifacts.

I added "browser": ["chrome"]

So that the UI opens in the Chrome browser.

We have also added a dev command to the scripts object in the package.json file in the project's root directory. The scripts object allows us to alias console commands to a single npm command.

To launch the app, enter the command in the VS Code Console.
npm run dev
