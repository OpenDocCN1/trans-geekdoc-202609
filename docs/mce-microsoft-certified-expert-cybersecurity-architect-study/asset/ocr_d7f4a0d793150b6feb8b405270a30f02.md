Consequently, workload owners must be notified when security recommendations are open for remediation. The Workflow Automation feature of Defender for Cloud can be used to trigger actions, such as sending an email to the resource owner, whenever a recommendation is triggered. Here are the steps:

+   1. The Microsoft Defender for Cloud team identifies that a security recommendation needs to be addressed and which resources are affected by it.
+   2. There is a ticket opened and assigned to the workload owner. This ticket contains details about the security recommendation and suggestions for remediation.
+   3. The workload owner reviews the ticket and determines that this recommendation has a quick fix. They can click the View Remediation Logic button to understand what changes will be made to the system.
+   4. They schedule remediation once they feel comfortable with the changes.
+   5. On the scheduled date, the Azure resource remediation needs to be applied as per the plan.
