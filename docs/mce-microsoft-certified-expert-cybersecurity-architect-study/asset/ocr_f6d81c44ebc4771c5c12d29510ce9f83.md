# # Specify Security Baselines for Server and Client Endpoints

A security configuration still needs to be granular enough for each organization, despite Windows Client and Windows Server being designed to be secure out of the box. Microsoft provides security baselines to guide organizations on how to configure various security features to navigate a large number of controls. Using Microsoft’s industry-standard, widely known, and well-tested configurations, you can avoid the need to create baselines yourself.
