Defender for Storage can be enabled at the subscription (recommended) or resource (optional) level. The Azure Blob Storage and Azure Files services generate telemetry streams that Defender continuously analyzes for storage. Security alerts are generated when potentially malicious activities are detected. As well as the details of the suspicious activity and the appropriate investigation steps, remediation actions, and security recommendations, Microsoft Defender for Cloud displays these alerts in its alert pane. Using the dashboard of Defender for Cloud, enable Defender for Cloud with a single click. As soon as Defender for Cloud is enabled, it will monitor the storage account and generate security recommendations. If it detects suspicious activity, Defender for Cloud will alert users. Defender for Cloud dashboards or Microsoft Sentinel dashboards can facilitate the alert.

+   - Azure virtual networks and network security groups allow users to establish secure connections.
