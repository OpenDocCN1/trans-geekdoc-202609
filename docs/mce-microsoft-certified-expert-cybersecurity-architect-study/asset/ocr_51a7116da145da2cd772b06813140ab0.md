# Remote Access

A ransomware attacker may access your organization’s intranet through a remote access connection. The Colonial Pipeline cyberattack in 2021 is an excellent example of an attacker roaming on an intranet to gather intelligence, elevate privileges, and install ransomware once a user account is compromised.
