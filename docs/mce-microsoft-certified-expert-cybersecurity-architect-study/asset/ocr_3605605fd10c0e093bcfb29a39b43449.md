Authentication Who are you? Credentials, such as a username and password, are typically used to prove an entity's identity during authentication.
The following are recommendations from Microsoft for specific products/ services from an authentication standpoint.

# Web Application

+   - Authenticating a web application should be done using a standard authentication mechanism.
+   - Authentication failure scenarios must be handled securely by applications.
+   - Adaptive authentication or step-up authentication can be enabled.
+   - Ensure that administrative interfaces are appropriately secured.
+   - Ensure that forgot password functionality is implemented securely.
+   - Implement password and account policies.
+   - Prevent username enumeration by implementing controls.

# Database

+   - Connect to SQL Server using Windows Authentication whenever possible.
+   - Use Azure Active Directory authentication whenever possible when connecting to SQL databases.
+   - Ensure that SQL server account and password policies are enforced when SQL authentication mode is used.
+   - Databases contained within a container should not use SQL authentication.
