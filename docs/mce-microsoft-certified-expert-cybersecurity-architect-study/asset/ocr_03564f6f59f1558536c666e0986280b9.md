# # Using Microsoft Sentinel and Defender for Cloud to Monitor Hybrid Security

Monitoring is one of the most important aspects of hybrid security. An architecture built on good hybrid monitoring practices should be resilient in hybrid and multi-cloud environments to provide log insights about attacks and confidentiality, integrity, and availability.

Azure Monitor resources, Azure VMs, and even VMs hosted by other cloud providers can be monitored by Microsoft Defender for Cloud.

Data collection can be simplified with Microsoft Sentinel across different sources, including Azure, on-premises solutions, and clouds with built-in connectors. Data is collected at cloud scale by Microsoft Sentinel—across all users, devices, applications, and infrastructure, including on-premises and in multiple clouds.
