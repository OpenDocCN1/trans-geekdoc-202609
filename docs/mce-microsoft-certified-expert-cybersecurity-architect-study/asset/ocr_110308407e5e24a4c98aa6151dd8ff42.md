Using Azure Virtual Desktop, you can virtualize your desktop and apps. With it, you can simplify management, run multiple sessions of Windows 10/11, optimize Microsoft 365 apps for enterprise, and use Remote Desktop Services (RDS). With Azure, you can quickly deploy and scale Windows desktops and apps, as well as get built-in security and compliance options. Virtual machines running in your Azure Virtual Desktop network do not need a set of inbound network connections. They do need to allow outbound network connections.
