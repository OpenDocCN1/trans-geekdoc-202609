Are databases and file shares reliable sources of data?<br><br>The following are recommendations from Microsoft for specific products/services from an input validation standpoint.<br><br>**Web Application**<br>- Untrusted style sheets should not be used for Extensible Stylesheet LanguageTransformations (XSLT) scripting.<br>- Make sure all pages that could contain user-controllable content opt out of automatic Multipurpose Internet Mail Extensions (MIME) sniffing.<br>- Resolving XML entities in a hardened or disabled manner.<br>- The URL canonicalization verification process is performed by applications that utilize http.sys.<br>- Accepting files from users should be controlled appropriately.<br>- Type-safe parameters should be used for data access in web applications.<br>- To prevent Model View Controller (MVC) mass assignment vulnerability, separate model binding classes or binding filter lists should be used.<br>- Prior to rendering, encode untrusted web output.<br>- All string type model properties should be validated and filtered.<br>- Rich text editors, for instance, should be sanitized since they accept all characters.<br>- Sinks without built-in encoding should not be assigned DOM elements.<br>- Make sure all redirects within the application are closed or done safely.<br>- Validate all string types accepted by controller methods.<br>- To prevent DoS due to bad regular expressions, set an upper limit time-out for regular expression processing.<br>- Razor views should not use Html.Raw.<br><br>**Database**<br>- Stored procedures should not use dynamic queries. |
