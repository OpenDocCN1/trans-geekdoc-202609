In our networks above we've been analyzing the weighted
combination $\sum_j w_j a_j$ output from the hidden neurons. We now
know how to get a lot of control over this quantity. But, as I noted
earlier, this quantity is not what's output from the network. What's
output from the network is $\sigma(\sum_j w_j a_j + b)$ where $b$ is the bias on the
output neuron. Is there some way we can achieve control over the
actual output from the network?
