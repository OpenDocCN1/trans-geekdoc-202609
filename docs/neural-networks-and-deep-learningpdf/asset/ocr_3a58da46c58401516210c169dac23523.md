This is usually true in classification problems, but for other

entropy is still minimized when $\sigma(z) = y$ for all training inputs.
When this is the case the cross-entropy has the value:

```
\(C = -\frac{1}{n} \sum_x [y \ln y + (1 - y) \ln(1 - y)].\) (64)
```

The quantity $-[y \ln y + (1 - y) \ln(1 - y)]$ is sometimes known as
the binary entropy.
