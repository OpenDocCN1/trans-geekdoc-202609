# Relevance to Student Experience

The materials, role-plays, simulations, or literature should contain or relate to themes or concepts that are important to the lives of students. The lessons need to be about the important issues related to students’ lives at their stage in development. All of the lesson objectives need to be embedded within this context so that learning is meaningful and can be applied.
