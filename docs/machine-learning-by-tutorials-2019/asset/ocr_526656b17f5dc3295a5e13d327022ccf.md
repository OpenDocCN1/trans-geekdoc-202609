Since logistic regression expects a one-dimensional vector as input, the Flatten layer unrolls the image's lines of pixels into one big strip:

![](bbox=[0.163, 0.178, 0.836, 0.293])

Flatten turns the 3D image into a 1D vector

The input image is 32×32 pixels times three channels, and so the flattened vector has length 3,072. Flatten doesn't do any computation, it just changes the shape of the input.

The real meat of the logistic regression happens in the Dense layer. This performs the matrix multiplication between the 3,072 inputs and the 20 outputs. This layer has 20 outputs because the user's number of classes is in the snacks data. In a Dense layer, each input is connected to each output.

![](bbox=[0.223, 0.496, 0.772, 0.743])

This is simply the equation we've seen before:

```
y = a[0]*x[0] + a[1]*x[1] + ... + a[3071]*x[3071] + b
```

This time, it's expressed in the slightly more efficient form as a matrix, so that Keras can compute this entire thing with a single matrix multiplication.
