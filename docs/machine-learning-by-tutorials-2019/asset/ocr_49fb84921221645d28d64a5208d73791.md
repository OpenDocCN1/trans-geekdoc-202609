# Key points

+   - MobileNet uses deep convolutions because they're less expensive than regular convolution. Ideal for running models on mobile devices. Instead of pooling layers, MobileNet uses convolutions with a stride of 2.

+   - Training a large neural network on a small dataset is almost impossible. It's smarter to transfer learning with a pre-trained model, but then you want to use data augmentation to artificially increase your training set. It's also a good idea to adapt the feature extractor to your own data by fine-tuning.

+   - Regularization helps build stable, reliable models. Besides increasing the amount of training data, you can use batch normalization, dropout and an L2 penalty to stop the model from memorizing specific training examples. The larger the number of learnable parameters in the model, the more important regularization becomes.
