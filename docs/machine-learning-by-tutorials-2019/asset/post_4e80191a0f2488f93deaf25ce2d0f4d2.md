# Using a fixed validation set

Turi Create creates a random validation dataset from the training dataset — 5% of the images. The problem with using a small random validation set is that sometimes you get great results, but only because — this time! — the validation dataset happens to be in your favor.

For example, if the model is really good at predicting the class "waffle" and the validation set happens to be mostly images of waffles, the validation accuracy will be higher than the true performance of the model. That's bad, because it may lead you to overestimate how good the model really is.

If you repeat training the model a few times, you'll see the validation accuracy vary a lot. it's better than the 67% you saw before, sometimes it's worse — on one of the author's training runs, it went low as 59%. It's hard to understand how well the model is doing when there is so much variation between runs.

To get more elaborate estimates of accuracy, use your validation set instead of letting Turi randomly select one. By using a collection of validation images that is always the same, you can control your experiments better and get reproducible results. You can now train the model with a few different configuration settings, also known as the hyperparameters, and compare the results to determine which settings work best. If you were to use a different validation set each time, the variation in the chosen images could obscure the effect of the changed hyperparameter.

# Increasing max iterations

So, is a validation accuracy of 63% good? Meh, not really. Turi Create knows too — at the end of the training output says:

> This model may not be optimal. To improve it, consider increasing max_iterations this model still has some issues (It's possible you won't get this message, this seems to vary with Turi Create.)

Let's train again, with more iterations — 200 instead of 100:

```
model = tc.image_classifier.create(train_data, target="label",
    model="squeezenet_v1.1",
    verbose=True,
    max_iterations=200,
    validation_set=val_data)
```

Note: Like ML, Turi Create has to extract the features again. It does not keep those features around — if 100 iterations already took a long time, feel free to load the pre-trained model from notebook:

```
model = tc.load_model("Snacks_200.model")
```

The number of iterations is an example of hyperparameter. This is a fancy name for the configuration settings for your model. Why? The things the model learns from the training data are called "parameters" or learned parameters. The things you configure by hand, which don't get by training, are therefore the "hyperparameters." The hyperparameters tell the model how to learn, while the training data tells the model what to learn, and the parameters describe what has actually learned.

The max_iterations setting determines how long the model will be trained. For all, it's important to set it to a good value or else the result may not be as good as you'd. If the training time is too short, the model won't had the opportunity to learn all; if the training time is long, the model will overfit.

The training accuracy is now 90%! This means on the training of 4582 examples it only gets 10%, as opposed to 20% (when the training accuracy was about 80%).

That pretty good, but remember that you shouldn't put too faith in the training accuracy by itself. More important is the validation accuracy. As you can see, this briefly went up and then down again.

The sweet spot for this model seems to be around 150 iterations where it gets a validation accuracy of 63.7%. If you train for longer, the validation accuracy starts to drop and the model becomes worse, then the training accuracy will slowly keep improving. A classic sign of overfitting.

Overfitting has a bad risk, and it's certainly an issue you'll run when you start training your own models. Overfitting isn't necessarily a bad thing to experience, as it means your model still has capacity to learn more. It's just learning the wrong things, and techniques such as regularization will help you to stay on the right path. (More about regularization later in this chapter.)

Unfortunately, Turi Create does not let you select the iteration of the model with the best validation accuracy, only the last one, and you'll have to train again with max_iterations=150, to get the best result.
