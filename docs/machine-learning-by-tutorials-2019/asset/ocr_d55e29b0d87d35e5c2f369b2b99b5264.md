# Chapter 3: Training the Image Classifier

There are several ways to deal with overfitting. The best strategy is to train with more data. Unfortunately, for this book we can't really make you download a 100GB dataset, and so we've decided to make do with a relatively small dataset. For image classifiers, we can augment your image data by flipping, rotating, shearing or changing the exposure of images. Here's an illustration of data augmentation:
