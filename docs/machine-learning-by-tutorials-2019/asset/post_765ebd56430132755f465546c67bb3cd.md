# Chapter 14: Natural Language Classification

You'll train your text classifier with Create ML, so you import it here. And you import the Playground Support framework to access the Shared Playground Data folder you set up earlier.

Now, add this bit of code to access your training and test data:

```swift
// 1
let projectDir = "TextClassification/"
let dataURL = "MovieReviews/"
let trainURL = 
playgroundSharedDataDirectory.appendingComponent(
    projectDir + dataURL + "train", isDirectory: true)
let testURL = 
playgroundSharedDataDirectory.appendingComponent(
    projectDir + dataURL + "test", isDirectory: true)
// 2
let trainData = 
MLTextClassifier.DataSource.labeledDirectories(at: trainURL)
let testData = 
MLTextClassifier.DataSource.labeledDirectories(at: testURL)
```

This creates the datasets that you'll use for training and testing your model. Here's what you did:

- 1. Create URLs pointing to the MovieReviews/train and MovieReviews/test folders containing your dataset.
- 2. Create MLTextClassifier.DataSources backed by those folders. This lets your model access data stored on disk as separate files, one subfolder per label you want to handle.

As you can see in the following image, your dataset includes two folders: "test" and "train," and each contains two more: "neg" and "pos."

![](img/5720be5c3cca252e12448e68d25607b5_462_0.png)

Each of the files stored in these subfolders contains a single review, and the name of its folder is its classification label. So all the reviews in a "pos" folder are classified with positive sentiment, and the ones in a "neg" folder are classified with negative sentiment.

> Note: This way of loading data works when your dataset is spread across files like this. However, you can also train your model with an MLDataTable, which you can create from a JSON or CSV file, or from a Swift dictionary. You can populate one programmatically if you need to. Whatever method works for your dataset. You'll see an example of loading a JSON file a bit later.

Now, create an MLTextClassifier with the following code:

```swift
let sentimentClassifier = try!
MLTextClassifier(
  trainingData: trainData,
  parameters:
  MLTextClassifier.ModelParameters(language: .english))
```

This single line not only creates your model, it trains it, too! It even separates a portion of the training data to act as a validation set to ensure the model doesn't overfit.

Note the ModelParameters object you pass to the function. This is optional, but lets you specify some details about how you trained the model. You can set a few things, including a validation dataset, but you've only told that it's trained to work with English. This is a good idea later so you can query its supported language to ensure you use only it in the proper context.

You didn't specify a validation set as part of the ModelParameters, so the classifier spends 5% of the training data for that purpose. It spends a good bit of time keeping the reviews and converting them to training features. After that process completes, it starts training a MaxEnt model (on more than that), performing multiple training iterations until it reports a training accuracy close to 100%.

That's great performance on the training data, but what really matters is how it performs on data that it hasn't ever seen. Add the following code to your playground to evaluate your model against a real test dataset:

```swift
// 1
let metrics = sentimentClassifier.evaluation(on: testData)
// 2
if metrics.isValid {
    print("Error rate (lower is better): \(metrics.classificationError)")
} else if let error = metrics.error {
    print("Error evaluating model: \(error)")
} else {
    print("Unknown error evaluating model")
}
```

This looks like more code than it is. Here's what you've added:

- 1. You pass a data source to the model's evaluation(on:) function. This compares the model's predictions for each item in the given test dataset against the correct labels.
- 2. You display the results.
