A heatmap shows small values as "cool" colors — black and dark purple — and large\values as "hot" colors — red to pink to white. The larger the value, the brighter it
s in the confusion matrix, you expect to see a lot of high values on the diagonal,
since these are the correct matches.

For example, the row for the "pretzel" class has 14 matches and 11 wrong
one. The wrong predictions are one "apple," two "cookie," one "doughnut," and
seven "hotdog." Note that often gets mistaken for orange, cookie,
doughnut, and muffin also get mixed up.

The confusion matrix is very useful because it shows potential problem areas for the
model. From this particular confusion matrix, it's clear the model has learned a great
deal already, since the diagonal stands out, but it is still far perfect.
Ideally, you want everything to be zero except the diagonal. It might be a little\misleading from the picture since at glance it appears that there aren't\many mistakes. But all the small numbers in the dark squares up to 340
misclassified images out of 952 total, or 36% wrong.

Keep in mind that some categories have more images than others. For example,
zel has only 25 images in the test set, while most of the other classes have 50, so
it will never have as many correct matches. Still, it only scores 14 out of 25 correct
(56%), so overall the model actually does poorly on pretzels.
