That's to indicate how the output for each timestep can be used within an RNN layer, through the recurrent connection, as well as passed to the next, possibly recurrent, layer of the network. The final output of an RNN layer can be the output for the sequence's last timestep, or the entire sequence of outputs the layer generated while processing the input sequence.

Early implementations of this basic RNN design showed was possible to learn relationships between timesteps in a sequence, but they don't actually do it well. Due to how the underlying math works, they take too long to train and can't relate items separated by many timesteps. For example, imagine an RNN processing our example sentence — it would likely remember the fox is brown, but it might have forgotten that there is a cat by the time it gets to the dog at the end of the sentence.

In reality a basic RNN could properly handle sentences like that, but relationships span much greater distances in many sequences. To continue with our reading example, while words within a sentence are surely related to each other, they can also be related to words in sentences earlier in the same paragraph, many pages in the same chapter or several chapters in a book. The distance between relationships can be arbitrarily long, and basic RNNs simply aren't suited to handle that.

But then came LSTMs.

LSTM's recurrent behavior shown as separate layers

As you can see, an LSTM is a recurrent unit enhanced with an internal memory. LSTMs are used just like regular recurrent layers, but instead of processing only their input and previous output, an LSTM also considers the contents of its memory. And instead of just producing output, the LSTM can also update its memory to remember (or forget) information it thinks is important about the sequence far.

But terms like remembering, forgetting and thinking make it sound like LSTMs have more agency than they really do. Just like other parts of a neural network, the LSTM's "memory" is really just a bunch of numbers that gets manipulated by various math functions. And it doesn't really choose to remember or forget, it learns weights that cause it to react to different sequences.

> Note: LSTM units are more complex than they appear in the diagram, with each cell made up of four layers combined by various operations. If you're interested in their inner workings, check this excellent blog post. But the truth is, unless you're working to invent new types of neural network layers, you probably won't need to know those low-level details.

The important thing to know about LSTMs is that they train much more easily than the basic RNNs that come before them, and they offer better performance. Most RNNs in use today use some variation of the LSTM unit, as is the case with the activity classifier you trained in Turi Create.

## Turi Create's activity classifier

Current research seems to be moving away from RNNs because they don't scale with hardware as well as other models. But for now, recurrent models are still a popular choice in practice.

What does Turi Create's activity classifier take? It's actually a combination of a CNN and an RNN. It uses convolutional layers to extract features from short sequences — the predictions mentioned earlier in the chapter — and uses an LSTM layer to reason over sequences of predictions.

That lets recognize sporadic activities, as the gestures you train your model to classify, as well as activities spanning longer periods of time, made up of smaller ones. For example, imagine the following sequence of activities: putting a teapot in a cup, pouring hot water in a cup, waiting patiently, and removing the teapot from a cup.

Each of those individual activities might be recognizable from small sequences of data — like what you could provide in a single prediction window. But when series of activities occurs over multiple prediction windows, then the model might be to recognize the overarching activity — making a cup of tea.

You provide a sequence of sensor data as input — one prediction window's worth and the model's first layer treats each input feature as a separate channel and performs a one-dimensional convolution over them. A 1D convolution is just like the 2D convolutions you've already used, except it uses kernels instead of matrices.

Each kernel is the length of the prediction window and gets applied to all the features to produce a new output channel. The current version of the code applies 64 such kernels.

The convolutional layer in this diagram may seem confusing because it looks like the waves are two-dimensional, but these are actually vectors with numbers in them that we are displaying as 2D. To display a vector in two dimensions, we treat each item's index in the vector as its value along the X axis. That is, each item in the vector represents a value at a specific point in time.

Remember from the discussions on transfer learning earlier in the book, how the pre-trained CNN extracts features from images and then the layers use those extracted features as inputs? This might be what Turi's model does, except the CNN isn't pre-trained. The CNN learns to output a vector encapsulating any temporal found within the prediction window. For example, it notices patterns of peaks and valleys that are helpful when identifying a shaking phone.

> To understand why CNNs might be well suited to this task, it can help to think of this as a vision: imagine you plotted the sensor data for a prediction window, similar to what we show in the previous diagram, and then passed to a CNN. If CNNs can learn to recognize dogs in images, they should be capable of learning to recognize patterns in sequences just like the ones you saw in the previous chapter exploring the dataset.

The LSTM layer receives the extracted features from the CNN layer, it produces an output based on those features combined with its internal memory and its output from the previous prediction window. The LSTM's output passes through fully connected layers with batch normalization and dropout, and finally a softmax layer that outputs probabilities for each of the classes the model knows about.
