The conv_pw_13 layers at the top are part of MobileNet. On the right, it shows the classifier branch, and on the left the new bounding box prediction branch. Note that the bounding box branch is slightly larger: it has an extra convolution layer between the MobileNet output and the global averaging pooling.

> Note: You might be wondering exactly why you've added another Conv2d layer. Why not do the same as in the classifier branch and just have a Dense layer that immediately follows the global pooling? Good question. The answer is that the author tried and adding the convolution gave much better results. This is probably because this extra layer helps to convert image-level features to features that are more useful for predicting bounding boxes. The downside is that this extra Conv2d layer adds over 4 million parameters to the model. Yikes. In the next chapter, you'll look at a more refined approach to building bounding box predictors that use way fewer parameters.

Now, at this point, there is an important step you shouldn't overlook. Because you reconstructed the model's classification layers, the weights for these are still initialized with random numbers. If you'd use this model to make a classification, it would predict a random class. So before you continue, put the weights back:

```
layer_dict = {layer.name:i for i, layer in 
enumerate(model.layers)}

# Get the weights from the checkpoint model.
weights, biases = classifier_model.layers[-2].get_weights()

# Put them into the new model.
model.layers[layer_dict["dense_class\]].set_weights((weights,
biases))
```

The layer_dict lets you look up layers in the Keras model by name. That's why we gave the layer names when you created them. "dense_class" is the name of the Dense layer in the classification branch. With get_weights() you can grab a layer's weights, and biases if it has them; with set_weights(), you can change the weights on a layer.
