> Note: The activation function used by Darknet is actually a variation of ReLU, known as leaky ReLU. Where a regular ReLU completely removes any values that are less than zero, the leaky version makes negative values a lot smaller but still lets them "through."

The extra layers are all convolutional. Unlike before, where the output of the model was either a vector containing a probability distribution or the coordinates for the bounding box, the output of YOLO is a three-dimensional tensor of size $13 	imes 13 	imes 375$ that we refer to as the grid.

YOLO takes a $416	imes416$ pixel image as input. That's larger than what you typically use for classification. This small, details don't get lost. There are five pooling layers in Darknet that each halve the spatial dimensions of the image, for a total reduction factor of 32. Since $416/32 = 13$, the final grid is $13	imes13$ pixels.

Looking at this the other way around, each of the cells in the grid refers to a $32	imes32$ block of pixels in the original image. Each cell is therefore responsible for detecting objects in or around that particular $32	imes32$ region of the input image.

Each cell in the grid is responsible for its own region in the original image

YOLO, therefore has $13	imes13 = 169$ different bounding box predictors, and each of these are assigned to look only at a specific location in the image. Actually, this isn't entirely true: Each grid cell has not just one but 15 different predictors, for a total of $169	imes15 = 2,535$ bounding box predictors across the entire image. That's quite an upgrade over the simple model you made previously!

Having multiple predictors per grid cell means we can let specialize in different shapes and sizes of objects. Each cell will have a predictor that looks for small objects, a different predictor that looks for large objects, one that looks for narrow but tall objects, and so on.
