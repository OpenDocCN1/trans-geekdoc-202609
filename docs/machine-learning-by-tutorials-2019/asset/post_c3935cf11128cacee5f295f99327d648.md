def plot_prediction(row, image_dir):
    # Same as before:
    image_path = os.path.join(image_dir, row["folder"])

    # Get the ground-truth bounding box:
    bbox_true = [row["x_min"], row["x_max"],
                 row["y_min"], row["y_max"],
                 row["class_name"].upper()]

    # Make the prediction:
    x = img.to_array(img)
    x = np.expand_dims(x, axis=0)
    x = prepreprocess_input(x)
    pred = model.predict(x)
    bbox_pred = [*pred[1][0], labels=np.argmax(pred[0])][0]

    # Plot both bounding boxes and print the IOU:
    plot_image(img, bbox_true, bbox_pred)
    print("IOU: ", iou(bbox_true, bbox_pred))

## Chapter 10: YOLO & Semantic Segmentation

**Note:** This chapter has been updated

You've seen how easy it was to add a bounding box predictor to the model. But it only predicts a single object. Unfortunately, it doesn't work well when there are multiple objects.

A slightly smarter approach is to first try and figure out which parts of the image are potential regions of interest. This is the approach taken by the popular R-CNN family of models. The classifier is still run on multiple regions, but now only on regions that are at least likely to have an object.

To predict which regions are interesting, the "Faster R-CNN" model uses a Region Proposal Network, which sounds impressive but is just a bunch of layers on top of the feature extractor. Even though it has "Faster" in its name, this model is still on the slow side and not really suitable for mobile devices.

For speed freaks and mobile devices, the so-called single stage detectors are very appealing. As the names imply, these models run the classifier once on the input image and all of the work in a single pass. Examples of single-stage object detectors are YOLO (You Only Look Once), SSD (Single Shot multi-box Detector) and DetectNet.

Turi Create lets you train a YOLO model with just a few lines of code, so that's what you'll next.
