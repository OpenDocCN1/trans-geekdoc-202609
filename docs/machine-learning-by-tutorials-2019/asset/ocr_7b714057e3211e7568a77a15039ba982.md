The numbers you'll see will be different because the generator randomly shuffles the examples. y_class will be something like this:

```
array([ 9, 16, 12, 7, 8, 18, 10, 1, 14, 2, 7, 17, ...])
```

The are also has of the classes that belong to the bounding boxes. To turn this into text labels, you can do the following:

```
from helpers import labels
list(map(lambda x: labels[x], y_class))
```

The label variable contains class names corresponding to these indices and is defined in helpers. Using the map() function, which works the same way as Swift's map, you can convert from y_class's numeric indices to text labels. The helpers also has a label2index dictionary that maps the other around, from text labels to numeric indices.

__len__() method determines how many batches this generator can produce: the number of rows in the dataframe, len(df), divided by the size of the batch. The // operator in Python means integer division.

When you use it(train_generator), Python automatically invokes the __len__()method. It should output 220. The generator produces exactly 220 batches because 7,040 rows / 32 rows = 220 batches. Usually, the training set doesn't divide neatly by batch_size, in which case the last, incomplete batch is ignored or padded with zeros to make it a full batch. (We ignore it).
