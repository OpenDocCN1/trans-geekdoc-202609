Now you've got your model in the project, use NLPHelper.swift and replace getSentimentClassifier with the following:

```
func getSentimentClassifier() -> NLModel? {
    return try! NLModel(mModel: SentimentClassifier().model)
}
```

This creates an instance of your model, but it does so a bit differently from other models you've created. You instantiate a SentimentClassifier, then use its model property to create an NLModel.

NLModel wraps Core models for use with the Natural Language framework. Xcode will let you use MLClassifier objects directly, which you've used in earlier chapters, but it is essential to wrap them in NLModel first. This ensures the model preprocesses inputs the same way you Create ML during the training process. And as you've learned, it's vital for preprocessing steps to match training and inference, otherwise your models won't produce the correct results.

func predictSentiment(
