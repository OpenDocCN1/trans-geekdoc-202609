# Chapter 8: Advanced Convolutional Neural Networks

```
from keras.applications.mobilenet import MobileNet
base_model = MobileNet(
input_shape=(image_height, image_width, 3),
include_top=False,
weights="imagenet',
pooling=None)
```

Keras's MobileNet has been trained on the ImageNet dataset. But you want to use MobileNet only as a feature extractor, not as a classifier for the 1000 ImageNet categories. That's why you need to specify include_top=False and pooling=None when creating the model. That Keras leaves off the classifier layers.

You can use base_model.summary() to see a list of all the layers in this model, or run the following code to save a diagram of the model to a PNG file (which requires the pydot package to be installed):

```
from keras.utils import plot_model
plot_model(base_model, to_file="mobilenet.png")
```

If you look at the architecture of MobileNet in that PNG file, you'll see that it is made up of the repeating structure:

![](bbox=[0.417, 0.522, 0.582, 0.715])

MobileNet uses depthwise separable convolutions

First, there is a so-called DepthwiseConv2D layer with kernel size 3×3, followed by a BatchNorm layer, and a ReLU activation. Then there is a Conv2D layer with kernel size 1×1, which is also followed by its own BatchNormalization and ReLU. MobileNet consists of 13 of these building blocks stacked together.
