```
func enableMotionUpdates() {
// 1
  motionManager.deviceMotionUpdateInterval = 
    1.0 / Config.samplesPerSecond
// 2
  activityData = [String]()
// 3
  motionManager.startMotionUpdates(
    queue:.XArbitraryVertical, withHandler: {[weak self] motionData, error in
// 4
    guard let self = self, let motionData = motionData else {
      if error = error {
        print(
          "Device motion update error: \\n(error.localizedDescription)")
      }
      return
    }
    // 5
    self.processMotionData(motionData)
  })
}
```

+   1. Use samplesPerSecond that you defined earlier to set how often motionManager sends updates to your app. In case, you're setting it to update every 0.04 seconds, or 25 times per second.
2. Initialize activityData to an empty array. The project starter code calls each time the user starts a new recording session — this ensures each session starts with a fresh array.
3. This line instructs motionManager to start sending motion updates, passing a block to execute on queue for each update. The using parameter tells CoreMotion to use XArbitraryVertical as device position relative to the device's values should be reported. Check out CMAltitudeReferenceFrame for available options.
4. This guard statement ensures the callback received motion data. If not, an error message is available. If you find getting many errors, you may need a more robust solution here. For example, receiving too many errors in a row could trigger the stop and discard the data.
5. Call processMotionData, which you added, to extract features from the sensor data and append them to activityData.
