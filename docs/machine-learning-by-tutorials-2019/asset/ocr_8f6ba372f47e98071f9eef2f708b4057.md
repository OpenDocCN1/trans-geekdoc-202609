Now, create an MLTextClassifier with the following code:

```
let sentimentClassifier = try!
MLTextClassifier(
  trainingData: trainData,
  parameters:
  MLTextClassifier.ModelParameters(language: .english))
```

This single line not only creates your model, it trains it, too! It Even separates a portion of the training data to act as a validation set to ensure the model doesn't overfit.

Note the ModelParameters object you pass to the function. This is optional, but lets you specify some details about how you trained the model. You can set a few things, including a validation dataset, but you've only told that it's trained to work with English. This is a good idea later you you can query its supported language ensure you use only it in the proper context.
