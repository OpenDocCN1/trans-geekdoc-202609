# Converting your model to Core ML

So far, you used teacher forcing to train a Keras seq2seq model to translate Spanish text to English, then you used those layers to create separate encoder and decoder models that work without you needing to provide them with the correct translation. That is, you removed the teacher-forcing aspect of the model that only makes sense while training. At this point, you *should* be able to convert your encoder and decoder models to Core ML and use them in your app.

But is it that easy?

Currently, there are issues with Core ML and/or coreml (the Python package that converts models into Core ML format), preventing you from exporting the models you've made. Don't worry — this section shows how to work around each of and convert your models to Core ML. Start with the code: Run the following code to do a bunch of stuff you shouldn't have to do, which is explained after the code block:

```python
# 1
coreml_enc = Input(
    shape=(None, in_vocab_size), name="encoder_in")
coreml_lstm = LSTM(
    latent_dim, return_states=True, name="encoder_lstm")
coreml_enc_out, _ = coreml_lstm(coreml_enc, coreml_enc)
coreml_encoder_model = Model(coreml_enc, coreml_enc_out)
# 2
coreml_encoder_model.output_layers = \
    coreml_encoder_model.output_layers
# 3
```

```python
inf_encoder.save_weights("Es2EnCharEncoderWeights.h5")
coreml_encoder_model.load_weights("Es2EnCharEncoderWeights.h5")
```

Everything you just wrote is to work around a conversion problem or otherwise you haven't done these things. Here's what's going:

- 1. This creates a new, untrained encoder model, completely separate from the one trained. It is necessary to work around two issues you would encounter without it. First, Core ML does not support masking layers, so you need to create them new. The second issue is a bug that causes the crash when exporting shared layers.
- 2. This is a bit ridiculous, but coremltools currently allows you to name the output layers, so you can use them in the app.
- 3. Finally, you copy the weights from the trained encoder to the new one.

The coremltools package provides utilities to help you get your models into Core ML format. Run the following code to convert your encoder:

```python
import coremltools
coreml_encoder = coremltools.converters.keras.convert(
    coreml_encoder_model, input_names="encodedSeq", output_names="ignored")
coreml_encoder.save("Es2EnCharEncoder.mlmodel")
```

With your encoder exported, it's time to turn to the decoder. Run the following code to perform the same exactly to prepare your decoder for Core ML:

```python
coreml_dec_in = Input(shape=(None, out_vocab_size))
coreml_dec_lstm = LSTM(
    latent_dim, return_sequences=True, return_states=True,
    name="decoder_lstm")
coreml_dec_out, _ = coreml_dec_lstm(coreml_dec_in)
coreml_dec_dense = Dense(out_vocab_size, activation="softmax")
coreml_dec_out = coreml_dec_dense(coreml_dec_out)
coreml_dec_model = Model(coreml_dec_in, coreml_dec_out)
```

```python
coreml_decoder_model.output_layers = \
```
