# Getting to know your model

Open the GestureIt starter project in Xcode. If you've gone through the chapters leading up to this one, you've already practiced adding Core ML models to your projects — find the GestureClassifier.mlmodel file created when you saved your trained model in the previous section and drag it into Xcode. Or, if you'd like to use the model trained on the provided dataset, add notebooks/pre-trained/GestureClassifier.mlmodel instead.

> Note: Now that you have the model in Xcode, the rest of this section is all theory. You can safely skip it if you aren't interested in this discussion right now.
