In practice, a convolution layer will have more than one of these filters. It's common to see layers with 52, 64, 128, 256, 512 or even 1,024 or more of these convolutions. Each filter learns its own set of weights and bias values.

The number of filters in the convolution layer determines the depth of its output image, all with a 3×3 window size. The neural network in the illustration above has several convolutional layers, all with the input that the has three channels (RGB), each convolution filter from this first layer learns 3×3×3 weights.

The layer has 32 of those convolution filters, and so it can detect 32 different patterns. Because all it has 32 filters that all produce one channel's worth of data, the output of this layer is a new image of 227×227×32. Notice that the convolution layer kept the width and height of the image the same but expanded the number of channels from 3 to 32.

If you count them up, this first layer learned 3×3×3×32 weights. Read this as $kernelHeight \times kernelWidth \times InputChannels \times outputChannels$. The layer has learned 32 bias values, one for each output channel.

> Note: The first convolution layer outputs a tensor of size (227, 227, 32). Even though we still call this "image" of size 227×227×32 — you can't really display such images. Your computer's display panel has only one red, green and blue LED for each pixel — what would it do with the other 29 color channels?! Think of this output tensor as consisting of 32 individual grayscale images, each describing how well the input image matched the template or pattern learned by the corresponding convolution filter.
