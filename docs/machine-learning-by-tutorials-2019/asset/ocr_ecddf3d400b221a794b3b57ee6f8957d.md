2. You loop over the samples and one-hot encode each of their sequences into
enc_in_seqs, dec_in_seqs, dec_out_seqs as appropriate. This is, for each
token in a sequence, we place a 1 in its corresponding location within a vector of
zeros.

3. Notice how you populate dec_out_seqs, we use out_seq[1:] to skip thenSTART token in the sequence. That's because this tensor contains the outputs
y model learns to predict. It will never predict the START token because it's
always given that it is its first input, and it lets keras predict the next token.

The only thing left to do is one-hot encode your datasets, then you're ready to train.
You could encode them all at once and let keras randomly sample batches
that works and it's how many people do it. However, if you ensure batches contain
on sequences of similar lengths, you can minimize the amount of padding
necessary.

Why does that matter? The Masking layers added to seq2seq_model ensure the
padding doesn't affect your training results, but it takes time to process those
steps in the sequences. With this model and dataset, minimizing padding makes
go nearly twice as fast.

The chapter resources include a file called seq2seq_util.py in the notebooks folder.
It defines a class Seq2SeqBatchGenerator that you'll use to generate properly
randomized batches while minimizing necessary padding. We won't go over the
details of this code here; read the code and comments in the file if you're
interested.

Running the code in a new cell to import the Seq2SeqBatchGenerator class
 creates instances of it for your training and validation datasets:

```
from seq2seq_util import Seq2SeqBatchGenerator

batch_size = 64
train_generator = Seq2SeqBatchGenerator(
  train_samples, batch_size, encode_batch)
valid_generator = Seq2SeqBatchGenerator(
  valid_samples, batch_size, encode_batch)
```

You'll use these objects while training your model to create batches with the given
batch size. Seq2SeqBatchGenerator needs a way to one-hot encode each batch of
samples, so you pass it to the encode function.
