# It could be better...

What does this mean? Well, the model did learn something. After all, you started with a validation accuracy of 0.05 and it went up to about 0.12. The model did gain a bit of knowledge about the dataset. It is no longer making random guesses — but it is still not doing better than that.

How come the training accuracy is so high? It goes to about 90% after 50 epochs... This is an extreme case of overfitting. Yup, there is it again. The model isn't actually learning to classify images, it's learning to tell apart the images that are in the training set. It's likely that the model is learning with combinations of pixels to which training image — and that's not what you want. The model to understand what pixels represent in a more abstract sense.

The model has 61,460 learnable parameters and there are only 4,838 images in the training set, the model easily has capacity to remember which class goes with image the training set. In fact, with a training accuracy of 90%, and a very low accuracy on the validation set and test, it means that the model managed to memorize the class for nine out of 10 images. In the previous chapter, you saw that the Turi model also suffered from overfitting and had fewer parameters than this model, only 19,019. In general, the more parameters a model has, the worse the problem overfitting becomes.

You don't want to train a model that remembers specific training images; you want a model that can learn to classify images it hasn't seen yet. This model fails spectacularly at that. There are several techniques you can use to dissuade the model from overfitting, it's clear that trying to learn directly from pixels what these 20 different types of categories are, a task that logistic regression is not up to.

Now don't let this make you believe that logistic regression is a bad machine learning model. It isn't. In fact, for many ML problems it is the go-to solution. For logistic regression to work well it is important that the number of features is much less than the number of training examples.
