tf-coreml will now load the TensorFlow model, analyze the graph, and convert all the operations to Core ML layers. When it's done and everything went well, you will have a brand new DeepLab.mlmodel file.

Double-click to open it in Xcode, and this is what you should see:

![](bbox=[0.237, 0.215, 0.762, 0.483])

DeepLab's output is a multi-array of size 21*513*513. Multi-array is the term that Core ML uses for tensor. When you need to deal with tensor objects in Core ML, it's always through the MLMultiArray class. You'll get a taste of that shortly.

Notice that Core ML puts the number of channels (21) at the front of the sensor, the outermost dimension. Usually, in this, we've described the size of a tensor as height × width × channels (HWC), but in practice, you'll also see it the other way around: channels × width × height (CHW). It's important to know which format you're working with at any given time.

Open DeepLab.mlmodel with Netron, and put it side-by-side with the original TensorFlow model to see different/similar the two models are.
