# Mixed-length sequences with padding

This image shows padding as crossed-out boxes, but you could use anything that isn't already in the vocabulary. And even though this looks characters arranged in a two-dimensional batch, in reality it's three-dimensional with each character represented by a zero-hot encoding. For this project, you'll pad sequences with zero-vectors. Since make_batch_storage returns a batch filled with zeros, it's basically pre-padded and there's no need to add any padding-specific tokens to the vocabularies.

Now, run the following code to define the second of the two functions for one-hot encoding — the one that actually encodes:

```
def encode_batch(samples):
    # 1
    batch_size = len(samples)
    max_length = max([len(seq) for seq, _ in samples])
    max_out_length = max([len(seq) for _, seq in samples])
    enc_in_seqs, dec_in_seqs, dec_out_seqs = make_batch_storage(batch_size, max_length, max_out_length)
    # 2
    for i, (in_seq, out_seq) in enumerate(samples):
        for time_step, token in enumerate(in_seq):
            enc_in_seqs[i, time_step, token2int[token]] = 1
        for time_step, token in enumerate(out_seq):
            dec_in_seqs[i, time_step, token2int[token]] = 1
        # 3
        for time_step, token in enumerate(out_seq[1:]):
            dec_out_seqs[i, time_step, token2int[token]] = 1
    return enc_in_seqs, dec_in_seqs, dec_out_seqs
```
