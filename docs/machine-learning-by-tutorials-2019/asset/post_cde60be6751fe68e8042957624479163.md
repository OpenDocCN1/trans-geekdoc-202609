    tagger.enumerateTags(in: text.startIndex..<text.endIndex, unit: .word,
        scheme: .lemma, options: options) { tag, tokenRange in
        // 3
        let lemma = tag?.rawValue.lowercased()
        block(lemma)
        return true
    }
}
```



This code looks a lot like PeopleNames that you added earlier. That's because it follows the same pattern. Here's what's different:

- 1. The function accepts an additional parameter — an optional language character code. You can ignore this for now.
- 2. You're using the .lemma tagging scheme, which tells the tagger you want it to return the lemma for each token it encounters. Just like when searching for names, the .lemma scheme only works for .word token units.
- 3. If the tag-identifies a lemma — it won't always be able to to — then it's contained in the NLTagger'ssValueValue property. You extract it, ensure it's lowercase — this app won't work case-sensitive search — and pass it to the block that was passed into getSearch-terms.

The app's starter code already calls getSearch-terms for each review, mapping the review to each term generated by this function.
