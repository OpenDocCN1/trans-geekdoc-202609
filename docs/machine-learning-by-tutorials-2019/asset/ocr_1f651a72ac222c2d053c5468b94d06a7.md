# # Finding named entities

Sometimes, you'll want to find names mentioned in a piece of text. Maybe you want
to sort articles based on who they are about, organize restaurant reviews based on
the city, or extract important information from a document, which
includes names of people, places and organizations. This is called entity
recognition (NER), and it is a common NLP task with many use cases. It's also a form
of text classification.

When you're looking for a specific word, a simple search is often enough. However,
when there are many such words, and especially when you aren't sure in advance
what words will be, that machine learning can help. The Natural
Language framework provides well-trained models capable of finding names of
people, places and organizations.

In this section, you'll use SMBDB ability to sort reviews based on the people's
names they contain. The app doesn't know what names might exist, so it
to examine the text and classify words as either names or not names. Apple
provides a class that can handle this task — and more — NLTagger.

    .whitespace, .ompunctuation, .omitOther, .joinNames]
  // 3
  tag.enumerateTags(
    in: text.Range<text.endIndex>, unit: .word,
    scheme: .nameType, options: options) { tag, tokenRange in
      // 4
      if tag == .personalName {
        block(String(text[tokenRange]))
        return true
      }
  }
