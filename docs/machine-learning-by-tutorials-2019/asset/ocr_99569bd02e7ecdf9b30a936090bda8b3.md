# MobileNet and data augmentation

The final classification model you'll be training is based on MobileNet. SqueezeNet, this is an architecture that is optimized for mobile devices — hence the name.

MobileNet has more learned parameters than SqueezeNet, so it's slightly bigger but it's also more capable. With MobileNet as the feature extractor, you should be able to get a model that performs better than what Turi create in Chapter 5, "Digging Into T Create." You'll also be using some additional training techniques to make the model as much as possible from the dataset.
