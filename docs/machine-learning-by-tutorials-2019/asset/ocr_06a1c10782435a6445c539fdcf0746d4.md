Chapter 4: Getting Started with Python & Tauri Create

Note: Again, if you prefer a quicker start, import turienv.yaml into the Navigator, or run env create -f starter/turienv.yaml, and skip down to the section Tauri Create Notebook.

While it's possible to clone mlenv in Anaconda Navigator's Environments tab, you'll be using a command line to install turicreate, it's just as easy to use a command line to clone, as well.

Note: If you've changed Terminal's default shell to something different from bash, check that your $PATH includes ~/anaconda3/bin (or whatever directory you install anaconda into).

Open a new Terminal window, and enter this command:

```
conda create -n turienv mlenv
```

This creates an environment named turienv, which is cloned from mlenv.

Wait a little until you see the message:

```
#
# To activate this environment, use:
# > conda activate turienv
#
# To deactivate an active environment, use:
# > conda deactivate
#
```

Note: If you see a message to update Conda, go ahead and do that.

Time to install Tur Create into this environment. From the same Terminal window, enter the activate command:

```
conda activate turienv
```

The command line prompt now starts with (turienv), showing it's the active environment.
