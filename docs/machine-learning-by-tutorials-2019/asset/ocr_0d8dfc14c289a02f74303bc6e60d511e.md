You need to tell locationManager how often to produce sensor data. ViewController stores its configuration-related constants in its Config struct, so add the following constant:

```
static let samplesPerSecond = 25.0
```

Here you set samplesPerSecond to 25, which you'll use to specify if you want the device to use 25 sensor updates every second. This number is important because it determines how much data your model looks at on how often you perform predictions. That is, if you classify the user's activity per second, this gives you 25 samples per classification; if you do it every four seconds, this rate gives you 100 samples.
