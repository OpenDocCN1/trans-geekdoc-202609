Now to use the new models. Rather than remove the code you wrote in the previous chapter, you’ll create a separate function that creates the decoder input suitable for your bidirectional model. Add the following function inside NLPHelper.swift.

```
func bidirDecoderInput(encoderInput: MLMultiArray) ->
Es2BidirGruCharDecoder16BitInput {
  let encoder = Es2BidirGruCharEncoder16Bit()
  let decoderOut = try! encoder.prediction(
oneHotEncodedSeq: encoderInput,
fwd_gru_h: nil, rev_gru_h: nil)
  let decoderIn = initMultiArray(
  shape: [NSNumber(value: intToChar.count)])
  return Es2BidirGruCharDecoder16BitInput(
encoderChar: decoderIn,
dru_h_in: decoderOut.decodersInitialState)
}
```

This is almost what you wrote in decoderInput in the previous chapter. This version only changes class and parameter names to match the ones Xcode created for your new models. Notice you set decoder_gru_h_in to the encoder output to decodersInitialState value — that’s the name of the output that concatenates the outputs of forward and reverse GRUs.
