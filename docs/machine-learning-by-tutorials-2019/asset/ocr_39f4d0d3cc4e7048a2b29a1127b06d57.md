# SentimentClassifier.mlmodel in the chapter resources.

Xcode playgrounds have special access to a specific folder on your Mac, where you'll store your dataset and output your trained model. If it doesn't already exist, create a folder named Shared Playground Data inside your Documents folder. This must have that exact name and be in location for your playgrounds to access it.

> Note: You can add files to your playground's bundle resources — you'll see later in this chapter. But when I tried that with the large dataset involved here, Xcode struggled and I spent way too much staring at spinning baseballs and force-quitting the app. Things performed much better with the data outside of the bundle.

Next, create a folder named TextClassification inside Shared Playground Data. You'll keep everything for this chapter organized.

Find projects/starter/datasets/MovieReviews.zip in the chapter resources and unzip it into the Shared Playground Data/TextClassification folder you created. You should now have a subfolder MovieReviews.

This new folder contains subfolders with 50 thousand movie reviews, half labeled as positive and the other negative. It is a slightly pared-down version of the Large Movie Review Dataset, from the 2011 paper,“Learning Word Vectors for Sentiment Analysis,” by Andrew L. Maas et al., published by the Association for Computational Linguistics.

Interested readers can find the paper at www.aclweb.org/anthology/P11-1015. There's a README describing the changes we made, primarily to save space by eliminating files that were unrelated to this chapter.

Create a new playground file using any template for macOS. The specific template doesn't matter, but the operating system does Create ML is only available on macOS. Or if you'd follow along with a completed playground, you can find it on projects/final/playgrounds/MovieSentiment.playground.

If you started from a template, whatever starter code Xcode provided and add the following imports:

```
import CreateML
import PlaygroundSupport
```
