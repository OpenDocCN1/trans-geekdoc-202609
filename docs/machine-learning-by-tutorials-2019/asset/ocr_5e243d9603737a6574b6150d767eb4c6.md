Once the model is done training, you can save:

```
model.save("SnackDetector.model")
```

Also, export the model to Core ML. It's possible you get some warnings at this point from coreml. You can safely ignore these.

```
model.export_coreml("SnackDetector.mlmodel")
```

Before you put this model into an app, let's use Turi Create to evaluate how well it does on the test set.

# # How good is it?

In case you don't have the hardware or the time to train this model yourself, we've included the model in the downloads as a .zip file in the final folder, SnackDetector.zip. Unzip this model to your working directory and load it into the:

```
model = tc.load_model("SnackDetector.model")
```

Also, load the test images and their annotations:

```
test_dir = os.path.join(data_dir, "test")
test_data = load_images_with_annotations(test_dir, data_dir + "/annotations-test.csv")
```

Then call model.evaluate(test_data) on the test setFrame:

```
scores = model.evaluate(test_data)
```

This predicts the bounding boxes for every image in the test set and then compares these predictions against the ground-truths. It can take a few minutes if you're running this on a CPU. When it's done, some looks looks like this:

```
{average_precision_50': {
  'apple': 0.5278854132511876,
  'banana': 0.4193912680862453,
}
```
