Here are more details about NLTagger and the code you just added:

+   NLTagger operates on tokens, but what a "token" means depends on the value you of . .word, .sentence, .paragraph or .document. The tagger will consider text in these unit-sized chunks, broken using the rules it understands for the text's language. Some tagging schemes use only with specific units — for example, the .nameType used here works with words.

+   When NLTagger labels a token, it calls the code block you specify with an NLTag object and the range of the tagged token within the source text. The actual value of the NLTag object is based on the tagging scheme — in the case of names, it can be .personName, .placeName or .organizationName, but there are other possibilities using different tagging schemes.

+   You used the .nameType scheme to initialize the tagger to classify names, but Apple provides several different built-in options. You'll take a look at another one in the next section.
