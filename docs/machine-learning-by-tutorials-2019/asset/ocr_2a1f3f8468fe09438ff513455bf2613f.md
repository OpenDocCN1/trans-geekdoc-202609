# The sequence-to-sequence model

Inside the chapter resources, you'll find a text file named spa.txt in projects/notebooks/data/. This file comes from manythings.org at http://www.manythings.org/anki/, which provides sentences for many different languages. These pairs were culled from an even larger dataset provided by the Tatoeba Project at www.tatoeba.org.

The file contains lines that look like

| Go. | Ve. |
| Go. | Vete. |
| Go. | Vaya. |
| Go. | Vayase. |
| Hi. | Hola. |
| Run! | iCorre! |
| Run. | Corred. |

The first seven lines of spa.txt

Each line has an English sentence — they aren't all one-word line in the image — followed by one possible Spanish translation of that sentence. You're going to use this data to train a neural network to ingest Spanish text, like "Corre!", and translate it into English text, like "Run!"
