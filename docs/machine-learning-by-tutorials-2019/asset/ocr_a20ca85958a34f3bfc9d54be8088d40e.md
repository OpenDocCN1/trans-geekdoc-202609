ReLU is an extremely simple mathematical function that looks like this:

![](bbox=[0.223, 0.153, 0.776, 0.313])

The ReLU activation function

In code, it is is:

```
y = max(0, x)
```

In other words, if the x is less than 0, the output of the ReLU is 0, otherwise the number passes through to the next layer changed.

There are other activation functions, too, such as the logistic sigmoid that you've seen in the math section (if you don't skip it), but usually you'd use ReLU. The **linear unit** of ReLU's name means that it's just a straight line, and **rectified** means the line gets flattened for negative values, making this function non-linear.

It turns out that the actual shape of the activation function that you're using doesn't really matter much, as long as it introduces non-linear behavior into the model. Most machine-learning models use ReLU because it's really simple and fast to compute. A *logistic regression*, you would usually use the sigmoid activation function, so technically speaking the first half of this neural network isn't truly a logistic regression because it uses ReLU instead, but that's a detail you will conveniently ignore.

The math for this network is something like this:

```
output_dense_1 = relu(matmul(W_1, x) + b_1)
output_dense_2 = softmax(matmul(W_2, output_dense_1) + b_2)
```

For each layer, the pattern is the same: a matrix multiplication of the layer's input with the weights, plus the bias, and an activation function applied to it. Repeated twice because you have two Dense layers.
