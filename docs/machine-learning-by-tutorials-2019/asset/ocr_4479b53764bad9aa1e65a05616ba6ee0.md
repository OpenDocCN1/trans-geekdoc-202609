Chapter 3: Training the Image Classifier

The HealthySnacks and MultiSnacks models you used in the previous chapter were built on top of using SqueezeNet. The underlying model used by Create ML is not SqueezeNet but VisionFeaturePrint_Screen, a model that was designed by Apple specifically for giving high-quality results on iOS devices.

VisionFeaturePrint_Screen was pre-trained on a enormous dataset to recognize a huge number of classes. This did by learning what features to look for in an image and by learning to combine these features to classify the image. Almost all of the training time for your dataset, the model spends extracting 2,048 features from your images. These include low-level edges, mid-level shapes and task-specific high-level features.

Once the features have been extracted, Create ML spends only a relatively tiny amount of time training a logistic regression model to separate your images into 20 classes. It's similar to fitting a straight line to scattered points, but in 2,048 dimensions instead of two.

Transfer learning only works when features of your dataset are reasonably similar to features of the dataset that was used to train the model. A model pre-trained on ImageNet — a large collection of photos — might not transfer well to pencil drawings or microscopy images.
