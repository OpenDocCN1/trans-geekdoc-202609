# The convolution window slides over the image, left to right, top to bottom

Usually, the convolution window is 3×3 pixels in size, but you'll also see larger windows as 5×5 and 7×7. Keeping with the trend of using multiple names for the same thing, now is also known as the convolution **kernel filter**.

For every pixel at coordinate **i, j** in the input image, this is the math that makes a 3×3 convolution window:

```
y[i,j] = w[0,0]*x[i-1,j-1] + w[0,1]*x[i-1,j] + w[0,2]*x[i-1,j+1]
+ w[1,0]*x[i,j-1] + w[1,1]*x[i,j] + w[1,2]*x[i,j+1]
+ w[2,0]*x[i+1,j-1] + w[2,1]*x[i+1,j] + w[2,2]*x[i+1,j+1]
+ bias
```

As you recognize by now, this is nothing more than a dot product between the weight values **w** and the pixel we're looking at, **x[i,j]**, as well as the pixels surrounding it. As usual, it also adds a bias value.

Therefore, the output value for coordinate **i, j** is a weighted sum of the input pixel at that same coordinate and the pixels that surround it. The larger the window, the more surrounding pixels this product includes. 3×3 windows are the most common, and the output value is the weighted sum of nine pixels.

This formula is repeated for every pixel in the input image. We vary **i** between 0 and the image height, and **j** between 0 and the image width, and compute the dot product at each pixel coordinate **i, j**. That’s why we say a convolution “slides” over the image.
