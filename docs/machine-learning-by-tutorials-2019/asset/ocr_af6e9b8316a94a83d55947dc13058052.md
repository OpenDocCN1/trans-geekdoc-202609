Each step computes a single output value from the $3\times3$ window at the center pixel
While the pixel values inside the window will be different as it slides over the image, the same $3\times3$ weight values are used in every image position. This is what allows the convolution layer to learn patterns in the image, regardless of where these patterns appear. In math-speak, convolution is **translation invariant**, because the weights are the same no matter where you look.

Think of it way: The convolution operation tries to match a small template — the weights — to every group of $3\times3$ pixels under the sliding window in the input image. If this group of pixels is a good match for the template, then the dot product's output value will be high.

If the pixels don't match the template very, then the output value will be small, close to zero. And if the pixels are the complete opposite of the template, the output will be high negative.

> Note: You may know this principle from statistics **correlation**, and it's why convolution is also known as cross-correlation. The "cross" comes from the fact that you slide the window over the image. Technically speaking, convolution and cross-correlation are not **exactly** the same thing, as convolution is really cross-correlation done backwards, but \\_(\ツ)\_/.
