## Got GPU?

Having a GPU is no longer a luxury. Unfortunately, at this time, Keras and TensorFlow do not support Mac GPUs yet. Modern Macs ship with GPUs from Intel or AMD, while deep learning tools usually cater to GPUs from NVIDIA. Older Macs may still have an NVIDIA, but these are often too old. Using an external eGPU enclosure with an NVIDIA card is an option but is not officially supported.

Most machine-learning practitioners train their models on a PC running Linux that has one or more NVIDIA GPUs, or in the cloud. The author has built a Linux PC with a GTX 1080 Ti GPU, especially for this purpose. If you're serious about deep learning, this expense is worth making.

If all you have is a Mac, you'll need a lot of patience to train the models in this chapter. Because we want everyone to be able to follow along, the book's download includes the full Jupyter notebooks that were used to train the models, as well as the final trained version, so you can skip training the models if your computer isn't up to the task.

> **Note:** Even though they have limitations, the big benefit of Create ML and Turi is that they support Mac GPUs through Metal. No big surprise there, as both are provided by Apple. Let's hope TensorFlow and other popular training tools will suit and support Metal, too. There's no reason the Intel or AMD GPU in your Mac cannot compete with NVIDIA chips — the only thing missing is software support.

If you have a spare PC with a reasonably recent NVIDIA GPU, and you don't mind installing Linux on it, by all means give that a go. It's also possible to use Keras and TensorFlow from GPUs, but this is a bit weird. We suggest using Ubuntu from ubuntu.com, the most popular Linux for machine learning.

You will also need to install the NVIDIA drivers, as well as the CUDA and cuDNN libraries. See developer.nvidia.com for more details. To install the python learning packages, use Conda as explained in Chapter 4, "Getting Started with Python & Turi Create." The process is very similar to Linux and Windows.

> **Tip:** If you're installing TensorFlow by hand, make sure to install the tensorflow-gpu package instead of tensorflow. You can change this in kerasenv.yaml or run pip install -u tensorflow-gpu. Also, be sure to install the version of TensorFlow that matches your version of CUDA and cuDNN. If these versions don't match, TensorFlow won't work. Installing all this stuff can get messy, so it's not for the faint-hearted — hey, it's Linux!

## Convolution layers

The models you've built in Keras have, so far, consisted of Dense layers, which take a one-dimensional input. But images are two-dimensional, and we want to preserve that spatial structure. A convolutional layer transforms the input image into a feature map by sliding a filter over the image.

The filter is a set of weights that the model learns during training. At each position, we compute a dot product between the filter and the input pixels. This is why we don't "flatten" the image before the convolution. Flattening would destroy the spatial relationships between pixels.

The output of the convolution is a feature map, where each pixel represents the presence of a certain feature. By using multiple filters, the model can extract various features from the image.

## What is convolution?

If you have no idea what convolution is, rest assured it sounds a lot more intimidating than it really is. A convolution is a window that slides over the image. At each position, we compute a dot product between the filter and the input pixels.

## The convolution window slides over the image, left to right

Usually, the convolution window is 3×3 in size, but you'll also see larger windows as 5×5 and 7×7. Keeping with the trend of using multiple names for the same thing, now is also known as the convolution filter.

For every pixel at coordinate **i, j** in the input image, this is the math that makes 3×3 convolution:

```
y[i,j] = w[0,0]*x[i-1,j-1] + w[0,1]*x[i-1,j] + w[0,2]*x[i-1,j+1]
+ w[1,0]*x[i,j-1] + w[1,1]*x[i,j] + w[1,2]*x[i,j+1]
+ w[2,0]*x[i+1,j-1] + w[2,1]*x[i+1,j] + w[2,2]*x[i+1,j+1]
+ bias
```

As you recognize by now, this is nothing more than a dot product between the weight values **w** and the pixel we're looking at, **x[i,j]**, as well as the pixels surrounding it. As usual, it also adds a bias value.

Therefore, the output value for coordinate **i, j** is a weighted sum of the input pixel at that same coordinate and the pixels that surround it. The larger the window, the more surrounding pixels this product includes. 3×3 windows are the most common, and the output value is the weighted sum of nine pixels.

This formula is repeated for every pixel in the input image. We vary **i** between 0 and the image height, and **j** between 0 and the image width, and compute the dot product at each pixel coordinate **i, j**. That’s why we say a convolution “slides” over the image.
