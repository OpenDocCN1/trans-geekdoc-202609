# Machine Learning   Chapter 6: Taking Control of Training with Keras

> Note: This model has 1.5 million parameters. That's a lot for a model with just two layers. This is a downside of using Dense or fully-connected layers. Since each of the 3072 inputs is connected to the 500 intermediate neurons, this requires 3072*500=1.5 million connections, 500 bias values. Because this model has so many learned parameters, you can expect it to overfit again on the relatively small dataset.

As usual, don't forget to compile the model first or you cannot train it:

```
model.compile(loss="categorical_crossentropy",
               optimizer=optimizers.Adam(lr=1e-3),
               metrics=["accuracy"]
```

Train this model by calling fit_generator(), and you'll see that the results will be a little better before:

```
model.fit_generator(train_generator,
                              steps_per_epoch=len(train_generator),
                              validation_data=val_generator,
                              validation_steps=len(val_generator),
                              epochs=3,
                              workers=4)
```

Training for three epochs gives the following results:
