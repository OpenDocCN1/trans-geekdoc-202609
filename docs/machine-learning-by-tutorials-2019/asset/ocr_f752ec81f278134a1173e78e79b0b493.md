The Output Shape column gives the size of the data after it has been transformed by that layer. As expected, Flatten shows a vector with 3,072 elements and Dense outputs a vector with one element for each of the 20 classes.

Even though Flatten produces a one-dimensional vector, the output shape in the summary actually has two dimensions with the first dimension being None.

Keras automatically adds a dimension to the front of the layer's output, which is the batch dimension. This extra dimension is used during training, so you can train on multiple images at the same time. When images are combined into a so-called batch or mini-batch. If you were to train on a typical batch size of 64 images at once, the output shape of the Flatten layer is actually a (64, 3072) tensor. Typically, you don't specify the batch size when you construct the model, which is why Keras shows it as None.

> What the ##!& is a tensor? It finally happened, we used the T-word, so we'd better explain what a tensor is at this point. Are you ready? Tensor is a fancy word for multi-dimensional array. Yup, that's all.

In machine learning, you often use multi-dimensional arrays to store your data. You already see that an image is stored as an array of shape (height, width, 3). This is a three-dimensional array where the first dimension is the height of the image, the second dimension is the width of the image, and the third final dimension is for three color channels (RGB). When you'll use arrays with even more dimensions: four, five or six.
