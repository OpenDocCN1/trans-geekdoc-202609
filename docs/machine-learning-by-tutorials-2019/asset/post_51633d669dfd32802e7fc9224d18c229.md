When you’re adding a model to your iOS app, size matters. Larger models use more battery power and are slower than smaller models. The size of the Core ML file is proportional to the number of learned parameters in the model. For example, ResNet50 download is 103 MB for a model with 25.6 million parameters. MobileNetV2 has 6 million parameters and its download is “only” 25 MB. By the way, just because a model has more parameters doesn’t necessarily mean it is more accurate. ResNet50 is much larger than MobileNetV2 but both models have similar classification accuracy.

These models, like other models you can find on the web, are trained on generic datasets. If you want to make a model that can detect a faulty thingamajig in the gizmos you manufacture, you’ll have to get lucky and stumble upon a model that someone else has trained and made for free — fat chance! There’s big money in building good models, so companies aren’t just going to give them away, and you’ll have to know how to make your own model.

## Convert existing models with coremltools

If there's an existing model that does exactly what you want but it's not in Core ML format, don't panic! There's a good chance you'll be able to convert it.

There are many popular open-source packages for training machine-learning models. To name a few:

- Apache MXNet
- Caffe (and the relatively unrelated Caffe2)
- Keras
- PyTorch
- scikit-learn
- TensorFlow

If you have a model that is trained with one of these packages — or others such as XGBoost, LIBSVM, IBM Watson you can convert to Core ML format using coremltools so that you can run the model from your iOS app.

coremltools is a Python package, and you'll need to write a small Python script in order to use it. Python is the dominant programming language for machine-learning projects, and most of the training packages are also written in Python.

Some popular model formats, such as TensorFlow and MXNet, are not directly supported by coremltools but have their own Core ML converters. IBM's Watson gives you a Swift project that works the Core ML model in its own API.

Because there are so many different training tools that all have their own, incompatible formats, there are several industry efforts to create a standard format. Apple's Core ML is one of efforts, but the rest of the industry seems to have chosen ONNX instead. Naturally, there is a converter from ONNX to Core ML.

> Note: It's important to note that Core ML has many limitations — is not as capable as some other machine-learning packages. There is no guarantee that a model trained with any of these tools can actually be converted to Core ML, because certain neural layer types may not be supported. In that case, you may need to tweak the original model before you can convert it.

## Transfer learning with Create ML and Turi

Create ML and Turi use transfer learning to let you customize pre-trained models with your own data. The base models have been trained on very large datasets, but transfer learning can produce an accurate model for your data with a much smaller dataset and much less time. You only need dozens or hundreds of images instead of tens of thousands, and training takes instead of hours or days.

In fact, both Create ML and Turi can use the Mac’s GPU to speed up the training process. Apple acquired the startup Turi in August 2016, a machine-learning tool which requires you to work in Python environment. At WWDC 2018, Apple announced Create ML, which is essentially a Swift-based subset of Turi to give you transfer learning for image and text classification using Swift.

Turi Create and Create ML are task-specific, rather than model-specific. This means that you specify the type of problem you want to solve, rather than choosing the type of model you want to use. Select the task that matches the type of problem you want to solve, then Turi Create analyzes your data and chooses the right model for the job.

Turi Create has several task-focused toolkits, including:

- Image classification: Images with labels that are meaningful for your app.
- Drawing classification: specifically for drawings.
- Image similarity: Find images that are similar to a specific image.
- Recommender system: Provide personalized recommendations.
- Object detection: Locate and classify objects in an image.
- Style transfer: Apply stylistic elements of a style to a new image.
- Activity classification: Use data from device's motion sensors to classify what the user is doing.

Of these toolkits, Create ML supports image, text, activity and sound classification, as well as object detection. We expect that Apple will add more toolkits in future updates.

- Text classification: Analyze the sentiment — positive or negative — text in social media, movie reviews, call transcripts, etc.
- Sound classification: Detect when certain sounds are made.

### Turi Create's statistical models

So far, we've described task-specific solutions. Let's now look one level of abstraction deeper at the model level. Instead of choosing a task and then letting the API select the best model, here you choose the model yourself. This gives you more control — on the flip side, it's also more work.

Turi Create includes these general-purpose models:

- Classification: Boosted trees classifier, decision tree classifier, logistic regression, nearest neighbor classifier, random forest classifier, and Support Vector Machines SVM.
- Clustering: K-Means, DBSCAN (density based).
- Graph analytics: PageRank, shortest path, graph coloring and more.
- Nearest neighbors.
- Regression: Boosted trees regression, decision tree regression, linear regression and random forest regression.
- Topic models: for text analysis.

You probably won't need to learn about these; when you use a task-focused toolkit, Turi Create picks suitable statistical models based on its analysis of your data. They're listed here so that you know you can also use them directly, if Turi Create's choices don't produce a good example.

For more information about Turi Create, visit the user guide: github.com/turicreate/tree/master/userguide/
