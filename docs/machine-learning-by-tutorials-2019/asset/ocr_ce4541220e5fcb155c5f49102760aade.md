```
let trainUrl =
  Bundle.main.url(
    forResource: "custom_tags",withExtension: "json")
let trainData = try MLDataTable(contentsOf: trainUrl)
```

You access the custom-tags.json file from the playground's resource bundle, and use it to create an MLDataTable. This class stores tabular data for use with Create ML. It populates itself with a new row for each item in the JSON file's list. It uses the keys in each dictionary as column names, and maps the dictionary values to the corresponding row-column cell.

So for the file you loaded, the MLDataTable will have 11 rows, each with two columns named "tokens" and "tags".

Next, add the following line to create your model:

```
let model = try MLWordTagger(
trainingData:trainData,
tokenColumn:tokens",labelColumn:tags",nparameters: MLWordTagger.ModelParameters(language:.english)
```

Here, you create an MLWordTagger, passing in the training data and the names of the columns, which defines the tokens and labels. Regardless of how much your table contains, the model only looks over the two columns you specify here. This is why it doesn't matter how you name the keys in your JSON file — pick whatever you like and then let MLWordTagger what to look for when you create it.

Once again, you specify the language as English, to match the training data. You will see how MLTagger uses this information a bit later.

In Classic ML fashion, creating your model object also handles training. You could test this model like you would any Create ML, but for now just save it out with the following code:

```
let projectDir = "TextClassification/"
// Optionally add metadata before saving model
```

```
let savedModelUrl =
  playgroundSharedDataDirectory.appendingPathComponent(
  projectDir + "AppleProductTagger.mlmodel")
try model.write(to:savedModelUrl)
```

Here, you export your model in Core ML format to the same Shared Data/Classifier folder you used to train your sentiment analysis model.
