> Note: You may be wondering how Create ML can load all of the training data in memory, since 4,800 images may take up more physical memory than you have RAM. Create ML loads data into MLDataTable structures, which keep only the image metadata in memory, then loads the images themselves on demand. This means that you can have very large MLTables that contain a lot of data.
