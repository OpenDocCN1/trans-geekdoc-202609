or .nameOrLexicalClass tag schemes and the tagger assigns NLTag values indicating how those are used in the text. For example, .noun, .verb or .adjective. Consult documentation for the possible values.

Tokenization is the process of splitting a text into smaller units. It most means dividing strings into individual words and punctuation, but it could mean breaking into other units, like sentences or characters.

The classes you've used throughout this chapter all tokenize their inputs automatically, so you haven't needed to worry about it. However, if you ever need to do yourself, the Natural Language framework provides NLTTokenizer to chunk text by word, sentence, paragraph or document. It uses language-specific rules which are generally good but might not be exactly what you want. Still, it's a nice option you should have at least the next time you need to tokenize some text.

You'll use NLTokenizer as a preprocessing step when you implement language translation in the next chapter. In the meantime, you can check out NLExtras.playground in the projects/final/playgrounds folder to see sample code for part-of-speech tagging and tokenization.

# Key points

+   * Apple's new Natural Language framework to take advantage of fast, well trained machine-learning models for NLP.
* NLLanguageRecognizer can identify the language used in a piece of text.
* NLTagger and NLTagScheme allow you to chunk text into specific, labeled types. There are several built-in tagging schemes available, and you can specify your own.
* NLTokenizer can break up text into documents, paragraphs, sentences or words.
* Use Create ML and MLTextClassifier to train your models to classify larger chunks of text, sentences, paragraphs or documents.
* Use Create ML and MLWordTagger to train models to classify text at the word level.
* NLModel wraps Create ML models like MLTextClassifier and MLWordTagger in a way that ensures inputs are preprocessed in your app as they were during training. It's the required type for custom tagging schemes used with NLTagger.
