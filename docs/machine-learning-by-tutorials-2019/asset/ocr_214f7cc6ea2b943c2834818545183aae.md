This plots all samples in the test set labeled rest_it, which means data that is not a gesture. Here are the results:

![](bbox=[0.196, 0.203, 0.803, 0.452])

'rest_it' samples in test dataset

Unlike with the gestures you plotted earlier, the resting data shows no clear pattern. That makes sense — users can do whatever they want between gestures, so there are basically an infinite number of possible sequences that could appear with this label.

Depending on how similar the resting and activity data are, a model might have trouble learning to classify them both. In those cases, it often helps to increase the size of your dataset. However, in many cases — such as this one — the model will learn to recognize both resting and activity. This is probably because the sequences related to the other gestures are so more distinct. It is likely to classify the other gestures well, and then learn that anything is resting. It will get some wrong — users sometimes performs the gestures while GestureDataRecorder is recording resting data, essentially adding mislabeled data to your dataset — but the juxtaposition of the messy resting data and the patterned gestures should make the model even more confident about its gesture predictions.

For this app, train with all your data, including the resting samples. However, you're encouraged to try making another model that excludes the resting data to see which you prefer. The results might vary depending on exactly what datasets look like.
