# Using a fixed validation set

Turi Creates a random validation dataset from the training dataset — 5% of the images. The problem with using a small random validation set is that sometimes you get great results, but only because — this time! — the validation dataset happens to be in your favor.

For example, if the model is really good at predicting the class "waffle" and the validation set happens to be mostly images of waffles, the validation accuracy will be higher than the true performance of the model. That's bad, because it may lead you to overestimate how good the model really is.

If you repeat training the model a few times, you'll see the validation accuracy vary a lot. it's better than the 67% you saw before, sometimes it's worse — on one of the author's training runs, it went low as 59%. It's hard to understand how well the model is doing when there is so much variation between runs.

To get more elaborate estimates of accuracy, use your validation set instead of letting Turi randomly select one. By using a collection of validation images that is always the same, you can control your experiments better and get reproducible results. You can now train the model with a few different configuration settings, also known as the hyperparameters, and compare the results to determine which settings work best. If you were to use a different validation set each time, the variation in the chosen images could obscure the effect of the changed hyperparameter.
