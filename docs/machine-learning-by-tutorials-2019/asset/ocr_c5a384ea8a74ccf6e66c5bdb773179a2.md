The dataframe is actually much bigger: when you len(train_annotations) it should print 7040. The dataframe has one row for each annotation. There are over 4,800 images in the training set but some pictures have multiple objects in them — that’s why there are more annotations than training images.

Some training images contain objects of different types. The dataframe all belong to the same name, a picture of a cake, but apparently, there’s also ice cream in that image (see rows 1 and 2).

There are also a number of images in the training set that do not have bounding annotations at all.

The coordinates of the bounding box are given by four numbers: x_min, x_min, x_max, y_min and y_max. The top-left corner of the box is (x_min, y_min), the bottom-right corner is (x_max, y_max). These are floating-point values — between 0 and 1, also known as normalized coordinates.

It’s convenient to use normalized coordinates because it makes them independent of the actual size of the image. This is important: remember we scale images to 224×224 pixels during training. The dataframe has two columns that contain class names: class_name, which is the class of the object inside this bounding box, and folder, where the image is stored in the dataset. folder is also the name of the class used for training the classifier in the previous chapters. From now on, you’ll only use the class_name for training, but you still need folder to know where to load the image file.
