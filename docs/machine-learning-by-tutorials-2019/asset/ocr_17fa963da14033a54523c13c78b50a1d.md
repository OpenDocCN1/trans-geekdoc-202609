The loss function for the bounding box predictions is "mse" or **mean squared error**.
This is a typical loss function for regression tasks, i.e., when the output of the model
consists of real-valued numbers, such as bounding box coordinates. The math for
this loss function looks like this:

```
mse_loss = sum( (truth - prediction)**2 ) / (4*batch_size)
```

Let's unpack this:

+   * First, it finds the difference between the ground-truth value and the prediction by
subtracting the two numbers: truth - prediction. This is the **error in mean**nsnsared error.
* Then it takes the square, which in Python is done with **2, so that difference
will be a positive number. This also makes larger errors count since
the square of a large number is much bigger than the square of a small number.
This a common mathematical trick that you see all the time in machine learning.
Now you have the **squared error**.
* Finally, it sums all these squared differences and divides by how many there
are. The loss is computed over a batch at a time, and there are four predicted
numbers for bounding box. In other words, it takes the average — the
of squared errors for all the predictions in the batch. It puts all together and you
get the **mean squared error**.

You don't need to remember this; just realize that it's really simple formula
and "mse" is the loss function to use when dealing with predictions that are just
numbers, opposed to probability distributions.
