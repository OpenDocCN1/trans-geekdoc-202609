The training loss certainly went down significantly but the validation loss doesn't
look particularly impressive. So is the model actually learning anything useful? It's
hard to say because the loss itself doesn't tell you much about how well the model
works. The only thing you can say for is that the model works better when it has
a lower loss than when it has a higher loss — not very enlightening.

At least for the classification output, you can compute the accuracy, which is more
interpretable than the loss. If the loss goes down by 10%, what does that mean? Who
knows... But the accuracy going up by 10% makes a lot of sense.

Fortunately, for the bounding box predictions, there is also a metric that gives us
