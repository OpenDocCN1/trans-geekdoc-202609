That's not half bad! The YOLO model does a pretty good job at finding —
proper classifying — the objects in the test images. It doesn't always find all
objects, and sometimes its predictions are wrong, but overall this is a very good
result. By the way, if Turi didn't find any objects in a test image, the predictions
column contains an empty list [].
