# Getting individual predictions

So far, you've just repeated the steps from the previous chapter. The evaluate () metrics give you an idea of the model's overall accuracy you can get a lot more information about individual predictions. Especially interesting predictions where the model is wrong, but with very high confidence that it's right. Knowing where the model is wrong can help you improve your training dataset.

![](bbox=[0.423, 0.273, 0.576, 0.417])

To get some more insight into what's going on, run the following cell:

```
metrics.explore()
```

This opens a new window (Mac only) that lets you examine the accuracy and other metrics visually. It also shows examples of images that were correctly — and more interestingly, incorrectly — classified. Very handy!
