# Learning rate annealing

One trick you can use to give the accuracy a little boost is to change the learning rate. It is like 1e-3 or 0.001 (set when you compiled the model), and you can change it by doing the following:

```
import keras.backend as K
K.set_value(model.optimizer.lr,
K.set_value(model.optimizer.lr) / 10
```

K refers to the Keras backend package, which is a wrapper around TensorFlow. You cannot set the optimizer's learning rate directly and must do it in this special way.
