> **Note:** Even though they have limitations, the big benefit of Create ML and Turi is is they support Mac GPUs through Metal. No big surprise there, as both are provided by Apple. Let's hope TensorFlow and other popular training tools will suit and support Metal, too. There's no reason the Intel or AMD GPU in your Mac cannot compete with NVIDIA chips — the only thing missing is software support.

If you have a spare PC with a reasonably recent NVIDIA GPU, and you don't mind installing Linux on it, by all means give that a go. It's also possible to use Keras and TensorFlow from GPUs, but this is a bit weird. We suggest using Ubuntu from ubuntu.com, the most popular Linux for machine learning.

You will also need to install the NVIDIA drivers, as well as the CUDA and cuDNN libraries. See developer.nvidia.com for more details. To install the python learning packages, use Conda as explained in Chapter 4, "Getting Started with Python & Turi Create." The process is very similar to Linux and Windows.

> **Tip:** If you're installing TensorFlow by hand, make sure to install the tensorflow-gpu package instead of tensorflow. You can change this in kerasenv.yaml or run pip install -u tensorflow-gpu. Also, be sure to install the version of TensorFlow that matches your version of CUDA and cuDNN. If these versions don't match, TensorFlow won't work. Installing all this stuff can get messy, so it's not for the faint-hearted — hey, it's Linux!

# # Your head in the clouds?

If you're just getting your feet wet and you're not quite ready to build your own deep-learning rig, the quickest way to get started with GPU training is to use the cloud. You can use some of these cloud services for free!

Often, there is a starter tier where you get a certain amount of compute hours for free. Some machine-learning-in-the-cloud services make it easy to run Jupyter notebooks but pay attention: make sure to shut down your Jupyter notebook when you're done with it. Usually, you only pay for what you use, but as you keep the Jupyter server running — even if it sits doing nothing — it uses compute time. And when your free limit runs out, this can cost quite quickly.
