Note: Earlier, we mentioned that the generator for the test set should not use data augmentation. Otherwise, running evaluate_generator() more than once would give different scores each time. You can actually use such differences to your advantage, known as TTA, or Test Time Augmentation.

For example, instead of making only one prediction for each test image, could you do it once for the normal image and once for the image flipped? Then the more different variations of the two predictions, the better the final score of the test you use, the better the score will be.

This trick is often used in competitions to squeeze a few extra points out of the model's performance. Of course, making multiple predictions per image is also so slow and therefore not really suitable for mobile apps.
