tokens. This reduces the power of your encoder. If that's not clear enough, don't
worry, it will be by the end of the chapter.

Finally, for these networks to produce their expected results, they require the
same padding at inference time. For example, if you trained a model to
translate "Hola" with a batch of 10-character-long sequences, you'd\have five padding tokens.

Your model would likely only produce the correct result during inference
if you tried to translate it with those same padding tokens, because the
same letters without the padding tokens would encode differently and
likely to translate something.

One drawback of using Masking layers is Core ML doesn't actually support
one. It won't be a problem for this project — you'll see why later -
means you won't be able to perform batch translations in iOS because it's
unlikely that you can create a batch of sequences of equal length without
padding.
