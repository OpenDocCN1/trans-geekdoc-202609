Also, note that the Detector model has three inputs and two outputs. In addition to the regular image input for a 416×416 color image, there are two inputs named `iouThreshold` and `confidenceThreshold`. These two values are used by NMS to decide which bounding boxes it should keep.

The higher you set the confidence threshold, the larger the confidence score on a predicted box has be in order to keep that. The IOU threshold determines when overlapping boxes are too small. A lower value means even boxes that only overlap a little bit are considered duplicates.

Even though you saw earlier that YOLO produces a single tensor of size 13×13×375, the Core ML model actually has two outputs. The Core ML pipeline applies NMS to the predictions from YOLO and even outputs the best bounding boxes. That's why the first dimension is so, or **unknown** NMS will return a different number of boxes depending on how many objects are in the image. For convenience, Core ML provides the class predictions and coordinates as separate values.

However, you don't have to worry about these inputs and outputs because you're going to be using this model through the Vision framework.

Most of the source code in `ViewController.swift` is exactly as as in the previous example apps. Make the `VNCoreMLModel` and `VNCoreMLRequest` objects the same way as before. You start the request using the `VNIRequestRequestHandler`. The only thing that's different is the result object returned by Vision.

Previously the result objects were of type `VNClassificationObservation`, but now they are `VNRecognizedObjectObservation`. This is a new class that was added to Vision with iOS 12, and it specifically to handle the results from YOLO model. All your app needs to do is handle these `VNRecognizedObjectObservation` instances. In the demo app, we draw a rectangle over any detected objects.

The fun stuff happens in `processObservations(error:)`, which is called from the completion handler for the Vision request. This function receives an array of zero or more `VNRecognizedObjectObservation` instances. If the array is empty, no objects were found. In that case, the app removes any previous rectangles from the screen.
