# # Chapter 4: Getting Started with Python & Turi Create

By Audrey Tam & Matthijs Hollemans

**Update Note:** This chapter has been updated to iOS 13, Xcode 11 and Swift 5.1

Congratulations! If you've made it far, you've developed a strong foundation for absorbing machine learning material. However, before we can move forward, we need to address the 10,000 pound snake in the room... Python. Until this point, you've made do with Xcode and Swift, however, if you're going to get serious about Machine Learning, then it's best you prepare yourself to learn Python. In this chapter,

+   - You will learn how set up and use tools from the Python ecosystem for data science and machine learning (ML).
- You will install **Anaconda**, a very popular distribution of Python (and R).
- You will use terminal commands to create ML environments which you'll use throughout this book.
- Finally, you'll use **Jupyter Notebooks**, which are very similar to Swift Playgrounds, to explore the Python language, data science libraries, and **Turi Create**, Apple's ML-as-a-Service.
