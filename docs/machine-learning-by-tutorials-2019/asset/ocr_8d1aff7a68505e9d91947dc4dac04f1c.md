# Machine Learning Chapter 2: Getting Started with Image Classification

The main benefit of SqueezeNet is that it's small. As you can see in Xcode, the size of this model is "only" 5 MB. This is tiny compared to many other deep learning architectures, which can take up hundreds of MBs. Such large models are usually not a good choice for use in a mobile app. Not only do they make the app download bigger but larger models are slower and use more battery power.

The Prediction section lists the inputs that the model expects and the outputs that it produces. Since this is an image classifier there is only one input, a color image that must be 227 pixels wide and 227 pixels tall.

You cannot use images with other dimensions. The reason for this restriction is that the SqueezeNet architecture expects exactly this size. If it's any smaller or larger, the math used by SqueezeNet doesn't work. This means any image you pick from the photo library or with the camera must be resized to 227×227 before you can use it with this Core ML model.

> Note: If you're thinking that 227×227 pixels are not very big, you're right. A 12-megapixel photo is 4052×3024—that is more than 200 times as many pixels! But there is a trade-off between image size and processing time. These deep learning models need a lot of calculations: For a single 227×227 image, SqueezeNet performs 390 million calculations. Making the image twice as large and the number of calculations doubles. At some point, that just gets out of hand and the model will be too slow to be usable!

Making the image smaller will make the model faster, and can even help the models learn better scaling down the image helps remove unnecessary details that would otherwise confuse the model. But there's a limit here too: At point, the image loses too much detail, and the model won't be able to do a good job anymore. For image classification, 227×227 is a good compromise. Typical image sizes used are 224×224 and 299×299.

The HealthySnacks model has two outputs. It puts probability distribution named labelProbability that will look like this:

```
labelProbability = [ "healthy": 0.15, "unhealthy": 0.85 ]
```

For convenience, the second output from the model is the class of the top prediction: "healthy" if the probability of the snake being healthy is greater than 50%, "unhealthy" if it's less than 50%.
