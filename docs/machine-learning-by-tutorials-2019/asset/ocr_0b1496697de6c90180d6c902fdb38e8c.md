# Chapter 10: YOLO & Semantic Segmentation

The demo app already includes the converted .mlmodel file, but it's a good idea to try converting this model by yourself.

> Note: You can also download a version of DeepLab v3+ from developer.apple.com/machine-learning/models/. It is the same model you'll be using.

First, download the file containing the pre-trained TensorFlow model. We used mobilenetv2_coco_voc_trainfrom from link download.tensorflow.org/models/deeplabv3 mnv2 pascal trainval 2018 01 29.tar.gz. We recommend that you use this exact version, or risk running it into errors.

After you unzip the download, look for the file frozen_inference_graph.pb. The extension pb stands for protobuf, which is the format that TensorFlow models — or graphs as they are saved in.

This particular file is a "frozen" graph that has been optimized for inference; all the operations for training have been removed from this graph.

Netron can open pb files, so take a look inside.

The particular section of the graph shown in the figure on the next page, has the layers that are responsible for performing the semantic segmentation. These are all layer types you've seen before: convolution, batch normalization, ReLU and average pooling.

There isn't some special semantic segmentation layer that performs all the magic — this neural network uses the same building blocks that they all do.
