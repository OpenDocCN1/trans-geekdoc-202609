The SFrame contains the annotations dictionaries

To view the annotations for a specific training image more detail you can run a cell train_data[some_index], but even better Turi's built-in visualization tool:

```
util = tc.object_detector.util
train_data['image_with_ground_truth'] = =
util.draw_bounding_boxes(
train_data['image'],
train_data['annotations'])
train_data.explore()
```

This adds another column to the SFrame named image_with_ground_truth does exactly what it says: It contains the images with the ground-bounding boxes drawn on top.
