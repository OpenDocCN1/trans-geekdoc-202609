> Note: With semantic segmentation, pixels only know which class they belong
to. Also is a kind called instance segmentation, where the
pixels only know their class but also distinct object they belong to.
For example, in a photo of two people who are sitting by side and are
touching, semantic segmentation will only see a single blob in which all the
pixels are class of "person." Instance segmentation will be able to distinguish
between person 1 and person 2.

A popular model for instance segmentation is Mask R-CNN, which adds
segmentation capabilities to the Faster R-CNN object detector. It makes sense
to think of instance segmentation as being a combination of object detection
and segmentation. As should be obvious by now, all these techniques are
closely related.
