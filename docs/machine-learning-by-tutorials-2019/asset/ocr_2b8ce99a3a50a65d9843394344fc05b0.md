algorithm keeps the predictions with the highest confidence scores and removes any other boxes that overlap with higher scores by more than a certain threshold, say an IOU of 45% or more. The model created by Turi Create automatically takes care of this post-processing step for you, so you don't have to worry about any of this.

> Note: Turi's object detection model is known as TinyYOLO because it is smaller than the full YOLO. The full version of YOLO has multiple output grids of varying dimensions in order to handle different object sizes, but this model is also larger and slower. Another popular single-stage detector is SSD. Architecturally, YOLO and SSD are very similar in design and differ only in the details. SSD does not have its own feature extractor and can be used with many different convnets. Particularly suitable for use on mobile is the combination of SSD and MobileNet.
