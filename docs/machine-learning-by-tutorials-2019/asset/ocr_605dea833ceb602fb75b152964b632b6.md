an image of size 224×224 pixels and 3 channels (RGB). Recall that Keras adds a dimension for the batch size at the front of the tensor. Usually, you keep this batch size unspecified when defining the model, which is why it shows up as None in the summary.

The output of the first conv layer, named conv2d_1 by Keras, is a tensor of size (None, 224, 224, 32). Instead of 3 channels, this layer's output “image” now has 32 channels. That's because this convolution layer has 32 filters, and there is one channel in the output for each filter.

> Note: We put “image” in quotes because the output from this layer is no longer something we can properly display on the screen. From now on, we'll call these blobs by more appropriate name: tensors.

The second conv layer, conv2d_2, takes this (None, 224, 224, 32) tensor and produces a new tensor of the same size. Because the second layer also has 32 filters, it also outputs 32 channels.

It's important to note that even though the input tensor and the output tensor for this layer both 32 channels, these are totally unrelated numbers. The number of filters in the layer is independent of the number of channels in the input tensor. It just so happens that these two numbers are the same for this particular layer. However, the number of output channels for a layer is always the same as the number of filters it has.

Each filter will reduce all of the 32 channels to a single channel in the output tensor. This is repeated 32 times because this layer has 32 filters, and each filter has its own set of weights and therefore learns to detect its pattern. To detect the pattern, each filter always looks at all of the input channels.
