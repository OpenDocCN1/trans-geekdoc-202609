# Machine Learning Chapter 6: Taking Control of Training with Keras

As you might have expected if you've worked with images before, the pixels have values between 0 and 255. In principle you can train the model directly on these pixel values but it is customary to **normalize** the data before you start training on it.

Normalizing or **feature scaling** means that the data will have an average value of 0 and usually a standard deviation of 1. This is important when different features are not all in the same range. For example, if your data has one feature with values between 0 and 1000 and another feature with values between 5 and 10, training will generally work better if you first normalize the features so that both are between -1 and +1.

In your case it not such a big deal since the pixels are the same scale from 0 to 255. This normalization is good practice so let's do it anyway.
Write this function:

```python
def normalize_pixels(image):
    return image / 127.5 - 1
```

This simply scales the pixel values from 0 to 255 to a new range that goes from -1 to +1. Sometimes subtract different mean values for the red, green, and blue channels and also divide by a standard deviation, but the above method is good for dealing with most kinds of images.

> Note: In this function, image is a tensor with 32×32 elements. When you write image / 127.5, NumPy will perform the division on each of the tensor's elements separately. This kind of "vectorized" processing, where you perform an operation on an entire tensor at, is much simpler — and faster! — than for loop. You'll see this sort a lot in Python code.

The steps to normalize an image are then:

```python
x = image.img_to_array(img)
x = normalize_pixels(x)
x = np.expand_dims(x, axis=0)
```

# Machine Learning Chapter 6: Taking Control of Training with Keras

As you might have expected if you've worked with images before, the pixels have values between 0 and 255. In principle you can train the model directly on these pixel values but it is customary to **normalize** the data before you start training on it.

Normalizing or **feature scaling** means that the data will have an average value of 0 and usually a standard deviation of 1. This is important when different features are not all in the same range. For example, if your data has one feature with values between 0 and 1000 and another feature with values between 5 and 10, training will generally work better if you first normalize the features so that both are between -1 and +1.

In your case it not such a big deal since the pixels are the same scale from 0 to 255. This normalization is good practice so let's do it anyway.
Write this function:

```python
def normalize_pixels(image):
    return image / 127.5 - 1
```

This simply scales the pixel values from 0 to 255 to a new range that goes from -1 to +1. Sometimes subtract different mean values for the red, green, and blue channels and also divide by a standard deviation, but the above method is good for dealing with most kinds of images.

> Note: In this function, image is a tensor with 32×32 elements. When you write image / 127.5, NumPy will perform the division on each of the tensor's elements separately. This kind of "vectorized" processing, where you perform an operation on an entire tensor at, is much simpler — and faster! — than for loop. You'll see this sort a lot in Python code.

The steps to normalize an image are then:

```python
x = image.img_to_array(img)
x = normalize_pixels(x)
x = np.expand_dims(x, axis=0)

Normalizing or **feature scaling** means that the data will have an average value of 0 and usually a standard deviation of 1. This is important when different features are not all in the same range. For example, if your data has one feature with values between 0 and 1000 and another feature with values between 5 and 10, training will generally work better if you first normalize the features so that both are between -1 and +1.

In your case it not such a big deal since the pixels are the same scale from 0 to 255. This normalization is good practice so let's do it anyway.
Write this function:

```python
def normalize_pixels(image):
    return image / 127.5 - 1
```

This simply scales the pixel values from 0 to 255 to a new range that goes from -1 to +1. Sometimes subtract different mean values for the red, green, and blue channels and also divide by a standard deviation, but the above method is good for dealing with most kinds of images.

> Note: In this function, image is a tensor with 32×32 elements. When you write image / 127.5, NumPy will perform the division on each of the tensor's elements separately. This kind of "vectorized" processing, where you perform an operation on an entire tensor at, is much simpler — and faster! — than for loop. You'll see this sort a lot in Python code.

The steps to normalize an image are then:

```python
x = image.img_to_array(img)
x = normalize_pixels(x)
x = np.expand_dims(x, axis=0)
```

# Too soon to make predictions?

An untrained model will make a prediction for each class that is very close to the average, because it hasn't learned how to distinguish the classes. It's unlikely you'll see a high percentage such as 90% on the output at this point. You'll probably get different results since your model will be initialized with different weights and biases.

```python
pred = model.predict(x)
print(pred)
```

```python
[[0.04173137, 0.02269506, 0.02333559, 0.1150756 , 0.0060842, 0.00578367, 0.03252693, 0.03938768, 0.08140159, 0.07274284, 0.03577968, 0.03044504, 0.07940029, 0.04531444, 0.0115772 , 0.17158438, 0.02129039, 0.02889681, 0.0514159, 0.0475868]]

To figure out what the actual predicted class is for this image, you find the maximum value amongst the predicted probabilities:

```python
np.argmax(pred)
```

For the prediction shown above, this prints 12, because the element at index 12 is the highest (0.17158438).

So which class is this? Well, you actually haven't assigned class labels to each of the 20 outputs yet. That will be done automatically by Keras during training. It usually does this alphabetically, so the winning class will be "orange" since that is the 12th class; as usual we start counting at 0.
