> Note: For a binary classifier, you can keep using softmax and the loss function "categorical_crossentropy", which gives you two output values, one for each category. Alternatively, you can choose to have just a single output value, in which case the final activation should not softmax but Activation("sigmoid"), the logistic sigmoid. The corresponding loss function is "sigmoid + binary_crossentropy" for the classifier. If you feel up to a challenge, try using this sigmoid + binary crossentropy. The class_model of the ImageDataGenerator should be "binary" instead of "categorical".

Tip: To add a Conv2D layer after the GlobalAveragePoolingD layer, you have to add a Reshape layer after pooling, because global pooling turns the tensor into a vector, while Conv2D layers expect a tensor with three dimensions.

```
top_model.add(GlobalAveragePoolingD())
top_model.add(Reshape((1, 1, 1024)))
top_model.add(Conv2D(...))
```
