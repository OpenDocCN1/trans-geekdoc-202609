## What is feature extraction?

You may recall that machine learning happens on “features,” where we've defined a feature to be any kind of data item that we find interesting. You could use the photo's pixels as features, but as the previous chapter demonstrated, the individual RGB values don't say much about what sort of objects are in the image.

VisionFeatureExtractor transforms the pixel features, which are hard to understand, into features that are more descriptive of the objects in the images.

This is the pipeline we've talked about before. Here, however, the output of VisionFeatureExtractor is not a probability distribution that says how likely is that the image contains an object of each class.

VisionFeatureExtractor's output is well, more features.

![](img/5720be5c3cca252e12448e68d25607b5_104_0.png)

VisionFeatureExtractor extracts features

For each image, VisionFeatureExtractor produces a list of 2,048 numbers. These numbers represent the content of the image at a high level. Exactly what these numbers mean isn't always easy to describe in words, but think of each image as being a point in this new 2,048-dimensional space, where images with similar properties are grouped together.

For example, one of those 2,048 numbers could represent the color of a snack, and oranges and carrots would have very similar values in that dimension. Another feature could represent how elongated an object is, and bananas, carrots and hot dogs would have larger values than oranges and apples.

On the other hand, apples, oranges and doughnuts would score higher in the dimension for how "round" is, while waffles would score lower in that dimension (assuming a negative value for that feature means squareness instead of roundness).

Models usually aren't that interpretable, though you get the idea: new 2,048 features describe the objects in the images by their true characteristics, which are much more informative than pixel intensities. However, you cannot draw a line (sorry, a hyperplane) through this 2,048-dimensional space to separate the images into the different classes we're looking for, because VisionFeatureExtractor is not trained on our own dataset. It is trained on ImageNet, which has 1000 classes, not 20.

While VisionFeatureExtractor does a good job of creating useful features from the training images, in order to classify these images we need to transform the data one more into the 20-dimensional space that we can interpret as the probability distribution over 20 types of snacks.

How do we do that? Well, Create ML uses these 2,048 numbers as the input to a new machine learning model called logistic regression. Instead of training a big, hairy model on images that have 150,000 features (difficult!), Create ML trains a much simpler model on top of the 2,048 features that VisionFeatureExtractor has extracted.

## Logistic regression

By the time you're done reading the previous section, Create ML has (hopefully) finished training your model. The status shows training took 2 minutes, most of time was spent on extracting features.

> Note: I'm running Create ML on a 2018 MacBook Pro with a 6-core 2.7GHz CPU and Radeon 560 GPU. You'll probably see different results than this. Untrained models, in this case the logistic regression, are initialized with random numbers, which can cause variations between different training runs.

The solver that Create ML trains is a classifier called logistic regression. This is an old-school machine learning algorithm but it's still extremely useful. It's arguably the most common ML model in use today.

## Linear and logistic regression

Logistic regression does the same thing, but: All points on one side of the line belong to class A, and all points on the other side of the line belong to class B. See how we're literally drawing a line through space to separate it into two classes?

Because books cannot handle 2,048-dimensional illustrations, the logistic regression in the above illustration is necessarily two-dimensional, but the algorithm works well, regardless of how many dimensions the input data has. Instead of a line, the decision boundary is really a high-dimensional object we've mentioned before: a hyperplane. But because humans have trouble thinking in more than two or three dimensions, we prefer to visualize it with a straight line.

Create ML actually uses a small variation of the algorithm — multinomial logistic regression — handles more than two classes.

Training the logistic regression algorithm to transform the 2,048-dimensional features into a space that allows us to draw separating lines between the 20 classes is fairly easy; we already start with features that say something meaningful about the image, rather than pixel values.

> Note: If you're wondering about exactly how logistic regression works, as usual it involves a transformation of the features. The closer the point is to the decision boundary, the more certain we are it belongs to a class. The more iterations, the better the model is.

## Looking for validation

Even though there are 4,858 images in the training set, Create ML uses only 95% of them for training.

During training, it's useful to periodically check how well the model is doing. For this purpose, Create ML sets aside a small portion — 5%, about 240 images. It doesn't train on these, but uses them to evaluate how well the model does.

This is the output graph for **training accuracy** and **validation accuracy:**

![](img/5720be5c3cca252e12448e68d25607b5_107_0.png)

After 12 iterations, validation accuracy levels off at 94%, meaning that out of 100 validation examples it correctly predicts the class for 94 of them. But training accuracy keeps increasing to 100% — the classifier is correct for 10 out of 10 training images.

> Note: What Create ML calls an iteration is one pass through the entire training set, also known as an "epoch". This means Create ML has given the model a chance to look at all training images. If you do 10 iterations, the model will have seen each training image (or its features) 10 times.

By default, Create ML trains the logistic regression for up to 25 iterations, but you can change this with the Maximum Iterations parameter. In general, the more iterations, the better the model, but also the longer you have to wait for training to finish. But training the logistic regression doesn't take long, so no problem!
