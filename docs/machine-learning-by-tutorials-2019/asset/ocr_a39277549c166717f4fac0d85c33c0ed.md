You declare make_batch_storage to take three parameters, — along with the vocabulary sizes — define the dimensions of the tensors it creates. It returns three NumPy arrays, sized to hold batch_size sequences that are each in/out_seq_len characters long, with each character in out/vocab_size width. Specifying dtype=np.float32 keeps NumPy from default to 64-bit floats.

The in_seq_len and out_seq_len parameters to make_batch_storage deserve more explanation. Consider this: If you create a batch with random samples from your training set, are all their sentences guaranteed to have the same length?

Mixed-length sequences without padding

Each sequence has a different length, but needs fixed dimensions. That means each item in a batch need to fill the same amount of space in the tensor, regardless of how many tokens are in the actual sequences. To accomplish this, you'll use special padding tokens to the end of each input sequence shorter than in_seq_len, and at the end of each output sequence shorter than out_seq_len.
