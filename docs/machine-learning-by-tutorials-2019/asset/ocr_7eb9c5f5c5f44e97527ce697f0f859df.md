# Chapter 8: Advanced Convolutional Neural Networks

The output from the squeeze convolution branches into two parallel convolutions, one with a 1×1 window size and the other with a 5×3 window. Both convolutions have 64 filters, which is why this is called the expand partition of the fire module, as the layers increase the number of channels again. Afterwards, the output tensors from these parallel convolution layers are concatenated into one big tensor that has 128 channels.

The squeeze layer from the next fire module then reduces these 128 channels again to 16 channels, and so on. As is usual for convets, the number of channels increases the further you go into the network, but this pattern of reduce-and-expand repeats several times over.

The reason for using two convolutions on the same data is that by using of different transformations potentially lets you extract more interesting information. You see similar ideas in the Inception modules from Google's famous Inception-v5 model, which combines 1×1, 3×5, and 5×5 convolutions, and even pooling, into the kind of parallel structure.

The fire module is very effective, by the fact that SqueezeNet is a powerful model — especially for one that has 1.2 million learnable parameters. It scores about 67% correct on the snakers dataset, compared to 40% from the basic convnet of the previous section, which has about the same number of parameters.

If you are curious, you can see a Keras version of SqueezeNet in the notebook SqueezeNet.ipynb in this chapter's resources. This notebook reproduces the results from Turi with Keras. We're not going to explain that code in detail here since you'll be using an architecture that gets better results than SqueezeNet. However, feel free to play with this notebook — it's fast enough to run on your Mac, no GPU needed for this.

# The Keras functional API

One thing we should mention in this point is the Keras functional API. You've seen how to make a model using Sequential but that is limited to linear pipelines that consist of layers in a row. To code SqueezeNet's branching structures with Keras, you need to specify your model in a slightly different way.

In the file squeezezenet/squeezenet.py, there is a function SqueezeNet(...) that defines the Keras model. It more-or-less does the following:

```
img_input = Input(shape=input_shape)
x = Conv2D(64, 3, padding='valid')(img_input)
```
