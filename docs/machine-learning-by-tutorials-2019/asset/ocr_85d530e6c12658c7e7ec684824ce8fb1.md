# Machine Learning Chapter 11: Data Collection for Sequence Classification

Each of the above images tells only part of the story. Rather than considering them individually, you need to reason over them as a sequence, applying what you see in earlier frames to interpret later ones.

There are many tasks that involve working with sequential data, such as:

+   - Extracting meaning from videos. Maybe you want to make an app that translates sign language, or search for clips based on the events they depict.

+   - Working with audio, for example converting speech to text, or songs to sheet music.

+   - Understanding text, as these sentences you've been reading, are sequences of words, themselves sequences of letters (assuming you're reading this in a language that uses letters, that is)

+   - Countless others. From weather data to stock prices to social media feeds, there are endless streams of sequential data.

With many types of data and almost as many techniques for working with it, this chapter can't possibly cover everything. You'll learn ways to deal with text in later chapters, and some of the techniques shown here are applicable to multiple domains. But to keep things practical, this chapter focuses on a specific type of sequence classification — human activity detection. That is, using sensor data from a device worn by a person to identify what that person is physically doing. You've already experienced activity detection on your devices, by checking your daily step count on your iPhone or closing rings on your Apple Watch. Those just scratch the surface of what's possible.

In this chapter, you'll learn how to collect sensor data from Apple devices and prepare for it by training a machine learning model. You'll use that data in the next chapter, along with Turi's task-focused API for activity detection, to build a neural network that recognizes user activity from device motion data. Finally, you'll use your neural net to recognize player actions in a game. The game you make is like the popular Pop It, but instead of calling out physical bits to bob and twist, it will call out gestures for the player to make with their iPhone. Perform the correct action before time runs out! The gestures detected include a chopping motion, a shaking motion and a driving motion (imagining turning steering wheel).

We choose this project because collecting data and testing it is so comfortable within the ability of most readers. However, you can use what you learn here for more than just gesture recognition — these techniques let you track or reach any activity identifiable from sensor data available on an Apple device.
