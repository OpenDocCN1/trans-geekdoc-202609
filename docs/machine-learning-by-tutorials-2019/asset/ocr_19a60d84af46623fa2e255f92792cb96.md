# Machine Learning Chapter 8: Advanced Convolutional Neural Networks

The pretrained MobileNet knows a lot about photos in general, including photos of food items. This is why you've trained a classifier on top of MobileNet's layers so that it can translate this general knowledge about photos to your 20 categories of snacks.

The pretrained feature extractor contains a lot of irrelevant knowledge, too, about animals, vehicles and all kinds of things that are not snacks. We don't need this knowledge for our task of classifying snacks.

With fine-tuning, you can adjust the knowledge inside the feature extractor to make it more relevant to your own data. Now the feature extractor itself understands more about this specific task.

To fine-tune the MobileNet layers, first set them to trainable and then compile the model again:

```
for layer in base_model.layers:
    layer.trainable = True

top_model.compile(loss="categorical_crossentropy",
                   optimizer=optimizers.Adam(lr=1e-4),
                   metrics=["accuracy"])
```

It's important to use a lower learning rate, lr=1e-4. That's why you don't want to completely throw away the MobileNet layers you have already learned — only you tweak these values a little.

It's better to set the learning rate too low than too high at this point, or you might end destroying useful knowledge. The author found 1e-4 by experimenting a bit.

Run top_model.summary() and you will see that there are now over 3 million parameters instead of 20,500. There are still non-trainable parameters; these are used by the BatchNorm layers to keep track of internal state.

Simply run the cell with top_model.fit_generator() to start fine-tuning. The loss may bounce around a bit in the beginning because suddenly the optimizer has a lot more work to do.

It also lost track of where it because because compiled the model again. But you should see the training and validation accuracy start to improve quite quickly again. If not, lower the learning rate.
