# Shutting down Jypter

To shut down Jupyter, click the **Logout** button in this browser window and also in the window showing your ML directory.

In the **Terminal** window from which you ran jupyter notebook — or the one that ran jupyter_mac.command ; exit; if you used Anaconda Navigator to launch Jupyter — press **Control-C** to stop the server. You may need to press this twice. If the prompt doesn't return, close this terminal.

# Deactivating the active environment

If you activated **turienv** at the terminal command line, enter this command to deactivate it:

```
conda deactivate
```

This deactivates the **turienv** environment; the command line prompt loses the (turienv) prefix.

# Docker and Colab

There are two high-level tools for supporting machine learning in Python: Docker and Google Colaboratory. These can be useful for developing machine learning projects, but we're not covering them in this detail.

Docker is a useful tool for creating reproducible environments for machine learning projects, and is therefore a useful tool when you want to scale up projects. Colaboratory is a Jupyter notebook in the cloud that gives you access to free GPU. But, while you're working through the Turi Create and Keras examples in this book and trying out your modifications, it's more convenient to use the **turienv** environments, and know how to build or modify them.

# Docker

Docker is like a virtual machine but simpler. Docker is a container-based system that allows you to re-use and modularize reusable environments, and is a fundamental building block to scaling services and applications on the Internet.
