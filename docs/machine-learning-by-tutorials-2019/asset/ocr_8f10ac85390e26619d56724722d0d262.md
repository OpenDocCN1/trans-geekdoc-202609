# Showing the results

Of course, printing stuff to the output pane isn't very exciting, so let's properly show these results in the app.

Inside the declaration of lazy classificationRequest, change the completion handler for the VNCoreMLRequest object to the following:

```
let request = VNCoreMLRequest(model: visionModel,
    completionHandler: {
        [weak self] request, error in
        self?.processObservations(for: request, error: error) // add this
    }
)
```

Instead of the print statement that was previously there, you're now calling a new method, processObservations(for:error). It's perfectly possible to push the code that handles the results directly inside the completion handler, but it tends to make the code harder read.

Add the new method to ViewController.swift:

```
func processObservations(for request: VNRequest, error: Error?) {
    // 1
    DispatchQueue.main.async {
        // 2
        if let results = request.results as? [VNClassificationObservation] {
            // 3
            if results.isEmpty {
                self.resultsLabel.text = "nothing found"
            } else {
                self.resultsLabel.text = String(format:"%@ %.1f%%", results[0].identifier, results[0].confidence * 100)
            }
            // 4
        } else if let error = error {
            self.resultsLabel.text = "error: \(error.localizedDescription)"
        } else {
            self.resultsLabel.text = "???"
        }
        // 5
        self.showResults()
    }
}
```
