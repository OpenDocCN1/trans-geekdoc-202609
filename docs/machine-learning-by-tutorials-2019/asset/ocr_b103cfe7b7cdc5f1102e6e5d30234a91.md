There are many parameters available to control training models. Here's how we
trained one:

+   1. Keras lets you add callbacks to monitor and modify the training process between
epochs. You can use an EarlyStopping callback that will stop training if
validation loss improves. The patience parameter tells it to keep training
for number of epochs even if the loss is not improving, and
restore_best_weights tells it to use the model weights from the epoch with the
best value than the one last.

+   2. You call fit_generator on the seq2seq_model object you created earlier,
passing the two Seq2SeqBatch objects you just made. This function
trains the model, using those objects to create batches for training and
validation. You told to train it for 500 epochs, but the early_stopping callback
should stop it before it reaches that number.

The model provided with the chapter had its best validation loss of 0.595 at epoch
179. If you try training your model, you'll get different results, but probably not
too different. The specific values aren't really important here, just that you
understand the architecture so you can apply it to your own problems in the future.
