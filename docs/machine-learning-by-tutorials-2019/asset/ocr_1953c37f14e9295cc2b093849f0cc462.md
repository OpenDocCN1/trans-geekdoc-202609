The "learning" in machine learning really applies only to the training phase. Once you've trained the model, it will no longer learn anything new. When you use a machine-learning model in an app, you're not implementing learning so much as "using a fixed model that has previously learned something.". Of course, it's possible to re-train your model every so often — for example, after you've gathered new data and update your app to use this new model.

> Note: New Core ML 3 is on-device personalization of models. This lets you incorporate the user's own data into the model. You'd still start out with a model that has been fully trained and already contains a lot of general knowledge, but fine-tune the model to each user's specific needs. This type of training happens right on the user's device, no servers needed.

# # Supervised learning

The common type of machine learning practiced today, and the main topic of this book, is **supervised learning**, in which the learning process is guided by a human — you! — tells the computer what it should learn and how.

With supervised learning, you train the model by giving it **examples** to look at, as photos of your friends, you also tell it those examples represent so the model can learn to tell the difference between them. **labels** tell the model (or what) is actually in those photos. Supervised training always needs labeled data.

> Note: Sometimes people say "samples" instead of examples. It's the same thing.
