# Transfer learning with Create ML and Turi

Create ML and Turi Create use transfer learning to let you customize pre-trained base models with your own data. The base models have been trained on very large datasets, but transfer learning can produce an accurate model for your data with a much smaller dataset and much less time.

You only need dozens or hundreds of images instead of tens of thousands, and training takes instead of hours or days. That means you can train these kinds of models straight from the comfort of your Mac.

In fact, both Create ML and Turi Create (as of version 5) can use the Mac’s GPU to speed up the training process.

Apple acquired the startup Turi in August 2016, then released Turi Create as open-source software Apple’s first transfer-learning tool, which requires you to work in the alien environment of Python.

At WWDC 2018, Apple announced Create ML, which is essentially a Swift-based subset of Turi, to give you transfer learning for image and text classification using Swift and Xcode. As of Xcode 11, Create ML is a separate app.
