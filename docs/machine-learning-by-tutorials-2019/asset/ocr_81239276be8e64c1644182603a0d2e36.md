# Converting your model to Core ML

So far, you used teacher to train a Keras seq2seq model to translate Spanish text to English, then you used those layers to create separate encoder and decoder models that work without you needing to provide them with the correct translation. That is, you removed the teacher-forcing aspect of the model that only makes sense while training. At this point, you *should* be able to convert your encoder and decoder models to Core ML and use them in your app.

But is it that easy?

Currently, there are issues with Core ML and/or coreml (the Python package that converts models into Core ML format), preventing you from exporting the models you've made. Don't worry — this section shows how to work around each of and convert your models to Core ML. Start with the code: Run the following code to do a bunch of stuff you shouldn't have to do, which is explained after the code block:

```

# 2
```
