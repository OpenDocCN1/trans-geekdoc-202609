Frequency varies from 6 to 361. You can plot a histogram of this distribution:

```
plt.hist(freq, bins=100)
plt.show()
```

![](bbox=[0.263, 0.532, 0.737, 0.786])

Specifying bins=100 divides the range [6, 361] into 100 consecutive, non-overlapping intervals, called bins and buckets. The histogram's x-axis has 100 bins, between 0 and 361-ish. The y-axis shows the number of authors in each bin.
