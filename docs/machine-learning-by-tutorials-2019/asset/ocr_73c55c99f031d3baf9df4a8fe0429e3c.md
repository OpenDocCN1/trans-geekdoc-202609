In the last chapter, we used 32x32-pixel images to keep the number of learnable parameters down. For a conv, the number of learnable parameters does not depend on the size of the input image, only on the size of the convolution kernels. For convnets you can get away with large images, which is using 224x224 pixels. That's a typical input size for convnets.

> Note: You can also keep the input width and height undefined, or None, in which case the convnet will accept input images of any size. You might think that larger images would give more accurate results, but this is not always the case. The patterns a model learned from 224x224 images may not actually appear in a 1,000x1,000 image. Of course, you could train on 1,000x1,000 images, but large images can easily take up more RAM than in your GPU, making harder to train these models. For classification models, 224x224 is a good compromise between memory usage and accuracy. Vision FeaturePrint uses 229x299, SqueezeNet uses 227x227. Feel free to experiment with different images in this chapter.
