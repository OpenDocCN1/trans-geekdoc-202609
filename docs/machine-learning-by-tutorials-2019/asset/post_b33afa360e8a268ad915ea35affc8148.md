Instead of creating a Sequential object and then doing model.add(layer), here a layer is created by writing:

x = LayerName(parameters)

Then this layer is immediately applied to the output from the previous layer:

x = LayerName(parameters)(x)

x, is not a layer object but a tensor object. This syntax may look a little weird, but in Python, you're allowed to call an object instance (the layer) as if it were a function. This is actually a very handy way to define models of arbitrary complexity.

To create the actual object, you need to specify the input tensor as well as the output tensor, which is now in x:

model = Model(img_input, x)

You can see how the branching structure is made in the fire_module function, which is now in an abbreviated version:

```python
def fire_module(x, squeeze=16, expand=64):
    sq = Conv2D(squeeze, 1, padding='valid')(x)
    sq = Activation('relu')(sq)

    left = Conv2D(expand, 1, padding='valid')(sq)
    left = Activation('relu')(left)

    right = Conv2D(expand, 3, padding='same')(sq)
    right = Activation('relu')(right)

    return concatenate([left, right])
```

This has four tensors: x that has the input data, sq with the output of the squeeze layer, left for the left branch and right for the right branch. At the end, left and right are concatenated into a single tensor again. This is where the branches come together.

A lot of Keras will use both Sequential models and models defined using this functional API, so it's good to be familiar with it.

## MobileNet and stride

The *stride* is the size of the steps the convolution kernel takes as it slides through the image. Usually, this step size is 1 and the convolution looks at all the pixels.

With a stride of 2, the window will skip every other pixel, thereby computing products for half the pixels in both the width and height directions. This way you don't need a special pooling layer to make the image smaller.

## Depthwise separable convolutions

MobileNet achieves this by setting the stride of some of the Conv2D and Depthwise2D layers to 2 instead of 1. This is why MobileNet is so suitable for mobile devices.

The final layer in this model outputs a tensor of size (7, 7, 1024). This tensor contains the features that MobileNet has extracted from the input image. You're simply going to add a logistic regression on top of these extracted features, exactly like you've done before.
