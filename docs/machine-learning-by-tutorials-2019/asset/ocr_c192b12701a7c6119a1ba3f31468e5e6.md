An untrained model will make a prediction for each class that is very close to the average, because it hasn't learned how to distinguish the classes. It's unlikely you'll see a high percentage such as 90% on the output at this point. Most classes will have a probability score around 0.05, or 1/num_classes, although it can vary a bit because of the random initialization.

If we were to make predictions for the entire dataset at this point, each class would be predicted the same number of times and the overall accuracy would be 0.05 or 5% — basically a random guess. The goal of machine learning is to train a classifier that can do better than random guessing.
