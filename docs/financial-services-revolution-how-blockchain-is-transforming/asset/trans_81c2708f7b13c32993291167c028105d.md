
另一个例子是首次公开募股（IPO）市场。在其上一次繁荣——即 1990 年代末互联网泡沫期间——该市场问题重重。一个关键问题是发行的分配和准入规则。传统上，主承销投资银行控制谁能获得发行股份。对于热门 IPO，存在诸多利益冲突：例如，一个广泛报道的担忧是，承销投资银行有动机通过给予其最优质客户低价股份来取悦他们。^([375](#21_bm005.html#fnr375)) 另一个广泛报道的问题是“阶梯承销”过程，即投资者只有承诺以更高价格购买更多股份，才能获得发行股份。^([376](#21_bm005.html#fnr376)) 在当今的投资银行业世界中，承销商很难说服发行人和投资者，利益冲突在其建议和决策中不起作用。将此与目前火热的 ICO（首次代币发行）市场形成对比（无论好坏），许多 ICO 从所有实际目的来看，都类似于证券发行。^([377](#21_bm005.html#fnr377)) 该市场的分配机制完全透明，因为它内嵌于那段决定代币如何分配的公开可见代码中。^([378](#21_bm005.html#fnr378))

在一篇备受推崇的论文中，David Yermack 强调了区块链技术可为公司治理带来的诸多潜在益处。^([379](#21_bm005.html#fnr379)) 例如，Yermack 认为，区块链上的透明所有权归属有助于解决所谓的“空投票”现象，即某实体在没有公司经济利益的情况下，却对经济上有意义的决策进行投票。^([380](#21_bm005.html#fnr380)) 通常的假设是，对公司的经济利益和投票权与股份所有权相挂钩。然而，衍生品合约使得一方有可能在没有公司经济利益的情况下获得大量投票权。^([381](#21_bm005.html#fnr381)) 通过区块链进行所有权归属，在任何时间点，谁拥有股票、谁拥有经济上合理的投票权，都将是透明的。

内幕交易是金融业和学术界另一个争议颇多的话题，也是一个显而易见的应用场景。内幕人士已经被要求披露其交易和持仓，但交易与报告之间往往存在显著延迟。^([382](#21_bm005.html#fnr382)) 因此，如果所有交易都记录在区块链上，那么——通过揭示其公开 ID——内幕人士可以可信且即时地展示其交易。他们所有的交易都将可见，这将消除昂贵的报告要求，并可能增加公众信任。^([383](#21_bm005.html#fnr383)) 公众将能够更好地了解内幕持仓和内幕交易，公司高管将与股东建立信任。这一论点在内幕交易违规执法不如北美严格的司法管辖区中尤为适用。最后，内幕交易的透明度应能降低内幕人士从事非法交易的倾向。随着透明度降低了内幕交易者的灵活性，外部人士生成关于公司的信息将变得更有利可图。

Yermack 强调，公共区块链的不可篡改性改善了（公司）治理。在当前系统中，土地记录可被伪造，公司利润表可被操纵，期权授予可被回溯定价。当所有这些数据都记录在公共区块链上时，实施此类操纵将变得极其困难且昂贵。

在金融领域，合同和持仓的透明度超越了公司治理核心的逆向选择和道德风险的解决，并对风险管理具有潜在的深远影响。2008 年金融危机后的一个重大发展是，特定类型的衍生品合约（如掉期）被强制要求通过新开发的“中央对手方”（CP）进行清算。基本思路是：当 A 想卖给 B 时，A 卖给 CP，然后 CP 卖给 B。为什么这有必要？设想 A 也从 C 处买入，但 C 破产了。A 将无法向 B 交付，自己也可能破产。因此，在与 A 交易时，B 面临两种对手方风险：(a) A 独立破产的风险，以及 (b) C 破产并连累 A 一起倒下的风险。

考虑金融危机前 AIG 在信用违约掉期市场上的衍生品交易，当时显而易见，AIG 持有大量未对冲头寸。AIG 的违约将引发其对手方的违约，导致整个金融系统发生连锁反应。当所有交易都由 CP 清算时，风险集中在 CP。尽管该系统能产生互利的风险分担水平，但也存在问题：因为它是一个“大而不能倒”的实体，CP 需要受到严格监控、拥有充足资本，并可能面临严格监管。此外，目前只有少数合约符合 CP 清算资格。CP 必要性的根本原因在于对聚合风险的信息不足，这造成了道德风险。正如我们从美国经济学家 George Akerlof 的开创性工作中所知，信息不对称可能导致市场崩溃。

我们可以认为，区块链技术实现的透明度提供了一种基于市场的解决方案：当所有金融义务都可见时，我们将能够追踪双边互动之外的对手方风险。未对冲头寸将变得可见。此外，我们将能够编写带有保护性契约的智能合约，迫使对手方通过代码及时建立对冲，或阻止其从事未对冲合约。

最后，智能合约本身可以从根本上改善经济互动。作为第一步，智能合约可以在违约时自动转移所有权，从而促进抵押品的交付。这种自动化极大地改善了抵押品的执行，提高了其价值，降低了风险，并可能释放资本。

我们使用合约向他人（如股东）证明货物转移将会发生（或已被合法化）。我们可以在没有区块链和非透明环境下使用智能合约；但在透明的区块链中，各方可能能够出售未来付款的权利。换句话说，公司可能能够直接从合约中出售现金流，并可能直接对冲现金流风险。此外，正如 Cong、He 和 Zheng 所展示的，智能合约可以缓解信息不对称，从而促进准入和竞争，进而带来更高的社会福利和消费者剩余。^([384](#21_bm005.html#fnr384))

总而言之，支持区块链技术所提供的交易和合约透明度的可靠商业理由是存在的，这些优势远远超出了解决因头版丑闻而产生的担忧。就目前而言，企业实体的隐私已经受到限制，尤其是与个人隐私相比。假设监管直接要求基于区块链的互动披露，这并不无道理——如果区块链确实成为金融交易的标准，那么这种披露在程序上是廉价的。
