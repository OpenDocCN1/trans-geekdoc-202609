

# 重新思考中央银行

随着范式的转移，旧时代的领导者往往是最后拥抱新事物的人，如果他们能活到那时候的话。那么，为什么百视达没有创建奈飞，而西尔斯没有创建亚马逊？其中一个原因是创新者的窘境，即旧范式的颠覆者难以颠覆自己，这主要归因于良好的管理。哈佛商学院教授克莱顿·克里斯滕森解释道：

> 那些对成熟公司成功至关重要的决策制定和资源配置流程，恰恰是那些排斥颠覆性技术的流程：倾听客户意见；仔细追踪竞争对手的行动；并投入资源设计和制造性能更高、质量更好、能带来更高利润的产品。^([58](#21_bm005.html#fnr58))

这并不是说现有巨头在初创公司如雨后春笋般涌现时坐视不管。恰恰相反。曾在哈佛和伦敦商学院任教的战略与创业学教授唐·萨尔发现，成功公司的领导者加倍押注于使他们成功的因素，在过时技术上投入更多，而不是将资金导向创新。萨尔将这种现象称为*主动惰性*：“当世界改变时，陷入主动惰性的组织会做更多同样的事情。”^([59](#21_bm005.html#fnr59)) “陷入主动惰性的组织就像一辆后轮陷入车辙的汽车，”萨尔写道。“管理者猛踩油门。他们非但没有摆脱车辙，反而陷得更深。”^([60](#21_bm005.html#fnr60))

许多所谓的数字化转型项目往往陷入“故技重施，仅披上数字外衣”的阵营。这些举措往往不成功且浪费资源。例如，据《福布斯》的史蒂夫·佐贝尔称，70%的数字化转型计划未能达到目标。^([61](#21_bm005.html#fnr61)) 尽管在数字化转型上花费了1.3万亿美元，但约有9000亿美元被浪费了。^([62](#21_bm005.html#fnr62))

然而，有时旧时代的领导者确实会拥抱新事物。IBM迄今已成功驾驭多次转型——从穿孔卡片到大型机、个人电脑再到互联网。联邦快递40年来一直是供应链和物流领域的创新者；它现在有一个宏大愿景，即联邦快递将成为一家建立在区块链开放标准之上的金融服务公司。^([63](#21_bm005.html#fnr63)) 脸书或许也通过推出天秤币看到了同样的前景。这些例子的共同点在于：专注于客户试图解决的问题。

在金融服务领域，区块链常被吹捧为一种神奇的降本灵丹妙药，有望从现有市场中削减冗余、浪费和复杂性。这可能属实，但远非全貌。断言区块链能从某细分市场削减X成本，预设了该细分市场本身将继续存在。历史告诉我们，技术不仅颠覆行业，还能彻底消灭行业。

现有巨头并未袖手旁观。摩根大通和富达的策略反映了现有巨头采取的不同路径。摩根大通代表了部分领先金融机构在该领域的做法。该行推出了`Quorum`，这是以太坊网络的一个许可制实现。该行将`Quorum`吹捧为公共区块链技术的一个变体，具有强权限和隐私保护。这种对隐私的关注可以理解，因为许多金融交易敏感且要求匿名。例如，摩根大通早在2017年就将Zcash的零知识证明集成到了`Quorum`中。同年，该行还推出了自己的银行间信息网络，该行称其为业界首个由区块链驱动的可扩展P2P网络。^([64](#21_bm005.html#fnr64))

该行在该领域保持活跃。2018年，它展示了`Dromaius`，一个用于区块链交易的原型。当时，摩根大通区块链卓越中心负责人克里斯汀·莫伊表示，该项目可以“简化运营、帮助节省成本，并总体上使此类金融工具的交易或发行体验更加无缝和简化。”^([65](#21_bm005.html#fnr65)) 2019年2月，该行宣布成为首家“成功测试代表法币的数字货币”的美国主要银行。在一份新闻稿中，该行表示：“JPM Coin基于区块链技术，可实现机构客户之间的即时支付转账。”^([66](#21_bm005.html#fnr66))

虽然摩根大通在该领域的努力值得赞赏，但它们仍主要集中于降低现有金融市场的成本、复杂性和摩擦。它们并未拥抱加密资产，且高层管理人员对比特币等仍持怀疑态度。^([67](#21_bm005.html#fnr67))

将摩根大通的做法与富达进行比较。作为美国最负盛名的金融机构之一，富达长期以来一直宣扬加密货币及其底层区块链技术的优势。早在2014年，CEO阿比盖尔·约翰逊就在宣扬比特币的优势，且富达已挖矿比特币数年。或许因为富达是私营公司，它可以专注于长期颠覆而非短期利润。

2018年，这家资产管理巨头推出了富达数字资产公司，一个单独管理的子公司，这并不令人意外。由华尔街资深人士汤姆·杰索普掌舵，富达数字资产正在创建一套产品和服务，以便于购买、出售和存储数字资产。最初，它专注于比特币和其他成熟的加密货币。然而，富达还管理或托管近6万亿美元的客户资产，我们有理由推测，富达数字资产最初涉足加密资产领域，是在培养将现有证券和金融产品迁移到区块链所需的知识和人才。无论哪种方式，通过拥抱原生加密资产行业，富达正为自己构建新业务定位，这很可能会吸引许多新客户和年轻客户。

越来越多的金融公司分为这两类：专注于成本或专注于收入。我们相信，通过专注于后者，金融业现有巨头不仅能生存，还能在数字颠覆的新时代蓬勃发展。

## 重新思考中央银行

中央银行本身正在接受区块链技术带来的威胁与机遇的考验，从加密货币到分布式账本。一方面，加密货币——无论是比特币、天秤币还是其他——要求中央银行直面政府货币垄断可能终结的前景。但区块链也是一种强大工具，政府极可能利用它实现自身目的，这或许也是好事。据纽约大学教授大卫·耶马克和马克斯·拉斯金称，区块链技术的兴起重燃了“关于这些政策明智性的**辩论**，并**引发了对古典货币经济学的兴趣复苏**。”^([68](#21_bm005.html#fnr68))

被提名为欧洲央行（ECB）行长的克里斯蒂娜·拉加德在接受CNBC采访时，精准捕捉了区块链和加密货币的威胁与机遇：“我认为颠覆者的角色，以及任何使用分布式账本技术的事物，无论你称其为加密、资产、货币还是其他。……**这显然正在动摇体制**。”她补充道：“我们不希望动摇体制到失去所需稳定性的地步。”^([69](#21_bm005.html#fnr69))
