## 区块链与 Web 3.0

### 社会、经济和技术挑战

编辑：
马西莫·拉涅达和朱塞佩·德斯特法尼斯

![](img/a0011e82f3a3a41227dc70cd0ddb893a_0_0.png)

区块链已不再仅仅关于比特币或一般的加密货币。相反，它可以被视为一种颠覆性的、革命性的技术，将对我们生活的多个方面产生重大影响。这种技术的革命性可与万维网和互联网所引发的革命相媲美。正如互联网是共享信息的手段一样，区块链技术可以被视为引入下一个层次的方式：共享价值。

*区块链与 Web 3.0*通过在多种学科环境中举办关于新技术的讨论，填补了我们对区块链技术理解的空白。确实，本书解释了这类技术如何具有颠覆性，并对这些颠覆的社会、经济、技术和法律后果进行了比较性审视。这种比较视角在关于区块链的辩论中此前被弱化，进而导致我们对去中心化技术的理解存在不足。

强调区块链技术的出现和 Web 3.0 的兴起所带来的风险与机遇，*区块链与 Web 3.0*将吸引对社会学与社会政策、赛博文化、新媒体以及隐私和数据保护等领域感兴趣的研究人员和学者。
