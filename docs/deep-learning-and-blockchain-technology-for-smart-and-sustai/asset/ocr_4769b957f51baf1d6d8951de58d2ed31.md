The software-based security solution is achieved by Tinysec [17]. It implements authentication and encryption techniques in the link layer. A group key is generated to encrypt the data packets, and the message authentication code is calculated. The disadvantage of Tinysec is that it does not protect against node capture. Some applications require on-chip hardware encryption instead of software. The hardware encryption is implemented using Chip Con 2420 ZigBee compliant RF Transceiver. This chip supports CBC-MAC authentication, CCM encryption plus authentication and counter mode encryption and decryption. The CC2420 executes IEEE 802.15.4 security protocols with Advanced Encryption Standard using 128-bit keys.
