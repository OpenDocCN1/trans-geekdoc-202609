Figure 11.1: The proposed system’s main flowchart depicts the operation of the smart wheelchair, initiated by pressing the start button. Upon activation, the system engages all on-board sensors, each with its predefined threshold. Utilizing accelerometer, gyroscope, and ESP32 dev Module, the system monitors for values surpassing the thresholds, triggering the fall detection mechanism. Upon detection, the user can verify the fall’s legitimacy; if deemed false, the snooze button deactivates the alert. However, in case of a genuine fall, failure to press snooze within 5 seconds activates the buzzer, signalling nearby assistance. Simultaneously, the GSM module initiates a call for aid. Registered individuals can access the wheelchair’s fall detection via the IoT platform, facilitating prompt assistance.
