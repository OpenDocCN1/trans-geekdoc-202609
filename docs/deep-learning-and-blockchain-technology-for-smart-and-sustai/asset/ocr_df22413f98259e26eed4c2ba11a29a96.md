The decision-making process advances iteratively, partitioning the dataset into smaller subsets at each node until a termination condition is satisfied [24]. This criterion could include reaching a maximum depth for the tree, having a smallest sample size in each leaf node, or when additional division is unnecessary, it significantly improves the classification accuracy. When this decision tree is constructed for classification, each leaf node is associated with a class label. During prediction, an input sample traverses a decision tree from the root node to a leaf node according to its feature values. The class label associated with the leaf node reached by the sample becomes the class that will be predicted for that sample [25]. This algorithm is known for simplicity, interpretability, and capacity to manage both numerical and categorical data. They can capture intricate decision boundaries and interactions among features, rendering them applicable for diverse purposes, including medical diagnosis, fraud detection, and customer segmentation. Yet, decision trees are susceptible to overfitting, especially when they grow deep, which can be mitigated through techniques like pruning or using ensemble methods such as Random Forests.
