# 10.4.5 Accuracy

Accuracy (ACC) is the percentage of overall perfect forecasts to the entire test dataset. It can also be expressed as 1- ERR. There is a 1.0 maximum accuracy and a 0.0 minimum accuracy.

```
ACC = \frac{TP+TN}{TP+TN+FN+FP} \times 100
```

+   ■ True positive (TP): Predicted positive, but the right answer is positive.
+   ■ False positive (FP): Predicted positive, but the right answer is negative.
+   ■ True negative (TN): Predicted negative, but the right answer is positive.
+   ■ False negative (FN): Predicted negative, but the right answer is negative (Figure 10.8).
