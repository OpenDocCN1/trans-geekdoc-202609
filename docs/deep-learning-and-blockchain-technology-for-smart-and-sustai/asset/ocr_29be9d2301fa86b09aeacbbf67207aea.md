# 19.1.2 Literature Survey

Sunitha et al., in their paper, cover the elucidation for the deaf-mute communication interpreter [7]. As of now for the deaf-mute communication, there are two methods: one is physically wearable hearing aids and the other is learning system through internet. In wearable device, the user wears a glove with keypad with a micro-controller or a touch screen [8]. But in this method, an external device is utilized for communication between the deaf/non-deaf people. In learning systems, the usage of an extra device can be eliminated. Learning system based on online has five subdivided methods: SLIM module, TESSA, WI-See Technology, SWI_PELE System, and Web-Sign Technology [9]. Anand et al. devised an ISLR system that uses a pattern recognition and classification with the use of Discrete Wavelet Transform (DWT), and the nearest neighbor classifier recognizes the hand gesture with a 92.23% accuracy. Another model by Mandeep Kaur Ahuja and Amardeep Singh uses the skin color and template matching for recognizing the hand signs [1].
