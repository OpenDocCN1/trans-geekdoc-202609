+   3. **Streams**: Streams are the data channels that connect nodes across a Mediapipe graph. Streams transport the input and output data across nodes. The input data types can be an image, a video file, audio samples, or even numerical values.

+   4. **Calculators**: The implementations of specific processing operations within the nodes are known as calculators. The algorithms and the computations that are to be carried out on an input to achieve a desired output are elucidated by the calculators.

+   5. **Framework**: Mediapipe framework handles the construction, management, and execution of the graphs. The tools for building, running, and visualizing graphs and APIs are provided by the framework. The optimized functioning and parallel execution of the nodes are taken care by the framework.
