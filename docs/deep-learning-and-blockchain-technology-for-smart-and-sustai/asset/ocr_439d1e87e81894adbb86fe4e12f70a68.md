# Figure 11.2 Flowchart for accelerometer with a gyroscope sensor.

Figure 11.3: The wheelchair fall detection system with IoT comprises two main sections: the fall detection and monitoring system, and the graphical user interface (GUI) section. The modified overall block diagram depicts two inputs: gyroscope sensor and a secure button. These sensors gather data from the wheelchair and transmit it to the ESP32 module. The GPS module captures the wheelchair’s the speed and orientations, which are also sent to the ESP32. The secure button serves to deactivate the buzzer when triggered. Data from all sensors are analyzed and relayed from the ESP32 module to the Blynk mobile application.
