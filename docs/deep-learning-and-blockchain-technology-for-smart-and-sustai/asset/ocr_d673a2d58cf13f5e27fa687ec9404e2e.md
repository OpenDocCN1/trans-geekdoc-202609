Mean Absolute Error (MAE): MAE = \frac{1}{N_1} \sum_{i=1}^{N_1} |yy_i - yy'_i| \quad (15.1)
where
N_1 is the number of data points
yy_i is the true values
yy'_i is the prediction values

Mean Squared Error (MSE): MSE = \frac{1}{N_1} \sum_{i=1}^{N_1} (yy_i - yy'_i)^2 \quad (15.2)
where
N_1 is the number of data points
yy_i is the observed values
yy'_i is the predicted values

Root Mean Squared Error (RMSE): RMSE = \sqrt{\frac{\sum_{i=1}^{NN} (x_i - y_i)^2}{NN}} \quad (15.3)
where
x_1, x_2, x_3, ..., x_n are observed values
y_1, y_2, y_3, ..., y_n are predictions values
NN is the number of observations

R-squared (R^2)Score: R^2 = 1 - \frac{RSSr}{TSSr} \quad (15.4)
where
RSSr is the sum of squares of residuals
TSSr is the total sum of squares
