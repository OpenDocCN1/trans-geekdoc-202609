# Figure 11.1 Block diagram of proposed system.

Figure 11.2: The flowchart for the accelerometer with a gyroscope sensor outlines its role in detecting wheelchair movement and stability. By monitoring speed and position, deviations from set thresholds signal potential falls. If detected, the system prompts an alarm. Users can dismiss false alarms by pressing the snooze button within 5 seconds. Failure to do so activates the buzzer, alerting nearby individuals. Simultaneously, the GSM module initiates a call for assistance. Through the IoT platform, registered individuals can promptly get the wheelchair fall alert and provide aid.
