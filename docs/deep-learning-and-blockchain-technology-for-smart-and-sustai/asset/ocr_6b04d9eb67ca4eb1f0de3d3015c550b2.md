# 5.1.1 Key Features of Blockchain

+   1. Security: Data on blockchain is encrypted using cryptographic techniques, making transactions immune to fraud and illegal access.
+   2. Transparency: Because blockchain technology is transparent, all users can see and validate transactions, which encourages responsibility and confidence.
+   3. Decentralization: Peer-to-peer transactions are made possible by blockchain, which eliminates the need for middlemen and lowers costs while boosting efficiency.
+   4. Immutability: Data cannot be altered or removed once it is entered into the blockchain, making it a trustworthy and auditable record of transactions.
+   5. Interoperability: Blockchain technology possesses the capability to function in conjunction with many platforms and systems, enabling smooth data transfer and network integration [2].
