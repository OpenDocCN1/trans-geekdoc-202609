# 18.3 Brute Force Algorithm

In the context of machine learning, the Brute Force algorithm refers to an approach where a model systematically tries all possible solutions to find the best one. This method exhaustively explores every potential solution without considering any specific strategies to optimize the search process. For example, in the context of hyperparameter tuning, a brute force way of approaching would involve trying out every combinations of hyperparameters within a specified range, without considering any prior knowledge about which hyperparameters are likely to be more influential or which values are more promising.

While brute force algorithms guarantee to find the optimal solution with given enough time and computational resources, they are often not adjustable due to their higher time complexity, especially when dealing with larger datasets or complex models. As a result, more efficient techniques such as grid search and random search or more advanced optimization algorithms like genetic algorithms or Bayesian optimization are commonly used in practice to search for optimal solutions more effectively.

In this chapter, this algorithm has been used to find the best solution among all the possible solutions by combining several weather patterns of different years for a particular location. By using this, the accuracy of getting the profit percentage increases as different patterns are analyzed for the same location at the same time.
