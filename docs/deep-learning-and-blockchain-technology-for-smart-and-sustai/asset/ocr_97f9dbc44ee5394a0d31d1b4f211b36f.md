# 15.3.2 LSTM

An RNN architecture called LSTM models was created to overcome the shortcomings of conventional RNNs in identifying long-range dependencies in sequential data. In contrast, conventional RNNs have trouble during training with the vanishing gradient issue. Because of their distinctive design, LSTMs are ideally suited for time series prediction because they can efficiently identify temporal patterns and correlations in sequential data.

**Data Preprocessing:** When preparing data for training a LSTM model, there are usually several preprocessing steps to ensure that the data is in an appropriate format so that the model can learn effectively. Here is a step-by-step description of the preprocessing methods used on the dataset.

**Random Sampling Imputation:** This method substitutes observed values from the same feature that are randomly sampled for missing values. It preserves the variable’s distribution and is helpful when data is absent arbitrarily. The mean of the corresponding feature is used to fill in missing values in numerical features. Although the procedure is straightforward, bias may be introduced if data is not missing randomly.

**Outlier Detection and Removal:** The distribution of continuous data can be seen and outliers can be found using boxplots. Observations that lie above the third quartile plus 1.5 times the IQR or below the first quartile minus 1.5 times the IQR are considered outliers.
