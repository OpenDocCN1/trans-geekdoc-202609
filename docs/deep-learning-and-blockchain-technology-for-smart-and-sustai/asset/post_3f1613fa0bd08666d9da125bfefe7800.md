
**Feature Scaling**: This technique involves scaling characteristics to a comparable scale. Because it uses the median and interquartile range rather than the mean and standard deviation, it is resistant to outliers. It can thus be applied to data that contains outliers.

**One-Hot Encoding**: Using a binary vector representation, each category in a set of categorical variables is transformed into a binary feature (0 or 1). This is helpful for algorithms (like linear regression) that may understand categories as ordered values but are unable to operate directly with categorical data.

**Train–Test Split**: Training and testing sets make up the dataset. The model is trained on the training set, and its performance is assessed on the testing set. The trained model’s ability to generalize to new data is estimated using this.
