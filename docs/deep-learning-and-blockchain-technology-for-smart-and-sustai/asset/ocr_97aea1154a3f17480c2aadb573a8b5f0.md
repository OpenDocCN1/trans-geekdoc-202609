# 19.1.8 KERAS

KERAS is a high-level neural network API written using python. It gives a user-friendly and less complex framework to produce a deep learning model. It abstracts the lower level involved when in low-level deep learning frameworks like Tenser-flow and CNTK. KERAS provides built-in layers in a wide range such as dense, convolutional, recurrent, pooling, normalization, and dropout layers. It provides functions to compile the modules with optimization algorithms and includes various training techniques like mini-batch gradient descent and stochastic gradient descent. It also consists of various pre-trained deep learning models.

# 19.1.9 Workflow with KERAS

**Model Definition**: The starting step is to define a model; it may be a simple sequential model or a more complex model using functional APIs.

**Model Compilation**: The defined model should be compiled by specifying the optimizers, loss function, and the evaluation metrics.

**Model Training**: After choosing the required model and compiling it, the model should be trained by giving the training datasets, and the forward and backward data propagation is done by the KERAS framework itself during training.

**Model Evaluation**: The trained model can be evaluated by the returned loss function and the evaluation metrics specified for the dataset.

**Model Prediction**: After evaluation, the model can now be used to predict the output for the new datasets for classification or regression tasks.
