In 2018, the authors suggested using SVMs to classify spam emails. The email dataset is classified using a nonlinear SVM classifier. This methodology took into account emails from Gmail inboxes and the SpamAssassin public dataset, using both linear and Gaussian kernel functions. When compared to the Gaussian kernel function, it is discovered that the linear kernel yields the maximum level of accuracy for the test dataset. Using these two kernel functions to categorise the test dataset takes the same amount of time [6].

Using Natural Language characteristics, an anti-spam filter comprising five classifiers has been suggested in 2015 and tested on the Enron-spam and Ling spam datasets. To create binary classifiers, the real valued and natural language properties are taken out of the email content. Using five different learning methods, the classifiers are investigated and assessed using the non-personalized email datasets from CSDMC2010, SpamAssassin, Enron-Spam, and LingSpam. In this work, the relevance of the traits is measured using the BORUTA algorithm, which is also used to generate spam attribute scores. This study finds that ADABOOSTM1 and BAGGING outperform Random Forest and suggests that readability attributes are less significant than Natural Language features [7].

Fruit fly optimisation and the clustered negative selection method were proposed by the authors in 2017 for the detection of email spam. To increase classification accuracy, the fruit fly optimisation and K-means algorithms are coupled with the Negative Selection algorithm [8].

The authors had put forward an improved methodology in 2020 for email classification based on semantic features. This approach performed a semantic analysis of the email dataset’s text properties. There are two stages to this semantic-based text analysis. All of the emails are categorised into distinct domains at the first level, such as finance, education, and health. In order to identify spam emails, the second level combines the physically defined and often extracted semantic aspects of emails. This domain classification aids in offering a subject for the spam email description. This research uses the Naive Bayes, Decision Tree, Random Forest, Ada Boost, and K closest neighbour algorithms to categorise emails as spam or ham.
