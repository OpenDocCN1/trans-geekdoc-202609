# # 19.1.10 Data Collection

Data collection refers to the steps involved in acquiring the required data to help the system train by feeding it with the dataset so that it can identify and detect the trained object if it's found in an image or a video source [15]. The acquisition of data is so important since the application is trained by using these data so the acquired data should be clear to achieve a high accuracy in the object prediction. A large quantity of similar objects should be provided to the system for making the system accurate in the object detection. Regarding this chapter, we created a dataset with the required signs of several words [2]. After collecting and forming the dataset, we need to train the system.
