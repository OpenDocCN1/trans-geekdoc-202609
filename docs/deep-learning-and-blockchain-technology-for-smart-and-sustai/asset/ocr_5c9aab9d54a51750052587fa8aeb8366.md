# 10.3.1 Convolutional Neural Network

A CNN is a type of feed-forward neural network that possesses an understanding of topological information within the input image. Its functionality involves utilizing a classifier to extract features from the raw image and subsequently classify them. CNNs exhibit insensitivity to distortions or basic geometric alterations such as translation, scaling, rotation, or squeezing. To achieve partial shift, scale, and distortion invariance, CNNs employ three architectural strategies: local receptive fields, shared weights, and spatial or temporal sub-sampling. Similar to the training process of a conventional neural network, CNNs utilize backpropagation for network education. The Convolutional layer specifically plays a crucial role in extracting local receptive fields from the underlying layer. Feature map, which are planes of neurons responsible for identifying a certain feature and retrieving various forms of data, makes up a Convolutional layer local data. A 55% convolution kernel connects 25 in a network and inputs the local receptive field from the preceding layer into a 55% area.

Neuron can extract fundamental visual elements like edges using local receptive fields. Neurons in different parts of the brain may use the same connection structure and weights to extract the same visual feature. The result is a feature map, which is a representation of collection of neurons. This is equivalent to using a tiny kernel to convolution the input image.
