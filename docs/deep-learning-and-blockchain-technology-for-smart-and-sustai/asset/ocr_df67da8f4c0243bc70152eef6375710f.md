# **Figure 20.6 Precision.**

A period stands for one pass via the whole training dataset. Precision is a statistic suggesting the percentage of appropriate forecasts made by the version.
Monitoring Accuracy over epochs helps track the model's learning progress.
Ideally, you'd expect the Accuracy to increase as the model trains on more data.

```
Accuracy = \frac{TP+TN}{TP+TN+FP+FN} \quad Precision = \frac{TP}{TP+FP} \quad Recall = \frac{TP}{TP+FN}
F-measure = \frac{2*Precision*Recall}{Precision+Recall}
```
