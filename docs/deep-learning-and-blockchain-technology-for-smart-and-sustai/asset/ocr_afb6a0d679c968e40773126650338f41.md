# 18.4 Linear Regression

Linear regression is a statistical method used to model the relationship between one or more independent variables and a continuous dependent variable. In a simpler way, using linear regression, we can find an unknown value using a known value. It assumes a linear relationship between the variables, where changes in the independent variable will also affect the dependent variable. If a value of known value is changed, it will result in the change in the unknown value also. Linear regression is widely used in machine learning for understanding the relationship between the data in a dataset. It serves as a foundation technique for more complex regression models and machine learning algorithms. In this chapter, there will be multiple historical data as weather patterns for the same place but for various different years. In such situation, linear regression comes into action. The multiple linear regression algorithm identifies patterns among data and processes them as per input conditions [5]. This will help us to find the best feasible crops according to the weather pattern in a particular location [5]. This predictive capability enables farmers and policymakers to make informed decision about crop selection, planting schedules, and resource allocation, ultimately maximizing the agricultural output and mitigating risk. Moreover, the insights gained from linear regression analyses can inform the development of more complicated machine learning models tailored to specific agricultural contexts, further enhancing yield prediction accuracy and agricultural sustainability.
