The lightweight cryptography algorithms designed for medical applications are Advanced Encryption Standard, Camelia, Leak extraction, Light Encryption Device, International Data Encryption Algorithm, rabbit, RC5, Salsa20, Simon and Speck [20,21]. The features like energy consumed by the devices, memory and execution time determine the choice algorithm. The fast execution of algorithm minimizes the energy consumption and maximizes the battery life.

The various characteristics of lightweight cryptographic algorithms are listed in Table 14.3.

# Table 14.3 Characteristics of Lightweight Encryption Algorithms

| Algorithm | Key Size (Bits) | Stream/Block Cipher | Functions | Implementation Strategy |
|---|---|---|---|---|
| Advanced encryption standard | 128 | Block cipher | Substitute bytes shift rows Mix columns Add round key | Software |
| Leak extraction | 128,256 | Stream cipher | Setup phase Initial vector Secret state | Software |
| Camelia | 192,128,256 | Block cipher | XOR | Hardware and software |
| Light encryption device | 64,128,80 | Block cipher | Active S-box XOR | Hardware |
| International data encryption algorithm | 128 | Block cipher | Simple arithmetic and XOR operations | Software |
| Rabbit | 128 | Stream cipher | Shifting | Software |
