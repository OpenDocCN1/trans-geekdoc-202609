When dealing with the target item, which is the pollutant, a ML-based multiple imputation technique (Narasimhan and Vanitha, 2023) is used to approximate the missing data using an imputation function that employs the mean value technique.

There are many missing values in the gathered data, and there are also extreme values that differ from other data observations. This could be a sign of experiment flaws, measurement variability, or uniqueness. The missing data causes noise to be added to the dataset, which negatively affects the model's predictive power. The missing data leaves gaps that are filled in using linear interpolation. It is a method for producing new data points that fall inside a predetermined range of an already-existing discrete bunch of data points.

The outliers are treated using the Inter-Quartile Range (IQR) method. It is a quantitative metric used to characterize data distribution. The process involves determining the data's 25th and 75th percentiles as depicted in the following equation:

```
IQR = 75th percentile – 25th percentile (13.1)
```

Upper and lower bounds are computed to handle outliers. The supplied information is replaced by the higher limit if it exceeds the upper limit, and the given information is replaced by the lower limit if it falls below the lower limit, as indicated in Equations (13.2) and (13.3).
