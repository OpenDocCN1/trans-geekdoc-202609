### 18.2 Literature Survey

In the realm of agriculture, where uncertainties abound, reliable and timely forecasts are indispensable for informed planning and decision-making [4]. They excel in identifying correlated patterns between input data and target values through training, enabling accurate predictions for new datasets.

### 18.3 Brute Force Algorithm

In the context of machine learning, the Brute Force algorithm refers to an approach where a model systematically tries all possible solutions to find the best one. This method exhaustively explores every potential solution without considering any specific strategies to optimize the search process. For example, in the context of hyperparameter tuning, a brute force way of approaching would involve trying out every combinations of hyperparameters within a specified range, without considering any prior knowledge about which hyperparameters are likely to be more influential or which values are more promising.

While brute force algorithms guarantee to find the optimal solution with given enough time and computational resources, they are often not adjustable due to their higher time complexity, especially when dealing with larger datasets or complex models. As a result, more efficient techniques such as grid search and random search or more advanced optimization algorithms like genetic algorithms or Bayesian optimization are commonly used in practice to search for optimal solutions more effectively.

In this chapter, this algorithm has been used to find the best solution among all the possible solutions by combining several weather patterns of different years for a particular location. By using this, the accuracy of getting the profit percentage increases as different patterns are analyzed for the same location at the same time.

In the agricultural domain, the application of the Brute Force algorithm offers a systematic approach to optimize crop selection and yield prediction by exhaustively exploring all possible combinations of weather patterns for a given location across different years. By aggregating and analyzing diverse historical weather data, this method enables the identification of optimal cropping strategies that maximize profitability and mitigate risks associated with changing environmental conditions. While Brute Force algorithms guarantee the discovery of the most optimal solution, they often pose computational challenges, particularly when dealing with large datasets or complex models. Despite these limitations, the utilization of Brute Force algorithms in conjunction with advanced machine learning techniques holds promise for revolutionizing agricultural decision-making processes and enhancing the resilience of farming systems. By harnessing the strength of computational brute force, stakeholders can unlock the valuable insights into crop performance, paving the way for more sustainable and productive agricultural practices.

### 18.4 Linear Regression

Linear regression is a statistical method used to model the relationship between one or more independent variables and a continuous dependent variable. In a simpler way, using linear regression, we can find an unknown value using a known value. It assumes a linear relationship between the variables, where changes in the independent variable will also affect the dependent variable. If a value of known value is changed, it will result in the change in the unknown value also. Linear regression is widely used in machine learning for understanding the relationship between the data in a dataset. It serves as a foundation technique for more complex regression models and machine learning algorithms. In this chapter, there will be multiple historical data as weather patterns for the same place but for various different years. In such situation, linear regression comes into action. The multiple linear regression algorithm identifies patterns among data and processes them as per input conditions [5]. This will help us to find the best feasible crops according to the weather pattern in a particular location [5]. This predictive capability enables farmers and policymakers to make informed decision about crop selection, planting schedules, and resource allocation, ultimately maximizing the agricultural output and mitigating risk. Moreover, the insights gained from linear regression analyses can inform the development of more complicated machine learning models tailored to specific agricultural contexts, further enhancing yield prediction accuracy and agricultural sustainability.
