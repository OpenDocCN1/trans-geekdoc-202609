Each layer in cyber-physical system is affected by attacks. The possibility of attacks in the perception layer is port scan, passive replay and eavesdropping. To secure information at this layer, end-to-end encryption is required. The measures applied to this layer are source authentication, data protection and secure data/systems. Strong encryption algorithms are required to provide security for transmission and application layer. The security solutions are categorized, as shown in Figure 14.4.
