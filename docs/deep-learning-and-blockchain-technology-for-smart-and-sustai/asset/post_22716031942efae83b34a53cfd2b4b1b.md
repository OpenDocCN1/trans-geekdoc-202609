## 19.1.5 Convolutional Neural Networks

CNNs serve as a pivotal technology, enabling the inspection of visual inputs and classification of hand signs to assist in communication for people having hearing and speech impairments. CNNs are structured in a grid topology, allowing them to efficiently process and analyze visual data [22]. Within our project, CNNs classify input data, such as hand signs, by transforming them into spectrograms. This transformation involves breaking down the input into n number of layers, with each layer undergoing filtering using weights positioned at specific locations [23]. Furthermore, pooling layers play a crucial role in minimizing input data. Unlike CNN layers that apply filters with weights, pooling layers utilize aggregation functions. These functions either select the maximum pixel value within a receptive field to produce the output array or calculate the average value. This process helps streamline the data while retaining essential features for classification. Following the processing by CNN and pooling layers, the Fully Connected Layer aggregates the processed input. This layer is equipped with fully connected weights obtained from the preceding layers. It utilizes a softmax activation function to classify inputs, assigning probabilities ranging from 0 to 1 to different classes [1]. In the context of smart cities, the application of CNNs in our project holds significant potential. By accurately classifying hand signs, our system facilitates real-time communication for people having hearing and speech impairments, enhancing inclusivity and accessibility within urban environments. Moreover, by leveraging advanced neural network architectures like CNNs, our project contributes to the development of smarter, more responsive urban systems, fostering equitable access to essential services and communication tools for all residents.

## 19.1.6 Media Pipe

Media Pipe is an open-source framework of google that enables the user to work with real-time multimedia processing pipelines. This framework is very useful in building complex pipelines by connecting predefined components known as media pipe graphs [24]. The combination of these graphs is utilized for the speech, facial, and gesture recognitions. The media pipe offers features like graphs (The Components), nodes (The Process involved), and streams (input data) [25]. Its wide range of applications include object detection and tracking and facial recognition.

### Key Components of Mediapipe:

- 1. **Graphs**: Mediapipe graph is implemented using a Directed Acyclic Graph (DAG), which represents the processing pipeline. The graph consists of a collection of nodes that perform operations on an input and produce an output data. The connection of the nodes can give the flow of data through the system.

- 2. **Nodes**: These nodes are the building blocks of the Mediapipe graph. Every single node represents an input operation such as video decoding, image filtering, and feature extraction. Nodes can consume and produce data by utilizing the input and output streams.

- 3. **Streams**: Streams are the data channels that connect nodes across a Mediapipe graph. Streams transport the input and output data across nodes. The input data types can be an image, a video file, audio samples, or even numerical values.

- 4. **Calculators**: The implementations of specific processing operations within the nodes are known as calculators. The algorithms and the computations that are to be carried out on an input to achieve a desired output are elucidated by the calculators.

- 5. **Framework**: Mediapipe framework handles the construction, management, and execution of the graphs. The tools for building, running, and visualizing graphs and APIs are provided by the framework. The optimized functioning and parallel execution of the nodes are taken care by the framework.

## 19.1.7 CVZONE

CVZONE is an open-source library that dispenses various modules to computer vision functions. It is built over OpenCV, a library that aims to provide a high-level computer vision function. CVZONE provides various modules for covering the key aspects of computer vision [20]. Face detection and facial landmark detection detect faces and extract landmarks like position of eyes, Gesture recognition recognizes the gestures with the help of pre-loaded dataset useful in sign language recognition, and modules track a particular object in a video stream, estimate the positions of the human body, and function to replace the backgrounds in a video or an image.

CVZONE offers set of modules, which are as follows:

- 1. **Face Detection and Facial Landmark Detection**: CVZONE provides us with the functions that can be utilized for face and face landmark detections. This module allows us to detect the landmarks in a face like the position of the eyes, color of the eyes, and the position of the mouth and nose. This also helps us in detecting the face in images or videos.

- 2. **Gesture Recognition**: CVZONE provides us with a module that can be utilized to detect the gestures that are pre-trained from images and videos. This is useful in creating working models that are based on hand gestures or sign language.

- 3. **Pose Estimation**: This helps us to roughly calculate the position and orientation of the object in images and videos. This can be utilized in the applications that require motion tracking, augmented reality, and so on.

- 4. **Object Tracking**: The algorithms such as MedianFlow, MOSSE, and CSRT are utilized for robust object tracking across frames. These help us to track a specific object in the video streams.

- 5. **Virtual Background**: CVZONE can be used to modify the background of an existing image or video with a new background. This can be helpful in the case of augmented reality and video conferencing applications.

- 6. **Utilities**: To simply perform common computer vision tasks, CVZONE provides us with utility functions and classes. Using this, we can resize images, crop images, blend images, and more. This can be utilized to create custom video stream handlers and processing pipelines.

## 19.1.8 KERAS

KERAS is a high-level neural network API written using python. It gives a user-friendly and less complex framework to produce a deep learning model. It abstracts the lower level involved when in low-level deep learning frameworks like TensorFlow and CNTK. KERAS provides built-in layers in a wide range such as dense, convolutional, recurrent, pooling, normalization, and dropout layers. It provides functions to compile the modules with optimization algorithms and includes various training techniques like mini-batch gradient descent and stochastic gradient descent. It also consists of various pre-trained deep learning models.

## 19.1.9 Workflow with KERAS

**Model Definition**: The starting step is to define a model; it may be a simple sequential model or a more complex model using functional APIs.

**Model Compilation**: The defined model should be compiled by specifying the optimizers, loss function, and the evaluation metrics.

**Model Training**: After choosing the required model and compiling it, the model should be trained by giving the training datasets, and the forward and backward data propagation is done by the KERAS framework itself during training.

**Model Evaluation**: The trained model can be evaluated by the returned loss function and the evaluation metrics specified for the dataset.

**Model Prediction**: After evaluation, the model can now be used to predict the output for the new datasets for classification or regression tasks.
