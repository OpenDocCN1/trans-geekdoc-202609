
如果你这样做，就能使用组策略中最不常用的功能之一——服务质量 (QoS) 策略，它可以对数据包进行优先级排序。除此之外，你还可以使用 OneDrive 来指定最大上传带宽。关键的策略设置名为 **Set the maximum upload bandwidth that OneDrive.exe uses**。在用户端的组策略中，可参见 [Figure 7.25](#c07.xhtml#figure7-25)；在计算机端，可参见 [Figure 7.27](#c07.xhtml#figure7-27)。对于 Intune，可参见 [Figure 7.23](#c07.xhtml#figure7-23)。

由于在组策略中，此设置既可配置在用户端也可配置在计算机端，我建议使用计算机端。这将影响计算机上的每个 OneDrive 实例，从而保持配置更加一致。

启用后，默认值为 70%，意味着 70% 的带宽将用于将 `Desktop`、`Documents` 和 `Pictures` 文件夹中的 OneDrive 文件上传至云端。

请记住，你不必立即全盘部署 KFM（已知文件夹移动）。你可以使用组策略并将作用域限定在某些计算机上，待你准备就绪且确信其按预期工作后，再逐步推广到更多计算机。

#### 设置 KFM 策略（组策略和 MDM）

在你为带宽使用设定好基础并分发了那些策略（通过组策略或 MDM）后，你就可以指定 KFM 模式了。共有两种模式：Prompted（提示式）或 Silent（静默式）。

Prompted 意味着用户会看到你之前在 [Figure 7.33](#c07.xhtml#figure7-33) 中看到的内容。每次 OneDrive 启动时，他们都会收到提议，并可以选择开始或忽略。

Silent 顾名思义，无提示，直接执行。

这里我们将了解如何对本地机器使用组策略执行此操作，以及如何对纯云机器使用 MDM 执行此操作。

##### 使用组策略执行已知文件夹移动

提示式 KFM 的组策略设置名为 **Prompt users to move Windows known folders to OneDrive**。该设置本身可见于 [Figure 7.34](#c07.xhtml#figure7-34)。要使其生效，你需要填入我们在本章开头获取的租户 ID。

### 文件还原（针对恶意软件或用户错误）

恶意软件很烦人。加密勒索软件更甚。

一旦发作，它就会疯狂地尝试读取并加密用户有权访问的每一个文件（以及驱动器盘符等）。但是，通过将用户文件保护在 OneDrive 中，你获得了使用 OneDrive 执行时间点还原的优势。

用户需前往其 OneDrive 位置，这与我们之前探讨的 SharePoint URL 略有不同。用户的个人 OneDrive 位置类似于 `https://fabrikam1000-my.SharePoint.com/`。登录后，他们只需点击齿轮图标，点击“Restore your OneDrive”（还原你的 OneDrive），如 [Figure 7.39](#c07.xhtml#figure7-39) 所示，然后按提示操作。

![Figure 7.39 How a user can manually restore their own OneDrive](images/c07f039.jpg)

[**Figure 7.39**](#c07.xhtml#figureanchor7-39) How a user can manually restore their own OneDrive

然后用户可以选择一天，比如 Yesterday（昨天）（如 [Figure 7.40](#c07.xhtml#figure7-40) 所示）或具体的几天前。然后……搞定。即时还原。

![Figure 7.40 Pick a day ago or a custom date to restore to.](images/c07f040.jpg)
