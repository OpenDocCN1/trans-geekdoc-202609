

## Windows Configuration Designer (WCD)

### 获取 WCD

*   可在 Windows 应用商店作为应用下载

本书将使用 Windows 应用商店应用。原因？它始终保持最新，且安装更加容易。

那为什么还需要 ADK 版本？仅当你需要回退并教导旧版机器（如 Windows 1803、1709、1703 或类似版本）如何重新配置时。

如果使用 Windows 应用商店版 WCD，它始终是最新的，与最新版 Windows 保持同步。你可以在管理工作站上获取 WCD。只需前往 Windows 应用商店搜索并获取，如[图 8.1](#c08.xhtml#figure8-1)所示。

### WCD 能做什么？（以及不该做什么？）

在此场景中，Jack 获得一台新 Windows 机器，必须是最新版 Windows 才能配合 Windows 应用商店版 WCD 进行后续操作。如果 Jack 拿到的是旧版 Windows 机器，必须先通过 Windows 自动更新升级到最新版，然后 Windows 应用商店版 WCD 才能按你的意愿重新配置它。

那么之后 WCD 能做什么？以下是主要优势：

*   安装 Win32 应用程序
*   将设备注册到 Active Directory
*   加入 Azure AD
*   添加证书
*   更改产品版本
*   指定 Wi-Fi 参数
*   配置邮件配置文件
*   运行 PowerShell 脚本
*   配置“始终开启 VPN”客户端
*   移除 OEM 预装软件

你能做镜像部署过程中的*所有*事情吗？不，不能做所有事，但能做很多——通常是最重要的那些事。

我不建议尝试配置任何你*同时*打算通过 MDM 管理的内容，如策略或证书。但我可以预见这样一个场景：也许你需要立即预配某些项目以确保它们即刻就绪，或者这些项目专属于这些机器，不会通过 MDM 下发。

这正是 WCD 的意义所在。

### WCD 示例

本示例将使用 WCD 安装 Jack 急需的应用程序，并移除预装软件（也被称为更“政治正确”的名称：*预装软件*）。

首先运行 WCD 并选择“预配桌面设备”，即左上角的第一个磁贴，如[图 8.2](#c08.xhtml#figure8-2)所示。正如你所见，WCD 还能做很多其他事，如预配 HoloLens 和 Surface Hub，但我们暂且跳过那些。

![图 8.2 WCD 主界面，支持执行预配任务](images/c08f002.jpg)

**[图 8.2](#c08.xhtml#figureanchor8-2)** WCD 主界面，支持执行预配任务

在[图 8.3](#c08.xhtml#figure8-3)中，你将看到在最终生成预配文件（即 `.PPKG` 文件）前需执行的步骤。我将演示其中部分步骤。另请注意页面底部（未显示）有“切换到高级编辑器”选项，稍后我们会讨论。

![图 8.3 “预配桌面设备”的 WCD 导航](images/c08f003.jpg)

让我们简要逐一浏览各主要页面。

#### 设置设备页面

在“设置设备”页面，你将看到[图 8.4](#c08.xhtml#figure8-4)所示内容。可指定机器接受包后的设备名称。格式可能类似 `Fabrikam%RAND:4%`，生成的机器名如 `Fabrikam0001`。

![图 8.4 WCD 的“设置设备”页面](images/c08f004.jpg)

**[图 8.4](#c08.xhtml#figureanchor8-4)** WCD 的“设置设备”页面

此外，我最喜欢的功能就在这页：“移除预装软件”开关，它几乎能清除盒子里的所有内容并执行 Windows 重置。换言之，它会自动清除预装软件和垃圾，让系统焕然一新！虽增加些时间，但谁不想从最干净的机器开始呢？

本页还有个功能（示例未用）：可直接输入企业产品密钥。若机器初始为 Windows 10 Pro，而你输入 Enterprise 或 Business 密钥，则……搞定。完成后机器将重生为该类型。这太神奇了。

#### 设置网络页面

若目标机有 Wi-Fi，可预填网络 SSID 以便连接。我未端到端测试，但看来仅支持开放网络和 WPA2 个人版密码类型。

也可将其关闭，确保必须使用有线以太网继续。

#### 账户管理页面

账户管理页面见[图 8.5](#c08.xhtml#figure8-5)。在此选择机器是加入本地 Active Directory（需 VPN 连接）、注册到 Azure AD（我们将设置此项），还是仅设本地管理员。我选择“注册到 Azure AD”。还需设置批量令牌过期日期，即允许该包注册机器的时长。可设 30 或 90 天，甚至未来 10 年，随你定。据我所知，一旦注册令牌烘焙进 `.PPKG` 文件，即无法撤销。但每次创建令牌都会在 AAD 中创建对应账户。若能识别出创建该令牌的账户，删除该账户即可有效停用令牌。

[图 8.5](#c08.xhtml#figure8-5)展示了提供 Frank Rizzo 的 Azure 管理员凭据并设置未来日期后的成功结果。

![图 8.5 提供凭据并创建批量令牌的结果](images/c08f005.jpg)

**[图 8.5](#c08.xhtml#figureanchor8-5)** 提供凭据并创建批量令牌的结果

#### 添加应用程序页面

“添加应用程序”页面见[图 8.6](#c08.xhtml#figure8-6)。若某包不会通过 MDM 自动部署，此页很有用。本例中我添加 PuTTY（`www.putty.org`），一种常见网络应用。选中后，命令行参数已自动填好，贴心设计。

![图 8.6 通过 WCD 添加应用程序](images/c08f006.jpg)

**[图 8.6](#c08.xhtml#figureanchor8-6)** 通过 WCD 添加应用程序

注意实际应用程序本身嵌入在 `.PPKG` 文件中。添加的应用越多，文件越大。有个限制：每个应用只能有一个文件，外加安装该文件的命令行。若安装程序包含多文件，必须用自解压安装程序打包，虽不难但挺麻烦。

记住，最终得把 `.PPKG` 文件传给用户，通常用 U 盘或 DVD。请留意这点。此外，如前所述，无需通过 `.PPKG` 传递那些反正会通过 MDM 经互联网部署的内容，也请记在心上。

#### 添加证书页面

“添加证书”页面也很实用。很多时候需预置证书到机器中，使其即刻信任资源。在[图 8.7](#c08.xhtml#figure8-7)中，我导入 `.CER` 格式证书。
