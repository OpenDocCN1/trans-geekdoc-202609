

### 将应用程序重新打包为 MSIX 格式

```powershell
$CertPassword = ConvertTo-SecureString -String "p@ssw0rd" -Force -AsPlain
Export-PfxCertificate -Cert "cert:\CurrentUser\My\$($cert.Thumbprint)" -FilePath "c:\temp\test.pfx" -Password $CertPassword
```

PowerShell 命令的结果如[图 6.22](#c06.xhtml#figure6-22)所示，其中 `test.pfx` 文件已生成。

![Figure 6.22 Creating a self-signed PFX certificate for testing](images/c06f022.jpg)

**[图 6.22](#c06.xhtml#figureanchor6-22)** 创建用于测试的自签名 PFX 证书

`test.pfx` 生成后，请妥善保管。你马上就需要用它来签名即将创建的 MSIX。而且，同一个证书还必须分发到终端设备，这能验证你正在创建和签名的 MSIX 是受信任的，因为它们共享同一个证书。

既然你已经有了工具和证书，就可以以管理员身份运行 MSIX 打包工具了。选择“应用程序包：创建你的应用程序包”，如[图 6.23](#c06.xhtml#figure6-23)所示。

然后在下一个屏幕上，输入你拥有的所有内容：

* Notepad++ .EXE 安装程序的路径
* `test.pfx` 代码签名证书的路径
* 代码签名证书的密码

![Figure 6.23 Create your MSIX package by clicking on “Application package.”](images/c06f023.jpg)

**[图 6.23](#c06.xhtml#figureanchor6-23)** 单击“应用程序包”创建 MSIX 包

你可以在[图 6.24](#c06.xhtml#figure6-24)中看到此内容。

![Figure 6.24 Create a new package by providing an existing application and certificate.](images/c06f024.jpg)

**[图 6.24](#c06.xhtml#figureanchor6-24)** 通过提供现有应用程序和证书来创建新包

下一个屏幕标题为“选择环境”，此处不显示。它允许你在虚拟机或本台计算机上创建包。就目前撰写本书时而言，虚拟机的想法尚未成真。我认为其构想是让你下载一个预配置的 VM，然后将其用作设置复杂应用程序的“倾倒场所”。对于 Notepad++，使用“本台计算机”即可。单击“下一步”。

下一个屏幕是“包信息”，如[图 6.25](#c06.xhtml#figure6-25)所示。在此页面上，你将输入包名称和显示名称（可以相同也可以不同）、发布者名称（应自动从证书填入）、发布者显示名称、版本号，以及你打算安装应用程序的目标文件夹。

我选择了 `c:\NotePadPlusPlusMSIX\`。

Notepad++ 通常不安装在 `c:\NotePadPlusPlusMSIX`，但我打算把它安装在那里。当我这样做时，MSIX 打包工具将会检测到并从那里获取核心内容。

![Figure 6.25 Enter the details of the package.](images/c06f025.jpg)

**[图 6.25](#c06.xhtml#figureanchor6-25)** 输入包的详细信息

下一个屏幕是“准备计算机”，如[图 6.26](#c06.xhtml#figure6-26)所示。此时，首次运行时，MSIX 打包工具将安装一个驱动程序，并建议禁用计算机上启用的某些项目。对于像 Notepad++ 这样的小程序，这实际上不是必需的，但对于大型应用程序可能需要。

单击“下一步”继续。

![Figure 6.26 The MSIX Packaging Tool installs a driver and makes recommendations for the safest capture.](images/c06f026.jpg)

**[图 6.26](#c06.xhtml#figureanchor6-26)** MSIX 打包工具安装驱动程序并为最安全的捕获提供建议

下一个屏幕是安装屏幕，如[图 6.27](#c06.xhtml#figure6-27)所示。MSI 打包工具将自动启动 Notepad++ 安装程序。启动时，请务必将 Notepad++ 指向安装位置，以确保最佳捕获效果。

完成 Notepad++ 的所有安装步骤，最后在提示时运行一次并将其关闭。完成后，在 MSIX 打包工具中单击“下一步”。

下一页是“首次启动任务”（请参阅[图 6.28](#c06.xhtml#figure6-28)）。此页面可帮助你验证捕获工具是否真正捕获了你想要的内容。你可以看到 `Notepad++.exe` 被发现为一个*入口点*。其他应用程序可能有更多入口点，如辅助应用程序等。目前这没问题，所以单击“下一步”。

![Figure 6.27 Run the application and deploy it to the target location.](images/c06f027.jpg)

**[图 6.27](#c06.xhtml#figureanchor6-27)** 运行应用程序并将其部署到目标位置

![Figure 6.28 See the entrypoints of your application.](images/c06f028.jpg)

**[图 6.28](#c06.xhtml#figureanchor6-28)** 查看应用程序的入口点

此时可能会提示“完成了吗”。我们完成了，所以单击“完成，继续”。包已准备就绪，你可以指定保存位置。

最后一个屏幕是“创建包”。指定 MSIX 包的输出位置并单击“创建”，将出现最终确认（如[图 6.29](#c06.xhtml#figure6-29)所示）并显示成功消息。

![Figure 6.29 Success when creating an MSIX package](images/c06f029.jpg)

**[图 6.29](#c06.xhtml#figureanchor6-29)** 创建 MSIX 包成功

现在你几乎准备好测试了。

### MSIX 预测试

事实上，在继续之前，请转到“添加/删除程序”并卸载 Notepad++，因为在此过程中，你实际上刚刚那样做了。

所以，这行不通，但我还是希望你试一下。

既然 Notepad++ 已从系统中移除，请尝试再次安装它，但这次使用你创建的 MSIX 包。只需双击安装（顺便说一句，这仅适用于 Windows 10 1809 及更高版本的计算机）。

你应该会看到安装失败，如[图 6.30](#c06.xhtml#figure6-30)所示。

![Figure 6.30 MSIX Installation fails because your computer doesn’t trust the certificate that signed the MSIX.](images/c06f030.jpg)

**[图 6.30](#c06.xhtml#figureanchor6-30)** MSIX 安装失败，因为计算机不信任给 MSIX 签名的证书

因此，对于这个快速测试，仍以管理员身份登录到 Windows 10 计算机，双击之前创建的 `test.pfx` 文件。目标是将证书导入到计算机的“受信任的根证书颁发机构”存储中。

基本（手动）步骤是选择“本地计算机”作为存储位置，如[图 6.31](#c06.xhtml#figure6-31)所示。

在下一步（未显示）中，确认 PFX 证书的文件名。

再下一步（未显示）中，你需要提供证书的密码。在 PowerShell 创建示例中，我们使用了 `p@ssw0rd`。

然后在“证书存储”页面，不要自动安装证书，而是指定使用用户的“受信任的根证书颁发机构”，如[图 6.32](#c06.xhtml#figure6-32)所示。

![Figure 6.31 Starting the Certificate Import Wizard](images/c06f031.jpg)

**[图 6.31](#c06.xhtml#figureanchor6-31)** 启动证书导入向导

![Figure 6.32 Import the certificate into the Trusted Root Certification Authorities.](images/c06f032.jpg)

**[图 6.32](#c06.xhtml#figureanchor6-32)** 将证书导入到受信任的根证书颁发机构

然后单击“完成”以完成向导并安装证书。

现在再次单击之前创建的 MSIX 包。它现在应该能安装到计算机上了（请参阅[图 6.33](#c06.xhtml#figure6-33)）。

![Figure 6.33 See your MSIX package install.](images/c06f033.jpg)

**[图 6.33](#c06.xhtml#figureanchor6-33)** 查看 MSIX 包安装

![image](images/tip.jpg) 这些 MSIX 包安装程序也可以通过 PowerShell 命令 `Add-AppXPackage` 进行脚本化安装。
