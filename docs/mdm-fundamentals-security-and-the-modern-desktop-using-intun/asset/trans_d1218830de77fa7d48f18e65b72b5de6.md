## 使用 PolicyPak 克服 UAC 提示

我们在[第 10 章](#c10.xhtml)中看到过 PolicyPak，当时我们讨论了在需要管理 BitLocker 时如何克服 UAC 提示。标准用户无法备份自己的 BitLocker 恢复密钥，在该章中我展示了如何使用 PolicyPak Least Privilege Manager 来克服这一问题。

然而，几乎肯定会有这样一些情况：您部署的应用程序，怎么说呢，又旧又难搞。或者可能是新但也难搞。当用户运行它时，应用程序会显示一个 UAC 提示，这会阻止用户按设计运行它，或者完全阻止用户运行它。

要克服此问题，您可以使用 PolicyPak Least Privilege Manager 提升顽固应用程序的权限以绕过 UAC 提示（[图 11.21](#c11.xhtml#figure11-21)）。

![图 11.21 运行需要 UAC 提示的应用程序](images/c11f021.jpg)

[**图 11.21**](#c11.xhtml#figureanchor11-21) 运行需要 UAC 提示的应用程序

使用 PolicyPak Least Privilege Manager，您只需设置规则。在[图 11.22](#c11.xhtml#figure11-22)中，我创建了一条规则，意思是：“每当我看到 TreeSizeFree 版本高于 4.0.3 左右，且由 JAM Software GmbH 签名时，则以提升的权限运行。”

![图 11.22 使用 PolicyPak Least Privilege Manager 克服 UAC 提示](images/c11f022.jpg)

## 使用 PolicyPak 阻止和允许 UWP 应用程序

如果您设置了商业版 Windows 应用商店，您将拥有一个精选的应用程序库，可按需下载和安装。但面向消费者的 Microsoft Store 怎么办？

也许您想允许消费者版 Microsoft Store，但允许用户安装和运行来自特定供应商的应用程序——例如，放行所有 Adobe 产品但阻止其他所有内容。

借助 PolicyPak Least Privilege Manager 以及阻止和允许 UWP 应用程序、但允许特定供应商或应用程序通过的能力，这简直易如反掌。

此功能的端到端视频可在此处找到：

`https://www.policypak.com/video/policypak-manage-block-and-allow-windows-universal-uwp-applications.html`

此外，特别提醒使用 Windows 10 专业版的用户：PolicyPak Least Privilege Manager 可以阻止消费者版 Microsoft Store（通常无法通过其他方式实现）。此外，如果您想这么做，也可以阻止 Microsoft Edge 的运行。

我经常被问到这两个问题。

## 使用 PolicyPak 管理应用程序、浏览器和 Java 设置

应用程序通过 Intune 部署后，将带有赋予它们的任何默认设置“诞生”。这很可能不是您想要的。即使是低ly 的 Internet Explorer 也需要为您的安全设置进行最佳配置。

以下是三个可以协同工作以管理应用程序、浏览器和 Java 的组件的超快速概述。

*   **PolicyPak Application Settings Manager：** 拥有 500 个预配置的 Pak，可管理您可能部署到 Windows 10 桌面的几乎每个应用程序中的几乎每个设置。请参阅[图 11.24](#c11.xhtml#figure11-24)，了解 PolicyPak Application Settings Manager 如何管理 Firefox、Internet Explorer、Chrome 和 Java 以及大量其他应用程序的几乎所有设置。

*   **PolicyPak Browser Router：** 现在您有两个浏览器，Internet Explorer 和 Edge。很可能还有 Chrome 和 Firefox。某些网站仅根据打开它们的浏览器不同，工作效果就会更好。在[图 11.25](#c11.xhtml#figure11-25)中，您可以看到如何创建 PolicyPak Browser Router“路由”来指定特定网站（或模式）将使用正确的浏览器打开。

*   **PolicyPak Java Rules Manager：** 旧应用程序很糟糕。但许多需要 Java。且需要特定版本的 Java。借助 PolicyPak Java Rules Manager，您可以强制特定 Web 应用程序与特定版本的 Java 匹配。请参阅[图 11.26](#c11.xhtml#figure11-26)。

要点很简单：尽可能简单地部署您的应用程序和浏览器。然后在顶层叠加您需要的策略设置，以确保正确的外观和设置，随后在正确的时间将它们交付给正确的人员。
