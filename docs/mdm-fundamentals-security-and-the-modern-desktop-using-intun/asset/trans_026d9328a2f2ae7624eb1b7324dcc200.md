## 使用 Team Site Automount

好的。您已将一个或多个本地文件共享连同其中的大量数据迁移到了云端。这有点像……Sky……Drive。一个非常 Groove(y) 的 Sky……Drive。等等，我们不能叫这个名字。

无论如何，现在文件已经在云端，您如何告诉本地机器如何使用它们？您将同时使用 Group Policy 和 MDM，向 OneDrive 客户端提供您的租户 ID 和库 ID。

之前我们为了这一刻就已经暂存了 OneDrive ADMX 文件。

而 Intune 在 Intune Administrative Templates 节点中预置了 OneDrive ADMX。

让我们同时设置 Group Policy 和 MDM，强制向 OneDrive 推送我们的新库，使其非常像、有点像、几乎像一个映射驱动器。这称为 Team Site Automount。

### 使用 Group Policy 设置 Team Site Automount

您要查找的策略设置同时存在于用户端和计算机端。这意味着，您可以指定此设置影响计算机（从而影响该计算机上的所有用户）或特定用户（无论他们漫游到何处）。

我将在计算机端进行演示：`Computer Configuration` ➢ `Administrative Templates` ➢ `OneDrive` ➢ **Configure team site libraries to sync automatically**。示例请参见 **Figure 7.20**。

![Figure 7.20 Use the Configure team site libraries to sync automatically policy setting to specify the library ID in the Value section.](images/c07f020.jpg)

**Figure 7.20** 使用“Configure team site libraries to sync automatically”策略设置在 Value 部分指定库 ID。

您可以看到我输入了一个值名称（顺便说一句，用户并不真正使用或看到它，但最好还是与库名称匹配）。我还输入了一个值。一个代表我的租户和库 ID 的超长字符串。我是怎么得到的呢？

在 Sync 按钮下方（我们之前在 SharePoint 的库信息中见过），您可以点击“Copy library ID”，如 **Figure 7.21** 所示。仅此而已。这就是您需要的*此库*的秘密握手。

![Figure 7.21 Grabbing the library ID](images/c07f021.jpg)

**Figure 7.21** 获取库 ID

该字符串看起来如下所示：

```
tenantId=2d8180fa%abcde%2D42f5%2Db95c%2abcdeabcdbfd0&siteId=%7B55760d6e%
2D5821%2D41cf%2Dbae1%2D73f1936e5fcf%7D&webId=%7Bba7799e2%2D17dc%2D4247%
2Da10f%2D39b8e2650059%7D&listId=%7B1abcdD%2DCB85%2D433D%2DBD31%
2DABCDF001F7%7D&webUrl=https%3A%2F%2Ffabrikam1000%2ESharePoint%2Ecom&version=1
```

在 Group Policy 中，只需为您想通过 OneDrive 公开的每个库放置一行，如 **Figure 7.22** 所示。

![Figure 7.22 The Registry item that is created for each Team Site Automounted library](images/c07f022.jpg)

**Figure 7.22** 为每个 Team Site Automount 库创建的注册表项

结果如 **Figure 7.22** 所示。即，在 `HKLM\Software\Policies\Microsoft\OneDrive\TennantAutoMount` 处创建了一个注册表项。

### 在 MDM 中设置 Team Site Automount

请记住，您环境中的某些系统可能*永远*不会加入域。因此，它们永远不会获得 OneDrive Group Policy 设置。

于是 MDM 登场了。但有个障碍。

您需要的设置在计算机端只是一个单纯的注册表设置。

目前尚无（且到您阅读本书时肯定会有、且最简单的）Intune 中的 Administrative Template 项来配置 Team Site Automount。OneDrive 的 Administrative Templates 可见于 **Figure 7.23**。确实，我们稍后会用到其中一些。但正如您所见，目前没有任何设置与我们在 Group Policy 中看到的 **Configure team site libraries to sync automatically** 设置相对应。

![Figure 7.23 The Intune Administrative Template settings for OneDrive](images/c07f023.jpg)

**Figure 7.23** Intune 中 OneDrive 的 Administrative Template 设置
