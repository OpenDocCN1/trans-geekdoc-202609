Here is the general form of a class declaration in Python:

```
class ClassName:
    def method1(self, ...):
        block1
    def method2(self, ...):
        block2
    etc.
```

A class declaration starts out with the keyword class, followed by the name of the class you are defining, with the colon (:). The methods of the class follow; each method starts with "def", just as you use to define a function.

Before we look at the construction of the class, let's see how it works in practice. To create an instance in Python, you use the name of the class as if it were a function call, followed by a list of arguments in parentheses. Our SnailRun constructor method will need two arguments: the snail's name and finish time. Once we have defined the class, we can build a new instance like:

judyRace9 = SnailRun ('judy', 87.3)

To get the snail's name and attributes from an instance, we use the instance name, followed by a dot (.), followed by the attribute name:

```
>>> judyRace9.name
'judy'
```

```
>>> print judyRace9.time
87.3
```

Our example class, SnailRun, will have just two methods:

+   - All classes have a constructor method named "__init__". This method is used to create a new instance.
- We'll write a .show() method to format the contents of the instance for display.

Continuing our example from above, here's an example of the use of the .show() method:

