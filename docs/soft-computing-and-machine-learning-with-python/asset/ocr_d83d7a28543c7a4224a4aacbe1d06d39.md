Just as the amount of neighbors a weight falls off, the amount weight can learn also decreases with time. On the first iteration, the winning weight becomes the sample vector t has a full range of 0 to 1. As as time progresses, the winning weight becomes slightly more like the sample where the maximum value of t decreases. The rate at which the amount weight can learn falls of linearly. To depict this visually, in the previous plot, the amount weight can learn is equivalent to how high the bump is at their location. As time progresses, the height of the bump will decrease. Adding this function to the neighbourhood function will result in the height of the bump going down while the base of the bump shrinks.

So once a weight is determined the winner, the neighbours of that weight is found and each of those neighbours in addition to the winning weight change to become more like the sample vector.
