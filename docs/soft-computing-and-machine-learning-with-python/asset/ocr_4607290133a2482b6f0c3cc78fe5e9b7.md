# INTRODUCTION

In recent years there has been a wealth of research in methods for learning structured prediction, as well as in their application in areas such as natural language processing and computer vision. Unfortunately few implementations are publicly available—many applications are based on the non-free implementation of Joachims et al. (2009).

PyStruct aims at providing a high-quality implementation with an easy-to-use interface, in the high-level Python language. This allows practitioners to efficiently test a range of models, as well as allowing researchers to compare to baseline methods more easily than is possible with current implementations. PyStruct is BSD-licensed, allowing modification and redistribution of the code, as well as use in commercial applications. By embracing paradigms established in the scientific Python community and reusing the interface of the widely-used scikit-library (Pedregosa et al., 2011), PyStruct can be used in existing projects, replacing standard classifiers. The online documentation and examples help new users understand the somewhat abstract behind structured prediction.

# STRUCTURED PREDICTION AND CASTING INTO SOFTWARE

Structured prediction can be defined as making a prediction f(x) by maximizing a compatibility function between an input x and the possible labels y (Nowozin and Lampert, 2011). Most current approaches use linear labels, leading to:

```
$f(x) = \arg \max_{y \in Y} \theta^T \Psi(x, y).
(1)
```

Here, y is a structured label, $\Psi$ is a joint feature function of x and y, and $	heta$ are parameters of the model. Structured means that y is more complicated than a single output label, for example a word in a sentence or a label for each pixel in an image. Learning structured prediction means learning the parameters $	heta$ from training data.

Using the above formulation, learning can be broken down into three sub-problems:

+   1. Optimizing the objective with respect to $	heta$.
2. Encoding the structure of the problem in a joint feature function $\Psi$.
