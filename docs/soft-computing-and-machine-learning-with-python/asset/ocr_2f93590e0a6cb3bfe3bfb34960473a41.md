In addition to the printable characters with codes in the range from 32 to 127 inclusive, a Python string can contain any of the other unprintable, special characters as well. For example, the null character, whose official name is NUL, is the character whose code is zero. One way to write such a character is to use this form:

```
`\NN`
```

where N is the character>s code in hexadecimal (base 16) notation:

```
>>> chr(0)
```

```
`\x00`
```

```
>>> ord(\\x00')
```

Another special character you may need to deal with is the newline character, whose official name is LF (for "line feed"). Use the special escape sequence "\n" to produce this character.

```
>>> s = "Two-line\nstring."
```

```
>>> s
```

'Two-line\nstring.'

```
>>> print s
```

Two-line

string.

As you can see, when a newline character is displayed in conversational mode, it appears as "\n", but when you print it, the character that follows will appear on the next line. The code for this character is 10:

```
>>> ord(\
')
```

10

```
>>> chr(10)
```
