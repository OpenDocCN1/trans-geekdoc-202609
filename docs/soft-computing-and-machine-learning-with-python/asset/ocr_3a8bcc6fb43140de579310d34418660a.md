# # Unsupervised Learning

Unsupervised learning seems much harder: the goal is to have the computer learn how to do something we don't tell it how to do! There are actually two approaches to unsupervised learning. The first approach is to teach the agent not by giving explicit categorizations, but by using some sort of reward system to indicate success. Note that this type of training will generally fit into the decision problem framework because the goal is not to produce a classification but to make decisions that rewards. This approach nearly generalizes to the real world, where agents might be rewarded for doing certain actions and punished for doing others. Often, a form of reinforcement learning can be used for unsupervised learning, where the agent bases on the previous rewards and punishments without necessarily even learning anything about the exact ways that its actions affect the world.
