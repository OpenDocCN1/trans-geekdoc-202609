Exponentiation is expressed as “x ** y”, meaning x to the y power.

```
>>> 2 ** 8
256
>>> 2 ** 30
1073741824
>>> 2.0 ** 0.5
1.414213562730951
>>> 10.0 ** 5.2
158489.31924611141
>>> 2.0 ** 100
1.267506002282294e+30
```

That last number, 1.267506002282294e+30, is an example of exponential or scientific notation. This number is read as “1.26765… times to the 10th power”. Similarly, a number like 1.66e-24 is read as “1.66 times ten to the minus 24 power”.

So far we have seen examples of the integer type, which is called in Python, and the floating-point type, called the float type in Python. Python guarantees that int type supports values between -2,147,483,648 and 2,147,483,647 (inclusive).

There is another type called long, that can represent much larger integer values. Python automatically switches to this type whenever an expression has values outside the range of int values. You will see letter “L” appear at the end of such values, but they act just like regular integers.

```

1125899906842624L
>>> 2 ** 100
```
