In this form:

+   S is a format string that specifies the fixed parts of the desired text and also tells where the variable parts are to go and how they are to look.

+   The .format() method takes zero or more positional arguments p_i, followed by zero or more keyword arguments k_i=e_i, where each k_i is any Python name and each e_i is any Python expression.

+   The format string is a mixture of ordinary text and format codes. Each of the format codes is enclosed in braces {...}. A format code containing a number refers to the corresponding positional argument, and a format code containing a name refers to the corresponding keyword argument.

Examples:

```
>>> "We have {0} bananas.".format(27)
'We have 27 bananas.'
```

```
>>> "We have {0} cases of {1} today.".format(42, 'peaches')
'We have 42 peaches of today.'
```

```
>>> "You'll have {count} new {thing}s by {date}".format(
    count=27, date="St. Swithin's Day", thing="cooker")
'You'll have 27 new cooks by St. Swithin's Day'
```

You can control the formatting of an item by using a format code {N:type}, where N is the number or name of the argument to the .format() method, and type specifies the details of the formatting.

The type may be a single code like s for string, d for integer, or f for float.

```
>>> "{0:d}".format(27)
'27000000'
```

```
>>> "{animal:s}".format(animal="sheep")
'sheep'
```

You may also include a field size just before the type code. With float values, you can also specify a precision after the field size using a ".f followed by the desired number of digits after the decimal.
