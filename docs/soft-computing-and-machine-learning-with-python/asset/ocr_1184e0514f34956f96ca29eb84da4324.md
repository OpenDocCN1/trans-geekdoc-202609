# 181.4 Blake

The .sort() method on a list uses Python’s cmp() function to compare items when sorting them, and this in turn will call our class’s __cmp__() method to sort them by finishing time.

```
>>> race4.sort()
>>> for run in race4:
...     print run
...
67.3 Judy
76.5 Jim
88.8 Sally
181.4 Blake
```
