Here is another useful method:
d.get(k)
If k is a key in d, this method returns d[k]. However, if k is not a key, the method returns the special value None. The advantage of this method is if the k is not a key in d, it is not considered an error.

```
>>> nameNo.get("two")
2
>>> nameNo.get("eleven")
>>> huh = nameNo.get("eleven")
>>> print huh
None
```

Note that when you are in conversational mode, and you type an expression that results in the value None, nothing is printed. However, the print statement will display the special value None visually as the example above shows. There is another way to call the .get() method, with two arguments:

```
d.get(k, default)
```

In this form, if k exists, the corresponding value is returned. However, if k is not a key in d, it returns the default value.
