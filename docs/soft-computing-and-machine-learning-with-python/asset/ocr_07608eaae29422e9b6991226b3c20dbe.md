There can be any number of statements after the if, but they must all indented, and all indented the same amount. This group of statements is called a block.

When the if statement is executed, the condition C is evaluated, and converted to a bool value (if it isn't already Boolean). If that value is True, the block is executed; if the value is False, the block is skipped.

Here’s an example:

```
>>> half = 0.5
>>> if half > 0:
    print “Half is better than none.”
    print “Burma!”
```

Half is better than none.
Burma!

Sometimes you want to do some action A when C is true, but perform different action B when C is false. The general form of this construct is:

if C:

```
block A
...
```

else:

```
block B
...
```
