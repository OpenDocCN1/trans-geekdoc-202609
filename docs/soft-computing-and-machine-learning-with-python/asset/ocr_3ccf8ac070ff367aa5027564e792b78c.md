# Soft Computing and Machine Learning with Python

Here, for example, is a diagram showing all the positions of the string
'ijklm'.

| -5 | -4 | -3 | -2 | -1 |
|---|---|---|---|\||
| i | j | k | 1 | m |
| 0 | 1 | 2 | 3 | 4 | 5 |

In the diagram above, the numbers show the positions between characters.
Position 0 is the position before the first character; position 1 is the position
between the first and characters; and so on.

You may also refer to the position relative to the end of a string. Position -1
refers to the position before the last character; -2 is the position before the
next-to-last character; and so on.

To extract from a string s the character that occurs just after position n,
use an expression of this form:

```
s[n]
Examples:
>>> stuff = 'ijklm'
>>> stuff[0]
'i'
>>> stuff[1]
'j'
>>> stuff[4]
'm'
>>> stuff [ -1 ]
'm'
>>> stuff [-3]
'k'
>>> stuff[5]
Traceback (most recent call last):
File "<stdin>", line 1, in ?
IndexError: string index out of range
```

The last example shows what happens when you specify a position after
all characters in the string.

You can also extract multiple characters from a string; see Section 4.3,
"Slicing sequences"..
