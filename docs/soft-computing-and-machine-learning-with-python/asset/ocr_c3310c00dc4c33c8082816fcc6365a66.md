# Advantages and Disadvantages of NN:

Advantages: Adaptive Learning, Self-Organization, Real Time Operation Fault Tolerance via Redundant Information Coding.

Disadvantages: Less over fitting needs great computational effort. Sample Size must be large. It’s consuming. Engineering Judgment does not develop the relations between input and output variables so that the model behaves like a black box [26].
