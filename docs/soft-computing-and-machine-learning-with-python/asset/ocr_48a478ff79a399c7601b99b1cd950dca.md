You can delete a slice from a sequence by assigning an empty sequence to a slice.

```
>>> L
[0, 1, 93, 94, 95, 96, 97, 4, 5]
>>> L[3]
94
>>> L[7]
4
>>> L[3:7] = []
>>> L
[0, 1, 93, 94, 4, 5]
```

Similarly, you can insert elements into a sequence using an empty slice on the left-hand side.

```
>>> L
[0, 1, 93, 94, 4, 5]
>>> L[2]
93
>>> L[2:2] = [41, 43, 47, 53]
>>> L
[0, 1, 41, 43, 47, 53, 93, 4, 5]
```
