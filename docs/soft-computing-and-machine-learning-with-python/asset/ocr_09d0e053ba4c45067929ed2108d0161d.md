machine learning techniques to real-world data, which frequently show
skewness properties. A typical example from industry where skewed data
is intrinsic problem is fraud detection in finance data. In the following
we provide examples, where appropriate, to facilitate the understanding
of data mining of skewed data. The topics explored include but are not
