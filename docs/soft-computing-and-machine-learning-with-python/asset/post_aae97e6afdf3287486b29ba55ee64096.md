When Python starts up, three variables are always defined: __builtins__, __doc__, and __name__. These variables are for advanced work and needn't concern us now.

Note that when we define a variable (frankness), next time we call dir(), frankness is in the result list. When we define a function (oi), its name is also added. Note that you can also use the type(function) to find the type of any currently defined name: frankness has type float, and oi has type function.

Now let's see what happens when we import the math module into the global namespace:

```python
>>> from math import *
>>> dir()
['__builtins__', '__doc__', '__name__', 'acos', 'asin', 'atan', 'atan2', 'ceil', 'cos', 'cosh', 'degrees', 'e', 'exp', 'fabs', 'floor', 'fmod', 'frankness', 'frexp', 'hypot', 'ldexp', 'log', 'log10', 'modf', 'oi', 'pi', 'pow', 'radians', 'sin', 'sinh', 'tan', 'tanh']
>>> sqrt(64)
8.0
>>> pi*10.0
31.415926535897931
>>> cos(0.0)
>>>
```

As you can see, the names we have defined (oi and frankness) are still there, but all of the variables and functions from the math module are now in the global namespace, and we can use its functions and variables like sqrt() and pi.

In general, an import statement of this form copies all the functions and variables from the module into the current namespace:

```python
from someModule import *
```

However, you can also be selective about which items you want to import. Use a statement of this form:

```python
from someModule import item1, item2, ...
```

where the keyword import is followed by a list of names, separated by commas.

Here’s another example. Assume that you have just started a brand Python session, and you want to import only the sqrt() function and the constant pi:

```python
>>> dir()
['__builtins__', '__doc__', '__name__']
>>> math import sqrt, pi
>>> dir()
['__builtins__', '__doc__', '__name__', 'pi', 'sqrt']
>>> sqrt(25.0)
5.0
>>> cos(0.0)

File "stdin>", line 1, in <module>
NameError: name 'cos' is not defined
```

We didn’t ask for the cos() function to be imported, so it is not part of the global namespace.

# Import Entire Modules

Some modules have hundreds of different items in them. In cases like that, you might not want to clutter your global namespace with all those items. There is another way to import a module. Here is the general form:

```python
import moduleName
```

This statement adds only one name to the current namespace—the name of the module itself. You can then refer to any item inside that module using an expression of this form:

```python
moduleName.itemName
```

Here is an example, again using the built-in math module. Assume that you have just started a new Python session and you have added nothing to the namespace yet.

```python
>>> dir()
['__builtins__', '__doc__', '__name__']
```

```python
>>> import math
>>> dir()
['__builtins__', '__doc__', '__name__', 'math']
>>> type(math)
<type 'module'>
>>> math.sqrt(121.0)
11.0
>>> math.pi
3.1415926535897931
>>> math.cos(0.0)
1.0
```

As you can see, using this form of import adds only one name to the namespace, and that name has type module.

There is one more additional feature of import we should mention. If you want to import an entire module $M_1$, but you want to refer to its contents using a different name $M_2$, use a statement of this form:

```python
import $M_1$ as $M_2$
```

An example:
```python
>>> dir()
['__builtins__', '__doc__', '__name__']
>>> import math as crunch
>>> dir()
['__builtins__', '__doc__', '__name__', 'crunch']
>>> type(crunch)
<type 'module'>
>>> crunch.pi
3.1415926535897931
>>> crunch.sqrt(888.888)
29.81422479287362
```

You can apply Python's built-in dir() function to a module object to find what names are defined inside it:

```python
>>> import math
>>> dir()
['__builtins__', '__doc__', '__name__', 'math']
```

# A Module is a Namespace

Modules are another example of a Python namespace, just as we’ve discussed in Section 2.2, “The assignment statement” and Section 5.3, “A namespace is like a dictionary.”

When you import a module using the form “import moduleName”, you can refer to some N inside that module using the period operator: `moduleName.N`. So, like any other namespace, a module is a container for a unique set of names to which each name is connected.

# Build Your Own Modules

If you have a common problem to solve, chances are good that modules already written will reduce the amount of code you have to write.

- Python comes with a large collection of built-in modules. See the Python Library.
- The Python.org site also hosts a collection of third-party modules: see the Python package.

You can also build your own modules. A module is similar to a script (see Section 7, “How to write a self-executing script”) it is basically a text file containing definitions of Python functions and ordinary statements. To build your module, use a text editor to create a file with a name of the form “moduleName.py”. The `moduleName` must be a valid Python name–it must start with a letter or underscore, and consist entirely of letters, underscores, and digits. Inside that file, place Python function definitions and assignment statements.

```python
def cube(x):
    return x**3

cubeVersion = 9
```

Here is an interactive session that uses:
```python
>>> dir()
['__builtins__', '__doc__', '__name__']
>>> from cube import *
>>> dir()
['__builtins__', '__doc__', '__name__', 'cube', 'cubeVersion']
>>> cube(3)
27
>>> cubeVersion
'9'
```

There is one refinement for documenting a module. If the first line of the module’s file is a string constant, it is saved as the module’s “documentation string.” If you later import such module you can retrieve the contents of the documentation string using the expression `moduleName.__doc__`.

```python
def cube(x):
    return x**3

cubeVersion = 9
```

Finally, an example of how to retrieve the documentation string:
```python
>>> import cube
>>> print(cube.__doc__)
```

# INPUT AND OUTPUT

Python makes it easy to read and write files. To work with a file, you must first open it using the built-in open() function. If you are to read the file, use the form “open(filename)”, returns a file object. Once you have a file object, you can use a variety of methods to perform operations on the file.

# Reading Files

For example, for a file F, the method F.readline() attempts to read and return the next line from that file. If there are no lines remaining, it returns an empty string.

Let’s start with a small text file named trees containing three lines:
yew
oak
aligator

Suppose this file lives in your current directory. Here is how you might read it line at a time:

```python
>>> treeFile = open('trees')
>>> treeFile.readline()
'yew\n'
>>> treeFile.readline()
'oak\n'
>>> treeFile.readline()
'aligator\n'
>>> treeFile.readline()
''
```

Note that the newline characters ('\n') are included in the return value. You can use the string.rstrip() method to remove trailing newlines, but beware: it also removes any other trailing whitespace.

```python
>>> 'aligator\n'.rstrip()
'aligator'

>>> 'eat all my trailing spaces\n'.rstrip()
'eat all my trailing spaces'
```

To read all the lines in a file at once, use the .readlines() method. This returns a list whose elements are strings, one per line.

```python
>>> treeFile=open("trees")
>>> treeFile.readlines()
['yew\n', 'oak\n', 'aligator\n']
```

A general method for reading files is the .read() method. Used without arguments, it reads the entire file and returns it to you as one string.

```python
>>> treeFile = open("trees")
>>> treeFile.read()
'yew\noak\naligator\n'
```

To read exactly N characters from a file F, use the method F.read(N). If N characters remain in the file, you will get them back as an N-character string. If fewer than N characters remain, you will get the remaining characters in the file (if any).

```python
>>> treeFile = open ("trees")
>>> treeFile.read(1)
'y'
>>> treeFile.read(5)
'ew\noa'
>>> treeFile.read(50)
'k\nalligator juniper\n'
>>> treeFile.read(80)
```
