# Soft Computing and Machine Learning with Python

Rajeswari and Reena [19] used the data mining algorithms of Naive Bayes, K star and FT tree to analyze the liver disease. Data set is taken from UCI which contains 345 instances and 7 attributes. 10 cross validation test are applied by using WEKA tool. Naive Bayes provides 96.52% Correctness in 0 sec. 97.10% accuracy is achieved by FT tree in 0.2 sec. K star classify the instances about 83.47% accurately in 0 sec. On the basis of others, highest accuracy is achieved by FT tree on liver disease dataset as compared to other data mining algorithms.
