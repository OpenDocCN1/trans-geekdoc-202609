There is one refinement we suggest for documenting the contents of a module. If the first line of the module’s file is a string constant, it is saved as the module’s “documentation string.” If you later import such a module you can retrieve the contents of the documentation string using the expression `moduleName.__doc__`.

```
def cube(x):
    return x**3
```

cubeVersion = “1.9.33”

Finally, an example of how to retrieve the documentation string:
>>> import cuber
>>> print cuber.__doc__
