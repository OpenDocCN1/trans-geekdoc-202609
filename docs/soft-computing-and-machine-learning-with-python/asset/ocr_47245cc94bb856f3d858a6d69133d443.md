# Liver Disease

Vijayarani and Dhananday [17] predict the liver disease using Support vector machine and Naive bayes Classification algorithms. ILPD data set is obtained from UCI. Data set consists of 560 instances and 10 attributes. Comparison is made on the base of accuracy and time execution. Naive bayes shows 61.28% correctness in 1670.00 ms. 79.66% accuracy is attained in 3210.00 ms by SVM. For implementation, MATLAB is used. SVM shows highest accuracy as compared to the Naive bayes for liver prediction. In terms of time execution, Naive bayes takes less time as compared to the SVM.

A study on intelligent techniques to classify the liver patients is performed by the Giulia et al. [18]. Used data is picked up from UCI. WEKA data mining tool and five intelligent techniques J48, MLP, Random Forest, SVM and Bayesian Network classifiers are used in this experiment. In first step, all algorithms are applied on the original data and get in second step, feature selection is applied on whole data-set to get the significant subset of liver patients and all these algorithms are used to test the subset of whole-data-set. In third step they take comparison of outcomes before and after feature selection. FS, algorithms provide highest accuracy as J48 presents 70.669% accuracy, 70.8405% exactness is achieved by the MLP algorithm, SVM provides 71.3551% accuracy, 71.8696% accuracy is offered by Random forest and Bayes Net shows 69.1252% accuracy.
