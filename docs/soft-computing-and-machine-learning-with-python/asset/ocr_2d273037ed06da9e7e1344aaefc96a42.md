Feature subset selection is the process of identifying and removing as many irrelevant and redundant features as possible (Yu, 2004) . This reduces the dimensionality of the data and enables data mining algorithms to operate faster and more effectively. The fact that many features depend on one another unduly influences the accuracy of supervised ML classification models. This problem can be addressed by constructing new features from the basic feature set. This technique is called feature construction/transformation. These newly generated features may lead to the creation of more concise and accurate classifiers. These inputs, often called the “training set”, are the examples from which the agent tries to learn. Learning the training set well is not necessarily the best thing to do. For instance, if I tried to teach exclusive-or, but only showed you combinations consisting of one true and false, but never false or both true, you might learn the that the answer is always true. Similarly, with machine learning algorithms, a common problem is over-fitting the data and essentially memorizing the training set rather than learning a more general classification technique. As you might imagine, not all training sets have the inputs correctly classified. This can lead to problems if the algorithm used is powerful enough to memorize the apparently “special cases” that don’t fit the more general principles. This, too, can lead to overfitting, and it is a challenge to find algorithms that are both powerful enough to learn complex functions and robust enough to produce generalisable results.
