integer, a whole number. If any of the numbers involved contain a decimal point, the computation is done using floating point type:

```
>>> 1.0 / 4.0
0.25
>>> 1.0 / 3.0
0.3333333333333333
```

That second example above may also surprise you. Why is the last digit a one? In Python (and pretty much all other contemporary programming languages), many real numbers cannot be represented exactly. The representation of 1.0/3.0 has a slight error in the seventeenth decimal place. This behavior may be slightly annoying, but in conversational mode, Python doesn't know how much precision you want, so you get a ridiculous amount of precision, and this shows up the fact that some values are approximations.

You can use Python's print statement to display values without quite so much precision:

```
>>> print 1.0/3.0
0.3333333333333333
```

It's okay to mix integer and floating point numbers in the same expression. Any integer values are coerced to their floating point equivalents.

```
>>> print 1.0/5
0.2
>>> print 1/5.0
0.2
```

Later we will learn about Python's string format method , which allows you to specify exactly how precision we want when displaying numbers. For now, let's move on to more of the operators on numbers.

The “%” operator between two numbers gives you the modulo. That is, the expression “x % y” returns the remainder when x is divided by y.

```
>>> 13 % 5
3
>>> 5.72 % 0.5
```
