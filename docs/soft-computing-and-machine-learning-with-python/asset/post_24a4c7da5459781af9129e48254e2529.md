# INTRODUCTION

Machine learning is a relatively new science field composed by a broad class of computational and statistical methods to make predictions, inferences, and to discover new relations in data (Flach, 2012; Tibshirani, & Friedman, 2009). There are two main areas within the machine learning field: unsupervised learning focuses on the discovery of patterns and trends, while supervised learning focuses on the prediction. If the outcome is categorical, it is called classification; if it is numeric it is called regression.

There are several types of algorithms to perform, especially the tree-based models which are of special interest to the interaction effects (Hastie et al., 2009). The main benefit of using tree-based models in psychology is that they do not make any assumption regarding normality, linearity of the relation between variables, homoscedasticity, collinearity or independence (Geerts, Irthum & Wehenkel, 2009). Finally, the tree-based models, especially the techniques, can lead to high prediction accuracy, since they are known as the state-of-the-art methods in terms of prediction accuracy (Flach, 2012; Ebert et al., 2009).

# Recursive Partitioning and Ensemble Techniques

A classification tree partitions the feature space into several distinct mutually exclusive regions. Each region is fitted with a specific model that designates one of the classes to that particular space. The class is assigned to the region of the feature space by identifying the majority class in that region. In order to arrive in a solution that separates the feature space into pure nodes (regions), recursive binary partitioning is used.
