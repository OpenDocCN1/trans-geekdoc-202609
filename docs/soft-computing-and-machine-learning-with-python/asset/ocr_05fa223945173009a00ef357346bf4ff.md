if C_1:
  block_1

  block_2

  block_3

  block_F

So, in general, an if statement can have zero or more elif clauses, optionally followed by an else clause. Example:

```
>>> i = 2
>>> if i==1: print "One"
... elif i==2: print "Two"
... elif i==3: print "Three"
... else: print "Many"
...
```
