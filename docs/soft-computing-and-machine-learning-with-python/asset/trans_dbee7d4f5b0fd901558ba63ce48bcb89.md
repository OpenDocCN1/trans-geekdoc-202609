## 架构与编程语言

算法用C++实现。源代码被翻译（编译）成机器语言，这使得算法执行更高效，因为代码直接由处理器执行。该语言具有其他翻译成二进制代码的语言（C和Fortran）所缺乏的高级抽象。C++通过提供虚函数、多基继承以及异常支持面向对象编程，并方便了函数式和遗传编程，包括模板和lambda函数。标准C++库很紧凑但经过了良好测试且高效。它包含了对输入输出支持、字符串和字符串操作（如正则表达式），以及集合集合（如使用树或哈希表的vector、list和关联数组）。应该提到的是，C++11标准（ISO/IEC 14882:2011）引入了并发支持机制，因此可以利用具有多个处理器和/或多个核心的现代计算机的全功能。如果使用不支持C++11的旧版C++编译器，可能需要使用Boost [5]库：Boost.Thread用于创建可移植的多线程应用程序，Boost.Regex用于正则表达式，以及Boost.Chrono用于时间工具。此外，现代图形处理器单元（GPU）提供的向量计算在C++中可用，并应用了OpenCL [6]标准。

所提解决方案中的服务器应用程序使用了Python语言，主要因为与C++相比，这种开发更快。在计算过程中不构成瓶颈的模块应该用Python实现。Python是一种脚本语言，因此体积很小且语法简单、规则。该语言是动态类型检查的，使用统一的数据模型，并提供引用计数管理，因此没有内存泄漏问题。Python软件仓库（PIP）https://pypi.python.org/pypi包含超过30,000个包，可以使用许多现成的解决方案，特别是用于交换数据的包以及支持所用Web应用程序的包。需要注意的是，Biopython库 [7]提供了一组用Python编写的生物计算工具。

在biow中，Boost.Python [5]库实现了C++模块与Python模块之间的互操作性。其他解决方案，如直接从Python使用API、使用简化封装器和接口生成器（SWIG）生成代码、C++、Pyrex和cyton被认为用处较小，因为界面不够方便，且缺乏对遗传数据软件开发中所用技术的支持。Boost.Python使用Python API和元编程技术，允许将C++类、函数和对象暴露给Python，反之亦然，支持在C++代码内部使用Python。BoostPython允许通过简单的语法暴露元素并注册转换，且易于学习。

编译器和解释器的使用使得开发的软件更具活性。应用程序定制在任何情况下都要求使用解释器，更改设置不应要求重新构建软件。使用Python存储用户设置简化了应用的定制，因为设置不需要是名称和值的列表，并且可以使用Python控制指令。

客户端应用程序通过HTTP协议发送到标准端口，并由Web服务器通过进程间通信机制（例如sockets和命名管道）重传。

重传使用了mod_fastcgi和socket机制。考虑了三个开源Python库：来自PIP的Flup、Web2py http://web2py.com以及来自http://www.djangoproject.com的Django。这些库支持Web服务器网关接口（WSGI）。

Flup是一个简单的WSGI服务器，但其库很小（256KB），因此当接收到客户端的http请求时，其功能在Python函数层面上是有限的。更高级的库是Web2Py（9MB）和Django（22MB），其功能包含了参数转换、身份验证、授权以及使用对象映射的数据库支持。Flup、Web2py和Django都经过了本研究的测试，因为Web2py和Django的特征相似。然而，推荐Django因为它所有功能都是显式编写的。Django当前版本内部使用Flup配合Lighttpd；这种配置在所有流行的现代操作系统（Linux、Windows等）上都能正常工作。

Bioweb为客户端模块提供了两种竞争性解决方案，其中一种是基于JavaScript的HTML5，另一种是使用Apache Flex和Adobe Flash插件。JavaScript HTML5应用程序使用现代浏览器可用的Ajax技术，主要是XMLHttpRequest对象，因此用JavaScript开发的客户端应用程序可以在后台发送和检索数据。数据使用JavaScript对象格式（JSON）交换，Python标准库模块支持JSON编码器和解码器。HTML5标准包含了可缩矢量图形，改进了用户界面。JavaScript由Web浏览器解释并符合国际标准ISO/IEC 16262:2011。当前版本使用视图模型（MVVM）客户端JavaScript框架AngularJS [8]。

Apache Flex是一个免费提供的软件开发工具，支持构建使用Adobe Flash插件的应用程序。该插件在大多数浏览器上均可用，允许用户查看多媒体、矢量图形和动画。Apache Flex应用程序从服务器加载并在客户端执行。与服务器的通信使用动作消息格式
