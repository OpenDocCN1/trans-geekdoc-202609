- s.isalpha() tests all the characters of s are letters.
- s.isupper() tests all the letters of s are uppercase. (It ignores any non-letter characters).

- s.isdigit() tests whether all the characters of s are digits.

```python

True

False
```

# .split(): Break fields out of a string

The .split() method is used to break a string up into pieces wherever a certain string called the delimiter is found; it returns a list of strings containing the text between the delimiters. For example, suppose you have a string that contains a series of numbers separated by whitespace. A call to the .split() method on that string, with no arguments, returns a list of the parts of the string that are surrounded by whitespace.

```python
>>> line = "1.4 8.6 -23.49"
>>> line.split()
['1.4', '8.6', '-23.49']
```

You can also specify a delimiter as the argument of the .split() method.

```python
>>> s = 'farcical/aquatic/ceremony'
>>> s.split('/')
['farcical', 'aquatic', 'ceremony']
>>> 'a/b/c/'.split('/')
['a', 'b', 'c', '']
>>> 'Stilton,Wydale,Cheddar:Edam'.split(',')
['Stilton', 'Wydale', 'Cheddar:Edam']
```

You may also provide a second argument that limits the number of pieces from the string.

```python
>>> t = 'a/b/c/d'
>>> t.split('/', 1)
['a', 'b/c/d']
>>> t.split('/', 3)
['a', 'b', 'c', 'd']
```

# The String Format

One of the common string operations is to combine fixed text and variable values into a single string. For example, maybe you have a variable that contains the number of bananas, and you want to format a string like "We have 27 bananas". Here is how you do it:

```python
>>> bananas = 54
>>> "We have {} bananas".format(bananas)
'We have 54 bananas'
```

Here is the general form of the string format:
`"{n:type}".format(p0, ..., kn=en, ...)`

# Soft Computing and Machine Learning with Python

In this form:

- n is a format string that specifies the fixed parts of the desired text and tells where the variable parts go and how they look.
- The .format() method takes zero or more positional arguments, followed by zero or more keyword arguments, where each kn is any Python name and each en is any expression.
- The format string is a mixture of ordinary text and format codes. Each format code is enclosed in braces. A format code containing a number refers to the corresponding positional argument, and a format code containing a name refers to the corresponding keyword argument.

Examples:

```python
>>> "We have {0} bananas.".format(27)
'We have 27 bananas.'
>>> "We have {0} cases of {1} today.".format(42, 'peaches')
'We have 42 peaches of today.'
>>> "You'll have {count} new {thing}s by {date}".format(count=27, date="St.within Day", thing="cooker")
"You'll have 27 new cooks by St.within Day"
```

You can control the formatting of an item by using a format code {N:type}, where N is the number or name of the argument to the .format() method, and type specifies the details of the formatting. The type may be a single code like s for string, d for integer, or f for float.

```python
>>> "{0:d}".format(27)
'27000000'
>>> "{animal:s}".format(animal="sheep")
'sheep'
```

You may also include a field size just before the type code. With float values, you can also specify a precision after the field size using a .f followed by the desired number of digits after the decimal.

```python
>>> "{bat:8s}".format(bat='fruit')
'fruit   '
>>> "{0:8f}".format(1.0/7.0)
'.0142857'
>>> "{n:20.11f}".format(n=1.0/7.0)
'0.14285714286'
>>> "{silly:50.40f}".format(silly=5.33333)
'5.3333300000000012619238970993793010117'
```

Notice in the last example above that it is possible for you to produce a number of spurious digits beyond the number originally! Beware, because those digits are utter garbage. When you specify a precision, the value is rounded to the nearest value with that precision.

```python
>>> "{0:.1f}".format(0.999)
'1.0'
>>> "{0:.1f}".format(0.99)
'1.0'
>>> "{0:.1f}".format(0.9)
'0.9'
>>> "{0:.1f}".format(0.96)
'1.0'
>>> "{0:.1f}".format(0.9501)
'1.0'
>>> "{0:.1f}".format(0.949999)
'0.9'
```
