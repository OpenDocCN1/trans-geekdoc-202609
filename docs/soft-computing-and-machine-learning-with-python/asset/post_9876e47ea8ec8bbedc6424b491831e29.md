# NUMERIC TYPES

Python has different kinds of numbers. Any number without a decimal point is considered an integer, a whole number. If any of the numbers involved contain a decimal point, the computation is done using floating point.

# Basic Operations

Here are some examples:

```python
>>> 99 + 1
100
>>> 1 - 99
-98
>>> 7 * 5
35
```

If you want to override the usual precedence of Python operators, use parentheses:

```python
>>> (2+3)*4
20
```

Here's result you may not expect:

```python
>>> 1 / 5
0
```

You might expect a result of 0.2, not zero. However, Python has several ways of representing numbers. To do calculations:

```python
>>> 1.0 / 4.0
0.25
>>> 1.0 / 3.0
0.3333333333333333
```

When an expression contains more than one operation, Python defines the usual order of operations, so that higher-precedence operations like multiplication and division are done before addition and subtraction. In this example, even though the addition comes after the multiplication,

```python
>>> 2 + 3 * 4
14
```

The “%” operator between two numbers gives you the modulo. That is, the expression “x % y” returns the remainder when x is divided by y.

```python
>>> 13 % 5
3
>>> 5.72 % 0.5
```
