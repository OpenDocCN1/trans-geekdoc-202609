# Liver Disease

Vijayarani and Dhananday [17] predict the liver disease using Support vector machine and Naive bayes Classification algorithms. ILPD data set is obtained from UCI. Data set consists of 560 instances and 10 attributes. Comparison is made on the base of accuracy and time execution. Naive bayes shows 61.28% correctness in 1670.00 ms. 79.66% accuracy is attained in 3210.00 ms by SVM. For implementation, MATLAB is used. SVM shows highest accuracy as compared to the Naive bayes for liver prediction. In terms of time execution, Naive bayes takes less time as compared to the SVM.

A study on intelligent techniques to classify the liver patients is performed by the Giulia et al. [18]. Used data is picked up from UCI. WEKA data mining tool and five intelligent techniques J48, MLP, Random Forest, SVM and Bayesian Network classifiers are used in this experiment. In first step, all algorithms are applied on the original data and get in second step, feature selection is applied on whole data-set to get the significant subset of liver patients and all these algorithms are used to test the subset of whole-data-set. In third step they take comparison of outcomes before and after feature selection. FS, algorithms provide highest accuracy as J48 presents 70.669% accuracy, 70.8405% exactness is achieved by the MLP algorithm, SVM provides 71.3551% accuracy, 71.8696% accuracy is offered by Random forest and Bayes Net shows 69.1252% accuracy.

# Soft Computing and Machine Learning with Python

Rajeswari and Reena [19] used the data mining algorithms of Naive Bayes, K star and FT tree to analyze the liver disease. Data set is taken from UCI which contains 345 instances and 7 attributes. 10 cross validation test are applied by using WEKA tool. Naive Bayes provides 96.52% Correctness in 0 sec. 97.10% accuracy is achieved by FT tree in 0.2 sec. K star classify the instances about 83.47% accurately in 0 sec. On the basis of others, highest accuracy is achieved by FT tree on liver disease dataset as compared to other data mining algorithms. Dengue is becoming a severe contagious disease. It creates trouble in those countries where weather is humid for example Thailand, Indonesia and Malaysia. Decision Tree (DT), Artificial Neural Network (ANN), and Rough Set Theory (RS) are the classification algorithms that are used in this study to predict dengue disease. Data set are taken from Public Health Department of Selangor State. WEKA data mining with two tests (10 Cross-fold Validation and Percentage split) is used. Using 10-fold validation DT offers 99.95% accuracy, ANN presents 99.98% of Correctness and RS shows 100% accuracy. After using PS, Both Decision tree and Artificial Neural Network gives 99.92% of correctness. RS achieves 99.72% accuracy.

Fathima and Manimegalai [21] performed a work to predict Arbovirus-Dengue disease. Data mining algorithm that are used by these researchers are Support Vector Machine. Data set for analysis is obtained from King Institute of Preventive Medicine and surveys of many hospitals and laboratories of Chennai and Tirunelveli from India. It contains 29 attributes and 5000 samples. Data is examined by R project version 2.12.2. Accuracy that is achieved by SVM is 0.9042.

Ibrahim et al. [22] suggested a system in which Artificial neural network is used for forecasting the defeverence day of fever in patients of dengue disease. Only clinical signs and symptoms are used by the proposed system for detection. The data are gathered from 252 hospitalized patients, in which 4 patients are having DF (Dengue fever) and 248 patients are having DHF (dengue hemorrhagic fever). MATLAB’s neural network toolbox is used. Algorithm of Multilayer feed-forward neural network (MFNN) is used in this experiment. Day of defeverence of fever is accurately predicted by MFNN in DF and DF with 90% correctness.
