# Heart Disease

Otoom et al. [5] presented a system for the purpose of analysis and monitoring. Coronary artery is detected and monitored by this proposed system. Cleveland heart data set is taken from UCI. This data consists of 303 cases and 76 attributes/features. 13 features are used out of 76 features. Two tests with three algorithms Bayes Net, Support vector machine, and Functional Trees FT are performed for detection purpose. WEKA tool is used for detection. After experimenting Holdout test, 88.3% accuracy is attained by using SVM technique.
