Here are the six comparison operators:

| Math symbol | Python | Meaning |
| --- | --- | --- |
| < | < | Less than |
| <= | <= | Less than or equal to |
| > | > | Greater than |
| >= | >= | Greater than or equal to |
| = | = | Equal to |
| != | !=! | Not equal to |

The operator that compares for equality is "=". (The "=" symbol is an operator: it is used only in the assignment statement.)
