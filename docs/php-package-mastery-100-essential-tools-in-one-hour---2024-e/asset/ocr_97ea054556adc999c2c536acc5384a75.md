# 71. Respect\\Validation

Respect\\Validation is a powerful, fully featured validation library for PHP that simplifies data validation in applications. It offers a wide range of pre-built validators and the ability to create custom rules, supporting fluent interfaces for clean, readable syntax.

```
```php
Ex:\\Respect\\Validation
    require 'vendor/autoload.php';
    use Respect\\Validation\\Validator as v;
    $usernameValidator = v::alnum()->noWhitespace()->length(1, 15);
    $emailValidator = v::email();
    try {
        $usernameValidator->assert('myusername');
        $emailValidator->assert('user@example.com');
        echo "Validation passed!";
    } catch (\\Respect\\Validation\\Exceptions\\ValidationException $exception) {
        echo $exception->getMessage();
    }
```
