# 56. PHP League's Omnipay

Omnipay is a payment processing library for PHP. It provides a consistent, standardized interface for interacting with multiple payment gateways, including Stripe, PayPal, and many others. It abstracts the differences among various payment gateways, allowing developers to work with a single, unified API.

Ex:PHP League's Omnipay

```
```php
use Omnipay\Omnipay;
$gateway = Omnipay::create('Stripe');
$gateway->setApiKey('your_stripe_api_key');
$response = $gateway->purchase([
  'amount' => '10.00',
  'currency' => 'USD',
  'token' => 'card_token',
])->send();
if ($response->isSuccessful()) {
  // Payment was successful
  echo $response->getTransactionReference();
} else {
  // Payment failed
  echo $response->getMessage();
}
