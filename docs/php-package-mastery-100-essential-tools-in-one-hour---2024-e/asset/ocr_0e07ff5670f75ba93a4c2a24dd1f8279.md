# 30. array_map

array_map applies a callback function to the elements of one or more arrays and returns an array containing all the elements after applying the callback function.

Ex:array_map

```
function square($n) {
return $n * $n;
}
$numbers = [1, 2, 3, 4];
$squared = array_map('square', $numbers);
print_r($squared);
```

Array

```
(
[0] => 1
[1] => 4
[2] => 9
[3] => 16
)
```
