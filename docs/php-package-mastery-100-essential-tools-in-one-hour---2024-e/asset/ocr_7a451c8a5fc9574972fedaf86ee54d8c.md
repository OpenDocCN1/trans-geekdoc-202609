# 15. SPL (Standard PHP Library)

The SPL is a collection of interfaces and classes that are meant to solve common problems. It includes data structures, iterators, and interfaces for object serialization.

Ex:SPL (Standard PHP Library)

```
```php
// Example of using SPL's ArrayObject
$array = array('1' => 'PHP', '2' => 'Python', '3' => 'JavaScript');
$arrayObject = new ArrayObject($array);
// Iterate over the array values
for($iterator = $arrayObject->getIterator(); $iterator->valid(); $iterator->next()) {
    echo $iterator->key() . '=>' . $iterator->current() . "\n";
}
?>
