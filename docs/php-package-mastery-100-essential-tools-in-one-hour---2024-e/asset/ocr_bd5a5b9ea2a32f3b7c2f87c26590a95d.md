# 54. League\Uri

Allows manipulation and validation of URIs in PHP.

```
```php
Ex:League\\Uri
    // Example of parsing a URI and getting its components
    use League\\Uri\\UriString;
    $uri = 'https://example.com:443/path?query=123#fragment';
    $components = UriString::parse($uri);
    echo $components['scheme'];
```
```

https

In this snippet, we're using the League\Uri package, specifically the UriString class, to parse a URI string and extract its components. The UriString::parse method decomposes the given URI into its constituent parts, such as scheme, host, port, path, query, and fragment. By accessing the 'scheme' key from the resulting array, we can see the protocol (in this case, 'https') used in the URI. This functionality is incredibly useful for web applications that need to manipulate or validate URIs, as it provides a straightforward interface for breaking down and examining the structure of URIs.
