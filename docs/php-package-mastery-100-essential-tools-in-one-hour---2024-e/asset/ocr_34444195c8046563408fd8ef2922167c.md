# 16. CURL

CURL is a library used to make HTTP requests in PHP. It supports a wide range of protocols like HTTP, HTTPS, FTP, and more, making it versatile for web development tasks such as API calls.

# Ex:CURL

```
```php
// Example of using cURL to make a GET request
$curl = curl_init('http://example.com');
curl_setopt($curl, CURLOPT_RETURNTRANSFER, true);
// Execute the HTTP request
$response = curl_exec($curl);
// Close the cURL session
curl_close($curl);
// Print the response
echo $response;
?>
```
