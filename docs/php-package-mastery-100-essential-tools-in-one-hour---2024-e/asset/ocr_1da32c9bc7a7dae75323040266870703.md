# 36. Whoops

Whoops is a PHP library that helps handle errors and exceptions in a less painful way. It provides a stack-based error handler that can display a detailed error page, showing you where things went wrong along with the context in which the error occurred.

Ex:Whoops

```
```php
require 'vendor/autoload.php';
use Whoops\\Run;
use Whoops\\Handler\\PrettyPageHandler;
$whoops = new Run;
$whoops->pushHandler(new PrettyPageHandler());
$whoops->register();
```
```

When an error occurs in your PHP application, instead of the standard PHP error page, you'll see a detailed and styled error page provided by Whoops, showing the error message, stack trace, and context.
