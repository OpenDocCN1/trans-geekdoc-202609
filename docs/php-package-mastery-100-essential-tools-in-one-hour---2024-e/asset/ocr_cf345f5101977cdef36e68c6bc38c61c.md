# 41. ParagonIE Sodium Compat

This library is a polyfill for the libsodium library, providing cryptography features for PHP projects, such as encryption, decryption, signatures, and secure key exchange, particularly aiming to improve security practices.

```
Ex:ParagonIE Sodium Compat
require 'vendor/autoload.php';
use ParagonIE\Sodium\Core\Salsa20;
$message = 'This is a secret message.';
$key = \random_bytes(Salsa20::KEYBYTES); // Generate a random key
$nonce = \random_bytes(Salsa20::NONCEBYTES); // Generate a random nonce
// Encrypt the message
$encrypted = 
\ParagonIE\Sodium\Core\Salsa20::crypto_stream_xor($message, $nonce, $key);
// Decrypt the message
$decrypted = 
\ParagonIE\Sodium\Core\Salsa20::crypto_stream_xor($encrypted, $nonce, $key);
echo $decrypted;
```
