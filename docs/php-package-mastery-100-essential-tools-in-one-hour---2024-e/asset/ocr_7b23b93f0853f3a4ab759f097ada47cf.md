# 31. Aura.Sql

Aura.Sql is an extension of the PDO class that provides advanced features for database interaction, such as lazy connection, array quoting, query building, and a profiler. It aims to enhance PDO usage by offering convenient methods for common tasks and queries.

Ex:Aura.Sql

```
```php
require 'vendor/autoload.php';
// Create a new Aura.Sql instance for MySQL.
$pdo = new
Aura\Sql\ExtendedPdo('mysql:host=localhost;dbname=test', 'username',
'password');
// Example of query with array quoting
$query = "SELECT * FROM users WHERE id IN (:user_ids)";
$result = $pdo->fetchAll($query, ['user_ids' => [1, 2, 3]]);
echo json_encode($result);
?>
```
```

A JSON representation of the users with IDs 1, 2, and 3 from the "users" table.
