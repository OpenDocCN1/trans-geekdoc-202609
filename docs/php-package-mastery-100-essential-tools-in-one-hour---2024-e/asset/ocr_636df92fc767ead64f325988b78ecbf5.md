# 72. PHP League's OAuth2 Client

PHP League's OAuth2 Client is a package that provides a flexible and extensible way to integrate OAuth 2.0 client capabilities into PHP applications. It supports multiple OAuth 2.0 service providers out of the box and allows for custom provider implementations.

# Ex:PHP League's OAuth2 Client

```
```php
require 'vendor/autoload.php';
$provider = new League\OAuth2\Client\Provider\GenericProvider([
    'clientId' => 'demoapp',
    'clientSecret' => 'demosecret',
    'redirectUri' => 'http://example.com/your-redirect-url/',
    'urlAuthorize' =>
    'http://brentertainment.com/oauth2/lockdin/authorize',
    'urlAccessToken' =>
    'http://brentertainment.com/oauth2/lockdin/token',
    'urlResourceOwnerDetails' =>
    'http://brentertainment.com/oauth2/lockdin/resource'
]);
try {
    // Get authorization code
    $authUrl = $provider->getAuthorizationUrl();
    $_SESSION['oauth2state'] = $provider->getState();
    echo "Authorization URL: " . $authUrl;
```
