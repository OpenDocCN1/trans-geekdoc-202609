# 23. PCNTL

PCNTL (Process enables PHP scripts to control processes on Unix-based operating systems.

Ex:PCNTL

```
```php
$pid = pcntl_fork();
if ($pid == -1) {
    die('could not fork');
} else if ($pid) {
    // parent process
    pcntl_wait($status); // Protect against Zombie children
    echo "Parent Process";
} else {
    // child process
    echo "Child Process";
}
?>
```
```

Depending on the execution path, it displays "Child Process" in the child process and waits for the child process to finish in the parent process, then the parent process may display "Parent Process".
