# # 28. PsySH

PsySH is a runtime developer console, interactive debugger, and REPL (Read-Eval-Print Loop) for PHP. It allows developers to interactively execute PHP code in the command line, making it a valuable tool for debugging and development.

# Ex:PsySH

```
```shell
// This is a command you would run in your terminal, not a PHP script.
// Ensure PsySH is installed globally or in your project via Composer.
// Then, simply type:
psysh
```
```

```
```text
Psy Shell v0.x.x (PHP x.x.x — cli) by Justin Hileman
>>>
```
```

To use PsySH, you first need to ensure it's installed either globally on your system or within your specific PHP project using Composer. Once installed, you can start the PsySH shell by typing psysh in your terminal.
