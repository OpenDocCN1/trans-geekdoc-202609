# 27. mysqli

The MySQLi extension (MySQL Improved) is a relational database driver used in the PHP programming language to provide an interface with MySQL databases. It supports prepared statements, transactions, and enhanced debugging capabilities.

Ex:mysqli

```
```php
$mysqli = new mysqli("localhost", "user", "password", "database");
if ($mysqli->connect_errno) {
    echo "Failed to connect to MySQL: " . $mysqli->connect_error;
    exit();
}
// Perform a query, check for error
if (!$mysqli->query("CREATE TEMPORARY TABLE myCity LIKE City")) {
    echo "Query Failed: " . $mysqli->error;
    exit();
}
$mysqli->close();
?>
