# 2.2.3 Data Preprocessing

The data preprocessing phase involves several steps to ensure data quality and consistency. The steps applied were compiled from a BRFSS 2015 Codebook implementation [6]. Missing values are handled by using a function called _dropna()_ which removes rows or columns with missing values (NaN) from a data frame.
