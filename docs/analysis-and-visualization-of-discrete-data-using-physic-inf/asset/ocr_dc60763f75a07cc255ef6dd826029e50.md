A unique feature of PointNet is its ability to process point clouds directly. Conventional methods typically represent point clouds by converting them to voxel grids or 3D meshes and then applying a CNN. However, such methods can lead to compression and loss of information. PointNet avoids these problems by processing point clouds directly. PointNet can be used for tasks such as classification, segmentation, and object detection of point clouds. PointNet learns features such as point locations, colors, and normals from an input point cloud and combines these features to create a feature representation of the entire point cloud (Figure 2.2).

Using this global feature representation, PointNet can generate classification output data for a given point cloud data (Figure 2.3).
