Assuming that a three-dimensional image of a machine part has been obtained, the areas that can be determined to be the points on the crack surface can be identified by mouse operation, etc., and the data stored in the system along with their certainty value (scalar value). NN can be trained on the stored scalar data (physical data) to build a continuously distributed confidence model. An ordered lattice is defined in the same region as the three-dimensional image, and data are retrieved from the confidence model at the lattice points to generate the ordered lattice data.

When visualizing the page surfaces of ancient documents that cannot be turned, the page planes are extracted, and the three-dimensional images of the documents are mapped on the page planes. In this case, the area that can be determined as a point on the page surface is identified by a mouse operation, etc., and stored in the system along with its page number (scalar value) (Figure 2.36).
