In this sheet function, the labels $(wi\text{-}jk, i = 1, \text{number of neurons in layer } i + 1, j = 1, \text{number of neurons in layer } i + 1, k = 1, \text{number of neurons in layer } i)$ and the values of the weights, which are defined for each neuron-to-neuron bond between layers, are filled in the column direction. The neuron values in layer $i + 1$ are the result of multiplying all neuron values in layer $i$ by their individual weights and passing the result to the activation function. In the last layer, a single neuron value is calculated and becomes the regression $Y^{\prime}$ for the objective variable. The square error $(Y - Y^{\prime})^2$ of this $Y^{\prime}$ and the explanatory variable $Y$ is entered in the cell to the right of $Y^{\prime}$.

In the third and subsequent rows, the sheet function formulas entered in the two rows are copied for (number of observations $- 1$) rows. In a cell one row apart from the last row of all copied data, enter the formulas for the mean square error and the mean square error. The weight labels and values are entered in the two columns to the right. For clarity, the columns with the neuron labels and values corresponding to each layer are colored.
