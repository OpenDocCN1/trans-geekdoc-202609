# 2.5.2. Implementation of regression analysis

We have discussed the regression analysis using the Data Analysis tools in Excel. The regression analysis can also be performed using a Solver.

Now, we determine an error in a simple regression equation that represents a regression line. Assume that the equation of the regression line that can successfully account for $N$ discrete points is $y = \beta_0 + \beta_1 x$. For the $i$th point, the error in the $y$ axis direction is $e_i = y_i - (\beta_0 + \beta_1 x_i)$. The sum of squares of this error is

```
$$\sum_{i=1}^{N} e_i^2 = \sum_{i=1}^{N} (y_i - (\beta_0 + \beta_1 x_i))^2 \quad (2.21)$$
```
