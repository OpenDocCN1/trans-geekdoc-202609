Unlike the previous example, the dataset for training the NN model is obtained by simulation using traditional spectral methods. The above Burgers' equation is integrated from the start time $t = 0$ to the end time $t = \frac{\pi}{5}$. This is accomplished by Fourier spectral discretizations of 101 modes in the spatial domain $x \in [0, 2\pi]$ and an explicit Runge–Kutta time integrator of the first order with time step size $\pi / 500$. A solution for each $\Delta t = \frac{\pi}{500}$ is recorded to obtain 100 observation points. These are $n_x = 101$, $n_t = 100$, and $n_d = 10100$ for these data.
