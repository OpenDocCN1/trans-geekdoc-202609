Automatic differentiation or algorithmic differentiation refers to a technique of analyzing a function defined in a program to derive a program that calculates a partial derivative value [24]. Even a complex program consists of combinations of basic arithmetic operations, such as addition, subtraction, multiplication, and division, and basic functions, such as exponential, logarithmic, and trigonometric functions. Automatic differentiation takes advantage of this feature to find a solution by repeatedly applying the chain rule to these arithmetic operations. Automatic differentiation allows you to obtain a partial derivative value automatically with less computational effort.
