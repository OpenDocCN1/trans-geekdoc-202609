# **1.1.5.  _Autofill_**

The Autofill function in Exce1 helps you enter data efficiently. It automatically suggests data to be entered next based on the data that have already been entered (Figure 1.5).

For example, suppose that columns contain month and day data. The data “January”, “February”, and “March” are entered in the “Month” column, and the data “1st”, “2nd”, and “3rd” are entered in the “Day” column. If you enter “4” in the April cell of the “Month” column, “4” will also be automatically entered in the 4th cell of the “Day” column.

The Autofill function allows you to enter data more efficiently, so you can perform Exce1 work more efficiently. The Autofill function also reduces input errors, thereby increasing data reliability.
