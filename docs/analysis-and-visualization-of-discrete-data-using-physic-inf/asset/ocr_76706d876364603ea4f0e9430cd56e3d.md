layers and the chain rule are used to calculate as follows:

```
$$\left\{\begin{align*}\frac{\partial y}{\partial x_{1}} &= \frac{\partial y}{\partial m_{1}}\frac{\partial m_{1}}{\partial x_{1}} + \frac{\partial y}{\partial m_{2}}\frac{\partial m_{2}}{\partial x_{1}} \\
\frac{\partial y}{\partial x_{2}} &= \frac{\partial y}{\partial m_{1}}\frac{\partial m_{1}}{\partial x_{2}} + \frac{\partial y}{\partial m_{2}}\frac{\partial m_{2}}{\partial x_{2}}
\end{align*}\right\} \tag{3.9, 3.10}$$
```

Now, using the sigmoid function $\sigma(x) = 1/(1+e^{-x})$ as the activation function, each partial differential term on the right side of the above Equations (3.9) and (3.10) is expressed as follows:

```
$$\left\{\begin{align*}
&\frac{\partial y}{\partial m_{1}} = y(1-y)w_{11}^{2} & &\frac{\partial y}{\partial m_{2}} = y(1-y)w_{21}^{2}\\
&\frac{\partial m_{1}}{\partial x_{1}} = m_{1}(1-m_{1})w_{11}^{1} & &\frac{\partial m_{2}}{\partial x_{1}} = m_{2}(1-m_{2})w_{12}^{1}\\
&\frac{\partial m_{1}}{\partial x_{2}} = m_{1}(1-m_{1})w_{21}^{1} & &\frac{\partial m_{2}}{\partial x_{2}} = m_{2}(1-m_{2})w_{22}^{1}
\end{align*}\right\}$$
```

That is,

```
$$\left\{\begin{align*}\frac{\partial y}{\partial x_{1}} &= y(1-y)\left\{w_{11}^{2}m_{1}(1-m_{1})w_{11}^{1} + w_{21}^{2}m_{2}(1-m_{2})w_{12}^{1}\right\}\\
\frac{\partial y}{\partial x_{2}} &= y(1-y)\left\{w_{11}^{2}m_{1}(1-m_{1})w_{21}^{1} + w_{21}^{2}m_{2}(1-m_{2})w_{22}^{1}\right\}
\end{align*}\right\}$$
```

A mean squared error from the partial derivative calculated by these two methods is calculated as follows:

```
$$MSE_{grad} = \frac{1}{N_{u}}\sum_{i=1}^{N_{u}}\left\{\left(\frac{\partial y}{\partial x_{1}}-(2x_{1}+1)\right)^{2} + \left(\frac{\partial y}{\partial x_{2}}-(3x_{2}^{2}+2x_{2})\right)^{2}\right\} \tag{3.11}$$
```

The calculated mean squared error is added to $MSE_{u}$, the mean squared error that was minimized last time (Figure 3.7). The resulting sum was minimized with the Excel solver function, resulting in $MSE_{u}$ being changed from 0.0081 to 0.00696. The reason for this improvement is as follows: For the partial differentiation of the regression equation of this time, the calculated result is already known, so we have successfully improved the predictive accuracy of the regression equation by using this information.
