# 1.1.6. Relative reference

In Excel, the relative reference function allows the reference destination in a referenced cell to be automatically changed when the referenced cell is moved (Figure 1.6).

For example, for a cell containing the formula “=A1”, if you were to move this cell to the right by one cell, the formula will be automatically rewritten to “=B1”. The function capable of changing the reference destination in a cell automatically when the cell is moved is known as “relative reference”.
