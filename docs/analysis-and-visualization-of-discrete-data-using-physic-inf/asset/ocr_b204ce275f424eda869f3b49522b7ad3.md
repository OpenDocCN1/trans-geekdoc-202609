# 4.1.4.4. One-dimensional Poisson’s equation

Poisson’s equation is a type of partial differential equation used to describe the distribution of certain physical quantities in space-time. Specifically, Poisson’s equation is expressed as follows:

```
\(\nabla^2 u = -\rho\) \(\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad\qquad (4.16)\)
```

where \(u\) is a scalar field representing the distribution of physical quantities and \(\rho\) is a source term such as charge density or mass density in space.
