is decomposed by the partial derivative with respect to the $k-1$th layer variable $u_{m_{k-1}}^{k-1}$. 

```
$$\frac{\partial u_j^{k+1}}{\partial u_{m_{k-2}}^{k-2}} = \sum_{m_{k-1}=1}^{n_{k-1}} \frac{\partial u_{m_{k+1}}^{k+1}}{\partial u_{m_{k+1}}^{k-1}} \frac{\partial u_{m_{k-1}}^{k-1}}{\partial u_{m_{k-2}}^{k-2}} \qquad(3.5)$$
```

where the subexpression in Equation (3.5) is calculated from Equations (3.3) and (3.4). The differentiation can be performed with respect to the variables in the $k-n$ layer by repeating this process sequentially.

```
$$\frac{\partial u_j^{k+1}}{\partial u_{m_{k-n}}^{k-n}} = \sum_{m_{k+1-n}=1}^{n_{k+1-n}} \frac{\partial u_{m_{k+1}}^{k+1}}{\partial u_{m_{k+1-n}}^{k+1-n}} \frac{\partial u_{m_{k+1-n}}^{k+1-n}}{\partial u_{m_{k-n}}^{k-n}} \qquad(3.6)$$
```

The subexpressions in Equation (3.6) are calculated from the partial differentiation for the $m$th and $k+1-n$th layers. $\frac{\partial u_L^{L+1}}{\partial u_j}$ is calculated by setting $k=L$ in Equation (3.6) and repeating the calculation by increasing $n$ from 0 to L.
