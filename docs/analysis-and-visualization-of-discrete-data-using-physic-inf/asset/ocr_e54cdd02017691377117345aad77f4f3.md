# 1.1.9. Introduction of PDE derivation with Excel

This section introduces how to use data analysis (regression analysis) in Excel to derive a PDE from the given data; detailed operations will be described in subsequent sections. Regression analysis is a method of analyzing the degree of impact (weight) of two or more explanatory variables on an objective variable. As a concrete example, consider a model that describes the annual sales of a restaurant. Each restaurant corresponds to a row in Excel. In each row, enter annual sales (unit: 10,000 yen), the number of seats (number), walking time from the nearest station (minutes), and presence/absence of breakfast (0, 1). The regression analysis tool allows you to easily create a formula that explains annual sales by adding a weight to each of the following explanatory variables, and an intercept: Number of seats (number), walking time from the nearest station (minutes), and presence/absence of breakfast (0, 1) (Figure 1.10).
