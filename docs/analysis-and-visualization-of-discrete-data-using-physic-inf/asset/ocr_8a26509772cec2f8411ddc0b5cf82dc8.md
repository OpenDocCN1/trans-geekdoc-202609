Specifically, the inputs of the neural network are the spatiotemporal variables $(x, y, z, t)$ and the outputs are the corresponding dependent variables $(u)$. Neural networks are used to predict output variables from input variables. The loss function is the mean squared error (MSE) of the difference between the predicted output and the true output. The Adam (Adaptive Moment Estimation) optimizer is used as the optimization method and the weights and biases are updated for the specified number of iterations. Adam is a kind of optimization method using gradient descent. Adam is a technique that combines features such as learning rate tuning and momentum exploitation and is widely used in deep learning training.
