The PhysicsInformedNN_extend class defines a neural network for deriving the 3D advection-diffusion equation. Specifically, the initialize_NN method initializes the weights and biases, and the net_u method computes the output of the neural network. Also, the net_f method computes the time and space derivatives of the output. As explained in Chapter 3, TensorFlow has a tf.GradientTape API for automatic differentiation, i.e., computing the gradient of the computational result with respect to the input variables. TensorFlow “records” on a “tape” all operations performed within the context of a tf.GradientTape. TensorFlow then uses that tape and the gradient associated with each operation recorded on it to compute the gradient of the “recorded” computation using top-down automatic differentiation (reverse mode).
