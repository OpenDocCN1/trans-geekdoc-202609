K-means clustering is an unsupervised machine learning algorithm that finds a rule to group similar data.

```
$J(V) = \sum_{i=1}^{c} \sum_{j=1}^{c_i} (||x_i - y_j||)^2$
```

where, $[x_i - y_{jk}]$ is Euclidean distance between $x_i$ and $y_j$, $c_i$ is the number of data points in $i^{th}$ cluster, 'c' is the number of cluster centers.
