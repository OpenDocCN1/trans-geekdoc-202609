# 3 PROPOSED METHODOLOGY

+   - The Approach to the project would begin by clustering the areas in the target location based on the latitude and longitude coordinates.
- Using the Unsupervised Machine Learning technique: K-Means Clustering and Elbow method, the least optimal number of clusters is found and agreed. The K-Means algorithm identifies number of centroids and allocates every data point to the nearest cluster, while keeping the centroids as small as possible.
- User's location is accessed via the Geo-location API through which co-ordinates are obtained of the host.
- Based on the latitude and longitude coordinates obtained, the user is identified to which cluster he/she belongs to by taking the distance as the metric in order to make the best classification of the cluster for its representation.
- The Bangalore venue data is cleaned, pre-processed and stored after handling the missing data and inconsistent values.
- On the basis of the location aware recommendation system, the user is provided with recommendations. For this Hybrid Recommender system: Top K recommendations and Collaborative Filtering is used as the tool.
- API's are used to provide the user details with regard to the brief overview, the timings of the place, reviews. For this, GooglePlaceID and Google Place API are used.
- In addition, Weather API – RapidX API fetches real-time weather details of the place based on location's coordinates.
