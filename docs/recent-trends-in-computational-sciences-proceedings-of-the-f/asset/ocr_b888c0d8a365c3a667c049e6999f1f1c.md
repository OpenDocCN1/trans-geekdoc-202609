# 3.4 Performance evaluation metrics

The performance of the different ML and DL methods were evaluated using three metrics namely, accuracy, sensitivity and specificity. These metrics are computed from the confusion matrix (Figure 4) using the True Positive (TP), False Negative (FN), False Positive (FP) and True Negative (TN) values using Eqns (1)-(3).

```
Accuracy (%) = \frac{TP + TN}{TP + TN + FP + FN} \times 100
Sensitivity (%) = \frac{TP}{TP + FN} \times 100
Specificity (%) = \frac{TN}{TN + FP} \times 100
```
