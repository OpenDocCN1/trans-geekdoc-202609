# 3.2.1.5 Random Forest Classifier

Random Forest is a classification algorithm based on ensemble learning and supervised machine learning. It uses multiple decision trees internally to make classifications. In a random forest classifier, each internal decision tree is a weak learner, and the final prediction is obtained by combining the outputs of all the weak decision trees, typically by taking the mode of all the predictions. In summary, the random forest works as:

+   1. Fix the k side effects from data (clinical data) the sum of m manifestations arbitrarily (here k << m). At that point, it assembles a Decision tree with the help of side effects of k.
2. Reshashes n times with goal with that we have n of decision tree worked from various random mixes of indications which is denoted as 'k' (or alternate example of information, known as bootstrap forest).
3. Consider every one of the n-constructed trees and proceeds a variable which is random to forest the illness. Here k that anticipated illness, so that we can have a sum of n illness anticipated from n of the decision tree.
4. Computes the decisions in factor for each anticipated illness and consider the mode (which is most continuous illness anticipated) as expectation from the Random Forest model calculation

# 3.2.1.2 Support Vector Classifier

The Support Vector Classifier is a type of machine learning algorithm that is used for classification tasks. It tries to find an optimal hyperplane in hyperspace that separate the samples into different categories with maximum possible margin between the decision boundary and the data points. The hyperplane that chosen by the algorithm is the one that can best classify the samples into their respective categories. This makes the Support Vector Classifier a powerful tool for solving classification problems, especially when the data is complex or high-dimensional.
