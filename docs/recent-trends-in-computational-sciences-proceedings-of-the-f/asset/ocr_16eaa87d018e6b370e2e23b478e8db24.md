# 3.7 Beacon events view

This view's prime operations are created, read, update and delete by the admin. It includes the Beacon entry Component has the members – ID, UUID, Description and URL describing the beacons.

The following functions are defined and invoked to perform the admin operations.

+   - getEntries: This function is invoked to display the updated list of beacon entries present in the database on the admin web. This function is called when the admin wishes to edit the details of any beacon entries. The edit flag is true. The alterable attributes are ID, UUID, Description and URL describing the beacon.
- showError: This function selects the beacon entry from the database and updates the list view with the updated list of beacon entries from the database.
- onSubmission: On the beacon entry form submission, the function checks for any empty or invalid fields and shows error messages. If the edit flag is true then the existing beacon entry is updated, else a new entry is created.

# 3.8 Android application

Android application of the system comprises of two components Transmitter and Receiver. The Transmitter component contains the following functions:

+   - onRequestPermissionResult: Requests Bluetooth connection to execute the application. The Beacon ID and Shared Preferences are initialized. The UUID of transmitter beacon is displayed in Beacon ID view component. Shared Preferences are utilized to obtain Bluetooth related information from the mobile device.
