# Securing crime case summary and E-FIR using blockchain concept

Tamuja Kayaraga
VVCE, Mysore, India

C.V. Kavitha, P. Lokamathe, M. Yamuna & M.S. Meghana
Department of CSE, VVCE, Mysore, India
ORCID ID: 0000-0001-5818-3055

ABSTRACT: Electronic First Information Report (e-FIR) is a basic document filed to the police stations by a victim or on his/her behalf when a cognizable offense such as murder, kidnapping, rape, theft, etc. is committed. In the E-FIR database, the offense’s record can be compromised due to its centralized nature, and further the intentional registration of false e-FIR can occur. In this paper, e-FIR data integrity and false registration appended with police stations in a centralized database are addressed via a consensus-based distributed blockchain solution, as an integral part of a smart city environment. Specifically, a smart contract based framework has been utilized to explore the performance of Ethereum blockchain in providing integrity to e-FIR data stored in a police station’s database. Local database is interfaced with Ethereum blockchain using Web3 Remote Procedure Call (RPC) protocol. Multiple simulations have been performed to evaluate the performance of the proposed framework. Our results show a trade-off between different hashing algorithm security level for the offenses data and number of transactions stored in a single block on blockchain ledger.

Keywords: e-FIR, technology, Blockchain
