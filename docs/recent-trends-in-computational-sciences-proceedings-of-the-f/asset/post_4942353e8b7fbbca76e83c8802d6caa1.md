## 3.1 User module

This includes the operations that a user can perform with the system. It helps to know what all tasks a user can perform and view. It includes the beacon receiver, view calculated distance and viewing the location image.

- Beacon Receiver:
This is the application installed in the user's device which acts as a receiver of the beacon signal. When a transmitter is recognized, this application displays the necessary details to the user.

- Calculated Distance and Location Image:
This is a block in the user interface displaying the distance calculated from the transmitter to the receiver and the location where the user is in. In a map is displayed on the user interface.

## 3.2 Beacon module

This includes all the Bluetooth devices involved in the indoor positioning system. It consists of the beacon receiver and the beacon transmitter devices.

- Beacon Transmitter:
The beacon transmitter is used to transmit radio signals so that the receiver receives the signal and the wanted information. Here, we use android devices as the beacon transmitter.

- Beacon Receiver:
The beacon receiver is the one who detects the signals from the transmitter. The beacon receiver is present in the user module as well as the beacon module.

## 3.3 Admin module

The admin is a vital part of the system. The admin details are present in the database and authenticated individuals can only access the portal. This includes a web view where the admin is allowed to enter user's ID, location URL and description. The user is also allowed to edit and delete the beacon entries. The beacon transmitting signal will be recognized by the receiver if only the transmitter ID is entered by the admin and present in the cloud database.

## 3.5 Indoor navigation system

The system's first component is the Cloud Database where the beacon's information such as UUID, Description, URL are stored.

### 3.5.1 Admin module

- The module fetches the username and password from the cloud database.
- This is required to perform a validation on the user interface and allow admin to log into the web application.
- After login, the admin can create, edit, delete beacon entries which are stored and updated in the database.

### 3.5.2 Beacon module

- The module uses database to make API calls and fetch the required destination image.
- The transmitter broadcasts the required image device via Bluetooth. The response is received by the receiver and displayed on the screen.
- The receiver can receive multiple advertised messages from transmitters. The distance from the user is displayed as a list view.

## 3.6 Web application

Web Application of the system contains two components: Login Module and Beacon Entries View. The Login Module includes the Login Component which consists of the username and password. Attributes are stored in the cloud database. This module also includes validation checks for the members. The function includes:

- Verification of the fields that were entered. When the status is successful, the session begins and admin is directed to the beacon entry page.
- When the status is unsuccessful, appropriate errors are notified.

## 3.7 Beacon events

View operations are created, read, update and delete by the admin. Beacon entry includes ID, Description and URL describing the beacons. The following functions are defined and invoked to perform admin operations:

- getEntries: This function is invoked to display the updated list of beacon entries present in the database when the admin wishes to edit the details of any beacon. The edit flag is true. The attributes are ID, Description and URL describing the beacon.
- showError: This function selects the beacon entry from the database and updates the list view with the beacon entries.
- onSubmission: On beacon entry submission, the function checks for any empty or invalid fields and shows error messages. If the edit flag is true then the existing beacon entry is updated, else a new entry is created.

## 3.8 Android application

Android application of the system comprises two components: Transmitter and Receiver. The Transmitter component contains the following functions:

- onRequestPermissionResult: Requests Bluetooth connection to execute the application. The Beacon ID and Shared Preferences are initialized. The UUID of transmitter beacon is displayed in Beacon ID view. Shared Preferences are utilized to obtain Bluetooth related information from the mobile device.
- initObjects: A condition is made to see if the Bluetooth is enabled. If not, the Settings screen is displayed. A function is called through Shared Preferences to obtain an existing Beacon ID. If ID is empty, a random ID is generated and set to Beacon ID view.
- transmitBeacon: A beacon object is retrieved from Beacon library. The value of UUID is set as beacon ID which is obtained from Shared Preferences.
- startAdvertising: Instructs the beacon transmitter to transmit the advertising message. The advertisement image which the transmitter has to broadcast is obtained from the cloud database.

The Receiver component contains the following functions:

- onRequestPermissionResult: To operate the application, permission to enable Bluetooth connection is requested.
- initObjects: A RecyclerView View is initialized to display a list of transmitter beacons. Text Message view is set to alert the user that the application process is fetching beacons.
- initRecyclerView: The Adapter for RecyclerView is configured when hidden. The RecyclerView View displays the data which is fetched from the API calls and automatically updates it on the screen.
- initState: When a response is received, the API calls are executed again and the screen is updated if any incorrect response is received.
- getBeaconEntries: The Transmitter Beacon information as description and advertisement message is fetched through an API call using transmitter ID as a parameter. If an empty response is received, an appropriate message is displayed on the screen.
- setLoading: Until a response from the required API call is obtained, a loading page is displayed on the screen to keep the user informed.
- monitorBeacons: Bluetooth Settings screen is displayed if Bluetooth adapter is not enabled. If there is no beacon advertising advertising messages, an appropriate message such as ‘Scanning for beacons’ is displayed on the screen. If Text View is set to null, the response is shown using RecyclerView View. Each list item in the RecyclerView contains distance from the transmitter, advertising image and other transmitter information.
- onClickListener: The destination image or the advertising image received from a particular beacon is displayed when a list item is tapped by the user.

## 4 RESULTS

The system includes two android applications, one which acts as a beacon (transmitter), the other which acts as user application (receiver). It also includes web application for the admin and a cloud database. The receiver captures the signal only if the transmitter beacon information is already present. If not, a randomly UUID is retrieved from the database and displayed on the screen, which admin can subsequently add to the database. The transmitter beacon broadcasts the advertising message. The receiver application receives the advertised information from the transmitter. The location image with the calculated distance is shown in the form of a list view. Upon listing the item, the user can edit.
