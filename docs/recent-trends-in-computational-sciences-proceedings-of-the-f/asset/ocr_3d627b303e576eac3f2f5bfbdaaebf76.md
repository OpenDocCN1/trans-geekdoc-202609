ABSTRACT: Pandemic bringing a change in the medical system and medical data collections and storage. In such a scenario there a requires to be a system that enables the efficient transport of a patient to a distant hospital with minimal human support. In such remote telehealth service, the inclusion of a system which is capable of sending and receiving medical data like image of patients, X-Rays and multimedia images would result in better and fast pre-hospitalization. In emergency situation, the contention has to be balanced between the ambulance and the doctor in the least possible time. An efficient image compression algorithm will ensure the faster communication. The proposed framework is a combination of mobile application an interactive OpenTok API, cloud based platform Heroku and Firebase. The proposed system ensures a dedicated high speed data sharing environment based on cloud and mobile API to make an interactive framework for Healthcare industry.

Keywords: Remote telehealth, Image compression, Cloud computing, LRJPEG, OpenTok SDK

# 1 INTRODUCTION

Cloud computing is a model for enabling convenient, on-demand network access to a shared pool of configurable resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider. A ‘cloud’ is a collection of resources (e.g., CPU, storage) which are provided as utilities that the user can request and access through the internet or on demand fashion. 75% of the cloud comprises of data ice., cloud mostly comprises storage. This helps the client to access his/her data whenever he/she wishes to do so. This reduces the complexity of storing the client’s data without another computer or storing valuable data on the cloud.
