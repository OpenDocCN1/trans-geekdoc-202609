#  4.3 Web interface

Initially, the users will be shown a landing page from which they can redirect to the home page where a brief introduction about the system can be found. If they are a new user, they can sign up, else they can log in.

Once they log in, they will be redirected to their respective profile page i.e., based on their user type which is student, admin, or recruiter. Accordingly, a different page will be rendered for different user type.

The admin will be able to upload the certificate along the student details as shown in Figure 3(a) as SRN, College name, document description, and the Document to be uploaded.

Once the transaction is sent through the Polygon Mumbai Testnet, the document will be uploaded and will be available to view and download them. The details of the individual transaction can also be verified on the polygon official website by entering the transaction id as displayed in Figure 3(b).
