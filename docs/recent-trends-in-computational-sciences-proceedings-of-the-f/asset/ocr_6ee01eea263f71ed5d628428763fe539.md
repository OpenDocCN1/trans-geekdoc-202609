The offline working of the application requires cache memory. The Access-Mode should be ServerAndCache mode. The application must be first run in the presence of internet to store the location of every coordinates. It also stores the location of nearby places that show on the map tiles. For offline usage of the application the desired places must be first run in the presence of internet where map location is stored in the memory and can be accessed offline. For offline usage, the application works when the AccessMode is ServerAndCache mode or CacheOnly mode. It must be noted that during the initial run, the AccessMode must be ServerAndCache mode only. For large requirements of data, larger cache memory may be required. Larger memory efficient systems with higher capacity Central Processing Units would be used.

# IMPLEMENTATION

We implemented and tested both these applications as part of our internship programme in a private organization located in Bangalore, Karnataka, India which provides digital tools to help traffic police of Karnataka.

This helped the police patrol to track the culprits who violated traffic rules and help the public. Our application benefited the department immensely to get a comprehensive coverage of address point data with the help of coordinates. This allows users to take advantage of a number of location based benefits.

Any organization which controls the fleet of vehicles needs a system that can keep track of where each unit is at any given time. The geographic coordinates convert data into a human readable address on the map on the exact location. This is the greatest advantage of Reverse Geocoding.
