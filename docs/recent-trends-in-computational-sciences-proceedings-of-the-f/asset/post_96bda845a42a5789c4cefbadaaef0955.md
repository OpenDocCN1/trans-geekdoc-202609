## 3 TOOLS USED IN THE DEVELOPMENT

### 3.1 LRJPEG

A luminance based method for JPEG-LRJPEG is an algorithm which helps us to compress an image without the loss. The algorithm calculates the CR(Compression ratio), PSNR (Peak signal-to-noise ratio) and MSE(Mean squared error). Compression ratio(CR) is the ratio or the amount of compression that has occurred. CR has been calculated in order to analyse the changes in the image sizes to analyse the efficiency of the system. PSNR and MSE are two error measures used to evaluate the quality and performance of image compression. MSE shows the cumulative squared error between the original image and the compressed image, while PSNR shows the peak error measure.

### 3.2 Firebase

Firebase can be called a BaaS(Backend as a service). Any BaaS enables developers to stop worrying about managing the server or the backend API. This enables the developer to focus on improving the user experience. In short, Firebase enables the developer to design and develop the apps quicker. Firebase offers many functionalities like Authentication, Cloud functions, Database, File Storage, Cloud messaging. In messagingAll these features are integrated with the Gmail account. When we make all of these features, we can develop and deploy an efficient application. Firebase also gives the developer in depth analytics and statistics of their application growth.

### 3.3 OpenTok SDK

OpenTok SDK is developed and maintained by TokBox Inc. They are a PaaSPlatform as a service based company. The server side SDKs and client side SDKs maintained by TokBox enables us to integrate live video calling into your application without focusing on the backend server. OpenToksWebRTC supports Android, Javascript and IOS. The basic services of OpenTok are free by the company. However the advanced features like video calling would require payment.
