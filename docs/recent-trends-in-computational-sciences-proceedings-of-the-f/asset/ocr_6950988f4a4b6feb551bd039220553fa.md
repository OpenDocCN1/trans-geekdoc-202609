# Real-time CAPTCHA using hand gesture recognition for highly secure websites

Lasya Priya, Beru Neha, B. Vivek Sai Chinna, Sai Raju Reddy Balireddygardy & K.N. Divaprabrah

Department of Computer Science, PES University, Bangalore, India

ABSTRACT: Completely Automated Public Turing Tests to Tell Computers and Humans Apart (CAPTCHAs) are almost now a security measure which protect against unwanted and malicious programs on the Internet. There are several security threats on websites and it would be a major risk to nation defense websites or other classified material were exposed. Several algorithms are in place to solve CAPCHAs automatically. The true definition of CAPTCHA is that it must be able to determine that humans, computers, are attempting to get into a password-protected account. Our work provides an efficient and highly secure alternative to classic CAPTCHA. The objective is to essentially device a two-step “bot-proof” authentication with camera access as a requirement. According to studies, implementing Multi-factor authentication makes a specific account 99.9% less likely to penetrated and similarly building a two-level CAPTCHA would ensure the security of the user beneath. The first level involves a CAPTCHA and in the second level, a new CAPTCHA technique recognizes hand gestures in real time aids in preventing the possibility of breaking by attackers. Hand gesture detection was first implemented using Support Vector Machine (SVM) and improved with Convolution Neural Network (CNN). Finally, Mediapiece assisted and produced fast and accurate results in real time. The authentication will be guaranteed to the website if the human performs the task successfully in the second level.

*Keywords*: Hand Gesture Recognition, SVM, CNN, Mediapiece, Web Security

# INTRODUCTION

This work proposes a simple, real-time and efficient two-step bot-proof process of authentication. The complete architecture of our work is shown in Figure 1. The user needs to first login to the website and enter the credentials correctly. Text-based CAPTCHA [1] is used in the initial authentication to differentiate harmful bots from people. Background interference, noise levels, and geometric modifications are just a few of resistance mechanisms that are added to CAPTCHA in order to increase security. To make it harder, the alphabets and numbers are distorted and rotated. The computer generates a string of characters. The user must submit an identity that matches the computer-generated string to advance to the next level. The user has two attempts to enter the right identity; failing to do, access to the website will be denied. However, all protection systems have been dismantled thanks to the development of deep learning algorithms. The text-based CAPTCHA’s security is frequently shielded by several mechanisms to hinder machine recognition [2]. Most prior attacks against text ChatGPTAs [1] have used a three-step strategy: pre-processing, segmentation and recognition. Thus, the introduction of second level hand gesture recognition.
