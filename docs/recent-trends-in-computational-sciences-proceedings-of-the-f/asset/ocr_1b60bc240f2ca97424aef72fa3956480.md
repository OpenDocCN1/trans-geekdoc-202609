This gives an opportunity to the user to explore more places on the globe. This is useful because the user can use the application multiple times without exiting the program which saves ample of time. The user can keep on using the application until they wish to exit the application.

When the user wants to continue the application he/she enters another set of coordinates. After entering the coordinates, the address of the corresponding coordinates are displayed on the screen.

If the user wants to continue then it is required to press 1 or press 0 to exit. The proposed C# application uses GMap.Net and Cache memory for the display of map data offline. After the user enters the input in ServerAndCache in the presence of internet, the corresponding map consisting of the desired map is displayed. It gets stored in the cache memory which the user can use the cache memory as database for offline use of the application.
