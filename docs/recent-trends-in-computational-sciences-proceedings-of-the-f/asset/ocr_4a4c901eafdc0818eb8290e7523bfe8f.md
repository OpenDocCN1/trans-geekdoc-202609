# 3.6.2 Association rule mining

We then mine association rules, a rule-based machine learning method for discovering relationships between items in transactional databases [8]. We used the metric of ‘confidence’ to filter out our association rules.

Rule: X ⇒ Y ... (i)
Support: (Frequency (X, Y))/N... ... (ii)
Confidence: (Frequency (X, Y))/(Frequency(X)) ... (iii)
The highest confidence rule was (Pasta) -> Pizza, with a confidence of 0.51, closely followed by (Pizza) -> (Pasta) with a confidence of 0.483.

The association rules of (North India, South India) -> (Chinese) and (Chinese, South Indian) -> (North Indian) signify a common trend in many restaurants in Bangalore, to serve snacks/meals from all three cuisines simultaneously. Therefore, if any of the three cuisines are present, there is a high chance that dishes of the third cuisine will also be served in Figure 3.

# 3.6.3 Clustering

Clustering algorithms are popular unsupervised learning techniques to find patterns in datasets. It works on distance or density-based methods which imply that the similarity in the data enters the deciding factor for cluster an entry belongs to. Data points are grouped based on similarity. In this project, we try to cluster restaurants based on the said attributes. Two popular clustering techniques, namely K and DBSCAN have been implemented in this project. Many companies use similar methods for recommender systems for their services.

# 3.6.31 k-means clustering

k-means is a distance-based clustering algorithm. Euclidean distance is used as the metric to measure distance between data points. K refers to the number of clusters into which the data will be clustered. First, k data points are taken as the centroids for clustering the data. Then all data points are segregated according the euclidean distance from each centroid [9]. Given that there are 51,104 data points in our dataset, we used a k value of 1000 to get clusters whose size are approximately 51. A random state of 0 has been used.
