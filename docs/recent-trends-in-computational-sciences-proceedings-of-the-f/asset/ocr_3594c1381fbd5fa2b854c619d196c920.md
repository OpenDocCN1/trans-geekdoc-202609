From the input fruit photos, the suggested model distinguishes between fresh and rotten. Apples, bananas, and oranges are the three types of fruits in this project. used to categorize the input fruit image into fresh and rotten fruits, and a convolutional neural network (CNN) is used to extract features from the input fruit image.
