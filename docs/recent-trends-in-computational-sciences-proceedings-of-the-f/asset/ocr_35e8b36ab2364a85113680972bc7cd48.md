# 5 CONCLUSIONS AND FUTURE WORK

Real-time vision-based hand gesture identification is one of the most challenging research issues in the field of human-computer interaction. An effective Hand Gesture CAPTCHA system was proposed and implemented. In this method, a form containing a CAPTCHA image of hand gesture from the database was displayed with a message asking the user to copy the gesture. The user then made a gesture in front of the systems camera out of conscience, and the model checked to see if it matched the gesture in the image or not. It is impossible for the robot to learn how to copy the identical move as displayed in the image on its own, using this approach would secure the identification of the user.
