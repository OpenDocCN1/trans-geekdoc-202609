In [5] the author proposes an efficient method to handle the traffic and balance the workload between multiple nodes consisting of a large number of computers. The author proposes an algorithm with four modules. The first module is coordinator algorithm which collects status of all the nodes in the network. The second module is data phase which calculates the weights for each node after receiving the data from the server. The third module is load balancing which checks if the nodes are already loaded with the processes or not. They identify the ones and the heavy loads. The fourth module is data migration which transfers the processes from the heavily loaded node to the node with less load in it. This will increase the performance as the loads are evenly distributed across the network.
