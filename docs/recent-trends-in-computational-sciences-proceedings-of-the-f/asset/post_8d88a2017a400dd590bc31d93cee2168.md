## 2 LITERATURE SURVEY

The emphasis of most ASD studies is on genetic factors. In a study by V. Pream Sudha and M. S. Vijaya [2], Support Vector Machine (SVM), Decision Tree Classifier and Multilayer Perceptron (MLP) were utilized. They linked various disorders, monogenic illnesses and pathogenic mutations. SVM accuracy was 0.96, MLP accuracy was 0.95, and Decision Tree accuracy was 0.98.

Support vector machines (SVM), K-nearest Neighbours (KNN), and Random Forest machine learning algorithms are used by A. Demir [3] to evaluate ASD adolescent scan data to quickly and accurately diagnose the ASD status. With 10-fold validation (CV) using SVM, KNN, and RF techniques in respective accuracy rates of 95%,99%, and 100%. This method utilizing automated screening for ASD, classification with the RF approach may successfully identify ASD patients.

Using classification techniques, M. S. Mythili, A. R. Mohamed Shanavas [4] conducted a study on ASD. The paper's primary goals were to identify the problem and degrees of autism associated with it: SVM, Fuzzy, and WEKA tools are utilized in their neural network to study the social interaction and behavior of the students.

Using levels of assessment, an interactive framework is presented by Khondaker et al. [5]. It first screens the children through a questionnaire via mobile application. If suspected, a window is displayed, and the child's responses are captured and sent to the remote format expert. Upon such report, the child is directed to the nearest Autism Resource Center (ARC) for an actual assessment.

The major purpose of the research by Aishwarya et al. [6] is to construct an autism screening tool for detecting ASD in children and young adults under the age of three. Using the AQ-10 dataset (1054 instances), the suggested model can reliably diagnose autism with 92.28%, 96.20%, 100.00%, and 79.14% for the Decision tree, Random Forest, Adaboost and SVM algorithms, respectively. The results showed that the Random Forest and Adaboost algorithms excelled.

## 3 IMPLEMENTATION

The screening system is built on a web application with 10 questions to answer, along with other parameters such as age, sex, ethnicity, medical history of the child, and family history of autism. The user can select three algorithm options – Logistic Regression, K-Nearest Classifier, and Decision Tree. The front-end is built using react.js and deployed on Vertex, while the back is built using Flask and hosted on Render. The response is sent back to the user as a prediction. Two databases are maintained – one is a CSV file containing data used for prediction, and the second is a scikit-learn library NoSQL database that stores all the requests received by the backend.

### 3.1 Data collection
The dataset used in this study was collected from Kaggle repository [8]. The actual dataset was compiled by Adi Fayez, who has multiple papers in the relevant field of Machine Learning and Autism mobile application. The dataset includes information on ten traits as well as individual traits that proved to be effective. The dataset had 1054 instances and 18 attributes (including the class variable).

### 3.2 Data pre-processing
Pre-processing entails putting raw data in an understandable and meaningful structure. Real-world data is frequently inconsistent and lacking null values. Well-processed data always results in positive results. However, some of dataset's features like 'Sex', 'Ethnicity', 'Family_history', 'Class_Traits' were of categorical type. These categorical features were converted to numeric using LabelEncoder() from the sklearn library for better analysis and machine learning purposes.

### 3.3 Load-processed data
The processed data was cleaned and converted to a suitable format, the dataset was divided into 80% training purposes and 20% testing purposes. The "Class_Traits" was set as the target variable.

### 3.4 Apply machine learning algorithms
The machine learning algorithms such as Decision Tree, K-Nearest Neighbour, and Logistic Regression were employed. The models were trained and tested in this phase. The goal of using Decision Tree is to create a model that can be used to predict the class value. KNN stores all the available data and classifies a new data point by similarity. Based on independent factors, logistic regression calculates the likelihood that a specific event will occur. The dependent variable's range is 0 to 1 since the outcome is probability. The Confusion Matrix and Classification report were obtained to understand the performance of the models better.

### 3.5 Evaluation of ASD
The trained and tested models predicted the input as Autistic or Not with different accuracies. In the first iteration, we realized that the model considered the "Q-10-Score" attribute, which is aggregate of the values allotted to the options. So, in the second iteration, we decided to drop the "Q-10-Score" attribute and then test the models. The results now displayed allowed us to test real-time data and classify as Autistic or Not-Autistic.

## 5 FUTURE SCOPE

Currently, we have implemented three algorithms. As future scope of development, we can implement multiple algorithms into a single system, which is publicly accessible. A method for user authentication can be implemented, through which we can store the medical reports of the child whose ASD is being predicted. The prediction can thus be verified with the genetically tested reports, thereby increasing the algorithm's accuracy. The API we have implemented is publicly accessible, and this means that anyone can make use of our API to integrate the prediction system into their system. This public access can be restricted to a specific limit and, therefore, will help scale it to more platforms and save more computational power.
