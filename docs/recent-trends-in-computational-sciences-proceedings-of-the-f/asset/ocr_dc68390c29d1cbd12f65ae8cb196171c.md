# 5 FUTURE SCOPE

Currently, we have implemented three algorithms. As future scope of development, we can implement multiple algorithms into a single system, which is publicly accessible. A method for user authentication can be implemented, through which we can store the medical reports of the child whose ASD is being predicted. The prediction can thus be verified with the genetically tested reports, thereby increasing the algorithm's accuracy. Modifications can be made in a way that we are accepting the answers from the user, and it can be implemented in such way that we assign unique scores to each of the options available to the user and normalize it to predict the outcome. This implementation would consider the prominence of the individual options and thus increasing the accuracy of the algorithm. The API we have implemented is publicly accessible, and this means that anyone can make use of our API to integrate the prediction system into their system. This public access can be restricted to a specific limit and, and therefore, will help scale it to more platforms and save more computational power.
