
# 4 IMPLEMENTATION

## 4.1 Dataset

Dataset is collected from Kaggle [16]. This dataset is used for Telco customer churn. This dataset has 21 features includes Customer ID, Gender, Senior Citizen, Partner, Dependents, Tenure, Phone Service, Multiple Lines, Internet Service, Online Security, Online Backup, Device Protection, Tech Support, Streaming TV, Streaming Movies, Contract, Paperless Billing, Payment Method, Monthly Charges, Total Charges, Churn. Here Churn is the prediction class.

## 4.2 Data preprocessing

Our dataset is categorical so it should be converted to numeric to be able to process. First, we remove the Customer ID column as it is not useful because all records have unique values. We remove records with empty fields. The field “No internet service”, “No phone service” into “No”. All the columns with “Yes” or “No” values can be converted to binary values. “Yes” value can be changed to “1”. In the gender column, female is changed to “1” and male to “0”.

The columns Internet Service, Contract, and Payment Method which have three class values are manipulated and turned into dummy indicator values for the tenure. Monthly Charges, and Total Charges are scaled using a MinMax Scaler, a dataset with a total of 7032 records with 27 features is generated. But this preprocessed data is imbalanced. Records with churners are very less compared to nonchurners. This dataset can't be used for training our neural network models as it leads to overfitting problems.

## 4.3 Handling imbalanced data

To tackle imbalanced datasets there are techniques like oversampling and undersampling. In this case, oversampling technique called Synthetic Minority Oversampling Technique (SMOTE). The SMOTE algorithm can be applied to solve overfitting problems. SMOTE generates more samples to the dataset [4]. This paper implements SMOTE by imbalanced learning library (imblearn) [17]. After application of SMOTE, the dataset will have a total of 10326 records.

## 4.4 Training and testing

Our first model is trained using imbalanced data. Our second and third models use SMOTE Dataset split into training and testing sets in ratio of 4:1 (80% and 20%). This testing set from balanced dataset is used to test all the models. First and second neural network models have the same structure. They have three hidden layers. Rectified Linear Unit (ReLU) activation function is used by Input and hidden layers. Sigmoid activation function is used in the output layer. We use a Dense layer from Keras. Third model has only one hidden layer with 50 neurons. Input and hidden layers use Rectified Linear Unit (ReLU) as activation function. The Output layer uses sigmoid activation.

# 5 RESULTS AND DISCUSSIONS

All three models have been trained for 100 epochs. And then all models are given a testing set to predict. The predicted sets from all models are taken and considered in ensemble model. The predictions from all models are used as votes and the most popular vote is considered as the prediction of ensemble model.

# 6 CONCLUSION AND FUTURE SCOPE

In this, paper aimed to perform churn prediction and used an ensemble of three neural network models. Even though the dataset used is a telecom churn dataset, the proposed model can be used over any churn dataset. So any sector can use this in their customer relation or behavior analyses. Ensemble learning considers every constituent model. These constituent models are important. In all, the constituent models are based on neural networks. This paper shows over telecom churn dataset. Accuracy was to be 84% and the least difference between accuracies of ensemble and constituent models is 6%. This 3% difference is the improvement by proposed ensemble method. In Future networks used be be optimized and can use more models to form ensemble models. Data is very important in churn prediction. Working with proper datasets can provide a positive level of results.
