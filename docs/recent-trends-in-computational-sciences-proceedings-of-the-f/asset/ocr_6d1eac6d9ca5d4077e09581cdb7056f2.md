# 3.1 Data collection

The dataset used in this study was collected from the Kaggle repository [8]. The actual dataset was compiled by D.Fadi Fayez Thabht, who has multiple papers in the relevant field of Machine Learning and Autism to his name. This data was collected by Tabah F. utilizing a mobile application for diagnosing ASD [7]. The dataset includes information on ten behavioural traits as well as additional individual traits that have proved to be effective in detecting the ASD cases from controls in behaviour science. The dataset had 1054 instances and 18 attributes (including the class variable).
