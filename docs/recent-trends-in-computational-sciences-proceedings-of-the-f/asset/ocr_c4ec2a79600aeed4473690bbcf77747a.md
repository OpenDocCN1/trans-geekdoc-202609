Figure 1. The normalized capacity, CC/B, at the SC receiver output for variable parameters $k$, $\mu$, and $L$.

When the $\mu$ parameter increases, the CC increases and the system has better performances. When the $k$ parameter increases, the CC increases the SIR decreases, and the system performance gets worse. The system has the best characteristics with the number of input branches $L$, as can be seen from the picture.

If we compare the obtained values, we notice that the biggest improvement is achieved for enlarging the number of input branches from 2 to 3. Further increase makes the system more expensive without much economic justification in terms of improved performance.

# 3 ADOPTING QUANTUM MACHINE LEARNING FOR QOS PREDICTION

Predictions enabled to make machine learning models among key enablers for many innovative scenarios like proactive adaptation and infrastructure maintenance to Enhance Quality of Service (QoS) perceived by the end users, which comes to latest generation wireless and mobile networks [16]. In this paper, a method aiming-based classification along other factors as input. The emergence of re-scaled quantum mechanics has brought various advantages with respect to traditional techniques, including both the processing time reduction due to faster quantum-based linear algebra operations and also greater effectiveness of predictive modeling use of higher-dimensional feature spaces that increase with prediction accuracy [17]. In this paper, it is leveraged for QoS level estimation making use of consumer product prediction.

In Figure 2, the following workflow for network planning and simulating quantum machine learning is illustrated. First, users draw smart mobile network diagram within graphical user interface in web browser, whose structure is defined by metamodel from [16]. Additionally, value of CC is calculated using relying-grade GPU hardware NVIDIA CUDA kernels [18]. About 67 times speed-up is achieved compared to what Mathematics CC offers general purpose GPU (GPGPU) programming.

After that, the CC values are used as one of independent variables for quantum machine learning learning predictive model. In the last step, base station nodes based on software-defined radio (SDR) are either turned off (existence of anomalies) or on (requesting requests from consumers).
