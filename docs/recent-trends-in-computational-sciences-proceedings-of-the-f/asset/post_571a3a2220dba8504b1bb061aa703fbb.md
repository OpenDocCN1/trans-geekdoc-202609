In order to save, production costs, and production time, this research suggests a method based on recognizing fruits in the agriculture sector. These flawed fruits can impact healthy fruits if we are unaware of. As a result, we suggested a methodology to stop corruption from spreading. From the input fruit photos, the suggested model distinguishes between fresh and rotten. Apples, bananas, and oranges are the three types of fruits in this project. used to categorize the input fruit image into fresh and rotten fruits, and a convolutional neural network (CNN) is used to extract features from the input fruit image. Utilizing the Kaggle dataset, the suggested model performance is assessed. This results in 81% accuracy.
