R. Abhilash and P. Asha adopted web browsers for implementing an Indoor Navigation System. The user opt for the source and the destination places. Using this data, the route map displays all the possible paths to reach the destination from the source [3]. The shortest path among all possible routes and important landmarks is emphasized. Whenever a user request is sent with source and destination data, the route generates the floor map and creates the route with site of the coordinates. The floor map and the route are created with the site area of the given, the routing direction are created which assisting the user [3].

The advantage of this system is that there is no use of internet technologies to create the map and there is no use of the Global Positioning System (GPS) to locate the user's location. Also, the system makes navigation simple by designing it in offline mode [3]. It is difficult for the user to track where they are at a given instance without knowing his/her real time location. This system offers a smooth navigating experience.

As described by Mila Herrera Vargas [4], another way to implement an indoor positioning system is a combination of wireless, positioning and other technologies. An application based on the Wi-Fi API of android is based on the Received Signal Strength Indicator (RSSI) and Base Service Set Identifier (BSSID) of each wireless access point (AP). Fingerprinting is used to compare this radio map to the strength of the Wi-Fi signal received at a random point to assign a pattern of mesh most closely resembles the user.

The advantage of finger printing is that it is efficient and effortless way to get location from your wi-fi infrastructure. The infrastructure can be scaled up quickly. When equipment is replaced or relocated, radio mapping/surveying is no longer valid and everything becomes an annoying issue. In parts of a building where access points have less (especially at the end of a hallway), there is not enough data to determine their location. In these errors often occur when finding a room floor. This approach consumes a lot of electricity, and it is not cost-effective.

M. Sequeira implements short-range radio technology using Ultra wideband [5]. Ultra-wideband (UWB) is a short-range radio technology that can be used for indoor navigation. This technology requires a precision of 10-30 centimeters. This short-range radio technology uses an extremely wide frequency with a bandwidth of at least 500 MHz. UWB works with a low transmission power (0.5 mW / -41.3 dB/MHz) to avoid disturbing occupied frequencies. To detect the signals, we use unique UWB receivers. To measure the running time of light from a transmitter (UWB tag) and number of receivers are determined based on location. Currently, an efficient UWB system is not in the picture. The basic requirement involves installation of antennas of the venue before indoor positioning with UWB can be enabled. For accurate positioning several tags are required. We cannot send enormous amount of data as it is limited by slow-data transmission. UWB signals can hinder the existing lines of communication as it uses a wider bandwidth.
