The CDF of $z_i$ is [11]:

```
$F_{z_i}(t) = \begin{cases} 0 & t \leq 0 \ \frac{1}{e^{\mu K}} \sum_{l_1=0}^{\infty} \sum_{l_2=0}^{\infty} \frac{(\mu K)^{l_1+l_2}}{l_1!l_2!} \frac{\Gamma(i_1+i_2+2)}{\Gamma(i_1+\mu)\Gamma(i_2+\mu)} B(t; \frac{S_{z_i}}{\Omega+S_{z_i}}) & t > 0 \end{cases}$
```

If the Incomplete Beta function $B_x(p,q)$, appearing in previous expression, is presented in the shape of sum 8, [eq. (6)], from [12, eq. (39)], the CDF is obtained in the next form:

```
$F_{z_i}(z) = \frac{1}{e^{\mu K}} \sum_{l_1=0}^{\infty} \sum_{l_2=0}^{\infty} \frac{(\mu K)^{l_1+l_2}}{l_1!l_2!} \frac{(i_1+\mu)^{l_1}(1-\mu)^{l_2}}{\Gamma(i_1+i_2+2)} \frac{(\mu K)^{l_1+i_1}(1-\mu)^{l_2+i_2}}{\Gamma(i_1+\mu)\Gamma(i_2+\mu)} (\frac{S_{z_i}}{\Omega+S_{z_i}})^{l_1+i_1+l_2mu}$
```

The SC receiver output $SIR$ is maximal value of all SIRs $z_i, z = max(z_1, z_2, \dots, z_L)$. Accordingly, the output will have a new PDF as [113]:

```
$P_z(z) = L_z(z)F_z(z)^{L-1} = \frac{2}{L} \sum_{l_1=0}^{\infty} \sum_{l_2=0}^{\infty} \frac{(\mu K)^{l_1+l_2}}{l_1!l_2!} \frac{(i_1+\mu)^{l_1}(1-\mu)^{l_2}}{\Gamma(i_1+i_2+2)} (1-2z)^{i_1+i_2+2L-1} \frac{1}{e^{\mu K}} \sum_{l_1=0}^{\infty} \sum_{l_2=0}^{\infty} \frac{(\mu K)^{l_1+l_2}}{l_1!l_2!} \frac{(i_1+\mu)^{l_1}(1-\mu)^{l_2}}{\Gamma(i_1+i_2+2)} \frac{(\mu K)^{l_1+i_1}(1-\mu)^{l_2+i_2}}{\Gamma(i_1+\mu)\Gamma(i_2+\mu)} (\frac{S_{z_i}}{\Omega+S_{z_i}})^{l_1+i_1+l_2+mu}$
```

# 2. Derivation of the channel capacity

Channel capacity, as one of the most important performance measure of wireless system, is defined as maximum speed at which data can be transferred through the channel [14]. The normalized CC is:

```
$CC = \frac{1}{B} \int_0^{\infty} z \ln(1+z)p_z(z)dz$,
```

where CC is Shannon capacity in bits/s, and $B$ is marked transmission bandwidth in Hz. When the logarithmic function introduced in the following shape:

```
$$\ln(1+x) = \sum_{i=0}^{\infty} \frac{(-1)^{i}x^{i+1}}{i+1}$
```

is used, normalized CC will be:

```
$CC = \frac{1}{B} \int_0^{\infty} \frac{2z}{L} \sum_{l_1=0}^{\infty} \sum_{l_2=0}^{\infty} \frac{(\mu K)^{l_1+l_2}}{l_1!l_2!} \frac{(i_1+\mu)^{l_1}(1-\\mu)^{l_2}}{\Gamma(i_1+i_2+2)} \frac{\Gamma(i_1+i_2+2)}{\Gamma(i_1+\mu)\Gamma(i_2+\mu)} (1-z)^{i_1+i_2+2L-1} \ \frac{(i_1+\mu)^{l_1}(1-\\mu)^{l_2}}{\Gamma(i_1+\mu)\Gamma(i_2+\mu)} \frac{(\mu K)^{l_1+i_1}(1-\\mu)^{l_2+i_2}}{\Gamma(i_1+\mu)\Gamma(i_2+\mu)} (\frac{S_{z_i}}{\Omega+S_{z_i}})^{l_1+i_1+l_2+mu} dr$
```

If the formula with $\beta$ function from [12, 3251] is obtained in (9), the normalized CC is:

```
$CC = \frac{1}{B} \int_0^{\infty} \frac{2z}{L} \sum_{l_1=0}^{\infty} \sum_{l_2=0}^{\infty} \frac{(\mu K)^{l_1+l_2}}{l_1!l_2!} \frac{(i_1+\mu)^{l_1}(1-\\mu)^{l_2}}{\Gamma(i_1+i_2+2)} \frac{\Gamma(i_1+i_2+2)}{\Gamma(i_1+\mu)\Gamma(i_2+\mu)} (1-z)^{i_1+i_2+2L-1} ( \frac{(i_1+\mu)^{l_1}(1-\\mu)^{l_2}}{\Gamma(i_1+\mu)\Gamma(i_2+\mu)} + \frac{(\mu K)^{l_1+i_1}(1-\\mu)^{l_2+i_2}}{\Gamma(i_1+\mu)\Gamma(i_2+\mu)} (\frac{S_{z_i}}{\Omega+S_{z_i}})^{l_1+i_1+l_2+mu} ) dr$
```
