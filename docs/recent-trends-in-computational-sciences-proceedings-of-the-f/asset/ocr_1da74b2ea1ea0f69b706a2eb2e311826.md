ABSTRACT: Computer vision gives us the ability to detect and analyze human actions from images and video. Artificial Intelligence combined with computer vision can be used to perform certain tasks based on the information detected from a video or an image. This paper introduces home automation framework using image processing and computer vision. The work will done derive meaningful gestures of a person from a video and use it to control the appliances. Based on the gesture detected, the corresponding appliance can be controlled or automated. The proposed works on developing a framework where the appliances can be automated based on desired parameters by the user.

Keywords: Microcontroller, Gesture, Arduino, Python

# 1 INTRODUCTION

Automation is the key to progress in any industry. The ability to control and automate the tasks will reduce the time and effort. One such task is the home automation. The controlling of home appliances can be automated according to human needs. To automate the switching of appliances we have Bluetooth, Internet of Things (IoT), smartphone applications. Although all these methods are able to automate home appliances, this paper focus on developing a more effective and efficient alternative solution for the same. The idea of proposed work is developing an automation system in a way that anybody can control the home appliances hassle free by using their hand gestures.
 Automation framework is developed here, which any feature can be added. Through computer vision we be able to detect the hand gestures we need to process in order to get desired and meaningful information. The corresponding appliance is controlled by the gesture detected. There is an interface between computer vision and the microcontroller that controls the appliances. This method provides an ecosystem system inside a house such that anything can be automated as desired by the user.
