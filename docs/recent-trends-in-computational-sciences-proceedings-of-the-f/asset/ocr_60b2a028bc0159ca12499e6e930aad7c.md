+   (B) Experimental setup: The proposed architecture is built in edition-10 following a device configuration of an Intel(R) Core(TM) i5-62500 CPU @ 2.30GHz to 2.40GHz with 50 epochs and 001 initial learning rate value. The Tensorflow version-2.7 is used along with Numpy, Pandas, Keras, and Matplotlib. Adam optimizer is used as an optimization algorithm in this framework [20].
