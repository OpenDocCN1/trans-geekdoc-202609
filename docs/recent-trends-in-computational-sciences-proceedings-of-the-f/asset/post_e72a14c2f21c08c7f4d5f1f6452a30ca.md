
- * Temperature Sensor: Due to various factors during an accident, the temperature of the rider changes abnormally and this can be recorded with the help of a temperature sensor.

# 5 CONCLUSION AND FUTURE WORK

A smart helmet that incorporates the Internet of Things (IoT) technology has been designed to increase the safety of two-wheeler riders. The system is proposed to send alert messages to authorized contacts, which help monitor the safety of the rider. In addition, the helmet features a detector that can identify problems within the system and immediately alerts via messages. The proposed system is expected to improve rider safety by providing automatic detection of issues and sending help messages to peers or nearby police stations through IoT. This enhances rider safety and ensures that prompt assistance be provided if needed.

In future, this technology could be expanded to incorporate an automatic system that includes a key to start the vehicle. This system would also be designed to detect the use of mobile phones while riding and restricted triple riding. These measures can help reduce the number of rider fatalities and improve overall rider safety.
