# NFT minting and order verification in an NFT E-commerce website

Shashwat & Ravi Shankar Pandey

Department of Computer Science and Engineering, Birla Institute of Technology Mesra, Patna Campus, India

ABSTRACT: NFTs or non-fungible tokens are digital assets with identifiable characteristics. NFTs can take the form of digital art, GIFs, videos, collectibles, video game merchandise, music, and even tweets. Uniqueness of a digital asset encompasses more than just visual properties, but also factors as item IDs and hash codes. This means that even though the NFTs are virtually indistinguishable, they have different IDs and codes. In the digital space, these elements are an integral part of an asset's identity as they contain important data about the object's story. The popularity of the Non-Fungible Token (NFT) has grown tremendously since 2020, becoming one of the most popular applications in the Fintech field. However there is still lack of platforms which can provide all the functionality regarding NFTs (including minting, buying and selling) at a single place. This research paper introduces an algorithm for creation of NFTs along ensuring order verification which can be used for the NFTs in an E-commerce website using the MOTOKO language for creation of canisters consisting the order id for order verification and the principal id which serves as a unique token id for the NFT.

**Keywords:** NFTs, blockchain

# 1 INTRODUCTION

NFT stands for Non Fungible tokens. These are digital assets cryptographically recorded on the blockchain which serves as a mark of ownership as the blockchains are highly secure. The blockchain is an open, immutable, distributed public ledger that allows transactions to be processed in a decentralized fashion without the need for a trusted party [1]. The blockchain is extremely secure as the data stored in the chain is not tampered. The blockchain consists of nodes which is a random number generated during mining of block, the data to be stored, the previous hash is the hash value of the previous block and the current hash is the hash value of the current. The previous hash of the first block (called the genesis block) is zero. The value of each hash is generated using SHA 256 hashing algorithm which is highly secure. The current hash is formed by combining the data, and previous hash together. Every new block to added is validated by comparing the hash of the new block with the last block, which is the linking orders. Since the generation of hashes involves the data as, it ensures high security if anyone alters the data of the block, the value of the current will be changed which will disrupt the link.
