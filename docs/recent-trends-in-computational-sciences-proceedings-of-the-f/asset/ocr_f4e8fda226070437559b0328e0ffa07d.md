In the mobile environment, [33] employed an innovative adaptive balancing technique. [34] used History Analysis module to keep track of all tasks executed out in the history, and used this information to find where to schedule the task in the fog. In a fog environment, [35] used a QCI-based neural network for load balancing and maintaining minimum latency in a real-time scenario. According to [36], the author employed fuzzy rules based on predefined priorities, deadlines, and job size. Based on priority, the task is assigned to the device, the dev layer, the fog layer, or the cloud layer. At these levels, the probabilistic neural network is utilised to balance load.

[37] proposed a reinforcement learning-based task scheduling system in a cloud-based scheduler keeps track of the task queue and feeds the status of all tasks to a reinforcement network, which subsequently sends the job to the cloud or the best fog node. [38] used off supervised training and an online unsupervised technique, followed by a multiple regression model. [39] has presented a 'cloud-edge' aware task placement algorithm that makes use of the deep reinforcement learning exploration property.
