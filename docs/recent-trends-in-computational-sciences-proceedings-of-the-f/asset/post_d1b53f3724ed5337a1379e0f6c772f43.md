In the paper [10], soil images are captured using Smartphone and them are measured using K-Mean Algorithm and features of the soil are determined using Hue, Saturation and Value (HSV) color processing. ## 3 METHODOLOGY

India is much rich in cultivation. Soil plays an important role in plant growth. Soil testing is required to obtain proper and equal amount of nutrients from the soil. The model is developed to help the rural farmers to analyse the soil before planting. The system consists of five different sections i.e., Image Capturing, Image Pre-Processing, Image Segmentation, Training System, and Result.

### 3.1 Image capturing

A mobile phone is a good device to capture the soil. In most of the agriculture study, a digital camera is used to capture the sample images but mobile phone is also used to capture the agriculture images. Here, mobile phone is used to capture all the samples and it is stored as soil dataset. Image capturing is done under visible light. The soil images collected manually from Udupi Soil Health Lab about 4000 soil images were collected.

### 3.2 Image pre-processing

In this phase, the system pre-process the input image. It checks the image quality, size, removes the unwanted noise from the image, enhances the brightness of the image and resize the input image into fixed dimensions.

### 3.3 Image segmentation

The features of the image are extracted using HSV (Hue Saturation Value) technique. Hue consists of primary colors (Red, Blue, Yellow) and secondary colors (Orange, Green, violet) that appears in the color circle or color wheel. Color Saturation is the purity and strength of a color. Higher the saturation of a color is more realistic and intense. If the color saturation is low, it is closer to pure grey on the grey scale. Color Value indicates relative darkness or lightness of a color. The color value is assumed based on the amount of light reflected off a surface and absorbed by the human eye. ### 3.4 Training system

A Neural Network is a network with neurons. The dataset contains 4000 soil samples, 80% used for training; 20% for testing. The CNN model consists of various layers as Convolutional layer, ReLu layer, Pooling layer, Fully connected layer.

- a) Convolutional layer. The first step is Convolution layer, the relation between pixels is preserved by the image using various filters will perform operation like blur, edge detection and sharper by applying filters. The convolution layer is called using annConvLayer. ReLu layer-Linear activation as the non-linear operation. The basic need of it is to introduce non-linearity to convert. ReLu provides better performance compared to other linear functions such as tanh or sigmoid.
- c) Pooling layer. In the Pooling layer when images are large the number of parameters is reduced. subsampling and downsampling are also called as spatial pooling, which decreases the dimensionality of every map but only the required information. Pooling works better and takes largest element from rectified map.
- d) Fully-Connected Layer. The final is the Fully-Connected layer also called as dense FC layer. This layer extracts only the important information from the image, with the help of input layer, all the features are combined to create a model. Here, there is one hidden layer and one output layers.

To train the model with training dataset, we use the function: `train(cnn,train_x,train_y,no_of_epochs,batch_size);` where train_x is training data, y is corresponding images, batch_size should be in integer multiple of total no.of training data and, no_of_epochs should be >1 for better accuracy it takes lot of time to train.

To test the model, we use the function: `test(cnn,test_x,test_y);` where test_x is test data, test_y is corresponding values. The process of training is repeated, the training number is reached.
