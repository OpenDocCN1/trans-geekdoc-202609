Non-registration, false registration and integrity of e-FIR crime case summary data are the main concerned problems connected with it. These problems are due to police corruption, inefficiency and lack of accountability, data tapers like Hacker as shown in the Figure 1, e-FIR related case summary data is stored in a central database of police station location, which is shared with the head quarter (HQ) of police station could easily be manipulated by the control of e-FIR summary database within the police station. To address this problem, applying blockchain technology can help us respond to the security challenges and endeavor data integrity, as blockchain is a fraud-resilient, distributed ledger, which can record all the transactions in a Peer-to-Peer (P2P) network.

Blockchain has a decentralized architecture, and its popularity in the cryptocurrency world in securing the distributed data communication is remarkable [8]. In this paper, the major contributions are twofold: First, a blockchain-enabled framework providing sufficient integrity to e-FIR data, which is applicable in, and is an integrated part of, smart city environment. Secondly, false registration of e-FIR is minimized by resolving it through the concept of blockchain. To the best of knowledge, this is a first attempt replacing false registration and providing transparency to e-FIR using blockchain technology.
