# ## CONCLUSIONS

It has been demonstrated via this research that wireless sensor nodes are self-configuring networks because of which some malicious nodes enter the network and cause active and passive attacks to occur. The malicious nodes overwhelm the victim with raw packets during a denial of service attack, or DDoS. The threshold technique, which isolates malicious nodes from the network and detects them, is suggested. The suggested technique enhancement results in an increase in throughput, network longevity and network delay reduction.
