# LITERATURE SURVEY

The objective of paper [1] was a detailed explanation of the blockchain and its applications and the terms related to blockchain, the methodology they used research on the top to down stack of the blockchain technology and uses. The authors in paper [2] have proposed a system that uses the blockchain's immutable characteristics to make it possible to issue digital certificates. The method implemented in paper [3] is validating and verifying a person's birth record. In paper [4] the document is split into multiple uscade data objects, is being provided to the authority. This creates an immutable data object which can only be accessed by the user with the hash key. Block IPFS provides data integrity, and an alternate solution for a decentralized storage. The authors in paper [5] have proposed a blockchain-based identity verification system in which verifying data and the certificate authority plays a crucial role. The system uses Proof of consensus algorithm to verify and upload the document onto the blockchain, which makes it very costly to implement it as will require heavy machinery for the miners to verify the transaction and add it to the blockchain. The system architecture in paper [6] contains two entities, student, and mentor. The student will be given an option to upload the image of the certificates, and will be put on wait for approval response under which the certificate was issued. Upon successful verification, the certificate will be then using md5 algorithm and then added to the blockchain. The drawback with this system is that it requires 3 validators i.e., each time a student uploads a certificate which makes it a very tedious approach for a variety of certificates issued by multiple institutions and and uploaded by numerous students. Paper [7] provides the information about implementation of smart contracts in the blockchain technology, using which, the system can be automated to execute the functions on receiving valid inputs from the user or when certain tasks are executed on the blockchain.

# PROPOSED METHODOLOGY

Our proposed system uses Blockchain in connection with IPFS. In this system, the document is uploaded into smaller chunks, which are cryptographically hashed and stored in the peer-to-peer network of nodes by the IPFS. The combined hash of all of these is stored into the blockchain with a consensus forming via the proof of stake algorithm. The main advantages of this system are that it protects the document's integrity, data is stored on a P2P network, hence chances of data loss and compromising is less, and the last important advantage is that we do not require any heavy machinery to add a block or put up high stakes as were.
