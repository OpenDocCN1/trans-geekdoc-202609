The application layer, network layer, data layer, and consensus layer are the four fundamental layers that makeup blockchain architecture.

## 2.1 Application layer

The application layer refers to the set of software, protocols, and services built on top of blockchain technology. This layer is the most visible to end-users and is responsible for providing various applications that interact with the blockchain and use its underlying functionalities. The application layer plays a crucial role in driving the adoption and utilization of blockchain technology across various domains, including finance, supply chain, real estate. One of the primary features of the application layer is to provide users with a user-friendly interface that enables them to interact with the blockchain and access its features. This interface can range from web-based applications to more complex desktop or mobile applications. The interface provides users with simple ways to initiate transactions, access their assets, and monitor the status of their transactions. Another function of the application layer is to provide developers with a platform to build decentralised applications (dApps) that interact with the blockchain and access its features. The platform allows developers to build and deploy their dApps with blockchain network, providing users with access to a wide range of decentralised applications that can help manage and automate various tasks and processes.
