# ### Box 1. Self-supervised learning

Self-supervised learning (SSL) is a family of methods in which a model creates its own training signal. Rather than relying on external labels, the model either corrupts parts of its inputs to predict them from the surrounding context. This allows the system to learn directly from data, unlabeled datasets.
A widely used SSL approach is pretraining, introduced in the original GPT paper, where models are trained to predict the next element in an input sequence (e.g., the next word in a sentence). The basic units the model operates on are called tokens, which generalize across data types. In text, tokens may be words, sub-words, or characters; in images, they are patches; in audio, they are short time bins or neural events (e.g., spikes). This shared tokenization principle allows the same embeddings to extend beyond to images, audio/video, recordings, and behavior.
A foundation model refers to a network pretrained at scale (usually with SSL) on heterogeneous data to learn versatile representations. These representations can then be adapted for downstream tasks using methods such as linear probing, fine-tuning.
Today's models are all built on the transformer architecture, which has largely replaced earlier designs (MLPs, CNNs, RNNs). Transformers use a mechanism called self-attention, where the model's representation is updated based on weighted relations (“attention scores”) over tokens in the input sequence. In decoder-only models (e.g., GPT, Centaur), attention is restricted to past tokens (causal masking), supporting next-token prediction. In encoders (e.g., BERT), attention is bidirectional and covers all tokens. Despite these differences, the common recipe is to pretrain a transformer on datasets to learn general-purpose representations and then adapt it to specific tasks.
For neuroscientists, a useful analogy is the contrast between handcrafted features (filtering, performing PCA) and learned representations. Downstream workflows depend on manually defined features that are fed into a dense layer (often small). SSL removes the manual feature-engineering step: the model learns features from raw or lightly processed data. The remarkable progress of foundation models reflects this shift from handcrafted to learned, representations—coupled with massive amounts of data and compute. This flexibility enables models to capture complex patterns in behavior, modality, and driving strong performance on tasks.

# ### Box 2. Foundation model scaling

Recent progress has been driven by empirical scaling laws, which show that model performance improves predictably as data, compute, and parameters increase. These laws have guided the design of ever-larger foundation models pretrained on diverse datasets and adapted to diverse tasks.
The same pretraining-finetuning paradigm enables multimodal learning across text, images, audio, and other data types. For example, vision-language models trained on large image-dataset corals can support clinical tasks, while vision-language-action models enable robots to follow natural-language commands.
