
那么这种类型的值将拥有 `Point` 的所有方法、`RGBA` 的所有方法，以及直接在 `ColoredPoint` 上声明的任何额外方法。当编译器将选择器（如 `p.ScaleBy`）解析为方法时，它首先查找名为 `ScaleBy` 的直接声明方法，然后查找从 `ColoredPoint` 的嵌入字段提升一次的方法，接着查找从 `Point` 和 `RGBA` 内部嵌入字段提升两次的方法，以此类推。如果选择器有歧义，因为有两个方法从同一层级提升，编译器会报错。

方法只能声明在命名类型（如 `Point`）及其指针（`*Point`）上，但得益于嵌入，*未命名* 结构体类型也可以拥有方法，这有时很有用。

这里有个很好的技巧来说明这一点。这个例子展示了一个简单缓存的部分实现，使用了两个包级变量：一个互斥锁（[§9.2](#ebook_split_088.html#id-mutex)）和它所保护的映射：

[点击此处查看代码图片](#ch06_images.html#id163pro01_r)

```
var (
    mu sync.Mutex // guards mapping
    mapping = make(map[string]string)
)

func Lookup(key string) string {
    mu.Lock()
    v := mapping[key]
    mu.Unlock()
    return v
}
```

下面的版本功能等价，但将两个相关变量归组在一个单一的包级变量 `cache` 中：

[点击此处查看代码图片](#ch06_images.html#id163pro02_r)

```
var cache = struct {
    sync.Mutex
    mapping map[string]string
} {
    mapping: make(map[string]string),
}

func Lookup(key string) string {
    cache.Lock()
    v := cache.mapping[key]
    cache.Unlock()
    return v
}
```

新变量为与缓存相关的变量提供了更具表达力的名称，并且因为 `sync.Mutex` 字段嵌入其中，其 `Lock` 和 `Unlock` 方法被提升到了未命名结构体类型，使我们能够用不言自明的语法来锁定 `cache`。

## 6.4 方法值与方法表达式

通常我们在同一个表达式中选择并调用方法，如 `p.Distance()`，但这两个操作也可以分开。选择器 `p.Distance` 生成一个*方法值*，这是一个将方法（`Point.Distance`）绑定到特定接收者值 `p` 的函数。随后可以在没有接收者值的情况下调用该函数；它只需要非接收者参数。

[点击此处查看代码图片](#ch06_images.html#id164pro01_r)

```
p := Point{1, 2}
q := Point{4, 6}

distanceFromP := p.Distance        // 方法值
fmt.Println(distanceFromP(q))      // "5"
var origin Point                   // {0, 0}
fmt.Println(distanceFromP(origin)) // "2.23606797749979", √5

scaleP := p.ScaleBy // 方法值
scaleP(2)           // p 变为 (2, 4)
scaleP(3)           //      然后 (6, 12)
scaleP(10)          //      然后 (60, 120)
```

当包的 API 需要一个函数值，而客户端希望该函数的行为是调用特定接收者上的方法时，方法值很有用。例如，函数 `time.AfterFunc` 在指定延迟后调用一个函数值。这个程序用它在 10 秒后发射火箭 `r`：

[点击此处查看代码图片](#ch06_images.html#id164pro02_r)

```
type Rocket struct { /* ... */ }
func (r *Rocket) Launch() { /* ... */ }

r := new(Rocket)
time.AfterFunc(10 * time.Second, func() { r.Launch() })
```

方法值语法更简短：

[点击此处查看代码图片](#ch06_images.html#id164pro03_r)

```
time.AfterFunc(10 * time.Second, r.Launch)
```

与方法值相关的是*方法表达式*。调用方法时，与普通函数不同，我们必须使用选择器语法以特殊方式提供接收者。方法表达式写作 `T.f` 或 `(*T).f`（其中 `T` 是类型），生成一个函数值，其第一个常规参数取代了接收者，因此可以用常规方式调用。

[点击此处查看代码图片](#ch06_images.html#id164pro04_r)

```
p := Point{1, 2}
q := Point{4, 6}

distance := Point.Distance   // 方法表达式
fmt.Println(distance(p, q))  // "5"
fmt.Printf("%T\n", distance) // "func(Point, Point) float64"

scale := (*Point).ScaleBy
scale(&p, 2)
fmt.Println(p)            // "{2 4}"
fmt.Printf("%T\n", scale) // "func(*Point, float64)"
```

当你需要一个值来代表同一类型的几个方法中的选择，以便能用许多不同的接收者调用选定的方法时，方法表达式会有所帮助。在下面的例子中，变量 `op` 代表类型 `Point` 的加法或减法方法，`Path.TranslateBy` 为 `Path` 中的每个点调用它：

[点击此处查看代码图片](#ch06_images.html#id165pro01_r)

```
type Point struct{ X, Y float64 }

func (p Point) Add(q Point) Point { return Point{p.X + q.X, p.Y + q.Y} }
func (p Point) Sub(q Point) Point { return Point{p.X - q.X, p.Y - q.Y} }

type Path []Point

func (path Path) TranslateBy(offset Point, add bool) {
    var op func(p, q Point) Point
    if add {
        op = Point.Add
    } else {
        op = Point.Sub
    }
    for i := range path {
        // 调用 path[i].Add(offset) 或 path[i].Sub(offset) 中的一个。
        path[i] = op(path[i], offset)
    }
}
```

## 6.5 示例：位向量类型

Go 中的集合通常实现为 `map[T]bool`，其中 `T` 是元素类型。用映射表示的集合非常灵活，但对于某些问题，专门的表示可能性能更好。例如，在数据流分析等领域，集合元素是较小的非负整数，集合拥有许多元素，且并集和交集等集合操作很常见，*位向量* 是理想选择。

位向量使用无符号整数值的切片或“字”，每一位代表集合的一个可能元素。如果第 *i* 位被置位，则集合包含 *i*。下面的程序演示了一个带有三个方法的简单位向量类型：

[点击此处查看代码图片](#ch06_images.html#id165pro02_r)

`gopl.io/ch6/intset`

```
// IntSet 是一个包含小非负整数的集合。
// 其零值代表空集。
type IntSet struct {
    words []uint64
}

// Has 报告集合是否包含非负值 x。
func (s *IntSet) Has(x int) bool {
    word, bit := x/64, uint(x%64)
    return word < len(s.words) && s.words[word]&(1<<bit) != 0
}

// Add 将非负值 x 添加到集合中。
func (s *IntSet) Add(x int) {
    word, bit := x/64, uint(x%64)
    for word >= len(s.words) {
        s.words = append(s.words, 0)
    }
    s.words[word] |= 1 << bit
}

// UnionWith 将 s 设为 s 和 t 的并集。
func (s *IntSet) UnionWith(t *IntSet) {
    for i, tword := range t.words {
        if i < len(s.words) {
            s.words[i] |= tword
        } else {
            s.words = append(s.words, tword)
        }
    }
}
```

因为每个字有 64 位，为了定位 `x` 的位，我们用商 `x/64` 作为字索引，用余数 `x%64` 作为该字内的位索引。`UnionWith` 操作使用按位或运算符 `|` 一次计算 64 个元素的并集。（我们将在[练习 6.5](#ebook_split_057.html#id-intset32)中重新审视 64 位字的选择。）
