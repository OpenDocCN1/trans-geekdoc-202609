## 1.8 遗留问题

Go 语言的内容远不止我们在本快速介绍中涵盖的内容。以下是我们仅略微涉及或完全省略的主题，我们提供了恰到好处的讨论，以便当它们在完整讲解之前简短出现时，你能对它们有所熟悉。

### 控制流

我们介绍了两个基本的控制流语句 `if` 和 `for`，但未介绍 `switch` 语句，它是一种多路分支。这里有一个小例子：

[点击此处查看代码图像](#ch01_images.html#id023pro01_r)

```
switch coinflip() {
case "heads":
    heads++
case "tails":
    tails++
default:
    fmt.Println("landed on edge!")
}
```

调用 `coinflip` 的结果将与每个 case 的值进行比较。Case 从上到下依次求值，因此第一个匹配的 case 会被执行。可选的 default case 在其他 case 都不匹配时匹配；它可以放在任何位置。Case 不会像 C 语言那样自动贯穿到下一个（尽管存在一个很少使用的 `fallthrough` 语句可以覆盖此行为）。

`switch` 语句不需要操作对象；它可以只列出 case，每个 case 是一个布尔表达式：

```
func Signum(x int) int {
    switch {
    case x > 0:
        return +1
    default:
        return 0
    case x < 0:
        return -1
    }
}
```

这种形式称为*无标签 switch*；它等同于 `switch true`。

与 `for` 和 `if` 语句一样，`switch` 可以包含一个可选的简单语句——短变量声明、增量或赋值语句，或函数调用——可用于在测试前设置值。

`break` 和 `continue` 语句修改控制流。`break` 使控制流在最内层的 `for`、`switch` 或 `select` 语句（稍后将介绍）之后的下一条语句恢复执行，正如我们在[第 1.3 节](#ebook_split_013.html#id-findingduplicatelines)中所见，`continue` 使最内层的 `for` 循环开始其下一次迭代。语句可以被标记，以便 `break` 和 `continue` 可以引用它们，例如一次跳出多层嵌套循环或开始最外层循环的下一次迭代。甚至还有一个 `goto` 语句，尽管它是为机器生成的代码准备的，而非程序员常规使用。

### 命名类型

`type` 声明使得为现有类型命名成为可能。由于结构体类型通常很长，因此它们几乎总是被命名。一个熟悉的例子是为二维图形系统定义 `Point` 类型：

```
type Point struct {
    X, Y int
}
var p Point
```

类型声明和命名类型将在[第 2 章](#ebook_split_019.html#id-programstructure)中介绍。

### 指针

Go 提供了指针，即包含变量地址的值。在某些语言中（特别是 C），指针相对不受约束。在其他语言中，指针被伪装成“引用”，除了传递它们之外没什么可做的。Go 采取了一个中间立场。指针是显式可见的。`&` 运算符生成变量的地址，`*` 运算符获取指针指向的变量，但不支持指针运算。我们将在[第 2.3.2 节](#ebook_split_022.html#id-pointers)中解释指针。

### 方法和接口

方法是与命名类型关联的函数；Go 的不寻常之处在于方法可以附加到几乎任何命名类型上。方法将在[第 6 章](#ebook_split_052.html#id-methods)中介绍。接口是抽象类型，它们让我们能够根据具体类型拥有的方法，以相同的方式对待不同的具体类型，而不关心它们如何表示或实现。接口是[第 7 章](#ebook_split_059.html#id-interfaces)的主题。

### 包

Go 自带了一个庞大的标准库，包含许多有用的包，Go 社区也创建并分享了更多。编程往往更多的是关于使用现有的包，而不是编写自己的原创代码。全书中，我们将指出几十个最重要的标准包，但还有许多我们因篇幅所限未提及，我们也无法为任何包提供类似完整参考手册的内容。

在着手编写任何新程序之前，最好先看看是否已存在一些包能帮你更轻松地完成工作。你可以在 `https://golang.org/pkg` 找到标准库包的索引，在 `https://godoc.org` 找到社区贡献的包。`go doc` 工具使这些文档可轻松从命令行访问：

[点击此处查看代码图像](#ch01_images.html#id025pro01_r)

```
$ go doc http.ListenAndServe
package http // import "net/http"

func ListenAndServe(addr string, handler Handler) error

    ListenAndServe listens on the TCP network address addr and then
    calls Serve with handler to handle requests on incoming connections.
...
```

### 注释

我们已经提到了程序或包开头的文档注释。在每个函数声明之前编写注释以指定其行为也是良好的风格。这些约定很重要，因为它们被 `go doc` 和 `godoc` 等工具用来定位和显示文档（[§10.7.4](#ebook_split_102.html#id-documentingpackages)）。

对于跨越多行或出现在表达式或语句内部的注释，还有其他语言熟悉的 `/* ... */` 表示法。这种注释有时用于文件开头的大段解释性文本，以避免每行都写 `//`。在注释内部，`//` 和 `/*` 没有特殊含义，因此注释不能嵌套。

# 2. 程序结构

在 Go 中，与其他任何编程语言一样，人们从一小组基本构造构建大型程序。变量存储值。简单表达式通过加法、减法等操作组合成更大的表达式。基本类型聚合成数组和结构体等聚合类型。表达式用于语句中，其执行顺序由 `if` 和 `for` 等控制流语句决定。语句被分组成函数以实现隔离和复用。函数被收集到源文件和包中。

我们在上一章中看到了其中大多数的示例。在本章中，我们将更详细地介绍 Go 程序的基本结构元素。示例程序故意保持简单，以便我们专注于语言本身，而不被复杂的算法或数据结构分心。

## 2.1 名称

Go 函数、变量、常量、类型、语句标签和包的名称遵循一条简单规则：名称以字母（即 Unicode 视为字母的任何字符）或下划线开头，后面可以跟任意数量的字母、数字和下划线。大小写敏感：`heapSort` 和 `Heapsort` 是不同的名称。

Go 有 25 个*关键字*，如 `if` 和 `switch`，它们只能在语法允许的地方使用；不能用作名称。
