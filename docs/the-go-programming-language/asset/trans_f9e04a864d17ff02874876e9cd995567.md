
如果字段在该类型的字面量中被省略，它将被设置为其类型的零值。因为提供了名称，字段的顺序无关紧要。

这两种形式不能在同一个字面量中混合使用。也不能使用（基于顺序的）第一种字面量形式来绕过规则，即不能从另一个包引用未导出的标识符。

[点击此处查看代码图像](#ch04_images.html#id103pro02_r)

```
package p
type T struct{ a, b int } // a 和 b 未导出

package q
import "p"
var _ = p.T{a: 1, b: 2} // 编译错误：无法引用 a, b
var _ = p.T{1, 2}       // 编译错误：无法引用 a, b
```

尽管最后一行没有提及未导出的字段标识符，但它实际上隐式地使用了它们，因此这是不允许的。

结构体值可以作为参数传递给函数，也可以从函数返回。例如，此函数按指定因子缩放 `Point`：

[点击此处查看代码图像](#ch04_images.html#id103pro03_r)

```
func Scale(p Point, factor int) Point {
    return Point{p.X * factor, p.Y * factor}
}

fmt.Println(Scale(Point{1, 2}, 5)) // "{5 10}"
```

为了效率，较大的结构体类型通常通过指针间接地传递给函数或从函数返回，

[点击此处查看代码图像](#ch04_images.html#id103pro04_r)

```
func Bonus(e *Employee, percent int) int {
    return e.Salary * percent / 100
}
```

如果函数必须修改其参数，则需要这样做，因为在像 Go 这样的按值调用语言中，被调用函数仅接收参数的副本，而不是对原始参数的引用。

[点击此处查看代码图像](#ch04_images.html#id103pro05_r)

```
func AwardAnnualRaise(e *Employee) {
    e.Salary = e.Salary * 105 / 100
}
```

因为结构体通常通过指针来处理，所以可以使用这种简写符号来创建并初始化一个 `struct` 变量并获取其地址：

```
pp := &Point{1, 2}
```

它完全等同于

```
pp := new(Point)
*pp = Point{1, 2}
```

但 `&Point{1, 2}` 可以直接在表达式中使用，例如函数调用。

## 4.4.2 比较结构体

如果结构体的所有字段都是可比较的，那么该结构体本身就是可比较的，因此该类型的两个表达式可以使用 `==` 或 `!=` 进行比较。`==` 操作按顺序比较两个结构体的对应字段，因此下面打印的两个表达式是等价的：

[点击此处查看代码图像](#ch04_images.html#id104pro01_r)

```
type Point struct{ X, Y int }

p := Point{1, 2}
q := Point{2, 1}
fmt.Println(p.X == q.X && p.Y == q.Y) // "false"
fmt.Println(p == q)                   // "false"
```

可比较的结构体类型，像其他可比较类型一样，可用作映射的键类型。

[点击此处查看代码图像](#ch04_images.html#id104pro02_r)

```
type address struct {
    hostname string
    port     int
}

hits := make(map[address]int)
hits[address{"golang.org", 443}]++
```

## 4.4.3 结构体嵌入和匿名字段

在本节中，我们将看到 Go 不寻常的*结构体嵌入*机制如何让我们将一个命名结构体类型用作另一个结构体类型的*匿名字段*，提供了一种方便的语法快捷方式，使得简单的点表达式如 `x.f` 可以代表一串字段如 `x.d.e.f`。

考虑一个 2D 绘图程序，它提供了一个形状库，如矩形、椭圆、星星和轮子。以下是它可能定义的两种类型：

```
type Circle struct {
    X, Y, Radius int
}

type Wheel struct {
    X, Y, Radius, Spokes int
}
```

`Circle` 拥有其圆心 `X` 和 `Y` 坐标的字段，以及一个 `Radius`。`Wheel` 拥有 `Circle` 的所有特性，外加 `Spokes`（内切辐条的数量）。让我们创建一个轮子：

```
var w Wheel
w.X = 8
w.Y = 8
w.Radius = 5
w.Spokes = 20
```

随着形状集合的增长，我们必然会注意到它们之间的相似性和重复性，因此提取其公共部分可能会很方便：

```
type Point struct {
    X, Y int
}

type Circle struct {
    Center Point
    Radius int
}

type Wheel struct {
    Circle Circle
    Spokes int
}
```

应用程序可能因此变得更清晰，但这项更改使得访问 `Wheel` 的字段变得更加冗长：

```
var w Wheel
w.Circle.Center.X = 8
w.Circle.Center.Y = 8
w.Circle.Radius = 5
w.Spokes = 20
```

Go 允许我们声明一个只有类型没有名称的字段；这样的字段称为*匿名字段*。该字段的类型必须是命名类型或指向命名类型的指针。在下面的代码中，`Circle` 和 `Wheel` 各有一个匿名字段。我们说 `Point` 被*嵌入*在 `Circle` 中，而 `Circle` 被嵌入在 `Wheel` 中。

```
type Circle struct {
    Point
    Radius int
}

type Wheel struct {
    Circle
    Spokes int
}
```

得益于嵌入，我们可以在不给出中间名称的情况下引用隐式树叶子节点的名称：

[点击此处查看代码图像](#ch04_images.html#id106pro01_r)

```
var w Wheel
w.X = 8        // 等价于 w.Circle.Point.X = 8
w.Y = 8        // 等价于 w.Circle.Point.Y = 8
w.Radius = 5   // 等价于 w.Circle.Radius = 5
w.Spokes = 20
```

上面注释中显式的形式仍然有效，这表明“匿名字段”在一定程度上是个误称。字段 `Circle` 和 `Point` 确实有名称——即命名类型的名称——但这些名称在点表达式中是可选的。在选择其子字段时，我们可以省略任意或所有匿名字段。

遗憾的是，结构体字面量语法没有相应的简写，因此以下两行都无法编译：

[点击此处查看代码图像](#ch04_images.html#id106pro02_r)

```
w = Wheel{8, 8, 5, 20}                       // 编译错误：未知字段
w = Wheel{X: 8, Y: 8, Radius: 5, Spokes: 20} // 编译错误：未知字段
```

结构体字面量必须遵循类型声明的结构，所以我们必须使用下面两种形式之一，它们彼此等价：

[点击此处查看代码图像](#ch04_images.html#id106pro03_r)

gopl.io/ch4/embed

```
w = Wheel{Circle{Point{8, 8}, 5}, 20}

w = Wheel{
    Circle: Circle{
        Point:  Point{X: 8, Y: 8},
        Radius: 5,
    },
    Spokes: 20, // 注意：此处尾随逗号是必要的（Radius 处也是）
}

fmt.Printf("%#v\n", w)
// Output:
// Wheel{Circle:Circle{Point:Point{X:8, Y:8}, Radius:5}, Spokes:20}

w.X = 42

fmt.Printf("%#v\n", w)
// Output:
// Wheel{Circle:Circle{Point:Point{X:42, Y:8}, Radius:5}, Spokes:20}
```

注意 `#` 修饰符导致 `Printf` 的 `%v` 动词以类似 Go 语法的形式显示值。对于结构体值，这种形式包含每个字段的名称。

因为“匿名”字段确实有隐式名称，所以不能有两个相同类型的匿名字段，因为它们的名称会冲突。而且因为字段的名称由其类型隐式决定，字段的可见性也是如此。在上面的例子中，匿名字段 `Point` 和 `Circle` 是导出的。如果它们是未导出的（`point` 和 `circle`），我们仍然可以使用简写形式

[点击此处查看代码图像](#ch04_images.html#id106pro04_r)

```
w.X = 8 // 等价于 w.circle.point.X = 8
```

但注释中显示的显式长形式将在声明包之外被禁止，因为 `circle` 和 `point` 将不可访问。

到目前为止我们看到的结构体嵌入只是用于选择结构体字段的点表示法上的一点语法糖。稍后我们将看到，匿名字段不必是结构体类型；任何命名类型或指向命名类型的指针都可以。但为什么要嵌入一个没有子字段的类型呢？
