
底层类型决定了命名类型的结构和表示，以及它支持的内置操作集，这与直接使用底层类型时相同。这意味着算术运算符对 `Celsius` 和 `Fahrenheit` 的作用方式与对 `float64` 的作用方式相同，正如你所期望的那样。

[点击此处查看代码图片](#ch02_images.html#id040pro01_r)

```
fmt.Printf("%g\n", BoilingC-FreezingC) // "100" °C
boilingF := CToF(BoilingC)
fmt.Printf("%g\n", boilingF-CToF(FreezingC)) // "180" °F
fmt.Printf("%g\n", boilingF-FreezingC)       // 编译错误：类型不匹配
```

比较运算符（如 `==` 和 `<`）也可用于比较命名类型的值与同类型的另一个值，或与底层类型的值。但两个不同命名类型的值不能直接比较：

[点击此处查看代码图片](#ch02_images.html#id040pro02_r)

```
var c Celsius
var f Fahrenheit
fmt.Println(c == 0)          // "true"
fmt.Println(f >= 0)          // "true"
fmt.Println(c == f)          // 编译错误：类型不匹配
fmt.Println(c == Celsius(f)) // "true"!
```

请仔细注意最后一种情况。尽管名为类型转换，`Celsius(f)` 并不会改变其参数的值，只会改变其类型。该测试为真是因为 `c` 和 `f` 都是零。

如果命名类型有助于避免反复编写复杂类型，它可以提供符号上的便利。当底层类型像 `float64` 这样简单时，优势很小；但对于复杂类型，优势很大，我们在讨论结构体时将会看到。

命名类型还使得为该类型的值定义新行为成为可能。这些行为表示为与该类型关联的一组函数，称为该类型的*方法*。我们将在[第 6 章](#ebook_split_052.html#id-methods)详细介绍方法，但这里先略窥一二。

下面的声明中，`Celsius` 参数 `c` 出现在函数名之前，这为 `Celsius` 类型关联了一个名为 `String` 的方法，该方法返回 `c` 的数值后跟 `°C`：

[点击此处查看代码图片](#ch02_images.html#id040pro03_r)

```
func (c Celsius) String() string { return fmt.Sprintf("%g°C", c) }
```

许多类型声明这种形式的 `String` 方法，因为它控制着该类型的值在由 `fmt` 包打印为字符串时的外观，正如我们将在[第 7.1 节](#ebook_split_060.html#id-stringer)中看到的那样。

[点击此处查看代码图片](#ch02_images.html#id041pro01_r)

```
c := FToC(212.0)
fmt.Println(c.String()) // "100°C"
fmt.Printf("%v\n", c)   // "100°C"; 无需显式调用 String
fmt.Printf("%s\n", c)   // "100°C"
fmt.Println(c)          // "100°C"
fmt.Printf("%g\n", c)   // "100"; 不调用 String
fmt.Println(float64(c)) // "100"; 不调用 String
```

## 2.6 包和文件

Go 语言中的包与其他语言中的库或模块作用相同，支持模块化、封装、单独编译和复用。包的源代码位于一个或多个 `.go` 文件中，通常存放在一个目录里，目录名以导入路径结尾；例如，`gopl.io/ch1/helloworld` 包的文件存放在目录 `$GOPATH/src/gopl.io/ch1/helloworld` 中。

每个包为其声明提供了一个独立的*命名空间*。例如，在 `image` 包中，标识符 `Decode` 指代的函数与 `unicode/utf16` 包中的同名标识符不同。要从包外引用函数，我们必须*限定*标识符，以明确是指 `image.Decode` 还是 `utf16.Decode`。

包还通过控制哪些名称在包外可见（即*导出*），来实现信息隐藏。在 Go 中，一条简单的规则决定了哪些标识符被导出：以大写字母开头的标识符会被导出。

为了演示基础知识，假设我们的温度转换软件变得流行，我们想将其作为一个新包提供给 Go 社区。该如何做呢？

让我们创建一个名为 `gopl.io/ch2/tempconv` 的包，这是前一个示例的变体。（此处我们打破了按顺序编号示例的惯例，以使包路径更现实。）该包本身存储在两个文件中，以展示包内不同文件中的声明如何被访问；在实际中，像这样微小的包只需一个文件即可。

我们将类型、常量及其方法的声明放在 `tempconv.go` 中：

[点击此处查看代码图片](#ch02_images.html#id041pro02_r)

`gopl.io/ch2/tempconv`

```
// Package tempconv performs Celsius and Fahrenheit conversions.
package tempconv

import "fmt"

type Celsius float64
type Fahrenheit float64

const (
    AbsoluteZeroC Celsius = -273.15
    FreezingC     Celsius = 0
    BoilingC      Celsius = 100
)

func (c Celsius) String() string    { return fmt.Sprintf("%g°C", c) }
func (f Fahrenheit) String() string { return fmt.Sprintf("%g°F", f) }
```

将转换函数放在 `conv.go` 中：

[点击此处查看代码图片](#ch02_images.html#id042pro01_r)

```
package tempconv

// CToF converts a Celsius temperature to Fahrenheit.
func CToF(c Celsius) Fahrenheit { return Fahrenheit(c*9/5 + 32) }

// FToC converts a Fahrenheit temperature to Celsius.
func FToC(f Fahrenheit) Celsius { return Celsius((f - 32) * 5 / 9) }
```

每个文件都以 `package` 声明开头，定义包名。导入包时，其成员通过 `tempconv.CToF` 等限定名来引用。包级名称（如一个文件中声明的类型和常量）对该包的所有其他文件可见，就好像源代码都在一个文件中一样。注意 `tempconv.go` 导入了 `fmt`，但 `conv.go` 没有，因为它未使用 `fmt` 中的任何内容。

因为包级 `const` 名称以大写字母开头，它们也可以通过限定名（如 `tempconv.AbsoluteZeroC`）访问：

[点击此处查看代码图片](#ch02_images.html#id042pro02_r)

```
fmt.Printf("Brrrr! %v\n", tempconv.AbsoluteZeroC) // "Brrrr! -273.15°C"
```

在导入 `gopl.io/ch2/tempconv` 的包中，要将摄氏温度转换为华氏温度，可以编写如下代码：

[点击此处查看代码图片](#ch02_images.html#id042pro03_r)

```
fmt.Println(tempconv.CToF(tempconv.BoilingC)) // "212°F"
```

紧接在 `package` 声明之前的*文档注释*（[§10.7.4](#ebook_split_102.html#id-documentatingpackages)）为整个包提供文档。按照惯例，它应以摘要句开头，风格如上所示。每个包中只应有一个文件包含包文档注释。大量的文档注释通常放在单独的文件中，按惯例命名为 `doc.go`。

### 2.6.1 导入

在 Go 程序中，每个包由一个称为*导入路径*的唯一字符串标识。这些字符串出现在 `import` 声明中，如 `"gopl.io/ch2/tempconv"`。语言规范未定义这些字符串的来源或含义；由工具来解释它们。使用 `go` 工具（[第 10 章](#ebook_split_095.html#id-packagesandthegotool)）时，导入路径表示一个目录，其中包含一个或多个 Go 源文件，它们共同构成该包。

除了导入路径，每个包还有一个*包名*，即出现在其 `package` 声明中的简短（且不一定唯一）名称。按照惯例，包名与其导入路径的最后一段匹配，这使得预测 `gopl.io/ch2/tempconv` 的包名为 `tempconv` 变得容易。

要使用 `gopl.io/ch2/tempconv`，我们必须导入它：
