
# Go 语言概述

Go 拥有足够完善的类型系统，能避免动态语言中常见的粗心错误，但其类型系统比同类型的静态语言更简单。这种设计有时会在更广泛的类型框架内形成孤立的“非类型化”编程区域，Go 程序员不会像 C++ 或 Haskell 程序员那样，费尽心力将安全属性表达为基于类型的证明。但在实践中，Go 在不增加复杂类型系统负担的情况下，提供了相对强类型系统的大部分安全性和运行时性能优势。

Go 鼓励程序员关注现代计算机系统设计，特别是局部性的重要性。其内置数据类型和大多数库数据结构的设计旨在自然工作，无需显式初始化或隐式构造函数，因此代码中隐藏的内存分配和内存写入相对较少。Go 的聚合类型（结构体和数组）直接持有其元素，相比使用间接字段的语言，需要更少的存储空间、更少的分配和更少的指针间接寻址。既然现代计算机是并行机器，Go 基于 CSP（通信顺序进程）提供了并发特性。Go 的轻量级线程（`goroutines`）具有可变大小的栈，初始大小足够小，使得创建一个 `goroutine` 开销很低，创建百万个也切实可行。

Go 的标准库常被描述为“开箱即用”，为 I/O、文本处理、图形、加密、网络和分布式应用提供了整洁的构建块和 API，并支持许多标准文件格式和协议。库和工具广泛使用约定来减少配置和解释的需求，从而简化程序逻辑，使不同的 Go 程序更加相似，也更易于学习。使用 `go` 工具构建的项目，仅通过文件名、标识符名和偶尔的特殊注释，即可确定项目的所有库、可执行文件、测试、基准测试、示例、平台特定变体和文档；Go 源代码本身即包含构建规范。

# 书籍结构

我们假设您已掌握一门或多门其他编程语言，无论是编译型的（如 C、C++、Java）还是解释型的（如 Python、Ruby、JavaScript），因此我们不会像面对完全初学者那样事无巨细地解释。表面语法、变量和常量、表达式、控制流及函数对您都应当熟悉。

- [第 1 章](#ebook_split_010.html#id-tutorial) 是 Go 基本构造的教程，通过十余个处理日常任务的程序（如读写文件、格式化文本、创建图像、与互联网客户端和服务器通信）进行介绍。
- [第 2 章](#ebook_split_019.html#id-programstructure) 描述 Go 程序的结构元素——声明、变量、新类型、包和文件以及作用域。
- [第 3 章](#ebook_split_027.html#id-basicdatatypes) 讨论数字、布尔值、字符串和常量，并解释如何处理 Unicode。
- [第 4 章](#ebook_split_034.html#id-compositetypes) 描述复合类型，即使用数组、映射、结构体和 `slices`（切片，Go 语言处理动态列表的方法）由简单类型构建而成的类型。
- [第 5 章](#ebook_split_041.html#id-functions) 涵盖函数，并讨论错误处理、`panic` 和 `recover` 以及 `defer` 语句。

第 1 章至第 5 章涵盖了基础内容，这些是任何主流命令式语言的组成部分。Go 的语法和风格有时与其他语言不同，但大多数程序员能快速上手。剩余章节聚焦于 Go 方法较不传统的主题：方法、接口、并发、包、测试和反射。

Go 对面向对象编程有独特的见解。没有类层次结构，甚至没有类；复杂对象行为通过组合而非继承从简单行为创建而成。方法可关联到任何用户定义类型，而不仅限于结构体，具体类型与抽象类型（`interfaces`，接口）的关系是隐式的，因此具体类型可能满足其设计者未曾知晓的接口。方法在 [第 6 章](#ebook_split_052.html#id-methods) 介绍，接口在 [第 7 章](#ebook_split_059.html#id-interfaces) 介绍。

- [第 8 章](#ebook_split_075.html#id-concurrency) 展示 Go 的并发方法，基于通信顺序进程（CSP）思想，由 `goroutines` 和 `channels`（通道）体现。
- [第 9 章](#ebook_split_086.html#id-concurrencywithsharedvariables) 解释基于共享变量的更传统的并发方面。

- [第 10 章](#ebook_split_095.html#id-packagesandthegotool) 描述包——组织库的机制。本章还展示如何有效使用 `go` 工具，它在单个命令内提供编译、测试、基准测试、程序格式化、文档生成等众多任务。
- [第 11 章](#ebook_split_103.html#id-testing) 讨论测试，Go 采用显著的轻量级方法，避免充满抽象的框架，青睐简单的库和工具。测试库提供了基础，必要时可在其上构建更复杂的抽象。
- [第 12 章](#ebook_split_110.html#id-reflection) 讨论反射——程序在执行期间检查自身表示的能力。反射是强大工具，但需谨慎使用；本章通过展示其如何实现一些重要的 Go 库，解释如何找到正确的平衡点。
- [第 13 章](#ebook_split_120.html#id-lowlevelprogramming) 解释使用 `unsafe` 包绕过 Go 类型系统进行底层编程的细节，以及何时适用。

每章都包含若干练习，供您测试对 Go 的理解，并探索书中示例的扩展与替代方案。

除最简单的代码示例外，本书所有示例均可从 `gopl.io` 的公共 Git 仓库下载。每个示例由其包导入路径标识，可使用 `go get` 方便地获取、构建和安装。您需选择一个目录作为 Go 工作区，并设置 `GOPATH` 环境变量指向它。`go` 工具会在必要时创建该目录。例如：

[点击此处查看代码图像](#pref01_images.html#idxvipro01_r)

```
$ export GOPATH=$HOME/gobook            # 选择工作区目录
$ go get gopl.io/ch1/helloworld         # 获取、构建、安装
$ $GOPATH/bin/helloworld                # 运行
Hello,
```

运行示例需要至少 Go 1.5 版本。

```
$ go version
go version go1.5 linux/amd64
```

若您计算机上的 `go` 工具过旧或缺失，请遵循 `https://golang.org/doc/install` 的安装说明。
