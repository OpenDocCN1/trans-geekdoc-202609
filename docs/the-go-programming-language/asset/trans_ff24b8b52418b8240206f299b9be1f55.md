

```go
package format

import (
	"reflect"
	"strconv"
)

// Any 将任意值格式化为字符串。
func Any(value interface{}) string {
	return formatAtom(reflect.ValueOf(value))
}

// formatAtom 在不检查内部结构的情况下格式化值。
func formatAtom(v reflect.Value) string {
	switch v.Kind() {
	case reflect.Invalid:
		return "invalid"
	case reflect.Int, reflect.Int8, reflect.Int16,
		reflect.Int32, reflect.Int64:
		return strconv.FormatInt(v.Int(), 10)
	case reflect.Uint, reflect.Uint8, reflect.Uint16,
		reflect.Uint32, reflect.Uint64, reflect.Uintptr:
		return strconv.FormatUint(v.Uint(), 10)
	// ...为简洁起见，省略了浮点数和复数情况...
	case reflect.Bool:
		return strconv.FormatBool(v.Bool())
	case reflect.String:
		return strconv.Quote(v.String())
	case reflect.Chan, reflect.Func, reflect.Ptr, reflect.Slice, reflect.Map:
		return v.Type().String() + " 0x" +
			strconv.FormatUint(uint64(v.Pointer()), 16)
	default: // reflect.Array, reflect.Struct, reflect.Interface
		return v.Type().String() + " value"
	}
}
```

到目前为止，我们的函数将每个值视为一个不可分割且无内部结构的整体——因此得名 `formatAtom`。对于聚合类型（结构体和数组）以及接口，它仅打印值的*类型*；对于引用类型（通道、函数、指针、切片和映射），它打印类型和十六进制的引用地址。这虽然不够理想，但仍是一个重大改进，而且由于 `Kind` 只关心底层表示，`format.Any` 对命名类型同样适用。例如：

[点击此处查看代码图片](#ch12_images.html#id333pro01_r)

```go
var x int64 = 1
var d time.Duration = 1 * time.Nanosecond
fmt.Println(format.Any(x))                  // "1"
fmt.Println(format.Any(d))                  // "1"
fmt.Println(format.Any([]int64{x}))         // "[]int64 0x8202b87b0"
fmt.Println(format.Any([]time.Duration{d})) // "[]time.Duration 0x8202b87e0"
```

```go
	display(name, reflect.ValueOf(x))
}
```

在 `display` 中，我们将使用之前定义的 `formatAtom` 函数来打印基本值——基本类型、函数和通道——但我们将使用 `reflect.Value` 的方法来递归显示更复杂类型的每个组件。随着递归的深入，`path` 字符串（最初描述起始值，例如 `"e"`）将被扩充，以表明我们是如何到达当前值的（例如 `"e.args[0].value"`）。

既然我们不再试图实现 `fmt.Sprint`，我们将使用 `fmt` 包以保持示例简短。

[点击此处查看代码图片](#ch12_images.html#id334pro01_r)

```go
func display(path string, v reflect.Value) {
	switch v.Kind() {
	case reflect.Invalid:
		fmt.Printf("%s = invalid\n", path)
	case reflect.Slice, reflect.Array:
		for i := 0; i < v.Len(); i++ {
			display(fmt.Sprintf("%s[%d]", path, i), v.Index(i))
		}
	case reflect.Struct:
		for i := 0; i < v.NumField(); i++ {
			fieldPath := fmt.Sprintf("%s.%s", path, v.Type().Field(i).Name)
			display(fieldPath, v.Field(i))
		}
	case reflect.Map:
		for _, key := range v.MapKeys() {
			display(fmt.Sprintf("%s[%s]", path,
				formatAtom(key)), v.MapIndex(key))
		}
	case reflect.Ptr:
		if v.IsNil() {
			fmt.Printf("%s = nil\n", path)
		} else {
			display(fmt.Sprintf("(*%s)", path), v.Elem())
		}
	case reflect.Interface:
		if v.IsNil() {
			fmt.Printf("%s = nil\n", path)
		} else {
			fmt.Printf("%s.type = %s\n", path, v.Elem().Type())
			display(path+".value", v.Elem())
		}
	default: // 基本类型、通道、函数
		fmt.Printf("%s = %s\n", path, formatAtom(v))
	}
}
```

让我们按顺序讨论各种情况。

### 切片和数组

两者的逻辑相同。`Len` 方法返回切片或数组值的元素数量，`Index(i)` 以 `reflect.Value` 形式检索索引 `i` 处的元素；如果 `i` 越界则会 panic。这些类似于序列上的内置 `len(a)` 和 `a[i]` 操作。`display` 函数在序列的每个元素上递归调用自身，将下标表示法 `"[i]"` 追加到路径后。

虽然 `reflect.Value` 有许多方法，但只有少数几个可以安全地在任意给定值上调用。例如，`Index` 方法可以在 `Slice`、`Array` 或 `String` 类型的值上调用，但在其他类型上会 panic。

### 结构体

`NumField` 方法报告结构体中的字段数量，`Field(i)` 将第 *i* 个字段的值作为 `reflect.Value` 返回。字段列表包括从匿名字段提升的字段。要将字段选择器表示法 `".f"` 追加到路径，我们必须获取结构体的 `reflect.Type` 并访问其第 *i* 个字段的名称。

### 映射

`MapKeys` 方法返回一个 `reflect.Value` 切片，每个映射键对应一个。像往常一样遍历映射时，顺序是未定义的。`MapIndex(key)` 返回与 `key` 对应的值。我们将下标表示法 `"[key]"` 追加到路径后。（此处我们偷了个懒。映射键的类型不限于 `formatAtom` 能最好处理的类型；数组、结构体和接口也可以是有效的映射键。扩展此情况以完整打印键是[练习 12.1](#ebook_split_113.html#id-ex-printstruct)。）

### 指针

`Elem` 方法返回指针指向的变量，同样作为 `reflect.Value`。即使指针值为 `nil`，此操作也是安全的，此时结果的 Kind 为 `Invalid`，但我们显式使用 `IsNil` 来检测空指针，以便打印更合适的消息。我们在路径前加上 `"*"` 并加上括号以避免歧义。

### 接口

同样，我们使用 `IsNil` 测试接口是否为 nil，如果不为 nil，则使用 `v.Elem()` 获取其动态值并打印其类型和值。
