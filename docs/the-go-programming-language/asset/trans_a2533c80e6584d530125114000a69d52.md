

```
// Dup1 打印标准输入中出现次数超过一次的每行文本，前面带有其计数。
package main

import (
    "bufio"
    "fmt"
    "os"
)

func main() {
    counts := make(map[string]int)
    input := bufio.NewScanner(os.Stdin)
    for input.Scan() {
        counts[input.Text()]++
    }
    // NOTE: ignoring potential errors from input.Err()
    for line, n := range counts {
        if n > 1 {
            fmt.Printf("%d\t%s\n", n, line)
        }
    }
}
```

与 `for` 一样，`if` 语句的条件两侧从不使用括号，但主体部分需要花括号。可以有一个可选的 `else` 部分，在条件为假时执行。

`map` 存储一组键值对，并提供常数时间复杂度的存储、检索或测试集合中某项的操作。键可以是任何可用 `==` 比较的类型，字符串是最常见的例子；值可以是任意类型。在本例中，键是字符串，值是 `int`。内置函数 `make` 创建一个新的空 map；它还有其他用途。Map 将在 [4.3 节](#ebook_split_037.html#id-maps) 中详细讨论。

每次 `dup` 读取一行输入，该行被用作 map 的键，对应的值递增。语句 `counts[input.Text()]++` 等价于以下两条语句：

```
line := input.Text()
counts[line] = counts[line] + 1
```

如果 map 尚不包含该键也没关系。第一次遇到新行时，右侧表达式 `counts[line]` 的值为其类型的零值，对于 `int` 即为 `0`。

为了打印结果，我们再次使用基于 `range` 的 `for` 循环，这次遍历 `counts` map。和之前一样，每次迭代产生两个结果：一个键和该键对应的 map 元素值。map 的迭代顺序未指定，但在实践中是随机的，每次运行可能不同。这种设计是有意为之，因为它防止程序依赖任何并不保证的特定顺序。

接下来介绍 `bufio` 包，它有助于使输入输出高效且方便。其最有用的特性之一是 `Scanner` 类型，它读取输入并将其拆分为行或单词；这通常是处理天然按行输入的最简单方式。

程序使用短变量声明创建一个新变量 `input`，指向一个 `bufio.Scanner`：

```
input := bufio.NewScanner(os.Stdin)
```

扫描器从程序的标准输入读取。每次调用 `input.Scan()` 读取下一行并移除末尾的换行符；结果可通过调用 `input.Text()` 获取。`Scan` 函数若有行则返回 `true`，无更多输入时返回 `false`。

函数 `fmt.Printf` 与 C 及其他语言中的 `printf` 类似，根据表达式列表产生格式化输出。其第一个参数是格式字符串，指定后续参数如何格式化。每个参数的格式由转换字符决定，即百分号后的字母。例如，`%d` 以十进制格式化整数操作数，`%s` 展开为字符串操作数的值。

`Printf` 有十多种此类转换，Go 程序员称之为 *verb*（动词/格式动词）。下表远非完整规范，但展示了许多可用特性：

| Verb | 含义 |
| --- | --- |
| `%d` | 十进制整数 |
| `%x, %o, %b` | 十六进制、八进制、二进制整数 |
| `%f, %g, %e` | 浮点数：`3.141593 3.141592653589793 3.141593e+00` |
| `%t` | 布尔值：`true` 或 `false` |
| `%c` | rune（Unicode 码点） |
| `%s` | 字符串 |
| `%q` | 带引号的字符串 `"abc"` 或 rune `'c'` |
| `%v` | 任意值的自然格式 |
| `%T` | 任意值的类型 |
| `%%` | 字面百分号（无操作数） |

`dup1` 中的格式字符串还包含制表符 `\t` 和换行符 `\n`。字符串字面量可包含此类 *escape sequences*（转义序列），用于表示其他不可见字符。`Printf` 默认不写入换行符。按照惯例，名称以 `f` 结尾的格式化函数（如 `log.Printf` 和 `fmt.Errorf`）使用 `fmt.Printf` 的格式化规则，而以 `ln` 结尾的函数遵循 `Println`，将参数按 `%v` 格式化后加上换行符。

许多程序要么从标准输入读取（如上），要么从一系列命名文件读取。`dup` 的下一个版本可以从标准输入读取，或使用 `os.Open` 处理文件名列表：

gopl.io/ch1/dup2

```
// Dup2 打印输入中出现次数超过一次的行的计数和文本。
// 它从标准输入或一系列命名文件中读取。
package main

import (
    "bufio"
    "fmt"
    "os"
)

func main() {
    counts := make(map[string]int)
    files := os.Args[1:]
    if len(files) == 0 {
        countLines(os.Stdin, counts)
    } else {
        for _, arg := range files {
            f, err := os.Open(arg)
            if err != nil {
                fmt.Fprintf(os.Stderr, "dup2: %v\n", err)
                continue
            }
            countLines(f, counts)
            f.Close()
        }
    }
    for line, n := range counts {
        if n > 1 {
            fmt.Printf("%d\t%s\n", n, line)
        }
    }
}

func countLines(f *os.File, counts map[string]int) {
    input := bufio.NewScanner(f)
    for input.Scan() {
        counts[input.Text()]++
    }
    // NOTE: ignoring potential errors from input.Err()
}
```

函数 `os.Open` 返回两个值。第一个是打开的文件（`*os.File`），供 `Scanner` 后续读取使用。

`os.Open` 的第二个返回值是内置 `error` 类型的值。若 `err` 等于特殊内置值 `nil`，则文件打开成功。读取文件，到达输入末尾时，`Close` 关闭文件并释放资源。反之，若 `err` 不为 `nil`，则出错。此时错误值描述了问题。我们的简单错误处理使用 `Fprintf` 和 verb `%v`（以默认格式显示任意类型值）向标准错误流打印消息，随后 `dup` 继续处理下一个文件；`continue` 语句跳转到外层 `for` 循环的下一次迭代。

为保持代码示例规模合理，早期示例有意在错误处理上略显随意。显然我们必须检查 `os.Open` 的错误；但我们忽略了使用 `input.Scan` 读取文件时发生错误的可能性较小的情况。我们会标注跳过错误检查的地方，并在 [5.4 节](#ebook_split_045.html#id-errors) 详细介绍错误处理。

注意 `countLines` 的调用先于其声明。函数及其他包级实体可按任意顺序声明。

Map 是对 `make` 创建的数据结构的 *reference*（引用）。将 map 传递给函数时，函数接收引用的副本，因此被调函数对底层数据结构的任何修改都将通过调用者的 map 引用可见。在本例中，`countLines` 插入 `counts` map 的值在 `main` 中可见。
