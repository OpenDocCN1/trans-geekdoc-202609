

## `reverse` 中的 `Len` 和 `Swap`

`Len` 和 `Swap` 是 `reverse` 的另外两个方法，它们由原始的 `sort.Interface` 值隐式提供，因为它是一个嵌入字段。导出函数 `Reverse` 返回一个包含原始 `sort.Interface` 值的 `reverse` 类型实例。

## 按不同列排序

要按不同的列排序，我们必须定义一个新类型，例如 `byYear`：

[点击此处查看代码图片](#ch07_images.html#id189pro04_r)

```
type byYear []*Track

func (x byYear) Len() int           { return len(x) }
func (x byYear) Less(i, j int) bool { return x[i].Year < x[j].Year }
func (x byYear) Swap(i, j int)      { x[i], x[j] = x[j], x[i] }
```

使用 `sort.Sort(byYear(tracks))` 按年份对 `tracks` 进行排序后，`printTracks` 显示按时间顺序排列的列表：

## `customSort` 类型

对于我们需要的每一种切片元素类型和排序函数，我们都要声明一个新的 `sort.Interface` 实现。正如你所见，对于所有切片类型，`Len` 和 `Swap` 方法都有相同的定义。在下一个示例中，具体类型 `customSort` 将一个切片和一个函数结合在一起，让我们只需编写比较函数即可定义一种新的排序顺序。顺便说一下，实现 `sort.Interface` 的具体类型并不总是切片；`customSort` 是一个结构体类型。

[点击此处查看代码图片](#ch07_images.html#id190pro01_r)

```
type customSort struct {
    t    []*Track
    less func(x, y *Track) bool
}

func (x customSort) Len() int           { return len(x.t) }
func (x customSort) Less(i, j int) bool { return x.less(x.t[i], x.t[j]) }
func (x customSort) Swap(i, j int)      { x.t[i], x.t[j] = x.t[j], x.t[i] }
```

让我们定义一个多层排序函数，其主排序键是 `Title`，次排序键是 `Year`，第三排序键是运行时间 `Length`。下面是使用匿名排序函数调用 `Sort` 的代码：

[点击此处查看代码图片](#ch07_images.html#id190pro02_r)

```
sort.Sort(customSort{tracks, func(x, y *Track) bool {
    if x.Title != y.Title {
        return x.Title < y.Title
    }
    if x.Year != y.Year {
        return x.Year < y.Year
    }
    if x.Length != y.Length {
        return x.Length < y.Length
    }
    return false
}})
```

这是结果。请注意，两个标题均为 “Go” 的曲目之间的平局，倾向于较旧的那一个。

## 检查是否已排序

虽然对长度为 *n* 的序列进行排序需要 O(*n* log *n*) 次比较操作，但测试一个序列是否已经排序最多只需要 *n*−1 次比较。`sort` 包中的 `IsSorted` 函数可以为我们完成这项检查。与 `sort.Sort` 一样，它使用 `sort.Interface` 同时抽象了序列及其排序函数，但它永远不会调用 `Swap` 方法。

以下代码演示了 `IntsAreSorted` 和 `Ints` 函数以及 `IntSlice` 类型：

[点击此处查看代码图片](#ch07_images.html#id190pro04_r)

```
values := []int{3, 1, 4, 1}
fmt.Println(sort.IntsAreSorted(values)) // "false"
sort.Ints(values)
fmt.Println(values)                     // "[1 1 3 4]"
fmt.Println(sort.IntsAreSorted(values)) // "true"
sort.Sort(sort.Reverse(sort.IntSlice(values)))
fmt.Println(values)                     // "[4 3 1 1]"
fmt.Println(sort.IntsAreSorted(values)) // "false"
```

为了方便起见，`sort` 包提供了针对 `[]int`、`[]string` 和 `[]float64` 使用其自然顺序的函数和类型的特化版本。对于其他类型，如 `[]int64` 或 `[]uint`，我们需要自己动手，尽管过程很简单。

## 7.7 `http.Handler` 接口

在 [第 1 章](#ebook_split_015.html#id-fetchingaurl) 中，我们略微了解了如何使用 `net/http` 包来实现 Web 客户端（[§1.5](#ebook_split_015.html#id-fetchingaurl)）和服务端（[§1.7](#ebook_split_017.html#id-awebserver)）。在本节中，我们将更仔细地研究服务端 API，其基础是 `http.Handler` 接口：

[点击此处查看代码图片](#ch07_images.html#id191pro01_r)

```
package http

type Handler interface {
    ServeHTTP(w ResponseWriter, r *Request)
}

func ListenAndServe(address string, h Handler) error
```

`ListenAndServe` 函数需要一个服务端地址，例如 `"localhost:8000"`，以及一个 `Handler` 接口实例，所有请求都应分派给该实例。它将永远运行，直到服务端失败（或启动失败）并返回一个错误（总是非 nil）。

设想一个电子商务网站，其数据库将待售商品映射为其美元价格。下面的程序展示了最简单的实现。它将库存建模为一个映射类型 `database`，并为其附加了一个 `ServeHTTP` 方法，使其满足 `http.Handler` 接口。该处理器遍历该映射并打印商品。

[点击此处查看代码图片](#ch07_images.html#id191pro02_r)

```
func main() {
    db := database{"shoes": 50, "socks": 5}
    log.Fatal(http.ListenAndServe("localhost:8000", db))
}

type dollars float32

func (d dollars) String() string { return fmt.Sprintf("$%.2f", d) }

type database map[string]dollars

func (db database) ServeHTTP(w http.ResponseWriter, req *http.Request) {
    for item, price := range db {
        fmt.Fprintf(w, "%s: %s\n", item, price)
    }
}
```

如果我们启动服务端，

```
$ go build gopl.io/ch7/http1
$ ./http1 &
```

然后使用 [1.5 节](#ebook_split_015.html#id-fetchingaurl) 中的 `fetch` 程序（或 Web 浏览器）连接到它，我们将得到以下输出：

[点击此处查看代码图片](#ch07_images.html#id192pro01_r)

```
$ go build gopl.io/ch1/fetch
$ ./fetch http://localhost:8000
shoes: $50.00
socks: $5.00
```

到目前为止，服务端只能列出其全部库存，并且对每个请求都执行此操作，而不管 URL 如何。一个更现实的服务端会定义多个不同的 URL，每个 URL 触发不同的行为。让我们把现有的那个称为 `/list`，并添加另一个名为 `/price` 的 URL，它报告单个商品的价格，该商品作为请求参数指定，如 `/price?item=socks`。
