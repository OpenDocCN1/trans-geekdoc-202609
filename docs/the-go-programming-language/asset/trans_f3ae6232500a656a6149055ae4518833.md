
内置的 `len` 函数返回字符串中的字节数（而非 rune 数），索引操作 `s[i]` 获取字符串 `s` 的第 `i` 个字节，其中 `0 ≤ i < len(s)`。

[点击此处查看代码图像](#ch03_images.html#id064pro04_r)

```
s := "hello, world"
fmt.Println(len(s))     // "12"
fmt.Println(s[0], s[7]) // "104 119"  ('h' 和 'w')
```

尝试访问此范围之外的字节会导致 panic：

[点击此处查看代码图像](#ch03_images.html#id064pro05_r)

```
c := s[len(s)] // panic: index out of range
```

字符串的第 `i` 个字节不一定是字符串的第 `i` 个*字符*，因为非 ASCII 码点的 UTF-8 编码需要两个或更多字节。稍后将讨论如何处理字符。

*子字符串*操作 `s[i:j]` 生成一个新字符串，该字符串由原字符串从索引 `i` 开始、直到但不包括索引 `j` 处字节的字节序列组成。结果包含 `j-i` 个字节。

```
fmt.Println(s[0:5]) // "hello"
```

同样，如果任一索引越界，或者 `j` 小于 `i`，则会导致 panic。

`i` 和 `j` 操作数中的任一个或两个均可省略，在这种情况下，分别假定其默认值为 `0`（字符串开头）和 `len(s)`（字符串结尾）。

[点击此处查看代码图像](#ch03_images.html#id065pro01_r)

```
fmt.Println(s[:5]) // "hello"
fmt.Println(s[7:]) // "world"
fmt.Println(s[:])  // "hello, world"
```

`+` 运算符通过连接两个字符串来创建一个新字符串：

[点击此处查看代码图像](#ch03_images.html#id065pro02_r)

```
fmt.Println("goodbye" + s[5:]) // "goodbye, world"
```

字符串可以使用 `==` 和 `<` 等比较运算符进行比较；比较是逐字节进行的，因此结果是自然的字典序。

字符串值是不可变的：字符串值包含的字节序列永远不能被改变，尽管当然我们可以给字符串*变量*赋一个新值。例如，要将一个字符串追加到另一个字符串后面，我们可以写：

```
s := "left foot"
t := s
s += ", right foot"
```

这不会修改 `s` 原来持有的字符串，而是导致 `s` 持有由 `+=` 语句形成的新字符串；同时，`t` 仍然包含旧字符串。

[点击此处查看代码图像](#ch03_images.html#id065pro03_r)

```
fmt.Println(s) // "left foot, right foot"
fmt.Println(t) // "left foot"
```

由于字符串不可变，试图原地修改字符串数据的构造是不被允许的：

[点击此处查看代码图像](#ch03_images.html#id065pro04_r)

```
s[0] = 'L' // compile error: cannot assign to s[0]
```

不可变性意味着两个副本的字符串共享相同的底层内存是安全的，这使得复制任意长度的字符串代价很低。类似地，字符串 `s` 和像 `s[7:]` 这样的子字符串也可以安全地共享相同的数据，因此子字符串操作也很廉价。这两种情况都不需要分配新内存。[图 3.4](#ebook_split_032.html#id-figures-stringshare) 说明了一个字符串及其两个子字符串共享同一个底层字节数组的排列。

### 3.5.1 字符串字面量

字符串值可以写成*字符串字面量*，即用双引号括起来的一系列字节：

```
"Hello, "
```

因为 Go 源文件总是采用 UTF-8 编码，且 Go 文本字符串按惯例解释为 UTF-8，所以我们可以在字符串字面量中包含 Unicode 码点。

在双引号字符串字面量中，以反斜杠 `\` 开头的*转义序列*可用于将任意字节值插入字符串。一组转义序列处理像换行、回车和制表符这样的 ASCII 控制码：

| 转义序列 | 说明 |
| --- | --- |
| `\a` | “alert” 或响铃 |
| `\b` | 退格 |
| `\f` | 换页 |
| `\n` | 换行 |
| `\r` | 回车 |
| `\t` | 制表符 |
| `\v` | 垂直制表符 |
| `\'` | 单引号（仅用于 rune 字面量 `'\''`） |
| `\"` | 双引号（仅用于 `"..."` 字面量内） |
| `\\` | 反斜杠 |

任意字节也可以通过十六进制或八进制转义包含在字面量字符串中。*十六进制转义*写作 `\xhh`，包含恰好两个十六进制数字 `h`（大小写均可）。*八进制转义*写作 `\ooo`，包含恰好三个八进制数字 `o`（0 到 7），不超过 `\377`。两者都表示一个具有指定值的单个字节。稍后我们将看到如何在字符串字面量中以数字形式编码 Unicode 码点。

*原始字符串字面量*写作 `` `...` ``，使用反引号代替双引号。在原始字符串字面量中，不处理任何转义序列；内容按字面意思获取，包括反斜杠和换行符，因此原始字符串字面量在程序源代码中可以跨越多行。唯一的处理是删除回车符，以便字符串的值在所有平台上都相同，包括那些习惯在文本文件中放置回车符的平台。

原始字符串字面量是编写正则表达式的便捷方式，因为正则表达式往往包含大量反斜杠。它们对于 HTML 模板、JSON 字面量、命令用法消息等也很有用，这些内容通常跨越多行。

[点击此处查看代码图像](#ch03_images.html#id067pro01_r)

```
const GoUsage = `Go is a tool for managing Go source code.

Usage:
    go command [arguments]
...`
```

### 3.5.2 Unicode

很久以前，生活很简单，至少在狭隘的视角下，只有一个字符集需要处理：ASCII，即美国信息交换标准代码。ASCII，或更准确地说 US-ASCII，使用 7 位来表示 128 个“字符”：英文大小写字母、数字，以及各种标点和设备控制字符。在计算机早期的大部分时间里，这已经足够，但它导致世界上很大一部分人口无法在计算机中使用自己的书写系统。随着互联网的增长，各种语言的数据变得更加普遍。如何处理这种丰富的多样性，如果可能的话，如何高效处理？

答案是 Unicode (`unicode.org`)，它收集了世界上所有书写系统中的所有字符，以及重音符号和其他变音符号、像制表符和回车符这样的控制码，还有大量晦涩字符，并为每一个分配一个标准编号，称为* Unicode 码点*，或者用 Go 术语来说，称为* rune*。

Unicode 8.0 版为 100 多种语言和文字中的 120,000 多个字符定义了码点。这些在计算机程序和数据中如何表示？保存单个 rune 的自然数据类型是 `int32`，这正是 Go 所使用的；它为此目的提供了同义词 `rune`。

我们可以用一系列 `int32` 值来表示一系列 rune。在这种称为 UTF-32 或 UCS-4 的表示法中，每个 Unicode 码点的编码大小相同，均为 32 位。这简单且统一，但比必要的空间大得多，因为大多数计算机可读文本是 ASCII，每个字符只需 8 位或 1 字节。广泛使用的所有字符总数仍少于 65,536，可以放入 16 位。我们能做得更好吗？
