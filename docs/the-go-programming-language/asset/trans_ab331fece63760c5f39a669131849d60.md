观察这两个示例之间的区别：

```
var i interface{} = 3

Display("i", i)
// Output:
// Display i (int):
// i = 3

Display("&i", &i)
// Output:
// Display &i (*interface {}):
// (*&i).type = int
// (*&i).value = 3
```

在第一个示例中，`Display` 调用 `reflect.ValueOf(i)`，它返回一个 Kind 为 `Int` 的值。正如我们在 [12.2 节](#ebook_split_112.html#id-reflecttypeandreflectvalue) 中提到的，`reflect.ValueOf` 总是返回一个具体类型的 `Value`，因为它会提取接口值的内容。

在第二个示例中，`Display` 调用 `reflect.ValueOf(&i)`，它返回一个指向 `i` 的指针，Kind 为 `Ptr`。`Ptr` 的 switch case 会对此值调用 `Elem`，它返回一个代表变量 `i` 本身的 `Value`，Kind 为 `Interface`。像这样间接获得的 `Value` 可以代表任意值，包括接口。`display` 函数会递归调用自身，这一次它会为接口的动态类型和值分别打印组件。

按目前的实现，如果 `Display` 在对象图中遇到循环，将永远不会终止，例如这个吞噬自己尾巴的链表：

[点击此处查看代码图像](#ch12_images.html#id337pro01_01_r)

```
// 一个指向自身的结构体
type Cycle struct{ Value int; Tail *Cycle }
var c Cycle
c = Cycle{42, &c}
Display("c", c)
```

`Display` 打印出这种不断增长的展开：

[点击此处查看代码图像](#ch12_images.html#id337pro02_r)

```
Display c (display.Cycle):
c.Value = 42
(*c.Tail).Value = 42
(*(*c.Tail).Tail).Value = 42
(*(*(*c.Tail).Tail).Tail).Value = 42
...ad infinitum...
```

许多 Go 程序至少包含一些循环数据。使 `Display` 对此类循环具有鲁棒性比较棘手，需要额外的记账工作来记录迄今为止已跟踪的引用集合；开销也很大。通用的解决方案需要 `unsafe` 语言特性，正如我们将在 [13.3 节](#ebook_split_123.html#id-exampledeepequivalence) 中看到的那样。

对 `fmt.Sprint` 而言，循环不构成太大问题，因为它很少尝试打印完整的结构。例如，当它遇到指针时，会通过打印指针的数值来中断递归。它可能会在尝试打印包含自身作为元素的切片或映射时陷入困境，但这种罕见情况不值得花费巨大精力去处理循环。

**练习 12.1：** 扩展 `Display`，使其能够显示键为结构体或数组的映射。

**练习 12.2：** 通过限制放弃递归前的步数，使 `display` 在循环数据结构上使用安全。（在 [13.3 节](#ebook_split_123.html#id-exampledeepequivalence) 中，我们将看到另一种检测循环的方法。）

## 12.4 示例：编码 S 表达式

`Display` 是一个用于显示结构化数据的调试例程，但它距离能够将任意 Go 对象编码或 *封送* 为适合进程间通信的可移植符号中的消息已经不远了。

正如我们在 [4.5 节](#ebook_split_039.html#id-json) 中所见，Go 标准库支持多种格式，包括 JSON、XML 和 ASN.1。另一种仍被广泛使用的符号是 *S 表达式*，即 Lisp 的语法。与其他符号不同，Go 标准库不支持 S 表达式，这在很大程度上是因为尽管经历过多次标准化尝试且存在许多实现，但 S 表达式并没有一个公认的通用定义。

在本节中，我们将定义一个包，使用支持以下结构的 S 表达式符号来编码任意 Go 对象：

[点击此处查看代码图像](#ch12_images.html#id338pro01_r)

```
42             整数
"hello"        字符串（带 Go 风格引号）
foo            符号（未加引号的名称）
(1 2 3)        列表   （用括号括起来的零个或多个项）
```

布尔值传统上使用符号 `t` 表示真，用空列表 `()` 或符号 `nil` 表示假，但为简单起见，我们的实现将忽略它们。它也会忽略通道和函数，因为它们的状态对反射是不透明的。并且它会忽略实数和复数浮点数以及接口。为它们添加支持是 [练习 12.3](#ebook_split_114.html#id-encodecases)。

我们将使用 S 表达式按如下方式编码 Go 的类型。整数和字符串以显而易见的方式编码。空值编码为符号 `nil`。数组和切片使用列表符号编码。
