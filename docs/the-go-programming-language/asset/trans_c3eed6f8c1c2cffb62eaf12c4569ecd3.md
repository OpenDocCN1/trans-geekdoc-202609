
# 2.3.2 指针

*变量* 是一块包含值的存储区域。通过声明创建的变量由一个名字标识，例如 `x`，但许多变量仅通过诸如 `x[i]` 或 `x.f` 之类的表达式来标识。所有这些表达式都读取变量的值，除非它们出现在赋值语句的左侧，在这种情况下会给变量赋予一个新值。

*指针* 值是一个变量的 *地址*。因此，指针是存储值的位置。并非每个值都有地址，但每个变量都有。通过指针，我们可以 *间接* 地读取或更新变量的值，而无需使用甚至知道该变量的名字（如果它确实有名字的话）。

如果一个变量声明为 `var x int`，表达式 `&x`（“`x` 的地址”）将产生一个指向整数变量的指针，即类型为 `*int` 的值，读作“指向 int 的指针”。如果这个值被称为 `p`，我们就说“`p` 指向 `x`”，或者等价地说“`p` 包含 `x` 的地址”。`p` 所指向的变量写作 `*p`。表达式 `*p` 产生该变量的值，即一个 `int`，但由于 `*p` 表示一个变量，它也可能出现在赋值语句的左侧，在这种情况下赋值会更新该变量。

```
x := 1
p := &x         // p, of type *int, points to x
fmt.Println(*p) // "1"
*p = 2          // equivalent to x = 2
fmt.Println(x)  // "2"
```

聚合类型变量的每个组成部分——结构体的字段或数组的元素——也是一个变量，因此也拥有地址。

变量有时被描述为 *可寻址* 的值。表示变量的表达式是唯一可以应用 *取地址* 操作符 `&` 的表达式。

任何类型指针的零值都是 `nil`。如果 `p` 指向一个变量，则测试 `p != nil` 为真。指针是可比较的；当且仅当两个指针指向同一个变量或两者都是 nil 时，它们才相等。

```
var x, y int
fmt.Println(&x == &x, &x == &y, &x == nil) // "true false false"
```

函数返回局部变量的地址是完全安全的。例如，在下面的代码中，由对 `f` 的这次特定调用创建的局部变量 `v` 即使在调用返回后仍将继续存在，指针 `p` 仍将引用它：

```
var p = f()

func f() *int {
    v := 1
    return &v
}
```

每次调用 `f` 都会返回一个不同的值：

```
fmt.Println(f() == f()) // "false"
```

因为指针包含变量的地址，将指针参数传递给函数使得函数能够更新被间接传递的变量。例如，此函数增加其参数所指向的变量的值，并返回该变量的新值，以便可在表达式中使用：

```
func incr(p *int) int {
    *p++ // increments what p points to; does not change p
    return *p
}

v := 1
incr(&v)              // side effect: v is now 2
fmt.Println(incr(&v)) // "3" (and v is 3)
```

每当我们获取一个变量的地址或复制一个指针时，我们都会为同一个变量创建新的 *别名* 或标识方式。例如，`*p` 是 `v` 的别名。指针别名很有用，因为它允许我们在不使用变量名的情况下访问变量，但这是一把双刃剑：要找到所有访问某个变量的语句，我们必须知道它的所有别名。不仅仅是指针会创建别名；当我们复制其他引用类型的值时，如切片、映射和通道，甚至包含这些类型的结构体、数组和接口，也会发生别名现象。

指针是 `flag` 包的关键，该包利用程序的命令行参数来设置分布在整个程序中的某些变量的值。为了说明这一点，这个早期 `echo` 命令的变体接受两个可选标志：`-n` 导致 `echo` 省略通常会打印的尾随换行符，而 `-s sep` 导致它使用字符串 `sep` 的内容分隔输出参数，而不是默认的单个空格。因为这是我们的第四个版本，所以该包称为 `gopl.io/ch2/echo4`。

```
gopl.io/ch2/echo4

// Echo4 prints its command-line arguments.
package main

import (
    "flag"
    "fmt"
    "strings"
)

var n = flag.Bool("n", false, "omit trailing newline")
var sep = flag.String("s", " ", "separator")

func main() {
    flag.Parse()
    fmt.Print(strings.Join(flag.Args(), *sep))
    if !*n {
        fmt.Println()
    }
}
```
