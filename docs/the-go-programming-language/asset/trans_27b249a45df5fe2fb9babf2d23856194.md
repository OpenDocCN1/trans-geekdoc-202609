
在线访问 Go 语言资源最有用的特性之一（而这也是纸质书籍令人遗憾的局限性）在于：可以直接运行网页中描述的 Go 程序。该功能由 `play.golang.org` 上的 Go Playground 提供，并可嵌入其他页面中，例如 `golang.org` 的主页或 `godoc` 工具提供的文档页面。

Playground 让用户能方便地进行简单实验，通过编写短程序来验证对语法、语义或库包的理解，在许多方面取代了其他语言中的“读取-求值-打印循环”（REPL）。其持久化的 URL 非常适合与他人分享 Go 代码片段、报告 Bug 或提出建议。

Go Tour（`tour.golang.org`）构建于 Playground 之上，由一系列简短的互动课程组成，涵盖 Go 语言的基本概念和结构，引导读者有序地了解该语言。

Playground 和 Tour 的主要短板是：它们只允许导入标准库，且出于实际或安全考虑，许多库特性（例如网络功能）受到限制。它们还需要联网才能编译和运行每个程序。因此，对于更复杂的实验，你必须在自己的计算机上运行 Go 程序。幸运的是，下载过程非常简单，从 `golang.org` 获取 Go 发行版并开始编写和运行自己的 Go 程序，通常只需几分钟。

由于 Go 是一个开源项目，你可以在 `https://golang.org/pkg` 在线阅读标准库中任意类型或函数的源代码；这些代码也包含在下载的发行版中。利用这一点可以弄清某事物的工作原理，解答关于细节的疑问，或者仅仅是看看专家是如何编写高质量 Go 代码的。

# 1. 教程

本章将带领大家游览 Go 语言的基本组成部分。我们希望提供足够的信息和示例，帮助你快速上手并尽早做出实用的东西。本书中的示例（包括本章）都针对你在现实世界中可能遇到的任务。在本章中，我们将尝试让你领略用 Go 编写程序的多样性，范围涵盖从简单的文件处理和图形绘制到并发的互联网客户端和服务器。我们当然不会在第一章解释所有内容，但在一门新语言中研究此类程序是一个有效的入门途径。

学习一门新语言时，人们自然倾向于用已熟知语言的风格来编写代码。学习 Go 时请留意这种偏见，并尽量避免。我们已努力阐释和解释如何编写地道的 Go 代码，因此在编写自己的代码时，请以此处的代码为指南。

## 1.1 Hello, World

我们将从经典的“hello, world”示例开始，它最早出现在 1978 年出版的《C 程序设计语言》开头。C 语言是 Go 语言最直接的影响来源之一，“hello, world”展示了许多核心概念。

[点击此处查看代码图片](#ch01_images.html#id001pro01_r)

gopl.io/ch1/helloworld

```
package main

import "fmt"

func main() {
    fmt.Println("Hello, ")
}
```

Go 是一门编译型语言。Go 工具链将源程序及其依赖转换为计算机原生机器语言的指令。这些工具通过一个名为 `go` 的单一命令访问，该命令包含若干子命令。最简单的子命令是 `run`，它编译一个或多个以 `.go` 结尾的源文件，将其与库链接，然后运行生成的可执行文件。（全书统一使用 `$` 作为命令提示符。）

```
$ go run helloworld.go
```

不出所料，这将打印

```
Hello, 
```

Go 原生支持 Unicode，因此可以处理世界上所有语言的文本。

如果程序不仅仅是一次性实验，你大概率希望编译一次并保存编译结果以备后用。这通过 `go build` 完成：

```
$ go build helloworld.go
```

这将创建一个名为 `helloworld` 的可执行二进制文件，可随时运行而无需进一步处理：

```
$ ./helloworld
Hello, 
```

我们为每个重要示例都加上了标签，提醒你可以从书籍的源代码仓库 `gopl.io` 获取代码：

gopl.io/ch1/helloworld

如果你运行 `go get gopl.io/ch1/helloworld`，它将获取源代码并将其放入相应目录。更多相关内容请参见 [第 2.6 节](#ebook_split_025.html#id-packagesandfiles) 和 [第 10.7 节](#ebook_split_102.html#id-thegotool)。

现在让我们谈谈程序本身。Go 代码组织在包中，这类似于其他语言中的库或模块。一个包由单个目录下的一个或多个 `.go` 源文件组成，定义了包的功能。每个源文件以 `package` 声明开头（此处为 `package main`），说明该文件属于哪个包，随后是导入的其他包列表，然后是该文件中存储的程序声明。

Go 标准库拥有 100 多个包，用于输入输出、排序、文本处理等常见任务。例如，`fmt` 包包含用于格式化输出和扫描输入的函数。`Println` 是 `fmt` 中的基本输出函数之一；它打印一个或多个值，值之间用空格分隔，并在末尾添加换行符，使这些值显示为单行输出。

`main` 包比较特殊。它定义了一个独立的可执行程序，而非库。在 `main` 包中，`main` `function`（函数）也很特殊——它是程序执行的入口。`main` 做什么，程序就做什么。当然，`main` 通常会调用其他包中的函数来完成大部分工作，例如 `fmt.Println` 函数。
