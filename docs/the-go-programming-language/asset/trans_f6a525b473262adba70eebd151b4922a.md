## 作用域与可见性

如果实体是在函数内部声明的，它对该函数是*局部*的。如果是在函数外部声明，则在其所属包的所有文件中均可见。名称首字母的大小写决定了其跨包边界的可见性。若以大写字母开头，则为*导出*的，意味着它在自己的包之外可见且可被访问，如 `fmt` 包中的 `Printf`。包名本身总是小写。

名称长度无限制，但 Go 程序的惯例和风格倾向于短名称，尤其是作用域较小的局部变量；你更可能看到名为 `i` 的变量，而非 `theLoopIndex`。通常，名称的作用域越大，其命名应越长且越有意义。

在风格上，Go 程序员组合单词形成名称时使用“驼峰命名法”；即首选内部大写字母，而非内部下划线。因此标准库中有 `QuoteRuneToASCII` 和 `parseRequestLine` 这样的函数名，但绝不会有 `quote_rune_to_ASCII` 或 `parse_request_line`。像 ASCII 和 HTML 这样的首字母缩略词的字母始终保持相同大小写，因此函数可能称为 `htmlEscape`、`HTMLEscape` 或 `escapeHTML`，但不应为 `escapeHtml`。

## 2.2 声明

*声明*为程序实体命名，并指定其部分或全部属性。主要有四种声明：`var`、`const`、`type` 和 `func`。本章讨论变量和类型，常量见[第 3 章](#ebook_split_027.html#id-basicdatatypes)，函数见[第 5 章](#ebook_split_041.html#id-functions)。

Go 程序存储在一个或多个以 `.go` 结尾的文件中。每个文件以 `package` 声明开头，说明该文件属于哪个包。随后是任意 `import` 声明，然后是类型、变量、常量和函数的*包级*声明序列，顺序不限。例如，下面的程序声明了一个常量、一个函数和几个变量：

[点击查看代码图像](#ch02_images.html#id029pro01_r)

gopl.io/ch2/boiling

```go
// Boiling prints the boiling point of water.
package main

import "fmt"

const boilingF = 212.0

func main() {
    var f = boilingF
    var c = (f - 32) * 5 / 9
    fmt.Printf("boiling point = %g°F or %g°C\n", f, c)
    // Output:
    // boiling point = 212°F or 100°C
}
```

常量 `boilingF` 是包级声明（`main` 也是），而变量 `f` 和 `c` 局限于 `main` 函数。每个包级实体的名称不仅在包含其声明的源文件中可见，而且在该包的所有文件中均可见。相比之下，局部声明仅在声明它们的函数内可见，甚至可能仅在函数的一小部分内可见。

函数声明包含名称、参数列表（由调用者提供值的变量）、可选的结果列表，以及函数体（定义函数功能的语句）。若函数无返回值，则省略结果列表。函数执行从第一条语句开始，直到遇到 `return` 语句或到达无结果函数的末尾。随后控制权及任何结果返回给调用者。

我们已见过不少函数，后续还有更多，包括第 5 章的详细讨论，此处仅作概述。下面的 `fToC` 函数封装了温度转换逻辑，使其仅定义一次却可在多处使用。这里 `main` 调用了它两次，使用两个不同局部常量的值：

[点击查看代码图像](#ch02_images.html#id029pro02_r)

gopl.io/ch2/ftoc

```go
// Ftoc prints two Fahrenheit-to-Celsius conversions.
package main

import "fmt"

func main() {
    const freezingF, boilingF = 32.0, 212.0
    fmt.Printf("%g°F = %g°C\n", freezingF, fToC(freezingF)) // "32°F = 0°C"
    fmt.Printf("%g°F = %g°C\n", boilingF, fToC(boilingF))   // "212°F = 100°C"
}

func fToC(f float64) float64 {
    return (f - 32) * 5 / 9
}
```

## 2.3 变量

`var` 声明创建特定类型的变量，赋予其名称，并设置初始值。每个声明的通用形式为：

```
var name type = expression
```

类型或 `=` `expression` 部分可以省略，但不能同时省略。若省略类型，则由初始化表达式推断。若省略表达式，初始值为该类型的*零值*：数字为 `0`，布尔值为 `false`，字符串为 `""`，接口和引用类型（切片、指针、映射、通道、函数）为 `nil`。数组或结构体等聚合类型的零值是其所有元素或字段的零值。

零值机制确保变量始终持有其类型的明确定义值；Go 中不存在未初始化变量。这简化了代码，且往往在无需额外工作的情况下保证边界条件的合理行为。例如：

```go
var s string
fmt.Println(s) // ""
```

将打印空字符串，而非导致错误或不可预测行为。Go 程序员常致力于使复杂类型的零值具有意义，以便变量一诞生即处于有用状态。

可在单个声明中声明并可选初始化一组变量，配合匹配的表达式列表。省略类型允许声明不同类型的多个变量：

[点击查看代码图像](#ch02_images.html#id030pro01_r)

```go
var i, j, k int                 // int, int, int
var b, f, s = true, 2.3, "four" // bool, float64, string
```

初始化表达式可以是字面值或任意表达式。包级变量在 `main` 开始前初始化（[§2.6.2](#ebook_split_025.html#id-packageinitialization)），局部变量在函数执行遇到其声明时初始化。

一组变量也可通过调用返回多值的函数来初始化：

[点击查看代码图像](#ch02_images.html#id030pro02_r)

```go
var f, err = os.Open(name) // os.Open returns a file and an error
```
