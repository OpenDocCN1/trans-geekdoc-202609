## 13.3 示例：深度相等

`reflect` 包中的 `DeepEqual` 函数用于报告两个值是否“深度”相等。`DeepEqual` 使用内置的 `==` 运算符比较基本值；对于复合值，它会递归遍历它们，比较对应的元素。因为它适用于任意一对值，甚至包括那些无法用 `==` 比较的值，所以它在测试中被广泛使用。以下测试使用 `DeepEqual` 来比较两个 `[]string` 值：

[点击此处查看代码图像](#ch13_images.html#id358pro03_r)

```
func TestSplit(t *testing.T) {
    got := strings.Split("a:b:c", ":")
    want := []string{"a", "b", "c"}
    if !reflect.DeepEqual(got, want) { /* ... */ }
}
```

虽然 `DeepEqual` 很方便，但它的区分标准可能显得武断。例如，它不认为 nil map 等于非 nil 的空 map，也不认为 nil slice 等于非 nil 的空 slice：

[点击此处查看代码图像](#ch13_images.html#id359pro01_r)

```
var a, b []string = nil, []string{}
fmt.Println(reflect.DeepEqual(a, b)) // "false"

var c, d map[string]int = nil, make(map[string]int)
fmt.Println(reflect.DeepEqual(c, d)) // "false"
```

在本节中，我们将定义一个函数 `Equal` 来比较任意值。与 `DeepEqual` 一样，它基于元素比较 slice 和 map，但与 `DeepEqual` 不同，它认为 nil slice（或 map）等于非 nil 的空 slice（或 map）。对参数的基本递归可以通过反射完成，使用类似于我们在 [12.3 节](#ebook_split_113.html#id-display) 中看到的 `Display` 程序的方法。像往常一样，我们定义一个未导出的函数 `equal` 用于递归。暂时不用担心 `seen` 参数。对于要比较的每一对值 `x` 和 `y`，`equal` 检查两者是否都有效（或都无效），并检查它们是否具有相同的类型。函数的结果定义为一组 switch case，用于比较两个相同类型的值。由于篇幅限制，我们省略了几个 case，因为到现在为止这种模式应该已经很熟悉了。

[点击此处查看代码图像](#ch13_images.html#id359pro02_r)

gopl.io/ch13/equal

```
func equal(x, y reflect.Value, seen map[comparison]bool) bool {
    if !x.IsValid() || !y.IsValid() {
        return x.IsValid() == y.IsValid()
    }
    if x.Type() != y.Type() {
        return false
    }

    // ...循环检查省略（稍后展示)...

    switch x.Kind() {
    case reflect.Bool:
        return x.Bool() == y.Bool()

    case reflect.String:
        return x.String() == y.String()

    // ...为简洁起见省略了数值 case...

    case reflect.Chan, reflect.UnsafePointer, reflect.Func:
        return x.Pointer() == y.Pointer()

    case reflect.Ptr, reflect.Interface:
        return equal(x.Elem(), y.Elem(), seen)

    case reflect.Array, reflect.Slice:
        if x.Len() != y.Len() {
            return false
        }
        for i := 0; i < x.Len(); i++ {
            if !equal(x.Index(i), y.Index(i), seen) {
                return false
            }
        }
        return true

    // ...为简洁起见省略了 struct 和 map case...
    }
    panic("unreachable")
}
```

像往常一样，我们不在 API 中暴露反射的使用，因此导出函数 `Equal` 必须对其参数调用 `reflect.ValueOf`：

[点击此处查看代码图像](#ch13_images.html#id360pro01_r)

```
// Equal 报告 x 和 y 是否深度相等。
func Equal(x, y interface{}) bool {
    seen := make(map[comparison]bool)
    return equal(reflect.ValueOf(x), reflect.ValueOf(y), seen)
}

type comparison struct {
    x, y unsafe.Pointer
    t    reflect.Type
}
```

为了确保算法即使对于循环数据结构也能终止，它必须记录已经比较过哪些变量对，并避免第二次比较它们。`Equal` 分配一组 `comparison` 结构体，每个结构体保存两个变量的地址（表示为 `unsafe.Pointer` 值）和比较的类型。我们除了地址之外还需要记录类型，因为不同的变量可能具有相同的地址。例如，如果 `x` 和 `y` 都是数组，`x` 和 `x[0]` 具有相同的地址，`y` 和 `y[0]` 也是如此，区分我们是比较了 `x` 和 `y` 还是 `x[0]` 和 `y[0]` 非常重要。

一旦 `equal` 确定其参数具有相同类型，并在执行 switch 之前，它会检查是否在比较两个已经见过的变量，如果是，则终止递归。

[点击此处查看代码图像](#ch13_images.html#id360pro02_r)

```
// 循环检查
if x.CanAddr() && y.CanAddr() {
    xptr := unsafe.Pointer(x.UnsafeAddr())
    yptr := unsafe.Pointer(y.UnsafeAddr())
    if xptr == yptr {
        return true // 相同引用
    }
    c := comparison{xptr, yptr, x.Type()}
    if seen[c] {
        return true // 已见过
    }
    seen[c] = true
}
```

这是我们的 `Equal` 函数的实际运行效果：

[点击此处查看代码图像](#ch13_images.html#id360pro03_r)

```
fmt.Println(Equal([]int{1, 2, 3}, []int{1, 2, 3}))        // "true"
fmt.Println(Equal([]string{"foo"}, []string{"bar"}))      // "false"
fmt.Println(Equal([]string(nil), []string{}))             // "true"
fmt.Println(Equal(map[string]int(nil), map[string]int{})) // "true"
```

它甚至适用于类似于导致 [12.3 节](#ebook_split_113.html#id-display) 中的 `Display` 函数陷入循环的循环输入：

[点击此处查看代码图像](#ch13_images.html#id361pro01_r)

```
// 循环链表 a -> b -> a 和 c -> c。
type link struct {
    value string
    tail  *link
}
a, b, c := &link{value: "a"}, &link{value: "b"}, &link{value: "c"}
a.tail, b.tail, c.tail = b, a, c
fmt.Println(Equal(a, a)) // "true"
fmt.Println(Equal(b, b)) // "true"
fmt.Println(Equal(c, c)) // "true"
fmt.Println(Equal(a, b)) // "false"
fmt.Println(Equal(a, c)) // "false"
```

## 13.4 使用 `cgo` 调用 C 代码

Go 程序可能需要使用 C 实现的硬件驱动程序、查询 C++ 实现的嵌入式数据库，或使用 Fortran 实现的某些线性代数例程。C 长期以来一直是编程领域的通用语言，因此许多旨在广泛使用的包都会导出兼容 C 的 API，无论其实现语言是什么。

在本节中，我们将构建一个简单的数据压缩程序，它使用 `cgo`，这是一个为 C 函数创建 Go 绑定的工具。此类工具称为*外部函数接口*（FFI），`cgo` 并不是 Go 程序唯一的此类工具。SWIG (`swig.org`) 是另一个；它提供了与 C++ 类集成的更复杂功能，但我们这里不演示它。

标准库的 `compress/...` 子树为流行的压缩算法提供了压缩器和解压缩器，包括 LZW（Unix `compress` 命令使用）和 DEFLATE（GNU `gzip` 命令使用）。这些包的 API 在细节上略有不同，但它们都为 `io.Writer` 提供了一个压缩写入数据的包装器，并为 `io.Reader` 提供了一个解压缩读取数据的包装器。例如：

[点击此处查看代码图像](#ch13_images.html#id361pro02_r)

```
package gzip // compress/gzip

func NewWriter(w io.Writer) io.WriteCloser
func NewReader(r io.Reader) (io.ReadCloser, error)
```
