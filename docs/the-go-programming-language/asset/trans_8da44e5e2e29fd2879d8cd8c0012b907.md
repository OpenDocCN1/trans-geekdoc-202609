## 1.5 获取 URL

对于许多应用程序而言，从互联网获取信息与访问本地文件系统同样重要。Go 提供了一组包，归类在 `net` 下，它们使得通过互联网发送和接收信息、建立低级网络连接以及搭建服务器变得容易，而 Go 的并发特性（将在第 8 章[第 8 章](#ebook_split_075.html#id-concurrency)中介绍）对于服务器编程特别有用。

为了演示通过 HTTP 检索信息所需的最小代码量，这里有一个名为 `fetch` 的简单程序，它获取每个指定 URL 的内容并将其作为未经解释的文本打印出来；它的灵感来源于不可或缺的工具 `curl`。显然，通常我们会对这些数据做更多处理，但这展示了基本思路。我们将在本书中频繁使用该程序。

[点击此处查看代码图像](#ch01_images.html#id016pro01_r)

`gopl.io/ch1/fetch`

```
// Fetch prints the content found at a URL.
package main

import (
    "fmt"
    "io/ioutil"
    "net/http"
    "os"
)

func main() {
    for _, url := range os.Args[1:] {
        resp, err := http.Get(url)
        if err != nil {
            fmt.Fprintf(os.Stderr, "fetch: %v\n", err)
            os.Exit(1)
        }
        b, err := ioutil.ReadAll(resp.Body)
        resp.Body.Close()
        if err != nil {
            fmt.Fprintf(os.Stderr, "fetch: reading %s: %v\n", url, err)
            os.Exit(1)
        }
        fmt.Printf("%s", b)
    }
}
```

该程序介绍了来自两个包的函数：`net/http` 和 `io/ioutil`。`http.Get` 函数发起一个 HTTP 请求，如果没有错误发生，则在响应结构体 `resp` 中返回结果。`resp` 的 `Body` 字段包含一个可读的流作为服务器响应。接下来，`ioutil.ReadAll` 读取整个响应；结果存储在 `b` 中。关闭 `Body` 流以避免资源泄漏，`Printf` 将响应写入标准输出。

[点击此处查看代码图像](#ch01_images.html#id016pro02_r)

```
$ go build gopl.io/ch1/fetch
$ ./fetch http://gopl.io
<html>
<head>
<title>The Go Programming Language</title>
...
```

如果 HTTP 请求失败，`fetch` 会报告失败：

[点击此处查看代码图像](#ch01_images.html#id017pro01_r)

```
$ ./fetch http://bad.gopl.io
fetch: Get http://bad.gopl.io: dial tcp: lookup bad.gopl.io: no such host
```

在任一错误情况下，`os.Exit(1)` 都会导致进程以状态码 1 退出。

**练习 1.7：** 函数调用 `io.Copy(dst, src)` 从 `src` 读取并写入 `dst`。用它代替 `ioutil.ReadAll` 将响应体复制到 `os.Stdout`，这样就不需要一个足以容纳整个流的大缓冲区。务必检查 `io.Copy` 的错误结果。

**练习 1.8：** 修改 `fetch`，如果参数 URL 缺少 `http://` 前缀，则自动添加。你可能会用到 `strings.HasPrefix`。

**练习 1.9：** 修改 `fetch`，使其同时打印 HTTP 状态码，该状态码位于 `resp.Status` 中。

## 1.6 并发获取多个 URL

Go 最有趣、最新颖的方面之一是其对并发编程的支持。这是一个大话题，第 8 章[第 8 章](#ebook_split_075.html#id-concurrency)和第 9 章[第 9 章](#ebook_split_086.html#id-concurrencywithsharedvariables)将专门讨论，因此这里我们只是让你略窥 Go 主要并发机制——goroutine 和 channel 的门径。

下一个程序 `fetchall` 与前一个示例一样获取 URL 的内容，但它并发地获取多个 URL，因此该过程所花费的时间不会超过最慢的那一次获取，而不是所有获取时间之和。这个版本的 `fetchall` 丢弃响应内容，但报告每个请求的大小和耗时：

[点击此处查看代码图像](#ch01_images.html#id017pro02_r)

`gopl.io/ch1/fetchall`

```
// Fetchall fetches URLs in parallel and reports their times and sizes.
package main

import (
    "fmt"
    "io"
    "io/ioutil"
    "net/http"
    "os"
    "time"
)

func main() {
    start := time.Now()
    ch := make(chan string)
    for _, url := range os.Args[1:] {
        go fetch(url, ch) // start a goroutine
    }
    for range os.Args[1:] {
        fmt.Println(<-ch) // receive from channel ch
    }
    fmt.Printf("%.2fs elapsed\n", time.Since(start).Seconds())
}

func fetch(url string, ch chan<- string) {
    start := time.Now()
    resp, err := http.Get(url)
    if err != nil {
        ch <- fmt.Sprint(err) // send to channel ch
        return
    }

    nbytes, err := io.Copy(ioutil.Discard, resp.Body)
    resp.Body.Close() // don't leak resources
    if err != nil {
        ch <- fmt.Sprintf("while reading %s: %v", url, err)
        return
    }
    secs := time.Since(start).Seconds()
    ch <- fmt.Sprintf("%.2fs  %7d  %s", secs, nbytes, url)
}
```

这是一个示例：

[点击此处查看代码图像](#ch01_images.html#id018pro01_r)

```
$ go build gopl.io/ch1/fetchall
$ ./fetchall https://golang.org http://gopl.io https://godoc.org
0.14s     6852  https://godoc.org
0.16s     7261  https://golang.org
0.48s     2475  http://gopl.io
0.48s elapsed
```

*goroutine* 是一种并发的函数执行。*channel* 是一种通信机制，允许一个 goroutine 将指定类型的值传递给另一个 goroutine。`main` 函数运行在一个 goroutine 中，`go` 语句创建额外的 goroutine。

`main` 函数使用 `make` 创建一个字符串 channel。对于每个命令行参数，第一个 range 循环中的 `go` 语句启动一个新的 goroutine，异步调用 `fetch` 并使用 `http.Get` 获取 URL。`io.Copy` 函数读取响应体并通过写入 `ioutil.Discard` 输出流来丢弃它。`Copy` 返回字节计数以及发生的任何错误。随着每个结果的到达，`fetch` 在 channel `ch` 上发送一行汇总信息。`main` 中的第二个 range 循环接收并打印这些行。

当一个 goroutine 尝试在 channel 上发送或接收时，它会阻塞，直到另一个 goroutine 尝试执行相应的接收或发送操作，此时值被传递，两个 goroutine 继续执行。在本例中，每个 `fetch` 在 channel `ch` 上发送一个值（`ch <- 表达式`），而 `main` 接收所有这些值（`<-ch`）。让 `main` 处理所有打印可确保每个 goroutine 的输出作为一个整体被处理，如果两个 goroutine 同时完成，不会出现交织输出的危险。
