
由于在文件结束条件下，除了这一事实本身外没有其他信息可报告，因此 `io.EOF` 具有固定的错误消息 `"EOF"`。对于其他错误，我们可能需要报告错误的“性质”和“数量”，可以说，因此固定的错误值将无法满足需求。在 [7.11 节](#ebook_split_070.html#id-discriminatingerrors) 中，我们将介绍一种更系统的方法来将特定错误值与其他错误值区分开来。

## 5.5 函数值

在 Go 中，函数是*一等值*：与其他值一样，函数值拥有类型，它们可以被赋值给变量，也可以作为参数传递给函数或从函数返回。函数值可以像其他函数一样被调用。例如：

[点击此处查看代码图像](#ch05_images.html#id132pro03_r)

```
func square(n int) int     { return n * n }
func negative(n int) int   { return -n }
func product(m, n int) int { return m * n }

f := square
fmt.Println(f(3)) // "9"

f = negative
fmt.Println(f(3))     // "-3"
fmt.Printf("%T\n", f) // "func(int) int"

f = product // 编译错误：无法将 f(int, int) int 赋值给 f(int) int
```

函数类型的零值是 `nil`。调用 nil 函数值会导致 panic：

[点击此处查看代码图像](#ch05_images.html#id132pro04_r)

```
var f func(int) int
f(3) // panic: call of nil function
```

函数值可以与 `nil` 比较：

```
var f func(int) int
if f != nil {
    f(3)
}
```

但它们不可比较，因此不能相互比较，也不能用作 map 的键。

函数值让我们能够不仅针对数据，还能针对行为对函数进行参数化。标准库中包含许多示例。例如，`strings.Map` 会将一个函数应用于字符串的每个字符，将结果连接起来形成另一个字符串。

[点击此处查看代码图像](#ch05_images.html#id133pro01_r)

```
func add1(r rune) rune { return r + 1 }

fmt.Println(strings.Map(add1, "HAL-9000")) // "IBM.:111"
fmt.Println(strings.Map(add1, "VMS"))      // "WNT"

fmt.Println(strings.Map(add1, "Admix"))    // "Benjy"
```

[5.2 节](#ebook_split_043.html#id-recursion) 中的 `findLinks` 函数使用了一个辅助函数 `visit`，来访问 HTML 文档中的所有节点并对每个节点应用一个操作。通过使用函数值，我们可以将树遍历的逻辑与要应用于每个节点的操作逻辑分离开来，从而让我们能够用不同的操作复用遍历逻辑。

[点击此处查看代码图像](#ch05_images.html#id133pro02_r)

gopl.io/ch5/outline2

```
// forEachNode 对树 n 中的每个节点 x 调用函数 pre(x) 和 post(x)。
// 这两个函数都是可选的。
// pre 在访问子节点之前被调用（前序），post 在之后被调用（后序）。
func forEachNode(n *html.Node, pre, post func(n *html.Node)) {
    if pre != nil {
        pre(n)
    }

    for c := n.FirstChild; c != nil; c = c.NextSibling {
        forEachNode(c, pre, post)
    }

    if post != nil {
        post(n)
    }
}
```

`forEachNode` 函数接受两个函数参数，一个在访问节点的子节点之前调用，一个在之后调用。这种安排给调用者提供了极大的灵活性。例如，函数 `startElement` 和 `endElement` 打印 HTML 元素的开始和结束标签，如 `<b>...</b>`：

[点击此处查看代码图像](#ch05_images.html#id133pro03_r)

```
var depth int

func startElement(n *html.Node) {
    if n.Type == html.ElementNode {
        fmt.Printf("%*s<%s>\n", depth*2, "", n.Data)
        depth++
    }
}

func endElement(n *html.Node) {
    if n.Type == html.ElementNode {
        depth--
        fmt.Printf("%*s</%s>\n", depth*2, "", n.Data)
    }
}
```

这些函数还利用另一个 `fmt.Printf` 技巧来缩进输出。`%*s` 中的 `*` 修饰符会打印一个用可变数量的空格填充的字符串。宽度和字符串由参数 `depth*2` 和 `""` 提供。


## 5.6 匿名函数

命名函数只能在包级别声明，但我们可以使用*函数字面量*在任何表达式中表示一个函数值。函数字面量的写法类似于函数声明，但在 `func` 关键字后没有函数名。它是一个表达式，其值被称为*匿名函数*。

函数字面量让我们能够在使用点定义函数。作为一个例子，前面对 `strings.Map` 的调用可以重写为：

[点击此处查看代码图像](#ch05_images.html#id135pro02_r)

```
strings.Map(func(r rune) rune { return r + 1 }, "HAL-9000")
```

更重要的是，以这种方式定义的函数可以访问完整的词法环境，因此内部函数可以引用外部函数的变量，如下例所示：

[点击此处查看代码图像](#ch05_images.html#id135pro03_r)

gopl.io/ch5/squares

```
// squares 返回一个函数，每次调用该函数都会返回下一个平方数。
func squares() func() int {
    var x int
    return func() int {
        x++
        return x * x
    }
}

func main() {
    f := squares()
    fmt.Println(f()) // "1"
    fmt.Println(f()) // "4"
    fmt.Println(f()) // "9"
    fmt.Println(f()) // "16"
}
```

函数 `squares` 返回另一个类型为 `func() int` 的函数。调用 `squares` 会创建一个局部变量 `x` 并返回一个匿名函数，每次调用该匿名函数时，它都会递增 `x` 并返回其平方。第二次调用 `squares` 将创建第二个变量 `x` 并返回一个新的匿名函数，该函数递增这个新变量。

`squares` 示例表明函数值不仅仅是代码，还可以拥有状态。匿名内部函数可以访问并更新外部函数 `squares` 的局部变量。这些隐藏的变量引用就是我们将函数归类为引用类型以及函数值不可比较的原因。像这样的函数值是使用一种称为*闭包*的技术实现的，Go 程序员经常用这个术语来指代函数值。

这里我们再次看到一个变量的生命周期不由其作用域决定的例子：变量 `x` 在 `squares` 返回后仍存在于 `main` 中，即使 `x` 隐藏在 `f` 内部。
