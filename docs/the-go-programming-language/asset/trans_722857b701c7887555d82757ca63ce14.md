
下面的 `Unpack` 函数执行三项任务。首先，它调用 `req.ParseForm()` 来解析请求。此后，`req.Form` 包含所有参数，无论 HTTP 客户端使用的是 GET 还是 POST 请求方法。

接下来，`Unpack` 会建立一个映射，从每个字段的*有效*名称到该字段对应的变量。如果字段带有标签，有效名称可能与实际名称不同。`reflect.Type` 的 `Field` 方法返回一个 `reflect.StructField`，它提供了关于每个字段类型的信息，如名称、类型和可选标签。`Tag` 字段是一个 `reflect.StructTag`，这是一个字符串类型，提供了一个 `Get` 方法来解析并提取特定键的子串，本例中即为 `http:"..."`。

[点击此处查看代码图像](#ch12_images.html#id349pro01_r)

gopl.io/ch12/params

```
func Unpack(req *http.Request, ptr interface{}) error {
    if err := req.ParseForm(); err != nil {
        return err
    }

    // Build map of fields keyed by effective name.
    fields := make(map[string]reflect.Value)
    v := reflect.ValueOf(ptr).Elem() // the struct variable
    for i := 0; i < v.NumField(); i++ {
        fieldInfo := v.Type().Field(i) // a reflect.StructField
        tag := fieldInfo.Tag           // a reflect.StructTag
        name := tag.Get("http")
        if name == "" {
            name = strings.ToLower(fieldInfo.Name)
        }
        fields[name] = v.Field(i)
    }

    // Update struct field for each parameter in the request.
    for name, values := range req.Form {
        f := fields[name]
        if !f.IsValid() {
            continue // ignore unrecognized HTTP parameters
        }
        for _, value := range values {
            if f.Kind() == reflect.Slice {
                elem := reflect.New(f.Type().Elem()).Elem()
                if err := populate(elem, value); err != nil {
                    return fmt.Errorf("%s: %v", name, err)
                }
                f.Set(reflect.Append(f, elem))
            } else {
                if err := populate(f, value); err != nil {
                    return fmt.Errorf("%s: %v", name, err)
                }
            }
        }
    }
    return nil
}
```

最后，`Unpack` 遍历 HTTP 参数的名称/值对，并更新相应的结构体字段。请记住，同一个参数名可能出现多次。如果发生这种情况，且该字段是一个切片，则该参数的所有值都会累积到该切片中。否则，该字段会被反复覆写，以至于只有最后一个值生效。

`populate` 函数负责根据参数值设置单个字段 `v`（或切片字段的单个元素）。目前，它仅支持字符串、有符号整数和布尔值。支持其他类型留作练习。

[点击此处查看代码图像](#ch12_images.html#id350pro01_r)

```
func populate(v reflect.Value, value string) error {
    switch v.Kind() {
    case reflect.String:
        v.SetString(value)

    case reflect.Int:
        i, err := strconv.ParseInt(value, 10, 64)
        if err != nil {
            return err
        }
        v.SetInt(i)

    case reflect.Bool:
        b, err := strconv.ParseBool(value)
        if err != nil {
            return err
        }
        v.SetBool(b)

    default:
        return fmt.Errorf("unsupported kind %s", v.Type())
    }
    return nil
}
```

## 12.8 显示类型的方法

我们反射的最后一个示例使用 `reflect.Type` 来打印任意值的类型并枚举其方法：

[点击此处查看代码图像](#ch12_images.html#id351pro01_r)

gopl.io/ch12/methods

```
func Print(x interface{}) {
    v := reflect.ValueOf(x)
    t := v.Type()
    fmt.Printf("type %s\n", t)

    for i := 0; i < v.NumMethod(); i++ {
        methType := v.Method(i).Type()
        fmt.Printf("func (%s) %s%s\n", t, t.Method(i).Name,
            strings.TrimPrefix(methType.String(), "func"))
    }
}
```

`reflect.Type` 和 `reflect.Value` 都有一个名为 `Method` 的方法。每次 `t.Method(i)` 调用返回一个 `reflect.Method` 实例，这是一个结构体类型，描述单个方法的名称和类型。每次 `v.Method(i)` 调用返回一个 `reflect.Value`，代表一个方法值（[§6.4](#ebook_split_056.html#id-methodvaluesandexpressions)），即绑定到其接收者的方法。使用 `reflect.Value.Call` 方法（此处因篇幅限制不作展示），可以像调用这种 `Func` 类型的 `Value` 一样进行调用，但本程序只需要它的 `Type`。

## 12.9 一句忠告

反射 API 的内容远不止我们有空间展示的这些，但前面的示例已经让你了解可能实现的功能。反射是一个强大且富有表现力的工具，但应谨慎使用，主要有三个原因。

第一个原因是基于反射的代码比较脆弱。对于每一个会导致编译器报告类型错误的失误，都有相应的反射误用方式，但编译器会在构建时报告错误，而反射错误则在执行期间作为 panic 报告，可能是在程序编写很久之后，甚至是在程序开始运行很久之后。
