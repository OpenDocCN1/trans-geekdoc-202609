
所以 January 是 `months[1]`，December 是 `months[12]`。通常，索引为 0 的数组元素会包含第一个值，但因为月份总是从 1 开始编号，我们可以在声明中省略它，它将被初始化为空字符串。

*切片操作符* `s[i:j]`，其中 0 ≤ `i` ≤ `j` ≤ `cap(s)`，会创建一个新切片，引用序列 `s` 中从 `i` 到 `j-1` 的元素，序列 `s` 可以是数组变量、数组指针或另一个切片。生成的切片有 `j-i` 个元素。如果省略 `i`，则默认为 0；如果省略 `j`，则默认为 `len(s)`。因此切片 `months[1:13]` 引用了所有有效月份的范围，`months[1:]` 也是如此；切片 `months[:]` 引用整个数组。让我们为第二季度和北半球夏天定义重叠的切片：

[点击此处查看代码图像](#ch04_images.html#id085pro01_r)

```
Q2 := months[4:7]
summer := months[6:9]
fmt.Println(Q2)     // ["April" "May" "June"]
fmt.Println(summer) // ["June" "July" "August"]
```

June 包含在两者中，并且是这个（低效的）公共元素测试的唯一输出：

[点击此处查看代码图像](#ch04_images.html#id085pro02_r)

```
for _, s := range summer {
    for _, q := range Q2 {
        if s == q {
            fmt.Printf("%s appears in both\n", s)
        }
    }
}
```

超出 `cap(s)` 进行切片会导致 panic，但超出 `len(s)` 进行切片会扩展切片，因此结果可能比原切片更长：

[点击此处查看代码图像](#ch04_images.html#id086pro01_r)

```
fmt.Println(summer[:20]) // panic: out of range

endlessSummer := summer[:5] // extend a slice (within capacity)
fmt.Println(endlessSummer)  // "[June July August September October]"
```

顺便提一下，注意字符串上的子串操作与 `[]byte` 切片上的切片操作的相似性。两者都写作 `x[m:n]`，都返回原始字节的子序列，共享底层表示，因此两种操作都只需常数时间。如果 `x` 是字符串，表达式 `x[m:n]` 产生一个字符串；如果 `x` 是 `[]byte`，则产生一个 `[]byte`。

既然切片包含指向数组元素的指针，将切片传给函数允许函数修改底层数组元素。换句话说，复制切片会为底层数组创建一个*别名*（[§2.3.2](#ebook_split_022.html#id-aliasing)）。函数 `reverse` 就地反转 `[]int` 切片的元素，它可以应用于任意长度的切片。

[点击此处查看代码图像](#ch04_images.html#id086pro02_r)

gopl.io/ch4/rev

```
// reverse reverses a slice of ints in place.
// reverse 就地反转 int 切片。
func reverse(s []int) {
    for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
        s[i], s[j] = s[j], s[i]
    }
}
```

这里我们反转整个数组 `a`：

[点击此处查看代码图像](#ch04_images.html#id086pro03_r)

```
a := [...]int{0, 1, 2, 3, 4, 5}
reverse(a[:])
fmt.Println(a) // "[5 4 3 2 1 0]"
```

将切片向左*旋转* n 个元素的简单方法是三次应用 `reverse` 函数：首先作用于前导 n 个元素，然后作用于剩余元素，最后作用于整个切片。（要向右旋转，先进行第三次调用。）

[点击此处查看代码图像](#ch04_images.html#id086pro04_r)

```
s := []int{0, 1, 2, 3, 4, 5}
// Rotate s left by two positions.
// 将 s 向左旋转两个位置。
reverse(s[:2])
reverse(s[2:])
reverse(s)
fmt.Println(s) // "[2 3 4 5 0 1]"
```

注意初始化切片 `s` 的表达式与数组 `a` 的有何不同。*切片字面量*看起来像数组字面量，是一个由逗号分隔、用花括号包围的值序列，但不指定大小。这会隐式地创建一个适当大小的数组变量，并产生一个指向它的切片。与数组字面量一样，切片字面量可以按顺序指定值，或显式给出索引，或混合使用这两种风格。

与数组不同，切片不可比较，所以我们不能用 `==` 来测试两个切片是否包含相同元素。标准库提供了高度优化的 `bytes.Equal` 函数用于比较两个字节切片（`[]byte`），但对于其他类型的切片，我们必须自己进行比较：

[点击此处查看代码图像](#ch04_images.html#id087pro01_r)

```
func equal(x, y []string) bool {
    if len(x) != len(y) {
        return false
    }
    for i := range x {
        if x[i] != y[i] {
            return false
        }
    }
    return true
}
```

考虑到这种“深度”相等测试是多么自然，且其运行时开销并不比字符串数组的 `==` 操作符更大，切片比较不以这种方式工作可能令人费解。深度等价有问题主要有两个原因。首先，与数组元素不同，切片元素是间接的，这使得切片有可能包含其自身。虽然有办法处理这种情况，但没有一种是简单、高效且最重要的是显而易见的。

其次，因为切片元素是间接的，随着底层数组内容被修改，一个固定的切片值在不同时间可能包含不同的元素。因为像 Go 的 map 类型这样的哈希表只对其键进行浅拷贝，它要求每个键的相等性在哈希表的整个生命周期内保持不变。因此深度等价会使切片不适合用作 map 键。对于指针和通道等引用类型，`==` 操作符测试*引用身份*，即两个实体是否指向同一事物。针对切片的类似“浅”相等测试可能很有用，并能解决 map 的问题，但 `==` 操作符对切片和数组的不一致处理会令人困惑。最稳妥的选择是完全禁止切片比较。

唯一合法的切片比较是与 `nil` 比较，如：

```
if summer == nil { /* ... */ }
```

切片类型的零值是 `nil`。nil 切片没有底层数组。nil 切片的长度和容量为零，但也存在长度和容量为零的非 nil 切片，例如 `[]int{}` 或 `make([]int, 3)[3:]`。与任何可以有 nil 值的类型一样，特定切片类型的 nil 值可以用转换表达式书写，如 `[]int(nil)`。

[点击此处查看代码图像](#ch04_images.html#id087pro02_r)

```
var s []int    // len(s) == 0, s == nil
s = nil        // len(s) == 0, s == nil
s = []int(nil) // len(s) == 0, s == nil
s = []int{}    // len(s) == 0, s != nil
```

因此，如果你需要测试切片是否为空，请使用 `len(s) == 0`，而不是 `s == nil`。除了与 `nil` 比较相等外，nil 切片的行为像任何其他零长度切片一样；例如 `reverse(nil)` 完全安全。除非文档明确说明相反情况，Go 函数应以相同方式对待所有零长度切片，无论是 nil 还是非 nil。

内置函数 `make` 创建一个指定元素类型、长度和容量的切片。容量参数可以省略，在这种情况下容量等于长度。

[点击此处查看代码图像](#ch04_images.html#id088pro01_r)

```
make([]T, len)
make([]T, len, cap) // same as make([]T, cap)[:len]
```

在底层，`make` 创建一个未命名的数组变量并返回它的切片；该数组只能通过返回的切片访问。在第一种形式中，切片是整个数组的视图。在第二种形式中，切片只是数组前 `len` 个元素的视图，但其容量包含整个数组。额外的元素被预留用于未来增长。
