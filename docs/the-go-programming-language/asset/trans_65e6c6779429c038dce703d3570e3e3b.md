
有多种方法可以处理这个潜在问题。最直接的方法是避免使用 `:=`，而是在单独的 `var` 声明中声明 `err`：

[点击此处查看代码图像](#ch02_images.html#id049pro03_r)

```
var cwd string

func init() {
    var err error
    cwd, err = os.Getwd()
    if err != nil {
        log.Fatalf("os.Getwd failed: %v", err)
    }
}
```

我们现在已经了解了包、文件、声明和语句如何表达程序的结构。在接下来的两章中，我们将探讨数据的结构。

# 3. 基本数据类型

归根结底，一切皆比特，但计算机从根本上操作的是称为*字*的固定大小数字，它们被解释为整数、浮点数、位集或内存地址，然后组合成更大的聚合体，以表示数据包、像素、投资组合、诗歌以及其他一切事物。Go 提供了多种组织数据的方式，拥有一系列数据类型，一端匹配硬件特性，另一端提供程序员方便表示复杂数据结构所需的功能。

Go 的类型分为四类：*基本类型*、*聚合类型*、*引用类型*和*接口类型*。基本类型是本章的主题，包括数字、字符串和布尔值。聚合类型——数组（[§4.1](#ebook_split_035.html#id-arrays)）和结构体（[§4.4](#ebook_split_038.html#id-structs)）——通过组合多个更简单的值来形成更复杂的数据类型。引用类型是一个多样化的群体，包括指针（[§2.3.2](#ebook_split_022.html#id-pointers)）、切片（[§4.2](#ebook_split_036.html#id-slices)）、映射（[§4.3](#ebook_split_037.html#id-maps)）、函数（[第 5 章](#ebook_split_041.html#id-functions)）和通道（[第 8 章](#ebook_split_075.html#id-concurrency)），但它们的共同点是都*间接*引用程序变量或状态，因此对某个引用应用的操作效果会被该引用的所有副本观察到。最后，我们将在[第 7 章](#ebook_split_059.html#id-interfaces)中讨论接口类型。

## 3.1 整数

Go 的数值数据类型包括多种大小的整数、浮点数和复数。每种数值类型决定了其值的大小和符号性。让我们从整数开始。

Go 同时提供有符号和无符号整数运算。有四种不同大小的有符号整数——8、16、32 和 64 位——分别由类型 `int8`、`int16`、`int32` 和 `int64` 表示，以及对应的无符号版本 `uint8`、`uint16`、`uint32` 和 `uint64`。

还有两种类型仅称为 `int` 和 `uint`，它们是在特定平台上有符号和无符号整数的自然或最高效大小；`int` 是迄今为止使用最广泛的数值类型。这两种类型具有相同的大小，要么是 32 位，要么是 64 位，但不能假设是哪一种；即使在相同的硬件上，不同的编译器也可能做出不同的选择。

类型 `rune` 是 `int32` 的同义词，通常表示某个值是 Unicode 码点。这两个名称可以互换使用。类似地，类型 `byte` 是 `uint8` 的同义词，强调该值是一段原始数据，而不是一个微小的数值。

最后，还有一种无符号整数类型 `uintptr`，其宽度未指定，但足以容纳指针值的所有位。`uintptr` 类型仅用于底层编程，例如在 Go 程序与 C 库或操作系统的边界处。当我们在[第 13 章](#ebook_split_120.html#id-lowlevelprogramming)处理 `unsafe` 包时将会看到相关示例。

无论其大小如何，`int`、`uint` 和 `uintptr` 都与其显式指定大小的同类类型不同。因此 `int` 与 `int32` 不是同一类型，即使整数的自然大小是 32 位，将 `int` 值用于需要 `int32` 的地方（反之亦然）也需要显式转换。

有符号数采用二进制补码形式表示，其中高位保留用于数字的符号，*n* 位数字的取值范围是从 −2^(*n*−1) 到 2^(*n*−1)−1。无符号整数将所有位用于非负值，因此取值范围是 0 到 2^(*n*)−1。例如，`int8` 的范围是 −128 到 127，而 `uint8` 的范围是 0 到 255。

Go 的算术、逻辑和比较二元运算符按优先级递减顺序列在下面：

[点击此处查看代码图像](#ch03_images.html#id052pro01_r)

```
*    /    %    <<    >>    &    &^
+    -    |    ^
==   !=   <    <=    >     >=
&&
||
```

二元运算符只有五级优先级。同一级别的运算符从左结合，因此为了清晰起见，或者为了使运算符按预期顺序求值（如表达式 `mask & (1 << 28)`），可能需要使用括号。

例如，上表前两行中的每个运算符（如 `+`）都有一个对应的*赋值运算符*（如 `+=`），可用于缩短赋值语句。

整数算术运算符 `+`、`-`、`*` 和 `/` 可用于整数、浮点数和复数，但取余运算符 `%` 仅适用于整数。不同编程语言中 `%` 对负数的行为各异。在 Go 中，余数的符号总是与被除数的符号相同，因此 `-5%3` 和 `-5%-3` 结果都是 `-2`。`/` 的行为取决于其操作数是否为整数，因此 `5.0/4.0` 是 `1.25`，但 `5/4` 是 `1`，因为整数除法会将结果向零截断。

如果算术运算的结果（无论有符号还是无符号）所需的位数超过了结果类型所能表示的范围，则称为*溢出*。无法容纳的高位会被静默丢弃。如果原始数字是有符号类型，当最高位为 1 时结果可能为负，如下面的 `int8` 示例所示：

[点击此处查看代码图像](#ch03_images.html#id053pro01_r)

```
var u uint8 = 255
fmt.Println(u, u+1, u*u) // "255 0 1"

var i int8 = 127
fmt.Println(i, i+1, i*i) // "127 -128 1"
```

两个相同类型的整数可以使用下面的二元比较运算符进行比较；比较表达式的类型是布尔值。

| `==` | 等于 |
| --- | --- |
| `!=` | 不等于 |
| `<` | 小于 |
| `<=` | 小于或等于 |
| `>` | 大于 |
| `>=` | 大于或等于 |

事实上，所有基本类型的值——布尔值、数字和字符串——都是*可比较的*，这意味着相同类型的两个值可以使用 `==` 和 `!=` 运算符进行比较。此外，整数、浮点数和字符串是*有序的*，可由比较运算符排序。许多其他类型的值不可比较，也没有其他类型是有序的。随着我们遇到每种类型，将介绍其值的*可比较性*规则。

还有单目加法和减法运算符：

| `+` | 单目正号（无效果） |
| --- | --- |
| `-` | 单目负号（取反） |

对于整数，`+x` 是 `0+x` 的简写，`-x` 是 `0-x` 的简写；对于浮点数和复数，`+x` 就是 `x`，`-x` 是 `x` 的取反。

| `&` | 按位与 |
| --- | --- |
| `|` | 按位或 |
| `^` | 按位异或 |
| `&^` | 位清除（AND NOT） |
| `<<` | 左移 |
| `>>` | 右移 |
