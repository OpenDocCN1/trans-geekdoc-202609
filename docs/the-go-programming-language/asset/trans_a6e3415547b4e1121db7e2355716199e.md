### 3.5.5 字符串和数字之间的转换

除了字符串、rune 和字节之间的转换之外，经常还需要在数值及其字符串表示之间进行转换。这可以通过 `strconv` 包中的函数来完成。

要将整数转换为字符串，一种选择是使用 `fmt.Sprintf`；另一种是使用函数 `strconv.Itoa`（“integer to ASCII”，整数转 ASCII）：

```
x := 123
y := fmt.Sprintf("%d", x)
fmt.Println(y, strconv.Itoa(x)) // "123 123"
```

`FormatInt` 和 `FormatUint` 可用于以不同的基数格式化数字：

```
fmt.Println(strconv.FormatInt(int64(x), 2)) // "1111011"
```

`fmt.Printf` 的动词 `%b`、`%d`、`%u` 和 `%x` 通常比 `Format` 函数更方便，特别是当我们想在数字之外包含额外信息时：

```
s := fmt.Sprintf("x=%b", x) // "x=1111011"
```

要解析表示整数的字符串，请使用 `strconv` 函数 `Atoi` 或 `ParseInt`，对于无符号整数则使用 `ParseUint`：

```
x, err := strconv.Atoi("123")             // x 是一个 int
y, err := strconv.ParseInt("123", 10, 64) // 基数 10，最多 64 位
```

`ParseInt` 的第三个参数给出了结果必须适应的整数类型的大小；例如，16 表示 `int16`，特殊值 0 表示 `int`。无论哪种情况，结果 `y` 的类型始终是 `int64`，你可以将其转换为更小的类型。

有时 `fmt.Scanf` 可用于解析由字符串和数字有序混合且全部在单行上的输入，但它可能不够灵活，特别是在处理不完整或不规则输入时。

## 3.6 常量

常量是其值在编译时已知且求值保证发生在编译时而非运行时的表达式。每个常量的底层类型都是基本类型：布尔型、字符串或数字。

`const` 声明定义了命名的值，它们在语法上看起来像变量，但其值是常量，这防止了在程序执行期间意外（或恶意）地更改。例如，常量比变量更适合用于像 `pi` 这样的数学常量，因为它的值不会改变：

```
const pi = 3.14159 // 近似值；math.Pi 是更好的近似值
```

与变量一样，一组常量可以出现在一个声明中；这适用于一组相关的值：

```
const (
    e  = 2.71828182845904523536028747135266249775724709369995957496696763
    pi = 3.14159265358979323846264338327950288419716939937510582097494459
)
```

许多常量上的计算可以在编译时完全求值，减少了运行时所需的工作并启用了其他编译器优化。通常在运行时检测到的错误，如果其操作数是常量，则可以在编译时报告，例如整数除以零、字符串索引越界，以及任何会导致非有限值的浮点运算。

应用于常量操作数的所有算术、逻辑和比较操作的结果本身也是常量，转换的结果以及对某些内置函数的调用结果也是常量，例如 `len`、`cap`、`real`、`imag`、`complex` 和 `unsafe.Sizeof`（[§13.1](#ebook_split_121.html#id-sizeof)）。

由于它们的值在编译时已知，常量表达式可以出现在类型中，具体来说是作为数组类型的长度：

```
const IPv4Len = 4

// parseIPv4 解析一个 IPv4 地址 (d.d.d.d)。
func parseIPv4(s string) IP {
    var p [IPv4Len]byte
    // ...
}
```

常量声明可以同时指定类型和值，但在没有显式类型的情况下，类型将从右侧的表达式推断得出。在下面的代码中，`time.Duration` 是一个底层类型为 `int64` 的命名类型，而 `time.Minute` 是该类型的常量。因此，下面声明的两个常量也都具有 `time.Duration` 类型，正如 `%T` 所揭示的那样：

```
const noDelay time.Duration = 0
const timeout = 5 * time.Minute
fmt.Printf("%T %[1]v\n", noDelay)     // "time.Duration 0"
fmt.Printf("%T %[1]v\n", timeout)     // "time.Duration 5m0s"
fmt.Printf("%T %[1]v\n", time.Minute) // "time.Duration 1m0s"
```

当一组常量作为一组声明时，除第一个外，其余的右侧表达式可以省略，这意味着再次使用前面的表达式及其类型。例如：

```
const (
    a = 1
    b
    c = 2
    d
)

fmt.Println(a, b, c, d) // "1 1 2 2"
```

如果隐式复制的右侧表达式总是求值为相同的东西，这不是很有用。但如果它可以变化呢？这就引出了 `iota`。

### 3.6.1 常量生成器 `iota`

`const` 声明可以使用*常量生成器* `iota`，它用于创建一系列相关的值，而无需显式地拼写每一个。在 `const` 声明中，`iota` 的值从零开始，并在序列中的每一项增加一。

这是来自 `time` 包的一个示例，它定义了类型为 `Weekday` 的命名常量来表示一周中的每一天，从零代表 `Sunday` 开始。这类类型通常称为*枚举*，简称 *enums*。

```
type Weekday int

const (
    Sunday Weekday = iota
    Monday
    Tuesday
    Wednesday
    Thursday
    Friday
    Saturday
)
```

这声明了 `Sunday` 为 0，`Monday` 为 1，依此类推。

我们也可以在更复杂的表达式中使用 `iota`，如这个来自 `net` 包的示例，其中无符号整数的最低 5 位中的每一位都被赋予了一个独特的名称和布尔解释：

```
type Flags uint

const (
    FlagUp Flags = 1 << iota // is up
    FlagBroadcast            // supports broadcast access capability
    FlagLoopback             // is a loopback interface
    FlagPointToPoint         // belongs to a point-to-point link
    FlagMulticast            // supports multicast access capability
)
```

随着 `iota` 的增加，每个常量被赋予 `1 << iota` 的值，其结果为连续的 2 的幂，每个对应单个位。我们可以在测试、设置或清除一个或多个这些位的函数中使用这些常量：

```
gopl.io/ch3/netflag
```
