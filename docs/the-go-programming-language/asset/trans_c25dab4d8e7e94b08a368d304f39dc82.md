

幸运的是，`sort` 包提供了根据任意排序函数对任意序列进行**原地排序**的功能。其设计相当独特。在许多语言中，排序算法与序列数据类型相关联，而排序函数与元素类型相关联。相比之下，Go 的 `sort.Sort` 函数对序列或其元素的表示形式不做任何假设。相反，它使用一个接口 `sort.Interface` 来指定通用排序算法与每个可排序序列类型之间的契约。该接口的实现同时决定了序列的具体表示（通常是切片）及其元素的期望排序顺序。

原地排序算法需要三样东西——序列的长度、比较两个元素的方法、交换两个元素的方法——因此它们就是 `sort.Interface` 的三个方法：

[点击此处查看代码图片](#ch07_images.html#id186pro02_r)

```
package sort

type Interface interface {
    Len() int
    Less(i, j int) bool // i, j 是序列元素的索引
    Swap(i, j int)
}
```

要对任意序列进行排序，我们需要定义一个实现了这三个方法的类型，然后将 `sort.Sort` 应用于该类型的一个实例。作为最简单的例子，考虑对字符串切片进行排序。下面展示了新类型 `StringSlice` 及其 `Len`、`Less` 和 `Swap` 方法。

[点击此处查看代码图片](#ch07_images.html#id187pro01_r)

```
type StringSlice []string

func (p StringSlice) Len() int           { return len(p) }
func (p StringSlice) Less(i, j int) bool { return p[i] < p[j] }
func (p StringSlice) Swap(i, j int)      { p[i], p[j] = p[j], p[i] }
```

现在我们可以通过将字符串切片 `names` 转换为 `StringSlice` 来对其进行排序，如下所示：

```
sort.Sort(StringSlice(names))
```

该转换产生一个切片值，它与 `names` 具有相同的长度、容量和底层数组，但其类型拥有排序所需的三个方法。

对字符串切片进行排序非常常见，因此 `sort` 包提供了 `StringSlice` 类型，以及一个名为 `Strings` 的函数，以便将上述调用简化为 `sort.Strings(names)`。

此技术很容易适应其他排序顺序，例如忽略大小写或特殊字符。（为本书对索引词和页码进行排序的 Go 程序就做了这件事，并额外添加了处理罗马数字的逻辑。）对于更复杂的排序，我们使用相同的思路，但会用到更复杂的数据结构或更复杂的 `sort.Interface` 方法实现。

我们用于排序的持续示例将是一个音乐播放列表，以表格形式显示。每个曲目是一行，每一列是该曲目的一个属性，如艺术家、标题和运行时长。想象一个图形用户界面呈现该表格，点击列头会按该属性对播放列表进行排序；再次点击同一列头则反转顺序。让我们看看响应每次点击可能发生的情况。

下面的变量 `tracks` 包含一个播放列表。（作者之一为另一作者的音乐品味道歉。）每个元素都是间接的，即指向 `Track` 的指针。虽然如果我们直接存储 `Track` 值，下面的代码也能工作，但排序函数将交换许多元素对，因此如果每个元素是一个指针（单个机器字），而不是整个 `Track`（可能有八个字或更多），运行速度会更快。

[点击此处查看代码图片](#ch07_images.html#id187pro02_r)

```
type Track struct {
    Title  string
    Artist string
    Album  string
    Year   int
    Length time.Duration
}

var tracks = []*Track{
    {"Go", "Delilah", "From the Roots Up", 2012, length("3m38s")},
    {"Go", "Moby", "Moby", 1992, length("3m37s")},
    {"Go Ahead", "Alicia Keys", "As I Am", 2007, length("4m36s")},
    {"Ready 2 Go", "Martin Solveig", "Smash", 2011, length("4m24s")},
}

func length(s string) time.Duration {
    d, err := time.ParseDuration(s)
    if err != nil {
        panic(s)
    }
    return d
}
```

`printTracks` 函数将播放列表作为表格打印。图形化显示会更美观，但这个小程序使用 `text/tabwriter` 包生成一个列整齐对齐并填充的表格，如下所示。请注意 `*tabwriter.Writer` 满足 `io.Writer`。它收集写入的每一片数据；其 `Flush` 方法格式化整个表格并将其写入 `os.Stdout`。

[点击此处查看代码图片](#ch07_images.html#id188pro01_r)

```
func printTracks(tracks []*Track) {
    const format = "%v\t%v\t%v\t%v\t%v\t\n"
    tw := new(tabwriter.Writer).Init(os.Stdout, 0, 8, 2, ' ', 0)
    fmt.Fprintf(tw, format, "Title", "Artist", "Album", "Year", "Length")
    fmt.Fprintf(tw, format, "-----", "------", "-----", "----", "------")
    for _, t := range tracks {
        fmt.Fprintf(tw, format, t.Title, t.Artist, t.Album, t.Year, t.Length)
    }
    tw.Flush() // 计算列宽并打印表格
}
```

要按 `Artist` 字段对播放列表进行排序，我们定义一个具有必要的 `Len`、`Less` 和 `Swap` 方法的新切片类型，这类似于我们对 `StringSlice` 所做的。

[点击此处查看代码图片](#ch07_images.html#id188pro02_r)

```
type byArtist []*Track

func (x byArtist) Len() int           { return len(x) }
func (x byArtist) Less(i, j int) bool { return x[i].Artist < x[j].Artist }
func (x byArtist) Swap(i, j int)      { x[i], x[j] = x[j], x[i] }
```

要调用通用排序例程，我们必须首先将 `tracks` 转换为定义顺序的新类型 `byArtist`：

```
sort.Sort(byArtist(tracks))
```

`sort.Reverse` 函数值得仔细研究，因为它使用了组合（§6.3），这是一个重要的概念。`sort` 包定义了一个未导出类型 `reverse`，它是一个嵌入了 `sort.Interface` 的结构体。`reverse` 的 `Less` 方法调用嵌入的 `sort.Interface` 值的 `Less` 方法，但交换了索引，从而反转了排序结果的顺序。

[点击此处查看代码图片](#ch07_images.html#id189pro03_r)

```
package sort

type reverse struct{ Interface } // 即 sort.Interface

func (r reverse) Less(i, j int) bool { return r.Interface.Less(j, i) }

func Reverse(data Interface) Interface { return reverse{data} }
```
