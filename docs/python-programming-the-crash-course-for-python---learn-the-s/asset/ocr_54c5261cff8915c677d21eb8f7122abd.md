# Moving to the random forest

Now that we have had some time to explore what the decision tree is all about, it is time to move on another step of looking at the random forest. There are times when just one single decision tree is going to be enough to help you make some decisions for your needs. But sometimes, you need to compare a lot of different options and you are going to need to work with a group of decision trees, which will make up your random forest.

These random forests are going to be a popular option to work with when we talk about machine learning. So, if you plan to work with decision trees on machine learning quite a bit, then it is also important to learn how to work with the random forests as well.
