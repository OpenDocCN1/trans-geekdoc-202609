We trained and configured deep learning networks using the composite dataset and evaluated their performance by the confusion matrix of tests. These models included a fully connected neural network, a recurrent neural network based on long short-term memory (Supplementary Figures 16 and 17) and a CNN (Supplementary Figure 1). The CNN achieved the highest recall (-0.92), precision (-0.93), F1-score (-0.94) and showed superior performance in gesture recognition (Fig. 3b, Supplementary Figure 18 and Supplementary Note 11). We customized the CNN to match the signal dimensions and optimize the performance in this study (Fig.3c).
