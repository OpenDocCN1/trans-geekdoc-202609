+   6. Implementation: The model is then equipped with the ability to generalize new or unknown data that it has not witnessed previously. The way this implementation is going to be applied shall be determined by the environment. Through the use of these highly defined phases, both researchers and practitioners are given the opportunity to transform ML capabilities into understandable and useful information, which can be used to solve problems in multidisciplinary fields. Through the type of data that they use to train their ML algorithms, data scientists classify algorithms into two major categories.

Supervised learning – Algorithms that require labeled data, where each data point has a defined outcome or classification, are included in this category. By understanding the correlation between the input properties and the intended outputs, these algorithms can forecast, new, unknown data. Examples of supervised learning algorithms are as follows:

Linear regression – This approach is based on the calculation of real numbers with a fixed linear scale, depending on the input variable.

Logistic regression – Basically designed to determine data points as one of two different categories, this algorithm is used in problems of binary classification.

Decision trees – These algorithms study tree-like structures, where each branch represents a decision influenced by the specific characteristics of the data. The algorithm will classify or predict a new data point by following this tree.

K-nearest neighbors (KNNs) – This strategy classifies information points by considering their similarity to the closest neighbors within the training data.
