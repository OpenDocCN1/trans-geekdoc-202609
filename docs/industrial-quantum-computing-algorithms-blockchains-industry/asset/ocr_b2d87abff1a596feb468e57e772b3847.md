Similar to traditional kernel methods, QKs, as shown in Figure 11.6, can be used to work with data that is in high-dimensional feature spaces. A QK function Q(x, y) can be defined as the dot product between the functions f(x) and f(y), where f maps the $n$-dimensional input vectors $x$ and $y$ into an $m$-dimensional space, with $n < m$. This QK function serves as a foundation to perform segmentations and regressions in the quantum domain:

```
Q(x, y) = <f(x), f(y)>
```

Recent research has investigated constructing QKs for use in quantum SVMs [1]. For classification problems in which we have a smaller number of training samples, the performance has been found to exceed that of optimized classical SVMs using conventional kernels. Additionally, QKs allow for interpreting the learning process using quantum information theory tools.
