This quantum kernel matrix serves as the base for training the QSVM, similar to classical SVMs. Note that there are QSVM variants where training is also performed on a quantum computer, but these may not be practical on near-term quantum devices. QSVMs offer enhancements in specific classification problems by merging the principles of classical SVMs with quantum computing.

# Table 9.3: Key differences between classical SVMs and quantum SVMs.

| Aspect | Classical SVM | Quantum SVM (QSVM) |
|---|---|---|n| Basis of computation | Classical computing | Quantum computing |
| Kernel function | Employs classical kernel functions (e.g., linear and RBF) | Utilizes quantum kernel functions |
| Feature map | Not applicable | Quantum feature maps translate classical data to quantum states |
| Data representation | Classical data representation | Quantum states representation |
| Computational complexity | Polynomial time complexity (efficient for most cases) | Potential for exponential speedup in certain cases |
| Training methodology | Convex optimization problem | Variational optimization problem |
| Handling nonlinear data | Utilizes the kernel trick for nonlinear separation | Inherent capability to handle nonlinear data |
| Scalability | Limited scalability for large datasets | Potential scalability advantages with quantum parallelism |
| Noise sensitivity | Generally robust to noise | Susceptible to noise and errors in quantum computation. |
| Realization on quantum hardware | Not applicable | Realization requires quantum hardware and algorithms |

Table 9.3 provides a concise comparison of classical SVMs and QSVMs across various aspects, highlighting the fundamental differences between the two approaches in terms of computation, representation, methodology, scalability, and sensitivity to noise.

# 9.3.1 Choosing a quantum framework

There are different quantum frameworks like Qiskit developed by IBM, Cirq provided by Google, and ProjectQ. Therefore, to implement QSVMs, it is very important to select an appropriate framework that depends on various factors like hardware capability, community support, and its features.
