QNNs consist of layers, including input encoding, where classical data is transformed into quantum data; quantum gate layers, where operations are performed on qubits; entanglement layers for creating complex relationships between qubits; parameterized gates for adjustable operations; measurement layers for obtaining classical output; and error correction layers for mitigating noise and de-coherence. By utilizing the features of quantum mechanics, QNNs hold promise for revolutionizing various fields of ML and computational science.

## 9.2.2 Architecture of QNN

The QNNs are developed as feed-forward networks, where each layer evaluates input from the previous layer and passes the output to the next layer. The layers can have different widths (varying numbers of qubits) and are trained similarly to classical neural networks.

The circuit in Figure 9.2 is a feed-forward network. In the first layer, all the qubits are initialized to the 0 state. The boxes represent the operations performed on the qubits, which are executed by one. Vertical lines are used to generate entanglement between the QNN, one of the important features of quantum technology.

In the first layer, which is an encoding layer, different algorithms are used to convert classical data into quantum data. This conversion is done by transforming input data into quantum values and using these values as parameters $x_1, x_2, x_3$, etc., for the operations performed in the encoding layer.

Where the hidden layer of the QNN involves quantum circuits consisting of different quantum gates denoted by $y_1, y_2, y_3$, etc., this layer accepts input from the previous layer, and its parameters serve as input for the next layer.

The last layer is an output layer that provides predictions. These predicted values are then compared with the desired results. This type of QNN is called a "hybrid quantum classical" network because the computations happen on the quantum computer, while a classical computer (using an optimizer like Adam) handles adjusting the network's parameters to improve its performance [14].

This systematic approach outlines the basic steps involved in creating a QNN. However, the actual implementation and complexity can depend on the specific task, architecture, and quantum computing framework being used. Additionally, QNNs are an active area of research, and new advancements continue to refine and expand their capabilities.

## 9.3 Quantum support vector machine (QSVM)

In classical support vector machines (SVMs), we aim to find a hyperplane (or in 2D) that separates data points related to distinct classes. The SVM constructs this hyperplane by increasing the distance between the hyperplane and the nearest data points from each class. To handle nonlinearly, quantum SVMs (QSVMs) leverage quantum circuits to define the kernel function. The quantum feature maps are used to convert classical data points into quantum states. Then, the quantum kernel is calculated as the inner product of these quantum feature maps. This quantum kernel matrix serves as the base for training the QSVM, similar to classical SVMs. Note that there are QSVM variants where training is also performed on a quantum computer, but these may not be practical on near-term quantum devices. QSVMs offer enhancements in specific classification problems by merging the principles of classical SVMs with quantum computing.

## 9.3.2 Data encoding

Transforming classical data input into quantum data is the second phase, once you have selected a quantum framework. The quantum feature map is used to transform classical features into quantum states that can be processed by the quantum algorithm [6]. For example, a simple quantum feature map could be represented as follows:

```
M(\Phi(x)) = 0 + e^{i\theta(x)} (1)
```

Here, $\theta(x)$ is a function that depends on the classical features of x.

- $M_0 = e^{i\theta(x)}$ (quantum state representing the 0 state)
- $M_1 = e^{i\theta(x)}$ (quantum state representing the 1 state after applying a phase shift by $\theta(x)$)
- $M\Phi(x) = M_0 + M1$ the quantum feature map can be described by combining the two quantum states.

## 9.3.3 Training the QSVM

Training a QSVM includes building the quantum kernel matrix and optimizing the quantum circuit parameters to learn the optimal hyperplane that separates the data points of different classes. The different steps involved in QSVM are explained.

### 9.3.3.1 Construction of quantum kernel matrix

The initial phase in QSVM training is to make the quantum kernel matrix by computing quantum kernels. The $N \times N$ quantum kernel matrix is denoted by $K$, where $N$ is the number of training data points, and $K_{ij}$ represents the quantum kernel value between data points $i$ and $j$ [7]:

```
$K_{ij} = \langle\Phi(x_i) | \Phi(x_j)\rangle$
```

Here $\Phi(x_i) | \Phi(x_j)$ is an inner product of the quantum feature maps of data points $i$ and $j$.
