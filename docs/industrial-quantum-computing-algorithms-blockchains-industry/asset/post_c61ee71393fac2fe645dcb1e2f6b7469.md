## 3.1.4 Requirements for handling quantum computations

Following are the requirements for handling quantum computations [1]:

- Setup of a scalable physical system encompassing clearly defined qubits
- Devising an easy, primary, fiducial input state
- Methods to accurately measure a qubit state
- Exceptionally faithful execution of universal gate procedures
- Handling extended coherent periods
- Converting stationary and flying qubits into each other
- Reliable passing of qubits between two designated locations

## 3.1.5 Quantum computing algorithms

There are two most popular algorithms of quantum computing: Grover's algorithm and Shor's factorization algorithm [7].

### 3.1.5.1 Shor's factorization algorithm

Peter Shor's factorization algorithm, made possible by quantum physics, may solve the factorization problem in polynomial time as opposed to the exponential time required by conventional approaches. This might have a big effect on the field of data security, which is based on the prime factorization of enormous numbers. While factorization lacks a polynomial-time technique, there are various polynomial-time algorithms for multiplying integers, such as Euclid's algorithm [10].

Consequently, Shor created Shor's factorization technique, which enables a quantum computer to factor very large numbers for non-prime integers N of L bits in polynomial time [10].

## 3.2 Importance of integration of machine learning with quantum computing

Large dataset management is a popular application of machine learning in computer science these. Large tensor management and postprocessing have demonstrated the effectiveness of quantum computing [18]. The fusion of machine learning and quantum computing has created new opportunities for businesses and academics. With its ability to perform parallel computations, quantum computing has greatly improved learning models and demonstrated notable success in a number of challenging application domains, including NP-hard problems like graph clustering, quadratic unconstrained binary optimization (QUBO), and optimization problems.

### 3.2.1 Machine learning to improve QUBO

Rules and procedures have long been created to comprehend the implications of certain model cases. In mixed-integer programming, this type of machine learning is frequently used to find correlations, as values or bounds for variables or inequalities, may successfully restrict feasible spaces. These methods are now widely acknowledged as an important and practical subset of the machine learning field [8]. ### 3.2.2 Unsupervised machine learning with QUBO

Unsupervised machine learning can take various forms, but clustering is one of the most well-known ones. This method benefits from a favorable link to unsupervised machine learning through the application of the QUBO set partitioning model, which yields a very straightforward clustering function. Due to its flexible model for correlation clustering and maximizing modularity, the clique partitioning problem is important in machine learning [28, 29]. The unsupervised machine learning representation of QUBO may be used alone or in conjunction with quantum computing [31].
