# 3.2.2 Unsupervised machine learning with QUBO

Unsupervised machine learning can take various forms, but clustering is one of the most well-known ones. This method benefits from a favorable link to unsupervised machine learning through the application of the QUBO set partitioning model, which yields a very straightforward clustering function. Due to its flexible model for correlation clustering and maximizing modularity, the clique partitioning problem is important in machine learning [28, 29]. The unsupervised machine learning representation of QUBO may be used alone or in conjunction with quantum computing [31].
