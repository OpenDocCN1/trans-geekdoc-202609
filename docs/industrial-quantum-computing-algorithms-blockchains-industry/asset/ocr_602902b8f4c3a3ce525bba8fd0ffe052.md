# 9.3.3.3 Optimization

The main aim of optimization is to find the optimal parameters for a quantum circuit to minimize a cost function that represents the classification error. In general, gradi- descent or various classical optimization algorithms are used for optimization. The QSVM finds the ideal hyperplane that ideally separates the classes by minimizing this cost function. The cost function measures the difference between the predicted values by the QSVM and the actual output of the training data. To minimize the cost function and enhance the QSVM's classification performance, the optimization algo-rith adjusts the parameters. Iterative updates of the quantum circuit's parameters are part of the training process. The predictions of the QSVM are computed in each iteration using the quantum kernel matrix $k$ and the current parameters.

# 9.3.3.4 Convergence

The training process repeats until the convergence criteria are met, which is usually determined by reaching an established threshold for the cost function or the par- ters. The QSVM is ready for classification and prediction tasks once convergence is reached. The training complexity of the model is based on various aspects such as the size of the data, the design of the quantum circuit, and the algorithm used for optimization.

# 9.3.4 Testing and evaluation

After training the model, the performance of QSVM can be determined by testing the data. The efficiency of the model in the areas of classification and prediction can be evaluated by factors such as accuracy, precision, recall, and F1-score. The se-lected framework provides documentation and resources that cover all the informa- tion for implementing QSVMs.

In summary, building QSVMs involves different phases, i.e., data encoding, quan- tum kernel calculation, training, classification, and optimization. Therefore, combin- ing quantum computing with classical SVM offers enhancements in prediction and classification problems.
