In the first layer, which is an encoding layer, different algorithms are used to convert classical data into quantum data. This conversion is done by transforming input data into quantum values and using these values as parameters x1, x2, x3, etc., for the operations performed in the encoding layer.

Where the hidden layer of the QNN involves quantum circuits consisting of different quantum gates denoted by y1, y2, y3, etc., this layer accepts input from the previous layer, and its parameters serve as input for the next layer.

The last layer is an output layer that provides predictions. These predicted values are then compared with the desired results. This type of QNN is called a "hybrid quantum classical" network because the computations happen on the quantum computer, while a classical computer (using an optimizer like Adam) handles adjusting the network's parameters to improve its performance [14].

This systematic approach outlines the basic steps involved in creating a QNN. However, the actual implementation and complexity can depend on the specific task, architecture, and quantum computing framework being used. Additionally, QNNs are an active area of research, and new advancements continue to refine and expand their capabilities.

# 9.2.3 Advantages of QNN

+   i. In every industry and field, data is an important aspect for growth. Therefore, data analysis, pattern recognition, and optimization of data are real challenges. QNN has the ability to handle complex data.

+   ii. With the properties of quantum computations, i.e., entanglement and superposition, QNN can process large amounts of data more efficiently than regular computers.

+   iii. In contrast to classical methods, quantum algorithms such as the quantum optimization algorithm may offer improved results for optimization problems.
