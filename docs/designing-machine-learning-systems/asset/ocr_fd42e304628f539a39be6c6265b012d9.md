For example, by using a number of strategies including replacing 3 × 3 convolution with 1 × 1 convolution, SqueezeNets achieves AlexNet-level accuracy on ImageNet with 50 times fewer parameters.21

Similarly, MobileNets decomposes the standard convolution of size K × K × C into a depthwise convolution (K × K × 1) and a pointwise convolution (1 × 1 × C), with K being the kernel size and C being the number of channels. This means that each new convolution uses only K² + C instead of K²C parameters. If K = 3, this means an eight to nine times reduction in the number of parameters (see Figure 7-9).22
