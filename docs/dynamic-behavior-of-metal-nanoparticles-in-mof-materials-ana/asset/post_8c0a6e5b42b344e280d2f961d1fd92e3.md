For the best performance, individual filter settings are required for the particular type of video being examined. However, heuristically, an effective combination of parameters was established that satisfies the use of the U-Net convolutional neural network at a subsequent stage. This makes it possible to increase the flexibility of the approach and the developed software as a whole. In this case, the following sequence of classical digital filters was used:

- (1) non-local means filter;
- (2) bilateral filter;
- (3) median filter;
- (4) Gaussian filter.

**Binarization** is used to increase the contrast of images on the frames of the video stream with the creation of conditions for the successful solution of the input data segmentation problem at the next stage. The training sample of the used neural network is formed on the basis of the sample under study and allows processing data from samples of the same type with fairly good flexibility, which increases the stability of the system to changes in the input data.

**Segmentation** allows dividing binarized data into a set of objects with differentiated characteristics. The obtained binarized data are subjected to the contour detection algorithm, which is based on the method of topological structural analysis of images. This results in a list of objects containing a description of each contour in the form of parameters (the coordinates of generating points, moments, hierarchical position relative to other contours, etc.). The resulting list of objects is subjected to additional a posteriori filtering. Thus, for the further operation of the algorithm, only those objects are used, the parameters of which lie in the given ranges of values. Permissible ranges of values are selected by a heuristic method, taking into account the type of sample under study and the parameters of the video stream generation system (frame rate, resolution).

Additional division into groups of parent and child objects was used to facilitate the task of tracking. This allows redundant calculations to be eliminated, which in turn improves system performance by reducing the processing time of each frame.

Tracking is the final stage of processing, which allows the selection of specific objects in the image and the calculation and tracking of changes in spatial and temporal characteristics. The task of tracking is the identification of objects and the calculation of specified metrics. The identification algorithm consists of finding the similarity coefficient between the objects of adjacent frames. The data processed by the tracking module were preprocessed and filtered. For this reason, each processed object is either a new object that needs to be assigned its own unique index or a previously identified object and requires data to be updated based on the information received.

The similarity coefficient is calculated as a Euclidean distance based on a set of given measures (center of gravity coordinates, area, perimeter, density, and position in the hierarchy). For the calculation, data are taken only for those objects whose parameters lie in the specified ranges of values. Objects with anomalous data are cut off in this way. An example of this is a too high rate of change of tracked parameters, which may mean the appearance of a new object, but with a high similarity score, relative to the objects of the previous frame.

Taking into account the specified ranges of values and the selected data output format, the tracking module generates a list of detected and identified objects, as well as the corresponding calculated characteristics.
