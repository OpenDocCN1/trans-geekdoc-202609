## 第 8 章：考试当天

考试当天首先要做的是放松。你不必惊慌，而应保持冷静，抱有最好的期望。不要惊慌并开始焦虑，因为这会让你忘记所有准备好的内容。你应该为考试做好充分准备。确保你已经复习了考试中包含的所有大纲内容。除了大纲之外，你还需要了解考试的所有相关细节。

在考试当天之前，有几件事你应该做：

- 1. 充分准备大纲：

考试所涉及的所有课程都必须准备充分，这一点非常重要。你应当认真准备课程。复习所有考试的主题。详细阅读考试所包含的所有 8 个网络安全领域。你的考试准备非常重要。你必须做得很好。

- 2. 考试期间不要惊慌：

另一件你应该做的重要事情是不要惊慌。惊慌会对你造成巨大损害。你会失去对考试理解和知识的把控，因此请务必保持冷静和放松。放松的心态将引导你走向成功之路。

- 3. 确保你了解所有相关信息：

在参加考试之前，你应当确保自己了解考试的所有相关细节。你要了解关于考试的所有规则和规定。这一点非常重要，否则你将处于持续困惑的状态。这种困惑状态会浪费你本应用于考试的时间。因此，请提前做好所有准备，以免在最后一刻还要处处追赶。

- 4. 前一天晚上睡个好觉：

考试当天你需要精神焕发。你需要尽可能精神。你应该在考试前一天晚上尽早睡觉，以便有 8 小时的睡眠。如果你的作息不规律，考试时你会感到头晕和笨拙。你会不停地打哈欠，无法集中精力参加考试。因此，你应该确保作息规律。你应该在考试前一天晚上尽量获得 8 到 10 小时的睡眠。好好睡一觉将帮助你度过考试当天。你的大脑需要休息，由于持续的学习安排，它渴望获得正常运作所需的休息。因此，为了更好地掌控考试，你应该确保在考试前一天晚上睡 8 到 10 小时。那段时间避免任何学习。

### 考试当天准备：

你应该提前了解一切。你应该了解考试的整个流程。尽量减少考试当天的意外情况。为即将发生的一切做好准备。让我们从考试当天醒来开始说起。

### 散步：

今天是考试日。你为此准备了很长时间。经过数周数月密集而艰苦的学习，终于到了参加考试的日子。你应该以愉快的心情开始这一天。早起出去散个步。这次散步对你的心灵会有惊人而清新的效果。在户外新鲜空气中散步会让你感觉精神焕发，如沐春风。它会让你的内心感到平静。所以，你应该出去散散步。

### 锻炼：

如果你无法出去散步，可以尝试做一些轻度运动来感到清新。做几个运动动作不会对任何人造成伤害。你应该在考试当天早上进行一些体育活动。

### 给自己做喜欢的早餐：

你应该在考试当天吃早餐。

强烈不建议你在最需要早餐的那天跳过早餐。你可以吃一些你喜欢的食物。考试时间会很长且繁重，因此你应该确保在家吃早餐。这样你就不会浪费时间，也不需要中途离开考试去吃饭。

### 考试中心：

你应当准时出发前往考试中心。早起，然后早点出发去中心，以便准时到达。检查好所有相关文件。确保你携带了考试所需的所有重要文件。到达考试中心时，不要忘记携带证明身份的文件。你可以通过提供签名或掌静脉扫描来证明身份。只有在法律允许的情况下才能提供掌静脉扫描。证明身份后，你需要拍照。拍照时不应佩戴任何帽子或外套。此外，不允许将任何个人物品带到考试房间。你需要在考试室外脱下外套、帽子、围巾等物品，因为它们不允许在内佩戴。Pearson VUE 不保证你个人物品的安全。虽然你将可以使用安全的储物空间。这些储物空间很小，因此你应确保不携带任何大件物品。

之后，你将被引导至考试室。考试管理员将首先给你一个简要介绍并进行定向流程。在考试管理员的定向之后，你将被带到计算机终端前参加考试。在开始考试之前，你将有 5 分钟时间审阅并接受保密协议。如果你不接受保密协议（NDA），将不允许参加考试。如果你想参加考试，应在开始前签署保密协议。不签署保密协议将不允许申请费用退款。考试费用不会退还给你。

### 你需要携带的文件：

你在前往考试中心参加考试时需要携带一些文件。你必须携带的第一个也是最重要的东西是身份证件。你需要携带主 ID 和次要 ID。这些身份证件是必需的。进入考试设施之前，你还将被要求进行掌静脉扫描。如果你不能证明身份，将不允许参加网络安全考试。

你必须携带的身份证件不得过期。它们应当是有效且合法的身份证件。你携带的文件必须是原件且真实。就身份证件而言，你的主 ID 上必须有你的照片。主 ID 上的照片应固定在文件上。它还应有你的签名。另一方面，次要 ID 需要有签名，而主 ID 则需要同时有照片和签名。

接受的主 ID 可能包括你的身份证、出生证明、驾驶执照、护照、军人 ID、员工 ID、学校 ID、信用卡、配偶及受抚养人军人 ID 等。

接受的次要 ID 可能包括你的信用卡、ATM 卡、借记卡、美国社会安全卡等。

信用卡既可以用作主 ID 也可以用作次要 ID。主 ID 是指任何带有你的照片和签名且有效的证件。因此，如果你的信用卡同时有照片和签名，它可以用作你的主 ID。事实上，任何同时带有你的照片和签名的卡片或文件都可以用作你的主 ID。主 ID 和次要 ID 都应当有效且未过期，如果过期将不予接受。

### 考试期间休息：

你应该一直留在座位上。只有当考试管理员说可以离开座位并站起来时，你才能离开座位，否则请就座。如果你想去洗手间，将由考试管理员陪同。不允许你独自离开。会有人陪同你。不允许你更换终端，因为这也是不允许的。如果你用于参加考试的计算机终端出现问题，只有在考试管理员（TA）的指示下才能更换。

### 考试期间的协助：

你应该与考试中心工作人员保持良好行为。你不应在考试中心行为不当或制造不必要的场面。你应该遵守规则。确保你知道考试中心应遵守的所有规则。如果你需要什么或想离开座位，请举手。只有在考试管理员允许时才能离开座位。如果他不允许，请安静地坐着。如果你的计算机终端出现问题、需要什么、需要考试管理员协助或想休息，可以举手让管理员知道。

### 考试期间休息：

考试期间你可以休息的次数由你自己决定。关于考试期间可以休息的次数，没有严格的规定。但你必须牢记一点：无论休息多少次，所有休息时间都会从你的考试时间中扣除。完成考试所需时间为 6 小时，你必须在 6 小时内完成。因此，休息时时钟绝不会停止，而是会继续走动。你应尽量不要休息太多次，除非绝对必要。休息会浪费你的时间，而这是你无法承受的。
