## 第2章：考试模式与规则

### 考试模式：

考试包含约250道选择题。这些选择题涵盖CISSP考试的全部8个领域。为了通过考试，你需要确保自己掌握网络安全全部8个领域的相关知识。考试及格分为1000分中的700分。考试总分为1000分。这意味着通过考试需要总分的70%。

考试包含全部8个领域的内容。以下是构成考试题目的各领域所占百分比。

- 风险与安全管理约占CISSP考试的15%。这是一个多样化的主题，能让你了解所有与风险和安全管理相关的主题，并让你了解所需内容。

- 资产安全约占考试的10%。本部分涵盖所有涉及安全物理基础的主题。

- 安全工程占考试的13%，涵盖所有数据安全理论。

- 网络安全占考试的14%，涵盖处理网络安全的不同方法。

- 身份与访问管理（IAM）约占CISSP考试的13%。它涵盖与识别和授权相关的主题。

- 保护与安全运营占考试的13%。这涉及安全与安保运营，并提供应对此类情况的解决方案。

- 软件开发安全也是CISSP考试大纲的一部分，可帮助你了解如何处理应用程序并确保其安全。

### 考试规则与条例：

### 网络威胁：

如今网络威胁非常普遍。在当今世界，所有设备都连接到互联网，这使攻击者非常容易发起攻击并威胁用户数据。
下面简要介绍了多种网络安全威胁：

- 恶意软件是最常见的网络安全威胁类型。恶意软件实际上就是恶意软件。它是攻击者创建用于损坏潜在用户计算机系统的恶意软件。
- 病毒是内部嵌有恶意代码的软件。这种软件会自我复制，并在用户点击时复制自身。每次用户点击时，文件都会继续自我复制，最终导致主机计算机上的合法文件受损和感染。
- 木马是一种类似合法软件的恶意软件。
- 间谍软件会获取你计算机系统的访问权限，用于从你的系统窃取信息。它会在用户未察觉的情况下严重损坏系统。
- 广告软件是显示广告的恶意软件。它用于广告推广。除了推广广告，它还会传播恶意软件。
- 攻击者将恶意软件伪装成真实合法的软件，一旦进入主机计算机，软件就开始运行。攻击者会持有数据并要求支付赎金以释放。
- 僵尸网络是机器人网络的缩写。它是一个连接的计算机网络。僵尸网络由攻击者远程控制，主要目的是获取经济利益或启动攻击者倾向于发布或运行的网站和应用程序。
- Emotet 被认为是最危险的病毒。它采用暴力破解方法工作。Emotet 是一种通过电子邮件附件传播的高级木马，一旦用户点击，它就会释放有效载荷并开始感染计算机上存储的文件和其他数据。
- 拒绝服务攻击是一种网络攻击，通过通信网络发送伪造消息和数据包，使预期用户无法使用该服务。
- 钓鱼是攻击者用来诱骗用户提供敏感个人信息的欺诈行为。
- 中间人攻击是指双方通信时，攻击者窃听他们的对话。还可以在用户不知情的情况下修改信息。
- 社会工程学是一个常用术语，指通过人与人之间的交互发生的恶意活动。
- 密码攻击也用于获取个人数据访问权限。这是一种非常常见且非常容易的方法，可以闯入他人的个人信息和私密空间。
- 结构化查询语言（SQL）注入是一种网络攻击，当恶意代码被注入使用 SQL 的服务器时就会发生。

## 云计算与网络安全

云计算与网络安全看似完全相反，但两者之间确实存在联系。在云计算中，你基本上是将数据存储在非本地位置，而网络安全意味着不惜一切代价保护数据。云计算本质上是对数据的外包，你通过共享数据来信任这些服务，并让它们为你存储数据。在网络安全中，你信任为保护存储在这些远程服务器上的数据而制定的程序和协议。

### 云安全的重要性

许多企业现在正在向云端迁移；他们更倾向于将数据存储在云平台上。攻击者变得更加复杂和狡猾，他们发起的攻击非常难以识别。因此，就像本地服务器面临风险一样，云计算服务也面临风险。云安全的重要性如下：

- 云服务遵循集中化原则。所有使用云服务的应用程序和设备都是集中化的。安全性也是集中化的，它们用来确保安全的所有安全程序都是集中化的。当有大量设备和端点时（例如，如果公司实行自带设备政策），它们管理安全协议变得非常困难。
- 如果你将数据托管给云服务，你实际上能节省大量资金。它使你免于投资专用硬件。它还有助于降低管理开销。
- 当你信任一个可靠且值得信赖的云服务提供商时，手动配置就成为过去式了。
- 你的数据在云端是安全的，你可以随时在任何想要的设备上访问它，无论它存储在云端的哪个位置。

### 云计算的风险

云计算伴随着其自身的风险和挑战。

- 业务所有者可能面临的第一个风险是多云环境的挑战。存在的不止一个云，而是多个云。用户需要选择他们偏好的云来存储数据。
- 由于业务所有者和云服务提供商之间存在共享的安全责任，这往往会导致混淆。
- 云计算环境中可能面临的主要挑战之一是缺乏可见性。
- 如果可见性功能不够强大，你将永远不知道有多少数据受到影响，哪些客户的数据受到影响。
- 存储在云端的数据需要活跃的互联网连接。这意味着任何连接到互联网的人都容易受到潜在网络威胁的风险。
- 数据在攻击者或入侵者手中丢失始终是一个潜伏的恐惧。
- 存储在云端的数据并不完全安全。

### 处理云安全风险

以下是一些可以帮助你处理云安全风险的方法：

- 在云服务提供商和用户之间划分职责。
- 强大的用户访问控制可以帮助定义谁可以访问数据，谁不能。不仅如此，它还能显示他们被授权访问哪些数据。
- 用户和云服务提供商都需要密切合作，制定最佳计划，以保护数据免受任何泄露。
- 应对这些员工进行适当培训，以免他们以这种消极方式影响组织。需要对他们进行持续监控，并保持严格的检查。
- 所有使用云服务并拥有访问权限的用户都应该设置强密码。
- 应该使用审计工具来保护数据。
- 它既有好处也有风险。参与数据处理的双方，即组织和云服务提供商，需要确保各自履行各自的职责，并确保一切顺利运行。

### 3. 网络与通信安全

网络安全是一组用于防止网络遭受恶意攻击者的政策、协议和实践。这是一个非常多样且广泛的术语，涵盖不同技术并维护网络的隐私。网络安全基本上涉及对网络上数据访问的授权，这是网络管理员控制和监督网络的职责。为了访问网络，用户会被分配一个 ID 和密码用于身份识别。登录账户后，他们可以访问其权限范围内的信息。

- 用户应启用三步验证以维护账户安全。
- 为了使系统更安全并确保两台主机之间的通信免受任何恶意活动，加密数据非常重要。
- 防火墙确保实施网络安全策略并监控网络用户可以访问哪些数据。
- 像蜜罐这样的诱饵资源是一种良好的实践，它被放置在网络上的这样一个点，攻击者认为那里未被监控，并将其视为漏洞。这些蜜网被故意设置为脆弱，以便攻击者发现攻击它们很容易，从而浪费他们的时间和资源。
- 用户应在设备上安装反恶意软件或反病毒软件。这将为他们提供额外的安全层。
- 数据访问控制用于监控谁在访问哪些数据。为了使系统安全，您需要向经过授权的用户提供访问权限。
- 如果恶意软件进入计算机系统，它就很容易损坏数据，一旦数据损坏就无法使用。还会发生数据丢失。
- 为了保护网站上的数据安全，已经引入了不同的软件技术。如果员工访问它们，他们也会将这些恶意威胁带到自己的设备和网络环境中。
- 网络分段是一种常见的做法，用于确保网络免受网络安全威胁。
- 电子邮件安全软件确保过滤所有进出邮件，以维护系统和网络的安全。
- 如果您的系统开始出现异常行为，您的网络安全和 IT 团队需要找出根本原因并提供解决方案。

### 4. 资产与 IoT 安全

### 资产安全

在信息技术中，资产是指对用户重要的任何数据、设备及其他所有此类事物。资产包括对用户重要的硬件、软件和其他信息或数据。这些资产需要防止未经授权的访问、使用和利用。为了确保资产安全，对数据进行分类并根据其优先级确保其保护非常重要。

- 公开数据是指普通公众可以查看的数据。此类数据不需要保护。
- 私人数据是指需要防止他人查看的数据。这可能是您的个人信息、信用卡号码、银行对账单、健康记录等。泄露这些数据可能会导致严重问题。
- 不惜一切代价需要严格保护的数据称为敏感数据。
- 机密数据是指仅相关人员可以查看的数据。
- 不太重要的数据可以不进行分类。它不是敏感数据。
- 泄露秘密信息可能会危及国家安全。
- 极其重要的受保护信息。如果泄露可能会导致大规模破坏。

### 数据管理

组织必须管理大量的数据、信息和计算机资源。为了有效地做到这一点，需要一个良好且高效的数据管理计划。高效计划应由政策、程序和实践组成，以确保数据得到妥善管理。

- 为了制定一个高效且严格的数据管理计划，需要着手制定数据政策。数据政策文件是由高级管理层制定的官方文件，其中包含组织努力实现的所有长期目标。
- 对流经组织的数据分配所有权非常重要。信息所有者将对该数据负责。数据所有者还负责数据分类。数据所有者必须确定更改或替换某些信息所需的成本，他需要能够确定信息将如何影响组织的目标，不仅如此，当信息完成其生命周期时，他还负责销毁信息。数据所有者需要确保他们创建有关数据所有权权利的文档。
- 数据保管员的主要职责是监控数据并确保为数据创建最新的备份。
- 使用数据来完成工作的人是用户。
- 管理数据的人称为数据管理员。

## 第6章：考试策略及如何利用考试资源

### 考试策略：

在参加考试之前，请确保你为考试制定了充分的策略。以正确的策略应对考试非常重要。它能帮助你完成整个考试。它能帮助你合理管理时间，从而不浪费太多时间就能解答每道题。CISSP的考试策略简单而有效。你可以先从你100%确定的问题开始解答。先解答那些，然后再处理其他问题。这样你就不会浪费太多时间。你已经为考试做了准备，所以显然你知道自己在解答哪些问题。你确定的、简单而容易的问题解答起来不会花太长时间，因此自然你会有充足的时间去尝试那些复杂而冗长的问题。由于是选择题，你完成它们不会花太长时间。如果你觉得对某些问题很熟悉但不知道确切答案，你可以先排除明显错误的选项，然后再尝试找出正确答案。排除错误选项会让你更容易从剩下的选项中做出选择。尽量不要从工程师的角度来回答问题。这项考试主要是面向管理者的。所以尽量用管理者对某事的观点来回答问题。人们常犯的一个错误是不注意问题，忘记考试中有些问题应该从管理者的观点和角度来回答。尽可能多地收集问题。这也能让你了解测试会是什么样子。尝试在不同的在线资源上搜索问题，然后在完成准备后，你可以开始做模拟测试。模拟测试是一次性通过考试的关键。

之后，你将被引导至考试室。考试管理员将首先给你一个简要介绍并进行定向流程。在考试管理员的定向之后，你将被带到计算机终端前参加考试。在开始考试之前，你将有 5 分钟时间审阅并接受保密协议。如果你不接受保密协议（NDA），将不允许参加考试。如果你想参加考试，应在开始前签署保密协议。不签署保密协议将不允许申请费用退款。考试费用不会退还给你。

### 你需要携带的文件：

你在前往考试中心参加考试时需要携带一些文件。你必须携带的第一个也是最重要的东西是身份证件。你需要携带主 ID 和次要 ID。这些身份证件是必需的。进入考试设施之前，你还将被要求进行掌静脉扫描。如果你不能证明身份，将不允许参加网络安全考试。

你必须携带的身份证件不得过期。它们应当是有效且合法的身份证件。你携带的文件必须是原件且真实。就身份证件而言，你的主 ID 上必须有你的照片。主 ID 上的照片应固定在文件上。它还应有你的签名。另一方面，次要 ID 需要有签名，而主 ID 则需要同时有照片和签名。

接受的主 ID 可能包括你的身份证、出生证明、驾驶执照、护照、军人 ID、员工 ID、学校 ID、信用卡、配偶及受抚养人军人 ID 等。

接受的次要 ID 可能包括你的信用卡、ATM 卡、借记卡、美国社会安全卡等。

信用卡既可以用作主 ID 也可以用作次要 ID。主 ID 是指任何带有你的照片和签名且有效的证件。因此，如果你的信用卡同时有照片和签名，它可以用作你的主 ID。事实上，任何同时带有你的照片和签名的卡片或文件都可以用作你的主 ID。主 ID 和次要 ID 都应当有效且未过期，如果过期将不予接受。

### 考试期间休息：

你应该一直留在座位上。只有当考试管理员说可以离开座位并站起来时，你才能离开座位，否则请就座。如果你想去洗手间，将由考试管理员陪同。不允许你独自离开。会有人陪同你。不允许你更换终端，因为这也是不允许的。如果你用于参加考试的计算机终端出现问题，只有在考试管理员（TA）的指示下才能更换。

### 考试期间的协助：

你应该与考试中心工作人员保持良好行为。你不应在考试中心行为不当或制造不必要的场面。你应该遵守规则。确保你知道考试中心应遵守的所有规则。如果你需要什么或想离开座位，请举手。只有在考试管理员允许时才能离开座位。如果他不允许，请安静地坐着。如果你的计算机终端出现问题、需要什么、需要考试管理员协助或想休息，可以举手让管理员知道。

### 考试期间休息：

考试期间你可以休息的次数由你自己决定。关于考试期间可以休息的次数，没有严格的规定。但你必须牢记一点：无论休息多少次，所有休息时间都会从你的考试时间中扣除。完成考试所需时间为 6 小时，你必须在 6 小时内完成。因此，休息时时钟绝不会停止，而是会继续走动。你应尽量不要休息太多次，除非绝对必要。休息会浪费你的时间，而这是你无法承受的。




你必须离开正在进行考试的房间。如果你想休息，不能留在那里。你每次休息前后都需要进行静脉掌纹扫描。你可以离开考试房间，但不能离开考试中心。你必须留在考试场地内。休息期间，你不得触摸或使用个人物品。只有在需要服用药物等情况下，才可以访问个人物品；否则无需访问。你也不得访问手机及其他电子设备。

### 你参加考试的环境：

考试中心会同时进行多场考试。并非所有人都会参加与你相同的考试。Pearson VUE 监考员会在同一中心同时进行多场考试。与你在同一房间的人可能正在参加某些综合考试。有些人可能正在回答问题。例如，论文类题目需要作答。因此房间里会有噪音。你无法控制参加考试房间的环境。人们在键盘上打字也会产生噪音。你应该习惯，因为这是每个考试中心都会出现的噪音。

不过，你可以申请降噪免持式耳机或耳塞。这样你就听不到噪音，可以安静地继续考试。

### 考试后：

考试结束后，你不应该突然站起来大喊自己考完了，因为同一房间还有其他人正在考试，你应避免打扰他们。你不应直接前往团队管理员处，而应举手通知团队管理员过来。团队管理员过来后，你应告知他已完成考试。考试结束后你应离开场地。但如果你认为考试中出现了违规情况，或觉得考试条件和环境对考试产生了负面影响，应立即与团队管理员交谈。在与他们交谈前不得离开场地。如果你离开后再前来讨论考试违规问题，将不予受理。在处理好与考试相关的所有事项后方可离开。

### 罕见技术问题：

虽然罕见，但考试中心可能会出现一些技术问题。如果考试设施出现任何问题，你随时可以重新安排考试。在正常情况下，如果你想重新安排考试，必须至少在考试前 48 小时通过在线网站通知 Pearson VUE，或在电话预约前 24 小时通知。但如果出现问题，你将获得重新安排的选项。如果出现的问题占用了你预定考试时间超过 30 分钟，你可以重新安排。如果考试期间出现任何技术问题且解决时间超过 30 分钟，你可以选择等待继续或改期至其他时间。在这种情况下，不会向你收取额外的重新安排费用。如果你选择在延迟后继续考试，则该考试成绩将被计入，且无法申诉。但如果你选择取消考试，可以免费重新安排。

如果在预定考试时间之前出现需要一段时间修复的问题，团队会提前联系你并告知。因为你的时间宝贵，不应就这样浪费掉。

### 测试设施内禁止携带的物品：

之前已讨论过你应携带的物品，现在我们来讨论测试设施内禁止携带的物品。你不应将任何武器带入测试设施。如果你携带了武器或类似武器的物品，将被要求将其存放在车内。如果你不是开车到测试设施，则将被要求将其与其他随身物品一起存放。只有负责安保人员才允许携带武器，因为他们在履行职责。即使你本人是安保人员且有预约考试，也不允许携带武器。

### 另一条重要更新：

你需要确保姓名填写正确。你必须在 Pearson VUE 上注册与身份证件上一致的名和姓。如果身份证件上的姓名与在 Pearson VUE 注册的姓名不一致，你将不得参加考试。

如果你的姓名已合法更改，你需要出示官方文件向考试管理员证明。Pearson VUE 不接受所有类型的文件，只接受离婚判决书、结婚许可证和姓名更改法庭文件。如果身份证件上的姓名与在 Pearson VUE 注册的姓名不同，你需要在考试当天前更正。此类事项不会在考试当天处理，你将被要求离开。

### 迟到与缺考政策：

首先，你应尽量准时到达。你应尽早出发以准时到达。如果万一迟到或完全未到场，你必须承担后果。

如果你比预定考试时间晚到 15 分钟，将被视为迟到。之后是否允许你参加考试将由 Pearson VUE 决定；决定将在不影响其他正在考试的人的前提下作出。Pearson VUE 会尽量为迟到的你安排座位，但如果没有空座位，他们将不得不让你离开。

如果你迟到或完全未到场，系统中会显示你为缺考考生，你将无法要求退还考试费用。因此，为避免此类情况，你需要在考试开始前大约 30 分钟到达。这也能帮助你放松，从而在考试中发挥更好。如果你迟到且早晨匆忙赶时间，可能会感到紧张或恐慌。感到一切都很匆忙会增加考试焦虑。

### 考试中作弊：

如果在考试中被发现作弊，将采取严厉措施；如果你发现他人作弊，对他们也将采取严厉措施。你应将此视为自己的责任：如果在考试中发现或抓到有人作弊，请立即报告。

## 第 9 章：考试后

与考试前和考试期间需要牢记的重要步骤一样，考试结束后也有几件事需要注意。离考时，Pearson VUE 会提供你考试的非正式成绩；之后官方成绩将通过电子邮件发送给你。如果你通过了考试，将进一步指导你如何完成认证流程。

### 成绩政策：

(ISC)2 有严格的成绩政策。在确定及格或不及格分数之前，会对分数数据进行详细和全面的统计。统计分析需要最少数量的考生。这是一个非常详尽和关键的过程；参加考试的人数越多，编制成绩所需的时间就越长。成绩可能需要至少 6 到 8 周。离考时提供给你的成绩将是非正式成绩。官方成绩不会立即提供；相反，在对分数数据进行统计分析后，将通过电子邮件发送给你。离考时的非正式成绩将由 Pearson VUE 提供。由于参加考试的人数众多，官方成绩编制需要较长时间。如果在统计评估期间你的分数受到影响，(ISC)2 会通知你。参加考试时要非常小心和留意。如果在考试前、中或后发现任何违规行为，你将面临可能影响总体成绩的严重后果。如果怀疑存在违规行为，(ISC)2 将审查情况并据此采取相应行动。这可能导致不给受损试卷评分或取消完整成绩。高级机构认为适当的任何行动都将被采取。

这还可能影响你之前获得的所有认证；(ISC)2 可以撤销你之前的所有认证。他们不仅会撤销你之前的认证，还会禁止你未来参加其他认证。

### 重考政策：

考试重考政策会给你一定的灵活性。在考试和重考之间，你会获得没有考试的天数。你可以在此期间进一步巩固概念，并确保为考试做好充分准备。这是一个绝佳的机会，可以针对之前考试中的不足进行改进，并将其转化为优势。

你可以多次尝试通过考试。第一次考试后，你可以在 30 天后重考。这 30 天是没有考试的天数。如果第二次考试不合格且未获得认证，你可以在上次尝试后 60 天重考。如果第三次考试仍不合格，你将获得 90 天


从之前的尝试中重新参加考试。第三次尝试后，您可以随时在最近一次尝试后90天重新参加考试。

### CERTIFICATION PROCESS

在您收到官方成绩单并通过考试后，可以进入下一步，即认证。您可以从背书流程开始。这个背书将显示您是否符合认证资格。它将包含您的考试结果和相关工作经验的信息，以证明您是否符合认证流程的资格。背书申请必须由一名(ISC)2认证专业人士进行数字签名。如果您没有(ISC)2认证专业人士作为熟人，(ISC)2本身将成为您的背书人。您的背书申请提交并确认后，您将成为(ISC)2俱乐部的成员。您将通过电子邮件收到通知，然后可以通过支付年度维护费或AMF来开始您的会员周期。支付这笔年度维护费对您来说很重要，以便您能成为社区的会员。

### YOU CAN APPLY FOR RECERTIFICATION

如果您的认证或资格被暂停，您可以通过支付所有应缴的未付款项来重新激活它。您还需要支付所有年度维护费和CPE学分。维护费必须每年支付。如果过去几年您没有支付，您的认证和资格将被暂停，要重新获得或激活，唯一的办法是支付所有未支付年份的未付款项。在您的认证或资格被暂停后，将开始一个90天的期限，在此期间您需要支付CPE学分和年度维护费或AMF。这个90天的期限被称为宽限期。您可以保持暂停状态的时间最长可达2年。如果会员被连续暂停两年，他们需要自行重新认证。是的，他们不需要重新考试作为对其专业技能的认可，但需要支付600美元的重新激活费。他们只需为重新认证付款，而无需投入时间和精力再次参加考试。

如果在暂停两年后仍未清偿未付款项，所有会员权利将被撤销，并且会员资格将被终止。如果任何被终止的会员希望重新激活，他必须再次参加考试并通过，必须参加考试并支付600美元的重新激活费。

## Chapter 10: Time Management Tips And Tricks

### TIME

时间非常宝贵，不应浪费，没有什么比时间更宝贵。您需要珍惜时间，如果您学会如何珍惜时间，您将在为之奋斗的任何事情中取得成功。您为之奋斗的一切都是驱动您热情的基本力量。

### TIME MANAGEMENT

要成为一个不浪费时间、能够有效按时完成所有杂务的人，您需要开始练习，然后逐步掌握时间管理的艺术。这一切都取决于您以及您管理时间的能力。

### TIPS AND TRICKS FOR TIME MANAGEMENT

珍惜时间是成功的标志，如果一个人珍惜时间，他就被视为成功的人。时间不等人，它在不断流逝。以下是一些技巧和窍门，可以帮助您在考试前和考试期间进行时间管理。

### 1. SET GOALS

您需要先设定目标。如果您的目标是成为认证CISSP专业人士，您需要努力实现它。如果您没有目标，您将无法珍惜时间。只有在您需要取得许多成就、为自己热爱的事情奋斗时，才能学习到时间的重要性和价值。您为自己设定的目标应当是SMART的。您应该尝试为自己设定可实现且可衡量的目标。您应该设定具体、可衡量、可实现、相关和有时限的目标。您可以将您的目标与这些属性进行比较。在网络安全CISSP考试的例子中，您的目标是SMART的。您成为CISSP认证专业人士的目标应该是具体的，您应该知道自己想要做什么。它是可衡量的，因为如果您通过了考试就算成功，没通过就算失败，这很明确。您的目标也是可实现的，这意味着您可以实现它。您成为认证网络安全专家的目标在当今和未来都具有相关性。您应该设定您希望实现目标的时间限制。一旦您这样做，实现目标就会变得容易。

### 2. PRIORITIZE YOUR TASKS

您应该根据紧急程度和重要性来优先安排您的任务。划分您的任务，然后尝试处理那些重要且相关的任务。不要尝试做那些不重要或无关紧要的任务，因为您会浪费时间。这不是时间管理的方法。您可以通过优先安排任务来管理时间。划分您的日常任务，然后确定哪些任务需要优先处理，哪些可以稍后处理。您应该将任务分为以下四类：

- IMPORTANT AND URGENT:

您认为紧急且最重要的任务应优先处理。您不应该拖延这些任务，并应尽快完成。

- IMPORTANT BUT NOT URGENT:

这些是重要但不那么紧急的任务。您可以根据自己的方便决定何时完成它们。

- URGENT BUT NOT IMPORTANT:

如果有紧急但不重要的任务，您可以请别人替您做。您可以在将该任务交给别人时去做其他事情。

- NOT URGENT AND NOT IMPORTANT:

可能存在既不重要也不需要很快完成的任务。您可以将这些任务搁置一旁，稍后再处理。您不必为了完成这些任务而放下其他重要任务。您可以在以后的某个时间做它们。

### 3. COMPLETE TASKS WITHIN A SPECIFIC TIME

您可以尝试在特定的时间限制内完成任务。您不应该花一整天只做一项任务。尝试指定或设定一个时间限制来完成该任务。这将大大帮助您管理时间，并尽快完成待办事项列表上的大部分任务。查看您需要完成的任务，然后为当天的每项任务分配时间。每项任务都会分配到完成时间。您不会坐着或躺着一整天只做一项任务而把其他所有任务都抛在后面。您还需要为可能出现的问题分配一些时间。您必须处理这些潜在问题，因此必须预留一些时间来处理它们并解决这些问题。

### 4. POMODORO TECHNIQUE FOR TIME MANAGEMENT

番茄工作法是一种非常好的技巧，可以帮助您进行时间管理。它是最有效的时间管理技巧之一。番茄工作法可以帮助您克服拖延。在番茄工作法中，您需要选择一项要完成的任务。然后您可以设置计时器并开始工作。将计时器设置为25分钟。在这25分钟内，尽可能多地完成工作。当计时器结束时，就是您休息5分钟的时候了。不要长时间休息。休息结束后，您可以重新开始整个流程，继续做尚未完成的同一任务，或者如果该任务已完成，则选择另一项任务。然后再次将计时器设置为25分钟并开始处理该任务。当计时器结束时，短暂休息5分钟。不断重复该过程，尽可能多地完成任务。连续4个番茄钟后，您可以休息25到30分钟的长假。当您为任务设置计时器时，请确保不要不断暂停它，一旦开始就必须完成。在这25分钟内，您不得回复短信、接电话、接听来电或查看电子邮件。专注于您正在处理的任务。不要让这些干扰分散您的注意力。您可以在休息时间做所有这些事情。如果您有一项较大的任务无法在25分钟内完成，您应该将其分解为小任务，然后在一个番茄钟内完成每个小任务。这样，您就能在更短的时间内、不受任何干扰地完成任务。这是一个您可以遵循的很好的时间管理技巧。您也可以使用番茄工作法来帮助您准备CISSP考试。课程内容非常广泛，完成它需要很长时间。您可以将每个领域分解为小块，然后在番茄工作法的25分钟内完成每个块。如果您注意到您在25分钟内决定完成的某项任务提前结束，那并不意味着您可以浪费剩余时间，



剩下的时间可以用来进行过度学习。如果在计时器响起前完成了任务，应该继续学习更多内容。

### 5. 适当休息：

为了提高效率，完成一项任务后应该尝试休息一下。如果一直工作且不休息，你会感到厌倦，然后就什么都不想做了。所以中间要休息，帮助自己恢复精神。你可以在中间读读书，或者尝试出去散散步。

### 6. 尽量保持有条理：

你应该每天制定待办事项清单，这样你会更有条理，并知道哪些重要任务即将到来。这能让你轻松了解所有任务，并能以合适的方式对其进行优先级排序。保持条理也能帮助你不浪费时间，知道自己的东西放在哪里，而不必到处寻找。把所有截止日期和所有要求完成的工作都写下来，这样你就不会浪费时间。整理好每天的任务和物品，真的能帮助你好好管理时间。记下任务、制定待办事项清单的好处在于，能让你更轻松地管理任务，知道什么时间该做什么事，并据此把事情做完。

### 7. 把不重要的任务留到以后：

制作待办事项清单，然后评估哪些任务重要、哪些不重要。评估之后，可以把不重要的任务留到以后。你需要专注于重要任务并完成它们。如果看到任何额外且不重要的任务，可以请别人代劳，或者在空闲时自己完成。如果摆脱了不重要的任务和活动，你就能有时间处理真正重要的事情。

### 8. 提前计划：

提前计划能极大地帮助你管理时间。你将能够好好安排时间。每天早上都应该列出清单，了解当天是否有重要事项，有时你可能太忙而忘记做重要的工作。提前一天做计划也能在这方面提供帮助。

### 时间管理不善的后果：

如果无法有效管理时间，你将面临许多问题。更好的时间管理确实能让你的生活变得轻松。如果时间管理不善，你将面临严重后果。以下将讨论因时间管理不善而可能面临的后果：

### 1. 效率低下：

如果你在时间管理上遇到困难，工作效率就会变得很低。很多重要事情会被搁置未完成，并对工作产生负面影响。如果你在备考期间无法妥善管理时间，这会对备考产生非常不利的影响。你要意识到，所有领域都有课程内容包含在考试中，仅仅因为缺乏良好的时间管理，你就会看到这对考试结果产生的负面影响。网络安全考试课程内容的所有领域都同样重要，你不能只留下部分课程不学。你必须花足够的时间学习和准备所有领域。所有课程内容都需要认真准备。

### 2. 宝贵时间被浪费：

时间很宝贵，你不应该浪费它，并意识到它的重要性。但如果你不擅长时间管理，最终会发现自己在浪费时间。你会沉溺于干扰之中。在工作时，如果无法抵御干扰，会导致你浪费大量时间，也没有足够时间完成其他事情。

### 3. 时间管理不善会导致焦虑：

如果无法妥善管理时间，你可能会面临焦虑。如果你提前计划并制定当天的待办事项清单，就可以避免这种情况，因为你知道接下来该做什么；但如果无法妥善管理时间，你会不断对接下来要做什么感到困惑。你无法为即将到来的事情做好准备。时间管理不善会让你时刻感到焦虑和困惑。

### 4. 工作质量会下降：

时间管理不善会让你牺牲工作质量。你无法为即将到来的事情做准备，持续的焦虑和困惑感会攫住你，并反映在你的工作中。这会降低工作质量。假设你已经安排了CISSP考试，但因为忙于其他事情而最终忘记了它。你没有充分准备。到了紧要关头，你才意识到自己还有考试要参加，然后会匆忙完成考试前需要做的所有任务，这会反映在你的考试成绩上并降低你的分数。另一方面，如果你把一切都计划好了，你就会做好准备。这样一来，你就会知道考试安排在什么时候。你会在约定的时间去考试中心，充分准备参加考试。所以为了避免这种情况，你应该始终尝试做计划，知道什么时候该做什么。这样你就不会面对这些令人困惑的情况，工作质量也不会受到影响。一切都会进行得很顺利。

### 5. 时间管理不善会产生负面影响：

如果无法妥善管理时间，你的声誉可能会受到很大影响。这会对你的工作产生非常不好的影响。客户会将工作交给你，仅仅因为你无法好好管理时间，你就会延迟交付工作。你的工作会因此受到很大影响。你在社区中的声誉也会受到很大影响。这只会给你带来损失。当你无法交付客户信任你的工作时，他们肯定会把生意带到别处，因为每个人都希望自己的工作能按时交付，而你仅仅因为无法有效管理时间就造成延误。如果你能好好管理时间，不让任何干扰分散注意力，你会发现自己的日程安排有很大改善。你最终能按时完成工作。不仅如此，你还能为自己腾出一些空闲时间，在那段时间完成所有待办工作。你将能成功地妥善处理专业和个人工作。

### CISSP考试前的时间管理：

以下是一些可以帮助你在CISSP考试前进行时间管理的建议。你需要先为备考制定时间表。这将极大地帮助你在不同考试领域之间分配时间。至少在考试前一周，你应该已经覆盖了将包含在测试中的整个课程。不仅如此，还要确保你已经做了至少1500道选择题作为测试练习。如果你完成了这两件事，那么你就管理好了时间，并为考试做好了准备。如果你没有完成其中任何一项或两项，你就会有问题，并考虑推迟考试，直到你完全准备好为止。在考试前，当你完成课程准备后，应该回到练习题，不要做新题目，而是尝试纠正之前做错的题目。这将帮助你在考试当天做好充分准备。

### 考试当天的时间管理：

在考试当天，你需要早起。你需要有效管理时间，以免迟到考试。(ISC)2对考试迟到有非常严格的规定。迟到还可能导致考试被取消且不退费。

考试期间，你需要有一个策略来做好这些问题。先做你有把握的、陈述较短的、看起来容易的问题。要谨慎地做。这很重要，因为如果你在这些简单题或陈述较短的题上浪费太多时间，你将只剩下很少的时间来处理陈述较长或看起来复杂的选择题。如果你在每个问题上花太多时间，你就无法在规定的时间内完成考试。你知道你只有六个小时完成考试，如果中间休息，考试时间会进一步减少。因此你需要在问题之间分配时间，并尽力做到


不要超过那个时间。给简单的问题分配更少的时间，给复杂的问题分配稍多一点的时间。你应当采取快速策略对待前 50 到 60 道题目，尽快做完，以便为其他题目留出时间。前 50 到 60 道题目并不那么困难。它们相对容易，所以尽量不要在它们上花费太多时间。你应当合理安排时间，为困难题目留出足够时间，因为那些题目需要思考，所以请务必安排好时间。

## 第 11 章：自信是关键

### 自信：

考前和考试期间，你需要的就是自信。不要因为考试而恐慌，反而应对自己为考试所学的一切充满信心。你需要相信自己和自己的准备。紧张或恐慌对你毫无好处，反而会影响你的准备，让你仿佛忘记了所学的一切。如果遇到一道不会答或难以解决的题目，紧张会让你大脑一片空白，这也会影响试卷的其余部分。你可能懂试卷的其余部分，但仅仅因为你让考试当天的紧张和恐惧对你造成影响，就会非常负面地影响你的考试结果。在参加考试前应避免紧张。不要失去信心，也不要让任何人打击你的士气。对自己有信心，你就会考试取得好成绩。应努力不让任何负面想法进入你的脑海，干扰你的考试及其准备。

### 减轻考试焦虑的建议：

以下是一些可以帮助你克服考试焦虑的建议。考试当天的恐惧会对你的准备和最终结果产生真正的负面影响。

- 1. 积极思考：

积极是成功的关键。应尝试进行一些心理锻炼，激励你的心态产生积极的想法。你的想法很重要。如果你持续有消极和负面的想法，你会看到这对你有多大的负面影响；另一方面，如果你积极思考，你会看到积极性带来的不同。因此，请务必不让任何负面想法打垮你。我们的期望会极大地影响我们的表现。如果我们期待积极的结果，结果就会是积极的；但如果期待消极的结果，结果无论如何都会是消极的。所以，对你的试卷要抱有更好的期望。你可以通过肯定语来让自己的心态产生积极的想法。不断提醒自己，你能行，你足够好，一切都会变好。可以看一些有趣的电影或节目，把消极想法从脑中赶走，你就会开始积极思考。应挑战自己，如果你发现很难积极思考，觉得消极想法正在淹没你，请务必挑战那些消极想法。找到方法，让它们离开你的脑海，开始给积极的想法腾出空间。积极是关键，没有积极，你就无法取得任何好成果。为了培养考试自信，你首先要做的就是让积极的想法进入你的脑海。

- 2. 你的认知很重要：

你的认知非常重要。应不断提醒自己，无论如何都可以重考。考试的任何成绩都不能定义你，但你的努力和毅力可以。焦虑水平升高会极大地改变你的结果。如果你对自己和准备感到自信，你就能不带消极或不良想法地参加考试。如果你这样想，就能帮助自己降低焦虑水平并增强自信。

另外，当考试管理员第一次发给你试卷时，你应该先浏览整份试卷。如果你的准备充分，你就能认出简单的问题。先从简单的问题开始，这也能帮助你建立信心。这会让你意识到你掌握了知识，然后你可以慢慢逐渐地去解决困难的问题。

- 3. 让自己冷静下来：

当你感到害怕或紧张时，身体会释放肾上腺素，可能会产生一些生理反应，例如头晕、出汗、颤抖等。如果你处于这种生理状态，大脑将无法正常思考，你可能会感到沮丧，对自己缺乏信心。你会觉得自己准备的一切都忘了，现在一无所知。如果你发现自己处于这种情况，需要让自己冷静下来，可以通过深呼吸来做到这一点。当你开始深呼吸时，心跳会恢复正常。你的呼吸会变得均匀，吸气的时间会等于呼气的时间。另一个可以让自己平静下来的方法是走动一下。这有助于你清空思绪，关注周围环境并积极思考。一段时间内不要只担心你的考试。伸展和放松肌肉也有助于你的身心平静下来。你的身体一直处于紧张状态，为了缓解，你可以尝试进行全身扫描，每次专注于身体某个部位几秒钟。可以从脚趾开始，逐渐向上进行。你也可以将双手向上和向身后伸展，从而释放身体的一些紧张。这些练习之后你会感到非常放松。

- 4. 考前吃点东西：

考试当天应尽量不要不吃早餐。尽量吃一些健康的食物，不要吃垃圾食品或喝能量饮料，因为它们可能会进一步增加你的焦虑水平。尽量吃一些富含蛋白质的零食。即使你不想吃东西，也应在参加考试前尽量吃点东西。

- 5. 考前一晚睡个好觉：

考试前一晚应尽量睡个好觉。确保休息充分，不感到困倦。好好睡一晚对你大有裨益，会让你的头脑清新而放松。如果睡眠不足，可能会让你头脑模糊，最终对自己造成伤害。因此，考试前一晚应至少睡 8 到 10 个小时。

- 6. 相信你的准备：

在参加考试前，避免向任何人谈论考试或你为其做的准备。有时，为了缓解压力，你可以什么都不想，也不谈论它。你可以暂时不去想它，让头脑放松。应该相信自己的准备，并不断提醒自己，该做的都已经做了。你的考试准备已经完成。应避免在考试开始前几分钟复习课程和页面。考试开始前至少一小时应合上书本和其他相关学习材料，给身心一些时间放松，因为这是你在过去几天紧张环境中应得的休息时间。

- 7. 包含休息时间：

应尝试在学习计划中加入休息时间，因为你需要一些时间来放松。这对你的心智很重要。给自己所需的放松时间。在休息时间做一些轻松有趣的活动。这真的能帮助你排解压力，让你感觉神清气爽。

- 8. 做瑜伽和冥想：

瑜伽和冥想对身心有着惊人的效果。瑜伽练习旨在帮助你放松，并在结束时感到清新。应定期练习瑜伽和冥想。它可以帮助减轻你可能感受到的精神压力和紧张。这也能提高你的专注力和注意力，因为瑜伽练习正是为此目的而设计的。请确保不要把瑜伽和冥想排除在你的学习计划之外。

- 9. 心理咨询：

与治疗师的心理咨询会议也能帮助你提升自信水平并降低焦虑水平。寻求专业帮助不必感到羞耻。如果你觉得其他什么都无法帮助你应对焦虑和紧张问题，你随时可以去找治疗师寻求专业帮助。治疗师确实会不遗余力地帮助患者，这是不应该拒绝的帮助。这些心理咨询会议能给你带来巨大的改变。

- 10. 让自己身边围绕着积极的



### 10. PEOPLE:

你应该尽量与那些不会让你沮丧的人相处，他们反而会提升你的士气，让你能够面对生活抛给你的任何挑战。让自己身边围绕着自信且自尊心较高的人。他们知道如何帮助他人，并且不回避提供任何帮助。试着多花时间和那些关心你、更欣赏你的人在一起。你可能有几个朋友试图让你沮丧，或者不支持你热衷的任何事情。他们不会放过任何机会来夸耀自己、吹嘘自己并贬低你。他们不断的贬低会降低你的积极性并增加你的焦虑程度。与这样的人相处后，你会注意到自己内心出现负面变化。但如果你与那些欣赏你且积极向上的人相处，你会注意到自己出现积极而良好的变化。你应该尽量远离消极和有毒的人，并加强与坚强、积极、良好之人的关系。这些人能够改变你的思维模式和思考过程。你会对自己更有信心，你的自尊心会增强。如果你的自尊心提升，你就会因为你是谁而热爱自己，并停止批评自己那些你无法控制的事情。

### 11. WATCH THE CLOCK:

有时候，如果你在考试最后时刻看一眼手表，发现时间不多，而需要解决的问题却很多。意识到这一点，你会因为还有题目没做而感到紧张。在那最后的时刻，你会无所适从，因为你会开始感到焦虑。为了避免这种情况，你应该在考卷开始前就为每道题分配时间。数一下题目数量，然后将分配的时间除以每道题。真正能帮助你的是，给复杂的长难题分配更多时间，给简单的短题分配更少时间。

### 12. DO YOUR OWN EXAM:

你应该专注并集中精力在自己的试卷上。不要看别人在做什么。你已经做好了自己的准备，只有你自己知道如何运用所有这些信息。每个人面对考试或测验都有不同的方法，所以不要因为别人在做什么而让自己压力过大。试着不要因为看着别人在做什么而分散对自己试卷的注意力。注意你的问题以及解决问题的速度，最好忘记班里还有其他学生。不要让自己因为更多地关注他们的考试而少关注自己的考试而感到困惑。

### 13. REACH THE TEST CENTER EARLY:

另一个能帮助你减轻焦虑、提升自信心的好建议是，尽量比预定时间更早到达考试中心。如果你比预定时间早到，你会有一些时间来熟悉环境，这在一定程度上能帮助你降低焦虑水平。尽量在考试前至少30分钟到达考试中心。如果你迟到，没有按时到达考试中心，你就会开始匆忙行事，而这会成为你焦虑和紧张的原因。

### 14. LISTENING TO SOME CALMING MUSIC:

听一些舒缓放松的音乐可以帮助降低你升高的焦虑水平。在开始考试前，你可以听自己最喜欢的音乐。音乐确实能极大地帮助平静你的心灵。听完音乐后，你的心灵会自动感觉到清新和宁静。你也可以听一些播客来帮助增强自信，减轻压力和焦虑。励志播客在考前听很棒。它们能促进健康积极的思维模式和生活方式。

### 15. NEVER UNDERESTIMATE YOUR POWER:

你有能力，你也很强大。你不应该低估自己的力量。这样做可以帮助你增强自信，在考试前不要开始感到恐惧和害怕。

### 16. DO NOT GET OVERCONFIDENT:

自信是好事，但过度自信是坏事。过度自信确实可能是一种令人担忧的情况。如果你觉得自己太过自信，就不会好好准备考试。你的准备工作会受到过度自信的严重影响。要学会控制它，不要让它对你造成伤害。你应该努力对自己和自己的能力保持自信，你清楚自己准备了什么以及如何准备，所以自信是你需要的，但过度自信是不必要的。过度自信会让你听起来自吹自擂，夸耀自己和自己的能力。尽量不要变得过度自信，因为这对你毫无好处，反而会让别人打击你，这不是一件好事。你应该努力保持谦逊和脚踏实地。这些品质是你成功的关键。

### 17. BELIEVE IN YOURSELF:

你应该相信自己和自己的能力，你知道自己能做到什么。不要让别人指使你，而是去追随你认为正确的一切。对自己和自己的能力有信心。你就是你，世界上绝对没有第二个像你这样的人。你足够好，你值得拥有。在脑海中不断重复积极的自我肯定，以帮助你应对局面。因此，不要怀疑自己的能力，而要学会如何将其发挥到最大潜力。自信地前往考试中心，尽力而为。不要慌乱或焦虑。这对你毫无好处，反而会影响你的试卷，进而影响结果。

## 第12章：CISSP 认证专业人士的福利

### CISSP 认证专业人员：

(ISC)2 的 CISSP 考试是一项你可以参加并成为认证安全专业人员的考试。它是备受尊崇且广泛认可的考试之一，能真正为你的职业生涯加分。CISSP 安全专业人员考试于1994年推出。该认证已获国防部（DoD）批准。全世界不同国家的任何人都可以参加这项考试。该考试在114个国家的882个考点提供。该考试提供8种语言；你可以根据方便选择想要参加考试的语言。CISSP 认证被认为是LinkedIn上最重要的认证之一。CISSP 专业人员获得认证后会将自己的技能付诸实践，目前他们在世界上近170个国家工作。约有142,000名专业人士获得认证，并凭借其专业知识帮助不同的组织。他们将在备考期间学到的所有信息付诸实践。这也是认证的先决条件之一：你需要在CISSP网络安全的8个领域中任何一个领域有将近5年的有偿工作经验。这为他们提供了专业经验，并进一步培养他们，使他们日后能够胜任全职工作。除了全职工作，他们还可以就不同组织面临的安全问题提供建议。网络安全是当今组织面临的巨大问题，这些网络安全专业人员帮助解决这些问题。他们为组织创建尖端的计划和程序，以应对攻击者和黑客发起的这些网络安全漏洞。CISSP 计算机自适应考试也已推出，与线性网络安全考试相比，它更短且更精准。它包含近150道选择题。这些题目需要在3小时内完成。线性考试包含250道选择题，时长6小时。两项考试的课程内容和大纲相似，但各领域包含的百分比略有不同。(ISC)2 的 CISSP 计算机自适应考试于2017年12月18日推出。

经认证的 CISSP 专业考试与其他任何考试都不同。与您至今可能参加过的任何其他考试相比，它更加困难。您需要制定广泛的学习计划，才能在第一次尝试中通过考试。全世界只有少数人通过了 CISSP 考试，并完成了其他要求，成为 (ISC)² 的认证专业人员。如今，安全专家非常受需求，因为这是互联网的世界。对互联网的依赖度越来越高，使得设备及其中存储的数据更容易受到黑客恶意攻击。网络安全专业人员需要为组织和个人设计和规划网络安全方案，以帮助保护其数据；如果数据被泄露，他们能够恢复数据，并制定备份计划，最大限度地降低损失。

CISSP 网络安全专业考试时长 6 小时，包含约 250 道选择题。为了帮助您充分备考，您需要遵循一个合理的计划。所有您需要知道且对通过考试有帮助的重要事项，都已在本书中详细解释。本书将引导您完成整个考试流程，包括考试注册、考试准备、考试实施，以及随后的认证流程指导。CISSP 考试是从管理人员的角度出发进行设计的。因此，您必须确保相应地回答问题。

请确保准时参加考试。您应该尽早到达，以便熟悉环境并放松心情。这也有助于减轻考试焦虑。很多人考前因为紧张和恐惧，最终影响了成绩。您可以遵循此处提到的技巧和方法，以免影响考试结果并帮助减轻焦虑。您也应该尽量在考前保持良好的睡眠。考前一晚至少要睡 8 到 10 小时，这样您醒来时精神焕发，考试期间也不会感到头晕。这些小事对备考和考试过程大有裨益。我们常常忘记去做，结果便会体现在考试成绩上。

做历年真题对考试准备非常有帮助。为了充分备考，您需要尽可能多地刷练习试卷。尽可能收集大量选择题，以便了解考试大致形式。这会带来两个好处：既有助于备考，又能在考试当天降低您的焦虑水平。这是因为您会知道可能会出现什么类型的问题，以及考试形式会是什么样。这在时间管理方面也非常有帮助。通过做这些历年真题，您能够在考试中合理安排时间。在考试中管理时间至关重要。您应该尝试练习所有您计划在考试中使用的策略。
