
# 家得宝数据泄露与第三方风险

2014年发生的家得宝数据泄露事件中，攻击者使用了第三方的登录凭证进入该供应商的环境。进入供应商网络后，他们利用了 Windows 的零日漏洞，从而获得了进入家得宝企业环境的访问权限。在家得宝网络内部，他们向公司的 POS 系统部署了内存抓取恶意软件，导致超过 5000 万张信用卡和借记卡号码被窃取，同时还窃取了类似数量的电子邮件地址。有效的客户电子邮件地址是网络钓鱼攻击的金矿。已有多个研究探讨家得宝本可以通过安装 IDS/IPS、端到端加密、网络分段以及其他技术和流程改进来检测攻击者利用的漏洞。很少有人提到建立更健全的网络安全尽职调查计划对供应商是多么合适。

该第三方供应商与家得宝有连接。虽然我们的大部分讨论都集中在数据安全上，但有一些供应商需要连接到你的网络来执行其业务功能。这类供应商带来的风险正如家得宝事件所示：他们不充分的安全控制正是黑客所需的滩头阵地。可以合理地认为，如果家得宝在企业内部有更好的安全模式，攻击可能已被阻止或更早被发现（他们潜伏了数月）。然而，如果家得宝采用了我们更完善的网络安全第三方风险方法，建立滩头阵地的风险就会降低。

在此更新的方法中，我们希望关注以下几点：
* 家得宝与其供应商的合同中有相关条款吗？它是否包含：
    * 与直接连接家得宝网络的供应商合同中适当的网络安全语言？
    * 合同条款中允许家得宝进行验证或获得供应商安全控制保证的条款？
* 以下几个高层问题本应得到更认真的审查：
    * 大多数供应商在客户现场维护的用于端到端连接的硬件通常会落入无人管理的地带，即谁来维护它。如果第三方拥有它，请确保他们安全地维护。是否按与供应商预先建立的定期频率对其进行验证以设定期望？
    * 他们的访问管理策略是什么以及他们如何在生产环境中执行？如果他们有策略，为什么没有发现此次活动？日志记录和监控是否不足？
    * 供应商的补丁管理策略是什么，他们是否知道该版本 Windows 中存在的零日漏洞？

请注意，其中许多问题是事件管理类型的问題，网络安全事件管理团队（CIMT）通常会在内部提出。在这种情况下，是第三方风险团队向供应商提出类似问题，利用写入合同中的语言，并将他们的安全作为你自身安全的延伸进行管理。

## 结论

网络安全与许多基于技术的职业一样复杂，通常需要大量的培训、学习和在该领域的沉浸才能熟练掌握。保密性、完整性和可用性这三个基本网络安全要素可以作为围绕数据保护和第三方进行的任何风险讨论的指引。信息安全侧重于确保数据仅限授权人员访问、受保护不被篡改，以及可供获准访问的人员访问。网络安全可以涵盖大多数企业网络中的广泛活动，将成为后续章节中尽职调查和审慎活动如何执行的基础。

网络安全框架为组织提供了降低安全事件风险的指南。需要关注的框架包括 NIST-CSF、ISO 27001 和 27002、NIST-853、2002 年联邦信息安全现代化法案（FISMA）、纽约金融服务部（NYDFS），以及适用于业务开展的行业、国家或地区的任何框架。对一个或多个这些结构的采用和遵守告知客户供应商如何应对风险降低。通过了解其框架采用情况，用他们的“语言”与他们交流，可以简化差距分析和补救措施的讨论。

网络犯罪和网络威胁的类型始终在不断演变。高级持续性威胁（APTs）和网络犯罪组织对他人构成最大威胁，因为它们往往拥有近乎无限的时间、资源和精力。攻击类型同样多种多样，但最近最常产生影响或被看到的是网络钓鱼和勒索软件攻击。利用伪造电子邮件进行社会工程，欺骗内部人员泄露其凭证，或下载加密其所有文件的恶意软件，通常是黑客阻力最小的路径。

了解泄露是如何发生的被分解为五个步骤——研究、入侵、横向移动、权限提升和数据外泄——我们还包含了其在 Target 如何实现的演练。这五个步骤（即阶段）说明了大多数 APT 和网络罪犯如何开展工作，以及这些步骤对何时以及如何阻止泄露的重要性。如果网络安全团队的侦查工作能在入侵或横向移动阶段发现泄露，就有很大机会以最小的损害和数据丢失遏制影响。然而，如果他们的检测直到数据外泄阶段才发生（这通常是检测发生的时间，因为黑客造成的损害变得为人所知），那么就完全没有机会阻止数据丢失和损害。这就是为什么网络安全专业人员推动诸如 IDS/IPS 和 DLP 等工具，以增强检测能力。

# 第 3 章

## COVID-19 大流行对网络安全和第三方风险的影响

大流行、由此产生的封锁、旅行限制和行为变化将在我们的生活、商业和政府中留下持久印记。由于这些即时影响，网络罪犯迅速行动，将其重点和努力转向利用围绕 COVID-19 的恐慌和混乱。随着时间的推移和其他新闻塑造事件，这些坏行为者继续根据该新闻改变其策略和信息。网络事件增加，因为重点更多地集中在如何在 COVID-19 期间赚取最多钱并造成最大损害。随着疫苗的接种和封锁可能结束，数据显示趋势将在封锁和旅行恢复正常后继续存在。被认为的“正常”将不同，这些修改意味着会有更多员工在线且保持连接，这将导致更大的攻击面（即更多连接 + 更多在线用户 = 更多目标）。

## 大流行停摆

2020 年 3 月 19 日，首批封锁令开始在美国各地实施。北美和南美大部分地区、欧洲以及亚洲大部分地区处于类似轨迹或已实施封锁。让员工在家工作的冲刺已经开始，包括与计划外大规模劳动力搬迁相关的所有风险。虽然一些公司已制定大流行计划和/或自然灾害计划来应对大流行，但绝大多数公司并未为如此规模和程度的大流行做好准备。当政府援助开始流向有需要的公民时，必然的网络罪犯和黑客抓住了机会。每个人所在位置和日常规律都被颠覆，这导致安全风险被忽视或未知。
