
### 入侵防御系统 (IPS)
入侵防御系统 (IPS) 是能够同时检测和阻止已知威胁的软件或硬件。这些系统也可以仅发出警报，具体取决于其阈值的配置方式。这些系统不断演进，近年来已取得进步。网络访问控制和防火墙现在也提供此功能。

### 防火墙
防火墙检查网络流量并根据规则阻止或允许流量。作为硬件和软件可用，这些设备从早期发展至今已高度演进，现在可以读取和检查加密流量。这些下一代防火墙 (NGFW) 可以深入查看流经网络流量中的数据，并提供采取行动的选项，阻止任何符合其恶意标准的流量。

### IP 地址
IP 地址是一串数字，用于标识唯一的计算机或网络。这些唯一数字允许在私有网络内或通过互联网进行通信。可以将 IP 地址想象成邮件上找到的地址。随着电子邮件（或流量）在网络上传递，所提供的 IP 地址指示电子邮件必须去往何处才能到达预期收件人。IP 地址由四组数字组成：192.168.1.1 或 10.102.201.32，组合数以十亿计。

### 端口
端口是物理或逻辑的开口，允许特定程序或应用程序进行连接。物理端口的示例可以是插入鼠标或 USB 闪存盘。逻辑方面，示例是正常互联网浏览，它通过端口 80 进行。如果您连接到安全站点，例如您的银行，您将通过端口 443 连接。这些端口的存在是为了使连接的每一方在通信时都知道确切使用哪个端口。与 IP 地址类似，端口使流量到达目标计算机或网络；端口指定对话要去的“房间”。

### 域名服务器 (DNS)
域名服务器 (DNS) 是一套计算机系统，将人类友好的名称（[www.rasner.com](http://www.rasner.com)）翻译成 IP 地址，原因很简单，IP 地址可能会变化，几乎没有人愿意记住一个。每当用户输入网站地址时，DNS 服务器会帮助将其翻译成正确的 IP 地址，以确保找到目标资源（即网站、数据库服务器、打印机等）。

### 网络访问控制
网络访问控制是一种方法，通过确保设备（即笔记本电脑、移动设备、计算机、服务器、打印机等）符合安全策略来限制对网络资源的访问。它也以其协议名称 802.1x 闻名，并被视为限制网络访问至符合安全标准并被允许连接网络的设备的重要工具。

### 带外通信
带外通信是指非主要连接设备的设备。例如，许多供应商会使用路由器或 VPN 集中器作为硬件设备连接到客户网络。有些会在路由器离线时放置调制解调器或替代设备以连接到该网络。这些设备对连接可能存在问题，因为它们通常未连接到任何监控或日志系统；因此，它们可能被黑客用作后门。

### 共享责任模型
云安全的共享责任模型由云服务提供商 (CSPs) 遵循，指的是不同解决方案如何将责任从 CSP 转移到客户。在公司拥有的传统数据中心中，该公司负责其技术的交付。部署到云时，随着从基础设施即服务 (IaaS) 转移到平台即服务 (PaaS)，客户的责任水平会增加。IaaS 模型要求客户比 PaaS 模型执行更多安全和维护工作。

### 个人身份信息 (PII)
个人身份信息 (PII) 是单独使用或与其他数据一起使用时能够使查看者识别个人的数据。构成 PII 数据的信息组合成千上万种，但通常包含姓名、社会安全号码、财务信息、驾驶执照、物理地址、电话号码等。

### 个人健康信息 (PHI)
个人健康信息 (PHI) 是与个人医疗信息相关的 PII，例如吸烟状况、任何疾病、药物以及其他非常保密的医疗数据。PHI 被认为比 PII 更敏感，因此需要更强的安全保护。

### 数据分类
数据分类是对数据进行分析并根据其对分类组织而言的敏感性将其组织到类别中。大多数公司通常有三到四个数据类别，但应只有一个类别标记为公开，另一个标记为私有或敏感。

就本书而言以及网络安全第三方风险如何处理此主题，云被定义为任何不在您自己的数据中心、服务器机柜或笔记本电脑硬盘驱动器（如果您是小型企业主）内部的位置。云可能位于云服务提供商 (CSP) 处，例如 AWS、Google 或 Azure，位于托管设施提供商处，或位于供应商直接管理的数据中心。

### 高级持续性威胁 (APT)
高级持续性威胁 (APT) 被认为是一种更高级的威胁行为者，因为黑客使用持续、隐秘和先进的技术来获得访问权限、更长时间保持隐蔽，并且通常未被检测到或只留下很少的取证证据。APT 开始利用供应链网络弱点。

## 网络安全框架
信息安全领域已存在足够长的时间，足以撰写出不止几个标准。安全框架是一系列政府网络安全政策和指南以及最佳实践的集合，用于保护信息系统。它们通常对组织处理 PII 有具体说明，以降低泄露或损害的风险。全球存在数十种，但您必须了解其中几个最有用的，以理解其范围和重点。网络安全框架为人员、流程和技术提供明确的结构，公司可将其作为参考来保护其网络、数据和系统免受网络威胁。有些是监管指导（例如，纽约金融服务部 \[NYDFS\] 或《健康保险流通与责任法案》 \[HIPAA\]），提供框架结构。一些公司采用与其行业相符的框架（例如，信息与相关技术控制目标 \[COBIT\] 和金融，或 HIPPA 和医疗保健提供商）。

### 国家标准与技术研究院网络安全框架 (NIST-CSF)
国家标准与技术研究院网络安全框架 (NIST-CSF) 是为响应美国总统行政命令 13636 而创建的，其目的是增强国家关键基础设施的安全性。虽然目标是电力和供水等关键基础设施，但许多私营公司已采用它。NIST-CSF 包含以下五个管理数据和系统安全风险的功能：识别、保护、检测、响应和恢复。这在 [图 2.2](#c02.xhtml#c02-fig-0002) 中显示。

识别功能侧重于识别物理和软件资产作为管理资产的基础。它根据其优先事项、约束、风险承受能力和支持管理其供应链风险的风险决策的假设，定义组织的供应链风险管理策略是什么。
