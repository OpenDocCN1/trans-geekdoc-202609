
# 供应商能否确保数据在需要时可供需要的人使用？

由于本书主要聚焦于第三方，参考内容将围绕这一重点展开。它*不*是关于贵组织正在执行的安全措施，而是关于第三方的情况，既包括他们提供的具体服务，也包括他们如何保护自身企业。我们提供了多个供应商连接被用于攻击公司的示例，以及他们的公司范围网络控制如何直接影响保护公司数据以及与贵网络的任何连接（无论是间歇性还是持续性）能力。

## 第三方风险的网络安全基础

某些术语和一些基础的网络安全原则是讨论供应商风险管理所必需的。本书通篇回顾了这些网络安全概念和组件。读者无需是网络安全专家；然而，如果您对其有基本了解，更容易把握风险、优先级和行动。您应牢记以下加粗术语，它们都有简化的解释。

### 加密

**加密**是将明文，如短信或电子邮件，转换为称为*密文*的不可读格式的过程。此文本有助于保护数据的保密性，无论数据存储在计算机系统上还是通过互联网等网络传输。这种能力是大多数数据安全讨论的核心。该领域存在子类别，例如同步加密和异步加密，但对于本书而言，讨论主要围绕加密级别展开。高级加密标准（AES）是美国政府等最常使用的加密类型。大多数组织通常为其企业采用 AES-128 或 AES-256 级别的加密。更高加密级别的权衡是速度——数字越高，解密所需的处理能力越多——因此，数字越高越好。

另一个需要关注的加密领域是加密的三种状态。数据包含三种状态：静态、传输中和使用中。*静态*顾名思义，即数据位于数据库或文件中时。*传输中*是指数据通过网络或互联网传输时。当进程正在使用数据，如 CPU 或内存中时，则被视为*使用中*。在所有三种状态下，数据都应加密。在与供应商讨论他们如何保护数据时，请确保讨论涵盖全部三种状态。

近年来，出现了一个新口号：“Identity is the new perimeter。”这句话指的是数百万人，尤其是在 COVID-19 大流行期间远程办公激增后，现在在远离工作和学校的地方连接工作和学习。他们的身份用于将用户连接到组织、工作或学校，以及该访问如何被管理，即*访问管理*，在保护企业（以及存储在供应商内部的数据）时非常重要。它要求实体在第三方风险方面关注多个领域。

首先，我们介绍访问流程，其中包括三个步骤：身份识别、授权和访问。身份识别阶段是用户输入姓名和密码，系统确认其身份的地方。接下来，授权步骤确认用户拥有哪些访问权限——该用户被允许查看和执行的内容。最后，提供正确的访问级别。一旦完成这三个步骤，用户即可访问其有权查看的数据和资源。

企业环境中最常见的访问类型、基于角色的访问控制（RBAC）包括具有特定访问权限的预定义职位角色。这种实现方式可通过两种角色类型的差异示例来说明。例如，人力资源（HR）经理很可能可以访问工资单和人事档案。然而，如果他们尝试登录财务服务器，系统将不允许连接，因为他们在财务部门没有角色。如果人力资源经理需要进入该服务器，他们必须向访问管理团队提交需要访问该服务器的业务理由。

### 单点登录（SSO）

**单点登录（SSO）**是一种限制用户为访问验证而提交身份次数的机制。在大多数大型组织中，用户需要与多个系统交互。他们的单点登录使他们只需登录一次即可获得权限，无需重新输入凭据。不同系统在它们之间静默传递此凭据权限，并在不引用凭据的情况下提供对其他系统和服务的访问。

### 多因素认证（MFA）

**多因素认证（MFA）**，也称为双因素认证（2FA），是指需要一个以上登录步骤的情况。（注意，此认证中可能涉及两个或多个因素。）MFA 主要有四种类型：
1. 你知道的东西，如密码或 PIN。
2. 你拥有的东西，如员工徽章或安全令牌（物理和软令牌）。
3. 你可以引用的东西，如指纹、视网膜或声音等生物识别项目。
4. 你所在的位置——你的位置。大多数系统在后台利用这一点，因此最终用户可能不知道此检查。注意，这种 MFA 类型并不常用，但如果您位于美国，而有人尝试在南美洲使用您的登录信息，系统会注意到这种差异并采取适当措施，例如提示进行额外验证或拒绝访问。

MFA 是一项重要的安全功能，应推广到所有账户类型。至少，MFA 必须用于所有特权和提升权限的账户。特权账户是指具有提升访问权限和执行更高风险操作权限的账户，例如系统管理员、高级管理人员和数据所有者。此重要功能可确保只有授权用户才能访问数据。

### 最小权限

**最小权限**是一种原则，即用户仅拥有完成当前任务或工作所需的权限（即访问权限）。例如，仅需要访问权限来查看数据记录的数据库用户不应具有执行删除或更改任何用户对数据库权限的权限。最小权限对于确保数据的保密性、完整性和可用性至关重要。

作为安全卫生的一部分，**补丁管理**是一个重要组成部分。它是分发和应用软件和硬件更新的过程。此过程对于修复错误和漏洞至关重要。供应商必须关注其流程以及在识别和分类安全漏洞（从高到低优先级）、测试并部署到生产环境时如何对其进行优先级排序。

### 入侵检测系统（IDS）

**入侵检测系统（IDS）**是监控网络流量和计算机系统以查找异常行为或已知威胁的硬件或软件。IDS 会提醒安全人员，这就是为什么该系统被称为检测系统——它除了检测和报警外不采取其他任何行动。虽然有几种 IDS 类型，但供应商使用哪种通常不是问题。IDS 的缺点是它不采取任何行动，只是报警；如果它检测到可疑网络流量，不会阻止该流量。一般经验法则是，大多数公司不会单独购买 IDS 作为独立产品，而是作为套件或捆绑产品的一部分。该系统不会对可疑流量采取行动，而是将其保留在企业内部并通知安全部门，以便进行监控。
