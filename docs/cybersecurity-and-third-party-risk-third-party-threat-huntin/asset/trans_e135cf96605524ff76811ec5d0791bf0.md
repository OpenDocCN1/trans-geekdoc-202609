
# 网络安全威胁与供应商尽职调查

## 网站伪造
网站伪造使用 JavaScript 劫持地址栏并将受害者指向目标网站。Cross‐site scripting is leveraged in these attacks where the hacker exploits flaws in a legitimate trusted website to direct the user to the hacker's own site for the attack. 这些攻击中利用了跨站脚本攻击，黑客利用合法受信任网站中的漏洞，将用户导向黑客自己的站点以实施攻击。The user signs in to the site thinking they are logging in to their bank, broker, or service, but in fact the site is collecting their data for exploitation later. 用户登录该站点，以为自己正在登录银行、经纪商或服务，但实际上该站点正在收集其数据以供日后利用。Website forgery is very hard to detect and often the user is not aware that they have been tricked. 网站伪造非常难以检测，而且用户通常不知道自己已被欺骗。

## 隐蔽重定向
隐蔽重定向与链接篡改类似，但区别在于使用真实网站配合恶意登录弹出窗口来掩盖攻击。例如，受害者收到一封钓鱼邮件，其中包含一个看似指向 Twitter 的链接。用户点击链接后，弹出窗口要求受害者授权该应用程序。一旦授权，应用程序就会将令牌发送给攻击者，受害者的数据就会泄露。如果未授权，攻击者可以尝试将用户重定向到恶意网站以进一步损害其数据。

钓鱼邮件是大多数组织面临的最大安全风险之一，因此需要成为公司持续尽职调查的一部分。虽然 90% 的钓鱼邮件会被邮件扫描软件拦截，但成功通过的邮件的复杂性足以使公司暴露于恶意软件之下。仅需一名用户即可使企业暴露于勒索软件或其他钓鱼攻击之下。平均而言，每月创建 150 万个钓鱼网站。平均 spear phishing 攻击导致损失 160 万美元，而企业遭受的 95% 的攻击都是由成功的 spear phishing 活动造成的。统计数据令人糟糕，虽然有软件可以过滤钓鱼邮件，但最好的防御手段是对用户群体的培训和教育。

确保向您的供应商询问其针对钓鱼的 用户意识和培训。此培训必须至少每年进行一次，并要求用户接受测试或验证。测试应在培训期间进行，也应作为反钓鱼活动的一部分进行。这些活动涉及使用软件工具发送虚假钓鱼邮件，以测试用户群体以寻找再培训机会。最好能看到供应商还开展 spear phishing 意识活动，测试高管和其他可能的目标。应为这些目标量身定制并发送特殊邮件，以查看他们是否会上当。要求查看贵公司供应商如何处理在这些活动中“失败”的员工。他们是否需要接受额外培训？如果他们持续失败，采取了哪些纠正措施来确保该用户不会危及企业？

## 入职与持续网络安全人员
该尽职调查层级的分析师可能处于网络安全专业知识的初级或早期阶段。KC Enterprises 要求该层级的分析师拥有 2–4 年的网络安全经验，证明其具备发现信息安全风险的能力。在面试期间，加密、访问管理和数据隐私相关主题的知识是关键领域。虽然不一定是入门级职位，但如果候选人与更有经验的分析师配对一段时间，则可以是入门级职位。如果入职时没有任何认证，此类员工需要在入职第一年内参加与其技能水平相称的认证课程。

在 KC，该员工职级从入门级网络安全分析师到高级网络安全分析师不等。这些角色非常适合成长为网络安全第三方风险团队中的其他尽职调查角色，或成长为信息安全其他领域中更胜任的角色。通常，这些评估员会接受培训成为现场角色，这需要更多的经验。如果这些人尚未拥有网络安全方面的认证，认证应成为他们的目标。

## 勒索软件：历史与未来
*勒索软件* 是一种恶意软件，它会加密您的数据并要求支付费用（即赎金）以将数据返还给您，受害者。这种攻击呈指数级增长，近几年增长了 350%，其中 68% 通过钓鱼攻击传播。预测到 2021 年，勒索软件攻击将每 11 秒发生一次。50% 的 IT 专业人士不相信他们的公司准备好防御勒索软件攻击。预计到 2021 年，这种恶意软件在全球的成本将达到 200 亿美元。

历史上最大的勒索软件攻击是 WannaCry 攻击，它说明了一些根本原因、如何减少其发生以及在尽职调查中与供应商就其控制措施进行沟通以防止其发生。2017 年 5 月，WannaCry 针对的是较旧的 Microsoft Windows 操作系统。它加密数据并要求以比特币货币支付赎金。Microsoft 发布了补丁以关闭漏洞，但仍有足够多的系统未打补丁以供利用。被利用的许多系统是 Windows 的生命周期结束版本，例如 Windows XP 和 Windows Server 2003。这些系统缺乏必要的制造商支持，并且自 2014 年和 2015 年以来分别没有可用的安全补丁。Windows 7 也具有较大的攻击面，因为它被广泛使用，而且许多用户没有定期对其进行修补。事实上，大量数据报告称，被感染的计算机中多达 98% 为 Windows 7。

攻击发生后的第二天，Microsoft 为多个生命周期结束的产品发布了额外补丁：Windows XP、Windows 8 和 Windows Server 2003。这些补丁是在 2017 年 1 月收到有关漏洞的提示后，于 2 月创建的。鉴于这些系统仍在运行并且长期缺乏安全补丁，这意味着许多系统在攻击发生后数天仍未打补丁继续运行。它们本就未进行补丁管理，并在随后的几天里继续未受管理，使得 WannaCry 的传播更加广泛。

随后是攻击者和防御者之间的一系列猫捉老鼠游戏。一名安全研究人员发现了硬编码在恶意软件内部的 kill-switch 域名。该 kill switch 的工作原理如下：如果无法联系用于传播恶意软件的恶意域名，它将继续加密数据。如果能够连接，软件将停止攻击。Microsoft 创建了一个 sinkhole（即网站的假地址），阻止了进一步传播，但并未修复已感染的系统。攻击者和防御者之间发生了几次其他来回交锋，使用新的 WannaCry 变种来绕过 sinkhole，最终出现了一个完全避免 kill-switch 域名的版本。

从这种勒索软件攻击中吸取的教训直接关系到供应商风险尽职调查工作应如何关注一些关键控制措施。由于钓鱼邮件是勒索软件的主要传播渠道之一，如前所述的反钓鱼活动的教育、培训和测试是关键控制措施。其他领域可以要求供应商提供更多信息，以帮助降低勒索软件风险。
