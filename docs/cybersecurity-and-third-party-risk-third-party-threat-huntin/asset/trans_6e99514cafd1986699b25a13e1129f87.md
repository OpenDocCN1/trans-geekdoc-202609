# 第16章

## 结论

在 [第1章](#c01.xhtml) 中，我们通过各种公司因其供应商而遭受泄露的报告，介绍了与第三方合作的网络安全风险。2020 年底。SolarWinds 供应链攻击的消息传出。然后，越南和蒙古的供应链黑客攻击事件公开。所有这些最新的泄露事件据信都是由高级持续性威胁（APTs）所为，他们花费数月时间进行侦察并利用关键组件来 exploit 公司、政府和个人在第三方尽职调查方面的弱点。

### 高级持续性威胁是新的危险

关于 SolarWinds 以及攻击者如何使用复杂手段进行攻击的证据越来越多，发现攻击中使用了第三种已识别的恶意软件。命名为 Sunspot，该恶意软件除了已识别的 Sunburst 和 Teardrop 恶意软件外还被使用。据信 Sunspot 漏洞利用是链条中首先使用的。令人惊讶的是，网络安全公司 CrowdStrike 发布信息称，该恶意软件首次部署是在 2019 年 9 月 SolarWinds 网络首次被入侵时。

似乎攻击者在 SolarWinds 的构建服务器上植入了 Sunspot，该服务器用于构建软件和构建他们销售的应用程序。Sunspot 的设计目的只有一个：监视构建服务器并观察组装 Orion 软件的命令——最终被利用的软件——它是拥有超过 30,000 名全球客户的顶级产品。这相当不可思议，因为据暗示黑客对他们想要用于更广泛攻击的顶级产品进行了研究，因为 SolarWinds 只是达到目的的手段，而非最终目标。他们安装了它并让它长时间运行，这意味着他们愿意等待以实现其最终目标——获得数万个 SolarWinds 客户网络的访问权限。

当观察到 Sunspot 恶意软件做了什么时，情况变得更加耐人寻味：当构建命令发送到 Orion 应用程序的构建服务器时，它会 stealthily 提取合法代码并用攻击者创建的代码替换它，其中包括 Sunburst 恶意软件。这意味着源代码被篡改，甚至开发人员也不知情。然后，受感染的代码被上传到官方 SolarWinds 更新服务器供客户下载，这无意中使他们的网络暴露于数据窃取和破坏之下。

当恶意软件感染的 Orion 软件在客户网络（例如政府、组织、公司）上下载并安装时，它会收集数据并通过命令和控制服务器（C&C）将其发送回攻击者。（所使用的技术并不常见，但之前曾被 APT 团队使用。）C&C 使用 DNS 通信来躲避监控工具的雷达。Orion 使用了 *域名生成算法*（DGA）来创建联系的域名。DGA 是一种在许多恶意软件形式中使用的算法，会定期生成大量域名，这些域名用作 C&C 服务器的投放位置。DGA 创建的庞大投放位置数量使得任何执法或取证团队几乎不可能确定这些位置并将其关闭。攻击者甚至进一步使用公钥加密来冒充黑客，因为 C&C 服务器只接受来自正确签名的控制器的命令。

每个受感染的计算机由 Sunburst 恶意软件接收一个唯一 ID。该 ID 由 MAC（硬件）地址、计算机的域名和 Windows 安装的通用唯一标识符（UUID）组成。然后该 ID 使用 MD5 哈希（即通常用于数字签名的加密算法）和其他复杂的加密方法进行加密。由于通信方式，受感染的计算机不会直接联系 C&C 服务器，而是通过正常的 DNS 流量，直到到达黑客的 DNS 服务器。有效载荷包括受感染公司的域名以及在受损计算机上找到的信息。

与 C&C 的通信还包括有关计算机上运行的任何安全软件的信息。恶意软件会检查是否存在 CrowdStrike、Carbon Black、FireEye、ESET、F-Secure 或 Microsoft Defender 工具，以及它们是处于运行、停止还是禁用状态。根据这些信息，软件随后决定是否停止攻击或部署另一个通信通道。攻击者随后根据收集到的信息决定受害者是否值得下一步：部署 Teardrop 后门木马。对于被认为不重要或风险过高的受害者，Sunburst 恶意软件被指示从网络中自行移除。

进一步的证据现在表明攻击者进行了测试运行。从 2019 年 9 月到 11 月，Orion 产品中包含黑客的更改，他们只是想看看是否可以在不被检测的情况下将恶意代码插入构建中。随着公司和政府继续承认自己是黑客攻击的受害者，更多的 revelations 将继续。一个仍然存在的谜团是黑客最初是如何获得 SolarWinds 网络访问权限的。是钓鱼活动、泄露的凭证，还是其他某种方法？

对 SolarWinds 时间线和攻击者方法的这一详细解释是网络安全第三方风险中的新篇章。与之前提到的其他事件（越南、蒙古等）一起，它显示了这些攻击者为了达到最终受害者是多么有耐心但又专注。这些漏洞利用凸显了我们在第三方软件安全和检测能力方面存在的众多差距；它们揭示了非关键软件如何被利用，以及即使是安全专家和公司也可能被黑客攻击。陷入 SolarWinds 攻击的组织的名称并非小公司，而是拥有良好纵深防御和安全实践的组织。
