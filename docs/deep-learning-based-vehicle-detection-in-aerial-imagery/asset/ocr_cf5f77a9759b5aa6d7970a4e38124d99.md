# Detection Framework Adaptation

In the context of this thesis, Faster R-CNN is applied as base detection framework. Compared to other deep learning based detection frameworks, Faster R-CNN achieves superior detection accuracy, especially for small object instances, and thus, seems most promising for the task of vehicle detection
