As conventional object detectors generally compute features for each candidate window separately, the restriction only to areas of interest is straightforward to realize, e.g., by prior filtering out of non relevant candidate windows. In the context of this thesis, a novel Search Area Reduction (SAR) module is proposed to reduce the search area within deep learning based detection frameworks such as Faster R-CNN. The extension of Faster R-CNN by the proposed SAR module is schematically illustrated in Figure 7.6. In essence, the SAR module divides the employed feature map into tiles that correspond to certain areas of the input image and predicts a confidence score of how likely a tile and consequently the respective area of the input image contains at least one object.
