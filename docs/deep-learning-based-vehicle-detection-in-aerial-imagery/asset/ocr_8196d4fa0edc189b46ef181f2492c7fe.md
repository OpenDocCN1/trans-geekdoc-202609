# Filtering Scheme

The proposed filtering scheme is straightforward as illustrated in Figure 6.11. A separate CNN network is employed to generate a semantic labeling mask, which is then used to compute the category distribution within each region proposal or detection. The characteristics of the category distribution are lastly employed to accept or reject the corresponding region proposal or detection.
