# # Table of Symbols

# ## Calligraphic Symbols

| Symbol | Description |
|---|---|
| $\mathcal{A}$ | set of ground truth annotations |
| $\mathcal{B}$ | batch |
| $\mathcal{O}$ | set of object proposals |

# ## Greek Symbols

| Symbol | Description |
|---|---|
| $\alpha$ | percentage of filters kept after pruning |
| $\beta$ | shift parameter |
| $\gamma$ | scale parameter |
| $\delta$ | weight decay |
| $\epsilon$ | small value |
| $\eta$ | learning rate |
| $\lambda$ | weighting factor |
| $\mu$ | mean |
| $\mu_B$ | mean over batch |
| $\xi$ | width multiplier |
| $\rho$ | resolution multiplier |
| $\sigma^2$ | variance |
