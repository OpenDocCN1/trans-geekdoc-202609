For the usage of PeleeNet as base network within the SSD detector, only the output of the 1 × 1 convolutional layer after the 2ⁿᵈ stack of Two-Way Dense Layers is exploited as feature map. All deeper layers are truncated from the network. In contrast to the other computation-efficient networks, weights pre-trained on PASCAL VOC and MS COCO are used for initialization¹, as no weights pre-trained on ImageNet were publicly available at that time. Each model is trained for 30,000 iterations using the Adam optimizer with a batch size of 16 and an initial learning rate of 0.001.
