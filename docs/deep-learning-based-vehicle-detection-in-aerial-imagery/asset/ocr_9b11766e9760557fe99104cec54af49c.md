Instead of computationally expensive 7 × 7 convolutions, SqueezeNet v1.1 (see Table 7.5), which is built on SqueezeNet v1.0, utilizes less expensive 3 × 3 convolutions to improve the inference speed. By performing max pooling after earlier layers, i.e., the initial convolutional layer, the 2nd and 4th Fire module, the computational costs are further reduced due to smaller input volumes for some convolutional layers. Based on SqueezeNet v1.1, Gschwend [Gsc16] proposed ZynqNet (see Table 7.6), which improves the classification accuracy.
