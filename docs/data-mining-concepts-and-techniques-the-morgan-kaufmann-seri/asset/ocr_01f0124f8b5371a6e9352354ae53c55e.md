Let the value of $p_i$ on dimension $d$ be $v(p_i, d)$. We say $p_i$ is dominated by $p_j$ if and only if for each preference dimension $d$, $v(p_j, d) \le v(p_i, d)$, and there is at least one $d$ where the equality does not hold.

+   a. Design a ranking cube (see the previous question) so that skyline queries can be processed efficiently.
