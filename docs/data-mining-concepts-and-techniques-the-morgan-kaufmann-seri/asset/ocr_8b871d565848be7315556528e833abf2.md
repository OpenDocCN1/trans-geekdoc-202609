More concretely, it will stop growing a prefix-based projected databases S|β if it is of the same size as that of the prefix-based projected database S|α and α and β have substring/superstring relationships.

This is based on a property of sequence databases, called equivalence of projected databases, stated as follows: Two projected sequence databases, S|α = S|β, α ⊑ β (i.e., α is a subsequence of β), are equivalent if and only if the total number of items in S|α is equal to the total number of items in S|β.
