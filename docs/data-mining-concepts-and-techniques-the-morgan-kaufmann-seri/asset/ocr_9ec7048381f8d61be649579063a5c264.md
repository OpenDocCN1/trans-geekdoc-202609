a zero vector, we have that A - λI is not invertible, and its determinant must be zero. To compute all the eigenvalues of A, we need to solve the roots of equation det(A - λI) = 0. Since the equation has n degrees for λ, there are n eigenvalues in total, with possible duplicates.

There are some useful relationships between eigenvalues and matrix's traces and determinants:

+   - The sum of eigenvalues equals to the trace: tr(A) = \sum_{i=1}^n \lambda_i.
+   - The product of eigenvalues equals to the determinant: det(A) = \prod_{i=1}^n \lambda_i.

When matrix A has n independent eigenvectors, it could be decomposed into

```
A = X\Lambda X^{-1},
```

where the columns of X are the n eigenvectors of A, and \Lambda is a diagonal matrix whose diagonal entries are the n eigenvalues of A. This decomposition is named as eigendecomposition. Notice the symmetric matrix always has n independent eigenvectors and could always be eigendecomposed. From A = X\Lambda X^{-1}, we have A^k = X\Lambda^k X^{-1}, which means the eigenvalues of A^k are \lambda_1^k, \cdots, \lambda_n^k. Besides, for each v \in R^n, it could be written as v = c_1 x_1 + \cdots + c_n x_n. This gives an easier way to compute A^k v:

```
A^k v = c_1 \lambda_1^k x_1 + \cdots + c_n \lambda_n^k x_n.
```

# Singular value decomposition (SVD)

Given a matrix A^{m \times n} with rank r, the SVD of A is written as

```
A = U \Sigma V^T,
```

where U \in R^{m \times n} is the orthogonal matrix containing orthonormal eigenvectors of AA^T, V \in R^{n \times n} is the orthogonal matrix containing orthonormal eigenvectors of A^T A, \Sigma \in R^{m \times n} is a matrix that satisfies \Sigma_{ii} = \sigma_i, i = 1, \cdots, r, and the other entries are all zeros. Here, we call \sigma_1, \cdots, \sigma_r singular values. The singular values are all positive and in the descending order. Notice that different from eigendecomposition, SVD is applicable for any rectangle matrix.

To compute SVD, we first perform eigendecomposition on A^T A and obtain the orthogonal eigenvectors v_1, \cdots, v_r. From the form of SVD, we know that Av_k = u_k \sigma_k, k = 1, \cdots, r. Hence u_k = \frac{Av_k}{\sigma_k}, k = 1, \cdots, r. For the last n - r columns of V, we have Av_k = 0, k = r + 1, \cdots, n. Therefore v_{r+1}, \cdots, v_n are the orthogonal basis from the nullspace of A. Similarly, u_{r+1}, \cdots, u_m are the orthogonal basis from the nullspace of A^T.

With SVD, A could be written as the sum of rank one matrices:

```
A = \sigma_1 u_1 v_1^T + \cdots + \sigma_r u_r v_r^T.
```

This provides important factors for matrix approximation. Specifically, singular values \sigma_1, \sigma_2, \cdots, \sigma_r are ordered according to its importance. The first term \sigma_1 u_1 v_1^T is the closest rank one matrix to A, which means ||A - B|| achieves the minimum value in terms of both l_2 norm and Frobenius norm only if rank one matrix B = \sigma_1 u_1 v_1^T. Furthermore, A_k = \sigma_1 u_1 v_1^T + \cdots + \sigma_k u_k v_k^T is the closest rank k approximation to A.
