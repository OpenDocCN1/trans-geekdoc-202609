# Continuous Probability Distributions

+   1. Normal Distribution: Known as the Gaussian distribution, it is characterized by its bell-shaped curve. The probability density function (PDF) is: [ f(x) = \frac{1}{\sqrt{2\pi}\sigma^2}} e^{-\frac{(x - \mu)^2}{2\sigma^2}} ] where ( \mu ) is the mean and ( \sigma ) is the standard deviation.

```
use rand_distr::{Normal, Distribution};

fn normal_distribution() {
    let normal = Normal::new(0.0, 1.0).unwrap(); // Mean 0, Standard Deviation 1
    let value: f64 = normal.sample(&mut rand::thread_rng());
    println!("Normal distribution sample: {}", value);
}

fn main() {
    normal_distribution();
}

...
```
