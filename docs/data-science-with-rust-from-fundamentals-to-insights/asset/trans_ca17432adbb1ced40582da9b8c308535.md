## 理解批处理

批处理是指一次性执行一系列非交互式作业。与实时处理不同，实时处理在数据到达时即进行处理，而批处理会在一段时间内收集数据并批量处理。这种方法特别适用于不需要即时反馈的操作，例如日终报告、大规模数据转换和归档任务。

- 1. **优势：**
- 2. **效率**：以结构化方式处理大量数据。
- 3. **资源优化**：在非高峰时段利用系统资源。
- 4. **可扩展性**：易于扩展以处理不断增加的数据量。
- 5. **挑战：**
- 6. **延迟**：由于处理的周期性，存在固有延迟。
- 7. **复杂性**：管理依赖项和调度可能非常复杂。
- 8. **错误处理**：确保在故障面前具有鲁棒性。
