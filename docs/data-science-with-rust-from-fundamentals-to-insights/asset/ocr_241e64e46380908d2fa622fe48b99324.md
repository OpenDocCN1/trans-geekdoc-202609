+   - **Manhattan Distance:** Measures the distance between two points along axes at right angles. [ d(p, q) = \sum_{i=1}^n |p_i - q_i| ]

+   - **Minkowski Distance:** A generalized distance metric that includes both Euclidean and Manhattan distances. [ d(p, q) = \left( \sum_{i=1}^n |p_i - q_i|^p \right)^{1/p} ]

Choosing the appropriate distance metric and K value significantly impacts the algorithm's performance.
