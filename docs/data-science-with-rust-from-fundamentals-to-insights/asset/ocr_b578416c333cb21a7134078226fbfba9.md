# # Law of Large Numbers

The Law of Large Numbers states that as the number of trials increases, the experimental probability will converge to the theoretical probability. To illustrate this, consider continuously flipping a coin and observing the proportion of heads.

```
```rust
use rand::Rng;

fn main() {
    let mut rng = rand::thread_rng();
    let mut count_heads = 0;
    let trials = 10000;

    for _ in 0..trials {
        if rng.gen_bool(0.5) {
            count_heads += 1;
        }
    }

    println!("Proportion of heads: {}", count_heads as f64 / trials as f64);
}
