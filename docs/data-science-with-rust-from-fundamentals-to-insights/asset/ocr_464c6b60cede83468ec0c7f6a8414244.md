fn main() {

    println!("Clusters: {:?}", clusters);
}

In this example, we define a HierarchicalClustering struct with methods to fit the model and compute distances between clusters. The fit method initializes each data point as its cluster, merges the two closest clusters iteratively, and continues until all data points are in a single cluster.
