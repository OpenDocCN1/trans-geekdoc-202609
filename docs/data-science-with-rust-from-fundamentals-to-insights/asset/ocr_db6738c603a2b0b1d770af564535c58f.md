# ## 6. Handling Overfitting and Underfitting

Overfitting occurs when a model learns the training data too well, including noise, leading to poor generalization. Underfitting happens when the model is too simple to capture the underlying patterns.

# # Techniques to Address Overfitting:

+   - **Regularization:** Penalizes large weights to prevent overfitting (e.g., L1, L2 regularization).
+   - **Dropout:** Randomly drops neurons during training to prevent co-adaptation.
+   - **Data Augmentation:** Increases the training data by adding slightly modified copies.
