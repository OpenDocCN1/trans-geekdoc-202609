+   2. **Assignment**: Assign each point (x_i) to the nearest centroid: [ c_i = \arg\min_j \|x_i - \mu_j\|^2 ]

+   3. **Update**: Recalculate the centroids: [ \mu_j = \frac{1}{|S_j|} \sum_{\{x_i \in S_j\}} x_i ] where (S_j) is the set of points assigned to cluster (j).
