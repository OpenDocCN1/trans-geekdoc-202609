# Cumulative Distribution Function (CDF)

The CDF of a random variable ( X ) gives the probability that ( X ) will take a value less than or equal to ( x ): [ F(x) = P(X \leq x ) ]

For discrete distributions, the CDF is the sum of the PMF values up to ( x ). For continuous distributions, it's the integral of the PDF up to ( x ).

# Example: Computing the CDF for a Binomial Distribution

```
'''rust fn binomial_cdf(n: u32, p: f64, k: u32) -> f64 {
(0..=k).map(|i| { let comb = (0..i).fold(1.0, |acc, j| acc * (n - j) as
f64 / (j + 1) as f64); comb * p.poww(i as i32) * (1.0 - p).poww((n - i)
as i32) }).sum() }
fn main() {
    let cdf_value = binomial_cdf(10, 0.5, 5); // CDF for 5 successes in 10 trials
    println!("Binomial CDF value: {}", cdf_value);
}
```
