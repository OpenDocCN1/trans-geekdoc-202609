# 1. Reading Data from a CSV File

```
use polars::prelude::*;

fn main() -> Result<()> {
    let df = CsvReader::from_path("data.csv")?
        .has_header(true)
        .finish()?;

    println!("{:?}", df);
    Ok(())
}
```

In this example, data is read from a CSV file. The CsvReader provides a simple interface for loading data into a DataFrame.
