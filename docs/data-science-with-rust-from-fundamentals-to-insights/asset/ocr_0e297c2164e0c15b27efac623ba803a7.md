# 3. **Output:**

+   o **Supervised Learning**: Produces explicit predictions or classifications based on the input data.

+   o **Unsupervised Learning**: Reveals hidden patterns and groupings within the data, often requiring interpretation by the analyst.

# 4. **Algorithms:**

+   o **Supervised Learning**: Includes regression, decision trees, support vector machines, and neural networks.

+   o **Unsupervised Learning**: Includes clustering algorithms (e.g., K-Means, hierarchical clustering) and dimensionality reduction techniques (e.g., PCA, t-SNE).

Supervised learning’s strength lies in prediction and classification, while unsupervised learning excels in uncovering hidden structures within data.
