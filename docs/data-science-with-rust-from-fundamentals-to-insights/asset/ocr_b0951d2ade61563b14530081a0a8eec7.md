# Performing CRUD Operations

CRUD (Create, Read, Update, Delete) operations are fundamental for interacting with any database. Let's explore these operations using Diesel in Rust.

+   1. Creating Records:

Define a NewUser struct and implement a function to insert new users:

```
```rust
#[derive(Insertable)]
#[table_name = "users"]
struct NewUser<'a> { name: &'a str, email: &'a str, }

fn create_user<'a>(conn: &PgConnection, name: &'a str, email: &'a str) -> usize {
    use crate::schema::users;

    let new_user = NewUser { name, email };

    diesel::insert_into(users::table)
    .values(&new_user)
    .execute(conn)
}
