```
# Transforming Data

Once we have the raw data, the next step is to transform it. This involves cleaning, normalizing, and enriching the data.

+   1. Cleaning the Data:

Filter out any users with invalid email addresses:

```
```rust
fn clean_data(users: Vec) -> Vec {
    users.into_iter() .filter(|user| user.email.contains("@"))
        .collect() }
```
```

+   1. Normalizing Data:

Normalize user names by converting them to lowercase:

```
```rust
fn normalize_data(users: &mut Vec) { for user in
users.iter_mut() { user.name = user.name.to_lowercase(); } }
```
