Descriptive statistics can highlight inconsistencies or outliers that need to be addressed during data cleaning.

```rust
use polars::prelude::*;

fn main() -> Result<()> {
    let df = df! {
        "Values" => &[10, 20, 20, 30, 40, 50, -999, 50]
    }?;

    // Identify and handle outliers
    let clean_df = df.filter(&df["Values"].gt_eq(0))?;
    println!("{:?}", clean_df);

    Ok(())
}
```
