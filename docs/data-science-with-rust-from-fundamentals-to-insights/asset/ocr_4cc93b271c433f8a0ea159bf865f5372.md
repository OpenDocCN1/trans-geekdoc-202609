# Writing CSV Files

Now, let's turn our attention to writing CSV files. Suppose you've performed some analysis on the stock prices and want to save the results to a new CSV file. Here's how you can do it:

```
/// use csv::WriterBuilder; use serde::Serialize; use
std::error::Error;
```

```
#[derive(Debug, Serialize)]
struct StockAnalysis {
    date: String,
    price_change: f64,
    volume: u64,
}
```

```
fn write_csv(file_path: &str, data: &[StockAnalysis]) -> Result<(), Box<dyn
Error>> {
    let mut wtr = WriterBuilder::new()
        .has_headers(true)
        .from_path(file_path)?;

    for record in data {
        wtr.serialize(record)?;
    }

    wtr.flush()?;

    Ok(())
}
```
