# Confidence Intervals

# Understanding Confidence Intervals

At the heart of confidence intervals lies the concept of repeated sampling. If we were to take multiple samples from the same population and compute a confidence interval for each sample, a certain percentage of those intervals would contain the true population parameter. This percentage is known as the confidence level, typically set at 95% or 99%.

Key Components:

+   1. Point Estimate: The central value around which the interval is constructed. Common point estimates include the sample mean or proportion.
+   2. Margin of Error: Reflects the variability of the estimate and is influenced by the sample size and the standard deviation.
+   3. Confidence Level: Indicates the proportion of times the confidence interval would contain the true parameter if we repeated the sampling process numerous times.

# Constructing Confidence Intervals

The process of constructing a confidence interval involves the following steps:

+   1. Selecting a Point Estimate: Determine the sample statistic (e.g., mean or proportion) that serves as the basis for the interval.
+   2. Choosing a Confidence Level: Common levels are 90%, 95%, and 99%, with 95% being the most widely used.
