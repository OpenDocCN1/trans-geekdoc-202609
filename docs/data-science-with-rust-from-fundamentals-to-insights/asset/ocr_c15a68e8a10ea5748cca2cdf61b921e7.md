# Interoperability with Existing Tools

Transitioning to Rust doesn’t mean abandoning your existing data science toolkit. Rust’s interoperability with Python through tools like PyO3 and Rust-FFI allows data scientists to write performance-critical sections of their code in Rust while retaining the convenience and flexibility of Python for other tasks.

For instance, you might write a computationally expensive function in Rust and call it from a Python script:

```
rust // lib.rs #[no_mangle] pub extern "C" fn expensive_computation(x: i32) -> i32 { x * 2 // Simplified example }
```

```
python # main.py import ctypes lib = ctypes.CDLL('./target/debug/libexample.so') result = lib.expensive_computation(42) print(result)
```

This symbiotic relationship allows you to leverage Rust’s performance while maintaining the productivity benefits of Python.
