# Setting the Stage with Rust Libraries

Rust's ecosystem, though still growing, offers powerful libraries for web scraping. Two primary libraries we'll focus on are reqwest for making HTTP requests and scraper for parsing and extracting data from HTML documents. Let's begin by setting up these libraries in your Rust environment.

First, ensure reqwest and scraper are added to your Cargo.toml:

```
```toml [dependencies] reqwest = { version = "0.11", features = ["blocking"] } scraper = "0.12" ```
```

# Making HTTP Requests

At the heart of web scraping lies the ability to make HTTP requests to fetch web pages. The reqwest crate simplifies this process. Here's a basic example of fetching the HTML content of a webpage:

```
```rust use reqwest::blocking::get; use std::error::Error;

fn fetch_html(url: &str) -> Result<String, Box<dyn Error>> {
    let response = get(url)?.text()?;
    Ok(response)
}

fn main() -> Result<(), Box<dyn Error>> {
    let url = "https://example.com";
    let html = fetch_html(url)?;
    println!("{}", html);
    Ok(())
}
```
