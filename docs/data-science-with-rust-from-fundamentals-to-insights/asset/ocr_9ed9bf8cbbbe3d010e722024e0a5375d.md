# Error Handling

Rust distinguishes itself with its robust error handling, primarily using the Result and Option enums.

# Using Result for Error Handling:

```
````rust use std::fs::File;

fn main() {
    let file = File::open("hello.txt");
    let file = match file {
        Ok(file) => file,
        Err(error) => panic!("Problem opening the file: {:?}", error),
    };
}
````
```

# Using Option for Nullable Values:

```
````rust fn main() { let number: Option = Some(5); match number {
Some(n) => println!("The number is: {}", n), None => println!("No number"), } }
````
```
