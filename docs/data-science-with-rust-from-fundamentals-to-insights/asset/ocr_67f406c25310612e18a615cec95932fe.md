# 1. Minimum and Maximum

Identifying the minimum and maximum values is critical for understanding the range of data.

```
use polars::prelude::*;

fn main() -> Result<()> {
    let df = df! {
        "Scores" => &[89, 72, 94, 68, 77]
    }?;

    // Minimum
    let min_value = df["Scores"].min();
    println!("Minimum: {:?}", min_value);

    // Maximum
    let max_value = df["Scores"].max();
    println!("Maximum: {:?}", max_value);

    Ok(())
}
...
```

This snippet highlights the minimum and maximum scores, crucial metrics for performance evaluation.
