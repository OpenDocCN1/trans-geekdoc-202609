# Advanced DataFrame Operations

Beyond basic operations, polars supports more advanced functionalities like joins, pivot tables, and window functions.

# 1. Joining DataFrames

```
```rust
use polars::prelude::*;

fn main() -> Result<()> {
    let df1 = df! {
        "Name" => &["Alice", "Bob"],
        "Age" => &[25, 30]
    }?;

    let df2 = df! {
        "Name" => &["Alice", "Bob"],
        "City" => &["Vancouver", "Toronto"]
    }?;

    let joined_df = df1.left_join(&df2, "Name", "Name")?;
    println!("{:?}", joined_df);
    Ok(())
}
```
```

Joins are used to combine two DataFrames based on a common column.
