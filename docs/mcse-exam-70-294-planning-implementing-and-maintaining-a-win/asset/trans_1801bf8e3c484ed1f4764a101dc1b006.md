
站点使用 Windows Server 2003 的 `Active Directory Sites and Services` 工具进行重命名。练习 6.02 将引导您完成重命名站点的步骤。

## 练习 6.02

### 重命名新站点

1. 要打开 `Active Directory Sites and Services` 工具，请单击 `Start | Control Panel | Administrative Tools`。双击 `Active Directory Sites and Services`。`Active Directory Sites and Services` 对话框如 [图 6.9](#B978193183694450012X.xhtml#f0050) 所示出现。

![图 6.9 Active Directory Sites and Services 工具](images/B978193183694450012X/f06-09-9781931836944.jpg)

图 6.9 Active Directory Sites and Services 工具

2. 在 `Active Directory Sites and Services` 控制台的左侧树窗格中突出显示 `Sites` 文件夹。展开 `Sites` 文件夹，您将看到站点显示为小型黄色办公楼图标，如 [图 6.10](#B978193183694450012X.xhtml#f0055) 所示。

![图 6.10 Sites 文件夹](images/B978193183694450012X/f06-10-9781931836944.jpg)

图 6.10 Sites 文件夹

3. 右键单击要重命名的站点并从上下文菜单中选择 `Rename` 选项，如 [图 6.11](#B978193183694450012X.xhtml#f0060) 所示。

![图 6.11 Rename 选项](images/B978193183694450012X/f06-11-9781931836944.jpg)

图 6.11 Rename 选项

4. 在左侧控制台窗格的 `Name` 框中输入站点的名称，如 [图 6.12](#B978193183694450012X.xhtml#f0065) 所示。

![图 6.12 Rename 对话框](images/B978193183694450012X/f06-12-9781931836944.jpg)

图 6.12 Rename 对话框

5. 单击 `OK`。这完成了使用 `Active Directory Sites and Services` 工具重命名站点的过程。

## 创建子网

子网与 `Active Directory` 站点关联以匹配客户端计算机。子网由一系列 IP 地址表示。`Active Directory Sites and Services` 用户界面免除了您手动提供子网名称的需要；相反，您将被提示输入网络地址。IP 版本 4 网络的子网名称示例是 `10.14.208.0/20`。此 IP 地址由两部分组成：网络地址出现在斜线之前，斜线之后是子网掩码的表示。一些常见的子网掩码及其对应的斜线表示法显示在 [表 6.1](#B978193183694450012X.xhtml#t0010) 中。斜线后面的数字表示构成 IP 地址网络部分的二进制位数（位）。255 在十进制中转换为 11111111 在二进制 8 位)，因此您可以看到 [表 6.1](#B978193183694450012X.xhtml#t0010) 中的子网掩码如何转换为相应的斜线表示法。

表 6.1

子网掩码和斜线表示法

| 子网掩码 | 斜线表示法 |
|---|---|
| `255.0.0.0` | `/8` |
| `255.255.0.0` | `/16` |
| `255.255.255.0` | `/24` |

子网使用 Windows Server 2003 的 `Active Directory Sites and Services` 工具创建。[练习 6.03](#B978193183694450012X.xhtml#b0090) 显示了创建子网所涉及的步骤。

1. 要打开 `Active Directory Sites and Services` 工具，请单击 `Start | Control Panel | Administrative Tools`，然后双击 `Active Directory Sites and Services`。`Active Directory Sites and Services` 控制台如 [图 6.13](#B978193183694450012X.xhtml#f0070) 所示出现。

![图 6.14 Sites 文件夹](images/B978193183694450012X/f06-14-9781931836944.jpg)

图 6.14 Sites 文件夹

## 将子网与站点关联

创建站点和子网后，下一步是将子网与站点关联。Active Directory 网络上的计算机使用传输控制协议/互联网协议 (`TCP/IP`) 相互通信，该协议根据其在子网中的位置分配给站点。请记住，站点由一个或多个 IP 子网组成。您通过在 `Active Directory Sites and Services` 控制台中创建子网对象来指定网络上每个站点关联的子网。将子网与站点关联使 Active Directory 网络上的计算机能够使用子网信息找到同一站点中的 `DC`，从而使身份验证流量不会跨越 `WAN` 链路。Active Directory 在复制过程中也使用子网来确定 `DC` 之间的最佳路由。

子网使用 Windows Server 2003 的 `Active Directory Sites and Services` 工具与站点关联。[练习 6.04](#B978193183694450012X.xhtml#b0095) 将引导您完成将子网与站点关联所涉及的步骤。

### 练习 6.04

#### 将子网与站点关联

1. 要打开 `Active Directory Sites and Services` 工具，请单击 `Start | Control Panel | Administrative Tools`，然后双击 `Active Directory Sites and Services`。

2. 突出显示 `Active Directory Sites and Services` 控制台左侧树窗格中存在的 `Subnet` 文件夹（参见 [图 6.19](#B978193183694450012X.xhtml#f0100)）。

![图 6.19 Subnet 文件夹](images/B978193183694450012X/f06-19-9781931836944.jpg)

图 6.19 Subnet 文件夹

3. 右键单击新创建的子网并选择 `Properties` 选项；这将打开一个 `Properties` 对话框，如 [图 6.20](#B978193183694450012X.xhtml#f0105) 所示。

![图 6.20 用于关联/更改站点的子网对话框](images/B978193183694450012X/f06-20-9781931836944.jpg)

图 6.20 用于关联/更改站点的子网对话框

4. 通过从站点下拉菜单中选择可用站点将任何站点与此子网关联，并单击 `OK`，如 [图 6.20](#B978193183694450012X.xhtml#f0105) 所示。

5. 单击 `OK`。这完成了使用 `Active Directory Sites and Services` 工具将子网与站点关联的过程。
