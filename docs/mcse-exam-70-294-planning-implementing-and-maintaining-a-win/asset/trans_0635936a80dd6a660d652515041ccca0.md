### 第 1 章 Active Directory 基础结构概述

#### 介绍目录服务

1. 公司有一名员工退休，你刚刚禁用了他的账户，以便没有人能以该用户身份登录到域。当此更改进行时，它将在目录中存储在哪里？
A. `Domain partition`
B. `Configuration partition`
C. `Schema partition`
D. `Application partition`
☑ `Domain partition` 包含有关域的信息，包括有关用户、计算机、资源以及各自相关属性的信息。
![wrong](images/wrong.png) 答案 B 不正确，因为 `Configuration partition` 存储有关 `Active Directory` 拓扑的信息，并包括网络中域、域树和林如何配置的信息。`Configuration partition` 还包括有关 DC 和 GC 位置的信息，这是 `Active Directory` 中包含的数据的子集。答案 C 不正确，因为 `Schema partition` 包含 `Active Directory` 中存在的对象类以及每个对象类的属性的信息。`Schema partition` 包含定义域中使用的对象类和属性的信息。它决定了 `Active Directory` 中可以存在哪些类型的对象，以及每个对象可以具有哪些属性。答案 D 不正确，因为 `Application partition` 用于存储特定于网络上运行的不同应用程序的数据

2. 你公司的员工由两个工会代表。管理层有一个代表管理层利益的工会，而公司其他员工则属于另一个工会。每个工会都要求从工资单中扣除会费以支付其代表费用。财务部门要求在每个用户账户中添加一个字段，以便在账户上输入代码以显示每位员工所属的工会。他们要求你创建此字段。当此新属性已添加到用户对象时，它将在目录中存储在哪里？
A. `Domain partition`
B. `Configuration partition`
C. `Schema partition`
D. `Application partition`
☑ C. `Schema partition` 存储有关对象类以及每个类的属性的信息。`Active Directory` 中的每个对象都有特定的属性，用于确定对其存储的信息。`Active Directory` 中存在的对象以及每个对象具有哪些属性是由架构决定的。`Schema partition` 包含定义域中使用的对象类和属性的信息。
![wrong](images/wrong.png) 答案 A 不正确，因为 `Domain partition` 包含有关域的信息。它存储有关对象的信息，但不用于存储有关可在对象中存储哪些信息的规则。答案 B 不正确，因为 `Configuration partition` 包含有关 `Active Directory` 拓扑的数据，并包括网络中域、域树和林如何配置的信息，以及 DC 和 GC 的位置信息。答案 D 不正确，因为 `Application partition` 存储特定于网络上运行的不同应用程序的数据。程序可以使用此分区在特定应用程序在服务器上运行时存储所需的设置。

3. 你在网络上搜索 Active Directory，以查找目录中存储的对象。在执行此搜索时，将使用什么协议？
A. `IPX/SPX`
B. `Directory Access Protocol (DAP)`
C. `Lightweight Directory Access Protocol (LDAP)`
D. `X.500`
☑ C. `Active Directory` 使用 `LDAP` 进行客户端与目录服务器之间的通信。
![wrong](images/wrong.png) 答案 A 不正确，因为 `IPX/SPX` 不是用于搜索 `Active Directory` 的协议。它是主要用于旧版 Novell NetWare 或需要与 NetWare 服务器通信的 Windows 网络的协议。答案 B 不正确，因为 `DAP` 是 `LDAP` 的完整版本。`DAP` 包含比 `LDAP` 更多的代码，并且功能太多，无法在个人计算机、瘦客户端和通过互联网通信时高效使用。答案 D 不正确，因为 `X.500` 是一个标准而不是协议。`X.500` 由国际电信联盟开发并由国际标准化组织发布，定义了目录服务。`DAP` 是 `X.500` 定义的协议之一。
