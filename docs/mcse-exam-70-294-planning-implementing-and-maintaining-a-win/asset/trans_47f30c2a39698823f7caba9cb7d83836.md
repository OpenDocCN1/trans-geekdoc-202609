
# 在现有林中创建新的域树

这通常是您安装的第二个域，如 [图 4.17](#B9781931836944500106_1.xhtml#f0090) 所示。这种安排适用于由两个不同公司部门或大型公司内的两个公司组成的林。域用作安全和管理的边界。按照 [练习 4.06](#B9781931836944500106_1.xhtml#b0035) 中的步骤，您将同时创建第一个非根顶级域，以及林中的第二棵树。请注意，会自动与林根创建新的双向传递信任。

## 练习 4.06
### 创建现有林中的新域树

1. 以本地管理员身份登录。
2. 单击 `Start | Run`。
3. 输入 `dcpromo`。
4. 单击“确定”开始 Active Directory 安装向导。
5. 在“欢迎使用 Active Directory 安装向导”窗口中，单击“下一步”。
6. 在“操作系统兼容性”窗口中，单击“下一步”。
7. 在“域控制器类型”窗口中，单击“用于新域的域控制器 | 下一步”，如 [图 4.18](#B9781931836944500106_1.xhtml#f0095) 所示。
![图 4.18 用于在现有林中创建新的域树的域控制器类型对话框](images/B9781931836944500106/f04-18-9781931836944.jpg)
图 4.18 用于在现有林中创建新的域树的域控制器类型对话框
8. 在“创建新域”窗口中，单击“现有林中的域 | 下一步”，如 [图 4.19](#B9781931836944500106_1.xhtml#f0100) 所示。
![图 4.19 用于在现有林中创建新的域树的创建新域对话框](images/B9781931836944500106/f04-19-9781931836944.jpg)
图 4.19 用于在现有林中创建新的域树的创建新域对话框
9. 在“网络凭据”窗口中，输入林根域中企业管理员或域管理员的用户名、密码和域名。单击“下一步”。
10. 在“新域树”窗口中，输入新域的完整 DNS 域名，然后单击“下一步”。
11. 在“NetBIOS 域名”窗口中，验证 NetBIOS 名称并单击“下一步”。通常默认名称是最好的选择。
12. 在“数据库和日志文件夹”窗口中，输入或浏览到您希望放置数据库和日志文件夹的位置。单击“下一步”。
13. 在“共享系统卷”窗口中，输入或浏览到您希望放置 `SYSVOL` 文件夹的位置。单击“下一步”。
14. 在“DNS 注册诊断”窗口中，配置现有 DNS 服务器使其对该树具有权威性，或单击“在此计算机上安装并配置 DNS 服务器”，并将此计算机设置为使用该 DNS 服务器作为其首选 DNS 服务器。单击“下一步”，如 [图 4.20](#B9781931836944500106_1.xhtml#f0105) 所示。
![图 4.20 用于在现有林中创建新的域树的 DNS 注册诊断对话框](images/B9781931836944500106/f04-20-9781931836944.jpg)
图 4.20 用于在现有林中创建新的域树的 DNS 注册诊断对话框
15. 在“权限”窗口中，您有两个选项：“与 Windows 2000 之前的服务器操作系统兼容的权限”和“仅与 Windows 2000 或 Windows Server 2003 操作系统兼容的权限”。选择其中一个，然后单击“下一步”。
16. 在“目录服务还原模式管理员密码”窗口中，输入并确认目录服务还原模式的密码。单击“下一步”。
17. 阅读“摘要”窗口。单击“下一步”，如 [图 4.21](#B9781931836944500106_1.xhtml#f0110) 所示。安装将继续进行数分钟。
![图 4.21 用于在现有林中创建新的域树的摘要对话框](images/B9781931836944500106/f04-21-9781931836944.jpg)
图 4.21 用于在现有林中创建新的域树的摘要对话框
18. 重启新的域控制器。
19. 验证安装是否成功。打开命令提示符并输入 `Net Share` 命令。它应报告 `Netlogon` 和 `SYSVOL` 共享的存在。要验证新域控制器的 DNS 服务定位记录是否成功创建，请执行以下步骤：
1. 单击 `Start | Administrative Tools | DNS` 启动 DNS 管理员控制台。
2. 展开服务器名称。
3. 展开正向查找区域。
4. 展开域。
5. 验证 `\_msdcs`、`\_sites`、`\_tcp` 和 `\_udp` 文件夹是否存在并且包含新域控制器的记录。这些服务定位记录对域控制器的运行至关重要。有关所需记录的更详细说明，请参阅 [表 4.7](#B9781931836944500106_2.xhtml#t0040)，有关用于查看它们的 DNS 管理员工具的视图，请参阅 [图 4.16](#B9781931836944500106_1.xhtml#f0085)。

# 在现有域中创建新的子域

这通常是您安装的第三个域，如 [图 4.22](#B9781931836944500106_1.xhtml#f0115) 所示。这种安排适用于由两个不同公司组组成的树，有时位于物理上不同的位置。由于域用作安全和管理的边界，因此有许多原因需要将子组隔离。如果某个组需要更高或更低级别的安全性，或者如果不同的管理员组需要完全控制，则子域是一个不错的选择。按照 [练习 4.07](#B9781931836944500106_1.xhtml#b0040) 中的步骤，您将在林中的任何现有树内创建第一个子域。请注意，会自动与父域创建新的双向传递信任，同时在子域和林根之间创建隐式信任。有关信任的传递性和方向性的更多信息，请参阅本章后面的“建立信任关系”部分。

![图 4.22 在现有域中创建新的子域](images/B9781931836944500106/f04-22-9781931836944.jpg)
图 4.22 在现有域中创建新的子域

## 练习 4.07
### 在现有域中创建新的子域

1. 以本地管理员身份登录。
2. 单击 `Start | Run`。
3. 输入 `dcpromo`。
4. 单击“确定”开始 Active Directory 安装向导。
5. 在“欢迎使用 Active Directory 安装向导”窗口中，单击“下一步”。
6. 在“操作系统兼容性”窗口中，单击“下一步”。
7. 在“域控制器类型”窗口中，单击“用于新域的域控制器 | 下一步”，如 [图 4.23](#B9781931836944500106_1.xhtml#f0120) 所示。
![图 4.23 用于在现有域中创建新的子域的域控制器类型对话框](images/B9781931836944500106/f04-23-9781931836944.jpg)
图 4.23 用于在现有域中创建新的子域的域控制器类型对话框
8. 在“创建新域”窗口中，单击“现有域树中的子域 | 下一步”，如 [图 4.24](#B9781931836944500106_1.xhtml#f0125) 所示。
![图 4.24 用于在现有域中创建新的子域的创建新域对话框](images/B9781931836944500106/f04-24-9781931836944.jpg)
图 4.24 用于在现有域中创建新的子域的创建新域对话框
9. 在“网络凭据”窗口中，输入林根域中的企业管理员，或父域中的域管理员的用户名、密码和域名，然后单击“下一步”。
10. 在“子域安装”窗口中，验证父域并输入新子域的名称。单击“下一步”，如 [图 4.25](#B9781931836944500106_1.xhtml#f0130) 所示。
![图 4.25 用于在现有域中创建新的子域的子域安装对话框](images/B9781931836944500106/f04-25-9781931836944.jpg)
