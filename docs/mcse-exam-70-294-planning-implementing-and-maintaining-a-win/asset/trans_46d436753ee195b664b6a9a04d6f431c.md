
## ![u09-01-9781931836944](images/B9781931836944500155/u09-01-9781931836944.jpg)实施组策略

现在您已经了解如何评估组策略对目录的影响，是时候开始创建策略对象并将策略应用于环境了。在本节中，您将了解可以在何处创建 GPO 以及用于修改和管理的工具。

### 组策略对象编辑器 MMC

组策略对象编辑器是 MMC 的一个管理单元。由于组策略可以在多个位置应用，打开组策略对象编辑器的方式取决于您希望应用组策略的位置。

在 MMC 中，您可以从“添加/删除管理单元”窗口中选择组策略对象编辑器管理单元。当从独立管理单元列表中选择组策略对象编辑器时，组策略向导将打开，允许您选择要处理的组策略范围。单击此向导中的“浏览”按钮将打开“浏览组策略对象”窗口，如 [图 9.15](#B9781931836944500155.xhtml#f0080) 所示。窗口中的前三个选项卡允许您搜索特定类型的 GPO：域/OU、站点和计算机。第四个选项卡，在 [图 9.15](#B9781931836944500155.xhtml#f0080) 中选中，显示域中所有策略对象的列表，而不考虑位置。本地计算机策略对象不会在此列表中显示，因为它们存储在计算机上，而不是域中。

![u09-02-9781931836944](images/B9781931836944500155/u09-02-9781931836944.jpg)注意

本地计算机策略是组策略向导中的默认值。要访问它，只需在向导的第一页单击“完成”，而不是单击“浏览”按钮。

要编辑 Active Directory 中存储的一个现有 GPO，请从其中一个选项卡中选择 GPO 并单击“确定”。这将带您返回组策略向导。当您在向导中单击“完成”时，组策略对象编辑器将在 MMC 中打开，您可以开始编辑 GPO。

### 创建、配置和管理 GPO

在 MMC 中加载组策略对象编辑器管理单元将允许您编辑网络中现有的策略。当域首次创建时，会创建三个默认策略：

- 默认站点策略
- 默认域策略
- 默认域控制器策略

您可能希望创建新策略并将其与目录中的特定区域关联。

#### 创建和配置 GPO

在目录中创建新的 GPO 有两种方法。您已经知道如何将组策略对象编辑器管理单元加载到 MMC 中，因此让我们看看如何从组策略向导创建新的 GPO。

在 [图 9.15](#B9781931836944500155.xhtml#f0080) 中，您看到了单击组策略向导中的“浏览”按钮时打开的“浏览组策略对象”窗口。在“查看位置”下拉菜单旁边，您会找到“创建新的组策略对象”按钮。单击此按钮时，将在“查看位置”菜单中选择的范围内创建新的 GPO。在此范围内创建 GPO 将自动将对象链接到在范围内选定的容器。

另一种打开 GPO 编辑器并创建新 GPO 的方法是使用 Active Directory 站点和服务或 Active Directory 用户和组工具。右键单击要创建 GPO 的容器列表中的对象，然后选择“属性”。然后，在属性窗口中选择“组策略”选项卡，以查看已链接到容器的策略，或为容器创建新对象。[图 9.16](#B9781931836944500155.xhtml#f0085) 显示了 IT 管理容器的“组策略”选项卡。在此示例中，只有一个对象与此容器关联。要创建和编辑新的 GPO，请单击“新建”按钮，为策略命名，然后单击“编辑”以打开新 GPO 的组策略对象编辑器。

#### 为 GPO 命名

目录中创建的所有 GPO 都应具有唯一名称。尽管每个 GPO 都与特定容器关联，并且可能与树中另一个对象的名称相同，但在排除故障时，如果每个 GPO 名称都是唯一的，将会少很多混淆。GPO 名称可以包含字母、数字和特殊字符，但名称不能超过 255 个字符。任何超过 255 个字符的 GPO 名称都将被自动截断为 255 个字符的最大值。

关于如何命名每个 GPO 没有其他具体规则。与您应将目录中每个对象的名称与其功能或用途相匹配的方式相同，您也可以在命名 GPO 时考虑相同的方法。如果您有一组策略会影响目录中的单个容器，例如 OU，您可以在 GPO 名称中包含 OU 的名称。如果 GPO 中包含的策略将链接到目录中的多个容器，您可以根据策略的设计用途为 GPO 命名。

#### 管理 GPO

从容器属性窗口的“组策略”选项卡，您可以对与容器关联的 GPO 执行许多功能。我们已经介绍了如何从界面创建和编辑新的 GPO。现在让我们看看从此界面管理 GPO 的其他方法。

[图 9.17](#B9781931836944500155.xhtml#f0090) 显示了 My Corp 域根的“组策略”选项卡。Active Directory 中在此容器中存储了三个 GPO：默认域策略、文件夹重定向策略和管理员工具策略。根据图中显示的信息，默认域策略和文件夹重定向策略对象将在此域内登录的对象中处理。管理员工具策略在此级别不会与其他两个 GPO 一起处理，因为它在此级别已被禁用，如策略对象旁“已禁用”列下的复选标记所示。我们还可以看到，没有任何 GPO 被标记为“无覆盖”。

![图 9.17 管理根域的组策略](images/B9781931836944500155/f09-17-9781931836944.jpg)

图 9.17 管理根域的组策略

“无覆盖”和“已禁用”设置可以在两个位置设置。单击“选项”按钮将为所选 GPO 打开一个选项窗口。选项窗口，如 [图 9.18](#B9781931836944500155.xhtml#f0095) 所示，允许您为对象设置“无覆盖”和“已禁用”设置。此外，您可以通过右键单击列表中的 GPO 并在弹出菜单中选择“无覆盖”或“已禁用”条目来设置这两个选项。
