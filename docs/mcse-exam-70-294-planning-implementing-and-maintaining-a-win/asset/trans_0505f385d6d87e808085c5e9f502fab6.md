
## 控制级别

此选项按钮决定其他人如何使用远程控制与用户的会话。选项包括查看用户会话，仅允许其他人查看用户正在进行的操作，以及与会话交互，允许另一用户接管会话并执行任务，就好像他或她坐在发起会话的用户的计算机前一样。

### 配置文件路径

此文本框指定应与终端服务一起使用的用户配置文件的路径。如果未指定路径，则使用配置文件选项卡中的设置。

### 终端服务主文件夹

此文本框允许您指定在终端服务会话期间应使用的用户主目录的位置。与配置文件选项卡一样，本节提供两个选项。本地路径字段用于指定终端服务计算机上位置的本地路径。连接下拉框允许您为会话中可用的映射驱动器指定驱动器号，以及主目录网络位置的 UNC 路径。如果未指定主文件夹，则使用配置文件选项卡中的设置。

### 允许登录到终端服务器

此复选框用于启用用户建立终端服务会话。默认情况下处于启用状态。

## 与安全相关的选项卡

通过用户对象的属性可以获得多个选项卡，用于控制与帐户关联的安全设置。这些选项卡为已发布证书、拨入、安全性 和 成员身份。它们共同允许您管理与访问控制和身份验证相关的问题。

### 已发布证书选项卡

已发布证书选项卡提供帐户使用的证书列表，并允许您添加其他证书。如图所示 [图 2.21](#B9781931836944500088.xhtml#f0110)，该选项卡允许您查看为用户帐户发布的任何 X.509 证书，并包括说明其颁发者、颁发对象、证书的预期用途及其到期日期的字段。 “从存储区添加”按钮可用于从计算机的本地证书存储区向列表中添加其他证书。 “从文件添加”按钮也可用于从文件添加证书。如果不再需要证书，可以选择不再希望应用于帐户的证书并单击“删除”按钮。最后，“复制到文件”按钮将把列表中选中的证书导出到文件。

### 拨入选项卡

拨入选项卡允许您配置在用户尝试使用拨号或 VPN 连接远程连接到网络时使用的设置。当用户拨入 Windows Server 2003 远程访问服务器或尝试使用 VPN 连接时应用这些设置。如图所示 [图 2.22](#B9781931836944500088.xhtml#f0115)，该选项卡分为多个包含多个选项的部分，包括：

![图 2.22 拨入选项卡](images/B9781931836944500088/f02-22-9781931836944.jpg)

图 2.22 拨入选项卡

#### 远程访问权限（拨入或 VPN）

此选项按钮指定用户是否可以通过拨号或 VPN 连接连接到网络。本节中的选项包括允许访问，启用拨入或 VPN 远程访问；拒绝访问，禁止拨入或 VPN 远程访问；以及通过远程访问策略控制访问，这是默认选项，指定使用远程访问策略控制远程访问权限。

#### 验证呼叫者 ID

此复选框允许您指定用户必须从其拨打电话才能建立成功连接的电话号码。它需要能够检测用户拨打电话号码的硬件。

#### 回叫选项

本节中的配置设置有不回叫、由呼叫者设置（仅限路由和远程访问服务）和始终回叫到。不回叫是默认选项。它允许用户远程连接且不使用回叫。当设置此选项时，用户将支付任何长途费用。由呼叫者设置（仅限路由和远程访问服务）允许呼叫者指定服务器将回叫的电话号码。当建立远程连接时，会提示用户输入用户名和密码。如果身份验证成功，则会检查该选项卡上的设置，并提示用户输入回叫电话号码。服务器随后断开连接并在该号码回叫用户。这允许公司支付任何长途费用，通常会节省成本。始终回叫到是最后一个选项。这是一个安全选项，而不是节省成本选项，强制服务器在预配置的电话号码回叫用户。由于此设置要求用户位于该电话号码处，因此未经授权的用户尝试远程连接的风险降低。

#### 分配静态 IP 地址

此复选框在用户远程连接时为用户分配特定的 IP 地址。

#### 应用静态路由

此复选框在连接时在路由表中放置额外的路由。

#### 静态路由

此按钮用于定义在连接时将放置在路由表中的额外路由。

### 安全选项卡

正如我们在 [第 1 章](#B9781931836944500076.xhtml) 所见，安全选项卡（[图 2.23](#B9781931836944500088.xhtml#f0120)）用于配置其他用户和组对对象的权限。该选项卡由两个窗格组成。顶部窗格列出已添加到帐户 DACL 的用户和组。它还允许您向 DACL 添加或删除用户和组。在底部窗格中，您可以通过在“允许”或“拒绝”列中选中复选框来启用或禁用特定权限。还可以通过单击“高级”按钮为对象设置特殊权限，该按钮会显示一个对话框（见 [图 2.24](#B9781931836944500088.xhtml#f0125)），可在其中应用额外的权限。

![图 2.23 安全选项卡](images/B9781931836944500088/f02-23-9781931836944.jpg)

图 2.23 安全选项卡

![图 2.24 特殊权限对话框](images/B9781931836944500088/f02-24-9781931836944.jpg)

图 2.24 特殊权限对话框

如 [图 2.24](#B9781931836944500088.xhtml#f0125) 所示，通过安全选项卡的“高级”按钮访问的特殊权限对话框允许您配置高级设置并向帐户应用额外权限。如该对话框所示，权限选项卡还提供一个标记为允许从父级继承的权限传播到此对象和所有子对象的选项。当选中此复选框时，应用于父对象（在本例中为 OU）的任何权限也将应用于此帐户。如果取消选中此复选框，则在更高级别应用的任何权限都不会应用，并且对象仅具有为其显式设置的权限。

### 成员身份选项卡

如 [图 2.25](#B9781931836944500088.xhtml#f0130) 所示，该选项卡提供用户的组成员身份列表。通过单击“添加”按钮，将出现一个对话框，其中列出用户可以成为成员的可用组。从“成员身份”选项卡上的列表中选择一个组并单击“删除”按钮将把该用户从组的成员身份中删除。
