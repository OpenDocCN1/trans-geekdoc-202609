
## 分发组
分发组与安全组不同，主要不用于访问控制，尽管它们可以在应用层 ACL 中使用。分发组仅设计用于电子邮件应用程序。你可以将分发组转换为安全组（或反之），如果功能级别为 Windows 2000 原生或更高。你必须是域管理员或企业管理员，或帐户操作员组成员（或拥有相应的委派权限）才能转换组。更改组类型非常简单，只需在 Active Directory 用户和计算机 中右键单击该组，单击属性，然后在常规选项卡上单击所需的组类型即可。

## 域树
域树可以被视为由一个或多个域组成的 DNS 命名空间。如果计划创建具有不连续命名空间的林，则必须创建多个树。回顾 [图 4.1](#B9781931836944500106_1.xhtml#f0010)，你会看到该林中有两棵树，[Cats.com](http://www.Cats.com) 和 [Dogs.com](http://www.Dogs.com)。每棵树都有连续的命名空间，因为每个层次结构中的域都与其所在树中上下域直接相关。该林具有不连续的命名空间，因为它包含两个不相关的顶级域。

## 林和域功能级别
功能级别是 Microsoft 用于在 Active Directory 中移除过时向后兼容性的机制。这是一项有助于提高性能和安全性的功能。在 Windows 2000 中，每个域有两个功能级别（称为“模式”），即原生模式和混合模式，而林只有一个功能级别。在 Windows Server 2003 中，域和林中各有另外两个级别需要考虑。要启用所有 Windows Server 2003 林和域范围内的功能，所有 DC 必须运行 Windows Server 2003，并且功能级别必须设置为 Windows Server 2003。[表 4.2](#B9781931836944500106_1.xhtml#t0015) 总结了各级别、各级别支持的 DC 以及每个级别的主要用途。

### 域功能
在考虑提高域功能级别时，请记住新功能只会影响被提高的域。可用的四个功能级别为：

■ Windows 2000 混合

■ Windows 2000 原生

■ Windows Server 2003 临时

■ Windows Server 2003

一旦域功能级别被提高，就无法向域添加先前版本的 DC。在 Windows Server 2003 域功能级别的情况下，提高功能后无法将 Windows 2000 服务器提升为 DC。[表 4.2](#B9781931836944500106_1.xhtml#t0015) 总结了各级别、各级别支持的 DC 以及每个级别的主要用途。请参阅 [表 4.3](#B9781931836944500106_1.xhtml#t0020) 以了解当前 Windows 2000 和新的 Windows Server 2003 域功能级别的能力总结。

#### Windows 2000 混合域功能级别
Windows 2000 混合域功能级别主要设计用于在升级过程中支持混合环境。通常这适用于从 Windows NT 到 Windows 2000 的过渡，尽管它也是新创建的 Windows Server 2003 域的默认模式。其特点是安全性功能和默认值降低，以及 Active Directory 可能达到的最高兼容性级别。

■ 支持所有 Windows DC。

■ 此模式不支持的 Active Directory 域功能：

■ 组嵌套

■ 通用组

■ SIDHistory

■ 在安全组和分发组之间转换组

■ 域控制器重命名

■ 登录时间戳属性更新并复制

■ InetOrgPerson 对象类上的用户密码支持

■ 约束委派

■ 用户和计算机容器重定向

■ 可以提升到 Windows 2000 原生模式或直接提升到 Windows Server 2003 域级别。

■ 永远无法降低，因为不存在更低的域功能级别。

在默认级别的 Windows 2000 混合功能级别中，可以存在 Windows 2000 及更高版本的 DC，以及 Windows NT 备份域控制器（BDC）。新创建的 Windows Server 2003 域始终从此级别开始。Windows NT 主域控制器（PDC）在 Active Directory 的任何版本中都不存在。

#### Windows 2000 原生域功能级别
Windows 2000 原生域功能级别主要用于支持从 Windows 2000 升级到 Server 2003。通常这适用于现有的 Active Directory 部署，因为混合和临时模式支持从 Windows NT 升级。其特点是更好的安全功能和默认值，以及平均兼容性级别。

■ 不支持 Microsoft Windows NT 4.0 DC。

■ 此模式不支持的 Active Directory 域功能：

■ 域控制器重命名

■ 登录时间戳属性更新并复制

■ InetOrgPerson 对象类上的用户密码支持

■ 约束委派

■ 用户和计算机容器重定向

■ 可以提升到 Windows Server 2003 域级别。

■ 永远无法降回 Windows 2000 混合模式。
