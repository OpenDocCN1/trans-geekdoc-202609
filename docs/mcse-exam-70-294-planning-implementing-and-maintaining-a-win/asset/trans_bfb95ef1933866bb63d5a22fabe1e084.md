
# Windows Server 2003 中的身份验证

任何完善的安全模型都需要解决以下三个主题：身份验证、授权和记账（或审计）。身份验证处理的是一个人的身份，授权围绕已验证用户被允许执行的操作，而记账/审计则关注跟踪谁对文件、服务或其他资源执行了什么操作。Windows Server 2003 涵盖了该安全模型的全部三个方面，首先从本章讨论的用户身份验证策略开始。
