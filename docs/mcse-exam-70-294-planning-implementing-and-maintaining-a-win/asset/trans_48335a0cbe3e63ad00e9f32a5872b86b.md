
# Active Directory 组属性和计算机账户

## Adding Members

通过单击 `Add` 按钮，会显示 [图 2.29](#B9781931836944500088.xhtml#f0150) 所示的对话框。在本对话框中，您可以搜索要添加到“成员”列表中的对象。通过单击 `Object Types` 按钮，将出现一个对话框，允许您指定要查找的对象类型。在该对话框中，您可以单击复选框以指定是否搜索联系人、计算机、组、用户或其他对象。为了将搜索限制为仅从目录结构中的特定点开始，您可以单击 `Locations` 按钮打开一个显示目录树的对话框，在其中选择开始搜索的点。最后，`Enter the object names to select` 是输入对象名称的位置。单击 `OK` 后，Active Directory 将使用这些参数查找要添加到“成员身份”列表中的对象。

## Member Of Tab

`Member Of` 选项卡，如 [图 2.30](#B9781931836944500088.xhtml#f0155) 所示，用于将该组添加到 Active Directory 中其他现有组。此选项卡提供一个字段，列出该组所属的所有组。要将该组添加到其他组，请单击 `Add` 按钮打开一个对话框，在其中可以输入希望该组成为其成员的组的名称。单击 `OK` 后，组的名称将被添加到 `Member Of` 选项卡上的列表中。要将该组从另一个组的成员身份中移除，请从列表中选择该组，然后单击 `Remove` 按钮。

![图 2.30 组属性中的“成员身份”选项卡](images/B9781931836944500088/f02-30-9781931836944.jpg)

图 2.30 组属性中的“成员身份”选项卡

## Managed By Tab

`Managed By` 选项卡用于指定负责管理该组的账户。这使得用户可以轻松确定需要联系谁以请求加入该组，以及如何建立联系。选中 `Manager can update membership list` 复选框还允许此选项卡上列出的账户添加和删除组成员。要指定管理员，请单击 `Change` 按钮并指定账户。添加后，它将显示在此选项卡上的 `Name` 字段中。然后可以通过单击 `Properties` 按钮查看此账户的属性；但是，此账户的许多常用查看元素将自动显示在选项卡上。如 [图 2.31](#B9781931836944500088.xhtml#f0160) 所示，办公室、街道、城市、省/州、国家/地区、电话号码和传真号码等信息将出现。要将此账户从管理角色中移除，请单击 `Clear` 按钮。

## Object Tab

要查看有关组的信息，您可以使用 `Object` 选项卡。如 [图 2.32](#B9781931836944500088.xhtml#f0165) 所示，此选项卡允许您查看有关此 Active Directory 对象的详细信息。`Canonical name of object` 字段显示组的规范名称，而其下方的字段提供其他无法通过选项卡修改的数据。`Object class` 字段告知您这是一个组，其下方的信息说明了创建时间和最后修改时间。其下方的 `Update Sequence Numbers (USNs)` 字段显示此对象的原始和当前更新序列号，这些序列号由复制使用，以确保所有 DC 都有对象信息的更新副本。

![图 2.32 组属性的“对象”选项卡](images/B9781931836944500088/f02-32-9781931836944.jpg)

图 2.32 组属性的“对象”选项卡

`USNs` 是复制的重要组成部分，用于指示对象发生了更改。当账户发生更改时，其 `USN` 会递增以指示发生了更改。

## Security Tab

`Security` 选项卡用于配置其他账户对该组的权限。如 [图 2.33](#B9781931836944500088.xhtml#f0170) 所示，此选项卡的上部窗格列出具有账户权限的用户和组，而下部窗格显示在上部窗格中选定的账户的权限。可以通过单击 `Add` 按钮为新账户授予访问权限。一旦账户被添加到上部窗格并被选中，您可以通过在“允许”或“拒绝”列中选择复选框来启用或禁用特定权限。还可以通过单击 `Advanced` 按钮为对象设置特殊权限。要删除一个账户，请在上部窗格中选择该账户，然后单击 `Remove` 按钮。

## Exercise 2.03 Creating and Modifying Group Accounts

练习 2.03

创建和修改组账户

1. 通过单击选择 `Start | Administrative Tools | Active Directory Users and Computers` 打开 Active Directory 用户和计算机。
2. 当 Active Directory 用户和计算机打开时，展开控制台树，以便可以看到您的域及其中的容器。
3. 从控制台树中选择 TestOU OU。从“操作”菜单中选择 `New | Group`。
4. 当“新建对象 - 组”对话框出现时，在 `Group name` 文本框中输入 Accounting Users。
5. 编辑 `Group name (pre-Windows 2000)` 文本框，使其包含值 Accounting。
6. 在组作用域下选择 `Global` 选项。
7. 在组类型下选择 `Security` 选项。
8. 单击 `OK` 创建组。
9. 右键单击新创建的 Accounting Users 组，并从上下文菜单中选择属性。
10. 在 `General` 选项卡上，单击 `Description` 字段，然后输入 Group account for users in the Accounting department。
11. 在 `Members` 选项卡上，单击 `Add` 按钮。
12. 当 `Select Users, Contacts, Computers, or Groups` 对话框出现时，在 `Enter the object names to select` 文本框中输入 John Public; Jane Doe。这些是在 [练习 2.02](#B9781931836944500088.xhtml#b0075) 中创建的两个用户，以分号分隔。
13. 单击 `OK` 添加这些用户。当“成员”选项卡再次出现时，这两个用户应现在出现在“成员”列表中。
14. 在 `Member Of` 选项卡上，单击 `Add` 按钮。
15. 当 `Select Groups` 对话框出现时，在 `Enter the object names to select` 文本框中输入 Backup Operators。
16. 单击 `OK` 使该组成为 Backup Operators 组的成员。
17. 单击 `OK` 确认这些更改并退出组属性对话框。

## Working with Active Directory Computer Accounts

计算机账户是存储在 Active Directory 中并用于唯一标识域中计算机的对象。借助计算机账户，计算机上的数据存储在 Active Directory 中，使您能够查看有关计算机的信息并使用该账户设置资源权限、安装应用程序以及执行与网络可用性相关的其他操作。

## Creating Computer Accounts

计算机账户可以在 `Computers` 容器或 Active Directory 中创建的 OU 中创建。要创建新的计算机账户，您需要与创建用户和组账户时相同的权限。只有 `Administrators` 组、`Account Operators` 组、`Domain Admins` 组、`Enterprise Admins` 组成员，或已被授予授权的用户或组才能创建新账户。如果用户被授予了 `Add workstations to a domain` 权限，则他或她可以在域中创建最多 10 个计算机账户。
