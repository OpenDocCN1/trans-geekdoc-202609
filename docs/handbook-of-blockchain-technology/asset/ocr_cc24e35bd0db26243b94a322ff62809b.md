# 11.3.2  BRI “Standard Version”

The default BRI “Standard Version” provides users with rankings and results reflecting equal indicator weighting. This version is accessible for free and is expected to satisfy the needs of a significant number of interested stakeholders within the public and private sectors, such as blockchain startups and policymakers.

Upon collection of the numerical values for each indicator, a score per country is conducted by the following four computational steps:

+   1. **Data Normalization**
+   
+      All non-normalized values are normalized with respect to the population of each country. Such values are derived from non-index sources such as Bitcoin/Ethereum Nodes and Bitcoin ATMs per country. All values are then normalized to a max-based scheme [0, 1] interval.

+   2. **Benchmark Level – The Ideal Country**
+   
+      The objective of the scoring mechanism is to fairly calculate the country scores based on an accurate benchmark target index. The concept of an “Ideal Country” is introduced to facilitate this cause. The “Ideal Country” is a non-existent country that exhibits the highest scoring values with regard to the considered indicators.

+   3. **Similarity between the Ideal Country and each Examined Country**
+   
+      The computation of similarities between each country and the Ideal Country is implemented by vectoring the indicators’ values and calculating the cosine similarity between the corresponding vectors. The cosine similarity is computed using the following formula to give the BRI Score for each country:

$$\mathrm{similarity}(A,B)=\frac{A\cdot B}{\lVert A\rVert\lVert B\rVert}$$

+   4. **Country Rankings**
+   
+      Countries with BRI scores are expected to be close to the concept of the Ideal Country, as they reflect the similarity of the respective country with the best possible indicator values.

A significant flaw of certain scientific country-based indexes is that complete data sets are unable to be gathered for the majority of countries worldwide. This may lead to insufficient information communicated to stakeholders and affect their decision-making. The BRI develops an additional step so that a fair score is calculated for all countries with incomplete datasets (missing indicator[s]). To achieve this in computational terms, the total number of indicators missing is considered when applying the above formula to derive the country’s BRI score.
