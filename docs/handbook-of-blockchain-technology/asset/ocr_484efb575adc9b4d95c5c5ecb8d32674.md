The extraction and analysis of relevant literature screened to be included in the review was leveraged using the capabilities offered by AI, specifically that of GPT4. The screening process was limited to manual methods to determine the 78 remaining publications used in this research. Through this screening process, the narrowing of research ensured that the studies included for data extraction would provide the most relevant data possible.

Using standard data extraction algorithms provided by GPT4, 78 studies were then analyzed by the new technology. Firstly, each of the direct links to the research publications was recorded and manually databased to standardize the AI-extraction process. Once the links to these studies were listed, the manual validation of each link occurred. This confirmed that each link would directly lead the AI programs to the source material.

With the recent developments of GPT4, plug-ins and real-time web surfing are within the AI’s abilities. The plug-ins utilized for the data extraction process are as follows: Prompt Perfect, AskYourPDF, ChatWithPDF, Link Reader, and ScholarAI. The complementation of these applications allowed for GPT4 to individually access the material provided with each link and determine the relevant information in a collaborative process with us.

Through GPT4, a specific prompt would be entered into the message bar that requested specific information from a given article. Based on the title and abstract of these articles, which were previously databased, an informed prompt could be directed at obtaining an array of data relating to the subject material. Once a prompt is entered, GPT4 communicates with Prompt Perfect to ensure that there is a consensus on what is being asked of the technology. This ensures that the prompt will request the preferred information.

Once a link was inserted within this prompt, GPT4 would enlist Link Reader and Scholar AI applications to open the link and process any steps towards accessing the direct information. From here, AskYourPDF and ChatWithPDF would examine and process the source material, targeting information surrounding the keywords prompted. The AI then collaborates with the operator to ensure the data extracted is relevant to the subject matter. This process was repeated for each of the 78 publications, in which the AI would project all the relevant data from each for use in this study. This information is then subjected to the manual databasing process, in which the study title, citation, link, and data extraction are all recorded.

Following this process, the information presented by the AI is manually reviewed and categorized according to the subject matter. Based on the presented data, it was determined that the use of cryptocurrency and NFTs could be categorized into seven overarching aspects, which are further examined in the results of this SLR.
