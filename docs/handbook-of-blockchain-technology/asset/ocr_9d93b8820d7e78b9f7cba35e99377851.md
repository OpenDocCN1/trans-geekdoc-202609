The decentralized web, often referred to as Web 3.0, is a vision for the internet that aims to make it more open, secure, and user-centric. Unlike the current web (Web 2.0), where data and control are centralized in the hands of a few key players, the decentralized web aims to distribute data and control across many nodes, giving users more control over their own data and online experiences. Blockchain is a key technology for Web 3.0, as it provides a distributed ledger that can store and verify transactions and records without the need for a central authority or intermediary. It enables trustless and transparent interactions among users and entities, as well as the creation of digital assets such as cryptocurrencies, Non-Fungible Tokens (NFTs), and smart contracts (SCs) (Madine et al., 2022). Blockchain also supports the development of decentralized applications (dapps) and decentralized autonomous organizations (DAOs), which are web applications and entities that run on a network of nodes without relying on centralized servers or platforms (Papangelou et al., 2023; Santana et al., 2022). To define and understand how these technologies are used in what we know as the metaverse, we must first explore the string of development in which they emerged.

The convergence of decentralization and peer-to-peer transactions that blockchain embodies, along with a fusion of other transformative technologies, has been implemented into augmented reality (AR) applications to form the creation of the metaverse (Themistocleous et al., 2022). The metaverse can be described as a multi-technology convergence, where various technologies and disciplines come together to create a unified virtual space. It combines elements of virtual reality (VR), AR, artificial intelligence (AI), blockchain, internet of things (IoT), and other emerging technologies. Each of these components plays a crucial role in shaping the metaverse, and their details are described in further detail below (Ning et al., 2023). This convergence enables immersive and interactive experiences, seamless communication and collaboration, and the integration of physical and digital realms. The metaverse leverages these technologies to create a dynamic and interconnected environment where users can interact, explore, and create new experiences. It represents a fusion of technologies that blur the boundaries between the physical and digital worlds, offering vast possibilities for social, economic, and educational interactions (Far et al., 2023).
