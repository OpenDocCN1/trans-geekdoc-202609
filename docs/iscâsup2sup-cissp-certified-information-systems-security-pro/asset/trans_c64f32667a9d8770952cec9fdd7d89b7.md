

# 拆分知识

*拆分知识*将职责分离和双人控制的概念结合到一个解决方案中。基本思想是执行某项操作所需的信息或特权在两个或多个用户之间进行划分。这确保了没有任何单个人拥有足够的特权来危害环境的安全。

## 岗位轮换

通过使用*岗位轮换*，可以进一步控制和限制特权能力。岗位轮换（有时称为职责轮换）简单来说就是员工在不同岗位间轮换，或者至少将部分工作职责轮换给不同的员工。将岗位轮换作为一种安全控制手段，可以提供同行评审、减少欺诈，并实现交叉培训。交叉培训有助于使环境不再依赖任何单一的个人。

岗位轮换既可以起到威慑作用，也可以作为一种检测机制。如果员工知道未来某个时候会有其他人接管他们的工作职责，他们就不太可能参与欺诈活动。如果他们无论如何还是选择这样做，稍后接管工作职责的人很有可能会发现欺诈行为。

## 强制休假

许多组织要求员工以一周或两周为增量进行*强制休假*。这提供了一种同行评审的形式，并有助于检测欺诈和串通。该政策确保另一名员工接管个人的工作职责至少一周。如果某员工涉及欺诈，接管职责的人很有可能会发现它。

正如岗位轮换政策一样，强制休假既可以起到威慑作用，也可以作为一种检测机制。即使其他人只接管一个人的职责一两周，这通常足以发现异常情况。

## 特权账户管理

特权账户管理确保人员拥有的特权不超过其所需，且不会滥用这些特权。特权操作是指需要特殊访问权限或提升的权利和许可来执行许多管理和敏感工作任务的活动。这些任务的示例包括创建新用户账户、向路由表添加新路由、更改防火墙的配置，以及访问系统日志和审计文件。使用通用的安全实践（如最小权限原则）可确保只有少数人拥有这些特殊特权。监控可确保被授予这些特权的用户不会滥用它们。

被授予提升权限的账户通常被称为特权实体，它们拥有普通用户无法访问的特殊、更高阶的能力。如果被滥用，这些提升的权利和许可可能会对组织资产的机密性、完整性或可用性造成重大危害。因此，监控特权实体及其访问行为非常重要。

在大多数情况下，这些提升的特权仅限于管理员和某些系统操作员。在此背景下，系统操作员是指需要额外特权来执行特定工作职能的用户。普通用户（或普通系统操作员）只需要最基本的特权来完成工作。

担任这些特权角色的员工通常是受信任的员工。然而，员工从受信任员工转变为不满员工或恶意内部人员的原因有很多。导致受信任员工行为改变的原因可能很简单，比如奖金低于预期、负面的绩效评估，或者仅仅是对另一名员工的个人恩怨。然而，通过监控特殊特权的使用，组织可以威慑员工滥用特权，并在受信任员工确实滥用时检测到该行为。

一般来说，任何类型的管理员账户都具有提升的特权，应当受到监控。也可以在不给予用户完全管理访问权限的情况下授予其提升的特权。考虑到这一点，当用户拥有特定的提升特权时，监控用户活动也很重要。以下列表包含一些需要监控的特权操作示例。

*   访问审计日志
*   更改系统时间
*   配置接口
*   管理用户账户
*   控制系统重启
*   控制通信路径
*   备份和恢复系统
*   运行脚本/任务自动化工具
*   配置安全机制控制
*   使用操作系统控制命令
*   使用数据库恢复工具和日志文件

有许多自动化工具可用于监控这些活动。当管理员或特权操作员执行其中一项活动时，工具可以记录事件并发送警报。此外，访问审查审计可以检测这些特权的滥用行为。

## 管理信息生命周期

第 5 章“保护资产安全”讨论了多种保护数据的方法。当然，并非所有数据都值得同等级别的保护。然而，组织会定义数据分类，并根据其分类确定保护数据的方法。组织定义数据分类，并通常将其发布在安全策略中。政府常用的一些数据分类包括绝密、机密、秘密和非密。民用分类包括机密（或专有）、私密、敏感和公开。

安全控制在整个生命周期中保护信息。然而，没有一致的标准来识别数据生命周期的每个阶段或步骤。有人将其简化为简单的“从摇篮到坟墓”，即从创建时到销毁时。以下列表包含用于识别数据生命周期中不同阶段的一些术语：

### 创建或捕获

数据可以由用户创建，例如用户创建文件时。系统也可以创建数据，例如创建日志条目的监控系统。数据也可以被捕获，例如用户从互联网下载文件且流量通过边界防火墙时。

### 分类

确保数据尽快被分类非常重要。组织对数据的分类方式不同，但最重要的考虑因素是确保敏感数据被识别并根据其分类得到适当处理。第 5 章讨论了用于定义敏感数据和定义数据分类的不同方法。一旦数据被分类，人员就可以确保根据分类对其进行适当的标记和处理。标记（或标签）数据可确保人员轻松识别数据的价值。人员应在创建数据后尽快对其进行标记。例如，绝密数据的备份应标记为绝密。同样，如果系统处理敏感数据，该系统应标记上相应的标签。除了在外部标记系统外，组织通常还会配置壁纸和屏幕保护程序，以清晰地显示系统上处理的数据级别。例如，如果系统处理秘密数据，其壁纸和屏幕保护程序会明确指示其处理秘密数据。
