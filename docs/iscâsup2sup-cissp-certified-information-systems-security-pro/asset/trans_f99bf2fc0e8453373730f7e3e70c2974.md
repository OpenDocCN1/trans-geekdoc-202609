

# 网格拓扑

**网格拓扑** 使用多条路径将系统连接到其他系统（请参见 [图 11.12](#c11.xhtml#figure11-12)）。全网格拓扑将每个系统连接到网络上的所有其他系统。部分网格拓扑将许多系统连接到许多其他系统。网格拓扑为系统提供冗余连接，允许多个线段发生故障而不会严重影响连通性。

# 无线通信与安全

无线通信是网络、连接、通信和数据交换技术领域中一个快速扩展的领域。有成千上万种协议、标准和技术可被归类为无线技术。这些包括手机、蓝牙、无绳电话和无线网络。随着无线技术的持续普及，贵组织的安全工作必须超越锁定其本地网络的范畴。安全应是一种端到端的解决方案，涵盖所有形式、方法和技术的通信。

## 通用无线概念

无线通信利用无线电波在一定距离内传输信号。无线电波频谱是有限的；因此，必须对其进行妥善管理，以允许多个同时使用且几乎不产生干扰。无线电频谱通过频率进行测量或区分。频率是特定时间内波振荡次数的度量，使用单位 **赫兹**，即每秒振荡次数。无线电波的频率范围在 `3 Hz` 到 `300 GHz` 之间。不同频率范围被指定用于特定用途，例如 AM 和 FM 广播、VHF 和 UHF 电视等。目前，`900 MHz`、`2.4 GHz` 和 `5 GHz` 频率是无线产品中最常用的，因为它们属于免许可频段。然而，为了管理有限无线电频率的同时使用，开发了若干频谱使用技术。这些包括扩频、FHSS、DSSS 和 OFDM。

扩频意味着通信同时发生在多个频率上。因此，消息被分解成多个片段，每个片段同时发送但使用不同的频率。实际上这是一种并行通信，而非串行通信。

**跳频扩频** 是扩频概念的早期实现。然而，它不是以并行方式发送数据，而是在不断改变使用频率的情况下以串行方式传输数据。会使用整个可用频率范围，但一次只使用一个频率。当发送方从一个频率跳变到下一个频率时，接收方必须遵循相同的跳频模式才能接收信号。FHSS 的设计初衷是通过不使用单一频率（单一频率可能受到干扰）来帮助最小化干扰。相反，通过不断变换频率，它将干扰降至最低。

**直接序列扩频** 以并行方式同时使用所有可用频率。这比 FHSS 提供更高的数据吞吐率。DSSS 还使用一种称为扩频码的特殊编码机制，允许接收方即使在信号因干扰而部分失真的情况下也能重建数据。这与 RAID-5 的奇偶校验允许重建缺失驱动器上的数据的方式非常相似。

**正交频分复用** 是频率利用的另一种变体。OFDM 采用数字多载波调制方案，允许进行更紧凑的传输。调制后的信号是垂直（正交）的，因此不会相互造成干扰。最终，OFDM 所需的频率集合更小（也称为信道带宽），但可以提供更大的数据吞吐量。

## 手机

手机无线通信是指使用便携设备通过一组特定的无线电波频率，与手机运营商的网络以及其他手机设备或互联网进行交互。手机运营商使用的技术众多且往往令人困惑。一个困惑点在于 `2G` 和 `3G` 等术语的使用。这些术语并不特指具体技术，而是指手机技术的代际。因此，`1G` 是第一代（主要为模拟），`2G` 是第二代（主要为数字，`3G` 和 `4G` 也是如此），以此类推。当系统集成了第二代和第三代技术时，甚至还有 `2.5G` 的说法。[表 11.10](#c11.xhtml#table11-10) 试图澄清其中一些令人困惑的问题（这只是技术的部分列表）。

表中列出的某些技术被标记并作为 `4G` 进行营销，但实际上并不满足被归类为 `4G` 的技术要求。国际电信联盟无线电通信部门 (ITU-R) 于 2008 年定义了 `4G` 的要求，但在 2010 年默许运营商可以将其不合规的技术称为 `4G`，前提是这些技术能通向未来的合规服务。`5G` 技术正在开发中，2018 年已部署了一些测试网络。

关于手机无线传输，有几个关键问题需要牢记。首先，并非所有手机流量都是语音；手机系统常被用来传输文本甚至计算机数据。其次，通过手机运营商网络进行的通信，无论是语音、文本还是数据，不一定是安全的。第三，利用特定的无线嗅探设备，您的手机传输可能被拦截。事实上，您运营商的基站可以被模拟以实施中间人攻击。第四，使用手机连接访问互联网或办公网络，为攻击者提供了另一条潜在的攻击、访问和入侵途径。许多此类设备可能充当网桥，从而在您的网络中创建不安全的入口。
