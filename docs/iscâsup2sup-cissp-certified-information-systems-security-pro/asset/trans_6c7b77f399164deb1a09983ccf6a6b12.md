
# 知识点总结

**了解安全控制的工作原理及其功能。** 安全控制使用访问规则来限制主体对客体的访问。

**能够列出 TCSEC、ITSEC 和通用准则的类别。** TCSEC 的类别包括经验证保护、强制保护、自主保护和最低保护。[表 8.4](#c08.xhtml#table8-4) 涵盖并对比了 TCSEC、ITSEC 和 CC 的等效及适用排名（请记住，ITSEC 中 F7 到 F10 的功能性等级在 TCSEC 中没有对应的等级）。

**定义可信计算基（TCB）。** TCB 是形成可信基础的硬件、软件和控制的组合，用于实施安全策略。

**能够解释什么是安全边界。** 安全边界是将 TCB 与系统其余部分分隔开的假想边界。TCB 组件通过可信路径与非 TCB 组件通信。

**了解参考监视器和安全内核。** 参考监视器是 TCB 的逻辑部分，在授予访问权限前确认主体是否有权使用资源。安全内核是实现参考监视器功能的 TCB 组件的集合。

**理解信息系统的安全能力。** 常见的安全能力包括内存保护、虚拟化和可信平台模块 (TPM)。
