
# 用户需知问题

用户需知的问题包括避免浪费、欺诈和未经授权的活动。组织中的所有成员（从高级管理层到临时实习生）都需要同等程度的认知。组织中的认知计划应与其安全策略、事件处理计划、业务连续性和灾难恢复程序相结合。要使认知建设计划有效，必须保持其新颖性、创造性，并经常更新。认知计划还应与对企业文化如何影响个人及整个组织安全的理解相结合。如果员工看不到安全策略和标准的执行（尤其是在认知层面），他们可能就不会觉得有义务遵守这些规定。

# 培训

**培训**是指教导员工执行其工作任务并遵守安全策略。培训通常由组织主办，面向具有相似工作职能的员工群体。所有新员工都需要一定程度的培训，以便能够遵守安全策略强制规定的所有标准、指南和程序。新用户需要知道如何使用 IT 基础设施、数据存储在何处，以及资源分类的方式和原因。许多组织选择在授予新员工网络访问权限之前对其进行培训，而其他组织则会授予新用户有限的访问权限，直到其特定职位的培训完成。培训是一项持续的活动，必须在组织的整个生命周期内为每位员工持续进行。它被视为一种管理类安全控制。

呈现认知和培训的方法和技术应随时间修订和改进，以最大化收益。这要求收集和评估培训指标。这可能包括培训后测试，以及监控工作一致性的改进、停机时间、安全事件或错误的减少。这可以视为计划有效性评估。

认知和培训通常在内部提供。这意味着这些教学工具由组织内部创建和部署。然而，下一层级的知识分发通常来自外部第三方来源。

# 教育

**教育**是一项更详细的工作，学生/用户学到的知识远超其执行工作任务所需。教育通常与追求认证或寻求晋升的用户相关。它通常是寻求安全专业职位人员的要求。安全专业人员需要具备整个组织的安全和本地环境的广泛知识，而不仅仅是其特定的工作任务。

组织内所需的认知、培训和教育的适当水平评估应通过定期内容审查定期修订。随着组织随时间演变，培训工作需要更新和调整。此外，还应实施新的大胆且微妙的认知手段，以保持内容的新鲜感和相关性。如果没有针对内容相关性的定期审查，材料将变得陈旧，员工可能会诉诸于制定自己的指南和程序。安全治理团队有责任制定安全规则，并提供培训和教育以推动这些规则的实施。

# 管理安全职能

要管理安全职能，组织必须实施适当且充分的安全治理。执行风险评估以驱动安全策略，是管理安全职能最清晰、最直接的例子。

安全必须具有成本效益。组织没有无限的预算，因此必须适当分配资金。此外，组织预算中包含专门用于安全的资金比例，就像大多数其他业务任务和流程需要资本一样，更不用说员工薪资、保险、退休金等支出。安全应足以抵御组织面临的典型或标准威胁，但前提是这种安全的成本不应超过所保护资产的价值。正如本章前面“理解并应用风险管理概念”所述，成本超过资产价值本身的对策通常不是有效的解决方案。

安全必须可度量。可度量的安全意味着安全机制的各个方面能够发挥作用、提供明确的收益，并拥有一个或多个可记录和分析的指度量标准。类似于性能指标，安全指标是与安全功能操作相关的性能、功能、操作、动作等的测量。实施对策或保护措施时，安全指标应显示不想要事件的减少或尝试检测的增加。否则，安全机制就没有提供预期的收益。测量和评估安全指标的行为，即评估安全计划的完整性和有效性的实践。这还应包括根据通用安全指南进行衡量，并跟踪其控制措施的成功情况。跟踪和评估安全指标是有效安全治理的一部分。然而，值得注意的是，选择不正确的安全指标可能会导致严重问题，例如选择监控或衡量安全人员几乎无法控制的事物，或基于外部驱动因素的事物。

资源既会被安全机制本身消耗，也会被安全治理流程消耗。显然，安全机制应尽可能少地消耗资源，并将对系统生产力或吞吐量的影响降至可行的最低水平。然而，每个硬件和软件对策以及用户必须遵循的每个策略和程序都会消耗资源。在对策选择、部署和调优前后，了解并评估资源消耗是安全治理和管理安全职能的重要组成部分。

管理安全职能包括信息安全策略的开发和实施。CISSP 考试的大部分内容（因此也是本书的大部分内容）都涉及信息安全策略开发和实施的各个方面。

# 总结

在规划安全解决方案时，重要的是要考虑到人类往往是组织安全中最薄弱的环节。无论部署了何种物理或逻辑控制，人类都能发现避免、规避、颠覆或禁用它们的方法。因此，在为您的环境设计和部署安全解决方案时，必须将用户纳入考量。安全招聘实践、角色、策略、标准、指南、程序、风险管理、认知培训和管理规划等方面共同有助于保护资产。使用这些安全结构可以为您的安全解决方案提供一定程度的保护，以抵御人类带来的威胁。

安全招聘实践需要详细的职位描述。职位描述用作选择候选人并对其进行适当评估的指南。通过职位描述维护安全包括职责分离、工作职责和工作轮换的使用。

需要终止策略来保护组织及其现有员工。终止程序应包括见证人、归还公司财产、禁用网络访问、离职面谈和护送离开场所。
