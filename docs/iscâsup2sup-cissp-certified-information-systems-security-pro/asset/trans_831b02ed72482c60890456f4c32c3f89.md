

# 免费 Wi-Fi

免费 Wi-Fi 在旅途中往往颇具吸引力。然而，它很容易成为一个陷阱，被配置用来捕获用户的所有流量。例如，攻击者可以将 Wi-Fi 连接配置为中间人攻击，强制所有流量经过攻击者的系统。随后，攻击者便可捕获所有流量。复杂的中间人攻击能在客户端与攻击者系统之间建立一个超文本传输安全协议 (HTTPS) 连接，并在攻击者系统与基于互联网的服务器之间建立另一个 HTTPS 连接。从客户端的角度来看，这看起来像是客户端计算机与基于互联网的服务器之间建立了一条安全的 HTTPS 连接。然而，所有数据都在攻击者的系统上被解密，且易于查看。相反，用户应拥有创建自己互联网连接的方法，例如通过智能手机或使用 Mi-Fi 设备。

# VPN

雇主应提供虚拟专用网络 (VPN) 的访问权限，以便员工创建安全连接。这些网络可用于访问内部网络中的资源，包括工作相关的电子邮件。

## 应急管理

应急管理计划和实践有助于组织在灾难发生后解决人员安全与安保问题。灾难可以是自然灾害（如飓风、龙卷风和地震），也可以是人为灾害（如火灾、恐怖袭击或导致大规模停电的网络攻击），详见第 18 章“灾难恢复规划”。组织将根据其可能遇到的自然灾害类型制定不同的计划。

## 安全培训与意识

实施安全培训和意识计划也很重要。这些计划有助于确保人员了解胁迫系统、旅行最佳实践、应急管理计划以及通用的安全最佳实践。

# 安全配置资源

安全运营领域的另一个要素是在资源的整个生命周期中对其进行配置和管理。第 13 章“管理身份和认证”涵盖了作为身份与访问配置生命周期一部分的用户账户配置与取消配置。本节重点关注其他资产类型（如硬件、软件、物理、虚拟和基于云的资产）的配置与管理。

组织应用各种资源保护技术，以确保资源得到安全配置和管理。例如，台式计算机通常使用镜像技术进行部署，以确保它们从一个已知的安全状态启动。变更管理和补丁管理技术确保系统通过所需的更改保持最新状态。这些技术因资源而异，将在以下各节中描述。

## 管理硬件和软件资产

在此语境下，硬件是指计算机、服务器、路由器、交换机和外设等 IT 资源。软件包括操作系统和应用程序。组织通常执行例行清点以追踪其硬件和软件。

### 硬件清点

许多组织使用数据库和清点应用程序来执行清点，并在整个设备生命周期中追踪硬件资产。例如，可用的条形码系统可以打印条形码以粘贴在设备上。条形码数据库包含硬件的相关详细信息，如型号、序列号和位置。购买硬件时，会在部署前先贴上条形码。定期，人员使用条形码阅读器扫描所有条形码，以验证组织仍控制着该硬件。

一种类似的方法使用射频识别 (RFID) 标签，它可以向 RFID 阅读器传输信息。人员将 RFID 标签贴在设备上，并使用 RFID 阅读器对设备进行清点。RFID 标签和阅读器比条形码和条形码阅读器更昂贵。然而，RFID 方法能显著减少执行清点所需的时间。

在处置设备之前，人员会对其进行清理。清理设备会移除所有数据，以确保未经授权的人员无法访问敏感信息。当设备达到使用寿命终点时，个人很容易忽视其中包含的数据，因此使用清单对系统进行清理通常很有价值。清单可包括对硬盘驱动器、非易失性内存以及系统内的可移动介质（如光盘 (CD)、数字多功能光盘 (DVD) 和通用串行总线 (USB) 闪存驱动器）进行清理的步骤。NIST 800-88r1 和第 5 章提供了有关驱动器清理程序的更多信息。

存放敏感数据的便携式介质也作为资产进行管理。例如，组织可以用条形码标记便携式介质，并使用条形码清点系统定期完成清点。这使他们能够定期清点存放敏感数据的介质。

### 软件许可

组织为软件付费，许可密钥常用于激活软件。激活过程通常需要通过互联网联系许可服务器以防止盗版。如果许可密钥泄露到组织外部，可能会导致组织内部的密钥失效。监控许可合规性以避免法律问题也很重要。

例如，组织可能购买了某软件产品五次安装的许可密钥，但最初只安装并激活了一个实例。如果密钥被盗并在组织外部的四个系统上安装，这些激活将会成功。当组织尝试在内部系统上安装该应用程序时，激活将会失败。因此，任何类型的许可密钥对组织都极具价值，应受到保护。

软件许可还指确保系统未安装未经授权的软件。有许多工具可远程检查系统以检测系统详细信息。例如，Microsoft 的 System Center Configuration Manager (ConfigMgr 或 SCCM) 是一款服务器产品，可查询网络上的每个系统。ConfigMgr 拥有广泛的功能，包括识别已安装的操作系统和应用程序的能力。这使其能够识别系统上运行的未经授权的软件，并帮助组织确保其遵守软件许可规则。

## 保护物理资产

物理资产不仅限于 IT 硬件，还包括所有物理资产，如组织的建筑物及其内容。用于保护物理安全资产的方法包括围栏、路障、锁闭的门、警卫、闭路电视 (CCTV) 系统等。

当组织规划布局时，通常将敏感的物理资产置于建筑物的中心位置。这使组织能够实施逐步增强的物理安全控制。例如，组织会将数据中心置于靠近建筑物中心的位置。如果数据中心位于外墙边，攻击者可能开着卡车撞破墙壁并窃取服务器。

同样，建筑物通常设有任何人均可进入的公共入口。然而，额外的物理安全控制限制了对内部工作区域的访问。密码锁、人员闸、安全徽章和警卫都是常用的访问控制方法。
