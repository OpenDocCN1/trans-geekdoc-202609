

# 会话层（第 5 层）

`会话层（第 5 层）`负责在两台计算机之间建立、维护和终止通信会话。它管理对话规程或对话控制（单工、半双工、全双工），建立检查点以进行分组和恢复，并重传自上一个已验证检查点以来失败或丢失的 PDU。以下协议在会话层运行：

*   网络文件系统 (NFS)
*   结构化查询语言 (SQL)
*   远程过程调用 (RPC)

通信会话可以在三种不同的规程或控制模式下运行：

**单工** 单向通信

**半双工** 双向通信，但同一时间只能有一个方向发送数据

**全双工** 双向通信，数据可同时在两个方向发送

# 表示层（第 6 层）

`表示层（第 6 层）`负责将从应用层接收的数据转换为任何遵循 OSI 模型的系统都能理解的格式。它在数据上强制实施通用或标准化的结构和格式规则。表示层还负责加密和压缩。因此，它充当网络与应用程序之间的接口。正是这一层允许各种应用程序通过网络进行交互，它通过确保数据格式被两个系统同时支持来实现这一点。大多数文件或数据格式都在此层运行。这包括图像、视频、声音、文档、电子邮件、网页、控制会话等的格式。以下列表包含存在于表示层中的一些格式标准：

*   美国信息交换标准代码 (ASCII)
*   扩展二进制编码十进制交换模式 (EBCDICM)
*   标记图像文件格式 (TIFF)
*   联合图像专家组 (JPEG)
*   运动图像专家组 (MPEG)
*   音乐设备数字接口 (MIDI)

# 应用层（第 7 层）

`应用层（第 7 层）`负责将用户应用程序、网络服务或操作系统与协议栈进行接口连接。它允许应用程序与协议栈通信。应用层确定远程通信伙伴是否可用且可访问。它还确保有足够的资源可用以支持请求的通信。

应用程序本身并不位于此层；相反，传输文件、交换消息、连接到远程终端等所需的协议和服务位于此处。此层中包含大量特定于应用程序的协议，例如以下各项：

*   超文本传输协议 (HTTP)
*   文件传输协议 (FTP)
*   行式打印机守护进程 (LPD)
*   简单邮件传输协议 (SMTP)
*   Telnet
*   简单文件传输协议 (TFTP)
*   电子数据交换 (EDI)
*   邮局协议版本 3 (POP3)
*   因特网消息访问协议 (IMAP)
*   简单网络管理协议 (SNMP)
*   网络新闻传输协议 (NNTP)
*   安全远程过程调用 (S-RPC)
*   安全电子交易 (SET)

有一种网络设备（或服务）工作在应用层，即网关。然而，应用层网关是一种特定类型的组件。它充当协议转换工具。例如，IP 到 IPX 网关接收来自 `TCP/IP` 的入站通信，并将其转换为 `IPX/SPX` 以进行出站传输。应用层防火墙也在此层运行。其他网络设备或过滤软件可能会在此层观察或修改流量。

# TCP/IP 模型

`TCP/IP 模型`（也称为 `DARPA` 或 `DOD 模型`）仅包含四层，而 OSI 参考模型有七层。TCP/IP 模型的四层分别是应用层（也称为进程层）、传输层（也称为主机到主机层）、网际层（有时称为互联网层）和链路层（尽管有时也使用网络接口和网络接入）。[图 11.5](#c11.xhtml#figure11-5) 展示了它们与 OSI 模型七层的对比。TCP/IP 协议套件是在 OSI 参考模型创建之前开发的。OSI 参考模型的设计者小心确保 TCP/IP 协议套件适配他们的模型，因为该套件已在网络中广泛部署。

![图 11.5 OSI 模型与 TCP/IP 模型的对比 ](images/c11f005.jpg)

[**图 11.5**](#c11.xhtml#figureanchor11-5) OSI 模型与 TCP/IP 模型的对比

TCP/IP 模型的应用层对应 OSI 模型的第 5、6 和 7 层。TCP/IP 模型的传输层对应 OSI 模型的第 4 层。TCP/IP 模型的网际层对应 OSI 模型的第 3 层。TCP/IP 模型的链路层对应 OSI 模型的第 1 和 2 层。

由于混淆、误解，或许还有懒惰，现在通行的做法是用 OSI 模型对应层的名称来称呼 TCP/IP 模型的层。TCP/IP 模型的应用层已经使用了从 OSI 借来的名称，所以这一点很容易。TCP/IP 模型的主机到主机层有时被称为传输层（OSI 模型的第 4 层）。TCP/IP 模型的网际层有时被称为网络层（OSI 模型的第 3 层）。而 TCP/IP 模型的链路层有时被称为数据链路层或网络接入层（OSI 模型的第 2 层）。

## TCP/IP 协议套件概述

最广泛使用的协议套件是 `TCP/IP`，但它不仅仅是单个协议；而是一个由数十个单独协议组成的协议栈（参见[图 11.6](#c11.xhtml#figure11-6)）。TCP/IP 是一个基于开放标准的、与平台无关的协议。然而，这既是优势也是劣势。TCP/IP 几乎存在于所有可用的操作系统中，但它消耗大量资源，且相对容易被攻击，因为它的设计初衷是易用性而非安全性。

![图 11.6 TCP/IP 的四层及其组成协议 ](images/c11f006.jpg)

[**图 11.6**](#c11.xhtml#figureanchor11-6) TCP/IP 的四层及其组成协议

可以使用系统间的虚拟专用网络 (VPN) 链路来保护 TCP/IP。VPN 链路经过加密，以增加隐私性、机密性和认证性，并维护数据完整性。用于建立 VPN 的协议包括 `点对点隧道协议 (PPTP)`、`第 2 层隧道协议 (L2TP)`、`安全外壳协议 (SSH)`、`OpenVPN`（SSL/TLS VPN）和 `IP 安全协议 (IPSec)`。另一种提供协议级安全性的方法是使用 TCP 包装器。`TCP 包装器`是一种应用程序，可通过根据用户 ID 或系统 ID 限制对端口和资源的访问，充当基本防火墙。使用 TCP 包装器是一种基于端口的访问控制形式。

### 传输层协议

TCP/IP 的两个主要传输层协议是 `TCP` 和 `UDP`。`传输控制协议 (TCP)` 是一种全双工面向连接的协议，而 `用户数据报协议 (UDP)` 是一种单工无连接协议。当在两个系统之间建立通信连接时，是通过端口完成的。TCP 和 UDP 各有 65,536 个端口。由于端口号是 16 位二进制数，端口总数为 `2^16`，即 65,536，编号从 0 到 65,535。端口只不过是通信链路两端在传输层传输数据时约定使用的一个地址编号。端口允许单个 IP 地址支持多个同时进行的通信，每个通信使用不同的端口号。IP 地址和端口号的组合称为 `套接字`。
