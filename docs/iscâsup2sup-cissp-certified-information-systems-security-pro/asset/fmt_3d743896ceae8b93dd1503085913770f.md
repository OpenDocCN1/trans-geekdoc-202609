
# 附录 B 书面实验答案

## 第 1 章：通过原则和政策进行安全治理

1.  CIA 三要素是机密性、完整性和可用性的组合。机密性是指用于确保数据、信息或资源的秘密性得到保护的措施概念。完整性是指保护数据的可靠性和正确性的概念。可用性是指授权主体被授予及时、不间断地访问对象的概念。术语 CIA 三要素用于表示安全解决方案的三个关键组成部分。

2.  问责制的要求包括识别、认证、授权和审计。这些组件中的每一个都需要具有法律效力，才能真正让某人对其行为负责。

3.  变更控制管理的好处包括：防止因不受控制的变更而导致安全性降低、记录和跟踪环境中的所有更改、标准化、符合安全策略，以及在发生意外或非预期结果时回滚更改的能力。

4.  (1) 确定保管人，并定义其职责。(2) 指定信息将如何被分类和标记的评估标准。(3) 对每个资源进行分类和标记。虽然此步骤由所有者执行，但主管应对其进行审查。(4) 记录发现的分类策略例外情况，并将其纳入评估标准。(5) 选择将应用于每个分类级别的安全控制，以提供必要的保护级别。(6) 指定取消分类资源的程序以及将资源的保管权转移给外部实体的程序。(7) 创建全企业范围的意识培训计划，指导所有人员了解分类系统。

5.  六个安全角色是：高级管理层、IT/安全人员、所有者、保管人、操作员/用户和审计员。

6.  安全策略的四个组成部分是：策略、标准、指南和程序。策略是广泛的安全声明。标准是硬件和软件安全合规性的定义。当没有合适的程序时，使用指南。程序是以安全方式执行工作任务的详细分步说明。

## 第 2 章：人员安全和风险管理概念

1.  可能的答案包括：职位描述、最小权限原则、职责分离、工作职责、工作轮换/交叉培训、绩效评估、背景调查、工作行动警告、安全意识培训、岗位培训、离职面谈/解雇、保密协议、竞业禁止协议、雇佣协议、隐私声明和可接受使用策略。

2.  公式如下：

*   `SLE = AV * EF`
*   `ARO = # / yr`
*   `ALE = SLE * ARO`
*   `Cost/benefit = (ALE1 – ALE2) – ACS`

3.  德尔菲技术是一种匿名反馈和响应过程，用于使小组达成匿名共识。其主要目的是引出所有参与者诚实且不受影响的回应。参与者通常聚集在一个会议室中。针对每次反馈请求，每位参与者匿名在纸上写下他们的回应。结果被汇总并呈现给小组进行评估。该过程重复进行，直到达成共识。

4.  风险评估通常涉及一种混合方法，同时使用定量和定性方法。纯定量分析是不可能的；并非分析的所有要素和方面都可以量化，因为有些是定性的、主观的和无形的。由于纯定量风险评估是不可能的，平衡定量分析的结果至关重要。将定量和定性分析结合起来形成最终组织风险评估的方法称为混合评估或混合分析。

## 第 3 章：业务连续性规划

1.  许多联邦、州和地方法律或法规要求企业实施 BCP 规定。在 BCP 团队中包含法律代表有助于确保您遵守法律、法规和合同义务。

2.  “拍脑袋”方法是那些不想投入时间和金钱来妥善制定 BCP 的个人使用的借口。当没有一个周密的计划来指导在压力巨大的紧急情况下的响应时，这可能导致灾难。

3.  定量风险评估涉及使用数字和公式来做决策。定性风险评估包括专业知识而非数字度量，例如情绪、投资者/消费者信心和员工队伍稳定性。

4.  BCP 培训计划应包括面向所有员工的计划概述简报，以及针对直接或间接参与人员的具体培训。此外，每个关键 BCP 角色的备份人员也应接受培训。
