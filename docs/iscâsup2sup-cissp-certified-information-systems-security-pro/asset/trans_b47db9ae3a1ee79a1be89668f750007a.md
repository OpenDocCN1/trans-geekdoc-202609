
# 伪缺陷

**伪缺陷** 是有意植入系统中的虚假漏洞或明显的漏洞，旨在引诱攻击者。它们常用于蜜罐系统，以模拟众所周知的操作系统漏洞。试图利用已知缺陷的攻击者可能会偶然发现伪缺陷，并误以为已成功渗透系统。更复杂的伪缺陷机制实际上会模拟渗透过程，使攻击者信服他们已获得系统的额外访问权限。然而，当攻击者正在探索系统时，监控和警报机制会触发并向管理员发出威胁警报。

## 理解填充单元

**填充单元** 系统类似于蜜罐，但它采用不同的方法执行入侵隔离。当 IDPS 检测到入侵者时，该入侵者会被自动传送到填充单元。填充单元具有实际网络的外观和感觉，但攻击者无法从填充单元内执行任何恶意活动或访问任何机密数据。

填充单元是一个模拟环境，提供虚假数据以保持入侵者的兴趣，这点与蜜罐相似。然而，IDPS 在未通知入侵者变更已发生的情况下，将入侵者传送到填充单元。相比之下，攻击者会直接选择攻击蜜罐，而不会被 IDPS 传送到蜜罐。管理员会密切监控填充单元，并利用它们来检测和观察攻击。安全专业人员可利用它们来检测攻击手法，并收集证据以便可能对攻击者提起诉讼。填充单元如今不常用，但考试中可能仍会涉及。

## 警告横幅

警告横幅告知用户和入侵者基本的安全策略准则。它们通常提及在线活动会被审计和监控，并经常提供关于受限活动的提醒。在大多数情况下，从法律角度来看，横幅中的措辞很重要，因为这些横幅可以在法律上约束用户遵守允许的行为、举止和流程。

以某种方式设法登录系统的未授权人员也会看到警告横幅。在这种情况下，你可以将警告横幅视为“禁止入内”标志的电子等效物。当警告明确声明禁止未授权访问，且任何活动都将被监控和记录时，大多数入侵和攻击都可以被起诉。

## 反恶意软件

防范恶意代码最重要的保护措施是使用具有最新签名文件和启发式功能的反恶意软件。攻击者定期发布新的恶意软件，并经常修改现有恶意软件以防止被反恶意软件检测到。反恶意软件供应商会寻找这些变化，并开发新的签名文件来检测新的和修改过的恶意软件。多年前，反恶意软件供应商建议每周更新一次签名文件。然而，如今大多数反恶意软件都包含每天多次自动检查更新的功能，无需用户干预。

许多组织采用多管齐下的方法来阻止恶意软件并检测任何进入系统的恶意软件。具有内容过滤功能的防火墙（或专用内容过滤设备）通常部署在互联网与内部网络的边界，以过滤掉任何类型的恶意代码。专用反恶意软件安装在邮件服务器上，以检测和过滤通过电子邮件传递的任何类型的恶意软件。此外，反恶意软件安装在每个系统上，以检测和阻止恶意软件。组织通常使用中央服务器部署反恶意软件、下载更新的定义，并将这些定义推送到客户端。

在每个系统上安装反恶意软件并过滤互联网内容的多管齐下方法，有助于保护系统免受来自任何来源的感染。例如，在每个系统上使用最新的反恶意软件将检测并阻止员工 USB 闪存驱动器上的病毒。

反恶意软件供应商通常建议在任何系统上仅安装一个反恶意软件应用程序。当系统上安装了多个反恶意软件应用程序时，这些应用程序可能会相互干扰，有时会导致系统问题。此外，拥有多个扫描程序会消耗过多的系统资源。

遵循最小权限原则也有帮助。用户将没有系统的管理权限，也无法安装可能是恶意的应用程序。如果病毒确实感染了系统，它通常会冒充登录用户。当该用户拥有有限权限时，病毒的能力也会受到限制。此外，随着额外应用程序的增加，与恶意软件相关的漏洞也会增加。每个额外的应用程序都为恶意代码提供了另一个潜在的攻击点。

教育用户了解恶意代码的危险、攻击者如何诱骗用户安装恶意代码，以及他们可以采取什么措施来降低风险，是另一种保护方法。很多时候，用户只需不点击链接或不打开通过电子邮件发送的附件，就能避免感染。

第 14 章涵盖了社会工程学战术，包括网络钓鱼、鱼叉式网络钓鱼和鲸钓。当用户了解这些类型的攻击时，他们不太可能上当受骗。尽管许多用户接受过关于这些风险的教育，但网络钓鱼邮件仍然充斥互联网并进入用户的收件箱。攻击者之所以继续发送它们，唯一的原因是它们仍然能欺骗一些用户。

### 白名单与黑名单

应用程序白名单和黑名单可以是一种有效的预防措施，防止用户运行未授权的应用程序。它们也有助于防止恶意软件感染。白名单标识获授权在系统上运行的应用程序列表，而黑名单标识未获授权在系统上运行的应用程序列表。

白名单不包含恶意软件应用程序，因此会阻止它们运行。某些白名单使用哈希算法创建哈希值来标识应用程序。然而，如果应用程序感染了病毒，病毒会有效地改变哈希值，因此这种类型的白名单也会阻止受感染的应用程序运行。（第 6 章“密码学和对称密钥算法”更深入地介绍了哈希算法。）

运行在 iPhone 和 iPad 上的 Apple iOS 是白名单极端版本的一个示例。用户只能安装 Apple App Store 上提供的应用。Apple 人员会审核并批准 App Store 上的所有应用，并迅速移除行为不当的应用。虽然用户可以绕过安全措施并越狱其 iOS 设备，但大多数用户不会这样做，部分原因是这会导致保修失效。

如果管理员知道要阻止哪些应用程序，黑名单是一个不错的选择。例如，如果管理层希望确保用户不在系统上运行游戏，管理员可以启用工具来阻止这些游戏。

## 防火墙

防火墙通过过滤流量为网络提供保护。正如第 11 章所讨论的，防火墙多年来经历了许多变化。

基本防火墙根据 IP 地址、端口和一些协议（使用协议编号）过滤流量。防火墙在 ACL 中包含允许特定流量的规则，并以一条隐式拒绝规则结束。隐式拒绝规则会阻止前一条规则未允许的所有流量。例如，防火墙可以通过分别允许使用 TCP 端口 80 和 443 的流量来允许 HTTP 和 HTTPS 流量。（第 11 章更深入地介绍了逻辑端口。）
