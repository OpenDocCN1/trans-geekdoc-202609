
Web 应用服务器以加密格式接收数据。它解密数据并将其发送给 Web 应用程序。Web 应用程序在临时内存缓冲区中存储数据，同时使用这些数据来授权交易。当 Web 应用程序不再需要数据时，它会采取措施清除内存缓冲区，确保所有残留的敏感数据从内存中完全移除。

## 处理信息和资产

管理敏感数据的一个关键目标是防止数据泄露。数据泄露是指任何未经授权的实体可以查看或访问敏感数据的事件。如果你关注新闻，可能经常听到数据泄露的消息。像 2017 年的 Equifax 数据泄露这样的大型事件会登上主流新闻。Equifax 报告称，攻击者窃取了约 1.43 亿美国人的个人数据，包括社会安全号码、姓名、地址和出生日期。

然而，即使你可能从未听说过较小的数据泄露，它们也在定期发生，2017 年平均每周报告的数据泄露超过 25 起。以下章节确定了组织内部人员为限制数据泄露可能性而遵循的基本步骤。

### 标记敏感数据和资产

标记（通常称为标签）敏感信息可确保用户轻松识别任何数据的分类级别。标记或标签提供的最重要信息是数据的分类。例如，`top secret` 标签能让任何看到该标签的人清楚地知道该信息被归类为绝密。当用户了解数据的价值时，他们更有可能根据分类采取适当措施来控制和保护数据。标记包括物理标记和电子标记及标签。

物理标签指示存储在资产（如介质）上或在系统上处理的数据的安全分类。例如，如果备份磁带包含机密数据，贴在磁带上的物理标签会明确告知用户它包含机密数据。

同样，如果计算机处理敏感信息，该计算机将贴有标签，指示其处理的最高分类信息。用于处理机密、秘密和绝密数据的计算机应标记为处理绝密数据的标签。物理标签在系统或介质的整个生命周期内保留。

标记还包括使用数字标记或标签。一种简单的方法是在文档中将分类作为页眉和/或页脚包含进去，或将其嵌入为水印。这些方法的好处是它们也会出现在打印输出上。即使用户在打印输出上包含页眉和页脚，大多数组织仍要求用户将打印的敏感文档放在包含标签或封面页的文件夹中，清楚地指示分类。页眉不限于文件。备份磁带通常包含页眉信息，分类可以包含在此页眉中。

页眉、页脚和水印的另一个好处是 DLP 系统可以识别包含敏感信息的文档，并应用适当的安全控制。一些 DLP 系统在检测到文档被分类时，还会向文档添加元数据标签。这些标签提供了对文档内容的洞察，并帮助 DLP 系统适当地处理它。

同样，一些组织强制要求其计算机使用特定的桌面背景。例如，用于处理专有数据的系统可能具有黑色桌面背景，带有白色的 `Proprietary` 字样和宽橙色边框。背景还可以包含“本计算机处理专有数据”等声明，以及提醒用户保护数据责任的声明。

在许多安全环境中，人员也会为非密介质和设备使用标签。这可以防止遗漏错误，即敏感信息未被标记。例如，如果包含敏感数据的备份磁带未被标记，用户可能会假设它只包含非密数据。然而，如果组织也标记非密数据，未标记的介质就会很容易被注意到，用户会对未标记的磁带产生怀疑。

组织通常会确定降级介质的程序。例如，如果备份磁带包含机密信息，管理员可能想将磁带降级为非密。组织会确定可清除磁带上所有可用数据的受信任程序。管理员清除磁带后，可以对其进行降级并替换标签。

然而，许多组织完全禁止降级介质。例如，数据策略可能禁止降级包含绝密数据的备份磁带。相反，策略可能要求在磁带达到其生命周期结束时销毁它。同样，降级系统也很少见。换句话说，如果系统一直在处理绝密数据，很少会将其降级并重新标记为非密系统。无论如何，都需要创建批准的程序以确保正确降级。

### 处理敏感信息和资产

处理是指介质在其整个生命周期内的安全运输。人员根据数据的价值和分类以不同方式处理数据，正如你所料，高度机密的信息需要更多的保护。即使这是常识，人们仍会犯错。很多时候，人们习惯于处理敏感信息，变得松懈大意。

例如，据 2011 年报道，英国国防部在回应信息自由请求时，错误地发布了关于核潜艇的机密信息以及其他敏感信息。他们使用图像编辑软件将机密数据涂黑来进行编辑。然而，任何尝试复制数据的人都可以复制所有文本，包括被涂黑的数据。

另一个常见情况是备份磁带的控制丢失。备份磁带应受到与备份数据相同级别的保护。换句话说，如果备份磁带上有机密信息，该备份磁带应作为机密信息受到保护。然而，有许多情况并未遵循这一点。例如，TD Bank 在 2012 年丢失了两盒包含 260,000 多条客户数据记录的备份磁带。与许多数据泄露一样，详细信息需要很长时间才会披露。TD Bank 在磁带丢失约六个月后向客户报告了数据泄露。两年多后，即 2014 年 10 月，TD Bank 最终同意支付 85 万美元并改革其做法。

最近，存储在 Amazon Web Services (AWS) Simple Storage Service (S3) 中的数据因权限不当暴露了数十 TB 的数据。AWS S3 是一种基于云的服务，美国政府的 Outpost 计划公开从社交媒体和其他互联网页面收集数据。抓取网络数据和监控社交媒体并不新鲜。然而，这些数据存储在一个名为 `CENTCOM` 的公开可访问归档中。该归档未受加密或权限保护。
