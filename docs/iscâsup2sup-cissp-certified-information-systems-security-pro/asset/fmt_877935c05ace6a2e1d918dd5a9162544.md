# 评估测试答案

1. **C. 检测性访问控制**用于发现（并记录）不需要的或未授权的活动。

2. **D. 强密码选择**难以猜测、不可预测，且具有指定的最小长度，以确保密码条目无法通过计算确定。它们可能是随机生成的，并利用所有字母、数字和标点字符；绝不应记录或共享；不应存储在公开可访问或通常可读的位置；且不应以明文传输。

3. **B. 基于网络的 IDS**通常能够检测攻击的发起或正在进行的攻击尝试（包括拒绝服务，即 `DoS`）。然而，它们无法提供关于攻击是否成功或哪些特定系统、用户账户、文件或应用程序受到影响的信息。基于主机的 IDS 在检测和追踪 `DoS` 攻击方面有一定困难。漏洞扫描器不检测 `DoS` 攻击；它们测试可能的漏洞。渗透测试可能导致 `DoS` 或测试 `DoS` 漏洞，但它不是检测工具。

4. **B. 并非所有 `DoS` 实例都是恶意攻击的结果。** 操作系统、服务和应用程序中的编码错误导致了 `DoS` 状况。例如包括进程未能释放 CPU 控制权，或服务消耗系统资源的比例与其处理的服务请求不成比例。社会工程学和嗅探通常不被视为 `DoS` 攻击。

5. **A. 网络硬件设备（包括路由器）在第三层（即网络层）运行。**

6. **D. 动态包过滤防火墙**支持根据流量内容实时修改过滤规则。

7. **D. `VPN` 链路**可在任何其他网络通信连接上建立。这可能是典型的 `LAN` 电缆连接、无线 `LAN` 连接、远程访问拨号连接、`WAN` 链路，甚至是客户端用于访问办公室 `LAN` 的互联网连接。

8. **C. 特洛伊木马**是一种利用社会工程学策略诱骗受害者安装的恶意软件——诀窍在于让受害者相信他们下载或获得的只是宿主文件，而实际上它隐藏着恶意载荷。

9. **D. CIA 三要素的组成部分**是机密性、可用性和完整性。

10. **B. 隐私**不是提供问责制所必需的。

11. **C. 组用户账户**允许多人使用单一用户账户登录。这导致串通，因为它阻止了个人问责制。

12. **B. 数据所有者**必须先为资源分配安全标签，数据管理员才能适当地保护该资源。

13. **C. `SW-CMM` 的受控阶段**涉及使用定量开发度量。软件工程协会（`SEI`）将该级别的关键过程领域定义为定量过程管理和软件质量管理。

14. **B. 第 1 层和第 2 层包含设备驱动程序，但在实践中通常不实现。** 第 0 层始终包含安全内核。第 3 层包含用户应用程序。第 4 层不存在。

15. **B. `SYN` 数据包**首先从发起主机发送到目标主机。目标主机随后响应 `SYN/ACK` 数据包。发起主机发送 `ACK` 数据包，连接随即建立。

16. **B. 参数检查**用于防止缓冲区溢出攻击的可能性。

17. **A. `~` OR 符号**表示 OR 函数，当一个或两个输入位为真时结果为真。

18. **C. 置换密码**使用加密算法重新排列明文消息的字母以形成密文消息。

19. **B. `MD5` 算法**为任何输入生成 128 位的消息摘要。

20. **C. 任何接收者**都可使用 Mike 的公钥来验证数字签名的真实性。

21. **C. 迭代**不是与安全模型相关的合成理论之一。级联、反馈和挂钩是三种合成理论。
