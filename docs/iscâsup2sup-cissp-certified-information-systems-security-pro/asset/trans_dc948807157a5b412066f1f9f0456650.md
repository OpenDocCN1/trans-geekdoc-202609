
**能够描述 IPsec。** IPsec 是一种安全架构框架，支持通过 IP 进行安全通信。IPsec 以传输模式或隧道模式建立安全通道。它可用于建立计算机之间的直接通信，或在网络之间建立 VPN。IPsec 使用两种协议：认证头 (AH) 和封装安全载荷 (ESP)。

**能够解释常见的密码学攻击。** 暴力攻击是尝试随机寻找正确的加密密钥。已知明文攻击、选择密文攻击和选择明文攻击要求攻击者除了拥有密文外，还掌握一些额外信息。中间相遇攻击利用了使用两轮加密的协议。中间人攻击欺骗双方与攻击者通信，而不是直接相互通信。生日攻击是尝试在哈希函数中寻找碰撞。重放攻击是尝试重用身份验证请求。

**理解数字版权管理 (DRM) 的用途。** 数字版权管理 (DRM) 解决方案允许内容所有者强制执行他人对其内容使用的限制。DRM 解决方案通常保护娱乐内容，如音乐、电影和电子书，但偶尔也会在企业中发现，用于保护存储在文档中的敏感信息。
