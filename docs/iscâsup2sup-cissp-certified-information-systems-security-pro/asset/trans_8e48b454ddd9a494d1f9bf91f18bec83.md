
# 理解不同的无线技术
手机、蓝牙（802.15）和无线网络（802.11）都被称为无线技术，尽管它们各不相同。请注意它们的差异、优势和劣势。理解保护 802.11 网络的基础知识。

# 理解光纤通道
光纤通道是一种网络数据存储解决方案（即 SAN（存储区域网络）或 NAS（网络附属存储）），允许高速文件传输。

# 理解 FCoE
FCoE（基于以太网的光纤通道）用于在以太网网络上封装光纤通道通信。

# 理解 iSCSI
iSCSI（互联网小型计算机系统接口）是一种基于 IP 的网络存储标准。

# 理解 802.11 及 802.11a、b、g、n 和 ac
802.11 是无线网络通信的 IEEE 标准。版本包括 802.11（2 Mbps）、802.11a（54 Mbps）、802.11b（11 Mbps）、802.11g（54 Mbps）、802.11n（600 Mbps）和 802.11ac（1.3+ Gbps）。802.11 标准还定义了有线等效隐私（WEP）。

# 理解现场勘测
*现场勘测* 是调查特定环境中部署的无线接入点的存在性、强度和覆盖范围的过程。此任务通常涉及携带便携式无线设备走动，记录无线信号强度，并将其绘制在建筑物的平面图或示意图上。

# 理解 WPA2
WPA2 是一种新的加密方案，称为带有密码块链消息认证码协议的计数器模式（CCMP），基于 AES 加密方案。

# 理解 EAP
EAP（可扩展认证协议）不是一种特定的认证机制；而是一个认证框架。实际上，EAP 允许新的认证技术与现有的无线或点对点连接技术兼容。

# 理解 PEAP
PEAP（受保护的可扩展认证协议）在 TLS 隧道中封装 EAP 方法，该隧道提供认证和潜在的加密。

# 理解 LEAP
LEAP（轻量级可扩展认证协议）是思科专有的 TKIP 替代方案，用于 WPA。它的开发是为了在 802.11i/WPA2 系统被批准为标准之前解决 TKIP 中的缺陷。

# 理解 MAC 过滤
MAC 过滤器是授权无线客户端接口 MAC 地址的列表，无线接入点使用它来阻止所有未授权设备的访问。

# 理解 SSID 广播
无线网络传统上会在信标帧（beacon frame）这一特殊数据包中定期广播其 SSID。当广播 SSID 时，任何具有自动检测和连接功能的设备不仅能看到该网络，还能发起与该网络的连接。

# 理解 TKIP
TKIP（临时密钥完整性协议）被设计为 WEP 的替代品，且不需要更换传统无线硬件。TKIP 在 802.11 无线网络中以 WPA（Wi-Fi Protected Access）的名称实现。

# 理解 CCMP
CCMP（带有密码块链消息认证码协议的计数器模式）被创建用于替代 WEP 和 TKIP/WPA。CCMP 使用带有 128 位密钥的 AES（高级加密标准）。

# 理解网络门户
网络门户是一种认证技术，它将新连接的无线 Web 客户端重定向到门户访问控制页面。

# 理解天线类型
无线客户端和基站可使用多种天线类型。这些包括全向极化天线以及多种定向天线，如八木天线、罐装天线、平板天线和抛物面天线。

# 了解标准网络拓扑
标准网络拓扑包括环形、总线形、星形和网状。

# 了解常见网络设备
常见网络设备包括防火墙、路由器、集线器、网桥、调制解调器、中继器、交换机、网关和代理。

# 理解不同类型的防火墙
防火墙有多种类型：静态包过滤、应用层网关、电路级网关、状态检测、深度包检测和下一代防火墙。

# 了解用于连接 LAN 和 WAN 通信技术的协议服务
这些协议服务包括帧中继、SMDS、X.25、ATM、HSSI、SDLC、HDLC 和 ISDN。
