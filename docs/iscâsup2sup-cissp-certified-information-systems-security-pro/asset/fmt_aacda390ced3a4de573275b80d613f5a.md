
# 威胁建模与访问控制攻击

## 高级持续性威胁

任何威胁模型都应考虑已知威胁的存在，这包括**高级持续性威胁（APT）**。APT 是一群协同工作、动机高度强烈、技术娴熟且极具耐心的攻击者。他们拥有先进的知识和多种技能，用于检测和利用漏洞。他们具有持续性，专注于利用一个或多个特定目标，而非单纯的机会目标。国家（或政府）通常为 APT 提供资金。然而，一些有组织的犯罪集团也会资助并运营 APT。

如果组织将攻击者识别为潜在威胁（而非自然威胁），威胁建模将尝试识别攻击者的目标。某些攻击者可能旨在瘫痪系统，而另一些则意在窃取数据，每个目标都代表一个独立的威胁。一旦组织识别出这些威胁，会根据底层资产的优先级对其进行分类。

过去，保护网络安全只需比其他网络更安全即可。攻击者会瞄准容易得手的目标，避开安全防护完善的网络。你可能记得那句老话：“被灰熊追赶时你需要跑多快？” 答案：“只需比你小组里最慢的人跑得稍微快一点。”

然而，如果你手里拿着熊想要的蜂蜜罐，它可能会无视其他人，专门追着你跑。这正是 APT 的行为模式。它根据想从目标身上获取的利益，专门针对特定目标发动攻击。如果想了解更多案例，可使用常用搜索引擎搜索“cozy bear attacks”（舒适熊攻击）和“fancy bear attacks”（花哨熊攻击）。

## 威胁建模方法

威胁的可能性近乎无限，因此难以使用结构化方法识别相关威胁。相反，许多组织采用以下三种方法之一（或多种组合）来识别威胁：

**以资产为中心** 此方法利用资产估值结果，尝试识别针对高价值资产的威胁。人员评估特定资产以确定其遭受攻击的易感性。如果资产托管数据，人员将评估访问控制，以识别可绕过身份验证或授权机制的威胁。

**以攻击者为中心** 部分组织识别潜在攻击者，并根据攻击者的目标识别其构成的威胁。例如，政府通常能识别潜在攻击者并洞悉其意图。随后可利用这些知识识别并保护相关资产。不过，随着众多由外国民族国家资助的 APT 出现，这变得愈发困难。

**以软件为中心** 若组织开发软件，可考虑针对软件的潜在威胁。多年前组织自行开发软件并不常见，但如今已司空见惯。具体而言，大多数组织都有网络业务，许多还自建网站。花哨的网站能吸引更多流量，但也需要更复杂的编程，并带来额外威胁。第 21 章“恶意代码与应用攻击”涵盖了应用攻击和 Web 应用安全。

# 识别漏洞

在识别出有价值的资产和潜在威胁后，组织将执行**漏洞分析**。换言之，它试图发现这些系统针对潜在威胁的弱点。在访问控制背景下，漏洞分析旨在识别不同访问控制机制的优劣势，以及威胁利用弱点的潜在可能性。

漏洞分析是一个持续过程，可包含技术和管理步骤。在大型组织中，特定人员可能全职从事漏洞分析。他们定期执行漏洞扫描，查找各类漏洞，并汇报结果。在小型组织中，网络管理员可能按周期（如每周或每月）运行漏洞扫描。

风险分析通常包含漏洞分析，通过针对已知威胁和漏洞评估系统和环境，随后进行渗透测试以利用漏洞。第 16 章“管理安全运营”详细介绍了如何将漏洞扫描和漏洞评估作为整体漏洞管理的一部分使用。

# 常见访问控制攻击

访问控制攻击旨在绕过或规避访问控制方法。正如第 13 章所述，访问控制始于标识和授权，访问控制攻击往往试图窃取用户凭证。攻击者窃取用户凭证后，可发起在线**冒充**攻击，以该用户身份登录并访问其资源。在其他情况下，访问控制攻击可绕过身份验证机制直接窃取数据。

本书涵盖多种攻击，以下章节介绍一些直接与访问控制相关的常见攻击。

## 访问聚合攻击

**访问聚合**指收集多条非敏感信息并将其组合（即聚合）以获取敏感信息。换言之，个人或团体可收集关于系统的多个事实，再利用这些事实发动攻击。

侦察攻击属于访问聚合攻击，它结合多种工具识别系统的多个要素，如互联网协议（IP）地址、开放端口、运行中的服务、操作系统等。攻击者也对数据库使用聚合攻击。第 20 章“软件开发安全”涵盖了聚合和推理攻击，这些攻击通过聚合和推理技术间接允许未授权个人访问数据。

结合纵深防御、最小知情权限和最小权限原则有助于防范访问聚合攻击。

## 密码攻击

密码是最薄弱的身份验证形式，存在多种密码攻击手段。若攻击者在密码攻击中得逞，即可访问该账户及其授权资源。若攻击者发现 `root` 或管理员密码，便可访问任何其他账户及其资源。若攻击者在高安全环境中获取了特权账户密码，该环境的安全性将永远无法完全恢复信任。攻击者可能已创建其他账户或后门访问系统。组织可能选择从头重建整个系统，而非接受该风险。

**强密码**有助于防范密码攻击。它长度足够且包含多种字符类型。“长度足够”是一个动态目标，取决于用途和环境。第 13 章讨论了密码策略、强密码及口令的使用。关键在于：较长的密码比较短的密码更强。
