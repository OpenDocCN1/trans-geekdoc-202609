物理和环境安全主题在多个领域中均有涉及。主要出现在领域 3“安全架构与工程”和领域 7“安全运营”中。CISSP 认证考试通用知识体系 (CBK) 这两个领域的多个子章节涉及与设施安全相关的主题和问题，包括基础原则、设计与实施、火灾防护、外围安全、内部安全等。

物理安全的目的是防范物理威胁。以下是最常见的物理威胁：火灾和烟雾、水灾（内涝/外溢）、地质运动（地震、滑坡、火山）、风暴（大风、闪电、雨、雪、冰雹、冰冻）、蓄意破坏/恶意损坏、爆炸/毁坏、建筑物倒塌、有毒物质、公用设施中断（电力、供暖、制冷、空气、水）、设备故障、盗窃和人员损失（罢工、疾病、通行、交通）。

本章探讨这些问题，并讨论防范它们的保障措施和对策。在许多情况下，如果发生严重的物理威胁（如爆炸、蓄意破坏或自然灾害），你将需要灾难恢复计划或业务连续性计划。第 3 章“业务连续性规划”和第 18 章“灾难恢复规划”详细涵盖了这些主题。

## 将安全原则应用于站点和设施设计

此时应该显而易见，如果无法控制物理环境，任何管理、技术或逻辑访问控制的集合都无法提供充分的安全性。如果恶意人员能够获得对你设施或设备的物理访问权限，他们几乎可以为所欲为，从破坏、泄露到篡改。物理控制是你的第一道防线，而人员是最后一道防线。

实施和维护物理安全有许多方面。核心要素之一是选择或设计用于容纳你的信息技术 (IT) 基础设施和组织运营的设施。选择或设计设施安全的过程总是从计划开始。

### 安全设施计划

*安全设施计划* 概述了组织的安全需求，并强调了为提供安全所采用的方法或机制。此类计划通过称为关键路径分析的过程来制定。*关键路径分析* 是一项系统性工作，旨在识别关键任务应用程序、流程和操作与所有必要支持要素之间的关系。例如，一台用于通过网络销售产品的电子商务服务器依赖于互联网接入、计算机硬件、电力、温度控制、存储设施等。

当关键路径分析正确执行时，会生成维持组织运作所需的相互依赖关系和交互作用的完整图景。一旦分析完成，其结果将作为一份待保护项目的清单。设计安全 IT 基础设施的第一步是为组织及其计算机的基本需求提供安全保障。这些基本需求包括电力、环境控制（换句话说，建筑物、空调、供暖、湿度控制等）以及水/污水处理。

在检查关键路径时，评估已完成或潜在的技术融合也很重要。*技术融合* 是指各种技术、解决方案、公用设施和系统随时间推移而演变和合并的趋势。这通常会导致多个系统执行相似或冗余的任务，或者一个系统接管另一个系统的功能和能力。虽然在某些情况下这可以提高效率和节省成本，但它也可能代表单点故障，并成为黑客和入侵者更有价值的目标。例如，如果语音、视频、传真和数据流量共享单一连接路径而不是各自独立的路径，一次针对主连接的蓄意破坏行为就足以让入侵者或窃贼切断外部通信。
