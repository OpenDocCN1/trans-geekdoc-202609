

# 带冲突避免的载波侦听多路访问 (CSMA/CA)

这是一种 LAN 媒体访问技术，通过以下步骤执行通信：

1.  主机与 LAN 媒体有两个连接：入站和出站。主机在入站连接上监听以确定 LAN 媒体是否正在使用。
2.  如果 LAN 媒体未被使用，主机请求传输许可。
3.  如果在超时期限后未授予许可，主机返回步骤 1 重新开始。
4.  如果获得许可，主机通过出站连接传输其通信。
5.  主机等待确认。
6.  如果在超时期限后未收到确认，主机返回步骤 1 重新开始。

AppleTalk 和 802.11 无线网络是采用 `CSMA/CA` 技术的网络示例。`CSMA/CA` 通过在任何给定时间仅授予单个通信许可来尝试避免冲突。该系统需要指定一个主系统或主系统，它响应请求并授予发送数据传输的许可。

# 带冲突检测的载波侦听多路访问 (CSMA/CD)

这是一种 LAN 媒体访问技术，通过以下步骤执行通信：

1.  主机监听 LAN 媒体以确定其是否正在使用。
2.  如果 LAN 媒体未被使用，主机传输其通信。
3.  传输时，主机监听冲突（即两个或多个主机同时传输）。
4.  如果检测到冲突，主机发送干扰信号。
5.  如果收到干扰信号，所有主机停止传输。每个主机等待一段随机时间，然后返回步骤 1 重新开始。

以太网网络采用 `CSMA/CD` 技术。`CSMA/CD` 通过让冲突域中的每个成员在重新开始该过程前等待一段短暂但随机的时间来响应冲突。不幸的是，允许冲突发生然后响应或反应冲突会导致传输延迟以及所需的重复传输。这导致潜在吞吐量约 40% 的损失。

# 令牌传递

这是一种使用数字令牌执行通信的 LAN 媒体访问技术。拥有令牌允许主机传输数据。传输完成后，它将令牌释放给下一个系统。令牌传递用于令牌环网络，例如 `FDDI`。令牌环通过仅允许拥有令牌的系统传输数据来防止冲突。

# 轮询

这是一种使用主从配置执行通信的 LAN 媒体访问技术。一个系统被标记为主系统。所有其他系统被标记为从系统。主系统依次轮询或询问每个从系统它们是否有传输数据的需求。如果从系统表明有需求，则授予其传输许可。传输完成后，主系统继续轮询下一个从系统。同步数据链路控制（`SDLC`）使用轮询。

轮询通过尝试使用许可系统防止冲突来解决冲突问题。轮询是 `CSMA/CA` 方法的逆过程。两者都使用主从（或主和从）系统，但 `CSMA/CA` 允许从系统请求许可，而轮询由主系统提供许可。轮询可配置为授予一个（或多个）系统优于其他系统的优先级。例如，如果标准轮询模式是 1, 2, 3, 4，则要给系统 1 优先级，轮询模式可更改为 1, 2, 1, 3, 1, 4。

# 总结

设计、部署和维护网络安全的任务需要对网络中涉及的技术有深入了解。这包括协议、服务、通信机制、拓扑、布线、端点和网络设备。

`OSI` 模型是评估所有协议的标准。理解 `OSI` 模型如何使用以及如何应用于实际协议，可以帮助系统设计人员和系统管理员提高安全性。`TCP/IP` 模型直接源自该协议，大致映射到 `OSI` 模型。

大多数网络采用 `TCP/IP` 作为主要协议。然而，在 `TCP/IP` 网络中可以找到许多子协议、支持协议、服务和安全机制。对这些实体的基本了解有助于您设计和部署安全网络。

除了路由器、集线器、交换机、中继器、网关和代理外，防火墙也是网络安全的重要组成部分。防火墙有几种类型：静态包过滤、应用层网关、电路级网关、状态检测、深度包检测和下一代。

汇聚协议在现代网络中很常见，包括 `FCoE`、`MPLS`、`VoIP` 和 `iSCSI`。软件定义网络和内容分发网络扩展了网络的定义以及其用例。可使用各种硬件组件构建网络，其中不乏将所有设备连接在一起的布线。了解每种布线类型的优缺点是设计安全网络的一部分。

无线通信以多种形式发生，包括蜂窝电话、蓝牙（`802.15`）、`RFID`、`NFC` 和网络（`802.11`）。无线通信更容易受到干扰、窃听、拒绝服务和中间人攻击。

最常见的 LAN 技术是以太网。还有几种常见的网络拓扑：环形、总线、星形和网状。

# 考试要点

## 了解 OSI 模型层及每层所在的协议

`OSI` 模型的七层及每层支持的协议如下：

*   **应用层**：`HTTP`、`FTP`、`LPD`、`SMTP`、`Telnet`、`TFTP`、`EDI`、`POP3`、`IMAP`、`SNMP`、`NNTP`、`S-RPC` 和 `SET`
*   **表示层**：加密协议和格式类型，如 `ASCII`、`EBCDICM`、`TIFF`、`JPEG`、`MPEG` 和 `MIDI`
*   **会话层**：`NFS`、`SQL` 和 `RPC`
*   **传输层**：`SPX`、`SSL`、`TLS`、`TCP` 和 `UDP`
*   **网络层**：`ICMP`、`RIP`、`OSPF`、`BGP`、`IGMP`、`IP`、`IPSec`、`IPX`、`NAT` 和 `SKIP`
*   **数据链路层**：`SLIP`、`PPP`、`ARP`、`L2F`、`L2TP`、`PPTP`、`FDDI`、`ISDN`
*   **物理层**：`EIA/TIA-232`、`EIA/TIA-449`、`X.21`、`HSSI`、`SONET`、`V.24` 和 `V.35`

## 透彻了解 TCP/IP

了解 `TCP` 和 `UDP` 的区别；熟悉四个 `TCP/IP` 层（应用层、传输层、网际层和链路层）及其如何对应 `OSI` 模型。此外，了解知名端口的用法并熟悉子协议。

## 了解不同的布线类型及其长度和最大吞吐率

这包括 `STP`、`10BaseT`（`UTP`）、`10Base2`（细缆）、`10Base5`（粗缆）、`100BaseT`、`1000BaseT` 和光纤。您还应熟悉 `UTP` 1 类到 7 类。

## 熟悉常见的 LAN 技术

最常见的 LAN 技术是以太网。还应熟悉模拟与数字通信；同步与异步通信；基带与宽带通信；广播、组播和单播通信；`CSMA`、`CSMA/CA` 和 `CSMA/CD`；令牌传递；和轮询。

## 理解安全网络架构和设计

网络安全应考虑 `IP` 和非 `IP` 协议、网络访问控制、使用安全服务和设备、管理多层协议以及实施端点安全。

## 理解各种网络分段的类型和目的

网络分段可用于管理流量、提高性能和实施安全。网络段或子网的示例包括内联网、外联网和 `DMZ`。
