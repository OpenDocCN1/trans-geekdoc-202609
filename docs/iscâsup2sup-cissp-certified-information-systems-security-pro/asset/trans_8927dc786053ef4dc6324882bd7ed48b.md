
# 使用虚拟内存

使用虚拟内存是一种低成本的方法，可让计算机运行起来就好像它拥有的真实内存比实际安装的物理内存更多。其主要缺点是，当数据在主存和辅存之间交换时发生的分页操作相对较慢（内存功能以纳秒为单位，磁盘系统以微秒为单位；通常这意味着三个数量级的差异！）并消耗大量的计算机开销，从而拖慢整个系统。随着实际物理 RAM 容量的增加，对虚拟内存的需求会减少，并且可以通过使用闪存卡或 SSD 来托管虚拟内存分页文件，以减轻虚拟内存带来的性能损失。

## 内存安全问题

内存存储并处理您的数据——其中一些可能极其敏感。您必须了解各种类型的内存，并知晓它们如何存储和保留数据。任何可能保留敏感数据的内存设备，在允许其因任何原因离开您的组织之前，都应进行清除。对于设计为断电后仍能保留数据的辅助内存以及 `ROM`/`PROM`/`EPROM`/`EEPROM` 设备，这一点尤为重要。

然而，内存数据保留问题并不局限于那些设计用于保留数据的内存类型。请记住，静态和动态 RAM 芯片通过电容器和触发器存储数据（参见侧边栏“动态 RAM 与静态 RAM”）。从技术上讲，这些电气元件在断电后可能会在有限的时间内保留部分电荷。技术娴熟的个人理论上可以对这些元件进行电学测量，并检索存储在这些设备上的部分数据。然而，这需要相当深厚的技术专长，除非您的对手拥有令人难以置信的深厚资金，否则这不太可能构成威胁。

存在一种攻击会冻结内存芯片，以便在系统关闭或 RAM 从主板上拔出时延缓驻留数据的衰减。请参阅 <http://en.wikipedia.org/wiki/Cold_boot_attack>。甚至还有针对内存镜像转储或系统崩溃转储以提取加密密钥的攻击。请参阅 <http://www.lostpassword.com/hdd-decryption.htm>。

围绕内存最重要的安全问题之一，是在计算机使用期间控制谁可以访问存储在内存中的数据。这主要是操作系统的责任，也是本章前几节中描述的各种处理模式所涉及的主要内存安全问题。在本章后面的“基本安全保护机制”部分，您将了解进程隔离原则如何用于确保进程无法访问读取或写入未分配给它们的内存空间。如果您在多级安全环境中操作，确保采取足够的保护措施以防止内存内容在安全级别之间发生意外泄露（无论是通过直接内存访问还是隐蔽信道）就显得尤为重要（隐蔽信道的完整讨论将在本章后面出现）。

## 存储

*数据存储设备*构成了我们将要讨论的计算机系统组件的第三大类。这些设备用于存储信息，以便计算机在数据写入后的任何时间使用。我们将首先探讨一些与存储设备相关的常用术语，然后介绍与数据存储相关的一些安全问题。

### 主存与辅存

主存储和辅存储的概念可能会让人有些困惑，尤其是在与主存和辅存进行比较时。有一个简单的方法可以理清它们——它们是同一回事！*主内存*，也称为*主存储*，是计算机在运行时用于保持必要信息随时可供 CPU 使用的 RAM。*辅助内存*（或*辅助存储*）包括您每天使用的所有熟悉的长期存储设备。辅助存储由磁性和光学介质组成，例如 `HDD`、`SSD`、闪存驱动器、磁带、`CD`、`DVD`、闪存卡等。

### 易失性与非易失性

您已经从我们之前关于内存的讨论中熟悉了易失性的概念，尽管您可能以前没有听说过用该术语来描述它。存储设备的易失性仅仅是衡量其在断电时丢失数据的可能性有多大。设计用于保留数据的设备（如磁性介质）被归类为*非易失性*，而设计用于丢失数据的设备（如静态或动态 RAM 模块）被归类为*易失性*。回顾前一节的讨论，复杂的技术有时可能能够在断电后从易失性内存中提取数据，因此两者之间的界限有时可能会变得模糊。

### 随机与顺序

存储设备可以通过两种方式之一进行访问。*随机访问存储*设备允许操作系统通过某种寻址系统，立即从设备内的任意点进行读取（有时也可写入）。几乎所有主存储设备都是随机访问设备。您可以使用内存地址访问 RAM 芯片中任意位置存储的信息，而无需读取其之前物理存储的数据。大多数辅助存储设备也是随机访问的。例如，硬盘驱动器使用可移动磁头系统，允许您直接移动到磁盘上的任意点，而无需旋转经过先前磁道上存储的所有数据；同样，CD 和 DVD 设备使用光学扫描仪，可将自身定位在盘片表面的任何位置。

另一方面，*顺序存储*设备不提供这种灵活性。它们要求您读取（或跳过）物理存储在所需位置之前的所有数据。顺序存储设备的一个常见示例是磁带驱动器。为了访问存储在磁带中间的数据，磁带驱动器必须物理扫描整个磁带（即使在快进模式下不一定处理其经过的数据），直到到达所需位置。

显然，顺序存储设备的运行速度比随机访问存储设备慢得多。然而，您再次面临成本/收益的决策。许多顺序存储设备可以在相对廉价的介质上存储海量数据。这一特性使磁带驱动器成为与灾难恢复/业务连续性计划相关的备份任务的独特选择（请参阅第 3 章“业务连续性规划”和第 18 章“灾难恢复规划”）。在备份场景中，您通常有极大量的数据需要存储，且极少需要访问这些存储的信息。这种情况非常适合使用顺序存储设备！

### 存储介质安全

我们在上一节中讨论了围绕主存储设备的安全问题。对于辅助存储设备的安全性，有三个主要关注点；它们都反映了针对主存储设备提出的担忧：

*   数据可能即使在被擦除后仍保留在辅助存储设备上。这种情况称为*数据残留*。大多数精通技术的计算机用户都知道，即使文件已被删除，也有可用的实用程序可以从磁盘中检索文件。从技术上讲，从已重新格式化的磁盘中检索数据也是可能的。如果您真的想从辅助存储设备中移除数据，必须使用专门设计用于销毁设备上所有数据痕迹的实用程序，或将其损坏或销毁到无法修复的程度（通常称为*清理*）。
