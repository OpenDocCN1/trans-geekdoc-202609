

# 信息安全调查流程

信息安全专业人员必须熟悉调查流程。这涉及收集和分析进行调查所需的证据。安全专业人员应熟悉主要的证据类别，包括实物证据、书面证据和证人证言。电子证据通常通过对硬件、软件、存储介质和网络的分析来收集。必须使用适当的程序收集证据，以确保不篡改原始证据并保持证据保管链。

## 计算机犯罪类别

计算机犯罪被归类为几大类，每一类中的犯罪具有共同的动机和预期结果。了解攻击者的意图有助于妥善保护系统。

例如，军事和情报攻击旨在获取无法通过合法途径获得的秘密信息。商业攻击与此类似，不同之处在于它们针对民用系统。其他类型的攻击包括金融攻击（电话欺诈是金融攻击的一个例子）和恐怖主义攻击（在计算机犯罪背景下，指旨在破坏正常生活的攻击）。最后，还有怨恨攻击，其目的是通过破坏数据或利用信息使组织或个人难堪来造成损害，以及刺激攻击，由缺乏经验的破解者发起，旨在攻破或瘫痪系统。虽然通常不够复杂，但刺激攻击可能令人恼火且代价高昂。

## 职业道德与专业操守

规范你个人行为的一套准则称为职业道德准则。安全专业人员可以遵循若干职业道德准则，其性质从一般到具体不等。`(ISC)²` 将接受其职业道德准则作为认证的要求。

# 考试要点

**了解计算机犯罪的定义。** 计算机犯罪是指针对计算机或直接涉及计算机的犯罪（或违反法律法规的行为）。

**能够列举并解释计算机犯罪的六大类别。** 计算机犯罪分为六类：军事和情报攻击、商业攻击、金融攻击、恐怖主义攻击、怨恨攻击和刺激攻击。能够解释每种攻击类型的动机。

**了解收集证据的重要性。** 一旦发现事件，你必须立即开始收集证据以及尽可能多的关于该事件的信息。证据可用于后续的法律诉讼或查明攻击者身份。证据还有助于确定损害程度。

**理解电子取证流程。** 预期将成为诉讼目标的组织有责任通过称为电子取证或 eDiscovery 的流程来保存数字证据。eDiscovery 流程包括信息治理、识别、保存、收集、处理、审查、分析、生成和呈现等活动。

**知道如何调查入侵以及如何从设备、软件和数据中收集足够的信息。** 你必须掌握设备、软件或数据才能对其进行分析并将其作为证据使用。你必须在不修改证据且不允许他人修改的情况下获取证据。

**了解扣押证据的三种基本替代方案及其各自适用的场景。** 首先，证据持有者可自愿移交。其次，可使用传票强制当事人移交证据。第三，当你需要在不给当事人篡改证据机会的情况下扣押证据时，搜查令最为有用。

**了解保留调查数据的重要性。** 因为你可能在事件发生后才发现它们，除非你确保关键日志文件在合理的时间内得到保留，否则你将失去宝贵的证据。你可以就地或在归档中保留日志文件和系统状态信息。

**了解证据在法庭上被采纳的基本要求。** 要被采纳，证据必须与案件中的争议事实相关，该事实必须对案件实质性，且证据必须是合格的或合法收集的。

**解释刑事或民事审判中可能使用的各种证据类型。** 实物证据由可带入法庭的实际物品组成。书面证据由提供事实洞察的书面文件组成。证人证言由证人作出的口头或书面陈述组成。

**理解职业道德对安全人员的重要性。** 安全从业者被授予极高的权限和责任来执行其工作职能。滥用权力的可能性存在，如果没有严格的个人行为准则，安全从业者可能被视为拥有不受约束的权力。遵守职业道德准则有助于确保此类权力不被滥用。

**了解 `(ISC)²` 职业道德准则和 RFC 1087 “互联网伦理”。** 所有 CISSP 候选人都应熟悉完整的 `(ISC)²` 职业道德准则，因为他们必须签署协议承诺遵守它。此外，还应熟悉 `RFC 1087` 的基本声明。

# 复习题

1. 什么是计算机犯罪？
   1. 安全策略中专门列出的任何攻击
   2. 任何危害受保护计算机的非法攻击
   3. 任何涉及计算机的违反法律法规的行为
   4. 未能在计算机安全方面履行尽职调查

2. 军事和情报攻击的主要目的是什么？
   1. 攻击军事系统的可用性
   2. 从军事或执法来源获取秘密和受限信息
   3. 利用军事或情报机构系统攻击其他非军事站点
   4. 攻破军事系统以用于攻击其他系统

3. 哪种攻击针对存储在民用组织系统上的专有信息？
   1. 商业攻击
   2. 拒绝服务攻击
   3. 金融攻击
   4. 军事和情报攻击

4. 以下哪个目标*不是*金融攻击的目的？
   1. 访问未购买的服务
   2. 泄露机密的个人员工信息
   3. 将资金从未经批准的来源转入自己的账户
   4. 从另一个组织窃取资金

5. 以下哪种攻击最能表明是恐怖主义攻击？
   1. 篡改敏感的商业机密文件
   2. 破坏通信和应对物理攻击的能力
   3. 窃取非机密信息
   4. 向其他国家转移资金

6. 以下哪项不会是怨恨攻击的主要目标？
   1. 泄露令人尴尬的个人信息
   2. 在组织系统上释放病毒
   3. 发送伪造受害组织发件地址的不当邮件
   4. 使用自动化工具扫描组织系统以查找脆弱端口

7. 攻击者实施刺激攻击的主要原因是什么？（选择所有适用项。）
   1. 吹嘘资本
   2. 出售窃取文件获利
   3. 攻破安全系统的成就感
   4. 对个人或组织进行报复

8. 收集证据时必须遵循的最重要规则是什么？
   1. 在给屏幕拍照之前不要关闭计算机。
   2. 列出收集证据时在场的所有人员。
