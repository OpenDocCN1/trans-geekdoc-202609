

# 数据生命周期管理

## 存储

数据主要存储在磁盘驱动器上，人员会定期备份有价值的数据。存储数据时，必须确保根据其分类级别应用足够的安全控制来保护数据。这包括应用适当的权限以防止未经授权的披露。敏感数据还应进行加密以保护它。敏感信息的备份存储在本地的一个位置，并将副本存储在异地的另一个位置。物理安全方法可防止这些备份被盗。环境控制可防止因热和湿度等环境破坏导致数据丢失。

## 使用

使用是指数据在使用中或在网络上传输的任何时候。数据在使用时处于未加密格式。应用程序开发人员需要采取措施，确保任何敏感数据在使用后从内存中清除。传输中的数据（通过网络传输）需要根据数据的价值提供保护。发送前对数据进行加密可提供这种保护。

## 归档

有时为了遵守要求保留数据的法律或法规而将数据归档。此外，作为基本的安全控制，会备份有价值的数据，以确保即使失去对原始数据的访问，数据仍可用。归档和备份通常存储在异地。传输和存储此数据时，提供的保护级别应与本地存储期间相同。保护级别取决于数据的分类和价值。

## 销毁或清除

当数据不再需要时，应以无法读取的方式将其销毁。仅仅删除文件并不会真正删除它们，而只是将它们标记为待删除，因此这不是销毁数据的有效方法。技术人员和管理员会在必要时使用各种工具删除文件的所有可读元素。这些工具通常用 1 和 0 的模式覆盖文件或磁盘，或使用其他方法粉碎文件。删除敏感数据时，许多组织要求人员销毁磁盘，以确保数据不可访问。美国国家标准与技术研究院（NIST）特别出版物（SP）SP 800-88r1《媒体清理指南》提供了如何清理媒体的详细信息。此外，第 5 章介绍了各种销毁和清除数据的方法。

# 服务级别协议

服务级别协议（SLA）是组织与外部实体（如供应商）之间的协议。SLA 规定了性能期望，通常还包括供应商未达到这些期望时的惩罚措施。

例如，许多组织使用基于云的服务来租用服务器。供应商提供服务器访问权限并对其进行维护，以确保其可用。组织可以使用 SLA 来指定可用性，例如最大停机时间。考虑到这一点，组织在与第三方合作时应清楚了解自身需求，并确保 SLA 包含这些需求。

除了 SLA，组织有时还会使用谅解备忘录（MOU）和/或互连安全协议（ISA）。MOU 记录了两个实体为共同目标而合作的意向。虽然 MOU 类似于 SLA，但它不那么正式，且不包含任何一方未履行职责时的金钱惩罚。

如果两个或多方计划传输敏感数据，可以使用 ISA 来指定连接的技术要求。ISA 提供了关于双方如何建立、维护和断开连接的信息。它还可以确定用于保护数据的最低加密方法。

# 人员安全与安保

人员安全问题是安全运营的重要组成部分。数据、服务器甚至整栋建筑等物品总是可以替换的。相比之下，人员是无法替换的。考虑到这一点，组织应实施增强人员安全的安全控制。

例如，考虑由按钮式电子密码锁控制的数据中心出口门。如果火灾导致停电，出口门是自动解锁还是保持锁定？重视服务器室资产胜过人员安全的组织可能会决定在断电时确保门保持锁定。这保护了数据中心的物理资产。然而，这也会危及室内人员的生命，因为他们无法轻松离开房间。相反，重视人员安全胜过数据中心资产的组织将确保断电时锁具解锁出口门。

## 胁迫

当人员独自工作时，胁迫系统很有用。例如，一名保安可能在下班后独自看守一栋建筑。如果一群人闯入大楼，保安可能无法独自阻止他们。但是，保安可以使用胁迫系统发出警报。简单的胁迫系统只是一个发送求救信号的按钮。监控实体接收求救信号并根据既定程序做出响应。监控实体可以向发送求救信号的人回拨电话或发送短信。在本例中，保安通过确认情况来响应。

安全系统通常包含人员用来验证一切正常或验证存在问题的代码词或短语。例如，表示一切正常的代码短语可以是“everything is awesome”。如果保安无意中激活了胁迫系统，监控实体做出响应，保安说“Everything is awesome”并解释发生了什么。但是，如果罪犯控制了保安，他可能会跳过该短语，而是编造一个他意外激活胁迫系统的故事。监控实体会识别出保安跳过了代码短语并派遣援助。

## 差旅

另一个安全问题是员工差旅，因为罪犯可能会在员工差旅时将其作为目标。对人员进行差旅安全实践培训可以提高他们的安全性并防止安全事件。这包括一些简单的事情，例如在打开酒店房门前验证对方身份。如果客房服务送来免费食物，给前台打个电话可以核实这是否有效或是否为诈骗的一部分。

员工还应被告知差旅时与电子设备（如智能手机、平板电脑和笔记本电脑）相关的诸多风险。这些风险包括：

### 敏感数据

理想情况下，设备不应包含任何敏感数据。这可以防止设备丢失或被盗时数据泄露。如果员工差旅时需要此数据，应使用强加密进行保护。

### 恶意软件和监控设备

已有许多报告称员工访问外国时系统被安装恶意软件。同样，我们也听说过员工出国旅行后，设备内部被安装物理监控设备的第一手报告。人们可能认为设备在酒店房间里很安全，因为他们外出去当地餐厅用餐。然而，这足够让看起来像酒店工作人员的人进入房间，在操作系统中安装恶意软件，并在计算机内部安装物理窃听设备。始终保持对设备的物理控制可以防止这些攻击。此外，安全专家建议员工不要携带个人设备，而是携带临时设备在旅行期间使用。旅行结束后，这些设备可以被擦除并重新制作镜像。
