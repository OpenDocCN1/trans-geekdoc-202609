

# Wi-Fi Protected Access (WPA) 和无线安全

*Wi-Fi Protected Access (WPA)* 旨在取代 WEP；它是一个临时修复方案，直到新的 802.11i 修正案完成。制定新修正案的过程耗时数年，因此 WPA 在市场上站稳了脚跟，至今仍被广泛使用。此外，WPA 可用于大多数设备，而 802.11i 的功能则排除了某些低端硬件。

802.11i 是定义取代 WEP 的加密解决方案的修正案。然而，当 802.11i 最终确定时，WPA 解决方案已被广泛使用，因此他们无法按原计划使用 WPA 名称；因此它被命名为 WPA2。但这并不表示 802.11i 是 WPA 的第二个版本。事实上，它们是两套完全不同的技术。802.11i（即 WPA2）实现了类似于 IPSec 的概念，为无线通信带来了迄今为止最好的加密和安全性。

Wi-Fi Protected Access 基于 LEAP 和临时密钥完整性协议（TKIP）密码系统，并通常采用秘密口令进行身份验证。不幸的是，使用单一静态口令是 WPA 的致命弱点。攻击者只需对 WPA 网络运行暴力猜测攻击即可发现口令。如果口令长达 14 个字符或更多，这通常是一个耗时过长以至于不可行的尝试，但并非不可能。此外，WPA 的 LEAP 和 TKIP 两种加密选项现在均可通过多种破解技术被破解。虽然比攻破 WEP 更复杂，但 WPA 不再提供长期可靠的安全性。

## WPA2

最终，一种新的无线安全保护方法被开发出来，至今仍普遍被认为是安全的。这就是称为 *802.11i* 或 *Wi-Fi Protected Access 2 (WPA2)* 的修正案。它是一种称为 *Counter Mode Cipher Block Chaining Message Authentication Code Protocol (CCMP)* 的新加密方案，基于 AES 加密方案。2017 年底，一种称为 KRACK（密钥重装攻击）的攻击概念被披露，它能破坏客户端与 WAP 之间最初的四次握手，迫使其重用先前使用的密钥，在某些情况下甚至使用仅由零组成的密钥。大多数易受攻击的无线设备已更新或有可用更新来解决此问题。更多信息请见 [https://www.krackattacks.com/](https://www.krackattacks.com/)。

## 802.1X/EAP

WPA 和 WPA2 均支持称为 *802.1X/EAP* 的企业级身份验证，这是一种基于端口的标准网络访问控制，确保客户端在完成适当身份验证之前无法与资源通信。实际上，802.1X 是一种移交系统，允许无线网络利用现有网络基础设施的身份验证服务。通过使用 802.1X，远程认证拨入用户服务（RADIUS）、终端访问控制器访问控制系统（TACACS）、证书、智能卡、令牌设备和生物识别等其他技术和解决方案可集成到无线网络中，提供相互认证和多因素认证的技术。

*可扩展认证协议 (EAP)* 不是一种特定的认证机制；而是一个认证框架。实际上，EAP 允许新的认证技术与现有的无线或点对点连接技术兼容。超过 40 种不同的 EAP 认证方法被广泛支持。这些包括 LEAP、EAP-TLS、EAP-SIM、EAP-AKA 和 EAP-TTLS 等无线方法。并非所有 EAP 方法都是安全的。例如，EAP-MD5 和一种称为 LEAP 的预发布 EAP 也可被破解。

## PEAP

*受保护的可扩展认证协议 (PEAP)* 将 EAP 方法封装在一个提供认证和潜在加密的 TLS 隧道中。由于 EAP 最初设计用于物理隔离的信道，因此假设路径是安全的，EAP 通常不加密。因此 PEAP 可以为 EAP 方法提供加密。

## LEAP

*轻量级可扩展认证协议 (LEAP)* 是思科专有的 WPA 替代方案，用于替代 TKIP。这是在 802.11i/WPA2 系统被批准为标准之前，为解决 TKIP 的缺陷而开发的。2004 年发布了一款名为 Asleap 的攻击工具，可利用 LEAP 提供的最终薄弱保护。应尽可能避免使用 LEAP；建议改用 EAP-TLS 作为替代，但如果必须使用 LEAP，强烈建议使用复杂密码。

## MAC 过滤

*MAC 过滤* 是授权无线客户端接口 MAC 地址的列表，由无线接入点用于阻止所有未授权设备的访问。虽然是一个有用的功能，但管理起来可能比较困难，且倾向于仅用于小型、静态环境。此外，拥有基本无线黑客工具的黑客可以发现有效客户端的 MAC 地址，然后将该地址伪造到他们的攻击无线客户端上。

## TKIP

*临时密钥完整性协议 (TKIP)* 旨在取代 WEP，且无需更换传统无线硬件。TKIP 在 WPA（Wi-Fi Protected Access）名称下被实施到 802.11 无线网络中。TKIP 的改进包括：一个密钥混合功能，在将初始化向量（IV）（即随机数）与秘密根密钥结合后，再将该密钥与 RC4 配合使用以执行加密；使用序列计数器防止数据包重放攻击；以及使用一个名为 Michael 的强完整性检查。

TKIP 和 WPA 于 2004 年正式被 WPA2 取代。此外，针对 WPA 和 TKIP 的特定攻击（即 coWPAtty 和基于 GPU 的破解工具）已使 WPA 的安全性变得不可靠。

## CCMP

CCMP（带有密码分组链接消息认证码协议的计数器模式）被创建用于取代 WEP 和 TKIP/WPA。CCMP 使用带有 128 位密钥的 AES（高级加密标准）。CCMP 是 802.11i 指定的 802.11 无线网络的首选标准安全协议。迄今为止，尚无成功针对 AES/CCMP 加密的攻击。

# 确定天线放置位置

部署无线网络时，天线放置位置应是一个考虑因素。在进行适当的现场勘测之前，不要固守特定位置。将无线接入点及/或其天线放置在一个可能的位置；然后测试不同位置的信号强度和连接质量。只有在确认潜在的天线放置位置提供令人满意的连接性后，才应将其固定下来。

寻求最佳天线放置位置时，请考虑以下准则：

- 使用中心位置。
- 避免实体物理障碍物。
- 避免反射性或其他平坦金属表面。
- 避免电气设备。

如果基站具有外置全向天线，通常应将其垂直向上放置。如果使用定向天线，将焦点指向期望使用的区域。请记住，无线信号会受到干扰、距离和障碍物的影响。在设计安全无线网络时，工程师可能会选择定向天线，以避免在不希望提供信号的区域进行广播，或用更强的信号专门覆盖某个区域。

# 天线类型

无线客户端和基站可使用多种天线类型。许多设备可将其标准天线替换为更强（即增强信号）的天线。

标准的直杆或极化天线是*全向天线*，可在垂直于天线本身线路的所有方向上发送和接收信号。这是大多数基站和某些客户端设备上常见的天线类型。这种天线有时也称为基站天线或胶棒天线（因为大多数都覆盖着柔性橡胶涂层）。
