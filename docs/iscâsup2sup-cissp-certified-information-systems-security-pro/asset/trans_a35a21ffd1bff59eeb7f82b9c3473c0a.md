

# 闪存

**闪存** 是 EEPROM 的衍生概念。它是一种非易失性存储介质，可以被电子擦除和重写。EEPROM 和闪存的主要区别在于，EEPROM 必须完全擦除才能重写，而闪存可以以块或页为单位进行擦除和写入。最常见的闪存类型是 NAND 闪存。它广泛应用于存储卡、U 盘、移动设备和 SSD（固态硬盘）。

## 随机存取存储器

**随机存取存储器 (RAM)** 是可读可写的内存，包含计算机在处理过程中使用的信息。只有在持续供电的情况下，RAM 才能保留其内容。与 ROM 不同，当计算机断电时，存储在 RAM 中的所有数据都会消失。因此，RAM 仅适用于临时存储。关键数据绝不应仅存储在 RAM 中；应始终在另一存储设备上保留备份副本，以防止因突然断电导致数据丢失。以下是 RAM 的类型：

### 实存

**实存**（也称为**主存**或**主存储器**）通常是计算机可用的最大 RAM 存储资源。它通常由若干动态 RAM 芯片组成，因此必须由 CPU 定期刷新（有关更多信息，请参阅侧边栏“动态 RAM 与静态 RAM”）。

### 高速缓存 RAM

计算机系统包含许多缓存，当数据可能被重复使用时，它们通过从较慢的设备获取数据并暂时存储在较快的设备中来提高性能；这就是**高速缓存 RAM**。处理器通常包含一个板载极高速内存缓存，用于存放其将要操作的数据。这可以称为 L1、L2、L3 甚至 L4 缓存（L 代表 level，即级别）。许多现代 CPU 包含多达三级片上缓存，其中一些缓存（通常是 L1 和/或 L2）专用于单个处理器核心，而 L3 可能是核心间共享的缓存。某些 CPU 可能涉及 L4 缓存，它可能位于主板上或 GPU（图形处理单元）上。同样，实存通常也包含存储在磁性介质或 SSD 上的信息的缓存。这一链条沿着内存/存储层级向下延伸，使计算机能够通过将可能接下来要用到的数据保存在更近的地方（无论是用于 CPU 指令、数据获取、文件访问还是其他用途）来提高性能。

许多外设也包含板载缓存，以减轻它们给 CPU 和操作系统带来的存储负担。例如，许多高端打印机包含大容量 RAM 缓存，以便操作系统能快速将整个打印作业脱机输出到打印机。之后，处理器就可以不再理会该打印作业；它无需等待打印机实际生成请求的输出、一次次地喂给它数据块。打印机可以从其板载缓存预处理信息，从而释放 CPU 和操作系统去处理其他任务。许多存储设备，如硬盘驱动器 (HDD)、固态驱动器 (SSD) 和某些 U 盘，都包含缓存以帮助提高读写速度。然而，在断开连接或断电之前，这些缓存必须刷新到永久或辅助存储区，以避免驻留在缓存中的数据丢失。

## 寄存器

CPU 还包含少量板载内存，称为**寄存器**，它们为 CPU 提供直接可访问的内存位置，CPU 的大脑——**算术逻辑单元 (ALU)**——在执行计算或处理指令时会使用这些位置。事实上，除非数据作为指令的一部分直接提供，否则 ALU 要操作的任何数据都必须加载到寄存器中。这种内存的主要优势在于它是 ALU 本身的一部分，因此以典型的 CPU 速度与 CPU 同步运行。

## 内存寻址

在使用内存资源时，处理器必须有某种方法来引用内存中的各个位置。解决此问题的方法称为**寻址**，根据不同情况会使用多种不同的寻址方案。以下是五种较常见的寻址方案：

### 寄存器寻址

正如您在上一节所学，寄存器是 CPU 中直接的小内存位置。当 CPU 需要从其寄存器之一获取信息以完成操作时，它使用**寄存器地址**（例如，“寄存器 1”）来访问其内容。

### 立即寻址

**立即寻址** 本身并非一种内存寻址方案，而是一种将作为指令一部分提供给 CPU 的数据的引用方式。例如，CPU 可能会处理“将 2 加到寄存器 1 中的值”这一命令。该命令使用了两种寻址方案。第一种是立即寻址——CPU 被告知要加上值 2，不需要从内存位置检索该值——它作为命令的一部分被提供。第二种是寄存器寻址；它被指示从寄存器 1 检索值。

### 直接寻址

在**直接寻址**中，CPU 获得要访问的内存位置的实际地址。该地址必须位于与正在执行的指令相同的内存页上。直接寻址比立即寻址更灵活，因为内存位置的内容比立即寻址的硬编码数据更容易修改。

### 间接寻址

**间接寻址** 使用的方案类似于直接寻址。然而，作为指令一部分提供给 CPU 的内存地址不包含 CPU 要用作操作数的实际值。相反，该内存地址包含另一个内存地址（可能位于不同的页上）。CPU 读取间接地址以得知所需数据所在的地址，然后从该地址检索实际的操作数。

### 基址+偏移量寻址

**基址+偏移量寻址** 使用存储在 CPU 寄存器之一中的值作为开始计数的基址位置。CPU 然后将指令提供的偏移量加到该基址上，并从计算出的内存位置检索操作数。

## 辅助存储器

**辅助存储器** 通常用来指代磁性、光学或基于闪存的介质，或其他包含 CPU 不能立即访问的数据的存储设备。为了让 CPU 访问辅助存储器中的数据，操作系统必须先读取数据并将其存储在实存中。然而，辅助存储器比主存便宜得多，可用于存储海量信息。在此背景下，硬盘、闪存驱动器和光学介质（如光盘 (CD)、数字多功能光盘 (DVD) 和蓝光光盘）都可以作为辅助存储器发挥作用。

虚拟内存是一种特殊的辅助存储器，操作系统对其进行管理，使其外观和行为就像实存一样。最常见的虚拟内存类型是大多数操作系统作为其内存管理功能一部分来管理的页面文件。这个特殊格式的文件包含之前存储在内存中但近期未被使用的数据。当操作系统需要访问存储在页面文件中的地址时，它会检查该页面是否驻留在内存中（如果是，可以立即访问），或者它是否已被换出到磁盘，在这种情况下，它会将数据从磁盘读回实存（这个过程称为**换页**）。
