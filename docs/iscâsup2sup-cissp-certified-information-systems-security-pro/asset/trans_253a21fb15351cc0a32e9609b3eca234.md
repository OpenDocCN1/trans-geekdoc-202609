

# 使用安全设计原则实施和管理工程流程

安全性应在系统开发的每个阶段都予以考量。程序员应致力于将安全性构建到他们开发的每个应用程序中，为关键应用程序以及处理敏感信息的应用程序提供更高级别的安全性。从开发项目的早期阶段就考虑其安全影响至关重要，因为将安全性构建*进*系统比向现有系统*添加*安全性要容易得多。以下各节将讨论几项基本的安全设计原则，这些原则应在硬件或软件项目的工程流程早期实施和管理。

## 对象和主体

在安全系统中控制对任何资源的访问涉及两个实体。*主体* 是发出请求以访问资源的用户或进程。访问可以指从资源读取或向资源写入。*对象* 是用户或进程想要访问的资源。请记住，主体和对象是指某个特定的访问请求，因此同一资源在不同的访问请求中既可以充当主体，也可以充当对象。

例如，进程 A 可能会向进程 B 请求数据。为了满足进程 A 的请求，进程 B 必须向进程 C 请求数据。在该示例中，进程 B 是第一个请求的对象，也是第二个请求的主体：

| 第一个请求 | | 进程 A (主体) | | 进程 B (对象) |
| --- | --- | --- | --- | --- |
| 第二个请求 | | 进程 B (主体) | | 进程 C (对象) |

这也是*传递信任*的一个示例。*传递信任* 是指如果 A 信任 B 且 B 信任 C，则 A 通过传递性继承了对 C 的信任——这就像在数学方程中一样：如果 a = b，且 b = c，则 a = c。在前面的示例中，当 A 向 B 请求数据，然后 B 向 C 请求数据时，A 接收到的数据实质上来自 C。传递信任是一个严重的安全问题，因为它可能导致绕过 A 和 C 之间的限制，特别是当 A 和 C 都支持与 B 交互时。一个例子是组织为提高员工工作效率而屏蔽对 Facebook 或 YouTube 的访问。因此，员工 (A) 无法访问特定互联网站点 (C)。然而，如果员工能够访问 Web 代理、虚拟专用网络 (VPN) 或匿名化服务，则这可以作为绕过本地网络限制的手段。换句话说，如果员工 (A) 正在访问 VPN 服务 (B)，而 VPN 服务 (B) 可以访问被屏蔽的互联网服务 (C)；那么 A 就能通过利用传递信任，经由 B 访问 C。

## 闭源系统和开源系统

系统的设计和构建遵循两种不同的理念：*闭源系统* 旨在与有限范围的其他系统良好协作，这些系统通常均来自同一制造商。闭源系统的标准通常是专有的，且不公开披露。另一方面，*开源系统* 是使用商定的行业标准进行设计的。开源系统更容易与支持相同标准的不同制造商的系统集成。

闭源系统较难与异构系统集成，但可能更安全。闭源系统通常由不包含行业标准的专有硬件和软件组成。这种缺乏集成便利性的特性意味着，针对许多通用系统组件的攻击要么无效，要么必须经过定制才能成功。在许多情况下，攻击闭源系统比攻击开源系统更难。许多已知存在漏洞的软件和硬件组件可能不存在于闭源系统中。除了闭源系统缺乏已知易受攻击的组件外，通常还需要具备针对特定目标系统更深入的知识才能发动成功的攻击。

开源系统通常更容易与其他开源系统集成。例如，用一台 Microsoft Windows Server 机器、一台 Linux 机器和一台 Macintosh 机器创建局域网 (LAN) 非常容易。尽管这三台计算机使用不同的操作系统，且可能代表多达三种不同的硬件架构，但每台都支持行业标准，使得网络通信（或其他通信）变得容易。然而，这种便利性是有代价的。因为标准通信组件被纳入了这三个开源系统中的每一个，所以存在更多可预测的入口点和攻击方法。总体而言，它们的开放性使其更容易受到攻击，而其广泛的可用性使得攻击者能够找到（甚至练手）大量潜在目标。此外，开源系统比闭源系统更流行，吸引了更多关注。掌握了基本攻击技能的攻击者会在开源系统上发现比闭源系统更多的目标。这个更大的潜在目标“市场”通常意味着更重视以开源系统为攻击目标。不可否认，关于如何攻击开源系统的共享经验和知识库比闭源系统大得多。

## 确保机密性、完整性和可用性的技术

为保证数据的机密性、完整性和可用性，必须确保所有有权访问数据的组件都是安全且行为良好的。软件设计师使用不同的技术来确保程序仅执行所需操作，不做多余操作。假设一个程序对另一个程序正在使用的内存区域进行写入和读取。第一个程序可能会破坏所有三大安全原则：机密性、完整性和可用性。如果受影响的程序正在处理敏感或机密数据，则无法再保证该数据的机密性。如果数据以不可预测的方式被覆盖或篡改（当多个读取者和写入者无意中访问同一共享数据时，这是常见问题），则无法保证完整性。而且，如果数据修改导致损坏或彻底丢失，则可能导致数据无法在未来使用。虽然以下各节讨论的概念都与软件程序相关，但它们也常用于安全领域的各个方面。例如，物理隔离可确保对硬件的所有物理访问均受到控制。
