

# 理解安全控制的通用特征

安全控制应对用户透明。哈希总计和 CRC 校验可用于验证消息完整性。记录序列用于确保传输的序列完整性。传输日志记录有助于检测通信滥用行为。

# 理解电子邮件安全的工作原理

互联网电子邮件基于 `SMTP`、`POP3` 和 `IMAP`。它本质上是不安全的。虽然可以对其进行保护，但所使用的方法必须在安全策略中加以规定。电子邮件安全解决方案包括使用 `S/MIME`、`MOSS`、`PEM` 或 `PGP`。

# 了解传真安全的工作原理

传真安全主要基于使用加密传输或加密通信线路来保护传真资料。主要目标是防止截获。活动日志和异常报告可用于检测传真活动中的异常，这些异常可能是攻击的症状。

# 了解与 PBX 系统相关的威胁以及应对 PBX 欺诈的对策

应对 PBX 欺诈和滥用的对策包括许多用于保护典型计算机网络的相同预防措施：逻辑或技术控制、管理控制和物理控制。

# 理解与 VoIP 相关的安全问题

VoIP 面临来电显示欺骗、语音钓鱼、SPIT（垃圾互联网电话）、呼叫管理器软件/固件攻击、电话硬件攻击、`DoS`、`MitM`、欺骗和交换机跳转的风险。

# 识别什么是“电话破解者”

电话破解是一种特定类型的攻击，攻击者利用各种技术绕过电话系统，以拨打免费长途电话、更改电话服务功能、窃取专用服务，甚至导致服务中断。电话破解者常用的工具包括黑盒、红盒、蓝盒和白盒。

# 理解语音通信安全

语音通信容易受到多种攻击，尤其是随着语音通信成为网络服务的重要组成部分。您可以通过使用加密通信来获得机密性。必须部署对策以防止截获、窃听、监听和其他类型的利用。请熟悉语音通信主题，如 `POTS`、`PSTN`、`PBX` 和 `VoIP`。

# 能够解释什么是社会工程学

社会工程学是一种手段，陌生人通过说服员工相信其与高层管理人员、技术支持或帮助台有关联，从而获得您组织内部人员的信任。受害者通常会被诱导更改其系统上的用户帐户，例如重置密码，以便攻击者利用它访问网络。针对此类攻击的主要对策是用户培训。

# 解释安全边界的概念

安全边界可以是一个受保护区域与另一个受保护区域之间的划分。它也可以是一个受保护区域与一个未受保护区域之间的划分。这两者都必须在安全策略中加以规定。

# 理解与通信安全相关的各种网络攻击和对策

通信系统容易受到多种攻击，包括分布式拒绝服务 (`DDoS`)、窃听、冒充、重放、篡改、欺骗以及 `ARP` 和 `DNS` 攻击。请能够为每种攻击提供有效的对策。
