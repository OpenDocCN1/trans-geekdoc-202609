

# 服务质量

服务质量控制可保护数据网络在负载下的完整性。许多不同因素都会影响最终用户体验的质量，QoS 试图管理所有这些因素，以创建满足业务要求的体验。

影响 QoS 的部分因素如下：

- **带宽**：可用于承载通信的网络容量。
- **延迟**：数据包从源传输到目的地所需的时间。
- **抖动**：不同数据包之间延迟的变化。
- **丢包**：某些数据包可能在源和目的地之间丢失，需要重新传输。
- **干扰**：电气噪声、设备故障和其他因素可能会破坏数据包的内容。

除了控制这些因素外，QoS 系统通常还会为某些流量类型分配优先级，这些流量类型对干扰的容忍度低和/或具有较高的业务要求。例如，QoS 设备可能会被编程为优先处理来自高管会议室的视频会议流量，而非来自实习生电脑的视频流媒体流量。

# 恢复策略

当灾难中断您的业务时，您的灾难恢复计划应近乎自动地启动，并开始为恢复操作提供支持。灾难恢复计划的设计应使首批到达现场的员工能够立即以有组织的方式开始恢复工作，即使官方 DRP 团队成员尚未抵达现场。在以下章节中，我们将介绍制定有效灾难恢复计划所涉及的关键子任务，该计划可指导常规业务流程的快速恢复以及在主要营业地点恢复活动。

除了提高响应能力外，购买保险还可以降低财务损失的风险。选择保险时，请务必购买足够的保障，以便您能从灾难中恢复。简单的价值保障可能不足以涵盖实际的重置成本。如果您的财产保险包含实际现金价值 (ACV) 条款，则您受损的财产将根据损失当天物品的公平市场价值减去自购买以来的所有累计折旧进行赔偿。这里的关键在于，除非您的保险保障中包含重置成本条款，否则您的组织很可能因遭受的任何损失而自掏腰包。许多保险提供商提供专门承保机密性、完整性和可用性泄露的网络安全责任保单。

贵重文件保险保障为铭文、印刷品、手写文件和手稿及其他印刷业务记录提供保护。但是，它不承保纸币和印刷有价证券的损坏。

## 业务单元和职能优先级

为了以最高可能的效率恢复您的业务运营，您必须设计灾难恢复计划，使优先级最高的业务单元首先得到恢复。您还必须识别关键业务职能并确定其优先级，以便定义灾难或故障后要恢复哪些职能以及恢复的顺序。

为实现这一目标，DRP 团队必须首先识别这些业务单元并就优先级顺序达成一致，同时也必须对业务职能做同样的工作。（请注意：并非所有关键业务职能都一定在关键业务单元中执行，因此该分析的最终结果极有可能包含关键业务单元的超集以及其他选定的单元。）

如果这个过程听起来耳熟，那应该是因为它很熟悉！这非常类似于 BCP 团队在第 3 章讨论的业务影响评估期间执行的优先级排序任务。事实上，大多数组织将完成业务影响评估 (BIA) 作为其业务连续性规划过程的一部分。该分析识别漏洞，制定策略以最小化风险，并最终生成一份 BIA 报告，描述组织面临的潜在风险并识别关键业务单元和职能。BIA 还识别与故障相关的成本，包括现金流损失、设备更换、为清理工作积压而支付的薪资、利润损失、因无法吸引新业务而产生的机会成本等。这些故障从财务、人员、安全、法律合规、合同履行和质量保证等方面的潜在影响进行评估，最好以货币形式表示，以便使影响具有可比性并设定预算预期。掌握所有这些 BIA 信息后，您应将生成的文档作为该优先级排序任务的基础。

该任务的输出至少应是一份按优先级排序的业务单元简单清单。然而，一份按优先级排列的具体业务流程的更详细清单将是更有用的交付成果。这种面向业务流程的清单更能反映现实情况，但需要付出大量额外努力。然而，它将极大地协助恢复工作——毕竟，优先级最高的业务单元执行的并非每项任务都具有最高优先级。您可能会发现，最好将最高优先级的单元恢复到 50% 的产能，然后转向优先级较低的单元，在尝试全面恢复之前，先在整个组织中实现一定的最低运营产能。

同理，必须对关键业务流程和职能完成相同的练习。这些事项不仅可能涉及多个业务单元并跨越它们之间的界限，而且还定义了灾难或其他业务中断后必须恢复的运营要素。这里同样，最终结果应是一份按优先级排序的清单，每项都有自己的风险和成本评估，以及相应的平均恢复时间 (MTTR) 和相关恢复目标及里程碑。这些指标包括一个称为最大可容忍中断时间 (MTO) 的指标。这是业务在不经历重大中断的情况下能够承受服务不可用的最长时间。业务连续性规划人员可以比较 MTTR 和 MTO 值，以识别需要干预和额外控制的情况。

## 危机管理

如果灾难袭击您的组织，恐慌很可能会蔓延。对抗恐慌的最佳方式是制定有组织的灾难恢复计划。您企业中最有可能首先注意到紧急情况的人员（即保安、技术人员等）应充分接受灾难恢复程序培训，并知晓正确的通知程序和即时响应机制。

许多平时看似常识的事情（例如发生火灾时拨打 911）可能会从惊慌失措、寻求逃离紧急情况的员工脑海中溜走。对抗这种情况的最佳方式是持续开展灾难恢复职责培训。回到火灾的例子，所有员工都应接受培训，在发现火灾时拉响火警警报或联系紧急救援官员（当然，前提是先采取适当措施保护自己）。毕竟，消防部门接到 10 个报告贵单位失火的电话，总比所有人都假设别人已经处理了要好。

危机管理是一门科学，也是一门艺术。如果您的培训预算允许，为关键员工投资危机培训是个好主意。这能确保您至少有一些员工知道如何妥善处理紧急情况，并能为惊恐的同事提供至关重要的“现场”领导力。
