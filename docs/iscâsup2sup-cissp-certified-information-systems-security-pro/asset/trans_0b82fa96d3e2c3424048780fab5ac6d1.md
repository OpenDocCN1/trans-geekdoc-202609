

# 安全治理

安全治理需要涵盖组织的各个方面。这包括收购、剥离和治理委员会等组织流程。收购和合并会使组织面临更高水平的风险。此类风险包括不当的信息披露、数据丢失、停机或无法实现足够的投资回报率（ROI）。除了合并和收购中所有典型的业务和财务方面外，适度的安全监督和加强审查往往对于降低此类转型期间发生损失的可能性至关重要。

同样，剥离或任何形式的资产或员工裁减也是风险增加的时期，因此需要更加专注的安全治理。资产需要经过清理以防止数据泄露。存储介质应被移除并销毁，因为介质清理技术无法保证防止数据残留恢复。离职员工需要接受离职简报。此过程通常称为离职面谈。此过程通常涉及审查任何保密协议，以及雇佣关系终止后仍将继续生效的任何其他具有约束力的合同或协议。

对强大的安全治理至关重要的组织流程还有两个例子：变更控制/变更管理和数据分类。

## 变更控制/管理

安全管理的另一个重要方面是对变更的控制或管理。在安全环境中，变更可能会引入漏洞、重叠、缺失对象和疏忽，从而导致新的脆弱性。面对变更，维持安全的唯一方法是系统地管理变更。这通常涉及与安全控制和机制相关的活动的大量规划、测试、记录、审计和监控。环境变更记录随后被用于识别变更因子，无论这些因子是对象、主体、程序、通信路径，甚至是网络本身。

`变更管理`的目标是确保任何变更都不会导致安全性降低或受损。变更管理还负责使任何变更都能回滚到之前的安全状态。无论安全级别如何，变更管理都可以在任何系统上实施。归根结底，变更管理通过保护已实施的安全免受无意的、间接的或受影响的安全降低，从而提高环境的安全性。虽然变更管理的一个重要目标是防止安全性的意外降低，但其主要目的是使所有变更都接受详细的文档记录和审计，从而能够被管理层审查和监督。

变更管理应用于监督系统各方面的变更，包括硬件配置、操作系统（OS）和应用软件。变更管理应包含在设计、开发、测试、评估、实施、分发、演进、增长、持续运行和修改中。它需要每个组件和配置的详细清单。它还要求收集和维护每个系统组件的完整文档，从硬件到软件，从配置设置到安全功能。

配置管理或变更管理的变更控制流程有若干目标或要求：

*   以受监控且有序的方式实施变更。变更始终受到控制。
*   包含正式的测试流程，以验证变更是否产生预期结果。
*   所有变更均可逆转（也称为回退或回滚计划/程序）。
*   在变更发生前通知用户，以防止生产力损失。
*   系统地分析变更的影响，以确定安全或业务流程是否受到负面影响。
*   将变更对能力、功能和性能的负面影响降至最低。
*   变更由`变更咨询委员会 (CAB)`审查和批准。

变更管理流程的一个例子是并行运行，这是一种新系统部署测试，其中新系统和旧系统并行运行。在每个系统上同时执行每个主要或重要的用户流程，以确保新系统支持旧系统所支持或提供的所有必需业务功能。

## 数据分类

`数据分类`或分级，是根据数据对保密性、敏感性或机密性的需求来保护数据的主要手段。在设计和实施安全系统时，如果对所有数据一视同仁，则效率低下，因为某些数据项需要比其他数据更多的安全保护。以低安全级别保护所有内容意味着敏感数据易于访问。以高安全级别保护所有内容成本过高，且会限制对非机密、非关键数据的访问。数据分类用于确定为保护数据和控制访问而分配多少精力、资金和资源。数据分类或分级，是将项目、对象、主体等按相似性组织成组、类别或集合的过程。这些相似性可能包括价值、成本、敏感度、风险、脆弱性、权限、特权、可能的损失或损害程度，或知情需求。

数据分类方案的主要目标是，根据分配的重要性和敏感度标签，将保护数据的过程正式化和分层化。数据分类用于为数据的存储、处理和传输提供安全机制。它还涉及如何从系统中移除和销毁数据。

使用数据分类方案有以下好处：

*   它证明了组织致力于保护有价值的资源和资产。
*   它有助于识别对组织最关键或最有价值的资产。
*   它为选择保护机制提供了依据。
*   它通常是法规遵从性或法律限制所要求的。
*   它有助于定义访问级别、授权使用类型，以及不再有价值的资源的解密和/或销毁参数。
*   它有助于数据生命周期管理，这部分包括数据的存储长度（保留期）、使用和销毁。

数据分类的标准因执行分类的组织而异。然而，您可以从通用或标准化的分类系统中归纳出许多共性：

*   数据的有用性
*   数据的时效性
*   数据的价值或成本
*   数据的成熟度或期限
*   数据的生命周期（或过期时间）
*   与人员的关联
*   数据披露损害评估（即数据披露将如何影响组织）
*   数据修改损害评估（即数据修改将如何影响组织）
*   数据的国家安全影响
*   数据的授权访问（即谁有权访问数据）
*   数据的访问限制（即谁被限制访问数据）
*   数据的维护和监控（即谁应维护和监控数据）
*   数据的存储

使用适合组织的任何标准，对数据进行评估，并分配适当的数据分类标签。在某些情况下，标签会被添加到数据对象上。在其他情况下，当数据被放入存储机制或置于安全保护机制后时，标签会自动生成。
