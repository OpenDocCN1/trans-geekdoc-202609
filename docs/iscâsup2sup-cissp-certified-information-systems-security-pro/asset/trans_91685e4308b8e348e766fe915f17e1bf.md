## 调查

每一位信息安全专业人员都会在某个时候遇到需要调查的安全事件。在许多情况下，这种调查将是简短的、非正式的，以确定该事件是否严重到足以采取进一步行动或涉及执法部门。然而，在某些情况下，所构成的威胁或造成的损害将足够严重，需要进行更正式的调查。当这种情况发生时，调查人员必须小心确保遵循正确的程序。未能遵守正确程序可能会侵犯被调查个人的公民权利，并可能导致起诉失败，甚至针对调查人员的法律行动。

### 调查类型

安全从业者可能会因各种原因进行调查。其中一些调查涉及执法部门，必须遵循旨在产生法庭可采纳证据的严格标准。其他调查支持内部业务流程，所需严谨性要低得多。

#### 行政调查

行政调查是内部调查，旨在检查运营问题或违反组织政策的行为。它们可以作为技术故障排除工作的一部分，或支持其他行政流程（如人力资源纪律程序）而进行。

运营调查检查与组织计算基础设施相关的问题，其主要目标是解决运营问题。例如，信息技术（IT）团队发现其 Web 服务器存在性能问题，可能会进行运营调查以确定性能问题的原因。

运营调查对信息收集的标准最为宽松。它们不旨在产生证据，因为它们仅用于内部运营目的。因此，进行运营调查的管理员将仅进行得出运营结论所需的分析。收集过程无需彻底或有详细记录，因为解决问题是主要目标。
