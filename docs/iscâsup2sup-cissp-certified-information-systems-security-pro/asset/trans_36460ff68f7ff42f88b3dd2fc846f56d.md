

# 生日攻击

*生日攻击*专注于寻找碰撞。其名称源于一种称为生日悖论的统计现象。生日悖论指出，如果一个房间里有 23 个人，那么其中任意两人的生日相同（指月份和日期相同，如 3 月 30 日，而非同年）的概率为 50%。

考虑到闰年的 2 月 29 日，一年只有 366 种可能的日期。如果房间里有 367 个人，那么至少有两人生日相同的概率为 100%。将人数减少到仅 23 人，任意两人生日相同的概率仍为 50%。

这类似于寻找具有相同哈希值的任意两个密码。如果一个哈希函数只能生成 366 个不同的哈希值，那么拥有仅 23 个哈希样本的攻击者就有 50% 的几率发现两个产生相同哈希值的密码。哈希算法能生成的不同哈希值远多于 366 个，但关键在于生日攻击方法不需要遍历所有可能的哈希值就能找到匹配项。

从另一个角度来看，假设你是房间里的人之一，想找一个和你生日相同的人。在这个例子中，房间里需要有 253 人，才能达到找到另一个与你生日相同的人的概率为 50%。

同样，某些工具也可以找出另一个能产生给定哈希值相同哈希值的密码。例如，如果你知道管理员账户密码的哈希值是 `1A5C7G`，某些工具可以识别出一个能产生相同哈希值 `1A5C7G` 的密码。这不一定是同一个密码，但如果它能产生相同的哈希值，它就和原密码一样有效。

你可以通过使用具有足够位数以使碰撞在计算上不可行的哈希算法，以及使用盐值（在下一节“彩虹表攻击”中讨论）来降低生日攻击的成功率。曾有一段时间，安全专家认为 `MD5`（使用 128 位）是无碰撞的。然而，算力持续提升，`MD5` 已不再无碰撞。`SHA-3`（安全哈希算法版本 3 的简称）最多可使用 512 位，目前被认为能抵御生日攻击和碰撞——至少目前如此。算力持续提升，因此未来 `SHA-3` 终将被另一种具有更长哈希值和/或更强密码学方法创建哈希的哈希算法所取代。

## 彩虹表攻击

通过猜测密码、对其进行哈希运算，然后将其与有效的密码哈希进行比较来寻找密码，这需要很长时间。然而，*彩虹表*通过使用预计算哈希值的大型数据库来缩短这一时间。攻击者猜测密码（使用字典法或暴力破解法），对其进行哈希运算，然后将猜测的密码及其哈希值同时存入彩虹表中。

密码破解工具随后可以将彩虹表中的每个哈希值与被盗密码数据库文件中的哈希值进行比较。传统的密码破解工具必须先猜测密码并对其进行哈希运算，然后才能比较哈希值，这需要时间。然而，使用彩虹表时，密码破解工具不需要花费任何时间去猜测和计算哈希值。它只需比较哈希值直到找到匹配项。这可以显著缩短破解密码所需的时间。

许多系统通常会对密码进行*加盐*，以减弱彩虹表攻击的效果。盐值是在对密码进行哈希运算前添加的一组随机位。加密方法在哈希前添加这些额外的位，使得攻击者难以利用彩虹表攻击密码。`Bcrypt` 和 `基于密钥派生函数 2 (PBKDF2)` 是两种常用的给密码加盐的算法。

然而，给予足够的时间，攻击者仍可使用暴力破解攻击破解加盐密码。在加盐密码中添加胡椒值可增加安全性，使其更难破解。盐值是存储在保存哈希密码的同一数据库中的随机数，因此如果攻击者获取了数据库，也就获得了密码的盐值。*胡椒值*是一个存储在别处的大常数，例如服务器上的配置值或存储在应用程序代码中的常量。

虽然加盐做法最初是专门为了挫败彩虹表攻击而引入的，但它也阻碍了离线字典攻击和暴力破解攻击的有效性。这些离线攻击必须计算猜测密码的哈希值，如果存储的密码包含盐值，除非攻击者也发现了盐值，否则攻击就会失败。同样，将胡椒值存储在保存加盐哈希密码的数据库之外，会使所有这些攻击变得更加困难。

## 嗅探攻击

*嗅探*是指捕获网络上发送的数据包以分析这些数据包。嗅探器（也称为数据包分析器或协议分析器）是一种捕获网络上传输流量的软件应用程序。管理员使用嗅探器分析网络流量并排查问题。

当然，攻击者也可以使用嗅探器。*嗅探攻击*（也称为窥探攻击或偷听攻击）发生在攻击者使用嗅探器捕获网络上传输的信息时。他们可以捕获并读取以明文形式通过网络发送的任何数据，包括密码。

`Wireshark` 是一款流行的协议分析器，可免费下载。[图 14.4](#c14.xhtml#figure14-4) 展示了一个相对较小的捕获内容的 `Wireshark` 界面，演示了攻击者如何捕获并读取通过网络以明文发送的数据。

以下技术可以防止成功的嗅探攻击：

*   加密通过网络发送的所有敏感数据（包括密码）。攻击者无法轻易使用嗅探器读取加密数据。例如，`Kerberos` 对票据进行加密以防止攻击，攻击者无法轻易使用嗅探器读取这些票据的内容。
*   当无法或不可行进行加密时，使用一次性密码。一次性密码可防止嗅探攻击成功，因为它们仅使用一次。即使攻击者捕获了一次性密码，也无法使用它。
*   使用物理安全保护网络设备。控制对路由器和交换机的物理访问，可防止攻击者在这些设备上安装嗅探器。
*   监控网络中的嗅探器特征。入侵检测系统可监控网络中的嗅探器，并在检测到网络上有嗅探器时发出警报。

## 欺骗攻击

*欺骗*（也称为伪装）是指假装成其他事物或他人。欺骗攻击种类繁多。例如，攻击者可以使用他人的凭证进入建筑物或访问 IT 系统。某些应用程序会伪造合法的登录屏幕。有一次攻击弹出了一个与操作系统登录屏幕完全相同的登录屏幕。当用户输入凭证时，虚假应用程序捕获了用户的凭证，攻击者稍后加以利用。某些网络钓鱼攻击（本节后面将介绍）通过伪造网站模仿这种手法。
