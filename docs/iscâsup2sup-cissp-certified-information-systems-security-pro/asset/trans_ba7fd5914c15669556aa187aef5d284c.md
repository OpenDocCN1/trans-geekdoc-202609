

# Sybex 赠送的模拟练习考试

Sybex 包含赠送的模拟练习考试，每套试题旨在考察您对 CISSP CBK（通用知识体系）关键要素的理解。本书提供六套赠送考试，每套包含 150 道题目，以匹配真实考试可能的最长长度。这些考试可在 [http://www.wiley.com/go/sybextestprep](http://sybextestbanks.wiley.com) 以数字形式获取。

## 如何使用本书的学习工具

本书具有多项功能，旨在指导您为 CISSP 认证考试的学习工作。它通过在每章开头列出本章涵盖的 CISSP 通用知识体系领域主题，并确保每个主题在章节内得到充分讨论，来为您提供帮助。每章末尾的复习题和模拟考试旨在测试您对所读材料的掌握程度，以确保您了解需要花费额外学习时间的领域。以下是使用本书和学习工具（位于 [www.wiley.com/go/cissptestprep](http://sybextestbanks.wiley.com)）的一些建议：

*   在开始阅读材料前参加评估测试。这将让您了解需要在哪些领域花费额外学习时间，以及哪些领域可能只需要简要复习。
*   阅读完每章后回答复习题；如果答错任何题目，请返回该章复习该主题，或在需要更多信息时利用额外资源。
*   将闪存卡下载到您的移动设备，在白天有几分钟空闲时复习它们。
*   抓住一切机会测试自己。除了评估测试和复习题外，随附的额外学习工具中还包含赠送的模拟练习考试。在不参考章节内容的情况下参加这些考试，看看您的表现如何——返回复习您错过的任何主题，直到您完全理解并能应用这些概念。

最后，如果可能的话，找一个学习伙伴。与他人一起备考和参加考试会使过程更愉快，并且您会有人帮助您理解对您而言困难的主题。您还能通过在学习伙伴薄弱环节给予帮助来巩固自己的知识。
