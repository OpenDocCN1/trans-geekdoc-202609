

# IP 欺骗攻击

在 IP 欺骗攻击中，攻击者将有效的源 IP 地址替换为虚假地址，以隐藏其身份或冒充受信任的系统。访问控制攻击中使用的其他类型的欺骗包括电子邮件欺骗和电话号码欺骗。

## 电子邮件欺骗

垃圾邮件发送者通常会欺骗 `From` 字段中的电子邮件地址，使电子邮件看起来像是来自另一个来源。网络钓鱼攻击经常这样做，以诱使用户认为该电子邮件来自受信任的来源。`Reply To` 字段可以是不同的电子邮件地址，电子邮件程序通常不会显示此字段，直到用户回复该电子邮件。到那时，他们往往会忽略它或没有注意到它。

## 电话号码欺骗

来电显示服务允许用户识别来电者的电话号码。电话号码欺骗允许来电者将此号码替换为另一个号码，这是互联网协议语音 (VoIP) 系统上常用的一种技术。攻击者最近一直在使用的一种技术是，将实际来电号码替换为包含与被叫号码相同区号的电话号码。这使其看起来像是一个本地来电。

## 社会工程学攻击

有时，获取某人密码最简单的方法就是直接询问，这是社会工程师常用的手段。**社会工程学** 是指攻击者试图通过欺骗手段（如虚假奉承或冒充身份）或奸诈行为，获取某人的信任。攻击者试图诱骗人们泄露他们通常不会透露的信息，或执行他们通常不会执行的操作。通常，社会工程师的目标是获取对 IT 基础设施或物理设施的访问权限。

例如，熟练的社会工程师可以说服一名未受过安全教育的服务台员工，声称他们与高层管理人员有关联且正在远程工作，但忘记了密码。如果被骗，该员工可能会重置密码并将新密码提供给攻击者。其他时候，社会工程师会诱骗普通用户泄露自己的密码，从而让攻击者获得对用户账户的访问权限。教育员工了解常见的社会工程学战术，可以降低此类攻击的有效性。

社会工程学攻击可能通过电话、当面或电子邮件发生。当面攻击时，恶意人员通常冒充维修技术人员（如电话维修技术人员）以获取物理访问权限。如果他们获得了对网络基础设施的访问权限，随后可以安装嗅探器来捕获敏感数据。在提供访问权限前验证访客身份，可以缓解此类冒充攻击。

有时，社会工程师只是试图从个人肩膀上方窥视，以读取计算机屏幕上的信息，或观察用户打字时的键盘。这通常被称为**肩窥**。放置在显示器上的屏幕滤光片可以限制攻击者的视线。此外，密码掩码（显示星号等替代字符，而不是实际的密码字符）常用于缓解肩窥。

### 网络钓鱼

**网络钓鱼** 是一种社会工程学形式，旨在诱骗用户泄露敏感信息、打开附件或点击链接。它通常通过伪装成合法公司，试图获取用户凭证或个人身份信息 (PII)，如用户名、密码或信用卡详细信息。攻击者将网络钓鱼邮件作为垃圾邮件无差别发送，不知道谁会收到，但希望有些用户会做出回应。网络钓鱼邮件有时会告知用户一个虚假的问题，并声称如果用户不采取行动，公司将锁定用户的账户。例如，邮件可能声称公司检测到账户上有可疑活动，除非用户验证用户名和密码信息，否则公司将锁定该账户。

简单的网络钓鱼攻击会告知用户存在问题，并要求收件人通过电子邮件回复其用户名、密码和其他详细信息。`From` 电子邮件地址通常被欺骗得看起来合法，但 `Reply To` 电子邮件地址是攻击者控制的账户。复杂的攻击包含指向虚假网站的链接，这些网站看起来很合法。例如，如果网络钓鱼邮件描述了 PayPal 账户的问题，该虚假网站看起来就会像 PayPal 网站。如果用户输入凭证，该网站会捕获它们并传递给攻击者。

其他时候，发送网络钓鱼邮件的目的是在用户系统上安装恶意软件。邮件可能包含受感染的文件（如附件），并鼓励用户打开它。邮件可能包含指向网站的链接，该网站会在用户不知情的情况下安装恶意的**路过式下载**。

一些恶意网站试图诱骗用户下载并安装软件。例如，近年来勒索软件在攻击者中变得非常流行。勒索软件是一种控制用户系统或数据并阻止用户访问的恶意软件，直到用户支付费用或赎金。攻击者通过恶意附件和路过式下载投放它，并通过鼓励用户下载并安装软件来传播它。

攻击者在制作网络钓鱼邮件时，经常利用社交媒体来识别人与人之间的友谊或关系。例如，假设你有一个在社交媒体网站上非常活跃的妹妹，并且你与她建立了联系。攻击者会注意到这种联系，然后发送带有欺骗性电子邮件地址的邮件给你，使其看起来像是你妹妹发的。这些邮件通常只有一行字，如“看看这个”或“我觉得你可能会喜欢这个”。点击链接会将你带到一个恶意网站，该网站会尝试进行路过式下载。

人员可以通过遵循一些简单的规则来避免一些与网络钓鱼相关的常见风险：

*   对意外的电子邮件或来自未知发件人的电子邮件保持怀疑。
*   切勿打开意外的电子邮件附件。
*   切勿通过电子邮件共享敏感信息。
*   对电子邮件中的任何链接保持怀疑。

网络钓鱼攻击有几种变体，包括鱼叉式网络钓鱼、鲸钓和语音钓鱼。

#### 鱼叉式网络钓鱼

**鱼叉式网络钓鱼** 是一种针对特定用户群体的网络钓鱼形式，例如特定组织内的员工。它可能看起来源自组织内的同事或同事，或来自外部来源。

例如，攻击者利用 Adobe PDF 文件中的零日漏洞，该漏洞允许他们嵌入恶意代码。如果用户打开该文件，它会在用户系统上安装恶意软件。攻击者将该 PDF 文件命名为类似“合同指南”的名称，并在邮件中说明它提供了关于合同授标流程的更新信息。他们将邮件发送给知名政府承包商（如洛克希德·马丁公司）的目标电子邮件地址。如果任何承包商打开了该文件，它就会在他们的系统上安装恶意软件，使攻击者能够远程访问受感染的系统。

#### 鲸钓

**鲸钓** 是一种针对高级管理人员（如公司首席执行官 (CEO) 和总裁）的网络钓鱼变体。一次著名的鲸钓攻击以姓名标识了约 20,000 名高级企业高管，并声称他们被传唤出席大陪审团。邮件包含一个链接以获取有关传票的更多信息。如果高管点击了该链接，网站上的消息会提示高管需要安装浏览器插件才能阅读该文件。

批准安装该插件的高管在其系统上安装了恶意软件，该软件记录他们的击键，捕获他们访问的不同网站的登录凭证。它还给了攻击者对高管系统的远程访问权限，允许攻击者安装额外的恶意软件，或读取系统上的所有数据。
