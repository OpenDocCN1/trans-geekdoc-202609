

# 安全基线

安全基线提供了一组安全控制，组织可将其作为安全的起点来实施。某些出版物（如 `NIST SP 800-53`）规定了安全控制基线。然而，这些基线并不平等地适用于所有组织。相反，组织会使用范围界定和裁剪技术来确定要在其基线中实施的安全控制。此外，组织还会确保实施适用于其组织的外部标准所强制要求的安全控制。

## 考试重点

**理解数据和资产分类的重要性。** 数据所有者负责定义数据和资产分类，并确保数据和系统被正确标记。此外，数据所有者定义保护不同分类数据的要求，例如对静态和传输中的敏感数据进行加密。数据分类通常在安全策略或数据策略中定义。

**了解 PII 和 PHI。** 个人身份信息（`PII`）是指任何可用于识别个人身份的信息。受保护的健康信息（`PHI`）是指任何可与特定个人关联的健康相关信息。许多法律法规强制要求保护 `PII` 和 `PHI`。

**了解如何管理敏感信息。** 敏感信息是指任何类型的机密信息，妥善管理有助于防止未经授权的披露导致机密性丧失。妥善管理包括标记、处理、存储和销毁敏感信息。组织经常疏忽的两个方面是：充分保护存放敏感信息的备份介质，以及在介质或设备生命周期结束时对其进行清理。

**理解记录保留。** 记录保留策略确保数据在需要时保持可用状态，在不再需要时被销毁。许多法律法规强制要求保存数据特定的时间，但在没有正式法规的情况下，组织会在策略中指定保留期限。审计追踪数据需要保留足够长的时间以重建过去的事件，但组织必须确定他们想要追溯调查的时间范围。许多组织的当前趋势是通过实施针对电子邮件的短保留策略来降低法律责任。

**了解不同角色的区别。** 数据所有者是负责对数据进行分类、标记和保护的人员。系统所有者负责处理数据的系统。业务和任务所有者拥有流程，并确保系统为组织提供价值。数据处理者通常是代表组织处理数据的第三方实体。管理员根据数据所有者提供的指导方针授予数据访问权限。用户在执行工作任务时访问数据。保管员承担保护和存储数据的日常职责。

**理解 GDPR 安全控制。** 欧盟《通用数据保护条例》（`GDPR`）强制要求保护隐私数据。`GDPR` 中提到的两项关键安全控制是加密和假名化。假名化是用假名替换某些数据元素的过程。这使得识别个人变得更加困难。

**了解安全控制基线。** 安全控制基线提供了一份组织可作为基线应用的控制清单。并非所有基线都适用于所有组织。然而，组织可以应用范围界定和裁剪技术，将基线调整为适应其需求。
