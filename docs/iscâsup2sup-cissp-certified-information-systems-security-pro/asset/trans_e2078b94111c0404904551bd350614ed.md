

# 安全解决方案中的防火墙

防火墙只是整体安全解决方案的一部分。有了防火墙，许多安全机制都集中在一个地方，因此防火墙可能成为单点故障。防火墙故障最常见的原因是人为错误和配置错误。防火墙仅为跨越防火墙从一个子网传输到另一个子网的流量提供保护。它们无法为子网内部的流量（换句话说，位于防火墙后面的流量）提供保护。

## 防火墙的类型

防火墙有几种基本类型，包括静态包过滤防火墙、应用层网关防火墙、电路层网关防火墙和状态检测防火墙。还可以通过将两种或多种防火墙类型组合到单一防火墙解决方案中，来创建混合或复杂的网关防火墙。在大多数情况下，多级防火墙能提供对流量过滤更强的控制。无论如何，我们将介绍各种防火墙类型，并讨论防火墙部署架构：

### 静态包过滤防火墙

`静态包过滤防火墙`通过检查消息头中的数据来过滤流量。通常，规则涉及源地址、目的地址和端口地址。使用静态过滤时，防火墙无法提供用户身份验证，也无法判断数据包源自内部还是外部私有网络，且容易被欺骗数据包愚弄。静态包过滤防火墙被称为第一代防火墙；它们在 OSI 模型的第 3 层（网络层）运行。它们也被称为`筛选路由器`。

### 应用层网关防火墙

`应用层网关防火墙`也称为代理防火墙。`代理`是一种将数据包从一个网络复制到另一个网络的机制；复制过程还会更改源地址和目的地址，以保护内部或私有网络的身份。应用层网关防火墙根据用于传输或接收数据的互联网服务（换句话说，即应用程序）来过滤流量。每种类型的应用程序都必须有其自己独特的代理服务器。因此，应用层网关防火墙由许多单独的代理服务器组成。这种类型的防火墙会对网络性能产生负面影响，因为每个数据包在通过防火墙时都必须被检查和处理。应用层网关被称为第二代防火墙，它们在 OSI 模型的应用层（第 7 层）运行。

### 电路层网关防火墙

`电路层网关防火墙`用于在受信任的合作伙伴之间建立通信会话。它们在 OSI 模型的会话层（第 5 层）运行。`SOCKS`（源自 `Socket Secure`，即 TCP/IP 端口）是电路层网关防火墙的常见实现。电路层网关防火墙也称为`电路代理`，它们根据电路而非流量内容来管理通信。它们仅根据通信电路的端点标识（即源地址和目的地址以及服务端口号）来允许或拒绝转发决策。电路层网关防火墙被视为第二代防火墙，因为它们代表了应用层网关防火墙概念的一种修改。

### 状态检测防火墙

`状态检测防火墙`（也称为`动态包过滤防火墙`）评估网络流量的状态或上下文。通过检查源地址和目的地址、应用程序用法、来源以及当前数据包与同一会话中前序数据包之间的关系，状态检测防火墙能够为授权用户和活动授予更广泛的访问权限，并主动监视和阻止未授权用户和活动。状态检测防火墙的运行效率通常高于应用层网关防火墙。它们被称为第三代防火墙，并在 OSI 模型的网络层和传输层（第 3 层和第 4 层）运行。

### 深度包检测防火墙

`深度包检测 (DPI) 防火墙`是一种通常在应用层运行的过滤机制，旨在根据通信的有效载荷内容进行过滤，而不仅仅基于头部值。DPI 也称为完全包检测和信息提取 (IX)。DPI 过滤能够阻止通信有效载荷中的域名、恶意软件、垃圾邮件或其他可识别元素。DPI 通常与应用层防火墙和/或状态检测防火墙集成。

### 下一代防火墙

下一代防火墙是一种多功能设备 (MFD)，除防火墙外还包含多种安全功能；集成组件可包括 IDS、入侵防御系统 (IPS)、TLS/SSL 代理、Web 过滤、QoS 管理、带宽限制、NAT、VPN 终结和防病毒。

## 多宿主防火墙

某些防火墙系统拥有多个接口。例如，`多宿主防火墙`必须至少有两个接口来过滤流量（它们也被称为双宿主防火墙）。所有多宿主防火墙都应禁用 IP 转发，IP 转发会自动将流量发送到另一个接口。这将强制过滤规则控制所有流量，而不是允许一个接口与另一个接口之间通过软件支持的捷径进行通信。`堡垒主机`是一台暴露在互联网上并已加固的计算机或设备，加固方式是移除所有不必要的元素，如服务、程序、协议和端口。`屏蔽主机`是受防火墙保护的系统，在逻辑上位于私有网络内部。所有入站流量都被路由到屏蔽主机，后者反过来充当私有网络内所有受信任系统的代理。它负责过滤进入私有网络的流量，以及保护内部客户端的身份。

屏蔽子网的概念与屏蔽主机类似，不同之处在于子网被置于两个路由器或防火墙之间，而堡垒主机位于该子网内。所有入站流量都被定向到堡垒主机，只有授权流量才能通过第二个路由器/防火墙进入私有网络。这创建了一个子网，允许某些外部访问者与网络提供的资源进行通信。这就是 DMZ 的概念，DMZ 是一个网络区域（通常是一个子网），设计为允许外部访问者访问，但仍与组织的私有网络隔离。DMZ 通常托管公共 Web、电子邮件、文件和其他资源服务器。

## 防火墙部署架构

有三种常见的防火墙部署架构：单层、双层和三层（也称为多层）。

正如您在[图 11.8](#c11.xhtml#figure11-8)中所见，单层部署将私有网络置于防火墙之后，防火墙再通过路由器连接到互联网（或其他不受信网络）。单层部署仅对通用攻击有用。这种架构仅提供最低限度的保护。

双层部署架构可能采用两种不同的设计之一。一种使用具有三个或更多接口的防火墙。另一种使用两个串联的防火墙。这允许设置 DMZ 或公开可访问的外联网。在第一种设计中，DMZ 位于主防火墙的其中一个接口上；而在第二种设计中，DMZ 位于两个串联防火墙之间。DMZ 用于托管外部用户应有权访问的信息服务器系统。防火墙根据其严格的过滤规则将流量路由到 DMZ 或受信网络。这种架构引入了中等程度的路由和过滤复杂性。
