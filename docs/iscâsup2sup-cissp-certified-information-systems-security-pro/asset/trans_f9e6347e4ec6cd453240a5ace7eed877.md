## 比较访问控制模型

第 13 章重点关注识别和认证。在对主体进行认证后，下一步是授权。授权主体访问客体的方法因 IT 系统所使用的访问控制方法而异。

### 比较权限、权利和特权

在学习访问控制主题时，你会经常遇到*权限*、*权利*和*特权*这些术语。有些人会交替使用这些术语，但它们并不总是意味着同一件事。

**权限** 通常情况下，权限是指授予客体的访问权，它决定了你可以对该客体做什么。如果你对某个文件拥有读取权限，就能打开并读取它。你可以授予用户在文件服务器上创建、读取、编辑或删除文件的权限。同样，你也可以授予用户访问文件的访问权，因此在这种情况下，访问权和权限是同义词。例如，你可能被授予某应用程序文件的读取和执行权限，这赋予了你运行该应用程序的权利。此外，你可能被授予数据库中的数据权利，允许你检索或更新数据库中的信息。

**权利** 权利主要是指对客体执行操作的能力。例如，用户可能拥有修改计算机系统时间的权利，或恢复备份数据的权利。这是一个微妙的区别，并不总是被强调。然而，你很少会看到将对系统执行操作的权利称为权限。

**特权** *特权*是权利和权限的组合。例如，计算机的管理员将拥有完全特权，授予管理员对计算机的完全权利和权限。管理员将能够执行任何操作并访问计算机上的任何数据。

## 复习题

1.  保护系统和数据的机密性、完整性和可用性。

2.  确保只有有效的客体可以在系统上进行认证。

3.  防止未经授权访问主体。

4.  确保所有主体都经过认证。

5.  用户使用登录 ID 和密码登录。登录 ID 的目的是什么？

    1.  认证
    2.  授权
    3.  审计/问责
    4.  标识

6.  问责制需要以下所有项目，但有一项除外。哪一项不是问责制所必需的？

    1.  标识
    2.  认证
    3.  审计
    4.  授权

7.  可以使用什么来防止用户在两个密码之间轮换使用？

    1.  密码复杂度
    2.  密码历史
    3.  密码使用期限
    4.  密码长度

8.  以下哪项*最能*说明口令的优势？

    1.  它很短。
    2.  它易于记忆。
    3.  它包含单一字符集。
    4.  它易于破解。

9.  以下哪项是类型 2 认证因素的示例？

    1.  你所拥有的东西
    2.  你的生理特征
    3.  你的行为特征
    4.  你所知晓的东西

10. 你的组织向员工发放设备。这些设备每 60 秒生成一次一次性密码。组织内部托管的服务器在任何给定时间都知道该密码是什么。这是什么类型的设备？

    1.  同步令牌
    2.  异步令牌
    3.  智能卡
    4.  通用访问卡

11. 以下哪项基于主体的物理特征提供认证？

    1.  账户 ID
    2.  生物识别
    3.  令牌
    4.  PIN 码

12. 生物识别设备的 CER（交叉错误率）表示什么？

    1.  它表示灵敏度过高。
    2.  它表示灵敏度过低。
    3.  它表示拒真率等于认假率的点。
    4.  当其足够高时，表示生物识别设备具有高度准确性。

13. Sally 拥有一个用户账户，之前曾使用生物识别系统登录。今天，生物识别系统未能识别出她，导致她无法登录。*最能*描述这种情况的是什么？

    1.  拒真
    2.  认假

    1.  机密性
    2.  完整性
    3.  认证
    4.  审计/问责

### 第 18 和 19 题场景

一名管理员在一个组织工作了 10 多年。他在公司内部不同的 IT 部门之间流动，并保留了他在任职期间担任的每份工作的特权。最近，主管因他对系统进行未经授权的更改而训斥他。他再次进行了一次未经授权的更改，导致意外停机，管理层决定终止他的雇佣关系。第二天，他回到公司清理办公桌和个人物品，在此期间他安装了一个恶意脚本，该脚本计划在下个月的第一天作为逻辑炸弹运行。该脚本将更改管理员密码、删除文件，并关闭数据中心的 100 多台服务器。

18. 在该管理员的受雇期间，违反了以下哪项基本原则？

    1.  默认拒绝
    2.  可用性丧失
    3.  防御性特权
    4.  最小权限

19. 在他受雇期间，什么本可以发现该用户账户的问题？

    1.  要求强认证的策略
    2.  多因素认证
    3.  日志记录
    4.  账户审查
