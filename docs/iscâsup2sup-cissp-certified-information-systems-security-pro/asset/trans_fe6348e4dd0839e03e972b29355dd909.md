
# 数据库分区与多实例化

管理员可能会采用**数据库分区**来规避聚合和推理漏洞，这些漏洞将在本章后面的“聚合”部分讨论。数据库分区是将单个数据库拆分为多个部分的过程，每个部分具有唯一且不同的安全级别或内容类型。

**多实例化**，在数据库上下文中，是指同一关系数据库表中的两行或多行似乎具有相同的主键元素，但包含供不同分类级别使用的不同数据。它常被用作防御某些类型推理攻击的手段（参见第9章中的“推理”）。

考虑一个包含多艘巡逻海军舰艇位置的数据库表。通常，该数据库在机密级别存储每艘舰艇的确切位置。然而，有一艘特定的舰艇——`USS UpToNoGood`——正在执行一项前往绝密地点的秘密任务。军事指挥官不希望任何人知道该舰艇偏离了其正常巡逻路线。如果数据库管理员仅将 `USS UpToNoGood` 的位置分类更改为绝密，拥有机密许可的用户在无法查询该舰艇位置时，就会知道发生了异常情况。但是，如果使用多实例化，可以向表中插入两条记录。第一条记录在绝密级别，反映舰艇的真实位置，仅对具有相应绝密安全许可的用户可用。第二条记录在机密级别，表明该舰艇正在执行例行巡逻，并将返回给拥有机密许可的用户。

最后，管理员可以将虚假或误导性数据插入 DBMS，以重定向或挫败信息机密性攻击。这是一个称为**噪声和扰动**的概念。使用此技术时必须极其小心，以确保插入数据库的噪声不影响业务操作。

# 开放数据库互连

**开放数据库互连 (ODBC)** 是一项数据库功能，允许应用程序与不同类型的数据库通信，而无需为与每种类型的直接交互进行编程。ODBC 作为应用程序和后端数据库驱动程序之间的代理，使应用程序程序员在创建解决方案时拥有更大的自由度，而无需担心后端数据库系统。[图 20.9](#c20.xhtml#figure20-9) 说明了 ODBC 与后端数据库系统之间的关系。

# NoSQL

随着数据库技术的发展，许多组织在需要提高速度或其数据不适合整齐地放入表格形式的情况下，开始放弃关系模型。NoSQL 数据库是一类使用除关系模型以外的模型来存储数据的数据库。

NoSQL 数据库主要有三大类：

*   **键/值存储** 或许是数据库最简单的形式。它们以键/值对的形式存储信息，其中键本质上是一个用于唯一标识记录的索引，记录由一个数据值组成。键/值存储适用于高速应用程序和超大数据集。

*   **图数据库** 以图格式存储数据，使用节点表示对象，使用边表示关系。它们适用于表示任何类型的网络，例如社交网络、地理位置以及其他适合图表示的数据集。

*   **文档存储** 与键/值存储类似，它们使用键来存储信息，但存储的信息类型通常比键/值存储中的更复杂，且以文档形式存在。文档存储中常用的文档类型包括可扩展标记语言 (XML) 和 JavaScript 对象表示法 (JSON)。

NoSQL 数据库使用的安全模型可能与关系数据库有显著差异。使用此技术的组织中的安全专业人员应熟悉其所用解决方案的安全功能，并与数据库团队协商设计适当的安全控制。

# 存储数据和信息

数据库管理系统帮助利用数据的力量，并对谁可以访问数据以及他们可以对数据执行什么操作获得一定程度的控制。然而，安全专业人员必须记住，DBMS 安全仅涵盖通过传统“前门”渠道访问信息的情况。数据还通过计算机的存储资源进行处理——包括内存和物理介质。必须采取预防措施，确保这些基本资源也受到保护，免受安全漏洞的影响。毕竟，你永远不会花费大量时间和金钱保护家里的前门，却把后门大敞四开，对吧？

## 存储类型

现代计算系统使用多种类型的存储来维护系统和用户数据。系统在各种存储类型之间取得平衡，以满足组织的计算需求。有几种常见的存储类型：

*   **主存储（或“实”存储）** 由直接可用于系统 CPU 的主内存资源组成。主存储通常由易失性随机存取存储器 (RAM) 组成，通常是系统可用的最高性能存储资源。

*   **辅助存储** 由价格较低、非易失性的存储资源组成，可供系统长期使用。典型的辅助存储资源包括磁性和光学介质，如磁带、磁盘、硬盘驱动器、闪存驱动器和光盘/数字多功能光盘 (CD/DVD) 存储。

*   **虚拟内存** 允许系统通过使用辅助存储来模拟额外的主内存资源。例如，一个昂贵 RAM 资源不足的系统可能会将一部分硬盘用于直接 CPU 寻址。

*   **虚拟存储** 允许系统通过使用主存储来模拟辅助存储资源。虚拟存储最常见的例子是 RAM 磁盘，它向操作系统呈现为辅助存储设备，但实际上是用易失性 RAM 实现的。这为各种应用程序提供了极快的文件系统，但不提供恢复能力。

*   **随机存取存储** 允许操作系统从介质内的任意点请求内容。RAM 和硬盘驱动器是随机存取存储资源的例子。

*   **顺序存取存储** 要求从头开始扫描整个介质以到达特定地址。磁带是顺序存取存储资源的常见例子。

*   **易失性存储** 在电源从资源移除时丢失其内容。RAM 是最常见的易失性存储资源类型。

*   **非易失性存储** 不依赖电源的存在来维护其内容。磁性/光学介质和非易失性 RAM (NVRAM) 是典型的非易失性存储资源示例。
