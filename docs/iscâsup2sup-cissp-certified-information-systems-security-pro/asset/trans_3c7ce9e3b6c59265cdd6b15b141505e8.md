

# AAA 协议

AAA 协议提供认证、授权和审计。流行的 AAA 协议包括 RADIUS、TACACS+ 和 Diameter。

# 身份与访问配置生命周期

身份与访问配置生命周期包含创建、管理和删除主体所用账户的过程。配置包括创建账户的初始步骤，并确保授予它们对对象的适当访问权限。随着用户工作职责的变化，他们通常需要对初始访问权限进行更改。账户审查过程确保账户修改遵循最小权限原则。当员工离开组织时，应尽快禁用账户，并在不再需要时将其删除。

# 考试要点

## 了解主体与对象的区别

您会发现 CISSP 考题和安全文档通常使用*主体*和*对象*这两个术语，因此了解它们之间的区别非常重要。主体是访问被动对象（如文件）的主动实体（如用户）。用户是在执行某项操作或完成工作任务时访问对象的主体。

## 了解各种访问控制类型

您应该能够识别任何给定访问控制的类型。访问控制可分为预防性（阻止不需要或未授权的活动发生）、检测性（发现不需要或未授权的活动）或纠正性（在不需要或未授权的活动发生后将系统恢复正常）。威慑性访问控制试图通过鼓励人们决定不采取不需要的行动，来阻止违反安全策略的行为。恢复控制试图在安全策略违规后修复或恢复资源、功能和能力。指令性控制试图指导、限制或控制主体的行为，以强制或鼓励其遵守安全策略。补偿性控制为现有控制提供选项或替代方案，以协助安全策略的实施和支持。

## 了解访问控制的实施方法

控制措施可作为管理控制、逻辑/技术控制或物理控制来实施。管理控制包括实施和强制执行整体访问控制的策略或程序。逻辑/技术控制包括用于管理对资源和系统的访问并为这些资源和系统提供保护的硬件或软件机制。物理控制包括部署的物理屏障，用于防止与设施内的系统或区域进行直接接触和访问。

## 了解标识与认证的区别

访问控制依赖于有效的标识和认证，因此了解它们之间的区别很重要。主体声称一种身份，标识可以像用户的用户名一样简单。主体通过提供认证凭据（如与用户名匹配的密码）来证明其身份。

## 了解授权与问责的区别

在认证主体之后，系统根据其已验证的身份授权对对象的访问。审计日志和审计跟踪记录事件，包括执行操作的主体身份。有效的标识、认证和审计相结合可提供问责制。

## 了解主要认证因素的详细信息

认证的三个主要因素是：您知道的某事（如密码或 PIN 码）、您拥有的某物（如智能卡或令牌）和您本身的特征（基于生物特征）。多因素认证包含两个或更多认证因素，使用它比使用单一认证因素更安全。密码是最薄弱的认证形式，但密码策略通过强制执行复杂性和历史要求有助于提高其安全性。智能卡包含微处理器和加密证书，令牌生成一次性密码。生物特征方法根据指纹等特征识别用户。交叉错误率标识生物特征方法的准确性。它显示了拒真率等于认假率的点。

## 了解单点登录

单点登录 (SSO) 是一种机制，允许主体认证一次即可访问多个对象，而无需再次认证。Kerberos 是组织内部最常用的 SSO 方法，它使用对称加密和票据来证明身份并提供认证。当多个组织想要使用通用的 SSO 系统时，它们通常会使用联合身份管理系统，其中联盟或组织群体就通用的认证方法达成一致。安全断言标记语言 (SAML) 常用于共享联合身份信息。其他 SSO 方法包括脚本访问、SESAME 和 KryptoKnight。OAuth 和 OpenID 是互联网上使用的两种较新的 SSO 技术。谷歌等许多大型组织推荐使用 OAuth 2.0 而非 OAuth 1.0。

## 了解 AAA 协议的目的

多种协议提供集中式认证、授权和审计服务。网络接入（或远程接入）系统使用 AAA 协议。例如，网络接入服务器是 RADIUS 服务器的客户端，RADIUS 服务器提供 AAA 服务。RADIUS 使用 UDP 且仅加密密码。TACACS+ 使用 TCP 且加密整个会话。Diameter 基于 RADIUS 并改进了 RADIUS 的许多弱点，但 Diameter 与 RADIUS 不兼容。Diameter 在智能手机等移动 IP 系统中越来越流行。

## 了解身份与访问配置生命周期

身份与访问配置生命周期是指账户的创建、管理和删除。配置账户可确保它们根据任务要求拥有适当的特权。定期审查可确保账户没有过度特权并遵循最小权限原则。撤销包括员工离职时尽快禁用账户，并在不再需要时删除账户。
