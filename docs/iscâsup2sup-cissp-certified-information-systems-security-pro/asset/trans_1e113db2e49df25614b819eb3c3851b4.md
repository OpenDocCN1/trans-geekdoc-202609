

# 理解 SECaaS

安全即服务（SECaaS）是一种云服务提供商概念，即安全性通过在线实体提供给组织，或由在线实体提供。

# 理解智能设备

智能设备是一系列移动设备，为用户提供大量自定义选项，通常通过安装应用程序实现，并可能利用设备端或云端的人工智能（AI）处理能力。

# 理解物联网

物联网（IoT）是连接互联网的设备的一个新子类别，甚至可能是一个新类别，旨在为家庭或办公室环境中的传统或新型设备/电器提供自动化、远程控制或 AI 处理功能。

# 理解移动设备安全

设备安全涉及移动设备可能具备的各种潜在安全选项或功能。并非所有便携式电子设备（PED）都具备良好的安全功能。PED 安全功能包括全设备加密、远程擦除、锁定、屏幕锁、GPS、应用控制、存储分段、资产追踪、库存控制、移动设备管理、设备访问控制、可移动存储以及禁用未使用的功能。

# 理解移动设备应用安全

移动设备上使用的应用程序和功能需要得到保护。相关概念包括密钥管理、凭据管理、认证、地理标记、加密、应用程序白名单以及传递信任/认证。

# 理解 BYOD

自带设备（BYOD）是一项允许员工携带个人移动设备上班，并使用这些设备连接公司网络以访问业务资源和/或互联网的政策。虽然 BYOD 可能提高员工士气和工作满意度，但会增加组织的安全风险。相关问题包括数据所有权、支持所有权、补丁管理、防病毒管理、取证、隐私、入职/离职管理、遵守企业政策、用户接受度、架构/基础设施考量、法律顾虑、可接受使用政策以及机载摄像头/视频。

# 理解嵌入式系统和静态环境

嵌入式系统通常是围绕一组有限的特定功能设计的，这些功能与其作为组件的更大产品相关。静态环境是指为特定需求、能力或功能配置的应用程序、操作系统、硬件集合或网络，配置完成后设定为保持不变。

# 理解嵌入式系统和静态环境的安全顾虑

静态环境、嵌入式系统以及其他受限或单一用途的计算环境需要安全管理。这些技术可能包括网络分段、安全层、应用防火墙、手动更新、固件版本控制、包装器，以及控制冗余和多样性。

# 理解最小权限原则、权限分离和问责制如何应用于计算机体系结构

最小权限原则确保只有最少数量的进程被授权在监督模式下运行。权限分离增加了安全操作的粒度。问责制确保存在审计追踪，以便将操作追溯到其源头。

# 能够解释什么是隐蔽信道

隐蔽信道是指任何用于传递信息但通常不用于信息传递的方法。

# 理解什么是缓冲区溢出和输入检查

当程序员在将数据写入特定内存位置之前，未能检查输入数据的大小，就会发生缓冲区溢出。事实上，任何未能验证输入数据的行为都可能导致安全违规。

# 描述安全架构的常见缺陷

除了缓冲区溢出，程序员在系统部署后可能还会在系统上留下后门和特权程序。即使编写良好的系统也可能容易受到分时检查到分时使用（TOCTTOU）攻击。任何状态变更都可能成为攻击者攻破系统的潜在机会窗口。
