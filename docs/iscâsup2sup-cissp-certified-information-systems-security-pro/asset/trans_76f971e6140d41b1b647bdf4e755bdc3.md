
# 恶意软件开发的最新趋势伴随着高级持续性威胁（APT）的兴起

APT 是拥有高超技术技能和大量资金资源的复杂对手。这些攻击者通常是军事单位、情报机构或可能与政府机构有关联的神秘组织。APT 攻击者与其他恶意软件作者的主要区别之一在于，这些恶意软件开发者通常能接触到软件供应商尚不知情的零日漏洞。由于供应商不知道该漏洞，因此没有补丁，且该漏洞利用极其有效。APT 构建的恶意软件具有高度针对性，旨在仅影响极少数的敌对系统（通常少至一个！），且难以防御。您将在本章后面阅读到 Stuxnet，它是 APT 开发恶意软件的一个例子。

## 病毒

计算机病毒或许是困扰安全管理员的最早形式的恶意代码。事实上，病毒如今如此普遍，以至于大规模爆发会受到大众媒体的关注，并在普通计算机用户中引发轻度恐慌。据主要杀毒软件供应商赛门铁克称，2016 年全球网络上游荡着超过 3.57 亿种恶意代码，且这一趋势仍在继续，一些来源表明每天有 20 万个新的恶意软件变体出现在互联网上！每天有成百上千种病毒变体袭击毫无防备的计算机用户。许多病毒携带恶意载荷，造成的损害范围从在屏幕上显示亵渎性信息，到导致本地硬盘上存储的所有数据彻底销毁不等。

正如生物病毒一样，计算机病毒有两大主要功能——繁殖和破坏。创建病毒的不法分子精心设计代码，以新颖创新的方法实现这些功能，希望能逃避检测并绕过日益复杂的杀毒技术。可以说，病毒编写者和杀毒技术人员之间已经形成了一场军备竞赛，双方都希望开发出比对方领先一步的技术。繁殖功能定义了病毒如何在系统之间传播，感染其经过的每一台机器。病毒的载荷通过实施病毒编写者设想的任何恶意活动来释放破坏力。这可能是任何对系统或数据的机密性、完整性或可用性产生负面影响的行为。

### 病毒繁殖技术

根据定义，病毒必须包含使其能够在系统之间传播的技术，这需要毫无戒心的计算机用户通过交换磁盘、共享网络资源、发送电子邮件或使用其他方式来共享数据从而提供协助。一旦它们“接触”到一个新系统，就会使用几种繁殖技术之一来感染新受害者并扩大其影响范围。在本节中，我们将介绍四种常见的繁殖技术：主引导记录感染、文件感染、宏感染和服务注入。

#### 主引导记录病毒

`主引导记录 (MBR) 病毒` 是已知最早的病毒感染形式之一。这些病毒攻击 MBR——可启动介质（如硬盘、通用串行总线 (USB) 或光盘/数字多功能光盘 (CD/DVD)）中计算机在启动过程中用于加载操作系统的那部分。由于 MBR 非常小（通常为 512 字节），它无法容纳实现病毒繁殖和破坏功能所需的所有代码。为了绕过这一空间限制，MBR 病毒将其大部分代码存储在存储介质的另一部分上。当系统读取受感染的 MBR 时，病毒会指示它读取并执行存储在该备用位置的代码，从而将整个病毒加载到内存中，并可能触发病毒载荷的释放。

大多数 MBR 病毒通过用户无意中共享的受感染介质在系统之间传播。如果受感染的介质在启动过程中留在驱动器中，目标系统会读取受感染的 MBR，病毒加载到内存中，感染目标系统硬盘上的 MBR，并将其感染传播到另一台机器。

#### 文件感染型病毒

许多病毒感染不同类型的可执行文件，并在操作系统尝试执行它们时触发。对于基于 Windows 的系统，这些文件的名称以 `.exe` 和 `.com` 扩展名结尾。`文件感染型病毒` 的繁殖例程可能会轻微修改可执行程序的代码，从而植入病毒复制和破坏系统所需的技术。在某些情况下，病毒实际上可能会用受感染的版本替换整个文件。不使用隐藏技术（如隐身或加密，请参阅本章后面的“病毒技术”部分）的标准文件感染型病毒，通常可以通过比较感染前后的文件特征（如大小和修改日期）或比较哈希值来轻松检测。“杀毒机制”部分提供了这些技术的技术细节。

文件感染型病毒的一个变种是 `伴随病毒`。这些病毒是独立的可执行文件，它们通过使用与合法操作系统文件相似但略有不同的文件名来逃避检测。它们依赖基于 Windows 的操作系统在执行程序文件时默认追加的文件名扩展名（按顺序为 `.com`、`.exe` 和 `.bat`）。例如，如果您的硬盘上有一个名为 `game.exe` 的程序，伴随病毒可能会使用名称 `game.com`。如果您随后打开命令工具并仅输入 `GAME`，操作系统将执行病毒文件 `game.com`，而不是您实际想要执行的文件 `game.exe`。这是避免使用快捷方式并完整指定要执行的文件名的一个很好的理由。

#### 宏病毒

许多常见的软件应用程序实现了某种脚本功能，以协助自动化重复性任务。这些功能通常使用简单但强大的编程语言，如 Visual Basic for Applications (VBA)。虽然宏确实为计算机用户提供了巨大的生产力提升机会，但它们也使系统面临另一种感染途径——宏病毒。

`宏病毒` 于 1990 年代中期首次出现，利用粗糙的技术感染流行的 Microsoft Word 环境中创建的文档。尽管它们相对不复杂，但这些病毒传播迅速，因为杀毒社区未曾预料到它们，因此杀毒应用程序未提供任何针对它们的防御。宏病毒迅速变得司空见惯，供应商争相修改其杀毒平台以扫描应用程序文档中的恶意宏。1999 年，Melissa 病毒通过利用 Microsoft Outlook 中的安全漏洞进行复制，借助 Word 文档进行传播。臭名昭著的“我爱你”病毒紧随其后，于 2000 年初利用类似的漏洞，向我们展示了快速传播的病毒已困扰我们近 20 年。

在 20 世纪末期宏病毒爆发后，生产力软件开发商对宏开发环境进行了重要更改，限制了不受信任的宏在未获得明确用户许可的情况下运行的能力。这导致宏病毒的流行程度大幅下降。
