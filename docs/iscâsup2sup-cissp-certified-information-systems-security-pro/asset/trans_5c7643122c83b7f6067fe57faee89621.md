
如果书面证据满足实质性、胜任力和关联性要求，且遵守最佳证据规则和口头证据规则，则可被法庭采纳。

### 证人证言证据

**证人证言证据** 简单来说，就是由证人证词组成的证据，无论是法庭上的口头证词，还是记录在案的书面证词（即证词记录）。证人必须宣誓承诺讲真话，且其证词必须基于个人知晓的情况。此外，证人必须记住其证词的依据（他们可以查阅书面笔记或记录来辅助记忆）。证人可以提供 **直接证据**：基于其自身直接观察，能够证明或反驳主张的口头证词。大多数证人的证言证据必须严格限制在基于证人事实观察的直接证据上。但是，如果证人已被法庭认定为某一领域的专家，则不适用此限制。在这种情况下，证人可以基于呈堂的其他事实及其对该领域的个人知识，提供 **专家意见**。

证言证据不得为 **传闻证据**。即证人不能就法庭外他人告诉他们的内容作证。未经系统管理员认证的计算机日志文件也可被视为传闻证据。

#### 证据收集与取证程序

收集数字证据是一个棘手的过程，应仅由专业的取证技术人员尝试。国际计算机证据组织 (IOCE) 概述了六项原则，指导数字证据技术人员在追求取证恢复证据的过程中进行介质分析、网络分析和软件分析：

*   处理数字证据时，必须应用所有通用的取证和程序原则。
*   扣押数字证据时，采取的行动不应改变该证据。
*   当有必要由某人访问原始数字证据时，该人员应接受过相应目的的培训。
*   与数字证据的扣押、访问、存储或传输相关的所有活动，必须完整记录、保存，并可供审查。
*   个人对其持有数字证据期间采取的所有行动负责。
*   负责扣押、访问、存储或传输数字证据的任何机构，均有责任遵守这些原则。

在进行取证证据收集时，保留原始证据非常重要。请记住，调查行为本身可能会改变您正在评估的证据。因此，在分析数字证据时，最好尽可能使用实际证据的副本进行工作。例如，在调查硬盘驱动器内容时，制作该驱动器的镜像，将原始驱动器密封在证据袋中，然后使用磁盘镜像进行调查。

#### 介质分析

介质分析是计算机取证分析的一个分支，涉及从存储介质中识别和提取信息。这可能包括以下内容：

*   磁性介质（如硬盘、磁带）
*   光学介质（如光盘 (CD)、数字多功能光盘 (DVD)、蓝光光盘）
*   存储器（如随机存取存储器 (RAM)、固态存储）

介质分析使用的技术可能包括：从物理磁盘的未分配扇区恢复已删除文件、对连接到计算机系统的存储介质进行实时分析（在检查加密介质时特别有用）、以及对存储介质的取证镜像进行静态分析。

#### 网络分析

取证调查人员通常也对安全事件发生期间网络上发生的活动感兴趣。由于网络数据的易失性，这通常很难重构——如果在发生时没有刻意记录，通常不会被保留。

因此，网络取证分析通常依赖于对事件正在进行的事先知情，或使用预先存在的记录网络活动的安全控制。这些包括：

*   入侵检测和防御系统日志
*   流量监控系统捕获的网络流数据
*   事件期间刻意收集的数据包捕获
*   防火墙和其他网络安全设备的日志

网络取证分析师的任务是从这些不同来源收集并关联信息，生成尽可能全面的网络活动图景。

#### 软件分析

取证分析师也可能被要求对应用程序或运行中应用程序内发生的活动进行取证审查。在某些情况下，当怀疑存在恶意内部人员时，取证分析师可能被要求审查软件代码，寻找后门、逻辑炸弹或其他安全漏洞。有关这些主题的更多信息，请参见第 21 章“恶意代码和应用攻击”。

在其他情况下，取证分析师可能被要求审查和解读应用程序或数据库服务器的日志文件，寻找其他恶意活动迹象，如 SQL 注入攻击、权限提升或其他应用攻击。这些内容也在第 21 章中讨论。

#### 硬件/嵌入式设备分析

最后，取证分析师通常必须审查硬件和嵌入式设备的内容。这可能包括对以下内容的审查：

*   个人计算机
*   智能手机
*   平板电脑
*   汽车、安全系统和其他设备中的嵌入式计算机

进行这些审查的分析师必须具备对被审查系统的专业知识。这通常需要聘请熟悉此类设备的内存、存储系统和操作系统的专家顾问。由于软件、硬件和存储之间复杂的交互，硬件分析学科要求同时具备介质分析和软件分析的技能。

### 调查流程

当你启动计算机安全调查时，首先应组建一支由胜任分析师组成的团队协助调查。该团队应在组织现有的事件响应政策下运作，并获得一份章程，明确界定调查范围；调查人员的权限、角色和职责；以及他们在调查过程中必须遵守的任何交战规则。这些交战规则定义并指导调查人员在调查不同阶段被授权采取的行动，如联络执法部门、讯问嫌疑人、收集证据和中断系统访问。

#### 收集证据

为了进行适当的调查，通常会没收设备、软件或数据。没收证据的方式很重要。证据的没收必须以适当的方式进行。有三种基本选择。

首先，证据所有人可以 **自愿交出** 证据。这种方法通常仅适用于攻击者不是所有者的情况。极少有罪方会自愿交出他们知道会使自己受到指控的证据。经验较浅的攻击者可能认为他们已成功掩盖踪迹，从而自愿交出重要证据。优秀的取证调查员可以从计算机中提取大量“被掩盖”的信息。在大多数情况下，向嫌疑攻击者索要证据只会警告嫌疑人，您即将采取法律行动。
