

# 采样

*采样*，或称*数据提取*，是指从大量数据集合中提取特定元素，以构建整体的有意义表征或摘要的过程。换句话说，采样是一种数据缩减形式，它允许某人通过仅查看审计追踪中的一小部分数据样本，就能获取有价值的信息。

统计采样使用精确的数学函数，从海量数据中提取有意义的信息。这类似于民意测验员用来在不采访所有人口的情况下了解大众意见的科学方法。采样数据永远存在无法准确代表整体数据的风险，而统计采样可以识别误差范围。

## 截断水平

截断是一种非统计采样形式。它仅选择超过*截断水平*的事件，截断水平是事件的预定义阈值。系统会忽略事件，直到它们达到此阈值。

例如，失败的登录尝试在任何系统中都很常见，因为用户很容易输错一两次密码。与其为每一次失败的登录尝试都发出警报，不如设置一个截断水平，仅当在 30 分钟内检测到五次失败的登录尝试时才发出警报。许多账户锁定控制使用类似的截断水平。它们不会在一次登录失败后就锁定账户。相反，它们会统计失败登录的次数，仅当达到预定义阈值时才锁定账户。

截断水平广泛用于审计事件的过程中，以建立常规系统或用户活动的基线。仅当超过基线时，监控系统才会发出警报以示异常事件。换句话说，截断水平使系统忽略常规事件，仅在检测到严重入侵模式时才发出警报。

一般来说，非统计采样是自由裁量采样，即由审计员自行决定进行的采样。它无法提供整体数据的准确表征，并会忽略未达到截断水平阈值的事件。然而，当用于聚焦特定事件时，它是有效的。此外，非统计采样比统计采样成本更低、更易于实施。

## 其他监控工具

尽管日志是审计中使用的主要工具，但组织内还有一些值得一提的额外工具。例如，闭路电视（CCTV）可以自动将事件录制到磁带上以供后续审查。安全人员还可以实时监控实时 CCTV 系统，以发现不需要的、未经授权的或非法的活动。该系统可以独立工作，也可以与安保人员配合使用，而安保人员本身也可以受到 CCTV 监控，并对任何非法或不道德的活动负责。其他工具包括击键监控、流量分析监控、趋势分析监控以及防止数据丢失的监控。

### 击键监控

**击键监控**是记录用户在物理键盘上执行的击键行为。监控通常通过技术手段完成，例如硬件设备或称为键盘记录器的软件程序。不过，视频录像机也可以执行可视化监控。在大多数情况下，攻击者将击键监控用于恶意目的。在极端情况下和高度受限的环境中，组织可能会实施击键监控以审计和分析用户活动。

击键监控常被比作窃听。关于击键监控是否应像电话窃听一样受到限制和控制，存在一些争议。许多采用击键监控的组织会通过雇佣协议、安全策略，或登录/注册区域的警告横幅，通知授权和未授权用户正在进行此类监控。

### 流量分析和趋势分析

**流量分析**和**趋势分析**是监控的形式，它们检查数据包的流向，而不是实际的数据包内容。这有时被称为网络流监控。它可以推断出大量信息，例如主备通信路由、主服务器的位置、加密流量的来源和网络支持的流量大小、典型的流量流向、通信频率等。

这些技术有时可以揭示可疑的流量模式，例如当某员工的账户向其他人发送大量电子邮件时。这可能表明该员工的系统是僵尸网络的一部分，受远程位置的攻击者控制。同样，流量分析可能检测到不道德的内部人员是否通过电子邮件将内部信息转发给未授权方。这类事件通常会留下可检测的特征。

## 出站监控

*出站监控*是指监控传出流量以防止数据渗漏，数据渗漏是指未经授权将数据传输到组织外部。防止数据渗漏的一些常用方法包括使用数据丢失防护技术、查找隐写术尝试，以及使用水印来检测流出的未授权数据。

高级攻击者（如国家资助的高级持续性威胁）通常会在将数据发送出网络之前对其进行加密。这可以挫败一些试图检测数据渗漏的常用工具。不过，也可以部署监控发出网络的加密数据量的工具。

### 数据丢失防护

*数据丢失防护（DLP）*系统旨在检测并阻止数据渗漏尝试。这些系统具备扫描未加密数据以查找关键字和数据模式的能力。例如，假设某组织使用机密、专有、私密和敏感等数据分类。DLP 系统可以扫描文件中的这些词汇并将其检测出来。

模式匹配 DLP 系统查找特定模式。例如，美国社会安全号码具有 `nnn-nn-nnnn` 的模式（三个数字、一个连字符、两个数字、一个连字符和四个数字）。DLP 可以查找此模式并将其检测出来。管理员可以根据需要设置 DLP 系统以查找任何模式。

DLP 系统主要有两种类型：基于网络的和基于端点的。

#### 基于网络的 DLP

基于网络的 DLP 扫描所有传出数据以查找特定数据。管理员会将其部署在网络边缘，以扫描离开组织的所有数据。如果用户发送包含受限数据的文件，DLP 系统将检测到并阻止其离开组织。DLP 系统会发送警报，例如发送电子邮件给管理员。

#### 基于端点的 DLP

基于端点的 DLP 可以扫描存储在系统上的文件以及发送到外部设备（如打印机）的文件。例如，组织的基于端点的 DLP 可以防止用户将敏感数据复制到 USB 闪存驱动器，或将敏感数据发送到打印机。管理员会配置 DLP 使用适当的关键字扫描文件，如果检测到包含这些关键字的文件，它将阻止复制或打印作业。也可以配置基于端点的 DLP 系统定期扫描文件（如文件服务器上的文件），查找包含特定关键字或模式的文件，甚至未经授权的文件类型，如 MP3 文件。

DLP 系统通常具备执行深度检查的能力。例如，如果用户将文件嵌入压缩的 zip 文件中，DLP 系统仍能检测到关键字和模式。但是，DLP 系统没有解密数据的能力。
