
# 实施移动设备策略时

在实施移动设备策略时，组织应评估其网络和安全设计、架构及基础设施。如果每位员工都自带个人设备，网络上的设备数量可能会翻倍。这需要规划来处理 IP 地址分配、通信隔离、数据优先级管理，以及入侵检测系统 (IDS)/入侵防御系统 (IPS) 监控负载的增加，还有内部和跨互联网链路带宽消耗的增加。大多数移动设备都支持无线功能，因此这很可能需要更强大的无线网络，并应对 Wi-Fi 拥塞和干扰。移动设备策略需结合其将引发的额外基础设施成本予以考量。

## 法律顾虑

公司律师应评估移动设备的法律顾虑。在执行业务任务时使用个人设备，可能意味着责任负担加重和数据泄露风险增加。移动设备或许能让员工满意，但对组织而言，可能并非一项值得或具有成本效益的举措。

## 可接受使用策略

移动设备策略应引用公司的可接受使用策略，或包含一个专注于独特问题的移动设备专用版本。随着个人移动设备在工作中使用，信息泄露、分心和访问不当内容的风险增加。员工应时刻铭记，在工作时的首要目标是完成生产力任务。

## 载入相机/摄像头

移动设备策略需涉及带有载入相机的移动设备。某些环境禁止任何类型的相机。这将要求移动设备不得带有相机。如果允许使用相机，应明确记录并向员工解释何时可以使用、何时不得使用。移动设备可充当存储设备，提供通往外部提供商或服务的备用无线连接路径，还可用于采集泄露机密信息或设备的图像和视频。

# 评估并缓解嵌入式设备和网络物理系统中的漏洞

**嵌入式系统** 是作为大型系统一部分实现的计算机。嵌入式系统通常围绕一组有限的特定功能进行设计，这些功能与其作为组件的大型产品相关。它可能由典型计算机系统中相同的组件组成，也可能是一个 **微控制器** (一种带有板载内存和外设端口的集成芯片)。嵌入式系统的示例包括网络连接打印机、智能电视、暖通空调 (HVAC) 控制器、智能家电、智能恒温器、车载娱乐/驾驶辅助/自动驾驶系统以及医疗设备。

与嵌入式系统类似的另一个概念是 **静态系统** (又称 **静态环境**)。**静态环境** 是一组不变的条件、事件和周围环境。理论上，一旦被理解，静态环境不会提供新的或令人惊讶的元素。**静态 IT 环境** 是指旨在保持不变、不被用户和管理员更改的任何系统。其目标是防止，或至少减少用户实施可能导致安全性或功能操作降低的变更的可能性。

在技术领域，静态环境是指为特定需求、能力或功能配置的应用程序、操作系统、硬件集合或网络，随后设置为保持未改变状态。然而，尽管使用了 **静态** 一词，但不存在真正的静态系统。硬件故障、硬件配置变更、软件漏洞、软件设置变更或漏洞利用始终有可能改变环境，导致不期望的操作参数或实际的安全入侵。

## 嵌入式系统和静态系统的示例

**网络启用设备** 是指具有原生网络功能的任何类型的便携式或非便携式设备。这通常假设相关网络为无线网络，主要指移动电信公司提供的网络。不过，它也可以指连接 Wi-Fi 的设备（尤其是能自动连接的设备）、从无线电信服务共享数据连接的设备（如 **移动热点**），以及带有用于接收标准以太网电缆进行有线连接的 RJ-45 接口的设备。网络启用设备包括智能手机、移动电话、平板电脑、智能电视、机顶盒、或 HDMI 棒状流媒体播放器（如 **Roku Player**、**Amazon Fire TV** 或 **Google Android TV/Chromecast**）、网络连接打印机、游戏系统等。

**网络物理系统** 是指提供计算手段来控制物理世界中事物的设备。过去这些可能被称为嵌入式系统，但网络物理系统这一类别似乎更侧重于物理世界的结果，而非计算方面。网络物理设备和系统本质上是机器人技术和传感器网络中的关键元素。基本上，任何能导致现实世界中发生运动的计算设备都被视为机器人元件，而任何能检测物理状况（如温度、光线、运动和湿度）的此类设备则是传感器。网络物理系统的示例包括提供人体增强或辅助的假肢、车辆防撞系统、空中交通管制协调、机器人手术的精准操作、危险环境下的远程操作，以及车辆、设备、移动设备和建筑中的节能系统。

网络物理系统、嵌入式系统和网络启用设备的另一个延伸是 **物联网** 。如前所述，物联网是指能够通过互联网相互通信或与控制台通信，以影响和监控现实世界的设备集合。物联网设备可能被标记为智能设备或智能家居设备。办公楼中工业环境控制的许多理念，正逐渐进入面向小型办公室或个人家庭的消费级解决方案。物联网不限于固定位置设备，也可用于陆地、空中或水上载具，或移动设备上。物联网设备通常属于静态系统，因为它们可能仅运行制造商提供的固件。

**大型机** 是用于执行高度复杂计算和提供大量数据处理的高端计算机系统。较老的大型机可被视为静态环境，因为它们通常围绕单一任务设计，或支持单一关键任务应用程序。这些配置没有提供显著的灵活性，但确实提供了高稳定性和长期运行能力。许多大型机能够运行数十年。

现代大型机灵活得多，常用于提供高速计算能力以支持众多虚拟机。每个虚拟机可用于托管独特的操作系统，进而支持广泛的应用程序。如果现代大型机被实施为为某个操作系统或应用程序提供固定或静态支持，则可被视为静态环境。

**游戏主机**，无论是家用系统还是便携式系统，都可能是静态系统的示例。游戏主机的操作系统通常是固定的，仅在供应商发布系统升级时才会更改。此类升级通常是操作系统、应用程序和固件改进的混合体。尽管游戏主机的功能通常专注于玩游戏和媒体，但现代主机可能支持一系列经过筛选的第三方应用程序。应用程序支持越灵活、开放，它作为静态系统的特性就越弱。
