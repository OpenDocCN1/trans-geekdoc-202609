## 非对称密码学

第 6 章中的“现代密码学”部分介绍了私钥（对称）和公钥（非对称）密码学背后的基本原理。您了解到，对称密钥密码体制要求通信双方拥有相同的共享密钥，从而产生了安全密钥分发的问题。您还了解到，非对称密码体制通过使用公钥和私钥对来促进安全通信，避免了复杂密钥分发系统的开销，从而绕过了这一障碍。这些系统的安全性依赖于逆转单向函数的难度。

在以下章节中，我们将更详细地探讨公钥密码学的概念，并了解当今使用的三种较常见的公钥密码体制：Rivest–Shamir–Adleman（`RSA`）、El Gamal 和椭圆曲线密码学（`ECC`）。

### 公钥和私钥

回顾第 6 章可知，`公钥密码体制` 依赖于分配给密码体制每个用户的一对密钥。每个用户都维护一个公钥和一个私钥。顾名思义，公钥密码体制用户将其公钥免费提供给任何他们想要通信的人。第三方仅持有公钥并不会给密码体制带来任何弱点。另一方面，私钥仅供拥有密钥的个人单独使用。它绝不与任何其他密码体制用户共享。

公钥密码体制用户之间的正常通信非常简单直接。[图 7.1](#c07.xhtml#figure7-1) 展示了通用流程。

请注意，该过程不需要共享私钥。发送方使用接收方的公钥加密明文消息（`P`）以创建密文消息（`C`）。当接收方打开密文消息时，他们使用自己的私钥对其进行解密，以重新创建原始明文消息。

一旦发送方使用接收方的公钥加密了消息，如果不知道接收方的私钥（用于生成消息的公私钥对的另一半），任何用户（包括发送方）都无法解密该消息。这就是公钥密码学的精妙之处——公钥可以通过不安全的通信自由共享，然后用于在先前互不相识的用户之间创建安全通信通道。

您在上一章中还了解到，公钥密码学涉及更高程度的计算复杂性。公钥系统中使用的密钥必须比私钥系统中使用的密钥更长，才能产生具有同等强度的密码体制。

### RSA

最著名的公钥密码体制以其创建者的名字命名。1977 年，Ronald Rivest、Adi Shamir 和 Leonard Adleman 提出了 `RSA 公钥算法`，该算法至今仍是全球标准。他们为该算法申请了专利，并成立了一个名为 RSA Security 的商业企业，以开发其安全技术的主流实现。如今，RSA 算法已发布到公共领域，并被广泛用于安全通信。

RSA 算法依赖于分解大素数所固有的计算难度。密码体制的每个用户都使用以下步骤中描述的算法生成一对公钥和私钥：

1.  选择两个大素数（每个约 200 位），标记为 `p` 和 `q`。

2.  计算这两个数的乘积：`n = p * q`。

3.  选择一个数 `e`，满足以下两个要求：

    1.  `e` 小于 `n`。

    2.  `e` 和 `(p – 1)(q – 1)` 互质——即这两个数除了 1 之外没有其他公因数。

4.  找到一个数 `d`，使得 `(ed – 1) mod (p – 1)(q – 1) = 1`。

5.  将 `e` 和 `n` 作为公钥分发给所有密码体制用户。保密 `d` 作为私钥。

如果 Alice 想要向 Bob 发送加密消息，她会使用以下公式从明文（`P`）生成密文（`C`）（其中 `e` 是 Bob 的公钥，`n` 是密钥生成过程中创建的 `p` 和 `q` 的乘积）：

```
C = Pe mod n
```

当 Bob 收到消息时，他执行以下计算以检索明文消息：

```
P = Cd mod n
```

### El Gamal

在第 6 章中，您了解了 Diffie–Hellman 算法如何利用大整数和模运算，促进在不安全通信信道上安全交换密钥。1985 年，T. El Gamal 博士发表了一篇文章，描述了如何将 Diffie–Hellman 密钥交换算法背后的数学原理扩展为支持用于加密和解密消息的完整公钥密码体制。

在发布时，El Gamal 相对于 RSA 算法的主要优势之一是它被发布到了公共领域。El Gamal 博士没有为其对 Diffie-Hellman 的扩展申请专利，因此它可自由使用，这与当时已获专利的 RSA 技术不同。（RSA 于 2000 年将其算法发布到了公共领域。）

然而，El Gamal 也有一个主要缺点——该算法会使其加密的任何消息长度加倍。在加密长消息或将通过窄带宽通信线路传输的数据时，这构成了一个主要困难。

### 椭圆曲线

同样在 1985 年，两位数学家——来自华盛顿大学的 Neal Koblitz 和来自 IBM 的 Victor Miller——独立提出了将 `椭圆曲线密码学`（`ECC`）理论应用于开发安全密码系统。

任何椭圆曲线都可以由以下方程定义：

```
y2 = x3 + ax + b
```

在该方程中，`x`、`y`、`a` 和 `b` 均为实数。每条椭圆曲线都有一个对应的 `椭圆曲线群`，由椭圆曲线上的点以及位于无穷远处的点 `O` 组成。同一椭圆曲线群内的两个点（`P` 和 `Q`）可以通过椭圆曲线加法算法相加。该运算非常简单地表示如下：

```
P + Q
```

通过假设 `Q` 是 `P` 的倍数，即以下情况，可以将此问题扩展为涉及乘法：

```
Q = xP
```
