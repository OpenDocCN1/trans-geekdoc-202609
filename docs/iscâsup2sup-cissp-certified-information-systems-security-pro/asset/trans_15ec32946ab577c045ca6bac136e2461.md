

# 安全人员参与场地与设施设计

安全人员应参与场地与设施的设计考量。否则，对于逻辑安全存在至关重要的许多物理安全重要方面可能会被忽视。让安全人员参与物理设施设计，可以确保您组织的长期安全目标不仅得到策略、人员和电子设备的支持，也得到建筑本身的支持。

## 场地选择

场地选择应基于组织的安全需求。成本、位置和规模固然重要，但满足安全要求应始终优先。在选择建设设施的场地或挑选预存结构时，务必仔细审视其位置的方方面面。

资产安全在很大程度上取决于场地安全，这涉及众多考量因素和情境要素。场地位置和建筑结构在整体场地选择过程中起着关键作用。易受骚乱、抢劫、非法闯入和破坏影响，或位于高犯罪率区域，显然都是不佳的选择，但并不总能由我们决定或控制。环境威胁如断层线、龙卷风/飓风多发区，以及靠近其他自然灾害区域，在场地选择过程中也构成重大问题，因为您并不总能规避这些威胁。

与其他建筑和企业的邻近程度是另一项关键考量。它们会吸引什么样的关注，这又如何影响您的运营或设施？如果附近的企业吸引过多访客、产生大量噪音、造成震动或处理危险材料，都可能危害您的员工或建筑。与应急响应人员的距离也是一个考量因素，此外还有其他要素。一些公司有能力购买或建设自己的园区，以将周边因素排除在外，并实施更严格的访问控制和监控。然而，并非每家公司都能行使这一选项，只能利用现有且负担得起的条件。

至少，应确保建筑设计能承受相当极端的天气条件，并能阻止或抵御公然的非法闯入企图。窗户和门等脆弱入口点往往主导此类分析，但您还应评估可能遮挡非法闯入企图的物体（树木、灌木或人造物品）。

## 可视性

可视性至关重要。周围地形如何？是否容易在不被发现的情况下，乘车或步行接近设施？周围区域的构成也很重要。它是位于住宅区、商业区还是工业区附近？当地犯罪率如何？最近的应急服务（消防、医疗、警察）位于何处？附近可能存在哪些独特隐患（化工厂、无家可归者收容所、大学、建筑工地等）？

可视性的另一个要素与安全摄像头监控的区域有关。务必确保安全摄像头的位置和性能与设施的内部和外部设计相协调。摄像头的部署应确保对所有外墙、出入口以及内部走廊拥有清晰的视线。

## 自然灾害

另一个关注点是自然灾害可能对该区域造成的潜在影响。该区域是否易发地震、泥石流、塌陷、火灾、洪水、飓风、龙卷风、落石、暴雪、暴雨、结冰、潮湿、高温、极寒等？您必须为自然灾害做好准备，并配置 IT 环境，使其能在事件中幸存或易于替换。如前所述，业务连续性和灾难规划主题分别在第 3 章和第 18 章中介绍。

## 设施设计

在设计设施建设时，您必须了解组织所需的安全级别。适当的安全级别必须在施工开始前进行规划和设计。

需考虑的重要问题包括：可燃性、耐火等级、建筑材料、承重等级、布局，以及对墙壁、门、天花板、地板、`HVAC`（暖通空调）、电力、水、污水、燃气等项目的控制。强行闯入、应急通道、抗进入能力、出入口朝向、报警器的使用、导电性等也是需要评估的重要方面。设施内的每个元素都应从其如何被用于保护或危害 IT 基础设施和人员的角度进行评估（例如，从设施内部向边界外部的气流和水流正压）。

还有一套成熟的“安全建筑”思想流派，常被称为*环境设计预防犯罪*。其指导思想是构建物理环境和周边，以影响潜在犯罪者在实施犯罪行为前的决策。国际 CPTED 协会是获取该主题信息的绝佳来源（[www.cpted.net](http://www.cpted.net)），Oscar Newman 所著、由 HUD 政策发展与研究办公室出版的《创造可防御空间》也是如此（您可以在 [www.defensiblespace.com/book.htm](http://www.defensiblespace.com/book.htm) 免费下载 PDF）。

# 实施场地与设施安全控制

为管理物理安全而实施的安全控制可分为三类：管理类、技术类和物理类。由于这些是描述访问控制所使用的相同类别，因此必须专注于这些控制的物理安全层面。*管理类物理安全控制*包括设施建设与选择、场地管理、人员控制、意识培训、应急响应和程序。*技术类物理安全控制*包括访问控制；入侵检测；报警；闭路电视（`CCTV`）；监控；供暖、通风和空调（`HVAC`）电源；以及火灾探测和抑制。*物理安全的物理控制*包括围栏、照明、锁具、建筑材料、人员闸、警犬和警卫。

在为环境设计物理安全时，应关注控制措施应按何种功能顺序使用。顺序如下：

1.  威慑
2.  拒绝
3.  检测
4.  延迟

安全控制的部署应使得最初对物理资产的访问企图受到*威慑*（边界限制即实现此目的）。若威慑失败，则应*拒绝*对物理资产的直接访问（例如，上锁的金库门）。若拒绝失败，系统需*检测*入侵（例如，使用运动传感器），并使入侵者在访问尝试中受到足够的*延迟*，以便当局做出响应（例如，资产上的钢缆锁）。部署物理安全控制时，请务必记住此顺序：先威慑，后拒绝，再检测，最后延迟。

## 设备故障

无论组织选择购买和安装的设备质量如何，最终都会发生故障。理解并为这一必然情况做好准备，有助于确保 IT 基础设施的持续可用性，并应有助于保护资源的完整性和可用性。
