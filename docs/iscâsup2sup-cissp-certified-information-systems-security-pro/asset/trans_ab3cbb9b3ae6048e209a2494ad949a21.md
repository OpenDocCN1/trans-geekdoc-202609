

# 调查

除了解决运营问题外，运营调查通常还会进行*根因分析*，旨在确定运营问题发生的原因。根因分析往往会凸显出需要补救的问题，以防止未来发生类似事件。

非运营性质的行政调查可能需要更严格的证据标准，特别是当调查可能导致对个人实施制裁时。对于这些调查中适当的证据标准，没有固定的指导方针。安全专业人员应咨询调查发起人及其法律团队，以确定行政调查中适当的证据收集、处理和保留指南。

## 刑事调查

刑事调查通常由执法人员进行，旨在调查涉嫌违反刑法的行为。刑事调查可能导致对嫌疑人提起刑事指控，并在刑事法庭上对这些指控进行起诉。

大多数刑事案件必须满足*排除合理怀疑*的证据标准。遵循这一标准，控方必须通过呈现事实来证明被告犯有罪行，这些事实不得有其他合乎逻辑的结论。因此，刑事调查必须遵循非常严格的证据收集和保全流程。

## 民事调查

民事调查通常不涉及执法部门，而是涉及代表法律团队工作的内部员工和外部顾问。他们准备在民事法庭上提交证据，以解决双方之间的纠纷。

大多数民事案件不遵循排除合理怀疑的举证标准。相反，它们使用较弱的*证据优势*标准。满足这一标准仅要求证据证明案件的结果更有可能发生而非不发生。因此，民事调查的证据收集标准不如刑事调查严格。

## 监管调查

当政府机构认为个人或公司违反了行政法时，可能会进行监管调查。监管机构通常会按照与其预期审理案件的法庭相称的证明标准来进行这些调查。监管调查的范围和程序差异很大，通常由政府特工执行。

某些监管调查可能不涉及政府机构。这些调查基于行业标准，例如支付卡行业数据安全标准（PCI DSS）。这些行业标准不是法律，而是参与组织签订的合同义务。在某些情况下（包括 PCI DSS），组织可能被要求接受独立第三方进行的审计、评估和调查。拒绝参与这些调查或调查结果不佳可能导致罚款或其他制裁。因此，针对违反行业标准的调查应以类似于监管调查的方式对待。

## 电子取证

在法律程序中，双方都有责任保存与案件相关的证据，并通过取证程序与对手共享信息。这一取证程序适用于纸质记录和电子记录，电子取证（或 eDiscovery）流程促进了电子信息的处理以供披露。

电子取证参考模型描述了进行电子取证的标准流程，共九个步骤：

*   **信息治理**确保信息组织良好，以便未来的电子取证工作。
*   **识别**在组织预计可能发生诉讼时，定位可能响应取证请求的信息。
*   **保全**确保潜在可取证的信息免受篡改或删除。
*   **收集**将响应信息集中收集，以供电子取证流程使用。
*   **处理**筛选收集的信息，对无关信息进行“粗略剔除”，减少需要详细筛选的信息量。
*   **审查**检查剩余信息，确定哪些信息响应请求，并移除受律师-委托人特权保护的任何信息。
*   **分析**对剩余信息的内容和上下文进行更深入的检查。
*   **生成**将信息转换为可与他人共享的格式。
*   **呈现**向证人、法庭和其他当事方展示信息。

进行电子取证是一个复杂的过程，需要信息技术专业人员和法律顾问之间的仔细协调。

# 证据

要成功起诉犯罪，控方律师必须提供充分的证据，证明个人有罪达到了排除合理怀疑的程度。在以下章节中，我们将解释证据在被法庭采纳前必须满足的要求、可引入的各种证据类型，以及证据处理和记录的要求。

## 可采纳证据

证据要在法庭上被采纳，有三项基本要求。要被视为*可采纳证据*，法官在公开审理前必须认定其同时满足以下三项要求：

*   证据必须与确定事实*相关*。
*   证据旨在确定的事实必须与案件*实质相关*（即相关联）。
*   证据必须*合法有效*，意味着其必须通过合法手段获得。因非法搜查而获得的证据将因不合法而被判定为不可采纳。

## 证据类型

法庭上可使用三类证据：物证、书证和证人证言。每类证据对于可采纳性都有略微不同的额外要求。

### 物证

*物证*（也称为*实物证据*）由可实际带入法庭的物品组成。在常见的刑事诉讼中，这可能包括凶器、衣物或其他实物。在计算机犯罪案件中，物证可能包括被扣押的计算机设备，例如带有指纹的键盘或来自黑客计算机系统的硬盘驱动器。视情况而定，物证也可能是*确凿证据*，例如脱氧核糖核酸（DNA），这是无可辩驳的。

### 书证

*书证*包括带入法庭以证明当前事实的任何书面材料。此类证据也必须经过认证。例如，如果律师想将计算机日志作为证据引入，他们必须传唤证人（例如系统管理员）出庭作证，证明该日志是作为常规业务实践收集的，且确实是系统收集的实际日志。

两条额外的证据规则专门适用于书证：

*   *最佳证据规则*规定，当文件在法庭程序中作为证据使用时，必须提交原始文件。除非适用该规则的特定例外情况，否则原始证据的副本或描述（称为*次级证据*）将不被接受为证据。
*   *口头证据规则*规定，当当事人之间的协议以书面形式订立时，推定书面文件包含协议的所有条款，任何口头协议均不得修改书面协议。
