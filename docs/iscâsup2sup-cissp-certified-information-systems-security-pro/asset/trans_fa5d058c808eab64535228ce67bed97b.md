多年来，数学家和计算机科学家开发了一系列日益复杂的密码算法，旨在提高对数据提供的保护级别。当密码学家致力于开发强加密算法时，黑客和政府也投入了大量资源试图破解它们。这导致了密码学领域的“军备竞赛”，并促成了当今使用的极其复杂的算法的开发。

## 密码学历史里程碑

自最早的文明以来，人类就设计了各种书面交流系统，从洞穴墙壁上的古代象形文字到现代塞满百科全书信息的闪存设备。只要人类在交流，就一直使用秘密手段将这些交流的真实含义隐藏在窥视的眼睛之外。古代社会使用复杂的秘密符号系统来标识战争时期的安全住所。现代文明使用各种代码和密码来促进个人和团体之间的私密通信。在以下章节中，您将了解现代密码学的演变以及几次著名的秘密拦截和破译加密通信的尝试。

### 凯撒密码

已知最早的密码系统之一由尤利乌斯·凯撒在征服欧洲期间用于与罗马的西塞罗通信。凯撒知道发送消息存在多种风险——信使可能是敌方间谍，或在前往部署部队的途中遭到伏击。因此，凯撒开发了一种现称为*凯撒密码*的加密系统。该系统极其简单。要加密消息，只需将字母表中的每个字母向右移动三位。例如，`A` 变为 `D`，`B` 变为 `E`。如果在此过程中到达字母表末尾，只需循环回到开头，因此 `X` 变为 `A`，`Y` 变为 `B`，`Z` 变为 `C`。因此，凯撒密码也被称为 `ROT3`（或 Rotate 3）密码。凯撒密码是一种单表替换密码。

以下是凯撒密码的实际示例。第一行包含原始句子，第二行显示使用凯撒密码加密后的句子。

```
THE DIE HAS BEEN CAST
WKH GLH KDV EHHQ FDVW
```

要解密消息，只需将每个字母向左移动三位。

### 美国内战

在凯撒时代至美国早期之间，科学家和数学家在古代文明使用的早期密码基础上取得了重大进展。在美国内战期间，联邦军和邦联军都使用了相对先进的加密系统在前线秘密通信，因为双方都在窃听电报线以监视对方。这些系统使用复杂的单词替换和置换组合（详见本章后面的“密码”部分）来试图挫败敌方的解密工作。内战期间广泛使用的另一个系统是由军医阿尔伯特·J·迈耶开发的一系列旗语信号。

### “超级”计划与“恩尼格玛”密码机

美国人并非唯一在制造优越编码机器上投入大量资源的一方。二战前，德国军工综合体将一款昵称为“恩尼格玛”的商用编码机改装为政府用途。该机器使用三到六个转子来实现极其复杂的替换密码。用当时的技术解密消息的唯一途径，是使用具有相同转子设置的类似机器（即发射设备使用的设置）。德国人认识到保护这些设备的重要性，使得盟军极难获取一台。

盟军发动了一项代号为“超级”的绝密行动，以攻破“恩尼格玛”密码。最终，他们的努力得到了回报：波兰军方成功重建了一个“恩尼格玛”原型机，并将研究成果分享给英美密码学专家。在艾伦·图灵的带领下，盟军于 1940 年成功破解了“恩尼格玛”密码，历史学家认为这一胜利在最终击败轴心国的过程中发挥了重要作用。盟军破解“恩尼格玛”的故事已被著名电影《U-571》和《模仿游戏》大众化。
