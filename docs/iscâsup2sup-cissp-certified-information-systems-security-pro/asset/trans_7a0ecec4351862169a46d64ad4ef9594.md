

## 环境控制：HVAC 与湿度

除了电源考量外，维护环境还涉及对 HVAC（供暖、通风与空调）机制的控制。主要用于放置计算机的机房，温度通常应保持在 60 至 75 华氏度（15 至 23 摄氏度）之间。不过，也存在一些极端环境：有的将设备运行温度降至 50 华氏度，有的则高于 90 华氏度。计算机机房的湿度应维持在 40% 至 60% 之间。湿度过高会导致腐蚀；湿度过低会产生静电。即使铺设了防静电地毯，若环境湿度过低，仍可能产生 20,000 伏的静电放电。正如 [表 10.1](#c10.xhtml#table10-1) 所示，即使是极低水平的静电放电也能损毁电子设备。

### 表 10.1 静电电压与损害

| 静电电压 | 可能造成的损害 |
| :--- | :--- |
| 40 V | 破坏敏感电路及其他电子元件 |
| 1,000 V | 扰乱显示器画面 |
| 1,500 V | 破坏硬盘上存储的数据 |
| 2,000 V | 导致系统突然关机 |
| 4,000 V | 打印机卡纸或元件损坏 |
| 17,000 V | 永久性电路损坏 |

## 水患问题（如泄漏、洪水）

水患问题（如泄漏和洪水）应在环境安全策略和程序中予以处理。管道泄漏虽非日常高发事件，但一旦发生，可能造成严重损害。

水电不相容。若计算机系统接触水，尤其是在运行状态下，必然导致损坏。此外，水和电还会给附近人员带来严重的触电风险。尽可能将服务器机房、数据中心和关键计算机设备安置在远离任何水源或输水管道的位置。您也可以在任务关键型系统周围的地板上安装水检测电路。一旦水逼近设备，水检测电路会发出警报并通知您。

为将紧急情况降至最低，应熟悉关断阀和排水口的位置。除了监控管道泄漏外，还应评估设施应对周边暴雨或洪水的能力。设施是位于山顶还是山谷？排水是否充足？是否有洪水或积水历史？服务器机房是设在地下室还是一楼？

## 火灾预防、探测与抑制

火灾预防、探测和抑制绝不可忽视。保护人员免受伤害，应始终是任何安全或防护系统的首要目标。除了保护人员，火灾探测和抑制旨在将火灾、烟雾、高温及抑制材料造成的损害降至最低，尤其是对 IT 基础设施的损害。

标准的火灾预防和处理培训涉及火灾三角（参见 [图 10.2](#c10.xhtml#figure10-2)）的知识。三角形的三个顶点分别代表燃料、热量和氧气。三角形中心代表这三种元素间的化学反应。火灾三角的要旨在于：若能从火灾三角中移除任一项（三要素加化学反应共四项），火灾即可被扑灭。不同的灭火介质针对火灾三角的不同方面：

*   **水**：降低温度。
*   **苏打酸及其他干粉**：抑制燃料供应。
*   **CO₂**：抑制氧气供应。
*   **卤代烷替代品及其他不燃气体**：干扰燃烧化学反应和/或抑制氧气供应。

![图 10.2 火灾三角](images/c10f002.jpg)

**图 10.2 火灾三角**

选择灭火介质时，应考虑其针对火灾三角的哪个方面、实际代表何意、通常灭火效果如何，以及对环境将产生何种影响。

除了理解火灾三角，还应了解火灾发展阶段。火灾会经历多个阶段，[图 10.3](#c10.xhtml#figure10-3) 展示了最关键的四个阶段。

![图 10.3 火灾的四个主要阶段](images/c10f003.jpg)

**图 10.3 火灾的四个主要阶段**

**阶段 1：初期阶段** 此阶段仅有空气电离，无烟雾产生。

**阶段 2：冒烟阶段** 起火点冒出可见烟雾。

**阶段 3：明火阶段** 肉眼可见火焰。

**阶段 4：高热阶段** 火势显著发展，热量剧烈积聚，区域内一切物品均开始燃烧。

火灾探测越早，扑灭越容易，其及灭火介质造成的损害也越小。

火灾管理的基础之一是人员意识培训。所有人员应彻底熟悉所在设施的灭火机制。每个人还应熟悉从主要工作区撤离的至少两条疏散路线，并知晓如何在设施其他位置寻找疏散路线。人员应接受灭火器位置和使用方法的培训。火灾或一般应急响应培训的其他内容包括：心肺复苏术（CPR）、紧急关机程序，以及预先设定的集合地点或安全核实机制（如语音信箱）。

### 灭火器

灭火器有多种类型。了解在各类火灾中应使用哪种灭火器，对有效灭火至关重要。若使用不当或选错类型，火势不但不会熄灭，反而可能蔓延加剧。灭火器仅适用于火灾仍处于初期阶段的情况。[表 10.2](#c10.xhtml#table10-2) 列出了三种常见类型的灭火器。

### 表 10.2 灭火器分类

| 类别 | 火灾类型 | 灭火剂 |
| :--- | :--- | :--- |
| A 类 | 普通可燃物 | 水、苏打酸（干粉或液体化学剂） |
| B 类 | 液体 | CO₂、卤代烷*、苏打酸 |
| C 类 | 电气设备 | CO₂、卤代烷* |
| D 类 | 金属 | 干粉 |

* 卤代烷或 EPA 批准的卤代烷替代品

### 火灾探测系统

要妥善保护设施免受火灾侵害，必须安装自动探测和抑制系统。火灾探测系统类型繁多：

*   **定温探测系统**：当温度达到特定值时触发灭火。触发装置通常是喷头中的金属或塑料部件，在特定温度下熔化。另一种版本包含装有化学药剂的小玻璃管，药剂在特定温度下汽化产生超压使容器破裂。
*   **升温速率探测系统**：当温度变化速率达到特定水平时触发灭火。
*   **火焰驱动系统**：基于火焰的红外能量触发灭火。
*   **烟雾驱动系统**：使用光电或放射性电离传感器作为触发器。
*   **初期烟雾探测系统**（又称吸气式传感器）：能在火灾通过其他手段被发现之前，探测到燃烧极早期通常伴随的化学物质。

大多数火灾探测系统可连接消防部门通报机制。触发灭火时，此类联动系统会通过自动消息或警报联系当地消防部门请求救援。
