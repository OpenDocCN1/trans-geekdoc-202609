

# APIPA

APIPA 通常不直接涉及安全问题。然而，它仍然是一个需要理解的重要问题。如果你发现某个系统被分配了 APIPA 地址而不是有效的网络地址，这表明存在问题。这可能只是像坏线缆或 DHCP 服务器断电这样平常的原因，但也可能是 DHCP 服务器遭受恶意攻击的症状。你可能会被要求在给出 IP 地址的场景中判断问题。你应该能够辨别某个地址是公网地址、RFC 1918 私有地址、APIPA 地址还是环回地址。

# 交换技术

当两个系统（单个计算机或局域网）通过多个中间网络连接时，将数据包从一个传输到另一个的任务是一个复杂的过程。为了简化这一任务，开发了交换技术。第一种交换技术是电路交换。

## 电路交换

**电路交换**最初是为在公用交换电话网上管理电话呼叫而开发的。在电路交换中，会在两个通信方之间创建一条专用的物理路径。一旦呼叫建立，双方之间的链路在整个通话过程中保持不变。这提供了固定或已知的传输时间、统一的质量水平，以及极少或没有信号丢失或通信中断。电路交换系统采用永久的物理连接。然而，*永久*一词仅适用于每个通信会话。该路径在单次通话期间是永久的。一旦路径断开，如果双方再次通信，可能会组装一条不同的路径。在单次通话期间，相同的物理或电子路径贯穿整个通信过程，且仅用于该次通信。电路交换授予当前通信伙伴对通信路径的独占使用权。只有在会话关闭后，路径才能被其他通信重用。

## 分组交换

最终，随着计算机通信的增加超过了语音通信，开发了一种新形式的交换。**分组交换**发生在消息或通信被分解成小段（通常是固定长度的分组，具体取决于所采用的协议和技术）并通过中间网络发送到目的地时。每个数据段都有自己的头部，其中包含源和目的地信息。每个中间系统读取头部，并用它将每个分组路由到其预期目的地。每个信道或通信路径仅在分组实际在其上传输时被保留使用。一旦分组发送完毕，该信道即可供其他通信使用。

分组交换不强制通信路径的独占性。它可以被视为一种逻辑传输技术，因为寻址逻辑决定了通信如何在通信伙伴之间穿越中间网络。[表 12.2](#c12.xhtml#table12-2) 对比了电路交换与分组交换。

### 表 12.2：电路交换 vs. 分组交换

| 电路交换 | 分组交换 |
| --- | --- |
| 恒定流量 | 突发流量 |
| 固定已知延迟 | 可变延迟 |
| 面向连接 | 无连接 |
| 对连接丢失敏感 | 对数据丢失敏感 |
| 主要用于语音 | 用于任何类型的流量 |

就安全而言，有几个潜在问题需要考虑。分组交换系统将来自不同源的数据放在同一物理连接上。这可能导致泄露、篡改或窃听。需要适当的连接管理、流量隔离，通常还需要加密，以防范共享物理路径带来的担忧。分组交换网络的一个优势是，它们不像电路交换那样依赖特定的物理连接。因此，当物理路径损坏或离线时，可以使用备用路径继续数据/分组传输。电路交换网络经常因物理路径故障而中断。

## 虚电路

**虚电路**（也称为通信路径）是在分组交换网络上两个特定端点之间创建的逻辑路径或电路。分组交换系统中有两种类型的虚电路：

*   **永久虚电路 (PVC)**
*   **交换虚电路 (SVC)**

PVC 类似于专用租用线路；逻辑电路始终存在并等待客户发送数据。PVC 是一种预定义的虚电路，始终可用。虚电路在不使用时可能会关闭，但需要时可即时重新打开。SVC 更像拨号连接，因为必须使用当前可用的最佳路径创建虚电路后才能使用，传输完成后再将其拆除。在任一类型的虚电路中，当数据包进入虚电路连接的 A 点时，该数据包会被直接发送到 B 点或虚电路的另一端。然而，同一传输中一个数据包的实际路径可能不同于另一个数据包的路径。换句话说，作为虚电路两端的 A 点和 B 点之间可能存在多条路径，但进入 A 点的任何数据包最终都会到达 B 点。

PVC 就像双向无线电或对讲机。每当需要通信时，你按下按钮开始说话；无线电会自动重新打开预定义的频率（即虚电路）。SVC 更像短波或业余无线电。每次想与某人通信时，你都必须将发射机和接收机调谐到新频率。

# WAN 技术

广域网链路用于连接远程的网络、节点或单个设备。这可以改善通信和效率，但也可能使数据面临风险。为了确保连接安全，尤其是在公共网络链路上，需要适当的连接管理和传输加密。WAN 链路和长距离连接技术可分为两大类：

**专用线路**（也称为**租用线路**或点对点链路）是无限期且持续为特定客户保留使用的线路（参见[表 12.3](#c12.xhtml#table12-3)）。专用线路始终开启并等待传输流量。客户局域网与专用 WAN 链路之间的链接始终是开放且已建立的。专用线路连接两个特定端点，且仅连接这两个端点。

### 表 12.3：专用线路示例

| 技术 | 连接类型 | 速度 |
| --- | --- | --- |
| 数字信号级别 0 (DS-0) | 部分 T1 | 64 Kbps 至 1.544 Mbps |
| 数字信号级别 1 (DS-1) | T1 | 1.544 Mbps |
| 数字信号级别 3 (DS-3) | T3 | 44.736 Mbps |
| 欧洲数字传输格式 1 | E1 | 2.108 Mbps |
| 欧洲数字传输格式 3 | E3 | 34.368 Mbps |
| 电缆调制解调器或电缆路由器 | | 10+ Mbps |

**非专用线路**是指在数据传输发生前需要建立连接的线路。非专用线路可用于连接任何使用相同类型非专用线路的远程系统。

标准调制解调器、DSL 和 ISDN 是非专用线路的示例。数字用户线路 (DSL) 是一种利用升级后的电话网络为消费者提供 144 Kbps 至 20 Mbps（或更高）速度的技术。DSL 有多种格式，如 ADSL、xDSL、CDSL、HDSL、SDSL、RASDSL、IDSL 和 VDSL。每种格式在具体提供下行和上行带宽方面有所不同。
