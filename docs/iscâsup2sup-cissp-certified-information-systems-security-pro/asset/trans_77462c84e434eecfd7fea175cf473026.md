
DSL 线路距离中心局（即电话网络的一种特定类型的分发节点）的最大距离约为 5,000 米。

*综合业务数字网 (ISDN)* 是一种完全数字化的电话网络，同时支持语音和高速数据通信。ISDN 服务有两种标准类别或格式：

*   **基本速率接口 (BRI)** 为客户提供包含两个 B 信道和一个 D 信道的连接。B 信道支持 64 Kbps 的吞吐量，用于数据传输。D 信道用于呼叫建立、管理和拆除，带宽为 16 Kbps。尽管 D 信道并非设计用于支持数据传输，但 BRI ISDN 被称为可为用户提供总计 144 Kbps 的总吞吐量。

*   **主速率接口 (PRI)** 为用户提供包含多个 64 Kbps B 信道（2 到 23 个）和一个 64 Kbps D 信道的连接。因此，PRI 可部署的带宽范围从 192 Kbps 到 1.544 Mbps。但请记住，这些数字是带宽而非吞吐量，因为它们包含了不能用于实际数据传输的 D 信道（至少在大多数正常的商业实现中不能）。

### WAN 连接技术

对于需要多个地点之间甚至外部合作伙伴之间通信服务的公司，有许多可用的 WAN 连接技术。这些 WAN 技术在成本和吞吐量方面差异很大。然而，大多数共享一个共同特性：对连接的 LAN 或系统是透明的。WAN 交换机、专用路由器或边界连接设备提供了网络运营商服务与公司 LAN 之间所需的所有接口。边界连接设备称为 *信道服务单元/数据服务单元 (CSU/DSU)*。这些设备将 LAN 信号转换为 WAN 运营商网络使用的格式，反之亦然。CSU/DSU 包含 *数据终端设备/数据电路终接设备 (DTE/DCE)*，它为 LAN 的路由器（DTE）和 WAN 运营商网络的交换机（DCE）提供实际的连接点。CSU/DSU 充当转换器、存储转发设备和链路调节器。WAN 交换机只是针对特定类型的运营商网络、内置 CSU/DSU 的 LAN 交换机的专用版本。有许多类型的运营商网络或 WAN 连接技术，例如 `X.25`、`Frame Relay`、`ATM` 和 `SMDS`。

#### X.25 WAN 连接

*X.25* 是一种较老的分组交换技术，曾在欧洲广泛使用。它使用永久虚拟电路在两个系统或网络之间建立特定的点对点连接。它是 Frame Relay 的前身，运作方式大致相同。由于与 Frame Relay 或 ATM 相比，其性能和吞吐率较低，X.25 的使用正在减少。然而，即使是 Frame Relay 和 ATM 也计划退役，因为它们正被光纤和无线解决方案取代。

#### Frame Relay 连接

与 X.25 类似，*Frame Relay* 也是一种分组交换技术，也使用 PVC（参见虚拟电路的讨论）。然而，与 X.25 不同的是，Frame Relay 支持在单个 WAN 运营商服务连接上建立多个 PVC。Frame Relay 是一种第 2 层连接机制，它使用分组交换技术在通信端点之间建立虚拟电路。与专线或租用线（其成本主要基于端点间的距离）不同，Frame Relay 的成本主要基于传输的数据量。Frame Relay 网络是一种共享介质，通过在其上创建虚拟电路来提供点对点通信。所有虚拟电路彼此独立且不可见。

与 Frame Relay 相关的一个关键概念是 *承诺信息速率 (CIR)*。CIR 是服务提供商向客户保证的最小带宽。它通常远低于提供商网络的实际最大能力。每个客户可能会在其合同中建立并定义不同的 CIR。当有额外带宽可用时，服务网络提供商可能允许客户在短时间内超过其 CIR。这称为按需带宽。（尽管乍一听这似乎是一项杰出的福利，但现实是客户需为额外消耗的带宽支付溢价。）Frame Relay 作为一种面向连接的分组交换传输技术，在 OSI 模型的第 2 层（数据链路层）运行。

Frame Relay 要求在每个连接点使用 DTE/DCE。客户拥有 DTE，它充当路由器或交换机，为客户网络提供对 Frame Relay 网络的访问。Frame Relay 服务提供商拥有 DCE，它执行数据在 Frame Relay 上的实际传输，以及为客户建立和维护虚拟电路。然而，Frame Relay 现在是一种较老的技术，正在被更快的光纤解决方案逐步淘汰。

#### ATM

*异步传输模式 (ATM)* 是一种单元交换 WAN 通信技术，不同于像 Frame Relay 这样的分组交换技术。它将通信分片为固定长度的 53 字节单元。固定长度单元的使用使 ATM 能够非常高效并提供高吞吐量。ATM 可以使用 PVC 或 SVC。与 Frame Relay 提供商一样，ATM 提供商可以为其租用服务保证最小带宽和特定的服务质量等级。当服务网络上有可用带宽时，客户通常可以按需消耗额外带宽，并按使用付费。ATM 是一种面向连接的分组交换技术。然而，ATM 现在是一种较老的技术，正在被更快的光纤解决方案逐步淘汰。

#### SMDS

*交换多兆位数据服务 (SMDS)* 是一种无连接的分组交换技术。通常，SMDS 用于连接多个 LAN 以形成城域网 (MAN) 或广域网 (WAN)。SMDS 曾是连接通信不频繁的远程 LAN 的首选连接机制。SMDS 支持高速突发流量和按需带宽。它将数据分片为小的传输单元。

#### 同步数字体系和同步光网络

同步数字体系 (SDH) 和同步光网络 (SONET) 是光纤高速网络标准。SDH 由国际电信联盟 (ITU) 标准化，SONET 由美国国家标准协会 (ANSI) 标准化。SDH 和 SONET 主要是硬件或物理层标准，定义基础设施和线路速率要求。SDH 和 SONET 使用同步时分复用 (TDM) 实现高速双工通信，且只需极少的控制和管理开销。

这两个标准只有细微差别，并使用相同的带宽级别层次结构。传输服务支持 51.48 Mbps 的基础速度级别，该级别支持 SDH 的同步传输信号 (STS) 和/或 SONET 的同步传输模块 (STM)。光载波 (OC) 一词也可替代 STS。SDH 和 SONET 的主要带宽级别如 [表 12.4](#c12.xhtml#table12-4) 所示。
