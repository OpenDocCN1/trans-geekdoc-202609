

# SQL 注入及相关攻击

归根结底，SQL 注入是处理前端（通常是 Web 服务器）与后端数据库交互的脚本的漏洞。如果脚本编写时采取了防御措施，并包含转义（使无效或拒绝）元字符的代码，则 SQL 注入将不可能发生。

## LDAP 注入

**LDAP 注入**是输入注入攻击的一种变体；然而，攻击的焦点在于 LDAP 目录服务的后端，而非数据库服务器。如果 Web 服务器前端使用脚本根据用户输入构建 LDAP 语句，则 LDAP 注入可能构成威胁。正如 SQL 注入一样，输入清理和防御性编码对于消除此威胁至关重要。

## XML 注入

**XML 注入**是 SQL 注入的另一种变体，其后端目标是 XML 应用程序。同样，输入清理对于消除此威胁是必要的。

## XML 利用

**XML 利用**是一种编程攻击形式，用于伪造发送给访问者的信息，或导致其系统在未经授权的情况下泄露信息。关于 XML 攻击，一个日益令人担忧的领域是**安全断言标记语言 (SAML)**。SAML 滥用通常集中在基于 Web 的身份认证上。SAML 是一种基于 XML 的约定，用于在安全域之间组织和交换通信身份认证和授权详细信息，通常通过 Web 协议进行。SAML 常用于提供基于 Web 的 SSO（单点登录）解决方案。如果攻击者能够伪造 SAML 通信或窃取访问者的访问令牌，他们可能能够绕过身份认证并获得对站点的未授权访问。

## 跨站脚本 (XSS)

**跨站脚本 (XSS)** 是一种恶意代码注入攻击形式，攻击者能够攻破 Web 服务器，并将其自己的恶意代码注入发送给其他访问者的内容中。黑客已经发现了许多巧妙的方法，通过通用网关接口 (CGI) 脚本、Web 服务器软件漏洞、SQL 注入攻击、框架利用、DNS 重定向、Cookie 劫持以及许多其他形式的攻击，将恶意代码注入网站。成功的 XSS 攻击可能导致身份盗窃、凭证窃取、数据窃取、财务损失，或在访问客户端上植入远程控制软件。

对于网站管理员而言，防御 XSS 的措施包括维护已修补的 Web 服务器、使用 Web 应用防火墙、运行基于主机的入侵检测系统 (HIDS)、审计可疑活动，最重要的是执行服务器端输入验证，包括长度检查、恶意内容检查和元字符过滤。作为 Web 用户，您可以通过保持系统已修补、运行防病毒软件、避免访问非主流网站来防御 XSS。某些 Web 浏览器有插件，例如 Firefox 的 NoScript 和 Chrome 的 uBlock Origin，它们仅允许执行您选择的脚本。

## 跨站请求伪造 (XSRF)

**跨站请求伪造 (XSRF)** 是一种性质类似于 XSS 的攻击。然而，XSRF 的攻击焦点更多地在于访问用户的 Web 浏览器，而非被访问的网站。XSRF 的主要目的是诱骗用户或用户的浏览器执行其未打算或未授权的操作。这可能包括注销会话、上传站点 Cookie、更改账户信息、下载账户详情、进行购买等。XSRF 的一种形式会用恶意软件感染受害者的系统，该软件保持休眠状态，直到访问特定网站。然后恶意软件以用户身份伪造请求，以欺骗 Web 服务器并对 Web 服务器和/或客户端执行恶意操作。

利用 XSRF 的一个此类漏洞示例是 Zeus，它会隐藏在受害者的系统中，直到用户访问其网上银行站点；随后，在检查其账户余额并确定其银行账号后，这些详细信息会被发送给控制攻击者，后者会发起 ACH 转账到另一家银行。因此，这是恶意软件协助直接从受害者账户窃取资金的一个示例。

网站管理员可以通过在连接的客户端请求敏感或高风险操作时要求确认或重新认证，来实施针对 XSRF 的预防措施。这可能包括要求用户重新输入密码、通过短信或电子邮件向用户发送必须提供回网站的代码、触发基于电话的验证，或解决全自动区分计算机和人类的图灵测试 (CAPTCHA)（一种区分人类和软件机器人的机制）。另一种潜在的保护机制是向每个 URL 请求和会话建立添加一个随机字符串（称为**一次性数 (nonce)**），并检查客户端 HTTP 请求头引用页是否存在欺骗。最终用户可以养成更安全的习惯，例如运行反恶意软件扫描器；使用 HIDS；运行防火墙；避免访问非主流网站；始终从网站注销，而不是关闭浏览器、关闭标签页或转到另一个 URL；保持浏览器已修补；并定期清理临时文件和缓存的 Cookie。

关于 XSS 和 XSRF 的更多内容，请参见第 21 章“恶意代码和应用程序攻击”。

# 评估和缓解移动系统中的漏洞

随着智能手机和其他**移动设备**越来越多地具备与互联网以及企业网络交互的能力，它们带来的安全风险也日益增加。当个人拥有的设备被允许在没有限制、监督或控制的情况下进出安全设施时，潜在危害是巨大的。

恶意内部人员可以通过各种存储设备从外部带入恶意代码，包括手机、音频播放器、数码相机、存储卡、光盘和通用串行总线 (USB) 驱动器。这些相同的存储设备可用于泄露或窃取内部机密和私人数据，以便向外界披露。（您认为 WikiLeaks 上的大部分内容来自哪里？）恶意内部人员可以执行恶意代码、访问危险网站，或故意执行有害活动。

移动设备通常包含敏感数据，如联系人、短信、电子邮件，以及可能的笔记和文档。任何带有摄像头功能的移动设备都可以拍摄敏感信息或地点的照片。移动设备的丢失或被盗可能意味着个人和/或企业机密的泄露。

移动设备是黑客和恶意代码的常见目标。重要的是要将非必要信息保留在便携设备之外，运行防火墙和防病毒产品（如果可用），并保持系统锁定和/或加密（如果可能）。

许多移动设备还支持 USB 连接，以便与台式机和/或笔记本电脑同步通信和联系人，以及传输文件、文档、音乐、视频等。

此外，移动设备也无法免疫窃听。借助合适类型的复杂设备，大多数移动电话通话都可能被窃听——更不用说任何 15 英尺范围内的人都能听到您在说话。通过手机讨论事情时要小心，尤其是在公共场所。

移动设备上提供了广泛的安全功能。然而，支持某项功能并不等同于该功能已正确配置并启用。只有当安全功能生效时，才能获得安全收益。请务必检查设备上所有期望的安全功能是否按预期运行。
