
尽管许多供应商建议在所有系统上安装基于主机的 IDS，但由于 HIDS 的一些缺点，这种做法并不普遍。相反，许多组织选择仅在关键服务器上安装 HIDS，作为一种额外的保护层。HIDS 的一些缺点与成本和易用性有关。HIDS 的管理成本高于 NIDS，因为它们需要对每个系统进行单独的管理关注，而 NIDS 通常支持集中管理。HIDS 无法检测针对其他系统的网络攻击。此外，它通常会消耗大量的系统资源，从而降低主机系统的性能。虽然通常可以限制 HIDS 使用的系统资源，但这可能导致其错过正在进行的攻击。此外，HIDS 更容易被入侵者发现并禁用，且其日志保存在系统上，一旦攻击成功，日志就容易被篡改。

## 基于网络的 IDS

NIDS 监控并评估网络活动，以检测攻击或事件异常。单个 NIDS 可以通过使用远程传感器在关键网络位置收集数据，并将数据发送到中央管理控制台和/或 SIEM，从而监控大型网络。这些传感器可以监控路由器、防火墙、支持端口镜像的网络交换机以及其他类型的网络分流器上的流量。

中央控制台通常安装在一台专用计算机上，该计算机经过加固以抵御攻击。这减少了 NIDS 中的漏洞，并使其能够近乎隐形地运行，从而使攻击者更难发现并禁用它。NIDS 对整体网络性能的负面影响微乎其微，当部署在专用系统上时，它不会对任何其他计算机的性能产生不利影响。在流量巨大的网络上，单个 NIDS 可能无法跟上数据流，但可以通过添加额外的系统来平衡负载。

通常，NIDS 可以通过执行反向地址解析协议 (RARP) 或反向域名系统 (DNS) 查找来发现攻击源。然而，由于攻击者经常欺骗 IP 地址或通过僵尸网络利用僵尸主机发起攻击，因此需要进一步调查以确定实际来源。这可能是一个繁琐的过程，且超出了 IDS 的范围。不过，通过一定的调查，有可能发现欺骗 IP 的来源。

NIDS 通常能够检测攻击的发起或正在进行的攻击，但并不总能提供关于攻击是否成功的信息。它无法知晓攻击是否影响了特定系统、用户账户、文件或应用程序。例如，NIDS 可能会发现缓冲区溢出漏洞利用代码通过网络发送，但不一定知道该漏洞利用是否成功渗透了系统。然而，管理员收到警报后可以检查相关系统。此外，调查人员可以将 NIDS 日志作为审计追踪的一部分，以了解发生了什么。

### 入侵防御系统

入侵防御系统 (IPS) 是一种特殊类型的主动 IDS，它试图在攻击到达目标系统之前检测并阻止攻击。它有时被称为入侵检测与防御系统 (IDPS)。IDS 和 IPS 之间的一个显著区别在于 IPS 部署在流量的直通路径上，如[图 17.4](#c17.xhtml#figure17-4)所示。换句话说，所有流量都必须经过 IPS，IPS 在分析后可以选择转发哪些流量、阻止哪些流量。这使得 IPS 能够防止攻击到达目标。

相比之下，未部署在直通路径上的主动 IDS 只能在活动到达目标后进行检查。主动 IDS 可以在攻击开始后采取措施进行阻止，但无法预防攻击。

IPS 可以使用基于知识的检测和/或基于行为的检测，就像其他任何 IDS 一样。此外，它还可以记录活动并向管理员提供通知，就像 IDS 所做的那样。

## 具体预防措施

尽管入侵检测和防御系统在保护网络方面发挥了巨大作用，但管理员通常还会实施额外的安全控制来保护其网络。以下几节将介绍其中几种作为额外的预防措施。

### 蜜罐/蜜网

*蜜罐* 是作为诱捕入侵者陷阱而创建的单个计算机。*蜜网* 是两个或多个联网的蜜罐，它们协同工作以模拟一个网络。它们看起来并表现得像合法系统，但不存放对攻击者有任何真实价值的数据。管理员通常会配置带有漏洞的蜜罐，以引诱入侵者攻击它们。它们可能未打补丁，或者管理员故意留下安全漏洞。目的是吸引入侵者的注意力，使其远离托管宝贵资源的合法网络。合法用户不会访问蜜罐，因此对蜜罐的任何访问极有可能是未经授权的入侵者。

除了将攻击者隔离在生产环境之外，蜜罐还为管理员提供了一个在不危及实时环境的情况下观察攻击者活动的机会。在某些情况下，蜜罐的设计目的是拖延入侵者足够长的时间，以便自动化 IDS 检测到入侵并尽可能多地收集关于入侵者的信息。攻击者在蜜罐上花费的时间越长，管理员调查攻击并潜在识别入侵者的时间就越多。一些安全专业人员（如从事安全研究的人员）认为蜜罐是针对零日漏洞利用的有效对策，因为它们可以观察攻击者的行为。

管理员通常在虚拟系统上托管蜜罐和蜜网。攻击发生后，这些系统更容易重建。例如，管理员可以配置蜜罐，然后对蜜罐虚拟机进行快照。如果攻击者修改了环境，管理员可以将机器恢复到快照时的状态。使用虚拟机 (VM) 时，管理员应密切监控蜜罐或蜜网。攻击者通常能检测出自己身处 VM 中，并可能尝试 VM 逃逸攻击以突破 VM。

蜜罐的使用引发了诱惑与诱捕的问题。如果入侵者是在蜜罐所有者没有任何外部努力的情况下自行发现蜜罐，组织可以合法地将蜜罐作为诱惑装置使用。将一个带有开放安全漏洞和已知漏洞利用的活动服务的系统放置在互联网上属于诱惑。被诱惑的攻击者会自行决定实施非法或未经授权的行为。诱捕是非法的，当蜜罐所有者主动招揽访问者访问该站点，然后指控其未经授权的入侵时，就会发生诱捕。换句话说，当你欺骗或鼓励某人实施非法或未经授权的行为时，这就是诱捕。不同国家的法律各异，因此了解当地关于诱惑和诱捕的相关法律非常重要。
