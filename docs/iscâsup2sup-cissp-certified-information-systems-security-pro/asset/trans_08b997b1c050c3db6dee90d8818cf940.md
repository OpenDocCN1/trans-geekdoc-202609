

# 数据存储系统的信息安全威胁

信息安全专业人员应了解针对数据存储系统的两大主要威胁。首先，无论使用何种类型的存储，非法访问存储资源的威胁始终存在。如果管理员未实施足够的文件系统访问控制，入侵者可能仅通过浏览文件系统就偶然发现敏感数据。在更敏感的环境中，管理员还应防范绕过操作系统控制并直接访问物理存储介质以检索数据的攻击。这最好通过使用加密文件系统来实现，该文件系统仅可通过主操作系统访问。此外，在多级安全环境中运行的系统应提供足够的控制，以确保共享内存和存储资源设置了失效安全控制，使得某一密级的数据在较低密级下不可读。

隐蔽通道攻击构成了针对数据存储资源的第二大主要威胁。隐蔽存储通道允许通过直接或间接操纵共享存储介质，在密级之间传输敏感数据。这可能仅仅是将敏感数据写入无意中共享的内存部分或物理存储中。更复杂的隐蔽存储通道可能被用来操纵磁盘上的可用空间大小或文件的大小，以隐蔽地在安全级别之间传递信息。有关隐蔽通道分析的更多信息，请参见第 8 章“安全模型、设计与能力原则”。

# 理解基于知识的系统

自计算机诞生以来，工程师和科学家一直致力于开发能够执行常规操作的系统，这些操作会让人类感到厌烦并消耗大量时间。该领域的大多数成就都集中在减轻计算密集型任务的负担上。然而，研究人员在开发具有“人工智能”且能模拟（某种程度上）纯人类推理能力的系统方面也取得了巨大进展。

以下部分将探讨两种基于知识的人工智能系统：专家系统和神经网络。我们还将了解它们在计算机安全问题上的潜在应用。

## 专家系统

专家系统旨在体现特定主题专家的积累知识，并以一致的方式将其应用于未来的决策。多项研究表明，当专家系统得到妥善开发和实施时，在面对常规决策时，其决策往往优于部分人类对应者。

每个专家系统都有两个主要组件：知识库和推理引擎。

知识库包含专家系统已知的规则。知识库旨在将人类专家的知识编纂为一系列“如果/那么”语句。让我们考虑一个简单的专家系统，旨在帮助房主决定当飓风来袭时是否应撤离该区域。知识库可能包含以下语句（这些语句仅为示例）：

* 如果飓风为 4 级或更高，则洪水通常会达到海平面以上 20 英尺的高度。
* 如果飓风风速超过 120 英里/小时 (mph)，则木结构建筑将被摧毁。
* 如果处于飓风季节末期，则飓风在逼近海岸时往往会变得更强。

在实际的专家系统中，知识库将包含数百或数千条类似上述的断言。

专家系统的第二个主要组件——推理引擎——分析知识库中的信息以得出适当的决策。专家系统用户通过某种用户界面向推理引擎提供当前情况的详细信息，推理引擎结合逻辑推理和模糊逻辑技术，基于过去的经验得出结论。继续以飓风为例，用户可能会告知专家系统一个 4 级飓风正以平均 140 英里/小时的风速逼近海岸。推理引擎将分析知识库中的信息，并基于这些过往知识做出撤离建议。

专家系统并非万无一失——它们的优劣取决于知识库中的数据和推理引擎中实现的决策算法。然而，它们在压力情境下有一个主要优势——其决策不涉及被情绪模糊的判断。专家系统可在分析紧急事件、股票交易及其他情感投入有时会妨碍逻辑决策的场景中发挥重要作用。因此，许多贷款机构现在使用专家系统做出信贷决策，而不依赖可能会想“吉姆虽未按时还款，但他看起来是个挺好的人”的贷款官员。

## 机器学习

机器学习技术利用分析能力从数据集中开发知识，而无需直接应用人类洞察。机器学习的核心方法是允许计算机直接分析数据并从中学习，开发和更新活动模型。

机器学习技术分为两大类。

* **监督学习** 技术使用标记数据进行训练。创建机器学习模型的分析师提供数据集及正确答案，并允许算法开发可应用于未来案例的模型。例如，如果分析师想开发恶意系统登录的模型，分析师将提供一段时间内系统登录信息的数据集，并标明哪些是恶意的。算法将利用这些信息开发恶意登录的模型。
* **无监督学习** 技术使用未标记数据进行训练。提供给算法的数据集不包含“正确”答案；相反，算法被要求独立开发模型。在登录案例中，算法可能被要求识别相似登录的群组。分析师随后可查看算法开发的群组，并尝试识别可能为恶意的群组。

## 神经网络

在神经网络中，计算单元链被用来尝试模仿人类大脑的生物推理过程。在专家系统中，一系列规则存储在知识库中；而在神经网络中，则建立了一条长长的计算决策链，它们相互馈送并最终求和以产生所需输出。神经网络是机器学习技术的延伸，也常被称为*深度学习*或认知系统。

请记住，迄今为止设计的任何神经网络都远未达到人类思维的推理能力。尽管如此，神经网络显示出巨大潜力，可将人工智能领域推向当前状态之外。神经网络的优势包括线性、输入输出映射和自适应性。这些优势在语音识别、人脸识别、天气预测以及思维和意识模型探索的神经网络实现中显而易见。
