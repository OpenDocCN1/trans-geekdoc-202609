
在本章前面关于一次性密码本的讨论中，你了解到一次性密码本算法的主要优势源于它使用极长密钥这一事实。事实上，对于该算法，密钥长度至少与消息本身一样长。大多数现代密码系统使用的密钥没有那么长，但密钥长度仍然是决定密码系统强度以及加密不被密码分析技术破解的可能性的一个极其重要的因素。

计算能力的快速提升使你能够在密码学工作中使用越来越长的密钥。然而，这种计算能力也掌握在试图破解你所用算法的密码分析师手中。因此，必须使用足够长的密钥来击败当代密码分析工作，从而超越对手。此外，如果你想提高数据在未来一段时间内免受密码分析威胁的安全几率，必须努力使用能在数据必须保密的整个时间段内，超越预期密码分析能力增长的密钥。例如，量子计算的出现可能会改变密码学，使当前的密码系统变得不安全，正如本章前面所讨论的那样。

几十年前，当数据加密标准（`DES`）被创建时，56 位密钥被认为足以维护任何数据的安全。然而，现在普遍认为 56 位 `DES` 算法不再安全，这是因为密码分析技术和超级计算能力的进步。现代密码系统使用至少 128 位的密钥来保护数据免受窥探。请记住，密钥长度与密码系统的工作函数直接相关：密钥越长，破解密码系统就越困难。

### 对称密钥算法

对称密钥算法依赖于分发给所有参与通信成员的“共享密钥”。该密钥由所有参与方用于加密和解密消息，因此发送方和接收方都持有共享密钥的副本。发送方使用共享密钥加密，接收方使用该密钥解密。当使用大尺寸密钥时，对称加密非常难以破解。它主要用于执行批量加密，且仅提供机密性安全服务。对称密钥密码学也称为 `secret key cryptography`（秘密密钥密码学）和 `private key cryptography`（私钥密码学）。[图 6.3](#c06.xhtml#figure6-3) 说明了对称密钥加密和解密过程。

对称密钥密码学有几个弱点。

**密钥分发是一个主要问题。** 在使用对称密钥协议建立通信之前，各方必须有一种安全的方法来交换秘密密钥。如果没有可用的安全电子通道，通常必须使用离线密钥分发方法（即带外交换）。

**对称密钥密码学不实现不可抵赖性。** 因为任何通信方都可以使用共享密钥加密和解密消息，所以无法证明给定消息的来源。

**算法不可扩展。** 大型群体使用对称密钥密码学进行通信极其困难。组内个人之间的安全私密通信只有在每一对可能的用户组合共享一个私钥时才能实现。

**密钥必须频繁重新生成。** 每当一名参与者离开群体时，该参与者所知的所有密钥都必须废弃。

对称密钥密码学的主要优势在于其运行速度极快。对称密钥加密非常快，通常比非对称算法快 1,000 到 10,000 倍。由于所涉及数学的本质，对称密钥密码学也天然适合硬件实现，从而创造了更高速操作的机会。

本章后面的“对称密码学”部分将详细介绍当今使用的主要秘密密钥算法。

### 非对称密钥算法

`Asymmetric key algorithms`（非对称密钥算法），也称为 `public key algorithms`（公钥算法），为对称密钥加密的弱点提供了解决方案。在这些系统中，每个用户有两个密钥：一个公钥，与所有用户共享；一个私钥，保密且仅用户本人知道。但这里有个转折：必须成对使用相反且相关的密钥来进行加密和解密。换句话说，如果公钥加密消息，则只有相应的私钥能解密它，反之亦然。

[图 6.4](#c06.xhtml#figure6-4) 显示了公钥密码系统中用于加密和解密消息的算法。考虑这个例子。如果 Alice 想使用公钥密码学向 Bob 发送消息，她创建消息，然后使用 Bob 的公钥对其加密。解密该密文的唯一可能方法是使用 Bob 的私钥，而拥有该密钥访问权限的唯一用户是 Bob。因此，Alice 加密后甚至无法自己解密该消息。如果 Bob 想回复 Alice，他只需使用 Alice 的公钥加密消息，然后 Alice 使用她的私钥解密即可读取消息。

非对称密钥算法还支持数字签名技术。基本上，如果 Bob 想向其他用户保证一条以他名义发送的消息确实是由他发送的，他首先使用哈希算法创建消息摘要（下一节将详细介绍哈希算法）。然后 Bob 使用他的私钥加密该摘要。任何想要验证签名的用户只需使用 Bob 的公钥解密消息摘要，然后验证解密后的消息摘要是否准确。第 7 章将更详细地解释此过程。

以下是非对称密钥密码学主要优势的列表：

**添加新用户只需生成一对公私钥。** 同一密钥对用于与非对称密码系统的所有用户通信。这使得算法具有极强的可扩展性。

**从非对称系统中移除用户要容易得多。** 非对称密码系统提供密钥吊销机制，允许取消密钥，从而有效地将用户从系统中移除。

**只有在用户的私钥泄露时才需要重新生成密钥。** 如果用户离开社区，系统管理员只需使该用户的密钥失效。没有其他密钥被泄露，因此不需要为任何其他用户重新生成密钥。

**非对称密钥加密可提供完整性、认证和不可抵赖性。** 如果用户不与其他个人共享其私钥，则由该用户签名的消息可被证明是准确且来自特定来源的，且事后无法抵赖。

**密钥分发是一个简单的过程。** 想要参与系统的用户只需将其公钥提供给他们想通信的任何人。没有任何方法可以从公钥推导出私钥。
