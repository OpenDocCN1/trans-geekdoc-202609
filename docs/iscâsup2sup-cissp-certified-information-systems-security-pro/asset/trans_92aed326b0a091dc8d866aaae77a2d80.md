

# 日志记录与监控

日志记录与监控若与有效的身份识别和认证实践相结合，可提供整体的问责性。

## 日志记录

日志记录涉及在日志和数据库文件中记录事件。安全日志、系统日志、应用日志、防火墙日志、代理日志和变更管理日志都是常见的日志文件。日志文件包含有价值的数据，应受到保护以确保它们不被修改、删除或损坏。如果得不到保护，攻击者通常会尝试修改或删除它们，并且它们将无法作为起诉攻击者的证据被采纳。

## 监控

监控涉及实时审查日志，以及稍后作为审计一部分进行审查。审计追踪是通过将有关事件和发生情况的信息记录到一个或多个数据库或日志文件中而创建的记录，可用于重建事件、提取事件相关信息，以及证明或反驳过错。审计追踪提供了一种被动形式的侦查型安全控制，并以与闭路电视（CCTV）或保安相同的方式起到威慑作用。此外，它们在起诉罪犯时可作为关键证据。日志可能非常大，因此会使用不同的方法来分析它们或减小其大小。抽样是一种用于分析日志的统计方法，而使用截断水平是一种非统计方法，涉及关注项的预定义阈值。

## 访问控制审计

可使用不同类型的审计和评估来评估访问控制的有效性。审计是对环境进行的有条不紊的检查或评估，以确保符合法规并检测异常、未经授权的事件或彻头彻尾的犯罪行为。访问评审审计确保对象访问和账户管理实践支持组织的安全策略。用户权利审计确保人员遵循最小权限原则。

## 审计报告

审计记录文档记录审计的结果。这些报告应受到保护，且分发应仅限于组织内的特定人员。高级管理层和安全专业人员需要访问安全审计的结果，但如果攻击者获得审计报告的访问权限，他们可利用该信息识别可利用的漏洞。

## 安全审计与评估

安全审计和评估通常用于保证控制措施按指示实施并按预期运行。通常会包含审计和评估来检查补丁管理、漏洞管理、变更管理和配置管理项目。

# 考试精要

## 了解事件响应步骤

CISSP 安全运营领域将事件响应步骤列为：检测、响应、缓解、报告、恢复、补救和经验教训。在检测并验证事件后，首要响应是在保护证据的同时限制或遏制事件的范围。根据管辖法律，组织可能需要向官方机构报告事件，如果个人身份信息（PII）受到影响，则需要通知相关个人。补救和经验教训阶段包括根因分析，以确定原因并推荐解决方案以防止再次发生。

## 了解基本预防措施

基本预防措施可防止许多事件的发生。这些措施包括：保持系统最新、移除或禁用不需要的协议和服务、使用入侵检测和防御系统、使用具有最新特征库的反恶意软件，以及同时启用基于主机和基于网络的防火墙。

## 了解拒绝服务（DoS）攻击

DoS 攻击会阻止系统响应合法的服务请求。常见的 DoS 攻击是 SYN 洪水攻击，它会破坏 TCP 三次握手。尽管由于基本防范措施能阻止它们，较旧的攻击如今不那么常见，但你仍可能会被测试这些内容，因为许多较新的攻击通常是旧方法的变体。Smurf 攻击利用放大网络向受害者发送大量响应数据包。Ping-of-death 攻击（死之 Ping 攻击）向受害者发送大量超大 Ping 数据包，导致受害者冻结、崩溃或重启。

## 了解僵尸网络、僵尸网络控制器和牧羊人

僵尸网络因可发起攻击的海量计算机而构成重大威胁，因此了解它们是什么很重要。僵尸网络是由被称为“僵尸网络牧羊人”的犯罪分子控制的、被攻陷的计算设备集合（通常称为僵尸或肉鸡），并组织成一个网络。牧羊人使用命令与控制服务器远程控制僵尸，并经常利用僵尸网络对其他系统发起攻击，或发送垃圾邮件或钓鱼邮件。牧羊人还将僵尸网络的访问权限出租给其他犯罪分子。

## 了解零日漏洞利用

零日漏洞利用是一种利用漏洞的攻击，该漏洞要么仅攻击者知晓，要么仅为数不多的一小群人知晓。表面上听起来似乎无法防范未知漏洞，但基本安全实践在防止零日漏洞利用方面大有裨益。移除或禁用不需要的协议和服务可减少攻击面，启用防火墙可阻断许多访问点，使用入侵检测和防御系统有助于检测和阻止潜在攻击。此外，使用蜜罐和加固单元等工具有助于保护生产网络。

## 了解中间人攻击

当恶意用户能够获得通信链路两个端点之间的逻辑位置时，就会发生中间人攻击。尽管攻击者完成中间人攻击需要相当高的技术水平，但从攻击中获得的数据量可能非常巨大。

## 了解破坏与间谍活动

如果内部人员因某些原因变得不满，他们可能会对组织实施破坏。间谍活动是指竞争对手试要窃取信息，他们可能会利用内部员工。基本安全原则，如实施最小权限原则并立即禁用离职员工的账户，可限制这些攻击造成的损害。

## 了解入侵检测与入侵防御

IDS 和 IPS 是针对攻击的重要侦查型和预防型措施。了解基于知识的检测（使用类似于反恶意软件特征库的数据库）和基于行为的检测之间的区别。基于行为的检测以基线为起点以识别正常行为，并将活动与基线进行比较以检测异常活动。如果网络被修改，基线可能会过时，因此环境变更时必须更新基线。

## 识别 IDS/IPS 响应

IDS 可以通过记录日志和发送通知被动响应，或通过改变环境主动响应。有些人将主动 IDS 称为 IPS。但重要的是要认识到，IPS 部署在流量的直通路径上，并包含在恶意流量到达目标之前将其阻断的能力。

## 了解 HIDS 与 NIDS 的区别

基于主机的 IDS（HIDS）只能监控单个系统上的活动。一个缺点是攻击者可能会发现并禁用它们。基于网络的 IDS（NIDS）可以监控网络上的活动，且 NIDS 对攻击者的可见性不高。

## 了解蜜罐、加固单元和伪缺陷

蜜罐是一个通常具有伪缺陷和假数据以引诱入侵者的系统。管理员可以在攻击者身处蜜罐时观察其活动，只要攻击者在蜜罐中，他们就不在生产网络中。一些 IDS 在检测后具有将攻击者转移到加固单元的能力。虽然蜜罐和加固单元相似，但请注意：蜜罐引诱攻击者，而攻击者被转移到加固单元。
