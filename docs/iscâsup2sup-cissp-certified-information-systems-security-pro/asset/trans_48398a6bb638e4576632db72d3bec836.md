

# 为了规划工作场所中的自然灾害和非自然灾害，您首先必须了解它们的各种形式，如下节所述。

## 自然灾害

*自然灾害*反映了我们栖息地偶尔的暴怒——源于地球表面或大气变化、超出人类控制范围的剧烈事件。在某些情况下，例如飓风，科学家已经开发出复杂的预测模型，可在灾害发生前提供充足的预警。而另一些，例如地震，可能在瞬间造成毁灭性后果。灾难恢复计划应提供应对这两类灾害的机制，无论是逐步集结响应力量，还是对迅速出现的危机做出即时反应。

### 地震

地震是由地震板块移动引起的，几乎可能在世界任何地方毫无预警地发生。然而，它们更有可能发生在世界许多地区已知的断层带沿线。一个著名的例子是圣安德烈亚斯断层，它对美国西部部分地区构成重大风险。如果您居住在断层带沿线、地震频发的地区，您的 DRP 应涵盖地震事件中断正常业务活动时，贵企业将实施的程序。

### 洪水

洪水几乎可能在世界任何地方、一年中的任何时间发生。一些洪水源于雨水在河流、湖泊和其他水体中逐渐积聚，随后漫溢堤岸淹没社区。另一些洪水被称为*山洪*，当突如其来的强风暴在短时间内向某地区倾泻的雨水超过地面吸收能力时发生。大坝决堤也会导致洪水。由地震活动引起的大浪，即*海啸*，将水的巨大威力和重量与洪水结合在一起，正如我们在 2011 年日本海啸中所见。那次海啸充分展示了水的巨大破坏力，以及它在引发福岛前所未有的核灾难时，给各类企业和经济造成的浩劫。

根据政府统计数据，洪水每年在美国给企业和家庭造成的损失约为 80 亿美元（那是 *b*illion，十亿！）。您的 DRP 必须为洪水可能袭击您设施这一情况制定适当的响应计划，这至关重要。

虽然理论上洪水可能发生在世界几乎任何地区，但在某些特定区域发生的可能性要大得多。FEMA 的国家洪水保险计划负责对全美进行洪水风险评估，并以图形形式向公众提供这些数据。您可以在以下网址在线查看洪水地图：

<http://msc.fema.gov/portal>

该网站还提供有关已记录的地震、飓风、风暴、冰雹风暴和其他自然灾害的宝贵信息，帮助您准备组织的风险评估。

查看洪水地图时（如[图 18.1](#c18.xhtml#figure18-1)所示示例），您会发现分配给某区域的两个常见风险是“百年一遇洪泛区”和“五百年一遇洪泛区”。这些评估分别意味着政府估计在任何给定年份发生洪水的几率为 1/100 或 1/500。如需了解阅读洪水地图和当前地图信息的更详细教程，请访问 <http://www.fema.gov/media/fhm/firm/ot_firm.htm>。

### 风暴

风storm 形式多样，给企业带来多种风险。长时间的强降雨带来了上一节所述的山洪风险。飓风和龙卷风伴随时速超过 100 英里的大风，破坏建筑物的结构完整性，将树木、庭院家具甚至车辆等日常物品变成致命的飞射物。冰雹风暴带来破坏性的冰块从天而降。许多风暴还带来雷击风险，这可能对敏感电子元件造成严重损坏。因此，您的业务连续性计划应详述防范雷击损害的适当机制，而您的灾难恢复计划应包含针对雷击可能导致的停电和设备损坏的充分预案。切勿低估单次风暴可能造成的破坏。

2017 年，四级大西洋飓风“哈维”标志着有史以来登陆美国大陆的代价最高、致死人数最多、强度最强的飓风之一。它在德克萨斯州开辟出一条毁灭之路，摧毁了自然和人造设施。哈维造成的损失带来的总经济影响估计超过 1250 亿美元，并直接导致至少 63 人死亡。

### 火灾

火灾可能因多种原因引起，无论是自然原因还是人为原因，两者破坏力均不相上下。在 BCP/DRP 过程中，您应评估火灾风险，并实施至少基本的措施来降低该风险，为企业从关键设施的灾难性火灾中恢复做好准备。

世界上某些地区在温暖季节易发生野火。这些火灾一旦发生，蔓延模式具有一定的可预测性，消防专家与气象学家合作可对野火的潜在路径做出相对准确的预测。

### 其他区域性事件

世界上某些地区易发生局部类型的自然灾害。在 BCP/DRP 过程中，您的评估团队应分析贵组织的所有运营地点，并评估此类事件可能对您的业务造成的影响。例如，世界许多地区会发生火山爆发。如果您在活火山或休眠火山附近开展业务，您的 DRP 很可能需要应对这一情况。其他局部性自然事件包括亚洲的季风、南太平洋的海啸、山区的雪崩以及美国西部的泥石流。
