

# 网格计算

网格计算通常使用中央主服务器核心来管理项目、跟踪工作包并整合返回的工作片段。如果中央服务器过载或离线，可能会导致网格完全失效或崩溃。然而，通常当中央网格系统无法访问时，网格成员会完成其当前的本地任务，然后定期轮询以发现中央服务器何时重新上线。还存在一种潜在风险，即中央网格服务器遭到攻破可能被利用来攻击网格成员，或诱骗网格成员执行恶意操作，而非网格社区的预期用途。

## 对等网络

**对等网络**技术是一种网络和分布式应用解决方案，可在对等节点之间共享任务和工作负载。这与网格计算类似；主要区别在于没有中央管理系统，且提供的服务通常是实时的，而非计算能力的集合。常见的 P2P 示例包括许多 VoIP 服务，如 Skype、BitTorrent（用于数据/文件分发）和 Spotify（用于流式音频/音乐分发）。

P2P 解决方案的安全顾虑包括：被认为会诱导盗版受版权保护的材料、能够窃听分发的内容、缺乏中央控制/监督/管理/过滤，以及服务可能消耗所有可用带宽的潜在风险。

# 物联网

**智能设备**是一系列移动设备，通过安装应用程序等方式为用户提供大量定制选项，并可利用设备端或云端的人工智能（AI）处理。可被标记为“智能设备”的产品范围在不断扩大，目前已包括智能手机、平板电脑、音乐播放器、家庭助手、极限运动相机和健身追踪器。

**物联网**是智能设备的一个新子类别，甚至是一个新类别，这些设备连接互联网，旨在为家庭或办公室环境中的传统或新型设备/电器提供自动化、远程控制或 AI 处理。IoT 设备有时是对您可能已在本地手动执行了数十年的功能或操作的革命性改良，让您从此离不开它们。另一些 IoT 设备则不过是昂贵的花哨小工具，使用最初几分钟后就被遗忘和/或丢弃。与 IoT 相关的安全问题关乎访问控制和加密。IoT 设备往往在设计时未将安全作为核心概念，甚至未作为事后考量。这已经导致了大量家庭和办公室网络安全漏洞。此外，一旦攻击者获得对 IoT 设备的远程访问权限或通过其进行访问，他们可能能够访问受损网络上的其他设备。在决定安装 IoT 设备时，应评估设备的安全性以及供应商的安全声誉。如果新设备无法满足或接受您现有的安全基线，则不要仅为了一时新奇的小工具而妥协您的安全。

一种可能的安全实施方案是为 IoT 设备部署一个独立的网络，使其与主网络保持分离和隔离。这种配置通常被称为**三台傻瓜路由器**（参见 [https://www.grc.com/sn/sn-545.pdf](https://www.grc.com/sn/sn-545.pdf) 或 [https://www.pcper.com/reviews/General-Tech/Steve-Gibsons-Three-Router-Solution-IOT-Insecurity](https://www.pcper.com/reviews/General-Tech/Steve-Gibsons-Three-Router-Solution-IOT-Insecurity)）。

虽然我们通常将智能设备和 IoT 与家庭或个人使用联系在一起，但它们也是每个组织关注的问题。这部分是因为员工在公司设施内甚至在组织网络上使用移动设备。网络专业人员关注的另一个方面是，许多 IoT 或网络自动化设备正被添加到业务环境中。这包括环境控制，如供暖、通风和空调（HVAC）管理、空气质量控制、碎屑和烟雾检测、照明控制、门禁自动化、人员和资产追踪，以及耗材库存管理和自动补货（如咖啡、零食、打印机碳粉、纸张和其他办公用品）。因此，智能设备和 IoT 设备都是现代业务网络的潜在组成部分，需要适当的安全管理和监督。有关智能设备和 IoT 设备进行适当安全管理重要性的更多阅读材料，请参阅“NIST Initiatives in IoT”，网址为 [https://www.nist.gov/itl/applied-cybersecurity/nist-initiatives-iot](https://www.nist.gov/itl/applied-cybersecurity/nist-initiatives-iot)。

# 工业控制系统

**工业控制系统**是一种计算机管理设备，用于控制工业过程和机器。ICS 广泛应用于制造、加工、发电和配电、配水、污水处理和石油炼制等众多行业。ICS 有多种形式，包括**分布式控制系统**、**可编程逻辑控制器**和**数据采集与监视控制系统**。

DCS 单元通常用于工业过程工厂，在这些场所从单一位置收集数据并对大规模环境实施控制至关重要。DCS 的一个重要方面是控制元件分布在受监控的环境中，例如制造车间或生产线，而集中监控位置向这些局部控制器发送命令，同时收集状态和性能数据。根据执行的任务或受控设备的不同，DCS 可能是模拟或数字性质的。例如，液体流量阀 DCS 将是模拟系统，而电压调节器 DCS 很可能是数字系统。

PLC 单元实际上是专用或特定用途的数字计算机。它们通常部署用于各种工业机电操作的管理和自动化，例如控制装配线上的系统或大规模数字灯光显示（如体育场的巨型显示系统或拉斯维加斯大道招牌上的显示屏）。

SCADA 系统可以作为独立设备运行，与其他 SCADA 系统联网，或与传统信息技术（IT）系统联网。大多数 SCADA 系统设计有极简的人机界面。通常，它们使用机械按钮和旋钮或简单的 LCD 屏幕界面（类似于商务打印机或 GPS 导航设备上的界面）。然而，联网的 SCADA 设备可能具有更复杂的远程控制软件界面。

理论上，SCADA、PLC 和 DCS 单元的静态设计及其极简的人机界面应使系统相当能抵抗攻破或修改。因此，这些工业控制设备内置的安全性很少，尤其是在过去。但近年来发生过几起著名的工业控制系统攻破事件；例如，Stuxnet 向位于核设施的 SCADA 系统投递了首个根工具包。许多 SCADA 供应商已开始在其解决方案中实施安全改进，以防止或至少减少未来的攻破。然而，在实践中，SCADA 和 ICS 系统通常仍然安全防护薄弱、漏洞众多且更新不频繁，未针对安全设计的旧版本仍广泛使用。
