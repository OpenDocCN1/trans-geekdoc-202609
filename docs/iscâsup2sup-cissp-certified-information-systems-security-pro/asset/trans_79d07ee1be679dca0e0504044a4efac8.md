## 15. A
截断是一种非统计抽样形式，它根据截断级别阈值减少记录的数据量。抽样是一种统计方法，从审计日志中提取有意义的数据。日志分析审查日志信息，寻找趋势、模式以及异常或未经授权的事件。警报触发器是在发生特定事件或达到阈值时发送给管理员的通知。

## 16. B
流量分析更关注数据的模式和趋势，而非实际内容。击键监控记录特定的击键以捕获数据。事件日志记录特定事件以记录数据。安全审计记录安全事件和/或审查日志以检测安全事件。

## 17. B

## 18. D

## 19. C

# 第 18 章：灾难恢复规划

## 1. C
一旦灾难中断业务运营，DRP 的目标是尽快恢复正常业务活动。因此，灾难恢复规划从业务连续性规划结束的地方继续开始。

## 2. C

## 3. D

## 4. B
大多数普通商业保险和房主保险单不提供任何针对洪水或山洪风险的保障。如果洪水对您的组织构成风险，您应考虑在 FEMA 的国家洪水保险计划下购买补充洪水保险。

## 5. B
廉价磁盘冗余阵列（RAID）是容错控制，允许组织的存储服务承受一个或多个单独磁盘的损失。负载均衡、集群和 HA 对都是为服务器设计的容错服务，而非存储。

## 6. C
云计算服务为备份存储提供了绝佳位置，因为它们可从任何位置访问。

## 7. B
*百年一遇洪水区* 一词用于描述预计每 100 年发生一次洪水的区域。然而，从数学上更准确的说法是，该标签表明在任何给定年份发生洪水的概率为 1%。

## 8. D
当使用远程镜像时，数据库的精确副本将保持在备用位置。您通过同时在主站点和远程站点执行所有事务来保持远程副本的最新状态。

## 9. C

## 10. B
在业务影响评估阶段，您必须确定组织的业务优先级，以协助分配 BCP 资源。您可以使用相同的信息来驱动 DRP 业务单元的优先级排序。

## 11. C
冷站点不包含恢复运营所需的任何设备。所有设备必须搬入并配置，数据必须恢复到其中，然后才能开始运营。这通常需要数周时间。

## 12. C
暖站点通常需要约 12 小时才能从宣布灾难时刻激活。这与热站点相对即时的激活以及使冷站点达到运行状态所需的漫长时间（至少一周）形成对比。

## 13. D
暖站点和热站点都包含工作站、服务器和实现运行状态所需的通信线路。两者的主要区别在于热站点包含近实时的运营数据副本，而暖站点需要从备份中恢复数据。

## 14. D
远程镜像是唯一一种备份选项，其中远程站点的实时备份服务器维护主服务器内容的逐位副本，同步程度仅受主系统和远程系统之间链路延迟的限制。

## 15. A

## 18. C
任何备份策略在流程的某个时刻都必须包含完全备份。增量备份的创建速度比差异备份快，因为每次需要备份的文件数量较少。

## 19. A
任何备份策略在流程的某个时刻都必须包含完全备份。如果使用完全备份和差异备份的组合，最多只需恢复两个备份。如果选择完全备份和增量备份的组合，所需的恢复次数可能是无限的。
