

# 描述制定连续性策略所采用的过程

在策略制定阶段，BCP 团队确定将缓解哪些风险。在条款与流程阶段，设计将缓解风险的机制和程序。随后，计划必须经高级管理层批准并付诸实施。人员还必须接受关于其在 BCP 流程中角色的培训。

# 解释为何必须将组织的业务连续性计划完整记录在案的重要性

将计划以书面形式固定下来，能为组织提供一份灾难发生时应遵循程序的书面记录。它能防止“都记在我脑子里”这一弊端，并确保在紧急情况下事件能有序推进。

# 第 4 章：法律、法规与合规

## 本章涵盖的 CISSP 考试主题包括：

### 领域 1：安全与风险管理

*   1.3 确定合规要求
    *   1.3.1 合同、法律、行业标准和法规要求
    *   1.3.2 隐私要求
*   1.4 理解在全球背景下与信息安全相关的法律和法规问题
    *   1.4.1 网络犯罪和数据泄露
    *   1.4.2 许可和知识产权要求
    *   1.4.3 进出口管制
    *   1.4.4 跨境数据流动
    *   1.4.5 隐私

对于信息技术（`IT`）和网络安全专业人员而言，合规世界是一个法律和法规的丛林。国家、州和地方政府都以拼凑的方式通过了重叠的法律，监管网络安全的不同组成部分。这给安全专业人员带来了极其困惑的局面，他们必须协调多个司法管辖区的法律。对于跨国公司而言，情况变得更加复杂，因为它们还必须驾驭国际法之间的差异。
