

# 隐形病毒

**隐形病毒** 通过实际篡改操作系统来隐藏自身，从而欺骗防病毒软件包，使其误以为一切运行正常。例如，隐形引导扇区病毒可能会用恶意代码覆盖系统的主引导记录，但随后也会修改操作系统的文件访问功能以掩盖踪迹。当防病毒软件包请求一份 MBR 副本时，被修改的操作系统代码会提供给它防病毒软件包所期望看到的内容——一个干净的、不含任何病毒特征码的 MBR 版本。然而，当系统启动时，它会读取被感染的 MBR 并将病毒加载到内存中。

# 多态病毒

**多态病毒** 在从系统传播到系统的过程中，实际上会修改自身的代码。病毒的传播和破坏技术保持不变，但病毒的特征码在每次感染新系统时都会有所不同。多态病毒创建者希望这种不断变化的特征码能使基于特征码的防病毒软件包失效。然而，防病毒软件供应商已经“破解”了许多多态技术的“代码”，因此当前版本的防病毒软件能够检测已知的多态病毒。不过，供应商生成阻止多态病毒所需的特征文件往往需要更长的时间，这意味着病毒可以在互联网上肆意传播更长一段时间。

# 加密病毒

**加密病毒** 使用加密技术（如第 6 章所述）来避免被检测。从外观上看，它们实际上与多态病毒非常相似——每个被感染的系统上的病毒都有不同的特征码。然而，它们并非通过改变代码来生成这些修改后的特征码；相反，它们改变的是自身在磁盘上的存储方式。加密病毒使用一段非常短的代码，称为 **病毒解密程序**，其中包含加载和解密存储在磁盘其他位置的主病毒代码所需的加密信息。每次感染都使用不同的加密密钥，导致主代码在每个系统上看起来完全不同。然而，病毒解密程序通常包含明显的特征码，这使得它们容易被更新后的防病毒软件包检测到。

## 病毒骗局

如果不提及病毒 **骗局** 造成的麻烦和资源浪费，关于病毒的讨论就不算完整。几乎每个电子邮件用户都曾在某个时候收到过朋友或亲戚转发的消息，警告互联网上出现了最新的病毒威胁。这种所谓的“病毒”总是被描述为有史以来破坏力最强的病毒，且没有任何防病毒软件包能够检测和/或清除它。一个著名的骗局例子是“Good Times”病毒警告，它最早于 1994 年在互联网上出现，至今仍在流传。

社交媒体格局的变化只是改变了这些骗局的传播方式。除了电子邮件，恶意软件骗局现在还通过 Facebook、Twitter、WhatsApp、Snapchat 以及其他社交媒体和即时通讯平台传播。

有关此主题的更多信息，辟谣网站 Snopes 在 <https://www.snopes.com/tag/virus-hoaxes-realities/> 维护着一个病毒骗局列表。

# 逻辑炸弹

**逻辑炸弹** 是感染系统并潜伏的恶意代码对象，直到由一个或多个条件（如时间、程序启动、网站登录等）的发生而触发。绝大多数逻辑炸弹是由软件开发人员编入定制应用程序中的，旨在确保如果他们意外离职，其工作成果会被销毁。

与所有恶意代码对象一样，逻辑炸弹形式多样。事实上，许多病毒和特洛伊木马都包含逻辑炸弹组件。著名的“米开朗基罗”病毒于 1991 年被发现时引起了媒体轰动，因为它包含一个逻辑炸弹触发器。该病毒通过共享受感染的软盘感染系统的主引导记录，然后隐藏起来，直到 3 月 6 日——著名意大利艺术家米开朗基罗·博那罗蒂的生日。到了那天，它就会发作，重新格式化受感染系统的硬盘驱动器，销毁其中包含的所有数据。

最近，2013 年 3 月，一枚逻辑炸弹针对韩国的组织。该恶意软件渗透了韩国媒体公司和金融机构的系统，导致系统瘫痪和数据丢失。在这种情况下，恶意软件攻击触发了军事警报，因为韩国政府怀疑该逻辑炸弹是朝鲜发动攻击的前奏。

# 特洛伊木马

系统管理员时刻警告计算机用户，除非绝对确定来源可信，否则不要从互联网下载和安装软件。事实上，许多公司严格禁止安装任何未经 IT 部门预先审核的软件。这些政策旨在最大限度地降低组织网络被 **特洛伊木马** 攻破的风险——特洛伊木马是一种表面上看似无害，实则携带恶意后台载荷的软件程序，有可能对系统或网络造成严重破坏。

特洛伊木马的功能差异很大。有些会销毁系统上存储的所有数据，试图在尽可能短的时间内造成最大程度的破坏。有些则相对无害。例如，2002 年中，互联网上出现了一系列特洛伊木马，声称能让 PC 用户在电脑上运行专为微软 Xbox 游戏系统设计的游戏。当用户运行该程序时，它根本无法工作。然而，它还会向 Windows 注册表插入一个值，导致每次计算机启动时都会打开一个特定的网页。特洛伊木马创建者希望通过 Xbox 特洛伊木马带来的大量页面浏览量产生的广告收入获利。不幸的是，防病毒专家迅速识破了他们的真实意图，该网站被关闭。

近年来对安全社区产生重大影响的一类特洛伊木马是流氓防病毒软件。这种软件通过声称自己是防病毒软件包，往往以模仿安全警报外观的弹窗广告形式，诱骗用户安装。一旦用户安装了该软件，它要么窃取个人信息，要么提示用户付费“更新”流氓防病毒软件。“更新”仅仅是禁用该特洛伊木马！

另一种变体 **勒索软件** 尤为阴险。勒索软件感染目标机器，然后利用加密技术，用仅恶意软件创建者知道的密钥，加密系统上存储的文档、电子表格和其他文件。用户随后无法访问其文件，并会收到一条不祥的弹窗消息，警告除非在短时间内支付赎金，否则文件将被永久删除。用户往往会支付赎金以恢复对文件的访问。最著名的勒索软件变种之一是名为 Cryptolocker 的程序。

# 蠕虫

**蠕虫** 对网络安全构成重大风险。它们具有与其他恶意代码对象相同的破坏潜力，但有一个额外的特点——它们无需任何人工干预即可自我传播。

互联网蠕虫是互联网上发生的第一起重大计算机安全事件。自那时以来，数百种新蠕虫（包含数千个变种）在互联网上释放了其破坏力。以下章节将探讨一些具体的蠕虫。
