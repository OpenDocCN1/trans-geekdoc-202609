

# 构建职位描述的重要要素

符合组织流程的职位描述构建要素包括职责分离、工作职责和轮岗制度。

## 职责分离

**职责分离**是一种安全概念，即将关键、重要和敏感的工作任务分配给多个独立的管理员或高级操作员（图 2.1）。这可以防止任何单个人拥有破坏或颠覆关键安全机制的能力。可以将职责分离视为将最小权限原则应用于管理员。职责分离也是一种防止串通的保护措施。**串通**是指两人或多人为欺诈、盗窃或间谍活动等目的而进行的负面活动。通过限制个人的权限，职责分离要求员工必须与他人合作才能实施更大规模的违规行为。寻找他人协助违规以及实施违规的行为更有可能留下证据并被发现，从而直接减少了串通的发生（通过威慑力，即他们可能被抓住的机会）。因此，串通难以实施，且在实施行为前增加了发起者的风险。

## 工作职责

**工作职责**是员工需要定期执行的具体工作任务。根据其职责，员工需要访问各种对象、资源和服务。在安全网络中，必须根据员工的工作任务授予其相关要素的访问权限。为保持最高安全性，访问权限应根据最小权限原则进行分配。**最小权限原则**规定，在安全环境中，用户应仅被授予完成其所需工作任务或工作职责所必需的最低访问权限。真正应用这一原则需要对所有资源和功能进行低层级的细粒度控制。

## 轮岗制度

**轮岗制度**，即在多个职位间轮换员工，是组织提升整体安全性的一种手段（图 2.2）。轮岗具有两大功能。首先，它提供了一种知识冗余。当多名员工都能胜任多个职位所需的工作任务时，即使一名或多名员工因疾病或其他事件长期无法工作，组织也不太可能遭遇严重的停机或生产力损失。

**图 2.2** 管理职位间轮岗的示例

其次，人员流动可以降低欺诈、数据篡改、盗窃、破坏和信息滥用的风险。一个人在特定职位上工作的时间越长，越有可能被分配额外的工作任务，从而扩大其特权和访问权限。随着一个人对其工作任务越来越熟悉，他们可能会滥用特权谋取私利或出于恶意。如果一名员工实施了滥用或误用行为，另一名了解该职位和工作职责的员工将更容易发现。因此，轮岗也提供了一种同行审计的形式，并防止串通。

轮岗要求审查安全特权和访问权限，以维持最小权限原则。轮岗、交叉培训和长期任职员工的一个顾虑在于他们持续积累特权和访问权限，其中许多是他们不再需要的。特权、权限、权利、访问权限等的分配应定期审查，以检查是否存在特权蔓延或与工作职责不符的情况。**特权蔓延**是指随着工作职责的变化，员工随着时间的推移积累特权。最终结果是，根据该员工当前的工作职责，其拥有的特权超出了最小权限原则的规定。

当数人合谋犯罪时，称为串通。采用职责分离、受限工作职责和轮岗原则，可以降低同事因被发现风险较高而愿意合作实施非法或滥用计划的可能性。通过严格监控特殊特权（如管理员、备份操作员、用户管理员等的特权），可以减少串通和其他特权滥用。

职位描述不仅用于招聘流程；它们应在组织的整个生命周期内得到维护。只有通过详细的职位描述，才能将一个人*应该*负责的内容与他们*实际*负责的内容进行比较。确保职位描述尽可能少地重叠，且一名员工的职责不发生偏移或侵占他人的职责，是一项管理任务。同样，管理者应审计特权分配，确保员工不会获得完成工作任务并不严格要求的访问权限。

# 候选人筛选与招聘

特定职位的应聘候选人筛选基于职位描述定义的敏感性和分级。特定职位的敏感性和分级取决于该职位人员因意外或故意违反安全规定可能造成的危害程度。因此，筛选过程的彻底程度应反映待填补职位的安全级别。

应聘候选人筛选、背景调查、推荐人核查、学历验证和安全许可验证，是证明候选人胜任、合格且值得信赖、可担任安全职位的基本要素。**背景调查**包括获取候选人的工作和教育经历；核查推荐人；验证学历；面谈同事、邻居和朋友；查阅警方和政府记录以了解是否有被捕或违法活动；通过指纹、驾照和出生证明验证身份；以及进行面谈。此过程还可能包括测谎测试、药物测试和性格测试/评估。

执行在线背景调查和审查申请人的社交网络账户，已成为许多组织的标准做法。如果潜在员工在其照片分享网站、社交网络简介或公共即时通讯服务上发布了不当材料，那么与那些没有发布此类材料的人相比，他们就不是那么有吸引力的候选人。当我们在公众视野中的行为以文本、照片或视频形式被记录并发布到网上时，它们就变成了永久记录。通过查看一个人的在线身份，可以快速了解其态度、智力、忠诚度、常识、勤奋、诚实、尊重、一致性以及对社会规范和/或企业文化的遵守情况的总体画像。
