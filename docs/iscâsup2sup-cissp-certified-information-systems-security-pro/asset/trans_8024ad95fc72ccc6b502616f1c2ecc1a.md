

# 互联网协议语音 (VoIP)

**互联网协议语音 (VoIP)** 是一种隧道机制，用于通过 TCP/IP 网络传输语音和/或数据。VoIP 有潜力取代或替代 PSTN（公共交换电话网），因为它通常成本更低，并提供更多种类的选项和功能。VoIP 既可用作计算机网络上的直接电话替代品，也可用于移动设备。然而，VoIP 能够支持视频和数据传输，以实现视频会议和项目远程协作。VoIP 有商业版和开源版两种选择。某些 VoIP 解决方案需要专用硬件，以替代传统电话听筒/基站，或允许这些设备连接到 VoIP 系统并在此系统上运行。某些 VoIP 解决方案仅基于软件，例如 `Skype`，允许用户现有的扬声器、麦克风或耳机替代传统电话听筒。其他解决方案则更多基于硬件，例如 `magicJack`，它允许将现有的 PSTN 电话设备插入通用串行总线 (USB) 适配器，以利用互联网上的 VoIP。通常，VoIP 到 VoIP 的通话是免费的（假设使用相同或兼容的 VoIP 技术），而 VoIP 到固定电话的通话通常按分钟收费。

# 软件定义网络 (SDN)

**软件定义网络 (SDN)** 是一种独特的网络运行、设计和管理方法。其概念基于这样一种理论：传统网络依赖设备上的配置（即路由器和交换机），其复杂性往往迫使组织坚持使用单一设备供应商（如 `Cisco`），并限制了网络响应不断变化的物理和业务条件的灵活性。SDN 旨在将基础设施层（即硬件和基于硬件的设置）与控制层（即数据传输管理的网络服务）分离。此外，这还消除了传统网络概念（如 IP 寻址、子网、路由等）需要被编程到托管应用程序中或由其解析的需求。

SDN 提供了一种新的网络设计，可从中心位置直接编程，具有灵活性、供应商中立性，并基于开放标准。使用 SDN 使组织无需从单一供应商采购设备。相反，它允许组织根据需要混合搭配硬件，例如选择最具成本效益或吞吐量评级最高的设备，而不受供应商限制。然后通过集中管理界面控制硬件的配置和管理。此外，应用于硬件的设置可根据需要动态更改和调整。

理解 SDN 的另一种方式是将其视为网络虚拟化。它允许数据传输路径、通信决策树和流控制在 SDN 控制层中虚拟化，而不是在硬件上按设备单独处理。

## 内容分发网络

**内容分发网络 (CDN)**，或内容交付网络，是部署在互联网上众多数据中心中的一组资源服务，旨在为托管内容提供低延迟、高性能和高可用性。CDN 通过分布式数据主机的概念，提供客户所需的多媒体性能质量。媒体内容不再存储在单一位置并传输到互联网的各个部分，而是分发到互联网上的众多位置。这导致了一种地理和逻辑负载均衡。没有单个服务器或服务器集群会因所有资源请求的负载而紧张，且托管服务器位于更靠近请求客户的位置。总体结果是更低的延迟和更高质量的吞吐量。有许多 CDN 服务提供商，包括 `CloudFlare`、`Akamai`、`Amazon CloudFront`、`CacheFly` 和 `Level 3 Communications`。

虽然大多数 CDN 侧重于服务器的物理分发，但基于客户端的 CDN 也是可能的。这通常被称为 `P2P`（对等网络）。最广为人知的 P2P CDN 是 `BitTorrent`。

# 无线网络

**无线网络** 是连接企业和家庭系统的一种流行方法，因为它易于部署且成本相对较低。它使网络比以往任何时候都更通用。工作站和便携式系统不再受线缆束缚，而是可以在部署的无线接入点的信号范围内自由移动。然而，这种自由也带来了额外的漏洞。历史上，无线网络一直相当不安全，主要是因为最终用户和组织缺乏知识，以及设备制造商设置的不安全默认配置。无线网络面临与任何有线网络相同的漏洞、威胁和风险，此外还面临远程窃听、数据包嗅探以及新形式的 DoS 和入侵。为可靠访问和安全性妥善管理无线网络并不总是一件简单或直接的事情。本节将探讨各种无线安全问题。

**数据辐射** 是通过电磁信号传输数据。计算机内部或网络中的几乎所有活动都使用某种形式的数据辐射来执行。然而，该术语通常用于关注不需要的辐射，或因辐射而面临风险的数据。

电子移动时就会发生辐射。电子的运动会产生磁场。如果你能读取该磁场，就可以在别处重现它，以复现电子流。如果原始电子流用于通信数据，那么重现的电子流也是原始数据的重现。这种形式的电子窃听听起来像科幻小说，但却是科学事实。美国政府自 20 世纪 50 年代起就在 `TEMPEST` 项目下研究辐射安全。

防范窃听和数据窃取需要多管齐下的努力。首先，你必须对所有电子设备保持物理访问控制。其次，在未经授权的人员仍可能获得物理访问或接近的情况下，你必须使用屏蔽设备和介质。第三，你应始终使用安全加密协议传输任何敏感数据。

## 保护无线接入点

**无线小区** 是物理环境中无线设备可以连接到无线接入点的区域。无线小区可能泄漏到安全环境之外，允许入侵者轻松访问无线网络。你应该调整无线接入点的强度，以最大化授权用户的访问并最小化入侵者的访问。这可能需要独特的无线接入点放置、屏蔽和噪声传输。

**802.11** 是无线网络通信的 IEEE 标准。该标准的各个版本（技术上称为修正案）已在无线网络硬件中实现，包括 `802.11a`、`802.11b`、`802.11g` 和 `802.11n`。`802.11x` 有时用于统称所有这些特定实现；然而，首选使用 `802.11`，因为 `802.11x` 容易与 `802.1x` 混淆，后者是一种独立于无线的认证技术。`802.11` 标准的每个版本或修正案都提供了略微更好的吞吐量：分别为 2 MB、11 MB、54 MB 和 200 MB+，如[表 11.7](#c11.xhtml#table11-7)所述。`b`、`g` 和 `n` 修正案都使用相同的频率；因此，它们保持向后兼容性。

### 表 11.7：802.11 无线网络修正案

| 修正案 | 速度 | 频率 |
| --- | --- | --- |
| 802.11 | 2 Mbps | 2.4 GHz |
| 802.11a | 54 Mbps | 5 GHz |
| 802.11b | 11 Mbps | 2.4 GHz |
