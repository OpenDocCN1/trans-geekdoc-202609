

# NAT

NAT 用于隐藏私有网络的内部结构，并使多个内部客户端能够通过少量公共 IP 地址访问互联网。NAT 通常是边界安全设备的原生功能，例如防火墙、路由器、网关和代理。

# 电路交换与分组交换

在电路交换中，会在两个通信方之间创建一条专用的物理路径。分组交换是指将消息或通信分割成小段（通常是固定长度的分组，具体取决于所采用的协议和技术），并通过中间网络发送到目的地。在分组交换系统中，有两种通信类型：路径和虚拟电路。虚拟电路是在分组交换网络上两个特定端点之间创建的逻辑路径或电路。虚拟电路有两种类型：永久虚拟电路（PVC）和交换虚拟电路（SVC）。

# WAN 链路

WAN 链路，或长距离连接技术，可分为两大类：专用线路和非专用线路。专用线路连接两个特定端点，且仅连接这两个端点。非专用线路是在数据传输发生前需要建立连接的线路。非专用线路可用于连接任何使用相同类型非专用线路的远程系统。WAN 连接技术包括 X.25、帧中继、ATM、SMDS、SDLC、HDLC、SDH 和 SONET。

# 网络通信的安全控制

在为网络通信选择或部署安全控制时，您需要结合您的环境、能力和安全策略评估众多特性。安全控制应对用户透明。哈希总计和 CRC 校验可用于验证消息完整性。记录序列用于确保传输的序列完整性。传输日志记录有助于检测通信滥用行为。

# 虚拟化

虚拟化技术用于在单台主机计算机的内存中托管一个或多个操作系统。此机制允许几乎任何操作系统在任何硬件上运行。它还允许多个操作系统在同一硬件上同时工作。虚拟化提供多种优势，例如能够根据需要启动服务或服务的单独实例、实时可扩展性，以及能够运行应用程序所需的确切操作系统版本。

# 电子邮件安全

除非您采取措施保护，否则基于互联网的电子邮件是不安全的。要保护电子邮件，您应提供不可抵赖性，限制授权用户访问，确保完整性得以维护，验证消息来源，确认投递，甚至对敏感内容进行分类。这些问题必须在安全策略中得到解决，然后才能在解决方案中实施。它们通常以可接受使用策略、访问控制、隐私声明、电子邮件管理程序以及备份和保留策略的形式出现。

电子邮件是恶意代码的常见传播机制。过滤附件、使用防病毒软件和教育用户是针对此类攻击的有效对策。电子邮件垃圾邮件或邮件轰炸是一种拒绝服务形式，可通过过滤器和 IDS 予以阻止。可以使用 S/MIME、MOSS、PEM 和 PGP 来提高电子邮件安全性。

# 传真和语音安全

通过使用加密来保护文档传输并防止窃听，可以提高传真和语音安全性。有效培训用户是防范社会工程学攻击的有用对策。

# 安全边界

安全边界可以是一个安全区域与另一个安全区域之间的划分，也可以是一个安全区域与一个非安全区域之间的划分。这两者都必须在安全策略中予以解决。

# 通信系统漏洞

通信系统容易受到多种攻击，包括分布式拒绝服务（DDoS）、窃听、冒充、重放、篡改、欺骗，以及 ARP 和 DNS 攻击。幸运的是，针对这些攻击中的每一种都存在有效的对策。PBX 欺诈和滥用以及电话破解也是必须解决的问题。

# 考试要点

## 理解远程访问安全管理相关问题

远程访问安全管理要求安全系统设计人员解决实现过程中的硬件和软件组件问题，以及与策略、工作任务和加密相关的问题。

## 熟悉可用于 LAN 和 WAN 进行数据通信的各种协议和机制

这些包括 `SKIP`、`SWIPE`、`SSL`、`SET`、`PPP`、`SLIP`、`CHAP`、`PAP`、`EAP` 和 `S-RPC`。它们还可以包括 `VPN`、`TLS/SSL` 和 `VLAN`。

## 了解什么是隧道技术

隧道技术是将协议可传递消息封装在第二个协议中。第二个协议通常执行加密以保护消息内容。

## 理解 VPN

VPN 基于加密隧道技术。它们可以作为点对点解决方案提供身份验证和数据保护。常见的 VPN 协议有 `PPTP`、`L2F`、`L2TP` 和 `IPsec`。

## 能够解释 NAT

NAT 保护私有网络的寻址方案，允许使用私有 IP 地址，并使多个内部客户端能够通过少量公共 IP 地址获得互联网访问权限。NAT 受许多安全边界设备支持，例如防火墙、路由器、网关和代理。

## 理解分组交换与电路交换的区别

在电路交换中，会在两个通信方之间创建一条专用的物理路径。分组交换是指将消息或通信分割成小段，并通过中间网络发送到目的地。在分组交换系统中，有两种通信路径或虚拟电路：永久虚拟电路（PVC）和交换虚拟电路（SVC）。

## 理解专用线路与非专用线路的区别

专用线路始终处于开启状态，并为特定客户保留。专用线路的示例包括 `T1`、`T3`、`E1`、`E3` 和有线调制解调器。非专用线路在数据传输发生前需要建立连接。它可用于连接任何使用相同类型非专用线路的远程系统。标准调制解调器、`DSL` 和 `ISDN` 是非专用线路的示例。

## 了解与远程访问安全相关的各种问题

熟悉远程访问、拨号连接、屏幕抓取器、虚拟应用程序/桌面以及一般远程办公安全顾虑。

## 了解各种 WAN 技术

了解大多数 WAN 技术需要信道服务单元/数据服务单元（CSU/DSU），有时称为 WAN 交换机。存在多种类型的载波网络和 WAN 连接技术，例如 `X.25`、`帧中继`、`ATM`、`SMDS`、`SDH` 和 `SONET`。某些 WAN 连接技术需要额外的专用协议来支持各种类型的专用系统或设备。

## 理解 PPP 与 SLIP 的区别

点对点协议（`PPP`）是一种封装协议，旨在支持通过拨号或点对点链路传输 IP 流量。`PPP` 包括广泛的通信服务，包括 IP 地址的分配和管理、同步通信的管理、标准化封装、复用、链路配置、链路质量测试、错误检测，以及功能或选项协商（如压缩）。`PPP` 最初设计用于支持 `CHAP` 和 `PAP` 进行身份验证。然而，`PPP` 的最新版本也支持 `MS-CHAP`、`EAP` 和 `SPAP`。`PPP` 取代了串行线路互联网协议（`SLIP`）。`SLIP` 不提供身份验证，仅支持半双工通信，没有错误检测功能，且需要手动建立和拆除链路。
