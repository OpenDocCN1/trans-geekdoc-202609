
# 设备安全

设备安全是指移动设备可能提供的各种潜在安全选项或功能。并非所有`便携式电子设备 (PEDs)`都具备良好的安全功能。但即使设备拥有安全功能，除非启用并正确配置，否则它们毫无价值。在做出购买决定前，请务必考虑新设备的安全选项。

## 全设备加密

某些移动设备（包括便携式计算机、平板电脑和手机）可能提供设备加密。如果设备的大部分或全部存储介质均可加密，这通常是一项值得启用的功能。然而，加密并不能保证数据绝对安全，特别是当设备在解锁状态下被盗，或系统本身存在已知的后门攻击漏洞时。

当使用网络电话协议 (VoIP) 服务时，移动设备上可能实现语音加密。计算机类设备之间的 VoIP 服务比连接传统固定电话或普通手机的 VoIP 连接更有可能提供加密选项。当语音通话被加密后，窃听将变得毫无意义，因为通话内容无法解读。

## 远程擦除

如果设备丢失或被盗，执行`远程擦除`或`远程清理`正变得越来越普遍。远程擦除允许你从远处删除设备上的所有数据，甚至可能包括配置设置。擦除过程可通过移动电话服务触发，有时也可通过任何互联网连接触发。然而，远程擦除并不能保证数据安全。窃贼可能足够聪明，在导出数据的同时阻断会触发擦除功能的连接。此外，远程擦除主要是一种删除操作。使用取消删除或数据恢复工具，通常可以恢复已擦除设备上的数据。为确保远程擦除能销毁数据使其无法恢复，设备应当加密。这样，取消删除操作恢复的仅是加密数据，攻击者将无法解读。

## 锁定

移动设备上的锁定类似于公司工作站上的账户锁定。当用户在反复尝试后未能提供凭据时，账户或设备将被禁用（锁定）一段时间，或直到管理员清除锁定标志。

移动设备可能提供锁定功能，但仅在配置了屏幕锁定时才会生效。否则，简单的屏幕滑动解锁无法提供足够的安全性，因为未发生认证过程。某些设备会随着认证失败次数的增加，触发越来越长的访问尝试延迟。某些设备允许设定尝试次数（如三次），超限后触发持续数分钟的锁定。其他设备则触发持久锁定，要求使用不同的账户或主密码/代码才能重新获得设备访问权。

## 屏幕锁定

屏幕锁定旨在防止他人随意拿起你的手机或移动设备即可使用。然而，大多数屏幕锁定可通过滑动图案或在键盘显示上输入数字来解锁。这两者都不是真正安全的操作。屏幕锁定可能存在变通方法，例如通过紧急呼叫功能访问电话应用程序。而且，如果黑客通过蓝牙、无线网络或 USB 线缆连接设备，屏幕锁定不一定能保护设备。

屏幕锁定通常在非使用超时期后触发。如果系统闲置几分钟，大多数 PC 会自动触发受密码保护的屏幕保护程序。同样，许多平板电脑和手机会在 30-60 秒后触发屏幕锁定，并调暗或关闭显示屏。锁定功能确保当你离开设备、设备丢失或被盗时，其他人将难以访问你的数据或应用程序。要解锁设备，你必须输入密码、代码或 PIN；绘制图案；提供虹膜或面部进行识别；扫描指纹；或使用近距离设备，如近场通信 (NFC) 或射频识别 (RFID) 戒指或标签。

## GPS

许多移动设备包含全球定位系统 (GPS) 芯片，以支持并受益于基于位置的服务（如导航），因此可以追踪这些设备。GPS 芯片本身通常只是来自轨道 GPS 卫星信号的接收器。然而，移动设备上的应用程序可以记录设备的 GPS 位置，然后将其上报给在线服务。你可以使用 GPS 追踪来监控自己的移动，追踪他人（如未成年人或送货人员）的移动，或追回被盗设备。但要使 GPS 追踪生效，移动设备必须具备互联网或无线电话服务，以便通信其位置信息。

## 应用程序控制

`应用程序控制`是一种设备管理解决方案，用于限制可安装到设备上的应用程序。它也可用于强制安装特定应用程序，或强制执行某些应用程序的设置，以支持安全基线或维护其他形式的合规性。使用应用程序控制通常可以通过限制用户安装来自未知来源或提供非工作相关功能的应用程序的能力，从而降低遭遇恶意应用程序的风险。

## 存储分段

`存储分段`用于在存储介质上人为地隔离各种类型或价值的数据。在移动设备上，设备制造商和/或服务提供商可能使用存储分段，将设备的操作系统和预装应用与用户安装的应用和用户数据隔离开。某些移动设备管理系统进一步实施存储分段，以将公司数据和应用与用户数据和应用分离。

## 资产追踪

资产追踪是用于维护库存（如已部署的移动设备）监管的管理流程。资产追踪系统可以是被动或主动的。被动系统依赖资产本身定期向管理服务签到，或在员工每次到岗时检测到设备在场。主动系统使用轮询或推送技术向设备发送查询以引出响应。

你可以使用资产追踪来验证设备是否仍在指派的授权用户手中。某些资产追踪解决方案可以定位丢失或被盗的设备。

某些资产追踪解决方案超越了硬件库存管理，可监管设备上安装的应用、应用使用情况、存储的数据和数据访问。你可以使用此类监控来验证是否遵守安全准则，或检查机密信息是否暴露给未授权实体。

## 库存控制

术语`库存控制`可能描述硬件资产追踪（如前一主题所述）。然而，它也可以指利用移动设备作为在仓库或储物柜中追踪库存的手段。大多数移动设备都有摄像头。利用移动设备摄像头，可拍照或扫描条形码的应用程序可用于追踪实物商品。那些具备 RFID 或 NFC 功能的移动设备，可能能够与已电子标记的物体或其容器进行交互。
