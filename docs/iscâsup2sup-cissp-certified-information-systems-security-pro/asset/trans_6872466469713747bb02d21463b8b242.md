通读本书，您已了解到信息安全专业人员实施的许多不同控制措施，以保护数据的机密性、完整性和可用性。其中，技术控制在保护服务器、网络和其他信息处理资源方面发挥着重要作用。安全专业人员构建并配置这些控制措施后，必须定期对其进行测试，以确保它们持续有效地保护信息。

安全评估与测试计划执行定期检查，以确保已建立充分的安全控制措施，且这些措施能有效执行其指定功能。在本章中，您将了解全球安全专业人员使用的许多评估与测试控制措施。

## 建立安全评估与测试计划

信息安全团队的基石维护活动是其安全评估与测试计划。该计划包含测试、评估和审计，定期验证组织拥有充分的安全控制措施，且这些安全控制措施运行正常，有效保护信息资产。

在本节中，您将了解安全评估计划的三大主要组成部分：

*   安全测试
*   安全评估
*   安全审计

### 安全测试

*安全测试* 验证控制措施是否正常运行。这些测试包括自动化扫描、工具辅助渗透测试和手动破坏安全的尝试。安全测试应按固定时间表定期进行，并关注保护组织的每项关键安全控制。在安排安全控制审查时，信息安全经理应考虑以下因素：

*   安全测试资源的可用性
*   受测试控制保护的系统和应用程序的关键性
*   受测试系统和应用程序上所含信息的敏感性
*   实施控制的机制发生技术故障的可能性
