
# 练习题答案与解析

## 物理安全与环境安全（第10-20题）

### 10. B
基于水的灭火系统最常见的故障原因是人为错误。如果你在火灾后关闭水源却忘记重新打开，将来会遇到麻烦。此外，在无火灾情况下拉响警报会触发破坏性的水释放，波及整个办公室。

### 11. C
钥匙锁是最常见且最廉价的物理访问控制设备形式。照明、保安和围栏的成本都高得多。

### 12. D
电容式运动探测器可感应受监控物体周围电场或磁场的变化。

### 13. A
不存在预防性警报这一说法。警报总是响应检测到的入侵或攻击而触发。

### 14. B
无论使用何种形式的物理访问控制，都必须部署保安或其他监控系统以防止滥用、伪装和尾随。间谍活动无法通过物理访问控制来预防。

### 15. C
人员安全是所有安全解决方案最重要的目标。

### 16. B
计算机机房的湿度理想范围应为 40% 至 60%。

### 17. D
存储在硬盘上的数据可能因 1,500 伏特的静电而被破坏。

### 18. A
水绝不是 B 类灭火器的灭火介质，因为 B 类灭火器用于扑灭液体火灾。

### 19. C
预作用系统是计算机设施最佳的基于水的火灾抑制系统类型。

### 20. D
光线通常不会损坏大多数计算机设备，但火灾、烟雾和灭火介质（通常是水）具有极强的破坏性。

## 第 11 章：安全网络架构与网络组件安全

### 1. D
传输层是第 4 层。表示层是第 6 层，数据链路层是第 2 层，网络层是第 3 层。

### 2. B
封装是指数据在 OSI 协议栈向下移动时添加首部和尾部。

### 3. B
第 5 层（会话层）管理单工（单向）、半双工（双向，但同一时间只能单向发送数据）和全双工（双向，数据可同时双向发送）通信。

### 4. B
`UTP`（非屏蔽双绞线）对 `EMI`（电磁干扰）的抵抗能力最弱，因为它未屏蔽。`Thinnet`（`10Base2`）是一种屏蔽同轴电缆，可抵抗 `EMI`。`STP`（屏蔽双绞线）是抗 `EMI` 的屏蔽双绞线形式。光纤不受地源 `EMI` 影响。

### 5. D
`VPN`（虚拟专用网）是一种安全隧道，用于跨潜在不安全的中介网络建立连接。内联网、外联网和 `DMZ` 是网络分段的示例。

### 6. B
`RFID`（射频识别）是一种追踪技术，基于当天线置于磁场中时产生的电流为无线电发射器供电的能力。`RFID` 可在相当远的距离（通常数百米）外被触发/供电并读取。

### 7. C
`Bluejacking` 攻击（蓝牙劫持）是针对蓝牙的无线攻击，`Bluejacking` 攻击中最常见的受害设备是手机。

### 8. A
以太网基于 `IEEE 802.3` 标准。

### 9. B
`TCP Wrapper`（TCP 包装器）是一种应用程序，可通过基于用户 ID 或系统 ID 限制访问，充当基本防火墙。

### 10. B
封装既是多层协议的优势，也是其潜在的有害影响。

### 11. C
状态检测防火墙能为授权用户和活动授予更广泛的访问权限，并主动监视和阻止未授权用户和活动。

### 12. B
状态检测防火墙被称为第三代防火墙。

### 13. B
大多数防火墙提供广泛的日志记录、审计和监控功能，以及警报甚至基本的 `IDS`（入侵检测系统）功能。防火墙无法阻止通过其他授权通信通道传输的病毒或恶意代码，无法防止用户未授权的意外或故意信息泄露，无法防止已在防火墙内部的恶意用户发动攻击，也无法保护数据在传出或进入私有网络后的安全。

### 14. C
存在多种动态路由协议，包括 `RIP`、`OSPF` 和 `BGP`，但 `RPC` 不是路由协议。

### 15. B
交换机是一种智能集线器。之所以称为智能，是因为它知道连接在每个出站端口上的系统地址。

### 16. A
`WAP`（无线应用协议）是与手机接入互联网相关的技术，而非 `802.11` 无线网络。

### 17. C
`OFDM`（正交频分复用）以最小的干扰提供高吞吐量。`OSPF` 是路由协议，而非无线频率接入方法。

### 18. A
端点安全是一种安全理念，鼓励管理员在每台主机上安装防火墙、恶意软件扫描器和 `IDS`。

### 19. B
`ARP`（地址解析协议）将 `IP` 地址（逻辑地址）解析为 `MAC` 地址（物理地址）。

### 20. C
企业扩展基础设施模式是指无线网络设计为通过单个 `SSID` 但众多接入点来支持大型物理环境。

## 第 12 章：安全通信与网络攻击

### 1. B
`Frame Relay`（帧中继）是一种第 2 层连接机制，使用分组交换技术在通信端点之间建立虚拟电路。`Frame Relay` 网络是一种共享介质，跨其创建虚拟电路以提供点对点通信。所有虚拟电路相互独立且不可见。

### 2. D
独立系统无需隧道技术，因为系统间不存在通信，也不存在中介网络。

### 3. C
`IPsec`（IP 安全）是一种基于标准的机制，用于为点对点 `TCP/IP` 流量提供加密。

### 4. B
`169.254.x.x` 子网属于 `APIPA` 范围，不属于 `RFC 1918`。`RFC 1918` 定义的地址为：`10.0.0.0–10.255.255.255`、`172.16.0.0–172.31.255.255` 和 `192.168.0.0–192.168.255.255`。

### 5. D
建立 `VPN` 链路需要中介网络连接。

### 6. B
需要静态模式 `NAT` 以允许外部实体发起与 `NAT` 代理后内部系统的通信。

### 7. A, B, D
`L2F`、`L2TP` 和 `PPTP` 均缺乏原生数据加密。只有 `IPsec` 包含原生数据加密。

### 8. D
`IPsec` 在网络层（第 3 层）运行。

### 9. B
`VoIP`（IP 语音）允许通过现有 `TCP/IP` 网络和互联网连接进行电话通话。

### 10. D
`NAT` 无法防范或阻止暴力破解攻击。

### 11. B
当透明性是服务、安全控制或访问机制的特征时，它对用户不可见。

### 12. B
虽然可用性是安全的关键方面，但它是面向互联网交付的电子邮件安全系统中最不重要的方面。

### 13. D
备份方法不是与最终用户讨论电子邮件保留时的重要因素。

### 14. B
邮件炸弹是将电子邮件作为攻击机制。向系统发送大量消息会导致拒绝服务。

### 15. B
垃圾邮件往往难以阻止，因为消息来源通常被伪造。

### 16. B
永久虚拟电路（`PVC`）可描述为始终存在并等待客户发送数据的逻辑电路。

### 17. B
更改 `PBX` 系统的默认密码能带来最有效的安全性提升。

### 18. C
社会工程学常可绕过即使是最有效的物理和逻辑控制。攻击者说服受害者执行的任何活动，通常旨在打开一个后门，供攻击者用以获取网络访问权限。

### 19. C
暴力破解攻击不被视为 `DoS`（拒绝服务）攻击。
