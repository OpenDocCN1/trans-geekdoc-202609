

# 网络型 DLP 系统与审计评估

基于网络的 DLP 系统过去可能阻止了一些重大泄露事件。例如，在 2014 年的索尼攻击事件中，攻击者窃取了超过 25 GB 的敏感未加密数据，涉及索尼员工的社会安全号码、医疗和薪资信息。如果攻击者在检索数据前未对其加密，DLP 系统本可检测到将数据传出网络的尝试。

然而，值得注意的是，高级持续性威胁（如第 14 章讨论的 Fancy Bear 和 Cozy Bear）通常在将流量传出网络前对其进行加密。

## 隐写术

**隐写术** 是将消息嵌入文件中的做法。例如，个人可以修改图片文件中的比特位来嵌入消息。这种变化肉眼观察图片时无法察觉，但如果其他人知道要寻找该消息，他们就可以将其提取出来。

如果你拥有原始文件和一个疑似包含隐藏消息的文件，就有可能检测出隐写术尝试。如果你使用哈希算法（如安全哈希算法 3，`SHA-3`），可以为这两个文件分别创建哈希值。如果哈希值相同，则文件不包含隐藏消息。但是，如果哈希值不同，则表明第二个文件已被修改。取证分析技术可能能够检索该消息。

在出站监控的背景下，组织可以定期获取极少变动的内部文件的哈希值。例如，`JPEG` 和 `GIF` 等图形文件通常保持不变。如果安全专家怀疑恶意内部人员在这些文件中嵌入额外数据并将其通过电子邮件发送到组织外部，他们可以将原始哈希值与恶意内部人员发送出去的文件哈希值进行比较。如果哈希值不同，则表明文件不同，可能包含隐藏消息。

## 水印技术

**水印技术** 是在纸张中嵌入不易察觉的图像或图案的做法。它常用于货币以防止伪造。同样，组织经常在文档中使用水印。例如，敏感文档的作者可以使用适当的分类标记，如“机密”或“专有”。任何处理该文件或其打印副本的人都能轻松看到分类标记。

从出站监控的角度来看，DLP 系统可以检测未加密文件中的水印。当 DLP 系统通过这些水印识别出敏感数据时，它可以阻止传输并向安全人员发出警报。这可以防止文件传出组织。

水印技术的一种高级实现是**数字水印**。数字水印是秘密嵌入数字文件中的标记。例如，一些电影制片厂会对发送给不同分销商的电影副本进行数字标记。每个副本都有不同的标记，制片厂会追踪哪个分销商收到了哪个副本。如果任何分销商发布了电影的盗版副本，制片厂就能识别出是哪个分销商泄露的。

## 审计以评估有效性

许多组织已制定了强有力且有效的安全策略。然而，策略到位并不意味着人员知晓或遵守它们。很多时候，组织希望通过审计环境来评估其安全策略及相关访问控制的有效性。

**审计** 是对环境进行有条理的检查或审查，以确保符合法规并检测异常、未经授权的事件或犯罪。它验证环境中部署的安全机制是否为环境提供了足够的安全性。测试过程确保人员遵守安全策略或其他法规规定的要求，且部署的安全解决方案中不存在重大漏洞或弱点。

**审计员** 负责测试和验证流程和程序是否到位以实施安全策略或法规，以及它们是否足以满足组织的安全要求。他们还验证人员是否遵循这些流程和程序。换句话说，审计员执行审计工作。

### 检查审计

安全的 IT 环境高度依赖审计作为一种侦察型安全控制，以发现和纠正漏洞。在访问控制的背景下，两项重要的审计是访问审查审计和用户权利审计。

明确定义并遵守审查频率非常重要。组织通常根据风险来确定安全审计或安全审查的频率。人员评估针对组织宝贵资产的漏洞和威胁，以确定总体风险水平。这有助于组织证明审计费用的合理性，并确定他们希望多久进行一次审计。

与部署和维护安全的许多其他方面一样，安全审计通常被视为尽职调查的关键要素。如果高级管理层未能强制执行定期安全审查的合规性，利益相关者可以追究他们的责任，并让他们为因安全漏洞或策略违规导致的任何资产损失承担法律责任。不执行审计会造成管理层未尽到尽职调查的印象。

### 访问审查审计

许多组织执行定期访问审查和审计，以确保对象访问和账户管理实践支持安全策略。这些审计验证用户没有过度特权，且账户得到适当管理。它们确保安全流程和程序到位、人员遵循这些流程和程序，且这些流程和程序按预期工作。

例如，对高价值数据的访问应仅限于需要它的用户。访问审查审计将验证数据已分类，且数据分类对用户清晰明了。此外，它将确保任何有权授予数据访问权限的人都了解什么条件使有资格获得该访问权限。例如，如果服务台专业人员可以授予对高度机密数据的访问权限，该专业人员需要知道什么条件使有资格获得该级别的访问权限。

在检查账户管理实践时，访问审查审计将确保根据最佳实践和安全策略禁用和删除账户。例如，如果员工被解雇，应尽快禁用其账户。典型的解雇程序策略通常包括以下要素：

*   离职面谈期间至少有一名见证人在场。
*   面谈期间禁用账户访问权限。
*   面谈期间或面谈后立即收回员工识别徽章和其他物理凭证（如智能卡）。
*   面谈后立即护送员工离开现场。

访问审查验证策略存在且人员正在遵循。当解雇的员工在离职面谈后仍持续拥有网络访问权限时，他们很容易造成破坏。例如，管理员可以创建一个单独的管理员账户，并使用它访问网络，即使该管理员的原始账户已被禁用。

### 用户权利审计

用户权利是指授予用户的特权。用户需要权利和权限（特权）来执行其工作，但他们只需要有限数量的特权。在用户权利的背景下，最小权限原则确保用户仅拥有执行其工作所需的特权，不多不少。
