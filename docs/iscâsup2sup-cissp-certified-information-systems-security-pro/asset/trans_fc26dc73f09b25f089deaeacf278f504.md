
执法机构近年来大力打击网络犯罪。世界各国的立法机构至少已尝试解决网络犯罪问题。许多执法机构都有全职、受过良好训练的计算机犯罪调查员，他们具备高级安全培训背景。那些没有此类人员的机构，通常也知道在需要这种经验时该向何处求助。

在本章中，我们将介绍处理计算机安全问题的各类法律。我们将探讨围绕计算机犯罪、隐私、知识产权及其他多个相关主题的法律问题。我们还将介绍基本的调查技术，包括寻求执法部门协助的利弊。

## 法律的类别

三大主要法律类别在我们的法律体系中发挥作用。每一类都涵盖各种情况，且违反不同类别法律的处罚差异巨大。在以下章节中，您将了解刑法、民法和行政法如何相互作用，形成复杂的司法体系网络。

### 刑法

刑法构成了维护治安、保障社会安全的法律体系基石。许多备受瞩目的法庭案件涉及刑法事务；这些是警方和其他执法机构关注的法律。刑法禁止谋杀、袭击、抢劫和纵火等行为。违反刑事法规的处罚范围包括：强制社区服务时数、以罚款形式出现的金钱处罚（大额或小额），以及以监禁形式剥夺公民自由。

许多刑法旨在保护社会免受计算机犯罪侵害。在本章后续章节中，您将了解到某些法律（如《计算机欺诈和滥用法》、《电子通信隐私法》和《身份盗窃和假冒阻遏法》等）如何为严重计算机犯罪提供刑事处罚。精通技术的检察官与关注此事的执法机构联手，利用法院系统对罪犯判处长期监禁，从而对“黑客地下世界”造成严重打击，这些罪行过去常被视为无害的恶作剧。

在美国，各级政府的立法机构通过民选代表制定刑法。在联邦层面，众议院和参议院通常必须以多数票通过刑法案，该案才能成为法律。一旦通过，这些法律即成为联邦法律，适用于联邦政府拥有管辖权的所有案件（主要涉及州际贸易、跨州案件或针对联邦政府本身的犯罪）。如果不适用联邦管辖权，州政府将依据州立法机构通过的类似法律处理案件。

所有联邦和州法律必须遵守规定美国政府体制运作的最高权威——美国宪法。所有法律均接受地区法院的司法审查，并可一路上诉至美国最高法院。如果法院认定某法律违宪，有权将其废除并宣布无效。

请记住，刑法事务严肃重大。如果您以证人、被告或受害者身份卷入刑事机关介入的事务中，强烈建议您寻求熟悉刑事司法系统、特别是计算机犯罪事务的律师协助。在如此复杂的体系中“单打独斗”并不明智。

### 民法

民法构成了我们法律体系的主体。其旨在提供有序的社会环境，管辖那些不属于犯罪、但需要公正仲裁人在个人和组织间裁决的事务。可依据民法裁决的事务类型包括：合同纠纷、房地产交易、雇佣事务和遗产/遗嘱认证程序。民法还用于构建行政分支履行职责所用的政府框架。这些法律为政府活动提供预算，并规定授予行政分支制定行政法的权力（见下一节）。

民法的颁布方式与刑法相同。它们必须经立法程序通过方能生效，并受相同的宪法参数和司法审查程序约束。在联邦层面，刑法和民法均收录于《美国法典》（USC）中。

民法与刑法的主要区别在于执行方式。通常，执法机关除采取恢复秩序所需的必要行动外，不介入民法事务。在刑事起诉中，政府通过执法调查员和检察官对被指控犯罪的人提起诉讼。在民事事务中，自认为受到损害的人有责任聘请法律顾问，向自认为应对其不满负责的人提起民事诉讼。政府（除非是原告或被告）不在争议中站队，也不为任何一方辩护。政府在民事事务中的唯一角色是提供审理民事案件所需的法官、陪审团和法庭设施，并依法在管理司法系统中发挥行政作用。

与刑法一样，如果您认为需要提起民事诉讼，或有人对您提起民事诉讼，最好寻求法律援助。虽然民法不构成监禁威胁，但败诉方可能面临严重的经济处罚。您只需看看晚间新闻即可找到例子——针对烟草公司、大型企业和富人的数百万美元诉讼每天都在提起。

### 行政法

政府行政分支赋予众多机构广泛职责，以确保政府职能有效运行。这些机构有责任遵守并执行立法机关颁布的刑法和民法。然而，显而易见，刑法和民法不可能为所有可能的情况规定规则和程序。因此，行政分支机构有一定自由度制定行政法，以政策、程序和法规的形式管控机构日常运作。行政法涵盖的主题范围极广，从联邦机构内部申请办公电话的程序等琐事，到执行国会通过的法律所用的移民政策等重大问题。行政法公布于《联邦法规汇编》，常被称为 CFR。

尽管行政法无需立法机关法案即可生效，但必须遵守所有现有的民法和刑法。政府机构不得实施直接与立法机关通过的现有法律相抵触的法规。此外，行政法（及政府机构的行为）也必须遵守美国宪法，并接受司法审查。
