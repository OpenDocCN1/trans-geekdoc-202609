
**解释漏洞管理。** 漏洞管理包括例行漏洞扫描和定期漏洞评估。漏洞扫描器可以检测已知的安全漏洞和弱点，例如缺失补丁或弱密码。它们生成报告，指示系统的技术漏洞，并作为补丁管理计划的有效检查手段。漏洞评估不仅限于技术扫描，还可以包括审查和审计以检测漏洞。
