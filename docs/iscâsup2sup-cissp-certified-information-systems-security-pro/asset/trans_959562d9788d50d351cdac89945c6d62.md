

# 扫描设备环境中的徽章

徽章也可用于由扫描设备而非保安把守的环境中。在此类条件下，徽章可用于**识别**或**认证**。当徽章用于识别时，需在设备上刷卡，随后徽章持有者必须提供一个或多个认证因素，例如密码、口令或生物特征（如果使用生物识别设备）。当徽章用于认证时，徽章持有者提供 ID、用户名等，然后刷卡进行认证。

## 运动探测器

`motion detector`（运动探测器）或 `motion sensor`（运动传感器）是一种能感知特定区域内移动或声音的设备。运动探测器类型繁多，包括红外、热感、波形、电容、光电和无源音频等。

*   `infrared motion detector`（红外运动探测器）监控受监区域红外光照模式的显著或有意义变化。
*   `heat-based motion detector`（热感运动探测器）监控受监区域热度水平和模式的显著或有意义变化。
*   `wave pattern motion detector`（波形运动探测器）向受监区域发射一致的低频超声波或高频微波信号，并监控反射模式的显著或有意义变化或干扰。
*   `capacitance motion detector`（电容运动探测器）感知受监物体周围电场或磁场的变化。
*   `photoelectric motion detector`（光电运动探测器）感知受监区域可见光照度的变化。光电运动探测器通常部署在无窗且保持黑暗的内部房间中。
*   `passive audio motion detector`（无源音频运动探测器）监听受监区域内的异常声音。

## 入侵报警器

每当运动探测器记录到环境中的显著或有意义变化时，就会触发报警。`alarm`（报警器）是一种独立机制，可触发威慑、驱赶和/或通知。

### 威慑型报警器

触发威慑措施的报警器可能会启动额外的锁、关闭门等。此类报警器的目标是使进一步的入侵或攻击变得更加困难。

### 驱赶型报警器

触发驱赶措施的报警器通常会拉响音频警笛或警铃并打开灯光。这类报警器用于阻止入侵者或攻击者继续其恶意或非法闯入活动，并迫使其离开现场。

### 通知型报警器

触发通知的报警器从入侵者/攻击者的角度来看通常是静默的，但会记录事件数据并通知管理员、保安和执法部门。事件记录可以采取日志文件和/或闭路电视（CCTV）录像带的形式。静默报警的目的是将授权安保人员引至入侵或攻击现场，以期抓获实施非法或未授权行为的人员。

报警器也可按其安装位置分类：本地、中心/专有或辅助。

### 本地报警系统

`Local alarm systems`（本地报警系统）必须广播可听见的（高达 120 分贝 [db]）报警信号，且在 400 英尺（约 122 米）范围内清晰可闻。此外，它们必须受到防篡改和防禁用保护，通常由保安负责。为了使本地报警系统有效，必须有安保团队或保安驻守在附近，以便在报警触发时做出响应。

### 中心站系统

报警器在本地通常是静默的，但异地监控代理会收到通知，以便他们对安全漏洞做出响应。大多数住宅安防系统属于此类。大多数中心站系统为知名或国家级安保公司，如 Brinks 和 ADT。`proprietary system`（专有系统）类似于中心站系统，但宿主组织拥有自己的现场安保人员，随时待命响应安全漏洞。

### 辅助站

`Auxiliary alarm systems`（辅助报警系统）可添加到本地或中心报警系统中。当安全边界被突破时，会通知紧急服务部门响应事件并抵达现场。这可能包括消防、警察和医疗服务。

两种或多种类型的入侵和报警系统可整合在单一解决方案中。

## 二次验证机制

当使用运动探测器、传感器和报警器时，应部署二次验证机制。随着这些设备灵敏度的提高，误触发的频率也会增加。动物、鸟类、昆虫或授权人员的出现等无害事件均可能触发误报。部署两个或多个检测和传感器系统，并要求在报警发出前在短时间内连续发生两次或多次触发，可显著减少误报，并增加报警指示实际入侵或攻击的可能性。

闭路电视（CCTV）是一种与运动探测器、传感器和报警器相关的安全机制。然而，CCTV 并非自动化的检测与响应系统。CCTV 需要人员观看捕获的视频以检测可疑和恶意活动并触发报警。安防摄像头可扩大保安的有效可视范围，从而增加监管范围。在许多情况下，CCTV 不用作主要检测工具，因为雇佣专人盯着视频屏幕的成本过高。相反，它被用作辅助或后续机制，在自动化系统触发后进行复查。事实上，用于审计和审计追踪的逻辑同样适用于 CCTV 和录制事件。CCTV 是一种预防措施，而复查录制事件则是一种侦查措施。

## 环境与生命安全

物理访问控制和维护设施安全的一个重要方面是保护环境基本要素和人身安全。在任何情况下和所有条件下，安全最重要的方面都是保护人员。因此，防止人员受到伤害是所有安全解决方案的首要目标。

维护人员安全的部分工作是维护设施的基本环境。在短时间内，人员可以在无水、无食物、无空调和无电力的情况下生存。但在某些情况下，这些要素的丧失可能导致灾难性后果，或成为更直接、更危险问题的征兆。洪水、火灾、有毒物质泄漏和自然灾害均威胁人类生命及设施稳定性。物理安全程序应重点关注保护人身安全，其次是恢复环境安全，并恢复 IT 基础设施运行所需的公用设施。

人员安全应始终是您的首要任务。只有在人员安全得到保障后，才能考虑处理业务连续性问题。许多组织采用人员应急预案（OEP）来指导和协助在灾难发生后维持人员安全。OEP 提供了关于如何将生命威胁降至最低、预防伤害、应对胁迫、处理出行、提供安全监控以及保护财产免受破坏性物理事件损害的指导。OEP 不涉及 IT 问题或业务连续性，仅关注人员和一般财产。业务连续性计划（BCP）和灾难恢复计划（DRP）解决 IT 和业务连续性及恢复问题。

## 隐私责任与法律要求

任何组织的安全策略中也必须涉及个人信息的安全。此外，安全策略必须符合其所在行业和司法管辖区的监管要求。
