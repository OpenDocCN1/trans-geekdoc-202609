## 密码学基础

任何科学的研究都必须从探讨其建立所依据的基本原理开始。以下章节将奠定这一基础，回顾密码学的目标，概述密码技术的基本概念，并审视密码系统所使用的主要数学原理。

### 密码学的目标

安全从业者使用密码系统来实现四个基本目标：机密性、完整性、认证和不可抵赖性。实现这些目标中的每一个都需要满足许多设计要求，且并非所有密码系统都旨在实现这四个目标。在以下章节中，我们将详细探讨每个目标，并简要描述实现它所需的技术要求。

#### 机密性

*机密性* 确保数据在三种不同情况下保持私密：静止时、传输中和使用中。

机密性可能是密码系统最广为人知的目标——即保护存储信息或个人和群体之间通信的秘密性。两种主要类型的密码系统用于实施机密性。

*   *对称密码系统* 使用密码系统所有用户均可用的共享密钥。
*   *非对称密码系统* 为系统的每个用户使用各自的公钥和私钥组合。本章后面的“现代密码学”部分将探讨这两个概念。

在为提供机密性而开发密码系统时，必须考虑三种不同类型的数据。

*   *静态数据*，或存储数据，是指驻留在永久位置等待访问的数据。静态数据的示例包括存储在硬盘驱动器、备份磁带、云存储服务、USB 设备和其他存储介质上的数据。
*   *传输中数据*，或线路上的数据，是指在两个系统之间跨网络传输的数据。传输中数据可能在企业网络、无线网络或公共互联网上传输。
*   *使用中数据* 是存储在计算机系统活动内存中、可供在该系统上运行的进程访问的数据。

这些情况中的每一种都带来不同类型的机密性风险，密码学可以防范这些风险。例如，传输中数据可能易受窃听攻击，而静态数据更易受物理设备盗窃的威胁。如果操作系统未正确实现进程隔离，使用中数据可能被未授权进程访问。

#### 完整性

*完整性* 确保数据未经授权不被篡改。如果已采取完整性机制，消息接收者可以确定收到的消息与发送的消息完全相同。同样，完整性检查可确保存储的数据在创建和访问之间未被篡改。完整性控制可防范所有形式的篡改，包括第三方试图插入虚假信息的故意篡改、故意删除部分数据，以及传输过程中故障导致的非故意篡改。

消息完整性通过使用加密的消息摘要（称为 *数字签名*）来实施，这些摘要在消息发送时创建。消息接收者只需验证消息的数字签名是否有效，即可确保消息在传输过程中未被篡改。完整性既可由公钥密码系统实施，也可由密钥密码系统实施。第 7 章“PKI 和密码应用”将详细讨论这一概念。第 21 章“恶意代码和应用攻击”将讨论使用密码哈希函数保护文件完整性。

#### 认证

*认证* 验证系统用户的声称身份，是密码系统的主要功能。例如，假设 Bob 想与 Alice 建立通信会话，且两人均为共享密钥通信系统的参与者。Alice 可能会使用质询-响应认证技术来确保 Bob 就是他声称的那个人。

[图 6.1](#c06.xhtml#figure6-1) 展示了此质询-响应协议的实际工作方式。在此示例中，Alice 和 Bob 使用的共享密钥代码非常简单——仅是将每个单词的字母顺序反转。Bob 首先联系 Alice 并表明身份。Alice 随后向 Bob 发送一条质询消息，要求他使用仅 Alice 和 Bob 知道的秘密代码加密一条简短消息。Bob 回复加密后的消息。Alice 验证加密消息正确后，即信任连线另一端的确实是 Bob 本人。

#### 不可抵赖性

*不可抵赖性* 向接收者保证消息由发送者发出，而非冒充发送者的其他人。它还防止发送者声称从未发送过该消息（也称为 *抵赖* 消息）。密钥（或对称密钥）密码系统（如简单替换密码）不提供这种不可抵赖性保证。如果 Jim 和 Bob 参与密钥通信系统，他们都可以使用共享密钥生成相同的加密消息。只有公钥（或非对称）密码系统才提供不可抵赖性，第 7 章将更详细地讨论该主题。

### 密码学概念

与任何科学一样，学习密码学前必须熟悉特定术语。让我们看看一些用于描述代码和密码的关键术语。在消息转换为编码形式之前，它被称为 *明文* 消息，在描述加密函数时用字母 `P` 表示。消息发送者使用密码算法 *加密* 明文消息，生成 *密文* 消息，用字母 `C` 表示。该消息通过某种物理或电子方式传输给接收者。接收者随后使用预定算法解密密文消息，恢复明文版本。（有关此过程的说明，请参阅本章后面的 [图 6.3](#c06.xhtml#figure6-3)。）

所有密码算法都依赖 *密钥* 来维护其安全性。在大多数情况下，密钥无非是一个数字。它通常是一个非常大的二进制数，但终究是一个数字。每种算法都有特定的 *密钥空间*。密钥空间是指可用作特定算法密钥的有效取值范围。密钥空间由其 *位大小* 定义。位大小无非是密钥中二进制位（0 和 1）的数量。密钥空间是全 0 密钥与全 1 密钥之间的范围。换一种说法，密钥空间是从 0 到 `2^n` 的数字范围，其中 `n` 是密钥的位大小。因此，128 位密钥的取值范围是从 0 到 `2^128`（约为 `3.40282367 × 10^38`，一个非常大的数字！）。保护密钥的安全至关重要。事实上，你从密码学获得的所有安全性都建立在你保持所用密钥私密的能力之上。
