

# 第 5 章：保护资产安全

## 问题 7-20

### 7. A
版权法是 Matthew 可用的唯一类型的知识产权保护。它仅涵盖 Matthew 使用的特定软件代码。它不涵盖软件背后的流程或构想。商标保护不适用于此类情况。专利保护不适用于数学算法。Matthew 无法寻求商业秘密保护，因为他计划在公开的技术期刊上发表该算法。

### 8. D
Mary 和 Joe 应将他们的石油配方视为商业秘密。只要他们不公开披露该配方，就可以无限期地将其作为公司机密保存。

### 9. C
Richard 的产品名称应受商标法保护。在其注册获批之前，他可以在名称旁使用 `™` 符号，告知他人该名称受商标法保护。一旦申请获批，该名称即成为注册商标，Richard 便可以开始使用 `®` 符号。

### 10. A
1974 年《隐私法》限制了政府机构在特定情况下使用私人公民向其披露的信息的方式。

### 11. B
由美国商务部和联邦贸易委员会管理的“隐私盾”框架，允许美国公司认证其符合欧盟数据保护法。

### 12. A
《儿童在线隐私保护法案》（COPPA）对未经父母同意收集幼童信息的公司规定了严厉的处罚。COPPA 规定，在收集任何信息（获取该同意所需的基本信息除外）之前，必须获得 13 岁以下儿童父母的同意。

### 13. A
《数字千年版权法》在“暂时性活动”豁免的保护要求中，不包含任何地理位置要求。其他选项是五项强制性要求中的三项。另外两项要求是：服务提供商不得确定材料的接收者，且材料的传输不得对其内容进行任何修改。

### 14. C
《美国爱国者法案》是在 2001 年 9 月 11 日恐怖袭击发生后通过的。它扩大了政府监控私人公民通信的权力，从而实际上削弱了消费者和互联网用户的隐私权。文中提到的其他法律都包含旨在加强个人隐私权的条款。

### 15. B
收缩包装许可协议在用户打开软件包装时生效。点击包装协议要求用户在安装过程中点击按钮以接受许可协议条款。标准许可协议要求用户在使用软件前签署书面协议。口头协议通常不用于软件许可，但也需要软件用户的某种主动参与。

### 16. B
《格雷姆-里奇-比利雷法案》除其他内容外，还规定了金融机构处理其客户私人信息的方式的相关法规。

### 17. C
美国专利法规定了自专利申请提交给专利商标局之日起 20 年的独占期。

### 18. C
《通用数据保护条例》（GDPR）是一项全面的数据隐私法律，保护全球欧盟居民的个人信息。该法律计划于 2018 年生效。

### 19. C
《支付卡行业数据安全标准》（PCI DSS）适用于涉及存储、传输和处理信用卡信息的组织。

### 20. A
2009 年《健康信息技术经济与临床健康法案》（HITECH）修订了 HIPAA 的隐私和安全要求。

## 第 5 章：保护资产安全（问题 1-10）

### 1. A
信息分类过程的主要目的是识别敏感数据的安全分类，并定义保护敏感数据的要求。信息分类过程通常包括保护静态敏感数据（在备份中和存储在介质上）的要求，但不包括备份和存储所有数据的要求。同样，信息分类过程通常包括保护传输中敏感数据的要求，但不一定包括保护传输中所有数据的要求。

### 2. B
数据根据其对组织的价值进行分类。在某些情况下，根据未经授权的人员访问它可能造成的潜在负面影响进行分类。它不是基于处理系统进行分类的，而是处理系统基于其处理的数据进行分类。同样，存储介质基于数据分类进行分类，但数据不是基于其存储位置进行分类的。可访问性受分类影响，但可访问性不决定分类。人员实施控制以限制对敏感数据的访问。

### 3. D
发布在网站上的数据不敏感，但 PII、PHI 和专有数据都是敏感数据。

### 4. D
分类是标记介质最重要的方面，因为它明确标识了介质的价值，用户知道如何根据分类来保护它。包含日期和内容描述等信息不如标记分类重要。可以使用电子标签或标记，但它们应用于文件，而非介质，并且在使用时，标记介质仍然很重要。

### 5. C
清除介质通过多次覆盖现有数据来移除所有数据，以确保数据无法使用任何已知方法恢复。已清除的介质随后可在安全要求较低的环境中重复使用。擦除介质执行删除操作，但数据仍然保留且易于恢复。清零（或覆盖）用非机密数据覆盖现有数据，但某些复杂的取证技术可能能够恢复原始数据，因此不应使用此方法来降低介质的分类级别。

### 6. C
清理可能不可靠，因为人员可能不当地执行清除、消磁或其他过程。如果操作得当，已清除的数据无法使用任何已知方法恢复。无法从已焚烧的介质中检索数据。数据并非物理蚀刻在介质上。

### 7. D
在给定选项中，清除是最可靠的方法。清除通过多次用随机位覆盖介质，并包含额外步骤以确保数据被移除。虽然不是可选答案，但销毁驱动器是一种更可靠的方法。擦除或删除过程很少从介质中移除数据，而是将其标记为待删除。固态硬盘（SSD）没有磁通量，因此对 SSD 进行消磁不会销毁数据。

### 8. C
物理销毁是删除 DVD 等光学介质上数据的最安全方法。格式化和删除过程很少从任何介质中移除数据。DVD 没有磁通量，因此对 DVD 进行消磁不会销毁数据。

### 9. D
数据残留是指以残余磁通量形式保留在硬盘驱动器上的数据残余。清零、清除和覆盖都是擦除数据的有效方法。

### 10. C
Linux 系统使用 `bcrypt` 加密密码，而 `bcrypt` 基于 Blowfish。`bcrypt` 增加 128 位额外的盐值以防止彩虹表攻击。高级加密标准（AES）和三重 DES（或 3DES）是单独的对称加密协议，两者均不基于 Blowfish，也与防止彩虹表攻击无直接关系。安全复制（SCP）使用安全外壳（SSH）加密通过网络传输的数据。
