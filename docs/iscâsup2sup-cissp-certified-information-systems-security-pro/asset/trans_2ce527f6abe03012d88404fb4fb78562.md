
Code Red 蠕虫在 2001 年夏季因在运行未修补版本的微软 Internet Information Server (IIS) 的 Web 服务器中迅速传播而受到媒体的广泛关注。Code Red 在渗透的系统上执行了三项恶意操作：

*   它随机选择数百个互联网协议 (IP) 地址，然后探测这些地址，查看它们是否被运行易受攻击版本 IIS 的主机使用。它发现的任何系统都会被迅速攻破。这极大地扩大了 Code Red 的影响范围，因为它感染的每个主机都会寻找许多新目标。
*   它篡改了本地 Web 服务器上的 HTML 页面，将正常内容替换为以下文本：

```
Welcome to http://www.worm.com!
Hacked By Chinese!
```

*   它植入了一个逻辑炸弹，将针对 IP 地址 `198.137.240.91` 发起拒绝服务攻击，该地址当时属于托管白宫主页的 Web 服务器。反应迅速的政府网络管理员在攻击真正开始前更改了白宫的 IP 地址。

蠕虫的破坏力对现代互联网构成了极端风险。系统管理员必须确保在软件供应商发布安全补丁时，及时将其应用到连接互联网的系统上。一个典型的例子是，微软在 Code Red 蠕虫攻击互联网前一个多月就已提供了针对其利用的 IIS 漏洞的安全修复程序。如果安全管理员及时应用了该补丁，Code Red 将会彻底失败。

### Stuxnet

2010 年中，一款名为 Stuxnet 的蠕虫出现在互联网上。这种高度复杂的蠕虫使用多种先进技术进行传播，包括多个此前未公开的漏洞。Stuxnet 使用以下传播技术：

*   搜索本地网络上系统的未受保护管理共享
*   利用 Windows Server 服务和 Windows 打印后台处理程序服务中的零日漏洞
*   使用默认数据库密码连接到系统
*   通过共享受感染的 USB 驱动器进行传播

虽然 Stuxnet 可以肆无忌惮地在系统间传播，但它实际上在寻找一种非常特定类型的系统——使用西门子制造的控制器、据称用于生产核武器材料的系统。当它发现此类系统时，会执行一系列旨在破坏连接到西门子控制器的离心机的操作。

Stuxnet 似乎始于中东地区，具体是伊朗境内的系统。据称它是由西方国家设计，意图破坏伊朗的核武器计划。根据《纽约时报》的一篇报道，以色列的一个设施包含用于测试该蠕虫的设备。报道称：“以色列拥有与伊朗几乎相同的核离心机”，并指出“那里的行动，以及美国的相关努力，……是该病毒被设计为美以合作项目以破坏伊朗计划的线索。”

如果这些指控属实，Stuxnet 标志着恶意代码领域的两大演变：利用蠕虫对设施造成重大物理破坏，以及在国家间战争中使用恶意代码。

### 间谍软件和广告软件

另外两种不需要的软件会干扰你正常使用计算机的方式。*间谍软件* 监视你的操作，并将重要详细信息传输给监视你活动的远程系统。例如，间谍软件可能会等待你登录银行网站，然后将你的用户名和密码传输给间谍软件的创建者。或者，它可能会等待你在电子商务网站上输入信用卡号，然后将其传输给欺诈者以便在黑市上转售。

*广告软件* 虽然在形式上与间谍软件非常相似，但目的不同。它使用多种技术在受感染的计算机上显示广告。最简单形式的广告软件会在你浏览网页时在屏幕上显示弹窗广告。更恶劣的版本可能会监视你的购物行为，并将你重定向到竞争对手的网站。

### 零日攻击

许多形式的恶意代码利用*零日漏洞*，即由黑客发现但安全社区尚未彻底解决的安全缺陷。系统受这些漏洞影响主要有两个原因：

*   发现新类型恶意代码与发布补丁和防病毒更新之间必要的延迟。这被称为*脆弱性窗口*。
*   系统管理员应用更新的迟缓

零日漏洞的存在使得采用纵深防御网络安全方法至关重要，该方法应包含一套多样化的重叠安全控制。这些控制应包括强大的补丁管理计划、最新的防病毒软件、配置管理、应用程序控制、内容过滤和其他防护措施。当这些重叠控制结合使用时，能增加至少有一个控制检测并阻止恶意软件安装尝试的可能性。

## 密码攻击

攻击者用于获取系统非法访问权限的最简单技术之一，是获取授权系统用户的用户名和密码。一旦他们以普通用户身份获得访问权，就获得了系统的立足点。此时，他们可以使用其他技术（包括自动化 Rootkit 包）来获取系统的更高访问权限（请参阅本章后面的“权限提升和 Rootkit”部分）。他们还可能将受损系统作为跳板，对同一网络上其他更有价值的目标发起攻击。

以下部分将探讨攻击者用于获取合法用户密码并访问系统的三种方法：密码猜测攻击、字典攻击和社会工程学攻击。许多此类攻击依赖于薄弱的密码存储机制。例如，网站可能会在单个文件中存储消息摘要算法 5 (MD5) 密码哈希值。如果攻击者能够操纵 Web 服务器软件或操作系统以获取该文件副本，他们就可以利用它进行攻击。

### 密码猜测

在最基本的密码攻击类型中，攻击者只是简单地尝试猜测用户的密码。无论用户接受多少安全教育，他们往往都会使用极其薄弱的密码。如果攻击者能够获取授权系统用户列表，他们通常能迅速弄清正确的用户名。（在大多数网络中，用户名由用户名字的首字母加上姓氏的一部分组成。）有了这些信息，他们就可以开始对用户的密码进行一些有根据的猜测。最常用的密码是用户姓氏、名字或用户名的某种形式。例如，用户 `mchapple` 可能会使用薄弱密码 `elppahcm`，因为它容易记忆。不幸的是，它也很容易被猜到。

如果尝试失败，攻击者会转向互联网上广泛可用的最常用密码列表。其中一些如“最常用密码”栏所示。

最后，对一个人稍微了解一些就能为其密码提供极好的线索。许多人使用配偶、孩子、宠物、亲戚或喜爱的艺人名字。常见密码还包括生日、纪念日、社会安全号码、电话号码和自动取款机 (ATM) 个人识别码 (PIN)。
