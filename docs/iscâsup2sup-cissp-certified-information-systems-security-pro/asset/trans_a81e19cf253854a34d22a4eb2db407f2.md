

# 香肠攻击

根据所有公开报告，`香肠攻击` 更多属于传说色彩。该攻击名称指的是对账户资产或其他具有财务价值记录的系统性侵蚀，即定期、例行地从余额中扣除极小金额。打个比方，这种攻击就像在顾客付费使用切片机切香肠时，每次都偷偷切走一片极薄的香肠。然而，尽管没有此类攻击的文档化案例，大多数安全专家都承认香肠攻击是可能发生的，尤其是当组织内部人员参与其中时。只有通过适当的职责分离和对代码的适当控制，组织才能完全防止或消除此类攻击。设置财务交易监控以追踪极小额的资金转移或其他价值物品的转移，有助于检测此类活动；定期通知员工此类做法，有助于阻止此类攻击尝试。

## 编程

我们已经提到过编程中最大的缺陷：缓冲区溢出，如果程序员未能检查或清理输入数据的格式和/或大小，就会发生这种情况。程序还有其他潜在缺陷。任何无法优雅处理异常的程序都有以不稳定状态退出的危险。在程序提升安全级别以执行正常任务后，有人可能巧妙地使其崩溃。如果攻击者成功在恰当的时机使程序崩溃，他们就能获得更高的安全级别，并破坏系统的机密性、完整性和可用性。

所有直接或间接执行的程序都必须经过全面测试，以符合您的安全模型。请确保安装了任何软件的最新版本，并了解任何已知的安全漏洞。由于每个安全模型和每个安全策略都不同，您必须确保所执行的软件不会超出您允许的权限。编写安全代码很难，但绝对可行。请确保您使用的所有程序在设计时都考虑到了安全问题。更多关于代码审查和测试的信息，请参阅第 15 章。

## 时序、状态变更与通信中断

计算机系统以严格的精度执行任务。计算机擅长可重复的任务。攻击者可以根据任务执行的可预测性开发攻击。算法的常见事件序列是：先检查资源是否可用，如果被允许则访问它。`检查时间 (TOC)` 是主体检查对象状态的时间。在返回访问对象之前，可能需要做出几个决定。当决定访问对象时，过程会在 `使用时间 (TOU)` 访问它。TOC 和 TOU 之间的差异有时足够大，以便攻击者用另一个符合其需求的对象替换原始对象。`检查时间到使用时间攻击 (TOCTOU)` 通常被称为 `竞争条件`，因为攻击者正在与合法进程竞争，试图在对象被使用前将其替换。

TOCTTOU 攻击的一个经典例子是在数据文件身份验证通过后、数据读取前替换该文件。通过将一个真实的数据文件替换为攻击者精心挑选和设计的另一个文件，攻击者可以潜在地以多种方式控制程序的行为。当然，攻击者必须对被攻击的程序和系统有深入了解。

同样，攻击者可能试图在资源状态或整个系统状态发生变化时，利用两个已知状态之间的间隙采取行动。通信中断也提供了攻击者可能试图利用的小时间窗口。任何时候资源的状态检查先于对资源的操作，在检查和操作的短暂间隔中就存在潜在攻击的机会窗口。这些攻击必须在您的安全策略和安全模型中加以应对。TOCTTOU 攻击、竞争条件利用和通信中断被称为 `状态攻击`，因为它们攻击的是时序、数据流控制以及从一种系统状态到另一种系统状态的转换。

## 技术与流程集成

评估和理解系统架构中的漏洞非常重要，特别是关于技术与流程集成方面。当多种技术和复杂流程在打造新的独特业务功能时相互交织，新的问题和安全隐患往往会浮现。随着系统集成，应关注潜在的单点故障，以及 `面向服务架构 (SOA)` 中出现的弱点。SOA 利用现有但独立且独特的软件服务构建新的应用程序或功能。由此产生的应用程序通常是新的；因此，其安全问题未知、未经测试且无防护。所有新部署，特别是新应用程序或功能，在被允许上线到生产网络或公共互联网之前，都需要经过彻底的审查。

## 电磁辐射

仅仅因为构建它们的电子元件种类，许多计算机硬件设备在正常运行期间都会发射电磁 (EM) 辐射。与其他机器或外围设备通信的过程会产生可被拦截的辐射。甚至可以通过拦截和处理来自键盘和计算机显示器的电磁辐射，还原键盘输入或显示器输出。您还可以在网络数据包沿网段传输时，被动地（即不实际接入电缆）检测和读取它们。这些辐射泄露可能导致严重的安全问题，但通常易于解决。

消除电磁辐射拦截最简单的方法是通过电缆屏蔽或管道减少辐射，并通过实施物理安全控制，阻止未经授权的人员和设备过于接近设备或线缆。通过降低信号强度并增加敏感设备周围的物理缓冲区，可以大幅降低信号被拦截的风险。

如前所述，几种 TEMPEST 技术可提供针对电磁辐射窃听的防护。这些包括法拉第笼、干扰器或噪声发生器以及控制区。`法拉第笼` 是一种特殊的外壳，充当电磁电容器。使用法拉第笼时，没有电磁信号能进入或离开封闭区域。`干扰` 或 `噪声发生器` 利用这样一个原理：当干扰过大时，很难或不可能恢复信号。因此，通过广播自己的干扰，可以防止不必要的电磁拦截。该概念唯一的问题是，必须确保干扰不会影响您设备的正常操作。确保这一点的一种方法是使用 `控制区`，即用于阻挡故意广播干扰的法拉第笼。例如，如果您想在办公室的几个房间内使用无线网络，但不允许在其他地方使用，您可以用一个法拉第笼将这些房间封闭起来，然后在控制区外部放置几个噪声发生器。这将允许在指定房间内正常使用无线网络，但完全阻止这些指定区域外的正常使用和窃听。
