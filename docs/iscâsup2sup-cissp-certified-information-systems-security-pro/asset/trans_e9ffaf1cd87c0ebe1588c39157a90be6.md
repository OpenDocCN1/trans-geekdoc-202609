

# SSD 与清除

SSD 在清除方面存在独特问题。SSD 的磨损均衡意味着通常存在一些未标记为“活动”的数据块，但它们在数据被复制到磨损程度较低的块时保存了数据的副本。这意味着传统的零擦除作为 SSD 的数据安全措施是无效的。

# 辅助存储设备盗窃

辅助存储设备也容易被盗。经济损失并非主要因素（毕竟，备份磁带或硬盘值多少钱？），但机密信息的丢失构成巨大风险。如果有人将你的商业机密复制到可移动介质光盘上并带出大门，其价值远超光盘本身的成本。因此，使用全盘加密以降低未经授权实体访问数据的风险至关重要。由于 SSD 的磨损均衡技术，在存储任何数据之前对其进行加密是良好的安全实践。这将最大程度地减少明文数据驻留在休眠块中的可能性。幸运的是，许多 HDD 和 SSD 设备提供设备原生加密功能。

# 辅助存储的访问控制

对存储在辅助存储设备上的数据的访问，是计算机安全专业人员面临的最关键问题之一。对于硬盘，数据通常可以通过操作系统访问控制的组合来保护。可移动介质构成更大的挑战，因此保护它们通常需要加密技术。

# 介质保留与淘汰

由于可用性也是安全三要素的一部分，因此选择能在所需时间长度内保留数据的介质至关重要。例如，备份磁带可能在数据保留期结束前就已降解。此外，用于辅助存储的技术可能会过时，导致难以恢复/读取数据。

# 输入和输出设备

输入和输出设备通常被视为基本、原始的外设，通常在它们停止正常工作前不会受到太多关注。然而，即使这些基本设备也可能给系统带来安全风险。安全专业人员应了解这些风险，并确保采取适当的控制措施来缓解它们。接下来的四节将探讨特定输入和输出设备带来的一些风险。

## 显示器

显示器看起来相当无害。毕竟，它们只是显示操作系统呈现的数据。当你关闭它们时，数据从屏幕上消失且无法恢复。然而，名为 `TEMPEST` 的程序技术可能会危及显示器上显示数据的安全。通常，阴极射线管（CRT）显示器更容易产生显著辐射，而液晶显示器（LCD）泄露的辐射少得多（有人声称不足以泄露关键数据）。

`TEMPEST` 是一种技术，允许从远处读取每个显示器产生的电子辐射（称为 `Van Eck 辐射`）（此过程称为 `Van Eck 窃听`），甚至可以从另一个位置读取。该技术也可用于防范此类活动。各种演示表明，你可以轻松读取办公楼内显示器的屏幕内容，只需使用停在街边货车内的设备即可。不幸的是，防止 `Van Eck 辐射` 所需的保护控制（大量的铜！）实施成本高昂且使用笨重。可以说，任何显示器最大的风险仍然是肩窥或相机长焦镜头。有人用肉眼或摄像机看到你屏幕内容的概念称为 `肩窥`。不要忘记 `肩窥` 适用于台式机显示器、笔记本显示器、平板电脑和手机。

## 打印机

打印机也可能代表安全风险，尽管相对简单。取决于组织采用的物理安全控制，带走纸质形式的敏感信息可能比带走闪存驱动器或磁性介质容易得多。如果打印机是共享的，用户可能忘记取走敏感打印件，使其暴露在窥视之下。许多现代打印机还在本地存储数据，通常在硬盘上，有些甚至无限期保留打印副本。打印机通常在网络上暴露以便访问，且通常未设计为安全系统。但根据打印机型号，可能有许多配置设置可提供合理级别的安全网络打印服务。这些可以包括加密数据传输和打印机交互前的身份验证。这些问题最好由组织的安全策略来解决。

## 键盘/鼠标

键盘、鼠标和类似的输入设备也无法免疫安全漏洞。所有这些设备都容易受到 `TEMPEST` 监控。此外，键盘还容易受到不那么复杂的窃听。一个简单的装置可以放置在键盘内部或其连接线上，以拦截所有按键并利用无线电信号传输给远程接收器。这具有与 `TEMPEST` 监控相同的效果，但可以用成本低得多的设备完成。此外，如果你的键盘和鼠标是无线的，包括蓝牙，它们的无线电信号可能被拦截。

## 调制解调器

随着普遍宽带和无线连接的出现，调制解调器正成为稀缺的遗留计算机组件。如果你的组织仍在使用旧设备，调制解调器可能是硬件配置的一部分。用户系统上存在调制解调器，往往是安全管理员最大的烦恼之一。调制解调器允许用户在你的网络中创建不受控制的接入点。在最坏的情况下，如果配置不当，它们会造成极其严重的安全漏洞，允许外部人员绕过所有边界保护机制，直接访问网络资源。在最好的情况下，它们创建了一个替代的出口通道，内部人员可用来将数据输送到组织外部。但请记住，只有当调制解调器连接到正在运行的电话固定线路时，这些漏洞才能被利用。

除非确实有业务需求，否则你应在组织的安全策略中认真考虑全面禁止调制解调器。在这些情况下，安全官员应知晓网络上所有调制解调器的物理和逻辑位置，确保它们配置正确，并确保采取适当的保护措施以防止其非法使用。

# 固件

`固件`（在某些领域也称为 `微代码`）是用于描述存储在 ROM 芯片中的软件的术语。这种类型的软件不经常更改（实际上，如果存储在真正的 ROM 芯片上而非 EPROM/EEPROM 上，则永不更改），且通常驱动计算设备的基本操作。固件有两种类型：主板上的 BIOS 以及通用的内部和外部设备固件。

## BIOS 和 UEFI

`基本输入/输出系统 (BIOS)` 包含计算机启动并从磁盘加载操作系统所需的、与操作系统无关的原始指令。BIOS 包含在固件设备中，计算机在启动时立即访问它。在大多数计算机中，BIOS 存储在 EEPROM 芯片上以便于版本更新。更新 BIOS 的过程称为“`刷新` BIOS”。

已有少数恶意代码嵌入 BIOS/固件的案例。还有一种称为 `phlashing` 的攻击，即安装官方 BIOS 或固件的恶意变体，在设备中引入远程控制或其他恶意功能。
