

# 无线天线与安全

大多数其他类型的天线是定向的，意味着它们将发送和接收能力集中在一个主要方向上。`定向天线` 的一些示例包括八木天线、罐头天线、面板天线和抛物面天线。八木天线的结构类似于传统的屋顶电视天线。八木天线由一根带有横截面的直杆制成，用于捕捉主杆方向上的特定无线电频率。罐头天线由一端密封的管子制成。它们沿着管子开口端的方向聚焦。最早的一些罐头天线是用 Pringles 薯片罐制作的。面板天线是扁平设备，仅从面板的一侧聚焦。抛物面天线用于聚焦来自极远距离或微弱信号源的信号。

## 调整功率电平控制

某些无线接入点提供物理或逻辑方式的天线功率电平调整。功率电平控制通常由制造商设置为适合大多数情况的设置。然而，如果在执行现场勘测和调整天线位置后，无线信号仍然不令人满意，则可能需要进行功率电平调整。但请记住，更改信道、避开反射面和信号散射面以及减少干扰，在提高连接可靠性方面通常更为重要。

调整功率电平时，应进行微调，而不是试图将设置最大化或最小化。此外，请记下初始/默认设置，以便需要时可以恢复到该设置。每次调整功率电平后，在重新执行现场勘测和质量测试之前，请重置/重启无线接入点。有时降低功率电平可以提高性能。重要的是要记住，某些无线接入点能够提供高于其销售国家/地区法规允许的功率电平。

## WPS

`Wi-Fi Protected Setup (WPS)` 是无线网络的安全标准。其目的是简化将新客户端添加到安全性良好的无线网络所涉及的工作。它通过在管理员按下基站上的 WPS 按钮触发该功能后，自动将第一个寻找网络的新无线客户端连接到网络来运作。然而，该标准还要求提供一个代码或个人识别号 (PIN)，该代码或 PIN 可以远程发送到基站，以触发 WPS 协商，而无需物理按下按钮。这导致了一种暴力猜测攻击，黑客可在数小时内（通常少于六小时）猜出 WPS 代码，进而将其自己的未授权系统连接到无线网络。

WPS 是大多数无线接入点上默认启用的功能，因为它是设备通过 Wi-Fi 联盟认证的要求。作为以安全为重点的预部署流程的一部分，禁用它非常重要。如果设备不提供关闭 WPS 的功能（或关闭开关不起作用），请升级或更换基站的固件，或更换整个设备。

通常，请保持 WPS 关闭。每次升级固件时，请再次执行以安全为重点的预部署流程，以确保所有设置（包括 WPS）均已正确设置。如果您需要向网络添加大量客户端，可以暂时重新启用 WPS —— 只需确保事后立即将其禁用即可。

## 使用捕获门户

`捕获门户` 是一种身份验证技术，它将新连接的无线 Web 客户端重定向到门户访问控制页面。门户页面可能要求用户输入付款信息、提供登录凭据或输入访问代码。捕获门户还用于向用户显示可接受使用策略、隐私策略和跟踪策略，用户必须同意这些策略才能跨网络进行通信。捕获门户最常位于为公共用途实施的无线网络上，例如酒店、餐厅、酒吧、机场、图书馆等。不过，它们也可用于有线以太网连接。

## 常规 Wi-Fi 安全程序

基于无线安全和配置选项的详细信息，以下是在部署 Wi-Fi 网络时应遵循的常规指南或程序。这些步骤按考虑和应用/安装的顺序排列。此外，此顺序并不意味着哪个步骤提供更多安全性。例如，使用 WPA2 是一项真正的安全功能，而禁用 SSID 广播则不是。以下是步骤：

1.  更改默认管理员密码。
2.  根据您的部署要求，决定是否禁用 SSID 广播。
3.  将 SSID 更改为唯一的名称。
4.  如果无线客户端池相对较小（通常少于 20 个）且静态，则启用 MAC 地址过滤。
5.  考虑使用静态 IP 地址，或配置带有预留的 DHCP（仅适用于小型部署）。
6.  开启支持的最高形式的身份验证和加密，目前为 WPA2，未来可能是 WPA3（一种正在开发中的新安全模式，截至 2018 年初：[https://www.networkworld.com/article/3247658/wi-fi/wi-fi-alliance-announces-wpa3-to-secure-modern-networks.html](https://www.networkworld.com/article/3247658/wi-fi/wi-fi-alliance-announces-wpa3-to-secure-modern-networks.html)）。如果您的设备上没有 WPA2 或更新/更强的解决方案，则需要获取新的无线设备。
7.  将无线视为远程访问，并使用 802.1X 管理访问。
8.  将无线视为外部访问，并使用防火墙将 WAP 与有线网络隔离。
9.  将无线视为攻击者的入口点，并使用入侵检测系统 (IDS) 监控所有 WAP 到有线网络的通信。
10. 要求无线客户端与 WAP 之间的所有传输均经过加密；换句话说，要求建立 VPN 链路。

## 无线攻击

无线通信是网络、连接、通信和数据交换技术领域快速扩张的领域。成千上万种协议、标准和技术可被标记为无线。这些包括手机、蓝牙、无绳电话和无线网络。随着无线技术的持续普及，您组织的安全必须超越锁定其本地网络。安全应是一种端到端的解决方案，解决所有形式、方法和技术的通信问题。

无线网络已成为企业和家庭网络的常态。为可靠访问和安全性而妥善管理无线网络并不总是一件简单的事。即使存在无线安全措施，无线攻击仍可能发生。针对网络的攻击种类日益增多，其中许多对有线和无线环境均有效。少数攻击专门针对无线网络。本节探讨各种无线安全问题。

### 战争驾驶

`战争驾驶` 是使用检测工具寻找无线网络信号的行为。通常，战争驾驶指某人寻找其未获授权访问的无线网络。从某种意义上说，战争驾驶是为可能恶意或至少未经授权的目的执行现场勘测。该名称源于遗留的攻击概念“战争拨号”，后者用于通过拨打某区号或前缀下的所有号码来发现活动的计算机调制解调器。

战争驾驶可使用专用手持探测器、具有 Wi-Fi 功能的 `个人电子设备 (PED) 或移动设备`，或装有无线网卡的笔记本电脑来执行。它可以使用操作系统的原生功能或使用专用扫描和检测工具来执行。
