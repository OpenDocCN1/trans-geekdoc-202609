

# 无线网络标准

| 标准 | 速度 | 频率 |
| :--- | :--- | :--- |
| 802.11g | 54 Mbps | 2.4 GHz |
| 802.11n | 200+ Mbps | 2.4 GHz 或 5 GHz |
| 802.11ac | 1 Gbps | 5 GHz |

在部署无线网络时，你应该部署配置为使用 `infrastructure mode`（基础架构模式）而非 `ad hoc mode`（自组网模式）的无线接入点。自组网模式意味着任意两个无线网络设备（包括两个无线网络接口卡 [NIC]）可以在没有中央控制机构的情况下进行通信。基础架构模式意味着需要一个无线接入点，系统上的无线 NIC 无法直接交互，并且会强制执行无线接入点针对无线网络访问的限制。

在基础架构模式的概念中，存在几种变体，包括独立模式、有线扩展模式、企业扩展模式和桥接模式。当无线接入点将无线客户端相互连接，但不连接到任何有线资源时，会出现 `stand-alone`（独立）模式基础架构。无线接入点专门充当无线集线器。当无线接入点充当连接点，将无线客户端链接到有线网络时，会出现 `wired extension`（有线扩展）模式基础架构。当使用多个无线接入点 (WAP) 将大型物理区域连接到同一个有线网络时，会出现 `enterprise extended`（企业扩展）模式基础架构。每个无线接入点将使用相同的 `extended service set identifier (ESSID)`（扩展服务集标识符），以便客户端可以在该区域漫游，同时保持网络连接，即使其无线 NIC 将关联从一个无线接入点更改为另一个。当无线连接用于链接两个有线网络时，会出现 `bridge`（桥接）模式基础架构。这通常使用专用无线网桥，并在有线网桥不方便时使用，例如在楼层之间或建筑物之间链接网络。

## 保护 SSID

无线网络被分配一个服务集标识符 (SSID)（BSSID 或 ESSID），以将一个无线网络与另一个区分开来。如果同一个无线网络涉及多个基站或无线接入点，则会定义一个扩展站集标识符 (ESSID)。SSID 类似于工作组的名称。如果无线客户端知道 SSID，他们就可以将其无线 NIC 配置为与相关的 WAP 通信。不过，了解 SSID 并不总能获得访问权限，因为 WAP 可以使用多种安全功能来阻止未经授权的访问。SSID 由供应商默认定义，由于这些默认 SSID 广为人知，标准安全实践要求在部署前将 SSID 更改为唯一的内容。

SSID 通过一种称为 `beacon frame`（信标帧）的特殊传输由 WAP 广播。这允许范围内的任何无线 NIC 看到无线网络，并使连接变得尽可能简单。然而，应禁用这种默认的 SSID 广播，以保持无线网络的隐蔽性。即便如此，攻击者仍可使用无线嗅探器发现 SSID，因为 SSID 仍必须用于无线客户端与 WAP 之间的传输中。因此，禁用 SSID 广播并非真正的安全机制。相反，应使用 WPA2 作为可靠的身份验证和加密解决方案，而不是试图隐藏无线网络的存在。

## 进行现场勘测

发现物理环境中可能存在未经授权无线访问区域的一种方法是执行现场勘测。`site survey`（现场勘测）是调查环境中部署的无线接入点的存在性、强度和覆盖范围的过程。此任务通常涉及携带便携式无线设备四处走动，记录无线信号强度，并将其绘制在建筑物的平面图或示意图上。

应进行现场勘测，以确保所有可能使用无线设备的位置都有足够的信号强度，同时将不应允许无线访问的位置（公共区域、跨楼层、其他房间内或建筑物外部）的无线信号最小化或消除。现场勘测对于评估现有无线网络部署、规划当前部署的扩展以及规划未来部署非常有用。

## 使用安全加密协议

IEEE 802.11 标准定义了无线客户端在正常网络通信跨无线链路发生之前，可用于向 WAP 进行身份验证的两种方法。这两种方法是 `open system authentication (OSA)`（开放系统认证）和 `shared key authentication (SKA)`（共享密钥认证）。OSA 意味着不需要真正的身份验证。只要客户端和 WAP 之间可以传输无线电信号，就允许通信。同样，使用 OSA 的无线网络通常以明文传输所有内容，因此不提供任何保密性或安全性。SKA 意味着在网络通信发生之前必须进行某种形式的身份验证。802.11 标准为 SKA 定义了一种可选技术，称为有线等效保密 (WEP)。对原始 802.11 标准的后续修正增加了 WPA、WPA2 和其他技术。

### WEP

`Wired Equivalent Privacy (WEP)`（有线等效保密）由 IEEE 802.11 标准定义。它旨在为无线网络提供与有线或缆线网络相同级别的安全性和加密。WEP 可防止针对无线传输的数据包嗅探和窃听。

WEP 的一个次要好处是，它可以配置为防止未经授权访问无线网络。WEP 使用预定义的共享密钥；然而，它不是典型的动态对称加密解决方案，而是共享密钥是静态的，并在所有无线接入点和设备接口之间共享。该密钥用于在通过无线链路传输之前加密数据包，从而提供机密性保护。哈希值用于验证接收到的数据包在传输过程中未被修改或损坏；因此 WEP 也提供完整性保护。知晓或持有该密钥不仅允许加密通信，还充当一种基本的身份验证形式，因为没有它，将禁止访问无线网络。

WEP 发布后不久即被破解。如今，破解 WEP 只需不到一分钟，因此它成为一种毫无价值的安全预防措施。幸运的是，有 WEP 的替代方案，即 WPA 和 WPA2。WPA 是对 WEP 的改进，因为它不使用相同的静态密钥来加密所有通信。相反，它与每个主机协商一组唯一的密钥。然而，使用单个密码短语来授权与基站的关联（即允许新客户端建立连接）。如果密码短语不够长，可能会被猜测。通常建议密码短语为 14 个字符或更长。

WEP 加密采用 Rivest Cipher 4 (RC4)，一种对称流密码（有关加密的更多一般信息，请参见第 6 章“密码学和对称密钥算法”以及第 7 章“PKI 和密码学应用”）。由于其设计缺陷和 RC4 的实现问题，WEP 在几个方面很薄弱，其中两个是使用静态公共密钥和 IV（初始化向量）的糟糕实现。由于这些弱点，WEP 破解可以在发现足够多的被不当使用的 IV 后揭示 WEP 密钥。这种攻击现在可以在 60 秒内完成。发现 WEP 密钥后，攻击者可以加入网络，然后监听所有其他无线客户端的通信。因此，不应使用 WEP。它不提供真正的保护，并可能导致错误的安全感。
