

# 理解德尔菲技术

德尔菲技术简单来说是一种匿名的反馈与响应过程，用于达成共识。这种共识使责任方有机会妥善评估风险并实施解决方案。

# 了解风险处理选项

降低风险，或风险缓解，是实施保障措施和对策。转移风险将风险所代表的损失成本转嫁给另一个实体或组织。购买保险是转移或分配风险的一种形式。接受风险意味着管理层已评估可能保障措施的成本/效益分析，并确定对策成本远超因风险导致的可能损失成本。这也意味着管理层同意在风险成真时承担后果和损失。

# 能够解释总风险、剩余风险和控制差距

总风险是指组织在未实施任何保障措施时将面临的风险量。计算总风险请使用以下公式：

```
威胁 * 脆弱性 * 资产价值 = 总风险
```

剩余风险是指管理层选择接受而非缓解的风险。总风险与剩余风险之间的差额即为控制差距，它是通过实施保障措施所降低的风险量。计算剩余风险请使用以下公式：

```
总风险 – 控制差距 = 剩余风险
```

# 理解控制类型

术语 `control` 是指一系列广泛的控制措施，它们执行诸如确保仅授权用户能够登录、防止未授权用户访问资源等任务。控制类型包括预防性、检测性、纠正性、威慑性、恢复性、指令性和补偿性。控制也可按其实施方式分类：管理类、逻辑类或物理类。

# 了解如何实施安全意识培训与教育

在实际培训开始前，必须使用户建立起对安全作为一个公认实体的意识。一旦完成这一点，便可开始培训，即教授员工执行其工作任务并遵守安全策略。所有新员工都需要一定程度的培训，以便他们能够遵守安全策略强制规定的所有标准、指南和程序。教育是一项更深入的工作，学员/用户学到的知识远超其执行工作任务所需。教育通常与追求认证或寻求晋升的用户相关联。

# 理解如何管理安全职能

要管理安全职能，组织必须实施适当且充分的安全治理。执行风险评估以驱动安全策略，是管理安全职能最清晰、最直接的例子。这也涉及预算、度量指标、资源、信息安全策略，以及评估安全计划的完整性和有效性。

# 了解风险管理框架的六个步骤

风险管理框架的六个步骤为：分类、选择、实施、评估、授权和监控。
