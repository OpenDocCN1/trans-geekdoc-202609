
### Vishing

虽然攻击者主要通过电子邮件发起网络钓鱼攻击，但他们也利用其他手段欺骗用户，例如即时通讯（IM）和 VoIP。

**Vishing** 是一种网络钓鱼变体，利用电话系统或 VoIP。常见的攻击方式是通过自动呼叫告知用户信用卡账户出现问题，诱导用户验证或确认信用卡号、有效期以及卡背面的安全码等信息。Vishing 攻击通常会伪造来电显示号码，以冒充合法的银行或金融机构。

#### 智能卡攻击

智能卡提供比密码更好的身份验证，尤其是当它们与另一个认证因素（如个人识别号 `PIN`）结合使用时。然而，智能卡也容易受到攻击。**侧信道攻击** 是一种被动的、非侵入式攻击，旨在观察设备的运行。一旦攻击成功，攻击者可以获取卡内的宝贵信息，例如加密密钥。

智能卡包含一个微处理器，但没有内部电源。相反，当用户将卡插入读卡器时，读卡器为卡提供电力。读卡器有一个电磁线圈，激发卡上的电子元件，从而为智能卡向读卡器传输数据提供足够的电力。

侧信道攻击分析发送给读卡器的信息。有时它们可以测量芯片的功耗，利用功耗监控攻击或差分功耗分析攻击来提取信息。在时序攻击中，它们可以监控处理时序，根据不同计算所需的时间获取信息。故障分析攻击试图制造故障（例如向卡提供过少的电力）以获取有价值的信息。

### 保护方法总结

以下列表总结了许多防范访问控制攻击的安全预防措施。但重要的是要认识到，这并不是针对所有类型攻击的综合防护清单。本书其他章节还将介绍有助于防止攻击的其他控制措施。

**控制对系统的物理访问。** 关于安全有一句老话：如果攻击者获得了对计算机的无限制物理访问权限，那么攻击者就拥有了这台计算机。如果攻击者能物理接触到认证服务器，他们可以在极短时间内窃取密码文件。一旦攻击者拥有密码文件，他们就可以离线破解密码。如果攻击者成功下载密码文件，应视所有密码均已泄露。

**控制对文件的电子访问。** 严格控制并监控对所有重要数据（包括包含密码的文件）的电子访问。最终用户和非账户管理员无需为日常工作任务访问密码数据库文件。安全专业人员应立即调查任何对密码数据库文件的未授权访问。

**制定强密码策略。** 密码策略通过程序强制使用强密码，并确保用户定期更换密码。攻击者需要更多时间才能使用多种字符类型破解更长的密码。给予足够的时间，攻击者可以在离线暴力破解攻击中发现任何密码，因此定期更换密码是维护安全所必需的。更安全或敏感的环境要求更强的密码，并要求用户更频繁地更换密码。许多组织为管理员账户等特权账户实施单独的密码策略，以确保它们拥有更强的密码，并且管理员比普通用户更频繁地更换密码。

**对密码进行哈希和加盐。** 使用 `bcrypt` 和 `PBKDF2` 等协议对密码进行加盐，并考虑使用外部加胡椒进一步保护密码。结合强密码的使用，加盐和加胡椒的密码极难通过彩虹表或其他方法破解。

**使用密码掩码。** 确保应用程序绝不在任何屏幕上以明文显示密码。相反，通过显示替代字符（如星号 `*`）来掩盖密码显示。这可以减少肩窥攻击，但用户应意识到攻击者可能通过观察用户在键盘上敲击按键来获知密码。

**部署多因素认证。** 部署多因素认证，例如使用生物识别或令牌设备。当组织使用多因素认证时，攻击者仅发现密码无法访问网络。许多在线服务（如 Google）现在提供多因素认证作为额外的保护措施。

**使用账户锁定控制。** 账户锁定控制有助于防止在线密码攻击。它们在输入错误密码达到预定义次数后锁定账户。账户锁定控制通常使用截断级别，忽略一些用户错误，但在达到阈值后采取行动。例如，通常允许用户最多输入五次错误密码才锁定账户。对于不支持账户锁定控制的系统和服务（如大多数文件传输协议 `FTP` 服务器），大量的日志记录结合入侵检测系统可以保护服务器。

**使用最后登录通知。** 许多系统显示一条消息，包含上次成功登录的时间、日期和位置（如计算机名称或 IP 地址）。如果用户注意此消息，可能会发现其他人是否登录过其账户。例如，如果用户上周五登录了账户，但最后登录通知显示有人在周六访问了该账户，则表明存在问题。怀疑他人登录自己账户的用户可以更改密码或向系统管理员报告问题。如果发生在组织账户上，用户应遵循组织的安全事件报告程序进行报告。

**教育用户了解安全。** 经过适当培训的用户对安全有更好的理解，也更懂得使用更强密码的好处。告知用户切勿共享或记录他们的密码。管理员可能会为最高敏感度的账户（如管理员或 `root` 账户）记录长而复杂的密码，并将这些密码存放在保险库或保险箱中。向用户提供关于如何创建强密码（如使用密码短语）以及如何防止肩窥的提示。此外，让用户了解对所有在线账户（如银行账户和游戏账户）使用相同密码的危险。当用户对所有这些账户使用相同密码时，游戏系统遭受的成功攻击可能让攻击者访问用户的银行账户。用户还应了解常见的社会工程学战术。

## 总结

本章涵盖了许多与访问控制模型相关的概念。权限是指授予对象的访问权，决定了用户（主体）可以对对象执行什么操作。权利主要是指对对象执行操作的能力。特权包含权利和权限。隐式拒绝确保除非已明确授予主体访问权限，否则拒绝对对象的访问。

访问控制矩阵是一个以对象为中心的表，包含对象、主体和分配给主体的特权。表中的每一行代表单个对象的 `ACL`。`ACL` 以对象为中心，标识授予主体针对特定对象的访问权限。能力表以主体为中心，标识主体可以访问的对象。
