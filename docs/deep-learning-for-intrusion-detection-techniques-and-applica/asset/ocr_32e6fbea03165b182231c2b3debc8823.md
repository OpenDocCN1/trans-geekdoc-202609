One of the most widely used optimizers for deep learning tasks [45].

$m^{(t)} = \beta_1 m^{(t-1)} + (1 - \beta_1) \frac{\partial E}{\partial w_{ij}}$ 

$v^{(t)} = \beta_2 v^{(t-1)} + (1 - \beta_2) \left(\frac{\partial E}{\partial w_{ij}}\right)^2$

$\hat{m}^{(t)} = \frac{m^{(t)}}{1 - \beta_1^t}, \quad \hat{v}^{(t)} = \frac{v^{(t)}}{1 - \beta_2^t}$

$w_{ij}^{(t+1)} = w_{ij}^{(t)} - \frac{\eta}{\sqrt{\hat{v}^{(t)}} + \epsilon} \hat{m}^{(t)}$

where $\beta_1 = 0.9$ and $\beta_2 = 0.999$ are decay rates for momentum and variance respectively.

# 3.3.5 Regularization Techniques in Neural Networks

To prevent overfitting, deep learning models use regularization techniques that penalize overly complex models.

# 3.3.5.1 L1 and L2 Regularization

+   1) **L1 Regularization (Lasso)**: Adds an absolute weight penalty to the loss function:
+   
+   $$E_{reg} = E + \lambda \sum_{i=1}^{n} |w_i|$$
+   
+   Encourages sparsity by driving some weights to zero, making it useful for feature selection [46].

+   2) **L2 Regularization (Ridge)**: Adds a squared weight penalty:
+   
+   $$E_{reg} = E + \lambda \sum_{i=1}^{n} w_i^2$$
+   
+   Prevents large weight values, improving generalization in deep networks [47].

# 3.3.6 Dropout: Reducing Overfitting

Dropout is another regularization method that randomly disables a fraction of neurons during training. Given a dropout rate, $p$, a neuron is retained with probability $1 - p$:

$$y_i = \frac{x_i}{1 - p}, \quad \text{where } x_i \text{ is dropped with probability } p$$

Dropout forces the network to learn redundant representations, improving robustness [48].
