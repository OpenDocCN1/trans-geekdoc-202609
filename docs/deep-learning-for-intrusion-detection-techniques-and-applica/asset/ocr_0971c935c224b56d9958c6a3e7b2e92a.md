# 3.3.4.1 Advanced Optimization Techniques

# *Momentum-Based Optimization*

Momentum-based optimization accelerates gradient descent by incorporating an exponentially decaying moving average of past gradients. The momentum term helps the optimizer navigate along steep gradients more effectively. The update rule is:

$v^{(t+1)} = \beta v^{(t)} + (1 - \beta) \frac{\partial E}{\partial w_{ij}}$  
$w_{ij}^{(t+1)} = w_{ij}^{(t)} - \eta v^{(t+1)}$

where:

+   - $v^{(t)}$ is the exponentially averaged gradient at iteration $t$.
+   - $\beta$ is the momentum coefficient (commonly set to 0.9).

Momentum helps prevent oscillations in the optimization path and speeds up convergence, particularly in deep networks [23].

# *Adaptive Learning Rate Methods*

To further improve convergence, adaptive learning rate algorithms adjust $\eta$ dynamically based on past gradients. Key methods include as follows:

# 1) Adagrad (Adaptive Gradient Algorithm):

+   - Modifies the learning rate for each parameter based on historical gradients.
+   - Works well for sparse data but suffers from diminishing learning rates over time [43].

$w_{ij}^{(t+1)} = w_{ij}^{(t)} - \frac{\eta}{\sqrt{G_{ij}^{(t)} + \epsilon}} \frac{\partial E}{\partial w_{ij}}$

where $G_{ij}^{(t)}$ is the sum of squared gradients up to iteration $t$.

# 2) RMSprop (Root Mean Square Propagation):

+   - Introduces an exponentially decaying average of squared gradients to mitigate Adagrad's vanishing learning rate issue.
+   - Well-suited for training RNNs [44].

$G_{ij}^{(t)} = \beta G_{ij}^{(t-1)} + (1 - \beta) \left(\frac{\partial E}{\partial w_{ij}}\right)^2$  
$w_{ij}^{(t+1)} = w_{ij}^{(t)} - \frac{\eta}{\sqrt{G_{ij}^{(t)} + \epsilon}} \frac{\partial E}{\partial w_{ij}}$

# 3) Adam (Adaptive Moment Estimation):

+   - Combines the benefits of Adagrad and RMSprop by computing both first-moment and second-moment estimates of gradients.
