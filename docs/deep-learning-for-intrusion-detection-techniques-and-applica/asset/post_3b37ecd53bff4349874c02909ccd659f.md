- **Resource Constraints:** Nodes in wireless networks have restricted processing power because of battery power and resource limitations. Execution of computationally heavy IDS algorithms consumes resources rapidly, reducing the life span of the nodes as well as the overall network performance.

### 10.3.2 Advanced Threats

- **Novel Attack Approaches:** Attackers are continually creating new and sophisticated methods to exploit flaws in these networks. IDSs must be adaptable and evolve in order to detect these emerging threats. Wireless networks face several dangers, such as routing assaults (e.g., blackhole, wormhole, Sybil), DoS attacks, and deception. Because of the continually developing nature of these threats, IDSs must be adaptive and capable of recognizing novel attack patterns.
- **Unknown Assaults:** Traditional IDSs might not be able to identify unknown or zero-day assaults, necessitating the use of more sophisticated strategies like anomaly detection, hybrid detection approaches.

### 10.3.3 Flexibility and Distributed Processing

- **Decentralized Architecture:** Wireless networks decentralized architecture necessitates distributed or cooperative IDSs. This adds complexity since nodes must work together to detect intrusions in real time, and malevolent nodes can use this structure to disrupt detection measures. However, coordinating and synchronizing several IDS nodes can also be challenging when it comes to handling larger networks with higher mobility.
- **Wide Network Sizes:** MANETs and WSNs might include hundreds or even thousands of nodes, making it difficult to create a centralized IDS capable of quickly tracking and evaluating traffic from all nodes.

### 10.3.4 Privacy Concerns

- **Secure Transmission:** A proactive IDS requires nodes to share data for analysis, ensuring safe transmission. However, establishing secure communication between possibly unreliable nodes is difficult, because attackers can use various methods to inject bogus data or disrupt IDS operations.
- **Data Gathering and Analysis:** IDSs may be required to gather and analyze sensitive data about network traffic and node behavior, which raises privacy concerns for users.
- **False Positives and Negatives:** The dynamic nature of wireless networks and open characteristics can lead to high false positives and negatives, making it difficult to distinguish between legitimate and malicious conduct. As a result, IDSs often experience false positives (legitimate activity incorrectly identified as malicious activity) and false negatives (malicious activity not detected). This can consequently cause privacy breaches and network interruptions.

### 10.3.5 Wireless Medium Weaknesses

- **Eavesdropping:** Because wireless signals are broadcast, they can be thwarted by any device within range. This allows attackers easy access to private information such as user data, passwords, or control signals.
- **Data Theft:** Attackers employ security flaws to gain access to sensitive information, and use it for nefarious purposes like fraud, identity theft, or intellectual property theft. Attackers could gain unauthorized access to the network by impersonating identities or simulating legitimate nodes and processes.
- **Denial of Service (DoS) Attacks:** This attack uses jamming to disrupt wireless signals to restrict communication. This can block legitimate nodes from sending or receiving data, resulting in DoS to the authorized party.
- **Network Disruption:** Other device or environmental interferences can affect signal quality, which leads to packet loss, increased latency, and overall network downtime. This can diminish the effectiveness of the IDS by making it challenging to monitor and analyze network traffic efficiently.

## 10.4 Intrusion Detection Systems

Wireless networks require effective defense against malicious behavior, secure routing, and the overcoming of limitations of cryptographic systems. IDSs [17] can be used as a second line of defense to detect malicious traffic and misbehaving nodes in wireless environments [18]. To handle all these issues, network security aims to prevent unwanted attacks and data breaches against the network and its resources to preserve integrity, enhance availability, maintain authenticity, and offer auditability of data to the user. Having a powerful IDS in place is the key to ensuring reliable, secure access to the network and protection against vulnerabilities [23]. An IDS is a system safety technique developed for detecting accessible attacks on the target system [4]. It can be defined as a software application that analyzes system traffic for malicious activity and breaching of rules. A security information and event management (SIEM) system usually communicates any illegal activity to the network officials and raises an alert using an alarm when such activity is detected. It can be classified into two types based on how they are deployed; network-based (NIDSs) and host-based (HIDSs). To detect malignant traffic on a network, NIDS normally comprises hardware (sensors) coupled with a network interface card (NIC) and is placed within the network. It operates in a promiscuous mode to analyze incoming network traffic from multiple sources, matches that traffic to a database of known attacks in the system, and sends an alert to the NIDS management server if such activity is discovered [1]. HIDS runs on a host system on which it is installed and detects intrusions and policy violations by monitoring the system's incoming and outgoing traffic. It detects suspicious or mischievous behavior and reports it to the network manager by comparing system files with the existing database. Three commonly used approaches for intrusion detection are HIDS (host-based), AIDS (anomaly-based), and SIDS (signature-based) [24]. In order to find possible threats, signature-based IDS analyzes a certain set of well-known patterns called sequences. By default, this method maintains a database of attack signatures/rules from prior known assaults on the system, which is used to check incoming traffic against stored signatures. Alerts are issued when signatures match. The SIDS can easily identify known assaults but is unable to identify new attacks since there is no accessible sequence. For identifying unknown malware threats, an AIDS builds a reliable activity model using ML methods. By combining two IDS methodologies (AIDS and HIDS), hybrid-based IDS (H-IDS) is produced. To prevent attacks on the system, it recognizes as many threats as possible and tries to evade every tactic employed by them to protect user data.

In wireless networks, some other IDSs are also proposed such as distributed and cooperative IDS, DL-based intrusion detection systems. In distributed and cooperative IDS, each node has an IDS agent that detects intrusions locally and interacts with nearby nodes for global detection when indeterminate evidence warrants a more comprehensive search. When an intrusion is detected, an IDS agent may provide a local or global response. Each node runs an IDS agent to detect and respond to intrusions. An IDS agent detects and collects local data to identify network attacks and respond independently. Deep learning algorithms have gained popularity and are now used for a variety of tasks. Research indicates that they outperform previous methods. The study aims to create a flexible and effective IDS using deep neural networks (DNNs) to identify and categorize unanticipated attacks. As network behavior and assaults evolve, it’s important to examine both static and dynamic datasets generated over time.

Deep learning uses numerous networks, including CNNs, DBNs, RBMs, and RNNs, each with unique capabilities and qualities. These networks can perform learning in unsupervised, semi-supervised, or supervised settings. Additionally, hierarchical layers are used to extract high-level features from raw input data, eliminating the need for manual features.
