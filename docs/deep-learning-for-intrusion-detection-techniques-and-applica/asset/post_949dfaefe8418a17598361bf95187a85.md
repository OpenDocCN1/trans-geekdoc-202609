### 10.1 Introduction

Wireless networks have already become an integral part of modern communication systems, providing seamless connections between various locations. Wireless networks transmit data over radio frequency waves instead of through physical wires, as is done in wired networks. While that distinction creates tremendous freedom, it also creates unique security challenges, requiring imaginative solutions, especially as cyber threats increasingly evolve.

Focusing on security applications, deep learning (DL) techniques with remarkable quality of self-learning are beneficial to develop the intrusion detection models that are used to discover malicious nodes or network anomalies [9]. These DL models result in low false rates and high accuracy as compared to traditional machine learning techniques. Similarly, recurrent neural networks (RNNs) and long short-term memory (LSTM) networks come under the category of supervised sequence learning methods and are the most popular methods used for detecting malware activities with self-learning techniques. These analyze temporal data to detect abnormalities, such as routing attacks (e.g., black hole, grey hole, or wormhole) in MANETs. Artificial neural networks (ANNs), deep neural networks (DNNs), convolutional neural networks (CNNs), and autoencoders can employ supervised instance learning with a feed-forward neural network. ANNs are emphatic in monitoring network traffic and detecting imminent attacks. A fully connected network model with more than three hidden layers is considered a DNN. DNNs have been used to detect data injection or jamming assaults in sensor data, extending machine learning models such as support vector machines (SVMs). CNN or autoencoder is applied to sensor data to detect intrusion patterns, such as unauthorized access or node capture attacks by adjusting the model weights and repeating the task to improve the accuracy using backpropagation in WSNs. Deep learning also supports transfer learning methods used to generate generic problem statements and reuse them with other models. Reinforcement learning models improve the adaptability of routing protocols by learning through dynamic changes and evolving threats in the network. Reinforcement learning such as Deep Q-Learning, enables the network to dynamically update its security procedures in response to new threats and topology shifts in both MANETs and WSNs. It also optimizes key distribution in MANETs and WSNs, lowering overhead and increasing resistance to eavesdropping. Autoencoders (AE), deep belief networks (DBNs), restricted Boltzmann machines (RBMs), and generative adversarial networks (GANs) are generative DL techniques that follow semi-supervised instance learning used for conditional/discriminate models, and the combination of both is considered an ensemble technique that analyzes traffic data to detect signature-based and anomaly-based threats. Generative adversarial networks (GANs) are employed to mimic attack patterns and enhance detection methods by recognizing compromised paths and node interdependencies, and algorithms like graph neural networks (GNNs) facilitate secure data exchange in MANETs.

### 10.1.1 Mobile Ad Hoc Networks

Mobile ad hoc networks (MANETs) are an independently organizing group of mobile nodes that exchange information with one another wirelessly without any fixed infrastructure such as routers or access points. MANETs are decentralized in the context that every node in the network is both a node and a router, relaying information to other nodes. MANETs are extremely dynamic, with nodes capable of moving, joining, or departing the network at any time [4]. This makes MANETs appropriate for regions where traditional network configurations are not feasible. Community users such as the military, researchers, businesses, students, and emergency services are the primary users of these networks. The key feature of MANETs is their ad hoc nature. MANET devices communicate directly within their respective transmission ranges. For long-distance communication, packets are routed through intermediate nodes, resulting in a multi-hop network. Every node has an IP address, and all nodes use the Internet Protocol.

- 1) **Nodes:** Nodes (mobile devices) play the twin functions of hosts and routers. Every node can act as a source of data and act as a middleman by forwarding packets to other nodes. These gadgets, which include laptops, cell phones, tablets, and other wirelessly enabled gadgets, are usually portable. Because nodes are mobile, the topology of the network is dynamic and subject to quick changes, necessitating the use of adaptive routing techniques.

- 2) **Links:** Wireless communications, which offer flexibility and do away with the need for infrastructure like routers or access points, are used by nodes in MANETs to interact. Because of node mobility, interference, and environmental conditions, these interconnections are naturally unstable and frequently break and rejoin. Commonly used wireless communication technologies include Bluetooth, Wi-Fi, and other short-range protocols.

- 3) **Protocols:** Routing protocols are crucial for the efficient operation of a MANET because they establish the optimum path for data transmission between nodes. These protocols respond to changes in the network topology. They are generically characterized into three categories as follows:
  - a) **Proactive Routing Protocols:** Always keep routing tables up to date (for example, destination-sequenced distance vector).
  - b) **Reactive routing Protocols:** Create routes only when data has to be transferred (e.g., ad hoc on-demand distance vector).
  - c) **Hybrid Routing Protocol:** Combine aspects of both proactive and reactive techniques (e.g., zone routing protocol).
  - d) **Medium Access Control (MAC) Protocols:** The MAC layer in MANETs controls how nodes use the shared wireless channel to reduce collisions and maximize data transmission. Common approaches include carrier sense multiple access (CSMA) and versions of time division multiple access (TDMA). Efficient MAC protocols are critical for reducing energy usage while improving performance.

The working mechanism of MANETs is based on adaptive communication and dynamic topology management operations. Firstly, the establishment of a network takes place where a node first checks to see if the destination is within its direct transmission range before deciding to transfer data. Otherwise, a multi-hop communication pathway is formed in which the source node depends on intermediary nodes to transmit the message using wireless signals. Secondly, the routing protocols make sure that the best route is selected by taking into account variables like network congestion, energy consumption, and distance. Data transmission takes place when routing tables or on-demand path discovery methods are utilized to decide how data packets should be forwarded from one node to another. Mobility and dynamic adjustments are carried out because MANETs are decentralized where nodes must work together to guarantee data delivery. Regular changes in the node position, result in changes in network topology where routing protocols dynamically recalculate routes when the topology of a network changes. To guarantee effective operation, the network manages problems including power consumption, bandwidth optimization, and collision avoidance.

### 10.1.2 Wireless Sensor Networks (WSNs)

A WSN is a decentralized communication system that enables users to establish and operate their own networks without relying on fixed infrastructure or a central hub. It is one of the most intriguing advancements in wireless communication technology [15]. A WSN is made up of autonomous, spatially dispersed sensor nodes that are intended to monitor environmental or physical parameters like motion, vibration, temperature, humidity, and pollution. The system utilizes a network of dynamic nodes running on different radio frequencies to enable sensing, observing, and evaluating operations, where communication among the nodes is enabled. The sensors work together to gather data and send it wirelessly to a central base station to process and analyze it. WSNs have their applications in various fields like smart urban applications (e.g., traffic management in smart cities), industry automation (e.g., predictive maintenance through the monitoring of machinery), environmental monitoring (e.g., animal tracking in forests), military surveillance, agriculture, and many more. WSNs are cheaper and easier to deploy compared to traditional wired networks as they do not need advanced infrastructure. They also have limitations like low energy supplies, processing constraints, and security vulnerabilities. Despite these limitations, ongoing innovation in low-power sensors, wireless communication, and microelectronics has significantly improved WSNs’ performance and functionality, making them a central part of the Internet of Things (IoT) revolution [10]. The main parts of a WSN are key to its good and stable work. Each sensor node has four main parts: the sensing part, the processing part, the communication part, and the power part [11] as shown in Figure 10.2. The sensing part, which has an analog-to-digital converter (ADC) and sensors, measures things about the world and turns them into a digital form. The processing part, run by a microcontroller or microprocessor, manages the node and handles local data. The communication part is used for sending data wirelessly between nodes and a base station using good and stable methods.
