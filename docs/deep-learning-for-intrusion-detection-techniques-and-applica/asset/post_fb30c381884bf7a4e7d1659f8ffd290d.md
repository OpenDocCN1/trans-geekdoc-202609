With reference to network intrusion detection systems (NIDSs), DL provides significant benefits over conventional ML techniques. Initially, DL models may acquire intricate features from unprocessed data on their own, doing away with the necessity for human feature engineering. Because NIDS applications frequently work with high-dimensional data, this feature is particularly helpful. Second, DL models are more resilient to data noise and outliers, which is important for NIDSs that regularly deal with imperfect and noisy data. Last but not least, DL makes it possible to create innovative NIDS strategies like hybrid and anomaly detection.

## 4.4 Deep Learning Algorithms

DL architectures are revolutionizing NIDSs by tackling limitations inherent in traditional methods. These powerful models, driven by ANNs, automatically extract intricate features from raw network traffic, capturing complex relationships and nuances beyond the reach of statistical or rule-based approaches. This enables DL to detect not just known attack signatures, but also subtle anomalies and even zero-day threats before they wreak havoc. Therefore, several recent studies have explored innovative approaches for network intrusion detection using DL techniques.

DL models applied in IDSs include DNNs, deep belief networks (DBNs), convolutional neural networks (CNNs), recurrent neural networks (RNNs), long short-term memory (LSTM) networks, and AEs.

### 4.4.1 Deep Neural Networks (DNNs)

DNNs are a class of ANNs with multiple layers of neurons, enabling them to learn complex nonlinear relationships in data. In network anomaly detection, DNNs are effective at extracting and analyzing features from raw network traffic to identify irregularities. Their ability to model intricate patterns makes them well-suited for detecting subtle anomalies that simpler models might overlook. For example, Amarasinghe et al. introduced a supervised learning IDS utilizing DNNs, which increases user trust by producing feedback on the decision-making produced by IDSs [22]. This plan produces online feedback throughout the deployment phase and offline feedback following the training phase. The Network Security Laboratory – Knowledge Discovery in Databases (NSL-KDD) is used to assess this strategy in order to detect two distributed denial of service (DDoS) and probe attacks with varying depths. The authors demonstrated how the user can add an additional layer of evaluation using their generated input.

However, when establishing online feedback, the authors did not take into account how quickly things happen; instead, they should use approaches that are easy for people to understand. An IDS technique utilizing a DNN was proposed in the work in [23] and it was trained using packet traces that were exchanged between electronic control units in the vehicular network. In order to identify both legitimate and malicious packets, they looked for appropriate properties that might be derived from network data. This IDS method tracks packet exchange in automotive networks and trains the features offline to provide a high detection ratio and quick reaction to security threats. They also assessed the amount of time needed for the testing and training phases.

### 4.4.2 Deep Belief Networks

DBNs are probabilistic generative models that have contributed significantly to advancements in DL. DBNs are constructed by stacking Restricted Boltzmann Machines (RBMs), where each pair of adjacent layers forms an RBM. The hidden layer of one RBM serves as the visible layer for the next RBM, while the top two layers are undirected. Lower layers exhibit either generative (top-down) or recognition (bottom-up) directed connections. DBN training consists of two main stages: pretraining and fine-tuning. During pretraining, RBMs are trained sequentially in a bottom-up manner using an unsupervised learning algorithm, often the contrastive divergence (CD) algorithm. In the fine-tuning stage, network parameters are refined to enhance the model’s generative or discriminative performance using the up-down algorithm (a variant of the wake–sleep algorithm) or the backpropagation algorithm. The DBN network structure is illustrated in Figure 4.2.

To detect intrusions, a number of researchers employed the DBN technique. For example, DBN was utilized by Kang and Kang [23] to detect intrusions in a vehicle network.

Several researchers have shown that DBN-based unsupervised pretraining models could increase the accuracy of intrusion detection. This model's drawback is that its centralized methodology may make it less applicable in fog networks. Zhang et al. presented an IDS approach based on the DBN and an improved genetic algorithm (GA), which intends to find an optimal network structure for DBN to classify security attacks. It reduces the network structure complexity and enhances the accuracy of classification. Gao et al. presented an IDS model based on the DBN in [24], which blends RBM and a backpropagation network. The DL model that this technique suggests can complete the classification challenge and learn high-dimensional representations. Additionally, this method tunes the DBN to learn high-dimensional data and make classification easier by using the unsupervised greedy learning algorithm for pretraining. The ability of the DBN to perform intrusion detection on the NSL-KDD following training was examined by the intrusion detection method put out in [25]. The authors assessed their system's testing and training durations. It showed that, even in the face of nonlinear and partial data, it could identify security attacks and categorize them into five kinds. Additionally, [26] offered a hybrid IDS that generated and classified security threat signatures using DL approaches.

This plan makes use of an extensive stack of denoising AEs for DBN implementation, which may provide malware signatures and analyze raw input data for DNN training. Their method uses a dataset of major malware attacks and DBN-generated signatures to attain a high degree of accuracy.

### 4.4.3 Autoencoders

AEs, also referred to as auto-associators, are a type of neural network designed for efficient encoding and learning representations in an unsupervised manner. They are commonly used for dimensionality reduction. The primary objective of an AE is to learn a representation from which input data can be accurately reconstructed. During training, AEs aim to transform input vectors into a low-dimensional representation (encoding process) while minimizing the reconstruction error. The encoding process involves extracting relevant features from input data while filtering out irrelevant information. An AE first transforms the input vector into a hidden representation, which serves as the encoded representation, using a weight matrix. The decoding process then reconstructs the input data from the hidden representation using a separate weight matrix. The overall architecture of an AE is depicted in Figure 4.3.

Single-layer AEs are often limited in their ability to extract useful features. To improve performance, deep AEs were introduced. A deep AE functions as a dimensionality reduction technique when the number of neurons in higher layers of the encoder decreases progressively.

Several researchers have employed AEs for intrusion detection. For example, [27] developed a DL-based approach for creating a flexible and efficient NIDS using the NSL-KDD benchmark dataset. Their method applied a self-taught learning (STL) scheme based on an unsupervised sparse AE for training. The extracted features were subsequently used for classifying labeled test data as either normal or attack instances. N-fold cross-validation was used for performance evaluation, with metrics including accuracy, precision, recall, and F-measure. Comparisons with the Softmax Regression (SMR) classifier, applied directly to the dataset without feature learning, showed that the STL-based approach outperformed previous models.

AEs have also been used for anomaly detection. Sakurada et al. [28] applied nonlinear feature reduction via AEs to train normal network profiles. Their study found that AEs successfully learned normal states and responded differently when given anomalous input. Similarly, [29] leveraged autoencoders for feature extraction and DBNs as classifiers to detect malicious code, using the KDDCUP’99 benchmark dataset. Their results demonstrated that the hybrid approach was more effective and accurate in detection time and classification performance compared to using a single DBN. While DL networks have proven highly beneficial for cyberattack detection, they require up-to-date datasets, which presents a significant challenge in research.
