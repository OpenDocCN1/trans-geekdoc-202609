+   - **Poisoning Attacks:** Adversaries inject malicious samples into IDS training datasets, corrupting the learning process and reducing model accuracy.
+   - **Adversarial Example Crafting:** Attackers use algorithms (e.g., the fast gradient sign method [FGSM] and the Carlini & Wagner [C&W] attack) to generate malicious traffic patterns that evade detection.
+   - **Traffic Obfuscation:** Attackers modify payloads, headers, and packet sequences to mimic legitimate traffic and avoid IDS detection.

# 11.6.1.2 Defensive Measures: Adversarial Training and Robust IDS Models

To counter adversarial attacks, IDS models need to be hardened using defensive mechanisms, such as the following:

+   - **Adversarial Training:** Enhancing IDS robustness by training on adversarially generated network traffic samples.
+   - **Defensive Distillation:** Smoothing the model's decision boundary to reduce susceptibility to adversarial perturbations.
+   - **GANs for IDS Defense:** Using GANs to simulate sophisticated attacks and train IDS models to recognize them.
+   - **Robust Feature Selection:** Identifying network traffic features that are less sensitive to adversarial perturbations.
+   - Developing an adversarial-resilient IDS remains an open research challenge, requiring continuous improvements in AI security.

# 11.6.2 Computational Overhead and Energy Efficiency

DL models require significant computational resources, making it challenging to deploy IDSs on resource-constrained devices such as IoT nodes and edge servers.

# 11.6.2.1 Issues in Deploying Deep Learning Models on Resource-Constrained Devices

+   - **High Memory and Processing Requirements:** Many IDS models require GPUs or TPUs for real-time processing, making deployment on IoT or embedded systems impractical [35].
+   - **Battery and Energy Constraints:** Wireless devices have limited power, making continuous DL-based IDS monitoring infeasible.
+   - **Network Bandwidth Limitations:** Processing high volumes of network traffic in real time is computationally expensive and can introduce latency issues.
