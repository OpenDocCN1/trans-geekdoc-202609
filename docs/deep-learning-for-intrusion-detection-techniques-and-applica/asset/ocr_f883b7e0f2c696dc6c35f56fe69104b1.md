# 4.4.3 Autoencoders

AEs, also referred to as auto-associators, are a type of neural network designed for efficient encoding and learning representations in an unsupervised manner. They are commonly used for dimensionality reduction. The primary objective of an AE is to learn a representation from which input data can be accurately reconstructed. During training, AEs aim to transform input vectors into a low-dimensional representation (encoding process) while minimizing the reconstruction error. The encoding process involves extracting relevant features from input data while filtering out irrelevant information. An AE first transforms the input vector into a hidden representation, which serves as the encoded representation, using a weight matrix. The decoding process then reconstructs the input data from the hidden representation using a separate weight matrix. The overall architecture of an AE is depicted in Figure 4.3.

Single-layer AEs are often limited in their ability to extract useful features. To improve performance, deep AEs were introduced. A deep AE functions as a dimensionality reduction technique when the number of neurons in higher layers of the encoder decreases progressively.
