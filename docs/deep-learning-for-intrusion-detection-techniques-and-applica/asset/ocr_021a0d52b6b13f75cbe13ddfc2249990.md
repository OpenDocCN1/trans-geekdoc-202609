# Common Algorithms:

+   - **Decision Trees:**
+     - Uses a tree-like structure to make decisions based on feature thresholds.
+     - Advantages: Easy to interpret, fast to train, and effective for small to medium-sized datasets.
+     - Applications: Distinguishing between normal and malicious traffic patterns.
+   - **Support Vector Machines (SVMs):**
+     - Identifies a hyperplane that best separates data points of different classes in a high-dimensional space.
+     - Advantages: Works well with limited data and high-dimensional feature spaces.
+     - Applications: Classifying network traffic into normal and attack categories.
+   - **Neural Networks:**
+     - Mimic the structure of the human brain to learn complex patterns in data.
+     - Advantages: Effective for large-scale, high-dimensional data; can model non-linear relationships.
+     - Applications: Classifying sophisticated attacks like polymorphic malware.

# 2.3.3.1 Clustering Algorithms

Clustering algorithms are unsupervised methods used to group similar data points and identify outliers. These are particularly useful when labeled data is scarce.

# Common Algorithms:

+   - **K-means:**
+     - Groups data into K clusters based on feature similarity.
+     - Advantages: Simple and efficient for large datasets.
+     - Applications: Grouping network flows to detect unusual clusters that may signify attacks.
