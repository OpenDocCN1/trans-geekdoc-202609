+   2) **Links:** Wireless communications, which offer flexibility and do away with the need for infrastructure like routers or access points, are used by nodes in MANETs to interact. Because of node mobility, interference, and environmental conditions, these interconnections are naturally unstable and frequently break and rejoin. Commonly used wireless communication technologies include Bluetooth, Wi-Fi, and other short-range protocols.
+   
+   3) **Protocols:** Routing protocols are crucial for the efficient operation of a MANET because they establish the optimum path for data transmission between nodes. These protocols respond to changes in the network topology. They are generically characterized into three categories as follows:
+      a) **Proactive Routing Protocols:** Always keep routing tables up to date (for example, destination-sequenced distance vector).
+      b) **Reactive routing Protocols:** Create routes only when data has to be transferred (e.g., ad hoc on-demand distance vector).
+      c) **Hybrid Routing Protocol:** Combine aspects of both proactive and reactive techniques (e.g., zone routing protocol).
+      d) **Medium Access Control (MAC) Protocols:** The MAC layer in MANETs controls how nodes use the shared wireless channel to reduce collisions and maximize data transmission. Common approaches include carrier sense multiple access (CSMA) and versions of time division multiple (TDMA). Efficient MAC protocols are critical for reducing energy usage while improving performance.

The working mechanism of MANETs is based on adaptive communication and dynamic topology management operations. Firstly, the establishment of a network takes place where a node first checks to see if the destination is within its direct transmission range before deciding to transfer data. Otherwise, a multi-hop communication pathway is formed in which the source node depends on intermediary nodes to transmit the message using wireless signals. Secondly, the routing protocols make sure that the best route is selected by taking into account variables like network congestion, energy consumption, and distance. Data transmission
