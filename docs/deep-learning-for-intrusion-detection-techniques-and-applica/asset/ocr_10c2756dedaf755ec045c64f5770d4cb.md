# 10.1.1 Mobile Ad Hoc Networks

Mobile ad hoc networks (MANETs) are an independently organizing group of mobile nodes that exchange information with one another wirelessly without any fixed infrastructure such as routers or access points. MANETs are decentralized in the context that every node in the network is both a node and a router, relaying information to other nodes. MANETs are extremely dynamic, with nodes capable of moving, joining, or departing the network at any time [4]. This makes MANETs appropriate for regions where traditional network configurations are not feasible. Community users such as the military, researchers, businesses, students, and emergency services are the primary users of these networks. The key feature of MANETs is their ad hoc nature. MANET devices communicate directly within their respective transmission ranges. For long-distance communication, packets are routed through intermediate nodes, resulting in a multi-hop network. Every node has an IP address, and all nodes use the Internet Protocol.
