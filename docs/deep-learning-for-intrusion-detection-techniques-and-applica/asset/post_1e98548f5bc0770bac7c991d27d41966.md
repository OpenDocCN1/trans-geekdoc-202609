
- Maps inputs to a range between 0 and 1.
- Frequently used in the output layer for binary classification tasks.
- However, it suffers from vanishing gradients in deep networks [16].

## 3) Hyperbolic Tangent (Tanh):
$f(z)=\frac{e^z-e^{-z}}{e^z+e^{-z}}$

- Similar to the sigmoid but maps inputs between $[-1, 1]$.
- Often used in RNNs for sequence modeling [32].

### Example 3.1 Calculation
Consider a neuron with three inputs:

$x_1=2,\quad x_2=3,\quad x_3=1$

and corresponding weights:

$w_1=0.5,\quad w_2=-0.2,\quad w_3=0.8$

with a bias term:

$b=1$

Using the ReLU activation function, the output is computed as:

$z=(0.5\times2)+(-0.2\times3)+(0.8\times1)+1$

$z=1.0-0.6+0.8+1=2.2$

$y=\operatorname{ReLU}(2.2)=\max(0,2.2)=2.2$

This demonstrates how activation functions process weighted inputs and introduce nonlinearity in neural networks [33].

## 3.3.3 Training Deep Learning Models Using Backpropagation and Weight Optimization
Training deep learning models involves adjusting their parameters to minimize error. Backpropagation is the primary algorithm used to update network weights based on the error between predicted and actual outputs. The weight update formula is:

$w_{ij}=w_{ij}-\eta\frac{\partial E}{\partial w_{ij}}$

where:

- $w_{ij}$ is the weight connecting neuron $i$ in one layer to neuron $j$ in the next.
- $\eta$ (learning rate) controls the magnitude of weight updates.
- *E* is the error function that quantifies the difference between predicted and actual outputs.
- *∂E/∂w_ij* is the gradient, determining how much the weight should be adjusted to reduce the error [34].

### 3.3.3.1 Error Functions in Neural Networks
Error functions guide the backpropagation process by quantifying how far predictions deviate from actual values. Common error functions include as follows:

### Mean Squared Error (MSE):
$$E = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

- Used for regression tasks.
- Measures the average squared difference between predicted and actual values [35].

### Cross-Entropy Loss:
$$E = - \sum_{i=1}^{n} y_i \log(\hat{y}_i)$$

- Commonly used in classification problems.
- Measures the discrepancy between predicted probabilities and actual class labels [36].

### 3.3.3.2 Steps in Backpropagation
1. **Forward Pass**: Compute the network output using the current weights and biases.
2. **Compute Error**: Calculate the loss *E* based on the predicted and actual values.
3. **Backward Pass**: Compute the gradient of the loss function concerning each weight using the chain rule of differentiation.
4. **Update Weights**: Adjust weights using the computed gradient and learning rate [37].

### Example of Backpropagation in Action
Suppose the gradient of the error with respect to a weight *w_ij* is 0.5 and the learning rate is 0.1. The updated weight is calculated as follows:

$$w_{ij} = w_{ij} - 0.1 \times 0.5$$

$$w_{ij} = w_{ij} - 0.05$$

This demonstrates how backpropagation iteratively improves model accuracy by adjusting weights [38].

## Applications of Activation Functions and Backpropagation
- **Activation Functions:**
  - **ReLU**: Used in deep convolutional networks for image classification and object detection.
  - **Sigmoid**: Applied in binary classification tasks, such as spam detection.
  - **Tanh**: Used in sequential data processing, particularly in RNNs.
- **Backpropagation:**
  - **Training Deep Networks**: Essential for learning representations in deep learning models.
  - **Optimization**: Utilized in gradient-based optimizers like stochastic gradient descent (SGD) and Adam to efficiently update weights [39].

These concepts form the foundation of deep learning, enabling ANNs to extract meaningful patterns from complex datasets and achieve high predictive accuracy.

## 3.3.4 Gradient Descent: The Backbone of Learning in Neural Networks
To optimize the parameters of an ANN, gradient descent is employed. This iterative optimization algorithm seeks to minimize the loss function by updating model parameters in the direction of the negative gradient. The general weight update rule in gradient descent is given by:

$$w_{ij}^{(t+1)} = w_{ij}^{(t)} - \eta \frac{\partial E}{\partial w_{ij}}$$

- $w_{ij}^{(t)}$, represents the weight at iteration $t$.
- $w_{ij}^{(t+1)}$, is the updated weight.
- $\eta$ (learning rate) controls the step size of updates.
- $\frac{\partial E}{\partial w_{ij}}$, is the gradient of the loss function with respect to the weight.

Gradient descent has several variants to improve convergence efficiency as follows:

1. **Batch Gradient Descent (BGD)**: Updates weights after computing the gradient using the entire dataset. While stable, it is computationally expensive for large datasets [40].
2. **Stochastic Gradient Descent (SGD)**: Updates weights after processing each training sample. This introduces noise but allows faster convergence and escapes local minima more easily [41].
3. **Mini-Batch Gradient Descent (MBGD)**: A compromise between BGD and SGD, where updates are performed after computing the gradient over small batches of data. This approach balances efficiency and stability [42].

### 3.3.4.1 Advanced Optimization Techniques

### Momentum-Based Optimization
Momentum-based optimization accelerates gradient descent by incorporating an exponentially decaying moving average of past gradients. The momentum term helps the optimizer navigate along steep gradients more effectively. The update rule is:

$v^{(t+1)} = \beta v^{(t)} + (1 - \beta) \frac{\partial E}{\partial w_{ij}}$  
$w_{ij}^{(t+1)} = w_{ij}^{(t)} - \eta v^{(t+1)}$

where:

- $v^{(t)}$ is the exponentially averaged gradient at iteration $t$.
- $\beta$ is the momentum coefficient (commonly set to 0.9).

Momentum helps prevent oscillations in the optimization path and speeds up convergence, particularly in deep networks [23].

### Adaptive Learning Rate Methods
To further improve convergence, adaptive learning rate algorithms adjust $\eta$ dynamically based on past gradients. Key methods include as follows:

### 1) Adagrad (Adaptive Gradient Algorithm):
- Modifies the learning rate for each parameter based on historical gradients.
- Works well for sparse data but suffers from diminishing learning rates over time [43].

$w_{ij}^{(t+1)} = w_{ij}^{(t)} - \frac{\eta}{\sqrt{G_{ij}^{(t)} + \epsilon}} \frac{\partial E}{\partial w_{ij}}$

where $G_{ij}^{(t)}$ is the sum of squared gradients up to iteration $t$.

### 2) RMSprop (Root Mean Square Propagation):
- Introduces an exponentially decaying average of squared gradients to mitigate Adagrad's vanishing learning rate issue.
- Well-suited for training RNNs [44].

$G_{ij}^{(t)} = \beta G_{ij}^{(t-1)} + (1 - \beta) \left(\frac{\partial E}{\partial w_{ij}}\right)^2$  
$w_{ij}^{(t+1)} = w_{ij}^{(t)} - \frac{\eta}{\sqrt{G_{ij}^{(t)} + \epsilon}} \frac{\partial E}{\partial w_{ij}}$

### 3) Adam (Adaptive Moment Estimation):
- Combines the benefits of Adagrad and RMSprop by computing both first-moment and second-moment estimates of gradients.

One of the most widely used optimizers for deep learning tasks [45].

$m^{(t)} = \beta_1 m^{(t-1)} + (1 - \beta_1) \frac{\partial E}{\partial w_{ij}}$ 

$v^{(t)} = \beta_2 v^{(t-1)} + (1 - \beta_2) \left(\frac{\partial E}{\partial w_{ij}}\right)^2$

$\hat{m}^{(t)} = \frac{m^{(t)}}{1 - \beta_1^t}, \quad \hat{v}^{(t)} = \frac{v^{(t)}}{1 - \beta_2^t}$

$w_{ij}^{(t+1)} = w_{ij}^{(t)} - \frac{\eta}{\sqrt{\hat{v}^{(t)}} + \epsilon} \hat{m}^{(t)}$

where $\beta_1 = 0.9$ and $\beta_2 = 0.999$ are decay rates for momentum and variance respectively.

## 3.3.5 Regularization Techniques in Neural Networks
To prevent overfitting, deep learning models use regularization techniques that penalize overly complex models.

### 3.3.5.1 L1 and L2 Regularization
1) **L1 Regularization (Lasso)**: Adds an absolute weight penalty to the loss function:

$$E_{reg} = E + \lambda \sum_{i=1}^{n} |w_i|$$

Encourages sparsity by driving some weights to zero, making it useful for feature selection [46].

2) **L2 Regularization (Ridge)**: Adds a squared weight penalty:

$$E_{reg} = E + \lambda \sum_{i=1}^{n} w_i^2$$

Prevents large weight values, improving generalization in deep networks [47].

## 3.3.6 Dropout: Reducing Overfitting
Dropout is another regularization method that randomly disables a fraction of neurons during training. Given a dropout rate, $p$, a neuron is retained with probability $1 - p$:

$$y_i = \frac{x_i}{1 - p}, \quad \text{where } x_i \text{ is dropped with probability } p$$

Dropout forces the network to learn redundant representations, improving robustness [48].
