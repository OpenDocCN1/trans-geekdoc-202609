# Table 2.5   Summary of semi-supervised learning algorithms.

| Aspect | Self-training | Co-training | Graph-based SSL | Generative models |
|---|---|---|---|---|
| Key idea | Use a single classifier to iteratively label and expand the training set. | Use multiple classifiers to label data based on different feature views. | Represent data as a graph and propagate labels through its structure. | Learn the underlying data distribution to identify anomalies or generate new samples. |
| Data requirement | Labeled and unlabeled data. | Labeled and unlabeled data, with distinct feature subsets. | Labeled and unlabeled data, with similarity relationships among data points. | Labeled and unlabeled data, typically using both normal and anomalous patterns. |
| Algorithm examples | Logistic Regression, Decision Trees. | SVM, Naive Bayes, Random Forests. | Label Propagation, Label Spreading. | Semi-supervised GANs, Variational Autoencoders (VAE). |
| Strengths | • Simple and effective for small datasets.<br>• Leverages confidence scores to improve iteratively. | • Exploit feature diversity.<br>• Reduces overfitting by combining classifiers. | • Captures global structure of the data.<br>• Effective for non-linear relationships. | • Models complex patterns.<br>• Can generate synthetic data or detect anomalies. |
| Weaknesses | • Risk of propagating errors.<br>• Sensitive to initial classifier accuracy. | • Requires conditionally independent feature subsets.<br>• Sensitive to initial classifiers’ performance. | • Computationally expensive for large datasets.<br>• Requires a well-constructed similarity graph. | • Resource-intensive.<br>• Requires significant training data for accurate generative models. |
| Applications in an IDS | • Iteratively refine classifications for network intrusion detection. | • Leverage diverse traffic features (e.g., protocol type vs. packet size) to identify attacks. | • Propagate known attack labels through network similarity graphs.<br>• Detects anomalies in network flows. | • Identify rare or unseen attack patterns.<br>• Generate synthetic attack data for training. |
| Computational cost | Low to medium, depending on iterations. | Medium, depends on the number of classifiers and iterations. | High, due to graph construction and propagation steps. | High, especially for deep learning-based models. |
| Best use cases | When confident predictions are possible and errors can be controlled. | When data has diverse feature representations with sufficient independence. | When data relationships can be effectively modeled as a graph. | When learning complex patterns or generating synthetic data is critical. |
