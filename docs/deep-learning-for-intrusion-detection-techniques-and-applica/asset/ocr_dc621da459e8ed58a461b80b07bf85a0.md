# 6.2 Data

Network traffic is typically captured in one of two formats: flow-based or packet-based [1]. Packet-based traffic is obtained by duplicating data from network device ports, enabling the collection of complete payload information for every packet. On the other hand, flow-based traffic is a more compact representation, as it retains only connection metadata rather than capturing the entire packet content. Wheelus et al. illustrate this difference with a metaphor: packet capture is like hiking through a forest, offering a detailed view, while flow-based capture is akin to observing the forest from a hot air balloon, providing a broader perspective [2] Additionally, this study introduces a third category, “other data,” which lacks a standard format and varies depending on the specific dataset.

# 6.2.1 Packet-Based Data

Packet-based data is typically stored in the PCAP format and includes payload information. The available metadata depends on the network and transport protocols in use, with the most significant ones being User Datagram Protocol, Transmission Control Protocol, Internet Protocol, and Internet Control Message Protocol.
