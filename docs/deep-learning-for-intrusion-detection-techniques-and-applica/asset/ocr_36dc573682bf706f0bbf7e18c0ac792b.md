# 10.5.1 Neural Networks

Any neural network, including the perceptron, is based on neurons. The networks are composed of interconnected nodes (neurons) that process information flow as shown in Figure 10.4. Each neuron receives information, does a computation, and then transmits the result to other neurons. After applying weights and receiving inputs, these digital entities provide an output.

a) **Neurons:** Neurons like real neurons, using activation functions to generate an output after receiving inputs and applying weights. The formula is y = (∑(xi · wi) + b).

xi: Inputs
wi: Weights
b: Bias
f: Activation function

b) **Layers:** The neural networks are structured into various layers that include:

+   - **Input Layer:** It receives raw data (such as network traffic data or picture pixels).
+   - **Hidden Layers:** Run complicated computations on the data to extract higher-level information. Deep learning models often include several hidden layers, which allow them to learn complex patterns.
+   - **Output Layer:** It generates the final output, such as a categorization viz., classification or prediction. ("malicious" or "benign").

c) **Activation Functions:** These functions add nonlinearity to the network, allowing it to learn complicated relationships in data. Some activation functions are rectified linear unit (ReLU), sigmoid, and tanh.

d) **Weights and Biases:** The network’s movable parameters that determine a threshold for activation and impact the significance of input information are called weights and biases.
