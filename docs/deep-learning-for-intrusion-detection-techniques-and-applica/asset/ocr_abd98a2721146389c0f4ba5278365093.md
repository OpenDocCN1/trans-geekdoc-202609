# 11.5.1.1 **Security Challenges in Resource-Constrained IoT Devices**

IoT networks face several security challenges that necessitate the use of DL-based IDS [21]:

+   - **Limited Computational Resources:** Many IoT devices have low processing power, memory, and energy availability, restricting the deployment of complex security algorithms.
+   - **High Attack Surface:** IoT devices operate in diverse environments with weak authentication mechanisms, making them vulnerable to botnets, distributed denial of service (DDoS) attacks, and malware infections.
+   - **Scalability Issues:** The vast number of connected IoT devices generates enormous amounts of data, making traditional IDS solutions ineffective for real-time monitoring.
+   - **Lack of Standardized Security Protocols:** IoT security is fragmented, with different manufacturers implementing varying security mechanisms, leading to vulnerabilities.

# 11.5.1.2 **Deploying Lightweight Deep Learning Models on IoT Gateways**

To address these challenges, lightweight DL models can be deployed on IoT gateways, which act as intermediaries between IoT devices and the cloud [22]. Some effective DL techniques are as follows:

+   - Convolutional neural networks (CNNs) for extracting key features from network traffic with minimal computational overhead.
+   - Recurrent neural networks (RNNs) and long short-term memory (LSTM) models are used to analyze time-series traffic and detect anomalous behavior.
+   - Autoencoders for unsupervised anomaly detection in IoT traffic, identifying zero-day attacks without labeled data.
+   - Federated learning (FL) is for decentralized IDS deployment. It enables IoT devices to train models collaboratively without sharing raw data and enhances privacy and efficiency.

# 11.5.1.3 **Real-World Implementations**

+   - CNN-based IDSs deployed on IoT gateways achieved 94% accuracy in detecting botnet traffic [23].
