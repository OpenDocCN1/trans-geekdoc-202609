# 4.4.2 Deep Belief Networks

DBNs are probabilistic generative models that have contributed significantly to advancements in DL. DBNs are constructed by stacking Restricted Boltzmann Machines (RBMs), where each pair of adjacent layers forms an RBM. The hidden layer of one RBM serves as the visible layer for the next RBM, while the top two layers are undirected. Lower layers exhibit either generative (top-down) or recognition (bottom-up) directed connections. DBN training consists of two main stages: pretraining and fine-tuning. During pretraining, RBMs are trained sequentially in a bottom-up manner using an unsupervised learning algorithm, often the contrastive divergence (CD) algorithm. In the fine-tuning stage, network parameters are refined to enhance the model’s generative or discriminative performance using the up-down algorithm (a variant of the wake–sleep algorithm) or the backpropagation algorithm.
