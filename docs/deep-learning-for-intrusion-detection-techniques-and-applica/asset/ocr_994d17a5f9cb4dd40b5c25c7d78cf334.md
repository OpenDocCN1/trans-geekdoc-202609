# 5.2.2.2 Convolutional Neural Networks (CNNs)

CNN—used for the recognition of objects and classification of images—is a network architecture for DL. Evolving from the traditional ANNs, a CNN is a network of convoluted layers. These layers are used for detection and extraction of various features from the input data, using small filters (kernels) while processing the input image or the previous layer’s feature map. At each location, the filter computes “a dot product between itself and the corresponding region of the input” [5]. They are fully connected and each layer “generates a successive abstraction of the input data with a high level, called a feature map, which saves essential unique information” [13]. CNN is a kind of DL model used for object recognition and image classification. They several features extracted from the input data (information) by using filters, resulting in a feature map. A feature map, which is an output of a convolutional layer, signifies specific features in the input image or a previous layer’s feature map [14]. Feature maps are also known as activation maps or convolutional feature maps. They are defined as “a two-dimensional array or grid of numbers resulting from the application of convolutional filters (also called kernels) to an input image or a previous layer’s feature map. Feature maps play a crucial role in the CNN architecture and are responsible for detecting different visual features or patterns in the input data” [15]. CNNs are tasked with image and video recognition and are able to learn automatically features from the images, making them suitable for tasks like image classification, object detection, and image segmentation [1].

In CNNs, an algorithm is trained on a labeled dataset and works through supervised learning. Here, convolution means a “process of applying a filter or a kernel to an input or feature map.” A filter or kernel is “a small matrix of weights that slides over the input image or feature map and performs a dot product operation at each position” [16]. CNNs perform amazingly by using a very deep hierarchy of layers. They consist of two main types of layers; one layer for feature extraction and the other for classification. The feature extraction layers are convolution layers and max-pooling layers [15].
