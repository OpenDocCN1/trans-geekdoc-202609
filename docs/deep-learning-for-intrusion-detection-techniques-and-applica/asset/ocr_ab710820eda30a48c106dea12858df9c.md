+   - **Keeping signatures up to date:** Network administrators may need to manually update their databases to keep signatures current.
+   - **Expensive:** IDSs/ (intrusion prevention systems (IPSs) can be expensive to buy and maintain.
+   - **Hard to set up and maintain:** An IDS/IPS can be hard to set up, configure, and maintain.

# 2.2.2.2 Transition to ML-Based Approaches

With the limitations of traditional methods becoming more apparent, particularly with the rise of sophisticated and stealthy attacks, ML emerged as a promising alternative. ML-based IDS use models trained on large datasets of both normal and malicious behavior, enabling them to learn patterns and relationships that are not feasible to define manually. The shift to ML-based IDS includes the adoption of techniques like:

+   - **Supervised Learning:** Commonly used for known attack detection, supervised ML techniques like Decision Trees, Random Forests, and support vector machines (SVMs) classify network events as normal or malicious based on labeled data. This approach effectively detects threats similar to those seen in training.
+   - **Unsupervised Learning:** Used for anomaly detection, unsupervised learning techniques such as clustering and anomaly detection algorithms identify deviations from expected behavior. This is useful for detecting new, unknown threats but can result in higher false-positive rates.
+   - **Reinforcement Learning:** Used for adaptive response strategies, reinforcement ML techniques like Q-learn and Policy Gradient use an agent that learns to make decisions by interacting with an environment to maximize a cumulative reward.

# 2.2.2.3 Current ML-Based IDS Landscape

Today, ML-based IDS have become more sophisticated, incorporating advanced techniques such as:

+   - **Feature Engineering and Selection:** Identifying the most relevant features in data to improve model accuracy and efficiency.
+   - **Real-Time Detection and Response:** ML models can now detect and respond to threats in real time by analyzing incoming data streams as they occur.
+   - **Automated Learning and Self-Adaptation:** New ML techniques allow IDSs to update and retrain themselves with minimal human intervention, enabling continuous improvement in threat detection.
