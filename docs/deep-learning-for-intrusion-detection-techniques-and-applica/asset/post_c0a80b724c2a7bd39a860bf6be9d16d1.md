
However, the advent of powerful hardware, such as graphics processing units (GPUs), and the availability of massive datasets, such as ImageNet, reignited interest in deep learning [15]. Breakthroughs such as the development of CNNs for image recognition and RNNs for sequential data analysis have solidified deep learning as a cornerstone of modern artificial intelligence [20].

## 3.2.2 Key Differences Between Deep Learning and Traditional Machine Learning

While traditional machine learning algorithms rely on handcrafted features and shallow architectures, deep learning models leverage multiple layers of neurons to learn hierarchical representations of data. This enables deep learning models to achieve superior performance in tasks such as image recognition, natural language processing, and intrusion detection [21]. The key differences between deep learning and traditional machine learning are summarized below:

- **Feature Engineering**: Traditional machine learning algorithms require manual feature engineering, where domain experts extract relevant features from raw data. In contrast, deep learning models can automatically extract features from raw data, eliminating the need for manual intervention [22].
- **Model Complexity**: Deep learning models are typically more complex than traditional machine learning models, with millions or even billions of parameters. This complexity enables deep learning models to capture intricate patterns and relationships within the data, but it also makes them computationally expensive to train and deploy [23].
- **Data Requirements**: Deep learning models require large amounts of labeled training data to achieve high accuracy. In contrast, traditional machine learning algorithms can often achieve reasonable performance with smaller datasets [24].
- **Interpretability**: Traditional machine learning models, such as decision trees and linear regression, are often more interpretable than deep learning models. The “black-box” nature of deep learning models can make it difficult to understand how they arrive at specific decisions, which can hinder trust and compliance in critical applications [25].

## 3.2.3 Why Deep Learning Is Suited for Intrusion Detection

Intrusion detection involves analyzing large volumes of data to identify patterns indicative of malicious activity. Deep learning models excel at this task due to their ability to process high-dimensional data and detect subtle anomalies [26]. For example, RNNs can analyze sequential network traffic data to identify patterns associated with DDoS attacks, while CNNs can detect malware by analyzing binary code or behavioral patterns [27].

The hierarchical learning process of deep learning models makes them particularly well-suited for intrusion detection. Lower layers of the network can capture simple features, such as packet headers or system logs, while higher layers can capture more complex patterns, such as attack signatures or behavioral anomalies. This enables deep learning models to detect both known and unknown threats, making them highly effective in dynamic and complex environments [28].

## 3.2.4 Artificial Neural Networks (ANNs) as the Core of Deep Learning

ANNs form the foundation of deep learning, drawing inspiration from the architecture of the human brain. These networks consist of interconnected processing units, known as neurons or nodes, which are organized into distinct layers. Each neuron performs computations on the received input data and transmits the results to the subsequent layer. The fundamental capability of ANNs lies in their ability to automatically identify complex patterns and relationships within data by adjusting internal parameters through a learning process [29].

### 3.2.4.1 Structure of ANNs

A typical ANN is composed of three primary types of layers as follows:

- 1) **Input Layer**: This layer receives raw data and forwards it to the subsequent layers without performing any transformation. Each neuron in this layer represents a feature or attribute of the data input.
- 2) **Hidden Layers**: These intermediate layers extract meaningful features by applying weighted computations and activation functions. The depth and number of hidden layers define the complexity of the model. Deep learning models contain multiple hidden layers, enabling them to learn hierarchical representations of data [17].
- 3) **Output Layer**: The final layer generates predictions or classifications based on the learned features from the hidden layers. The number of neurons in this layer depends on the nature of the problem, such as binary classification, multiclass classification, or regression [1].

### 3.2.4.2 Working Mechanism of ANNs

The core functionality of ANNs relies on mathematical computations involving weights, biases, and activation functions. Each neuron computes a weighted sum of its inputs and applies an activation function to introduce nonlinearity, allowing the network to learn complex patterns. The learning process is governed by an optimization technique called backpropagation, which adjusts the weights using gradient descent to minimize the error between predicted and actual outputs [30].

The power of ANNs stems from their ability to approximate complex functions and generalize well to unseen data. Variants such as CNNs and RNNs extend ANNs to specialized domains, including image processing and sequential data analysis, respectively. The growing availability of high-performance computing resources, such as GPUs and TPUs, has further enhanced the scalability and efficiency of ANNs, making them a fundamental component of modern artificial intelligence systems Figure 3.1 [31].

### 3.3.2.2 Neuron Activation Function

In ANNs, the activation function plays a crucial role in determining whether a neuron should be activated based on the input it receives. This function introduces nonlinearity, allowing the network to capture intricate patterns and relationships within data. The mathematical representation of a neuron's output is given by:

$$y = f\left(\sum_{i=1}^{n} w_i x_i + b\right)$$

where:

- **x_i (Inputs):** These represent the features or signals received by the neuron. For instance, in an IDS, inputs might include packet size, protocol type, or source IP address.
- **w_i (Weights):** Each input has an associated weight that determines its importance in the computation. During training, the model adjusts these weights to minimize the error.
- **b (Bias):** The bias term allows the neuron to shift its activation function, improving the model's adaptability to data distributions.
- **∑_{i=1}^n w_i x_i + b (Weighted Sum):** Represents the total signal received by the neuron before activation.
- **f (Activation Function):** This function introduces nonlinearity to the model, allowing it to learn complex data representations [19].

Different activation functions are used in neural networks depending on the type of problem being solved as follows:

1) **Rectified Linear Unit (ReLU):**

$$f(z) = \max(0, z)$$

- Used in deep networks due to its simplicity and effectiveness.
- Helps mitigate the vanishing gradient problem.
- Commonly applied in CNNs [20].

2) **Sigmoid Function:**
