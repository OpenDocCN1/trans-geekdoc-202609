# 8.1.2.4 Advantages of AI-Based AD Methods

AI-powered AD methods can:

+   - Dynamically adapt to the new data
+   - Identify subtle and complex anomalies
+   - Provide improved/enhanced security
+   - Provide enhanced operational efficiency in industrial processes, health sectors, etc.
+   - Achieve cost savings/reductions
+   - Provide scalability
+   - Enable predictive maintenance
+   - Perform enhanced and accurate data analysis on a huge amount of data
+   - Perform real-time monitoring
+   - Reduce false positives
+   - Improve decision-making

# 8.1.2.5 Challenges in AI-Based AD

Major problems in AI-based AD processes are listed as follows:

+   - Complexities and unknowingness in datasets
+   - Heterogeneous anomaly classes
+   - Unavailability of labeled data
+   - Data integration
+   - Computational demands
+   - Data privacy
+   - Interpretability
+   - Adversal attacks
