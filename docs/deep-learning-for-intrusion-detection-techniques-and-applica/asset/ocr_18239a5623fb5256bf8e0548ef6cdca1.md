CNNs have been widely utilized for intrusion detection. For example, Shen et al. [30] introduced a compressed CNN model named CSCNN for image classification. This model integrates compressive sensing theory into the input layer of CNN models, optimizing resource usage while enhancing accuracy. The evaluation, conducted using the MINST and CIFAR-10 datasets, demonstrated improved training efficiency and classification accuracy. Similarly, Praanna et al. [31] developed a hybrid model combining CNN and LSTM algorithms, evaluated using the KDD99 dataset. The experimental results showed that this approach outperformed other models, including SVM, CNN, and DBN, achieving a 99.78% accuracy rate. Furthermore, Nguyen and Kim [32] proposed a novel NIDS based on a genetic algorithm (GA)-driven exhaustive search and fuzzy C-means clustering. This method identified the optimal CNN structure, referred to as the deep feature extractor, through GA-based optimization. The study concluded that implementing this approach in real-world internet networks could enhance security by detecting and categorizing malicious activities. However, a notable drawback of this method was the computational time required to execute the exhaustive GA-based search for selecting optimal features and CNN configurations.
