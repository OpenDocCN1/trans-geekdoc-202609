+   - Maps inputs to a range between 0 and 1.
+   - Frequently used in the output layer for binary classification tasks.
+   - However, it suffers from vanishing gradients in deep networks [16].

# 3) **Hyperbolic Tangent (Tanh):**

$f(z)=\frac{e^z-e^{-z}}{e^z+e^{-z}}$

+   - Similar to the sigmoid but maps inputs between $[-1, 1]$.
+   - Often used in RNNs for sequence modeling [32].

# **Example 3.1**  _Calculation_

Consider a neuron with three inputs:

$x_1=2,\quad x_2=3,\quad x_3=1$

and corresponding weights:

$w_1=0.5,\quad w_2=-0.2,\quad w_3=0.8$

with a bias term:

$b=1$

Using the ReLU activation function, the output is computed as:

$z=(0.5\times2)+(-0.2\times3)+(0.8\times1)+1$

$z=1.0-0.6+0.8+1=2.2$

$y=\operatorname{ReLU}(2.2)=\max(0,2.2)=2.2$

This demonstrates how activation functions process weighted inputs and introduce nonlinearity in neural networks [33].

# 3.3.3  **Training Deep Learning Models Using Backpropagation and Weight Optimization**

Training deep learning models involves adjusting their parameters to minimize error. Backpropagation is the primary algorithm used to update network weights based on the error between predicted and actual outputs. The weight update formula is:

$w_{ij}=w_{ij}-\eta\frac{\partial E}{\partial w_{ij}}$

where:

+   - $w_{ij}$ is the weight connecting neuron $i$ in one layer to neuron $j$ in the next.
+   - $\eta$ (learning rate) controls the magnitude of weight updates.
