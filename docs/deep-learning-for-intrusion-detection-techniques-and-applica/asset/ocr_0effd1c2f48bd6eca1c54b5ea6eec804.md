To detect malignant traffic on a network, NIDS normally comprises hardware (sensors) coupled with a network interface card (NIC) and is placed within the network. It operates in a promiscuous mode to analyze incoming network traffic from multiple sources, matches that traffic to a database of known attacks in the system, and sends an alert to the NIDS management server if such activity is discovered [1]. HIDS runs on a host system on which it is installed and detects intrusions and policy violations by monitoring the system's incoming and outgoing traffic. It detects suspicious or mischievous behavior and reports it to the network manager by comparing system files with the existing database. Three commonly used approaches for intrusion detection are HIDS (host-based), AIDS (anomaly-based), and SIDS (signature-based) [24]. In order to find possible threats, signature-based IDS analyzes a certain set of well-known patterns called sequences. By default, this method maintains a database of attack signatures/rules from prior known assaults on the system, which is used to check incoming traffic against stored signatures. Alerts are issued when signatures match. The SIDS can easily identify known assaults but is unable to identify new attacks since there is no accessible sequence. For identifying unknown malware threats, an AIDS builds a reliable activity model using ML methods. By combining two IDS methodologies (AIDS and HIDS), hybrid-based IDS (H-IDS) is produced. To prevent attacks on the system, it recognizes as many threats as possible and tries to evade every tactic employed by them to protect user data.

In wireless networks, some other IDSs are also proposed such as distributed and cooperative IDS, DL-based intrusion detection systems. In distributed and cooperative IDS, each node has an IDS agent that detects intrusions locally and interacts with nearby nodes for global detection when indeterminate evidence warrants a more comprehensive search. When an intrusion is detected, an IDS agent may provide a local or global response. Each node runs an IDS agent to detect and respond to intrusions. An IDS agent detects and collects local data to identify network attacks and respond independently. Deep learning algorithms have gained popularity and are now used for a variety of tasks. Research indicates that they outperform previous methods. The study aims to create a flexible and effective IDS using deep neural networks (DNNs) to identify and categorize unanticipated attacks. As network behavior and assaults evolve, it’s important to examine both static and dynamic datasets generated over time.

Deep learning uses numerous networks, including CNNs, DBNs, RBMs, and RNNs, each with unique capabilities and qualities. These networks can perform learning in unsupervised, semi-supervised, or supervised settings. Additionally, hierarchical layers are used to extract high-level features from raw input data, eliminating the need for manual features.
