However, ISCX 2012 has some limitations, as it was collected over only seven days, making it insufficient for capturing long-term network behaviors or evolving attack strategies. Additionally, the dataset lacks modern attack techniques such as ransomware, AI-driven threats, and zero-day exploits, making it outdated for today’s cybersecurity landscape. Besides, a major drawback is the absence of encrypted traffic (SSL/TLS, VPNs), which limits its applicability for real-world intrusion detection in modern networks. The dataset also lacks IoT and cloud-based attack scenarios, restricting its usefulness for contemporary security research. While it includes various attack types, it misses advanced multi-vector threats like APTs and fileless malware, and the attacks were scripted, reducing their variability. There is also a class imbalance, potentially leading to biased ML models, and simulated user behaviors lack real-world unpredictability. Furthermore, evasion techniques such as polymorphic malware and adversarial attacks are not included, limiting its effectiveness for training robust IDS models. Lastly, as the dataset was generated from a single controlled network environment, models trained on it may struggle to generalize to different infrastructures.

# 6.4.5 UNSW-NB15

The UNSW-NB15 [21] dataset is a contemporary and extensive intrusion detection dataset designed by the Australian Centre for Cyber Security (ACCS) at the University Of New South Wales (UNSW), Canberra. It was developed to address the shortcomings of earlier datasets, such as KDD99 and NSL-KDD, which fail to accurately reflect current network traffic patterns and evolving cyber threats. Unlike its predecessors, UNSW-NB15 includes a hybrid of real-world and synthetic network traffic, incorporating modern cyber threats and a diverse set of attack categories. The dataset was generated in a controlled testbed environment using the IXIA PerfectStorm tool, which simulated various attack types, and tcpdump, which captured network packets. The data collection spanned two separate periods: the first simulation (16 hours) recorded one attack per second, while the second simulation (15 hours) generated ten attacks per second, resulting in a total of 100GB of raw network traffic. The dataset was then processed using Argus and Bro-IDS tools to extract 49 distinct features, categorized into basic, content, time, and additional attack-related attributes [22].

The UNSW-NB15 dataset consists of 2,540,044 network connections, of which 2,218,761 are normal traffic, and 321,283 correspond to malicious activities.
