+   - *E*, is the error function that quantifies the difference between predicted and actual outputs.
+   - *∂E/∂w_ij*, is the gradient, determining how much the weight should be adjusted to reduce the error [34].

# 3.3.3.1 Error Functions in Neural Networks

Error functions guide the backpropagation process by quantifying how far predictions deviate from actual values. Common error functions include as follows:

# Mean Squared Error (MSE):

$$E = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$

+   - Used for regression tasks.
+   - Measures the average squared difference between predicted and actual values [35].

# Cross-Entropy Loss:

$$E = - \sum_{i=1}^{n} y_i \log(\hat{y}_i)$$

+   - Commonly used in classification problems.
+   - Measures the discrepancy between predicted probabilities and actual class labels [36].

# 3.3.3.2 Steps in Backpropagation

+   1. **Forward Pass**: Compute the network output using the current weights and biases.
+   2. **Compute Error**: Calculate the loss *E* based on the predicted and actual values.
+   3. **Backward Pass**: Compute the gradient of the loss function concerning each weight using the chain rule of differentiation.
+   4. **Update Weights**: Adjust weights using the computed gradient and learning rate [37].

# *Example of Backpropagation in Action*

Suppose the gradient of the error with respect to a weight *w_ij* is 0.5 and the learning rate is 0.1. The updated weight is calculated as follows:

$$w_{ij} = w_{ij} - 0.1 \times 0.5$$

$$w_{ij} = w_{ij} - 0.05$$

This demonstrates how backpropagation iteratively improves model accuracy by adjusting weights [38].
