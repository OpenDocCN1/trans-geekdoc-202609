# 4.1 Introduction

The rapid advancement of digital technologies, including smart cities, autonomous vehicles, mobile banking, and wearable health devices, has significantly increased dependence on the internet [1–3]. While these innovations offer convenience and efficiency, they also expose users and organizations to severe cybersecurity threats. Cybercriminals exploit system vulnerabilities, leading to data breaches, financial losses, and reputational damage [4]. As a result, ensuring robust network security has become a critical concern. Organizations traditionally rely on security mechanisms such as firewalls, encryption, and antivirus software to safeguard their systems. However, these defenses primarily serve as a first layer of protection and often fall short in countering sophisticated and evolving cyberattacks [5, 6]. To strengthen security measures, intrusion detection systems (IDSs) have emerged as an essential solution. First introduced by Denning in 1987, IDSs monitor network traffic to detect unauthorized access and malicious activities [7]. IDSs are designed to identify security violations by analyzing network behavior and system activities. Unlike firewalls, which control external access, IDSs operate within the network, examining traffic patterns to detect intrusions. These systems not only identify threats but also document attacks and provide insights into network vulnerabilities. An effective IDS aims for high detection accuracy while minimizing false positives. Based on deployment strategy, IDSs are categorized into network-based (NIDS), host-based (HIDS), and hybrid-based IDSs. NIDS monitors network-wide traffic, offering a broad security overview. HIDSs, deployed on individual devices, provide detailed analysis but lack a global network perspective. Hybrid-based IDSs combine both approaches, improving detection accuracy by leveraging network-wide and device-specific data.
