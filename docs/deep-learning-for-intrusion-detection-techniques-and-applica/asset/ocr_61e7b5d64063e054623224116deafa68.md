The application of ML techniques has become prevalent in the field of IDS, where various methods and algorithms, such as neural networks, clustering, nearest neighbors, association rules, genetic algorithms, and decision trees, are utilized to extract insights from intrusion datasets. ML methods have been instrumental in developing multiple IDS to enhance accuracy and reduce the reliance on human expertise. Research in this field primarily focuses on identifying patterns and creating IDSs using datasets. Generally, ML methods fall into three categories: unsupervised, supervised, and semi-supervised.

a) Supervised Methods in IDS: IDS employing supervised learning techniques detect intrusions by using labeled training data. This approach involves two main phases: the training phase and the testing phase. During the training session, essential features and categories are identified, and the algorithm learns from these data points. In supervised learning-based IDS, each record includes a host or a network data source along with a corresponding output value, indicating either an intrusion or a normal condition. Feature selection may be applied to eliminate redundant characteristics. Once features are selected using training data, a classifier is trained through a supervised learning approach, enabling it to learn the relationship between its labeled output value and input data. In the testing session, the previously trained model is utilized to classify unknown data into either normal or intrusion categories. The classifier, developed through this process, transforms into a predictive model capable of determining the potential category of input data by analyzing a set of feature values. Various classification methods are available, such as nearest neighbors, decision trees, neural networks, support vector machines, naive Bayes, and rule-based systems techniques. Each method employs a learning methodology to construct a classification model. An effective classification method should not only handle the training data well but also accurately determine the class of records it hasn’t encountered before. The learning algorithm plays a crucial role in creating classification models with reliable generalization capabilities.

b) Unsupervised Methods in IDS: Unsupervised learning aims to derive meaningful insights from input datasets that lack class labels. In this approach, input data points are treated as random variables, and a joint density model is created for the entire dataset. Unlike supervised learning, which relies on output labels for training and predicting new data, unsupervised learning operates without any labeled data. Instead, it autonomously groups the data into different classes.
