However, in the context of smart environments, many security threats are novel and cannot be predicted or explicitly labeled in advance. For example, a new type of malware might exploit a previously unknown vulnerability in an IoT device, and traditional systems would need a preexisting label to detect it, which is not possible without prior knowledge of the attack [16].

Deep learning, especially through **unsupervised learning** techniques, is well-suited to address this problem. In unsupervised learning, the model is trained on large volumes of **normal behavior data** (e.g., sensor readings, network traffic, device logs) without needing any labeled examples of anomalous activity. The deep learning model learns the **underlying distribution** or **structure** of the data and can then identify data points that deviate from this learned behavior as potential anomalies.

For example, a model might be trained on a data representation of how normal things work within the home via smart lighting. But then again, once the anomalies—such as high-energy consumption in unexpected events or turning the lights at awkward hours without apparent causes—are found out, this would still work without ever being told or trained that this was out of bounds. That means this whole system, all through unguided supervision, could really adapt constantly and dynamically for new or unprecedented behavior, and other risks as well [17].

# 9.8.1.2 High-dimensional Data Processing: Learning Complex Patterns in Smart Environments

Smart environments are sources of a tremendous amount of data generated by a variety of interconnected devices, sensors, and systems. This is usually high-dimensional data, meaning that it is composed of a large number of variables that may interact in complex ways.
