# 11.5.3 IDS for Mobile Ad Hoc Networks (MANETs)

A MANET is a wireless network formed by a group of nodes that can move around freely and communicate with one another. This kind of network is often seen in the military and emergency response sectors and can support dynamic vehicular networks [29]. Like any form of mobile infrastructure, however, the ad hoc network is highly vulnerable to a range of eavesdropping, spoofing, and DoS attacks.

# 11.5.3.1 Challenges of Decentralized and Dynamic MANET Security

MANETs face unique security challenges that complicate intrusion detection as detailed below:

+   - Lack of Centralized Control: No dedicated security infrastructure, making IDS deployment difficult.
+   - High Mobility and Topology Changes: Frequent node movement leads to unpredictable traffic patterns, requiring adaptive IDS models.
+   - Limited Computational Resources: Battery-powered nodes require energy-efficient security mechanisms.
+   - Routing Vulnerabilities: Attacks such as wormhole, Sybil, and blackhole exploit weaknesses in MANET routing protocols.

# 11.5.3.2 Deep Learning Techniques for Detecting Routing Attacks

A DL-based IDS enhances MANET security by detecting malicious routing behavior [30] using the following:

+   - Graph neural networks (GNNs) to analyze MANET topology and detect abnormal route modifications.
+   - LSTM networks and RNNs to model temporal traffic patterns and identify deviations.
+   - Autoencoders for unsupervised anomaly detection, flagging previously unseen attack behaviors.
+   - Reinforcement learning (RL)-based IDSs that dynamically adjust detection parameters as the network topology evolves.
