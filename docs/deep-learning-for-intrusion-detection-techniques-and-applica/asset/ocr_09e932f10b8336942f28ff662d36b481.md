# 7.3.3.2 Training with MI and Chi-Squared Methods

During the training phase, techniques like MI and Chi-Squared are employed to fine-tune the feature set fed into machine learning models.

+   - **MI for Ranking Feature Importance:** MI evaluates the relevance of each feature with respect to the target variable, ensuring that only the most informative attributes are retained. For example, in detecting DDoS attacks, MI might prioritize features such as packet rates or source IP distribution, which are highly indicative of such threats.
+   - **Chi-Squared for Statistical Significance:** The Chi-Squared method assesses the statistical independence of each feature relative to the target, identifying those with the greatest impact on the model's predictions. This technique is particularly effective in datasets containing categorical variables, such as system alerts or event logs, where meaningful relationships need to be uncovered.

# 7.3.3.3 Hybrid Approaches for Enhanced Results

In practice, a hybrid approach often delivers the best performance by combining multiple techniques. For instance, feature selection (FS) can be combined using a hyperparameter selection approach to improve intrusion detection systems [17]. This layered strategy leverages the strengths of different methods, ensuring that the system is both efficient in processing and precise in detection.
