The ISCX 2012 dataset has several strengths. It is realistic, diverse, and well-labeled, making it highly effective for ML-based intrusion detection. Unlike earlier datasets such as KDD99 and DARPA98, which contain synthetic or outdated attack scenarios, ISCX 2012 captures modern attack behaviors and ensures completeness by preserving entire packet payloads. The dataset is also extensible and shareable, meaning researchers can modify and reuse traffic profiles for further experimentation.

The dataset is publicly available and is widely used in cybersecurity research and IDS development. It can be used to train ML models, evaluate intrusion detection and prevention systems (IDS/IPS), and study attack patterns in network traffic. Overall, ISCX 2012 remains one of the reliable benchmark datasets for intrusion detection research, offering a balance between real-world traffic, attack diversity, and completeness.

Compared to other publicly available IDS datasets, ISCX 2012 is more comprehensive and realistic. While KDD99 and DARPA98 suffer from outdated attack scenarios and heavy anonymization, ISCX 2012 provides detailed packet-level interactions and diverse attack types. Additionally, while datasets like CAIDA and LBNL contain large-scale real-world traffic, they lack proper labeling, making them less useful for ML applications. In contrast, ISCX 2012 ensures detailed labeling of all traffic flows, making it an excellent resource for IDS benchmarking.

However, ISCX 2012 has some limitations, as it was collected over only seven days, making it insufficient for capturing long-term network behaviors or evolving attack strategies. Additionally, the dataset lacks modern attack techniques such as ransomware, AI-driven threats, and zero-day exploits, making it outdated for today’s cybersecurity landscape. Besides, a major drawback is the absence of encrypted traffic (SSL/TLS, VPNs), which limits its applicability for real-world intrusion detection in modern networks. The dataset also lacks IoT and cloud-based attack scenarios, restricting its usefulness for contemporary security research. While it includes various attack types, it misses advanced multi-vector threats like APTs and fileless malware, and the attacks were scripted, reducing their variability. There is also a class imbalance, potentially leading to biased ML models, and simulated user behaviors lack real-world unpredictability. Furthermore, evasion techniques such as polymorphic malware and adversarial attacks are not included, limiting its effectiveness for training robust IDS models. Lastly, as the dataset was generated from a single controlled network environment, models trained on it may struggle to generalize to different infrastructures.

## 6.4.5 UNSW-NB15

The UNSW-NB15 [21] dataset is a contemporary and extensive intrusion detection dataset designed by the Australian Centre for Cyber Security (ACCS) at the University of New South Wales (UNSW), Canberra. It was developed to address the shortcomings of earlier datasets, such as KDD99 and NSL-KDD, which fail to accurately reflect current network traffic patterns and evolving cyber threats. Unlike its predecessors, UNSW-NB15 includes a hybrid of real-world and synthetic network traffic, incorporating modern cyber threats and a diverse set of attack categories. The dataset was generated in a controlled testbed environment using the IXIA PerfectStorm tool, which simulated various attack types, and tcpdump, which captured network packets. The data collection spanned two separate periods: the first simulation (16 hours) recorded one attack per second, while the second simulation (15 hours) generated ten attacks per second, resulting in a total of 100GB of raw network traffic. The dataset was then processed using Argus and Bro-IDS tools to extract 49 distinct features, categorized into basic, content, time, and additional attack-related attributes [22].

The UNSW-NB15 dataset consists of 2,540,044 network connections, of which 2,218,761 are normal traffic, and 321,283 correspond to malicious activities. The dataset covers nine major attack families, making it more comprehensive than previous datasets. These attack categories include Fuzzers (random data injection to crash systems), Analysis (port scanning, spam, HTML injections), Backdoors (stealth access mechanisms), Denial of Service (DoS) (resource exhaustion attacks), Exploits (system vulnerability exploitation), Generic (attacks on cryptographic systems), Reconnaissance (network scanning for vulnerabilities), Shellcode (malicious code injection), and Worms (self-replicating malware). Each attack type is labeled, providing a well-structured dataset suitable for training and evaluating intrusion detection and prevention systems (IDS/IPS). Compared to KDD99 and NSL-KDD, UNSW-NB15 offers significant improvements, including a balanced dataset, modern attack vectors, diverse network protocols (HTTP, FTP, SSH, DNS), and a larger feature set (49 attributes vs. 41 in NSL-KDD and 42 in KDD99). Additionally, it eliminates redundancy and reflects contemporary low-footprint cyber threats.

Despite its strengths, UNSW-NB15 has some limitations. The dataset does not include encrypted traffic (SSL/TLS-based attacks), which is crucial in modern cybersecurity. Furthermore, while it covers a wide range of attack types, some behaviors remain simulated rather than captured from real-world incidents, which may affect generalizability. Another limitation is its fixed collection period (31 hours in total), which may not fully capture evolving attack strategies over time. However, despite these constraints, UNSW-NB15 remains one of the most widely used benchmark datasets for network security research and ML-based intrusion detection. It provides researchers with structured CSV files containing labeled attack data, and raw PCAP files are also available for deeper analysis. Overall, UNSW-NB15 represents a significant advancement in intrusion detection datasets, offering a more realistic and diverse representation of modern cyber threats compared to earlier benchmarks like KDD99 and NSL-KDD.
