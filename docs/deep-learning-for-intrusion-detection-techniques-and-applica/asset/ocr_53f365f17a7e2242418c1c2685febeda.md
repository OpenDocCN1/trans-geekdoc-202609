+   - Inspects data packets for signs of suspicious activity through deep packet inspection (DPI).

# **Advantages:**

+   - Provides a broad view of the network, making it effective for detecting attacks that spread across the network.
+   - Monitors real-time traffic, enabling quick detection of large-scale network-based attacks.
+   - Less resource-intensive on individual hosts as it is deployed on network devices or segments.

# **Limitations:**

+   - Limited visibility into encrypted network traffic without decryption capabilities, which may allow certain attacks to go undetected.
+   - Cannot detect attacks that occur entirely within a host’s system or through legitimate-looking traffic.
+   - Prone to generating false positives in environments with high volumes of traffic or legitimate but unusual activity.

***Hybrid Intrusion Detection Systems***  **Definition:** An HID combines elements of both the HIDS and NIDS, leveraging both host-level and network-level data to provide a more comprehensive view of potential intrusions [4]. A hybrid IDS integrates host-based and network-based monitoring for a layered detection approach, often using central analysis tools to correlate data from multiple sources.

# **Key Functions of Hybrid IDS:**

+   - Collects data from both network traffic and individual hosts, allowing for cross-correlation of events.
+   - Provides a unified view of security across the network and its endpoints, improving the detection of complex, multistage attacks.
+   - Can implement advanced analytics to detect blended attacks that affect both hosts and the network.

# **Advantages:**

+   - Offers a comprehensive security view by combining the granular monitoring of an HIDS with the broad network visibility of a NIDS.
+   - Can reduce false positives by correlating events from different sources, improving accuracy.
+   - Effective at detecting multistage attacks, such as APTs, which may involve both network traffic and host exploitation.
