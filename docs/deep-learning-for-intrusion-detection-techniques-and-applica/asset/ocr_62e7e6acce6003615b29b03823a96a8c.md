# 2 Machine Learning for Intrusion Detection

# 2) Co-Training:

+   - Use two (or more) classifiers trained on different feature subsets.
+   - Classifiers teach each other by labeling unlabeled data, which is added to the training set.

+   - Different features like packet size, protocol types, or connection duration can be used in separate classifiers.

• Challenges: Requires features that are conditionally independent and sufficient for classification.

# 3) Graph-Based Semi-supervised learning:

+   - Represent the data as a graph where nodes are data points and edges represent similarity.
+   - Propagate labels from labeled nodes to unlabeled ones based on graph structure.

+   - Build graphs based on network traffic similarity and propagate known attack types.

+   - Label propagation, label spreading.

• Challenges: Computationally expensive for large-scale datasets.

# 4) Generative Models:

+   - Use models like VAEs or semi-supervised GANs to model the distribution of data.
+   - Detect anomalies by identifying points that deviate from the learned normal patterns.

+   - Train on both normal traffic (labeled) and unlabeled traffic to generate new samples or identify anomalies.

• Challenges: Requires substantial computational resources.

# 2.7.2 Applications in IDSs

# 1) Network Anomaly Detection:

+   - Detects deviations from normal behavior in real-time traffic.
+   - SSL helps utilize vast amounts of unlabeled network traffic effectively.

# 2) Malware Detection:

+   - Identifies malicious payloads or behaviors using labeled malware samples and large-scale unlabeled network data.
