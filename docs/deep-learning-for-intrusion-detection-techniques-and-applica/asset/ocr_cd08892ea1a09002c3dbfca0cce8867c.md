The final tree consists of leaf nodes, which represent the predicted class labels, and internal nodes, which contain the decision rules. Decision Trees are popular for their simplicity, interpretability, and ability to handle both categorical and numerical data. However, they are prone to overfitting, especially when the tree grows too deep, and may require techniques like pruning or ensemble methods to improve generalization [12].

**Random Forest** is an ensemble learning method that combines multiple decision trees to improve prediction accuracy and robustness. Each tree in the forest is trained on a random subset of the data, created using bootstrapping (sampling with replacement), and considers a random subset of features for each split. This randomness introduces diversity among the trees, reducing the likelihood of overfitting and making the model more generalizable. During prediction, the Random Forest aggregates the results from all individual trees—typically through majority voting for classification tasks or averaging for regression tasks. This approach leverages the collective wisdom of the trees, resulting in higher accuracy and stability compared to a single decision tree [13]. Random Forest is versatile, capable of handling large datasets with high-dimensional features, and robust to noisy data. However, it can be computationally intensive and less interpretable than standalone Decision Trees.

**Support Vector Machines (SVMs)** are supervised learning algorithms designed to find the optimal hyperplane that separates data points into distinct classes in a high-dimensional space. The hyperplane is chosen to maximize the margin, which is the distance between the hyperplane and the nearest data points from each class, called support vectors. This maximization enhances the model's ability to generalize to unseen data. SVMs can handle linear and non-linear separations by using kernel functions, such as polynomial or radial basis functions (RBF), to map data into a higher-dimensional space where it becomes linearly separable. SVMs are effective for binary and multiclass classification tasks, especially in cases with high-dimensional data and smaller sample sizes. However, they can be computationally expensive for large datasets and require careful tuning of parameters, such as the regularization term and kernel choice, for optimal performance [14].

**Naive Bayes** is a simple yet effective probabilistic ML algorithm based on Bayes’ theorem. It assumes that all features are independent of each other given the class label, an assumption often unrealistic in practice but effective in many scenarios. The algorithm calculates the posterior probability of each class by combining prior probabilities with the likelihood of the observed features, selecting the class with the highest posterior probability as the prediction.
