+   - **Resource Constraints:** Nodes in wireless networks have restricted processing power because of battery power and resource limitations. Execution of computationally heavy IDS algorithms consumes resources rapidly, reducing the life span of the nodes as well as the overall network performance.

# 10.3.2 Advanced Threats

+   - **Novel Attack Approaches:** Attackers are continually creating new and sophisticated methods to exploit flaws in these networks. IDSs must be adaptable and evolve in order to detect these emerging threats. Wireless networks face several dangers, such as routing assaults (e.g., blackhole, wormhole, Sybil), DoS attacks, and deception. Because of the continually developing nature of these threats, IDSs must be adaptive and capable of recognizing novel attack patterns.
+   - **Unknown Assaults:** Traditional IDSs might not be able to identify unknown or zero-day assaults, necessitating the use of more sophisticated strategies like anomaly detection, hybrid detection approaches.

# 10.3.3 Flexibility and Distributed Processing

+   - **Decentralized Architecture:** Wireless networks decentralized architecture necessitates distributed or cooperative IDSs. This adds complexity since nodes must work together to detect intrusions in real time, and malevolent nodes can use this structure to disrupt detection measures. However, coordinating and synchronizing several IDS nodes can also be challenging when it comes to handling larger networks with higher mobility.
+   - **Wide Network Sizes:** MANETs and WSNs might include hundreds or even thousands of nodes, making it difficult to create a centralized IDS capable of quickly tracking and evaluating traffic from all nodes.

# 10.3.4 Privacy Concerns

+   - **Secure Transmission:** A proactive IDS requires nodes to share data for analysis, ensuring safe transmission. However, establishing secure communication between possibly unreliable nodes is difficult, because attackers can use various methods to inject bogus data or disrupt IDS operations.
+   - **Data Gathering and Analysis:** IDSs may be required to gather and analyze sensitive data about network traffic and node behavior, which raises privacy concerns for users.
