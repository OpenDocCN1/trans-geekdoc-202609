### 4.1 Introduction

The rapid advancement of digital technologies, including smart cities, autonomous vehicles, mobile banking, and wearable health devices, has significantly increased dependence on the internet [1–3]. While these innovations offer convenience and efficiency, they also expose users and organizations to severe cybersecurity threats. Cybercriminals exploit system vulnerabilities, leading to data breaches, financial losses, and reputational damage [4]. As a result, ensuring robust network security has become a critical concern. Organizations traditionally rely on security mechanisms such as firewalls, encryption, and antivirus software to safeguard their systems. However, these defenses primarily serve as a first layer of protection and often fall short in countering sophisticated and evolving cyberattacks [5, 6]. To strengthen security measures, intrusion detection systems (IDSs) have emerged as an essential solution. First introduced by Denning in 1987, IDSs monitor network traffic to detect unauthorized access and malicious activities [7]. IDSs are designed to identify security violations by analyzing network behavior and system activities. Unlike firewalls, which control external access, IDSs operate within the network, examining traffic patterns to detect intrusions. These systems not only identify threats but also document attacks and provide insights into network vulnerabilities. An effective IDS aims for high detection accuracy while minimizing false positives. Based on deployment strategy, IDSs are categorized into network-based (NIDS), host-based (HIDS), and hybrid-based IDSs. NIDS monitors network-wide traffic, offering a broad security overview. HIDSs, deployed on individual devices, provide detailed analysis but lack a global network perspective. Hybrid-based IDSs combine both approaches, improving detection accuracy by leveraging network-wide and device-specific data.

IDSs also differ in detection methodology, classified into misuse-based and anomaly-based detection. Misuse-based IDSs operate by comparing observed activities against predefined attack signatures. While effective against known threats, these IDSs struggle to detect new or zero-day attacks. In contrast, anomaly-based IDSs analyze deviations from normal behavior using heuristics and rule-based approaches. Although these systems can identify unknown threats, defining and maintaining accurate detection rules is complex and requires extensive training [8, 9]. Anomaly-based IDSs employ various techniques, including statistical methods, knowledge-based detection, and machine learning (ML) approaches. Statistical anomaly detection assesses deviations from expected network behavior, while knowledge-based IDSs rely on predefined attack knowledge and system vulnerabilities [10]. ML-based IDSs enhance intrusion detection by recognizing complex attack patterns in large datasets. However, traditional ML approaches often require extensive training data, face scalability challenges, and struggle with high-dimensional data analysis.

To address these limitations, deep learning (DL) has gained significant attention as an advanced IDS solution. DL models, particularly artificial neural networks (ANNs), improve security by automating feature extraction, enhancing accuracy, and adapting to evolving cyber threats. These models offer superior detection performance, making them suitable for modern high-dimensional and dynamic network environments. The remainder of this paper is organized as follows: Section 4.2 ANNs and their role in an IDS. Section 4.3 provides an overview of DL and its significance in cybersecurity. Section 4.4 explores various DL algorithms used in IDSs. Section 4.5 concludes the paper by summarizing key findings and future directions.

### 4.2 Artificial Neural Networks

DL techniques emerged in 2006 and have since gained significant research interest. The term “deep” refers to the presence of multiple hidden layers in an ANN. ANNs, also known as neural networks (NNs), are a subset of ML algorithms designed to replicate the functioning of the human brain. As depicted in Figure 4.1a, a typical ANN consists of three primary layers: the input layer, hidden layer(s), and the output layer. The input layer processes incoming data, which is then transferred to hidden layers where computations are performed. Finally, the output layer generates predictions or classification results based on the processed information.

For a given input dataset (x), the learning process follows a structured approach. Initially, small values close to zero are assigned as weights (w) and biases (b), typically drawn from a uniform or normal distribution [11]. Next, the input data is passed through the network, propagating through the hidden layers where various operations are performed to derive an output. This mechanism is known as **forward propagation**.

As shown in Figure 4.1b, each layer’s output transforms using an **activation function**, which introduces nonlinearity into the network. This nonlinearity allows ANNs to capture complex patterns from input data [12]. In a binary classification problem, where observations in space belong to one of two classes, the dataset is considered **linearly separable** if a straight line (or hyperplane in higher dimensions) can effectively distinguish between the classes. However, when a simple linear boundary is insufficient, the classification problem is **nonlinearly separable**, necessitating the use of nonlinear activation functions to define decision boundaries.

Common activation functions in neural networks include the **sigmoid function** and **rectified linear unit (ReLU)** [12]. The final output y, generated by the last layer of the ANN, is also processed through an activation function to ensure the model produces the expected results. For instance, in binary classification tasks, the sigmoid function is often used to determine the probability that a given input belongs to a specific class. The predicted value is then compared with the actual output (correct class), and any difference between them constitutes a **classification error**. To refine its predictions, an ANN continuously adjusts its weights based on the error. This adjustment process is guided by a specialized function known as the **loss function (or cost function)**, which aims to minimize errors and improve prediction accuracy [13]. The choice of loss function depends on the type of problem being solved. Once the error is calculated, it is propagated backward through the hidden layers to update the weights—this process is called **backpropagation** and is executed using **gradient descent** [14]. Gradient descent is an optimization technique that seeks to identify the point where the error is minimized as much as possible.

Backpropagation is a fundamental component of ANN-based classification and predictive models. Once the model reaches an optimal state with minimal error, it converges and provides the final classification result. While traditional ANNs, such as **single-layer perceptrons** or **feed-forward networks**, are capable of handling some nonlinear classification problems, they have limitations in malware detection due to their simple architectures. These basic models struggle to process complex, large-scale data, especially high-dimensional structured and unstructured information.

With the increasing prevalence of malware across Windows, Linux, and Android platforms, traditional ANNs prove inadequate in effectively detecting such threats. To overcome these shortcomings, **DL algorithms** were introduced, offering more advanced capabilities for handling sophisticated data patterns. However, it is worth noting that training ANN models typically requires less time compared to DL models, which involve more extensive computations.

### 4.3 Overview of Deep Learning

DL is a subset of ANNs that features a greater number of hidden layers than traditional neural networks, often extending up to 150 layers. While DL is a branch of ML, its complex structure and data representation learning make it a more advanced extension of ML. Similar to ML, DL employs algorithms that learn from examples to improve their performance. DL serves as a foundational technology for numerous fields, including computer vision [15], natural language processing [16], autonomous vehicles [17], fraud detection [18], malware detection [19], and more. Characterized by deep network architectures with multiple hidden layers, DL models are highly effective at performing classification tasks on images, audio, and text with superior accuracy. Unlike traditional neural network algorithms, DL models can automatically extract features from input datasets without requiring manual feature engineering, enhancing their capabilities [20]. Some DL algorithms can be trained on a standard computer with a CPU, but more complex networks typically require graphics processing units (GPUs) to expedite the training process [21].

The performance of ML and DL algorithms varies with the scale of the data. DL algorithms require vast amounts of data to recognize intricate patterns, whereas ML algorithms generally perform well with smaller datasets. The depth of a network can be increased by adding additional hidden layers to an ANN, allowing data to be processed at multiple levels, thus deepening the learning process.
