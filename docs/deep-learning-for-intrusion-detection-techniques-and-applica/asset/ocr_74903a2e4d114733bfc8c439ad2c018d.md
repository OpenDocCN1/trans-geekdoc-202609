[12]. HIDSs typically employ detection software known as agents, which are installed on specific hosts to monitor their activities. Agents are utilized to collect data and send it to management servers, where database servers and consoles are used for system management and monitoring. Some HIDSs utilize dedicated devices that directly execute the agent software, eliminating the need for individual host installations.

These devices are positioned to oversee network activity on specific hosts and can be considered a type of network-based IDS. IDSs based on the host have a tendency to generate false positives and false negatives, impacting their accuracy in identifying potential threats. The challenge with detecting threats using HIDSs lies in their lack of contextual information about detected events, such as file system monitoring and log analysis.
