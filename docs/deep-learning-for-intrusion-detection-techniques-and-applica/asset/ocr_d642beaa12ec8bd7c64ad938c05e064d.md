IDSs also differ in detection methodology, classified into misuse-based and anomaly-based detection. Misuse-based IDSs operate by comparing observed activities against predefined attack signatures. While effective against known threats, these IDSs struggle to detect new or zero-day attacks. In contrast, anomaly-based IDSs analyze deviations from normal behavior using heuristics and rule-based approaches. Although these systems can identify unknown threats, defining and maintaining accurate detection rules is complex and requires extensive training [8, 9]. Anomaly-based IDSs employ various techniques, including statistical methods, knowledge-based detection, and machine learning (ML) approaches. Statistical anomaly detection assesses deviations from expected network behavior, while knowledge-based IDSs rely on predefined attack knowledge and system vulnerabilities [10]. ML-based IDSs enhance intrusion detection by recognizing complex attack patterns in large datasets. However, traditional ML approaches often require extensive training data, face scalability challenges, and struggle with high-dimensional data analysis.

To address these limitations, deep learning (DL) has gained significant attention as an advanced IDS solution. DL models, particularly artificial neural networks (ANNs), improve security by automating feature extraction, enhancing accuracy, and adapting to evolving cyber threats. These models offer superior detection performance, making them suitable for modern high-dimensional and dynamic network environments.
