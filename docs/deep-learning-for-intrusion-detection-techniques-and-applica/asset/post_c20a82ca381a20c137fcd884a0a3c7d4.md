
## 10.5.1 Neural Networks

Any neural network, including the perceptron, is based on neurons. The networks are composed of interconnected nodes (neurons) that process information flow as shown in Figure 10.4. Each neuron receives information, does a computation, and then transmits the result to other neurons. After applying weights and receiving inputs, these digital entities provide an output.

a) **Neurons:** Neurons like real neurons, using activation functions to generate an output after receiving inputs and applying weights. The formula is y = (∑(xi · wi) + b).

xi: Inputs
wi: Weights
b: Bias
f: Activation function

b) **Layers:** The neural networks are structured into various layers that include:

- **Input Layer:** It receives raw data (such as network traffic data or picture pixels).
- **Hidden Layers:** Run complicated computations on the data to extract higher-level information. Deep learning models often include several hidden layers, which allow them to learn complex patterns.
- **Output Layer:** It generates the final output, such as a categorization viz., classification or prediction. ("malicious" or "benign").

c) **Activation Functions:** These functions add nonlinearity to the network, allowing it to learn complicated relationships in data. Some activation functions are rectified linear unit (ReLU), sigmoid, and tanh.

d) **Weights and Biases:** The network’s movable parameters that determine a threshold for activation and impact the significance of input information are called weights and biases. Every feature of the input data is assigned a weight, signifying its significance in the choice. Biases serve as the bare minimum needed for a feature to be useful. The capacity of the model to produce precise predictions is improved by adjusting weights and biases during training.

e) Training: The process of minimizing the discrepancy between the desired values and the model's predictions by modifying the weights of the connections. Usually, optimization algorithms such as the Stochastic gradient descent (SGD), Adam, and RMSprop are used.

## 10.5.2 Artificial Neural Networks (ANNs)

Artificial neural networks (ANNs) are the underlying architecture for DL. At its core, an ANN is made up of interconnected nodes that include an input layer, one or more hidden layers, and an output layer. Figure 10.5 shows that information flows are unidirectional, from the input layer via the hidden levels to the final output. Each node in the network is equivalent to a neuron and connected to nodes in the subsequent layer. The connections are weighted, representing their strength. Input data is propagated through the network, and as it passes through each layer, the weighted sum is calculated, with an activation function controlling the output of each node. This continues until the last layer generates the network's output. The backpropagation method optimizes the accuracy and performance of the model afterward. Backpropagation, the fundamental concept, facilitates learning by modifying weights based on prediction errors. Input data is propagated through the network, with weighted sums building up in each layer, where activation functions regulate node outputs.

Loss functions estimate the difference between predicted and actual outputs. The goal is to minimize the difference in training by decreasing the distance between its prediction and the real target. This recurrent process reaches its peak in the final output layer, generating the desired result. The simplicity, convenience, and capability of mapping intricate relationships within data are the power of ANNs [8]. These models can learn from massive databases and generalize effectively to new data, making them widely utilized in real-world applications.

## 10.5.3 Conventional Neural Networks (CNNs)

Convolutional neural network (CNN) is a significant image processing, feature learning, and classification model framework. It consists of three basic layers and is optimized to efficiently deal with input image data, making it a key component of a variety of applications.

- **Convolutional Layer (CONV)**: Convolutional layers are the building block of CNNs, with the primary task of performing convolution operations. To accomplish convolution processes, the layers use kernels or filters that move horizontally and vertically according to the stride rate. The convolutional layer utilizes nonlinear activation functions, the most common of which is the ReLU). ReLU improves the network's ability to understand complex trends by introducing nonlinearity.
- **Pooling Layer (POOL)**: The pooling layer, which handles dimensionality reduction, minimizes computational expenses while maintaining significant information. Two common types are maximum pooling, which picks the maximum value in a region of a kernel, and average pooling, which calculates average values in the kernel. Pooling enhances network resilience and aids in improved management of computing resources.
- **Fully Connected Layers (FC)**: The FC layer, in conjunction with a flattened input, connects each input to all neurons, initiating the classification process. FC layers are usually found at the end of the network and execute mathematical operations to finalize the process of classification as shown in Figure 10.6. Apart from these steps, other elements contribute to CNN's performance. The activation function influences the classification output, especially in the final fully linked layer. The softmax function, commonly used, normalizes outputs to represent target probability classes. Dropout layers prevent overfitting during training, eliminate individual neurons' contributions, and promote more resilient learning from various batches of training data.

## 10.5.4 Recurrent Neural Networks (RNNs)

The distinctive feature of recurrent neural networks (RNNs) is that they can handle sequential data by adding a memory component that allows them to recognize temporal relationships. RNNs, unlike feed-forward networks, possess looping connections that assist them in remembering past inputs, and therefore, they are best suited for context-requiring tasks. RNNs can handle sequences that are best suited for time-series forecasting, language modeling, and speech recognition tasks due to their recursive nature. Nevertheless, the capacity of normal RNNs to learn long-term dependencies is poor. This weakness is circumvented by LSTM and GRU architecture, which enhances RNNs’ capacity to handle and learn sequential input.

- **Input Layer:** The layer is presented with the first piece of sequence data. In each step, data is fed to the network as shown in Figure 10.7. The input can be a single value, a vector, or a more complex data structure.
- **Hidden Layer:** The core of the RNN, consisting of connected neurons. Each neuron is presented with the current input and the previous hidden layer’s state. This “state” holds the network’s memory of the previous inputs and allows it to understand the current element in context. This process allows the RNN to remember and pass relevant information across time and allows it to simulate long-term dependencies.
- **Activation Function:** This function introduces nonlinearity into the network, allowing it to learn intricate patterns. It transforms the combined input from the current input layer and the previous hidden layer state before passing it. Some of them include sigmoid, tanh, and ReLU functions.
- **Output Layer:** This layer provides the network’s prediction based on the processed data. The output can be a classification, regression, or another sequence.
- **Recurrent Connection:** An important feature of RNNs is the recurrent connection within the hidden layer. This connection enables the network to transmit concealed state information (the network’s memory) to the following time step. This establishes a loop inside the network, allowing it to sustain an internal state that includes information from prior inputs.
