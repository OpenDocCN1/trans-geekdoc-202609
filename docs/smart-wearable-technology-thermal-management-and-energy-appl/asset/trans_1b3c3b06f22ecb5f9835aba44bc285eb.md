## 3. 模型建立

### 3.1. 假设和边界条件

为分析不同蒸汽注入技术高温热泵的性能，基于以下假设建立了数学模型：

- (1) 热泵系统中的工作流体处于稳态；
- (2) 忽略换热器和管道中的热损失和压力损失；
- (3) 热泵压缩机效率为常数；
- (4) 膨胀阀过程视为等焓过程。

参考值和边界条件如表 2 所示。

| 参数 | 参考值 | 边界条件 |
| :--- | :--- | :--- |
| 制冷剂质量流量 \(\dot{m}_{ref}/(kg/s)\) | 1 | - |
| 蒸发温度 \(t_e/^\circ C\) | 55 | 40~80 |
| 过热度 \(t_{sup}/^\circ C\) | 10 | 0~15 |
| 冷凝温度 \(t_c/^\circ C\) | 125 | 100~130 |
| 副冷度 \(t_{sub}/^\circ C\) | 5 | 0~15 |
| 注入质量流量比 A | 0.3 | - |
| 相对注入压力 RIP | 1 | - |
| 注入过热度 \(t_{sup,inj}/^\circ C\) | 5 | 0~20 |
| 压缩机等效效率 \(\eta_{is}\) | 0.72 | 0~0.9 |

### 3.2. 模型建立

基于能量守恒方程和质量守恒方程，建立了带闪蒸罐蒸汽注入和副冷凝器蒸汽注入的高温热泵热力学模型。

在冷凝器中，热量从工作流体传递到冷却热源，工作流体的焓值降低，而压力损失很小。因此，冷凝过程可视为定压放热过程。冷凝热可根据工作流体质量流量与冷凝器进出口焓差的乘积，按公式 (1) 计算。

```
\( Q_{cond} = (1 + A) \times \dot{m}_{ref} \times (h_{cond,in} - h_{cond,out}) \) (1)
```

膨胀阀节流过程视为等焓过程，因此

```
\( h_{th,in} = h_{th,out} \) (2)
```

对于 SCVI 热泵系统，热量在副冷凝器中传递，因此

```
\( \dot{m}_{ref} \times (h_6 - h_9) = \dot{m}_{ref} \times A \times (h_3 - h_8) \) (3)
```

对于 FTVI 热泵系统中的闪蒸罐

```
\( \dot{m}_{ref} \times (1 + A) \times h_6 = \dot{m}_{ref} \times h_7 + \dot{m}_{ref} \times A \times h_3 \) (4)
```

在两个热泵系统的蒸发器中，蒸发热可根据工作流体质量流量与蒸发器进出口焓差的乘积，按公式 (5) 计算：

```
\( Q_{evap} = \dot{m}_{ref} \times (h_{evap,out} - h_{evap,in}) \) (5)
```

在两个循环的压缩过程中，过程 1–2 和 2′–4 为绝热压缩过程，过程 3–2 可视为定压混合过程，因此

```
\( h_2 = (h_{2s} - h_1) / \eta_{is} + h_1 \) (6)
```

```
\( h_4 = (h_{4s} - h_{2'}) / \eta_{is} + h_{2'} \) (7)
```

```
\( \dot{m}_{ref} \times (1 + A) \times h_{2'} = \dot{m}_{ref} \times h_2 + \dot{m}_{ref} \times A \times h_3 \) (8)
```

```
\( W_{c1} = \dot{m}_{ref}(h_2 - h_1) \) (9)
```

```
\( W_{c2} = \dot{m}_{ref} \times (1 + A) \times (h_4 - h_{2'}) \) (10)
```

W = W_{c1} + W_{c2} (11)

注入质量流量比 A 和相对注入压力 RIP 定义如下：

A = \frac{\dot{m}_{inj}}{\dot{m}_{ref}} (12)

RIP = \frac{P_{inj}}{\sqrt{P_{cond}P_{evap}}} (13)

压缩机排气温度可根据冷凝压力和压缩机出口制冷剂焓值计算。

t_{disch} = f(P_{cond}, h_{disch}) (14)

最常用的性能系数 (COP) 用于评估热泵系统的效率。COP 根据供热能力和压缩机功耗计算，如公式 (15) 所示。为比较供热能力和吸气管体积流量的影响，体积供热能力 (VHC) 使用公式 (16) 计算：

COP = Q_{cond} / (W_{c1} + W_{c2}) (15)

VHC = Q_{cond} / \dot{m}_{ref}v_1 (16)

## 4. 结果与讨论

蒸发温度、冷凝温度、压缩机吸气过热度、副冷度和压缩机等效效率是影响高温热泵性能的主要因素。因此，在这些不同主要因素下，比较了带闪蒸罐蒸汽注入和带副冷凝器蒸汽注入的高温热泵的性能。

### 4.1. 不同蒸发温度下的性能比较

图 3 显示了不同蒸发温度下带闪蒸罐蒸汽注入和副冷凝器蒸汽注入高温热泵循环的性能比较。两个循环之间的一个重要区别在于，注入 FTVC 压缩机的制冷剂蒸汽处于饱和状态，而 SVIC 的制冷剂蒸汽可以处于饱和状态或过热状态。因此，还研究了不同注入过热度下的 SVIC。SVIC-0、SVIC-5、SVIC-10 和 SVIC-20 分别表示注入过热度为 0 °C、5 °C、10 °C 和 20 °C 的 SVIC。如图 3a 所示，在相同蒸发温度下，FTVC 系统的 COP 高于 SVIC。同时，从图 3a 可以看出，随着注入过热度的增加，SVIC 热泵系统的 COP 降低。当蒸发温度、冷凝温度和注入压力分别为 55 °C、125 °C 和 921.4 kPa 时，FTVC、SVIC-0、SVIC-5、SVIC-10 和 SVIC-20 对应的系统 COP 分别为 4.49、4.19、4.16、4.14 和 4.09，FTVC 的 COP 分别比 SVIC-0、SVIC-5、SVIC-10 和 SVIC-20 系统高 6.7%、7.3%、7.8% 和 8.9%。图 3b 显示，注入质量流量比随蒸发温度升高而降低，这是因为蒸发温度升高导致冷凝压力与注入压力之间的压差减小。同时，从图 3b 可以看出，在不同注入过热度下，FTVC 的注入质量流量比高于 SVIC，这导致在相同注入压力下 FTVC 的 COP 高于 SVIC。在蒸发温度 55 °C、冷凝温度 125 °C 和注入压力 921.4 kPa 时，FTVC 的注入质量流量比分别比 SVIC-0、SVIC-5、SVIC-10 和 SVIC-20 高 18.6%、23.6%、28.0% 和 35.2%。图 3c 显示，在不同注入过热度下，FTVC 的体积供热能力也高于 SVIC。当蒸发温度、冷凝温度和注入压力为 55 °C、125 °C 和 921.4 kPa 时，FTVC、SVIC-0、SVIC-5、SVIC-10 和 SVIC-20 的 VHC 分别为 3976、3714、3710、3706 和 3699 kJ/m³。图 3d 显示了不同系统在不同蒸发温度下的排气温度。根据图 3d，FTVC 和 SVIC-0 在不同蒸发温度下具有等效的排气温度。当蒸发温度和注入过热度增加时，排气温度升高。
