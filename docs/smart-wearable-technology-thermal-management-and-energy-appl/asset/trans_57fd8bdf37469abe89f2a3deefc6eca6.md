

纤维、空气和水的热阻。三个因素的热阻计算公式如下[3]（参见公式 (3)–(5)：

```
Fiber thermal resistance : \( R_f = \frac{h(1 - \varepsilon)}{\lambda_f} \)
```

```
Air thermal resistance : \( R_a = \frac{h\varepsilon}{\lambda_a(1 - \mu)} \)
```

```
Water thermal resistance : \( R_w = \frac{h\varepsilon}{\lambda_w\mu} \)
```

其中，\( R_f \)、\( R_a \) 和 \( R_w \) 分别代表纤维、空气和水的热阻，单位为 m²·°C/W。\( \lambda_f \) 是纤维聚合物的热导率，单位为 W/(m·°C)。\( \lambda_a \) 是空气的热导率，单位为 W/(m·°C)，而 \( \lambda_w \) 是水的热导率，单位为 W/(m·°C)。\( \mu \) 是织物的含水率，单位为 %。

湿态织物的热阻可以通过将其纤维、空气和水分量的热阻以串联、并联或两者结合的方式组合来预测。基于实际中不同的串联和并联配置，Mangat 等人[3]总结了八种湿态织物热阻模型（参见公式 (6)–(13)）。通过将这些模型的预测结果与实际测量值进行比较，最终选择了相关性最好的热阻模型作为热阻的理论预测模型。八种热阻模型如下：

```
Model 1 : \( R_t = R_f + R_a + R_w \)
```

```
Model 2 : \( R_t = (R_f^{-1} + R_a^{-1} + R_w^{-1})^{-1} \)
```

```
Model 3 : \( R_t = \frac{R_a \cdot R_f}{R_a + R_f} + R_w \)
```

```
Model 4 : \( R_t = \frac{R_f \cdot R_w}{R_f + R_w} + R_a \)
```

```
Model 5 : \( R_t = \frac{R_a \cdot R_w}{R_a + R_w} + R_f \)
```

```
Model 6 : \( R_t = \frac{R_w(R_a + R_f)}{R_a + R_w + R_f} \)
```

```
Model 7 : \( R_t = \frac{R_a(R_w + R_f)}{R_a + R_w + R_f} \)
```

```
Model 8 : \( R_t = \frac{R_f(R_w + R_a)}{R_a + R_w + R_f} \)
```

在 Mangat 等人[3]总结的八种模型中，模型 1 和模型 2 代表 Mangat 等人[3]预测的热阻值，模型 1 和模型 2 代表纤维、空气和水直接串联和并联的预测热阻值，因此在选择最佳热阻模型时应将其排除在考虑之外。在随后的实验中，Mangat 等人验证了上述模型在不同含水率下预测单层针织织物热阻的准确性。结果表明，他们的模型组中模型 3 与测试的某种斜纹棉织物具有良好的相关性，而模型 5 和模型 7 与所有实验数据表现出最佳一致性，并适用于不同类型的针织织物。

应注意的是，Mangat 等人在空气和水热阻的计算公式中，分别使用含水率 \(\mu\) 和 \(1 - \mu\) 来表示织物间隙中水和空气的比例。根据含水率公式，它表示湿织物中水的比例。因此，使用含水率来表示织物间隙中水和空气的比例并不严谨。Mangat 等人结果中的热阻预测曲线往往低估了实际测量值，这可能是由含水率的定义引起的。在本研究中，我们遵循了 Mangat 等人的热阻预测模型框架，并使用含水饱和度来表示织物间隙中水和空气的比例，即织物能吸收的最大含水量。含水饱和度计算为测试过程中测得的水的重量与织物最大吸水重量之比。织物的最大吸水量基于浸润前后样品的重量计算，使用公式 (14) 和 (15)：

```
WAC = \frac{m_{water}}{SA} \times 100\%
```

```
\eta = \frac{m_{wet} - m_{dry}}{WAC} \times 0.09
```

其中，WAC 是织物的最大吸水量，单位为 g/m²，SA 是织物面积，单位为 m²，$m_{water}$ 是织物能吸收的最大水重量，单位为 g，$m_{wet}$ 是湿织物的重量，单位为 g，$m_{dry}$ 是超干织物的重量，单位为 g，\(\eta\) 是含水饱和度，单位为 %。织物样品均为尺寸为 0.3 m × 0.3 m 的大样品；样品总面积为 0.09 m²。

### 3.2. 样品制备

测量织物样品的最大吸水量是评估织物吸湿和存湿能力的第一步。实验方法遵循 Tang 等人[19]的方法。为确保测量前织物完全干燥，所有测试织物在烘箱中于 105 °C 下烘干 30 min，以去除多余水分并达到 Naka 等人[11]提出的“超干状态”。然后，将织物样品在去离子水中浸泡 3 min，并垂直悬挂直到 30 s 内不再有液滴滴落，表明织物已完全浸湿。

基于织物的最大吸水量、织物饱和度和织物样品面积，确定添加到织物样品中的水量。织物饱和度定义为添加水量占织物最大吸水量的百分比，反映了织物中含水饱和度的程度。由于热阻测试仪的测试时间相对较长，测试过程中测试织物的水分蒸发不仅会影响周围环境的温度和湿度，还会导致织物含水率降低。为解决此问题，采用了 Raccuglia 等人[20]提出的密封湿织物的方法。具体来说，将超干织物平放在密封袋中，量取一定量的去离子水并倒入加湿喷雾瓶中。然后将喷雾瓶悬挂在织物样品中心上方约 2 cm 处，用去离子水均匀喷洒。静置 5 min 后，一旦织物完全浸湿，即密封袋子。

此外，对超干织物和饱和度为 20%、40%、60%、80% 和 100% 的织物进行了热阻测试。如果测试样品的饱和度超过 100%，即织物与模拟皮肤之间存在过多水分，则湿度程序分两步进行，以避免因过多水分粘附在密封袋内壁而导致水分不足。首先，根据样品的最大吸水量确定添加水量，然后在进行热阻测试前使用微量移液枪将过多水分添加到样品中心。

### 3.3. 设备与方法

织物样品的热导率、热阻和隔热性能使用纺织品热传递性能测试仪（宁波纺织仪器有限公司，中国宁波，YG606E，见图 1）按照 GB/T 11048-2018《纺织品 生理影响 恒态条件下热和水汽阻力的测定（出汗守恒热板法）》[21] 进行测定。该仪器可快速测量稳态和瞬态热性能。在某种程度上，该仪器模拟了在无强制对流环境中，织物初次接触皮肤时，人体皮肤向织物传递的热流密度 q (W/m²)。织物厚度使用数字式织物厚度仪（温州互科测试仪器有限公司，中国温州，YG(B)141D）按照 GB/T 3820-1997《纺织品及纺织制品 厚度的测定》[22] 测定，表面密度使用精度为 ±0.1 g 的电子天平按照 GB/T 4743-2009《纺织品 包装纱线 络筒法测定线密度（单位长度质量）》[23] 测定。织物样品在通风烘箱（温州百恩仪器有限公司，中国温州，Y802K）中干燥，并使用手动压封机封口；还使用了加湿器。

在织物织造过程中混纺两种纤维时，混纺纤维的密度无法直接获得。但是，可以使用 Militky [24] 提出的以下方程进行估算。

```
\rho_{ab} = r\rho_a + (1 - r)\rho_b
(16)
```

其中，a 和 b 表示纤维类型，$\rho_a$ 和 $\rho_b$ 表示它们的纤维密度，$r$ 表示纤维 a 的比例，$\rho_{ab}$ 表示混纺纤维的密度。所有测试均在实验室条件下进行，温度为 20 ± 1 °C，相对湿度为 50 ± 5%，风速 < 0.4 m/s。
