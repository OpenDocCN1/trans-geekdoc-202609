

### (2) 多节点模型

多节点人体热模型是两节点模型的扩展和更复杂的版本，如图 14 所示 [115]。已提出了各种模型来预测人体热调节状态。也许最具影响力的是 Stolwijk 提出的 25 节点模型 [116]，由 24 个身体“节点”（六个身体段，每个段有四个隔室）和一个中心血液“节点”组成。每个节点都有一定量的代谢热产生、与中心血液腔的对流热交换以及与相邻节点的对流热交换。随后，一些学者也改进了这种人体热调节模型，使其适用于更广泛的场景，例如寒冷环境、空间环境等。研究人员对模型进行了各种改进，以准确预测人体不同部位的局部响应模式。Munir 等人 [117] 重新评估了 Stolwijk 模型的动态特性，并考察了模型的几种改进。

![](img/c1925febd7dde400183c23c14d668ef0_29_0.png)

图 14. 模型分段以及两节点和多节点模型的比较 [115]。

多节点模型使用偏微分方程来描述人体中的热传递问题。微分方程通常采用有限差分法、有限体积法或有限元法进行离散化，以求得每个节点的线性代数方程。多节点模型的优点是可以根据需要划分截面和节点，具有更好的灵活性和准确性，并可应用于动态、非稳态环境。缺点是，在温度梯度变化大的环境中，其精度不如多节点模型。特定模型的特性见表 8。

表 8. 特定模型的特性 [114,118]。

| 模型名称 | 模型分类 | 模型特性 |
| :--- | :--- | :--- |
| 人体热调节模型 | 两节点模型 多节点模型 | 当人体存在较大温差时，使用多节点和多单元模型可以获得更准确的仿真结果。 |
| 服装热湿传输建模 | 稳态模型 瞬态模型 | 模拟服装的热湿传输过程，以推导服装的热湿性能。 |
| 人体-服装-环境系统模型 | - | 将人体-服装环境作为一个整体，结合人体热调节模型和服装热湿传输模型。 |

### 5.3.2. 热湿管理性能评价

目前没有通用的性能评估方法可用于评估可穿戴系统在热湿管理方面的性能。可穿戴系统的性能评估涉及两个主要方面：(i) 穿着者舒适度和安全性；(ii) 可穿戴系统的功能性。Ismail 等人 [119] 通过将人体简化为带有均匀环形空气层的垂直圆柱体，研究了均匀横风对穿衣人体通风、热量和湿度传递的影响。但是，现有的评估方法发展不够充分，特别是在特定炎热潮湿条件下对可穿戴系统进行性能评估方面。由于可穿戴系统种类繁多，涉及的功能和技术各不相同，因此需要为不同类型的可穿戴系统开发特定的评估方法。这些评估方法应能全面考虑热湿对可穿戴系统舒适度和安全性的影响，并准确评估热湿调节和能量转换的性能。可穿戴系统热湿管理的现有标准评估方法见表 9 [75]。

表 9. 可穿戴系统热湿管理的现有标准评估方法。

| 热/湿度传递 | 热/湿度传递 | 指标 | 测试设备 |
| :--- | :--- | :--- | :--- |
| 人体 → 环境 | 热传递 | 热阻 | 加热平板；加热躯干；加热人体模型 |
| | 湿度传递 | 液态水传递指标 | 湿度管理测试仪 |
| | 耦合热湿传递 | 蒸发阻力 | 出汗加热平板；出汗躯干；出汗加热人体模型 |
| 环境 → 人体 | 热传递 | 水蒸气透过率 | 测试皿，天平 |
| | | 吸收热能 | 热防护性能测试仪；辐射防护测试仪；辐射防护性能测试仪 |

从热湿管理角度看，可穿戴系统的性能评估可包括以下方面：(i) 特定热湿条件下的可穿戴舒适度和安全性，需考虑热湿调节性能以及人体和环境的热湿状况；(ii) 特定热湿条件下的可穿戴功能性，包括热湿能量转换和生理感应。为了评估可穿戴系统在该等炎热潮湿条件下的性能，有必要提供标准化且可重复的评估方法，以支持可穿戴系统的开发。

我们的研究小组目前正在开发一种利用膜分离降低皮肤温度并吸收表面汗液的制冷除湿服装，从而在服装内部创造凉爽舒适的微环境。因此，未来研究应进一步探索同时调节温度和湿度的技术，以改善人体的热湿舒适度并提供更好的防护。

## 6. 结论

所提出的分析全面概述了个人热湿管理可穿戴系统，讨论了其功能、最新发展和性能评估方法。研究结果有助于理解在可穿戴系统中调节温度和湿度所涉及的挑战和注意事项。鉴于本研究，主要研究结果可总结如下：

- (1) 虽然当前制冷方法在调节环境温度方面有效，但如果制冷介质温度低于空气露点，可能会产生冷凝。

- (2) 纺织品的除湿受周围环境湿度的强烈影响。此外，当使用干燥剂吸收人体周围的水蒸气时，干燥剂会吸收水蒸气并释放潜热，导致体温升高。

- (3) 温湿度调节是一个复杂的耦合过程，目前没有通用的性能评估方法可用于评估可穿戴系统在温湿度管理方面的性能。

- (4) 解决上述问题需要综合考虑制冷和除湿因素，例如使用智能控制系统，其在维持有效除湿性能与最佳舒适度之间的微妙平衡方面发挥着至关重要的作用。
