The standard deviation was so small, with a maximum value at one point of 0.0009 and a mean value over the 14 points of 0.0005, that no boxplot was used, but the same format as in Figure 4.11 with the thresholding results. The network thus calculates stable consistent values for a given scan with the same FVC, regardless of whether it was augmented or not. This indicates a good geometric independence of the network. In addition, several runs of the CNN training were made with the same settings and the results also hardly differed, which indicates a low intrinsic uncertainty of the CNN. The biggest variation between runs was rather at which epoch the loss plot reached its minimum, which could vary by 5-10 epochs.
