```
h^{(l)} = \frac{1}{1 + \exp(-w^{(l)\tau}x)},
(2.112)
```

which translates any input between $(-\infty; \infty)$ to the range $[0; +1]$ and can therefore be thought of as a smooth version of the binary step function [205]. While the binary step function is not differentiable at $x=0$, the logistic function is differentiable infinitely many times on its entire domain [205, 206]. Owing to their effect of "squashing" the real values into a bounded interval, they are occasionally called squashing functions (cf. Figure 2.22) [205]. Hence, they can suffer from vanishing gradients, especially in deep networks [206, 207]. The logistic sigmoid function is therefore often used in rather shallow networks or often in output layers of networks due to its value distribution [206].
