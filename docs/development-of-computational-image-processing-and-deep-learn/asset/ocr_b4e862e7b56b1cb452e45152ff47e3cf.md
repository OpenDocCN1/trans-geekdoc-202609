# Binary step function

The activation function that is closest to the reaction of a biological neuron is a simple binary step function, which is either zero or positive, defined by

```
\( h^{(l)} = \left\{ \begin{array}{ll} 1 & \text{if } \boldsymbol{w}^{(l)\top} \boldsymbol{x} \ge 0, \\ 0 & \text{if } \boldsymbol{w}^{(l)\top} \boldsymbol{x} < 0, \end{array} \right. \) (2.111)
```
