In the vanilla GAN, both generator and discriminator are normal MLPs with trainable parameters \(\theta\) [143]. A value function \(V(G, D)\) is used to evaluate the cost of the training. During the training process, only the parameters of one model are updated, while the parameters of the other are fixed [239].

The MLP representing the generator \(G\) is a differentiable function with parameters \(\theta_G\). In order to learn the distribution \(p_g\) over real data \(\boldsymbol{x}\), a mapping of the input noise variables \(p_z(\boldsymbol{z})\) to the data space, \(G(\boldsymbol{z}, \theta_G)\), is required. The second MLP representing the discriminator, \(D(\boldsymbol{x}, \theta_D)\) outputs a single scalar. \(D(\boldsymbol{x}) \in [0, 1]\) describes the probability that \(\boldsymbol{x}\) came from the training data and not the distribution of the generator \(p_g\). [143] Hence, the generator is trained to maximize the probability \(D(G(\boldsymbol{z}))\) or to minimize \(\log(1 - D(G(\boldsymbol{z}))\) leading to the following equation for the training of the generator, while the discriminator is fixed:

\(\min_G V(D, G) = \mathbb{E}_{\boldsymbol{z} \sim p_z(\boldsymbol{z})} [\log(1 - D(G(\boldsymbol{z})))] \ [143]. \quad (2.121)\)

The expectation operator \(\mathbb{E}\) denotes the expected value of the specific distribution function [179]. The parameters \(\theta_G\) are updated by calculating and subsequently descending the stochastic gradients based on this equation. [143]

The discriminator is provided with samples from the unknown input distribution \(p_{\text{data}}(\boldsymbol{x})\) and the (at the training time of the discriminator) fixed generator samples. Hence, the value function is given by

\(\max_D V(D, G) = \mathbb{E}_{\boldsymbol{x} \sim p_{\text{data}}(\boldsymbol{x})} [\log D(\boldsymbol{x})] + \mathbb{E}_{\boldsymbol{z} \sim p_z(\boldsymbol{z})} [\log(1 - D(G(\boldsymbol{z})))] \ [143]. \quad (2.122)\)

The discriminator parameters get updated analogously by ascending the stochastic gradient based on this equation.
