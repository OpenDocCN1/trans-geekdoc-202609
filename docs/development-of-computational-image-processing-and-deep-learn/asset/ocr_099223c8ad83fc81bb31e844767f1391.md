# 2. Resizing

All data used to train the CNN should be of the same shape so that one input size of the network can be established. Furthermore, reshaping all arrays into cubes adds an additional possible axis to rotate the data by without changing its shape. That allows for an additional augmentation step and thus doubles the amount of input data after augmentation.
