In the index notation, the base \(\boldsymbol{e}_i\) has been omitted respectively. In practice, after the orientation of \(N\) fibers is measured in a region of interest, e.g., through image-processing of \(\mu\)CT images, the orientation tensors of second- and fourth- order can be calculated via

```
$$
\boldsymbol{A} = \frac{1}{N} \sum_{i=1}^N (\boldsymbol{p} \otimes \boldsymbol{p})_k ,$$

$$
A_{ij} = \frac{1}{N} \sum_{i=1}^N (p_i p_j)_k ,$$

$$
\mathbb{A} = \frac{1}{N} \sum_{i=1}^N (\boldsymbol{p} \otimes \boldsymbol{p} \otimes \boldsymbol{p} \otimes \boldsymbol{p})_k ,$$

$$
A_{ijkl} = \frac{1}{N} \sum_{i=1}^N (p_i p_j p_k p_l)_k \, \text{[88, 89].}$$

(2.50)
```
