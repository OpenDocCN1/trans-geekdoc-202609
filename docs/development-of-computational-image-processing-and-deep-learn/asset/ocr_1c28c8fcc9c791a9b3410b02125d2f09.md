# ## Parametrization of FOT

Any FOT of second order \(\mathbf{A}\) is symmetric (see Equation (2.51)), and positive semi-definite as all of its eigenvalues are non-negative, \(\lambda_i \ge 0\) (cf. Equation (2.46)). Consequently, it can be rotated in a way that only the diagonal of the matrix is populated, hence it can be diagonalized. This so-called eigendecomposition of a matrix is defined as such

```
\(\mathbf{A} = \mathbf{R} \unknown \mathbf{R}^T = \mathbf{R} \star \unknown,\) (2.56)
```

with \(\mathbf{R} \in SO(3)\) being an orthogonal matrix (\(\mathbf{R}\mathbf{R}^T = \mathbf{R}^T \mathbf{R} = \mathbf{I}\) holds), whose \(i\)-th column is the eigenvector \(\mathbf{v}_i\) of \(\mathbf{A}\) (the three eigenvectors are orthonormal to each other) and is sometimes called rotation matrix for aforementioned reasons. \(\unknown\) is the diagonal matrix with the corresponding eigenvalues \(\unknown = \mathbf{I}\lambda\) with \(\lambda = [\lambda_1, \lambda_2, \lambda_3]^\mathsf{T}\).
