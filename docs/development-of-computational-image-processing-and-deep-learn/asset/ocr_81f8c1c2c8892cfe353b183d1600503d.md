# ## Erosion

Erosion (cv.erode) is like the antagonist of dilation computing a local minimum across the area of the given kernel:

```
(I \ominus X)(x, y) = min { I(x+s, y+t) - X(s, t) | (s, t) \in D_x }. [280, 281] (3.2)
```

It can be seen in Figure 3.8 that by applying dilation to the scan image, the pores can be filled in. However, the edge also expands beyond the edge of the actual plastificate. A subsequent erosion operation can reverse this expansion of the edge. The result is an image which (apart from small errors at the edge) has segmented the plastificate quite well.
