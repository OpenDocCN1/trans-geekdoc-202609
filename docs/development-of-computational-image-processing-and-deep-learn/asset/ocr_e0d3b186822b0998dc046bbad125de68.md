First of all, it is assumed that the orientation of a fiber in any coordinate system can be described by a unit vector \(\boldsymbol{p} \in \mathcal{S}\), where \(\mathcal{S} = \{ \boldsymbol{p} \in \mathbb{R}^3 \mid \| \boldsymbol{p} \| = 1 \}\). \(\mathcal{S}\) denotes the two-dimensional unit sphere as the set of all possible directions of \(\boldsymbol{p}\). The components of \(\boldsymbol{p}\) can be determined using the angles that the fiber makes with the axes of the coordinate system (cf. Figure 2.6) using trigonometric functions as follows:

```
p_1 = \sin \theta \cos \phi
p_2 = \sin \theta \sin \phi
p_3 = \cos \theta.
(2.42)
```
