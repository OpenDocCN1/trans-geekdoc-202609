A denotes the tensor containing the eigenvalues on the principal diagonal and **R** is defined as the orthogonal rotation matrix consisting of the normalized eigenvectors.

**Orientation** The rotation matrix **R** can be interpreted as a rotation around a rotation axis and can therefore be transformed into a quaternion as described in the State of the Art:

```
q = a + bi + cj + dk,
q = \cos \frac{\theta}{2} + (u_x \boldsymbol{i} + u_y \boldsymbol{j} + u_z \boldsymbol{k}) \sin \frac{\theta}{2},
```

with rotation axis: \(\boldsymbol{u} = (u_x, u_y, u_z)^T\) and rotation angle \(\theta\).

The quaternion is calculated from the given rotation matrix \(\boldsymbol{R}\) via:

```
t = \text{tr}(\boldsymbol{R}), \quad r = \sqrt{1+t} \quad \text{and} \quad a = \frac{r}{2} \quad \text{with}
b = \text{sgn}(R_{zy} - R_{yz}) \left| \frac{1}{2} \sqrt{1 + R_{xx} - R_{yy} - R_{zz}} \right|,
c = \text{sgn}(R_{xz} - R_{zx}) \left| \frac{1}{2} \sqrt{1 - R_{xx} + R_{yy} - R_{zz}} \right|,
d = \text{sgn}(R_{yx} - R_{xy}) \left| \frac{1}{2} \sqrt{1 - R_{xx} - R_{yy} + R_{zz}} \right|.
```
