Based on the premise that stress is defined by

```
\(\sigma = \frac{F}{A},\)
(2.7)
```

the force equilibrium

```
\(F_c = F_m + F_f\)
(2.8)
```

can be rewritten with the help of Equation (2.6) as

```
\(E_c \varepsilon_c A_c = E_m \varepsilon_m A_m + E_f \varepsilon_f A_f\)
(2.9)
```

and further as

```
\(E_c = E_m \frac{A_m}{A_c} + E_f \frac{A_f}{A_c}.\)
(2.10)
```
