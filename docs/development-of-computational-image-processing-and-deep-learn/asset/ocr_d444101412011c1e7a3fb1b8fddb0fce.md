The fiber orientation distribution function (FODF) \(\psi : \mathcal{S} \rightarrow \mathcal{P}\) describes the probability of finding a fiber in direction \(\boldsymbol{p}\) with \(\mathcal{P} = \{ \psi \in \mathbb{R} \mid 0 \le \psi \le 1 \}\) [43]. \(\psi\) is defined in a way that the probability of finding a fiber between angles \(\theta_1\) and \((\theta_1 + d\theta)\) as well as between \(\phi_1\) and \((\phi_1 + d\phi)\) is given by

```
\(\mathcal{P}(\theta_1 \le \theta \le \theta_1 + d\theta, \phi_1 \le \phi \le \phi_1 + d\phi) = \psi(\theta_1, \phi_1) \sin \theta_1 d\theta d\phi\) [43].
(2.44)
```

In practice, the distribution of orientations can be given in the form of a histogram as a discrete approximation to the underlying probability density function for orientation [88] (as can be seen in Figure 4.33 on the right side).

The function \(\psi(\boldsymbol{p})\) has to fulfill multiple mathematical conditions. First of all, fibers have an orientation but do not have a direction [85] meaning a fiber with angles \(\theta, \phi\) is identical to one with angles \(\pi - \theta, \phi + \pi\) to the function [43]. In other words, the beginning and end of a fiber cannot be distinguished [86]. Hence, \(\psi(\boldsymbol{p})\) is periodic and therefore a symmetric function

```
\(\psi(\boldsymbol{p}) = \psi(-\boldsymbol{p}).\)
(2.45)
```

The function \(\psi(\boldsymbol{p})\) is also non-negative [85]:

```
\(\psi(\boldsymbol{p}) \ge 0.\)
(2.46)
```

Secondly, \(\psi(\boldsymbol{p})\) has to be normalized as every fiber has an orientation [43], i.e.,

```
\(\int_{\theta=0}^{\pi} \int_{\phi=0}^{2\pi} \psi(\theta, \phi) \sin \theta d\theta d\phi = \oint \psi(\boldsymbol{p}) d\boldsymbol{p} = \int_S \psi(\boldsymbol{p}) dp = 1,\)
(2.47)
```
