本章讨论主机安全，这是**纵深防御**的关键组成部分。多年前，边界安全和在计算机上安装防病毒软件可能就足够了。现在情况已不再如此。如今，每当用户打开计算机、点击链接或打开电子邮件时，都可能发生攻击。这就是为什么基于主机的解决方案（如反恶意软件、防病毒和反间谍软件）对纵深防御策略如此重要的原因。虽然这些项目是解决方案的一部分，但良好的逻辑安全就像良好的物理安全一样，需要主机加固。逻辑安全不要求你在计算机周围建起 10 英尺高的混凝土墙，但它确实要求你以一种让攻击者工作更困难的方式来加固主机。这项工作始于移除不需要的服务。它还包括实施安全策略和控制。最后，它关乎最小权限原则的建立；仅提供用户完成手头任务所需的内容，不提供更多，同时保持安全基线。

在本章中，我们将研究端点安全和主机加固。我们将探讨资产管理、入侵检测和入侵防御所扮演的角色等主题。CompTIA 要求你为考试了解这些主题。你可能会遇到场景题、模拟题，甚至拖放题，要求你正确放置所需的控制和对策。

## 防火墙和网络访问控制

防火墙可以是硬件、软件或两者的组合。防火墙通常位于受信和不受信网络元素之间的分界线上。防火墙在重要资产的隔离中起着关键作用。典型防火墙放置示例可见 [Figure 4.1](#c04.xhtml#c04-fig-0001)。

![FIGURE 4.1 Firewall placement and design](images/c04f001.jpg)

[**FIGURE 4.1**](#c04.xhtml#c04-fig-anc-0001) Firewall placement and design

防火墙规则决定检查何种类型的流量、允许何种流量通过以及阻止何种流量。配置防火墙规则最基本的方法是通过访问控制列表（`ACL`）。`ACL` 用于数据包过滤，并用于选择要由防火墙或设备分析、转发或以某种方式影响的流量类型。`ACL` 是数据流执行的基本示例。简单的防火墙，更具体地说是 `ACL` 配置，可能会根据源地址和目标地址阻止流量。然而，更高级的配置可能会根据接口、端口、协议、阈值和各种其他标准拒绝流量。在实施 `ACL` 之前，请务必对网络和安全组件执行安全配置和基线化。放置在 `ACL` 中的规则不仅可用于允许或阻止流量。例如，规则还可用于记录活动以供日后检查或记录警报。示例规则集如 [Table 4.1](#c04.xhtml#c04-tbl-0001) 所示。

[**TABLE 4.1**](#c04.xhtml#c04-tbl-anc-0001) Basic rule set

| Rule 50 | Allow | HTTP, HTTPS | 80, 443 | Outbound | None |
