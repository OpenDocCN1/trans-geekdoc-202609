

## 2. 关闭所有正在运行的程序

您运行的程序越多，可供其他程序使用的内存就越少。安装程序通常会更新文件和程序；因此，如果您让其他程序保持运行状态，安装可能无法正常进行。

## 3. 让您当地的电脑店为您的电脑增加内存

坦白说，这是一个激进且颇具成本的步骤。然而，增加内存确实可以提高电脑的运行速度，并允许同时运行更多程序。
