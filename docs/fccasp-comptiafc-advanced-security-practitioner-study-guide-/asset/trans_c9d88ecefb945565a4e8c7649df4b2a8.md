## 企业安全

*企业安全* 一词是指对安全的整体观。多年来，我们对 IT 安全的看法发生了变化，数据安全、IT 安全和物理安全等项目现在被视为完整安全解决方案的组成部分。企业安全是一个框架，用于应用全面的控制措施，旨在保护公司，同时将关键服务映射到所需的信息系统。企业安全的目标如下：

*   为公司增加价值
*   使 IT 目标与公司目标保持一致
*   建立问责制
*   验证是否已建立责任金字塔，从最底层的员工开始，逐级向上延伸至高层管理人员。

在过去十年中，企业安全变得更加重要。考虑到安全漏洞的数量和糟糕安全管理的报告数量，原因显而易见。

从最基本的层面来看，企业安全基于机密性、完整性和可用性。这三个概念是信息安全的核心。*机密性* 确保只有授权主体才能访问信息和数据。*完整性* 确保数据未被修改且正确可信。*可用性* 意味着拥有访问权限的人可以使用信息或服务，而其他未经授权的主体不应能使这些项目不可用。其他关键安全服务包括保护机制（如身份验证和授权）；检测服务（如监控和审计）；以及事件响应和取证。[图 3.1](#c03.xhtml#c03-fig-0001) 展示了企业安全的一些常见组件。
