任何生物识别系统的最终考量因素是用户接受度和易用性。系统的可接受性取决于用户如何看待它。例如，虹膜扫描被认为比视网膜扫描更准确。这是因为视网膜可能会因糖尿病和怀孕等状况随时间发生变化。视网膜扫描对用户来说也更具侵入性，因此使用频率较低。用户教育很有帮助，因为许多人担心视网膜或虹膜系统会损害他们的眼睛，或者他们的信息得不到充分保护。

为确保生物识别系统可用，必须检查处理时间和环境。生物识别中一个不常被讨论的方面是生物识别数据管理和退役。生物识别数据需要进入系统数据库，即使采用专有数据库格式，存储人们的生物识别数据也存在额外风险。随着更多生物识别系统的推出，这种风险将在未来增加。生物识别系统也需要安全退役，以确保个人的生物识别信息永不泄露。

管理大量密码的另一种方法是单点登录。单点登录（SSO）旨在通过允许用户向单一认证机构进行一次认证，随后无需重新认证即可访问其他受保护资源，来解决这一问题。一种备受关注的单点登录形式是由美国商务部支持的版本，称为网络空间可信身份国家战略（NSTIC）。该提案规定了一种单点登录，每次计算机或手机开机时都会使用，采用数字令牌、智能卡或指纹阅读器等设备。有人认为此计划可能具有侵入性，而另一些人则将其视为消除当今密码诸多问题的手段。[练习 8.3](#c08.xhtml#c08-ex-03) 演示了密码认证的弱点。

### Technology Evolution (RFCs, ISO)
你是否想过谁在管理互联网？有几个机构负责此事。首先是互联网协会（ISOC）。ISOC 负责互联网技术标准，并充当互联网信息和教育的全球交换中心。向 ISOC 汇报的实体包括互联网架构委员会（IAB）、互联网工程指导组（IESG）、互联网工程任务组（IETF）、互联网研究指导组（IRSG）、互联网研究任务组（IRTF）和征求意见稿（RFC）小组。

IAB 负责协议和标准，并管理 IETF。IETF 的职责是监督创建指导互联网如何设计、使用和管理的技术文档。这项使命的很大一部分集中在创建 RFC 上，RFC 作为互联网的“行为准则”白皮书。RFC 描述了互联网技术实践的方法、行为、研究和创新。创建 RFC 时，会分配一个永不改变的编号。发布新技术时，会先创建一个互联网草案作为新 RFC，然后将其最终确定为 RFC。此时，旧的 RFC 可能会变得过时。此流程不同于 ISO 等其他组织。一些知名的 RFC 及其标题如[表 8.1](#c08.xhtml#c08-tbl-0001)所示。

国际标准化组织（ISO）将自己描述为“由 162 个国家标准机构组成的网络，每国一名成员，中央秘书处设在瑞士日内瓦，协调连接公共和私营部门的体系”。

CASP 应了解几份 ISO 文档。其中之一是 ISO 15408。ISO 15408 经过多年的起草于 1997 年首次发布，当前为 3.1 版，更广为人知的名称是通用准则。通用准则旨在为表达产品和系统 IT 安全需求提供通用结构和语言。它是供应商描述其产品能力以及买家测试此类产品以确保其满足特定需求的一种方式。通用准则文档的一大成就是弥合了早期文档（如 ITSEC 和 TCSEC）之间的差距。通用准则保证了计算机安全产品的规范、实现和评估过程已以严格且标准的方式进行。因此，通用准则可在全球范围内使用，并对更广泛的受众具有意义。[表 8.2](#c08.xhtml#c08-tbl-0002) 给出了通用准则评估保证级别（EAL）的一些示例。
