## Answers to Assessment Test

### 1. Buffer Overflows
**C.** The `C` programming language is particularly vulnerable to buffer overflows. This is because some functions do not perform proper bounds checking (Chapter 5).

### 2. Security Tenets
**B.** Nonrepudiation is not considered one of the three basic tenets of security (Chapter 3).

### 3. Pre-employment Process
**B.** Many organizations start the pre-employment process with a background check. This process is done to make sure the right person is hired for the job (Chapter 7).

### 4. Cryptography Definition
**A.** In cryptography the process of converting clear text into something that is unreadable is known as encryption (Chapter 2).

### 5. Connection-based Protocol
**B.** TCP is considered a connection-based protocol, whereas UDP is considered connectionless (Chapter 1).

### 6. Cloud Computing Costs
**C.** Although there are many benefits to cloud computing, increased cost is not one of them. Cloud computing is designed to lower costs (Chapter 3).

### 7. ACLs and Routers
**D.** The term `ACL` is most closely related to a router. ACLs are used as a basic form of firewall (Chapter 4).

### 8. Cookies
**B.** A cookie is used to maintain state when moving from one web page to another (Chapter 5).

### 9. Cryptography Authenticity
**B.** In the study of cryptography, authenticity is used to prove the identity of an individual (Chapter 1).

### 10. Backtrack
**A.** Backtrack is an example of a Linux bootable distribution. It is one of the items on the CASP tools and technology list (Chapter 8).

### 11. HTTP Protocol
**A.** HTTP is the basic transport protocol for the Web. HTTP uses TCP as a transport (Chapter 5).

### 12. Denial of Service
**D.** A denial of service does not give an attacker access but blocks legitimate users (Chapter 6).

### 13. IPv4 Address Length
**C.** IPv4 uses 32-bit addresses, whereas IPv6 uses 128-bit addresses (Chapter 1).

### 14. IMAP vs POP3
**D.** IMAP can be used as a replacement for POP3 and offers advantages over POP3 for mobile users (Chapter 10).

### 15. HTTP Default Port
**C.** HTTP uses port 80 by default (Chapter 4).

### 16. Service Level Agreements
**B.** A service level agreement (SLA) requires the provider to maintain a certain level of support (Chapter 6).

### 17. SPIT
**B.** SPIT is the name given to Spam over Internet Telephony (Chapter 10).

### 18. Policy Documents
**C.** A policy is a high-level document used by management to set the overall tone (Chapter 7).

### 19. Symmetric Encryption
**C.** DES makes use of a single shared key and is an example of symmetric encryption (Chapter 2).

### 20. Separation of Duties
**B.** Separation of duties prevents one individual from having too much power (Chapter 9).

### 21. Virtualization Example
**A.** VMware is an example of virtualization. These tools are very popular today and are required knowledge for the CASP exam (Chapter 3).

### 22. Wireshark
**A.** Wireshark is a well-known open source packet capture and sniffer program (Chapter 8). Although packet sniffers are not malicious tools, they can be used to capture clear-text usernames and passwords.

### 23. PCI Compliance
**B.** One area of policy compliance that many companies need to address is in meeting the Payment Card Industry (PCI) data security standards (Chapter 7).

### 24. OSI Model Layers
**C.** The OSI model consists of seven layers: physical, data link, network, transport, session, presentation, and application (Chapter 1).
