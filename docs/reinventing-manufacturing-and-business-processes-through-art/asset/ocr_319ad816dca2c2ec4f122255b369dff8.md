# 7.4.1 PROBLEM DEFINITION

The objective of using IoT in industries differs from industry to industry. Lower production rate, poor quality, on-time delivery, downtime of machine tools, and many more are the most significant issues of project-based industry, where a wide variety of products exists. It is vital to identify the list of problems industries want to be addressed with the help of IoT. The list of the problem must be shortlisted.

# 7.4.2 DATA COLLECTION

The main objective of the application of IoT in machining is for automation, processing monitoring and control, and predictive maintenance (Benardos and Vniakos, 2017). It is essential to shortlist tentative responsible parameters to control the variety of data. Filtration of the parameters takes place in the preprocessing stages using various data preprocessing algorithms. After identifying the required parameter, the next step is to collect the data. The data collection can take place in the following different ways.

# 7.4.2.1 Automatic

The majority of the parameters collection should be done in automatic for high accuracy.
The temperature, vibration, speed, etc., can be collected automatically by the help of sensors. RFID can be used to identify the machine tool or product automatically.

# 7.4.2.2 Semi-Automatic

Some of the parameters cannot be collected solely from sensors, mainly in the job production system. Such parameters can be stored using the human-machine interface (HMI). In HMI, the operator needs to provide input. Due to human interaction, data is less accurate.
Collected data can be classified into three categories: 1) structured data, 2) unstructured data, and 3) semi-unstructured data. Sensor and RFID data in Microsoft Excel form are an example of structured data, while video, audio and images are examples of unstructured data. XML and JSON files are examples of semi-structured data. The biggest challenge to send the data to the server is high volume, high verity and high velocity.
