# 3.3.4 MACHINE LEARNING PROGRAMMING USING PYTHON

Python is an interpreter, high-level and object-oriented programming language. Python data structures, combined with dynamic binding and dynamic typing, makes it very attractive for RAD (rapid application development). Python language is easy to learn and simple syntax emphasizes readability. Features of language reduce the cost of program maintenance. Python is also used as scripting as well as a backend language to connect existing components together. Python encourages code reuse and program modularity by modules and packages. The Python interpreter and its extensive standard library are freely distributed and available in source or binary format without charge for all major platforms. Python libraries have prebuilt functions for artificial intelligence, machine learning, numerical calculations, graph plotting, computer vision and many more.
