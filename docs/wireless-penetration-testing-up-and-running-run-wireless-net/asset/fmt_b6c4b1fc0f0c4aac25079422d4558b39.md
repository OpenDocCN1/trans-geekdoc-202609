
因为黑客很少以软件漏洞为目标，所以它们的危害性比操作系统缺陷要小。即便如此，某些程序缺陷（如 Internet Explorer 或 Microsoft Office 中的缺陷）也可能构成重大危害。补丁一旦发布，这些漏洞就会通过 Windows 更新例行修复。Microsoft Update、Windows Update 和 Office Update 都提供安全升级。您可以通过搜索关键字 `security update` 轻松找到它们。例如，如果 Nessus 在您的 Windows 系统上将 MS07-036 识别为漏洞，您可以搜索该安全公告编号，然后下载所有可用更新来修补您的计算机。谈到程序漏洞，您应始终检查并尽快下载最新的软件升级。

# 客户端攻击是如何工作的？

要完全理解客户端攻击的运作方式，我们必须首先考察服务器端攻击与客户端攻击的区别。如[图 7.1](#c07.xhtml#fig7_1)所示，客户端通过各种应用程序和服务与服务器连接。这些服务器服务可供已向其提供服务的客户端使用，以尝试利用漏洞。随着服务器上启动的服务越多，其面临的攻击风险就越大：

![](images/Figure-7.1.jpg)

**图 7.1：** 客户端攻击

客户端攻击不同于服务器端攻击。这些攻击旨在利用与恶意服务器交互的客户端应用程序中的缺陷。如果客户端未连接到服务器，则不会处理来自服务器的任何内容，因此不面临风险。由于大多数客户端均自动配置为连接到服务器，即时通讯应用程序可能会使客户端面临攻击，如[图 7.2](#c07.xhtml#fig7_2)所示：

![](images/Figure-7.2.jpg)

**图 7.2：** 客户端攻击场景 1

最常见的客户端攻击发生在用户访问针对其 Web 浏览器应用程序的恶意网页时。如果攻击成功，攻击者可以轻松控制客户端。除了基于 Web 的攻击外，还有通过电子邮件、即时通讯和 FTP 发起的攻击，如[图 7.3](#c07.xhtml#fig7_3)所示：

![](images/Figure-7.3.jpg)

**图 7.3：** 客户端攻击场景 2

只有提供防御措施时，客户端才受到保护。防火墙和代理将网络流量限制为仅受信任的网站和服务器。硬件防火墙（如 WatchGuard 的 XTM 800 系列）包含数据包过滤、入侵防御服务和应用程序控制。如果您的企业网络没有硬件防火墙，所有系统和设备都将面临风险。

# 客户端攻击的类型

客户端攻击利用用户对其访问的网站或服务器的信任，如[图 7.4](#c07.xhtml#fig7_4)所示：

![](images/Figure-7.4.jpg)

**图 7.4：** 客户端攻击示例

以下是最典型的客户端攻击类型：

*   **欺骗：** 让用户相信网站或服务器是真实的行为。
