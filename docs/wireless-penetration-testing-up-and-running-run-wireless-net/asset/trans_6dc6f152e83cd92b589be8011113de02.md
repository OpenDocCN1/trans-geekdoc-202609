## 配置接入点设置

我们现在要设置接入点。如前所述，本书中的所有实验都将使用 NETGEAR D1500 无线路由器进行。不过，你也可以使用任何其他接入点。核心操作和使用原则保持不变。

我们将配置接入点使用开放式认证，SSID 为 Wireless Lab。请遵循以下步骤：

1. 打开接入点电源后，使用网线将笔记本电脑连接到接入点的一个以太网端口。

2. 在浏览器中输入接入点配置终端的 IP 地址。NETGEAR 的默认 IP 地址为 `192.168.1.1`。你的接入点 IP 地址可以在接入点的设置指南中找到。如果你没有接入点的说明书，可以使用 Web 浏览器访问 **[http://routerlogin.net](http://routerlogin.net)**。接入点的 IP 地址通常用作网关 IP 地址。连接成功后，你应该会看到如下所示的配置门户。请参阅 *[图 1.21](#c01.xhtml#fig1_21)*：

![](images/Figure-1.21.jpg)

**图 1.21：** 无线路由器登录

默认情况下，用户名和密码均为 admin。如果你无法访问，必须将路由器重置为默认配置设置。为此，按住无线路由器背面的按钮 5 秒钟，路由器将恢复默认设置。

3. 要将 SSID 重命名为 `Wireless Lab`，请导航到 `Wireless` 选项卡，然后选择 `Wireless Settings`。请参阅 *[图 1.22](#c01.xhtml#fig1_22)*。

4. 如前所述，必须将接入点的安全设置更改为 `Open Authentication`。从 `Wireless` 菜单中选择 `None`，然后选择 `Security` 选项。如果安全功能被禁用，则接入点处于 `Open Authentication Mode`（开放式认证模式）（请参阅 *[图 1.22](#c01.xhtml#fig1_22)*）。

5. 保存对接入点的更改，如有必要则重启它。你的接入点现在应该可以使用 SSID Wireless Lab 正常工作了。

![](images/Figure-1.22.jpg)

**图 1.22：** 无线路由器设置

我们已成功将接入点配置为 Wireless Lab SSID。它正在广播其存在，这被我们的 Windows 笔记本电脑和其他处于接入点**射频**（**RF**）范围内的设备检测到。

值得注意的是，我们将接入点设置为 `Open` 模式，这是安全性最低的选项。目前，不建议将此接入点连接到互联网，因为 RF 范围内的任何人都能利用它访问互联网。
