
帧是由网络划分成的小块信息片段。数据包包含在这些帧中。攻击者可能以帧、数据包或两者为目标。

如果网络未遵循最新的无线加密标准，攻击者可以利用帧来检测该区域的隐藏无线网络并获得未经授权的访问。网络管理员使用这些方法来调试网络故障。

# Wireshark 应用程序

Wireshark 是一款免费且开源的数据包分析器。它用于排查和分析网络。它能详细捕获并显示网络数据包。网络和安全管理员使用 Wireshark 来诊断网络和安全问题。

多年前，有各种工具可供使用，但它们的使用成本都相对较高。Wireshark 通过免费向公众提供自身改变了这一现状。Wireshark 是目前可用的最强大的开源数据包分析器之一。

Wireshark 有多种用途。网络管理员将使用它来发现和排查网络问题。网络安全工程师可以调查安全问题。开发人员可以调试协议实现。用户可以很好地理解网络协议的工作原理，以及攻击者可能如何破坏它们。

在现实世界中，Wireshark 对于查看实时数据包以诊断 Web 应用程序问题、身份验证问题（如三次 TCP 握手）和审计特别有用。Wireshark 会告诉你数据包来自何处、要去往何处以及它们的用途。

例如，你可以查看某个用户是否比其他人使用了更多的网络流量。在工作时间，该用户可能在大量下载或观看 YouTube 视频。你可以限制该用户的带宽，以免网络因其而为其他所有人变慢。

Wireshark 是一款可在 Windows、Mac OS X 和 Linux 上运行的网络协议分析器。有关功能和支持的更多信息，请访问 [https://www.wireshark.org/](https://www.wireshark.org/)。Wireshark 预装在 Kali Linux 上，因此你无需安装它。不过，你可能需要在所需的任何操作系统上安装它。还有其他网络协议分析器工具，如 SolarWinds 深度包检测和分析工具、NetFlow 分析器和 PRTG Network Monitor。

# Ettercap

Ettercap 通过中间人攻击来冒充路由器或服务器。

攻击者可将 Ettercap 用于以下目的：

*   篡改数据
*   收集 FTP、HTTP、POP 和 SSHv1 等协议的密码
*   在 HTTPS 会话中伪造 SSL 证书

在 ARP 欺骗之后，我们将在本 Ettercap 演示中把 Kali Linux 系统定位为 `man-in-the-middle`（中间人）。让我们开始吧！

1.  打开一个 bash 终端并输入 `ettercap –G` 以图形模式启动 Ettercap，如 [图 3.16](#c03.xhtml#fig3_16) 所示。选择 `Primary Interface`（主接口）`wlan0`，然后接受设置：

    ![](images/Figure-3.16.jpg)

    **图 3.16：** Ettercap

2.  选择 `Hosts`（主机），然后从下拉菜单中选择 `Scan for hosts`（扫描主机），如 [图 3.17](#c03.xhtml#fig3_17) 所示：

    ![](images/Figure-3.17.jpg)

    **图 3.17：** 扫描主机

3.  点击 `Hosts`（主机），然后点击 `Hosts list`（主机列表），如 [图 3.18](#c03.xhtml#fig3_18) 所示：

    ![](images/Figure-3.18.jpg)

    **图 3.18：** 主机列表

4.  选择路由器的 IP 地址后添加到 `Target 1`（目标 1）。如果你想以另一台路由器或服务器为目标，从列表中选择另一个 IP 地址并点击 `Add to Target 2`（添加到目标 2），如 [图 3.19](#c03.xhtml#fig3_19) 所示：

    ![](images/Figure-3.19.jpg)

    **图 3.19：** 添加目标

    如果你不选择任何内容，整个子网都将遭受 ARP 投毒。**切勿在生产网络上执行此操作！** 本示例中使用的路由器 IP 地址为 `192.168.1.1`。

5.  然后转到 `Mitm`，再选择 `ARP poisoning`（ARP 投毒），如 [图 3.20](#c03.xhtml#fig3_20) 所示：

    ![](images/Figure-3.20.jpg)

    **图 3.20：** ARP 投毒

6.  勾选 `Sniff remote connections`（嗅探远程连接）复选框，如 [图 3.21](#c03.xhtml#fig3_21) 所示：

    ![](images/Figure-3.21.jpg)

    **图 3.21：** 嗅探远程连接

7.  点击 `Start`（开始），然后点击 `Start Sniffing`（开始嗅探），如 [图 3.22](#c03.xhtml#fig3_22) 所示：

    ![](images/Figure-3.22.jpg)

    **图 3.22：** 开始嗅探

现在子网已陷入中间人攻击，攻击者只需对子网发起修改过的或过滤后的攻击即可。这些过滤器可与 Ettercap 的插件配合使用，或从头构建。常见的攻击如 DNS 欺骗、FTP 提示篡改和 SSH 降级攻击均发生于此。最终用户将完全不知情。网络管理员可以使用 Wireshark 找出数据包的来源并追踪攻击者的 IP 地址。作为一条规则，请勿使用默认或自动安全设置。强制实施最高级别的安全性，并教育员工遵循安全最佳实践。

# dsniff

dsniff 是一款功能强大的密码嗅探器，可检测多种网络协议，包括 Telnet、FTP、SMTP、POP3、IMAP、HTTP、CVS、Citrix、SMB、Oracle 等。虽然 Wireshark 可以揭示关于数据包的大量信息，但 dsniff 可以揭示用户名和密码。你可以选择要监听的接口，并将结果保存为稍后可读的文件格式。让我们看几个使用 dsniff 的示例，如 [图 3.23](#c03.xhtml#fig3_23) 所示：

![](images/Figure-3.23.jpg)

**图 3.23：** dsniff 工具

执行以下步骤：

1.  打开一个新的终端窗口。
2.  输入以下命令：`dsniff -i wlan0`。选项 `-i` 是网络接口，我们选择了 `wlan0`，如 [图 3.24](#c03.xhtml#fig3_24) 所示：

    ![](images/Figure-3.24.jpg)

    **图 3.24：** dsniff -i wlan0 命令

3.  使用前面提到的几乎任何系统协议的账户登录，如 [图 3.25](#c03.xhtml#fig3_25) 所示：

    ![](images/Figure-3.25.jpg)

    **图 3.25：** FTP 协议

4.  如果你回到另一个终端，你应该会注意到 dsniff 已暴露你的登录凭据，如 [图 3.26](#c03.xhtml#fig3_26) 所示：

    ![](images/Figure-3.26.jpg)

    **图 3.26：** dsniff 输出

如果有人在未使用加密的情况下登录，dsniff 将捕获登录凭据。因此，强烈建议在可用时始终使用加密。请确保你使用的是最新的 TLS 标准和带有 2048+ 位密钥的优秀安全证书。然而，如果你正在配置服务器，请将默认端口更改为独特的端口。这有助于减少潜在攻击的数量以及野外可能存在的任何安全风险。

假设你想使用 dsniff 在本地局域网上嗅探远程电脑的密码？当然，没问题！有一个叫作 arpspoof 的工具，可让你欺骗攻击计算机的 IP 地址，使其成为默认网关或发起中间人攻击。要使此攻击生效，你需要为计算机启用 IP 路由，以有效地在两台计算机系统之间建立正确的通信。
