只有基于 ARM 的硬件才能执行某些应用程序。我们可以通过从 <https://docs.google.com/file/d/0B-p1r5SNN4adcmhtaGdMVml0Qzg/edit> 获取 ARM 转换包来添加特定的软件包以解决此问题，从而防止应用崩溃，这些应用尤其会用到这些 ARM 架构。

# 为 HTTP 代理配置模拟器

这里我们假设两种测试情况：第一，通过 Wi-Fi 连接的 Genymotion Android 模拟器；第二，连接互联网的 LTE/3G/2G 设备。即使在真实设备中，情况也是一样的。

在开始为模拟器配置代理之前，让我们看看可用的各种代理工具。这些工具包括但不限于以下内容：

*   **Burp Suite：** 大多数渗透测试人员选择的代理，可从 <https://portswigger.net/burp/download.html> 下载。它有两个版本：一个是免费的，另一个用于商业用途。商业版提供多种选项，包括扫描器等。
*   **Paros Proxy：** 这个基于 Java 的开源代理专门用于查找 Web 应用程序中的弱点。可从 <https://sourceforge.net/projects/paros/files/> 下载。由于更新不够及时，它已被 OWASP ZAP 取代。不过，你仍然可以将此代理作为备用。
*   **OWASP ZAP：** 这是一个开源的集成漏洞发现工具。可从 <https://github.com/zaproxy/zaproxy/wiki/Downloads> 下载。

还有其他一些工具可供调查，例如 Context Application Tool、ProxyFuzz、Odysseus proxy、Fiddler 等。

拦截设备与服务器之间数据流有两种方法：

*   在 Wi-Fi 设置中设置代理。
*   在移动运营商设置中设置代理。

## 在 Wi-Fi 设置中设置代理

假设设备只能连接 Wi-Fi，没有使用 SIM 卡的能力：

1.  转到 `Settings` | `Wi-Fi` 并选择当前连接的 Wi-Fi。等待 30 秒后，继续查看 [图 10.48](#c10.xhtml#fig10_48) 中所示的选项：

    ![](images/Figure-10.48.jpg)

    **图 10.48：** Wi-Fi 设置

2.  导航至 `Modify Network` | `Advanced Option` | `Proxy` | `Manual`。

3.  输入代理的 IP 地址；在本例中，Burp Suite 在 `192.168.2.1` 的 `8080` 端口运行。请参阅 [图 10.49](#c10.xhtml#fig10_49)：

    ![](images/Figure-10.49.jpg)

    **图 10.49：** 代理 IP 地址和代理端口设置

4.  Wi-Fi 已成功设置为拦截代理。我们可以从 Burp Proxy [图 10.50](#c10.xhtml#fig10_50) 看到，我们可以窃听 HTTP Web 流量：

    ![](images/Figure-10.50.jpg)

    **图 10.50：** Burp Suite

如果你希望设备可通过网络访问，可以通过打开 Oracle Virtual Box 并选择 `Name of the` `VM` | `Settings` | `Network` | `Adapter 2` | `Change the NAT to Bridged` 将设置更改为桥接模式。默认情况下，Genymotion 将 Oracle Virtual Box 中的网络适配器设置配置为 NAT。

## 在移动运营商设置中设置代理

假设 Android 设备可以连接 Wi-Fi 和 SIM 卡：

1.  点击 `Settings` | `More` | `Cellular networks` | `APN` | 如 [图 10.51](#c10.xhtml#fig10_51) 所示，选择要编辑的 APN：

    ![](images/Figure-10.51.jpg)

    **图 10.51：** APN 设置

2.  设置代理的 IP 地址和端口号。

3.  你已将设备配置为连接到你的代理。

包括屏幕截图、电话选项、虚拟设备版本等在内的许多功能，在 Genymotion 免费个人版中均不可用。

# Android 渗透测试工具

有许多可用于 Android 渗透测试的工具，但让我们看看常用的前六个：

## 1. Android Debug Bridge (ADB)

**Android Debug Bridge (ADB)** 是一个用于与设备交互的命令行工具。该应用程序可以安装、调试、备份，并可以将数据推送到设备或从设备拉取数据，以及其他设备功能。请参阅 [图 10.52](#c10.xhtml#fig10_52)：

![](images/Figure-10.52.jpg)

**图 10.52：** ADB 工具

## 2. MobSF：移动安全框架

**移动安全框架** 是一个自动化的、一体化的移动应用渗透测试框架，可对运行在 Android、iOS 和 Windows 上的移动应用程序进行静态、动态和恶意软件分析。它支持二进制文件（APK、IPA 和 APPX）以及压缩的源代码，可用于 Android、iOS 和 Windows 移动应用程序的高效快速安全分析。此外，MobSF 还具有动态测试应用程序的能力，如 [图 10.53](#c10.xhtml#fig10_53) 所示。MobSF 可从 <https://github.com/MobSF/Mobile-Security-Framework-MobSF> 下载：

![](images/Figure-10.53.jpg)

**图 10.53：** MobSF 工具

## 3. Drozer

MWR Labs 创建了 Drozer，这是一个用于 Android 的全面安全和攻击框架。你可以与底层操作系统、Dalvik VM 以及其他程序员的 IPC 端点进行通信，如 [图 10.54](#c10.xhtml#fig10_54) 所示。Drozer 可从 <https://github.com/FSecureLABS/drozer> 下载：

![](images/Figure-10.54.jpg)

**图 10.54：** Drozer 工具
