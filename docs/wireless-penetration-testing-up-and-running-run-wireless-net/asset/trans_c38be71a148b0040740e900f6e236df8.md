
任何未经授权放置在网络上、因此不由网络管理员维护的无线**接入点** (**AP**) 称为流氓接入点 (AP)。流氓接入点不像普通接入点那样受到保护。它们特别危险，因为它们物理上隐藏在网络防火墙后面，允许任何有权访问该 AP 的人获得对整个网络的访问权限。流氓 AP 可以直接插入防火墙或网络交换机、墙面网口，甚至其他网络设备，并可能由攻击者恶意安装，或仅仅是由寻求自己 Wi-Fi 接入的员工安装。另一方面，流氓接入点可用于多种攻击，包括拒绝服务、数据窃取和恶意软件部署，如 *[图 2.3](#c02.xhtml#fig2_3)* 所示：

# Ad hoc 关联

Ad hoc 连接攻击是一种特别恶劣的攻击类型，攻击者（恶意用户）利用第三方合法用户作为中间人，位于攻击者设备与 AP 或其他类型网关之间。

Ad hoc 无线网络功能对于*中间设备*操作至关重要，可在 Windows 和 Linux 计算机上部署，支持在客户端设备之间建立 Ad hoc（点对点）无线链路（无需 AP 等额外网络基础设施）。你在后台所做的就是在电脑上构建一个虚拟软件 AP，第二台设备与你创建的 SSID 关联（从而有效建立无线链路）。

Ad hoc 攻击可按以下场景描述，如 *图* *2.4* 所示。假设攻击者是计算机 2、3 或 4 中的一个。计算机 1 将是受害者（中间人）。这台笔记本电脑将是运行并向周围区域提供无线连接的设备，并拥有另一个连接到有线网络以获取互联网访问的接口。

攻击者可能连接到计算机 1 的 WLAN，然后利用它通过这台受害者的电脑将所有流量路由到互联网。从互联网的角度来看，计算机 1 似乎是流量的来源！从计算机 1 到所有攻击者的无线链路不一定是 Wi-Fi 连接；它们可以是蓝牙或通信双方均支持的任何其他类型无线技术。

# MAC 地址欺骗

# 802.11 RADIUS 破解

虽然我们不常听说这种攻击，但它是一个必须讨论的重要话题。在此攻击中，攻击者使用暴力破解从 802.11 接入请求中获取 **远程认证拨号用户服务** (**RADIUS**) 密钥，用于恶意目的。在 AP 和 RADIUS 服务器之间的局域网上，任何抓包工具都能奏效。由于许多 AP、服务器甚至软件服务都会要求 RADIUS 登录，因此风险很高。如果 RADIUS 被攻破，攻击者可以访问所有需要 RADIUS 批准访问的资源。此攻击如 *[图 2.6](#c02.xhtml#fig2_6)* 所示：

# 机密性攻击

这些攻击试图拦截通过无线网络传输的私密数据，无论数据是以明文发送，还是使用 802.11 或更高层协议加密。

以下章节讨论各种机密性攻击。

# 窃听

当然，我们都明白什么是窃听，但你是否理解它在安全方面的含义？在计算机安全领域，窃听意味着捕获数据、解码数据，然后获取潜在的敏感信息。这就像偷听电话通话。你监听交谈、记录下来，然后从中提取潜在的敏感信息。Ettercap、Kismet 和 Wireshark 都能做到这一点。该攻击如 *图* *2.7* 所示：

# WEP 密钥破解

# 邪恶双生 AP

你听说过邪恶双生 AP 吗？流氓接入点就像邪恶双生 AP。为了诱使用户误以为它是受信任的无线网络，攻击者建立一个虚假的无线 AP。由于信标更快且距离更近，它们会增强信号，导致客户端瞬间连接到它们。你在实际环境中最常遇到的邪恶双生攻击场景是带有网络认证页面（Captive Portals）的场所，如星巴克、机场和酒店。这些攻击可通过 Honeypot、CqureAP、D-Link G200、HermesAP、Rogue Squadron 和 WifiBSD 等工具实施。下图描绘了一个常用工具，如 *[图 2.9](#c02.xhtml#fig2_9)* 所示：

# AP 钓鱼

为了钓取登录凭据、银行账户和信用卡详细信息，攻击者在虚假 AP 上运行一个伪造的 Web 门户或 Web 服务器。因为普通用户不会察觉到正在发生的攻击，这可以说是最危险、最可怕的攻击之一。他们会以为这是真正的网站，但攻击者只是在另一端等待他们登录，以便窃取他们的数据。这些攻击可使用 Airpwn、Airsnarf、Hotspotter、Karma 和 RGlueAP 等工具实施，如 *[图 2.10](#c02.xhtml#fig2_10)* 所示：
