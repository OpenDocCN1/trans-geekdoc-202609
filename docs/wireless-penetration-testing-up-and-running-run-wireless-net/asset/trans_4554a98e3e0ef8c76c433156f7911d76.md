
我们可以继续执行以下操作：

1.  使用 `genpmk` 工具，我们可以提前为给定的 SSID 和字典计算 PMK：

    ```
    genpmk -f <chosen wordlist> -d PMK-Wireless-Lab -s “Wireless Lab”
    ```

    这将生成 `PMK-Wireless-Lab` 文件，其中包含 PMK，如 *[图 4.19](#c04.xhtml#fig4_19)* 所示：

    ![](images/Figure-4.19.jpg)

    **图 4.19：** genpmk 命令

2.  我们现在将使用密码 `abcdefgh`（存在于字典中）构建一个 WPA-PSK 网络，并捕获其 WPA 握手包。如随附的 *[图 4.20](#c04.xhtml#fig4_20)* 所示，我们现在使用 `Cowpatty` 破解 WPA 密码：

    ```
    cowpatty -d PMK-Wireless-Lab -s “Wireless Lab” -r wpacracking-05.cap
    ```

    ![](images/Figure-4.20.jpg)

    **图 4.20：** Cowpatty 命令

    `Cowpatty` 使用预计算的 PMK 在约 6 秒内破解密钥。

3.  使用相同的字典文件，我们现在运行 `aircrack-ng`，破解操作耗时近 22 分钟。这演示了预计算带来的巨大优势。

4.  我们需要使用一个名为 `airolib-ng` 的工具，以便在 `aircrack-ng` 中使用这些 PMK，具体如下：

    ```
    airolib-ng PMK-Aircrack --import cowpatty PMK-Wireless-Lab
    ```

    其中 `PMK-Aircrack` 是待构建的兼容 `aircrack-ng` 的数据库，而 `PMK-Wireless-Lab` 是之前创建的符合 `genpmk` 规范的 PMK 数据库。请参阅 *[图 4.21](#c04.xhtml#fig4_21)*：

    ![](images/Figure-4.21.jpg)

    **图 4.21：** airolib-ng 命令

5.  我们现在将此数据库提供给 `aircrack-ng`，这将显著加快破解过程。使用以下命令，如 *[图 4.22](#c04.xhtml#fig4_22)* 所示：

    ```
    aircrack-ng -r PMK-Aircrack wpacracking-05.cap
    ```

    ![](images/Figure-4.22.jpg)

    **图 4.22：** aircrack-ng 命令

6.  其他 Kali 工具（如 `Pyrit`）可以利用多处理器平台来加速破解。例如，Intel® CoreTM i7 CPU 可以执行更快的破解操作。`-r` 选项指定 `pcap` 文件名，而我指定符合 `genpmk` 规范的 PMK 文件。在与前面工具相同的系统上，使用相同的通过 `genpmk` 准备的 PMK 文件，`Pyrit` 大约只需 3 秒即可破解密钥。

**除了上述因素外，WPA/WPA2 PSK 的长度在破解过程中起着主要作用。破解较长的密码需要更长的时间。**

# [MAC 地址欺骗](#toc.xhtml#s82a)

您可能知道 MAC 地址过滤并不完全安全。在我看来，它比 WEP 加密的效果差得多，因为它很容易被伪造。这并不是说 MAC 地址过滤没有用。它确实能过滤掉许多只对最薄弱环节网络感兴趣的攻击者。无论您做什么，**不要仅依赖 MAC 过滤！** WEP 加密总比没有加密要好。请参阅 *[图 4.23](#c04.xhtml#fig4_23)* 了解 MAC 欺骗的示意图：

![](images/Figure-4.23.jpg)

**图 4.23：** MAC 欺骗

这不需要高水平的技术。您只需监听无线网络流量，并将您的 MAC 地址更改为已连接用户的地址即可。借助自动化脚本或应用程序，更改 MAC 地址就像 1、2、3 一样简单。然后，让我们看看如何使用名为 `macchanger` 的应用程序来欺骗我们的 MAC 地址。

1.  打开终端。

2.  输入以下命令并按 *Enter* 键：

    ```
    ifconfig wlan0 down
    ```

    此命令禁用或关闭无线接口，如 *[图 4.24](#c04.xhtml#fig4_24)* 所示：

    ![](images/Figure-4.24.jpg)

    **图 4.24：** ifconfig wlan0 down 命令

3.  使用以下命令重新激活 `wlan0` 并按 *Enter* 键，如 *[图 4.25](#c04.xhtml#fig4_25)* 所示：

    ```
    ifconfig wlan0 up
    ```

    ![](images/Figure-4.25.jpg)

    **图 4.25：** ifconfig wlan0 up 命令

4.  输入以下命令并按 *Enter* 键：

    ```
    macchanger --random wlan0
    ```

    此命令为无线接口随机生成一个伪造的 MAC 地址，如 *[图 4.26](#c04.xhtml#fig4_26)* 所示：

    ![](images/Figure-4.26.jpg)

    **图 4.26：** macchanger 命令_1

5.  输入以下命令并按 *Enter* 键：

    ```
    macchanger --mac=00:11:22:33:44:55 wlan0
    ```

    如显示的那样，此命令允许您在无线接口上伪造一个 MAC 地址，如 *[图 4.27](#c04.xhtml#fig4_27)* 所示：

    ![](images/Figure-4.27.jpg)

    **图 4.27：** macchanger 命令_2

就这么简单！难道不简单吗？了解这一点可以帮助您避开那些需要长期付费的付费热点网络。这些网络常见于咖啡店、餐厅、机场和酒店。当用户付费后，其 MAC 地址会被添加到允许访问互联网的 MAC 地址列表中。

# [防范无线攻击](#toc.xhtml#s83a)

我们必须时刻了解如何防御此类威胁和攻击。

接下来，我们将介绍防范这些攻击的方法：

*   更强大的加密可降低遭受攻击的可能性。
*   MAC 过滤也有助于降低遭受攻击的几率。
*   如果您的设备不兼容 WPA/WPA2，可以改用 WEP；但不建议这样做，因为它不安全。
*   创建单独的 VLAN 以限制对企业网络的访问。
*   应禁用或关闭 WPS 设置。
*   设置强且复杂的密码。
*   每三到四个月更换一次密码。
*   仅在万不得已时才使用制造商的默认密码。
*   使用 EAP 代替 PSK。
*   更改默认的 SSID 名称。
