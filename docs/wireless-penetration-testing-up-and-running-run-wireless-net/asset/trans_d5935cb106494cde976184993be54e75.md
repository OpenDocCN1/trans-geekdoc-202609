# [蜜罐攻击](#toc.xhtml#s123a)

随着技术的进步，无线网络在带宽和范围方面变得大得多。黑客可以简单地建立一个无线蜜罐，诱使受害者进入他们假定为安全的无线网络。什么是无线蜜罐，它是如何工作的？**无线蜜罐** 是一种设备，它被设置为一个接入点，拥有与该区域内另一个接入点相同的 `SSID`，并设置了一个指向攻击者计算机的代理。

如果用户连接到蜜罐，攻击者可以过滤或监控其所有网络活动，从而可能导致中间人攻击。该连接内的任何未加密流量（如电子邮件、即时消息、`FTP` 和 `telnet` 会话）都将对攻击者可见。请参阅 *[图 7.15](#c07.xhtml#fig7_15)*：

![](images/Figure-7.15.jpg)

**图 7.15：** 未加密连接

如果攻击者拥有高增益天线，客户端极有可能在可用无线网络列表的顶部看到攻击者的天线。另一点需要注意的是，大多数 Microsoft Windows 操作系统都设置为自动连接到无线网络，如果附近有一个具有相同 `SSID` 和密码的蜜罐，这可能会造成问题。此功能可以关闭。

# [保护自己免受蜜罐或中间人攻击](#toc.xhtml#s124a)

不使用无线网络是防御蜜罐攻击最简单的方法之一，如 *[图 7.16](#c07.xhtml#fig7_16)* 所示。如果你的公司需要无线访问怎么办？应在 `BYOD` 设备上创建配置文件，以仅允许受信任的无线网络连接到客户端设备。使用 `3G/4G` 或有线连接。如果你仍然需要无线访问怎么办？**无线入侵防御系统** (**WIPS**) 可以使用软件和硬件检测流氓接入点：

![](images/Figure-7.16.jpg)

**图 7.16：** 中间人攻击

`WIPS` 使用 `SSID`、信道、信号强度和 `MAC` 地址来识别这些接入点。如果标准不匹配，则该 `AP` 很有可能是蜜罐。如果黑客使用与你相同的 `SSID` 和信道会怎样？然后 `WIPS` 将使用信号强度。信号强度有助于确定 `AP` 是否真实。

**KFSensor** 是一款用于 Windows 的蜜罐 **入侵检测系统** (**IDS**)。它作为一个蜜罐运作，吸引并检测黑客、蠕虫、流氓软件和漏洞。它可以通过作为诱饵来转移攻击，增加一层额外的防御。`KFSensor` 界面如 *[图 7.17](#c07.xhtml#fig7_17)* 所示：

# [如何启动虚假接入点（虚假 Wi-Fi）](#toc.xhtml#s125a)

正如你所知，不受信任的 Wi-Fi 网络如果你连接它们，可能会造成相当大的危害。如果你身处陌生环境并碰巧连接到了一个开放网络，无论你使用什么设备，你的数据都将对掌管该接入点的人可见。不仅如此，负责人还可以通过将你连接到恶意网页或后门，从而完全控制你的设备。

有许多方法可以实现这一点。你可以将连接的用户发送到你控制的恶意网站，并用它来挂马控制他们的设备。在连接的设备上使用 python `MITM` 脚本，你也可以运行和执行后门。甚至可以在不引起怀疑的情况下，即时替换连接用户请求的下载文件。

让我们看看如何启动一个虚假 AP：

1. 首先，我们需要将 Kali Linux 更新到最新版本并安装所需的包，如 *[图 7.18](#c07.xhtml#fig7_18)* 所示：

```
apt-get update
apt-get install hostapd dnsmasq apache2
```

![](images/Figure-7.18.jpg)

**图 7.18：** 安装包

2. 我们需要将无线网卡置于监听模式，以允许我们嗅探网络内外的数据包。你可以使用 *[图 7.19](#c07.xhtml#fig7_19)* 所示的方法：

```
ifconfig wlan0 down
iwconfig wlan0 mode monitor
ifconfig wlan0 up
```

![](images/Figure-7.19.jpg)

**图 7.19：** 无线网卡设置

3. 如果那不起作用，你可以使用 *[图 7.20](#c07.xhtml#fig7_20)* 所示的方法：

```
airmon-ng start wlan0
```

![](images/Figure-7.20.jpg)

**图 7.20：** airmon-ng 命令

4. 为了使事情井井有条且易于操作，我们将在 root 目录下创建一个新目录并将其命名为 `fap`（虚假接入点）。请参阅 *[图 7.21](#c07.xhtml#fig7_21)*：

```
mkdir /root/fap
cd /root/fap
```

![](images/Figure-7.21.jpg)

**图 7.21：** mkdir 命令

5. 一旦我们进入刚创建的 `/root/fap` 目录，我们将建立一个新的 `hostapd` 配置文件并在其中编写指令，如 *[图 7.22](#c07.xhtml#fig7_22)* 所示。`hostapd`（主机接入点守护进程）是一个软件接入点，允许用户使用其无线适配器同时广播多个接入点。

```
nano hostapd.conf
```

`nano`：是大多数 Linux 安装中包含的命令行文本编辑器。

`hostapd.conf`：是我们创建的配置文件的名称。

现在，在 `hostapd.conf` 内部，我们需要为其设置指令顺序：

```
interface=wlan0
driver=nl80211
ssid=Free-Wi-Fi
hw_mode=g
channel=1
macaddr_acl=0
ignore_broadcast_ssid=0
```

写完这些指令后，按 `Ctrl` + `X`，然后按 `Y`，再按 `Enter`。现在，`hostapd.conf` 已全部设置完毕。

* `interface`：我们在监听模式下使用的无线适配器的名称。
* `driver`：`hostapd` 支持的驱动程序。
* `ssid`：广播的 Wi-Fi 名称。
* `hw_mode=g`：仅指示其使用 2.4 GHz 频段。
* `channel`：用于虚假接入点的信道编号。
* `macaddr_acl=0`：告诉 `hostapd` 不使用 MAC 过滤。[`macaddr_acl=1`] 告诉它使用 MAC 过滤。
* `ignore_broadcast_ssid=0`：使虚假接入点可见且不隐藏。

请参阅 *[图 7.22](#c07.xhtml#fig7_22)*：

![](images/Figure-7.22.jpg)

**图 7.22：** Nano 命令

6. 通过执行以下操作启动虚假接入点：

```
hostapd hostapd.conf
```

你会注意到我们的接入点将显示为一个开放的 Wi-Fi 网络。现在，在不关闭前一个窗口的情况下打开一个新的终端窗口。在新终端窗口中，通过执行以下操作导航回 fap 目录：

```
cd /root/fap
```

请参阅 *[图 7.23](#c07.xhtml#fig7_23)*：

![](images/Figure-7.23.jpg)

**图 7.23：** hostapd 命令
