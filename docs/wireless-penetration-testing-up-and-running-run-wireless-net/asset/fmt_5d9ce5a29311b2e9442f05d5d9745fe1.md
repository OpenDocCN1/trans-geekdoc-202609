
存在多种易受网络嗅探攻击的网络服务和公共网络。任何具备必要能力和 Wireshark 知识的人都可以快速入侵您的账户。

请始终检查以下事项以保持安全：

*   使用 WPA 或 WPA2 加密。
*   在公共网络上始终使用 HTTPS。
*   使用 SSH 或加密邮件进行文件传输。
*   在公共网络上使用 VPN。
*   使用密码管理器登录网站。

# 中间人攻击

您可能听说过“中间人”，但什么是“中间人攻击”？**中间人攻击**（**MITM**）发生在用户数据被网络拦截时。在网络上，恶意用户充当路由器，捕获所有网络流量。这涵盖电子邮件、登录凭据、聊天消息等。请参阅*[图 8.2](#c08.xhtml#fig8_2)*：

![](images/Figure-8.2.jpg)

**图 8.2：** MITM 攻击

此演示仅旨在作为教学工具。黑客技术用于提高安全性是一项宝贵的技能。在大多数国家，未经授权在未获许可的网络上从事恶意活动属于重罪。在下一个演示中，我们将使用自己的计算机和网络。

在本例中我们使用了 HTTP 协议，但在现实世界中，HTTPS 协议用于保护通信安全。在这种情况下，作为攻击者，您会怎么做？攻击者将应用 **SSLStrip** 概念（如*[图 8.24](#c08.xhtml#fig8_24)*所示），**SSLStrip** 是一种 MITM 攻击，强制用户使用 HTTP 协议而非 HTTPS 进行通信，从而使攻击者能以明文形式查看所有 SSL 流量。**HTTP 严格传输安全（HSTS）** 是一种安全防护机制，可保护您免受此类威胁：

![](images/Figure-8.24.jpg)

**图 8.24：** SSLStrip 概念

要使用 SSLStrip 概念，我们将在 Ettercap 程序中激活 SSLStrip 插件。在菜单栏上，点击 `Plugins`，然后 `Manage the plugins`，再双击 `sslstrip` 插件。激活后左侧会出现 `*` 标记（如*[图 8.25](#c08.xhtml#fig8_25)*所示）：

![](images/Figure-8.25.jpg)

**图 8.25：** SSLStrip 插件

恭喜！您已成功实施完整的 MITM 攻击。

要停止攻击，请选择 `Stop sniffing`（如*[图 8.26](#c08.xhtml#fig8_26)*所示）：

![](images/Figure-8.26.jpg)

**图 8.26：** 停止嗅探

攻击终止后，Ettercap 将发送 ARP 数据包，网络将在几分钟内恢复正常。使用 ARP 检测工具（如 XArp 或 Snort）可防范此类攻击。分配静态 ARP 条目也有助于防止攻击。这会告知攻击者路由器的 MAC 地址是固定且不可修改的，因此攻击者发送的所有 ARP 数据包都将被忽略。

# Metasploit

对于渗透测试人员和 IDS 开发人员，Metasploit 是最知名的开源工具。Metasploit 框架是一个安全漏洞利用和脚本数据库。它是编写和在目标系统上运行漏洞利用代码的最广泛使用的开源工具之一。
