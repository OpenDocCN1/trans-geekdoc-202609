
从本质上讲，这是一种利用被攻陷的计算机来访问我们原本无法访问的网络的做法。如果一台具有网络访问权限的计算机被攻陷，网络隔离将变得毫无意义。这种方法允许攻击者通过路由到被攻陷的系统来访问秘密网络。枢纽用于将所有请求传输到新发现的网络。它就像一种隧道。请参阅 [图 9.2](#c09.xhtml#fig9_2)：

![](images/Figure-9.2.jpg)

**图 9.2：** 枢纽

如拓扑所示，具有两块 NIC 的设备可以访问 `192.168.1.0/24` 和 `192.168.10.0/24` 网络。除非定义了路由规则，否则在正常情况下这两个网络之间无法互访。根据此拓扑，授权用户正在使用一台配有两块 NIC 网卡的计算机，必须访问 DMZ 中的某些服务。

# 端口转发

端口转发是枢纽的第一步之一。隐秘网络上指定系统的某些服务可能无法直接访问（Web 服务器等）。这是由于缺乏双向路由。我们知道如何到达目标系统并发送请求，但因为目标不知道我们的位置，我们的请求将被拒绝。请参阅 [图 9.14](#c09.xhtml#fig9_14)：

![](images/Figure-9.14.jpg)

**图 9.14：** 端口转发

因此，我们使用当前的 meterpreter 会话将本地系统上的一个端口路由到目标。只要此进程存活，路由就会生效。

此时需要注意一点：`autoroute` 运行命令允许我们得益于所提供的路由，在 Metasploit 框架内自由工作。然而，我们将需要像端口转发和 ProxyChains 这样的工具，以便使用 Kali 工具访问目标。

端口转发可以使用 `portfwd` 模块完成，它是 Metasploit 的后渗透模块之一。请参阅 [图 9.15](#c09.xhtml#fig9_15)：
