

# 扫描策略

扫描策略基本上是一组扫描指令。扫描策略告诉扫描器要完成什么任务以及如何完成它们。您可以从多个预配置的扫描策略模板中进行选择，或自定义复杂扫描。Tenable 将 Nessus 的扫描功能分为三类：

*   **发现扫描**：针对地址空间，报告存活主机和开放端口。
*   **漏洞扫描**：针对端点，评估已知漏洞。
*   **合规性扫描**：针对端点，评估端点配置是否符合特定标准（例如，**互联网安全中心 (CIS) 基准**、**安全技术实施指南 (STIG)** 等）。

请按照以下步骤构建并配置您的扫描策略。

1.  `Policies`（策略）位于屏幕左侧菜单中 `Resources`（资源）类别下，如 *[图 6.15](#c06.xhtml#fig6_15)* 所示：
    ![](images/Figure-6.15.jpg)
    **图 6.15：** 从 Nessus 菜单中选择策略

2.  从屏幕右上角的菜单中选择 `New Policy`（新建策略），如 *[图 6.16](#c06.xhtml#fig6_16)* 所示：
    ![](images/Figure-6.16.jpg)
    **图 6.16：** 从 Nessus 策略页面创建新策略

3.  从下拉菜单中选择 `Basic Network Scan`（基础网络扫描）。`Basic Network Scan` 选项包含用于评估 Kali Linux 服务器漏洞的 `Pre-configured settings`（预配置设置），如 *[图 6.17](#c06.xhtml#fig6_17)* 所示：
    ![](images/Figure-6.17.jpg)
    **图 6.17：** 从 Nessus 策略模板页面选择基础网络扫描

    选择扫描策略模板后，会出现其他可调整组件。目前请保持每个预配置设置为默认状态，但之后您可以随意尝试修改。

4.  为扫描策略指定 `Name`（名称）后，点击 `Save`（保存）按钮。本教程使用的扫描策略名称为 `Basic Network Vulnerability Scan Policy`（基础网络漏洞扫描策略），如 *[图 6.18](#c06.xhtml#fig6_18)* 所示：
    ![](images/Figure-6.18.jpg)
    **图 6.18：** 在 Nessus 基础网络漏洞扫描策略页面输入策略名称并使用预配置默认值

Tenable 需要管理访问权限才能运行漏洞检查（其中一些将在本教程中演示）。在没有凭据的情况下执行扫描，可以深入了解可从外部枚举的漏洞，模拟攻击者的视角。

# 配置 Nessus 漏洞扫描

配置扫描是流程的下一阶段。在此过程中，按照以下说明选择扫描策略和目标主机。

1.  从屏幕左侧的菜单中选择 `My Scans`（我的扫描），如 *[图 6.19](#c06.xhtml#fig6_19)* 所示：
    ![](images/Figure-6.19.jpg)
    **图 6.19：** 在 Nessus 菜单上选择我的扫描

2.  点击屏幕右上角的 `New Scan`（新建扫描）按钮，如 *[图 6.20](#c06.xhtml#fig6_20)* 所示：
    ![](images/Figure-6.20.jpg)
    **图 6.20：** 在 Nessus 中创建新扫描

3.  从 `User Defined`（用户定义）选项卡中选择新创建的 `Basic Network Vulnerability Scan`（基础网络漏洞扫描），如 *[图 6.21](#c06.xhtml#fig6_21)* 所示：
    ![](images/Figure-6.21.jpg)
    **图 6.21：** 选择创建用户定义的 Nessus 扫描

4.  选择您在上一节中设置的扫描策略。本课程中的 `Basic Network Vulnerability Scan Policy`（基础网络漏洞扫描策略）显示为可选项，如 *[图 6.22](#c06.xhtml#fig6_22)* 所示：
    ![](images/Figure-6.22.jpg)
    **图 6.22：** 选择基础网络漏洞扫描策略

5.  定义您的目标。在 `Targets`（目标）文本输入框中输入 `localhost` 以将目标指向您的本地 Kali Linux 主机，如 *[图 6.23](#c06.xhtml#fig6_23)* 所示：
    ![](images/Figure-6.23.jpg)
    **图 6.23：** 定义漏洞扫描目标

    可以通过逗号分隔，在一次扫描中定义多个目标。例如，指定 `localhost`、`10.10.10.10` 将同时针对您的本地主机和 `10.10.10.10` IP 地址。

6.  为扫描命名，然后点击 `Save`（保存）按钮。本教程的扫描名称为 `Basic Network Vulnerability Scan`（基础网络漏洞扫描），如 *[图 6.24](#c06.xhtml#fig6_24)* 所示：
    ![](images/Figure-6.24.jpg)
    **图 6.24：** 保存新的 Nessus 漏洞扫描

# 启动 Nessus 漏洞扫描

保存扫描后，在 Nessus 应用程序的 `My Scans`（我的扫描）部分将创建一个条目。

1.  点击 `Basic Network Vulnerability Scan` 旁边的 `Play`（播放）按钮以开始扫描，如 *[图 6.25](#c06.xhtml#fig6_25)* 所示：
    ![](images/Figure-6.25.jpg)
    **图 6.25：** 运行 Nessus 漏洞扫描

2.  旋转的绿色箭头指示器表示正在扫描。请耐心等待，因为扫描需要一些时间才能完成，如 *[图 6.26](#c06.xhtml#fig6_26)* 所示：
    ![](images/Figure-6.26.jpg)
    **图 6.26：** 旋转的绿色箭头图标表示正在运行扫描

3.  当旋转的绿色箭头图标变为绿色复选标记时，扫描完成。只需点击扫描名称即可查看结果！请参阅 *[图 6.27](#c06.xhtml#fig6_27)*：
    ![](images/Figure-6.27.jpg)
    **图 6.27：** 绿色复选标记表示漏洞扫描完成

    太棒了！您刚刚完成了对 Kali Linux 主机的漏洞扫描！在扫描摘要页面，点击 `Vulnerabilities`（漏洞）选项卡查看结果，如 *[图 6.28](#c06.xhtml#fig6_28)* 所示：
    ![](images/Figure-6.28.jpg)
    **图 6.28：** 在扫描摘要页面显示发现的漏洞

4.  点击其中一个漏洞。它将提供更多信息，如 *[图 6.29](#c06.xhtml#fig6_29)* 所示：
    ![](images/Figure-6.29.jpg)
    **图 6.29：** 显示漏洞的更多信息

报告解释了什么是漏洞及其影响。它将提供解决方案以及更多资源的参考。对于普通用户来说，这将提供您所需的所有信息，以弄清楚导致问题的原因、风险和威胁是什么，以及如何修复它们。

# 生成报告

创建报告将帮助您组织工作，并在渗透测试期间为您提供一个中心位置来分析所有输出和结果。报告很有用，因为它们将所有信息集中在一个地方，无需求助于其他文档。

1.  现在我们已经安装并执行了扫描，是时候获取报告了。点击 `Vulnerabilities`（漏洞），如 *[图 6.30](#c06.xhtml#fig6_30)* 所示：
    ![](images/Figure-6.30.jpg)
    **图 6.30：** 漏洞

2.  点击 `Report`（报告），如 *[图 6.31](#c06.xhtml#fig6_31)* 所示：
    ![](images/Figure-6.31.jpg)
    **图 6.31：** 报告

3.  选择文件格式（PDF/HTML/CSV）并选择一个 `Report Template`（报告模板），然后点击 `Generate Report`（生成报告）按钮（这将下载您选择的文件格式）。

4.  打开文件查看其是否为可查看和工作的格式，如 *[图 6.32](#c06.xhtml#fig6_32)* 所示：
    ![](images/Figure-6.32.jpg)
    **图 6.32：** PDF 报告

恭喜，您已成功在 Nessus 中生成漏洞报告！
