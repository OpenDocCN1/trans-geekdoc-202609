# 前言

由于无需网线即可从全球各地轻松访问互联网，无线技术越来越普及。然而，如果您不了解其风险，更重要的是，如果不采取安全措施，无线网络可能并不安全。为了您自身的安全，保护您的无线网络至关重要。过去几年来，身份盗窃和个人信息窃取事件日益增多。

不安全的无线网络不再安全，因为尽管它们更易于设置和连接，但您的个人信息被盗的可能性更大。另一个人即使几乎没有经验也能轻松拦截它。用户监视您在线活动的另一种方式包括无保护的无线网络。这包括对话、电子邮件，甚至您的网上银行账户。虽然本书提供了保护无线网络的方法，但主要集中在攻击者如何访问受保护的无线网络。此外，它还演示了攻击者一旦获得无线网络访问权限所拥有的权力。

本书分为 **12 章**。它们将涵盖无线网络基础、无线渗透测试的基础和进阶内容。详情如下。

**[第 1 章](#c01.xhtml)** 将介绍搭建您自己的无线实验室的分步指南。还将介绍在硬盘上安装 Kali 以及虚拟机（`VMWare`）实验的基础知识。本章将提供关于无线渗透测试工具的知识，例如 `Wireshark` 和 `Aircrack-ng`。将讨论如何使用 Web 界面配置您的接入点。

**[第 2 章](#c02.xhtml)** 将介绍对多种不同无线攻击策略的完整理解，例如访问控制攻击、机密性攻击、凭证攻击和认证攻击。

**[第 3 章](#c03.xhtml)** 将讨论如何扫描无线网络以获取信息，并展示两种不同形式的无线扫描及其工作原理。然后本章将展示如何使用 `Ettercap` 通过 ARP 欺骗嗅探无线网络，以及如何使用 `dsniff` 收集登录详细信息。最后，将介绍多种防御这些攻击的方法。

**[第 4 章](#c04.xhtml)** 将展示如何制定攻击计划。接下来，将介绍多种攻击方法。然后，本章将详细讨论 `WEP`、`WPA` 和 `WPA2` 加密。最后，将介绍多种降低无线攻击风险的方法。

**[第 5 章](#c05.xhtml)** 将阐述在对网络进行渗透测试时，查找存活主机数量的重要性。接下来，将介绍使用 `Kali Linux` 识别网络上的主机。最后，本章将介绍确定网络规模。

**[第 6 章](#c06.xhtml)** 将介绍规划评估的能力、评估的关键组成部分以及评估的分步流程。将介绍安装 `Nessus`、注册、下载插件并运行 `Nessus` 的能力。本章还将讨论创建新策略和扫描、识别漏洞、阅读漏洞详情，并针对漏洞提供解决方案的能力。

**[第 7 章](#c07.xhtml)** 将介绍如何捕获未加密流量，并了解蜜罐攻击和方法、`Karmetasploit`、`Jasager` 以及威胁防范。

**[第 8 章](#c08.xhtml)** 将介绍使用无线进行高级攻击的基础，包括建立无线 MITM 攻击环境，并利用其窃听受害者流量。然后，本章将讨论如何利用相同环境通过 DNS 投毒攻击劫持受害者的应用层（具体为 Web 流量），以及如何使用 `Metasploit`。最后，将讨论这些威胁的防范。

**[第 9 章](#c09.xhtml)** 将介绍如何使用一级和二级跳板调查隐藏网络及缓解方法。
