# Introduction

All our lives, we have been using a global model of data structure that functions in a completely centralized environment. This system has very little flexibility and it is permanently under the control and supervision of a few individuals both in public and private sectors with a few proactive collaborations between all stakeholders. But this scenario is rapidly changing with the emergence of many technological initiatives that can change the centralized model we all have known all our lives.
