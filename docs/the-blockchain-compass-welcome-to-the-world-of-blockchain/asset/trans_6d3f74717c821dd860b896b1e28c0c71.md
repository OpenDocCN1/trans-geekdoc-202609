
# Hyperledger Fabric

Hyperledger Fabric 无疑是以太坊的竞争对手之一，且该平台近年来人气大增。该智能合约平台由 Linux 基金会于 2015 年创立，作为一个开源项目。该平台的目标是成为一个开源项目，支持基于区块链的分布式账本的开发。目前该平台正在开发的框架包括 `Hyperledger Sawtooth`、`Hyperledger Burrow`、`Hyperledger Indy` 和 `Hyperledger Fabric`。

对于正在探索使用哪个智能合约平台的开发者来说，Hyperledger 可能是一个绝佳选择，原因有几点。随着时间的推移，该平台已被证明是以太坊的可靠替代方案。`Hyperledger Fabric` 是一个许可制区块链基础设施，支持智能合约的执行。因为它是许可制网络，所有参与者都具有已知身份，这使其成为组织在创建智能合约的同时，遵守要求身份已知的数据保护法律的理想解决方案。

使 Hyperledger 独特且更灵活的功能之一是，开发者只需安装合适的模块，即可使用 JavaScript 以及其他常见编程语言创建智能合约。因此，在该平台上，开发者无需像依赖 `Solidity` 那样仅依赖一种语言就能编写智能合约。

## Hyperledger Fabric 的挑战

与以太坊不同，该平台缺乏自己的代币系统，虽然此功能提供了诸多优势，但也有其缺点。例如，它限制了可在该平台上开发的智能合约类型。对于希望开发需要支付转账的智能合约（如 ICO）的公司或组织来说，以太坊将是更好的选择。您将在 Hyperledger 中发现的其他主要功能包括：

*   许可制成员资格
*   可靠性能
*   支持插件组件
*   开源且免费使用
*   开发者可使用多种语言编写智能合约
*   由 IBM 支持

如前所述，该平台的一个主要缺点是缺乏代币系统。

# Nem

一些开发者偏爱 Nem 的原因之一是它是用 Java 编写的，而 Java 是一门广为人知的编程语言。因此，无需专门为区块链平台学习一门新编程语言（如 `Solidity`）。一些开发者偏爱该平台的另一个充分理由是 Java 实际上更成熟，因此与较新的编程语言相比，安全漏洞更少。

大多数安全专家透露，Nem 发布的 `Mijin V.2` 更新使该区块链网络成为区块链领域最安全的智能合约平台。除了改进 NEM 区块链外，该更新被视为一个行业里程碑，开启了分布式账本数据库功能新可能性的时代。Nem 最大的卖点或许在于其高度可扩展。例如，以太坊每秒处理约 15 笔交易 (TPS)，而 Nem 每秒可处理数百笔交易。这就是为什么越来越多的开发者被 Nem 吸引。请看 Nem 关键特性的总结：

*   卓越性能
*   Java 语言使其易于使用
*   可扩展
*   无平台专用语言

尽管有其优势，但也存在一些缺点，其中之一是工具不多。由于其使用的代码并非基于区块链，该平台去中心化程度较低。最后，与其他平台相比，Nem 的开发者社区也较小。

# 选择智能合约平台时需考虑的因素

如果您有兴趣选择一个智能合约平台，区块链领域有很多可供选择。我们刚刚探讨了其中几个，但在选择之前，有几件事您需要考虑。

## 考虑平台的声誉

多年来，对于想要创建加密代币的人来说，以太坊已比其他智能合约区块链平台更受欢迎。以太坊的开发者团队创建了 `Ethereum Virtual Machine` (EVM)。它是一个图灵完备系统，任何人都可用于开发区块链应用。以太坊拥有丰富的生态系统，使开发者创建去中心化应用 (dApps) 更轻松。

如果您需要通过去中心化实现安全性，以太坊也是最佳选择，这是因为它使用了 `PoW` 共识机制。目前，大量去中心化金融项目使用以太坊平台。随着向 `Ethereum 2.0` 的过渡，这也将把区块链从 `PoW` 过渡到 `PoS`，可扩展性问题将得到缓解，平台安全性将进一步提高。

## 如果您不需要代币

事实是，并非所有项目都需要加密代币。如果您的项目属于这一类，那么您很可能对需要许可制区块链的用例感兴趣。例如，如果您正在尝试开发供应链保障系统，则不需要加密代币。适合您项目的最佳智能合约平台类型是企业级区块链解决方案，此类平台之一是 `Hyperledger Fabric`。像 `Quorum` 这样的智能合约平台将适合对金融科技特定用例感兴趣的公司。`Quorum` 也是一个企业级区块链平台，在 JP Morgan 的协助下开发。2020 年，ConsenSys 收购了该公司。

# 第 7 章：区块链技术及其挑战

![Image](Image00024.jpg)

多年来，有兴趣进入区块链领域的公司名单持续增长。尽管分布式账本技术有许多优势，但在普遍采用之前，它仍需克服几大障碍。这些挑战范围从缺乏适当监管到可扩展性低，以及合格人员不足。在本节中，我们将梳理区块链技术面临的技术和组织挑战，并了解第三代解决方案为应对其中一些挑战所做的实施。

## 区块链技术的主要挑战

多年来，区块链技术主流采用面临的挑战之一关乎声誉。目前，大多数人将区块链技术等同于比特币和加密货币。不幸的是，世界仍将加密货币（并由此关联区块链）视为欺诈、投机者、黑客和恶意行为者的代名词。我们将同时探讨非技术或组织层面的挑战，以及技术层面的挑战，如缺乏互操作性、与遗留系统集成困难、可扩展性问题、分布式账本技术的复杂性以及人才短缺。

企业层面的一些组织挑战包括对技术缺乏足够的认知和理解、缺乏良好的治理、缺乏用户体验等。我们将探讨大多数挑战，以及区块链领域为应对其中大多数挑战所做的努力。
