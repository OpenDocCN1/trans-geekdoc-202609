

# 智能合约：定义与运作

智能合约包含*“一组承诺”*，这些承诺可能是合同性的，也可能是非合同性的——这取决于智能合约的模型。此外，这些承诺可能包含基于规则的操作和/或为执行业务逻辑而确立的合同条款。

定义中的第二个要素是“以数字形式指定”。这也意味着智能合约主要以电子形式运行，由若干行代码以及有助于规定正确条件和结果的软件组成。所有合同条款和/或功能性结果均以代码形式添加到软件中。

此外，萨博定义中使用的“协议”以算法的形式出现，该算法确立了管理所有利益相关者处理与智能合约相关数据方式的特定规则。它还指基于规则和技术赋能的操作，允许执行某些动作，如释放付款。智能合约的核心组成部分之一与自动履行有关。

我们也可以考察国际金融公司（IFC）提供的智能合约定义。他们将其定义为*“运行在区块链上的自执行软件代码。”* 根据这一定义，我们将主要关注基于区块链的智能合约。当智能合约与分布式账本技术结合时，有可能提供一种高效、自动化且透明的方式来执行多种合同流程，特别是在无需依赖中介机构的情况下跟踪协议履行情况。

因此，基于我们迄今看到的两个定义，我们可以得出结论：智能合约简单来说就是基于区块链的计算机协议。这些协议以数字方式促进两方或多方之间协议的控制、验证和实际执行——绝对不需要中介机构。

## 智能合约如何运作

![Image](Image00023.jpg)

起点是合同双方达成一致。此时，所有参与方需要识别商业机会和预期结果。他们识别的机会通常是以某种方式使所有参与方受益。在这种情况下，协议可能包括资产互换、权利转让、业务流程等。

一旦合同双方识别了机会领域和期望结果，下一阶段涉及设定智能合约的条件。智能合约的参与方可以自行发起，也可以在满足特定条件时发起，例如自然灾害、金融市场指数或任何特定事件。此外，时间条件实际上可以在宗教节日、生日或假期发起智能合约。

下一阶段涉及编写业务逻辑代码，如果双方无法自行处理，开发人员可以负责智能合约的这一方面。它涉及一个计算机程序，以确保在满足条件参数的那一刻自动执行安排的方式编写。然后消息将通过区块链加密传递，以帮助验证和认证智能合约中所有利益相关者之间的消息。一旦开发人员编写好智能合约，则所有利益相关者同意的一方将验证智能合约，并继续将协议记录在区块链上。

托管智能合约的区块链类型也将决定智能合约的性质。如果托管在以太坊等公共/无许可区块链上，智能合约中的交易将对公众可见。

第四步涉及执行和处理。在区块链迭代中，节点就智能合约的认证和验证达成共识后，智能合约将被写入区块。此时，智能合约评估数据并自动执行或失效——协议条款将决定结果。然后网络将在智能合约执行后更新所有节点以反映新状态。一旦智能合约经过验证并发布到区块链网络，其记录就无法被篡改。

托管在区块链上的智能合约的第三阶段涉及智能合约通过数据库服务（如金融机构账户或数据源）连接外部数据源。智能合约中包含的最常见语句是简单的*“如果/当……那么……”*语句。这些语句随后被编写为首选区块链网络上的代码。一旦预定条件得到满足并验证，节点网络将执行相应动作。

动作示例包括登记汽车、向正确个人释放资金、发行票据，甚至发送特定通知。一旦节点执行动作，该信息将在区块链上更新以显示已完成。只要需要说服参与者任务已成功完成，智能合约中可能存在多项约定。

在确立条款的过程中，所有各方需要确定其数据和交易在所选区块链平台上如何表示。他们还需要就将管辖其所有交易的*“如果/当……那么……”*规则达成一致。合同各方需要就之一下重要因素达成一致，即所有可能的例外情况，并在出现争议时，就适当的争议解决指南达成一致。

除了可以协助编写智能合约的开发人员外，随着行业的发展，正在出现更多选择。例如，越来越多将区块链用于业务的公司现已开发出模板、精美的 Web 界面以及其他在线工具，有助于简化和构建智能合约。

## 智能合约的效率与优势

随着技术的不断改进，智能合约的优势数量在未来可能会进一步增加。与传统安排相比，智能合约提供了多项优势，例如：

*   **准确性提高：** 智能合约的前提之一是详细显式记录合同的所有条款和条件。单一遗漏可能导致交易错误，因此自动化合约有助于防止手工填表的弊端。
*   **沟通清晰：** 由于陈述合同条款需要准确性，一切都是显式的。这消除了沟通不畅或误解的可能性。因此，合同双方可以降低因沟通鸿沟导致的低效率。
*   **速度：** 与涉及文书工作的传统合同不同，智能合约运行在软件代码上，并在互联网上实时进行。这也意味着我们可以快速轻松地执行它们。智能合约的执行速度有助于减少传统业务流程浪费的工时。*有了智能合约，无需手工处理文档，因为一切都以数字化方式完成*。由于智能合约执行速度的提高，企业将以更高的效率运营。更高的效率将进一步导致单位时间内处理更多创造价值的交易。
