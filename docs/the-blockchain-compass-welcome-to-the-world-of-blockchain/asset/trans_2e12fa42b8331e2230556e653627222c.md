

# 去中心化数字身份：用例与平台

## 游戏行业
您会同意我的观点，游戏行业是一个庞大的产业，而该行业处理的事项之一就是玩家的身份。遗憾的是，在大多数情况下，该行业未能为玩家提供足够的安全保障。另一点是，大多数游戏应用还具备应用内购买功能。这进一步增加了对充分安全性的需求，因为此类应用会要求输入信用卡号。去中心化数字身份能够提供去中心化身份基础设施及相应法规，从而规范整个流程，进而消除信用卡详情被盗的案件。

## 医疗保健
事实是，大多数医疗机构未能妥善保护患者的个人和健康信息。因此，这些数据大多被用于私人研究，而其他医疗机构则在未经患者必要授权的情况下访问其敏感信息。有了去中心化身份基础设施，患者现在可以享受他们应得的完全控制权和隐私，医疗机构也能保护与患者健康相关的所有数据。

## 适用于去中心化身份的理想企业级平台

区块链领域已有多个优秀的企业级区块链平台，它们非常适合管理去中心化身份管理平台。它们为各种身份问题提供卓越的服务。

### Hyperledger
这是一个企业级区块链项目，已有多个项目运行在该平台上。Hyperledger 实际上提供了适合去中心化身份管理的优秀项目，其中之一称为 `Hyperledger Indy`。这是一个主要用于数字身份的分布式账本。该分布式账本还附带创建去中心化身份管理系统所需的库、组件和工具等其他功能。

此外，还可以在不同平台上使用您的身份。Hyperledger 推出的项目之一称为 `Aries`，该项目于 2021 年初从孵化状态毕业为活跃状态。该项目作为一个工具包，就像您在模块上使用各种功能创建自己的平台一样。`Aries` 的功能包括：

*   高性能和更强的可扩展性。
*   提供许可型区块链平台以及开源工具包。
*   数据可用性严格遵循“仅按需知晓”原则。
*   提供增强的安全措施，以确保敏感信息的安全。
*   提供查询语言以帮助搜索账本。
*   提供即插即用的模块化结构。

### Ethereum
也许，`Ethereum`（以太坊）是仅次于比特币的第二大热门区块链网络，多年来该项目的采用率不断提高。该项目的核心开发者之一是 `Vitalik Buterin`（V 神），他在加密货币牛市期间，因 `Ether`（以太币）触及历史高点，成为最年轻的加密货币亿万富翁。`Ethereum` 区块链的目标是面向企业级用途，但它是无许可的。这可能会导致多种挑战，特别是对于去中心化身份管理系统而言，因为隐私是大多数用户的首要需求。然而，`Ethereum` 通过 `Enterprise Ethereum Alliance`（企业以太坊联盟）为企业提供了私有版本。借助其平台的私有版本，任何人都可以开发安全的去中心化身份管理系统。您将从该平台享受到的显著特性包括：

*   开源平台。
*   来自公共版本的持续更新。
*   用户将获得来自 `Enterprise Ethereum Alliance (EEA)` 的权威支持，用于 `Ethereum` 平台上的各类项目。这对于完成指南和标准很有用。
*   该平台提供多项标准，使任何人都能简单直接地开发不同类型的平台。
*   `Enterprise Ethereum Alliance` 还为在其旗下开发的所有项目提供政府支持。这意味着，如果您发现另一个组织开发了您所需的多项吸引人功能，`EEA` 也将为您提供相同的功能。

## 数字身份领域的项目

多年来，已涌现出多个现实生活中的数字身份解决方案，且仍在不断开发中。以下是一些正在研究这一独特身份模型结构的热门数字身份公司：

### Civic
该项目是一个个人身份验证流程，利用分布式账本技术提供数字身份。使用该平台时，不仅可以创建您的虚拟身份，还可以存储其他信息。但在将信息存储到数字身份解决方案之前，您需要验证所有凭证。希望在这些数字身份公司发展业务的人士，可以使用以下四种不同解决方案中的任意一种：

*   可重复使用的 `KYC`，有助于管理各种形式的 `KYC` 要求。
*   “无密码”登录。
*   安全 ID 平台，允许用户通过安全身份访问任何网站。
*   自动化零售授予用户访问智能售货机的权限。

所有形式的咨询、投资和业务关系都有各自的 ID 代码。

### Sovrin
另一个为用户提供自主身份（Self-Sovereign Identity）的热门项目是 `Sovrin`。这家非营利组织致力于去中心化数字身份解决方案，使用户能够享受信任、控制以及易于使用的数字身份。该项目以提供数字身份的新标准为荣，用户可以获取其身份证和驾照的数字副本。该项目是一个元系统，让个人和组织有机会使用任何应用程序，而无需担心身份问题。

### uPort
通过 `uPort` 项目，用户可以享受对其身份的完全控制自由。该项目构建在 `Ethereum` 区块链上，正如前文所述，它是去中心化数字身份的顶级平台之一。在 `uPort` 平台上，用户只需创建其数字身份解决方案。可以请求或发送凭证、签署交易、管理其数据和密钥，并执行其他多项任务。该平台为用户提供凭证——一个身份凭证生态系统。您可以轻松通过您的应用程序索取其他用户的凭证，但这取决于他们的批准——即他们是否愿意与您共享。此外，该平台的开发工具采用模块化结构，使用起来并不困难。这类数字身份公司还为您提供访问多种协议和消息传递选项的权限。

## 结论
随着我们的世界经历一个杰出的数字化转型时代，我们正逐渐看到物理世界和数字世界融合为单一现实。毫无疑问，现在迫切需要更好的方式来维护我们日益增长的数字身份。随着越来越多的项目进入去中心化数字身份领域，脱颖而出的将是那些在各方面都具备安全性和隐私性的项目。去中心化数字身份赋予用户对其身份权利的完全控制，同时使其易于管理。未来，我们很可能会见证去中心化身份数量的增加。
