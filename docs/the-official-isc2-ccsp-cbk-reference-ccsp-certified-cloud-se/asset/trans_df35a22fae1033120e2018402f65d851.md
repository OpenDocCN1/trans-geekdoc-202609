## 代理

代理是一个系统，它利用大语言模型来推理问题、制定计划并通过使用工具执行计划以解决问题。

## 大语言模型 (LLM)

帮助代理决定做什么以及如何做的推理引擎。它是代理的核心。

## 工具

代理可用于与世界交互的工具，例如搜索、计算器、代码解释器等。

## 规划

代理将大型任务分解为较小的可管理子任务，并为每个子任务制定解决方案方法。

## 记忆

记忆帮助代理存储和回忆信息，并从过去的经验中学习以改进未来的决策。
