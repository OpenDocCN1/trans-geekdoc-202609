## Agents

An agent is a system that leverages an LLM to reason through a problem, create a plan, and execute the plan to solve the problem by using tools.

## Large Language Model (LLM)

The reasoning engine that helps the agent decide what to do and how to do it. It's the core of agent.

## Tools

The tools that the agent can use to interact with the world, e.g., search, calculator, code interpreter, etc.

## Planning

The agent breaks down a large task into smaller manageable subtasks and devises a method to solve each subtask.

## Memory

Memory helps the agent store and recall information, and learn from past experiences to improve future decision making.
