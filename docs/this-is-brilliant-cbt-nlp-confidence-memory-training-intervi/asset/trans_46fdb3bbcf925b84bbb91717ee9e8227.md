不要自毁前程。如果你有过糟糕的经历，无论是无辜失业，还是因自己的行为导致失业——如果这些都在过去，并且不会通过推荐信暴露出来——就不要提及它。

### 我应该怎么说？

一些面试官会通过向你提出假设性场景来了解你的优缺点，以看看你临场反应能力有多强。这些问题并不是为了寻找一个‘正确’答案而设计的，所以不要浪费时间纠结于正确的解决方案。面试官寻找的是你常识的证据、你在压力下做决定的能力，以及你了解自身局限性的能力。

![images](images/00038.gif)你是一家大型超市的经理，接到一个匿名电话，称你销售的若干婴儿食品被一个抗议团体篡改了。你会如何反应？

![images](images/00039.gif)我可能会怀疑这只是个恶作剧，但当然，我会采取一切预防措施，以防情况并非如此。如果我有助手，我会让他们安排封锁婴儿食品货架，并看看能做些什么防止任何商品通过收银台。我还会通过广播系统平静地发布公告。我会致电警察，也会联系当地报纸和广播电台，开始召回任何可疑商品。如果我没有助手，我的首要任务就是阻止任何人购买相关产品，然后联系警察。
