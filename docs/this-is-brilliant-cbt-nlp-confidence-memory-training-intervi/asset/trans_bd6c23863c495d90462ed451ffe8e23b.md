遇到咄咄逼人的面试官对候选人来说是一种不愉快但幸运的是罕见的经历。在某种程度上，这种面试风格已经过时，对平等机会的担忧以及对胜任力面试的日益依赖，使其不太可能受到青睐。不过，您的面试官可能状态不佳、压力很大，或者根本不具备理想的面试官性格。

雇主可能希望了解您在敌对情况下的反应，并通过其他方式（而不仅仅是让您描述）来发现您性格的某些方面。保持冷静、避免与对手发生冲突是一个基本的起点。然而，重要的是您不能在压力下崩溃，并且要继续清晰而果断地表达您准备充分的答案。

![image](images/00004.jpeg）

听起来咄咄逼人的问题通常以“为什么”开头。“你为什么做出这个决定？”“这个问题为什么会出现？”保持冷静；不要因恐慌而给出糟糕的答案，并尽量不要把事情太过个人化。

请记住，问题本身并不更难，即使以不愉快的方式提出。您申请的职位可能意味着您将与一些相当咄咄逼人的同事或客户打交道，如果面试官意识到这一点，他们想确认您能够应对。

偶尔，您很友好，面试官也很和蔼，但环境困难。您的面试不断被电话或闯入房间的人打断。面试官可能比您更心烦意乱（除非这是某种奇怪的心理测试）。计划不周、时间压力或人手不足更可能是解释。记下对话中断的地方，以便如果面试官在努力回忆“我们说到哪了”时，您能迅速将其拉回正轨。一位在海滨小镇公司应聘的候选人，其面试因面试官是当地救生艇队成员并被召去执行救援任务而中断——所以有些中断必须原谅。

### 总结与提醒

您可以通过仔细思考和计划来应对即使是最尴尬、最具挑战性或最令人不安的问题。

1. 提前为您知道可能存在弱点的领域做好准备。

2. 确保您提供作为推荐人的人事先知道并已授权您这样做。这不仅是礼貌，而且意味着，如果有任何令人担忧的领域，他们可能愿意与您提前讨论。

3. 接受有些面试会进行得很糟糕，您并不总能挽回局面。

4. 坦诚真实，但不要提供别人没有询问的信息；您不必把所有丑事都搬出来。

5. 请记住，如果没有真正的机会让您成为成功候选人，您绝不会被叫来面试，所以要保持积极。
