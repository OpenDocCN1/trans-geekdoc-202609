

问题只能存在于你的脑海中——在你的脑海之外，只有各种情况。你把一种情况称为问题，这表明了你的思维方式。一个人的问题可能是另一个人的动力来源。因此，你对所处任何情况的思考方式非常重要，因为它会产生后果。

在一天的交谈中，“this”和“that”这两个词被多次使用，但当它们用于任务和人时——例如“那个任务”或“这个人”——它们表明说话者与所指对象是关联还是疏离。当对任务/人有积极意图时，围绕它很可能存在积极心态——它是一个this。当对它没有积极意图时，围绕它很可能存在消极心态——它是一个that。

与某事疏离是拖延的根源。如果你可以选择不参与，那么就不会有问题，但当你不得不参与因为这是你的工作时，你就被迫关联，这时消极情绪可能会控制你的思维。在被迫关联的情况下，重新构建你的思维并将that转化为带有积极意图的this是有用的。

这里涉及四个关键原则：

1. 你可以与任务和人关联（this）或疏离（that）。当你以积极的方式关联时，你在情感上与之相连，并且很可能比当你与任务或人保持距离、从而变得疏离时取得更好的结果。表现不佳源于与that的“被迫关联”——当你在没有明确积极意图的情况下执行一个that任务时，你正在强迫自己与之关联，因此情感联系很可能是消极的。这就是表现不佳的配方。

2. 拥有有意识的积极意图为成功铺平道路——你的所有意图对你来说都是积极的，即使在其他人看来可能并非如此。你的潜意识可能会告诉你不要进行一项不愉快的任务，因为它的积极意图是让你感觉良好。拥有明确的积极意图并在任务中寻找好的方面，让你能够掌控自己的成功。正如明确的积极意图为成功清除障碍，没有它则会导致你挣扎。你的潜意识意图将是感觉更好并寻找方法，让你不必承担不愉快的任务或遇到让你感到不舒服的人。这样做，你会给自己带来压力和不适。

3. 当你夸大你思考情况的方式的荒谬性时，你就为改变奠定了基础。你可以在几乎任何事物中找到荒谬性，并利用它来创造改变。下一节将给出一个示例来演示这一点。

4. 将that改为this主要是关注什么是好的并拥有积极意图的问题。阴阳的概念表明，要在生活中实现平衡和流动，一切都必须包含其对立面的元素。热包含冷的元素，好包含坏的元素，反之亦然。因此，每个that都必须包含一个this的元素。不幸的是，当你专注于that时，你对undoubtedly存在的this视而不见。如果你选择专注于this并允许它发展和成长，你的结果将更加成功。

你将某事或某人视为that可能有无数原因。that的示例可能包括：

* 你不喜欢且不期待的活动

* 你觉得自己没有完全胜任以达到令人满意的标准完成的工作

* 你持有负面信念的人或事物

* 与个人价值观冲突的活动

* 你觉得难以相处或令人沮丧的人。

### 使用荒谬性来创造思维改变

你可以在几乎任何事物中找到荒谬性。考虑这句话：“我必须在每天下午6点前把晚餐摆上桌。”它暗示所有家庭成员每天都会在同一时间饿了并准备好吃饭。这种情况发生的可能性很小，因此，这句话是荒谬的。

这种技巧夸大你思维中的荒谬性。这样做，你的情况变得如此荒谬，以至于你会想要改变你的观点并重新构建它，因为继续以旧的方式思考太痛苦了。

Peter是一位项目经理，非常注重细节和程序。他被赋予了一个涉及Simon的重大项目的责任。Simon每次想到这个项目时都会变得越来越焦虑。

Peter和Simon从一开始就发生了冲突。当Peter坚持在会议上引入Simon认为不必要的细节时，Simon不知道如何应对。这开始影响他理性贡献的能力。他在项目团队面前会冷笑并对Peter的管理风格发表贬损评论。当被问及情况时，Simon回答说：“如果他想有所作为，他就需要学习一课——我会教训他，你放心吧。”

Simon得到了以下重新构建：

“那么，Simon，似乎你想继续对这段关系感到难过，不是吗？你将继续尖刻地攻击Peter，让其他人在你背后嘲笑你。你甚至不介意他们认为你表现得像个孩子。项目将受损，你的情感能量将被用于对Peter产生消极情绪，因此你将几乎没有剩余的能量用于项目的创造性工作。不过你不会介意，因为教训Peter比建立良好关系并成功完成项目对你来说重要得多。当你发现自己未来不再被邀请加入项目团队时，你的对抗行为将对你很有好处。你甚至可能发现自己完全没有角色，那也没关系，因为这里最重要的是让Peter出丑，不是吗？”

这种技巧可能看起来有点严厉，但对合适的人来说，它可能是最有效的工具。在这种情况下，Simon是那种让自我妨碍的人，因此这种技巧必须比他膨胀的自我更强大。Simon收到的是一种重新构建，使他从认为“Peter需要被教训”转变为“我的事业比我对Peter的感受更重要”。这给Simon的自我带来了足够的痛苦，使他放弃教训Peter的需要，而是对自己的思维和行为做出积极调整。

### 关注积极意图

荒谬性技巧对某些人可能有效（我们希望你尝试在自己处于状态X的情况下试用），但有时你可能需要更多积极的鼓励。无论你多么消极地看待一种情况或一个人，总能找到一些好的方面。
