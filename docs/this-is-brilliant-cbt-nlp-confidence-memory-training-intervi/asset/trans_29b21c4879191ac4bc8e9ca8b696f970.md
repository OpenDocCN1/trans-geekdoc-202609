本章将教你如何处理职业生涯历史中的任何薄弱环节和棘手问题、尴尬的问题、尴尬的停顿和刻薄的面试官。除非你是那种让我们其他人都感到烦恼的稀有人，他们一生顺风顺水，每个决定都结果良好，好运总是眷顾他们，否则你很可能有过去的某些方面（无论是考试成绩不佳、一段失业期、工作经历不连贯、健康记录不佳等），你不希望在求职面试中被问及。然而，你知道，由于这些问题是你历史的一部分，它们很可能从你的简历、申请表或雇佣和品格推荐信中浮现出来，因此很可能引起未来雇主的好奇。面试官确实希望对看似与你的历史和品格的其他证据相矛盾的结果或情况做出解释，并让他们心中充满疑问：“为什么？”

![image](images/00004.jpeg)

提醒自己，你已经被叫去面试了。你不是来凑数的，所以无论你认为自己有什么缺点，他们一定喜欢他们在纸面上看到的东西。

在准备回答可能适用于你的任何棘手问题之前，你应该记住，面试官问这些事情是因为他们真的想知道。他们想确定某个薄弱环节是暂时的失误，还是反映了更普遍的问题。你可能会被问及这些“阿喀琉斯之踵”的第二个可能原因是——面试官知道你可能会在这些问题上感到脆弱，他们想看看你是否会变得敌对或防御，或者你是否会抓住机会，运用你的沟通、说服、分析和冷静理性的技巧，提供合理且令人信服的解释。

## 关于真话的几句话

本书不承诺提供关于真话在求职竞争丛林中所处的哲学和道德地位的严谨分析。然而，它确实就此主题提供了一些常识性建议。如果你在简历和/或求职面试中隐瞒某些事情，你不太可能沟通得那么有效，也不太可能像你希望的那样放松和自然。你选择不说的事情、虚构的考试成绩、你编造的工作或由你妈妈写来增强你论点的推荐信，很可能会让你露馅。雇主几乎总是在雇佣你之前会查询推荐信，如果你在面试中不得不隐瞒真相，那么你就要问问自己，如果你是成功的候选人，你将如何维持下去。还要记住，如果雇主后来发现你对他们不坦诚，他们可能会以此为由解雇你或采取其他纪律处分程序。

本章涵盖了候选人感到焦虑的许多问题——以及一些应对这些问题的建议方法。

![image](images/00003.jpeg)

首先考虑这个示例问题和范例答案。这个问题和答案之后，是对使该答案成功的原因的快速分析。

![images](images/00038.gif)你有任何资格证书吗？

如果你有，那么这个问题不会让你感到脆弱；如果你没有，那么你想要组织一个良好、开放、热情的回答。

![images](images/00039.gif)我的主要优势在于实用且相关的工作经验。我在酒店行业工作了七年，并充分利用了大量内部培训课程。我一离开学校就开始当接待员：我迫不及待地想去工作并赚取薪水。在我目前担任助理经理的工作中，我处理过各种各样的问题，涉及客户方面和人力资源方面。如果机会出现，我当然很乐意参加相关资格认证；我认为这将有助于我未来的发展，并且抓住机会退后一步审视自己正在做的事情总是有用的。我不觉得纸面上没有资格证书迄今为止阻碍了我。

为什么这个答案有效：

* 它没有回避你没有正式资格证书的事实，但它避免发出粗鲁和令人生畏的“不”。
* 它迅速转向展示对培训的承诺。
* 它强调了职业阶梯的晋升。
* 它承认了一点急躁和过去可能做出的不明智的决定。
* 它保证这个决定没有造成严重后果。
* 它表达了对未来教育和学习的积极态度。

尝试分析本章后面的一些答案，看看它们为什么有效。当你制定自己的范例答案时，可以使用同样的技巧。

![images](images/00038.gif)我看到你的 GCSE 成绩非常好，但 A-Level 成绩却很差。发生了什么事？

![images](images/00039.gif)我不确定是否想留在学校读 A-Level；这是我父母推动的，但我并不真的愿意。我对其他事情太感兴趣了，我就没有付出应有的努力。

（对此的一个可能的后续问题，很容易引发防御性反应，可能如下。）

![images](images/00038.gif)那么，我可以认为，如果你不喜欢某件事，你就不再努力工作了吗？如果我们给你一份工作，而你发现其中有些部分你不喜欢，那怎么办？

![images](images/00039.gif)自从离开学校三年以来，我一直有良好的工作记录，在那段时间里，我处理常规和重复性任务没有任何困难。我从 17 岁以来长大了很多，我似乎在工作环境中比在学校环境中学得更好。不过，我正在参加一个网站设计的晚间课程，我真的很享受。

![images](images/00038.gif)你的简历上似乎有八个月的空档期。这段时间你在做什么？

![images](images/00039.gif)之前两年我一直在做临时工，我真的想要一些更有方向感的事情。事后看来，我可能应该等到有了固定工作再放弃临时工作，但我真的想专注于求职，并全心全意地投入。我没有预料到那段时间就业市场会如此糟糕。我通过参加一个短期的密集秘书技能课程让自己重新振作起来，并很高兴重新回到工作环境中。

![images](images/00039.gif)当然，我很失望——我希望拿到二等甲，我前两年的成绩表明我能达到这个水平。我在最后一年遇到了很多个人问题，这些问题现在都已过去并解决了，但它们确实影响了我的成绩。我的个人项目和小组项目成绩很好，我认为这些培养了我胜任这个特定职位所需的沟通、时间管理和信息收集技能——所以我知道自己在有用的、相关的工作技能方面很强。
