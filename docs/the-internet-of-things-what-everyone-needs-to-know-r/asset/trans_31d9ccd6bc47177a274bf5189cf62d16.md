

# 充当规范企业家的企业

充当规范企业家的企业可以通过帮助开创和传播标准与规范，在提升 IoE 安全性方面发挥重要作用，[^(85)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-806) 甚至可以组织评级和标签系统，清晰地“解释用户的安全责任”。[^(86)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-807) 美国国会某些派别青睐的网络风险缓解策略，例如网络风险保险，可以帮助企业在发生数据泄露时限制其风险暴露，[^(87)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-808) 但如果没有从一开始就注入最佳实践的主动策略，它们可能对提升整体网络安全帮助不大。[^(88)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-809) 还必须克服其他问题，例如“战争除外责任”，这可能会因被保险实体在网络战争中被归类为“附带损害”而限制赔偿。[^(89)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-810) 此外，必须使用强大的信息共享机制来分析投资的类型和范围，以灌输技术、预算和组织方面的最佳实践。[^(90)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-811) 还需要做更多工作来澄清责任结构，从而界定责任和问责的边界，[^(91)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-812) 包括充当“守门人”，位于“我们家庭与互联网其余部分之间”的互联网服务提供商（ISP）。[^(92)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-813) 最重要的是，科技公司应当实践预防原则，该原则指出：“当潜在危害巨大时，我们应当在没有安全性证明的情况下，宁可不部署新技术。”[^(93)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-814)

# 政府促进网络安全尽职调查

在更高一级，政府可以做更多工作来促进 IoE 中的网络安全尽职调查，例如成立网络和平部队、国家网络安全委员会，[^(94)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-815) 甚至成立网络空间国际刑事法庭。[^(95)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-816) 各州已经开始行动。除了加利福尼亚州（在[第 5 章](#14_chapter5.xhtml#actrade-9780190943813-chapter-5)中讨论）之外，俄亥俄州通过提供安全港，鼓励投资于网络安全最佳实践和框架的公司。[^(96)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-817) 二十五个州也通过了反 DDoS 法律，另有五个州专注于勒索软件这一紧迫问题，仅 2016 年一年，勒索软件变体就增加了五倍。[^(97)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-818) 其他州专注于从 IoT 设备中移除不安全功能，并加强事件响应计划。[^(98)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-819) 同样，二十多个国家正在尝试各种自下而上的网络安全风险管理方法，这些方法模仿 NIST CSF。[^(99)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-820) 联邦政府在解决本书中讨论的集体行动和搭便车问题方面也发挥着无价的作用。[^(100)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-821) 例如，它可以制定基准标准、基于结果的规则、规范和组织机构。[^(101)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-822) 法院也可以帮助培养网络安全尽职调查，甚至追究高管在其任期内发生数据泄露的责任。[^(102)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-823) 当然，这一切都不简单，[^(103)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-824) 而且很容易走得太远；正如施奈尔所指出的，“如果计算机像梯子一样受到产品责任法规的约束，它们可能至今还无法上市。”[^(104)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-825) 但鉴于利害关系，美国政府可以而且必须在 IoT 治理方面发挥更大的领导作用，[^(105)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-826) 否则其他人将填补真空。

# 全球网络安全合作

在全球范围内，七国集团在 2016 年继续开展网络安全工作，发表了其观点，即“没有任何国家应该进行或明知支持 ICT（信息和通信技术）赋能的知识产权盗窃”，并且所有七国集团国家都应努力“保护互联网的全球性”，包括信息的自由流动，这暗示了将网络空间视为“全球网络公地”的概念。[^(106)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-827) 双边关系，例如 G2（美国和中国）、小多边俱乐部（包括五眼联盟 \[FVEY\] 和北约），以及最终的国际社会，也必须在这一多中心努力中积极主动，以传播网络安全尽职调查并促进网络和平。部分原因是人们认为网络风险“正在失控地升级”，[^(107)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-828) 因此存在开展关于规范建设的建设性国际对话的机会。一个想法是借鉴 2015 年巴黎协定模式，各个国家和俱乐部可以在年度缔约方大会（COP）聚会上宣布“网络和平承诺”，以帮助推动就 IoT 治理达成全球协议，其中包括澄清现有国际法如何适用于 IoT。所有这些都可能为最终（尽管仍显空想）的联合国网络和平框架公约奠定基础。然而，即使是这一结果，也不是终点线，而只是另一个里程碑——成功治理 IoE 需要我们所有人尽自己的一份力。

# 我能做什么？我们需要你！掌控局面，要求更好，做一名负责任的网民。

在 20 世纪 70 年代，人们对食品安全普遍存在担忧。英国科学家阿尔伯特·霍华德爵士正在倡导将养分归还土壤，帮助开启了有机运动。[^(108)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-829) 然而，正如我们现在看到的 IoT 认证计划一样，最初面向消费者的有机食品计划是分散的，基本上是各州各自为政的事务。直到 1990 年，国会才通过《有机食品生产法》（OFPA），最终引入了全国有机食品标准。定义有机食品生产和处理的最终法规直到 2002 年才颁布。[^(109)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-830) 总的来说，适当标记有机食品的探索花了近四分之一世纪，与汽车安全相比，这已经非常快了。最早推动改善汽车安全的流行报告之一由《大众科学》杂志于 1950 年发表。[^(110)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-831) 但之后又花了近二十年，碰撞测试结果才被公布，以向消费者告知汽车不同的安全性能。第一项强制使用安全带的美国法律直到 1984 年才通过。
