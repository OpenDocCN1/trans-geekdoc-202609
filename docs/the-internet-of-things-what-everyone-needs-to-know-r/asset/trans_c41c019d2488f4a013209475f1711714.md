

# 基础设施有限和高昂成本延迟了我们今天所认为的物联网的实现

在 1990 年代，尽管越来越多的企业开始实现更广泛的互联网连接，但速度缓慢和网络架构不佳仍然限制了联网机器的使用。[^(19)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-149) 物联网技术的潜力可以说直到 2010 年才得以实现，[^(20)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-150) 这是至少三个因素汇合的结果。首先，宽带互联网的日益普及提供了高速网络连接，使设备能够通过无线网络在发达世界的大部分地区相互通信。[^(21)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-151) 其次，增强的计算能力使大量非结构化数据的实时分析成为可能。[^(22)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-152) 第三，传感器成本的降低使制造商能够以微小的增量成本向任何设备添加小型无线芯片。[^(23)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-153) 这些因素的结合创造了智能互联设备的完美环境，催生了物联网（以及最终的 IoE）。进一步的进步，[^(24)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-154) 例如由机器学习和 AI 带来的计算能力提升，或包括 5G 推广在内的改进的连接性和通信，将使更大的增长以及新功能成为可能。确实，正如 Schneier 所主张的，来自物联网、机器学习、AI、云计算和机器人的趋势线相互加强，导致了“一个感知、思考和行动的互联网”。[^(25)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-155)

没有通用的物联网定义，部分原因可能是该术语描述的是“定义我们如何与物理世界交互的新概念”，而不是一种技术架构类型。[^(26)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-156) 尽管如此，组织和个人仍提出了描述它的方式，强调了一些共同的元素和主题。2014 年，美国国家安全电信咨询委员会（NSTAC）将物联网描述为一个去中心化的设备、应用程序和服务网络，可以“感知、记录、解释、通信、处理并对物理环境中的各种信息或控制设备采取行动……”。[^(27)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-157) 2015 年，一份电气和电子工程师学会（IEEE）出版物认为物联网架构有三个层级：感知；网络和数据通信；以及应用。[^(28)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-158) 2017 年，一家物联网公司 Leverage 的一位总监将物联网解释为一个“集成四个不同组件：传感器/设备、连接性、数据处理和用户界面”的系统。[^(29)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-159) 传感器生成数据，这些数据通常通过（例如，通过蜂窝、卫星、蓝牙、Wi-Fi 等连接）发送至和/或发送到云服务进行处理（从检查温度读数是否在可接受范围内，到使用计算机视觉识别物体，例如家中的入侵者）；最后，用户可以访问这些信息并可能采取行动。[^(30)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-160) 云服务还可以帮助维护为物联网设备提供动力的软件，提供更新或安全监控。累积起来，这些功能为物理设备增加了一层“数字智能”。[^(31)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-161)

物联网现在已经从一台智能售货机发展到包含相当不同的网络星座。[^(32)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-162) 确实，描述物联网的另一种方式是区分相对复杂度较低的“小”场景（例如，一个网络上的几个东西）和复杂度较高的“大”场景（例如，许多东西和/或网络）。[^(33)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-163) 从使用预测分析来了解用户行为模式以创建定制供暖时间表的智能恒温器，到智能人行道，都有可以获取的信息和可以提取的价值。[^(34)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-164) 但随着连接性、分析和管理能力的提高，HVAC 系统可以与其他网络（例如电话服务、安全和照明网络）集成，以创建可远程控制的交互式智能家居环境。随着物联网的成熟，不同的智能住宅和商业网络也将能够相互通信，创建智能（且可能更具韧性）的城市。[^(35)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-165) 在宏观层面，这一结果类似于网络早期的日子，当时 Cisco 使用多协议路由连接不同的网络。这最终导致了名为互联网协议（IP）的通用网络标准的创建，该标准是互联网的基础，并且至今仍被大量依赖。物联网似乎将遵循类似的路线，尽管规模更大，涵盖无数个行业和领域。

## 互联网上不同类型的“东西”的增长预测是什么，它们准确吗，为什么它们很重要？

2018 年，三星承诺到 2020 年使其*所有*设备（包括电视和冰箱以及可穿戴设备）实现联网和智能化。[^(36)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-166) 前谷歌主席 Eric Schmidt 更进一步，预测“互联网将消失。会有如此多的 IP 地址……如此多的设备、传感器、你穿戴的东西、你正在交互的东西，以至于你甚至感觉不到它。它将始终成为你存在的一部分。”[^(37)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-167) 虽然在短期内不太可能，但许多，也许大多数，设备在中期内将连接到互联网的可能性是真实的。在 2018 年推出 Azure Sphere 时（有关 Azure Sphere 的更多信息，请参见[第 3 章](#12_chapter3.xhtml#actrade-9780190943813-chapter-3)，这是一个旨在提高安全性的物联网解决方案），Microsoft 强调，今天，许多日常设备都有微控制器（MCU）——一颗通常比你的指甲还小的小芯片。确实，每年部署超过 90 亿个 MCU 驱动的设备，但今天很少有设备连接到互联网。[^(38)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-168)
