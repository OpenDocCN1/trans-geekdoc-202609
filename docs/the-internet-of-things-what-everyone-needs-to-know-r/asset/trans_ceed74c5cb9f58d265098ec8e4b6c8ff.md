

# 物联网治理

任何年龄段的陪伴益处都有充分的文献记录。根据美国疾病控制与预防中心的说法，“研究表明，人与宠物之间的纽带可以提高体能、降低压力，并给主人带来幸福。”[^(90)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-453) 然而，有时老年人可能无法照顾宠物。相反，一些人正在转向各种机器人伴侣，例如孩之宝的“快乐岁月”系列，其中包括一款售价99美元的逼真陪伴宠物猫。[^(91)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-454) 遗憾的是，此类数字伴侣可能会加剧对监控和隐私的担忧，这对老年人来说可能尤其成问题，因为他们更容易成为身份盗窃和其他类型网络犯罪的受害者。[^(92)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-455) 总的来说，研究人员和记者已经记录了家庭中物联网设备普遍使用所收集的大量信息，“从我们刷牙的时间，到我们开关灯的时间，我们流媒体音乐的时间，我们在Hulu上观看的内容，以及我们睡眠的质量。”[^(93)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-456) 类似地，机器人吸尘器公司iRobot于2018年宣布，打算将其设备生成的用户家庭地图分享给谷歌、Facebook和Apple等公司。[^(94)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-457)

基于后果、美德和规则的伦理传统可以帮助指导各种物联网技术的推广。第一种基于后果的方法示例是编程自动驾驶汽车以保护一群行人（甚至可能以牺牲单独驾驶者为代价），这符合功利主义及其现代迭代——成本效益分析。麻省理工学院的道德机器代表了对这类问题进行众包的努力，向参与者展示各种场景，并允许他们选择失控自动驾驶汽车应如何行为。[^(95)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-458) 其次，物联网公司可以在其产品和服务中展示美德（道德品格），确保其符合诚实（即数据处理实践中的透明度和准确性）等特质。第三，公司可以内化规则和义务，例如GDPR（在[第5章](#14_chapter5.xhtml#actrade-9780190943813-chapter-5)中探讨），并与商业合作伙伴合作制定一般行为准则，这些准则可能最终成为全球标准。[^(96)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-459)

考虑到收集的数据量巨大，以及物联网固有的近乎持续的监控，并搁置在[第5章](#14_chapter5.xhtml#actrade-9780190943813-chapter-5)中讨论的潜在法律责任，围绕物联网存在一系列具体的伦理问题。大多数问题都围绕数据收集的方式、收集谁的数据，以及谁在数据收集后（以及保留多长时间）控制数据展开。[^(97)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-460) 这些概念在以下三大类别中成形，涵盖了普遍的伦理问题：（1）访问，（2）控制，以及（3）隐私。

## 访问与信息使用

连接性的增加降低了用户避免物联网产品的能力，即使他们希望如此；我们中的许多人，无论是有意还是无意，都在被同化进物联网环境，无论我们是否喜欢。[^(98)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-461) 除了同意之外，其他伦理问题还围绕数据收集对不同群体可能产生的不成比例的影响。这包括这样的担忧：社会中的老年成员可能拥有潜在更多的资源和数据，因此在发生泄露时风险更大。这一情况因他们可能对如何保护数据的理解不够成熟而更加复杂，尽管调查对此观点存在分歧。[^(99)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-462)

## 控制与财产权

当万物互联时，谁是最终用户，谁是收集者？一旦数据被各种物联网设备收集，谁有权使用它，用于什么目的？随着系统变得集成且日益自主，数据是否会导致不同群体受到不同待遇的差异？[^(100)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-463) 换句话说，算法的已知偏见——无论是有意还是无意——可能会被新的物联网应用所助长并进一步加剧。[^(101)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-464) 随着政府开始将物联网设备收集的数据纳入其流程，此类结果引起的关注日益增加，这一点体现在：进入美国旅游或移民的人在被要求时必须提交手机进行检查。[^(102)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-465)

## 隐私与信息完整性

一个相关的担忧围绕着数据收集者是否应在信息收集前获得同意，[^(103)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-466) 以及所给予同意的范围，以及如何最好地将其针对特定目的进行定制。[^(104)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-467) 例如，许多患者同意收集其医疗数据用于治疗，但这是否应隐含包括研究？如果医院将这些信息与第三方共享呢？隐私保护倡导者有理由质疑，鉴于通知和同意经常无法保护个人隐私，任何此类制度是否有效。[^(105)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-468) 事实上，根据一项研究，阅读普通互联网用户一年访问的网站的所有政策大约需要一个月的时间。[^(106)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-469)

为了帮助应对这些伦理挑战，一些人，例如弗雷德·凯特教授和维克托·迈尔-舍恩伯格教授，主张更新共享隐私原则，包括：收集限制、数据质量、目的明确、使用限制、安全保障、公开性、个人参与和问责制。[^(107)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-470) 相关地，还有关于用户操纵的令人担忧的问题需要考虑，这可能需要制定伦理行为准则。[^(108)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-471) 一些公司（如礼来公司）正在探索的另一种选择是，不仅将网络安全视为经营成本，而且将其视为竞争优势和企业社会责任。其论点是，企业界（以及国家安全）从长远来看，将私营部门风险管理实践采取如此广泛的视角以涵盖不太传统的因素（类似于公司在可持续性方面所做的）符合其自身的长期利益，这一点将在[第5章](#14_chapter5.xhtml#actrade-9780190943813-chapter-5)和[第6章](#15_chapter6.xhtml#actrade-9780190943813-chapter-6)中进一步探讨。[^(109)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-472)
