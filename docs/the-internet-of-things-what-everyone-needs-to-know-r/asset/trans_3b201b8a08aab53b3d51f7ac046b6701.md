

# 在家庭环境中，这些传感器可以帮助提供安全性、能源效率、便利性、新颖性、专业知识（即，让你像专业人士一样烹饪或追踪你的跑步姿势），或人际连接。[^(87)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-217) 在安全性方面，除了 Ring，智能家居安防系统使用图像和运动传感器来监控谁进出（或儿童或老人的健康状况），智能烤箱可能会使用温度或气体传感器在发生故障时发送信号。在感应式电磁炉的情况下，专业知识可能由压力和化学传感器实现，这些传感器仅在金属锅放置在上面时加热——不再有无人看管的燃烧器运行，也不再有锅被过热。[^(88)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-218) 为了进一步提高能源效率，运动检测和光学或红外传感器可以提供局部加热，液位和湿度传感器可以帮助智能热水器和洗衣机提醒你泄漏，或让 HVAC 系统发出信号表明它们需要预测性维护。Roombas 提供便利和新颖性（去看看 Instagram 上的那些猫视频），需要近距离和压力传感器。为了改善人际连接，图像和运动传感器不仅可以帮助传输亲人的面孔，还可以通过在有人携带连接设备移动空间时触发，来创造物理接近感或意识。

# 在工业 IoT 中，许多相同的传感器用于类似目的，但也存在差异；例如，即使在特别恶劣的环境中，工业传感器也应能够发出信号表明特定条件正在被保持。[^(89)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-219) 虽然传感器在制造业中已使用数十年，但在 IoT 技术之前，它们受到信号噪声、信号衰减（即，信号减弱）和响应动态等问题的限制；IoT 已改变了传感器，使它们能够用于更多机器（因为它们可以更小且更灵活），执行更复杂的计算，并具有更多功能。[^(90)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-220) 广义上讲，工业 IoT 传感器可以提高对现有工作流程和流程的可见性，帮助预测不同环境中的结果，或创造新的商业模式；例如，Kaeser Compressor（一家传统制造和销售压缩空气机器的德国公司）通过使用 IoT 传感器意识到，他们还可以将压缩空气作为一种服务提供。[^(91)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-221) 更具体地说，工业 IoT 传感器倾向于实时监测和测量温度、速度、重量、位置、操作故障、操作变化、物体移动和阀门状态等条件，以及机器性能、氧气水平和员工心率。[^(92)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-222) 最终，这些传感器提供几个关键好处，包括：设备和环境条件的维护、满足监管要求、改进和自动化物流和资产管理，以及控制能源成本。[^(93)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-223)

# 传感器是 IoT 设备的核心，使能够收集可用于增强功能的数据。然后数据在设备上进行处理，利用连接性，并执行某些功能，要么自动执行，要么响应用户输入。这是 IoT 设备和服务的真正附加值——也是引入大部分风险的地方，这将我们带到 IoE 革命中更具挑战性的方面。

成功有时会带来意外或适得其反的后果。例如，正如 Kleenex、Q-Tip 和 Band-Aid 的制造商所知道的那样，广泛的成功可能导致商标在美国和其他地方变成“通用化”，从而破坏品牌在独特标识符上的投资。在互联网的情况下，成功削弱了关于安全性如何运作的假设。早期互联网开发者更关注互操作性而非安全性，因为他们正在为一个相对较小、受信任的技术专家社区构建网络，但指数级增长带来了许多新的互联网用户，使得内置安全性变得更加重要。[¹](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-238) 此外，速度、效率以及抢占市场先机的愿望长期以来一直胜过安全性，至少直到 2000 年代初期登上头条的病毒出现为止。[²](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-239)

今天，随着万物互联（IoE）的普及并影响我们生活的许多方面，这种背景为日益庞大的生态系统中的安全问题奠定了舞台，该生态系统从消费品延伸到智能制造及更远的领域；甚至 NASA 现在也在帮助将物联网（IoT）带到最后的边疆。[³](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-240) 因此，IoT 为安全性带来了巨大的挑战，在几十年来不断累积的网络安全问题之上，叠加了新的威胁、漏洞、后果以及技术和技术架构，尽管这些问题正日益受到重视，解决这些问题的努力也在不断增加。本章将深入探讨这些影响，从基础安全问题开始，然后再讨论智能灯泡这个看似美妙的想法。

### [IoT 的一些基础安全挑战和好处是什么？](#05_Contents1.xhtml#n0017)

IoT 设备本身以及它们利用的服务和网络都面临安全挑战。首先，IoT 设备依赖的网络和基础设施（包括移动网络）必须受到保护并具有弹性。此外，IoT 设备和服务面临着与其他由硬件和软件组成并由用户交互的系统和程序类似的问题，例如漏洞（即代码中的弱点）[⁴](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-241）和不良的用户卫生习惯（例如，弱密码、延迟打补丁或安装更新，以及成功的“网络钓鱼”或“精准网络钓鱼”诈骗）。[⁵](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-242) 移动技术的挑战也凸显了 IoT 设备在更广泛部署并以更集成的方式与家庭和工作环境中的用户交互时可能带来的一些潜在问题。虽然增加的用户功能推动了消费者中移动设备的增长，就像 IoT 应用程序一样，[⁶](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-243) 但这种增长也扩大了必须防御的“攻击面”。[⁷](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-244)
