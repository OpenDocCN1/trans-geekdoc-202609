

# 克服这些挑战，以实现对 IoT 技术的有效监管

克服这些挑战，以实现对 IoT 技术的有效监管并非易事。仅数据治理就是一项巨大的挑战，据思科（Cisco）估计，数十亿台 IoT 设备每天产生超过 5 京字节的数据，这一数字预计将呈指数级增长。[^(17)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-489) 这种数据积累水平引发了各种担忧——包括谁有权访问这些数据，他们可以在多大程度上使用这些数据（用于分析、转售等），以及数据应如何安全存储——每一项都需要在多个治理层面采取不同的应对措施。[^(18)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-490) 例如，在美国语境下，取决于涉及的设备或应用程序，一系列机构（FDA、FCC、FTC 等）对 IoT 拥有一定的管辖权。[^(19)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-491) 还有相关问题，即过于严格的监管可能会阻碍创新，尽管一些评论家如布鲁斯·施奈尔（Bruce Schneier）认为 IoT 法律实际上可以激发创新。[^(20)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-492) 例如，买家对 FDA 批准的产品表现出更高的信心。[^(21)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-493) 消费者对 IoT 技术信任度的提高——或许由政府支持的标准或认证计划推动——同样可以增强信任，从而带动销售。

尽管如此，尽管存在困难，但不言而喻的是，当今绝大多数消费者（在一项 2017 年的调查中超过 90%）对 IoT 设备的安全性缺乏信心。[^(22)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-494) 最近的攻击，如前言中介绍并在 [第 3 章](#12_chapter3.xhtml#actrade-9780190943813-chapter-3) 中讨论的 Mirai 僵尸网络，加强了人们对 IoT 普遍存在漏洞的看法（这种看法往往是准确的）。作为回应，本章余下部分将探讨保护 IoT 中数字隐私和安全的三种主要方法，即：(1) 允许自由市场创新来提供一套解决方案；(2) 依赖州、联邦和国际法规来强制执行安全和隐私标准；或 (3) 利用上述方法的组合，在多中心方法中确保充分的保护。

正如我们将看到的，基于市场的方法侧重于教育消费者、鼓励行业最佳实践，并利用当前的执法工具更好地保护消费者的数据完整性。[^(23)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-495) 虽然自由市场鼓励创新，但不太可能产生消费者所期望的全面保护。缺乏有效的市场机制来激励企业和制造商改进数字安全。[^(24)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-496) 目睹市场未能充分惩罚遭受网络攻击的公司，正如 2018 年国家经济研究局的一项研究所记录的那样，该研究发现受影响组织的股价立即仅下降了 1%。[^(25)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-497)

没有单一途径能够管理 IoT 面临的全部威胁。需要采取全方位的方法来增强数字隐私和安全。[^(26)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-498) 越来越多的人认识到，这种多中心方法是前进的首选路线。这种多层级、多目的、多功能、多部门的模式，由包括诺贝尔奖得主埃莉诺·奥斯特罗姆（Elinor Ostrom）和文森特·奥斯特罗姆（Vincent Ostrom）教授在内的学者倡导，通过展示自我组织的好处、在“多个层级”上建立网络化法规，以及考察国家和私人控制在多大程度上可以与社区管理共存，来挑战正统观念。[^(27)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-499) 正如文森特·奥斯特罗姆教授最初解释的那样，“多中心政治体系将由以下部分组成：(1) 许多彼此正式独立的自治单元，(2) 选择以考虑他人的方式行事，(3) 通过合作、竞争、冲突和冲突解决的过程。”[^(28)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-500) 在许多方面，这种治理模式——已被应用于从管理内城警察分局[^(29)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-501)到适应气候变化[^(30)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-502)乃至减轻轨道碎片[^(31)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-503)等各种集体行动问题——非常适合解决动态（且往往碎片化）的 IoT 问题，因为涉及众多不同的参与者和技术。这些应用的示例包括域名系统本身的问题，技术社区为此开发了一项安全升级，但直到二十多年后仍未得到实施，原因是“它需要大多数网站采用后，任何人才能看到好处。”[^(32)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-504) 没有治理系统是完美的，多中心主义也有其缺点，例如对僵局和缺乏明确层级的担忧。[^(33)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-505) 但这种方法可能有助于将关于“事物安全”的辩论引向更具建设性的方向，作为促进一定程度网络和平的总体运动的一部分。[^(34)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-506)

## 自我组织在 IoT 中可行吗？

多中心治理的一个重要方面是自我监管。[^(35)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-507) 在某些情况下，自我监管比成文法更能更好、更快地适应快速变化的技术和社会力量。它也可能比命令控制式监管更高效、更具成本效益，[^(36)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-508) 但它并非万能药，因为此类努力是自愿的，并受市场力量（例如，消费者需求变化）的影响。[^(37)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-509) 只需回顾 Facebook 承诺改革及其未能做到的情况，就能明白为什么呼吁结束互联网平台自我治理的声音正在日益高涨。[^(38)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-510) 不过，一些监管者，如前 FTC 主席莫琳·奥尔豪森（Maureen Ohlhausen），曾表示支持允许 IoT 提供商自我监管，[^(39)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-511) 这一观点也得到了美国参议院的一项决议的呼应，该决议强调了私营部门在开发和监管 IoT 应用中的核心作用，以及决策者对这一问题所给予的重视程度。[^(40)](#17_Notes.xhtml#actrade-9780190943813-miscMatter-10-note-512)
