# 44.2.2 Virtual Waypoints

The methodology of this document recommends basing the selection of waypoints directly on the digital twins. Using the software BIM, this process can be performed on the georeferenced 3D model during the infrastructure design phase. Alternatively, you can use the Unreal Engine to set up waypoints by simply specifying targets. Once these locations of interest have been established, the proposed methodology allows for the autonomous creation of UAV trajectories to facilitate data collection and avoid aircraft collisions.
