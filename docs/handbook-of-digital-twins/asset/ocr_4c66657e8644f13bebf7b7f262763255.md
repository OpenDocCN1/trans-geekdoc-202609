The trajectory planning problem is thus concerned with the real-time planning of the actual vehicle’s transition from one feasible state to the next, as well as the corresponding acceleration (or velocity). At each planning cycle, hence, the path planner module generates a set of possible trajectories from the vehicle’s current location, and evaluates the optimal trajectory with respect to their length, duration and safety score referred to the probability of collisions with other vehicles, workers or obstacles.
