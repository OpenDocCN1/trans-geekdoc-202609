| Data File Type | Extension | The Main Type of Data Stored | Type of Research | Availability of Time Stamps |
| :--- | :--- | :--- | :--- | :--- |
| FEF | .FEF | Biological signal | Electrocardiogram | There is a field for a sequence of time values |
| UFF | .BDF | Multichannel biological signal | Electroencephalogram | There are four fields for time values: * "Start date of recording", * "Start time of recording", * "Number of data records", * "Duration of a data record, in seconds" |
| LabPas HL7 | .HL7 | The result of a blood test | Blood test | There is the field “Date/Time of the Observation” |
| UFF | .UFF | Ultrasound data | Ultrasound | There is the field “local_time” |
| NIFTI | .NII | MRI data | Magnetic resonance imaging | There is a reserved field for time values |
| DICOM | .DC3, .DCM, .DIC | Medical images and metadata | Computed tomography, radiography, etc. | There is the field “Study date” ra “Study time” |
| CSV | .CSV | Integers and real numbers (ASCII) | Spirometry, thermometry, sphygmomanometry, etc. | No |
