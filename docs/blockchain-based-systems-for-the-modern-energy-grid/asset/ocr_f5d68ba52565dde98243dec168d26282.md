# 12.2 Types of blockchain technologies

# 12.2.1 Public blockchain network

Anyone can join public blockchains, and all the information is accessible by them. This makes blockchains suitable for firms that value transparency and trust concerns in data storage. As a result, NGOs and social support organizations can benefit from the public blockchain. The public blockchain is depicted in Fig. 12.2.

Because of its public nature, the data stored by a public blockchain cannot be used for private-sector operations since the information is not secured for the use of just one entity or organization but can be accessed by anyone. Furthermore, public blockchains can be costly to maintain since they require nodes to function as miners and run either proof-of-work or proof-of-stack (PoS) algorithms (PoS).
