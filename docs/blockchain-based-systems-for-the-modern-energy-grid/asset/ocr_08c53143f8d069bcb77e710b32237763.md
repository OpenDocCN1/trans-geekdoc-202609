# 12.2.3 Consortium blockchain network

Next, rather than a centralized node (private) or a decentralized (public) network, a consortium blockchain network is functioned by a group of organizations or nodes.

A consortium blockchain is advantageous since it includes nodes that have been pre-selected.

It’s great for a solution that necessitates cross-departmental cooperation. Supply chain, food, and medicine, for example, would all necessitate cross-brand collaboration.

# 12.2.4 Hybrid blockchain network

Finally, we have the hybrid blockchain, which is the most recent blockchain technology type. This blockchain combines all of the advantages of both private and public blockchains with the least number of drawbacks.

In actuality, the hybrid blockchain, like other blockchain technology types, has drawbacks though fairly minor ones.

Hybrid blockchains appear to be ideal for a variety of prospective business models.
