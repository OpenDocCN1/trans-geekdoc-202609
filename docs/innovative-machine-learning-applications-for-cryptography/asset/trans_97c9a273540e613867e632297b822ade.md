

# 密码分析中的预测建模与机器学习

利用数据建模预测未来事件的过程称为**预测建模**。一旦发现机器学习算法预测输入的趋势，便可投入更多精力为更稳健的加密技术创建模型。对于这类情况，预测建模效果良好，而利用机器学习提供精准预测则是理想方法（[AWS Dashboard, n.d.](#979-8-3693-1642-9.ch009.xhtml#r3)）。与机器学习这一更广泛的领域（可处理任何类型的数据）不同，预测建模主要处理表格数据（[Brownlee, 2021](#979-8-3693-1642-9.ch009.xhtml#r4)）。

## DES 算法概述

**DES** 中十六轮操作的每一轮都使用不同的轮密钥和相同的过程。**DES** 轮函数以由上一轮生成的密文作为输入，输出被分为左、右两半的密文，作为下一轮的输入。这种置换通过移动比特位置来运作。32 位值通过 Mangler 函数（扩展置换函数）从 32 位扩展到 48 位，然后将 48 位密钥代入该 32 位值中（[YouTube, n.d.](#979-8-3693-1642-9.ch009.xhtml#r21)）。

## 支持向量机 (SVM)

名为**支持向量机**的学习算法是最优秀的“开箱即用”监督学习算法——甚至许多人认为它是最好的。在讲述 **SVM** 的故事之前，我们必须先讨论间隔以及用显著“间隙”分离数据的概念。随后我们将通过讨论最优间隔分类器，涉足拉格朗日对偶性的话题。此外还将讨论核函数，它为在极高维（即无限维）特征空间中应用**支持向量机**提供了有效方法（[Ng & Notes, n.d.](#979-8-3693-1642-9.ch009.xhtml#r12)）。根据 Lipo Wang 的说法，**SVM** 在机器学习领域是一种相当节省内存的技术（[Wang & Machines, 2005](#979-8-3693-1642-9.ch009.xhtml#r20)）。它在高维领域也很有效。因此，这是对称加密算法预测输入的首选方案。

# 方法论

本文旨在探究机器学习算法如何逆向工程哈希函数，后者用于加密并被认为不易被逆向工程。直接导入免费源库即可获得 **DES** 算法。**SVM** 算法可在 Jason Brown 的电子书《Machine Learning Mastery》中找到。

**DES** 用于加密固定大小的数据。初始消息被分割成 64 位分块。置换发生在分割后的数据上：左半部分分给 `xor` 函数，然后应用于右半部分。右半部分随后分给左半部分，并扩展为右侧的 48 位，该 48 位由分割而来并收缩，再次发生置换，随后 `xor` 应用于右侧。每个子密钥总共执行 16 次。密文的右侧和左侧被分割为置换和逆置换。左侧生成密钥和右侧分组密文是加密的两个组成部分。对密钥执行二进制转换，并对 **DES** 数据类型执行 ASCII 到十六进制再到比特的转换（[Exchange, n.d.](#979-8-3693-1642-9.ch009.xhtml#r8)）。利用 56 位密钥加密多个 64 位块。首个输入为 64 位值。它是一个八字节字符串密钥。打印 0 和 1 并创建随机字符串，以使数据为机器学习例程做好准备。由于结果与先前运行无关，因此具有不可预测性，故可重复执行。

## DES 实现算法

**DES** 实现算法如下：

1.  从 `mit` 库导入 `Pydes` 的 `permute`，用于密钥置换的数据置换（[Github Code Resource, n.d.](#979-8-3693-1642-9.ch009.xhtml#r9); [Robin David, n.d.](#979-8-3693-1642-9.ch009.xhtml#r15)）
2.  生成 `pydes` 字符串至 `birs` 数据，使用密钥加密数据，输出数据
3.  下一步训练测试，保留 `t` 作为输入的最后一位，分割训练集 `x`, `y` 和测试集 `x`, `y`
4.  使用密钥进行 `pydes` 加密
5.  `T` 输入数据比特，输出过期比特
6.  `T’` 输出数据比特，输入数据比特
7.  已知训练集和测试集
8.  数据准备好供机器学习算法使用

破解 **DES** 意味着找到一个将该明文映射到该密文的密钥（[Speciner et al., 2002](#979-8-3693-1642-9.ch009.xhtml#r17)）。

1.  首要任务是将 64 位转换为字节
2.  `T’` 是 `outdata`（**DES** 加密后）**`indata[0]`**（输入的第一位）
3.  `T’` 输入 `xg`
4.  每次运行都会得到不同的 `xo`
5.  机器学习算法 **SVM** 每次运行都会针对训练集进行测试
6.  然后混淆矩阵测量最后一次运行 `exp`
7.  用于创建模型的样本称为训练数据集。
8.  测试集用于评估性能。

每次实现都会产生独特且不可预测的结果。用于测试的数据与用于训练的数据是分开的。对于由两个字符串组成的元组列表，神经网络充当“识别器”。初始字符串被加密，后续字符串包含加密的明文数据。数据包含在两个表中。模型被输入字符串，而测试端忽略输入。测试端忽略输入并使用 200 个元素创建输出，而 **DES** 算法加密训练数据，每个测试用例 `N=200`、`N=100` 或 `N=300`。

## 混淆矩阵结果

### 运行 1
**准确率 46.00%** ，混淆矩阵：
*   `[50 50]`
