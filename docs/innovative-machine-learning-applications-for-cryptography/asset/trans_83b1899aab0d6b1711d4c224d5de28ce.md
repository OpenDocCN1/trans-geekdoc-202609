
自那时起，同态加密（HE）已成为一个快速发展的研究领域。研究人员提出了越来越有效且实用的方案。这些技术突破源于数据隐私和安全在云计算、金融、医疗等领域日益重要的地位。密码学家、数学家和计算机科学家之间的合作一直是HE发展的显著特征。

同态加密如今在安全数据处理的探索中处于领先地位。在大数据和云计算时代，隐私比以往任何时候都更重要，这被视为一项必不可少的技术（[A. Singla, N. Sharma 2022](#979-8-3693-1642-9.ch010.xhtml#r17)）。在后续关于HE的章节中，我们将看到这项技术不仅仅是一个概念，实际上可以成为人们用来彻底改变我们处理和加工信息方式的工具。

## 2. 同态加密技术

密码学最初的构想是创建一个能够保证各实体间安全通信的系统。一方加密消息并发送给另一方，后者对其进行解密（[A. Singla, N. Sharma 2022](#979-8-3693-1642-9.ch010.xhtml#r17)）。在加密数据上进行计算的想法最早由Rivest、Adleman和Dertouzos于1978年作为“隐私变换”提出。目前所知的同态加密正是随着时间的推移从这一想法发展而来的。广义上讲，同态加密允许我们在加密数据上进行计算。如果一个方案具有以下特征，我们称其为加法（或乘法）同态：

```
[x] ⊕ [y] = [x + y] and [x] ⊗ [y] = [x · y]
```

在此语境下，字母`[⊗]`代表明文值的加密，而字符`⊗`和`·`表示在密文空间中执行的同态加法和乘法运算。简单来说，如果一个加密系统是加法同态的，那么先加密数据再相加，等同于先将数据相加再加密。图1展示了这一思想的实际应用。

### 部分同态加密（PHE）

部分同态加密方案专门用于允许对加密数据执行特定类型的操作。这些方案只能执行加法或乘法，不能两者兼顾（[G. Karatas, O. Demir and O. K. Sahingoz, 2019](#979-8-3693-1642-9.ch010.xhtml#r6)）。一个显著的例子是`RSA`加密，它表现出乘法同态特性。在PHE中，如果你加密两个数字并相乘它们的密文，解密后的结果将是原始数字的乘积。与其更先进的对应方案相比，PHE效率相对较高，并构成了同态加密早期许多应用的基础。

### 近似同态加密（SWHE）

近似同态加密是PHE的延伸。SWHE方案可以在密文上执行有限次数的加法和乘法运算。这一限制源于每次同态运算都会向密文中引入少量噪声，且噪声会随每次操作累积（A. Sharma, K. S and M. R. Arun, 2022）。一旦噪声达到一定阈值，密文就会变得过于损坏而无法可靠解密。SWHE是通往全同态加密的关键垫脚石，它比PHE提供了更大的灵活性，但仍受噪声累积的制约。

在一项独立研究中，Smart和Vercauteren提出了一种支持单指令多数据流（`SIMD`）操作的安全同态加密（`SHE`）技术。通过一种称为密文打包的方法，这一特性使全同态加密（`FHE`）能够实现并行化。将多个明文值编码到单个密文向量中，是`SIMD`指令提升计算性能的一个例子。密文打包的主要用途之一是批量计算，这是许多`FHE`算法的常见特性。此外，它还允许在打包密文中重新排序明文槽位，这可能会带来更快的评估速度。图2是这些想法的图形化表示（[M. N. Reza, and M. Islam, 2021](#979-8-3693-1642-9.ch010.xhtml#r14)）；它展示了一个包含多个值的向量，这些值可通过单条指令处理，且其槽位可为不同用途重新排列。

在最高层级上，全同态加密（`FHE`）保护数据免受窥探。可在加密数据上执行的加法和乘法运算数量是无限的。`FHE`的突破性成就在于其能够管理和控制困扰`SWHE`方案的噪声累积问题（Kumar, Pullela SVVSR, & Chaturvedi, Abhay, 2023）。这是通过一种称为`bootstrapping`（自举/引导）的方法实现的，该方法用于降低噪声水平，从而允许持续计算。自诞生以来，`FHE`一直是主要研究领域。持续的工作正在进行，旨在从效率和计算资源方面使其更加实用。

### 同态加密的数学基础

HE的数学基础在于数论和代数（Kumar, R & B. Ashreetha, 2023）。事实上，HE的本质利用了包括基于格的密码学、环理论和多项式算术在内的复杂数学概念。这些数学基础使得在加密数据上的操作能够以安全稳定的方式进行。
