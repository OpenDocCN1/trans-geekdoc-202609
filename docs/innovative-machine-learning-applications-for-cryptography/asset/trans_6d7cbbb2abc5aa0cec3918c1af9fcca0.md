## 摘要

追尾碰撞对道路安全构成威胁，因此可靠的碰撞避免技术至关重要。传统系统因数据丢失和隐私顾虑而存在诸多问题。作者引入了一种加密人工神经网络（ANN）方法，以防止前车追尾碰撞。该系统利用加密技术和ANN算法实时识别前车刹车灯。没有适当的密钥，信息无法被解读。传输过程中拦截数据可防止读取。该系统昼夜均可工作。在准确率方面，ANN优于LR、SVM、DT、RF和KNN。基于加密ANN的机器学习模型可区分刹车信号与正常信号。ANN准确率达93.7%。驾驶员接收进一步警报以避免追尾碰撞。本文提出了一种轻量级、安全的基于ANN的刹车灯图像加密方法。所提方法可应用于其他碰撞场景，包括侧面和正面碰撞。该技术将更具适应性，并适用于多种道路安全场景。

## 1. 引言

追尾碰撞在第三世界国家常见且往往致命。在充满未知因素的复杂环境中，传统系统很难可靠地识别和预测追尾碰撞的可能性。事故源于驾驶员未能足够快地对潜在威胁做出反应（[Feng等人, 2020](#979-8-3693-1642-9.ch008.xhtml#r8)）。有60%的碰撞可通过0.5秒的预警避免，而惊人的90%可通过1.5秒的预警避免（[Karungaru等人, 2021](#979-8-3693-1642-9.ch008.xhtml#r15)）。现有的碰撞检测方法往往很大程度上依赖单一智能算法，尽管混合方法可能带来优势。此外，它们经常未能考虑到可能降低能见度的恶劣天气，导致其检测系统失效。
