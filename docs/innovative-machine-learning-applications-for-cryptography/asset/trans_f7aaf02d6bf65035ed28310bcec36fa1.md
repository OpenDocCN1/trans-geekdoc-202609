

# 简介

如果没有破译密文的方法，就无法解码数据或确定消息的意图。选择安全的加密技术对于防止数据被轻易解码至关重要。如果没有可靠且安全的加密技术，安全问题可能会受到威胁。当有人从发送者那里接收数据或文档时，他们可以使用私钥对其进行解密和解码。一个例子是发送带有密码的 PDF 文档以及电子邮件。要打开文档，收件人或电子邮件必须知道密码。由于收件人的电子邮件地址是公开知识，且应仅在发送者和收件人之间共享，因此密码充当了私钥的一个示例。一个常见的问题是公钥和私钥有什么区别，以及应该使用哪种加密技术。加密数据的发送者和接收者共享一个私钥，该密钥用于加密和解密数据。公钥被交换且始终保持公开，而私钥则被隐藏保管。

使用攻击者的密钥增加额外的加密层是破解加密数据最常用的方法。解密通信需要用于加密该通信的私钥（[Open.edu, n.d.](#979-8-3693-1642-9.ch009.xhtml#r13)）。存在许多加密技术，每种都有其独特的风格。对称加密和非对称加密的区别就是一个例子。非对称加密使用公钥进行加密、私钥进行解密，而对称加密则使用单个密钥进行这两种操作（[Dataoverhaulers, n.d.](#979-8-3693-1642-9.ch009.xhtml#r6)）。

哈希、对称加密和非对称加密都是保护数据的可能方法。对称加密方法使用单个密钥来加密和解密数据。三重数据加密算法（`TDEA`）、高级加密标准（`AES`）和数据加密标准（`DES`）是最广泛使用的对称算法。

目前可用的最广泛使用的加密技术是 `DES` 算法。由于其广泛使用和高知名度，`DES` 已被多次破解，不再被视为安全。对于研究目的，`DES` 是一种可行但不安全的加密技术。数据加密标准，即 `DES`，是一种 56 位对称加密方法。数据的加密和解密使用相同的 56 位对称技术，称为 `DES`。`NIST` 于 1970 年采用了 `IBM` 创建的 `DES` 对称密钥分组加密。该过程使用 68 位密钥将明文转换为密文。通过使用 48 位密钥，分组密码算法将 64 位明文转换为密文。

`DES` 是一种 56 位对称密钥算法，它使用 64 位长的加密密钥对 64 位消息或数据进行加密，其中每第 8 位被忽略以创建 56 位密钥长度。`DES` 最具争议的部分之一是其使用 56 位密钥。情报机构以外的人士早在 `DES` 采用之前就长期抗议 56 位安全性是不够的。`DES` 在密码学中被广泛使用，尽管更强的加密技术使用更长的密钥长度，这使得解密更加困难。本次 `DES` 实验的目标是推进未来的密码学和网络安全应用。密码函数或方法的输出可以使用密钥进行解密或解码，密钥是将明文转换为密文的特殊方式。如果机器学习技术可以在不需要密钥的情况下解密消息，那么它就不是一种安全的加密方法。这就像给没有墙的房子锁上门。如果能够预测输出本身，密钥将变得毫无意义。

为了改进加密和解密方法、发现数据中的潜在漏洞以及展示密码系统产生的输入和输出数据之间的关系，机器学习技术正被广泛应用于密码学（[Anees, 2022](#979-8-3693-1642-9.ch009.xhtml#r1)）。

如果机器学习方法能够在不知道输入内容的情况下估计函数的输入，那么该单向函数就是可逆的，因此不适合用于加密。如果函数可以被撤销且内容变得可见，则它是不安全的。哈希函数的定义就是单向函数。机器学习算法有能力通过逆向工程强哈希加密方法来猜测密钥，从而破译文档或消息的内容（[Armstrong, 2021](#979-8-3693-1642-9.ch009.xhtml#r2)）。

在本文中，我们提出一种监督机器学习算法 `SVM` 可以学习对称哈希函数 `DES` 的输入概率超过 50%。这表明对对称哈希函数输入的攻击存在更大的可能性，而根据定义，对称哈希函数应该具有抗碰撞性。不应能够逆向工程哈希函数的摘要消息。可以使用机器学习技术破译加密数据的初始位，这意味着可以使用类似的方法对整个通信进行逆向工程。

# 背景

公认网络安全是指用于保护数字数据免受入侵或攻击的一系列方法和程序。给定一个足够强的分组密码，`DES` 可被用作单向哈希函数。足够大的密钥空间是分组密码被视为优良的先决条件。较大的密钥空间使暴力破解攻击效果变差。如果 `DES` 算法的密钥空间足够大，则可被视为适合单向函数。`DES` 算法通过应用一系列 `XOR` 和置换操作将明文转换为密文。通过哈希（可使用 `DES` 完成），明文输入被转换为哈希值。在当今商业领域，`DES` 是最流行且应用最广泛的加密函数（[Armstrong, 2021](#979-8-3693-1642-9.ch009.xhtml#r2)）。

Kelly Armstrong 声称，大多数研究人员在预测密码时仅使用猜测检查或暴力破解攻击。这些技术可能永远无法及时产生准确的估计。由于大多数技术仅使用暴力破解攻击，因此未展示出能够预测加密文档的成功机器学习算法，即使使用了通常无效的强加密技术（[Armstrong, 2021](#979-8-3693-1642-9.ch009.xhtml#r2)）。

此外，使用随机预言机模型创建黑盒猜测以生成输入的概念已被彻底证明能产生唯一输入（[Mahmoody et al., 2012](#979-8-3693-1642-9.ch009.xhtml#r11)）。这也被称为时间锁问题。另一种来自 `PassGAN` 的深度学习密码预测方法是基于规则的密码猜测，也称为马尔可夫模型。该技术训练神经网络自行识别密码结构和特征，并利用此信息生成具有相同分布的新样本（[Hitaj et al., 2019](#979-8-3693-1642-9.ch009.xhtml#r10)）。实际上，该研究并未集中于单个正确猜测数据位的可预测性，而是集中于将密码作为整个比特串进行猜测。
