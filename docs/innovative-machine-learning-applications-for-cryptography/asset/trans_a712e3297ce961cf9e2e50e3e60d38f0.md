

# 摘要

人工智能（AI）和密码学最近各自都取得了快速进展，形成了一种令人惊讶的相互关系。随着AI的发展，它正演变到这样一个阶段：AI能够研究甚至设计密码系统。然而，密码学研究人员不断推出新方法，以保护AI基础设施免受不断变化的攻击的侵害。因此，在该领域，作者们审视未来的地形，并考虑这两个突破性研究领域可能交汇的各种可能方式。同时，量子计算和神经形态技术可能将先进AI推向比以往任何计算机所能达到的更远的地方。一方面，密码学方法还有助于在面临攻击时，保持AI模型的开放、安全，并符合法律隐私法规。简而言之，前沿AI和密码学研究正共同重塑人工智能领域内互联网安全的前沿。未来将如何？本章阐述了这一激动人心的交叉领域的问题与前景。

## 1.1 AI与密码学的融合

AI在密码学中的作用广泛而深远。这种融合最显著的方面是AI驱动加密的出现。传统加密基于算法和数学结构，虽有效但绝不适应当今的计算环境。AI处理了这一方面，因为它可以学习调整加密技术，专门用于保护数据（Shivashankar, and S. Mehta, 2016）。但AI与密码学的融合确实是一个迷人的现象。两者正变得日益交织，相互促进。AI在密码学中的应用彻底改变了我们对数据安全和信息保护的思考方式。事实上，AI是推动密码学创新突破极限的引擎。

例如，AI筛选数据流量模式以即时增强加密。这样，重要信息即使在传输途中也能得到良好保护。它还可以改进密钥生成程序，降低加密的工作量和耗时。这些基于AI的加密算法在不断学习和进化，始终比潜在攻击者领先一步。AI与密码学重叠的另一个主要领域是称为密码分析的针对性用途。破译密码是秘密解码，而发现加密方法中的缺陷是密码分析。事实上，正是在这里，AI的分析能力大放异彩。（L. R. Knudsen and J E Mathiassen 2000）得益于其处理海量数据和识别复杂模式的能力，AI可以发现人类分析师忽视的缺陷。在识别数据流中的异常和不规则性方面无可匹敌的机器学习算法，因此成为密码分析师的宝贵武器。通过使用AI驱动密码分析，我们可以预测和预防威胁。它们对安全的主动方法可能永远改变我们保护敏感信息的方式。

## 1.2 协同效应的意义

AI与密码学之间的协同效应不仅仅是简单的合作，更象征着对数据安全和人工智能思维方式的差异。它将改变我们对数字景观的理解。首先，这种协同效应可以在一个日益相互依存的世界中带来更高的安全性。随着技术进步，通过网络传输的敏感数据量持续呈指数级增长（R. Beaulieu, D. Shors, J. Smith 2018）。从个人信息到金融交易和关键基础设施数据，充分的加密和安全现在都至关重要。这些以解决方案为导向、融合了AI的密码学方法提供了对抗新威胁的灵活性。
