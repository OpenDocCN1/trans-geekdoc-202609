## 3. SECURITY MODELS IN PRACTICES

### 3.1 Based on the Security Model

Model-based security is based on the level of security the user prefers; the user can choose single-level security, two-level security, or multi-level security. The complexity of the security is based on the value of the data or the application to be used. For better understanding, if the security of mere data is concerned, single or two-level security authentication is preferred. If securing credentials like property documents, investing banking bonds, or transferring money, multi-level security can be considered (miniOrange, n.d.).

### 3.2 Based on the User Level Usage

This way of security authentication is based on the user's level of security awareness. Users who are very much aware of technology and other authentication complexities prefer multi-level authentication for their applications. Coming to the layman—a normal person who doesn’t have much knowledge about authentication procedures and complexities—mostly prefers single-level security authentication and two-level authentication.

Before discussing the combination of authentication aspects, different types of authentication methodologies are elaborated for better understanding.

### 3.2.1 Protection Through Passwords

The most prominent method of protection is provided through password protection. The most commonly used login authentication system is through password protection; the regular daily-based login system is a password authentication system. To utilize online services to enter the using system, all are required to provide passwords. While using a password-based authentication system, the user provides their username and password as self-authentication. Mostly, the password will be memorized by the user. The password types will be numeric, alphabetical, or alphanumeric symbolic. Mostly, the password will be a combination of all of these. Password length will vary product to product; the password length will be a minimum of four characters for mobile phones and eight characters for mail or other services protection. The password is matched with the previously stored set of integers in the database; if it matches, the service access is enabled; otherwise, it is disabled.

The password protection can be easily challenged and broken by cyber criminals. For the best password protection, the password should often be changed at regular intervals. If the use of the same password prolongs, there are chances of attack by cybercriminals; by that operation, similar to phishing and data breaches, is possible. Due to the foretold drawbacks, the user requires further protection over the password protection for their working applications. Organizations using password protection in their systems are looking for better protection now for their systems to protect their data credentials.

### 3.2.2 Authentication With Multiple Parameters

Authentication with multiple parameters is a verification method in which a user should pass multiple parameter conditions. To gain access to the services, multiple parameter kinds of factors must be proven by the user. With the support of password protection and other multi-level security aspects also considered here. The user should prove their authentication. It may be answering their personal questions, which only they may know. A single-time password will be generated and provided to the user through their mail or mobile number. Based on the above-said parameters, the user will try to gain the service with their Username and Password.

### 3.2.3 Authentication Through Biometric

Every user has unique features that others don’t possess. Users possess unique features in the following aspects of the human body: thumb, retinas, palms, voice, facial recognition, finger impression. These features are collectively grouped under an attribute aspect, and a security model is developed: biometric-oriented authentication. These physicals can be verified individually or collectively matched with the previous data and authentication provided. These aspects are already in use in the market for attendance marking, device accessing, and biometric money transaction cards.
