

# 使用单一全同态加密（FHE）方案的简化协议

如[图 3](#979-8-3693-1642-9.ch010.xhtml#f03)所示，展示了一个使用单一全同态加密（FHE）方案的简化协议。该协议从服务器对两个关键元素 `P` 和 `T` 的加密开始；随后客户端将这些加密表下载到自己的计算机上。接下来，对每个类别 `i` 的 `[Pi]` 使用同态技术，从而为用户生成一个评分（S Tan 等人，2021）。然后客户端可以与服务器进行私有的 `argmax` 交互，以找出具有 `pi` 的类别。通过一系列线性比较来确定该最大值。为了保护隐私，客户端以随机顺序将每个类别的后续似然值发送给服务器。服务器通过将这些概率与记录在案的最大数值进行比较，确定新的最大值，并通过加密比较协议将其返回给客户端。该返回值经过精心掩码处理，以确保客户端无法推断出数值间的任何偏序关系，从而保证了过程的机密性（[P. H. Kumar and T. Samanta, 2022](#979-8-3693-1642-9.ch010.xhtml#r8)）。例如，格密码学是许多同态加密方案的核心，它涉及多维几何格的使用。在这些格中的计算对于持有解密密钥（了解格结构）的人来说很容易，但对于其他任何人来说却极其困难。这种困难通常基于诸如最短向量问题（SVP）或最近向量问题（CVP）等困难数学问题，据信这些问题能抵御甚至量子计算机的攻击（[P. Gope, O. Millwood and B. Sikdar, 2022](#979-8-3693-1642-9.ch010.xhtml#r1)）。从定性上讲，部分同态加密技术比全同态加密更简单。如果我们要充分认识同态加密在不同领域的潜在价值和局限性，不仅要了解这些差异，还要了解其数学基础。在本章中，我们将看到这些技术如何应用于机器学习。我们从未见过这种用于隐私保护数据分析的范式。

# 3. 加密域中的机器学习

人工智能领域中开发从数据中学习算法，并利用这些知识进行预测或决策的分支即为机器学习（ML）。用于学习的数据越多，这些算法的效果越好。监督学习、无监督学习和强化学习是 ML 算法的三大主要类别。

## 监督学习

在这种情况下，算法通过标记数据集进行训练，并理解输入数据与输出标签之间的关系。示例包括回归模型和分类模型。

## 无监督学习

此处使用未分类数据的算法来搜索隐藏模式或内部结构。典型示例包括聚类和降维。

## 强化学习

通过与复杂环境交互并尝试实现既定目标，算法学习如何做出一系列决策。它广泛应用于机器人技术、游戏和导航领域。

## 机器学习中的隐私担忧

对于必须拥有足够数据才能运行的机器学习模型而言，个人数据或医疗记录等私人信息并非没有隐私问题。传统 ML 通过从不同来源收集数据来训练模型。这带来了多种隐私风险：

### 数据泄露风险

如果数据集中存储，也可能被黑客入侵并非法窃取。这意味着大规模的隐私侵犯。

### 数据滥用

但当第三方介入时，也存在数据被用于原本从未预期方式的危险。

### 匿名性丧失

然而，即使数据已匿名化，强大的 ML 有时也能绕过匿名化重新识别个人，从而侵犯其隐私。

## 同态加密作为解决方案

同态加密为解决这些隐私担忧带来了希望。对加密信息进行计算意味着在构建 HE ML 模型时无需暴露原始数据。因为关键信息在整个 ML 过程中始终保持加密状态，所以数据泄露和滥用的发生大大减少。

### 在加密数据上训练

ML 模型可直接在加密数据上进行训练，确保底层数据保持安全和私密。

### 从加密数据推理

ML 模型可对加密数据进行预测，这在输入数据敏感的场景中特别有用。

然而，在机器学习中使用 HE 并非没有挑战。HE 的计算复杂性可能导致处理时间增加和资源需求上升，我们将在后续章节中探讨这一点。然而，得益于采用同态加密的隐私保护 ML，在医疗和金融等高度敏感领域使用 ML 的新机遇已经出现。

# 4. 同态加密与机器学习的融合

同态加密（HE）与机器学习（ML）的结合是保护敏感信息的一大进步。保护数据隐私是 HE 的首要任务，这也是它允许 ML 算法直接在加密数据上工作的原因（[S. Zhu and Y. Han, 2021](#979-8-3693-1642-9.ch010.xhtml#r19)）。这种协同效应不仅保护了敏感信息，还为在各个行业中安全利用 ML 开辟了新可能性。

## 使 ML 算法适配加密数据
