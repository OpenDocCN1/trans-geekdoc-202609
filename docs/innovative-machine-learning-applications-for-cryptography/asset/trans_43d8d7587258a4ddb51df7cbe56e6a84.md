

# 智能环境与物联网安全

智能环境（SE）旨在通过物联网（IoT）形式提升日常生活的舒适度。凭借其稳定且易用的操作，它开启了许多日常服务。任何基于物联网架构的现实世界智能环境都将隐私和安全放在首位。物联网系统容易受到安全缺陷的影响，进而影响智能环境应用。为了识别针对物联网智慧城市的攻击，本文提出了一种基于迭代分层神经模糊推理网络（ILNFIN）的入侵检测系统（IDS）。首先对 TON-IoT 数据集进行预处理，稀疏包装器头部选择方法分离出与攻击相关的特征。迭代堆叠神经模糊推理网络将受攻击数据与正常数据进行分类。非对称素数混沌 Rivest Shamir Adleman 技术确保非受攻击数据的安全传输。为了展示所建议的安全数据传输技术的有效性，作者将其实验结果与现有方法进行了对比。

## 1. 引言

近年来，物联网（IoT）在全球多个地区获得了显著的普及。预计到 2030 年，物联网设备的数量将达到 1250 亿台，而目前联网设备的数量今年已超过 270 亿台。智慧城市应用促进了众多物联网设备与现实世界有形物品之间的连接，对城市生活产生了重大影响。由于跨越多种技术和协议（包括有线/无线、卫星/蜂窝、蓝牙/Wi-Fi 等）的海量物联网设备，未来管理物联网网络将是一项重大挑战。因此，由于可能被利用的重大网络安全顾虑和弱点，市民的个人信息面临风险。无论用户或管理员是否知情，这些网络威胁都可能侵入物联网设备。因此，智慧城市应用易受两大主要危害。由于物联网协议的多样性，以及大规模攻击可能隐藏在物联网设备内部，在智慧城市的云数据中心检测零日攻击构成了初始障碍。通过使用复杂的网络攻击检测方法，可以提前识别物联网恶意软件攻击，从而防止其通过物联网网络影响智慧城市。目前，物联网传感器正在收集当前大多数运行中的传感器在云服务器上处理的海量数据的全部传输数据。传统入侵检测系统（IDS）不适用于资源和能力受限的设备（[Haseeb et al., 2020](#979-8-3693-1642-9.ch014.xhtml#r11)；[Kolivand et al., 2021](#979-8-3693-1642-9.ch014.xhtml#r18)；[Saba, 2020](#979-8-3693-1642-9.ch014.xhtml#r22)；[Saba, Sadad, Rehman et al, 2021](#979-8-3693-1642-9.ch014.xhtml#r24)；[Yar et al., 2021](#979-8-3693-1642-9.ch014.xhtml#r26)）。

### 1.2 智慧城市

“智慧城市的技术、人口和基础设施都是城市的关键方面。根据功能程度的不同，城市可被描述为数字城市、泛在城市，甚至是智能社区。智慧城市是指在上述三个领域具有高度重视和运营效率的城市。人口增长是全球各国政府面临的主要问题。资源绝不能短缺，且供应必须维持以满足需求。其他标准还包括关注环境并尽可能节约资源。

人们致力于维护安全标准，并采用更受控的方法调节高速公路的交通拥堵。城市发展规划中使用了众多信息通信技术（ICT）以提升生活质量。通过在城市服务中使用信息通信技术（ICT），促进了政府与市民之间健康积极的联系（英国标准协会 2014）。ICT 与城市发展的融合催生了智慧城市。

### 1.3 入侵检测系统

物联网（IoT）打破了数字世界与物理世界之间的界限。尽管如此，其在全球经济中不可避免的扩张却因缺乏足够的安全管理而受到挑战。物理设备安全、网络安全、传感器安全和数据传输安全都需要管理。因此，研究人员必须实现物联网安全管理操作的自动化，以便随时检测非法访问并采取必要措施。公司的需求应指导物联网安全管理架构的设计。物联网安全管理系统有三个组成部分，分别是：物联网参考模型、分层功能架构和安全管理信息库（[Abubakar & Pranggono, 2017](#979-8-3693-1642-9.ch014.xhtml#r4)）。
