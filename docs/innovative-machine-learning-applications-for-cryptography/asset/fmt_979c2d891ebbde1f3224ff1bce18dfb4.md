## 6. CONCLUSION

Presently, several cybersecurity measures are in place to uphold the security and privacy of `IoT` networks. Therefore, this study has introduced an `artificial intelligence (AI)` model for detecting intrusions in `Internet of Things (IoT)` networks. The model utilises `TON-IoT` datasets and aims to make a valuable contribution in this field.
