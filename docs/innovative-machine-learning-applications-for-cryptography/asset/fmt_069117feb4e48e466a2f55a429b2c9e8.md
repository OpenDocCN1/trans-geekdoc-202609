
# Machine Learning in Cryptosystem and Cryptanalysis: An Optimized Deep Learning Model for Intrusion Detection

Machine learning is a powerful tool in both cryptosystem and cryptanalysis. Intrusion detection is a significant part of cyber defence plans where improvements are needed to deal with challenges such as detection of false alarms, everyday new threats, and enhancing performance and accuracy. In this chapter, an optimized deep learning model is proposed to detect intrusion using Whale Optimization Algorithm (`WOA`) with Light Gradient Boosting Machine (`LightGBM`) algorithm. To increase the performance of the model, the collected network data from the KDD dataset are pre-processed with feature selection and dimensionality reduction methods. The `WOA-LightGBM` algorithm processes the pre-processed data for training. The outcomes of these experiments are compared with the performance of benchmarking algorithms to prove that this intrusion detection model provides better performance and accuracy. The proposed model detects the intrusion with high accuracy in a short period of time.

## 1 Introduction

Cryptography is the art of generating secure systems for secret data through encryption and decryption techniques ([Yan et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r29)). Machine learning (`ML`) techniques are used to automate the analytical model facilitating continuous learning even for big data inputs. This is the major reason for the application of `ML` in cryptosystems (`CS`). Moreover, `ML` and `CS` both process a huge amount of data with large search spaces. Private Key generation in cryptography is supported through reinforcement learning `ML` techniques ([Yan et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r29)). From the steganography perspective, `ML` classification methods, Bayesian classification, AdaBoost, and Support Vector Machine (`SVM`) are popularly used to perform classification of encrypted traffic and conversion of objects to steganography ([Yan et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r29)).

The intrusion is an effort to influence the security mechanism and its regulations. This intrusion detection structure is designed to monitor network traffic and discover unfamiliar behaviour that may cause harm ([Ahmad and Mirvaziri, 2019](#979-8-3693-1642-9.ch005.xhtml#r1)). The techniques of detection are used to spot the attributes of data sets that appear to be homogeneous and typical but are rare ([Sahil et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r22)). These unusual cases are also referred to as outliers, variations, exceptions, divergences, peculiarities, etc. ([Sahil et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r22)).

A Swarm Intelligence based approach detects intrusion effectively for dynamic systems ([Hanieh et al., 2019](#979-8-3693-1642-9.ch005.xhtml#r10)). Here, a cryptosystem is viewed as a communication network in which individual node's dynamic behaviour is fully or partially observed by another node. Changes in system behaviour might directly change the system's domestic communication structure by including, removing, or altering (i.e., strengthening or weakening) existing communication channels. Thus, changes in the communication structure may replicate changes in the operating conditions of the system, and the detection of these modifications is a key component for intrusion detection ([Hanieh et al., 2019](#979-8-3693-1642-9.ch005.xhtml#r10)).

The familiar Whale Optimization Algorithm (`WOA`) is a novel meta-heuristic population-based optimization algorithm used for clustering which mimics the hunting behaviour of humpback whales. In `WOA`, each whale represents a potential solution to the optimization problem, and the whales move through the search space to find the optimal solution.

The `ML` model such as `XGBoost` has been utilized in networks or IoT (Internet of Things) intrusion detection. Zhang and Hamori ([Zhang and Hamori, 2020](#979-8-3693-1642-9.ch005.xhtml#r30)) and Deng et al. ([Deng et al., 2021](#979-8-3693-1642-9.ch005.xhtml#r7)) utilized extreme gradient boosting (`XGBoost`) as an investigational model for prediction, and the outputs shown that the `XGBoost` model was capable of attaining an accuracy value of 86%. In (Cheng and Shi, 2021), Yan Song et al. proposed an intrusion detection model mostly based on `XGBoost`, using `WOA` to discover suitable constraints. Though the accuracy rate is not bad, the drawback of the `XGBoost` model is found to traverse the dataset even during the node dividing process, which tremendously increases the computational load ([Xiang et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r28)) and has particular boundaries in selecting or optimizing model parameters ([Huang et al., 2021](#979-8-3693-1642-9.ch005.xhtml#r12) and [Chaofei et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r4)).

Light Gradient Boosting Machine (`LightGBM`) is an enhanced version of the gradient boosting decision tree model using an exclusive leaf-wise growing strategy based on a huge depth limit, which may decrease many issues and obtain improved accuracy while using the equivalent amount of splits ([Xiang et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r28)). Therefore, detection methods become more efficient and precise when `WOA` optimized parameters are combined with the `LightGBM` model, which is proposed in this article to enhance the correctness of intrusion detection. ## 2 Literature Review

In ([Yan et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r29)), Amir Anees et al. made a review on a number of latest works on progress in various features of `ML` applications in cryptosystems and cryptanalysis. Developing anomaly detection models directly on data has a high fault rate with respect to accuracy and detection ([Sahil et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r22)). The dimensionality of datasets can be considerably condensed using feature selection methods. Deep learning approach, Restricted Boltzmann Machine, is highly effective in extracting high-level features and creating clusters at various scale levels ([Sahil et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r22)).

Hongjiao Wu et al. (2024) presented an improvised network attack detection method using Naïve Bayes with feature weight value based on context. Zhao et al. ([Zhao et al., 2021](#979-8-3693-1642-9.ch005.xhtml#r31)) described an ID archetype using deep ANN (Artificial Neural Network) for larger datasets. In (Maheswari and Arunesh, 2020), authors provided a model with fusion of KNN (K-nearest neighbor) and network traffic. Privacy preserving models maintain security of the data and effectively predict intrusion even in limited resources ([Mourad et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r17) and [Rahman et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r20)). Deep learning with LSTM (long short-term memory) and GRU (gated recurrent unit) contexts is more effective in model classification of some attacks ([Gautam et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r9) and [Esmaeili et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r8)).

Unbalanced training data distribution is one of the challenges tackled by the author using one-sided gradient oversampling with binded mutually exclusive features ([Cong et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r6)). Tu et al. ([Chung-Jui et al., 2007](#979-8-3693-1642-9.ch005.xhtml#r5)) proposed a model to extract features with crossbreeding of PSO and SVM where classification is carried out using PSO fitness function.
