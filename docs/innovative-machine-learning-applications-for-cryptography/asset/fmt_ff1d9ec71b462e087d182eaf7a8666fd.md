
# 利用人工神经网络（ANN）的加密图像分析防止追尾碰撞

利用人工神经网络（ANN）进行的加密图像分析能够执行深度分析、识别模式并做出高度准确的预测（[Guo et al., 2022](#979-8-3693-1642-9.ch008.xhtml#r12)）。这就像拥有一位极其聪明的乘客，能够预见潜在事故。道路上最常见的事故原因之一是追尾碰撞。分心驾驶、驾驶员疲劳和跟车过近只是其中的几个原因（[Shang et al., 2021](#979-8-3693-1642-9.ch008.xhtml#r28)）。为了防止前车追尾事故，本研究提出了一种结合 ANN 的加密技术。

如果 ANN 判断驾驶员无法足够快地做出反应以避免碰撞，将触发警报。研究结果表明，所提方法最多可将追尾事故减少 50%。追尾碰撞是交通事故的主要原因之一（[Shen et al., 2023](#979-8-3693-1642-9.ch008.xhtml#r30)）。在美国，约 25% 的交通死亡归因于追尾碰撞（[Zhang et al., 2022](#979-8-3693-1642-9.ch008.xhtml#r37)）。导致追尾碰撞的因素多种多样，包括分心驾驶、疲劳和跟车过近（[Kushwaha, 2023](#979-8-3693-1642-9.ch008.xhtml#r17)）。

## 避免追尾碰撞的常规技术

可用于避免追尾碰撞的技术包括：

*   驾驶员应始终与前车保持安全跟车距离。这将给他们留出足够的反应时间，以应对前车突然停车的情况。
*   驾驶员驾驶时应避免分心，例如打电话或发短信。这些分心行为会妨碍驾驶员关注路况，从而导致追尾碰撞。
*   驾驶员应时刻留意周围环境，并做好必要时停车的准备。这包括了解周围车辆的速度和距离。

## 基于 AI 的防撞系统

利用人工智能（AI）预防追尾碰撞在近年来越来越受欢迎（[Fu et al., 2021](#979-8-3693-1642-9.ch008.xhtml#r10); [Pu et al., 2021](#979-8-3693-1642-9.ch008.xhtml#r26)）。借助 AI，我们可以创建系统来研究个别驾驶员的驾驶习惯，并预测他们何时会引发事故（[Kushwaha & Abirami, 2023](#979-8-3693-1642-9.ch008.xhtml#r19)）。这些系统收集的数据可用于发出警告或采取其他预防措施。

该系统尝试利用 ANN 机器学习（ML）算法实时检测来自前车的刹车灯（[Hadjidimitriou et al., 2020](#979-8-3693-1642-9.ch008.xhtml#r13); [Yang et al., 2020](#979-8-3693-1642-9.ch008.xhtml#r36)）。ANN 方法的准确性优于其他 ML 分类器，包括逻辑回归（LR）、支持向量机（SVM）、决策树（DT）、随机森林（RF）、K 近邻（KNN）、朴素贝叶斯（NB）、决策树（DT）、随机梯度下降（SGD）、梯度提升（GB）和 AdaBoost。为了区分正常信号和刹车信号，采用了基于 ANN 的 ML 模型。

研究人员和政府决策者将发现这些信息对于减少交通死亡人数的努力极具价值（[Abirami et al., 2021](#979-8-3693-1642-9.ch008.xhtml#r2)）。建议的方法利用 ANN 来防止追尾碰撞并检测前车刹车灯。车速、与前车的距离以及驾驶员反应时间只是用于训练 ANN 的部分传感器输入。如果 ANN 判断驾驶员无法足够快地做出反应以避免碰撞，将触发警报。ANN 是一种 ML 方法。ANN 中的每个神经元在接收来自上一层的输入后都会产生一个值。我们利用输出层神经元返回的数据来预测驾驶员的反应时间。

## 加密技术

加密是对信息进行编码的过程，使其在没有正确密钥的情况下无法被破译（[Alsafyani et al., 2023](#979-8-3693-1642-9.ch008.xhtml#r3)）。如果数据在传输过程中被拦截，这可以防止任何人读取它。可以使用加密方法保护移动警报消息数据，这些方法将信息转换为没有正确密钥无法破译的代码（[Silva et al., 2023](#979-8-3693-1642-9.ch008.xhtml#r31)）。这样，即使信息在传输途中被拦截，也极其安全。

虽然存在多种数据加密方法，但最常见的包括：

*   **对称加密**：加密和解密数据使用相同的密钥。这便于实现，但要求密钥必须保密。
*   **非对称加密**：由于私钥从不泄露，此方法比对称加密更安全。

发送追尾碰撞后的驾驶员警报消息时，受保护的信息可能包括驾驶员姓名、事故地点和碰撞严重程度。可通过认证和授权程序限制对敏感信息的访问。所有数据访问均可记录日志，以帮助揭露任何未经授权的访问尝试。物理安全措施也可用于保护数据免受窥探。

## 提出的解决方案与优势

提出的解决方案为防止前车追尾事故提供了一种新颖途径。本文提出了一种安全、轻量级的 ANN 加密技术，以保护车辆刹车灯图像中的信息。该方法依赖于使用车辆刹车灯图像数据集开发和训练的 ANN。如果 ANN 判断驾驶员无法足够快地做出反应以避免碰撞，将触发警报。研究发现，所提方法最多可将追尾碰撞频率减少一半（[Wang et al., 2020](#979-8-3693-1642-9.ch008.xhtml#r33)）。这些结果意味着所提方法可能显著提高道路安全性。

所提方法可通过以下几种方式加以改进：例如，ANN 可使用更大规模的刹车灯信息集合进行训练。因此，ANN 将更好地理解驾驶员行为并做出可靠预测。所提方法可推广到更广泛的碰撞场景，包括但不限于侧面撞击和正面碰撞。这将使该方法更加灵活，可用于更广泛的道路安全场景。该方法具有以下优势：

*   基于 ANN 的加密保护关键刹车灯数据免受未经授权的访问和恶意攻击。
*   为实时处理进行优化，使 ANN 能够快速识别碰撞并做出响应。
*   在大型数据集上训练 ANN，确保精确的刹车灯识别和事故风险评估。
*   通过将安全加密与实时防撞技术相结合，该方法在最大限度提高道路安全性的同时，将数据丢失降至最低（[Li et al., 2021](#979-8-3693-1642-9.ch008.xhtml#r20)）。

## 研究贡献

本研究做出了以下贡献：

*   **(i)** 我们提出了一种利用 ANN 和其他 ML 模型加密刹车灯帧的新方法。开发了一种新颖的加密算法，以保护刹车灯图像在传输和存储过程中的安全。这在保持数据集完整性的同时确保了隐私合规性。
*   **(ii)** 使用加密的刹车灯图像训练 ANN。通过反向传播和微调技术优化模型，以实现高准确性。
*   **(iii)** 实时运行期间，解密加密的刹车灯图像以进行分析。ANN 的输出触发防撞机制，有助于提高道路安全性。
