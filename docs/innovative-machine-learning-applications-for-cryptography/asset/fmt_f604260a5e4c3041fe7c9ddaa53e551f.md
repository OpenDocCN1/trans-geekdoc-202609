## 3.2.12 API Passwords

An API key is a unique solution for web service queries; it identifies the user request based on the source. When a request arises from the user, a secret key is generated, a key token is enabled, and provided to the user. The user should use this key while using it for the first time through registration. This key token is paired with the API. If the user attempts to use the service subsequent times, the previously generated token link will be activated, verification is made, and service is provided.
