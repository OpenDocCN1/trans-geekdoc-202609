

# 机器学习在密码系统与密码分析中的应用：用于入侵检测的优化深度学习模型

机器学习是密码系统和密码分析中强有力的工具。入侵检测是网络防御计划的重要组成部分，需要改进以应对误报检测、每日新增威胁以及提升性能和准确性等挑战。在本章中，提出了一种优化的深度学习模型，利用鲸鱼优化算法（`WOA`）结合轻量级梯度提升机（`LightGBM`）算法来检测入侵。为了提高模型性能，从 KDD 数据集收集的网络数据通过特征选择和降维方法进行预处理。`WOA-LightGBM` 算法处理预处理后的数据进行训练。将这些实验结果与基准算法的性能进行比较，以证明该入侵检测模型提供了更好的性能和准确性。所提出的模型能在短时间内以高准确度检测入侵。

## 1 简介

密码学是通过加密和解密技术为秘密数据生成安全系统的艺术（[Yan et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r29)）。机器学习（`ML`）技术用于自动化分析模型，即使对于大数据输入也能促进持续学习。这是 `ML` 应用于密码系统（`CS`）的主要原因。此外，`ML` 和 `CS` 都处理具有大搜索空间的海量数据。密码学中的私钥生成通过强化学习 `ML` 技术得到支持（[Yan et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r29)）。从隐写术的角度来看，`ML` 分类方法、贝叶斯分类、AdaBoost 和支持向量机（`SVM`）常被用于执行加密流量分类和对象到隐写术的转换（[Yan et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r29)）。

入侵是影响安全机制及其规则的尝试。这种入侵检测结构旨在监控网络流量并发现可能造成危害的异常行为（[Ahmad and Mirvaziri, 2019](#979-8-3693-1642-9.ch005.xhtml#r1)）。检测技术用于识别那些看似同质且典型但实则罕见的数据集属性（[Sahil et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r22)）。这些异常情况也被称为离群值、变异、例外、偏差、怪癖等（[Sahil et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r22)）。

基于群体智能的方法能有效检测动态系统中的入侵（[Hanieh et al., 2019](#979-8-3693-1642-9.ch005.xhtml#r10)）。在此，密码系统被视为一个通信网络，其中单个节点的动态行为被另一个节点完全或部分观察。系统行为的变化可能会通过添加、移除或改变（即加强或削弱）现有通信通道，直接改变系统的国内通信结构。因此，通信结构的变化可能反映系统运行条件的变化，而检测这些修改是入侵检测的关键组成部分（[Hanieh et al., 2019](#979-8-3693-1642-9.ch005.xhtml#r10)）。

众所周知的鲸鱼优化算法（`WOA`）是一种新颖的基于种群的元启发式优化算法，用于聚类，它模仿座头鲸的捕猎行为。在 `WOA` 中，每条鲸鱼代表优化问题的一个潜在解，鲸鱼在搜索空间中移动以寻找最优解。

`XGBoost` 等 `ML` 模型已被用于网络或物联网（`IoT`）入侵检测。Zhang 和 Hamori（[Zhang and Hamori, 2020](#979-8-3693-1642-9.ch005.xhtml#r30)）以及 Deng 等人（[Deng et al., 2021](#979-8-3693-1642-9.ch005.xhtml#r7)）利用极端梯度提升（`XGBoost`）作为研究预测模型，结果显示 `XGBoost` 模型能够达到 86% 的准确率。在（Cheng and Shi, 2021）中，Yan Song 等人提出了一种主要基于 `XGBoost` 的入侵检测模型，利用 `WOA` 发现合适的约束。尽管准确率不错，但发现 `XGBoost` 模型的缺点是在节点分裂过程中甚至会遍历数据集，这极大地增加了计算负载（[Xiang et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r28)），并在选择或优化模型参数方面存在特定局限（[Huang et al., 2021](#979-8-3693-1642-9.ch005.xhtml#r12) 和 [Chaofei et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r4)）。

轻量级梯度提升机（`LightGBM`）是梯度提升决策树模型的增强版，它基于巨大的深度限制采用独特的叶子优先生长策略，这可以减少许多问题，并在使用相同分裂次数的情况下获得更高的准确性（[Xiang et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r28)）。因此，当 `WOA` 优化的参数与 `LightGBM` 模型相结合时，检测方法变得更高效、更精确，本文提出该组合以提高入侵检测的正确性。所提出模型的架构图如[图 1](#979-8-3693-1642-9.ch005.xhtml#f01)所示。

## 2 文献综述

在（[Yan et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r29)）中，Amir Anees 等人综述了关于 `ML` 在密码系统和密码分析各个特性应用进展的多项最新工作。直接在数据上开发异常检测模型在准确性和检测方面具有较高的错误率（[Sahil et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r22)）。数据集的维度可以通过特征选择方法大幅压缩。深度学习方法、受限玻尔兹曼机在提取高层特征和在不同尺度层级创建聚类方面非常有效（[Sahil et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r22)）。

Hongjiao Wu 等人（2024）提出了一种基于上下文的特征权重值的朴素贝叶斯改进网络攻击检测方法。Zhao 等人（[Zhao et al., 2021](#979-8-3693-1642-9.ch005.xhtml#r31)）描述了一种用于大型数据集的基于深度 ANN（人工神经网络）的 ID 原型。在（Maheswari and Arunesh, 2020）中，作者提供了一种融合 KNN（K 近邻）和网络流量的模型。隐私保护模型维护数据安全，甚至在有限资源下也能有效预测入侵（[Mourad et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r17) 和 [Rahman et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r20)）。具有 LSTM（长短期记忆）和 GRU（门控循环单元）上下文的深度学习在某些攻击的模型分类中更有效（[Gautam et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r9) 和 [Esmaeili et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r8)）。

不平衡的训练数据分布是作者使用单侧梯度过采样与绑定互斥特征相结合来解决的挑战之一（[Cong et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r6)）。Tu 等人（[Chung-Jui et al., 2007](#979-8-3693-1642-9.ch005.xhtml#r5)）提出了一种利用 PSO 和 SVM 杂交提取特征的模型，其中分类使用 PSO 适应度函数进行。
