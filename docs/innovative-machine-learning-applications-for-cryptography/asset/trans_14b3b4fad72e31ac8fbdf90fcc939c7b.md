## 4.2 讨论

刹车灯检测是通过多种机器学习模型识别的。这是发现的特征之一。为了评估车辆刹车灯的有效性，将所提出的模型与多种其他方法进行了对比，包括集成方法以及 LR、NB、DT、SVM 和 KNN 等基础学习器模型。使用所提出的模型，我们能够识别出重要特征，这些特征占数据集总可用特征的一半以上。本研究提出了一种有效的自动刹车灯识别系统方案。

首先，没有机器学习模型将可用属性作为输入。作为调查后续阶段的一部分，由所提出模型识别出的最显著特征被用作所有机器学习模型的输入。在本节中，我们将讨论在识别刹车灯时观察到的四个最重要的结果。

第一，所有机器学习模型和 ANN 在识别刹车灯方面均表现良好。在使用重要特征作为输入的情况下，ANN 达到了最高的 ACC (0.937)。LR 达到 ACC 0.926，GB 达到 0.916。NB 达到较低的 ACC 0.743，而 RF、DT、SGD、KNN 和 AdaBoost 的 ACC 分别为 0.895、0.853、0.832、0.895 和 0.889。每个机器学习模型的 ACC 结果显示在[图 5](#979-8-3693-1642-9.ch008.xhtml#f05)中。当刹车类和正常类具有同等重要性且不存在显著的类别不平衡时，达到较高水平的 ACC 变得至关重要。

第二，如[图 6](#979-8-3693-1642-9.ch008.xhtml#f06)所示，在 ACC 方面，ANN 优于其他机器学习模型。通过利用关键特征，ANN 以 0.936 的精确率值产生了更好的结果。LR 使用所有测试数据集作为输入达到了 0.927 的 ACC 评级，低于 ANN 达到的 0.936 的 P 分数。RF 达到 0.892，而 SGD、GB 和 AdaBoost 集成模型的 ACC 分数分别为 0.889、0.819 和 0.884。树集成模型（[Abirami 等人, 2020](#979-8-3693-1642-9.ch008.xhtml#r1)）比其他模型具有更高的 RF。然而，KNN、DT、SVM 和 NB 的 ACC 分数分别为 0.892、0.850、0.873 和 0.716。结果发现 NB 的 P 分数低于其他技术。在刹车灯检测中，假阳性可能导致严重后果，因此高精度是有利的。

第四，分析 F1-score，这是一个平衡 ACC 和 R 分数的关键评估指标。当刹车灯检测中漏报正例的代价很大时，强召回率至关重要。

![图 8](i/ch008.f08.png)

[图 8](#979-8-3693-1642-9.ch008.xhtml#f08) 显示，ANN 的 F1-score (0.936) 大于其他模型。LR 和 GB 分别达到了 0.922 和 0.913。SGD 达到的 F1-score 较低，为 0.845。DT、KNN、RF、SVM (M.S., 2020; [Xie 等人, 2021](#979-8-3693-1642-9.ch008.xhtml#r35))、Adaboost 和 NB 的 F1-score 分别为 0.851、0.887、0.887、0.869、0.884 和 0.849。当类别分布不均，或必须同时将假阳性和假阴性降至最低时，F1-score 特别有用。根据结果摘要，当主要关注识别汽车刹车灯的整体性能时，模型可以识别出构成原始特征集子集的重要特性。将关键特性作为输入提供给机器学习模型可提高 ACC、P、R 和 F1-score。结合相关属性，推荐技术不仅提高了可能性性能，还降低了数据收集成本。

刹车灯检测系统包含 185 帧，用于评估系统。当由所提出模型识别出的刹车和正常标签的关键特征被认可并纳入考量时，刹车灯检测过程得到了显著改进。在所有特征和基本特征均被用作输入后，也可以估算机器学习模型的性能。当考虑重要属性时，推荐模型的表现优于实验中使用的任何其他模型。管理层应更加重视影响刹车检测的重要因素。就 ACC、R、P 和 F1-score 而言，在这些指标上数值最高的模型表明其平衡且有效。

## 5. 结论

所提出的解决方案为防止前车追尾事故提供了一种新方法。本文提出了一种结合 ANN 的安全轻量级加密技术，以保护车辆刹车灯图像中的信息。该方法依赖于使用车辆刹车灯图像数据集开发和训练的 ANN。如果 ANN 判断驾驶员无法足够快地做出反应以避免碰撞，将触发警报。研究发现，所提出的方法可能将追尾事故的频率降低多达一半。这些结果意味着所提出的方法可能显著提高道路安全性。

有几种方式可以增强所提出的方法。例如，可以使用更广泛的刹车灯信息集合来训练 ANN，使其能够更好地理解驾驶员行为并做出可靠预测。建议的方法可以推广到更广泛的碰撞场景，包括侧面撞击和正面碰撞，使其在道路安全应用中更加灵活。未来，我们将结合 AI 方法和机器学习模型来避免追尾事故。
