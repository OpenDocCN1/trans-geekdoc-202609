
Kamel 等人（[Rongfeng et al., 2020](#979-8-3693-1642-9.ch005.xhtml#r21)）在关于机器学习系统和蜜罐的文章中介绍了相关内容，并基于这些技术，准备了一个用于网络攻击规避与预测的智能代理。Zheng 等人（[Muhammed et al., 2011](#979-8-3693-1642-9.ch005.xhtml#r18)）研究了用于区分良性与恶意流量以训练聚类模型的先驱统计特征。在文献（[Chen et al., 2021](#979-8-3693-1642-9.ch005.xhtml#r3)）中，作者通过攻击基本数据加密标准、Simon 和 Speck 等轻量级分组密码，证明了基于深度学习的密码分析的可行性。输出结果证明，当密钥空间限制为 64 个 ASCII 字符时，基于深度学习的密码分析可以有效地恢复密钥位。

群体智能被用于挖掘动态系统的内部通信拓扑（[Chen et al., 2016](#979-8-3693-1642-9.ch005.xhtml#r4)）。文献（[Ahmad and Mirvaziri, 2019](#979-8-3693-1642-9.ch005.xhtml#r1)）的作者应用了一种基于群体智能的算法，利用从高斯分布和非高斯分布中提取的数据。WOA 是一种新型元启发式优化算法，通过模拟座头鲸的气泡网捕食和攻击机制，复制了座头鲸的捕猎机制（Wang and Wang, 2021, [Sharma and Singh, 2020](#979-8-3693-1642-9.ch005.xhtml#r23), Alsabti et al., 1998）。在文献（[Xiang et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r28)）中，作者提出了一种利用 WOA-LightGBM 和 CEEMDAN 开发的生猪期货价格集体预测模型，这表明单一机器学习模型在预测正确性和模型稳定性方面存在弱点。

## 3 材料与方法

本节详细讨论了拟议原型中使用的各种方法和材料。

### 3.1 鲸鱼优化算法

该算法是座头鲸聪明捕猎行为（称为“气泡网”）的复制形式。鲸鱼在环绕猎物的圆形路径上制造气泡，然后在猎物周围形成类似“9”字的螺旋形状（[Mohamed et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r16)）。以类似模式，需要一种力量系统来识别入侵者，并为网络保护创建无缝安全系统。基于 WOA 的系统能高效地检测和保护网络。然而，WOA 容易陷入局部优化，因此本文将 LightGBM 与 WOA 相结合，以提高入侵检测的成功率（[Mohamed et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r16)）。

WOA 算法是一种基于种群的元启发式优化算法，通过产生圆形或数字“9”形的气泡网，模拟座头鲸的捕猎行为（[Xiang et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r28)）。WOA 有三个主要组成部分：

*   猎物搜索 —— 包围
*   围捕 —— 螺旋搜索和随机搜索
*   气泡网攻击

在此方法中，鲸鱼（候选解）通过在单维/多维空间中改变其移动方向（向量）来捕猎，从而有效地平衡探索阶段。

在 WOA 中，鲸鱼一个个从一个偶然的位置开始，然后，每个个体鲸鱼根据每次迭代后找到的最优个体鲸鱼位置或任意找到的个体鲸鱼位置来改善自己的位置（[Xiang et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r28)）。[表 1](#979-8-3693-1642-9.ch005.xhtml#t1) 列出了本文使用的术语。

### 3.5 LightGBM

LightGBM 是一种可用于入侵检测的机器学习算法，入侵检测的任务是识别网络上的恶意或未经授权的活动。LightGBM 是梯度提升的一种快速高效的实现，梯度提升是一种将众多弱学习器（如决策树）组合成一个能够做出精准预测的强学习器的技术（Tian 2022）。

使用 LightGBM 进行入侵检测的一些优势包括：

*   它能高效处理大规模和高维数据，因为它使用基于直方图的算法，减少了分裂点数量和内存使用。
*   它能处理不平衡数据，这在入侵检测中很常见，因为它使用一种称为梯度单边采样的采样技术，保留最有信息量的实例并丢弃信息量较小的实例。
*   它能自动处理缺失值和分类特征，从而减少数据预处理和特征工程的需求。
*   它能执行特征选择，这可以提高模型性能和可解释性，因为它使用一种称为互斥特征捆绑的正则化技术，将互斥特征分组在一起并减少特征数量。

LightGBM 是一种基于决策的梯度提升模型，支持并行学习（[Xiang et al., 2022](#979-8-3693-1642-9.ch005.xhtml#r28)）。与 XGBoost 模型相比，LightGBM 的优势在于训练速度快、内存占用低（[Machado 2003](#979-8-3693-1642-9.ch005.xhtml#r15)）。设 M 表示一个包含输入值 x = {x1,..,xn} 和预测标签 y={y1,..yn} 的数据集。设 f(x) 表示模型函数，L(y, f(x)) 为损失函数。根据梯度提升方法，gij，其中 j 为迭代次数，可得
