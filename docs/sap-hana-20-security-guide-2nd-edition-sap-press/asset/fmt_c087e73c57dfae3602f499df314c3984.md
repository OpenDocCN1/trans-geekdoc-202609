
# 交付单元管理

交付单元管理窗口分为两个主要部分。窗口上半部分标题为 Delivery Units。在此部分中，您可以在系统中创建和删除交付单元。要创建交付单元，请单击部分右侧的 Create 按钮。将出现 New Delivery Unit 窗口，如 [Figure 14.3](#14_002.html#f14.3) 所示。

在此窗口中，输入交付单元的 Name。Vendor 字段应已填充在 indexserver.ini 配置文件中配置的内容供应商 ID。所有其他配置字段均为可选。Version、Support Package Version、Patch Version、Caption 和其他字段通常由 SAP 或为 XS 引擎提供插件的其他供应商使用。单击 OK 以创建交付单元。要删除交付单元，请删除所有已分配的包，在 Delivery Unit 列表中突出显示交付单元，然后单击 Delete 按钮。

[![New Delivery Unit Window in SAP HANA Studio](bilderklein/klein14_003.png)](img-f14.3.html)

**Figure 14.3** New Delivery Unit Window in SAP HANA Studio

在 [Figure 14.2](#14_002.html#f14.2) 的底部，您将看到 Assigned Packages 部分。您将使用此部分从交付单元中添加或删除包。要将包添加到选定的交付单元，请单击 Add 按钮。将出现 Assign Packages 窗口，如 [Figure 14.4](#14_002.html#f14.4) 所示。

## Repository Role Dependencies

在我们的示例中，我们将所有与安全相关的开发工件打包到一个交付单元中。我们包含了依赖的子包项，例如架构和分析特权。尽管此方法将捕获大多数依赖项，但交付单元可能不会包含所有依赖项。所有依赖项必须打包到它们自己的交付单元中，并在导入特定于安全的交付单元之前传输到目标系统。

[![Assign Packages Window in SAP HANA Studio](bilderklein/klein14_004.png)](img-f14.4.html)

**Figure 14.4** Assign Packages Window in SAP HANA Studio

要选择包，请使用窗口的 Select Package(s) 部分中的包层次结构顶级包节点。要包含顶级包节点的所有子包，请选择 Selects all sub-packages under the selected nodes 复选框。单击 Finish 将包添加到交付单元。要从 Assigned Packages 部分中删除包或子包，请在列表中选择它，然后单击 Remove 按钮。将出现确认弹出窗口。单击 OK 确认您要从交付单元中删除所选包。

## 14.2.2 使用 SAP HANA Application Lifecycle Management 创建交付单元

在 [Section 14.3](#14_003.html#h14.3) 和 [Section 14.4](#14_004.html#h14.4) 中，我们将更详细地讨论 SAP HANA Application Lifecycle Management。在本节中，我们将具体探讨 SAP HANA Application Lifecycle Management 中的交付单元管理。要访问 SAP HANA Application Lifecycle Management，您必须使用 Web 浏览器。为您的系统自定义以下 URL。

要通过安全套接字层 (SSL) 访问 SAP HANA Application Lifecycle Management，请使用以下 URL：

`https://<host_name>:43<instance number>/sap/hana/xs/lm`

例如，URL 可能如下所示：

`https://w5-3db-hana01.e-corp.root.local:4300/sap/hana/xs/lm`

如果未配置 SSL，请使用以下 URL：

`http://<host_name>:80<instance number>/sap/hana/xs/lm`

例如，URL 可能如下所示：

`http://w5-3db-hana01.e-corp.root.local:8000/sap/hana/xs/lm`

在这些示例中，将 `<host_name>` 变量替换为 SAP HANA 实例的主机名，并将 `<instance number>` 变量替换为 SAP HANA 实例的两位实例号。

要访问 SAP HANA Application Lifecycle Management 并管理交付单元，您必须拥有 `sap.hana.xs.lm.roles::Administrator` 角色。在我们的测试中，我们发现即使被授予者拥有使用 SAP HANA Studio 执行相同操作所需的权限，也需要此角色。一旦您获得 SAP HANA Application Lifecycle Management 的访问权限，并使用为您的环境配置的方法登录，将出现如 [Figure 14.5](#14_002.html#f14.5) 所示的主页。

[![SAP HANA Application Lifecycle Management Homepage](bilderklein/klein14_005.png)](img-f14.5.html)

**Figure 14.5** SAP HANA Application Lifecycle Management Homepage

在主页上，单击标记为 Delivery Units 的磁贴。将出现一个新窗口，导航路径 Products • Delivery Units 将被预选。在此 Delivery Units 窗口中，您将在左侧看到交付单元列表。在右侧，您将找到所选交付单元的配置选项。[Figure 14.6](#14_002.html#f14.6) 显示了 SAP HANA Application Lifecycle Management 中交付单元管理窗口的示例。

[![Delivery Unit Management Window in SAP HANA Application Lifecycle Management](bilderklein/klein14_006.png)](img-f14.6.html)

**Figure 14.6** Delivery Unit Management Window in SAP HANA Application Lifecycle Management

要创建新交付单元，请单击左上角的 `+ Create` 按钮。将出现 New Delivery Unit 窗口，如 [Figure 14.7](#14_002.html#f14.7) 所示。

Name 字段是必填字段，必须维护。Vendor 字段将包含在您的环境中配置的内容供应商名称。所有其余字段均为可选。输入所需信息后，单击 Create。

[![New Delivery Unit Window in SAP HANA Application Lifecycle Management](bilderklein/klein14_007.png)](img-f14.7.html)

**Figure 14.7** New Delivery Unit Window in SAP HANA Application Lifecycle Management

要将包分配给交付单元，请在左侧选择交付单元，然后在窗口右侧向下滚动，直到 Assigned Packages 部分可见。在此部分中，单击 Assign 按钮将包添加到交付单元。将出现 Assign Packages 窗口，如 [Figure 14.8](#14_002.html#f14.8) 所示。

[![Assign Packages Window in SAP HANA Application Lifecycle Management](bilderklein/klein14_008.png)](img-f14.8.html)

**Figure 14.8** Assign Packages Window in SAP HANA Application Lifecycle Management

单击要分配给交付单元的包节点级别。选择 Select Sub Packages 选项以包含交付单元中的所有子包。单击 Assign 按钮分配包。

要从交付单元中删除包，请在左侧选择交付单元，然后在右侧向下滚动到 Assigned Packages 部分。选择要删除的包，然后单击 Unassign。要保存对交付单元所做的更改，请单击 `+ Create` 按钮右侧的 Save 按钮。
