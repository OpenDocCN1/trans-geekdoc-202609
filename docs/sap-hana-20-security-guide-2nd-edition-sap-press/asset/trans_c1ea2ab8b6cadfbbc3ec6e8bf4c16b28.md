## 14.3.2 将交付单元导出到文件

除了使用 SAP HANA 应用生命周期管理在 [第 14.2.3 节](#14_002.html#h14.2.3) 中导出交付单元外，您还可以使用 SAP HANA Studio。此功能在 SAP HANA cockpit 中不可用，因此我们将在本章中介绍如何使用 SAP HANA Studio。SAP HANA Studio 提供了一个界面，用于将交付单元导出到压缩文件。此压缩文件稍后可以重新导入到 SAP HANA 存储库中。开发人员通常使用此导出过程作为其代码的备份。但是，此功能也可用于生命周期管理，尽管 SAP HANA 应用生命周期管理是管理 SAP HANA 实例之间传输的首选工具。

要启动该过程，请在 SAP HANA Studio 中切换到管理控制台透视图。从菜单栏中，选择“文件” > “导出”。将出现“导出”窗口。在“选择导出向导”部分，展开“SAP HANA 内容”，然后选择“交付单元”。单击“下一步”继续。将出现“选择源系统”窗口。在系统列表中，选择将作为交付单元源的系统。单击“下一步”继续。将出现带有副标题“选择交付单元”的“通过交付单元导出”窗口。此窗口用于指定交付单元导出选项，如 [图 14.16](#14_003.html#f14.16) 所示。

[![SAP HANA Studio 中的导出选项](bilderklein/klein14_016.png)](img-f14.16.html)

## 图 14.16 SAP HANA Studio 中的导出选项

在此窗口中，使用“交付单元”下拉列表选择要导出的交付单元。导出工具将包含“包列表”部分中列出的包相关的所有开发工件。但是，您也可以根据激活日期导出开发工件。使用“按时间筛选”复选框启用基于时间的筛选器。选中“按时间筛选”复选框后，使用提供的下拉列表选择一个时间间隔。下拉列表提供以下间隔：上周、上个月和时间范围。选择“时间范围”以指定自定义的“从”和“到”日期。

导出交付单元文件时，您可以选择将文件放在服务器上，或将文件下载到 SAP HANA Studio 的客户端系统。通常，您会导出到客户端系统，因为大多数开发人员无法访问 SAP HANA 服务器的文件系统。在“导出位置”部分，单击“导出到客户端”。在“位置”字段中，指定将下载交付单元文件的本地文件路径。“文件名”字段将预填基于当前时间、系统和交付单元名称的文件名。您可以更改名称，但请务必保留文件扩展名 .tgz。单击“下一步”继续。将出现一个摘要页面，概述导出设置。单击“完成”以启动导出过程。完成后，将在配置的路径中出现一个文件。创建后，该文件可用作备份或导入源。

## 14.3.3 从文件导入交付单元

除了使用 SAP HANA 应用生命周期管理在 [第 14.2.3 节](#14_002.html#h14.2.3) 中导入交付单元外，您还可以使用 SAP HANA Studio。此功能在 SAP HANA cockpit 中不可用，因此我们将在本章中介绍如何使用 SAP HANA Studio。SAP HANA Studio 提供了一个界面，用于将交付单元文件导入到包存储库中。该工具将导入文件中找到的所有开发工件，并在存储库中激活它们。假设导出源和导入源共享类似的 SAP HANA 软件版本，则该文件可以导入到 SAP HANA 实例中。

要启动导入过程，请在 SAP HANA Studio 中切换到管理控制台透视图。从菜单栏中，选择“文件” > “导入”。将出现“导入”窗口。在“选择导入向导”部分，展开“SAP HANA 内容”，然后选择“交付单元”。单击“下一步”继续。将出现一个名为“目标系统”的新弹出窗口。在系统列表中，选择将作为交付单元文件导入目标的系统。单击“下一步”继续。将出现“通过交付单元导入”窗口，如 [图 14.17](#14_003.html#f14.17) 所示。

[![SAP HANA Studio 中的导入选项](bilderklein/klein14_017.png)](img-f14.17.html)

## 图 14.17 SAP HANA Studio 中的导入选项

要配置导入选项，首先选择导入文件位置。对于存储在 SAP HANA Studio 客户端系统上的文件，请选择“客户端”位置。单击“浏览”按钮以指定文件路径。在“操作”部分，从以下选项中选择：选择“覆盖非活动版本”复选框，以便即使目标中已存在另一个版本的内容，也要导入交付单元内容。选择“激活对象”复选框，以便导入向导激活新导入的开发工件。如果未选择此选项，则对象将在未激活的情况下导入。

在“激活模式”下拉列表中，决定向导应如何处理不一致性。“激活并忽略受影响对象中的不一致性”模式将直接激活交付单元文件中找到的对象，即使其激活会导致现有开发工件变得不一致。“如果受影响对象中存在不一致性，则停止激活”选项将在导入过程中检测到任何不一致性时停止激活过程。默认选项是“激活并忽略导入对象及其受影响对象中的不一致性”。选择此选项后，导入向导将尝试激活交付单元文件中找到的开发工件，即使某些工件及其受影响对象导入失败。

“对象导入模拟”部分包含将要导入的开发工件列表。此外，您还将根据对目标存储库的审查，看到预期的激活状态。请注意，即使模拟指示不会出现错误，对象仍可能导入失败。单击“完成”以导入对象。
