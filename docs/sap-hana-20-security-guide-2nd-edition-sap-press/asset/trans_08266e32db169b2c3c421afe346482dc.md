在使用此界面时，如果出现任何激活问题，警告消息将显示在 User Management 窗口底部的状态窗格中。状态窗格具有深色背景，错误消息将以红色文本显示。仅在尝试激活或保存更改时才会生成错误。在以下部分中，我们将更详细地审查 System Privileges、Object Privileges、Analytic Privileges、Package Privileges、Application Privileges 和 Privileges on Users 选项卡。

## System Privileges

要授予或撤销用户帐户的系统权限，请找到 System Privileges 选项卡。要添加系统权限，请单击 + 以打开 Find System Privileges 选项卡。您可以使用搜索框根据输入的文本过滤列表。从列表中选择一个或多个权限，然后单击 OK 继续。您选择的系统权限现在将列在选项卡中。要将 Grantable to Other Users and Roles 分配给选定的权限，请选择权限，并根据需要在 Details for 区域右侧每个选定系统权限右侧的复选框中找到复选框。[Figure 4.13](#04_003.html#f4.13) 显示了此界面的示例，您可以在其中查看列出的系统权限以及可以配置 Grantable to Other Users and Roles 的详细信息部分。

[![Working with System Privileges in the SAP HANA Web-Based Workbench Security Interface](bilderklein/klein04_013.png)](img-f4.13.html)

**Figure 4.13** Working with System Privileges in the SAP HANA Web-Based Workbench Security Interface

要撤销系统权限，请从列表中选择该权限，然后单击红色 X。要保存更改，请按 `(Ctrl)+(S)`。或者，单击左上角的保存图标（软盘）以保存并激活权限。在权限选项卡下方深色背景区域中查找激活错误。错误将以红色文本列出。白色文本将指示更改成功。

## Object Privileges

用户管理界面中的第三个选项卡称为 Object Privileges。您将使用此选项卡授予或撤销对象权限。要添加对象权限，请单击 + 并搜索所需的目录对象。将出现一个搜索对话框，允许您搜索对象。与 SAP HANA cockpit 不同，SAP HANA Web-Based Development Workbench 还提供基于对象类型的其他搜索选项作为复选框，这可能会使按类型定位特定对象变得更加容易。选择所需的对象并单击 OK。选定对象的列表将出现在选项卡中，如 [Figure 4.14](#04_003.html#f4.14) 所示。每个对象右侧是可使用复选框授予的适用权限列表。保存更改时，选中的项将被授予，未选中的框将被撤销。Grantable to Others 选项也可使用 Yes 和 No 单选按钮使用。

[![Working with Object Privileges in the SAP HANA Web-Based Workbench Security Interface](bilderklein/klein04_014.png)](img-f4.14.html)

**Figure 4.14** Working with Object Privileges in the SAP HANA Web-Based Workbench Security Interface

要撤销对象权限的所有权限，请从列表中选择该对象，然后单击红色 X。这将删除对象并撤销当前授予的所有权限。要保存更改，请按 `(Ctrl)+(S)` 或单击磁盘图标以保存并激活权限。在选项卡下方深色背景区域中查找激活错误。错误将以红色文本列出。白色文本将指示更改成功。

## Analytic Privileges

用户管理界面中的第四个选项卡称为 Analytic Privileges。要将分析权限添加到列表中，请单击 + 并搜索所需的分析权限。要撤销分析权限，请从列表中选择该权限，然后单击红色 X 以删除分析权限。要保存更改，请按 `(Ctrl)+(S)` 或单击磁盘图标以保存并激活权限。

## Package Privileges

用户管理界面中的第五个选项卡称为 Package Privileges。要添加包并配置其权限，请单击 + 并搜索所需的包层次结构级别。将出现 Find Package 搜索界面窗口，允许您搜索并选择一个或多个包级别。选择要保护的包并单击 OK 按钮返回到上一屏幕，您可以在其中授予所需的包权限。[Figure 4.15](#04_003.html#f4.15) 显示了 Package Privileges 界面的示例，您可以在其中分配包并授予权限。

[![Working with Package Privileges in the SAP HANA Web-Based Workbench Security Interface](bilderklein/klein04_015.png)](img-f4.15.html)

**Figure 4.15** Working with Package Privileges in the SAP HANA Web-Based Workbench Security Interface

要撤销包权限，请从列表中选择包层次结构级别并选择红色 X 将其删除。要保存更改，请按 `(Ctrl)+(S)` 或单击磁盘图标以保存并激活权限。

## Application Privileges

用户管理界面中的第六个选项卡称为 Application Privileges。要将应用程序权限添加到列表中，请单击加号图标 (+) 并搜索所需的应用程序权限。要撤销应用程序权限，请从列表中选择该权限，然后单击红色 X 以删除应用程序权限。要保存更改，请按 `(Ctrl)+(S)` 或单击磁盘图标以保存并激活权限。

## Privileges on Users

用户管理界面中的第七个链接名为 Privileges on Users。您将使用此界面为当前经过身份验证的用户向被授予者授予附加调试器权限。此 GUI 界面仅限于一个操作。单击添加图标（绿色加号）将自动将登录用户添加到列表中。然后，只能检查或选择 Attach Debugger 权限。要保存更改，请按 `(Ctrl)+(S)` 或单击磁盘图标以保存并激活权限。如果权限已授予，请单击撤销图标（红色 X），通过在列表中选择用户来撤销权限。
