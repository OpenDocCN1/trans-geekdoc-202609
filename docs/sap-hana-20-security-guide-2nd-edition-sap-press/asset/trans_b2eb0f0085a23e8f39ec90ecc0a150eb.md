## 14.3 将安全包传输到其他 SAP HANA 系统

如前所述，在系统之间传输安全模型可使整体 SAP HANA 环境中安全模型的实现更加一致。要使用 SAP HANA 传输系统并实现此目标，必须在安全模型中定义基于存储库的角色。如果安全模型基于使用 SQL 语句创建的标准角色，则无法在 SAP HANA 实例之间传输它。

在系统之间传输交付单元时，交付单元中的所有包和开发工件都会在目标系统中导入并激活。如果存在同名的现有对象，则会被覆盖。如果对象存在于目标系统但不存在于交付单元中，则会被标记为删除。如果对象存在于交付单元中但不存在于目标系统，则会在目标系统中创建。导入交付单元时，同一交付单元会在目标系统中创建，包括与该交付单元关联的所有包和开发工件。因此，交付单元是确保存储库角色保持一致的绝佳方式。

SAP HANA 提供了两种工具，用于在实例之间传输与安全相关的交付单元。第一种工具是 SAP HANA 应用生命周期管理，我们在 [第 14.2.2 节](#14_002.html#h14.2.2) 中介绍过。第二种工具是 SAP HANA Studio，它提供导出和导入交付单元到压缩文件的选项。生成的文件可以导入到运行类似软件版本的 SAP HANA 系统中。

在本节中，我们将探讨使用 SAP HANA 应用生命周期管理传输交付单元的过程。我们还将回顾使用 SAP HANA Studio 导出和导入交付单元的过程。

### 14.3.1 使用 SAP HANA 应用生命周期管理传输交付单元

为了管理系统之间内容的传输或迁移，SAP 开发了 SAP HANA 应用生命周期管理 Web 应用程序。该应用程序托管在 XS 引擎中。在将对象传输到新系统时，必须访问目标 SAP HANA 实例上的 SAP HANA 应用生命周期管理实例。SAP HANA 应用生命周期管理使用拉取方法，这意味着目标 SAP HANA 应用生命周期管理实例访问源 SAP HANA 应用生命周期管理实例，并将交付单元拉取到目标系统的本地存储库中。[图 14.9](#14_003.html#f14.9) 显示了此过程的概览。

[![高级别 SAP HANA 应用生命周期管理传输过程](bilderklein/klein14_009.png)](img-f14.9.html)

**图 14.9** 高级别 SAP HANA 应用生命周期管理传输过程

如 [图 14.9](#14_003.html#f14.9) 所示，该过程的第一步要求开发人员或安全管理员在 SAP HANA DEV 实例中创建内容。该过程的第二步要求传输管理员将内容分配给源实例中的交付单元。在最后一步，传输管理员将访问目标 SAP HANA 应用生命周期管理实例，并将交付单元从源系统拉取到目标系统。

提醒一下，您可以使用特定于每个实例的 URL 访问 SAP HANA 应用生命周期管理，如下所示：

*   `https://<host_name>:43<instance number>/sap/hana/xs/lm`

*   `https://w5-3db-hana01.e-corp.root.local:4300/sap/hana/xs/lm`

或者，如果未配置 SSL：

*   `http://<host_name>:80<instance number>/sap/hana/xs/lm`

*   `http://w5-3db-hana01.e-corp.root.local:8000/sap/hana/xs/lm`

在 SAP HANA 应用生命周期管理实例的主页上，您将看到一系列磁贴。磁贴上方有一个菜单栏，如 [图 14.10](#14_003.html#f14.10) 所示。该菜单栏中的第三个选项卡是 `Transport`；单击此选项卡以启动传输过程。

[![SAP HANA 应用生命周期管理主页](bilderklein/klein14_010.png)](img-f14.10.html)

**图 14.10** SAP HANA 应用生命周期管理主页

传输管理窗口在主菜单栏下方有三个主要选项卡或菜单选项。默认情况下选择 `System` 选项卡，`Transports` 和 `Logs` 选项卡也可用，如 [图 14.11](#14_003.html#f14.11) 所示。

[![传输管理窗口和系统选项](bilderklein/klein14_011.png)](img-f14.11.html)

**图 14.11** 传输管理窗口和系统选项

在传输过程开始之前，必须在目标系统的 SAP HANA 应用生命周期管理实例中注册源系统。要注册新系统，请单击子菜单栏下方的 `+ Register` 按钮。将出现“注册系统”窗口，如 [图 14.12](#14_003.html#f14.12) 所示。

[![SAP HANA 应用生命周期管理中的注册系统窗口](bilderklein/klein14_012.png)](img-f14.12.html)

**图 14.12** SAP HANA 应用生命周期管理中的注册系统窗口

在此窗口中，输入源 SAP HANA 实例的主机。在 XS 引擎 HTTP(S) 端口字段中输入源 SAP HANA 实例 XS 引擎的 TCP/IP 端口。注释字段为可选项。输入正确信息后，单击 `Next`。将出现一个名为“配置目标”的新窗口。此窗口说明必须配置特定于源 SAP HANA 实例的连接和身份验证详细信息。要配置这些详细信息，请单击 `Maintain Destination` 按钮以打开名为“HTTP 目标详细信息”的新窗口。

在此窗口中，指定源系统的连接详细信息。单击 `Authentication Details` 菜单选项以打开其配置页面。在身份验证详细信息页面上，单击右下角的 `Edit` 按钮。现在，您可以指定源系统的身份验证详细信息。最常见的选项是选择 `Basic` 身份验证类型。然后，可以使用 `User` 和 `Password` 字段指定源系统的登录凭据。将使用的源系统服务帐户至少需要授予 `sap.hana.xs.lm.roles::Transport` 角色。输入凭据后，单击右下角的 `Save` 按钮。单击窗口右上角的 `X` 关闭“HTTP 目标详细信息”窗口。在“注册系统”窗口上单击 `Finish`。您的源系统现在应该已在传输系统列表中注册。

该过程的下一步是定义传输路径。要创建传输路径，请单击名为 `Transports` 的子菜单项，如 [图 14.13](#14_003.html#f14.13) 所示。

[![传输管理窗口和传输选项](bilderklein/klein14_013.png)](img-f14.13.html)

**图 14.13** 传输管理窗口和传输选项

要创建新的传输路径，请单击 `+ Create` 按钮。将出现“创建传输路径”窗口，如 [图 14.14](#14_003.html#f14.14) 所示。
