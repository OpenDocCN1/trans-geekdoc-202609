
# SAP HANA Cockpit: System Configuration GUI

Instead of using SQL commands to update the security policy settings, you can use the Manage System Configuration options in the SAP HANA cockpit found under Database Administration. Click on Manage System Configuration to launch the System Configuration GUI.

The System Configuration GUI lists any default or custom defined configuration settings for SAP HANA. Just below the Parameters tab, you’ll see a search bar and a series of dropdown lists, as shown in [Figure 12.1](#12_001.html#f12.1) for reference. Note that you’ll need the `INIFILE ADMIN` system privilege to view or modify these settings.

[![SAP HANA Cockpit System Configuration GUI](bilderklein/klein12_001.png)](img-f12.1.html)

**Figure 12.1** SAP HANA Cockpit System Configuration GUI

You can use the search bar to search for a specific parameter name. In addition, you can use the Configuration File dropdown list to filter the list to a specific configuration file. Individual parameters are organized into sections of associated parameters. You can use the Section dropdown list to filter to a specific section. If the SAP HANA system has multiple servers (scale-out), you can use the Host section to filter the list for a given server node or host. Finally, you can use the Database dropdown list to filter the list to settings specific to a given tenant database.

Once a parameter is located, you can use the Override Value link, located on the far-right side of the parameter, to change the current value or, in some cases, the default value. [Figure 12.2](#12_001.html#f12.2) shows an example of the GUI where we’ve searched for the term “password” and chosen the indexserver.ini option in the Configuration File dropdown list. The results show the section `[]password_policy` and a list of parameters that can be changed. To change an individual parameter configuration value, click the Override Value option on the far right, which will launch a configuration window for the associated parameter.

[![Viewing Password Policy Settings of the indexserver.ini Configuration File Using the SAP HANA Cockpit GUI](bilderklein/klein12_002.png)](img-f12.2.html)

**Figure 12.2** Viewing Password Policy Settings of the indexserver.ini Configuration File Using the SAP HANA Cockpit GUI

[Figure 12.3](#12_001.html#f12.3) shows an example of the `last_used_passwords` parameter configuration window and how parameters can be overwritten for a System Value, either all tenant databases or an individual tenant database value under the Select Database dropdown list.

[![Changing Password Policy Settings for last_used_passwords](bilderklein/klein12_003.png)](img-f12.3.html)

**Figure 12.3** Changing Password Policy Settings for last_used_passwords

The configuration window will list the Default and Active values for the setting. In addition, you can click the Restore Default button to quickly restore the default value for the setting. To change the configuration setting, enter the desired value in the provided field and click the OK button. To cancel changes before they’re saved, click the Cancel button. Password policy settings are implemented instantly within the SAP HANA system; no reboot is required for them to take effect.

## SAP HANA Cockpit: Authentication Password Policy GUI

The SAP HANA cockpit also offers a dedicated GUI to manage the password policy. You can access the GUI by clicking the Password Policy link in the Authentication section of the System Overview page of the SAP HANA cockpit. [Figure 12.4](#12_001.html#f12.4) shows an overview of the password policy management GUI in the SAP HANA cockpit. Notice that the same configuration settings listed in the previous section are available in this GUI as well.

To modify the password policy, click the Edit button found at the top right side of the window. For each setting, an editable field or radio button option will appear. Click the Save button located at the bottom to save the changes. Click Cancel to discard any unsaved changes.

[![Password Policy Configuration GUI in the SAP HANA Cockpit](bilderklein/klein12_004.png)](img-f12.4.html)

**Figure 12.4** Password Policy Configuration GUI in the SAP HANA Cockpit

The GUI also offers an additional Password Blacklist tab, located at the top, next to the Password Policy tab, as shown in [Figure 12.4](#12_001.html#f12.4). This interface, shown in [Figure 12.5](#12_001.html#f12.5), allows an administrator to define a list of specific words, phrases, or password combinations that won’t be accepted by the system for a given user.

[![Password Blacklist Configuration GUI](bilderklein/klein12_005.png)](img-f12.5.html)

**Figure 12.5** Password Blacklist Configuration GUI

To add a blacklist item, click the Edit button on the top right side of the Password Blacklist tab. In the columns provided, click the Add Entry button to insert a new phrase into the list. If you want the system to look for the word within the provided password, select the checkbox beside the Contained in Password option. For example, if the blacklisted word is “welcome,” the password “welcome1234” wouldn’t be accepted because it contains the target word. If the Contained in Password option isn’t selected, the system will only prevent the exact word as listed in the first cell. Using the same example, the password “welcome1234” would be acceptable because it isn’t an exact match for “welcome.” If the word should be evaluated using the exact case of the entered text, select the Case-Sensitive checkbox. For example, if the Case-Sensitive option is selected, then “Welcome” would be accepted if the provided blacklisted word is “welcome.”

You can also execute the following SQL statement to view a list of configured blacklisted password words defined in the system:

```
SELECT * FROM "_SYS_SECURITY"."_SYS_PASSWORD_BLACKLIST"
```

## SAP HANA Cockpit: User Group-Specific Password Policy

Starting with SAP HANA 2.0, you can also define user groups. Users groups are organizational units that help you group users into containers for delegated administration purposes and password policy purposes. User groups are not currently used for authorization purposes. With user groups, you can give specific administrators access to a select group of users. You can also define a unique password policy for each group.

Within the SAP HANA cockpit, you can access this password policy from the same tile and link we used to create and edit groups. Locate the User & Role Management tile and click the Manage User Groups link, which will launch the User Group management window. Within the management window, you’ll see a list of previously defined user groups. Click a group within the list to open the management options for the group. With the group management window open, click the Password Policy tab. You’ll then see a list of configured password policy options for the group. Click the Edit button to modify the password policy for the group.

Note that, if an individual password policy is not explicitly configured for a user group, the value will default to the value configured for the system or tenant database. You can also issue the following SQL statement to view the password policy for a given user at any time to see their effective password policy:

```
SELECT * FROM "SYS"."M_EFFECTIVE_PASSWORD_POLICY" WHERE USER_NAME = '<USER_NAME>';
```

## SAP HANA Web-Based Development Workbench Security Manager

The SAP HANA Web-Based Development Workbench security manager, hosted within the XS engine, provides an interface to manage security settings, including password policies.

You can access the SAP HANA Web-Based Development Workbench security manager by updating the following two URLs to match the details of your environment:

*   `http://<sap_hana_host>:80<instance_number>/sap/hana/ide/security`
*   `https://<sap_hana_host>:43<instance_number>/sap/hana/ide/security`
