

你将使用此链接来创建、编辑和删除数据库用户。你只能在此链接中配置用户账户设置。例如，你可以在此区域配置用户的身份验证模式、密码、第三方身份验证设置和自定义用户属性。你不能使用此区域向用户授予角色或权限。相反，你将使用“Assign role to users”和“Assign privilege to users”链接来执行这些活动。我们将在[第 4 章](#04_001.html#h4)中更详细地讨论这些选项。

*   Assign role to users  

    你将使用此链接来授予或撤销用户账户的角色。我们将在[第 5 章](#05_001.html#h5)中更详细地讨论此链接。

*   Assign privilege to users  

    你将使用此链接来授予或撤销用户的单个权限。我们将在[第 4 章](#04_001.html#h4)和从[第 6 章](#06_001.html#h6)到[第 11 章](#11_001.html#h11)中更详细地讨论此链接。

*   Manage roles  

    你将使用此链接来查看和管理标准数据库运行时角色，例如，向角色授予其他角色、系统权限和对象权限。你还将使用此链接来创建和删除角色。我们将在[第 5 章](#05_001.html#h5)中更详细地讨论此链接。

*   Manage user group  

    你将使用此链接来创建和编辑用户组。用户组有助于将用户组织成组。你可以配置用户组，以便只有特定用户可以管理组内的其他用户账户。你还可以为每个用户组建立唯一的密码策略。

*   View database object dependencies  

    你将使用此链接来查看给定目录对象的授权依赖项，这是安全管理员在删除数据库对象之前必须执行的重要步骤，也是用于确定哪些用户可以访问数据库对象的步骤。

### 1.2.4 安全相关链接

你将使用“安全相关链接”磁贴及其链接来管理 SAP HANA 数据库中的多个安全相关项目，如[图 1.14](#01_002.html#f1.14)所示。

[![Security Related Links Tile and Links in SAP HANA Cockpit](bilderklein/klein01_014.png)](img-f1.14.html)

**图 1.14** SAP HANA Cockpit 中的“安全相关链接”磁贴和链接

让我们更详细地探索每个链接的目的和预期用途：

*   Manage certificates  

    你将使用此链接来访问数据库内的证书。如我们将在[第 13 章](#13_001.html#h13)中进一步讨论，你将使用此界面来导入和删除证书。

*   Manage certificate collections  

    你将使用此链接来管理证书集合。证书集合是一个物理或逻辑存储，用于保存证书并定义其用途。如我们将在[第 13 章](#13_001.html#h13)中进一步讨论，你将使用此界面来管理存储在数据库中的证书集合。

*   View network security information  

    你将使用此链接来访问一个页面，该页面提供有关通信加密状态、传输层安全 (TLS)/安全套接字层 (SSL) 设置和类型以及内部通信加密的一般信息。此信息为只读，且无法在此界面中更改任何设置。

*   Manage SAML identity providers  

    你将使用此链接来管理第三方安全断言标记语言 (SAML) 身份验证提供程序，并导入和删除对该机制至关重要的 SAML 证书。如我们将在[第 12 章](#12_001.html#h12)中进一步讨论，SAML 可以为 SAP HANA 数据库和 Web 应用程序界面提供单点登录功能。

*   Manage JWT identity providers  

    你将使用此链接来管理 SAP HANA 系统中支持的用于单点登录的 JSON Web 令牌 (JWT) 提供程序。JWT 是一种开放标准 (RFC 7519)，概述了使用 JavaScript 对象表示法 (JSON) 对象在两方之间传递安全信息的方法。SAP HANA 对此功能的支持有限，如我们将在[第 12 章](#12_001.html#h12)中进一步讨论。

*   Security checklist  

    你将使用此链接来访问 SAP 的检查清单，以便将当前 SAP HANA 安全设置与 SAP 的建议进行比较。此检查清单提供与保护 SAP HANA 系统相关的实时报告、警告和信息。该界面仅提供警告，不推荐具体操作。请参见[第 17 章](#17_001.html#h17)，了解如何降低检查清单中发现的一些警告所关联的风险。

*   Security administration help  

    你将使用此链接来打开托管在 SAP HANA Cockpit Web 应用程序服务器上的 SAP HANA Administration with SAP HANA Cockpit 指南。此指南提供有关管理 SAP HANA Cockpit 的详细信息。此链接将直接带你进入指南的“安全管理”部分。

*   SAP HANA security website   

    你将使用此链接来打开 [www.sap.com](http://www.sap.com) 上的 SAP HANA 安全产品页面。在此页面上，你将找到指向相关安全帮助文档、白皮书和案例研究的链接。

你现在应该已基本了解如何访问“安全相关链接”磁贴以及它在管理 SAP HANA 安全模型时提供的选项。在下一节中，我们将探索“匿名化报告”磁贴及其链接。

### 1.2.5 匿名化报告

从 SAP HANA 2.0 SPS 04 开始，你可以定义 SQL 视图，以便在基于各种参数和方法查询数据时对数据进行匿名化处理。使用此功能保护的视图称为匿名化视图。你可以使用“匿名化报告”磁贴和链接来访问“查看可用匿名化视图”链接，该链接将引导你进入“匿名化报告”界面。在“匿名化报告”界面中，你将看到一个启用了此功能的目录视图列表。你可以点击每个列出的视图，以查看已应用于该视图的匿名化参数和方法的只读信息。
