

# Listing 18.4 外部目录对象引用所需的 SYSTEM.hdbsynonym 文件

同义词在 HDI 架构 `MYPROJ_HDI_DB_1` 中创建，当 HDI 容器内的对象必须引用 HDI 容器外的对象时需要它。同样，`#OO` 用户必须有权访问此对象，否则项目将无法构建。

此外，您还需要创建一个 `.hdbroleconfig` 文件，用于描述对外部架构 `SYSTEM` 的引用。[Listing 18.5](#18_004.html#l18.5) 显示了所需文件的示例。此 JSON 文件要求您按名称将 HDI 容器角色映射到外部架构引用或别名。然后，您将在 `.hdbrole` 文件的定义中使用引用名称 `"REF_SYSTEM"`。

```
{ 
  "MyProj.db.roles::TABLE_READ_ONLY_ACCESS":{ 
    "REF_SYSTEM":{ 
      "schema":"SYSTEM" 
    }
  } 
}
```

# Listing 18.5 外部架构引用所需的 ROLEREF.hdbroleconfig 文件

现在我们已经回顾了示例文件，让我们来看看可以使用的其他语法值。`.hdbrole` 文件可以在 `"global_roles"` 值数组中引用 HDI 容器内的现有角色。以下代码是用于引用现有角色的值字符串示例：

```
"global_roles":[ 
    "HDI_ROLE_1", 
    "HDI_ROLE_2" 
]
```

系统权限可以使用 `"system_privileges"` 值数组进行配置。在以下示例中，我们引用了两个系统权限：

```
"system_privileges":[  
   "BACKUP ADMIN",
   "USER ADMIN"
 ]
```

分析权限或结构化权限可以使用 `"schema_analytic_privileges"` 值数组进行引用。所需语法取决于引用的对象。如果您引用的是 HDI 容器内的分析权限，则会使用以下语法：

```
"schema_analytic_privileges":[
{
"privileges": ["MyProj.db.aps::AP_CUSTOMER"]
} 
```

在这种情况下，您只需要在 `"privileges"` 值字符串中输入命名空间或包文件夹结构以及分析权限的名称。如果您引用的是带有架构的外部结构化权限，则会使用 [Listing 18.6](#18_004.html#l18.6) 中所示的语法。

```
"schema_analytic_privileges":[
   {
     "schema_reference":"APSchemaRef1",
     "privileges": ["AP1", "AP2"] }
 ]
```

## .hdbrole 文件语法的其他信息

有关 `.hdbrole` 文件完整语法的其他信息，请参阅 SAP HANA 2.0 SPS 04 的 SAP HANA 开发基础架构参考指南中的“SAP HDI 工件类型和构建插件参考”部分，可在 [http://s-prs.co/v498223](http://s-prs.co/v498223) 上查阅。

回顾 [第 6 章](#06_001.html#h6)，SAP HANA XS 平台中的基于存储库的角色不能直接使用 `GRANT` 或 `REVOKE` 语句授予给受让人。您必须执行存储过程并提供输入参数来授予存储库角色。这种限制是因为只有所有者 `_SYS_REPO` 可以授予角色，因为没有其他用户拥有 `WITH GRANT OPTION`。但是，大多数 GUI 界面在您在 GUI 工作流中选择存储库角色时会自动执行这些过程。HDI 角色有类似的要求。只有系统管理的技术用户可以开箱即用地授予 HDI 容器角色。使用 SAP HANA XS 存储库角色时，您只需将 `EXECUTE` 权限授予 `_SYS_REPO` 架构的安全管理员，允许他们执行该操作。该过程易于执行，因为 `SYSTEM` 帐户拥有这些权限，包括 `WITH GRANT OPTION`。您也可以不费吹灰之力将它们包含在存储库角色中。

在 HDI 平台中，只有 `_SYS_DI` 用户和少数其他技术用户默认直接拥有这些权限。因此，您只有两种授予这些权限的选项：

*   您可以使用基于 HDI 容器服务连接的 SAP HANA 数据库资源管理器。在该连接中，您可以右键单击并选择 `Open SQL Console (Admin)`，这将打开模拟具有过程 `EXECUTE` 访问权限的用户的 SQL 控制台。

*   您可以利用 `_SYS_DI` 架构中名为 `GRANT_CONTAINER_API_PRIVILEGES_WITH_GRANT_OPTION` 的存储过程。默认情况下，`SYSTEM` 帐户对该过程拥有 `EXECUTE` 权限。但是，运行此过程并不简单，因为您必须按正确顺序运行一系列其他 SQL 语句才能正确使用此过程。

让我们更详细地查看每个选项，从第一个选项开始。

## 使用 SAP HANA 数据库资源管理器授予 HDI 角色

要使用 SAP Web IDE for SAP HANA 授予 HDI 角色，您必须先访问 SAP HANA 数据库资源管理器。在 [第 18.3 节](#18_003.html#h18.3) 中，我们提供了访问 SAP Web IDE for SAP HANA 应用程序的详细信息。登录应用程序后，您会注意到左侧垂直栏上有三个图标，如 [图 18.12](#18_004.html#f18.12) 所示。显示为一组堆叠立方体或方框的图标是用于启动 SAP HANA 数据库资源管理器视图的图标。您也可以使用文件菜单选项 `Tools • Database Explorer` 来启动 SAP HANA 数据库资源管理器界面。

[![SAP HANA Database Explorer in SAP Web IDE for SAP HANA](bilderklein/klein18_012.png)](img-f18.12.html) 

**图 18.12** SAP Web IDE for SAP HANA 中的 SAP HANA 数据库资源管理器

在启动 `Open SQL Console (Admin)` 选项之前，您需要创建正确类型的数据库连接。要创建连接，请定位 [图 18.12](#18_004.html#f18.12) 中包含现有数据库连接的窗格上方的大号加号 (`+`)。如果这是您第一次访问 SAP HANA 数据库资源管理器，则没有现有连接。单击加号 (`+`) 后，`Add Database` 窗口将出现。选择数据库类型 `HDI container`。搜索您当前的容器。在我们的环境中，正确的容器以当前登录用户的名称开头，后跟一个序列代码，然后项目名称以 `hdi_db` 结尾，如 [图 18.13](#18_004.html#f18.13) 所示。

[![Adding a Database from an HDI Container Connection](bilderklein/klein18_013.png)](img-f18.13.html) 

**图 18.13** 从 HDI 容器连接添加数据库

此连接将显示 HDI 数据库架构中的所有目录对象。要以管理员身份访问 SQL 控制台，请右键单击连接的顶部节点并选择 `Open SQL Console (Admin)`，如 [图 18.14](#18_004.html#f18.14) 所示。

SQL 控制台将在右侧打开，您可以在其中执行一系列 SQL 语句，将 HDI 容器角色授予指定用户。必须执行的 SQL 有些复杂。您必须运行五个不同的语句来授予角色。此外，您还需要 HDI 容器的技术名称。

[![Accessing the SQL Console as an HDI Container Administrator](bilderklein/klein18_014.png)](img-f18.14.html) 

**图 18.14** 以 HDI 容器管理员身份访问 SQL 控制台

如果您需要 HDI 容器的技术名称，可以运行 SQL 语句来查看名称，但您需要使用不同的 SQL 控制台。管理员用户没有正确的访问权限来显示技术容器名称，因此您需要在具有 `_SYS_DI` 架构 `SELECT` 访问权限的用户连接的 SQL 控制台中运行 SQL 语句。例如，`SYSTEM` 用户默认拥有此访问权限。以下语句将显示 HDI 容器的技术名称：

```
SELECT * FROM "_SYS_DI".M_ALL_CONTAINERS WHERE CONTAINER_NAME like 'MYPROJ%';
```
