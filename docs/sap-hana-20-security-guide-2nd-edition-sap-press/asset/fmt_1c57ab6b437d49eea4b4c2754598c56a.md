
# 6.4 管理仓库角色与权限

大多数用户会发现，使用 SAP HANA Web-Based Development Workbench 编辑器 GUI 创建仓库角色更加简单。该界面无需记忆每种对象类型的确切语法。您还可以在目录或仓库中搜索对象。在以下部分中，我们将首先了解如何访问 SAP HANA Web-Based Development Workbench 并浏览其基本功能。然后，我们将回顾授予系统权限、对象权限、分析权限、包权限和应用程序权限所需的具体流程。

## 6.4.1 访问和浏览 SAP HANA Web-Based Development Workbench 编辑器

您可以使用 [第 6.2.1 节](#06_002.html#h6.2.1) 中的说明访问 SAP HANA Web-Based Development Workbench。一旦您获得 SAP HANA Web-Based Development Workbench 编辑器的访问权限，请展开窗口右侧的 Content 节点。展开 Packages 以查看系统中定义的包列表。如前所述，仓库角色必须存储在仅安全管理员可以访问的包中。您通常会创建一个名为 Security 的顶级包来托管此类对象。

要创建仓库角色，请右键单击要存储角色的包，然后选择 New • Role，如 [图 6.5](#06_004.html#f6.5) 所示。

![Navigating the SAP HANA Web-Based Development Workbench Editor and Creating a Repository Role](bilderklein/klein06_005.png)

**Figure 6.5** Navigating the SAP HANA Web-Based Development Workbench Editor and Creating a Repository Role

将出现一个名为 New Role 的小窗口。输入所需的角色名称并单击 Create。右侧大窗格中将出现一个新的选项卡窗口。选项卡标签应与提供的仓库名称匹配。新窗口将包含一系列子选项卡：Granted Roles、System Privileges、Object Privileges、Analytic Privileges、Package Privileges 和 Application Privileges。

与基于仓库的角色相关，您可以在 SAP HANA Web-Based Development Workbench 编辑器中执行三项主要任务。您可以创建新角色、编辑现有角色，或管理分配给现有仓库角色的权限。

我们已在 [第 6.2 节](#06_002.html#h6.2) 中讨论了创建仓库角色的流程，因此现在让我们讨论在 SAP HANA Web-Based Development Workbench 编辑器中删除基于仓库的角色的流程。首先，在包层次结构中找到要删除的角色。右键单击该角色并选择 Delete。将出现一个 Confirmation Needed 窗口。选择 OK 以删除仓库角色。

要在 SAP HANA Web-Based Development Workbench 编辑器中编辑现有仓库角色，首先在包层次结构中找到要编辑的角色。单击该角色以打开角色编辑器 GUI。或者，右键单击该角色并选择 Open With • Role Editor 以使用 GUI 编辑该角色。您也可以选择 Open With • Text Editor 以编辑角色的脚本，如前面在 [第 6.2.1 节](#06_002.html#h6.2.1) 中讨论的那样。

如果您使用角色编辑器打开了仓库角色，现在可以从角色中添加或删除权限。让我们现在更仔细地了解授予每种权限所需的流程。

## 6.4.2 系统权限

单击 System Privileges 选项卡以显示可以添加或删除系统权限的界面。要添加系统权限，请单击子选项卡标题上的大号加号 (+) 按钮。将出现 Select System Privilege 弹出窗口，如 [图 6.6](#06_004.html#f6.6) 所示。此窗口中将出现一个搜索框；输入系统权限名称的一部分以缩小结果范围。或者，您可以滚动未过滤的列表以找到所需的系统权限。在列表中选择一个或多个权限。按住 (Ctrl) 键的同时单击以选择多个项目。所选项目将以浅蓝色突出显示。单击窗口底部的 OK 按钮以最终确定选择。

![Selecting and Assigning System Privileges in the SAP HANA Web-Based Development Workbench](bilderklein/klein06_006.png)

**Figure 6.6** Selecting and Assigning System Privileges in the SAP HANA Web-Based Development Workbench

所选权限将出现在 System Privileges 选项卡中，如 [图 6.7](#06_004.html#f6.7) 所示。

![Selected System Privileges](bilderklein/klein06_007.png)

**Figure 6.7** Selected System Privileges

要删除已分配的系统权限，请从列表中选择一个，然后单击列表上方的大号减号 (–) 以删除该权限。列表中的项目必须一次删除一个。

配置好所需的系统权限列表后，请单击左上角的保存所有图标（三个软盘）。

如果在保存和激活仓库角色时出现任何问题，消息将以红色文本显示在打开的 Repository Roles 选项卡下方的控制台窗口中。控制台窗口具有深色背景，位于打开的选项卡底部。肯定消息将以白色文本显示，错误消息将以红色文本显示。

要关闭打开的仓库角色选项卡，请单击选项卡右侧的小 X。

## 6.4.3 对象权限

单击 Object Privileges 选项卡以显示可以添加或删除对象权限的界面。要添加对象，请单击子选项卡标题上的大号加号 (+) 按钮。将出现 Select Object Privilege 弹出窗口，如 [图 6.8](#06_004.html#f6.8) 所示。搜索框分为两种广泛的对象类型。顶部的两个单选按钮允许您在设计时对象和运行时对象之间切换。搜索设计时对象时，请选择 Design-time 单选按钮。搜索运行时对象时，请选择 Run-time 单选按钮。

![Selecting and Assigning Object Privileges in the SAP HANA Web-Based Development Workbench](bilderklein/klein06_008.png)

**Figure 6.8** Selecting and Assigning Object Privileges in the SAP HANA Web-Based Development Workbench

单选按钮下方，有可用的筛选选项，用于将结果限制为特定对象类型。使用 Select Object Type 下拉列表选择要限制搜索结果的特定对象类型。默认选项是 All，表示考虑所有对象类型。例如，如果要将搜索结果限制为仅表，请从下拉列表中选择 Table，结果中将仅显示表对象。

在下拉列表下方，将出现一个搜索框。在文本框中输入对象名称的一部分以缩小结果范围。或者，您可以滚动未过滤的列表以按名称找到所需的对象。在列表中选择一个或多个对象。按住 (Ctrl) 键的同时单击以选择多个项目。单击窗口底部的 OK 按钮以最终确定选择。

所选对象将出现在 Object Privileges 选项卡中，如 [图 6.9](#06_004.html#f6.9) 所示。

![Selected Runtime and Design-Time Objects](bilderklein/klein06_009.png)

**Figure 6.9** Selected Runtime and Design-Time Objects

列出对象后，您现在需要为每个选定的对象分配各种对象权限。要为单个对象指定权限，请单击列表中的对象将其选中。在选定对象的右侧，将出现一系列权限和相应的复选框，如 [图 6.9](#06_004.html#f6.9) 右侧所示。

选择每个权限旁边的复选框，将所选权限分配给所选对象。对所有对象重复此过程。要删除权限，只需取消选择要删除的权限旁边的复选框即可。
