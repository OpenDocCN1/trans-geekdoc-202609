## 热门机器学习方法

既然你了解了机器学习为何成为你生活的一部分，你就需要了解它是如何能够学习的。

一般而言，主要有两种机器学习技术，即监督学习和无监督学习。机器学习中大约有百分之七十实际上是监督学习。另外百分之十到百分之二十是无监督学习。还有其他技术，如半监督学习和强化学习，但它们使用得不那么频繁。以下是这些技术所能实现的简要介绍：

- 1. 监督学习：只有在能够识别输入和输出且有标记数据可供使用时，才能实现这种机器学习方法。算法将获取其输入及其匹配的输出，以检测错误。根据输入，模型将进行调整。整个过程实际上是模式识别，这些算法始终依赖于回归、分类、预测或梯度提升等技术。请记住，你还将需要处理未标记的数据，而模式识别正是用来填补这些空白的。一旦建立了模式，算法就可以预测标签的值。监督机器学习通常用于需要预测未来的应用程序。例如，查找信用卡交易欺诈。

- 2. 无监督学习：监督学习涉及使用历史数据来预测未来事件，但无监督学习并非如此。这种类型的算法分析收集到的数据以确定其结构。这就是为什么无监督学习被用于理解没有任何突出属性的客户类别，或者为你提供在线推荐。一些最流行的无监督机器学习技术包括最近邻和K-Means聚类。

机器学习将长期存在，这就是为什么每个人都在谈论它。它是当今科技领域最大的趋势之一，因为它服务于日常目的。它被应用于如此多的领域，无疑也包括你的日常生活。这使得机器学习成为最有利可图的科技领域之一，提供了广泛的职业机会供你选择。所以，如果你想分一杯羹，你拥有所需的所有资源。

## 条件语句

既然你了解了基本数据类型，现在来快速学习涉及条件语句的更复杂操作。条件语句用于赋予应用程序有限的自主思考能力，并根据其对情况的评估做出决策。换句话说，它分析变量所需的条件，以指示程序根据该分析的结果做出反应。

Python 语句易于理解，因为它们逻辑清晰，语法反映了人类思维。例如，用英语写出的语法大致如下：“如果我不舒服，我就不去任何地方，否则我就得去上班”。在此示例中，我们指示程序检查你是否感觉良好。如果该语句的值为 false，意味着你感觉良好，因此它将继续执行下一行，即一个 "else" 语句。在一般编程中，"if" 和 "if else" 条件语句都经常使用。以下是语法示例：

```
x = 100
if (x < 100):
    print("x is small")
```

这是该语句的最基本形式。它检查是否为真，如果为真，则会发生某事；如果不为真，则什么都不会发生。以下是同时使用 else 语句的示例：

```
x = 100
if (x < 100):
    print("x is small")
else:
    print("x is large")

print ("Print this no matter what")
```

添加 "else" 关键字后，我们指示应用程序在返回 false 值时执行不同的任务。此外，我们有一个位于条件语句之外的独立声明。无论结果如何，都会执行它。

另一种条件语句涉及使用 "elif"，它允许应用程序在做出决策前分析多个语句。以下是示例：

```
if (condition1):
    add a statement here
elif (condition2):
    add another statement for this condition
elif (condition3):
    add another statement for this condition
else:
    if none of the conditions apply, do this
```

请注意，这次我们没有使用代码。你已经掌握了足够的 Python 语法和条件语句知识，可以将所有这些转换为代码。我们这里有的是伪代码，无论你是编写简单的 Python 练习还是使用机器学习算法，它都非常实用。伪代码允许你遵循 Python 编程结构，将想法写在“纸上”。这样，你就可以先列出大纲，再编写代码，从而更容易组织你的想法和应用程序。话虽如此，以下是实际代码：

```
x = 10
if (x > 10):
    print ("x is larger than ten")
elif x < 4:
    print ("x is smaller")
else:
    print ("x is pretty small")
```

现在你了解了关于条件语句的所有内容。将它们与你所学的数据类型结合起来进行练习。请记住，你需要始终练习这些基本的 Python 概念，以便之后理解机器学习算法的工作原理。

## 循环

代码有时需要反复执行，直到满足特定条件。这就是循环的用途。有两种类型：for 循环和 while 循环。让我们从第一个示例开始：

```
for x in range(1, 10):
    print(x)
```

这段代码将执行多次，每次打印 X 的值，直到达到十。

另一方面，while 循环仅在我们设置的条件仍为真时才重复执行代码块。因此，当条件不再满足时，循环将中断，应用程序将继续执行接下来的代码行。以下是 while 循环的示例：

```
x = 1
while x < 10:
    print(x)
    x += 1
```

x 变量被声明为整数，然后我们指示程序，只要 x 小于十，就应打印结果。请注意，如果此时不继续执行任何其他语句，将会创建一个无限循环，这不是你想要的。最后一条语句确保应用程序在每次执行时都会打印加一后的新值。当变量不再小于十时，条件不再满足，循环将中断，允许应用程序继续执行后续的任何代码。

请记住，无限循环很容易因错误和疏忽而发生。幸运的是，Python 有一个解决方案，即 "break" 语句，应将其放在循环末尾。以下是示例：

```
while True:
    answer = input("Type command:")
    if answer == "Yes":
        break
```

现在，通过键入命令可以中断循环。

## 函数

作为初学者机器学习者，这是在学习酷炫内容之前需要理解的最后一个 Python 组件。函数允许使你的程序更加高效、优化且易于处理。它们可以显著减少你需要输入的代码量，因此在系统资源方面使应用程序要求更低。以下是最基本的函数示例，供你了解语法：

```
def myFunction():
    print("Hello, I am now a function!")
```

函数首先使用 "def" 语句声明，后跟其名称。每当我们想要调用这段代码时，只需调用函数，而无需再次编写整段代码。例如，你只需输入：

```
myFunction()
```

函数后的括号表示可以存储多个参数的部分。它们可以像这样更改函数的定义：

```
def myName(firstname):
    print(firstname + " Smith")
```

```
myName("Andrew")
myName("Peter")
myName("Sam")
```

这里有一个名字参数，每当我们调用函数打印其参数时，它都会附加单词 "Smith" 一起打印。请注意，这只是一个非常基本的示例，以便你熟悉语法。更复杂的函数也以同样的方式编写。

以下是另一个示例，其中有一个默认参数，仅在没有其他内容可执行时才会被调用。

```
def myHobby(hobby = "leatherworking"):

```

```

```

myHobby ()

```

在这里你可以看到，没有参数的函数将使用我们设置的默认值。

此外，你还可以拥有返回值的函数。目前我们只编写了执行操作的函数，但它们不返回任何值或结果。这些函数要有用得多，因为结果可以随后被放入变量中，以便在其他操作中使用。在这种情况下，语法如下：

## TensorFlow

这是另一个以Python为中心的开源库，专为机器学习设计。请记住，机器学习是一个复杂的领域，手动实现算法和训练模型可能很困难。幸运的是，我们有像Tensorflow这样的工具来让我们的工作变得轻松得多。Tensorflow 不仅仅是一个简单的机器学习库。它实际上是一个框架，可以简化机器学习的几乎所有方面，例如数据获取、模型训练、提供预测，以及不断优化结果直到尽可能准确。

Tensorflow 由 Google 设计，旨在为复杂的大规模机器学习问题创建一个开源库。这个工具实际上包含了一些机器学习模型，以及神经网络模型和多种算法。换句话说，TensorFlow 为您提供了训练神经网络来分类手写数字、执行准确的图像识别、构建循环神经网络、处理自然语言处理等所需的一切。

Tensorflow 还允许您创建表示数据流的图。本质上，每个图都是一个可视化结构，显示信息如何通过多个数据处理节点。每个节点都由一个操作表示，节点之间的链接是一个多维数组，也称为张量。

所有这些功能均通过 Python 提供。如您已所知，这是您可以使用的最容易且最灵活的编程语言之一，由于其能够表达如何连接复杂抽象，因此非常适合执行所有机器学习任务。我们之前提到的张量和节点实际上是 Python 对象。因此，我们可以确定 Tensorflow 程序就是 Python 程序。但是，请注意，数学操作并非使用 Python 执行。为什么？因为 Tensorflow 使用 C++ 二进制文件来编写转换库以实现最佳性能。Python 仅用于连接各个部分，并允许我们使用复杂的编程操作来链接所有组件。

使用 Tensorflow 的另一个优势是，使用它开发的任何应用程序都可以在任何计算机系统上运行。它可以在本地系统、云端、Android 系统等上运行。例如，您可以使用 Google 的云服务与 Google 的 Tensorflow 处理单元一起运行该框架。但是，生成的机器学习预测模型需要安装在其预期运行的系统上。

请记住，迄今为止最大的优势是 Tensorflow 为我们的机器学习开发项目提供了抽象。这意味着您不必手动处理机器学习算法的实现。您甚至不需要知道如何将一个函数的输出设置为另一个函数的输入。虽然您应该知道如何完成所有这些工作，因为您想成为一名机器学习者，毕竟，Tensorflow 为您提供了只需将所有注意力放在应用程序本身而非其内部工作原理的能力。换句话说，您处理全局，而 Tensorflow 在幕后工作。

此外，Tensorflow 的一切都是为了让开发者的生活更轻松。如果您通过这个框架开发任何应用程序，您将受益于通过单独评估每个操作来调试它们。您将能够分析图形，然后根据需要对其进行编辑，而不是从头开始重建它们并再次执行分析。这样，图形可视化就变得非常交互且用户友好，尤其是当您可以通过易于理解的用户界面完全访问图形及其运行方式时。

这种行业标准机器学习库和框架的最后一个优势是，Google 仍在持续推动其开发，因此每个新版本都使其更易于使用且功能更强大。此外，将其集成到开发流程中所需的时间也大大减少。

如您所见，使用这个工具有许多优势，然而，像任何其他工具一样，它也有其缺点。最大的问题之一是由 Tensorflow 的实现方式引起的。某些训练模型结果很难提取，当我们在一个系统上训练模型，然后在另一个系统上训练时可以看到这一点。结果会在一定程度上有所不同。问题在于，其原因是一个复杂的问题，因此我们无法找到一个通用的解决方案。这就是为什么，为了实现最佳性能和准确性，您需要知道应用哪些机器学习技术，即使您不亲自完成所有脏活累活。

## 线性回归

许多机器学习问题（如预测分析）都使用线性回归来处理。只要训练数据有价值且噪声不太多，这种技术就能高精度地预测结果。请记住，这就是为什么您需要执行数据预处理，以清除可能影响结果的一些噪声和异常值。

线性回归的特征之一是根据自变量计算预测值。换句话说，当您需要计算多个变量之间的关联时，应选择此算法。但是请注意，线性回归只能处理回归问题，而不能处理分类问题。分类问题有其他算法。

现在让我们看一个示例，了解如何使用 Scikit-learn 和开源数据集应用线性回归。我们将使用 Scikit 库，因为它包含许多特定于机器学习的算法以及某些公开数据集。其中一个数据集是波士顿房价数据集，文档齐全且整洁。为了高效使用线性回归，我们将整个数据集划分为训练集（80%）和测试集（20%）。让我们开始工作：

```
from sklearn.datasets import load_boston
boston = load_boston()
from sklearn.cross_validation import train_test_split
X_train, X_test, Y_train, Y_test = train_test_split(boston.data,
boston.target, test_size=0.2, random_state=0)
```

如您所见，Python 代码易于阅读，无需太多解释即可相当易懂。我们已导入数据集并执行了拆分以获取训练集和测试集。拆分函数是 Scikit-learn 库包含的工具的完美示例。您会注意到，我们通过声明目标测试数据集应具有 0.2 的值来声明了百分比。这意味着它将包含 20% 的数据。此外，我们有一个 random state 参数，用于定义拆分期间随机数生成的值。基本上，它会随机选择将被归类为训练数据或测试数据的数据。

下一阶段，我们需要应用回归器，以便线性回归算法做出准确预测。实现后，我们只需测量结果以查看其表现如何。请记住，许多因素都可能影响准确性，例如随机错误、标记错误的数据、异常值、噪声等。这就是为什么您执行的预处理通常不够，您需要应用其他算法来改进结果。当您自行练习时，这是近期需要牢记的事项。现在让我们看看我们的回归器和获得的结果：

```

## 支持向量机

如果您需要一个几乎可以处理一切的多功能算法，那么支持向量机正是您所寻找的。与我们之前讨论的仅用于回归问题的线性回归算法不同，支持向量机可以处理回归、分类，甚至异常值检测。这种技术是每个机器学习者都需要学习并掌握如何实现的基础算法之一。



支持向量机很受欢迎，因为它们功能强大且不占用大量资源。通常，你对精度的要求越高，数据处理速度就越慢，因为这会对计算机系统提出更高要求。然而，支持向量机在不影响预测准确性的情况下，需要的计算能力少得多。此外，你还可以使用此算法清理数据集中的大部分噪声，从而减少预处理阶段所需的步骤（不过仍然建议执行所有步骤）。

那么，支持向量机为什么如此重要？它们应用于哪些领域？正因为其强大且多功能，支持向量机被应用于各个领域。例如，它们用于人脸识别软件、文本分类、手写识别，以及医疗行业的基因分类。这种算法的用途远不止这些，因为它能高效地分隔数据集中的数据点，从而产生足够准确的结果，适用于复杂应用。

我们将通过一个示例，了解支持向量机是如何实现的以及其工作原理。请记住，你需要再次使用 Scikit-learn 库，以缩短实现算法所需的时间。如你所见，无论你对机器学习、数据科学还是数据挖掘感兴趣，这个工具都不可或缺。话虽这么说，我们将使用支持向量机来预测银行券的有效性。这涉及图像分类，如前所述，该算法非常适合此过程。算法实现将很简单，因为分类是二进制的。我们只需确定银行券是真币还是伪币，即真或假。

请注意，我们将拥有一些描述银行券的属性。此外，我们需要在两个维度之间建立分界线，以避免任何误分类。虽然其他分类算法可以执行相同的过程，但支持向量机具有独特的方法。这种技术通过计算与每个类别非常接近的某些数据点之间的最大距离来确定决策边界。决策边界需要是最优的，因此我们不能随意选择它。这些最优数据点被称为支持向量，因此我们的算法才得名。请记住，它们是一种数学概念，我们不会深入探讨其计算方式等细节。在这个阶段，你不需要知道其中相当复杂的代数核心细节。

## 决策树

决策树，就像支持向量机一样，功能极其多样，因为它们既可以执行回归操作，也可以执行分类操作。这意味着在处理大型数据集时，它们非常有用，你应该熟悉它们。此外，决策树构成了另一种机器学习算法的基础，即集成方法，特别是被称为随机森林的方法。这都很合乎逻辑。如果你有大量的决策树，它们就构成了一棵森林，对吧？

顾名思义，决策树用于建模决策，包括确定整个过程中涉及的任何后果和所需的系统资源。此外，所有内容都以图表的形式直观呈现。换言之，最终你将得到一个流程图，其中包含你执行的每个测试。例如，假设你掷硬币若干次。每次结果都会被记录，你会得到若干表示这些结果的树枝，以及表示类别标签的叶子。

这种受监督的机器学习算法被认为是最强大的算法之一，因为它在不牺牲太多效率或要求系统提供太多资源的情况下，就能提供准确的结果。此外，图形系统让你能够轻松解读数据，并按需进行调整，而无需经历另一个同样能达成目标但工作量更大的繁琐过程。话虽这么说，让我们来讨论决策树提供的所有其他优势：

- 1. 用户友好：与许多其他算法或技术不同，即使对于没有显著机器学习或数学知识和经验的人来说，决策树也是合乎逻辑的。你不需要是数据科学家就可以开始使用它们。它们遵循一种简单的、类似编程的结构，类似于 Python 的条件操作。决策树遵循“如果是这样，那么执行那个，否则执行这个”的逻辑。此外，结果清晰，甚至不需要具备基本的统计学知识来解读它们。拥有一个能清晰解释你正在分析的数据的内置图表，这就是其中的好处。

- 2. 数据清洁：如前面关于数据预处理的章节所述，干净的数据能产生准确的

结果。因此，无论您使用哪种算法，您始终都需要通过使用某些方法和技术来消除尽可能多的噪声和异常值。但是，使用决策树的好处是它们几乎不受这些因素的影响。异常值和噪声只会是小小的麻烦，您通常可以完全忽略它们，同时仍然获得准确的结果。

- 3. 多用途：如您已知，某些机器学习算法的设计仅针对特定数据类型。有些只能应用于类别数据，而另一些则专门用于数值数据。出于此原因，在处理同时包含这两类信息的复杂数据集时，通常需要将它们结合使用。然而，决策树可以处理两种数据类型的训练过程，因此显著减轻了您的工作量。

- 4. 探索数据：数据探索是一个有价值的步骤，可能会耗费大量时间，因为您需要识别最有价值的数据点，然后建立它们之间的连接。然而，决策树在探索性分析方面表现出色，执行此步骤所需的时间将大大减少。此外，您将能够更高效地创建新特征，以进一步提升预测的准确性。探索数据可能会令人精疲力竭，因为在现实世界中，您通常需要处理成千上万个变量，如果没有合适的工具，找出最重要的变量可能会很困难。

现在您已经了解决策树是什么以及为什么它们是机器学习者中受欢迎的算法，您还应该了解它们带来的缺点。请记住，不存在完美的算法，那么让我们来看看在使用决策树时您会面临哪些困难：

- 1. 过拟合：这可能是您将面临的最大问题。决策树往往会夸大其词并构建过于复杂的决策树，这些树无法在一般数据上准确运行。然而，过拟合问题不仅存在此种情况。许多算法都必须应对这一问题。您可以部署的限制过拟合风险的最简单解决方案是应用参数限制。

- 2. 分类：当您的数据集包含大量连续数值变量时，决策树在对其进行分类时会遇到困难。在此过程中通常会丢失信息。请注意，连续变量被认为是任何值在特定最小值和最大值之间明确定义的变量。例如，假设我们有一些数据规定只有21岁到45岁的人才能参军。年龄变量被视为连续变量，因为我们设定了限制。

- 3. 挑剔的算法：算法并不总是选择最准确且高效的决策树，您从中得出结论。这只是该技术的固有特性。然而，解决方案很简单。您只需训练多棵树，以随机抽样更多数量的特征并找到最准确的解决方案。

在本节前面您已经了解到，决策树既用于执行回归任务，也用于分类任务。然而，这并不意味着您对两种任务使用相同的方法。您需要将决策树分为两个不同的类别，即回归树和分类树。两个类别的基础仍然相同，但是，有一些差异您需要了解：

- 1. 回归树专门应用于涉及连续因变量的任务。同时，在处理类别因变量时需要使用分类树。

- 2. 我们从训练数据中提取的结果值，对每类决策树的确定方式不同。对于分类树，该值计算为总体观测值的众数。这意味着，如果我们有一个未知的数据观测值，可以借助众数进行预测。请记住，众数是在给定值集合中出现频率最高的值。另一方面，回归树将总体观测值的均值作为从训练数据中提取的值。然后，用此均值来计算任何缺失的数据观测值。

- 3. 回归树和分类树都依赖二分法。该概念涉及从树的顶部到底部进行。这意味着，当我们在树的一个区域中有观测值时，下方会有若干被分割的分支。分割发生在预测器空间中。这个概念也常被称为贪婪法，因为算法寻找当前正在分析的分割所需的变量。该操作不考虑未来的分割，这就是为什么有时我们得不到最准确结果的原因。必须考虑这个问题，以便通过各种方法抵消其影响并创建更好的决策树。

现在让我们更多地讨论分割的概念，并看看它在哪里发生。如前所述，分割直接影响决策树的准确性。这意味着，如果我们在决策树上应用多个算法，它们都会影响数据节点被分成多个子节点的方式。此时，您应该牢记两个决策树类别之间的差异。分割产生的子节点将保持某种形式的一致性。此外，节点分割是在每个变量上执行的，但只有最一致的子节点会被选中。这个过程涉及一些数学知识，我们不会深入细节。理解该过程背后的理论足以开始构建决策树了。话虽如此，让我们看看如何在应用程序中使用它们。

# 第 6 章：机器学习与神经网络

神经网络在20世纪50年代开始出现，作为一种创建计算机系统的新技术，这些系统试图模仿人类的学习过程。请记住，人类神经网络和人工神经网络之间几乎没有联系。不幸的是，人脑仍然过于复杂，无法转化为人工版本。但是，机器学习技术的名称主要用于启发。

神经网络的神经元具有节点，这些节点实际上是一种处理代码形式，旨在重复执行直到找到问题的解决方案。当解决方案已知时，结果会被发送到同一层中的下一个节点。当某一层中的所有节点都完成处理后，最后一个节点会将结果传递给下一层的第一个节点。人类神经网络确实存在许多相似之处，然而，它还能够在同一时间在每一层的所有节点之间建立实时通信。这就是使人脑真正特殊和强大的原因，也是它至今仍无法被复制的原因。其背后的概念称为并行处理。在人工神经网络中，处理是线性的，从一个节点到下一个节点。

神经网络不是一种特定的机器学习算法。相反，它是机器学习的一个子领域，包含试图模拟人类思维处理某些方面的系统。神经网络通过节点网络传输信息。一旦信息被分析和分类，就会被传递到相邻节点。一旦到达那里，将进行另一轮分析和分类，循环重复。请注意，神经网络由若干层组成。通常结构包含输入层和输出层。神经网络最基本的形式甚至可以只有一层，然而，这是一种相当原始的模型，在实践中从不使用。此外，在这两个层之间，我们有若干个隐藏层，从零到你需要的任意多层不等。这些层处理从输入层发送的数据。请记住，标准网络包含三层，而拥有数百层的网络被称为深度学习系统。

在本章中，我们将重点介绍经典的前馈神经网络，以及循环神经网络。

## 前馈神经网络

这是最基本的神经网络类型。数据以线性方式传输，且只能单向传递。它从输入层传递到隐藏层，最后到输出层。就是这样。这种网络甚至不像更现代的系统那样对数据进行迭代。一旦过程结束，就结束了。数据不会循环。一旦操作完成，我们就得到结果。然而，前馈网络有两种类型。

第一种称为单层感知器，这是最基础的形式。只有一层，数据从第一个节点线性传递到最后一个节点。当输入通过一个节点时，它会被加权，如果下一个节点确定权重超过最小限制，它将被激活或去激活。

另一方面，多层感知器至少需要两层，尽管实际上它包含两层以上。数据传输仍然是线性的，然而，前一层的输出变成当前层的输入。请注意，当涉及两层以上时，这种神经网络通常会使用反向传播的概念。这意味着实际输出将与预期输出进行比较。然后计算两者之间的差异并确定误差程度。然后将此误差值发送到整个神经网络中，以便在再次通过所有节点时对其进行调整。这些调整将导致更接近的结果，然后重复该过程，直到结果尽可能准确匹配。请记住，根据层数的多少，可能需要进行大量迭代才能建立满意状态。此外，利用反向传播的多层感知器已不能再被称为真正的前馈神经网络。它们成为多层网络，可能是整个机器学习领域中最强大、最通用的算法之一。

## 循环神经网络

要理解循环神经网络，首先需要理解序列建模的概念。请记住，机器学习通常应用于序列，当我们这样做时，通常会将输入序列转换为输出序列。例如，你可能希望将各种声压的序列转换为单词序列。这意味着当我们没有特定的目标序列时，可以尝试使用教学信号来预测输入序列中的下一个单词。然后输出序列变成带有额外步骤的输入序列。这是一个相当自然的过程，在这种情况下非常合理。然而，当将同样的原理应用于图像时可能会出现问题。想象一下，使用你已经知道的图像的另一部分来预测图像的一部分。预测一个简单术语将同时使用有监督和无监督机器学习，从而消除它们之间的任何障碍。然而，特别之处在于，这两种技术都可以使用，但不需要两种不同的教学信号。

被认为没有内存的模型最适合这项任务。更准确地说，我们指的是自回归模型，因为它们可以使用所谓的延迟抽头基于先前已知的单词来预测下一个单词。一般来说，至少带有一个具有隐藏单元的层的前馈神经网络被认为是自回归的。然而，如果我们将某种隐藏状态引入生成模型，我们将获得一个可以在隐藏状态中存储信息的新模型。

牢记所有这些，让我们回到循环神经网络这个话题。本质上，它们是感知器。然而，请记住感知器具有特定状态。循环神经网络在各个传递之间创建连接，并且由于两个功能的组合而更加强大。首先，它们保持分布式隐藏状态，因此可以存储更多可以稍后传递的信息。其次，隐藏状态可以由于非线性动态而更新。换句话说，只要循环神经网络有足够的时间和足够数量的神经元，它就可以计算任何事情，前提是计算机能够处理。这种网络能够做很多事情，因为它有能力实现许多组件，每个组件都旨在包含一些数据。然后这些组件可以同时运行和交互，以执行复杂操作。

然而，循环神经网络有一个缺点，即消失梯度问题。在足够长的时间段内，信息最终可能会丢失。请注意，在这种情况下，信息指的是权重，这意味着只丢失过去的信息，而不是当前的神经元状态。例如，如果权重达到零或一百万的值，以前的状态将被消除。

总之，我们可以确定循环神经网络被广泛应用于许多领域，因为它们本质上提供了自动补全缺失信息的能力。

## 卷积神经网络

最后，我们有卷积神经网络，它出现在20世纪90年代末，当时有人想出了一种识别手写数字的方法。这个新概念依赖于带有反向传播和大量隐藏层的前馈网络。这些层


包含了大量存储复制单元的特征图，以及它们的输出池化和一个能够同时处理多个字符的大型网络。如此一来，一个新的训练系统应运而生。

卷积神经网络与我们之前讨论的另外两种类型没有太多共同之处，因为它们主要用于图像和音频处理。例如，如果你使用卷积神经网络，可以根据输入网络的图像对信息进行分类。本质上，它会带有一定重叠度地一次扫描图像中的若干像素。例如，如果你有一个尺寸为 1000 x 1000 像素的图像，你只会使用 10 x 10 的一小部分来发送到神经网络。分析完该部分后，你只需向右移动一个像素，即可发送另一个 10 x 10 的部分，从而产生大量重叠。

下一步是将输入数据通过多个卷积层而非普通层进行传输。区别在于神经节点之间没有相互连接。每个节点只会与其邻域内的单元进行通信。此外，卷积层有时还涉及池化层。池化的概念是关于移除不必要的细节。例如，如果你有一个红色的 2 x 2 像素区域，只有红度量最高的像素会被保留，其余像素将被丢弃。
