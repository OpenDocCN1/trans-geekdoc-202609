## 第 3 章：环境设置

在本章中，你将了解如何为机器学习需求设置合适的环境。请记住，虽然你真正需要的只是 Python，但如果没有任何其他工具，使用机器学习算法和技术将极其困难。这就是为什么在本章中，你将构建自己的机器学习工具包，其中包括 Python 库、模块、包、科学发行版等。

你将学习如何借助 NumPy、Pandas、Jupyter 等模块创建最佳环境，以及如何使用 Scikit-learn 和 TensorFlow 等工具大幅提高生产力。

### Python 发行版

在深入之前，你应该准备好工作环境，以便更轻松地进行数据预处理和分析。如果没有合适的工具，处理算法、大型数据集甚至编程本身都会非常耗时。

安装 Python 以及各种库和模块当然能为你提供所需的灵活性和功能，但还有一个更高效的入门方式。答案是 Python 科学发行版。这些发行版是将 Python 安装程序与机器学习者和数据科学家处理数据集和特定算法所需的许多工具打包在一起的。

最流行的科学发行版之一是 Anaconda，我们将在下一节中简要讨论它。不过，请记住，它只是包含机器学习所需模块和工具的众多发行版中的一个。你可以在学习过程中随时探索，以找到适合自己需求的发行版。

### Anaconda

Anaconda 是一个开源的 Python 科学发行版，因其包含的众多有用软件包和库以及它是一款任何人都可以免费使用的应用程序而越来越受欢迎。Anaconda 自带近 200 个 Python 软件包，其中包括 NumPy、Scikit-learn 和 Pandas 等最有价值的软件包。此外，Anaconda 也是一个软件包管理应用程序，使任何软件包或工具的导入和安装变得轻而易举。你可以下载、安装或移除所需的任何内容，并且可以单击按钮使所有内容保持最新。如果你更喜欢使用虚拟环境而不是直接在系统上操作，还可以设置虚拟环境。

Anaconda 可以下载并安装为基本版或高级版。请记住，对于大多数项目，免费版已经足够。它包含了数据预处理、探索或分析所需的所有内容。此外，它适用于所有计算机系统，因此你在将项目从一个系统移动到另一个系统时不应该遇到任何问题。

要使用 Anaconda 安装或更新任何内容，你需要了解一组命令。你最好查看该发行版的在线文档，以熟悉其所有功能。现在，让我们过一遍一些基本命令来帮助你入门。以下是安装 Python 软件包的方法：

```
conda install <my_package>
```

删除或卸载软件包的语法相同，只需将“install”替换为相应的关键字。此外，你可以一次安装、更新或删除多个软件包，而无需一个一个来。具体操作如下：

```
conda install <my_package1> <my_package2> <my_package3> <my_package233>
```

至于更新软件包，你可能希望让已安装的所有软件包保持最新，但如果必须逐个输入每个软件包的名称，这可能是一项繁琐的操作。以下是如何一次性更新所有内容：

```
conda update --all
```

各种科学发行版中包含的大多数软件包管理器的工作原理相同。如果你出于某些原因不想使用 Anaconda，可以将本节学到的所有内容应用到任何其他应用程序中。即使语法通常也相同。

### Python 工具包

没有多个模块和库，任何机器学习工具包都不完整。Python 是该领域的首选语言，因为扩展其功能并将其发挥到极限非常容易。使用多种工具准备工作环境与机器学习任务本身同样重要。

在本节中，我们将重点介绍一些专门用于机器学习领域的模块和工具。其中一些包含在许多科学发行版中，但你需要了解它们，以便知道导入什么。一些最重要的工具包括 Scikit-learn、Pandas、NumPy 和 Tensorflow 等。让我们简要讨论一下你将要使用的模块和库，然后更详细地探索 Tensorflow 等工具：

- 1. Pandas：这是一个专为 Python 设计的库，旨在用于分析和操作数据。它的显著特点在于提供了处理数值表格和时间序列的功能。
- 2. NumPy：这是另一个用于 Python 的库，因为它通过提供处理大型多维矩阵的能力来扩展该编程语言。此外，它还提供了可用于这些矩阵的多种操作和函数。
- 3. Scikit-learn：这个机器学习库是你工具包的核心。它包含了你将要使用的所有机器学习算法，例如 k-均值聚类、支持向量机、随机森林、梯度提升等。此外，Scikit-learn 设计为与 NumPy 库完全集成。
- 4. Matplotlib：这是一个开源的 Python 库，旨在为编程语言（以及 NumPy 模块）添加绘图功能。该工具用于可视化目的，允许你从特定数据（如数组）中创建图表。此外，创建图表后，你可以在同一环境中直接与之交互，而无需切换到其他应用程序。

无论你是机器学习初学者还是专业人士，这些库都被认为是必备的。它们都是开源的，且可以轻松获得，周围拥有庞大的支持社区。此外，它们文档完善，已被广泛用于处理真实世界数据集。这使你能够研究其他机器学习者，并了解他们如何为各种项目应用这些工具。永远不要低估流行产品的力量。即使外面有更好的付费产品，但如果它们只被少数人使用，你也应该坚持使用被视为标准的工具。这样一来，你始终可以获得大量资源，因为毫无疑问你经常会需要它们。
