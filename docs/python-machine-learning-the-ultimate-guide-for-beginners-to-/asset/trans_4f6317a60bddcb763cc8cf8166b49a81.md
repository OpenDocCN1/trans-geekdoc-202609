## 热门机器学习方法

既然你了解了机器学习为何成为你生活的一部分，你就需要了解它是如何能够学习的。

一般而言，主要有两种机器学习技术，即监督学习和无监督学习。机器学习中大约有百分之七十实际上是监督学习。另外百分之十到百分之二十是无监督学习。还有其他技术，如半监督学习和强化学习，但它们使用得不那么频繁。以下是这些技术所能实现的简要介绍：

- 1. 监督学习：只有在能够识别输入和输出且有标记数据可供使用时，才能实现这种机器学习方法。算法将获取其输入及其匹配的输出，以检测错误。根据输入，模型将进行调整。整个过程实际上是模式识别，这些算法始终依赖于回归、分类、预测或梯度提升等技术。请记住，你还将需要处理未标记的数据，而模式识别正是用来填补这些空白的。一旦建立了模式，算法就可以预测标签的值。监督机器学习通常用于需要预测未来的应用程序。例如，查找信用卡交易欺诈。

- 2. 无监督学习：监督学习涉及使用历史数据来预测未来事件，但无监督学习并非如此。这种类型的算法分析收集到的数据以确定其结构。这就是为什么无监督学习被用于理解没有任何突出属性的客户类别，或者为你提供在线推荐。一些最流行的无监督机器学习技术包括最近邻和K-Means聚类。

### 数字

在Python中，与数学中的情况一样，你有几类数字可供使用，并且在将它们用于代码时，必须指定你所指的是哪一类。例如，有整数、浮点数、长整数等。但是，最常用的是整数和浮点数。

整数，缩写为int，是可以是正数或负数的整数。所以，请确保在将数字声明为整数时不要输入浮点数。浮点数是小数或分数。

现在让我们讨论数学运算符。就像在小学时一样，你经常会使用加法、减法、乘法等基本数学运算符。请记住，这些与比较运算符不同，例如大于、小于或等于。现在让我们看看代码中的一些示例：

```
x = 99
y = 26
print (x + y)
```

这个基本操作简单地打印x和y的和。无论你的计算有多复杂，都可以使用此语法进行所有其他数学运算。现在让我们改用比较运算符输入命令：

```
x = 99
y = 26
print (x > 100)
```

如你所见，语法相同，但我们并没有进行计算。相反，我们正在验证x的值是否大于100。你将得到的结果是"false"，因为99不大于100。

## 字符串

字符串与文本有关，无论是字母、数字还是标点符号。但是，请注意，写为字符串的数字与数字数据类型不同。任何东西都可以定义为字符串，但要做到这一点，你需要在声明前后加上引号。让我们来看看语法：

```
n = "20"
x = 10
```

请注意，我们的n变量是字符串数据类型而不是数字，而x被定义为整数，因为它没有引号。你可以在字符串上执行许多操作。例如，你可以验证字符串的长度，或者连接多个字符串。让我们使用以下函数来看看单词“hello”中有多少个字符：

```
len ("Hello")
```

“len”函数用于确定字符数，在这里是五个。以下是字符串连接的示例。你会注意到它看起来类似于数学运算，但处理的是文本：

```
'42 ' + 'is ' + 'the ' + 'answer'
```

结果将是“42 is the answer”。请注意语法，因为你会发现我们在每个字符串后都留了一个空格，除了最后一个。编写字符串时会考虑空格。如果我们没有添加它们，所有字符串都会被连接成一个单词。

另一个流行的操作是字符串迭代。这是一个示例：

```
bookTitle = "Lord of the Rings"
for x in bookTitle: print(x)
```
