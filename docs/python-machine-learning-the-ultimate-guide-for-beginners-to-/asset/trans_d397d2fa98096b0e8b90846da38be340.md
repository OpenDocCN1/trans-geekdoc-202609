## 简介

机器学习是一个相当新的领域，但它迅速成为每个 IT 专家都试图跟进的最新趋势，这也是情理之中。这个技术领域可以用于解决当今各种各样的问题。*Python 机器学习*的目的是引导你逐步了解机器学习的所有基本概念。

在阅读本书的过程中，你将了解旅途中所需的所有专业工具。此外，你将通过结合理论与实践，学习各种机器学习算法和技术。你将在真实数据集上应用所学的一切，并掌握所学每个概念的实际用途。

请记住，为了从这本初学者终极指南中获益最大，你必须逐一研究每个实际应用，并将其拆解直到理解。此外，你还需要亲自动手练习，以打下坚实的基础。你不必是计算机科学专业的学生才能理解机器学习，但你确实需要大量的决心，最重要的是，实践！

## 第 1 章：为什么要学习机器学习？

所以你对 IT、编程或所有与技术相关的事情感兴趣，并且最近你不断听说机器学习。无论你转向哪个方向去探索新事物，这个概念都不断出现。到这个时候，你大概会期待一个穿着风衣的可疑家伙在黑暗的小巷里走近你，问你：“嘿，小子，对机器学习感兴趣吗？”你可能认为，既然每个会写几行 Python 代码的人都在谈论它，这里肯定有值得学习的东西。那么，什么是机器学习，为什么每个人都对它如此疯狂？

在本章中，我们将解答这些问题以及更多问题。理解为什么机器学习是如此热门的话题，以及为什么许多人将其视为技术的未来非常重要。你已经迈出了探索这个领域的第一步，但如果你能更好地了解机器学习的应用，你肯定会更有动力去学习和掌握它。

### 机器学习的重要性

机器学习最初是人工智能的一个组成部分，因此其定义在某种程度上与人工智能相关。本质上，机器学习软件从经验中学习，几乎就像人类一样。请记住，在这里经验是指数据，而学习能力不涉及直接编程。当机器学习应用程序接触到数据时，它会吸收数据，从中学习，根据数据调整自身并进化。换句话说，由机器学习驱动的系统不需要有人来指导如何搜索某物以及在哪里找到它。相反，它依靠自己的算法从数据中学习，然后应用所学知识以表现得更好并重复这个循环。明白了吗？它几乎像人类，但不，这不属于科幻领域。机器学习已经存在相当长一段时间，并且在研究和产品设计中正日益成为行业标准。

事实上，机器学习的理念至少和恩尼格玛机一样悠久，但只有在过去几十年里，由于计算机处理能力的巨大飞跃，它才能够执行大量完全自动化的数学运算。此外，近年来开发了许多新技术，而这些技术最充分地利用了机器学习。

要更好地理解机器学习为什么如此重要，你需要知道它实际上应用在哪里。你知道谷歌的全自动自动驾驶汽车吗？你要感谢机器学习。你使用 Facebook、Amazon 或 Netflix 吗？当然、当然、当然，它们都依赖机器学习来为其向你推荐你可能感兴趣的东西提供动力。这就是它们如何知道你喜欢有趣的猫视频。计算机系统可以通过将你生成的所有数据通过过滤器来学习所有这些信息，只保留与你相关且符合你模式的内容，然后给你甚至你自己都不知道自己在寻找的准确结果。

机器学习似乎进化得如此突然，尽管几个世纪前的伟大数学家（是的，甚至在计算机发明之前）就已经对其进行了理论研究，但这只是因为市场需求及其大众消费的现实世界应用。例如，你可能也曾在同一句话中听说过机器学习和大数据。这是因为它如今非常复杂，使我们能够处理和分析人类无法处理的海量数据。此外，机器学习在我们提取和分析数据的方式上引发了一场革命，因为它使我们能够自动化算法，从而取代曾经常见的缓慢、繁琐的统计方法。
