

# 区块链在各行业的应用

## 网约车行业的变革

目前优步和来福车等网约车公司主导着这一领域；然而，这些公司代表了一个中心化机构或中介，司机通过它们与乘客建立联系。随着采用区块链技术的公司出现，公司将为网约车提供直接的点对点网络。这意味着没有中心化机构控制司机，司机可以自由创建自己的市场空间，并按其认为合适的费率提供服务。这对乘客也有利，因为移除了中介佣金，乘车成本将会降低。一些基于区块链的共享出行应用，如 Arcade City 和 Drive，已经上线。用户也可以在这些应用上通过加密货币进行支付。

## 慈善透明度

如果慈善机构采用区块链来追踪机构内的资金流向，它们处理捐款的方式也将发生改变。这样，捐赠者可以准确追踪捐款的去向，并确认机构未将其挪作他用。这为慈善事业提供了透明度，可能会鼓励更多人捐款，因为许多人不捐款的原因是认为慈善机构腐败。多家公司正在该领域耕耘，例如比特币慈善机构 Bitgive Foundation，以及拥有全球慈善交易永久记录的基于区块链的捐赠平台 Givetrack。

# 产生影响的知名区块链公司

## 领先的加密货币

### 比特币

比特币是最初的加密货币，也是首个商业化使用区块链技术的工具。它始于 2008 年。比特币是一个点对点支付网络，通过它你可以在没有任何中央银行或权威机构的情况下向他人付款。比特币利用其底层的区块链技术来管理和记录交易。比特币在大众中普及了加密货币的概念，目前市值约为 9500 亿美元。

### 以太坊

以太坊是最著名的区块链公司之一，因引入智能合约概念而闻名。以太坊在金融服务领域运作，允许个人通过互联网进行借贷、借款和储蓄产品操作。它还运行以太币，这是按市值计算的第二大加密货币。以太坊让人们能够通过其智能合约进行操作。

## 其他知名区块链公司

### Chorus One

Chorus One 是一个由雄心勃勃、善于自省的人组成的社区，致力于为去中心化网络构建高可靠性基础设施。他们相信加密经济学和去中心化网络将实现全球规模的协作，并推动人类进化的下一阶段。Chorus One 正在为去中心化网络构建验证节点和跨链通信，使用户能够赚取更多代币并塑造新兴的开放金融系统。他们的工作处于金融服务和加密货币的交汇点。通过 Chorus One 一流的验证和质押服务，体验权益证明区块链网络的力量。

Chorus One 获得了 Celo 基金会和 Interchain 基金会的资助，用于开发跨区块链通信（IBC）模块的关键构建模块。该模块将实现 Celo 区块链与其他基于 Cosmos SDK 构建的网络之间的无缝通信。

通过我们的权益证明网络体验终极区块链安全，验证者是保障您平台安全的关键。区块链项目寻求能够运行验证节点的可靠验证者。通过我们可靠的验证节点质押您的资金，体验质押的力量。通过增加质押量和保障区块链安全，最大化您作为验证节点的收益。

### Sciencesoft

Sciencesoft 成立于 1989 年，服务于非 IT 企业和软件产品公司，经常受托进行 CRM、数据分析、协作与知识管理以及信息安全方面的定制和平台化开发。该公司还提供端到端的区块链软件和应用程序开发。客户包括中大型国际组织，如沃尔玛、IBM、雀巢、eBay 和 NASA JPL。

### Ripple Labs

Ripple Labs 成立于 2012 年，与客户现有的金融系统合作，以改进和简化其基础设施。该公司提供开源代码和开发工具以推动区块链技术的发展，是唯一一家拥有商用产品的企业级区块链公司。

### R3

R3 在为全球银行提供分布式账本技术方面发挥着重要作用。它最近甚至与瑞士央行合作，用于银行间大额加密货币交易的结算。

### Pledgecamp

Pledgecamp 是一个众筹平台。它利用区块链的交易历史和追踪功能，让众筹项目的支持者或投资者能够了解他们投入项目的资金花在何处。在这个平台上，资金会转入托管账户并缓慢释放给公司，记录始终透明地向支持者公开。

### Binance

Binance 目前是世界上最大的加密货币交易所之一。加密货币不在传统证券交易所上市，只能通过加密货币交易进行买卖。加密货币交易所通常会对其平台上的每笔交易收取少量手续费。

### Zweispace

Zweispace 是一家日本公司，开发了基于区块链的遗嘱和继承自动结算程序。在确认受托人去世后，死者的资产会自动传递给受益人，从而避免了遗嘱生效后通常漫长的法庭争夺。

### Republic

Republic 是一个基于区块链技术的投资平台。人们可以通过该平台投资房地产、初创公司甚至加密货币。Republic 是一个安全的平台，只有非常特定的公司才有资格上市；因此，人们可以对通过 Republic 进行的投资感到放心。

### SALT

SALT 是一个区块链平台，充当加密货币与现实世界之间的桥梁。用户可以在 SALT 上利用其加密资产获得法币贷款。借款人最长可贷 3 年。

### Drife

Drife 是一款印度网约车应用，目前仅在班加罗尔市运营。它是一款基于区块链的应用，为司机和乘客提供点对点平台，让他们自行决定服务类型和价格。这意味着应用不从每单车费中抽取佣金。不过，乘客必须支付年度费用以使用该应用。

### Winding Tree

Winding Tree 通过提供去中心化的旅行预订平台，帮助酒店和航空公司。这减少了中介赚取的佣金，并直接将客户与服务提供商连接起来。Winding Tree 已与汉莎航空、法航和加拿大航空等航空公司合作。

### Propy

Propy 是一家在房地产领域运营的基于区块链的公司。它利用区块链下创建的智能合约来处理房地产的购买、销售和租赁。房地产经纪人可以用它来简化流程，使交易更容易完成，并缩短每笔交易的时间。这也有助于提供更友好的客户体验。
