

# Chainlink (LINK)

Chainlink (LINK) 是一种加密货币区块链网络，它在现实世界数据和智能合约之间提供连接。该平台有助于执行智能合约，智能合约是区块链协议，在满足必要的先决条件后会自动完成。它提供一种名为 LINK 的可交易加密货币代币，用于支付 Chainlink 网络上的创新合约交易。与法币相比，LINK 代币也能保持其价值。

Chainlink 由创始人 Sergey Nazarov 于 2014 年创建，于 2017 年推出，他是一位在加密货币市场具有重要影响力的 32 岁企业家。最初，Chainlink 网络被设计为一个中心化的预言机系统，用于验证传入的信息。然而，它此后已转型为一个去中心化的预言机网络，该网络与智能合约配对，利用外部数据源和 API 来保障交易安全。

Chainlink 有助于弥合发送现实世界数据的预言机与区块链上的智能合约之间的鸿沟。Chainlink 在仅从最值得信任的节点和预言机获取数据的同时，可以生成多个子合约，以最大化准确性。尽管平台可处理的智能合约数量没有限制，但 LINK 代币的总供应量上限为 10 亿枚。Chainlink 网络是一个相对开放的系统。任何人都可以加入，向网络提供数据，或协助运营其相应的节点和预言机。这些运营商以 LINK 代币获得报酬，LINK 是 Chainlink 网络的原生货币。

随着区块链技术的日益普及，Chainlink 等网络可以补充创新合约的实施，充当以太坊等主流区块链的替代方案。

# Polkadot (DOT)

Polkadot (DOT) 是一个旨在“连接所有其他网络”的网络。与比特币等独立运行的网络不同，Polkadot 可以链接多个网络。

其最终目标是作为一个标准化的集成框架，供所有选择使用其技术的区块链使用。其理念是处理复杂且昂贵的加密货币挖矿过程，包括交易验证和安全协议，使开发者能够专注于创建高效的 dApps 和智能合约功能。以太坊联合创始人 Gavin Wood 构建了 Polkadot。

构建创新去中心化系统的开发者必须从头开始设计这些系统，包括区块链本身。这意味着时间、人才和资源被分流到构建竞争性网络上，而不是创建一个所有人都可基于此构建的标准。这就是 Polkadot 的目标，为开发者铺平道路，让他们在所有区块链之上构建价值，而不仅仅是一条链。

区块链可以连接到 Polkadot，并作为“平行链”并行工作，以访问网络的权益证明验证系统进行交易和安全保障。在网络的“中继链”中，会检查交易地址并标准化数据，以便每个参与系统都能理解。

在功能得到保障的同时，连接到 Polkadot 的区块链可以使用其 PoS 机制来决定何时以及如何更新其代码，并运行它们首选的 dApps 或代币。Polkadot 是一个“即插即用”的层，允许网络在保持安全性完整的同时，同时引入新协议。基于区块链的系统必须解决的两个基本问题是可扩展性——网络每秒能处理的交易数量——和治理：系统如何管理协议升级和变更。Polkadot 旨在高效解决这两个问题。

DOT 是 Polkadot 网络的原生代币，允许持有者对潜在的代码变更进行投票，如果达成共识，这些变更将自动在整个网络中升级。Polkadot 于 2020 年初推出主网，并迅速在投资者、开发者和加密货币交易者中获得关注。

在不到一年的时间里，它已经取得了几项令人印象深刻的成就和发展，包括：

- 晋升为第四大加密货币，市值峰值接近 180 亿美元。
- 经历重新面值，这是一个将旧 DOT 代币拆分 100 倍以产生新 DOT 代币的过程——将供应量从 1000 万增加到 10 亿。
- 开发者活动大幅激增，目前已有超过 350 个项目正在该平台上积极开发。

随着区块链技术渗透到传统商业模式和用例中，我们可以预期更多开发者将加入智能合约和 dApps 的世界；Polkadot 提出的框架模型在这种情况下将至关重要，因为开发者需要更专注于创建强大的智能合约和 dApps，而不是花费时间从头构建区块链。

# 山寨币市场的未来

随着比特币价格的天文数字般飙升，山寨币已成为新投资者的可行投资选择，因为这些加密货币价格相对合理；因此它们被购买得更多。

当今加密货币市场上的大多数交易者都是小型散户投资者，他们无法买卖比特币，因为这需要拥有足够的资金，所以他们自然会交易山寨币。

山寨币通常比比特币便宜，且以更优惠的价格提供给用户。此外，与比特币相比，这些币种具有更好的未来增长潜力。如果能通过适当的研究识别出区块链项目及其可扩展增长的潜力，此类山寨币可能成为绝佳的投资机会，能在短时间内产生数倍回报。以太坊就是这种山寨币的一个例子，它奖励了早期识别出其潜力的投资者。

加密货币代表了一个由技术驱动的新市场时代的开始，最终将颠覆传统的市场策略、长期的商业方法和传统的监管政策。加密货币具有开创性的潜力，能让其用户接入全球支付系统，参与门槛仅取决于互联网的可用性或加密钱包的拥有权，而非拥有银行账户等因素。

# 第 5 章：去中心化金融

## 什么是 DeFi？

自 2017 年诞生以来，去中心化金融（简称 DeFi）以旋风之势席卷全球。该术语的基本构成表明其涉及金融和去中心化。虽然“金融”不言自明，但“去中心化”是一个描述性术语，需要额外阐述以利于理解。这里的“去中心化”强调该系统不受任何主管机构（如银行）的控制；换句话说，它不是中心化的。它处于金融服务与技术的十字路口。

DeFi 以如此高效的方式融合了这两个领域，从而消除了对经纪人或银行等中介机构的需求。与中介机构处理金融的方式相比，DeFi 不需要账户、政府签发的身份证、地址证明等。换句话说，DeFi 允许供应商、贷方、借方等进行货币交易，非常像银行，但没有银行等中心化权威的实际参与。这是一个麻烦少得多的金融系统，不要求服务寻求者经历生成银行流水、出具大量文件等繁琐流程。
