

# NFT：用例与购买指南

## 赋能艺术家

然而，不仅仅是 Beeple 等知名艺术家从 NFT 中获利。即使是小众艺术家也可以将他们的艺术品转化为 NFT，从而实现作品变现。此外，利用智能合约，艺术家还可以在 NFT 中附加条款，规定每次 NFT 转手时都能获得一定比例的售价，以保障其经济利益，防止作品日后升值却无法分享收益。NFT 还将消除艺术家与艺术品收藏家之间对中介和其他中间商的需求。NFT 最终能让数字艺术世界与实体艺术世界站在同一起跑线上。

## 身份识别

非同质化代币也被用于提供身份证明。NFT 可以被编程以包含唯一信息，同时我们知道 NFT 在同一时间只能有一个所有者，且 NFT 内部的数据不可篡改；因此，NFT 可以被配置为用于颁发身份、许可证、资质等。例如，假设某人将获得一张俱乐部会员身份证。在这种情况下，该卡的数字版本可以配置 NFT，以确保入场时出示的是原版卡片。万一发生身份盗窃，即使罪犯能够复制身份证件，他们也无法复制附加在这些卡片上的 NFT。

## 收藏品

目前 NFT 另一个最常见且流行的用例是收藏品领域。我们知道 NFT 是非同质化且独一无二的代币，意味着每个 NFT 都不相同。收藏品此前在数字形式上是缺失的，因为它们很容易被复制和複製，但这个问题已通过 NFT 得以解决。现在可以创建限量版物品。因此，即使产品被复制，其真实性也无法被证明。这在所述物品的所有权上创造了一种排他性。一些利用 NFT 生成的收藏品包括：

### 交易卡

多年来，交易卡一直是现实世界中最受追捧的收藏品之一。交易卡类型多样，例如棒球或篮球等体育交易卡，或宝可梦、游戏王等游戏形式的卡片。稀有卡片有时能以数百万美元的价格售出。现在我们看到了《Gods Unchained》等数字交易卡游戏的兴起。

### 头像

CryptoPunks 是最早的 NFT 之一，已成为最受欢迎的 NFT 系列之一。限量版外星人 CryptoPunks 的购买价格经常超过 100 万美元。这些朋克没有内在价值，仅因其稀有性而被收藏。人们可以将它们用作各种平台上的头像或展示图片。

### 原版副本

正如现实世界中漫画书、小说、专辑封面等各种产品的原始文件由收藏家保存且价值数千美元一样，有声书、漫画等的数字原版副本也被收藏家收藏。不仅是书籍，最近甚至连 Twitter 创始人兼 CEO 发布的第一条推文的原版副本也通过 NFT 以 290 万美元的价格售予最高出价者。

### 体育

体育界也开始涉足 NFT 世界。NBA 售出了首个基于体育的 NFT。通过 NBA Top Shot，收藏家可以购买其喜爱的球员在 NBA 比赛中某个精彩瞬间的图片或一连串动作的原版所有权。一级方程式赛车和拳击也都在推出自己的 NFT 收藏系列。

### 域名

也可以购买和收藏域名。域名的所有权存储在 NFT 中。购买和存储名称的常见方式之一是通过以太坊域名服务。

## 金融

尽管 NFT 广为人知是因其表面用途（如艺术、收藏品），但它们也大有裨益。这为 NFT 持有者提供了持有 NFT 本身的价值。例如，如果一个 NFT 允许持有者进入一个独家投资者圈子，该 NFT 就可以因该权利而被交易或出售。持有者还可以质押 NFT 以赚取被动收入。一些 NFT 还兼具折扣券或套餐功能，例如 BAKE 优惠券。这些金融类 NFT 也可以附带艺术品，但其价值来源于其用途，而非其艺术性。

## 音乐与视频

正如可以将 NFT 附加到图片文件或 GIF 上一样，也可以将 NFT 关联到音频和视频文件。通过将 NFT 与音频文件或专辑关联，音乐人和视频制作者可以开始销售其产品的原版。仅仅因为某人持有某首歌或视频的 NFT，并不意味着他们拥有其版权。版权仍归艺术家所有。目前，唱片公司和其他中介从歌曲和音乐视频中获利；使用 NFT 将减少对这些第三方的需求，从而增加音乐人的收入。Kings of Leon 是首个发行数字专辑版本的大型摇滚乐队；每张专辑副本都通过 NFT 进行了唯一编号。

## 现实世界资产

现实世界资产，如股份、契约、合同等，也可以使用 NFT。伪造和欺诈在实体形式中司空见惯。然而，如果这些资产被赋予适当的 NFT，区块链技术就能证明其真实性。2021 年，有人创建了一个包含加利福尼亚州一处房产所有权的 NFT。谁拥有该 NFT，谁就拥有该房产的所有权。它还有助于证明珠宝等贵重物品的所有权。

## 高级时尚

高级时尚是 NFT 的另一个潜在用例。大多数奢侈时尚单品除其所有权提供的身份认同和排他性外别无他用。这使其成为 NFT 非常合乎逻辑的用例。人们可以购买数字时尚产品，如数字运动鞋或太阳镜，这些产品通过 NFT 进行认证。大型时装屋已经开始生产基于 NFT 的数字产品。Overpriced 推出的一款奢华虚拟连帽衫以 1.9 万英镑的价格售出。

## 许可授权

NFT 在软件许可领域大有可为。首先，它们将降低行业内的盗版率，因为当所有权详情存储在 NFT 上时，伪造变得极其困难。其次，NFT 允许人们将许可证直接出售给需要的人。因此，人们不会被许可证或长达一年的会员资格所困。他们可以去 NFT 市场将其出售给需要的人。

## 如何安全购买 NFT 及在哪里购买？

非同质化代币与其他加密代币一样，无法在常规证券交易所进行买卖。一些特定的平台和企业专门经营 NFT 业务。其中一些平台是专门为此目的而创建的。购买 NFT 的过程很简单，只需遵循几个步骤即可完成。

### 购买加密货币

购买 NFT 的第一步是购买加密货币。NFT 基于区块链，每条区块链都有其原生加密货币。购买 NFT 必须使用区块链原生加密货币支付相应价值。无法直接使用法币购买 NFT。必须先将其兑换为加密货币。如果想要获取基于以太坊区块链的 NFT，必须购买以太币；如果是基于 BNB 智能链的 NFT，则必须购买 BNB。加密货币可以在各种加密货币交易所购买，如 Binance、Coinbase 等。

### 将加密货币转入钱包

下一步是将你的以太币或其他加密货币转入钱包，如 MetaMask。这些钱包存储加密货币的访问权限，并提供防黑客安全保护。如果在同一条区块链上购买（例如在 Binance 上购买），也可以直接使用交易所内的加密货币支付 NFT 费用。
