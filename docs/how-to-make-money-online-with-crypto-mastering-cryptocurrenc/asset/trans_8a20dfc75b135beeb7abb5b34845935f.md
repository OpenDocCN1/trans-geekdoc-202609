

# NFT 与加密货币：关键差异

## 成本
NFT 和加密货币的成本或价格差异巨大。当我们谈论加密货币时，最流行且最昂贵的加密货币是 `Bitcoin`。在 2021 年的牛市期间，`Bitcoin` 达到的峰值价格略高于 64,000 美元。然而，与人们为某些 NFT 支付的价格相比，这显得微不足道。人们经常为 NFT 支付高达数百万美元，最昂贵的 NFT 在 2021 年 3 月的一次拍卖中以约 6,900 万美元成交。

## 可分割性
NFT 和加密货币的另一个区别在于它们能否被分割成更小的部分。加密货币可以被拆分成更小的片段，这些片段可以进一步细分。这对于像 `Bitcoin` 这样昂贵的加密货币至关重要，以便人们可以按较小的数量购买。NFT 始终作为一个整体存在，它们就像艺术品。它们无法被拆分、交易、收集和重组。

## 使用的区块链
两者使用的区块链也不同。对于加密货币，几乎每一种加密货币都运行在其自己的区块链上，该链存储该货币的交易。例如，`Ether` 的交易记录在 `Ethereum` 上。而 NFT 通常运行在 `Ethereum` 区块链上；其中一些也在 `Binance Smart Chain` 上。这是 NFT 最常用的两条区块链。

## 购买平台
两者的交易平台也不同。同时，加密货币在加密货币交易所交易，例如 `Binance` 和 `Coinbase`。这些加密货币交易所可以是中心化的，也可以是去中心化的。NFT 在 NFT 平台上买卖，如 `OpenSea` 和 `Nifty Gateway`。同时，NFT 也通过拍卖行出售，例如 `Sotheby's` 和 `Christie's`。

## 接受的货币
可用于购买两者的货币也不同。谈到加密货币时，人们可以用法币或其他加密货币支付，具体取决于其加密货币交易所。因此我们看到加密货币很容易兑换成现实世界的货币。另一方面，购买 NFT 只能用加密货币支付。如果 NFT 基于 `Ethereum` 区块链，则用 `Ethers (ETH)` 支付；如果在 `Binance Smart Chain` 上，则用 `Binance coins (BNB)` 支付。

## 时间线
两者出现的时间线也截然不同。加密货币最早创建于 2008 年，第一个是 `Bitcoin`。加密货币在 2010 年代中期至后期进入主流视野，首次牛市在 2017 年，第二次在 2021 年初。另一方面，第一个 NFT 于 2016 年推出；由于 `CryptoKitties` 和 `CryptoPunks`，它在 2017 年略微走红，但直到 2021 年 NFT 市场最终爆发时，才真正进入主流。

# NFT 的运作原理

## 创建 NFT
创建 NFT 相对容易；各种平台允许人们制作 NFT。要制作非同质化代币，需要两样东西：将被转换为非同质化代币的数字艺术品或资产，以及铸造的费用。最近，许多东西已被转换为非同质化代币，包括数字艺术、歌曲、视频，甚至推文；任何具有数字形式或签名的东西都可以转换为 NFT。创建后，所有者可以在钱包中查看 NFT，就像查看加密货币一样。这些 NFT 同样存在于区块链上的地址中，持有密钥的人可以访问。

## NFT 标准
在 NFT 的铸造过程中，NFT 的所有者或创作者执行符合不同 NFT 标准的代码。NFT 使用以下标准和协议：

### `ERC-721`
`ERC-721` 是 2017 年为创建 NFT 而开发的原始标准。它是用 `Solidity` 编写在 `Ethereum` 区块链上的。该标准使铸造新 NFT 变得更容易、更快捷且无重复。`ERC-721` 是最常用的标准；任何人都可以创建自己的 NFT。

### `ERC-1155`
`ERC-1155` 是 `Ethereum` 区块链上的另一个标准。它在 `ERC-721` 之后开发，被认为是对前者的升级。该标准通过以某种方式执行智能合约来创建新的非同质化代币。`ERC-1155` 相对于 `ERC-721` 的一个显著优势是，可以在单个智能合约上创建多个 NFT。在 `ERC-721` 上，每次创建新 NFT 都必须运行一次智能合约。`ERC-1155` 更高效，占用存储空间更少，但也更多样化，因为它可以制作同质化代币和非同质化代币。

### Hedera 代币服务
这是一个非基于 `Ethereum` 的标准，由 `Hedera` 提供。这比 `Ethereum` 标准便宜得多，速度也更快。`Infinite by SUKU` 是一家已从 `Ethereum` 转移到 `Hedera` 的公司。

## 部分化 NFT
目前我们看到 NFT 具有专有性且由单一所有者持有。计划很快推出部分化 NFT 标准，允许多个用户拥有单个 NFT 的一部分。这将与区块链普遍的去中心化和多节点特性保持一致。

# NFT 用例

NFT 可用于各个领域。其中一些用例包括：

## 游戏
非同质化代币主要用于在线游戏，在游戏领域得到广泛应用。最早的一些 NFT，如 `CryptoKitties`，就是建立在区块链上的游戏。NFT 在游戏中主要有两种用途：要么 NFT 的收集和存储本身就是一种游戏，人们试图获取 NFT，在游戏中将其转化为其他东西，然后尝试赢取奖励，如 `CryptoKitties` 或 `Alchemy Toys` 的情况。相反，NFT 也可能作为其他游戏的附属品使用。这些可以是装饰性的（皮肤、头像、头盔等）和实用性的（武器、宠物等）。

在大型多人在线角色扮演游戏中，人们可以使用 NFT 拥有特定的游戏内物品，赋予他们独家使用权。游戏行业是世界上增长最快的行业之一。随着移动游戏的增加和互联网在以前未开发地区的普及，未来几年将进一步扩张。预计到 2023 年，游戏行业将价值超过 3,000 亿美元。这为 NFT 提供了巨大的市场基础和该领域的潜在增长。

## 数字资产
数字资产市场也是这些代币最重要的用例之一。可以购买仅存在于数字世界中的资产。`Decentraland` 是购买作为 NFT 的数字资产时最常见的名字之一。`Decentraland` 是一个拥有有限且稀缺土地的虚拟世界。潜在买家可以从他人甚至开发者手中购买这块土地。土地价格很大程度上取决于这块“地皮”的位置，就像现实世界一样。游戏中一些黄金地段的数字房地产以数千美元的价格出售。公司计划在这些空间建立他们的数字商店。`Cryptovoxels` 是另一个人们可以购买和出售数字资产的项目。

## 艺术
目前，艺术是 NFT 应用最多的领域。多年来，数字艺术深受易于复制的问题困扰，因此由于缺乏稀缺性，数字艺术的价格无法走高。自从人们开始将数字艺术转换为 NFT 后，这种情况完全改变了。当艺术与 NFT 结合时，所述作品的所有者更容易验证其所有权。这创造了数字艺术的有限供应，导致其价值飙升。过去几年里，我们看到一些数字画作以天价售出，例如 *Everydays: The First 5000 Days*，以 6,900 万美元成交。
