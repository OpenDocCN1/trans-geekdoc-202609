
# NFT 概览

当一个人使用 NFT 购买艺术品时，艺术家或原始所有者会将数字信息和元数据加密并存储到区块链上。这些数据用于证明 NFT 的所有权。此外，由于区块链具有时间戳，甚至可以追溯数字资产的权利，查看其随时间推移何时以及多少次易手。

NFT 可以像其他数字资产一样进行交易；存在 NFT 市场，人们可以前往购买喜欢的代币。没有固定的市场力量决定 NFT 的价格；就像艺术品一样，其价格取决于买家愿意为资产支付多少。NFT 甚至可以被编程，使得每次 NFT 易手时所有者都能获得一定金额，这样即使 NFT 价格暴涨，原始所有者仍能获得补偿。NFT 使用分布式账本技术（如区块链），这意味着转移 NFT 不需要中介或交易所，从而降低了交易成本。

NFT 在全球市场上几乎没有监管，其未来与加密货币和区块链技术紧密相连。例如，如果某个国家禁止加密货币交易，那么该国的 NFT 买卖也将受到限制。

虽然 NFT 越来越受欢迎，但批评声也随之增加。与 NFT 相关的一个重要批评是其碳足迹。世界目前正面临一场气候灾难，部分原因是使用了不可再生和污染环境的能源。我们知道区块链是一个非常耗能的行业。运行负责区块链挖矿的服务器需要电力。创建 NFT 也需要类似的挖矿要求，导致污染和气候变化。一些艺术家在了解 NFT 的环境影响后，退出了 NFT 创作。

# 非同质化代币的特性

非同质化代币具有某些特性，使其能够以这种方式运作。其中一些特性包括：

## 独一无二

每个 NFT 都是独一无二的，即 NFT 无法被复制。与其他加密货币不同，一个 NFT 不等同于另一个 NFT，即使它们价值相同。如果有人交易 NFT，他们手中得到的是不同的东西，而不仅仅是同一事物的另一个副本。

## 不可分割

NFT 也是不可分割的，这意味着 NFT 无法被拆分成价值较低的较小部分，然后出售、回收并重组。NFT 始终作为一个整体进行交易。

## 不可销毁

NFT 的数据存储在区块链上。大多数 NFT 存储在以太坊区块链上。既然我们知道区块链上的数据难以销毁或篡改，尤其是在公共区块链上，那么 NFT 就无法被销毁。

## 绝对所有权

当一个人拥有 NFT 时，他们对该数字资产拥有完全所有权；这不同于购买使用特定图片、歌曲或 GIF 的许可证。这意味着所有者对这些 NFT 拥有不受限制的访问权。

## 可验证

由于关于 NFT 所有权的数据存储在区块链上，且此类数据始终带有时间戳并保证真实性，因此很容易验证和追溯 NFT 的所有权。

## 限量

NFT 数量有限；它们是稀缺的。大多数 NFT 仅单独生产；然而，艺术家可能会拥有有限数量的类似产品，例如 10 个或 50 个，这很像现实生活中制造商推出的限量版服装或汽车。

## 可转让

NFT 是宣示数字资产所有权的数字资产或证书；因此，像任何其他数字资产一样，NFT 可以有偿地从一个人转移给另一个人。

## 永久

存储在区块链上的数据是永恒的；一旦录入，将永远存在。与现实生活中的绘画或艺术形式可能随时间损坏不同，NFT 将是永久的。

# 非同质化代币的历史

非同质化代币的概念始于 2012 年的“彩色币”，它们在比特币区块链上发行。这些彩色币代表汽车、金属、房地产等现实资产的所有权。

非同质化代币于 2014 年由 Kevin Mckoy 首次铸造。他在将 NFT 广泛用于加密艺术之前，创造了第一个名为“Quantum”的非同质化代币。Quantum 是一个八边形物体的像素化图像，会变换形状和颜色。

NFT 在以太坊区块链上推出 CryptoKitties 和 CryptoPunks 后开始引起公众关注。CryptoKitties 是描绘猫咪的非同质化代币，每只猫都有独特的年龄、体型和颜色特征。这意味着没有两只猫是相同的；因此它们作为收藏品在人们之间交易，很像现实生活中的体育卡或宝可梦卡。反之，CryptoPunks 是被转化为 NFT 的头像或个人资料图片，人们可将其用于各种社交媒体平台。同样，每个赛博朋克头像都与其他不同并拥有自身价值。NFT 在加密社区中增长，但在 2021 年迎来了主流爆发。

# 2021 年的 NFT 革命

2021 年，人们对 NFT 的兴趣膨胀至前所未有的高度。虽然这与牛市同步，当时比特币、以太坊甚至狗狗币等加密货币的价格在上半年上涨，但观察到尽管这些加密货币价格在下半年从高点回落，同期非同质化代币的买卖仍持续增长。

2021 年 NFT 市场飞速增长。2021 年上半年，与 2020 年上半年 1370 万美元的销售额相比，NFT 销售额激增至近乎令人难以置信的 25 亿美元。在此期间，我们看到从第一季度到第二季度增长了约 114.6%。同期，存储 NFT 的钱包数量大幅增加，约为 151.89%。OpenSea 等 NFT 交易平台也随之增长，OpenSea 目前估值约 15 亿美元。NFT 销售已从仅在交易平台进行扩展到由苏富比和佳士得等传统拍卖行进行。

2021 年增加的不仅是 NFT 的销量。NFT 的价值也大幅上涨，有史以来最昂贵的 NFT 销售大多发生在 2021 年。2 月，音乐人 Grimes 的数字艺术品以近 600 万美元售出，而 Nyan Cat 的 GIF 以近 50 万美元或 300 枚以太币的价格成交。3 月，数字艺术家 Michael Winkelmann（化名 Beeple）的作品《Every Day: The First 5000 Days》由拍卖行佳士得上架，以 6930 万美元的创纪录价格售出。同月，Twitter 创始人兼 CEO Jack Dorsey 将其发布的第一条推文转化为 NFT 并售出，价格为 290 万美元。同样，各种 CryptoPunks 头像持续以从几十万美元到 760 万美元（即 CryptoPunks #7804 的 4200 枚以太币）不等的价格售出。

## 一些必须了解的最流行 NFT

### CryptoKitties

CryptoKitties 是最早被公众广泛交易的 NFT 之一。CryptoKitties 由加拿大开发工作室 Dapper Labs 于 2017 年开发。从那时起，游戏中各种猫咪的受欢迎程度和价格成倍增长，一些稀有猫咪（如“Dragon”）售价超过 100 万美元。CryptoKitties 是一款基于以太坊区块链的游戏。用户可以在游戏中购买、繁殖和出售猫咪。
