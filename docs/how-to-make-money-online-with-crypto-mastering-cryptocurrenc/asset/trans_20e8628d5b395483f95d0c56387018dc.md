

# NFT 概览

## CryptoKitties（加密猫）

游戏中的猫咪都是独一无二的。每只猫都有其颜色、体型、名字和其他特征，这些都无法被复制。用户拥有这些猫咪，因此任何人都无法将其夺走，包括游戏开发者。这些猫咪也可以作为收藏品，人们收集特定类型的猫咪并展示这些收藏。根据其属性和稀有度，游戏中有几种不同类型的猫咪，例如独家猫、花式猫和特别版猫。

## CryptoPunks（加密朋克）

加密朋克与加密猫一样，是非同质化代币领域的另一批开拓者。与加密猫类似，加密朋克也于 2017 年推出。加密朋克由名为 Larva Labs 的美国开发工作室创建。赛博朋克运动启发了加密朋克的诞生。反过来，加密朋克启发了以太坊的 ERC-721 标准，该标准现在被大多数数字艺术 NFT 所使用。

加密朋克是人们可以在各种平台上用作显示图片的头像。Larva Labs 总共创建了 10,000 个加密朋克。在这 10,000 个加密朋克中，6039 个是男性，3840 个是女性，88 个是僵尸，24 个是猿猴，9 个是外星人。每个加密朋克都是独一无二的，因此都拥有其自身的价值。加密朋克的价格取决于稀有度；其中 9 个外星人加密朋克最为稀有，迄今为止它们的成交价最高。

加密朋克经常出现在最昂贵 NFT 销售榜单上，例如 CryptoPunk #7804 以 760 万美元售出，CryptoPunk #6965 以 160 万美元售出，CryptoPunk #4156 以 130 万美元售出。甚至主流公司也开始购买朋克，Visa 于 2021 年 7 月花费近 176,000 美元购买了一个加密朋克。

## Rare Pepes（稀有佩佩）

稀有佩佩：稀有佩佩是 Counterparty 平台上首批提供的 NFT。佩佩是绿色青蛙的图像，经过各种方式编辑。不同种类的佩佩图像被转换为 NFT，然后卖给出价最高者。最“稀有”的佩佩——一张 Homer Pepe 的图片，即著名电视角色霍默·辛普森被编辑成佩佩的样子，于 2021 年 3 月以 320,000 美元的价格被买走。

## Everyday: The First 5000 Days（每一天：前 5000 天）及其他 Beeple 艺术品

《Everyday: The First 5000 Days》是迄今为止售出的最昂贵的 NFT。它在佳士得拍卖行的拍卖中以 6930 万美元或 42329 枚以太币的价格售出。这是一幅由 Beeple 创作的五千张图片拼贴而成的作品。它由 Vignesh Sundaresan 购得，目前正在一家数字博物馆中展出。

它不仅是迄今为止最昂贵的数字艺术品，也是在世艺术家售出的最昂贵艺术品之一。Beeple 是美国数字艺术家 Mike Winkelmann 的化名，他将许多数字作品转化为 NFT 并出售。他的艺术作品是加密世界中最抢手的 NFT 之一，大多数在几分钟内售罄，价格高得惊人。他的另一件作品名为《Crossroads》（十字路口），是一个 10 秒的视频，于 2021 年 2 月以约 660 万美元售出。

## Decentraland（去中心土地）

Decentraland 是一个 3D 虚拟现实世界。在这个世界里，产品、土地和其他设施作为 NFT 出售，连接了虚拟世界和现实世界。它最初由阿根廷开发者于 2015 年启动。它逐渐从像素化的球体发展为一个 3D 世界。最近，虚拟房地产价格成倍增长，Decentraland 中一些黄金地段的价格高达 100,000 美元。现实世界的公司如苏富比和 Republic Realm 正在这个世界购买数字房地产，用作数字办公室和购物场所。

## Alchemy Toys（炼金玩具）

Alchemy Toys 是一款基于币安智能链的游戏，由名为 Backupdev UG 的德国软件公司开发。它被宣传为非同质化代币、大型多人在线角色扮演游戏和去中心化金融的融合体。在游戏中，玩家可以拥有独特且稀有的炼金玩具，这些玩具可以组合形成新的玩具，或以实际价值出售给其他玩家。也可以牺牲或销毁这些玩具。如果有人集齐所有不同的玩具，将获得币安币作为奖励。

## Pancake Swap（薄饼交换）

Pancake Swap 也基于币安智能链。在该平台上，用户会获得作为 NFT 的小兔子。这些小兔子除了作为装饰外没有其他用途，除非用户也可以用它们兑换 Cake 币（该平台的加密货币）。

## Gods Unchained（众神未链）

Gods Unchained 很像现实生活中的卡牌交易游戏。在游戏中，玩家获得其卡牌的真实所有权，这些卡牌是可交易的 NFT。这些卡牌出售时，会为玩家提供加密货币和真实价值。卡牌的价值取决于其稀有度，有些价格高达一万美元以上。该游戏由 Immutable 创建，这是一家位于澳大利亚、专注于区块链游戏的开发工作室。

## NFT 与典型加密货币的区别

在探讨非同质化代币与比特币、以太坊或卡尔达诺等主流或典型加密货币的区别之前，我们必须首先了解它们的相似之处及联系。从本质上讲，NFT 和加密货币都是可以在在线平台上买卖的数字资产，几乎没有内在价值。NFT 和加密货币都基于区块链或分布式账本技术。两者的交易历史都存储在区块链上，且永久不可篡改。在监管方面，NFT 与加密货币一样，在大多数国家都处于灰色地带。

### 本质

我们看到的 NFT 和加密货币的第一个区别在于其本质属性。当我们谈论加密货币时，顾名思义，我们将其视为货币，即它们被用作购买其他事物或资产的工具或类货币工具。然而，在某些地方和某些人眼中，它们被视为可能增值并随后抛售的投资品。另一方面，当我们谈论 NFT 时，如前所述，尽管它们被称为代币，但它们并非货币。NFT 在本质上类似于资产。它们不用于购买其他东西，而是作为收藏品。如果将加密货币比作现实生活中的货币，那么 NFT 可以比作艺术品和奢侈品。

### 同质性

NFT 区别于典型加密货币最关键的特征，就在其名称中——即同质性。同质性是指相似商品或资产可互换或可被同类项目替代的能力。同质性是货币的基本特征。它确保人们可以自由使用现金，且一单位货币与另一单位货币没有区别。加密货币像法定货币一样具有同质性。如果你用一个以太币兑换另一个以太币，两者没有区别；你手中本质上拥有的还是同一种东西。另一方面，NFT 是非同质化的；每一个都是独一无二的，因此无法被复制。如果你用一个 NFT 交换另一个 NFT，你拥有的将与之前不同。

### 价值决定因素

NFT 价值的确定方式也不同于加密货币。由于加密货币交易量极大、流转极其频繁，因此加密货币的价格由当前的市场力量决定，即供需关系。NFT 具有唯一性，每个承载不同的价值；此外，NFT 的价格取决于买家愿意为该产品支付多少。在 NFT 的情况下，市场的供给端是恒定的。
