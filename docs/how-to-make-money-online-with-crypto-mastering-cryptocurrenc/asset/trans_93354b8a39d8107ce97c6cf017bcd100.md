
# 比特币交易幕后流程与加密货币优势

Luke 收到的 BTC 会扣除比特币矿工和网络收取的交易手续费。这些费用可能从每小时交付的 $0.05 到十分钟交付的 $0.58 不等。无论 Julia 发送 $25 还是 $25,000,000，费用都保持不变。现在，让我们剖析幕后发生的事情。从 Julia 将交易发送到区块链的那一刻起，比特币网络中的每个节点都会收到交易请求。每个节点都会验证 Julia 确实是其声称的那个人。节点使用私钥验证 Julia 的身份——私钥唯一标识资金发送源。谁拥有这把小小的钥匙，谁就能获得你的资金？这就是为什么保护私钥至关重要。我们始终应该使用自己的钱包，而不是将币留在交易所，稍后会详述，但请记住：**你的私钥，你的币**。

因为节点拥有交易总账的副本，它们可以验证 Julia 是否拥有资金。如果至少 51% 的节点就前面提到的两个组成部分达成一致，交易即为有效，节点会用新的交易记录更新账本。

如果将其与涉及法币的典型交易进行比较，我们可以看到加密货币交易是多么复杂。这些额外的层带来了一些价值，并可能解决传统金融体系的弱点。以下是加密货币可能彻底改变我们商业模式的几种方式。

## 交易比银行更快、更便宜、更安全

当今的银行系统亟需更新。国际银行转账可能需要长达一周的时间，因为双方都需要代理银行和特定国家的清算机构。即使是跨境支付数据交换，也充满了困难和摩擦。使用比特币等数字货币，银行交易可以快速且廉价地完成。

欺诈是几乎所有涉及资金业务的重大问题。无论是资金转账还是仅在不安全网站上使用信用卡，欺诈潜在风险都是每个人的重大担忧。这对曾经遭受过欺诈的个人尤其如此。

因为加密货币不与您的银行账户或现金关联，而是通过区块链以电子方式安全转移（区块链记录所有交易），加密货币将显著减少欺诈，让人高枕无忧。

## 全球汇款获得提振

每年，来自贫困国家的移民汇款回国超过 5000 亿美元，超过了外国直接投资。国际转账成本平均占汇款总额的 6%-10%，这对世界上最弱势群体影响巨大。技术有能力加速并降低这些转账的成本。

私人用户甚至可以通过手机使用虚拟货币直接向亲属汇款，剩余成本来自货币兑换。传统汇款企业必须维持资金以弥补国际资金流动延迟，而拥有数字货币的企业资本需求要低得多。资金持有成本和汇款手续费只是汇款公司经营成本的一部分。然而，成本降低可能使小公司更容易进入市场、开辟新汇款走廊，或让现有企业服务于较小城市或新国家。

## 为贫困人口提供安全的货币

某些国家传统货币遭受的通胀和波动令人担忧。虽然并非所有国家货币都易受极高通胀率影响，但一些国家采用比特币将获益良多。

例如，非洲移动技术的增长已表明贫穷国家可以成为技术领导者。据估计，肯尼亚高达 60% 或更多的贸易通过手机话费额度作为交换媒介进行。拥有手机的任何人都可用它存储资金并向其他用户转账。问题在于成本高昂：传统上，提现成本高达 20%，尽管许多客户可直接使用信用卡而无需支付高额费用。

在大多数人没有银行账户的国家，数字货币有潜力成为另一种简单安全的支付方式。虽然在一个国家采用比特币作为辅助货币会让人们面临货币风险，但这可能优于现有替代方案，尤其是在严重通胀国家。例如，它比把现金放在家里或购买金饰更安全。此外，比特币持有者可在全球比特币交易所将其兑换为更稳定的货币。这可能拓宽全球金融市场准入，让无银行账户者也能储蓄并对抗通胀。一个可能的后果是资本管制将更难实施。

## 释放电子商务潜力

对信用卡盗窃的担忧导致许多互联网企业拒绝潜在客户。这种欺诈在海外交易中尤为普遍，因此许多公司拒绝接受外国支付。使用比特币等数字货币进行转账一旦完成即不可逆转。这降低了商家的欺诈风险，使他们能够在全球范围内销售。此外，由于虚拟货币让消费者转账像发邮件一样简单，网购体验将变得愉悦得多。

此外，数字货币可能让欠发达国家的小企业更充分地参与全球电子商务。拉丁美洲工匠可向全球销售商品，中国青少年可通过 Skype 提供中文教学，非洲企业在在线广告市场推广产品将拥有目前缺失的支付选项。小额交易是一个引人注目的用例，因为极低的交易成本允许低价值的应用内购买或微支付，以阅读来自世界各地媒体来源的在线新闻。

## 可通过智能合约编程的货币

一旦创建了数字资产，它就可以自动转移。这为实现“可编程货币”和“智能合约”打开了大门。托管账户是一个现实的例子。这些账户已用于房地产购买等大额交易。买家将资金存入托管，只有当卖方将房产所有权转移给买方时，资金才会释放给卖方。在数字时代，当信任成为人们远距离交易的重大障碍时，这种方法可用于更小金额。

另一个例子是多重签名，要求多人认证后才能从账户提取资金。这可用于防止数字货币被盗，但也能保证资金在跨境、企业部门间、慈善团体与贫困国家承包商之间流转时不“丢失”或被盗。

此外，可编程货币可用于更复杂的合约，如多方金融交易和复杂衍生品。您可以将一些资金投入一项金融协议，根据特定股票价值的表现支付回报。计算机程序可连接到彭博终端数据源，然后根据某些股票或股票组合的表现，向不同人员支付资金。
