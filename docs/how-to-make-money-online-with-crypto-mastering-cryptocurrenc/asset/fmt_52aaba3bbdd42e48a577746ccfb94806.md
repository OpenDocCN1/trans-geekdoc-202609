
# Chainlink (LINK)

Chainlink (LINK) is a cryptocurrency blockchain network that provides a link between real-world data and smart contracts. The platform helps execute smart contracts, which are blockchain agreements that automatically complete upon filling in necessary preconditions. It offers a tradable cryptocurrency token called LINK, used to pay for innovative contract transactions on the Chainlink network. LINK tokens also hold their value in comparison to fiat currencies.

Chainlink was created in 2014 and launched in 2017 by its founder Sergey Nazarov, a 32-year-old entrepreneur with a significant presence in the crypto market. Initially, the Chainlink network was designed to be a centralized oracle system that could verify incoming information. However, it has since transformed into a decentralized oracle network that pairs with smart contracts to secure transactions using external data sources and APIs.

Chainlink helps bridge the gap between oracles that send real-world data and smart contracts on the Blockchain. Chainlink can generate multiple subcontracts while taking data from only the most trustworthy nodes and oracles to maximize accuracy. Although there is no limit on the number of smart contracts the platform can handle, the number of LINK tokens that will ever exist is capped at one Billion. The Chainlink network is a reasonably open system. Anyone can join it, provide data to the network, or help operate its corresponding nodes and oracles. These operators are paid in LINK tokens, which are the native currency of the Chainlink network.

As the proliferation of blockchain technology is increasing daily, networks such as Chainlink can supplement innovative contract implementations, acting as alternatives to mainstream blockchains such as Ethereum.

# Polkadot (DOT)

Polkadot (DOT) is a network designed to 'join the dots with all other networks. Unlike networks like Bitcoin, which operate independently, Polkadot can link multiple networks.

Its ultimate aim is to act as a standard integrated framework for all blockchains that opt-in to use its technology. The idea is to take care of complex and costly cryptocurrency mining processes that include validation of transactions and security protocols and enable developers to focus solely on creating efficient dApps and smart contract functionality. Gavin Wood, a co-founder of Ethereum, built Polkadot.

Developers building innovative, decentralized systems must engineer these systems from the ground up, including the Blockchain. This means that time, talent, and resources are diverted into building competing networks rather than creating a standard everyone builds off. That's Polkadot's aim, to make way for developers to build value on top of all blockchains rather than just one.

Blockchains can connect with Polkadot and work in parallel as "Para chains" to access the network's proof-of-stake validation system for transactions and security. In the network's "relay chain," transaction addresses are checked, and data is standardized so that every participating system can understand it.

While functionality is covered, blockchains connected to Polkadot can use their PoS mechanism to decide when and how to update their code and run the dApps or tokens they prefer. Polkadot is a pick-and-choose layer that allows networks to keep their security intact and incorporate new protocols simultaneously. The two fundamental issues blockchain-based systems must address are scalability—the number of transactions per second the network can handle—and governance: how the system manages protocol upgrades and changes. Polkadot aims to solve both of these problems efficiently.

DOT, the native token of the Polkadot network, allows holders to vote on potential code changes, which automatically upgrade across the network if a consensus is reached. Polkadot launched its main net in early 2020 and quickly gained traction among investors, developers, and cryptocurrency traders.

In less than a year, it has already racked up several impressive accolades and developments, including:

- Climbing to become the fourth-largest cryptocurrency and achieving a peak market capitalization of almost $18 billion.
- Undergoing redenomination, a process through which old DOT tokens are split 100 times to produce new DOT tokens—increasing the supply from 10 million to 1 billion.
- Seeing a dramatic surge in developer activity, with over 350 projects now being actively developed on the platform.

With blockchain technology penetrating conventional business models and use cases, we can expect more developers to get on board the smart contract and dApps universe; a framework model that Polkadot proposes will be of paramount importance in such a situation where developers are required to be more focused on creating robust smart contracts and dApps rather than devoting time to build a blockchain from the ground up.

# Chapter 5: Decentralised Finance

## What is DeFi?

Decentralized finance (abbreviated as DeFi) has taken the world by a whirlwind since its inception in 2017. The basic constitution of this term indicates the involvement of finances and Decentralization. While "finances" is self-explanatory, Decentralization is a descriptive term requiring extra elaboration for comprehension. "Decentralization" here highlights that this system is free from the control of any chief body like banks; in other words, it is not centralized. It stands at the crossroads of financial services and technology.

DeFi has amalgamated the two sectors with such efficiency that the need for intermediaries like brokers or banks has been eliminated. Compared to the financial handling by mediators, DeFi does not require an account, government-issued ID, address proof, etc. In other words, DeFi allows vendors, lenders, borrowers, etc., to engage in monetary transactions much like a bank but without the actual involvement of a centralized authority like that of a bank. It is a much less cumbersome finance system that does not require the service seeker to go through extensive processes like generating bank statements, producing many documents, etc.
