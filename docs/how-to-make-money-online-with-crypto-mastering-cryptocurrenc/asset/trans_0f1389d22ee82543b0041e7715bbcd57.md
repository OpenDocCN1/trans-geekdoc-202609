
# NFT 市场与购买流程

## 选择 NFT 市场

下一步是选择市场。有许多市场可供选择，每个市场都有其特点、交易成本和其他特性。在选择购买 NFT 的市场之前，必须综合考虑这些因素。

## 将钱包连接到市场

下一步是买家将存放加密货币的钱包连接到市场。这允许加密货币通过市场从您的钱包转移到卖家的钱包。

## 选择 NFT

此过程中最关键的步骤之一是在平台上选择要购买的 NFT。这些平台上有数千种不同的 NFT，且市场每天都在增长。选择 NFT 是一个至关重要的决定，必须基于充分信息做出，因为这是一项长期投资决策。

## 购买 NFT

最后一步是购买您选择的 NFT。平台上的购买通常有两种方式：拍卖形式（最高出价者获得 NFT），或卖家报价、买家支付金额购买。加密货币转移完成后，交易会存储在区块链上，所有权转移给新持有者。

这是 NFT 购买的常规方式。但最近我们也看到，一些现实中的拍卖行开始通过拍卖出售数字艺术品。

## 如何选择 NFT？

选择 NFT 应该是一个基于以下因素的明智决策：

### 价格

选择 NFT 前首要且最重要的因素是售价。必须结合预算，决定购买哪些预算范围内的 NFT。

### 区块链

另一个必须考虑的因素是 NFT 铸造所在的区块链。大多数 NFT 基于以太坊，但其他区块链也提供铸造服务。应选择值得信赖且成熟稳定的区块链。

### 稀有度

NFT 的稀有度会影响其未来价格。例如，CryptoPunks 中的外星人角色比人类角色更值钱，因为外星人角色仅有 9 个。

### 创作者

就像购买实体艺术品一样，数字艺术 NFT 也应根据创作者身份来购买。可以投资您认为未来会成名的艺术家的 NFT。

### 类型

NFT 的类型和种类也很重要。有人将 NFT 作为数字资产，有人作为收藏品或游戏道具，也有人将其视为金融工具。

## 如何选择 NFT 市场？

选择合适的 NFT 市场同样重要。选择时必须考虑以下因素：

### 代币标准

制作 NFT 使用多种不同的代币标准。根据您想购买的 NFT，应检查市场是否提供该代币标准的 NFT。

### 交易成本

每次购买或出售 NFT 都会发生交易并记录在区块链上。市场会对每笔交易收取费用或佣金。费率因市场而异，决策时应予以考虑。

### 类型

市场类型各异。有些是通用型，允许交易各类代币；有些则仅提供特定类型。

### 验证流程

市场对想要出售 NFT 的创作者有验证流程。这必须是严格的流程，以限制假冒和欺诈性 NFT 的存在。

### 定价机制

价格发现流程也因市场而异。有些通过拍卖，有些由卖家或创作者报价。

# 第 7 章：区块链技术

## 什么是区块链？

区块链常与第一种加密货币——比特币混淆。这是因为“区块链”一词仅在比特币诞生后才流行起来。实际上，区块链是支撑加密货币运行的核心技术。没有区块链，就不会有今天流通的任何加密货币。必须认识到，加密货币只是区块链技术众多潜在应用之一。

简单来说，区块链是围绕点对点（Peer-to-Peer）系统构建的分布式电子账本。该账本可在无限用户间共享供参考。录入区块链的交易防篡改且带有独立时间戳。一组有效交易构成一个完整的区块。每个经验证的区块链接到前一个区块，形成区块链——因此得名“区块链”！

区块链的运作方式不同于中心化系统。它是分布式账本，基于共识机制作为网络运行，因此具有去中心化特性。以下是区块链上交易的分步工作流程：

1. 区块链网络中的一个节点（计算机）接收发送方的交易，通过创建交易在网络上发起。随后，密码学技术使用私钥对交易进行数字签名。
2. 交易信息从该节点传递给网络上所有其他节点，根据区块链预设的标准验证交易。此过程称为“Gossip 协议”（Gossip protocol）。在技术术语中，它称为“工作量证明”（Proof of Work），即区块链的标准共识算法。根据该算法，节点必须解决复杂的数学难题以认证交易。通常需要两个或更多节点验证交易。
3. 节点完全验证交易后，将其打包进区块并广播至主区块链网络。此时交易获得首次确认。
4. 随后，当为同一交易创建新区块时，会经历上述相同过程并链接到第一个区块（称为“创世区块”）。区块获得首次确认，交易达到第二次确认。
5. 对每个新创建的区块重复相同过程进行再确认。通常需要约 5-6 次确认，交易才算正式完成。最终，加密货币/数字资产的所有权转移给接收方。

## 智能合约

使用区块链最根本的目的之一是无需中介。因为区块链去中心化，中介的所有职能均由复杂的计算机算法替代。区块链的一项革命性应用——智能合约，有潜力消除许多中介。

智能合约可定义为存储在区块链网络中的计算机化协议。在智能合约中，所有合约条款可预先编码，一旦满足合约条件，合约执行即可自动完成。由于智能合约存储在区块链网络中，合约的安全性、透明度和可访问性呈指数级提升。
