
# Blockchain Technology

## Miners

Miners are the people who are responsible for adding new blocks to a blockchain. To add a new block to a blockchain, one needs to solve a complex mathematical problem; this problem can only be solved by trial and error and hence requires significant computing power. A `nonce` is a 32-bit number, and the `hash` is a 256-bit number, so about 4 billion `nonce`-bit combinations are possible. The process of finding the correct combination is called mining. For undergoing this process, the miners are rewarded in cryptocurrencies.

## Principles of Blockchain

Blockchain technology works based on certain principles; these principles are:

### Distributed Database

The most basic principle behind blockchains is that the database in a blockchain is not stored in a single location and is spread across various nodes and servers. It means that for a transaction to be entered into a blockchain, it must be entered in every node, making it a very secure form of data storage, albeit a bit slower.

### Peer-to-peer Transactions

The transactions and communication in a blockchain happen directly between the peers and nodes and not via a moderator. This ensures a certain amount of trust and transparency between blockchain network users.

### Transparency

The transactions stored in a public blockchain are transparent. Anyone can access these transactions, making it harder for people to cheat or defraud others by creating false entries.

### Irreversibility

The transaction, once stored on the blockchain, is marked with a timestamp, and it is stored as such. The data, once entered, cannot be changed after that. The entire chain must be mined again to make even a small change on one of the blockchain blocks. This would require massive computing power and would be nearly impossible.

### Computational Logic

The data is stored on the blocks in a logical format, so the users don't have to add it manually. They can create algorithms to enter the transactions by themselves.

## Cryptography in a Blockchain

A blockchain uses two basic kinds of cryptography: the asymmetric key and the hash function. These two are used at the same time and have different processes.

### Asymmetric Key Cryptography

The asymmetric key means two types of keys are needed to access the blockchain. For every blockchain, there is a `public key` and a `private key`. The `public key` is available to everyone on the network, and it is the same for everyone. However, the `private key` is unique to every node and is only available to the node owner. In this kind of cryptography, the `public key` encrypts the plain data into cipher text. The node owner then uses the `private key` to decipher the reader to plain text. Combining the `private key` and `public key` creates a signature unique to the node owner.

### Hash Function

The hash function is the cryptography used for chaining the blocks to each other. Every block has its `hash`; at the same time, it also carries the previous block's `hash`. E.g., block number 21 in a blockchain will have the `hash` of block number 20, which will chain it to the last block. Meanwhile, block number 22 will have the `hash` of block number 21; this is how they connect and create a chain. It ensures no new person can create and attach random data to a blockchain. The block's `hash` is made via the Merkel tree, where every transaction has its `hash`, which keeps combining until we get a `hash` for the whole block.

## How do the Transactions go Through?

The process of transactions being recorded on the blockchain goes through the following procedure:

1. The transaction is requested by the people who want to purchase a cryptocurrency.
2. The transaction is broadcasted via the peer-to-peer network to all the nodes.
3. The node owners then validate the transaction on their records.
4. The node owners are compensated in the form of cryptocurrency.
5. The transaction is then recorded on the block that is open at the time being.
6. Once they are filled with transactions, the blocks are attached to the blockchain.
7. The transaction is completed and timestamped.

## Fundamental Properties of Blockchain

Some of the fundamental properties of a blockchain are:

### Distributed

One of the most essential features of blockchains is that they have a distributed ledger. They are also called distributed ledger systems for the same reason. It means a blockchain has multiple nodal centers instead of having a single central authority or a central node from where the data is disseminated. The data is hence stored on all these servers at the same time. These various nodes ensure the security of the data since it is nearly impossible to mutate the data on all nodes simultaneously. This also reduces the cost of the database since there is no need to have large servers on which the data is stored, thereby saving the cost of purchasing these servers and the rent of physically holding all these servers in a place.

### Immutable

The data in a blockchain is immutable, i.e., the data is permanent in nature, and it can't be mutated. This is so because once the various nodes verify the transaction on a blockchain, it is stored on a block, which is then attached to the chain. To change the data on a block, one needs to have the correct `nonce` and `hash` combination, which is one out of four billion and can only be found through the hit and trial method. Further, each block has its `hash` in the next block, so to change one block, one needs to change the data in every one of the blocks in the chain.

### Timestamped

One of the defining features of blockchain technology is that all of the transactions stored on the platform are time-stamped. This means the time and date are also simultaneously attached as soon as the transaction is entered on the block. This ensures that no one can backdate and change the values. It provides us with a record in chronological order. This feature allows us to keep track of all cryptocurrency transactions and ensure that the cryptocurrency is not doubly sold or bought.

### Unanimous

The data stored on the blockchain platform is unanimous because everyone on the forum is verified and accepted through all nodes. One of the nodes may carry a different value or transaction, and the other takes an additional weight or a trade. Due to this feature, everyone has access to the same data, reducing the risks of discrepancies and errors in communication.

### Anonymous

The transactions recorded on the blockchains do not carry the name or identity of the people involved. Most of these transactions are either anonymous or pseudonymous. This allows people to carry on transactions without associating themselves with it and, to a certain extent, pass various laws and regulations. The transactions cannot be traced back to the people.

### Secure

The data history on a blockchain is considered incredibly fast. Since the data is not stored on a single server and the same data is stored on multiple nodes across the network, it is tough for someone to hack into the blockchain network and change the data at every node. In a traditional database, central servers are easy to break into; however, this is not so in a blockchain. Hence, blockchains are much more secure than the usual servers.

### Programmable

Blockchain is a programmable data-storing service. This means the data must be manually put into the servers only sometimes. One can set up mathematical and logical algorithms that verify the transactions themselves. It also allows for setting up intelligent contracts over blockchain technology, a feature now increasingly used by blockchain companies such as Ethereum.
