# 9.4.2 DATA PREPROCESSING

The stroke prediction dataset that has been taken from Kaggle consists of 201 missing values in the column named “bmi” that have to be filled. If missing values are available in the dataset, it may ultimately lead to a decrease in the accuracy of our model. The values missing for the bmi attribute are filled with the mean of bmi. Also, label encoding is carried out to transform the categorical values into numerical values as training can only be done on the numerical value attributes.
