IDS at edge node, containerisation can be used. Containers at edge devices are used to manage the applications without difficulty. Containerisation is applied in edge computing for various applications like smart homes (Ozcan, M.O., Odaci, F. and Ari, I.; Morabito 2016), vehicular networks (Sami et al. 2020; Boettiger 2015), and industrial IoT (Okwuibe et al. 2020; Burns et al. 2016), but not applied in intrusion detection systems at edge nodes. Containerisation of security systems at fog node networks was proposed for a software defined network (SDN) (Prabavathy & Supriya 2021), but this system is specific to SDN and it performs behavior analysis for anomaly detection.

The proposed IDS is novel as it implements intrusion detection for healthcare IoT using deep-learning algorithms which are containerised and executed at the edge nodes to rapidly detect attacks from a vast amount of data from healthcare IoT devices.
