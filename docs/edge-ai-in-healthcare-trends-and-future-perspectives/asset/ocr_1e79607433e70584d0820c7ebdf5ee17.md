According to researchers, such techniques have several limitations, such as data availability, quality problems, and real-time processing in an environment where disease prevention and early detection of symptoms are the most important considerations. Healthcare systems employ personal and private information. Therefore, data security and storage are a key problem for these systems as well. Several researchers have also advocated the use of edge and fog nodes in distributed DL models, allowing them to minimise training and processing times. The edge nodes were tasked with local decision-making, whereas the cloud layer was tasked with model training. Edge nodes gained relevance due to the GPU devices being integrated at the edge level. They were also used to improve the model's computational capacity and data processing capabilities at a fog level by using Graphic Processing Unit (GPU)-powered nodes.
