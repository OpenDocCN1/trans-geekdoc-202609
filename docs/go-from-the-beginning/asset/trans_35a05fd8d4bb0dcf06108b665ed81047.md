      ```

      在前面的代码中，`hasBurger` 为 true，这足以使该表达式为 true。

    *   `!`，也称为 NOT，它会对表达式取反。以下是该运算符的使用示例：

      ```

      上面，表达式因为 `!hasSandwich` 的取反而评估为 true。
