The introduced application, optical time series gapfilling using a deep convolutional autoencoder, has illustrated how a deep neural network can easily combine multiple sources having different modalities, physical and spectral resolutions. While we have illustrated the versatility of deep learning through this particular application, we have no doubt that a huge number of problems in remote sensing can be addressed with carefully tailored deep learning architectures.
