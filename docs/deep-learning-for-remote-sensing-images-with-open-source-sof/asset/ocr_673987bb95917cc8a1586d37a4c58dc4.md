# ### 16.2.1.2 Merge masks

You should have ended the previous step with 3 new vector layers:

+   1. *Sentinel2_2019-07-05_holes.gpkg*
+   2. *Sentinel2_2019-07-25_holes.gpkg*
+   3. *Sentinel2_2019-08-24_holes.gpkg*

Since we want samples that are valid in the four images ($S2_{t-1}$, $S2_t$, $S2_{t+1}$ and $S1_t$), we need to merge the vector layers of images into a single one that indicates where at least one image has missing content. Use QGIS to merge the masks into a single vector layer. From the menu, select **Vector > Data management tools > Merge vector layers** ref to [figure 16.6](#figure-166).

![](bbox=[0.239, 0.332, 0.754, 0.416])

# **FIGURE 16.6**

Merge the masks.

In input layers, select the 3 vector layers *Sentinel2_2019-07-05_holes.gpkg*, *Sentinel2_2019-07-25_holes.gpkg* and *Sentinel2_2019-08-24_holes.gpkg*. Select the destination CRS (Coordinate Reference System) as EPSG:32630, which is the same as the Sentinel images. Save the output vector layer as a temporary layer. [Figure 16.7](#figure-167) summarizes the parameters to provide.

![](bbox=[0.262, 0.613, 0.734, 0.86])

# **FIGURE 16.7**

Select the masks to merge. Keep the same coordinate reference system as the images (EPSG:32630). Save the output vector layer as a temporary layer.
