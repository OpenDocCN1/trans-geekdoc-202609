The program will execute and achieve the following actions:

+   1. Load the input patch images.
+   2. For each epoch:
+      (a) Perform the gradient descent over the dataset.
+      (b) Assess the model error (in terms of L1 and L2 losses).
+      (c) Save the model weights into a *checkpoint* file.
