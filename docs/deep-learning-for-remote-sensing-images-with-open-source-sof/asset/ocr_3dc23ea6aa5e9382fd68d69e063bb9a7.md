Select features by location.

In the Select by location panel, set the following fields (figure 16.12):

+   1. **Select features from:** select *Grid*, corresponding to the vector layer that we have generated in the previous step.
+   2. **By comparing to the features from:** select the *Merged* layer.
+   3. **Where the features (geometric predicate):** set *disjoint* since we want to keep the patches that are outside the undesirable areas (clouds and *no-data* values).
+   4. **Modify current selection by:** select *creating new selection*.
