The output **size** depends on the following parameters of the convolution: padding, kernel size, and stride. The output **physical spacing** is changed accordingly to the stride in the convolution: *n* strides ensure that physical spacing is scaled by *n*.

> **Important note**
> 
> - Non-unitary strides modify the output physical spacing.
> - Without padding, the output size is changed, depending on the kernel size.
> - With padding, the output size can be kept (same as the input, if no stride) but values at the border might be contaminated by the zero padding.

# 1.3  Pooling

Another important concept of CNNs is pooling, which is a form of non-linear downsampling. The intuition is that the exact location of a feature is less important than its rough location relative to other features.
