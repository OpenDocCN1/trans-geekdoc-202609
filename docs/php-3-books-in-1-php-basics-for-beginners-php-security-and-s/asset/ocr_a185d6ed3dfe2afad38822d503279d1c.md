There are fourteen levels to choose from, and any combination is permitted. A complete list of these levels is provided in the table below. It's critical to remember that each level encompasses all preceding levels. For instance, the E_ALL level in the table logs any messages generated by the 13 levels behind it.

# Error Reporting Sensitivity Levels

| E_COMPILE_ERROR | serious faults during compilation |
