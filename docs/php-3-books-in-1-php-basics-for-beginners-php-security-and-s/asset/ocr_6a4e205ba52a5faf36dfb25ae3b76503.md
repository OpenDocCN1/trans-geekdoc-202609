The lines of code above, also known as the fluent interface, instructs the stub object that whenever the getAllCarteProducts method is called, it should return the value in $result instead. The expect() method is included in Mock (and Stub) objects created automatically by PHPUnit, as seen above. The except() method requires a matcher object. The matcher specifies how many times a specific method must be invoked or the cardinality of the expectation. The any() convenience method notifies the expect() method when a match fails except if zero or more calls to the related method were performed. This is useful for stub instances that return values without doing any invocation testing.

Here are some TestCase Matcher methods:

| TestCase | Method Description |
|---|---|
| never() | The relevant procedure is not called. |
| any() | Calls to the relevant method were made zero or more times. |
| atLeastOnce() | One or more times, a relevant method is called. |
| exactly($num) | Called the relevant procedure $num times. |
| Once() | The relevant method is only called once. |
