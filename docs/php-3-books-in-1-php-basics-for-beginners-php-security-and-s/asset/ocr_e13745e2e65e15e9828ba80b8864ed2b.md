Whenever one attempts to run an abstract method, one will receive an error. Methods that are abstract must be specified within an abstract class. Declaring an abstract method inside a non-abstract class will show an error during compilation.

Here, it’s a Cat abstract class with an abstract method meow():

```
```php
<?PHP

abstract class Cat {

private $title = null;
private $gender = null;
public function __construct($title) {
$this->name = $title;
}

public function getName() { return $this->name;}
public function setName($title) {$this->name = $title;}
abstract public function meow();

}

// Override the abstract meow() method from abstract Cat class

class Persian extends Cat {

public function meow() {
echo "MEOW!! MEOW! MEOW!" . "<br>";
}
}

class Maine extends Cat {
public function meow() {
echo "BRRR! BRRR! BRRR!" . "<br>";
}
}

// the class fails to enforce meow() resulting in an error of compilation.
class Mutt extends Cat {
// this will cause an error because this cat didn't override meow()
}

?>
```
```

# OUTPUT:

**Fatal error:** Class Cat contains 1 abstract method and must therefore be declared abstract or implement the remaining methods (Cat::meow)
