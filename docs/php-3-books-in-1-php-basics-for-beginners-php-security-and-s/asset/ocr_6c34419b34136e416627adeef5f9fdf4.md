In PHP, how do I get the values from a session?

The global variable $_SESSION can be used to get the value of a session variable. You'll create a new session with a variable that holds your name in the example below.

You'll use another file to access the variable now that it's been set. To access the name variable, you just set it, create a new file and write the following code.

```
<?php
session_start();
?>
<html>
<body>
<?php
echo "User is: ".$_SESSION["name"];
?>
</body>
</html>
```
