In the previous example, you can see how each function works individually and how they interact with each other.

The $x variable is defined as a float, and it is assigned the value of 5.6667.

The floor function returns 5.6667 to the calling code, so you can use this to display the value of $x.

The pow function returns 1 if its argument is an integer and 0 if it is a float. It also ignores negative numbers. That's why the pow(4, 0.25) returns 1, and the pow(-4, -0.25) returns 0 (if you used floats instead of integers).

The ceil, floor, round, and truncate functions ignore negative numbers.

Using the is_int() function, there is the possibility to change the behavior of pow(). By using pow(5, 3), between one and three will be added to 5.
