### Defining a Function

A function is a collection of code that performs a specific task. The first step in defining a function is to give it a name. This can be any word or short phrase, but it should be descriptive enough so that another coder can understand what the function does by reading its name alone. A computer will not execute code until it reaches the opening curly bracket `{` and sees the instructions "function." In order to add instructions for this particular function, type `function` followed by the name given to this new function. Finish with a closing curly bracket, `}`. The first instruction in any function will have the same name as the function to which it belongs. The second instruction within the curly brackets will begin with the name of the function. The other instructions within this function can be given any name not used anywhere else within PHP. As a result, you can have an additional section of code outside of your main program file, one that does not really "belong" within a program's functions and is only for your use.

It is possible to include as many instructions in a function as you want, but be careful not to include too many, or the code might become hard to follow. If you do encounter a section of code that seems unnecessary within your function, it can be deleted without damaging the rest of your code. When you have finished writing the code for this function, you must then return to your main program block in order to tell PHP that you are done with this function.

## PHP Function Default Values

It is possible to assign default values to arguments in PHP functions. The default value for a variable is the first value that does not have it defined inside of the function. When a PHP function is defined, the variable will have a default value assigned and can not be altered. This means that if you do not give any arguments to your function, then it will still have the same default value missing from it as when it was created.

### 1. Default Value established by the programmer

This is the first and most common way to establish a default value for your arguments. The `code_2` keyword can be used to set a default value. This means that all of the arguments will have this value unless otherwise defined by someone else. The example below shows how you can use it:

```php
<?php
function my_func($arg1 = "default value") {
} ?>
```

Here, the default value is set to be the string "default value" using the switch statement. This will be used if no other value is provided by any other source. If a different value is given, then it will replace this and work normally. This is because when arguments are not provided, PHP will use their default values and not create new variables with them.

### 2. Default Value established by `code_3`

The second way of establishing a default value for your arguments is to use the `code_3` keyword. This method uses the same error checking that is done when using switch statements which PHP recognizes as parameters being missing or incorrect, which results in programs failing. This is the most efficient way of doing things and allows you to avoid accidentally passing in incorrect arguments. Take a look at the following example:

```php
<?php
function my_func($arg1, $arg2 = "default value") {
} ?>
```

This example uses the `code_3` method to get the same results as above. If a user does not provide any arguments, then the string will still be missing from the function.
