The two following examples show how to get results for the top five employees (by the last name). This time, however, the results will be ordered so that the top five match with the top five based on age.

TOP 5 OF NEWSTAFFPARTITION WHERE LASTNAME = 'SMITH' ORDER BY LASTNAME

At this point, you’re probably starting to get used to how a TOP clause works and how it can help your queries. It's not quite that straightforward, though. There are some restrictions to keep in mind when using this clause. You can read more about these restrictions in the section below.

The TOP Clause can be used with all kinds of conditions (including IN and NOT IN). It will always evaluate at the end of the SQL statement, even if it is querying a result set that has been computed earlier in the process. In other words, if you have multiple SELECT statements that use LIMIT or ORDER BY clauses, only one of those statements will ever be executed under a TOP Clause. This means that you will miss out on possible complexity savings, even though SQL Server treats the operations as a unit.

## The ROWNUM Clause

The ROWNUM Clause helps SQL Server determine how many rows to return from a query. It is used to limit the number of rows that are returned from a SELECT statement.

The ROWNUM Clause has the same syntax as the TOP Clause, but its behavior is different. When used in a SELECT statement, it will only evaluate for the current row or for all rows in that query’s result set when executed with a LIMIT clause. That is, if there are exactly N rows and the ROWNUM clause is used, only N rows will be returned. If it’s not used, then all rows in the result set will be returned (i.e., once all ROWS affected by the query have been fetched).

In SQL-2005 and SQL-99 (but not in later versions), this behavior can be changed by adding an optional "NOT NULL" clause to the ROWNUM Clause. This is best illustrated by an example:

```sql
select * from newstaffpartition order by staffid, Lastname, firstname, age where staffid > 10
limit 5 ROWNUM(staffid)
```

This will return a result set that only includes five rows.

## The Wildcards

Wildcards are characters used to replace a portion of a string without changing the original text of that string. Wildcards typically come in two forms: Character Numeric Wildcard and Character String Wildcard.

The Character Numeric Wildcard is represented by a percent (%) symbol and can be used when you know that every instance of the specified character must appear within the string, but you don’t care exactly which character will be replaced. For example, given a user name of "Smith," you could use a % wildcard to replace the first character in the string with any character of your choosing. The final result would be smith%.

The Character String Wildcard functions are the same as the Character Numeric Wildcard, except that it allows you to specify a string of characters that can appear in replacement of the targeted character. Thus, you could specify a wildcard that can match any 3 characters in the string. For example, this string: "smith%" will replace smith with the word Smith and % with any word of your choosing. The final result would be Smith.

### How to use Wildcards

You can use the wildcard in the following ways:

- 1. Use a “%” character to specify any number of characters you want. If you wish to substitute for all characters except for the first one, use this: “% %. This can be replaced with any number of characters, but you must have at least one digit, and the percent must be included in the string.

- 2. Using a string of characters to specify the characters that you want to use in the replacement. For example, you might use %a%b%c% as a replacement string, where a, b and c are any three characters.

- 3. Use multiple % wildcards in your query to specify the exact character that you want to be replaced within your query. For example, select * from table where fieldname = %%%.

The general syntax of a wildcard:

Both the Character Numeric Wildcard and Character String Wildcard can be used as follows:

```
|<OriginalString> | <replaceCharacter> | <replaceString1>...<replaceStringm> |
```

The <replaceCharacter> can be any one of the characters listed below. Only one character can be used at a time in this way. So if you want to replace all matches for a particular character, it would look like this: replaceCharacter = ‘%’. You cannot have more than one ‘%’ character in the replace string.

The <replaceString> can be any one of the following combinations: %, %%, %a%, %b%, %c%, a%, b%, c%.

Example:

In the following example, you will perform a SQL wildcard search using the replaceCharacter, replace string combinations, and the Character Numeric Wildcard and Character String Wildcard.

- Step 1: Open a query and enter the following statement in your query window: select * from a table where fieldname like %a%. When you press enter, the query result will display all records in which the letters appear in the field name.

- Step 2: Now, make a wildcard query by replacing % with %%. For example, select * from table where fieldname like %%%. When you press enter, you get all results; hence all records corresponding to a% or b% or c% will be retrieved.

- Step 3: Perform another wildcard search by entering the following query: select * from table where fieldname like %b%. This will get all results related to b% or c% or a%.

- Step 4: Make use of the ‘?’ character in place of any single character. For example, for all fields with a name that begins with s, enter select * from the table where fieldname = ?s. Press enter, and you will get all records that begin with s.

Note: Use the ‘^’ character to match a range of characters. For example, to get all records with a name that starts with s and ends with e, enter select * from the table where fieldname = ?s^e. Press enter, and you will get all records that start with s and end with e.

- Step 5: Using the ‘_’ character as a wildcard allows you to replace any single character with any sequence of characters in sequence. For example, in the field name of a table, you could replace any single character with an underscore or replace a sequence of characters with an underscore. For example, enter select * from the table where fieldname = _%_%_. You will get all records in which the character _ occurs multiple times in the field name.
