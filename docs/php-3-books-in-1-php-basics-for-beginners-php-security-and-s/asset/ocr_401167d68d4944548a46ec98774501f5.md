# The Reflection API

![](bbox=[0.18, 0.17, 0.82, 0.46])

The PHP Reflection API is a collection of functions that allows the programmer to effortlessly inspect the inner structure of classes and interfaces. It makes it straightforward to determine whether a mirrored class defines a certain method or not, or whether the class declares a specified property, as well as whether that property is public, protected, or private.

```
$dinner_Carte = new DinnerCarte;
$reflect_dinner_Carte = new ReflectionClass('DinnerCarte');
echo $reflect_dinner_carte->getName();
```

# OUTPUT:

DinnerCarte

As demonstrated above, DinnerCarte is a class that I built as an example before constructing a new reflector object from the native "ReflectionClass" class. This is the building block around which the complete reflection API is built. It receives as an input argument the Class’s name to be reflected. In the above instance, constructor of "ReflectionClass" class had passed the text "DinnerCarte." This process returns a reflector object with helpful information about the class "DinnerCarte."

Because I'm just discussing the reflection API, the preceding code first calls a method named "getName()," which returns the reflected class's name.
