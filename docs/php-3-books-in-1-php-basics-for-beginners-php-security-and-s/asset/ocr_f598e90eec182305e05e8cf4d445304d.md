Sin: returns the sine function in radians. If a is an integer or a float, it returns the sin of that value. Otherwise, it returns NaN.

Cos: returns the cosine function in radians. If a is an integer or a float, it returns the cos of that value. Otherwise, it returns NaN.

tan: return the tangent function in radians (for example, tan(π/4) = 1). If a is an integer or a float, it returns the tangent of that value. Otherwise, it returns NaN.

Asin: returns the arcsine function in radians. If a is an integer or a float, it returns the arc sine of that value. Otherwise, it returns NaN.

acos: returns the arc cosine function in radians. If a is an integer or a float, it returns the arc cosine of that value. Otherwise, it returns NaN.

atan: returns the arctangent function in radians. If a is an integer or a float, it returns the arctangent of that value. Otherwise, it returns NaN.

sinh: returns the hyperbolic sine of its argument (for example, sinh(2) = 0.9749999999999999). It returns the hyperbolic sine of a number if x is an integer or a float and y is 0 or negative. Otherwise, NaN is returned.

cosh: returns the hyperbolic cosine of its argument. It returns the hyperbolic cosine of a number if x is an integer or a float and y is 0 or negative. Otherwise, it returns NaN.

tanh: returns the hyperbolic tangent function in radians (for example, tanh(π/4) = 0.23). It returns the hyperbolic tangent of a number if x is an integer or a float and y is 0 or negative. Otherwise, it returns NaN.

asinh: returns the hyperbolic arcsine function in radians. It returns the hyperbolic arc sine of a number if x is an integer or a float and y is 0 or negative. Otherwise, it returns NaN.

acosh: returns the hyperbolic arc cosine function in radians. It returns the hyperbolic arc cosine of a number if x is an integer or a float and y is 0 or negative. Otherwise, it returns NaN.

atan2: returns the arctangent of its two arguments. Returns a value in radians between 0 and π/2, unless both numbers are NaN.
