Let us now add this application to the repository. enter your prompt, by substituting ' your_user_name ' with your personal username:

```
$ svn import carte_proj file:///Users/user_name/svnrepos/carte_proj -m "Initial import"
```

**output:**

Adding Staff.PHP

Committed revision 1.

This completes the import of the folder 'proj_restaurant' into the repository 'svnrepos'. A "revision" is a unique number that identifies each version in the repository. Always include a brief description of the changes you made to the repository ('-m'). Checking Out Files from Subversion Now let’s retrieve, or “check out” a copy of the file to work on from the repository:

```
$ svn checkout ile:///Users/user_name/svnrepos/carte_proj-copy
```

The result will list all contents that have been uploaded ('A') to our working-copy: A **proj_restaurant-copy/Employee.PHP** Revision 1. has been checked. Navigate the directory of working-copy by entering:

```
$ cd carte_proj -copy
```

Then, at the terminal, double-check the data of working-copy:

```
$ ls -a1
```

This would return the directory, along with any hidden files:

+   - .
+   - ..
+   - .svn
+   - Staff.PHP

remember about the hidden directory '.svn'. It stores certain metadata subversion, such as the repository's name, so you won't have to input it hereafter.
