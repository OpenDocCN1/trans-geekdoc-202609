
### 5. Run custom functions on the information in an array

The information stored in a $_POST array is not limited to the five types of data listed above. It can include whatever you need it to store, whether it's HTML or plain text. To run a custom function on the value of this variable, start with the following line:

```php
$_POST['myArrayElement'] = myFunction($_REQUEST['myArrayElement']);
```

Here, myFunction is any function that you want to run on your array element. Then, when you need access to the value of this element, use the following syntax:

```php
echo myFunction($_POST['myArrayElement']);
```

### 6. Determine what information was submitted in the form

When you display a form that accepts user input, it is good practice to verify that all required fields have been submitted by the user. To do this, check the $HTTP_POST_VARS array, which contains any information submitted by the user.

```php
$HTTP_POST_VARS['name'] = reqval('name');
echo "Hello $name";
```

The above code would display Hello World if no name was entered into the form. If a name was entered into the form, it displays Hello John Doe or similar.

### Limitations of PHP $_POST Variable
The value of the $_POST array is limited to one entry per post in an HTML form.

## Interactive PHP Programming

This section is about how to manipulate the PHP super globals and use them for interactive programming. Interactive programming is a type of programming that helps you to create programs that update their own data during the course of their execution. A lot of people run into a very common problem with interactive PHP programming: it is so fun and easy to write the program that suddenly you have written yourself into the corner and want to use some kind of loop. More often than not, the problem is that you have overused the "eat your green eggs and ham" operator and are no longer in control of what your program does.

But what if you could use this awesome language feature to create your own loops with as little work as possible? You’ll still need to create some code to ensure that the variables you wish to update are updated correctly every time. But because PHP is a dynamic language, you can use these super globals within those loops to allow your program to react without any extra code.

This kind of programming is called interactive programming. It is appealing because it allows you to have an infinite loop without ever having to write any extra code for it. In other words, you can always have your program update itself automatically, just by writing a little code.

The way the PHP interpreter works is that you can use super globals to make a variable update automatically. For example, let's say you want to make your program think it has infinite line. It just keeps on going and prints "Hello World" over and over again until you tell it to do otherwise. ## PHP Date and Time

Working with time and dates in PHP can be a hassle. Thankfully, there are some pre-built globals that make it easy to work with dates and times. Here is a list of the superglobals available in PHP's date_time package.

- Date: The current date and time in Unix epoch seconds since 1 Jan 1970 00:00:00 UTC. It's stored as the number of days since 1 January 1970 00:00:00 UTC (for example, 1985202).
- Time: Since the epoch, the current time is seconds.
- Microtime(): Time in microseconds since the epoch (same as microtime()).

Now is a good time to recognize that PHP uses Unix-based conventions when defining dates. Here's how date and time in PHP are formatted: YYYY-MM-DD HH:MM:SS GMT offset, with the GMT offset being three digits representing the number of seconds before or after UTC.

The number is most accurate when you are dealing with microseconds.

In the previous example, the date string was formatted as: "2002-10-15 18:36:08 GMT".

In my code, I look for this date and then check to see whether it's a valid date. If it's not, I return false. You have to check your MySQL date format to find out what it should be formatted as.

First, let's create a new file called valid_date.php.

```php

if(!isset($stamp)) { echo "The date stamp is not valid.\n"; return false; } // Display the date and time. echo "The date and time is: ".date("H:i:s", $stamp)."\n"; ?>
```

To check the validity of a date, it's just a matter of checking whether the $_POST['date_expires'] variable is not null.
