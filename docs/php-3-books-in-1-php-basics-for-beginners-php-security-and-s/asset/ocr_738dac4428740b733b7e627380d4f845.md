You can fetch data from the database one row at a time by using the mysqli_fetch_array( ) function. The mysqli_fetch_array( ) has a return type of either a string or an object. If you receive an object, you will need to cast it as an array or choose to ignore the object.

The command mysqli_report( ) is used when you want to check if there are any warnings that might break your code. For example, if you set up a query not specifying the primary key, you'll receive a warning.

For loop, logic can be used to run queries again and again, such as an INSERT query or an UPDATE query. A common mistake is that it isn't always necessary to close the connection. For example, if you want to update the same table more than once in a script and leave your connection open, this is fine.

mysqli_close( ) is used to close the connection. In order to close the connection and leave it open, it is necessary to set the mysqli_multi_query flag on the connection before running the query.

# MySQL Functions

You can use three functions to fetch data:

mysqli_fetch( ), mysqli_num_rows( ) and mysqli_result( ). The first two are used to check the type of information you receive.

mysqli_fetch_array( ) returns an array, or a specific object. If you use mysqli_fetch( ), it will return an integer with the number of rows returned by the query. If there are no rows, you can check if mysqli_errno( ) is equal to zero.

mysqli_num_rows( ) returns a string that contains the number of rows in the table, or -1 if there are no rows. A query may have MySQL's built-in LIMIT clause, which allows you to specify how many rows should be returned.

mysqli_result( ) returns a string containing the number of rows that you specified in your query, or mysqli_affected_rows( ) if there is no LIMIT statement specified.

mysqli_connect( ) and mysqli_query( ) will also return an error if a query has been executed and there are errors. If you want to get the error message, you can use the mysqli_errno( ), which will return a string containing the MySQL error code.

Functions that can be used to join data are: mysqli_num_fields( ) and mysqli_field( ). The first function returns an integer indicating the number of fields in the row.
