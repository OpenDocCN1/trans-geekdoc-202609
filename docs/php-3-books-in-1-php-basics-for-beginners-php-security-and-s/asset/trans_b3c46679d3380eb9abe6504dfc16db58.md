## 显示类

现在我们已经构建了演示模板，完成 Show 功能视图还需要一件东西：一个名为 Display() 的实用程序类。Display 类负责组装模板文件，并在需要时写入来自关联模型 的动态数据。Display 类将使用从 Template 类实例化 的对象将此动态数据广播到静态模板文件。此类将保存为 show/views 目录中的 Display.PHP。
