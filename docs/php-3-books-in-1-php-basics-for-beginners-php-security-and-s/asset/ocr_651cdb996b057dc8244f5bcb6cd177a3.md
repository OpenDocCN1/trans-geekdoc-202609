# Updating PHP include path

by introducing pear to the PHP include path inside the "/etc/PHP.ini file," you can inform PHP
about the location of PEAR-library.

Mac doesn't comprise the said file. execute the respective prompt in the Console to generate the
file:

```
$ sudo cp /etc/PHP.ini.default /etc/PHP.ini
```

Then,via vi or TextMate, update the PHP include path. In /etc/PHP.ini, look for the proceeding
code:

```
;include_path = "/PHP/includes”
```

Delete the "semicolon ;" at the start of the code, then replace it with the PEAR library path.

```
include_path = "/usr/local/PEAR:/PHP/includes”
```

Save the file /etc/PHP.ini. Uncheck and recheck System Preferences/Sharing/Web Sharing to
reboot the Apache web server.

Then, in an internet browser, navigate to http://localhost/[your user name]/index.PHP. Look for
"include path" and double-check the

The path contains "/usr/local/PEAR." because of the installation of PEAR
