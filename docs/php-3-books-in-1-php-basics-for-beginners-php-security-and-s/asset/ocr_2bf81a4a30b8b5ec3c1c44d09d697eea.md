# PHP Arrays

![](bbox=[0.17, 0.16, 0.83, 0.42])

Arrays can be defined as a data structure in PHP that stores multiple items at the same time. A PHP array is an ordered and indexed list of values, where each item stores an integer, string, or other data type. The main purpose of arrays is to store different elements of the same type. In other words, it’s a group of related items grouped together into one common location. One of the advantages of an array is that it can be easily manipulated, which means that a simple way to create an array isn’t possible.

Arrays can be defined as a table, list, or matrix. A table is a set of rows and columns, a list is more than one type of data, and a matrix has multiple types. For example:

+   1. An array that stores numbers
+   2. An array that stores a list of integers and an array that stores a list of strings
+   3. An array that stores a set of integer, double-time, date, and Boolean values.
+   4. Whenever you want to store more than one type of data into an array, you must use a variable to define the type of data being stored in that variable.

A variable can be defined as an array of a variable. In other words, a variable can be defined as an array of a variable into which another variable is being stored. Because of this, we can change the type of data being stored in that variable.
