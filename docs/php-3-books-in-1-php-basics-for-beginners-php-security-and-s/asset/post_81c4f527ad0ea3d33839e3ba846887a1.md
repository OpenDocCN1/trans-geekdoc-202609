## PHP Classes

A PHP class is a way to group code together. The class can be used to define certain functions, called methods, which allow you to interact with the data that is stored in that class. This means that when you use a class, the name of the function will be preceded by a '->'. For example, suppose we had a Dog class and wanted to add an edit function. This can be done like so:

```
$dog->edit
```

Here, we have passed the name of the function (edit) to the Dog class. Inside the edit function, we will now be able to use methods to change the data.

Now, if you want to use this class in a script, you won't have to worry about assigning variables or creating a new class for each script. You can just call this single Dog class from any script that you create without having to worry about adding variables or creating new classes.

```
$dog = new Dog
```

This will create a new instance of the Dog class and assign it to the 'dog' variable. You can now use this variable to call methods on the Dog class. For example, if you wanted to change what breed of dog you have, all you have to do is:

```
$dog->breed = 'Pitbull'
```

And now, your dog will be considered a Pitbull instead of whatever breed it was originally.

Note that this method is an example, and there are some things that you may want to do differently. The most notable difference is that you should always try to pass properties as properties and not reference them directly.

## Why should you use PHP Classes?

The main uses of classes are to make your code easier to read, write and organize. They work by grouping variables, functions, and other information together so that you can access all of the data related to a certain entity in one place. This makes reading your scripts much more convenient because you don't have to go looking through the script for a variable every time you want to use it. All you have to do now is take a look at that class. This really separates PHP from other languages because it gives you a huge advantage over other languages that require you to specify the variable all the time.

This makes your code easier to read and gives you a lot of freedom. It allows you to use functions in different ways that are not available in other languages. You have the flexibility to use functions in a way that will make your script better for whatever problem you're trying to solve.

It also is extremely easier to organize your scripts in a highly organized manner. The class allows you to divide up your code into multiple files, which makes it easier for you to find anything that you need in the future. This means that your code isn't as cluttered and harder to read as it would be if you were just using one big script that had everything in it.

Finally, one of the greatest parts of using classes is the fact that they allow you to create your own functions and procedures. This can be very useful in large projects. For example, imagine that you are building an e-commerce website with hundreds of products. You will likely have a lot of different functions to deal with each product you sell. You could create your own class with all the functions related to products. This would allow you to keep track of every product in one place instead of having to look through a whole bunch of different scripts and files.

## Class Objects

Class objects define a class of objects which act similarly in many respects. For example, all cars are capable of driving and must have four wheels. These two properties are defined with class variables that are shared by every car.

Class objects should be used when you want to group similar types of objects together or when you want object-oriented programming to work with your code. Class-based languages like PHP provide the power and flexibility needed to create changing and flexible code easier than ever before.

In a class-based language, a class is an object that defines the behaviors and attributes of a type of object. Class-based programming allows you to create your own model of objects that can change over time and even be reused by different programs.

A class is like a blueprint for an object. It defines the attributes, behaviors, and relationships between its variables. A class does not create any objects itself; it merely defines the variable values for objects that are going to be created later on in the program. PHP provides the OOP capabilities needed to create an object-oriented world of changing and flexible code.

To create a class, put your variables inside the class. Then, you tell the PHP interpreter within the class what function to execute for each of the variables in that class.

Instead of putting all your code into a separate script file, you write everything in one script file. However, it depends on how you would like to use that script file. You can use it as a module or as a component.

A module is a set of code that can be reused in different programs and run independently from any other modules. A component is used in one specific program and does not exist outside that program.

Class objects may also be more secure because you only have to worry about one class and not many different classes.

PHP provides the OOP capabilities needed to implement class variables, method functions, and object creation. To define a class in PHP, you must first use the keyword "class," followed by your class name. Class variables are defined using the keyword "public" instead of "private."

Class variables are always capitalized and are prefixed with a "$". Class variables contain data that gets shared amongst all the objects of a class. For example, all cars have the same horsepower. However, the horsepower can change from car to car eventually. Class variables allow you to define your data values once and reuse them for many different objects in your program.

When creating an object, you must first tell your program which class it is going to be a part of by using the keyword "new." Then you can create a new object using the keyword "new." You can access public class variables and public methods by accessing the object with the "$" sign. For example, $myCar->hp;. Public methods are functions that you will use to interact with that object.
