We'll need to employ Apache's .htaccess URL rewriting for our Restaurant Carte Management (MVC framework) application.

We must construct a .htaccess file (take notice of the time at the commencement). This file will now be copied to the directory of roof in the website. On a directory-by-directory or site-by-site basis, this file outlines how Apache and its components are configured. In this example, .htaccess will appear as follows:

```
Options +FollowSymLinks
RewriteEngine on
RewriteRule ^([a-zA-Z-]*)/?([a-zA-Z-]*)/?([a-zA-Z0-9]*)?/?$
index.PHP?controller=$1&action=$2&id=$3 [NC,L]
```

The first two lines instruct Apache to accept our newly created rewriting instruction, that we'll build with the RewriteRule function.

Starting with a regular expression, this command progresses to a generic URL with variables. This rule indicates that Any URL requested by a user which fits this standard expression will get translated to a specified true URL at the website server level. This conversion won't get noticed by the user. Any matches found within the round brackets of the standard expression are allocated to a variable in a left-to-right manner. A dollar is the first variable, followed by a two-dollar variable, and so on. Furthermore, anything following the controller can be omitted from the URL using this rule (the question marks handle this).
