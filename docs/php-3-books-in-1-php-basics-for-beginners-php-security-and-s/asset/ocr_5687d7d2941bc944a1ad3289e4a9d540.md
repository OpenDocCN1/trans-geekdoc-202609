# 11. Using The sort() Function To Sort A Single Array Element

The eleventh method for working with arrays is using the sort() function. This function will sort an existing array into a new array. It will also return the sorted array for access in your applications. The following is the syntax for calling this function:

```
```php
sort($array);
```
