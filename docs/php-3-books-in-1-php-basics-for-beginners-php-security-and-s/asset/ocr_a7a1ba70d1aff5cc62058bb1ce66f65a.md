# # String Functions

In PHP, string functions are written with the str_ or htmlentities() function. They manipulate strings of text and deal with edge cases that can't be solved by methods like substring().

# ## Benefits of String Functions in PHP

There are a wide variety of string functions in PHP which can provide you with many benefits. Some are explained below:

+   1. They are very helpful in formatting text for presentations.
+   2. They are useful in validating your form data because they can deal with specific cases.
+   3. They can be used to develop template files and make them semantically correct without the need of using some form of validation tools.
+   4. You can create different types of strings using string functions which is a great way to separate the types of strings used in your code.
+   5. After using string functions, you can easily compare two strings and know which one is longer or shorter than the other by comparing values stored in variables.
+   6. You can change the case of any string using string functions.
+   7. You can add additional information about a string by passing it to the str_replace() function.
+   8. They are created in the core library and not in 3rd party libraries, making them more secure and stable with regards to performance and security.
+   9. They have a very large number of users because they are well-known functions used by almost all PHP developers without any trouble.

# ### 1. str_replace()

str_replace() function is used to search and replace one string with another. If the function does not find the first string, it will not change the original string. str_replace() always returns a new string.
