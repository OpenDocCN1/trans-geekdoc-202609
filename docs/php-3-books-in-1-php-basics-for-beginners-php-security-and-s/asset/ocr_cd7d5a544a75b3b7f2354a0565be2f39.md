# The SQL AND, OR Operators

The SQL AND OR operators are often used in a SELECT statement for more than just checking for the presence of one or the other value. Many times, the SQL AND operator is used to check if both conditions are true before proceeding with an action. For example, you might use it to find records that have been seen in a table by querying:

```
SELECT * FROM visitors

WHERE visitors.userid=1 AND visits > 3; - Executed on Table visitors
```

In this case, a userid of 1 is used to find certain records. A second condition is also added, that visits must be greater than 3. The result set will include any records where the userid is 1, and the number of visits is greater than three. The "AND" operator is used in this case to combine conditions together.

In a similar way, the SQL OR operator is useful for separating conditions. A common way to use the OR operator is to find all of the records that match one condition or another:

```
SELECT * FROM visitors

WHERE visitors.userid=1 AND visits > 3 OR visits > 4; - Executed on Table visitors
```

In this example, any records where the userid is 1 and visits are greater than 3 will be included in the result set. In addition, the result set will include any records where the userid is 1, and the number of visits is greater than four. The OR operator is useful for separating out conditions that you want to be in the result set.

The SQL AND and OR operators are used in a similar way to how they are used in mathematics:

In mathematics, an AND operator provides a condition such that for both conditions to be true. In SQL, this translates into requiring both of the conditions to be true before proceeding with an action. In mathematics, the OR operator is used to find all records that match either condition. This translates into SQL searching all records that match either of the conditions.
