The session data is still stored in the super global array $_SESSION when a session is deleted. Only when the script ends are the super global $.,_SESSION cleared. S SESSION super global data can be erased by initializing it with an empty array before the script is ended or the user quits the session.

```
$_SESSION=array();
```
