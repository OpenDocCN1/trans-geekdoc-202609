# # Interfaces

The term "interface" refers to a collection of templates. The interface's purpose is to provide you with flexibility by forcing your class to implement several interfaces while avoiding multiple inheritances. As you may recall, PHP does not support multiple inheritances. Class that uses an interface commits to implement all of the functions mentioned in it as a condition of doing so. In other words, every function in the interface must be implemented by classes that implement an interface.

Because PHP is a "loosely typed" Program, classes inherit the features of the interface they implement and any classes they extend.

Interfaces offer a method known as "programming to the interface." The concept is that programming logic is based on the interfaces of the objects being used, rather than on their internal implementation details.

By programming to the interface, you can lessen your dependency on implementation specifics and boost the reusability of your programs.

It enables the programmer to modify the system's behavior later by simply substituting another object that implements the same interface for the one now in use.

the interfaces are identical to the classes in which it permits the addition of code but does not require it. The names and arguments of methods can be defined in an interface, but not their contents. A class may implement many interfaces.

# ## Interface and Implements Keywords

The interface keyword is used to specify an interface, while the implements keyword is used to implement it.

```
```php
interface MyInterface {
}
class MyClass implements MyInterface {
}
```
```

We can define the methods in the interface, the same way as they are in a class, except for the body (lines written in the braces).

```
```php
interface TestingInterfaceProgram1{
public function someFunction();
}

interface TestingInterfaceProgram2{
public function someOtherFunction();
}
```
