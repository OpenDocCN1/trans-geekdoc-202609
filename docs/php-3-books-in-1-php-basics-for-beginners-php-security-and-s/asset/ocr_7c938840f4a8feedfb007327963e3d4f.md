# The Pre-Existing Exception Class

An exception is a specific object that is constructed from the Exception class in PHP or a class that helps in the extension of the PHP Exception class. Exception objects are used to keep track of and report on errors. The Exception class's Object() [native code] method receives two additional arguments: a text-message and an erroneous code.
