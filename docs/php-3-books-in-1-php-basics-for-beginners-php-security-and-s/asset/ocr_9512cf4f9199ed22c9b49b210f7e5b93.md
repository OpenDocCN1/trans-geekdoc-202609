# **Uses of PHP $_POST Variable**

+   1. Store information from a web form
+   
+   Using the $_POST array, you can store the name, address, and comments submitted by users on a form without having to display the form again on another page. The information will be saved to an array called $_POST.

+   2. Search element of an array
+   
+   This is one of the most useful features of the PHP $_POST variable. Its search element feature allows you to search an element of an array by its value.

```
```php
$_POST['search'] = "Google";
echo $_POST['search'];
```
```

The above code displays Google in the browser.

+   3. Update HTML elements and attributes dynamically
+   
+   This is one of the most common uses of the PHP $_POST variable. You can update the value of an HTML element or attribute by assigning them a value from the $_POST array. Forms that accept names, addresses, or other information from users should use this feature to retain their state and allow users to change them if desired.

```
```php
$_POST['name'] = $_POST['name'] . ' ' . $_POST['lastname'];
echo "Hello $name";
```
```

The above code concatenates the first and last name of the user and displays Hello $first name
<br> Last name.

+   4. Retrieve information stored in a database
+   
+   While it is not necessary to retrieve information from a database, most web applications use databases for storing non-HTML data. The information stored in the database is available to PHP through the $_POST array, just like any other piece of information on a website. To access this data, use the method demonstrated in the two sections above.
