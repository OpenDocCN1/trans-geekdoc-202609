Function arguments allow a programmer to use different variables within a function. In PHP, arguments are placed inside parentheses next to the function itself. One example is below:

```
<?php
echo "Argument 1";
echo "Argument 2";
echo "Argument 3";
function my_func($arg1) {
} ?>
```

This example uses the function my_func that takes one argument that is named $arg1. This variable can be used inside the my_func function. It is also possible to assign default values to arguments if they are not provided in the code by the user. This will be saved as a default value and will only be used if no other value is given. The example below shows this feature:

```
<?php
echo "Default Arg1: ";
echo $arg1;
?>
```

This example uses two different functions. One function has an argument that is named $arg1 and has a default value of one. Another function does not have a default value defined and takes one argument. This is an example of how the first function's variable can be used in the second function. The function will only be executed if no other argument is used inside the function.
