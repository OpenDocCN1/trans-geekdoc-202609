The information stored in a $_POST array is not limited to the five types of data listed above. It can include whatever you need it to store, whether it's HTML or plain text. To run a custom function on the value of this variable, start with the following line:

```
```php
$_POST['myArrayElement'] = myFunction($_REQUEST['myArrayElement']);
```
```

Here, myFunction is any function that you want to run on your array element. Then, when you need access to the value of this element, use the following syntax:

```
```php
echo myFunction($_POST['myArrayElement']);

# 6. Determine what information was submitted in the form

When you display a form that accepts user input, it is good practice to verify that all required fields have been submitted by the user. To do this, check the $HTTP_POST_VARS array, which contains any information submitted by the user.

```
```php
$HTTP_POST_VARS['name'] = reqval('name');
echo "Hello $name";
```
