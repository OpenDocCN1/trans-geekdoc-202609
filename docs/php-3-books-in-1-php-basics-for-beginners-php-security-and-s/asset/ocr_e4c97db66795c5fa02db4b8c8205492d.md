# Object-oriented Programming

![](bbox=[0.167, 0.177, 0.833, 0.521])

Object-Oriented Programming is a coding paradigm where the application is broken up into three distinct groups: Data, Objects, and Methods. Data are represented as objects that typically contain fields such as age, location, height, and weight. Objects contain methods like updateLocation(), createPerson(), and getNumberOfParents(). The implementation of each method can differ, but their function remains the same for each object.

# PHP Classes

A PHP class is a way to group code together. The class can be used to define certain functions, called methods, which allow you to interact with the data that is stored in that class. This means that when you use a class, the name of the function will be preceded by a '->'. For example, suppose we had a Dog class and wanted to add an edit function. This can be done like so:

```
`$dog->edit`
```

Here, we have passed the name of the function (edit) to the Dog class. Inside the edit function, we will now be able to use methods to change the data.
