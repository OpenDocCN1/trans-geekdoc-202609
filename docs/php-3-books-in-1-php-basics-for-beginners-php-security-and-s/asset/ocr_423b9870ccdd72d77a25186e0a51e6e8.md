# 1. WordPress uses PHP

Many bloggers use this popular blogging system to host their blogs. The reason why WordPress uses PHP is that it's an open-source, easy-to-use, and extensible language that's very popular with both users and developers.

# 2. Drupal and Mambo use PHP

Also a popular open-source CMS, Drupal uses the PHP language extensively in order to create websites for its users. Mambo is another open-source application that relies heavily on PHP, especially for its database backends.

# 3. Many other blogs, forums, and social networking sites use PHP

There are dozens of other blogs, forums, and social networking sites that use the PHP language, including WordPress.net and Digg.com. The reason why these websites use PHP is that it's a very functional language that's straightforward to learn because it's based on an easy-to-use scripting language called JavaScript (JScript).
