# Defining a Function

A function is a collection of code that performs a specific task. The first step in defining a function is to give it a name. This can be any word or short phrase, but it should be descriptive enough so that another coder can understand what the function does by reading its name alone. A computer will not execute code until it reaches the opening curly bracket () and sees the instructions "function." In order to add instructions for this particular function, type "function" followed by the name given to this new function. Finish with a closing curly bracket, }. The first instruction in any function will have the same name as the function to which it belongs. The second instruction within the curly brackets will begin with the name of the function. The other instructions within this function can be given any name not used anywhere else within PHP. As a result, you can have an additional section of code outside of your main program file, one that does not really "belong" within a program's functions and is only for your use.

It is possible to include as many instructions in a function as you want, but be careful not to include too many, or the code might become hard to follow. If you do encounter a section of code that seems unnecessary within your function, it can be deleted without it damaging the rest of your code. When you have finished writing the code for this function, you must then return to your main program block in order to tell PHP that you are done with this function.
