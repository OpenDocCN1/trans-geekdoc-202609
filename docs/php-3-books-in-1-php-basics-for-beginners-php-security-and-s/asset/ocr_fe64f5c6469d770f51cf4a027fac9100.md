# Immutable Arrays

PHP offers a feature called "Immutable Arrays," which makes sure that arrays never change their contents. This feature is useful in particular when compiling programs and while doing debugging. Immutable arrays cannot be changed after they have been defined. The 4 methods of defining arrays are:

+   1. Array()
+   2. Array(HASH)
+   3. Array(ARRAY)
+   4. Array(REFERENCE)

# Undefined Arrays

Sometimes an array is created, but it is never used. In such an instance, we say that the array has been defined but never used or that the array has been created but not assigned a value to it, which means that the array does not contain any values and is called an undefined array. The following example shows how to create an undefined array.

Example:

```
```php
echo $undefinedArray;
```
```

Results: This code will not show any error, but the undefined array is empty. The result is different when the reference type is being used since it will show an error. This might be useful for creating arrays that are never used, but it also means that you can create an array with a value at some point and then not use it, which means there won't be any way to retrieve the value later. We can use the array_init() function to create an undefined array.

Example:

```
```php
$array=array_init();
$array2 = array("one", "two", "three");
```
```

The code above will create the following undefined arrays: $undefinedArray, $undefinedArray2 and $undefinedArray3. We can see here that we have three unused arrays created in which we have the values one, two, and three at the time that we are executing that code.
