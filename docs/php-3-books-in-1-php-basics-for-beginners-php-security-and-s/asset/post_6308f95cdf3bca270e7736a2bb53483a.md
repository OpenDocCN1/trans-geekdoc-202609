### Comparison between a global variable and a superglobal variable

Global variables are declared within the script/function, whereas superglobal variables are not.

Global variables can be accessed through the usual array indexing operator and access their values without having to refer to them by their official names.

Superglobals can only be accessed through the register_globals, which is a function added to your PHP code from the php.ini file.

Global variables provide better performance than superglobals because they are stored in your script and take less memory.

Superglobals are a powerful feature, even though we have to use a dollar sign before using them. One thing to note is that some parts of the PHP parser may use certain superglobal variables without the dollar sign.

In some cases, when we create a global variable and it is used in other scripts and functions, the global variables are actually stored in the same file as our script, which may cause problems later on with writing each script in its own file, which is recommended for security reasons.

### Advantages of using PHP $_SERVER

- **1. Accessing $_SERVER from an external file**

  When you want to access a specific variable from an external file, you can do so by just adding the variable to the local variables while executing your script. You need not specify its type as long as it is of a scalar datatype. In previous editions of the PHP programming book, this was referred to as magic quotes and braces.

- **2. Anonymity**

  As long as the information you are sending is not sensitive (such as passwords, credit card details, and so on), there is no risk of someone else getting to know what exactly your server is doing. This can help ensure privacy and security.

- **3. Error Reporting**

  This gives you a very quick way of reporting errors to the browser, and it can be a faster way of reporting an error than logging in to each website individually and manually typing an error message into each site's error log file.

- **4. Security**

  You can reset a user to an anonymous guest or disable scripts from running from .htaccess files on Apache servers. This helps prevent some well-known attacks such as cross-site scripting, cross-site request forgery, SQL injection, and other malicious attacks against your website.

### Disadvantages of using PHP $_SERVER

- **1. No type of safety**

  As you are dealing with data coming from the browser, there is no type checking being done, and you need to use try-catch blocks to prevent your script from crashing.

- **2. HTTP Request and Response Variables**

  There is no way to know the details of an HTTP request, such as the request method or the IP address or domain name of who is viewing your pages. This information is only available after you get a response back to your script. You must then parse the response and get this information.

- **3. Unknowing information**

  Once the information is transmitted to your web server, it will be parsed by the web server and sent to the browser. In cases of cookies, DNS translations, and other features, other people on your network may have gotten them before you.

- **4. HTTP vs. HTTPS**

  The HTTP engine does not protect against somebody tampering with data being transmitted from a client as it is just a plain text HTTP protocol. On the other hand, HTTPS over SSL adds additional security layers for secure communication channels between servers and clients.

- **5. Cross-Origin Resource Sharing**

  If you are working on multiple machines with additional groups of people, all of them may have access to the same information without your knowledge. If all these people have access to your scripts, there is no way you can control who sees what information and what they do with it.

## PHP $_POST Variable

The $_POST variable is a predefined PHP global variable that stores information submitted by the form. The $_POST variable is typically used in an HTML form to allow users to submit information, such as name and address, without refreshing the page or returning to another page.

The $_POST variable is set when an HTML form is processed by the PHP engine. Each post in a form has its own dedicated entry in the $_POST array.

The syntax for setting a PHP variable that's usable as an array key is:

```php
$key = "value";
```

To access this value, use the syntax:

```php
$_POST['key']
```

You can use the $_POST array to pull information from a form, but you should use the $_GET array to retrieve information that a user has entered into a URL.

### Uses of PHP $_POST Variable

- **1. Store information from a web form**

  Using the $_POST array, you can store the name, address, and comments submitted by users on a form without having to display the form again on another page. The information will be saved to an array called $_POST.

- **2. Search element of an array**

  This is one of the most useful features of the PHP $_POST variable. Its search element feature allows you to search an element of an array by its value.

  ```php
  $_POST['search'] = "Google";
  echo $_POST['search'];
  ```

  The above code displays Google in the browser.

- **3. Update HTML elements and attributes dynamically**

  This is one of the most common uses of the PHP $_POST variable. You can update the value of an HTML element or attribute by assigning them a value from the $_POST array. Forms that accept names, addresses, or other information from users should use this feature to retain their state and allow users to change them if desired.

  ```php
  $_POST['name'] = $_POST['name'] . ' ' . $_POST['lastname'];
  echo "Hello $name";
  ```

  The above code concatenates the first and last name of the user and displays Hello $first name <br> Last name.

- **4. Retrieve information stored in a database**

  While it is not necessary to retrieve information from a database, most web applications use databases for storing non-HTML data. The information stored in the database is available to PHP through the $_POST array, just like any other piece of information on a website. To access this data, use the method demonstrated in the two sections above.
