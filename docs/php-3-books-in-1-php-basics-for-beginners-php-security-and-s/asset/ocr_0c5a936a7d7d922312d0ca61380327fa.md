In PHP, you can use 3 types of inheritance:

Classes: A class is a template that defines the structure of its child classes. The child class inherits all the methods and variables from its parent class.

Superclasses: A superclass is a class that extends another class. It has all the properties and methods of a parent class. The properties and methods of the parent are not inherited by the superclass. The superclass can override any function (method) or variable of the parent class.

Interfaces: an interface is a model for interchangeability, which is a set of behavior-related properties. An interface does not contain the implementation details and does not provide specific functionality.

# Inheritance Classes

There are basically two types of inheritance in PHP:

Implementation Inheritance: The child class inherits behavior from the parent class.

Behavioral Inheritance: The child class inherits implementation details but may choose to override those implementations with its own. Implementation inheritance is essentially the default behavior in PHP. In either case, a superclass inherits all properties and methods from a base class (parent) and does not have any new properties or functions added by the derived classes (children).

The syntax to inherit a class is:

```
class Superclass{ }
class Child extends SuperClass{ }
```

The example below shows a demonstration of inheritance in PHP. In this example, the class "Child" inherits the variable $age and method "showAge" from the parent class "Person." Any new variables or methods that would be added to this class should be placed after the declaration of its superclass. This is a way to ensure that the new variables and methods are not overwritten by the variables and methods of the parent class.

Notice that the child class is declared with "extends" at the beginning of the class declaration. This makes the child class a sub-class, and it inherits all properties and methods from its parent class. PHP calls the superclass a "base class." Since the base class is always first in a class, it's called "the base" or "the superclass." The parent class is "the base class" in the statements that set values for inherited properties.

```
<?php class Person { var $name; var $age; function showAge(){ echo($this->name, $this->age); } } class Child extends Person{ function showAge() { echo("Child: $this->age"); } } ?>
```
