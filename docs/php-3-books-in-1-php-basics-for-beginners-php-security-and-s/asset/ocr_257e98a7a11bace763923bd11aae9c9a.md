# Types of Cookies in PHP

There are many types of cookies in PHP. I will explain the most important ones.

+   1) Session Cookies (session_id()): In order to make a session (a transaction), you need a session ID that is unique for every session. This function returns the unique ID for a session.
+   
+   2) Set-Cookie: This function creates a cookie, which can be stored in the user’s browser. If you save this code in a script called test.php, it will send the cookies that it created to all users who visit the page.
+   
+   3) Cookie: This function retrieves a cookie from a user’s computer and stores it in an array for future use. If you save this code in a script called test.php, it will remove the cookie from the browser of all users who visit the page. Cookies are stored in a browser as a string (text), and they can be up to 4Kb in size.

If you want your cookies to be persistent then use this code:

```
Set-cookie: class_name="session_id=12345"; path="/"; expires=Sun, 25-Jan-2015 13:59:59 GMT; domain=".your_site.com";
```
