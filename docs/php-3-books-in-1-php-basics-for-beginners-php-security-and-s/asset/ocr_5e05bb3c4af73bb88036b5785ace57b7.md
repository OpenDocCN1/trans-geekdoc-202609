# 3. ***bool_escape()***

bool_escape() function is used to convert the characters in any string of text that starts with a '-' or a '+' sign. The original text will be returned, and no changes will be made to it. The bool_escape() function should not be used if you are looking for consistent results every time.

# 4. ***strtoupper()***

strtoupper() function is used as an alternative to strtolower(). It is used to convert the character into a string of text which starts with an uppercase character to lowercase. strtoupper() returns the lowercased version of the character.

# 5. ***whitespace_strip()***

whitespace_strip() function is used to remove all spaces from a string of text in order to make it look consistent and neat. The original text will be returned, and no changes will be made to it if the whitespaces can be found in the data supplied.

# 6. ***str_pad()***

str_pad() function is used to remove additional characters at the end of a string. If the string being passed to str_pad() is longer than 255 characters, only up to 255 characters are removed. The original text will be returned, and no changes will be made to it if no spaces can be found in the data supplied.

# 7. ***strlen()***

strlen() function is used to find out how many characters are in a string of text. The size of the original string is returned. If the string being passed to strlen() is longer than 255 characters, only up to 255 characters are returned.

htmlentities() function is used to convert text into HTML entities according to computer specifications for HTML encoding/decoding and then return a new string of text without any changes
