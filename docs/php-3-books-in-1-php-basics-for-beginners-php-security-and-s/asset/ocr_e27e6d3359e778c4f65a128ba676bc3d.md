> "I want to make my program have no limit on the number of iterations and loop forever."

For interactive programming, there is a simple trick that works like a charm: call set_time_limit() at the end of your program or close your script. This will create a statement called at that will stop running the program but allow it to keep on running in a loop until you tell otherwise. The reason this works is that it allows you to create an infinite loop within your program. So you can use set_time_limit() to call proc_open() to call print() to call dd() and so on and so forth. If you don't believe me, try running the following code:


# PHP Date and Time

Working with time and dates in PHP can be a hassle. Thankfully, there are some pre-built globals that make it easy to work with dates and times. Here is a list of the superglobals available in PHP's date_time package.

Date: The current date and time in Unix epoch seconds since 1 Jan 1970 00:00:00 UTC. It's stored as the number of days since 1 January 1970 00:00:00 UTC (for example, 1985202).

Time: Since the epoch, the current time is seconds.

Microtime(): Time in microseconds since the epoch (same as microtime()).

Now is a good time to recognize that PHP uses Unix-based conventions when defining dates. Here's how date and time in PHP are formatted: YYYY-MM-DD HH:MM: SS GMT offset, with the GMT, offset being three digits representing the number of seconds before or after UTC.

The number is most accurate when you are dealing with microseconds.
