We will show how easy it is to execute PHPUnit from within Eclipse without using any plug-ins. To begin, launch Eclipse. Do a unit test for our restaurant carte project. Maintain the code files for the restaurant project in a folder called "source" in your project workspace. Likewise, create a folder for your unit tests inside your project workspace and call it "test." The PHPunit executable is typically located in the /usr/local/bin/PHPunit.exe directory on a Mac.

Here we familiarize the reader with PHPUnit and some of its important functionalities. For further details, reference the official PHPUnit credentials by: http://www.PHPunit.de/manual/current/en/PHPunit-book.pdf. Additionally, this book is accessible in French and Japanese on www.PHPunit.de.
