### Types of Cookies in PHP

There are many types of cookies in PHP. I will explain the most important ones.

- 1) Session Cookies (session_id()): In order to make a session (a transaction), you need a session ID that is unique for every session. This function returns the unique ID for a session.
- 2) Set-Cookie: This function creates a cookie, which can be stored in the user’s browser. If you save this code in a script called test.php, it will send the cookies that it created to all users who visit the page.
- 3) Cookie: This function retrieves a cookie from a user’s computer and stores it in an array for future use. If you save this code in a script called test.php, it will remove the cookie from the browser of all users who visit the page. Cookies are stored in a browser as a string (text), and they can be up to 4Kb in size.

If you want your cookies to be persistent then use this code:

```
Set-cookie: class_name="session_id=12345"; path="/"; expires=Sun, 25-Jan-2015 13:59:59 GMT; domain=".your_site.com";
```

- 4) Cookiejar: This function will return an array containing all of the cookies that have been stored so far by PHP. You can use this function for debugging purposes or for storing all the cookies created during a session in an array for future use. If you save this code in a script called test.php, it will retrieve all of the cookies that have been stored so far and print their values to the browser using echo.

You can see the session cookies in action:

```
<span style="border:1px solid black;"> </span> <?php session_start(); ?>
```

The session cookie is handy, and it takes a lot of time to store if the user logs in and out a lot. This is because you have to call the setcookie() function, again and again each time it expires. There are two formats of session cookies they are namespaced and non-namespaced. The namespaced cookies are stored in a session, and this is the default way.

To store session cookies using namespaced, you need to add a namespace to your cookie name; for example, if you want to save it in the same session, then take the following code:

```
session_id()=YOUR_SESSION_ID;
```

- 5) Check Cookies: This function returns all of the cookies that have been stored so far. You can use this function for debugging purposes or for storing all the cookies created during a session in an array for future use.
- 6) Remove Cookies: This function removes all of the cookies that have been stored so far.
- 7) Set-Cookie Path: You can set the cookie path domain and secure these details using this function.
- 8) Cookie Expiration Time: This function expiration date you can set to expire from 3 minutes to one year from now.

### Mathematical Functions

Understanding what each mathematical function does and its general usage can help a lot when you're piecing together your own programs. So, this chapter will provide an introduction to mathematical functions in PHP that should get you well on your way towards solving any problems with them.

The following are some of the mathematical functions on PHP:

b: returns the absolute value of a number.

Ceiling: returns the ceiling function only if the argument is an integer. Otherwise, it returns NaN. It also ignores negative numbers.

Floor: returns the floor function only if the argument is an integer or a float (for example, when you divide by 0). Otherwise, it returns NaN. It also ignores negative numbers.

Truncate: truncates a number to the decimal point by removing the thousandth digits. To do so, use a binary operator (such as modulus) to get the remainder of dividing the number by 8, then divide it by 10. 5 % 8 = 1, so 7 is truncated to 0.

Abs: returns the absolute value of an integer or float. Also returns NaN when no argument is passed or if it is a negative value.

Pow: makes a floating-point number power another floating-point number. Returns 0 for negative or floating-point numbers for 0 (like 0 * 5 = 0). If the base isn't an integer, it returns NaN. Negative values will not get a very accurate result.

exp: in exponential notation, returns e to the power of x. If x is negative, it returns NaN.

log: as a float, returns the natural logarithm of its argument. (For example, log(100) = 2.) If x is not greater than 1, it returns NaN.

log10: returns the base 10 logarithm of its argument (for example, log10(100) = 2). If x is not greater than 0, it returns NaN.

Pow: returns the first argument raised to the power of the second argument. If either of them is 0 or negative, it returns NaN.
