## 网络安全进展

系列编辑：拉什米·阿格拉瓦尔 和 D. 甘尼什·戈帕尔

范围：本书系列的宗旨是呈现专门针对当今计算世界（包括云环境和移动环境）中关键安全挑战的图书，并讨论通过使用经典和现代的密码学、区块链及其他防御机制来防御这些攻击的机制。本书系列展示了在区块链、密码学以及计算与通信安全领域的一些最前沿研究成果。它是区块链、密码学、网络安全以及物联网（IoT）安全与隐私问题领域的研究人员、工程师、从业者、毕业生和博士生的宝贵知识来源。本书系列也将对研究生院和大学的教职人员有所帮助。本书系列全面审视了云安全的各个方面：基础设施、网络、服务、合规性和用户。它将提供现实世界的案例研究，阐述从安全角度在云基础设施中部署和管理服务时面临的真实及感知风险和挑战。本书系列将作为处理去中心化应用（DApps）及在开放区块链上运行的智能合约安全问题的图书平台。本书系列将成为信息安全与保障方面的全面且最新的参考资料。汇集了IT安全专业人员所需的知识、技能、技术和工具，它有助于保持对不断发展的威胁、标准和法规的领先理解。
