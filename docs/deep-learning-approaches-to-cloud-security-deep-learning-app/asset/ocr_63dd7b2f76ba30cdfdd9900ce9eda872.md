There is a need for privacy in a Multi-Tenancy system because of the risk of low privacy policies and weak security for data when tenants work on multi-tenant applications. The organisation and tenant are not able to self-secure all data [12]. Using Deep Learning creates a concept to secure data, providing there is a secure and private environment for the tenant to accept the Multi-Tenant application and work on that system freely.
