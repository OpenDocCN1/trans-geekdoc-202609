## CONCLUSION

In the present work, AGC of three area interconnected reheat thermal power system is investigated with PID controller considered as secondary controller. The ACO is used for optimizing the gain values of PID controller using ITAE objective function. The optimization process is performed without and with SMES energy storage unit in all the three interconnected areas.

The system performance with SMES energy storage unit is associated with performance of system without the energy storage unit. Simulation results depicted that SMES unit effectively damping out the oscillations and reduced the system response settling time during sudden load disturbance. The numerical values and response comparisons are given in the table and plot. It is clearly proved that system response with SMES unit settled quick response in comparison with the system response without considering SMES unit in all areas.
