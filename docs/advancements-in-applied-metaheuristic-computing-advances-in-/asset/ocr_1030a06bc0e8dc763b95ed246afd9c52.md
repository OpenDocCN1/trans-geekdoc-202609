Where n is the number of data points, Ypredicted,m and Yexperimental,m respectively indicate the predicted value and the target value from experimental data of one data point m. RMSE indicates the deviation between the experimental and predicted values. A very good fit yields R2 value of 1, where as a poor fit results in a value near zero.
