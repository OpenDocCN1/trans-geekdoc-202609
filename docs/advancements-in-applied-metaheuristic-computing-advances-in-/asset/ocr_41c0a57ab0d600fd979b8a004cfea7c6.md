Each node in the higher layer receives a weighted sum of input and weight factors from the previous layer. Each node in the hidden and output layer passes the information through a nonlinear activation function. In this way the information passes through the network and an output signal is produced at the output neuron called an estimated closing price. Now the actual/desired price is provided at the output neuron and an error signal is calculated by finding difference between the estimated and actual price. This error value act as a feedback to the network and the weight vector and biases are adjusted accordingly. The learning process is the process of finding optimal weight and bias values for the MLP model so that it will able to map the input value of the training data to the corresponding output value.
