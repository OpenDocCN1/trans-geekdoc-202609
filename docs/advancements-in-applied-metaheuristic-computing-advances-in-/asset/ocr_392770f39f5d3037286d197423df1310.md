# At bus m

$P_m = [V_m V_k B_{mk} \sin(\theta_m - \theta_k)] + [V_m V_{cR} B_{mm} \sin(\theta_m - \delta_{cR})]$ (5)

$Q_m = -V_m \wedge 2 B_{mm} - [V_m V_k B_{mk} \cos(\theta_m - \theta_k)] - [V_m V_{cR} B_{mm} \cos(\theta_m - \delta_{cR})]$ (6)

# At Series converter:

$P_{cR} = [V_{cR} V_k B_{km} \sin(\delta_{cR} - \theta_k)] + [V_m V_{cR} B_{mm} \sin(\delta_{cR} - \theta_m)]$ (7)

$Q_{cR} = -V_{cR} \wedge 2 B_{mm} - [V_k V_{cR} B_{km} \cos(\theta_k - \delta_{cR})] - [V_m V_{cR} B_{mm} \cos(\theta_m - \delta_{cR})]$ (8)

# At Shunt converter:

$P_{vR} = [V_{vR} V_k B_{cR} \sin(\delta_{vR} - \theta_k)]$ (9)

$Q_{vR} = V_{vR} \wedge 2 B_{vR} - [V_{vR} V_k B_{vR} \cos(\delta_{vR} - \theta_k)]$ (10)

The starting values of the UPFC voltage sources are taken to be $V_{cr} = 0.06$ p.u, $\delta_{cr} = 90^\circ$, $V_{vr} = 1$ p.u. and $\delta_{vr} = 0^\circ$. The source impedances are taken as $Z_{cr} = Z_{vr} = 0.1$ p.u.
