# Result Section for Color Images

In this study, proposed grey level image enhancement methodology is also applied in color image enhancement domain. Chien et.al. proposed exact Hue-Saturation-Intensity (eHSI) model to enhance the color images (Chien, C. L., Tseng, D. C. (2011), Chien, C. L., Tsai, W. H. (2014)). Any gray level contrast enhancement method can be successfully employed for color image by using eHSI model. eHSI model is a hue preserving model which has the capability to resolve the out-of-gamut problem i.e. the pixel values of output RGB image always lie within their respective intervals. Traditional HE was applied by the author for enhancement purpose (Chien, C. L., Tseng, D. C. (2011)). But in this paper proposed BHFCS with Chaotic DE and stated objective function is employed to obtain a natural enhanced image. The flowchart of the enhancement process is as Figure 2.
