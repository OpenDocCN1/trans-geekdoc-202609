WiMAX network by considering the dependent/output parameter such as throughput and the independent/input parameters such as bandwidth, average end-to-end delay and average jitter. The effects of these parameters are as follows:

+   1. **Throughput**: It is the rate of successful data delivery over a communication channel. Throughput is usually measured in bits per second (bit/s or bps).
+   2. **Bandwidth**: It is the measure of dataflow rate in a given network. This is usually measured in MHz.
+   3. **Average end-to-end delay**: It refers to the average time taken for data to be transmitted across a network from source to destination. This is usually measured in seconds.
+   4. **Average jitter**: It is the average of the all the time differences between transmission delay of a packet and transmission delay of its previous packet. Jitter can be calculated only if at least two packets have been received. This is usually measured in seconds.
