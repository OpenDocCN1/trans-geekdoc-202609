# 3.2.1 ASONN-GA Architecture

Figure 2 presents the standard ASONN-GA based forecasting model. The network has single layer architecture. The input signal contains the original closing prices as selected by the sliding window and product of these input signals resulting higher order terms of degree two. The neuron at the output layer receives the weighted sum of the input values along with a bias value of fixed weight one. This weighted sum is passed through a nonlinear activation which is a sigmoid function and produces an estimated closing price.
