# Subway map to agile practices

Agile Alliance^145
Printed with permission from Agile Alliance

The subway map is a screen print from an interactive subway map that shows various aspects of Scrum, Lean, Extreme Programming and others. Each stop on the subway line shows a term associated with the methods.

![](bbox=[0.11, 0.41, 0.91, 0.82])

Lines represent practices from the various Agile “tribes” or areas of concern:

Extreme Programming
Scrum
Design
Teams
Product management
Testing
Lean
Devops
Fundamentals
