

## 15. 可视化整体、松散和连接的概念

在某些情况下，你想要解释不涉及层级或移动的相关概念。例如，当事物并列存在或相邻时。在这些情况下，你可以使用圆形和矩形等简单形状。通过使它们变大或变小，你可以表达重要性，形状交叉的地方是重叠，而它们如何连接则表示一种关系。

| 气泡图 | 文氏图 | 同心圆图（洋葱图） |
|---|---|---|
| 雷达图 | 元素周期表 | 地理地图 |
| 矩阵 | 弦图 | 球体 |
| 平行坐标图 | 网络图 | 弧线图 |

更多示例请参阅：

- **气泡图：** 世界上最大的数据泄露和攻击事件¹⁴⁹、网络安全¹⁵⁰
- **文氏图：** 网络安全与信息安全的区别¹⁵¹、汽车网络安全与汽车信息安全差异的文氏图¹⁵²
- **元素周期表：** 构成安全专业人员的要素¹⁵³
- **网络：** 恶意软件分发网络¹⁵⁴
- **平行坐标：** 异常检测¹⁵⁵
- **地理地图：** 热力图¹⁵⁶ 和实时威胁地图¹⁵⁷-¹⁶¹
- **矩阵：** 勒索软件即服务（RaaS）商业模式的 SWOT 分析¹⁶²。
