# 14. Visualizing flow and direction

Cybersecurity work is often very dynamic. Flow and direction diagrams help to visualize how the workflows and what is expected of people. Visualizations help to order a sequence of events or can express a growth vision for the future. The diagrams can be directional, circular, or suggestive of a process. They have in common that they represent movement of some kind.

| | | |
|---|---|---|
| Flowchart | Bow Tie | Roadmap |
| Metromap | Comparison | Timeline |
| Circle | Ladder | Swim lane |
| Fishbone | Petri net | Maturity model |
| (Interactive) Pathways | Spiral | Sankey diagram |
