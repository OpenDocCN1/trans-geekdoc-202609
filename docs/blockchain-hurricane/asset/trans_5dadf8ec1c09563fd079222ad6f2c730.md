
-   [推动 Atari 这家长期稳固的游戏巨头开发代币的背景之一](https://wiki.example.org/feynmans_learning_method)是与 Atari Token 联合创始人 Daniel Doll-Steinberg 进行讨论，探讨支撑这一及其他区块链发展的虚拟世界理论。现实世界中的价值是通过出售技能、时间或资产来创造的，同样可以在虚拟世界中通过在游戏中具备相同经济和货币机制的设计来创造价值。通过在主机上投入大量时间的技能正在最高层面上开始产生可转移的现实世界价值。我们正在见证电子竞技的兴起，包括英语电子足球比赛——ePremier League (ePL)^([4](#08_Reference.xhtml#c5.4))，以及新一代一级方程式赛车手中，19 岁的 Lando Norris 将部分成功及他读懂赛道上其他车手的能力归功于多年的模拟赛车经历^([5](#08_Reference.xhtml#c5.5))以及参与 McLaren Shadow Esports 竞技赛事。Fortnite 也进入了赛场，其 2019 年世界杯总决赛在纽约直播，吸引了数百万粉丝。然而，从技能、时间或投资中直接在游戏平台内获取价值，而非在独立比赛中获取，是一个全新的机会。如果这可以被利用——而区块链提供了实现的手段——随后的价值创造将启动一个可持续、民主化、全球性的经济。这是游戏行业的颠覆性愿景，驱动着小型敏捷公司的发展，而 Atari 已经认识到这一点。

-   Atari 代币的开发过程比其他更为人知的区块链游戏项目要慢得多且公开性较低。作为一家在 NASDAQ 上市的公司，Atari 不能像小型企业和初创公司那样轻松进入 ICO 空间，但其愿景促使其在复杂的 NASDAQ 监管下规划代币发行。Doll-Steinberg 回顾了为项目构建结构的压力，即在创新环境中保持创始人舒适的同时满足监管要求。他回忆起看着一些缺乏商业经验的团队快速筹资并失败的挫败感，而 Atari Token 的高技能创始人则走的是长期道路。更具灵活性的独立公司公开其计划信息，但 Atari 受限于上市公司披露限制，不能发布任何可能影响股价或违反严格的内幕交易法律的信息。媒体在 2018 年 2 月通过一份巴黎证券交易所的强制报告中的几行内容报道了此事，但此时 2017 年牛市已崩盘，ICO 热潮正迅速衰退。代币发行计划在 2018 年夏季被放弃，但 Atari 仍在持续内部投资。

-   区块链游戏的大部分开发集中在小型公司，这符合我们对颠覆性创新的预期。正如互联网兴起时，既有市场领导者未能抓住浪潮，而 Google 从车库和 Facebook 从宿舍崛起并超越了他们。在游戏领域，大型公司尚未有动力改变其策略。它们的商业模式盈利且可持续，处于与各行业大型企业相同的位置——不愿或无法进行实验并冒险影响其底线。当拐点到来时，Atari 至少将做好准备进行反应。

-   当前正在涌现的、摆脱监管限制的创新者所带来的颠覆是什么？数字资产所有权的价值创造是首先实现的，而对时间投入和技能提升的回报也不远了。让我们现在转向数字猫，看看它们为何将改变世界。

-   **Cryptokitties 和 非同质化代币 (NFT)**

-   如果猫视频是现代万维网的象征，那么数字猫则是区块链和加密货币未来的旗帜。当 Cryptokitties^([6](#08_Reference.xhtml#c5.6))，首个高调区块链游戏，于 2017 年 11 月推出时，它立即吸引了区块链社区的注意。前几天在 Cryptokitties 市场上的交易量之大导致区块链网络难以应对负载^([7](#08_Reference.xhtml#c5.7))。这种兴奋并非完全源于它为加密货币用户提供了一个有趣的出口。锐眼的开发者在阅读开源代码时意识到，购买您的卡通小猫后，您拥有该可爱爪哇的绝对所有权。更深入的检查确认，当您将两只小猫进行繁殖时，您拥有后代，且每只小猫都有从其父母处继承并由智能合约执行繁殖交易定义的独特特征组合。每只小猫的基因代码都以离散的数字资产形式使用非同质化代币 (NFT) 记录。我们在 [第 2 章](#02_Chapter_2.xhtml) 中提到了可编程货币：让我们回顾一下。

-   **ERC 20、ERC 721 和 ERC 1155 代币**

-   代币不只是专有现金，它可以是价值衡量、非货币资产或社区影响力的度量。大多数基于以太坊虚拟机且自带原生货币的商业应用都在使用所谓的 ERC20 代币。ERC 代表 Ethereum Request for Comment，指的是在开源社区中关于如何开发每种代币类型的讨论，这些讨论促成了各类代币的形成。从编号可以看出，许多提案被讨论，但只有少数可行并被开发者社区采纳。ERC20 是数字现金：这些代币通常被称为替代币，它们的行为像钱。所有代币都相同且可分割，类似于一张钞票。数千种 ERC20 代币已被创建。许多被用于通过 ICO 进行众筹，有些随着其相关应用的发展而保有或获得价值，而有些则毫无价值。这些代币常被称为“shitcoins”，无价值的持有量在投资者中被称为“dust”。大多数区块链游戏直接使用 Ether (ETH) 进行游戏内购买和操作，尽管少数游戏拥有自己的 ERC20 货币，用于奖励和玩家留存机制。

-   游戏还利用了另外两种带有特殊属性的 ERC 代币。Cryptokitties 游戏及其他类似游戏采用了 ERC721 作为其首选代币。ERC721 是一种“一对一”的代币。它们仍然可以自由交换，但每个代币的相对价值会根据其具体特征、独特性和稀有度而有所不同。在技术术语中，这意味着该代币是“不可互换的”。互换性是货币的属性，例如，任何一张一美元钞票都可以用于购买一杯一美元或更少的饮料，找零确保了交换价值的一致性。相比之下，非同质化代币 (NFT) 代表一个独特、离散的项目，是一个收藏品，其价值基于其自身属性和购买者的感知。

-   在 Cryptokitties 的语境下，可视化 NFT 非常简单。虽然所有猫都有相同的基本卡通轮廓，但每只猫都因其被赋予的遗传特征而略有不同。有些人觉得某些特征吸引人，会主观为拥有紫色爪子的猫，或驾驶小型赛车的猫赋予价值。它们也是不可分割的：将它们切开是不可想象的。
