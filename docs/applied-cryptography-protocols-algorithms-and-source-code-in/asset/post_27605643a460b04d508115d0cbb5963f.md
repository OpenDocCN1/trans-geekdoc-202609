# CHAPTER 16 Pseudo-Random-Sequence Generators

If you only have a 16-bit computer, use this generator instead:

```c
static int s1 = 1; /* An "int" must be 16 bits long. */
static int s2 = 1;
static int s3 = 1;

#define MODMULT(a,b,c,m,q) s/=a; s = b*(s-a*q); if (s<0) s+=m;

/* combined LCG linear congruandom real value in the
range
* (0,1). It combines linear congruential generators with
* periods of 2^31-405, 2^31-1111, and has a period
* that is the product of these three prime numbers. */
double combinedLCG( void ) {
    int q;
    int z;
    MODMULT(206, 157, 21, 32363, s1)
    MODMULT(217, 146, 45, 31727, s2)
    MODMULT(222, 142, 133, 31657, s3)
    z = s1 - s2;
    if (z > 706)
        z -= 32362;
    if (z < 0)
        z += 32362;
    return z * 3.0899e-5;
}
```

```c
/* In general, call initLCG before using combinedLCG. */
void initLCG(int initS1, int initS2, int initS3) {
    s1 = initS1;
    s2 = initS2;
    s3 = initS3;
}
```

This generator works as long as the machine can represent all integers between -32768 and 32763. The variables, s1, s2, and s3 are global; they hold the current state of the generator. Before the first call, they must be initialized. The variable s1 needs an initial value between 1 and 32762. The variable s2 needs an initial value between 1 and 31726. The variable s3 needs an initial value between 1 and 31656. This generator has a period of 1.6*10⁷.
For of these generators, the constant term b in the linear congruence is 0.

# 16.2 LINEAR FEEDBACK SHIFT REGISTERS

Shift register sequences are used in both cryptography and coding theory. There is a wealth of theory about them; stream ciphers by shift registers have been the workhorse of military cryptography since the beginnings of electronics.

## 16.2 Linear Feedback Shift Registers

A shift register is made up of two parts: a shift register and a feedback function [see Figure 16.1]. The shift register is a sequence of bits. [The length of a shift register is registered in bits, if it is n bits long, it is called an n-bit shift register.] Each time a bit is needed, all of the bits in the shift register are shifted 1 bit to the right. The new leftmost bit is computed as a function of the other bits in the register. The output of the shift register is 1 bit, often the least significant bit. The period of a shift register is the length of the output sequence before it starts repeating.

Cryptographers have liked stream cipher made of shift registers: they are easily implemented in digital hardware. I will only touch on mathematical theory. Ernst Sommer, the Norwegian government's chief cryptographer, worked out the theory of shift registers in 1965 [1411]. Solomon Golomb, an NSA mathematician, wrote a book with Selmer's results and some of own [643]. See [970,971,1647].

The simplest kind of shift register is a linear feedback shift register, or LFSR (see Figure 16.2). The feedback function is the XOR of certain bits in the register; the list of these bits is called a tap sequence. Sometimes this is called a Fibonacci configuration. Because of simple feedback sequence, a large body of mathematical theory can be applied to LFSRs. Cryptographers like to analyze sequences to convince them they are random enough to be secure. LFSRs are the most common type of shift registers used in cryptography. Figure 16.3 is a 4-bit LFSR tapped at the first and fourth bit. If it is initialized with the value 1111, it produces the sequence of internal states before repeating:

An n-bit LFSR can be in one of $2^n-1$ internal states. This means that in theory, generate a $2^n-1$-bit-long pseudo-random sequence before repeating. (It's $2^n-1$ and not $2^n$ because a shift register filled with zeros will cause the LFSR to output a neverending sequence of zeros—this is not useful.) Only LFSRs with certain tap sequences cycle through all $2^n-1$ internal states; these are the maximal-period LFSRs. The resulting output sequence is called an m-sequence. In order for a particular LFSR to be a maximal-period LFSR, the polynomial formed from a tap sequence plus the constant 1 must be a primitive polynomial modulo 2. The degree of the polynomial is the length of the shift register. A primitive polynomial of degree $n$ is an irreducible polynomial that divides $x^{2^n-1}+1$, but not $x^d+1$ for any $d$ that divides $2^n-1$ (see Section 1.3). For the mathematical theory behind all this, consult [643,1649,1648].

## 16.2 Linear Shift Registers

In general, there is no way to generate primitive polynomials mod 2 for a given degree. The easiest way is to choose a random polynomial and test whether it is primitive. This is complicated—testing random numbers for primacy—many mathematical software packages do. We see [970,971] for some.

Table 16.2 lists some, but by no means all, primitive polynomials mod 2 of varying degrees [1583,643,1649,1648,1272,1691]. For example, the listing (32, 7, 5, 3, 2, 0) means that the following polynomial is primitive modulo 2:

```
$x^{32} + x^7 + x^5 + x^3 + x^2 + x + 1
```

It's easy to turn this into a maximal-period LFSR. The first number is the length of the LFSR. The next is always 0 and can be ignored. All the numbers, except the 0, specify the tap sequence, counting from the length of the shift register. That is, low degree terms in the polynomial correspond to taps near the left-hand side of the register.

To continue the example, the listing (32, 7, 5, 3, 2, 1, 0) means that if you take a 32-bit shift register and generate the new one by XORing the thirty-second, seventh, fifth, third, second, and first bits together (see Figure 16.4), the resultant LFSR will be maximum length; it will cycle through $2^{32}-1$ values before repeating.

The C code for this LFSR looks like:

```c
int LFSR() {
    static unsigned long ShiftRegister = 1;
    /* Anything but 0. */
    ShiftRegister = (((ShiftRegister >> 31)
        ^ (ShiftRegister >> 6)
        ^ (ShiftRegister >> 4)
        ^ (ShiftRegister >> 2)
        ^ (ShiftRegister >> 1)
        ^ (ShiftRegister))
    & 0x00000001)
    << 31
    | (ShiftRegister >> 1);
    return ShiftRegister & 0x00000001;
}
```
