# Conference Key Distribution

This protocol allows a group of n users to agree on a secret key using only insecure\channels. The group shares two large primes, p and q, and a generator g the same
size q.

(1) User i, where i goes from 1 to n, chooses a random r, less than q, and
broadcasts

z_i = g^i mod p

(2) Every user verifies z_i^q = 1 (mod p), for all i from 1 to n.

(3) User i broadcasts

x_i = [z_{i+1}/z_{i-1}]i mod p

(4) User computes

K = [z_{i-1}]^{if} · x_{i+1}^{n-2} · · · · x_{i-2} mod p

All index computations in the protocol i-1, i-2, and i—should be
computed mod n. At the end of the protocol, all honest users have the same K. No
else gets anything. However, this protocol fails to a man-in-the-middle attack.
Another protocol, not quite as prime, is in [757].
