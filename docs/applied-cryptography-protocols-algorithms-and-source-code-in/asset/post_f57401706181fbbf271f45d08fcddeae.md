## Blum Integers

If $p$ and $q$ are primes, and both are congruent to 3 modulo 4, then $n=pq$ is sometimes called a Blum integer. If $n$ is a Blum integer, each quadratic residue has exactly four square roots, one of which is also a square; this is the principal square root. For, the principal square root of 139 mod 437 is 24. The other three square roots are 185, 252, and 413.

## Generators

If $p$ is a prime, and $g$ is less than $p$, then $g$ is a generator mod $p$ if
for each $b$ from 1 to $p-1$, there exists some $a$ where $g^a \equiv b \pmod p$.

Another way of finding is that $g$ is primitive with respect to $p$. For example, if $p=11$, 2 is a generator mod 11:

```
$2^{10} = 1024 \equiv 1 \pmod{11}$
$2^1 = 2 \pmod{11}$
```

In general, testing whether a given number is a generator is not an easy problem. It is easy, if you know the factorization of $p-1$. Let $q_1, q_2, \dots, q_n$ be the distinct prime factors of $p-1$. To test whether a number $g$ is a generator mod $p$, calculate $g^{(p-1)/q_i} \equiv 1 (mod p)$ for all values of $q=q_1, q_2, \dots, q_n$.

If that number equals 1 for some value of $q$, then $g$ is not a generator. If that value does not equal 1 for any values of $q$, then $g$ is a generator.

For example, let $p=11$. The prime factors of $p-1$ are 10 are 2 and 5. To test whether 2 is a generator:

```
$2^{(11-1)/5} (mod 11) = 4$
$2^{(11-1)/2} (mod 11) = 10$
```

Neither result is 1, so 2 is a generator. To test whether 3 is a generator:

```
$3^{(11-1)/5} (mod 11) = 9$
$3^{(11-1)/2} (mod 11) = 1$
```

Therefore, 3 is not a generator.

If you need to find a generator $p$, simply choose a random number from 1 to $p-1$ and test whether it is a generator. Enough of them will be, so you'll probably find one fast.
