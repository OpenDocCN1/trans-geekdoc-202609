# 24.5 Kerberos

Kerberos is a trusted-party authentication protocol designed for TCP/IP networks. Kerberos service, sitting on the network, acts as a trusted arbitrator. Kerberos provides secure network authentication, allowing a person to access different machines on the network. Kerberos is based on symmetric cryptography [DES as implemented, but other algorithms could be used]. Kerberos shares a different secret key with every entity on the network and knowledge of that secret key proof of identity.

Kerberos was originally developed at MIT for Project Athena. The Kerberos model is based on Needham-Schroeder's trusted third-party protocol [see Section 3.3] [1159]. The original version of Kerberos, Version 4, is specified in [1094,1499]. [Versions 1 through 3 were internal development versions. ] Version 5, modified from Version 4, is specified in [86,877,878]. The best overview of Kerberos is [1163]. Other survey articles are [1384,1493], and two articles on using Kerberos in the real world are [371,782].

# The Kerberos Model

The basic Kerberos protocol was outlined in Section 3.3. In the Kerberos model, there are entities—clients and servers—sitting on the network. Clients can be users, but can also be independent software programs that need to do: download files, send messages, access databases, access printers, obtain administrative privileges, whatever.

Kerberos keeps a database of clients and secret keys. For a human user, the secret key is an encrypted password. Network services requiring authentication, as well as clients who know to use these services, register their secret key with Kerberos.

Because Kerberos knows everyone's secret key, it can create messages that one entity sends another's identity. Kerberos also creates sessions which are given to a client and a server (or to two clients) and no else. A session key is used to encrypt messages between the two parties, after which it is destroyed. Kerberos uses DES for encryption. Kerberos Version 4 provided a substantial mode for authentication. This mode is weak: it fails to detect changes to the ciphertext (see Section 9.10). Kerberos Version 5 uses CBC mode.
