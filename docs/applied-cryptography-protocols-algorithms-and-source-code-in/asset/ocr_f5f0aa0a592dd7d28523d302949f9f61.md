# Security of ESIGN

When this algorithm was originally proposed, k was set to 2 [1215]. This was quickly broken by Ernie Brickell and John DeLaurent [261], who extended their attack to k = 3. A modified version of this algorithm [1203] was broken by Shamir [1204]. The variant ESIGN is the current incarnation of this family of algorithms. Another new attack [963] does not work against ESIGN.

The authors currently recommend these values for k: 8, 16, 32, 64, 128, 256, 512, and 1024. They also recommend that p and q be each of at least 192 bits, making n at least 576 bits long. [if n should be twice the length.] With these parameters, the authors conjecture that ESIGN is secure as RSA or Rabin. Their analysis shows favorable speed comparison to RSA, ElGamal, and DSA [582].

# 20.7 CELLULAR AUTOMATA

A new and old idea, suggested by Papua Guam [665], is the use of cellular automata in public-key cryptystems. This system is far too new and has not been extensively, but a preliminary examination suggests that it may have a cryptographic weakness similar to one seen in other cases [562]. This is a promising area of research. Cellular automata have the property that, even if they are invertible, it is impossible to calculate the predecessor of an arbitrary state by reversing the rule for finding the successor. This sounds a whole lot like a trapdoor one-way function.
