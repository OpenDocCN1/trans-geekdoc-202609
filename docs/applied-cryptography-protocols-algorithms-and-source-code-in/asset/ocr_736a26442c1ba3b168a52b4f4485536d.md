In the world of extension fields, GF($2^{40}$) hasn't been ignored by researchers. An algorithm was proposed in [727]; Coppersmith's algorithm makes discrete logarithms in fields such as GF($2^{127}$) possible [368]. This was based on work in [180]. The precomputation stage of this algorithm is enormous, but otherwise it is nice and efficient. A practical implementation of a less efficient version of the same algorithm, after a seven-hour precomputation period, found discrete logs in GF($2^{127}$) in several seconds each [1130,180]. For surveys of some of these results, consult [1189,1631,1632], issecure.

More recently, the precomputations for GF($2^{327}$), GF($2^{513}$), and GF($2^{401}$) are done, and significant progress has been made towards being executed on an nCube-3 massively parallel computer with 1024 processors [649,650]. Computing discrete logarithms in GF($2^{509}$) is still barely out of reach.

Like discrete logarithms in a prime field, the precomputation required to calculate discrete logarithms in a polynomial field has to be done only once. TaherGamal [520] gives an algorithm for calculating discrete logs in the field GF($p^3$).
