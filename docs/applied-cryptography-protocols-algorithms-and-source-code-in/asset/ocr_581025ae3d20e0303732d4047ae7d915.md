# 18.11 Symmetric Block Algorithms

# LOKI Double-Block

This algorithm is a modification of Quisquater-Girault, specifically designed to work with LOKI [273]. All parameters are as in Quisquater-Girault.

```
$G_0 = I_0, \quad I_G \text{ is a random initial value}$
$H_0 = I_H, \quad I_H \text{ is another random initial value}$
$W_i = E_B \oplus G_{i-1}, [G_{i-1} \oplus R_i] \oplus H_{i-1}$
$G_i = E_B \oplus H_i, [W_i \oplus L_i] \oplus H_{i-1} \oplus L_i$\n$H_i = W_i \oplus G_{i-1}$
```

Again, in some instances the birthday attack is trivially solvable [925,926,1262,372,736]. Do not use this scheme.

# Parallel Davies-Meyer

This is another attempt at an algorithm with a hash rate twice the block length [736].

```
$G_0 = I_G, \quad I_G \text{ is a random initial value}$
$H_0 = I_H, \quad I_H \text{ is another random initial value}$
$G_i = E_B \oplus [G_{i-1} \oplus L_i] \oplus H_{i-1}$
$H_i = E_L[H_{i-1} \oplus R_i] \oplus R \oplus H_{i-1}$
```

Unfortunately, this scheme isn't secure [928,861]. As it turns out, a double-length hash function with a hash rate of 1 cannot be more secure than Davies-Meyer [861].

# Tandem and Breast Davies-Meyer

Another way around the inherent limitations of a block cipher with a 64-bit key uses an algorithm, like IDEA (see Section 13.9), with a 64-bit block and a 128-bit key. These schemes produce a 128-bit hash value and have a hash rate of 1 [930,925].
