The core of the algorithm is

TEMP = ({j,A,B,C,D,E,F,G} <<< 7) + M[H <<< 11] + M[i|r[j]]] + K[j]
H = G; G = F; F = E; D = C; C = B; A = TEMP

The variable number of rounds and variable-length output are 15 versions of this algorithm. Den Boef's and Bosselaers's attack on MD5 [203] did not apply to HAVAL because of the rotation of H.

# 18.10 One-Way Hash Functions

MD3 is yet another hash function designed by Ron Rivest. It had several flaws and never made it out of the laboratory, although a description recently published in [1335].

A group of researchers at the University of Waterloo have proposed a one-way hash function based on iterated exponentiation in GF(2^99) [22]. In this scheme, a message is divided into 593-bit blocks; with the first block, the blocks are successively exponentated. Each exponent is the result of the computation with the previous block; the first one is given by IV.

Ivan Damgård designed a one-way hash function based on the knapsack problem [see Section 19.2] [414]; it can be broken in 2^52 operations [290,1232,787]. Steve Wolfram's cellular automata [1608] have been proposed as a basis for one-way hash function. Cellbash [384,404], and an improved version, Subbash [384,402,405], are based on cellular automata; both are designed for hardware. Boingmix designs the design principles of Cellbash with those of MD4 [42,407]. StepUpRight can be implemented as a hash function as well as [402].

Clauss Schnorr proposed a one-way hash function based on the discrete Fourier transform, called FFT-Hash, in the summer of [1399]; it was broken a few months later by two independent groups [40,84]. Schnorr proposed a revised version, FFT-Hash II (the previous version was named FFT-Hash I [1400]), which was broken in a few weeks [1599]. Schnorr has proposed further modifications [1402,1403] but, as it stands, the algorithm is much slower than the others in this chapter.

Additional theoretical work on constructing one-way hash functions from one-way functions and one-way permutations can be found in [412,1138,1342].
