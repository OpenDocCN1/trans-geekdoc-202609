# Cryptanalysis of GOST

These are the differences between DES and GOST.

+   - DES has a complicated procedure for generating subkeys from the keys. GOST has a very simple procedure.
- DES has a 56-bit key, GOST has a 256-bit key. If you add the secret S-box permutations, GOST has a total of about 610 bits of secret information.
