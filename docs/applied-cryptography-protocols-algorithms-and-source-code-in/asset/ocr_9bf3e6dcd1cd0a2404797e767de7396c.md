Three-Way Marriage Problem. In a room are n men, n women, and n clergymen (priests, rabbis, whatever). There is also a list of acceptable marriages, which consists of one man, one woman, and one clergyman to officiate. Given this list of possible triples, is it possible to arrange marriages such that everyone is marrying one person or officiating at one marriage?

Three-Satisfiability. There is a list of n logical statements, each with three variables. For example: if (x and y) then z, (x and w) or (not z), then [(not u and not x) or (z or not x)], and so. Is there a truth assignment for all the variables that satisfies all statements? (This is a special case of the Satisfiability problem previously mentioned.)

# Modular Arithmetic

You learned modular arithmetic in school; it was called "clock arithmetic." Remember these words? If Mildred says she'll be home by 10:00, and she's 13 hours late, what time does she go home and how many years does her father get older? That's arithmetic modulo 12. Twenty-three modulo 12 equals 11.

```
(10 + 13) mod 12 = 23 mod 12 = 11
```

Another way of writing is to say that 23 and 11 are equivalent, modulo 12:

23 = 11 [mod 12]

Basically, a = [b mod n] if a = b + kn for integer k. If a is non-negative and b is between 0 and n, you can think of b as the remainder of a when divided by n. Sometimes, b is called the residue of a, modulo n. Sometimes a is congruent to b, modulo n (the triple sign ≡, denotes congruence). These are just different ways of saying the same thing.

The set of integers from 0 to n–1 forms a complete set of residues n. This means that, for every integer a, its residue modulo n is some number from 0 to n–1.

The operation a mod n denotes the residue of a, such that the residue is some integer from 0 to n–1. This operation is modular reduction. For, 5 mod 3 = 2.
