# 3.2 Authentication

The point here is to make sure that Mallory has to do a trial encryption of each password in his dictionary every time he tries to break another person's password, rather than just doing one massive precomputation for all possible passwords.

A lot of salt is needed. Most UNIX systems use only 12 bits of salt. Even with, Daniel Klein developed a password-guessing program that often cracks 40 percent of the passwords on a given host system within a week [847,848] [sec Section 8.1]. David Feldmeier and Philip Karn compiled a list of about 732,000 common passwords concatenated with each of 4096 possible salt values. They estimate that 40 percent of passwords on any given host can be broken with this salt [51].

Salt isn't pancake; increasing the number of salt bits won't solve everything. Salt protects against general dictionary attacks on a password file, not against a concerted attack on a single password. It protects people who have the same password on multiple machines, but doesn't make poorly chosen passwords any better.

# SKEY

SKEY is an authentication program that relies on a one-way function for its security.

To set up the system, Alice enters a number, R. The computer computes f(R), f(f(R)), f(f(f(R))), and so on, around a hundred times. Call these numbers x₁, x₂, ..., x₁₀. The computer prints out this list of numbers, and Alice puts it in her pocket for safekeeping. The computer also stores x₁₀ in the clear, in a login database next to Alice's name.

The first time Alice wants to log in, she types her name and x₁₀. The computer calculates f(x₁₀) and compares it with x₁₀; if they match, Alice is authenticated. Then, the computer replaces x₁₀ with x₁ in the database. Alice keeps x₁₀ off her list.

Every time Alice logs in, she enters the last unused number for her host: x. The computer computes f(x) and compares it with xᵢ₊ stored in the database. Eve can get any useful information because each number is used only once, and the function is one-way. Similarly, the database is not useful to an attacker. Of course, when Alice runs out of numbers on her list, she has to reinitialize the system.
