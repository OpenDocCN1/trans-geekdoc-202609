# Multiple Signatures

If many people want to sign the same document? The easy solution has each
of signing separately, but this signature scheme can do better than that here.
Alice and Bob sign the same document and Carol verifies the signatures, but any
number of people can be involved in the signature process. As, Alice and Bob
have their own unique $J$ and $B$ values: $[J_A, B_A]$ and $[J_B, B_B]$. The values $n$ and $v$ are com-
mon to the system.

+   (1) Alice picks a random integer, $r_A$, so that is between 1 and $n-1$. She
computes $T_A = r_A^{d_A} 	ext{ mod } n$ and sends $T_A$ to Bob.

+   (2) Bob picks a random integer, $r_B$, so that $r_B$ is between $1$ and $n-1$. He com-
putes $T_B = r_B^{d_B} 	ext{ mod } n$ and sends $T_B$ to Alice.

+   (3) Alice and Bob compute $T=[T_A,T_B] 	ext{ mod } n$.

+   (4) Alice and Bob compute $d = H(M,T)$, where $M$ is the message
signed and $H[x]$ is a one-way hash function. The $d$ produced by the hash func-
tion must be within this range, $0$ and $v-1 = [1280]$. If the output of the hash func-
tion is not within this range, it must be reduced modulo $v$.

+   (5) Alice computes $D_A = r_A^{d_A} 	ext{ mod } n$ and sends $D_A$ to Bob.

+   (6) Bob computes $D_B = r_B^{d_B} 	ext{ mod } n$ and sends $D_B$ to Alice.

+   (7) Alice and Bob compute $D=[D_A,D_B] 	ext{ mod } n$. The signature consists of
mntials, $M$, the two calculated values, $d$ and $D$, and her credentials of creden-
tials: $J_A$ and $J_B$.

+   (8) Carol computes $J=[J_A,J_B] 	ext{ mod } n$.

+   (9) Carol computes $T' = D^{d'} 	ext{ mod } n$. She computes $d'=H(M,T)$. If $d=d'$,
then the multiple signature is valid.

This protocol can be extended to any number of people. For people to
sign, they multiply their individual $T_i$ values together in step [3], and their indi-
ual $D_i$ values together in step [7]. To verify a multiple signature, multiply all the
signer $J_i$ values together in step [8]. Either all the signatures are valid or there is
one invalid signature.
