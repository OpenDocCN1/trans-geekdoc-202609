# 11.1 Information Theory

In most real-world cryptanalysis, the cryptanalyst has some probabilistic information about P before he starts. He probably knows the language of the plaintext. This language has a certain redundancy associated with it. If it is a message to Bob, it begins with "Dear Bob." Certainly "Dear Bob" is more than "C8tg[m." The purpose of cryptanalysis is to modify the probabilities associated with each plaintext. Eventually one plaintext will emerge from the pile of plaintexts as certain (or at least, very probable).

There is such a cryptystem that achieves perfect secrecy: a cryptystem which yields no information about the plaintext (except its length). Shannon theorized that it is only possible if the number of keys is at least as large as the number of messages. In other words, the key must be at least as long as the message itself, and no key can be reused. In other words, the one-time pad (see Section 1.5) is the only cryptystem that achieves perfect secrecy.

Perfect secrecy, the ciphertext unavoidably yields some information about the plaintext. A good cryptographic algorithm keeps this information to a minimum; a good cryptanalyst exploits this information to determine the plaintext.

Cryptanalysts use the natural redundancy of language to reduce the number of possible plaintexts. The more redundant the language, the easier it is to crystallize. This is the reason that many real-world cryptographic implementations use a compression program to reduce the size of the text before encrypting it. Compression reduces the redundancy of a message as well as the work required to encrypt and decrypt.

The entropy of a cryptystem is a measure of the size of the keyspace, K. It is approximated by the base logarithm of the number of keys:

```
H(K) = log2 K
```

A cryptystem with a 64-bit key has a 56-bit key with an entropy of 56 bits. In general, the greater the entropy, the harder it is to break a cryptystem.

# Unicity Distance

For a message of length n, the number of different keys that will decrypt a ciphertext message to some intelligible plaintext in the same language as the original plaintext (such as an English string) is given by the formula [712.95]:

```
H(K) = nD - 1
```

Shannon [1432] defined the unicity distance, U, also the unicity point, as an approximation of the ciphertext such that the sum of the real information [entropy] in the corresponding plaintext plus the entropy of the encryption key equals the number of bits used. He went on to show that cryptystems longer than this distance are reasonably certain to have only one meaningful decryption. Ciphertexts significantly shorter than this are likely to have multiple, equally valid decryptions and therefore gain security from the opponent's difficulty in choosing the correct one.
