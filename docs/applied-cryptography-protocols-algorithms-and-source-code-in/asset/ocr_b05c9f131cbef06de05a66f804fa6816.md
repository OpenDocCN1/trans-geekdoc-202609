# DSA

There is also a subliminal channel in DSA (Section 20.1)[1468,1469,1473]. In fact, there are several. The simplest subliminal channel involves the choice of k. If Alice chooses a particular 160-bit random number, then Bob, who knows Alice's private key, can recover it. Alice can send Bob a 160-bit subliminal message in each DSA signature; everyone simply verifies Alice's signature. Another complication: Since k would be random, Alice and Bob need to share a one-time pad and encrypt the subliminal message with the one-time to generate a k.

DSA subliminal channels that do not require Bob to know Alice's private key. These also involve choosing particular values of k, but cannot be used to send 160 bits of information. This scheme, presented in [1468,1469], allows Alice and Bob to exchange one bit of subliminal information per signed message.

+   (1) Alice and Bob agree on a random prime, P (different from the parameter p in the signature scheme). This is their secret key for the subliminal channel.

+   (2) Alice sends an anonymous message, M. If she wants to send Bob the subliminal bit, she makes the r parameter of the signature a quadratic residue modulo P. If she wants to send him o, she makes the r parameter is a quadratic nonresidue modulo P. She does this by signing the message with an r with the requisite property. Since quadratic residues and quadratic nonresidues are equally likely, this shouldn't be too difficult.

+   (3) Alice sends the signed message to Bob.
