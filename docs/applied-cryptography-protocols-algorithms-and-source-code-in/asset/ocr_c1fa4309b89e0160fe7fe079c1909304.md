# 23.11 Zero-Knowledge Proofs of Knowledge

Zero-Knowledge Proof of a Discrete Logarithm
Peggy wants to prove to Victor that she knows an x that satisfies

```
$A^x = B [mod p]$
```

where p is a prime, and x is a random number relatively prime to $p-1$. The numbers A, B, and p are public, here's how Peggy can prove she knows x without revealing it (see Section 5.1) [338,937].

+   (1) Peggy generates random numbers $r_1, r_3, \dots, r_t$, where all $r_i$ are less than $p-1$.
(2) Peggy computes $h_i = A^{r_i} \mod p$, for all values of $i$, and sends them to Victor.
(3) Peggy and Victor engage in a coin-flipping protocol to generate $t$ bits: $b_1, \dots, b_t$.
(4) For all $t$, Peggy does one of the following:
a) If $b_i=0$, she sends Victor $r_i$
b) If $b_i=1$, she sends $s_i = \{r_i - t_j) \mod (p-1)\}$, where $j$ is the lowest value for $b_j=1$
(5) For all $t$, Victor confirms one of the following:
a) If $b_i=0$, $A^{r_i} = h_i [mod p]$
b) If $b_i=1$, $A^{t_i} = b_i h_i^{-1} (mod p)
(6) Peggy proves Victor Z, where
$Z = \{x - t_j\} \mod [p-1]
(7) Victor confirms that
$A^2 = Bh_i^{-1} [mod p]$

Peggy's probability of successfully cheating is $2^{-t}$.
