This value then cascades into $N [N=8 in the figures]$ processing stages. The input to the next processing stage is the previous hash value XORed with one of eight constant values.

One processing stage is given in Figure 18.3. The message block is broken into four 32-bit values. The previous hash value is also broken into four 32-bit values. The function $S_0$ and $S_1$, are the same as they were in FEAL.

```
$S_0(a,b)=$ rotate left two bits $[(a+b) \mod 256]$\nS_1(a,b)=$ rotate left two bits $[(a+b+1) \mod 256]$
```

The output of one processing stage becomes the input to the next processing stage. After the last processing stage, the output is XORed with the $M_i$, and $H_{i-1}$, and then the next block is ready to be hashed.
