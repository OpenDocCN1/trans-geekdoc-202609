Merkle speculated that key sizes of 64- or 128-bits would be used for Kfrare and

In 1990 Biham and Shamir turned their differential cryptanalysis techniques
against Kfrare [170]. They were able to break 16-round Kfrare with a chosen-
plaintext attack using about 1500 encryptions. They could after an hour, using
the personal computer. Converting to a known-plaintext attack would require
about 2^8 encryptions. Kfrare with 24 rounds can be broken by a chosen-plaintext
attack using 2^25 encryptions, and a known-plaintext attack using 2^39 encryptions.

# 13.2 RC2

RC2 is a variable-key-size encryption algorithm designed by Rivest for RSA
Data Security. [RSADSI]. Apparently, “RC” stands for “Ron’s Code,” although
outially stands for “Rivest Cipher.” [RC3 was broken by RSADSI during devel-
ment, RC2 never got further than Rivest’s notebook.] It is proprietary, and its
details have not been published. Don't think for a minute that this helps security.
RC2 has already appeared in commercial products. As far as I know, RC2 has not
pat and is only protected as a trade secret.
