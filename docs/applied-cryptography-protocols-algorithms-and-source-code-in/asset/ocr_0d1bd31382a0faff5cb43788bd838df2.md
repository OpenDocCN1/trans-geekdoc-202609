This scheme [128|2] was broken in [369]:

$H_i = E_M[H_{i-1}]$

Davies and Price produced a variant which cycles the entire message through the algorithm twice [432,433]. Coppersmith's attack works on this variant with not much larger computational requirements [369].

Another scheme [432,458] was shown insecure in [1606]:

$H_i = E_M[H_{i-1}] \oplus H_{i-1}$

This scheme was shown insecure in [208] [c is a constant]:

$H_i = E_c[M \oplus H_{i-1}] \oplus M \oplus H_{i-1}$

# Modified Davies-Meyer

Lai and Massey modified the Davies-Meyer technique to work with the IDEA cipher [930,1925]. IDEA is a 64-bit block size and 128-bit key size. Their scheme is

$H_0 = IH_0$, where $IH_0$ is a random initial value

$H_i = E_{H_{i-1}}[M] \oplus H_{i-1}$

This function hashes the message in blocks of 64 bits and produces a 64-bit hash value (See Figure 18.10).

No known attack on this scheme is easier than brute force.
