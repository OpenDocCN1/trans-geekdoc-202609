# Cryptanalysis of LOKI9

Knudsen attempted to cryptanalyze LOKI9 [854,858], but found it secure against differential cryptanalysis. However, he found a related-key-plaintext attack that reduces the complexity of a brute-force search by a factor of four. This attack exploits a weak ness in the key schedule and may also apply if the algorithm uses a weak hash function (Section 18.11)

Another attack on related keys can break LOKI9 with 2¹² chosen-key plaintexts, or 2⁴ chosen known plaintexts [158]. The attack is independent of the number of rounds of the algorithm. (In the same paper, Biham breaks LOKI9 with 2⁷ chosen-key chosen plaintexts or 2³ known-key chosen plaintexts using related-key cryptanalysis.) It's easy to make LOKI9 resistant to this attack; avoid the simple key schedule.
