2. Shift the ciphertext by that length and XOR it with itself. This removes the key and leaves you with plaintext XORed with the plaintext shifted length of the key. Since English has 1 bits of real information per byte [see Section 11.1], there is plenty of redundancy for determining a unique decryption.

Despite this, the long list of software vendors that tout this toy algorithm as "almost as secure as DES" is staggering [1387]. It is the algorithm (with a 160-bit repeated "key") that NASA finally allowed the U.S. digital cellular phones to use for voice pricey. An XOR might keep your kid sister from reading your files, but it won't stop a cryptanalyst for more than a few minutes.

# 1.5 One-Time PADS

Believe it or not, there is a perfect encryption scheme. It's called a one-time pad, and was invented in 1917 by Major Joseph Mauborg and AT&T's Gilbert Vernam [794]. (Actually, a one-time pad is a special case of a threshold scheme; see Section 3.7) A one-time pad is nothing more than a large nonrepeating set of random key letters, written on sheets of paper and glued together in a pad. In its original form, it was a one-time tape for telewriters. The sender uses each key letter on the pad to encrypt exactly one plaintext character. Encryption is the addition modulo 26 of the plaintext character and the one-time pad key character.

Each letter is used exactly once, for only one message. The sender encrypts the message and destroys the used pages of the pad or used section of the tape. The receiver has an identical pad and uses each key on the pad, in turn, to decrypt each letter of the ciphertext. The receiver destroys the same pad pages or tape section after decrypting the message. New message—new key letters. For example, if the message is:

```
ONETEPAD
```
