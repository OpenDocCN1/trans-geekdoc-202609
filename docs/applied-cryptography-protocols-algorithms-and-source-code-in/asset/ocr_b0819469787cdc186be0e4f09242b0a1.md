The meat of the book is the "Table of Random Digits." It lists them in 5-digit groups—"10097 32533 76320 13586 ...”—50 on a line and 50 lines on a page. The table goes on for 400 pages, and except for a particularly wacky section on page 283 which reads "69696," for a boring read. The book also includes a table of 100,000 normal deviates.

The interesting thing about the RAND book is not its million random digits, but that they were created before the computer revolution. Many cryptographic algorithms use arbitrary constants—so-called "magic numbers." Choosing magic numbers from the RAND tables ensures they haven't been specially chosen for some nefarious reason. Khafre does this, for example.

# Using Random Noise

The best way to collect a large number of random bits is to tap the natural randomness of the world. This method requires specialized hardware, but you can try with computers.

Find an event that happens randomly: atmospheric noise peaking at a certain threshold, a toddler falling while learning to walk, or some such. Measure the time interval between one event and the next. Record it. Measure the time interval between the second event and the third. Record it as well. If the first time interval is greater than the second, output 1 as the bit. If the second time is greater, output 0 as the event. Do it for the next event.

Throw a dart at the New York Stock Exchange closing prices in your local newspaper. Compare the price of the stock with the closing price of the stock directly above it. If the one you hit is higher, output 0; if it is less, output 1.

Hold a Geiger counter up to your computer, count emissions over a fixed time, and keep the least significant. Or measure the time between successive ticks (since the radioactive source is decaying, the average time between successive ticks is continuously increasing. You want to choose a source with a half life long enough to make negligible—like platinum. Or if you're worried about health, apply appropriate statistical corrections.)
