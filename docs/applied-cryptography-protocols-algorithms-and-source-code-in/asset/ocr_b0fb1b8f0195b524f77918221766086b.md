# Security of Blowfish

Sergio Vaden examined Blowfish with known S-boxes and r rounds; a differential attack can recover the P-array with 2**+1 plaintexts [1568]. For certain weak keys that generate bad S-boxes (the odds of getting them randomly are 1 in 2^24), the same attack requires only 2*-1 plaintexts to recover the P-array. With unknown S-boxes this attack can detect whether a weak key is being used, but cannot determine what (neither the S-boxes nor the P-array). This attack only works against reduced-round variants; it is completely against 16-round Blowfish.

Of course, the discovery of weak keys is significant, even though they seem impossible to exploit. A weak key is one in which entries for a given S-box are identical. There is no way to check for weak keys before doing the key expansion. If you are worried, you have to do the key expansion and check for identical S-box entries. I don't think this is necessary, though.

I know of no successful cryptanalysis against Blowfish. To be safe, do not implement Blowfish with a reduced number of rounds.

Kent Marsh has incorporated Blowfish in their FolderBolt security product for Windows and Macintosh. It is also part of Nautilus and PGPPhone.

# 14.4 SAFER

SAFER K-64 stands for Secure And Fast Encryption Routine with a Key of 64 bits [1009]. James Massey produced this proprietary algorithm for Cylk Corp, and it is incorporated into some of its products. The government of Singapore is planning to use this algorithm—with a 128-bit key [1010]—for a variety of applications. There are no patent, copyright, or other restrictions on its use.

The algorithm has a key size of 64 bits. It is not a Feistel network like DES (see Section 14.10), but an iterated block cipher: The function is applied for some number of rounds. Each round uses 64-bit subkeys, and the algorithm only operates on bytes.

# Description of SAFER K-64

The plaintext is divided into eight byte-length subblocks: $B_1, B_2, \dots, B_8$. Then the sub-blocks go through $r$ rounds. Finally, an output transformation is applied to the sub-blocks. Each round uses two subkeys: $K_{2i-1}$ and $K_{2i}$.
