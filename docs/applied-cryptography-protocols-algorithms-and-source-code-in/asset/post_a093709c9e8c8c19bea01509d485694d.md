# Solving for Coefficients

Euclid's algorithm can be used to solve this class of problems: Given an array of m variables $x_1, x_2 ... x_m$ find an array of m coefficients, $u_1, u_2 ... u_m$ such that

```
$x_1*u_1 + ... + u_m*x_m = 1$
```

# Fermat's Little Theorem

If $m$ is a prime, and not a multiple of $m$, then Fermat's little theorem says

```
$a^{m-1} \equiv 1 \pmod m$
```

(Pierre de Fermat, pronounced 'Fair-ma', was a French mathematician who lived from 1601 to 1665. This theorem has nothing to do with his last theorem.)

# The Euler Totient function

There is another function for calculating the inverse modulo $n$, but it's not always possible to use. The reduced set of residues mod $n$ is the subset of the complete set of residues that are relatively prime to $n$. For example, the reduced set of residues mod 2 is $[1,5,7,11]$. If $n$ is prime, then the reduced set of residues mod $n$ is the set of all numbers from 1 to $n-1$. The number 0 is never part of the reduced set of residues for any $n$ equal to 1.

The Euler totient function, also called the Euler function and written as $\phi(n)$, $\phi(n)$ is the number of elements in the reduced set of residues modulo $n$. In other words, $\phi(n)$ is the number of positive integers less than $n$ that are relatively prime to $n$ (for any $n$ greater than 1). (Leonhard Euler, pronounced 'Oiler', was a Swiss mathematician who lived from 1707 to 1783.)

If $n$ is prime, then $\phi(n) = n-1$. If $n = pq$, where $p$ and $q$ are prime, then $\phi(n) = (p-1)(q-1)$. These numbers appear in, public-key algorithms; this is why. According to Euler's generalization of Fermat's little theorem, if $gcd(a,n) = 1$, then

```
$a^{\phi(n)} \pmod n = 1$
```

Now it is to compute $a^{-1} \pmod n$:

```
$x = a^{\phi(n)-1} \pmod n$
```

For example, when is the inverse of 5, modulo 7? Since 7 is prime, $\phi(7) = 7-1 = 6$. So, the inverse of 5, modulo 7, is

$5^{-1} \mod 7 = 5^5 \mod 7 = 3$

Both methods for calculating inverses can be extended to solve for x in the general problem [if $\gcd(a,n) = 1$]:

```
$(a \cdot x) \mod n = b$
```

Using Euler's generalization, solve

```
$x = (b \cdot a^{\phi(n)-1}) \mod n$
```

Using Euclid's algorithm, solve

```
$x = (b \cdot (a^{-1} \mod n)) \mod n$
```

In general, Euclid's algorithm is faster than Euler's generalization for calculating inverses, especially in the 500-bit range. If $\gcd(a,n) \neq 1$, all is not lost. In this case, $(a \cdot x) \mod n = b$, can have multiple solutions or no solution.

# Chinese Remainder Theorem

If you know the prime factorization of $n$, then you can use the Chinese remainder theorem to solve a whole system of equations. The basic version of this theorem was discovered by the first-century Chinese mathematician, Sun Tse. In general, if the prime factorization of $n$ is $p_1, p_2, \dots, p_k$, then the system of equations:

```
$(x \mod p_i) = a_i$, where $i = 1, 2, \dots, t$
```

has a unique solution, $x$, where $x$ is less than $n$. (Note that some primes can appear more than once. For example, $p_i$ might be equal to $p_j$.) In other words, (less than the product of some) primes) is uniquely identified by its residues mod those primes.

For example, use 3 and 5 as primes, and 14 as the number. $14 \mod 3 = 2$, and 14. There is only one number less $3 \cdot 5 = 15$ which has those residues: The two residues uniquely determine the remainder.

So, for an arbitrary $a < p$ and $b < q$ (where $p$ and $q$ are prime), there exists a unique $x$, where $x$ is less than $pq$, such that

```
$x = (a \mod p)$, and $x = (b \mod q)$
```

To find $x$, use Euclid's algorithm to find $u$, such that

```
$u \cdot q = 1 \mod p$
```

Then compute:

```
$x = ((a - b) \cdot u) \mod q + b$
```

Here is the Chinese remainder theorem in C:

```c
/* r is the number of elements in arrays m and u;
   m is the array of (pairwise prime) moduli
   u is the array of coefficients
   totient() is left as an exercise to the reader. */
int chinese_remainder(size_t r, int *m, int *u) {
  size_t modulus;
  int n;
  modulus = 1;
  for (i=0; i<r; ++i)
    modulus *= m[i];
  n = 0;
  for (i=0; i<r; ++i)
    n += u[i] * modexp(modulus / m[i], totient(m[i]), modulus);
  n %= modulus;
  return n;
}
```

The converse of the Chinese remainder theorem can also be used to find the solution to the problem: if $p$ and $q$ are primes, and $p$ is less than $q$, there exists a unique $x$ less than $pq$, such that $x = (a \mod p)$, and $x = (b \mod q)$. If $a \ge b \mod p$, then $x = ((a - b \mod p) \cdot u) \mod q + b$. If $a < b \mod p$, then $x = ((a + p - b \mod p) \cdot u) \mod q + b$.

# Quadratic Residues

If $p$ is prime, and $a$ is greater than 0 and less than $p$, then $a$ is a quadratic residue mod $p$ for some $x$. Not all values of $a$ satisfy this property. The quadratic nonresidues mod $p$, although I will not do here, it is easy to prove that, when $p$ is odd, there are quadratic residues mod $p$ and the same number of nonresidues mod $p$. Also, if $a$ is a quadratic residue mod $p$, then $a$ has exactly two square roots, one of them between $0 and $(p-1)/2$, and the other between $(p-1)/2$ and $(p-1)$. For example, if $p = 7$, the quadratic residues are 1, 2, and 4:

```
1² = 1 (mod 7)
2² = 4 (mod 7)
3² = 2 (mod 7)
4² = 16 ≡ 2 (mod 7)
5² = 25 ≡ 4 (mod 7)
6² = 36 ≡ 1 (mod 7)
```

Note that each quadratic residue appears twice in this list. There are no values of $x$ which satisfy any of these equations:
$x^2 = 3 \mod 7$
$x^2 = 5 \mod 7$
$x^2 = 6 \mod 7$

# Legendre Symbol

The **Legendre symbol**, written $L(a,p)$, is defined when $a$ is any integer and $p$ is a prime greater than 2. It is equal to 0, 1, or -1.

$L(a,p) = 0$ if $a$ is divisible by $p$.
$L(a,p) = 1$ if $a$ is a quadratic residue mod $p$.
$L(a,p) = -1$ if $a$ is a quadratic nonresidue mod $p$.

One way to calculate $L(a,p)$:

$L(a,p) = a^{(p-1)/2} \pmod p$

Or you can use the following algorithm:

1. If $a=1$, then $L(a,p) = 1$
2. If $a$ is even, then $L(a,p) = L(a/2,p) \cdot (-1)^{(p-1)/8}$
3. If $a$ is odd (and $\neq 1$), then $L(a,p) = L(a \mod p,p) \cdot (-1)^{(a-1)(p-1)/4}$

Note that this is also an efficient way to determine whether $a$ is a quadratic residue mod $p$ (when $p$ is prime).

# Jacobi Symbol

The Jacobi symbol, written $J(a,n)$, is a generalization of the Legendre symbol to composite moduli; it is defined for any integer $a$ and any odd integer $n$. The function helps in primacy testing. The Jacobi symbol is a function on the set of reduced residues of $n$ and can be calculated by several formulas [1412]. This is one method:

- Definition 1: $J(a,n)$ is only defined if $n$ is odd.
- Definition 2: $J(0,n) = 0$.
- Definition 3: If $n$ is prime, the Jacobi symbol $J(a,n) = 0$ if $n$ divides $a$.
- Definition 4: If $n$ is prime, the Jacobi symbol $J(a,n) = 1$ if $a$ is a quadratic residue mod $n$.
- Definition 5: If $n$ is prime, the Jacobi symbol $J(a,n) = -1$ if $a$ is a quadratic nonresidue mod $n$.
- Definition 6: If $n$ is composite, the Jacobi symbol $J(a,n) = J(a,p_1) \dots J(a,p_m)$, where $p_1 \dots p_m$ is the prime factorization of $n$.

The following algorithm computes the Jacobi symbol recursively:

- Rule 1: $J(1,n) = 1$
- Rule 2: $J(ab,n) = J(a,n)J(b,n)$
- Rule 3: $J(2,n) = 1$ if $(n^2 - 1)/8$ is even, and -1 otherwise
- Rule 4: $J(a,n) = J(a \mod n,n)$
- Rule 5: $J(a,b_1b_2) = J(a,b_1)J(a,b_2)$
- Rule 6: If the greatest common divisor of $a$ and $b$ is 1, and $a$ and $b$ are odd:
    - Rule 6a: $J(a,b) = J(b,a)$ if $(a-1)(b-1)/4$ is even
    - Rule 6b: $J(a,b) = -J(b,a)$ if $(a-1)(b-1)/4$ is odd

If $n$ is the product of two primes, $p$ and $q$, then there are $(p-1)(q-1)/4$ quadratic residues mod $n$. A quadratic residue mod $n$ is a perfect square modulo $n$. This is because to be a square mod $n$, the residue must be a square mod $p$ and a square mod $q$. For example, there are 8 quadratic residues mod 35: 1, 4, 9, 11, 14, 15, 16, 25, 29, and 30. Each quadratic residue has exactly four square roots.
