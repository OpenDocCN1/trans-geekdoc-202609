# 19.5 RABIN

Rabin's scheme [1283,1601] gets its security from the difficulty of finding square roots modulo a composite number. This problem is equivalent to factoring. Here is one implementation of this scheme.

First two primes, $p$ and $q$, both congruent to 3 mod 4. These primes are the private key, the product $n = pq$ is the public key.
To encrypt a message, $M$ [must be less than $n$], compute

```
$C = M^2 \pmod n$
```

Decrypting the message is just as easy, but slightly more annoying. Since the receiver knows $p$ and $q$, he can solve the two congruences using the Chinese remainder theorem.\Compute

```
$m_1 = C^{1/4} \pmod p\n$m_2 = [p - C^{1/4}] \pmod p\n$m_3 = C^{1/4} \pmod q\n$m_4 = [q - C^{1/4}] \pmod q$
```

Then an integer $a = q(q^{-1} \pmod p)$ and an integer $b = p[p^{-1} \pmod q]$. The four possible solutions are:

```
$m_1 = [am_1 + bm_3] \pmod n\n$m_2 = [am_1 + bm_4] \pmod n\n$m_3 = [am_2 + bm_3] \pmod n\n$m_4 = [am_2 + bm_4] \pmod n$
```

One of those fours, $M_1, M_2, M_3$, or $M_4$, equals $M$. If the message is English, it should be easy to choose the $M_i$. On the other hand, if the message is a random-bit stream (say, for key generation or a digital signature), there is no way to determine which $M_i$ is correct. One way to solve this problem is to add a known header to the message before encrypting.

# Williams

Hugh Williams redefined Rabin's scheme to eliminate these shortcomings [1601]. In his scheme, $p$ and $q$ are selected such that

```
$p = 3 \pmod 8\n$q = 7 \pmod 8$
```

and

```
$N = pq$
```

Also, there is a small integer, $S$. such that $J(S,N) = -1$. ($J$ is the Jacobi symbol—Section 11.3). $N$ and $S$ are prime. The secret key is $k$, such that

```
$k = 1/2 \cdot \{1/4 \cdot (p-1) \cdot (q-1) + 1\}$
```
