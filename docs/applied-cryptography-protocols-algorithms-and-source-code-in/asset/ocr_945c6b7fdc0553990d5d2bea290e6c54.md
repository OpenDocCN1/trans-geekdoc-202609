These subkeys must all be calculated before encryption or decryption.
To encrypt a 1024-block X:

+   (1) Divide X into 256 32-bit sub-blocks: $X_0, X_1, X_2, \dots, X_{255}$.
(2) Permute the sub-blocks of X according to $P$.
(3) For $r=0$ to $3r
For $g=0$ to $2r
A = X_{(4g)} \ll 2r
B = X_{(4g+1)} \ll 2r
C = X_{(4g+2)} \ll 2r
D = X_{(4g+3)} \ll 2r
For step $s=0$ to $7
A = A \oplus f_i[B,C,D] + S_{512r} + 8g + s
TEMP = D
D = C
C = B
B = A \ll 5
A = TEMP
X_{(4g)} \ll 2r = A
X_{(4g+1)} \ll 2r = B
X_{(4g+2)} \ll 2r = C
X_{(4g+3)} \ll 2r = D$

+   (4) Recombine $X_0, X_1, X_2, \dots, X_{255}$ to form the ciphertext.

The functions $f_i[B,C,D]$ are similar to those used in MD5:
f_0[[B,C,D] = (B \wedge C) \lor (
eg B \wedge D)$
f_1[[B,C,D] = (B \wedge D) \lor (C \wedge 
eg D)$
f_2[[B,C,D] = B \oplus C \oplus D$
f_3[[B,C,D] = C \oplus (B \lor 
eg D)]$
