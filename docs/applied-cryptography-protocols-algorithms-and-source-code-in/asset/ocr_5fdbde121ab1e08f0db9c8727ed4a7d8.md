The current version of PGP is 2.6.2. A new version of PGP, PGP 3.0, is scheduled for release by the end of 1995. Changes in 3.0 include options for triple-DES, SHA, and other public-key algorithms, a split of the encryption and signature public key/private-key pairs, enhanced procedures for key revocation, improved key ring management functions, an API for integrating PGP in other programs, and a completely rewritten code base.
PGP is available for MS-DOS, UNIX, Macintosh, Amiga, and Atari. It is free for personal, non-commercial use, and available for many sites on the Internet. To ftp PGP from MIT, telnet to net-dist.mit.edu, log in getpgpp, answer the questions, then ftp to net-dist.mit.edu and change to the directory named in the telnet session.
