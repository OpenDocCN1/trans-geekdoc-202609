# CHAPTER 14 Still Other Block Ciphers

+   - The S-boxes in DES have 6-bit inputs and 4-bit outputs; the S-boxes in GOST have 4-bit inputs and outputs. Both algorithms have eight S-boxes, an S-box in GOST is one-fourth the size of an S-box in DES.

+   - DES has an irregular permutation, called a P-box; GOST uses an 11-bit left circular shift.

+   - DES has 16 rounds, GOST has 32 rounds.

If there is no way to break GOST other than brute force, it is a very secure algorithm. DES has a 256-bit key—longer if you count the secret S-boxes. Against differential and linear cryptanalysis, GOST is probably stronger than DES. Although the random their secrecy adds to GOST's resistance against differential and linear attacks. Also, both of these attacks depend on the number of rounds: the more rounds, the more difficult the attack. GOST has twice as many rounds as DES, this alone makes both differential and linear cryptanalysis infeasible.

The other parts of DES are either on par or worse than DES. GOST doesn't have the same expansion permutation that DES has. Deleting this permutation from DES weakens it by reducing the avalanche effect, it is reasonable to believe that DES is weaker for not having it. GOST's use of addition is no less secure than DES's XOR.

The greatest difference between them is GOST's cyclic shift instead of a permutation. The permutation increases the avalanche effect. In GOST a change in one input affects one S-box in one round, which then affects two S-boxes in the next round, and so on. GOST requires 8 rounds before a single change in an input affects every output; DES only requires 5 rounds. This is certainly a weakness. GOST has 32 rounds for DES's 16.

GOST's designers tried to achieve a balance between efficiency and security. They modified DES's design to create an algorithm that is better suited for software implementation. They have tried to be less sure of their algorithm's security, and have tried to compensate by making the key length very large, keeping the S-boxes secret, and doubling the number of iterations. Whether their efforts have resulted in an more secure than DES remains to be seen.

# 14.2 CAST

CAST was designed in Canada by Carlisle Adams and Tavares Tavares [10,7]. They claim that the name refers to their design procedure and should conjure images of randomness, but note the authors' initials. The early CAST algorithm uses a 64-bit block size and a 64-bit key.

The structure of CAST should be familiar. The algorithm uses six S-boxes with an 8-bit input and a 32-bit output. Construction of these S-boxes is implementation-dependent and complicated; see the references for details.
