Adleman synthesized picomols of the DNA representing each road, made them all together with the DNA representing the cities, and added a lipase enzyme, which links together the ends of DNA molecules. The clever relationship between the road DNA strings and the city DNA strings causes the lipase to link the road strings together in a legal fashion. That is, the "exit" end of the road from P to K will always be linked to the "entrance" end of some road that originates at City K, never to the "exit" end of any road and never to the "entrance" end of a road that originates at some city other than K. After a carefully limited reaction time, the lipase has a built representing legal but otherwise random paths within the graph.

From this soup of random paths, Adleman can find the finest trace—perhaps even a single molecule—of the DNA that represents the answer to the problem. Using common techniques of molecular biology, he decides all the DNA representing paths that are too long or too short.(The number of roads in the desired path must equal the number of cities minus one.)Next he discards all the DNA strings that do not pass through City A, then that miss City B, and so on. If any DNA survives this screening, it is easy to find the sequence of roads that represents: This is the solution to the directed Hamiltonian path problem.

By definition, an instance of any NP-complete problem can be transformed, in polynomial time, into an instance of any other NP-complete problem, and into an instance of the directed Hamiltonian path problem. Since the 1970s, cryptographers have been trying to use NP-complete problems for public-key cryptography.

While the instance Adleman solved was very modest (seven cities on his map, a problem that can be solved by inspection in a few minutes), the technique is in its infancy and has no although keeping it from being extended to larger problems. Thus, arguments for the security of cryptographic protocols based on NP-complete problems have become vogue. "Suppose an adversary is a million processors, each of which can perform a million tests each second," may have to be replaced with. "Suppose an adversary has a thousand fermentation vats, each 20,000 liters in capacity."

# Quantum Computing

Now it gets weird The underlying principle behind quantum computing involves Einstein's wave-particle duality. A photon can simultaneously exist in a large number of states. A classic example is that a photon behaves like a wave when it encounters a silver surface; it is both reflected and transmitted, just as an ocean wave striking a seawall with a small opening in it will reflect off the wall and pass through it. However, when a photon is measured, it behaves like a particle and only a single state can be detected.

[In1443] Peter Shor outlines a design for a factoring machine based on quantum mechanical principles. Unlike a classical computer, a quantum computer can be thought of as having a single, fixed state at a time, a quantum computer has an internal wave function, which is a superposition of the possible basis states. Computations transform the wave function, altering the entire set of states in a single operation. In this way, a quantum computer is an improvement over classical finite-automata.
