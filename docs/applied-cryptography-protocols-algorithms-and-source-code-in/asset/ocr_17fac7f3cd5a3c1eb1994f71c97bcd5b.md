# Cellular Automaton Generator

In [1608.1609], Steve Wolfram proposed using a one-dimensional cellular automata- ton a pseudo-random-number generator. Cellular automaton is not the subject of this book, Wolfram's generator consisted of a one-dimensional array of bits, $a_1$, $a_2, a_3, \dots, a_k, \dots, a_n$ and an update function:

```
$a_k = a_{k-1} \oplus (a_k \vee a_{k+1})$
```

The bit is extracted from one of the $a_k$ values, which one really doesn't matter. The generator's behavior appears to quite random. However, there is a known- plaintext attack against these generators [1052]. This attack works on a PC with values of $n$ up to 500 bits. Additionally, Paul proved that the output of a cellular automaton can also be generated by a linear-feedback shift register of equal length and is therefore no more secure [83].

# 1/p Generator

This generator was proposed, and then cryptanalyzed, in [193]. If the internal state of the generator at time $t$ is $x_t$,

```
$x_{t+1} = bx_t \pmod p$
```

The output of the generator is the least significant bit of $x$, div p, where div is the truncated division. For maximum period, the constants $b$ and $p$ should be chosen so that $p$ is prime and $b$ is a primitive root mod $p$. Unfortunately, this generator- is not secure. (Note that for $b=2$, an FCSR with a connection generator outputs the reverse of this sequence.)

# crypt(1)

The ORIGINAL encryption algorithm, crypt[1], is a stream cipher based on the same ideas as the Enigma. This is a 256-element, single-rotor substitution cipher with a reflector. Both the rotor and the reflector are generated from the key. This algorithm is far simpler than the World II German Enigma and, for a skilled cryptanalyst, very easy to break [1576,1299]. A public-domain UNIX program, called Crypt Breakers Workbench [CBW], can be used to break files encrypted with crypt[1].
