# 19.10 FINITE AUTOMATON PUBLIC-KEY CRYPTOSYSTEM

Chinese cryptographer Tao Renii has developed a public-key algorithm based on finite automaton [1301,1302,1303,1300,1304,666]. Just as it is hard to factor the product of two large primes, it is also hard to factor the composition of two finite automata. This is especially so if one or both of them is nonlinear.

Much of this research took place in China in the 1980s and was published in Chinese. Renii is starting to write in English. His main result was that certain nonlinear automaton (quasilinear automaton) possess weak inverses, and if only, they have a certain echelon matrix structure. This property disappears if they are composed with an invertible quasilinear automaton and a linear automaton, and in the public-key algorithm, the secret key is an invertible quasilinear automaton and a linear automaton, and the corresponding public key can be derived by multiplying them out by term. Data is encrypted by passing it through the public automaton, and decrypted by passing it through the inverses of its components (in some cases provided they have been set to a suitable initial state). This system works for both encryption and digital signatures.

The performance of such systems can be summed by saying that like McEliece's system, they run much faster than RSA, but require longer keys. The keylength thought to give similar security to 512-bit RSA is 2792 bits, and to 1024-bit RSA is 4152 bits. For the former case, the system encrypts data at 20,869 bytes/sec and decrypts data at 17,117 bytes/sec, running on a 33 MHz 80486.

Renii has published three algorithms. The first is FAPK0. This is a weak system which uses linear components, and is primarily illustrative. Two serious systems, FAPKC1 and FAPK2, use one linear and one nonlinear component each. The latter is more complex, and was developed in order to support identity-based operation.

As for their strength, quite a lot of work has been done on them in China [where there are now over 30 institutes publishing cryptography and security papers]. One can see from the considerable Chinese language literature that the problem has been studied.

One possible attraction of FAPKC1 and FAPK2 is that they are not encumbered by any U.S. patents. Thus, once the Diffie-Hellman patent expires in 1997, they will unquestionably be in the public domain.
