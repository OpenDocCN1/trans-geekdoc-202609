Another unique feature in the design is the use of **masks**. These are numbers derived from the key table that are used to select the tables in a given function within a given range. Both the value of the data and the masks are used together to select the function tables.
Assuming that brute force is the most efficient means of attack, REDOC II is very secure: $2^{160}$ operations are required to recover the key.
