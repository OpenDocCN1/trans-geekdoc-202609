For $l \ge 3$, xDES' is probably too big to be useful as a block algorithm. For example, the block size for xDES' is 6 times that of the underlying cipher, the key size is 21, and 21 encryptions are required to encrypt a block 6 times that of the underlying cipher. Triple encryption is faster.

# Quintuple Encryption

If triple encryption isn't secure enough—perhaps you need to encrypt tripleencryption keys using an even stronger algorithm—then multiples might be in order. Quintuple encryption is very strong against meet-in-the-middle attacks. (Similar arguments to the ones used with double encryption can show quadruple minimal security improvements over triple encryption.)

```
$C = E_{K_1}(E_{K_2}(E_{K_3}(E_{K_4}(E_{K_5}(P))))))\nP = D_{K_1}(D_{K_2}(D_{K_3}(D_{K_4}(D_{K_5}(C)))))$
```

This construction is compatible with triple encryption if $K_2 = K_5$, and is backwards compatible with single encryption if $K_1 = K_5 = K_3$. Of course, it might be even stronger if all five keys were independent.

# 15.5 CDMF KEY SHORTENING

This method was designed by IBM for their Commercial Data Masking Facility or CDMF [see Section 24.8] to shrink a 56-bit DES to a 40-bit key suitable for [785]. It assumes that the original DES includes the parity bits.

+   (1) Zero the parity bits: 8, 16, 24, 32, 40, 48, 56, 64.
(2) Encrypt the output of step [1] with DES and the key 0xc408b0540ba0eaeac, and XOR the result with step [1].
(3) Take the output of step [2] and zero the following bits: 1, 2, 3, 4, 8, 16, 17, 18, 19, 20, 24, 32, 33, 34, 35, 36, 40, 48, 49, 50, 51, 52, 56, 64.
(4) Encrypt the output of step [3] with DES and the following key: 0xef2c04ce63832fe6. This key is then used for message encryption.

Remember that this method shortens the key length, and thereby weakens the algorithm.

# 15.6 WHITENING

Whitening is the given name to the technique of XORing some material with the input to a block algorithm, and XORing other key material with the output. This was first done in the DESX variant developed by RSA Data Security, Inc., and then (presumably independently) in Khufu and Khare. (Rivest named this technique; it's a nonstandard usage of the word.)
