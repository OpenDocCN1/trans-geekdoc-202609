# 6.1 Secure Elections

+   (4) The voter unblinds the messages and is left with a set of votes signed by twice the CTF. (These votes are signed unencrypted, so the voter can easily see which vote is "yes" and which is "no.")

+   (5) The voter chooses one of the votes (ah, democracy) and encrypts it with the CTF's public key.

+   (6) The voter sends his vote.

+   (7) The CTF decrypts the votes, checks the signatures, checks its database for a duplicate identification, saves the serial number, and tabulates the votes. It publishes the results of election, with every serial number and its associated vote.

A malicious voter, call Mallory, cannot cheat this system. The blind signature protocol ensures that his votes are unique. If he tries to send in the same vote twice, the CTF will notice the duplicate serial number in step [7] and throw out the second vote. If he tries to get multiple votes signed in step (2), the CTF will discover this in step (3). Mallory cannot generate his own votes because he doesn't know the facility's private key. He can't intercept and change other people's votes for the reason.

The cut-and-choose protocol in step (3) is to ensure that the votes are unique. Without that step, Mallory could create a set of votes that are the same for the identification number, and have them all validated.

A malicious CTF cannot figure out how individuals voted. The blind signature protocol prevents the facility from seeing the serial numbers on the votes before they are, the CTF cannot link the blinded vote signed with the vote eventually count. Publishing a list of serial numbers and their votes allows voters to confirm that their vote was tabulated correctly.

There are problems. If step (6) is not anonymous and the CTF can record who sent in which vote, then it can figure out who voted. However, if it receives votes in a locked box and then tabulates them later, it. Also, while the CTF may not be able to link votes to individuals, it can generate a large number of signed, valid votes by submitting those itself. And if Alice discovers that the CTF changed her vote, she has no way to prove it. A similar protocol, to solve these problems, is [1195,1370].

# Voting with Two Central Facilities

One solution is to split the CTF in two. Neither party would have the power to cheat on its one.

The following protocol uses a Central Legitimacy Agency (CLA) to certify voters and a separate CTF to count votes [1373].

+   [1] Each voter sends a message to the CLA asking for a validation number.

+   [2] The CLA sends the voter back a random validation number. The CLA maintains a list of validation numbers. The CLA also keeps a list of the validation numbers' recipients, in case someone tries to vote.
