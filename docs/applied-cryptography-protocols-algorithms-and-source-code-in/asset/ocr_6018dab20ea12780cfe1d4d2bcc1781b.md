# 16.12 PKZIP

Roger Schla designed the encryption algorithm built into the PKZIP data program. It's a stream cipher that encrypts data one byte at a time. At least, this is the algorithm in version 2.04g. I can't speak for later versions, but unless there is some amount you can probably assume that they are identical. The algorithm uses 32-bit variables, initialized as follows:

```
K_0 = 305419896
K_1 = 591751049
K_2 = 878082192
```

It has an 8-bit key, derived from K_2. Here is the algorithm [all symbols are standard C notation]:
C_i = P ^ K_5
K_0 = crc32(K_0 & 0x000000ff)
K_1 = K_1 • 1347758813 + 1
K_2 = crc32([K_2, K_1] >> 24)
K_3 = {[K_2 | 2]} | {(K_2 ^ 1]} >> 8

The function crc32 takes the previous value and a byte, XOR them, and calculates the next value by the CRC polynomial denoted by 0xebd88320. In practice, a 256-entry table can be precomputed and the crc32 calculation becomes:

```
crc32(a, b) = (a >> 8) ^ table[(a & 0xff) ^ b]
```

The table is precomputed by the original definition of crc32:

```
table[i] = crc32(i, 0)
```
