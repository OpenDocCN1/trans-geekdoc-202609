# ## 22.1 DIFFIE-HELLMAN

Diffie-Hellman was the first public-key algorithm ever invented, back way in 1976
[496]. It gets its security from the difficulty of calculating discrete logarithms in a
finite field, as compared with the ease of calculating exponentiation in the same
field. Diffie-Hellman can be used for key distribution—Alice and Bob can use this
alg to generate a secret key—but it cannot be used to encrypt and decrypt
messages.

The math is simple. Alice and Bob agree on a large prime, $n$ and $g$, such that
g$ is primitive mod $n$. These two integers do not have to be secret; Alice and Bob can
agree over some insecure channel. They can even be common among a
group of users. It doesn't matter.

Then, the protocol goes as follows:

+   (1) Alice chooses a random integer $x$ and sends Bob
$X = g^x \bmod n$

+   (2) Bob chooses a random integer $y$ and sends Alice
$Y = g^y \bmod n$

+   (3) Alice computes
$k = Y^x \bmod n$

+   (4) Bob computes
$k' = X^y \bmod n$
