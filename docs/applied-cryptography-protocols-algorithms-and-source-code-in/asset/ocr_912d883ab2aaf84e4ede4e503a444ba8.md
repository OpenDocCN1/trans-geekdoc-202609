The greater the bias, the greater the success rate with the same amount of data.

How do you identify good linear approximations for DES? Find good 1-round linear approximations and join them together. [Again, ignore the initial and final permutations; they do not affect the attack.] Look at the S-boxes. There are 6 input bits and 4 outputs. The input bits can be combined using XOR in 63 useful ways ($2^6-1$), and the output bits can be combined in 15 useful ways. Now, for each S-box you can evaluate the probability that for a randomly chosen input, an XOR combination equals some output XOR combination. If there is a combination with a high bias, then linear cryptanalysis will work.

If the linear approximations are unbiased, then they would hold for 32 of the 64 possible inputs. I spent the pages of tables, the most biased S-box is S-box 5. In fact, the second input bit equal to the XOR of all 4 output bits for only 12 inputs. This translates to a probability of $\Upsilon_6$, or a bias of $\Upsilon_6$, and is the most extreme bias in all the S-boxes. [Shamir noted in [1423], but could not find a way to exploit it]
