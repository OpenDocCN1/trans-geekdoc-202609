# Security of RSA

The security of RSA depends wholly on the problem of factoring large numbers. Technically, it's a lie. It is conjectured that the security of RSA depends on the problem of factoring numbers. It has been mathematically proven that you need to factor $n$ from $c$ and $e$. It is conceivable that an entirely different way to analyze RSA might be discovered. However, if this new way allows the cryptanalyst to deduce $d$, it could also be used as a new way to factor large numbers. One would worry much about it.

It is also possible to attack RSA by guessing the value of $\{p-1\}|q-1\}$. This attack is no easier than factoring $n$ $[116]$.

For the ultraskept, some RSA variants have been proved to be as difficult as factoring (see Section 19.5). Also look at [36], which shows that recovering even bits of information from an RSA-encrypted ciphertext is as hard as decrypting the entire message.

Factoring $n$ is the most obvious method of attack. Any adversary will have the public key, $e$, and the modulus. To find the decryption key, $d$ has to factor $n$. Section 11.4 discusses the current state of factoring technology. Currently, a 129-decimal-digit modulus is at the edge of factoring technology. So, $n$ must be larger than that. Read Section 7.2 on public key length.

It is possible for a cryptanalyst to try every $d$ until he stumbles on the correct one. This brute-force attack is even less efficient than factoring $n$.

From time to time, people claim to have found easy ways to break RSA, but no such claim has held up. For example, in 1993 a draft paper by William Payne proposed a method based on Fermat's little theorem [1234]. Unfortunately, this method is slower than factoring the modulus.
