# Initialization Vector

The OFB shift register must also be initially loaded with an IV. It should be unique but does not have to be secret.

# Error Propagation

OFB mode has no error extension. A single-bit error in the ciphertext causes a single-bit error in the recovered plaintext. This can be useful in some digitized voice or video, where the occasional single-bit error can be tolerated without error extension cannot.

On the other hand, a loss of synchronization is fatal. If the shift registers on the encryption end and the decryption end are not identical, then the recovered plaintext will be gibberish. Any system that uses OFB must have a mechanism for detecting a synchronization loss and a mechanism to fill both shift registers with new (or the same) IV to regain synchronization.
