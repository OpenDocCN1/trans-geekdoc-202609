The code is a little more complicated when the shift register is longer than the computer's word size, but not significantly.

Note that all of these listed LFRs have an odd number of coefficients. I have provided such a large table for stream-cipher cryptography and I wanted many examples so that people would pick primitive polynomials. Since, if $p(x)$ is primitive, then $x^a p(1/x)$ entry is actually two primitive polynomials.

For example, if $[a, b, 0]$ is primitive, then $[a, a - b, 0]$ is also primitive. If $[a, b, c, 0]$ is primitive, then $[a - d, a - c, a - b, 0]$ is also primitive. Mathematically:

```
$x^a + x^b + 1$ is primitive, so is $x^a - x^b + 1$
if $x^a + x^b + x^d$ is primitive, so is $x^a - x^d + x^c - c + x^b - b + 1$
```
