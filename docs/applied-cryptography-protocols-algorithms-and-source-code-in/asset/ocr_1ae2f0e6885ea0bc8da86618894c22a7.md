# 5.9 SIMULTANEANEOUS EXCHANGE OF SECRETS

Alice knows secret A; Bob knows secret B. Alice is willing to tell Bob A if Bob is willing to tell Alice B, if Alice tells him A. This protocol, observed in a schoolyard, does not work:

+   (1) Alice: “I’ll tell you if you tell me first."

+   (2) Bob: “I’ll tell you if you tell me first."
