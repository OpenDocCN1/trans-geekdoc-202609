# 23.9 All-or-Nothing Disclosure of Secrets

(1) Alice uses the RSA algorithm. The key pair she will use with Bob is: $n=7387, e = 5145,$ and $d = 777$. The key pair she will use with Carol is: $n=2747, e = 1421,$ and $d = 2261$. She tells Bob and Carol each their public key.

(2) Bob generates eight 12-bit numbers, $B_1=743, B_2=1988, B_3=4001, B_4=2942, B_5=3421, B_6=2210, B_7=2306,$ and tells them to Carol. Carol generates eight 12-bit numbers, $C_1=1708, C_2=711, C_3=1969, C_4=3112, C_5=4014, C_6=2308, C_7=2212,$ and $C_8=222,$ and tells them to Bob.

(3) Bob wants $S_7$, so he encrypts $C_7$ with the public key that Alice gives him.

```
$2212^{545} \pmod{3078} = 5928$
```

Now,

```
$2212 = 0100010100100\n5928 = 1011110010100$
```

So, the FBI of two numbers is $[0, 1, 4, 5, 6]$. He sends them to Carol. Carol wants to $S_2$, so she encrypts $B_2$ with the public key that Alice gave and gets the FBI of $B_2$ with the result of her encryption. She sends $[0, 1, 2, 6, 9, 10]$ to Bob.

(4) Bob takes $B_1, B_2,...,B_7$ and replaces every bit whose index is not in the $[0, 1, 2, 6, 9, 10]$ with his component. For example:

```
$B_2 = 111111001000 = 1988\nB'_2 = 0100111101000 = 1660$
```

He sends $B'_1, B'_2,...,B'_7$ to Alice. Carol takes $C_1, C_2,...,C_7$ and replaces every bit whose index is not in the $[0, 1, 4, 5, 6]$ with her component. For example:

```
$C_7 = 0100010100100 = 2212\nC'_7 = 1011110110100 = 5928$
```

She sends $C'_1, C'_2,...,C'_7$ to Alice.

(5) Alice decrypts $C'_7$ with Bob's private key and XORs the results with $S_7$. For example, for $i = 7:$

```
$5928^{777} \pmod{2212} = 2546; 2546 \oplus 2212 = 342$
```

She sends the results to Bob. Alice decrypts $B'_i$ with Carol's private key and XORs the results with $S_i$. For example, for $i = 2:$

```
$1660^{261} \pmod{2748} = 1988; 471 \oplus 1988 = 1555$
```

She sends the results to Carol.

(6) Bob gets $S_7$ by XORing $C_7$ and the seventh number he received from Alice.
