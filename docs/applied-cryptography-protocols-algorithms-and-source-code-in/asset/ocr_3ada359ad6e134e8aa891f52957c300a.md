# 11.2 Complexity Theory

The class NP includes the class P, because any problem solvable in polynomial time on a deterministic Turing machine is also solvable in polynomial time on a nondeterministic Turing machine, the guessing stage can be simply omitted.

If all NP are solvable in polynomial time, then P = NP. It seems obvious that some NP problems are much harder than others (a brute-force attack against an encryption algorithm using a random block of plaintext); it has never been proven that P ≠ NP (or that P = NP). However, most people working in complexity theory believe that they are unequal.

Stranger still, some problems in NP can be proven to be as difficult as possible in the propositional Boolean formula. Steven Cook [365] proved that the Satisfiability problem (given a Boolean formula, is there a way to assign true values to the variables that makes the formula true?) is NP-complete. This means that, if Satisfiability is solvable in polynomial time, then P = NP. Conversely, if any problem in NP can be proven not to have a deterministic polynomial-time algorithm, the proof will show that Satisfiability does not have a deterministic polynomial-time either. No problem is harder than Satisfiability in NP.

Since Cook's seminal paper was published, a huge number of problems have been shown to be equivalent to Satisfiability; hundreds are listed in [600], and some examples follow. By equivalent, I mean that these problems are NP-complete; they are in NP and as hard as any problem in NP. If their solvability in polynomial time were resolved, the previous NP question would be solved. The question of whether P = NP is the central unresolved question of computational complexity theory, and one objective to solve anytime. Whoever shows that P = NP, then most of this would be irrelevant: As previously explained, many classes of ciphers are trivially breakable in nondeterministic polynomial time. If P = NP, then they are breakable by feasible, deterministic algorithms.

Further out the complexity hierarchy is PSPACE. Problems in PSPACE are solvable in polynomial space, but not necessarily polynomial time. PSPACE includes NP, but some problems in PSPACE are thought to be harder than NP. Of course, this isn't proven either. There is a class of problems, the so-called PSPACE-complete problems, with the property that, if any one of them is in NP then PSPACE = NP and if any one of them is in P then PSPACE = P.
