# Poor Choices

When people choose their keys, they generally choose poor ones. They're far likely to choose "Barney" or "9 [hH/A]." This is not always due to security practices, "Barney" is easier to remember than "9 [hH/A]." The most secure algorithm won't help much if the users habitually choose their spouse's names for keys or their keys on little pieces of paper in their wallets. A smart brute-force attack doesn't try all keys in numerical order, it threatens the others keys.

This is called a dictionary attack, because the attacker uses a dictionary of commons. Daniel Klein was able to crack 40 percent of the passwords on the average using this system [87,848].
