# RSA

This RSA generator [35,36] is a modification of [200]. The initial parameters of true modulus $N$ which is two large primes $p$ and $q$, an integer $e$ which is relatively prime to $(p-1)$ $[q-1]$, and a random seed $x_0$ where $x_0$ is less than $N$.

```
$x_i = x_0^e \pmod N$
```

The output of the generator is the least significant bit of $x_i$. The security of this generator is based on the difficulty of breaking RSA. If $N$ is large enough, then the generator is secure. Additional theory can be found in [1569.1570,1571,30,354].

# Blum, Blum, and Shub

The simplest and most efficient complexity-theoretic generator is called the Blum, Blum, and Shub generator, after its inventors. Mercifully, we abbreviate to BBS, although it is sometimes called the quadratic residue generator [193]. The theory behind the BBS generator is to do with quadratic residues modulo $n$ [see Section 11.3]. Here's how it works.

First two prime numbers, $p$ and $q$, which are congruent to 3 modulo 4. The product of these numbers, $n$, is a Blum integer. Another random integer, $x$, which is relatively prime to $n$. Compute

```
$x_0 = x^2 \pmod n$
```

That's the seed for the generator. Now you can start computing. The $i$th pseudo-random bit is the least significant bit of $x_i$,

```
$x_i = x_{i-1}^2 \pmod n$
```

The most intriguing property of this generator is that you don't have to iterate through $i-1$ bits to get the $i$th bit. If you know $p$ and $q$, you can compute the $i$th bit directly.

```
$b_i = x_0^{(2^{i-1})/\phi(n)}} \pmod n$
```

This property means you can use this cryptographically strong pseudo-random generator as a cryptsystem for random-access file. The security of this scheme is based on the difficulty of factoring $n$. You can make $n$ public, so anyone can generate bits using the generator. However, unless a cryptanalyst factors $n$, he can never predict the output of the generator—not even with a statement: "The next bit has a 51 percent chance of being a 1."

More strongly, the BBS generator is unpredictable to the left and unpredictable to the right. This means that any given sequence generated by the generator, a cryptanalyst cannot predict the next bit in the sequence the previous bit in the sequence. This is not security based on some complicated generator that no one understands, but the mathematics behind factoring $n$.
