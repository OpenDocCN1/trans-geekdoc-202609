# LFSR/FCSR Summation/Parity Cascade

The theory is that addition with carry destroys the algebraic properties of LFSRs, and XOR destroys the algebraic properties of FCSRs. This generator combines those, as used in the LFSR/FCSR Summation Generator and the LFSR/FCSR Parity Generator just listed, with the Gollmann cascade.

The generator is a series of arrays of registers, with the clock of each array controlled by the previous array. Figure 17.6 is one using using addition with carry. The first array of LFSRs is clocked and the results are combined using addition with carry. If the input of this combining function is 1, then the next [of FCSRs] is clocked and the output of those FCSRs is combined with the previous combining function using XOR. If the output of the first combining function is 0, then the array of FCSRs is not clocked and the output is simply added to the carry from the previous round. If the output of this second combining function is 1, then the third array of LFSRs is clocked, and so on.

This generator uses lot of registers: $n, m$, where $n$ is the number of stages and $m$ is the number of registers per stage. I recommend $n=10$ and $m=5$.

# Alternating Stop-and-Go Generators

These generators are stop-and-go generators with FCSRs instead of some LFSRs. Additionally, the XOR operation can be replaced with an addition with carry [see Figure 17.7].
