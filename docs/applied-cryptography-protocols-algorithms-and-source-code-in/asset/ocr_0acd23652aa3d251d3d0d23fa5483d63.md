# 18.5 MD5

MD5 is an improved version of MD4 [1386,1322]. Unlike more complex than MD4, it is similar in design and also produces a 128-bit hash.

# Description of MD5

After some initial processing, MD5 processes the input text in 512-bit blocks, divided into 16 32-bit sub-blocks. The output of the algorithm is a set of 32-bit blocks, which concatenate to a single 128-bit hash value.

First, the message is padded so that its length is just 64 bits short of being multiple of 512. This padding is a single 1 bit added to the end of the message, followed by as many zeros as required. Then, a 64-bit representation of the message's length (before padding bits added) is appended to the result. These two steps to make the message length an exact multiple of 512 bits in length [required for the rest of the algorithm], while ensuring that different messages will not look the same after padding.

Four 32-bit variables are initialized:

```
A = 0x01234567
B = 0x89abcdef
C = 0xfcedcba98
D = 0x76543210
```

These are chained variables.

Now, the main loop of the algorithm begins. This continues for as many 512-bit blocks as in the message.

The four variables are copied into different variables: a gets A, b gets B, c gets C, and d gets D.
