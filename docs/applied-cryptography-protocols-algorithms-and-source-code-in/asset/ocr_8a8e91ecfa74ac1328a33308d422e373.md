# Preface

I have done my best to hunt and eradicate all errors in this book, but many I have assured that it is an impossible task. Certainly, the second edition has fewer errors than the first. An errata listing is available from me and will be periodically posted to the Usenet newsgroup sci.crypt. If any reader finds an error, please let me know. I'll send the first person to find each error in the book a free copy of the source code deisc.
