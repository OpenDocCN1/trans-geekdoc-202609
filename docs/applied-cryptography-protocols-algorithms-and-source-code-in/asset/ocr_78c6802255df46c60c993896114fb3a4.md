# 7.1 Symmetric Key Length

This machine consisted of a million chips, each capable of testing a mil-lion keys per second. Such a machine could test 2^56 keys in 20 hours. If built to attack an algorithm with a 64-bit key, it could test all 2^64 keys in 214 days.
A brute-force attack is tailor-made for parallel processors. Each processor can test a subset of the keyspace. The processors do not have to communicate among-selves; the only communication required is all a single message signifying suc-cess. It is easy to design a machine with a million parallel processors, each working independent of the others.

More recently, Michael Wiener decided to design a brute-force cracking machine (DES)[1597,1598]. He designed the machine for DES, but the analysis holds for almost any-algorithm. He specialized chips, boards, and racks. He estimated prices. And discovered that for $1 million, someone could build a machine that could crack a 56-bit DES in an average of 3.5 hours (results guaranteed in 7 hours). Table 7.1 generalizes these to a variety of key lengths. Remember Moore's Law: Computing power doubles approximately 18 months. This means costs go down by a factor of 10 every five years; what cost $1 million to build in 1995 would cost $100,000 in the year 2000. Pipelined computers might do even better [1224].

For 56-bit keys, these numbers are within the budgets of most large companies and many criminal organizations. The military budgets of most industrialized nations can afford to break 80-bit key is still beyond the realm of possibility, if current trends continue that will in 30 years.

Of course, it is ludicrous to estimate computing power 35 years in the future. Breakthroughs in science-fiction technology could make these numbers look like a joke. Conversely, physical limitations at the present time could make them unrealistically optimistic. In cryptography it is wise to be pessimistic. Fielding an algorithm with an 80-bit key seems extremely short-sighted. Insist on at least 112-bit keys.
