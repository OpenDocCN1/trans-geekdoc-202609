# CHAPTER 11 Mathematical Background

With judicious storing of intermediate results, you only need six multiplications:
((((a^2 mod n)*a mod n)^2 mod n^2 mod n^2)*a mod n

This is called addition chaining, [863], or the binary square and multiply method. It uses a simple and obvious addition chain based on the binary representation. In C, it looks like:

```
unsigned long q2(unsigned long x, unsigned long y, unsigned long n) {
    unsigned long s,t,u;
    int i;
    s = 1; t = x; u = y;
    while(u) {
        if(u&1) s = (s*t)%n;
        u>>=1;
        t = (t*t)%n;
    }
    return(s);
}
```

Another, recursive, algorithm is:

```
unsigned long fast_exp(unsigned long x, unsigned long y, unsigned long n) {
    unsigned long tmp;
    if(y==1) return (x % n);
    if((y&1)==0) {
        tmp = fast_exp(x,y/2,n);
        return (tmp*tmp)%n;
    } else {
        tmp = fast_exp(x,(y-1)/2,n);
        tmp = (tmp*tmp)%n;
        tmp = (tmp*x)%n;
        return (tmp);
    }
}
```

This technique reduces the operation to, on the average, 1.5·k operations, if k is the length of the number x in bits. Finding the calculation with the fewest operations is a hard problem (it has proven that the sequence must contain at least k-1 operations), but it is not too hard to get the number of operations down to 1.1·k or better, as k grows.

An efficient way to do modular reductions using the same y is Montgomery's method [1111]. Another method is Barrett's algorithm [87]. The software performance of these two algorithms and the algorithm previously discussed is in [210]. The algorithm I've discussed is the best choice for singular modular reductions, Barrett's algorithm is the best choice for small arguments; and Montgomery's method is the best choice for general modular exponentiations. Montgomery's can also take advantage of small exponents, using something called mixed arithmetic.
