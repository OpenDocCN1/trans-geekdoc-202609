# 17.14 Real Random-Sequence Generators

One solution is to clock the generator multiple times. If you want independent streams, clock the generator three times and send 1 bit into each stream. This technique works, but you may have trouble clock the generator as fast as you would like. If you only clock the generator three times as fast as the data stream, you can create three streams. Another way is to use the sequence for each channel—perhaps a variable time delay. This is insecure.

A clever idea [1489], patented by the NSA, is shown in Figure 17.11. Dump the output of your variable generator into an m-bit shift register. At each clock pulse, shift the register to the right. Then, for each output stream, AND the register with a m-bit bit control vector viewed as a unique identifier for the desired output stream, XOR all the bits together to get the output bit for that stream. If you want several output streams in parallel, you need a separate control vector and XOR/AND logic for each output stream.

There are some things to watch out for. If any of the streams are linear combinations of other streams, the system can be broken. But if you are clever, this is an easy and secure way to solve the problem.
