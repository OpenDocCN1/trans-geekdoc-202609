The three different variables can take on one of four possible values, so there are
64 schemes of this type. Bart Preneel showed them all [1262].

Fifteen are trivially weak the result does not depend on one of the inputs.
Thirty-seven are secure for more subtle relations. Table 18.1 lists the 12 secure
schemes remaining: The first 4 are secure against all attacks (see Figure 18.9) and
t last 8 are secure against all but a fixed-point attack, which is not really worth
worrying about.

The first scheme was described in [1028]. The third scheme was described in
[1555,1105,1106] and proposed as an ISO standard [766]. The fifth scheme was
proposed by Carl Meyer, which is commonly called Davies-Meyer in the literature
[1606,1607,434,1028]. The tenth scheme was proposed as a hash-function mode for
OKI [273].

The first, second, third, fourth, ninth, and eleventh schemes have a hash rate of l;
key equals the block length. The others have a rate of k/n, where k is thenkey length. This means that if the key is shorter than the block length, the
message block can only be the length of the key. It is not recommended that the
message be longer than the key length, even if the encryption algorithm's key
length is longer than the block length.

If the block algorithm has a DES-like complementarity property and DES-like
weak keys, there is an additional attack that is possible against all 12 schemes. The
attack isn't very dangerous and not really worth worrying about. However, you can
solve it by fixing bits 2 and 3 of the key to “01” or “10” [1081,1107]. Of course, this
reduces the length of k from 56 bits to 54 bits (in DES, for example) and decreases
hash rate.
