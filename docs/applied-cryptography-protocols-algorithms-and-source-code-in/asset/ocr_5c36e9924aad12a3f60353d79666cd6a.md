# 15.3 Doubling THE BLOCK LENGTH

There is argument in the academic community whether a 64-bit block is long enough. On the one hand, a 64-bit block length only diffuses plaintext over 8 bytes of ciphertext. On the other hand, a longer block length makes it harder to hide patterns securely; there is more room to make mistakes. some propose doubling the block length of an algorithm using multiple encryptions [299].
