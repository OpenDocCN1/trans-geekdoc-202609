#  3.2 AUTHENTICATION

When Alice logs into a host computer (or an automatic teller, or a telephone bank-\ing system, or any other type of terminal), how does the host who know she is? How\oes the host know she knows is not Eve trying to falsify Alice's identity? Traditionally,
passwords solve this problem. Alice enters her password, and the host confirms that
it is correct. Both Alice and the host know this secret of knowledge and the
host requests from Alice every time she tries to log in.

# Authentication Using One-Way Functions

What Rogeder and Mike Guy realized that the host does not need to
know the passwords; the host just has to differentiate valid passwords
from invalid passwords. This is easy with one-way functions [1599,526,1274,1121].
Instead of storing, the host stores one-way functions of the passwords.

+   (1) Alice sends the host her password.
(2) The host performs a one-way function on the password.
(3) The host compares the result of the one-way function to the value it pre-\viously stored.

Since the host no longer stores a tale of everybody's valid password, the threat of
some breaking into the host and stealing the password list is mitigated. The list
of passwords operated by the one-way function is useless, the one-way
function cannot recover the passwords.

# Dictionary Attacks and Salt

A file of passwords encrypted with a one-way function is still vulnerable. In
spare time, Mallory collects a list of 1,000,000 common passwords. He
ates on all 1,000,000 of them with the one-way function and stores the results. If
each password is 8 bytes, the resulting file will be no more than 8 megabytes,
it will fit on a few floppy disks. Mallory stores an encrypted password file. He
compares that file with his file of encrypted passwords and sees what
matches.

This is a dictionary attack, and it's surprisingly successful [Section 8.1]. Salt is
a way to make it more difficult. Salt is a random string that is concatenated
befores being operated by the one-way function. Then, both the salt
value and the result of the one-way function are stored in a database of the host.
inthe number of possible salt values is large enough, this practically eliminates a dic-
tary attack against commonly used passwords because Mallory has to generate
the-way hash for each possible salt value. This is a simple attempt at an initial-
ization vector (see Section 9.3).
