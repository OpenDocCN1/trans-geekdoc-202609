Then, sub-blocks are either XORed or added with bytes of subkey $K_{zi}$. The results of this operation are fed through three layers of linear operations designed to increase the avalanche effect. Each operation is called a Pseudo-Hadamard Transform (PHT). If the inputs to a PHT are $a_i$ and $a_j$, then the outputs are:

```
$b_i = (2a_i + a_j) \pmod{256}$
$b_j = (a_i + a_j) \pmod{256}$
```

After $r$ rounds, the first is a final output transformation. This is the same as the first of each round. $B_1, B_3, B_5,$ and $B_7$ are XORed with the corresponding bytes of the last subkey, $B_2, B_4, B_6,$ and $B_r$ are added to the corresponding bytes of the subkey. The result is the ciphertext.
