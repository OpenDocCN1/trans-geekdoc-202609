# Combining Linear Congruential Generators

Various people examined the combination of linear congruential generators [1595,941]. The results are no more cryptographically secure, but the combinations have longer periods and perform better in random tests [941].nUse this generator for 32-bit computers

> /*combinedLCG returns a pseudorandom value in the range
* (0,1). It combines linear congruential generators with
* periods of 2^31-1 and 2^31-1, and has a period that is the
* product of these two numbers. */

```
double combinedLCG ( void ) {
  long q;
  long z;

  MODMULT (53668, 40014, 12211, 2147483563, s1)
  MODMULT (52274, 40692, 3791, 2147483399, s2)
  z = s1 - s2;
  if (z < 1)
    z += 2147483562;
  return z * 4.656613e-10;
}
```

```
/* In general, call initLCG before combinedLCG. */
void initLCG ( long initS1, long initS2 ) {
  s1 = InitS1;
  s2 = InitS2;
}
```

This generator works as the machine can represent all integers between -2^31+85 and 2^31-85. The variables, s1 and s2, are global; they hold the current state of the generator. Before the first call, they must be initialized. The variable s1 needs an initial value between 1 and 2147483562, the variable s2 needs an initial value between 1 and 2147483398. The generator has a period somewhere in the neighbor-hood of 10^18.
