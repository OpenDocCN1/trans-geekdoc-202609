Capstone provides the cryptographic functionality needed for secure electronic commerce and other computer-based applications. The first application of Capstone is in a PCMCIA card called Forteza (It was originally called Tessera until a company called Tessera, Inc. complied).

NSA had considered lengthening Capstone's LEAF checksum in production versions for use in Forteza, in order to fuel the brute-force attack against the LEAF previously discussed. Instead, they added a feature that resists the card after 10 incorrect LEAFS. This only increases the time to find a but valid LEAF by 10 percent, to 46 minutes. I am not impressed.

# 24.18 AT&T MODEL 3600 TELEPHONE SECURITY DEVICE (TSD)

AT&T Telephone Security Device (TSD) is the Clipper phone. Actually, there are four models of the TSD. One contains the Clipper chip, another an exportable proprietary AT&T encryption algorithm, the third contains a algorithm for domestic use plus the exportable algorithm, and the fourth contains the Clipper, and exportable algorithms.

TSDs use a different key for each telephone call. A pair of TSDs generate a key using Diffie-Hellman key exchange, independent of the Clipper chip. Since Diffie-Hellman incorporates no authentication, the TSD has two methods to thwart a man-in-the-middle attack.
