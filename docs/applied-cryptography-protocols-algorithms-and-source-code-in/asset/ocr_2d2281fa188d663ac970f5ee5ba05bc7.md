# 18.7 Secure Hash Algorithm (SHA)

Tom Benson attempted to use differential cryptanalysis against a single round of MD5 [144], but his attack is ineffective against all rounds. A more successful attack by den Boer and Bosselaars produces collisions using the compression function in MD5 [203,1331,1336]. This does not lend itself to attacks on MD5 in practical applications, and it does not affect the MD5 in Luby-Rackoff-like encryption algorithms [see Section 14]. It means that one of the basic design principles of MD5—to design a collision-resistant compression function—has been violated. Although it is true that “there seems to be a weakness in the compression function, but has no practical impact on the security of the hash function” [1336]. I am wary of using MD5.

# 18.6 MD2

MD2 is another 128-bit one-way hash function designed by Ron Rivest [801,1335]. It, along with MD5, is used in the PEM protocols [see Section 24]. The security of MD2 is dependent on a random permutation of bytes. This permutation is fixed, and depends on the digits of $S_0, S_1, \dots, S_{35}$ is the permutation. To hash a message M:

+   (1) Pad the message with bytes of value $i$ so that the resulting message is a multiple of 16 bytes long.

+   (2) Append a 48-byte checksum to the message.

+   (3) Initialize a 48-byte block $X_0, X_1, X_2, \dots, X_{47}$. Set the first 16 bytes of $X$ to be 0, the second 16 bytes of $X$ to be the first 16 bytes of the message, and the third 16 bytes of $X$ to be the first 16 bytes of $X$ and the second 16 bytes of $X$.

+   (4) This is the compression function:

```
t = 0
For j = 0 to 17
For k = 0 to 47
t = X_k XOR $S_t$
X_k = t
t = (t + j) mod 256
```

+   (5) Set the first 16 bytes of $X$ to be the second 16 bytes of $X$ to be the XOR of the first 16 bytes of the message, and the second 16 bytes of $X$. Do step [4]. Repeat steps [5] and [4] with every 16 bytes of the message, turn.

+   (6) The output is the first 16 bytes of $X$.

Although no weaknesses in MD2 have been found [see [1262]], it is slower than most suggested hash functions.
