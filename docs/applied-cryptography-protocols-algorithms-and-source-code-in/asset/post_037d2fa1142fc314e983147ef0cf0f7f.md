## Failsafe Diffie-Hellman

Like the previous protocol, a group of users share a prime, $p$, and a generator, $g$. Alice's private key is $s$, and her public key is $t = g^s \mod p$.

- (1) The KDC chooses a random number, $B$, between 0 and $p - 2$, and commits to using a bit-commitment protocol (see Section 4.9).

- (2) Alice chooses a random number, $A$, between 0 and $p - 2$. She sends $g^A$ to the KDC.

- (3) The user “shares” with each trustee using a verifiable secret-sharing scheme (see Section 3.7).

- (4) The KDC reveals $B$ to Alice.

- (5) Alice verifies the commitment from step [1]. Then she sets her public key as

$t = \{g^A\}g^B \mod p$
She sets her private key as
$s = \{A + B\} \mod p$

## 23.11 Zero-Knowledge Proofs of Knowledge

### Zero-Knowledge Proof of a Discrete Logarithm
Peggy wants to prove to Victor that she knows an x that satisfies

```
$A^x = B [mod p]$
```

where p is a prime, and x is a random number relatively prime to $p-1$. The numbers A, B, and p are public, here's how Peggy can prove she knows x without revealing it (see Section 5.1) [338, 937].

- (1) Peggy generates random numbers $r_1, r_3, \dots, r_t$, where all $r_i$ are less than $p-1$.
- (2) Peggy computes $h_i = A^{r_i} \mod p$, for all values of $i$, and sends them to Victor.
- (3) Peggy and Victor engage in a coin-flipping protocol to generate $t$ bits: $b_1, \dots, b_t$.
- (4) For all $t$, Peggy does one of the following:
    a) If $b_i=0$, she sends Victor $r_i$
    b) If $b_i=1$, she sends $s_i = \{r_i - t_j) \mod (p-1)\}$, where $j$ is the lowest value for $b_j=1$
- (5) For all $t$, Victor confirms one of the following:
    a) If $b_i=0$, $A^{r_i} = h_i [mod p]$
    b) If $b_i=1$, $A^{t_i} = h_i^{-1} (mod p)$
- (6) Peggy proves $Z$, where
$Z = \{x - t_j\} \mod [p-1]$
- (7) Victor confirms that
$A^x = h_i^{-1} [mod p]$

Peggy's probability of cheating is $2^{-t}$.

## 23.12 Blind Signatures

(1) Alice and Bob agree on a random $k$ and an $m$ such that

```
$km = e (mod n)$
```

They should choose the numbers randomly, using coin-flip protocol to generate $k$ and then computing $m$. If both $k$ and $m$ are greater than zero, the protocol continues. Otherwise, choose again.

- (2) Alice and Bob generate a random ciphertext, $C$. Again, they should use coin-flip protocol.

- (3) Alice, using private key, computes

```
$M = C^d \mod n$
```

She computes

```
$X = M^k \mod n$
```

and sends X to Bob.

- (4) Bob confirms that $X^e \mod n = C$. If it does, he believes Alice. A similar protocol can be used to demonstrate the ability to break discrete logarithm problem.

### Zero-Knowledge Proof that n Is a Blum Integer
There are no truly practical zero-knowledge proofs that $n=pq$, where $p$ and $q$ are primes congruent modulo 4. However, if you allow $n$ to be of the form $p'q'$, where $p'$ and $q'$ are odd, then the properties which make Blum integers useful still hold. And there exists a zero-knowledge proof that $n$ is of that form. Assume Alice knows the factorization of Blum integer $n$, where $n$ is of the form previously discussed. Here's how she can prove to Bob that $n$ is of that form.

- (1) Alice sends Bob $u$ which has Jacobi symbol $-1$ modulo $n$.

- (2) Alice and Bob agree on random bits: $b_1, b_2, \dots, b_k$.

- (3) Alice and Bob jointly agree on random numbers: $x_1, x_2, \dots, x_k$.

- (4) For each $i=1, 2, \dots, k$. Alice sends Bob a square root modulo $n$, one of the four numbers: $x_i, -x_i, ux_i, -ux_i$. The square root must have the Jacobi symbol $b_i$.

The odds of Alice successfully cheating are $2^{-k}$.

## 23.12 BLIND SIGNATURES

The notion of blind signatures (see Section 5.3) was invented by David Chaum [317, 323], who also invented their first implementation [318]. It uses the RSA algorithm.

Bob has a public key, $e$, a private key, $d$, and a public modulus, $n$. Alice wants Bob to sign message $m$ blindly.

- (1) Alice chooses a random value, $k$, between 1 and $n$. Then she blinds $m$ by computing
$t = mk^e \pmod n$

- (2) Bob signs $t$
$t^d = \{mk^e\}^d \pmod n$

- (3) Alice unblinds $t^d$ by computing
$s = t^d/k \pmod n$

- (4) And the result is
$s = m^d$ easily
This can be shown
$t^d = \{mk^e\}^d \pmod n$, so $t^d/k = m^d k/k = m^d \pmod n$.

Chaum invented a family of more complicated blind signature algorithms in [320, 524], called unicipated signatures. These signatures are more complex in construction, but more flexible.

## 23.13 OBLIVIOUS TRANSFER

In this protocol by Rabin [1286], Alice has a 50 percent chance of sending Bob two primes, $p$, and $q$. Alice will not know whether the transfer is successful. [Section 5.5.] This protocol can be used to send Bob any message with a 50 percent success rate if $p$ and $q$ reveal an RSA private key.

- (1) Alice sends the product of the two primes: $n = pq$.
- (2) Bob chooses a random $x$.

## 23.14 SECUREARTY COMPUTATION

This special case of multiparty computation [see 6.2] is sometimes known as Yao's millionaire problem. For this example assume that $i$ and $j$ range from 1 to 100. Bob has a public key and private key.

- 1) Alice chooses a large number, $x$, and encrypts it in Bob's public key.

```
$c = E_{Bob}(x)$
```

- 2) Alice computes $c - i$ and sends the result to Bob.

- 3) Bob, using private key, computes the following 100 numbers:

```
$y_u = D_{Bob}(c - u)$, for $1 \leq u \leq 100$
```

$D_b$ is the decryption algorithm with Bob's private key. He chooses a random prime, $p$. (The $p$ should be somewhat larger than $x$. Bob doesn't know $x$, but Alice could easily tell him the size of $x$.) He computes the following 100:

- 4) Bob sends Alice this sequence of numbers in this order:

```
$z_1, z_2, \dots, z_{\mu}, z_1+1, z_2+1, \dots, z_{100}+1, p$
```

- 5) Alice checks whether the $i$th number in the sequence is congruent to $x \pmod{p}$. If it is, she concludes that $i \leq j$. If it is not, she concludes that $i > j$.

- 6) Alice tells Bob the conclusion.

The drawback to this protocol is that Alice learns the result of the computation before Bob does. Nothing stops her from completing the protocol up to step [5] and then refusing to tell Bob the results in [6]. She could even lie to Bob in step [6].
