What this means is that a known-plaintext attack against DES has only to test half the possible keys: $2^{55}$ keys instead of $2^{56}$ [1080]. Bih and Shamir showed [172] that there is a known-plaintext attack of the same complexity, requiring at least $2^{45}$ known plaintexts.
It is questionable whether this is a weakness, since most messages don't have blocks of plaintext (in random plaintext, the odds against it are extremely high) and users can be warned not to use complement keys.

# Algebraic Structure

All possible 64-bit plaintext blocks can be mapped onto all possible 64-bit ciphertext blocks in $2^{64}$ different ways. The DES algorithm, with its 56-bit key, gives us $2^{56}$ [approximately $10^7$] of these mappings. Using multiple encryption, it is possible to reach a larger portion of these possible mappings. However, this is only true if the DES operation does not have certain algebraic structures.
