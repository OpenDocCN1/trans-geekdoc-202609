# The Problem Defined

The N+1 problem is revealed as the following:

For each entity in a root collection, the application issues one additional query to retrieve each association for each entity.

In the above example, the application issued a total of 11 queries to build up a collection of 10 Post entities with their associated Comment collections:

+   - one query to fetch the ten entities in the root collection (this is the "1" in "N+1")
- ten more queries, for each entity in the root collection, to fetch the associations (this is the "N" in "N+1", where "N" equals the number of entities in the root collection).

# Performance Implications

There are two performance implications of the N+1 problem:

+   1. The number of queries grows as a factor of the number of entities in the root collection.
2. The number of queries *also* grows as a factor of the number of associations needed to complete each root entity.

This means that as the number of root entities and number of relationships increase *linearly*, the number of queries increases as a *multiple* of those two numbers. Each added query reduces the responsiveness of the application.
