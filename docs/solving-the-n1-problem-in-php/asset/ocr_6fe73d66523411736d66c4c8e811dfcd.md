# Performance Implications

Let's tally up our query and loop counts:

+   * A total of 5 queries: 1 for the root collection, and 1 for each of the Comment, Tag, Author, and Summary associations
* A total of 9 loops:
  - 1 to key the Post collection on its key values,
  - 1 each to rekey the Author and Summary collections on their key values
  - 1 each to create the quoted comma-separated values for the post_id and author_id lists
  - 1 each to stitch the Comment, Tag, Author, and Summary associations into the root collection

By contrast, an N+1 situation with 10 Post entities in the root collection would have had only one loop, but would have issued 41 queries. The query-and-stitch solution is certainly more lines of code, but its performance is much better than N+1 because of the reduced number of queries.
