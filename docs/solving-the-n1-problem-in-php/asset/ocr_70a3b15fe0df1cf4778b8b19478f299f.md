# 5. Solving N+1 With A Single Query

One approach to solving the N+1 problem is to retrieve all the data for the root entities, and all data for all the associations, all in one query:

+   - Issue a query that joins all necessary tables in a single result set.
- Convert each result row to entity objects in a PHP loop.

This approach is intuitively appealing, because it results in only a single query no matter the number of root entities or associations. While it works reasonably well for "to-one" relationships, it is generally unsuitable for "to-many" relationships. Even so, it warrants discussion, if only for completeness' sake.

# Handling “Many-To-One” Relationships

Let's say our blogging application needs to present a list of the 10 most-recent blog posts and their authors. In an N+1 situation, the relevant code might look like the following.

# The Original N+1 Code

```
<?php
// get the most recent posts
$stmt = 'SELECT *
FROM posts
ORDER BY datetime DESC
LIMIT 10';
$stmt = $pdo->prepare($stmt);
$stmt->execute();
$posts = $stmt->fetchAll(PDO::FETCH_CLASS, 'Post');

// get the author for each post
$stmt = 'SELECT *
FROM authors
WHERE author_id = :author_id'
$stmt = $pdo->prepare($stmt);
foreach ($posts as $post) {
    $stmt->execute(array('author_id' => $post->author_id));
    $post->author = $stmt->fetchObject('Author');
}
?>
```
