## PHP Classes

The following PHP classes represent entities in a naive blogging application. These are purposely stripped down to show the core substance of the classes, and should not be used as the basis for a real application. In particular, the classes use public properties to avoid boilerplate getter and setter methods; this is to reduce the volume of code presented, not to indicate a good practice.

```php
<?php
class Author {
    /** database columns */
    public $author_id;
    public $name;
}
```

```php
class Comment {
    /** database columns */
    public $comment_id;
    public $post_id;
    public $datetime;
    public $name;
    public $email;
    public $website;
    public $body;
}
```

```php
class Post {
    /** database columns */
    public $post_id;
    public $author_id;
    public $datetime;
    public $title;
    public $body;

    /** associations */
    public $author;
    public $comments;
    public $summary;
    public $tags;
}

class Summary {
  /** database columns */
  public $post_id;
  public $view_count;
  public $comment_count;
}

class Tag {
  /** database columns */
  public $tag_id;
  public $name;
}
```
