# Combining "Many-To-One" and "One-To-One"

The major selling point of the single-query solution is that we should be able to bring in all the data for the root entity and the associated entities in one results set. As an example, let's get the Author and Summary data in one query, and create the entities from that.

The combined data retrieval code would look like this:

```
<?php
$stm = 'SELECT
    posts.post_id AS post__post_id,
    posts.author_id AS post__author_id,
    posts.datetime AS post__datetime,
    posts.title AS post__title,
    posts.body AS post__body,
    authors.author_id AS author__author_id,
    authors.name AS author__name,
    summaries.post_id AS summary__post_id,
    summaries.view_count AS summary__view_count,
    summaries.comment_count AS summary__comment_count
FROM posts
JOIN authors ON authors.author_id = posts.author_id
JOIN summaries ON summaries.post_id = posts.post_id
ORDER BY datetime
LIMIT 10';
$stm = $pdo->prepare($stm);
$stm->execute();
$rows = $stm->fetchAll(PDO::FETCH_ASSOC);
?>
```

The "many-to-one" and "one-to-one" relationships are now combined into a single query. When we get the results, we can pick up each row by building the creation logic as well:

```
<?php
$authors = array();
$posts = array();
foreach ($rows as $row) {

    // create the post entity
    $post = new Post();
    $post->post_id = $row['post_id'];
    $post->author_id = $row['author_id'];
    $post->datetime = $row['datetime'];
    $post->title = $row['post_title'];
```
