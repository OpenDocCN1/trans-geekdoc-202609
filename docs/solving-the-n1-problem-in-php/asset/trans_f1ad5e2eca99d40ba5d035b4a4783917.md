## PHP 类

以下 PHP 类代表了一个简易博客应用程序中的实体。这些类经过了刻意简化，以展示类的核心内容，不应作为实际应用程序的基础。特别，这些类使用了公共属性来避免编写样板的 getter 和 setter 方法；这样做是为了减少展示的代码量，而不是表示这良好的实践。

```php
<?php
class Author {
    /** 数据库列 */
    public $author_id;
    public $name;
}
```

```php
class Comment {
    /** 数据库列 */
    public $comment_id;
    public $post_id;
    public $datetime;
    public $name;
    public $email;
    public $website;
    public $body;
}
```

```php
class Post {
    /** 数据库列 */
    public $post_id;
    public $author_id;
    public $datetime;
    public $title;
    public $body;

    /** 关联 */
    public $author;
    public $comments;
    public $summary;
    public $tags;
}

class Summary {
  /** 数据库列 */
  public $post_id;
  public $view_count;
  public $comment_count;
}

class Tag {
  /** 数据库列 */
  public $tag_id;
  public $name;
}
```
