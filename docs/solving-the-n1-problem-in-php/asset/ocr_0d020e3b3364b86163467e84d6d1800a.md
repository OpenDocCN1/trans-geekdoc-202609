# # Defining The N+1 Problem

# ## The Problem By Example

It is easiest to describe the N+1 problem by example. Let's say that our naive blog application needs to show a page of the 10 most recent blog posts, along with all the comments on each post.

First, the application retrieves the root collection of Post entities as an array:

```
<?php
$stm = 'SELECT *
FROM posts
ORDER BY datetime DESC
LIMIT 10';
$sth = $pdo->prepare($stm);
$sth->execute();
$posts = $sth->fetchAll(PDO::FETCH_CLASS, 'Post');
?>
```

So far so good: the application has issued one query to build the root collection of Post entities.\Next, the application collects the Comment entities on each entity:

```
<?php
// prepare a statement to select the comments
$stm = 'SELECT *
FROM comments
WHERE post_id = :post_id';
$sth = $pdo->prepare($stm);
foreach ($posts as $post) {
  $sth->execute(array('post_id' => $post->post_id));
  $post->comments = $sth->fetchAll(PDO::FETCH_CLASS, 'Comment');
}
?>
```

The application has issued ten queries to build the comments for each post. With this, we have arrived at the core of the N+1 Problem.
