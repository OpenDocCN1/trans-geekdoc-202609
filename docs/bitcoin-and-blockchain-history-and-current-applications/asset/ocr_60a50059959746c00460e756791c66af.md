# 1.8.4 ADDRESSES

Receiver’s public key is the address to which Bitcoins are being sent. Using sender’s private key, the digital signature of the user is encrypted and can be decrypted using the sender’s public key. Through this process, identification of the sender and the address of the receiver are verified. It is not possible to send Bitcoins if someone loses their private key. It is also possible for someone to steal the Bitcoins if he/she gets access to someone’s private key. Even if the victim knows the intruders public key, he cannot take back his Bitcoins as he don’t know the intruder’s private key and the transaction cannot be reversed.
