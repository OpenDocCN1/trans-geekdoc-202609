# Step 2: Endorsing and Generating RW Sets

Endorsing peers by invoking the respective chaincode at the request of the client user, executes the proposed transaction and produces the output. Endorsing peer then gathers RW sets (read set and write set) information. Read set is the values of the current state of the world without changing it with the transaction proposed. Write set is the current state modified values prior to the execution of the proposed transaction. Such improvements, however, are not reflected at this point in the ledger.
