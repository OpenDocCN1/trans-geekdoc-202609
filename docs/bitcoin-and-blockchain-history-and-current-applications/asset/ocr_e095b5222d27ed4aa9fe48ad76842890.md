# 9.7 TESTING WITH MOCHA FRAMEWORK

Whenever we compose a function for specific output, we can envision the functionality of that function and which parameters give what results. At the time of development of function, we can cross validate the function by running it and comparing the output with the expected one. This could be done by running the function in the console. In case, the output is not same as expected one then we can debug the code, run it again in the console, validate the result and keep on doing this till we get the expected or desired output.
