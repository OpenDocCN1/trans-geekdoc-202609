### 9.5 WEB3 LIBRARY

For creating and deploying the contract onto the Ethereum network, Node.js and its modules are used. For compiling a Solidity file in Node.js, a node module “solc” has to be installed on the machine. Using this module, the Node.js will compile the Solidity file, which gives the bytecode and the ABI. To interact with the contract on the blockchain, web3 [13, 14] library is used.

As mentioned in Section 9.4, web3 library is used to connect to the Ethereum network from an application. So, web3 is used as the perfect solution for communicating between a JavaScript application and the Ethereum network. The ABI is given to the web3 library, which it uses to give a programmatic access to the contract deployed on the Ethereum network [13].

To utilize Web3, an object of Web3 class must be instantiated.

```javascript
const Web3=require('web3');
    const web3=new Web3();//Instance
```
