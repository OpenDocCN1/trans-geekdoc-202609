# 3.8  SHA-256

SHA-256 is a cryptographic hash function which takes an input of any size and produces a fixed-size output [8]. Hash functions are more powerful because they are unidirectional, i.e., if an input is given, an output can be generated by anyone. Nevertheless, the input value can’t be recreated using the hashed output value. The powerful nature of SHA-256 makes it perfect for blockchain applications.
