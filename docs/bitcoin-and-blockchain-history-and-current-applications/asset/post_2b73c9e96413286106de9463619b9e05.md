## 6.5 Preliminaries of Bitcoin Mining

Bitcoin mining is performed by high-powered computers that solve complex computational math problems through the Internet. The miner who exchanges or creates new Bitcoins follows a protocol called Proof of Work (PoW) and later the block is placed in the blockchain. Mineworkers deliver a community service by safeguarding the net, and the system recompenses them for effort.

Once the transaction is broadcast in a system, the miners mine the transaction through PoW and solve mathematical puzzles. If the mining is successfully done, then the block can be added in the blockchain; this practice can be done every ten minutes. Each new block is added to the blockchain, and these dealings are confirmed and logged every ten minutes. The mineworkers’ competition for the following block starts. For this, there is a competition between miners who validate the transaction first. The first one to validate the transaction can add that block in the blockchain. It follows the Longest Chain Rule. All these methodologies of the Bitcoin mining procedure and protocol using a cryptographic hash algorithm are mentioned in the Bitcoin white paper.
