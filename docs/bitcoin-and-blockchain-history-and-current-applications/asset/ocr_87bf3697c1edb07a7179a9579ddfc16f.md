# 12.3.2.6 Peers

Peers are a network body that maintain a ledger as shown in Figure 12.2 and executes chain code to perform read/write operations in the network. Members own and retain peers. A peer can host more than one ledger and chaincode to help create more robust layout of the process. While all peers are the same, depending on how the network is designed, they may play multiple roles.

Committing peer: Every peer node in a channel is a peer to commit. It receives blocks of transactions created, which are subsequently validated before they are committed and attached to the ledger’s peer local copy.
