Make a new directory outside of Fabric, name it chaincode. Open the terminal and go to the chaincode folder path. Run “npm init, ”this command initializes the NodeJS project. After entering the details of npm init, run “npm i fabric-shim.”

Fabric-shim: The fabric-shim provides the framework for the chaincode, a lower-level API for “smart contracts” implementation.

By using fabric-shim NodeJS module, we will develop a chaincode, which transfers an asset from one organization to another with a message attached to it.
