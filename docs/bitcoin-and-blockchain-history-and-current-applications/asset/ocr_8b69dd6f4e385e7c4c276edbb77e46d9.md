In this walkthrough, we are using the Hyperledger Fabric SDK for NodeJS. This SDK provides a means to communicate with the blockchain, interact with smart contracts, i.e., chaincode deployed on the Fabric network.

Fabric-network: It provides user applications with high-level APIs to send transactions and test smart contract queries (chaincode).

API: Application developer pluggable APIs for providing alternative implementations of key SDK interfaces. Default implementations are included for each interface.

Fabric-client: It offers APIs to communicate with Hyperledger’s core blockchain network elements, namely peers, orderers, and event streams.

Fabric-ca-client: It provides APIs to interact with the fabric-ca optional component, which includes membership management services.
