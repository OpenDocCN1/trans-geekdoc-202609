## 1.2 数字辅助维护（DAM）

新型可穿戴技术（在本文中称为一种DAS）的出现，如智能眼镜、智能手表和平板电脑，推动了服务支持系统的新概念 [9]。DAS与云制造概念相结合，为应对日益复杂的维护程序提供了机会 [3]、[9]。DAS创造了塑造新工作环境的潜力，在这种环境中，现代技术用于协助工人进行在认知复杂性方面具有挑战性的活动 [14]。通过接口，相应的过程数据由嵌入辅助系统的软件组件进行处理和可视化，以通过头戴式显示器或便携式设备等方式为维护操作人员提供相关信息。文献的重点是探索和识别实施和部署DAS的应用领域 [5]。要实施DAS，面向服务架构方法已成为既定方法。尽管创新技术（例如Web服务）已应用于工业应用 [15]、[16]，但其在维护支持中的使用尚未得到足够重视。图1显示了关于DAS（特别是可穿戴设备）的适用性和工业适用性（即技术成熟度）的初步时间顺序市场和文献分析。

本节解释了所开发模型的方法论，用于为维护任务选择合适的DAS。所提议的模型基于三个集成元素（见图2）：i) 形态学方法，ii) 应用层和 iii) 设备选择层。

第一个元素代表形态框，它已开发用于促进和优化合适DAS的选择。第二个元素代表应用领域。应用层提供个人用户特定的系统要求以及应用场景（即描述和表示维护活动）。随后，源自i)需求形态的预定义参数和ii)应用层级别的系统和硬件要求得到评估，并根据其整体系统意义与潜在技术解决方案进行比较。该系统中的算法和相关性分析用于最终将要求映射到现有的数字辅助解决方案。使用所提议的方法，选择（组合）DAS并将其链接到维护活动。最后，我们通过使用所选数字辅助系统收集反馈，以提高建议的质量，并识别每个系统在实际用例中的优势和劣势。

### 2.1 形态学方法

为了促进和优化制造业中维护作业适合DAS的选择，已开发了一种形态学方法。形态分析（MA）是一种用于系统地结构化和分析多维、不可量化问题复合体中包含的一组关系的方法 [20]、[21]。MA通常包含三个步骤。首先，问题复杂性被分类为几个维度。其次，识别每个维度的所有可能条件（也称为参数）。这些参数代表每个维度的特征。最后，基于识别的维度及其分配的条件参数开发形态矩阵 [22]。图3描绘了一个形态矩阵，其中包含对选择辅助系统至关重要的识别功能集合。充分辅助系统的关键功能可以分为三组：i) 关于应用（软件）的要求：以何种方式以及在多大程度上将维护信息呈现给维护操作人员和工程师，以便以负担得起的方式提高他们的性能？ ii) 关于信息系统的要求：维护信息如何以及在多大程度上针对应用进行定制？ iii) 关于硬件的要求：对于选定的案例应应用哪种硬件？
