## 2.3 生产计划与控制中的 ML

ML 是人工智能的一个分支。许多其他人工智能学科，例如自然语言处理或机器人技术，其智能行为预设了广泛的知识基础，都建立在此基础上。

在各种工业应用中，ML 算法已被应用并取得了有希望的结果 [5]：在 [6] 中，一个 ML 算法被实现用于控制激光焊接工艺中的工艺参数功率。特定设置的实验结果表明，该算法能生成稳定解，并适用于实时动态控制机制。在生产控制背景下，其他作者研究了 ML 在订单调度中的应用。调度方法在整体架构上有所不同。例如，[2] 和 [3] 中提出的系统侧重于一种高度分布式形式，其中每种资源和每个订单都被视为智能代理。在这种架构中，资源会根据被选中时的预估加工成本为订单分配进行竞标。为了降低计算复杂度，提出了一种基于 ML 的解决方案来估计将作业分配给特定资源的效益。实现的 ML 算法在单目标问题中使用表格表示。[7] 的工作将 Q-learning 应用于单机调度问题和具有少数几个工艺步骤的布局。每台机器上的订单调度和订单释放由基于 ML 的代理执行。

这些示例展示了 ML 算法在生产工程领域中的广泛应用和成功案例。基于这项研究，本文探讨了 ML 在生产计划与控制中的更广泛应用。

## 3 CPPS 中强化学习的应用

作为 ML 算法的一个子类别，强化学习 (RL) 解决了以下问题：自主智能程序（以下亦称为代理）如何在环境中观察和行动，并学习选择最优动作，以实现最初定义的某个目标。为此，代理在环境中的每个动作都会通过一个标量数字得到奖励或惩罚，该数字表明相对于整体目标的动作可取性。代理的目标是最大化这种正反馈 [8]。因此，代理探索其环境并学习输入信号（即系统的当前状态）与动作之间的最优连接，而无需依赖任何先前的训练 [9]。

### 3.1 代理定义

代理不仅是 RL 的核心概念，也是智能计算和分布式系统设计的重要概念 [5]。从功能层面来看，代理是一种计算系统，它（i）与动态环境交互，（ii）能够执行自主动作，（iii）针对特定目标采取行动 [5]。为了实现这种行为，提出了一种具有三个关键组件的代理架构 [10]：为了与环境交互，代理需要传感器来感知周围环境的相关方面，并需要执行器来执行动作。为了生成目标驱动的动作，还需要第三个组件，即所谓的代理函数。这些特征与 CPPS 的一般特征一致。

在此模型中，代理函数是定义代理行为的关键组件。它决定如何处理感知到的信息以决定行动，从而使代理在整体目标方面表现出“良好”的性能。同时，它需要权衡代理的经验。这对于学习代理决策的后果至关重要。最终，代理函数代表了环境的学习模型。系统可以由具有重叠环境的多个代理组成。在这种情况下，它被称为多代理系统 [3]。

### 3.2 强化学习算法

RL 将基于学习代理的方法应用于优化问题。由于学习能力基于与环境的反复交互，它通常被称为“试错”学习 [11]。尽管存在许多不同的 RL 算法，它们在学习功能的具体实现上有所不同，但它们都遵循图 1 所示的代理-环境交互的相同步骤。

图 1. 代理-环境交互，源自 [11]

代理将环境的实际状态感知为向量 S_t。为了决定动作 A_t，信息在存储当前策略 π_t(a|s) = P(A_t = a | S_t = s) 的代理函数中进行处理。动作在环境中执行后，代理感知到新状态 S_{t+1} 和奖励信号 R_{t+1}。请注意，环境转换与马尔可夫决策过程 (MDP) 的概念密切相关。根据接收到的反馈，代理调整其策略。[11]

这些步骤以迭代方式重复。因此，代理以优化其行为的方式找到最大化长期回报的策略 π——因此，这是最符合代理目标的策略。[11]

寻找最优策略是一个迭代过程。在每次迭代中，当前策略 π_t 根据最新经验进行调整。确定新策略的主要技术有两种：(i) 基于值的方法和 (ii) 基于策略的方法。两种方法的主要区别在于，值近似在交互过程中学习动作值函数，而不是直接学习策略 \(\pi\)。值函数 \(q_\pi(s,a)\) 定义了在遵循策略 \(\pi\) 的情况下，在状态 \(s\) 中选择动作 \(a\) 时的预期长期回报。然后，策略从每个状态下所有可能动作的估计值中推导出来。另一方面，策略近似直接更新策略函数 \(\pi_t = \pi_t(a|s)\)。

大多数现实问题涉及连续的动作和状态空间。因此，在表中存储和更新策略或值函数在计算上效率低下且需要大量内存空间。一种可能性是近似存储原始策略或值函数。人工神经网络广泛用于此目的，因为它们能够通过连接网络中神经元的多个权重来近似复杂的函数关系，并允许在学习过程中动态调整这些权重 [11]。因此，神经网络通过在每次迭代中更新一组权重参数，而不是更新每个状态-动作对的值，从而减少了计算工作量。本文考虑了一种密集的全连接前馈网络。

根据问题的维度和特征，不同的学习方法可以取得良好结果。近年来，PPO [12]、TRPO [13] 和 DQN [14] 等新型 RL 算法被开发用于处理不同领域中的复杂问题。它们可以被视为高级策略或值近似算法，旨在实现高效稳定的学习过程。本文的结果基于这些 RL 算法。
