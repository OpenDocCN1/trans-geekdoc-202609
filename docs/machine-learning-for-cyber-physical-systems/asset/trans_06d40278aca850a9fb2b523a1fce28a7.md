## 电磁阀监测

电磁阀是当今工业中最重要的控制单元之一。特别是在流程工业中，电磁阀发挥着重要作用，因为它们控制气体和液体的介质流动。

当电流施加到磁绕组时，可动磁枢被吸引，从而将阀塞从阀座上释放（参见图 5）。介质可以流动。切断电流时，回位弹簧确保磁枢下降，从而由阀塞关闭阀座。运动部件上的机械载荷和介质的持续流动会导致电磁阀内部出现磨损迹象。此外，在高温和振动环境等困难工况下的持续使用也会造成额外磨损。由于电磁阀常用于安全关键型应用，故障可能带来灾难性的经济后果，更会危及人类生命。电磁阀内部的磨损不仅是安全隐患，电磁阀信号线（例如，导线断路、短路）中的错误也可能导致故障，从而构成高风险。

![](img/a2f5eed6507498d886a06be86239344b_120_0.png)

图 5：电磁阀示意图

为防止因磨损造成的过早磨损，必须监测电磁阀中的阀门或排水阀以及通往阀门的信号线。报告中占主导地位的四类错误 [NRC1987]：

- 阀内异物（16%）
- 线圈烧毁/短路（15%）
- 阀部件磨损或缺陷（11%）
- 线圈开路（9%）

在监测电磁阀时，有两种不同的方法。第一种方法是基于规则的方法。在运行期间，通过电子元件监测负载电流。如果电流低于或超过设定限值，该模块会向控制器发送信号。

![](img/a2f5eed6507498d886a06be86239344b_120_1.png)

图 6：曲线的显著偏移表明阀门机构有磨损迹象

使用此方法，可以检测和报告诸如导线断路、短路或过电压和欠电压等事件。但是，定义边界内系统动态的变化不会被检测到。

第二种方法致力于阀门故障的早期检测。在此，记录并比较开关循环的电流波形（参见图 6）。这种方法能够实现特定于设备和应用的监测，因为参考模型是在运行期间创建或参数化的。一定程度的偏差可能表明即将发生缺陷，从而启动及时更换阀门（参见图 6）。与之前的情况一样，实现这种监测策略不需要使用专用传感器，因为使用从已有信号中提取的特征。这也使得此类策略可以应用于低成本应用。
