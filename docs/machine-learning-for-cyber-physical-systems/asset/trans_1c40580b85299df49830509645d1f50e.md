

## 2 生产质量中的机器学习应用

### 2.1 工艺链中产品质量预测

接下来，我们将通过德国一家制造公司的具体用例，展示机器学习算法应用的价值，并鼓励企业使用机器学习算法进行流程优化。为了引入面向流程优化的数据驱动建模，通常可以采用行业标准数据挖掘流程（CRISP-DM）[5]。第一步是更详细地了解相关业务。初步数据采集后，确定数据特征以便理解数据。随后，为应用合适的机器学习算法对数据进行准备。基于数据准备，描述所选机器学习算法的实现。最后，评估模型结果，同时考虑各种标准。将详细介绍可借鉴的经验教训。

CRISP-DM 的第一步是业务理解。在此特定用例中，该公司旨在提升由六个不同工艺组成的工艺链的效率。每个产品依次经过每个工艺，部分工艺耗时数小时甚至数天。为了更好地理解工艺链及相应数据，我们与公司的工艺工程师举办了多次研讨会和网络会议。工艺链如图 1 所示。

产品是否合格可在每个工艺完成后确定。由于整个工艺链的周期时间为数天，因此在早期阶段预测产品是否会在某个工艺中超出规格将非常有用。如果能准确预测产品会超出规格，机器可以改加工其他产品。这将提高整个工艺链的效率和灵活性。

作为 CRISP-DM 流程第二步的数据理解与业务理解关系密切，因为这两个步骤都需要多次循环和迭代。获取的数据以半结构化 CSV 文件形式存储在六个工艺各自独立的产品相关数据库中。由于采集了大量测量值，每个产品每个工艺有超过 500 个值。整数、浮点数或字符串参数等不同数据类型描述了这一高维度。除了大量缺失值外，数据集也不平衡。在此语境下，不平衡数据集是指合格产品多于不合格产品。

为了预测产品质量，有必要追踪整个工艺链中的产品数据。因此，需要将六个不同的 CSV 文件关联起来。该关联通过产品识别号建立。由于 CSV 文件结构不统一，文件需要多次转换。建立产品相关关联后，通过删除空值、表面相关性以及降维来清理数据。总体而言，数据理解和准备过程占据了整个 CRISP-DM 流程约 80% 的时间。

在建模步骤开始时，需要选择合适的模型构建方法。由于使用机器学习算法学习数据驱动模型耗时，只能应用少量算法。机器学习算法的选择高度取决于用例、数据集的外观以及参与数据科学家的个人经验。在此特定情况下，我们将预测产品是否合格或不合格视为分类问题。一个类包含整个工艺链中始终合格的所有产品。由于产品质量在每个工艺后进行测量，产品可能在每个工艺后变为不合格，从而产生六个额外类。因为我们可以为数据集打标签，这个多类分类问题可以使用受监督学习算法解决。图 2 展示了工艺及七个类的可视化。

数据集的特征导致算法需要处理不平衡数据集、少量样本以及高维度等要求。从文献中借鉴了其他科学领域中类似问题的最佳实践。除了文献研究结果外，自身经验表明应用决策树算法能取得有益结果。考虑到上述说明，本用例选择决策树算法分类和回归树（CART）[6]。CART 可以处理高维数据集，并具有进一步优势，即工艺负责人能够非常快速且直观地理解分析结果。可以轻松检测预测指出产品将超出公差范围的定位。此外，决策树算法的实现和验证简单。

存在许多不同的数据挖掘和机器学习算法实现平台 [7]。这些平台可分为“数据科学与机器学习平台”（如 Matlab 或 RapidMiner）和“开源平台”（如 Python 和 R）。数据科学与机器学习平台以易用性和快速模型开发为特征 [8]。然而，操作平台可能导致高昂的许可成本 [9]。Python 和 R 等开源平台在数据科学市场中发挥越来越重要的作用，因为它们免费且是机器学习实现最常见的编程语言 [8]。我们决定使用“开源平台” Python，因为可调用的库（如 TensorFlow 和 scikit-learn）正在强力开发。该算法通过 scikit-learn 库在 Python 中调用决策树算法来实现。Scikit-learn 使用 CART 算法的优化版本 [10]。

为了获得更好的机器学习算法性能，必须设置超参数。超参数是外部于模型且其值无法从数据集中估计的配置 [11]。它们在通过 scikit-learn 调用算法时初始设置，并需要优化。决策树算法的超参数例如最大深度和树的最小大小。有不同方法优化超参数。在此用例中，将名为随机搜索的基础方法应用于决策树算法。随机搜索在可能超参数的间隔内随机选择任何要设置的超参数组合。如果该超参数组合带来更好的结果，则更新参数。设置和调优超参数的基础方法包括网格搜索和随机搜索。近年来，贝叶斯优化和梯度下降等其他调优方法变得流行 [12]。除了这些高级方法外，研究机构尝试将启发法应用于超参数调优问题。这些学术方法包括粒子群优化、蚁群优化和和声搜索等元启发法 [13]。

运行后，可通过多种指标评估模型性能。衡量分类模型性能的基础是混淆矩阵。2x2 混淆矩阵的行表示预测类中的实例，列表示实际类中的实例 [14]。如果分类模型将输入正确分类为正例（合格）或负例（不合格），则它们被视为真阳性（TP）或真阴性（TN）。将产品错误分类为正例或负例计为假阳性（FP）或假阴性（FN）。基于混淆矩阵，可以推导出不同指标。

可从混淆矩阵轻松推导的指标包括准确率和误差率。其他单值指标（如 F1-Score 和马修相关系数 MCC）设置更复杂，但仍可从混淆矩阵推导。为了评估本特定用例中 CART 算法的性能，选择了 MCC。与准确率和误差率相比，MCC 对不平衡数据集的处理更高效 [14]。数学关系可见公式 (1)。

MCC = \frac{TP \cdot TN - FP \cdot FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}} (1)
