## 基于随机森林的高度个性化产品错误预测分类器

Gerd Gröner

Carl Zeiss Vision International GmbH
http://www.zeiss.com
gerd.groener@zeiss.com

### 摘要

本文介绍了一种基于随机森林的分类器的应用，旨在识别高度自动化生产环境中有缺陷的产品。在本文过程中，突出了一些数据集和应用特征，这些特征使得底层分类问题相当复杂，并阻碍了直接开箱即用地使用机器学习算法。关于这些特征的发现以及如何处理所得出的挑战，以抽象和概括的方式进行了突出。

### 关键词

随机森林分类器, 不平衡数据, 复杂树模型, 数据的高度特殊性

## 1 引言

在制造高度个性化产品（如眼镜片）的生产过程中，这些产品是根据个性化处方生产的，很难在生产过程中提前识别可能失败的订单。这些产品可能会因其困难且多样的参数组合而失败。参数涵盖原材料特性、镜片设计、几何和制造参数（即机器设定值）。即使是此类个性化、定制产品也无法免受激烈市场竞争的影响。因此，避免材料和工作时间浪费是一个新兴问题。显然，由于此类面向特定客户的个性化产品无法被其他产品（如现货产品的情况）互换或替换，因此在生产前避免任何形式的报废/失败非常有价值。总而言之，分析产品（订单）参数，寻找特征和特征相关性，以便在任何制造过程开始之前预测（潜在）故障，正变得越来越有用。

在我们的案例中，我们面临一个相当棘手的问题，因为产品不能仅仅基于其产品特征（在我们的情况中，这些特征由个性化处方和设计给出）及其相应的目标处方完美地区分为好品或坏品。因此，纠正这一问题的一个挑战性机器学习（ML）任务是在预先区分好品和潜在故障产品的同时，避免过拟合等 ML 陷阱。此外，特征数量非常高，数据集相当不平衡，阻碍了 ML 模型的直接应用。

至今，ML 已被用于不同制造领域的错误检测（例如，[1–3]），但由于领域特定数据（高度个性化）以及完全自动化和高度标准化的制造流程，不同参数组合与结果处理步骤之间的差距是应用 ML 技术并相应评估其效益的一个开放性挑战。

我们提出了一种用于错误预测的随机森林分类器，该分类器源于对不同 ML 算法的深入分析，并已用于训练各种模型。这些模型按其分类质量进行评估。最佳模型进行了详细介绍。有趣的是，制造部门领域专家的疑虑（如区分困难）和发现（如重要特征）已得到模型的确认。最后，我们给出了理由，说明为什么随机森林模型在此特定用例中优于其他（相当复杂）模型，如神经网络和支持向量机（SVM）。

## 2 背景

本节简要介绍所研究特定用例的背景信息，然后介绍一些机器学习原理。

- **I. 用例：错误识别与预测。** 对于订购的产品，我们关注相关产品特征及相应的机器设置参数。总计 130 个描述产品（在我们的案例中为镜片）的特征，涉及几何、形状、目标处方、涂层和着色值等数据。我们移除了订单号和日期等标识符。在所使用的数据集中，总计约有 560000 条记录（即产品），涵盖无错误的产品以及首次生产出错并需要进一步（第二次）生产周期的情况。

由于我们使用历史数据来训练、测试和评估模型，因此每个产品都有对应的特征，指示其是错误还是非错误（二分类）。由于我们有兴趣对产品（及其相应的待处理参数）进行预先分类，因此我们在历史数据中忽略了由操作员、意外机器故障或其他任意情况引起的错误。剩余的（最终）错误比例约为 5.4 %.
