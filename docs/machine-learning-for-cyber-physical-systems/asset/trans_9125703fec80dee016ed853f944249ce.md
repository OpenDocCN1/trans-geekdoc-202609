

## 2 最新技术

基于机器学习的工艺控制最早的研究由Oh等人[4]开展，他们应用神经网络/偏最小二乘法来建模复杂结构金属板生产过程中多个工艺参数与多个质量参数之间的关系。Senn等人[5]使用主成分分析和人工神经网络来建模深拉工艺中观测量与状态变量之间的关系。然而，生产线内基于机器学习的工艺控制方面的综合研究仍然稀缺。为了填补这一空白，我们提出了一种直观的方法，以智能控制生产线中的工艺参数，从而提高最终产品的质量。所引入的智能系统基于线性回归和最小二乘优化。

## 3 数据与方法

我们考虑一条用于冲压硬化钣金以生产中柱的生产线，中柱是超高强度车身部件。在此，我们将关注三个工艺步骤：预热、搬运和淬火，见图1。该工艺涉及将已加热超过约900°C奥氏体化温度的钢板插入冷却成型工具中，然后在其中进行淬火。热集成加工生产出的冲压硬化零件具有极高的抗拉强度，可达1,500 MPa，适用于超高强度钢22MnB5。钢板的搬运由机器人完成。

### 3.2 用于质量预测的线性回归

模型描述 最终，我们的目标是在线工艺控制，这使得应用高速模型和快速预测成为必要。作为第一步（离线进行），我们需要以可区分的方式描述输入变量和输出变量之间的关系。考虑了一个考虑单个参数线性效应的通用线性模型。一般来说，线性回归方程有以下形式

```
DepVar = a + (b1 x IndepVar1) + ... + (bn x IndepVarn).
```

其中，a、b1、...、bn是未知参数，DepVar代表因变量，分别表示质量P1H和P2ST。IndepVar's是自变量，例如工艺参数。

分析在R中使用lm()函数分别对两个质量参数P1H和P2ST拟合线性模型来进行。得到的回归系数显示在表1中。

**模型验证** 回归分析表明，STemp、TT、ToTemp、QF、QT和Sp对P1H有显著影响，这一点由p值证实（ST无显著影响）。调整后的R²为0.90，描述了模型对因变量变化的解释比例，这支持了线性回归方法的整体适用性。P2ST可以通过ST、TT、ToTemp、QF、QT和Sp的线性组合彻底描述（STemp无显著影响），调整后的R²为0.99。

由于观测值总数有限，且划分训练集和测试集在不丢失显著建模能力的情况下不合理，因此使用K折交叉验证对模型进行了验证。对于K=5，线性模型预测P1H的总预测误差均方为97.6（与包含所有变量的完整模型的102相比），预测P2ST的误差为3.87 x 10^-6（与完整模型的6.14 x 10^-6相比）。尽管观测值数量有限（未来将增加），但这表明线性模型相当不错。

### 3.3 带约束的最小二乘优化

**优化问题设置** 生产线中的每个步骤之后，使用已经测量的变量结合对尚未执行的工艺步骤变量的假设（表1中的默认值）来估计质量P1H和P2ST。这些假设基于技术专家知识。预热工艺之后，我们知道ST和STemp。为了获得预期质量P1H和P2ST的首次估计，我们使用3.2中建立的线性回归模型，结合测得的ST和STemp以及表2中所述的TT、ToTemp、Sp、QT和QF的默认值。如果估计质量低于表2中也规定的预定义阈值，则必须调整后续工艺步骤的可控变量，以将质量带回理想区间。建立了一个优化过程，用于计算必要的调整。在每个工艺步骤后，应用最小二乘法求解出现的带约束的非齐次线性系统。随着每个步骤的推进，模型精度会提高，因为用于预测质量的工艺估计越来越少。

为了求解优化问题，执行带有等式和不等式约束的最小二乘法。R包limSolve中的函数称为lsei()，它求解

```
min ||Ax - b|| subject to Ex = f, Gx >= h.
```

对于工艺步骤1（预热）后的优化，矩阵A是维度为4的单位矩阵，因为制造过程后还剩四个随后可确定的变量。向量b包含4个可调变量的默认值/理想工艺值。目标函数试图找到一个对4个可调变量的解，使其尽可能接近所需的默认值。由于我们的优化问题没有等式，E是维度为4的零矩阵，f是零向量。不等式约束Gx >= h由上界和
