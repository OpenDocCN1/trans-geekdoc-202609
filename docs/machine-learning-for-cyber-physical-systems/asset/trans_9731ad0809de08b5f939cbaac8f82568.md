## 3 基于相关性的机器状态和参数降级的回归分析

如 [8] 所示的 MS 模糊聚类可以在不考虑 TPs 与 CVs 之间可能相关性的情况下进行。这是基于对感兴趣组件的实际考虑以及 CV 与 TP 之间（启发式预期）的相关性，对有限数量预定义 MS 进行的可能。如果将广泛的 TPs 与可变的 TP 节区分辨率以及时间跨度相结合，则所有组合（每个 CV）的聚类将变得不切实际，在统计上具有挑战性，且信息含量会下降。因此，对于这些状态，有必要对显著的 MS 和 TP 进行减少。这项任务可以通过使用人工神经网络 (ANN) 来解决，但其鲁棒性和准确性在很大程度上取决于训练数据的数量。这意味着每个相关 MS 必须出现几次，ANN 才能发挥其优势。在第 1 节所述的非系列机床应用中，这并不一定成立。

为此，本文建议采用 TPs 与 CVs 之间的回归分析。基于所介绍的周期，进行了回归分析。回归分析中使用的输入变量 (TP) 和响应变量 (CV) 如表 8 所示。这包括 MS 的所有变化参数。所考虑的 MS 回归分析并非旨在量化输入变量与响应变量之间的回归函数，而应从统计上验证输入变量的显著性（详情见 [9]）。因此，回归分析选用不含任何交互作用的线性函数。

基于这些周期，使用商业软件 Cornerstone® 为子阶段推导了线性回归分析。回归分析的目的不是推导定量模型以基于 TP 预测 CV。可用数据不足以实现此目的。回归模型仅为线性，且不具备代表 TP 与 CV 全范围的代表性。然而，回归分析为每个输入参数 (= TP) 提取了显著性项，从而区分特定 CV（表 4 中的响应变量）的相关 TP 与无关 TP。此外，通过将 TP 的显著性项与相关性分析的调整 R-Square 值进行比较，我们获得了定义适当子阶段的评估依据。此外，还会检查显著 TP 之间的相关性（协方差矩阵），以排除高协方差的 TP。例如，在子阶段 112 中，温度的显著性项甚至高于进给。然而，协方差矩阵显示温度与温度（-0,9861）高度相关，因此应将其排除在 CV fmax 的后续聚类之外。随后，相关 MS 的数量显著减少。相关 TP 的数量同时减少。表 4 描述了表 1 中每个 9 个 MS 分别对所有 10 个子阶段和 4 个输入得出的总体结果。

可从相关性分析结果及随后对显著 TP 协方差矩阵的调查中得出若干重要结论：

- 最具前景的子阶段（具有最佳相关性）是轴行程中段的动态相位；自动定义会检测到这些子阶段 MS
- 有效振动水平与螺母温度明显相关
- 丝杠螺母外圈滚珠通过频率与进给明显相关（该频率可基于几何参数计算）
