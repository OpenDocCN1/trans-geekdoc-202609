## 5 结论

本文介绍了一种面向水务数据驱动状态监测的通用数据分析平台。因此，提出了一种基于插件的软件架构，可用于从不同来源收集数据、使用不同的分析算法处理数据，并通过 Web 用户界面提供结果。得益于插件结构，该平台具有很大的灵活性，可适应非常复杂的场景。对于数据分析，实现了一种基于主成分分析和高斯混合模型相结合的数据驱动状态监测方法。在此方法中，原始输入数据被降至两个维度以生成进程图。接下来，该图与计算的进程轨迹相结合，用于可视化进程是否接近聚类中心，即处于正常状态。此外，计算一个异常指数，用于定义进程处于正常还是异常状态。作为用例，介绍了柏林市水质参数监测的结果。

摘要。随着数字化程度的提高，机器学习 (ML) 算法在生产质量领域的流程优化中具有巨大潜力。如今，ML 算法很少在生产环境中实现。本文介绍了一个具体的用例，其中 ML 算法用于预测流程链中产品的质量，并介绍了从应用中提取的经验教训。在所述项目中，选择 ML 算法的过程是瓶颈。因此，我们描述了一种有前途的方法，即决策工具如何帮助针对特定问题选择 ML 算法。

### 1 生产质量中的数据驱动建模

近年来，数字化导致数据稳步增加。借助更高的计算能力，可以处理大量数据 [1]。分析获取的数据可以增强理解和流程效率——或者用 Peter Sondergaard 的话来说：“信息是 21 世纪的石油，而分析是燃烧引擎” [2]。特别是金融领域或营销领域等部门在从数据中产生价值方面处于领先地位 [3]。特别是，过去十年机器学习 (ML) 算法的使用有所增加。除上述更高的计算能力和数据输入外，这一趋势的主要原因是算法可靠性的提高、算法实现更简单以及数据获取更加便捷。 [1]

尽管 ML 算法的应用在其他领域已非常成熟，但在生产质量领域尚未普及。在生产质量领域进行流程优化时，通常使用基于物理的建模 (PBM)。虽然 PBM 的优势在于可以通过物理依赖关系描述系统的当前和未来状态，但数据驱动模型利用观测数据中的信息来识别当前系统特征并预测未来状态，而无需深入了解流程的物理相互依赖性。 [4] 因此，数据驱动模型的发展为进一步优化生产流程展现出巨大潜力。在所呈现的案例中，我们选择通过应用 ML 算法将数据转换为数据驱动模型。
