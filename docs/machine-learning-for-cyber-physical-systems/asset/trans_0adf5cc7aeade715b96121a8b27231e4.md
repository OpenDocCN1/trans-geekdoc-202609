### 3.3 特征提取

拥有每个配置的一组片段后，下一步是确定所有片段的特征。尽管文献中提出了描述时间序列行为的多种方法，但我们将关注从每个片段中提取的常见统计特征。不过，特征的选择并非固定不变，因此可以使用任何适合特定应用场景的特征。较复杂特征的一个示例可能是高斯过程语境下核拟合的结果，尽管这会导致性能下降。由于目标是捕获片段的可比特征，我们计算不同的实值特征并将其组合为向量化表示。在 COMPOSITION 案例中，我们使用均值来描述平均水平，使用方差作为波动度量，使用下四分位数和上四分位数作为数值的粗略分布分箱。由于特征的表达能力取决于实际数据，优化特征选择的一种可能方法是主成分分析 [6]。仅仅使用大量特征以尽可能全面覆盖特征多样性，可能会对不相似性度量产生负面影响。原因是在距离计算中部分考虑了无关特征。

此外，由于阈值可以被视为比额外提取的特征更直观的解决方案，这种替换将导致识别出的异常数量显著减少。除了对异常值的敏感性之外，原因还在于忽略了时间序列的固有行为。例如，考虑安装在电机上的声学传感器的测量值，该电机最近正在发送波动的测量值，但仍在预定义的容差范围内。尽管记录的值仍被视为有效，但与音量相关的波动可能已经表明电机几乎有缺陷。最后，最初需要为每个配置的任何参数评估适当的阈值。

### 3.4 不相似性度量

目前为止，我们讨论了从分段时间序列中提取的固有信息的利用。GADPL 的最后一步是度量所有获得代表的不相似性水平。由于没有可用的基准真理来定义特定配置的默认行为，算法使用基于给定数据的近似值。在这方面的一个问题是默认行为的变异性，由多个模式组成。因此，像选择出现次数最多的代表这样的天真方法，对于由不同片段捕获的两个同样出现的模式组成的时间序列就会失败，结果一半的数据将被检测为

```
Algorithm 1 GADPL
Require: Time series T, Machine parameters M, Configuration transition time p,
Segment length (l_min, l_max), Number of nearest neighbors k,
Dissimilarity threshold Delta_max
C' = cluster_configurations(T, M)
R' = {R_1, .., R_|C'|}
for all configuration segments C_i in C' do
  for all segments s_j in C_i do
    s_j = truncate_transitions(s_j, p)
    if |s_j| < l_min then
      C_i = C_i \ s_j
    else if |s_j| > l_max then
      s'_j = split_segments(s_j, l_max)
      C_i = C_i U s'_j
      C_i = C_i \ s_j
    end if
    R_i = R_i U extract_features(s'_j)
  end for
end for
for all configuration representatives R_i in R' do
  for all representatives r_j in r_i do
    NN_k = query_index(r_j, k)
    if Delta(r_j, NN_k) > Delta_max then
      emit_anomaly(i, j)
    end if
  end for
end for
```

异常行为。

作为一种潜在解决方案，GADPL 使用指定数量的最近邻的平均值来描述每个片段的最相似行为。其思想是，尽管数据中可能存在多种不同的特征，但至少有预定义数量的元素与待处理项目代表相同的行为。否则，该项目相对于最相似的观测值将具有较高的平均不相似性，因此可以被归类为异常。

令 $r_i$ 为由特征提取获得的第 i 个片段的代表向量，并令 $NN_k(r_i)$ 为相应的 $k$ 个最近邻集合。$r_i$ 的不相似性度量 $\Delta$ 定义为：

```
\(\Delta(r_i, NN_k(r_i)) = \frac{1}{k} \sum_{j=1}^k \delta(r_i, NN_k^j(r_i))\)
```

其中 $NN_k^j(r_i)$ 对应于第 $j$ 个最近邻，$\delta$ 对应于定义在 $\mathbb{R}^n$ 上的地面距离。

## 4 评估

在本节中，我们将讨论在 COMPOSITION 范围内提供的历史数据集上进行的评估。虽然未来该算法应应用于持续流式传输的传感器数据，但初始评估是对七年期间记录的数据进行的。数据由机器参数（已按配方名称分类）和带时间标注的传感器测量值组成，包括温度值和功耗，采样率为 5 分钟。此外，单独的维护日志涵盖了之前风扇更换的日期。然而，运行期间故障仅发生了两次，因此相对罕见。因此，由于实际缺陷组件对结果的确认在一定程度上受到限制。由于本项目和在此提出的方法被视为持续进行的工作，所述评估也在同步继续。

图 1 说明了围绕一次风扇故障时间的 GDPL 应用，包括分段（上半部分）和不相似性度量（下半部分）。在此，不同颜色的圆代表分段后的时间序列切片，描述了风扇的百分比功耗。使用第 3.3 节中提到的特征，我们旨在感知数据中的偏差值和不典型波动，而不对由单个错误传感器测量产生的异常值敏感。考虑到 2012 年 2 月底有一次记录的风扇更换，算法结果清楚地显示在事件发生前不相似性（红色矩形）的值显著升高。尽管 2011 年 5 月底和 2011 年 9 月左右不相似性值的升高可以通过分析原始数据来解释，但当时没有缺陷组件的记录。然而，这并不自动意味着指示不正确，因为缺陷机器部件不是数据中异常特征的唯一原因。因此，对定义异常阈值的最大不相似性值做出适当选择可以显著影响准确性。缺陷风扇行为的两个案例都被算法清晰捕获，并由高不相似性强调。

## 5 结论

借助 GADPL，我们针对基于配置的生产线中无监督异常检测这一相关主题提出了一种解决方案。在简要概述主题及相关工作后，我们讨论了算法及其方法背后的意图，随后简要展示了基于项目数据的评估结果。由于该方法是持续进行的工作，未来我们将主要基于流式数据扩展评估。尽管我们使用历史数据描述了算法，但流式数据的处理过程是类似的。未来评估范围内的另一点是选择更复杂的特征及相关的自动特征选择。进一步改进该方法的另一个想法是对时间序列进行语义分割。目前，时间序列是利用领域知识进行分段的，但基于数据特征的分段可能会提高准确性。这也将防止最大分段长度选择不当，否则可能导致潜在模式内的数据被拆分。最后，我们计划研究多变量数据中异常的相关性。如果以当前状态使用 GADPL 处理多变量时间序列数据，则每个维度将独立处理。因此，在单个不相似性度量中结合跨维度信息以覆盖异常，将是进一步优化该方法的有用功能。
