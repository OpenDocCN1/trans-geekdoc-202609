## 3 数据集特征与应用范围

该数据集来自一个相当专业的领域，针对高度个性化产品的生产流程，存在一些可与完全不同领域的不同问题相比较和迁移的基本关键特征。因此，我们必须应对挑战以处理以下数据和应用特征。

该数据集高度 *不平衡*，这实际上是误差和非误差分类问题的本质特征。如前所述，约 5.4 % 的样本属于少数类（误差情况），而略多于剩余 94.6 % 的数据样本属于多数类（非误差情况）。众所周知，在平衡数据集上可以获得最佳的分类结果（cf. [11–13]）。此外，在我们的案例中，我们不仅关心正确的分类，还想知道导致最终属于这两类中的哪一类的最具影响力的特征是什么。因此，需要一个可靠的预测模型，能够进行适当的分类（即，非猜测解决方案！）。

另一个属性是模型的 *复杂性*。样本的纯数量（数据集中约 560000 条记录）是一个不错的规模，但相对的特征数量（约 130 个）相当高。特别是，问题不仅在于数量本身，而在于特征特性决定了复杂性，如我们在后面将看到的。不存在占主导地位的单个特征，且具影响力的特征数量较多，最终导致模型需要对特征表现和组合进行深入考虑，如下一节所示。

最后，第三个特征是模糊的 *可区分性*，在我们的案例中这是最难处理的一个。给定某个特定订单产品（误差情况）的所有特征，第一次制造过程失败了，而第二次运行使用非常相似甚至相同的特征（包括机器设置参数）却获得了良好的质量。因此，这种产品属性的具体特征无法预先确定是误差情况还是非误差情况。

### 4.1 数据准备与预处理

在数据库中创建数据模型以及处理异常值和缺失值等清理任务的基本步骤之后，我们应用了几个特征工程步骤。我们需要处理各种分类值。即使某些算法能够直接处理它们，我们也对所有分类特征应用了通用编码。我们在此步骤中使用经过验证的 `one-hot-encoding` 方法。此外，对于生产步骤（生产流程中的步骤）中具有不同值的一些参数，通过将这些参数的聚合（如平均值）添加到数据集中，结果得到了改善。
