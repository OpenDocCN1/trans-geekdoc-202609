

# 哪种深度人工神经网络架构适用于移动机器人运动学数据的异常检测？

Oliver Rettig¹, Silvan Müller¹, Marcus Strand¹, Darko Katic²

¹ Baden-Wuerttemberg Cooperative State University, Department for Computer Science, D-76133 Karlsruhe, Germany,
oliver.rettig@dhbw-karlsruhe.de
² ArtiMinds Robotics GmbH, D-76139 Karlsruhe, Germany

**摘要.** 地面上的小凸起超出了激光扫描仪的可检测范围，因此未被整合到基于SLAM的移动机器人地图中。然而，即使是这些小的不规则性也可能对机器人的稳定性和路径质量产生巨大影响。作为开发异常检测算法的基础，对电缆槽和灯泡板的通过过程进行了示例性运动学数据采集。基于自编码器原理的循环神经网络（RNN）可使用此数据成功训练。所描述的RNN架构看起来有望用于实时异常检测，也可用于量化路径质量。

**关键词:** 神经网络, DL4J, 异常检测, 惯性传感器数据, 移动机器人, 深度学习

## 1 引言

移动机器人的导航通常依赖于激光扫描仪数据。地面上的小凸起，例如电缆槽、门槛、地面不平整或其他环境异常，超出了其可检测范围。通常只能建立环境的2D地图，例如离地10cm处。然而，即使是这些小的不规则性也可能对机器人的稳定性和路径质量产生巨大影响。引起的振动可能会影响货物，或降低机器人及其机械部件的存储寿命。

我们项目的新想法是寻求将小异常的检测集成到路径执行过程中的动态适应以及路径规划本身中。这应基于加速度数据，惯性传感器可以简单且廉价地收集此类数据。

商业移动平台，如Mir-100，允许通过在地图上手动定义几个目标点来定义驾驶路线。随后，路径规划会自动进行，同时考虑多个边界条件，例如与墙壁的距离。这种基于地图的路径规划可以通过动态路径规划进行扩展，以适应环境中的临时变化 [1]。通过绕行或在不可预测且可能是动态障碍物前停止，可以避免碰撞。

## 2 方法论

在机器人技术中，通常使用具有特定于应用程序配置的高维感官数据。为了使异常检测组件可重复使用，而无需专家进行昂贵的适应，理想的做法是基于灵活架构（一个或多个输入通道），并且不使用关于数据的太多领域知识。这以及需要处理流式数据以查找异常子序列而不是仅查找单个离群值（可通过分数量化）的需求，排除了文献中许多可用的异常检测方法。

另一方面，人工神经网络通常已被用于解决机器人数据处理领域的广泛问题 [2]，特别是深度学习网络被确定为移动机器人领域的领先突破性技术 [3]。它们可以用于克服移动机器人感知和控制中的重要挑战。例如，在 [5, 6] 中描述了用于分析机器人环境的视觉数据新颖性检测。

在 [13] 中，我们表明基于自编码器的特定深度神经网络（DNN）允许在运动学数据中实现强大且易于扩展的异常检测，但是应该使用哪种架构呢？

有几种方法。一种常见的方法是用非异常数据训练神经网络，以便根据当前值和过去值预测时间序列中的未来几个时间帧。然后可以将测试数据与预测数据进行比较，预测误差可作为异常的指示 [4]。

另一类无监督方法将循环神经网络与用作重建模型的编码器/解码器相结合，其中某种形式的重建误差被用作异常的分数度量。所谓的自编码器被训练为重建正常时间序列，并假设该模型在重建训练期间未见过的异常时会表现不佳 [4]。

自编码器架构的一种较新变体是变分自编码器（VAE），在 [7, 8] 中引入，并被用于异常检测 [9] 等其他应用中。它基于重建概率而不是重建误差，这应该是一种更客观的异常度量。为了在这样的架构中考虑时间序列的时态结构，可以前置一个额外的LSTM [11] 层。

## 3 概念

本文背后的项目的更大目标是通过对变化环境的动态适应，使移动机器人的使用更加稳健和灵活。本文扩展了 [13] 的工作，后者详细描述了商业可用移动平台Mir-100在通过电缆槽（作为环境异常模型）过程中的运动学。在驾驶移动平台Mir-100（图1）于步态和运动分析实验室时，后轮的起跳特别强烈，因为前轮和驱动轮已经通过电缆槽，因此在驾驶过程中拉力更大。数据集及其采集的详细信息在 [13] 中描述。三次试验被任意选择以构建验证集。

[13] 中描述的测量是通过基于标记的光学系统以高精度进行的，以获得“黄金标准”。本文中提出的DNN也使用该数据集进行训练。

为了避免平台或其货物受损，其思路是在前轮通过电缆槽时实时检测其为异常，并在后轮到达电缆槽之前减慢移动平台。

## 4 实验

基于DL4J（一个开源的、面向行业的、商业支持的分布式深度学习框架，支持多个CPU和GPU）实现了两个DNN。

此外，还尝试了基于卷积层沿时间轴提取特征并将其馈送到循环层或密集层的架构。

第一个测试的架构由一系列四个网络层组成，其中三个为LSTM [12] 类型，节点数分别为64、256和100，激活函数为双曲正切，后跟一个具有100个节点和线性激活的密集层。对于权重拟合，选择均方误差作为损失函数，RMSPROP（为每个权重保存平方梯度移动平均值）作为优化器。

第二个架构包含六个网络层。第一个为LSTM [12] 类型，具有一个输入节点和100个输出节点，后跟一个变分自编码器（VAE），在 [7, 8] 中引入，并被用于异常检测 [9] 等其他应用中。它具有两个编码器层和两个解码器层，每层256个节点。序列末端是一个密集输出层。

两个DNN都使用来自参考数据集的垂直加速度数据进行训练，该数据集通过基于标记的光学系统以高精度收集，数据采集是在步态和运动分析实验室中驾驶移动平台Mir-100（图1）期间进行的。数据集及其采集的详细信息在 [13] 中描述。三次试验被任意选择以构建验证集。

两个DNN使用其余24个示例试验进行训练，每个试验约有15000个时间帧。训练集中仅包括试验中未通过电缆槽的部分。在每个试验上，宽度为100帧的时间窗口逐步移动，得到的100 * 试验长度序列被混合以构建训练序列。为了对数据进行归一化并使其更适合作为DNN的输入，减去均值并除以标准差。

## 5 结果

基于LSTM的自编码器和VAE（4）的训练均收敛良好，批量大小为50，学习率为0.2。训练1个周期和5个周期后，基于LSTM层的自编码器的损失函数值分别为4.686和1.154，VAE的损失函数值分别为0.619和0.039。对于所显示的数值，三个测试试验（基于光学标记的测量）之间没有差异。
