## 6 讨论

异常检测对两种测试过的 DNN 架构都有效，但 VAE 的训练收敛更快且损失函数值更小，这可能是一个优势。

图 6. 基于 VAE 的自动编码器的归一化异常分数（预测减去 z 方向原始加速度）；电缆通道超限。三个峰值分别对应前轮、驱动轮和后轮的超限。对应后轮的峰值最大。

这些积极结果不应掩盖这样一个事实：神经网络应用在其配置方面通常比明确制定的算法需要更多的关注和投入。

神经网络总是伴随着通过所谓的过拟合学习隐藏但不需要的规则的风险。

在实践中，可以通过多种安排来应对这一问题。

精心选择的架构细节，例如，为本项目使用的变分自动编码器设置的隐藏节点数高于输入/输出节点数。

这对防止过拟合大有帮助。

此外，如果训练数据集不够多样化或太小，可以使用所谓的数据增量技术。

为确保 DNN 将训练数据的具体路径学习为正常，我们将完整的运动路径切成片段，并用这些片段的随机序列创建训练集。

如果配置如此敏感，为什么还要使用神经网络？

电缆通道超限会产生带有尖峰的时间窗口。

使用简单的阈值尖峰检测器，可以用更少的努力实现异常检测。

此外，这还可能带来额外的优势，即可以明确定义被视为异常的尖峰数据的时间阈值，从而对具体移动平台产生有意义的影响。

如果只有 1D 加速度数据可用，这可能是更好的方法。

然而，如果可用多通道数据（例如来自多个 3D 加速度计和其他传感器的组合），并且算法应对单个传感器脱落具有鲁棒性，那么 DNN 方法更灵活。

与为多个传感器调整阈值并实施特定于配置的逻辑以使系统对脱落具有鲁棒性相比，使用不同传感器配置训练 DNN 要容易得多。

我们卷积层方法的失败似乎是由训练数据集太小引起的。

## 7 结论与未来工作

DL4J 及其 VAE 实现在我们的项目中已被证明是移动平台加速度数据异常检测的生产就绪框架。

这激励我们基于 DL4J 实现较新的所谓变分循环自动编码器 (VRAE) [10]。

VRAE 扩展了 VAE，并从零开始考虑动态时间行为。

下一步是建立一种多通道方法，使用三个或更多 3D 加速度传感器，并优化超参数。

为此，DL4J 提供了有前途的所谓 Arbiter API。

## 可扩展机器学习者的 GPU GEMM-Kernel 自动调优

Johannes Sailer, Christian Frey 和 Christian Kühnert

德国卡尔斯鲁厄 Fraunhofer IOSB 光电子学、系统技术和图像利用研究所

**摘要。** 深度学习（DL）是人工智能（AI）领域的关键技术之一 深度学习神经网络（DLNN）从整体指数级数据增长中获益良多，而另一方面，训练和推理的计算工作量大幅增加。DLNN 中大部分计算时间都用于卷积步骤，该步骤基于通用矩阵乘法（GEMM）。为了加速 DLNN 的计算时间，近年来提出了多种针对图形处理单元（GPU）的高度优化 GEMM 实现 [1]，但这些方法中的大多数都是针对 GEMM 软件内核的 GPU 硬件特定实现，并未考虑训练数据布局的性能依赖性。为了实现最大性能，必须针对不同的 GPU 硬件和训练任务的特定数据布局调整 GEMM 算法的参数。本文提出了一种基于 GPU 的 GEMM 算法的两步自动调优方法。第一步，通过多个性能标准对内核参数搜索空间进行剪枝，然后使用修改后的模拟退火算法进行进一步处理，以找到针对 GPU 硬件和任务特定数据布局的最佳内核参数组合。我们的研究在 160 个不同的输入问题上进行，采用所提方法，与 NVIDIA（cuBLAS）的最先进的实现相比，在 NVIDIA GTX 1080 Ti 加速卡上可实现平均约 12 倍的加速比。

**关键词：** GPU、矩阵乘法、自动调优、自动生成、加速、CUDA、BLAS
