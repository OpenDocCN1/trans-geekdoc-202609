# 3.1.1 CORE FUNCTIONALITY OF THE BLOCKCHAIN

To put blockchain technology to use, a P2P network consisting of all the nodes eager to do so must be set up. Two different keys, one public and one private, are assigned to each node in the network. A node's public key is used to encrypt data given to it by other users, while its private key is used to decode the data. For this reason, we use not just one but two separate keys: for encryption and one for decryption. A user's public key serves as an address, whereas blockchain transactions are signed using their private key.

Communications encrypted with a particular public key may be decrypted only by the owner of the accompanying private key. Learn why asymmetric cryptography is so named here. A node signs a transaction, it performs it and broadcasts it to its immediate peers. The transaction's authenticity and integrity are guaranteed by its unique signature. The signed transaction is received by the peers of the node that broadcasts it, and as soon as they have confirmed its validity, they retransmit it to other peers to disseminate it throughout the network. Particular nodes called “master nodes” organize and arrange the transactions distributed in this fashion and accepted by the web into a timestamped block. A Bitcoin transaction works in the following manner:

+   1. All network nodes share an identical copy of the Bitcoin ledger before the transaction. This displays the Bitcoin addresses and the corresponding balances, like all ledgers.

+   2. Each participant has a set of keys that relate to mathematics. Both public and private keys are used. The sender starts a transaction by sending some Bitcoins to the beneficiary’s address.
