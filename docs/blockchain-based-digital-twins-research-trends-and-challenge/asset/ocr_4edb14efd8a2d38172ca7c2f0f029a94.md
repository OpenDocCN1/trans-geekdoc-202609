+   - Interactions in industrial applications must enable user-defined data structures, unlike transactions in cryptocurrencies.
- Transaction size can have a big impact on confirmation delay, especially in IIoT networks with unstable wireless channels.
- Small transactions often have short transmission delays and high transmission success rates. User Datagram Protocol (UDP), a lightweight mechanism, is still widely used in industrial applications as a communication protocol.
- Because of its simplicity, the UDP protocol often provides only the most fundamental forms of communication; for example, it does not provide error correction.
- Lightweight industrial applications require special attention.
- For instance, keeping the transaction size within the limits of network protocols is preferred to limit network frame fragmentation and maximize effective communication (e.g., UDP and IP).
- It’s more likely that the participating nodes will mine these reduced transaction sizes.

# 7.4.1.2 MOTIVATION SYSTEMS

+   - Offering an incentive is the most common method for encouraging nodes to “work hard” and take part in a consensus mechanism that has already established.
- In the blockchain, a transaction fee is generally included, and this charge is a critical mechanism for controlling the use of the blockchain’s resources and balancing transaction costs.
- To illustrate, transaction costs may reflect the complexity or time sensitivity of a deal. Higher transaction fees are typically charged for transactions that use more resources. Additionally, the transaction fees offer a way to appropriately redistribute network resources, particularly for public blockchains with restricted capacity.
