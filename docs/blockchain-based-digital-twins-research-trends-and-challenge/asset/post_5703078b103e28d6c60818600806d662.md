### 10.1.1 BLOCKCHAIN FOR PREDICTIVE MAINTENANCE

Smart predictive maintenance relies on the real-time data collected from industrial machines to learn predictive models. The decentralized and immutable characteristics of blockchain technology draw the attention of researchers/industries and are considered to an optimal solution for safeguarding the sensitive information collected from the industry in real-time training for the predictive maintenance model. Blockchain technology can minimize cybersecurity risks [4]. Most of the data related to the various kinds of plants, starting from power plants, manufacturing plants, refining plants, etc., is currently handled manually by the field workers. To optimize the functioning of these plants and to perform predictive maintenance, the data gathered from various IoT points needs to be digitized and shared securely in a decentralized manner.

For the predictive maintenance of physical equipment, the health status of individual machine subparts needs to be regularly monitored. Hence, the data of vital parameters which describe the current state of machine parts should be monitored. In the present time, most machines are constructed by assembling various parts manufactured by different industries. Hence, predictive maintenance seeks the involvement of different organizations, and it is required to ensure integrity and transparency in the parameter values to be shared among them.

In Blockchain, the blocks that carry the real data are stockpiled in a distributed manner [5]. Basically, the chain of blocks is wareoused in a distributed peer-to-peer network. Each block also contains the hash of its data value and the hash of the previous block. The cryptographic nature of this hash ensures the genuineness, transparency, and integrity of the data. The verification process adopted by the blockchain to permit the addition of new blocks in the chains create trust among the organizers who share the data. Also, the consensus algorithm adopted in blockchain ensures that the data cannot be modified without the consensus of all the stakeholders or nodes in the network. This very basic characteristic of blockchain makes it suitable for DT-based predictive maintenance of the equipment that is assembled using parts manufactured by different vendors. ### 10.1.2 EDGE COMPUTING

Edge Computing in association with Blockchain has become a successful combination in providing a secure, distributed platform for IoT-based applications [6]. The data generated by the IoT-enabled machines is huge. Also, IoT-enabled machines do not have enough processing and storage capability to handle this huge volume of data. Edge computing addresses this issue of IoT sensors by bringing computing and storage closer to the machines where the data is collected [7]. Also, the integration of IoT with edge computing provides a way for rapid data analysis. Enormous amounts of data from IoT and the need to transmit over the network result in bandwidth problems.

The utilization of bandwidth can be optimized with the support of edge computing by transmitting only the long-term storage to the processing center. The longer latency problem of traditional cloud architecturebased IoT applications is also addressed in edge computing by making the response time faster. In DT-based predictive maintenance, the data sensed from the machine ends to be communicated to the cloud for the construction of blocks. Then the data from the block is fed into an analytical model to make decisions about maintenance. The communication of data from the origin to cloud infrastructure faces two major challenges including bandwidth consumption and security problems.

- 1. **Bandwidth Consumption**: To make the DT imitate the functioning of the real-time machine and to do predictive maintenance analysis, the data sensed from the machines is communicated to the destination frequently. This frequent communication consumes a large amount of communication bandwidth due to its huge size and frequency. This can be addressed by aggregating the continuous stream of data [8] and communicating only this aggregated data to the blockchain architecture over the cloud, which results in a notable reduction in the communication load.
- 2. **Security**: The vital reason for integrating blockchain technology in DT-based predictive maintenance is to ensure the security of the data common for multiple stakeholders who are the manufacturers of different parts of the machine. If the node from the cloud infrastructure is deputed with the responsibility of creating the block, then the raw data from the source end needs to be communicated over the network to the node. This makes the data exposed to security attacks. By bringing the block creation process close to the source end, the traveling of data in raw format over the network can be avoided, and hence security risk can be minimized.

The two challenges discussed above can be addressed using Aggregation and the Creation of blocks at the source end. But as mentioned already, IoT-enabled devices like sensor-fixed machines do not have enough computing power and storage. Hence, edge computing is considered a suitable solution for implementing these two processes. ### 10.1.3 MACHINE LEARNING MODEL FOR PREDICTIVE MAINTENANCE

Predictive maintenance indeed helps in determining the condition of industrial machines by analyzing the working status of individual parts and predicting when the machine parts require maintenance, and what type of maintenance to be given, like repairing or parts replacement. Implementation of a Machine Learning (ML)—based predictive model results in cost savings by avoiding unexpected downtime due to equipment failure. For predictive maintenance, data is collected over a period of time by continuously monitoring the state of machines in real-time. Besides, to facilitate the prediction of failure and maintenance, blockchain-based DTs of vital parts of the machines are constructed and data is extracted from these DTs. This data is stored in a decentralized manner in blockchain in our proposed framework. The main goal is to find the patterns that assist in predicting and preventing machine failures.

- Predictive models can be created to maximize the lifetime of equipment, functioning effectiveness, and uptime.
- Anomalies and failure patterns can be detected, and early warnings can be given.

There are multiple modeling techniques for predictive maintenance. Among them, the regression model can be used for predicting the remaining valuable lifetime. Failure can be predicted using classification models. Multiple types of failures can also be predicted by framing them as multi-class problems. In the classification model, prediction is done within a predefined time frame. In both these models, static and historical data are utilized for the prediction of failures and relationships among features. It is also used in modeling the degradation path [9]. The huge volume of data collected from real-time entities as well as from the DT helps the model to understand the relationship between characteristics of equipment during normal and failure times.
