4. **Data Wrangler**: The data wrangler is in charge of removing missing invalid data and converting dissimilar data types into a similar one before entering them into real and virtual environments. During the car manufacturing process, data is received from a variety of physical sources like sensors and actuators, and it is fed as input into physical and virtual domains.

5. **Data Synchronization**: It performs a consistent digital-physical mapping between sensor data gathered from the production unit and inbuilt performance parameters obtained from the storage unit to ensure data consistency.

6. **Data Fusion**: It is the method of binding data from numerous sources to create a consistent interpretation for a certain object. For example, critical information such as order details, supply chain data, simulation data, and consistency checks are already available for usage in the repository before the commencement of the automobile production process. Furthermore, data wrangling and data fusion are critical for obtaining and merging data after the automotive manufacturing process. This information can be used by threat intelligence to research the enemy's domain and alter S&S standards for covert activities.

7. **Blockchain**: It secures data handling for all transactions. Transactions between nodes serve as the essential building blocks of communication in the blockchain and are maintained in a shared ledger as appendonly-timestamped records. A consensus technique is used to build a secure trustworthy network. A block of transactions is assembled and appended to the ledger using the consensus algorithm. In the Blockchain framework, the hash value of the block enforces immutability and makes tampering with a block and hence transactions easier to detect.
