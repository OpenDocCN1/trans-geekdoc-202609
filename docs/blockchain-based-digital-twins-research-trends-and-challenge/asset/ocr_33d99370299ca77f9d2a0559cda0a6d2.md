# 3.4.1 SCALABILITY

When more and more transactions are added to the blockchain, managing it becomes more cumbersome. To verify blocks on the blockchain, every node must keep a copy of every transaction ever made, regardless of whether or not the funds from which it come are available. It is slow to build because its blocks are enormous, and each one takes a long time to set up; the Bitcoin blockchain cannot perform real-time transactions. Currently, only around seven transactions can be processed per second on the network. Miners prioritize transactions with a high fee; many lowvalue transactions may be delayed because of the limited size of blocks.
