+   3. Intelligent Contracts: It alludes to the set of guidelines for accelerating transaction times. Additionally, it runs and stores data in the blockchain. It establishes rules and guidelines for any transfers, including conditions.

+   4. Public Key Encryption: It serves as the fundamental building block of Blockchain. It makes use of public key encryption, a cryptographic method, to guarantee secure communication, confirm identities, and offer data integrity. Public Key encryption uses two cryptographic keys such as a public key and a private key [10].

# 4.3.3 WORKING OF BLOCKCHAIN

Blockchain works by the following steps. They are explained as follows:

+   1. Step 1: Record the Transaction: Every transaction is recorded as a block of data. It also covers the transfers and transactions of both tangible and intangible assets.

+   2. Step 2: Gain Consensus: The transaction was authentically recorded on the distributed blockchain network. The agreement rules differ based on the type of network, although they are often established at the outset of the network.

+   3. Step 3: Link the Blocks: After the parties have agreed, the transactions are then saved on the blockchain in blocks. The block contains the transactions and a cryptographic hash. The hash connects the blocks. If the block's data is modified intentionally or unintentionally, the hash value will change. The method of recognizing the data change is provided by this change in the hash value. Therefore, the chains and blocks are always linked and immutable. Blockchain verifies all the blocks that are connected with each other.

+   4. Step 4: Share the Ledger: The system shares the latest copy of the ledger to each user [11].
