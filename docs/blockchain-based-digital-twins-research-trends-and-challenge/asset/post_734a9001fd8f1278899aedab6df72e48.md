## 10.3.4 CONSTRUCTION OF DEEP LEARNING MODEL

To model the temporal relationship of sequential data collected from realtime IoT-enabled machines and its digital counterpart which is the collections of DTs, the RNN-based learning model is considered for the proposed framework. To predict the failures and recognize the patterns that require timely maintenance, it is required to model the longer-time dependencies from the data that describe the status of machine parts collected at different periods. To predict the abnormality in the operational behavior of machines, it is needed to identify the difference between expected target characteristics and the current behaviors of the machine.

This is supported in the proposed framework through the two kinds of blockchain RMBC and DTBC. The DTBC provides the expected behavior of the machine. Another requirement for predictive maintenance is finding the relationship between the sequence of state information. Let $s_t$ be the state of the machine at time 't' and $s_{t-1}$ be the state of the machine at time 't-1.' While analyzing the $s_t$ for predicting the maintenance requirement or probability of failure, the knowledge of the machine state at a time 't-1', i.e., $S_{t-1}$ is also to be considered. The Preciseness of the prediction task can be improved by also considering previous 'n' state information like $S_{t-1,t-2}, S_{t-3\dots t-n}$. Hence, the Long Short-Term Memory (LSTM) neural network is considered to be a suitable learning model for the proposed predictive maintenance.

The LSTM can do analysis and classification of current input using the knowledge acquired from the past data. The LSTM can decide which information is worth mentioning or not. The architecture of LSTM has four gates to support learning based on long-term dependencies. The gates decide what to learn, forget, remember, and use. The Learning gate takes the current state $C_t$ and previous short-term memory $SM_{t-1}$ as input. It decides which information is relevant and keeps only as learning for prediction. The operation of the learning gate $(lg)$ using the weight matrix $(M_n)$ is given below:

```
$Learning Matrix (L_t) = \tanh(M_n [SM_{t-1}, S_t]) + bias\_n$
```
```
$Ignoring factor (ig_t) = (M_n [SM_{t-1}, S_t]) + bias\_n$
```
```
$lg_{output} = L_t \cdot ig_t$
```

The Forgetting gate takes the long-term memory $(SM_t)$ as input and decides what to be forgotten and what to be remembered follows:

```
$Ignoring factor (ig_t) = (M_n [SM_{t-1}, S_t]) + bias\_n$
```
```
$LM_t = LM_{t-1} \cdot ((M_n [SM_{t-1}, S_t]) + bias\_n)$
```

The output of the remembering gate is produced by adding the output of the learning gate and the forgetting gate. The use gate combines vital information from the previous long-term memory and short-term memory to produce the short-term memory for the next cell. Once the data from the RMBC is fed into the LSTM-based learning model, the type of failure is predicted. Prediction accuracy is improved with the help of DTBC. ## 10.3.4.1 CHALLENGES OF BLOCKCHAIN-BASED DIGITAL TWIN PREDICTIVE MAINTENANCE

The major challenge of predictive maintenance is the variability in the data and behavior of industrial machines, making the models difficult under same environmental features. Though LSTM adopted in the proposed framework can address the problem of vanishing gradient by replacing the sigmoid function in the hidden layer with ReLU, it converges quickly and suffers from overfitting.

## 10.4 CONCLUSION

In this chapter, a novel framework for predictive maintenance of IoT-enabled industry was proposed by leveraging the benefits of edge computing, DT, and blockchain technologies. It utilized LSTM for feature extraction and predicted major maintenance activities like possible time and type of failure of different machine equipment and which parts of the machine require replacement or regular maintenance activities. The effectiveness of prediction functions was improved by managing the DTs of multiple parts. Parallel governance of DTs provides a comprehensive insight into the functionalities of machines. The data collected from the DT enables the framework to identify the difference between expected target characteristics and the current behaviors of the machine. The incorporation of blockchain technology ensures the security of data and allows the smooth sharing among diverse stakeholders.
