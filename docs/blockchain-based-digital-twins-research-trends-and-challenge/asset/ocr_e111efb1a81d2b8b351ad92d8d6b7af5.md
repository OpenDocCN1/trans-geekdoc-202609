#  10.1.2 EDGE COMPUTING

Edge Computing in association with Blockchain has become a successful combination in providing a secure, distributed platform for IoT-based applications [6]. The data generated by the IoT-enabled machines is huge. Also, IoT-enabled machines do not have enough processing and storage capability to handle this huge volume of data. Edge computing addresses this issue of IoT sensors by bringing computing and storage closer to the machines where the data is collected [7]. Also, the integration of IoT with edge computing provides a way for rapid data analysis. Enormous amounts of data from IoT and the need to transmit over the network result in bandwidth problems.
