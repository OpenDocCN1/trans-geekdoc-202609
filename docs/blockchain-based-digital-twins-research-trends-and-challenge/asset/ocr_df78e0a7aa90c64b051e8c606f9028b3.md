The next layer is the decision-making layer where the collaboration with various agencies give various timely outputs like pandemic outbreaks, information for announcing quarantine, etc. It is not practical to store all patient data in every block of the blockchain. Data lakes are commonly used to store large amounts of unstructured and semi-structured data. They are designed to provide scalable storage that can handle both structured and unstructured data and allow for easy retrieval and analysis of the data. In a healthcare context, data lakes can be used to store patient data that is not needed for every transaction on the blockchain but may be needed for future analysis or decision-making. The blockchain can then be used to store key metadata about the patient data, such as timestamps and hashes, which can be used to ensure the integrity and authenticity of the data.

Data lakes can also be used to store data from other sources, such as medical devices, wearables, and other IoT devices, which can be used to provide additional context and insights into a patient's health status as demonstrated in Figure 1.5. The data stored in the data lake can then be analyzed using machine learning and other data analytics tools to identify patterns and trends that can be used to improve patient care and outcomes.
