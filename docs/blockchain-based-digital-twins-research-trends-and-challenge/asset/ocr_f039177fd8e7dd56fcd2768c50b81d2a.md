# 10.1.5.1 CHALLENGES IN THE CREATION OF DIGITAL TWIN

+   Interoperability: it is considered a primary issue. While establishing DDT, the information between a real-time entity and its virtual counterpart needs to be communicated in coordination without the support of the end user so that the DDT can replicate its counterpart. Predictive maintenance of multiple dependent machines requires the DTs to communicate and share information. Also, the DT which replicates the complex physical entity is made up of a hierarchy of smaller DTs. Communication among these building blocks of DT would be synchronized and coordinated. Interoperability plays a vital role in the parallel governance of the functioning of these DT building blocks.

+   Storage: The stream of data communicated between DT and the physical entity, between DTs has to be stored in one place. It should be restructured to reflect the present standing of the corporal entity. Both archival and conceptual information in the storage should be available to the learning system for analysis in time. The more data, the better the performance of DT. Hence, the storage should be able to handle huge volumes of data. Also, it is essential to remove redundancy in the data stored in DT and avoid bottlenecks.

+   Transparent Communication: The DT constructed from multiple contributors replicates the data from multiple physical entities. Hence, ensuring transparency in the data being transmitted among the contributors is another challenging issue to be considered while designing the DT.
