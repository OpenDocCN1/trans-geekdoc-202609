+   1. **Decentralization**: The term “decentralization” describes a blockchain network that is not controlled by a central authority or intermediary. A blockchain, on the other hand, runs on a globally dispersed network of nodes (computers) that each keeps a copy of the complete blockchain.

+   2. **Immutability**: This is a blockchain that refers to the characteristic of data being permanent and impervious to tampering once it is added. Data that has been stored in a block and uploaded to the blockchain can no longer be changed or removed. Consensus techniques and cryptographic hashing are used to achieve this.

+   3. **Consensus**: The network’s users must reach a consensus on its validity using a consensus mechanism. Only authentic and valid transactions are added to the blockchain as a result of this agreement.
