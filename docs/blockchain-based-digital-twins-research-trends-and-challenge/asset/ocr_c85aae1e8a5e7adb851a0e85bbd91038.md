The major applications of the hash function in Blockchain are listed as follows:

+   1. **Integrity**: By keeping the root hash inside the block header, the integrity of the block header as well as the transactions can be protected. Because no two Merkle trees with the same root hash are impracticable.

+   2. **Authentication**: By generating the hash using the node-specific secret key, it can act as a digital signature which ensures the authentication of the blocks.

+   3. **Confidentiality**: The transactional data communicated to the blockchain network from the edge computing device is encrypted. Adopting asymmetric privacy homomorphism which allows the computation over the cipher data end-to-end confidentiality.

+   4. 10.9 Chain of Blocks: The hash is generated by applying the hash algorithm over the hash of the previous block, transaction data, and nonce. The inclusion of the previous block hash creates a virtual chain link between blocks.

The most commonly used hash functions in blockchain technology are:

+   i. **SHA-256 Algorithm**: This algorithm deterministically generates the hash output for the given amount of data. The output hash is 64 characters long.

+   ii. **ETHASH Algorithm**: It is an algorithm responsible for controlling the mining process of Ethereum Proof of Work.

The utilization of DAG for mining makes it a memory-hard function. The memory cost is so high that mining is possible with a GPU (Graphical Processing Unit).

+   iii. **Script Algorithm**: It is considered to be an optimized hashing algorithm as it can support huge volumes of data, guarantee integrity based on cryptography, and support the recovery of data.
