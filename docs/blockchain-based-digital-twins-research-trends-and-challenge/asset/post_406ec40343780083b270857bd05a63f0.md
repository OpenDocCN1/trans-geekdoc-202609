## 6.5 CONCLUSION

In this chapter, a system model and a privacy-preserving communication mechanism were designed for a blockchain-based cloud-based digital twin environment. According to the suggested method, data produced by physical assets is gathered by a data owner's smart device and transferred to a cloud center point after mutual verification. The simulation information can then be securely communicated to the data owner, who will receive it in real-time. Before sending the desired information to the user via a server located in the cloud in response to an information request from a data consumer, the data owner validates the individual's identity.
