Proof of work consensus algorithm over the Ethereum network is adopted in the proposed framework for arriving at the agreement while adding a new block of transaction in the blockchain. Mining is the process used in Blockchain technology to create new blocks in the blockchain. Each block has a distinctive nonce and hash. Block is linked to the blockchain by adding the reference of the hash of the previous block. This reference creates a link between blocks that are distributed across the network nodes. This distributed database is referred to as a Distributed ledger. The sample structure of chained blocks is given in Figure 10.8.

Finding the suitable nonce that generates the acceptable hash is a complex math problem. To compute this complicated mathematical puzzle, the miner requires large computation power. Also, to make the hash acceptable and hence the block valid, the hash has to meet certain criteria like some number of leading zeros. For this purpose, the field nonce (a number used once) is utilized. Finding the best nonce is the miner’s complicated mining task.
