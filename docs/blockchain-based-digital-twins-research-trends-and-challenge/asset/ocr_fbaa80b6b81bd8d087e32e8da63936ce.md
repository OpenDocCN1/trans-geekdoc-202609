Now let us come to the security part of it. Even brands want to tamper with the data, 51% approval is required to change the data. A single node cannot tamper with the data. In Figure 3.12, 12 nodes are there. At least the consent of seven nodes is required to tamper with the data. Again once, to prove the same fact, let us take a centralized environment where a single node works as a Single Point Shared/Private Server. It is easy for hackers to bypass the firewall, so they can easily hack and transfer data. Compare with the blockchain environment. If a hacker wants to transfer the data to a particular block, consent, and changes at all the blocks at different locations must be changed. Nodes are unaware of what other nodes are available in the system, then how can a hacker determine the same?

First and foremost, a hacker needs to find out exactly these different nodes are situated; if not all, but at least 51% of nodes, it should be able to find. Then only tampering would be possible. Multiple blocks allow the fetching of data quickly, preventing the system from being derailed by external hackers [9]. For some reason, let us assume the hacker can tamper with the data at node 1. However, is enough to change the data at all places? Once again, 51% of the sites should have updated data to apply the change at all the locations.
