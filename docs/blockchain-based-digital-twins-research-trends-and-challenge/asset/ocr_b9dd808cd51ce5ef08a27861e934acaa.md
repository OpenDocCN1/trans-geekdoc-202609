# 2.4.1 CONFIDENTIALITY AND INTEGRITY

The method employed in smart cities is a new technology that provides more sophistication and responsiveness and is already incorporated with blockchain technology. Instead of providing sufficient defenses, already it consists of several sensor nodes to provide security solutions with the help of defense mechanisms. A security breach is one of the main challenges in network security. The users in the network have become completely concealed as compared to fully traceable in blockchain technology. The transactions are often public and accessible to the user groups since cryptocurrencies have higher transparency. The surveillance of user behavior and the disclosure of individual's real identities could result from this, and the records could be used to facilitate data sharing. Therefore, true confidence should be improved.
