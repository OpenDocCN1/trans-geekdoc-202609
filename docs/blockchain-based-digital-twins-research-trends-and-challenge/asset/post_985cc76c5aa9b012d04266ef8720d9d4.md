## 4.7 OPEN-SOURCE PLATFORMS FOR BLOCKCHAIN-BASED DIGITAL TWIN

Blockchain-based Digital Twins can be difficult to create and implement, the appropriate tools make it much easier. Here are some open-source platforms for deploying Blockchain-based Digital Twins.

### 4.7.1 PROJECT DOETAIL

Project Dovetail by TIBCO LABS makes it easier to build, visualize, test, and audit smart contracts without requiring considerable programming.

Low-level code is segregated from logic, contracts can be easily integrated into a variety of blockchain stacks. Time to market can be sped up, on-chain, and off-chain compute can function more seamlessly together, and there is less risk of technology lock-in. Smart contracts are applications or business logic (written in code) that run within the architecture of a blockchain network.

Project dovetail provides the complete design, development, testing, and deployment of blockchain smart contracts. The modeling abstraction layer enables the creation of smart contracts based on a different kind of models, which may assist to:

- Increase security as reusable, tested code drawn from the model is made possible by the modeling abstraction layer.
- Utilize an extensible abstraction layer to streamline development (flow model).
- Break your code's connection to the underlying blockchain technology.
- Reduce the amount of code needed.
- Boost auditability and visibility.
- Make your industry’s modeling customizable.
- Develop a better user interface for designing smart contracts.

Project dovetail is intended to be lightweight, adaptable, adaptable, and embeddable, enabling the rapid development of blockchain-based solutions.

### 4.7.1.1 ARCHITECTURE – PROJECT DOETAIL

Project Dovetail can be conceived of as having four primary sections, from the top down:

- CLI: This tool installs the well-defined smart contracts to the desired blockchain layer.
- UI: Use to create the logic for blockchain smart contracts. Users can use pre-made drag-and-drop activities, add code, or create any required extensions. Data can also be altered and mapped.
- 3. **Metadata**: Outlines the model(s) on which the blockchain's smart contracts are based.
- 4. **Interpreter**: Uses the blockchain target's context to carry out the deployed smart contract.

### 4.7.2 EtherTwin

The EtherTwin prototype is built on a research methodology for communicating Digital Twin data across time [19]. EtherTwin employs a distributed strategy, utilizing the Ethereum blockchain and the distributed hash table (DHT) Swarm, to enable participation from the numerous lifecycle stakeholders without the requirement for trusted third parties (TTPs). Based on Automaton ML (AML) files that identify assets, a Digital Twin can be created and shared with the parties engaged in the twin’s lifetime. The EtherTwin prototype allows:

- Create digital twins;
- Sharing each twin, uploading paperwork, and modifying specs for each twin (versioning);
- Create sensor data feeds;
- Manage user access using asset attributes and lifecycle roles;
- Make a list of the asset's components (specification parsing).

### 4.7.3 SMARTTWIN

SmartTwin is a Blockchain-enabled Digital Twin software architectural structure [20]. The key elements of Digital Twin architecture involve the mixture of IoT (Internet of Things) devices as direct actors on the blockchain system and exploiting Blockchain’s cryptographic capabilities to ensure data security. Enterprise Digital Twin denotes the interaction of a person, equipment, and analytical software to create a paradigm relationship between the physical and digital worlds. Controls and enhances production cycle processes, simplifying operating activity, lowering failure frequency, and boosting equipment service life.

### 4.7.4 REMIX IDE

Smart contracts can be created using Remix IDE, which can then be compiled and deployed [21]. Ethereum is the favored platform for smart contract developers since it is the most extensively used platform for building smart contracts and includes the Solidity programming language for scripting smart contract code. In contrast, a specific piece of code is only useful if it can be compiled into machine-readable language. The Remix IDE is the preferred compiler for Ethereum smart contracts.

Watson IoT Platform was developed by IBM. It is an IoT data tool that gathers data from IoT gadgets and is used for managing large-scale real-time systems. This tool contains extra features cloud services, blockchain services, data analytics, and edge computing [23].

### 4.7.7 SOLIDITY

Solidity is the most often utilized coding language for building Ethereum smart contracts [24]. It is largely used for the creation of smart contracts on Blockchain platforms. Smart contracts are run on Blockchain, use business logic, and produce a sequence of transaction records. It executes code in an Ethereum virtual machine (EVM) [25].
