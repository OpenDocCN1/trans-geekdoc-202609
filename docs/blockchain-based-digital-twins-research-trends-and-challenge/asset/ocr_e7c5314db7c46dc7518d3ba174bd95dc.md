One further thing to think about is how the various IoT infrastructures interact with one another. When incorporating blockchain, one must decide whether these interactions will take place within the IoT, on the blockchain, or some combination of the two [35]. A gateway is typically used in an IoT deployment, and it is responsible for relaying sensor data to higher levels. End nodes with low resources are used to communicate with the gateway (cloud or server). To facilitate communication between end nodes and the blockchain, cryptographic functionality may be included in IoT devices. Achieving autonomy in the IoT, which calls for increasingly costly hardware and computing resources, is crucial. Gateway integration is possible with these systems in the same way it is with traditional installations, but the benefits of using blockchain in this way are limited. Despite blockchain's success, it's still not practical for many users since databases can serve the same purpose with less effort.
