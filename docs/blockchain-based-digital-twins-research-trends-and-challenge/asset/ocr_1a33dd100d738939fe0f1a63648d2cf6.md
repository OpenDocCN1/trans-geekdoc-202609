# 11.3.2 IOT

IoT is used to gather real-time data for a simulation [14, 15 and 16]. In the proposed process, IoT stands for Internet of Things. It is a technology that uses sensors to convert real-time data (analog) into machine-level data (digital). The proposed technology mainly involves embedded sensor systems, software, and other technologies (such as memory devices, displays, etc.).
