### 3.1.1 CORE FUNCTIONALITY OF THE BLOCKCHAIN

To put blockchain technology to use, a P2P network consisting of all the nodes eager to do so must be set up. Two different keys, one public and one private, are assigned to each node in the network. A node's public key is used to encrypt data given to it by other users, while its private key is used to decode the data. For this reason, we use not just one but two separate keys: for encryption and one for decryption. A user's public key serves as an address, whereas blockchain transactions are signed using their private key.

Communications encrypted with a particular public key may be decrypted only by the owner of the accompanying private key. Learn why asymmetric cryptography is so named here. A node signs a transaction, it performs it and broadcasts it to its immediate peers. The transaction's authenticity and integrity are guaranteed by its unique signature. The signed transaction is received by the peers of the node that broadcasts it, and as soon as they have confirmed its validity, they retransmit it to other peers to disseminate it throughout the network.

- All network nodes share an identical copy of the Bitcoin ledger before the transaction.
- Each participant has a set of keys that relate to mathematics. Both public and private keys are used. The sender starts a transaction by sending some Bitcoins to the beneficiary’s address.
- After the sender signs the transaction using his private and recipient keys, it is broadcast to the whole network. No other but the recipient's private one may be used to decode the payment; however, anybody can verify the transaction's provenance using the sender's public key.
- Transactions are verified by a particular group of participants known as “Miners,” who then compile them with all the other transactions into a “block.”
- Bitcoins that were sent now belong to the beneficiary, and accordingly, balances on the global ledger are updated.

During Bitcoin transactions, there are three types of blocks: those in the main chain, which include encrypted confirmations of previous transactions. Those related to the main chain but not included, for some reason, and orphan blocks. The first two sets form a directed rooted tree with back-to-root links, whereas the orphan sets stand alone. From a technical standpoint, the blockchain is a chain of hash pointers that may be used to create a linked list of past transactions, and the rooted tree eventually converges on the blockchain. Each block is marked with a unique cryptographic signature. Each participating network in a Bitcoin transaction manages its own private/public key infrastructure.
