Therefore, there is a need for automation to identify and address these issues at the initial stages. Looking at automation in agriculture, there are many innovations in management [2]. However, all these advancements face a common challenge, which is the collection, storage, and processing of data for management.

As agricultural fields contain millions of crops, the data collected for further processing is extensive. There is no backend option to retrieve this data for future use. Therefore, we decided to create a blockchain integrated with big data automation to monitor the crops, along with Artificial Intelligence (AI) to predict diseases at an early stage [3]. In the blockchain component, the data collected from the automation process is stored in the cloud for easy access at any time and for seamless transmission to the AI for evaluation metrics. Big data is utilized to store the large data extracted from the blockchain and real-time data for analysis. By using this data, the AI predicts diseases and provides information to the digital twin to visualize the real-time condition of the specific crop with the location indicated, as shown in Figure 11.1.
