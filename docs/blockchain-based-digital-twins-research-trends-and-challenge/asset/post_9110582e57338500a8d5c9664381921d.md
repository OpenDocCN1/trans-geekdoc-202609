
## 10.1.4 DEEP LEARNING TECHNIQUES FOR PREDICTIVE MAINTENANCE

Deep learning (DL) models perform better than traditional and statistical ML models in the area of predictive maintenance when adequate data is available. The term “DL” denotes neural networks, an artificial machine learning procedure inspired by the operation of the brain that goes beyond shallow 1 and shallow 2-hidden layer networks. Commonly used DL techniques for predictive maintenance are summarized below:

- Feed Forward Multilayer Perceptron (MLP): A fully connected Artificial Neural Network (ANN) with three kinds of layers: input, hidden, and output. It can have more than one hidden layer. The model learns from the observations fed to the system by mapping the input features and target features [10].

- Convolutional Neural Network (CNN): It is a class of neural networks that extracts features directly from data by applying convolutional filters and detects patterns in images. It is more effective in classifying sequential data like acoustic, time-series, and signal data. It is considered to be faster than the traditional learning model. But shows poor performance in modeling long-term dependencies [11].

- Recurrent Neural Network (RNN): This backpropagation-based neural network can recognize patterns from sequential and time-series data. This learning model helps in predicting the next possible scenario.

## 10.1.5 DIGITAL TWIN

The DT is considered to be a simulated depiction of real-time entities and has become an inevitable part of industries. DT replicates the operations of its physical counterparts. The DT can be of two kinds – static twin (SDT) and dynamic digital twin (DDT) [12]. SDT is a copy of the practical world entity and is not influenced by the data generated from its counterpart. But DDT can be paired with physical counterparts and remains updated using the data stream generated by sensory devices. DT can be used for building predictive maintenance models.

### 10.1.5.1 CHALLENGES IN THE CREATION OF DIGITAL TWIN

- Interoperability: it is considered a primary issue. While establishing DDT, the information between a real-time entity and its virtual counterpart needs to be communicated in coordination without the support of the end user so that the DDT can replicate its counterpart. Predictive maintenance of multiple dependent machines requires the DTs to communicate and share information. Also, the DT which replicates the complex physical entity is made up of a hierarchy of smaller DTs. Communication among these building blocks of DT would be synchronized and coordinated. Interoperability plays a vital role in the parallel governance of the functioning of these DT building blocks.

- Storage: The stream of data communicated between DT and the physical entity, between DTs has to be stored in one place. It should be restructured to reflect the present standing of the corporal entity. Both archival and conceptual information in the storage should be available to the learning system for analysis in time. The more data, the better the performance of DT. Hence, the storage should be able to handle huge volumes of data. Also, it is essential to remove redundancy in the data stored in DT and avoid bottlenecks.

- Transparent Communication: The DT constructed from multiple contributors replicates the data from multiple physical entities. Hence, ensuring transparency in the data being transmitted among the contributors is another challenging issue to be considered while designing the DT.

- Information Technology (IT) and Network Infrastructure: For successful function, DT requires a combination of networks that can handle the transportation of huge volumes of data with high speed and support of IoT devices. Also, it is necessary to preprocess the data and do precomputing before sending the data to the digital counterpart. This can be facilitated by bringing computation and storage facilities close to the source environment using Edge computing, a distributed IT infrastructure.

- Security: The creation and functionality of a DT depend on the huge volume of sensitive data collected from the physical counterpart. Integrity, confidentiality, and transparency of this sensitive data need to be ensured.

## 10.2 EXISTING SYSTEMS

In this section, the frameworks proposed using the DT and blockchain technology to address the problems in various real-time applications like Vehicular Ad hoc Network (VANET), Industry 4.0, etc., are discussed. In Ref. [13], a DT model has been proposed for VANET with improved secure information transformation using Blockchain and low average delay time. It used digital signatures to verify the correctness of the traffic information passed to the Roadside unit. The signature is generated using SHA256 and security is strengthened by adopting blockchain technology.

Shamir's Secret Sharing (SSS) algorithm [14] is adopted by this scheme for distributing the message among unknown opponents. The message is sliced into an 's' number of fragments. The protecting strength is based on the two-threshold values t,s, where 't' refers to the minimum count of vehicles to participate in the cooperation process for the recovery of messages from the fragments, and 's' refers to the total count of slices generated by the SSS. It is further strengthened by reducing the risk of communicating with harmful nodes. Harmful nodes are identified by calculating the direct trust using Bayesian estimation and indirect trust. Hence, trust and fragmentation-based secure data transmission using Blockchain technology minimizes the effect of change in vehicle speed on the performance of the algorithm.

Kumar et al. [15] projected research work to facilitate the data analysis of the critical processes in the Industrial Internet of Things. The two major security elements – integrity and authenticity, are secured by adopting a blockchain-based communication scheme. The authors projected a Deep Learning-based algorithm for detecting intrusion long-distance feature.

GRU can retain information for a certain duration using update gates and reset gates, allowing the model to refine the output. Another learning model utilizing an attention-based neural network is employed to identify the remaining healthy lifetime.
