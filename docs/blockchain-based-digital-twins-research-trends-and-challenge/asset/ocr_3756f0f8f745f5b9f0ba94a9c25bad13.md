# 6.3.4 SYSTEM MODEL PHASES

To provide safe authentication processes for systems that exchange blockchain-
and cloud-based digital twin data. The stages of the proposed approach are
verification of information, owner cloud verification, ownership-user
identification, the initialization process, authorization, and ownership. Users,
cloud servers, and data owners are registered on the network that B establishes.

Data owners then create a secure connection with cloud servers and send
real-time data produced by their physical assets. Using the digital twins of the
assets, cloud servers may replicate the assets. The generated simulation results
are stored in the blockchain together with the resulting data hash values. When
a data user requests information on a digital twin, the user must first establish
an authentication relationship with the data owner. The log records are kept
after data has been traded and then saved in the blockchain. Below, each stage
is described in more depth.
