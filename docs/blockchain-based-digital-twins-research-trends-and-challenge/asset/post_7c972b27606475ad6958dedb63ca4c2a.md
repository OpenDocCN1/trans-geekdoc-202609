## 4.3.2 COMPONENTS OF BLOCKCHAIN

The key workings of Blockchain are as follows:

- 1. **Distributed Ledger Technology**: The system uses a shared and distributed ledger to record transactions one at a time in order to prevent duplicates.
- 2. **Immutable Records**: It prevents any data in the shared ledger from being transformed, changed, or tampered with.
- 3. **Intelligent Contracts**: It alludes to the set of guidelines for accelerating transaction times. Additionally, it runs and stores data in the blockchain. It establishes rules and guidelines for any transfers, including conditions.
- 4. **Public Key Encryption**: It serves as the fundamental building block of Blockchain. It makes use of public key encryption, a cryptographic method, to guarantee secure communication, confirm identities, and offer data integrity. Public Key encryption uses two cryptographic keys such as a public key and a private key [10].

## 4.3.3 WORKING OF BLOCKCHAIN

Blockchain works by the following steps. They are explained as follows:

- 1. **Step 1: Record the Transaction**: Every transaction is recorded as a block of data. It also covers the transfers and transactions of both tangible and intangible assets.
- 2. **Step 2: Gain Consensus**: The transaction was authentically recorded on the distributed blockchain network. The agreement rules differ based on the type of network, although they are often established at the outset of the network.
- 3. **Step 3: Link the Blocks**: After the parties have agreed, the transactions are then saved on the blockchain in blocks. The block contains the transactions and a cryptographic hash. The hash connects the blocks. If the block's data is modified intentionally or unintentionally, the hash value will change. The method of change is provided by the hash value. blocks are immutable and linked to each other.
- 4. **Step 4: Share the Ledger**: The system shares the latest copy of the ledger to each user.

## 4.4 APPLICATIONS OF BLOCKCHAIN

The various applications of Blockchain are as follows:

- 1. **Energy and Utilities**: Blockchain has the potential to streamline billing and settlement processes, enabling peer-to-peer trading of energy generation.
- 2. **Finance**: It enables decentralized services, including lending, borrowing, and yield farming.
- 3. **Media and Entertainment**: It manages copyright rights and helps in preventing unauthorized use and plagiarism.
- 4. **Retail**: It tracks the movement of goods between suppliers and customers.

## 4.5 OPEN-SOURCE PLATFORMS – BLOCKCHAIN

A few open-source platforms of Blockchain are explained as follows:

- 1. **Hyperledger Fabric**: It is a project created by the Linux Foundation. It has a modular architecture that is suitable for enterprise-grade use cases.
- 2. **Ethereum**: It is an open-source platform that allows the development of smart contracts.
- 3. **Corda**: It is an open-source project that focuses on privacy, scalability, and interoperability.
- 4. **Quorum**: It is an open-source platform based on Ethereum that is used for private transactions.

The development of smart contracts involves the following tools:

- **Solidity**: It is an object-oriented language used for developing smart contracts. It is similar to JavaScript. 
- **Geth**: It is a client for Ethereum that provides a console for commands and operates the blockchain.
- **Remix**: It is a graphical user interface for compiling, debugging, and testing contracts.
- **MetaMask**: It is a browser extension that allows users access to Ethereum dApps.
- **Parity**: It is a client-based environment for smart contracts.
- **Truffle**: It is a platform for developing smart contracts that supports automated testing with technologies like Mocha and Chai.
- **Embark**: It is a developer platform that aids in the development of DApps and facilitates the construction of smart contracts.
