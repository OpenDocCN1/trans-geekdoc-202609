## 11.4 BLOCKCHAIN

Blockchain is a new trend which is called distributed ledger technology [18]. It has a ledger for every input and communication so that the proposed blockchain is used. Actually, there are more field areas and because of that, all the data taken by the sensors is stored in clouds and transferred to the simulation center. Using the microcontroller itself, communication can be done to the simulation center, but it might be very slow, and the data may or not be affected by the noise. Because of that, it may lead to the biggest error in the prediction. That is why Blockchain technology is proposed.

Using the particular method, communication can be done at high speed and the data in the blockchain is immutable. It is not able to update or insert any blocks into the chain, and it has high security, i.e., it is very safe to use for communication and storage of data. Moreover, it is generally used in big industries, banks, and mainly in the transaction of Bitcoins. As said before, the proposed module will get the information from the microcontroller (the processed raw data of the sensors) convert it into the respective format, and transmit the data to the simulation center.

In the simulation center, there is another blockchain module that will receive the information transmitted from the field area. It will data and sends it to the simulation. If any command is made by the AI, it is also transmitted from the blockchain module from the simulation center to the field area. That specific information is converted into data that will be given to the microcontroller block. It involves using particular technology for the proposed condition.

The first key point is “Distributed ledger technology,” which means it has some ledger data containing information. This makes it very convenient for the customer using it. It also has smart contracts, connecting the blocks in the shortest way to access those blocks. It has an irreversible data structure, and each data block is connected to the one before and after it (like a doubly linked list). These are the main features of the proposed blockchain.

## 11.5 BIG DATA

Big data is one of the most famous ways to process raw data [19]. In the process, structured, semi-structured, and unstructured data are processed. Using this, the process can be sped up. This is only based on the user and customer convenience and comfort. It can be characterized by three ‘V’s (alphabetical letter, 22nd letter). and they are as follows:

- The size of the data in every environment is very large.
- As big data is used to store huge data, a wide range and different types of data types are stored in the system.
- Data is stored in large amounts; then it looks into the velocity (speed) of which data is being received and processed for storage.

In general, it is very useful for companies for marketing, advancement, insight into the customer, and so on. It is also used in the medical field for identifying diseases, using some signs (like the structure of a wound, color of the wound, etc.), finding the root of the diseases, and predicting risk factors. In the proposed work, there is a lot of data. Not of all of it is from the same field area; data from different field areas and different sensors are available. It is important not only to write the data but also to read all the data in a faster manner, so it is better to opt for Big Data. In simple words, the sole purpose of the proposed technology is to store and access all the data in a faster and more comfortable manner.

## 11.6 AI

AI is used for decision-making. Actually, by using machine learning, the model can be trained. When compared to AI, the efficiency is low in machine learning. AI will think like humans, so using the technology, decisions can be based on real conditions because AI is more efficient than humans [20]. That is the reason why it is planned to implement AI in the proposed work. In the current study, there are many simulation options available. Therefore, it is better to make decisions based on information to find the best way. Thus, the accuracy of the simulation can be precise as it mimics the real world. Making some changes can improve the efficiency of plants and crops. This cannot be achieved by human beings as it needs to be done quickly like machines, which is impossible. Programming is also challenging as predicting future conditions is a complex task.

There are nearly a trillion possible combinations available, which is why it is preferable to utilize AI to work with. The main role of AI is to extract information from big data and process [21]. It can identify efficient ways to maximize the quantity and quality of crops. Subsequently, it provides information to the user (customer). By using real-time data and artificial intelligence, it is possible to determine the exact requirements for plants and crops. For instance, predicting the moisture content in the air and soil sunlight intensity can help determine the water requirements.

If irrigation is used (it is one of the best irrigation types), it will transport the water to the roots of the plants so we can control the waste of water. Also, by using AI, it is easy to find out the nutrients for the plants [22]. By doing so, the usage of fertilizer and some chemicals can be minimized. With this technology, fruits and vegetables can be protected from chemicals, and the health of crops can be predicted. Unhealthy or disease-affected crops can be identified, and the level of disease spread as well as additional nutrient content required for crop growth can be estimated. This is then fed to the digital twin for visualization.

## 11.7 DIGITAL TWIN

A digital twin is a know-how system that brings up the imagination of realtime products into visualization with the support of factual information in the virtual environment [23]. It virtually shows the structure of an object with its interior parts. It helps the developers to see their product virtually and make changes or get alerted before they create it into a model. The handling of the components and its simulation process is made easier by digital twins. So, as in agriculture, the agricultural fields are being shown virtually by digital twin using the factual information extracted from the previous process.

The information received from the AI prediction is made into 3D visualization. The field is made into a virtual model and, in that, the affected crops are being located by the location data obtained from the sensor. On looking into the particular location, the 3D visualization of the crop is made visible [24]. On the right side of the virtual model, the predicted data is shown for reference (disease name, disease spread percentage, nutrient content, required maintenance, etc.). On the other hand, the estimation of healthy species and their levels are displayed.

As shown in Figures 11.6 and 11.7, by using digital twin technology, field management is made easier, allowing farmers to identify diseased crops accurately and at an earlier stage. This helps satisfy the further requirements for the crops to recover from diseases. The virtual model of each crop can be viewed with options for rotation and zooming, making analysis more flexible and faster. As a result, the crop yield percentage increases, and due to effective management, the nutrient content remains rich.
