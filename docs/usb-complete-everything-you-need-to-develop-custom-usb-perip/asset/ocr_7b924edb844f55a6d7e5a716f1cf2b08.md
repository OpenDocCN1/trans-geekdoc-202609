# Obtaining a Handle

An application can use a retrieved device path name to obtain a handle that
enables communicating with the device. Table 10-2 shows the API func-
tions related to requesting a handle.

# Requesting a Communications Handle

After retrieving a device path name, an application is ready to open commu-
nications with the device. The CreateFile function requests a handle to an
object, which can be a file or another resource managed by a driver that sup-
ports handle-based operations. For example, applications can request a han-
dle to use in exchanging reports with HID-class devices.
