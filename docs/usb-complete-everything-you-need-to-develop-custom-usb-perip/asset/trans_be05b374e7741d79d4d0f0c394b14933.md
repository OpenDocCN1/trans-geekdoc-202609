
Philips 传输描述符 (PTD) 定义了与主机控制器驱动程序交换信息的一种格式。描述符由一个头部组成，头部包含诸如端点号、事务类型（Setup、IN、OUT）、总线速度、切换位值和完成代码等信息，其后是数据。

芯片包含两个 USB 端口。一个端口可在 OTG 设备中用作 OTG 端口，或用作非即插即用主机或设备的宿主机或设备端口。第二个端口只能用作主机端口，不建议在即插即用设备中使用。
