# READ A BYTE FROM THE USB HOST:

RXF# IS LOW WHEN THE FT245BM HAS RECEIVED A BYTE FROM THE HOST.

THE DEVICE CPU BRINGS RD# LOW TO CAUSE THE FT245BM TO PLACE THE BYTE ON THE DATA LINES.

THE DEVICE CPU READS THE BYTE ON THE DATA LINES AND BRINGS RXE# HIGH AGAIN.

# WRITE A BYTE TO THE USB HOST:

TXE# IS LOW WHEN THE FT245BM IS READY TO RECEIVE A BYTE FROM THE DEVICE CPU.

THE DEVICE CPU WRITES A BYTE TO THE DATA LINES.

THE DEVICE CPU TOGGLES WR TO CAUSE THE FT245BM TO READ THE BYTE. THE FT245BM THEN SENDS THE BYTE TO THE USB HOST.
