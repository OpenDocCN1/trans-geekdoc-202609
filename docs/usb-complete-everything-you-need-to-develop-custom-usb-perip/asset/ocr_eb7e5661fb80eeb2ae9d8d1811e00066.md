Table 15-4: The host can monitor and control Status bits at a port using Get_Port_Status, Set_Port_Feature, and Clear_Port_Feature.

| Field | Bit | Status Indicator | Meaning (0 state/1 state) |
|---|---|---|---|
| Port Status | 0 | PORT_CONNECTION | A device is not present/present. |
| Port Status | 1 | PORT_ENABLE | The port is disabled/enabled. |
| Port Status | 2 | PORT_SUSPEND | The port is not/is in the Suspend state. |
| Port Status | 3 | PORT_OVERCURRENT | An over-current condition exists/does not exist. |
| Port Status | 4 | PORT_RESET | The hub is not/is asserting Reset at the port. |
| Port Status | 5-7 | reserved | Returns 0 when read. |
| Port Status | 8 | PORT_POWER | The port is/is not in the Powered Off state. |
| Port Status | 9 | PORT_LOW_SPEED | The attached device is full or high speed/low speed. |
| Port Status | 10 | PORT_HIGH_SPEED | The attached device is full speed/high speed. (2.0 hubs only) |
| Port Status | 11 | PORT_TEST | The port is not/is in the Port Test mode. (2.0 hubs only) |
| Port Status | 12 | PORT_INDICATOR | Port indicator displays default/software controlled colors. (2.0 hubs only) |
| Port Status | 13-15 | reserved | Returns 0 when read. |
| Port Status Change | 0 | C_PORT_CONNECTION | Connect status has not changed/changed. |
| Port Status Change | 1 | C_PORT_ENABLE | A Port Error condition does not/does exist. |
| Port Status Change | 2 | C_PORT_SUSPEND | Resume signaling is not/is complete. |
| Port Status Change | 3 | C_PORT_OVERCURRENT | The over-current condition has not/has changed. |
| Port Status Change | 4 | C_PORT_RESET | Reset processing is not/is complete. |
| Port Status Change | 5-15 | reserved | Returns 0 when read. |
