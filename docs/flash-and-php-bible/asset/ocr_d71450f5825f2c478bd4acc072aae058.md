# Using an Alternative Trace

The last topic in this chapter will be building a new trace that allows colors as well as other features. This trace alternative is built as a stand-alone SWF and can be called by any other SWF in the same domain (local is your machine). The code behind this trace alternative is based upon the LocalConnection class, which is a prebuilt class that allows multiple movies to share communications as long as they are in the same domain. The first part of the code is responsible for building the local connection object and registering the callback function.
