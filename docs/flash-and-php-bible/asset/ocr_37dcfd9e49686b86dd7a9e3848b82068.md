The second method, getConnection, is set as public so other classes have access to it. However, the comments define it as private to ensure remoting classes cannot access it. This method first checks for an existing connection resource and if one isn't found, a call to the connect method is made.

The last step of this function is to return the active connection resource, which is used in other classes.

```
```php
/**
 * Get database connection
 * @access private
 * @returns database link, to be used in other sql calls
 */
public function getConnection()
{
    if($this->link == null)
    {
        $this->connect();
    }

    return $this->link;
}
```
