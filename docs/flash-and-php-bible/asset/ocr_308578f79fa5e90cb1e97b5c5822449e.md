# Building the VideoListItem class

The next step before you can test the application is to build the VideoListItem class. If you attempt to run the application in its current form you would not only get errors, but you would also not be able to load any videos because the items are not clickable at the moment.

The first step is to create a new ActionScript file in your favorite editor. Save this file as VideoListItem.as to the same directory where your FLA is located. After the file is created, you need to build the skeleton of the class file, which needs to extend the MovieClip class because it is attached to a MovieClip instance in the library.

```
package

   }
}
```
