## Summary

In this chapter, you started by building a very basic video player and expanded upon that concept to build a multicategory video player. Using PHP to handle the data between Flash and the database made the application more dynamic.

Once you had the video player completed, you began to expand on that by adding video tracking. You learned how easy it was to implement new features into the existing code based on the way the original video player application was developed in the previous section.

The fourth part of the chapter introduced the process of developing custom components that could be reused in your future projects. For this example, you developed a login component that would disable an application until the user logged in.

The fifth and final part was bringing all of these techniques together to develop a final real-world video player application with a login module and video tracking from the previous sections. All you have to do now is populate the database with real data and you will have a fully expandable, multicategory, tracking, secure video player application.
