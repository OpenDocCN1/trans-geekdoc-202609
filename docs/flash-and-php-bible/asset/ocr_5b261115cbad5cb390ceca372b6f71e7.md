# # Setting up version control

The process of setting up version control depends on the system your development environment runs. A more complete installation guide would be included with the application that you decide to use. Basic installation would include unpacking the contents of the version control application, modifying the configuration file, and alerting Apache to the existence of that application.

# ## Using version control

Normally, the process of using version control is integrated into your code editor. However, there are applications available to use version control directly within your operating system.

Two version control managers for Windows and Mac OS X are shown in Table 15.1.
