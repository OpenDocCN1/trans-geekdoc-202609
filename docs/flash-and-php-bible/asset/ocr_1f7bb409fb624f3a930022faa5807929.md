The loginHandler function is handling successful logins, but does not notify the user of an incorrect login attempt. This can be fixed by adding an else statement that updates the response box in the Login box.

```
function loginHandler(e:Event):void
{
    if(login.data.username == "guest" && login.data.password == "pass")
    {
        login.close();
    }
    else
    {
        login.responseString = "username and password incorrect";
    }
}
```
