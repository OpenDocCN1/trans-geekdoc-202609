Previous versions of Flash had a native RecordSet class. In AS3, you would have to create your own class. This class has been added to the extra content available on the book's Web site and properly mimics the AS2 RecordSet class.

The first step in working with the RecordSet class is to modify the album method.

```
/**
 * List of albums for RecordSet
 */
function getAlbumByGenreID($genreID)
{
    $this->connect();

    $sql = "SELECT g.name, a.artist, a.albumName
    FROM albums a, genre g
    WHERE a.genreID=g.id
    AND g.id= ". $genreID;

    return mysql_query($sql, $this->_connection);
}
```
