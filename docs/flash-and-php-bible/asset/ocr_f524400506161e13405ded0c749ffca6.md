The final and most important step is to destroy the variables that contain the MySQL connection information. Destroying or deleting a variable is done by passing the variable reference to the unset() function, which removes the existence of that variable.

```
unset($host);
unset($user);
unset($pass);
unset($database);
unset($link);
```

It is important to have this step to ensure that future aspects of an application can't gain access to these variables. This is especially important when introducing third-party applications into your custom application.
