The loadSites() method is responsible for loading the list of sites to watch. An event is attached to the loading sequence, which is called when the site data is successfully retrieved.

```
var variables:URLVariables = new URLVariables();
variables.action = "getsites";

var urlRequest:URLRequest = new URLRequest(phpFile);
urlRequest.data = variables;

var urlLoader:URLLoader = new URLLoader();
urlLoader.addEventListener(Event.COMPLETE, loadSiteHandler);
urlLoader.load(urlRequest);
```
