One limitation of the previous function is the variables var is only accessible within that function. To ensure the data returned is accessible by the entire application, it is a good idea to store that data in an external variable.

After the new Object variable is defined, the next step is to modify the serverResponse function to store the loaded data into the newly created variable.

```
function serverResponse(e:Event):void
{
var loader:URLLoader = URLLoader(e.target);
var variables:URLVariables = new URLVariables(loader.data);

// check for valid data
if(uint(variables.itemLength) > 0)
{
storedResult = variables;
}

userTxt.text = "Welcome back, " + variables.username;
levelTxt.text = "Your current level is: " + variables.level;
}
```

The loaded object data is stored within the storedResult Object, but only if a valid itemLength is found. The itemLength variable is also returned by the PHP and validated using a simple if statement.

With this new addition to the code you can share the loaded data to other variables and sections within this same application.
