To offer more than one poll, a unique ID is assigned to each answer that determines which question it is associated with.

```
CREATE TABLE poll (
  id INT NOT NULL DEFAULT 0,
  pollValue TEXT NOT NULL,
  pollType VARCHAR(20) DEFAULT "" NOT NULL,
  pollVotes INT(11) NOT NULL,
  active VARCHAR(1) DEFAULT 1 NOT NULL
 );
```

This schema is placing the questions and answers in one table for simplicity. However, in a more robust application you would want to place the question and answers in two separate tables for better scalability. This is how you make a database more efficient.

After the SQL is written, you can move on to developing the PHP code. This application has two actions: the ability to get poll data and to vote. In a more advanced application you would most likely have an editor and removal system.
