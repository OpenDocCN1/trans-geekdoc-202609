# Summary

A lot of information was covered in this chapter and at this point you should have a pretty good understanding of how object-oriented programming works and when to use it. As you may now notice, classes and OOP in general offer a lot of advantages. However, you might also notice OOP development does take more time. This isn't necessarily a bad thing, because in the long run you will notice less development time on future updates. It also offers the less obvious advantage of more secure code that the developer can control. At this point you know how to set up and use classes in PHP and Flash, and will probably want to experiment with some of the more advanced topics that were not covered in this chapter.
