# Sending the initial request

The sendRequest function is called when a connection is made. This function sends data to the
status function and clears any existing queued information in the socket connection.

```
function sendRequest() :void
{
 statusMessage("Send initial request to [" + host + "]",
 "#006600");
 socket.flush();
 enableInterface();
}
```
