```
<?php

$doc = domxml_open_file('sample.xml');
$node = $doc->document_element()->first_child();
while($node)
{
    if(($node->node_name() == 'sampleNode') &&
    ($node->node_type() == XML_ELEMENT_NODE))
    {
        $content = $node->first_child();
        print $content->node_value();
        break;
    }
    $node = $node->next_sibling();
}

?>
```

> The domxml code requires PHP 4.3, or you must have PECL installed separately. You can find more information on the PHP Web site (http://us.php.net/manual/en/ref.domxml.php).

The previous example loads in the XML file and using Dom XML parses through it to find the sampleNode. Working within the loop, you are looking for the chosen node and when that node is found you print the contents to the screen. Not a very elaborate example, but it shows the overall process that would be found in a more advanced example.

# Simple XML

Working with Simple XML quickly shows how easy loading XML can be. This block of code is achieving the same result as before, but with a lot fewer lines of code. Two lines of code instead of 13 is a considerable improvement.

```
<?php
$xml = simplexml_load_file('sample.xml');
print $xml->sampleNode;?>

```
