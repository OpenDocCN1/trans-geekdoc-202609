You will quickly notice that the URLLoader class is used again, but this time to retrieve the PHP response. This is then placed into the URLVariables class to pull out the result from the overall response. The PHP is set up to simply respond with a SENT or ERROR response; however, you also use an else statement to catch any unknown responses, some of which could include network errors or simple parse errors in the PHP code.

A Label component is located in the contact form MovieClip, which is where the response is sent for the user to see. In a more advanced script you would most likely return a result number and leave the text response in the Flash, which would allow the ability to tailor the responses to specific languages, also called localization.
