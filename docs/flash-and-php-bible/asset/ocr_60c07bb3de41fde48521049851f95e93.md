function userResponseHandler(e:Event):void
{
    var urlLoader:URLLoader = URLLoader(e.target);
    var args:URLVariables = new URLVariables(urlLoader.data);

}

The response function is passed a reference to the Event. The URLLoader and URLVariables instances handle the process of pulling apart the response and returning just the data that was sent back. The response comes back with other values and parameters, but most of the time you will only be interested in the data property of the URLLoader instance.

More complete applications often return XML format, which is covered in Chapter 3 with other various data-loading examples.
