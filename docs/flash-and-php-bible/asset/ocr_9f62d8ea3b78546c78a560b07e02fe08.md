```
{
$x = $points->point[$j]->x;
$y = $points->point[$j]->y;

$color = $points->point[$j]->c;
$color = hexdec($color);

imagesetpixel($img, $x, $y, $color);
}
```

The pixel data is placed in a grid pattern one line at a time; the $x and $y are the point each color
is to be placed. All of this data is passed to the imagesetpixel function on each pass of the
inner loop.

The last step of the PHP once the image is created is to render the image as a PNG, such as shown
in Figure 13.3, and save it to the file system.

```
header('Content-Type: image/png');
imagepng($img, 'render_' . time() . '.png');
```
