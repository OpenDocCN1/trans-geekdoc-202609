Methods in PHP are accessed using:

```
$instance->methodName();
```

However, when you want to access a method inside the same class, you can substitute the instance variable and use `$this`. So, assuming you want to access the `helloWorld` method in the `Speak` class, it would look like this:

```
$this->helloWorld();
```

You can also use the Scope Resolution Operator (also called Paamayim Nekudotayim, which is Hebrew for double-colon) to access methods and properties. The difference is instead of using `$this`, you would use the actual Class name. This approach makes the code easier to read.

```
Speak::helloWorld();
```
