# OR

The OR statement is used when you want only one condition to match. For example, you want users that have a level of admin or mod. Think of this as an if..else for SQL.

```
SELECT * FROM users WHERE level='admin' OR level='mod'
```

Conditions in MySQL can come in handy when trying to drill down data, especially when you start combining them. It is not rare to create very complex SQL statements in a matter of minutes.
