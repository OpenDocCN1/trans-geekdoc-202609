# # Determining the active sandbox

Determining the current sandbox type is not limited to a simple trace response. You can present the user with a warning screen notifying him or her that the current SWF cannot access remote resources because it is running locally. You can also forcefully stop a movie from running if a local sandbox is found, which means the movie is no longer running from your Web site. For example, a movie running locally could have been stolen from your site, so it is a good idea to check for this and act accordingly.
