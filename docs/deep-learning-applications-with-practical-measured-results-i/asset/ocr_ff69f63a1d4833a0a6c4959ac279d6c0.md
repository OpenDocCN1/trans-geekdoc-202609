Another common forecasting system is ANFIS [23]. ANFIS is based on a fuzzy rule-based inference mechanism. It is composed of five layers and each layer contains several nodes. The nodes are described by a node function. Let $O_i^j$ be the output of the $i$-th node in layer $j$. In the 1st layer, every node I is an adaptive node with node function:

$$O_i^1 = \mu A_i(x),\ i = 1,2 \tag{1}$$

or

$$O_i^1 = \mu B_{i-2}(y),\ i = 3,4 \tag{2}$$

where $x$ or $y$ is the input of the $i$th node and $A_i$ or $B_{i-2}$ is a linguistic label associated with the node. Hence, $O_i^1$ is the membership grade of a fuzzy set $A_1, A_2, B_1$ or $B_2$ and it specifies the degree to which the input $x$ or $y$ satisfies the quantifier $A$ or $B$. Any continuous and piecewise differential function can be used as node function in the 1st layer. In the 2nd layer, each node $\Pi$ multiplies the inputs and sends the product in output:

$$O_i^2 = w_i = \mu A_i(x)\mu B_i(y),\ i = 1,2 \tag{3}$$

In the 3rd layer, each node N computes the ratio

$$O_i^3 = \bar{w}_i = \frac{w_i}{w_1 + w_2},\ i = 1,2 \tag{4}$$

In the 4th layer, each node computes the contribution of the $i$th rule to the overall output:

$$O_i^4 = \bar{w}_i z_i = \bar{w}_i (a_i x + b_i y + c),\ i = 1,2 \tag{5}$$

where $\bar{w}_i$ is the output of the 3rd layer and $a_i, b_i, c$ are a set of parameters.

Finally, in the 5th layer, the node $\Sigma$ computes the final output as the summation of all inputs:

$$O_i^5 = \sum_i \bar{w}_i z_i = \frac{\sum_i w_i z_i}{\sum_i w_i} \tag{6}$$
