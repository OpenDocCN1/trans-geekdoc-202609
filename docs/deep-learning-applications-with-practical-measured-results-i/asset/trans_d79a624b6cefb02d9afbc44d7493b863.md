## 2.2. 模型假设与多重约束

本研究的目的是在无人机系统定位精度限制下寻找无人机的最佳最优轨迹规划，这是一个多约束组合优化问题。

假设无人机的飞行区域和安全位置如图1所示。起点为A，终点为B。其轨迹的约束如下：

(1) 无人机在飞行过程中需要实时定位，其定位误差包括垂直误差和水平误差。每飞行1m，垂直误差和水平误差将分别增加δ个指定单位。到达终点时，垂直误差和水平误差应小于θ个单位，为简化起见，假设当垂直误差和水平误差均小于θ个单位时，无人机仍可按计划轨迹飞行。

(2) 无人机在飞行过程中需要校正定位误差。飞行区域内存在一些安全位置（称为校正点）可用于误差校正。校正点的类型包括水平和垂直校正点。如果无人机到达校正点，则可根据校正点的类型对误差进行校正，假设飞行区域内的安全位置（即校正点的位置）在飞行轨迹规划前已确定。图1为某条轨迹的示意图。如果垂直误差和水平误差能及时校正，无人机即可按预定轨迹飞行，最终到达目的地。

(3) 在起点A，无人机的垂直误差和水平误差均为零。

### 3.1. 多约束优化问题

本研究的重点是为无人机从起点规划到终点的轨迹，并寻找满足问题1中多约束的最优轨迹，因此我们建立该问题的数学模型。

### 3.1.1. 校正区域

无人机规划的轨迹是三维的，是一个包含多个校正点的空间。(x, y, z)定义为校正区域中校正点的坐标，其中x为水平方向的误差，y为垂直方向的误差，z表示高度。轨迹规划的物理空间可表示为集合：S = {(x, y, z) | 0 ≤ x ≤ X_max, 0 ≤ y ≤ Y_max, 0 ≤ z ≤ Z_max} (1)

其中X_max、Y_max和Z_max指对应坐标的最大值，可从数据集中获得。此外，从数据集中，我们可以在三维空间中绘制垂直误差校正点和水平误差校正点。图2是我们用MATLAB绘制的结果。

图2. 物理空间和校正点。蓝色点为垂直误差校正点，黄色点为水平误差校正点，红色五角星表示起点，绿色五角星表示终点。坐标轴范围来自数据集。

### 3.1.2. 目标函数

提出两个目标优化函数以最小化无人机的轨迹长度和无人机被校正的次数：

$F_1 = \min\left(\sum_{i=1}^{m} (\eta_i + \lambda_i + h_i)\right)$ (2)

$F_2 = \min\left(\sum_{i=1}^{m} (a_i + b_i)\right)$ (3)

其中$F_1$表示无人机从起点A到终点B的轨迹长度，$F_2$表示无人机经过校正区域被校正的次数，m表示无人机整个飞行过程中的校正总次数，$\eta_i$表示无人机第i次飞行的距离，$\lambda_i$表示第i次飞行到垂直误差校正点的校正距离，$h_i$表示第i次飞行到水平误差校正点的校正距离，$a_i$表示无人机第i次飞行到达垂直误差校正点，$b_i$表示无人机第i次飞行在水平误差校正点。

### 3.1.3. 多约束

无人机每次飞行一米时，垂直误差和水平误差将增加δ个单位。到达终点时，垂直误差和水平误差应小于θ个单位。因此，无人机整个飞行过程中垂直误差和水平误差的总值必须小于θ，且无人机每次飞行的距离η_i不会超过整个轨迹的位移l_AB：

∑_{i=1}^m a_i η_i δ < θ  (4)
∑_{i=1}^m b_i η_i δ < θ  (5)
0 ≤ η_i ≤ l_AB  (6)

对于无人机第i次飞行到垂直误差校正点的校正距离λ_i米，当无人机到达垂直误差校正点时，假设无人机第i次飞行η_i米会使其垂直误差增加δ η_i个单位：

λ_i = a_i η_i δ, i = 1, …, m  (7)

对于无人机第i次飞行到水平误差校正点的校正距离h_i米，当无人机到达水平误差校正点时，假设无人机第i次飞行η_i米会使其水平误差增加δ η_i个单位：

h_i = b_i η_i δ, i = 1, …, m  (8)

飞行过程中，无人机要么在到达垂直误差校正点后进行校正，要么在到达水平误差校正点后进行校正。为了根据校正点的误差校正类型更准确地进行误差校正，对第i次飞行引入二元变量a_i和b_i。当无人机的垂直误差不大于α1个单位且水平误差不大于α2个单位时，可进行垂直误差校正。当无人机的垂直误差不大于β1个单位且水平误差不大于β2个单位时，可进行水平误差校正。二元变量a_i和b_i可表示如下：

a_i = { 1, 当无人机到达垂直误差校正点时, 0, 当无人机未到达垂直误差校正点时, }  (9)
b_i = { 1, 当无人机到达水平误差校正点时, 0, 当无人机未到达水平误差校正点时, }  (10)

然后，目标函数还应满足以下约束，当无人机进行垂直误差校正时必须满足：

λ_i ≤ α1, h_i ≤ α2  (11)

进一步，当无人机进行水平误差校正时，目标函数必须满足：

λ_i ≤ β1, h_i ≤ β2  (12)

其中λ_i为无人机第i次飞行到垂直校正点的校正距离，h_i为无人机第i次飞行到水平校正点的校正距离，α1、β1为无人机的垂直误差，α2、β2为无人机的水平误差。
