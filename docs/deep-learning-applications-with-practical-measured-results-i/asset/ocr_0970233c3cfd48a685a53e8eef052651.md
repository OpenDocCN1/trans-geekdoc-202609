where ∇f_i(t^(k)) is the value of the first derivative of f_i(t^(k)) on vector t evaluated at the point t^(k).

Substituting f_i(t) in Equation (16) with its Taylor Expansion approximation indicated by Equation (17), the approximation of F(t) is:

min φ(t) = Σ_{i=1}^k φ_i^2(t)
= Σ_{i=1}^k (∇f_i(t^(k))^T t - ∇f_i(t^(k))^T t^(k) + f_i(t^(k)))^2  (18)

To simplify the above equation, use A_k to represent ∇f_i(t^(k))^T, and b to represent ∇f_i(t^(k))^T t^(k) - f_i(t^(k)). Equation (18) is simplified into:

min φ(t) = Σ_{i=1}^k (A_k - b)^2  (19)

where,

A_k = [∇f1(t^(k))^T; ...; ∇fm(t^(k))^T] = [∂f1(t^(k))/∂t1 ∂f1(t^(k))/∂t2 ... ∂f1(t^(k))/∂tn; ...; ∂fm(t^(k))/∂t1 ∂fm(t^(k))/∂t2 ... ∂fm(t^(k))/∂tn]  (20)

b = [∇f1(t^(k))^T t^(k) - f1(t^(k)); ...; ∇fm(t^(k))^T t^(k) - fm(t^(k))] = A_k t^(k) - f^(k)  (21)

f^(k) = [f1(t^(k)); f2(t^(k)); ...; fm(t^(k))]  (22)

Therefore, it can be obtained:

φ(t) = (A_k t - b)^T (A_k t - b)  (23)

The solution of this equation is:

t^(k+1) = t^(k) - (A_k^T A_k)^-1 A_k^T f^(k)  (24)

This solution can be simplified as:

t^(k+1) = t^(k) - H_k^-1 ∇F(t^(k))  (25)

where, H_k is the Hessian matrix:

H_k = 2 A_k^T A_k  (26)

∇F(x^(k)) = 2 A_k^T f^(k)  (27)

Equation (25) can be solved iteratively by starting with an initial solution.
