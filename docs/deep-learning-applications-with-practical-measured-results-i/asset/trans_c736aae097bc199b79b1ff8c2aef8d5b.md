## 4. 结果

### 4.1. 改进的修复网络

我们在不使用标签或与这些图像相关的其他信息的情况下，在VOC2017和COCO数据集上评估我们提出的图像修复模型。COCO数据集包含118,288张训练图像和100张测试图像。VOC数据集包含17,126张训练图像和100张测试图像。这些测试图像随机选自验证数据集。

我们将实验结果与PatchMatch [25]和上下文注意力(Yu J [14])进行了比较。PatchMatch [25]是补丁合成中最先进的方法之一，而上下文注意力(Yu J [14])目前是基于深度学习的相对先进的图像修复网络。为了公平起见，我们使用所有方法在我们的数据集上进行训练。Yu J [14]训练模型处理固定孔洞。因此，我们在测试数据集上使用了固定孔洞，以便于将结果与PatchMatch [25]和上下文注意力(Yu J [14])进行比较。固定孔洞位于输入图像的中心，大小为128 × 128。所有结果均直接从导出的训练模型生成，未进行后处理。

首先，我们的结果与PatchMatch [25]、上下文注意力(Yu J [14])在高分辨率图像中的显示对比如图5所示。可以看出，与其他两种方法相比，我们模型的修复结果更逼真、更平滑，并且更接近周围区域的纹理。接下来，表1中的定量对比也显示了我们的方法与PatchMatch [25]、上下文注意力(Yu J [14])的比较结果。我们使用三个评价指标：峰值信噪比(PSNR)、结构相似性指数(SSIM)和平均误差(L1 loss)。PSNR的单位为dB，值越大，图像失真越小。SSIM的值范围为0到1，值越大，图像失真越小。L1 loss是输入与输出绝对差值的总和，值越小，图像失真越小。从表中可以看出，基于深度学习的方法在PSNR、SSIM和L1 loss三个指标上均优于基于补丁的传统方法。与上下文注意力(Yu J [14])相比，我们的模型在数据方面有所改进。并且图5中明显可见，我们的模型可以有效减少模糊纹理以及与周围区域不一致的不愉快边界。我们的结果优于上下文注意力，这证明了我们模型在图像修复中恢复纹理细节的有效性。

图5. 我们算法、PatchMatch [25]算法和Yu J [14]算法的结果对比图。

我们的完整模型在TensorFlow v1.3、CUDNN v7.0、CUDA v9.0上实现，并在CPU Intel(R) Xeon(R) gold 5117 (2.00 GHz)和GPU GTX 1080 Ti硬件上运行。我们在纹理细节修复网络中引入了16个残差。然而，在训练中，这16个残差块消耗大量内存并减慢训练速度。在尝试将16个残差块减少到5个残差块后，我们发现我们的完整模型在GPU上每帧运行0.2秒，速度显著提升，而性能没有显著变化。

此外，所提出的修复框架还可以应用于条件图像生成、图像编辑和计算摄影任务，包括基于图像的渲染、图像超分辨率、照片编辑等。

我们将我们的掩码数据集与Liu [12]提出的掩码数据集进行了比较，并使用修复模型[13]训练了混合掩码数据集。我们的掩码数据集包含23,500个用于训练的掩码和11,480个用于测试的掩码，这些掩码随机生成自COCO数据集。Liu [12]提出的掩码数据集包含55,115个用于训练的掩码。混合掩码数据集总共包含78,615个掩码（包括我们随机生成的23,500个训练掩码和Liu [12]中用于训练的55,115个掩码）。

## 5. 结论

基于GAN的图像修复近年来取得了很大进展，但由于内存限制和训练难度，它们只能处理低分辨率图像。对于高分辨率图像，修复区域变得模糊，不愉快的边界变得可见。许多研究人员致力于改进现有的图像修复网络框架。我们提出了一种基于深度生成模型的新型高分辨率图像修复方法。它是一个两阶段网络，包括内容重建和纹理细节恢复。在获得视觉上可信的模糊纹理后，我们进一步恢复更精细的纹理细节以提高图像修复质量。同时，我们将实例分割和图像修复的现有研究相结合，删除背景中不必要的行人并确保背景恢复的真实性。为了提高特殊应用场景中图像修复的准确性，我们提出了一个新的掩码数据集，该数据集将COCO数据集中的人物作为掩码收集，并且可以为特殊应用场景产生更好的修复结果。

在未来的工作中，我们将基于论文实验卷积深度置信网络(CDBN) [37]和PCANET [38]。与CNN一样，CDBN可以提取图像的高频特征。根据最新研究，CDBN在大型图像分类任务中表现优于CNN，因此对于高分辨率图像，使用CDBN代替CNN可能更好。此外，PCANET可以在编码器中进行不同大小特征图的特征融合，这增强了输入与输出之间的相关性。然而，PCANET的更好结果可能以速度为代价。
