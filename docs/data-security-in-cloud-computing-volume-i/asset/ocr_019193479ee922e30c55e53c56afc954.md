The hybrid model is made up of a blend of private and public cloud tools, where the private and public cloud infrastructures operate independently and typically speak over an encrypted link as shown in Figure 4.12. It is necessary to see that the private and public clouds are different and separate components. Typically, organizations store critical or significant data in the personal cloud, and along with the public cloud they may use the private cloud to receive computational tools that applications rely upon, which enhances safety and reduces the information vulnerability to an accepted minimal. Hybrid clouds possess many advantages and deliver many options, since this deployment version is acceptable for producing a backup when failover scenarios happen, or when there are equilibrium heavy workloads, and can be far more cost-effective than personal clouds and other benefits based on the example.
