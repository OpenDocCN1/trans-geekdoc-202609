Because of this, the implementation of a single service should not interfere with the next. Typically, isolation could be accomplished by only using different physical servers or remote system infrastructures. However, with regard to cloud computing, it is quite hard to have complete isolation, as the VMs discuss sources. Because of this, in the event of isolation malfunction, somebody who has access to shared resources is going to have the ability to recover confidential data (ENISA 2009; Raj et al. 2009).
