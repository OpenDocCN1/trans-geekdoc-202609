The cloud user has restricted visibility and central restricted management control in a PaaS version because the cloud provider implements the security functions in all layers below the integration and middleware layer.

The cloud consumer loses control and visibility in a SaaS model, and generally, controls below the presentation layer are opaque to the cloud user, because the cloud supplier implements all security functions. While all cloud actors involved in orchestrating a cloud ecosystem are responsible for fixing operational, security and privacy concerns, cloud consumers retain the information ownership and so remain fully accountable for

+   - Properly identifying data’s sensitivity
- Assessing the threat from any vulnerability or abuse of the data and the impact to their business
