# 4.1.5. THICK OR THIN . . . OR SMART?

A thin client machine is going to communicate with a central processing server, meaning there is not much hardware and software installed on the user’s machine. Occasionaly, thin may be defined as simply not needing the software or operating system installed on the user machine. This permits all end users’ systems to be centrally managed and software set up on a central server location as opposed to being set up on each individual system. Thin clients are best suited to surroundings where the exact same information will be accessed by the clients, which makes it a better solution for public environments. Because of this, thin clients are often deployed in airports and resorts, where installing software in all systems would not make sense.
