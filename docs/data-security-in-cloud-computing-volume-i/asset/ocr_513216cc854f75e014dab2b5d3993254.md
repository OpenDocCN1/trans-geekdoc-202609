# 1.1. INFRASTRUCTURE-AS-A-SERVICE

In this version, raw IT tools like storage, hardware, IP addresses, and firewalls are supplied to the cloud customers over the Internet. Cloud users have the freedom to set up an environment on these platforms along with the applications they need and control these tools along with their safety and dependability.

# 1.2. PLATFORM-AS-A-SERVICE

For cloud customers who need a more substantial degree of computing and management outsourcing, cloud suppliers also offer ready-to-use platforms as support. Within this version, an entire virtualized environment using a working system image installed may be leased. Having obtained a particular platform, cloud users are free to set up and manage software running on the virtualized environment.
