# Item Recall

In supply chain applications, it is necessary to quickly trace unsafe products back to their source and where they have been distributed.

In this implementation, the REST endpoint, http://localhost:3000/api/Packet/p3001001 provides details of the packet p3001001.

```
{
"$class":" org.jlp.trading.Package",
"packetID": "p3001001",
"mainExchange": "GBP",
"quantity": 300,
"unitprice": 2,
"commodity": "resource.org.jlp.trading.Commodity#grassfed10001",
"owner": "resource.jlp.trading.Trade#tesco"
}
```
