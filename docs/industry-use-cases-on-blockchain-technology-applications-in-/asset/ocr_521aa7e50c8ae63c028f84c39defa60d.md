The authors use a public and permissioned blockchain so that ledgers are decentralized, and a selected set of nodes participates in consensus procedure. The authors have implemented the above use case using Hyperledger Fabric⁵, Composer Playground, Hyperledger Explorer, and Docker on Ubuntu 18.04.

The high-level architecture for the proposed solution using Hyperledger Fabric is illustrated in Figure. 12.
