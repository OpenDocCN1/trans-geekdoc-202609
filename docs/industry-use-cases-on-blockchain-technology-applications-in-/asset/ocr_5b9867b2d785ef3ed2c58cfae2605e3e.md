The end-users finding end-to-end details about a product, that involves a set of transactions distributed in randomly distributed blocks in a blockchain, are not straightforward in the current blockchain architecture. Though blocks are connected using block hash mechanism, the chain concept and random blocks integration make it complicated to find the evolution of an item in a supply chain. However, the decentralized nature of records and having the same copy of up-to-date ledger allow participants to directly interact with end-to-end details of data.

The authors have created a REST-API which is creating REST endpoints to members on the blockchain, asserts, user-defined queries, and transactions in the blockchain. Queries are defined to extract necessary information from the ledger. Representational state of these resources can be extracted, filtered, and connected to find end-to-end details. The processes should be defined accordingly.
