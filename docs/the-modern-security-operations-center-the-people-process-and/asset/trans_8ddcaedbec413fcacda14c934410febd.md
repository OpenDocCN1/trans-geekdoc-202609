
我曾有一位客户告诉我，尽管他的 SOC 团队标记了系统中的漏洞，但桌面支持团队却持续忽视这些漏洞。为了证明这些漏洞确实存在，该客户克隆了受影响的系统，制作了一段克隆系统被利用的短视频，并将该视频提供给管理层，以展示他能够获取 root 权限。作为对这一演示的回应，管理层要求修补那些先前被忽视的漏洞。

### 资产管理与合规工具

行业最佳实践（如 CIS Controls，参见[第 6 章](#ch06.xhtml#ch06)“[降低风险与超越合规](#ch06.xhtml#ch06)”）指出了标准化主机系统配置对于保护主机系统的重要性。通过这样做，桌面支持团队可以制定有关应安装和运行什么内容的策略和标准，并建立一条基线，以界定什么被视为可接受。当系统偏离基线中指定的标准化构建而不合规时，桌面支持团队可以部署控制措施。如果没有标准化，主机系统可能安装任何形式的操作系统、更新和安全工具，这使得极难了解与主机系统相关的当前风险。缺乏标准化也使得难以适应所有不同类型的系统及其保持安全的独特需求。标准化有助于漏洞扫描，因为它明确了关于应安装和评估内容的预期。我建议在标准构建中包含漏洞扫描代理，以简化漏洞扫描流程。

资产管理平台不仅帮助桌面团队了解正在运行哪些主机系统，还赋予他们强制标准化的能力，并在发现合规违规时推送修复步骤。资产管理工具还可以包含资产漏洞评估工具和漏洞评估功能。这些评估的结果提供了一份需要扫描的资产清单，以及扫描后与其关联的漏洞。资产管理工具的示例包括 `BMC Helix ITSM`、`Certero` 和 `Snow Software Asset Management`。[图 9-17](#ch09.xhtml#ch09fig17) 展示了 `Certero` 仪表板的示例。

### 网络扫描器与网络准入控制

收集网络上资产清单的另一种选择是使用网络准入控制（`NAC`）解决方案（本章前面已介绍）。`NAC` 解决方案可以收集许多详细信息，包括硬件地址、IP 地址、用户信息以及安装了哪些应用程序，并将这些详细信息导出到漏洞扫描器。某些 `NAC` 解决方案还可以配置为对连接到网络的设备发起漏洞扫描。在漏洞管理计划中纳入此 `NAC` 设置，可确保在授予网络访问权限之前对新设备进行扫描，这是我见过组织在其策略中包含但因缺乏 `NAC` 工具提供的自动化而难以执行的要求。该保证仅适用于启用了 `NAC` 的网络。[图 9-18](#ch09.xhtml#ch09fig18) 展示了 Cisco `NAC` 解决方案列出网络上设备的示例。

![FIGURE 9-18 Network Access Control Asset List Example](Images/09fig18.jpg)

**图 9-18** 网络准入控制资产清单示例

> `NAC` 技术和资产清单管理工具相互补充。`NAC` 工具可以充当资产清单管理工具，但不会提供那么多细节。`NAC` 工具非常适合验证资产清单管理工具收集的内容。

网络设备也可以使用简单的扫描技术（如 `Nmap`、`Angry IP` 或 `Zenmap`）来识别。这种方法的弱点包括：扫描间隔期间遗漏设备、运行扫描器时对网络的影响，以及取决于影响漏洞扫描器的类似因素（时间、准确性和资源）的扫描调优要求。[图 9-19](#ch09.xhtml#ch09fig19) 是 `Zenmap` 进行端口扫描的示例。

`NAC` 只能在网络上启用的地方强制执行安全性，如果 `NAC` 未在局域网、VPN 或无线网络上启用，则可能存在威胁访问网络的可能性。结合 `NAC` 和网络扫描器，可以让网络扫描器验证 `NAC` 技术是否已识别出所有已连接到网络的设备。

大多数现代漏洞扫描器都包含网络扫描器，减少了对专用工具或额外扫描的需求。资产管理解决方案、`NAC` 解决方案和专用扫描器是可以向漏洞扫描器提供资产清单的其他选项，有助于制定漏洞扫描计划，并设定漏洞管理解决方案将评估的资产类型的预期。推荐的做法是集成拥有资产清单和漏洞数据的工具，以最大化投资回报，并确保所有系统都拥有关于资产的最新数据。

### 威胁检测工具

一些威胁检测工具将漏洞评估功能作为其工具包的一部分，以防御组织中的网络弱点。例如，入侵防御系统（`IPS`）旨在防止针对已知漏洞的利用。调优 `IPS` 的最佳方式是将其配置的防护对象与网络中存在的漏洞相匹配。这很合理，也解释了为什么 `IPS` 厂商正在增加漏洞评估功能，以此了解其解决方案应防护的内容。

[图 9-20](#ch09.xhtml#ch09fig20) 展示了 Cisco 下一代防火墙（`Firepower`）如何利用其应用防火墙功能被动收集的漏洞数据，以及从 Rapid7 `Nexpose` 漏洞扫描器拉取的额外漏洞数据，来调优 `Firepower` `IPS`。所有漏洞数据均用于识别网络中的漏洞，以便 `IPS` 关闭匹配网络中不存在资产的特征码，并启用特征码以防御当前未受保护的内容。

![FIGURE 9-20 Cisco Firepower Tuning with Vulnerability Data](Images/09fig20.jpg)

**图 9-20** 利用漏洞数据调优 Cisco Firepower

漏洞扫描器、资产管理工具、安全设备和网络准入控制技术都是能为您的漏洞管理实践提供价值的工具示例。随着技术向云端转移，这些工具的变体正变得流行。专注于 Web 应用程序的扫描器正成为客户要求的热门功能。此外，渗透测试工具正在增加违规模拟测试，以加快渗透测试流程，这意味着测试可以在不攻击任何实时系统的情况下执行。违规模拟基于持续更新的云端情报源，这些情报源代表当前的攻击活动，使组织能够基于真实世界的威胁数据更好地了解其风险暴露情况。[第 11 章](#ch11.xhtml#ch11)“[SOC 的未来](#ch11.xhtml#ch11)”将回顾这些及其他云趋势，并对其他安全概念进行未来展望。
