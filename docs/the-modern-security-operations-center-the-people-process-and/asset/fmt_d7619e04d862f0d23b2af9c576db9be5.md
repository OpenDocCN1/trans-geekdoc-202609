
# 技术漏洞管理

## 职责与资源定义

*   定义职责，包括漏洞监控、漏洞风险评估、资产补丁管理、资产跟踪以及任何必要的协调职责
*   定义识别相关技术漏洞并提高安全意识的资源
*   定义响应潜在相关技术漏洞的时间线
*   定义负责识别相关风险并在发现潜在技术弱点时采取行动的组织；这些行动可以包括修补受损系统或实施其他控制措施
*   通过定义的程序处理漏洞。高风险系统应优先处理
*   衡量安装补丁或其他补救措施的风险
*   定义用于衡量漏洞的参考来源
*   建立资产清单
*   为事后分析制作记录

为确保其效率和有效性，技术漏洞管理流程应定期进行监控和评估。

## 标准指南与策略制定

`ISO 27002 A.12.6.1` 是一项可靠的指南，但其中包含的步骤可能并非全部适用，具体取决于您提供的漏洞管理服务的侧重点。无论您计划提供哪种类型的漏洞管理服务，都需要制定策略和程序。策略确保项目目标得以实现，而程序则解释为满足策略设定的所有期望需要做什么。`ISO 27002 A.12.6.1` 包含许多需要纳入漏洞管理策略和程序的行动，包括定义谁负责什么、如何处理漏洞及修复漏洞相关的风险、如何识别资产、按何种优先级顺序处理漏洞，以及在漏洞管理生命周期中记录所有内容的明确建议。

[图 9-1](#ch09.xhtml#ch09fig01) 概览了评估漏洞可采取的步骤，接下来我将更深入地介绍我推荐的成熟漏洞管理服务交付程序。例如，我指出了您需要收集资产，但应该如何收集？应使用什么工具和程序？下一部分将提供此类详细信息。

我将建议分为四个步骤，这些步骤融合了诸如 `ISO 27002 A.12.6.1` 之类的指南建议：

**步骤 1.** 资产收集

**步骤 2.** 规划与资产评估

**步骤 3.** 启动扫描

**步骤 4.** 纠正措施或接受风险

我推荐的漏洞管理服务交付程序简述如下：首先收集有关必须评估内容的信息。接下来，利用这些数据制定计划，确定优先处理哪些系统、网络或应用程序以及如何处理这些目标。制定计划后，通过处理目标列表开始扫描以进行评估。根据结果，要么采取纠正措施，要么接受不执行纠正措施的风险。

让我们更仔细地看看这四个步骤各自涉及的内容。

## 步骤 1：资产收集

回顾代表漏洞管理最佳实践的[图 9-1](#ch09.xhtml#ch09fig01)以及我推荐的漏洞管理服务交付程序，第一步的重点是收集资产信息。在开始执行任何形式的评估服务之前，您需要知道需要评估什么。拥有完整可靠的资产清单将简化整个漏洞管理项目。*漏洞管理项目最常见的失败原因是评估范围内的内容与网络上实际存在的内容之间存在差距*。

本章前面介绍的可用于建立资产清单的常用工具包括：

*   **网络扫描器：** 对网络子网运行扫描并收集识别出的设备列表
*   **网络准入控制：** 收集设备连接网络时的设备列表
*   **资产管理工具：** 从已收集资产详细信息的工具中提取资产列表

许多组织使用分段作为跟踪资产并根据组织子网中资产价值提供不同扫描流程的方法。例如，数据中心的关键服务器可放置在单独的网络段上，其扫描频率会高于普通网络。工程师通常能通过 IP 地址判断系统是什么及其位置，这基于网络分段方式及系统获取 IP 地址的方式。

全书中您已看到基于设备类型的分段策略最佳实践示例。IoT 设备等与高风险相关，应放置在不同于包含敏感数据系统的网络上。扫描“IoT 网络段”使资产识别和收集的预期更简单，并允许额外检测，因为可制定规则以响应特定网络范围外的设备。组织中常见的示例是为 IP 电话专用一个网段。这样做是为了确保该段资源专用于 IP 电话，简化电话流量管理，确保网段有适当带宽，并识别非电话设备何时连接到该网段。投资稳健且规划良好的分段策略可带来诸多益处，包括简化资产管理和改进对未授权设备的事件响应。

### 资产收集最佳实践

总结资产识别的最佳实践，请考虑以下几点：

*   使用 NAC 解决方案监控谁和什么连接到网络。这使 SOC 能在设备连接网络时收集新设备信息
*   如果使用 NAC 解决方案，请确保 NAC 技术在网络所有部分均已启用，包括 LAN、VPN 和无线网络
*   如果使用 NAC 解决方案，请将其配置为能够解释未授权的集线器、交换机和路由器，即检测到此类设备时采取阻止或将其移至另一网络等行动。不这样做将允许设备连接而不被 NAC 技术识别
*   如果使用 NAC 解决方案，请将其配置为重新评估已连接网络特定时长的设备。重新评估过程可在设备强制网络重连时发生，或通过使用无需网络重连的网络扫描器进行
*   按设备类型和对组织的价值对设备分段。示例包括为移动设备、IP 电话、打印机、服务器和 IoT 设备提供单独网络
*   如果使用 NAC 解决方案，请将其配置为监控尝试连接到网络段的不符合预期设备类型的设备
*   定期使用网络扫描识别已连接网络的设备，即使您正在使用 NAC 技术
*   确保网络扫描覆盖网络所有部分，并按固定时间表定期进行，以免网络段之间的扫描间隔过长
*   使用集中式主列表整合所有收集资产的信息
*   确保对设备主列表执行的任何去重步骤不会移除看似相似但实际不同的资产
