

# 战术威胁情报

战术威胁情报旨在供负责组织防御的技术角色使用。职位可能包括系统架构师、管理员和其他安全人员。高管角色倾向于依赖其技术人员利用战术威胁情报，而高管们则寻找以战略威胁情报报告形式呈现的非技术性摘要。战术威胁情报的来源包括开源工具、蜜罐、暗网上的数据收集器、扫描技术、恶意软件分析师、闭源网络和技术专家。战术威胁情报中预期包含的细节包括潜在攻击目标、攻击载体（如网络钓鱼或某种恶意软件类型），以及攻击者使用的工具或技术基础设施。一个例子可能是关于勒索软件如何利用不同类型的漏洞感染主机的数据。了解这些细节将使 SOC 能够评估其防御勒索软件的能力，并为未来的攻击做好更充分的准备。战术威胁情报并不关注某个特定的勒索软件活动，后者可能包含特定威胁行为者独有的战术组合和定制化。战术威胁情报的范围更广。

## 行动威胁情报

虽然战术威胁情报涵盖了攻击行为的细节，但它并不关注某个特定的攻击或活动。攻击者倾向于使用一组漏洞利用，称为 `chained exploitation`（链式利用），从活动的角度来看，这可以被指纹识别、监控，有时还能关联到某个威胁行为者。了解特定活动使防御者能够追踪与该活动相关的影响和风险，并验证其是否改变战术或可能以其组织为目标。作为战术威胁情报与行动威胁情报区别的一个例子，针对勒索软件的战术威胁情报会关注勒索软件的一般类别，而行动威胁情报则会关注针对特定 Apache Struts 漏洞的当前勒索软件活动，并可能将其关联到位于世界特定地区的威胁行为者。

行动威胁情报的来源包括拥有威胁活动数据访问权限的现场级资源。例如，一组白帽黑客可能拦截或攻破了某个威胁组织的通信或基础设施。示例包括：潜入讨论威胁活动的聊天室的资源、识别出售来自威胁活动的受害者信息的暗网论坛的资源，或者可能看到出于政治或社会原因宣传攻击的组织的广告或通信，例如黑客活动家发起有针对性的攻击活动。Twitter 和 Facebook 等社交媒体来源也可能包含行动威胁情报。诸如 FBI 的 InfraGard 计划等资源可以向订阅者发出警报，告知由为此威胁情报计划做贡献的组织所遇到的当前活动。许多供应商研究部门和威胁情报团队，如 Cisco Talos (`https://talosintelligence.com/`) 和 Fortinet 的 FortiGuard Labs (`https://www.fortinet.com/fortiguard/labs`)，会在博客和其他公共媒体上提供关于活跃恶意活动的更新。

> **注意**
>
> 一个重要的旁注是，获取某些形式的行动威胁情报可能涉及可疑或非法行为。在评估此类资源时，您可能需要向威胁情报提供商询问关于如何获取行动威胁情报的法律和道德问题。

## 技术威胁情报

技术威胁情报专门指威胁行为者的工具和基础设施。这种形式的情报比战术威胁情报更具体、更详细，侧重于妥协指标，即 IOC。使用聚焦的技术威胁情报（通常输入安全工具）的目的是提供对威胁的快速分发和响应。理解技术威胁情报的一个简单方法是：它是指示妥协的任何工件或行为，需要立即关注。

技术威胁情报可以是供应商更新的一部分，其相关局限性我之前已介绍过。技术威胁情报也可以是通用源，包含恶意软件哈希列表、注册密钥或与恶意软件相关的其他文件工件、与网络钓鱼活动相关的电子邮件特征、恶意 URL 或域名，以及与恶意行为相关的 IP 地址，如已知的命令与控制 (C&C) 基础设施或漏洞利用工具包。如果这些数据点提供的上下文能帮助您的 SOC 做出更好的决策，它们将被视为威胁情报；然而，如果这些数据点只是未知的源，例如被归类为“坏”的数据在没有任何上下文的情况下被泵入工具，那么它们将代表威胁数据。

技术威胁情报的生命周期通常比其他类型的威胁情报短，并由各种类型的安全工具大量消费，以帮助这些工具了解近期的攻击指标。安全工具从其供应商处接收威胁数据是常见的；然而，通过更符合组织需求的第三方威胁情报源，可以增强工具的能力。例如，一所学校可能会购买一个威胁情报源，其中包含许多针对学校的 IOC 的具体技术细节，这使得学校的 SOC 能够知道学校何时被特定威胁行为者盯上，并有助于在供应商提供的通用威胁数据之外调整其安全工具。这些数据需要持续更新，因为 IOC 在不断变化。

# 威胁情报上下文

理解与威胁数据相关的上下文是使其成为威胁情报的关键价值。威胁情报可以在内部和外部获取。[第 5 章](#ch05.xhtml#ch05) 介绍了安全工具如何生成事件数据，这些数据可以被整合并转化为行动。我称这些数据为 `internal threat intelligence`（内部威胁情报）。将供应商更新提供的情报、您在本地网络中看到的事件以及通过外部威胁情报源看到的威胁相结合，可提供一个平衡的数据系统，使您的组织能够为未来事件做好最佳准备。成功的关键在于如何平衡外部和内部情报，这将根据所解决用例的预期结果而有所不同。[图 7-1](#ch07.xhtml#ch07fig01) 代表了恰当利用内部和外部威胁情报的概念。
