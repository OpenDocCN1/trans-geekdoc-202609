
# 反汇编与恶意软件分析

全球恶意软件分析师最常用的反汇编工具之一是 `IDA Pro`。[图 8-15](#ch08.xhtml#ch08fig15) 展示了使用 `IDA Pro` 反汇编程序的示例。该示例演示了学习如何反汇编程序时最常见的训练练习之一。在此示例中，我的目标是强制程序跳转到一个显示“密码正确”的函数。左下角命令行界面所示函数显示“Congratulations”，右下角命令行界面所示函数显示错误消息。本练习的目标是找出作为决策点的函数，该函数决定跳转到正确消息函数还是错误消息函数。通过识别该决策函数，我可以修改逻辑，例如允许密码为空或 `1=1`（即一恒等于一），强制程序始终跳转到“Congratulations”函数。这是研究人员从软件中移除密码要求时的常见行为，也称为破解软件，这很可能是非法的。

### 恶意软件分析案例：WannaCry 杀伤开关

`WannaCry` 是一场发生于 2017 年 5 月的勒索软件攻击，波及全球系统。恶意软件研究员 `Marcus Hutchins`（网名 `MalwareTech`）反汇编了 `WannaCry`，发现了一个有趣的 URL。他研究该 URL 后发现其未被注册。出于好奇，他注册了该 URL 以观察 `WannaCry` 恶意软件在 URL 可用时的反应。令他惊讶的是，恶意软件连接该 URL，验证其存在后，关闭了 `WannaCry` 勒索软件进程。本质上，`MalwareTech` 无意中发现了一个内置的杀伤开关，从而在全球范围内遏制了 `WannaCry`。这一举动瞬间让 `MalwareTech` 成为网络安全英雄（尽管后来因其过往工作陷入麻烦）。[图 8-17](#ch08.xhtml#ch08fig17) 展示了使用名为 `Ghidra` 的反汇编工具反汇编并查看 `WannaCry` 勒索软件中臭名昭著的杀伤开关的示例。杀伤开关即包含 `www` 的代码。

## 动态分析

了解制品的另一种方法是在受控环境中执行它并研究其行为。这样可以展示程序执行时的行为、通信目标及执行意图。**切勿**在具有网络或公共互联网访问权限的系统上测试恶意软件，因为这会将你的组织和其他组织暴露于被研究制品攻陷的威胁之下。相反，你需要一个容器来工作，可以是隔离系统或沙箱。

### 隔离系统与沙箱

使用隔离系统和使用沙箱是有区别的。沙箱专为研究制品而设计，大多数包含许多工具和检测机制，可在制品执行时用于了解其情况。大多数现代沙箱还包含反检测工具，可用于欺骗恶意软件，使其相信已找到易受攻击的主机。反检测能力很重要，因为许多恶意软件作者设计恶意软件仅在识别到特定人类特征和行为时才执行，目的是避开沙箱和其他安全工具。沙箱可以模拟鼠标移动并提供虚假网络资源，所有这些都是为了让制品相信它找到了真正的攻击目标。沙箱构建于通用操作系统之上，因此你找不到为旧版或定制系统构建的沙箱。如果你的用例有可用的沙箱选项，我强烈建议利用它。

隔离系统只是一个测试制品的安全场所。这意味着你必须执行所有测试，并能识别何时发生恶意行为，因为隔离系统没有沙箱提供的那些工具和检测机制。这允许对测试环境进行更深度的定制；然而，这也需要更多的工作和技能来构建一个能够正确识别制品显示的所有行为的系统。一个例子是我和一位同事为 `Windows 3` 和 `OS2` 创建隔离虚拟镜像，目的是观察当前勒索软件在旧系统上如何执行。我们找不到公开可用的 `Windows 3` 或 `OS2` 沙箱，不得不使用非常有限的监控工具来尝试理解勒索软件样本在这些环境中运行时的行为。如果我们能使用现代沙箱，耗费数周研究获得的结果本可在几分钟内得到。

### Joe Sandbox

一个可用于制品动态分析的免费在线沙箱是 `Joe Sandbox`（[https://www.joesandbox.com](https://www.joesandbox.com)）。注册 [Joesandbox.com](http://Joesandbox.com) 后，你可以上传任意制品，让 `Joe Sandbox` 的研究人员在其沙箱中运行该制品（每月限 15 次分析/每天 5 次）。几分钟内，你将收到一封包含研究结果的电子邮件，包括该制品是否为恶意，甚至包含在系统上运行该制品的视频。将 `Joe Sandbox` 纳入你的 SOC 实践，你可以声称拥有基本的动态分析能力，且组织零成本！[图 8-18](#ch08.xhtml#ch08fig18) 展示了在 `Joe Sandbox` 中运行制品并接收裁决的示例，包括支持该裁决的视频。

### 其他沙箱

还有许多更高级的沙箱可在云端或本地环境中运行。如果你是该领域的新手，我强烈建议使用企业版沙箱。恶意软件始终存在突破沙箱并导致安全事件的风险。企业版通常包含支持和培训，旨在帮助你更好地准备恶意软件研究工作。
