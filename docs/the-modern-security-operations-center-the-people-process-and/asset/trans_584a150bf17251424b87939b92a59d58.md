
[图 9-1](#ch09.xhtml#ch09fig01) 中所示的模型始于识别漏洞管理服务评估范围内的所有资产。换句话说，网络上有什么？如果你不知道网络上有什么，就无法正确评估所有可能存在漏洞的内容。有一整类软件产品专门致力于解决大型组织资产清单的挑战。其中一些产品效果很好，而另一些则拥有出色的营销策略，但在发现网络上的资产方面却表现不佳。

>
> 我曾为一位客户提供咨询，该客户在完成资产清单和发现项目后，成功大幅降低了多个软件包的许可成本，该项目发现该组织高估了其环境中活跃计算机工作站的数量。这只是运行强大的资产清单项目所能获得的众多收益中的一个例子。

良好的资产清单意味着你不仅要对终端进行画像，还要对每一个网络连接（有线和无线）进行画像，因为许多设备（如 IoT 设备）不会登录到集中式管理或身份验证服务器。

### 选项 1：自动化网络准入控制

有多种方法可以强制执行正确的资产清单实践。了解网络上有谁和什么的行业标准是利用基于通用准则（如 NIST SP 800-53《信息系统和组织的安全和隐私控制》）的网络准入控制 (NAC)。通过跨 LAN、无线网络和 VPN 自动化访问控制，当设备连接到网络时，你可以确信自己知晓该设备。[第 2 章](#ch02.xhtml#ch02)“[开发安全运营中心](#ch02.xhtml#ch02)”介绍了 NAC 如何与资产管理相关联；本章将在“[网络扫描器和网络准入控制](#ch09.xhtml#ch09lev2sec15)”一节中进一步深入探讨自动化 NAC 概念。

在与客户交谈时，我发现 NAC 解决方案面临的最大挑战是当 NAC 未在所有网络端口上强制执行时会遗漏什么；例如，仅将 NAC 用于无线网络，或未启用每个端口由 NAC 解决方案监控。未启用 NAC 的任何端口都无法追踪资产，导致需要验证漏洞的资产列表出现潜在盲区。此问题可能导致对网络连接设备的安全感知产生虚假安全感，进而导致漏洞管理项目出现问题。

### 选项 2：手动网络准入控制

利用 NAC 自动化优势的替代方案是逐端口强制执行安全性，例如使用粘滞 MAC，并从网络交换机数据库手动收集资产信息。粘滞 MAC 允许交换机收集受信任系统的 MAC 地址，并将一个端口专用于该系统。如果另一个系统尝试连接到该端口，该端口将关闭。

这种方法的一个主要缺陷在于端口通过检查 MAC 地址来进行验证。如果攻击者能够伪造受信任系统的 MAC 地址，攻击者就能绕过端口安全，欺骗交换机认为白名单上的系统已连接。此外，端口安全在其方法上具有与 NAC 相同的“遗漏”缺陷。未启用端口安全的端口将允许设备连接且不被追踪，再次在你的资产收集策略中造成盲区。

### 选项 3：网络扫描器

使用网络扫描器是收集网络上设备信息的另一种选择。扫描器可以识别网络上已有的设备并生成资产列表。这种方法面临的挑战包括工具运行的频率、工具是否有权访问整个网络，以及工具如何进行扫描。

将网络扫描器与手动或自动 NAC 选项相结合是一种推荐做法。这种方法允许在设备连接时收集设备，并通过定期网络扫描验证所有设备是否已被纳入管理，二者结合相得益彰。用于识别网络上设备的最流行的开源工具之一是 Nmap ([https://nmap.org/](https://nmap.org/))。[图 9-2](#ch09.xhtml#ch09fig02) 展示了 Nmap 扫描网段以查找资产的示例。

Nmap 和其他网络映射工具很有帮助；然而，大多数现代漏洞扫描器都包含扫描新设备的功能。通常会发现 NAC、NAC 画像和网络扫描器通常是由多种技术和解决方案组成的资产清单整体策略的一部分。网络规模越大、地理分布越广，完整准确的资产清单就越复杂。最佳实践要求利用 NAC 技术以及网络扫描器，并将收集到的信息集成到漏洞管理技术中。本章后面的“[网络扫描器和网络准入控制](#ch09.xhtml#ch09lev2sec15)”一节将更详细地介绍这一概念。

## 第 2 阶段：信息管理

漏洞管理模型的下一阶段是信息管理。信息管理包括收集关于你通过端口扫描和访问控制数据创建的资产清单上所有设备的信息。诸如系统上安装并运行的应用程序、部署的补丁级别以及其他因素等信息，都允许 SOC 识别系统中的潜在漏洞。服务器本身可能没有漏洞，但安装的应用程序可能不安全，攻击者可利用该应用程序访问已打补丁的服务器。我经常看到这种情况发生在易受攻击的 Internet 浏览器插件上，它们允许已打补丁且运行最新 Internet 浏览软件的服务器被利用。

回顾 NAC 概念，大多数现代 NAC 解决方案都提供收集访问网络的系统信息的功能。此功能的一些示例包括 Cisco ISE Profiling 功能、Fortinet 的 FortiNAC Profiling 功能以及 Forescout 的 eyeSight 功能。对于包括 Cisco、Fortinet 和 Forescout 在内的大多数 NAC 厂商，都会使用 DHCP、DNS、ARP 和 Linkup traps 等各种协议，在设备连接和使用网络时对其进行指纹识别。大多数现代 NAC 解决方案还可以使用代理或 Java 在主机防火墙后进行更深度的扫描，从而实现对系统的完全可见性。漏洞扫描器也具备查看端口和协议以对设备进行指纹识别的功能。许多 NAC 系统结合了自己的扫描器，或提供与主流行业认可扫描器的集成。一个流行的示例再次是使用 Nmap，但这次是启动 `nmap -A target` 命令。该命令将对目标进行指纹识别，如[图 9-3](#ch09.xhtml#ch09fig03)所示。

![FIGURE 9-3 Nmap Fingerprinting a Targeted System](Images/09fig03.jpg)

信息管理阶段的一部分是为漏洞管理项目的下一阶段（即风险评估）做准备，在该阶段你需要识别潜在风险。理解资产的详细信息以及数据是如何收集的至关重要。最强大的清单追踪包括安装的操作系统信息（精确到补丁级别）、应用程序（包括安装的扩展）、安装的库、操作系统内配置的数据以及资产上运行的服务。缺少这些细节将导致风险评估结果不够准确。
