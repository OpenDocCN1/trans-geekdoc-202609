

# ISO/IEC 27005

一份广受欢迎的出版物是 ISO/IEC 27005 *信息技术——安全技术——信息安全风险管理*，它为信息安全风险管理提供了指导方针。如 [图 6-3](#ch06.xhtml#ch06fig03) 所示，ISO/IEC 27005 管理信息安全风险的步骤包括：建立背景；通过识别、分析和评估风险来进行风险评估；然后处理风险。这些步骤中的持续活动包括沟通、协商、监控和审查。任何组织都可以利用 ISO/IEC 27005 中提供的细节，通过根据 ISO 建议进行审计，或执行桌面演练并将 ISO 建议作为对比现有实践的基准，来帮助改进其处理信息安全风险管理的方式。

![图 6-3 ISO/IEC 27005 信息安全风险管理过程](Images/06fig03.jpg)

**图 6-3** ISO/IEC 27005 信息安全风险管理过程

ISO/IEC 27005 出版物中的一个示例用例是“背景建立”下的第 7.2 节，该节侧重于建议的信息安全风险管理方法。ISO 建议使用适当的风险管理方法，以解决基本标准，如风险评估标准、影响标准和风险接受标准。此外，ISO 建议资源应能够执行风险评估、制定风险处理计划、定义和实施政策与程序、监控控制措施，并监控信息安全风险管理过程。第 7.2 节保持在高层面，使其成为制定风险管理政策的理想资源。ISO/IEC 27005 的其他章节提供了更多细节，可帮助组织为新政策或现有政策制定支持性程序；然而，程序应始终包含与贵组织相关的具体细节。

ISO 指南涵盖了许多其他信息安全主题。例如，ISO/IEC 27034 为指定、设计和编程或采购、实施和使用应用系统的人员提供信息安全指导。应用系统通常由用户界面、业务逻辑和某种数据库组成。ISO/IEC 27002 非常流行，是一项国际公认的信息安全控制实践标准准则。ISO 提供了数百份涵盖各种 IT 主题的文件，您可以在 [https://www.iso.org](https://www.iso.org) 上搜索浏览。

## CIS Controls

互联网安全中心 (CIS) 为网络防御提供最佳实践解决方案，并建立和领导行业小组，以在网络安全社区内营造信任环境。一项极受欢迎的 CIS 资源是 CIS Controls，这是提供具体且可操作方法来降低被利用风险的安全最佳实践。CIS Controls 源自领先威胁报告中强调的最常见攻击模式，并经由广泛的行业安全专业人士社区审核把关。参与 CIS Controls 审核的成员包括 NSA 红蓝队、美国能源部核能实验室以及各种执法机构，这些都为该资源增添了公信力。

CIS Controls 细分为以下三个类别，如 [图 6-4](#ch06.xhtml#ch06fig04) 所示（基于撰写时的当前版本 CIS Controls Version 7.1）：

*   **基本 CIS Controls：** 任何基础性措施都应被视为安全的“入场券”，意味着所有组织都应以某种形式将基本类别中的建议应用于其流程中。基本建议类别示例包括识别网络上的资产以及处理漏洞。
*   **基础 CIS Controls：** 针对恶意软件防御或保护组织 DMZ 或网络边界等威胁类别的防御措施。
*   **组织 CIS Controls：** 影响整个组织的控制措施，如事件响应。

![图 6-4 CIS Controls Version 7.1](Images/06fig04.jpg)

**图 6-4** CIS Controls Version 7.1

CIS 在考虑其建议适用的组织类型时，会根据组织的规模和预期资金进行划分。例如，一家小型餐厅不太可能投资昂贵的漏洞管理工具来评估其业务中使用的少数终端。CIS 采用三层分组系统来确定哪类组织应考虑所提供的建议。[图 6-5](#ch06.xhtml#ch06fig05) 展示了 CIS 如何定义其系统，以对预期使用 CIS Controls 资源的不同类型组织进行分组。

![图 6-5 CIS Controls 组织分组](Images/06fig05.jpg)

**图 6-5** CIS Controls 组织分组

CIS Controls 的一个示例用法是参考 CIS 子控制 2.2，其内容为“确保软件受供应商支持”。该建议被归类为“识别”安全功能，并适用于所有三个组织分组，这意味着任何规模的组织都应遵循此建议。该子控制的解释部分进一步将此建议定义为：仅根据供应商要求使用授权软件，并将任何未经授权的软件列为不受支持且潜在风险。

任何规模的组织都能从参考 CIS Controls 中受益。它们简短、战术性强，且经由行业专家充分审核把关。

## ISACA COBIT 2019

ISACA 是一个独立、非营利的全球性协会，致力于制定信息系统最佳实践指南。其最受欢迎的产品之一是 COBIT 2019 企业 IT 治理与管理业务框架。COBIT 2019 提供了详细的赋能指南，侧重于治理和管理最佳实践。COBIT 2019 还拥有针对实施、信息安全最佳实践、保证指导、风险管理及其他安全主题的专业指南。COBIT 2019 仅对会员开放，需支付少量费用。请访问 [https://www.isaca.org](https://www.isaca.org) 了解更多关于 COBIT 2019 和其他 ISACA 产品的信息。

## FIRST CSIRT 服务框架

事件响应与安全团队论坛 (FIRST) 是全球事件响应与安全团队的论坛。FIRST 提供各种标准、出版物和最佳实践指南，旨在为各种网络安全概念提供最佳实践。FIRST 一项广受欢迎的产品是计算机安全事件响应团队 (CSIRT) 服务框架。CSIRT 服务框架是一份高层级文档，描述了一系列网络安全服务及相关职能，供其他安全团队学习借鉴。CSIRT 服务框架本质上是一份事件响应最佳实践指南。
