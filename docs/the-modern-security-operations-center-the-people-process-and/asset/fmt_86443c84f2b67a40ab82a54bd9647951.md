
虽然提供内部 SOC 服务是许多组织的理想选择，但有时商业模式使其因成本过高而难以实现。外包服务的优势可能包括降低成本，因为组织无需招聘和支付员工薪资、提供医疗保险等福利，或提供工作空间和设备。人员是企业最昂贵的资产，在当今市场上，寻找并留住专门从事特定 SOC 服务的合适人才颇具挑战。依我经验，许多外包 SOC 服务的组织之所以做出此选择，是基于对比：组建一支拥有合适技能的团队及/或培训内部员工加入 SOC 的成本，与接入能更快产生影响且具有额外价值（如拥有处理其他客户事件的经验）的外部服务的成本。其他客户的数据可作为一种威胁情报形式，意味着服务提供商能看到其他组织发生的事件，从而帮助其主动为针对贵组织的未来攻击做好准备。

由于利益冲突情况，某些组织被要求外包部分 SOC 服务。例如，一个组织可能拥有内部数字取证专家，但因为这些专家知晓任何内部调查涉及的当事人，如果法官认定他们与受影响方的关系可能影响了其调查或证词，他们可能不被允许出庭作证。在这种情况下，组织应将调查移交给外包的数字取证团队，以使结果被视为无偏见的意见。

#### 服务劣势

正如前文讨论外包优势时所述，内部 SOC 服务的主要劣势是妥善创建和维护它们的成本，以及获得所需预算的相应挑战。确定创建内部 SOC 服务的成本颇具挑战，因为存在许多不确定性，例如寻找合适人员的成本、业务不可预见的变化、所需培训以及建立实践所需的时间。这就是为什么拥有高管赞助 SOC 如此重要的原因。没有这种级别的支持，这些成本障碍中的任何一个都可能得不到解决，导致 SOC 服务变得机能失调。我将在[第 2 章](#ch02.xhtml#ch02)中提供关于获得领导层支持 SOC 的建议。

在难以将组建 SOC 团队的总预期成本转化为美元价值的情况下，向领导层推销这一想法非常困难，因为你本质上是在要一张空白支票。有一些公式可用于克服这一顾虑。我将在[第 6 章](#ch06.xhtml#ch06)中介绍一种公式，用于计算事件发生的可能性，并确定事件发生时给组织造成的成本。该公式将考虑如何将该成本分摊到一段时间内。最终结果将是一个假设的事件成本金额，以及其成本如何随时间分摊，从而给领导层一个可供比较的价值，基于事件发生的可能性以及发生频率与风险进行对比。如果该价值极高，例如每次可能发生的安全事件高达数百万美元，那么为降低毁灭性事件发生几率而投入 SOC 服务成本就讲得通了。如果单次事件成本较低，合同制或临时服务等其他选项可能是企业的最佳选择。这些计算通常是假设性的，而大多数合同制和按需服务具有更清晰的相关成本，这使得外包成为负责为降低风险提供资金的各方更具吸引力的方法。如果你计划获得 CISSP 或 CompTIA CySA+ 认证，你将需要掌握计算安全成本的公式。

如前所述，外包服务的最大劣势是服务提供商对组织了解有限，以及缺乏灵活性，因为外包服务受固定合同约束。变更合同有成本，且提供商可能没有可用资源来支持所请求的变更。外包的另一个劣势是，外部服务通常使用部署在网络外部或放置在网络内部的工具来监控环境，这限制了组织对这些工具安装位置的可见性。此外，许多外包服务还会轮换人员，意味着分配给合同的资源并非专职，且对其被指派保护的环境知之甚少。最后，外包服务通常提供不同层级的覆盖范围，其结果是：如果顶级客户发生事件，将消耗服务提供商的顶尖人才，导致购买较低层级覆盖的其他客户只能获得有限支持。[表 1-2](#ch01.xhtml#ch01tab02) 概述了内部 SOC 服务和外包 SOC 服务的劣势。

**表 1-2** 内部 SOC 服务与外包 SOC 服务的劣势

| 内部劣势 | 外包劣势 |
| --- | --- |
| 成本 | 有限的业务知识 |
| 人员（招聘/维护） | 外部工具和数据流 |
| 潜在利益冲突 | 缺乏沟通 |
| ROI 担忧 | 通常非专职人员 |

#### 混合服务

组织通常采用混合方法，以获得内部和外包 SOC 服务方法的最大效益。我遇到过许多公司外包一级支持，并培训内部专家处理超出一级能力范围的升级事件。这一流程的价值在于将通用请求外包，减轻高成本内部资产的工作量。内部资产了解环境和内部政治，并拥有所有内部工具的访问权限。一级支持对组织的可见性有限，但足以处理许多第一线支持呼叫。这种混合示例还为组织提供了培养内部资产的机会，最终这些人员可处理一级支持需求，组织从而能解除未来的外包需求。同样的方法可用于特定服务，例如先外包事件响应服务，直到内部成员被要求或培训至能承担此职责。在需求旺盛时期（如可能需要特定专业知识的重大事件期间），服务也可被外包。

### SOC 服务

全球成熟的 SOC 往往拥有一组共同的核心安全服务。这些服务可能是内部的、外包的，甚至是按需的，使 SOC 能在需要时调用所需服务。按需服务可以是保留服务以备不时之需的合同，也可以是简单的保存服务报价，以便在未来某个时间点执行。无论交付方式如何，每个 SOC 都需要提供一些服务。总之，这些通用的 SOC 服务可定义为以下服务：

*   **风险管理：** 识别并做出决策以应对组织风险。这涉及管理任何类型的风险，从物理保护资产到修补软件中存在的数字漏洞。这也适用于修复薄弱策略，以及组织成员缺乏安全意识教育的问题。
