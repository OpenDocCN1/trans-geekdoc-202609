

# 文档分析与恶意软件识别指南

## 核心建议：明确调查目标

我能提供的最重要建议是：**明确执行调查的目标**。

- **目标：判断风险** —— 研究直到确认答案，然后停止。若仅计划移除恶意制品，无需耗费数小时做高级分析。
- **目标：了解威胁影响** —— 需分析制品功能运作方式，投入更多研究。
- **目标：识别特征以阻断同类恶意软件** —— 可能需完整反汇编与调试，耗时最长。

选择分析结果时，请综合考量所需时间与资源。

## 推荐分析流程

终点目标决定你在以下列表的哪一步停止，因为每一步都需要额外时间和资源：

**步骤 1** 回顾与制品相关的现有工具、日志及其他来源。

**步骤 2** 使用快速、简单的静态分析技术。

**步骤 3** 使用快速、简单的动态分析技术。

**步骤 4** 执行更深度的静态与动态分析。

**步骤 5** 执行深度分析，包含完整反汇编与调试。

大多数事件将在**步骤 1** 后停止，因为现有工具已提供足够信息判定制品为恶意。若步骤 1 证据不足，则进入步骤 2 做快速静态分析；静态分析细节不够再转步骤 3 动态分析。若事件响应流程要求追踪威胁传播方式，则需更深入研究，可能要投入大量时间搭建安全环境交互、反汇编制品。

我认为前三步适合事件响应分析师执行；更深层分析应升级给专门分析制品的专家。

## 识别制品类型

制品外表可能具有欺骗性。恶意软件创作者伪装制品，诱使用户或系统执行操作。例如，名为 `evil.doc` 的 Word 文件实为 `evil.doc.exe`，运行后会在目标系统执行恶意行为。[图 8-8](#ch08.xhtml#ch08fig08) 展示了导致用户不知扩展名被隐藏的 Windows 设置。

### 魔数

每个文件都有**魔数**标识其类型。验证文件的绝对方法是查看该数值。例如识别 GIF 文件，可在数据包层分析文件开头是否为 `47 49 46 39` 或包含 `GIF89`。许多安全工具采用此技术识别 PDF、GIF、JPEG 等类型。[图 8-9](#ch08.xhtml#ch08fig09) 展示我为 Snort 编写的 IDS 规则，检测流量中的 `47 49 46 39` 或 `GIF8`，匹配则触发日志“GIF file detected in network”。

### 文件识别工具

更简便的验证方法是使用文件识别工具，它们自动完成魔数分析，并常提供额外信息（如文件是否被加壳——恶意软件常见特征）。[图 8-10](#ch08.xhtml#ch08fig10) 为免费开源工具 **TrIDNET** 示例：点击“浏览”上传文件即可分析。类似工具还有 **PEiD**。

## 文件加壳

现代恶意软件多以**加壳文件**形式出现。开发者利用此技术对抗反汇编（及后续清除），因为安全工具可对未加壳恶意软件反汇编以学习其基本特征，供防御工具识别拦截。本质上，加壳即**可执行文件压缩**，发生在恶意程序生成并转为可执行文件之后。

[图 8-11](#ch08.xhtml#ch08fig11) 对比了未加壳程序（左）与加壳程序（右）。头部包含程序详情；程序调用的其他程序与资源均有标签；最后是实际程序代码。程序编译为可执行文件后转为机器码，研究人员可用工具逆向工程还原功能。为防止此情况，加壳会压缩并加密程序相关代码，阻碍恶意软件功能研究。
