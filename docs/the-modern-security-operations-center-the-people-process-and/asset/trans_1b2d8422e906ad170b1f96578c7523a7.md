### 使用 Phantom 的 DevOps 示例

商业 SOAR 简化了剧本创建过程；但这并不意味着完全移除了编程。企业 SOAR 解决方案通常通过使用模板、向导和可调用的预构建函数来帮助简化剧本创建；然而，为了创建工作流，必须进行一种称为 DevOps 的特定类型编程。[图 10-7](#ch10.xhtml#ch10fig07) 展示了在 Phantom 邮件泄露剧本模板中点击“创建工单”函数的示例。

![图 10-7 Phantom DevOps 编码示例](Images/10fig07.jpg)

**图 10-7** Phantom DevOps 编码示例

请注意，Phantom 会调出与生成工单相关的代码；向导和其他内置工具可以帮助分析师快速调整代码以满足组织需求。与大多数编程语言一样，Phantom 包含一个调试器（`Playbook Debugger`），它会标记剧本代码中发现的错误，并尝试高亮显示导致问题的代码行。此示例强调了为什么 DevOps 技能组合的需求日益增加，以及为什么 DevOps 技能被视为不同于 C++ 或 Pearl 等编程语言的通用编程经验的技能组合。这种编程技能组合的重点是理解工作流目标，并编写代码以使用最高效、最准确的方法实现这些目标。换一种说法，这种编程结合了 IT 运维和软件开发的目标。本章后面的“[DevOps 编程](#ch10.xhtml#ch10lev1sec6)”一节将更详细地探讨这种类型的编程。

前面的示例仅涉及 SOC 使用 Splunk Phantom 等企业 SOAR 解决方案所能做的事情的皮毛。从此用例中得出的关键点如下：

*   SOAR 解决方案专注于案例管理和节省时间等概念。
*   剧本可以是手动的，但 SOAR 的价值在于在适当的时候实现步骤自动化。
*   可以使用模板和向导实现自动化；但仍需要一些编程。
*   SOAR 解决方案中的编程是一种不同类型的编程，专注于让技术与其他技术协同工作，而不是创造新事物。
*   SOAR 解决方案不像 SIEM 解决方案那样专注于数据挖掘或事件管理，但非常适合事件整合，这可以成为剧本的一部分。例如，当发生特定事件时，SOC 可以启动剧本操作。

接下来要更仔细研究的主题是 EDR 和 XDR 解决方案，因为它们提供的价值与 SIEM/SOAR 解决方案组合类似。您将近距离了解 EDR 市场的领导者，以体会 XDR 的由来。

### 端点检测与响应

到目前为止，SIEM 和 SOAR 解决方案概念的讨论使用了网络层自动化的示例，重点关注剧本的工作流。自动化也可以关联到端点和软件。美国国家标准与技术研究院 (NIST) 发布了 NIST 机构间报告 (NISTIR) 8011《安全控制评估的自动化支持》，详细介绍了如何测试和自动化解决软件自动化相关网络安全问题的特定方法论。换句话说，NISTIR 8011 解决了关于如何审计自动化软件的问题。[表 10-2](#ch10.xhtml#ch10tab02) 列出了 NISTIR 8011 中记录的一些常见攻击方法及相应的缓解流程。

**表 10-2** NISTIR 8011 攻击方法论

| 攻击方法 | 缓解流程 |
| --- | --- |
| 内部入侵 | 阻止本地访问：限制管理员访问权限和软件安装特权 |
| 内部攻击 | 减少并禁止软件运行，除非事先授权 |
| 获立足点 | 限制软件安装 |
| 横向扩展 | 减少系统上的现有漏洞并强制执行网络间的隔离。 |

端点安全供应商已接受挑战，以类似于 SOAR 市场的方式解决这些问题，包括提供案例管理、剧本、自动化和编排，通常归类为端点检测与响应 (EDR)。与 SOAR 剧本一样，EDR 剧本考虑事件的整个生命周期，包括谁负责执行什么操作，以及在结案前应完成什么。

#### EDR 示例：CrowdStrike

一种流行的 EDR 企业解决方案示例来自 CrowdStrike，称为 Falcon。Falcon 是一种云交付的 EDR 解决方案，利用安装在端点上的代理。CrowdStrike Falcon 提供端点防病毒功能，结合事件管理的自动化和编排；利用各种形式的数据丰富和威胁情报进行高级威胁防护；以及一些端点设备控制功能，所有这些均基于购买的许可证类型和系统配置方式。

[图 10-8](#ch10.xhtml#ch10fig08) 展示了 CrowdStrike Falcon 仪表板的示例。第一个需要注意的关键数据点是高度关注事件检测。有涵盖所有累积事件感染的端点数量、已识别恶意软件相关的安全哈希算法 (SHA)、恶意软件使用的战术类型以及最近事件的控件。就事件而言，EDR 的运作方式类似于 SIEM 解决方案；不同之处在于 EDR 解决方案的范围仅限于端点。

![图 10-8 CrowdStrike Falcon 仪表板示例](Images/10fig08.jpg)

**图 10-8** CrowdStrike Falcon 仪表板示例

Falcon 以图形格式显示事件，以便分析师跟踪事件从开始到修复的生命周期。[图 10-9](#ch10.xhtml#ch10fig09) 展示了 Falcon 中一个事件的示例，该事件始于 Microsoft Outlook 并通过 `notepad.exe` 启动。攻击的每一步都可以被分析，以帮助 SOC 分析师了解发生了什么、为什么该操作是恶意的，以及应采取什么措施防止威胁采取进一步行动——换句话说，防止爆发。在 EDR 解决方案平台中，这种开发恶意软件在事件期间采取的每一步的图形视图的方法非常常见。
