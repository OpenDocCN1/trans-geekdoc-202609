
# 我对本书的愿景

我对本书的愿景是采取一种与厂商无关的安全方法，重点关注能力和最佳实践，以帮助你应对未来的威胁。书中包含大量开源和商业产品示例，但我始终关注建议的结果，因此所选厂商并不重要。我引用具体指南来验证我的建议，并解释不执行本书所涵盖内容的风险。我相信各个经验层次的安全专业人员都能从本书中受益，并希望本书能成为你对抗网络威胁旅程中的宝贵资产。

## 谁应该阅读本书？

我认为任何对网络安全感兴趣的人都将从本书中受益。我从领导层的期望到一线操作人员的关注点等不同视角来解释概念。主题包括建设 SOC、风险管理、漏洞管理、事件管理、恶意软件分析、合规、数字取证、态势感知与安全意识，以及研发。所有这些主题都对应全球成熟 SOC 提供的服务。任何有兴趣学习如何将这些服务构建到其安全实践中的人都将从本书中受益。

## 本书的组织方式

从你开始规划建设 SOC 的那一天起，就可以使用本书，它也可以作为帮助成熟现有 SOC 的资源。[第 1 章](#ch01.xhtml#ch01) 从所有高层 SOC 概念的总体概览开始。[第 2 章](#ch02.xhtml#ch02) 重点介绍如何建设 SOC，包括将 SOC 与业务对齐、使命宣言、范围，以及在规划 SOC 时应考虑的一切事项。

[第 3 章](#ch03.xhtml#ch03) 介绍了我在全球成熟 SOC 中发现的基本 SOC 服务。我在后续章节中逐一讲解每项服务，包括如何应对风险、漏洞、合规，以及组织依赖 SOC 处理的其他挑战。[第 8 章](#ch08.xhtml#ch08) 为某些主题提供了不同的方法，例如何时启动应急响应与取证调查。[第 2 章](#ch02.xhtml#ch02) 和 [第 11 章](#ch11.xhtml#ch11) 涵盖了当今常见的技术以及未来感十足但最终将成为普通 SOC 一部分的技术。一个例子是云技术（如安全访问服务边界 [SASE]）最终将像大多数企业中的 IP 语音 (VoIP) 一样普及。

全书中，我包含了红队和蓝队使用的工具和技术示例，这意味着我既展示了如何执行真实世界的利用，也展示了全球 SOC 如何防御现代攻击。许多工具是开源的，包括使用 Kali Linux 进行利用、使用 Ansible 进行自动化，以及使用 NIST 发布物（以及其他）作为指南。当主题需要引用企业级工具时，我会尝试在不同厂商之间切换，让你大致了解能力，而不是特定厂商工具的具体功能。我的目标是保持一种与厂商无关的安全方法，这也是我包含许多不同厂商示例和开源选项的原因。

[第 11 章](#ch11.xhtml#ch11) 通过对 SOC 未来的预测来结束全书。我的预测基于行业趋势、与客户的交流以及我在该行业 20 多年的个人经验。我相信本书中的许多主题是基本安全概念，将在本书出版后的许多年里依然适用。我写这本书是为了让你做好准备应对未来的威胁，无论它们是什么样子。我相信每个组织都能从本书中受益，并希望它能帮助你在建设和运营成功的安全运营中心的旅程中取得进展。

## 书籍结构

我将本书从一般 SOC 概念组织到详细 SOC 服务。以下是每章的简要总结及其与建设和维护成熟 SOC 的关系。

*   **[第 1 章](#ch01.xhtml#ch01)，“[安全运营与 SOC 简介](#ch01.xhtml#ch01)：** 本章介绍高层 SOC 概念。我提供了方法让你验证当前拥有哪些能力，以及如何评估现有流程，以便规划可以在哪些方面改进你的 SOC（如果已存在）。本章旨在作为后续章节的入门指引，并帮助你确定当前的安全状态，以便利用本书发展成熟的 SOC。

*   **[第 2 章](#ch02.xhtml#ch02)，“[开发安全运营中心](#ch02.xhtml#ch02)：** [第 2 章](#ch02.xhtml#ch02) 重点介绍在 SOC 能够提供服务之前必须到位的基本业务和运营需求。主题包括谁应该赞助、管理和支持 SOC，需要制定哪些类型的政策和程序，以及 SOC 正式上线前必不可少的其他业务目标。本章后半部分侧重于运营需求，例如如何规划 SOC 工作空间、如何容纳不同职责的 SOC 团队成员，以及根据 SOC 计划提供的服务需要考虑哪些类型的技术。解决本章中的主题是在 SOC 能够为组织提供任何价值之前的必要步骤。

*   **[第 3 章](#ch03.xhtml#ch03)，“[SOC 服务](#ch03.xhtml#ch03)：** 本章介绍了本书后续章节深入探讨的许多主题。我介绍了全球组织通用的基本 SOC 服务。我涵盖了这些服务如何由 SOC 提供，以及当你着手建立新的 SOC 服务时需要考虑的一切。这包括何时应该外包服务，以及何时利用内部能力开发服务更合理。[第 3 章](#ch03.xhtml#ch03) 代表了 SOC 进入上线状态并开始为组织提供价值的节点。

*   **[第 4 章](#ch04.xhtml#ch04)，“[人员与流程](#ch04.xhtml#ch04)：** 每项 SOC 服务都需要合适的人员和流程才能成功。本章介绍了全球成熟 SOC 中常见的所有不同工作角色。它描述了每个角色的技能要求以及日常职责的期望。我涵盖了如何为你的 SOC 找到合适的人员，并通过直接关联 SOC 服务成功的不同项目来培养他们。主题包括工作角色、招聘、面试、入职，以及人员和流程的外包。

*   **[第 5 章](#ch05.xhtml#ch05)，“[数据集中化](#ch05.xhtml#ch05)：** 一项基本的 SOC 能力是能够处理组织内部数据和外部安全数据（如威胁情报）。许多新 SOC 最初提供日志管理和分析服务。这意味着 SOC 负责从各种工具收集日志、分析日志，并在识别出特定事件时提供响应。数据集中化并非易事，因为数据有多种格式，而数据的更高级用例需要不同类型的编程和自动化技能。我涵盖了与如何收集和使用数据相关的所有内容，这是全球成熟 SOC 提供的许多其他服务的关键垫脚石。
