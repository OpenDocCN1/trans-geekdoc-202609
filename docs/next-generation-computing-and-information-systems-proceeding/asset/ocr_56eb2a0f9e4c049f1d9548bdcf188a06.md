# 5 CONCLUSION AND FUTURE SCOPE

In this study, we employ the CNN deep learning model to classify emotions based on EEG signals from 32 subjects in a public dataset. This paper makes use of a public dataset known as DEAP. An architecture model for a convolutional neural network with 80-20 train test ratio yields the greatest accuracy of 88.33% and with 75-25 train test ratio gives an accuracy of 88.12% on liking emotion. The model does rather well in generalizing findings for both splits, therefore the change in the train-test split little affects it.
