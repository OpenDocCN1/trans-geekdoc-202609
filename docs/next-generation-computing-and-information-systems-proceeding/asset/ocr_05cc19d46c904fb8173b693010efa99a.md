# 6 CONCLUSION

In this research, a combinational kernel SVM of linear and quadratic kernel uses brain images for the prediction of dyslexia in distributed environment. Apache Spark MILib is implemented which is a distributed approach that provides support for big data and overcomes big data processing and execution concerns. As a future advancement, the proposed model can be further improved to predict dyslexia better by considering a greater number of input parameters.
