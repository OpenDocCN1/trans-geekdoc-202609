# Table 1. Evaluation metrics.

| Metric | Formula |
| :--- | :--- |
| Mean Absolute Error (MAE) | \(\frac{1}{n} \sum_{i=1}^n |Y_i - \hat{Y}_i|\) |
| Mean Squared Error (MSE) | \(\frac{1}{n} \sum_{i=1}^n \left( Y_i - \hat{Y}_i \right)^2\) |
| Mean Absolute Percentage Error (MAPE) | \(\frac{1}{n} \sum_{i=1}^n \left| \frac{Y_i - \hat{Y}_i}{Y_i} \right| \times 100\) |
| Root Mean Squared Error (RMSE) | \(\sqrt{\frac{1}{n} \sum_{i=1}^n \left( Y_i - \hat{Y}_i \right)^2}\) |
| Variance | \(\frac{1}{n} \sum_{i=1}^n \left( Y_i - \bar{Y} \right)^2\) |
