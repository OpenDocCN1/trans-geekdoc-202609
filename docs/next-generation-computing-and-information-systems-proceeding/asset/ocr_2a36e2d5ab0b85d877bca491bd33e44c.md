# 4.3 Training setup

A non-linear CNN has used to train the model. All the dataset has captures with a commonly co-related features having minimum 8 common features. All the images are corrupted with a 0dB noise insertion technique to create a noisy training module. Initially we have selected the 256 samples to verify the level of the selected dataset for the selected model CNN and DNN. The samples are almost 56% overlapped (shown in the Figure 2).
