# 3.2 Phase two: Phase of the notification

When an accident is detected, effective communication and dispatch are vital. The system locates an accident using the smartphone’s GPS when it is spotted. The cloud has a hospital database and employs a mapping tool to locate the closest hospital. A message containing the location’s data and owner information is sent to the hospital. The obtained data is saved in the current database.
