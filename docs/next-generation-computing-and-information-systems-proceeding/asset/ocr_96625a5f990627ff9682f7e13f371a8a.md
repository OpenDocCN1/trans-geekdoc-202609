+   1) Divide the image into three layers, R, G, and B, convert them into three single-channel images, and divide them into multiple image squares of equal size and non-overlapping.
+   2) Calculate the grayscale histogram of each image square:

```
AVG(M) = \frac{M_x - M_y}{M_g} (5)
```

Among them, AVG(N) represents the average number of pixels of the grey level, M_x and M_y represent the number of pixels in the X-axis and Y-axis directions, respectively, and M_g is the number of grey levels in the image block.

+   3) Set a clipping coefficient O of the number of grey-scale pixels, and calculate the clipping threshold O_k
+   4) Equalize the histogram of each image square.
