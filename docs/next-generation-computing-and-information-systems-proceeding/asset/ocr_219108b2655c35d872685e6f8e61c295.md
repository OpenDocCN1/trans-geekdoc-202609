# 4.3 Pooling layer

Pooling layers come after convolutional layers. All four models use max-pooling layers as their type of pooling layer. The 2 × 2 max-pooling layer chooses the highest pixel intensity values from the image window the kernel currently covers. Images are down-sampled using max-pooling, which lowers the dimensionality and complexity of the image.
