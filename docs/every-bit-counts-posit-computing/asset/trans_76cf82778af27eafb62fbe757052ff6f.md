## 3.1 增加普适数动态范围

从一个3位普适数环开始，但让制度位表示4的幂（即2² = 4），而不是2的幂。这使动态范围翻倍：

![将西北角的值平方（并调整反射值）可使动态范围翻倍。](images/pg41_2.jpg)

将西北角的值平方（并调整反射值）可使动态范围翻倍。

这还为追加位时插入值创建了一条新规则。像往常一样，追加 `0` 位不会改变值；但当我们追加 `1` 位时，现在可以在值之间插入一个2的整数幂。

![在指数相差超过1的2的幂之间，插入几何平均数。](images/pg42_1.jpg)

在指数相差超过1的2的幂之间，插入几何平均数。

当在位终止位后追加一位时，我们称之为 `exponent bit`（指数位），并用 `blue`（蓝色）标记。如果是 `1` 位，两侧的值为 `2^k` 和 `2^m`，插入的值为 `2^((k+m)/2)`。制度位现在充当一种超级指数，它们表示的值是4的幂缩放，而不是2的幂。指数位随后让我们填补1和4之间、或1/4和1之间的空隙。为了更清晰，我们可以再追加一位，使得分数位出现在1/4到3的量级上（像往常一样用 `black` 显示）。指数位让我们用 4² · 2¹ = 8 填补 4 和 4² = 16 之间的空隙。2的整数幂仍然有完美的倒数，它们是关于水平轴的镜像。到补码整数的映射仍然是单调的，如这个环图所示：

![带1个指数位的5位普适数环图](images/pg42_2.jpg)

带1个指数位的5位普适数环图

假设我们想要更大的动态范围。我们可以再次将每个制度位的含义平方，变为 4² = 16，这样东北位置的值就是 16。填补 16⁰ = 1 和 16¹ = 16 之间意味着按 1、2、4 或 8 缩放，即 `2^e`，其中 `e` 从 0 到 3。作为无符号二进制，我们可以用指数位 `00`、`01`、`10` 和 `11` 来实现。这是一个带2位指数字段的5位普适数的环图：

![带2个指数位的5位普适数环图](images/pg43_1.jpg)

带2个指数位的5位普适数环图

指数字段的位数是 `eS`，是 `exponentSize` 的简短驼峰命名法。东北位置的值称为 `uSeed`，等于 `2^(2*eS)`。每当 `eS` 增加 1，`uSeed` 就平方，动态范围翻倍，代价是从小数部分的有效位中拿走一位。随着 `eS` 从 0 开始递增，`uSeed` 为 2、4、16、256、65 536……这是一个*非常*快速增长的序列。使用时要小心。

[第1章](#chapter1.xhtml) 介绍了没有指数位（`eS` = 0）的最简单普适数形式，但通过引入指数位，我们获得了强大得多的能力。以下是随着精度 `n` 增长，在普适数环上引入新值的完整规则：

*   向现有普适数追加 `0` 位不会改变其表示的值。
*   在 `NaR` 和一个实数之间，插入该实数乘以 `uSeed`。
*   在 0 和一个实数之间，插入该实数除以 `uSeed`。
*   在 `2^k` 和 `2^m` 之间（其中 `k` 和 `m` 相差超过 1），插入 `2^((k+m)/2)`。
*   否则，在 `x` 和 `y` 之间，插入它们的平均值 `(x + y)/2`。
