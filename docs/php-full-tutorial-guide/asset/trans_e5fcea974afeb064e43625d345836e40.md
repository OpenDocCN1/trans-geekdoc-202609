

# 整数

- 整数必须至少有一个数字 (`0-9`)
- 整数不能包含逗号或空格
- 整数不能有小数点
- 整数可以是正数或负数
- 整数可以用三种格式指定：十进制 (`10`-based)、十六进制 (`16`-based - 前缀为 `0x`) 或八进制 (`8`-based - 前缀为 `0`)

在以下示例中，我们将测试不同的数字。PHP `var_dump()` 函数返回变量的数据类型和值：

Example

```php
<?php 

$x = 5985; 

var_dump($x); 

echo "<br>"; 

$x = -345; // negative number 

var_dump($x); 

echo "<br>"; 

$x = 0x8C; // hexadecimal number 

var_dump($x); 

echo "<br>"; 

$x = 047; // octal number 

var_dump($x); 

?> 
```

## PHP 算术运算符

1. 加法或求和 (`+`)

`$x + $y`

`$x` 和 `$y` 的和

2. 减法 (`-`)

`$x - $y`

`$x` 和 `$y` 的差

3. 乘法 (`*`)

`$x * $y`

`$x` 和 `$y` 的积

4. 除法 (`/`)

`$x / $y`

`$x` 和 `$y` 的商

5. 取模 (`%`)

`$x % $y`

`$x` 除以 `$y` 的余数

下面的示例展示了使用不同算术运算符的不同结果：

Example

```php
<?php 

$x=5; 

$y=3; 

echo ($x + $y); // outputs 8

echo ($x - $y); // outputs 2 

echo ($x * $y); // outputs 15 

echo ($x / $y); // outputs 1.6666666666667 

echo ($x % $y); // outputs 2 

?> 
```

## PHP 赋值运算符

PHP 赋值运算符用于将值写入变量。

`x = y` 和是与 `x = y` 相同

`x += y`

`x -= y`

`x = x - y`

3. 乘法

`x *= y`

`x = x * y`

4. 除法

`x /= y`

`x = x / y`

5. 取模

`x %= y`

`x = x % y`

下面的示例展示了使用不同赋值运算符的不同结果：

Example

```php
<?php 

$x=10;

echo $y; // outputs 20

echo $z; // outputs 15

echo $i; // outputs 45

echo $j; // outputs 2
```

## PHP 比较运算符

PHP 比较运算符用于比较两个值（数字或字符串）：

1. 等于 (`==`)

`$x == $y`

如果 `$x` 等于 `$y`，则为真

2. 全等 (`===`)

`$x === $y`

如果 `$x` 等于 `$y`，并且它们的类型相同，则为真

3. 不等于 (`!=`)

`$x != $y`

如果 `$x` 不等于 `$y`，则为真

4. 不等于 (`<>`)

`$x <> $y`

如果 `$x` 不等于 `$y`，则为真

5. 不全等 (`!==`)

`$x !== $y`

如果 `$x` 不等于 `$y`，或者它们的类型不同，则为真

6. 大于 (`>`)

`$x > $y`

如果 `$x` 大于 `$y`，则为真

7. 小于 (`<`)

`$x < $y`

如果 `$x` 小于 `$y`，则为真

8. 大于或等于 (`>=`)

`$x >= $y`

如果 `$x` 大于或等于 `$y`，则为真

9. 小于或等于 (`<=`)

`$x <= $y`

如果 `$x` 小于或等于 `$y`，则为真

下面的示例展示了使用一些比较运算符的不同结果：

Example

```php
<?php 

$x=100; 

$y="100"; 

var_dump($x == $y); 

echo "<br>"; 

var_dump($x === $y); 

echo "<br>"; 

var_dump($x != $y); 

echo "<br>"; 

var_dump($x !== $y); 

echo "<br>"; 

$a=50; 

$b=90; 

var_dump($a > $b); 

echo "<br>"; 

var_dump($a < $b); 

?> 
```

## PHP 数组运算符

PHP 数组运算符用于比较数组：

1. 并集 (`+`)

`$x + $y`

`$x` 和 `$y` 的并集（但重复的键不会被覆盖）

2. 相等 (`==`)

`$x == $y`

如果 `$x` 和 `$y` 具有相同的键/值对，则为真

3. 全等 (`===`)

`$x === $y`

如果 `$x` 和 `$y` 具有相同的键/值对，顺序相同且类型相同，则为真

4. 不相等 (`!=`)

`$x != $y`

如果 `$x` 不等于 `$y`，则为真

5. 不相等 (`<>`)

`$x <> $y`

如果 `$x` 不等于 `$y`，则为真

6. 不全等 (`!==`)

`$x !== $y`

如果 `$x` 不全等于 `$y`，则为真

下面的示例展示了使用不同数组运算符的不同结果：

Example

```php
<?php 

$x = array("a" => "red", "b" => "green"); 

$y = array("c" => "blue", "d" => "yellow"); 

$z = $x + $y; // union of $x and $y 

var_dump($z); 

var_dump($x == $y); 

var_dump($x === $y); 

var_dump($x != $y); 

var_dump($x <> $y); 

var_dump($x !== $y);

```

## If 语句

PHP if 语句与其他编程语言中 if 语句的用法非常相似，请查看以下内容：

这种简单的 if/then 语句在日常生活中非常常见，在编程中也经常出现。每当你想要在某件事情为真时做出决定，并确保采取适当的行动时，你都在使用 if/then 关系。

example

`$my_name = "william";`

`if ( $my_name == "william" ) {`

`echo "Your name is william!<br />";`

`}`

Display:

Your name is william!

explanation

你是否明白我们是在将变量 `$my_name` 与 `"william"` 进行比较，看它们是否相等？在 PHP 中，你使用双等号 (`==`) 来比较值。此外，请注意，因为 if 语句结果为真，所以执行了代码段，打印出 "Your name is william!"。让我们深入了解一下细节

• 我们首先将变量 `$my_name` 设置为 `"william"`。
