MST then dips into the upper reaches of Jacobs Run, crosses Oregon Hill and descends into Browns Fork. From there swings east and picks up a management road in the Trout Run tract of SGL 75. After crossing Trout Run the MST heads up Hoyt Hoyt Hollow and then turns upstream along Big Run to Brill Hollow. After traversing Gillespie Point it descends to PA 414 in Blackwell.
