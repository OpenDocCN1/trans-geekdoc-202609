# NOTICE TO ALL TRAIL USERS

Every effort has been made by the Mid State Trail Association to provide the most accurate and up-to-date information about the Mid State Trail in this publication. However, conditions on the trail are constantly changing. Acts of nature, forestry practices, and human developments are only a small number of events that necessitate the rerouting of the Mid State Trail. Changes to the route described within this publication can and will occur over time and, therefore, no published route can be regarded as precisely accurate at the time you read this notice. Hikers using this publication should do so at their own risk and the use of this publication should be in conjunction with current maps, as well as a compass or GPS, and with common sense precautions. Always tell someone of your hiking plans. Visit the Mid State Trail website (http://www.hike-mst.org) for the most recent information regarding trail reroutes.
