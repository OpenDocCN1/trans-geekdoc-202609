1.80 Junction with blue blazed Axe Handle Trail that leads 200 m to Detweiler Road. 14.61

NB: Ahead the MST crosses Detweiler Run on a footbridge. Next it avoids repeated crossings of Detweiler Run by turning right on new trail. There is a spring and a small campsite where the trail returns to the Reichley Bros. railroad grade.

SB: Reach end of Reichley Bros logging RR grade. Note the cinders in the footway. Trail cuts through a corner of Detweiler Natural Area with old growth hemlocks and white pines. Do not camp in Detweiler Natural Area. Trail climbs side of valley before returning to Detweiler Run where it picks up Monroe Kulp's old logging RR grade.

2.79 Cross Texas Eastern pipeline clearing. 13.62

NB: Ahead the MST avoids two more crossings of Detweiler Run by an excursion up the right bank. Note the large tulip tree growing in the old RR grade just before the Reichley Trail.

SB: Next MST avoids repeated crossings of Detweiler Run by turning left on new trail. There is a spring and a small campsite where the trail leaves Reichley Bros. railroad grade. Ahead MST crosses Detweiler Run on footbridge.

NB=North bound hiking, SB=South bound hiking
