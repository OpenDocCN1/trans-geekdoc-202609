## SECTION D: BOHEN RUN TRAIL BLACKWELL TO WEST RIM TRAIL TIOGA STATE FOREST

The yellow-blazed Bohen Run Trail starts on PA 414 just across the bridge from Blackwell canoe access area and ends at the junction with the West Rim Trail on Bohen Run approximately 2.48 km from West Rim Road. A map and guide set for the West Rim Trail are available from a number of outfitters and various websites. There is no intermediate access but there is primitive camping at the mouth of Bohen Run. This section has a number of waterfalls and was opened on Memorial Day weekend 1986.

### GENERAL DESCRIPTION

From the Mid State Trail in Blackwell, cross Pine Creek on the PA 414 bridge to reach the southern terminus of the Bohen Trail. The trail follows Pine Creek upstream on the west side of the creek. It passes above the waterfall on Jerry Run then follows an old road along Bohen Run past a larger waterfall. Farther up Bohen Run it joins the West Rim Trail.

## SECTION E: JACKSON TRAIL PENNSYLVANIA ROUTE 26 TO MID STATE TRAIL ROTHROCK STATE FOREST

The Jackson Trail provides a scenic shortcut for hikers who do not need water or a place to camp. The Jackson Trail is very rocky as it follows the crest of Tussey Ridge from the Jo Hays Vista on PA 26, 3.2 km above Pine Grove Mills, to where the Mid State Trail climbs back out of Shaver Creek Valley. There is no intermediate access and there are no springs or streams. The Jackson Trail was opened in 1979

### GENERAL DESCRIPTION

The Jackson Trial follows the crest of Tussey Ridge northeast from Pennsylvania route 26 to a junction with the main trail. There are few changes in elevation but the footway is frequently very rocky. There are many views to both sides of the ridge, but no springs or streams. Take your time and stop to enjoy the views.
