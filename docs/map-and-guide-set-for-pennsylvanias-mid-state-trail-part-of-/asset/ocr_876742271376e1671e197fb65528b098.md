# INTRODUCTION

The Mid State Trail (MST) is an old fashioned wilderness foot path across Pennsylvania from Bedford County in the south to Tioga County. Features of the MST are its many views and side trails, its sense of isolation and remoteness, and its use of metric measure. Unique features are the tunnel under Paddy Mountain and a portion of the Greatland Indian Path near Ravensburg State Park. The latter is believed to be one of two or three bits of unaved Indian paths on public lands in Penn Woods. The Burnt Cabins to Franktown Path is crossed in SGL 118.

The Mid State Trail Association (MSTA) is an organization of trail overseers and others formed in 1982 and dedicated to the completion, maintenance, and preservation of the Mid State Trail System.

Most of the Mid State Trail is on public lands including State Forests, State Game Lands and State Parks. The MST links or traverses state game lands, two scout camps, four state wild areas, three state forest picnic areas, five state forests, eight state parks, ten state forest natural areas, the Woolrich factory outlet store and a token roadside rest. On State Game Lands, all users of the trail should be aware of the Game Lands regulations posted at each Game Landing area and on www.pgc.state.pa.us. All non-hunters must wear fluorescent orange between November 15th and December 15th. Wearing orange is strongly recommended from Columbus Day weekend to the end of the year, and especially during spring gobbler season from the last weekend of April through the week before Memorial Day.
