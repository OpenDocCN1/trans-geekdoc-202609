# # SECTION D: BOHEN RUN TRAIL
BLACKWELL TO WEST RIM TRAIL
TIOGA STATE FOREST

The yellow-blazed Bohen Run Trail starts on PA 414 just across the bridge from the town of Blackwell and canoe access area and ends at the junction with the West Rim Trail on Bohen Run approximately 2.48 km from the West Rim Road. A map and guide set for the West Rim Trail are available from a number of outfitters and from various websites online. There is no intermediate access but there is primitive camping at the mouth of Bohen Run. This section has a number of waterfalls and was opened on Memorial Day weekend in 1986.

# GENERAL DESCRIPTION

From the Mid State Trail in Blackwell, cross Pine Creek on the PA 414 bridge to reach the southern terminus of the Bohen Run Trail. The trail follows Pine Creek upstream on the west side of the creek. It passes above the waterfall on Jerry Run and then follows an old road along Bohen Run past a larger waterfall. Farther up Bohen Run it joins the West Rim Trail.
