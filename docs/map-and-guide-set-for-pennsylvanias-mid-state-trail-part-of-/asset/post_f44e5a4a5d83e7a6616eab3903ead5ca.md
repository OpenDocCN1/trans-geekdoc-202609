# SECTION C: REEDS GAP SPUR
REEDS GAP STATE PARK TOE PADDY PARK
BALD EAGLE FOREST

The Reeds Gap Spur starts at Reeds Gap and ends at a junction with Mid State Trail. Poe Paddy State Park is located at New Lancaster Valley east of 322. Rocky State Park is located at the junction of Big Gap and Bald Eagle Forest. The Reeds Gap Spur was opened in 1985 and is shown on Map 307-310. overnight instructions.

# GENERAL DESCRIPTION

From Reeds Gap Park the spur climbs through the same name to the top of Thick Mountain. It follows Thick Mountain east and descends into Treaster Valley by way of Bear Trail. Treaster Mountain. Continuing it climbs over Strong Mountain descends to Weik Run and then ascends White Mountain along the wild area boundary. Next to descends to a crossing of Swift Run and follows Swift Run Road to Poe State Park.
