# ELEVATION PROFILES

This edition of the trail guide is the first to include elevation profiles for each section of the trail. These profiles are displayed in a horizontal orientation on the the page immediately following the general description of the section. Using these profiles will help in visualizing the difficulty of hiking this particular section of the trail by visually representing the elevation changes found along the trail. The vertical exaggeration for these profiles is 5:1. This means that for every meter plotted on the x-axis (distance), a corresponding meter on the y-axis (elevation) is plotted at five meters. This vertical exaggeration is constant on all elevation profiles for each section.

One additional note regarding the elevation profiles: you may notice a discrepancy between the distances displayed on the elevation profiles versus listed in the guide text. The distances on the elevation profiles will seem to be shorter. This is because the elevation profiles are generated from GPS data whereas the guide text indicate the distance measured on the trail using a surveyor's wheel. Distances calculated using a GPS are typically shorter because they do not take into account changes in elevation and also because of the interpretation that place between data points.
