
正如表格所示，这在研究论文中可能会这样表述：“实验揭示了图标类型对任务完成时间有显著影响（*F*[1, 9] = 33.36，*p* < .0005）。”

### 6.2.8 检验组间效应

正如上一章所述，如果因子采用组内设计，则使用平衡法来抵消顺序效应。对于具有两个水平（A、B）的单一因子，参与者被分成两个等量的组。一组（G1）先测试A后测试B，另一组（G2）先测试B后测试A。目的是平衡或抵消可能出现的练习或疲劳效应。如果平衡法奏效，则不应存在组间效应——即G1和G2之间没有显著差异。这听起来很简单，但如何验证平衡法是否奏效呢？通过将“组”视为组间因子来检验组间效应。当然，“组”并非研究课题意义上的因子。尽管如此，数据仍可按组作为组间因子进行组织，方差分析（ANOVA）可检验*组间效应*——即组别对因变量的主效应。

让我们通过修改上一节的图标设计示例来探讨这一点。由于设计采用组内设计，因此很可能使用了平衡法来抵消练习效应。有10名参与者和两个条件，因此需要两组，每组5名参与者。一组先测试自然图标后测试抽象图标（NA）。另一组则按相反顺序接受条件（AN）。

修改后的数据位于`dix-example-h10x2b.txt`中，如[图6.19](#Chp006_243-291_B9780443140969000129.xhtml#f0100)所示。组别代码（NA、AN）作为单独的一列名义数据添加。同时也添加了表头行，以简化方差分析操作并提高ANOVA表的可读性。有关完整详情，请参阅`GoStats`中的ANOVA API。

![Figure 6.19 Contents of the file dix-example-h10x2b.txt. The data are for the icon recognition experiment modified to illustrate counterbalancing and the use of header lines with GoStats.](images/B9780443140969000129/gr019.jpg)

图6.19 `dix-example-h10x2b.txt`文件的内容。数据用于图标识别实验，经过修改以演示平衡法以及在`GoStats`中使用表头行。

添加组别代码后，实验现在成为一个2×2设计，包含一个组内因子（“图标类型”，水平为自然和抽象）和一个组间因子（“组别”，水平为NA和AN）。只需打开数据文件并点击“Analyse（分析）”即可执行ANOVA。见[图6.20](#Chp006_243-291_B9780443140969000129.xhtml#f0105)。由于文件包含表头行，因此无需提供额外信息。

![Figure 6.20 ANOVA for data in Fig. 6.19.](images/B9780443140969000129/gr020.jpg)

图6.20 图6.19数据的ANOVA。

组间效应显示在[图6.20](#Chp006_243-291_B9780443140969000129.xhtml#f0105)的顶行，不显著（*F*[1, 8] = 0.466，ns）。这是个好消息。不显著的组间效应意味着平衡法奏效了。发生的任何学习效应都被平衡抵消了。实验的主要结果保持不变，尽管由于计算方差时数据划分方式的改变，*F*值和*p*值略有不同。结果仍然显示图标类型对任务完成时间有显著影响（*F*[1, 8] = 30.68，*p* < .001）。

[图6.20](#Chp006_243-291_B9780443140969000129.xhtml#f0105)中还有一个第三效应。这是图标类型与组别之间的双向交互效应。正如ANOVA表所示，该效应不显著（*F*[1, 8] = 0.277，ns）。如果该效应显著，则代表一种称为*非对称技能迁移* [\[406\]](#Chp006_243-291_B9780443140969000129.xhtml#br2030)的现象，意味着存在学习效应，且从A过渡到N的效应与从N过渡到A的效应不同（另见第[5](#Chp005_203-242_B9780443140969000117.xhtml)章，第[5.12](#Chp005_203-242_B9780443140969000117.xhtml)节，第233页）。

在许多研究实验中，组内因子使用平衡法，但并不实际检验组间效应。这主要取决于选择。

## 6.3 卡方检验

用于研究关系的常见统计程序是卡方检验，也称为皮尔逊卡方检验，有时用“squared”代替“square”。发音为*kī*（与*sky*押韵）。这些关系存在于分类变量或名义尺度变量之间，这些变量代表人的属性、交互方法、系统等。数据通常汇总在*列联表*中——一种交叉分类表，将数据按行和列组织，每个单元格包含一个计数，即该类别中的观测数量。卡方检验将观测值——表中的计数——与期望值进行比较。期望值是在假设表中各类别无差异的前提下得出的。卡方检验是一种非参数检验，因为类别是名义尺度属性，没有与之相关的概率分布。一个假设例子将对此进行说明。
