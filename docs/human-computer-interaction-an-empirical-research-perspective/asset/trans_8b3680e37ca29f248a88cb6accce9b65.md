
使用精度调整进行计算，`TP` 是一种人类绩效度量，它同时包含了响应的速度和准确性。因此，`TP` 比单独的速度或准确性是一种更稳定的度量 [\[167\]](#Chp007_293-360_B9780443140969000130.xhtml#br0835)、[\[312\]](#Chp007_293-360_B9780443140969000130.xhtml#br1560)、[\[546\]](#Chp007_293-360_B9780443140969000130.xhtml#br2730)。[图 7.19](#Chp007_293-360_B9780443140969000130.xhtml#f0100) 展示了公式 [(7.7)](#Chp007_293-360_B9780443140969000130.xhtml#deq7) 的扩展版本，显示了与参与者响应速度和准确性的联系。

![Figure 7.19 Throughput equation showing speed and accuracy.](images/B9780443140969000130/gr019.jpg)

[图 7.19](#Chp007_293-360_B9780443140969000130.xhtml#cf0690) 显示速度和准确性的吞吐量公式。

吞吐量作为因变量，在以指向设备或指向技术作为自变量的因子实验中最为有用。

如果目标是使用菲茨定律作为预测模型，则完成任务的运动时间（`MT`）可使用一个简单的线性方程进行预测：^([^(134)](#fn134))

```
MT = a + b × ID
```
(7.10)

预测方程中的斜率和截距系数通过经验测试确定，通常使用线性回归。测试在受控实验中进行，使用一组参与者和一种或多种输入设备及任务条件。

### 7.2.2.2 示例

在本节中，我们演示如何使用一项比较两种指向设备实验的部分数据 [\[313\]](#Chp007_293-360_B9780443140969000130.xhtml#br1565) 来构建菲茨定律预测模型。其中一种设备是 Interlink Electronics RemotePoint。RemotePoint 是一种在空中操作的无线指向设备，例如在使用大型交互式垂直显示器进行演示时。光标位置由拇指操作的等距操纵杆控制。选择使用由食指操作的扳机式开关。参见 [图 7.20](#Chp007_293-360_B9780443140969000130.xhtml#f0105)a。Microsoft Mouse 2.0 作为基线条件。十二名参与者跨九种目标条件执行了一系列相互指向-选择任务：`A` = 40, 80, 160 像素与 `W` = 10, 20, 40 像素交叉。使用公式 [(7.6)](#Chp007_293-360_B9780443140969000130.xhtml#deq6)，目标条件跨越的难度范围从

```
ID = log₂(40/40 + 1) = 1.00 bits
```
(7.11)

到

```
ID = log₂(160/10 + 1) = 4.09 bits.
```
(7.12)

参见 [图 7.20](#Chp007_293-360_B9780443140969000130.xhtml#f0105)b。

![Figure 7.20 Fitts' law example. (a) RemotePoint pointing device. (b) Experiment task.](images/B9780443140969000130/gr020.jpg)

图 7.20 菲茨定律示例。(a) RemotePoint 指向设备。(b) 实验任务。

[图 7.21](#Chp007_293-360_B9780443140969000130.xhtml#f0110) 给出了鼠标和 RemotePoint 条件的数据。共有九行，每行对应一种 `A`-`W` 目标条件。左侧三列是目标条件（`A`、`W` 和计算出的任务难度指数 `ID`）。其余列是参与者的响应。`W`[e] 是有效目标宽度（公式 [(7.8)](#Chp007_293-360_B9780443140969000130.xhtml#deq8)）。`ID`[e] 是有效难度指数（公式 [(7.9)](#Chp007_293-360_B9780443140969000130.xhtml#deq9)）。`MT` 是以毫秒为单位的平均运动时间。`TP` 是以 bits/s 为单位的吞吐量（公式 [(7.7)](#Chp007_293-360_B9780443140969000130.xhtml#deq7)）。

![Figure 7.21 Experiment conditions (A, W, ID) and participant responses (We, IDe, MT, TP) for the standard mouse and the RemotePoint.](images/B9780443140969000130/gr021.jpg)

图 7.21 标准鼠标和 RemotePoint 的实验条件（`A`、`W`、`ID`）和参与者响应（`W`[e]、`ID`[e]、`MT`、`TP`）。

可以为 [图 7.21](#Chp007_293-360_B9780443140969000130.xhtml#f0110) 中的两种设备条件构建菲茨定律模型。预测方程使用 `MT` 作为因变量，使用 `ID` 或 `ID`[e] 作为预测变量。使用 `ID`[e] 的优势在于模型同时包含了响应的速度和准确性，因此能更准确地反映参与者行为。

构建和演示模型最简单的方法是使用电子表格应用程序。[图 7.22](#Chp007_293-360_B9780443140969000130.xhtml#f0115) 以散点图形式提供了每种设备数据的可视化。图表还包括回归线、预测方程和 `R`²。两个 `R`² 值都非常高。例如，鼠标模型解释了观测值中 97% 的方差。

![Figure 7.22 Scatter plot and regression lines for data in Fig. 7.21 (adapted from [313]).](images/B9780443140969000130/gr022.jpg)

图 7.22 图 7.21 数据的散点图和回归线（改编自 [\[313\]](#Chp007_293-360_B9780443140969000130.xhtml#br1565)）。

[图 7.22](#Chp007_293-360_B9780443140969000130.xhtml#f0115) 中预测方程的格式可以改进。对于 RemotePoint，将光标移动距离 `A` 以选择宽度为 `W` 的目标的预测时间为

```
MT = 597 + 408 × log₂(A/W + 1) ms.
```
(7.13)

对于鼠标，预测方程为

```
MT = 159 + 204 × log₂(A/W + 1) ms.
```
(7.14)

[图 7.22](#Chp007_293-360_B9780443140969000130.xhtml#f0115) 中的菲茨定律模型揭示了什么见解？最初的观察是，两种设备的指向-选择操作都符合菲茨定律，这从 `R`² 的高值中可见一斑。这是前文提到的菲茨定律的第一种用途。此外，显而易见的是，与鼠标相比，RemotePoint 表现不佳。对于所有目标条件，RemotePoint 的运动时间都要长得多。回归线的斜率表明 RemotePoint 的信息处理速率要低得多。斜率的单位是 ms/bit。斜率的倒数（换算为秒后）的单位是 bits/s。因此，较低的斜率意味着较高的信息处理速率（吞吐量）。鼠标显然是更好的设备。^([^(135)](#fn135))

关于吞吐量的计算方法也存在一些争议。例如，使用均值相除法（[图 7.21](#Chp007_293-360_B9780443140969000130.xhtml#f0110)），鼠标的吞吐量为 3.60 bits/s；而使用回归方程中的斜率倒数（[图 7.22](#Chp007_293-360_B9780443140969000130.xhtml#f0115)），即 `1/204` = 4.90 bits/s。进一步讨论请参见 Soukoreff 和 MacKenzie [\[466\]](#Chp007_293-360_B9780443140969000130.xhtml#br2330) 或 Zhai 等人 [\[546\]](#Chp007_293-360_B9780443140969000130.xhtml#br2730)。

HCI 文献中有许多包含菲茨定律预测模型的散点图。[图 7.23](#Chp007_293-360_B9780443140969000130.xhtml#f0120) 总结了一些示例。尽管图中所有模型的 `R`² > .8，但斜率系数存在显著差异。这部分归因于收集数据和构建模型时使用了不同的方法论。因此，跨研究的菲茨定律研究比较往往很困难。
