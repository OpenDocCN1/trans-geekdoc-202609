
## 7.2.4.4 Other applications and extensions

The example above is a common task on today's GUI systems. Other tasks offer a great range of possibilities for keystroke-level modelling. Examples include scrolling a document with a mouse wheel, finger, or thumb input on a mobile phone (perhaps while walking), two-thumb input on a mini-Qwerty keyboard, or stylus input on a PDA. How are these tasks modelled with a keystroke-level model? Clearly, there are many issues to consider in contemporary applications of the KLM. Despite this – or should we say, motivated by this – researchers continue to use the KLM to model interactions in novel HCI contexts.
