# 第二版前言

Scott MacKenzie

自 2013 年本书第一版出版以来……天哪，从何说起！发生了太多事情。2019 冠状病毒病（Covid-19）于 2020 年爆发，气候灾难如今已成为日常新闻，到处都有战争、外国渎职行为和政治动荡。哎呀，说错书了。是的，世界变了。幸运的是，本书的关注点是一个更窄的世界：人机交互（HCI）。在 HCI 领域，变化是持续的、快速的且意料之中的。计算产品、界面和交互技术层出不穷。现代智能手机拥有多个摄像头，并包含日益增大的内存、更高分辨率的显示屏、不断扩展的算力、指纹和其他新型传感器等。用于虚拟现实（VR）的头戴式显示器（HMD）不再是小众产品。新型 HMD 成为许多用户玩游戏的首选，且通常内置眼动追踪功能。智能手表、Fitbits、佳明（Garmins）和 Strava 记录我们的每一步，计时、测量距离、绘制路线，并激励我们锻炼和分享成就。有款应用适合这里，有款设备适合那里。是的，有太多内容需要拆解。别忘了人工智能（AI）的主流崛起。本书的下一版可能就会有位新作者：Chat-某某某。

2019 冠状病毒病（Covid-19）大流行改变了我们生活的许多方面，包括计算机的使用方式。大流行带来了交互方式的转变，转向远程工作和在线社交。2020 年 2 月，我从未听说过 Zoom。快进几个月，Zoom 就成了我日常工作的一部分。远程社交成了我们所有人的新常态。我们现在正在回归疫情前的常态，但未来如何，谁也说不准。

值得注意的是，实证研究在人机交互中的作用，今天与本书第一版出版时一样。不同之处仅在于，今天有新的产品和理念激励并挑战着我们。通过实证和实验性研究探索新理念的价值依然存在。

第二版包含与第一版相同的八章，但出现了数十个新主题，并更新了现有的主题和示例。新增了 20 多道学生练习题。现在增加了实证研究中最常用术语的词汇表。第 [2](#Chp002_31-91_B9780443140969000087.xhtml) 章（人为因素）增加了对误差和异常值的严谨处理；第 [3](#Chp003_93-160_B9780443140969000099.xhtml) 章（交互元素）增加了额外的现代交互方法。第 [4](#Chp004_161-201_B9780443140969000105.xhtml) 章（科学基础）现在包含对研究本质及其与工程和设计关系的更深入分析。第 [5](#Chp005_203-242_B9780443140969000117.xhtml) 章（设计 HCI 实验）更全面地涵盖了伦理问题和问卷设计。第 [6](#Chp006_243-291_B9780443140969000129.xhtml) 章（假设检验）的一项变更是使用单一 GUI 工具来演示和实现 HCI 用户研究中最常用的假设检验统计程序。`GoStats` 是一个易于使用的单一 `.jar` 文件，可在任何能运行 Java 程序的计算机上运行。它可在本书网站上免费下载。还增加了一个额外程序：用于正态性检验的 Lilliefors 检验。第 [7](#Chp007_293-360_B9780443140969000130.xhtml) 章（交互建模）增加了使用自我评价人形量化评定的情感圆环模型。第 [8](#Chp008_361-390_B9780443140969000142.xhtml) 章（撰写和发表研究论文）通过引文和参考文献的新实践以及推广 Overleaf 等现代环境而与时俱进。

一个网站作为本书的补充，主要用于托管包含书中数据和分析的可下载文件：

[www.yorku.ca/mack/HCIbook2e](http://www.yorku.ca/mack/HCIbook2e)

本书网站上的下载内容包括第 [6](#Chp006_243-291_B9780443140969000129.xhtml) 章（假设检验）中所有统计检验的 SPSS、R、MATLAB 和 StatView 实现。对于每种应用程序，都有一个可下载的 ZIP 文件，包含必要的文件和一个 `readme.txt` 文件，说明如何在 SPSS、R、MATLAB 或 StatView 中进行分析。
