
# 纵向研究中的交叉点与成本效益分析

在许多情况下，纵向研究的目标是将新技术的可行性与当前实践进行比较。这里的“当前实践”是指任何可用性能指标量化的常规交互。示例包括文本输入、编辑、指向、选择、搜索、平移、缩放、旋转、绘图、滚动、菜单访问等。如果用户熟练掌握当前的交互技术，则预期他们在使用新技术时初期表现相对较差。但随着学习的进展，性能趋势最终可能会交叉，即新技术的性能超过当前实践。这在[图 5.20](#Chp005_203-242_B9780443140969000117.xhtml#f0105)中有所说明。

![Figure 5.20 Crossover point. With practice, human performance with a new interaction technique may exceed human performance using a current technique (from [333](#Chp005_203-242_B9780443140969000117.xhtml#br1665)).](images/B9780443140969000117/gr020.jpg)

[图 5.20](#Chp005_203-242_B9780443140969000117.xhtml#cf0615) 交叉点。随着练习，人类使用新交互技术的性能可能超过使用当前技术的性能（来源：[333](#Chp005_203-242_B9780443140969000117.xhtml#br1665)）。

无处不在的 Qwerty 键盘是一个绝佳的例子。尽管已知存在改进的设计，但熟练使用 Qwerty 键盘的用户不太可能立即展示出使用替代设计的性能提升。可能需要大量的练习，新键盘的性能才能超过 Qwerty 键盘。例如，Dvorak 简化键盘（DSK）已在纵向研究中被证明比 Qwerty 具有速度优势（详见[文献 377](#Chp005_203-242_B9780443140969000117.xhtml#br1885)的综述）。然而，Qwerty 仍然是计算机键盘的主流外形规格。从实际角度来看，学习新技术需要付出代价，因为初期当前技术的性能更优。然而，一旦达到交叉点，新技术便提供收益，因为其性能优于当前实践。这种成本效益权衡如[图 5.21](#Chp005_203-242_B9780443140969000117.xhtml#f0110)所示。

![Figure 5.21 Cost-benefit progression in learning a new interaction technique where there is existing skill with current practice.](images/B9780443140969000117/gr021.jpg)

图 5.21 在已掌握当前实践技能的情况下学习新交互技术的成本效益演进。

尽管[图 5.21](#Chp005_203-242_B9780443140969000117.xhtml#f0110)中显示了长期收益，新技术往往仍徘徊在边缘，而成熟但非最优的设计继续主导市场。显然，收益不足以抵消成本。就 Qwerty 之争而言，存在两类成本。一是制造和改装成本。键盘是机电设备；因此，新设计需要从头重新设计，并采用新的制造材料和工艺。这很昂贵。另一成本在于克服用户的认知和态度。总体而言，用户厌恶变革：他们不愿放弃已习得且习惯的操作。Noyes 指出，用户“因需要重新培训而不愿更换新的键盘布局”[[377, p. 278](#Chp005_203-242_B9780443140969000117.xhtml#br1885)]。

一个有趣的例子是软键盘或虚拟键盘，常用于智能手机或平板电脑。输入通常通过手指或触控笔进行。大多数此类键盘采用 Qwerty 字母排列。然而，由于键盘是由软件创建的，替代设计不存在改装成本。因此，优化设计进入市场的机会可以说更大。一种提高文本输入速度的想法是重新排列字母，将常用字母聚集在布局中心，不常用字母分布在周边。速度的提升源于手指或触控笔移动距离的减少。然而，由于用户不熟悉优化后的字母排列，初期性能主要受视觉搜索（即寻找下一个字母）主导。如果学习新技术可能需要数小时或更长时间，则评估需要进行纵向研究，在多次输入会话中测试用户。最终，交叉点可能会出现。这一想法将在第 [7 章](#Chp007_293-360_B9780443140969000130.xhtml)（第 [7.2.5 节](#Chp007_293-360_B9780443140969000130.xhtml)，技能习得）中进一步探讨。

# 5.14 运行实验

当实验设计完成、装置构建并测试完毕、参与者招募和日程安排就绪后，测试便开始了。但请等一下！您确定开始测试的时机到了吗？用一两名参与者进行一次试点测试（是的，再做一次试点测试）总是有用的。这将有助于理顺参与者简报和准备的流程。它还可以核对每位参与者所需的时间量。如果测试安排为一小时，则所有测试加上简报、练习等必须能舒适地在一小时内完成。可能需要对流程进行最后的微调。现在调整总比事后后悔好。

实验正式开始。实验员迎接每位参并介绍实验，通常要求参与者签署知情同意书。通常会发放一份简短的问卷，以收集人口统计数据和参与者在研究主题方面的经验信息。这只需几分钟。随后展示装置，解释并演示任务。根据情况允许进行练习试验。

实验的一个重要方面是给参与者的指示。指示取决于实验的性质和任务。对于大多数交互任务，参与者应快速且准确地进行。这些术语——“快速”和“准确”——取决于解释和参与者的能力。对一名参与者而言合理的速度，对另一名可能无法达到。以个人舒适的速度合理快速且高准确地执行任务，通常是目标。示例请见[图 5.22](#Chp005_203-242_B9780443140969000117.xhtml#f0115)。可能需要额外的指示，例如发现错误时是应纠正还是忽略。

![Figure 5.22 Instructions to participants (example wording).](images/B9780443140969000117/gr022.jpg)

[图 5.22](#Chp005_203-242_B9780443140969000117.xhtml#cf0640) 给参与者的指示（示例措辞）。

无论目标如何，指示都必须经过仔细考虑，并以相同的方式给予所有参与者。如果参与者要求澄清，在详述指示时务必谨慎。应避免任何可能激励参与者表现出与其他参与者不同行为的额外解释。

实验员（又称研究者）扮演着特殊角色，是实验的公众形象。保持中立很重要。如果您创造了一个非常巧妙的东西并希望实验揭示这一点，这没问题。但不要向参与者推销您的想法。保持平和的态度，以避免在参与者行为中引入偏差。参与者不应感到有压力去产生特定结果。应避免刻意在某一测试条件下比另一条件下表现得更好。同样，参与者也不应察觉到实验员的特定态度。过度关注的实验员可能让参与者紧张。传达冷漠或漠视的态度可能会影响参与者。中立的态度最好。
