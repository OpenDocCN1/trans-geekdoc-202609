

### 3. 8-5 为文本输入研究招募一些参与者

采用类似于前一个学生练习的程序。但是，不要使用纸质模型，而要使用本书网站上的 `SoftKeyboardExperiment` 软件。许多选项通过设置对话框（[图 8.16](#Chp008_361-390_B9780443140969000142.xhtml#f0085)a）进行设置，包括从七种预配置键盘布局中进行选择。请参见 [图 8.16](#Chp008_361-390_B9780443140969000142.xhtml#f0085)b。任选其中两种。该软件还支持自定义布局和词补全。更多详情请参阅 API 文档。[图 8.16](#Chp008_361-390_B9780443140969000142.xhtml#f0085)c 展示了实验任务。数据收集在软件中自动进行，包括输入速度 (wpm)、错误率 (%) 和每字符击键数 (KSPC) 等因变量指标。

2.  **8-6 用户估算其打字速度的准确性如何？**

针对该问题开展一个小型实验。招募一些参与者，并向每人发放一份简短问卷。包含一个问题，询问他们在台式机上打字的速度（以词/分为单位）。然后使用本书网站提供的 `TypingTestExperiment` 软件测量他们的打字速度。[图 8.17](#Chp008_361-390_B9780443140969000142.xhtml#f0090) 展示了设置对话框和实验过程的屏幕快照。将软件配置为输入十个短语。将用户的估算值与观察到的打字速度进行比较。用户倾向于高估还是低估他们的打字速度？女性和男性参与者之间的差异是否不同？尝试思考其他需要考虑的问题。在简短报告或幻灯片演示中展示你的发现。
