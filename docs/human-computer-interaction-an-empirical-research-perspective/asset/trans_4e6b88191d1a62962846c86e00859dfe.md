

### 6.2.7 使用 GoStats 进行方差分析

利用本书网站提供的 `GoStats` 实用软件，可以轻松进行方差分析。只需启动 `GoStats` 并点击“Go”。请参见[图 6.2](#Chp006_243-291_B9780443140969000129.xhtml#f0015)。这将在 `GoStats` 中打开方差分析工具。请参见[图 6.18](#Chp006_243-291_B9780443140969000129.xhtml#f0095)a。

![Figure 6.18 GoStats. (a) Anova GUI. (b) Data in file dix-example-10x2.txt loaded into the data pane. (c) ANOVA table for data in dix-example-10x2.txt.](images/B9780443140969000129/gr018.jpg)

图 6.18 GoStats。(a) 方差分析 GUI。(b) 文件 `dix-example-10x2.txt` 中的数据已加载到数据窗格中。(c) `dix-example-10x2.txt` 中数据的方差分析表。

`GoStats` 方差分析工具包含一个内容详尽的教程，其中有许多方差分析示例等。这些内容均可在线查看，通过方差分析 GUI 中的 API 链接（图中的箭头所指）即可在浏览器中打开。让我们通过一个示例来演示操作过程。

文件 `dix-example-10x2.txt` 包含了一项关于图标识别的假设实验数据，该实验由 Dix 等人描述[[103, p. 337]](#Chp006_243-291_B9780443140969000129.xhtml#br0515)。要加载数据，请点击“打开……”，导航至 `GoStatsExamples` 文件夹并选择该文件。这会将数据加载到方差分析 GUI 的数据窗格中。请参见[图 6.18](#Chp006_243-291_B9780443140969000129.xhtml#f0095)b。

`dix-example-10x2.txt` 中的数据构成一个 10 × 2 矩阵。共有 10 名参与者和一个组内因素（图标设计），该因素有两个水平（自然和抽象）。数据是任务完成时间的测量值，即因变量。第一列包含自然图标的任务完成时间，第二列包含抽象图标的任务完成时间。每一行包含一名参与者的测量值。

平均任务完成时间（未显示）分别为：自然图标 697.7 秒，抽象图标 750.3 秒。显然，自然图标的识别时间比抽象图标少约 7%。方差分析可确定这种差异是否具有统计学显著性，还是可能归因于偶然因素。为此，首先在 `F1` 框中输入“2”。这表明第一个组内因素 `F1` 有两个水平。点击“分析”，方差分析表随即出现。请参见[图 6.18](#Chp006_243-291_B9780443140969000129.xhtml#f0095)c。
