

## 学生练习

### 2-5 Graffiti 手势输入实验

**图 2.51** 学生 Graffiti 手势输入练习。(a) 设置对话框 (Windows)。(b) 实验任务 (Windows)。(c) 设置对话框 (Android)。(d) 实验任务 (Android)。

1.  设置对话框中的选项之一是“Phrases file”（短语文件）。请使用 `alphabet.txt`。将“Number of phrases”（短语数量）设置为 10。保持“Show gesture set”（显示手势集）选中状态。手势可在实验屏幕中查看（参见[图 2.51](#Chp002_31-91_B9780443140969000087.xhtml#f0260)）。参与者可使用退格笔画（←）纠正错误。但请指导参与者每个符号的纠正尝试不超过三次。

2.  数据收集是自动化的。完整详情请参考 `API`。分析数据以揭示两组参与者在 10 次试验中的进展。分析输入速度 (wpm)、错误率 (%) 和每字符击键数 (KSPC)。（此处“击键”指手势笔画。）准备一份简要报告或幻灯片演示来展示你的发现。

### 2-6 人类反应时间实验

使用本书网站上的 `ReactionTimeExperiment` 软件进行一项关于人类反应时间的小型实验。招募约 10 名参与者。设置对话框如[图 2.52](#Chp002_31-91_B9780443140969000087.xhtml#f0265)所示。实验过程的示例在前文已给出（参见“Reaction Time”，第 66 页）。考虑以某种方式修改软件，例如在视觉搜索任务中使用单词代替字母，或在简单反应时间任务中使用听觉刺激代替视觉刺激。该修改可作为比较点（例如，单词与字母的视觉搜索对比，或听觉刺激与视觉刺激的反应时间对比）。准备一份简要报告或幻灯片演示来展示你的发现。

### 2-9 目标选择任务数据分析

以下数据来自一个目标选择任务：

| From (x/y): | | 765, 592.5 |
| --- | --- | --- |
| To (x/y): | | 640, 126 |
| Width: | | 100 |
| Px: | | 762, 764, 766, 766, 767, 768, 769, … |
| Py: | | 626, 628, 629, 630, 631, 631, 631, … |

任务是将光标从“From”坐标移动到“To”坐标，并选择一个直径为“Width”、中心位于“To”坐标的圆形目标。实际光标路径以一系列点的形式给出，其坐标为 *P*[*x*] 和 *P*[*y*]。完整路径以 224 个点进行数字化。完整数据集位于本书网站的文件 `StudentExercise[2-9](#Chp002_31-91_B9780443140969000087.xhtml#o0050).txt` 中。分析数据以计算运动变异性 (MV) 和目标重入次数 (TRE)。计算可以在电子表格中完成，也可以使用你选择的编程语言。包含可能揭示交互性能问题的其他指标。准备一份简要报告或幻灯片演示来展示你的发现。根据需要包含视觉辅助材料。
