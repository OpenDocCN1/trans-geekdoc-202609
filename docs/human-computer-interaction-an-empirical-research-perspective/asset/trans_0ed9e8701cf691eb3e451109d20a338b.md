

## 目标重入 (TRE)

在 [图 2.41](#Chp002_31-91_B9780443140969000087.xhtml#f0210)b 的目标选择任务中，光标进入目标，移出，然后在最终选择前重新进入。正如前面所述，这种行为可能表明最终选择阶段存在控制问题。捕捉此行为的一个指标是**目标重入 (TRE)**，即光标（在已进入一次后）重新进入目标的次数。显然，计数为零是最理想的。[图 2.44](#Chp002_31-91_B9780443140969000087.xhtml#f0225) 展示了一项研究平板电脑上目标选择实验的示例试次 [\[326, 图 9\]](#Chp002_31-91_B9780443140969000087.xhtml#br1630)。该交互利用设备倾斜来控制光标。选择要求光标进入目标并停留 500 ms。在该示例中，`TRE = 3`。

![Figure 2.44 Digitized cursor path for a target selection task using tilt input on a tablet computer [\[326, Fig. 9\]](#Chp002_31-91_B9780443140969000087.xhtml#br1630). There were three target re-entries.](images/B9780443140969000087/gr044.jpg)

**图 2.44** 使用平板电脑倾斜输入进行目标选择任务的数字化光标路径 [\[326, 图 9\]](#Chp002_31-91_B9780443140969000087.xhtml#br1630)。共有三次目标重入。

正如 [图 2.44](#Chp002_31-91_B9780443140969000087.xhtml#f0225) 所示，交互中存在多种光标控制问题。如果 `MV` 或 `TRE` 等指标较高——或者更确切地说，在某一条件下比另一条件下更高——这对于区分交互方法具有相关性。结合交互的显性且已知属性来看待测量值，对于寻找合理的解释非常重要。这对研究至关重要——为了理解为什么某些测试条件效果良好而其他条件效果不佳。

### 目标选择的附加指标

目标选择任务的附加指标示例包括**运动偏移 (MO)**、**运动误差 (ME)**、**任务轴穿越 (TAC)**、**运动方向改变 (MDC)** 和**正交方向改变 (ODC)** [\[314\]](#Chp002_31-91_B9780443140969000087.xhtml#br1570)。这些指标与 `MV` 和 `TRE` 一样，都是实验中的潜在因变量，详见第 [5](#Chp005_203-242_B9780443140969000117.xhtml) 章（第 [5.5](#Chp005_203-242_B9780443140969000117.xhtml) 节，因变量）。这些指标在 HCI 实验中应用的示例可见于 Long 和 Gutwin [\[290\]](#Chp002_31-91_B9780443140969000087.xhtml#br1450)、Murthy 等人 [\[362\]](#Chp002_31-91_B9780443140969000087.xhtml#br1810)、Keates 和 Trewin [\[242\]](#Chp002_31-91_B9780443140969000087.xhtml#br1210)、Herring 等人 [\[188\]](#Chp002_31-91_B9780443140969000087.xhtml#br0940)、Pandey 等人 [\[386\]](#Chp002_31-91_B9780443140969000087.xhtml#br1930)、Wobbrock 和 Gajos [\[523\]](#Chp002_31-91_B9780443140969000087.xhtml#br2615) 以及 Pino 等人 [\[401\]](#Chp002_31-91_B9780443140969000087.xhtml#br2005) 的著作中。另请参阅学生练习 [2-9](#Chp002_31-91_B9780443140969000087.xhtml#o0050)。

## 文本输入指标

让我们转向 [图 2.41](#Chp002_31-91_B9780443140969000087.xhtml#f0210) 中的文本输入任务。在 (b) 部分中，最终文本是正确的，但这只是在经过纠正操作之后。因此，仅考虑最终文本会遗漏交互的重要方面。捕捉 (b) 部分行为的一个指标是**每字符击键数 (KSPC)** [\[303\]](#Chp002_31-91_B9780443140969000087.xhtml#br1515)，[\[325\]](#Chp002_31-91_B9780443140969000087.xhtml#br1625)。`KSPC` 既是一个分析指标，也是一个实证指标。分析指标或模型是通过分析计算得出的，无需观察实际交互。^([^(41)](#fn41))

```
KSPC = len(quicz < kly) / len(quickly) = 9 / 7 = 1.286
```
**(2.3)**

此处，我们假设输入是通过 Qwerty 键盘或其他某种一个动作产生一个字符的方法进行的。在此基础上，无误输入的基线为 `KSPC = 1.000`。`KSPC` 超出基线的程度衡量了制造和纠正错误的开销。

公式 [(2.3)](#Chp002_31-91_B9780443140969000087.xhtml#deq3) 适用于单个词条的输入。如果在多个输入单元上计算平均值（每个单元通常是从语料库中随机抽取的一个短语）[\[321\]](#Chp002_31-91_B9780443140969000087.xhtml#br1605)，`KSPC` 作为性能的实证指标会更有用。此外，跨两个或多个测试条件的计算有可能揭示区分测试条件的差异。关于 `KSPC` 作为实证指标在 HCI 文献中的更多应用示例，请参阅 Abdrabou 等人 [\[1\]](#Chp002_31-91_B9780443140969000087.xhtml#br0005)、Hassan 等人 [\[181\]](#Chp002_31-91_B9780443140969000087.xhtml#br0905)、Jain 和 Balakrishnan [\[218\]](#Chp002_31-91_B9780443140969000087.xhtml#br1090)、Kuang 等人 [\[258\]](#Chp002_31-91_B9780443140969000087.xhtml#br1290) 以及 Palin 等人 [\[384\]](#Chp002_31-91_B9780443140969000087.xhtml#br1920) 的著作。^([^(42)](#fn42))

### 最小字符串距离 (MSD) 和错误率 (ER)

在 [图 2.41](#Chp002_31-91_B9780443140969000087.xhtml#f0210)c 中，最终文本不正确：“qucehkly” 而非 “quickly”。在词级层面，这算作一个错误。但在字符级层面，情况有所不同，因为输入部分正确。再一次，超越可视化——量化观察行为的某个属性——是有价值的。让我们通过两个问题来研究这个想法。首先，最终文本（“qucehkly”）中有多少字符级错误？这有点棘手。仔细对比实际文本与期望文本表明有三个错误。捕捉这一点的一个指标是**最小字符串距离 (MSD)** [\[464\]](#Chp002_31-91_B9780443140969000087.xhtml#br2320)。`MSD` 算法递归遍历两个字符串，并构建一个矩阵来列出字符串间的差异。最后一个条目是一个整数，等于将一个字符串转换为另一个字符串所需的最少基本操作数。对于该示例，`MSD = 3`。见 [图 2.45](#Chp002_31-91_B9780443140969000087.xhtml#f0230)a。当然，无误输入产生 `MSD = 0`。`MSD` 随错误数量增加而上升。

![Figure 2.45 Character-level errors. (b) MSD matrix and statistic. (b) Alignments.](images/B9780443140969000087/gr045.jpg)

**图 2.45** 字符级错误。 (b) MSD 矩阵与统计量。 (b) 对齐。

该示例的错误率 (`ER`) 为

```
ER = MSD(A,B) / max(len(A), len(B)) = 3 / 8 = 0.125 = 12.5%
```
**(2.4)**

分母使用最大值函数以确保错误率不超过 100%。与公式 [(2.3)](#Chp002_31-91_B9780443140969000087.xhtml#deq3)（用于 `KSPC`）类似，公式 [(2.4)](#Chp002_31-91_B9780443140969000087.xhtml#deq4) 中的计算针对单个词条。当然，如果在更大的输入单元（如短语）上计算平均值，并跨多个测试条件进行分析，错误率分析最为有用。在 HCI 文献中使用 `MSD` 错误率的示例包括 Castellucci 等人 [\[72\]](#Chp002_31-91_B9780443140969000087.xhtml#br0360)、Hedeshy 等人 [\[185\]](#Chp002_31-91_B9780443140969000087.xhtml#br0925)、Mutasim 等人 [\[363\]](#Chp002_31-91_B9780443140969000087.xhtml#br1815)、Nicolau 和 Jorge [\[372\]](#Chp002_31-91_B9780443140969000087.xhtml#br1860) 以及 Tominaga 等人 [\[492\]](#Chp002_31-91_B9780443140969000087.xhtml#br2460) 的著作。^([^(43)](#fn43))
