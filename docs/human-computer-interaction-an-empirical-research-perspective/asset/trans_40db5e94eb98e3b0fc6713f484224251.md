
为了加快输入速度，通常采用两级扫描模式，例如行列扫描。[图 3.13](#Chp003_93-160_B9780443140969000099.xhtml#f0070) 展示了一个将字母按字母顺序排列在矩形中的示例。扫描逐行进行。当包含所需字符的行被高亮显示时，用户选择该行。随后扫描在该行内按列进行。当包含所需字符的键被高亮显示时，用户选择该键。该字符被追加到文本消息中，扫描从顶行重新开始。扫描是循环的，因此如果用户错过了机会，可以在下一轮进行选择。请注意，虽然两级扫描潜在速度更快，但对身体要求更高，因为生成每个字符需要两次选择。

![图 3.13 行列扫描。输入“K”。第 1 次选择行“I J K L”，第 2 次选择该行内的列“K”。](images/B9780443140969000099/gr013.jpg)

图 3.13 行列扫描。输入“K”。第 1 次选择行“I J K L”，第 2 次选择该行内的列“K”。

一个扫描键盘的例子是嵌入在 Microsoft Windows 中的屏幕键盘（OSK）。参见[图 3.14](#Chp003_93-160_B9780443140969000099.xhtml#f0075)。这是一个功能齐全的 Qwerty 键盘，提供对传统桌面键盘所有功能的访问。默认使用系统物理键盘上的空格键进行输入，尽管也支持其他输入选项。OSK 不使用行列扫描，而是采用三级行-组-键扫描。扫描逐行进行，然后在选定行中按组进行，最后在选定组中按键进行。在图中，用户即将输入“r”，它位于第 3 行的第 2 组中。预期短语为“hello world”。

![图 3.14 在 Microsoft 屏幕键盘（OSK）单开关扫描模式下输入“hello world”。键盘使用三级行-组-键扫描。用户即将在“hello world”中输入“r”。](images/B9780443140969000099/gr014.jpg)

图 3.14 在 Microsoft 屏幕键盘（OSK）单开关扫描模式下输入“hello world”。键盘使用三级行-组-键扫描。用户即将在“hello world”中输入“r”。

请注意[图 3.14](#Chp003_93-160_B9780443140969000099.xhtml#f0075)中，OSK 顶行包含单词预测功能，并纳入扫描序列中。对于该示例，用户无需输入“r”，可选择顶行并直接选中“world”，立即生效。显然，此时选择“world”减少了扫描步数，带来性能优势。[图 3.15](#Chp003_93-160_B9780443140969000099.xhtml#f0080) 对比了逐字母交互与使用单词预测交互的差异。差异显著：逐字母交互需 41 个扫描步，而使用单词预测仅需 18 个扫描步。

![图 3.15 在 Microsoft 屏幕键盘上使用扫描输入“world”的分析。(a) 逐字母。(b) 使用单词预测。在 Input 下，“.” 表示被动扫描步，“R” 表示行选择，“G” 表示组选择，“W” 表示单词选择，小写字母表示字母选择。](images/B9780443140969000099/gr015.jpg)

图 3.15 在 Microsoft 屏幕键盘上使用扫描输入“world”的分析。(a) 逐字母。(b) 使用单词预测。在 Input 下，“.” 表示被动扫描步，“R” 表示行选择，“G” 表示组选择，“W” 表示单词选择，小写字母表示字母选择。

[图 3.15](#Chp003_93-160_B9780443140969000099.xhtml#f0080) 中的分析有助于更广泛地考虑使用“每字符扫描步数”（SPC）作为分析指标的替代设计。对于包含 5 个字符的“world”，逐字母交互的 SPC 为 $\frac{41}{5} = 8.2$![Image](images/B9780443140969000099/si1.png)，使用单词预测的 SPC 为 $\frac{18}{5} = 3.6$![Image](images/B9780443140969000099/si2.png)。

对单个单词的交互进行比较虽有趣，但价值有限。加上语料库（如字母频率表或单词频率表），[图 3.15](#Chp003_93-160_B9780443140969000099.xhtml#f0080) 中的计算可推广到一种语言（如英语），并计算整个语料库的加权平均值。结果是使用特定键盘和交互策略进行英文文本输入的总体平均 SPC [[304]](#Chp003_93-160_B9780443140969000099.xhtml#br1520)。使用字母频率表，SPC 计算公式为

$$\text{SPC} = \frac{\Sigma(S_{c} \times F_{c})}{\Sigma(N_{c} \times F_{c})}$$

![Image](images/B9780443140969000099/si3.png)(3.1)

其中

*   • $S[c]$![Image](images/B9780443140969000099/si4.png) 为输入字符 $c$ 所需的扫描步数
*   • $F[c]$![Image](images/B9780443140969000099/si5.png) 为语料库中字符 $c$ 的频率计数
*   • $N[c]$![Image](images/B9780443140969000099/si6.png) = 1（字符 $c$ 的数量）

计算 SPC 的过程与计算 KSPC（每字符击键数）作为物理键盘分析指标（如多义电话键盘 [[303]](#Chp003_93-160_B9780443140969000099.xhtml#br1515),[[325]](#Chp003_93-160_B9780443140969000099.xhtml#br1625)）的过程相似。虽然公式 [(3.1)](#Chp003_93-160_B9780443140969000099.xhtml#deq1) 中 $N[c]$![Image](images/B9780443140969000099/si6.png) = 1，但若使用单词频率表，计算可在单词级进行，将公式中的 $c$（字符）替换为 $w$（单词）。此时 $N[w]$![Image](images/B9780443140969000099/si7.png) 为单词字符数 +1（单词后的空格）。

另一种加快输入的方法是将高频字母（如英语中的“e”、“a”、“t”）放在扫描序列的开头附近。这减少了到达这些字母所需的扫描步数。一个例子是 Shein 等人的 WiViK 键盘 [[445]](#Chp003_93-160_B9780443140969000099.xhtml#br2225)。[图 3.16](#Chp003_93-160_B9780443140969000099.xhtml#f0085) 展示了 WiViK 字母排列及单词预测的单词位置。用户可在优化字母排列或 Qwerty 字母排列间选择。对于优化排列，常用字母位于左上角，从而减少到达它们的扫描步数。结果为英文文本输入带来整体性能优势：优化排列 SPC = 2.64，Qwerty 排列 SPC = 3.80 [[304]](#Chp003_93-160_B9780443140969000099.xhtml#br1520).^([^(49)](#fn49))
