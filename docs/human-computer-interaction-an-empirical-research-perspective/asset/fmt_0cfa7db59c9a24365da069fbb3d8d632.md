
Calculated using the adjustment for accuracy, `TP` is a human performance measure that embeds both the speed and accuracy of responses. Because of this, `TP` is a more stable measure than speed or accuracy alone [\[167\]](#Chp007_293-360_B9780443140969000130.xhtml#br0835), [\[312\]](#Chp007_293-360_B9780443140969000130.xhtml#br1560), [\[546\]](#Chp007_293-360_B9780443140969000130.xhtml#br2730). [Fig. 7.19](#Chp007_293-360_B9780443140969000130.xhtml#f0100) presents an expanded version of Eq. [(7.7)](#Chp007_293-360_B9780443140969000130.xhtml#deq7) showing the connection to speed and accuracy in participant responses.

![Figure 7.19 Throughput equation showing speed and accuracy.](images/B9780443140969000130/gr019.jpg)

[Figure 7.19](#Chp007_293-360_B9780443140969000130.xhtml#cf0690) Throughput equation showing speed and accuracy.

Throughput is most useful as a dependent variable in factorial experiments using pointing devices or pointing techniques as independent variables.

If using Fitts' law as a predictive model is the goal, then the movement time (`MT`) to complete a task is predicted using a simple linear equation:^([^(134)](#fn134))

```
MT = a + b × ID
```
(7.10)

The slope and intercept coefficients in the prediction equation are determined through empirical tests, typically using linear regression. The tests are undertaken in a controlled experiment using a group of participants and one or more input devices and task conditions.

### 7.2.2.2 Example

In this section we demonstrate how to build a Fitts' law predictive model using a subset of the data from an experiment comparing two pointing devices [\[313\]](#Chp007_293-360_B9780443140969000130.xhtml#br1565). One device was an Interlink Electronics RemotePoint. The RemotePoint is a cordless pointing device operated in the air, for example, while giving a presentation using a large interactive vertical display. Cursor position is controlled by a thumb-activated isometric joystick. Selection uses a trigger-like switch operated with the index finger. See [Fig. 7.20](#Chp007_293-360_B9780443140969000130.xhtml#f0105)a. A Microsoft Mouse 2.0 served as a baseline condition. Twelve participants performed a series of reciprocal point-select tasks across nine target conditions: `A` = 40, 80, 160 pixels crossed with `W` = 10, 20, 40 pixels. Using Eq. [(7.6)](#Chp007_293-360_B9780443140969000130.xhtml#deq6), the target conditions spanned a range of difficulties from

```
ID = log₂(40/40 + 1) = 1.00 bits
```
(7.11)

to

```
ID = log₂(160/10 + 1) = 4.09 bits.
```
(7.12)

See [Fig. 7.20](#Chp007_293-360_B9780443140969000130.xhtml#f0105)b.

![Figure 7.20 Fitts' law example. (a) RemotePoint pointing device. (b) Experiment task.](images/B9780443140969000130/gr020.jpg)

Figure 7.20 Fitts' law example. (a) RemotePoint pointing device. (b) Experiment task.

The data for the mouse and RemotePoint conditions are given in [Fig. 7.21](#Chp007_293-360_B9780443140969000130.xhtml#f0110). There are nine rows, one for each `A`-`W` target condition. The three columns on the left are the target conditions (`A`, `W`, and the calculated index of task difficulty, `ID`). The remaining columns are the participants' responses. `W`[e] is the effective target width (Eq. A Fitts' law model can be built for both device conditions in [Fig. 7.21](#Chp007_293-360_B9780443140969000130.xhtml#f0110). The prediction equations use `MT` as the dependent variable and either `ID` or `ID`[e] as the predictor variable. The advantage in using `ID`[e] is that the model includes both the speed and accuracy of responses and therefore more accurately reflects participant behaviour.

The easiest way to build and demonstrate the models is using a spreadsheet application. [Fig. 7.22](#Chp007_293-360_B9780443140969000130.xhtml#f0115) provides a visualization of the data as a scatter plot for each device. The chart also includes the regression lines, the prediction equations, and `R`². Both `R`² values are very high. The mouse model, for example, explains 97% of the variance in the observations.

![Figure 7.22 Scatter plot and regression lines for data in Fig. 7.21 (adapted from [313]).](images/B9780443140969000130/gr022.jpg)

Figure 7.22 Scatter plot and regression lines for data in [Fig. 7.21](#Chp007_293-360_B9780443140969000130.xhtml#f0110) (adapted from [\[313\]](#Chp007_293-360_B9780443140969000130.xhtml#br1565)).

The format of the prediction equations in [Fig. 7.22](#Chp007_293-360_B9780443140969000130.xhtml#f0115) can be improved. For the RemotePoint, the predicted time to move a cursor over a distance `A` to select a target of width `W` is

```
MT = 597 + 408 × log₂(A/W + 1) ms.
```
(7.13)

For the mouse, the prediction equation is

```
MT = 159 + 204 × log₂(A/W + 1) ms.
```
(7.14)

What insight is found in the Fitts' law models in [Fig. 7.22](#Chp007_293-360_B9780443140969000130.xhtml#f0115)? An initial observation is that point-select operations with both devices conform to Fitts' law, as evident by the high values of `R`². This is the first use of Fitts' law, noted earlier. Also, it is apparent that the RemotePoint performed poorly compared to the mouse. The movement time was substantially longer for the RemotePoint, for all target conditions. The slopes of the regression lines demonstrate a substantially lower rate of information processing for the RemotePoint. The slope has units ms/bit. The slope reciprocal, with a conversion to seconds, has units bits/s. Thus, a lower slope is a higher rate of information processing (throughput). The mouse is clearly a better device.^([^(135)](#fn135))

There is also some debate on the method of calculating throughput. For example, the throughput for the mouse is 3.60 bits/s using the division of means ([Fig. 7.21](#Chp007_293-360_B9780443140969000130.xhtml#f0110)) or `1/204` = 4.90 bits/s using the slope reciprocal in the regression equation ([Fig. 7.22](#Chp007_293-360_B9780443140969000130.xhtml#f0115)). See Soukoreff and MacKenzie [\[466\]](#Chp007_293-360_B9780443140969000130.xhtml#br2330) or Zhai et al. [\[546\]](#Chp007_293-360_B9780443140969000130.xhtml#br2730) for further discussion.

There are many dozens of scatter plots in the HCI literature that include Fitts' law prediction models. Some examples are summarized in [Fig. 7.23](#Chp007_293-360_B9780443140969000130.xhtml#f0120). Although `R`² > .8 for all models in the figure, there is a significant spread in the slope coefficients. This is partly due to the use of different methodologies in collecting data and building the models. Consequently, across-study comparisons for Fitts' law research are often difficult.
