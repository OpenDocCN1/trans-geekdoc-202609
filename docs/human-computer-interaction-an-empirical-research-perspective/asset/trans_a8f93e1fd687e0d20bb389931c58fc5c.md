
预测模型的优势之一在于能够预测从未实际观测到的自变量值对应的结果。请注意[图 7.16](#Chp007_293-360_B9780443140969000130.xhtml#f0085)a 中，没有参与者的触键速度在 60 wpm 范围内。即便如此，我们仍可推测：触键速度为 60 wpm 的用户，其手写笔点击速度将为

*y* = 0.1342 × 60 + 15.037 = 23.1 wpm.

![Image](images/B9780443140969000130/si4.png)(7.3)

鉴于[图 7.16](#Chp007_293-360_B9780443140969000130.xhtml#f0085)b 中数据点的离散程度，该预测显然存在不确定性。标准误差（*SE*）是衡量这种不确定性的有用统计量。*SE* 确立了预测值周围的置信区间。对于[图 7.16](#Chp007_293-360_B9780443140969000130.xhtml#f0085)a 中的数据，*SE* = 3.39 wpm.^([^(132)](#fn132))

通常线性回归模型的报告会给出方程和 *R*²![Image](images/B9780443140969000130/si2.png)。置信区间和 *SE* 一般不予报告，尽管也有例外 [\[80](#Chp007_293-360_B9780443140969000130.xhtml#br0400),[309\]](#Chp007_293-360_B9780443140969000130.xhtml#br1545)。有时，线性回归模型中斜率和截距系数的标准误会单独给出 [\[2](#Chp007_293-360_B9780443140969000130.xhtml#br0010),[57](#Chp007_293-360_B9780443140969000130.xhtml#br0285),[387\]](#Chp007_293-360_B9780443140969000130.xhtml#br1935)。接下来我们将介绍人机交互领域一种流行的预测模型——费茨定律。

## 7.2.2 费茨定律

费茨定律是人机交互领域最广泛使用的模型之一。如果一种交互涉及快速瞄准运动（如移动手指或光标至目标并选中目标），那么很有可能有人已针对该交互进行过实验，并使用费茨定律对其建模。费茨定律在人机交互中有三大用途：

*   通过建立预测方程并检验相关性的“拟合优度”，判断设备或交互技术是否符合该模型
*   利用预测方程分析设计备选方案
*   将费茨性能指数（现称吞吐率）作为因变量用于对比评估

下文将逐一探讨这些用途。

由于费茨定律源于实验心理学的基础研究，我们首先回顾一些背景知识。详细综述请参阅其他文献 [\[301](#Chp007_293-360_B9780443140969000130.xhtml#br1505),[356](#Chp007_293-360_B9780443140969000130.xhtml#br1780),[466](#Chp007_293-360_B9780443140969000130.xhtml#br2330),[514\]](#Chp007_293-360_B9780443140969000130.xhtml#br2570)。

### 7.2.2.1 背景

费茨是一位实验心理学家，致力于将信息论应用于人类行为研究。这是 1950 年代研究的常见主题，它将人类表现的概念与电子通信中当代新兴的数学“信息”概念相融合。费茨认为，瞄准运动的振幅类似于电子信号中的信息，而移动的空间精度类似于电子噪声。此外，他提出人类运动系统类似于一个通信通道，动作类似于信号的传输。费茨的类比源自香农定理 17，该定理表达了带宽为 *B*（单位 s⁻¹ 或 Hz）的通信通道的信息容量 *C*（单位 bits/s）：

```
C = B log₂(S/N + 1)
```

![Image](images/B9780443140969000130/si5.png)(7.4)

其中 *S* 为信号功率，*N* 为噪声功率 [\[444, p. 100-103\]](#Chp007_293-360_B9780443140969000130.xhtml#br2220)。

费茨在两篇极具影响力的论文中提出了他的类比——即现在的“定律”：一篇发表于 1954 年 [\[125\]](#Chp007_293-360_B9780443140969000130.xhtml#br0625)，另一篇发表于 1964 年 [\[126\]](#Chp007_293-360_B9780443140969000130.xhtml#br0630)。1954 年的论文描述了一个连续（或往返）目标获取任务，参交替点击宽度为 *W*、振幅相隔 *A* 的目标（见[图 7.18](#Chp007_293-360_B9780443140969000130.xhtml#f0095)a）。1964 年的论文描述了一个使用离散任务的类似实验，受试者根据刺激灯选择两个目标之一（见[图 7.18](#Chp007_293-360_B9780443140969000130.xhtml#f0095)b）。不难想象如何用计算机输入设备和屏幕渲染的目标来更新费茨的实验装置。

![Figure 7.18 Experiment paradigms for Fitts' law. (a) Serial task [125]. (b) Discrete task [126].](images/B9780443140969000130/gr018.jpg)

图 7.18 费茨定律的实验范式。(a) 连续任务 [\[125\]](#Chp007_293-360_B9780443140969000130.xhtml#br0625)。(b) 离散任务 [\[126\]](#Chp007_293-360_B9780443140969000130.xhtml#br0630)。

费茨研究的关系涉及运动任务的振幅、所需时间，以及运动终止区域的宽度（或容差）。在实验心理学史上或许是最低调的结论中，费茨总结其发现如下：“结果具有足够的一致性，表明速度、振幅和容差之间假设的关系可能是普遍的” [\[125, p. 389\]](#Chp007_293-360_B9780443140969000130.xhtml#br0625)。确实，费茨定律的稳健性非同寻常。自费茨开创性工作以来的几十年间，该关系已在极其多样的环境中被无数次验证，无论是在显微镜下还是在水下。

费茨提议利用信息论，以“比特”为度量单位，量化运动任务的难度——即难度指数 *ID*。具体而言：

```
ID = log₂(2A/W)
```

![Image](images/B9780443140969000130/si6.png)(7.5)

振幅 (*A*) 和宽度 (*W*) 分别类似于公式 [(7.4)](#Chp007_293-360_B9780443140969000130.xhtml#deq4) 中香农的信号 (*S*) 和噪声 (*N*)。请注意方程中 *A* 和 *W* 的抵消影响：目标距离加倍的效果等同于目标尺寸减半。费茨研究的一项重要论点是任务难度与运动时间 (*MT*) 之间呈线性关系。后来引入了以下 *ID* 表达式，以改进该关系的信息论基础 [\[301\]](#Chp007_293-360_B9780443140969000130.xhtml#br1505)：

```
ID = log₂(A/W + 1)
```

![Image](images/B9780443140969000130/si7.png)(7.6)

由于 *A* 和 *W* 均为距离度量，公式 [(7.6)](#Chp007_293-360_B9780443140969000130.xhtml#deq6) 括号内的项无量纲。“比特”单位源于对数以 2 为底。

费茨还提议以“比特每秒”为单位，量化人类在瞄准运动中的信息处理速率。这是一个纯基于类比而无人类心理运动行为学基础的大胆想法。费茨的*性能指数*，现称*吞吐率* (*TP*，单位 bits/s)，通过将 *ID*（比特）除以一系列试验的平均运动时间 *MT*（秒）来计算：

```
TP = IDₑ / MT
```

![Image](images/B9780443140969000130/si8.png)(7.7)

*ID*ₑ 中下标“e”反映了一个虽小但重要的调整，费茨在其 1964 年论文中认可了该调整。精度调整首先涉及计算有效目标宽度：

*W*ₑ = 4.133 × *SD*[*x*]

![Image](images/B9780443140969000130/si9.png)(7.8)

其中 *SD*[*x*] 为参与者选择坐标的标准差。^([^(133)](#fn133))

```
IDₑ = log₂(A/Wₑ + 1)
```

![Image](images/B9780443140969000130/si10.png)(7.9)
