
# 项目 16-1：NIST 网络安全框架电子表格

1. 从 [https://www.nist.gov/cyberframework](https://www.nist.gov/cyberframework) 下载 NIST 网络安全框架电子表格。
2. 熟悉 NIST 网络安全框架的所有不同组件、类别、子类别和参考资料。
3. 从 [https://www.nist.gov/cyberframework/csf-reference-tool](https://www.nist.gov/cyberframework/csf-reference-tool) 下载 NIST CSF 工具。熟悉该工具的所有不同功能，以及它如何帮助你开始构建自己的网络安全计划。
4. 准备一份报告，解释企业或私营部门组织如何利用该框架来帮助完成以下工作：
   * 识别资产及相关风险。
   * 防御威胁行为者。
   * 检测并应对任何网络安全事件和事故。
   * 在网络安全事故发生后恢复。

## 案例研究

### 英特尔和 McAfee 采用 NIST 网络安全框架

英特尔发布并提交了一份题为“网络安全框架：英特尔的实施工具和方法”的演示文稿。该演示文稿可在 [https://www.nist.gov/sites/default/files/documents/cyberframework/cybersecurityframework_6thworkshop_intel_corp.pdf](https://www.nist.gov/sites/default/files/documents/cyberframework/cybersecurityframework_6thworkshop_intel_corp.pdf) 找到。

英特尔使用 NIST 网络安全框架的目标包括与其风险承受能力实践保持一致。此外，他们还将框架用作向高级管理人员传达风险的指导。

同样，McAfee 发布了一篇题为“我们尝试了 NIST 框架，它有效”的博客文章，可通过 [https://securingtomorrow.mcafee.com/executive-perspectives/tried-nist-framework-works-2](https://securingtomorrow.mcafee.com/executive-perspectives/tried-nist-framework-works-2) 访问。

在其博客文章中，McAfee 解释了他们如何“专注于开发一个用例，该用例将创造一种共同语言，并鼓励将框架用作流程和风险管理工具，而非一套静态要求。”

研究这两种实施方式并回答以下问题：
1. 这些公司为何尝试将其网络安全计划与 NIST 网络安全框架保持一致？
2. 主要益处有哪些？
3. 描述英特尔和 McAfee 的努力如何相似和/或不同。
4. 研究其他也将其网络安全工作与 NIST 网络安全框架保持一致的公司，并将结果与英特尔和 McAfee 的结果进行比较。
