
# 供参考：行政命令13636，《改善关键基础设施网络安全》

美国行政命令13636《改善关键基础设施网络安全》于2013年2月发布，要求NIST制定一个以现有标准、指南和实践为中心的*自愿性*框架。主要目标是降低美国关键基础设施的网络安全相关风险。2014年后期，《2014年网络安全增强法案》加强了NIST制定此类框架的作用。

行政命令13636第7节“降低关键基础设施网络风险的基础框架”规定，“网络安全框架应包括一套标准、方法、程序和流程，使政策、业务和技术方法保持一致以应对网络风险。网络安全框架应最大程度地纳入自愿共识标准和行业最佳实践。网络安全框架应与自愿国际标准保持一致，当此类国际标准有助于推进本命令的目标时，并应符合经修订的国家标准与技术研究院法案（15 U.S.C. 271 及以下）、1995年国家技术转移与促进法（公共法律104-113）以及经修订的OMB通函A-119的要求。”

行政命令还规定框架“应提供一种优先、灵活、可重复、基于绩效且具有成本效益的方法，包括信息安全措施和控制，帮助关键基础设施的所有者和运营商识别、评估和管理网络风险”。此外，框架“应侧重于识别适用于关键基础设施的跨部门安全标准和指南”，并确定应通过与特定部门和标准制定组织未来合作解决的改进领域。

行政命令第10节包括关于政府机构采用该框架的指导。

私营部门组织通常有动力实施NIST网络安全框架以增强其网络安全计划。这些组织通常遵循NIST网络安全框架指导以降低其网络安全相关风险。

在本章中，我们研究NIST网络安全框架，并发现它如何可作为任何试图创建安全计划并分析其网络安全风险的组织的蓝图。

## 介绍NIST网络安全框架组件

NIST网络安全框架是在行业与政府合作下创建的。它由标准、指南和实践组成，以促进关键基础设施的保护。框架的优先、灵活、可重复且具有成本效益的方法有助于关键基础设施的所有者和运营商管理网络安全相关风险。

如[第3章](`#ch03.xhtml#ch03`)所述，“[网络安全框架](`#ch03.xhtml#ch03`)”，NIST网络安全框架的一个目标不仅是帮助美国政府，还为任何组织提供指导，无论其规模、网络安全风险程度或成熟度如何。

另一个需要强调的是，NIST网络安全框架是一个活文档，将随着参与者对实施提供反馈而持续更新和改进。框架的最新版本可在[`www.nist.gov/cyberframework`](`http://www.nist.gov/cyberframework`)获得。

该框架由标准、指南和实践构建，以为组织提供共同指导，使其能够做到以下几点：
* 描述其当前的网络安全态势。
* 描述其网络安全的目标状态。
* 在持续且可重复的过程的背景下识别和优先考虑改进机会。
* 评估向目标状态的进展。
* 就网络安全风险与内部和外部利益相关者进行沟通。

NIST非常明确地指出，该框架旨在补充贵组织的现有风险管理流程和网络安全计划。它不会取代此类流程或计划。您可以利用NIST网络安全框架通过遵循行业最佳实践来帮助加强您的政策和计划。如果您的组织没有现有的网络安全计划，您可以使用NIST网络安全框架作为参考来制定此类计划。

注意
尽管NIST网络安全框架是在美国创建的，但该框架也在美国以外使用。

NIST网络安全框架分为三个部分，如[图16-1](`#ch16.xhtml#ch16fig01`)所示。
* 框架核心是“跨关键基础设施部门通用的网络安全活动、成果和信息性参考的集合，为制定个人组织概况提供详细指导”。
* 框架概况旨在帮助底层组织使其网络安全工作与业务要求、风险承受能力和资源保持一致。
* 框架层级旨在帮助组织查看和理解其管理网络安全风险的方法的特征。

## 框架核心

框架核心旨在构建一份活动清单以实现某些网络安全成果，并包括实现此类成果的指导示例。

[图16-2](`#ch16.xhtml#ch16fig02`)列出了NIST网络安全框架核心中定义的功能。

![](graphics/16fig02.jpg)

然后框架核心进一步分解为每个框架功能的类别、子类别和信息性参考，如[图16-3](`#ch16.xhtml#ch16fig03`)所示。

![](graphics/16fig03.jpg)

[图16-3](`#ch16.xhtml#ch16fig03`)所示的元素如下：
* 类别将功能的要素分组为网络安全成果的集合，包括资产管理、身份管理和访问控制、安全持续监控、响应计划等许多内容。
* 子类别是每个类别内技术和/或管理活动的具体成果清单。它们可被视为一套结果，有助于实现每个类别的成果。
* 信息性参考指向对组织试图实现每个子类别相关成果有益的行业标准、指南和实践。NIST将这些信息性参考归类为“说明性且非详尽的”。信息性参考基于“框架开发过程中最常引用的跨部门指导”。您甚至可以按照以下网站概述的说明提交参考以供考虑：[`https://www.nist.gov/cyberframework/reference-submission-page`](`https://www.nist.gov/cyberframework/reference-submission-page`)。

### 识别

识别功能包括定义需要保护的流程和资产的类别和子类别。它用于开发理解，以便分析和管理对系统、资产、数据和能力的网络安全风险。[图16-4](`#ch16.xhtml#ch16fig04`)显示了识别功能类别。
