# 4.1.1 Arous convolutions and their impact

One major improvement in DeepLab was the use of atrous convolutions, also referred to as dilated convolutions. Dilations also increase the receptive field of the convolutional layers by adding zeros between the filters, thus widening the field of vision without leaving out high-resolution features in the maps. This design choice allows DeepLab to capture more contextual information at multiple scales, enhancing its ability to segment objects with varying sizes and shapes. The use of atrous convolutions addresses the limitations of traditional convolutions, which typically require downsampling to achieve a larger receptive field, leading to loss of spatial detail.

# 4.1.2 DeepLab’s spatial pyramid pooling module

Consequently, integrating spatial pyramid pooling (SPP) module in DeepLab resulted in even better performance because of the multiscale pooling used to gather contextual information. The SPP module uses ASPP to apply atrous convolutions at different rates, effectively capturing context at multiple scales. This approach allows the network to combine features from different resolutions, improving the segmentation of objects that span various sizes. The integration of ASPP into the DeepLab architecture provides a robust mechanism for handling the diverse range of object scales and complexities found in real-world images.
