FCNs are used in the final stages of many deep learning structures, especially CNNs, for feature extraction in classification problems. Figure 14 specifies that fully connected layers in neural networks allow coupling of features extracted by previous layers and generate the final output by applying weights and biases learned in the set of input features. Classification targets, such as class scores for classification tasks, and targets generating continuous values, are created by the fully connected layers, which process information gathered and represented by convolutional layers.

Because of the highly connected nodes in fully connected layers, the model had the ability to distinguish between multiple patterns and correlations present in the datasets. These layers summon all previous layers and use their features to capture subtle contingencies between characteristics. It was useful for jobs that involved understanding the larger picture, such as categorizing pictures.

It was also understood that deep learning models are more flexible and capable when the layers of both networks are fully coupled. You can modify the number of such layers as well as the neurons embedded in these layers to enhance the learning capacity of the given model from data. This is because fully linked layers with more nodes have much higher capabilities to overfit and require more computation to accommodate more complex information. Therefore, model capacity and generalization need to be achieved in a well-designed way through regularization.

In deep learning models, fully connected layers play a critical role in connecting feature extraction and the final prediction phase. By constantly being involved in the process as a feature aggregator, the ability to learn intricate features and patterns and move on to output prediction makes the architecture vital in delivering high performance in various DNN tasks.
