In the case of anomaly detection, it is highly important that data from different domains are fused properly for accuracy. Feature-level fusion refers to the integration of features extracted from some specific domain at an intermediate stage of the feature extraction process, so as to allow the model to learn a set of shared representation. Decision-level fusion integrates the outputs of the specific domains, thereby allowing various processing before the ultimate decision is reached. The recent trends include attention-based fusion, which assigns special emphasis to the contributions from domains as per their suitability to be incorporated in the anomaly detection process, in turn increasing the levels of interpretability as well as accuracy.
