## 2.2 Autoencoders for unsupervised feature extraction in supervised models

The application of autoencoders for feature learning in supervised anomaly detection systems has become a favorite strategy, especially in cases of data with many features such as image and video data. Autoencoders are NNs that are intended to transform the source input data into a compact and low-dimensional feature space by means of encoding output, in which the model retrieves input. This process enables encoding of the underlying structure of the data, thus making autoencoders appropriate in unsupervised learning where features to be learnt are useful, and no labels are available. Autoencoders can be used in the constituent steps of anomaly detection and extract unique features from raw unlabeled data that can be used in subsequent supervised learning models for anomaly detection with higher accuracy.

How autoencoders work: they use an NN to minimize the loss of the data being passed through them and in the reconstructed data they pay special attention to the features of normal data and hence are preferred for anomaly detection because of the learned latent representation. If an autoencoder learns from a set, which consists of only normal instances, it is able to reconstruct the instances quite well. This occurs because during the reconstruction, a conventional AE fails to map and reconstruct the peculiar, unseen patterns typical of the anomalous data that the model is tested with. It is then possible to come up with an indicator for anomaly detection by comparing the two results obtained above.

The major advantage of applying clustering in conjunction with classification resides in the detection of noise, specifically within an environment where there exists limited data. Considering the context of anomaly detection, it is ascertained that these are the measurements, which do not fit well into particular cluster and are located at the boundary of the formed clusters. The clustering technique is widely applied during the integration process as a preprocessing approach. Collectively, intermediate steps including proper transformations of the data for clustering result in grouped clusters of similar data. Once clusters are formed, a classification model including SVMs was trained for this purpose using labeled data. The clustering results used as the input features for the classifier add more information and make the classifier more general to detect anomalies.

The other method of using clustering and classification for anomaly detection was under semisupervised learning. Thus, the use of the clustering algorithm can be made to partition the unlabeled data into preliminary clusters. Subsequently, on a small labeled subset of the entire network, the classification model was trained and then run over the clustering groups in order to detect outliers within the groups. This method presents the advantages inherent in the use of unsupervised clustering to find out the groups of similar patterns with the subsequent classification to assign definite labels to the anomalous patterns in a supervised manner. The integration of both unsupervised learning for data discovery and supervised learning for prediction provides an efficient paradigm for solving anomaly detection problems with limited annotated data.

It is also important to combine clustering with classification through ensemble learning, where the result is obtained from a number of clustering algorithms. For example, the model combines clustering algorithms including k-means, DBSCAN, and Gaussian mixture models (GMM) and hence covers a wide variety of cluster shapes. Subsequently, a classification model is trained on the aggregation of the above clustering results, which enables the system to more effectively detect anomalies using multiple clustering facets of data. Such an ensemble learning strategy improves the reliability and efficiency of the anomaly detection model based on the fact that certain data sets have multiple underlying structures.

Although the integration of clustering and classification has many advantages, several problems appear crucial when employing this two-step approach. There is the problem of identifying the clustering algorithms that are relevant for a particular dataset. A given number of clusters can be found in different locations of the data space;

the distribution, noise, and density of the data influence the clustering solutions. It was thus imperative to select the correct clustering algorithm in a way that identified anomalous points have application relevance.

A problem that arises in this type of approach relates to when the data has many features, as it can cause issue with both clustering and classification. Since working with high-dimensional data the principal distances between the objects are less meaningful because of the “curse of dimensionality.” This problem can be solved by the projection for the lower dimensionality by common methods for example principal component analysis (PCA).

Integrating clustering with classification in order to detect anomalies seems highly feasible. This combined approach gives the capacity to detect irregularities that cannot be easily distinguished using the two methodologies. The application of clustering algorithm to discover the inherent structures of the data and classification models for definitive labeling of these discovered group structures lead to improved accuracy, flexibility, and robustness of the anomaly detection systems.

## 2.4 Enhancing robustness of anomaly detection through hybrid supervised and unsupervised learning

The combination of supervised and unsupervised learning approaches for anomaly detection has been a focus of much research interest in the past few years as it holds the potential to improve the general performance, and especially the robustness of a detection system in realistic problems. Figure 3 shows that while supervised learning models are very accurate when new labeled data is available, there are instances where they are hard to find. Indeed, the use of such techniques as clustering and outlier detection allows discovering new patterns without the provision of the training data set but it could also be problematic because of their inexact demarcation of decision regions. It is seen that through integration of ideas from both strategies, there is the likelihood of developing enhanced accuracy, flexibility, and robustness of the models used in anomaly detection.

Majority of the hybrid anomaly detection methods use a technique known as unsupervised learning to test the structures of the data. These known methods like the clustering algorithms (k-means, DBSCAN), etc., and dimensionality reduction (PCA, t-SNE), etc., can help in grouping similar data by features hitherto unknown. These unsupervised models aid in detecting regions of datasets that are most likely to contain outliers, given the fact that samples that do not belong to the learned clusters and have now fitted the assumed distribution are flagged by the algorithms. Yet, although these models can point to potential outliers, they do not have the capacity to classify these records definitively as outliers, without measuring specific features. That is where supervised models come into play.
