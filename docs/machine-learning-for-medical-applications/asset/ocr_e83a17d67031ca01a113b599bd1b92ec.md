# 3.2.2 Problems in data storage and management for big data

Due to the large cumulative size of imaging datasets, their storage and modalities of handling necessitate significantly large computing power and hardware. The current conventional storage systems face a problem in responding to the expanding data storage demands, resulting in problems such as data congestion and slow data access. Any large dataset thus requires scalable means of storage such as cloud storage systems and high-capacity storage arrays. Therefore, the data management practice must provide assurance on the quality, security, and retrievability of imaging data, which makes the data management process complex.
