# 5.1 Methods for handling missing or incomplete data in scaffold studies

Dealing with missing and incomplete values starts with determining the degree and types of missing data present. Determining whether missing data were missing completely at random (MCAR) or missing at random (MAR) is important for choosing the right techniques. It becomes the task of researchers to determine whether data were missing in MCAR, or MAR. This assessment is useful for selecting the methods for closing the gaps and ensuring that the integrity of the dataset is maintained.

Several procedures for handling missing values that involve estimation of the values with various techniques are called imputation methods. For numerical data, common methods include mean imputation, median imputation, and mode imputation; whereas for categorical data, most important category imputation can be employed. Other techniques are more complex and include, for example, multiple imputations, where the missing values are filled several times, creating several datasets, and then the results obtained regarding the variables with missing data are pooled as a measurement of the uncertainty under imputation. Besides that, classical methods that belong to the class of stacking algorithms include multiple imputations based on following the distribution of the neighbors, regression imputations, KNN, and other methods based on artificial intelligence, with the assistance of which missing values can be predicted based on data patterns.
