This approach is superior to the single-modal systems, where data from a single source is analyzed, as such systems do not collect enough information spectrum necessary to produce accurate anomalies [3–10]. Combined presentation of multimodal data facilitates detection of marginal patterns that could not be identified when analyzing each data set separately, thus enhancing the possibility of accurate diagnosis and optimization of workflow. Especially in areas where multiple couplings and interdependences are present, as for instance industrial production, diagnostics, and real-time monitoring, this integrated approach proves to be highly beneficial.

Many approaches have been created to make it easier to integrate and analyze multimodal data in order to find anomalies [11]. Two important methods are decision-level fusion, which integrates the outputs of distinct models trained on several modalities, and feature-level fusion, which combines data features from various modalities before classification [12]. Model-level fusion further extends these methods by combining multiple machine learning models that individually process different modalities [13]. Newer additions have also included deep learning, and graph-based methods that improve the feature of modeling high order relations and interactions in multimodal data. While graph-based approach highlights data correlation using complex graph structures, CNN and RNN models are efficient in feature extraction and fusion of multiple high-dimensional data.

The use of multimodal anomaly detection is across several important areas, while each gains from the capacity to fuse and analyze different types of information [14]. For example, in industrial manufacture, integration of data obtained through visual inspection, in combination with sensors, fare greatly in detecting defects and enhancing manufacturing processes [15]. There are numerous digital cases that show how information obtained from high-definition cameras and machine tools can help decrease the defect rates and improve the product quality across the automotive segment. In the same manner, combining data from the MRI and the CT scans with patient health records in the medical field has resulted in correct diagnoses and good treatment plans. Real-time monitoring systems adopted in smart cities and self-driving cars also owe their ability to recognize anomalous events across multiple modalities in order to improve awareness and increase safety [16].

Multimodal data integration has benefits, but in order to reach its full potential, a number of issues need to be resolved [17]. Given that the quantity and complexity of data rise with the number of modalities and data sources, scalability is a major concern [18]. Managing large-scale data integration requires robust storage solutions and efficient computational resources. Real-time processing is another challenge, particularly in dynamic environments where data needs to be processed and analyzed instantaneously [19].
