A critical challenge in segmentation was maintaining high-resolution predictions throughout the network, especially after multiple downsampling operations (such as pooling and strided convolutions), which are typical in traditional CNN architectures. Fully Convolutional Networks (FCNs) addressed this issue through a process known as upsampling. By applying learned upsampling layers, FCNs could restore the spatial resolution of feature maps, enabling the network to produce high-resolution predictions. As shown in Figure 1, FCNs also utilized skip connections to fuse high-level semantic information from deeper layers with low-level spatial details from earlier layers. This integration helped refine segmentation boundaries and capture finer details key to tasks like edge detection and object delineation.
