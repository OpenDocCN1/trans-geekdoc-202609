### 4.3 Metrics for assessing model performance (e.g., accuracy, precision, and recall)

The fitness, accuracy, and reliability of the models for the intended application in scaffold design can only be ascertained by assessing the performance of the predictive models. Performance of a model is normally measured by different criteria, each of which provides information on a particular aspect of the model’s fitness for prediction.

Accuracy is another commonly used statistic that looks at how well the model is at identifying the instances in the dataset, with a percentage indicating how well it is able to do so correctly. It is important for a model to be accurate, but accuracy generally is rather an indication of the overall nature of the model set.

The second important measure is precision, which is calculated as the ratio of true positives, that is, instances where the model is 100% confident of being positive, to all positive instances the model predicted. Precision measures the model's ability to avoid making wrong positive predictions. This is crucial in various fields such as drug and diagnostics, where it should avoid wrong positive predictions.

Recall shows the proportion of all actual positive cases in the collection correctly identified as such by the true positive predictions. It is occasionally called the true sensitivity. If false negatives are to be avoided at all costs, as in the case of a disease, then recall presents information about how well the model can identify all positive cases, true positives.

The F1-score is a combined parameter that equals the harmonic mean between the precision and the recall value. F1-score is a unified evaluation measure in model performance that can provide necessary additional information for datasets that are imbalanced, as it always prioritizes both precision and recall.

In binary classification tasks, there is a statistic known as the area under the ROC curve (AUC-ROC), which is often used to measure the ability of the model to distinguish between positive and negative events at various thresholds. AUC-ROC is particularly useful when assessing the discriminative ability of the model, as it encompasses all relevant information about the model's performance for all possible classification thresholds.

As we have already seen for regression problems, there are MAE and MSE that estimate the average of the difference between the target values and the predictions. The variable MAE is used to calculate the average of the absolute difference between the expected and actual values, and the average of the squared difference is calculated by MSE. ### 4.5 Interpretability of machine learning models in scaffold design

Relating the input data to output predictions and identifying the variables that affect the scaffold attributes and performance rely heavily on the interpretability of the machine learning models in scaffold design. Explainability is the ability to clearly explain decisions and easily understand why such decisions have been taken in order to distinguish important features, behavior of the model, and limitations.

Several methods improve the interpretability of machine learning models in scaffold design. One approach includes employing models with minimal complexity, like decision trees, linear regression, etc. These models provide comparatively easily interpretable coefficients that map input data to the output forecasts. Such models are very useful to understand how one aspect influences some performance and the qualities of the scaffold.

Another approach to model interpretation is feature importance analysis, which tracks how much of an impact each piece of input information has on the model parameters' estimates. Techniques like partial dependence plots, SHAP, and permutation feature importance can tell us how certain attributes and characteristics have an effect on the model. Through feature ranking, researchers can gain vital information on what aspects have significant effects on scaffold design outcomes, to design better scaffolds.

The representations of decision boundaries and model predictions are visualization techniques that can enhance the machine learning model's interpretability. The arrangement of the feature space is described, local density of clusters in the data can be identified, and the relation between the input features and output predictions can be visualized using existing instruments such as scatter plots, heat maps, and dimensionality reduction algorithms (t-SNE, UMAP, and others). Through visual information, researchers are able to identify certain sorts of outlying observations and also have more extensive information about the model's performance.

Any machine learning model can be used to give explanations regarding individual predicted values by using model-agnostic methods such as LIME and SHAP. These create local single-case analyses that explain how each of the characteristics of the input leads to a specific prediction, and enable the researcher to understand the rationale of the given model.

The formulation of interpretable machine learning models for scaffold design determines whether it can reveal pertinent characteristics, provide understanding of the cause of scaffold qualities and performance, and enhance model reliability and validity. They enhance the transparency of the ML models, actively using feature importance analysis, visualization, simple models, and model-agnostic interpretation techniques.

## 5 Optimization techniques

### 5.1 Overview of optimization algorithms used in scaffold design

Optimization algorithms are especially helpful in scaffold design because they are used to aid in finding solutions to problems that are best described using high dimensions in the design space. These algorithms are used for tuning any of the aspects of scaffold characteristics and functionality, such as material and scaffold architecture and fabrication process variables. Many optimization methods have been incorporated in scaffold design with varying success, flexibility, and suitability to certain design contexts.

Gradient algorithms are one of the optimization methods that determine the direction of optimization for design variables and are updated until the criterion has been met. These algorithms, namely quasi-Newton, gradient descent, and conjugate gradient descent, are used to optimize many objective functions that are continuous and are functions of a single differentiable variable. Shape and material characteristics of a scaffold are especially suitable for these methods, as the objective function can be presented as a continuous function of design variables.

Because of their capability in coping with nonlinearity, discontinuity, and multimodality in the objective function, in addition to the capability of exploring enormously large solution spaces, the evolutionary algorithms that stem from the principles of natural selection and hereditary features are widely used in scaffold design. These include simulated annealing, genetic algorithms (GAs), differential evolution (DE), and particle swarm optimization. To enhance the fitness of a population of candidate solutions with respect to the objective function, these algorithms, for example, use selection, crossover, mutation, etc. and iteratively build the population. GAs are very useful in searching through large complex design domains and also in cases where the design function has several local optima and is discrete and/or nonlinear.

Due to their ability to effectively and efficiently find near-optimal solutions in large solution spaces, metaheuristic algorithms like the firefly algorithm, ant colony optimization, as well as the artificial bee colony, are applied to scaffold design. These algorithms are inspired by collective behaviors and physical processes.
