# 2.2 Autoencoders for unsupervised feature extraction in supervised models

The application of autoencoders for feature learning in supervised anomaly detection systems has become a favorite strategy, especially in cases of data with many features such as image and video data. Autoencoders are NNs that are intended to transform the source input data into a compact and low-dimensional feature space by means of encoding output, in which the model retrieves input. This process enables encoding of the underlying structure of the data, thus making autoencoders appropriate in unsupervised learning where features to be learnt are useful, and no labels are available. Autoencoders can be used in the constituent steps of anomaly detection and extract unique features from raw unlabeled data that can be used in substitute supervised learning models for anomaly detection with higher accuracy.

How autoencoders work: they use an NN to minimize the loss of the data being passed through them and in the reconstructed data they pay special attention to the features of normal data and hence are preferred for anomaly detection because of the learned latent representation. If an autoencoder learns from a set, which consists of only normal instances, it is able to reconstruct the instances quite well. This occurs because during the reconstruction, a conventional AE fails to map and reconstruct the peculiar, unseen patterns typical of the anomalous data that the model is tested with.
