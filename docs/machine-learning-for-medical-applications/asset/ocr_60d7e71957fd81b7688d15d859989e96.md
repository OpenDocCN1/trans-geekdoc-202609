# 4.1.4 Evolution of DeepLab models

DeepLab framework has evolved over time, with successive releases having improvements and additions of different strategies. ASPP module was introduced in DeepLabv2 that enhanced the contextual aggregation to a very great extent. To extend DeepLabv3, the authors introduced global pooling to the design and improved the ASPP mechanism. DeepLabv3+ integration of the characteristics of previous models with an encoder-decoder structure made enhancements in boundary definition and segmentation. Every new transformation of the DeepLab architecture represents learning from the previous versions for addressing particular concerns.
