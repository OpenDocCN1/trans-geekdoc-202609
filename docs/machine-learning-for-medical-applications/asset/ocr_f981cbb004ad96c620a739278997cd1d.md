# 3 Traditional segmentation techniques

# 3.1 Thresholding methods

Fixed-level thresholding and Otsu’s method belong to the simplest type of the methods of image segmentation that are applied mostly to the simple bi-level segmentation. These approaches involve putting an image in different zones using pixel intensity values, and hence are well-suited for basic and well-defined problems of segmentation.

There are basically four main principles that are followed while selecting thresholding.

By fixing the intensity value at a certain threshold level, it becomes possible to distinguish between the background and the foreground of an image. Foreground pixels are defined as those having intensity values greater than the threshold “T,” while background pixels have values less than “T.” This technique is particularly effective when there is a clear intensity contrast between regions of interest and the background.
