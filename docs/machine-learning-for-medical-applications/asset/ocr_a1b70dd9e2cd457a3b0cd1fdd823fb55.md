# 3.2 Boosting and bagging in anomaly detection systems

Boosting and bagging are two common types of ensemble learning techniques employed in detecting anomalous patterns because of their effectiveness in improving the outcomes and tolerance to noise of corresponding learners. Such techniques utilize more base models and produce a more reliable and stable overall prediction, which is particularly important in the case of outlier detection. Anomalies are by their very nature uncommon and do not conform to typical procedures in data, which make their identification difficult. Trials increase and bagging address this problem by summing up the outcome produced by various base learners in order to enhance the training functionality and reduce mistakes. Despite being categorized under ensemble learning techniques, each method has a different perspective when handling the problem and each has its strengths in anomaly detection scenarios.

Bagging is an ensemble technique that involves training multiple and unrelated models of the training data with different random samples of data. These subsets are generated by selecting a subset of data with replacement, then passing the new subset of data to the next model. Subsequent to training, the individual models perform prediction and the results are ensembled through averaging (of residuals/root mean square error for regression type problems). The use of bagging lowers the variance of the model as the results of the individual learners are averaged out so that overfitting is avoided, which is common with high-variance models like decision trees.

Bagging is helpful because it allows the detection system to identify the noise and presence of high variance that is present in real databases. Since anomalies are rare and have a high variability, bagging can stabilize the detection process using multiple base models, while introducing deviations from the intake. For instance, in random forest model which belongs to a bagging-based method, the decision trees are trained on different samples of the data, and the outcome from all the trees is used to make a conclusion of whether a data point was an anomaly. Such a method is useful because even if an anomaly is missed by some of the individual trees at the time when built, with a large number of trees, the anomaly is likely to show up somewhere once all trees collectively make their prediction.

A common problem with anomaly detection tasks is class imbalance where majority of instances belong to the normal class. This problem is addressed in the bagging process because when each model has a different view of the data it provides the ensemble a better chance to identify those infrequent and obscured patterns. Overall, bagging minimizes the chances of false negatives, that is, it makes sure that outliers are detected regardless of how rarely they are encountered during training data.

Whereas, boosting is another kind of ensemble technique in which one model builds another model successively and the current model tries to minimize the mistakes of the previous model. Unlike bagging whose models are trained separately, boosting builds on the outputs of the previous weak learner models by focusing on the difficult sample points that previous models misclassify.
