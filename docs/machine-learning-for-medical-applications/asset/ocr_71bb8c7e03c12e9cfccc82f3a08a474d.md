# 4.5.4 Regulatory and ethical of healthcare

The rules for the application of DL-based segmentation tools in practice are still being discussed. It is very important for these health enhancing tools to meet medical device regulations for them to be approved in the market. Concerns like data ownership, model bias, and model fairness must be taken into consideration to ensure that these tools are used rightly.

# 4.5.6 Future prospects

The possibility for additional developments with future work of DL-based segmentation in the clinical practice exists. Future work includes building more stable and semantically flexible models; increasing the speed of the real-time processing to optimize it; and combining different imaging data modalities to increase the segmentation accuracy. Also, improvements in explainable AI and better graphic user interfaces continue to enable the enhanced use of such technologies in clinical practice.

The application of DL-based algorithms in medical picture segmentation is a revolution in the field of healthcare, which was capable of enhancing clinical effectiveness and accuracy of several diagnoses. This will enhance the actualization of these technologies in clinical practice but the challenges associated with these technologies must be addressed, while success gained from the effective implementation of these technologies should be exploited.
