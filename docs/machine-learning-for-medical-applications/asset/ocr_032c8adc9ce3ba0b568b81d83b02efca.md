U-Net and SegNet.These architectures expanded on the FCN structure by enhancing the effectiveness and speed of segmentation tasks. Additionally, various FCN variants emerged, incorporating multiscale features to improve performance in complex scene segmentation. While newer models have since been developed, the FCN remains a foundational deep learning architecture and continues to serve as a benchmark for evaluating segmentation approaches.

# 2.3 SegNet

Existing deep learning architecture SegNet was another of the first designs introduced for semantic image segmentation to serve the purpose of pixel-wise classification in high-dimensional images. Designed with a flavor of computer efficiency and memory utilization, SegNet had proposed an encoder-decoder network with high-performance balance. Its design was driven from the problem of obtaining the high-level feature representation while keeping the spatial information needed for pixel-level segmentation. It was for this reason that the SegNet’s approach would have been ideal for use in applications such as compact and real-time image understanding in real-world scenes such as road scenes.

SegNet’s fundamental architecture was an encoder-decoder framework. The encoder mimics well-known CNN architectures, such as VGG-16, by employing pooling and convolutional layers to extract hierarchical features from the input image while gradually lowering its spatial resolution. In order for the model to identify intricate patterns in the image, the encoder’s job was to record abstract representations of the input at different scales. In contrast, the decoder upsamples the encoded features in an attempt to rebuild the high-resolution segmentation map.

A key feature of SegNet’s decoder was the use of max-pooling indices from the encoder stage during the upsampling process. Instead of learning new parameters for upsampling, SegNet reuses the indices from the max-pooling layers in the encoder to perform nonparametric upsampling. This strategy reduces the number of parameters in the decoder, making the network more computationally efficient while also helping to preserve the boundary information critical for segmentation tasks.

One of the distinguishing innovations of SegNet was the use of pooling indices for upsampling in the decoder. Traditional upsampling methods often rely on deconvolution (transposed convolution) layers, which require learning additional parameters, and increase the computational burden. In contrast, SegNet’s nonparametric approach uses the indices from the max-pooling layers to guide the upsampling process. By recording the location of the maximum activation during pooling, SegNet ensures that the upsampled feature maps retain important spatial information from the original input image, leading to more accurate segmentation, especially along object boundaries.
