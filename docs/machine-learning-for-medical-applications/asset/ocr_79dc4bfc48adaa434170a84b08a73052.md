# 5 Reinforcement learning enhanced hybrid models

# 5.1 Reinforcement learning for adaptive anomaly detection

The RL was a particularly useful approach to adaptive anomaly detection because it provides the systems with an opportunity to develop the best strategies according to the discovered environment. Unlike supervised learning, the RL agents do not depend upon some fixed databases. Instead, they learn the policies that maximize the reward signal and this was why they were successfully applicable to the detection of anomalies in a changeable and uncertain world. In the context of anomaly detection, a reward function can be tailored to focus on the correct identification of the anomalies while at the same time lowering the rate of false positives, to make the system agile enough to adapt to a different scenario with different data distribution.
