### ReLU
Due to the problem of vanishing gradients in previous activation functions, the introduction of ReLU activation functions boosted network performance, accelerated the training phase, and imposed nonlinearity.

### Overlapping pooling
Instead of employing fully connected layers, the feature map dimensions were reduced, but important spatial information was maintained by using overlapping max-pooling.

### Data augmentation
Due to the fact that the amount of training data was relatively small, attempts were made to artificially increase it through data augmentation techniques such as picture translation and horizontal flipping.

### Dropout regularization
To avoid the issue of overfitting, dropout layers were added in the fully connected layers during training, where during each epoch, neurons were set to zero at random.

VGGNet, released by the Visual Geometry Group at Oxford, also built further deep learning architectures by focusing on simplicity as well as depth in 2014. The VGGNet architecture, specifically VGG16 and VGG19, introduced several key innovations:

### Uniform convolutional layers
In its architecture, VGGNet used only very small filters of 3 × 3 and operated only 2 × 2 pooling throughout the network. As one of the design principles of the small filter, this aspect focused on small and stacked filters to extract the intricacies of the pattern as well as hierarchical features.

### Increased depth
To increase the depth of convolutional networks, VGGNet proposed 16- and 19-layer configurations, and showed that net depth could be effectively increased without overly complex arrangements.

### Consistent pooling strategy
The consistent application of 2 × 2 max pooling layers in the network means that feature maps and spatial information decrease progressively but systematically, hence ensuring good feature extraction.

### Large fully connected layers
VGGNet used large fully connected layers near the end of the VGGNet architecture, which allowed high-level classification using the features extracted from the image based on the reasoning done by the model.

### Pretrained models
VGGNet made large-scale pretrained models more common, introducing transfer learning in several computer vision tasks and establishing a baseline for later architectures.

## 4.3 Convolutional layers and operations

CNNs, which are mandatory tools in contemporary deep learning frameworks for computer vision systems, mainly constitute convolutional layers. These layers facilitate the optimal identification of patterns and objects with the help of efficient automation, along with the ability of the network to learn spatial hierarchies of information from the input pictures.

![](img/18722240e44c225d7ff2f58a10eecb4a_36_0.png)

**Figure 12:** Convolutional layers and operations.

The main purpose of a given convolutional layer was to convolve the input image through a given series of filters known as kernels. As shown in Figure 12, the convolution layers and operations that happen in a deep learning model for feature extraction from images are explained. Each filter was multiplied by an element in the feature maps and added to a small matrix and then shifted over the input image to give out feature maps. The convolution was a sort of layer that helped the network to perceive local features in the input data, such as edges, textures, and form. By employing many filters, the network was able to obtain quite many attributes from the image.

At the time of convolution, the stride defines the manner in which, in terms of distance, the filter is shifted over the input image. This, when it comes to greater strides, results in the reduction of the output feature map’s spatial dimensions as the filter moves one pixel at a time when the stride is set to 1. Padding, as a technique in the convolution process, involves the expansion of the input picture by incorporating extra pixels at the edges to ensure the entire picture is in contact with the filter set. As much as padding assists in the preservation of the spatial dimension, it also increases control over the size of the feature map output.

After the convolution process, the resultant feature maps are passed through an activation function. The ReLU, which has become the most popular activation function in convolution layers, effectively introduces nonlinearity through certain modifications: the positive input values remain intact, while the negative input values all but vanish. The nonlinear nature helps the network to express itself more fully and to acquire more complex patterns.

Pooling layers are normally applied with the convolutional layers in order to restrict the spatial size of the feature maps and therefore decrease the computational complexity and the level of overfitting. ### Reduction of computational complexity
Pooling layers decrease the dimensionality of feature maps and thus require a smaller number of parameters and computations in subsequent levels. The reduction in computational complexity means there are faster times for both inference and training.

### Control overfitting
Hence, pooling layers serve as a kind of regularization, which makes the model more general. As prerequisites of the subsequent evaluation, downsampling makes little changes in the input insignificant for the network and introduces translational invariance, which in turn minimizes overfitting.

### Feature extraction
This means that necessary characteristics from the input data were retained and extracted with the help of pooling layers. The network was capable of rejecting components of an input image that are less useful for segmentation, yet it was able to focus on the primary values inside each pooling window.

The use of pooling layers shrinks the dimensions of feature maps, thus losing the spatial resolution of the data. Taking into account the positive impact that lower computing costs and better feature representation bring, this compromise is often justified. In order to develop various increasingly abstract representations of input data for achieving high performance in tasks such as object recognition and picture categorization, pooling layers play a significant role.
