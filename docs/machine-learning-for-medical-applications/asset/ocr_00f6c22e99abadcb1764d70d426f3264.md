When the models are conceptually different, then, they detect different types of anomaly because anomalies present many entity and feature patterns that an individual model find difficult to identify. For instance, in a situation where we have different type of anomalies present in a given data set, one model performs well when it comes to identifying certain kinds of anomaly, while another model performs well in identifying other kinds of anomaly. By fusing these models, the net outcome of the ensemble improves in its ability to detect a wider variety of anomalies in comparison to any one constituent model of the ensemble, and therefore yields a better global anomaly detection system.

Effective change of ensembles in the context of anomaly detection and its diversification was recognized and one of the methods is the use of different subsets of the data during the formation of each of the models included in the ensemble. This can be done by using techniques such as bagging where each model is developed when some data randomly chosen from the training data is used where each model is developed when the difficult instances for the previous models to learn are used. By training models on different portions of the data the ensemble knows about different parts of the underlying data distribution. Such a spread of the training data also enables the ensemble to generalize better and become less sensitive to noise and outliers, both of which are typical for the anomaly detection problem.

Besides in the data that the system uses to train, different learning algorithms can be used within the ensemble to temporarily increase the level of diversity. For example, some models within the ensemble method would be decision trees while other could implement SVM. The reason for joining several learning algorithms is that each of the learning methods has its advantages and is equipped for different patterns and discovers various sorts of anomalies. Popular algorithms such as decision trees, for instance, can address categorical features as well as nonlinear decision margins while SVMs do well in features spaces that are high. Due to the synergy of several algorithms, the ensemble can be enhanced in such a way as to have increased ability to identify anomalous events in various data types.

Architectural difference is another crucial element that improves variety in ensemble-based anomaly identification. The performance does not remain the same even within the learning algorithm, as variations are possible within the classifier model’s architecture. For example, a deep structure that contains more than one hidden layer develops the capability of identifying patterns inherent to the data set, while a shallow work develops the capability of identifying straightforward characteristics in the data set. It is also noteworthy that by including models with different depth, the ensemble can enhance its capacity to recognize patterns that are largely anomalous. This diversity in the architecture helps build a reliable anomaly detection system because different aspects of the data are utilized by the different components of the pipeline.
