Sobel and Prewitt operators: First used in the 1960s, such operators were among the first to point out edge detection in images through illumination of parts with large difference in intensity. These simple edge detection methods serve as the foundation for advanced edge detection methods that are used to segment medical images and to extract features from the images.

Canny edge detector: The Canny edge detector designed in 1986 was superior to previous works in that it used a multistage algorithm to detect all kinds of edges in noisy images. This algorithm is still one of the principal methods of image analysis for edge and structure detection in medical images.

# 2.3.1 Image filtering techniques for introductory courses

Gaussian filtering: The method of using Gaussian filters for image smoothing and noise removing gained popularity in the 1970s. Gaussian filtering is used in medical imaging for preprocessing of images in a way that the noise is eliminated allowing for readability of significant features.
