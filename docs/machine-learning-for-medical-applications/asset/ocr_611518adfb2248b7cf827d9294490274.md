# 5.4 Policy gradient methods for online anomaly detection
in visual data

Policy gradient methods constitute one of RL that aims at the direct optimization of decision-making policies by adjusting the policies through gradient ascent in the policy space. Usually, these methods present a higher level of flexibility combined with increased robustness in considering the dynamics and dimensionality of the anomaly detection problem in the context of visual data of the Web. While other methods rely on steep RL focusing on value, policy gradient is specifically designed for action spaces where a range of values can be recommended and stochastic systems, which were widely relevant for RTAD, since patterns and anomalies are dynamic by their nature.

Policy gradients entail defining a stochastic policy that can be controlled by a vector of parameters for the input states that are extracted from the visual data during the data classification process as normal. The policy is again maximized over a cumulative reward function that quantifies both the accuracy of the detections and their speed. In the case of the online detection, the system works with constant flow of the visual data and updates the policy in a step-by-step mode starting from the rewards that are being acquired by it. Such flexible learning capability enables the model to make little changes and fine-tuning towards better detection.

For policy gradient methods that have been described above the performance is highly dependent on the state representation that is derived from visual data. CNNs are used to extract features from raw images, which are used as inputs to the RL agent encompassing spatial and contextual information required for effective anomaly detection. Techniques like image normalization and augmentation are used in order to increase the quality of extracted features. Using these state representations, the policy gradient model is allowed to learn the deviations and denote an anomaly in real time.

Interpreting and designing a proper reward function should be an important step for improving the policy in the anomaly detection tasks. Several works have described that rewards are given concerning the performance of classification by the system and false positives and false negatives are penalized, whereas true detections are rewarded.
