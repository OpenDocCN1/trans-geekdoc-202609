# 5.1.1 Data preparation

The first step in data preparation was identifying and gathering a large and diverse dataset that was correctly labeled to suit the particular computer vision assignment at hand. This can involve collecting images and labeling them with ground truth using tags and object classes, respectively. Proper labeling was crucial to the process because the quality of annotations greatly affects the model's learning capacity for accurate prediction.

Correcting errors in inconsistent records was referred to as data cleansing. This was where I removed redundant images, corrected wrong tags, and dealt with any issues within the data. When it becomes important to train a model that does well when applied to new data, it is crucial that the dataset used to train the model is proper and clean.

The dataset typically consists of three subsets: test, validation, and training sets. Some of the techniques for preparing and supplementing data are explained in Figure 15 to enhance the variety and quality of training sets of models so as to achieve better results. The training set was employed for the development of the model, the validation set for tuning the hyperparameters, and the test set for the final measurement of model quality. Proper splitting of data eliminated overfitting and confirmed that the performance of the model was estimated against unknown data.

For the pixel values to be scaled and ensure they are standardized throughout the dataset, normalization and standardization are used. Standardization involves transforming pixel values so that they have a mean equal to 0 and a standard deviation of 1, while normalization typically means that pixel values are scaled within the range of 0 to 1. These procedures help in fine-tuning the process and making it converge, as well as bringing stability to training.
