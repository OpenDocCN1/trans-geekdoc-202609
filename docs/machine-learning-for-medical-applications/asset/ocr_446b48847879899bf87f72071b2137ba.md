The latest development in edge detection methods has been the formulation of adaptive and more so multi-scale edge detection techniques, which improve the results of edge detection under different image conditions. The integration with machine learning and DL also improve the edge detection capability; the models can learn specific image characteristics. These innovations help in achieving even higher accuracy in segmenting medical images to identify the necessary characteristics, to represent disease symptoms and develop proper diagnostic and therapeutic strategies.

Papers also still consider edge detection methods as vital tools for medical image segmentation since they provide the required information for structure and pathologic areas. The continued development of these algorithms with incorporation of modern computational techniques underlines the tenability of their contributions for enhancing medical image processing.

# 3.4 Clustering-based approaches

This approach to segmenting medical images has been widely used for many years as a powerful and general framework for partitioning images based on similarity criteria. These techniques operate on the principle that image pixels with similar features such as intensity or texture can be grouped into distinct clusters. # 3.4.1 *k*-Means clustering

*k*-Means clustering is one of the most employed clustering methods for picture division. From this approach, a picture was divided into *k* clusters through iterated assignment of each pixel to the closest cluster centroid; the centroids on the other hand update according to the mean of the assigned pixels. *k*-Means is useful and simplistic in terms of segmenting pictures that mainly had fairly equal means with clear partitions. Note that the algorithm is sensitive to the initialization and requires the number of clusters to be prespecified, thus limiting its applicability.

# 3.4.2 Gaussian mixture models (GMMs)

Gaussian mixture models (GMMs) are an extension of *k*-means that make any assumption that data was produced from a number of Gaussian distributions.
