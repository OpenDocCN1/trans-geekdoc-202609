# 2 Data acquisition and preprocessing

# 2.1 Sources of scaffold material data

Data acquisition and data preprocessing are critical factors that determine the potential and reliability of input data for predictive modeling in scaffold structure design. Data acquisition process means to collect information that relates to the scaffold materials in the context of the present project from repositories, research databases, and experimental works. To enhance the coverage and balance of the data collected for the scaffold design, it is essential to properly select data sources that would cover all types of properties, fabrication techniques, and biological factors. Consulting with tissue engineering and materials science specialists helps define which datasets should be collected, and guarantees that all the information necessary for analysis is collected.

Cleaning and formatting of the collected raw data is done through preprocessing procedures when the data is retrieved. This calls for several activities, amongst them being data cleaning to eliminate errors, gaps, and scrubs that pose a threat to the analysis. Missing data is handled in the context of the imputation process within the dataset in order to avoid having a lot of gaps in an analyzed value set.
