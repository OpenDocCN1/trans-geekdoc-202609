# 2.5 Advantages and limitations of deep learning

High performance on complex problems: Deep learning models perform very well on complex tasks that require working with large, high-dimensionality datasets. Significant progress has been demonstrated in some fields like speech recognition, picture identification, and natural language processing because of their ability to learn feature extraction from raw data.

Feature extraction: Most of the described typical machine learning approaches involve feature engineering, but deep learning chooses interesting features on its own as part of the data preprocessing step. Therefore, this capability decreases the amount of time spent on preprocessing and domain knowledge, eliminating time wastage in the development process.

Scalability and adaptability: Big data-based deep learning models have been adaptive to large data and occur along with advanced computational power. They are flexible, easily tunable, and scale up well with large quantities of data as more data is fed into the system. This scalability of the proposed model affords improvements in model accuracy and reliability over time.

Flexibility across domains: In fact, deep learning is very versatile and can be applied in almost every field and field of study.
