Data augmentation: Due to the fact that the amount of training data was relatively small, attempts were made to artificially increase it through data augmentation techniques such as picture translation and horizontal flipping.

Dropout regularization: To avoid the issue of overfitting, dropout layers were added in the fully connected layers during training, where during each epoch, neurons were set to zero at random.

VGGNet, released by the Visual Geometry Group at Oxford, also built further deep learning architectures by focusing on simplicity as well as depth in 2014. The VGGNet architecture, specifically VGG16 and VGG19, introduced several key innovations:

Uniform convolutional layers: In its architecture, VGGNet used only very small filters of 3 × 3 and operated only 2 × 2 pooling throughout the network. As one of the design principles of the small filter, this aspect focused on small and stacked filters to extract the intricacies of the pattern as well as hierarchical features.

Increased depth: To increase the depth of convolutional networks, VGGNet proposed 16- and 19-layer configurations, and showed that net depth could be effectively increased without overly complex arrangements.

Consistent pooling strategy: The consistent application of 2 × 2 max pooling layers in the network means that feature maps and spatial information decrease progressively but systematically, hence ensuring good feature extraction.

Large fully connected layers: VGGNet used large fully connected layers near the end of the VGGNet architecture, which allowed high-level classification using the features extracted from the image based on the reasoning done by the model.

Pretrained models: VGGNet made large-scale pretrained models more common, introducing transfer learning in several computer vision tasks and establishing a baseline for later architectures.

GoogLeNet, proposed by Google in 2014, pioneered the use of several inception modules. Key features of GoogLeNet include:

The network established an inception module, where more than two convolutional algorithms with different kernel sizes and pooling layers were used. In this approach, the model was able to cover a variety of sizes of characteristics in a single layer.

Network-in-network layers: The architecture of GoogLeNet used 1 × 1 convolutions as network-in-network layers in order to decrease the amount of computation while maintaining good features.

Global average pooling: Rather than using fully connected layers, GoogLeNet uses global average pooling, which is referred to as capsule,. It minimizes the number of parameters and overfits the feature maps to provide the classification output.

Efficient design: The incorporation of inception modules and working on the dimensions of the network enable the authors to design a network that has many fewer parameters while retaining low computational complexity and good accuracy.
