This integrated architecture is more suitable for high-dimensional data; its raw input contains spatial dependencies that are tough to be processed by normal ML algorithms. This way, the system can extract features from various depths of the image, which is important in finding anomalies while employing CNNs for feature extraction. The autoencoder proceeds in a compressed latent space, which again makes the process of detecting outliers more effective and less susceptible to overlearning than when solely using CNNs. It therefore becomes apparent that utilization of the hybrid CNN-autoencoder model makes it easier for the system to generalize and be able to identify anomalous data in a new unseen dataset.

Training any autoencoder CNN model is a delicate process especially if it is a CNN-autoencoder since the training of two of the phases – the features and reconstructions must be done at the same time. While training the CNN identifies important features within the input data and the AE reconstructs the input data using the features it was trained with. The usual loss function used for this task is the combination of the reconstruction of the autoencoder and the classification of the CNN if used in the supervised learning context. This at the same time enables the model to learn not only the normal spatial features but also the distribution of the data. The last score is obtained based on reconstruction error, whereby a higher error results in a high anomaly score.

In practice, CNN-autoencoder hybrid models have been applied in various types of systems, for example, for recognizing vision impaired items in manufacturing, diagnosis of unusual medical images such as tumors, and surveilling security camera videos for strange behaviors. For instance, in medical applications such as diagnosis of X-ray, CNNs extract spatial features, which are then fed to an autoencoder to learn normal patterns of healthy tissues. Any discrepancy in the normal reconstruction, for example, due to the existence of a tumor, would give a higher reconstruction error, as an indication of an anomaly. Likewise, CNNs can recognize motioning objects in video surveillance; the autoencoder recognizes an average motion pattern that was typical. For instance, if a person defies rules and moves to a prohibited zone, the system can identify it based on reconstruction error.
