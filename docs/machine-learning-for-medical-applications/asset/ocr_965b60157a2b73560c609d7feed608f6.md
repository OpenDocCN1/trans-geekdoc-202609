Contextual information was a subtle aspect of metadata that comprises location and time stamp, which provides the model with the needed interpretability aspect in developing anomaly detection models. As an extra dimension of data, metadata assists in explaining peculiarities found in images readings. For example, one detects the visual defect, which is important only during some operating conditions described in the metadata. This modality provides an integration of an intermediate result of the sensor and image data, providing a complete perspective of the anomaly context.

Efficient fusion of the image, sensor, and metadata modalities must therefore incorporate solutions to the problem of modality fusion. Feature-level fusion takes raw-level features from each modality to enable the model to learn the joint representations. The decision-level fusion synthesizes results from the diverse unimodal models so that different modalities are examined individually before reaching the final decision. Combining both strategies is done in hybrid methods, allowing the system to utilize both modality-specific and cross-modal data. Read attention capabilities, as well as multimodal autoencoders, improve the capacity to attend and focus on relevant features.

Multimodal anomaly detection frameworks introduced for hybrid models have correspondent structures for each data type. CNNs are applied on the image data and the sensor data is processed using another form of model commonly referred to as temporal models including LSTMs. Metadata was combined with other modalities through an embedding layer mechanism, making it visualizable. These architectures are integrated such that the layers in one formulation interact with those in another, thus allowing modality switches. These models are useful in capturing spatial, temporal, and contextual features, and hence enhance the overall detection of the models.

# 6.3 Cross-domain anomaly detection using hybrid neural networks

Anomaly detection across domains implies the detection of old anomalies in datasets drawn from different domains: vision, audio, and sensor data. This approach is crucial in cases when anomalies happen within rather different kinds of data, which are situated in various domains. Hybrid NN forms a versatile solution in cases where specialized NNs are developed for each of the domains to provide full-scale anomaly detection.

The domain-restricted cross-anomaly detection problem is solved through using a hybrid NN that comprises domain-specific models within a single architecture. For instance CNNs are used on spatial features from images; LSTM networks are used for temporal features in sequential sensor data. Through integration of these architectures, it is possible to analyze features from different domains at the same time; therefore, the intra-domain as well as the inter-domain correlation is possible.
