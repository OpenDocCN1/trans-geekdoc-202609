# 4.3 Metrics for assessing model performance (e.g., accuracy, precision, and recall)

The fitness, accuracy, and reliability of the models for the intended application in scaffold design can only be ascertained by assessing the performance of the predictive models. Performance of a model is normally measured by different criteria, each of which provides information on a particular aspect of the model’s fitness for prediction.

Accuracy is another commonly used statistic that looks at how well the model is at in identifying the instances in the dataset, with a figure percentage indicating how well it is able to do so correctly. It is important for a model to be accurate, but accuracy generally is rather an indication of the overall nature of the model set.

The second important measure is accuracy, which is calculated as the ratio of true positives, that is, instances where the model is 100% confident of being positive, to all positive instances the model predicted. Precision measures the model's ability of avoid making wrong positive predictions. This is crucial in various fields such as drug and diagnostics, where it should avoid wrong positive predictions.

Recall shows the proportion of all actual positive cases in the collection correctly identified as such by the true positive predictions. It is occasionally called the true sensitivity. If false negatives are to be avoided at all costs, as in the case of a disease, then recall presents information about how well the model can identify all positive cases, true positives.

The F1-score is a combined parameter that equals the harmonic mean between the recognition accuracy and the recall value. F1-score is a unified evaluation measure in model performance that can provide necessary additional information for datasets that are imbalanced; as always prioritize both precision and recall.

In binary classification tasks, there is a statistic known as ROC curves of area under curve (AUC-ROC), which is often used to measure the ability of the model to distinguish between a positive and negative event at various thresholds. AUC-ROC is particularly useful when assessing the discriminative ability of the model, as it encompasses action of all relevant information about the model's performance for all possible classification thresholds.

As we have already seen for regression problems, there are MAE and MSE that estimate the average of the difference between the target values and the predictions. The variable MAE is used to calculate the average of the absolute difference between the expected and actual values, and the average of the squared difference is calculated by MSE.
