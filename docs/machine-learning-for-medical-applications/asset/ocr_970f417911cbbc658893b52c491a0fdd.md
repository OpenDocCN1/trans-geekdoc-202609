# 3.4 Optimizing ensemble models for imbalanced anomaly detection datasets

There are always a large number of normal instances that overwhelm the small number of instances in an anomaly dataset and this brings a lot of challenges. In such datasets, traditional ML models, including ensemble methods often have a problem of classifying the minority class. This skewed distribution affects performance since models are inclined to the majority category and yield high false negatives for anomalies. Mitigating this challenge is needed in order to evaluate the replication of ensemble model optimization methodologies that can improve class imbalance yet retain effective anomaly detection on the financial data.

One of the main approaches that help fine-tune the ensemble models for imbalanced anomaly detection is the proper tuning of decision thresholds. In general, in ML models, the decision boundary is established for an instance to be classified as anomalous depending on the probability/score set a priori. Balancing the loads for unbalanced datasets presents a big problem in that the default threshold for training tends to overpredict the normal class. By reducing the decision threshold for flagging anomalies, the ensemble model is in a position to achieve higher sensitivity to the minority class. This adjustment is made to generalize more data as anomalous, thereby achieving higher recall of uncommon cases at the possible instance of lower precision. The question mark is about the need to achieve the best compromise between precision and recall in order to maintain high efficiency of the model.

Another technique using ensemble-based method for the treatment of class imbalance in anomaly detection is the resampling technique including oversampling the minority class and undersampling the majority class. Oversampling duplicates some specimens from the category of interest to make them more present in data sets, and undersampling does the reverse to normal samples. Such measures can assist in reducing the impact of imbalance of the majority class on the performance of the ensemble while at the same time enhancing the capability of the model to identify anomalies. To improve the model learning, other approaches as SMOTE (synthetic minority oversampling technique) create new artificial instances of the minority class. But the selection of resampling technique has to be done judiciously because wrong application can result in to overfitting and underfitting of the model.
