Gaining insight into the robustness of the model involves determining how well the model performs in cases where the input data is altered. Sensitivity analysis studies the shift in the performance of a model due to changes in the characteristics of inputs or hyperparameters. Through such assessments, the applicability and reliability of the model in actual practice situations are enhanced.

Hyperparameter adjustment and model assessment are essential stages in the deep learning model creation pipeline. While tuning makes the model perform very well, evaluation helps to ensure that the model is good enough to perform well in a variety of other situations, as would be desired.

# 6 Impact of deep learning on computer vision applications

# 6.1 Improvements in image classification accuracy

In particular, deep learning has brought about changes in image classification, improving many applications across various fields. CNNs have brought about improvements in the level of precision and effectiveness of image classification systems dominated by deep learning models.

Starting with natural scenes, deep learning models learn easy-to-hard feature representations of the input image. Each convolutional network has a lower layer that encodes basic features such as edges and textures and deep layers that encode complex features such as structures. That is why, due to the hierarchical feature extraction, important and weak features, which tend to be ignored by standard methods, are captured by models, providing better understanding and classification of pictures.
