# 6.5 Evaluating the impact of data quality on predictive model performance

This outstanding data quality was a crucial determinant of the performance of the models when applied to the biodegradable scaffold research. The quality of the data was the foundation of accurate and reliable models that provide data that was relevant and accurate, from which scaffolds’ degradation and stability could be predicted. With this kind of data, there was little room for error. On the other hand, poor data quality, defined by data errors, duplication, and missing values in the wrong format, produces unpredictable model results, misinterpretation, and consequently, wrong decisions.

Various problems, like the wrong variable measurement and variable labeling, can greatly harm the model’s quality. Machine learning uses data to learn, and these values are literally fed to the model; thus, errors in the data set impact the generality of the model and the accuracy of its predictions. For instance, mistakes in the recorded degradation rates properties entail producing wrong estimates of the scaffold performance in the future. Judging the degree of inaccuracy affects the precision of models; this requires comparing several parameters such as mean squared error, R-squared, and other similar measures, as well as comparing the model results with the actual results obtained from the database.

Other points that are considered critical to the models include missing data. When some parameters are missing, models either drop the records or make assumptions, both of which affect the accuracy of the predictions. If the dataset is not complete, one loses some variability within the data, which generalizes the model. Methods like data filling should be adopted based on how they would affect the accuracy of a model. The specifications for strong models of missing data plans should be checked thoroughly by simulation against different probabilities of missing observations.
