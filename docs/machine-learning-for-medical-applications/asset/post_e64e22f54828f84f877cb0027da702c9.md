## 5.3 Gradient descent and backpropagation

The evaluation of gradient descent and backpropagation algorithms was considered critical in training deep learning models, especially while optimizing neural networks in computer vision applications.

### 5.3.1 Gradient descent

Gradient descent is an optimization process of iteratively modifying model parameters’ values in a way that seeks to minimize the loss function of a neural network. The goal is to identify the correct configuration parameters by which the difference between estimated outputs and actual goals can be minimized.

In the gradient descent process, there was identification of how each model parameter contributes to the loss function. This analysis also showed which direction the parameters should be turned in order to minimize the loss. The change of each parameter was controlled by the learning rate at the specific step at which the change occurred. In order to reduce the values of the loss function, the settings are adjusted.

There were also hyperparameters that influenced how many steps were performed to minimize the loss: the learning rate was among them. Therefore, the model achieved an optimal solution when the learning rate was chosen appropriately in order to provide an efficient convergence rate. Figure 17 shows an illustration of gradient descent using backpropagation to minimize the loss function in order to arrive at the best weights and biases for the neural network. A low learning rate resulted in slow convergence, while a high learning rate resulted in the model going beyond the right parameters.

There are various methods used in gradient descent to make it more effective, as well as to ensure it converges well during the training stage. Among them are:

- **Batch gradient descent:** This can be computationally expensive when working with large datasets because the gradient is computed using the entire data.
- **SGD:** This introduces noise but can increase the speed of convergence and help come out of local minima as it updates parameters for each datum.
- **Mini-batch gradient descent:** This is a hybrid possessing aspects of both batch and stochastic gradient descent, but updates using only a subset of the data, making it fast enough while being stable enough in convergence.

Hyperparameter adjustment and model assessment are essential stages in the deep learning model creation pipeline. While tuning makes the model perform very well, evaluation helps to ensure that the model is good enough to perform well in a variety of other situations, as would be desired.

## 6 Impact of deep learning on computer vision applications

### 6.1 Improvements in image classification accuracy

In particular, deep learning has brought about changes in image classification, improving many applications across various fields. CNNs have brought about improvements in the level of precision and effectiveness of image classification systems dominated by deep learning models.

Starting with natural scenes, deep learning models learn easy-to-hard feature representations of the input image. Each convolutional network has a lower layer that encodes basic features such as edges and textures and deep layers that encode complex features such as structures. That is why, due to the hierarchical feature extraction, important and weak features, which tend to be ignored by standard methods, are captured by models, providing better understanding and classification of pictures.

Higher levels of network architectures have been implemented and have helped to advance performance in image classification. A number of current models, including AlexNet, VGGNet, GoogLeNet, and ResNet, have proposed different techniques, deeper architectures, inception modules, and residual connections. Transfer learning techniques, which involve the use of fine-tuning when given a number of pretrained models for specific tasks, entail using broad dataset experience to achieve high accuracy from fewer and more specific datasets.

Advanced image classification has also seen positive improvements through data augmentation, which artificially expands training data.
