## 5.3 Combining reinforcement learning with autoencoders for dynamic anomaly detection

The combination of RL with autoencoders is the present landmark on the horizon of dynamic anomaly detection. RL can be used for decision making in uncertain and dynamic contexts and autoencoders are good at feature extraction and reconstruction-based anomaly detection. The combination of both methods allows for efficient flagging of anomalies in datasets that are usually large and especially so in dynamic systems. This way, we propose a way to update the autoencoders’ reconstruction error as feedback for RL agents while retaining accurate anomaly detection throughout the system.

The hybrid architecture consists of two core components: the structure of the autoencoder and that of the RL agent. The autoencoder consists of an encoder/decoder network, which condenses the data to a latent representation and reconstructs it back. The reconstruction error is calculated as the difference between the input and the output. This error is one of the inputs to a feature signal in the RL agent, so it persists in a continuing learning process. The RL agent maps reconstructed states, which are latent between input and reconstruction, to actions such as evaluating the data as normal examination. This architecture keeps the system strong and flexible, so that even in uncertain conditions it does not deteriorate.

Autoencoders are another key component of this hybrid model of analyzing high-volume data because they help condense such data while identifying essential features that point to outliers. Due to their capability for learning the unsupervised representation they are ideal in cases of unorganized data sets. An inclusive measure, the reconstruction error, was also an ideal tool to use since it maps the difference between the input and the output. These errors are used not only for the anomaly detection but also as the input for reinforcing the RL agent where the unsupervised and RL mechanisms are employed concurrently.

The RL component refines the anomaly detection process by allowing appropriate action in complex scenarios. From the outlined reward-shaping strategy, the agent learns to detect patterns within errors in reconstruction and the best approaches to improving these detection strategies over successive instances of the cumulative reward function. It is also pointed out that scoring for the reward system can be structured to discourage false positives and false negatives in addition to encouraging the identification of actual anomalies. Given that the RL agent periodically relearns all the policies, the system inherently possesses the flexibility to dynamically adapt to changes in the data distributions.

## 5.4 Policy gradient methods for online anomaly detection in visual data

Policy gradient methods constitute a branch of RL that aims at the direct optimization of decision-making policies by adjusting the policies through gradient ascent in the policy space. Usually, these methods present a higher level of flexibility combined with increased robustness in considering the dynamics and dimensionality of the anomaly detection problem in the context of visual data of the Web. While other methods rely on deep RL focusing on value, policy gradient is specifically designed for action spaces where a range of values can be recommended and stochastic systems, which were widely relevant for RTAD, since patterns and anomalies are dynamic by their nature.

Policy gradients entail defining a stochastic policy that can be controlled by a vector of parameters for the input states that are extracted from the visual data during the data classification process as normal. The policy is then maximized over a cumulative reward function that quantifies both the accuracy of the detections and their speed. In the case of online detection, the system works with a constant flow of the visual data and updates the policy in a step-by-step mode starting from the rewards that are being acquired by it. Such flexible learning capability enables the model to make little changes and fine-tuning towards better detection.

For policy gradient methods that have been described above, the performance is highly dependent on the state representation that is derived from visual data. CNNs are used to extract features from raw images, which are used as inputs to the RL agent encompassing spatial and contextual information required for effective anomaly detection. Techniques like image normalization and augmentation are used in order to increase the quality of extracted features. Using these state representations, the policy gradient model is allowed to learn the deviations and denote an anomaly in real time.

Several works have described that rewards are given concerning the performance of classification by the system, and false positives and false negatives are penalized, whereas true detections are rewarded.
