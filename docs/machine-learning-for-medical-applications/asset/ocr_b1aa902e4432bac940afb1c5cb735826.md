# 1 Introduction

Scanned visual information was incorporated in essential applications like industrial automation, healthcare diagnostics, and security systems and the demand for reliable and efficient approaches to contouring anomalies has scaled up [1]. Abnormalities in the optical signals point to defects and irregularities, which require reliable schemes for detection in order to maintain system and decision-making reliability [2]. Some anomaly detection techniques were rule-based and statistical models, which are not so effective in the case of large high-dimensional data [3]. These limitations are a result of the discrete methods utilized in the algorithms, where fixed thresholds and assumptions cannot capture to a great extent the variability of data sets in real-life scenario [4].

Traditionally implemented techniques cannot handle these issues, for which machine learning (ML) models enjoy popularity due to their data pattern learning capability to handle them [5]. The regular approaches enumerated as SVMs and PCA have remained popular for conducting anomaly detection [6]. These approaches sometimes suffer from many issues such as how to handle big data and feature extraction at higher dimension of vision databases [7]. But deep learning has brought the next level of enhancement to this field mainly in aspects of feature learning and enhanced detection capability [8]. The convolutional neural network (CNN) and autoencoder are decidedly remarkable for spatial patterns and tiny variances in intensified scanned images [9].

Modern trends in the sphere have pointed towards the efforts to complement the existing and novel ML approaches with context-specific requirements to increase the detection performance [10, 11]. To deal with the issues of data imbalance, real-time adaptability, and time complexities, different supervised and unsupervised learning methodologies including reinforcement learning (RL) models have been put forward [12]. The overlaying of explainable AI (XAI) approaches has become a prominent region of study for enhancing the explainability of anomaly detection frameworks, thus increasing trust and usefulness in applications that entail high levels of risk. Here we present advanced ML models for anomaly detection on scanned visual data that try to balance accuracy and complexity [13–15].
