

深度学习的出现显著改变了 NLP 的格局。基于神经网络的模型，尤其是使用 `Long Short-Term Memory (LSTM)` 网络和 `Transformer` 等架构的模型，因其能够更有效地处理词序列及其上下文，已成为标准。例如，`Transformer` 模型由 Vaswani 等人在论文 "Attention is All You Need" 中提出，具有特别革命性。该模型摒弃了传统的循环架构，转而采用注意力机制，帮助模型根据需要关注输入序列的不同部分，从而提高了性能和训练速度。

`Transformer` 架构最值得注意的实现之一是在 `BERT`（Bidirectional Encoder Representations from Transformers，双向编码器表示）和 `GPT`（Generative Pre-trained Transformer，生成式预训练 Transformer）等模型中。`BERT` 设计用于通过在所有层上同时以左右上下文为条件来预训练深度双向表示。因此，经过预训练的 `BERT` 模型只需添加一个额外的输出层即可微调，从而为各种任务创建最先进的模型，例如问答和语言推理，而无需进行实质性的任务特定架构修改。

另一方面，`GPT` 使用左到右的架构，其中每个 token 在 `Transformer` 的自注意力层中只能关注之前的 token。这种设计使 `GPT` 能够基于给定的提示生成连贯且上下文相关的文本，使其在文本生成等任务中非常有效。

机器学习中的 NLP 还涉及对文本数据的显著预处理。这包括分词（将文本分解为单词或子词）、规范化（将文本转换为更一致的格式，如小写）和向量化（将文本转换为数值格式，以便机器学习模型能够理解）。向量化的一种流行方法是词嵌入，其中单词根据其语义含义表示为连续向量空间中的稠密向量。`Word2Vec` 和 `GloVe` 是创建此类嵌入的模型的例子。

尽管取得了进步，机器学习中的 NLP 仍面临重大挑战。人类语言中的歧义、文化细微差别以及语言不断演变的特性使 NLP 成为一个动态挑战的领域。此外，训练数据中的偏见以及深度学习模型的黑箱特性所带来的问题，随着 NLP 技术在日常应用中变得更加普遍，构成了需要解决的伦理和运营挑战。

总体而言，NLP 是机器学习更广泛格局中的关键组成部分，提供了使计算机能够以人类自己的语言与人类交互的基本能力，从而弥合了人类交流与计算理解之间的差距。

## 文本预处理和分词

`TEXT PREPROCESSING` 和分词是自然语言处理（`NLP`）领域的根本步骤，`NLP` 是机器学习的一个子领域，专注于计算机与人类语言之间的交互。文本预处理是将原始文本数据准备成适合机器学习模型处理的合适且一致格式的过程。分词是一种特定的文本预处理类型，涉及将文本划分为较小的部分，例如单词或短语，这些部分更容易被算法解释。

文本预处理的第一个步骤通常涉及清理文本。这可能包括删除特殊字符、纠正拼写错误，以及如果文本是从网络抓取的，则消除 HTML 标签。这至关重要，因为数据质量和一致性直接影响机器学习模型的性能。另一个常见任务是将所有文本转换为小写。这有助于减少数据的复杂性并避免同一单词的多个副本。例如，如果不转换为相同大小写，“Dog”和“dog”将被机器学习模型视为两个不同的词。

规范化是文本预处理的另一个关键方面。它涉及将单词的不同形式转换为单一、一致的形式。这可能包括词干提取和词形还原。词干提取将单词缩减为其基本或词根形式，通常导致本身不是有效单词的形式。例如，“running”、“runner”和“ran”都可能被缩减为“run”。词形还原另一方面涉及将单词缩减为其基本或词典形式，但它与词干提取不同之处在于它确保词根属于该语言。例如，“better”将被转换为“good”。此过程有助于减少文本中唯一单词的总数，从而简化模型的复杂性。

停用词移除是另一个预处理步骤，涉及消除可能对句子意义贡献不大的常见词。诸如“and”、“is”和“the”等词通常从文本中删除。其背后的理由是这些词在各种文本中频繁出现，通常不携带重要含义，因此它们的存在可能会稀释模型学习文本中更相关词的能力。

在初始清理和规范化之后，分词就发挥作用了。分词是将文本拆分为 token 的过程，这些 token 可以是单词、字符或子词。这是一个关键步骤，因为大多数机器学习模型，特别是 NLP 中使用的模型，并不以原始文本作为输入，而是使用数值数据。分词允许将文本转换为稍后在机器学习管道中可向量化（转换为数值形式）的格式。

分词有几种方法。最简单形式是空白分词，其中文本基于空格拆分，每个词都被视为一个 token。然而，这种方法对于标点符号在句子含义中起关键作用的复杂文本可能是不够的。因此，需要基于标点的分词，其中 token 在空格之外也在标点符号处拆分。更复杂的方法使用机器学习模型本身来预测最佳拆分位置，同时考虑语言的语言学特征。

子词分词是另一种高级分词形式，它将单词拆分为较小的有意义单元（子词或音节）。这种方法对于处理训练期间未见的罕见词或词特别有用。通过将单词分解为常见的子词，模型可以在测试期间更好地处理未知词。像字节对编码（`BPE`）或 `WordPiece` 这样的技术是 `BERT` 和 `GPT` 等模型中使用的流行子词分词方法。

分词完成后，下一步通常是将这些 token 转换为向量，即向量化过程。这至关重要，因为机器学习算法使用数字而不是文本。每个 token 被分配一个唯一的整数，此过程可以简单到创建所有唯一单词的字典。然而，更复杂的方法涉及嵌入，其中单词根据其语义相似性在连续向量空间中表示。`Word2Vec` 和 `GloVe` 是嵌入技术的例子，它们比简单的独热编码捕获更多上下文信息。

总之，文本预处理和分词是将原始文本为 NLP 中的机器学习模型做准备的关键步骤。这些步骤涉及清理和规范化文本、删除无关词、将文本分解为可管理的 token，并最终将这些 token 转换为机器学习模型可以处理的数值形式。每一步都至关重要，因为它直接影响模型的效率和有效性，影响文本分类、情感分析和机器翻译等任务中的训练过程和最终结果。
