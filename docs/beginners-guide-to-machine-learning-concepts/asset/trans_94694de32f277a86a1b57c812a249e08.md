

# 层次聚类概述

尽管存在这些挑战，层次聚类在许多领域中被广泛使用，例如生物学（用于基因和蛋白质序列分析）、金融（用于投资组合管理）和语言学（用于历史比较分析）等。在这些应用中，聚类的层次结构可以为数据提供有价值的见解，例如识别自然分组、理解数据结构以及执行数据降维。

在机器学习中，层次聚类通常与其他聚类技术进行比较和结合，以增强模型的鲁棒性和准确性。例如，它可以与降维技术如 `PCA`（主成分分析）结合使用，以改善聚类结果的可视化。此外，层次聚类可以作为初步步骤来确定适当的聚类数量，该数量可作为 `k-means` 聚类的输入，结合层次和划分方法的优势。

总体而言，层次聚类仍然是机器学习工具箱中的一种强大工具，为理解复杂数据集提供了一种灵活且富有洞察力的方法。它能够创建聚类的层次结构，并且无需预先指定聚类数量，这使其在数据点关系和分组至关重要的数据分析场景中具有独特地位。

## 基于密度的空间聚类（DBSCAN）

`DENSITY-BASED SPATIAL Clustering of Applications with Noise`（`DBSCAN`）是一种流行的聚类算法，用于机器学习中识别数据中任意形状的聚类。与其他需要预先指定聚类数量的聚类方法不同，`DBSCAN` 根据数据本身确定聚类数量，使其在聚类数量事先未知的情况下的应用中特别有用。

`DBSCAN` 背后的基本思想是通过识别彼此之间由低密度区域分隔的高密度区域，将紧密排列的点分组在一起。为此，`DBSCAN` 依赖于两个主要参数：epsilon（`ε`）和形成密集区域所需的最小点数（`minPts`）。`Epsilon` 定义了点周围邻域的半径，而 `minPts` 指定了在此邻域内所需的最小点数以将其视为密集区域。

`DBSCAN` 首先在数据集中随机选择一个点。如果该点在其 `ε`-邻域内至少有 `minPts`，则它构成新聚类的初始核心点。然后，`DBSCAN` 迭代收集从该核心点密度可达的所有点，这涉及查找已添加到聚类中的所有点 `ε`-邻域内的所有点。此过程一直持续到无法再向聚类添加新点为止。然后选择一个新的未访问点并重复该过程，可能导致发现额外的聚类。

`DBSCAN` 的优势之一是其处理噪声的能力。不属于任何聚类的点被归类为噪声，使 `DBSCAN` 对异常值具有鲁棒性。这一特性在现实世界的数据分析中特别有利，因为异常值和噪声很常见。此外，`DBSCAN` 发现任意形状聚类的能力使其优于假设聚类为球形的算法如 `k-means`。

然而，`DBSCAN` 的性能高度依赖于 `ε` 和 `minPts` 的选择。不合适的 `ε` 选择可能会合并单独的聚类或将单个聚类分割成多个聚类。同样，`minPts` 的较小值可能会导致噪声点数量增加，而较大的值可能会抑制较小聚类的形成。选择这些参数通常需要领域知识或启发式方法，尽管诸如 `k-distance plot` 之类的方法可以通过显示 `ε` 如何与数据集的密度分布相关来提供指导。

就计算复杂度而言，`DBSCAN` 相当高效，在假设使用索引结构存储数据点以进行快速邻域查询的情况下，其时间复杂度为 `O(n log n)`。如果没有此类索引结构，复杂度可能会退化为 `O(n²)`，使其对于非常大的数据集计算成本高昂。尽管如此，`DBSCAN` 的效率和简单性使其在各种应用中成为一种流行选择，包括图像分割、GPS 导航数据分析和网络流量中的异常检测。

`DBSCAN` 也已被以各种方式扩展和改编以增强其性能和适用性。例如，广义 `DBSCAN`（`GDBSCAN`）允许聚类标准在 `ε`-邻域密度标准之外进行自定义，以适应不同类型的数据和关系。另一个变体，`HDBSCAN`（层次 `DBSCAN`），通过将其转换为层次聚类算法来扩展 `DBSCAN`，它不仅可以找到不同密度的聚类，还提供了一个层次结构，可用于在不同尺度上理解数据结构。

在实践中，`DBSCAN` 在对具有噪声的复杂数据集进行聚类方面的有效性及其对参数调整的领域知识需求最小（与其它算法相比）使其成为机器学习从业者工具库中的宝贵工具。它在探索性数据分析中的实用性，在理解数据的内在结构比遵循特定聚类模型更重要的情况下，凸显了其多功能性和在科学和工业领域中的广泛适用性。

总体而言，`DBSCAN` 仍然是机器学习中一种强大且广泛使用的聚类算法，以其简单性、效率和所产生聚类的质量而受到赞赏。无论是处理空间数据、识别网络中的社区，还是根据消费者行为对市场进行细分，`DBSCAN` 都提供了一种稳健、无假设的方法来理解复杂数据集中潜在的模式。

## 评估聚类模型

`EVALUATING CLUSTERING` 模型在机器学习中是一项关键任务，有助于确定所用聚类算法的有效性。与由于存在真实标签（实际标签）而评估指标直接的监督学习模型不同，聚类模型通常以无监督方式进行评估，因为真实标签未知。这使得聚类模型的评估既具有挑战性又有趣。

用于评估聚类模型质量的主要指标之一是 `Silhouette Score`。该指标衡量对象与其自身聚类的相似程度与与其他聚类的相似程度。`Silhouette Score` 的取值范围为 -1 到 1，其中较高的值表示对象与其自身聚类匹配良好且与邻近聚类匹配较差。如果大多数对象的值较高，则聚类配置是合适的。然而，如果许多点具有较低或负分，则可能表明聚类重叠或定义不正确。

另一个流行的指标是 `Davies-Bouldin Index`，这是一种内部评估方案，其中使用数据集固有的数量和特征来验证聚类是否做得好。较低的 `Davies-Bouldin Index` 表示更好的划分。它本质上衡量每个聚类与其最相似的聚类之间的平均相似度，其中相似度是比较聚类之间的距离与聚类本身大小的度量。
