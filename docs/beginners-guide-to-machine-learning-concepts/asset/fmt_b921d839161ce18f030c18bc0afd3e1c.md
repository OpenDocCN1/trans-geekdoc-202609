### Basics of reinforcement learning

Reinforcement learning (`RL`) is a type of machine learning where an agent learns to make decisions by interacting with an environment. Unlike supervised learning where the model is trained with the correct answers (labels), in reinforcement learning, the agent learns from the consequences of its actions. It receives rewards by performing correctly and penalties for making errors. The goal of the agent is to maximize the total reward it receives over time.

The fundamental components of any reinforcement learning system are the agent, the environment, the state, the action, and the reward. The agent represents the decision-maker, the environment includes everything the agent interacts with, the state is a snapshot of the environment at any given time, actions are what the agent can do, and the reward is feedback from the environment based on the actions taken by the agent.

One of the key concepts in reinforcement learning is the policy. A policy is a strategy that the agent employs to determine its actions based on the current state. Policies can be deterministic, where a specific action is chosen for a given state, or stochastic, where an action is chosen based on a probability distribution. The quality of a policy is often measured by a value function, which estimates how good it is to be in a given state or to perform a certain action in a state. The ultimate goal in many RL scenarios is to find the optimal policy that maximizes the cumulative reward.
