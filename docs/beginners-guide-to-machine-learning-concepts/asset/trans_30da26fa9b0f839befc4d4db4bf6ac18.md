

# 自编码器

一个 `autoencoder` 学习将输入数据压缩（编码）成更短的形式，然后重构（解码）输出以匹配原始输入。这些网络被称为“自编码器”，因为它们编码自己的结构。通常，一个 `autoencoder` 由两个主要部分组成：`encoder` 和 `decoder`。`encoder` 压缩输入，而 `decoder` 尝试从这种压缩表示中重建输入。`autoencoder` 的性能通常通过比较输出与输入来衡量；两者越接近，模型的性能越好。

## 架构

`autoencoder` 的架构可以描述为一个瓶颈。输入层和输出层的大小相同，并且有若干隐藏层，其大小向中心层递减，中心层代表编码后的数据。中心层包含输入数据的压缩知识表示，通常远小于输入层的大小。这种压缩数据随后通过网络的 `decoder` 部分扩展回原始输入大小。

## 训练

训练 `autoencoder` 涉及典型的 `backpropagation` 技术。使用的损失函数通常是输入与输出之间的均方误差（`MSE`），尽管根据具体应用也可以使用其他损失函数，例如二进制输入数据的 `binary cross-entropy`。目标是最小化损失函数，使模型产生的输出尽可能接近输入，从而在无监督的情况下有效学习数据的关键特征。

## 应用

`Autoencoders` 对于特征选择和提取任务特别有用。通过学习忽略数据中的噪声并捕捉底层模式，`autoencoders` 可以在与其他机器学习模型结合使用时帮助提高其性能。这在数据未标记的场景中尤其有用，因为 `autoencoders` 无需标签即可从数据中学习。这使它们成为无监督学习任务中的强大工具。

## 自编码器的类型

有几种类型的 `autoencoders`，每种都有独特的特点，适用于不同类型的任务。例如，`Sparse autoencoders` 在隐藏层上施加稀疏性约束，迫使模型对输入数据的独特统计特征做出响应。另一方面，`Denoising autoencoders` 经过训练以从数据中去除噪声。它们通过有意向输入数据添加噪声并训练网络恢复原始未损坏的输入来工作。这种类型的 `autoencoder` 在输入数据预期存在噪声或需要预处理时特别有用。

`Variational autoencoders (VAEs)` 是另一个重要的变体。与传统的 `autoencoders` 不同，`VAEs` 建立在概率模型之上，为潜在空间中的输入数据提供统计描述。它们不仅学习压缩数据，还学习生成与输入数据相似的新数据。这种特性使 `VAEs` 在生成模型中极其有用，其目标不仅是识别或分类输入数据，而是生成新的数据实例。

`Autoencoders` 也可以堆叠形成更深的网络，通常称为 `stacked autoencoders`。`stacked autoencoder` 中的每一层通常学习编码前一层的输出，提供输入数据的深度层次表示。这种方法在逐层学习复杂数据结构时可能特别有效。

## 局限性

尽管应用广泛，`autoencoders` 仍存在局限性。它们本质上是有损的，这意味着输出不会完全匹配输入。在精度至关重要的应用中，这可能存在问题。此外，`autoencoders` 容易过拟合，尤其是当网络架构相对于输入数据量过于复杂时。

总之，`autoencoders` 是机器学习领域中多功能且强大的工具。它们提供了一种稳健的无监督数据学习方法，使其适用于标记数据稀缺或不可用的众多场景。无论是用于降维、特征提取，还是作为更复杂模型中的构建块，`autoencoders` 都是现代机器学习生态系统中的关键组成部分。

# 生成对抗网络 (GANs)

`GENERATIVE ADVERSARIAL Networks (GANs)` 是一类在无监督机器学习中使用的生成式人工智能算法，由两个神经网络系统实现，它们在零和博弈框架中相互竞争。该技术由 Ian Goodfellow 及其同事于 2014 年提出，此后一直是积极研究和大幅改进的领域。`GANs` 因其能够生成非常高质量、逼真的图像，甚至可与实际照片无法区分而受到广泛关注。

## 核心思想

`GANs` 的核心思想是设置两个竞争网络之间的游戏：`generator` 和 `discriminator`。`generator` 的任务是创建尽可能逼真的数据，试图欺骗 `discriminator`。另一方面，`discriminator` 的任务是准确判断接收到的数据来自真实数据集还是由 `generator` 生成。通过训练，`generator` 不断提高创建虚假数据的能力，而 `discriminator` 则变得更擅长识别这些伪造数据。这种对抗过程导致生成非常高质量的数据。

## 训练过程

`GANs` 的训练过程涉及 `backpropagation` 和 `gradient descent`，与其它神经网络类似。然而，`GANs` 的训练具有挑战性，因为需要保持 `generator` 和 `discriminator` 之间的平衡。如果 `discriminator` 太强，它会拒绝 `generator` 的所有输出，从而阻止 `generator` 有效学习。相反，如果 `generator` 相对于 `discriminator` 太强，它将没有足够的梯度信号来学习，导致所谓的 `mode collapse`，即 `generator` 产生有限种类的输出。

## 应用和优势

`GANs` 广泛用于图像生成、视频生成和语音生成应用。在图像生成中，`GANs` 可用于将低分辨率图像增强为高分辨率，通过学习各种艺术家的风格创建艺术图像，并生成现实中不存在的逼真人脸或物体。在视频生成中，`GANs` 可用于预测视频序列中的未来帧，这对于理解视频中的场景和活动可能很有用。在语音生成中，`GANs` 有助于从文本生成类人语音，这在虚拟助手和其他 AI 驱动的交互系统中具有应用。

`GANs` 的显著优势之一是它们能够在无需大量标记训练数据的情况下学习深度表示。这一特性使它们在标记数据稀缺或获取成本高昂的任务中非常有用。然而，`GANs` 需要大量计算资源和时间进行训练，并且对超参数设置敏感，这往往使它们难以使用。此外，`GANs` 的评估具有一定主观性且可能复杂，因为它通常涉及人类判断来评估生成数据的质量。
