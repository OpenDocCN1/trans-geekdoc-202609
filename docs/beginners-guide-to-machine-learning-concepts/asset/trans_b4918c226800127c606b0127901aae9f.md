

# K-MEANS 聚类

`K-MEANS CLUSTERING` 是一种在机器学习中常用的无监督学习算法，用于将一组数据点划分为 `K` 个不同的、不重叠的簇。`K-means` 的目标是将数据点分组到簇中，使得总的簇内变异（或总的簇内平方和 `WSS`）最小化。其基本思想是定义簇，使总的簇内方差最小化。

该算法首先通过随机初始化 `K` 个点，称为 `means`。这些 `means` 通常选自数据集中 `K` 个不同的对象。然后将数据集中的每个点分配给最近的 `mean`。 “最近”通常由点之间的 `Euclidean distance` 决定。所有点都被分配到簇后，会重新计算这些簇的质心。此过程迭代进行，直到质心不再显著移动，表明簇相对稳定且算法已收敛。

`K-means` 聚类算法的步骤可总结如下：
1. 随机初始化 `K` 个质心。
2. 将每个数据点分配给最近的质心。
3. 重新计算新形成簇的质心。
4. 重复步骤 2 和 3，直到质心不再显著变化或达到最大迭代次数。

`K-means` 聚类的主要优点之一是其简单性和计算成本方面的效率。它具有高度可扩展性，可以有效处理大型数据集。然而，该算法要求事先指定簇的数量，如果事先不知道数量，这可能是一个很大的缺点。此外，`K-means` 对质心的初始选择敏感，可能收敛到局部最优，这意味着它每次在相同数据上运行时可能不会产生相同的输出。

为了解决初始化敏感性问题，已经提出了几种方法。其中一种流行的方法是 `K-means++` 算法，它提供了一种更智能的初始化技术，在进行标准的 `K-means` 优化迭代之前放置初始质心。研究表明，这种方法可以提高最终簇的质量并降低收敛到次优解的可能性。

`K-means` 聚类假设簇是球形且大小均匀的，这意味着它在处理具有非球形簇或大小和密度不同的簇的数据时往往表现不佳。这种局限性源于使用 `Euclidean distance` 度量，它只考虑数据点的几何属性。根据数据的性质，其他距离度量，例如 `Manhattan` 或 `cosine similarity`，可能更合适。

尽管存在局限性，`K-means` 聚类已在各个领域成功应用。在营销中，它用于市场细分，识别具有相似行为的客户群体以进行有针对性的营销活动。在计算机视觉中，`K-means` 可用于颜色量化以减少图像中的颜色数量。它还用于文档聚类，以将文档组织成相似的组用于信息检索系统。

`K-means` 聚类的另一个重要方面是其评估。由于 `K-means` 是无监督方法，与监督学习不同，没有直接评估结果的方法。然而，可以使用几种指标来评估聚类的质量。最常见的是 `silhouette score`，它衡量对象与其自身簇的相似程度与其他簇的比较。较高的 `silhouette score` 表示簇定义更好。另一种方法是 `Elbow method`，它涉及绘制解释方差作为簇数量的函数，并将曲线拐点处的数量作为要使用的簇数。

总之，虽然 `K-means` 聚类是数据分析的强大工具，但了解其假设和局限性很重要。适当的数据预处理、选择合适的簇数量以及明智地初始化质心是可能显著影响 `K-means` 聚类算法结果的关键步骤。考虑到这些因素，`K-means` 可以成为各种实际应用中数据划分的有效方法。

## 层次聚类

`HIERARCHICAL CLUSTERING` 是一种用于机器学习的无监督学习算法类型，用于根据对象的相似性将一组对象分组到簇中。与 `k-means` 等其他聚类方法不同，层次聚类不需要事先指定簇的数量。相反，它通过分裂法（自上而下方法）或凝聚法（自下而上方法）构建簇的层次结构。

在凝聚层次聚类方法中，每个数据点最初被视为一个单独的簇。然后，迭代地合并最接近的簇对，直到所有数据点都在一个簇中或满足停止标准为止。簇之间的接近程度由链接方法确定，该方法将观测值集合之间的距离定义为观测值之间成对距离的函数。常见的链接方法包括 `single linkage`、`complete linkage`、`average linkage` 和 `Ward’s method`。`Single linkage` 使用两个簇成员之间的最小距离，`complete linkage` 使用最大距离，`average linkage` 使用平均距离，而 `Ward’s method` 最小化总的簇内方差。

另一方面，分裂法则以相反的方式工作。它从所有观测值在一个簇开始，并将簇分成更小的部分。在每一步中，根据数据点之间的距离等标准选择最佳候选簇进行分裂。该过程递归继续，直到每个数据点单独作为一个簇存在或满足停止标准为止。然而，由于其计算复杂度高于凝聚方法，分裂方法在实践中不太常见。

层次聚类的结果可以用树状图表示，称为 `dendrogram`，它说明了簇合并（在凝聚中）或分裂（在分裂中）的序列以及每次合并或分裂发生的水平。`dendrogram` 的 x 轴表示数据点，y 轴表示簇之间的距离或不相似性。分析 `dendrogram` 使研究人员能够通过在期望的不相似性水平处切割 `dendrogram` 来决定簇的数量；每个不相连的子树代表一个簇。

层次聚类的主要优点之一是其易于实现且结果易于解释。此外，它不需要假设特定的簇数量，这相对于 `k-means` 来说是一个显著的优势。层次聚类对于探索性数据分析和对于理解数据结构和对象之间关系比获得数据的单一划分更重要的情况特别有用。

然而，层次聚类也有其缺点。它计算成本高，尤其是对于大型数据集，因为凝聚聚类的复杂度通常为 `O(n^3)`，空间复杂度为 `O(n^2 log n)`，其中 `n` 是数据点的数量。这使其对于非常大的数据集不切实际。此外，一旦完成某一步（合并或分裂），就无法撤销，这可能会导致如果早期决策不 optimal 则聚类次优。此外，链接标准的<|message|> 选择和在何处切割 `dendrogram` 以定义簇的决定会显著影响结果，有时会导致对同一数据集的不同解释。
