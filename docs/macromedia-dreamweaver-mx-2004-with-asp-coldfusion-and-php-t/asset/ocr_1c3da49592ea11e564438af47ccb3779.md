3) In the Sort drop-down menu, choose tourName, and verify that the box beside it
is set to Ascending.

Unless you tell it otherwise, the database is going to display data in the order it appears
in the database. However, the data was not entered in any particular order. By sorting
the data by tourName ascending, you ensure that all of the tours are listed in alpha-
betical order, which will make it easier for your users to find the tour they want.
