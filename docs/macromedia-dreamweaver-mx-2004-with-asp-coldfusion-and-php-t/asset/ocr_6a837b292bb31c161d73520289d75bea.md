These settings should, at this point, all make sense to you, with one exception: Why does the class name begin with a period (.)? The period indicates that the style does not redefine an HTML tag in its own right, as in “all <p> tags should look like XYZ,” but rather that it defines an element subordinate to an HTML tag. One practical application of this is that you can use a custom class to specify the appearance of *some* <p> tags, but not all of them. That makes sense in this particular case—only some paragraphs should be designated as author paragraphs.

Another benefit to custom classes is that they can be applied to different HTML elements. For example, not only could you apply the .author class to any <p> tag, but you could also apply it to a <span> or <div> tag.
