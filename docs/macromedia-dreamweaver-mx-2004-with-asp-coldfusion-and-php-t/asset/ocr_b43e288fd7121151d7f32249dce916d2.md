# In Macromedia® Dreamweaver® MX 2004 with ASP, ColdFusion and PHP Training From the Source, learn how to:

+   - Use a relational database–Microsoft Access or MySQL—as the driving force behind a site
+   - Use Dreamweaver's built-in server behaviors and application objects to assist in the rapid development of dynamic Web applications
+   - Read and hand-code ASP VBScript, ColdFusion Markup Language, and PHP scripts well enough to understand how dynamic Web pages work, troubleshoot errors, and customize scripts
+   - Collect and manipulate user-entered data, performing calculations with it on the fly
+   - Use SQL to pass information between your pages and the database
+   - Validate forms using client-side and server-side scripts

# Learn by Doing:

Follow along, step-by-step, as you upgrade a static HTML site that uses obsolete code to an XHTML standard-compliant, CSS-formatted, dynamic site using Microsoft Active Server Pages (ASP), Macromedia ColdFusion, or the open source PHP. Create several integrated applications for a fictional travel tour operator, including a searchable listing of tour descriptions, country profiles, and a tour price calculator.

# System Requirements

You will need access to Microsoft's IIS Web server (for ASP), Macromedia's ColdFusion server (for ColdFusion), or the Apache Web server (for PHP) in order to test the applications created as part of the book's exercises. Microsoft Access is recommended, but not required, for ASP and ColdFusion. MySQL is required for PHP

Retrieve data from a database, writing your own SQL code—and testing the results—in Dreamweaver's Recordset dialog

Build a user authentication framework, complete with registration, login, and restricted pages

Provide search interfaces that allow users to access the information they want to see

Dynamically generate and format entire pages, including headings, images, and even their ALT descriptions

Create forms whose default values are retrieved from the database, based on user-specified criteria

Create forms that output data to a database or automatically send an email message
