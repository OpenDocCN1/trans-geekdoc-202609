# passing data between pages

# LESSON 5

The hallmark feature of dynamic Web pages is that the contents displayed in the browser are not coded in the page, as in static HTML, but rather inserted into the page on the fly as it is served. The implication of this is that the core skill in developing dynamic Web applications is knowing how to capture and embed data, so that it can be inserted into Web pages when they are served.

At the end of the preceding lesson, you got a taste of this process, when you displayed the first name that users entered on a form on a different page. To accomplish this task, you used ASP, ColdFusion, or PHP code to capture the firstName variable and inserted it inline into regular XHTML code. Though it was a simple little application, the form-to-Web transfer you achieved at the end of Lesson 4 is representative of a good portion of dynamic site development.
