8) Between the two sets of opening and closing <textarea></textarea> tags (for description and imageALT), insert the code necessary to output dynamic data as their default values.

In ASP:

```
<%=rs_countryDetail("description")%>
<%=rs_countryDetail("imageALT")%>
```

In ColdFusion:

```
<cfoutput>#rs_countryDetail.description#</cfoutput>
<cfoutput>#rs_countryDetail.imageALT#</cfoutput>
```

In PHP:

```
<?php echo $row_rs_countryDetail['description']; ?>
<?php echo $row_rs_countryDetail['imageALT']; ?>
```

The <textarea> tag uses slightly different syntax than other form element tags. Rather than having a value attribute, you place the default value between the opening and closing tags. The syntax for the ASP, ColdFusion, or PHP code is the same, though.
