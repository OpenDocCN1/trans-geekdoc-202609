+   1) Drag to select everything from (and including) the horizontal rule through the “Price this tour with the Tour Price Calculator” paragraph.

This will be the repeated region. You don’t want to include the copyright notice or the second Find Tours link in the repeated region—those should appear beneath all the tours.

+   2) Use the Server Behaviors panel to add a Repeat Region behavior to the selection.

In the Repeat Region dialog, enter 5 for the number of records to be shown at a time.

Click OK.

![](bbox=[0.281, 0.595, 0.675, 0.703])

A Repeat Region square is drawn around the entire selection, indicating its boundaries.

+   3) Save, upload, and press F12 to test the page, to view it in a browser.

You’ll see the first five records, listed alphabetically by country name. The first is still Highlights of Argentina, while the last record on the page should be Highlights of France.
