Alternatively, from the master page, users can choose to delete a country profile. When they click this link, they are redirected to admin_cp_delete_processor, which contains a script that deletes the selected country and redirects users back to the master page. This process takes a fraction of a second and appears to users as if they never left the master page—it simply updates with the selected country removed.
