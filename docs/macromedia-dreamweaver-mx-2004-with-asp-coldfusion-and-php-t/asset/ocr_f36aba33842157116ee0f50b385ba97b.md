2) Click the Validate button, and from the pop-up list, choose Settings.

This option is a shortcut to the Preferences dialog's Validator category, where you see a list of several different versions of HTML and proprietary language code. Before you can validate your code, you need to tell Dreamweaver which version of code you want to validate against.

3) In the validate against list, choose XHTML 1.0 Transitional. Uncheck all other options. Click OK to proceed.

By choosing XHTML 1.0 Transitional, you are aligning the Validator with the settings you specified at the beginning of this lesson, when you pasted the DOCTYPE declaration at the beginning of the document.
