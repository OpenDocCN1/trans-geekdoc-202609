Before testing this functionality, let's quickly take care of the number formatting. ASP and ColdFusion users can accomplish this task using Dreamweaver's interface, but PHP users will have to hand-code.

5) ASP and ColdFusion users: select and delete the dynamic text underneath the Population heading. Position the cursor in the now-empty line. From the Application tab of the Insert panel, choose Dynamic Text.

The dynamic text feature offers the same functionality as the Bindings panel, except that it lets you specify how to format the data.

![](bbox=[0.27, 0.28, 0.92, 0.68])

6) ASP and ColdFusion users: in the Dynamic Text dialog, select population from the list. In the Format drop-down, select Number – Rounded to Integer. Click OK.

In Lesson 7, I had you type in the function (FormatCurrency() or DllarFormat()) directly, so you could work with the code. In this step, you are doing the same thing (using a different function to format numbers, rather than currency) using Dreamweaver's visual interface.

When you are done with this step, the page in Dreamweaver looks just like it did before you deleted the original population number.
