+   4) Double-click the installer file, which is called something like apache_2.0.47-win32-x86-no_src.msi to launch the installation wizard.
+   The installer file is on your hard drive, in the directory you saved it in the preceding step.

+   5) Complete the installation wizard. In the Server Information screen, enter localhost in both the Network Domain and Server Name fields. Leave the default For All Users option selected.
+   
+   The Apache installer is entirely self-explanatory, with one exception: the Server Information screen. This screen tells Apache how developers and users alike should access the server. If you were installing Apache on a network server, you'd have to specify the computer name and domain, but since you are only installing it for use on a single machine, you can just enter localhost.
