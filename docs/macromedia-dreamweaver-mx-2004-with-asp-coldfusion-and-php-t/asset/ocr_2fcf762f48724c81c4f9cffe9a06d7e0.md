The navigation bar is an interesting problem, because it is not the navigation bar as a whole, but rather the individual button graphics on the bar that matter. Adding an alt attribute to this image doesn't convey what each of the buttons does. Remember, though, that what makes the buttons do something (namely, load another page when clicked) is the image map, and not the image itself. For this reason, it is necessary to add the alt attribute to each of the <area> tags within the image map. I have already done this for you.
