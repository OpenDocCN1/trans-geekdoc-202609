# INSTALLING PHP IN WINDOWS

Installing PHP in Windows is slightly more complex than Apache, because the files don't come with an installer. Instead, the files needed for the program come zipped. After you unzip them, you must manually move a few files to different locations.

+   1) Go to http://www.php.net/downloads.php and download the latest stable (not beta) version of PHP, choosing the Windows binary version.

At the time of this writing, the latest stable version is PHP 4.3.2. A beta is available for PHP 5, and it may be a stable release by the time you read this. Its release may also change some of the steps below. If you install PHP 5, check the book's Web site (at http://www.allelectomedia.com) for errata and addenda.

As long as you have PHP 4.2 or higher, the code in this book should work as described.
