# In ColdFusion:

```
<cfmail from="#form.emailAddress#" to="yourname@yourserver.com" subject=
=>"#form.subject#">
#form.body#
</cfmail>
```

# In PHP

```
<?
mail('yourname@yourserver.com', $_POST['subject'], $_POST['body']);
?>
```

If, rather than seeing the values you entered, you see form.subject as the subject,
or form.body as the body, then you probably forgot to remove the quotation marks
around the dynamic variables (ASP and PHP) or you forgot to include the pound
signs ## (ColdFusion).
