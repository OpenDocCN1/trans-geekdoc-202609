There are a couple of things to note here. First, look in the country column (it should be the fourth column from the left). Notice that it lists only numbers. If you had not done the join, and had output the country in the tour description, these would have appeared in the place of the country names. Scroll to the right, until you see the countryName column. There, you will see each of the countries listed, in alphabetical order. This column was added thanks to the join, and it means that you can output the actual country name, rather than its arbitrary primary key number.

Again, this is no different in its result than what you did in Lesson 10 with the region name. The only difference now is that you are using the best syntax (the INNER JOIN...ON...syntax) to retrieve this data.
