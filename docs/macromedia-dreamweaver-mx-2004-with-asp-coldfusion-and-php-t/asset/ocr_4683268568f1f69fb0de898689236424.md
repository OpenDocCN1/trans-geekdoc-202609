Find the following code in tours.php.

```
<?php
if ($_GET['error'] == "notnumeric")
{
echo "<p class=\"error\">*** Error! One or more fields was left blank or contained
>=a non-numeric character.</p>";
}
?>
```

Change that code block so that it reads as follows.

```
<?php
if (isset($_GET['error']))
{
if ($_GET['error'] == "notnumeric")
{
echo "<p class=\"error\">*** Error! One or more fields was left blank or contained
>=a non-numeric character.</p>";
}
}
?>
```

The error appears on only some implementations of PHP. The cause is that you’re testing whether a variable ($_GET['error']) is of a certain value (notnumeric), without actually making sure the variable exists in the first place.
