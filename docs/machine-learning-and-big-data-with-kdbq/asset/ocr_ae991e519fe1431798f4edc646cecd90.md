# Simulating Asset Prices

In this chapter, we provide a framework to simulate multivariate stochastic volatility process with jumps. We build the framework step by step, and wherever we need to introduce new functions, we build them on the fly. This chapter is motivated by Novotny and Urga (2017). The paper provides a test for co-jumps in asset prices. One section of the paper is a simulation exercise to assess the size and power of tests. In order to do that, we need to simulate a realistic price generating process. The choice was made for a stochastic volatility process with price jumps in both the price and volatility. This chapter illustrates that q can be naturally used for academic research as well.

# 18.1 STOCHASTIC VOLATILITY PROCESS WITH PRICE JUMPS

We start with a simulation of the Stochastic Volatility Model with an intraday pattern and price jumps both in the volatility process and the price process, proposed by Andersen et al. (2012). The price generating process is defined by the following equations:

```
$d\log F_t^{(i)} = \mu_t^{(i)} dW_t^{(i)} + U_t^{(i)} dJ_t^{(i)}$
$d\sigma_t^{(i)} = \kappa^{(i)}(\bar{\sigma}^{(i)} - \sigma_t^{(i)})dt + \omega^{(i)} dB_t^{(i)} + U_{t,\sigma}^{(i)} dJ_t^{(i)}$
$E[dW_t^{(i)} dB_t^{(i)}] = \rho^{(i)} dt$
$E[dW_t^{(i)} dB_t^{(j)}] = 0, i \neq j$,$
$E[dW_t^{(i)} dW_t^{(i)}] = \rho_w^{(i)} dt$
```

where $i = 1, \dots, N$, and

```
$u_t = c_t + c_{open} \exp(-a_{open}(t - t_{open})) + c_{close}(-a_{close}(t - t_{close}))$,
```

where $t$ denotes the time in the trading day, $t_{open}$ is the opening time, and $t_{close}$ is the closing time.
