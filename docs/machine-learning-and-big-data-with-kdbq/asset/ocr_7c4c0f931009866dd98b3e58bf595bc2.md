# 12.3.5.1 Implementation of the Test

In q language, the sign test can be implemented as follows. First, we define the characteristic of the basic characteristics of the binomial distribution:

```
quant.stats.characteristicsBinomial:{n;N;p}
// N -- population size
// n -- number of "1"
// p -- probability of "1" in every draw
// first moments: mean
mean: N*p;
// first moments: variance
variance: N*p*(1-p);
// sigma -- convenient
sigma start variance;
// first moments: skewness
skewness:(1-2.0*p)%sqrt[N*p*(1-p)];
// first moments: kurtosis
kurtosis:(1-6.0*p*(1-p))%N*p*(1-p);
// the output object
:(mean variance`sigma`skewness`kurtosis)!(mean;variance;sigma;skewness;kurtosis);
```
