# ## 14.1.4 ARMA(p, q) Process

The long memory $AR(p)$ model can be combined with the short memory $MA(q)$ process to produce a new family of tractable and flexible stationary processes called The autoregressive moving average $ARMA(p,q)$ refers to the model with $p$ autoregressive terms and $q$ moving average terms:

```
$X_t = c + \sum_{i=1}^{p} \Phi_i X_{t-i} + \sum_{i=1}^{q} \alpha_i \epsilon_{t-i}, \quad (14.15)$
```
