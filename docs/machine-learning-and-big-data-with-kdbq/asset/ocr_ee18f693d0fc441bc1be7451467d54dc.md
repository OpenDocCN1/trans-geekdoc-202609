# 20.5 LASSO REGRESSION

The second regularisation technique we introduce is the lasso regression. First of all, why do we introduce a new technique given the ridge regression is straightforward to implement and apply? The main reason is that ridge regression tends to penalise all the coefficients across the board, but in many instances, may be suitable to select a subset of features, i.e. remove some of the features instead of shrinking them significantly but still keeping them within the model. More importantly, feature selection can frequently when working with machine learning methods. The lasso regression assists us in feature selection as it is a better way to impose a penalty.

The lasso regression is a formulation of the OLS solution with imposed penalty having a form of an L₁ norm. The lasso estimator is solution to the problem:

```
$$\hat{\beta}_{\lambda}^{Lasso} = \arg\min_{\beta} (y - X\beta)^{T}(y - X\beta) + \lambda \sum_{j=1}^{p} |\beta_j| , \quad \quad (20.34)$
```
