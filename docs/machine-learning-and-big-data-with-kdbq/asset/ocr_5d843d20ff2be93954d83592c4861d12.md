Next, let us explore the properties of the ridge estimator. First, we can show that the estimator is biased:

```
$$\hat{\beta}_{\lambda}^{	ext{Ridge}}=(X^T X + \lambda I_p)^{-1}X^T Y \quad (20.19)\n=(A + \lambda I_p)^{-1}A(X^{-1}Y) \quad (20.20)\n=[I_p + \lambda A^{-1})^{-1}A(X^T X)X^{-1}Y \quad (20.21)\n=(I_p + \lambda A^{-1})^{-1}A^{-1}\hat{\beta}^{	ext{OLS}} \quad (20.22)\n=(I_p + \lambda A^{-1})^{-1}\hat{\beta}^{	ext{OLS}}[\hat{\beta}^{	ext{Ridge}}] \quad (20.23)\n=(I_p + \lambda A^{-1})^{-1}\beta, \quad (20.24)$
```

where $A=X^T X$ and $\lambda=0$, there is a bias in the classifier. The variance of the $\hat{\beta}_{\lambda}^{	ext{Ridge}}$ estimator can be expressed using matrix manipulations:

```
$Var[\hat{\beta}_{\lambda}^{	ext{Ridge}}]=Var[(I_p + \lambda A^{-1})^{-1}\hat{\beta}^{	ext{OLS}}] \quad (20.25)\n=(I_p + \lambda A^{-1})^{-1}Var[\hat{\beta}^{	ext{OLS}}](I_p + \lambda A^{-1})^{-1})^{-T} \quad (20.26)\n=\sigma^2(I_p + \lambda A^{-1})^{-1}X^T X^{-1}(X^T X + \lambda I_p)^{-1} \quad (20.27)\n=\sigma^2[X^T X + \lambda I_p]^{-1}X^T X[X^T X + \lambda I_p]^{-1}]^T. \quad (20.28)$
```

Let us recall the bias-variance formula for the MSE of estimators:

```
$MSE=E((\Theta - \hat{\Theta})^2)=E((\Theta - E[\Theta])^2 + E[\hat{\Theta} - E[\Theta]]^2) \quad (20.29)\n=E[\Theta - E[\Theta]]^2 + E[\hat{\Theta} - E[\Theta]]^2 - 2E[\Theta - E[\Theta]][\hat{\Theta} - E[\Theta]] \quad (20.30)\n=Var[\hat{\Theta}] + [Bias[\hat{\Theta}]]^2. \quad (20.31)$
```

It appears that there exists $\lambda^*$ such that $MSE[\hat{\beta}_{\lambda}^{	ext{Ridge}}] < MSE[\hat{\beta}^{	ext{OLS}}]$. This is (one of) why we use regularization

It remains to answer the obvious question, how to identify the value of such $\lambda^*$. The performance of the model for a given $\lambda$ has to be assessed in the out-of-sample context. An intuitive tool to use is the cross-validation technique we have discussed in the previous section. It is convenient to perform the cross-validation across a grid of $\lambda$ values and optimise for $\lambda$ based on the estimated landscape in terms of measure like RMSE.
