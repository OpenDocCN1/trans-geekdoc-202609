There is also the notion of the cross-product in the quaternion space. The cross-product is defined for purely "imaginary" quaternions, these are with zero real part $a=0$. In such a case, the cross-product is defined as:

```
$(0 + a_1i + b_1j + c_1k) \times (0 + a_2i + b_2j + c_2k) = (c_1d_2 - d_1c_2)i$
$+ (d_1b_2 - b_1d_2 - 2j) + (b_1c_2 - c_1b_2)k$.
```

Let us illustrate quaternions and introduce the basic algebraic operations on quaternions. We will use the notation, `quantQ`, which will be prepended to the function names. Using a similar approach to complex numbers, we will represent a quaternion as a dictionary, with expanded keys: `r` `i` `j`.

