# 12.3.2 Correlation

The basic tool we have at our disposal to assess the dependence between two variables $X$ and $Y$ is correlation, or Pearson correlation, denoted as $\rho_{XY}$. Correlation is defined as the covariance of two random variables normalised by their respective variances:

```$$\rho_{XY} = \frac{cov(X, Y)}{\sigma_X \sigma_Y}}, \quad (12.11)$$
```

where cov stands for covariance, and $\sigma_X$ and $\sigma_Y$ stands for square root of variance of $X$ and $Y$, respectively. Correlation is a definite quantity if the variance for both random variables exists. Correlation is bound to $[-1, 1]$, where values close to 1 suggest perfect correlation, values close to -1 imply anti-correlated, while uncorrelated variables have correlation to zero. The obvious null hypothesis to test is:

- $H_0$: Two random variables are uncorrelated.
- $H_1$: Two random variables are correlated.

Let us stress that we have formulated the alternative hypothesis in English. The proper formulation should be we reject the null hypothesis.

# 12.3.2.1 Implementation

The correlation is already implemented within $q$ under the ver. Let us illustrate its use:

```
x:100;
y:(0.2*x)+0.8*100;
cor[x;y];
```

The result shows a value different from 0, suggesting positive correlation. In order to test it, we have to calculate the statistic $t_\rho$. We do that in function tStatsCorr, which has two arguments: calculated correlation and size of sample (the true correlation under the null hypothesis is by definition $\rho_0 = 0$);

```
.quantQ.tStatsCorr[[rho;N]
// estimated correlation
// N -- size of sample
:rho*sqrt[(N-2)%rho*rho];
;
```

> Let us test the hypothesis (two-sided) that the correlation observed is different from 0. First, we calculate the statistic $t_\rho$;

```
.quantQ.stats.tStatsCorr[cor[x;y]; count x
```

The value is large. We assess its significance level against the normal asymptotic using a two-sided test:

```
.quantQ.stats.pValueTwoSided abs .quantQ.stats.tStatsCorr[cor[x;y]; count x
```

# 12.3.3 t-test: One Sample

Let us consider an independently drawn sample $x_1,\dots,x_N$ representing $N$ draws of a random variable $X$, which has a population mean $\mu$ and a standard deviation $\sigma$.

# Basic Overview of Statistics

Our motivation is to form a hypothesis about the population mean inferred from the observed sample. The statistical procedure to achieve this objective is to use t-test.
In general, t is a statistical hypothesis test where the test statistics under the null hypothesis follow t-distribution. t-distribution is parameterised by one parameter, $n$ denoted degree of freedom. For $n \infty$, the distribution converges to a normal distribution, while for $n$ small, the distribution is fat-tailed.
Example of such a t test is the following:

```
t = \frac{\bar{X} - \mu}{\sqrt{N}}
```

$\bar{X}$ is the sample average. The statistic under the null hypothesis is distributed as $t_n$; these can be used in the following statistical test about the population average:

- $H_0$: The population mean is $\mu$ (given the sample size N and standard deviation $\sigma$).
- $H_1$: The population mean is different from $\mu$.

The test is inconvenient as it requires knowledge of population standard deviation. This is, in practice, is hardly known and such an assumption cannot be made. Fortunately, the t-statistic can be modified so that we can replace knowledge of standard deviation by its estimator:

```
t' = \frac{\bar{X} - \mu}{s}
```

s is the standard deviation of the mean defined as:

```
s = \frac{1}{\sqrt{N}} \sqrt{\sum_{i=1}^{N} (x_i - \bar{X})^2}
```

Note that there is a factor $1/\sqrt{N}$ in the free square root.
The adjusted statistic $t' \sim t_{n-1}$. The estimator of the standard deviation of the mean cost one of freedom. The word "cost" is used as it worsens the asymptotic behaviour and makes the statistics further from the normal distribution.
We can form the following hypotheses to test the $t'$ statistic:

- $H_0$: The population mean is equal/smaller or equal/larger or equal to $\mu$, given the sample size N.
- $H_1$: The population mean is different/larger/smaller relative to $\mu$.

The test is assessed by calculating $t'$ and comparing $|t'| > t_{critical,n-1}, t' > t_{critical,n-1}, t' < -t_{critical,n-1}$, respectively. When the corresponding inequality is satisfied, we can reject the null hypothesis, where $t_{critical,n-1}$ is a corresponding critical value. In the subsequent part, we will assume the asymptotic limit holds and use the normal distribution to derive the critical values.
