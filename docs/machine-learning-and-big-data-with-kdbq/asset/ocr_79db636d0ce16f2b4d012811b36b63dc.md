# Towards AI - Monte Carlo Tree Search

The empty game tree is thus defined as:
treeCTS::[] index=`j$`;gameTree: `$()`;isWinner:`j$`);

Further, we define the dictionary with all the variables needed to run the MCTS. The dictionary will be propagated through the MCTS algorithm and updated accordingly.

bucket:(`moveStateisWinner`numberOfRuns`treeMCTS`c)!($);0;j;treeMCTS;sqrt(2);

where the dictionary describes a game in the beginning when no stone has been placed yet and there is no information available to proceed (no simulations).
The meaning of the variables is as follows:

+   - moveState - starting position of the game, it can be empty,
- isWinner - control variable to run the MCTS,
- numberOfRuns - max number of trees to be run by the algorithm,
- treeMCTS - game tree built up so far,
- c - parameter of the UCT formula, to be chosen to √2.

The key component of the MCTS algorithm is the formula for the Upper Confidence Bound, or UCT, defined in eq. (28.20). We implement it as a function with three input parameters. The first input parameter is a table with columns: gameTree corresponding to the child nodes, and isWinner with the status of the game which contains a given node. The second input is a perspective, and the third is the parameter c of the UCT formula. The function returns:
