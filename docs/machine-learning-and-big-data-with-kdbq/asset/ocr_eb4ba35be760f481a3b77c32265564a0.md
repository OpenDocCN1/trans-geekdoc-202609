# Basic Overview of Statistics

This chapter presents several tools which are useful when we need to go through the data at hand and get an initial understanding of the data content. The tools can be used individually or as an entire suite. It is an excellent habit to analyse the data before constructing a machine learning model. The tools presented in this chapter are a combination of statistics, tests and visualisation hints.

# 12.1 HISTOGRAM

A histogram is a representation of the data distribution, a visualisation tool for the data points in our sample. Theoretically, it represents an estimate of the probability function for a continuous variable. It is, in fact, an empirical function. In this chapter, we treat histograms as a visual tool which allows us to see and investigate the structure of our data.

A histogram can have two inputs, and the bins (or buckets); it returns the number of data points per bin. The bins represent a scheme which will split the interval of the data into a list of non-overlapping intervals. Although the bins are not necessarily equal, in this section we will only consider equidistant intervals.

It is convenient to normalise the histogram so it can represent a probability function, where every plot captures relative frequency. In such a case, the histogram is a kernel density estimator. Using some form of polynomials or splines, the kernel can be further enhanced to obtain smoothed histograms. In our example, we will use qPad, with the option "Bars", to obtain a visual representation of the histograms.

In our implementation, we use the binr, namely x binr. The verb performs a binary search of y in list x and returns the index of the minimum element of x, as n : x ∈ (x₁,xₙ). The function is mathematically expressed as:

```
quantQ stats.histogram::[data,rule]
// array of data
// rule function which takes data and returns bins
// calculate bins
bins: rule data;
```
