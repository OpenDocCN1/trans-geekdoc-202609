## Eigensystem and PCA

## 16 THEORY

Matrices and equations are everyday objects we encounter in statistics and data science. Square matrices play a unique role, and it is thus convenient to get familiar with them and able to deal with them numerically. The covariance matrix is a particular example of square matrix, whenever we get our hands on data. It is particularly useful to calculate the eigensystem of square matrices as it allows us to make inferences about the source of variation.

Let us start with a definition of eigenvalues and eigenvectors, or the eigensystem, for a square matrix. The notion of eigenvectors and eigensystems can be defined for a general linear transformation, but for our purpose, we consider a $p \times p$ matrix $A$, which can contain complex numbers, and a $p$-dimensional column vector $x$. The product of a matrix $A$ and a vector $x$ is:

$We say that vector $v$ is an *eigenvector*, when

$Av = \lambda_v v,$

and $\lambda_v$ is a scalar, which is known as *eigenvalue*. The eigenvector is a special vector, which is transformed by the matrix $A$ in a special way: it is rather stretched. It represents a special direction of the matrix $A$ in the vector space.

We can immediately say that $v$ is an eigenvector, any multiple of such a vector is an eigenvector with the same eigenvalue, or

$Av = \lambda_p v \Rightarrow Aav = \lambda_p av.$ (16.3)

Further, eq. (16.2) can be rewritten as:

$(A - \lambda_p I)v = 0,$ (16.4)

where $I_p$ is identity matrix. The eq. (16.4) has a non-trivial solution if the matrix $(A - \lambda_p I)$ is singular. For non-singular matrices, only trivial solutions can satisfy the equality. To be precise, the matrix is said to be singular when it is not invertible. In other words, some of its columns can be written as a linear combination of the remaining columns. This implies that such a matrix is not of the full rank. An equivalent definition is that its determinant is equal to zero (see the Appendix to this chapter for more about determinants and their implication in q). We can say that for square matrix $A$ the vector $v$ is an eigenvector corresponding to the eigenvalue $\lambda$ if

$|A - \lambda_p I| = 0,$ (16.5)

where $|A|$ stands for the determinant of the square matrix $A$. This equation is known as a characteristic polynomial. This comes from the fact that the determinant in eq. (16.5) is a polynomial of $p$ in $\lambda$.

It is due to the fundamental theorem of algebra which we can rewrite eq. (16.5) as a product of:

$|A - \lambda_p I| = (\lambda - \lambda_1)(\lambda - \lambda_2) \cdots (\lambda - \lambda_p).$ (16.6)

where $\lambda_i$ are roots of the polynomial. The roots can be all distinct or degenerate, and they can take complex values. When the root is degenerate, i.e. there is sequence of $(\lambda - \lambda_i)^{p_i}$, we say that the root has non-trivial algebraic multiplicity, $p_i$. The sum of all multiplicities is equal to the rank of the matrix.

It is further to introduce the notion of null space. For each eigenvalue $\lambda_i$, we define the subspace

$v_i : (A - \lambda_i I)v_i = 0.$ (16.7)

This space of all $v_i$'s is further known as eigenspace of $\lambda_i$. The eigenspace is closed under addition and multiplication as. Thus, if we have two vectors $v_i^1$ and $v_i^2$, eigenvectors of $\lambda_i$, then their linear combination is also an eigenvector of $\lambda_i$.

The consequence of this observation is that for square complex matrix $A$, the entire vector space (dimension p) can be written as a Cartesian product of all eigenspaces corresponding to eigenvalues. Furthermore, any $p$-dimensional vector can be written as a linear combination of eigenvectors of $A$. In other words, linearly independent eigenvectors of A form the eigenbasis of a $p$-dimensional vector space.

Let us mention a number of useful properties of the eigensystem. We assume that A is a $p$-dimensional square matrix. In this section, we provide an algorithm to solve the eigensystem, i.e. for any square matrix $A$, we find the eigenvalues and the corresponding eigenvectors. We utilise the eigensystem for principal component analysis (PCA), which is a powerful tool to analyse data.

## Eigensystem and PCA

## Determinant

(discussed at the end of this chapter) of the matrix $A$ can be written as:

$\det A = \prod_{i}^{p} \lambda_{i},$

where $\lambda_{i}$ are eigenvalues of the matrix $A$.

## Trace

of the matrix $A$ can be written as:

$\trace A = \sum_{i}^{p} \lambda_{i},$

where $\lambda_{i}$ are eigenvalues of the matrix $A$.

## Hermitian

matrix $A$, i.e. a matrix such that $A = A^*$, have all the eigenvalues real. If the matrix is positive-definite/ positive-semidefinite/ negative-definite/ negative-semidefinite/ every eigenvalue is positive/ non-negative/ negative/ non-positive.

## Unitary

matrix $A$ has all eigenvalues modulo to 1.

## Power

of the matrix $A$, i.e. $A^k$, has the eigenvalues $\lambda_1^k, \lambda_2^k, \dots, \lambda_p^k$.

## Invertibility

of the matrix $A$ is equivalent to a situation where every eigenvalue $\lambda_i$ is non-zero. Further, for an invertible matrix $A$, the eigenvalues of $A^{-1}$ are $\lambda_1^{-1}, \lambda_2^{-1}, \dots, \lambda_p^{-1}$. The algebraic multiplicity of the inverse eigenvalues coincides with the direct counterparts.
