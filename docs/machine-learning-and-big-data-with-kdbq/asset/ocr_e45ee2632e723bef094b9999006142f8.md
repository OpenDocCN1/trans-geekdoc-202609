The model contains a large number of parameters which have to be set according to the underlying process which is to be simulated. In order to get the specific numbers, we employ the calibration used by Novotny and Urga (2017) with N=3 based on Eraker (2004) and Lee (2011). In particular, the intra-day pattern is set as $c_i = 0.8892, c_{open} = 0.75, c_{close} = 0.25, a_{open} = 10,$ and $a_{close} = 10$. The following parameters for each asset are the same volatility for each asset: $x^{(i)} = 0.12, \delta^{(i)} = 0.53, \omega^{(i)} = 0.58,$ and $ho^{(i)} = -0.46$. This ensures that the portfolio has $N$ assets of the same type. The correlation coefficients, $ho_W^{(i)}$, are the same for each asset, $ho_W^{(i)} = 0.2$. The parameters are normalised to $T=1$ day.

The magnitude of the jump $U_{P,j}^{(i)}$ is set relative to the prevailing level of stochastic volatility as $U_{P,j}^{(i)} = v_{
u_j} \sigma^{(i)},$ where $\sigma^{(i)}$ is the prevailing volatility immediately before the jump occurs, and $
u_j$ is the parameter common to all assets, for which we consider $
u_1=4, 
u_2=8,$ and $
u_3=12$, respectively. The magnitude of the jumps $U_a^{(i)}$ follows for every exponential distribution with mean $\mu_{\zeta}=0.0167$. For every asset $i$, we assume that $U_a^{(i)}$ is drawn independently of each other. For each asset $i$, the arrival process $dN_t^{(i)}$ and $dJ_t^{(i)}$ are assumed to be driven by the stochastic intensity $d\Lambda_t^{(i)}$. In our setup, the price jump arrivals are drawn simultaneously.

In the provided specification, we consider positive jumps only on the price jumps. In the case of volatility, the volatility spikes up when the price jump arrives and converges back to the long-term value via the mean-reverting property of the price process.

The data generating process is simulated at a 5-minute frequency; the first tick is at $t_{in}:09:00:00$ and the last tick at $t_{fin}:16:30:00$, with 90 minutes at each day. We further consider that the last tick of a day and the first tick of the following day are identical ticks.

This excludes the accumulation of the economic events overnight we encourage the reader to extend the provided model by adding overnight tick and explicit price jumps in the price process at the opening tick. Such a change allows us to test consecutive days more realistically.

The parameters are captured in the following dictionary:

```
stochVars: {'day':'tIn','fin':'tFin','open':'aOpen','close':'aClose','kappa':'kappaIn','thetaIn':'thetaIn,'omegaIn':'omegaIn','sigmaIn':'sigmaIn,rho1,rho2,rho3,nu1,nu2,nu3,expDist':'09:00:00;16:30:00;0.75;0.25;10.0;10.0;0.0162;0.573;0.58:(neg 0.46);sqrt[0.573];0.2;0.2;0.2;4.0;8.0;0.2;1.25'}
```

Any change of parameters of the data generating process itself is done through the provided parameters dictionary. The parameters further contain some basic setup parameters like the initial and final time of the trading hours.
