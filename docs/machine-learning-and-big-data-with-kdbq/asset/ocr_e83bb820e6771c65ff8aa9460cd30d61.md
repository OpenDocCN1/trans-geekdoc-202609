to explore the outcome:

    ];0.1];

```
`beta`nObservations`dfn`regParameter)!(1.01004 0.998766 -0.9974558

```

The estimated numbers are close to the correct data generating process. The regu-
lisation makes thus sense and ensure our output of useful results. We do
not stop at this point, though, and try to understand what value to choose for our reg-
lisation parameter. Our value of 0.1 seems to provide a meaningful result; however,
in in a general case we do not know the correct data generating process, and we need some
tatistical assessment.

Let us start with the notion of in/out-of-sample and implement a function an-
gous to :quantQ.inOut. We split the sample into two parts: the in-sample part
is used to fit the model. The out-of-sample part is used to evaluate the model
data which has not been used to calibrate the model.

It is important to stress that regularisation is used only during training. One
parameters (regularised) are found, they are applied on the out-of-sample data while
λ is is. When the model is applied to predict values and compare them with the
correct values, regularisation does not play any role. In fact, this estimated
parameters are treated the same as if they came from the plain OLS model. The regular-
parameter does not enter any measure we use to assess the performance of the
model.

We implement the in/out procedure in the following function. The additional
parameter is inOutFlag, which works in the same way as forInOut. It decides
how we split the sample into two subsamples; it adds the RMSE statistics to the
out bucket

```
.quantQ.ridgeInOut:{y;reg;inOutFlag}
// y array of dependent variables
// x array of arrays of independent variables, constants to be
//    included
// regularization parameter for Ridge regression
// inOutFlag = atom/array to form in/out sample, 1=out
whereMissing: raze(where y=0); raze(where x=0) each x);
// remove the missing values
y:[(til count y) except whereMissing];
x:[(whereMissing) x(til count x) except whereMissing)][whereMissing];
//    each x;
inOutFlag is atom, in in sample is randomly chosen inOutFlag fraction of
//    sample
if([(i=count[inOutFlag]);
//    split sample: OUT
xOUT:ceiling[inOutFlag+count y] - flip x;
yOUT:ceiling[inOutFlag+count y] - y;
```
