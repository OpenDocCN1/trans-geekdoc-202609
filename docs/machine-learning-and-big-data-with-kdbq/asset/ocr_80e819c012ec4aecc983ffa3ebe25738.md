# 28.3.1 Random Games

Let us start with the implementation of random playouts of tic-tac-toe. We define the tic-tac-toe game first. The definition is that the game is inherently played on the 3 x 3 board. We encourage readers to change it into any dimension, but that would need the code change throughout the functions and definitions.

The game itself be characterised as a sequence of available moves on the board, performed by two players making moves in turns. We do not explicitly mark the players or make a dictionary between move and type of the player. Instead, we assume that every odd move is made by Player 1 every even move is made by Player 2. The game is thus a sequence of moves and the set of rules which determine the end of the game.

Let us start with the game itself and then add the stopping rule. We need to define a global variable movesSpace which captures all possible moves on the board. This is the set of elements from which the tree will be built.

```
movesSpace:{x1: string first x;x2: string last x; $x1,$x2} each (`a`b`c`) cross (`1`2`3`);
```
