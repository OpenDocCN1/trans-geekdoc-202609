#  13.6.1 Adjusted R-squared

There is a modification to the goodness-of-fit as introduced above which penalises the measure for the number of independent variables. The adjusted R$^2$ is based on the same principles as $R^2$, i.e. the ratio of unexplained variance to the total variance, except that the measure of variance is adjusted for the total number of degrees of freedom. In particular, let us denote the adjusted $R^2$ as $R^{-2}$ and define it as:

> $R^2 = 1 - \frac{RSS}{TSS}$
$$1 - \frac{RSS/df_p}{TSS/df_0}$
$$1 - \frac{RSS(n-1)}{TSS(n-p-1)}$$

$\overline{R^2}$ denotes the adjusted residual to the sum. The adjusted $R^2$ is the total sum of squares, $df_p$ is the total number of degrees of freedom for a model with $n$ data points, $p$ independent variables and constant, $df_p = n-p-1$, and $df_0$ is the total number of degrees of freedom for a model to equal constant.

The adjusted $R^2$ is no longer equivalent to the sum of the correlation coefficient for the univariate, neither is it a non-increasing function with the number of independent variables added to the model. The adjusted measures the trade-off between the explanatory power of the model and its parsimoniousness; thus the adjusted $R^2$ is increasing with additional variables if the unexplained variance is decreasing than $(n-p-1)$.

It is worth noting that adjusted $R^2$ is no longer bounded within $[0, 1]$. The adjusted $R^2$ can be an objective of the researcher when modelling the data trade-off is fully reflected. However, we do not recommend to use the adjusted $R^2$ as the criteria to be maximised without further considerations.
