Then, we can explore the properties of the projected y:

```
$$\hat{\mathbf{y}} = \mathbf{X}\hat{\beta} = \mathbf{X}(\mathbf{X}^	op\mathbf{X})^{-1}\mathbf{X}^	op\mathbf{y}. (13.23)$
```

where the matrix $H := \mathbf{X}(\mathbf{X}^	op)^{-1}\mathbf{X}^	op$ is known as the hat matrix – because it takes $\mathbf{y}$ and puts a hat on it, $\hat{\mathbf{y}}$. In our example, the matrix reads:

```
$H = \mathbf{X}(\mathbf{X}^	op)^{-1}\mathbf{X}^	op = \mathbf{XX}^	op = \begin{pmatrix} 1 & 1/26 & 3/26 & 4/26 \ 3/26 & 9/26 & 12/26 \ 4/26 & 12/26 & 16/26 \end{pmatrix}. (13.24)$
```

Matrix $H$ is one of the so-called orthogonal projection matrices. Let us check that it has the properties of orthogonal projection matrices:

# Symmetric

The matrix is symmetric as can be seen from:

```
$$\mathbf{H}^	op = (\mathbf{X}(\mathbf{X}^	op\mathbf{X})^{-1}\mathbf{X}^	op)^	op (13.25)$$
$$ = (\mathbf{X}^	op)^	op[(\mathbf{X}^	op\mathbf{X})^{-1}]^	op\mathbf{X}^	op (13.26)$$
$$ = \mathbf{X}[\mathbf{X}^	op\mathbf{X}]^{-1}\\mathbf{X}^	op (13.27)$$
$$ = \mathbf{X}(\mathbf{X}^	op\mathbf{X})^{-1}\mathbf{X}^	op = \mathbf{H}. (13.28)$
```

# Idempotent

The matrix is idempotent:

```
$$\mathbf{H}^2 = (\mathbf{X}(\mathbf{X}^	op\mathbf{X})^{-1}\mathbf{X}^	op)(\mathbf{X}(\mathbf{X}^	op\mathbf{X})^{-1}\mathbf{X}^	op) (13.29)$$
$$ = \mathbf{X}[(\mathbf{X}^	op\mathbf{X})^{-1}(\mathbf{X}^	op)(\mathbf{X})(\mathbf{X}^	op)^{-1}]\mathbf{X}^	op (13.30)$$
$$ = \mathbf{X}(\mathbf{X}^	op\mathbf{X})^{-1}\mathbf{X}^	op = \mathbf{H}. (13.31)$
```
