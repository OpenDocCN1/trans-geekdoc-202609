## 22.1.4 Overfitting

Neural networks are prone to overfit the model. They potentially contain a large number of parameters and fully connected networks need to adapt to the data too much. A popular choice is weight decay, where the function $Loss(Y,X;\Theta)$ contains equivalent penalty to the magnitude of the parameters of the model.

```
$Loss(Y,X;\Theta) \rightarrow Loss(Y,X;\Theta) + \rho \left(\sum_{n}\rho_n^{(i)}}^2 + \sum_{m}\alpha_m^{(n)}}^2\right), \quad (22.21)$
```

with $\rho$ driving the regularization.

Another popular method is dropout, Srivastava et al. (2014). The dropout is so equivalent to ridge regression and all faults. At every iteration step, we select which nodes will be updated according to a predetermined probability $p$ (this is a parameter of the regularization analogous to $\rho$ in the preceding paragraph). The nodes which have not been selected are physically removed from the network with all the connections and are not updated during the given iteration. After the iteration, the updated nodes are merged with the nodes which have been excluded.

Further, excluding the node from training means we lose some information and tend to emphasize the effect of the nodes which have been preserved. This means that we have to weigh the output of all nodes at the end by probability $p$. This will create a fully connected network with all the nodes included in the training situation.

Additional to regularization, with $p=0.5$, we can reduce the number of parameters to half, which may significantly speed up the calibration. Dropout technique is both a regularization method as well as a speed-up improvement and is gaining popularity in the machine learning community, especially for complex networks.

## 22.1.5 Dimension of the Hidden Layer(s)

We consider the neural network with one hidden layer. In general, nothing prevents us from creating a topology of the neural network with more hidden layers. It is in fact topology with a large number of hidden layers which brought fame to neural networks. Deep networks – how the neural networks work – learn complex patterns and, generalize the concepts. It is not fully understood what makes the deep networks successful in generalization.

Let us put aside deep networks and discuss the dimension of the hidden layer(s). Going beyond one hidden layer allows us to create a network able to model highly complex and nonlinear features. This brings the need for optimization of a large number of weights. For this, not only a huge data set is needed, but also proper training techniques and regularizations have to be well thought out.

For the case of one hidden layer, the question is what should be the dimension of the hidden layer, $N$. Since the dimension of the input (features) is $M$, we compare the dimension of the hidden layer relative to the size of the input. In the case of $N < M$, there is information suppression in the hidden layer as we aim to represent $M$-dimensional input through $N$-dimensional variables. Thus, it is recommended to use $N > M$ so that we can model nonlinear dependencies in the features.

There is, in fact, a reason to use $N < M$. Imagine the case when $Y = X$ and thus $L = M$. Such a setup allows to model the input variables and use the features to explain themselves. If we use $N < M$, the role of the hidden layer is to compress the input such that we can recover the input as much as possible. This is nothing but dimensional reduction, given we use the hidden layer to represent the input data. It can be shown that this is equivalent to the PCA. Then we can obtain PCA without the need to perform advanced matrix multiplications. The extreme case of $N=1$ means we want to compress the input into a single scalar factor.

### 22.2.1 Multivariate Encoder

It is convenient to map the $M$-class classification problem, where the dependent variable can take $M$ discrete values into an $M$-dimensional variable where every individual component is a binary variable. Such a transformation is not the most economical; we waste at least one dimension. Models are conveniently simple ones, and the extra dimension of the dependent variable does not cause in most of the situations during learning.

To implement the multivariate classifier, we need to use the $M$-class discrete binary into $M$ binary variables. The function `encoderMulti` takes as an argument ($M$ discrete cases of the dependent variable) and returns a dictionary, which can be used as a function to create a list of binary variables:

