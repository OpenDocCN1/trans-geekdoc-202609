# 21.3 FEATURE SELECTION: LOCAL NEAREST NEIGHBOURS APPROACH

The concept of nearest neighbours as introduced above is a rather brute force approach which aims to exploit similarity between past observations for the prediction of future states. In this section, we employ the nearest neighbours for feature selection or even in real time. as was introduced by Navot et al. (2006). The aim of the proposed method is not a prediction, but dimensionality reduction in the space of the independent variables.

The method comes from the field of biostatistics; it was invented for analysing neural activity, namely, to search through the high-dimensional space of neural features and explain the particular activity. The proposed algorithm extends the leave-one-out algorithm with mean-squared-error, where the optimal feature set is found using the forward selection algorithm, investigating of features by one. The proposed algorithm assigns weights to features and a score. This makes the problem differentiable, so the gradient can be calculated analytically and gradient descent of algorithms can be used to find the optimal weights. The features can be sorted by the assigned weights.

The method can also be viewed as an extension of the kNN regression, which assigns the value of a dependent variable for a point x, being n-dimensional vector of independent variables, based on the average value of the neighbourhood N:

```
\hat{y} = \frac{1}{\text{card N}} \sum_{x\in N} y(x'), \quad (21.5)
```

the average of the value of the dependent variables in the neighbourhood of y(x). The neighbourhood is defined in the same way as the previous sections. Analogously to the distance-weighted function we define the weighted regression based on the proximity, $L_2$ distance, as:

```
\hat{y} = \frac{1}{\sum_{x\in N} e^{-\frac{1}{2}\|x-x'\|^2}} \sum_{x\in N} y(x')e^{-\frac{1}{2}\|x-x'\|^2} \quad (21.6)
```

The factor in front of this normalises the estimate – average – based on the weights derived from $\|x-x'\|$. The weights do not have to be normalised.

The purpose of the algorithm is to assess the importance of individual independent variables. We thus introduce the weighted:

```
\|x-x'\|_W^2 = \sum(x_i - x'_i)^2 w_i^2, \quad (21.7)
```

where $w_i$ is an $n$-dimensional vector of weights, which puts emphasis on different independent variables. We do not need to impose any normalisation on weights.
