Auer et al. (2002a) elaborated the outlined approach and introduced the Upper
Confidence Bound algorithm. In order to formulate Upper Confidence Bound-
 its convergence properties, we need to impose an assumption on the distri-
bution of the individual arms: every distribution is $\sigma^2$-sub-Gaussian. Namely, we define
the running average of the i-th arm at time t:

```
$\mu_{i,t} = \frac{1}{\#(i,t)} \sum_{s\le t} X_{i,s}. (28.8)
```

where $(i,t)$ stands for the number of instances the strategy chosen has been i,
and $X_{i,t}$ being the realisations of the random variable $X_i$ in such cases.
The Upper Confidence Bound algorithms are based on the theory which says:

```
$P \ \mu_{i,t} \ge \mu_i + \frac{\sigma^2 \log \frac{1}{\delta}}{\#(i,t)} \le \delta || P \ \mu_{i,t} \le \mu_i - \frac{\sigma^2 \log \frac{1}{\delta}}{\#(i,t)} \le \delta, (28.9)
```

for positive real $\delta$, if the bandit is played sufficiently many times, the probability
we choose the one is going to zero. Auer et al. (2002a) for proofs.
The algorithm then follows these lines:

+   - Provide $\sigma^2$ and a sequence of probabilities $\delta_1,\ \delta_2,\ \delta_3,\ \dots$
- Initialise the algorithm by choosing every arm i once.
- Choose a strategy such that every time t, the index i results from:

```
$i = \arg \max_{i} \mu_{i,t} + \sqrt{\frac{\sigma^2 \log \frac{1}{\delta_i}}{\#(i,t)}} (28.10)
```

Practically, if the reward of each arm is $[0,1]$, the parameter $\sigma^2=1/4$\nbe a suitable choice using Hoeffding's lemma. The convenient choice for
the sequence of probabilities is:

```
$\delta_t = \frac{1}{t^2}. (28.11)
```

Such a choice of parameters provides an algorithm that optimises the Upper
Confidence Bound and is adaptive enough to avoid some pathological cases
which may occur – for instance, if one arm dominates some other arms, then under certain
circumstances the regret of the algorithm may be infinite. This will cause pathological
behaviour as a difference between an optimal arm and any other arm will be infinite.
