Finally, the model decides the class based on the sign of $G_l$, i.e.

$\hat{y} = 	ext{sign } G_l(x), \quad (23.5)

where the class of zero means indecisive outcome. We decide the value in such a case randomly; the probability to obtain such a class is theoretically zero (numerically, it is still possible).

# 23.4 IMPLEMENTATION OF ADABOST

We start by specifying the format of the data set. The hypothetical meta-a of the data set reads:

| c | t f a |
|---|---|---||
| y | j |
| weights | f |
| x0 | f |
| xN | f |

The first column corresponds to the dependent variable y taking values $\{-1, 1\}$. The second column is a vector of weights $w_j$. The third and further columns correspond to the independent variables or features. Due to the nature of the stump, we need to add for every column its negative counterpart. Such a construction allows us to capture both direct proportionality as well as inverse proportionality. Adding the negative features is done through the function addNegFeatureTable:

```
quantQ.addNegFeatureTable::[tab]
// tab input table, 3rd column onwards are
colsx: 2 cols tab
coly: first cols tab
// add negative features
.tab, flip raze[tab;yy;name] flip
eval (?tab;tab);ob(elist('$string[name],"n")!enlist (-;name))
[tab;coly]; each cols;
```
