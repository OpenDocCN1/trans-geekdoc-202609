The measure in particular useful when we search a document on several search queries. In such a case, the metrics are combined, and relevant document(s) is(are) chosen based on the combination of outcomes. We extend the polar bear example and imagine someone was looking for a combined query of "gargalesthesia" and "polar bear". The originator of the query could be an author of tales for children, who is writing a book about tikling polar bear, and for the sake of curiosity, to know if you can tick a polar bear.

The two terms are very different in terms of frequency of appearance. Although everyone has heard of polar bears, it is likely that gargalesthesia, the sensation commonly associated with tickling, has never been heard of by a number of readers. In October 2018, there were approximately 10,000 more pages found by google.com search engine for the term "polar bear" as opposed to "gargalesthesia". Thus, a document which has fewer mentions of "polar bear is not relevant for the writer without "gargalesthesia being contained in it. A fully devoted to polar bear could provide some hints, where some physiological features of polar bears can be described and give hints about the original query. On the other hand, a document out of the search query with few mentions of "gargalesthesia" can be relevant and as a feasible document with only a few mentions of "polar bear" is not contained in it.

This provides hints on how to optimise the web pages to be. If we write a text about a polar bear, mentioning only one does not give many chances to be found by algorithms in the preceding paragraphs. Further, it is worth using different synonyms for features described in the text. This gives a flavour of uniqueness into the text. As we have discussed above, the first component is a word frequency, or term tf in the definition. This corresponds to ϕsentence(w), where sentence is understood as a bag of words we want to classify. We can use the definition in (27.2),

```

```

```
$tf_{sentence;boolean}(w) = 1(w \in sentence),$
```

```
$tf_{sentence;relative}(w) = \frac{\sum_{w' \in sentence}1(w')}{\sum_{w' \in sentence}}$
```

or

```
$tf_{sentence;log}(w) = \log(1 + \phi_{sentence}(w)).$
```
