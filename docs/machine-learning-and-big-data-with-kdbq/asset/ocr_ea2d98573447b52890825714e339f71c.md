The learning by batches works so that we perform a single update of the parameters using a batch of data. The iteration progresses to the next step, when another batch is chosen and the parameters are further updated. It is convenient to refer to an epoch as the set of iterations which went through the entire training data.

# 22.1.2 The Learning Rate Parameter

The critical parameter in the backpropagation algorithm is the learning rate $\lambda$. If the parameter is too big, the update is massive and respond too harshly to the errors. This would be unpleasant when we are close to the solution: we would be forced to step over the optimum. On the other hand, a small value will cause the convergence to be too slow and numerically inefficient.

These problems could occur by letting $\lambda$ depend on the progress through iterations. Let us denote the index of the iteration by $

We can consider more advanced procedures. The learning rate parameter can depend on the error and be progressively chosen as needed. It can contain elements of stochastic annealing, even when converging to a specific value, the learning rate parameter can be suddenly increased, trying to probe the neighbourhood and prevent being stuck in the local solution. Even more advanced techniques, suitable for deep networks, would involve periodically decreasing $\lambda_

u$ reaches its minimum solution. The set of all such solutions then constitutes the set of we learners, which can be combined as trees in the forest.
