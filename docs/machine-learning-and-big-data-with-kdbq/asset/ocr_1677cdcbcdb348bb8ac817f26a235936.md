# LANGUAGE FUNDAMENTALS

The each-adverb can be used to add columns to tables as tables are the list of records.

```
tbl1::[[]c1::`a`b`c);
tbl2::[[]c2::(1f;2f;3f));
```

```
tbl1, `tbl2
```

joins the column of tbl11 with the column of tbl12:

```
c1 c2
---
a 1
b 2
c 3
```

The adverb * can be applied to user-defined functions:

```
(4 5 6f) {x*y}(5 6 7f)
```

The code applies the adverb * on the function x*y with arguments (4 5 6f) and (5 6 7f). In this trivial example, it is equivalent to calling the dyadic function x*y on the two lists ((4 5 6f); (5 6 7f)) with the dot notation:

```
[x*y] . ((4 5 6f); (5 6 7f))
```

```
20 38 42f
```

Note that in many cases, the native q functions will be sufficient on a pair of lists, having out to apply the each or each-both * adverbs.

For example, the dot product between two vectors,

| a1 | b1 |
| a2 | b2 |
| ... | ... |
| an | bn | = a1b1 + a2b2 + ... + anbn , | (3.1) |

need not to be defined as:

```
x: 1 2 3f
y: 3 4 5f
sum x * ` y
```

```
26f
```

since the native multiplication operator already applies on two vectors, as we have seen. So the above can be simplified to

```
sum x * ` y
```

```
26f
```
