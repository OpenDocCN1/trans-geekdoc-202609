# 16.4.5 Dimensionality Reduction

Finding the patterns in the data which can help us explain the dependent variable suffers the bias-variance trade-off. This can be explained as follows. The squared bias typically decreases with increasing model complexity, and variance increases with increasing complexity, and total error is the sum of the squared bias and variance components, so there is usually an optimal model complexity at which the total error is minimised.

Restricting complexity can be achieved by considering only a subset of available features. In particular, we may truncate our vector at $1 \leq d < p$ columns by removing the columns $d+1, d+2, \dots, p$:

```
$$\mathbf{W}_d = \begin{pmatrix} \\mathbf{w}_{(1)} & \mathbf{w}_{(2)} & \dots & \mathbf{w}_{(d)} \endend{pmatrix} \in \mathbb{R}^{p \times p}. \quad (16.77)$
```

Thus we keep only the first $d$ principal components:

```
$$\mathbf{Z}_d := \mathbf{X}^T \mathbf{W} \in \mathbb{R}^{n \times d}. \quad (16.78)$
```

Since

```
$$\text{Var}[\mathbf{Z}] = \text{Var}[\mathbf{X}^T \mathbf{W}] = \mathbf{W}^T \text{Var}[\mathbf{X}] \mathbf{W} \approx \mathbf{W}^T \mathbf{C} \mathbf{W} = \mathbf{\Lambda}, \quad (16.79)$
```

and, similarly,

```
$$\text{Var}[\mathbf{Z}_d] = \mathbf{\Lambda}_d, \quad (16.80)$
```
