## 12.3.4 t-test: Two Samples

In the previous, we tested one sample against a static mean value. In practice, we may want to test two samples that have the same mean. Let us consider independently drawn sample $X_1, ..., X_N$ representing $N$ draws of a random variable $X$, which has a population mean $\mu_1$ and a standard deviation $\sigma_1$, and independently drawn sample $y_1, ..., y_M$ representing $M$ draws of a random variable $Y$, which has a population mean $\mu_2$ and standard deviation $\sigma_2$. The hypothesis to be tested is of the form:

- $H_0$: The population means are equal, $\mu_1 = \mu_2$.
- $H_a$: The population means are different.

The test is done by constructing a suitable test. The form of the statistic depends on the assumptions imposed on $N$ and $M$, and $\sigma_1$ and $\sigma_2$, respectively. The stronger the assumptions, the closer to asymptotic behaviour but more prone to model error. In this test, we focus on the least restricted of the two-sample $t$-statistic, also known as Welch's test. In such a case, there is no assumption imposed on the relationship between $N$ and $M$, $\sigma_1$ and $\sigma_2$. The Welch $t_W$ statistic is defined as:

```
$t_W = \frac{\bar{X}-\bar{Y}}{s_W} \ (12.17)$
```

where $s_W$ is defined as:

```
$s_W = \sqrt{\frac{\frac{1}{N-1}\sum_{i=1}^N(X_i-\bar{X})^2}{\frac{1}{M-1}\sum_{i=1}^M(Y_i-\bar{Y})^2}} \ (12.18)$
```

The Welch's $t_W$ statistic follows under the null hypothesis $\sim t_{Wdf}$, where the number of degrees of freedom is:

```
$W_{df} = \frac{(\frac{\sigma_1^2}{N}+\frac{\sigma_2^2}{M})^2}{\frac{(\frac{\sigma_1^2}{N})^2}{N-1}+\frac{(\frac{\sigma_2^2}{M})^2}{M-1}} \ (12.19)$
```

We can form following hypotheses using the test $t_W$ statistic:

- $H_0$: The population $\mu_1$ is equal/smaller or equal/larger or equal to population $\mu_2$.
- $H_a$: The population $\mu_1$ is different/larger/smaller to population $\mu_2$.

The three tests, the two-sided and two one-sided tests, can be assessed in the previous case. We reject the null if $|t_W| > t_{critical,Wdf}$, $t_W < -t_{critical,Wdf}$, and $t_W > t_{critical,Wdf}$ respectively. However, we will assume the critical value $t_{critical,Wdf}$ depends on the significance level in the test, the asymptotic behavior and based on normal distribution.

## 12.3.4.1 Implementation

The calculation of the $t_W$ statistic is given as:

```
quantQ.stats.tTestTwoSample{x1;x2}
// x1,x2 -- arrays to be tested, unequal
// return Welch's statistics
// (avg[x1]-avg[x2])/sqrt((dev[x1]/count[x1])+(dev[x2]/count[x2]))
```

We test the function using two samples with the same mean but different size and variance:

```
quantQ.stats.tTestTwoSample[x1:100;1.0;x2:100]
```

## DATA SCIENCE

The value is then transformed into the corresponding p-value using the normal distribution:

```
quantQ.stats.pValueTwoSided abs quantQ.stats.tTestTwoSample[x1;x2]
```

The result suggests that we cannot reject the null hypothesis and thus conclude that two samples have the same mean as implied by the alternative hypothesis.

## 12.3.5 Sign Test

The sign test is a non-parametric test to assess the statistical difference between pairs of observations drawn from related populations. For example, consider a set of investors who invest every month and report their performance. If the general market conditions remain the same, the effect of the service can be estimated by comparing the performance before and after for a sample of investors. If the effect of the service is not material, then before/after comes from the same distribution. In particular, if every investor can have a different distribution – mean, sigma, or kurtosis, for example — we do not compare across investors. Instead, we should assess the statistical properties of the difference before/after. If the effect of the service is irrelevant, the distribution of differences should be symmetric around zero. On the other hand, if the difference is positive/negative, the effect is correspondingly negative/positive.

Let formulate the sign test explicitly: consider two related populations, $X$ and $Y$, and related pairs of draws, $(x_i, y_i)$, with $i=1\dots N$. Each population is continuous, and the two populations are ordinal, i.e. we can order any pair $(x_i, y_i)$. We further denote the inequality between $x_i$ and $y_i$. For the sake of simplicity, we assume that $x_i=y_i$ is not possible (with probability 0), and discuss ties in subsequent tests. Further, every pair of draws are independent of each other.

The ordinal variables may not be necessarily numeric. Consider for example a string of characters, which is not numeric, but we can easily sort the string alphabetically. In any case, we define the difference between $x_i$ and $y_i$ as $\delta_i = x_i - y_i$ for non-numerical variables where the difference can be defined as:

$$\delta_i = \begin{cases} +1, x_i > y_i; -1, \text{otherwise.} \end{cases}$$ (12.20)

Then, the basic formulation of the sign test tests:

- $H_0$: The difference between $x_i$ and $y_i$, $\delta_i = x_i - y_i$, has the same probability to be positive as negative.
- $H_0$: The difference between $x_i$ and $y_i$ is skewed towards positive or negative values.

## Basic Overview of Statistics

Alternatively, we can formulate one-sided tests:

- $H_0$: The difference between $x_i$ and $y_i$, $\delta_i = x_i - y_i$, is more likely to be positive/negative.
- $H_1$: The difference between $x_i$ and $y_i$ is either equally distributed for positive and negative values, or skewed towards negative/positive values.

Since the test is concerned with the sign, we can encode the difference as:

```
$z_i = \Theta(\delta_i),$
```

where $\Theta$ is a Heaviside step function. For the purpose of the test, the draws with the same value, $\delta_i = 0$, are discarded.

Under the null hypothesis, the sample of sign variables $z_i$ is drawn from the binomial distribution with $p = 0.5$. The (relevant) properties of the binomial distribution binomial$(N, p)$ can be summarized as:

- Mean of the sum: $\mu = Np$
- Variance of the sum: $\sigma^2 = Np(1-p)$.

The binomial distribution can be approximated by the normal distribution $N(\mu, \sigma^2)$ for reasonably large $N$. In general, a population larger than 30 observations can be approximated by the normal distribution. This fact can be used to perform tests of the null hypothesis for symmetrically distributed $\delta_i$,

When the sample is small the normal distribution cannot be used and we have to calculate the properties of the probability density function explicitly. Namely, the probability density function of the binomial distribution is defined as:

```
$pdf(n, N; p) = \binom{N}{n} p^n(1-p)^{N-n},
```

with the binomial number $\binom{N}{n}$ defined as:

```
$$\binom{N}{n} = \frac{N!}{n!(N-n)!},
```

We can use the knowledge of the binomial probability distribution function to calculate the null hypothesis $n$ cases of $z_i = 1$ in the sample of $N$ observations under $p = 0.5$. For a one-sided test of observing $z_i = 1$ less frequently than $z_i = 0$ we have observed $n$ instances with $z_i = 1$ out of $N$ cases, we calculate

```
$$\sum_{i=0}^{n} pdf(i, N; p = 0.5).$
```
