
## 3.2.3 Compose (')

The composition of a multivalent function f[a;b;c;...] with a monadic function g[x], expressed mathematically as gof, is defined as [g; f]. For example:

```
f:[a;b;c;d]a+(2*b)+(3*c)+4*d);
g:(log x);
d:('[g;f]);
d[5;6;7;8]);
```

computes log(5 + (2 * 6) * (3 * 7) * 4 * 8) = log(70), which is returned:

```
4.284895
```

## 3.2.4 Over and Fold /

The over adverb / modifies a dyadic function to accumulate the results over a list. Let us denote $y_i, i \in n^t$ element of a list $y$ of length $n$. The expression $x/ y$ recursively applies the function $f$ on $x$ and each element of $y$, i.e., computes expression $f[..;f[x;y_0];y_1];..;y_{n-2}];y_{n-1}]$.

The expression:

```
4f {x-y exp 2)/(5 6 7f)
```

is equivalent to:

```
(((4f-5f exp 2)-6f exp 2)-7f exp 2)
```

and returns:

```
-106f
```

The over adverb / can also be applied to monadic functions without specifying an accumulator $x$. The expression $(f/)$ on the list computes nested functions $f[..;y_0];..;y_{n-1}]$. Hence, the expression

```
{(x-y exp 2))/(5 6 7f)
```

computes:

```
(5f-6f exp 2)-7f exp 2)
```

and returns:

```
-80f
```

In prefix forms, the two previous expressions are written as follows:

```
{(x-y exp 2)}/[4f;(5 6 7f)]
((x-y exp 2)][(5 6 7f)]
```

## LANGUAGE FUNDAMENTALS

The over advert is often called fold when the function has two arguments. The expression $f[/x;y;z]$ computes expression $f[f..f[x;y_0];y_1;z_1];..;y_{n-2};z_{n-2}];y_{n-1};z_{n-1}]$.

```
{{x-y exp 2)}/(1 3f; 4f; 2f)
```

computes

```
( 2f + (2f+1f-4f exp 2) - 5f exp 2; 2f + (2f+3-4f exp 2) - 5f exp 2)
```

and returns:

```
-36 -34f
```

The advert can also be thought of in a map-reduce context, where we fold, i.e., reduce, the result. A very useful built-implementation of this is the function raze, which folds the input list into a single element:

```
raze (1 2 3;4 5 6)
```

Examining the implementation of raze reveals that it is the comma-join with the advert fold:

```
raze //)
```

and

```
(,/) (1 2 3;4 5 6)
```

+ 1 2 3 4 5 6

## 3.2.5 Scan

The scan behaves as the over advert except that intermediary results are shown after each accumulation. Hence, $f \y$ iteratively computes expression $f[f..f[x;y_0];y_1;..y_{n-2}];y_{n-1}]$ and displays each intermediary result $(x;f[x;y_0];y_1;..f[x;y_0];y_1];..f[f..f[x;y_0];y_1];..y_{n-2}];y_{n-1}])$.

We saw in our previous example that

```
{(x-y exp 2)}/(5 6 7f)
```

only returns the final result of the computation, i.e. $(5f - 6f exp 2)-7f exp 2 -80f$

while

```
{(x-y exp 2)\}(5 6 7f)
```

shows the intermediary results:

```
where5f is the first item of the x variable,--31f = 5f - 6f exp 2 and-80f = (5f - 6f exp 2) - 7f exp 2.
```

### 3.2.5.1 EMA: The Exponential Moving Average

Let's see how can be applied to compute this very common iterative function we want the intermediate results of the time series. Given a vector $x_0,x_1,...,x_i,...,x_j...xn$ and a weight $\lambda$, the EMA at point $i$ is defined as:

```
$EMA_{i}(\lambda) = x_{i-1} \times (1-\lambda) + EMA_{i-1} \times \lambda$
```

where $EMA_{0} = x_{0}$.
Given the vector 20 30, and a lambda of 2, the EMA at each point will be:

| Point | Calculation | Result |
| :--- | :--- | :--- |
| 0 | $x_0$ | 20 |
| 1 | $20 \times 0.8 + 30 \times 0.2$ | 22 |
| 2 | $22 \times 0.8 + 30 \times 0.2$ | 23.6 |

We can use scan to implement the above:

```
.stats.expma1::[lambda;vector]/ lambda -- memory
/ vector
```

Note that, since version 1, q has an optimisation which simplifies

```
{{z+y+x}\x;y]}
```

to

and our function can thus be written as

```
.stats.expma:[lambda;vector]]
// memory
// data
:(first vector)(-lambda)\vector+lambda;
```

q has a built-function for EMA, namely ema, which takes two arguments and has the equivalent definition. Nonetheless, our derivation of this function using scan has hopefully illustrated how we can write iterative code using adverbs and will be of use in other analytics we will encounter later; one example being the implementation of consecutive runs, as we see in Chapter 1.

## 3.2.6 Converge

The over / scan recursively apply a function to each item of a list. They can also be used to iterate over a list until a loop is detected.

### 3.2.6.1 Converge-repeat

The recursive pattern

```
f/ y
```

applies the function f times with initial value y. If x is a boolean to indicate a condition on recursive iteration, the expression is equivalent to while loop:

```
x:y; / initial condition
while[x;f]
```

The following expression recursively applies the function x-1 2 times on the list

```
(2 {x-1}/2 4 3 5f)
```

and returns:

```
2 132 30 380f
```

It is equivalent to applying the result of the first iteration:

```
1{x-1}/(2 4 3 5f)
```

```
2 12 6 20f
```

to the function x-1.

```
1{x-1}/2 12 6 20f
```

The following expression recursively applies the function x*x starting with the value 2 until the condition x<20 is fulfilled:

```
<x<20>{x*x}/2
```

and returns:

```
256
```

The function x*x is first applied on 2. As the result 4 is less than 20, the iteration continues and produces 256. The converge-iterate pattern is similar to the converge-repeat pattern described in the previous section but the scan advert to display all intermediary results. Hence, the previous example applied using the scan

```
2 {x-1}\2 4 3 5f
```

returns each intermediary results of the recursive iteration:

```
2 4 3 5
2 12 6 20
2 132 30 380
```

The first line displays the input parameters, the second line the result of the first iteration and the third line the final result.
Given the random function rand which returns a random between Ø and x, the expression:

```
{Ø.<x} rand\10f
```

written in prefix format as:

```
rand\[{.<x};10f]
```

repeated calls rand with parameter 10f until the condition Ø.7<x is not satisfied.

```
10 7.263142 6.694028 1.211308 0.7794329 0.2265884
```

When only takes a single argument, it will iterate until it converges to a value. Convergence means repeated items (for non-float datatypes) or equality within float tolerance. Each output of an iteration is the output of the next call.

Let us look at two examples, with integer convergence and with float. Let f to be a function which always adds 1 to the result of the rand call. The output of this call will be the input of the next iteration, so we add 1 to guarantee that we always sample from a non-zero number.

## 3.3 APPLY

The verbs @ and . apply a multivariate mapping to a list of arguments, written in prefix or infix form. Sections 3.3.1 and 3.3.2 describe the differences between the two notations.

### 3.3.1 @apply

The verb @ is used to apply a monadic function f on indices I of a list. The following expression applies the function cosine on the first and third elements of the list; the second element 1.570796 left unchanged:

```
@[(0.7853982; 1.570796; 3.141592654); 2; cos)]
```

It returns cos 0.7853982; 1.570796; cos 3.141592654:

```
0.707108 1.570796 -1
```

When applied to dyadic, @[L; f; a] applies a dyadic function f on the I-th elements of list L with second argument a. Example:

```
@[1 2 3 4f; 0; {x+2y}; 6 7f]
```

applies the function x+2*y on the first and third elements of 1 2 3 4f, namely 1 and 3 and the second argument 6 7f. The values of L=1 2 3 4f for all elements not in Ø 2 are returned, i.e. L@1=2 and L@3=4f. The expression computes 1+2+6f 2+3*7f 4f:

13 2 17 4f
