## 22.3.3 Regression

The third example is to regress, where the dependent variable is a real-valued array. We have mentioned in the introductory part that by suitable choice of the neural network parameters, we can turn the network into a dimensionality reduction tool. We explore this situation in our example as it provides both a handy and practical tool.

In particular, we select the case of four real-valued features. Each feature is constructed as a linear combination of a common factor and an idiosyncratic noise:

$x_i = c_i \cdot \phi + \sqrt{1 - \alpha_i^2} \cdot e_i$ with $i = 1, \dots, 4,$

where $\alpha_i$, is a parameter within $[0, 1]$, $e_i$ is an idiosyncratic noise, and $\phi$ is a factor across different features. The factor and the idiosyncratic noise have the same variance thus all the features have the same variance as.

We employ the uniform distribution to define factor and idiosyncratic noise variables:

```
factor:neg[1]+2*500?1;
tmp1:neg[1]+2*500?1;
tmp2:neg[1]+2*500?1;
tmp3:neg[1]+2*500?1;
tmp4:neg[1]+2*500?1;
```

The features are defined as linear combinations defined in eq. (22.24) with corresponding coefficients:

```
c1:0.2;
c2:0.4;
c3:0.6;
c4:0.0;
cX1:(c1*factor)+sqrt[1-c1*c1]+tmpC1;
cX2:(c2*factor)+sqrt[1-c2*c2]+tmpC2;
cX3:(c3*factor)+sqrt[1-c3*c3]+tmpC3;
cX4:(c4*factor)+sqrt[1-c4*c4]+tmpC4;
```

The last factor is not correlated to the common factor. Let us confirm that the correlation between factor and the features reflects the corresponding factors:

```
cor[cX1; factor];
```

We can proceed to train the neural network. We start with a similar parametric set-up as the binary classification case. In particular, we choose 1 neuron in the hidden layer.

```
modelC1::quantQ.nn.modelNN[flip "f$(xC1;xC3;xC4); flip "f$(xC1;xC2;xC3-xC4);i;count;100;0.01;'linearReg];
```

The focus is on the evaluation during the iteration. The provided model does not converge, and thus the reader could realise the number of iteration steps would be too large. This brings a useful insight: we should start with a smaller case using a few iterations and investigate the evolution of the training. Then, the full-scale learning.

Figure 22.3 depicts the learning path as a function of the iteration index. Contrary to previous cases, we plot log of the error in order to envisage the divergence of errors. The model does not converge, and thus we have to change the parameters of learning. The suspected parameter to be changed is the learning rate which may be too coarse, thus usging from the optimal values.

The data for the figure has been extracted as:

```
select Counter, log Error from modelC1 i>0
```

Let us repeat the training of the model with smaller learning rate parameter, in case 0.01. We should run the model for 3000 steps:

```
modelC2::quantQ.nn.modelNN[flip "f$(xC1;xC2;xC4); flip "f$(xC1;xC2;xC3-xC4);i;count;3000;0.001;'linearReg];
```

Figure 22.4 depicts the learning path (error) as it progresses through the iterations. The procedure converges in this case; the model is learning. The improvement of the error is approximately 50%, relatively mediocre improvement compared to all previous cases where the improvement have been in the.
