Forecasting the ARMA process follows the same principle. Given the ARMA process
X_t = \Phi_1 X_{t-1} + ... + \Phi_p X_{t-p} + \epsilon_t + \alpha_1 \epsilon_{t-1} + ... + \alpha_q \epsilon_{t-q},

the one-step ahead forecast is $X_{n+1} = \Phi_1 X_n + ... + \Phi_p X_{n-p+1} + (\epsilon_{n+1} = 0) + \alpha_1 \epsilon_n + ... + \alpha_q \epsilon_{n-q+1}$. The two-step ahead forecast is $X_{n+2} = \Phi_1 X_{n+1} + ... + \Phi_p X_{n-p+2} + (\epsilon_{n+2} = 0) + \alpha_1(\epsilon_{n+1} = 0) + ... + \alpha_q \epsilon_{n-q+2}$. The third-step ahead forecast is $X_{n+3} = \Phi_1 X_{n+2} + ... + \Phi_p X_{n-p+3} + (\epsilon_{n+3} = 0) + \alpha_1(\epsilon_{n+2} = 0) + \alpha_2(\epsilon_{n+1} = 0) + ... + \alpha_q \epsilon_{n-q+3}$. The $q+1$ step ahead forecast is $X_{n+q+1} = \Phi_1 X_{n+q} + ... + \Phi_p X_{n-p+q+1} + (\epsilon_{n+q+1} = 0) + \alpha_1(\epsilon_n = 0) + ... + \alpha_q(\epsilon_{n+1} = 0)$. We clearly see that the moving average terms depends. The implementation of this function is left as an advanced exercise for our readers. The function .quantQ.ts.forecastARMA has to be amended to tackle the case of ARMA.

# 14.2.1 Stationarity

A stochastic process is said to be stationary if its statistical properties do not change with time. Formally, a time series $X_t, t \in \mathbb{Z}$ is weakly stationary or wide sense stationary if:

+   - It has a finite variance $Var(X_t) < \infty$ $\forall t \in \mathbb{Z}$.
- The mean is constant: $\mu_X(t) = \mu$, $\forall t \in \mathbb{Z}$.
- The autocovariance does not depend on $Cov(X_t, X_{t+h}) = Cov(X_{t+r}, X_{t+r+h})$, $\forall r \in \mathbb{Z}$.

A process is said to be strictly stationary if any finite collection $(X_{n_1}, ..., X_{n_k})$ has the same distribution as $(X_{n_1+t}, ..., X_{n_k+t})$ for any $k \geq 1$ and $(n_1, ..., n_k, t) \in \mathbb{Z}$.
