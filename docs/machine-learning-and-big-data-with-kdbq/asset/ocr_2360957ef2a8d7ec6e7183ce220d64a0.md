It is worth making several comments. First: feature 1colsx explains how the feature for a given stump is chosen, namely we choose a feature randomly. This keeps randomness in the model. The apparent disadvantage is that our implementation of the AdaBoost does not allow to use it as a feature selection technique, though the quality of the technique is preserved. Given, the given feature, the optimal stump is chosen by iterating through all the possible splitting points – which are the unique values of the feature itself – and chooses the one with least loss. Finally, all the variables are updated.
