# 28.1.4 Bayesian Algorithms

Another class of algorithms to solve the multi-armed bandit problems are Bayesian algorithms. As the name suggests, the Bayesian strategies assume some prior knowledge about the bandits' distributions. This can be used to improve exploration strategies and work more accurately with information and regret.

In order to implement the strategy, we further assume that probability functions corresponding to bandits' arms are given as $P = \{P_{\theta\}_{\theta\in\Theta}}$ with being parameter $\theta$. In the simple settings, it can correspond to a $K$-dimensional real vector. The prior distribution imposed on the parameter space is just by $\pi(\theta)$. In order to solve the problem, we define the Bayesian regret:

```
$$\text{Reg}(A, \lambda, \pi) = E_{\pi} \left[ \sum_{t=0}^{n} \lambda(A, \theta) - \lambda(A^*, \theta) \right], \quad (28.12)$
```

where $A^*$ is the minimiser of the loss $\lambda$. We have denoted the expectations with index $\pi$ in order to stress the dependence on the prior distribution.

The textbook example for the bandit problem, which nicely illustrates the meaning of the parameter set and choice of $\lambda$. The Bernoulli bandit procedure is a setup where the probability functions modeling the reward of each arm $i$ are given by Bernoulli distributions with parameter $\theta_i$. The pay-off of arm $i$ is either 1, with probability $\theta_i$, or otherwise. To solve the Bernoulli multi-armed bandit problem means to find the arm with the highest $\hat{\theta}_i$. The loss function for the Bernoulli bandit can be chosen using $\lambda(i, \theta) = -\theta_i$.

The schema for the Bayesian algorithm then follows along the following lines:

+   - Provide a prior distribution $\pi$ for $\Theta$, connected to probabilities $P = \{P_{\theta\}_{\theta\in\Theta}$
- At each step $t$, choose prior distribution $\pi_t$ based on past realisations and corresponding losses.
- Draw $\hat{\theta}_i$, from the prior distribution $\pi_t$
- Choose an action that minimises the loss $\lambda(i, \hat{\theta}_i)$ over a set of admissible strategies.
- Obtain the outcome.

# Thompson sampling

The simple implementation of the Bayesian algorithm is to follow Thompson (1933) and take prior distribution $\pi$, equal to the posterior distribution of $\theta$, conditional on the history of all observed pay-offs:

```
$$\pi_t(\theta) = \pi(\theta|_{\{A_0, X_0, \dots, A_t, X_t\})., \quad (28.13)$
```

The Thompson sampling procedure for the Bayesian algorithm at every time step $t$ reads:

+   - ##(i, t, 1) the number of cases when arm $i$ was chosen and resulted in a pay-off of 1, and analogously, #(i, t, 0) the number of cases when arm $i$ was chosen and resulted in a pay-off 0.
