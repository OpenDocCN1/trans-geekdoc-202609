We can formulate the calculation of the p-value for a given realisation as a sum
of calls to pdfBinomial over extreme events. The function thus has pri-
marly calculate an array of events given N and n. Given two input paramet-
ters - number of positive instances and the size of the sample - function calculates thencorresponding p-value for left-sided, right-sided and two-sided tests, respectively:

```
quantQ.stats.pdfValTest::[n;N];
// n number of positive instances
// N -- size of sample
// calculate sets of extreme cases
leftSample: z where n=z;til N+1;
rightSample: z where n<=z;til N+1;
twoSample: asc distinct [$n<=N/2]((z where (N-n)<=z;til N+1),
(z where (N-n)=z;til N+1), (z where n<=z;til N+1));
// return p-values
(: pValueLeft`pValueRightTwoSided)(sum(quantQ.stats.pdfBinomial[
	[:N;0.5];
	teach leftSample:sum quantQ.stats.pdfBinomial[;0.5] each
	rightSample:sum
	quantQ.stats.pdfBinomial[;0.5] each twoSample));
```
