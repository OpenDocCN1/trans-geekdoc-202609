Recall that, in a right triangle,

$cos(\theta) = \frac{|adjacent\|}{||hypotenuse\|}$

thus

$$(cos(\theta))^2 = \frac{||Y||^2}{||y||^2} = \frac{ESS}{TSS} = \frac{TSS}{TSS} = 1 - \frac{RSS}{TSS} = R^2,$$

which is the quality also known as the coefficient of determination. It indicates how much better the function predicts the dependent variable than the default predictor in the absence of any inputs – the mean value of the output. It is also sometimes described as the proportion of variance explained. This measure reflects how closely the model captures the data generating process.

Regression can be seen as an orthogonal projection of $y$ onto the column space of $X$. An orthogonal projection minimizes the length of the vector that represents the difference between $y$ and the fitted values, $\hat{y}$, it minimizes $\epsilon$. The fitted values are in the column space of $X$. If we add a column to $X$, the column space of $X$ stays the same or more significant. Therefore, the orthogonal projection onto this new space cannot possibly be more extended since the original column space is a subspace of the new space.

The $R^2$ coefficient takes values between 0 and 1, where 0 means that explanatory power of the model is reliable. Interestingly, for the univariate models, the $R^2$ coefficient is equal to the square of the Pearson correlation coefficient. The $R^2$ is also referred to as the goodness-of-fit coefficient. The estimation procedure aims to provide such a model, which the highest possible $R^2$. Using the $R^2$ as an objective of the researcher to maximise its pitfalls. In particular, by adding one more variable into the model, the RSS decreases – or, precisely, non-increasing. By adding more and more variables, the RSS is minimised. Ultimately, by adding $n$ independent variables, we may achieve a holy grail of regression $R=0$, i.e. explaining all the uncertainty in the data.

This is, spurious goodness because adding more and more independent features, the number of degrees of freedom is decreasing. Furthermore, the primary objective of the data analysis is to introduce a model as simple as possible, which explains as much as possible. This is a trade-off between a number of independent variables and the $R^2$ measure, as introduced above, the implementation in q focuses solely on explanatory power.
