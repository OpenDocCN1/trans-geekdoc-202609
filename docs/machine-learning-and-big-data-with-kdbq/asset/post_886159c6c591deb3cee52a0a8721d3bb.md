Analogously to complex numbers, we may define the norm of the quaternion or its modulus. The norm corresponds to the geometric interpretation of the quaternion as a vector in a four-dimensional space:


The norm of the quaternion quat2 is defined as $L_2$-norm:

```
$|q| = |a + bi + cj + dk| = \sqrt{a^2 + b^2 + c^2 + d^2},
```

and implemented in the following function:

```
.quantQ.quat.norm[quat2]
```

The conjugate of the quaternion is similar to what we have defined for complex numbers:

```
$q^* = (a + bi + cj + dk)^* = a - bi - cj - dk$.
```

The conjugate can be expressed through addition and multiplication:

```
$q^* = -\frac{1}{2}(q + iq + jq + kkq).
```

The conjugate can also be used to define the norm introduced previously:

```
$|q| = \sqrt{qq^*}$.
```

The implementation then follows as:

```
.quantQ.quat.conjugate:{@x;'j`'k;neg];
```

and its functionality on the quaternion with all the coefficients equal to 1 reads:

```
.quantQ.quat.conjugate[quat2]
```

Quaternions also have a notion of polar decomposition. The polar decomposition means that we rewrite the quaternion q as pair of two numbers ($|q|$, $\bar{q}$), where $|q|$ is a norm of the quaternion and $\bar{q}$ is a unit quaternion given as:

```
$\bar{q} = \frac{q}{|q|}$
```

The polar decomposition thus does not correspond to a radius and polar angles, yet is still useful when we interpret quaternions as vectors and are interested in linear dependence.

In the geometric interpretation of quaternions, it is convenient to focus on the "imaginary" part of quaternions, i.e. coefficients b, c and d, while considering a = 0. Secondly, we introduce cross product, as it is known from three-dimensional geometry. The cross product of two imaginary quaternions is useful when we want to use them to express rotations in three-dimensional space. The generalised beyond purely imaginary cross product would need insight into wedge products, which can be perceived as cross product in one dimension. This is beyond the scope of this book, though, and we stick to dealing with imaginary quaternions. The cross product is defined as:

```
$q_1 \times q_2 = (b_1i + c_1j + d_1k) \times (b_2i + c_2j + d_2k)$ (42)
```

```

```

The cross product of the imaginary part of a quaternion results in an imaginary part of a quaternion as well. A symbolic definition of cross product using conjugate:

```
$q_1 \times q_2 = \frac{1}{2}(q_1q_2^* - q_2q_1^*)$ (44)
```

# 15.4 ADDENDUM: FRACTALS

We close this chapter with a brief reference to fractals and specifically the Mandelbrot set, due to its close relationship with complex numbers. Fractals have fascinated generations of scientists with their interesting properties and frequent occurrence in nature. They have a wide range of applications, with acoustics, neuroscience, geometry, fMRI and price analysis being a few examples where fractal area is used. Their potential applicability to long-memory processes in time series analysis and Fractal Brownian Motion also make them interesting area for exploration.

A fractal is usually defined as a recursive set which exhibits self-similarity. It is usually nowhere differentiable and will exhibit a dimension which is not necessarily an integer, known as a fractal dimension.
