# 14.4.4.4 Maximum Likelihood Estimation

Let $	heta = (\Phi_1, \dots, \Phi_p, \alpha_1, \dots, \alpha_q, \sigma^2)$ denote the parameters of the ARMA(p, q) process and let $x = (x_1, \dots, x_T)$ be the observed sample of size $T$. The joint probability density function of the data given the parameter $	heta$ is $f(x|X_{T-1}, \dots, x_1|	heta)$. The likelihood function of the parameter $	heta$ given $x$ is $L(	heta|x) = f(x_{T-1}, \dots, x_1|	heta)$. The maximum likelihood estimation is:

```
$\hat{	heta}_{MLE} = \max_{	heta \in \Theta} L(\theta|x) = \max_{	heta \in \Theta} log L(\theta|x)$
```

Assuming that the error of the ARMA(p, q) process is Gaussian, $\epsilon_t \sim WN(0,\sigma^2)$, the likelihood is:

```
$L(\theta|x) = (2\pi)^{-T/2}|\Gamma(\theta)|^{-1/2} \exp(-\frac{1}{2}x'T\Gamma(\theta)^{-1}x)$
```

where the $T \times T$ variance-covariance matrix of x is $\Gamma(\theta) = E[xx']$. The log-likelihood to optimise is:

```
$l(\theta|x) = log L(\theta|x) = -\frac{1}{2}(Tlog(2\pi) + log |\Gamma(\theta)| + x'\Gamma(\theta)^{-1}x)$
```
