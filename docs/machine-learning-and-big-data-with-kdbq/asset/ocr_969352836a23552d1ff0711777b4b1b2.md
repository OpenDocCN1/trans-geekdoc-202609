The infinity is generally represented by Ø?, where ? is the character from Table 1.1. The concept is in line with what we saw for null types, except for the guid type, which does not have infinity. A float infinity is denoted using lower case, where Øwf is the same as Øw, while Øw is the same as ØNj. Since temporal variables are internally stored as some numeric value, nulls/missing values and infinities are well defined for them, too.
