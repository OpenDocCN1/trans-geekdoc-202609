In order to define the local outlier factor, we have to fix the definition of the distance between two points in the feature space. We employ the one based on the $L_p$-norm, and in particular we set $p = 2$, i.e.

> $$d(X, Y) = \left(\sum_{i=1}^{N} |X_i - Y_i|^2\right)^{1/2} \quad (17.2)$$

for any two points $X$ and $Y$.

For our purpose, we implement the $L_2$-norm as a function of two arguments, where the first is a reference point and the other is a vector of points. The function calculates the distance between the reference point and each point of an array:

```
quantQ.of.L2distance:[point;dataVector]
// point -- reference point
// dataVector -- vector of data
:sqrt t wsum t:flip[dataVector]-point;
```

We can verify the implementation against the test point by updating the table dataSet by extra column distanceToPoint, which contains the distance between the test point and the feature array `x0,x1:`:

```
testPoint:(0.5;0.5);
// calculate distance to each point
dataSet: update distanceToPoint:quantQ.of.L2distance[testPoint;(x0,'x1)]
from dataSet;
```

The DistanceToPoint result contains the distance to the reference point. We can find and identify the neighbours, or inspect the histogram of the distances.

The local outlier factor is based on the k-nearest neighbours. We choose k conventionally:

```
k:12;
```

where the neighbourhood will be defined as 12 nearest points in the sense of $L_2$-norm. The value is arbitrary, and we encourage the reader to vary the parameter in the exercise.

Being equipped with the distance, we define the k-distance of the point X to be the distance of X from k-th neighbour. It may happen that the k-distance of the point X, is more than k elements; let us denote the number of such points as $n_k(X)$. This happens when data points lie on circle of radius k-distance with X being in origin.

We implement the k-distance of the point X and the number of points within the k-distance within one function:

```
quantQ.lof.getKNNProperties:{k;data;point}
// -- the parameter of the knn
// data -- the set with one column x, each observation is a list of
  features
// point reference point
// calculate distance to point and sort it
data:distanceToPoint xasc updateDistanceToPoint::quantQ.lof.
L2distance[point,x] from data;
// to k-th
distanceTOK data['distanceToPoint'][min[(k-1);count[distance]]];
// number of elements within the distance
numberTok:count select from data where distanceToPoint<=distanceTOK
// return values
(:distanceTok;numberTok)!(distanceTok;numberTok);
;
```

The function has three arguments: first, the size of the neighbourhood, data-set data, and the reference point denoted as point. The reference point does not have to be part of the data set and is considered as a separate point. We illustrate the use of the size of the function getKNNProperties as follows:

```
.quantQ.of.getKNNProperties[k; select x:(x0,'x1) from dataSet;testPoint]
```

numberTok | 12

Further, we define the reachability of the point X from the point Y as:

```
reachability_k(X,Y) = max(d(X,Y), k-distance(Y)), (17.3)
```

where the mean is that reachability between the two points is a maximum of their true distance and the k-distance of the point. The meaning of this definition is that k-distance is the minimum distance around point Y, or scale of neighbourhood of point Y. Any point within k-distance is considered to be the same.

We implement reachability distance as a function of three arguments: the point X, the index of Y within the data set, and size:

```
.quantQ.of.reachabilityDistance:[X;indexY;data;k]
// X -- point to distance, can be out of data
// indexY -- index of the point, it has to come from data
// data -- the data set with column x, each observation is a row of
// features
// k -- the parameter of the kNN
// extract point x from data
// component 1: distance between X and Y
distanceXY: first-th distance quantQ.of.L2distance[x;Y]
// component 2: k-th distance of Y within dataset
kDistanceY:quantQ.of.getKNNProperties[k;data;Y][distanceTok];
// return reachability distance
:max[(distanceXY,kDistanceY)];
;
```

In the table, we assume that features are common column x, each observation being an array of features for a given observation. We illustrate the function using test point and the first row of the data:

```
quantQ.of.reachabilityDistance[testPoint;select x:(x0,'x1) from dataSet;k]
```

0.534306

We use reachability distance to define local reachability density of the observation X as:

```
ρ(X) = \frac{1}{\sum_{Y \in n_k(X)} reachability_k(X,Y)} (17.4)
```

the density $\rho$ is the average of the average reachability distance of the observation X from its neighbours. The definition can show similarity for identical points. The density $\rho$ is implemented as:

```
.quantQ.lof.localReachabilityDensity:[X;data;k]
// X point to find distance, can be out of data
// data the data set with one column x, each observation is a row of
features
// k the parameter of the kNN
// update distance to point
data: update distanceToPoint:.quantQ.lof.L2distance[X;x] from data;
// find-neighbour of X
neighbourhood:.quantQ.lof.getKNNProperties[k;data;X];
// indices of k-neighbors contains neighbourhood[numberTok]
elements
index i from data where distanceToPoint<=neighbourhood[
numberTok);
// return density
sum.quantQ.lof.reachabilityDistance[X;data] each indices
;```

Finally, we define the outlier factor, or LOF, as the average local reachability distance of the neighbourhood of point X normalized by the local reachability distance of the point X itself:

> $$LOF_k(X) = \frac{\sum_{Y \in N_k(X)} \frac{\rho(Y)}{\rho(X)}}{\rho(X)} (17.5)$$

The value of $LOF_k$ around 1 implies that the observation is comparable to its neighbours. This means the point is not an outlier. On the other hand, values above 1 indicate an outlier with a lower density relative to its neighbourhood. Further, we can interpret smaller one as "inliers" – points which have higher density compared to their neighbourhood.

We implement the $LOF_k$ function as follows:

```
.quantQ.lof.LOF:{X;data;k}
// X point to find distance, can be out of data
// data the data set with one column x, each observation is a row of
features
// k the parameter of the kNN
// update distance to point
data: update distanceToPoint:.quantQ.lof.L2distance[X;x] from data;
// find-neighbour of X
neighbourhood:.quantQ.lof.getKNNProperties[k;data;X];
```

```
// indices of k-neighbours - contains neighbourhood`numberTok` elements
indicesY:exec i from data where distanceToPoint<=neighbour[
  distanceToK];
return LOF
:sum(quantQ.lof.localReachabilityDensity[:data;k] each exec x from
  data);indicesY]
Xneighbour[numberTok]*quantQ.lof.localReachabilityDensity[X;
  data;k];
```

The point lies in the middle of the square, in the corner of two clusters. This point is thus hard to be identified as an outlier, in particular when k = 12 neighbours considered. Let us increase the size of the neighbourhood to k = 10:

The values increase as intuition suggests that the neighbourhood “sees” the vast region around itself and refers to a broader set. Let us calculate the local outlier factor for list of points:

```
listPoints:((0.15;0.15);(0.85;0.85);(0.15;0.85);(0.85;0.15));
```

The first two points lie in one of the clusters1 and cluster2, the remaining two points lie outside the cluster and are produced by the noise background. The list of the corresponding LOFs reads:

```

The results clearly support our intuition, where the LOF of the first two points is higher than the LOF of those from the noise background. The result is more prominent with outlier:
