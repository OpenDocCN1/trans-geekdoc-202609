# 16.4.6 PCA Regression (PCR)

The natural extension of the dimensionality reduction using the PCA is the PCA regression, or PCR. In linear regression, we work with the model

$$y = X\beta + \epsilon, $$

where $y \in \mathbb{R}^n$ is the output vector, $\tilde{X} \in \mathbb{R}^{nx^*}$ is the data matrix $X$ possibly augmented with a vector of ones on the left to allow intercept (in case $p^* = p+1$) or not (in case $p^* = p$); $\beta \in \mathbb{R}^p$ is the vector of parameters of the model, and it is our task to estimate this estimator; and $\epsilon \in \mathbb{R}^n$ is the random variable representing some noise or disturbance.

$$y = \tilde{Z}_{\Delta}\gamma_{\Delta} + \eta, $$

where $\tilde{Z}_{\Delta} \in \mathbb{R}^{nd}$ is the matrix of principal component scores $Z$, possibly augmented with a vector of ones on the left to allow intercept (in case $d^{\Delta} = d+1$); $\gamma_{\Delta} \in \mathbb{R}^{d^*}$ is the vector of parameters of the model, and it is our task to estimate this estimator; and $\eta \in \mathbb{R}^n$ is the random variable representing some noise or disturbance.

The properties of the estimator $\hat{\gamma}_{\Delta}$ can be derived as follows: from linear regression theory, we know that the ordinary least squares (OLS) estimator of $\gamma_{\Delta}$ is

$$\hat{\gamma}_{\Delta} = (\tilde{Z}_{\Delta}^T\tilde{Z}_{\Delta})^{-1}\tilde{Z}_{\Delta}^Ty, $$

We know that this estimator is unbiased,

$$E[\hat{\gamma}_{\Delta} |\tilde{Z}_{\Delta}] = E[\hat{\gamma}_{\Delta} | X] = \gamma_{\Delta}, $$

and that its variance is given

$$Var[\hat{\gamma}_{\Delta}] = \sigma_{\Delta}^{*2}(\tilde{Z}_{\Delta}^T\tilde{Z}_{\Delta})^{-1}. $$
