# 22.3.2 M-class Classification

The second example involves testing the M-classification, where the dependent variable can take M distinct values. We test our implementation on Fisher's Iris data set iri. Let recall the meaning of the variables in the data set:

+   * Feature 1: sepal length in cm,
* Feature 2: sepal width in cm,
* Feature 3: petal length in cm,
* Feature 4: petal width in cm,
* Dependent variable: class: Iris Setosa, Iris Versicolour, and Iris Virginica, respectively.
