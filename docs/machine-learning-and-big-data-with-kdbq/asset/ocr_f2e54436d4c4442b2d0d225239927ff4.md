# and the diagonal matrix

```
.quantQ.ts.diag:[m]
// m -- array of numbers to put on diagonal
:{i,m] m(i,j);[m] each til count m;
;
```

The 1-step and n-step forecasts estimate the coefficients B of the VAR(p) model based on the data set and predict its future values. First, the implementation of the 1-step forecast reads:

```
.quantQ.ts.estimate1:{y;p}
// y -- historical data (list of floating numbers)
// p -- order of the VAR(p) process
b..quantQ.ts.varpest[y;p];
v:[b];
k: count b
+sum(i;y;k]b[(1+k)+til k] mmu y[(count y0)]-(1+i)][y;b;k]
// each til p;
;
```

Further, we implement the n-step forecast of the VAR(p) model:

```
.quantQ.ts.estimateN:{y;p}
// n -- positive integer indicating a n-step ahead forecast
// y -- historical data (list of floating numbers)
// p -- order of the VAR(p) process
output:quantQ.ts.estimat[y;p];
:$[n];
  .quantQ.ts.estimateN[n-1;y',output];
output;
;
```

The accuracy of the 1-step forecast is determined with the MSE function:

```
.quantQ.ts.forecastMSE:{y;p}
// y -- historical data (list of floating numbers)
// p -- order of the VAR(p) process
T:(count y[0])-p;
k: count y;
coef:(T(K+p)+1)&&
.coef*.quantQ.ts.covarianceResidual[y;p];
;
```

The 95% confidence interval of the 1-step forecast is:

```
.quantQ.ts.confinterval:{y;p}
// y -- historical data (list of floating numbers)
// p -- order of the VAR(p) process
se:1.96*sqrt[quantQ.ts.diag[.quantQ.ts.forecastMSE[y;p]]];
```
