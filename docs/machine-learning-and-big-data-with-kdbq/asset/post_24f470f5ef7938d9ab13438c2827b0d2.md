# NEAREST NEIGHBOURS APPROACH

The concept of nearest neighbours as introduced above is a brute force approach which aims to exploit similarity between observations for prediction. In this section, we employ the nearest neighbours for feature selection or even in real time as was introduced by Nav et al. (2006). The aim of the proposed method is not prediction but dimensionality reduction in the space of independent variables.

The method comes from the field of statistics; it was invented for analyzing activity, namely, to search through the high-dimensional space of features. The proposed algorithm extends the leave-one-out algorithm with mean-squared error, where the optimal feature set is found. The proposed algorithm assigns weights to features. This makes the problem differentiable, so the gradient can be calculated analytically and gradient descent algorithms can be used to find the optimal weights. The features can be sorted by the assigned weights. The method can also be viewed as an extension of the kNN regression, which assigns the value of a dependent variable for a point x, being n-dimensional vector of independent variables, based on the average value of the neighbourhood N:

```
\hat{y} = \frac{1}{\text{card N}} \sum_{x\in N} y(x'),
```

the neighbourhood of y(x) is defined in the same way as the previous sections. Analogously to the distance-weighted function we define the weighted regression based on proximity, $L_2$ distance, as:

```
\hat{y} = \frac{1}{\sum_{x\in N} e^{-\frac{1}{2}\|x-x'\|^2}} \sum_{x\in N} y(x')e^{-\frac{1}{2}\|x-x'\|^2}
```

The factor in front of this normalises the estimate based on the weights derived from $\|x-x'\|$. The weights do not have to be normalised.

The purpose of the algorithm is to assess the importance of individual independent variables. We thus introduce the weighted:

```
\|x-x'\|_W^2 = \sum(x_i - x'_i)^2 w_i^2,
```

where $w_i$ is an $n$-dimensional vector of weights, which puts emphasis on different independent variables. We do not need to impose any normalization on weights.

Having in hand the weighted norm, we define the weighted regression equation:

$$\hat{y}_w = \frac{1}{\sum_{x' \in N} e^{-\frac{1}{2}\|x-x'\|_w^2}} \sum_{x' \in N} y(x')e^{-\frac{1}{2}\|x-x'\|_w^2}}$$

Finally, we define a score function which assesses the performance of each vector of weights, $w$. The score is defined as the mean-squared error:

$$e(w) = -\frac{1}{2} \sum_{x} (y(x) - \hat{y}_w(x))^2$$

where we have used a factor of 1/2 for convergence. The method itself incorporates leave-one-out cross-validation approach as the estimated value of $y$ for a given $x$ does not use $x$.

Further, it is important to stress that the function is continuous in $w$. This is an essential feature as it allows us to obtain an analytic expression for the first derivative of the score concerning weights. Gradient-descent type of methods can be employed to find out which weights optimize this score. The algorithm for feature selection can be specified as follows:

- Initialize $w=(1, 1, \dots, 1)$, set $K=1$.
- Perform an update of weights:
  - Pick datum $x$ from the training set.
  - Calculate the gradient of the loss function ($L_2$ norm) as a function of weights:
  $$\nabla e(w) = -\sum_{x} (y(x) - \hat{y}_w(x)) \nabla_w \hat{y}_w(x)$$
  $$\nabla_w \hat{y}_w(x) = -\frac{1}{2\beta} \sum_{x'} f(x')a(x,x')u(x',x') / \sum_{x'} a(x,x')$$
  with
  $$a(x,x') = \exp(-(\|x-x'\|^2 + \|x-x'\|_w^2)/\beta)$$
  and vector $u$ com components
  $$u_i = w_i|(x-x')|^2 + (x-x'')^2$$
- Update $w = w + \eta_K \nabla_w \hat{y}_w(x)=w(1 + \eta_K \nabla_w \hat{y}_w(x))$.
- Update the counter $K=K+1$ and repeat the update of weights until convergence is achieved.
