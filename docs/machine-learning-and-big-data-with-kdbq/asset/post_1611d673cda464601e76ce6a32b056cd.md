## 13.5 SIGNIFICANCE OF PARAMETERS

In the previous section we calculated the OLS estimates of the parameters of a linear model. In this section, we assess the significance of the estimated parameters. First, we calculate the t-statistic:

```
tStat:beta%errors%count y;
```

The t-statistic is distributed according to the t-distribution with degrees of freedom equal to a number of observations, N. We can evaluate the null hypothesis a given coefficient comes from the distribution with zero mean. In order to evaluate the hypothesis, we may be able to calculate the t-distribution with general degrees of freedom. We overcome this task by sticking to approximation N → ∞, where the t-distribution converges to a normal distribution.

Further, we may need the probability that we may reject the null at general confidence level, but rather to check whether we can reject the null at several benchmark values. In particular, we check to 90%, 95%, 99%, and 99.9%. We will use the “*” notation, where * stands for a situation where we can reject the null at 90% confidence level, but not at a higher confidence level. Analogously, the case corresponds to 95% confidence level, *** corresponds to 99%, and **** corresponds to 99.9%, respectively, having with every estimated parameter its corresponding number of “*” gives the easiest-read statistical assessment of the estimated model.

We create a function that assigns the corresponding number of “*” for every given t-statistic under the asymptotic approximation:

## 13.6 HOW GOOD THE FIT

The question we have to answer is how good the overall fit is. The significance of individual parameters does not imply the model has features, all significant. Each of them have different from zero. In general, how do we know about the model? We can assert that we have acquired some knowledge about.

### Linear Regression

In order to answer the question about overall quality of the fit, we perform what we know as variance partitioning. Let $\bar{y} = \frac{1}{n}\sum_{i=1}^n y_i$ be the sample mean, and let us define:

- Total Sum of Squares (TSS), also referred to as Sum of Squares Total (SST): $\sum_{i=1}^n (y_i - \bar{y})^2$
- Estimated Sum of Squares (ESS), also referred as Sum of Squares Model (SSM): $\sum_{i=1}^n (\hat{y}_i - \bar{y})^2$
- Residual Sum of Squares (RSS), also referred as Sum of Squares Error (SSE): $\sum_{i=1}^n (y_i - \hat{y}_i)^2$.

Notice that the abbreviations used in the literature can be quite confusing: "E" stand for "estimated" or "error"; does "R" stand for "regression" or "residual"? To avoid confusion, we will stick with Total Sum of Squares (TSS), Estimated Sum of Squares (ESS), and Residual Sum of Squares (RSS).

If we define $\hat{y} \in \mathbb{R}^n$ as a vector of all elements are the sample mean $\bar{y}$, we can write this in vector notation:

```
TSS = \sum_{i=1}^n (y_i - \bar{y})^2 = (y - \bar{y})^T(y - \bar{y}),
ESS = \sum_{i=1}^n (\hat{y}_i - \bar{y})^2 = (\hat{y} - \bar{y})^T(\hat{y} - \bar{y}),
RSS = \sum_{i=1}^n (y_i - \hat{y}_i)^2 = (y - \hat{y})^T(y - \hat{y}).
```

Further, we notice that:

```
TSS = ||y - \bar{y}||^2 = ||y||^2 - 2y^T\bar{y} + ||\bar{y}||^2,
ESS = ||\hat{y} - \bar{y}||^2 = ||\hat{y}||^2 - 2\hat{y}^T\bar{y} + ||\bar{y}||^2,
RSS = ||y - \hat{y}||^2 = ||e||^2.
```

If the model includes the intercept, the first column of $X$ is a column of ones, and $X^T e = 0$, the sum of the residuals is zero. This is equivalent to $y^T\bar{y} = \hat{y}^T\bar{y}$. By Pythagoras's theorem,

```
||y||^2 = ||\hat{y}||^2 + ||e||^2.
```

hence

```
TSS = ESS + RSS,
```

which is a fundamental result known as variance partitioning. Irrespective of whether our model includes the intercept, if we center y by subtracting the sample mean $\tilde{y} = \frac{1}{n}\sum_{i=1}^n y_i$ from each element, we notice that TSS = ESS + RSS simply amounts to the above application of Pythagoras's theorem.

Recall that, in a right triangle,

$cos(\theta) = \frac{|adjacent\|}{||hypotenuse\|}$

thus

$$(cos(\theta))^2 = \frac{||Y||^2}{||y||^2} = \frac{ESS}{TSS} = \frac{TSS}{TSS} = 1 - \frac{RSS}{TSS} = R^2,$$

which is the quality also known as the coefficient of determination. It indicates how much better the function predicts the dependent variable than the default predictor in the absence of any inputs – the mean value of the output. It is also sometimes described as the proportion of variance explained. Regression can be seen as an orthogonal projection of $y$ onto the column space of $X$. An projection minimizes the length of the vector that represents the difference between $y$ and the fitted values, $\hat{y}$, it minimizes $\epsilon$.

The $R^2$ coefficient takes values between 0 and 1, where 0 means that explanatory power of the model is reliable. Interestingly, for the univariate models, the $R^2$ coefficient is equal to the square of the Pearson correlation coefficient. The $R^2$ is also referred to as the goodness-of-fit coefficient. The estimation procedure aims to provide such a model, which the highest possible $R^2$. Using the $R^2$ as an objective of the researcher to maximise its pitfalls. In particular, by adding one more variable into the model, the RSS decreases – or, precisely, non-increasing. By adding more and more variables, the RSS is minimised. Ultimately, by adding $n$ independent variables, we may achieve a holy grail of regression $R=0$, i.e. explaining all the uncertainty in the data.

This is, spurious goodness because adding more and more features, the number of degrees of freedom is decreasing. Furthermore, the primary objective of the data analysis is to introduce a model as simple as possible, which explains as much as possible. This is a trade-off between a number of independent variables and the $R^2$ measure, as introduced above, the implementation in q focuses solely on explanatory power.
