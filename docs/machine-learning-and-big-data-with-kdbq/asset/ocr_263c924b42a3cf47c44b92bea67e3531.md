# 14.3.2 VARX($p, q$) Process

The VAR model assumes that all stochastic variables of a system ($A_i$ in our case) have essentially the same status that they are all determined within the system. In practice, a VAR model only past determine its future values, the generation process may be affected by other observable variables which are determined outside the system of interest. Such variables are called exogenous or unmodel variables. In contrast, the variables determined within the system are called endogenous. A vector autoregressive process with exogenous variables VARX($p, q$) has the following form:

```
$Y_t = A_1Y_{t-1} + \dots + A_pY_{t-p} + B_0x_t + \dots + B_qx_{t-q} + u_t, \quad (14.28)$
```

where $A_i, i=1..p$ and $B_j=0..q, Y_t = (y_{1t}, \dots, y_{Kt})$ is a $K$-dimensional vector of endogenous variables, $x_t = (x_{1t}, \dots, x_{Mt})$ is an $M$-dimensional vector of exogenous variables and $u_t$ is white noise.

These types of models are also called transfer functions or distributed lag. In lag operator notation, the reduced form can be written as:

```
$A(L)y_t = B(L)x_t + u_t,$
```

where $A(L) := I_K - A_1L - \dots - A_pL^p$ and $B(L) := B_0 + B_1L + \dots + B_qL^q$. The final form of the system is given by:

```
$y_t = D(L)x_t + A(L)^{-1}u_t,$
```

where $D(L) := A(L)^{-1}B(L)$. The coefficient matrices $D_i$ of transfer operator contain the effects that in the exogenous variables have on the endogenous variables.

# 14.3.21 Estimator

The reduced form of a VARX($p, q$) model can be rewritten as:

```
$y_t = AY_{t-1} + Bx_{t-1} + B_0x_t, \quad (14.29)$
```

where $A = [A_1, \dots, A_p], B = [B_1, \dots, B_q]$.

![](bbox=[0.125, 0.733, 0.565, 0.79])

For a sample of size T, the system can be written compactly as $Y = [A, B, B_0]Z + U$ where $Y := [y_1, \dots, y_T], Z := \begin{bmatrix} Y_0, \dots, Y_{T-1} \ X_1, \dots, X_T \end{bmatrix}$ and $U := [u_1, \dots, u_T]$. Let $\beta := \text{vec}(A, B, B_0) = RY$. The reduced form can be vectorised as $y = (Z' \otimes I_K)\beta + u$ with $(Z' \otimes I_K)RY + u$ with $y = \text{vec}(Y)$ and $u = \text{vec}(U)$.
