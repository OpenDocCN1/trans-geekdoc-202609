The random number generator uses a seed which can be set using the -S start-up flag or seen by typing:

```
\S
```

The seed does not change during the call of the random number generator. If we want to set another seed, we specify an argument to \S which is a non-zero integer. In such a case, the first argument is the list to search through and the second argument is an element to find:

```
arr:1 2 3 4 5 6;
arr?
```

2

The function will exit upon finding the first occurrence of the element:

```
arr2:1 2 3 3 3 3;
arr2?
```
