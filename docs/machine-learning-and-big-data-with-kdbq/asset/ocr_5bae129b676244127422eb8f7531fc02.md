which, for every time index and symbol, i.e. every row from at3, finds corresponding last value in at4.

Let keep in mind that the ordering should be such that the left-most specified column should be grouping the observations into categories while the right-most column is the actual time index, the case which is present in most of the high-frequency analysis. Thus the case aj[`sym`t;at3; at4] is preferred to aj[`t`sym;at3; at4].
