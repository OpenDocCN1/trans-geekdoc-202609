# 11.2 Time Window VWAP

For a moving time-window VWAP, To do this, we use the join function, and specifically, its wj1 variation — to aggregate over a sliding window of, say, 1 hour. This is a similar use of the TWAP example we see in Chapter 7. We use wj1 instead because we want the values in the 1-hour window prior to each record, but without including the as-of-value, 1-hour prior to record's time:

```
vwap: wj1 [ -01:00 0+; exec time from trades;
  'code'; select code, time, price, volume from trades;
  ( select code, time, val: price * volume ,vol: volume from trades 
  \->)
  ( sum ( `val` ); sum ( `vol` ) ];
```

```
update vwapih: val % vol from vwap
```
