# 14.1.2.2 Estimation of AR(p) Parameters

The parameters $\Phi_1, \Phi_2, \dots, \Phi_p$ and $\sigma^2$ of the autoregressive process of order $p$ presented in (14.1) can be estimated using:

+   * The least squares method
* The maximum likelihood method
* The Yule-Walker equations

# 14.1.2.3 Least Squares Method

Since the innovations $\epsilon_t$ are uncorrelated with $X_{t-j}, j=1, \dots, p$, the ordinary least square OLS can be applied to estimate $\Phi_i$. The AR(p) process $X_t = c + \sum_{i=1}^p \Phi_i X_{t-i} + \epsilon_t$ is equivalent to $X_t = X_t - c - \sum_{i=1}^k \Phi_i X_{t-i}$. The OLS estimator minimises $\sum_{t=k+1}^n \epsilon_t^2 = (X_t - c - \sum_{i=1}^k \Phi_i X_{t-i})^2$. The AR(p) process can be represented in matrix as:

```
$X = Y\Phi + \epsilon,\quad (14.5)$
```

where $Y$ is $n-p 	imes p+1$ matrix defined as:

```
$\mathbf{Y} = \begin{pmatrix} Y_{i,1} = 1 & \forall i \in [1, n-p], \ Y_{i,j} = x_{i-j} & \forall j \in [2, p+1]. \end{pmatrix}$
```

and $X = (x_p, x_{p+1}, \dots, x_n)'$.
