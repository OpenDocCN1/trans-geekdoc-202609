Let us confirm the properties of the principal components. In particular, the correlation of the first component with itself is obviously one:

```
cor[sum[pcaTab[`eigenvectors`][0]*dataNorm];sum[pcaTab[`eigenvectors`][0]*dataNorm]]
```

1f

where the correlation between the first and second component is close to zero:

```
cor[sum[pcaTab[`eigenvectors`][0]*dataNorm];sum[pcaTab[`eigenvectors`][1]*dataNorm]]
```

-0.0404597

despite the fact that data itself is correlated:

```
cor[dataNorm[0];dataNorm[1]]
```

-0.4577103

We can finally construct the routine which provides the PCA decomposition and on top of that relative variance each component captures. The following function takes as argument matrix with data and returns the PCA decomposition:

```
.quantQ.mat.pca::[data]
// data - array of input data
// calculate eigensystem
pTab:flip .quantQ.mat.eigenSystem[.quantQ.mat.covarianceMatrixFast[data ->]];
```
