# 14.1.4.6 Forecast

The innovations algorithm (14.14) used to estimate and forecast the MA(q) process can be adapted to forecast the ARMA(p, q) model. The one-step predictor is given by:

```
$$\hat{X}_{n+1} = \begin{cases} \sum_{j=1}^{n} \alpha_{nj}(X_{n+1-j}) - \sum_{j=1}^{n-p} \alpha_{nj}(X_{n+1-p}) & 1 \leq n < m \ \Phi_1 X_n + \dots + \Phi_p X_{n-p} + \sum_{j=1}^{n} \alpha_{nj}(X_{n+1-j} - \hat{X}_{n+1-j}) & n \geq m \end{cases}$
```

$\alpha_{nj}$ is given in the innovations algorithm (14.14):

```
$$\hat{y}(i) = \begin{cases} \sigma^2\gamma(i-j) - \sum_{j=1}^{\min\{i,j\}} \Phi_r\gamma(r-|i-j|) & \min\{i,j\} \leq m < \max\{i,j\} \leq 2m \ \sum_{r=0}^{i} \alpha_r\hat{r}_{i-r}-0 & \min\{i,j\} > m \ \text{otherwise} \end{cases}$
```

# 14.1.5 ARIMA(p, d, q) Process

The autoregressive integrated moving average process is a generalisation of the ARMA(p,q) process. It is defined with three parameters: as for the ARMA process, $p$ is the order of the autoregressive component and $q$ is the order of the integration of the series. Let us define the $d$-lag difference operator $V_d$ by $V_d X_t = X_t - X_{t-d} = (1 - L^d)X_t$. The process $[X_t, t \in \mathbb{Z}]$ is said to be an ARMA(p,d,q) process if $V_d X_t$ is a causal ARMA(p,q) process. A causal ARIMA(p,d,q) process satisfies

```
$$\Phi(L)Y_t = \Phi^*(1-L^d)X_t = \alpha(L)\varepsilon_t$$
```

with $[\varepsilon_t \sim N(0, \sigma^2)$ where $\Phi^* \neq 0 \| \leq 1$. The process $V_d X_t = (I - L^d)X_t$ satisfies

```
$$\Phi^*(L)Y_t = \alpha(L)\varepsilon_t. \quad (14.18)$
```
