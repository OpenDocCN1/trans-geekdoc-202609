The first nine entries in the game tree corresponds to when child nodes have been expanded from a tree. With tenth entry, the expansion is occurring on the second level of the tree. The gameTree contains history of each node already explored and the one newly expanded node. The values are sorted as the nodes have been reached. This allows us to collect all nodes which went through a certain sub-path starting at the root node. Until we explore the entire state space of all games, every row in this column will be unique.
