The data have been extracted as:

```
select Counter, Error from modelB where i>0
```

Further, we extract model parameters at the training process:

```
pHid2Out: exec last parsHid2Out from modelB;
pIn2HidB: exec last parsIn2Hid from modelB;
```

We arrange the out-sample data into a new table tabB, and add an encoded dependent variable:

```
tabB:update classEnc: ..quantQ.nn.encoderMulti[distinctClass] class from
irisDataOUT;
```

Then, we predict the class of the iris using the trained model. The prediction is done by stacking the network:

```
tabB: update classEncPredict: ..quantQ.nn.funcNN['multiClassifier'][(1.0.,;
	quantQ.nn.sigmoid(1.0, 'Flip'(irisDataOUToutLength,irisDataOUT')
	sepalWidth,irisDataOUTpetalLength,irisDataOUTpetalWidth)]
mmu pHid2OutB from tabB;
```

The predicted classEncPredict is an encoded array of three values, where each value represents probability that given our observation is a class of the given class with highest probability wins. We can then check the accuracy of our prediction model as:

```
exec sum {(where y=max y)(where x=max x)}[classEncPredict;classEnc] from
	tabB
```
