The autoregressive process AR(p) is estimated with the Durbin-Levinson algorithm by default the procedure is quicker than solving the Yule-Walker algorithm or inverting the matrix (14.6) to compute the OLS estimator. The Durbin-Levinson algorithm is implemented as follows:

```
quantQ.ts.DurbinLevinson:[data;p]
// historical data (list of floating numbers) used to estimate
the AR(p) process
// p -- order of the AR(p) model.
p:p+1;
phi:(p:p)=0f;
v:w=0f;
phi[1:1]:.quantQ.ts.gamma[1;data]*.quantQ.ts.gamma[0];data;
v[0]:.quantQ.ts.gamma[0];data;
s:0f;
while[n<p]
  j:1;
  while[j<n]
    s:s+phi[n-1;j]*quantQ.ts.gamma[n-j];data;
    j:j+1;
phi[n:n]:(.quantQ.ts.gamma[n;data]-s)%v[n-1];
s:0f;
v[n]:v(n-1)*(1-phi[n] xexp 2));
  j:1;
  while[j<n]
    phi[n;j]:phi[n-1;j]-phi[n];phi[n-1;n-j];
    j:j+1;
n:n+1;
:1_phi[p-1];
```

Given the function .quantQ.ts.toeplitz to build the Toeplitz matrix (14.12) of sample autocovrelation .quantQ.ts.r, first, we define the sample autocovariance function of order h:

```
.quantQ.ts.gamma[[h;data]
// order of autocovrelation
// data -- data
// :neg[h]_data cov (h _data);
;
```

then the sample autocorrelation function of order h:

```
.quantQ.ts.r[[data;h]
// order of autocovrelation
// data -- data
// :quantQ.ts.data]%.quantQ.ts.gamma[0;data];
;
```

and, finally, the Toeplitz matrix:

```
.quantQ.ts.toeplitz::[data;p]
// data -- historical data (list of floating numbers)
// p -- order of the AR(p) process
tabs (p;p)="[x;data](til p);\quantQ.ts.r[data;x]][data] raze t;
;
```

The Yule-Walker equations can be solved as:

```
.quantQ.ts.yuleWalker::[data;p]
// data -- historical data (list of floating numbers)
// p -- order of the AR(p) model
inv[.quantQ.ts.toeplitz[data;p]] mmu {.quantQ.r[data;data]] each 1+til p
~;
;
```

Finally, the OLS estimator (14.6) can be implemented as:

```
.quantQ.ts.estAR::[data;p]
// data -- historical data (list of floating numbers) used to estimate
// p -- order of the AR(p) model
n:count_data;
dim:(n-p,p+1);
x:dim=0f;
i:0;j:1;
while i<(n-p);
x[i:0]:1f;
while j<p+1;
0<=i-j;
x[i;j]:data[i-j];nx[i;j]:0f;
j:j+1;
i:i+1;
y:neg[p]-inv([flip x] mmu (flip y);
;
```

An implementation of the innovations algorithm (14) to estimate the coefficients of MA(q) process is provided as:

```
.quantQ.ts.innovations:[data;q]
// data -- historical data (list of floating numbers) used to estimate
the MA(q) process
// q -- order of the MA(q) process
p:1:q until convergence
v:(p+1)*0f;
alpha:(p+1;p+1)*0f;
v[0]:.quantQ.ts.gamma[0;data];
n:1;
k:0;
while[n<=p>
  k:0;
  while[k<n]
    j:0; s:0f;
    while[j<k]
      s:s+(alpha[k-j]+alpha[n-j]+v[j]);
      j:j+1;
    ];
    alpha[n-k]:(quantQ.ts.gamma[n;data] - s)*v[k];
    k:k+1;
    s:0f; j:0;
    while[j<n]
      s:s+(alpha[n-j] xexp 2)*v[j];
      j:j+1;
    ];
    v[n]:.quantQ.ts.gamma[0;data]-s;
  n:n+1;
alpha[p-1;p+1];
```

The innovations algorithm converges more slowly than the number of lags of the moving average process. Thus, we multiply the number of lags q to improve the estimator and select the q first element of alpha matrix. The parameters of ARMA(p,q) are estimated by solving the Hannan-Rissanen algorithm with a two-step regression:

```
.quantQ.ts.HannanRissanen:[data;p;q]
// data -- historical data (list of floating numbers) used to estimate
the ARMA(p,q) process
// p -- order of the AR(p) process
// q -- order of the MA(q) process
```

```
// Step 1 - Estimate AR(max(p+q))
lags:1+(p+q)
arest:quantQ.ts.DurbinLevinson[data; lags]
res:.quantQ.ts.residuals[arest;data];
es:(lags+0),res;
// Step 2 - regress data[t] on (data[t-1],...,data[p],res[t-1],...,res
// for t = lag,q, by OLS
t:(lags+q) -- till count data
x:(reverse each quantQ.ts.matrix[t;p;data]),(reverse each .quantQ.ts.matrix[t;q]); mmu flip x mmu data[t]);
```

where the recursive function .quantQ.ts.matrix stacks the series d into matrix and computes [d-q];d[t-q];...d[t-1]:

```
.quantQ.ts.matrix:{t;q}
// t index
// q order of the MA(q) process
// d series
$[q=1]; d[t-q].quantQ.ts.matrix[t-q;d];d[t-1];
```

The implementation of the estimator for the ARMA(p,q) process is left as an exercise for our readers. It can be estimated by using the Yule-Walker election of ARMA(p,q) process or by adapting the Hannan-Rissanen algorithm.

## 14.6.3 Forecast

The generic function .quantQ.ts.forecast[data;period;process;lags] forecasts period-step ahead the process of order lags based on the data set data. The parameter data is a list of floating numbers. The argument process is a positive integer. The variable contains the values AR for autoregressive process, MA for moving average process or AR for autoregressive moving averages. The fourth parameter is positive integer or list of two integers for ARMA(p,q) models.

```
.quantQ.ts.forecast:{data;period;process;lags}
// data historical data (list of numbers) used to forecast
// the process
// period -- forecast-step ahead the process where period is a
positive integer.
// process -- type of process to simulate. Accepted values: AR, MA or ARMA
// lags -- order of the process. integer for AR and MA process. List of
-- two integers for ARMA.
$[process=AR;
$[(period=type period) & (period > 0);
$[(lags = type lags;
::quantQ.ts.forecastAR[data;period;lags];
$[lags = type lags];
```

To forecast a MA(q) process, we assume the true model is. Let's take an MA(2) process as an example:

![https://images.example.com/97f51288bd0c5f8d94c22307.png](https://images.example.com/97f51288bd0c5f8d94c222307.png)

The one-step forecast is:

$X_{n+1} = c + \varepsilon_{n+1}$

The two-step forecast is:

$X_{n+2} = c + \alpha_1\varepsilon_{n+1} + \alpha_2\varepsilon_n$

The three-step forecast is:

$X_{n+3} = c + \alpha_1\varepsilon_{n+2} + \alpha_2\varepsilon_{n+1}$ and the variance of the error is $\sigma^2(1-\alpha_1^2-\alpha_2^2)$.

The code to forecast MA(q) model can, therefore, be implemented as:

```
quantQ.ts.forecastMA:{data;q];
// historical data (list of floating) used to forecast the AR
// lags model
// q -- degree of MA
est:(q+2)#0f;
v:(q+1);q+1)#0f;
alpha:(q+1;q+1)#0f;
v[0]:.quantQ.ts.gamma[0;data];
n:1;
k:0;
while[n<=q]; {
  k:0;
  while[k<n]; {
    j:0; s:0f;
    while[j<k] {
      s:s+(alpha[k-j]*alpha[n-j]*v[j]);
      j:j+1;
    }
    ];
    alpha[n-k]:..quantQ.ts.gamma[n-k;data] - s)%v[k];
  k:k+1;
  s:0f; j:0;
  while[j<n]; {
    s:s+(alpha[n-j]*xexp 2)*v[j]);
    j:j+1;
  }
  ];
  v[n]:..quantQ.ts.gamma[0;data]-s;
}
n:n+1;
```
