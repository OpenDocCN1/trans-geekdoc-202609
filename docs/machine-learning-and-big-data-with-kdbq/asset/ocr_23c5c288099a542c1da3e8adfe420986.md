In the geometric interpretation of quaternions, it is convenient to focus on the "imaginary" part of quaternions, i.e. coefficients b, c and d, while considering a = 0. The algebraic operations for such quaternions resemble the three-dimensional geometry. We can then define the dot product and the vector product.

The dot-product for a pair of imaginary quaternions $q_1 = b_1i + c_1j + d_1k$ and $q_2 = b_2i + c_2j + d_2k$ is defined as:

```
$q_1 \cdot q_2 = b_1b_2 + c_1c_2 + d_1d_2,$  (15.40)
```

or

```
$q_1 \cdot q_2 = \frac{1}{2}(q_1q_2^* + q_2q_1^*) = \frac{1}{2}(q_1^*q_2 + q_2^*q_1),$ (15.41)
```

where the function $f$ in quarks represents the weighted sum function and is trivial:

```
`i`j`k! 1.0 1.0 1.0 wsum `i`j`k! 1.0 -1.0 2.0 0
```

Secondly, we introduce the cross product, as it is known from three-dimensional geometry. The cross product of two imaginary quaternions is useful when we want to use them to express the rotations in a three-dimensional space. The generalised beyond the purely imaginary cross product would need insight into the wedge products, which can be perceived as generalised of cross product in one dimension. This is beyond the scope of this book, though, and we stick to dealing with purely imaginary quaternions. The cross product is defined as:

```
$q_1 \times q_2 = (b_1i + c_1j + d_1k) \times (b_2i + c_2j + d_2k)$ (15.42)
```

```
= (c_1d_2 - d_1c_2)i + (d_1b_2 - d_2b_1)j + (b_1c_2 - c_1b_2)k.$ (15.43)
```

The cross product of the imaginary part of a quaternion results in an imaginary part of a quaternion as well. A symbolic definition of the cross product using conjugate reads:

```
$q_1 \times q_2 = \frac{1}{2}(pq^* - q^*p^*)$ (15.44)
```
