# Simulating Asset Prices

```
.quantQ.simul.multiNormal:[N;nRows;mu;Sigma]
// N -- number of variables
// nRows -- number of observations
// mu -- array of means
// Sigma -- variance-covariance matrix
// generate T nRows array
multinormalVari:[nRows;x].quantQ.simul.getNormalVari[nRows]]
-- nRows.] each til
// multiply the multinormal vari by the Cholesky lower diagonal
matrix
multvariateCorr:(quantQ.simul.choleskyChB[Sigma]) mmu
-- multinariateNormal;
// add a mean of each process
multvariateCorr:multinvariateCorr+mu;
// create a table, variables are named var1,var2...
:flip("var",string x) each i+til)multinvariateCorr;
```

The function generates N independent 1-dimensional normally distributed variables, each following N(0,1). They are then transformed into the correlated variables using the lower-diagonal matrix from the Cholesky decomposition. The array with nRows of N(0,1) variable is defined as

```
.quantQ.simul.getNormalVari:[nRows]
// nRows -- dimension of the array
// the Box-Muller procedure; we call it it (nRows%2) round-up times
ncall:calling nRows%2;
// ncall calls of quantQ.simul.genBoxMuller and then taking the first
nRows outcomes;
:raise ({quantQ.simul.genBoxMuller[:]} each til nCall)[til nRows];
```

The Box-Muller transformation is used to generate the normal random variable, N(0,1), from the uniform random variable defined on [-1,1].
