The construction arg=/:arg works as follows: the list arg is compared with each element of the list arg and creates boolean lists marking the match of the compared elements.\Namely,

```
1 2=/:1 2 3)
```

```
(100b,010b,001b)
```

We can test the function using the simple case where the argument of the function is a list of elements which are classified:

```
quantQ.nn.encoderMulti[`t1`t2`t3]
```

and creates a dictionary which has for each element of the list entering the function an
entry:

```
t1 | 1 0 0
t2 | 0 1 0
t3 | 0 0 1
```

We use the encoder function to convert the column containing the categorical variable-atom to an array of indicator time series:

```
t:[] index: 1 2 3 4 5;val: 100 200 100 300 100
update class: {.quantQ.nn.encoderMulti distinct exec val from t} val from t
```

```
val class
-----------------
1 100 1 0
2 200 1 0
3 100 1 0
4 300 0 1
5 100 1 0
```

The map is a variable val, which has three distinct values. As the outcome of the
encoding procedure, we have created a new variable class, which has for every atom
tree-dimensional array of binary variables. The array always has one of the elements
to equal 1b while the rest are zero, denoting which class is present.

# 22.2.2 Neurons

The critical component of any neural network is neurons. These are functions which
transform a signal coming from different nodes into a response. We consider both
hidden layer neurons and the activation function (the neurons mapping the hidden
layer into the output variable) as neurons. In addition to the response of the neuron
telf we need first derivatives to calculate the gradient of the errors for backward
propagation.
