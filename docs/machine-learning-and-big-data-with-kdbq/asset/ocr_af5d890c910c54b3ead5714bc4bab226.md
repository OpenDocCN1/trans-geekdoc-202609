# Time Series Econometrics

# 14.3.1.4 Code

The unbiased estimator of the VAR(p) process given in (14.22) is implemented in the function .quantQ.ts.varpest. It uses the vector matrices Y and Z introduced in the notation section. First, we implement a vectorisation of a matrix a denoted as vec(a) in the notation section:

```
quantQ.ts.vec::[a]
// -- matrix
i:(count raze a);
j:1;
v:(flip a)[0];
while[j:i]
v:v.,(flip a)[j];
j:=j+1;

v;
```

Then, compute Zt = (y(t),...,y(t-p+1)):

```
quantQ.ts.Z::[y]
// y historical data list (list of floating numbers)
// t time point (positive integer)
// p lags (positive integer) corresponding to the order of the VAR(p)
-> process
if,quantQ.ts.vec[y;(t-1)-til p];
```

and compute Z = (zt(0),...,zt(Y-T;p));

```
quantQ.ts.Z::[y,p]
// y historical data list (list of floating numbers)
// p lags (positive integer) corresponding to the order of the VAR(p)
-> process
flip {[y;i;p]}
quantQ.ts.Z[y;i];y;p] each p + til (count y[0])-p;
```

followed by the computation of Y = (y(1),...,y(T-p));

```
quantQ.ts.Y::[y,p]
// y historical data list (list of floating numbers)
// p lags (positive integer) corresponding to the order of the VAR(p)
-> process
y[:p+til (count y[0]);-p;
```

> We can now implement the estimator of the VAR(p) model:

```
quantQ.ts.varpest::[y;p]
// y historical data list (list of floating numbers) used to estimate the
-> VAR(p) model
// p order of the VAR(p) model
::quantQ.ts.Y[y;p] mmu (flip .quantQ.ts.Z[y;p]) mmu
inv.quantQ.ts.Z[y;p] mmu flip .quantQ.ts.Z[y;p];
```
