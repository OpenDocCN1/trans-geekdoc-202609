The trigonometric form of the complex number is given as:

```
z = r(cos\phi + i\sin\phi). (15.11)
```

We implement the polar decomposition, which returns a dictionary of the radius and the angle:

```
.quantQ.polar:{[cx]
// cx -- complex number
// radial part
r: sqrt cx.re^2 + cx.im^2;
// angular part
phi: atan2(cx.im, cx.re);
if (cx.re == 0 && cx.im == 0) phi = 0;
else if (cx.im > 0) phi = 0.5 * .quantQ.pi;
else if (cx.im < 0) phi = -0.5 * .quantQ.pi;
'radius angle!(r,phi);
};
```

Let us calculate a couple of examples:

For the sake of completeness, we provide a function which converts the polar coordinates to regular form using the trigonometric form:

```
.quantQ.complex.polar2Canonical:{[polar]
// polar -- complex number in polar coordinates
:re = polar.radius * cos(polar.angle);

};
```

Having in hand an implementation of complex exp, we need the complex equivalent of logarithm. Euler's formula allows us to obtain this in a straightforward manner: 

$log(z) = log(re^{i\phi}) = log(r) + i\phi. \quad (15.14)$

This solution is not unique, though. The ambiguity comes from periodicity of the cos and sin functions, or alternatively, the rotation in the complex plane $e^{i\pi} = e^{3i\pi} = e^{5i\pi} = \dots$ This results in a multivalued definition of the logarithm:

$\log(z) = log(r) + i(\phi + 2\pi k) \text{ with } k \in \mathbb{Z}. \quad (15.15)$

The function for complex logarithm has two arguments: the first argument is the complex number $z$ while the second argument is the branch cut $k$ as defined in the previous dialog. The default value for the branch cut is 0.

```
.quantQ.complex.log:{[cx,k]}
// cx complex number
// k branch cut
polar = .quantQ.complex.polar cx;
:re = log(polar.radius);
im = polar.angle + 2 * .quantQ.pi * k;
};
```

```
.quantQ.complex.log[cx1;0]}
```

# 15.2 DISCRETE FOURIER TRANSFORM

We are now equipped with formalism to treat complex numbers. We can proceed with introducing the Fourier transform (DFT). The DFT is a special example of Fourier analysis applied on sampled points. We start with introducing the DFT and then proceed with its discrete version. For references, encourage the reader to go through Arfken (1985) or Flannery et al. (1988) for a more empirical approach.

The Fourier transform consists of a continuous function of time $f(t)$ denoted as signal and decomposes it into its frequency components, Bracewell (1986) or Grafakos (2008). The DFT transforms the function from temporal coordinates into the frequency domain. The DFT of a function in the time domain is simply multiplication in the frequency domain. This is a very useful property in signal processing. The DFT deserves more than we can afford and thus restrict our interpretation of the DFT as a filter, which allows us to decompose a function of time into the frequency components and find the leading-frequencies. In financial time series, this could correspond to the mean reversion, for instance.

Let proceed to define a DFT. Let $f$ be an integrable function $f : R \to C$, then its Fourier Transform is defined as:

```
f(\zeta) = \int_{-\infty}^{\infty} f(t)e^{-2\pi i\zeta t}dt \quad (15.17)
```

with $\zeta$ being any real number.

The variable $\zeta$ corresponds to frequency in suitable units. Let us further define the inverse DFT, which is transforming from the frequency domain into the time domain:

```
f(t) = \int_{-\infty}^{\infty} f(\zeta)e^{2\pi i\zeta t}d\zeta \quad (15.18)
```

The definition above assumes that we are equipped with the full knowledge of $f$ across $(-\infty, \infty)$. In practical applications, we observe a finite sample $f_0, f_1, f_2,\dots,f_{N-1}$ of equidistant points of the process $f$. The sample points can be in general complex. The DFT can be thought of as a sequence $F_0, F_1, F_2, F_3,\dots,F_{N-1}$ given as:

```
F_k = \sum_{n=0}^{N-1} f_n e^{\frac{2\pi kn}{N}} \quad (15.19)
```

The component of the DFT can be interpreted as correlation of the input sequence with the complex sinusoid of frequency $\frac{k}{N}$. It filters out the frequency contribution to the given frequency amplitude. Furthermore, every coefficient $F_k$ is complex encoding $\frac{2ik}{N}$ the amplitude and phase of a complex periodic component $e^n$ of the original series. The DFT is defined on the domain $k \in 0, 1, \dots, N-1$. The transform can be extended over the domain, considering the sequence to be $N$-periodic, i.e. repeating every $N$ points.

Let us illustrate the DFT in an example. First, implement a function that takes a complex series and returns one of the DFT:

```
.quantQ complex.dft:[complex n;k]
// series of complex numbers
// n length of the series
// til index of the series
// k coefficient of the DFT coefficient
:sum: .quantQ.complex.mult[csx;flip] .quantQ.complex.realExp neg (2 *
  .quantQ.pi * k * til)
);
```

and then iterate to get the full set of DFT coefficients:

```
.quantQ.complex.dft:[csx]
// series of complex numbers to be transformed
::quantQ.complex.dft[n til N] peach count csx;
);
```

Note the use of peach to provide multithreaded processing when querying with slave threads (q - s n).
