As before, now $X$ projects onto the column space of $X$, the resulting projection onto $\hat{y}$ has two (linearly independent) columns, not one, so the projection is onto a plane, not onto a line. If we increase $p$ and add more columns to $X$, if these columns are linearly independent, we will further increase the dimension of the column space of $X$ onto which we project.
