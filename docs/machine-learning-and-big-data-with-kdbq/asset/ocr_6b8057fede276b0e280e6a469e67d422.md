The function below has three arguments, a, n and theta, and returns the output of the equation a * cos(n * theta):

```
compute([[a;theta]a*cos n*theta)
```

Hence,

```
compute[5;3.5;1.57]
```

returns

```
3.52566
```

Functions can be nested:

```
a:[[x;v]:[x;w]3*w+x];v[2*w]-4f
```

The function returns v - 4f, where v is a nested function returning 3(w+x). Hence,

```
a[4;3f]
```

first calls the v function:

```
v[4;2+3f]
```

and subtracts 4f, i.e.

```
v[4f;2+3f]-4f = (3*6f+4f) - 4f = 30f -4f
```

which will result in following output when executed:

```
26f
```

Functions and variables defined within a function are local. They are created and exist in the scope of the function. Therefore, in the example above, the scope inside the v function has no visibility to the local variables or the arguments of a function. Global variables are declared with a double : symbol:

```
a:4;
f:[[b]a::6;a+b];
f[7]
```
