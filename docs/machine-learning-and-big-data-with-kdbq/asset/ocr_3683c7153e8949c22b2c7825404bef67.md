The simulation of ARMA(p) model is performed by the function `quantQ.ts.simAR`. The function (14.1) generates the list of parameters `Φ_i, i ∈ [1..p]` and white noise `ε`.

```
quantQ.ts.simAR:[phi;eps]
 // phi -- list of parameters phii...,phip
 // eps -- list of random normal numbers
p:count phi;
 x:(count eps)!=0;
t:p;
while t<(count eps)
 // here all the error terms are used, can be replace with eps[t]
 x[t]:x((t-p)+til p) mmu phi+eps[t-p];
t:t+1;
:x;
```
