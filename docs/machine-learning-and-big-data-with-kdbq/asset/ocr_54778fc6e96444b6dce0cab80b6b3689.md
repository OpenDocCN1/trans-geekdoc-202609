First, we define a function which extracts substrings of length N from the pro-
vided protein. We need to remember that the protein is an ordered array of letters.
The function returns an array of substrings as are sequentially extracted from the array
without any filtering:

```
quantQ.infth.proteinSubstring([p;N])
// p - protein
// N - length of substring
// return all substrings of length N
// [[dict] dict[`strings`];dict[`strings`],enlist 3*dict[`protein`];dict[`n//      protein]=1_dict[`protein`];dict( /)]
// [[x;N] N=count x[protein];[N];strings`protein`((());p)][`strings
//]];
```
