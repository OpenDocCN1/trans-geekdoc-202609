### FIGURE 30.1 Circles

```
// convert into table
quantum.art.pivotColours:
// canvas with canvas and patterns:update (-1)^colour1, (-1)^colour2 from
(select x, colour1:y from canvas where colour=1)
(select x, colour2:y from canvas where colour=-1);
```

Let us produce two canvases, with one circles and one with squares. In each picture, we place 42 objects. First, we produce a random circle pattern:

```
canvas1: empty;
canvas1: (quantum.art.placeCircle[100]/[42;canvas1]);
canvas1: quantum.art.pivotColours[canvas1];
```

and then produce a random square pattern:

```
canvas2: empty;
canvas2: (quantum.art.placeSquare[100]/[42;canvas2]);
canvas2: quantum.art.pivotColours[canvas2];
```

Figure 30.1 depicts canvas2 and we call it Circles. Figure 30.2 depicts canvas2, which we will refer to as Squares. The randomness is far from that of professional artist, but the idea behind the pictures should be visible. The interplay of geometric objects and randomness follows. Let us add one step beyond pure randomness and put some mathematical order into our art. Instead of uniform placement, we use a more advanced rule to place the objects. In particular, we increase the likelihood of setting an object towards the upper-right direction using quadratic transform $\propto x^2$.

## Epilogue: Art

Let us produce another canvas with a new quadratic rule:

```
canvas3: empty;
canvas3: (quantum.art.placeGradient[100]/[42;canvas3]);
canvas3: quantum.art.pivotColours[canvas3];
```

Figure 30.3 depicts canvas3 and we call it Gradient. The difference is apparent; there is random order. The presented art aims to encourage readers outside of data science. We can easily employ different rules to place the objects and combine their shape. The readers can provide their ideas and share them with us. We have to keep in mind that there is no such thing as a bad picture; the only bad picture is no.
