Decreasing greedy algorithm

Finally, let us implement the greedy algorithm where the learning rate decays over time. We consider the decay rate to follow $\sqrt{n-1}$:

```
$$\epsilon_n = \frac{\epsilon}{\sqrt{n}} (28.14)$
```

when $\epsilon_n$ is the learning rate applied at $n$-th step of the algorithm. This choice is either ad hoc and not meant to be optimal. Besides, we adjust the value of $\epsilon$ considered:
epsilon:1.0;

when a large value is chosen to amplify the learning process at the beginning while keeping some learning present towards the end. The other parameters are kept the same as in previous cases. The function mapExplorationDecreasingGA

