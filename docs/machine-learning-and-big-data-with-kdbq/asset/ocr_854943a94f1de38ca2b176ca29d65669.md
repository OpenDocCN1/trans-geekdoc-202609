# DATA SCIENCE

The one-step predictor of the $MA(q)$ process is given by:

$$\hat{X}_{n+1} = \begin{cases} 0 & n=0 \ \sum_{j=1}^{n} \hat{\alpha}_j(X_{n+1-j} - \hat{X}_{n+1-j}) & n \ge 1 \end{cases}$$

The one-step predictors $\hat{X}_1, \hat{X}_2, ...$ can be computed recursively over the coefficients $\hat{\alpha}_{ij}$ have been determined by the innovations algorithm (14.14).

# 14.1.3.1 Estimation of MA(q) Parameters

While the Durbin-Levinson algorithm gives the estimates of the coefficients in the representation:

$$\hat{X}_t = \sum_{j=1}^{p} \hat{\alpha}_{pj}X_{t-j}$$

where $\hat{\alpha}_{pj}, j=1, ..., p$ are the parameters of the model, the innovations algorithm used to estimate the parameters of the $MA(q)$ process 14.13 considers the representation:

$$\hat{X}_t = \sum_{j=1}^{m} \hat{\alpha}_{mj}(X_{t-j} - \hat{X}_{t-j})$

As for the $AR(p)$ process, we rewrite the $MA(q)$ process with a double suffix $X_t = \epsilon_t + \alpha_{q,1}\epsilon_{t-1} + ... + \alpha_{q,q}\epsilon_{t-q}$. Starting with $\hat{\sigma}_0^2 = \hat{Y}(0)$, the estimator of $\alpha$ recursively solves:

$$\hat{\alpha}_{q,k} = \frac{\hat{\sigma}_q(k) - \sum_{j=0}^{k-1} \hat{\alpha}_{q,j}\hat{\alpha}_{k,j}\hat{\sigma}_j^2}{\hat{\sigma}_k^2}$$   (14.14)

for $q=1, 2, ..., k=0, 1, ..., q-1$ and $\hat{\sigma}_q^2 = \hat{Y}(0) - \sum_{j=0}^{q-1} \hat{\alpha}_{q,j}^2\hat{\sigma}_j^2$.

The innovations algorithm to estimate the parameters of the $MA(q)$ model is implemented with the function .quant.ts.innovations[data; q].
