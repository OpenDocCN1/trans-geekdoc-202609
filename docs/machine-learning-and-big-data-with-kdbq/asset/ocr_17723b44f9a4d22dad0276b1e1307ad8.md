We have written two derivatives as a product of the error for the current model evaluated against the t-th data point, $\Delta^{(2)}$ and $\Delta^{(5)}$, respectively, and the value of the gradient of the error:

```
$$\beta_n^{(i)} \to \beta_n^{(i)} - \lambda\sum_{t=1}^T \frac{\partial R_t^{(i)}}{\partial \beta_n^{(i)}}$ (22.19)
```

```
$$\alpha_m^{(n)} \to \alpha_m^{(n)} - \lambda\sum_{t=1}^T \frac{\partial R_t^{(i)}}{\partial \alpha_m^{(n)}}$ (22.20)
```

where we keep the ordering of the equations from the output layer towards the input layer. The parameter $\lambda$ is the learning rate. It reflects how much we want to update the parameter as a function of the error. We consider the parameter constant at this stage, but we cease this assumption below.
