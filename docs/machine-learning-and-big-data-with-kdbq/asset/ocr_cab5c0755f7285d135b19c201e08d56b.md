# 16.3.2 Inverse Iteration

At this step, we are equipped with the eigenvalues calculated by the QR algorithm. We will now implement the inverse iteration algorithm, which will for every eigenvalue numerically recover the eigenvector.

First, we define an Li matrix norm, which we need within the algorithm:

```
.quantQ.mat.normL1::[matt]
// matt -- matrix
// return L1 (column norm)
:max sum abs matt;
;
```
