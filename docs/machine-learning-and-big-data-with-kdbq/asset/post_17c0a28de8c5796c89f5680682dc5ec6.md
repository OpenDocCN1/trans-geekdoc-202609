## 16.4.6 PCA Regression (PCR)

The natural extension of the dimensionality reduction using the PCA is the PCA regression, or PCR. In linear regression, we work with the model

$$
y = X\beta + \epsilon,
$$

where $y \in \mathbb{R}^n$ is the output vector, $\tilde{X} \in \mathbb{R}^{nx^*}$ is the data matrix $X$ possibly augmented with a vector of ones on the left to allow intercept (in case $p^* = p+1$) or not (in case $p^* = p$); $\beta \in \mathbb{R}^p$ is the coefficient vector; $\epsilon \in \mathbb{R}^n$ is the error term.

In PCR, we replace the predictors $X$ with the first $d$ principal components $\mathbf{Z}_d$. The model becomes:

$$
y = \mathbf{Z}_d\beta^* + \epsilon,
$$

where $\beta^* \in \mathbb{R}^d$ is the vector of coefficients. The estimator for $\beta^*$ is given by

$$
\hat{\beta}^* = (\mathbf{Z}_d^T \mathbf{Z}_d)^{-1} \mathbf{Z}_d^T y.
$$

## Eigensystem PCA

The implementation of PCA involves computing the eigenvectors and eigenvalues of the covariance matrix. Here is a conceptual approach in Python:

```python
import numpy as np

# 1. Generate synthetic data
n, p = 100, 5
X = np.random.randn(n, p)
beta = np.array([1.5, -2.0, 0.5, 0.0, 1.0])
noise = np.random.normal(0, 1, n)
y = X @ beta + noise 

# 2. Center the data
X_centered = X - np.mean(X, axis=0)

# 3. Compute the covariance matrix
C = np.cov(X_centered.T)

# 4. Compute eigenvalues and eigenvectors
eigenvalues, eigenvectors = np.linalg.eigigh(C)

# 5. Sort them in descending order
idx = np.argsort(eigenvalues)[::-1]
eigenvalues = eigenvalues[idx]
eigenvectors = eigenvectors[:, idx]

# 6. Project data onto principal components
d = 3
Z_d = X_centered @ eigenvectors[:, :d]

# 7. Run regression on Z_d
beta_star = np.linalg.lstsq(Z_d, y, rcond=None)[0]
```
