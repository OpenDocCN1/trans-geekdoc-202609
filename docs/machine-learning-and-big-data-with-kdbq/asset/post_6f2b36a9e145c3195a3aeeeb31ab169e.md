# 20.4.1 Optimisation of the Regularisation Parameter

The cross-validation technique is used to find out the meta-parameters in estimations. The regularisation parameter is such a parameter. In order to find the optimal value of the regularisation parameter, we want to solve the following equation:

```
arg min RMSE(n;α); (20.33)
α
```

RMSE(n;α) stands for the cross-validated RMSE across the entire using n folds with regularisation parameter equal to α. In this exercise, we fix n even though this parameter can be optimised in the same way we do for α. The cross-validated RMSE is defined as the average RMSE across folds for a given α.

# 20.5 LASSO REGRESSION

The second regularisation technique we introduce is the lasso regression. First of all, why do we introduce a new technique given the ridge regression is straightforward to implement and apply? The main reason is that ridge regression tends to penalise all the coefficients across the board, but in many instances, may be suitable to select a subset of features, i.e. remove some of the features instead of shrinking them significantly but still keeping them within the model. More importantly, feature selection frequently working with machine learning methods. The lasso regression assists us in feature selection as it is a better way to impose a penalty.

The lasso regression is a formulation of the OLS solution with imposed penalty having a form of an L₁ norm. The lasso estimator is solution to the problem:

$$\hat{\beta}_{\lambda}^{Lasso} = \arg\min_{\beta} (y - X\beta)^{T}(y - X\beta) + \lambda \sum_{j=1}^{p} |\beta_j| , \quad \quad (20.34)$$

# 404 MACHINE LEARNING

where $\lambda \sum_{j=1}^p |\beta_j|$ corresponds to the $L_1(\beta)$ distance. Analogously to ridge regression, we keep an explicit dependence on $\lambda$.

When $\lambda=0$, we recover the OLS solution, while for large values $\lambda$, the parameters are suppressed significantly, ultimately leading to a trivial solution. We will still tacitly impose demean on the dependent and independent variables. This will be stressed in the implementation part again.

We are tempted to obtain such a solution, the lasso regression. It is, however, challenging to be solving the problem numerically. The lasso optimisation, as in (20.34), is NP-hard and thus is on the frontier of solvable numerical problems. If we want to implement this, we need a reliable optimization technique. least angle regression, or LAR, which is close to the lasso regression (there is an interesting theoretical relationship), which does not optimisation to provide a solution and mimics the lasso solution. Further, thanks to its construction it helps us to make a feature selection.

The least angle regression was introduced by Efron et al. (2004). The method emerges from forward stepwise regression. Forward stepwise regression starts with no feature selected and tests addition of a variable into the active set of features. The one with the most significant contribution to the feature is then added. The process continues until a stopping rule. The procedure allows us at every step to test removing a feature from an active set.

The LAR, on the other hand, is defined as follows: it starts with an empty set of features. First, it identifies the variable which is most correlated with the dependent variable. A small portion of the variable is added to the model and residuals are generated. The procedure is repeated. When another variable reaches correlation to the first variable, the second variable joins the active set. The two variables are added in a tied manner and contribute to the model by small portions.
