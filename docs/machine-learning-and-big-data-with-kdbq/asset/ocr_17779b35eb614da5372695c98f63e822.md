+   - Change $eta_j$ and $\hat{eta}_k$ jointly. The OLS coefficients give the direction $\epsilon = eta'_j x_k + \epsilon$ with residuals being updated by the previous steps. The value is updated until there is another variable $x_m$, which has the same correlation with updated residuals as the two variables.
- This process continues until all variables have been included ($p > n-1$, then the process stops when $n-1$ variables have been included).

The procedure outlined above can be stopped at any iteration. At the initial stage, the situation corresponds to $\lambda 	o \infty$. The more we progress in the iteration and keeping $eta$'s, the outcome corresponds to lower and lower $\lambda$. In the end, we end up with a full OLS solution which corresponds to $\lambda=0$. If we keep track of estimated coefficients $eta$ during the iteration, and for every vector of $eta$ we perform a cross-validation test, we can reach the optimally regularised estimator. The process is similar to choosing $\lambda$ for lasso procedure itself.

The least angle regression will give the same results as the lasso procedure until the first coefficient goes zero. At this point, solutions start to deviate from each other and least angle regression will be a different regularisation scheme. A possible correction of the presented algorithm which makes the solution mimic lasso regression:

+   - Once any coefficient $eta_k$ crosses zero, it is excluded from the active set. At this point, the linear regression is added for the remaining set is recalculated using $\hat{eta}_k$.

Once this rule is added, the lasso procedure is recovered. Excluding $\hat{eta}_k$ does not mean it may return to the active set. Our stopping rule is to include all the variables (if $p \le n-1$), it will return into the active set. In the following section, we implement the least angle regression procedure.
