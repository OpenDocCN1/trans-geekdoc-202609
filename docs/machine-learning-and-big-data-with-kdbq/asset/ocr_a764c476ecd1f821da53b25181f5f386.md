We can use the log-likelihood to find the estimated parameters. To find the critical points, we compute the first partial derivatives:

```
$$\frac{\partial \ln(L)}{\partial \beta} = -\frac{1}{2\sigma^2} \frac{\partial RSS}{\partial \beta} = \frac{1}{\sigma^2}(X^T y - X^T X\beta)$
```

```
$$\frac{\partial \ln(L)}{\partial \sigma^2} = -\frac{n}{2\sigma^2} + \frac{1}{2\sigma^4}RSS$
```

In order to confirm that the solution is the global maximum of the log-likelihood and not a saddle point, we have to add the Hessian matrix. Not our objective at this point. We want to use knowledge of the log-likelihood to strengthen our knowledge about the quality of the fit.

The $R^2$ measure and its adjusted version serve to provide an absolute measure of how much variance is explained by the model. We, however, is not the only one we can use to evaluate models and decide which one to use. We introduce the Akaike Information Criteria, AIC, introduced by Akaike(1974).

Let us assume that we have a process generated by a true model $f_{true}$. We choose a model $f$ and find out how good the model $f_1$ is to capture the dynamics of the data generated by model$f_{true}$. If we know both the true model and the chosen model, we can use the information theory and calculate information loss using the Kullback-Leiber divergence:

```
$$\D_{KL}(f_{true}||f_1) = \int_{-\infty}^{\infty} f_{true}(x) \log \frac{f_{true}(x)}{f_1(x)} dx.$
```

The knowledge of the true model is hardly known in reality. Calculating the information loss of a given model for the chosen model is not possible. Akaike showed that information loss as measure of quality for the chosen model as described above can still be used when we do not know the true model. In particular, if we have two competing models $f_1$ and $f_2$ related to the same true and unknown model $f_{true}$, we can derive criteria that will help us to decide which of the two models $f_1$ and $f_2$ is causing information loss. The measure does not allow us to say how good the models are; they can be both very poor or close to the true model and the criteria only allow us to compare their difference.

For a given model $f_1$, Akaike defined the information criterion proportional to information loss implied by the model fit as:

```
$AIC_1 = 2 \cdot p_1 - 2 \cdot \ln(L_1)$,
```

With $p_1$ denotes the number of parameters in the model $f_1$, and $\ln(L_1)$ is a log-likelihood of the model $f_1$.

For two competing models $f_1$ and $f_2$, we calculate the corresponding AICs, $AIC_1$ and $AIC_2$. The model with lower AIC is causing information loss in the asymptotic limit of infinite sample size. This is the main result of Akaike.
