We can proceed with construction of the k-nearest neighbour classifier. The implementation is in two steps:

- Identify the k neighbourhood of the test point.
- Classify the first step.

In the first step, we consider the given point and calculate the distance to every point in the training sample. Then, we select k points from the training sample which are closest to the given point. We have to store only the value of a dependent variable for every chosen point and the distance to the point. ## 2. PROTOTYPE CLUSTERING

The previous method is compelling as it does not assume any parametric form and can be tuned to fit many examples. The distinct disadvantage is requirement to have large data set in memory as a "model" (training up on the fly), and whenever the classification/regression is performed, we have to work with the full sample. Depending on how much RAM we have on processing, this may become problematic.

In this section, we focus on the prototype method, which is a classification method where we identify regions in space which exhibit the same dependent variable. The centre then characterizes such region. Every region has several centres, which are learned in the training sample. In the prediction/out-of-sample step, the value of the dependent variable is determined by the value of the nearest centre.

# MACHINE LEARNING

Let us proceed specifically, where we are equipped with training data set which contains independent variables, $x_i$, all of numeric type. We further assume that these variables are normalised using the z-score. Further, the data contains one dependent variable, $f$, which is of integer value. The support of $f$ is finite, and we further assume that cardinality of each value of variable $f$ is large. This is not a mathematical constraint but rather a practical constraint, where the reader should appropriately treat all pathological cases. Let us assume dependent variable $f$ takes L different values which we need to classify.

The following algorithm defines the prototype method based on the nearest neighbours:

- Split the sample by the value of the dependent variable $f$ into $L$ subsamples. Further, proceed for each subsample independently
- For each subsample, choose $R$ observations randomly. These observations are centres or the prototypes for a given sample.
- For each centre, find $k$ neighbours from the sample.
- Replace the centre by the new centre, which is the average of the $k$ neighbours and the centre itself.
- Iterate this procedure until convergence.
- Replace the training sample by $L \times R$ centres. Each centre carries information about the value of $f$.
- Predict the class of the out-of-sample observation by the class of the nearest neighbour.

This procedure is known in the literature as $k$-clustering. Let us implement the prototype method using the following: each observation is formed by $(x_1, x_2, f)$, where $x_i \in [0, 1]$, for $i = 1, 2$, and the dependent variable is defined

$f = I_{(x_1^2+x_2^2\le1)}.$

where $I$ is the indicator function taking value when the argument is true and otherwise. We thus have a dependent variable which classifies whether the point - in space - lies within a circle with origin and radius equal to one. Such data can be generated as follows:

```
tableKNN([], x1:10000?.0;x2:10000?.0);
tableKNN: update f:(x1*x1)+(x2*x2) tableKNN
```

We have generated 10,000 points. We can illustrate the data using the following "trick":

```
select x1,x2_0:x2 from tableKNN where f=0
select x1,x2_1:x2 from tableKNN where f=1
```

which can be depicted with the scatter plot option. Figure 21.1 depicts the results, where all points within the unit circle are dark gray and the remaining ones are plotted in light gray.
