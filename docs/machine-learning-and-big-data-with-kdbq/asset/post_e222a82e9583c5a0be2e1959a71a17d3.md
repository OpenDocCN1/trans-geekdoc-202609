We can learn a tree: for each of the records in the initial split, we iterate reach pure nodes (leaves) or until the maximum specified level (maxdepth key) is reached. When we reach a leaf, we return a flattened result and then recurse over t next split record until there are none left. The flattened tree should contain all the paths and a tree-like structure with all indices i parents.
