# 22.1.1 Calibration

The neural network is rather intuitive, and two-stage regression/classification interpretation makes it transparent. What is less clear, however, is the procedure for the calibration of the weights, as the parameters of this model are frequently called. There are all together

```
$N_{params} = L \cdot (N+1) + N \cdot (M+1) \quad (22.7)$
```

parameters. The dimensionality of the problem is large.

Let us first propose an exact solution. We index the observations by index $t$, with $t=1, \dots, T$ observations in total.

# Regression

Let us want to regress the $L$-dimensional dependent variable $Y_t$. The loss function used is the sum of squared residuals:

```
$Loss_{reg}(Y, X; \Theta) = \sum_{t=1}^{T} R_t(Y, X; \Theta) \n\= \sum_{t=1}^{T} \sum_{l=1}^{L} (Y_t^{(l)} - \tau_l(\beta_0^{(l)}Z_0(X; \alpha) + \beta_1^{(l)}Z_1(X; \alpha) + \dots + \beta_N^{(l)}Z_N(X; \alpha))^2), \quad (22.8)$
```

where $Z_p(X; \alpha)$ is a function of the input data $X$ and parameters $\alpha$, expressed symbolically for brevity, and $\Theta$ comprises all parameters in the model. The linear activation function usually works well for regression problems. The loss function $Loss_{reg}(Y, X; \Theta)$ is minimised with respect to all parameters $\Theta$.

# Classification

When we want to classify the $L$-dimensional dependent variable $Y_t$ into $L$ classes, a convenient loss function is the cross-entropy function:

```
$Loss_{class}(Y, X; \Theta) = -\sum_{t=1}^{T} \sum_{l=1}^{L} Y_t^{(l)} \log \tau_l(\beta_0^{(l)}Z_0(X; \alpha) + \beta_1^{(l)}Z_1(X; \alpha) + \dots + \beta_N^{(l)}Z_N(X; \alpha)), \quad (22.9)$
```
