## 14.1.4.1 Invertibility of the ARMA(p, q) process

Denoting $\pi(L) \equiv \frac{\Phi(L)}{\alpha(L)}$ and provided that $\sum_{j=0}^{\infty} |\pi_j| < \infty$ and $\pi_0=1$, the ARMA(p,q) process can be presented as an AR($\infty$) model presented in (14.1):

```
$$\$\epsilon_t = \frac{1}{\alpha(L)}(\Phi(L)X_t - c)
= \pi(L)X_t - c
= \sum_{j=0}^{\infty} \pi_j L^j X_t - c
= \sum_{j=0}^{\infty} \pi_j X_{t-j} - c$$
```

## 14.1.4.2 Hannan-Riesenen Algorithm: Two-Step Regression Estimation

ARMA(p,q) processes are a combination of autoregressive AR(p) and moving average MA(q) processes. The $p+q$ parameters $\mathbf{\Phi} = (\Phi_1, ..., \Phi_p)$, $\alpha = (\alpha_1, ..., \alpha_q)$ and $\sigma^2$ can be estimated with a two-step regression:

- Regress $x_t$ on its past values $x_{t-1}, ..., x_{t-m}, m > \max[p,q]$, and derive the OLS estimates of $\hat{\pi}_i, i=1, ..., m$
- Step 2: Regress $\hat{x}_t$ on $x_{t-1}, ..., x_{t-p}$ and $\hat{\epsilon}_{t-1} = x_t - \sum_{i=1}^m \hat{\pi}_i x_{t-i}$.

## 14.1.4.3 Yule-Walker Estimation

Following the same reasoning as for the AR(p) process, the generalised Yule-Walker equations for the ARMA(p,q) process are:

$$ \left[\begin{array}{c} r(q+1) \\ r(q+2) \\ \vdots \\ r(q+p) \end{array}\right] = \left[\begin{array}{cccc} r(q) & r(q-1) & ... & r(q-p) \\ r(q+1) & r(q) & ... & r(q-p+1) \\ \vdots & \vdots & \ddots & \vdots \\ r(q+p-1) & r(q+p-2) & ... & r(q) \end{array}\right] \begin{pmatrix}\Phi_1 \\ \Phi_2 \\ \vdots \\ \Phi_p\end{pmatrix}$$

The Yule-Walker system of equations can be used to solve for $\Phi_i$'s given the autocorrelation function $r(i)$'s.

## 14.4.4.4 Maximum Likelihood Estimation

Let $\theta = (\Phi_1, \dots, \Phi_p, \alpha_1, \dots, \alpha_q, \sigma^2)$ denote the parameters of the ARMA(p, q) process and let $x = (x_1, \dots, x_T)$ be the observed sample of size $T$. The joint probability density function of the data given the parameter $\theta$ is $f(x|X_{T-1}, \dots, x_1|\theta)$. The likelihood function of the parameter $\theta$ given $x$ is $L(\theta|x) = f(x_{T-1}, \dots, x_1|\theta)$. The maximum likelihood estimation is:

```
$\hat{\theta}_{MLE} = \max_{\theta \in \Theta} L(\theta|x) = \max_{\theta \in \Theta} \log L(\theta|x)$
```

Assuming that the error of ARMA(p, q) process is Gaussian, $\epsilon_t \sim N(0,\sigma^2)$, the likelihood is:

```
$L(\theta|x) = (2\pi)^{-T/2}|\Gamma(\theta)|^{-1/2} \exp(-\frac{1}{2}x'\Gamma(\theta)^{-1}x)$
```

where the $T \times T$ variance-covariance matrix of $x$ is $\Gamma(\theta) = E[xx']$. The log-likelihood to optimize is:

```
$l(\theta|x) = \log L(\theta|x) = -\frac{1}{2}(T\log(2\pi) + \log |\Gamma(\theta)| + x'\Gamma(\theta)^{-1}x)$
```

## 14.1.4.6 Forecast

The innovations algorithm (14.14) used to estimate and forecast the MA(q) process can be adapted to forecast the ARMA(p, q) model. The one-step predictor is given by:

```
$$\hat{X}_{n+1} = \begin{cases} \sum_{j=1}^{n} \alpha_j(X_{n+1-j}) - \sum_{j=1}^{n-p} \alpha_j(X_{n+1-j}) & 1 \leq n < m \\ \Phi_1 X_n + \dots + \Phi_p X_{n-p} + \sum_{j=1}^{n} \alpha_j(X_{n+1-j} - \hat{X}_{n+1-j}) & n \geq m \end{cases}$$
```

$\alpha_j$ is given in the innovations algorithm (14.14):

```
$$\hat{y}(i) = \begin{cases} \sigma^2\gamma(i-j) - \sum_{j=1}^{\min\{i,j\}} \Phi_r\gamma(i-|j|) & \min\{i,j\} \leq m < \max\{i,j\} \leq 2m \\ \sum_{r=0}^{i} \alpha_r\hat{r}_{i-r}-0 & \min\{i,j\} > m \text{otherwise} \end{cases}$$
```

## 14.1.5 ARIMA(p, d, q) Process

The autoregressive integrated moving average process is a generalization of the ARMA(p,q) process. It is defined with three parameters: as for the ARMA process, $p$ is the order of the autoregressive component and $q$ is the order of the integration of the series. Let us define the $d$-lag difference operator $V_d$ by $V_d X_t = X_t - X_{t-d} = (1 - L^d)X_t$. The process $[X_t, t \in \mathbb{Z}]$ is said to be an ARMA(p,d,q) process if $V_d X_t$ is a causal ARMA(p,q) process. A causal ARIMA(p,d,q) process satisfies:

```
$$\Phi(L)Y_t = \Phi^*(1-L^d)X_t = \alpha(L)\varepsilon_t$$
```

with $[\varepsilon_t \sim N(0, \sigma^2)$ where $\Phi^* \neq 0 \leq 1$. The process $V_d X_t = (I - L^d)X_t$ satisfies:

```
$$\Phi^*(L)Y_t = \alpha(L)\varepsilon_t. \quad (14.18)$$
```
