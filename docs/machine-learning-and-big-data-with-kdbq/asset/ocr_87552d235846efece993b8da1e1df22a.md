- For each feature, demean the observations and divide the observations by the sample range.

The essential element of the two methods above is division by scale – either deviation or range. The demeaning part is applied to be able to apply the scale. If any of the methods is applied, every new data point has to be normalised in the same way. The common mistake appears for splitting the sample into in-sample, where the model is calibrated, and out-of-sample, where the model is tested. Still, many researchers take the entire sample, calculate the sample mean and sample scale – variance or normalise the entire sample. Then, they split the normalised sample into two pieces. The in-sample uses information from the out-of-sample and this calibration of the model in the in-sample is not independent of the out-sample.

We introduce the local outlier factor technique with the implementation. For the sake of clarity, we restrict ourselves to N=2, where we can depict the data. First, we define the data set in which we apply our method. The data is composed of two features x0 and x1, defined on the square [0,1]². The data are formed of two clusters defining within the lower left corner of the support set:

The first cluster is defined in the upper-right corner of the support set:

```
// cluster 1
cluster1:([] x0:0.5+0.5*1000?1.0;x1:0.5+0.5*1000?1.0 );
```

The second cluster is defined in the upper-right corner of the support set:

```
// cluster 2
cluster2:([] x0:0.5+0.5*1000?1.0;x1:0.5+0.5*1000?1.0 );
```

and the noise is evenly spread over the support space:

```
// noise
noise:([] x0:100?1.0;x1:100?1.0 );
```

Finally, we merge the data into a unique table:

```
// DataSet
dataSet:cluster1,cluster2,noise;
```

Figure 17 depicts the DataSet. The objective of the outlier detection technique is to recognise points within each cluster as not outliers and those on the boundaries as well as those outside the clusters as outliers.
