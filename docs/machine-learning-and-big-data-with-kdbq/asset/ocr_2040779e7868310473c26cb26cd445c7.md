Having in hand the weighted norm, we define the weighted regression equation:

```
$$\hat{y}_w = \frac{1}{\sum_{x' \in N} e^{-\frac{1}{2}\|x-x'\|_w^2}} \sum_{x' \in N} y(x')e^{-\frac{1}{2}\|x-x'\|_w^2}} \quad (21.8)$
```

Finally, we define a score function which assesses the performance of each vector of weights, $w$. The score is defined as the mean-squared error:

```
$e(w) = -\frac{1}{2} \sum_{x} (y(x) - \hat{y}_w(x))^2, \quad (21.9)$
```

where we have used a factor of 1/2 for convergence. The method itself incorporates leave-one-out cross-validation approach as the estimated value of $y$ for a given $x$ does not use $x$.

Further, it is important to stress that the function is continuous in $w$. This is an essential feature as allows us to obtain an analytic expression for the first derivative of the score concerning weights. Gradient-descent type of methods can be employed to find out which weights, optimise this score. The algorithm for feature selection can be specified as follows:

+   * Initialize $w=(1, 1, \dots, 1)$, set $K=1$.
* Perform an update of weights:
  * Pick datum $x$ from the training set.
  * Calculate the gradient of the loss function ($L_2$ norm) as a function of weights

```
$$\nabla e(w) = -\sum_{x} (f(x) - \hat{y}_w(x)) \nabla_w \hat{y}_w(x), \quad (21.10)$
```

```
$$\nabla_w \hat{y}_w(x) = -\frac{1}{2\beta} \sum_{x'} f(x')a(x,x')u(x',x') / \sum_{x'} a(x,x'), \quad \quad (21.11)$
```

with

```
$a(x,x') = \exp(-(\|x-x'\|^2 + \|x-x'\|_w^2)/\beta), \quad (21.12)$
```

and vector $u$ com components

```
$u_i = w_i|(x-x')|^2 + (x-x'')^2). \quad \quad (21.13)$
```

+   * Update $w = w + \eta_K \nabla_w \hat{y}_w(x)=w(1 + \eta_K \nabla_w \hat{y}_w(x)).
* Update the counter $K=K+1$ and repeat the update of weights until convergence is achieved.
