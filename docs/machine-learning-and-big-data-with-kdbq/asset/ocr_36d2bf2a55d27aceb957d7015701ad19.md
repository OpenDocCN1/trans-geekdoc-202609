$G$ is known, $\hat{	heta}$ complex

Since the analytic derivations are possible, we can derive properties of $\hat{	heta}$ numerically. In particular, we generate $B$ samples $X_1^b, \dots, X_N^b$, with $b=1, \dots, B$, by sampling with replacement. For every sample, we calculate corresponding $\hat{	heta}_b$.

Having in $\hat{	heta}$, we can estimate $	au$ using the empirical distribution function of the observed sample. Assessing the variability of $\hat{	heta}$ is then straightforward; we can read it from the sample. We may test a hypothesis about the value of $\hat{	heta}$. It is worth noting out that our numerical limitations affect the accuracy of the approximation: the larger $B$ is, the more accurate the approximation is.

Let us consider a more interesting case, where we do not possess any knowledge of $G$. The only thing we know about $G$ is what is encoded in the sample $X_1, \dots, X_N$. To analyze the statistical properties of $\hat{	heta}$ is to employ a nonparametric bootstrap. First, we construct the empirical distribution $G_N$ from the observed sample. Such a function assigns equal probability $1/N$ to every value $x_i$, with $i=1, \dots, N$. We consider $G_N$ as approximation of $G$. Then, we proceed as follows: we sample $B$ samples of size $N$ from $G$. For every sample, we calculate $\hat{	heta}_b^*$. Then, we assess $\hat{	heta}$ from the distribution function derived from sequence $\hat{	heta}_b^*$. For instance, the standard deviation of $\hat{	heta}$ is given as:

```
$$\sigma_{\hat{	heta}} = \sqrt{\frac{1}{B} \sum_{b=1}^{B} (\hat{	heta}_b^* - \frac{1}{B} \sum_{b=1}^{B} \hat{	heta}_b)^2}$ $$(25.1)
```
