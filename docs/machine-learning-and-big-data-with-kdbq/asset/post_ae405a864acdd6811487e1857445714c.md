$X_t = \Phi_1 X_{t-1} + ... + \Phi_p X_{t-p} + \epsilon_t + \alpha_1 \epsilon_{t-1} + ... + \alpha_q \epsilon_{t-q}$,

## 14.2 STATIONARITY AND GRANGER CAUSALITY

### 14.2.1 Stationarity

A stochastic process is said to be stationary if its statistical properties do not change with time. Formally, a time series $X_t, t \in \mathbb{Z}$ is weakly stationary or wide sense stationary if:

- It has a finite variance $Var(X_t) < \infty$ $\forall t \in \mathbb{Z}$.
- The mean is constant: $\mu_X(t) = \mu$, $\forall t \in \mathbb{Z}$.
- The autocovariance does not depend on $t$: $Cov(X_t, X_{t+h}) = Cov(X_{t+r}, X_{t+r+h})$, $\forall r \in \mathbb{Z}$.

A process is said to be strictly stationary if any finite collection $(X_{n_1}, ..., X_{n_k})$ has the same distribution as $(X_{n_1+t}, ..., X_{n_k+t})$ for any $k \geq 1$ and $(n_1, ..., n_k, t) \in \mathbb{Z}$.

## Test of Stationarity – Dickey-Fuller and Augmented Dickey-Fuller Tests

The Dickey-Fuller (DF) test tests the hypothesis that a unit root is present in an autoregressive model. The test estimates three models:

- The first model is an AR(1) process without constant: $y_t = \rho_1 y_{t-1} + \epsilon_t$.
- The second model is an AR(1) process with constant: $y_t = \beta_2 + \rho_1 y_{t-1} + \epsilon_t$.
- The third model adds a trend to the AR(1) constant: $y_t = \mu_1 + \beta_3 t + \rho_1 y_{t-1} + \epsilon_t$.

The first model can be rewritten as $\Delta y_t = (\rho_1 - 1)y_{t-1} + \epsilon_t = \Phi_1 y_{t-1} + \epsilon_t$, the second model $\Delta y_t = \mu_1 + \Phi_2 y_{t-1} + \epsilon_t$, and the third $\Delta y_t = \mu_2 + \beta_3 t + \Phi_1 y_{t-1} + \epsilon_t$.

The ADF test tests the stability of AR(1) processes. The test can be augmented to detect a unit root for AR(p). It is Augmented Dickey-Fuller (ADF) test. The ADF estimates three models:

- The AR(p) model without constant: $\Delta y_t = \Phi_1 y_{t-1} + \sum_{j=2}^p \beta_j y_{t-j} + \epsilon_t$.
- The AR(p) model with constant: $\Delta y_t = \mu_1 + \Phi_1 y_{t-1} + \sum_{j=2}^p \beta_j y_{t-j} + \epsilon_t$.
- The AR(p) model with constant and trend: $\Delta y_t = \mu_2 + \beta_3 t + \Phi_1 y_{t-1} + \sum_{j=2}^p \beta_j y_{t-j} + \epsilon_t$.

The null hypothesis of ADF test is the non-stationarity (unit root) of variable $y_t$, i.e., $\phi=0$. The ADF test uses statistics given by MacKinnon (1996). The null hypothesis of non-stationarity is rejected at 5% if $t_{obs} < ADF_{critical}$. The optimal number of lags of AR(p) is determined with linear regression and implemented with the function .quantQ.ols AIC: To determine whether to retain the hypothesis of a unit root with or without a constant, Student-t associated with the constant $\mu_i$ is compared with tabulated values of the statistics. For the third model, the ADF test checks whether coefficients associated with the constant ($\mu_2$) and trend ($\beta_3$) are significantly different from zero with $H_0: \mu_2=0$ and $H_0: \beta=0$.

The $\Delta$ of a time series is simply deltas. Their autoregressive models can be estimated with the function .quantQ.ols. Tabulated values of the statistics given by MacKinnon can be stored in a dictionary and computed with t-stat $t_{obs}$ as implemented in the function .quantQ.fit.

The models presented so far are limited. They only use realizations of a random variable to explain its current and future values. In addition to the use of past values a model can be improved by adding historical values of external factors, also called exogenous variables. An autoregressive process of order p with exogenous variables, denoted as ARX(p), is given by:

```math
Y_t = a_0 + a_1Y_{t-1} + ... + a_pY_{t-p} + b_1X_{t-1} + ... + b_pX_{t-p} + \epsilon_t. (14.19)
```

By the same time, an ARX(p,q) process is defined as:

```math
Y_t = a_0 + \sum_{i=1}^p a_iY_{t-i} + \sum_{i=1}^p b_iX_{t-i} + \sum_{j=1}^q c_j\epsilon_{t-j}. (14.20)
```

The parameters of these two models with exogenous variables can be estimated with the same methods as their based models. To determine whether the lagged values of an exogenous explain the current and future values of a random variable, we introduce the Granger Causality test. The Granger Causality test is a statistical hypothesis test for determining whether an external series X(t) is useful in forecasting another Y(t). A time series X is said to be Granger-causal Y if it can be shown, by running a t-test or F-test on lagged values of X, that historical values of X provide statistically significant information about future values of Y. To find out X causes Y, we compare the AR(p) model with the corresponding ARX(p) model and perform a t-test for individual coefficients under the null hypothesis $H_0, b_1 = ... = b_p = 0$ against the alternative hypothesis $H_1$, that at least one coefficient is non-zero.

We can run an F-test:

```math
F = \frac{\frac{(R^2_{fullModel} - R^2_{restrictedModel})}{nbAdditionalVariables}}{\frac{1}{nObs - nParamsFullModel}}.
```

and compare with $F^*(nbAddedParams, nObs - nParamsFullModels). The null hypothesis of no Granger causality is rejected if $F > F'$. Note that the Granger Causality suffers from some limitations such as:

- Granger causality is not necessarily true
- The Granger Causality often fails if an exogenous variable X affects Y through other time Z.
- When(X) is autocorrelated, the impact of lagged values of X on Y(t) is simply a consequence of the impact of X(t) on Y(t).

A implementation of the F-test presented in the previous chapter is quant.ols.Statistics.

## 14.3 VECTOR AUTOREGRESSION

This chapter generalises the univariate autoregressive process to capture the linear interdependencies among multiple series. Simply speaking a vector autoregressive model VAR(p) is a generalisation of an AR(p) process where the random variable X_t is replaced with a vector of variables $X_{it}$.

### 14.3.1 VAR(p) Process

The vector autoregressive (VAR) of order p is given by

```math
Y_t = \nu + A_1Y_{t-1} + ... + A_pY_{t-p} + \epsilon_t, (14.21)
```

for $t = 0, 1, \dots$ where $u_t = (u_{1t}, \dots, u_{kt})^T$ is $K$-dimensional white noise or innovation process with $E[u_t]=0, \Sigma_u$ and $E[u_tu_s^T] = 0$ for $s \neq t$.

### 14.3.1 Notation

Let us assume $y_1, \dots, y_T$ are available for each of the $K$ variables for the same period. We introduce the following notations:

- $Y := (y_1, \dots, y_T)^T K \times T$ matrix
- $B := (Y, A_1, \dots, A_p) K \times (Kp+1)$ matrix
- $Z_t = \begin{pmatrix} y_t \\ \vdots \\ y_{t-p+1} \end{pmatrix} (Kp+1) \times 1$ matrix
- $Z := (Z_0, \dots, Z_{T-1}) (K+1) \times T$ matrix
- $U := (u_1, \dots, u_T) K \times T$ matrix
- $y := \text{vec}(Y) K \times 1$ matrix
- $\hat{\beta} = \text{vec}(B) (K^2p+K) \times 1$ matrix
- $b = \text{vec}(B') (K^2p+K) \times 1$ matrix
- $u = \text{vec}(U) KT \times 1$ matrix

### 14.3.1.2 Estimator

An unbiased estimator of a VAR(p) process defined in (14.21) is

```math
B = ZZ'(ZZ')^{-1}, (14.22)
```

The estimator of the variance-covariance matrix of the residual is given by

$$\Sigma_U = \frac{1}{T-Kp-1}(YY' - Y'(ZZ')^{-1}ZY'), (14.23)$$

To estimate whether the estimated coefficients $\hat{B}$ of the model are significant, we can compare the estimated element of t-ratios matrix

$$\frac{\hat{B}}{\sqrt{\text{diag}(\Sigma_U) \otimes (ZZ')^{-1}}}, (14.24)$$

with the critical values from a t-distribution with $KT-K^2p-K$ degrees of freedom. The operator $\otimes$ is the Kronecker product and diag is the diagonal of the matrix.
