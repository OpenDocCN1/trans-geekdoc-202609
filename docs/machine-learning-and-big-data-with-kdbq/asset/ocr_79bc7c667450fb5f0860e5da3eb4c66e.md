# 12.3.8.3 Holm Method

The Holm's method was introduced in Holm (1979) and provides an algorithm which ensures the family-wise error rate is $\alpha_{family}$. The method works as:

+   Sort in ascending order the p-values of all individual hypotheses: $p_{(1)} \le p_{(2)} \le \dots \le p_{(m)}$. The set of indices $i_{(k)}$ orders the hypotheses accordingly, i.e. hypothesis $H_{i_{(k)}}$ is the one with lowest p-value.
- For every index $i_k$, we define the critical value

$\alpha_k = \frac{\alpha_{family}}{m + 1 - k}$.

+   - Find the smallest index, that such

$p_{(k)} > \alpha_{(k)}$.

+   - Reject the hypotheses $H_{i_1}, \dots, H_{i_q}$. In addition, $H_{i_q}$ stands for no hypothesis to be rejected.

To implement the Holm's method, we need to provide an array of $m$ p-values and the family-wise confidence level $\alpha_{family}$. The implementation reads:

```
quantQ.stats.pHolm:[Array;alpha]
// alpha -- family-wise alpha
// pArray -- m-dimensional array of p-values
// return indices of hypothesis which are rejected
```
