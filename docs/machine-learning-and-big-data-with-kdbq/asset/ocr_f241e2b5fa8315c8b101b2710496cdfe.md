Demaning of variables is not part of the one step of iteration. We will discuss it later when we are done with iteration. This which creates the estimation suite for the entire LAR algorithm. At the end of every iteration, the vector of residuals r is updated accordingly. The vector of residuals contains a cumulative unexplained part of variance at the end of each step. The algorithm is supposed to stop once we cannot find any more correlation of the remaining variables to the data (within our precision).

```
quantQ:reg.oneStepLAR:[bucket]
// all the variables
beta:bucket[`beta`]
betaUsed:bucket[`betaUsed`]
betaDir:bucket[`betaDir`]
y:bucket[`y`]
xS:bucket[`xS`]
r:bucket[`r`]
path:bucket[`path`]
continue:bucket[`continue`]
step:bucket[`step`]
// set the significance limit
corTh:1.0*sqrt(f"$count y")
// step 1, find first variable
$1=count path;;
// find variable with largest correlation
betaUsed:z=max abs cor[r]; each xS;
// set the direction
betaDir:f"$betaUsed"
// update r
r-=step*betaDir;
// update beta
beta+=step*betaDir;
// update path
path,{[`step`:1].last path[`step`];beta: enlist beta}
];
// step 2, there is space for improvement
$1(1<count path) and (=-prd betaUsed);
[
// correlation with existing direction
corDir: abs cor[r];sum betaDir+xS;
// best correlation with the candidate directions
corNew: max z:not[betaUsed]+ abs cor[r]; each (),xS;
corWhere: z=max z;
// decide whether to continue
[$corTh>max(corDir,corNew]);
// stop the algorithm
continue:0;
// continue algorithm, decide the direction
$[(corDir>corNew];
// old direction
```
