## 29.2 ISING AGENT-BASED MODEL FOR FINANCIAL MARKETS

The agent-based model based on the Ising model of ferromagnetism is the main scope of this chapter. We first review the Ising model in physics and recast it into the model of interacting traders, who trade one or more assets and form the opinion on the price based on the mutual interaction.

### 29.2.1 Ising Model in Physics

The Ising model is a theoretical model of ferromagnetism in statistical mechanics and detailed by Brush (1967). The very first version of the model can be dated to 1924, Ernst Ising, a German physicist, who finished his thesis in he solved the one-dimensional model of interacting magnetic dipole moments of atoms, which are in two discrete states as ±1. The one-dimensional formulation does not allow for phase transitions, which appear in higher-dimensions only.

The Ising model can be described as follows. We consider a d-dimensional lattice – or graph – each node of the lattice carries a spin, σ = ±1. The configuration of all spins for every node determines the macroscopic properties of the lattice. Besides, the lattice nodes are interacting with neighbourhood nodes through an interaction term, and at the same time the entire lattice is under the influence of the external field.

### 29.2.2 Ising Model of Interacting Agents

Let us follow the formalism of Takaishi (2015), which is a multivariate generalisation of a standard Ising model as proposed by Bornhold (2001). The model demonstrated ability to mimic the stylized facts of price time series observed in the markets; e.g. Yamano (2002), Kaizoji et al. (2002), and Krause and Bornhold (2011).

The Ising model is defined as follows. We consider a set of $N = n \times n$ agents – traders in this class – placed on a square lattice, where trade $K$ stocks. Each $i$, forms a view about each asset, where the trader can be either bullish about asset $k$, the spin take value $\sigma^{(k)}_i=+1$, or bearish about asset $k$, the spin take value $\sigma^{(k)}_i=-1$. The spin reflects the desire of the trader to either buy or sell the asset. The opinion of a trader to bullish or bearish is formed by the local field, an analogy to the local energy in the ferromagnetic model, given as:

```
$\eta^{(k)}_i(t) = \sum_{j} I_{ij}\sigma^{(k)}(i)\sigma^{(k)}(j) - \alpha_k^{(k)}|\Pi^{(k)}(t)| + \sum_{j} \rho_{ik}\Pi^{(i)}(t), \quad (29.3)$
```

where $I_{ij}$ is a term describing an interaction of a trader $i$ with its neighbourhood, the term $\alpha$ is anti-polarization of trader to the prevailing opinion, and $\rho_{ik}$ is perceived correlation between asset $k$ and other assets.

The interaction term is further assumed to have a zero diagonal for nondagonal terms reflects the reach of interaction between traders. The nearest neighbour can be described by the lower and upper diagonal being non-zero, usually equal to one, while the rest is zero. The correlation of the perceived relationship between assets is a free parameter of the model and can be set accordingly, with diagonal terms being equal to zero.

On account, Bornholdt proposed the following updating procedure:

- At time $t$, the trader $i$ is randomly chosen.
- The spin of the trader $i$ is updated using the following updating procedure:

```
$$\sigma_k^{(k)}(t+1) = +1 \text{ with probability } p = \frac{1}{1 + \exp(-2\beta\eta_k^{(k)}(t))}, \quad (29.4)$
```

```
$$\sigma_k^{(k)}(t+1) = -1 \text{ with probability } 1-p. \quad (29.5)$
```

- Set time to $t \rightarrow t+1$.
- Calculate the market imbalance between buy and sell orders:

```
$$\Pi^{(k)}(t+1) = \sum_{j=1}^{N} \sigma_j^{(k)}(t+1). \quad (29.6)$
```

- Continue the iteration.

The market imbalance reflects the price of the asset and serves as a proxy for the price. The price process can be further enhanced by considering a certain number of assets to be traded per agent as well as some market clearing mechanisms. In our approach, we settle to the basic model with the price process being equal to market imbalance.

### 29.2.3 Numerical Implementation

We implement the Ising model as outlined in the previous section. Let us start with the simple case of $K=1$. Every agent is described by the 2-dimensional integer coordinates $(x,y)$. For the sake of simplicity, we build the one-dimensional Ising model. on a square lattice of size $10 \times 10$:

```
nGrid:10;
```

with the number of agents equal to 100:

```
nOfAgents:nGrid=nGrid;
```

The main grid is defined as a key table. Let us suggestively name it wallStreet as this table consists of the artificial traders in the market following the Ising model.
