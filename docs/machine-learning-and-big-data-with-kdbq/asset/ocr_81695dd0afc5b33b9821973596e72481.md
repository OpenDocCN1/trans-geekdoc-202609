AlphaGo utilises this a neural network, in particular, deep convolutional network with many layers. The network takes as an input s of the game and the history leading to the current board and provides two probability distribution for the possible moves reachable from the current state, denoted as P, and the value of the current state v. The value is a scalar and reflects the probability for a current player to win the state s. We formally write the network as:

```
$$(P, v) = f_{\theta}(s), \quad (28.23)$
```

where $\theta$ is a parameter set, and the probability $f_{\theta}$ of a given move a to be extracted as:

```
$$$P_a = P(s, a). \quad (28.24)$
```

The model $f_{\theta}$ was estimated from the record of games played by professional players. AlphaGo combines the two networks in the following manner:

+   - The algorithm starts at a root node equipped with $f_{\theta}$.
- The node has assigned prior probabilities for possible moves using $P(s_{root}, a)$, for all moves $a$, and every possible move gets a counter of visits $N(s_{root}, a)$, initialised at 0.
- Each simulation starts at the root node chooses a node $a$ that maximises the analogue to the UCT formula:

```
$$$a = \max_{a'} Q(s_{root}, a') + U(s_{root}, a'), \quad (28.25)$
```

where $Q$ is an action-value and $U$ corresponds to the exploration function. It is further utilised that:

```
$$$U(s_{root}, a') = \frac{P(s_{root}, a')}{1 + N(s_{root}, a')}. \quad (28.26)$
```

Since the value $v$ is noisy, the action-value is defined for any state s:

```
$$$Q(s, a') = \frac{1}{N(s, a)} \sum_{s'} v(s'), \quad (28.27)$
```
