# 3.2.6 Converge

The over / scan \ scan recursively apply a function to each item of a list. They can also be used to iterate over a list until convergence or until a loop is detected.

# 3.2.6.1 Converge-repeat

The recursive pattern

```
x f/ y
```

applies the function f times with initial value y.
If x is a boolean to indicate a condition on recursive iteration, the expression is equivalent to a while loop:

```
x:y; / initial condition
while[x;f]
```

The following expression recursively applies the function x+x-1 2 times on the list

```
(2 {x*x-1}/2 4 3 2 5f)
```

and returns:

```
2 132 30 2 380f
```

It is equivalent to applying the result of the first iteration:

```
1{x*x-1}/(2 4 3 2 5f)
```

```
2 12 6 2 20f
```

to the function x*x-1.

```
1{x*x-1}/2 12 6 2 20f
```
