# 9.1 PREDICATE FILTERING

# 9.1 The Where Clause

The function is the king of filters; we were first introduced to it in Chapter 1. It acts as a natural filter on a vector:

```
price:10000?10f;
price where price > 5f
```

```
5.615679 9.027819 6.233409 6.471146 8.091551 6.04611 5.45438 9.955497
- 8.851822 6.443215 9.732086 8.000355 9.900114 9.643722 7.929776
- 5.052403 5.779...
```

It is also our constraint filter in a select statement:

```
table: [ ] sym: count[ price ] ? a`b; price );
select table where price > 5f
```

```
sym price
nb 5.615679
a 9.027819
b 6.233409
b 6.471146
a 8.091551
```
