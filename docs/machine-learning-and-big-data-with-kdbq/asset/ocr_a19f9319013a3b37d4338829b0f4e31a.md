# Forests 501

The function returns b a dictionary where the first key `tree` is our tree for bootstrap sample `oob` containing the out-of-bag predictions, and a third entry denoted by `ibi`, which contains the in-the-bag indices for each sample. It `tags` the tree with the value of the corresponding $b$ under column B.

The procedure is then repeated until all B trees are created:

```
quantQ.rf.randomForest:{params}
// params dictionary,
ensemble: .quantQ.rf.bootstrapTree[params;params`m;peach till
// params`B;
// raze flip ensemble;
```

Using the Iris data set, we can now create a random forest of 10 trees by running the following code, which samples 3 features out of 4,m=3:

```
// sampling size = count of data sample
// start sampling 3/4 features in every breakpoint search
// n = count iris
forest: .quantQ.rf.randomForest params,params`n`B!(3;150;10)
```

Examining the result, we see that it is a dictionary with 3 keys, ensemble, the out-of-bag predictions and the "in-the-bag" indices, i.e., the trees selected for each bootstrap sample:

|type forest

|99h

|key forest

|`tree`oob`ibi`

The ensemble of trees – a table of treetops – and the out-of-bag predictions are both themselves, tables:

|each forest

|tree | 98
oob | 98
ibi | 99

The`ibi` key is a dictionary (type=99) of indices used for each tree B.
