## 13.6.1 Adjusted R-squared

There is a modification to the goodness-of-fit as introduced above which penalises the measure for the number of independent variables. The adjusted $R^2$ is based on the same principles as $R^2$, i.e. the ratio of unexplained variance to the total variance, except that the measure of variance is adjusted for the total number of degrees of freedom. In particular, let us denote the adjusted $R^2$ as $\overline{R^2}$ and define it as:

> $R^2 = 1 - \frac{RSS}{TSS}$

$$1 - \frac{RSS/df_p}{TSS/df_0}$$
$$1 - \frac{RSS(n-1)}{TSS(n-p-1)}$$

$\overline{R^2}$ denotes the adjusted residual to the sum. The adjusted $R^2$ is the total sum of squares, $df_p$ is the total number of degrees of freedom for a model with $n$ data points, $p$ independent variables and constant, $df_p = n-p-1$, and $df_0$ is the total number of degrees of freedom for a model to equal constant.

The adjusted $R^2$ is no longer equivalent to the sum of the correlation coefficient for the univariate, neither is it a non-increasing function with the number of independent variables added to the model. The adjusted measures the trade-off between the explanatory power of the model and its parsimoniousness; thus the adjusted $R^2$ is increasing with additional variables if the unexplained variance is decreasing more than $(n-p-1)$.

It is worth noting that adjusted $R^2$ is no longer bounded within $[0, 1]$. The adjusted $R^2$ can be an objective of the researcher when modelling the data trade-off is fully reflected. However, we do not recommend to use the adjusted $R^2$ as the criteria to be maximised without further considerations. The main problem is that incremental improvement to the adjusted $R^2$ can still produce insignificant improvement. The subsequent section considers a more appropriate tool to decide whether adding variables have a significant impact on the variance improvement.

We provide a function that implements the adjusted $R^2$ defined in the previous display as:

```
.quant.ols.rSquaredAdj[y;yHat;p]
// y -- the underlying data
// yHat -- the model
// p -- the number of explanatory variables excluding constant
// adjusted Total Sum of Squares
adjTSS:(1.0%(count[y]-1))*sum t*y-avg[y]
// Adjusted Sum of Squares
adjRSS:(1.0%(count[y]-1-p))*sum t*y-yHat
// adjusted R squared
:(adjTSS-adjRSS)%
;
```

The example under consideration shows very high adjusted $R^2$:

```
.quant.ols.rSquaredAdj[y; sum beta+x; count[beta]]
```

0.998931

The adjusted value is close to the unadjusted value and very high. The estimated model explains much of the variance; the unexplained variance is white noise without any pattern.

## 13.7 RELATIONSHIP WITH MAXIMUM LIKELIHOOD ESTIMATION AND AIC WITH SMALL SAMPLE CORRECTION

We link the OLS procedure to the maximum likelihood estimation. This is interesting theoretically well as useful from a practical perspective. It allows us to define additional criteria to assess the quality of the fit. If $\epsilon_1, \dots, \epsilon_n \sim N(0, \sigma^2)$. Then, taking $\mathbf{x}_1, \dots, \mathbf{x}_n$ as data, the observations have density functions $\varphi(y_i; \beta, \sigma^2)$, and the likelihood of $\beta$ and $\sigma$, based on the sample,

$$\mathcal{L} = \prod_{i=1}^n \varphi(y_i; \mathbf{x}_i^T, \beta, \sigma^2) = (2\pi\sigma^2)^{-n/2} \exp \left\{-\frac{1}{2\sigma^2}(\mathbf{y}-\mathbf{X}\beta)^T(\mathbf{y}-\mathbf{X}\beta)\right\}. (13.59)$$

It is convenient to take the logarithms and we obtain the log-likelihood

```
$$\ln(\mathcal{L}) = -\frac{n}{2}\ln(2\pi) - \frac{n}{2}\ln(\sigma^2) - \frac{1}{2\sigma^2}(\mathbf{y}-\mathbf{X}\beta)^T(\mathbf{y}-\mathbf{X}\beta) (13.60)$$
```

```
$=-\frac{n}{2}\ln(2\pi) - \frac{n}{2}\ln(\sigma^2) - \frac{1}{2\sigma^2}RSS. (13.61)$$
```

We can use the log-likelihood to find the estimated parameters. To find the critical points, we compute the first partial derivatives:

```
$$\frac{\partial \ln(L)}{\partial \beta} = -\frac{1}{2\sigma^2} \frac{\partial RSS}{\partial \beta} = \frac{1}{\sigma^2}(X^T y - X^T\beta)$$
```

```
$$\frac{\partial \ln(L)}{\partial \sigma^2} = -\frac{n}{2\sigma^2} + \frac{1}{2\sigma^4}RSS$$
```

In order to confirm that the solution is the global maximum of the log-likelihood and not a saddle point, we have to add the Hessian matrix. The $R^2$ measure and its adjusted version serve to provide a measure of how much variance is explained. We introduce the Akaike Information Criteria, AIC, introduced by Akaike (1974).

Let us assume that we have a process generated by true model $f_{true}$. We choose a model $f$ and find out how good the model $f_1$ is to capture the dynamics generated by $f_{true}$. If we know both the true model and the chosen model, we can use information theory and calculate information loss using Kullback-Leibler divergence:

```
$$\D_{KL}(f_{true}||f_1) = \int_{-\infty}^{\infty} f_{true}(x) \log \frac{f_{true}(x)}{f_1(x)} dx.$$
```

The knowledge of the true model is hardly known in reality. Calculating the information loss of a given model for the chosen model is not possible. Akaike showed that information loss as measure for the chosen model can still be used when we do not know the true model. In particular, if we have two competing models $f_1$ and $f_2$ related to the same unknown model $f_{true}$, we can derive criteria that will help us decide which of the two models $f_1$ and $f_2$ is causing information loss. The measure does not allow us to say how good the models are; they can both be poor or close to the true model and the criteria only allow us to compare their difference. For a given model $f_1$, Akaike defined the information criterion proportional to information loss implied by the model fit as:

```
$AIC_1 = 2 \cdot p_1 - 2 \cdot \ln(L_1),$
```

With $p_1$ denoting the number of parameters in the model $f_1$, and $\ln(L_1)$ is the log-likelihood of the model $f_1$. For two competing models $f_1$ and $f_2$, we calculate the corresponding AICs, $AIC_1$ and $AIC_2$. The model with lower AIC is causing information loss in the asymptotic limit of infinite sample size. This is the main result of Akaike.

The minimization of the information criteria gives an intuitive explanation to two terms forming the AIC. The first term corresponds to a penalty which might discriminate favor of complex models and prevent overfitting. The second term, on the other hand, corresponds to the quality of the fit. The AIC thus balances the bias-variance trade-off and guides towards models which are truthful but not too complex.

The concept of comparing information criteria for two competing models does not constitute any form of hypothesis testing. The comparison brings a relative measure without any significance. Let us assume have two models $f_1$ and $f_2$ with similar information criteria $AIC_1$ and $AIC_2$. Without loss of generality, let us assume that $AIC_1 < AIC_2$. Then, the:

```
$exp\frac{AIC_1 - AIC_2}{2} (13.66)$
```

is proportional to probability that model $f_2$ minimizes the information loss relative to $f_1$.

For linear OLS-based models, the comparison based on the AIC results in similar comparison. The advantage of the AIC is that it can be used for non-nested models while measures derived from $R^2$ ($F$-test) can be used to compare nested models only.

Once we have obtained log-likelihood, we can calculate the AIC for a given model. We can stick to $\ln(\beta) = -\frac{n}{2}\log(\sigma^2)$ as this is the term which will vary across models for a given sample. In the implementation below, however, we keep the full formula for log-likelihood:

```
logL::log[2*acos -1]+count[y%2.0]+neg[log[sqrt[SSR%count[y]]]+count[y]]+neg[(1.0%(2.0%count[y])];
logL
```

It is convenient to create a function which calculates the log-likelihood, as it is one of the main concepts used in modern econometrics:

```
.quantQ ols.logL[(n;RSS]
// -- size of the sample
// -- Residual sum of squares
:neg[log[2*acos-1]+n%2.0]+neg[log[sqrt[SSR%n]]+neg[(1.0%(2.0%n))]];
);
```
