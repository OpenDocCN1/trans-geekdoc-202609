# 10.1 DEFINITION

A parse tree is a list whose first element is a function, and the remaining entries are its arguments, expressed as tokens. This can be recursive so that the arguments can be functions themselves; therefore, the parse tree can be an elaborate construct spanning multiple levels and will be challenging to represent graphically. Tokens are q’s internal representation of constants and variables. There are two critical native operators which we need to work with parse trees: eval and parse.

# 10.1.1 Evaluation

eval takes as an argument the tree itself and returns the value corresponding to the evaluated parse tree. The parse tree itself is not evaluated unless explicitly done by being passed as an argument to eval. Let us start with a basic example:

