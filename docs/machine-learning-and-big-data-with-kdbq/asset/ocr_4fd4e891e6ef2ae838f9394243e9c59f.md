# Towards AI – Monte Carlo Tree Search

When enough simulations have been played, AlphaGo chooses the move to make. By its nature, the more valuable moves are explored more frequently by the algorithm and thus assessing the final value for deciding which move to make is as:

$\pi_a \propto N(s,a)^{1/\tau}$

The nodes with higher Q are visited more frequently. The probability for a node to be proportional to the exponential of the number of visits of the node, raised to the inverse power of temperature $\tau$. With $\tau \to 1$, there is possible exploration when making a decision for $\tau \to 0$ only the node with the highest count of visits is chosen. This concludes AlphaGo.

The role of the MCTS algorithm is the policy improvement operator. The initial values of P are prior probabilities in the Bayesian sense, and the MCTS algorithm is the posterior distribution, which is usually better than prior values themselves.

# 28.4.2 Reinforcement Learning

AlphaGo Zero goes one step beyond AlphaGo; see Silver et al. (2017). It uses Reinforcement Learning technique, which allows the algorithm to learn the policy and value networks $f_0$ without a need for human input. The algorithm starts with the randomly initialized parameter $\theta_0$.

The neural network plays games with itself, in particular, with previous versions of itself. During the game, the neural network is re-trained on the evolution of a game. The game starts as a random game where only the first principles, i.e. the rules of the game, are used. From the random moves, the neural network learns values and various board setups. The algorithm learns to use patterns on the fly. The patterns are learned, they are used, and thus the algorithm learns to explore the ways to beat the patterns. This expresses the evolution learning cycle of the algorithm.

The algorithm does not need any human input. The role of the MCTS is exploring how to improve itself given the current knowledge. The reinforcement learning ensures that the algorithm learns from all playouts. By chance a good pattern is found out, the algorithm remembers it and learns to use it further. At the same time, it finds out not to be beaten by the player using the same pattern.

It is striking that starting with first principles, AlphaGo Zero has to learn all the patterns, tactics, and starting positions taught by the go masters. These patterns have been found out by the algorithm itself. Besides, new patterns have been explored and thus the AlphaGo Zero playouts have explored the textbooks. It is not without surprise that it is time for human players to make their move and reinforce their understanding of the game and learn from AlphaGo Zero.
