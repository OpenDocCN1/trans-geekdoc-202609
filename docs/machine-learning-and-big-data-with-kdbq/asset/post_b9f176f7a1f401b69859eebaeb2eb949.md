
## 16.2.1 QR Decomposition

Given a square matrix **A**, the QR decomposition is a factorisation of the matrix into a product of **QR**, where **Q** is an orthogonal matrix and **R** is an upper triangular matrix. Symbolically, it reads:

```
A = QR. \quad (16.10)
```

The QR decomposition is useful for many applications, and in particular, it is a basis for the QR algorithm to find eigenvalues of the square matrix.

There are number procedures to find the QR decomposition. The favoured method is, for instance, Householder reflection, which is a transformation that carries a vector and reflects it about some plane or hyperplane. The hyperplane is chosen such that the sub-diagonal part of **A** disappears. Another popular method is the numerically unstable Gram-Schmidt orthogonalisation process, which can be turned into an expression for the matrix R. Last but not least, there is a method based on Givens rotations, which will be utilised in this chapter.

## Givens rotation

The notion of rotation is a general concept which stands for a rotation in a plane spanned by two dimensions with axes x, y, and z. Givens rotation is for example in x - y plane, where all z coordinates of a rotated object are constant. In linear algebra, rotation can be represented by a square matrix. For Givens rotation, such a matrix has the form of:

```
G(i,j;\theta) = \begin{pmatrix} 1 & & 0 & & & 0 \\ \vdots & 0 & & \vdots & & \vdots \\ 0 & & \cos(\theta) & & \dots & -\sin(\theta) & 0 \\ \vdots & & 0 & & \vdots & \\ 0 & & \sin(\theta) & & \cos(\theta) & 0 \\ \vdots & & \vdots & & \vdots & \\ 0 & & 0 & & 0 & 1 \end{pmatrix} \quad (16.11)
```

where the matrix **G** has a unit on the diagonal for every row but i-th and j-th one, respectively. The selected rows denote the plane in which the rotation takes place. The rotation in a two-dimensional space is given

```
R(\theta) = \boxed{\begin{pmatrix} \cos(\theta) & -\sin(\theta) \\ \sin(\theta) & \cos(\theta) \end{pmatrix}} \quad (16.12)
```

The rotation matrix is thus proved in i-th and j-th rows/columns. The QR decomposition can be found as follows:

- Start with the matrix **A.**
- Start with the first column.
- Start with the last, indexed with $p$. Find Givens rotation $G_{(p,1)} = G(p; \theta_{(p,1)})$, which zeros the $(p,1)$ element of matrix $A$: $\{G_{(p,1)}A_{(p,1)} = 0$.
- Take the outcome of the previous step and find a Givens rotation $G_{(p-1,1)}$ (we use compact notation from now onwards), which zeros the $(p-1, 1)$ element of the matrix. $\{G_{(p-1,1)}G_{(p,1)}A_{(p,1)} = 0$. By nature of the Givens rotation matrix, it will hold $\{G_{(p-1,1)}G_{(p,1)}A_{(p,1)} = 0$.
- Proceed until the $(2,1)$ element. At this end of this step, we have a matrix where the first column has all elements but the diagonal is equal to zero.
- Proceed with the second column and third column rotations that zeros elements $(p,2), \dots, (p-2)$ are zero, starting with $(p,2)$ element. Since this procedure does not involve any element with index 1, the property of the first column remains unchanged.
- Proceed with the same procedure to $p-1$-st column.
- Collect the results.

At the end of the algorithm, we have

```
$R = G_{(1,\rho-1)} \cdots G_{(p-1,1)}G_{(p,1)}.$ (16.13)
```

The matrix $R$ is an upper diagonal matrix by construction. If we denote

```
$Q^T = G_{(1,\rho-1)} \cdots G_{(p-1,1)}G_{(p,1)},$ (16.14)
```

we get

```
$R = Q^TA,$ (16.15)
```

which is the decomposition we were looking for once we will de-transpose the matrix $Q^T$, i.e. by transposing it one more time.
It remains to specify how to find the particular form of the Givens rotation matrix which will make the $(i,j)$ element zero. Let us consider the input matrix $A$, and our objective is to find $G = G(i,j; \theta_{(i,j)})$ such that $\{GA\}_{(i,j)} = 0$. If we recall the form of the matrix $G$ in equation (16.11), we directly write the equation for the $(i,j)$ element to zero:

```
$$\sin(\theta_{(i,j)})a_{(i,i)} + \cos(\theta_{(i,j)})a_{(i,j)} = 0,$$ (16.16)
```

which can be used to find $\theta_{(i,j)}$,

```
$$\theta_{(i,j)} = \arctan\left(-\frac{a_{(i,i)}}{a_{(i,j)}}\right). (16.17)
```

## 16.2.2 QR Algorithm for Eigenvalues

The QR algorithm allows us to find all eigenvalues of a square matrix. It works as follows:

- Initialise $A_0 = A$.
- For $k = 0, 1, 2, \dots$:
- Compute the QR decomposition $A_k = Q_k R_k$.
- Set $A_{k+1} = R_k Q_k$.

The diagonal elements of $R_k$ converge to the eigenvalues of $A$.

## 16.2.3 Inverse Iteration

Let us assume that we are equipped with the knowledge of the complete set of real eigenvalues. Our objective is to find corresponding eigenvectors. We will focus on inverse (power) iteration. The following procedure requires to associate eigenvalue $\lambda'$ to the matrix:

- Calculate the updated vector: $v_{k+1} = (A-\lambda'I)^{-1}v_k$.
- The algorithm proceeds in iterative steps, with $k$ denoting the iteration step, at $k = 0$:
- Normalise vector $v_{k+1}$ by its norm: $v_{k+1} = v_{k+1}/\|v_{k+1}\|$.
- Vector $v_{k+1}$ converges to $v'$.
