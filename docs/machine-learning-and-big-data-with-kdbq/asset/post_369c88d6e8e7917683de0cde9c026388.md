$\Sigma_{u} \otimes (ZZ')^{-1}$. Assuming that $y_i$ is Gaussian, an approximation of a $(1-\alpha)$ interval forecast-step ahead for $k$-th component is $\hat{y}_k(h) \pm z_{\langle\alpha/2\rangle}\hat{\delta}_k(h)$; $\hat{\delta}_k(h)$ is the square root of the $k$-th diagonal element of $\hat{\Sigma}_u(h)$ and $z_{\langle\alpha/2\rangle}$ is the $(\alpha/2)$-th quantile of the normal distribution.

```
$$\hat{\Sigma}_u(h) = \hat{\Sigma}_u(h) + \frac{1}{T}\hat{\Omega}(h)$$
$$\hat{\Omega}(h) = \sum_{i=0}^{T-1}\sum_{j=0}^{h-1}tr((B')^{h-1-i}B^{h-1-j}\hat{\phi}_i'\hat{\phi}_j)$$
```

with $\Gamma=E[Z,Z']$, $\phi_i=J_iB_i'$, $J_i=[O_{kX1} : I_K : O_{kX1} : \dots : O_{kX1}]$ a $K \times (Kp+1)$ matrix.

Choosing an unusually large value of $p$ reduces the forecast precision model. $Y$ is called a VAR(p) process if $A_p \neq 0$ and $A_i=0$ for $i>p$ so that $p$ is the smallest possible order. The likelihood ratio statistic determines the correct VAR order by testing the significance of coefficient $\Lambda_m$ of an upper bound VAR model. The null hypothesis $H^{M-m-1}: A_m=0$ versus the alternative hypothesis $H^{M-m-1}: A_m \neq 0$ is tested for decreasing values of $m \in[M, M-1, \dots]$ conditioned on the previous values being true. If $H_0^{M-m-1}$ is rejected, the order $\hat{p}$ is chosen as the optimal order of the VAR process. The likelihood ratio test for testing the $M-m-1$-th hypothesis solves:

```
$$\lambda_{LR}(M-m-1) = T[\log det(\Sigma_u(m-2)) - \log det(\Sigma_u(m-1))]$$
```

where $T$ is the length of the time series and $\Sigma_u$ is the least square estimator

```
$$\Sigma_u = \frac{1}{T}(Y_T-Z')(ZZ')^{-1}Y.$$
```

The likelihood ratio test $\lambda_{LR}$ follows a $\chi^2$ distribution with $K$ degrees of freedom.

## 14.3.1.3 Example

To illustrate the VAR(p) model, let us model the quarterly seasonally adjusted West German investment, disposable income and consumption expenditures given in file1.csv available on the book website. The data comes from Helmut (2005) and is present on the author's website, http://www.jmulti.de/download/datasets/e1.dat.

```
// store the content of the file in a table
data:(`invest`income`consumption`)!("";"") : `:e1.csv;
// add the dates
data:date xkey update date:date$`month$1960.01.01 + 3*till count date
-- from data;
```

We only take the data from 1960 until 1978 and compute the log-return for the three time series. The data set is a $3 \times 75$ matrix:

```
// compute the log return of the data
```

Figure 14.5 captures the evolution of the Investment (dashed line), disposable income (bold-dashed line), and consumption expenditure (dotted line) between years 1960 and 1978 for West Germany as given by the variable data. The log-return version of the data is presented in Figure 14.6.

We first want to determine the optimal order of the vector autoregressive process for the data set containing three time series: investment (S), disposable income (I), and consumption expenditure (C).

The optimal number of lags is the number $p$ such that parameters $A_i=0, i \in[1, \dots, p]$:

```
$$\hat{v} + \sum_{i=1}^{p} A_i y_{t-i} = \begin{pmatrix} S_{t+p} & I_{t+p} & C_{t+p} \\ S_{t+p-1} & I_{t+p-1} & C_{t+p-1} \\ \vdots & \vdots & \vdots \\ S_t & I_t & C_t \end{pmatrix}$$
```

Given an upper bound $M$, the likelihood ratio test $\lambda_{LR}$ follows a $\chi^2$ distribution with $K$ degrees of freedom. The order $p$ is significant at a 0.05 level if $lr(p) > \chi^2_K(0.05)$. Based on the p-value, the optimal number of lags is 2.
