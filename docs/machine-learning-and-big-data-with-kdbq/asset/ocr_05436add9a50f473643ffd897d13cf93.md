# Linear Regression

Having in the log-likelihood, we can formulate the AIC function:

```
.quantQ.ols.AIC:[p; logL]
// p -- number of parameters
// logl -- log-likelihood
// (2.@*)-2.@*logL;
;
```

The AIC for the example listed in this section gives:

```
.quantQ.ols.AIC[count[beta];.quantQ.ols.logL[count[y];RSS]]
```

-1783.824

As we have mentioned in the paragraphs leading this number, the AIC on its own does not give us any information. We cannot say whether -1783.824 is very small and thus information is small or if it is large and is unacceptable.

The calculation assumes the asymptotic holds, the size of the sample is infinite. This is not true as our sample contains 3 points. In such a case, the offset between the complexity of the model and its accuracy may adequately work. The sample correction for AIC should be considered. In general, this task is complicated and an analytic formula may not be possible to find for any model. Thus, methods like bootstrap are needed to use a numerical correction to AIC.

Fortunately, for the OLS model, or for univariate model linear in parameters, where residuals are normally distributed, the analytic formula works. In this case, the AIC corrected for the small size of the sample, usually denoted as AICc, is defined:

> AICc = AIC + \frac{2p^2 + 2p}{n - p - 1} (13.67)

Several observations are at the place: AICc $	o$ AIC as N $	o \infty$, thus the small sample correction indeed works in the case of the finite sample. Further, the AICc is proportional to $p^2$ and thus can be considered a second-order approximation to the relative information loss in the number of parameters.

The AIC implementation reads:

```
.quantQ.ols.AIC:[n;logL]
// n -- number of parameters
// sample -- sample size
// logl -- log-likelihood
// ..quantQ.ols.AIC[n;logL]+("F$2*(n+n)%%("$sample-1-n)"
;
```

```
.quantQ.ols.AIC[count[beta];count[y];.quantQ.ols.logL[count[y];RSS]]
```

-1783.784
