Then, we proceed directly with the function, which calculates the determinant. In order to illustrate the methods for calculating the determinant discussed in the previous section, we use different methods based on the dimensionality of the problem. In particular, for n=3, we use the Garrus rule explicitly, even if it is not necessary, as the Laplace expansion would be sufficient. For the Laplace expansion, we use recursion. In particular, we use z. s, which refers to the function itself when called from within the function. We could use the name of the function instead of the “dotzetdotes”. The function reads:

```
.quantQ.mat.det:([mat]
// mat - square matrix
// dimension of matrix
dimm count mat;
// split based on the dimension of the problem
// default output value
det:0;
// dim=1;
$dimM1=det:mat;
// dim=2;
$dimM2=det:(mat[0;]*mat[1;1])-(mat[0;]*mat[1;0]);
dim=3. Sarrus rule
$dimM3=

// extend matrix
maze(mat; mat);
// positive diagonal
posDiagonal:sum([mat;dim;offset] prd {[mat;offset;i] mat[i+offset:i]][mat;offset] each til dimM[mat;dimM] each til dimM;
// negative diagonal
negDiagonal:sum([mat;dim;offset] prd {[mat;offset;i] mat[(count-flip mat-i)+offset][mat;offset;]] each til dimM[mat;dimM each til dimM;
// determinant
det:posDiagonal-negDiagonal
];
// dim=3, Laplace expansion, always use first row
[
rowPivot:0;
signFact:(mat[rowPivot;x])exp[neg[1;0];(rowPivot+1+x)]][rowPivot;
 each til dimM;
det sum mat[rowPivot]*signFact*(z.s each quantQ.mat.minorMatrix[
 each rowPivot]; each til dimM);
];
// output determinant
det:;
```
