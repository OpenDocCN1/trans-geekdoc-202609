
## Unsupervised Machine Learning: The Apriori Algorithm

Chapters on Linear Regression, Decision Trees, Random Forests, AdaBoost, Neural Networks and $k\text{-Nearest Neighbours belong to the supervised machine learning family. In such cases, we are equipped with two types of variables in the data set: $x_1, \dots, x_M$, and the $K$-dimensional vector of dependent variables (usually $K=1$). Given the set of $N$ observations of features and corresponding dependent variables, we calibrate the chosen model using both types of data. The relationship between the features and the dependent variable is then learnt.

Our objective for this chapter is to assume that we have only features in our data set. The objective is to understand the relationship between features. This can be formalised as follows. The set of features $x_1,\dots,x_M$ is generated by a joint density function $P(x_1,\dots,x_M)$. The goal is to understand such properties of the distribution function. In this case, there is no supervisor in the data set or loss function, which would assess how correctly the properties of the distribution function have been found.

Further, the objective of the model is to find the link between individual features and the data set. Compared to supervised methods, the unsupervised machine learning algorithms face difficulties in assessing the power of the calibrated model. These heuristic methods are frequently used.

The unsupervised machine learning techniques can be easily solved for a very small number of dimensions as the joint probability function can be directly estimated. On the other hand, this is not possible in large dimensions, and various approximations are used. The favourite examples are for example Gaussian mixtures. We note that the dimensionality of the feature vector is usually much larger than that in the case of supervised learning problems. Further, researchers are trying to find patterns in high-dimensional data with various forms of clustering analysis, principal component analysis (PCA), independent component analysis, or self-organising maps. In this chapter, we focus in detail on another class of algorithms known as association rules. In particular, we discuss and implement the Apriori algorithm.

## 26.1 APRIORI ALGORITHM

The Apriori algorithm introduced by Agrawal et al. (1994) is one of the algorithms within the branch of association rules analysis. The association rules have been traditionally used for data mining to find frequent sets. The popular name for these methods is market basket analysis. The name comes from the following problem. Consider a store which sells M items. For every customer at the counter, we create a record in the database. The entry in the database is an M-dimensional binary variable, $b_1, \dots, b_M$, which indicates which item has been purchased or not.

It is apparent that the joint probability function $P(b_1, \dots, b_M)$ cannot be written as $P(b_1) \cdot \dots \cdot P(b_M)$. The customers tend to buy some goods if it captures their habits. Being able to find regularity in the joint distribution function helps improve sales by positioning goods in the better store and addressing the commercials more efficiently.

The association rules aim to work with subsets of $s_1, \dots, s_k$, where $s_i$ is a set of items of length $i$. The objective of interest is to find $P(s_i)$, which are in reality quite large. This means we do not need to model every combination but rather the significant combinations in the data. If the number of items is large, the problem cannot be solved directly as a number of combinations above reasonable limits.

In the Apriori algorithm, we define all itemsets $S$. An itemset is any combination of items. The cardinality of the set of all itemsets is huge, $2^M$. The objective of the algorithm is to find all items such that given item in the data is frequent, exceeding a given threshold. The advantage of the Apriori algorithm is to find such itemsets without many iterations and being poisoned by the curse of dimensionality.

The frequency of the itemset is defined as the number of observations – rows of the database – when the given item is present – an itemset is a subset of the items of present – divided by the size of the data set. The Apriori algorithm works as:

- * Initialisation: Set a threshold on the frequency of itemsets in the data $\phi$.
- * First iteration: Calculate the frequency of all itemsets containing one item. Keep those that exceed the frequency threshold of $\phi$. Those which do not exceed the threshold are discarded.
- It is important to realise that if a single item does not exceed the frequency threshold, then any combination of items which contains the low-frequency item cannot exceed the threshold.
- * Second iteration: Form all itemsets containing 2 items. Consider only those single items that have passed the first iteration. Calculate the frequency of all such 2-item itemsets and consider those which exceed the threshold, then discard the rest.
- * Third iteration: Form all itemsets containing 3 items. Consider only those 3-item itemsets which are composed of single items from the first iteration and where all 2 itemsets are present in the second step. Discard the rest.
- * General step of iteration: Form all n-item steps, where every subset of the chosen n-item step passed the previous steps. Keep only those n-item steps whose frequency exceeds the threshold; discard the rest.
- * Stopping rule: Stop when none of the n-item steps has exceeded the frequency threshold. Report all itemsets which exceeded the frequency threshold in any of the previous steps.

The algorithm itself resembles a technique of searching through the tree where all possible combinations have been expressed as a tree structure. The root node contains all zero items, the first level of the tree contains all 1-item items, the second level of the tree contains 2-item items, and every node has an assigned frequency. The algorithm seeks all items with a frequency exceeding the threshold of $\phi$.

The Apriori algorithm is the equivalent to a breadth-first search algorithm through the tree. The breadth-first algorithm is exploring the tree by level and then rejects the entire subtrees from infrequent nodes.

The advantage of the algorithm is that it can report all relevant itemsets within a few iterations. Every iteration corresponds to a pass over data. Thus, the method can be used for long data sets that fit into memory and calculation to be done sequentially. This will not be true if the threshold is low. If we are facing a time budget, we can modify the algorithm to build several instances of the Apriori algorithm at once, with a different threshold. When the time budget lapses, instances of the algorithm which finished can be reported for further analysis.

The algorithm itself is straightforward and intuitive. It represents a powerful tool for data mining. In the next section, we implement the algorithm and illustrate it on a synthetic example. We encourage the reader to stretch the limits of the algorithm and investigate its performance on bigger sets, preferably not using in-memory.
