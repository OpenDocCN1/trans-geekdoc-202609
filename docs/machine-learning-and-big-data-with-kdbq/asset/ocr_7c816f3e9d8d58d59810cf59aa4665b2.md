Once kdb+ is running, we will see the prompt

q)

This prompt indicates that the q interpreter is awaiting our first commands. From now
on on, we shall assume that we are always in an open q session and therefore shall omit
the prompt (q) from our listings.

Let us experiment with the q language by typing in the expression

```
1+1
```

We shall see the output

```
2
```

We have just evaluated our first q expression!
Any introduction to a programming language requires the presence of a "hello
world" example. We create a script file, named helloWorld.q in the directory
 we have launched our q session. The file contains the following line:

```
show "hello world!"
```

From the q session, we launch the script with system command \1:

```
\1 helloWorld.q
```

produces the output:

```
"hello world!"
```

The system command \1 loads the file helloWorld.q, which applies the show function
to its argument, the string "hello world!". The show function outputs its
to the console.

To close the q session, we enter at the prompt the system command

```
\\
```
