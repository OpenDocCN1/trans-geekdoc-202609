# Fourier Transform

Analogously to complex numbers, we may define the norm of the quaternion or its modulus. The norm corresponds to the geometric interpretation of the quaternion as a vector in a four-dimensional space:

```
.quantQ.complex.norm:{ sqrt x wsum };
```

The norm of the quaternion quat2 is defined as $L_2$-norm:

```
$|q| = |a + bi + cj + dk| = \sqrt{a^2 + b^2 + c^2 + d^2},
```

and implemented in the following function:

```
.quantQ.quat.norm[quat2]
```

The conjugate of the quaternion is similar to what we have defined for complex numbers:

```
$q^* = (a + bi + cj + dk)^* = a - bi - cj - dk$.
```

The conjugate can be expressed through addition and multiplication:

```
$q^* = -\frac{1}{2}(q + iq + jq + kkq).
```

The conjugate can also be used to define the norm introduced previously:

```
$|q| = \sqrt{qq^*}$.
```

The implementation then follows as:

```
.quantQ.quat.conjugate:{@x;'j`'k;neg];
```

and its functionality on the quaternion with all the coefficients equal to 1 reads:

```
.quantQ.quat.conjugate[quat2]
```

Quaternions also have a notion of polar decomposition. The polar decomposition means that we rewrite the quaternion q as pair of two numbers ($|q|$, $ar{q}$), where $|q|$ is a norm of the quaternion and $ar{q}$ is a unit quaternion given as:

```
$ar{q} = \frac{q}{|q|}$
```

The polar decomposition thus does not correspond to a radius and polar angles, yet is still useful when we interpret quaternions as vectors and are interested in linear dependence.
