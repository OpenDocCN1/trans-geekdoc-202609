getHistogram wraps the binr verb. It accepts a vector of numbers and a function which creates the bins. There are a number of options on how to create the bins, and we list a few below. We implement each option as a function which takes one or more arguments. The last argument is the data while all but are optional parameters whose meaning depends on the binning scheme. When we call getHistogram, we specify all arguments except for the last and thus pass in the projected binning scheme.

A few implementations of bucketing schemes:

## Grid

We specify the grid for binning explicitly. In such a case, the optional parameter is the grid for binning itself. The data will not be taking any role:

```q
/quantQ.stats.histGrid:[bins;data]
// bins -- explicit bins to use
// data -- array of data (not used)
// return bins
//bins;
```

## Width

We specify the width of the binning explicitly. The bins are then derived from the range of the data. The argument of the function is the h:

```q
/quantQ.stats.histWidth:[h;data]
// h -- width of bin
// data -- array of data
// return bins
//min[data]+h*til 1+ceil((max[data]-min[data])%h);
```

## Bins

We specify the number of equidistant bins n we want to plot. Since the function binr is considering semi-closed intervals, closed on the right, the number of bins created will be in fact n+1, with elements equal to min of the data falling into first bin:

```q
/quantQ.stats.histBin:[n;data]
// n -- number of bins
// data -- array of data
// return bins
//min[data]+((max[data]-min[data])%n)*til 1+n;
```

## Square root

The number of bins is derived from the size of the sample using the square-root formula:

$$n = \sqrt{N},$$ (12.1)

where [x] denotes the smallest integer larger than x, and is implemented as:

```q
.quantQ.stats.histSquareRoot::[data]
// data -- array of data
// number of bins
:ceiling sqrt count data;
// return bins
:min[data]+((max[data]-min[data])%n)*til 1+;
;
```

## Sturge's formula

The number of bins is derived from the binomial distribution and provides reasonable histograms for large sizes and approximately normally distributed. The formula for number of bins reads:

$$n = 1 + [\log_2 N],$$ (12.2)

implemented as:

```q
.quantQ.stats.histSturge::[data]
// data -- array of data
// number of bins
:n+ceiling log[2;count data];n// return bins
:min[data]+((max[data]-min[data])%n)*til 1+;
;
```

## Rice's rule

Similar to Sturge's formula can be achieved by Rice's formula, where number of bins is given as:

$$n = [N^{1/3}],$$ (12.3)

Function reads:

```q
.quantQ.stats.histRice::[data]
// data -- array of data
// number of bins
:ceiling 2*exp count data;1.0%3.0;
// return bins
:min[data]+((max[data]-min[data])%n)*til 1+;
;
```

## Scott’s rule

The final formula we implement is Scott’s rule for normally distributed data, where the width of bins depends on the estimated sample variance $\sigma^2$:

$$h = \frac{3.5\sigma}{N^{1/3}}, \quad (12.4)$$

where we further derive the number of bins from its width and range of the data in the same way as for histWidth function:

```q
quant.stats.histScott::[[data]
// data array of data
// width of bins
h:ceiling(3.5+dev data)%exp[count data;1.0%3.0];
// return bins
:min[data]+h*til 1+ceil((max[data]-min[data])%h);
```

## 2.2 FIRST MOMENTS

Let us define a useful utility function, which for a given numerical array returns a table with overview statistics. First, we define statistics within itself and then implement it as one compact state. Data are denoted as $(x_1, x_2, \dots, x_K)$, where subset of $N \le K$ observations are non-missing $x_1, x_2, \dots, x_N$.

### Sample mean

The sample mean is defined as:

$$\mu = \frac{1}{N} \sum_{i=1}^{N} x_i. \quad (12.5)$$

### Sample standard deviation

The sample standard deviation is defined as:

$$\sigma = \frac{1}{N-1} \sqrt{\frac{1}{N} \sum_{i=1}^{N} (x_i - \mu)^2. \quad (12.6)$$

### Sample skewness

The sample skewness is defined as:

$$S = \frac{\sqrt{N(N-1)}}{N-1} \frac{\frac{1}{N} \sum_{i=1}^{N} (x_i - \mu)^3}{\frac{1}{N-1} \sum_{i=1}^{N} (x_i - \mu)^2}. \quad (12.7)$$

where for distributions that are unimodal and not heavily suggests that distribution with negative skew is skewed to the left while positive skew is skewed to the right. For heavy-tailed distribution, the rule cannot be used.

### Sample kurtosis

The sample kurtosis is defined as:

$$K = \frac{\frac{1}{N} \sum_{i=1}^{N} (x_i - \mu)^4}{\frac{1}{N-1} \sum_{i=1}^{N} (x_i - \mu)^2}. \quad (12.8)$$

and can be used to assess the heavy tails of the data. If the value is positive, the data are said to be leptokurtic, i.e. heavy-tailed relative to Gaussian distributions, while if value is negative, the data are said to be platykurtic, i.e. thin-tailed relative to Gaussian distribution.
