Just like a, a window can be used with more than one column to join on, i.e.
b beside the time column, the sym and/or other columns can be specified. In such
case, the symbols should be used with a parted attribute, i.e. we to apply p#*

Let us use the symbol attribute to the dataSet1 and dataSet2 tables, without
assigning any attribute to the symbol:

```
dataSet1: update sym: 100?(`sym`2`sym3) from dataSet1
dSet2: update sym: 10000(`sym`2`sym3) from dataSet2
```
