# Basic Overview of Statistics

For every realisation of the test, we check whether there is at least one case with
p-value below or equal to the confidence level chosen, 0.05. We record the number of
realisations when at least one of the features shows statistical dependence:

```
sum {0.05>=min x} each pValues
```

In 41.3% of cases, we detect features which are significantly connected to the depen-\dent variable. This is, likely we receive false results significantly many more
times than the significance level we would suggest. Ten features are far from what is usually
ceived as a large number, and still, it may lead to a false conclusion quite!
Let us repeat the test while making the Bonferroni correction:

```
sum {.quantQ.stats.pBonferroni[0.05;10]>=min x} each pValues
```

leads to 15 cases, or 0.15% cases in relative terms when a significant feature has
been identified.
Sidak’s correction is performed anonymously:

```
sum {.quantQ.stats.pSidak[0.05;10]>=min x} each pValues
```

and to the same number of cases when a significant feature has been observed.
Finally, Holm’s method has a different functional form to apply, but is still very
straightforward:

```
sum {<count .quantQ.pHolm[x;0.05]} each pValues
```

The number of cases where a significant feature has been detected is the same.
The same results across the three methods is a consequence of our map between
t-stats and the corresponding p-value. Our implementation through the lookup table
is not granular enough to distinguish the nuances that are experienced in the cur-
ent rate. Nevertheless, all three methods significantly suppress the Type-I error and
lead to the correct conclusion more. We encourage readers to employ a more fine
resolution of the map between t-statistic and p-values and thus confirm the difference
bween the methods. Finally, we encourage readers to explore other ways of applying
the problem and observing different outcomes in the three methods.
