Note that wj aggregates data over the time window using the prevailing value as of the start of each window. There is another version of the "window join" function, wji, which aggregates over the strict window [low;high]; So including the observation before the beginning of the window can be avoided by using wji. If there is no observation in the window, wj returns an empty list. On the other hand, wj always returns a list with at least one observation - except the beginning of the data set.
