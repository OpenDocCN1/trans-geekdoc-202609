# 4.1.3 MA(q) Process

Autoregressive processes are long memory models. They generally have an infinite non-zero autocorrelation decaying over time. Autoregressive processes cannot represent short memory, where the current value of the series $X_t$ is only correlated with a few past values $X_{t-1}$. This section presents moving average processes that are generally a short-memory process of order $q$, denoted as MA(q), is defined as:

$X_t = c + \epsilon_t + \alpha_1\epsilon_{t-1} + \alpha_2\epsilon_{t-2} + \dots + \alpha_q\epsilon_{t-q}$,

where $\alpha_1, \alpha_2,\dots, \alpha_q$ are the coefficients of the process, $c$ and $\epsilon$ is white noise, $\epsilon_i \sim N(0,\sigma^2)$. The MA(q) process is stationary by construction. Its expectation is $E[X_t]$ and variance is $Var[X_t] = \gamma(0) = \sigma^2(1 + \alpha_1^2 + \alpha_2^2 + \dots + \alpha_q^2)$.

The autocorrelation $\gamma(s) = \frac{1}{\gamma(0)}\sigma^2(\alpha_s + \alpha_{s+1}\alpha_1 + \alpha_{s+2}\alpha_2 + \dots + \alpha_q\alpha_{q-s})$ for $s \leq q$, that $X_t$ is a zero-mean process with finite variance for each $t$ and $E[X_tX_j] = \gamma(i,j)$, where $|i-j|=n$ is non-singular for each $n=1,2,\dots$

The one-step predictor of the $MA(q)$ process is given by:

$$\hat{X}_{n+1} = \begin{cases} 0 & n=0 \\ \sum_{j=1}^{n} \hat{\alpha}_j(X_{n+1-j} - \hat{X}_{n+1-j}) & n \ge 1 \end{cases}$$

The one-step predictors $\hat{X}_1, \hat{X}_2, ...$ can be computed recursively over the coefficients $\hat{\alpha}_{ij}$ have been determined by the innovations algorithm (14.14).

While the Durbin-Levinson algorithm gives the estimates of the coefficients in the representation:

where $\hat{\alpha}_{pj}, j=1, ..., p$ are the parameters of the model, the innovations algorithm used to estimate the parameters of the $MA(q)$ process (14.13) considers the representation:

for $q=1, 2, ...$ and $\hat{\sigma}_q^2 = \hat{Y}(0) - \sum_{j=0}^{q-1} \hat{\alpha}_{q,j}^2$.

for $q=1, 2, ...$ and $\hat{\sigma}_q^2 = \hat{Y}(0) - \sum_{j=0}^{q-1} \hat{\alpha}_{q,j}^2$.

# ## 4.1.4 ARMA(p, q) Process

The long memory $AR(p)$ model can be combined with the short memory $MA(q)$ process to produce a new family of tractable and flexible stationary processes called The autoregressive moving average $ARMA(p,q)$ refers to the model with $p$ autoregressive terms and $q$ moving average terms:

```
$X_t = c + \sum_{i=1}^{p} \Phi_i X_{t-i} + \sum_{i=1}^{q} \alpha_i \epsilon_{t-i}, \quad (14.15)$
