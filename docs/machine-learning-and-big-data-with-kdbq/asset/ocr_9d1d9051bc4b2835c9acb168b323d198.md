# DATA OPERATIONS

The algorithm described in the previous display is executed as follows. First, create a list of windows:

```
winForJoin: (neg winTWAP;00:00:00) \:(exec time from data);
```

then, create table with extra variables for join:

```
dataForJoin: select time, timeWin:time, valWin:val from data;
```

perform aggregation with two lambdas for time and val variables, respectively:

```
dataJoin: wj {winForJoin; time; data;
  (select time, timeWin:time, valWin:val from data);
  (1_deltas[x]; timeWin); (-1_x; valWin) );
```

The output table dataJoin is large and does not fit on the page. This table at hand, we can perform the weighted average of valWin using the timeWin as weights. This can be achieved:

```
dataJoin: update twwap: timeWin wav' valWin from dataJoin;
select time, val, twwap from dataJoin
```

The output contains the column twwap, which denotes the approximate TWAP according to the prescribed algorithm.

We have started this exercise by claiming that the TWAP serves as a filter with mean zero. We demonstrate this by calculating the two moments of val and valWin:

```
exec meanVal: avg val, sdVal: dev val from dataJoin;
```
