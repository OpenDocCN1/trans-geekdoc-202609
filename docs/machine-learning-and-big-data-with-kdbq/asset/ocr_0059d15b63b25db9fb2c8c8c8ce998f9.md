We can now use the wavg function to implement the WMID formula:

```
select sym,time, wmid: ( bidSize1; bidSize2; ask1; askSize ) wavg (
  bid1; bid2; ask1; ask2)
```

We feel the benefit of wavg, which allows us to work in-depth with a vectorised approach across multiple (in this case 2 dimensions)!

Note that in this case - our approach is much faster than using an iterative approach, each-each, on each record. To demonstrate this, we time the two approaches after expanding our table to a more “realistic” of 10 million records:

```
q:1000000quote; // 'take' 10 records from quote table (this will
  repeatedly expand the table)
```
