# Outlier Detection

Outlier detection, or anomaly detection, is a data science technique aiming to identify observations which do not fit into the data set and are way too different from the “normal” data. In general, there are two reasons why such nonconformity in the data may exist. First, the anomalous data points can be produced by some technical error, where, for, the data recording technique failed, or the survey has not been correctly scanned, among others. A particular example can be limit order book data, where bid price is recorded as –999. Such a datum corresponds to a failed prater than to a situation where the technically possible in the particular case is negative. Such a transaction would not be technically possible in properly working venues.

Second, the more critical reason corresponds to actual anomalous behaviour in the data. This may correspond, for example, to cases of bank frauds which commit the unlawful act, often tries to make the transaction look unusual. However, it is not possible as the knowledge of transactions is not publicly available. The outliers may appear in the data analysis as records with the unusual size of the transaction, timing of trades, or their frequency do not fit into the common patterns.

The outlier detection is by its nature a data science technique, where the objective being “outlier” is rather vaguely defined. It is without surprise that outlier detection technique mimics the machine learning techniques. The non-supervised outlier detection works with unlabelled data. The majority of data is assumed to be valid, and the property of being an outlier is understood to the majority. Such a method can be illustrated by a PCA technique for dimensionality reduction. The reduced set of components replaces the data. Then, every observation recorded back from the reduced set, and the error of the reduction is recorded. The outliers are then observations with significant errors.

The supervised outlier detection assume assume that we have a labelled set, where data are labelled as “normal” or “ outlier”. One can then formulate a model, either theoretical or econometric, for “being outlier” and estimate the parameters. The typical choice can be a logistic regression model, which is well suited for modelling binary dependent variables. The usual problem for such techniques rests in the need for correct classification and presence of outliers, which are often very rare.
