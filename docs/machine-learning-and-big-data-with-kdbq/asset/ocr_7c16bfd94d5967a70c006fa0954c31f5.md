Multivalent functions can be projected by specifying only part of the parameters of the functions while keeping the remaining arguments. Projection is related to currying in functional programming. A function of n parameters is equivalent to a function of the first parameter that returns the function of the n-1 parameters.

A monadic function – frequently referred to as unary function – g can be a projection of a dyadic function – binary function – f by fixing only its first argument:

```
f:{x+y};
g:f[4]; // projection on f where x takes the value 4: {x+y}[4];
```

# 3.1 NAMESPACE

A namespace is a context within which a name resolves to a unique value. Functions and variables are defined in a namespace as follows:

```
.namespaceName.variableName
```

Hence the variable x and function f defined in namespace1 and namespace2 have different values:

```
.namespace1.x:4f;
.namespace1.f:{5+x};
.namespace2.x:5;
.namespace2.f:{1f+log x};
```

> We can call f from the two different contexts as follows:

```
.namespace2.f[.namespace1.x] // returns 1f+log 4f
```
