# 16.3.1 QR Decomposition

Let us proceed with the QR decomposition. Function QRdecomp implements the procedure. The input is the matrix we wish to decompose. The outcome of the function is three matrices: the original matrix, the rotated matrix, and the rotation matrix. The function itself iterative procedure, we iterate over all coordinates that need to be set to zero. We kept the iteration within the main function and not separated it. The reason it is important to run the function as defined. We stressed that in the description of the algorithm.

```
quantQ.mat.QRdecomp:[mat]
// input matrix
// calculate dimension of the matrix
dimM:count[mat]
// list of coordinates to iterate over
coord: range[[dimM;x]] {{x;y] (y;x)}'[t where x<t:reverse til dimM]][dimM]; each til dimM;
// inputmatrix
inputMat:mat;
// initialised rotation matrix
rotMat::quantQ.mat.diagMatrix[dimM]
// counter for bucket
counter:;
```
