Using the $R^2$, or better, the adjusted $R^2$ is one possible way to do so. Instead of comparing two numbers without any statistical insight, we can formulate a proper statistical test on the same features as $R^2$, which allows us to choose between two models. The way to do so is to use the $F$-statistic.

The $F$-statistic is a statistic to decide whether the nested model – indexed with 1 - brings a significant improvement in terms of the explained variance relative to the basic model – indexed with 2. The statistics are defined in terms of the difference between these two variances as:

```
$F = \frac{RSS_1 - RSS_2}{RSS_2 - P_1}, \quad (13.68)$
```

where $RSS_1$ is the residual sum of squares of the nested model, $RSS_2$ is the same quantity for the basic model from which the nested model was derived, and $p_1, p_2$ stands for the number of degrees of freedom including the constant for the nested and the basic models, respectively. Further, it holds that $p_1 < p_2$.

The $F$-statistic follows the $F$-distribution with $(p_2 - p_1, n - p_2)$ degrees of freedom, or:

```
$F \sim F_{(p_2-p_1,n-p_2)} \quad (13.69)$
```

The test works as follows. We start with the basic specification and estimate the properties of the model. We then consider the extension of the model adding one or more independent variables into the regression specification and run the estimation procedure. Finally, we calculate the $F$-statistic and test the following hypothesis:

+   $H_0$: The null hypothesis states that the nested model is not worse than the basic model in terms of the unexplained variance, or, $RSS = RSS_2$.$
$H_1$: The alternative hypothesis states that the basic model is an improvement relative to the nested model and decreases the unexplained variance, $RSS_1 > RSS_2$.

The null hypothesis $H_0$ is rejected at significance level $\alpha$ when $F > F(p_2 - p_1, n - p_2)$, where critical values are to be determined from statistical tables. We reject the null hypothesis, the alternative hypothesis can be accepted as a result of the test.
