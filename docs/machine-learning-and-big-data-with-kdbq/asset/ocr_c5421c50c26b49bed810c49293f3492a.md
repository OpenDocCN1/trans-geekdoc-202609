We further utilise the structure of the table tabDataMODEL. In particular, let us create a function which calculates the root-mean-squared error, or RMSE, between the true and the predicted values. The *RMSE* is defined as:

> $RMSE = \sqrt{rac{1}{N}\sum_{i=1}^{N}(y_i - y_{predicted})^2}, \quad (13.70)$

where $y_i$ stands for the value of the dependent variable, $y_{predicted}$, and there are altogether $N$ observations.
The root-mean-squared error is a popular method to compare the predicted values to true ones. There is a number of alternatives in the literature, e.g. mean absolute error (MAE), which employs the sum of absolute values rather than the sum of squares and square root. The reason for this stems from the sensitivity of *RMSE* to outliers, which are amplified by the squares present in the equation.

The *RMSE* is implemented as a function, which assumes the first two columns in an input table are the relevant ones. In fact, due to the square and square root, the order of true and predicted variables does not matter. Further, the columns beyond the second one are not considered. The function reads

```
quantO ls.RMSE[:tabModel]
// tabModel -- table where first column is true dependent variable and
  -- second is the estimated one
  sqrt t wavg t:tabModel[cols[tabModel]]-tabModel[cols[tabModel][1]];
```
