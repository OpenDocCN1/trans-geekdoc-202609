We start with the quadratic function iteration using the over adverb (/) and exit the iteration if the norm is less than 2.

```
.quantQ.complex.fractal::[cx]
// cx complex offset
// iterate z_n+1=(z_n+2) c and exit if the norm converges or hits max
// number of iterations
::[c;list]
newp::quantQ.complex.mult[p;p:first list] + c;
if(50<i:list or 2<quantQ.complex.norm newp::list];
(newp::1+i)
];cx][/`re'im! 0@ 0];);
```

The addition of a cap of 50 on a maximum number of iterations for the case where the norm does not converge. We encourage the reader to generalise the function such that bound on the norm and the maximum size of the list entry for such parameters, preferably through a dictionary.

We write wrapper functions which will re-centre our screen and return an output of 1b or 0b, depending on whether the norm converges for particular pair of pixels on our screen. The value for z_0 is (0,0):

```

// p starting point for iteration
// r real part
// i imaginary part
`rowcol!res!(r;i50<last quantQ.complex.fractal[`re'im!(r;i))`
```
