# 22.1.4 Overfitting

Neural networks are prone to overfit the model. They potentially contain a large number of parameters and fully connected networks need to adapt to the data too much. A popular choice is weight decay, where the function Loss(Y,X;Θ) contains equivalent penalty to the magnitude of the parameters of the model.

```
$Loss(Y,X;\Theta) \rightarrow Loss(Y,X;\Theta) + \rho \left(\sum_{ln}\rho_n^{(i)}}^2 + \sum_{mm}\alpha_m^{(n)}}^2\right), \quad (22.21)$
```

with $ho$ driving the regularisation.

Another popular method is dropout, Srivastava et al. (2014). The dropout is so equivalent to ridge regression and all faults. At every iteration step, we select which nodes will be updated according to a predetermined probability $p$ (this is a parameter of the regularisation analogous to $ho$ in the preceding paragraph). The nodes which have not been selected are physically removed from the network with all the connections and are not updated during the given iteration. After the iteration, the updated nodes are merged with the nodes which have been excluded.

Further, excluding the node from training means we lose some information and tend to emphasise the effect of the nodes which have been preserved. This means that we have to weigh the output of all nodes at the end by probability $p$. This will create a fully connected network with all the nodes included in the training situation.

Additional to regularisation, with $p=0.5$, we can reduce the number of parameters to half, which may significantly speed up the calibration. Dropout technique is both a regularisation method as well as a speed-up improvement and is gaining popularity in the machine learning community, especially for complex networks.
