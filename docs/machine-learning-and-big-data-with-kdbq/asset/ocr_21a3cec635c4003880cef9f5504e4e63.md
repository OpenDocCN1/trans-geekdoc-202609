# 29.3 CONCLUSION

We can thus conclude that q is flexible enough to create and simulate agent-based com- putational models. The model presented in this section is straightforward and simple. It lacks any object-oriented approach, which is so popular among the agent-based mod-elling community. Typically, the agents are objects as the links between agents. See for example a C++ based library Zarja zar, which defines agents and links between agents as objects, whose properties can be defined in a modular way.

In our approach, we have instead aimed for a demonstration of the possibility to approach the agent-based models in addition to time series analysis connected to q.
