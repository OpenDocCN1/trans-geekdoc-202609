At the end of the MCTS run, we have to decide which move is to be made. In order to choose the child node of the game tree built upon, we evaluate the average outcome for subtrees by the child nodes. We choose the node which has the highest average for the player who makes the turn. If there is more than one node with the highest score, we choose one randomly.

We implement the outcome of the game from Player 1's perspective. Thus, we are going to decide which node to choose, or the minimum average value when Player 2 is on the move: $[isOnMove;...max[tab w];...min[tab w]]. This ensures consistency for both players and utilises the game tree developed so far.

The function evaluateMCTS takes as game tree and returns the nodes chosen for a player to make:

```
quantO.mcts.evaluateMCTS::[[tab]
// tab table with treeMCTS
// decide who is on it affects perspective
isOnMove:1+mod[count [movesState];2];
// convertWinner to numerical value
tab: update w: ?[(isWinner-1) and isWinner<3;1;[(not isWinner=1) and
    - isWinner(3;0;0.5)] from tab];
// evaluate each possible move - take the one with best average
value
tab:select avg w by gameTree from select each gameTree, w from
    tab;
// return one of the best moves
:first $[isOnMove=1;1exec gameTree from (!tab) where w=max[tab w];1
    - exec gameTree
    from (!tab) where w=min[tab w]];
```
