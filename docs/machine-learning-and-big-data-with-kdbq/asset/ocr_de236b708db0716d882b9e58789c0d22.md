The value we have obtained is not saying much when it stands isolated. We need some anchor to judge the RMSE value and how the model performs out-of-sample. The possible application is to run the estimation for two more sets, which will be by the independent variables included in the model. In order to do that, we implement an estimation suite, which takes three arguments: the dependent variable, the matrix of independent variables, and the flag which determines the in- and out-of-sample splitting is:
quantQ.ols.out:(y;x;inFlag)
 // y array of dependent variables
 // array of arrays of independent variables, constants has to be
 // included
 // inFlag: raze/atom to form/in sample, 1=out
whereMissing: raze (where y<=0); raze (where x<=0) each x;
 // remove the missing values
y:y[(till count y) except whereMissing];
x[[:whereMissing]] x(till count x) except whereMissing]]
 each x;
 // inFlag is atom, is in randomly chosen inFlag fraction of
 sample
if(1=count[inFlag]);
 // split sample: OUT
xOUT:flip ceiling[inFlag+count y] - flip x;
yOUT:ceiling[inFlag+count y] - y;
 // split sample: IN
x:flip ceiling[inFlag+count y]*flip x;
y:ceiling[inFlag+count y]w=my
];
 // inFlag is Boolean array with 1b being In/0 Out
if(1=count[inOutFlag]);
inOutFlag:in(till count x) except whereMissing);
 // split sample: OUT
yOUT:y where inOutFlag;
x:flip flip[x] where inOutFlag;
 // split sample: IN
y:y where not inOutFlag;
x:flip flip[x] where not inOutFlag
];
 // IN sample regression
IN:quantQ.ols.fit(y;x);
 // OUT sample prediction
yPRED:sum regIN[beta]*xOUT;
RMSE: sqrt avg t:t:yOUT-yPRED;
regOUT:('RMSE
ObservationsOUT)!(RMSE;count[yOUT]);
 // output bucket
bucket:regIN,regOUT;
:bucket;
