- accuracy - the proportion of true cases among the total number of cases tested.
- recall - proportion of true positives to number of true cases with y = 1.
- precision - proportion of true positives to number of cases predicted as ŷ = 1.
- specificity - proportion of true negatives to number of true cases with y = -1.
- F1score - harmonic average of precision and recall.

The function is implemented as follows:

```
quantq.ada.adaPredictionStats::[tabAdaAdaPrediction
// tabAdaPrediction - output of .quantq.ada.adaBoostPrediction function
truePositive:sum (tabAdaPrediction[`y`]=tabAdaPrediction[`prediction`])
  and (tabAdaPrediction[`y`]=1);
trueNegative:sum (tabAdaPrediction[`y`]=tabAdaPrediction[`prediction`])
  and (tabAdaPrediction[`y`]=-1);
falsePositive:sum (tabAdaPrediction[`y`]=1) and (tabAdaPrediction[
  and `prediction`]=-1);
falseNegative:sum (tabAdaPrediction[`y`]=-1) and (tabAdaPrediction[
  and `prediction`]=1);
accuracy(`$truePositive+trueNegative`)*%f`($count tabAdaPrediction;
recall:(`$truePositive`)*%f`($truePositive+falsePositive);
precision:(`$truePositive`)*%f`($truePositive+falseNegative);
specificity:(`$trueNegative`)*%f`($falsePositive+trueNegative);
F1score:2.0::((1.0%%recall)%(1.0%%precision));
// output is dictionary with all measures
:truePositive`trueNegative`falsePositive`falseNegative`accuracy`recall`
  and precision`specificity
F1score:(truePositive;trueNegative;falsePositive;falseNegative;
  and accuracy;recall;
precision;specificity;F1score);
```

### 23.5 RECOMMENDATION FOR READERS

We suggest several extensions for readers:

- **Random feature** – The implementation of the AdaBoost algorithm selects features randomly. It would be more optimal to select the best feature, using the same criteria as is used for threshold selection. 
- **Meta-parameter selection** – The number of weak classifiers, $L_{AdaB}$, is chosen by the user. This may not necessarily provide the optimal number, overfitting may be encountered. The cross-validation is a possible technique which can be used to find an optimal value for $L_{AdaB}$; AdaBoost can be wrapped into the cross-validation utility, which will split the sample into parts and verify out-of-sample.
- **Subsampling** – The data set can be split into batches, and each weak classifier can be trained on the different batch. This will strengthen the power of the technique.
- **Regression** – The provided method is for binary classification only, The AdaBoost technique can be well-defined for regressions as well. Current functions can thus extended for regressions and encourage readers to master their machine learning skills.

## CHAPTER 24 Trees

In Chapter 23, we have introduced the notion of decision stumps and their use within the AdaBoost algorithm. A decision stump is the simplest example of a decision tree. In this chapter, we will cover decision trees in more detail; see Morgan and Quin (1963) for illustration of this direction, or Breiman et al. (1984) and Loh (2011). We present methods for both classification and regression. We start with a theoretical introduction and proceed with an implementation in q. The functions we will use to represent trees are based on the concept of trees first introduced by Steiner; see Quin (2010).

### 24.1 INTRODUCTION TO TREES

Let us consider a feature space spanned over the features $x_1, \dots, x_N$. Tree-based methods partition the space into rectangle-shaped domains and then assign a model to each domain. The simple model is usually constant and fits observations belonging to the given domain. This corresponds to CART or Classification and Regression Tree. Figure 24.1 illustrates partitioning for a case of $N=2$, where $x_i \in [-1,1]$ for $i=1,2$. We have produced this partitioning using the following code:

```
//grid
xGrid: -1..1;
xyGrid: xGrid cross xGrid;
// table
tab2D: flip 'x' 'y' flip xyGrid;
// fills
tab2D: update y1 from tab2D where x<=0.5, y<-0.2;
tab2D: update y2 from tab2D where x<=0.5, y<=-0.2;
tab2D: update y3 from tab2D where x<=0.5, x<-0.1,y<=0;
tab2D: update y4 from tab2D where x<=0.5, x<-0.1,y<=0;
tab2D: update y5 from tab2D where x<-0.1, x<-0.8;
tab2D: update y6 from tab2D where x<=-0.8,y<-0.7;
tab2D: update y7 from tab2D where x<=-0.8,y<-0.7;
```

where the shade of grey in the figure is increasing with the index of y.

Let us further assume that we are in fact solving a regression problem, where we have two features $x_1,x_2$, both defined in $[-1,1]^2$, and one dependent variable $y$, i.e. the model for the data looks like:

$y = f(x_1, x_2). \quad (24.1)$

We can use the tree structure built in the previous paragraph to model $y$ as a function of $x_1,x_2$. The regression model is such that we approximate the true function in every domain by a constant $c_i$:

$\hat{y} = \hat{f}(x_1, x_2) = \sum_{i=1}^{7} c_i 1((x_1,x_2) \in \text{domain}_i). \quad (24.2)$

where $1()$ is the indicator function used to model the tree domains.
