We use our q sample implementation by creating a function which can classify a real of values into distinct integer values. This will enable us to fit a classification where our sampled predicted variable takes values k=0,...,K-1 using 0 as the first class, in line with q's natural indexing.

```
quantQ.trees.classifier:[breakpoints;y] asc[breakpoints] binr y;
```

For our loss, we choose to implement a function which calculates entropy according to the formula we generate:

```
quantQ.trees::{{y;classes}}
// y -- vector of sampled predicted variable
// classes -- domain we wish to classify y, the distinct classes
p:(sum(x%y)%count x)[y]each classes;
neg p wsumum x 2 log p;
};
```

Information gain for a given classification in each split is given by:

```
quantQ.trees.info:{{yp;split;classes}}
// yp -- the parent node classification set of attributes
// split -- the node classifications set of attributes after the
-- split
// classes -- the set of classes
uncond: .quantQ.trees.entropy[yp][classes];
cond:(wsum). flip([count[y]%count x)[yp];quantQ.trees.entropy[
:classes])@\:ysplit;
:uncond -- cond;
};
```

Let us validate these definitions with a few intuitive examples. The entropy of a sample from 0 1 2 containing only 1's is 0:

```
0=.quantQ.trees.entropy[1 1 1;0 1 2]
```
