# Eigensystem and PCA

+   - Start with the last, indexed with $p$. Find Givens rotation $G_{(p,1)} = G(p; \theta_{(p,1)})$,
which zeros the $(p,1)$ element of matrix $A$: $\{G_{(p,1)}A_{(p,1)} = 0$.
- Take the outcome of the previous step and find a Givens rotation $G_{(p-1,1)}$ (we use
compact notation from now onwards), which zeros the $(p-1, 1)$ element of the
rix. $\{G_{(p-1,1)}G_{(p,1)}A_{(p,1)} = 0$. By nature of the Givens rotation matrix,
it will hold $\{G_{(p-1,1)}G_{(p,1)}A_{(p,1)} = 0$.
- Proceeded until the $(2,1)$ element. At this end of this step, we have a matrix
where the first column has all elements but the diagonal is equal to zero.
- Proceed with the second column and third column rotations that zeros elements
$(p,2), \dots, (p-2)$ are zero, starting with $(p,2)$ element. Since this procedure does
not involve any element with index 1, the property of the first column remains
unchanged.
- Proceed with the same procedure to $p-1$-st column.
- Collect the results.

At the end of the algorithm, we have

```
$R = G_{(1,\rho-1)} \cdots G_{(p-1,1)}G_{(p,1)}.$ (16.13)
```

The matrix $R$ is an upper diagonal matrix by construction. If we denote

```
$Q^T = G_{(1,\rho-1)} \cdots G_{(p-1,1)}G_{(p,1)},$ (16.14)
```

we get

```
$R = Q^TA,$$ (16.15)
```

which is the decomposition we were looking for once we will de-transpose the matrix
$Q^T$, i.e. by transposing it one more time.
It remains to specify how to find the particular form of the Givens rotation matrix
which will make the $(i,j)$ element zero. Let us consider the input matrix $A$, and our
objective is to find $G = G(i,j; \theta_{(i,j)})$ such that $\{GA\}_{(i,j)} = 0$. If we recall the form of the
matrix $G$ in equation (16.11), we directly write the equation for the $(i,j)$ element to
zero:

```
$$\sin(\theta_{(i,j)})a_{(i,i)} + \cos(\theta_{(i,j)})a_{(i,j)} = 0,$$ (16.16)
```

which can be used to find $\theta_{(i,j)}$,

```
$$\theta_{(i,j)} = \arctan\left(\frac{a_{(i,j)}}{a_{(i,i)}}\right),$$$ (16.17)
```

This concludes the algorithm which allows us to obtain the QR decomposition for
any square matrix.
