The OLS estimation is based on solving the system of linear equations with Moore-Penrose pseudoinverse of matrix X. We take this orientation to remind the reader that we formulate the solution to the OLS as:

```
$$\hat{\beta}^T = y^T X^T = Y^T X(X^T X)^{-1}$.$
```

We choose this formulation for convenience; these two building blocks we have to define calculate the solution to the problem: first, we need to define $Y^TX$:

ytx: enlist tabData[`y`] mmu flip[tabData[`const`x1`x2`x3]];

and then also $X^TX$

xtx: x mmu flip[x:tabData[`const`x1`x2`x3]];

We solve the equation for the $\beta$'s using the 1sqb corresponding to:

```
$Y^T X = \hat{\beta}^T(X^T X)$.
```

solution given as:

solution: ytx lsq xtx;
solution

enlist 1.010413 0.9998791 -0.9974519 1.996775

The solution is an estimated list of parameters corresponding to features `const`x1`x2`x3, in a given order. The provided code allows us to find a solution for more than one set of dependent variables, i.e the column `y` in the tabData table can be composed of lists instead of float atoms. The problems where we need OLS do not give us more than one dependent variable, and thus we restrict ourselves to situations where we have just need to get the solution from the list:

beta:first solution;
beta

1.010413 0.9998791 -0.9974519 1.996775

We have thus obtained the solution in the form:

```
$y = 1.010413 + 0.9998791 * x_1 - 0.9974519 * x_2 + 1.996775 * x_3$.
```
