# Scott’s rule

The final formula we implement is Scott’s rule for normally distributed data, where the width of bins depends on the estimated sample variance $\sigma^2$:

$h = \frac{3.5\sigma}{N^{1/3}}, \quad (12.4)$

where we further derive the number of bins from its width and range of the data in the same way as for histWidth function:

```
quant.stats.histScott::[[data]
// data array of data
// width of bins
h:ceiling(3.5+dev data)%xexp[count data;1.0%3.0];
// return bins
:min[data]+h*h 1+ceiling((max[data]-min[data])%h);
)
```

data:(1000?3.0), (200?1.0), (2.0+300?1.0);
