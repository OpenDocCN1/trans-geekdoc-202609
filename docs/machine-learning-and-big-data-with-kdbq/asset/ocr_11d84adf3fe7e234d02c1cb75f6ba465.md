The last statement allows us to create new entries into our table by providing a superdomain of values! q naturally fills the values of those new entries with null for column's data type. This is indeed powerful. For example, a very useful case is to build a full-time series from a sparsely sampled population. Recall:

t

sym time | price
---|---
a 0000:00:00.000000000 10
b 0000:01:00.000000000 20
c 0000:02:00.000000000 30

Let's aggregate the price by 30-second intervals. According to the definition of xbar, q will group by rounding down to the nearest value which divides the existing time vector.

```
select avg price by D00:00:30 xbar time from t
```
