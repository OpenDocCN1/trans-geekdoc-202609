The covariance matrix is not a random quantity, but we can only write down a specific covariance matrix if we assume that we “know” the distribution of the random variable **x**; often we only pretend that we know it. Here we assumed the random **x** is a column vector, i.e. **x** $\in \mathbb{R}^{p \times 1}$.

First, let us answer the question, what is the significance of the $(i,j)$-th entry of the covariance matrix $\Sigma$? If we write the $p$-dimensional random vector **x** as

```
$\mathbf{x} = \begin{bmatrix} x^{(1)} \ x^{(2)} \ x^{(3)} \ \vdots \ x^{(p)} \end{bmatrix} \quad (16.23)$
```

then the $(i,j)$-th entry of $\Sigma$ is the covariance between the scalar random variables $x^{(i)}$ and $x^{(j)}$:

```
$$\Sigma^{(i,j)} = \text{Cov}(x^{(i)}, x^{(j)}) = E[(x^{(i)} - E[x^{(i)}])(x^{(j)} - E[x^{(j)}])] \quad (16.24)$
```

where we notice that, in this notation for covariance of two random variables, Cov has two arguments, in the notation Cov[**x**] for the covariance matrix, Cov has a single article.

The key properties of covariance matrices are: first, it is symmetric, and second, it is positive semidefinite. To show that $\Sigma$ is semidefinite:

```
$$\Sigma^T = \E[(\mathbf{x} - E[\mathbf{x}])(\mathbf{x} - E[\mathbf{x}])^T]^T \interT \quad (16.25)$
```

```
$= E[{(\mathbf{x} - E[\mathbf{x}])^T(\mathbf{x} - E[\mathbf{x}])^T] \quad (16.26)$
```

```
$= E[(\mathbf{x} - E[\mathbf{x}])(\mathbf{x} - E[\mathbf{x}])^T] = \Sigma \quad (16.27)$
```

and to show that $\Sigma$ is positive semidefinite, let **u** $\in \mathbb{R}^p$ be a nonzero vector. Then

```
$$\mathbf{u}^T \Sigma \mathbf{u} = \mathbf{u}^T E[(\mathbf{x} - E[\mathbf{x}])(\mathbf{x} - E[\mathbf{x}])^T]\mathbf{u} \quad (16.28)$
```

```
$= E[{(\mathbf{x} - E[\mathbf{x}])^T\mathbf{u})(\mathbf{x} - E[\mathbf{x}])^T}] \quad (16.29)$
```

```
$= E \left| \begin{matrix} (\mathbf{x} - E[\mathbf{x}])^T\mathbf{u} \end{matrix} \right|^2 \geq 0 \quad (16.30)$
```

When we work with data, we often say that we calculate covariance matrix and talk about values of the covariance matrix coming from the given sample. In this case, we talk about the sample covariance matrix, which is given

```
$$\mathbf{Q} = \frac{1}{n-1} \sum_{i=1}^n (\mathbf{x}_i - \bar{\mathbf{x}})(\mathbf{x}_i - \bar{\mathbf{x}})^T \in \mathbb{R}^{p \times p} \quad (16.31)$
```
