# 16.6.1 Theory

Let us consider a square real matrix A:

```
A = \begin{pmatrix} A_{11} & A_{12} & \cdots & A_{1n} \ A_{21} & A_{22} & \cdots & A_{2n} \ \vdots & \vdots & \ddots & \vdots \ A_{n1} & A_{n2} & \cdots & A_{nn} \end{pmatrix} (16.86)
```

For every real-valued matrix (we do omit the complex matrices in this section, though the determinant can be extended to complex domain), we can define the determinant as a real-valued function, with inputs being elements of the matrix. The determinant is a polynomial of the order 2 in entries of the matrix A. The determinant is usually denoted as det(A), or, |A|. The determinant is met across the various topics in linear algebra. In this chapter, we have encountered the determinant when we have constructing the algorithm to calculate the eigensystem of a real matrix. It can be used to determine the linear independence of a system of n vectors, or calculating Jacobian.

The determinant has a geometric interpretation. Let us consider a unit n-dimensional cube and n-dimensional square matrix A. The columns of the matrix can be considered as edges which define the paralleleotope, with one corner at the origin. The paralleleotope is a deformed cube, which is deformed by the matrix transformation A. In 2-dimensions, the paralleleotope is a parallelogram, which is nothing but deformed. Then, the determinant is the volume of such a parallelotope.

Before we dive into the definition of the determinant, we first present the useful properties of the determinant:

+   - det(I) = 1 for any unit matrix I.
- det(A^T) = det(A).
- det(A^{-1}) = 1/det(A).
- det(AB) = det(A)det(B) where matrices A and B are square matrices of the dimension.
- det(cA) = c^n det(A) with c being a constant.
- det(A + B) >= det(A) + det(B) for matrices A and B being of the same size and both positive semidefinite.
- tr(A) = log(exp(A)) with tr tracing the trace of a square matrix.
- det(A) = \prod_{i=1}^{n} \lambda_{i}, where \lambda_{i} are eigenvalues of the matrix A.

The listed properties are useful when we manipulate determinants.
