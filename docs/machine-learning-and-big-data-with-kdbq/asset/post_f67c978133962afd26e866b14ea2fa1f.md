## 22.1.1 Calibration

The neural network is rather intuitive, and two-stage regression/classification interpretation makes it transparent. What is less clear, however, is the procedure for the calibration of the weights, as the parameters of this model are frequently called. There are all together

```
$N_{params} = L \cdot (N+1) + N \cdot (M+1) \quad (22.7)$
```

parameters. The dimensionality of the problem is large.

Let us first propose an exact solution. We index the observations by index $t$, with $t=1, \dots, T$ observations in total.

### Regression

Let us want to regress the $L$-dimensional dependent variable $Y_t$. The loss function used is the sum of squared residuals:

```
$Loss_{reg}(Y, X; \Theta) = \sum_{t=1}^{T} R_t(Y, X; \Theta) = \sum_{t=1}^{T} \sum_{l=1}^{L} (Y_t^{(l)} - \tau_l(\beta_0^{(l)}Z_0(X; \alpha) + \beta_1^{(l)}Z_1(X; \alpha) + \dots + \beta_N^{(l)}Z_N(X; \alpha))^2, \quad (22.8)$
```

where $Z_p(X; \alpha)$ is a function of the input data $X$ and parameters $\alpha$, expressed symbolically for brevity, and $\Theta$ comprises all parameters in the model. The linear activation function usually works well for regression problems. The loss function $Loss_{reg}(Y, X; \Theta)$ is minimised with respect to all parameters $\Theta$.

### Classification

When we want to classify the $L$-dimensional dependent variable $Y_t$ into $L$ classes, a convenient loss function is the cross-entropy function:

```
$Loss_{class}(Y, X; \Theta) = -\sum_{t=1}^{T} \sum_{l=1}^{L} Y_t^{(l)} \log \tau_l(\beta_0^{(l)}Z_0(X; \alpha) + \beta_1^{(l)}Z_1(X; \alpha) + \dots + \beta_N^{(l)}Z_N(X; \alpha)), \quad (22.9)$
```

where the same description as the regression holds. The choice of the activation function will affect the resulting model. Using the softmax function defined in eq. (22.4) and the majority vote, i.e. choosing the class according to:

```
$L = \arg \max_i \tau_i, \quad (22.10)$
```

is a convenient choice. In addition, it affects the interpretability of the model. The model can be understood as a logistic regression in $Z_i$. This corresponds to a class of models which are extensively studied in the literature and are frequently used in practice.

## 22.1.1 Backpropagation

The exact solution for the parameter set $\Theta$ may not be accessible or optimal. The solution can be overfitted as the neural network contains a large number of parameters and the expression for the parameters themselves may be cumbersome. A better approach is based on Rumelhart et al. (1986), a technique for backpropagation of errors for training neural networks. It is based on the optimisation method of gradient descent. It works as follows:

- Set the parameters of the model randomly.
- Propagate forward the input data and calculate the error of prediction at the output layer.
- Propagate backwards the errors through the network.
- Update the parameters of the model throughout the network based on the gradient of the error at each part of the network.

This mechanism, which the propagation goes forward and then backward, gives rise to an alternative name of the procedure, the forward-backward propagation. The procedure requires the knowledge of the gradient at each node. This is technically feasible for neural networks as chain rule can be used for calculating derivatives at each node. The procedure allows us to progress layer-by-layer and the information relevant for a given layer/node can be stored.

Let us derive the equations needed for the backpropagation algorithm, namely the gradients at each node. For that purpose we will employ the square loss function for the regression problem with $L$ dependent variables. Further, we need to express the equations describing the neural network for each observation. Then, we denote every feature and dependent variable as $X_t = (x_{m1}, x_{m2}, \dots, x_{mt})^T$ and $Y_t = (y_{t1}, y_{t2}, \dots, y_{it})^T$, respectively, where the observations are indexed by $t$. Analogously, the state of the node of the neural network when $t$-th occurs is read by the network:

```
$z_{nt} = \eta (\alpha_0^{(n)} x_{0t} + \alpha_1^{(n)} x_{1t} + \dots + \alpha_M^{(n)} x_{mt}). \quad (22.11)$
```

The gradient to be calculated is derived from eq. (22.8). We need to calculate derivatives with respect to the parameters $\alpha$ and $\beta$, respectively. We will use the chain rule for derivatives and thus we derive starting at the output node and proceeding towards the input node. Every node is chained to the previous one: the first derivative with respect to the parameter $\beta_n^{(i)}$ driving the error of the activation functions

$$\frac{\partial R_l^{(i)}}{\partial \beta_n^{(i)}} = -2\left(y_l^{(i)} - \tau_l^{(i)}(\beta_{0l}^{(n)}(X;\alpha) + \beta_{1l}^{(i)}z_{1l}(X;\alpha) + \dots + \beta_{nl}^{(i)}z_{nl}(X;\alpha)\right) \quad (22.12)$$

```
$\tau_l^{(i)}(\beta_{0l}^{(n)}(X;\alpha) + \beta_{1l}^{(i)}z_{1l}(X;\alpha) + \dots + \beta_{nl}^{(i)}z_{nl}(X;\alpha)) = z_{nl}.$ (22.13)$
```

Then, using the chain rule we can write down the first derivative with respect to $\alpha_m^{(n)}$

$$\frac{\partial R_l^{(i)}}{\partial \alpha_m^{(n)}} = -2\sum_{t=1}^{L} \left(y_l^{(i)} - \tau_l^{(i)}(\beta_{0l}^{(n)}(X;\alpha) + \beta_{1l}^{(i)}z_{1l}(X;\alpha) + \dots + \beta_{nl}^{(i)}z_{nl}(X;\alpha))\right) \quad (22.14)$$
