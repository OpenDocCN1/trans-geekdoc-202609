# Basic Overview of Statistics

# Square root

The number of bins is derived from the size of the sample using the square-root formula:

$$n = \sqrt{N},$$ (12.1)

where [x] denotes the smallest integer larger than x, and is implemented as:

```
.quantQ.stats.histSquareRoot::[data]
// data -- array of data
// number of bins
:ceiling sqrt count data;
// return bins
:min[data]+((max[data]-min[data])%n)*til 1+;
;
```

# Sturge's formula

The number of bins is derived from the binomial distribution and provides reasonable histograms for large sizes and approximately normally distributed. The formula for number of bins reads:

$$n = 1 + [\log_2 N],$$ (12.2)

implemented as:

```
.quantQ.stats.histSturge::[data]
// data -- array of data
// number of bins
:n+ceiling log[2;count data];n// return bins
:min[data]+((max[data]-min[data])%n)*til 1+;
;
```

# Rice's rule

Similar to Sturge's formula can be achieved by Rice's formula, where number of bins is given as:

$$n = [N^{1/3}],$$ (12.3)

Function reads:

```
.quantQ.stats.histRice::[data]
// data -- array of data
// number of bins
:ceiling 2*exp count data;1.0%3.0;
// return bins
:min[data]+((max[data]-min[data])%n)*til 1+;
;
```
