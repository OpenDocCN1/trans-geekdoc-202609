# 6.5 CONCLUSION

In this section we have shown how to save tables in disc: 3 ways:

+   - binary files: suitable for "small" (thousands or up to a million records) tables,
  with such static data.
- played tables: suitable for "medium" size tables, or tables that are very wide, i.e.
  have a large number of columns.
