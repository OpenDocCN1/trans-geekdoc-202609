## 28.2 MONTE CARLO TREE SEARCH

We focus on the Monte Carlo Tree Search algorithm, which is a popular heuristic search algorithm for decision processes frequently used in AI engines.

We focus on perfect information games. These games are turn-based, and there is no hidden information among players. There is no random element in the game like like drawing cards from the shuffled deck. Tic-tac-toe or chess are examples of such games.
