Lastly let us complement the definitions of the rank correlations by Kruskal's y. It is another coefficient measuring the similarity of ordering of the data for a pair of ordinal variables; see Goodman and Kruskal (1954). The $\gamma$ coefficient is defined as:

```
$$\gamma = \frac{N_C - N_D}{N_C + N_D},$
```

where $N_C$ and $N_D$ stand for the number of concordant and discordant pairs, respectively. Kruskal's $\gamma$ ranges over $[-1, 1]$. When there is no association between the two random variables, the $\gamma$ is close to 0.

Somers'; Kendall's $	au$, and Kruskal's $\gamma$ are presented as descriptive statistics. To order them in the form of a test, we have two options. The first option is to calculate the small sample distribution of given statistics. Methods like bootstrap can be used. In such a case, we simulate a number samples under the null hypothesis and evaluate the statistics for every simulation. We collect the distribution of the statistics and create critical values based on the simulated distributions.

Alternatively, we may seek the analytic distributions of the test statistics. Its form may not be straightforward, and sometimes the analytic approximations may be needed. Let us illustrate it for Kruskal's $\gamma$. We define new statistics:

```
$$t_\gamma = \gamma \sqrt{\frac{N_C + N_D}{N(1-\gamma^2)}}$,
```

where all have been defined so far, with $N$ being a number of observations. The statistics follows $\sim t_{N-1}$. For large $N$, the normal distribution can be used. We can then form the hypothesis:

+   * $H_0$: There is no association between two random variables.
"* $H_a$: There is an ordinal association between two random variables."

The one-sided/two-sided test can be run by comparing $t_\gamma$ against critical values $t_{critical:N-1}$.
