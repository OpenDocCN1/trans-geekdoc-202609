The function .quantQ.ts.estimate[y;p] returns the one-step prediction of the VAR(p) model. Hence, .quantQ.ts.estimate[d;2] forecasts the next values of d with a VAR(2) model.

```
-0.01081094 0.01991084 0.02162873
```

It computes $\hat{y} = \hat{A}_1\hat{y}_{T-1} + \hat{A}_2\hat{y}_{T-2}$

```
nu varp[];
a1:varp[;1:3];na2:varp[;4:5];
y2:d;(count d[0]-2);
y1:d;(count d[0]-1);
nu + (a1 mmu y2) + (a2 mmu y1)
```

The function .quantQ.ts.confInterval[y;p] computes the 95% confidence interval of the VAR(p) model, i.e. $[\hat{y}_k(h) \pm 1.96\hat{\delta}_k(h)]$

```
.quantQ.ts.confInterval[d;2]
```

returns

```
-0.1054982 0.03837633
0.004134704 0.04395638
0.02249761 0.04100769
```

It means that one-period ahead forecast of income within $[-0.1054982;0.03837633]$, log-return income within $[0.004134704;0.04395638]$ and log-return consumption within $[0.02249761;0.04100769]$.
