# 16.4.2 PCA: The First Principal Component

Let us introduce the principal components of the data set provided, which we will then extend to higher components. For the sake of clarity, calculation of the first principal component, let us once again stress that we have $p$ features. We shall model our data as a $p$-dimensional random variable $\mathbf{x} \in \mathbb{R}^{p 	imes 1}$.

The objective behind the PCA is to look for a vector of weights $\mathbf{w}_{(1)} \in \mathbb{R}^{p 	imes 1}$ such that the variance of the scalar random variable $\mathbf{w}_{(1)}^	op\mathbf{w}_{(1)}$ is maximised. Our objective is to find

```
\max \text{Var}[\mathbf{w}_{(1)}^	op\mathbf{w}_{(1)}] (16.38)
```

We assume that we are given a data matrix with $n$ observations, $\mathbf{X} \in \mathbb{R}^{n 	imes p}$. Let us centre this data on the centred data matrix $\mathbf{X}^\prime$. We have already argued that the sample covariance matrix:

```
\mathbf{Q} = \frac{1}{n-1}(\mathbf{X}^\prime)^	op\mathbf{X}^\prime (16.39)
```

is an unbiased estimator of the sample covariance matrix $	ext{Var}[\mathbf{Q}]$. At best, by the properties of variances,

```
\text{Var}[\mathbf{w}_{(1)}^	op\mathbf{w}_{(1)}] = \mathbf{w}_{(1)}^	op \mathbf{\Sigma} \mathbf{w}_{(1)}} (16.40)
```

In practice, however, we do not have access to $\mathbf{\Sigma}$. At best, we can approximate it by some matrix $\mathbf{C}$, which by the unbiased estimator – the sample covariance matrix:

```
\mathbf{C} = \mathbf{Q} := \frac{1}{n-1}(\mathbf{X}^\prime)^	op\mathbf{X}^\prime (16.41)
```

Thus our maximisation problem becomes:

```
\max \mathbf{w}_{(1)}^	op \mathbf{C}\mathbf{w}_{(1)}} (16.42)
```

This is not enough; let us add another requirement (in optimisation parlance, another constraint): we want our weights, $\mathbf{w}_{(1)}$, to be a unit vector:

```
\mathbf{w}_{(1)}^	op \mathbf{w}_{(1)}} = 1. (16.43)
```

Equivalently, we can add a penalty to our (again, in optimisation parlance) objective function for any deviation from zero of $\mathbf{w}_{(1)}^	op\mathbf{w}_{(1)} - 1$. The optimisation problem becomes

```
\max \mathbf{w}_{(1)}^	op \mathbf{C}\mathbf{w}_{(1)}} - \lambda(\mathbf{w}_{(1)}^	op\mathbf{w}_{(1)}} - 1), (16.44)
```
