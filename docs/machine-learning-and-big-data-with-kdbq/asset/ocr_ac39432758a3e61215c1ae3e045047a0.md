Let us illustrate how the prototypes perform for the out-of-sample test. We create a function which assigns a class to a point based on the proximity to the trained centres.

```

centre and f

// table with proximity of a point to the centres

-> point;2]

```

Moreover, we can test it as

```
.quantQ.knn.getPrototypeKNN;resultKNN;.2 .3
```
