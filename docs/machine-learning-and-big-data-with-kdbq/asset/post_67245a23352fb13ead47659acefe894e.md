
# Linear Regression

Having the log-likelihood, we can formulate the AIC function:

```
.quantQ.ols.AIC:[p; logL]
// p -- number of parameters
// logl -- log-likelihood
// (2*p)-2*p*logL;
;
```

The AIC for the example listed in this section gives:

```
.quantQ.ols.AIC[count[beta];quantQ.ols.logL[count[y]];RSS]
```

As we have mentioned in the paragraphs leading, the AIC on its own does not give us information. We cannot say whether -1783.824 is small and thus information is small or if it is large and unacceptable. The calculation assumes that holds, the size of the sample is infinite. This is not true as our sample contains finite points. In such a case, the offset between the complexity of the model and its accuracy may adequately work. The sample correction should be considered. In general, this task is complicated and an analytic formula may not be possible to find for any model. Thus, methods like bootstrap are needed to use a numerical correction to AIC.

Fortunately, for the OLS model, or for univariate linear model where residuals are normally distributed, the analytic formula works. In this case the AIC corrected for the small size of the sample, usually denoted as AICc, is defined:

$AICc = AIC + \frac{2p}{n - 1}$

Several observations are at place: as $n \to \infty$, AICc is proportional to $p^2$ and thus can be considered a second-order approximation to the relative information loss in number of parameters. The AIC implementation reads:

```
.quantQ.ols.AIC:[n;logL]
// n -- number of parameters
// sample -- sample size
// logl -- log-likelihood
// 2*n-2*n*logL;
```

```
.quantQ.ols.AIC[count[beta];count[y];quantQ.ols.logL[count[y]];RSS]
```

# ESTIMATION SUITE

Finally, we put all components together to create the entire regression suite of ordinary least squares including all additional statistics. The output of the function is a dictionary with various variables. The dictionary corresponds to a chosen model. The advantage of this approach, in this case, is that we can create later statistics which allows us to assess the quality of a model or compare to two or more models, as AIC suggests. The estimation suite consists of the measures and statistics introduced above; some of them have been directly incorporated into the suite rather than reused. We also added treatment for missing values. In particular, when a missing value is observed over any feature, the row to which the missing value belongs removed. This method is convenient when the data has only a few entries. If the missing values are too frequent or present pattern in the data, more sophisticated and tailored techniques will be needed.

```
.quantQ.ols.fit(y;x)
// y -- array of dependent variables
// x -- array of independent variables, constants has to be included
whereMissing:raise(where y=on;drop(where x=on) each)
// remove the missing values
y::y((count y) except whereMissing);
x::[[whereMissing;x] x:(count x) except whereMissing]][whereMissing];each x;
// y^T X
tyx:enlist y flip[x];
xtx: x flip[x];
// solve the OLS equation
solution: y tsq xtx;
// beta
beta:first solution;
// var cov matrix
varcov:(inv flip[xtx])*sum(1.0*(count[y])-count[beta]);
// beta+x;
// errors for every estimation (sample standard deviation)
// t-stat(sqrt y[varcov]) each til varcov;
// t-stat for every beta
tStats:statisticsbeta;
// TSS or Total Sum of Squares
TSS: sum y-avg[y];
// RSS or Residual Sum of Squares
RSS: sum y-beta*;
// R-squared
nRsquared:1.0.-RSS%TSS;
// adjusted R-squared
adjRsquared:(1-(Rsquared))*(count(y)-1.0)*(count(y)-(count[beta]-1.0))
```

```
// significance level in normal approximation (econometric)
convertPDict:(0j;1j;2j;3j;4j)!("-" (90% c.l.))"** (95% c.l.);
// "*** (99% c.l.)";
// "*** (99.9% c.l.));
```

The output contains all the information in a comprised and easy-to-retrieve way, but still beyond reach of human. For that purpose we summarise the results in a more convenient and standardised form:

```
quantQ.ols.fit[tab]
// tab - table with data
// names
yname:first cols
xnames:first cols
// running regressions
reg.:quantQ.ols.fit[tab];tab[xNames]
// regression of part
tabReg:xNames;coeff:reg[beta];error:reg[errors];tStat:reg[tStats]; significance:reg[signLevels]);
// stats per part
tabStats:STATISTICSnnObservations'TSS'RSquared'RSquaredAdjusted'AIC LogLikelihood AICC;coeff:(0;f"$count[y];y"df;
f$reg[`TSS];$f$reg[`RSS];reg[`Rsquared];reg[`adjRsquared];reg[`logL];reg[`aic];reg[`aicc]);
// return the table with results
tabReg tabstats;
