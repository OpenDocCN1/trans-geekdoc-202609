Finally, we define one of the Apriori algorithm as a function which takes as an argument a dictionary with all important variables including the data itself in the wide dummy format, the outcome of the Apriori algorithm after a given iteration as temporary variables, and returns the updated dictionary.

```
.quantQ.apriorioneRun:([bParams])
// dictionary with all data and parameters
// increase counter
bParams['step']=1;
// create set of all combinations -- distinguish first step
$bParams['step1']=zz; distinct each 1_cols bParams['largeTabDummies]; zz:
  -> asc as t
  bParams['step']=count each t; distinct asct bParams[
  bParams['colDummiesStep1]];
// if step1: test whether zz does not have subset from
  colDummiesStepALL
$bParams['step1']=zz; first flip t each 1b=last t::[bParams]; (x;
  -> not max
  quantQ.apriori.isin([each bParams['colDummiesStepALL]])[bParams
  ]; each zz;
// numerical criteria
yy: flip([largeTabDummies]);
  <-shr sum prod largeTabDummies[whr]
bParams['largeTabDummies]; each zz;
// temporary column variables -- split zz into two sub-sets
colDummiesStepMP: as each zz bParams['thresh]<(value first yy!)
  -> last(yy)]
count bParams['largeTabDummies];
colDummiesStepMPX: as each zz where not in colDummiesStepMP;
// define colDummiesStep1 in step
$bParams['step1']=1;bParams['colDummiesStep1]:colDummiesStepMP;
// populate bucket
bParams['colDummiesStepMP']=distinct colDummiesStepMP;
bParams['colDummiesStepALL']=distinct bParams['colDummiesStepALL];
  -> distinct colDummiesStepMP;
bParams['colDummiesStepMP']=distinct colDummiesStepMPX;
bParams['colDummiesStepALL']=distinct bParams['colDummiesStepALL];
  -> distinct colDummiesStepMPX;
// check if further improvement can be done
$[=count colDummiesStepMP,bParams['canImprove];0b;bParams['canImprove
  ]:1b);
// return bucket
:bParams;
```
