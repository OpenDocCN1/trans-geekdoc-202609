We reconstruct the stumps from the provided table. The first stump is based on feature '$x_1$, split at the threshold $\xi_1 = 0.938132$. The given split gives loss function, or error, of 0.381182 can be interpreted as an overall error of the weights have been initialised equal and normal to 1. In the subsequent iterations, it cannot be interpreted in the same way as weights are equal. Due to the overall normalization, the value of error is decreasing over time for improving the algorithm. If we assume this premise the algorithm suggests that the algorithm is not improving beyond the first stump. This is highly likely given how we have constructed the data set, where one of two features split around close to 0.9 is sufficient. We encourage the reader to run the function with a large $L_{max}$ and graphically explore the evolution of errors.

The step we miss is a function which would give us the prediction based on the entire AdaBoost committee we have collected the algorithm. This is done in the following function, which takes as input bucket and returns a table with four columns: `res` containing the numerical value provided by the model, `y` containing true value of the dependent variable based on the numerical value, and `isPredicted` column, which shows whether the observation has been correctly predicted, 1 value, or 0, not -1.

```
quant.ada.adaBoostPrediction:`[bucket`]
// dictionary with tab and ada tables
tab:bucket[`tab`]
ada:bucket[`ada`]
// calculate the sum of the individual predictions
res: sum(tab[`tab`];config[0]*quant.Q.ada.stump[tab[config[1]]];config[2]])
(ada[`alpha`,`ada[`stump`]);
// add prediction to tab table
update isPredicted: prediction+y from update prediction: signum res
- from ([] res:res; y:tab[`y`]);
```
