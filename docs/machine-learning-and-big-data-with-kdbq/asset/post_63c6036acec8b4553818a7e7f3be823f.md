The covariance matrix is not a random quantity, but we can only write down a specific covariance matrix if we assume that we “know” the distribution of the random variable $\mathbf{x}$; often we only pretend that we know it. Here we assumed the random $\mathbf{x}$ is a column vector, i.e. $\mathbf{x} \in \mathbb{R}^{p \times 1}$.

First, let us answer the question, what is the significance of the $(i,j)$-th entry of the covariance matrix $\Sigma$? If we write the $p$-dimensional random vector $\mathbf{x}$ as

```
\mathbf{x} = \begin{bmatrix} x^{(1)} \\ x^{(2)} \\ x^{(3)} \\ \vdots \\ x^{(p)} \end{bmatrix} \quad (16.23)
```

then the $(i,j)$-th entry of $\Sigma$ is the covariance between the scalar random variables $x^{(i)}$ and $x^{(j)}$:

```
$$\Sigma^{(i,j)} = \text{Cov}(x^{(i)}, x^{(j)}) = E[(x^{(i)} - E[x^{(i)}])(x^{(j)} - E[x^{(j)}])] \quad (16.24)
```

where we notice that, in this notation for covariance of two random variables, Cov has two arguments, in the notation Cov[$\mathbf{x}$] for the covariance matrix, Cov has a single argument.

The key properties of covariance matrices are: first, it is symmetric, and second, it is positive semidefinite. To show that $\Sigma$ is symmetric:

```
$$\Sigma^T = E[(\mathbf{x} - E[\mathbf{x}])(\mathbf{x} - E[\mathbf{x}])^T]^T \quad (16.25)
```

```
$= E[(\mathbf{x} - E[\mathbf{x}])^T(\mathbf{x} - E[\mathbf{x}])] \quad (16.26)
```

```
$= E[(\mathbf{x} - E[\mathbf{x}])(\mathbf{x} - E[\mathbf{x}])^T] = \Sigma \quad (16.27)
```

and to show that $\Sigma$ is positive semidefinite, let $\mathbf{u} \in \mathbb{R}^p$ be a nonzero vector. Then

```
$$\mathbf{u}^T \Sigma \mathbf{u} = \mathbf{u}^T E[(\mathbf{x} - E[\mathbf{x}])(\mathbf{x} - E[\mathbf{x}])^T]\mathbf{u} \quad (16.28)
```

```
$= E[(\mathbf{x} - E[\mathbf{x}])^T\mathbf{u})(\mathbf{x} - E[\mathbf{x}])] \quad (16.29)
```

```
$= E \left| (\mathbf{x} - E[\mathbf{x}])^T\mathbf{u} \right|^2 \geq 0 \quad (16.30)
```

When we work with data, we often say we calculate the covariance matrix and talk about values of the covariance matrix from the sample. In this case, we talk about the sample covariance matrix, which is given

```
\mathbf{Q} = \frac{1}{n-1} \sum_{i=1}^n (\mathbf{x}_i - \bar{\mathbf{x}})(\mathbf{x}_i - \bar{\mathbf{x}})^T \in \mathbb{R}^{p \times p} \quad (16.31)
```

# Eigensystem and PCA

$\mathbf{x}_i$ is the $i$-th row of the data matrix $\mathbf{X}$ written as a column vector and $\bar{\mathbf{x}}$ is the sample mean, also written as a column vector. We are still modelling $\mathbf{x}_i$ as a random variable, but now we have a data sample; for a concrete sample (a concrete data matrix $\mathbf{X}$), we obtain a specific matrix $\mathbf{Q}$ and use it as an estimator of the covariance matrix $\text{Cov}[\mathbf{x}]$ of the random variable $\mathbf{x}$.

Thus the sample covariance matrix is an estimator of the sample covariance, whereas the covariance matrix is an estimator of the variance of a random variable. However, people often use the term “covariance matrix” for both things, so beware of the confusion!

The sample covariance matrix is symmetric and positive semidefinite. We will leave it to the reader to construct the proof of this assertion. Please keep in mind that we use sums over all realizations in the sample data $X$. Another important feature of the sample covariance matrix is to be an unbiased estimator of the true covariance matrix $\text{Cov}[\mathbf{x}]$. This assertion follows from:

```
$$\mathbb{E}[\mathbf{Q}] = \frac{1}{n-1} \sum_{i=1}^n (\mathbf{x}_i - \bar{\mathbf{x}})(\mathbf{x}_i - \bar{\mathbf{x}})^T$$
= \frac{1}{n-1} \sum_{i=1}^n [\mathbf{x}_i\mathbf{x}_i^T - \bar{\mathbf{x}}\mathbf{x}_i^T - \mathbf{x}_i\bar{\mathbf{x}}^T + \bar{\mathbf{x}}\bar{\mathbf{x}}^T]$$
= \frac{1}{n-1} \sum_{i=1}^n \mathbb{E}[\mathbf{x}_i\mathbf{x}_i^T] - n\mathbb{E}[\bar{\mathbf{x}}\bar{\mathbf{x}}^T]$$
= \frac{1}{n-1} \sum_{i=1}^n (\boldsymbol{\Sigma} + \boldsymbol{\mu}\boldsymbol{\mu}^T) - n (\frac{1}{n} \boldsymbol{\Sigma} + \boldsymbol{\mu}\boldsymbol{\mu}^T)$$
$$= \frac{1}{n-1} [n\boldsymbol{\Sigma} + n\boldsymbol{\mu}\boldsymbol{\mu}^T - \boldsymbol{\Sigma} - n\boldsymbol{\mu}\boldsymbol{\mu}^T] = \boldsymbol{\Sigma}$$
```

So $\mathbf{Q}$ is an unbiased estimator of $\Sigma$.

Further, closely related to the covariance matrix is the correlation matrix. The correlation matrix of Pearson product-moment correlation coefficients between each element in the vector, $\mathbf{x}$, can be written as:

```
$$\text{Cor}[\mathbf{x}] = (\boldsymbol{\Sigma}^{(\text{diag})})^{-\frac{1}{2}} \boldsymbol{\Sigma} (\boldsymbol{\Sigma}^{(\text{diag})})^{-\frac{1}{2}}$$
```

where $\Sigma^{(\text{diag})}$ is the matrix of the diagonal elements of $\Sigma$, i.e. a diagonal matrix of $\Sigma$. The correlation matrix is thus a rescaling of the covariance matrix. Furthermore, the correlation matrix is symmetric and positive semidefinite. It is worth establishing a connection between the covariance matrix and the correlation matrix, in particular, when the data is centered, $(\mathbf{X}^T)$, the sample covariance matrix is given by a multiple of the Gram matrix, namely for the sake of clarity, the first components, we shall model our data as a $p$-dimensional random variable $\mathbf{x}$.

## 16.4.2 PCA: The First Component

The objective behind the PCA is to look for a vector of weights $\mathbf{w}_{(1)} \in \mathbb{R}^p$ such that the variance of the scalar random variable $\mathbf{w}_{(1)}$ is maximised.

```
\max \text{Var}[\mathbf{w}_{(1)}^T\mathbf{w}_{(1)}] \quad (16.38)
```

We assume that we are given a matrix with $n$ observations, $\mathbf{X} \in \mathbb{R}^{n \times p}$. Let us centre this data on the centred data matrix $\mathbf{X}'$. We have already argued that the sample covariance matrix:

```
\mathbf{Q} = \frac{1}{n-1} \sum_{i=1}^n (\mathbf{x}_i - \bar{\mathbf{x}})(\mathbf{x}_i - \bar{\mathbf{x}})^T \quad (16.39)
```

is an unbiased estimator of the covariance matrix $\Sigma$. In practice, however, we do not have access to $\Sigma$. At best, we can approximate it by some matrix $\mathbf{C}$, which by the unbiased estimator – the sample covariance matrix – is given by a multiple of the Gram matrix.

Thus our maximisation problem becomes:

```
\max \mathbf{w}_{(1)}^T \mathbf{C}\mathbf{w}_{(1)}} \quad (16.42)
```

This is not enough; let us add another requirement (in optimisation parlance, another constraint): we want our weights, $\mathbf{w}_{(1)}$, to be a unit vector:

```
\mathbf{w}_{(1)}^T \mathbf{w}_{(1)}} = 1. \quad (16.43)
```

Equivalently, we can add a penalty to our (again, in optimisation parlance) objective function for any deviation from zero of $\mathbf{w}_{(1)}^T \mathbf{w}_{(1)} - 1$. The optimisation problem becomes

```
\max \mathbf{w}_{(1)}^T \mathbf{C}\mathbf{w}_{(1)}} - \lambda(\mathbf{w}_{(1)}^T \mathbf{w}_{(1)}} - 1), \quad (16.44)
```
