In order to define the local outlier factor, we have to fix the definition of the distance between two points in the feature space. We employ the one based on the $L_p$-norm, and in particular we set $p = 2$, i.e.

> $$d(X, Y) = \left(\sum_{i=1}^{N} |X_i - Y_i|^2\right)^{1/2}$ \quad (17.2)$

for any two points $X$ and $Y$.

For our purpose, we implement the $L_2$-norm as a function of two arguments, where the first is a reference point and the other is a vector of points. The function calculates the distance between the reference point and each point of an array:

```
quantQ.of.L2distance:[point;dataVector]
// point -- reference point
// dataVector -- vector of data
:sqrt t wsum t:flip[dataVector]-point;
```

We can verify the implementation against the test point by updating the table dataSet by extra column distanceToPoint, which contains the distance between the test point and the feature array `\x0`x1:`:

```
testPoint:(0.5;0.5);
// calculate distance to each point
dataSet: update distanceToPoint:quantQ.of.L2distance[testPoint;(x0,'x1])
from dataSet;
```
