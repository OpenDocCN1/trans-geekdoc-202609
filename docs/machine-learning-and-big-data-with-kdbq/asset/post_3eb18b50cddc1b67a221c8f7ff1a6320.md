AlphaGo utilises this a neural network, in particular, deep convolutional network with many layers. The network takes as an input $s$ of the game and the history leading to the current board and provides two probability distribution for the possible moves reachable from the current state, denoted as $P$, and the value of the current state $v$. The value is a scalar and reflects the probability for a current player to win the state $s$. We formally write the network as:

```
$$(P, v) = f_{\theta}(s), \quad (28.23)$$
```

where $\theta$ is a parameter set, and the probability $f_{\theta}$ of a given move $a$ to be extracted as:

```
$$$P_a = P(s, a). \quad (28.24)$$
```

The model $f_{\theta}$ was estimated from the record of games played by professional players. AlphaGo combines the two networks in the following manner:

- The algorithm starts at a root node equipped with $f_{\theta}$.
- The node has assigned prior probabilities for possible moves using $P(s_{root}, a)$, for all moves $a$, and every possible move gets a counter of visits $N(s_{root}, a)$, initialised at 0.
- Each simulation starts at the root node chooses a node $a$ that maximises the analogue to the UCT formula:

```
$$$a = \max_{a'} Q(s_{root}, a') + U(s_{root}, a'), \quad (28.25)$$
```

where $Q$ is an action-value and $U$ corresponds to the exploration function. It is further utilised that:

```
$$$U(s_{root}, a') = \frac{P(s_{root}, a')}{1 + N(s_{root}, a')}. \quad (28.26)$$
```

Since the value $v$ is noisy, the action-value is defined for any state $s$:

```
$$$Q(s, a') = \frac{1}{N(s, a)} \sum_{s'} v(s'), \quad (28.27)$$
```

## Towards AI – Monte Carlo Tree Search

When enough simulations have been played, AlphaGo chooses the move to make. By its nature, the more valuable moves are explored more frequently by the algorithm and thus assessing the final value for deciding which move to make is as:

$\pi_a \propto N(s,a)^{1/\tau}$

The nodes with higher Q are visited more frequently. The probability for a node to be proportional to the exponential of the number of visits of the node, raised to the inverse power of temperature $\tau$. With $\tau \to 1$, there is possible exploration when making a decision for $\tau \to 0$ only the node with the highest count of visits is chosen. This concludes AlphaGo.

The role of the MCTS algorithm is the policy improvement operator. The initial values of P are prior probabilities in the Bayesian sense, and the MCTS algorithm is the posterior distribution, which is usually better than prior values themselves.

## 28.4.2 Reinforcement Learning

AlphaGo Zero goes one step beyond AlphaGo; see Silver et al. (2017). It uses Reinforcement Learning technique, which allows the algorithm to learn the policy and value networks $f_0$ without a need for human input. The algorithm starts with the randomly initialized parameter $\theta_0$.

The neural network plays games with itself, in particular, with previous versions of itself. During the game, the neural network is re-trained on the evolution of a game. The game starts as a random game where only the first principles, i.e. the rules of the game, are used. From the random moves, the neural network learns values and various board setups. The algorithm learns to use patterns on the fly. The patterns are learned, they are used, and thus the algorithm learns to explore the ways to beat the patterns. This expresses the evolution learning cycle of the algorithm.

The algorithm does not need any human input. The role of the MCTS is exploring how to improve itself given the current knowledge. The reinforcement learning ensures that the algorithm learns from all playouts. By chance a good pattern is found out, the algorithm remembers it and learns to use it further. At the same time, it finds out not to be beaten by the player using the same pattern.

It is striking that starting with first principles, AlphaGo Zero has to learn all the patterns, tactics, and starting positions taught by the go masters. These patterns have been found out by the algorithm itself. Besides, new patterns have been explored and thus the AlphaGo Zero playouts have explored the textbooks. It is not without surprise that it is time for human players to make their move and reinforce their understanding of the game and learn from AlphaGo Zero.

### Economophysics: The Agent-Based Computational Models

In this chapter, we step outside the main scope of this book and illustrate the usage of models in the economophysics domain. This field is a fusion between theories developed in physics on social sciences and in particular in economics. The emergence of economophysics dates back to 1990s when some models from statistical physics were used to analyse data. A very nice introduction of the methods from this period can be found in a seminal review by Mantegna and Stanley (1999). The main reason why the field itself appeared is likely due to the emergence of large amount of financial data which required statistical methods.

It is worth noting that the influence of physics on finance appears before the 1990s. Among many achievements, we recall the utility-based theory developed by Bernoulli (2011), the theory of gravity of international trade developed by a trained physicist and the first laureate in Nobel Prize in Economics Jan Tinbergen, Tinbergen and Hekscher (1962), or the apparent resemblance of the famous Black–Scholes equation and the heat equation used for a long time in physics to describe heat conductors. The trend in merging physics and finance was further shown by the econometric physicist Jean-Philippe Bouchaud of the Year for 2016.

In terms of economics, the most prominent trace of physics in finance is the widespread use of the power-law behaviour, which tends to be closer to reality than the famous and easy-to-model exponential or Gaussian laws. The power-law stands for the relationship between two variables, where one variable is a function of the power of the other variable. Such a behaviour describes the distribution of many phenomena in biology or physics ranging from the activity patterns of neurons to the magnitude of earthquakes or solar flares. In particular, the power-law has been frequently used to model the distribution of price returns.

It is worth pointing out that in physics, the presence of the power-law in certain distributions is linked to phase transitions of the systems. The exponents of the power-law behaviour are referred to as critical exponents of the physical system. It was shown that systems with similar critical exponents represent the same dynamics. Besides, distribution-wise the power-law behaviour forms a set of different attractors for which the central limit theorem and law of large numbers may not hold.
