# Linear Regression

The in and out sample splitting can be done in two ways: if the inOutFlag variable is a scalar value, which is between 0 and 1. Then, it represents the proportion of the data which are taken in the sample or training sample. Data are taken from the beginning. By using the time series approach, the out-of-sample data is conventionally taken as the most recent. Then, the out-of-sample data is remaining piece of the data.

On the other hand, we can specify which data to take as in-sample and to take out-of-sample. In that case, the inOutFlag variable is an array of boolean indicators, where true stands for being included in the training, and false to be in the out-of-sample. The array is used in conditional evaluation, and thus 0 serves as false while non-zero values are considered as true.
