# Eigensystem and PCA

# Determinant

(discussed at the end of this chapter) of the matrix $\mathbf{A}$ can be written as:

$\det \mathbf{A} = \prod_{i}^{p} \lambda_{i},$

where $\lambda_{i}$ are eigenvalues of the matrix $\mathbf{A}$.

# Trace

of the matrix $\mathbf{A}$ can be written as:

$\trace \mathbf{A} = \sum_{i}^{p} \lambda_{i},$

where $\lambda_{i}$ are eigenvalues of the matrix $\mathbf{A}$.

# Hermitian

matrix $\mathbf{A}$, i.e. a matrix such that $\mathbf{A} = \mathbf{A}^*$, have all the eigenvalues real. If the matrix is positive-definite/ positive-semidefinite/ negative-definite/ negative-semidefinite/ every eigenvalue is positive/ non-negative/ negative/ non-positive.

# Unitary

matrix $\mathbf{A}$ has all eigenvalues modulo equal to 1.

# Power

of the matrix $\mathbf{A}$, i.e. $\mathbf{A}^{k}$, has the eigenvalues $\lambda_{1}^{k}, \lambda_{2}^{k}, \dots, \lambda_{p}^{k}$.

# Invertibility

of the matrix $\mathbf{A}$ is equivalent to a situation where every eigenvalue $\lambda_{i}$ is non-zero. Further, for an invertible matrix $\mathbf{A}$, the eigenvalues of $\mathbf{A}^{-1}$ are $\lambda_{1}^{-1}, \lambda_{2}^{-1}, \dots, \lambda_{p}^{-1}$. The algebraic multiplicity of the inverse eigenvalues coincides with the direct counterparts.

In the next section, we proceed with numerical algorithms to find the eigensystem. We focus on the QR algorithm to find the eigenvalues and the inverse iteration algorithm to find the corresponding eigenvectors.
