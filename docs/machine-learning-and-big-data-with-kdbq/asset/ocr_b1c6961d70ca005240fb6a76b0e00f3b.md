Ordering of points based on their distance to the point. depends on the value of parameter X. The third row is classified as the closest observation by choice of X=1 while the other measures classify the point as most distant. The choice of the parameter X may affect results, and its role has to be investigated.

We can proceed with construction of the k-nearest neighbour classifier. The implementation is in two steps:

+   * Identify the k neighbourhood of the test point.
* Classify the first step.

In the first step, we consider the given point and calculate the distance to every point in the training sample. Then, we select k points from the training sample which are closest to the given point. We have to store only the value of a dependent variable for every chosen point and the distance to the point. The following function captures such procedure:

```
quantQ.knn.kNNNighbours:[point;tableFunction;LX;k]
// point -- N-dimensional array
// tableFunction -- table with training data, first N-1
  // st is dependent
  // LX -- parameter of the distance measure
  // k -- number of nearest neighbours to be selected
  // return dictionary, with dependent variable (`f`) and distance (`dist`)
  // flipselect([k]) -- dist xasc
  ([[] : f: tableFunction[last cols tableFunction][cols[tableFunction
    except ([f;LX]);
```

The function takes four arguments: for point the neighbourhood is being sought, the training sample with data in the form of a table, the parameter of the distance measure, and the size of the neighbourhood to be returned. The output is a dictionary of classes and corresponding distances.
