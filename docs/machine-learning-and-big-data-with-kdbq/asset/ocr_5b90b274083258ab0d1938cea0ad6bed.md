# Fourier Transform

The function for the cross product takes as an argument full quaternions and ignores the real part of quaternions. In the output, the real part is set to zero by definition, and thus the real part does not affect the calculation:

```
.quantQ.quat.crossProduct:[quat1,quat2]
// qt1, qt2 -- quaternion
// the real part is ignored and in the output set to zero
// r*j*k(0;:qt1[j]*qt2[k])-(qt1[k]*k[j]);(qt1[k]*qt2[i])-
(qt1[i]*qt2[k]);
(qt1[i]*qt2[j])-(qt1[j]*qt2[i]);
;
```

We can calculate the product of two quaternions which have the real part:

```
r | 0
i | -0.5991493
j | 0.2462253
k | 0.3529241
```

where the real part has not been considered in the calculation as expected.
In order to develop reasonable calculus with quaternions, it is convenient to have exponential and logarithmic functions, as many functions can be expressed through them. The exponential function of a quaternion is defined as:

exp(q) = exp(a + bi + cj + dk) (15.45)

= \sum_{n=0}^{\infty} \frac{q^n}{n!} (15.46)

= exp(a)|cos|bi + cj + dk| + \frac{bi + cj + dk}{|bi + cj + dk|}sin|bi + cj + dk| (15.47)

where the term in the last row is the real part of the resultant quaternion while the term corresponds to the purely imaginary part of the quaternion. Implementing:

```
.quantQ.quat.exp:[quat]
// qt -- quaternion
realPart: qt;
imPart: r_qt;
newRealPart: enlist[r]!enlist cos sqrt imPart wsum imPart;
newImPart: $@normImPart: sqrt imPart+imPart; imPart; (imPart%
-- normImPart)
s[sqrt imPart+imPart]];
// return exp of quaternion
:exp[realPart]+newRealPart,newImPart;
;
```

and applying it to the two sample quaternions we have defined in the beginning:

```
.quantQ.quat.exp[quat1]
```
