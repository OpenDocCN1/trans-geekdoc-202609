# 10.2.1 Functional Select

First, let us focus on the functional select. Our objective is as outlined in the previous paragraphs, we want to be able to run select flexibly with arguments being chosen in the function. The functional analogue to select function is defined as:

```
?table;where;group;columns
```

where the four arguments are:

+   * referring to the table from which we want to select the data. The table is passed by reference or by value.
* contains the filter criteria on which to choose from the table. Its form is a list of criteria in parse tree form. The table columns are passed by reference.
* group dictionary of the column names upon which the table is grouped. By the keys are the new column names while values are formed of the old names.
* columns dictionary of columns to be chosen. The keys define the new names, e.g a;, while values correspond to the statements on the right-hand side of the assign operator, e.g. b+1. If an empty list is chosen, all columns are chosen.
