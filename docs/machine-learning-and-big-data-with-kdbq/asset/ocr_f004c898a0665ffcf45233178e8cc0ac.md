# 3.2.3 Compose (')

The composition of a multivalent function f[a;b;c;...] with a monadic function g[x], expressed mathematically as gof, is defined as ' [g; f]. For example:

```
f:[a;b;c;d]a+(2*b)+(3*c)+4*d);
g:(log x);
d:('[g;f]);
d[5;6;7;8]);

computes log(5 + (2 * 6) * (3 * 7) * 4 * 8) = log(70), which is returned:

4.284895
```

# 3.2.4 Over and Fold /

The over adverb / modifies a dyadic function to accumulate the results over a list. Let us denote yᵢ,i ∈ ⁿᵗ element of a list y of length n. The expression x/ y recursively applies the function f on x and each element of y, i.e., computes expression f[..;f[x;y₀];y₁];..;y₋₂];y₋₁].
The expression:

```
4f {x-y xexp 2)/(5 6 7f
```

is equivalent to:

```
(((4f-5f xexp 2)-6f xexp 2)-7f xexp 2
```

and returns:

```
-106f
```

The over adverb / can also be applied to monadic functions without specifying an accumulator x. The expression (f/ ) on the list computes nested functions f[..;y₀];..y₋₁]. Hence, the expression

```
{(x-y xexp 2))/(5 6 7f
```

computes:

```
5f-6f xexp 2)-7f xexp 2
```

and returns:

```
-80f
```

In prefix forms, the two previous expressions are written as follows:

```
{(x-y xexp 2)}/[4f;(5 6 7f)]
((x-y xexp 2)][(5 6 7f)]
```
