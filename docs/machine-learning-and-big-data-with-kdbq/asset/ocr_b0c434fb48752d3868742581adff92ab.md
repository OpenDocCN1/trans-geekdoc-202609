We can proceed to train the neural network. We start with a similar parametric set-up as the binary classification case. In particular, we choose 1 neuron in the hidden layer.

```
modelC1::quantQ.nn.modelNN[flip "f$(xC1;xC3;xC4); flip "f$(xC1;xC2;xC3-xC4);i;count;100;0.01;'linearReg];
```

The focus is on the evaluation during the iteration. The provided model does not converge, and thus the reader could realise the number of iteration steps would be too large. This brings a useful insight: we should start with a smaller case using a few iterations and investigate the evolution of the training. Then, the full-scale learning.

Figure 22.3 depicts the learning path as a function of the iteration index. Contrary to previous cases, we plot log of the error in order to envisage the divergence of errors. The model does not converge, and thus we have to change the parameters of learning. The suspected parameter to be changed is the learning rate which may be too coarse, thus usging from the optimal values.

The data for the figure has been extracted as:

```
select Counter, log Error from modelC1 i>0
```

Let us repeat the training of the model with smaller learning rate parameter, in case 0.01. We should run the model for 3000 steps:

```
modelC2::quantQ.nn.modelNN[flip "f$(xC1;xC2;xC4); flip "f$(xC1;xC2;xC3-xC4);i;count;3000;0.001;'linearReg];
```

Figure 22.4 depicts the learning path (error) as it progresses through the iterations. The procedure converges in this case; the model is learning. The improvement of the error is approximately 50%, relatively mediocre improvement compared to all previous cases where the improvement have been in the orders of magnitude. This confirms the failure to converge for large learning
