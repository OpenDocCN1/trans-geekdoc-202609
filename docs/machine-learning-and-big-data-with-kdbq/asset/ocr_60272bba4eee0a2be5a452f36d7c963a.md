# 542 MACHINE LEARNING

The multi-armed bandit problem is defined as follows. Imagine that you are at a casino where are some slot machines. You can play one slot machine at a time. You do not see the other players using the slot machines and their outcome. Each slot machine is different and may provide different pay-out. A question has to answer is the optimal strategy to follow once you decide to play. You can play every game on a randomly chosen slot machine, or stick to one slot machine at the time. The question is whether there exists a more profitable strategy to follow.

Let us practise the problem mathematically. Let us consider K distribution functions $P_1, P_2, \dots, P_K$ over real numbers. We define the probability distribution functions with random variables $X_1, X_2, \dots, X_K$. Each random variable $X_i$ has a mean $\mu_i$ and is assumed to be $\sigma^2$-Gaussian:

```
$E[exp(\lambda(X_i - \mu_i))] \le \exp(\left(\frac{\lambda^2\sigma^2}{2}\right)) \quad (28.1)$
```

for positive and real $\lambda$. The multi-armed bandit problem is an optimisation problem to find the index $i$ which gives the maximum mean $\mu_i$, evaluating the suboptimal choices as little as possible. The problem is by its iterative nature, where at time $t$, player chooses index $I_t \in \{1, 2, \dots, K\}$ and then observes reward $X_i(t)$. The reward is drawn independently from corresponding probability distribution $P_i$.

The multi-armed bandit problem is usually defined as minimisation of regret after $n$ steps:

```
\arg \min_{A} \sum_{j=0}^n (\mu_{j^*} - \mu_{A_j}), \ \quad (28.2)$
```

where $\mu_j$ is a mean of the optimal distribution, i.e. the distribution with the highest mean:

```
$j^* = \arg \max_{i} \mu_i. \quad (28.3)$
```

The strategy $A$ is the ultimate goal of the problem and it represents the collection of indices chosen in each step. The index may be iterated; i.e. in order to choose the j-th index, we know the pay-offs of steps up to $j-1$ step. The regret function:

```
$Reg_n = \sum_{j=0}^n (\mu_{j^*} - \mu_{A_j}) \quad \quad (28.4)$
```

is a random quantity. The mathematical theory solving the multi-armed bandit problem seeks to estimate the bounds in expectations. For that purpose, one often defines the expected regret:

```
$Reg_n = E[\sum_{j=0}^n (\mu_{j^*} - \mu_{A_j})] \quad \quad (28.5)$
```

The solution sought by many numerical algorithms to the multi-armed bandit problem is thus the zero regret strategy. It is a strategy whose average regret per round
