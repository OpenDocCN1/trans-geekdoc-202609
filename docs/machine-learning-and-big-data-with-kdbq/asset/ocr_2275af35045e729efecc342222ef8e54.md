# Fourier Transform

The variable $\zeta$ corresponds to frequency in suitable units. Let us further define the inverse DFT, which is transforming from the frequency domain into the time domain:

```
$f(t) = \int_{-\infty}^{\infty} f(\zeta)e^{2\pi i\zeta t}d\zeta. \quad (15.18)$
```

The definition above assumes that we are equipped with the full knowledge of $f$ across $(-\infty, \infty)$. In practical applications, we observe a finite sample $f_0, f_1, f_2,\dots,f_{N-1}$ of equidistant sample points of the process $f$. The sample points can be in general complex. The DFT can be thought of as a sequence $F_0, F_1, F_2, F_3,\dots,F_{N-1}$ given as:

```
$F_k = \sum_{n=0}^{N-1} f_n e^{\frac{2\pi kn}{N}}. \quad (15.19)$
```

The component of the DFT can be interpreted as a correlation of the input sequence with the complex sinusoid of frequency $\frac{k}{N}$. It filters out the frequency contribution to the given frequency amplitude. Furthermore, every coefficient $F_k$ is complex encoding $\frac{2ik}{N}$ the amplitude and phase of a complex periodic component $e^n$ of the original series. The DFT is defined on the domain $k \in 0, 1, \dots, N-1$. The transform can be extended over the domain, considering the sequence to be $N$-periodic, i.e. repeating every $N$ points.

Let us illustrate the DFT in an example. First, implement a function that takes a complex series and returns one of the DFT:

```
.quantq complex.dft:[complex n;k]
// series of complex numbers
// n length of the series
// til index of the series
// k coefficient of the DFT coefficient
:sum: .quantq.complex.mult[csx;flip] .quantq.complex.realExp neg (2 *
  .quantq.pi * k * til)
);
```

and then iterate to get the full set of DFT coefficients:

```
.quantq.complex.dft:[csx]
// series of complex numbers to be transformed
::quantq.complex.dft[n til N] peach count csx;
);
```

Note the use of peach to provide multithreaded processing when querying with slave threads (q - s n).
