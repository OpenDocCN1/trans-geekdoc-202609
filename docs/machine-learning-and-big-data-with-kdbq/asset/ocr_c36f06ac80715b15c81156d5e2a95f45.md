# Basic Overview of Statistics

Our motivation is to form a hypothesis about the population mean inferred from the observed sample. The statistical procedure to achieve this objective is to use t-test.
In general, t is a statistical hypothesis test where the test statistics under the null hypothesis follow t-distribution. t-distribution is parameterised by one parameter, n denoted degree of freedom. For n ∞, the distribution converges to a normal distribution, while for n small, the distribution is fat-tailed.
Example of such a t test is the following:

```
t = \frac{\bar{X} - \mu}{\sqrt{N}}
```

\bar{X} is the sample average. The statistic under the null hypothesis is distributed as t ~ tn; these can be used in the following statistical test about the population average:

+   - $H_0$: The population mean is μ (given the sample size N and population standard deviation σ).
- $H_1$: The population mean is different from μ.

The test is inconvenient as it requires knowledge of a population standard deviation. This is, in practice, is hardly known and such an assumption in data analysis cannot be made. Fortunately, the t-statistic can be modified so that we can replace knowledge of population standard deviation by its estimator:

```
t' = \frac{\bar{X} - \mu}{s}
```

s is the standard deviation of the mean defined as:

```
s = \frac{1}{\sqrt{N}} \sqrt{\sum_{i=1}^{N} (x_i - \bar{X})^2}
```

Note that there is a factor 1/√N in the free square root.
The adjusted statistic t' ~ t_{N-1}. The estimator of the standard deviation of the mean cost use one of freedom. The word "cost" is used as it worsens the asymptotic behaviour and makes the statistics further from the normal distribution.
We can form the following hypotheses to test the t' statistic:

+   - $H_0$: The population mean is equal/smaller or equal/larger or equal to μ, given the sample size N.
- $H_1$: The population mean is different/larger/smaller relative to μ.

The three tests, i.e. a two-sided and two one-sided tests, can be assessed as follows: we reject the null if |t'| > t_{critical,N-1}, t' < -t_{critical,N-1}, respectively. The critical value t_{critical,N-1} depends on the significance level. In the subsequent part, we will assume the asymptotic limit holds and use the normal distribution to derive the critical values.
