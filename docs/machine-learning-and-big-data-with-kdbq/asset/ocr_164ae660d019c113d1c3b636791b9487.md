$\Sigma_{u} \otimes (ZZ')^{-1}$. Assuming that $y_i$ is Gaussian, an approximation of a $(1-\alpha)$ interval forecast-step ahead for $k$-th component is $\hat{y}_k(h) \pm z_{\langle\alpha/2\rangle}\hat{\delta}_k(h)$; $\hat{\delta}_k(h)$ is the square root of the $k$-th diagonal element of $\hat{\Sigma}_u(h)$ and $z_{\langle\alpha/2\rangle}$ is the $(\alpha/2)$-th quantile of the normal distribution.

```
$$\hat{\Sigma}_u(h) = \hat{\Sigma}_u(h) + \frac{1}{T}\hat{\Omega}(h)$
$$\$\hat{\Omega}(h) = \sum_{i=0}^{T-1}\sum_{j=0}^{h-1}tr((B')^{h-1-i}B^{h-1-j}\hat{\phi}_i'\hat{\phi}_j)$$
```

with $\Gamma=E[Z,Z']$, $\phi_i=J_iB_i'$, $J_i=[O_{kX1} : I_K : O_{kX1} : \dots : O_{kX1}]$ a $K \times (Kp+1)$ matrix.
choosing an unusually large value of $p$ reduces the forecast precision model. $Y$ is called a VAR(p) process if $A_p \neq 0$ and $A_i=0$ for $i>p$ so that p is the smallest possible order. The likelihood ratio statistic determines the correct VAR order by testing the significance of coefficient $\Lambda_m$ of an upper bound VAR model. The null hypothesis $H^{M-m-1}: A_m=0$ versus the alternative hypothesis $H^{M-m-1}: A_m \neq 0$ is tested for decreasing values of $m \in[M, M-1, \dots]$ conditioned on the previous values being true. If $H_0^{M-m-1}$ is rejected, the order $\hat{p}$ is chosen as the optimal order of the VAR process. The likelihood ratio test for testing the $M-m-1$-th hypothesis solves:

```
$$\lambda_{LR}(M-m-1) = T[\log det(\Sigma_u(m-2)) - \log det(\Sigma_u(m-1))]$
```

where $T$ is the length of the time series and $\Sigma_u$ is the least square estimator

```
$$\Sigma_u = \frac{1}{T}(Y_T-Z')(ZZ')^{-1}Y$.
```

The likelihood ratio test $\lambda_{LR}$ follows a $\chi^2$ distribution with $K$ degrees of freedom.
