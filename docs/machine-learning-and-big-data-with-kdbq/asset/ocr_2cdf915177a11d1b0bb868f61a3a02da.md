Take/reshape
The symbol # creates a list from the data provided on the right-hand side of # with a
dimension specified on the left-hand side. The basic specification is such that the left-
hand argument is an integer and the right-hand side argument is a vector. # takes
t first elements of the vector, as specified by the first argument:

```
3#1 2 3 4 5 6
```

```
1 2 3
```

If the first argument is negative, # takes the specified number of elements from the end
of the vector:

```
-31 2 3 4 5 6
```

```
4 5 6
```

If the provided vector is shorter than the length demanded by the integer, the array itself
will be repeated:

```
3#1 2 3 4 5 6
```

```
1 2 3 4 5 6 1 2 3 4 5 6 1
```

thus, the output has the length specified by the argument.
The symbol # can also reshape the array. If the left-hand argument is a two-
dimensional array, the output is a matrix with dimensions specified by the arguments
formed of an array on the right-hand side, where the vector itself may be repeated:

```
3 #1 2 3 4 5 6
```

```
(1 2 3; 4 5 6; 1 2 3)
```
