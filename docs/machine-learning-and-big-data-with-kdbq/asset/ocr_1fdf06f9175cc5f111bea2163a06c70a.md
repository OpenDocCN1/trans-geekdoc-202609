The k-fold cross-validation works as follows:

+   - Set the parameter $k$.
- Split the sample into $k$ equally sized parts. Parts are non-overlapping and cover the entire sample. We index them as $Data_j$, with $j=1,\dots,k$, such that $Data = \sum_j Data_j$.
- For $i=1,\dots,k$:
    - Define $Data_{in}$ and $Data_{out} = Data_i$.
    - Estimate the model on $Data_{in}$ and verify on the $Data_{out}$.
    - Get the correctness $RMSE_i$.
- Calculate the average $RMSE_{CV} = \frac{1}{k}\sum_i RMSE_i$.

We judge the model on the cross-validated $RMSE_{CV}$.
We implement the k-fold cross-validation in the following function. It runs in the same manner as the lsoOut function. The third parameter is an integer denoting the number of cross-validation folds:

```
quant0.ols.cv([y;nCV])
 // y array of dependent variables
 // x array of arrays of independent variables, constants has to // included
 // nCV number of Cross-validation folds
whereMissing:raise(where y<0; raise where x=0 each x);
 // remove the missing values
y:(til count y) except whereMissing)
 x:([whereMissing;x] x:(til count x) except whereMissing)][whereMissing;]
 // create all the Flags for every fold
foldFlag:(floor til[count y]%y%%nCV)=:til nCV;
 // return list of corresponding RMSEs
(:quant0.ols.out[y;x]; each foldFlag)[RMSE];
;
```

The function returns an average of k RMSEs:

```
cvEx:quant0.ols.cv[tabData[y],tabData[`x1*x2*x3`];12]
```
