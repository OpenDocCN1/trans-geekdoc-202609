The second function we need to define is the quaternion logarithm. The function reads:

> $log(q) = log|q| + \frac{bi+cj+dk}{|bi+cj+dk|} arccos \frac{a}{|q|}$ (15.48)

and is provided in the next display:

```
.quantQ.quat.log[[qt]
// qt -- quaternion
realPart: qr;
imPart: qr;
// exp of quaternion
newRealPart: enlist[r]!enlist log .quantQ.quat.norm qt ;
newImPart: $0=normImPart:sqrt sum imPart*imPart;0.*imPart;
(imImPart%normImPart)*acos[realPart %quantQ.quat.norm qt];
newRealPart,newImPart;
```
