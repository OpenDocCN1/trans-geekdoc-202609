# 10.2.4 Functional Delete

The functional version of delete is:

![table;where;ob;columns]

where the four arguments are slightly different now:

+   - table referring to the table from which we want to update. The table is passed by value.
- where contains the filter criteria on which rows to choose from the table. Its form is a list of criteria in parse tree form. The table columns are passed by reference.
- group is false ob.
- columns list of columns has to be chosen.

The function symbol ! is same as in functional update. In order to achieve the delete functionality, either where or columns to be empty. Let us illustrate the functionality ahead:

```
![tab;enlist(;`a;4);ob;symbol($) ~ delete from tab where a>4
```

```
![tab();ob;`a-c ~ delete a,c from tab
```

This concludes the functional form of SQL operations. Throughout the text, we use such operations. We tend to stick to qSQL syntax as it is more accessible. We encourage readers to replace such operations by their functional counterpart when a generalised is required.
