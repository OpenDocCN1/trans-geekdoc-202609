## 11.1 ROLLING VWAP

The first example originates in high-frequency finance. Any update in the market will result in an update (tick) in our data. It is of fundamental importance for any market participant to understand the current state of the market. For various statistics and indicators are needed to monitor market activity. Let us assume that we wish to calculate moving VWAP (Volume Weighted Average Price) over a rolling window. We will cover two use cases.

### 11.2 Time VWAP

For a moving time-window VWAP, to do this we use the asof function, specifically to aggregate over a sliding window of, say, 1 hour. This is a similar use case we see in Chapter 7. We use asof1 because we want the values in the 1-hour window prior to each record, without including the as-of value at record's time:

```
vwap: asof1[-1h;0; exec time from trades;
  select code, time, price, volume from trades;
  (select code, time, val: price * volume, vol: volume from trades) / (sum`vol)]
```

We examine the result of the window join:


## 11.2 WEIGHTED MID FOR N LEVELS OF AN ORDER BOOK

Let us recall that in market, the interest in buying an asset or a realized trade of a certain amount of the underlying asset is as quote or a trade respectively. Our previous example saw how to calculate an N-tick moving VWAP. In contrast, the quote data usually represents the state of a limit order book (LOB): the limit order book stores the market interest in buying and selling expressed as a list of prices and corresponding amounts. When analyzing the LOB, a standard extension to the top-of-book mid, i.e. the point equidistant between the best bid (higher price) and ask (lowest price), the weighted mid can take into account the size which is placed on each side and is therefore, a weighted average. In our case below we generalize this concept to include two levels, i.e. the best and second-best prices, respectively. In other words, we calculate the weighted mid at time as:

```
WMID_i = \frac{\sum_{j=i-N}^{i} bidSize_{i,j} \times bid_{i,j} + \sum_{j=i-N}^{i} askSize_{i,j} \times ask_{i,j}}{\sum_{j=i-N}^{i} bidSize_{i,j} + \sum_{j=i-N}^{i} askSize_{i,j}}
```

where N=2, in our case creates a quote with 2 levels of depth:

```
n: 10;
quote: ([sym] time:n; bid1: n?100; bidSize1: n?100; bid2: bid1+.1*n, bidSize2: n?100;
ask1: bid1-.1*n, askSize1: n?100; ask2: ask1+.2*n, askSize2: n?100) from quote;
```
