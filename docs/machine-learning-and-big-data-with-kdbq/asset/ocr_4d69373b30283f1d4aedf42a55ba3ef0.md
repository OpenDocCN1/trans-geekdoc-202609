We use the QR decomposition to obtain the eigenvalues. The QR algorithm is an iterative process that iteratively employs the QR decomposition and updates the matrix. First, the input is a dictionary with a matrix, which is input into the function QRdecomp. In the beginning, the input matrix is being read. The QR upper triangular matrix and the transposed orthogonal matrices. The QR decomposition is found and the new iterated matrix is calculated as a product of the two matrices. Beside, it contains counter to be able to control the iterations:
