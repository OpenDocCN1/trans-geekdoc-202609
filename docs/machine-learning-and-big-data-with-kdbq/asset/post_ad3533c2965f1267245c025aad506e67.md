# Functions

q defines the following function types:

- operators and primitive functions
- q-SQL functions, as described in the previous chapter, e.g. select, update, upsert
- user-defined functions
- derived functions, with the use of *.

All predefined q can be used in both infix and prefix notations, whereas user-defined functions must be called using a prefix notation. For example, the dyadic operator (function) + can be written as follows:

```
5 + 7 // infix notation
+[5;7] // prefix notation
```

> A function is delimited with open and closed brackets { }. The optional arguments of the function are defined-in-square brackets separated with semicolon; [arg1;arg2;...;argn] at the beginning of the function. Function x, y and z are implicitly defined. Functions can have a name with assignment : as variables. A function returning the square of a number is defined as:

```
{x*x}
```

Hence,

```

```

# 3.1 NAMESPACE

A namespace is a context within which a name resolves to a unique value. Functions and variables are defined in a namespace as follows:

```
.namespaceName.variableName
```

Hence the variable x and function f defined in namespace1 and namespace2 have different values:

```
.namespace1.x:4;
.namespace1.f:{5+x};
.namespace2.x:5;
.namespace2.f:{1+log x};
```

> We can call f from the two different contexts as follows:

```
.namespace2.f[.namespace1.x] // returns 1+log 4
```

and

```
.namespace1.f[.namespace1.x] // returns 5+4
```

# 3.2 THE SIX ADVERBS

kdb+ has nouns, verbs and adverbs. Functions and data objects are nouns. Verbs are syntactic sugar introduced to improve the readability of the language. They allow for infix notation to reduce the number of square brackets and parentheses in expressions. Arithmetic and logical operators over dyadic functions written in infix notation are verbs. Here, the verb * is:

```

# 3.2.1 Each

The "each" adverb comes in several forms. each modifies monadic functions, i.e. functions with valence of one. The more general each-both, denoted ` modifies dyadic — or more generally, polyadic functions provided that all arguments have equal length. Each-left and each-right, denoted by \: and /, respectively, are two other forms for each dyadic functions. A combination of each-left and each-right provides the cross product.
