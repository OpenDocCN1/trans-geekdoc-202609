The QR algorithm as intuitive is built upon the Givens rotation. We implement a function, which takes four arguments: the dimension of the matrix, the two coordinates i and j, and the angle of rotation θ, and returns the matrix with Givens rotation:

```
.quantQ.mat.givensRotation:[dimM;i;j;theta]
// dim1 -- dimension of the matrix
// i -- dim to dim-1
// j -- dim2 to dim-1
// theta -- angle of rotation
// unit matrix
givens:quantQ.mat.diagMatrix[dimM];
// insert cos
givens[i;i]:cos[theta];
givens[j;j]:cos[theta];
```

### 16.3.1 QR Decomposition

Let us proceed with the QR decomposition. Function QRdecomp implements the procedure. The input is the matrix we wish to decompose. The outcome of the function is three matrices: the original matrix, the rotated matrix, and the rotation matrix. The function itself iterative procedure, we iterate over all coordinates that need to be set to zero. We kept the iteration within the main function and not separated it. The reason it is important to run the function as defined. We stressed that in the description of the algorithm.

```
quantQ.mat.QRdecomp:[mat]
// input matrix
// calculate dimension of the matrix
dimM:count[mat]
// list of coordinates to iterate over
coord: range[[dimM;x]] {{x;y] (y;x)}'[t where x<t:reverse til dimM]][dimM]; each til dimM;
// inputmatrix
inputMat:mat;
// initialised rotation matrix
rotMat::quantQ.mat.diagMatrix[dimM]
// counter for bucket
counter:;
```

```
We use QR decomposition to obtain eigenvalues. The QR algorithm is an iterative process that iteratively employs QR decomposition and updates the matrix. First, the input is a dictionary with matrix, which is input into QRdecomp. In the beginning, the input matrix is read. The QR upper triangular matrix and orthogonal matrices. The QR decomposition is found and the new iterated matrix is calculated as product of two matrices. Beside, it contains counter to be able to control:

```
.quantQ.iterQR:[bucket]
// bucket contains matrix and counter
// QR decomposition
bucketTMP: quantQ.mat.QRdecomp[bucket[`matrix`]]
// define Q and R
Q: flip bucketTMP[`rotationated`]
R: bucketTMP[`rotationMatrix`]
// define new matrix, similar to original
bucket[`matrix`]: R mmu Q;
// increase counter
bucket[`counter`]:bucket[`counter`]+1
// return bucket
bucket:
};

## 16.3.2 Inverse Iteration

At this step, we are equipped with the eigenvalues calculated by the QR algorithm. We will now implement the inverse iteration algorithm, which will for every eigenvalue numerically recover the eigenvector.

First, we define an Li matrix norm, which we need within the algorithm:

```
.quantQ.mat.normL1::[matt]
// matt -- matrix
// return L1 (column norm)
:max sum abs matt;
;
```
