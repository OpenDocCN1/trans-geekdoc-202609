b | 0D00:01:00.000000000 |

The # (take) function is, therefore, naturally extended to dictionaries and tables. So apart from just taking the first n elements of a vector, it can select a subdomain of keys of a dictionary or columns of a table. In fact it can also apply to a superdomain of dictionary's keys:

```
`sym`pricesomecol` 0
```

| sym | a |
price | 10f |
somecol |
