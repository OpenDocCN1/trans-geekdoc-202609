# Regression

Finally, we utilise the neural network for regression. The output of the neuron is a simple pass by the input argument:

```
.quantQ.nn.linearNN:([arg]
// arg -- input argument
:arg;
;
```

with the corresponding squared error function:

```
.quantQ.nn.linearNNErr:([argX;argY]
// argX -- true value
// argY -- predicted values
:sum sum z*(argX-argY);
;
```

Finally, we wrap the functions and the error function into two dictionaries. We will call calling functions based on the purpose the neural network is used for, i.e. as a `classifier`, `multiClassifier` or `nonlinearReg`:

```
.quantQ.nn.funcNN: `classifier` `multiClassifier` `nonlinearReg!
  (quantQ.nn.sigmoid;quantQ.nn.softmax;quantQ.nn.
  --linear);
```

```
.quantQ.nn.funcNNErr: `classifier` `multiClassifier` nonlinearReg!
  (quantQ.nn.sigmoidErr;quantQ.nn.softmaxErr;quantQ.
  --linearNNErr);
```

The purpose of dictionaries is to put the functional forms under the surface and make them more convenient for users.

## 22.2.3 Training the Neural Network

We can proceed with implementing the training procedure for the neural network itself. At the beginning of the iteration procedure, we need to initialise the parameters of the neural network. Function weightNNInit takes arguments: the size of the input nodes, argIn, and the size of the layer, argOut. The output is the array for a given layer, where every parameter is initialised as a random number from U([0,1]);

```
.quantQ.nn.weightNNInit:([argIn;argOut]
// argIn -- number of input arguments
// argOut -- number of output arguments
: flip flip[weights]-avg weights:({x;y*?1.0}[argOut])each argIn;
;
```

We define one iteration of the gradient descent update. It takes the function forwardBackwardNNError performs one iteration. It takes the following arguments: the input and output arrays, inputValue and outputValue, respectively, learningRatio being the constant learning rate, func standing for the type of the problem to solve in order to choose a correct function for the neuron and the gradient of the error (choose from three options `classifier`, `multiClassifier`, and `nonlinearReg`, respectively), and dictionary of parameters, which are updated during iteration. The dictionary contains `out`, parameters of the hidden layer and `parHid2out`, `parIn2Hid`, respectively, from the Loss function, `Error`, and a counter of iteration.

```
quant_q.forwardBackwardnNwError:[inputValue;outputValue;learningRate;;
// func;params]
// inputValue -- array of input values
// outputValue -- array of output values
// learningRate -- learning rate for update
// purpose of the NN `classifier`multiClassifier`nonlinearReg
// params -- bucket of parameters to be updated
// Forward stage
// mapping Input -> using current parameters
hiddenLayer.i/:quant_q.sigmoid(inputValue params[`parIn2Hid`]);
// mapping Hidden -> using current parameters
outputLayer:=quant_q.funcNN[func][hiddenLayer params[`parHid2Out`]];
- Backward stage
// error -> Output
deltaLayer2H:(outputLayer-outputLayer);
// error Input -> Hidden
deltaLayer2H./:[$deltaLayer2H:flip params[`parHid2Out`]+hiddenLayer
HiddenLayer;
// updating the model
:`out`parHid2Out`parIn2Hid`Error`(outputLayer;params[`
-parHid2Out`parIn2Hid`Error+learningRate*
-flip[inputValue] mmu
deltaLayer2H;quant_q.funcNN[func][outputValue;outputLayer];
-params[`Counter`]];
```

The hidden layer uses the default sigmoid activation function. This can be easily changed by modifying the definition of hiddenLayer and deltaLayer2H accordingly. The function performs three steps. The first step is by propagating the input value through the network by stacking the layers atop each other. Then, the error is recorded and propagated back, keeping track of the gradient in each node. Finally, the parameters in dictionary params are updated and iteration is concluded.

We wrap the iteration step into the complete function modelNN. Similarly to one iteration step, the function has a number of input arguments to be specified: the input and output arrays, input and output, respectively; the number of neurons of the hidden layer, nNeurons; for the control of the terminal condition and corresponding parameter of the terminal type, Terminal and argTerminal; a binary variable to track the progress during convergence, monitorConvergence; and specification of the problem, func (choose from three options `classifier`, `multiClassifier`, and `nonlinearReg`, (respectively).

There are two terminal conditions supported: `count`, for a case where provided number of iterations is performed, and `relativeError`, being the required minimum error to be achieved during the convergence process. The function is implemented as follows:

```
quantq0.modelNN:[input,output,nNeurons;typeTerminal;argTerminal];
// input -- array of inputs
// output -- array of outputs
// nNeurons -- number of neurons in hiddn layer
// typeTerminal -- type of terminal condition: `count`relativeError
// argTerminal -- type of terminal condition
// learningRate -- learning rate for update
// purpose of the NN `classifier`multiClassifier`nonlinearReg
// params -- bucket of parameters to be updated
// Forward stage
// mapping Input -> using current parameters
hiddenLayer.i/:quant_q.sigmoid(inputValue params[`parIn2Hid`]);
// mapping Hidden -> using current parameters
outputLayer:=quant_q.funcNN[func][hiddenLayer params[`parHid2Out`]];
// Backward stage
// error -> Output
deltaLayer2H:(outputLayer-outputLayer);
// error Input -> Hidden
deltaLayer2H./:[$deltaLayer2H:flip params[`parHid2Out`]+hiddenLayer
HiddenLayer;
// updating the model
:`out`parHid2Out`parIn2Hid`Error`(outputLayer;params[`
-parHid2Out`parIn2Hid`Error+learningRate*
-flip[inputValue] mmu
deltaLayer2H;quant_q.funcNN[func][outputValue;outputLayer];
-params[`Counter`]];
```

### 22.3.1 Binary Classification

We test the binary classification on the following setup. We consider four features. Each feature can take two values. The operation would be XOR:

```
$y = XOR(x_1, x_2, x_3, x_4) = \begin{cases} 1, & \text{if } x_1 + x_2 + x_3 + x_4 = 1 \\ 0, & \text{otherwise}\end{cases}$
```

where $x_i$ are variables taking $[0, 1]$. Instead of using the range of variables as $[0, 1]$, we define variables to be taking $[-1, 1]$. Value of $-1$ corresponds to *false* while $1$ is *true*. We define them as:

```
xA1:500?-1 1;
A2:500?-1 1;
A3:500?-1 1;
A4:500?-1 1;
```

and define the dependent variable as being *true* when sum of the four features is $-2$, which corresponds to XOR function:

```
yA?:(neg [2]=xA1+xA2+xA3+xA4;1;0];
```

The probability of observing true value of $yA$ is $p = 0.25$, as can be verified by simple algebra. We can verify this assertion by:

```
sum yA
```

Having the data set comprising four features xA1, xA2, xA3, and xA4, and dependent variable yA, we can train the neural network. We use 6 neurons in the hidden layer (excluding bias), which exceeds the dimension of the features. As a terminal rule, we use `count` and 1000 iterations. The learning rate is 0.01, and we monitor the output of every iteration step. Further, the problem is binary classification, which has to be specified as a last argument for the function. The following calls invokes the learning of the neural network:

```
modelA::quantQ.nn.modelNN[flip `f$(xA1;xA2;xA3;xA4);yA;6`;`count --1000;0.01;`classifier`];
```
