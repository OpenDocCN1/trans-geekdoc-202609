# Linear Regression

In this chapter, we introduce the notion of linear regressions and implement within q. The linear regression model should be a starting point for nearly any problem where we want to establish a relationship between factors on one side and a dependent variable on the other side. The linear regression is close to understanding the correlation between variables. Why do we start with linear models which model the linear response of the system? The straightforward answer in the spirit of the famous physicist and Nobel prize winner Richard Feynman is "because we can solve them".

Linear regression corresponds to the modelling of a function based on the first-order Taylor expansion in the vicinity of a point $x_0$:

```
$f(x) = f(x_0) + \sum_{i=1}^n \frac{\partial}{\partial x_i}f(x_0)(x_i - x_0) + residual, \quad (13.1)$
```

which can be ultimately recast into a linear model

```
$f(x) \approx A_0 + A_1X_1 + A_2X_2 + \cdots + A_nX_n, \quad (13.2)$
```

where

```
$A_0 = f(x_0) + \sum_{i=1}^n \frac{\partial}{\partial x_i}f(x_0)(-x_i),$

$A_1 = \frac{\partial}{\partial x_1}f(x_0).$
```

In physics, making a linear approximation a suitable tool to start to explore a new physical problem or to explain an observed phenomenon. Since we have mentioned Richard Feynman, Veltman et al. (1994) for instance, Feynman diagrams for describing the interaction of the subatomic particles are a pictorial representation of an expansion of the interacting Hamiltonians in a small parameter (known as a perturbation expansion). The linear term in the expansion often provides enough insight to make reasonable physical assertions.

## 13.1 LINEAR REGRESSION

Let us start with the definition of the linear regression model. We use the matrix form to present the model. Let us denote $n \in \mathbb{N}$ as the number of data points, $p \in \mathbb{N}$ as the number of features, and $i \in [1, \dots, n]$ of observations. The true underlying data generating process reads

```
$y_i = \beta_1 x_{i1} + \dots + \beta_p x_{ip} + \epsilon_i, \ (13.3)$
```

where the variables in the equation are:

- $x_i$ are referred to as the inputs, or also regressors, independent variables, or explanatory variables.
- $y_i$ are referred to as the outputs, or also regressands, or dependent variables.
- $\epsilon_i$ are referred to as disturbance, or also noise, or error terms.

### Linear Regression

We can represent the model analogously in the matrix form:

$y = \begin{pmatrix} y_1 \\ y_2 \\ \vdots \\ y_n \end{pmatrix}, \quad X = \begin{pmatrix} x_{11} & x_{12} & \dots & x_{1p} \\ x_{21} & x_{22} & \dots & x_{2p} \\ \vdots & \vdots & \ddots & \vdots \\ x_{n1} & x_{n2} & \dots & x_{np} \end{pmatrix}, \quad \beta = \begin{pmatrix} \beta_1 \\ \beta_2 \\ \vdots \\ \beta_n \end{pmatrix}, \quad \varepsilon = \begin{pmatrix} \varepsilon_1 \\ \varepsilon_2 \\ \vdots \\ \varepsilon_n \end{pmatrix}. \ (13.5)$

The value of $p$ determines the notation: $p=1$, the model is referred to as simple linear regression, while for $p>1$, the model is referred to as multivariate regression. Variables $y$ and $X$ are given, i.e. they are arranged in vector and matrix, respectively. On the other hand, $\varepsilon$ is composed of random variables.

Let us focus on the error terms and the nature of disturbance and residuals. Notice that in (13.4), the term $\varepsilon$ is a random variable modelling the difference between regressor $y$ and deterministic function $X\beta$. Since $y$ depends on $X$, it is a random variable. When we are given $y$ as well as $X$ as data, then we compute

```
$\varepsilon = y - X\beta. \ (13.6)$
```

which we call the residual. Confusingly, use the same notation for $y$ when it is fixed sample while the residual is deterministic. Eq. (13.6) is all well, but we need to find a "good" estimate for $\beta$, say $\hat{\beta}$. In the given data $y$ and $X$, we need to fit the regression model and Eq. (13.6) is actually wrong; it should be

$\varepsilon = y - X\hat{\beta}. \ (13.7)$

It remains to define the notion of "good fit". We do that by minimising a suitable function of residuals, which has meaning of loss between features and dependent variables. This brings us to ordinary least squares methods.

## 13.2 ORDINARY LEAST SQUARES

In order to formulate the ordinary least squares, we have to make several assumptions:

- for all $i \in [1,\dots,n]$, $\varepsilon_i$ have a mean of zero, $E[\varepsilon_i] = 0$;
- for all $i \in [1,\dots,n]$, $\varepsilon_i$ have the same variance, $Var[\varepsilon_i] = \sigma^2 < \infty$, in other words, the random variables $\varepsilon_i$ are homoscedastic;
- for all $i, j \in [1, \dots, n], i \neq j$, the $\epsilon_i$ are uncorrelated, $Cov[\epsilon_i, \epsilon_j] = 0$;
- the regressors are non-random and observable;
- the regressors are not perfectly correlated with each other.

The ordinary least squares, or OLS, is constructed as follows: we aim to find such $\beta$ in

```
$y = X\beta + \epsilon, \ (13.8)$
```

which will minimise a certain loss function of the residual $\hat{\epsilon} := y - \hat{y}$. We use the squared error, which we'll now call the residual sum of squares (RSS)

```
$RSS = \hat{\epsilon}^T\hat{\epsilon} = (y - X\hat{\beta})^T(y - X\hat{\beta}). \quad (13.9)$
```

We will refer to the estimate as $\hat{\beta}$ that will give us the estimate of $y$,

```
$\hat{y} := X\hat{\beta}. \ (13.10)$
```

The OLS estimator is given as:

```
$\hat{\beta} = (X^TX)^{-1}X^Ty. \ (13.11)$
```

We can prove this by first rewriting the RSS:

```
$RSS = \hat{\epsilon}^T\hat{\epsilon} = (y - X\hat{\beta})^T(y - X\hat{\beta}) = y^Ty - 2y^TX\beta + \beta^TX^T\beta. \quad (13.12)$
```

Using the denominator for vector-vector and scalar-by-vector derivatives,

```
$\nabla_{\beta}RSS = \frac{\partial RSS}{\partial \beta} = -2X^Ty + 2X^TX\beta. \quad (13.13)$
```

When $\nabla_{\beta}RSS = 0$, we get $X^TX\hat{\beta} = X^Ty$ (this is the so-called normal equation), we obtain the solution $\beta = (X^TX)^{-1}X^Ty$. To check that this critical point is a minimum, we examine the Hessian matrix

```
$\frac{\partial}{\partial \beta} \left(\frac{\partial RSS}{\partial \beta}\right) = 2X^TX. \quad (13.14)$
```

If $X$ is full rank (i.e. has $p+1$ if we allow the intercept and $p$ if we don't; if $X$ is skinny or square), then $X^TX$ is positive definite and the critical point is indeed a minimum.

The important feature of the OLS estimator is that it is unbiased, i.e. conditional expectation of the estimator is its true value:

```
$E[\hat{\beta} | X] = E[(X^TX)^{-1}X^Ty | X] \quad (13.15)$
```

```
= (X^TX)^{-1}X^TE[y | X] \quad (13.16)$
```

```
= (X^TX)^{-1}X^T\beta = \beta. \quad (13.17)$
```
