
# Basic Overview of Statistics

alternative for paired t-tests cannot be assumed to be normally distributed. The test is used for paired samples, i.e. samples which are related, or repeated draws. The observations in pairs come from the same distribution, we can order the pair, and each pair is randomly and independently drawn. The Wilcox test states the following null and alternative hypotheses:

- $H_0$: The difference within the pair follows a symmetric distribution centred around zero.
- $H_1$: The difference within the pair does not follow a symmetric distribution centred around zero.

Consider the sample with related pairs $(x_i, y_i)$, with $i = 1, \dots, N$. Define the difference within i-th pair as $\delta_i = x_i - y_i$, and the sign of the difference $s_i = \text{sign}\delta_i$. Further, before we construct Wilcoxon statistics, we filter out cases with $x_i = y_i$. Let us denote the subsample without ties as $(x_i, y_i)$, with $i=1, \dots, N'$ and $N \ge N'$.

Then, we calculate the Wilcoxon statistics:

```
$W = \sum_{i=1}^{N'}(s_i \cdot r_i), \quad (12.26)$
```

$r_i$ is the rank of the i-th pair, where differences have been sorted based on the absolute value of their difference, $\delta_i$, with ties getting the average rank of the respective group.

The Wilcoxon statistic, $W$, under the null hypothesis the underlying distribution with mean 0 and variance:

```
$\sigma_W^2 = \sqrt{\frac{N'(N'+1)(2 \cdot N' + 1)}{6}} \quad (12.27)$
```

For small samples, the reader has to consult with Wilcoxon to find critical values. We reject the null hypothesis (of a two-sided test) if $|W| > W_{critical}$, with $W_{critical}$ being critical at a given confidence level.

For $N'$ large, the distribution of the $W$ statistics follows a normal distribution. We normal $W$ by its standard deviation $\sigma_W$, we get $W/\sigma_W \sim N(0,1)$. In such a case, we can use critical values from a standard normal distribution.

The Wilcoxon test is implemented in function wilcoxTest. It accepts two arrays x1 and x2, respectively to x and y. The function calculates various outcomes in the dictionary: Wilcoxon statistic W, size of standard deviation $\sigma_W$, and normalized Wilcox statistic $W/\sigma_W$:

```
quant.stats.wilcoxTest:{x1;x2}
// x1,x2 -- arrays of sample 1 and 2, respectively, of the same length
// the test is interpreted as a table
intTab:{[]x1;x2}
// abs diff and the sign of the difference
intTab: update absDif[x1-x2]; signum[x1-x2] from intTab;
```
