In order to answer the question about overall quality of the fit, we perform what we know as variance partitioning. Let $ar{y} = \sum_{i=1}^n y_i$ be the sample mean, and let us define:

+   - Total Sum of Squares (TSS), also referred to as Sum of Squares, Total (SST, SSO) and SYY: $\sum_{i=1}^n (y_i - ar{y})^2$;n- Estimated Sum of Squares (ESS), also referred to as Sum of Squares, Model (SSM), Estimated Sum of Squares (ESS), and Sum of Squares, Regression (SSR, Sreg): $\sum_{i=1}^n (\hat{y}_i - ar{y})^2$;n- Residual Sum of Squares (RSS), also referred to as Sum of Squares, Error (SSE): $\sum_{i=1}^n (y_i - \hat{y}_i)^2$.

Notice that the abbreviations used in the literature can be quite confusing: "E" stand for "estimated" or for "error"; does "R" stand for "regression" or for "residual"? To avoid confusion, we will stick with Total Sum of Squares (TSS), Estimated Sum of Squares (ESS), and Residual Sum of Squares (RSS).

If we define $\hat{y} \in \mathbb{R}^n$ as a vector of all elements are the sample mean $ar{y}$, we can write this in vector notation:

```
TSS = \sum_{i=1}^n (y_i - \bar{y})^2 = (y - \bar{y})^T(y - \bar{y}),
```

```
ESS = \sum_{i=1}^n (\hat{y}_i - \bar{y})^2 = (\hat{y} - \bar{y})^T(\hat{y} - \bar{y}),
```

```
RSS = \sum_{i=1}^n (y_i - \hat{y}_i)^2 = (y - \hat{y})^T(y - \hat{y}).
```

Further, we notice that:

```
TSS = ||y - \bar{y}||^2 = ||y||^2 - 2y^T\bar{y} + ||\bar{y}||^2$,
```

```
ESS = ||\hat{y} - \bar{y}||^2 = ||\hat{y}||^2 - 2\hat{y}^T\bar{y} + ||\bar{y}||^2$,
```

```
RSS = ||y - \hat{y}||^2 = ||e||^2$.
```

If the model includes the intercept, the first column of $X$ is a column of ones, and $X^T e = 0$, the sum of the residuals is zero. This is equivalent to $y^T\bar{y} = \hat{y}^T\bar{y}$. By Pythagoras's theorem,

```
$||y||^2 = ||\hat{y}||^2 + ||e||^2$.
```

hence

```
TSS = ESS + RSS$,
```

which is a fundamental result known as variance partitioning. Irrespective of whether our model includes the intercept, if we center y by subtracting the sample mean
