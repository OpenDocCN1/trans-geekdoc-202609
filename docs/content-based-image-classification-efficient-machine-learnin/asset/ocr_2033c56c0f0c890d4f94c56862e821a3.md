RGB color space is considered to carry out the technique and the principle of Block truncation Coding (BTC) [3] is followed to initiate feature extraction from the three color components—namely, Red (R), Green (G) and Blue (B). Two different varieties of images are formed—namely, even image and odd image—by following the equations 4.3 and 4.4 respectively.

$$\text{Even Image} = \frac{\text{Original Image} + \text{Flipped Image}}{2} \tag{4.3}$$

$$\text{Odd Image} = \frac{\text{Original Image} - \text{Flipped Image}}{2} \tag{4.4}$$

Primarily, flipping of the test images is performed across X- and Y-axes as in Fig. 4.6. This creates the a new flipped version of the original image and is added to the original image to create an even image. Subtracting the flipped version from the original image creates the odd image. Both the actions are shown in Fig. 4.6.

Once the preprocessing of the test images is over, the rest of the process is similar to the steps of feature extraction using mean threshold selection discussed in Section 4.2.1.
