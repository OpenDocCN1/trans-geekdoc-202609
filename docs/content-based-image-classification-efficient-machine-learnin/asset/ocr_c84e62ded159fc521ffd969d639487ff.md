# 10.1 Prelude

**Waikato Environment for Knowledge Analysis (WEKA)** is an open source data mining tool developed by the University of Waikato in New Zealand [1]. This book has extensively used WEKA to evaluate classification results of content-based image data.

WEKA is considered a technique for machine learning using graphical user interface (GUI). The software has a vast collection of machine learning algorithms that are capable of data preprocessing, classification, regression, clustering, association rules and visualization [2].
