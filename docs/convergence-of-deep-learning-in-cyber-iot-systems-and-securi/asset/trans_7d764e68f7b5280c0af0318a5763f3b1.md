# 参与者规范

学生
描述：参与者扮演学生角色，可以注册网站并选择他们想要尝试的测试类型。参与者随后尝试测试，并在完成后提交以便评估结果。

教师成员
描述：参与者扮演教师成员角色，可以注册网站并提供系统必须生成问题的章节。该参与者还可以查看学生的成绩。

在线考试系统
描述：作为网站的主节点提供某些服务。它维护注册到网站的学生和教师的详细信息。该系统接收教师提供的章节并生成客观和主观问题以及相应的答案。
