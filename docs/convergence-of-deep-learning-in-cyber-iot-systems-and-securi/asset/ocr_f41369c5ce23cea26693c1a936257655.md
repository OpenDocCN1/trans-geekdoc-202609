# 11.2 Related Work

In this section, we see the authentication schemes where we stay about IoT-based devices using RFID-based authentication mechanism in different integrated applications. Secure localizations for different smart home and smart care application using RFID-based scheme was proposed [1] where they proposed localization information needed to be more safeguard than the existing as they carry sensitive data. Fusion techniques, along with localization and tracking of objects, which can be used in occupancy has been discussed [2]. Identification of objects along with sensing distributed approach in obtaining data dynamics is proposed [3]. Access control for efficient energy for smart home and smart buildings along with case study has been proposed [4] with RFID importance especially in cities and its case [5] discussed about the theft approaches with misplaced security issues especially in RFID tags. A similar kind of study has been found in Kuan et al. [6], where sensitive information along with leakage information is discussed.

The level of security along with different models in smart home has been proposed [7]. Privacy attacks with user location information for protecting reader tag data have been discussed in Tuan and Aiello [8]. Integrated applications with hardware and software in smart cities and smart applications have been the focus [9]. Authentication mechanisms in IoT use cases have been discussed [10]. RFID and its applications along with its importance have been discussed in Kuzlu et al. [11]. Pervasive computing and its applications in IoT where the possibilities of security issues and using the reader tag have been discussed [12]. Privacy and security issues, which are mainly essential in safeguarding of IoT devices and its applications, have been discussed in Liang et al. [13]. Heterogeneous data and devices with their standards have been found along leakage of sensitive data were discussed [14], even proposed a framework to protect the system from privacy and security issues [15]. From the review, it is understood in a better way that is most needed for security especially and end to end communications between different devices, which has been taken care especially when treating RFID tag readers has been discussed in this chapter.
