# 3.8 结论

网络物理系统、深度学习、机器学习——这三种技术在当代研究和IT领域变得越来越重要。如今几乎所有的组织、机构和工业都在使用此类技术来获得更好的结果、效率和生产力。世界正日益数字化和自动化，向一个真正的数字社会和知识经济发展，因此这种技术的应用是极其迫切的需求。对于教育机构、学院和大学而言，在设计和开发网络物理系统、深度学习、机器学习课程方面的作用已被认为对计算和IT及相关学生具有价值。
