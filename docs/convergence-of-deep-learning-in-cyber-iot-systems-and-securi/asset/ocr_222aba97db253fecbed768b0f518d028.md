# 8.3.2 Compressive Sensing–Based Classification

Recently, CS theory-based classifier named as sparse representation-based classification (SRC) technique has received high attention in recognition problems [31]. But SRC is a very slow process and time consuming since it requires optimizing an objective function with L1-Norm. SRC basically consists of two important steps: first step is collaborative representation and second step is L1-norm constraint. To increase the speed of classification, a collaborative representation-based classification with regularized least square (CRC_RL) is presented [32]. While the SRC is based on the solution of l1-regularized least square decomposition, CR starts from l2-regularized least square formulation. In the paper, to increase the speed and accuracy of classification, CRC_RLS classifier [32] is used. The algorithm of CRC_RLS is discussed in Algorithm 1.

```
Algorithm 1: CRC_RLS Algorithm1
```

+   **Input:** Matrix A of training samples.
1: Normalize the columns of A matrix to have unit $l_2$ norm
2: Code the test samples $y_{test}$ over $A$ by $\hat{p} = p_{test}$
Where $p = (A^TA + \lambda I)^{-1} A^T$ (using Least square solution)
3: Compute the residuals $R_i = \frac{||y_{test} - A_i\hat{p}\|}{\||\hat{p}||}$
4: Compute the identity of test sample as $identity(y_{test}) = argmin_i R_i$
**Output:** Identity the test sample.
