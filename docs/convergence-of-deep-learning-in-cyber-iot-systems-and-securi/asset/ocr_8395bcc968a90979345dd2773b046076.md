# QA SYSTEM USING DL 217

Step 1: Input question or query is gone through standard pre-
processing technique, parsing and tokenization.

Step 2: Words of the question or query sentence are tagged
POS with the help of LTRC shallow parser developed by IIT
Bombay and hosted by IIIT Hyderabad.

Step 3: Applying grammatical rules, Content Words (CW),
Function Words (FW), Named Entities, subjects, objects and
WH words are marked in the question or query sentence with
the help of POS.

Step 4: Person, number, tense of the subject of the question
extracted from the surface level verb(s) of the sen-
tence and also the root form of the verb of the surface
level is determined using the algorithm depicted in
Das et al. [5].

Step 5: Classification methods namely Artificial Neural
Network (ANN), Support Vector Machine (SVM), Decision
Tree (DT), and Naive Bayes (NV) are used individually to
categorize the question into one of the eighty-six cateo-
ries using feature vector containing tf of all the grammati-
al attributes extracted in Step 3 & 4 like FW, CW, subject,
object, person, number, tense etc.

Step 6: Step 1 to 5 is repeated for the sentences in the repos-
 containing the class(es) of the question to collect the
sentences in the ANSWER_COLLECTION associated with
sentence_id.

Step 7: Collect the vector in matrix A using Word2Vec algo-
rith [14].

Step 8: Collect the vector in matrix Bi using Word2Vec algorithm
[14] for all the sentence:i to n in ANSWER_COLLECTION.

Step 9: Perform A.Bi^T i to n and write the value |Vij| in the
ANSWER_COLLECTION against the sentence_id i.

Step 10: Rank the answers in the descending order of [V].

Step 11: Try to form the exact answer (EA) from the answer
sentence with rank (with the smallest rank) using rule-
knowledge base or return the selected sentence as A
 record the feedback.

Step 12: For negative feedback repeat step 11 with rank
i=2 and so up unto n. (n = number of sentences in the
ANSWER_COLLECTION)

Step 13: END.
