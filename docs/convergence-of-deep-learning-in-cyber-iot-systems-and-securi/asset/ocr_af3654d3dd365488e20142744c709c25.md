# 2.3.4.7 Multioutput Regression

Multi output model is a regression-based neural network in which the output is simultaneously predicted by the previous output back to the system. The performance of the model always depends on the quality of the output label which is predicted. And hence extra care has to be taken in labelling the output [39].
