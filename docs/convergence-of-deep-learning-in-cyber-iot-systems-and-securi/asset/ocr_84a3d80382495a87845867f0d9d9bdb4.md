ii) Room Temperature and Humidity Measurement
Controlling electronic devices in homes and businesses has never been easier thanks to the Internet of Things (IoT). As a bonus, you can access any sensor’s data from anywhere in the world and analyze it in a graphical manner. A simple room temperature monitoring system is implemented in our project. We use the NodeMCU module to read the temperature sensor (DHT11) and upload it to an Adafruit cloud. The DHT11 sensor collects temperature data, processes it, and transmits it to a NodeMCU Module. The NodeMCU is a Wi-Fi module and one of the most popular platforms for the Internet of Things. It can send data to the IoT cloud (here Adafruit). Additionally, in add a new feed called “temperature monitor.” At this point, the sensor is reading a value every 30 seconds and publishing that value to Adafruit’s dashboard, which we can access from any location to see the room temperature logs in real time.
