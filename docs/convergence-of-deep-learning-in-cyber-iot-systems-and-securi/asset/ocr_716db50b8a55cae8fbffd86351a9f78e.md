# 14.4.5 Novelty of the Work

The main concern of this research is women’s safety. One of the primary features of this application is that it can work both in online and offline mode. Using the location of the victim, assistance can be provided to them by volunteers and caregiver. Another highlighted and unique feature of this application includes alert message by the user through gestures when in unexpected trouble. Faster helper is provided to help the user optimization of the application has been done, so that it can utilize all system resources efficiently and provide an expected, speedy outcome.
