## 13.1 Introduction to Malware

### 13.1.1 Computer Security

Computer security is the procedure of hiding confidential material from attackers. The attackers can be different categories such as insider and outsider. These types of attackers are badly affecting computers without the knowing of the computers or institute. Nowadays, organizations are shifting their aim toward security purpose. Security should be secure, and strong algorithms is applied on the wall of the system. Sometimes, organization innovate their own algorithms to secure database. The key principles of computer security are listed below (Figure 13.1):

- Confidentiality: It states that the data which hidden by organization should be read by end user. For example, customer personal details should not share with another third party. Organizations should take care of those things, which will not make serious issues.

![](img/081dc7f102a3793cb08980a6e19b8f17_293_0.png)

**Figure 13.1** Confidential data sending [4].

- Integrity: It is the procedure that the packet (internal data) which is sent by an authorize owner should not be change by the third party. Data modification is the threat or malicious act by attacker (Figure 13.2).

![](img/081dc7f102a3793cb08980a6e19b8f17_293_1.png)

**Figure 13.2** Integrity [4].

- Availability: It states that all previous record or data should be available to the owner at any time for strong communication and transaction. If no available information is present, error will occur in the system (Figure 13.3).

## Types of Malware

- 1. Worms: Worms are network viruses that have ability to spread over the network by replicating themselves. Worm attacks: First Love Letter

![](img/081dc7f102a3793cb08980a6e19b8f17_295_0.png)

Basic steps for worm attack: Target is searched by following methods (Selecting Randomly, Sequential Scan, Hit-List Scan, Pregenerated Scan List). Target space (hosting malware using Internet and email). Propagation method (exploiting the system very badly). Activation (spreading the hosted malware)

- 2. Trojan Horse: Trojan Horse: It is the most harmful and pretends that it is useful software.

![](img/081dc7f102a3793cb08980a6e19b8f17_295_1.png)

Basic steps for Trojan Horse:
a) Search for victims: random select, check for vulnerable system
b) Installation: spam link and fake pop-ups (Figure 13.5)
c) Distribution: After submitting fake pop-ups, it starts for malware

![](img/081dc7f102a3793cb08980a6e19b8f17_295_2.png)

**Figure 13.5** Basic diagram of Trojan horse [5].

- 3. Virus: a code or program is modified and attached with it is called as virus. It also gets infected while transferring (Figure 13.6).

**Figure 13.6** Basic diagram of virus [5].

- 4. Ransomwares: Ransomwares attack are very different, the attacker gets the file encrypted and does not allow the user to access (Figure 13.7).
