Applying the feature extraction step, we get the principal component (PC) from the detail subbands D1PC, D2PC, D3PC, D4PC, D5PC, D6PC, D7PC, and D8PC. Then the maximum value for each PC is chosen of eight detail subbands and multiplied with a weight. On the other hand, extracted PC, CSPC from coarse subband is also multiplied with weight considering linear combination rule. Finally, the fused features are:

Fused feature = μXCC+μX Max (D1PC, D2PC, D3PC, D4PC, D5PC, D6PC, D7PC, D8PC), where μ=0.7 and μ=0.3 is used. Numerical values of μ and μ are obtained from running the algorithm over a large set of images. After fusion of features classifier is used for identification of the test images. Here, CS theory-based CRC_RLS classifier is used for the recognition.
