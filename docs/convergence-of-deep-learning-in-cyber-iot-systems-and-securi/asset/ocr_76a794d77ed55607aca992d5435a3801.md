# 2.2.1 Literature Review on Comparing the Performance of the ML/DL Algorithms

Sewak et al. [1] presented the work of comparing the performance of machine learning algorithms for detection of malware in a system based on few features. Authors have used necessary dataset for training the system. The dataset used has issues with unbalancing, they have used Adaptive Synthetic (ADASYN) and have built models using machine learning-based random forest (RF) algorithm and deep learning-based deep neural network (DNN) algorithms. Various performance metrics were used for evaluating the performance and finally came up with 99.78%, 99.21% accuracy for RF and DNN methods.
