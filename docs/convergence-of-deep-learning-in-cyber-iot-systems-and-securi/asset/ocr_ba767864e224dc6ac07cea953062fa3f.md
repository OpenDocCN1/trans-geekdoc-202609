# 12.6 Conclusion

We have set up a simple implementation of the secure MQTT protocol in a smart home to control a few sensors and lights. Sensors and relay shields can be controlled wirelessly over the Internet using the ESP32 microcontroller. The coverage range of the Wi-Fi router indicates that the Internet of Things (IoT) devices can be utilized, and accessed anywhere on our premises. The Adafruit MQTT broker is used to efficiently implement the publish-subscribe model. Each client's connection is encrypted using an SSL port. MQTT's best feature is that when feeding data, the option to set a quality of service level (QoS), which is the most important feature. As a result, the proposed system improves automation service and security by verifying whether the data have been made available to the public. It reduces the amount of work required to perform computations. Smart homes and a more secure system are expected to be added in the future. A gateway has been eliminated in favor of using the cloud for intermediate data storage and processing, which has the added benefit of lowering the overall cost of the proposed system.

For future research, we plan to conduct additional attempts that may be applied to find which broker is the most secure and to establish a connection with IoT gadgets in smart homes and cities' safety.
