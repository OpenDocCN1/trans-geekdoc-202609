# 4.4.2 Evaluation

We are considering that when the model labels a news report as a fake then the result is positive. Then:

+   - Number of originally fake news, correctly recognized as fake (tp)
- Number of originally not fake news, incorrectly recognized as fake (fp)
- Number of originally fake news, incorrectly recognized as not fades (fn)
- Number of originally not fake news, correctly recognized as not fakes (tn)

Then, the formula of precision is given in equation 4.5.

```
$Precision (Pr) = \frac{tp}{tp + fp} (4.5)
```

And the formula of recall is given in equation 4.6.

```
$Recall (Rc) = \frac{tp}{fn + tp} (4.6)
```
