# 5—Answer Evaluation

The evaluation of answers varies along with the mode of the test. The answer evaluation for the two modes of the test are listed below:

# Objective Answer Evaluation

The answer for the objective type is generated along with the process of question generation. A variable “SCORE” is used to keep track of user’s makes. For every correct answer given by the user, the score is increased by 100. For every wrong answer given by the user, the score remains the same. The final score is divided by the number of questions to get the final result. If the final result is greater than 33.33, then the user is declared as “PASS” else the user is declared as “FAIL.”
