# buildErrorMsg() and errorMsg()

The buildErrorMsg() method simply sets the $ERROR_MSG property value to given arguments separated by $ERR_ARGS_DELIMITER:

```
function buildErrorMsg($err_msg, $err_arg='')
{
    $this->ERROR_MSG = $err_msg . $this->ERR_ARGS_DELIMITER . $err_arg;
}
```

We also define an error-reporting method as usual:

```
function errorMsg()
{
    return $this->ERROR_MSG;
}
?>
```

# Testing the Webmail Class

Try this class using different protocols and hosts:

```
<?php
//webmail_class_test.php
include("../webmail_class_ver1.php");
class My_Webmail extends Webmail
{
    function start() {
        // Does nothing yet
        return true;
    }
}

$host = "mail.whatever.com";
$protocol = "imap";
$port = 143;
$userid = "wankyu";
$userpassword = "12345";

$wmail = new My_Webmail();

if (!$wmail->init($host, $protocol, $port, $userid, $userpassword))
    echo($wmail->errorMsg());
else echo("Connected!");
if (!$wmail->start()) echo($wmail->errorMsg());

$wmail->end();
?>
```
