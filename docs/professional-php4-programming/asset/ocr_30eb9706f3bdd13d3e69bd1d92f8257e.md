# ftp_chdir()

```
boolean ftp_chdir(int ftp_link, string directory)
```

Returns true on success, and false on failure:

```
$dir = 'foo';

chdir($ftp_link, $dir)
or die("Could not set the current working directory to '$dir'");
```

Change the remote current working directory to the given directory.

# ftp_connect()

```
int ftp_connect(string host [, int port])
```

Returns an integer on success, and false on failure:

```
<?php
$host = 'ftp.example.com';
$ftp_handle = ftp_connect($host)
    or die("Could not connect to host '$host' on the default port.");
?>
```

Connect to an FTP server at the host and port specified. If port is not specified or is set to 0, then the default FTP port of 21 is assumed.
