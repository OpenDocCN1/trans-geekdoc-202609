# htmlHeader()

The htmlHeader() method takes two optional arguments: the HTML title and message character set:

```
function htmlHeader($title='', $charset='')
{
    $ret_str = "<html>\n";
    $ret_str .= "<head>\n";
    if (!empty($charset)) $ret_str .= "<meta http-equiv=\"CONTENT-TYPE\" \ncontent=\"TEXT/HTML; charset=$charset\">\n";
    $ret_str .= "<title>$title</title>\n";
    $ret_str .= "</head>\n";
    $ret_str .= "<body>\n";
    return $ret_str;
}
```

# htmlFooter()

The htmlFooter() method ends the web page:

```
function htmlFooter()
{
    $ret_str = "</body>\n";
    $ret_str .= "</html>\n";
    return $ret_str;
}
```
