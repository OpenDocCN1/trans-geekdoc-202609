# # moveMailMsg()

Moves a given range of messages to a new mailbox. We call the imap_copy_mail() function with the CL_MOVE argument. Nothing stops you from using the imap_mail_move() function:

```
```php
function moveMailMsg($msg_set)
{
    if (!imap_mail_copy($this->stream, $msg_set, "{$this->server}
    $this->new_mailbox", CP_UID | CP_MOVE)) {
        $this->buildErrorMsg($this->ERR_STR_CANT_MOVE_MESSAGE,
        imap_last_error());
        return false;
    }
    @imap_expunge($this->stream);
    return true;
}
```

# # setMsgFlag()

Sets flags to a given range of messages:

```
```php
function setMsgFlag($msg_set, $flags)
{
    if (!imap_setflag_full($this->stream, $msg_set, $flags, ST_UID)) {
        $this->buildErrorMsg($this->ERR_STR_CANT_SET_FLAGS,
        imap_last_error());
        return false;
    }
    return true;
}
```
```

# # clearMsgFlag()

Clears a given range of messages of specified flags:

```
```php
function clearMsgFlag($msg_set, $flags)
{
    if (!imap_clearflag_full($this->stream, $msg_set,
    $flags, ST_UID)) {
        $this->buildErrorMsg($this->ERR_STR_CANT_UNSET_FLAGS,
        imap_last_error());
        return false;
    }
    return true;
}
```
