```
# getMsgList()

The new getMsgList() method returns a two-dimensional array with each element storing header information of a message as another array.

The $sort property is used to determine in which order messages should be sorted defaulting to SORTDATE:

```
```php
function getMsgList($read_action, $mail_action)
{
    $msgs = @imap_sort($this->stream, $this->sort, $this
    ->reverse, SE_NOPREFETCH);
}
```
