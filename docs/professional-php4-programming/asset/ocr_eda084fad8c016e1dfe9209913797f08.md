Make the SELECT statement for retrieving the row containing data of the session:

```
// SELECT Statement
$selectStmt = "SELECT data FROM Session WHERE id = '" . $id . "'"";
```

Execute the MySQL query:

```
// Execute the query
if (!($result = mysql_query($selectStmt, $link))) {
    return null;
}
```

Fetch the row from the result of the query. If there was no row corresponding to the session then return null:

```
if (($row = mysql_fetch_array($result, MYSQL_NUM))) {
    $data = $row[0];
} else {
    $data = null;
}
```

Free the MySQL result object:

```
mysql_free_result($result);
```

Return the session data:

```
return $data;
}
```
