Some parts of the script are executed regardless of the action that we are performing. The script always
displays a list of the directories and files contained in the current working directory. The code below
takes the output of the ls() method and converts it into a more useable format:

```
$directory = array();
$file = array();
foreach ($ftp->ls($ftp->cwd) as $entry) {
    switch ($entry['type']) {
        case 'directory':
            $directory[] = $entry['name'];
            break;
    }

    default:
        // Handle files and symlinks
        $file[$entry['name']] =
        // with the default case
        sprintf("%s (%0.2f kb)", $entry['name'], $entry['size'] / 1024);
        break;
    }
}
?>
```
