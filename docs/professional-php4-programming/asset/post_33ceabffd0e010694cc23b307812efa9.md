The following variables contain the information for accessing the back-end database. Before running the application, make sure you change these variables to reflect your installation environment:

$dbHostName="localhost";   // Database server machine

$dbUserName = "PHP";       // Database user name

The function checkSessionAuthenticated() checks if the user session is authenticated. If the user session is not authenticated then the function sends a WML error page:

```php
function checkSessionAuthenticated()
{
    global $isAuthenticated;

    session_start();

    if (session_is_registered("isAuthenticated") && $isAuthenticated) {
        return true;
    } else {
        sendErrorPage("Unauthenticated Session");
        exit;
    }
}
```

The class Function_Result encapsulates the return value of most of the functions. The member variable $errorMessage stores the error message, and the member variable $returnValue stores the return value. On failure the value of member variable $returnValue is null:

```php
class Function_Result
{
    var $errorMessage;
    var $returnValue;
}
```

The constructor of Function_Result sets the value of member variables $errorMessage and $returnValue:

```php
function Function_Result($errMessage, $retValue)
{
    $this->errorMessage = $errMessage;
    $this->returnValue = $retValue;
}
```
