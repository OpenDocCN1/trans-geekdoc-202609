| Command | Response Codes |
|---|---|
| Upon connection | 200 – posting allowed<br>201 – posting not allowed |
| ARTICLE<br>BODY<br>HEAD<br>NEXT | The server maintains an internal pointer referring to the current article (you may use the NEXT command to move this pointer to the next article)<br>220 – Article retrieved with both the head and body blocks<br>221 – Article retrieved with the head block only<br>222 – Article retrieved with the body block only<br>223 – Internal pointer set to the article, request text separately<br>412 – No newsgroup selected<br>420 – No current article selected (NEXT)<br>423 – No such article number in this group<br>430 – No such article found |
| GROUP | 211 – Group selected<br>411 – No such group |
| LIST | 215 – List of newsgroups follows |
| POST | 340 – Command OK, send article<br>240 – Article posted successfully<br>441 – Posting failed<br>440 – Posting not allowed |
| QUIT | 205 – Closing connection |
| Others | 400 – Service discontinued<br>500 – Command not recognized<br>501 – Syntax error<br>502 – Access restriction or permission denied |

To post an article to a particular newsgroup, you need to test the server response code to each command using a regular expression as the following:

+   - [ ] **Upon connection**
+     If the 201 code is returned, we can't post an article on this news server.
