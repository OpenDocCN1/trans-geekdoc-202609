This part of the script prints out the values of each of the elements:

```
<div align="center"><center><table border="1"  cellpadding="0"
cellspacing="0" width="100%">
<tr>
<td width="25%">Your Full Name</td>
<td width="75%"><?php echo ($name) ?><?/td>
</tr>
<tr>
<td width="25%">Your Address</td>
```

The address field is a textarea. So to reproduce the line breaks in the address properly we use the
nl2br() function which converts any new line characters to <BR> tags. If this is not done the entire
address will be seen on a single line:

```
<td width="75%"><?php echo(nl2br($address)) ?><?/td>
</tr>
<tr>
<td>Gender</td>
```

The field gender is a group of two radio buttons. PHP handles radio button variables just like text
fields. The variable $gender will contain the value of the radio button that the user selected:

```
<td><?php echo($gender) ?><?/td>
</tr>
<tr>
<td>Would like e-mail notification?</td>
<td>
```
