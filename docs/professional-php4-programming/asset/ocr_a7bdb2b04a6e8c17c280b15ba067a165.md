# # Uploading Files from Clients

There are two mechanisms that can be used by browsers for uploading files to the server:

+   - [ ] Based on the HTTP PUT method
+   - [ ] Based on the HTTP POST method

The HTTP protocol provides three basic methods GET, PUT, and POST for accessing information from
the web server.

The GET method is used to fetch web pages. When GET is used to fetch dynamic pages, the form
variables are passed as part of the URL. It is safe for the browser to fetch a page using the GET method
as many times it likes – the GET method should not cause any permanent change on the server. Some
web servers have a limit on the length of the URL (mostly 1024) that they can handle, so GET should
not be used to pass form data greater than this limit.

The PUT method is used for updating information on the server. It requests that the enclosed data be
stored as the requested URL on the server. The PUT method is used mostly for publishing pages.

The POST method is used if requesting the URL will cause a permanent change on the server. For
example, deleting a folder in a web based e-mail application. The browser should not execute the POST
method again without getting user confirmation. The POST method sends all the form variables as part of
the request body. The POST method is also used when lots of form data needs to be passed to the URL.
