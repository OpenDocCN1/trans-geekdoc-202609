Set the session handlers:

```
header("Content-Type: text/vnd.wap.wml");
setSessionHandlers();
```

Remove extra spaces from the $userId and $password form variables:

```
// Check if the form variables are null
$userId = trim($userId);
$password = trim($password);
```

If $userId or $password is null, then send an error page:

```
if (($userId == "") || ($password == "")) {
    sendErrorPage("The username and password you have entered are invalid.
    Please try again");
    exit;
}
```

Load the user:

```
$funcResult = loadUser($userId);
if ($funcResult->returnValue == null) {
    sendErrorPage($functionResult->errorMessage);
    exit;
}
$user = $funcResult->returnValue;
```

Check the password of the user:

```
if (!$user->checkPassword($password)) {
    sendErrorPage("Invalid Password");
    exit;
}
```

Create a PHP session:

```
// Create user session
if (!session_start()) {
    sendErrorPage("Internal Error: Could not create user session");
    exit;
}
```
