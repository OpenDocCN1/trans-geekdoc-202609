The actual IP address is a 32-bit number, often considered as type long on several architectures. This method takes a dot-separated IP address string and converts it into a 32-bit quantity:

```
function dottedToIp($dotted)
{
    if (!$dotted) {
        log_err("Dot formatted IP address is required to get
         long IP address");
        return -1;
    } elseif (!ereg("[1-254]\.[1-254]\.[1-254]\.[1-254]", $dotted)) {
        log_err("Incorrect IP address format");
        return -1;
    } elseif ($ret = $ipLong[$dotted]) {
        return $ret;
    } elseif (($ret = ip2long($dotted)) == false) {
        log_err("Long IP address could not be found for ". $dotted);
        return -1;
    } else {
        $ipLong[$dotted] = $ret;
        $ipDotted[$ret] = $dotted;
        return $ret;
    }
}
```
