| Algorithm Name | Notes |
|---|---|
| XTEA | A "Tiny Encryption Algorithm" designed for places where code space was at a premium. This algorithm uses a 128 bit key size and 64 bit block size. Accessible via the `CRYPT_XTEA` constant. |
| 3-WAY | An algorithm with a key and block size of 96 bits. Accessible via the `CRYPT_THREEWAY` constant. |
| SKIPJACK | An algorithm designed by the US NSA to be part of the proposed Escrowed Encryption Standard, which never actually made it to be standardized. This is available via an extra library in mcrypt and is based on a 64 bit block size and 80 bit key. Accessible via the `CRYPT_SKIPJACK` constant. |
| BLOWFISH | An improvement on DES. Key size of up to 448 bits is available. Accessible via the `CRYPT_BLOWFISH` constant. |
| TWOFISH | Twofish is intended to be highly secure and flexible. It supports key sizes of 128, 192, and 256 bits. Accessible via the `CRYPT_TWOFISH` constant. |
| LOKI97 | Uses 128, 192, and 256 bit key sizes. Accessible via the `CRYPT_LOKI97` constant. |
| RC2 | 64 bit block size and a key size ranging from 8 to 1024 bits. This algorithm is very old and optimized for 16 bit machines. Accessible via the `CRYPT_RC2` constant. |
| ARCFOUR/RC4 | RC4 is a trademark of RSADSL so mcrypt does not use the RC4 algorithm but a compatible one called ARCFOUR. It's a stream-based cipher and has a maximum key size of 2048 bits. Accessible via the `CRYPT_ARCFOUR` constant. |
| RIJNDAEL | A cipher with a variable block and key length. Accessible via the `CRYPT_RIJNDAEL_128`, `CRYPT_RIJNDAEL_192`, and `CRYPT_RIJNDAEL_256` constants. |
| SERPENT | 128 bit block cipher, faster than DES. Accessible via the `CRYPT_SERPENT` constant. |
| IDEA | A 64 bit block and 128 bit key algorithm. Accessible via the `CRYPT_IDEA` constant. |
| ENIGMA / CRYPT | Based on a one-rotor enigma machine, not secure but included for completeness. Accessible via the `CRYPT_CRYPT` constant. |
| GOST | A 256 bit key and 64 bit block algorithm. Accessible via the `CRYPT_GOST` constant. |
| SAFER | An fast and safe algorithm which supports both 64 bit and 128 bit keys. Accessible via the `CRYPT_SAFER64` and `CRYPT_SAFER128` constants. |
| SAFER+ | An extension of the Safer algorithm supports 128, 196, and 256 bit keys. Accessible via the `CRYPT_SAFERPLUS` constant. |
