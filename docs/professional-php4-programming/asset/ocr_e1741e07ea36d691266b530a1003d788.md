```
$mapping = array (
    'No' => 'ingen',
    'files' => 'filer',

```

It's clear that only as long as such a mapping can be defined can the logic in the two languages be expected to match. Only then will the translation work smoothly. The logic cannot be viable, if we had to alternate between two different words for the English word "file".

To understand the problem fully, let's take a look at how the function should look if it were to give correct output in Polish:

```
function outNumFiles($count)
{
    if ($count == 0) {
        return "Nie ma plików.";
    } elseif ($count == 1) {
        return "1 plik.";
    } elseif ($count <= 4) {
        return "$count pliki.";
    } elseif ($count <= 21) {
        return "$count plików.";
    } else {
        $last_digit = substr($count, -1);
        if ($last_digit >= 2 & $last_digit <= 4) {
            return "$count pliki.";
        } else {
            return "$count plików.";
        }
    }
}
```
