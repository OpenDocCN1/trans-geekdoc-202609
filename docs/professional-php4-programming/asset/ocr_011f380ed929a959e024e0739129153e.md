The isSessionAuthenticated() function checks if the session is an authenticated session. After authentication (refer to login.php), the variable $isAuthenticated with value true is stored in the session:

```
function isSessionAuthenticated()
{
    global $isAuthenticated;
    session_start();
    if (session_is_registered("isAuthenticated") &&
        $isAuthenticated) {
        return true;
    } else {
        return false;
    }
}
?>
```
