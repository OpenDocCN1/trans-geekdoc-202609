# Register session variable currentFolder:

```
if (!session_register("currentFolder")) {
sendErrorPage("Internal Error: Could not add currentFolder variable
to the user session");
exit;
}
```

The default value of the current folder is $username. Note that the name of the root folder of user is $username:

```
$currentFolder = $username;

include_once("main.php");
exit;
?>
```

The following PHP file main.php displays the main page:

```
<?php
include_once("common.php");
```

Check if the user is authenticated:

if (!isSessionAuthenticated()) {
