Then we have some rather unfriendly looking nested if-then-else() statements. The first statement checks whether or not $a[$i] is a special character. If so, we also check $b[$i].

If both characters are special characters, then we use the two-dimensional array to sort the characters. If $a[$i] is a special character, but $b[$i] is not, then $a[$i] is considered greater that $b[$i], so we return 1. If neither $a[$i] or $b[$i] are special characters we just use PHP's standard way of comparing strings: strcmp(). This function is binary safe, case insensitive, and will not work on control characters:

```
// $a[$i] is a special character
if (strrpos($special_chars, $a[$i])) {
    // Both characters are special
    if (strrpos($special_chars, $b[$i])) {
        /* $a[$i] is greater than $b[$i]
            because it is a special
            character. */
        return $matrix[$a[$i]][$b[$i]];
    } else {
        return 1;
    }
}
// $b[$i] is special character
} elseif (strrpos($special_chars, $b[$i])) {
    // Both characters are special
    if (strrpos($special_chars, $a[$i])) {
        /* $a[$i] is less than $b[$i]
            because it is not a special
            character. */
        return $matrix[$a[$i]][$b[$i]];
    } else {
        return -1;
    }
} else {
    /* None of the characters are special */
    return strcmp($a, $b);
}
?>
```

It should be fairly easy to adapt this function to other languages. All we need to change is the two-dimensional array. This should be quite easy, because of its symmetrical shape.
