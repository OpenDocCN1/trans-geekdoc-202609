# Store isAuthenticated in the session:

```
```php
// Register isAuthenticated flag
if (!session_register("isAuthenticated")) {
    sendErrorPage("Internal Error: Could not add isAuthenticated variable
        to the session");
    exit;
}
$isAuthenticated = true;
```
```
