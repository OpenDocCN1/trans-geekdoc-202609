### htmlHeader()

htmlHeader() 方法接受两个可选参数：HTML 标题和消息字符集：

```
function htmlHeader($title='', $charset='')
{
    $ret_str = "<html>\n";
    $ret_str .= "<head>\n";
    if (!empty($charset)) $ret_str .= "<meta http-equiv=\"CONTENT-TYPE\" \ncontent=\"TEXT/HTML; charset=$charset\">\n";
    $ret_str .= "<title>$title</title>\n";
    $ret_str .= "</head>\n";
    $ret_str .= "<body>\n";
    return $ret_str;
}
```

### htmlFooter()

htmlFooter() 方法结束网页：

```
function htmlFooter()
{
    $ret_str = "</body>\n";
    $ret_str .= "</html>\n";
    return $ret_str;
}
```
