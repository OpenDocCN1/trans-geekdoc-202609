# # Problems with Cookies

Several mistakes are commonly made when using the setcookie() function. The most common is in trying to set cookie data after the data has already been sent to the client.

For example:

```
<html>
 Putting text or HTML tags here will force actual page content to be sent,
 causing the cookie to result in error.
 <?php
 $access++;
 setcookie("access", $access);
 ?>
 Thank you for visiting my site. You've seen this page
```
