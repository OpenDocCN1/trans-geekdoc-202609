You may also connect to a news server using this application. Change the settings and try
news.php.net. The following screenshot shows what it looks like when we connect to the server and
select the php.test newsgroup.

> Most news servers return tens of thousands of available newsgroups. If you're going to
> use this application with one of those news servers, it may take ages to list them all or
> the application will time out while waiting for a server response. The application is
> designed to work with a small news server like news.php.net.
