## admin_winners.php

We created a few pages to ensure that the winner selected is notified of the exciting news and that we give the notification in a way that gives some security. This isn’t much, but to make reasonably sure that the person who claimed the prize was the person you intended, you would need to make use of a login system, and users of a silly little survey may not be interested in keeping track of yet another password.

The best we can do here is try to make sure that if some immoral person sees the claim information one week, that person will not be able to easily spoof our system in future weeks. When we send the winner notification, we will include an eight-character claim code. This prize can only be claimed with knowledge of the code.

To make things as secure as possible, we want to make sure this code is unique and very difficult to guess.

```php
mt_srand ((double) microtime() * 1000000);
$claim_code = substr(md5(uniqid(rand())),0,8);
```

This uses the uniqid() and md5() functions to create string that is very random. There's little for a hacker to latch onto when trying to figure out how the string is constructed. md5() will create a string that is 32 characters, but that can be a bit unwieldy. So we're using substr() to limit the string to 8 characters.

The user_id, the claim code, and the week of interest are inserted into the winners table.

```php
$query = "replace into winners

    ('$weekdate', $user_id, '$claim_code', now())
";
```

The winner is sent an email that is something like, where the claim code matches what has been entered in the database: http://mydomain.com/claim.php?claim_code=k15g4ju9.
