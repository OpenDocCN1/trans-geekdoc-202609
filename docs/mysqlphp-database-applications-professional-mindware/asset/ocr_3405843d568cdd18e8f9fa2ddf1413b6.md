# Summary

This chapter discussed everything you need to know in order to create and maintain databases and database tables when working with MySQL. It is possible that you will never need to commit the details of the create statement to memory, as graphical tools like phpMyAdmin can help you create and alter tables.

Still, it is important to understand the column types and the purposes of indexes, as a quick and efficient database will always use the correct data type and will only include indexes when necessary. As you will see in Parts III and IV of this book, we take a good deal of care to make sure that we get the most out of our databases.
