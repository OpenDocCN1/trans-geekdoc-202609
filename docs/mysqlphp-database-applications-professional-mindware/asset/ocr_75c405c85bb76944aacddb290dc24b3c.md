# TABLE E-42 PAYFLOW PRO FUNCTIONS

| Function | Returns | Action |
|---|---|---|
| pfpro_version() | string | Returns the version of the Payflow Pro library |
| pfpro_init() | void | Initializes the Payflow Pro library |
| pfpro_cleanup() | void | Shuts down the Payflow Pro library |
| pfpro_process_raw(string parmlist [, string hostaddress [, int port [, int timeout [, string proxyAddress [, int proxyPort [, string proxyLogon [, string proxyPassword]]]]]]]) | string | Performs a raw Payflow Pro transaction |
| pfpro_process(array parmlist [, string hostaddress [, int port [, int timeout [, string proxyAddress [, int proxyPort [, string proxyLogon [, string proxyPassword]]]]]]]) | array | Performs a Payflow Pro transaction using arrays |

![](bbox=[0.16, 0.67, 0.24, 0.73])

Use of these functions requires payflo pro libraries from verisign and PHP to compile with --with-payflo.
