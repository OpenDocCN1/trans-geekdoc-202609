# Summary

As you've seen, PHP has more functions than you will be able to commit to memory any time soon. It can seem intimidating, but the quantity and quality of these functions are what make PHP such a great language. Most anything you need to do can be done quickly and painlessly.

At first, you may need to study and play with the functions in order to get them to work. But in time, it will get a lot easier. You'll be making use of more and more functions, and keeping your scripts more compact and easier to read.
