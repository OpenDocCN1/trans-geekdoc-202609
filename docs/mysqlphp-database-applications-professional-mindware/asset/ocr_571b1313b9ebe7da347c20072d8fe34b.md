# Using phpMyAdmin

If you are an old-time Unix guy or gal, you may be perfectly comfortable keying in all of your commands and sorting out the errors when you mistype something or screw up the syntax. But myself, I like the convenience of a graphical interface.

If you're like me, you will be thrilled to know that a couple of programmers have used PHP to create a great Web-based interface to MySQL. Best of all, they're giving their program away. All you need to do is cruise over to phpwizard.net and download the appropriate .tar, .gz, or .zip file. We would have included it on the CD, but you're really better off getting the most recent version off their site. It's constantly being improved.
