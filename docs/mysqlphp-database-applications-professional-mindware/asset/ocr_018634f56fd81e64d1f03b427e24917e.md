|---|---|---|
| `array_unique(array input)` | array | Removes duplicate values from array |
| `array_intersect(array arr1, array arr2 [, array ...])` | array | Returns the entries of arr1 that have values that are present in all the other arguments |
| `array_diff(array arr1, array arr2 [, array ...])` | array | Returns the entries of arr1 that have values that are not present in any of the other arguments |
| `array_multisort(array ar1 [, SORT_ASC|SORT_DESC [, SORT_REGULAR|SORT_NUMERIC|SORT_STRING]] [, array ar2 [, SORT_ASC|SORT_DESC [, SORT_REGULAR|SORT_NUMERIC|SORT_STRING]], ...])` | bool | Sorts multiple arrays at once (works like the ORDER BY clause in SQL). Retruns TRUE on success, FALSE on failure. |
| `array_rand(array input [, int num_req])` | mixed | If the second argument is blank or set to 0, this will return a single key form the input array. If the second argument is greater than 0, it will return an array, each element of which is a random key from the input array. |
