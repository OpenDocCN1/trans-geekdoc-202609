使用这些函数需要来自 http://mhash.sourceforge.net/ 的 mhash 库。PHP 必须编译 --with-mhash。

msql 数据库是另一个开源 SQL 数据库服务器。它不再积极维护，并且有一些限制，使其与 MySQL、PostGRES 或 Interbase 相比成为一个较差的选择。请注意，msql 和 MySQL 具有几乎相同的函数集。
