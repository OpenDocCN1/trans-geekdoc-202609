This is easy enough to accomplish in SQL. In the from portion of the select statement all of the tables to be joined must be listed. And in the where portion, the fields on which the join takes place must be shown:

```
select *
from companies, contacts
where companies.company_ID = contacts.company_ID
```

At times when a reference to a field name is ambiguous, you need to specify which table the column comes from the by using the syntax table_name.column_name. This is done in the where clause in Figure 3-12. If you fail to indicate the table from which you're pulling the company_id column in the SQL statements, MySQL will return an error.
