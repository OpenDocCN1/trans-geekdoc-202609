## 确定应用的范围和目标

我们对该应用程序的目标相当 modest。想象一下，你拥有一家某种零售店，里面有你想兜售的商品。此外，假设你对通过网络进行实际交易不感兴趣。也许你只是对这种新式信用卡处理方法过于偏执。或者你可能正在运行一个复杂的逃税计划，要求你只使用未标记的二十美元钞票。
