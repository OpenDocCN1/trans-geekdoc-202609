# CLENUP_TEXT()

This function goes a long way toward making sure we don't insert malicious text in our database.

```
function cleanup_text ($value = "", $preserve="", $allowed_tags="")
{
    if (empty($preserve))
    {
        $value = strip_tags($value, $allowed_tags);
    }
    $value = htmlspecialchars($value);
    return $value;
}
```
