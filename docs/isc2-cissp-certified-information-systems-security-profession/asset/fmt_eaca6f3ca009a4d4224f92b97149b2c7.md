
# 1. Primary Difference Between Discretionary and Nondiscretionary Access Control Models
The primary difference is that **discretionary access control (DAC)** grants object owners full control over permissions, allowing them to modify access rights, while **nondiscretionary access control (NAC)** is centrally managed by administrators and does not allow owners to change permissions, enforcing access based on predefined policies.

# 3. Three Types of Attacks Used to Discover Passwords
- Dictionary attacks  
- Brute-force attacks  
- Rainbow table attacks  

# 4. Differences Between Salt and Pepper in Password Hashing
- **Salt** is added to a password before hashing to thwart rainbow table attacks; it is stored in the same database as the hashed password.  
- **Pepper** is a large constant value added to the password (or salt) before hashing to further increase security; it is stored outside the database containing the hashed passwords.  

# Review Questions

## 1. Which of the following *best* describes an implicit deny principle?  
1. All actions that are not expressly denied are allowed.  
2. All actions that are not expressly allowed are denied.  
3. All actions must be expressly denied.  
4. None of the above.  

**Answer:** 2. All actions that are not expressly allowed are denied.  

## 2. What is the intent of least privilege?  
1. Enforce the most restrictive rights required by users to run system processes.  
2. Enforce the least restrictive rights required by users to run system processes.  

**Answer:** 2. Enforce the least restrictive rights required by users to run system processes.
