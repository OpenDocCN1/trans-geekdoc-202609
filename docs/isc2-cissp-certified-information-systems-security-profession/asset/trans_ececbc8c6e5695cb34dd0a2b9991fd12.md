
-   [日志和监控]结合有效的识别和身份验证措施时，能够提供整体问责。日志涉及在日志文件和数据库文件中记录事件。安全日志、系统日志、应用日志、防火墙日志、代理日志和变更管理日志都是常见的日志文件。日志文件包含有价值的数据，应受到保护，以确保它们不会被修改、删除或损坏。如果未受到保护，攻击者通常会尝试修改或删除它们，并且它们将无法作为证据用于起诉攻击者。

-   监控涉及实时查看日志以及在稍后作为审计的一部分进行查看。审计轨迹是通过记录事件和发生情况的信息创建的，存储在一个或多个数据库或日志文件中，可用于重建事件、提取事件信息以及证明或否定 culpability。审计轨迹作为一种被动的侦测安全控制，与闭路电视或保安的作用方式相同，起到威慑作用。此外，它们在起诉罪犯时也可作为关键证据。日志文件可能非常大，因此使用不同的方法对其进行分析或缩小大小。抽样是一种统计方法，用于分析日志；而使用阈值的削减（cl being= truncated levels）是一种非统计方法，涉及为感兴趣的项目设定预定义阈值。

-   访问控制的有效性可以通过不同类型的审计和审查来评估。审计是对环境的系统性检查或审查，以确保符合法规并检测异常、未经授权的发生或 outright 犯罪。访问审计确保对象访问和账户管理实践支持组织的安全政策。用户权限审计确保人员遵循最小权限原则。

-   审计报告记录审计的结果。这些报告应受到保护，并仅分发给组织中特定的人员。高级管理人员和安全专业人员有权查看安全审计的结果，但如果攻击者获取审计报告，他们可以利用其中的信息识别可被利用的漏洞。

-   安全审计和审查通常用于确保控制按预期实施并正常工作。常见的做法包括检查补丁管理、漏洞管理、变更管理和配置管理程序的审计和审查。

**考试要点**

**了解应急响应步骤。** CISSP 安全运营领域将应急响应步骤列为：检测、响应、缓解、报告、恢复、整改和经验教训。在检测并验证事件后，第一步是限制或遏制事件范围，同时保护证据。根据相关法律，组织可能需要向官方机构报告事件，如果涉及个人身份信息（PII），则需要通知相关个人。整改和经验教训阶段包括根本原因分析，以确定原因并提出防止再次发生的建议。

**了解基本预防措施。** 基本预防措施可以防止许多事件发生。这些措施包括保持系统更新、移除或禁用不必要的协议和服务、使用入侵检测和防御系统、使用带有最新签名的防病毒软件、以及启用主机防火墙和网络防火墙。

**了解拒绝服务（DoS）攻击。** DoS 攻击阻止系统响应合法请求。常见的 DoS 攻击是 SYN 洪水攻击，它会破坏 TCP 三次握手。虽然较老的攻击因为基本防护措施而不再常见，但你仍可能会被考到，因为许多新攻击都是对旧方法的变体。Smurf 攻击利用放大网络发送大量响应包到受害者。Ping-of-death 攻击发送大量 oversized ping 包，导致受害者冻结、崩溃或重启。

**了解僵尸网络、僵尸网络控制者和僵尸指挥者。** 僵尸网络因能够动员大量计算机而构成重大威胁，因此了解它们很重要。僵尸网络是由被入侵的计算设备（通常称为僵尸或僵尸主机）组成的网络，受僵尸指挥者（bot herder）控制。僵尸指挥者使用命令和控制服务器远程控制僵尸，并常用僵尸网络发起针对其他系统的攻击，或发送垃圾邮件和钓鱼邮件。僵尸指挥者还会将僵尸网络访问权出租给其他罪犯。

**了解零日漏洞利用。** 零日漏洞利用是利用一种既被攻击者所知，又可能仅被有限人员知晓的漏洞的攻击。表面上看，似乎无法防范未知漏洞，但基本的安全实践仍能大幅降低零日漏洞的风险。移除或禁用不必要的协议和服务可缩小攻击面，防火墙阻断许多接入点，入侵检测和防御系统有助于检测并阻止潜在攻击。此外，使用蜜罐（honeypots）和加固单元（padded cells）也能保护生产网络。

**了解中间人攻击。** 中间人攻击发生在恶意用户能够在通信链路的两端之间获得逻辑位置时发生。虽然完成中间人攻击需要攻击者具备相当高的技术 sophistication，但从攻击中获取的数据量可能非常大。

**了解破坏和间谍行为。** 不满的内部人员可能会对组织进行破坏。间谍行为是竞争对手试图窃取信息，他们可能会利用内部员工。基本的安全原则，如实施最小权限原则并立即禁用已终止员工的账户，可以限制这些攻击的损害。

**了解入侵检测和入侵防御。** IDS（入侵检测系统）和 IPS（入侵防御系统）是重要的侦测和预防措施。了解基于签名的检测（使用类似防病毒签名的数据库）与基于行为的检测之间的区别。行为检测以基线为起点，识别正常行为，并与基线对比以检测异常活动。基线如果网络环境发生变化，可能会过时，因此在环境变更时必须更新基线。

**识别 IDS/IPS 的响应方式。** IDS 可以被动地记录日志并发送通知，或主动地改变环境。有些人将主动 IDS 称为 IPS，但需要注意的是 IPS 会置于流量链路中，并能在恶意流量到达目标之前阻止其传输。

**了解 HIDS 与 NIDS 的区别。** 基于主机的 IDS（HIDS）只能监控单个系统的活动，缺点是攻击者可以发现并禁用它们。网络基于 IDS（NIDS）可以监控整个网络的活动，且不易被攻击者察觉。

**了解蜜罐、加固单元和伪缺陷。** 蜜罐是一种常带有伪缺陷和假数据的系统，用来诱骗入侵者。管理员可以在攻击者停留于蜜罐期间观察其活动，确保攻击者不在真实网络中。一些 IDS 具备在检测到攻击后将攻击者转入加固单元的功能。虽然蜜罐和加固单元相似，但需注意：蜜罐诱骗攻击者，而攻击者在加固单元中被转移。
