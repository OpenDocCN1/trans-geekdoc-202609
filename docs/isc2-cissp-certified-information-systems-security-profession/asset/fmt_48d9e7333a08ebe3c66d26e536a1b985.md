### Describe the difference between TCP SYN scanning and TCP connect scanning.

TCP SYN scanning sends a SYN packet and expects a SYN‑ACK response without completing the three‑way handshake, while TCP connect scanning uses the operating system’s connect system call to complete the full handshake (SYN‑ACK‑ACK) and then tears down the connection.

### What are the three port status values returned by the nmap network discovery scanning tool?

The three port status values are **open**, **closed**, and **filtered**.

### What is the difference between static and dynamic code testing techniques?

Static testing examines source code without executing it, looking for defects in the code itself, whereas dynamic testing runs the compiled program and observes its behavior to find defects during execution.

### What is the difference between mutation fuzzing and generational fuzzing?

Mutation fuzzing modifies existing valid inputs by random changes (bit flips, insertions, deletions) to generate test cases, while generational fuzzing creates new inputs from models or grammars that represent expected input structures.
