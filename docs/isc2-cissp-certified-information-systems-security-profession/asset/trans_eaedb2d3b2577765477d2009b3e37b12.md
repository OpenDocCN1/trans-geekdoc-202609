
自2011年以来，大多数系统制造商在其主板上将传统的BIOS系统替换为统一可扩展固件接口（UEFI）。UEFI是硬件与操作系统之间更高级的接口，它仍然保持对传统BIOS服务的支持。

#### 设备固件

许多硬件设备（如打印机和调制解调器）也需要一定的处理能力来完成任务，同时尽量减轻操作系统本身的负担。在许多情况下，这些“微型”操作系统完全包含在服务于它们的设备上的固件芯片中。与计算机的BIOS类似，设备固件通常存储在EEPROM设备上，以便在必要时进行更新。

#### 客户端系统

客户端系统的漏洞会使用户、其数据以及系统面临被破坏和破坏的风险。客户端攻击是指任何能够损害客户端的攻击。通常在讨论攻击时，默认假设主要目标是服务器或服务器端组件。客户端攻击或客户端导向攻击是指客户端本身或客户端上的进程是攻击的目标。常见的客户端攻击示例是恶意网站将恶意移动代码（如小程序）传输到客户端上运行的易受影响的浏览器。客户端攻击可以通过任何通信协议发生，而不仅仅是超文本传输协议（HTTP）。另一个客户端基于的潜在漏洞是本地缓存中毒的风险。

#### Applets

请回顾，代理是从用户系统发送到远程系统以查询和处理数据的代码对象。Applets的作用相反；这些代码对象是从服务器发送到客户端以执行某些操作。事实上，Applets是能够独立于发送它们的服务器运行的自包含微型程序。万维网的使用场景不断变化。Applets的使用在当今已不像2010年代初期那样普遍。然而，Applets并未从Web中消失，大多数浏览器仍然支持它们（或仍有支持它们的插件）。因此，即使您的组织在内部或公共网页设计中不使用Applets，您的浏览器在浏览公共Web时仍可能遇到它们。

想象一个提供各种金融工具的Web服务器。其中一个工具可能是按揭计算器，它处理用户的财务信息，并根据贷款的本金、期限以及借款人的信用信息提供每月按揭支付额。与将数据处理并返回结果给客户端系统不同，远程Web服务器可能会向本地系统发送一个Applet，使其能够自行执行这些计算。这为远程服务器和最终用户带来了多项好处：

*   将处理负担转移到客户端，从而释放服务器资源以处理更多用户的请求。

*   客户端可以使用本地资源生成数据，而无需等待远程服务器响应。在许多情况下，这能加快输入数据变化时的响应速度。

*   在正确编程的Applet中，Web服务器不会接收作为输入提供给Applet的任何数据，从而保持用户财务数据的安全和隐私。

然而，与代理一样，Applets也带来了一系列安全问题。它们允许远程系统向本地系统发送代码以供执行。安全管理员必须采取措施确保网络中系统接收到的代码是安全的，并经过适当的恶意活动筛查。此外，除非代码逐行分析，终端用户永远无法确定Applet是否包含特马组件。例如，按揭计算器可能在未经用户知晓或同意的情况下将敏感的财务信息传输到Web服务器。

Applets的两个历史类型是Java Applets和ActiveX控件。

**Java Applets** *Java*是由Sun Microsystems（现被Oracle收购）开发的平台无关编程语言。Java在现代应用中基本被取代，且在大多数浏览器中不再直接支持。但您仍应了解Java，因为它可能仍在内部使用或在您组织所使用的特定浏览器中受支持。虽然现代Web设计已转移 away from Java，但这并不意味着Java从互联网上被清除。大多数编程语言使用编译器生成针对特定操作系统定制的应用程序，这需要为每个支持的平台使用多个编译器来生成该应用的不同版本。Java通过插入*Java Virtual Machine (JVM)*来克服这一限制。每个运行Java代码的系统会下载其操作系统支持的JVM版本。JVM然后将Java代码翻译成该特定系统可执行的格式。这种安排的巨大好处是，代码可以在不同操作系统之间无需修改即可共享。Java Applets仅是通过互联网传输的短Java程序，用于在远程系统上执行操作。

Java平台的设计将安全置于首位，Sun的开发团队创建了“沙箱”概念，用于对Java代码施加权限限制。沙箱将Java代码对象与操作系统的其余部分隔离，并严格限制这些对象可访问的资源。例如，沙箱会禁止Java Applet从未明确分配给它的内存区域检索信息，从而防止Applet窃取信息。不幸的是，尽管沙箱化减少了通过Java发起的恶意事件的形式，但仍有大量广泛被利用的其他漏洞。

**ActiveX Controls** *ActiveX*控件是Sun的Java Applets的Microsoft答案。它们的工作方式相似，但使用了多种语言实现，包括Visual Basic、C、C++和Java。Java Applets与ActiveX控件之间有两个关键区别。首先，ActiveX控件使用专有的Microsoft技术，因此只能在运行Microsoft浏览器的系统上执行。其次，ActiveX控件不受Java Applets所施加的沙箱限制。它们拥有完整的Windows操作环境访问权限，并能执行一系列特权操作。因此，在决定下载并执行哪些ActiveX控件时，必须采取特殊 precautions。一些安全管理员采取了相当严厉的立场，禁止除少数可信站点外的所有站点下载ActiveX内容。

ActiveX仍然受到Internet Explorer 11的支持，但Microsoft的最新浏览器Edge（随Windows 10发布）不包含ActiveX支持。这表明Microsoft正在逐步淘汰ActiveX。
