
This is not the only way to reduce predicate calculus formulas to theorems; there are other equivalent ways. The reduction to propositions is not logically equivalent, but the following assertion is true, which we give without proof.

**Set.** Those formulas that are obtained by reducing the original formulas to sets form an inconsistent set if and only if the original set of formulas does not hold.

Let's consider examples of reducing first-order predicate calculus formulas to propositions using the sequence of actions given above.

Let's reduce the formula to sentences: `∀ x (P(x) → ∃ y Q(x, y))`.

1.  `∀ x (¬ P(x) ∨ ∃ y Q(x, y))`
2.  Formula unchanged
3.  Formula unchanged
4.  `x ∃ y (¬ P(x) ∨ Q(x, y))`
5.  `∀ x (¬ P(x) ∨ Q(x, f(x)))`
6.  `¬P(x) ∨ Q(x, f(x))`
7.  Formula unchanged
8.  Formula unchanged

Now let's reduce the negation of the previous formula to theorems: `¬∀ x (P(x) → ∃ y Q(x, y))`.

1.  `¬ ∀ x (¬ P(x) ∨ ∃ y Q(x, y))`
2.  `∃ x (P(x) & ∀ y (¬ Q(x, y)))`
3.  Formula unchanged
4.  `x ∀ y (P(x) & ¬ Q(x, y))`
5.  `∀ y (P(a) & ¬ Q(a, y))`
6.  `P(a) & ¬ Q(a, y)`
7.  Formula unchanged
8.  `P(a), ¬ Q(a, y)`

### 4.1.4. Resolution Rule

The solving method uses not only a special kind of formulas, but also a special inference rule.

The **solution rule** (resolution rule) is the rule for deriving a new formula (theorem) from two theorems. **Resolution** — A new clause resulting from the application of the resolution rule.

The resolution rule applies only to clauses containing complementary literals (`P` and `¬P`) and is as follows. Given two clauses (which contain complementary unifiable literals), a new clause can be derived from that pair of clauses by combining the original clauses and eliminating the complementary literals:

```
P ∨ Q₁ ∨ ... ∨ Qₙ, ¬P ∨ R₁ ∨ ... ∨ Rₘ
---------------------------------------
Q₁ ∨ ... ∨ Qₙ ∨ R₁ ∨ ... ∨ Rₘ
```

Remember that we really like to write the inference rules "multi-story", i.e., like this: the premises (antecedent) of the rule are placed above the line, the conclusion (succedent) is placed below the line.

The **resolvent** is the union (more precisely, the disjunctive union) of all literals except for a pair of opposites. In this case, both the index `n` and the index `m` can have any value. In particular, if clauses are resolved that contain only complementary literals, then the resolvent is an **empty clause**. Note that by definition, an empty clause is considered identically false.

The resolution rule is a very powerful rule! Many rules (such as *modus ponens* [[65]](#part0005.xhtml#_ftn65)) are particular manifestations of the resolution rule. Table 4.1 below shows some well-known rules in the traditional form and written in the constraints of the resolution method when premises and conclusions are non-quantifier disjunctions of literals. These examples show that the resolution rule is no weaker than the traditional ones, and anything that can be derived in the traditional way using *modus ponens* can also be derived using the resolution rule!

**Table 4.1. Traditional and Resolving Form of Inference Rules**

| Rule Name | Traditional Form | Operational Form (Resolution) |
| :--- | :--- | :--- |
| **Modus Ponens** | `A, A → B` / `B` | `A, ¬A ∨ B` / `B` |
| **Hypothetical Syllogism** | `A → B, B → C` / `A → C` | `¬A ∨ B, ¬B ∨ C` / `¬A ∨ C` |
| **Merger** | `A ∨ B, A → B` / `B` | `A ∨ B, ¬A ∨ B` / `B` |

The resolution rule alone forms a complete and consistent set of rules (see point 0). Let us prove this assertion for the case of the propositional calculus by giving suitable simplified definitions.

An inference rule is **consistent** (sound) if the conclusion is a logical consequence of the premises.

**Theorem.** The resolution rule is consistent.

**Proof.** Let `I` be any interpretation, `C₁` and `C₂` are clauses that are resolved according to the resolution rule, `P` is the literal that is resolved upon. For clarity, assume that the predicate `P` enters clause `C₁` positively and enters `C₂` negatively. Let `C₁'` and `C₂'` be what you get after eliminating the complementary literals from the clauses.

By the condition of the theorem `I(C₁) & I(C₂)`. Then if `I(P)`, then `C₁' ≠ ∅ & I(C₁')`, meaning `I(C₁' ∨ C₂')`. If `I(¬P)`, then `C₂' ≠ ∅ & I(C₂')`, which means `I(C₁' ∨ C₂')` anyway. Q.E.D.

An inference rule is **complete** if a valid formula can be derived from this rule.

**Theorem.** The resolution rule is complete.

**Proof.** As is known, the *modus ponens* rule for propositional calculus is complete and a special case of resolution, as can be seen from Table 4.1. Q.E.D.

### 4.1.5. Unification

To apply the resolution method, we need to find the complementary literals. This problem does not exist with propositional calculus. Every variable and the same variable with a negation is a pair of complementary literals. With the first-order predicate calculus this is not so easy. Even if we found two occurrences of the same predicate, positive and negative, it doesn't mean that a complementary pair was found. Various arguments can follow the predicate letter, which can be different in each case. In some cases it is possible to **unify** literals by **substitution**, that is, to make such changes to variables that the atoms of the literals become the same, but in other cases this is not possible. There are algorithms (in particular **Algorithm 4.1**) that check whether two formulas (particularly two atoms) can be unified and find a set of unifying substitutions if unification is possible. Let's refine the definitions.

A **special case** (instance) of a formula is the result of substituting a specific term into a given formula in place of all occurrences of a specific variable in the original formula.

**Unification** is a method of computing a most general common instance for two formulas (if one exists).

A **unifier** is a set of substitutions of certain terms for variables, which, when applied to given formulas, makes them identical (yields their common instance).

The **most general unifier (MGU)** is the minimal substitution that unifies formulas.

Let's make some general comments about the definitions.

1.  In many formal theories, an instance of a formula is its logical consequence. This applies in particular to propositional calculus formulas and to clauses (quantifier-free disjunctions of literals).
2.  In the vast majority of cases, the formulas have no common instance. Therefore, during unification, it is important to receive a negative response as soon as possible.
3.  In general, instead of replacing a variable, you can substitute a term that contains the same variable. However, such a substitution can never result in unification, so such substitutions are forbidden in unifiers (occurs check).
4.  If `σ` is the most general unifier (standard abbreviation **MGU**) and `θ` is an arbitrary unifier, then there is a substitution `ρ` such that `θ = σ ∘ ρ`, where `∘` is the sign of composition of substitutions.

For example, two formulas `P(x, f(a))` and `P(g(b), y)` are unifiable, **MGU** `[P(x, f(a)), P(g(b), y)] = {g(b)/x, f(a)/y}`.

At the same time, the formulas `P(x, f(a))` and `P(y, g(b))` are not unifiable, because `f(a) ≠ g(b)` for any substitution of terms for variables. Also, the formulas `P(x, f(a))` and `P(g(b), x)` are not unifiable, since unification would require substituting term `f(a)` and term `g(b)` for the variable `x`, which is obviously impossible (occurs check violation).
