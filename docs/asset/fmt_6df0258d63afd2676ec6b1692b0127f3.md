
![Image](img/r.jpg) **B, D.** 渗透测试由安全专业人员执行，他们受特定范围和交互规则（rules of engagement）的约束，这些规则在评估开始前必须经过仔细制定、审查并达成共识。这种协议允许在组织高层管理人员决定要测试其 IT 安全人员的反应时间和方法时，进行不预告测试。

![Image](img/w.jpg) **A, C,** 和 **E** 是错误的，因为这些是关于渗透测试的错误陈述。除非范围协议中明确禁止，否则社会工程学是任何真实渗透测试的重要部分。范围协议通常定义了测试人员可以走多远——例如，不允许进行意的拒绝服务攻击等。测试后，会向客户提供一份发现的漏洞列表，即使团队没有利用它们：在评估过程中并不总能破解每一个安全漏洞，但这并不是向客户隐藏它们的理由。最后，最终报告中包含了所有参与测试的人员列表。

### 20. 以下哪种因素会导致潜在的安全泄露？

**A.** 漏洞 (Vulnerability)

**B.** 威胁 (Threat)

**C.** 漏洞利用 (Exploit)

**D.** 零日 (Zero day)

![Image](img/r.jpg) **B.** 那么哪个是先生的——鸡还是蛋？这个问题和它的逻辑非常相似，可能非常令人困惑，但如果你关注问题的“原因”部分，你就没问题了。当然，漏洞必须存在；然而，漏洞本身不会导致任何结果。`threat`（威胁）是可能利用现有漏洞的东西。威胁可以是故意的、无意的、人为的，甚至是“天灾”。黑客是一个利用系统上开放端口和/或弱质密码策略的威胁。雷暴雨是一个利用屋顶裂缝并导致水水渗漏到你系统中的威胁。老天，犀牛是一个会撞破并并毁房间内所有设备的威胁。这些威胁是否有意图、是否可行、以及是否愿意/能够利用漏洞，是需要风险评估来决定的；他们可能会加强密码策略并修复屋顶，但我怀疑在犀牛方面不会做什么。

![Image](img/w.jpg) **A** 是错误的，因为漏洞是安全方面的一个弱点。漏洞可能是一个问题，也可能不是一个问题。例如，你的系统可能有一个极其糟糕的密码策略，甚至缺少了安全补丁，但如果它从未连接到网络，并且被锁在一个有守卫的房间里，只有三个人可以进入，且他们必须通过生物识别系统才能打开门，那么这些漏洞的存在就没有意义。

![Image](img/w.jpg) **C** 是错误的，因为漏洞利用（exploit）是威胁主体为了利用漏洞而执行或实际上可以的操作。漏洞利用可以是局部的或远程的、一段软件、一系列命令，或任何实际利用漏洞获取访问权限或其他影响目标的东西。

![Image](img/w.jpg) **D** 是错误的，因为零日利用（zero-day exploit）仅仅是指我们大多数人在使用它时并不真正了解它的漏洞利用。例如，几年前，一些坏分子发现了 Adobe Reader 中的一个漏洞并开发了针对它的利用程序。从创建该利用程序到 Adobe 最终意识到其存在并构建了修复措施来缓解它之间，该利用程序被称为 `zero-day`。

### 21. 哪种 Metasploit 负载（payload）类型通过 DLL 注入运行，防病毒软件难以检测？

**A.** Inline（内联）

**B.** Meterpreter

**C.** Staged（分阶段）

**D.** Remote（远程）

![Image](img/r.jpg) **B.** 对于那些为这个问题恐慌的人，请放松。你不需要了解 Metasploit 的所有内部原理，但在用于 CEH 认证的各种学习材料中，它的出现频率足够高——EC-Council 希望你了解一些基础知识，而这个问题就属于这一类。Metasploit 中有许多不同的负载类型，`meterpreter`（meta-interpreter 的缩写）就是其中之一。以下摘自 Metasploit 网站：“Meterpreter 是一个包含在 Metasploit Framework 中的高级负载。它的目的是提供复杂且高级的功能，否则这些功能在汇编语言中实现将非常繁琐。它实现这一目标通过允许开发者以共享对象（DLL）文件的形式编写自己的扩展，这些文件可以在利用发生后被上传并注入到目标上的运行进程中。Meterpreter 及其加载的所有扩展完全在内存中执行，从不接触磁盘，从而允许它们在防病毒检测的防范区内执行。”

![Image](img/w.jpg) **A** 是错误的，因为内联负载（inline payloads）是包含完整利用和 shell 代码的单一负载。它们可能比其他负载更稳定，但由于体积原因，可能不适用于攻击。

![Image](img/w.jpg) **C** 是错误的，因为分阶段负载（staged payloads）在攻击机和受害者之间建立连接。一旦连接建立，负载就会返回并在远程机器上执行。

![Image](img/w.jpg) **D** 是错误的，因为“远程”（remote）并不是一种认可的负载类型。

### 22. Metasploit 是一个允许针对远程主机开发和执行利用代码的框架，设计用于渗透测试。框架由多个库组成，每个库执行特定的任务和功能。哪个库被认为是 Metasploit 框架最基础的组件？

**A.** MSF Core

**B.** MSF Base

**C.** MSF interfaces

**D.** Rex

![Image](img/r.jpg) **D.** 再次，这是另一个你在考试中可能会看到的奇怪问题（涉及框架的任何组件）。在这里包含是为了让你在实际考试中不会感到措手不及，也不会因为没听过它而不知所措。不要担心在考试前学习 Metasploit 的所有细节和架构——专注于记忆框架的基础知识（每个区域的关键词会有帮助），你就会没事的。

正如你们所知，Metasploit 是一个允许各种自动化（点对点）渗透测试方法的开源框架。该框架采用模块化设计，每个库和组件负责其自己的功能。以下摘自 Metasploit 的开发指南（你现在可以在很多地方找到，只需在 Google 上搜索 `msf_dev_guide filetype:pdf`）：“架构中最基础的部分是 Rex 库，它是 Ruby Extension Library 的缩写。Rex 提供的某些组件包括封装套接子系统、协议客户端和服务器的实现、日志子系统、利用工具类以及许多其他有用类。” Rex 为整个框架提供关键服务。

![Image](img/w.jpg) **A** 是错误的，因为 `MSF Core` “负责实现所有必需的接口，允许与漏洞模块、会话和插件进行交互。”它直接与 `Rex` 接口。

![Image](img/w.jpg) **B** 是错误的，因为 `MSF Base` “设计用于为处理框架核心提供简单的封装例程，并提供用于处理框架不同方面的实用程序类，例如将模块状态序列化到不同的输出格式”。Base 是 Core 的扩展。

![Image](img/w.jpg) **C** 是错误的，因为 `MSF` 接口是您（用户）与框架交互的手段。Metasploit 的接口包括 `Console`、`CLI`、`Web` 和 `GUI`。

#### 23. 下列哪些措施可能是针对内部攻击者的有效反措施？（选择所有适用项。）

**A.** 强制执行高特权控制。

**B.** 加固所有的垃圾桶和碎纸收集箱。

**C.** 强制良好的物理安全实践和政策。

**D.** 对所有员工进行背景检查。

![Image](img/r.jpg) **A, B, C, D.** 所有答案都是正确的。诚然地说，你确实无法做任何完全防止内部攻击。根本没有办法确保每一位员工都能保持快乐和满意，就像无法判断某人何时会突然决定转向犯罪一样。这种情况在美国企业界中不断发生，因此你所能做的最好的，当然就是你所能做的最好的。

强制执行高特权控制（即确保用户仅拥有完成工作所需的访问权限、权利和特权，而更多）似乎是一项常识，但许多企业网络竟然忽视了这一点，这令人惊叹。毕竟，一个对自己的机器拥有管理员权限的不满员工所造成的损害，比只有普通用户权限的员工大得多。加固垃圾桶和实施良好的物理安全措施应该有助于防止想要在下班后回来窥探的内部人员。此外，虽然对员工进行背景检查在那种情况下绝非灵丹妙药，但确实可以帮助确保你从一开始就招聘了正确的人（在许多公司，背景检查是 `law` 的要求）。以下是其他步骤：

* 监控用户网络行为。

* 监控用户计算机行为。

* 禁用远程访问。

* 在所有系统上禁用可移动驱动器的使用（USB 驱动等）。

* 粉碎所有丢弃的纸张。

* 进行用户教育和培训计划。
