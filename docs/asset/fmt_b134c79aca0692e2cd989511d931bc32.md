
**离散随机变量**：`X` 可以取自有限或可数无限集合中的任意值。

**连续随机变量**：`X` 的值为实数值。

### 2.2.2 多元随机变量

#### 2.2.2.1 联合累积分布函数

我们用 `F(x,y) ≜ P(X≤ x ∩ Y≤ y) = P(X≤ x, Y≤ y)` 表示联合累积分布函数。

```
p(u,v)
F(x,y) ≜ P(X≤ x, Y≤ y) = ∑_{u≤x,v≤y} p(u,v)  (离散)
F(x,y) ≜ P(X≤ x, Y≤ y) = ∫_{-∞}^{x} ∫_{-∞}^{y} f(u,v) du dv  (连续)
```

#### 2.2.2.2 边缘分布

**边缘累积分布函数**：

```
F_X(x) ≜ F(x, +∞) = P(X = x_i) = ∑_j P(X = x_i, Y = y_j)  (离散)
F_X(x) ≜ ∫_{-∞}^{x} f_X(u) du = ∫_{-∞}^{x} ∫_{-∞}^{+∞} f(u,v) dv du  (连续)
```

```
F_Y(y) ≜ F(+∞, y) = P(Y = y_j) = ∑_i P(X = x_i, Y = y_j)  (离散)
F_Y(y) ≜ ∫_{-∞}^{y} f_Y(v) dv = ∫_{-∞}^{y} ∫_{-∞}^{+∞} f(u,v) du dv  (连续)
```

**边缘概率质量函数和概率密度函数**：

```
P(X = x_i) = ∑_{j=1}^{+∞} P(X = x_i, Y = y_j)  (离散)
f_X(x) = ∫_{-∞}^{+∞} f(x,y) dy  (连续)
```

```
P(Y = y_j) = ∑_{i=1}^{+∞} P(X = x_i, Y = y_j)  (离散)
f_Y(y) = ∫_{-∞}^{+∞} f(x,y) dx  (连续)
```

#### 2.2.2.3 条件分布

**条件概率质量函数**：

```
p(X = x_i | Y = y_j) = p(X = x_i, Y = y_j) / p(Y = y_j)  if p(Y) > 0  (2.9)
```

概率质量函数 `p(X|Y)` 称为条件似然。

**条件概率密度函数**：

```
f_{X|Y}(x|y) = f(x,y) / f_Y(y)  (2.10)
```

#### 2.2.3 贝叶斯法则

```
p(Y = y | X = x) = p(X = x, Y = y) / p(X = x)
p(X = x | Y = y) p(Y = y) / ∑_{y'} p(X = x | Y = y') p(Y = y')  (2.11)
```

#### 2.2.4 独立性与条件独立性

如果我们可以将联合分布表示为两个边缘分布的乘积，即

```
P(X,Y) = P(X)P(Y)  (2.12)
```

则称 `X` 和 `Y` 为**显式独立**或**边缘独立**，记作 `X ⊥ Y`。

如果条件联合分布可以写成条件边缘分布的乘积，则称给定 `Z` 时 `X` 和 `Y` **条件独立**（CI）：

```
X ⊥ Y | Z = P(X,Y|Z) = P(X|Z)P(Y|Z)  (2.13)
```

#### 2.2.5 分位数

由于累积分布函数 `F` 是单调递增函数，它有一个反函数；我们将其记为 `F^{-1}`。如果 `F` 是 `X` 的累积分布函数，则 `F^{-1}(α)` 是使得 `P(X ≤ x_α) = α` 成立的 `x_α` 值；这称为 `F` 的 `α`-分位数。值 `F^{-1}(0.5)` 是分布的**中位数**，概率质量有一半在左侧，一半在右侧。值 `F^{-1}(0.25)` 和 `F^{-1}(0.75)` 分别是下四分位数和上四分位数。

#### 2.2.6 均值与方差

分布最自然的性质是其均值，或期望值，记为 `µ`。

对于离散随机变量，定义为 `E[X] ≜ ∑_x x p(x)`；对于连续随机变量，定义为 `E[X] ≜ ∫ x p(x) dx`。如果该积分不是有限的，则均值未定义。

方差是分布离散程度的度量，记为 `σ²`。定义如下：

```
var[X] ≜ E[(X - µ)²]
     = ∫ (x - µ)² p(x) dx
     = ∫ x² p(x) dx - 2µ ∫ x p(x) dx + µ² ∫ p(x) dx
     = E[X²] - µ²  (2.15)
```

由此我们得到有用的结果 `E[X²] = σ² + µ²` (2.16)。

标准差定义为 `std[X] ≜ √var[X]` (2.17)。这很有用，因为它与 `X` 本身具有相同的单位。

### 2.3 一些常见的离散分布

在本节中，我们回顾一些常用的定义在离散状态空间（包括有限和可数无限）上的参数分布。

#### 2.3.1 伯努利分布与二项分布

**定义 2.1**。现在假设我们只抛一次硬币。令 `X ∈ {0,1}` 为一个二元随机变量，成功或正面的概率为 `θ`。我们称 `X` 服从**伯努利分布**。这记作 `X ∼ Ber(θ)`，其概率质量函数定义为

```
Ber(x|θ) ≜ θ^{I(x=1)} (1-θ)^{I(x=0)}  (2.18)
```

**定义 2.2**。假设我们抛硬币 `n` 次。令 `X ∈ {0,1,...,n}` 为正面出现的次数。如果正面的概率是 `θ`，则称 `X` 服从**二项分布**，记作 `X ∼ Bin(n,θ)`。其概率质量函数为

```
Bin(k|n,θ) ≜ (n choose k) θ^k (1-θ)^{n-k}  (2.19)
```

#### 2.3.2 多努利分布与多项分布

**定义 2.3**。伯努利分布可用于模拟一次抛硬币的结果。为了模拟投掷一个 `K` 面骰子的结果，令 `x = (I(x=1), ..., I(x=K)) ∈ {0,1}^K` 为一个随机向量（这称为虚拟编码或独热编码），则称 `X` 服从**多努利分布**（或**分类分布**），记作 `X ∼ Cat(θ)`。其概率质量函数为：

```
p(x) ≜ ∏_{k=1}^K θ_k^{I(x_k=1)}  (2.20)
```

**定义 2.4**。假设我们投掷一个 `K` 面骰子 `n` 次。令 `x = (x_1, x_2, ..., x_K) ∈ {0,1,...,n}^K` 为一个随机向量，其中 `x_j` 是骰子第 `j` 面出现的次数，则称 `X` 服从**多项分布**，记作 `X ∼ Mu(n,θ)`。其概率质量函数为

```
p(x) ≜ (n! / (x_1! x_2! ... x_K!)) ∏_{k=1}^K θ_k^{x_k}  (2.21)
```

其中 `x_1 ... x_K ≜ x_1! x_2! ... x_K!`。

伯努利分布只是 `n = 1` 时二项分布的一个特例，正如多努利分布之于多项分布。见表 2.1 总结。

**表 2.1：多项分布及相关分布总结。**

| 名称 | K | n | X |
| :--- | :--- | :--- | :--- |
| 伯努利 | 1 | 1 | `x ∈ {0,1}` |
| 二项 | 1 | n | `x ∈ {0,1,...,n}` |
| 多努利 | K | 1 | `x ∈ {0,1}^K, ∑_{k=1}^K x_k = 1` |
| 多项 | K | n | `x ∈ {0,1,...,n}^K, ∑_{k=1}^K x_k = n` |

#### 2.3.3 泊松分布

**定义 2.5**。如果 `X ∈ {0,1,2,...}` 的概率质量函数为

```
p(x|λ) ≜ e^{-λ} λ^x / x!  (2.22)
```

则称其服从参数为 `λ > 0` 的**泊松分布**，记作 `X ∼ Poi(λ)`。

第一项只是归一化常数，用于确保分布总和为 1。

泊松分布常用作稀有事件计数的模型，如放射性衰变和交通事故。

#### 2.3.4 经验分布

经验分布函数，或经验累积分布函数，是与样本经验测度相关联的累积分布函数。令 `D = {x_1, x_2, ..., x_N}` 为样本集，其定义为

```
F_n(x) ≜ (1/N) ∑_{i=1}^N I(x_i ≤ x)  (2.23)
```

# 概率分布

## 高斯分布

如果 `X ∼ N(0,1)`，我们称 `X` 服从标准正态分布。高斯分布是在统计学中应用最广泛的分布。主要原因有以下几点：

1.  它有两个易于解释的参数，能够捕捉分布最基本的性质，即均值和方差。
2.  根据中心极限定理（见第 TODO 节），独立随机变量的和近似服从高斯分布，这使其成为建模残差误差或噪声的良好选择。
3.  在给定均值和方差的约束下，高斯分布做出的假设最少（具有最大熵），正如第 TODO 节所示；这使其成为许多情况下的良好默认选择。
4.  它具有简单的数学形式，由此产生易于实现且通常非常有效的方法，我们将在后续看到。关于高斯分布为何被广泛使用的更广泛讨论，请参见 (Jaynes 2003, ch 7)。

## Student's t 分布

其中 `Γ(x)` 是伽马函数：

```
Γ(x) = ∫_0^∞ t^{x-1}e^{-t}dt \tag{2.24}
```

`µ` 是均值，`σ² > 0` 是尺度参数，`ν > 0` 称为自由度。请参见图 2.1 查看部分图示。方差仅在 `ν > 2` 时定义。均值仅在 `ν > 1` 时定义。

作为 Student 分布鲁棒性的一个例证，请考虑图 2.2。我们看到高斯分布受影响很大，而 Student 分布几乎不变。这是因为 Student 分布具有更重的尾部，特别是对于较小的 `ν`（见图 2.1）。

如果 `ν = 1`，该分布称为柯西分布或洛伦兹分布。它以尾部如此之重以至于定义均值的积分不收敛而著称。

为保证方差有限，我们要求 `ν > 2`。通常使用 `ν = 4`，这在一系列问题中表现良好 (Lange et al. 1989)。当 `ν ≥ 5` 时，Student 分布迅速接近高斯分布并失去其鲁棒性。
