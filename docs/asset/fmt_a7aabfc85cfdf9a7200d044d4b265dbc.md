
其中 $\hat{x}_{n}(i)$ 是 ${\widehat{\mathbf{x}}}_{n}$ 的第 $i$ 个元素，已假设为零均值向量；这由以下事实证明：如果 $\Sigma[\hat{x}]$ 确实是对角矩阵且等于 $\Lambda$，则特征值对应于各元素的方差。各项 $\sigma_{i}^{2}$ 以时域递归方式估计，从而得到算法 5.6 所示方案。

### 算法 5.6：变换域 LMS

#### 初始化

1. $\widehat{\mathbf{\theta}}_{-1} = 0$ 或任意其他值。
2. $\sigma[-1]^{2}(i) = \delta, \quad i = 1, 2, \dots, l$；其中 $\delta$ 为较小值。
3. 选择 $\mu$，且 $0 \ll \beta < 1$。

#### 迭代过程

对于 $n = 0, 1, 2, \dots$ 执行：

1. $\widehat{\mathbf{x}}_{n} = T^{H}\mathbf{x}_{n}$
2. 对于 $i = 1, 2, \dots, l$ 执行：
   * $\sigma[i]^{2}(n) = \beta\sigma[i]^{2}(n-1) + (1-\beta)|\hat{x}_{n}|^{2}$
3. 结束内层循环
4. $D = \text{diag}\{\sigma[i]^{2}(n)\}$
5. $e_{n} = y_{n} - \widehat{\mathbf{\theta}}_{n-1}^{H}\widehat{\mathbf{x}}_{n}$
6. $\widehat{\mathbf{\theta}}_{n} = \widehat{\mathbf{\theta}}_{n-1} + \mu D^{-1}\widehat{\mathbf{x}}_{n}e_{n}^{*}$

结束外层循环

### 子带自适应滤波器

*子带自适应滤波器* 是一类相关算法，通过分块数据处理和多速率滤波器组实现白化。此类方案最早见于文献 [41, 53, 54]，并已成功应用于回声消除 [45, 53] 等场景。

另一种被采用以提高收敛速率的方法，针对系统辨识应用的情况，是选择特定类型的输入激励信号。例如，文献[5]指出，优化 NLMS 算法收敛速度的激励信号是一种确定性完美周期序列（PPSEQ），其周期等于系统的冲激响应。此类序列已在文献[24,25]中被用于推导 LMS 的变体，这些变体不仅收敛快，而且计算复杂度极低，每次更新仅需一次乘法、一次加法和一次减法。

信道均衡任务在图 4.12 中已作介绍。均衡器的输入是一个随机过程（随机信号），根据第 2.4 节引入的符号约定，将其表示为 `u[n]`。请注意，在接收到被（通信）信道加噪和失真的样本 `u[n]` 后，必须获得最初发送的信息序列 `s[n]` 的估计值，该估计值延迟了 `L − 1` 个时间滞后，这考虑了所涉及的整体传输系统施加的各种延迟。因此，在时刻 `n`，均衡器判决 `ŝ[n − L + 1]`。理想情况下，如果已知最初发送的信息序列直到并包括时刻 `n − L` 的真实值，用 `s[n − L]`、`s[n − L − 1]`、`s[n − L − 2]…` 表示，利用该信息连同接收序列 `u[n]` 来恢复 `ŝ[n − L + 1]` 的估计值，只会有益无害。这一思路在*判决反馈均衡器*（DFE）中得以探索。对于复值数据情况，均衡器的输出现在写为

```
${\widehat{d}}_{n} = \sum\limits_{i = 0}^{L - 1}w_{i}^{f \ast}u_{n - i} + \sum\limits_{i = 0}^{l - 1}w_{i}^{b \ast}s_{n - L - i} = \mathbf{w}^{H}\mathbf{u}_{e,n}$
```

其中

$$

\mathbf{w} := \begin{bmatrix} \mathbf{w}^{f} \\ \mathbf{w}^{b} \end{bmatrix} \in \mathbb{C}^{L + l},\quad \mathbf{u}_{e,n} := \begin{bmatrix} \mathbf{u}_{n} \\ \mathbf{s}_{n} \end{bmatrix} \in \mathbb{C}^{L + l}

$$

![Equation](img/si397.png)

和

$$

\mathbf{s}_{n} := \left[ s[n-L], \dots, s[n-L-l+1] \right]^{T}

$$

![Equation](img/si398.png)。

时刻 $n$ 的目标/期望响应为

$$

d[n] = s[n-L+1]

$$

![Equation](img/si399.png)

在实际应用中，初始训练期结束后，信息样本 $s[n-L-i]$ 将由其计算出的估计值 $\hat{s}[n-L-i],\ i = 0, 1, \dots, l-1$ 替代，这些估计值可从先前时刻做出的判决中获得。此时称均衡器处于*判决导向*模式。基本 DFE 结构如图 5.20 所示。注意在训练期间，参数向量 $\mathbf{w}$ 经过训练以使误差功率最小化，

$$

e[n] = d[n] - \hat{d}[n] = s[n-L+1] - \hat{d}[n]

$$

![Equation](img/si402.png)

一旦所有可用的训练样本都已用完，训练将继续使用估计值 `ŝ[n − L + 1]` 进行。例如，对于二进制信息序列 `s[n] ∈ {1, −1}`，通过将 `d̂[n]` 传递给阈值判决器来获得时刻 `n` 的估计判决，从而得到 `ŝ[n − L + 1]`。注意，DFE 是*半监督*学习的早期示例之一，其中训练数据不足，估计值被用于训练 [94]。通过这种方式，假设在训练阶段结束时 `ŝ[n − L + 1] ≈ s[n − L + 1]`，并且假设时间变化缓慢，以保证 `d̂[n] ≈ d[n]`，我们有理由期望（以足够大的概率）`ŝ[n − L + 1]` 将保持接近 `s[n − L + 1]`，从而使均衡器能够跟踪变化。关于 DFE 及其误差性能的更多内容见 [77]。

![图 5.20 DFE 的前向部分作用于接收样本，而后向部分作用于训练数据/判决，具体取决于运行模式。](img/gr020.jpg)

**图 5.20** DFE 的前向部分作用于接收样本，而后向部分作用于训练数据/判决，具体取决于运行模式。

迄今为止处理的任何在线/自适应方案都可以用于 DFE 场景，方法是在输入向量 `u_e` 中，当在判决导向模式下运行时，将项 `s[n]` 替换为 `ŝ_n`。注意，自适应算法首次用于均衡任务的背景见 [44, 78]。一种在频域工作的 DFE 版本首次在 [14] 中提出。

因此，线性 DFE 的 LMS 递归公式集，在其复值形式下，变为

#### 算法描述

**公式：**

```
d̂[n] = w[n−1]ᴴ u[e, n]
d[n] = s[n−L+1];          // 训练模式下
d[n] = T[d̂[n]];           // 决策导向模式下
e[n] = d[n] − d̂[n]
w[n] = w[n−1] + μ u[e, n] e[n]*
```

其中 `T[·]` 表示阈值操作。
