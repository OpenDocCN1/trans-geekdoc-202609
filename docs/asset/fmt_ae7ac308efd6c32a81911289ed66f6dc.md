## 信息收集与漏洞扫描

**本章涵盖了与 CompTIA PenTest+ PT0-002 考试领域 2.0（信息收集与漏洞扫描）相关的以下主题：**

*   2.1 给定一个场景，执行被动侦察。
*   2.2 给定一个场景，执行主动侦察。
*   2.3 给定一个场景，分析侦察练习的结果。
*   2.4 给定一个场景，执行漏洞扫描。

攻击者在策划攻击时采取的第一步是收集有关目标的信息。这种信息收集的行为被称为 `reconnaissance`（侦察）。攻击者使用扫描和枚举工具，结合互联网上公开的信息来建立关于目标的档案。正如你可以想象的，作为一名渗透测试员，你也必须复制这些方法，以确定你正试图防御的网络和系统的暴露情况。本章将开始讨论什么是侦察，以及被动方法与主动方法之间的区别。你将简要学习一些常用的工具和技术。从那里，本章将深入探讨漏洞扫描的过程。

`主动侦察` 是一种信息收集方法，其工具实际上会向目标网络或系统发送探测包，以获取响应，然后利用这些响应来确定网络或系统的状态。这些探测包可以使用多种协议和不同程度的攻击性，通常取决于扫描的内容和时间。例如，你可能正在扫描一个像打印机这样没有健壮 TCP/IP 栈或网络硬件的设备。通过发送主动探测包，可能会导致此类设备崩溃。大多数现代设备没有这个问题；但这种情况是可能的，因此在进行主动扫描时，你应该意识到这一点并相应地调整扫描器的设置。

`被动侦察` 是一种信息收集方法，工具不直接与目标设备或网络交互。被动侦察有多种方法。有些涉及使用第三方数据库来收集信息。另一些则使用工具的方式使其不会被目标发现。特别是这些工具的工作原理仅仅是监听网络上的流量，并利用情报推断出网络上设备通信的信息。这种方法对网络的侵入性小得多，这种类型的侦察极不可能导致打印机等系统崩溃。因为它不产生任何流量，所以也不可能被发现，且不会在其调查的网络上引起任何警报。另一个让被动扫描器派上用场的场景是：渗透测试人员需要对无法中断的生产网络进行分析。你使用的被动侦察技术取决于你想要获得的信息类型。学习渗透测试最重要的方面之一是建立良好的方法论，这将帮助你在执行任务期间选择合适的工具和技术。

### DNS 查询

假设例如，一个攻击者盯上了一个目标 `h4cker.org`。`h4cker.org` 像大多数公司一样在互联网上有存在。这种存在表现为一个托管在 `www.h4cker.org` 的网站。就像入室窃贼在实施抢劫之前需要确定家里有哪些入口和出口一样，网络攻击者需要确定目标的哪些端口和协议暴露在互联网上。窃贼可能会绕着房子外面走走，寻找门窗，然后可能查看门上的锁以确定它们的弱点。类似地，网络攻击者会执行扫描和枚举等任务。

通常，攻击者会从少量信息开始，在扫描过程中收集更多信息，最终转向执行不同类型的扫描并收集额外信息。例如，针对 `h4cker.org` 的攻击者可能首先使用 DNS 查询来确定 `h4cker.org` 使用的 IP 地址或地址以及任何其他可能使用的子域名。假设这些查询显示 `h4cker.org` 正在使用 IP 地址 `185.199.108.153` 用于 `www.h4cker.org`，使用 `185.199.110.153` 用于 `mail.h4cker.org`。示例 3 显示了在 Kali Linux 中使用 `dnsrecon` 工具查询 `h4cker.org` 的 DNS 记录的示例。
