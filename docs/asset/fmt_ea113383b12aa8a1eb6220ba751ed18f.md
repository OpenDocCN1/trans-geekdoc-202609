#### 无分类器引导

前一种方法的一个主要问题是需要训练一个单独的分类器。在文献 [86] 中，通过联合训练条件和无条件扩散模型，绕过了对单独分类器的需求。

让我们用 `s_θ(x_t, t, y)` 表示评分函数的类条件估计，用 `s_θ(x_t, t)` 表示无条件估计。在训练期间，使用单个神经网络来参数化这两个模型。这是通过一个简单的技巧实现的。使用一个对应于无条件模型的输入标记 `∅`，将类嵌入向量代入关联的类标签 `y` 的位置。即：

```
s_θ(x_t, t) = s_θ(x_t, t, y = ∅).
```

通过根据预先选定的用户定义概率 `p_∅`，在条件输入（`y ≠ ∅`）和无条件输入（`y = ∅`）之间随机选择，联合训练条件和无条件模型。

为了对类条件模型执行采样，通过以下线性组合获得所需的评分函数估计：

$$
\widehat{\mathbf{s}}_{\mathbf{\theta}_{\ast}}(\mathbf{x}_{t},t,y) = \mathbf{s}_{\mathbf{\theta}_{\ast}}(\mathbf{x}_{t},t,\varnothing) + \gamma\left( \mathbf{s}_{\mathbf{\theta}_{\ast}}(\mathbf{x}_{t},t,y) - \mathbf{s}_{\mathbf{\theta}_{\ast}}(\mathbf{x}_{t},t,\varnothing) \right),
$$

其中 $\gamma > 0$ 是引导尺度常数。换句话说，神经网络的输出被进一步外推至 $\mathbf{s}_{\mathbf{\theta}_{\ast}}(\mathbf{x}_{t},t,y)$ 的方向，并远离 $\mathbf{s}_{\mathbf{\theta}_{\ast}}(\mathbf{x}_{t},t,\varnothing)$。如果两边同时取负号，并乘以该时间步对应的标准差，则公式 (19.85) 可以等价地用相应的 $\boldsymbol{\epsilon}_{\boldsymbol{\theta}}$ 估计值来表示，以替代 $\mathbf{s}_{\boldsymbol{\theta}}$。注意，若 $\gamma = 0$，公式 (19.85) 退化为无条件模型；若 $\gamma = 1$，则与标准类条件模型一致。

公式 (19.85) 的解释依赖于公式 (19.83)。公式 (19.85) 涉及公式 (19.83) 中真实对应项的近似梯度，前提是我们使用一个*隐式*分类器：

$$
q^{(i)}(y|\mathbf{x}_{t}) \propto \left( \frac{q(\mathbf{x}_{t}|y)}{q(\mathbf{x}_{t})} \right)^{\gamma}.
$$

注意，根据贝叶斯法则：

$q(y|\mathbf{x}_t) \propto \frac{q(\mathbf{x}_t|y)}{q(\mathbf{x}_t)}.$

![Equation](img/si694.png)

换句话说，在隐式分类器中，我们将前面的比率提升到 `γ` 次方。在实践中，选择 `γ` 的值是在样本多样性和样本质量之间进行权衡的结果。在生成图像时，增加 `γ` 会降低多样性并提高样本保真度，例如 [86]。这在图 19.25 中展示。最左边的图对应无条件模型，`γ = 0`（高多样性-低保真度），中间的图对应 `γ = 1.5`，最右边的图对应 `γ = 3`（低多样性-高保真度）。^(¹⁴⁷)

图 19.25（左）无条件模型（`γ` = 0）表现出高多样性和低图像保真度。（中）对应 `γ` = 1.5。（右）对应 `γ` = 3，表现出低多样性和高图像保真度。

正如我们即将看到的，基于分类器或无分类器引导的条件模型已被扩展并用于这样的情况：模型受约束的不再是类别标签，而是更一般的约束，例如文本描述。

### 19.7.7 应用

扩散模型已被应用于广泛的领域，目前，在越来越多的学科中采用此类建模的趋势正在快速增长。

在计算机视觉中，除了图像和视频生成外，它们还被用于图像超分辨率、编辑、修复、复原和分割等任务。在时间序列分析中，它们被应用于插补、预测、波形生成等任务。在 NLP 任务中，它们被用于序列到序列生成，例如 [60]。关于相关的大量文献综述，请参见例如 [41]、[200]、[115]。

最“热门”且知名度最高的应用之一（远超科学界）是文本到图像生成，下文将重点介绍。

#### 文本到图像生成

文本到图像生成可以被视为一种以相应文本描述为条件的图像生成任务。文本到图像生成的主题可追溯至 [127]，其中 DRAW ([65]) 生成模型被扩展为以图像标题为条件以生成新颖的视觉场景。在这项工作之后，[153] 采用了一种 GAN，提高了生成图像的质量，并能生成具有可识别属性的物体。在 [151] 中，文本到图像生成是基于 Transformer 进行的，该 Transformer 将文本和图像标记自回归地建模为单一数据流。^(¹⁴⁸)

**CLIP**：遵循自监督背后的通用原理，CLIP 使用两个分支联合训练两个编码器。请参阅图 19.26 以获取简化的框图。上部分支编码器的输入被馈送描述图像的文本描述（标题），该标题又馈送给下部分支编码器的输入。例如，如果图像包含一只戴帽子的狗（如图所示），相应的描述可能是“戴帽子的狗”。标题中的文本经过适当的嵌入（参见例如第 19.3.1 节）后被编码为相应的向量表示。

![Figure 19.26 CLIP consists of two branches. In the upper one, a text description/caption is prompted, which is then mapped into a vector embedding, t. The lower branch is fed with an image, x, that relates to the text description. In the sequel, t and x are provided as inputs to two parameterized encoders, gϕ and fξ, respectively. The corresponding encoded outputs, zt = gϕ(t) and zi = fξ(x), are used in the contrastive loss function \mathcal{L}Equation. The parameters, ϕ and ξ, of the two encoders are jointly optimized to make the respective encoded outputs, zt and zi, more similar (dissimilar) if the text description and the content of the corresponding image match (do not match).](img/gr026.jpg)

图 19.26 CLIP 由两个分支组成。在上部分支中，输入一段文本描述/标题，随后将其映射为向量嵌入 `t`。下部分支输入一幅与该文本描述相关的图像 `x`。随后，`t` 和 `x` 分别作为输入被提供给两个参数化编码器 `g_ϕ` 和 `f_ξ`。相应的编码输出 `z_t = g_ϕ(t)` 和 `z_i = f_ξ(x)` 被用于对比损失函数 `ℒ`。两个编码器的参数 `ϕ` 和 `ξ` 被联合优化，以使相应的编码输出 `z_t` 和 `z_i` 在文本描述与相应图像内容匹配（不匹配）时变得更相似（不相似）。

设 `t` 和 `x` 分别为输入相应编码器的文本和图像表示。两个编码器的输出记为 `z_t = g_ϕ(t)` 和 `z_i = f_ξ(x)`，它们具有相同的维度。参数 `ϕ` 和 `ξ` 分别对两个编码器进行参数化，根据对比损失原理进行联合优化，该原理已在第 19.6.5 节中讨论过。换句话说，在训练期间，如果字幕中的描述与图像内容匹配，则根据对比损失函数使两个编码器的编码输出向量更加相似；如果不匹配，则使其更加不相似。相似度通过归一化内积函数来量化。例如，假设一幅图像包含一只猫，并被编码为 `z_i`。对于图像内容的描述，我们给出两个字幕。一个是“A cat sitting”（编码为 `z_t`），另一个是“A dog running”（编码为 `z_t'`）。那么，我们期望训练后：

```
\frac{\mathbf{z}_{t}^{T}}{||\mathbf{z}_{t}||}\frac{\mathbf{z}_{i}}{||\mathbf{z}_{i}||} > \frac{{\mathbf{z}_{t}^{\prime}}^{T}}{||\mathbf{z}_{t}^{\prime}||}\frac{\mathbf{z}_{i}}{||\mathbf{z}_{i}||},
```

其中 `|| ⋅ ||` 表示欧几里得范数。关于两个编码器网络的详细信息见文献 [149]。

在推理阶段，数据集中的每幅图像都被视为一个*单独的类别*。给定一个文本描述/字幕，对其进行编码，所得向量表示与数据集中图像的编码表示进行比较。根据相似度度量（归一化内积）的最大值选择一幅图像。在计算机视觉中，这种将示例视为单独类别的分类类型称为单样本分类。^(¹⁴⁹)

**GLIDE**：在文献 [132] 中提出的名为*用于生成和编辑的引导语言到图像扩散*模型中，CLIP 扮演分类器的角色，以引导扩散模型中的反向过程。CLIP 在*含噪*图像 `x_t` 上单独训练。在扩散模型反向过程的采样期间，条件模型均值 `μ_θ* (x_t, t, t)` 在给定文本字幕 `t` 的条件下被扰动为：

$$
\widehat{\boldsymbol{\mu}}_{\boldsymbol{\theta}_{\ast}}(\mathbf{x}_{t},t,\mathbf{t}) = \boldsymbol{\mu}_{\boldsymbol{\theta}_{\ast}}(\mathbf{x}_{t},t,\mathbf{t}) + \gamma\Sigma_{\boldsymbol{\theta}_{\ast}}(\mathbf{x}_{t},t,\mathbf{t})\nabla_{\mathbf{x}_{t}}\left( \mathbf{f}^{T}(\mathbf{x}_{t})\mathbf{g}(\mathbf{t}) \right),
$$

![Equation](img/si704.png)

其中，**f**(·)和**g**(·)分别表示与预训练 CLIP 的图像编码器在时间*t*的输出（即**x**[*t*]）和文本编码器的输出（即**t**）相关的向量函数。换句话说，公式(19.82)中对数概率的梯度被两个编码器输出嵌入向量的内积梯度所替代。

除了基于 CLIP 的引导外，GLIDE 还使用了第 19.84 节中的无分类器引导概念，其中标签*y*被相关的字幕**t**所替代，而∅对应空文本序列。据报道，无分类器引导能产生质量更高的图像。

GLIDE 经过训练，可基于文本字幕编码生成图像，这些编码由基于文本 Transformer 的编码器输出产生；实现细节请参见文献[132]。

##### unCLIP

在文献[152]中，文本到图像生成任务采用了三步法。

*   首先训练一个 CLIP 网络，通过两个编码器的输出嵌入向量，在潜在空间中学习文本和图像的联合表示。
*   训练一个所谓的*先验*扩散模型，以生成*CLIP 图像嵌入向量*，这些向量*条件*于相应的编码文本字幕，并可选择性地条件于相应的 CLIP 文本嵌入向量。为提高样本质量，还采用了无分类器引导方法，在训练期间有 10%的时间随机丢弃文本条件信息。
*   采用一个称为解码器的扩散模型，该模型经过训练可基于先验扩散模型生成的*CLIP 图像嵌入向量*生成图像。也可选择性地采用基于编码文本字幕的条件。解码器中也使用了无分类器引导，在训练期间有 10%的时间随机将 CLIP 嵌入向量设为零，并有 50%的时间随机丢弃文本字幕编码。解码器还涉及两个超分辨率扩散上采样模型。

虽然解码器可直接使用 CLIP 图像嵌入向量工作，但先验模型可以*生成*条件于字幕输入的图像嵌入向量。名称 unCLIP 表明图像是通过反转 CLIP 图像编码器来生成的。此外，这种设置便于在潜在（CLIP 嵌入）空间中进行图像操作，如插值、编辑等。

图 19.27 展示了 unCLIP 网络的简化框图。^(¹⁵⁰)

##### 文本到图像生成：简要讨论

前文讨论的最先进文本到图像生成器被证明非常强大，能够将不相关的概念（如物体、纹理、颜色）组合起来，生成具有前所未有的照片真实度的采样示例。这使它们具有巨大的潜力，可部署并用于各种应用。然而，由于其强大的能力，也引发了一系列伦理问题。

例如，此类模型可能成为恶意行为者生成有害内容和深度伪造的有力工具^(¹⁵³)

虚假信息的传播不仅危害个人，例如霸凌或性虐待。其影响远不止于此，还构成了威胁，动摇了与我们作为人类的社会和政治结构相关的基本核心功能与规范。作为社会性生物，我们需要基于知情决策参与集体行动。大规模、快速传播的虚假信息会严重损害这一人类独有的社会活动，而该活动是推动进步与文明的基本力量之一，例如 [143]。

此外，相关平台对艺术家和图形设计师构成了巨大威胁。针对这一问题，此类平台的一些最新版本被设计为拒绝生成在世艺术家风格图像的请求。

*   **性能度量**：我们已在第 19.7.5 节讨论过，设计生成网络的一个主要目标是使生成样本具有良好的质量并展现广泛的覆盖范围。换句话说，生成的样本应“忠实”于用于训练的真实样本，并且应尽可能多样化，其变化应与训练集中的变化相匹配。在第 19.2.5 节末尾，曾讨论了初始分数（IS）和 Fréchet 初始距离（FID）作为相关度量。这些也被用于评估扩散模型的性能。然而，根据其定义，这些指标试图通过单一指数来衡量上述概念。
*   最近，例如在文献 [162]、[106] 中，提出可以通过两个独立的指标来衡量质量和多样性。*精确率*衡量平均样本质量，*召回率*量化样本分布的覆盖范围。用更“专业”的术语来说，设 `p[r]` 和 `p[g]` 分别为真实样本和生成样本的分布。*精确率*是从 `p[g]` 中随机生成的样本落入 `p[r]` 支撑集内的概率。*召回率*是从 `p[r]` 中随机抽取的样本落入 `p[g]` 支撑集内的概率。
