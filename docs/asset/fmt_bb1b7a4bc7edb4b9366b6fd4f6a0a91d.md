
### 11.10.2 不可分类别

我们现在将注意力转向更现实的类别重叠情况，以及公式 (11.61)–(11.63) 中任务的相应几何解释。在这种情况下，不存在能够正确分类所有点的（线性）分类器，必然会发生一些错误。图 11.17 展示了线性分类器的相应几何结构。注意，尽管类别不可分，我们仍将间隔定义为两个超平面 $f(\mathbf{x}) = \pm 1$ 之间的区域。存在三类点。

*   位于边界上或间隔之外且在分类器正确一侧的点，即
    $$
    y_n f(\mathbf{x}_n) \geq 1
    $$
    这些点不产生（间隔）错误，因此对于
    $$
    \xi_n = 0
    $$
    满足 (11.62) 中的不等式。

##### 支持向量机中的点分类

*   **位于分类器正确一侧但在边界内的点（圆圈标记）**：即
    $$
    0 < y_n f(\mathbf{x}_n) < 1.
    $$
    ![Equation](img/si376.png)

*   这些点犯了边界错误，且满足公式 (11.62) 中的不等式：
    $$
    0 < \xi_n < 1.
    $$
    ![Equation](img/si377.png)

*   **位于分类器错误一侧的点（方块标记）**：即
    $$
    y_n f(\mathbf{x}_n) \le 0.
    $$
    ![Equation](img/si378.png)

*   这些点犯了分类错误，且满足公式 (11.62) 中的不等式：
    $$
    1 \le \xi_n.
    $$
    ![Equation](img/si379.png)

![Figure 11.17 当类别重叠时，存在三类点：(a) 位于边界外或边界上且分类正确的点（$\xi_n = 0$）；(b) 位于边界内且分类正确的点（$0 < \xi_n < 1$），用圆圈表示；(c) 分类错误的点，用方块表示（$\xi_n \ge 1$）。](img/gr017.jpg)

**图 11.17** 当类别重叠时，存在三类点：(a) 位于边界外或边界上且分类正确的点（$\xi_n = 0$）；(b) 位于边界内且分类正确的点（$0 < \xi_n < 1$），用圆圈表示；(c) 分类错误的点，用方块表示（$\xi_n \ge 1$）。

我们希望估计一个超平面分类器，以**最大化边界，同时将错误数量（包括边界错误）保持在尽可能小的水平**。如果用指示函数 $I(\xi_n)$ 代替 $\xi_n$，这一目标可通过优化任务 (11.61)–(11.62) 来表达，其中
$$
I(\xi) = \begin{cases}
1, & \text{if } \xi > 0, \\
0, & \text{if } \xi = 0.
\end{cases}
$$
![Equation](img/si381.png)

然而，在这种情况下任务变成了组合优化问题。因此，我们放宽条件，用 $\xi_n$ 代替指示函数，从而得到公式 (11.61)–(11.62)。注意，优化是在权衡的原则下实现的；用户定义的参数 $C$ 控制着最小化任务中两个贡献项的影响力。若 $C$ 很大，所得边界（由 $f(\mathbf{x}) = \pm 1$ 定义的两个超平面之间的距离）将很小，以减少边界错误的数量。若 $C$ 很小，情况则相反。正如我们将从仿真示例中看到的，$C$ 的选择至关重要。

###### 解

解再次表示为训练点子集的线性组合：
$$
\widehat{\boldsymbol{\theta}} = \sum_{n=1}^{N_s} \lambda_n y_n \mathbf{x}_n,
$$
![Equation](img/si351.png) (11.79)

其中 `\lambda[n]`，`n = 1, 2, …, N[s]`，是与支持向量相关联的非零拉格朗日乘子。在这种情况下，支持向量是指所有位于以下位置的点：(a) 位于定义间隔的那一对超平面上；或 (b) 位于间隔内部；或 (c) 位于间隔外部但在分类器的错误一侧。也就是说，位于间隔外部的正确分类点不参与解的构成，因为对应的拉格朗日乘子为零。对于 RKHS 情况，类别预测规则与公式 (11.68) 相同，其中 `\thetâ[0]` 由对应于 `\lambda[n] ≠ 0` 和 `\xi[n] = 0` 的约束条件计算得出；这些点对应于位于定义间隔的超平面上且在分类器正确一侧的点。

###### 优化任务

和以前一样，初次阅读时可以跳过这一部分。

与 (11.61)–(11.63) 相关的拉格朗日函数由下式给出：
```
L(θ, θ₀, ξ, λ) = ½‖θ‖² + C∑ₙ₌₁ᴺ ξₙ − ∑ₙ₌₁ᴺ μₙξₙ − ∑ₙ₌₁ᴺ λₙ(yₙ(θᵀxₙ + θ₀) − 1 + ξₙ)
```
从而得到以下 KKT 条件：
```
∂L/∂θ = 0 ⟶ θ̂ = ∑ₙ₌₁ᴺ λₙyₙxₙ
```
(11.80)

##### KKT 条件与对偶问题

$$
\frac{\partial L}{\partial\theta_{0}} = 0\ \longrightarrow\sum\limits_{n = 1}^{N}\lambda_{n}y_{n} = 0,
$$
![Equation](img/si386.png)(11.81)

$$
\frac{\partial L}{\partial\xi_{n}} = 0\ \longrightarrow\ C - \mu_{n} - \lambda_{n} = 0,
$$
![Equation](img/si387.png)(11.82)

$$
\lambda_{n}(y_{n}(\boldsymbol{\theta}^{T}\boldsymbol{x}_{n}+\theta_{0})-1+\xi_{n}) = 0,\ n = 1, 2, \dots, N,
$$
![Equation](img/si388.png)(11.83)

$$
\mu_{n}\xi_{n} = 0,\ n = 1, 2, \dots, N,
$$
![Equation](img/si389.png)(11.84)

$$
\mu_{n} \ge 0,\ \lambda_{n} \ge 0,\ n = 1, 2, \dots, N,
$$
![Equation](img/si390.png)(11.85)

按照我们熟悉的步骤，对偶问题表述为：
$$
\text{maximize with respect to}\ \boldsymbol{\lambda}\quad\sum\limits_{n = 1}^{N}\lambda_{n} - \frac{1}{2}\sum\limits_{n = 1}^{N}\sum\limits_{m = 1}^{N}\lambda_{n}\lambda_{m}y_{n}y_{m}\boldsymbol{x}_{n}^{T}\boldsymbol{x}_{m}
$$
![Equation](img/si391.png)(11.86)

subject to $0 \le \lambda_{n} \le C,\ n = 1, 2, \dots, N$，
![Equation](img/si392.png) (11.87)

$$\sum_{n=1}^{N} \lambda_n y_n = 0.$$
![Equation](img/si368.png) (11.88)

在 RKHS 中工作时，代价函数变为
$$\sum_{n=1}^{N} \lambda_n - \frac{1}{2} \sum_{n=1}^{N} \sum_{m=1}^{N} \lambda_n \lambda_m y_n y_m \kappa(\mathbf{x}_n, \mathbf{x}_m).$$
![Equation](img/si369.png)

请注意，与 (11.74)–(11.76) 中线性可分情况的对应公式相比，唯一的区别在于 `\lambda[n]` 的不等式约束中存在 `C`。以下评论按序排列：

*   由式 (11.83) 可知，对于位于间隔之外且在分类器正确一侧的所有点（对应 `\xi[n] = 0`），我们有
    $$y_n(\boldsymbol{\theta}^T \mathbf{x}_n + \theta_0) > 1,$$
    ![Equation](img/si372.png)

*   因此，`\lambda[n] = 0`。也就是说，这些点不参与式 (11.80) 中解的形成。

*   只有对于位于边界超平面上、间隔内部，或位于间隔外部但在分类器错误一侧的点，才有 `\lambda[n] \neq 0`。这些点构成了支持向量。

*   对于位于间隔内部或位于间隔外部但在错误一侧的点，`\xi[n] > 0`；因此，由式 (11.84) 可得 `\mu[n] = 0`，由 (11.82) 可得
    `\lambda[n] = C`.
    ![Equation](img/si397.png)

*   位于间隔边界超平面上的支持向量满足 `\xi[n] = 0`，因此 `\mu[n]` 可以非零，从而得到
    `0 \le \lambda[n] \le C`.
    ![Equation](img/si399.png)

##### 备注 11.5

*   **\nu-SVM**：文献 [104] 给出了 SVM 分类的另一种公式化，其中间隔由一对超平面定义，
    $$\boldsymbol{\theta}^T \mathbf{x} + \theta_0 = \pm \rho,$$
    ![Equation](img/si400.png)
    而 *ρ* ≥ 0 作为自由变量，由此产生 *ν*-SVM；*ν* 是一个额外参数，用于控制 *ρ* 在相关代价函数中的重要性。文献 [23] 已证明，对于 *C* 和 *ν* 的适当选择，*ν*-SVM 和上述讨论的公式（有时称为 *C*-SVM）会导致相同的解。然而，*ν*-SVM 的优势在于 *ν* 可以直接与支持向量数量的界限以及相应的错误率联系起来（另见 [123]）。

*   • **简化凸包解释**：文献 [58] 表明，对于线性可分类别，SVM 公式等价于寻找由两类数据形成的凸包之间的最近点。该结果在文献 [33] 中推广到了重叠类别的情况；文中表明，在这种情况下，*ν*-SVM 任务等价于寻找与训练数据相关的*简化凸包*（RCH）之间的最近点。搜索 RCH 是一个组合性质的计算难题。文献 [73–75,121] 高效地解决了该问题，提出了通过最近点搜索算法求解 SVM 任务的高效迭代方案。更多相关内容可参考文献 [66,122,123]。

*   • **ℓ₁ 正则化版本**：迄今为止讨论的优化任务中使用的正则化项一直基于 ℓ₂ 范数。大量研究工作集中在将 ℓ₁ 范数正则化用于处理线性情况的任务。为此，除了平方误差、合页损失和 *ϵ*-不敏感版本外，还使用了许多不同的损失函数，例如逻辑损失。此类任务的解属于第 8 章讨论的一般框架。事实上，其中一些方法已在该章中讨论过。文献 [131] 提供了相关的简明综述。

*   • **多任务学习**：在多任务学习中，两个或多个相关任务（例如分类器）被联合优化。此类问题在计量经济学和生物信息学等领域备受关注。文献 [40] 表明，如果使用一族适当定义的多任务核函数，带有正则化的多任务函数估计问题可以转化为单任务学习问题。

##### 示例 11.4

在本示例中，在二分二维分类任务的背景下测试 SVM 的性能。数据集包含 *N* = 150 个在区域 [−5, 5] × [−5, 5] 内均匀分布的点。对于每个点 **x**[*n*] = [*x*[*n*, 1], *x*[*n*, 2]]^(*T*)，*n* = 1, 2, …, *N*，我们计算
*y*[*n*] = 0.05*x*[*n*, 1]³ + 0.05*x*[*n*, 1]² + 0.05*x*[*n*, 1] + 0.05 + *η*，
其中 *η* 代表方差为 *σ*[*η*]² = 4 的零均值高斯噪声。根据噪声的值以及该点相对于函数图像的位置，将其分配给两个类别之一：
*f*(*x*) = 0.05*x*³ + 0.05*x*² + 0.05*x* + 0.05
在二维空间中。即，如果 `x[n, 2] ≥ y[n]`，该点被分配给类 `ω[1]`；否则，分配给类 `ω[2]`。

使用了高斯核，`σ = 10`，因为这产生了最佳性能。图 11.18A 显示了 `C = 20` 时获得的分类器，图 11.18B 显示了 `C = 1` 时的分类器。观察获得的分类器（因此性能）如何严重依赖 `C` 的选择。前一种情况下，支持向量的数量等于 64，后一种情况下等于 84。

### 11.10.3 SVM 的性能与应用

SVM 的一个显著特征是其复杂度独立于相应 RKHS 的维度。这影响泛化性能；SVM 在实践中表现出非常好的泛化性能。理论上，这种主张由其在优雅的 `structural risk minimization theory`（结构风险最小化理论）框架内的最大边界解释来证实 [28, 123, 127]。

文献 [77] 报告了一项广泛的比较研究，涉及 SVM 与其他 16 种流行分类器的性能对比。结果验证了 SVM 在这些分类器中名列前茅，尽管存在其他方法得分更好的情况。文献 [25] 报告了另一项比较性能研究。然而，必须注意，这些结果如今更多具有历史价值，因为它们是在深度网络时代兴起之前进行的。

很难找到一个与机器学习/模式识别相关的学科，其中未应用 SVM 和核空间工作的概念。早期应用包括数据挖掘、垃圾邮件分类、目标识别、医学诊断、光学字符识别 (OCR) 和生物信息学（例如，参见 [28] 综述）。较新的应用包括认知无线电（例如 [35]）、频谱制图和网络流预测 [9] 以及图像去噪 [13]。
