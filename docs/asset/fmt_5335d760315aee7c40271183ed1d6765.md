# 机器学习技术用于商业智能与决策

Vijay Anand Rajasekaran, Magesh Guru, Veena Grover DOI: [10.1201/9781032051873](https://doi.org/10.1201/9781032051873)

## 引言

商业智能（BI）是收集和分析数据以寻求见解并进行决策的过程。传统的商业智能严重依赖描述性分析，提供对过去的回顾[1–3]。大数据是指数据在数量、多样性和速度上的爆炸，这使得传统的 BI 工具无法处理，迫使其从中提取价值，而机器学习已被证明是游戏规则改变者。因此，它是补充商业智能框架不可或缺的工具。

它有助于商业智能从描述性和诊断性分析向预测性和指导性分析转型。预测性分析预测未来事件。指导性分析则为预期结果提供行动策略。这种高级分析能力允许企业预测客户需求、优化运营并识别市场新机会。此类机器学习驱动的商业智能系统超越了静态仪表板和基于规则的报告，让组织享受动态和实时的见解。

这是机器学习在商业智能背景下的特征：机器学习实际上可以处理非结构化数据的样本。传统方法通常限于关系数据库中的结构化数据，而机器学习算法可以处理文本、图像、视频和其他形式的非结构化数据。这种能力在当今数字世界中更为相关，因为机构正在社交媒体、客户评论、物联网设备等方面收集大量的非结构化数据。例如，情感分析是机器学习的一个领域，企业可以根据社交媒体上的可用文本数据理解客户的意见和偏好。这种见解对于定制营销策略具有极高价值[4–6]以增强客户体验并确保品牌忠诚度。机器学习影响商业智能的另一种重要方式是与其实时决策潜力有关。

传统的流程按时间分批进行大部分商业智能。通过来自物联网传感器、交易系统甚至在线平台的流式数据，机器学习算法可以为业务人员提供即时见解和建议。例如，在电子商务网站案例中，动态定价算法将使用机器学习根据需求、竞争定价以及库存水平动态更新价格。同样，在金融服务中，在使用机器学习的异常欺诈检测系统中，异常交易模式将在发生时立即被标记，从而确保实时干预的可能性。最后，但同样重要的是，机器学习技术的多样性凸显了处理许多业务挑战的灵活性。

监督学习、无监督学习、强化学习和深度学习，都更适用于特定的 BI（商业智能）领域使用场景。监督学习基于标记数据集提供解决方案，为大多数与预测相关的任务提供方案，例如销售预测、客户细分和信用风险评估。深度学习是 `ML` 的子领域，其通过神经网络的应用在处理高维数据时取得了令人瞩目的成果，这为图像识别处理、语音处理和自然语言处理（NLP）等领域带来了先进进展。在 BI 领域采用 `ML` 方法时会出现一些问题。

这些问题中的第一个是数据样本的质量和可用性。`ML` 算法的好坏取决于输入其中的数据。质量较差或不完整的数据会导致偏见和错误的决策，而且 `ML` 系统的实际实现和配置投入了大量精力——基础设施、人才和工具。大多数公司并不擅长此，因为将 `ML` 引入 BI 对能力有很高的要求——数据科学、编程技能以及其所在工作领域的某些知识。此外，在决策过程中应用 `ML` 时，还存在数据隐私、公平性和透明等重大的伦理问题。只有当技术创新与强大的治理结构同时出现时，才能解决此类问题。但考虑到与 BI-ML 相关的所有问题，其收益不容忽视，许多组织正在少数部门内开展工作，并引入 `ML` 来支持其决策并在竞争中占据更好位置。

零售商使用基于 `ML` 的推荐引擎来个性化客户的购买体验，从而提升销售和客户满意度。预测性分析协助医疗领域的临床人员预测患者需求、优化治疗方案并改进结果。在制造业中，通过 `ML` 进行预测性维护减少了停机时间并最大化了运营效率。可解释人工智能 (`XAI`)旨在使 `ML` 系统变得透明且可解释。长期以来，深度神经网络等复杂模型一直受到"黑箱"问题的困扰。此外，通过联邦学习（一种允许在不共享原始数据的情况下进行协作模型训练的技术），医疗、金融和其他行业的隐私保护分析的未来正在开启。`AutoML` 自动化了构建和调优 `ML` 模型的过程，使高级分析变得民主化，并赋予了组织可以利用的少量数据科学专业知识以在 BI 中使用 `ML`。总之，释放数据样本的潜力将彻底改变 BI 和决策。

从描述性分析向预测性和指导性分析的转变将使企业能够以竞争优势发现运营趋势。它的转型是多功能性的，开启了分析非结构化数据的能力、做出实时决策的可能性、解决多样化问题的能力并改变了 BI 系统。随着企业在数字化旋涡中航行，如何将 `ML` 集成到 BI 系统将成为决定组织智能数据驱动策略的关键组件。本章描述了驱动这些进展的特定 `ML` 技术，并阐述了它们如何应用、以及在智能业务管理中的优势和挑战。通过对这些主题的全面涵盖，读者将能够理解 `ML` 将如何改变 BI 的未来面，以及它是如何改变决策过程的。

### 3.1.1 BI 的定义与范围

BI 是过程、技术和工具的集合，能够将原始数据转换为洞察，为业务每个部门做出妥善决策提供信息。BI 是基于组织战略的数据分析核心构建过程，该战略基于通过增强运营效率来改善客户体验，从而获得竞争优势。随着时间的推移，它反映了技术的进步和数据格局日益的复杂性。今天，BI 通用称为工具的集合（如数据分析、可视化和报告），这些工具支持基于组织的决策。它涵盖了从数据采集、以可用格式处理、分析趋势到向利益相关者直观呈现结果的全端到端流程。

通常，大多数 BI 系统包含许多工具和技术，涉及数据仓库、提取、转换和加载 (`ETL`) 过程、在线分析处理 (`OLAP`)。这些部分集成在一起以确保数据集成、实时分析和自动化报告，这对于在竞争环境中生存的现代企业至关重要。

#### 3.1.1.1 BI 的范围

数字时代下 BI 的地平线由于大数据技术、云计算和人工智能的快速创新已经跨越了多个边界。到目前为止，BI 只能实现静态报告和仪表板；相反，动态决策和实时决策已属于 BI 的范畴。这些变化 [7–9](#ch03.xhtml#_24032-0872_chp003_ref9) 重写了 BI 范围的规则：

> **数据管理与集成**：BI 的核心在于帮助管理和整合来自各种来源的数据。现代组织从交易系统、客户交互、供应链运营甚至 IoT 设备中产生海量数据。BI 系统在强大的数据集成框架中聚合数据，以确保一致性、准确性和可靠性。数据仓库解决方案提供了一个中心存储库，用于存储和组织数据以便于访问和分析。BI 中的数据集成不仅限于传统数据库典型的结构化数据，还包括半结构化和非结构化格式，如电子邮件、社交媒体内容、传感器读取和多媒体文件。这种能力有助于捕捉业务运营和客户行为的完整且全的画面。

**描述性、预测性和指导性分析**：BI 可以认为涵盖了某些分析能力，从非常描述性的分析到稍微先进的预测性和指导性方法。描述性分析涉及总结过去的历史，以解释在那段时间内发生了什么。

预测性分析通过使用 `ML` 算法将 BI 提升到另一个水平，对趋势和结果给出未来预测。通过预测性 BI 模型，企业可以预测客户群的流失、需求波动甚至供应链的中断风险。指导性分析再次更进一步，从预测的场景中开出最佳行动方案。因此，在提取实时交通数据结合过去趋势后，物流公司将获得关于最高效率路线的指导性见解。

**实时决策支持**：使现代 BI 具有高度的转型性：提供实时决策支持能力。在今天，特别是在快速变化的业务环境中，任何组织都无法跟上变化的速度进行数据分析和反应。BI 系统中的实时分析和数据可视化工具使利益相关者能够监控关键性能指标 (KPI)、识别异常并做出实时响应。例如，电子商务网站可以根据客户的实时需求和竞争对手的活动动态调整价格或库存。这种实时能力将 BI 的范围从传统业务领域扩展到金融交易、网络安全和物联网（IoT）驱动的行业。它使企业能够保持敏捷性 `[10–12]`，并通过实时的可执行见解保持主动性。

**自助服务民主化**：BI 工具的自助服务民主化是近期过去的主要趋势之一；它已经扩展到了非技术用户。自助服务 BI 解决方案允许业务用户自行浏览和分析数据，而无需寻求 IT 团队或数据科学家的服务。这些通常带有直观的用户界面、拖拽功能和自然查询能力，帮助跨部门的利益相关者独立探索数据，以获得对流程的洞察。因此，自助性质使其应用涵盖了每个行业和组织体系中的每个层级，从使用仪表板制定战略计划的执行团队，到为运营决策寻求信息的前线员工。

**跨行业应用**：BI 具有多功能性，适用于每一个行业。在零售业，它改进了客户细分、库存管理和营销活动的执行。医疗保健领域利用 BI 更好地优化患者护理资源、资源分配并优化运营。

**高级数据可视化和报告**：可视化是 BI 的基石。因此，人们可以使用图表、图形、热力图等工具视觉化地解释复杂的信息。可视化工具曾非常复杂，但现在通过更简单、更具互动性的方式呈现见解，使其进入了一个完全不同的领域，以便与更广泛的用户进行交流。仪表板促进了对丰富见解的交互式探索，用户可以深入研究数据点或关系，以发现某些静态报告无法呈现的发现。BI 报告已进一步发展，演变为自动的、AI 驱动的自然语言叙述，总结数据洞察中的趋势，并将技术分析与业务语言接起来，使其在过程中易于解释并具有可操作性。

**协作与移动 BI**：协作是 BI 的本质。特别是对于大型组织而言，这是一种内在属性，因为决策过程跨越了许多利益相关者。协作 BI 允许团队通过集成的通信功能共享见解并标注报告，从而使战略一致。

**伦理与合规维度**：随着 BI 系统日益复杂且无处不在，伦理考量随同合规性问题一起出现，这些必将属于 BI 系统的范畴。例如，所有的 BI 活动应完全符合 GDPR 和 CCPA，特别是数据隐私立法。此外，它们应该考虑有关数据分析和决策系统的偏差、透明度和问责制的伦理问题。通过这种方式，组织通过将这些 XAI 技术集成到 BI 系统中克服了这些风险，并在过程中使见解更有信息量且易于解释。

#### 3.1.1.2 商业智能 – 意义与范围

它随着技术的进步、数据使用量的增加以及在决策过程中对此类信息依赖程度的提高而演变。BI 在现代业务战略发展中的潜力作用几乎是无限的，从管理不同的数据源和复杂分析到实时决策和协作。它的范围正随着自助工具、移动 BI 和伦理框架的演变，成为任何希望在这一数据驱动的世界中领先的组织的不可或缺的工具。从本质上说，BI 的核心功能是将原始数据转化为执行的见解，帮助企业应对不确定性并抓住机会，从而获得可持续的增长。当企业在数据洪流中运行并需压力下做出及时决策时，机器学习通过跨复杂数据的自动模式、趋势发现以及预测性输出等形式来满足这一需求，使决策者能够在正确的土地上进行战略移动。

### 3.1.2 机器学习变革决策范式

企业传统的决策方式涉及直觉、经验和基于规则的系统。在动态环境中，由于不断变化的复杂性因素，这些决策模式将暴露出弱点。机器学习变革了这一范式：数据驱动决策 (DDDM) 是基于证据而非主观的见解。通过 ML 模型分析获取的历史数据，提取出的模式关系是人类分析师无法感知的。这些发现为不同业务功能（包括营销、运营和财务）的明智决策形成了基础。机器学习对决策艺术产生的最关键的影响之一在于其处理海量、高维数据集的能力。在信息来源方面，现代组织现在从许多来源产生信息：可以来自客户互动、物联网设备和社交媒体。ML 算法非常高效地处理这些信息，从而提取有用特征并过滤掉噪声进行精确分析。这对于在考虑各种变量和限制的情况下做出决策的零售、医疗保健和制造业非常重要。

#### 3.1.2.2 实时决策支持

在当今瞬息万变的商业环境中，竞争优势将取决于实时决策。因此，`ML` 将促进即时决策，因为它能够对流数据进行实时处理并即时交付可操作的洞察。这在动态定价、欺诈检测和供应链优化等情景中变得尤为重要。电子商务平台是一个经典的例子，`ML` 算法可以根据需求、竞争对手定价和库存水平动态调整价格。因此，金融服务中的此类异常可以通过异常检测模型自动标记，这些模型通过扫描实时交易数据来发现可能的欺诈活动。提供速度与准确性融合的高级 `ML` 架构支持实时决策。在线学习算法与流处理框架的集成，帮助企业在新数据到达时不断更新其模型。因此，这种方法将导致更低的延迟和更好的响应，且决策是基于过程中范围内最新信息做出的。

#### 3.1.2.3 个性化与以客户为中心的策略

`ML` 驱动决策的一个关键优势是，它能够实现独特客户体验的个性化。由于零售、娱乐和医疗健康领域的客户需求和偏好差异巨大，个性化变得越来越重要。因此，`ML` 模型将通过客户数据来提供推荐、内容和服务，旨在提供更令人满意和更高忠诚度的体验。
