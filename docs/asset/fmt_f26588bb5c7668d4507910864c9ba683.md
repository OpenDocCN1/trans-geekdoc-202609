# 序言

当我于2019年7月写此文时，新闻中充斥着与组织化（通常是国家级）团体引起的计算机问题的报道。这包括：俄罗斯对社交媒体产生影响力以干扰欧盟和美国选举的报道；针对市政府和医疗保健机构部署的勒索软件的报道；中国间谍活动人员对知识产权的大规模盗窃；美国为了报复无人机坠毁而对伊朗指挥控制系统进行的攻击；对伊朗和俄罗斯秘密渗透电力系统基础设施的警告；以及对北朝鲜黑客可能对金融系统发动攻击的警告——这一切都发生在短短两周内！

为了给我的言论提供背景，请考虑我已经在现在所谓的“网络安全”和“国家安全”领域工作了近四十年。我通过打孔卡和插线板学习编程。我曾帮助运行过最早的社交媒体之一（Usenet）。我在普渡大学创立了全球网络安全中心（CERIAS），它是全球最大的网络安全中心之一。在所有这些时间里，我看到计算机事件的节奏稳步增加，损害不断增长。是的，防御措施也得到了发展，但其应用并不均衡。此外，随着人口的增长，寻找规避这些控制以盗取有价值物品、操纵认知和破坏功能的方法也随之增加。现在的威胁是我见过的最严重的，并且仍在持续增长……损失的增长也也是如此。

我们如何描述这些损失和行为者，将影响我们应对他们的方式。这些作案者仅仅是罪犯，还是别的什么？当国家行为实施敌对行为时，这些是好斗的姿态、是“合法”间谍活动、是恐怖主义，还是战争行为？如果是战争行为，我们为什么不动用全部力量去应对？为什么我们对许多事件的反应似乎是无效率的？这些是涉及政策问题的语义问题，已有许多人探讨过。

# 第一章

## 战争的特征与本质以及震蠕病毒陷阱

### 战争的特征与战争的本质

战争是对明确敌对对象的政策导向的武力使用，是人类事务中一个持久但令人不快的元素。战争的证据至少可以追溯到公元前 10000 年。卡尔·冯·克劳塞维的《战争论》在写作两个世纪后仍然是一部具有里程碑意义的作品，因为它在其他方面还解释了武力和暴力是政策目标的表达和工具。¹不确定性、人类敌对之间相互反应的斗争，以及为了实现政策目标而使用的武力，继续描述着战争的本质。军事史显示，敌双方试图在冲突中获得优势，这通常涉及使用不同的方法或战术、使用不同的技术，并且经常对战术和技术同时进行改变，以便更有效地使两者协同工作。

攻击与技术的结合包括：17 世纪长方形方阵（tercio）的发展，该阵列配备了长矛和火绳枪，能够以相对相等的感觉进行推进或撤退；18 世纪步兵以密阵列移动并配备带有刺刀的联动式火枪，进行斜线攻击；以及 20 世纪合成兵种作战的出现，其中步兵可以与友军武装部队协同推进，并由空中力量引导火力攻击敌人。这三个例子中战斗的特征是截然不同的：特西奥方阵以步行速度移动，拥有有限的有机火力，但可以迅速改变方向；而发起的斜线攻击的密集的步兵以相同的速度移动，力量更大但灵活性较小，同时拥有更大的火力；合成兵种部队可以移动得更快，并协同投送出毁灭性的大量火力。

### 网络战争的神话与现实

尽管它们作为组织在维持和在战斗中使用方面有不同的后勤需求。每个例子都展示了合并战术和技术以应对其各自时代冲突挑战的不同表现。尽管每种方式对单一战争的特征都有重要影响，但这三者都没有改变战争的本质。手持长矛的方阵步兵、18 世纪的火枪手、坦克坦克以及他们的任何同事，都参与了使用武力来支持其各自社会或国家的政策目标。战争的本质是持久，新战术或技术的引入并没有改变战争的本质。

随着新技术的出现，新的战斗领域改变了战争的特征，但它们没有改变战争的本质。然而，虽然新领域频繁出现在战场，但新的战斗领域出现得很少。这可能会诱导人们想象新战斗领域的出现可能会以某种方式成为革命性战争。此外，大多数用于开发的新领域都是最近出现的，这为“新领域改变战争核心”的观点提供了虚假的真实感。虽然陆战可以追溯到公元前 10000 年，而第一次海战被认为发生在公元前 1200 年左右，落后了九个世纪。相比之下，其他领域的引入发生在 1903 年莱特兄弟之后、20 世纪世纪 60 年代的太空领域，以及自互联网以来的网络领域。

这三个例子中战斗的特征是截然不同的：特西奥方阵以步行速度移动，拥有有限的有机火力，但可以迅速改变方向；而发起的斜线攻击的密集的步兵以相同的速度移动，力量更大但灵活性较小，同时拥有更大的火力；合成兵种部队可以移动得更快，并协同投送出毁灭性的大量火力。

### 网络战的迷话与现实

甚至阻碍了对某些历史战争的深入理解，而且这种“影响并控制对手的判断和战斗意志”的新机会并没有推翻战争的本质.¹¹¹⁰

格雷格·康蒂（Greg Conti）和大卫·雷蒙德（David Raymond）在《论网络空间》（*On Cyber*）一书中对网络战的理解和传达是如此有力：

> “网络带来了新的能力，并将从根本上改变战争。然而，从核心来看，战争将依然是战争。战争是丑陋、卑鄙的，并且伴随着我们……正如空中力量无法解决所有问题，网络也是如此。然而，网络空间将在未来的所有冲突中发挥日益重要的作用。”¹¹¹

尽管这一点明确，许多著作（包括几项优秀且值得引用的研究）甚至认为，战争的经典哲学已被网络冲突取代，“扩大了可能伤害的范围并超过了战争与和平的概念”。——¹² 新形式的危险构成了威胁性的威胁，但它们并不会使对战争的基本理解失效，正如炮兵、空中力量或战场武器的引入尽管对冲突性质产生了不可否认的影响，但并没有改变战争的本质一样。

此外，基于政策的紧张局势难以用“战争”术语归类，并带来了令人头疼的政策挑战；然而，这在军事史上并非一个完全全新的动态。考虑到人员的生命危险和国家政策目标的重大利害，意味着“战争鼓励——甚至迫使人们努力进行创新。战争的本质部分在于，战争的特征将会改变。”¹³ 棘手的挑战可能比它们看起来要新，而且它们很可能是为了希望扰乱对手的准备并帮助获得胜利而进行的尝试。

对手对竞争优势的追求带来了重塑不同冲突特征的挑战。当研究人员谈论网络领域中“技术、政策和社会维度的混合……结合在一起创造并完成了协同进化的复杂自适应系统”¹⁴时，历史学家在战斗的物理领域发现了相似之处。因此，战争的特征而非本质在进行自我重塑。为了实现目的而施加敌意行为仍然是战争意义的核心，即使犯罪行为和战争行为在发生时可能难以区分。“将网络安全危机称为网络战的影响”是巨大的，因为在防御侵略者时可能考虑的反应与抓捕罪犯涉及的工作不同。当然，事件的范围也可能存在重要差异。这些考虑解释了为什么政策制定者及其顾问——以及为了集体安全而建立的国际联盟——在将“战争”一用于网络攻击时表现出犹豫，即使在怀疑对手国家发起了攻击的情况下，即使在政治因素似乎与其动机有关的情况下¹⁵

### 战争的特征与本质，以及斯塔克斯网陷阱

这可能与关于物理破坏或死亡可能如何影响与“战争”相关的网络战措施的其他担忧是分开的。然而，从根本上说，决定行为是否构成战争是一个政治问题。这一决定取决于许多因素，不同的决策者在做出决定时使用不同的标准和背景。这在实际上强制导致了共识的缺失。

本书将网络战广泛地视为将网络领域卷入政策目标之中。因此，网络战涉及技术行动，这些行动在本章中受到了关注，也是第2、3、4章的重点。隐私专家布鲁斯·施奈尔（Bruce Schneier）贴切地将恶意软件描述为一种“功能性升级。它是你不想要的、你不请求的、你不需要的，是由某人给给你的东西。”¹⁶ 使用恶意软件等技术手段获取非法访问以支持政治相关动机的行为，符合本书对网络攻击的定义。其他不那么微妙的活动，包括为了政治目的而发起的目标拒绝服务（DoS），也属于这一范畴。

关于网络战的无数反复出现的格言已变成根深蒂固的迷话。这些包括关于网络武器特征的观点，如瞬时打击、使距离和地理变得无关、易于且广泛获取，以及作为一次性工具（因为它们会暴露其利用漏洞）。其他迷话则涉及网络武器的影响，包括关于其本质上可逆的影响、关于网络进攻的自然主导地位、目标在自身受害过程中的作用，以及网络与较老的冲突领域之间的关系。

政治动机的社交媒体敌意行为和对存储数据的利用占据了第5、6、7章的注意力，并出现在第8章。这意味着网络领域被用作在其他领域可能被识别的活动的载体。作为全球日益增长的人口的新闻和连接的主要来源，社交媒体是信息操作的一个极具吸引力的途径。不同的社交媒体和社交网络应用特别适用于其他类型的冲突相关活动，包括非国家组织分散成员之间的离散通信。社交媒体在冲突中的效用，与其在所谓的言论民主化以及机构对政治言论和武力使用的优势和垄断下降有关。数字通信本质上产生数据，这些数据被定期用于不同的目的，包括重新用于支持战略目标。

正如老生常调的情况，事实被推断和扭曲到了需要研究和澄清的程度。本书旨在对网络领域及通过网络进行的政治导向型斗争中流行的某些概念提供重要的分析。

### 广义定义“战争”

定义非常重要，关于什么构成“网络攻击”或“网络战”的问题会极大影响对网络领域敌意活动严重性的判断以及可以采取的应对。然而，对于这些问题的观点非常多；但在国家和国际层面难以达成共识。学术研究和行动似乎总共归为三类思想：广义地解释网络攻击和战争、狭义地解释，以及根据情境背景而非铁律原则对事件进行案例分类。

广义定义的倡导者认为，领域内攻击性活动的政治取向比任何损害或杀伤力方面的基准更能表明该行为是一次“攻击”或“战争”的一部分¹⁷某些作者提供了非常广泛的定义，例如“网络战争是利用信息系统针对个人或群体的虚拟形象”。美国国家标准与技术研究院（NIST）宣布，“任何试图收集、干扰、拒绝、降级或破坏信息系统资源或信息本身的恶意活动”均构成网络空间中的攻击¹⁸ 如果攻击的有效性没有比攻击者的动机重要，那么根据该论点，即使是失败的攻击也应该被承认其本意。

模糊性可以被解释为支持这种观点。技术网络攻击与网络间谍活动的相似性，是军事力量的动能攻击在物理领域并不具备的相似性。当军事单位寻求渗透敌方的防御位置时，渗透者穿着的武器、设备甚至服装可能与战斗员相对应。旨在研究目标系统以获取数字入侵者，与计划实施 NIST 识别为攻击的干扰、拒绝、降级或破坏的入侵者无法很好区分。这种相似性是因为造成此类伤害之前的准备步骤涉及了解目标系统是如何运作的。

证据表明，网络领域中一些臭名昭著且极具攻击性的国家行为者支持广泛的、甚至是随意扩张的“数字领域实战”概念。使用入侵工具和恶意软件的技术性网络攻击被解释为处于长光谱中的一部分，而该光谱还包括将数字通信作为支持国家战略目标的媒介。由于目前对网络武器没有明确的禁令，据报道，某些行为者认为这整个光谱都保持开放状态。这种观点已经延伸得远到，包含了与北朝鲜相关的勒索软件攻击。

其他网络攻击的支持者则希望，网络空间可以被使用并接受为一种谨慎减少高伤亡战争和此类冲突死亡人数的手段。拉宾（Rabin）和优（Yoo）认为，“战争规则必须进化以跟上技术”，并赞赏他们的信念，即“网络武器提供的比动力武器更多”，从而能够实现强制性信息传递，而不会将战争推向光谱中更具“总体性”、更严重的极端。为了消除针对其军事指挥控制系统的定向网络攻击（这可以被解释为侵略者后续攻击的网络准备）的风险，“限制升级到对抗的风险”可能会让对民用基础设施发动网络攻击成为明智之举。”拉宾和优暗示“精确网络攻击提供了外交和经济压力之外的更多步骤，但尚未达到常规水平”，他们不仅将网络攻击解释为实现目标，还主张在冲突背景下接受通过网络空间进行一系列敌对行动。

### 网络战的神话与现实

说拉宾和优支持西方学者中的一种非传统观点是低估了。其他学者建议，更谨慎、更节制地使用网络武器是可以接受的。一位现代哲学家指出，“理想的战争应该是那种平民伤亡极小或不存在，且暴力行为能够完美区分战斗员与非战斗员的战争”，并认为“网络战使得这种理想的战争成为可能。”

尽管一些支持者推崇利用该领域来推进类似于战争的政策目标，但另一些人对网络定义非常广泛，同时以此寻求限制被接受的活动范围。法律和伦理问题已延伸到防御者的追踪和惩罚入侵者的工作中。由于这种主动防御（也称为黑客行为）“通常涉及侵入多台计算机，根据《计算机欺诈和滥用法》，这通常是非法的。”²³ 这种论点表明，应当认为对网络的广义定义对于代表该领域的敌对活动是必要的

### 狭义地定义“战争”

许多网络安全问题的权威倾向于更狭义地定义战争。这些观点伴随着对参与被认为是网络行为的抵触，尽管其中一些学者甚至实际上宣布了……

一种悠久的方法是使用所谓的“蜜罐”（honeypots）。这种方法借鉴自物理领域（特别是冷战期间）或为了获取目标情报而进行的人际诱惑，网络蜜罐吸引入侵者去探索防御者系统中的“红鱱”（red herring）元素。它们被专门维护以监控入侵者，因为对外部人员来说，它们可能看起来是有价值的目标，但对内部人员来说，它们是系统中的无关或虚假元素。网络蜜罐有几种形式，包括旨在“检测网络扫描和枚举尝试”的蜜罐端口，以及模拟管理员密码的“蜜语”（honeywords）。蜜罐能迅速警报防御者入侵者的存在和活动，“这有助于防御者努力防止未来的入侵，并减少未来事件的影响。”²⁴

### 战争的性质与本质，以及震网（Stuxnet）陷阱

蜜罐也可以是“有毒的”，包含可以伤害入侵者的代码。有毒蜜罐比其他用于追踪入侵者的类型更具争议，学者对其使用的影响和反应持有分歧。攻击性性的数字反制措施“可能会不必要地激怒其他国家，导致动力冲突爆发”，尽管符合攻击性性的反制措施可能带来升级的特征，但其他学者指出，“利用武器化蜜罐的国家可以从几个理由辩护其行为的合法性，”特别是由于蜜罐造成的损害是由入侵者的行为而非防御者的行为引起的。一个来自世纪80年代的美国中央局（CIA）蜜罐在2004年解密，涉及在管道控制软件（据称苏联特工窃取的）中植入恶意软件，据报道这导致了故障和爆炸，给西伯利亚造成了数百万美元的损失。⁵

与攻击性反制措施可能带来升级的特征一致，著名的网络分析师马丁·利比基（Martin Libicki）认为，“跨领域反应可能被他人视为侵略行为，尽管此前发生了网络攻击。”⁶ 这符合他主张的所谓的“拉斯维加规则”（The Vegas Rules），即网络空间内发生的事情应该留在网络空间内，不应允许扩大到其他领域并升级。其他研究人员也同意这一观点，认为对网络攻击采取“以眼还眼”的方法“过于宽松”，或者断言将攻击性网络活动（例如2008年归咎于俄罗斯的格鲁吉亚战争）分类为攻击可能会导致更激烈、持久的冲突，并产生更具破坏性的物理影响。”²⁷ 这些考虑显然表明攻击性网络攻击是——且非——“真实的”战争行为，这些论点主张狭义定义网络战争，以避免紧张升级带来预期的伤亡。
