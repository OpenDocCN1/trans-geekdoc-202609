
## 15.5 决策网络

在本节中，我们将观察一种做出理性决策的通用机制。这种符号通常被称为影响图（Howard and Matheson, 1984），但我们将使用更具描述性的术语决策网络。

决策网络增加了用于动作和效用的额外节点类型。我们以选择机场选址问题作为示例。

### 15.5.1 用决策网络表示决策问题

在最通用的形式中，决策网络表示关于代理体当前状态、其可能采取的动作、这些动作将产生的结果以及该状态的效用。它为实现第 2.4.5 节中首次引入的基于效用的代理体提供了基础。图 15.6 显示了用于机场选址问题的决策网络。它阐明了使用的三类型的节点：

- *机会节点（椭圆）* 表示随机变量，就像在贝叶斯网络中那样。代理体可能对建设选择、交通水平以及潜在的诉讼风险不确定，还包括了安全性（`Safety`）、安静性（`Quietness`）和总节约性（`total Frugality`）变量，这些变量也取决于所选的选址。每个机会节点都关联一个条件分布，该分布由父节点的状态进行索引。在决策网络中，父节点可以是决策节点，也可以是机会节点。注意，每个当前状态节点都可能是一个大型贝叶斯网络的一部分，用于评估建设成本、空中流量或诉讼潜力。

- *决策节点（矩形）* 表示决策代理体有动作可供选择。在这种情况下，机场选址（`AirportSite`）动作可以针对每种状态考虑取不同的值。这种选择会影响结果的安全性、安静性和节约性。我们假设有一个单一决策节点。第 16 节涵盖了必须做出多个决策的情况。

- *效用节点（菱形）* 表示代理体的效用函数。效用的变量是描述直接影响效用的结果。与效用节点相关的是代理体效用作为父属性的描述。该描述可能仅仅是该函数的表格化列举，也可能是关于属性值的参数化加法函数或线性函数。目前，我们假设效用是确定的；也就是说，给定其父变量的值，效用的值就是完全被决定的。

在许多情况下也使用简化的形式。记法保持相同，但省略了描述结果的机会节点。相反，效用节点直接连接到当前状态节点和决策节点。在这种情况下，效用节点不再表示关于结果的效用函数，而是与每个动作相关联，正如第 519 页方程 (15.1) 定义所示；即该节点是动作-效用函数（在强化学习中也称为第 23 节描述的 `Q` 函数）。图 15.7 显示了机场选址问题的动作-效用表示。

注意，图 15.6 中的安静性、安全性和节约性机会节点指的是这些状态，它们的值从未作为证据变量出现。因此，当可以使用更通用的形式时，可以使用省略了这些节点的简化版本。简化形式包含较少的节点，但省略了对选址决策结果的显式描述意味着它对于环境变化的灵活性较差。

这些节点在文献中也被称为值节点（`value nodes`）。

### 15.5.2 评估决策网络

通过评估决策节点每种可能的设置的决策网络来选择动作。一旦决策节点被设置，它的行为就与一个被设置为证据变量的机会节点完全一样。评估决策网络的算法如下：

1. 设置当前状态的证据变量。
2. 针对决策节点的每个可能值：
   (a) 将决策节点设置为该值。
   (b) 使用标准的概率推理算法计算效用节点父节点的后验概率。
   (c) 计算该动作产生的效用。
3. 返回效用最高的动作。

这是一个直接的方法，可以利用任何可用的贝叶斯网络算法，可以直接整合到第 406 页图 12.1 中的代理设计中。我们将在第 16 节中看到，顺序执行多个动作的可能性使得问题变得更有趣。

## 15.6 信息价值

在先前的分析中，我们假设所有相关信息，或至少所有信息，在代理体做出决策之前已提供。在实践中，这种情况几乎不存在。决策过程中最重要的部分之一是知道要问什么问题。例如，医生不能期望在患者第一次进入诊室时就能获得所有诊断测试的结果。测试通常是昂贵的。

## 15.6 节 信息的价值

![](img/e36752d03ef5263fc4a8dddbd735be2d_538_0.png)

**图 15.8** 信息价值的三种通用情况。在 (a) 中，`a1` 几乎肯定优于 `a2`，因此不需要该信息。在 (b) 中，选择不明确，信息至关重要。在 (c) 中，选择不明确，但由于其差异很小，信息的价值较低。（注：`U2` 在 (c) 中具有峰值意味着其期望值比 `U{U1}` 具有更高的确定性。）

现在我们正在两条长度略有不同的土路之间做出选择，并且我们载着一名重伤的乘客。这时，即使 `U'1` 和 `U'2` 非常接近，`U1` 和 `U2` 的分布也非常不同。存在很大可能使得第二条路被证明是畅通的，而第一条路被堵住了，在这种情况下，效用的差异将非常大。VPI 公式表明，获取卫星报告可能是值得的。这种情况如图 15.8(b) 所示。

最后，假设我们是在夏季在两条土路之间做出选择，不太可能被积雪阻塞。在这种情况下，卫星报告可能显示某条路线比风景路线更好，可能是因为高山草甸开花，或者因为最近下了雨。因此，如果我们拥有信息，可能会改变计划。然而，在这种情况下，两条路线之间的价值差异可能非常小，所以我们不会费心获取报告。这种情况如图 15.8(c) 所示。

给定信息，`a1` 显然是更优的，但 `a2` 可能被积雪阻塞，而 `a1` 不可能被任何东西阻挡。因此，`U1` 比 `U2` 更清晰。获取关于每条路实际状态的卫星报告 `Ei`，将为交叉口提供新的期望值 `U'1` 和 `U'2`。这些期望的分布如图 15.8(a) 所示。不需要卫星报告，因为从从中获得的信息不太可能改变计划。如果没有改变，信息就没有价值。

> 总之，信息的价值取决于它可能导致计划改变的程度，以及新计划在多大程度上将显著优于旧计划。

### 15.6.3 信息价值的属性

人们可能会问信息是否可能是有害的：它真的会产生负面影响吗？直觉上，人们会认为这是不可能的。毕竟，在最坏的情况下，只需忽略信息并假装从未收到过即可。以下定理证实了这一点，该定理适用于任何使用可能观测值 `Ej` 的决策论代理。

## 第 15 章 做出简单决策

信息的期望价值是非负的：

`∀j VPI(Ej) ≥ 0`。

该定理直接源于 VPI 的定义，我们将证明留作练习题（练习题 15.NNVP）。当然，这是一个关于*期望值*的定理，而不是实际价值的定理。如果信息恰好具有误导性，额外的信息很容易导致一个比原计划更差的计划。例如，结果为阳性的医学测试可能会导致不必要的手术；但这并不意味着不应该进行测试。

记住，VPI 取决于信息的状态。它可以随着更多信息的获取而改变。对于任何信息 `Ej`，获取它的价值可能会降低（例如，如果另一个变量限制了 `Ej` 的后验概率）或增加（例如，如果另一个变量为构建 `Ej` 提供了线索，从而制定一个新的、更好的计划）。因此，VPI 不是相加的。

`VPI(Ej, Ek) ≠ VPI(Ej) + VPI(Ek)`（一般情况下）。

VPI 是顺序无关的。也就是说，

`VPI(Ej, Ek) = VPI(Ej) + VPI(Ek|Ej) = VPI(Ek) + VPI(Ej|Ek) = VPI(Ek, Ej)`

### 15.6.4 信息收集代理的实现

一个理性的代理会以合理的顺序提问，应该避免提无关的问题，应该考虑每条信息相对于其成本的重要性，并在适当的时候停止提问。所有这些能力都可以通过使用信息价值作为指导来实现。

图 15.9 显示了一个可以在行动之前进行智能收集的代理整体设计。现在，我们假设每个观测变量 `Ej` 都有一个相关的成本 `C(Ej)`，它反映了通过测试、顾问或其他方式获取证据的成本。代理请求根据单位成本效用增益看起来最高效的观测。假设动作 `Request(Ej)` 的结果是后续提供了 `Ej` 的值。如果没有哪个观测值值得其成本，代理将选择一个“真实”动作。

我们实现的算法是信息收集的一种形式，称为近视（`myopia`）。这是因为它短视地使用 VPI 公式，计算信息的价值就好像将获取单一证据一样。近视控制基于与贪婪搜索相同的启发式方法，并且在实践中运行良好（例如，已证明它在选择测试方面优于专家医生）。然而，如果没有单一证据可以提供很大帮助，近视代理可能会匆忙采取行动，而先请求两个或多个变量再采取行动会更好。下一节将考虑获取多个观测的可能性。

## 15.6 节 信息的价值

```
function INFORMATION-GATHERING-AGENT(percept) returns an action

persistent: D, a decision network

integrate percept into D
j ← the value that maximizes VPI(Ej) / C(Ej)
if VPI(Ej) > C(Ej)
then return Request(Ej)
else return the best action from D
```

图 15.9 简单、近视信息收集代理的设计。该代理通过反复选择信息价值最高的观测来工作，直到下次观测的成本大于其预期收益。

### 15.6.5 非近视信息收集

观测序列的价值在排列下保持不变这一事实引人注目，但其本身并没有导致高效的信息收集算法。如果我们限制为预先选择一个固定的观测子集，对于 `n` 个观测有 `2^n` 种子集。在一般情况下，如果我们面临更复杂的条件计划问题（如 11.5.2 节所述），即根据结果选择观测或采取其他行动，此类计划的数量且数量相对于 `n` 呈超指数级。

对于决策网络中的观测，事实证明当网络是树形时这是不可行的。然而，在某些情况下问题是可以解决的。在这里我们展示一个案例：宝藏搜索问题（或者对于不倾向的人来说是最小成本测试问题）。有 `n` 个位置 `1,...,n`；每个位置以独立概率 `P(i)` 包含宝藏，检查位置 `i` 的成本为 `C(i)`。代理按照顺序检查位置直到找到宝藏；问题是，最佳顺序是什么？

为了回答这个问题，我们需要考虑各种观测序列的期望成本和概率，假设找到宝藏为止。设 `x` 为序列，`xy` 为序列 `x` 和 `y` 的拼接，`C(x)` 是 `x` 的期望成本，`P(x)` 是序列 `x` 找到宝藏的概率；`F(x) = 1 - P(x)` 是失败的概率。给定这些方程：

```
C(xy) = C(x) + F(x)C(y), (15.3)
```

也就是说，序列 `xy` 将产生 `x` 的成本，如果失败，也将产生 `y` 的成本。

任何序列优化问题的基本思想是观察当通用序列 `wxyz` 中的两个相邻子序列 `x` 和 `y` 翻转时，成本的变化 `Δ = C(wxyz) - C(wyxz)`。如果所有此类变化都使序列变差，则该序列是最优的。

在部分观测环境中搜索序列行为的一般问题属于部分观测马尔可夫决策过程范畴，这些过程在第 16 章中有描述。
