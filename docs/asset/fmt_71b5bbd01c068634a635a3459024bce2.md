
人脸聚类是把同一个人的图像分组在一起的过程。可以提取脸部的嵌入，并可以使用像 `kmeans` 这样的算法算法进行聚类。TensorFlow 提供了一个名为 `tf.contrib.learn.kmeans` 的 API 用于 `kmeans`。
