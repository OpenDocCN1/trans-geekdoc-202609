
# 域名劫持

**域名劫持** 是一种类似于网络钓鱼的欺诈形式。在域名劫持中，即使用户输入了正确的网站地址，目标也可能被重定向到一个虚假网站。这最常见的是通过 DNS 缓存投毒攻击来实现的，如图 5.10 所示，攻击者会将虚假数据引入 DNS 服务器解析器缓存中。

![图 5.10 域名劫持](img/c05f010.png)

**图 5.10** 域名劫持

ISP 和主要 DNS 提供商会验证 DNS 响应，以确保它们来自权威来源。然而，许多组织选择运行自己的名称服务器，如果配置不当，它们可能会以这种方式被投毒。

域名劫持还可能涉及攻击者入侵合法网站并更改链接，将其用户重定向到欺诈网站。这甚至可能涉及入侵**互联网注册商账户**，从而完全更改域名服务器。为注册商账户使用强且唯一的密码对于帮助防止此类攻击非常重要。

## 水坑攻击

**水坑网络攻击** 是针对特定用户群体（如目标组织的成员）在他们可能访问的某个网站位置实施的攻击。这非常类似于狮子在猎物可能前来饮水的水坑附近潜伏。在这类攻击中，攻击者会感染目标用户已知常访问的一个或多个网站。攻击涉及设置网站，使其从网站向目标计算机下载恶意载荷，从而授予攻击者访问其网络的权限。

## 互惠利用

**互惠利用** 是一个拉丁短语，意为“以物易物”。它通常在合同法实践中被提及，指代有价值的事物与另一有价值事物的交换。本质上，互惠利用意味着用一种商品或服务交换另一种。

在道德黑客攻击中，互惠利用的前提也可应用于社会工程学。基本上，攻击者会向社会工程学目标提供某种有价值的东西，希望目标能回报某种有价值的东西，例如敏感信息或对受限区域的访问权限。

这种技术常用于心怀不满的员工，例如因晋升或加薪被忽视的个人。有时，此类员工会接受社会工程师的提议，以报复心理损害其雇主。心怀不满的员工也可被称为**内部威胁**，因为他们对其工作的组织构成威胁，并能“从内部”对该组织造成危害。已有许多案例显示，网络犯罪分子利用此技术诱导员工在其组织内部释放勒索软件。

## 数字侦察

攻击链侦察阶段的另一个重要组成部分是执行**数字侦察**活动。这通常涉及枚举网络、执行漏洞扫描和执行端口扫描。这些工具和技术将在第 9 章“ICS 安全评估”中讨论。

## 武器化

完成所有侦察后，攻击过程将进入**武器化阶段**。在此阶段，收集到的信息被应用于创建用于发动攻击的工具。具体而言，带有后门的**漏洞利用代码**会与**恶意载荷**相结合，以便投递给目标。这是杀伤链准备阶段的第二步，完成时间可能从几小时到几个月不等。

洛克希德·马丁将武器化阶段定义为“将**远程访问木马**（`RAT`）与漏洞利用代码结合成可投递的载荷，通常通过一种称为**武器生成器**的自动化工具来实现。”`RAT` 只是授予攻击者对主机远程访问权限的后门，可用于执行各种操作。

在防御方面，洛克希德·马丁建议进行完整的恶意软件分析，以确定载荷是什么以及它是如何构建的。此外，扫描系统以查找武器生成器。检查恶意软件的创建日期以确定其存在多久，从而区分漏洞利用代码是旧还是新。这对于确定恶意软件的能力可能很重要。

- 受感染的闪存驱动器
- 受感染的网站
- 水坑攻击——被攻陷的网站
- 社交媒体互动

这是杀伤链入侵阶段的三个步骤中的第一步。

在防御方面，杀伤链中的这一步代表了防御者阻止入侵的第一次机会。理想情况下，这是阻止高比例攻击的阶段。在此级别进行防御工作的关键是收集和分析电子邮件及 Web 日志，以便进行取证分析。特别是，您需要分析投递系统，并确定其在以组织资源为目标方面所扮演的角色。

## 利用

利用可以针对硬件或软件漏洞，但通常取决于人为漏洞。这包括受害者触发的利用，例如打开电子邮件附件或点击通向恶意软件利用的网站链接。

此类利用的常见 `attack vector`（攻击向量）涉及执行恶意软件，例如通过目标操作系统或其他应用程序中的漏洞执行武器化的远程访问木马（`RAT`），以激活利用。通常，这些 `RAT` 被用来在系统中创建后门，以便控制从管理任务（如添加用户）到关闭主机、记录击键，甚至开启网络摄像头等各种任务。

如果您密切关注 Microsoft 更新，会注意到其中许多是 Windows 以及 Microsoft Office 的安全更新。由于许多 `RAT` 嵌入在 PDF 和 Office 文件中，因此修补 Office 产品中的漏洞对 Microsoft 至关重要。请务必安装这些更新！

此阶段常用的其他利用包括利用零日漏洞和针对服务器漏洞的攻击者触发型利用。零日漏洞是指软件制造商或普通网络安全人群尚未发现的漏洞。当攻击者发现这些漏洞时，他们能够利用它们，直到制造商为该漏洞发布安全补丁。

在杀伤链利用环节的防御方面，有三条大致的途径可循：

- 人员网络安全培训。这延伸至针对管理员、管理人员、软件和 Web 开发人员以及员工的特定网络培训。
- 渗透测试并配合定期的网络漏洞扫描。
- 端点加固工作。端点加固工具和方法在第 4 章“ICS 模块和要素加固”中有详细描述。

## 安装

现在已经获得了访问权限，有必要建立与目标的持久连接。以上一节的示例为例，`RAT` 执行后，链中的下一步是在目标设备上安装后门或植入程序，以便攻击者能够保持对受攻陷系统的访问。他们还可能通过向系统添加服务来创建持久化点，以辅助其持久化方案。这是杀伤链入侵阶段的最后一步，所有这些通常只需几秒钟即可完成。

`RAT` 可以通过多种方式执行，但最简单的示例是创建一个打包为 `.exe` 文件的 `RAT`。由于 Windows 7 默认隐藏已知文件类型的扩展名，在文件末尾追加 `.doc` 可使其看起来像文档文件。运行该文件实际上会执行木马。

此阶段的防御措施包括安装基于主机的入侵检测和预防技术，以检测并警报/阻止常见的软件安装路径。还必须审核端点进程，以检测异常的文件创建。端点审核在第 10 章“ICS 安全监控和事件响应”中有详细介绍。

## 命令与控制

`高级持续性威胁`（`APT`）恶意软件通常需要攻击者手动与恶意软件交互，而大多数恶意软件是自动化的，无需攻击者采取任何行动即可将信息发送回攻击者。

因此，`APT` 恶意软件必须与`命令与控制`（`C2`）`服务器`建立双向连接，以建立所谓的`C2 信道`。此`C2 信道`使攻击者能够直接与受攻陷主机交互，这会使威胁变得非常危险，因为攻击者可以对缓解威胁的尝试做出反应。

建立`C2 信道`后，攻击者可以从目标窃取知识产权；泄露机密电子邮件、公司记录和员工信息等敏感数据；或渗透并感染整个网络。

然而，`APT` 行动的执行往往比其他类型的网络攻击复杂得多。它们通常始于更常见的攻击，例如 SQL 或跨站（`VSS`）攻击，以建立对目标的初始渗透。然后安装带有后门 Shell 的木马，以在攻击者和目标之间创建持久存在。

杀伤链中的这一环节代表了防御者通过识别和阻断`C2 信道`来终止攻击的最后机会。该信道通常通过恶意软件分析方法来识别。

## 目标行动

完成前面的步骤后，攻击者可以执行各种目标，例如收集数据并将其发送回`C2 服务器`。在我们讨论的许多攻击中，这是攻击者的主要目标之一。数据范围从信用卡信息到公司和政府的机密数据。

此时，攻击已被归类为事件，必须启动组织的事件响应计划（`IRP`）。`IRP` 的推进步骤如下：

1. 启动事件响应团队（`IRT`），以识别和验证事件的性质。
2. 采取措施遏制事件并限制影响范围。
3. 对事件执行根因分析，以确定导致事件的源头。
4. 采取措施修复事件。
5. 采取措施从事件中恢复。
6. 利用经验教训更新 `IRP`，以防止未来发生类似的利用。

该计划在第 10 章中有详细讨论。

# 攻击方法

术语 `attack method`（攻击方法）和 `attack mode`（攻击模式）用于描述攻击者可能用于攻击资产（网络、计算设备、程序或数据）的方式或技术。以下部分介绍许多不同的攻击方法。

## 广播风暴

当 `broadcast traffic`（广播流量）被每个网络设备重新广播时，持续的广播或 `multicast traffic`（组播流量）会迅速使交换机和路由器过载，并压垮网络。这种活动称为 `broadcast storm`（广播风暴）或 `network storm`（网络风暴），如图 5.12 所示。

![图 5.12 广播风暴](img/c05f012.png)

**图 5.12** 广播风暴

监控网络中的 `broadcast storms`（广播风暴）很重要。然而，确保网络正确配置也同样重要。如果网络节点直接与多个交换机通信，则查找表可能会混淆，导致数据包在段之间泛洪。这可能代表许多网络中的一个主要弱点。

拥有足够强大、能够快速移动数据并快速学习路由以满足组织需求的硬件也很重要。随着网络速度提升到千兆及更快，所有网络硬件都必须适应该数据速率，这一点变得越来越重要。

## 生成树协议与网络欺骗

### 生成树协议

虽然可以通过分割网络来最小化广播风暴的风险，但创建 `spanning-tree protocol`（`STP`，生成树协议）是为了解决这一问题。`STP` 采用 `spanning-tree algorithm`（`STA`，生成树算法）来识别交换机可能与网络节点有多条通信路径，并管理最优路径，同时仍能回退到次要路径。任务关键型网络必须使用 `STP` 来最小化广播风暴。

第 2 层设备采用一种名为生成树协议 (`STP`) 的协议，为多路径网络（如图 5.13 所示）中的交换机提供无环路、冗余的链路。它通过配置交换机端口来实现这一点，使其根据所连接的段类型转发或阻塞流量。

**图 5.13** 多路径交换机连接

### 欺骗

字典将 `spoofing` 定义为“欺骗或恶作剧”。在网络安全领域，欺骗用于使设备看起来像另一台设备，且可以通过多种不同方式实现。许多网络漏洞侧重于以某种方式获取有效凭证。显而易见，攻击者伪造或欺骗网络身份并不难。`Masquerade attacks`（伪装攻击）可能源于窃取的凭证、欺骗的 IP 或电子邮件地址，或两者兼有。如果攻击者能诱使用户泄露其凭证，他们就能获得该用户的网络权限。多因素认证措施（涉及你知道的、你拥有的或你本身的特征）可以降低伪装攻击的效率，但这些解决方案并不总是切实可行。

### IP 欺骗

`IP header manipulation`（IP 头部操纵），或 `IP spoofing`（IP 欺骗），是一种通过更改 IP 或 TCP 网络数据包头部部分所含信息来隐藏网络身份的技术。此操作还用于执行多种其他攻击，如中间人 (`MITM`) 攻击和拒绝服务 (`DoS`) 攻击。

如果我们检查图 5.14 中提供的示例 IP 头部，可以看到前 12 字节（顶部三行）数据包含关于数据包的各种信息，如长度、生存时间 (`TTL`) 和协议 (`IPv4` 或 `IPv6`)。接下来的 8 字节（第 4 行和第 5 行）包含源和目标 IP 地址信息。

![FIGURE 5.14 IP header](img/c05f014.png)

**图 5.14** IP 头部

使用互联网上可用的几种工具之一，攻击者可以轻松修改这些地址，特别是“源地址”字段，使其成为他们想要的任何内容。通过这样做，攻击者可以欺骗网络数据包的源地址，使其看起来像是来自与实际完全不同的位置。这可用于在攻击期间隐藏其身份，或者根据网络防御情况，可能用于从外部访问私有内部网络。

### 防御 IP 欺骗

幸运的是，有几种相当有效的方法可以防御 IP 欺骗：

- 在路由器处过滤网络流量
- 实施加密和认证

在边界网络路由器上同时实施 `ingress`（入站流量）和 `egress`（出站流量）过滤是防御欺骗攻击的起点。应实施访问控制列表，如图 5.15 所示，以便阻止私有 IP 地址（包括组织的内部 IP 地址范围）在下游接口通过。

`downstream interface`（下游接口）是允许流量从互联网进入网络的接口。互联网是世界上最大的公共网络，因此没有正当理由允许私有和内部流量通过路由器的下游接口，因为这是攻击者试图绕过防火墙的常用手段。这也是创建 VPN 的原因。

路由器的 `upstream interface`（上游接口）允许流量流向不同的子网或互联网。该接口应限制为仅允许来自组织有效 IP 范围内的源地址通过。这有助于防止欺骗的网络数据包在互联网上传输。

![FIGURE 5.15 Perimeter network protection](img/c05f015.png)

**图 5.15** 边界网络防护

实施加密和认证也有助于防止欺骗攻击。这些功能包含在 `IPv6` 中，`IPv6` 旨在消除所有当前的欺骗攻击威胁。

网络内部还应消除基于主机的认证。基于主机的认证依赖信息（如图 5.16 所示的 MAC 地址和主机名）向网络进行认证。这些信息不太安全，攻击者也可以轻易伪造。相反，应建立并通过安全的加密连接实施适当的认证措施。

### MAC 欺骗

`MAC spoofing`（MAC 欺骗）如图 5.17 所示，是前几章介绍的另一种常见欺骗技术。由于许多安全设备和软件依赖 MAC 地址来控制对网络资源的访问，因此能够更改 MAC 地址非常方便。优秀的安全从业人员经常使用此技术来测试安全设备和其他防御措施。

![FIGURE 5.17 MAC spoofing](img/c05f017.png)

**图 5.17** MAC 欺骗

MAC 欺骗可用于多种目的。然而，最常见的场景之一涉及使用欺骗方法来欺骗网络环境中用于连接互联网的硬件的 MAC 地址。ISP 通常使用 MAC 地址注册其自己的设备并允许访问其网络。

如果客户购买了新的路由器/调制解调器设备并希望将其用于现有的互联网服务提供商，则必须向 ISP 注册该设备。客户选择不向 ISP 注册新设备的 MAC 地址，而是通过使用旧设备的地址代替新设备的地址来欺骗旧设备的 MAC 地址。通常，这违反了 ISP 与客户之间的 `EULA`（最终用户许可协议），并可能被视为非法行为。

### ARP 欺骗/投毒

要理解 `ARP spoofing`（ARP 欺骗），也常称为 `ARP poisoning`（ARP 投毒），我们需要了解为什么需要 ARP 以及它是如何工作的。地址解析协议 (`ARP`) 用于将 IP 地址映射到 MAC 地址。这样，设备就能通过第 2 层设备（如交换机）进行通信。当网络流量到达路由器时，它将使用帧中的 IP 地址信息将数据包从一个网络路由到另一个网络。

例如，设想一个简单的网络，其中两台设备仅由一台交换机隔开。第一台设备（我们称之为 Smith）的 IP 地址为 `10.0.0.10`，MAC 地址为 `AB:CD:EF:12:34:56`。它需要与第二台设备（称为 Jones）通信。我们恰好知道 Jones 的 IP 地址是 `10.0.0.20`。

由于以太网段仅需使用物理 MAC 地址进行通信，我们需要确定 Jones 的 MAC 地址。

Smith 将发送一个广播帧，其目标 IP 地址设置为 `FF:FF:FF:FF:FF:FF`。请记住，我们已经知道源 IP 地址 (`10.0.0.10`)、目标 IP 地址 (`10.0.0.20`) 和源 MAC 地址 (`AB:CD:EF:12:34:56`)。

当交换机接收到广播帧时，如图 5.18 所示，它会将该帧发送回连接到交换机的所有其他设备。Jones 将接收到该帧，并识别出该广播帧是发给它的，因此它会使用广播帧的地址作为目标地址，发回一个`反向 ARP` (`RARP`) 帧。

![FIGURE 5.18 ARP](img/c05f018.png)

**图 5.18** ARP

你可能会想知道的下一件事是：“是什么防止了监听网络的人接收广播帧并发回伪造的信息。” 事实是，几乎没有什么防范措施！ARP 欺骗更常见的用例之一是中间人攻击。

### DNS 欺骗

在计算机网络中，域名系统是一个分层的（即多级的）计算机命名系统，可以是集中式的，也可以分布在网络中，无论是私有网络还是公共互联网。DNS 的主要职责是将域名（如 `exampledomain.net`）转换为这些域在网络中所在位置的实际 IP 地址。

这样做的原因是域名比 IP 地址更容易让人类用户记忆。想象一下，如果每次想在互联网上通过 Google 搜索内容，你都必须记住并输入 `216.58.217.142`！你每天访问的所有其他收藏网站也是同理。

如果用于上网的主机计算机不知道所请求域名的 IP 地址，它必须联系 DNS 服务器并请求其帮助查找，如图 5.19 所示。如前所述，DNS 由多个层级组成，所有层级负责域名的不同部分。

**图 5.19** DNS 过程

如果其中一台 `DNS 名称服务器` (`NSs`) 不知道所有请求的部分，它会继续将请求推送到系统中的下一个更高层级服务器。此过程持续进行，直到请求的域名被完整组装并找到 IP 地址。为了加快此过程，当主机计算机收到所请求域名的 IP 地址时，它会将该信息存储在其本地 DNS 缓存中，以便下次请求同一域名时立即使用。

假设 DNS 服务器从攻击者处接收到虚假信息，并将其缓存以供客户端系统未来请求使用。该 DNS 服务器现已被攻陷，被视为遭到投毒。因为 DNS 服务器被投毒，它会为请求的域名返回错误的 IP 地址，进而将流量发送到另一台通常属于攻击者的计算机。

攻击者可利用 DNS 欺骗向受害者发送欺骗性网站，例如虚假的银行网站或其他需要个人登录凭据以获取敏感信息访问权限的网站。这些页面通常设计得非常逼真，难以识别。

受害者将凭据输入登录提示后，网络数据包会被发回给攻击者，攻击者会收集受害者的凭据以备后用。视 DNS 欺骗的复杂程度而定，页面可能会实际将受害者重定向到他们最初寻找的合法网站和域名。或者，可能将他们转向其他预定域名。无论哪种情况，在受害者眼中这可能只是表现为一个“故障”。
