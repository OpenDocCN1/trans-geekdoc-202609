
这里，我们只有一个自变量，即摄入的卡路里（`x`）。我们在*图 1.15*中绘制了这些数据。假设我们的回归数学模型是一条直线 `y = 0.0004 * x + 4.2`，如*图 1.15*所示。那么，对于摄入卡路里 = 1222（上述第 2 个样本），预测的体重增加为 4.7，但实际体重增加为 6.38 千克。请参考下图：

![](img/Image38673.jpg)

**图 1.15：** *卡路里与体重增加的绘图*

以下是评估回归模型的指标：

*   **平均绝对误差（`MAE`）**：`MAE` 是一个非常简单的指标，用于计算实际值与预测值之间平均绝对差异。在前面的示例中，我们模型的预测值是对应 x 轴上每个卡路里值的直线上的点；因此：

    `MAE` = ![](img/569C1eqg10.jpg)(|5.18 – 4.79| + |6.17 – 4.78| + … + |3.64 – 4.49|) = 1.075

    这表明，平均而言，上述模型对体重增加的估计将会有 ±1.075 千克的误差。该误差与目标变量具有相同的单位。

*   **均方误差（`MSE`）**：`MSE` 计算实际值与预测值之间平均平方差。

    `MSE` = ![](img/569C1eqg10.jpg)((5.18 – 4.79)² + (6.17 – 4.78)² + … + (3.64 – 4.49)²) = 1.536

    与 `MAE` 相比，距离预测值较远的点的平方误差更大。但该误差现在是一个平方量，不再与预测值具有相同的单位。

*   **均方根误差（`RMSE`）**：`RMSE` 是均方误差的简单平方根。这与目标变量具有相同的单位。

还有其他一些用于衡量回归的指标，如用于衡量回归误差的 R 平方和调整后的 R 平方。我们将在后续章节中重新讨论这些指标。

对于比较各种回归模型，有一些统计度量。模型既根据其在训练数据集上的表现进行评分，也根据模型参数的数量或模型的复杂度进行评分。

*   **赤池信息准则（`AIC`）**：`AIC` 会惩罚使用更多参数的模型。

    ```
    AIC = 2k – 2ln(L)
    ```

    `k` 是模型参数的数量。`L` 是模型可能产生观测到的目标值的概率的对数。`AIC` 越低，模型越好。这些对数概率的计算将在后面的章节中讨论。

*   **贝叶斯信息准则（`BIC`）**：另一个在为模型评分时也考虑样本数量的类似指标称为 `BIC`。较低的 `BIC` 值表示更好的模型。我们将在稍后提供该数学公式，因为它需要引入一些回归的理论基础。

`AIC`、`BIC` 也可以针对分类模型进行计算并加以比较。

# 特征工程与深度学习

在上述所有类型的机器学习算法中，无论是监督学习、无监督学习还是强化学习，一个重要的步骤是特征工程。这是一个手动步骤，涉及利用领域知识从观测数据中手工制作特征。为了理解这一步骤的复杂性，让我们以一个稍微复杂的分类问题——人脸识别——的特征工程为例。给定一张查询人脸图像和一个已知人脸数据库，任务是找到查询图像与数据库中图像的最佳匹配。解决此问题的第一个合乎逻辑的步骤是从人脸图像中提取特征，并用数值表示数据库中的人脸。查询图像也可以转换为一组数值观测，然后我们可以将查询图像的观测值与数据库中所有图像的数值表示进行比较。为了得出这种图像表示，我们利用了领域知识——人脸最显著的特征是什么：眼睛、眉毛、鼻子、下颌线、嘴巴，以及这些特征之间的相对距离。然后，我们必须设计算法从人脸图像中找到这些点。

因此，我们看到特征工程步骤是机器学习中最耗时和最困难的。有没有办法可以自动化特征工程过程？下一节讨论的机器学习算法子类解决了这个问题。

## 深度学习

**深度学习**是机器学习的一个子领域，它创建数据的分层表示。层次结构的高层由低层表示的组合形成。更重要的是，这种表示层次结构通过完全自动化特征工程，从数据中自动学习。在多个抽象层级上自动学习特征，使系统能够直接从数据中学习从输入到输出的复杂表示，而不依赖于人工设计的特征。深度学习中使用的模型统称为**神经网络**。

神经网络由称为神经元的小型计算单元组成（受人脑中生物神经元的启发），它们本质上是输入的参数化函数。神经元的输出是一个单一的实数。因此，拥有 `N` 个神经元，我们可以获得一组 `N` 个实数或 `N` 个特征。改变参数值会为相同的输入产生不同的特征向量。以人脸识别示例为例，我们可以设计一个神经网络，以原始数字图像作为输入。输入图像是一个 `n × n` 的像素数组或矩阵。我们定义一个参数化函数，计算图像中每组连续 `3 × 3` 像素的加权平均值并输出一个单一值。用于计算加权平均值的权重是神经元的参数。这些参数从数据中学习。我们可以拥有许多具有不同权重集的此类神经元，从而拥有一层表示各种图像特征（如边缘、颜色和纹理）的神经元。像这样堆叠多层神经元层次结构，我们可以得到一个称为深度神经网络的神经元网络。网络的深度由神经元层的数量定义。深度学习方法与经典机器学习方法的比较如*图 1.16*所示：

# 数据集准备

神经网络需要大量数据来自动计算特征。多少数据才足以让算法学习？经验法则是：数据集大小必须随着可学习参数和数据维度的增加而增加。

> **提示：** 我们必须确保数据集中的样本不重复，或者某一类别的样本数量不高于其他类别。这会促使模型为倾斜的类别/样本学习更好的表征，从而导致其他类别或样本的性能下降。

在实践中，整个数据集并不用于训练神经网络模型。清洗数据后，将其分为三组：训练集、验证集和测试集。划分应使得数据的变化在所有三组中均被捕获。神经网络学习算法和许多其他机器学习算法都是迭代算法。

大多数学习算法通常从参数的随机初始化开始，并通过从训练数据获取反馈来迭代地改进参数值。随着学习算法在训练阶段学习参数值，它需要验证自己是否朝着正确的方向前进。为此，使用验证数据集。在从训练数据学习参数几次迭代后，使用最近运行的参数在验证集上运行部分训练好的模型。在验证集上的表现为模型搜索更好的参数值指明了方向。模型验证的必要性在于限制模型仅在训练样本上工作，而在训练样本之外的任何数据上都惨遭失败。这样的模型毫无用处，被称为*过拟合*模型。在验证数据上评估模型性能，确保模型学习的是数据中的通用模式，而非死记硬背训练样本。

也可能出现另一种情况。我们看到模型甚至无法很好地学习训练数据，因此验证集上的性能也没有提高。这种情况称为*欠拟合*模型。这通常表明我们的模型需要更多参数或更大的容量来学习数据中的模式。训练完成后，在测试集上评估训练好的模型，并将这些数字作为模型性能报告。

> **注意：** 测试集绝不应用于训练或验证。模型性能必须始终在测试集上报告。

对于规模适中的数据集，我们可以将数据集分为训练集：80%，测试集：20%。在训练集中，5% 可用作验证数据集。如果数据集规模超过百万样本，则可以将数据集分为训练集：98% 和测试集：2%。验证集可以是训练样本的 2%。划分后的数据集在分析时应反映相似的模式（统计分布）。任何数据集中偏向任何模式或类别的倾斜数据都会导致学习算法性能下降。

> **提示：** 为了获得所有三个数据集之间相似的统计分布或模式，我们可以随机打乱数据集并为每个数据集选择样本。如果是分类数据集，则确保每个类别的样本在每个数据集中按比例表示。

从训练集中选择验证集时，我们可以采用固定验证集，也可以在每次训练迭代中从训练集中随机抽取少量样本并将这些样本用作验证。后一种技术称为*交叉验证*，在数据集规模较小的情况下被认为更稳健。下面列举了几种流行的交叉验证策略：

*   **K 折交叉验证**：训练样本被随机划分为 *k* 个大小相等的集合。在一次训练迭代中，选择一个集合作为验证集，其余 *k-1* 个集合用于训练。此过程重复 *k* 次，每个集合仅被用作验证集一次。然后将这 *k* 个结果平均以产生单一估计。*k* 可以是任何值，通常 *k=10*，如*图 1.17*所示。在图中， 表示与迭代相关的成本或误差。‘*E*’ 表示通过平均所有  获得的单一估计。请参阅下图：

    ![](img/Image38734.jpg)

    **图 1.17：** *10 折交叉验证*

*   **留 p 法交叉验证**：在 *n* 个训练集样本中，该方法使用 *p* 个观测值作为验证集，剩余 *n-p* 个观测值作为一次训练迭代的训练集。这在所有可能的 ![](img/569C1eqg12.jpg) 个集合上重复进行。*p* 可以是任何值。最流行的值是 *p=1*，称为留一法交叉验证。

*   **重复随机子采样法**：该方法也称为蒙特卡洛交叉验证。此处，样本集被随机分割为训练集和验证集。分割集用于一次训练迭代。对于每次训练迭代，样本集每次都被随机分割。然后将结果平均以产生单一估计。迭代次数不取决于样本集大小。在该方法中，可能发生某些样本永远不会被选为验证集，而某些样本可能最终被选中多次。

在许多情况下，数据集不够详尽，无法捕捉真实数据的所有变化。这会导致在训练集和交叉验证数据集上表现优异，甚至在测试集上表现良好，但在部署到真实环境时表现不佳。我们应收集更多能反映真实数据统计分布的样本。

数据增强是使数据集稳健的技术之一。*数据增强*技术通过对现有数据集施加细微修改或从现有数据集合成新样本，向数据集添加更多样本。修改或合成应以这样的方式进行：原始样本的标签及其对应的修改或合成样本的标签应保持不变。

增强数据的技术取决于数据的性质和期望的输出。

以识别猫或狗的图像数据集为例。对于该数据集，我们可以对现有图像应用旋转、平移、剪切、翻转技术。请注意，这些技术不会将标签从原始样本变为变换后的样本。包含猫的图像在这些变换后仍将被识别为猫。其中一些图像增强技术将在*第 9 章，计算机视觉*中讨论。

# 数学在 AI 中的作用

AI 的目标是设计能够在*不确定性下进行基于数据的自动化决策*的算法。数据是起点，而这些数据总是不足的。永远不可能在任何数据集中捕捉所有可能的场景，如果能捕捉所有场景，则就不需要 AI 了。我们不需要 AI 来编写计算任意两个数之和的算法，因为我们知道所有可能出现的场景，并拥有针对所有场景的规则。数据的不足是*不确定性*的主要来源，即在不完美或不完整的信息下工作。

不确定性的其他来源包括数据中的噪声、收集数据时的错误以及建模时做出的假设。我们可以用概率论和统计学的数学理论来定性地表示这种不确定性。概率论为量化、处理和利用不确定性提供了基础和工具。统计学处理数据的收集、呈现、分析、解释和推断方法。数据在数值上表示为高维空间（称为向量空间）中的一个点。然而，超出三个维度后，我们无法可视化数据；因此，收集到的每一个观测值都是一个抽象的数值对象。线性代数为我们提供了操作这些称为向量的抽象对象的所有工具，并定义了这些向量之间的相似性、距离和角度等概念。

有了所有这些工具，我们就能够用数学方式定义决策制定，这是实现从数据中自动化决策制定、即达到 AI 最终目标所必需的。这些决策可以分为两类：离散型或连续型。离散决策类似于分类或在强化学习（RL）场景中决定动作，连续决策类似于回归。

在数学上，离散决策可以表示为对数据点所在的高维空间进行划分，并为每个分区分配一个类别。另一方面，连续决策是将高维空间中的一个点映射到实数的某些函数。在这两种情况下，都必须找到一组参数化的数学函数，使其能够输出最优决策。为此，我们需要高维空间中函数优化的工具，这由向量微积分理论提供。这四种数学工具，即线性代数、向量微积分、概率论和统计学，是 AI 的四大支柱，如*图 1.19*所示。这些主题中的每一个都非常广泛，并不需要完全精通这些主题就能理解 AI 理论。在本书中，我们提供了深入理解 AI 所需的这些主题中的核心概念。请参考下图：

## 线性代数

线性代数是处理向量及向量上的线性函数的数学分支。向量是将抽象对象表示为数学实体的一种方式。正如我们可以对数字进行加、减、乘运算，我们也可以对两个或多个向量进行类似的运算以获得新向量。例如，数字图像可以表示为像素向量。让我们以同一相机位置拍摄的两张数字图像为例。第一张是一位女士站在她房子前的照片，第二张是一辆汽车的照片，背景与女士的照片相同。如果我们将这两张图像相加，就会得到一张新图像，其中女士的房子前多了一辆汽车。许多此类图像操作都可以用向量运算和向量变换来表示。

在机器学习中，将抽象对象表示为向量是第一个挑战，称为*特征工程*。传统上，这一过程完全是手动的且耗时。深度学习部分自动化了这一任务。在内部，深度学习利用线性代数、向量微积分和优化技术的力量来实现这一点。在本章介绍向量的线性变换后，我们将介绍一个线性神经网络的小例子。

## 线性方程

包含两个变量 `x`、`y` 的线性方程表示一条直线：`y = mx + c`，其中 `m` 称为斜率，`c` 称为直线的截距。在这里，斜率 `m` 控制直线与 y 轴形成的角度（`斜率 = tan(角度)`），截距 `c` 告诉我们直线在哪里与 y 轴相交。截距代表 `x = 0` 时 `y` 的值。我们在日常生活中会遇到此类方程。例如，我们使用以下线性方程将摄氏度 (C) 下测量的温度转换为华氏度 (F)：

```
F = (9/5)C + 32
```

请参考*图 2.1*：

![](img/celsius_to_fahrenheit.jpg)

**图 2.1：** *直线表示摄氏度与华氏度之间的映射关系*

## 一阶方程称为线性方程

将线性方程重写为 `9*C* – 5*F* + 160 = 0` 的形式，可得到通式 `ax + by + c = 0`。这被称为线性方程的通式，因为我们可以轻松地将其扩展到两个以上变量，即 `a[1]x[1] + a[2]x[2] + … + a[n]x[n] + a[0] = 0`。常数 `a[i]` 称为系数，`a[0]` 称为方程的截距。三个变量的线性方程（`a[i] ≠ 0; 1 ≤ i ≤ 3`）在几何上表示三维空间中的超平面或平面。超平面的概念可以推广到 `n` 维。

当多个线性方程在 `n` 维空间中表示时，分析这些方程所代表的超平面的公共点或交点是很有趣的。这些公共点同时位于所有超平面上，被称为**线性方程组**的*解*。

现在，让我们将一个简单的问题建模为线性方程组并求解。

假设一群朋友计划去商场。他们打算在看电影、保龄球和游戏机上花费时间。由于对从哪里开始玩意见不一，他们分成了三组。在商场玩了一会儿后，他们聚在一起讨论。

第一组 `G1` 提到他们在 1 个*保龄球道*、1 台*游戏机*和 1 张*电影票*上花费了 ₹1500。第二组 `G2` 在 3 个*保龄球道*、4 台*游戏机*和 2 张*电影票*上花费了 ₹4400。第三组 `G3` 在 5 个*保龄球道*、3 台*游戏机*和 5 张*电影票*上花费了 ₹6500。根据这些信息，能否推导出保龄球道、游戏机和电影票的价格？可以用方程形式表示上述数据如下：

`G1: 1 保龄球道 + 1 游戏机 + 1 电影票 = ₹1500`

`G2: 3 保龄球道 + 4 游戏机 + 2 电影票 = ₹4400`

`G3: 5 保龄球道 + 3 游戏机 + 5 电影票 = ₹6500`

用 `b` 替换*保龄球道*，`p` 替换*游戏机*，`m` 替换*电影票*来表示线性方程组，得到 3 个线性方程：

`e[1]: 1*b + 1*p + 1*m = 1500`

`e[2]: 3*b + 4*p + 2*m = 4400`

`e[3]: 5*b + 3*p + 5*m = 6500`
