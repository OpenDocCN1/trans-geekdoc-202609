
# 10.5 基于分析的稀疏表示压缩感知

$$
\min_{\mathbf{s}}\quad\left\| \Phi^{H}\mathbf{s} \right\|_{0},\text{s.t.}\quad\mathbf{y} = X\mathbf{s},\ \text{or}\ \left\| \mathbf{y} - X\mathbf{s} \right\|_{2}^{2} \leq \epsilon,
$$

具体取决于通过传感矩阵 `X` 获得的观测是精确的还是含噪的。严格来说，示例 10.1 中使用的全变分最小化方法属于这种分析模型表述的范畴，因为最小化的是图像梯度变换的 $\ell_1$ 范数。

(10.28) 中给出的两种表述中的优化任务，都是建立在感兴趣信号具有*稀疏分析表示*这一假设之上的。现在显而易见的问题是，(10.28) 中的优化任务与 (9.38) 或 (9.39) 中的对应任务是否有任何不同。阐明这一问题的早期工作之一见于文献 [51]。文中指出，这两个任务虽有关联，但总体上是不同的。此外，它们的相对性能取决于具体问题。例如，考虑涉及的字典对应于正交变换矩阵（如 DFT）的情况。在这种情况下，我们已经知道分析矩阵和合成矩阵的关系为

$$
\Phi = \Psi = \Psi^{(-H)}
$$

这导致了前面所述两种形式化方法之间的等价性。确实，对于这种变换，我们有

```
\underset{\text{Analysis}}{\underset{︸}{\widetilde{\mathbf{s}} = \Phi^{H}\mathbf{s}}}\quad\Leftrightarrow\quad\underset{\text{Synthesis}}{\underset{︸}{\mathbf{s} = \Phi\widetilde{\mathbf{s}}}}.
```

使用公式 (10.28) 中的最后一个公式，(9.38) 或 (9.39) 中的任务可以通过将 $\boldsymbol{\theta}$ 替换为 $\mathbf{s}$ 而轻松获得。然而，这种推理无法推广到过完备字典的情况；在这些情况下，这两个优化任务可能会导致不同的解。

关于基于合成或基于分析的稀疏表示比较性能的前面讨论不仅具有“哲学”价值。事实证明，在实践中，某些过完备字典的性质往往不允许使用基于合成的形式化方法。这些情况是指过完备字典的列表现出高度相关性；即矩阵的相干性（定义见第 9.6.1 节）具有较大值。此类过完备字典的典型例子包括 Gabor 框架、曲波框架和过采样 DFT。使用此类字典可在许多应用中提升性能（例如，[111,112]）。以我们熟悉的 DFT 变换为例。该变换以采样指数正弦波的形式提供信号样本的表示，其积分频率是 $\frac{2\pi}{l}$ 的倍数

即，

```
\mathbf{s}: = \begin{bmatrix} s_{1} \\ s_{2} \\ \vdots \\ s_{l - 1} \\ \end{bmatrix} = \sum\limits_{i = 0}^{l - 1}{\widetilde{s}}_{i}\mathbf{\psi}_{i},
```

(10.29)

其中，现在，$\tilde{s}[i]$ 是 DFT 系数，$\boldsymbol{\psi}[i]$ 是频率等于 $\frac{2\pi}{l}i$ 的采样正弦波

即，

```
\mathbf{\psi}_{i} = \begin{bmatrix} 1 \\ {\exp\left( - j\frac{2\pi}{l}i \right)} \\ \vdots \\ {\exp\left( - j\frac{2\pi}{l}i(l - 1) \right)} \\ \end{bmatrix}.
```

(10.30)

然而，这不一定是最高效的表示。例如，信号极不可能仅由整数频率组成，而只有此类信号才能使用 DFT 基获得稀疏表示。通常情况下，极有可能存在介于 DFT 基频率采样点之间的频率，导致非稀疏表示。利用这些额外的频率，可以获得信号频率含量的更好表示。然而，在这样的字典中，原子不再线性无关，相应（字典）矩阵的相干性增加。

一旦字典表现出高相干性，就无法找到一个感知矩阵 `X` 使得 `XΨ` 满足 RIP。回顾一下，稀疏感知学习的核心在于稳定嵌入的概念，它允许在将向量/信号投影到低维空间后将其恢复，这正是所有可用条件（例如 RIP）所保证的。然而，高相干字典无法实现稳定嵌入。以第一个和第二个原子相同的极端情况为例。此时，没有任何感知矩阵 `X` 能够实现信号恢复，以区分向量 `[1, 0, …, 0]^T` 和 `[0, 1, 0, …, 0]^T`。那么，能否得出结论：对于高相干过完备字典，压缩感知技术行不通？幸运的是，答案是否定的。毕竟，我们在压缩感知中的目标始终是恢复信号 `s = Ψθ`，而不是识别综合模型表示中的稀疏向量 `θ`。后者只是达到目的的手段。虽然对于高相干字典无法保证 `θ` 的唯一恢复，但这不一定会给使用少量测量样本恢复 `s` 造成任何问题。出路将来自于考虑分析模型公式化。

## 10.5.1 连贯字典中稀疏信号表示的压缩感知

本小节的目标是建立条件，以保证使用少量与信号相关的测量值，恢复在冗余且连贯字典中具有稀疏表示的信号向量。设手头的字典为紧框架 `Ψ`（见章节附录，可从书籍网站下载）。则我们的信号向量可写为

`s = Ψθ,`

其中 `θ` 假定为 `k`-稀疏。回顾紧框架的性质（如附录所总结），Eq. (10.31) 展开式中的参数可写为 `⟨ψ[i], s⟩`，相应向量为

`θ = Ψ^T s,`

因为紧框架是自对偶的。那么，(9.39) 中综合公式化的分析对应形式可表述为

```
min_s ||Ψ^T s||_1, s.t. ||y - Xs||_2² ≤ ε.
```

现在的目标是研究该凸优化任务恢复解的精度。事实证明，与第 9 章研究的综合公式化情况类似，强有力的定理对此问题同样适用。

### 定义 10.1

设 $\Sigma_k$ 为 $\Psi$ 的所有 $k$ 列子集张成的所有子空间的并集。若满足

```
(1 - δ[k]) ||s||_2² ≤ ||Xs||_2² ≤ (1 + δ[k]) ||s||_2²
```

对所有 $s \in \Sigma_k$ 成立，则称感知矩阵 `X` 以 $\delta_k$ 满足适应于 `Ψ` 的限制等距性质（$\Psi$-RIP）。

子空间的并集 $\Sigma_k$ 是所有 $k$ 稀疏向量在 $\Psi$ 下的像。这是与第 9.7.2 节中给出的 RIP 定义的区别。本章前面讨论的所有随机矩阵都可以被证明以压倒性概率满足这种形式的 RIP，前提是观测数 $N$ 至少达到 $k \ln(l/k)$ 的量级。我们现在准备好建立关于我们 $\ell_1$ 最小化任务的主要定理。

### 定理 10.2

设 $\Psi$ 为任意紧框架，$X$ 为满足 $\Psi$-RIP 且 $\delta_{2k} \le 0.08$ 的测量矩阵，其中 $k$ 为某个正整数。则公式 (10.32) 中最小化任务的解 $\mathbf{s}_*$ 满足以下性质

$$
\left\| \mathbf{s} - \mathbf{s}_* \right\|_2 \leq C_0 k^{-\frac{1}{2}} \left\| \Psi^T \mathbf{s} - (\Psi^T \mathbf{s})_k \right\|_1 + C_1 \sqrt{\epsilon},
$$

其中 $C_0, C_1$ 为依赖于 $\delta_{2k}$ 的常数，而 $(\Psi^T \mathbf{s})_k$ 表示 $\Psi^T \mathbf{s}$ 的最佳 $k$ 稀疏近似，其通过仅保留 $\Psi^T \mathbf{s}$ 中幅度最大的 $k$ 个分量、将其余分量置零而得到。

公式 (10.34) 中的界是公式 (9.36) 中给出界的对应形式。换句话说，上述定理表明：如果 $\Psi^T \mathbf{s}$ 衰减迅速，则 $\mathbf{s}$ 可以仅从少量（相对于信号长度 $l$）观测中重构。该定理首次见于文献 [25]，也是此类定理首次在一般背景下为稀疏分析模型公式提供结果。

## 10.5.2 余稀疏性

### 稀疏分析公式化

在稀疏综合公式化中，人们在由字典 `Ψ` 的所有可能的 $k$ 列组合形成的子空间并集中寻找解。信号向量位于这些子空间之一中——即由 `Ψ` 中索引位于支撑集（第 10.2.1 节）内的那些列所张成的子空间。

在稀疏分析方法中，情况有所不同。出发点是我们原始变换 $\widetilde{\mathbf{s}} := \Phi^{T}\mathbf{s}$ 的稀疏性，其中 `Φ` 定义了变换矩阵或分析算子。因为假设 $\widetilde{\mathbf{s}}$ 是稀疏的，所以存在一个索引集 $\mathcal{I}$，使得 $\forall i \in \mathcal{I}$，$\tilde{s}[i] = 0$。换句话说，$\forall i \in \mathcal{I}$，$\boldsymbol{\phi}[i]^{(T)}\mathbf{s} := \langle \boldsymbol{\phi}[i], \mathbf{s} \rangle = 0$，其中 $\boldsymbol{\phi}[i]$ 代表 `Φ` 的第 $i$ 列。因此，$\mathbf{s}$ 所在的子空间是由变换向量 $\widetilde{\mathbf{s}}$ 中对应零值的那些 `Φ` 列所形成的子空间的正交补。现在假设 $\text{card}(\mathcal{I}) = C_o$。信号 $\mathbf{s}$ 可以通过在由 `Φ` 的所有可能的 $C_o$ 列组合形成的子空间的*正交补*上搜索来识别，即

```
⟨ϕ[i], s⟩ = 0,  ∀i ∈ I.
```

综合问题与分析问题的区别如图 10.12 所示。为了便于对这一新设定进行理论处理，*余稀疏度* 的概念在文献 [92] 中被引入。

图 10.12 搜索稀疏向量 **s**。(A) 在综合模型中，稀疏向量位于由字典 `Ψ` 的 $k$ 列（此处 $k = 2$）组合形成的子空间中。(B) 在分析模型中，稀疏向量位于由变换矩阵 `Φ` 的 $C_o$ 列（此处 $C_o = 2$）形成的子空间的正交补中。

#### 定义 10.2

信号 $\mathbf{s} \in \mathbb{R}^l$ 关于 $p \times l$ 矩阵 $\Phi^T$ 的余稀疏度定义为

```
C_o := p - ||Φ^T s||_0.
```

(10.35).

简而言之，余稀疏度是所得变换向量 $\widetilde{\mathbf{s}} = \Phi^{T}\mathbf{s}$ 中零元素的数量；相反，稀疏度衡量的是相应稀疏向量中非零元素的数量。如果假设 $\Phi$ 具有“满火花”^(⁶⁸)，

现在设我们的信号关于矩阵 $\Phi^{(T)}$ 的余稀疏度为 $C_{o}$。那么，为了从信号隐藏其中的子空间中挖掘出该信号，必须构建 $\Phi$ 的所有可能的 $C_{o}$ 列组合，并在它们的正交补空间中进行搜索。在 $\Phi$ 满秩的情况下，我们之前已经看到 $C_{o} < l$，因此，$\Phi$ 的任意 $C_{o}$ 列都是线性无关的。换句话说，这些列张成空间的维度是 $C_{o}$。结果，我们在其中搜索 $\mathbf{s}$ 的正交补空间的维度是 $l - C_{o}$。

到目前为止，我们已经积累了足够的信息，可以详细阐述之前关于合成任务和分析任务性质不同的论述。让我们考虑一个使用 $l \times p$ 字典的合成任务，并设 $k$ 为信号按该字典展开时对应的稀疏度水平。求解所在子空间的维度是 $k$（假设 $k$ 小于相应矩阵的火花数）。让我们保持相同的维度，用于我们将在其中搜索分析任务解的子空间。因此，在这种情况下 $C_{o} = l - k$（假设为满火花矩阵）。此外，为了便于比较，假设分析矩阵为 $p \times l$。求解合成任务时，必须搜索 $\binom{p}{k}$ 个子空间，而求解分析任务时，必须搜索 $\binom{p}{C_{o} = l - k}$ 个子空间。这是两个不同的数字；假设 $k \ll l$ 且 $l < p/2$，这对于过完备字典来说是自然的假设，那么后者远大于前者（请用计算机代入一些典型值验证一下）。换句话说，需要搜索的分析低维子空间比合成低维子空间多得多。大量的低维子空间使得从分析模型中算法恢复解变得更加困难 [92]。然而，这可能揭示出分析模型相比合成模型具有强得多的描述能力。

另一个凸显这两种方法差异的有趣方面如下。假设合成矩阵和分析矩阵满足 $\Phi = \Psi$ 的关系，这正是紧框架的情况。在此假设下，$\Phi^{(T)}\mathbf{s}$ 为基于 $\Phi = \Psi$ 的原子的合成展开提供了一组参数。此外，如果 $\|\Phi^{(T)}\mathbf{s}\|_{0} = k$，那么 $\Phi^{(T)}\mathbf{s}$ 就是合成模型的一个可能的 $k$-稀疏解。然而，无法保证这是最稀疏的解。

现在该研究是否可以推导出保证稀疏分析公式解唯一性的条件了。答案是肯定的，且对于精确观测的情况，这已在文献[92]中得到确立。

#### 引理 10.1

设 `Φ` 为满火花（full spark）变换矩阵。则对于几乎所有的 $N \times l$ 感知矩阵，且当 $N > 2(l - C_o)$ 时，方程

```
y = Xs
```

至多只有一个余稀疏度至少为 $C_o$ 的解。

上述引理保证了优化问题

```
min_s ||Φ^T s||_0, s.t. y = Xs.
```

(10.36)

的解（若存在）是唯一的。

然而，求解前述的 $\ell_0$ 最小化任务很困难，且我们知道其综合对应问题在一般情况下已被证明为 NP-hard 问题。其松弛的凸对应问题是 $\ell_1$ 最小化：

```
min_s ||Φ^T s||_1, s.t. y = Xs.
```

(10.37)
