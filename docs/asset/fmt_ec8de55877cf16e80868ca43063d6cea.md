# Nmap 发现

你已经通过 Nmap 扫描获得了你想要的信息。在这种情况下，你确定了这台 Debian Linux 5 机器运行着 OpenSSH 5.1 版本。快速查询 NIST 国家漏洞数据库，发现了针对此版本 OpenSSH 的以下漏洞：

`http://web.nvd.nist.gov/vuln/detail?vulnId=CVE-2010-4478`

你的 tcpdump 捕获了执行扫描的基础系统的 IP 地址；然而，情况并不总是如此，因为有多种方法可以伪造 IP 地址。其中一种方法是 Nmap 空闲扫描（Idle scanning），你可以在此处阅读：`http://nmap.org/book/idlescan.html`。这仅仅是 Nmap 能力的冰山一角，而且还有许多其他扫描器可用，例如 Scanline、SuperScan 和 Angry IP Scanner，它们适用于几乎每一种操作系统。若要获取更多 Nmap 扫描示例，请查看`http://nmap.org/benniston-tutorial`，如果你想查看一些视频教程，请检查 YouTube 或访问`www.irongeek.com`并搜索 Nmap。
