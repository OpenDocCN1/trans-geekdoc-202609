- (A) 为特定范围配置隐式拒绝规则
- (B) 为特定 IP 范围设置蜜罐

## 问题 371
ZenTech 是一家跨国公司，最近采纳了多云策略，在多个云服务提供商处部署了工作负载。这种方法的主要安全益处是什么？

## 问题 372

- (A) 将 Web 服务器放置在内部网络并严格监控流量
- (B) 将 Web 服务器放置在 DMZ（非军事区），在其前面设置一个防火墙，并在 DMZ 和内部网络之间设置另一个防火墙

## 问题 377

选项 D 错误。常规备份测试确保备份可以成功恢复，但不测试系统之间的即时切换能力。

## 问题 380
安全管理员 Sarah 正在为她的组织服务器基础设施实施监控解决方案。她希望方案不需要在服务器本身上安装任何额外软件。Sarah 应该选择哪种类型的监控监控方法？

- (A) 基于代理的监控
- (B) 入侵检测系统 `IDS`
- (C) 无代理监控 `Agentless monitoring`
- (D) 基于网络的应用程序性能监控 `APM`

**解释 380。正确答案：C. 无代理监控。** 无代理监控解决方案不需要在监控的服务器上安装任何软件代理。它们通常依赖标准协议和接口来收集性能和其他数据。

选项 A 错误。基于代理的监控需要在每个要监控的服务器或设备上安装软件代理。

选项 B 错误。虽然入侵检测系统 `IDS` 是一种安全工具，但它并非专门为无代理基础设施监控设计的。

选项 D 错误。基于网络的应用程序性能监控 `APM` 专注于监控网络上的应用程序性能，而不是无代理服务器监控。

## 问题 381
网络安全分析师 Alice 的任务是在新部署的 Web 应用程序上线之前识别其基础设施中的潜在缺陷。她希望一种工具能够主动发现并报告系统漏洞、缺失补丁和配置错误。Alice 应该利用哪种工具？

- (A) 入侵检测系统 `IDS`
- (B) 网络嗅探器
- (C) 漏洞扫描器
- (D) 安全信息和事件管理 `SIEM` 系统

**解释 381。正确答案：C. 漏洞扫描器。** 漏洞扫描器旨在通过探测和分析来发现并报告潜在漏洞。它们可以检测缺失补丁、配置错误等问题。

选项 A 错误。IDS 根据特定签名或启发式算法对潜在恶意活动进行检测并告警，但不会主动扫描漏洞。

选项 B 错误。网络嗅探器捕获并分析网络流量，但不对基础设施组件进行漏洞评估。
