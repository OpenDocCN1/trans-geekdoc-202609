## 问题 544
在进行安全评估时，Lucy 发现当她输入一个远大于输入字段设计处理能力的字符串时，特定的应用程序就会崩溃。这可能允许她在应用程序的范围内执行任意代码。Lucy 可能正试图利用哪种漏洞？

- (A) SQL 注入
- (B) 跨站脚本 (XSS)
- (C) 缓冲区溢出
- (D) 目录遍历

### 解析 544
正确答案：C. 缓冲区溢出。

缓冲区溢出漏洞发生在写入缓冲区的数据超过该缓冲区的边界时，可能会覆盖相邻的内存位置。如果成功利用，可能会导致任意代码执行。

缓冲区溢出是指应用程序向缓冲区写入多于其能容纳的数据，导致额外数据溢到相邻内存空间。当这种情况发生时，攻击者可以覆盖内存的特定部分，可能导致任意代码执行、应用程序崩溃或数据损坏。

选项 A 错误。`SQL` 注入涉及将恶意的 `SQL` 语句注入输入字段中执行，旨在操纵数据库。它与缓冲区边界或内存溢出无关。

选项 B 错误。跨站脚本 (`XSS`) 允许攻击者在其他用户查看的网页中注入恶意脚本。虽然这是一种输入验证漏洞，类似于缓冲区溢出，但 `XSS` 专门针对浏览器中的脚本执行，不涉及缓冲区边界。

选项 D 错误。目录遍历攻击旨在访问 Web 目录之外的文件和目录。它们不涉及缓冲区边界或内存溢出。

## 问题 551
在年度审查期间，一家公司发现其关键系统在今年发生了多次计划外停机。首席执行官（CTO）建议转向高可用架构以解决这个问题。在实施高可用性时，**主要**关注的是什么？

- (A) **确保没有单点故障**
- (B) 确保系统定期更新补丁
(C) 实现多因素身份认证
(D) 在多个地理位置存储备份

**解析 551.** **正确答案：A. 确保没有单点故障。** 在高可用 (HA) 系统中，消除单点故障至关重要。通过确保每个潜在的故障点都具有冗余，即使某个组件发生故障，系统也能保持运行。

**选项 B 错误。** 虽然补丁对于安全很重要，但它不是实现高可用性时的首要要考虑的问题。

**选项 C 错误。** 多因素身份认证对于安全访问至关重要，但与高可用架构没有直接关系。

**选项 D 错误。** 在不同的地理位置拥有备份更多与灾难恢复有关，而不是高可用性。

## 问题 552
一家政府机构遭遇了网络安全事件，其通信平台被破解。入侵者对提取敏感数据或引起中断并不感兴趣，但观察到他们一直在静地监控外交通信。攻击者的可能动机是什么？

- (A) 从内幕交易中获取利益
- (B) **间谍活动，以理解和预测外交动向**
- (C) 内部员工的不满
- (D) 扩大其网络犯罪网络的的尝试

**解析 552. 正确答案：B. 间谍活动，以理解和预测外交动向。** 静默监控外交通信而不外泄数据或引起中断，表明其动机是为了理解、预测并可能操纵政府或外交行动。这是一个间谍活动的经典案例。

**选项 A 错误。** 虽然敏感信息对内幕交易来说可能很有价值，但对外交通信的关注表明其具有更广泛的战略意图，而不仅仅是财务收益。

**选项 C 错误。** 不满的员工可能会进行破坏或数据泄露，但静默监控外交通信表明其具有更高水平的策略和手段，通常超个人恩怨的范围。

**选项 D 错误。** 攻击者的行为专门针对监控外交渠道，并没有表明试图将更多系统或个人招募进犯罪网络。

## 问题 553
AlphaTech 的 IT 部门正在为远程员工推出新的身份验证协议。作为多因素认证过程的一部分，员工需要提供一种记忆的且无法从物理上夺走的认证信息。以下哪项代表了这种类型的身份验证因子？

(A) 指纹
(B) 智能卡
(C) PIN 
(D) USB 安全密钥

**解析 553. 正确答案：C. PIN。** 个人识别码 (PIN) 代表多因素认证中的“你所知的”因素。这种信息是由用户记忆的，不是可以被夺走的物理物品或生物特征。
