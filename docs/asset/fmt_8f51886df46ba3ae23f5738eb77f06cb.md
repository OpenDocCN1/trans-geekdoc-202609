# Glossary

**access control entry (ACE)**   访问控制列表中的一个条目，指定安全主体（如特定用户）或用户组在对象上的审核条目或访问权限。

**access control list (ACL)**   对象的安全权限或审核设置列表。

**access permissions**   在操作系统中授予对象的各种类型的访问权限。Windows 包含多种访问权限，包括读取、执行和修改。

**account**   包含使人员能够访问和使用网络的信息，包括用户名和登录规范，如登录时间和密码。*另请参阅* user account。

**account lockout**   在一定数量的登录失败尝试后锁定账户的功能（三次失败尝试是常见选择）。通常，被锁定的账户在管理员解锁前无法使用。这有助于防止黑客入侵账户。

**account policies**   一组关于密码使用和账户锁定的规则。

**account restrictions**   确定用户何时以及如何获得网络访问权限。

**ACE**   *参见* access control entry。

**acknowledgment (ACK)**   接收方计算机发送给发送方计算机的一个信息包，用于验证传输已被接收。传输失败将生成否定确认 (NACK)。

**ACL**   *参见* access control list。

**Active Directory**   一种 Microsoft Windows 目录服务，存放网络账户、组和组策略对象。

**active hub**   星型拓扑中用于再生信号并将数据分发到连接到集线器的每个节点的集线器设备。与无源集线器不同，有源集线器需要供电。*另请参阅* hub。

**active partition**   指示系统通电时引导哪个可引导分区。

**adapter**   插入系统以提供功能的卡，如网络适配器，提供网络连接。

**address resolution**   使用另一种地址形式查找主机地址的过程。例如，当使用 IP 地址时，必须将其解析为 MAC 地址。

**Address Resolution Protocol (ARP)**   用于根据 IP 地址确定主机的 MAC 地址。为实现这一功能，ARP 会发送一条广播消息（一个包含其试图查找的系统 IP 地址的 ARP 请求包）。本地网络上的所有系统都会检测到该广播消息，拥有 ARP 正在查找的 IP 地址的系统会通过在 ARP 回复包中将其物理地址发送给源系统来进行回应。物理/IP 地址组合随后存储在源系统的 ARP 缓存中以供将来使用。*另请参阅* Media Access Control。

**administrator account**   用于管理 Windows 服务器和网络设置的账户。此账户在安装期间创建，拥有对服务器的无限访问权限。以管理员身份登录服务器时必须小心，因为管理员访问权限包括关闭服务器和擦除关键数据的能力。

**American Standard Code for Information Interchange (ASCII)**   标准字母和其他键盘字符的计算机可读二进制格式表示。

**application layer**   为应用程序发出网络请求提供一致方式的 OSI 层。应用层协议的示例包括 HTTP、SMTP 和 FTP。

**application server**   运行网络应用程序（如电子邮件或数据库应用程序）的服务器。通常，客户端从用户的桌面连接到应用程序服务器。

**archiving**   将旧文件从文件服务器移出以释放磁盘空间给新文件的过程。如果稍后需要旧文件，可以取消归档并检索它们。归档数据可以保存到 CD、DVD 或磁带。

# 术语表

## A

**ARP**  

*请参阅* 地址解析协议。

**arp**  

一种 TCP/IP 命令行实用程序，用于操作系统上的 ARP 缓存。

**array controller**  

一种接口卡，连接 RAID 解决方案中的所有驱动器，并提供硬件级容错能力。

**ASCII**  

*请参阅* 美国信息交换标准代码。

**asymmetric encryption**  

一种加密方案，使用用户的公钥加密数据，使用用户的私钥解密数据。

**attribute-based access control (ABAC)**  

基于用户账户的特征授予访问权限。

**attributes**  

文件的特征。文件可被指定不同的文件系统属性或文件系统特征，如只读、系统、隐藏和存档。

**authentication**  

向系统证明您的身份，以便访问资源。

**authentication factor**  

代表您用于向系统进行身份验证的方法——您知道的某事、您拥有的某物、您本身的特征、您所在的位置，或您执行的某项操作。

## B

**back door**  

黑客用于获取系统未授权访问权限的方法。此后门可能因系统漏洞而存在，或因先前的攻击被植入而产生。

**backbone**  

互联网络的主干缆线。

**backup**  

将文件保存到单独位置（通常是脱机存储位置，如磁带）的过程。

**backup set**  

为单次备份操作而选定的一组文件、目录或磁盘。

**bandwidth**  

介质可传输的数据量。带宽通常以比特每秒 (bps) 为单位进行测量。

**baseline**  

系统或网络在正常运行条件下的快照，用作衡量未来异常情况的标尺。

**binary**  

用一组零和一表示的任何值。

**binding**  

将不同层级的网络组件链接起来，以实现这些组件之间的通信。例如，将协议绑定到网络适配器，允许网络适配器使用该协议进行通信。

**bit order**  

计算机跨网络传输二进制数的顺序。计算机在跨网络传输二进制数时，可以从任一端开始。

**boot partition**  

包含操作系统文件的 Windows 分区。

**bootup**  

计算机通电时执行的过程。启动过程包括初始化硬件的文件和操作系统的启动。

**bottleneck**  

导致系统性能不足的系统拥塞点。

**bridge**  

一种 OSI 第 2 层硬件设备，用于连接相同或不同拓扑结构的两个 LAN 网段。网桥检查网络数据包的目标和源 MAC 地址，并决定是否将该数据包传递给 LAN 网段。网桥可用于过滤本地子网的流量，防止其传递到不必要的 LAN 网段。

**bring your own device (BYOD)**  

一种允许员工将其个人移动设备连接到网络以执行工作职责的模式。

**broadcast**  

发送给网络上所有系统的数据包。

**broadcast domain**  

一组可以接收彼此广播消息的系统。

**broadcast storm**  

当网络上存在过多广播数据包，导致网络带宽容量接近或达到饱和时发生。

**browser**  

(1) 一种使用 HTTP 访问 URL 并下载和显示网页（通常用 HTML 编写的文档）的应用程序。(2) 一台维护网络服务器集中列表的计算机。

**buffer space**
