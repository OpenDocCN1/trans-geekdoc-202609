
在前面的章节中，我们涵盖了许多内容。目前为止涵盖的大多数主题都是其他编程语言通用的基础概念。在本章中，我们将学习 PHP 特有的内容——PHP 超局变量（superglobals）。我们将学习如何使用这些超局变量与 HTML 表单进行交互，并将信息从一个 PHP 脚本传递到另一个脚本。

## 8.1 PHP 表单处理

首先，这个主题要求你对 HTML 表单元素有基本的了解。如果你不熟悉，`https://www.w3schools.com/html/html_form_elements.asp` 提供了一个你可以参考的快速指南。如果你熟悉，让我们从创建一个简单的 HTML 表单开始，供稍后使用。

打开 Brackets 并在你的 `htdocs` 文件夹中创建一个名为 `form.php` 的新文件。向其中添加以下代码：

```html
<!DOCTYPE html>
<html>
<head><title>PHP Form Handling</title></head> <body>
<form action = "" method = "get"> Enter Name <BR>  
<input type = "text" name = "studentname" value = "Your Name">  
<BR><BR>  
Favorite Subject(s)<BR>  
<input type = "checkbox" name = "subj[]" value = "EL">English  
<input type = "checkbox" name = "subj[]" value = "MA">Math  
<input type = "checkbox" name = "subj[]" value = "PG">Programming  
<BR><BR>  
Gender <BR>
<input type = "radio" name = "gender" value = "M">Male  
<input type = "radio" name = "gender" value = "F">Female  
<BR><BR>
<input type = "submit" name="sm" value = "Submit">
</form>
</body>
</html>
```

仔细研究上面的代码。注意我们使用了以下 `<form>` 标签 `<form action="" method="get">`。这个标签有两个属性 `action` 和 `method`。`action` 属性指定了我们想要处理 HTML 表单的文件。在我们的示例中，我们给它分配了一个空字符串。这意味着我们想要使用当前文件（`form.php`）。如果我们想使用另一个文件来处理表单，我们需要将该文件的路径分配给 `action` 属性。例如，假设我们想使用 `process.php` 且 `process.php` 与 `form.php` 在同一个文件夹中，我们需要编写 `<form action="process.php" method="get">`。

接下来，我们有 `method` 属性。该属性指定了我们想要使用的发送表单数据的方法。有两种方法可用：`get` 和 `post`。如果我们不指定任何方法，默认是 `get`。在我们的示例中，我们指定了想要使用 `get` 方法。我们稍后会讨论这两种方法。

接下来，让我们看看表单中的 `<input>` 标签；这些标签用于创建各种元素。注意，所有的 `<input>` 标签都有一个 `name` 属性。该属性用于为相应的表单元素命名。例如，第一个表单元素（文本框）被命名为 `studentname`，如下方的代码所示。

如果我们想用 PHP 处理这些元素，那么为表单元素命名是强制性的。就像 PHP 中的变量有名称一样，所有表单元素必须有一个 `name`，以便我们以后在代码中引用它们。

接下来，注意我们表单中所有的复选框（`type="checkbox"`）都命名为 `subj`，两个单选按钮（`type="radio"`）都命名为 `gender`。两个单选按钮具有相同的名称，因为它们属于同一个组（即：它们都是“性别”的选项）。同样，复选框具有相同的名称 `subj`，因为它们都是“喜欢的科目”的选项。由于用户可以为复选框选择多个选项，我们需要添加一对方括号 `[]` 来指示所选的选项将被存储为数组。

最后但同样重要的是，注意所有的 `<input>` 标签都有一个 `value` 属性。该属性的行为根据表单元素而不同。对于文本框，它指定了显示在框中的初始值。对于 `submit` 按钮，它指定了按钮上的文本。对于复选框、单选按钮和下拉列表，它指定了每个所选选项将提交的值。例如，如果选择了以下复选框 `<input type="checkbox" name="subj[]" value="EL">`，字符串 `"EL"` 将被提交。

明白了吗？太棒了！让我们继续，，来讨论 `isset()` 函数。

### 1. `isset()` 函数

`isset()` 函数是一个在 PHP 表单处理中常用的函数。它检查变量是否已声明且不为 `NULL`。`NULL` 是一个特殊值，讽刺地表示变量没有值。

假设我们有两个变量 `$a` 和 `$b`，如下：

```php
$a = 5;
$b = NULL;
```

以下语句：

```php
var_dump(isset($a));
var_dump(isset($b));
var_dump(isset($c));
```

给出了：

```
bool(true)
bool(false)
bool(false)
```

`a` 被认为是 set（即 `isset($a)` 返回 true），因为它已声明并有一个非 NULL 值。相反， `$b` 和 `$c` 都被认为是 unset（即 `isset($b)` 和 `isset($c)` 返回 false），因为 `$b` 值为 `NULL` 而 `$c` 未声明。`isset()` 函数通常用于判断按钮是否被点击。我们稍后会学习这一点。

### 2. `get` 和 `$_GET`

`get` 和 `post` 方法都可以将表单数据发送到 PHP 服务器进行处理。主要区别在使用 `get` 方法时，表单数据附加到 URL。此外，使用 `get` 方法传输的数据量有一个限制。`form.php` 中的表单目前使用 `get` 方法。假设我们用以下数据填充表单：

![](img/image_rsrc1J2.jpg)

点击“提交表单”按钮时，URL 变为 `http://localhost/form.php?studentname=Alex&subj%5B%5D=EL&subj%5B%5D=MA&gender=` 注意 URL 中的问号（`?`）？这个问号用分隔符；URL 中问号之后的内容被称为查询字符串。查询字符串包含了我们提交的表单数据，每个数据以 `name=value` 对的形式呈现，并用符号（`&`）分隔。例如，当我们在名为“studentname”的文本框中输入字符串“Alex”时，键对 `studentname=Alex` 被附加到 URL 中。

`subj%5B%5D=EL&subj%5B%5D=MA` 被附加到 URL 之后。这些组合使用 URL 编码来编码 URL 中无法显示的特殊字符。`%5B` 编码字符“[”，而 `%5D` 编码“]”。如果你解码

`subj%5B%5D=EL&subj%5B%5D=MA`

你将得到

`subj[]=EL&subj[]=MA` 这表示我们为 `subj` 表单元素提交了值“EL”和“MA”。

现在，假设我们想在 PHP 脚本中使用存储在查询字符串中的信息，我们该如何做呢？

很简单。我们使用 `$_GET` 超全局变量。`$_GET` 是一个将查询字符串存储为关联数组的超全局变量。要查看 `$_GET` 中的所有数据，我们可以使用 `print_r()` 函数。要查看它是如何工作的，请将以下代码添加到 `form.php` 的 `</form>` 和 `</body>` 标签之间：

```php
<?php
if (isset($_GET['sm']))
    print_r($_GET);
?>
```

在这里，我们使用 `isset()` 函数来检查 `$_GET['sm']` 是否设置。在点击“提交表单”按钮（命名为“sm”）之前，`$_GET['sm']` 被认为未设置。当我们点击按钮时，PHP 将字符串 'Submit Form' 分配给 `$_GET['sm']`，该变量变为已设置。

当这种情况发生时，`isset($_GET['sm'])` 返回 `true`，并执行 `if` 块。刷新 `form.php`（不带查询字符串）并输入之前输入的数据。接下来，点击“提交表单”按钮；你会在页面底部看到附加的行：`Array [studentname] => Alex [subj] => Array ([0] => EL [1] => MA) [gender] => M [sm] => Submit Form )` 这给了我们 `$_GET` 数组的内容。也就是说，`$_GET['studentname'] = 'Alex'`，`$_GET['subj'] = array('EL', 'MA')`，`$_GET['gender'] = 'M'` 且 `$_GET['sm'] = 'Submit Form'`。明白了吗？太棒了！我们现在来看 post 方法。

### 8.1.3 post 和 `$_POST`

`post` 方法与 `get` 方法类似，但表单数据不会附加到 URL。这使得 `post` 方法适用于向服务器发送敏感信息，因为信息不会在 URL 中可见。让我们来看一个例子。将 `form.php` 中的

`<form action="" method="get">`

更改为

`<form action="" method="post">`

接下来，将 PHP 代码更改为

```php
if (isset($_POST['sm']))
    print_r($_POST);
```

最后，再次不带查询字符串加载 `form.php` 并输入之前输入的数据。点击“提交表单”按钮。你应该发现 URL 保持不变。除此之外，其他一切都是相同的。也就是说，你会在表单底部得到相同的输出。使用 `get` 与 `post` 方法处理表单非常相似。主要的区别是一个会将查询字符串附加到 URL，而另一个不会。此外，使用 `get` 方法时我们使用 `$_GET` 超全局变量；使用 `post` 方法时我们使用 `$_POST` 超全局变量。清楚吗？

### 8.1.4 在表单中保留值

在之前的章节中，我们学习了使用 `get` 和 `post` 方法处理 HTML 表单。无论使用哪种方法，注意每当点击“提交表单”按钮时，表单都会刷新且输入的数据不再显示在表单上？如果表单处理成功，这是正确的。但是，如果表单没有处理成功我们需要用户重新提交，这将非常麻烦，因为用户需要再次填写所有字段。如果我们不想这种情况发生，可以使用 `echo` 语句。对于文本框，我们使用 `echo` 语句来修改 `value` 属性。该属性允许我们为文本框填充文本。在 `form.php` 中，我们在文本框中填充了文本“Your Name”。或者，我们可以使用 PHP 用输入的数据填充文本框。为了做到，将

`<input type="text" name="studentname" value="Your Name">`

更改为

`<input type="text" name="studentname" value="<?php

if (isset($_POST['studentname']))

    echo $_POST['studentname'];

?>">`

如果你仔细分析上面的代码，你会注意到我们将文本“Your Name”替换为了以下 PHP 代码块：

```php
<?php
if (isset($_POST['studentname']))
    echo $_POST['studentname']; ?>?>
```

这段代码首先检查 `$_POST['studentname']` 是否设置。如果是（即用户之前提交了该文本字段的数据），我们使用 `echo` 语句用提交的信息填充文本框。明白了吗？用输入的数据填充文本框是相对直接的。

当我们想要填充如复选框、单选按钮和下拉列表等元素时，情况会变得复杂一点。要填充这些元素，我们需要知道选择了哪个选项，并使用 PHP 动态地选择这些选项。让我们来看一个使用复选框的例子。在标签中添加单词“checked”（不带引号）时，复选框就会被选中。例如，

`<input name="subj[]" type="checkbox" value="EL" checked>`

English 导致名为“English”的复选框被选中。如果我们想让 PHP 动态选择这个复选框，我们需要将上面的代码替换为：

`<input type="checkbox" name="subj[]" value="EL" <?php if (isset($_POST['subj']) && in_array('EL', $_POST['subj'])) { echo 'checked'; } ?>>`

English 这里。在这里，我们使用 PHP 检查 `$_POST['subj']` 是否设置以及当前选项是否被选中。如果是，字符串 'EL' 应该在 `$_POST['subj']` 数组中找到。也就是说，`in_array('EL', $_POST['subj'])` 应该返回 `true`。如果是那样，我们就 `echo` 'checked' 来选择这个复选框。这动态选择了名为“English”的复选框。明白了吗？太棒了！稍后将在项目中编写一个填充表单的函数。

### 8.1.5 过滤用户输入

接下来，让我们讨论如何在表单中过滤用户输入。过滤指的是对用户输入进行清洗（sanitization）和验证（validation）。清洗是从输入中移除无效字符的过程。例如，对一个整数进行清洗涉及移除输入中除数字、加号和减号以外的所有字符。另一方面，验证是检查输入是否符合某些标准的过程。例如，如果输入应该是电子邮件地址，我们可以使用验证过程检查它是否确实是电子邮件地址（例如是否包含“@”字符）。要过滤用户输入，我们使用一个名为 `filter_var()` 的内置函数。使用此函数时，我们需要指定如何过滤我们的输入。我们通过在 https://www.php.net/manual/en/filters.php 找到预定义过滤器来实现。根据所使用的过滤器，此函数将返回过滤后的数据或返回 `false`。例如，如果我们想从一个整数中移除无效字符，可以使用 `FILTER_SANITIZE_INT` 过滤器，如下：

```php
$num = '12.5abc';
echo filter_var($num, FILTER_SANITIZE_INT);
```

如果你运行上面的代码，将得到输出 `125`。如果我们想验证电子邮件地址是否有效，可以使用 `FILTER_VALIDATE_EMAIL` 过滤器。向函数传递有效的电子邮件地址，它将返回该电子邮件地址。否则，它返回 `false`。例如，

```php
$email = 'abc@gmail';
var_dump(filter_var($email, FILTER_VALIDATE_EMAIL));
```

我们得到 `bool(false)`，因为“abc@gmail”不是有效的电子邮件地址（缺少“.com”）。

### 8.1.6 跨站脚本 太棒了！我们涵盖了 PHP 中大部分的表单处理概念。最后但同样重要的是，让我们转向跨站脚本。对于这一点，我需要进行演示。将 `form.php` 中的 PHP 代码（在 `</form>` 和 `</body>` 标签之间）更改为以下：

```php
if (isset($_POST['studentname']))
    echo 'You entered'.$_POST['studentname'].'into the text field';
```

并刷新页面。在文本字段中输入 `<script>alert('Hacked');</script>` 并点击“提交表单”按钮。你得到了什么？

你得到了一个显示“Hacked”的警告框，对吧？

![](img/image_rsrc1J3.jpg)感到惊讶吗？

此示例演示了 PHP 中的一个关键安全概念——跨站脚本（也称为 XSS）。当用户在我们的 PHP 表单中输入不希望脚本代码并提交代码时，就会发生跨站脚本攻击。如果我们的网站随后存储了这些代码（例如存储在数据库中）并显示给另一个用户，恶意代码将在另一个用户的浏览器中执行。在我们的示例中，我们使用 Javascript 创建了一个无害的警报框。然而，具有恶意意的用户完全可以使用相同的技术在受害者的浏览器上运行有害的脚本代码。

为了防止这种情况的发生，每当我们显示用户输入的信息时都必须小心。有几种方法可以实现。最简单的方法是使用名为 `htmlspecialchars()` 的内置函数。该函数将特殊字符转换为 HTML 实体。特殊字符是指在 HTML 中具有特殊意义的字符，例如 `<` 和 `>` 。如果你不希望 `<` 和 `>` 代表 HTML 标签的开始和结束，你就需要使用 `htmlspecialchars()` 函数对它们进行编码。该函数将 `<` 和 `>` 分别转换为 `&lt;` 和 `&gt;`。因此，`<script>` 将被转换为 `&lt;script&gt;`，不再被解释为 HTML 标签。

要查看这是如何工作的，请将上面的 PHP 代码更改为：

```php
if (isset($_POST['studentname'])) {
    echo 'You entered ' .htmlspecialchars($_POST['studentname']) .' into the text field';
}
```
