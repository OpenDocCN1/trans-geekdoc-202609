### 9.2.2.3 基于梯度的 SBX (gSBX) 核心思想

通过重写方程 (9.3)，我们得到：

```math
\begin{cases}
c_1^i = x_1^i + \alpha_1(x_1^i - x_2^i)/2 \\
c_2^i = x_2^i - \alpha_2(x_1^i - x_2^i)/2
\end{cases}, \quad 1 \le i \le n
```

其中

```math
\begin{cases}
\alpha_1 = \beta_1 - 1 \\
\alpha_2 = \beta_2 - 1 \\
\beta_1 = \beta_2 = \beta
\end{cases}
```

为了将梯度 `g1` 和 `g2` 引入遗传算子中，我们可以得到：

```math
\begin{cases}
c_1^i < x_1^i, g_1^i < 0 \\
c_2^i < x_2^i, g_2^i < 0
\end{cases}
```

其中 `c_{1,2}` 代表 `c1` 或 `c2`，`x_{1,2}` 表示 `x1` 或 `x2`，而 `g_{1,2}` 代表 `g1` 或 `g2`。
