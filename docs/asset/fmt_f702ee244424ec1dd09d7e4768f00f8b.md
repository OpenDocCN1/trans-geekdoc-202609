
## 实验 15.1：启用系统保护并配置文件资源管理器

### 1. 启用系统保护并创建还原点
如果你不小心安装了某个糟糕的软件，你需要一个在一切还很完好时的系统还原点（系统保护默认是禁用的）。搜索“创建还原点”。

![图 15.1：在 Windows 中创建还原点](img/e8e965bc3537819be0d570febb3fc1d_248_0.png)

### 2. 配置系统保护
打开“创建还原点”项目，弹出“系统属性”对话框。点击右下角的“配置”按钮。

![图 15.2：配置系统保护](img/e8e965b6c3537819be0d570febb3fc1d_249_0.png)

开启系统保护并调整用于系统保护的最大磁盘空间。这是 FIFO（先入先出）机制：当空间填满时，旧的还原点将被删除，以为新点留出空间。

> **注意**：如果你的硬盘被感染了，你可能想要删除那些你认为已经受损的还原点；否则，你可能会导致系统被感染。

### 3. 创建还原点
为你的磁盘分区设置 3% 的磁盘空间后，点击“应用”。回到“系统属性”页面时，点击“创建”。

### 4. 命名还原点
为你的还原点命名并点击“创建”。若需从这些点之一进行还原，可点击“系统属性”选项卡上的“系统还原”按钮。如果你无法启动到 Windows 菜单，可以在启动期间按 `F1`、`F8` 或 `Shift+F8` 进入大多数电脑的紧急菜单。如果 `F8` 不起作用，请搜索你的笔记本电脑品牌和型号以获取启动菜单选项。

### 5. 配置文件资源管理器选项
默认情况下，Windows 隐藏了大多数文件扩展名和操作系统文件。导航到“控制面板”，在右上角的“按类型查看”旁边选择“大图标”，打开“文件资源管理器选项”。

![图 15.3：配置文件资源管理器选项](img/e8e965b6c3537819be0d570febb3fc1d_250_0.png)

在“常规”选项卡上进行更改以适应你的工作流。打开“查看”选项卡并检查设置：建议显示隐藏的文件和文件夹、显示完整路径、隐藏空驱动器，以及**取消勾选**“隐藏已知文件类型的扩展名”。对于是否取消隐藏受保护的操作系统文件，请做出明智的决定（建议保持隐藏）。

![图 15.4：配置文件属性](img/e8e965b6c3537819be0d570febb3fc1d_250_1.png)

### 6. 配置系统设置
从“开始”菜单输入“设置”打开“系统”设置。

![图 15.5：配置系统属性](img/e8e965b6c3537819be0d570febb3fc1d_251_0.png)

搜索“默认”以显示应用程序设置的选项，你也可以更改文档保存的位置。

![图 15.6：配置设置](img/e8e965b6c3537819be0d570febb3fc1d_251_1.png)
