## 实验编号 1

**目的：** 实现并演示 `FIND-S` 算法，以根据给定的训练数据样本集找到最具体的假设。从 CSV 文件读取训练数据。

### FIND-S 算法

1. 将 `h` 初始化为 `H` 中最具体的假设
2. 对于每个正训练实例 `x`
3. 对于 `h` 中的每个属性约束
4. 如果约束被 `x` 满足，则不执行任何操作
5. 否则用 `x` 满足的下一个更一般的约束替换 `h` 中的约束
6. 输出假设 `h`

### 训练数据集：ML1.CSV

![](img/image-v5wsotgm.jpg)

#### 程序

```python
import pandas as pd
import numpy as np

##### 读取 csv 文件中的数据
data = pd.read_csv("ML1.csv")

##### 创建包含所有属性的数组
d = np.array(data)[:, :-1]
print("The attributes are:", d)

##### 分离包含正例和反例的目标属性
target = np.array(data)[:, -1]
print("The target is:", target)

##### 实现 find-s 算法的训练函数
def train(c, t):
    for i, val in enumerate(t):
        if val == "Yes":
            specific_hypothesis = c[i].copy()
            break

    for i, val in enumerate(t):
        if t[i] == "Yes":
            for x in range(len(specific_hypothesis)):
                if val[x] != specific_hypothesis[x]:
                    specific_hypothesis[x] = '?'

    return specific_hypothesis

##### 获取最终假设
print("The final hypothesis:", train(d, target))
```

## 实验编号 2

**目的：** 对于存储在 .CSV 文件中的给定训练数据示例集，实现并演示候选消除算法，以输出与训练示例一致的所有假设集合的描述。

### 候选消除学习算法

候选消除算法计算包含 `H` 中所有与观察到的训练示例序列一致的假设的版本空间。

1. 将 `G` 初始化为 `H` 中一组最一般的假设
2. 将 `S` 初始化为 `H` 中一组最具体的假设
3. 对于每个训练示例 `d`，执行
   - 如果 `d` 是正例
     - 从 `G` 中移除任何与 `d` 不一致的假设
     - 对于 `S` 中每个与 `d` 不一致的假设 `s`
       - 从 `S` 中移除 `s`
       - 将 `s` 的所有最小泛化 `h` 添加到 `S`，使得
         - `h` 与 `d` 一致，且 `G` 的某个成员比 `h` 更一般
       - 从 `S` 中移除比 `S` 中另一个假设更一般的任何假设
   - 如果 `d` 是反例
     - 从 `S` 中移除任何与 `d` 不一致的假设
     - 对于 `G` 中每个与 `d` 不一致的假设 `g`
       - 从 `G` 中移除 `g`
       - 将 `g` 的所有最小特化 `h` 添加到 `G`，使得
         - `h` 与 `d` 一致，且 `S` 的某个成员比 `h` 更具体
       - 从 `G` 中移除比 `G` 中另一个假设不那么一般的任何假设

### 使用版本空间的候选消除算法

### 训练 ML2.CSV

![](img/image-fh7n34ub.jpg)

#### 程序

```python
import numpy as np
import pandas as pd

data = pd.read_csv("ML2.csv")
concepts = np.array(data)[:, :-1]
target = np.array(data)[:, -1]

def learn(concepts, target):
    specific_h = concepts[0].copy()
    general_h = [["?" for _ in range(len(specific_h))] for _ in range(len(specific_h))]

    for i, h in enumerate(concepts):
        if target[i] == "Yes":
            for x in range(len(specific_h)):
                if h[x] != specific_h[x]:
                    specific_h[x] = '?'
                    general_h[x][x] = '?'

        if target[i] == "No":
            for x in range(len(specific_h)):
                if h[x] != specific_h[x]:
                    general_h[x][x] = specific_h[x]
                else:
                    general_h[x][x] = '?'

    # 候选消除算法步骤
    print("\n")
    indices = [i for i, val in enumerate(general_h) if val == ['?', '?', '?', '?', '?', '?']]
    for i in indices:
        general_h.remove(['?', '?', '?', '?', '?', '?'])

    return specific_h, general_h

s_final, g_final = learn(concepts, target)
print("Final Specific_h:", s_final)
print("Final General_h:", g_final)
```
