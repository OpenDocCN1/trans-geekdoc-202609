
`L'(w) = L'(a) * a'(z) * z'(w) = L'(a) * σ'(z) * x`

对于神经网络模型，损失函数关于每一层输出、中间变量和输入的梯度计算过程，与正向传播的计算过程恰好相反。它是先计算损失函数关于输出层输出的梯度，然后逐层向前，计算损失函数关于每一层中间变量、模型参数和该层输入的梯度。这个计算过程称为**反向传播**。

从简单函数构建复合函数，不仅是函数复合运算，还包括普通的加减乘除运算。无论用什么运算构建复合函数，从自变量计算函数输出的正向计算，以及函数关于中间变量和自变量的导数（梯度）的反向求导过程是相似的。我们通过一个简单的例子进一步加深对正向计算和反向求导过程的理解。

对于两个自变量 `x`、`y`，函数 `f(x, y) = (2*x + 3*y)² + (x - 4*y)²` 可以看作：`f(x, y) = s + t`；`s`、`t` 可以看作：`s = u²`，`t = v²`；而 `u`、`v` 可以看作：`u = 2*x + 3*y`，`v = x - 4*y`。该函数的复合过程如图所示。

**图 4-24** 函数 `f(x, y) = (2*x + 3*y)² + (x - 4*y)²` 的复合过程

函数 `f(x, y)` 的正向计算过程如下：

`x, y → u = 2*x + 3*y, v = x - 4*y → s = u², t = v² → f = s + t`

函数 `f(x, y)` 关于 `x` 的偏导数反向求导过程如下：

`f'(s) = 1, f'(t) = 1 → f'(u) = f'(s)*s'(u) + f'(t)*t'(u), f'(v) = f'(s)*s'(v) + f'(t)*t'(v) → f'(x) = f'(u)*u'(x) + f'(v)*v'(x) = (f'(s)*s'(u) + f'(t)*t'(u))*u'(x) + (f'(s)*s'(v) + f'(t)*t'(v))*v'(x)`

#### 反向传播计算过程分析

从这个反向计算图可以看出，*f*^′^(*x*) 来自两条路径的偏导数累积：一条是从 *u* 的反向推导，另一条是从 *v* 的反向推导，即 *f*^′^(*x*) = *f*^′^(*u*)*u*^′^(*x*) + *f*^′^(*v*)*v*^′^(*x*) = *f*^′^(*u*)，而 *f*^′^(*u*) 仅来自 *s* 的反向导数，即 *f*^′^(*u*) = *f*^′^(*s*)*s*^′^(*u*)，同理 *f*^′^(*v*) = *f*^′^(*t*)*t*^′^(*v*)。因此有：

*f*^′^(*x*) = *f*^′^(*s*)*s*^′^(*u*)*u*^′^(*x*) + *f*^′^(*t*)*t*^′^(*v*)*v*^′^(*x*)

也就是说，先求 *f*^′^(*s*)，再求 *s*^′^(*u*)，再求 *u*^′^(*x*)，就可以求出 *f*^′^(*s*)*s*^′^(*u*)*u*^′^(*x*)，即沿着正向计算的反方向计算导数，*f*^′^(*t*)*t*^′^(*v*)*v*^′^(*x*) 也是同样的反向推导过程。

已知 *f*^′^(*s*) = 1，*f*^′^(*t*) = 1，*s*^′^(*u*) = 2*u*，*t*^′^(*v*) = 2*v*，*u*^′^(*x*) = 2，*v*^′^(*x*) = 1，所以最终 *f*^′^(*x*) 为：

*f*^′^(*x*) = 1 × 2*u* × 2 + 1 × 2*v* × 1

#### 前馈神经网络的前向计算

前馈神经网络由多层神经元组成，每层神经元接收上一层的输入 *a*^\[*l*−1\]，并利用神经元自身的模型参数 *w*^\[*l*\]、*b*^\[*l*\] 计算加权和 *z*^\[*l*\] = *a*^\[*l*−1\]*w*^\[*l*\] + *b*^\[*l*\]。然后通过激活函数 *g*^\[*l*−1\] 生成自身的输出 *a*^\[*l*\]，该输出作为下一层神经元的输入，使计算结果层层传递至输出层。输出层的输出与目标值计算某种损失 ℒ(*a*^\[*L*\]*, y*)。

对于上述 2 层神经网络，各层神经元的加权和 *z*^\[1\]、*z*^\[2\] 和输出值 *a*^\[1\]、*a*^\[2\] 可按以下顺序计算，最后计算损失函数值 ℒ(*a*^\[2\]*, y*)：

*z*^\[1\] = *W*^((1))*x* + *b*^\[1\] → *a*^\[1\] = *σ*(*z*^\[1\]) → *z*^\[2\] = *W*^\[2\]*a*^\[1\] + *b*^\[2\] → *a*^\[2\] = *σ*(*z*^\[2\]) → ℒ(*a*^\[2\]*, y*)

该计算过程可用图 4-26 表示：

**图 4-26 两层神经网络的前向计算过程**

神经网络函数可视为其模型参数和中间变量的函数。计算损失函数对这些参数和变量的梯度（导数）过程，与计算任意复杂函数反向导数的过程相同。从最外层的损失函数开始，“由外向内”沿着神经网络函数值正向计算的反方向，依次计算这些中间变量和参数的梯度。

过程为：先求损失函数对输出层输出的梯度；若已得到损失函数对某层 *l* 输出的梯度，即 $\frac{\partial\mathcal{L}}{\partial a^{[l]}}$，根据该层各神经元的激活函数，可得该层神经元加权和 *z*^\[*l*\] 的梯度 $\frac{\partial\mathcal{L}}{\partial z^{[l]}}$（假设该层神经元激活函数为 *g*，即 $\frac{\partial\mathcal{L}}{\partial z^{[l]}} = g'(\frac{\partial\mathcal{L}}{\partial a^{[l]}})$）；根据公式 ()，在已知 $\frac{\partial\mathcal{L}}{\partial z^{[l]}}$ 的情况下，可求出损失函数对该层模型参数 *W*^\[*l*\] 和输入 *a*^\[*l*−1\] 的梯度 $\frac{\partial\mathcal{L}}{\partial W^{[l]}}$ 和 $\frac{\partial\mathcal{L}}{\partial a^{[l-1]}}$。

对于上述 2 层神经网络，反向推导过程如下：

$$

\frac{\partial\mathcal{L}}{\partial a^{[2]}} \rightarrow \frac{\partial\mathcal{L}}{\partial z^{[2]}} \rightarrow \left(\frac{\partial\mathcal{L}}{\partial W^{[2]}}, \frac{\partial\mathcal{L}}{\partial b^{[2]}}, \frac{\partial\mathcal{L}}{\partial a^{[1]}}\right) \rightarrow \frac{\partial\mathcal{L}}{\partial z^{[1]}} \rightarrow \left(\frac{\partial\mathcal{L}}{\partial W^{[1]}}, \frac{\partial\mathcal{L}}{\partial b^{[1]}}\right)

$$

模型各层中间变量和参数的损失函数梯度依赖于正向计算过程中的结果（如 *a*^\[*l*\]）。为避免重复计算这些值，可在正向计算过程中将这些结果存储在神经网络对应层中，反向推导时直接使用这些存储结果，从而避免连续重复计算，提高效率。从计算图角度看，这些中间结果可保存在计算图对应节点上。当前深度学习平台通过计算图表达神经网络的前向传播和反向推导过程，并在计算图对应节点上保存相关中间计算结果。

因此，计算图不仅能保证前向和反向计算的正确计算顺序，还能保存中间结果以提高计算效率。

### 4.2.3 损失函数对输出的梯度

反向推导首先计算损失函数对最终输出层输出的梯度，然后从输出层沿着前向传播的反方向，依次计算损失函数对各层中间变量和参数的梯度，直到输入层。

不同问题（回归、分类）的损失函数定义不同。下面讨论几种常见损失函数对输出层梯度的计算方法。

#### 1. 二元交叉熵损失函数对输出的梯度

针对二分类问题，输出层为一个逻辑回归神经元，*z* 表示该神经元输入的加权和。该加权和通过 Sigmoid 函数产生 (0, 1) 之间的输出值 *a* = *σ*(*z*)，表示样本属于两类中某一类的概率（属于另一类的概率为 1 − *a*）。对于输出层，本书习惯用 *f* = *a* 表示输出值，即 *f* = *σ*(*z*)，用 *y* 表示取值为 1 或 0 的目标值。

根据 3.5 节，二分类的交叉熵损失 *L*(*f*, *y*) = −(*y* log(*f*) + (1 − *y*) log(1 − *f*)) 对 *f* 的导数为：

$$

\frac{\partial L}{\partial f} = - \left(\frac{y}{f} - \frac{1 - y}{1 - f}\right) = \frac{f - y}{f(1 - f)}

$$

而 *f* = *σ*(*z*) 对 *z* 的导数为：

$$

\frac{\partial f}{\partial z} = \sigma(z)(1 - \sigma(z)) = f(1 - f)

$$

因此，*L*(*f*, *y*) 对 *z* 的导数为：*f* − *y*。

对于二分类问题，多个样本的交叉熵为单个样本交叉熵的均值：

$$

L(F, Y) = \frac{1}{m}\sum_{i=1}^{m} L_i(y^{(i)}, f^{(i)}) = - \frac{1}{m}\sum_{i=1}^{m} \left[ y^{(i)}\log(f^{(i)}) + (1 - y^{(i)})\log(1 - f^{(i)}) \right]

$$

因此，交叉熵损失 *L*(*FF*, *YY*) 关于 *zz* 的梯度为：

$$

\frac{\partial L}{\partial FF} = \frac{1}{m}\frac{FF - YY}{FF(1 - FF)}

$$

$$

\frac{\partial FF}{\partial ZZ} = \sigma(ZZ)(1 - \sigma(ZZ)) = FF(1 - FF)

$$

$$

\frac{\partial \mathcal{L}}{\partial ZZ} = \frac{\partial L}{\partial ff}\frac{\partial \pmbf}{\partial zz} = \frac{1}{m}(FF - YY)

$$

目前：

$$

\begin{matrix}

FF = \begin{bmatrix} f^{(1)} \\ \vdots \\ f^{(i)} \\ \vdots \\ f^{(m)} \end{bmatrix} \quad\quad

YY = \begin{bmatrix} y^{(1)} \\ \vdots \\ y^{(i)} \\ \vdots \\ y^{(m)} \end{bmatrix} \quad\quad

\frac{\partial \mathcal{L}}{\partial ZZ} = \frac{1}{m}\begin{bmatrix} f^{(1)} - y^{(1)} \\ \vdots \\ f^{(i)} - y^{(i)} \\ \vdots \\ f^{(m)} - y^{(m)} \end{bmatrix}

\end{matrix}

$$

需要注意的是：因为每个样本对应不同的 *z*^((*i*))，交叉熵损失 *L* 应分别对每个 *z*^((*i*)) 求导，而不是将这些导数相加。此外，上述公式中的向量乘法和除法均为逐元素操作。

根据神经网络的输出 out 是加权求和表示的分数，还是 *σ* 函数的输出概率，可以写出以下计算来计算两类交叉熵损失的加权求和或输出概率的梯度。

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def binary_cross_entropy(f, y, epsilon=1e-8):
    # np.sum(y*np.log(f+epsilon)+ (1-y)*np.log(1-f+epsilon), axis=1)
    m = len(y)
    return - (1./m)*np.sum(np.multiply(y, np.log(f+epsilon)) \
                           + np.multiply((1 - y), np.log(1 - f+epsilon)))

def binary_cross_entropy_grad(out, y, sigmoid_out=True, epsilon=1e-8):
    if sigmoid_out:
        f = out
        grad = ((f-y)/(f*(1-f)+epsilon)) / (len(y))
    else:
        f = sigmoid(out)  # out is z
        grad = (f-y)/(len(y))

def binary_cross_entropy_loss_grad(out, y, sigmoid_out=True, epsilon=1e-8):
    if sigmoid_out:
        f = out
        grad = ((f-y)/(f*(1-f)+epsilon)) / (len(y))
    else:
        f = sigmoid(out)  # out is z
        grad = (f-y)/(len(y))
    loss = binary_cross_entropy(f, y, epsilon)
    return loss, grad
```

z = np.array([-4, 5, 2])   # 三个样本对应的分类分数
f = sigmoid(z)             # 三个样本对应的分类 1 的概率
y = np.array([0, 1, 0])    # 3 个样本对应的分类

loss, grad = binary_cross_entropy_loss_grad(z, y, False)
print(loss, grad)
loss, grad = binary_cross_entropy_loss_grad(f, y)
print(loss, grad)

#### 2. 均方误差损失函数在输出端的梯度

对于回归问题，输出层为一个或多个线性回归神经元，即每个神经元直接输出其输入的加权和 *z*[*i*]，输出层中多个神经元输出的这些值组成一个输出向量 *zz* = (*z*[1], *z*[2], ..., *z*[*K*]) 作为整个输出层的输出 *ff* = *zz*。当 K>1 时，目标值为同等大小的向量 *yy* = (*y*[1], *y*[2], ..., *y*[*K*])。

对于一个样本，可用输出向量 *zz* 与目标值向量 *yy* 之间欧氏距离的平方作为误差 ‖(*ff*^((*i*)) − *yy*^((*i*)))‖₂²。为了使导数（梯度）形式更简洁，通常乘以一个常数，即用 $\frac{1}{2}{\parallel (ff^{(i)} - yy^{(i)}) \parallel_2}^{2}$ 作为误差。该误差关于 *ff*^((*i*)) 的梯度为 *ff*^((*i*)) − *yy*^((*i*))。

若输出值维度为 K，则：

$$

\frac{1}{2}{\parallel (ff^{(i)} - yy^{(i)}) \parallel_2}^{2} = \frac{1}{2}\sum_{k=1}^{K}{(f_k^{(i)} - y_k^{(i)})}^{2}

$$

误差关于 *f*^((*i*)) 的梯度为 (*f*[1]^((*i*)) − *y*[1]^((*i*)), *f*[1]^((*i*)) − *y*[2]^((*i*)), ⋯, *f*[*K*]^((*i*)) − *y*[*K*]^((*i*))) = *f*^((*i*)) − *y*^((*i*))。

对于由多个样本组成的矩阵 *FF*, *YY*，均方误差 $L(FF, YY) = \frac{1}{2m}\sum_{i=1}^{m}{\parallel (ff^{(i)} - yy^{(i)}) \parallel_2}^{2}$。*FF* 的梯度为 $\frac{1}{m}(FF - YY)$。因为 *FF* = *ZZ*，即：

$$

\frac{\partial \mathcal{L}}{\partial ZZ} = \frac{\partial \mathcal{L}}{\partial FF} = \frac{1}{m}(FF - YY)

$$

```python
def mse_loss_grad(f, y):
    m = len(f)
    loss = (1./m)*np.sum((f-y)**2)  # np.square(f-y))
    grad = (2./m)*(f-y)
    return loss, grad
```
