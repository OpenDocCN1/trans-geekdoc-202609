## 安全无线网络

在本章中，你将：

* 根据给定场景，排错与无线网络相关的安全问题

* 学习无线网络的安全影响

* 学习不同版本中内置的安全功能

* 识别不同的 802.11 版本

无线接入日益成为人们访问 Internet 的方式。由于无线接入被视为一种消费者福利，许多企业增加了无线接入点以吸引顾客。随着第三代 (3G) 和第四代 (4G) 移动蜂窝网络的推出，人们越来越多地通过手机访问 Internet。非传统电脑（如笔记本电脑、电子阅读器和平板电脑）普及度的巨大增长也推动了无线接入的流行。

随着无线使用的增加，无线协议的安全性已成为整个网络安全中更重要的因素。作为安全专业人员，你需要理解无线网络应用，因为在广播任何人都可以截获的网络中存在固有风险。在公共波上发送未加密的信息等同于在公司大门上贴出密码。

本章将介绍几种当前的无线协议及其安全特性。

### 无线网络

无线网络是通过不使用直接物理链路的物理拓扑传输分组数据的方式。该定义可以缩小为适用于使用无线电波在公共或私有频段传输信号的网络，而不是使用标准的网络电缆。

802.11 协议已由 IEEE 为无线局域网 (WLAN) 标准化。目前有五个版本在投产——802.11a、802.11b、802.11g、802.11n 和 802.11ac。802.11n 是最新标准，但提供了与 802.11g 硬件的兼容。

### SSID

802.11 协议设计者预见到了一些安全问题，并尝试在 802.11 协议中构建机制以确保足够的安全性。802.11 标准包含了对基础身份验证和机密性控制的尝试。身份验证由 802.11 接入点 (AP) 以最基本的形式处理，强制客户端在尝试“关联”到 AP 时执行握手。关联是 AP 允许客户端跨越 AP 连接到网络之前所需要的过程。

认证功能被称为 `服务集标识符 (SSID)`。这个唯一的 32 字符标识符被附加在数据包的头部。只有当客户端拥有握手过程中所需的所有正确参数（其中 `SSID`）时，才会发生关联。此 `SSID` 设置应将访问限制仅限无线网络的授权用户。`SSID` 默认作为网络名称广播，但可以禁用此信标帧（beacon frame）。许多接入点（AP）也使用默认的 `SSID`；例如，对于许多版本的 Cisco AP，此默认值为 `tsunami`，这可能表示该 AP 未配置任何安全防护措施。重命名 `SSID` 并禁用 `SSID` 广播都是好主意；然而，由于 `SSID` 是每个数据帧的一部分，这些措施不应被视为保护了网络。由于 `SSID` 理论上是一个唯一标识符，只有知道标识符的人才能完成与 AP 的关联。

虽然 `SSID` 在理论上是一个好主，但它在数据包中是以明文传输的，因此在实践中，`SSID` 提供的安全性意义不大——任何嗅探器都能确定 `SSID`，并且许多操作系统（例如 Windows XP 及更高版本）会显示区域内活跃的 `SSIDs` 列表，并提示用户选择连接哪一个。这种弱性由于大多数 AP 默认传输信标帧的设置被放大了。信标帧的目的是发布无线网络的存在和能力，以便 WLAN 卡能够尝试与其关联。在许多 AP 中，这可以在软件中禁用此功能，特别是那些功能更复杂的 AP。从安全角度来看，信标帧是有害的，因为它包含了 `SSID`，而且此信标帧按固定的间隔传输（默认为每秒十次）。由于一个没有任何其他流量的默认 AP 每秒发送十次明文 `SSID`，你可以看出为什么 `SSID` 无法提供真正的认证。诸如 `NetStumbler` 的扫描程序是通过捕获所有 AP 的信标帧并从而获取其 `SSIDs` 来工作的。

### WEP

802.11 协议的设计者还尝试通过引入有线等隐私 (`WEP`) 来维护机密性，它使用加密算法对在空气中传输的数据进行加密。`WEP` 已被证明存在实现问题，可以利用这些问题来破坏安全性。`WEP` 使用 `RC4` 流加密器对跨网络传输的数据进行加密，以确保机密性。（`RC4` 加密器的细节请参见第 24 节）。这种同步加密方法确保了某种认证机制。该系统依赖于客户端和 AP 之间拥有共享密钥，确保只有持有正确密钥的授权人员才能访问无线网络。`WEP` 支持两种密钥长度：40 位和 104 位，尽管这些通常被称为 64 位和 128 位。在 802.11a 和 802.11g 中，制造商将其扩展到 152 位的 `WEP` 密钥。这是因为在所有情况下，总密钥长度的 24 位被用于初始化向量 (`IV`)。

### EAP

扩展身份验证协议（`EAP`）定义在 `RFC 2284` 中（被 `3748` 取代）。`EAP-TLS` 依赖于传输层安全（`TLS`），这是一种尝试标准化 SSL 结构以传递凭据的方法。`EAP-TTLS`（缩名为 `EAP–Tunneled TLS Protocol`）是 `EAP-TLS` 协议的变体。`EAP-TTLS` 的工作方式与 `EAP-TLS` 基本相同，服务器通过证书验证客户端，但该协议对客户端认证进行了隧道处理，允许使用传统的认证协议，如密码认证协议（`PAP`）、挑战握手认证协议（`CHAP`）、`MS-CHAP` 或 `MS-CHAP-V2`。

### PEAP

`PEAP` 或受保护的 EAP 的开发目的是通过 `TLS` 封装来保护 `EAP` 通信。这是由思科、微软和 RSA 共同开发的标准。`EAP` 的设计假设存在安全的通信信道。`PEAP` 通过 `TLS` 隧道作为协议的一部分提供这种保护。`PEAP` 被许多供应商广泛支持用于无线网络。

### LEAP

思科设计了一种名为轻量扩展身份验证协议（`LEAP`）的专用 `EAP`；然而，它正在逐渐被 `PEAP` 或 `EAP-TLS` 等新协议取代。由于容易受到离线密码破解，且已有可以主动破解 `LEAP` 安全性的工具，该协议已被弃用，转而采用更强的 `EAP` 方法。

### CCMP

正如之前讨论 `WPA2` 时提到的，`CCMP` 代表计数模式密码分组链消息认证码协议（或 CBC-MAC 计数模式协议）。`CCMP` 是一种用于无线环境的数据封装加密机制。`CCMP` 实际上是使用 `AES` 算法提供消息完整性的模式。与 `WPA` 不同，`CCMP` 需要新硬件来执行 `AES` 加密。

### 无线操作

无线安全由之前讨论过的协议和操作特性管理。多种操作要素都可以提高无线网络的安全性。`MAC` 过滤、天线类型、放置和功率水平，以及根据现场调查结果布局都可以增强安全性。

### MAC 过滤器

`MAC` 过滤是基于批准的媒体访问控制（`MAC`）地址列表选择性通过数据包。这种方法应用于交换机上，用于提供机器认证的手段。在有线网络中，它受到线路的保护，使得截获信号以确定其 `MAC` 地址变得困难。在无线网络中，这种机制面临一个问题：攻击者可以看到进出接入点所有流量的 `MAC` 地址，然后就可以伪造允许通过接入点通信的 `MAC` 地址。

### 天线放置

Wi-Fi 本质上是一种基于无线电的方法，因此使用天线传输和接收信号。天线的实际设计和放置对射频（`RF`）媒介传输流量可用性有显著影响。天线有多种类型，每种都有自己的传输模式和增益因子。高增益天线可以处理较弱的信号，但覆盖有限。宽覆盖全向天线可以覆盖更广泛的区域，但增益水平较低。天线放置的目标是最大化物理区域的覆盖并减少低增益区域。这在有墙壁、电气干扰和其他干扰源的建筑中可能非常复杂，通常需要现场调查来确定合适的放置位置。

**考试提示** 由于无线天线可以传输到设施外，天线的调优和放置对安全至关重要。通过功率水平控制调整辐射功率将有助于防止无线信号广播到物理访问控制区域之外。

### 功率水平控制

出于多种原因，硬件可以控制 Wi-Fi 功率。使用的功率越低，干扰的机会越少。但如果功率水平太低，信号强度就会限制范围。接入点可以通过手动或编程控制设置功率水平。对于大多数用户来说，功率水平控制并不有用，保持默认模式是最佳选择。在复杂的企业环境中，通过现场调查和计划的叠加区域，这种信号控制方面可以增加网络的容量和控制。

### 天线类型

标准接入点配备有全向天线。全向天线向所有方向工作，使得设备之间的相对方向不那么重要。全向天线每个天线的覆盖面积最大。弱点出现在墙角和难以到达的区域以及设施的边界，在这些地方需要方向性天线来完成覆盖。图 4-2 显示了常见 Wi-Fi 天线的示例：4-2(a) 是常见的家用无线路由器，(b) 是商业室内无线接入点，(c) 是室外方向性天线。室内 `WAPs` 可以如所示可见，也可以隐藏在天花板吊上方。

由信号强度弱引起的无线网络问题有时可以通过在接入点安装升级的 Wi-Fi 无线天线来解决。在业务网络中，多个接入点的复杂性通常需要全面的现场调查，以绘制办公楼内外的 Wi-Fi 信号强度地图。然后可以在需要的地方策略性地放置额外的无线接入点以解决死角。对于只需要单个接入点的小企业和家庭，升级天线可能是解决 Wi-Fi 信号问题的更简单、更具效益的选择。

升级天线的两种常见形式是八角天线（Yagi antenna）和面板天线。如图 4-2(c) 所示。八角天线和面板天线本质上都是方向性的，在更有限的范围内扩散 `RF` 能量，增加一个方向的有效范围，同时限制其他方向的范围。面板天线可以提供良好的室内性能，同时防止信号向天线背面泄露。这在站点边缘效果良好，可以限制可能在场外采集到的杂散发射。八角天线的作用更像步枪，将能量沿着波束汇聚。这使得标准功率即可实现更远的通信距离。此外，由于天线本身提供的增益，窃听者也可以从更远的距离捕获信号。

### 强制门户 (Captive Portals)

`Captive portal`是指使用 `HTTP` 客户端处理无线网络身份验证的特定技术。强制门户经常用于公共热点，它会打开网页浏览器并跳转到身份验证页面。这发生在用户被允许接入网络之前。接入点通过拦截所有数据包并返回登录网页来使用这种简单机制。提供身份验证页面的实际 Web 服务器可以位于网络的隔离区域，在用户成功身份验证之前，阻止其访问互联网。

### VPN（通过开放无线网络）
