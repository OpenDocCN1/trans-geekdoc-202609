
在本章中，提出了一种高效的基于图像的去雾方法，使用对比限制直方图均衡化（`CLAHE`）和引导滤波（`GF`）从雾天图像中去除雾气。直方图均衡化是最常用的图像增强技术之一，它只有在图像中像素分布均匀时才能良好地工作。自适应直方图均衡化（`AHE`）可以克服这个问题。然而，该方法的问题仍然是它倾向于过度放大图像的对比度。因此，引入了 `AHE` 的变体 `CLAHE`。该过程与 `AHE` 类似，但使用 `[0, 1]` 范围的归一化裁剪来消除噪声和对比度的过度放大。虽然它可以减少过度放大的问题，但可能会因为裁剪直方图而丢失某些信息。为了从 `CLAHE` 输出的图像中获得最后的信息，对结果图像应用了边缘保持引导滤波。

本章的结构如下：第12.2节介绍了文献综述；第12.3节涵盖了背景研究。第12.4节给出了所提的方法论。第12.5节给出了数据集的收集与分析。第12.6节创建了图像质量评价标准。第12.7节展示了不同的实验结果并进行了讨论。第12.8节得出了结论和未来展望。

## 12.2 文献综述

在 [20] 中，通过考虑大气颗粒在不同天气条件下会发生散射，建立了一种大气散射模型。此后，目前已经提出了多种基于多图像 [29, 30]、基于天气条件的方法 [21, 22, 25] 以及基于暗通道先验的去雾方法。

基于物理的去雾技术 [15, 34] 也也得到了发展，其中可以使用估计的天气信息来恢复图像对比度。但它仅适用于某些已知的场景深度。另一种基于图像的去雾技术是基于深度图的方法 [14, 23]，它根据用户输入的深度信息来对图像进行去雾。这种方法的问题是它不是自动的，需要用户交互。另一种对图像去雾的有效方法是基于小波的融合方法 [8]，它可以去除图像中的模糊效果。

基于多图像去雾方法的唯一局限性是它需要同一场景的多个图像，这在许多场景中（例如任何移动物体）可能非常难以获取。因此，基于单图像的去雾方法变得越来越流行，因为它只需要一个输入图像，从而解决了多图像去雾方法所面临的问题。

论文 [40] 提出了一种使用对比限制 `AHE` 的去雾方法。该方法将 `RGB` 图像转换为 `HSI` 颜色模型，然后使用 `CLAHE` 处理图像的强度分量。所提方法的缺点是某些图像信息可能会丢失，图像的对比度可能会受到干扰。图像处理的一些先进技术描述如下：

`Jackson` 等人在 [11] 中描述的最有效的去雾方法之一是基于暗通道先验 [2]，该方法假设无雾图像中的某些斑块具有非常低的强度。通过使用 `DCP`，可以获得雾的厚度，从而提高雾图像质量。然而，`DCP` 方法有两个局限性：首先，它无法去除类似于大气光的物体，例如雪地或汽车大灯；其次，其实时性较高。`Chaudhary` 等人在 [1] 中提出了一种计算大气光的方法。在 [2] 中，使用高斯分布提出了一种大气光估计方法，其时间复杂度低于其他方法。`DCP` 结合高斯滤波器用于 [9]，尽管该方法适用于具有均匀雾的图像，但在保留边缘方面存在不足。

[16] 中提出的新方法结合了 `DCP` 和 亮度通道先验（`BCP`），该方法有效地实现了图像清除，但由于 `DCP` 和 `BCP` 是一种统计量，在某些特定图像上可能无法产生预期结果。基于非局部颜色先验（`NLCP`）的方法被提出 [17]。此外，[18] 引入了基于快速暗通道先验（`FDCP`）的方法以提高速度。基于引导通道先验（`GCP`）的方法被提出 [19] 以增强边缘。最后，基于引导滤波（`GF`）的方法被用于 [20] 以提高去雾图像的质量。

## 12.3 背景研究

### 12.3.1 白平衡 `WB`

在初始阶段，对输入的雾天图像应用白平衡。相对于白色识别或调整图像的实际颜色，使其看起来更自然。雾天图像通常具有较高的温度，即较冷的光。由于由于，可能会产生颜色偏差（特定的不需要色调），影响图像质量。在输入的雾天图像上应用 `WB` 进行校正。白平衡程序的伪代码如算法 12.1 所示。

> 算法12.1 白平衡

```
Input: 雾天图像， (Img)
Output: 白平衡图像
procedure WHITE_BALANCE(Img)
  [M, Scale] ← Scale(Img)
  if Scale > 1 then
    R_avg ← mean(mean(Img(:, :1)), :1))
    G_avg ← mean(mean(Img(:, :2)))
    B_avg ← mean(mean(Img(:, :3))) ▷ R_avg, G_avg 和 B_avg 是平均 R, G 和 B 颜色分量
  end
  RGB_avg ← [R_avg, G_avg, B_avg]
  Gray_Value ← (R_avg + G_avg + B_avg) / 3
  Scale_Value ← Gray_Value / RGB_avg
  White_Balanced(:, :1) ← scaleValue(1) × Img(:, :1)
  White_Balanced(:, :2) ← scaleValue(1) × Img(:, :2)
  White_Balanced(:, :3) ← scaleValue(1) × Img(:, :3)
end procedure
```

### 12.3.2 `CLAHE`

直方图均衡化是增强图像最简单的方法之一。它有助于在不确定退化实际原因的情况下提高图像质量。只有当图像的像素值分布相同时，它的效果才良好。`CLAHE` [26] 是 `AHE` [13] 的改进版本，旨在限制后者所面临的问题。`CLAHE` 的工作方式与 `AHE` 相同，唯一的区别在于裁剪限制（`clip limit`）的计算，它规定了对比度增强的限制。裁剪限制的值越高，图像的对比度越高。裁剪限制基于归一化直方图，包含了邻域区域的大小。

最初，将图像划分为多个相同大小的互不重叠块。接着，计算每个区域的直方图，并获得一个所需的裁剪限制以对直方图进行裁剪。重新分配直方图，使其高度不超过裁剪限制。这个重新分配过程可能需要对裁剪因子进行多次迭代。最后，使用双线性插值合并所有相邻块，并根据修改后的直方图改变其灰度值。`CLAHE` 程序的伪代码如算法 12.2 所示。

这里，`$N_{average}$` 是纹理区域平均灰度数。`$NrX$` 是上下文区域 `X` 维度上的像素数，`$NrY$` 是上下文区域 `Y` 维度上的像素数，`$N_{CLIP}$` 是实际裁剪限制，`$N_{clip}$` 是范围 `[0,1]` 内的归一化裁剪限制，`$N_{total}$` 是被裁剪像素的总数，`$N_{vremain}$` 是待分配的平均像素数，`$N_{remain}$` 是待分配的像素数，`$H(i)$` 是每个区域在第 `i` 个灰度级的原始直方图，`$H_{clip}(i)$` 是每个区域在第 `i` 个灰度级的裁剪直方图。

### 12.3.3 `GF`

`GF` 使用另一幅图像（例如引导图像）的属性来执行滤波过程。`GF` 在许多方面都有帮助，例如消除图像中的伪边缘和阶梯效应，以及用于图像平滑和去噪。从数学上讲，`GF` 可以表示为：

```
$q_i = a_k l_i + b_k, \forall i \in \omega_k$$
```

其中，引导图像表示为 `I`，输入图像表示为 `p`，输出图像可以定义为 `q_i`，`$\omega_k$` 是以像素 `k` 为中心的窗口大小，`$(a_k, b_k)$` 是常数。值的计算为：

```
$a_k = \frac{\sum_{i \in \omega_k} l_i p_i - \mu_k \Gamma_k}{\sigma_k^2 + \varepsilon}$
```

```
$b_k = \Gamma_k - a_k \mu_k$
```

### 算法 12.2 `CLAHE`

输入：`$Input_{img}$`

输出：`$Enhanced_{img}$`

1. 将原始强度图像划分为 `M` 个重叠的上下文区域。图像块的总数等于 `M × N`。

2. 根据数组图像中的灰度级计算每个上下文区域的直方图。

3. 通过裁剪限制值计算上下文区域的对比度自适应直方图如下：

```
$N_{average} = (Nx \times Ny) / N_{levels}$
N_{CLIP} = N_{clip} \times N_{gray}$
```

重新分配的平均像素数由 `N_{avggray} = N_{total} / N_{levels}` 给出。

4. 像素裁剪程序：

if `H(i) > N_{CLIP}` 则

`H_{clip} = N_{CLIP}`

else

if `H(i) + N_{avggray} > N_{CLIP}` 则

`H_{clip} = N_{CLIP}`

else

`H_{clip} = H(i)`

end if

5. 重新分配剩余像素直到分配完毕。重新分配步骤由 `N_{levels} / N_{remain}` 给出。

6. 使用插值计算子区域内像素的新灰度级分配

其中 `$\omega$` 是块中的像素数，`$\mu_k$` 和 `$\sigma_k^2$` 是 `I` 的平均值和方差，`$\varepsilon$` 是避免 `a_k` 值最大化的正则参数，`p` 是窗口 `$\omega_k$` 内 `p` 的平均值。

线性模型可以应用于整个图像的每个局部窗口。但包含该像素的每个窗口 `$\omega_i$` 找到输出图像 `q_i` 每个可能像素平均值的简单方法可以所示：

```
$q_i = \frac{1}{|\omega|} \sum_{k \in \omega} a_k l_i + b_k \quad (12.6)$
```

```
$=\overline{a_i} l_i + \overline{b_i} \quad (12.7)$
```

其中 `$\overline{a_i}$` 和 `$\overline{b_i}$` 分别是块 `a_k` 和 `b_k` 的平均值。

## 12.4 方法

所提算法解释如下：

1. 首先，取雾图作为输入图像。

2. 将算法 12.1 给出的白平衡程序应用于雾图，以白色调整输入图像的颜色，使其看起来自然。

3. 为了提高雾图的可见性，将算法 12.2 给出的 `CLAHE` 程序应用于白平衡图像。在此过程中，将图像划分为互不重叠的块，并计算每个块的直方图。之后选择一个裁剪限制来裁剪超出限制的部分。

4. 最后，使用双线性插值对每个区域的直方图进行限制，并根据新的直方图改变灰度值。

5. 由于 `CLAHE` 对直方图的裁剪，图像的一些信息可能会丢失。对于 `GF`，考虑引导图像 `$(l)$` 并进行滤波过程。

6. 计算 `$(l)$`、`CLAHE` 输出 `$(p)$` 以及 `$(I \times p)$` 的平均值。

7. 计算 `$(I,p)$` 的协方差为：

```
$cov\_Ip = mean\_I.*mean\_p \quad (12.8)$
```

8. 获取 `$(I)$` 的方差以获得线性系数 `a` 和 `b`：

```
$var\_I = mean\_l.*mean\_l \quad (12.9)$
```

9. `a` 和 `b` 的值对于获取最终结果非常重要，可以通过获得：

```
$a = (cov\_Ip)/(var\_I + \epsilon) \quad (12.10)$
```

```
$b = mean\_p - a*mean\_l \quad (12.11)$
```

其中 `$\epsilon$` 是正则化参数。

计算 `a` 和 `b` 的平均值并获得图像的最终输出即 `q`：

```
$q = mean\_a.*mean\_b \quad (12.12)$
```

## 12.6 图像质量评估标准

### 12.6.1 峰值信噪比 `PSNR` 和均方误差 `MSE`

峰值信噪比 `PSNR` 和均方误差 `MSE` [17, 18, 27, 41] 是比较去雾图像质量常用的两种误差矩阵。改进去雾图像与原始图像之间的累计平方误差由 `MSE` 表示，其数学表示可以为：

```
MSE = \left[ \frac{1}{M \times N} \right]_{M,N} \sum [I_t(m,n) - I_z(m,n)] \quad (12.13)
```

这里，`$I_t(m,n)$` 和 `$I_z(m,n)$` 分别是雾图和改进图像，`$M \times N$` 是图像的大小，`m, n` 表示图像像素的 `x, y` 位置。

`MSE` 值越小表示误差越小，也就是说 `MSE` 值越低，图像质量越好。

峰误差的衡量标准由 `PSNR` 表示，它可以描述为 `MSE` 的倒数。在数学上，它可以表述为：

```
PSNR = 10 \times \log_{10} \frac{(2^B-1)^2}{MSE} \quad (12.14)
```

`B` 表示每个样本的比特，范围在 0 到 255 之间。`PSNR` 的单位是分贝（dB）。如果方法产生了低 `MSE` 和高 `PSNR` 值，则认为该方法是良好的。

### 12.6.2 熵

图像的熵可以识别其纹理以及图像的随机性。低熵表示区域是均匀的，与雾较大的图像相比，模糊图像具有较低的熵值。在数学上，它可以被估计为：

```
$H = -sum p_i \log_2 p_i \quad (12.15)
```

其中 `p_i` 表示一个灰度级强度出现的概率。

### 12.6.3 结构相似性指数

该指数有助于衡量由各种处理引起引起的图像退化。其计算需要一张参考图像。在数学上，

```
$SSIM(x,y) = \frac{(2\mu_x\mu_y + c_1)(2\sigma_{xy} + c_2)}{\mu_x^2 + \mu_y^2 + c_1(\sigma_x^2 + \sigma_y^2 + c_2)} \quad (12.16)
```

`$\mu_x$` 和 `$\mu_y$` 分别是 `x` 和 `y` 的平均值，`$\sigma_x^2$` 和 `$\sigma_y^2$` 分别是 `x` 和 `y` 的方差，`$\sigma_{xy}$` 是 `x` 的协方差，`c_1` 和 `c_2` 是用于稳定偏差的变量。

### 12.6.4 对比度增益

对比增益是增强图像与原始图像（雾图）对比之间的平均差异 [6]。它可以通过以下方式计算：

```
$C_{gain} = C_j - C_i \quad (12.17)
```

其中 `C_j` 是输出增强图像的平均对比度，`C_i` 是原始雾图的对比度。

增强图像的对比度值越高，去雾算法的结果就越越好。
