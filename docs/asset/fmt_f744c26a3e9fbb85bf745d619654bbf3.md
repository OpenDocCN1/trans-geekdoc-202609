### 4.4.2 针对复值变量的优化：Wirtinger 演算

迄今为止，为了推导线性估计器和广义线性估计器的参数估计，我们都调用了正交性条件。对于复线性估计情况，通过直接最小化公式 (4.20) 中的代价函数，在问题 4.6 中推导出了正规方程。尝试求解该问题的人都经历过一个比实值线性估计更繁琐的过程。这是因为必须使用所有涉及复变量的实部和虚部，并仅用等效的实值量来表示代价函数；然后才能执行优化所需的梯度计算。回顾一下，任何复函数 *f* : ℂ → ℝ 都不可对其复参数求导，因为违反了 Cauchy–Riemann 条件（问题 4.11）。前面提到的将涉及变量分解为实部和虚部的过程，在代数运算方面可能会变得繁琐。Wirtinger 演算提供了一种等效的表述，它基于简单的规则和原则，与标准复微分的规则有很大相似性。

#### 维廷格微积分

设 $f: \mathbb{C} \mapsto \mathbb{C}$ 为定义在 $\mathbb{C}$ 上的复函数。显然，此类函数既可视为定义在 $\mathbb{R}²$ 上，也可视为定义在 $\mathbb{C}$ 上（即 $f(z) = f(x + jy) = f(x, y)$）。此外，它既可视为复值函数 $f(x, y) = f_r(x, y) + j f_i(x, y)$，也可视为向量值函数 $f(x, y) = (f_r(x,y), f_i(x,y))$。若 $f_r$ 和 $f_i$ 均可微，则称 $f$ 在*实数意义上可微*。维廷格微积分考虑了 $f$ 的复数结构，并用一种等价表述来描述实导数，这极大地简化了计算；而且，这种表述与复导数有着惊人的相似性。

## 4.5 线性滤波

线性统计滤波是通用估计任务的一个实例，当需要考虑时间演化的概念，并在每个时间瞬间获得估计值时。会出现三类主要问题：

*   **滤波**，其中时间瞬间 `n` 的估计基于所有先前接收（测量）到的输入信息，*直到并包括*当前时间索引 `n`。
*   **平滑**，其中首先收集离散时间集合 `{0, 1, …, N}` 上的数据，并利用时间索引集合 `{0, 1, …, N}` 对应的*所有*可用信息，在每个时间瞬间 `n ≤ N` 获得估计值。
