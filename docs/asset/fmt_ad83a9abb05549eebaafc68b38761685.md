
**u**[*x*]^(*T*)*Σ̂*[*x**y*]**u**[*y*, *i*] = 0,  **u**[*y*]^(*T*)*Σ̂*[*y**x*]**u**[*x*, *i*] = 0,  *i* = 1, 2, …, *k*.

![Equation](img/si159.png) (20.38)

换句话说，每一对新向量的计算都使其归一化（公式 (20.36)），同时每个向量都与之前迭代步骤中获得的向量正交（广义上的正交）（公式 (20.37) 和 (20.38)）。请注意，这保证了推导出的典型变量与所有先前推导出的典型变量不相关。这让人联想到 PCA 中主成分的不相关性质。CCA 中唯一的非零相关性，即在每个迭代步骤中被最大化的相关性，是 *z*[*x*, *k*] = **u**[*x*, *k*]^(*T*)**x** 和 *z*[*y*, *k*] = **u**[*y*, *k*]^(*T*)**y** 之间的相关性，*k* = 1, 2, …, *m*。

![Equation](img/si160.png)

更多关于 CCA 的内容可参阅文献 [6,26]。在再生核希尔伯特空间中的 CCA 扩展也已被开发并应用（例如见 [9,89,117] 及其参考文献）。在文献 [89] 中，核 CCA 被用于基于内容的图像检索。其目的是允许通过文本查询检索图像，而无需参考与图像相关的任何标注。该任务被视为一个跨模态问题。CCA 的概率贝叶斯公式已在文献 [15,113] 中给出。基于稀疏性论证的正则化 CCA 版本已在文献 [90] 中推导。文献 [65] 提出了一种 CCA 变体，称为*相关成分分析*；它不是推导两个方向（子空间），而是为两个数据集推导一个公共方向。该方法背后的思想是这两个数据集可能差别不大，因此单个方向就足够了。这样，任务需要估计的自由参数更少。此外，正交性约束被取消了，在某些情况下这可能在物理上是不可辩护的。该方法的贝叶斯扩展见文献 [147]。

## 20.5 独立成分分析

PCA 的潜变量解释在公式 (20.17)–(20.19) 中进行了总结，其中每一个观测随机变量 `x[i]` 都（近似地）写为潜变量（在本例中为主成分）`z[i]` 的线性组合，后者又通过公式 (20.19) 获得，施加了不相关性约束。

ICA 的出发点是假设以下潜变量模型为真：

```
x = A s, (20.44)
```

其中（未知的）潜变量 `s` 被假定为相互统计*独立*，我们称它们为*独立成分*（ICs）。任务包括获得矩阵 `A` 和独立成分的估计。我们将重点关注 `A` 为 `l × l` 方阵的情况。对应于潜变量数量 `m` 小于或大于观测随机变量数量 `l` 的场景，即胖矩阵和高矩阵的扩展也已被考虑和开发（见例如 [100]）。

矩阵 `A` 称为*混合矩阵*，其元素 `a[ij]` 称为*混合系数*。潜变量的*估计*将表示为 `z[i], i = 1, 2…, l`，我们也将它们称为独立成分。观测随机变量 `x[i], i = 1, 2, …, l` 有时称为*混合变量*或简称混合物。

为了获得潜变量的估计，我们采用模型

```
ŝ := z = W x, (20.45)
```

其中 `W` 也称为*解混*或*分离*矩阵。注意

```
z = W A s,
```

我们必须估计未知参数，使得 `z` 尽可能接近 `s`。对于方阵，假设可逆，有 `A = W^(−1)`。

### 20.5.1 ICA 与高斯性

$p(\mathbf{s}) = \frac{1}{{(2\pi)}^{l/2}}\exp\left( - \frac{||\mathbf{s}||^{2}}{2} \right)$

为简单起见，我们假设所有变量均已归一化为单位方差。令混合矩阵 `A` 为正交矩阵，即 `A^(-1) = A^(T)`![Equation](img/si186.png)。则混合信号的联合 PDF 很容易得到为（参见公式 (2.45)）

然而，由于 `A` 的正交性，我们有 `||A^(T)x||² = ||x||²`![Equation](img/si188.png) 和 `|det(A^(T))| = 1`![Equation](img/si189.png)，这使得 `p(s)`![Equation](img/si190.png) 与 `p(x)`![Equation](img/si191.png) 无法区分。也就是说，通过观察 `x` 无法得出关于 `A` 的任何结论，因为所有相关信息都已丢失。从另一个角度来看，混合信号 `x[i]`![Equation](img/si76.png) 互不相关，因为 `Σ[x] = I`![Equation](img/si192.png)，而 ICA 无法提供进一步信息。这是联合高斯变量的不相关性等价于独立性这一事实的直接后果（参见第 2.3.2 节）。换句话说，如果潜在变量是高斯分布的，ICA 无法比 PCA 走得更远，因为后者提供不相关分量。也就是说，对于高斯独立分量，混合矩阵 `A` **不可识别**。在更一般的情况下，如果某些分量是高斯的而另一些不是，ICA 可以识别出非高斯分量。因此，为了使矩阵 `A` 可识别，**至多只能有一个**独立分量是高斯的。

从数学角度来看，ICA 任务对于高斯变量是不适定的。确实，假设已经获得了一组独立高斯分量 `z`；则由酉矩阵对 `z` 进行的任何线性变换也将是一个解（如前所示）。注意，PCA 避开了这个问题，因为后者对变换矩阵施加了特定结构。

为了处理独立性，必须以某种方式引入高阶统计信息。二阶统计信息足以施加不相关性，如 PCA 的情况，但这对于 ICA 是不够的。为此，多年来开发了大量技术和算法，回顾所有这些技术远远超出了书籍章节的篇幅限制。此处的目标是为读者提供这些技术背后的核心要义，并引入高阶统计量。感兴趣的读者可参考文献 [55,58,81,100,120] 深入研究该领域。

对 `z` 的分量相互独立施加约束，等价于要求所有高阶 `cross-cumulants`（交叉累积量，附录 B.3）为零。实现这一点的一种可能性是将自身限制在四阶累积量以内 [57]。正如附录 B.3 所述，对于零均值变量，前三个累积量等于相应的矩，即

#### 算法步骤

假设涉及的概率密度函数（PDF）是对称的，这使得奇阶累积量为零。因此，我们只剩下二阶和四阶累积量。在上述假设下，我们的目标是估计解混矩阵 `W`，使得 (a) 二阶累积量和 (b) 四阶累积量变为零。这通过两个步骤实现。

####### 步骤 1

计算

```
ẑ = U^T x
```

其中 `U` 是与 PCA 相关的酉 `l × l` 矩阵。此变换保证 `ẑ` 的分量不相关，即：

```
E[ẑ[i]ẑ[j]] = 0, i ≠ j, i, j = 1, 2, …, l.
```

####### 步骤 2

计算一个正交矩阵 `Û`，使得变换后的随机向量

```
z = Û^T ẑ
```

各分量的四阶交叉累积量为零。为实现这一点，需求解以下最大化任务：

```
max_{ÛÛ^T = I} Σ_{i=1}^l κ_4²(z_i).
```

步骤 2 的依据如下。文献 [57] 表明，四阶累积量平方和在正交矩阵的线性变换下是不变的。因此，由于 `z` 的四阶累积量平方和是固定的，最大化 `z` 的自累积量平方和将迫使相应的交叉累积量为零。观察到这本质上是四阶累积量多维数组的对角化问题。在实践中，这可以通过推广用于矩阵对角化的 Givens 旋转方法来实现 [57]。注意，被最大化的和是以下因素的函数：(a) 未知矩阵 `Û` 的元素，(b) 已知矩阵 `U` 的元素（此步骤已知），以及 (c) 混合信号 `x` 的随机分量的累积量，这些必须在应用该方法前估计。在实践中，通常只能近似地将交叉累积量设为零。这是因为公式 (20.44) 中的模型可能不精确，例如由于噪声的存在。此外，混合信号的累积量仅近似已知，因为它们是由可用观测值估计的。

一旦计算出 `U` 和 `Û`，解混矩阵即可直接获得，我们可以写为：

```
z = W x = (U Û)^T x
```

混合矩阵则为 `A = W^(-1)`。

围绕高阶累积量的思想已经开发出许多算法，这些算法也被称为`张量方法`。张量是矩阵的推广，累积量张量是协方差矩阵的推广。此外，请注意，正如协方差矩阵的特征分析导出不相关（主）成分一样，累积量张量的特征分析导出独立成分。感兴趣的读者可参考文献 [39,57,119] 获取此类技术的更详细说明。

###### ICA 的不确定性

任何 ICA 方法都只能在以下两种不确定性范围内（近似地）恢复独立成分。

*   独立成分（IC）只能恢复到一个常数因子内。确实，如果 `A` 和 `z` 是 ICA 算法恢复的量，那么根据公式 (20.44) 可知，`(1/a)A(1/a)A` 和 `az` 也是解。因此，通常将恢复的潜在变量（IC）归一化为单位方差。
