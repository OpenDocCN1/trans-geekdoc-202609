## 迭代重加权最小二乘算法

之前使用的迭代加权概念也已应用于*迭代重加权最小二乘算法*的背景中。观察到 `ℓ₁` 范数可以写为

```
‖θ‖₁ = ∑_{j=1}^{l} |θⱼ| = θᵀ W_θ θ
```

其中

$$

\mathcal{W}_{\theta} = \begin{bmatrix} \frac{1}{|\theta_{1}|} & 0 & \cdots & 0 \\ 0 & \frac{1}{|\theta_{2}|} & \cdots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \cdots & \frac{1}{|\theta_{l}|} \\ \end{bmatrix},

$$

![Equation](img/si197.png)

其中当 $\theta[i] = 0$ 时，对于某些 $i \in \{1, 2, \dots, l\}$，$\mathcal{W}[\theta]$ 相应的系数被定义为 1。如果 $\mathcal{W}[\theta]$ 是一个常数加权矩阵，即对于某个固定的 $\widetilde{\mathbf{\theta}}$ 有 $\mathcal{W}[\theta] := \mathcal{W}[\tilde{\theta}]$，那么求得最小值

$$

\widehat{\mathbf{\theta}} = {\arg\min}_{\mathbf{\theta} \in \mathbb{R}^{l}}\ \left\| \mathbf{y} - X\mathbf{\theta} \right\|_{2}^{2} + \lambda\mathbf{\theta}^{T}\mathcal{W}_{\widetilde{\theta}}\mathbf{\theta},

$$

![Equation](img/si202.png)

将是直接且类似于岭回归的。在迭代重加权方案中，$\mathcal{W}[\tilde{\theta}]$ 被 $\mathcal{W}[\theta^{(i)}]$ 所取代，后者是利用从前一次迭代获得的参数相应估计值形成的，即 $\widetilde{\mathbf{\theta}} := \mathbf{\theta}^{(i)}$，这与我们之前所做的一样。在后续过程中，每次迭代求解一个加权岭回归任务。

`focal underdetermined system solver` (FOCUSS) 算法 [64] 是第一个使用 `iterative-reweighted-least-squares` 概念的算法，它将 ℓ[*p*], *p* ≤ 1 表示为加权 ℓ[2] 范数，以求得欠定方程组的稀疏解。该算法也具有历史意义，因为它是最早强调稀疏性重要性的算法之一；此外，它还提供了全面的收敛分析以及算法驻点的表征。这一基本迭代加权方案的变体也已被提出（参见例如 [35] 及其参考文献）。

## 弹性网络正则化

在 [126] 中，引入了 `elastic net` 正则化惩罚项，它以权衡的方式将 ℓ[2] 和 ℓ[1] 概念结合在一起，即

```
$\lambda\sum\limits_{i = 1}^{l}\left( \alpha\theta_{i}^{2} + (1 - \alpha)|\theta_{i}| \right),$
```

其中 *α* 是一个用户定义的参数，控制每个单独项的影响。弹性网络背后的思想是结合 LASSO 和岭回归的优势。在 ***x*** 中存在一组高度相关的变量的问题中，LASSO 倾向于在 ***θ*** 中选择一个对应的参数，并以一种相当随意的方式将其余参数设为零。通过仔细观察贪婪算法的工作原理，可以理解这一点。当稀疏性被用于选择 ***x*** 中最重要的变量（特征选择）时，最好选择该组中所有相关的分量。如果知道哪些变量是相关的，可以将它们组成一组，然后使用组 LASSO。然而，如果不知道这一点，引入岭回归可以为该问题提供补救。这是因为岭回归中的 ℓ[2] 惩罚倾向于将与相关变量关联的参数相互收缩（例如 [68]）。在这种情况下，最好采用结合了 LASSO 和岭回归的弹性网络基本原理。

## Dantzig 选择器

在 [23] 中，通过将平方误差项替换为涉及相关性的项来修改 LASSO 任务，最小化任务变为

```
$\widehat{\mathbf{\theta}}:\ \ \ \ \ \min\limits_{\mathbf{\theta} \in \mathbb{R}^{l}}\left\| \mathbf{\theta} \right\|_{1},\text{s.t.}\ \ \ \ \left\| X^{T}(\mathbf{y} - X\mathbf{\theta}) \right\|_{\infty} \leq \epsilon,$
```

其中 *ϵ* 与 *l* 和噪声方差有关。该任务称为 `Dantzig selector`。也就是说，不再约束误差的能量，而是对误差向量与 *X* 的任意列的相关性施加一个上限。在 [5,15] 中表明，在某些条件下，LASSO 估计量和 Dantzig 选择器变得相同。

## 全变分 (TV) 与图像处理

`Total variation` (TV) [107] 是一个与 ℓ[1] 稀疏性促进概念密切相关的概念，已广泛应用于图像处理。大多数灰度图像数组 *I* ∈ ℝ^(*l* × *l*) 由缓慢变化的像素强度组成，边缘除外。因此，图像数组的离散梯度将近似稀疏（可压缩）。

### 离散梯度算子定义

图像数组的离散方向导数按像素定义为：

**x 方向上的离散梯度算子：**

```
∇ₓ(I)(i, j) := I(i + 1, j) − I(i, j),  ∀i ∈ {1, 2, …, l − 1},
```

![Equation](img/si210.png) (10.17)

**y 方向上的离散梯度算子：**

```
∇ᵧ(I)(i, j) := I(i, j + 1) − I(i, j),  ∀j ∈ {1, 2, …, l − 1},
```

![Equation](img/si211.png) (10.18)

**边界条件：**

```
∇ₓ(I)(l, j) := ∇ᵧ(I)(i, l) := 0,  ∀i, j ∈ {1, 2, …, l − 1}.
```

![Equation](img/si212.png) (10.19)

**离散梯度变换** $\nabla : \mathbb{R}^{(l \times l)} \to \mathbb{R}^{(l \times 2l)}$ 以矩阵形式定义为：

```
∇(I)(i, j) := [∇ₓ(i, j), ∇ᵧ(i, j)],  ∀i, j ∈ {1, 2, …, l}.
```

![Equation](img/si213.png)
![Equation](img/si214.png) (10.20)

### 全变分范数与优化

图像 $I$ 的全变分（TV）范数定义为：

$$

\left\| I \right\|_{\text{TV}} := \sum_{i=1}^{l}\sum_{j=1}^{l}\left\| \nabla(I)(i,j) \right\|_{2} = \sum_{i=1}^{l}\sum_{j=1}^{l}\sqrt{\left( \nabla_{x}(I)(i,j) \right)^{2} + \left( \nabla_{y}(I)(i,j) \right)^{2}}.

$$

请注意，这是 $\ell_2$ 和 $\ell_1$ 范数的混合。全变分周围的稀疏性促进优化定义为：

$$

I_{\ast} \in \text{arg}\min_{I}\left\| I \right\|_{TV},\text{s.t.}\ \ \left\| \mathbf{y} - \mathcal{F}(I) \right\|_{2} \leq \epsilon,

$$

其中 $\mathbf{y} \in \mathbb{R}^{N}$ 为观测向量，$\mathcal{F}(I)$ 表示线性算子作用于 $I$ 后的向量化结果。例如，这可以是部分二维 DFT 作用于图像的结果。将 DFT 矩阵进行子采样作为构建感知矩阵的一种手段，已在 9.7.2 节中讨论过。(10.22) 式中的任务保持其凸性质，基本上表达了我们在给定可用观测条件下，重建尽可能平滑图像的愿望。NESTA 算法可用于求解全变分最小化任务；除了 NESTA 之外，该任务的其他高效算法可参见例如文献 [63, 120]。

文献 [22] 已针对精确观测情况（$\epsilon = 0$），文献 [94] 针对误差观测情况证明了：保证从 (10.22) 式任务中恢复图像阵列的条件和界限可以推导出来，且与我们针对 $\ell_1$ 范数情况所讨论的非常相似。

## 10.4 在线稀疏性促进算法

本节介绍用于稀疏感知学习的在线方案。必须采用此类方案的原因有很多。正如前几章所述，在各种信号处理任务中，数据是按顺序到达的。在这种情况下，使用批处理技术来获得未知目标参数向量的估计将是非常低效的，因为训练点的数量不断增加。这种方法对于实时应用是不可行的。此外，当学习环境不是平稳的，而是随时间演变发生变化时，时域递归方案可以轻松地融入自适应的概念。除了信号处理之外，还有越来越多的其他机器学习应用领域，其中在线处理至关重要，例如生物信息学、高光谱成像和数据挖掘。在这些学科中，训练点的数量轻易就达到几千到几十万个点。关于环境（特征）空间的维度，可以声称存在类似范围的数字。例如，在文献 [82] 中，任务是在维度高达 $10⁹$ 的特征空间中搜索稀疏解，并能访问多达 $10⁷$ 个点的数据集。用今天的技术在单台计算机上使用批处理技术是不可能的。

本节采用的设置与前几章（例如第 5 章和第 6 章）中使用的设置相同。我们假设存在一个未知参数向量，根据线性回归模型生成数据：

$$y[n] = \mathbf{x}[n]^{(T)}\boldsymbol{\theta} + \eta[n], \quad \forall n,$$

![Equation](img/si220.png)

并且训练样本是按顺序接收的（`y[n]`，`x[n]`），`n = 1, 2, …`。在平稳环境的情况下，我们期望算法在 `n → ∞` 时渐近收敛到产生观测值 `y[n]` 的真实参数向量，或者“几乎”收敛到该向量，当时它被 `x[n]` 感知时。对于时变环境，算法应能随时间推移跟踪潜在的变化。在继续之前，有一点评论很重要。因为时间索引 `n` 被允许增长，我们在前几节中关于欠定方程组的所有论述都失去了意义。迟早我们将拥有的观测值数量超过数据所在空间的维数。这里我们主要关注的问题变成了平稳环境下渐近收敛的问题。现在显而易见的问题是，为什么不使用标准算法（例如 LMS、RLS 或 APSM），因为我们知道这些算法会收敛到解，或者在某种意义上“足够接近”解（即算法将渐近地识别出零点）？答案是，如果这些算法经过修改以感知潜在的稀疏性，收敛速度将显著加快；在实际应用中，人们没有“奢侈”地等待很长时间才能得到解。在实践中，一个好的算法应该能在相对较少的迭代步骤后提供足够好的解，并且在稀疏解的情况下*获得支撑集*。

在第 5 章中，我们评论了修改经典在线方案（例如比例 LMS）以考虑稀疏性的尝试。然而，这些算法的性质相当权宜。在本节中，围绕 `ℓ₁` 范数正则化的强大理论将被用来获得促进稀疏性的时域自适应方案。

### 10.4.1 LASSO：渐近性能

在介绍第 3 章参数估计的基本原理时，引入了与估计量性能相关的偏差、方差和一致性概念。在许多情况下，这些性能指标是渐近推导出来的。例如，我们已经看到最大似然估计量是渐近无偏且一致的。在第 6 章中，我们看到在存在独立同分布白噪声样本的情况下，LS 估计量也是渐近一致的。此外，在后一假设下，基于 `n` 个观测值的 LS 估计量 `\hat{\mathbf{\theta}}_n` 本身是一个随机向量，满足 `\sqrt{n}`-估计一致性，即

```
\sqrt{n}\left( {\widehat{\mathbf{\theta}}}_n - \mathbf{\theta}_o \right)\longrightarrow\mathcal{N}\left( 0,\sigma_\eta^{2}\Sigma^{- 1} \right),
```

其中 `\mathbf{\theta}_o` 是产生观测值的真实向量，`\sigma_\eta²` 表示噪声源的方差，`\Sigma` 是输入序列的协方差矩阵 `\mathbb{E}[\mathbf{x}\mathbf{x}^T]`，该序列已假设为零均值，极限表示依分布收敛。

公式 (9.6) 形式的 LASSO 是最小化平方误差和代价函数的 `ℓ₁` 范数正则化版本的任务。然而，到目前为止尚未提及该估计量的统计性质。我们提到的唯一性能指标是 (9.36) 中给出的误差范数界。然而，尽管该界在其提出的背景下很重要，但并未提供太多统计信息。自 LASSO 估计量提出以来，许多论文都探讨了与其统计性能相关的问题（参见例如 [45,55,74,127]）。

#### 稀疏性促进估计量与神谕性质

在处理稀疏性促进估计量（如 LASSO）时，会出现两个关键问题：(a) 即使在渐近意义上，如果真实参数向量是稀疏的，该估计量能否获得支撑集；以及 (b) 量化该估计量关于非零分量估计值的性能——即那些索引属于支撑集的分量。特别是对于 LASSO，后一个问题转化为研究 LASSO 关于这些非零分量的表现是否与无正则化的 LS 一样好。这一任务首次在文献 [55] 中以更一般的设定得到解决。

设真实但未知的 `k` 稀疏参数向量 `θ[o]` 的支撑集记为 `S`。另设 `Σ[|S|]` 为 `k × k` 协方差矩阵 `E[x[|S|]x[|S|]^(T)]`，其中 `x[|S|] ∈ ℝ^(k)` 是仅包含 `x` 中索引在支撑集 `S` 内的 `k` 个分量的随机向量。如果一个估计量满足以下条件，则称其渐近地满足*神谕性质*：

*   `lim_{n→∞} Prob{ S_{θ̂_n} = S } = 1`；这被称为*支撑集一致性*；
*   `√n ( θ̂_{n|S} - θ_{o|S} ) ⟶ N( 0, σ_η² Σ_{|S|}^{-1} )`；这是 `√n`-*估计一致性*。

我们用 `θ[o|S]` 和 `θ̂_{n|S}` 分别表示从 `θ_o, θ̂_n` 中保留索引位于支撑集 `S` 内的分量后得到的 `k` 维向量，极限指分布意义上的极限。换句话说，根据神谕性质，一个优秀的稀疏性促进估计量应能在渐近意义上预测真实支撑集，且其关于非零分量的性能应与预先知晓非零系数位置的“神谕辅助” LS 估计量一样好。

不幸的是，LASSO 估计量*无法*同时满足这两个条件。已有研究表明 [55,74,127]：

*   为实现支撑集一致性，正则化参数 `λ := λ[n]` 应为时变的，使得

$$

\lim_{n\rightarrow\infty}\frac{\lambda_{n}}{\sqrt{n}} = \infty,\quad\lim_{n\rightarrow\infty}\frac{\lambda_{n}}{n} = 0.

$$

![Equation](img/si242.png)

*   也就是说，$\lambda_n$ 必须比 $\sqrt{n}$ 增长得快，但比 $n$ 增长得慢。

*   为了实现 $\sqrt{n}$-一致性，$\lambda_n$ 必须按以下方式增长：

    $$

    \lim_{n\rightarrow\infty}\frac{\lambda_{n}}{\sqrt{n}} = 0,

    $$

    即它的增长速度比 $\sqrt{n}$ 慢。
