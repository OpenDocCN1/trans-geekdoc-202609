
```go
func remove(slice []int, i int) []int {
    copy(slice[i:], slice[i+1:])
    return slice[:len(slice)-1]
}

func main() {
    s := []int{5, 6, 7, 8, 9}
    fmt.Println(remove(s, 2)) // "[5 6 8 9]"
}
```

如果不需要保留顺序，只需将最后一个元素移入空缺位置：

```go
func remove(slice []int, i int) []int {
    slice[i] = slice[len(slice)-1]
    return slice[:len(slice)-1]
}

func main() {
    s := []int{5, 6, 7, 8, 9}
    fmt.Println(remove(s, 2)) // "[5 6 9 8]"
}
```

## 4.3 Map

哈希表是所有数据结构中最精巧、用途最广的之一。它是一个无序的键值对集合，所有键各不相同，且无论哈希表多大，都能通过平均常数次键比较来检索、更新或删除给定键关联的值。

在 Go 中，`map` 是对哈希表的引用，map 类型写作 `map[K]V`，其中 `K` 和 `V` 分别是其键和值的类型。给定 map 中的所有键类型相同，所有值类型也相同，但键类型不必与值类型相同。键类型 `K` 必须支持 `==` 比较，以便 map 判断给定键是否等于已有键。虽然浮点数可比较，但用浮点数做相等比较是坏主意，正如第 3 章所述，若 `NaN` 是可能值则更糟。值类型 `V` 无限制。

内置函数 `make` 可创建 map：

```go
ages := make(map[string]int) // mapping from strings to ints
```

也可用 *map 字面量* 创建并初始化键值对：

```go
ages := map[string]int{
    "alice":   31,
    "charlie": 34,
}
```

这等价于：

```go
ages := make(map[string]int)
ages["alice"] = 31
ages["charlie"] = 34
```

因此，新建空 map 的另一种写法是 `map[string]int{}`。

通过下标符号访问 map 元素：

```go
ages["alice"] = 32
fmt.Println(ages["alice"]) // "32"
```

用内置函数 `delete` 删除元素：

```go
delete(ages, "alice") // remove element ages["alice"]
```

这些操作在元素不存在时也安全；用不存在的键查找 map 会返回该类型的零值，因此即使 `"bob"` 尚不在 map 中，以下代码也能工作，因为 `ages["bob"]` 的值将是 `0`：

```go
ages["bob"] = ages["bob"] + 1 // happy birthday!
```

简短赋值形式 `x += y` 和 `x++` 也适用于 map 元素，故上述语句可改写为：

```go
ages["bob"] += 1
```

甚至更简洁地：

```go
ages["bob"]++
```

但 map 元素不是变量，不能取其地址：

```go
_ = &ages["bob"] // compile error: cannot take address of map element
```

原因之一是 map 扩容可能导致现有元素被重新哈希到新存储位置，从而使地址失效。

用基于 `range` 的 `for` 循环遍历 map 中所有键值对，类似切片遍历。循环每次迭代将 `name` 和 `age` 设为下一对键值：

```go
for name, age := range ages {
    fmt.Printf("%s\t%d\n", name, age)
}
```

map 迭代顺序未指定，不同实现可能用不同哈希函数导致不同顺序。实践中顺序是随机的，每次执行都不同。这是有意为之：让顺序变化有助于强制程序在不同实现下保持健壮。要按序遍历键值对，必须显式排序键，例如键为字符串时用 `sort` 包的 `Strings` 函数。这是常见模式：

```go
import "sort"

var names []string
for name := range ages {
    names = append(names, name)
}
sort.Strings(names)
for _, name := range names {
    fmt.Printf("%s\t%d\n", name, ages[name])
}
```

既然一开始就知道 `names` 的最终大小，预先分配所需大小的数组更高效。下面语句创建一个初始为空但容量足以容纳 `ages` map 所有键的切片：

```go
names := make([]string, 0, len(ages))
```

第一个 `range` 循环只需 `ages` map 的键，故省略第二个循环变量。第二个循环只需 `names` 切片的元素，故用空标识符 `_` 忽略第一个变量（索引）。

map 类型的零值是 `nil`，即不引用任何哈希表。

```go
var ages map[string]int
fmt.Println(ages == nil)    // "true"
fmt.Println(len(ages) == 0) // "true"
```

包括查找、`delete`、`len` 和 `range` 循环在内的大多数 map 操作，在 nil map 引用上均安全，因为其表现如空 map。但向 nil map 存值会引发 panic：

```go
ages["carol"] = 21 // panic: assignment to entry in nil map
```

### Map 操作与模式

### Map 的初始化与访问

在存入数据前，你必须先分配 map。

通过下标访问 map 元素总会产生一个值。如果 key 存在于 map 中，你会得到对应的值；如果不存在，你会得到该元素类型的零值，正如我们在 `ages["bob"]` 中所见。对于许多用途这已经足够，但有时你需要知道该元素是否真实存在。例如，如果元素类型是数值类型，你可能需要区分一个不存在的元素和一个恰好值为零的元素，可以使用如下测试：

```go
age, ok := ages["bob"]
if !ok { /* "bob" 不是此 map 中的 key；age == 0. */ }
```

你经常会看到这两条语句合并写法，如下所示：

```go
if age, ok := ages["bob"]; !ok { /* ... */ }
```

在此语境下对 map 进行下标访问会产生两个值；第二个值是一个布尔值，报告该元素是否存在。该布尔变量通常命名为 `ok`，特别是当它紧接着在 `if` 条件中使用时。

### Map 的比较

与切片一样，map 之间不能相互比较；唯一合法的比较是与 `nil` 比较。要测试两个 map 是否包含相同的 key 和相同的关联值，我们必须编写一个循环：

```go
func equal(x, y map[string]int) bool {
    if len(x) != len(y) {
        return false
    }
    for k, xv := range x {
        if yv, ok := y[k]; !ok || yv != xv {
            return false
        }
    }
    return true
}
```

观察我们如何使用 `!ok` 来区分“缺失”和“存在但为零”这两种情况。如果我们天真地写成 `xv != y[k]`，下面的调用会错误地报告其参数相等：

```go
// 如果 equal 写法不正确，则为 True。
equal(map[string]int{"A": 0}, map[string]int{"B": 42})
```

### Map 作为集合

Go 没有提供 `set` 类型，但由于 map 的 key 是唯一的，map 可以胜任这一用途。为了说明这一点，程序 `dedup` 读取一系列行并仅打印每个不同行的第一次出现。（它是我们在第 1.3 节展示的 `dup` 程序的一个变体。）`dedup` 程序使用一个 map，其 key 代表已经出现过的行的集合，以确保后续出现的行不被打印。

gopl.io/ch4/dedup

```go
func main() {
    seen := make(map[string]bool) // 一个字符串集合
    input := bufio.NewScanner(os.Stdin)
    for input.Scan() {
        line := input.Text()
        if !seen[line] {
            seen[line] = true
            fmt.Println(line)
        }
    }

    if err := input.Err(); err != nil {
        fmt.Fprintf(os.Stderr, "dedup: %v\n", err)
        os.Exit(1)
    }
}
```

Go 程序员通常不加赘述地将以这种方式使用的 map 描述为“字符串集合”，但要当心，并非所有 `map[string]bool` 值都是简单的集合；有些可能同时包含 `true` 和 `false` 值。

### 处理不可比较的 Key 类型

有时我们需要 key 为切片的 map 或集合，但因为 map 的 key 必须是可比较的，所以无法直接表达。不过，这可以分两步完成。首先我们定义一个辅助函数 `k`，将每个 key 映射为一个字符串，其性质是：当且仅当我们认为 `x` 和 `y` 等价时，`k(x) == k(y)`。然后我们创建一个 key 为字符串的 map，在访问 map 前对每个 key 应用该辅助函数。

下面的示例使用 map 记录 `Add` 被以给定字符串列表调用的次数。它使用 `fmt.Sprintf` 将字符串切片转换为适合作为 map key 的单个字符串，使用 `%q` 对每个切片元素加引号，以忠实记录字符串边界：

```go
var m = make(map[string]int)

func k(list []string) string { return fmt.Sprintf("%q", list) }

func Add(list []string)       { m[k(list)]++ }
func Count(list []string) int { return m[k(list)] }
```

同样的方法可用于任何不可比较的 key 类型，不仅限于切片。当你想要一种不同于 `==` 的相等定义时，它甚至对可比较的 key 类型也很有用，例如字符串的大小写不敏感比较。而且 `k(x)` 的类型不必是字符串；任何具有所需等价性质的可比较类型都可以，例如整数、数组或结构体。

### Unicode 字符计数

这是另一个 map 实际应用的例子，该程序统计输入中每个不同 Unicode 码点出现的次数。由于可能的字符数量巨大，而在任何特定文档中只会出现其中一小部分，map 是一种自然的方式，用来跟踪那些已出现的字符及其对应的计数。

gopl.io/ch4/charcount

```go
// Charcount 计算 Unicode 字符的计数。
package main

import (
    "bufio"
    "fmt"
    "io"
    "os"
    "unicode"
    "unicode/utf8"
)

func main() {
    counts := make(map[rune]int)    // Unicode 字符的计数
    var utflen [utf8.UTFMax + 1]int // UTF-8 编码长度的计数
    invalid := 0                    // 无效 UTF-8 字符的计数

    in := bufio.NewReader(os.Stdin)
    for {
        r, n, err := in.ReadRune() // 返回 rune、字节数、错误
        if err == io.EOF {
            break
        }
        if err != nil {
            fmt.Fprintf(os.Stderr, "charcount: %v\n", err)
            os.Exit(1)
        }
        if r == unicode.ReplacementChar && n == 1 {
            invalid++
            continue
        }
        counts[r]++
        utflen[n]++
    }
    fmt.Printf("rune\tcount\n")
    for c, n := range counts {
        fmt.Printf("%q\t%d\n", c, n)
    }
    fmt.Print("\nlen\tcount\n")
    for i, n := range utflen {
        if i > 0 {
            fmt.Printf("%d\t%d\n", i, n)
        }
    }
    if invalid > 0 {
        fmt.Printf("\n%d invalid UTF-8 characters\n", invalid)
    }
}
```

`ReadRune` 方法执行 UTF-8 解码并返回三个值：解码后的 rune、其 UTF-8 编码的字节长度和一个错误值。我们预期的唯一错误是文件结束。如果输入不是 rune 的合法 UTF-8 编码，返回的 rune 为 `unicode.ReplacementChar`，长度为 1。

`charcount` 程序还打印输入中出现的 rune 的 UTF-8 编码长度的计数。map 不是该用途的最佳数据结构；因为编码长度仅从 1 到 `utf8.UTFMax`（值为 4），数组更紧凑。

作为一个实验，我们曾在某个时间点对这本书本身运行了 `charcount`。虽然它当然主要是英文，但确实包含相当数量的非 ASCII 字符。以下是前十名：

```
°  27    15    14  é  13  x  10  ≤  5  ×  5    4    4    3
```

```

```

### 复合 Map 值

map 的值类型本身可以是复合类型，例如 map 或切片。在下面的代码中，`graph` 的 key 类型是 `string`，值类型是 `map[string]bool`，代表一个字符串集合。从概念上讲，`graph` 将一个字符串映射到一组相关字符串，即有向图中的后继节点。

gopl.io/ch4/graph

```go
var graph = make(map[string]map[string]bool)

func addEdge(from, to string) {
    edges := graph[from]
    if edges == nil {
        edges = make(map[string]bool)
        graph[from] = edges
    }
    edges[to] = true
}

func hasEdge(from, to string) bool {
    return graph[from][to]
}
```

`addEdge` 函数展示了惯用的方式来惰性填充 map，即在键首次出现时初始化每个值。`hasEdge` 函数展示了缺失 map 条目的零值通常是如何被利用的：即使 `from` 和 `to` 都不存在，`graph[from][to]` 也总会给出一个有意义的结果。

## 4.4 结构体

*结构体* 是一种聚合数据类型，它将零个或多个任意类型的命名值组合在一起作为一个单一实体。每个值被称为一个 *字段*。来自数据处理的结构体经典示例是员工记录，其字段包括唯一 ID、员工姓名、地址、出生日期、职位、薪水、管理者等。所有这些字段被收集到一个单一实体中，可以作为一个单元进行复制、传递给函数和从函数返回、存储在数组中，等等。
