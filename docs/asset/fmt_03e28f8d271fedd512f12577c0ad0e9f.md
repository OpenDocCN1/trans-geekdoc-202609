
> $L(x, \lambda) = f(x) - \lambda g(x)$

这里的逻辑非常直接。首先，让我们对该方程的两边取梯度。

> $\nabla L(x, \lambda) = \nabla f(x) - \lambda\nabla g(x)$

在极值点，$L$ 的梯度必须为零。如果我们将左侧设为零，就回到了我们上面分析的等式：

> $\nabla f(x) = \lambda\nabla g(x)$

这意味着，优化问题简化为寻找拉格朗日函数的极值。

### 最优间隔

在我们转向讨论拉格朗日乘数之前，我们的目标是找到权重向量`w`，使得 ![Equation reads, the norm of vector squared over 2.](img/p220_01.png)最小。还有一个额外的约束，即对于位于边界或边界之外的数据点，必须满足以下方程（间隔规则）：

> $y_i(w \cdot x_i + b) \geq 1$

嗯，我们进入了拉格朗日领域。

你会通过将 ![Equation reads, the norm of vector squared over 2.](img/p220_01.png) 视为 $f(x)$，将 $(y_i(w \cdot x_i + b)-1)$ 视为 $g(x)$ 来写出拉格朗日函数，然后按照上述描述的过程进行。然而，得到的方程并不总是可以通过解析法求解，你需要专门的数学技术来寻找拉格朗日乘数。（这些乘子的数量与约束方程的数量相同，而我们每个数据点都有这样一个方程。）

我们将重点关注约束优化的结果。第一个结果是，权重向量由该公式给出：

![](img/p221_01.png)

每个`α[i]`（alpha sub-i）都是一个标量，特定于特定的数据点及其相关标签（`x[i]`, `y[i]`）。这些 alpha 值就是拉格朗日乘子。（为了与许多文献保持一致，我们现在称它们为 alphas 而不是 lambdas。）给定一些训练数据，专门的优化技术可以为我们提供 alpha 值，从而帮助我们计算权重向量和偏置项。从数学分析中得出的另一个关键见解是，alpha 值*仅依赖于表示数据样本的向量之间的互点积*。请记住这一点。

如你从上面的方程所示，权重向量实际上是表示数据样本的向量的线性组合，其组合系数为这些 alpha 值。这是一个令人惊叹的结果。

因此，一旦我们得到了 alpha 值，就可以计算权重向量，它连同偏置项`b`共同决定了超平面。然后，很容易判断一个新数据点——我们称其为`u`——位于超平面的哪侧还是另一侧。

> 新数据点的标签为![公式内容：u 等于负 1，w 点 u 加 b 小于 0；正 1，w 点 u 加 b 大于等于 0。](img/p221_02.png)

我们可以代入上方方程中的`w`值，得到第二个结果，即决策规则：

> 新数据点的标签为![公式内容：u 等于负 1，alpha 下标 i y 下标 i x 下标 i 点 u 从 i 求和加 b 小于 0；正 1，alpha 下标 i y 下标 i x 下标 i 点 u 从 i 求和加 b 大于等于 0。](img/p221_03.png)

请注意，决策规则同样仅依赖于新样本与每个表示训练数据的向量之间的点积。事实证明，对于不位于边界上的样本，`α[i]` 将为零；因此，实际上，我们只处理那些位于边界上的数据点。

![](img/p222_01.png)

上面的图表只显示了位于边界上的数据。这些数据点显然是向量，因为它们有助于定义（或锚定）边界，所以它们被称为支持向量。此外，所有的分析适用于任何维度的向量，而不仅仅是我们为了方便可视化而使用的 2D 向量。

如果说这个复杂的讨论让我们领会了某一点，那就是：最优分类超平面仅取决于支持向量彼此之间的点积；而告诉我们新数据点`u`被分类为 +1 还是 −1 的决策规则，仅取决于`u`与每个支持向量的点积。因此，如果你的数据集有 10,000 个数据点，但只有十个是支持向量，你只需要担心计算这十个向量之间的互点积，以及新数据点与每个支持向量的点积。（这个回顾略去了为了找到每个支持向量的`α[i]`所需复杂优化。）

无论如何，这是一个非常了不起的发现，它源于 Vapnik 在 1964 年设计的算法。这是 Boser 在 1991 年秋季在贝尔实验室研究的算法。他完成了该算法针对线性可分数据集的实现和测试，但在搬到伯克利之前还有时间可以打发。Vapnik 建议 Boser 尝试通过将数据投影到高维来对线性不可分的数据进行分类。Boser 开始思考这个问题。这个想法是，尽管数据在原始的低维空间中是线性不可分的，但可以将其投影到某些高维空间，在其中它可能是线性可分的，并且可以使用最优边界分类器找到该高维超平面。如果你将超平面投影回低维空间，它看起来就像某些将数据分成若干簇的非线性曲线。

将数据投影到高维空间有许多方法。对于我们的目的，此类投影带来了两个主要的考虑。一个与 Vapnik 的原始算法有关，它需要数据样本的互点积。假设原始数据集是十维的。这将需要计算十维向量的点积。如果这些数据在 10D 空间中是线性不可分的，且如果被投影到 1000 维，数据干净地聚类两个可分离类别，那么每个数据点将由一个 1000 维向量表示。算法需要这些巨大向量的点积。随着你进入越来越高的维度以寻找找到线性分离平面的最优空间，计算点积的成本可能会高到无法接受。另一个考虑是，有时人们将数据投影到一个具有无限维的空间。（我们很快就会看到如何实现这一点。）这具有巨大的优势，因为在无限维空间中，你总是能找到分离超平面。但对于如何计算无限维向量的点积，更不用说将此类向量存储在计算机内存中了。那么，你如何找到超平面呢？

一个早晨，在一起上班的路上，Boser 开始与他的妻子 Isabelle Guyon 讨论他的项目，Guyon 是一个机器学习专家，思维非常倾向于数学。她也工作在贝尔实验室。Guyon 对此类问题进行了很多思考，特别是为了她的博士论文。她立即提出了一种解决方案，可以跳过在高维空间计算点积的需求。这涉及到一种精妙的技巧，其历史可以追溯到 20 世纪 60 年代俄罗斯数学家的工作。Guyon 的洞察以及随后与 Vapnik 和 Boser 的合作，导致了最成功的机器学习算法之一。

### 核技巧

在 20 世纪 80 年代，Isabelle Guyon 是巴黎的一位年轻工程学生，对控制论感兴趣并正在寻找实习。她的教授之一 Gérard Dreyfus（后来成为了她的博士导师）告诉她阅读一位名为 John Hopfield 的物理学家的论文。这篇论文描述了一种构建神经网络的新颖方法，这种网络可以被训练存储记忆。这些网络被称为 Hopfield 网络（下一章的主题），设计用于存储记忆，引起了神经网络研究人员的关注。作为实习生，Guyon 开始研究它们，并在读硕士期间继续这项研究。她开发了一种更高效的训练 Hopfield 网络的方法，并尝试使用这些网络分类手写数字。但这些网络的特殊性质使得它们在这种分类任务上效果并不理想。Guyon 转向其他模式识别算法。她拿起当时领域的“圣经”，一本由 Richard Duda 和 Peter Hart 写的关于模式分类的书——我们在第五章遇到过 Hart，他是 Cover-Hart K 最近邻算法的共同发明者——并开始实现和测试各种模式识别算法。Guyon 在获得博士学位期间遇到的两个想法与其后来在贝尔实验室的工作直接相关。其中一个是边界分类器的想法。即使在使用 Hopfield 网络和其他算法构建线性分类器时，Guyon 也了解了两位物理学家 Werner Krauth 和 Marc Mézard 的工作，他们当时在巴黎附近的巴黎高等师范学院工作。Krauth 和 Mézard

当 Bernhard Boser 向 Guyon 提到 Vapnik 的最优间隔分类器时（这是 Boser 本人在 1991 年秋季实现的），Guyon 感到如耳一新。而 Vapnik 要求 Boser 将低维中线性不可分的数据投影到某些高维空间，这更让她大为震动。Guyon 在读博士期间遇到过此类思想。她研究过的该主题的一篇关键论文是由三位俄罗斯研究人员于 1964 年写的。

在他们的论文中，这三位俄罗斯人受物理思想启发，开发了一种算法，允许 Rosenblatt 的感知机能够找到非线性边界。我们可以直接探讨他们所做的本质，避开早期作品中许多复杂的表述。回想一下 Rosenblatt 的感知机算法仅在数据线性可分时才有效。这里有一个无法处理的简单数据集：

![](img/p226_01.png)

在左图中，无法通过画一条直线（或线性分离超平面）来将圆圈与三角形区分开来。但如果我们将这些数据投影到三维空间，使得三角形位于圆圈之上（右图），我们就能找到这样一个分离超平面。

这里是实现方法。每个原始数据点都是二维的，其特征为`x1`和`x2`（在本情况下为两个轴上的值）以及标签`y`，标签可以是 1（圆圈）或 −1（三角形）。我们可以通过创建一个第三特征`(x1² + x2²)`并将其绘制在 z 轴上，将数据投影到三维。因此，现在三维中的每个数据点由`(x1, x2, x1² + x2²)`表示，分别对应 x、y、z 轴上的值。在 3D 中绘制时，三角形位于圆圈之上；感知机可以找到所示的超平面来分离两者。

对于我们刚刚解决的问题，想出一个第三特征来帮助将数据分为两类并不困难。但如果 2D 数据是这样呢？

![](img/p227_01.png)

现在选择什么特征并不显而易见；`x1² + x2²`是行不通的。我们需要一种更有规律的方法将数据投影到高维空间。即使低维空间本身远高于 2D（导致我们无法进行可视化），该方法也有效。此外，一旦我们将数据投影到高维空间，在扩展空间中寻找线性分离超平面就涉及计算高维向量的点积，这在计算上可能是不可行的（从时间和内存角度考虑）。因此，算法需要同时完成两件事：(1) 创建新特征，使得数据可以映射到某些高维空间；(2) 避免在该新空间中执行点积，并且仍能找到分离超平面。

Aizerman 和 Rozono 在他们 1964 年的论文中展示了如何对感知机算法做到这一点。在他们对算法的重述中，表征超平面的权重向量表示为构成训练数据集的向量的线性组合，而分类数据点的决策规则仅取决于该点与训练集中其他所有数据点的点积。

我们将探索 Aizerman 和 Rozonoer 提出的思想，但避免使用那三位研究人员使用的精确映射；相反，我们将使用一种十年后开发的映射，因为它更容易理解。让我们从二维数据开始，使用三个特征将其映射到三维空间。给定低维空间中的向量`xj`（在本例中为 2D），它被映射到高维空间中的向量`ϕ(xj)`（在本例中为 3D）。

```
xj → ϕ(xj)
```

我们的映射如下：`x1 x2`到`x1², x2², square root of 2 x1 x2`。（images/p228_01.png）

因此，如果 2D 中的点`a`由`a1 a2`给出，点`b`由`b1 b2`给出，那么这些点在投影到 3D 空间时，将变为`a1², a2², square root of 2 a1 a2`和`b1², b2², square root of 2 b1 b2`。（images/p228_02.png）

为了找到线性分离超平面，我们必须计算高维空间的向量的点积。在这个玩具示例中，执行 3D 空间中所有向量的点积并不费力。但在现实世界中，扩展空间的维度可能是巨大的，导致计算过于耗费资源（从时间和内存而言）。但 Aizerman 和 Rozono 向我们展示了一个可以完全避免这种复杂性的巧妙技巧。

重申一下，要在高维空间中找到线性分离超平面，我们必须计算所有`i`和`j`组合的`ϕ(xj)`与`ϕ(xi)`点积。

如果我们能对两个低维向量`xi`和`xj`进行计算，并得到与高维空间中对应向量点积相同的答案呢？如果我们能找到一个函数`K`，使得：

```
K(xi, xj) → ϕ(xi).ϕ(xj)
```

换句话说，如果我们向函数`K`传递两个低维向量，那么该函数的输出值应该等于高维空间中扩展向量的点积。让我们看向量`a`和`b`的具体示例：

![](img/p229_01.png)

我们需要一个产生相同输出的函数`K`。这样的函数是这样的：

```
K(x, y) = (x.y)²
```

将这两个低维向量`a`和`b`馈给该函数看看会发生什么：

```
K(a, b) = (a.b)²
= (a1*a2).(b1*b2)²
= (a1*b1 + a2*b2)²
= (a1²*b1² + a2²*b2² + 2*a1*a2*b1*b2)
```

因此，`K(a, b) = ϕ(a).ϕ(b)`。

这太棒了。因为我们一直在研究 2D 和 3D 空间，这种意义可能并不显而易见。让我们暂时想象`a`和`b`是 100 维向量，而`ϕ(a)`和`ϕ(b)`是百万维。如果我们找到合适的映射`xj` → `ϕ(xj)`，使得`K(xi, xj) → ϕ(xi).ϕ(xj)`，那么我们就可以在不进入百万维空间的情况下计算高维向量的点积；我们可以在百维空间中计算。

你可以看到，在 3D 空间中两类数据点被清晰地分开，这使得算法能够找到一个平面（在这种情况下是任意一个平面），将圆与三角形分开。现在，给定 2D 中的任意一个新数据点，我们可以将其投影到 3D 空间，并根据其相对于超平面的位置将其分类为圆或三角形。当这个划分好的 3D 空间投影回原始的 2D 空间时，我们就得到了一个将圆与三角形分开的非线性边界（参见图）。

![](img/p231_01.png)

# 历史发展

Boser 承担了算法实现和测试的大部分工作，特别是针对当时最受欢迎的数据集：修改后的美国国家标准技术研究院（`MNIST`）手写数字数据库。与此同时，Guyon 自主撰写了一篇论文，准备提交给年度计算学习理论（`COLT`）会议。她在贝尔实验室的同事和朋友，特别是`Esther Levin`和`Sara Solla`，曾为这个声誉国际的会议发表过论文。Guyon 说：“人们当时倾向于认为，如果你在 COLT 上发表了论文，你就是一个真正的机器学习专家，因为这是一场非常硬核的理论会议。”
