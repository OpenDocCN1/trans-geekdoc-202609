## 第 7 章：访问管理

### 复习题答案

1.  强制访问控制。更多信息，请参阅“强制访问控制”部分。

2.  安全管理员。行政职责的划分可能涉及一名专门的安全管理员，负责为网络中的服务器、主机和连接设备执行信息安全任务。在这些环境中，行政职责的分离应尽可能清晰、明确和受控。更多信息，请参阅“简介”部分。

3.  RBAC。基于角色的访问控制模型是一种旨在对所有网络对象和用户进行集中控制的策略。它根据用户在组织中的职位提供访问控制。网络管理员被授予指定和实施明确安全策略的权力，以执行组织的既定策略。每个网络用户或组被分配一个或多个角色。更多信息，请参阅“基于角色的访问控制”部分。

4.  组策略。这些是目录服务数据库对象，管理员用它们根据用户在组织中的职位和工作角色来创建对网络资产的组访问和限制。这些对象使管理员能够从单一管理环境中跨网络实施这些策略。更多信息，请参阅“访问控制模型”部分。

5.  访问控制列表 (ACL) 将权限附加到网络对象上，系统利用这些权限来控制对资产（程序、文件夹、文件、打印机）的访问，以及可对这些资产执行的活动。更多信息，请参阅“访问控制模型”部分。

6.  封装安全载荷 (ESP) 提供源认证以及加密。ESP 对整个 TCP/UDP 数据报进行加密和封装，置于一个不包含任何端口信息的 ESP 头部中。更多信息，请参阅“虚拟专用网络”部分。

7.  用户账户限制是添加到模型中的最后一个访问控制组件。这些是管理员应用于用户账户（而非文件夹、文件和打印机）的配置，旨在限制其在本地计算机上（本地账户）或整个网络中（域账户）的活动。更多信息，请参阅“访问控制模型”部分。

## 8. 认证头 (AH)

认证头 (AH) 提供数据完整性和源认证，以防止重放攻击（攻击者重放记录的传输以获取访问权限的攻击）。有关更多信息，请参阅“虚拟专用网络”部分。

## 9. 目录服务

目录服务是分布式、可定制的信息存储结构，提供一个单一入口，用户可由此搜索并定位分散在整个网络中的资源。有关更多信息，请参阅“目录服务”部分。

## 10. Active Directory 结构

树是共享相同 DNS 名称的对象集合。Active Directory 可将域细分为组织单位（销售、管理等），这些单位可包含其他单位，或叶对象（如打印机和用户）。有关更多信息，请参阅“Active Directory”部分。

## 11. 安全账户管理器 (SAM)

此数据库包含有关用户账户、组账户和计算机账户的信息。它跟踪域内所有对象的名称和资源请求。您可能还会发现此数据库被称为安全账户管理器 (SAM)。有关更多信息，请参阅“Active Directory”部分。

## 12. Linux 目录服务

较新的发行版已转向基于 LDAP 的目录服务。与 Active Directory 一样，基于 LDAP 的 Linux 平台为系统信息查找和认证提供单一目录源。将用户信息存储在基于 LDAP 的目录服务器中，使网络具有可扩展性、可管理性和安全性。有关更多信息，请参阅“Linux 目录服务”部分。

## 13. 远程访问服务器 (RAS)

RAS 是一台专门为远程用户（不属于域 ACL 成员的用户）提供网络访问的服务器。该服务器负责认证这些用户以访问特定网络资产，并为他们提供登录凭据。有关更多信息，请参阅“远程访问服务器认证”部分。

## 14. 管理员和用户

这些基本上是网络中的两类用户。有关更多信息，请参阅“用户访问管理”部分。

## 15. Root

Root 管理员组是一个标准的、默认的 Linux 组，拥有对系统的完全管理控制权。有关更多信息，请参阅“Linux 组账户”部分。

6.  攻击面分析过程旨在明确设备或系统的哪些方面构成漏洞，以便组织了解与该特定设备或系统相关的风险。更多信息，请参阅“攻击面分析”部分。

7.  ISASecure 认证旨在提供保证，即其供应商组织已将网络安全制度化并融入其产品开发实践中。更多信息，请参阅“供应链”部分。

8.  **渗透测试**。渗透测试是组织利用外部资源（或内部资源）尝试闯入网络或系统并可能发起攻击的一种方式，目的是向网络所有者提供信息，说明如何修复其网络中的不安全因素。更多信息，请参阅“ICS 渗透测试”部分。

9.  **漏洞利用代码**，即设计用于利用特定漏洞的计算机程序。这些漏洞利用代码可能被用于向目标系统投放载荷，从而授予黑客对该系统的访问权限。更多信息，请参阅“ICS 渗透测试”部分。

10. **数据包嗅探器**。使用数据包分析器，白帽黑客捕获网络中移动的数据包，记录它们，然后解码其原始数据。随后他们可以分析这些数据，实际上是在监视网络用户。更多信息，请参阅“安全测试工具”部分。

11. **端口扫描**。使用端口扫描工具探测网络服务器和设备的开放端口以便利用。它们还可以识别主机上运行的服务以供潜在利用。更多信息，请参阅“安全测试工具”部分。

## 12. Vulnerability Scanners

Vulnerability scanning uses a network vulnerability scanner package to scan an organization's network to find different types of common vulnerabilities, such as system misconfigurations and default password usage, as well as generating malformed packets to create DoS attacks. See the "Security Testing Tools" section for more details.
