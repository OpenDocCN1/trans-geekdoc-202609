
已经提出了各种专门的启发式方法来提高多项式文档分类器的性能（Rennie et al. 2003）。我们现在介绍一种替代的类条件密度，它的表现与这些专门的启发式方法一样好，但具有概率学上的合理性（Madsen et al. 2005）。假设我们简单地用狄利克雷复合多项分布或 DCM 密度替换多项式类条件密度，定义如下：

```
p(xi|yi = c, α) = ∫ Mu(xi|Ni, θc) Dir(θc|αc)
```

# 4.1.2 高斯分布的最大熵推导

在本节中，我们将展示多元高斯分布是在预定义均值和协方差的约束下，具有**最大熵**的分布（另见第 TODO 节）。这是高斯分布被**广泛使用**的原因之一：前两个矩通常是我们能从数据中可靠估计的全部，因此我们需要一种能捕捉这些性质，但除此之外做尽可能**少的额外假设**的分布。为简化符号，我们将假设均值为零。概率密度函数（pdf）具有以下结构：

```
f(x) = 1/Z exp(-1/2 x^T Σ^{-1} x)  (4.10)
```

### 4.2 高斯判别分析

多元正态分布（MVN）的一个重要用途是为生成式分类器中的类条件密度建模，即：

```
p(x|y = c, θ) = N(x|μ_c, Σ_c)  (4.11)
```

由此产生的方法称为（高斯）判别分析或 GDA（尽管它是生成式而非判别式分类器，有关此区别的更多信息请参见第 TODO 节）。如果 `Σ_c` 是对角的，这等同于朴素贝叶斯。我们可以使用以下决策规则对特征向量进行分类，该规则源自公式 3.1：

```
y = argmax_c [log p(y = c|π) + log p(x|θ)]  (4.12)
```

当我们计算 x 在每个类条件密度下的似然时，我们实际上是在使用马氏距离测量 x 到每个类中心 `μ_c` 的距离。这可以被视为最近质心分类器。例如，图 4.2 展示了二维空间中两个高斯类条件密度，分别代表人类的身高和体重。我们可以看到特征之间存在相关性，这符合预期（个子高的人通常体重也更重）。每个类别的椭圆包含 95% 的概率质量。假设我们对类别有均匀先验，我们可以按如下方式对新的测试向量进行分类：

```
y = arg max_c (x - μ_c)^T Σ^{-1} (x - μ_c)  (4.13)
```

#### 4.2.1 二次判别分析 (QDA)

通过将高斯密度的定义代入公式 3.1，我们可以得到：

```
p(y|x, θ) = π_c |2π Σ_c|^{-1/2} exp[-1/2 (x - μ)^T Σ^{-1} (x - μ)]
            -------------------------------------------------------------  (4.14)
            ∑_c' π_c' |2π Σ_c'|^{-1/2} exp[-1/2 (x - μ)^T Σ^{-1} (x - μ)]
```

对该结果进行阈值处理会得到 x 的二次函数。该结果称为**二次判别分析 (QDA)**。图 4.3 给出了一些二维空间中决策边界外观的示例。

#### 4.2.2 线性判别分析 (LDA)

我们现在考虑一种特殊情况，即协方差矩阵在各类别间被绑定或共享，`Σ_c = Σ`。在这种情况下，我们可以将公式 4.14 简化如下：

```
p(y|x, θ) ∝ exp(μ_c^T Σ^{-1} x - 1/2 μ_c^T Σ^{-1} μ_c + log π_c)  (4.15)
```

由于二次项 `x^T Σ^{-1} x` 与 c 无关，它将在分子和分母中抵消。假设我们定义：

```
γ_c ≜ -1/2 μ_c^T Σ^{-1} μ_c + log π_c  (4.16)
β_c ≜ Σ^{-1} μ_c  (4.17)
```

我们可以写成：

```
p(y|x, θ) = e^{β_c^T x + γ_c} / ∑_c' e^{β_c'^T x + γ_c'} = σ(η)_c  (4.18)
```

其中 `η ≜ (e^{β_1^T x + γ_1}, ..., e^{β_C^T x + γ_C})`，`σ()` 是 softmax 激活函数，定义如下：

```
exp(q_i)
σ(q, i) = ------------  (4.19)
∑_j exp(q_j)
```

当由某个常数 `α > 0` 定义时，以下公式成为最大值函数的一个平滑、可微近似：

```
∑_D x_j e^{α x_j}
S_α(x) = ---------------  (4.20)
∑_D e^{α x_j}
```

`S_α` 具有以下性质：

1. `S_α → max` 当 `α → ∞` 时

2. `S_0` 是其输入的平均值

3. `S_α → min` 当 `α → -∞` 时

请注意，softmax 激活函数源自统计物理学领域，在那里通常使用玻尔兹曼分布，其形式与 softmax 激活函数相同。公式 4.18 的一个有趣性质是，如果我们取对数，最终会得到 x 的**线性函数**。（之所以是线性的，是因为 `x^T Σ^{-1} x` 从分子和分母中抵消了。）因此，任意两个类别（设为 c 和 c′）之间的决策边界将是一条直线。因此该方法称为**线性判别分析 (LDA)**。

> 16 http://en.wikipedia.org/wiki/Softmax_activation_function

另一种方法是不先拟合 LDA 模型再推导类后验，而是直接拟合 `p(y|x, W) = Cat(y|W x)`，其中 W 为某个 `C × D` 权重矩阵。这称为多类逻辑回归，或多项逻辑回归。我们将在第 TODO 节详细讨论该模型。这两种方法的区别在第 TODO 节中解释。

#### 4.2.3 二分类 LDA

为了更深入地了解这些方程的含义，让我们考虑二分类情况。在这种情况下，后验概率由下式给出：

```
p(y = 1|x, θ) = e^{β_0^T x + γ_0} / (e^{β_0^T x + γ_0} + e^{β_1^T x + γ_1})  (4.21)
              = 1 / (1 + e^{(β_0 - β_1)^T x + (γ_0 - γ_1)})  (4.22)
              = sigm((β_1 - β_0)^T x + (γ_0 - γ_1))  (4.23)
```

其中 `sigm(x)` 指代 sigmoid 函数。

现在：

```

          = 1/2 (μ_1 - μ_0)^T Σ^{-1} (μ_1 + μ_0) + log(π_1/π_0)  (4.25)
```

因此如果我们定义：


# w 的大小决定了策略容量的陡峭程度

`w` 的大小决定了策略容量的陡峭程度，这取决于均值之间的隔离程度与方差的相对比较。在脑科学和信号检测理论中，通常使用一个称为 d-prime 的量来表征信号相对于背景噪声的可辨别度：

```
d′ ≜ (µ1 − µ0) / σ
```

其中 `µ1` 是信号的均值，`µ0` 是噪声的均值，`σ` 是噪声的标准差。如果 `d′` 很大，信号将更容易从噪声中分离出来。

#### 4.2.5 防止过拟合的策略

MLE 方法的速度和简洁性或许是其最大的吸引力。然而，MLE 在高维情况下可能会严重过拟合。具体来说，当 `N_c < D` 时，全协方差矩阵的 MLE 是奇异的。即使 `N_c > D`，MLE 也可能是病态的，意味着它接近奇异。针对这个问题有几种潜在的解决方案：

*   对每个类使用对角协方差矩阵，这假设特征在条件上是独立的；这等同于使用朴素贝叶斯分类器（第 3.5 节）。

*   使用全协方差矩阵，但将其约束为所有类共享，即 `Σ_c = Σ`。这是参数绑定或参数共享的一个例子，等同于 LDA（第 4.2.2 节）。

*   使用对角协方差矩阵并约束其共享。这称为对角协方差 LDA，将在第 TODO 节讨论。

*   使用全协方差矩阵，但施加先验然后将其积分掉。如果我们使用共轭先验，这可以利用第 TODO 节的结果以闭式形式完成；这类似于第 3.5.1.2 节的贝叶斯朴素贝叶斯方法。详见 (Minka 2000f)。

*   通过 MAP 估计拟合全或对角协方差矩阵。我们在下面讨论两种不同类型的先验。

*   将数据投影到低维子空间，在那里拟合高斯分布。参见第 TODO 节以寻找最佳（最具判别性）线性投影的方法。

##### 5.2.1.1 无不确定性度量

使用后验分布来总结我们对一组未知变量的所有了解，是贝叶斯统计的核心。在本章中，我们将更详细地讨论这种统计方法。

MAP 估计最明显的缺点，实际上任何点估计（如后验均值或中位数）的缺点，都是它不提供任何不确定性度量。在许多应用中，知道可以在多大程度上信任给定的估计至关重要。我们可以从后验中获得此类确定性度量，正如我们在第 5.2.2 节讨论的那样。后验 `p(θ | D)` 总结了我们对未知量 `θ` 的所有了解。在本节中，我们讨论可以从概率分布（如后验）中得出的一些基本量。这些汇总统计量通常比完整的联合分布更易于理解和可视化。

##### 5.2.1.3 众数是一个非典型点

我们可以通过计算后验均值、中位数或众数，无疑地得出一个未知量的点估计。在第 5.7 节中，我们将探讨如何利用决策理论在这些方法之间进行选择。通常，后验均值或中位数是实值量最合适的选择，而后验边缘向量是离散量的最佳选择。然而，后验众数，即 MAP 估计，是最流行的选择，因为它归结为一个优化问题，对于此类问题通常存在高效的算法。此外，MAP 估计可以用非贝叶斯术语来解释，即通过使用决策理论，我们将在第 5.7 节中讨论。基本思想是指定一个损失函数，其中 `L(θ, ˆθ)` 是假设真值为 `θ` 而你的估计为 `ˆθ` 时所造成的损失。如果我们使用 0-1 损失 `L(θ, ˆθ) = I(θ ≠ ˆθ)`（见 1.2.2.1 节），那么最优估计就是后验众数。0-1 损失意味着只有在你不犯任何错误时才能得分，否则一分不得：在这种损失函数下没有部分得分！对于连续值量，我们通常更倾向于使用平方误差损失，`L(θ, ˆθ) = (θ − ˆθ)²`；正如我们在第 5.7 节所示，相应的最优估计量是后验均值。或者我们可以使用更稳健的损失函数，`L(θ, ˆθ) = |θ − ˆθ|`，这将得到后验中位数。
