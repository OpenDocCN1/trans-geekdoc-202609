
# 反向传播神经网络概述

反向传播神经网络（以及许多其他类型的网络）在某种意义上是终极的‘黑箱’。除了定义网络的总体架构并可能用随机数对其进行初始种子化外，用户除了输入数据、观察其训练并等待输出外别无他事。事实上，有人说过关于反向传播，“你几乎不知道自己在做什么”。一些自由可用的软件包（`NevProp`、`bp`、`Mactivation`）确实允许用户在定期时间间隔内采样网络的‘进展’，但学习本身自行进行。这种活动的最终产品是一个训练好的网络，它除了其自身的内部数学之外，不提供定义关系的方程或系数（如回归）。网络‘就是’关系的最终方程。

反向传播网络也倾向于比其他类型的网络训练得更慢，有时需要数千个 `epoch`。如果在真正并行的计算机系统上运行，这个问题并不是真正的问题，但如果 BPNN 是在标准串行机器（即单台 SPARC、Mac 或 PC）上模拟的，训练可能需要一些时间。这是因为机器的 CPU 必须分别计算每个节点和连接的函数，这在具有大量数据的非常大的网络中可能存在问题。然而，大多数当前机器的速度足以使这通常不是什么大问题。

# 神经网络在医学诊断中的应用

疾病的诊断是一个广泛而具有挑战性的领域。其任务是检测具有症状的患者所患的疾病。这一过程非常复杂，因为并非所有疾病的症状都特异于单一疾病，而且症状往往会重叠。在此过程中由人为因素造成的错误并不罕见。为了消除人为错误，现代医学如今使用了不同的技术。其中一些是临床决策支持系统。这些是交互式计算机程序，可在诊断患者疾病时协助医生。通过使用关于患者状况的信息在数学模型中，可以确定可能的诊断。这些数学模型基于统计分布、回归模型和人工智能。人工智能的一部分——人工神经网络，以其逼近任意非线性变换的能力，是逼近和分类问题的良好工具。

## 使用神经网络进行医学诊断

人工神经网络（ANNs）在统计分类方法上具有明显的优势。ANNs 在传统分类方法因数据嘈杂或不完整而失效的情况下适用。神经网络在具有高度相关性的多变量分类问题中也受益。疾病的诊断是此类复杂分类问题的良好例子。通过在此领域正确应用人工神经网络，以便获得症状与适当诊断之间的相互依赖性，可以对这种依赖性进行概括。

基于此概括模型，我们随后可以对代表各种疾病症状的输入模式进行分类。然而在应用过程中，并不需要指定算法，或以其他方式识别疾病。应用只需要输入模式。整个疾病诊断过程可以分为训练和诊断两部分。一般来说，训练过程始于为分类问题相关的目标疾病的选择。在适当选择疾病后，需要确定具体参数、症状和实验室结果，这些参数和结果详细描述了该疾病的特征。

神经网络使用此数据库进行训练，随后在此过程中获得的结果将被验证。如果训练好的神经网络的结果是正确的，则神经模型可以在医学实践中使用。由此诊断过程开始。患者的数据由神经网络处理，从而确定可能的诊断。然后该结果由主管医生验证。最终诊断是医生的决定结果，他基于自己的经验，评估疾病的所有方面以及神经网络分类的结果。

## 数据库的创建

在为神经网络训练创建数据库的过程中，需要该数据能够正确描述患者的临床状况。代表患者诊断的无用或不准确信息的资料不应使用。合适特征数据的选择过程是医生的任务。最常见的是这些数据是关于患者健康状况的基本信息、生化分析结果、症状以及有助于确定正确诊断的其他信息。收集并评估的一个患者的所有这些数据代表了神经网络的一个输入模式。

在训练过程中使用的输入模式在很大程度上决定了所发现的症状与诊断之间依赖关系的泛化能力。因此，数据库应包含足够数量的可靠模式，这些模式表征了诊断。这将在神经网络的训练过程中使之能够逼近数据集中的隐藏依赖关系，并利用这一知识在患者的诊断案例中进行泛化，即使对于训练数据中不存在的案例也是如此。数据库的结构形式为包含患者健康状况及其诊断信息的表格或矩阵。

# 人工智能、神经网络和智能计算机

今天的计算机系统已大幅增长，已成为社会技术演进的一部分，生活在没有计算机的世界就像停止进步一样，因为它们是日常生活中任何活动中最重要的工具，它们帮助我们维护账户、开发新技术并将我们连接到全世界。

常规计算机能够每秒执行数百万次操作，然而，它不能自行做出决策，换句话说，计算机不能自行执行任务，它需要被编程，但单个程序仅限于执行特定任务，而多任务需要多个程序。计算机制造商为我们提供操作计算机所需的硬件，而软件开发人员提供允许我们将硬件用作工具的程序，但，如果计算机能够在不使用大量专用软件的情况下做出决策会怎样？

新技术开发者寻求实现这一任务的替代方案。50 年前在研究人类大脑时做出了惊人的发现；有可能实现基于生物神经网络相同架构及其运作的人工系统，因此他们开发了人工智能和神经网络。

人工智能不过是一套基于人类大脑行为的技术，主要在学习和决策方面。在很大程度上，生活有机体是生物系统，它们学习并基于这种学习能够做出决策，其中这些决策通常基于生存。

同样，人工智能系统需要学习和决策，但与生物系统不同，人工系统基于数学算法运行，学习是为特定目的而诱导的。在人工智能中存在许多类别，但在智能计算机的情况下，最常用的是人工神经网络和遗传算法等。

神经网络不过是对大脑神经系统的仿真，其中生物系统的每个元素都被数学等价物所取代。人工神经网络可以执行与人类大脑相似的任务，即常规计算机无法执行的任务，如图像识别、语音识别和决策，与编程系统相比，该系统的缺点是它需要训练，换句话说，未经训练的神经网络就像一个刚来到世界的新生儿，因此科学家开发了各种神经网络模型，每个模型具有不同的能力和不同的算法。

今天人工智能和神经网络的使用正被应用于软件中，模仿神经网络的并行特性到线性系统中。最常见的应用是语音识别、字符识别（OCR）、图像重建等，但也正在硬件中实现，其中处理器的线性结构被改变为神经结构，这利用了神经网络的并行特性。这种新技术被称为神经处理器。

目前神经处理器正被用于特定应用，例如机器人，在那里目前很容易实现，但最近人们一直在开发使用微处理器和神经处理器的混合系统，这些系统通常用于服务器。

有人可能会认为人工智能技术将帮助社会实现更好的生活水平，但我们也必须牢记，将我们的生物能力继承给机器会使我们更加依赖它们，而这种依赖只会抑制我们的智力能力。为了避免这种情况，我们必须把这些机器看作它们本来的样子：改善生活的工具。

# 将新神经元整合到神经网络中

过去，神经研究领域一直坚信人们在年老时无法生长出新的神经元。但 1998 年的一项惊人发现改变了一切。现在人们普遍认为，人们在衰老时仍可以生长新的神经元。现在研究的重点主要放在这些新神经元如何优雅地整合到现有的神经网络中而不引起任何潜在问题。研究在胚胎啮齿动物和猴子身上进行表明，神经递质 GABA，通常抑制神经元放电，可能反而会刺激新神经元放电。

为这一结论感到惊讶，约翰霍普金斯大学的一个团队专注于海马体的一部分，齿状回。他们将一种使分裂神经元发出绿色荧光的逆转录病毒注入小鼠。之后他们可以测量这些细胞对不同神经递质的反应性。

最初，神经元对扩散到细胞间空间的 GABA 敏感。一周后，新细胞与已建立的神经元相连，后者以脉冲方式传递 GABA。再过一周，细胞形成了接收谷氨酸的连接，这是成年神经元中主要的兴奋性神经递质。结果表明，尽管胚胎和成体之间存在差异，“新形成的神经元必须遵循这一序列”，法国地中海神经生物学研究所所长、与约翰霍普金斯工作无关的 Yehezkel Ben-Ari 说道。

显然，年轻细胞内部氯离子过量负责了 GABA 对其的兴奋。科学家们改造的 GABA 缺乏神经元显示出连接发育延迟两周并最终死亡。约翰霍普金斯神经科学家 Hongjun Song 说，该团队希望测试在正确的时间和剂量下将 GABA 应用于干细胞是否可以帮助修复中枢神经系统损伤。

# 使用神经网络的虹膜识别

在世界各地，人类验证的方式各不相同，因为对所有组织和不同中心来说都很重要。如今，最重要的人类验证方式是通过 DNA、面部、指纹、签名、语音和虹膜识别。

其中，最近、可靠且技术化的方法之一是虹膜识别，目前一些组织正在实践这种方法，其在未来的广泛使用毋庸置疑。虹膜是由彩色肌肉组成的非同一性器官，包括带有形状线条的机器人。这些线条是使每个人的虹膜不相同的根本原因。甚至一个人的一对眼睛的虹膜也完全不同。即使在同卵双胞胎的情况下，虹膜也是完全不同的。每个虹膜都由非常狭窄的线条、梳状物和血管在不同的人中特化而成。通过使用更多细节来增加虹膜识别的精度。已经证明，虹膜模式几乎从孩子一岁时起就不会改变，一直到他的一生。

在过去的几年里，由于其对数据的分类能力，基于神经网络的模式识别系统的发展受到了相当大的关注。研究人员实践的神经网络类型是 `Learning Vector Quantization`，这是一种在模式分类领域功能良好的竞争网络。虹膜图像作为数据库准备的形式为 `PNG`（便携式网络图形）模式，同时它们必须经过预处理，通过这种方式识别虹膜的边界并提取其特征。为此，使用 `canny` 方法进行边缘检测。为了更具多样性和虹膜图像的特征提取，实践了 `DCT` 变换。

## 特征提取

为了提高我们虹膜验证系统的精度，我们应该提取特征，以便它们包含用于比较和识别的图像的主要项目。提取的特征应该以一种方式存在，使系统输出的错误最小化，在理想情况下，系统的输出错误应为零。应该提取的有用特征是通过第一步中的边缘检测获得的，然后在下一步中使用 `DCT` 变换。

## 边缘检测

第一步定位虹膜的外边界，即虹膜与巩膜之间的边界。这是通过对灰度虹膜图像执行边缘检测来完成的。在这项工作中，虹膜的边缘是使用 "`Canny method`" 检测的，该方法通过寻找梯度的局部最大值来寻找边缘。梯度是使用高斯滤波器的导数计算的。该方法使用两个阈值来检测强边缘和弱边缘，并且仅在弱边缘与强边缘相连时才将其包含在输出中。该方法对加性噪声具有鲁棒性，能够检测“真实”的弱边缘。

尽管某些文献考虑了理想阶跃边缘的检测，但从自然图像中获得的边缘通常根本不是理想的阶跃边缘。相反，它们通常受到以下一种或多种效应的影响：由有限景深和有限点扩散函数引起的焦点模糊、由非零半径光源产生的阴影引起的半影模糊、平滑物体边缘处的阴影，以及物体边缘附近的局部镜面反射或互反射。

### Canny 方法

`Canny` 边缘检测算法被许多人认为是最佳边缘检测器。`Canny` 的意图是在他开始工作时增强当时已有的许多边缘检测器。他在实现目标方面非常成功，他的思想和方法可以在他的论文“边缘检测的计算方法”中找到。在他的论文中，他遵循了一系列标准来改进当前的边缘检测方法。第一个也是最明显的是低错误率。图像中存在的边缘不应被遗漏，并且不应对非边缘产生响应。第二个标准是边缘点应很好地定位。换句话说，检测器找到的边缘像素与实际边缘之间的距离应最小。第三个标准是对单一边缘只有一次响应。这是因为前两个标准不足以完全消除对边缘的多次响应的可能性。

Canny 算子以多阶段过程工作。首先，图像通过高斯卷积进行平滑。然后将简单的二维一阶导数算子（有点像 Roberts Cross）应用于平滑后的图像，以突出图像中具有重要空间导数的区域。边缘会在梯度幅值图像中产生脊。算法然后沿着这些脊的顶部跟踪，并将所有不是真正位于脊顶部的像素设为零，以便在输出中得到细线，这一过程称为非极大值抑制。跟踪过程表现出由两个阈值控制的滞后：`T1` 和 `T2`，其中 `T1` > `T2`。跟踪只能从高于 `T1` 的脊点开始。跟踪然后从该点向两个方向继续，直到脊的高度低于 `T2`。这种滞后有助于确保噪声边缘不会被分解成多个边缘片段。
