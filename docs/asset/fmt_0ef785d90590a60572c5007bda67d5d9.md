
Given a set of observations $\mathbf{x}[n] \in \mathbb{R}^l, n = 1, 2, \dots, N$ of a random vector $\mathbf{x}$, assumed to have zero mean (otherwise subtract the mean/sample mean), PCA determines a **subspace** of dimensionality $m \le l$ such that the statistical variation of the data is optimally preserved upon projection onto this subspace. This subspace is defined by **$m$ mutually orthogonal axes**, called **principal axes** or **principal directions**, computed to maximize the variance of the data projected onto the subspace [95].

We will derive the principal axes step by step. First, assume $m = 1$; the goal is to find a direction in $\mathbb{R}^l$ that maximizes the variance of the corresponding projections of the data points. Let $\mathbf{u}_1$ denote the principal axis. Under the assumption that the data is centered, the variance of the projection is given by:

## 主成分分析推导

$J(\mathbf{u}_1) = \frac{1}{N}\sum_{n=1}^{N}(\mathbf{u}_1^T\mathbf{x}_n)^2 = \frac{1}{N}\sum_{n=1}^{N}(\mathbf{u}_1^T\mathbf{x}_n)(\mathbf{x}_n^T\mathbf{u}_1) = \mathbf{u}_1^T\widehat{\Sigma}\mathbf{u}_1$

![Equation](img/si14.png)

其中

$\widehat{\Sigma} := \frac{1}{N}\sum_{n=1}^{N}\mathbf{x}_n\mathbf{x}_n^T$

![Equation](img/si15.png) (20.1)

是数据的样本协方差矩阵。对于较大的 $N$ 值或如果统计量可计算，可以使用协方差矩阵（而非样本协方差矩阵）。现在的任务变为最大化方差。然而，因为我们只关心方向，主轴将由相应的单位范数向量表示。因此，优化任务表述为

![](img/fx001.jpg)

这是一个约束优化问题，对应的拉格朗日函数为

$L(\mathbf{u}, \lambda) = \mathbf{u}^T\widehat{\Sigma}\mathbf{u} - \lambda(\mathbf{u}^T\mathbf{u} - 1)$

![Equation](img/si16.png) (20.4)

求梯度并令其等于零，得到

$\widehat{\Sigma}\mathbf{u} = \lambda\mathbf{u}$

![Equation](img/si17.png) (20.5)

换句话说，主方向是样本协方差矩阵的特征向量。将公式 (20.5) 代入公式 (20.2) 并考虑 (20.3)，可得

$\mathbf{u}^T\widehat{\Sigma}\mathbf{u} = \lambda$

![Equation](img/si18.png) (20.6)

因此，如果 $\mathbf{u}_1$ 是对应于最大特征值 $\lambda_1$ 的特征向量，则方差最大化。回想一下，由于（样本）协方差矩阵是对称且半正定的，所有特征值均为实数且非负。假设 $\widehat{\Sigma}$ 可逆（因此必然有 $N > l$），则所有特征值均为正，即 $\lambda_1 > \lambda_2 > \dots > \lambda_l > 0$，我们也假设它们互不相同，以简化讨论。

第二主成分的选择需满足：（a）与 $\mathbf{u}_1$ 正交；（b）在将数据投影到该方向后使方差最大化。遵循类似的前序论证，带有额外约束 $\mathbf{u}^T\mathbf{u}_1 = 0$ 的类似优化任务随之产生。可以很容易地证明（问题 20.1），第二主轴是对应于第二大特征值 $\lambda_2$ 的特征向量。该过程持续进行，直到获得 $m$ 个主轴；它们是对应于 $m$ 个最大特征值的特征向量。

### PCA、SVD 与低秩矩阵分解

矩阵的 SVD 分解已在 6.4 节 中讨论。给定矩阵 $X \in \mathbb{R}^{l \times N}$，我们可以写为：

$X = U D V^T$。

对于秩为 $r$ 的矩阵 $X$：$U$ 是 $l \times r$ 矩阵，其列为 $X X^T$ 对应于 $r$ 个非零特征值的特征向量；$V$ 是 $N \times r$ 矩阵，其列为 $X^T X$ 相应的特征向量；$D$ 是一个 $r \times r$ 的方形对角矩阵，包含奇异值^154。

#### 最小误差解释

在建立了 PCA 与 SVD 之间的桥梁之后，PCA 方法的另一种解释便变得显而易见。因为 $\widehat{\mathbf{X}}$ 是 $\mathbf{X}$ 在弗罗贝尼乌斯意义下的最佳 $m$ 秩矩阵近似，所以该量

$||\widehat{X} - X||_{F}^{2} := \sum\limits_{i}\sum\limits_{j}|\widehat{X}(i,j) - X(i,j)|^{2} = \sum\limits_{n = 1}^{N}||\widehat{\mathbf{x}}_{n} - \mathbf{x}_{n}||^{2}$

![Equation](img/si55.png)

取得最小值；也就是说，通过选择投影到另一个 $m$ 维子空间来获得 $\mathbf{x}[n]$ 的任何其他 $m$ 维近似（设为 $\widetilde{\mathbf{x}}_{n}$），与 PCA 产生的结果相比，都会导致更高的平方误差范数近似。这也是一个强有力的结果，确立了 PCA 方法作为一种降维技术的显著优点。这种解释可以追溯到 Pearson [146]。

#### PCA 与信息检索

前述的最小误差解释为在大型数据库中识别相似模式，铺平了围绕 PCA 构建高效搜索过程的道路。假设有 `N` 个原型用 `l` 个特征来表示，从而产生特征向量 `x[n] ∈ ℝ^l, n = 1, 2, …, N`，并存储在数据库中。给定一个由特征向量 `x` 表示的未知物体，任务是识别该模式与哪一个原型最为相似。相似度通过欧氏距离 `||x − x[n]||²` 来度量。如果 `N` 和 `l` 很大，搜索最小欧氏距离在计算上可能非常昂贵。其思路是将描述 `N` 个原型在 `span{u[1], …, u[m]}` 上投影的分量 `z[n]^(m) := [z[n1], …, z[nm]]^T`（见公式 (20.12)）保留在数据库中，而不是原来的 `l` 维特征向量。假设 `m` 足够大，能够捕捉原始数据的大部分变异性（即数据的内在维数在很好的近似下为 `m`），那么 `z[n]^(m)` 就是一个良好的特征向量描述，因为我们知道在这种情况下 `x̂_n ≈ x_n`。现在给定一个未知模式 `x`，我们首先将其投影到 `span{u[1], …, u[m]}` 上，得到

```
x̂ = ∑_{i=1}^m (u_i^T x) u_i := ∑_{i=1}^m z_i u_i.
``` (20.13)

于是我们有

$||\mathbf{x}_{n} - \mathbf{x}||^{2} \approx ||\widehat{\mathbf{x}}_{n} - \widehat{\mathbf{x}}||^{2} = \left\| \sum\limits_{i = 1}^{m}z_{ni}\mathbf{u}_{i} - \sum\limits_{i = 1}^{m}z_{i}\mathbf{u}_{i} \right\|^{2} = ||\mathbf{z}_{n}^{(m)} - \mathbf{z}||^{2}$

![Equation](img/si64.png)

其中 $\mathbf{z} := [z_{1}, \dots, z_{m}]^{T}$

![Equation](img/si65.png)。换句话说，欧氏距离是在低维子空间中计算的，这带来了显著的计算增益（例如，参见 [22,63,160] 及其参考文献）。此方法也称为*潜在语义索引*。

随机分量 $z_i$，$i = 1, 2, \dots, m$ 被称为*主成分*。有时，它们的观测值 $z_i$ 被称为*主成分得分*。事实上，主成分即构成了我们在本节开头提到的*潜在*变量。
