
### 选项 A 错误
在不考虑依赖关系的情况下立即升级可能会导致中断。

### 选项 B 错误
虽然备份服务器是一个良好的做法，但识别依赖关系应该放在优先。

告知用户是关重要的，但理解影响是首位的。

## 问题 327
一名员工注意到，在使用 RFID 卡进入办公大楼时，一个陌生人带着一个设备离她非常近。几天后，她同事的卡突然停止工作，尽管该卡没有被报告或损坏。安全团队应该怀疑哪种类型的攻击？

### 解析 327
**正确答案：B. RFID 克隆。** RFID 克隆是通过捕获其信号来制作 RFID 卡或标签的未经授权复制。那个带着设备离得近的陌生人可能一直在捕获 RFID 信号以进行克隆。

## 问题 329
用户报告说，每当他们尝试访问在线银行网站时，都会被重定向到一个看起来完全相同但 URL 略有不同的网站。假网站要求提供银行从未请求过的额外个人详情。用户可能遇到的是哪种 DNS 攻击？

- (A) DNS 隧道（DNS Tunneling）
- (B) DNS 快速变化（DNS Fast Flux）
- (C) DNS 缓存毒（DNS Cache Poisoning）
- (D) 域名劫持（Domain Hijacking）

### 解析 329
正确答案：C。DNS 缓存毒。DNS 缓存毒（也称为 DNS 欺骗）涉及破坏 DNS 解析器中的 DNS 缓存数据，将用户重定向到恶意网站而不是实际的预期网站。

选项 A 错误。DNS 隧道是一种将非 DNS 流量封装在 DNS 协议中的技术。它是绕过网络安全的方法，但通常不会导致所描述的重定向场景。

选项 B 错误。DNS 快速变化涉及快速更改与域名关联的 IP 地址，以隐藏其背后的恶意服务器。它用于防止恶意域名被封禁，但不会导致重定向到类似的站点。

选项 D 错误。域名劫持涉及在未经所有者许可的情况下通过更改其注册数据来获得对域名的控制。虽然这可能导致类似的结果，但场景描述的是只有用户被重定向的情况，而不是域的所有访问者。

## 问题 330
一个 IT 安全团队收到报告，称一种新的、此前未知的漏洞正在野外被积极利用。软件供应商尚未为该漏洞提供补丁。对于这种漏洞最准确的术语是什么？

- (A) 遗留漏洞（Legacy vulnerability）
- (B) 零日漏洞（Zero-day vulnerability）
- (C) 已修补漏洞（Patched vulnerability）
- (D) 已知漏洞（Known vulnerability）

### 解析 330
正确答案：B。零日漏洞。零日漏洞是指软件、硬件或固件中供应商未知的缺陷。这种漏洞之所以是一种风险，是因为在发现时没有修复程序或补丁，而且它可能已经被恶意攻击者积极利用。

**选项 A 错误。** 遗留漏洞通常指旧软件或系统中的漏洞，这些系统可能不再受到支持，而不一定是未知且未修补的缺陷。

**选项 C 错误。** 已修补漏洞意味着该缺陷已经有了修复方法。在提供的场景中，尚未发布补丁。

**选项 D 错误。** 虽然该漏洞对某些实体可能是知的（例如场景中的安全团队），但对于软件供应商来说仍然是知的。因此，在这种语境下，“已知漏洞”不是最准确的描述。

## 问题 331
一个在线支付网关正在评估增强其支付处理系统安全的方法。他们希望有一种解决方案，将敏感的持卡人数据替换为本身没有内在价值的唯一标识符。他们应该实施哪种方法？

- (A) 对卡数据进行哈希（Hashing）
- (B) 对卡数据进行加密（Encryption）
- (C) 对卡数据进行掩码（Masking）
- (D) 对卡数据进行令牌化（Tokenizing）

### 解析 331
正确答案：D。对卡数据进行令牌化。令牌化涉及将敏感数据替换为非敏感等等物（令牌），令牌没有外部或可利用的意义或价值。

**选项 A 错误。** 哈希会产生一个固定大小的字符串，它无法还原为原始值，但它并没有创建一个可以换回原始数据的“令牌”。

**选项 B 错误。** 加密将数据转换为另一种形式或代码，以便只有访问秘密密钥或密码的人才能读取它。它没有将数据替换为没有内在价值的唯一标识符。

**选项 C 错误。** 掩码涉及隐藏部分数据，例如显示信用卡卡的最后四位。它没有将数据替换为唯一标识符。

故障排除

## 问题 334
一个在线银行网站使用了一种系统，在用户无活动 10 分钟后自动注销用户，以确保如果用户忘记注销，其他人无法更改其银行详情。该银行网站最直接针对 CIA 三要素（CIA triad）中的哪种原则？

(A) 机密性 (Confidentiality)
(B) 可用性 (Availability)
(C) 身份认证 (Authentication)
(D) 完整性 (Integrity)

### 解释 334
正确答案：D. 完整性。CIA 三要素中的完整性维度确保数据的准确性和可靠性。通过在无活动一段时间后注销用户，银行网站旨在防止用户银行详情被未经授权的修改（可能由获取了无人会话的他人进行），从而维护数据的完整性。

**选项 A 错误。** 虽然注销用户确实具有机密性方面，但此场景中的主要目标是防止未经授权的更改，而不是未经授权的查看。

**选项 B 错误。** 可用性确保授权用户在需要时访问数据和系统。此场景没有讨论根据系统运行时间或可访问性提供或限制访问。

**选项 C 错误。** 身份认证确保用户是他们声称的身份。虽然该场景涉及安全措施，但这里的主要关注是防止对数据的未经授权更改，这与完整性相符，而不是身份认证。

## 问题 335
用户 Amy 想安全地向同事 Bob 发送一份机密文件。Amy 决定加密文件以确保其机密性。Amy 应该使用以下哪项来加密文件，以确保只有 Bob 可以解密？

(A) Amy 的私钥
- (B) Amy 的公钥
- (C) Bob 的私钥
- (D) Bob 的公钥

### 解释 335
正确答案：D. Bob 的公钥。在非对称加密中，如果使用个人的公钥加密消息，则只有对应的私钥可以解密。因此，为了确保 Bob 是唯一可以解密文件的人，Amy 应该使用 Bob 的公钥进行加密。

**选项 A 错误。** 使用 Amy 的私钥加密将允许任何拥有 Amy 公钥的人解密，而且它作为数字签名而不是确保机密性。

**选项 B 错误。** 使用 Amy 的公钥没有意义，因为那样只有 Amy 的私钥可以解密。

**选项 C 错误。** 私钥绝不应共享或用于加密。它的主要用途是解密和签名。

## 问题 336
一家科技初创公司正在开发移动应用程序，由于许可协议，该程序仅向特定国家内的用户提供独家内容。初创公司应该使用哪种方法来确保只有该国家的用户可以访问内容？

- (A) 集成基于时间的一次性密码 (TOTP) 系统
- (B) 使用基于地理位置的访问控制

**选项 A 错误。** TOTP 系统提供基于时间的第二因素身份认证，而不是基于地理位置。

**选项 C 错误。** 生物识别认证根据物理或行为特征验证用户身份，但不根据地理位置限制访问。

## 问题 337
一个组织的 IT 部门注意到过去 24 小时内网络流量激增。同时，许多员工报告他们的系统运行缓慢，并且他们从同事的邮件收到了一个名为“updatePatch.exe”的文件，尽管同事并没有刻意发送过任何文件。哪种恶意软件最可能是这种行为 true？

## 问题 338
一家软件开发公司维护着一个共享代码库。该公司希望确保只有开发人员可以对代码进行更改，但测试人员应该查看代码而不修改它。应该实施哪种方法？

- (A) 为所有员工分配只读权限
- (B) 为测试人员提供管理员权限
- (C) 实现基于角色的访问控制 (RBAC)
- (D) 对仓库使用数据加密

### 解释 338
正确答案：C. 实现基于角色的访问控制 (RBAC)。RBAC 根据组织内的角色分配权限。可以给开发者分配允许修改代码的角色，而给测试人员分配仅允许读取代码的角色。

**选项 A 错误。** 为所有员工分配只读权限将阻止开发者对代码进行必要的更改。

**选项 B 错误。** 为测试人员提供管理员权限将赋予他们额外的权限，可能允许他们修改代码。

**选项 D 错误。** 虽然数据加密确保了数据的机密性，但它没有解决不同用户角色特定权限的需求。

## 问题 339
一个组织最近部署了一个云数据库来支持其新应用程序。几周后，检测到数据库有未经授权的访问。调查发现，数据库在没有密码的情况下即可访问。以下哪种配置错误是导致安全漏洞的主要原因？

- (A) 默认配置未更改

**选项 B 错误。** 虽然网络分段对于安全至关重要，但此场景中的主要问题是数据库缺乏密码保护，而不是其网络位置。

在一次例行安全审查期间，一名安全分析师发现安全机房的电子门禁系统出现多次登录失败尝试，且都发生在短时间内。访问日志显示访问代码是按顺序进行尝试的。这可能是在尝试哪种类型的物理攻击？

- (D) 社会工程学 (Social engineering)

### 解释 340
**正确答案：C. 暴力破解。** 暴力破解攻击涉及尝试所有可能的组合以找到正确的组合。日志中按顺序尝试访问代码的模式表明，攻击者正在系统地遍历所有潜在的组合。

**选项 A 错误。** 尾随攻击涉及攻击者在没有相应凭据的情况下，跟随授权的人员进入安全区域。它不涉及多次电子访问代码的尝试。

**选项 B 错误。** 网络钓鱼是一种社会工程学攻击，通常涉及欺骗某人泄露凭据或其他敏感信息。它不涉及直接的物理访问尝试。

**选项 D 错误。** 虽然社会工程学确实涉及操纵个人以获得未经授权的访问，但它特指针对电子系统的暴力破解攻击。

## 第 341 题
一家跨国电子商务公司正在扩大其基础设施以处理日益增长的流量。主要目标是将传入的 Web 流量分布到多个服务器上，以确保没有哪个服务器被过载。该公司应该使用哪种方法？

- (A) 部署 Web 应用防火墙
- (B) 实现服务器集群
- (C) 使用硬件级防火墙
- (D) 设置负载均衡器

### 解释 341
**正确答案：D. 设置负载均衡器。** 负载均衡器将传入的流量分布到多个服务器上，确保没有单个服务器过载，从而增强应用程序的可用性和容错能力。

**选项 A 错误。** 虽然 Web 应用防火墙可以防止 Web 威胁，但它不会将传入的流量分布到服务器上。

**选项 B 错误。** 服务器集群主要关注提供冗余和故障转移能力，而不是分配传入流量。

**选项 C 错误。** 硬件级防火墙主要用于过滤流量并保护网络免受外部威胁，而不是分配传入的 Web 流量。
