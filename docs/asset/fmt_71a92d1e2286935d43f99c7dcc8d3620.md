
## 不同的特征融合方法

### 从最后卷积层提取特征并处理类别不平衡后，两个 CNN 模型的水平特征融合

在这种方法中，特征从 CNN 模型中提取后，会在两个 CNN 模型的组合中进行水平融合。由于不同 CNN 模型提取的特征维度不同，无法进行垂直融合（图 7.1）。

![FIGURE 7.1 Horizonal feature fusion of SMOTE-treated data for two CNN applications.](img/fig7.1.jpg)

**FIGURE 7.1** Horizonal feature fusion of SMOTE-treated data for two CNN applications.

Python 实现代码如下：

```python
import tensorflow as tf

def getData(model1, model2, image_size):
    train_data_dir = "../class_imbalance/" + layer + "/" + str(image_size) + "/"
    test_data_dir = "../feature_extractor/" + layer + "/" + str(image_size) + "/"
    X_train1 = np.load(train_data_dir + model1 + "_X_train_SMOTE.npy")
    X_train2 = np.load(train_data_dir + model2 + "_X_train_SMOTE.npy")
    X_train = tf.keras.layers.concatenate([X_train1, X_train2], axis=1)
    y_train = np.load(train_data_dir + model1 + "_y_train_SMOTE.npy")
    X_test1 = np.load(test_data_dir + model1 + "_test_images.npy")
    X_test2 = np.load(test_data_dir + model2 + "_test_images.npy")
    X_test = tf.keras.layers.concatenate([X_test1, X_test2], axis=1)
    y_test = np.load(test_data_dir + "test_labels.npy")
    return X_train, y_train, X_test, y_test
```

### 水平拼接特征：从最后卷积层提取的特征与处理类失衡后，结合三个 CNN 模型

在此方法中，在从 CNN 模型中提取特征后，它们会在三个 CNN 模型的组合中水平拼接（图 7.2）。

![FIGURE 7.2 水平特征拼接 SMOTE 处理后的数据，用于三个 CNN 应用。](img/fig7.2.jpg)

**FIGURE 7.2** 水平特征拼接 SMOTE 处理后的数据，用于三个 CNN 应用。

### 水平拼接 PCA 特征：从最后卷积层提取的特征与类失衡处理，结合两个 CNN 模型

拼接 PCA 特征后，所有模型的数据维度相同，因为 PCA 处理后，来自不同模型的特征数组维度相同（图 7.3）。

![FIGURE 7.3 水平特征拼接 PCA 处理后的数据，用于两个 CNN 应用。](img/fig7.3.jpg)

**FIGURE 7.3** 水平特征拼接 PCA 处理后的数据，用于两个 CNN 应用。

例如，从 `Xception` 或 `VGG16` 模型提取特征；PCA 处理后，两者的数据维度相同。若将维度减小到 50，则两个数组现在都有 50 列。

因此，将它们水平拼接后，所有模型的数据维度相同。此外，由于水平拼接，记录数保持不变（此例为 6000），但列数会根据拼接的模型数量增加，这里为 2。

Python 实现代码：

```python
import tensorflow as tf

def getData(model1, model2, image_size, n_component):
    X_data_dir = "../pca/" + layer + "/" + str(image_size) + "/"
    y_train_data_dir = "../class_imbalance/" + layer + "/" + str(image_size) + "/"
    y_test_data_dir = "../feature_extractor/" + layer + "/" + str(image_size) + "/"
    X_train1 = np.load(X_data_dir + model1 + "_train_" + str(n_component) + ".npy")
    X_train2 = np.load(X_data_dir + model2 + "_train_" + str(n_component) + ".npy")
    X_train = tf.keras.layers.concatenate([X_train1, X_train2], axis=1)
    y_train = np.load(y_train_data_dir + model1 + "_y_train_SMOTE.npy")
    X_test1 = np.load(X_data_dir + model1 + "_test_" + str(n_component) + ".npy")
    X_test2 = np.load(X_data_dir + model2 + "_test_" + str(n_component) + ".npy")
    X_test = tf.keras.layers.concatenate([X_test1, X_test2], axis=1)
    y_test = np.load(y_test_data_dir + "test_labels.npy")
    return X_train, y_train, X_test, y_test
```

### 垂直拼接 PCA 特征：从最后卷积层提取的特征与类失衡处理，结合两个 CNN 模型

本节讨论在两个 CNN 模型的组合中，对 PCA 特征进行垂直拼接。与 PCA 特征拼接的说明相同，将它们相互垂直拼接后，所有模型的数据维度相同（图 7.5）。

![FIGURE 7.5 垂直特征拼接 PCA 处理后的数据，用于两个 CNN 应用。](img/fig7.5.jpg)
