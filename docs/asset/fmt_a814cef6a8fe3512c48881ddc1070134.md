
# PHP 的 `Intl` 扩展：日期、时间、货币与数字格式化

PHP 的 `Intl` 扩展为日期和时间格式化提供了强大的工具。您可以使用 `IntlDateFormatter` 类创建感知不同区域设置和文化偏好的日期和时间格式化器。

## 使用 `IntlDateFormatter` 格式化日期和时间

以下是使用 `IntlDateFormatter` 格式化日期和时间的示例：

```php
// Create a date formatter for the 'en_US' (U.S. English) locale
$locale = 'en_US';
$dateStyle = IntlDateFormatter::MEDIUM;
$timeStyle = IntlDateFormatter::MEDIUM;
$formatter = new IntlDateFormatter($locale, $dateStyle, $timeStyle);

// Format the current date and time
$timestamp = time();
$formattedDateTime = $formatter->format($timestamp);
```

在本示例中，我们为 `en_US` 区域设置创建了一个具有中等日期和时间样式的日期格式化器。然后，我们使用 `format()` 方法格式化当前日期和时间。

## 自定义日期和时间格式

您可以通过指定模式进一步自定义日期和时间格式。例如，您可以定义像 `dd-MM-yyyy` 这样的自定义日期模式，将日期显示为 `05-01-2023`。您还可以创建自定义时间模式来控制时间的外观。

```php
// Create a custom date formatter pattern
$locale = 'fr_FR';
$datePattern = 'dd-MM-yyyy';
$formatter = new IntlDateFormatter($locale, IntlDateFormatter::NONE, IntlDateFormatter::NONE, null, null, $datePattern);

// Format a specific date
$date = new DateTime('2023-01-05');
$formattedDate = $formatter->format($date);
```

在本示例中，我们为 `fr_FR`（法语）区域设置创建了一个具有 `dd-MM-yyyy` 模式的自定义日期格式化器。

## 本地化时区

显示日期和时间信息时，必须考虑时区。不同地区的用户可能希望看到调整到其本地时区的时间。您可以使用 `IntlTimeZone` 类处理时区转换。

```php
// Create a time zone formatter for 'America/New_York'
$timeZoneId = 'America/New_York';
$timeZone = IntlTimeZone::createTimeZone($timeZoneId);

// Set the time zone for the date formatter
$formatter->setTimeZone($timeZone);

// Format a date and time in the specified time zone
$formattedDateTime = $formatter->format($timestamp);
```

在本示例中，我们为 `America/New_York` 创建了一个时区格式化器，并将其设置为日期格式化器，以在东部时间区显示日期和时间信息。

## 日期和时间本地化的最佳实践

为了有效地本地化日期和时间格式，请考虑以下最佳实践：

1.  **用户偏好**：尽可能允许用户指定其首选的日期和时间格式及时区。
2.  **自动检测**：检测用户的浏览器设置或位置，以自动选择合适的区域设置和时区。
3.  **测试**：使用不同的区域设置和时区彻底测试日期和时间格式化，以确保准确性。
4.  **回退机制**：在用户首选的区域设置或时区不可用时，提供回退的日期和时间格式。

遵循这些实践并利用 PHP 的 `Intl` 扩展，您可以创建能够无缝适应全球用户群日期和时间偏好的应用程序。在接下来的章节中，我们将探讨国际化和本地化的其他方面，包括货币和数字格式化、字符编码，以及全球化 PHP 8 应用程序的最佳实践。

# 第 16.3 节：货币和数字格式化

根据地区惯例格式化货币和数字对于创建用户友好的应用程序至关重要。PHP 8 提供了处理货币和数字格式化的工具，确保以文化适宜的方式呈现数值。

## 货币格式化

显示货币值时，必须考虑货币符号、小数分隔符和分组分隔符等因素。PHP 8 提供了 `NumberFormatter` 类来处理货币格式化。

以下是使用 `NumberFormatter` 格式化货币值的示例：

```php
// 为 'en_US'（美式英语）区域设置创建货币格式化器
$locale = 'en_US';
$formatter = new NumberFormatter($locale, NumberFormatter::CURRENCY);

// 格式化货币金额
$amount = 1234.56;
$formattedCurrency = $formatter->formatCurrency($amount, 'USD');
```

在本例中，我们为 ‘en_US’ 区域设置创建了一个货币格式化器，并格式化了 1234.56 美元的货币金额。生成的 `$formattedCurrency` 变量将包含格式化后的货币字符串，包括货币符号。

## 自定义货币格式化

您可以通过指定货币符号样式、货币代码和小数位数等选项来自定义货币格式化：

```php
// 使用自定义选项创建货币格式化器
$locale = 'fr_FR';
$options = [
    NumberFormatter::CURRENCY_SYMBOL => '€',  // 自定义货币符号
    NumberFormatter::CURRENCY_CODE => 'EUR',  // 货币代码
    NumberFormatter::FRACTION_DIGITS => 2,    // 小数位数
];

$formatter = new NumberFormatter($locale, NumberFormatter::CURRENCY, NumberFormatter::CURRENCY_PATTERN, null, null, $options);

// 格式化货币金额
$amount = 1234.56;
$formattedCurrency = $formatter->formatCurrency($amount, 'EUR');
```

在本例中，我们为 ‘fr_FR’（法语）区域设置创建了一个带有自定义选项的货币格式化器。结果是一个根据指定偏好格式化的货币字符串。

## 数字格式化

PHP 的 `NumberFormatter` 类功能多样，也可用于格式化非货币数字。您可以轻松地格式化整数、小数和百分比：

```php
// 为 'de_DE'（德语）区域设置创建数字格式化器
$locale = 'de_DE';
$formatter = new NumberFormatter($locale, NumberFormatter::DECIMAL);

// 格式化数字
$number = 1234.567;
$formattedNumber = $formatter->format($number);
```

在本例中，我们为 ‘de_DE’ 区域设置创建了一个数字格式化器，并格式化了一个十进制数字。结果将使用德语约定的小数点和分组分隔符。

## 货币和数字格式化的最佳实践

为确保在 PHP 8 应用程序中有效地进行货币和数字格式化，请考虑以下最佳实践：

1.  **用户偏好**：允许用户指定其首选的货币符号、小数分隔符和分组分隔符。
2.  **自动检测**：检测用户的浏览器设置或位置，以自动选择合适的区域设置和货币。
3.  **本地化**：对货币和数字使用特定于区域设置的格式化，为用户创造熟悉的体验。
4.  **测试**：使用不同的区域设置彻底测试货币和数字格式化，以确保准确性。

通过遵循这些实践并利用 PHP 的 `NumberFormatter` 类，您可以创建以符合全球用户群期望的方式呈现货币和数值的应用程序。在下一节中，我们将探讨字符编码和文本处理，这对于在 PHP 8 应用程序中处理多语言内容至关重要。

# 第 16.4 节：字符编码和文本处理

字符编码和文本处理是 PHP 8 应用程序中国际化（i18n）和本地化（l10n）的基础方面。在处理多语言内容时，处理不同的字符集、编码转换和文本操作至关重要。

## 字符编码基础

字符编码定义了字符在计算机系统中如何表示为二进制数据。在 PHP 8 中，最常用的字符编码是 UTF-8，它支持来自不同语言和脚本的广泛字符。

以下是如何为您的 PHP 脚本设置字符编码：

```php
// 将字符编码设置为 UTF-8
header('Content-Type: text/html; charset=utf-8');
```

通过将字符集设置为 UTF-8，您可以确保 PHP 脚本能够处理和显示来自各种语言的字符。

## 文本的编码和解码

PHP 提供了在不同字符编码之间对文本进行编码和解码的函数。`mb_convert_encoding` 函数是用于编码转换的多功能工具：

```php
// 将字符串从 ISO-8859-1 转换为 UTF-8
$text = "Café";
$utf8Text = mb_convert_encoding($text, 'UTF-8', 'ISO-8859-1');
```

在本例中，我们将一个字符串从 ISO-8859-1 编码转换为 UTF-8，这是处理遗留数据时的常见转换。

## 文本长度和操作

在处理多语言文本时，考虑字符串的长度很重要，因为某些字符可能占用多个字节。`mb_strlen` 函数允许您正确计算多字节字符串的长度：

```php
// 计算 UTF-8 字符串的长度
$text = "Café";
$length = mb_strlen($text, 'UTF-8');
```

在这种情况下，长度将正确计算为 4，并考虑了重音字符。

您还可以执行各种文本操作任务，例如子字符串提取和替换，同时尊重字符边界。`mb_substr` 和 `mb_str_replace` 函数有助于完成这些任务。

## 多语言文本排序

由于各种语言有不同的排序规则，对多语言文本进行排序可能具有挑战性。PHP 8 的 `Collator` 类提供了区域设置感知排序的解决方案：

```php
// 为 'fr_FR'（法语）区域设置创建排序器
$collator = new Collator('fr_FR');

// 对法语单词数组进行排序
$words = ["éclair", "chocolat", "amour", "bonjour"];
$collator->sort($words);
```

在本例中，我们为法语区域设置创建了一个排序器，并使用它对法语单词数组进行排序，遵循正确的排序顺序。

## 处理多语言输入

在处理用户输入时，特别是通过表单，请注意字符编码问题。确保在任何进一步处理或存储之前，用户输入始终转换为所需的字符编码（通常为 UTF-8）。

总之，字符编码和文本处理对于构建支持多种语言和字符集的 PHP 8 应用程序至关重要。通过理解编码、使用适当的函数并考虑字符边界，您可以创建健壮且用户友好的多语言应用程序。接下来，我们将探讨创建全球化 PHP 8 应用程序的最佳实践。

# 第 16.5 节：全球化 PHP 8 应用程序的最佳实践

构建面向国际受众的全球化 PHP 8 应用程序需要遵循国际化（i18n）和本地化（l10n）的最佳实践。这些实践确保您的软件能够有效地处理各种语言、地区和文化偏好。

### 1. 到处使用 UTF-8

在整个 PHP 8 应用程序中始终如一地使用 UTF-8 字符编码。UTF-8 是一种通用编码，支持来自不同语言和脚本的广泛字符。确保您的数据库、文件处理和文本处理都使用 UTF-8。

### 2. 将内容与代码分离

避免将文本直接硬编码到 PHP 脚本中。相反，将标签、消息和用户界面元素等内容外部化到单独的资源文件中。PHP 的 `gettext` 扩展是处理消息目录和翻译的常用选择。

### 3. 正确识别用户的区域设置

检测用户的首选区域设置、语言和区域设置。您可以使用用户浏览器发送的 `Accept-Language` 标头，或提供选项让用户选择其首选语言。PHP 中的区域设置函数可帮助您为用户交互设置正确的区域设置。

### 4. 使用语言常量

为不同的语言和地区定义常量，以确保应用程序的一致性。这些常量可以代表资源文件中的键，并使动态切换语言变得更加容易。

```php
define('LANG_EN_US', 'en_US');
define('LANG_FR_FR', 'fr_FR');
```

### 5. 采用复数规则

不同的语言有各种复数化规则。请使用 PHP 的 `MessageFormatter` 或类似工具来正确处理复数形式。这能确保您的应用程序消息在每种语言中都符合语法规范。

### 6. 使用示例数据进行测试

使用不同语言和地区的示例数据彻底测试您的应用程序。这有助于发现文本溢出、布局和内容对齐方面的问题，确保流畅的用户体验。

### 7. 维护术语表

创建并维护一份不同语言中常用术语和短语的术语表。这有助于翻译人员确保整个应用程序的一致性。翻译管理系统 (TMS) 等工具可协助完成此过程。

### 8. 为翻译人员提供上下文

在准备翻译内容时，为翻译人员提供上下文和说明。上下文信息有助于翻译人员理解文本在应用程序中的使用方式，从而做出准确的翻译。

### 9. 测试从右向左 (RTL) 语言

如果您的应用程序支持阿拉伯语或希伯来语等 RTL 语言，请确保用户界面元素能正确适配。测试文本、图像和用户界面组件的布局与对齐，以确保 RTL 用户获得无缝体验。

### 10. 定期更新翻译

随着应用程序的发展，保持翻译的最新状态。新功能、用户界面元素的变更和错误修复可能需要更新翻译。维护翻译管理流程，以确保及时更新。

### 11. 遵循 Web 无障碍标准

确保您的应用程序符合 Web 无障碍标准，例如 WCAG (Web 内容无障碍指南)。这包括为非文本内容提供文本替代方案，并确保屏幕阅读器能准确解读不同语言的内容。

遵循这些最佳实践，您可以创建面向全球受众、无障碍且用户友好的 PHP 8 应用程序。有效的国际化和本地化能增强用户粘性，并扩大您的应用程序在不同语言和文化背景下的覆盖范围。

# 第 17.1 节：使用 PHP 8 为移动应用程序创建 API

移动应用程序通常依赖后端 API 与服务器和数据库进行交互。PHP 8 是一种用于构建作为移动应用骨干的 API 的通用语言。在本节中，我们将探讨使用 PHP 8 创建 API 以满足移动开发特定需求的最佳实践和技术。

## 1. RESTful API 设计

REST (Representational State Transfer，表述性状态转移) 是一种广泛采用的 API 设计架构风格。在为移动应用构建 API 时，遵循 RESTful 原则可确保简洁性、可扩展性和易用性。为资源定义清晰的端点，适当使用 HTTP 方法 (`GET`、`POST`、`PUT`、`DELETE`)，并确保使用正确的响应代码（例如：`200` 表示成功，`404` 表示未找到，`401` 表示未授权访问）。

```php
// PHP 8 中的 RESTful API 端点示例

if ($_SERVER['REQUEST_METHOD'] === 'GET') {
    // 处理 GET 请求
} elseif ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // 处理 POST 请求
}
```

## 2. 认证与授权

实施强健的认证和授权机制以保护您的 API。移动应用通常使用令牌（如 JWT 或 OAuth）来认证用户。PHP 8 提供了用于处理基于令牌认证的库和包，确保只有授权用户才能访问特定的 API 端点。

```php
// PHP 8 中的 JWT 认证示例

if (validateJWT($_GET['token'])) {
    // 用户已认证
} else {
    // 未授权访问
    http_response_code(401);
    echo json_encode(['error' => 'Unauthorized']);
}
```

## 3. JSON 作为数据格式

移动应用通常以 JSON (JavaScript Object Notation，JavaScript 对象表示法) 格式消费和发送数据。PHP 8 对 JSON 编码和解码提供了出色的支持。使用 `json_encode()` 和 `json_decode()` 函数在服务器和移动应用之间序列化和反序列化数据。

```php
// 在 PHP 8 中将数据编码为 JSON

$data = ['name' => 'John', 'age' => 30];
$json = json_encode($data);
```

## 4. 版本控制

考虑对您的 API 进行版本控制，以管理变更并确保与现有移动应用的向后兼容性。在 API 端点中包含版本信息（例如 `/v1/resource`），并向移动应用开发者清晰地传达变更。

```php
// API 端点版本控制

$app->group('/v1', function () {
    $this->get('/resource', 'ResourceController:getResource');
});
```

## 5. 速率限制

实施速率限制以防止 API 滥用。速率限制可确保移动应用无法在特定时间范围内发出过多请求。PHP 8 中间件或库可帮助您有效实施速率限制。
