
如果我们要经常对公司资产进行扫描，我们可能会在集中式服务器上安装 Nessus 服务器软件。如果是那样的话，我们只想选择`Nessus Server`选项，并取消客户端安装功能。服务器软件本身并不消耗大量的处理能力或内存分配。消耗处理器和内存的是正在运行的活动扫描数量。对于大型组织，良好的配置是在整个网络中（包括内部和外部）运行多个 Nessus 服务器。在企业环境中拥有私有网络也并不常见，这需要在这些网络内放置额外的服务器。硬件选择应具有足够的内存和处理周期；这允许对系统进行定期扫描，以检查安全保护级别的任何变化。一旦执行实际扫描的服务器就位，我们就可以在支持系统和管理员系统中单独安装客户端。这种配置允许服务器进行所有处理，并允许管理员根据需要使用客户端远程启动扫描。扫描也可以是自动化，但实现这一方法对本文主题来说并不真正重要。许多关于 Nessus 的优秀书籍深入探讨了自动化技术，包括`Nessus Network Auditing`，`2e`，ISBN: 978-1-59749-208-9，Syngress。由于我们不是那种每天扫描数千个系统的大公司，我们可以在同一系统上同时安装服务器和客户端。该应用程序没有多少开销，而且我们并没有进行大量的扫描，所以这对我们来说是一个完美的选项。一旦安装完成，我们将获得注册程序的选项，如图 11.5 所示。

每当结果出现时我们都可以选择任何结果，但[图 11.17]显示了完成的扫描。当我们更仔细地查看扫描时，发现一个一个漏洞。在这种情况下，我们的漏洞位于端口`22`的安全外壳`SSH`服务。Nessus 探测不同的端口、协议和应用程序以获取信息，这些信息以标志和响应的形式出现。收到响应后，它提供了上面的摘要。然而，它并没有实际验证漏洞——那是渗透测试人员或系统管理员的工作。虽然安全漏洞警告看起来糟糕，但在我们确定 pWnOS 易受到端口`22`的攻击或没有某些缓解防御机制产生误报之前，我们需要进行验证。如果你还记得在本章之前的练习中，我们发现端口 10000 运行 Webmin。在图 11.18 中，我们看到 Nessus 扫描器也注意到了这一点。

根据 Nessus 的说法，`Webmin`是一个威胁，但并不是安全漏洞，因为它被标记为黄色。由于我们已经知道任何人可以使用已发布的利用程序来攻击`Webmin`并获取敏感信息（如加密后的密码和用户名），这似乎可能被误标记了。`Nessus`的一个非常棒的特性是，你可以修改插件以反映符合你公司需求的风险水平。`Nessus`用颜色对漏洞进行排序以达到视觉效果，红色表示“高风险”，绿色表示“低暴露”。在不使用自动化工具的情况下进行漏洞识别似乎是一项艰巨得多的任务！虽然我们在进行渗透测试时可能会运行`Nessus`扫描，但我们应该始终跟进行手动跟进，使用书中之前提到的相同步骤来验证结果。每项任务始终务必使用两个工具。稍后我们将看到，在我们使用`CORE IMPACT`进行扫描时，这条规则变得多么重要。在完成任何自动化扫描后进行手动扫描的另一个原因是，可能会漏掉某些通常不会漏掉的内容，例如高端口上的服务。通过进行手动扫描，我们确切知道哪些端口在何时被检查过。扫描时间是渗透测试中的一个重要因素。通常，自动扫描发生在每天的同一时间。如果我们改变扫描时间（无论是自动扫描还是手动扫描），就可以识别出不同的安全风险。黑客（Black Hats）经常试图伪装他们的活动，一种方法是在下班后保持活跃。这样，系统操作人员就不会注意到系统行为有任何异常，因为他们通常在下午 5:00 离开回家。作为渗透测试员，我们应该对同一系统进行多次随机扫描，以查看非工作时间（包括周末）是否会出现任何异常端口。在奇特时间打开端口的甚至不非是黑客。某些系统管理员使用远程访问程序，例如`Virtual Network Computing (VNC)`。如果管理员正在使用某个版本的、可被利用的`VNC`应用程序，我们可能无法通过自动的计划扫描捕捉到它的使用。

## 漏洞利用

在本次练习中，我们将关注`Nessus`扫描器识别出的安全漏洞；特别是`Debian OpenSSH/Open Secure Sockets Layer (SSL) Package 随机数生成器缺陷`。由于我们想要自动化攻击，我们将使用`CORE IMPACT`工具。我们使用这个工具而不是免费工具`Metasploit`是出于几个原因：1. `Metasploit Framework`在会议演示、提供演示示例的互联网网站以及相关书籍中被广泛讨论和使用（包括我贡献过的一本书：`Metasploit Toolkit: For Penetration Testing, Exploit Development, and Vulnerability Research`，ISBN 978-1-59749-074-0，Syngress）。2. `CORE IMPACT`是不可思议的。不，我不是`IMPACT`制造公司`Core Security Technologies`的企业托儿。我只是将其作为专业渗透测试员日常工作的一部分，并发现它是渗透测试工具箱中不可或缺的工具。由于这本书是关于专业渗透测试的，如果只谈论没有价格标签的工具将是一个巨大的疏忽。
