# 从构思到发表：学术研究中使用生成式人工智能的伦理规范

## 作者

Jaswinder Pal Singh, Neha Mishra 和 Babita Singla

Chitkara 商学院，Chitkara 大学，旁遮普普邦，印度

### 摘要

从构思到发表，学术研究中的生成式智能（`AI`）涉及许多伦理、社会和法律考量；生成式 `AI` 在学术研究中发挥着重要作用。`AI` 文档的创建、改写和增强改变了学术写作。`AI` 工具通过类人类的响应帮助研究人员开发新的数据和想法。虽然 `AI` 有许多优势，但其在学术研究中的应用也带来了伦理关注，特别是关于作者身份和知识产权的问题。与 `AI` 系统协作具有挑战性，因为它们容易出现写作错误。同样，由于法律系统中缺乏对 `AI` 所有权的认可，`AI` 生成的内容在伦理上是不确定的。本研究通过 `AI` 的透明度来鼓励伦理实践。理解 `AI` 的概念对于在学术研究中依赖和使用 `AI` 以维护诚信至关重要。然而，`AI` 的规范适用于提高教育和接受度。尽管 `AI` 可以创造技术工作，但也可以消除平庸的工作并转型教育。该研究还强调了 `AI` 生成材料的有害原则、优势和缺点。`AI` 系统的设计、部署和监控必须符合伦理，以避免偏见和误导。本研究总结了生成式 `AI` 在学术研究中的经济和社会影响。开展进一步研究以制定未来可以实施的全面 `AI` 实践至关重要。

**关键词**：生成式 `AI`；伦理实践；学术研究；构思；发表

## 1. 引言

科学界对生成人工智能（`AI`）在学术研究中的应用感到兴奋。研究人员越来越多地利用 `AI` 驱动的技术来协助他们完成学术写作过程的不同阶段。作者利用生成式 `AI` 方法创建初稿，这同时也为增强之前编写的内容提供了见解性的建议。生成式 `AI` 技术为学术人员提供了产生想法的新手段，拓宽了研究领域并刺激了生成式 `AI` 思维过程。生成式 `AI` 实践的广泛采用从根本上改变了学术写作领域。生成式 `AI` 可能改进学术研究写作，但它也引发了一些重要的伦理问题。在学术界，对于我们是否应该使用 `AI` 以及它是否应该处理教育任务存在争论，部分原因是由于目前对 `AI` 的构建和使用缺乏监管，这样做可能会引发对 `AI` 生成内容信誉的质疑。如果我们学术界认为在学术背景下某些 `AI` 的使用是有益且符合伦理的，我们该如何处理作者身份问题？调查已开始对生成式 `AI` 系统是否可以被科学研究的作者产生怀疑，尤其是因为它们无法为前述行为以及作为作者的非常重要的后果承担责任。即使在考虑什么最能被称为“作者”时，真实性也归取决于这种程度，以至于即使是 `AI` 设计的论文也可以与真实的科学话语进行比较。我们的社会对作者身份问题投入了大量审查。生成式 `AI` 系统没有法律依据来声称生成文档的所有权。这是因为法律只允许自然人类或认可的法律实体这样做。证明 `AI` 应用的认知研究对其被广泛接受至关重要，因为它是方法论的一个重要要素。根据 Bukar 等人 (2024) 的观点，现代 `AI` 系统有潜力产生看似逻辑清晰且重要的语言，但实际上是幻觉的。描述这一现象的术语是“人工欺诈”，Sison 等人 (2023)。认识 `AI` 的局限性和威胁有助于作者维护其工作的完整性。用于训练 `AI` 系统的数据集可能会强化并污染偏见。这可能会传播误导信息，鼓励不伦理的行为和坏想法——Krammer (2023)。作者私下使用生成式 `AI` 使得很难检测和优化研究参与者中的偏见。
