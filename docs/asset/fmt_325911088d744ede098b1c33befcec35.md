
# 安全外壳（SSH）协议

安全外壳（`SSH`）协议是一种加密的远程终端。

# 互联网协议版本 4 (IPv4)

互联网协议版本 4 (IPv4) 是目前最常用的 IP 协议版本。它的特点是使用 32 位地址表示法，以 `X.X.X.X` 的点分十进制形式表示，其中 `X` 的范围从 0 到 255。IPv4 用于在互联网上路由数据包，并通过包括 `ICMP`、`TCP` 和 `UDP` 在内的系列相关协议提供广泛的服务。

## IPv6

互联网协议版本 6 (IPv6) 是 `IPv4` 的替代方案。它使用 128 位地址空间，代表大约 $3.4 \times 10^{(38)}$ 个地址。IPv6 地址可以用八组四个十六进制数字表示，使用冒号作为分隔符。除了增加地址空间外，IPv6 还提供了许多功能，包括自动配置、增强的安全性、`IPsec` 支持和增强的组播支持。IPv6 与 `IPv4` 不互操作，给网络和安全运维人员带来了若干挑战。IPv6 设计用于主机到机的连接，使得 `NAT` 等旧系统变得过时。它也给安全供应商带来了挑战，因为用于保护 `IPv4` 的工具和技术在 IPv6 中的工作方式并不相同。

## iSCSI

互联网小型计算机接口 (iSCSI) 是一种基于 IP 的存储协议。`iSCSI` 可通过现有的网络基础设施发送数据，从而实现存储区域网络 (SAN)。作为光纤通道存储的成本替代方案，其唯一的实际限制是网络带宽。

## Fibre Channel

光纤通道 (FC) 是一种高速网络技术（吞吐量高达 16 Gbps），用于将存储设备连接到计算机系统。`FC` 协议是一种传输协议，类似于 IP 网络中的 `TCP` 协议。由于通过特殊电缆传输，基于 `FC` 的存储缺点之一是成本。

## FCoE

以太网光纤通道 (FCoE) 协议封装 `FC` 帧，能够在万兆以太网网络上进行 `FC` 通信。

## Telnet

Telnet 是一种在远程机器上实例化命令行控制的明文方法。`Telnet` 使用 `TCP` 端口 23 并以未加密的形式发送所有传输，导致流量容易被窃听。`Telnet` 是一种使用了数十年的旧协议，但由于安全考虑，已被 `SSH` 取代。

## NetBIOS

NetBIOS 是一个与 `DNS` 不同的命名方案，用于旧的 Windows 系统。它在局域网中使用 `TCP` 和 `UDP` 端口 137、138、139 和 445，用于 Windows PC 的文件和打印机共享等功能。`NetBIOS` 是黑客经常的目标，已大部分过时，仅存在于旧的较小的网络环境中。
