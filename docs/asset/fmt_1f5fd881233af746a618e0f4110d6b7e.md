### 恶意代码

恶意代码对象包括一系列广泛的程序化计算机安全威胁，它们利用各种网络、操作系统、软件和物理安全漏洞，将恶意载荷传播到计算机系统。某些恶意代码对象（如计算机病毒和特洛伊木马）依赖人类不负责任的计算机使用，才能成功地在系统间传播。其他对象（如蠕虫）则凭借自身力量在脆弱系统间迅速蔓延。

所有信息安全从业者都必须熟悉各类恶意代码对象带来的风险，以便制定充分的对策保护其管辖的系统，并在系统遭到入侵时实施适当的响应。

#### 恶意代码的来源

恶意代码从何而来？在计算机安全的早期，恶意代码编写者是极其熟练（尽管方向错误）的软件开发人员，他们以精心设计创新的恶意代码技术为荣。事实上，他们通过揭露流行软件包和操作系统中的安全漏洞，提高了计算机社区的安全意识，实际上起到了某种有用的作用。有关此类代码编写者的示例，请参阅本章后面的侧边栏“RTM 与互联网蠕虫”。

现代催生了*脚本小子*——这类恶意个人不理解安全漏洞背后的技术，但从互联网下载现成的软件（或脚本）并用它们对远程系统发起攻击。这一趋势催生了一类新的病毒创建软件，让任何具备最低技术水平的人都能创建病毒并将其释放到互联网上。这反映在迄今为止防病毒专家记录的大量病毒中。业余恶意代码开发者通常只是在尝试他们下载的新工具，或试图给一两个敌人制造麻烦。不幸的是，恶意软件有时会迅速蔓延，给广大互联网用户带来麻烦。

此外，脚本小子使用的工具也可被怀有更邪恶犯罪意图的人自由获取。事实上，国际有组织犯罪集团已知参与恶意软件扩散。这些犯罪分子位于执法薄弱的国家，利用恶意软件窃取世界各地人们的钱财和身份，尤其是美国居民。事实上，`Zeus` 特洛伊木马被广泛认为是东欧有组织犯罪集团的产物，旨在感染尽可能多的系统以记录按键并收集网上银行密码。`Zeus` 于 2007 年首次出现，但至今仍在不断更新，并不断发现新变种。

### 恶意软件开发的最新趋势伴随着高级持续性威胁（APT）的兴起

APT 是拥有高超技术技能和大量资金资源的复杂对手。这些攻击者通常是军事单位、情报机构或可能与政府机构有关联的神秘组织。APT 攻击者与其他恶意软件作者的主要区别之一在于，这些恶意软件开发者通常能接触到软件供应商尚不知情的零日漏洞。由于供应商不知道该漏洞，因此没有补丁，且该漏洞利用极其有效。APT 构建的恶意软件具有高度针对性，旨在仅影响极少数的敌对系统（通常少至一个！），且难以防御。您将在本章后面阅读到 `Stuxnet`，它是 APT 开发恶意软件的一个例子。

#### 病毒

计算机病毒或许是困扰安全管理员的最早形式的恶意代码。事实上，病毒如今如此普遍，以至于大规模爆发会受到大众媒体的关注，并在普通计算机用户中引发轻度恐慌。据主要杀毒软件供应商赛门铁克称，2016 年全球网络上游荡着超过 3.57 亿种恶意代码，且这一趋势仍在继续，一些来源表明每天有 20 万个新的恶意软件变体出现在互联网上！每天有成百上千种病毒变体袭击毫无防备的计算机用户。许多病毒携带恶意载荷，造成的损害范围从在屏幕上显示亵渎性信息，到导致本地硬盘上存储的所有数据彻底销毁不等。

正如生物病毒一样，计算机病毒有两大主要功能——繁殖和破坏。创建病毒的不法分子精心设计代码，以新颖创新的方法实现这些功能，希望能逃避检测并绕过日益复杂的杀毒技术。可以说，病毒编写者和杀毒技术人员之间已经形成了一场军备竞赛，双方都希望开发出比对方领先一步的技术。繁殖功能定义了病毒如何在系统之间传播，感染其经过的每一台机器。病毒的载荷通过实施病毒编写者设想的任何恶意活动来释放破坏力。这可能是任何对系统或数据的机密性、完整性或可用性产生负面影响的行为。

##### 病毒繁殖技术

根据定义，病毒必须包含使其能够在系统之间传播的技术，这需要毫无戒心的计算机用户通过交换磁盘、共享网络资源、发送电子邮件或使用其他方式来共享数据从而提供协助。一旦它们“接触”到一个新系统，就会使用几种繁殖技术之一来感染新受害者并扩大其影响范围。在本节中，我们将介绍四种常见的繁殖技术：主引导记录感染、文件感染、宏感染和服务注入。

###### 主引导记录病毒

`主引导记录 (MBR) 病毒` 是已知最早的病毒感染形式之一。这些病毒攻击 MBR——可启动介质（如硬盘、通用串行总线 (USB) 或光盘/数字多功能光盘 (CD/DVD)）中计算机在启动过程中用于加载操作系统的那部分。由于 MBR 非常小（通常为 512 字节），它无法容纳实现病毒繁殖和破坏功能所需的所有代码。为了绕过这一空间限制，MBR 病毒将其大部分代码存储在存储介质的另一部分上。当系统读取受感染的 MBR 时，病毒会指示它读取并执行存储在该备用位置的代码，从而将整个病毒加载到内存中，并可能触发病毒载荷的释放。

大多数 MBR 病毒通过用户无意中共享的受感染介质在系统之间传播。如果受感染的介质在启动过程中留在驱动器中，目标系统会读取受感染的 MBR，病毒加载到内存中，感染目标系统硬盘上的 MBR，并将其感染传播到另一台机器。

###### 文件感染型病毒

许多病毒感染不同类型的可执行文件，并在操作系统尝试执行它们时触发。对于基于 Windows 的系统，这些文件的名称以 `.exe` 和 `.com` 扩展名结尾。`文件感染型病毒` 的繁殖例程可能会轻微修改可执行程序的代码，从而植入病毒复制和破坏系统所需的技术。在某些情况下，病毒实际上可能会用受感染的版本替换整个文件。不使用隐藏技术（如隐身或加密，请参阅本章后面的“病毒技术”部分）的标准文件感染型病毒，通常可以通过比较感染前后的文件特征（如大小和修改日期）或比较哈希值来轻松检测。“杀毒机制”部分提供了这些技术的技术细节。

文件感染型病毒的一个变种是 `伴随病毒`。这些病毒是独立的可执行文件，它们通过使用与合法操作系统文件相似但略有不同的文件名来逃避检测。它们依赖基于 Windows 的操作系统在执行程序文件时默认追加的文件名扩展名（按顺序为 `.com`、`.exe` 和 `.bat`）。例如，如果您的硬盘上有一个名为 `game.exe` 的程序，伴随病毒可能会使用名称 `game.com`。如果您随后打开命令工具并仅输入 `GAME`，操作系统将执行病毒文件 `game.com`，而不是您实际想要执行的文件 `game.exe`。这是避免使用快捷方式并完整指定要执行的文件名的一个很好的理由。

###### 宏病毒

许多常见的软件应用程序实现了某种脚本功能，以协助自动化重复性任务。这些功能通常使用简单但强大的编程语言，如 `Visual Basic for Applications (VBA)`。虽然宏确实为计算机用户提供了巨大的生产力提升机会，但它们也使系统面临另一种感染途径——宏病毒。

`宏病毒` 于 1990 年代中期首次出现，利用粗糙的技术感染流行的 Microsoft Word 环境中创建的文档。尽管它们相对不复杂，但这些病毒传播迅速，因为杀毒社区未曾预料到它们，因此杀毒应用程序未提供任何针对它们的防御。宏病毒迅速变得司空见惯，供应商争相修改其杀毒平台以扫描应用程序文档中的恶意宏。1999 年，`Melissa` 病毒通过利用 Microsoft Outlook 中的安全漏洞进行复制，借助 Word 文档进行传播。臭名昭著的“我爱你”病毒紧随其后，于 2000 年初利用类似的漏洞，向我们展示了快速传播的病毒已困扰我们近 20 年。

在 20 世纪末期宏病毒爆发后，生产力软件开发商对宏开发环境进行了重要更改，限制了不受信任的宏在未获得明确用户许可的情况下运行的能力。这导致宏病毒的流行程度大幅下降。

### 服务注入病毒

最近爆发的恶意代码使用了另一种技术来感染系统并逃避检测——将自身注入到操作系统的受信任运行时进程中，例如 `svchost.exe`、`winlogin.exe` 和 `explorer.exe`。通过成功破坏这些受信任的进程，恶意代码能够绕过主机上运行的任何防病毒软件的检测。防范服务注入的最佳技术之一，是确保所有允许查看 Web 内容的软件（浏览器、媒体播放器、辅助应用程序）都接收最新的安全补丁。

#### 易受病毒攻击的平台

正如大多数宏病毒感染运行流行的 Microsoft Office 套件应用程序的系统一样，大多数计算机病毒旨在破坏运行世界上最流行的操作系统——Microsoft Windows 各版本的系统的活动。根据 av-test.org 2017 年的一项分析，研究人员估计现存恶意软件中有 77% 以 Windows 平台为目标。与过去几年超过 95% 的恶意软件以 Windows 系统为目标相比，这是一个重大变化；这反映了恶意软件开发的转变，开始以移动设备和其他平台为目标。

值得注意的是，2016 年针对 Mac 系统的恶意软件数量增加了两倍（即变为原来的三倍），而针对 Android 设备的恶意软件变体数量在同年翻了一番。底线是，所有操作系统的用户都应意识到恶意软件威胁，并确保已采取足够的防护措施。

#### 防病毒机制

如今投入使用的几乎每台台式计算机都运行着某种防病毒软件包。流行的桌面产品包括 `Microsoft Security Essentials`、`McAfee AntiVirus`、`Avast Antivirus`、`Trend Micro Antivirus`、`ESET NOD32 Antivirus`、`Sophos Antivirus` 和 `Symantec Norton AntiVirus`，但市场上还有大量其他产品，提供从单个系统到整个企业的防护；其他软件包旨在防范特定的常见病毒入侵载体，例如入站电子邮件。

绝大多数此类软件包利用一种称为 `signature-based detection`（基于特征码的检测）的方法来识别系统上的潜在病毒感染。本质上，防病毒软件包维护一个极大的数据库，其中包含所有已知病毒的明显特征。根据防病毒软件包和配置设置，它会定期扫描存储介质，检查是否有任何文件包含与这些标准匹配的数据。如果检测到任何匹配项，防病毒软件包将采取以下行动之一：

* 如果软件能够根除病毒，它会对受影响的文件进行消毒，并将计算机恢复到安全状态。
* 如果软件识别出病毒但不知道如何对文件进行消毒，它可能会隔离这些文件，直到用户或管理员能够手动检查它们。
* 如果安全设置/策略不允许隔离，或者文件超过了预定义的危险阈值，防病毒软件包可能会删除受感染的文件，以试图保持系统完整性。

使用 `signature-based`（基于特征码的）防病毒软件包时，必须记住：该软件包的有效性仅取决于其所基于的病毒定义文件。如果您不经常更新病毒定义（通常需要年度订阅费），您的防病毒软件将无法检测新创建的病毒。每天都有数以千计的病毒出现在互联网上，过时的定义文件将迅速使您的防线失效。

许多防病毒软件包还使用 `heuristic-based`（基于启发式的）机制来检测潜在的恶意软件感染。这些方法分析软件的行为，寻找病毒活动的明显迹象，例如试图提升权限级别、掩盖电子踪迹以及修改无关或操作系统文件。这种方法过去并未广泛使用，但现在已成为许多组织使用的高级端点保护解决方案的主流。一种常见的策略是让系统隔离可疑文件并将其发送到恶意软件分析工具，在隔离但受监控的环境中执行它们。如果软件在该环境中表现出可疑行为，它将被添加到整个组织的黑名单中，从而快速更新防病毒特征码以应对新威胁。

现代防病毒软件产品能够检测和清除多种类型的恶意代码，然后清理系统。换句话说，防病毒解决方案很少仅限于病毒。这些工具通常还能防范蠕虫、特洛伊木马、逻辑炸弹、Rootkit、间谍软件以及各种其他形式的电子邮件或 Web 传播代码。如果您怀疑新的恶意代码正在互联网上蔓延，您最好的应对措施是联系您的防病毒软件供应商，询问您针对新威胁的防护状态。不要等到下一次计划内或自动的特征码字典更新。此外，切勿轻信任何第三方关于防病毒解决方案提供的防护状态的说法。请始终直接联系供应商。大多数负责任的防病毒供应商会在发现新的重大威胁后立即向客户发送警报，因此请务必注册此类通知。

其他安全软件包，如流行的 `Tripwire` 数据完整性保证软件包，也提供辅助防病毒功能。`Tripwire` 旨在向管理员发出未经授权的文件修改警报。它常用于检测 Web 服务器篡改和类似攻击，但如果关键系统可执行文件（如 `command.com`）意外被修改，它也可能提供病毒感染的某些预警。这些系统通过维护系统上存储的所有文件的哈希值数据库来工作（有关用于创建这些值的哈希函数的完整讨论，请参见第 6 章“密码学和对称密钥算法”）。然后将这些存档的哈希值与当前计算的值进行比较，以检测两个时期之间被修改的任何文件。在最基本的层面上，哈希是一个用于汇总文件内容的数字。只要文件保持不变，哈希值就会保持不变。如果文件被修改，哪怕只是轻微修改，哈希值也会发生巨大变化，表明文件已被修改。除非该操作似乎可以解释（例如，发生在安装新软件、应用操作系统补丁或类似更改之后），否则可执行文件的突然变化可能是恶意软件感染的迹象。

#### 病毒技术

随着病毒检测和根除技术的发展以应对恶意开发者编写的新威胁，旨在击败这些系统的新型病毒也不断涌现。本节将探讨四种使用隐蔽技术试图逃避检测的特定类型病毒——多重病毒、隐形病毒、多态病毒和加密病毒。

##### 多重病毒

`Multipartite viruses`（多重病毒）使用多种传播技术，试图渗透仅针对一种方法进行防御的系统。例如，1993 年发现的 `Marzia` 病毒通过向每个文件添加 2,048 字节的恶意代码来感染关键的 COM 和 EXE 文件，最著名的是 `command.com` 系统文件。这一特征使其成为文件感染型病毒。此外，在感染系统两小时后，它会将恶意代码写入系统的主引导记录，使其也成为引导扇区病毒。

### 隐形病毒

`隐形病毒` 通过实际篡改操作系统来隐藏自身，从而欺骗防病毒软件包，使其误以为一切运行正常。例如，隐形引导扇区病毒可能会用恶意代码覆盖系统的主引导记录，但随后也会修改操作系统的文件访问功能以掩盖踪迹。当防病毒软件包请求一份 MBR 副本时，被修改的操作系统代码会提供给它防病毒软件包所期望看到的内容——一个干净的、不含任何病毒特征码的 MBR 版本。然而，当系统启动时，它会读取被感染的 MBR 并将病毒加载到内存中。

### 多态病毒

`多态病毒` 在从系统传播到系统的过程中，实际上会修改自身的代码。病毒的传播和破坏技术保持不变，但病毒的特征码在每次感染新系统时都会有所不同。多态病毒创建者希望这种不断变化的特征码能使基于特征码的防病毒软件包失效。然而，防病毒软件供应商已经“破解”了许多多态技术的“代码”，因此当前版本的防病毒软件能够检测已知的多态病毒。不过，供应商生成阻止多态病毒所需的特征文件往往需要更长的时间，这意味着病毒可以在互联网上肆意传播更长一段时间。

### 加密病毒

`加密病毒` 使用加密技术（如第 6 章所述）来避免被检测。从外观上看，它们实际上与多态病毒非常相似——每个被感染的系统上的病毒都有不同的特征码。然而，它们并非通过改变代码来生成这些修改后的特征码；相反，它们改变的是自身在磁盘上的存储方式。加密病毒使用一段非常短的代码，称为 `病毒解密程序`，其中包含加载和解密存储在磁盘其他位置的主病毒代码所需的加密信息。每次感染都使用不同的加密密钥，导致主代码在每个系统上看起来完全不同。然而，病毒解密程序通常包含明显的特征码，这使得它们容易被更新后的防病毒软件包检测到。

#### 病毒骗局

如果不提及病毒 `骗局` 造成的麻烦和资源浪费，关于病毒的讨论就不算完整。几乎每个电子邮件用户都曾在某个时候收到过朋友或亲戚转发的消息，警告互联网上出现了最新的病毒威胁。这种所谓的“病毒”总是被描述为有史以来破坏力最强的病毒，且没有任何防病毒软件包能够检测和/或清除它。一个著名的骗局例子是“Good Times”病毒警告，它最早于 1994 年在互联网上出现，至今仍在流传。

社交媒体格局的变化只是改变了这些骗局的传播方式。除了电子邮件，恶意软件骗局现在还通过 Facebook、Twitter、WhatsApp、Snapchat 以及其他社交媒体和即时通讯平台传播。

有关此主题的更多信息，辟谣网站 Snopes 在 <https://www.snopes.com/tag/virus-hoaxes-realities/> 维护着一个病毒骗局列表。

#### 逻辑炸弹

`逻辑炸弹` 是感染系统并潜伏的恶意代码对象，直到由一个或多个条件（如时间、程序启动、网站登录等）的发生而触发。绝大多数逻辑炸弹是由软件开发人员编入定制应用程序中的，旨在确保如果他们意外离职，其工作成果会被销毁。
