
# 贝叶斯分类器

贝叶斯分类器使用了一个简单的思想：利用训练数据根据特征值计算每个类别的观测概率。当稍后使用同一分类器处理未分类数据时，它使用观测概率来预测新特征最可能属于类别。对训练数据观测结果的应用也可以被看作是将我们的先验知识或先验信念应用到结果的概率上，使其有更高的概率符合实际或现实结果。这个简单的概念被用于贝叶斯规则，并应用于机器学习术语中的机器训练。贝叶斯分类器的一些现实生活应用如下：

*   基于文本的分类，如垃圾邮件过滤、作者识别或主题分类
*   医学诊断，例如在给定疾病期间观察到某一组症状的情况下，识别新病人患该疾病的概率
*   网络安全，如检测计算机中的非法入侵或异常

贝叶斯分类器的优势之一是它们利用所有可用参数来细微地改变预测，而许多其他算法倾向于忽略影响较弱的特征。贝叶斯分类器假设，即使少数单个参数对结果的影响很小，这些参数的集体效应可能很大。对于这类学习任务，朴素贝叶斯分类器是最有效的。

贝叶斯学习方法广受欢迎的某些特性如下：

*   候选假设的先验知识与观测数据相结合，以得出假设的最终概率。因此，两个重要组成部分是每个候选假设的先验概率以及对于每个可能的假设在观测数据集上的概率分布。
*   贝叶斯学习方法比其他方法更灵活，因为每个观测到的训练模式都可以通过增加或减少关于假设的估计概率来影响假设的结果，而大多数其他算法在假设与单个训练模式不一致时，倾向于舍弃该假设。
*   贝叶斯方法在验证做出概率预测的假设时，性能可能优于其他方法。例如，在启动一个新软件项目时，根据项目的人口统计，我们可以预测在项目执行期间遇到挑战的概率。
*   通过贝叶斯方法的简单方法，可以通过结合多个假设的预测（按各自概率加权）对新实例进行分类。
*   在某些情况下，当贝叶斯方法无法确定性地计算结果时，可以使用它们创建一个最优决策的标准，以此衡量其他方法的性能。

正如我们上面讨论的，贝叶斯方法的成功在很大程度上取决于关于假设集概率的初始知识是否可用。因此，如果我们事先不知道这些概率，就必须使用一些背景知识、以前的数据或对数据集的假设，以及相关的概率分布函数来应用这种方法。此外，得出最优贝叶斯假设通常涉及很高的计算成本。

## 6.3 贝叶斯定理

在讨论贝叶斯定理及其在概念学习中的应用之前，我们应该清楚什么是概念学习。让我们以孩子如何开始学习新词的含义为例，例如“球”。孩子提供了“球”这类物体的正向示例。起初，孩子可能会被许多不同颜色、形状和大小的球所困扰，也可能被看起来像球的物体（如气球或地球仪）所困扰。孩子的父母不断向她提供正向示例，如“那是球”、“这是球”、“把那个球拿给我”等。概念教学中很少使用负向示例，如“这不是球”，但当父母指着气球说“那不是球”它是气球时，可能会消除孩子的困惑。但观察发现，学习受正向示例的影响最大，而不是负向示例，预想是一旦孩子明确了“球”的概念，她就能从各种物体和放在一起的不同种类的球中识别出“球”这个物体。

将上述学习概念与贝叶斯的数学模型联系起来，我们可以将“学习单词含义”的学习过程等同于使用二分类的概念学习。让我们定义一个概念集 `C` 和一个相应的函数 `f(k)`。我们还定义当 `k` 在集合 `C` 内部时 `f(k) = 1`，否则 `f(k) = 0`。我们的目标是学习指示函数 `f`，定义哪些元素在集合 `C` 中。因此，通过使用函数 `f`，我们能够将元素分类在概念集内部或外部。在贝叶斯定理中，学习如何使用标准概率演算来确定函数 `f` 的不确定性，并可以通过提供正向示例来验证分类。

在深入研究贝叶斯定理的细节之前，将引入一些符号。下面讨论了贝叶斯规则：

```
p(A|B) = p(B|A) * p(A) / p(B)
```

其中 `A` 和 `B` 是相关事件，`p(A|B)` 表示事件 `B` 发生时事件 `A` 发生的概率。

假设我们有一个观测数据集 `D`，我们的任务是通过使用 `D` 的知识在空间 `H` 中确定最佳假设。

### 6.3.1 先验概率 (Prior)

在贝叶斯定理的语境中，关于 `H` 中各种假设的先验知识或信念被称为**先验**。例如，如果我们需要判断特定类型的肿瘤是否为恶性，这种肿瘤的先验知识可以用来验证我们的假设，并简单地称为先验。

让我们引入一些符号来解释这些概念。我们将假设 `P(h)` 是仅根据恶性测试的先验知识，患者患恶性肿瘤 `h` 的初始概率。同样，`P(T)` 是训练数据 `T` 将被观测到的概率，在这种情况下，测试结果。我们将 `P(T|h)` 记为 `h` 成立时观测到数据 `T` 的概率。

### 6.3.2 后验概率 (Posterior)

基于先验的特定假设成立的概率被称为后验概率，或简单地称为**后验**。在上面的例子中，考虑到患者患恶性肿瘤的恶性测试先验是后验概率。在我们的符号中，我们感兴趣的是找出 `P(h|T)`，这意味着给定观测训练数据 `T` 时假设是否成立。这在机器学习语言中被称为后验概率或简单地称为后验。因此，先验概率 `P(h)`（独立于训练数据）现在通过 `P(h|T)` 的引入而得到了完善。

根据贝叶斯定理

```
P(h|T) = P(T|h) * P(h) / P(T)
```

将先验和后验概率结合在一起。

从上面的方程可以推断出，随着 `P(h)` 和 `P(T|h)` 的增加，`P(h|T)` 也会增加，同时也取决于 `P(T)`。简单的解释是，当 `T` 独立于 `h` 发生的概率更大时，那么 `h` 从 `T` 中获得支持的概率就较低。

机器学习中的一个常见问题是在给定观测训练数据 `T` 的一组假设集合 `H` (`h∈H`) 中找到概率最大的假设 `h`。这种概率最大的假设被称为**后验概率 (MAP)**。通过使用贝叶斯定理，我们可以从每个候选假设的后验概率中识别出 MAP 假设：

```
h_MAP = argmax_{h∈H} P(h|T) = argmax_{h∈H} P(T|h) * P(h) / P(T)
```

由于 `P(T)` 是独立于 `h` 的常量，在这种我们可以我们可以：

```
h_MAP = argmax_{h∈H} P(T|h) * P(h)
```

### 6.3.3 似然 (Likelihood)

在某些机器学习问题中，如果 `H` 中的每个假设具有相同的先验概率 `P(h[i]) = P(h[j])`，我们可以进一步简化方程 6.1，然后仅从概率 `P(T|h)` 确定 `P(h|T)`。因此，`P(T|h)` 被称为给定 `h` 时数据 `T` 的似然，而任何使 `P(T|h)` 最大化的假设都被称为极大似然 (ML) 假设，`h[ML]`。参见图 6.1 和 6.2，了解贝叶斯定理的概念和数学表示，以及先验、后验和似然之间的关系。

#### 思考要点

根据相关事件的概率得出事件的完善概率是一个强大的概念，与我们日常处理事件以及利用我们的知识影响决策密切相关。

**示例**。让我们以特定患者肿瘤的恶性识别作为贝叶斯规则的应用。我们将计算样本人群中病例百分的先验知识以及测试结果正确的概率如何影响正确诊断的概率结果。我们有两个备选假设：(1) 特定肿瘤是恶性类型，(2) 特定肿瘤是非恶性类型。可用的先验信息有——1. 只有 0.5% 的人口患这种恶性肿瘤；2. 实验室报告存在某种不准确性，因为它只能以 98% 的准确率检测出恶性的存在，而只有在 97% 的情况下才能正确显示不存在恶性。这意味着测试预测存在恶性，而这实际上在 2% 的情况下是误报，并在 3% 的情况下也漏检了真正的恶性肿瘤。

**解**：让我们用恶性肿瘤 = MT，阳性实验室测试 = PT，阴性实验室测试 = NT

`h[1]` = 特定肿瘤是恶性类型 = MT

`h[2]` = 特定肿瘤不是恶性类型 = !MT

`P(MT) = 0.005` `P(!MT) = 0.995` `P(PT|MT) = 0.98` `P(PT|!MT) = 0.02` `P(NT|!MT) = 0.97` `P(NT|MT) = 0.03`

所以，对于新患者，如果实验室测试报告显示阳性结果，让我们看看是否应该将其宣布为恶性病例：

```
P(h[1]|PT) = P(PT|MT) * P(MT) / P(PT)
           = 0.98 * 0.005 / (0.98 * 0.005 + 0.02 * 0.995)
           ≈ 0.198
```

```
P(h[2]|PT) = P(PT|!MT) * P(!MT) / P(PT)
           = 0.02 * 0.995 / (0.98 * 0.005 + 0.02 * 0.995)
           ≈ 0.802
```

由于 `P(h[2]|PT)` 高于 `P(h[1]|PT)`，显然假设 `h[2]` 更有可能。因此，`hMAP` = `h2` = !MT。

这表明即使恶性的后验概率显著高于非恶性，但基于先验知识，患者不患恶性的概率仍然更高。此外，应该注意到，通过贝叶斯定理，我们识别出一个假设的概率高于另一个，而并没有通过该定理完全接受或拒绝假设。此外，贝叶斯定理的成功应用高度依赖先验数据的可用。

## 6.4 贝叶斯定理与概念学习

概念学习的一种简单观点可以是，如果我们向机器输入训练数据，它就可以计算假设的后验概率并输出概率最大的假设。这也被称为暴力贝叶斯学习算法，而且观察到该算法提供正确概率假设的一致性与其他算法非常相当。

### 6.4.1 暴力贝叶斯算法

我们现在讨论如何使用 MAP 假设的输出来设计一种名为暴力 MAP 学习算法的简单学习算法。假设学习者考虑一个有限的假设空间 `H`，其中学习者将尝试学习某个目标概念 `c:X → {0,1}`，其中 `X` 是对应 `H` 的实例空间。训练示例的序列为 `{(x[1], t[1]), (x[2], t[2]),…, (x[m], t[m])}`，其中 `x[i]` 是 `X` 的实例，`t[i]` 是 `x[i]` 的目标概念，定义为 `t[i] = c(x[i])`。在不影响算法效率的情况下，我们可以假设实例 `x` 的实例序列 `{x[1],…, x[m]}` 是固定的，那么目标值序列就变为 `T = {t[1],…, t[m]}`。

为了计算最高后验概率，我们可以使用本章之前讨论过的贝叶斯定理：

计算 `H` 中每个假设 `h` 的后验概率：

```
P(h|T) = P(T|h) * P(h) / P(T)
```

识别具有最高后验概率的 `h[MAP]`

```
h[MAP] = argmax_{h∈H} P(h|T)
```

请注意，计算每个假设的后验概率需要巨大的计算量，对于大量的假设空间，这可能很难实现。

让我们尝试将概念学习问题与识别 `h[MAP]` 的问题联系起来。基于概率分布 `P(h)` 和 `P(T|h)`，我们可以推导出学习任务的先验知识。需要做出以下几个重要的假设：

1. 训练数据或目标序列 `T` 是无噪声的，这意味着它仅是 `X` 的直接函数（即 `t[i] = c(x[i])`）
2. 概念 `c` 位于假设空间 `H` 之中
3. 每个假设的概率相等，且相互独立

基于假设 3，我们可以说空间 `H` 内的每个假设 `h` 具有相等的先验概率，而且由于假设 2 的存在，我们可以说这些先验概率之和为 1。因此，我们可以写道：

```
P(h) = 1 / |H|
```

`P(T|h)` 是在 `h` 成立且正确描述概念 `c` 的空间中，固定实例集 `{x[i],…, x[m]}` 观测到目标值 `t[i]` 的概率。使用上述假设 1，我们可以说如果 `T` 与 `h` 一致，则给定假设 `h` 的情况下数据 `T` 的概率为 1，否则为 0：

```
P(T|h) = 1  if T 与 h 一致
P(T|h) = 0  otherwise
```

使用贝叶斯定理识别后验概率

```
P(h|T) = P(T|h) * P(h) / P(T)
```

对于 `h` 与训练数据 `T` 不一致的情况，使用公式 6.5 得到

```
P(h|T) = 0  当 h 与 T 不一致时
```

当 `h` 与 `T` 一致时

```
P(h|T) = P(h) / P(T)
```

现在，如果我们将假设 `H` 中与 `T` 一致的子集定义为 `H[D]`，那么通过使用全概率公式，我们得到

```
P(T) = |H[D]| / |H|
```

这使得 6.5 变为

```
P(h|T) = 1 / |H[D]|
```

因此，基于对 `P(h)` 和 `P(T|h)` 的假设，我们得到的后验概率 `P(h|T)` 为

```
P(h|T) = 1 / |H[D]|  if h 与 T 一致
P(h|T) = 0             otherwise
```

其中 `H[D]` 是空间 `H` 中与目标数据集 `T` 一致的假设数量。该评估的解释是：最初，每个假设具有相等的概率，随着我们引入训练数据，不一致假设的后验概率变为零，而总和为 1 的总概率平均地分布在集合中一致的假设之间。因此，在这种条件下，每个一致的假设都是一个后验概率为 `1 / |H[D]|` 的 MAP 假设。

### 6.4.2 一致性学习器的概念

通过上述讨论，我们理解了被称为一致性学习器（consistent learners）的一类通用学习器的行为。因此，在训练数据上产生零误差并输出假设的学习器被称为一致性学习器。如果训练数据是无噪声且确定性的（即如果 `D` 和 `h` 一致则 `P(D|h) = 1`，否则为 0），并且如果 `H` 上存在均匀的先验概率分布（因此对于所有 `m, n`，`P(h[m]) = P(h[n])`），那么每个一致性学习器都会输出 MAP 假设。这一结论的一个重要应用是，即使算法没有显式处理概率，贝叶斯定理也可以描述学习算法的行为。由于它可以帮助识别算法输出 MAP 假设的 `P(h)` 和 `P(T|h)` 的最优分布，这些知识可以用于描述算法表现最优的假设条件。

尽管我们在本节讨论了贝叶斯输出的一种特殊情况（该情况对应于无噪声训练数据和假设的确定性预测，在这种情况下 `P(T|h)` 取值为 1 或 0），但该定理可以同样有效地用于有噪声的数据。

### 6.4.3 贝叶斯最优分类器

在本节中，我们将讨论使用 MAP 假设来回答给定训练数据时最可能的分类问题。为了说明这一概念，让我们假设有假设 `h[1]`、`h[2]` 和 `h[3]`，它们在假设空间 `H` 中的后验概率分别为 0.4、0.3 和 0.3。有一个新实例 `x` 被 `h[1]` 分类为真，被 `h[2]` 和 `h[3]` 分类为假。

通过加权所有假设的预测，可以得到新实例的最可能的分类。通过将集合 `C` 中的可能分类标记为 `c[i]`，则新实例为 `c[i]` 的概率 `P(c[i]|T)` 为：

```
P(c[i]|T) = Σ_{h∈H} P(c[i]|h) * P(h|T)
```

最优分类是其后验概率最大的那个：

```
argmax_{c[i]∈C} P(c[i]|T)
```

#### 思考点

贝叶斯最优分类器的方法是根据后验概率权重计算每个新实例的最可能的分类。

扩展上述示例，实例的可能结果集为 `{True, False}`，且

`P(h[1]|T) = 0.4`，`P(False|h[1]) = 0`，`P(True|h[1]) = 1`

`P(h[2]|T) = 0.3`，`P(False|h[2]) = 1`，`P(True|h[2]) = 0`

`P(h[3]|T) = 0.3`，`P(False|h[3]) = 1`，`P(True|h[3]) = 0`

那么，

```
P(True|T) = 0.4 * 1 + 0.3 * 0 + 0.3 * 0 = 0.4
```

和

```
P(False|T) = 0.4 * 0 + 0.3 * 1 + 0.3 * 1 = 0.6
```

这种方法在已知训练数据、假设空间以及假设先验概率的情况下，最大化新实例被正确分类的概率。因此这也是贝叶斯最优分类器。

### 6.4.4 朴素贝叶斯分类器

朴素贝叶斯是一种构建分类器的简单技术：为问题实例分配类别标签的模型。贝叶斯规则的基本思想是根据观测到的证据 `E` 来预测假设的结果。从贝叶斯规则中，我们观察到

1. 假设 `h` 的先验概率 `P(h)`：这是观测证据之前事件或假设的概率。
2. `h` 的后验概率 `P(h|D)`：这是在群体 `D` 中观测到证据之后事件的概率。

```
P(h|D) = P(D|h) * P(h) / P(D)
```

**后验概率的格式为“给定观测到的特征值，某个特定对象属于类别 i 的概率是多少？”**

例如，一个人的身高和体重分别为 182 cm 和 68 kg。那么此人属于“篮球运动员”类别的概率是多少？这可以使用朴素贝叶斯分类器进行预测。这被称为概率分类。

在机器学习中，概率分类器是一种在给定感知（输入）的情况下，通过对一组类别进行似然计算来预测的分类器，而不是仅仅产生（输出）最可能的类别。朴素贝叶斯模型的参数估计使用机器学习方法。贝叶斯定理用于当新信息可用时修正先验确定的概率。根据概率模型的特定性质，朴素贝叶斯分类器可以在监督学习环境中进行训练。

让我们来看看朴素贝叶斯分类器的原理。我们取一个学习任务，每个实例 `x` 具有某些属性，且目标函数 `f(x)` 可以从分类集合 `C` 中取任何值。此外，我们也有针对目标函数的训练样本集 `a[1], a[2], ..., a[n]`。我们的任务是预测新实例的分类。

根据贝叶斯定理的方法，新实例的分类是通过分配最可能的目标分类 `MAP` 完成的，基于新实例的属性值 `{a[1], a[2], ..., a[n]}`。因此，

```
argmax_{c[i]∈C} P(c[i]|a[1], a[2], ..., a[n])
```

可以使用贝叶斯定理重写为：

```
argmax_{c[i]∈C} P(a[1], a[2], ..., a[n]|c[i]) * P(c[i]) / P(a[1], a[2], ..., a[n])
```

新实例属性的组合概率始终等于 1

```
P(a[1], a[2], ..., a[n]) = 1
```

因此，为了得到最可能的分类器，我们需要评估两个项 `P(a[1], a[2], ..., a[n]|ci)` 和 `P(ci)`。在实际场景中，通过计算训练集中每个目标值 `c[i]` 的频率可以计算 `P(ci)`。但 `P(a[1], a[2], ..., a[n]|ci)` 无法轻易估计，因为这些项的数量等于可能实例的数量与可能目标值的乘积，因此实例空间中的每个实例需要访问多次才能得出估计。因此，朴素贝叶斯分类器做一个简单假设，应用这种简化，我们现在说对于实例的目标值，观测到组合 `a[1], a[2], ..., a[n]` 的概率是单个属性概率 `P(a[i]|c[j])` 的乘积。

```
P(a[1], a[2], ..., a[n]|c[j]) = Π_{i=1}^n P(a[i]|c[j])
```

然后，从公式 6.7，我们得到朴素贝叶斯分类器的方法为：

```
argmax_{c[i]∈C} P(c[i]) * Π_{j=1}^n P(a[j]|c[i])
```

在这里，我们将能够计算 `P(a[i]|c[j])`，因为我们只需要计算不同属性值 (`ai`) 的数量乘以不同目标值 (`cj`) 的数量，这比两个集合的乘积小得多。朴素贝叶斯分类器方法流行的最重要的原因是不需要搜索整个假设空间，而是通过简单统计训练示例中各种数据组合的频率来得到目标分类器。
