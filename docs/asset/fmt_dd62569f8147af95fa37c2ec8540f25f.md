## 捕获未加密流量

正如图 8.1 所示，任何连接到同一无线网络的人都可以以明文形式读取未加密的无线流量。你的电子邮件、即时消息、FTP 文件、Telnet 连接、HTTP 会话和其他数据都可能被窃取。其原理是什么？当用户使用 HTTP 浏览网站时，他们发送的数据从头到尾都未加密；因此，同一网络上的任何人都可以拦截并记录这些数据：

**图 8.1：** 未加密连接

`Wireshark` 是一款网络分析器，允许你检查和保存实时网络数据包。`Wireshark` 兼容 Windows、Mac OS X、Linux 和 Unix。如果有人在网络上运行 `Wireshark`，他们可以观察到人们访问了哪些网站、传输了哪些文件、发送了哪些即时消息等。

存在多种易受网络嗅探攻击的网络服务和公共网络。任何具备必要能力和 `Wireshark` 知识的人都可以快速入侵您的账户。

*   在公共网络上使用 VPN。
*   使用密码管理器登录网站。

### 什么是路由？

路由是定义不同网络中的设备如何相互通信的过程。路由通常借助称为*路由器*的设备来完成。路由器使用路由表将网络数据包路由到其预期目的地。路由不仅可以在路由器等网络设备上进行，也可以在安装了操作系统的任何计算机上进行。请参阅图 9.1：

![](img/Figure-9.1.jpg)

**图 9.1：** 路由

根据上图示例，要在 `192.168.1.0/24` 和 `192.168.10.0/24` 网络之间成功通信，需要一条路由表记录。根据路由器的规则，从源 `192.168.1.0/24` 访问目标 `192.168.10.0/24`。

网络数据包的传输历程如下：

1.  要访问的 IP 地址是否在本地网络上？
    1.  如果是，直接到达目的地。
    2.  如果不是，发送给网关。
2.  路由器接收数据包后，检查自己的路由表。
    1.  是否有针对目标 IP 地址或网络的路由规则？
        1.  如果有，将数据包发送给目标或目的地。
        2.  如果没有，发送给网关。
3.  其他路由器经历类似的过程。
4.  最后，数据包到达负责机构互联网出口的路由器。随后数据包被发送到互联网。

### 什么是跳板？

从本质上讲，这是一种利用被攻陷的计算机来访问我们原本无法访问的网络的做法。如果一台具有网络访问权限的计算机被攻陷，网络隔离将变得毫无意义。这种方法允许攻击者通过路由到被攻陷的系统来访问秘密网络。枢纽用于将所有请求传输到新发现的网络。它就像一种隧道。请参阅图 9.2：

![](img/Figure-9.2.jpg)

**图 9.2：** 枢纽

如拓扑所示，具有两块 NIC 的设备可以访问 `192.168.1.0/24` 和 `192.168.10.0/24` 网络。除非定义了路由规则，否则在正常情况下这两个网络之间无法互访。根据此拓扑，授权用户正在使用一台配有两块 NIC 网卡的计算机，必须访问 DMZ 中的某些服务。

## 端口转发

端口转发是枢纽的第一步之一。隐秘网络上指定系统的某些服务可能无法直接访问（Web 服务器等）。这是由于缺乏双向路由。我们知道如何到达目标系统并发送请求，但因为目标不知道我们的位置，我们的请求将被拒绝。请参阅图 9.14：

![](img/Figure-9.14.jpg)

**图 9.14：** 端口转发

因此，我们使用当前的 `meterpreter` 会话将本地系统上的一个端口路由到目标。只要此进程存活，路由就会生效。

此时需要注意一点：`autoroute` 运行命令允许我们得益于所提供的路由，在 `Metasploit` 框架内自由工作。然而，我们将需要像端口转发和 `ProxyChains` 这样的工具，以便使用 Kali 工具访问目标。
