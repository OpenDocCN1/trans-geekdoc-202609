
# 网络空间安全概述

## 网络空间安全的挑战

在网络空间设计和构建的大多数环节中，安全未被纳入考量。遗憾的是，事后加装安全极其困难。主要困难源于向后兼容性的需求——即使系统某部分升级得更安全，所有系统必须继续运行，且没有至高权威能强制在所有地方安装改进的新组件。网络空间有许多部分正在使用缺陷广为人知的计算机和软件，却因成本、无知或惰性未更新或替换。有时，这种新旧安全机制混杂的异质性会引入新漏洞，导致安全工作往往看似“前进两步，后退一步（甚至两步）”。

一些主要参与者正承担起强制更新系统以提高安全性的责任。例如，`Microsoft` 使得不自动安装 `Windows` 更新变得更难；`Google` 和 `Mozilla` 均在后台更新其浏览器；手机制造商强制推送系统更新；`Amazon` 更新 `Kindle`，所有这些基本无需用户操作。

强制更新看似天然利好，实则是一把双刃剑。为解决安全问题的更新往往会破坏运行中系统的其他部分，这对依赖持续可用性的企业可能是灾难性的。因此，组织倾向于阻止自动更新；结果是，尽管已有修复补丁，已知安全漏洞往往仍存在于关键系统中，成为可乘之机。

一个更根本的问题是攻防之间的不对称性。网络空间任何部分必须成功防御*所有*可能的攻击。攻击者只需找到一种有效的攻击手段。这迫使防御者投入资源用于防御，其中大多基于假设性威胁，难以说服资源提供方买单。攻击者的动机层级也可能更高。组织的安全人员是为薪水工作；攻击者往往有更个人化或直接的目的。

另一个显著问题是网络空间利益相关者倾向于搞*安全表演*。这是指组织强加的安全流程看似增强了安全，实则对提升安全毫无裨益或作用极小。这通常意味着推行针对低风险但高可见度漏洞的流程，而忽视低可见度但风险更大的隐患。常见例子是要求定期更改密码，尽管有大量证据表明这弊大于利（人们通过循环遍历规定次数将密码改回原样，或将密码写下来）。

## 2.14 网络空间的非善意使用

网络安全旨在防止网络空间被用于正常用途以外的目的。这范围从无聊者的破坏行为、牟利犯罪，到国家将其作为国际政策杠杆。某些用途虽非技术层面的犯罪，但具有社会破坏性。

对犯罪分子而言，安全漏洞为其犯罪创造了新途径，主要是牟利类犯罪（而非暴力犯罪）。其中一些是在线版传统犯罪，例如从银行账户窃取资金而非抢劫。此类线上线下犯罪的区别在于规模——窃取 100 元与 100,000 元付出的努力相同——以及时机——转账可在几毫秒内完成。

线上犯罪也往往更隐蔽。抢劫受害者知晓事发，但扒手受害者一时不知。线上犯罪更像扒手，但我们不习惯像看管钱包那样追踪在线资源。因在线信息和知识是数字化的，窃取它们意味着复制副本，因此可能毫无明显迹象表明发生了窃取。

电子邮件和其他形式消息传递的覆盖范围，也使得寻找轻信者所需的成本比现实世界中低得多。事实上，网络犯罪诈骗往往会故意让自己看起来比实际情况更不可信，因为这能确保只有真正轻信的人才会上当受骗。各种类型的骗术（如尼日利亚王子诈骗）在网络空间蓬勃发展，并持续为其制造者带来利润。

网络空间还催生了依赖其新能力的新型犯罪。一个典型例子是基于勒索软件的敲诈。勒索软件攻击会加密系统上的文件，并要求系统所有者付款以解密文件。

网络空间的存在还因其提供的相互通信能力而改变了犯罪格局。罪犯可以找到具有特定技能的其他罪犯进行合作。罪犯也可以在线学习新技能。用于实施犯罪的产品可以在网上更容易地购买，而不像在物理世界那样困难。在线购物可以提供开锁工具等在现实世界中非法持有、因此难以买卖的工具。罪犯还可以购买软件工具（“即插即用型网络攻击工具包”），利用它们在网络空间实施犯罪。

网络空间也已成为国家力量角逐的竞技场。以一种被动形式来看，它是一个情报收集平台，因为几乎所有数据都在网络空间内传输，而非通过无线电。所有政府都利用这一点监视其他国家，许多政府也利用它监视本国公民（当他们在国外时，通常在国内也是如此）。网络空间也可以被武器化，使一国能通过瘫痪目标国的在线活动来攻击另一国，鉴于我们对在线活动的高度依赖，这可能产生巨大影响；或者利用网络空间对物理系统发动攻击（这些系统几乎总是由计算机控制）。

国家还通过其他国家的本国公民对这些国家实施低强度干扰，利用虚假信息通过改变态度或试图左右选举来使其动荡不安。

企业利用网络空间的两种方式至少是有问题的。首先，依赖抓取注意力（例如投放广告）的社交媒体企业开发了使其界面更具吸引力的方法，以便用户更频繁、更长时间地与其互动。这产生了不幸的副作用，即因暴露于为保持兴趣而推送的负面内容，以及被抓取的时间和注意力挤占了生活的其他方面，从而对人们造成心理伤害。

其次，网络空间使得收集所有人活动的大量详细描述成为可能。这些数据被广泛分发给利用它们建立个人画像的企业。通常，这种建模表面上旨在投放更好的广告，但数据永远不会消失，因此可以且必然会被用于不那么光鲜的目的。

网络空间中的一些负面活动是正常流程的腐败变质，但也有一些需要滥用网络空间。对于犯罪行为，可以采取法律补救措施，但这些措施受困于法律法规的国家属性与网络空间跨国属性之间的错位。罪犯几乎无需在其所属司法管辖区的国家内活动。这还因在快速变化的网络空间世界中保持法律法规的相关性极其困难而加剧。总的来说，立法者不了解网络空间，因此立法太慢、太缺乏针对性，无法提供应有的帮助。

在国际舞台上，同样的问题被放大了。国际法不适用于网络空间的大多数问题，国家可以随心所欲地行事，再加上当国家确实采取行动时，归因困难，问题更加复杂。

# 第 3 章 加密与哈希

在电报早期，电报按字收费，因此企业开发了代码本，用单个代码词（如“enbet”，一个真实例子）来表达原本需要许多单词才能说清的内容（“船长疯了”）。当然，这还有一个额外的优势，即通信含义被掩盖了，但这并非其主要目的。尽管如此，由于电报操作员能看到他们传输的所有内容，在某些情况下使用代码是必要的。据称，出于安全原因，表示伊丽莎白二世女王驾崩的代码短语是“伦敦大桥垮了”。

当电话系统取代电报后，人们就不太需要担心通信内容被截获（至少在电话接线员不再发挥作用后）。截获仍然可能，但需要物理行动，且在许多国家需要法律程序。

在网络空间中，各种通信以不可预测的方式跨越管道、穿过节点流动，且其经过的设备往往不在通信端点所在的司法管辖区内。迫切需要能够隐藏数据传输内容，防止被截获和窥探。加密技术由此登场。

加密利用一种映射，将数据从其原始存在形式（称为 `plaintext`）映射为一种新形式（称为 `ciphertext`），该映射具有以下两个属性：

*   在不知道密钥的情况下，很难逆向还原，即需要数年的计算才能重建原始内容；且
*   原始数据的结构与其加密形式之间没有关系。例如，两个几乎相同的 `plaintext` 应被映射为截然不同的加密形式。

加密的基本属性是：从实际意义上讲，知道加密形式（`ciphertext`）无法在不持有密钥的情况下重建原始数据（`plaintext`）。

加密使得在网络中移动数据成为可能，即使网络不可信，因为能够看到加密数据并不允许除发送方和接收方之外的任何人发现通信内容。

## 3.1 私钥加密

加密主要有两种方法：`private key encryption`（私钥加密）和 `public key encryption`（公钥加密）。在 `private key encryption` 中，有两个密钥，一个用于加密 `plaintext` 数据，另一个用于将 `ciphertext` 解密回原始 `plaintext`。通常这两个密钥相同，或至少紧密相关，以便双方可以使用同一个密钥进行相互传输。例如，凯撒密码使用一种编码，加密时将字母表中的每个字母替换为其右侧第 5 个（如“a”变为“f”）。解密时，加密消息中的每个字符被替换为其左侧第 5 个。只要双方约定偏移量为 5，就可以使用这种简单的加密方法相互通信。

加密系统已使用数千年，但它们往往依赖方法的保密性，而非密钥的保密性。毕竟，破解凯撒密码只需尝试所有可能的偏移量，这从其首次使用时就切实可行。任何通过固定方式将每个单字符替换为另一个字符的替换密码，都很容易通过字符频率分析来攻击。例如，英语中最常见的字母是“e”，因此加密消息中出现频率最高的字符很可能是“e”的加密版本。

## 3.2 公钥加密

第二种主要的加密方法更为常见，因为与私钥系统相比，它具有许多吸引人的特性。这被称为**公钥加密**。在此场景中，用于加密的密钥和用于解密的密钥是不同的，不同到无法从其中一个（在计算上）推断出另一个。然而，它们的工作方式与之前相同：如果明文消息使用加密密钥进行加密，则密文可以使用解密密钥解密回明文。

节点（或个人）*A* 拥有一个私钥，必须保密，用于解密。*A* 还拥有一个公钥，无需保密，任何人都可以用它来加密发送给 *A* 的消息。让该密钥广为人知并不是问题，因为使用它的唯一方式是加密只有 *A* 能解密的消息；而且无法从 *A* 的公钥推导出其私钥。

因此，任何想给 *A* 发送消息的人都可以查找其公钥，用它加密消息并发送给 *A*，而 *A* 是唯一能解密它的人。这两个节点不需要共享任何公共密钥。*A* 可以创建两个密钥，保留私钥并公开公钥。

## 3.3 数字签名与数字哈希

我们已经知道解密是加密的逆操作（从一条消息开始，加密它，然后解密它，会产生原始消息）。通常，加密系统的结构意味着加密也是解密的逆操作。换句话说，如果消息首先通过应用解密机制进行转换，然后应用加密机制将再次产生原始消息。

当这成立时，公钥技术可用于**数字签名**。如果 *A* 创建一份法律文档，然后使用其（私有）**解密密钥**对其进行加密，那么生成的文档在很强的意义上与 *A* 绑定。任何人都可以使用 *A* 的公钥来**解密**它；如果结果是一份合理的文档，那么它必定是由 *A* 加密的（唯一知道正确密钥的人）。如果结果是随机乱码，则该文档不是由 *A* 加密的。这就像 *A* 的签名：只有 *A* 能使其生效，它与 *A* 绑定，*A* 无法抵赖，并且没有人能在不破坏它的情况下篡改它（例如，试图使其成为他人的签名）。

数字签名可用于解决公钥加密系统的一个问题——保证 *A* 的公钥确实属于 *A*。如果有人设法分发他们自己的公钥但使其看起来像属于 *A*，他们就能读取所有发给 *A* 的消息。解决方案使用**证书颁发机构**，即通过收取费用来验证和确认公钥的组织。

*A* 将其公钥连同身份声明（“我真的是 *A*”）发送给证书颁发机构。证书颁发机构使用多种机制之一检查 *A* 是否真的是其声称的身份，并颁发一份包含 *A* 的公钥和 *A* 身份的文档，该文档使用证书颁发机构的私钥进行数字签名。任何想要检查 *A* 的公钥的人都可以使用证书颁发机构的公钥来解封此文档，并确保身份和公钥匹配。

当然，这意味着要信任证书颁发机构的公钥确实属于它；这可以通过依赖更高级别的证书颁发机构来实现（依此类推）。因此，这个过程是关于增加信心——腐败一个证书颁发机构比腐败 *A* 更难——但该过程不提供最终保证。

获取证书的成本是小型组织倾向于不使用公钥加密的一个主要原因（即使他们可以）。但证书一直是个烂摊子，因为它们往往在尴尬的时刻过期，而且大多数人遇到证书问题时，会继续做他们原本打算做的事。

另一种使用加密思想的技术是**数字哈希**。这里的目标是将某些数据映射为加密形式，但加密后的数据被强制限制在受限的大小内。我们不关心能否解密数据，因此只需要单向机制，即我们使用加密密钥但没有匹配的解密密钥。该思想的本质是：数据的加密形式即数字哈希，由于加密的特性（明文的任何微小变化都应产生密文的巨大变化），它是整个数据的紧凑表示。

由于初始数据集可以任意多，但加密形式的数量限制在固定大小的结果中，因此这种映射不能保证为所有初始集合产生唯一的哈希，但如果固定大小不太小，冲突极不可能发生。例如，如果固定大小为 32 字节，则有 2²⁵⁶ 种可能的数字哈希，远超将来存在的文档数量。

我们要求该映射以加密相同的方式混淆输入和输出之间的关系。两个相似的初始数据片段必须产生截然不同的哈希，并且在知道某些明文及其哈希的情况下，不得能推断出另一个哈希到相同值的明文。

数字哈希是一组数据整个内容的一种摘要，但如果没有密钥知识就无法操纵它。它用于创建文档或应用程序代码的紧凑表示，以便检查其完整性。应用程序开发者可以提供应用程序及其数字哈希；下载者可以从应用程序代码重新计算哈希，并检查答案是否与原始哈希匹配，以验证应用程序未被恶意篡改或在传输中损坏。

## 3.4 加密的应用

加密的基本目的是允许双方进行私密通信，即消除窃听的可能性。在网络空间中需要加密，因为数据从源到目的地的路径上，对其去向和方式几乎没有控制。

加密的设计初衷是使得在不知道适当密钥的情况下，实际上无法解密数据。即使在那些（号称）拥有“无密钥解密困难性证明”的系统中，这也并非总是成立。曾有政府信号情报机构游说推广已知但隐蔽缺陷的加密方案，以便在不知道密钥的情况下利用暴力破解，在合理的时间内完成解密。

理论上难以解密的加密系统的实现，可能会无意中引入捷径，使其在实践中变得脆弱。而且人们可能对密钥管理不善，将其留在系统中从而被窃取。

政府和执法部门经常进行如下讨论：“加密为恶人相互隐瞒通信提供了机会。因此，加密系统应配备后门，允许执法部门（在一定司法监督下）解密此类通信。”这些后门基本上就是解密密钥。

现在你可以看到，不可能既有后门，又能同时保持前门的坚固。在设计良好的加密系统中，解密消息的唯一途径是使用解密密钥。为了创建后门，执法部门将不得不坚持持有每个人解密密钥的副本。这些密钥将成为全球价值最高的攻击目标之一，因为获取它们将使海量数据以未加密形式暴露。存放它们的保险库必须受到相应的保护，不仅要防范外部攻击者，还要防范可能被收买的内部人员，或那些难以抗拒诱惑、解密其喜爱的名人的邮件或健康检测结果的内部人员。各国公民对政府保护这些密钥的技术能力，以及其仅在法律授权下使用它们的意愿，信任程度远未达到要求。

因此，内容要么可以为所有人受到加密保护，要么无人受保护，但不可能只保护“良性”通信，同时允许执法或情报机构读取“恶性”通信。不存在中间地带。

这也是互联网的全球触达与国家政府想要持有密钥副本的愿望发生冲突的另一个领域。几乎没有什么能阻止个人（更不用说跨国企业）在另一个司法管辖区获取他们的加密密钥；而政府很难证明他们已经这样做了。出于这两个实际但不可避免的原因，将解密密钥托管在某种托管机构中的提议行将就木。与我们生活的大多数其他方面不同，我们的网络空间存在受国家边界约束要少得多。这将是一个持续的主题。

不幸的是，加密可以隐藏通信的*内容*，但无法隐藏通信的*事实*，因为数据必须能够由不可信的中介传递。这造成了另一种漏洞，虽然不那么关键，但潜在影响重大。

在 20 世纪初，大英帝国开发了*全红线*，一个仅经过英国控制领土的电报网络，正是为了防止截获。在网络空间中无法做到这一点，因为通信的端点无法控制其传输路径。因此，对手原则上可以记录两个端点之间流动的数据量及频率，即使内容本身被加密。这被称为*流量分析*，可能极具启示性，特别是当端点未将其纳入考量时。

正如我们将看到的，加密在保卫网络空间中发挥着重要作用，但仍有大量方法可以颠覆它。

# 第 4 章 节点安全

正如我们所见，网络空间中的节点既包括计算机，从某种意义上说也包括人。将网络空间中的计算机划分为几类是很有用的。

第一类是我们用来与在线信息交互、相互通信的计算机（和手机）。我们可以称之为*边缘节点*。

第二类是组织用来运营业务的计算机，通常规模更大、算力更强。这些包括后端处理，如记录你的资金、运行自动化工厂、规划零售店补货的方式和时间、以及执行数据分析以理解复杂系统。其中一些计算机隐性地对普通用户可见，例如向你的浏览器提供网页的 Web 服务器，或旅行预订网站，但许多则不那么可见。

第三类是*云*，协同工作的大型计算机群，可供企业使用，而无需拥有和管理自己的计算资源。云与其他计算资源的重要区别在于，云被设计为*共享*的，这带来了新的安全问题。

第四类是包含联网计算机但没有直接可用界面的设备，*物联网*设备。这些大多是传感器或执行器，例如智能恒温器、监控摄像头、智能灯泡或耳塞。一些几乎完全自主工作，但大多数从互联网上的其他地方远程控制。例如，电力变压器开关从控制室远程控制；智能灯泡从某人手机上的应用程序控制。

虽然将节点视为*计算*资源是很自然的，但也存在主要目的为存储数据并在被请求时提供数据的节点。这些可能是专用的（例如数据库服务器）或特殊形式的数据云。

据估计，联网设备超过 200 亿台，因此节点数量远超人口数量。

## 4.1 获取节点访问权限

节点安全的首要问题之一是允许谁访问它们。我们都有边缘节点的经验——我们的个人电脑和手机受到保护，只有我们能通过密码或生物识别等机制访问它们。网络安全中最大的弱点之一在于，获取节点合法访问权限的机制——*认证*——薄弱不堪，对于物联网设备而言，往往极其薄弱。

我们可以将认证机制分为三类：你知道的东西、你拥有的东西、或你本身的特征。

### 你知道的东西

“你知道的东西”最常见的例子是*密码*。你知道它，你用来认证的系统也知道它（以某种形式），但其他人不应该知道。

你用于认证的系统不应以明文形式存储你的密码，因为那样任何设法入侵系统的人都将获得其所有账户的访问权限。为避免这种情况，密码以数字哈希形式存储。当你输入密码时，你输入的文本会立即使用相同的映射进行哈希运算，并将结果与存储的版本进行比较。如果匹配，你就通过了认证。

#### 系统漏洞与密码安全

系统漏洞可能导致所有哈希版本被窃取，但由于数字哈希的特性，无法直接将这些哈希值映射回生成它们的密码。遗憾的是，虽然成本较高，但确实存在推算出原始密码的方法。用于创建哈希密码的标准数字哈希算法只有几种，因此攻击者可以从将这些算法应用于“a”、再应用于“b”开始，依此类推使用越来越长的单词。最终，某个单词会映射到已知的哈希值，该单词即为密码。

这就是为什么密码建议设置得较长（因为必须尝试许多可能的文本字符串才能找到正确的那个）并包含不常用字符（因为这增加了必须检查的文本字符串的多样性）。攻击者无需太高的技巧即可先尝试常见的密码选择，然后是字典中的单词，接着是日期，最后才诉诸暴力搜索。这就是为什么常见的建议是创建不属于这些可预测类别的密码。请注意，攻击者可以预先计算出所有短于特定长度的潜在单词的哈希值，因此攻入新账户的边际成本非常低。
