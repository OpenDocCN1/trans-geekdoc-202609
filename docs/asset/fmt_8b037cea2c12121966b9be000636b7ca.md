## 14.4 拒绝采样

应用前面报告的技术依赖于以方便的（解析）形式获得所涉及的变换函数，这通常是例外而非规则。从现在开始，我们将注意力转向替代方法。

*拒绝采样*（例如，\[7,37\]）在概念上是一种简单的技术；为了从期望的概率密度函数 *p*(**x**) 生成独立样本，人们从另一个更容易处理的分布，比如说 *q*(**x**) 中抽取样本，然后不应用变换，而是根据适当的准则*拒绝*其中一些点。

给定两个随机变量 x 和 u，回顾一下，边缘分布 *p*(*x*) 是通过对联合概率密度函数 *p**x*, *u* 积分获得的，即

现在让我们考虑以下恒等式：

$$p(x) \equiv \int_0^{p(x)} 1 \, dx = \int_{-\infty}^{+\infty} \chi_{[0, p(x)]}(u) \, du$$

其中 $\chi_{[0, p(x)]}(\cdot)$ 是我们熟悉的区间 $[0, p(x)]$ 上的特征函数，即

$$

\chi_{[0, p(x)]}(u) = \begin{cases}

1, & \quad 0 \leqslant u \leqslant p(x), \\

0, & \quad \text{其他情况}。

\end{cases}

$$

对比公式 (14.21) 和 (14.22)，结果表明 $\chi_{[0, p(x)]}(u)$ 可以解释为定义在集合

$$\mathcal{A} = \{(x, u) : x \in \mathbb{R}, 0 \le u \le p(x)\}$$

上的二元组 $(x, u)$ 的联合 PDF。

仔细观察 $p(x, u) = \chi_{[0, p(x)]}(u)$，不难发现这是图 $u = p(x)$ 下方区域的**均匀密度**，如图 14.5A 所示。换句话说，如果在图 14.5A 的阴影区域中均匀随机填充点 $(x, u)$，然后忽略 $u$ 维度，则得到的点即为从 $p(x)$ 中抽取的样本。

我们可以更进一步，假设 $p(x)$ 并不完全已知，即：

$$

p(x) = \frac{1}{Z}\phi(x),

$$

且归一化常数不可用（正如我们所知，计算归一化常数通常并不容易）。此时我们有：

$$

p(x) = \frac{1}{Z}\phi(x) = \frac{1}{Z}\int_{0}^{\phi(x)} du = \frac{1}{Z}\int_{-\infty}^{+\infty} \chi_{[0, \phi(x)]}(u) du,

$$

$Z$ 由下式给出：

$$

Z = \int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} \chi_{[0, \phi(x)]}(u) \, du \, dx.

$$

因此，

$$

p(x) = \frac{\int_{-\infty}^{+\infty}\chi_{[0,\phi(x)]}(u)\ du}{\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty}\chi_{[0,\phi(x)]}(u)\ du\ dx}.

$$

![Equation](img/si109.png) (14.24)

换句话说，即使 $p(x)$ 不完全已知，仍可得到 $p(x)$，此时是用均匀分布 $\chi_{[0,\phi(x)]}(x, u)$ 并适当归一化来表示。然而，重新缩放均匀分布不影响边缘分布。只需在区域 $\mathcal{A}$ 内均匀随机采样即可，该区域现在应用 $\phi(x)$ 而非 $p(x)$ 来定义。通过考虑扩展空间 $(\mathbf{x}, u)$，前述内容也适用于随机向量 $\mathbf{x} \in \mathbb{R}^{(l)}$，此时我们讨论的是曲面 $\phi(\mathbf{x})$（或 $p(\mathbf{x})$）下方的体积。

![Figure 14.5 (A) Filling in the shaded area uniformly at random with points (xn,un), after neglecting the coordinate un, is equivalent to drawing points xn from p(x). (B) The proposal distribution, cq(x), is everywhere larger than or equal to ϕ(x).](img/gr005.jpg)

**图 14.5** (A) 用点 $(x_n, u_n)$ 均匀随机地填充阴影区域，忽略坐标 $u_n$ 后，等同于从 $p(x)$ 中抽取点 $x_n$。(B) 建议分布 $c q(x)$ 处处大于或等于 $\phi(x)$。

我们现在转而关注如何用均匀随机点填充由 $u = \phi(\mathbf{x})$（若完全可用则为 $u = p(\mathbf{x})$）形成的曲面下方的体积。设 $q(\mathbf{x})$ 为一个我们知道如何从中抽取样本的分布；我们称之为*建议分布*。我们选择一个常数 $c$ 使得^[¹⁰⁷]

$$

\phi(\mathbf{x}) \le c q(\mathbf{x}),\ \forall \mathbf{x} \in \mathbb{R}^{(l)}.

$$

![Equation](img/si117.png)

相应的几何结构如图 14.5B 所示。目标是在区间 `[0, c*q*(x)]` 内绘制点，然后仅保留位于曲面 `u = ϕ(x)` 下方区域内的那些点。以下算法可完成此任务。

### 算法 14.2：拒绝采样

*   **对于** `i = 1, 2, …, N`，**执行**

    1.  采样 `x[i] ∼ q(x)`

    2.  采样 `u[i] ∼ 𝒰(0, c*q(x[i]))`

    3.  若满足以下条件则保留样本

        *   `u[i] ≤ ϕ(x[i])`

*   **结束循环**

接受点 `x` 的概率由下式给出：

```
Prob{ u ≤ ϕ(x) } = (1 / (c*q(x))) * ϕ(x)
```

而对所有可能的 `x` 值求和，接受样本的总概率等于

```
Prob{ acceptance } = (1/c) ∫ (ϕ(x)/q(x)) q(x) dx = (1/c) ∫ ϕ(x) dx
```

因此，如果 `c` 取较大值，最终保留的点只占一小部分。为了得到一个实用的算法，必须选择 `c*q(x)` 使其能很好地拟合 `ϕ(x)`。图 14.6A 是一个糟糕选择的示例，而图 14.6B 对应一个良好的示例。这就是拒绝采样*无法随维度良好扩展*的原因之一。在高维空间中，为保证 `c*q(x) ≥ ϕ(x)`，可能不得不选择一个过大的 `c` 值（问题 14.5）。

![图 14.6 (A) 如果 cq(x) 远大于 ϕ(x)，大多数样本会被拒绝（红点），效率低下。(B) 如果 cq(x) 和 ϕ(x) 匹配良好，大多数样本会被保留。](img/gr006.jpg)

图 14.6 (A) 如果 `cq(x)` 远大于 `ϕ(x)`，大多数样本会被拒绝（红点），效率低下。(B) 如果 `cq(x)` 和 `ϕ(x)` 匹配良好，大多数样本会被保留。

除了基本的拒绝采样方案外，还提出了许多变体，以克服选择一个“看起来像”目标分布的建议分布的困难。*自适应拒绝采样*就是一种这样的技术（参见，例如，[11]及其中的参考文献）。根据这种方法，建议分布是基于`ln p(x)`的导数自适应构建的。对于对数凹函数，这是一个非递减函数，可用于构建`p(x)`的包络函数。

尽管拒绝采样不适合困难的任务，但它仍被使用，有时以其更精炼的形式，从许多标准分布生成样本，例如高斯分布、伽马分布和学生 *t* 分布（参见，例如，[22]）。

## 14.5 重要性采样

*重要性采样*（IS）是一种用于估计期望的方法。设`f(x)`为随机向量变量`x`的已知函数，`x`按`p(x)`分布。如果能从`p(x)`中抽取样本，则公式(14.1)中的期望可按公式(14.2)近似。我们现在假设无法从`p(x)`中抽取样本，并进一步假设`p(x)`仅在归一化常数下已知，即

```
p(x) = (1/Z) * phi(x)
```

设`q(x)`为另一个可以从中抽取样本的分布。则我们可以写为

```
E[f(x)] = (1/Z) * ∫ f(x) * phi(x) dx
        = (1/Z) * ∫ f(x) * (phi(x) / q(x)) * q(x) dx
        ≈ (1/(N*Z)) * Σ f(x_i) * w(x_i)
```

其中`x[i]`，`i = 1, 2, …, N`，是从`q(x)`中抽取的样本。

$w(\mathbf{x}) := \frac{\phi(\mathbf{x})}{q(\mathbf{x})}$.

![Equation](img/si133.png) (14.26)

归一化常数可以很容易地得到为

$$

Z = \int_{-\infty}^{\infty} \phi(\mathbf{x}) \, d\mathbf{x} = \int_{-\infty}^{\infty} \left( \frac{\phi(\mathbf{x})}{q(\mathbf{x})} \right) q(\mathbf{x}) \, d\mathbf{x} \approx \frac{1}{N} \sum_{i=1}^{N} w(\mathbf{x}_i).

$$

![Equation](img/si134.png) (14.27)

结合公式 (14.25) 和 (14.27)，我们最终得到

$$

\mathbb{E}\left[ f(\mathbf{x}) \right] \approx \frac{\sum_{i=1}^{N} w(\mathbf{x}_i) f(\mathbf{x}_i)}{\sum_{i=1}^{N} w(\mathbf{x}_i)},

$$

![Equation](img/si135.png) (14.28)

或者

![Equation](img/fx001.jpg)

其中 $W(\mathbf{x}_i) = \frac{w(\mathbf{x}_i)}{\sum_{i=1}^{N} w(\mathbf{x}_i)}$ 为归一化权重。不难证明（问题 14.6），估计量

$$

\widehat{Z} = \frac{1}{N} \sum_{i=1}^{N} w(\mathbf{x}_i)

$$

![Equation](img/si137.png) (14.29)

对应于归一化常数的无偏估计量。这非常有趣，因为计算归一化常数在许多任务中是特别有用的信息。回顾一下第 12 章讨论的证据函数，它就是一个归一化常数；另见文献 [26] 的相关评论。

相比之下，与公式 (14.28) 相关的估计量，作为一个比率的结果，仅在渐近意义上是无偏的，对于有限的 `N` 值，它是一个 `biased`（有偏）估计量（问题 14.6）。因此，如果拥有非常大量样本 `N` 的奢侈条件，公式 (14.28) 将是一个足够好的估计。然而，在实践中，`N` 无法任意增大，由此产生的估计可能并不令人满意。

如果 `q(x) ≈ p(x)`，或者至少 `q(x)` 是 `ϕ(x)` 的一个相当好的近似，那么公式 (14.28) 将近似公式 (14.2)。然而，对于大多数实际情况，这并不容易实现，尤其是在高维空间中。如果 `q(x)` 与 `ϕ(x)` 不匹配，则很可能存在一些区域，在这些区域 `ϕ(x)` 很大而 `q(x)` 却小得多。相应的权重将具有相对于其他区域较大的值，并且它们将在求和中占主导地位（公式 (14.28)）。

其效果等同于减少样本数 `N`。此外，`q(x)` 在某些区域取极小值也是可能的，这使得在公式 (14.28) 中，来自这些区域的样本极有可能完全缺失（参见 图 14.7）。在这种情况下，不仅结果估计可能是错误的，而且我们不会意识到这一点，而权重 `w(x[n])` 和 `w(x[n])f(x[n])` 的方差可能表现出较低的值。*这些现象在高维空间中更加突出*（参见，例如，[26] 和问题 14.7）。

![图 14.7 如果 q(x) 不是 ϕ(x) 的良好匹配，会出现许多不良效应。来自区域 A 的样本将产生比区域 B 大得多的权重值。由于区域 C 中 q(x) 的值极低，考虑到样本数量 N 的有限性，极有可能不会从该区域抽取到任何样本，尽管这是 ϕ(x)(p(x)) 的最主要区域。](img/gr007.jpg)

为了缓解上述缺陷，已经提出了许多变体来搜索高概率区域，在模态周围进行局部近似，并利用它们来生成样本（参见，例如，[30] 及其参考文献）。

## 14.7 马尔可夫链蒙特卡洛方法

正如我们已经讨论过的，拒绝采样和重要性采样方法的一个主要缺点是它们无法很好地处理高维空间中的任务。

在本节中，我们将介绍那些能更好地随样本空间维度扩展的方法。这类技术建立在源自马尔可夫链理论的论证之上；我们首先给出一些与这一重要理论相关的定义和基础知识。隐马尔可夫模型（见第 16.5 章）是马尔可夫链的实例。在这里，我们将从另一个角度更深入地阐述此类模型。

马尔可夫链/过程以俄罗斯数学家安德烈·安德烈耶维奇·马尔可夫（Andrey Andreyevich Markov，1856–1922）命名，他在随机过程领域发表了开创性的论文。作为圣彼得堡大学的教授，在 1908 年的学生骚乱期间，他拒绝了政府监视和间谍其学生的命令，并辞去了大学职务。

### 定义 14.1

函数 $\mathcal{Q}(\boldsymbol{\xi}, \boldsymbol{\xi}^{(j)}) = \mathbb{E}[\ln p(\mathcal{X}^{(l)}, \mathcal{X}; \boldsymbol{\xi})] = \int p(\mathcal{X}^{(l)}|\mathcal{X}; \boldsymbol{\xi}^{(j)}) \ln p(\mathcal{X}^{(l)}, \mathcal{X}; \boldsymbol{\xi}) d\mathcal{X}^{(l)}$，其中 $\mathcal{X}^{(l)}$ 是隐变量集合，$\mathcal{X}$ 是观测值集合，$\boldsymbol{\xi}$ 是未知参数集合。
