## 14.6 钓鱼 URL 检测

钓鱼 URL 是网络安全面临的主要威胁之一，它导致了垃圾邮件、身份盗用、金融欺诈等各种网络攻击。互联网的增长增加了网络欺诈活动的频率。黑名单等传统方法在处理钓鱼网站的变体时效率低下，而且无法检测到新的恶意网站。传统方法需要人工干预来更新钓鱼网站的数据库。基于机器学习（ML）的解决方案在解决安全领域的挑战性问题上显示出良好的前景。在这种情况下，我们提出了深度学习（机器学习的一个子集）来检测和分类钓鱼网站。在这项工作中，我们使用了各种深度学习架构，如 `CNN`、`RNN`、`LSTM`、`GRU` 和 `IRNN`。文中提到的实验运行了最多 1001 个轮次（`epochs`），学习率范围在 [0.01–0.05] 之间。

### 14.6.1 钓鱼检测的数据描述

第二个任务是检测钓鱼 URL 并将其分类为良性和恶性。用于准备数据的合法 URL 从 `Alexa` 和 `DMOZ` 目录爬取，而钓鱼 URL 则从 `Phishtank` 和 `OpenPhish` 爬取。数据统计结果列如表 14.19 所示。URL 被随机分为训练数据和测试数据。这些数据集使用文本编码转换为数值格式。

### 14.6.2 URL 表示

在任何机器学习任务中，数值格式的数据表示都非常重要。文本编码将原始特征转换为数值。文本表示主要有两种类型——文本的序列表示和非序列表示。序列化表示保留了词序，而非序列表示则不保留词序。我们使用了文本的序列表示。序列化表示涉及将句子分词为单词，并将单词拆分为字符。在预处理阶段，大写字母被替换为小写字母。词汇表使用小写训练字符构建。第二步是通过训练数据创建词汇表。词汇表的大小在每个类别的训练向量与学习给定任务所需的参数数量之间起到平衡作用。输入文本被转换为列表。列表中的每个唯一字符被分配一个数字。每个唯一 ID 是一个表示词汇表大小的向量。这些唯一字符通过查找表操作转换为特征向量。这些连续向量被作为输入到 `RNN`、`CNN`、`LSTM`、`GRU`、`IRNN` 和经典的机器学习技术。

## 14.7 基于机器学习的网络安全提议架构

在计算机安全领域，计算机技术的使用日益增长，这使得它在我们社会中变得至关重要。根据2008年的国家统计数据，英国65%的家庭已连接到互联网，大约相当于1600万户（国家统计数据 2008）。此外，近年来，计算机恶意软件的数量在快速增加。计算机用户始终面临着风险，即使系统没有连接到互联网也是如此。此外，无人看守的系统容易受到未经授权的访问和系统滥用。如果计算机连接到网络，攻击的风险将进一步增加。在这种情况下，世界各地的任何用户都可以远程访问任何计算机，并尝试访问个人和机密信息。这些攻击通常通过侵入、钓鱼类URL实施。为了应对侵入和钓鱼类URL的增加，我们为机构提出了一个网络威胁态势感知平台。所提系统的高层架构如图14.9所示。

## 14.8 结论与未来工作

这项工作分析了监督和无监督学习技术在侵入和钓鱼URL中的有效性。经典机器学习分类器对 `KDD-Cup-99` 侵入数据的检测率与其他方法密切相当。实验通过完整数据集和最少特征进行了评估，以理解每个特征的重要性。基于 `DNN` 的分类优于所有经典的机器学习技术。这可以通过促进训练、在现有架构中堆叠更多层数，或向现有数据中添加新特征来改进。在大多数情况下，低频攻击类别产生单条连接记录；然而，当隐藏在其他连接记录中时，`DNN` 在检测率上的性能优于 `KDD-Cup-99` 挑战赛获奖作品和其他发表的结果。由于深度学习架构计算开销高，我们未能采用其他架构。未来的工作可以包含使用 `CNN`、`LSTM`、`GRU`、`IRNN` 等其他深度学习架构的分类，以及如 `CNN-LSTM` 等混合网络。当模型被构建为无监督学习问题时，检测率很高。`M-ZOOM` 框架展示了无监督学习的潜力。在钓鱼 URL 检测方面，`CNN-LSTM` 表现最佳。在这项工作中，我们从机构角度出发，提出了一种基于 AI 的态势感知平台，用于检测侵入和钓鱼 URL。所提架构中的投票方案是未来工作的方向。
