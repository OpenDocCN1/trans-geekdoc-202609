
我们无法确定 IC 的顺序。确实，如果已恢复 `A` 和 `z`，且 `P` 是一个置换矩阵，那么 `AP^(-1)` 和 `Pz` 也是解，因为 `Pz` 的分量与 `z` 的分量相同，只是顺序不同（具有相同的统计特性）。

### 20.5.3 非高斯性与独立成分

随机变量 `z` 的四阶（自）累积量，

```
κ4 = 𝔼[z⁴] − 3(𝔼[z²])²
```

被称为该变量的`峰度`，它是`非高斯性`的一种度量。服从高斯分布的变量峰度为零。次高斯变量（在相同方差下，其概率密度函数衰减速率低于高斯分布的变量）具有负峰度。超高斯变量（对应于衰减速率高于高斯分布的概率密度函数）具有正峰度。因此，如果我们保持方差固定（例如，将变量归一化为单位方差），最大化平方峰度之和，就会导致最大化恢复 IC 的非高斯性。通常，恢复 IC 的峰度绝对值被用作对它们进行排序的度量。如果 ICA 被用作特征生成技术，这一点很重要。图 20.8 展示了一些典型的次高斯和超高斯示例，以及相应的高斯分布。

![图 20.8 高斯分布（实心灰线）、超高斯分布（红色虚线）和次高斯分布（实心红线）。](img/gr008.jpg)

图 20.8 高斯分布（实心灰线）、超高斯分布（红色虚线）和次高斯分布（实心红线）。

回顾第 12 章（第 12.8.1 节），高斯分布是在方差和均值约束下使熵最大化的分布。换句话说，在这些约束下它是最随机的，从这个角度来看，它关于数据潜在结构的信息量最少。相反，与高斯分布最不相似的分布更有趣，因为它们能更好地揭示与数据相关的结构。这一观察构成了`投影追踪`的核心，后者与 ICA 技术族密切相关。这些技术的本质是在特征空间中寻找方向，使得数据在这些方向上的投影可用非高斯分布来描述 [97,106]。

### 20.5.4 基于互信息的 ICA

基于将二阶和四阶交叉累积量置零的方法并非唯一途径。另一种途径是通过最小化潜在变量之间的`互信息`来估计 `W`。互信息的概念在第 2.5 节中已介绍。在公式 (2.158) 的基础上稍作详述，并对右侧进行积分（针对两个以上变量的情况），可以很容易地证明：

```
I(z) = - H(z) + ∑(i=1 to l) H(z_i)
``` (20.51)

其中 $H(z_i)$ 是 $z_i$ 相关的熵，定义见公式 (2.157)。在第 2.5 节中已表明，$I(\mathbf{z})$ 等于联合概率密度函数 (PDF) $p(\mathbf{z})$ 与各边缘概率密度乘积 $\prod_{i=1}^{l} p_i(z_i)$ 之间的 Kullback-Leibler (KL) 散度。KL 散度（因此相关的互信息 $I(\mathbf{z})$）是非负量，当分量 $z_i$ 统计独立时，它变为零。这是因为只有在这种情况下，联合 PDF 才等于相应边缘 PDF 的乘积，从而使 KL 散度为零。因此，现在的思路变为计算 $W$ 以使 $I(\mathbf{z})$ 最小化，因为这将使 $\mathbf{z}$ 的分量*尽可能独立*。将公式 (20.45) 代入公式 (20.51) 并考虑联系 $\mathbf{x}$ 和 $\mathbf{z}$ 这两个 PDF 的公式（公式 (2.45)），我们得到

```
I(\mathbf{z}) = - H(\mathbf{x}) - \ln|\text{det}(W)| - \sum_{i=1}^{l} \int p_i(z_i) \ln p_i(z_i)  dz_i.
```

(20.52)

未知矩阵 $W$ 的元素也隐藏在潜在变量 $z_i$ 的边缘 PDF 中。然而，要显式地表达这种依赖关系并不容易。一种可能性是遵循 Edgeworth 展开（附录 B），将每一个边缘密度在标准高斯 PDF（此处记为 $g(z)$）周围展开，并将级数截断为合理的近似。例如，保留 Edgeworth 展开中的前两项，我们得到

$p_{i}(z_{i}) = g(z_{i})\left( 1 + \frac{1}{3!}\kappa_{3}(z_{i})H_{3}(z_{i}) + \frac{1}{4!}\kappa_{4}(z_{i})H_{4}(z_{i}) \right),$

其中 $H_{k}(z_{i})$ 是 $k$ 阶埃尔米特多项式（附录 B）。为了得到用 $z_{i}$ 的累积量（零均值并归一化为单位方差）和 $W$ 表示的 $I(\mathbf{z})$ 的近似表达式，我们可以（a）将公式 (20.53) 中的 PDF 近似代入公式 (20.52) 中，（b）采用近似 $\ln(1 + y) \approx y - y^{2}$，以及（c）执行积分。这无疑是一项相当痛苦的任务！对于公式 (20.53) 的情况并约束 $W$ 为正交矩阵，可以得到以下近似（例如，[57]）：

```
I(\mathbf{z}) \approx C - \sum\limits_{i = 1}^{l}\left( \frac{1}{12}\kappa_{3}^{2}(z_{i}) + \frac{1}{48}\kappa_{4}^{2}(z_{i}) + \frac{7}{48}\kappa_{3}^{4}(z_{i}) - \frac{1}{8}\kappa_{3}^{2}(z_{i})\kappa_{4}(z_{i}) \right),
```

其中 $C$ 是一个与 $W$ 无关的量。假设 PDF 是对称的（因此三阶累积量为零），可以证明，最小化公式 (20.54) 中互信息的近似表达式等价于最大化四阶累积量平方和。请注意，正交 $W$ 约束并非必要，如果不采用该约束，将得到 $I(\mathbf{z})$ 的其他近似表达式（例如，[91]）。

可以通过梯度下降技术（第 5 章）最小化公式 (20.54) 中的 $I(\mathbf{z})$，其中涉及的期望（与累积量相关）被相应的瞬时值所替代。虽然我们不会详细推导算法方案，但为了了解其中涉及的技巧，让我们回到应用近似之前的公式 (20.52)。因为 $H(\mathbf{x})$ 不依赖于 $W$，最小化 $I(\mathbf{z})$ 等价于最大化

$$

J(W) = \ln|\det(W)| + \mathbb{E} \left[ \sum_{i = 1}^{l} \ln p_{i}(z_{i}) \right].

$$

对代价函数关于 $W$ 求梯度可得

$$

\frac{\partial J(W)}{\partial W} = W^{-T} - \mathbb{E}\left[ \boldsymbol{\phi}(\mathbf{z})\mathbf{x}^{T} \right],

$$

其中

$$

\boldsymbol{\phi}(\mathbf{z}) := \left[ - \frac{p_{1}^{\prime}(z_{1})}{p_{1}(z_{1})}, \ldots, - \frac{p_{l}^{\prime}(z_{l})}{p_{l}(z_{l})} \right]^{T},

$$

且

$$

p_{i}^{\prime}(z_{i}) := \frac{dp_{i}(z_{i})}{dz_{i}}.

$$

![Equation](img/si225.png) (20.58)

并且我们使用了公式

$$

\frac{\partial \text{det}(W)}{\partial W} = W^{-T} \text{det}(W).

$$

![Equation](img/si226.png)

显然，边缘概率密度的导数取决于每种情况下采用的近似类型。现在第 *i* 次迭代步的一般梯度上升方案可以写为

$$

W^{(i)} = W^{(i-1)} + \mu_i \left( (W^{(i-1)})^{-T} - \mathbb{E} [\boldsymbol{\phi}(\mathbf{z}) \mathbf{x}^T] \right),

$$

![Equation](img/si227.png)

或者

$$

W^{(i)} = W^{(i-1)} + \mu_i \left( I - \mathbb{E} [\boldsymbol{\phi}(\mathbf{z}) \mathbf{z}^T] \right) (W^{(i-1)})^{-T}.

$$

![Equation](img/si228.png) (20.59)

在实践中，忽略期望算子并用相应的观测值替换随机变量，这符合随机近似的基本原理（第 5 章）。

公式 (20.59) 中的更新方程涉及当前 `W` 估计值的转置求逆。除了计算复杂度问题外，在自适应过程中无法保证可逆性。使用所谓的*自然梯度* [68] 代替公式 (20.56) 中的梯度，可得

$$

W^{(i)} = W^{(i-1)} + \mu_i \left( I - \mathbb{E} [\boldsymbol{\phi}(\mathbf{z}) \mathbf{z}^T] \right) W^{(i-1)},

$$

![Equation](img/si229.png) (20.60)

这既不涉及矩阵求逆，同时又能改善收敛性。对该问题的更详细处理超出了本书的范围。仅为对数学感兴趣的读者深入钻研该领域提供一点激励，只需说明：我们熟悉的梯度，即公式 (20.56)，若空间是欧氏空间，则指向最陡上升方向。然而，在我们的情况下，参数空间由所有非奇异的 *l* × *l* 矩阵组成，这是一个乘法群。该空间是黎曼空间，结果表明，指向最陡上升方向的自然梯度，是通过将公式 (20.56) 中的梯度乘以 *W*^(*T*)*W* 得到的，后者是相应的黎曼度量张量 [68]。

#### 备注 20.4

*   从公式 (20.56) 中的梯度可以很容易地看出，在驻点处以下关系成立：

```
∂J(W)/∂W * W^T = E[I - φ(z)z^T] = O.
```

*   换句话说，我们用 ICA 实现的是 PCA 的*非线性推广*。回想一下，对于后者，不相关性条件可以写为

```
E[I - zz^T] = O.
```

*   *非线性*函数 **φ** 的存在使我们超越了简单的不相关性，并引入了累积量。事实上，公式 (20.61) 正是启发 ICA 早期开创性工作的公式，作为 PCA 的直接非线性推广 [93,107]。

*   ICA 的起源可追溯到开创性论文 [93]。多年来，它主要局限于法国信号处理和统计学界。两篇论文对其广泛应用和普及起到了催化作用，即 1990 年代中期的 [18] 以及 `FastICA` 的开发^(¹⁵⁷)。

*   在机器学习中，将 ICA 用作特征生成技术的理由基于以下论点。文献 [17] 指出，视觉皮层特征检测器执行的早期处理结果可能是*冗余度降低*过程的结果。因此，在给定输入数据的条件下寻找独立特征，符合这一主张（参见，例如，[75,114] 及其参考文献）。

*   虽然我们专注于无噪声情况，但 ICA 向有噪声任务的扩展也已被提出（参见，例如，[100]）。关于复值情况下 ICA 的扩展，请参见 [2]。非线性扩展也已被考虑，包括核化 ICA 版本（例如，[13]）。

*   在文献 [3] 中，ICA 的处理也涉及随机过程，可以识别包括高斯信号在内的更广泛的信号类别。

*   在文献 [7] 中，讨论了*独立向量分析*（IVA）的多集 ICA 框架。结果表明，如果考虑二阶以外的高阶统计量，它推广了多集 CCA。

### 20.5.5 ICA 的替代路径

除了前面讨论的两条 ICA 路径外，还提出了许多替代方案，从不同方面阐释了该问题。一些值得注意的方向如下。

*   *Infomax 原理*：该方法假设潜在变量是以下形式的非线性系统（神经网络，第 18 章）的输出

```
z[i] = φi + η,  i = 1, 2, …, l,
```

*   其中 `φ[i]` 为非线性函数，`η` 为加性高斯噪声。权重向量 `w[i]` 的计算旨在最大化输出的熵；其推理基于关于网络中信息流动的一些信息论论据 [18]。

*   *最大似然*：从公式 (20.44) 出发，观测变量的 PDF 以独立分量的 PDF 形式表示

#### 独立成分分析 (ICA) 的数学基础

$$

p(\mathbf{x}) = |\text{det}(W)| \prod_{i=1}^{l} p_i(\mathbf{w}^T \mathbf{x}_i)

$$

![Equation](img/si236.png)

其中

`W = A^{-1}`

![Equation](img/si237.png)

*   假设我们有 `N` 个观测值，`x[1], x[2], ..., x[N]`，并对联合概率 `p(x[1], ..., x[N])` 取对数，可以关于 `W` 最大化对数似然。很容易推导出对数似然函数，并观察到它与公式 (20.55) 中给出的 `J(W)` 非常相似。`p[i]` 的选择使其属于非高斯分布族（例如，[100]）。Infomax 方法与最大似然方法之间的联系已在 [37,38] 中建立。

*   **负熵**：根据这种方法，出发点是最大化非高斯性，现在用 **负熵** 来度量，定义为

    $$

    J(\mathbf{z}) := H(\mathbf{z}_{\text{Gauss}}) - H(\mathbf{z})

    $$

    ![Equation](img/si242.png)

    其中 `z_Gauss` 对应于具有相同协方差矩阵的高斯分布变量，这对应于最大熵 `H`。因此，最大化负熵（一个非负函数）等同于使潜在变量尽可能不呈高斯分布。通常采用负熵的近似，用高阶累积量表示，或通过将非线性与源分布匹配来表示 [100,141]。

*   如果解混矩阵被约束为正交，则负熵和最大似然方法变得等价 [2]。

#### 鸡尾酒会问题

一个展示 ICA 力量的经典应用是所谓的 **鸡尾酒会问题**。在一个聚会中，有各种人在说话；在我们的例子中，我们也将考虑音乐。假设有两个人（一男一女）以及单声道音乐，总共三个声源。然后，在房间的不同位置放置三个麦克风（与声源数量相同）并记录混合语音信号。我们将三个麦克风的输入分别表示为 `x1`, `x2` 和 `x3`。在最简单的模型中，三个记录的信号可以被视为单个源信号的线性组合。不考虑延迟。目标是使用 ICA 从记录的混合信号中恢复原始语音和音乐。

为此，为了将任务置于我们之前采用的公式化框架中，我们将三个信号在不同时刻的值视为相应随机变量 `x[1]`、`x[2]` 和 `x[3]` 的不同观测值，将它们组合在一起形成随机向量 `x`。我们进一步采用一个非常合理的假设：原始源信号，记为 `s1`、`s2` 和 `s3`，是相互独立的，（类似于之前）不同时刻的值对应于三个潜在变量的值，将它们一起记为随机向量 `s`。

现在我们准备应用 ICA 来计算解混矩阵 `W`，从中我们可以获得对应于三个麦克风接收到的观测值的独立成分（IC）的估计值，

```
z(t) = z[1, z2, z3]^(T) = Wx[1, x2, x3]^(T)
```

图 20.9A 展示了三个不同的信号，它们被线性组合（由一组定义混合矩阵 `A` 的混合系数）形成三个“麦克风信号”。图 20.9B 展示了结果信号，随后按前述方法用于 ICA 分析。图 20.9C 展示了恢复的原始信号，作为相应的独立成分。采用了 FastICA 算法。^(¹⁵⁸)

请注意，鸡尾酒会问题代表了一大类任务，在这些任务中，若干记录信号是其他独立信号的线性组合；目标是恢复后者。此类任务的一个著名应用见于脑电图（EEG）。EEG 数据由头皮不同位置（或最近的耳内 [112]）记录的电位组成，这些电位是由大脑和肌肉活动的不同潜在成分组合产生的。任务是利用 ICA 恢复这些成分，进而可以揭示关于大脑活动的有用信息（例如，[158]）。

鸡尾酒会问题被称为*盲源分离*（BSS）这一更一般任务类别的典型例子。在这些任务中，目标是仅基于驻留在观测值中的信息来估计“因果”（源、原始信号），而没有任何其他额外信息，这就是使用“盲”一词的原因。从另一个角度来看，BSS 是无监督学习的一个例子。ICA 是此类问题中最广泛使用的技术之一。
