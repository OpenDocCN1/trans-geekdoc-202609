
在鸢尾花数据集上，第一主成分将保留 92.5% 的总方差。前两个主成分将保留 97.7% 的总方差。加上第三主成分将达到 99.5%。对于鸢尾花数据集，我们可以放心地将维度从四维降至三维，同时保留原始数据 99.5% 的方差。

## 何时使用 PCA

AI 算法假设特征是相互独立的。如果我们希望使特征独立，那么 PCA 将是正确的选择。通过 PCA，如果少数主成分能够保留我们所需的方差，我们还能降低数据的维度，当然这取决于数据本身。

在原始数据中，每个维度代表一个特征。这些特征传达了关于所考虑样本的含义。然而，当通过 PCA 降维后，降维后数据的维度/特征可能无法用于理解样本。如果你想保留每个维度的含义，请勿使用 PCA 进行降维。

## t-SNE

**t 分布随机邻域嵌入**（`t-SNE`）`[1]` 是一种无监督非线性降维技术，适用于将高维数据在二维或三维空间中可视化。t-SNE 计算高维空间中数据之间的相似度度量及其在低维空间中对应点之间的相似度度量，然后优化这两种相似度。

让我们考虑一个包含 `n` 个样本 $x_i$ 的数据集，这些样本属于高维空间 $\mathbb{R}^D$，它们将被映射为低维空间 $\mathbb{R}^d$ 中的 `n` 个样本 $y_i$，其中 $d \ll D$。计算高维空间中的成对相似度。然后，寻找 $y_i$，使得低维空间中的成对相似度度量等于其在高维空间中对应的相似度度量。

两个样本 $x_i, x_j$ 之间的相似度是条件概率 $p_{j|i}$，即如果邻居按以 $x_i$ 为中心的高斯分布下的概率密度成比例被选取，$x_i$ 会选取 $x_j$ 作为其邻居（在高维空间 $\mathbb{R}^D$ 中）。其定义如下：

$$p_{j|i} = \frac{\exp(-\|x_i - x_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|x_i - x_k\|^2 / 2\sigma_i^2)}$$

其中 $\sigma_i$ 是以 $x_i$ 为中心的高斯分布的方差。确定 $\sigma_i$ 的方法将在后面讨论。因为我们只关心成对相似度，所以可以设定 $p_{i|i} = 0$。当 $x_i$ 是异常值时，高维空间中的这种成对相似度会导致问题。对于异常值，概率值会极小 $p_{j|i} \approx 0$，导致对应映射的 $y_i$ 的位置对代价函数影响甚微。因此，异常值 $x_i$ 的映射位置 $y_i$ 无法被很好地确定。通过在高维空间中定义联合概率 $p_{ij}$ 为对称的条件概率，可以克服这个问题：

$$p_{ij} = \frac{p_{j|i} + p_{i|j}}{2n}$$

这确保了对于 $i \neq j$ 有 $p_{ij} > 0$，结果是每个数据样本都对代价函数做出显著贡献。

现在，让我们计算低维空间中映射样本 $y_i, y_j$ 之间的相似度。在高维空间中，我们使用高斯分布将距离转换为概率。在低维映射中，我们可以使用比高斯分布拥有更重尾部的概率分布将距离转换为概率。这使得高维空间中的中等距离可以通过低维空间中大得多的距离来忠实建模。t-SNE 使用自由度为 1 的 Student $t$-分布（柯西分布）作为低维空间中的重尾分布。使用该分布，联合概率或成对相似度计算如下：

$$q_{ij} = \frac{(1 + \|y_i - y_j\|^2)^{-1}}{\sum_{k \neq l} (1 + \|y_k - y_l\|^2)^{-1}}$$

现在，我们得到了高维和低维空间中的相似度度量或联合分布。下一步是计算高维空间中联合概率分布 $P$ 与低维空间中联合概率分布 $Q$ 之间的单一 `库尔巴克-莱布勒散度`：

$$C = KL(P \| Q) = \sum_i \sum_j p_{ij} \log \frac{p_{ij}}{q_{ij}}$$

其中 $q_{ij} \neq 0$。我们必须学习优化该代价函数的参数。可以使用梯度下降来学习参数。该代价函数的梯度函数如下：

$$\frac{\partial C}{\partial y_i} = 4 \sum_j (p_{ij} - q_{ij}) (y_i - y_j) (1 + \|y_i - y_j\|^2)^{-1}$$

## 选择 $\sigma_i$

高斯分布的带宽由 $\sigma_i$ 的值控制。由于数据密度的变化，不太可能存在一个对所有样本都最优的单一 $\sigma_i$ 值。在稠密区域，比在稀疏区域更适合使用较小的 $\sigma_i$ 值。$\sigma_i$ 的值在所有数据样本上诱导出概率分布 $P_i$。该分布具有随 $\sigma_i$ 增加而增加的熵。我们可以对 $\sigma_i$ 的值执行二分搜索，使得生成的 $P_i$ 产生用户指定的困惑度。困惑度定义如下：

$$\text{Perp}(P_i) = 2^{H(P_i)}$$

其中 $H(P_i)$ 是 $P_i$ 的香农熵（以比特为单位），定义如下：

$$H(P_i) = -\sum_j p_{j|i} \log_2 p_{j|i}$$

困惑度的典型值范围为 [5, 50]。它可以被解释为有效邻居数量的平滑度量。

## PCA 与 t-SNE

PCA 是一种线性降维技术，旨在最大化方差并保留较大的成对距离。差异较大的数据样本最终会被分得很远。这可能导致较差的可视化效果，特别是在处理非线性流形结构时。可以将流形结构想象为圆柱体、球体或曲线。t-SNE 与 PCA 的区别在于它仅保留较小的成对距离或局部相似度，而 PCA 关注保留较大的成对距离以最大化方差。PCA 和 t-SNE 分别保留数据的全局结构和局部结构。

此外，t-SNE 有三个超参数，即学习率、步数和困惑度，而 PCA 没有。
