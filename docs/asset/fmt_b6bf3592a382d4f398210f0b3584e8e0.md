简而言之，由 `x` 表示的模式被归入使后验概率最大的那个类别。有时，我们也将此规则称为*贝叶斯分类器*。

注意，在接收任何观测值之前，我们关于类别的不确定性通过先验类别概率来表达，记为 `P(ω[i])`，`i = 1, 2, …, M`。一旦获得了特征向量 `x`，这一额外信息消除了部分原始不确定性，相关的统计信息现在由后验概率提供，随后用于分类。

在公式 (7.1) 中应用贝叶斯定理，

$$P(\omega_{j}|\mathbf{x}) = \frac{p(\mathbf{x}|\omega_{j})P(\omega_{j})}{p(\mathbf{x})},\quad j = 1,2,\ldots,M,$$

其中 $p(\mathbf{x}|\omega_{j})$ 是相应的条件概率密度函数（PDF），贝叶斯分类规则变为

$$\text{将 } \mathbf{x} \text{ 归入 } \omega_{i} = \arg\max_{\omega_{j}} p(\mathbf{x}|\omega_{j})P(\omega_{j}),\quad j = 1,2\ldots,M.$$

注意，公式 (7.2) 分母中的数据概率密度函数 (PDF) $p(\mathbf{x})$ 不参与最大化任务，因为它是一个与类别 $\omega_{j}$ 无关的正量；因此，它不影响最大化过程。换句话说，分类器取决于先验类概率和相应的条件 PDF。此外，请回顾

$$p(\mathbf{x}|\omega_{j})P(\omega_{j}) = p(\omega_{j}, \mathbf{x}) = p(y, \mathbf{x}),$$

在当前语境中，输出变量 $y$ 表示与相应类别 $\omega_{i}$ 关联的标签。最后一个方程验证了第 3 章所述内容；即贝叶斯分类器是一种生成式建模技术。

## 估计相关量

我们现在转向如何获得相关量的估计。回顾一下，在实践中，我们手头拥有的只是一组训练数据，必须从中获得先验概率以及条件概率密度函数（PDF）的估计。假设我们得到一组训练点 $(y_n, \mathbf{x}_n) \in \mathcal{D} \times \mathbb{R}^l, n = 1, 2, \dots, N$，其中 $\mathcal{D}$ 是类别标签的离散集合，考虑包含 `M` 个类别的一般任务。假设每个类别 $\omega_i, i = 1, 2, \dots, M$ 在训练集中由 $N_i$ 个点表示，且 $\sum_{i=1}^M N_i = N$。那么先验概率可以近似为

$$P(\omega_i) \approx \frac{N_i}{N}, \quad i = 1, 2, \dots, M. \tag{7.4}$$

对于条件 PDF $p(\mathbf{x}|\omega_i), i = 1, 2, \dots, M$，可以动用任何估计 PDF 的方法。例如，可以为每个条件概率假设一个已知的参数形式，并采用第 3.10 节讨论的最大似然（ML）方法，或第 3.11.1 节讨论的最大后验（MAP）估计器，利用每个类别的训练数据来获得参数估计。另一种选择是采用非参数直方图类技术，如第 3.15 节讨论的 Parzen 窗和 $k$ 近邻密度估计技术。也可以采用其他 PDF 估计方法，如第 12 章将讨论的混合建模。感兴趣的读者也可参考文献 [38, 39]。

## 贝叶斯分类器最小化误分类误差

在第 3.4 节中指出，设计分类器的目标是将特征向量所在的空间划分为若干区域，并将每个区域唯一地关联到某一个类别。对于二分类任务（推广到多类别很简单），设 $\mathcal{R}_1, \mathcal{R}_2$ 为 $\mathbb{R}^l$ 中的两个区域，分别决定支持类别 $\omega_1$ 和 $\omega_2$。分类错误概率由下式给出：

### 7.2.1 平均风险

因为在分类中因变量（标签）`y` 具有离散性质，分类错误概率似乎是最自然的待优化代价函数。然而，情况并非总是如此。在某些应用中，并非所有错误都具有同等重要性。例如，在医学诊断系统中，将 X 光图像中某发现的类别预测为“恶性”而其真实类别为“正常”所犯的错误，不如相反方向的错误严重。前一种情况下，错误诊断会在下一轮医学检查中被揭示。然而，后一种情况可能导致不良后果。对于此类情形，人们会使用错误概率代价函数的一种替代形式，根据错误的重要性赋予其相对权重。该代价函数称为*平均风险*，它产生的判决规则类似于贝叶斯分类器，但因权重的存在而略有修改。

让我们从较简单的两类情况入手。与两个类别中的每一个相关联的*风险*或*损失*定义为

#### 最优平均风险分类器

##### 条件风险公式

对于类别 $\omega_1$ 的条件风险 $r_1$：

$$r_1 = \lambda_{11}\int_{\mathcal{R}_1}p(\mathbf{x}|\omega_1)d\mathbf{x} + \lambda_{12}\underset{\text{error}}{\underbrace{\int_{\mathcal{R}_2}p(\mathbf{x}|\omega_1)d\mathbf{x}}}$$

(7.7)

对于类别 $\omega_2$ 的条件风险 $r_2$：

$$r_2 = \lambda_{21}\underset{\text{error}}{\underbrace{\int_{\mathcal{R}_1}p(\mathbf{x}|\omega_2)d\mathbf{x}}} + \lambda_{22}\int_{\mathcal{R}_2}p(\mathbf{x}|\omega_2)d\mathbf{x}$$

(7.8)

##### 平均风险最小化

通常情况下，$\lambda_{11} = \lambda_{22} = 0$，因为它们对应正确决策。需最小化的平均风险 $r$ 由下式给出：

$$r = P(\omega_1)r_1 + P(\omega_2)r_2$$

##### 决策规则与风险分析

**决策规则：**

将 **x** 分配给 $\omega_1$（或 $\omega_2$），如果：

$$

\underset{P'(\omega_1)}{\underbrace{\lambda_{12}P(\omega_1)}} p(\mathbf{x}|\omega_1) > (<) \underset{P'(\omega_2)}{\underbrace{\lambda_{21}P(\omega_2)}} p(\mathbf{x}|\omega_2). \tag{7.10}

$$

注意：如果 $\lambda_{12}$ 相比于 $\lambda_{21}$ 很大，这意味着类别 $\omega_1$ 更“重要”。从略微不同的角度来看，可以将权重的使用解释为一种相对于类别 $\omega_2$ 来*增加*类别 $\omega_1$ 先验概率的方法，即：

$$

\frac{P'(\omega_1)}{P'(\omega_2)} > \frac{P(\omega_1)}{P(\omega_2)}.

$$

对于 `M` 类问题，与类别 $\omega_k$ 相关的*风险*（或*损失*）定义为：

$$

r_k = \sum_{i=1}^{M} \lambda_{ki} \int_{\mathcal{R}_i} p(\mathbf{x}|\omega_k) \, d\mathbf{x}. \tag{7.11}

$$

其中 `λ[k k] = 0`，而 `λ[k i]` 是控制将来自类别 `ω[k]` 的模式分配给类别 `ω[i]` 这一错误显著性的权重。*平均风险* 由下式给出：

```
r = ∑_{k=1}^{M} P(ω_k) r_k = ∑_{i=1}^{M} ∫_{R_i} ( ∑_{k=1}^{M} λ_{ki} P(ω_k) p(x|ω_k) ) dx
```

如果我们通过选择每个 `R_i`（在其中我们判定为类别 `ω[i]`）来划分输入空间，使求和中的 *M* 个积分中的每一个都达到最小，则该式最小化；采用以下规则即可实现这一点：

```
将 x 分配给 ω_i: ∑_{k=1}^{M} λ_{ki} P(ω_k) p(x|ω_k) < ∑_{k=1}^{M} λ_{kj} P(ω_k) p(x|ω_k), ∀ j ≠ i
```

或者等价地，

![Equation](img/fx004.jpg) (7.13)

通常将权重 `λ[i j]` 视为定义一个 *M* × *M* 矩阵：

```
L := [λ[i j]], i, j = 1, 2, …, M
```

(7.14)

这被称为 `loss` 矩阵。注意，如果我们设定 `λ[k_i] = 1, k = 1, 2, …, M`, `i = 1, 2, …, M`, `k ≠ i`，则可得到贝叶斯判决规则（请自行验证）。

#### 备注 7.1

*   **拒绝选项**：贝叶斯分类依赖于后验概率 `P(ω_i|x), i = 1, 2, …, M` 的最大值。然而，在实践中，对于某些向量 `x`，最大值往往与后验概率在其他类别上取得的值相当。例如，在一个二分类任务中，可能出现 `P(ω_1|x) = 0.51` 和 `P(ω_2|x) = 0.49` 的情况。如果发生这种情况，对于这一特定模式 `x` 不做决定可能更为明智。这被称为拒绝选项。如果采用这种判决场景，需选取一个用户定义的阈值 `θ`，仅当最大后验概率大于该阈值时才进行分类，即 `P(ω_i|x) > θ`。否则，不做决定。类似的论点也可用于平均风险分类。

#### 示例 7.1

在一个二分类、一维的分类任务中，两个类别的数据分别服从以下两个高斯分布：

```
p(x|ω_1) = \frac{1}{\sqrt{2\pi}}\exp\left( - \frac{x^{2}}{2} \right),
```

和

```
p(x|ω_2) = \frac{1}{\sqrt{2\pi}}\exp\left( - \frac{{(x - 1)}^{2}}{2} \right).
```

该问题对来自类别 `ω_1` 的模式的分类错误更为敏感，这通过以下损失矩阵来表达：

```
L = \begin{bmatrix} {0\ } & 1 \\ {0.8\ } & 0 \\ \end{bmatrix}.
```

换言之，`λ₁₂ = 1` 且 `λ₂₁ = 0.8`。这两个类别被视为等概率。推导阈值 `xᵣ`，它将特征空间 `ℝ` 划分为两个区域 `ℛ₁`、`ℛ₂`，在这两个区域中我们分别判定为类别 `ω₁` 和 `ω₂`。当使用贝叶斯分类器时，阈值是多少？

解：根据平均风险准则，判定为类别 `ω₁` 的区域由下式给出

```
ℛ₁: λ₁₂ * (1/2) * p(x|ω₁) > λ₂₁ * (1/2) * p(x|ω₂),
```

相应的阈值 `xᵣ` 由以下方程计算得出

```
exp(-xᵣ²/2) = 0.8 * exp(-(xᵣ - 1)²/2),
```

对两边取对数并求解该方程后，简单地得到

```
xᵣ = (1/2)(1 - 2 ln 0.8).
```

若令 `λ₂₁ = 1`，则得到贝叶斯分类器的阈值为

```
x_B = 1/2.
```

几何情况如图 7.2 所示。换句话说，使用平均风险将阈值移至贝叶斯分类器对应值的右侧；也就是说，它扩大了我们判定为更显著类别 `ω₁` 的区域。请注意，如果两个类别不是等概率的，情况也是如此，如 `P(ω₁) > P(ω₂)` 所示（在我们的例子中，`P(ω₁) = 1.25 P(ω₂)`）。

# 7.3 判决（超）曲面

任何分类器的目标都是将特征空间划分为若干区域。这种划分是通过 `ℝ` 中的点、`ℝ²` 中的曲线、`ℝ³` 中的曲面以及 `ℝˡ` 中的超曲面来实现的。任意超曲面 `S` 可用一个函数来表示：

```
g : ℝˡ ↦ ℝ,
```

它包含所有满足以下条件的点：

```
S = {x ∈ ℝˡ : g(x) = 0}.
```

回顾一下，位于该超曲面一侧的所有点得分为 `g(x) > 0`，而位于另一侧的所有点得分为 `g(x) < 0`。出于显而易见的原因，由此产生的（超）曲面被称为*判决（超）曲面*。以双类贝叶斯分类器为例。相应的判决超曲面由以下公式（隐式）形成：

```
g(x) := P(ω₁|x) − P(ω₂|x) = 0. (7.15)
```

确实，如果 `x` 落在公式 (7.15) 定义的超曲面的正侧（区域 `ℛ₁`），我们就判定为类别 `ω₁`；如果落在负侧（区域 `ℛ₂`），则判定为 `ω₂`。这在图 7.3 中进行了说明。此时，请回顾备注 7.1 中的拒绝选项。不做判决的点是那些靠近判决超曲面的点。

一旦我们脱离设计分类器的贝叶斯概念（正如我们即将看到的，这将出于多种原因而进行），则可以采用不同族的函数来选择 `g(x)`，具体形式将通过不同的优化准则获得，这些准则不一定与错误概率/平均风险相关。

在后续内容中，我们将重点研究贝叶斯分类器这一特殊情况下决策超曲面所呈现的形式，以及类别中的数据服从高斯概率密度函数（PDF）的情况。这能进一步揭示分类器划分特征空间的方式，并且在特定场景下，也将引出贝叶斯分类器的一些有用实现。为求简化，重点将放在二分类任务上，但结果可平凡地推广到更一般的 `M` 分类情况。

## 7.3.1 高斯分布情况

假设每个类别中的数据服从高斯概率密度函数，因此

```
p(x|ω_i) = 1/((2π)^(l/2)|Σ_i|^(1/2)) exp( -1/2 (x - μ_i)^T Σ_i^(-1) (x - μ_i) ), i = 1,2,...,M.
```

由于对数函数是单调递增的，它不影响函数最大值出现的位置。因此，考虑到高斯分布的指数形式，如果用以下函数来表达贝叶斯判据，计算将会更加方便：

```
g_i(x) := ln(p(x|ω_i)P(ω_i)) = ln p(x|ω_i) + ln P(ω_i), i = 1,2,…,M,
```

我们寻找使相应函数取得最大值的类别。此类函数也被称为*判别函数*。

现在让我们专注于二分类任务。与贝叶斯分类器相关的决策超曲面可以表示为

```
g(x) = g_1(x) - g_2(x) = 0,
```

将高斯条件概率的具体形式代入公式 (7.17) 并经过少量简单的代数运算后，变为

$$
