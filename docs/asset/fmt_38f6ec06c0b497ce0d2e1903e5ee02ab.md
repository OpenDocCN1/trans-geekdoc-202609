
这一次的递归更新，即一旦接收到 `y[n]` 的观测值，其形式是我们在本书中将反复遇到的。“新”（后验）估计等于“旧”（先验）估计，加上一个修正项；后者与新到达的观测向量与基于“旧”估计的预测之间的误差 `e[n]` 成正比。矩阵 `K[n]`，称为卡尔曼增益，控制修正量，其值的计算旨在最小化均方误差（MSE）；换句话说，

```
J(K[n]) := 𝔼[e[n|n]^(T) e[n|n]] = trace{P[n|n]},
```

其中

```
P[n|n] = 𝔼[e[n|n] e[n|n]^(T)]
```

以及

```
e[n|n] := x[n] - x̂[n|n].
```

可以证明，最优卡尔曼增益等于（问题 4.22）

```
K[n] = P[n|n−1] H[n]^(T) S[n]^(−1),
```

其中

```
S[n] = R[n] + H[n] P[n|n−1] H[n]^(T).
```

### 卡尔曼滤波算法推导

更新后的协方差矩阵由以下公式给出：

```
P[n|n] = P[n|n-1] - K[n]H[n]P[n|n-1]
```

算法现已推导完成。现在所需的只是选择初始条件，其选择方式为：

```
x̂_{1|0} = E[x_1]
```

```
P_{1|0} = E[(x_1 - x̂_{1|0})(x_1 - x̂_{1|0})^T] = Π_0
```

其中 `Π_0` 为某个初始猜测值。卡尔曼算法总结在**算法 4.2**中。

#### 算法 4.2：卡尔曼滤波

**输入：** `F[n]`、`H[n]`、`Q[n]`、`R[n]`、`y[n]`、`n = 1, 2, ...`

**初始化：**

1. `x̂_{1|0} = E[x_1]`

2. `P[1|0] = Π_0`

**对于** `n = 1, 2, ...` **执行：**

1. `S[n] = R[n] + H[n]P[n|n-1]H[n]^T`

##### 卡尔曼滤波更新方程

2. **卡尔曼增益计算**

   `K[n] = P[n|n-1] * H[n]^(T) * S[n]^(-1)`

3. **状态更新**

   `x̂[n|n] = x̂[n|n-1] + K[n] * (y[n] - H[n] * x̂[n|n-1])`

4. **协方差更新**

   `P[n|n] = P[n|n-1] - K[n] * H[n] * P[n|n-1]`

5. **时间更新（状态预测）**

   `x̂[n+1|n] = F[n+1] * x̂[n|n]`

6. **时间更新（协方差预测）**

   `P[n+1|n] = F[n+1] * P[n|n] * F[n+1]^(T) + Q[n+1]`

* **循环结束**

对于复值变量，转置操作被埃尔米特运算所取代。

##### 备注 4.7

##### 卡尔曼滤波器的变体与扩展

###### 基本方案的变体

除了前面推导的基本方案外，还有许多变体。虽然理论上它们都是等价的，但它们的实际实现可能会导致不同的性能。请注意，`P[n|n]` 是作为两个正定矩阵之差计算的；由于数值误差，这可能导致 `P[n|n]` 不是正定的。这会导致算法发散。一种流行的替代方案是所谓的信息滤波方案，它传播逆状态误差协方差矩阵，即 `P[n|n]^(−1)` 和 `P[n|n−1]^(−1)` [20]。相反，算法 4.2 中的方案被称为协方差卡尔曼算法（问题 4.24）。

###### 数值稳定性

为了解决数值稳定性问题，一系列算法传播 `P[n|n]`（或 `P[n|n]^(−1)`）的因子，这些因子源自相应的乔莱斯基分解 [5,40]。

###### 替代推导：正交性原理

有不同的方法可以得到卡尔曼滤波递推公式。一种替代推导基于应用于与观测序列相关的所谓创新过程的正交性原理，使得

```
ε(n) = y_n - ŷ_{n|1:n-1}
```

其中 `ŷ_{n|1:n-1}` 是基于过去观测历史的预测 [17]。在第 17 章中，我们将把卡尔曼递推公式重新推导一遍，将其视为一个贝叶斯网络。

###### 与最优 MSE 线性滤波的联系

卡尔曼滤波是最优 MSE 线性滤波的推广。可以证明，当涉及的过程是平稳时，卡尔曼滤波器在其稳态下收敛到我们熟悉的正规方程 [31]。

###### 扩展卡尔曼滤波器

扩展卡尔曼滤波器。在公式 (4.112) 和 (4.113) 中，状态方程和输出方程都对状态向量 `x[n]` 有线性依赖。在更一般的表述中，卡尔曼滤波可以表述为

```
x[n] = fn + η[n]
y[n] = hn + v[n]
```

其中 `f[n]` 和 `h[n]` 是非线性向量函数。在扩展卡尔曼滤波（EKF）中，其思路是通过泰勒级数展开，在每个时刻对函数 `h[n]` 和 `f[n]` 进行线性化，并仅保留线性项，从而得到

```
F_n = ∂f_n(x_n)/∂x_n|_{x_n = x̂_{n-1|n-1}}, H_n = ∂h_n(x_n)/∂x_n|_{x_n = x̂_{n|n-1}},
```

然后利用为线性情况推导出的更新公式继续进行。

从其定义本身来看，EKF 是次优的，且在实践中经常可能面临算法发散的问题；总体而言，必须指出其实际实施需要谨慎进行。话虽如此，必须强调的是它在许多实际系统中得到了广泛应用。

无迹卡尔曼滤波器代表了一种应对非线性的替代方法，其主要思想源于概率论证。从 `p(x[n]|y[1],…,y[n])` 的高斯近似中确定性地选取一组点；这些点通过非线性函数传播，从而获得均值和协方差的估计 [15]。粒子滤波将在第 17 章讨论，它是另一种利用概率论证处理非线性状态空间模型的强大且流行的方法。

最近，再生核希尔伯特空间中的卡尔曼滤波扩展提供了一种处理非线性的替代方法 [52]。

第 5 章中出现了许多用于分布式学习的卡尔曼滤波版本，例如见 [9,23,43]。文献 [33] 中，子空间学习方法被用于与状态变量相关的预测阶段。

关于卡尔曼滤波的文献浩如烟海，特别是在涉及应用方面。感兴趣的读者可参考更多专业文献，例如 [4,8,17] 及其参考文献。
