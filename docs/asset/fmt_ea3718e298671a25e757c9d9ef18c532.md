
另一种方法使用密码学工具构建数据挖掘模型。例如，在 [LIND2000] 中，目标是在训练集分布在两方之间的情况下安全地构建 `ID3` 决策树。利用密码学技术给出了不同的解决方案来解决不同的数据挖掘问题（例如 [CLIF2002, KANT2004, VAID2003]）。这种方法将隐私保护数据挖掘视为安全多方计算的一个特例，不仅旨在保护个人隐私，还试图防止除最终结果外的任何信息泄露。但当参与方数量变大时，通信和计算成本会呈指数级增长。

我们的方法是一种修改后的 `C4.5` 决策树算法 [QUIN1993]，并采用噪声加法方法。我们的方法适用于许多参与方希望执行数据挖掘，但每方仅拥有少量数据的场景。为了获得全局数据挖掘模式，各方必须共享其数据，但每方都有其隐私和安全顾虑。我们的方法正是针对这种情况的解决方案。在我们的方法中，每方根据预设随机噪声的分布扰动其数据，并将扰动后的数据发送给数据挖掘者。数据挖掘者收集各方的扰动数据集，并知晓用于扰动数据的分布。基于这些信息，数据挖掘者构建一个分类器，并将该分类器返回给每个参与方。然后每方可使用此分类器对其数据进行分类。在这种情况下，每方仅知晓自己的数据和分类器，而不知晓其他方的任何数据。数据挖掘者仅能访问扰动数据和噪声数据的分布。这样，隐私得以保护，且每方的通信和计算成本被最小化。

## 12.3 隐私度量

在 [AGRA2001] 的工作中，Agrawal 和 Aggarwal 基于微分熵提出了一种隐私度量。我们在此简要重述其思想。随机变量 `A` 的微分熵 `h(A)` 定义如下：

```
h(A) = −∫[Ω[A]] fA log[2] fA da  (12.1)
```

其中 `ΩA` 是 `A` 的定义域。

实际上，`h(A)` 是统计学中 `A` 值固有不确定性的度量。基于此，Agrawal 和 Aggarwal [AGRA2001] 提出了随机变量 `A` 固有的隐私度量 `Π(A)`。

```
Π(A) = 2^(h(A))  (12.2)
```

例如，在 0 和 `a` 之间均匀分布的随机变量 `U` 具有隐私度：

```
Π(U) = 2^(log2) = a.
```

因此，如果 `Π(A)` = 1，则 `A` 具有与在长度为 1 的区间上均匀分布的随机变量同等的隐私度。此外，如果

```
fB = 2 fA,
```

则 `B` 提供的隐私度仅为 `A` 的一半。这很容易说明：在 [0, 1] 上均匀分布的随机变量，其隐私度仅为在 [0, 2] 上均匀分布的随机变量的一半。在 [AGRA2001] 中，Agrawal 和 Aggarwal 还定义了条件隐私和信息损失。更多细节请参考原始文献 [AGRA2001]。我们在工作中选择此隐私度量来量化实验中的隐私。

## 12.4 决策树构建概述

### 我们提出了一种修改后的 C4.5 决策树分类器，它从扰动数据构建决策树，并可用于对原始数据和扰动数据进行分类。

这种方法背后的思想如下：当我们考虑属性的分裂点时，也会考虑噪声数据集的偏差。每当我们试图寻找最佳属性、最佳分裂点并划分训练数据时，都会计算偏差。`C4.5` 算法是 `ID3` 算法的扩展，由 Quinlan 在 [QUIN1993] 中提出。经过多年的改进，`C4.5` 算法已成为处理数值连续属性的最佳算法之一 [QUIN1996]。它能找到最佳分裂属性以及数值连续属性的最佳分裂点。

### 12.4.1 分裂准则

分裂准则在构建决策树时至关重要。它决定使用哪个属性进行分裂，对于数值连续属性，还决定使用哪个值进行分裂。它决定了决策树是否高效，并极大地影响分类准确率。`ID3` 使用信息增益作为分裂准则。`C4.5` 算法使用信息增益率，在检查属性时会考虑分支数量。信息增益和增益率的公式如下：

```
Info(S) = - Σ_{j=1}^{k} (freq(C_j, S) / |S|) × log₂(freq(C_j, S) / |S|)  (12.3)
```

```
Info_{Test_A}(S) = Σ_{i=1}^{n} (|S_i| / |S|) × Info(S_i)  (12.4)
```

```
gain(Test[A]) = Info(S) − Info_{Test[A]}(S)  (12.5)
```

```
splitInfo(Test_A) = - Σ_{i=1}^{n} (|S_i| / |S|) × log₂(|S_i| / S)  (12.6)
```

```
gainRatio(Test_A) = gain(Test_A) / splitInfo(Test_A)  (12.7)
```

设 `S` 为训练集，`|S|` 为 `S` 中实例的数量，`freq(C_j, S)` 为属于类别 `j` 的实例数量，其中 `j` 从 1 到 `k`。`|S_i|` 为类别 `S_i` 中实例的数量。`Test[A]` 为所选属性。

### 12.4.2 连续属性离散化

#### 二元分裂法

`C4.5` 算法也旨在处理数值属性。`C4.5` 算法不使用固定范围，而是在可能的分裂点中搜索以找到最佳分裂点。假设数值属性 `A_i` 按升序具有值 `{x_1, x_2, …, x_m}`。`C4.5` 将实例划分为两组 `S_1` 和 `S_2`，其中 `S_1` 包含不超过 `x_j` 的值，`S_2` 包含大于 `x_j` 的值。对于每个划分，`C4.5` 计算增益率并选择使增益率最大化的划分。

### 12.4.3 停止准则

停止准则决定何时停止决策树的生长。在 `C4.5` 算法中，当满足以下两个准则之一时，树停止生长。一是节点上的所有实例具有相同的类别标签 `C_i`；我们称该节点为纯节点。二是节点上的实例数量小于或等于预设的阈值；我们称该数量为节点的最小实例数。我们在隐私保护决策树 `C4.5` (`PPDTC4.5`) 中也使用相同的停止准则。

## 12.5 基于扰动数据的朴素贝叶斯分类器构建

正如 [LIU2007] 所述，朴素贝叶斯分类器可直接应用于扰动数据。为求完整，我们在此简要描述。

### 12.5.1 朴素贝叶斯分类器

朴素贝叶斯分类器通过分配最可能的类别值来标记新实例。此外，它假设在给定类别值的条件下属性值相互独立，以简化所需概率的估计。利用上述假设，朴素贝叶斯分类器选择最可能的分类 `C_nb`：

```
C_nb = argmax_{C_j ∈ C} P(C_j) ∏_i P(X_i | C_j)  (12.8)
```

其中 `X = X_1, X_2, …, X_n` 表示属性集，`C = C_1, C_2, .., C_d` 表示可能的类别标签有限集，`C_nb` 表示朴素贝叶斯分类器输出的类别标签 [MITC1997]。

显然，我们需要根据训练数据计算公式 12.8 中使用的概率 `P(X_i = x | C_j)`。在实践中，对于数值属性，`P(X_i = x | C_j)` 通过高斯分布 `N(μ_ij, σ_ij²)` 进行估计。所需参数 `μ_ij = E(X_i | c_j)` 和 `σ_ij² = Var(X_i | C_j)` 通过训练数据估计。接下来，我们展示如何使用扰动训练数据来估计参数 `μ_ij` 和 `σ_ij²`。

### 12.5.2 基于扰动数值数据

我们需要使用扰动数值数据，为每个属性 `X_i` 和每个类别标签 `C_j` 估计 `μ_ij` 和 `σ_ij²`，以构建朴素贝叶斯分类器。在扰动数据情况下，我们不再看到原始属性值 `X_i`，而是看到 `W_i = X_i + R` 的值。设 `w_ij^(t)` 为具有类别标签 `C_j` 的第 `t` 个训练数据实例的第 `i` 个属性值。此外，我们假设有 `n` 个实例具有类别标签 `C_j`。

我们还知道 `w_ij^(t) = x_ij^(t) + r_ij^(t)`，其中 `r_ij^(t)` 为均值为零、方差 `σ_R²` 已知的随机生成噪声。利用上述事实，我们可以证明：

```
w̄_ij = (1/n) · Σ_{t=1}^{n} (w_ij^t)
```

的期望值等于 `μ_ij`。

由于样本方差

```
S² = (1/(n - 1)) · Σ_{t=1}^{n} (w_ij^t - w̄_ij)²
```

的期望值为 `σ_ij² + σ_R²`，我们可以利用 `S²` 和已知的 `σ_R²` 来估计 `σ_ij²`（即用 `S² − σ_R²` 来估计 `σ_ij²`）。

因此，只要我们不改变类别标签，就可以直接从扰动数据构建朴素贝叶斯分类器。更进一步说，由于使用扰动数据和原始数据进行参数估计具有相同的期望值，我们在两种情况下都应该能获得相似的分类准确率。为验证上述直觉，我们使用 `WEKA` 机器学习工具包 [WITT2005] 中的朴素贝叶斯分类器进行了一些实验。

使用包含所有六个数值连续属性的相同数据集，我们从原始数据集构建朴素贝叶斯分类器，获得 79.7% 的分类准确率。类似地，如果直接从扰动训练数据集构建朴素贝叶斯分类器并在扰动测试集上测试，可获得 78% 的分类准确率。正如预期的那样，这两个分类准确率值非常接近。

## 12.6 隐私保护决策树 C4.5 (PPDTC4.5)

### 12.6.1 动机

在本节中，我们将描述如何从扰动训练数据集构建决策树分类器。我们将展示阈值法和随机路径选择法这两种不同的构建分类器的方式。阈值算法对原始数据集的分类提供了相当不错的准确率。随机路径选择算法使用概率作为权重，为属性寻找良好的分裂点。然而，正如我们将看到的，随机选择路径来划分训练数据集并不能构建一个良好的决策树分类器。

我们将随机路径选择算法纳入其中，主要是为了比较目的，同时也为未来的工作提供一些方向，即构建决策树分类器来对扰动数据集进行分类。我们认为，通过对随机变量 `R` 的紧界进行适当改进，可以提高随机路径选择算法的性能。

目标是从扰动数据构建一个决策树模型，该模型能够准确地对原始数据集或扰动数据集进行分类。在我们的场景中，由于添加了噪声，我们不知道原始的 `x[j]` 值。相反，我们观察到 `w[j] = x[j] + R`，其中 `R` 是随机噪声，且我们知道其分布。显然，对于属性 `A[i]` 的分裂点 `t`，如果我们知道 `x[j]` 的值，我们将使用以下规则将实例分裂到 `S[1]` 和 `S[2]` 中：

```
split(x_j, t) = { S_1, if x_j ≤ t; S_2, if x_j > t } (12.9)
```

由于我们不知道 `x[j]` 的值，因此只能计算给定分裂点 `t` 和 `w[j]` 时 `w[j]` 属于 `S[1]` 的概率。注意 `Pr{w[j] ∈ S[1]} = Pr{w[j] − R ≤ t} = Pr{w[j] − t ≤ R}`。由于我们知道 `R` 的累积分布函数，因此可以轻松计算该概率。令 `pS1` 为给定分裂点 `t` 和 `w[j]` 时 `w[j]` 属于 `S[1]` 的概率。类似地，定义 `pS2 = 1 − pS1`。一般来说，令 `pS` 为 `w[j]` 属于集合 `S` 的概率。现在，我们不再根据公式 (12.9) 进行分裂，而是可以使用 `pS` 值来估计最佳分裂点，并对 `w[j]` 进行划分，就像原始数据 `x[j]` 会被划分那样。

### 12.6.2 使用阈值的分裂准则

我们可以为每个 `w[j]` 值计算给定分裂点 `t` 下的概率 `pS1`。该 `pS1` 值表示 `w[j] ∈ S[1]` 的可能性。我们可以设定一个阈值，并统计具有类标签 `C[j]` 且 `pS1` 值大于该阈值的 `w[j]` 的数量。这可以用以下方程形式表示：

```
freq'(C_j, S_i) = Σ_{w_j ∈ S_i} ( I_{w_j ∈ C_j}, p_{Si}(w_j) > threshold ) (12.10)
```

在上述方程中，我们通过使用 `pS1` 来计算类值的频率。`I[wj∈Cj]` 是一个指示函数，如果 `w[j]` 具有类标签 `C[j]`，则返回 1。公式 (12.3) 变为如下形式：

```
Info(S) = - Σ_{j=1}^k ( freq'(C_j, S) / |S| ) × log_2( freq'(C_j, S) / |S| ) (12.11)
```

使用上述公式 (12.11)，加上公式 (12.4)、(12.5)、(12.6) 和 (12.7)，我们可以通过最大化 `gainRatio` 来找到数值连续属性的最佳分裂属性和最佳分裂点。

### 12.6.3 通过阈值分裂训练数据

训练数据的分裂准则是直观的。

```
splitThreshold(w_j, t) = { S_1, if p_{S_1}(w_j | t) > threshold; S_2, if p_{S_1}(w_j | t) ≤ threshold } (12.12)
```

请注意，条件 `pS1 > threshold` 等价于条件 `pS2 ≤ (1 − threshold)`，反之亦然。例如，条件 `pS1(wj|t) > 0.2` 等价于条件 `pS2(wj|t) ≤ 0.8`。伪代码如 Algorithm 12.1 所示。

使用阈值方法看似是一种简单的方法，但设置能够导致成功分类器的适当阈值并非易事。根据定义，`pS1` 是给定分裂点 `t` 和扰动实例 `w[j]` 时 `w[j]` 属于 `S[1]` 的概率。当给定分裂点 `t` 和扰动实例 `w[j]` 时，唯一的不确定性就是随机噪声 `R`。换句话说，阈值的选择与随机噪声的分布有关。在我们的实验中，我们对随机噪声均使用了均匀分布和高斯分布。这两种分布的阈值不同。对于高斯分布，当阈值设置为 0.30 时，分类器给出较高的准确率；对于均匀分布，当阈值设置为 0.50 时，分类器给出较高的准确率。实验结果将在下一节讨论。

决定阈值的另一个好方法是保持其灵活性，就像 `C4.5` 算法为数值连续属性寻找最佳分裂点 `t` 那样。这将带来良好的结果，但会增加计算成本。

### 12.6.4 对原始实例进行分类

使用前两小节描述的算法，我们选择实际属于原始数据的分裂属性和分裂点。我们还根据对原始值的估计对扰动训练数据进行划分。这样我们就可以为原始数据构建一个决策树分类器。然后，当我们用它对原始数据进行分类时，只需根据属性值是小于还是大于某个属性分裂点来进行分类。对原始数据进行分类的伪代码如 Algorithm 12.2 所示。

### 12.6.5 分裂准则

使用概率作为权重，我们利用 `pS1` 和 `pS2` 值作为权重重写所有方程，如下所示：

```
freq''(C_j, S_i, S) = Σ_{w_j ∈ S} ( I_{w_j ∈ C_j} × p_{S_i}(w_j) ) (12.13)
```

在上述方程中，我们通过使用 `pS1` 作为权重来计算类值的频率。`I[wj∈Cj]` 是一个指示函数，如果 `w[j]` 具有类标签 `C[j]`，则返回 1。为了归一化，我们需要计算总权重之和（即所有 `pS1` 值之和）

```
w(S_i, S) = Σ_{w_j ∈ S} ( p_{S_i}(w_j) ) (12.14)
```

现在，利用上述两个定义，我们准备好使用 `pS1` 值重新定义条件熵。

```
Prob(S_i, S) = freq''(C_j, S_i, S) / |w(S_i, S)| (12.15)
Info'(S_i, S) = - Σ_{j=1}^k Prob(S_i, S) × log_2( Prob(S_i, S) ) (12.16)
Prob(S_i, S) = freq''(C_j, S_i, S) / |w(S_i, S)| (12.17)
Info'(S_i, S) = - Σ_{j=1}^k Prob(S_i, S) × log_2( Prob(S_i, S) ) (12.18)
```

类似地，我们需要更新选择属性 `A` 及分裂点 `t` 时的信息增益。

```
Info'_Test_A(S) = Σ_{i=1}² ( |w(S_i, S)| / |S| ) × Info'(S_i, S) (12.19)
```

此外，在计算 `splitInfo` 时，我们需要使用 `w(S_i, S)`。

```
splitInfo'(Test_A) = - Σ_{i=1}^n ( |w(S_i, S)| / |S| ) × log_2( |w(S_i, S)| / |S| ) (12.20)
```

现在，我们可以将上述修改后的定义插入原始测试中，以选择分裂点和属性。

```
gain'(Test_A) = Info(S) - Info'_S(Test_A)(S)  (12.21)
```

```
gainRatio'(Test_A) = gain'(Test_A) / splitInfo'(Test_A)  (12.22)
```

现在，我们可以使用公式 (12.22) 来选择一个分裂点和一个属性。请注意，`C4.5` 中使用的原始公式与我们的公式之间的主要区别在于，我们在公式中使用了属于某个分区的概率作为权重。这种修改背后的基本原理如下：如果我们清晰地写出原始公式，可以看到存在一个隐含的指示函数，它根据实例属于集合 `S[1]` 还是集合 `S[2]` 来分配 0 或 1。由于我们无法确定某个实例是在 `S[1]` 中还是在 `S[2]` 中，因此我们使用属于 `S[1]` 或 `S[2]` 的概率作为权重。

### 12.6.6 使用随机路径选择分割训练数据集

该方法是在找到分裂点和属性后，将训练数据分成两部分的一种替代方式。同样，在我们的实现中，我们基于 `p[S1]` (`w[j]`) 和 `p[S2]` (`w[j]`) 的值使用随机分割。

```
splitRandom(w_j, t) = { S_1, with prob. p_{S_1}(w_j); S_2, with prob. p_{S_2}(w_j) } (12.23)
```

### 12.6.7 使用随机路径选择对扰动实例进行分类
