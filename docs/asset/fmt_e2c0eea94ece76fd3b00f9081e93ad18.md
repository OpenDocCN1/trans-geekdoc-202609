
# 术语表

## C

**Contraband check**  
旨在识别禁止进入安全区域（如飞机）的物品。

**Control Objectives for Information and related Technology**  
参见——`COBIT`。

**Control unit**  
`CPU` 组件，充当交通指挥，向 `ALU` 发送指令。

**Convergence**  
网络上的所有路由器就路由状态达成一致。

**COOP**  
`Continuity of Operations Plan`，灾难期间维持运营的计划。

**Copyright**  
保护艺术、音乐或文学作品表达形式的知识产权类型。

**CORBA**  
`Common Object Request Broker Architecture`，开放的供应商中立的网络对象代理框架。

**Corrective controls**  
修复受损系统或过程的控制措施。

**Corroborative evidence**  
为可能受到质疑的事实提供额外支持的证据。

**COTS**  
`Commercial Off-the-Shelf Software`，面向公众的第三方开发商业软件。

**Counter Mode**  
参见——`CTR`。

**Counter Mode CBC MAC Protocol**  
参见——`CCMP`。

**Coupling**  
`OOP` 概念，将对象连接到其他对象。高耦合对象具有低内聚。

**Covert channel**  
任何违反安全策略的通信。

**CPPT**  
`Continuity Planning Project Team`，由组织内的利益相关者组成的团队，专注于确定如果发生特定紧急事件，谁需要发挥作用。

**CPU**  
`Central Processing Unit`，计算机的“大脑”，能够控制和执行数学计算。

**Credential Management System**  
实现账户凭据和密码更安全存储和使用的软件。

**Criminal law**  
受害者可视为社会本身的法律。

**Crippleware**  
部分功能的专有软件，通常禁用关键功能。用户通常需要付费以解锁全部功能。

**Crisis Management Plan**  
参见——`CMP`。

**CRL**  
`Certificate Revocation Lists`，`PKI` 组件，列出已被吊销的数字证书。

**Crossover**  
遗传算法概念，结合两种算法。

**Crossover Error Rate**  
参见——`CER`。

**Cross-Site Request Forgery**  
参见——`CSRF`。

**Cross-Site Scripting**  
参见——`XSS`。

**Cryptanalysis**  
破解加密消息（恢复其含义）的科学。

**Cryptographic Protocol Governance**  
描述为特定工作选择正确密码和实现的过程。

**Cryptography**  
创建隐藏含义消息的科学。

**Cryptology**  
安全通信的科学。

**CSIRT**  
`Computer Security Incident Response Team`，负责监控、识别和响应安全事件的团队。

**CSMA**  
`Carrier Sense Multiple Access`，以太网网络用于允许共享基带网络并避免冲突的方法。

**CSRF**  
`Cross-Site Request Forgery`，在受信任站点的安全上下文中对静态内容的第三方重定向。

**CSU/DSU**  
`Channel Service Unit/Data Service Unit`，`DCE` 设备。

**CTR**  
`Counter`，使用计数器进行反馈的 `DES` 流模式。

**Custodian**  
提供资产的实操保护。

**Customary Law**  
被群体普遍接受以至于被视为法律的习俗或惯例。

**CWR**  
新 `TCP` 标志，`Congestion Window Reduced`。

**Cyber Incident Response Plan**  
旨在应对破坏性网络事件的计划，包括基于网络的攻击、蠕虫、计算机病毒和特洛伊木马。

**Cybersquatting**  
注册与另一组织知识产权相关的互联网域名。

## D

**DAC** (`Discretionary Access Control`)：自主访问控制，赋予主体对其拥有或被授权访问的对象的完全控制权，包括与其他主体共享对象。

**DAD** (`Disclosure, Alteration, and Destruction`)：泄露、篡改和破坏，是机密性、完整性和可用性的对立面。

**DARPA** (`Defense Advanced Research Projects Agency`)：国防高级研究计划局，最初的 `MILNET` 和 `ARPANET` 的资助者。

**DAST** (`Dynamic Application Security Testing`)：动态应用安全测试，在代码执行过程中对其进行测试。

**Data at rest**：静态数据，驻留在磁盘和/或文件中的存储数据。

**Data controllers**：数据控制者，在组织内创建和管理敏感数据的角色。例如人力资源员工：他们创建和管理敏感数据，如薪资福利数据、员工制裁报告等。

**Data Circuit-Terminating Equipment**：数据电路终接设备，参见 **DCE**。

**Data Definition Language**：数据定义语言，参见 **DDL**。

**Data dictionary**：数据字典，包含数据库表的描述，包括模式、数据库视图信息，以及授权的数据库管理员和用户账户信息。

**Data Encryption Algorithm**：数据加密算法，参见 **DEA**。

**Data Encryption Standard**：数据加密标准，参见 **DES**。

**Data Execution Prevention**：数据执行保护，参见 **DEP**。

**Data hiding**：数据隐藏，参见 **Encapsulation (object)**。

**Data in transit**：传输中数据，也称为动态数据，指正在跨网络传输的数据。

**Data in use**：使用中数据，指在应用程序中正被主动使用的数据，例如用户在打开的电子表格中查看的数据。

**Data link layer**：数据链路层，`OSI` 模型的第 2 层，处理对物理层的访问以及局域网通信。

**Data maintenance**：数据维护，保护数据的日常操作过程。

**Data Manipulation Language**：数据操作语言，参见 **DML**。

**Data mining**：数据挖掘，用于在数据仓库中搜索模式，如欺诈活动。

**Data Owner**：数据所有者，负责确保特定数据受到保护的管理层员工。

**Data processor**：数据处理者，代表数据控制者管理数据的角色。外包薪资公司是数据处理者的一个例子。

**Data Quality Principle**：数据质量原则，`OECD` 隐私准则原则之一，规定个人数据应当完整、准确，并以与数据收集目的一致的方式维护。

**Data remanence**：数据残留，参见 **Remanence**。

**Data Terminal Equipment**：数据终端设备，参见 **DTE**。

**Data warehouse**：数据仓库，大量数据的集合。

**Database**：数据库，相关数据的结构化集合。

**Database Administrators**：数据库管理员，参见 **DBA**。

**Database journal**：数据库日志，所有数据库事务的日志。若数据库损坏，可将其恢复至备份副本，随后从日志中“重放”后续事务，以恢复数据库完整性。

**Database Management System**：数据库管理系统，参见 **DBMS**。

**Database replication**：数据库复制，镜像实时数据库，允许客户端对多个复制的数据库进行同时读写。

**Database shadowing**：数据库影子，两个或多个完全相同的数据库同时更新。

**Database view**：数据库视图，数据库查询的结果。

**DBA** (`Database Administrators`)：数据库管理员，管理数据库的角色。

**DBMS** (`Database Management System`)：数据库管理系统，控制对数据库的所有访问并强制执行数据库安全策略。

**DCE** (`Data Circuit-Terminating Equipment`)：数据电路终接设备，用于连接 `DTE` 的设备，如路由器。

**DCOM** (`Distributed Component Object Model`)：分布式组件对象模型，跨网络定位和连接对象。

**DDL** (`Data Definition Language`)：数据定义语言，用于创建、修改和删除表。

**DDoS** (`Distributed Denial of Service`)：分布式拒绝服务，利用多个系统发起的可用性攻击。

**DEA** (`Data Encryption Algorithm`)：数据加密算法，由 `DES` 描述。

**Deadbolt**：插芯锁，一种由钥匙固定的刚性锁定机制，伸出时防止门打开或完全关闭。

**Decryption**：解密，将密文转换为明文。

**Defense-in-depth**：纵深防御，跨越多个域应用多重防护措施以保护资产。

**Defined**：`CMM` 第 3 阶段。

**Degaussing**：退磁，破坏存储介质磁化的完整性，使数据无法恢复。

**Demarc** (`Demarcation point`)：分界点，`ISP` 责任结束和客户责任开始的地点。

**Demilitarized Zone**：非军事区，参见 **DMZ**。

**Denial of Service**：拒绝服务，参见 **DoS**。

**DEP** (`Data Execution Prevention`)：数据执行保护，可在硬件和/或软件中启用，使堆栈的特定页面不可执行。

**Deprovisioning**：取消配置，将资源（如用户、系统、应用程序）从运行状态中移除。

**Depth of field**：景深，处于聚焦状态的区域。

**DES** (`Data Encryption Standard`)：数据加密标准，一种使用 56 位密钥和 64 位块大小的对称分组密码。

**Detection phase**：检测阶段，事件管理阶段之一，分析事件以确定其是否构成安全事件。

**Detective controls**：检测型控制，在攻击成功期间或之后发出警报的控制措施。

**Deterrent controls**：威慑型控制，阻止用户在系统上执行操作的控制措施。

**Develop an IT contingency plan**：制定 `IT` 应急计划，`NIST SP 800-34` 应急规划过程的第五步。

**Develop recovery strategies**：制定恢复策略，`NIST SP 800-34` 应急规划过程的第四步。

**Develop the contingency planning policy statement**：制定应急规划政策声明，`NIST SP 800-34` 应急规划过程的第一步。

**DevOps**：一种更敏捷的开发和支持模式，呼应包括 `Sashimi` 和 `Scrum` 在内的敏捷编程方法。开发人员直接支持运维职能。

**DevSecOps**：开发、安全和运维：将安全集成到 `DevOps` 过程中，延续对敏捷方法论的关注。

**DHCP** (`Dynamic Host Configuration Protocol`)：动态主机配置协议，为系统分配临时 `IP` 地址租约，以及 `DNS` 和默认网关配置。

**Diameter**：`RADIUS` 的继任者，旨在提供改进的认证、授权和审计 (`AAA`) 框架。

**Dictionary attack**：字典攻击，使用预定义单词列表（如字典）的密码破解方法，将每个单词通过哈希算法运行。

**Differential backup**：差异备份，自上次完整备份以来已更改文件的归档。

**Differential cryptanalysis**：差分密码分析，寻找加密后的相关明文之间的“差异”。

**Diffie-Hellman Key Agreement Protocol**：`Diffie-Hellman` 密钥协商协议，允许双方通过公共信道在无密钥预共享的情况下安全地协商对称密钥。

**Diffusion**：扩散，明文的顺序应在密文中被分散。

**Digital**：数字，以比特（0 和 1）传输数据的通信方式。

**Digital Rights Management**：数字版权管理，参见 **DRM**。

**Digital signature**：数字签名，提供不可抵赖性，包括签名者身份认证和文档完整性证明。

**Digital Subscriber Line**：数字用户线路，参见 **DSL**。

**Direct evidence**：直接证据，证人就其亲身经历提供的证词。

**Direct Sequence Spread Spectrum**：直接序列扩频，参见 **DSSS**。

**Directory Path Traversal**：目录路径遍历，通过引用“`../..`”等目录，从 `Web` 服务器根目录（如 `/var/www`）逃逸到常规文件系统。

**Disassembler**：反汇编器，尝试将机器语言转换为汇编语言。

**Disaster**：灾难，任何中断正常系统操作的破坏性事件。

**Disaster Recovery Plan**：灾难恢复计划，参见 **DRP**。

**Disclosure, Alteration, and Destruction**：泄露、篡改和破坏，参见 **DAD**。

**Discretionary Access Control**：自主访问控制，参见 **DAC**。

**Diskless workstation**：无盘工作站，包含 `CPU`、内存和固件但无硬盘的计算机系统，属于瘦客户端的一种。

**Distance vector**：距离矢量，使用简单度量（如跳数）的路由协议。

**Distributed Component Object Model**：分布式组件对象模型，参见 **DCOM**。

**Distributed Denial of Service**：分布式拒绝服务，参见 **DDoS**。

**Distributed Network Protocol**：分布式网络协议，参见 **DPN3**。

**Distributed systems**：分布式系统，将多个位置的计算机组合在一起，视为一个逻辑系统。

**Divestitures**：剥离，也称为反向合并和反向收购，代表收购的另一面：一家公司分裂为两家或更多。

**DML** (`Data Manipulation Language`)：数据操作语言，用于查询和更新表中存储的数据。

**DMZ** (`Demilitarized Zone`)：非军事区网络，用于隔离受信网络与非受信网络。

**DNP3** `Distributed Network Protocol`，提供一种开放标准，主要用于能源领域，实现不同供应商的 `SCADA` 和智能电网应用之间的互操作性。

**DNS** `Domain Name System`，一个分布式全球层级数据库，将名称转换为 `IP` 地址，反之亦然。

**DNS reflection attack** 使用第三方 `DNS` 服务器的欺骗性 `DoS` 攻击。

**DNSSEC** `Domain Name Server Security Extensions`，通过使用公钥加密为 `DNS` 响应提供认证和完整性。

**Domain Name Server Security Extensions** 见——**DNSSEC**。

**Domain Name System** 见——**DNS**。

**Domains of trust** `Windows Active Directory` 使用的访问控制模型。

**DoS** `Denial of Service`，针对可用性的攻击。

**DRAM** `Dynamic Random Access Memory`，将比特存储在小电容器中（如小电池），比 `SRAM` 更便宜但速度更慢。

**DRM** `Digital Rights Management`，旨在通过水印、产品密钥和区域锁定等控制手段限制受版权保护材料和其他形式知识产权的使用。

**DRP** `Disaster Recovery Plan`，从破坏性事件中恢复的短期计划。

**DSL** `Digital Subscriber Line`，利用现有铜线对为家庭和小型办公室提供数字服务。

**DSSS** `Direct Sequence Spread Spectrum`，一次性使用整个无线频段。

**DTE** `Data Terminal Equipment`，网络“终端”，如台式机、服务器或实际终端。

**DTE/DCE** 跨越分界点的连接。

**Dual-factor authentication** 见——**Strong authentication**。

**Dual-homed host** 具有两个网络接口的主机：一个连接到受信网络，另一个连接到不受信网络。

**Due care** 要求关键组织利益相关者在履行职责时审慎行事，又称“审慎人规则”。

**Due diligence** 对尽职照管的管理。
