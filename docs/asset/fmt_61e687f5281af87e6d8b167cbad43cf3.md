
\sigma_{y}^{2} = \sigma_{\eta}^{2} + \mathbf{\phi}^{T}(\mathbf{x})\Sigma_{\theta|y}\mathbf{\phi}(\mathbf{x}) = \sigma_{\eta}^{2} + \mathbf{\phi}^{T}(\mathbf{x})\left( \frac{1}{\sigma_{\theta}^{2}}I + \frac{1}{\sigma_{\eta}^{2}}\Phi^{T}\Phi \right)^{- 1}\mathbf{\phi}(\mathbf{x}) = \sigma_{\eta}^{2} + \sigma_{\eta}^{2}\sigma_{\theta}^{2}\mathbf{\phi}^{T}(\mathbf{x})\left( \sigma_{\eta}^{2}I + \sigma_{\theta}^{2}\Phi^{T}\Phi \right)^{- 1}\mathbf{\phi}(\mathbf{x}).

$$

![Equation](img/si74.png)(12.23)

因此，给定 `x`，可以使用最可能的值来预测 `y` 相应的值，即公式 (12.22) 中的 `μ[y]`。请注意，通过公式 (12.10) 中的 MAP 估计（或公式 (12.12)（如果 `θ[0] = 0`，也可通过岭回归任务获得））会得到相同的预测值。那么，采用贝叶斯方法是否获得了额外的收获？答案是肯定的。*现在可以获得关于预测值的更多信息，因为* 公式 (12.23) *量化了相关的不确定性*。

为了进一步研究公式 (12.23)，让我们通过采用以下近似来简化它：

$R_{\phi} := \mathbb{E}\left[ \mathbf{\phi}(\mathbf{x})\mathbf{\phi}^{T}(\mathbf{x}) \right] \approx \frac{1}{N}\sum\limits_{n = 1}^{N}\mathbf{\phi}(\mathbf{x}_{n})\mathbf{\phi}^{T}(\mathbf{x}_{n}) = \frac{1}{N}\Phi^{T}\Phi$

![Equation](img/si77.png)

或

$\Phi^{(T)}\Phi \approx N R[\phi]$

![Equation](img/si78.png)(12.24)

其中 $R[\phi]$ 是随机向量 $\mathbf{\phi}(\mathbf{x})$ 的自相关矩阵。

![Equation](img/si79.png)![Equation](img/si80.png)

将公式 (12.24) 代入公式 (12.23) 得到

$\sigma_{y}^{2} \approx \sigma_{\eta}^{2}\left( 1 + \sigma_{\theta}^{2}\mathbf{\phi}^{T}(\mathbf{x})(\sigma_{\eta}^{2}I + N\sigma_{\theta}^{2}R[\phi])^{-1}\mathbf{\phi}(\mathbf{x}) \right)$

![Equation](img/si81.png)(12.25)

当 $N$ 足够大时，这变为

$\sigma_{y}^{2} \approx \sigma_{\eta}^{2}\left( 1 + \frac{1}{N}\mathbf{\phi}^{T}(\mathbf{x})R_{\phi}^{-1}\mathbf{\phi}(\mathbf{x}) \right).$

![Equation](img/si82.png)

因此，对于大量观测值，$\sigma_{y}^{2} \to \sigma_{\eta}^{2}$，我们的不确定性由噪声源造成，无法再进一步减小。对于较小的 $N$ 值，存在与参数 $\mathbf{\theta}$ 相关的额外不确定性，在公式 (12.25) 中由 $\sigma_{\theta}^{2}$ 衡量。

本节目前我们处理的是高斯分布，这使得积分具有可处理性且可解析计算。是否有方法应对更一般的情况？此外，即使在高斯概率密度函数（PDF）的情况下，我们也假设协方差矩阵 `Σ[θ]`、`Σ[η]` 是已知的。在实践中，它们并非已知。即使假设 `Σ[η]` 可以通过实验测量，`Σ[θ]` 仍然未知。能否通过优化过程选择相关参数？如果答案是肯定的，这种优化能否在训练集上进行，还是必然会遇到类似于正则化方法所面临的问题？我们将在后续章节中探讨所有这些挑战。

## 12.3 证据函数与奥卡姆剃刀法则

在上一节中，我们曾对边际 PDF `p(y)` 的重要性做过评论。本节将专门讨论这一量。在公式 (12.14) 所用的符号中，我们隐含地省略了对所采用模型的依赖关系。例如，公式 (12.8) 中先验的高斯假设和公式 (12.9) 中条件概率的高斯假设本应反映在边际概率中，记为 `p(y; ϕ, Σ[η], Σ[θ])`，因为可以使用不同的高斯分布、不同的基函数和不同阶数 `K` 的模型。此外，也可以采用非高斯 PDF。在更一般的设定中，让我们将对模型的依赖关系显式地表示为 `p(y|M[i])`。假设模型的选择是随机的，再次调用贝叶斯定理，我们得到

```
P(M_i|y) = P(M_i)p(y|M_i) / p(y),
```

(12.29)

其中

$p(\mathbf{y}) = \sum\limits_{i}P(\mathcal{M}_{i})p(\mathbf{y}|\mathcal{M}_{i}),$

其中 $P(\mathcal{M}[i])$ 是 $\mathcal{M}[i]$ 的先验概率；$P(\mathcal{M}[i])$ 提供了对所有可能模型的主观先验度量，这表达了我们在数据到达之前，对某模型相对于其他备选模型的合理性的猜测。由于公式 (12.29) 中的分母与模型无关，因此可以通过最大化分子，在观测到 $\mathbf{y}$ 后获得最可能的模型。如果给所有可能的模型分配相等的概率，那么在给定观测集下检测最可能的模型，就变成了关于模型 $\mathcal{M}[i]$ 最大化 $p(\mathbf{y}|\mathcal{M}[i])$ 的任务。这就是该概率密度函数被称为模型的*证据函数*或简称为*证据*的原因。在实践中，我们满足于使用最可能的模型，尽管正统贝叶斯派会建议像公式 (12.30) 那样，对所有可能模型获得的所有量进行平均。在理想的贝叶斯设定中，不在模型间进行选择；预测是通过对所有可能模型求和来执行的，每个模型按其相应概率加权。然而，在许多实际问题中，我们可能有理由认为证据函数在某个特定模型周围强烈尖峰；毕竟，这种假设可能会大大简化任务。

从数学公式的角度来看，每个模型都用一组非随机（确定性）参数来表示。获得使证据最大化的模型，等价于关于这些参数进行最大化。例如，假设在回归任务中，我们为噪声采用高斯分布，为回归任务的随机参数 $\mathbf{\theta}$ 采用高斯先验。那么这一对高斯分布构成了我们的模型，描述该模型的参数是这两个高斯分布各自的协方差矩阵以及先验的均值。为了区别于描述原始学习任务（如回归）的随机参数 $\mathbf{\theta}$，这些额外的参数通常被称为*超参数*。稍后，在第 13 章中，我们将看到超参数也可以被视为随机变量。我们现在将注意力转向隐藏在关于不同模型优化 $p(\mathbf{y}|\mathcal{M}[i])$ 背后的内容。在继续之前，值得评论一下。肤浅的初看可能会让人怀疑这是否与最大化似然 $p(\mathbf{y}; \mathbf{\theta})$ 有何不同，正如第 12.2.1 节所做的那样。事实上，这两种情况属于两个不同的世界。ML 在采用的模型内关于单个（向量）参数进行最大化，而这正是使 ML 易受过拟合影响的弱点。最大化证据是关于模型本身的优化任务，这是一种明智的替代方案，可以防止过拟合，正如我们接下来所解释的。

由公式 (12.14) 可得

![Equation](img/fx003.jpg)(12.31)

为简单起见，假设 $\theta$ 是标量，$\theta \in \mathbb{R}$，并且公式 (12.31) 中的被积函数根据贝叶斯定理类似于后验 $p(\theta|\mathbf{y}, \mathcal{M}[i])$，在某个值附近达到峰值；这显然是会作为 MAP 估计 $\hat{\theta}_{MAP}$ 结果的值。图 12.3 说明了相应的图形。因此，公式 (12.31) 可以近似为

*p*(**y**|ℳ[*i*]) ≈ *p*(**y**|ℳ[*i*], *θ̂*[*MAP*])*p*(*θ̂*[*MAP*]|ℳ[*i*])*Δ**θ*[*θ*|*y*].

![Equation](img/si122.png) (12.32)

为了更好地理解公式 (12.32) 中涉及的各个因子，让我们还假设先验 PDF 是（近似）均匀的，其宽度等于 Δ*θ*。那么公式 (12.32) 可重写为

```
$p(\mathbf{y}|\mathcal{M}_{i}) \approx p(\mathbf{y}|\mathcal{M}_{i},{\widehat{\theta}}_{MAP})\frac{\Delta\theta_{\theta|y}}{\Delta\theta}.$
```

![Equation](img/si123.png) (12.33)

公式 (12.33) 右侧乘积中的第一个因子与似然函数在其最优值处重合，因为对于这种均匀先验的情况，*θ̂*[MAP] = *θ̂*[ML]。换句话说，该因子为我们提供了模型 ℳ[*i*] 在给定观测集上所能达到的最佳拟合。然而，现在与 ML 方法相反，证据函数还取决于第二个因子，$\frac{\Delta\theta_{\theta|y}}{\Delta\theta}$。正如文献 [13,27,28] 所指出的，这一项解释了模型的复杂度，并因显而易见的原因被称为奥卡姆因子。让我们遵循文献 [28] 中给出的推理，对此进行更详细的阐述。

![Figure 12.3 The posterior peaks around the value {\widehat{\theta}}_{MAP} Equation and the posterior PDF can be approximated by p({\widehat{\theta}}_{MAP}|\mathbf{y};\mathcal{M}_{i}) Equation over an interval of values equal to Δθθ|y.](img/gr003.jpg)

图 12.3 后验分布在 *θ̂*[*MAP*] 值附近达到峰值，后验 PDF 可在等于 Δ*θ*[*θ*|*y*] 的数值区间内由 *p*(*θ̂*[*MAP*]|**y**; ℳ[*i*]) 近似。

奥卡姆因子会惩罚那些针对接收到的观测值进行精细调整的模型。举个例子，如果两个不同的模型 `ℳ[i]` 和 `ℳ[j]` 其先验概率密度函数（PDF）的取值范围相似，那么如果 `Δθθ|y ≪ Δθθ|y`，则 `ℳ[i]` 会受到更大的惩罚；接收到 `y` 后，只有很小范围的 `θ` 值能够保留下来（即对应于高概率值）。因此，如果这种针对数据精细调整的模型 `ℳ[i]` 导致了最大似然（ML）项取较大值，也不一定证据会因此而最大化，因为奥卡姆因子会很小。这两个模型究竟哪个最终胜出，取决于这两个相关项的乘积。稍后我们将看到，奥卡姆项也与参数数量有关，即与所采用模型的复杂度有关。
