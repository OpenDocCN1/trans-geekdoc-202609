
在有约束对手的假设下，主要研究成果可进一步划分为博弈论解决方案和非博弈论解决方案。对于实践者而言，困难在于为手头的问题选择最合适的方法。在博弈论框架下开发的解决方案几乎总是假设一个理性博弈。此外，假设每个参与者都拥有关于对手的一定知识量。同样，非博弈论方法通常对对手的知识、损坏数据的分布以及可用计算资源做出假设。在实践中，对手很少是最优的，且他们拥有的知识和资源难以评估。对于分类问题，常见的假设是数据独立同分布。当存在主动对手修改数据以影响预测时，这一假设极易被违反。当数据以不可预测的方式持续被修改时，训练数据永远不足以诱导出一个准确的分类器。积极的一面是，在训练时我们可以探索特征空间，找到对手在特征空间中移动数据以影响分类器的最有效方向。一旦找到这样的方向，我们就可以通过应对这些潜在移动来改进分类器。

虽然在第 10 章中我们讨论了对抗支持向量机学习，但本章讨论的学习模型是*相关向量机*（RVM）。与支持向量机方法类似，RVM [TIPP2001] 是一种稀疏线性参数化模型。它建立在稀疏模型的贝叶斯框架之上。与支持向量机引入惩罚项以避免模型参数过拟合不同，相关向量机模型以一组超参数的形式引入了权重的先验分布，每个超参数独立地与一个权重相关联。超参数的极大值（对应零权重）意味着输入无关。与剩余非零权重相关联的训练数据点被称为*相关向量*。相关向量机通常比 SVM 使用少得多的核函数。

在本章中，我们提出了一种用于对抗学习的稀疏相关向量机集成。该方法的基本思想是为输入空间中每个维度 `d[i]` 学习一个单独的核参数 `η[i]`。这些参数连同权重及其相关的超参数一起从数据中迭代估计。在每次迭代中更新核参数，使得正类（恶意）数据点的似然度最小化。这实质上将对抗攻击建模为对手被授予了访问学习算法内部状态的权限。我们不使用固定的核参数，而是在学习算法更新相关向量机的权重和权重先验时，搜索能够模拟最坏情况攻击的核参数。我们学习 `M` 个这样的模型并将它们组合起来形成最终假设。

我们的主要贡献包括：

*   将稀疏贝叶斯相关向量机模型扩展以应对对抗攻击；
*   开发了一种核参数拟合技术，以在 RVM 框架内建模对抗攻击。

个性化核参数的使用已被证明对基于核的学习有益 [TIPP2001]；然而，这是首次将其应用于对抗学习。

## 11.2 相关工作

关于恶意噪声率和学习准确性的界限，有若干理论结论。Kearns 和 Li [KEAR1993] 证明了样本中可容忍的恶意错误率的理论上界。他们假设对手可以生成性质未知且不可预测的恶意错误。Bshouty 等人 [BSHO1999] 引入了一种 PAC 学习模型的变体，用于在存在恶意噪声的情况下进行学习。他们证明了当样本噪声率为 `η` 时，没有任何学习算法能以低于 `2η` 的准确度学习非平凡概念类。Auer 和 Cesa-Bianchi [AUER1998] 提出了一种用于处理损坏数据的在线学习模型。他们扩展了“闭包算法”，并证明了学习任意交换闭合概念类的最坏情况错误界。Lowed 和 Meek [LOWD2005] 提出了一种寻找具有最小对抗成本实例的算法。他们将该算法称为对抗分类器逆向工程（ACRE）算法。对抗学习问题已在博弈论框架内得到广泛研究。Dalvi 等人 [DALVI2004] 将学习问题视为两个成本敏感对手之间的博弈。对手总是采取最优策略。给定一个成本函数，他们的算法预测使条件效用最大化的类别。Kantarcioglu 等人 [KANT2011] 提出了一种模拟退火和遗传算法，用于搜索纳什均衡以选择最优属性集。他们假设双方都知道对方的收益函数。关于如何博弈纳什策略的改进类似工作也已被提出 [BRÜC2009, LIU2010]。Brückner 和 Scheffer [BRÜC2011] 通过假设对手总是理性行事，提出了一种最优博弈。他们的算法不要求唯一均衡。

在略有不同的研究途径中，人们提出了稳健学习技术来处理分类时噪声 [DEKE2008, DEKE2010, LANC2002, TEO2007]。Globerson 和 Roweis [GLOB2006] 研究了分类时特征删除问题。他们提出了一种 SVM 算法，在预定义约束下构建最优分类器。El Ghaoui 等人 [GHAO2003] 提出了一种针对由超矩形界定的训练数据的极大极小策略。他们将给定区间内数据的最坏情况损失最小化。

Zhou 等人 [ZHOU2012a] 提出了两种攻击模型，并推导出了相应的最优学习策略。他们构建了一个凸优化问题，其中约束基于所提出的攻击模型定义在样本空间上。他们证明，其对抗 SVM 模型比标准 SVM 和单类 SVM 模型更能抵御对抗攻击。

## 11.3 相关向量机

给定一组 *N* 个训练数据 (*x*[*i*], *y*[*i*])，*i* = 1, …, *N*，其中 *x*[*i*] ∈ ℝ^*d* 为 *d* 维数据点，*y*[*i*] ∈ {0, 1} 为标签，输入空间上的函数 *h*(*x*) 通过以下线性加权形式推断：

*h*(*x*; *w*) = *w*^*T**φ*(*x*)

其中 *φ*(*x*) 表示基函数，且

*φ*(*x*) = [1, *K*(*x*, *x*[1]), *K*(*x*, *x*[2]), …, *K*(*x*, *x*[*N*])]

其中 *K*(*x*, *x*[*i*]) 为核函数。对于二分类问题，给定输入 *x* 的类别成员资格的后验概率为：

```
p(y | w) = ∏_{i=1}^N g(h(x_i; w))^{y_i} [1 - g(h(x_i; w))]^{1 - y_i}  (11.1)
```

其中 *g*(*t*) 为应用于 *t* 的 Sigmoid 函数 *g*(*t*) = 1 / (1 + *e*^(−*t*))。

由于权重参数的数量与训练样本一样多，模型会遭受过拟合。为避免过拟合，在权重上定义了零均值高斯先验，每个先验由其自身的超参数 *α* 控制。因此，

```
p(w | α) = ∏_{i=0}^N N(w_i | 0, α_i^{-1})
```

其中 *α*[*i*] 为 *w*[*i*] 的超参数。为每个权重分配单独的超参数相当于一个正则化惩罚项。当超参数取值很大（通常趋近无穷大）时，正则化效应变得极大，以至于相应的权重参数迅速收敛到零，从而可以剪除相应的基函数。当超参数取值很小时，先验对其调节的权重参数影响极小，因此相应的基函数 *φ**k* 即为相关特征，其所中心的样本 *x*[*k*] 被选为相关向量。

由于权重后验 *p*(*w* | *y*, *α*) 和边际似然 *p*(*y* | *α*) 无法解析计算，Tipping [TIPP2001] 采用拉普拉斯近似方法，迭代估计以均值 $\bar{w}$ 为中心的高斯分布对 *p*(*w* | *y*, *α*) 的近似后验协方差。随后利用均值和协方差来优化超参数 *α*。详情请参阅其著作 [TIPP2001]。

在相关向量机的贝叶斯框架内，我们引入另一组参数，直接对输入空间中每个维度上两个向量的差异进行加权。在下一节中，我们将讨论利用单独的核参数来建模对抗攻击。

## 11.4 核参数拟合

### 11.4.1 我们的方法

RVM 训练过程迭代更新权重向量 `w` 和超参数向量 `α`。设想在每次迭代中，对手都有机会修改训练数据，特别是正类（恶意）训练数据，使其能够跨越当前迭代推断出的决策边界。对手修改数据的最佳策略是什么？如果对手可以自由地向有利于自己的方向移动每个数据点，他会遵循使正类实例被错误分类的可能性增加最大的方向。在讨论搜索该方向的技术之前，我们先讨论核及其输入尺度参数。

### 11.4.2 核参数向量

考虑 RBF 核

*K*(*x*[*i*], *x*[*j*]) = exp(−*η*‖(*x*[*i*] − *x*[*j*])‖²)

其中 *η* = (*η*[1], …, *η*[*d*]) 为 *d* 个参数的向量，*η*[*k*] 为第 *k* 个参数，位于第 *k* 个输入维度的平方距离 (*x*[*ik*] − *x*[*jk*])² 之前。通常只有一个核参数，其值通常通过交叉验证确定。我们使用单独的核参数，以便在每个维度中建模对抗性数据修改。例如，当对手修改第 *k* 维使得 *x*[*ik*] ≈ *x*[*jk*] 时，令 *η*[*k*] ≈ 0 可达到相同效果。因此，通过调整输入第 *k* 维的核参数，我们可以在输入空间和特征空间中建模对抗攻击。随后我们可以更新权重参数及相应的超参数以对抗攻击。

下面展示典型的 RBF 核和我们使用的 RBF 核。

典型 RBF 核

*K*(*x*[*i*], *x*[*j*]) = exp(−*η*‖(*x*[*i*] − *x*[*j*])‖²)

我们使用的 RBF 核为：

```
η = (η_1, …, η_d)
K(x_i, x_j) = exp(-‖η · (x_i - x_j)‖²)
```

即，

```
K(x_i, x_j) = exp(-∑_{k=1}^d η_k · (x_ik - x_jk)²)
```

### 11.4.4 训练问题

在训练过程中，我们需要迭代更新三个参数：权重 `w`、超参数 `α` 和核参数向量 `η`。更新这些参数的一种方法是同时优化 `w|α` 和 `η`。这使我们能够找到最优解，但计算量会很大。另一种方法是交替更新 `w`/`α` 和 `η`。对于每一个 (`w`，)，我们基于对数似然的梯度搜索 `Δη` 的几个步骤，并通过向 `η` 添加 `τ · Δη` 来更新它，其中 `τ` > 0 为动量。这种方法可能无法得到期望的解，但效率更高。在本章中，我们采用局部更新方法。我们训练多个对抗 RVM 模型，并选择满足 `u`[+] < `ρ` · `u`[−] 的 `M` 个模型，其中 `u`[+] 表示预测正训练实例的不确定性，`u`[−] 表示预测负训练实例的不确定性，`ρ` ∈ (0, 1] 为正常数。比率

```
ρ = u₊ / u₋,
```

越小，决策边界距离正训练样本越远。也就是说，当集成中的分类器数量少于 `M` 时，通过学习 `w`/`α` 和 `η` 来训练一个对抗 RVM 分类器 `h`[i]；然后如果满足

```
u₊ < ρ · u₋
```

则将 `h`[i] 加入集成。

不确定性 `u`[+] 和 `u`[−] 分别在正、负训练数据上按如下方式估计：

```
u₊ = (Σᵢ yᵢ · (1 - h(xᵢ; w))) / Σᵢ yᵢ          (11.4)
```

```
u₋ = (Σᵢ (1 - yᵢ) · h(xᵢ; w)) / Σᵢ (1 - yᵢ)    (11.5)
```

其中

```
Σᵢ yᵢ
```

为正训练实例的总数，

```
Σᵢ (1 - yᵢ)
```

为负训练实例的数量。我们选择 `M` 个这样的模型并将它们组合起来，通过多数表决进行最终预测。

### 11.4.5 对抗 RVM 学习算法

我们现在介绍对抗 RVM 学习算法，即 `AD-RVM`。给定一组训练数据，我们首先初始化 `α` 的值并用它来更新权重向量 `w`；接下来，在给定 `w` 和 `α` 的情况下更新核参数向量 `η`；最后更新超参数 `α`。该过程迭代预定义的最大轮数。我们训练多个此类分类器，并选择满足 `ρ u`[+] < `u`[−] 的 `M` 个分类器组成集成。详细算法见 算法 11.1。
