
# 数据与任务的物理学：深度学习中的局部性与组合性理论

## 摘要

深度神经网络取得了卓越的成功，但我们对它们如何学习的理解仍然有限。这些模型可以学习高维任务，而由于“维度灾难”，这些任务通常情况下是不可行的。这种明显的悖论表明，数据具有某种底层结构。这种结构的本质是什么？神经网络是如何编码并利用它的？它又是影响性能的——例如，泛化能力如何随着训练示例数量的增加而提高？

本论文通过研究局部性和组合性在数据和深度学习中的作用来解决这些问题。我们首先分析了无限宽度限制下的卷积网络，在这种情况下，学习变得简单且在分析上是可行的。利用统计物理和学习理论的工具，我们表征了它们的泛化能力，并证明如果目标函数是局部的，它们就可以克服维度灾难。

我们转向更复杂的结构，其中特征按层次组合，较大的元素由较小尺度构建。我们使用简单的概率模型对图像数据进行建模。在该框架内，我们研究了基于扩散的模型如何通过组合示例特征来生成新数据。该理论预测了生成过程中的相变，我们在图像和语言中通过实验证实了这一点，为自然数据的假设提供了支持。我们进一步证明，学习这些任务的样本复杂度随数据多项式增长，这为模型避免维度灾难提供了机制。

最后，我们将分析从输入空间的数据结构转移到参数空间中的结构。在这里，我们研究了一种新型的组合形式，即任务可以组合。特别是，我们通过实验证明了大模型权重空间中的不同方向与函数空间中的特定任务区域相关，以及这种模块化结构如何实现大规模的任务编辑。

**关键词**：深度学习、泛化、缩放法则、数据结构、局部性、组合性、概率图模型、卷积网络、扩散模型。

## 1.1 深度学习导论

### 1.1.1 基于深度神经网络的监督学习

机器学习中最基础的设定是监督学习，模型通过示例学习从输入到标签的映射。例如，在从图片中分类动物物种的任务中，模型在带有正确标签的图像示例上进行训练，目标是准确分类新的、未过的图像。

形式上，每个输入`x_i ∈ X`都配对一个标签`y_i ∈ Y`。输入空间`X`通常是高维的（例如，`X = R^d`，其中`d >> 1`代表图像中的像素数量）。输出空间可以代表实值`Y ∈ R`（回归）或类别标签`Y = {1, ..., C}`（分类，如上述的动物物种）。学习者获得`P`个示例`(x_i, y_i)_{i ∈ P}`，即训练集，其中假设`(x_i, y_i)`是从`X × Y`上的联合分布`p`独立同分布地抽自的。

在深度学习中，用于学习这种映射的模型类由深度神经网络表示。在最基础的形式中，全连接神经网络（`FCN`）这些模型由连续的线性变换层组成，中间穿插着非线性激活。一个具有`L`个隐藏变换的网络通过以下方程将输入`x`转换为输出`f(x, θ)`：

```
z^{(1)} = σ^{(1)}(w_h^{(1)T}x + b^{(1)}) for h ∈ [H]
z^{(l)} = σ^{(l)}(w_h^{(l)T}z^{(l-1)} + b^{(l)}) for h ∈ [H], l ∈ [2, ..., L]
f(x, θ) = z^{(L+1)}
```

> 全连接网络是最简单的神经网络架构。

`θ`表示一个包含所有从数据中学的参数（即权重`w_h^{(l)}`和偏置`b^{(l)}`）的向量，层位于`l ∈ [L + 1]`。函数`σ^{(l)}`是标量激活函数，逐元素应用，`ReLU`非线性函数`σ(u) = max(0, u)`。`L`被称为网络的深度，`H`被称为网络的宽度。

监督学习的主要目标是找到参数`θ`使泛化误差最小化。

这些架构先验知识显著减少了参数数量，并增强了在具有空间结构任务上的泛化能力，支撑了深度学习的革命。

### 1.1.2 理论谜题

尽管深度神经网络取得了卓越的经验成功，我们对高维任务如何保持有效的理论理解仍然有限。一个核心问题是：模型需要多少数据点才能以良好的精度学习一项任务？也就是说，泛化误差`E(P)`是否随着训练示例数量`P`的增加而减小？值得注意的是，从经验上看，对于许多高维任务，`E(P)`符合幂律衰减拟合：

```
E(P) ~ P^{-β}
```

其中指数`β`捕捉了模型从数据学习的效率。这些经验缩放律表明`β`取决于数据集、任务和算法。一般性工作表明，`β`在输入维度`d`很大时会消失，这意味着在维度很大的设定中，学习实际上是不可能的，而现实中恰恰如此（例如，`d`是像素和颜色通道数的图像）。这就是维度灾咒的本质。在高维空间中，体积随`d`指数级增长。
