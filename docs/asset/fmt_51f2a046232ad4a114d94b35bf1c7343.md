# 问题 204

# 问题 205

- (A) 应用程序的侧载

- (D) 使用开放的 Wi-Fi 网络

**选项 D 是错误的。** 使用开放的 Wi-Fi 网络可能会使移动设备暴露在威胁中，但 Sarah 的漏洞源于获取 root 权限，而不是她对 Wi-Fi 网络的选择。

# 问题 206
在某公司中心数据库遭受最近的网络攻击后，IT 部门被要求增强其网络基础设施的安全性。以下哪种技术是**最佳**的，可以确保人力资源和财务等不同部门无法访问对方的敏感数据？

- (A) 基于部门实施网络分段
- (B) 升级整个网络的带宽
- (C) 为所有部门使用单一的强密码
- (D) 将所有部门数据移动到云端

**选项 B 是错误的。** 虽然升级带宽可能会提高网络速度，但它没有解决部门数据隔离的安全问题。

# 问题 207
在组织的安全审查期间，网络安全分析师注意到不同的用户账户有多次失败的登录尝试，每个账户使用了几个常用的密码。这种场景**最准确**描述了哪种类型的密码攻击？

- (A) 暴力破解攻击
- (B) 字典攻击
- (C) 凭据填充攻击（Credential Stuffing）
- (D) 密码喷洒（Password Spraying）

**解释 207. 正确答案：D。密码喷洒。** 密码喷洒是一种攻击方法，攻击者对多个用户账户尝试几个常用的密码，而不是对单个账户尝试许多密码。描述的场景是针对多个具有常用密码的用户账户，这与该方法相符。

**选项 A 是错误的。** 暴力破解攻击涉及对特定账户尝试所有可能的密码组合。场景描述的是在多个账户上尝试常用密码，而不是在一个账户上进行穷举组合。

**选项 B 是错误的。** 字典攻击涉及对单个账户尝试可能的密码列表（这些列表通常从字典或常用密码列表中提取）。该场景强调的是多个账户。

**选项 C 是错误的。** 凭据填充涉及使用之前泄露的用户名和密码对来获取未经授权的访问。重点是使用已知的凭据，而不是常用密码。

# 问题 209
某组织的 IT 部门注意到过去 24 小时内网络流量迅速增加。同时，许多员工报告他们的系统变慢，并且通过电子邮件从同事那里收到了一个名为`updatePatch.exe`的文件，尽管这些同事并没有故意发送任何文件。哪种类型的恶意软件最可能负责这种行为？

- (C) 广告软件

# 问题 210

# 问题 211
一个机构正在为数字签名选择哈希函数。他们希望确保该函数能够抵抗攻击者产生两个具有相同哈值的不同消息的情况。他们正试图防御哪种攻击？

- (A) 旁信道攻击
- (B) 重放攻击
- (C) 生日攻击
- (D) 仅密文攻击

**解析 211。正确答案：C。生日攻击。** 在生日攻击中，攻击者利用概率论中生日问题背后的数学原理，旨在找到两个产生相同输出（或哈值）的不同输入。在为数字签名选择哈希函数时，选择一个抵抗生日攻击的函数对于维护签名完整性至关重要。

选项 A 错误。旁信道攻击涉及从加密系统的物理实现获取信息，而不是利用算法或协议的理论缺陷。它与产生具有相同哈值的消息无关。

# 问题 212
一个 IT 安全团队收到报告，称一个新的、此前未知的漏洞正在野外被积极利用。软件供应商尚未为该漏洞提供补丁。关于该漏洞，最准确的术语是什么？

- (A) 遗留漏洞
- (B) 零日漏洞
- (C) 已修复漏洞
- (D) 已知漏洞

**解析 212。正确答案：B。零日漏洞。** 零日漏洞指的是软件、硬件或固件中对于供应商未知的缺陷。这种漏洞存在风险，因为在发现时没有修复程序或补丁，而且它可能已经被恶意攻击者积极利用。

选项 A 错误。遗留漏洞通常指旧软件或系统中的漏洞，这些系统可能不再支持，而不一定是未知且未修复的漏洞。

选项 C 错误。已修复漏洞意味着该漏洞已有可用修复方案。在提供的场景中，尚未发布补丁。

选项 D 错误。虽然该漏洞可能对某些实体（如此场景中的安全团队）已知，但对软件供应商来说仍然未知的。因此，在此语境下，“已知漏洞”不是最准确的描述符。

# 问题 213
一家公司最近部署了一个新的电子商务应用程序。安全团队希望确保能够检测到应用程序上的任何未经授权或恶意的活动。以下哪种是实现这一目标的最有效方法？

- (B) 在应用程序前安装防火墙

# 问题 215
一家中型公司刚刚为 HR 部门部署了一个新的文件服务器。他们希望确保只有 HR 员工可以查看和编辑 HR 特定的文档，而 IT 部门应仅执行维护任务。公司应该实施什么来实现这一要求？

- (A) 在 HR 和 IT 部门之间安装防火墙
- (B) 为文件服务器实施访问控制列表 (ACL)
- (C) 为 HR 部门强制强密码策略
- (D) 对文件服务器启用全盘加密

**解析 215。正确答案：B。为文件服务器实施访问控制列表（ACL）。** 访问控制列表（ACL）定义了谁可以访问资源以及他们在访问后可以对资源执行的操作。通过为文件服务器设置 ACL，公司可以精确地定义人力资源部门和 IT 部门的权限，确保只有授权用户才有权以相应的级别访问数据。

选项 A 错误。安装防火墙会限制部门之间的网络流量，但无法提供对服务器上文件进行细粒度的访问控制。

选项 C 错误。虽然强力密码策略对于安全至关重要，但它无法区分人力资源部门和 IT 部门之间的访问，也无法控制用户在访问服务器后可以的操作。

选项 D 错误。全磁盘加密保护静态数据的安全，但它无法根据用户规则对特定文件或目录提供差异化访问。

# 问题 216
某电子商务网站突然流量激增，导致网站运行缓慢且有时无法访问。IT 团队观察到，大量请求源自分布在不同国家的 IP 地址。该电子商务网站可能正在经历哪种网络攻击？

- (A) 中间人攻击
- (B) DNS 欺骗
- (C) 分布式拒绝服务（DDoS）攻击
- (D) ARP 投毒

**解析 216。正确答案：C。分布式拒绝服务（DDoS）攻击。** 在 DDoS 攻击中，攻击者利用多个系统（通常是来自不同位置受入侵系统）向目标系统发送大量请求，导致目标系统缓慢或无法访问。

选项 A 错误。中间人攻击涉及攻击者秘密地拦截并可能篡改双方之间的通信。它不会由于高流量导致网站无法访问。

选项 B 错误。DNS 欺骗是指攻击者引入损坏的 DNS 缓存信息，以将流量重定向到不同的 IP 地址（通常由攻击者控制）。它不会导致来自不同国家的流量增加。

选项 D 错误。ARP 投毒是一种攻击者通过向局域网发送伪造 ARP 消息的技术。这通常用于将攻击者的 MAC 地址与另一个主机的 IP 地址绑定，导致任何发往该 IP 地址的流量都被发送给攻击者。

# 问题 217
安全审计员发现网站的登录表单返回详细的错误信息，如“列名错误”或“未找到表”。攻击者可能利用这些信息利用哪种漏洞？

- (A) 暴力破解攻击
- (B) 结构化查询注入（SQLi）
- (C) 中间人攻击
- (D) 会话劫持

**解析 217。正确答案：B。结构化查询注入（SQLi）。** 当网站提供详细的数据库错误信息时，它可以给攻击者提供有关数据库结构的线索，使他们更容易构建出成功的 SQL 注入攻击。

通过返回详细的数据库错误信息，网站在无意中为攻击者提供了有关数据库结构和潜在漏洞点的宝贵见解。这可以被用于精炼和增强 SQLi 攻击，使攻击者能够访问、修改或删除数据。

选项 A 错误。暴力破解攻击涉及尝试许多密码或短语以猜出正确的。数据库的详细错误信息通常不用于暴力破解。

选项 C 错误。中间人攻击拦截并可能篡改双方之间的通信。数据库错误信息与此类攻击没有直接关系。

选项 D 错误。会话劫持涉及接管活动的用户会话。详细的数据库错误信息在此类攻击中不起直接作用。

# 问题 218
某大型公司的一名员工最近从网站为公司配发的移动设备安装了一个 App，而不是通过批准的应用商店。该 App 声称能帮助提高效率，但不久后，发现移动设备上的敏感数据被传输到未知服务器。利用了哪种移动端漏洞？

- (A) 密码策略不完善
- (B) 无线连接连接
- (C) 侧载攻击
- (D) 缺乏加密

**解析 218。正确答案：C。侧载攻击。** `Sideloading`指的是从官方应用商店之外的来源安装应用。该场景涉及从非授权来源安装 App。

选项 A 错误。密码策略不完善与从非官方商店安装应用无关。

选项 B 错误。无线连接不安全可能导致数据泄露，但场景描述的是安装未经审核的应用。

选项 D 错误。缺乏加密是关于数据传输，而非安装未经审核的应用。

# 问题 219
XYZ 公司的 IT 部门发现服务器日志在非工作时间记录了登录尝试，且这些尝试发生在异常时间段。以下哪项是该现象最合理的解释？

- (A) 员工正在加班
- (B) 服务器存在时区配置错误
- (C) 未授权用户正尝试访问
- (D) 服务器正在自动安装补丁

**解析 219。正确答案：C。未授权用户正尝试访问。** 非工作期间的异常登录尝试通常是恶意访问的迹象。

选项 A 错误。虽然员工可能会加班，但这通常不会解释日志中记录的异常访问模式。

选项 B 错误。时区配置错误可能导致日志时间显示错误，但不会产生大量的登录尝试记录。

选项 D 错误。服务器自动安装补丁不会产生此类登录尝试记录。

# 问题 220
一名员工注意到，当在使用 RFID 卡进入办公楼时，有一个陌生人拿着一个不熟悉的设备离她非常近。几天后，她同事的卡突然失效了，尽管卡并未报告丢失或损坏。安全团队应该怀疑是哪种类型的攻击？

- (A) 访问控制系统的暴力破解攻击
- (B) RFID 克隆攻击
- (C) 尾随入侵
- (D) RFID 干扰

**解析 220。正确答案：B。RFID 克隆攻击。** RFID 克隆涉及对 RFID 卡进行非法复制，或通过捕获其信号来实现。那个陌生人拿着设备离得很近可能是捕获了 RFID 信号进行克隆。

选项 A 错误。访问控制系统的暴力破解攻击涉及尝试多种组合以获取权限，场景并未描述多次访问尝试或与系统本身的交互。

选项 C 错误。尾随入侵（Tailgating）是在没有相应权限的情况下跟随授权人员进入安全区域。场景描述的是可能的 RFID 获取，而非跟随他人。

选项 D 错误。RFID 干扰是指干扰 RFID 信号使其无法工作，而不是复制 RFID 详情进行非法使用。
