
# 连接到远程桌面 PC

在机器上启用远程桌面后，你可以使用“远程桌面连接”应用程序从另一个 Windows 客户端或服务器连接到它。如果你连接的是局域网 (LAN) 之外的系统，任何入站防火墙 ACL 规则必须允许端口 3389。连接到局域网内的主机最为简单。

- 1. 从 Windows 7 或 Vista 桌面，通过点击“开始”按钮开始远程桌面连接。在搜索框中输入**远程桌面连接**（英文为 **Remote Desktop Connection**），然后在结果列表中点击“远程桌面连接”。

- 2. 在“计算机”框中，输入你想要连接的计算机名称，然后点击“连接”（你也可以输入 IP 地址来代替计算机名称）。

- 3. 点击“选项”下拉箭头，查看自定义显示选项；配置对本地资源的访问；限制访问并从而在连接时仅允许执行特定程序；以及根据连接速度配置连接过程中的体验（例如连接的图形丰富程度）。

- 4. 在“常规”选项卡中，输入你想要连接的授权远程用户名

如果你看到显示“无法验证证书”（The Certificate Cannot Be Verified）的提示，请不要担心。这表示服务器正在使用自签名证书。如果你知道可以信任服务器，请点击“是”进行连接。

Windows 远程程序 (RDC) 可以通过计算机开始菜单上的快捷方式启动，也可以通过命令行启动。如果你觉得使用命令行更方便，或者只是想更熟悉它，了解如何执行此项操作将是一项非常有价值的学习技能。微软终端服务客户端 (MSTSC) 可用于创建到远程桌面会话主机的连接，或编辑现有的远程桌面连接配置文件（使用 .rdp 扩展名）。

- 1. 打开命令提示符。点击“开始”，在运行窗口中输入 CMD，然后按回车。

![](img/7868547987f5920cfe632b85047c64af_639_0.png)

在后续实验中，我将直接指示你“执行”命令，而不是“输入”命令并按回车。

- 2. 要从命令提示符访问 RDC，请使用 MSTSC.EXE。决定你想用哪些选项启动 RDC 程序。可用选项有：

```
MSTSC.EXE /v: /f /w: /h:
```

其中 `MSTSC.EXE` 是程序名称，`/v:` 是用于指定远程计算机的命令，`/f` 以全屏模式启动 RDC，而 `/w:` 和 `/h:` 选项指定窗口大小（如果你没有选择使用全屏模式）。

- 3. 在命令提示符中输入 `mstsc.exe` 连同你想使用的开关以启动 RDC 客户端。选择你想连接的用户。

系统可以支持多个 VPN 连接。由于安全要求各异，因此每个 VPN 都有自己的“属性”对话框。

Windows 默认 VPN 身份验证协议 MSCHAP V2 仅支持使用安全（哈希）密码进行身份验证。为了提供更强的身份验证，可以使用数字证书对计算机进行相互验证。你通过选择“VPN 类型”下的“高级设置”来配置此项。通常会建立公密钥基础结构 (PKI)，允许系统仅使用域内凭据进行身份验证。

安全性较低的相互身份验证方法是在客户端和服务器上配置预共享密钥（密码），类似于 Wi-Fi 或 RADIUS 使用的密钥。同样，你通过选择“VPN 类型”下的“高级设置”来操作。

强身份验证对任何网络都关重要。在设置 VPN 时尤其为重要，因为攻击者很容易通过此后门未经授权地访问你的公司局域网。你需要将 VPN 访问限制为那些具有合法业务需求的用户。

## A6：使用 Windows 命令行界面 (CLI)

命令提示符是 Windows 的一个功能，提供了一个非图形界面（外），用于输入 MS-DOS 和其他底层计算机命令。要打开命令提示符界面，点击“开始”按钮，在“运行”字段中输入 **cmd**，然后按回车键。

命令行工具适用于各种任务，开关可以提供增强功能。要查看常用命令列表，在命令提示符处输入 **help**，然后按回车键。要查看有关这些每个命令的更多信息，请输入 **help command name**，其中 **command name** 是你想获取更多信息的命令名称。访问 technet.microsoft.com/en-us/library/cc754340.aspx 查看命令行参考。至少，CASP 应该熟悉以下命令：

- **DIR** 显示目录文件和子目录的列表。如果不带参数使用，`dir` 将显示磁盘的卷标和序列号，然后列出磁盘上的目录和文件列表（包括名称以及最后修改日期和时间）。对于文件，`dir` 会显示扩展名和以字节为的大小。

- **IPCONFIG** 显示系统上每个活动网适配器 (NIC) 的所有 TCP/IP 网络配置值。开关允许刷新动态主机配置协议 (DHCP) 和域名系统 (DNS) 设置。在不带参数的情况下，`ipconfig` 显示所有适配器的 Internet协议版本 4 (IPv4) 和 IPv6 地址、子网掩码和默认网关。有多个可用开关，最重要的是：

- `/all` 显示所有适配器的完整 TCP/IP 配置。适配器可以代表物理接口（如已安装的网络适配器）或逻辑接口（如拨号连接）。
