
再次，我们看到了验证准确率的另一次跃升和损失的下降，尽管不如上次明显（图 10.6，左下角）。SqueezeNet 在第 75 个 epoch 之后达到了 ~54% 的分类准确率，且没有下降。我决定尝试使用 `1e-5` 的学习率运行几个 epoch 看看是否有差异，但此时学习率太低，无法在损失函数平面中找到更低的区域：
