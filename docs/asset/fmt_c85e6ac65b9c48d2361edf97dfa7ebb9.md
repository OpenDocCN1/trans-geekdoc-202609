
正如之前所述，无监督学习是一种通过学习数据的潜在规律性和统计结构来发现并揭示数据中隐藏信息的方法。通过这种方式，预训练可以被视为一种依赖数据的`正则化项`，它通过利用无监督学习获得的额外信息，将未知参数推向存在良好解的区域（参见例如 [47]）。

图 19.2 图示了一个具有三个隐藏层的多层感知机。与任何监督学习任务一样，起点始终是一组训练样本，`(y[n], x[n])`，`n = 1, 2, ..., N`。采用前述方法训练深度多层感知机包含两个主要阶段：(a) 预训练和 (b) 监督微调。与隐藏节点相关的权重预训练涉及通过 RBM 理论进行无监督学习。假设有 `K` 个隐藏层，`h^(k)`，`k = 1, 2, ..., K`，我们成对地查看它们，即 `(h^(k-1), h^(k))`，`k = 1, 2, ..., K`，其中 `h⁰ := x` 为输入层。每一对将以层次化方式被视为一个 RBM，前一个的输出成为下一个的输入。可以证明（例如 [80]），每次增加一层都会增加训练数据对数概率的一个变分下界。

通向输出节点的权重预训练通过监督学习算法执行。最后一个隐藏层连同输出层不被视为 RBM，而是被视为单层前馈网络。换句话说，该`监督`学习任务的输入包含在最后一个隐藏层中形成的特征。

最后，微调涉及在典型的反向传播算法原理中进行重新训练，使用预训练期间获得的值进行初始化。这对于更好地感受和理解学习如何工作非常重要。标签信息`仅`在微调阶段用于隐藏层。在预训练期间，每一层的特征值掌握与输入分布和潜在规律性相关的信息。标签信息不参与发现特征的过程。这部分大部分留给预训练期间的无监督阶段。请注意，即使部分数据未标记，这种类型的学习也能起作用。未标记信息是有用的，因为它提供了关于输入数据的宝贵额外信息。事实上，这是半监督学习的核心（参见例如 [181]）。

关于基于 RBM 的预训练的更多细节，可以在本书网站上当前章节相关的“附加材料”部分找到（另见 [82]）。

### 19.2.3 深度信念网络

上一章的重点在于讨论前馈架构。我们的重点是前馈或自底向上的信息流。然而，这只是整个故事的一部分。另一部分涉及训练`生成`模型。此类学习任务的目标是“教会”模型生成数据。实现这一点的一种方法是通过学习概率模型，将一组可观测变量与另一组隐藏变量联系起来。RBM 只是此类模型的一个实例。此外，必须强调的是，如果使用足够多的隐藏单元，RBM 可以表示任何离散分布 [54,112]。

在本节迄今为止的讨论中，我们将深度网络视为一种逐层形成特征的特征的机制，即输入数据越来越高层的表示。现在的问题在于，能否从对应于最高层表示的最后一层开始，遵循一条`自顶向下`的路径，以生成数据为新目标。除了某些实际应用的需求外，还有一个额外的理由来审视这种反向的信息流。

一些研究表明，这种自顶向下的连接存在于我们的视觉系统中，用于从高层表示生成图像的低层特征。这种机制可以解释做梦时生动意象的产生，以及通过提供来自前几帧的上下文先验信息，对局部图像区域解释产生消歧效应（例如 [110,111,136]）。

表示统计生成模型的一种流行方法是通过使用概率图模型，这些模型在第 15 章和第 16 中进行了处理。生成模型的一个典型例子是 S 型网络，在第 15.3.4 节中介绍，它们属于参数贝叶斯（信念）网络家族。图 19.3A 示出了一个 S 型网络，其中展示了一个有向无环图（贝叶斯）。遵循第 15 章中发展的理论，分布在 *K* 层中的观测变量（***x***）和隐藏变量的联合概率由下式给出

其中第 *k* 层 *I*[*k*] 个节点中的每一个的条件概率定义为

文献 [80] 提出了一条替代路径，遵循的方案类似于之前用于神经网络预训练的方案。换句话说，从输入层开始的所有隐藏层都被视为 `RBMs`，并采用了一种自底向上的贪婪逐层预训练理念。必须强调的是，通过这种方案恢复的条件概率只能被视为真实条件概率的近似。毕竟，原始图是有向的，而不是 `RBM` 假设所施加的无向图。唯一的例外在于顶层，在那里 `RBM` 假设是有效的。

一旦自底向上的过程完成，估计出的未知参数值将被用于初始化另一种微调训练算法；这种方案在文献 [79] 中为训练 S 型网络而开发，被称为 `wake-sleep`（唤醒-睡眠）算法。`wake-sleep` 方案的目标是在自顶向下的过程中调整权重，以最大化网络生成观测数据的概率。该方案具有变分近似的特点，如果随机初始化，收敛需要很长时间。然而，使用从预训练获得的值进行初始化，该过程可以显著加速 [83]。

#### 19.2.4 自编码器

*自编码器*在文献 [12,159] 中被提出作为降维方法。自编码器由两部分组成：*编码器* 和 *解码器*。编码器的输出是输入模式的降维表示，它用一个向量函数定义，

```
f : x ∈ ℝ^l ↦ h ∈ ℝ^m,  (19.6)
```

其中

```
h[i] := fi = ϕe,  i = 1, 2, ..., m,  (19.7)
```

`ϕ[e]` 为激活函数；通常取为逻辑斯蒂 S 型函数，`ϕe = σ(·)`。换句话说，编码器是一个单隐藏层前馈神经网络。

解码器是另一个函数 `g`，

#### 19.2.4 自编码器

$$

\mathbf{g}: \mathbf{h} \in \mathbb{R}^{m} \longmapsto \widehat{\mathbf{x}} \in \mathbb{R}^{l},

$$

其中

$$

\hat{x}[j] = gj = \phi_{d}(\boldsymbol{\theta}_{j}^{\prime T}\mathbf{h} + b_{j}^{\prime}), \quad j = 1, 2, \dots, l.

$$

激活函数 $\phi_{d}$ 通常取为恒等函数（线性重构）或逻辑斯蒂 S 型函数。训练的任务是估计参数

$$

\Theta := [\boldsymbol{\theta}_{1}, \dots, \boldsymbol{\theta}_{m}], \mathbf{b}, \quad \Theta^{\prime} := [\boldsymbol{\theta}_{1}^{\prime}, \dots, \boldsymbol{\theta}_{l}^{\prime}], \mathbf{b}^{\prime}.

$$

通常假设 $\Theta^{\prime} = \Theta^{T}$。参数的估计使得在可用输入样本上，重构误差 $\mathbf{e} = \mathbf{x} - \widehat{\mathbf{x}}$ 在某种意义上达到最小。通常采用平方误差代价，但其他选择也是可能的。涉及参数范数的正则化版本也是一种可能（例如，[155]）。如果激活函数 $\phi_{e}$ 选为恒等函数（线性表示）且 $m < l$（为避免平凡解），则自编码器等价于 PCA 技术 [12]。PCA 在第 20 章中有更详细的论述。

如果在训练期间向输入添加噪声 [191, 192]，则会得到自编码器的另一个版本。这是一个随机对应版本，称为*去噪自编码器*。对于重构，使用的是未损坏的输入。该版本背后的思想是：通过尝试消除噪声的影响，可以捕捉输入之间的统计依赖关系。更具体地说，在 [191] 中，损坏过程随机将某些输入（多达一半）设置为零。因此，去噪自编码器被迫从非缺失值中预测缺失值，针对随机选择的缺失模式子集。

自编码器也已被用于深度网络的预训练，取代了前面讨论的 RBM（例如，见 [81]）。在后者中，采用了多层自编码器，而不是单层。

### 19.2.5 生成对抗网络

在第 19.2.1 和 19.2.3 节中，我们考虑了用于概率分布估计以及数据生成的生成式概率图模型。此类模型的主要缺点在于，在最大化相关似然函数及相关代价以计算定义图模型的未知参数时，存在计算上的难解性。

设计生成模型的另一种路径最早是在文献[61]中描述的。突破性的概念在于放弃*直接*对概率分布建模的想法；取而代之的是采用了一种博弈论场景，让生成器网络与*对抗者*进行*竞争*。^(¹²⁸)

![图 19.4 一类包含真实图像，另一类包含生成图像。后者由生成器产生，生成器以噪声为激励输入。判别器的输出表示输入模式源自真实数据类别的概率。如果两类完全可分，判别器的输出 y 对真实图像将等于 1，对生成图像将等于 0。训练 GAN 的目标是“迷惑”判别器，使其输出对真实和生成图像均变为 1/2。](img/gr004.jpg)

**图 19.4** 一类包含真实图像，另一类包含生成图像。后者由生成器产生，生成器以噪声为激励输入。判别器的输出表示输入模式源自真实数据类别的概率。如果两类完全可分，判别器的输出 `y` 对真实图像将等于 1，对生成图像将等于 0。训练 GAN 的目标是“迷惑”判别器，使其输出对真实和生成图像均变为 1/2。

生成器的输入端接收噪声样本，依据概率分布 `p_z(z)`，该分布通常为均匀分布或高斯概率密度函数（PDF）。生成器对输入噪声向量进行变换。^(¹²⁹)

判别器是一个作为深度神经网络实现的*二分*分类器。其输入接收样本 `x`，并输出相应的概率值 `y = D(x; θ_d)`。参数向量 `θ_d` 包含定义相关神经网络的所有参数，并在训练过程中学习得到。输出值 `y` 表示相应输入模式 `x` 源自观测数据而非生成器的概率。换句话说，`D(x; θ_d)` 是 `x` 为真实样本的概率，而 `1 − D(x; θ_d)` 是 `x` 为生成样本的概率。如果判别器被设计为能做出完美决策，则输出对真实数据应为 1，对生成数据应为 0。

训练期间，参数向量被最优估计，使判别器将真实数据点与生成数据点*混淆*。为此，文献[61]采用了以下双人极大极小博弈值（代价函数）：

```
min_θ_g max_θ_d J(θ_g, θ_d)
```

其中

```
J(θ_g, θ_d) = E_{x~p_r(x)}[log D(x; θ_d)] + E_{z~p_z(z)}[log(1 - D(G(z; θ_g); θ_d))]
```

且 `p_r(x)` 表示与真实数据相关的概率分布（下标 `r` 提醒我们这是 *real* 即真实的意思）。

用文字描述，如果 `θ[g]` 保持固定，则通过 `θ[d]` 训练判别器，使其输出对于真实样本（`D(x; θ[d])`）和生成样本（`1 − D(G(z; θ[g]); θ[d])`）均达到最大化。此外，保持 `θ[d]` 固定，通过 `θ[g]` *同时* 训练 `G` 以最小化 `1 − D(G(z; θ[g]); θ[d])`，从而迷惑判别器。
