之所以在 ICA 中早先拒绝将高斯分布作为源，是因为它不允许对源进行唯一恢复。这是因为 PCA 似然对源 `zt` 和混合矩阵 `W` 的任何正交变换都是不变的。PCA 可以恢复信号所在的最佳线性子空间，但无法唯一恢复信号本身。ICA 要求 `W` 是方阵，因此可逆。在非方阵情况下（例如源比传感器多时），我们无法唯一恢复真实信号，但可以计算后验 `p(zt|xt,W)`，这代表了我们对源的信念。在这两种情况下，我们都需要估计 `W` 以及源分布 `pj`。下面我们将探讨如何做到这一点。

令 `xt ∈ RD` 为时刻 `t` 传感器处观测到的信号，`zt ∈ RL` 为源信号向量。我们假设

```
xt = W zt + ϵt (12.50)
```

其中 `W` 是一个 `D×L` 矩阵，且 `ϵt ∼ N(0,Ψ)`。在本部分中，我们将每个时间点视为独立观测，即我们不建模时间相关性（因此可以用 `I` 替换下标 `t`，但我们保留 `t` 以与大部分 ICA 文献保持一致）。目标是推断源信号 `p(zt|xt,θ)`。在此背景下，`W` 称为混合矩阵。如果 `L = D`（源的数量 = 传感器的数量），则 `W` 为方阵。

在本部分中，我们讨论评估无噪声 ICA 模型中方形混合矩阵 `W` 的方法。按照惯例，我们假设观测值已中心化；因此我们也可以假设 `z` 为零均值。此外，我们假设观测值已白化，这可以通过 PCA 完成。如果数据已中心化且白化，则有 `E[xxT] = I`。然而，在无噪声情况下，我们还有

```
cov[x] = E[xxT] = WE[zzT]WT (12.52)
```

因此我们看到 `W` 必须是正交的。这将我们需要估计的参数数量从 `D2` 减少到 `D(D−1)/2`。它还将简化数学推导和算法。令 `V = W−1`；这些通常称为识别权重，相对于 `W`（即生成权重）。因为 `x = W z`，根据公式 2.46，我们有

```
px(W zt) = pz(zt)|det(W−1)| = pz(V xt)|det(V)| (12.53)
```

因此，假设有 `T` 个独立同分布样本，我们可以写出对数似然如下：

```
log p(D|V) = log |det(V)| + 1/T ∑∑ log pj(vjTxt) (12.54)
```

其中 `vj` 是 `V` 的第 `j` 列。因为我们强制 `V` 为正交，第一项是常数，所以可以省略。我们也可以用期望算子替换对数据的平均，得到以下目标：

```
NLL(V) = ∑ E[Gj(zj)]
```

其中 `zj = vjTx` 且 `Gj(z) ≜ −log pj(z)`。我们需要在 `V` 的列正交的约束下最小化该目标。我们还需要它们具有单位范数，因为这保证了因子的方差为单位（因为对于白化数据，`E[vjTx] = ||vj||2`，这是固定权重尺度所必需的）。换句话说，`V` 应该是一个正交矩阵。推导梯度下降算法来拟合此模型是直接的；然而，它相当缓慢。也可以推导出遵循自然梯度的更快算法；详见例如 (MacKay 2003, ch 34)。一种流行的替代方法是使用近似牛顿法，我们将在第 12.6.2 节中讨论。另一种方法是使用 EM，我们将在第 12.6.3 节中讨论。

### 14.1 简介

我们在下面给出几个例子。到目前为止，在本书中，我们一直假设我们希望分类、聚类或以其他方式处理的每个对象都可以表示为固定大小的特征向量，通常形式为 `xi ∈ RD`。然而，对于某些类型的对象，如何最好地将它们表示为固定大小的特征向量并不清楚。例如，我们如何表示一个文本文档或蛋白质序列，它们可以是可变长度的？或者一个分子结构，它具有复杂的 3D 几何形状？又或者一个系统发育树，它具有可变的大小和形状？解决此类问题的一种方法是为数据定义一个生成模型，并使用推断出的潜在表示和/或模型的参数作为特征，然后将这些特征输入标准方法。例如，在第 28 章 TODO 中，我们讨论深度学习，它本质上是一种学习良好特征表示的无监督方法。另一种方法是假设我们有某种衡量对象间相似性的方法，而不需要将它们预处理为特征向量形式。例如，在比较字符串时，我们可以计算它们之间的编辑距离。令 `κ(x,x′) ≥ 0` 为对象 `x, x′ ∈ X` 之间的某种相似性度量，我们将称 `κ` 为核函数。注意，“核”一词有多种含义；我们将在第 14.7.1 节 TODO 中讨论另一种解释。在本章中，我们将研究几种核函数。然后我们描述一些可以纯粹用核函数计算来编写的算法。当我们无法访问（或选择不查看）正在处理的对象 `x` 的内部结构时，可以使用此类策略。

### 14.2 核函数

**定义 14.1。** 核函数是一个两个参数的实值函数，`κ(x,x′) ∈ R`。通常该函数是对称的（即 `κ(x,x′) = κ(x′,x)`）且非负的（即 `κ(x,x′) ≥ 0`）。

#### 14.2.1 RBF 核

高斯核或平方指数核 (SE 核) 定义为

```
κ(x,x′) = exp(−1/2 (x−x′)T Σ−1 (x−x′)) (14.1)
```

如果 `Σ` 是对角的，这可以写为

```
κ(x,x′) = exp(−1/2 ∑ (xj−x′j)2 / σj2) (14.2)
```

我们可以将 `σ` 解释为定义维度 `j` 的特征长度尺度。如果 `σ = ∞`，则忽略相应的维度；因此这被称为 ARD 核。如果 `Σ` 是球形的，我们得到各向同性核

```
κ(x,x′) = exp(− ||x−x′||2 / 2σ2) (14.3)
```

这里 `σ2` 称为带宽。公式 14.4 是径向基函数或 RBF 核的一个例子，因为它只是 `||x−x′||2` 的函数。

#### 14.2.2 TF-IDF 核

```
κ(x,x′) = ϕ(x)T ϕ(x′) / (||ϕ(vecx)||2 ||ϕ(x′)||2) (14.4)
```

其中 `ϕ(x) = tf-idf(x)`。

#### 14.2.3 Mercer（正定）核

如果核函数满足要求，即对于任意输入集合 `{xi}i=1N`，由下式定义的 Gram 矩阵

```
K = [κ(x1,x1) ... κ(x1,xN); ... ; κ(xN,x1) ... κ(xN,xN)] (14.5)
```

为正定。我们称这样的核为 Mercer 核，或正定核。如果 Gram 矩阵是正定的，我们可以按如下方式计算其特征向量分解：

```
K = UT Λ U (14.6)
```

其中 `Λ` 是特征值 `λi > 0` 的对角矩阵。现在考虑 `K` 的一个元素：

```
Kij = (Λ1/2 U:,i)T (Λ1/2 U:,j) (14.7)
```

令我们定义 `ϕ(xi) = Λ1/2 U:,i`，那么我们可以写成 `Kij = ϕ(xi)T ϕ(xj)` (14.8)。

#### 14.2.4 线性核

```
κ(x,x′) = xT x′ (14.10)
```

#### 14.2.5 Matern 核

Matern 核常用于高斯过程回归（见第 15.2 节），具有以下形式：

```
κ(r) = 21−ν / Γ(ν) (√2ν r / ℓ)ν Kν(√2ν r / ℓ) (14.11)
```

其中 `r = ||x−x′||`，`ν > 0`，`ℓ > 0`，且 `Kν` 是修正贝塞尔函数。当 `ν → ∞` 时，这趋近于 SE 核。如果 `ν = 1`，核简化为

```
κ(r) = exp(−r/ℓ) (14.12)
```

## 核函数与特征映射

一般来说，如果核是 Mercer 核，则存在一个将 $x \in \mathcal{X}$ 映射到 $\mathbb{R}^D$ 的函数 $\phi$，使得

$$

\kappa(x, x') = \phi(x)^T \phi(x') \tag{14.9}

$$

其中 $\phi$ 依赖于 $\kappa$ 的特征元素（因此 $D$ 是一个潜在的无限维空间）。

### 字符串核

令 $\phi_s(x)$ 表示子串 $s$ 在字符串 $x$ 中出现的次数。

我们将两个字符串 $x$ 和 $x'$ 之间的核定义为

$$

\kappa(x, x') = \sum_{s \in A^*} w_s \phi_s(x) \phi_s(x') \tag{14.13}

$$

其中 $w_s \ge 0$，且 $A^*$ 是字母表 $A$ 上所有可能字符串（任意长度）的集合（这被称为 Kleene 星算子）。这是一个 Mercer 核，并且可以在 $O(|x| + |x'|)$ 时间内计算（对于特定的权重 $\{w_s\}$ 设置），利用后缀树（Leslie et al. 2003; Vishwanathan and Smola 2003; Shawe-Taylor and Cristianini 2004）。

对于多项式核 $\kappa(x, x') = (\gamma x^T x' + r)^M$（其中 $r > 0$），可以证明相应的特征向量 $\phi(x)$ 将包含所有最高 $M$ 次的项。例如，如果 $M = 2, \gamma = r = 1$ 且 $x, x' \in \mathbb{R}²$，我们有

$$

(x^T x' + 1)² = (1 + x_1 x'_1 + x_2 x'_2)²

$$

$$

\begin{aligned}

\phi(x) &= (1, \sqrt{2}x_1, \sqrt{2}x_2, x_1², x_2², \sqrt{2}x_1 x_2) \\

\kappa(x, x') &= \phi(x)^T \phi(x')

\end{aligned}

$$

在高斯核的情况下，特征映射存在于无限维空间中。在这种情况下，显式表示特征向量显然是不可行的。

通常，证明一个核是 Mercer 核是困难的，需要泛函分析的方法。然而，可以证明可以通过一组标准规则从更简单的核构建新的 Mercer 核。例如，如果 $\kappa_1$ 和 $\kappa_2$ 都是 Mercer 核，那么 $\kappa(x, x') = \kappa_1(x, x') + \kappa_2(x, x')$ 也是 Mercer 核（详见 Schoelkopf and Smola 2002）。

如果我们只考虑固定长度 $k$ 的字符串，我们得到 $k$ 谱核。这已被用于将蛋白质分类到 SCOP 超家族中（Leslie et al. 2003）。

### 从概率生成模型导出的核

假设我们有一个特征向量的概率生成模型 $p(x|\theta)$。然后有几种方法可以利用该模型定义核函数，从而使模型适合判别任务。我们在下面简述两种方法。

#### 概率乘积核

$$

\kappa(x_i, x_j) = \int p(x|x_i)^\rho p(x|x_j)^\rho dx \tag{14.14}

$$

其中 $\rho > 0$，且 $p(x|x_i)$ 通常由 $p(x|\hat{\theta}(x_i))$ 近似，其中 $\hat{\theta}(x_i)$ 是利用单个数据向量计算的参数估计。这被称为概率乘积核。虽然拟合单个数据点的模型似乎很奇怪，但请记住，拟合的模型仅用于衡量两个对象的相似性。具体来说，如果我们将模型拟合到 $x_i$，然后模型认为 $x_j$ 很可能，这意味着 $x_i$ 和 $x_j$ 是相似的。

例如，假设 $p(x|\theta) \sim \mathcal{N}(\mu, \sigma² I)$，其中 $\sigma²$ 是固定的。如果 $\rho = 1$，且我们使用 $\hat{\mu}(x_i) = x_i$ 和 $\hat{\mu}(x_j) = x_j$，我们发现（Jebara et al. 2004, p825）

$$

\kappa(x_i, x_j) = \frac{1}{(4\pi\sigma²)^{D/2}} \exp\left(-\frac{\|x_i - x_j\|²}{4\sigma²}\right) \tag{14.15}

$$

这（在常数因子下）是 RBF 核。似乎可以为各种生成模型计算公式 14.14，包括带有潜在变量的模型，如 HMM。这提供了一种在变长序列上定义核的方法。此外，该方法即使序列是实值向量也适用，这与第 14.2.6 节的字符串核不同。详见 (Jebara et al. 2004)。

#### Fisher 核

利用生成模型定义核的一种更有效方法是使用 Fisher 核，其定义如下：

$$

\kappa(x_i, x_j) = g(x_i)^T F^{-1} g(x_j) \tag{14.16}

$$

其中 $g$ 是对数似然的梯度（或得分向量），在 MLE $\hat{\theta}$ 处评估：

$$

g(x) \triangleq \frac{d \log p(x|\theta)}{d\theta} \Big|_{\hat{\theta}} \tag{14.17}

$$

而 $F$ 是 Fisher 信息矩阵，本质上是 Hessian 矩阵：

$$

F \triangleq \frac{\partial²}{\partial\theta\partial\theta^T} \log p(x|\theta) \Big|_{\hat{\theta}} \tag{14.18}

$$

注意 $\hat{\theta}$ 是所有数据的函数，因此 $x_i$ 和 $x_j$ 的相似性是相对于所有数据计算的。同样，注意我们只需要拟合一个模型。

## 在 GLM 中使用核

### 核机器

我们将核机器定义为输入特征向量具有以下形式的 GLM：

$$

\phi(x) = (\kappa(x, \mu_1), \dots, \kappa(x, \mu_K)) \tag{14.19}

$$

其中 $\mu_k \in \mathcal{X}$ 是一组 $K$ 个中心点。如果 $\kappa$ 是 RBF 核，这被称为 RBF 网络。我们将在下文讨论选择 $\mu_k$ 参数的方法。

我们将公式 14.19 称为核化特征向量。注意在这种方法中，核不必是 Mercer 核。我们可以通过定义 $p(y|x,\theta) = \text{Ber}(y|w^T \phi(x))$ 将核化特征向量用于逻辑回归。这提供了一种定义非线性决策边界的简单方法。例如，见图 14.1。我们也可以通过定义 $p(y|x,\theta) = \mathcal{N}(y|w^T \phi(x), \sigma²)$ 在线性回归模型中使用核化特征向量。

## 核技巧

与其将特征向量显式表示为核函数的形式 $\phi(x) = (\kappa(x, x_1), \dots, \kappa(x, x_N))$，我们可以保留原始特征向量 $x$，但修改算法，使其将所有形式为 $\langle x_i, x_j \rangle$ 的内积替换为对核函数 $\kappa(x_i, x_j)$ 的调用。这被称为核技巧。事实证明，许多算法都可以通过这种方式核化。我们在下面给出几个例子。注意，为了使该技巧生效，我们要求核必须是 Mercer 核。

### 核化 KNN

欧几里得距离可以展开为

$$

\|x_i - x_j\|² = \langle x_i, x_i \rangle + \langle x_j, x_j \rangle - 2 \langle x_i, x_j \rangle \tag{14.20}

$$

然后，通过将所有 $\langle x_i, x_j \rangle$ 替换为 $\kappa(x_i, x_j)$，我们得到核化 KNN。

### 核化 K-medoids 聚类

K-medoids 算法类似于 K-means（见第 11.4.4 节），但不是用分配给该簇的所有数据向量的均值来表示每个簇的中心，而是使每个中心成为数据向量本身之一。因此我们始终处理整数索引，而不是数据对象。

该算法可以通过使用公式 14.20 替换距离计算来核化。

### 核化岭回归

将核技巧应用于基于距离的方法是直接的。将其应用于参数模型（如岭回归）则不那么明显。尽管如此，这是可以做到的，我们现在将解释。这将作为研究 SVM 的良好准备。
