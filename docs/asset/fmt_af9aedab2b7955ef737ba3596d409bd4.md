
基于这一原理，已提出了多种基本坐标下降法的变体。*循环坐标下降法*（CCD）最简单的形式是指每个迭代周期对一个坐标进行*循环*更新；即在第 *i* 次迭代中求解以下最小化问题：

```
θ_k^(i) := arg min_θ J(θ_1^(i), ..., θ_{k-1}^(i), θ, θ_{k+1}^(i-1), ..., θ_l^(i-1)).
```

换言之，除 `θ[k]` 外的所有分量均视为常数；那些分量 `θ[j], j < k` 固定为其更新值 `θ[j]^(i), j = 1, 2, …, k−1`，其余分量 `θ[j], j = k+1, …, l` 固定为上一轮迭代的可用估计值 `θ[j]^(i−1)`。此技术的优点在于可获得极小值点的简单闭式解。此类技术在稀疏学习模型（第 10 章）的背景下重焕生机 [18,67]。CCD 的收敛性问题已在 [36,62] 中探讨。针对最小二乘（LS）任务的 CCD 算法也已在 [66] 及其参考文献中研究。除了基本的 CCD 方案外，还有其他变体可用，它们采用不同的策略来选择每次更新的方向，以改善收敛性，范围从随机选择到坐标系变换，后者称为*自适应坐标下降*方案 [35]。

## 6.13 全最小二乘法

在本节中，LS 任务将从另一个角度进行表述。假设数据为零均值（中心化），并采用我们熟悉的线性回归模型，利用观测样本，

**y** = *X***θ** + **η**，

正如第 6.2 节所述。我们已经看到，LS 任务等价于将 `y` 正交投影到 `X` 的列向量张成的空间 `span{x₁ᶜ, …, xₗᶜ}` 上，从而使误差

```
e = y - ŷ
```

正交于 `X` 的列空间。等价地，这可以写为：

```
minimize ‖e‖², s.t. y - e ∈ ℛ(X)
```

其中 `ℛ(X)` 是 `X` 的值域空间（有关定义请参见备注 6.1）。此外，一旦获得了 `θ̂_LS`，我们可以写成

```
ŷ = X θ̂_LS = y - e,
```

或者

```
[X ⋮ y - e] [θ̂_LS; -1] = 0,
```

(6.66)

其中 `[X ⋮ y - e]` 是通过向 `X` 增加一列 `y - e` 而得到的矩阵。因此，所有点 `(yₙ - eₙ, xₙ) ∈ ℝ^(l+1)`，`n = 1, 2, …, N`，都位于同一超平面上，且该超平面穿过原点，如图 6.11 所示。换句话说，为了将超平面拟合到数据，LS 方法对输出样本施加了一个修正 `eₙ`，`n = 1, 2, …, N`。因此，我们隐含地假设回归变量是通过精确测量获得的，并且噪声仅影响输出观测值。

在本节中，将考虑更一般的情况，即允许输入（回归变量）和输出变量均受到（未观测到的）噪声样本的扰动。这种处理方法由来已久，可追溯至 19 世纪 [1]。该方法长期默默无闻，直到 50 年后被 Deming [13] 复兴并用于二维模型；有时称为 *Deming 回归*（历史综述见例如 [19]）。此类模型也称为 *误差变量* 回归模型。

我们的出发点是式 (6.65) 中的表述。令 `**e**` 为施加于 `**y**` 的修正向量，`E` 为施加于 `X` 的修正矩阵。*全最小二乘法* (TLS) 通过求解以下优化任务来计算未知参数向量：

```

```

```
(X − E)**θ** = **y** − **e**.
```

将从式 (6.69) 得到的解代入式 (6.68)，后者可重写为，

### 示例 6.3

为了演示 TLS 相对于 LS 估计器改进性能的潜力，在本示例中，我们同时在输出和输入样本中使用噪声。为此，我们随机生成一个输入矩阵 `X ∈ ℝ^(150×90)`，并根据标准化高斯分布 `𝒩(0, 1)` 填充元素。随后，我们通过从标准化高斯分布中随机抽取样本生成向量 `θ[o] ∈ ℝ⁹⁰`。输出向量形成如下：

```
y = X θ[o].
```

然后我们生成一个噪声向量 `η ∈ ℝ¹⁵⁰`，用从 `𝒩(0, 0.01)` 随机抽取的元素填充它，并形成

```
ỹ = y + η.
```

输入矩阵的噪声版本通过以下方式获得：

```
X̃ = X + E,
```

其中 `E` 通过从 `𝒩(0, 0.2)` 抽取样本随机填充元素。

使用生成的 `ỹ, X, X̃` 并假装我们不知道 `θ[o]`，获得了其值的以下三个估计。

*   结合 `X` 和 `ỹ` 使用最小二乘（LS）估计器公式 (6.5)，所得估计值 `θ̂` 与真实值之间的平均（10 次不同实现的平均）欧几里得距离等于 `‖θ̂ − θ_o‖ = 0.0125`。

*   结合 `X̃` 和 `ỹ` 使用最小二乘（LS）估计器公式 (6.5)，所得估计值 `θ̂` 与真实值之间的平均（10 次不同实现的平均）欧几里得距离等于 `‖θ̂ − θ_o‖ = 0.4272`。

*   结合 `X̃` 和 `ỹ` 使用全最小二乘（TLS）估计器公式 (6.69)，所得估计值 `θ̂` 与真实值之间的平均（10 次不同实现的平均）欧几里得距离等于 `‖θ̂ − θ_o‖ = 0.2652`。

观察可知，使用带噪输入数据时，LS 估计器导致的误差比 TLS 估计器大。然而请注意，TLS 的成功应用预设了导出 TLS 估计器的假设是有效的。
