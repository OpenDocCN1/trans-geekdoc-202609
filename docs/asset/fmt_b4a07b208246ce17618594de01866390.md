
因此，避免重采样可能是有益的。在实践中，仅当权重方差的相关度量低于某个阈值时才执行重采样。在文献 [30,31] 中，*有效样本数* 近似计算为

```
N_eff ≈ 1 / Σ_{i=1}^N (W_n^(i))²
```

(17.40)

该指标的取值范围为 1 到 `N`。如果 `N_eff ≤ N_T` 则执行重采样，通常取 `N_T = N/2`。

#### 算法 17.5：通用粒子滤波

*   选择先验分布 `p`，以生成初始状态 `x[0]` 的粒子。
*   选择建议分布 `q`。
*   选择粒子流的数量 `N`。
*   **对于** `i = 1, 2, …, N`，**执行**
    1.  采样 `x[0]^(i) ~ p(x)`；初始化 `N` 条流。
    2.  设置 `W_0^(i) = 1/N`；所有初始归一化权重相等。
*   **结束循环**

##### 算法流程

**For** `n = 1, 2, 3, …` **Do**

1. **For** `i = 1, 2, …, N` **Do**
    1. 从 `q(x | x_{n-1}^(i), y_n)` 中抽取 `x_n^(i)`
    2. 
    ```
    w_n^(i) = w_{n-1}^(i) * p(x_n^(i) | x_{n-1}^(i)) * p(y_n | x_n^(i)) / q(x_n^(i) | x_{n-1}^(i), y_n)
    ```
2. **End For**
3. **For** `i = 1, 2, …, N` **Do**
    1. 计算归一化权重 `W_n^(i)`。
4. **End For**
5. 计算 `N_eff`；公式 (17.40)。
6. **If** `N_eff ≤ N_T`；预选值 `N_T`。
    1.  ⁎ 重采样 `{x[n]^(i), W[n]^(i)}[i=1]^N` 以获得 `{\\overline{x}[n]^(i), 1/N}[i=1]^N`
    2.  ⁎ `x[n]^(i) = \\overline{x}[n]^(i)`, `w[n]^(i) = 1/N`
7.  – **结束 If**
*   • **结束 For**

*   • 建议分布的一个常用选择是先验分布

*   这产生了以下权重更新递推公式，

### 17.4.3 辅助粒子滤波

*辅助粒子滤波器*在文献 [36] 中被引入，旨在提高处理重尾分布时的性能。该方法引入了一个辅助变量；即前一时间瞬间粒子的索引。我们允许在时间 `n` 第 `i` 条流中的粒子，使用时间 `n − 1` 不同流中的粒子来抽取。设时间 `n` 的第 `i` 个粒子为 `x_n^(i)`，其在时间 `n − 1` 的“父”粒子索引为 `i_{n−1}`。核心思想是对配对 `(x_n^(i), i_{n−1})` 进行采样，`i = 1, 2, …, N`。利用贝叶斯法则，可得

```
p(x_n, i|y_{1:n}) ∝ p(y_n|x_n)p(x_n, i|y_{1:n−1}) = p(y_n|x_n)p(x_n|i, y_{1:n−1})P(i|y_{1:n−1})
``` (17.41)

其中利用了状态空间模型所基于的条件独立性。为了使符号表示更加简洁，我们用 `x[n]` 代替 `x[n]^(i)`，并省略了 `i[n - 1]` 中的下标 `n - 1`，直接用 `i` 表示。注意根据索引 `i[n - 1]` 的定义，我们有

```
p(x[n]|i, y[1:n-1]) = p(x[n]|x[n-1]^(i), y[1:n-1]) = p(x[n]|x[n-1]^(i))
```

(17.42)

并且

```
P(i|y[1:n-1]) = W[n-1]^(i).
```

(17.43)

因此，我们可以写成

```
p(x[n], i|y[1:n]) ∝ p(y[n]|x[n]) p(x[n]|x[n-1]^(i)) W[n-1]^(i).
```

(17.44)

建议分布选取为

*q*(**x**[*n*], *i*|**y**[1 : *n*]) ∝ *p*(**y**[*n*]|**μ**[*n*]^((*i*)))*p*(**x**[*n*]|**x**[*n* − 1]^((*i*)))*W*[*n* − 1]^((*i*)).

![Equation](img/si212.png)(17.45)

请注意，我们在 *p*(**y**[*n*]|**x**[*n*]) 中用 **μ**[*n*]^((*i*)) 代替了 **x**[*n*]，因为 **x**[*n*] 仍有待抽取。估计值 **μ**[*n*]^((*i*)) 的选择旨在易于计算，同时能很好地代表 **x**[*n*]。通常，**μ**[*n*]^((*i*)) 可以是均值、众数、一次抽样，或与分布 *p*(**x**[*n*]|**x**[*n* − 1]^((*i*))) 相关的另一个值；例如，**μ**[*n*]^((*i*)) ∼ *p*(**x**[*n*]|**x**[*n* − 1]^((*i*)))。此外，如果状态方程为 **x**[*n*] = **f**(**x**[*n* − 1]) + **η**[*n*]，一个好的选择将是 **μ**[*n*]^((*i*)) = **f**(**x**[*n* − 1]^((*i*)))。

应用公式 (17.45) 中的贝叶斯法则并采用

我们得到

$$q(i|\mathbf{y}_{1:n}) \propto p(\mathbf{y}_n|\boldsymbol{\mu}_n^{(i)})W_{n-1}^{(i)}. \tag{17.46}$$

因此，我们从多项式分布中抽取索引 $i_{n-1}$ 的值，即

$$i_{n-1} \sim q(i|\mathbf{y}_{1:n}) \propto p(\mathbf{y}_n|\boldsymbol{\mu}_n^{(i)})W_{n-1}^{(i)}, \quad i = 1, 2, \dots, N. \tag{17.47}$$

索引 $i_{n-1}$ 标识了将从中抽取 $\mathbf{x}_n^{(i)}$ 的分布，即

$$\mathbf{x}_n^{(i)} \sim p(\mathbf{x}_n|\mathbf{x}_{n-1}^{(i_{n-1})}), \quad i = 1, 2, \dots, N. \tag{17.48}$$

请注意，公式 (17.47) 实际上执行的是重采样。然而，现在在时刻 `n - 1` 的重采样会考虑到在时刻 `n` 变得可用的信息，即通过观测值 `y[n]`。利用这些信息是为了确定在给定时刻重采样后哪些粒子得以存活，以使其“后代”有可能落在高概率质量区域。一旦抽取了样本 `x[n]^(i)`，索引 `i[n - 1]` 即被丢弃，这等价于将 `p(x[n], i | y[1:n])` 边缘化以获得 `p(x[n] | y[1:n])`。每个样本 `x[n]^(i)` 最终根据以下公式被赋予一个权重：

```
w_n^(i) ∝ p(x_n^(i), i_{n - 1} | y_{1:n}) / q(x_n^(i), i_{n - 1} | y_{1:n}) = p(y_n | x_n^(i)) / p(y_n | μ_n^(i)),
```

这通过将公式 (17.44) 和 (17.45) 的右边相除得到。请注意，该权重反映了实际样本处的似然 `p(y[n] | ·)` 与预测点 `μ[n]^(i)` 处的似然之间的不匹配。由此产生的算法总结如下。

* 除前述算法外，多年来还提出了许多变体，旨在克服粒子滤波器的主要局限性——方差增加与样本贫化问题。在*重采样-移动* [18] 和*分块采样* [15] 中，不仅在时刻 $n$ 对 $\mathbf{x}_n^{(i)}$ 进行采样，还试图结合新到达的观测 $\mathbf{y}_n$，修改固定窗口大小 $L$ 内（即 $[n-1, n-L+1]$）的历史值。在*正则化粒子滤波器* [34] 中，在 算法 17.5 的重采样阶段，不再从离散分布采样，而是从平滑近似中抽取样本：

```
p(\mathbf{x}_n|\mathbf{y}_{1:n}) \approx \sum_{i=1}^{N} W_n^{(i)} K(\mathbf{x}_n - \mathbf{x}_n^{(i)}),
```

其中 $K$ 为平滑核密度函数。文献 [28, 29] 利用高斯分布近似后验；与传统扩展卡尔曼滤波器不同，其更新与滤波通过粒子传播实现。更多粒子滤波相关信息，可参考教程类文献 [1, 10, 16]。

* *Rao-Blackwell 化* 是一种降低蒙特卡洛采样法估计方差的技术（如文献 [4]）。该技术也被应用于动态系统的粒子滤波中。实践中常见部分状态在给定非线性状态下呈条件线性。核心思想是将这些线性状态视为干扰参数，并将其从估计过程中*边缘化*掉。非线性状态的粒子随机传播，随后利用卡尔曼滤波器对线性部分进行处理（参见文献 [11, 13, 26]）。

###### 平滑与滤波

*平滑*与滤波处理密切相关。在滤波中，目标在于基于索引集合{1, 2, …, *n*}内的观测值，即**y**[1 : *n*]，获得**x**1 : *n*的估计。在平滑中，则基于观测集合**y**[1 : *n* + *k*]（*k* > 0）获得**x**[*n*]的估计。平滑有两种途径。一种称为*固定滞后*平滑，其中*k*为固定滞后。另一种称为*固定区间*平滑，旨在基于时间索引集合{1, 2, …, *T*}内的观测值，即基于固定观测集合**y**[1 : *T*]获得估计。

####### 平滑的算法途径

平滑存在不同的算法途径。最朴素的方法是将粒子滤波运行至时刻*n* + *k*或*T*，并利用获得的权重对时刻*n*的粒子进行加权，以构建随机测度，即：

```
p(\mathbf{x}_{n}|\mathbf{y}_{1:n + k}) \approx \sum\limits_{i = 1}^{N}W_{n + k}^{(i)}\delta\left( \mathbf{x}_{n} - \mathbf{x}_{n}^{(i)} \right).
```

对于较小的*k*值（或*T* − *n*），这可以是一个合理的近似。其他更精细的技术采用双遍历原理。首先运行粒子滤波，然后利用一组反向递归来修正权重（参见文献\[11\]）。

####### 高维挑战

粒子滤波方法的主要困难之一在于，近似底层分布所需的粒子数量随状态维度呈指数级增长。为克服此问题，已提出若干方法：

*   文献\[32\]中，作者提出对状态进行划分并独立估计每个分区。
*   文献\[17\]提出了退火粒子滤波，该方法通过使用一系列平滑加权函数实施粗到精策略。
*   无迹粒子滤波\[39\]提出对每个粒子使用无迹变换，以避免在低似然区域浪费资源。
*   文献\[33\]提出了一种分层搜索策略，利用辅助低维模型引导高维空间中的搜索。

####### 可微粒子滤波

*可微粒子滤波*：这是一个新兴领域，它融合了经典粒子滤波思想（如前所述）与源自神经网络领域的学习策略。核心思想在于*构建*并*学习*相关模型，即动态状态模型、观测模型、建议分布模型，以及最近的重采样策略。这些技术似乎能提供复杂高维应用所需的模型表达能力。“可微”这一术语源于利用梯度技术来学习所采用的模型，相关综述参见文献\[5,25\]。
