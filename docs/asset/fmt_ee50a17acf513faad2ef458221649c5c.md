
```
P.pos thick/ = (P.thickjpos/ · P.pos/) / P.thick/
```

(2.3)

### m 估计的本质

让我们通过一个某面出现更频繁的不均匀硬币来解释这一原理。在没有更好引导的情况下，正面的先验期望为`nheads = 0.5`。辅助参数`m`帮助工程师告诉分类程序他对该值（先验期望）有多大的信心（`m`信心越高）。让我们用`Nall`表示硬币投掷的次数，用`Nheads`表示正面的次数。将这些值与先验期望和信心结合的方法由公式总结：

```
Pheads = (Nheads + m*nheads) / (Nall + m)
```

![image](img/image112.png) 

––––––––

![image](img/scene_break.png) 

(2.7)

![image](img/image112.png)![image](img/image112.png) 注意，如果`Nall = 0`，公式将退化为先验期望`nheads`。相反，如果`Nall`和`Nheads`足够大使得`m*nheads`和`m`可以忽略，它将收敛于相对频率。使用值`nheads = 0.5`和`m = 2`，我们得到：

```
P = (Nheads + 2*0.5) / (Nall + 2) = (Nheads + 1) / (Nall + 2)
```
