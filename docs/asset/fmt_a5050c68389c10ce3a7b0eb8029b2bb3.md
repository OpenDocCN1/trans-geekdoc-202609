
# NIST 特别出版物

**`800-61-r2`，“计算机安全事件处理指南”**
：一份 NIST 特别出版物，旨在指导组织使用四阶段生命周期方法进行事件响应流程。

**`800-115`，“信息安全测试和评估技术指南”**
：一份 NIST 特别出版物，旨在协助组织规划和实施渗透测试、分析发现并制定缓解策略。

**`800-137`，“联邦信息系统和组织的信息安全持续监控 (ISCM)”**
：一份 NIST 特别出版物，旨在指导组织开展持续安全监控操作。

**`800-161`，“联邦信息系统和组织的供应链风险管理实践”**
：一份 NIST 特别出版物，旨在指导组织识别、评估和缓解其 IT/OT 供应链风险。

# A

**`AAA protocol`**
：认证、授权和计费，使用不同的链路层协议（如 `PPP`），并使用 `PAP` 或 `CHAP` 进行认证。

**`acceptable use policy (AUP)`**
：一份书面策略，定义员工在使用其组织的计算机和网络设备时的角色和限制。

**`access control`**
：确保资源仅授予有权访问的用户的安全预防措施。

**`access control list`**
：通过白名单或黑名单控制对网络段访问的列表。

**`Active Directory`**
：微软提供的一种目录服务，负责处理域管理，包括认证、授权、证书管理等。

**`active RFID tags`**
：自供电标签，提供更长的范围，但成本高得多。有源射频识别标签通过电磁场传输识别信息。

**`actuator`**
：负责控制机械系统的设备，如电动机启动器或气动/电磁阀。

**`Adaptive Frequency Hopping Spread Spectrum (AFHSS)`**
：一种安全的射频传输方法，根据仅发射端和接收端已知的模式，在大带宽上快速改变其载波频率。蓝牙规范在免许可的 2.4GHz 频段实现此传输方法，通过在预先划分的子频率间跳频，以提供安全性并避开拥挤的频率范围。

**`Address Resolution Protocol (ARP) spoofing attack`**
：一种攻击，攻击者发送伪造的 ARP 消息，将其 MAC 地址与另一用户的 IP 地址关联。一旦建立关联，发往该地址的消息将被转移至攻击者。攻击者随后可利用从拦截消息中获得的信息发起其他类型的攻击，如 `DoS` 或中间人攻击。

**`Advanced Encryption Standard (AES)`**
：一种使用对称密钥的分组加密算法。由 NIST 于 2001 年发布，已被美国政府采用并取代 `DES`。

**`Advanced Metering Infrastructure (AMI)`**
：新型数字电力监测仪表的配套基础设施，在公用事业中心办公室与客户端智能能源设备的 `HAN` 之间提供通信路径。

**`advanced persistent threats`**
：在持续一段时间内针对非常特定且非常安全的系统的威胁。

**`adware`**
：不需要的、未经请求的广告，通常显示在 Web 浏览器中。

**`algorithm`**
：就计算机安全而言，算法是应用于数据以改变其内容（加密算法）的算术代码，称为 `cipher`，使未经授权的人员无法读取。数字处理中常用的加密算法包括 `Triple DES`、`AES`、`RSA`、`Blowfish` 和 `Twofish`。

**`annunciator`**
：一种报警系统设备，通过声音、灯光或其他指示来指示系统的运行状态。

**`anomaly analysis`**
：一种分析系统，将统计分析技术应用于数据流，以确定其在任何给定时间是“正常”还是“异常”。

**`anonymous proxy`**
：一种代理服务器，通过隐藏客户端的原始 IP 地址来提供客户端匿名性。

**`antispyware`**
：通过检测并移除间谍软件和/或首先阻止它们来防御间谍软件的程序。

**`antivirus`**
：通过检测并移除计算机病毒和/或首先阻止它们来防御计算机病毒的程序。

**`application-level encryption`**
：在应用程序内应用加密以保护数据（静态、传输中、使用中）的方法。通常应用加密的其他级别包括文件夹、文件和磁盘级别。

**`application service provider (ASP)`**
：现代云计算的鼻祖。一种通过网络向付费客户提供基于应用程序服务的企业。

**`application servers`**
：配置为在组织业务活动中提供特定角色、供组织内部用户使用的服务器。

**`application zone`**
：由内联网环境中应用程序的使用定义的委派区域。该区域通过防火墙、路由器和交换机的使用来创建。

**`asymmetric keys`**
：加密算法中使用的双密钥系统，其中一个密钥用于加密，另一个密钥用于解密。这些密钥类型也称为公钥和私钥。

**`asymmetrical (out-of-band) virtualization`**
：虚拟化设备安装在网络与存储系统之间的实际数据路径之外。

**`attack surface`**
：受攻击的不同机会的总和。

**`attenuation`**
：信息跨越传输介质（如光纤电缆）移动时发生的信号损耗度量。

**`audit entries`**
：发生审核事件时添加到安全日志中的项目。

**`audit policy`**
：定义将被监控并添加到系统安全日志中的事件类型的策略。用于审查和治理组织的内部准则和标准。

**`audit trail`**
：用户计算机使用情况的记录。

**`auditing`**
：一种会计形式，是一种预先计划的监控方法，用于评估或确定特定领域内是否存在问题。

**`authentication`**
：确定某人是其所声称身份的过程。

**`authentication, authorization, and accounting (AAA)`**
：网络管理员用于保障信息安全的方法。

**`Authentication Header (AH)`**
：`IPSec` 用于防止传输中数据包被篡改的协议。这提供了完整性和认证。

**`authentication server (AS)`**
：其功能是为网络用户提供认证的服务器。

**`authentication system`**
：用于提供认证的网络系统。

## 术语表

# A

**`authoritative name server`**
：提供对 DNS 查询的权威回答，而非来自缓存或通过向另一台名称服务器请求该信息的服务器。

**`authorization`**
：用户有权访问的资源以及他们可以执行的操作。

**`automated access control`**
：一种设计特性，要求对试图从远程位置访问安全区域或计算机系统的用户身份进行认证。

**`automated provisioning`**
：一种类似于基于规则的访问控制的方法，其中规则是基本元素。规则定义了可以执行的操作。

# B

**`backup media`**
：存储数据备份的介质，例如磁带或 DVD-R。

**`backup policy`**
：定义备份什么、何时备份以及将备份存储在何处的策略。还包括谁拥有备份的授权以及如何制作备份。

**`barriers`**
：阻碍入侵者从外围推进到内部区域的障碍物。也称为防撞柱。

**`bastion host`**
：设计用于位于 DMZ 中的特定计算机，可以是防火墙、路由器、服务器或一组不受另一防火墙保护但可直接访问互联网的计算机。

**`beacon frames`**
：`802.11` 无线局域网中的管理帧，让附近的客户端知道它们正在广播什么网络。

**`beacon interval`**
：广播信标帧之间指定的时间间隔。

**`biometrics`**
：使用人体物理特征来验证个人身份的访问控制机制。利用一个人的独特身体特征（指纹、声纹和/或视网膜扫描）来提供身份识别和认证。

**`BitLocker`**
：某些 Windows 操作系统上的原生实用程序，提供全磁盘级加密。

**`black-hat hacker`**
：拥有广泛网络安全技能并将其用于绕过或突破网络安全结构以达到恶意或犯罪目的的个人。

**`blacklisting`**
：一种仅拒绝符合给定标准（基于用户、软件、系统）的用户访问的方法。

**`block cipher`**
：一种将算法应用于数据块而非单个比特的密码。

**`Blowfish`**
：一种使用对称密钥加密的分组加密算法。

**`blue team`**
：渗透测试中通常作为目标的团队。

**`Bluetooth`**
：用于个人区域网络（PAN）的无线网络规范，将包括手机、数码相机、PC、笔记本电脑和打印机在内的个人设备组网在一起。

**`bot herder`**
：控制僵尸网络的未授权人员。

**`botnet`**
：由僵尸网络控制者控制的大量僵尸或机器人的集合。

**`bots (zombie computers)`**
：由未授权人员控制的 PC、IoT 设备或其他智能可编程设备。

**`bring-your-own-device (BYOD)`**
：授权员工使用自己的设备而非公司提供的设备进行业务相关活动。

**`broadcast storm`**
：每个网络设备重新广播广播流量，最终导致流量传递失败。这会迅速使交换机和路由器过载并压垮网络。

**`broadcast traffic`**
：向网络上所有可能的目标发送消息。

**`Browser Exploitation Framework (BeEF)`**
：一个著名的开源渗透测试工具，专注于通过 Web 浏览器进行的 Web 攻击。

**`brute-force attack`**
：攻击者使用应用程序基于已知列表或预测性数学方案系统地猜测密钥或密码。这可能涉及数百或数千次尝试。

**`buffer overflow`**
：程序越过缓冲区边界的异常，导致行为异常、内存访问错误和/或系统崩溃。系统实际上被禁用，用户无法使用。

**`buffer overflow attack`**
：旨在导致计算系统出现缓冲区溢出状况的攻击。

**`Building Automation and Control Network (BACnet)`**
：由美国采暖、制冷与空调工程师学会开发的协议，用于将楼宇自动化设备联网在一起。

**`business continuity plan`**
：描述组织在发生破坏性事件时的准备工作、增长计划和未来规划的文档。

**`business-to-business (B2B)`**
：组织用于与其他受信任组织进行安全交易的网络渠道。

**`bypass mode`**
：许多报警系统中可用的一种模式，旨在让人员通过报警区域而不触发报警。在不影响系统其余部分的情况下关闭或禁用传感器、设备或整个区域。

# C

**`C2 channel`**
：C2 通道（命令与控制）使攻击者能够直接与受损主机交互，这会使威胁变得非常危险，因为攻击者可以响应缓解威胁的尝试。

**`cache poisoning`**
：攻击者建立一个流氓 DNS 服务器，然后利用该服务器向主 DNS 服务器反馈虚假信息，从而污染主 DNS 服务器的缓存资源。

**`caching servers`**
：代理服务器使用缓存的网页，将已访问的网页从其缓存中提供给请求客户端，而无需访问互联网。

**`caching web proxies`**
：缓存（存储）Web 资源以便更快访问的本地服务器。

**`certificate chain`**
：证书列表，从根证书开始，随后是每个后续证书，其中一个证书的颁发者或签名者是下一个证书的主体。

**`Challenge-Handshake Authentication Protocol (CHAP)`**
：使用三次握手（SYN、SYN-ACK、ACK）识别远程客户端的认证方法。`CHAP` 用于认证用户或网络——挑战、响应、成功或失败——它可防止重放攻击。

**`chokepoints`**
：人员或其他交通必须通过的门户位置，例如大门、门口、走廊或通道/道路，可能导致单点故障。

**`chroot`**
：一种基于 Linux 的命令，用于调整当前正在运行的进程的根目录位置。也可用于创建和管理操作系统的多个虚拟化副本。

**`cipher`**
：在密码学中，密码是用于加密数据的算法。

**`cipher locks`**
：当用户在密码锁键盘上输入正确的编程代码时，通过解锁磁性门锁来操作的锁。

**`ciphertext`**
：经过加密密钥编码后的任何数据的文本。

**`Cisco Discovery Protocol (CDP)`**
：`CDP` 协议使思科设备能够与其他思科设备通信以交换信息。攻击者可以使用此协议收集网络上运行 `CDP` 的交换机和其他网络设备的信息。

**`cleartext`**
：未加密的存储或传输数据。

**`clickjacking attack`**
：采用欺骗性框架技术诱使用户点击其内容而非预期内容的攻击。

**`client-server model`**
：基于集中式、控制型服务器设备的网络模型，该设备为连接到网络的若干客户端设备提供服务。

**`cloud-based services`**
：具有特殊客户端应用程序软件的托管服务，可将用户的桌面或移动文件和数据存储扩展到互联网服务。

**`cloud computing`**

## C

**`云计算`**
：利用远程联网服务器获取资源。这些资源可能包括数据存储、数据处理等，从而减少了本地机器的硬件需求。

**`Common Platform Enumeration (CPE)`**
：一种在网络上描述和识别操作系统、硬件设备及应用程序类别的标准化方法。

**`Common Vulnerabilities and Exposures (CVE)`**
：一个用于引用公开已知漏洞的系统。由 MITRE Corporation 维护，并得到美国国土安全部的支持。

**`Common Vulnerability Scoring System (CVSS)`**
：一个对 CVE 漏洞进行评分的系统，使相关风险更易于理解。

**`Completely Automated Public Turing test to tell Computers and Humans Apart (CAPTCHA)`**
：一种表单输入请求，要求输入单词、短语、随机字符和数字组合，或执行一个无法轻易自动化的简单测试。

**`复杂度`**
：就密码而言，复杂度是输入长度、宽度和深度的组合。

**`机密性、完整性和可用性 (CIA)`**
：经典的信息安全模型。

**`连接设备`**
：用于创建网络连接的设备，包括集线器、交换机和路由器。

**`应急计划`**
：在灾难/紧急情况发生前进行的规划。

**`控制模式`**
：控制器用于校正测量值 PV 与指定设定点 SP 之间差值的技术。

**`控制器`**
：控制器是一种硬件设备或软件程序，负责接收输入信息，将该信息与预设条件或参考值进行比较，决定应采取的行动，最后向执行机构发送校正误差信号，以调节被操纵变量。

**`Cookie`**
：Web 服务器在其页面被访问时发送给 Web 浏览器的小文件。发送 Cookie 的目的是为了允许在 Web 页面或基于 Web 的应用程序的不同访问会话之间保留信息。

**`破解`**
：利用软件循环猜测密码，直到获得访问权限。

**`CRAM-MD5`**
：一种质询-响应认证机制，支持以哈希形式传输密码的电子邮件认证系统。

**`凭据收集`**
：收集用户认证信息的任何方法。

**`跨站脚本攻击 (XSS)`**
：一种允许将客户端脚本注入 Web 页面的攻击方法，该页面可能被其他毫无戒备的用户使用。

**`crypt`**
：早期 UNIX 版本附带的原始加密实用程序。

**`密码学`**
：用于将数据转换为秘密代码的程序、过程和技术。

**`CryptoLocker`**
：一种勒索软件木马。

**`密码术`**
：对密码学的研究。

**`电流环`**
：流经某区域两个连接点之间的电流大小。

**`Cyber Kill Chain®`**
：由洛克希德·马丁公司开发的一种流程，旨在通过一系列步骤追踪网络安全攻击的阶段，以应对威胁攻击：侦察、武器化、投递、利用、安装、命令与控制、目标行动。

**`网络战`**
：一种虚拟冲突，涉及出于政治动机对对手的 IT 或 ICS 网络发动攻击。

**`网络犯罪分子`**
：通常由贪婪驱动、寻求经济利益的个人。这类攻击者可能是最著名的黑客类型，因为他们往往引起最多的关注。

**`网络安全`**
：在保护对财产、系统和设备端口的物理访问的同时，保护包括电子、光学和信息访问在内的系统数据和控制等无形资产。

**`网络安全策略`**
：解释保护组织网络数据和计算机系统所需总体要求的公司策略。

**`网络恐怖分子`**
：通常不以金钱为动机，而是为了推进政治议程或意识形态。目标是给公众造成伤害和混乱。也称为黑客活动家。

# D

**`守护进程`**
：一个拥有执行程序（后台进程）权限的标准默认用户/组，这些程序无需用户指导即可运行。

**`数据汇聚器`**
：数据收集设备，用于将多个智能电表分组，并聚合其数据传输以传送给中央办公室的公用事业服务器。这些设备是 AMI 运营中数据和能源管理的核心。

**`数据二极管`**
：一种在具有不同安全级别分类的网络或网段之间创建单向连接的设备。

**`Data Encryption Standard (DES)`**
：一种用于数据加密的对称密钥算法。

**`Data Execution Prevention (DEP)`**
：一种沙箱机制，将给定程序隔离在特定内存区域，以保护系统其余部分免受潜在攻击。

**`数据历史服务器`**
：负责记录和检索从 PLC 获取的数据的软件组件。
