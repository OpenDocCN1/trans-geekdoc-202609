## 恶意软件的目的

`malware`术语指的是一组具有共同目标——入侵计算机并使其执行某些操作的不同类型的软件。它通常被称为恶意软件。在许多情况下，恶意软件会执行不受欢迎的操作并在未经所有者明确许可的情况下运行。然而，并非总是如此。某些类型的恶意软件是在所有者完全知情的情况下下载并安装的。

恶意软件最初被引入计算机和网络时是作为"无害"的实验或恶作剧。事实上，后来被称为恶意软件的早期程序示例实际上完全没有恶意。最早的恶意软件开发者大多感兴趣的是了解新颖的计算机程序能实现什么。今天，大多数恶意软件具有更不光鲜的目的。目前的恶意软件通常是为了实现以下一个或多个目的：

- **破坏计算机运行**——恶意软件程序可以破坏计算机运行其他程序或与其他计算机或设备通信的能力。它们还可能损坏甚至删除其他程序运行所需的关键操作系统组件。恶意软件还可以更改或删除程序运行所需的内存或磁盘内容。恶意软件为扰乱破坏计算机运行而采取的大多数操作都会导致程序无法处理的意外状况。结果就是程序出现意料之外的行为，甚至程序崩溃。

- **收集敏感信息**——许多类型的恶意软件程序在不通知的情况下运行。它们搜索敏感数据，例如财务数据和个人身份识别数据。它们存储找到的任何数据，或通过计算机的网络连接将其发送给恶意软件创建者。用户存储敏感信息的地方有很多，包括浏览器缓存、磁盘上的文件，甚至是内存。恶意软件程序知道去哪里寻找常见的敏感数据。

- **获取对受限计算机资源的未经授权访问**——恶意软件的第三主要目的是为攻击者提供访问计算机和其他网络资源的方法。为此目的编写的恶意软件利用漏洞进入受保护的网络。然后它会采取一些行动，为攻击者产生新的访问方法。实际上，这种类型的恶意软件为受限的计算机打开了一扇新门。

恶意软件的存在可能是为了执行特定的攻击，或仅作为更复杂攻击中的一步。例如，恶意软件通常可以帮助攻击者识别后续攻击的可能受害者。攻击者惯常使用许多类型的工具来实施攻击。恶意软件只是他们武器库中的工具之一。

## 恶意软件类型

攻击者可以选择不同类型的恶意软件来满足其攻击目标。任何情况下最好的恶意软件类型取决于攻击的类型。恶意软件可以大致分为两类：传播或感染的程序和隐藏的程序。

传播或感染的程序会积极尝试将自己复制到其他计算机。它们的主要目的是在新的目标上执行指令。这种类型的恶意软件包括：

- 病毒
- 蠕虫

其他恶意软件隐藏在计算机中执行其指令，同时避免检测。倾向于隐藏的恶意软件包括：

- 特洛伊马
- 根管理器（Rootkits）
- 间谍软件

了解这五种基本的恶意软件类型以及如何保护你的系统免受侵害是良好安全计划的重要组成部分。以下章节描述了每种恶意软件类型。

### 参考

贝尔实验室的开发者实际上在 1962 年就创建了一个名为`Darwin`的游戏，其中包含类似病毒的行为。该游戏允许"生物"生长、繁衍并相互超越。开发者之一的罗伯特·莫里斯老士（Robert Morris, Sr.）创造了一个使用类病毒策略感染游戏场区域的致命猛兽。它受限于单台计算机，但为未来的恶意软件铺了道路。

### 病毒

计算机`病毒`是一种附加到另一个程序或将其复制到另一个程序中的软件程序。它导致计算机遵循原始程序开发者无意设计的指令。病毒"感染"宿主程序并可能导致该宿主程序将自己复制到其他计算机。"病毒"一词用于描述作用方式与生物病毒类似的恶意软件。病毒离开宿主无法存在，类似于许多寄生虫。它可以以感染的方式从一个主机传播到另一个主机。

`Creeper`是记录的第一个跨计算机间病毒。它是鲍勃·托马斯（Bob Thomas）在 1971 年编写的。`Creeper`会将自己复制到其他网络计算机，并显示信息"我是 Creeper，有能就抓住我！"它被设计为一个实验性的自我复制程序，以观察此类程序如何影响网络上的计算机。在`Creeper`发布后不久，`Reaper`程序被释放以寻找并消灭`Creeper`。

今天，有数千种已知病毒感染所有类型的程序。病毒主要的担忧是它们通常附加到经常运行的程序上。当用户运行这些被感染的程序时，他们实际上是在使用自己的用户凭据和授权运行病毒代码。病毒不需要提升权限。运行感染程序的用户为病毒提供了经过验证的凭据和权限。

### 蠕虫

蠕虫是一种自包含的恶意软件。它是一种复制并将副本发送到其他计算机的程序，通常跨越网络。蠕虫可能会采取其他行动，或者它的目的可能只是通过占用网络带宽来降低可用性。病毒和蠕虫的主要区别是蠕虫不需要宿主程序即可感染；蠕虫是一个独立的程序。由于蠕虫不依赖宿主，它们通常可以传播得更快、更远。另一方面，蠕虫往往具有某些平台特性，因为它们是独立的程序。

第一个报告在"野外"传播的蠕虫是`Morris worm`（莫里斯蠕虫）。`Morris worm`由罗伯特·塔潘·莫里斯二世（Robert Tappan Morris, Jr.）于 1988 年编写。它被设计在整个互联网传播并感染运行`UNIX`操作系统版本的计算机。该蠕虫的原始意图是估计互联网的大小，但蠕虫传播得比作者预期的要快。该蠕虫最终多次感染计算机，并最终降低了每台被感染计算机的速度直到其无法使用。

莫里斯蠕虫利用了`buffer overflow`（缓冲区溢出）漏洞。缓冲区溢出是指运行程序将数据存储在分配的数据内存区域之外。通过存储比程序预期更多的数据，可以向程序中放入更改其运行时行为的指令。缓冲区溢出无处不在，并且总是由于程序员忽略验证输入数据而导致。

自莫里斯蠕虫以来，攻击者发布了许多其他著名的蠕虫，例如`Melissa`、`The Love Bug`（爱虫病毒）、`Code Red`（红色代码）、`Nimda`、`SQL Slammer`、`Sasser`和`Conficker`。蠕虫倾向于在用户不考虑潜在后果的情况下运行它们的环境中繁衍。在过去，许多蠕虫通过电子邮件信息传输。在不久的将来，预计将看到通过社交网络传播的蠕虫大幅增加。通过社交媒体机制进行快速通信为攻击者和安全管理员开启了新的机会。

### 特洛伊马

`Trojan horse`（也称为`Trojan`）是一种隐藏自己或伪装成有用或无害程序的恶意软件。这个名字源自《埃涅伊德记》中特洛伊马的故事。在故事中，希腊人建造了一个巨大的木马并将其作为礼物送给特洛伊。在与特洛伊战争十年后，希腊人留下了木马并离开。这个礼物被视为胜利祭品并带入城市。那天，躲在空心木马内的希腊士兵打开了城门，让在夜后返回的希腊军队进入城市。希腊人在那天晚上彻底击败了特洛伊。

特洛伊马程序利用其外表来欺骗用户运行它们。它们被伪装成执行有用任务的程序，但实际上隐藏了恶意代码。一旦程序运行，攻击指令就会以用户的权限和权威执行。从本质上说，特洛伊马开发者欺骗用户运行了攻击程序。

第一个已知的特洛伊马是`Animal`，发布于 1974 年。该程序被伪装成一个简单的测验游戏，用户想一个动物，程序会通过提问来尝试猜出该动物。除了提问之外，该程序实际上会将自己复制到用户具有写入权限的每个目录中。如今的特洛伊马功能远比保存自己的副本得多。特洛伊马可以隐藏收集敏感信息的程序、为计算机打开后门，或主动上传和下载文件。这种可能性是无尽的。

### Rootkit（内核包）

`rootkit`是一种恶意软件，通过修改或替换一个或多个现有程序来隐藏计算机已被入侵的事实。Rootkit 经常修改操作系统的部分来掩盖其存在的痕迹。Rootkit 可以存在于任何层，从计算机的启动指令到运行在操作系统中的应用程序。一旦安装，rootkit 就能为攻击者提供访问受损计算机的机会，并能轻松启动额外的攻击。

Rootkits 比其他类型的恶意软件要新，直到 1990 年左右才出现。它们很难被检测和删除，因为它们的主要目的是隐藏自己的存在。但识别和删除 rootkit 对于维护系统的安全至关重要。

![image](img/note.jpg) **提示**

Rootkits 经常与其他恶意软件协同工作。假设一个程序`malware.exe`正在 Windows 系统上运行。一个简单的 rootkit 示例是将 Windows 任务管理器替换为修改过的版本，该版本不会列出任何名为`malware.exe`的程序。管理员将不知道该恶意程序正在运行。

### Spyware（间谍软件）

最后一种主要的恶意软件类型是`spyware`。间谍软件是在用户不知或未授权的情况下秘密收集信息的软件。收集的信息可以是敏感的个人信息，例如密码或信用卡号，或者是用于构建未来行动画像的信息。间谍软件通常被激进的营销人员用于收集有关客户的特定信息及其偏好。

大多数间谍软件寄生在其他合法程序上。它们随着目标程序一起安装。虽然大多数间谍软件的主要目的是收集和报告信息，但这一过程可能会导致其他问题。间谍软件会运行额外的进程来收集信息碎片。这增加了进程数量，消耗了更多内存，并通常会减慢计算机速度。安装了许多间谍软件的计算机运行速度明显慢于干净的计算机。

间谍软件自 20 世纪 90 年代后期一直存在，但在 2000 年之后变得更加普遍。互联网的快速增长使攻击者能够从毫无防备的用户那里收集有用信息。间谍软件收集的信息用途范围从定制化的建议性销售到身份盗窃。间谍软件的主要目标是收集和交付信息——尤其是隐私信息。一旦成功，间谍软件就违反了信息隐私，并为未经授权的用户提供了轻松访问的机会。隐私信息应该保持私密。间谍软件是一种专门威胁信息机密性的恶意软件。

### Ransomware（勒索软件）

另一类型的恶意软件尝试直接从计算机用户获取资金。`Ransomware`攻击计算机并限制用户访问计算机的能力。它可以通过减慢计算机速度、拒绝授权用户的访问或阻止对特定程序或资源的访问来限制访问。某些勒索软件通过加密重要文件甚至整个磁盘并使其无法访问来运行。攻击者通常会通知用户这些限制，并要求支付费用以恢复完全访问权限。这种付款，即"赎金"，赋予了此类恶意软件其名称。攻击者承诺在收到赎金后解密用户数据或移除任何阻止访问的机制。大多数计算机用户依赖于他们的计算机和存储的数据。很少有计算机用户能够在失去对数据和其他资源的访问权限而不遭遇持续的挫败。

业务用户可能会发现勒索软件不仅仅是一个简单的骚扰。无法访问业务计算系统的关键部分可能与`DoS`攻击的效果相同。勒索软件可以导致组织在短时间内损失巨额资金。发起勒索软件攻击的攻击者让自己暴露在巨大的风险中，但也获得巨利。勒索软件是恶意软件中日益增长的趋势。用户对移动设备的依赖使得此类设备成为具有吸引力的目标。随着 Windows 计算机和设备变得更加移动，它们更容易受到潜在的勒索软件攻击。

### 恶意软件类型总结

目前大多数恶意软件倾向于复杂的，并具有本节中讨论的几种基本类型的特征。现代恶意软件通常是两种或更多类型的混合体，使其更有效且更难对付。尽管混合恶意软件变得越来越常见，但理解基本类型以及如何保护你的系统仍然重要。防止更复杂的恶意软件通常包括保护系统不受基本恶意软件类型组合的影响。

**警告**

计算机不必连接到网络也可能被恶意软件感染。恶意软件可以通过可移动介质以及网络在计算机之间传输。任何 CD、DVD、USB 设备或可移动设备都有将受感染程序传输到目标机器的可能。在制定反病毒策略时，不要忽视可移动介质。

## 杀病毒软件

`杀毒软件`可以帮助检测和缓解某些类型的恶意软件。市上有许多杀毒程序，它们可以识别许多已知的恶意软件类型，并帮助应对恶意软件程序带来的威胁。大多数杀毒软件侧重于病毒、蠕虫和特洛伊马，但可能也处理根包（rootkits）和间谍软件。目前的杀毒软件提供了预防、检测和移除恶意软件实例的能力。

市上有许多高质量的杀毒软件产品。表 5-2 列出了 Windows 平台上较常用的几种杀毒产品。请注意，表 5-2 仅仅是一些常用杀毒产品的示例列表。

识别恶意软件最常用的方法是将已知的恶意软件代码与内存中运行的进程或存储在磁盘上的文件进行比较。每个恶意软件实例都有一组独特的指令，称为恶意软件的`signature`（签名），用于识别您系统上的任何恶意软件副本。已知恶意软件签名的组织集合存储在`signature database`（签名数据库）中。杀毒软件在扫描进程或文件时可以使用签名数据库进行签名匹配。任何包含与已知恶意软件签名匹配指令的进程或文件都被标记为恶意软件。

### 反间谍软件

`Anti-spyware`软件是另一类型的反恶意软件。它帮助检测和缓解恶意软件。正如其名所示，首要目标是间谍软件。虽然许多杀毒软件套件可能包含反间谍软件组件，但使用一个或多个独立的反间谍产品是有价值的。间谍软件实例非常多，因此使用多个反间谍软件产品是有意义的，以确保你尽可能识别计算机上尽可能多的实例。

### 更新软件的重要性

攻击者每天都会引入新的恶意软件。来自 Kaspersky 的 Eugene Kaspersky 报告，每天有 70,000 种新的病毒、木马和其他恶意软件。这与几年前相比是巨大的增长。如果你每周只更新杀毒或反间谍软件，你可能会面临 1,400 个新威胁。

当攻击者发布新的恶意软件时，竞赛就开始了。从一开始，启发式软件就可以检测到活动并将其识别为恶意软件。基于签名的恶意软件工具在签名添加到数据库之前无法识别该威胁。最大的潜在受害者出现在零日攻击中。零日攻击是指利用未知漏洞的恶意软件，且符合以下情况之一：

- 恶意软件的行为已被注意到但漏洞尚未发现。
- 恶意软件的行为已被注意到但尚未被识别为攻击。
- 恶意软件和漏洞已被识别，但尚无修复。
