## EternalBlue 漏洞

近期最常用的 SMB 漏洞之一是 EternalBlue 漏洞，它是由一个名为“影子经纪”的实体泄露的，据称他们从美国国家安全局（NSA）盗了大量漏洞。成功利用 EternalBlue 可以允许未经身份的远程攻击者入侵受影响系统并执行任意代码。该漏洞已用于 WannaCry 和 Nyeta 等勒索软件。该漏洞已被移植到许多不同的工具，包括 Metasploit。

示例 5-2 提供了 Metasploit 中 EternalBlue 漏洞的简要示例。（第 10 章，“工具与代码分析”提供了关于 Metasploit 的详细信息。）

### 提示

如何知道寻找特定的漏洞，例如 EternalBlue 漏洞？要确定任何漏洞的精确位置，你可以使用 Metasploit 中的 `search` 命令。

在示例 5-2 中，调用了 `use exploit/windows/smb/ms17_010_eternalblue` 命令来使用 EternalBlue 漏洞。然后使用 `show options` 命令显示 EternalBlue 漏洞的所有可配置选项。至少必须配置远程主机的 IP 地址（`RHOST`）和你希望受害者在利用后与之通信的主机 IP 地址（`LHOST`）。要配置 `RHOST`，你使用 `set RHOST` 命令后跟远程系统的 IP 地址（在本例中为 `10.1.1.2`）。要配置 `LHOST`，你使用 `set LHOST` 命令后跟远程系统的 IP 地址（在本例中为 `10.10.66.6`）。远程端口（`445`）已默认为你配置好了。在运行 `exploit` 命令后，Metasploit 会对目标系统执行利用并启动 Meterpreter 会话，允许你控制并进一步渗透该系统。Meterpreter 是一种后渗透利用工具，你将在第 10 章中学习到。枚举在渗透测试中起着重要作用，因为其可以使用 `nmap` 等工具发现受漏洞的系统。

## DNS 投毒

DNS 缓存中毒是攻击者利用的另一种常用攻击。简单来说，DNS 缓存中毒涉及通过注入损坏的数据来操纵 DNS 解析器，强制 DNS 服务器向受害者发送攻击系统的 IP 地址。这在图 5-2 中有所说明。

**图 5-2 投毒示例**

以下步骤如图 5-2 所示：

1. 攻击者破坏缓存以伪造网站。
2. 攻击者执行 DNS 毒后，DNS 服务器将 `theofhacking.org` 解析到攻击系统。
3. 受害者向 DNS 服务器请求获取 `theofhacking.org` 的 IP 地址。
4. DNS 服务器回复攻击系统的 IP 地址。
5. 受害者向攻击系统发送 HTTP GET 请求，攻击者伪装了 `theofhacking.org`。

### 示例 5-3 投毒攻击前的 DNS 解析

```

```
