
另一类此类矩阵的流行例子是通过从伯努利分布或相关分布中独立同分布采样条目来构造的：

```
X(i, j) = {
    + 1/sqrt(N),  with probability 1/2,
    - 1/sqrt(N),  with probability 1/2
}
```

或者：

```
X(i, j) = {
    + sqrt(3/N),  with probability 1/6,
    0,            with probability 2/3,
    - sqrt(3/N),  with probability 1/6
}
```

最后，可以采用均匀分布，通过在 $\mathbb{R}^N$ 中的单位球面上均匀随机采样来构造 `X` 的列。事实证明，只要观测数 `N` 满足不等式

$$N \ge C k \ln(l/k)$$

此类矩阵以极大概率满足 `k` 阶 RIP，其中 `C` 是依赖于等距常数 $\delta_k$ 的某个常数。换句话说，有了这样的矩阵，可以从 `N < l` 个观测值中恢复一个 `k` 稀疏向量，其中 `N` 比稀疏度大一个由不等式 (9.33) 控制的量。关于这些问题的更多信息可参考文献 [6, 67]。

除了随机矩阵，还可以构造其他满足 RIP 的矩阵。其中一个例子是部分傅里叶矩阵，它是通过从 *l* × *l* DFT 矩阵中均匀随机选择 *N* 行形成的。尽管满足 RIP 所需的样本数量可能比公式 (9.33) 中的界限更大（参见文献 [79]），但基于傅里叶的感知矩阵在存储（𝒪(*N* ln *l*））和矩阵-向量乘积（𝒪(*l* ln *l*））方面提供了特定的计算优势 [20]。文献 [56] 考虑了包含行间统计依赖的随机托普利茨感知矩阵的情况，并表明它们也可以以高概率满足 RIP。这在信号处理和通信应用中尤为重要，因为系统通常通过时间序列在输入端被激励，因此不能假设连续输入行之间的独立性。文献 [44, 76] 考虑了可分离矩阵的情况，其中感知矩阵是单独满足 RIP 的矩阵的克罗内克积结果。此类矩阵对于多维信号很有意义，旨在利用每个相关维度上的稀疏结构。例如，当试图“编码”跨越时间、频谱、空间和其他域的事件相关信息时，可能会出现此类信号。

尽管它们在理论上很优雅，但确定特定稀疏水平所需观测数量的推导界限却低于实验证据（例如文献 [39]）。在实践中，一个经验法则是使用 3*k*–5*k* 阶的 *N* [18]。对于与稀疏水平相比较大的 *l* 值，文献 [38] 的分析表明，当 *N* ≳ 2*k* ln(*l*/*N*) 时，我们可以恢复大多数稀疏信号。为了克服与 RIP 相关的不足，已经提出了许多其他技术（例如文献 [11, 30, 39, 85]）。此外，在特定应用中，使用实证研究可能是一条更合适的途径。

请注意，原则上，从 *N* < *l* 个观测中恢复一个 *k*-稀疏向量所需的最小观测数是 *N* ≥ 2*k*。确实，正如 定理 9.3 后的讨论精神所言，感知矩阵必须满足的主要要求是不将两个不同的 *k*-稀疏向量映射到相同的观测向量 **y**。否则，永远无法从它们的（共同）观测中恢复出这两个向量。如果我们有 2*k* 个观测，并且感知矩阵保证任意 2*k* 列线性无关，则满足上述要求。然而，为了使相应矩阵满足 RIP 而设定的观测数量界限更大。这是因为 RIP 还考虑了恢复过程的稳定性。我们将在第 9.9 节讨论*稳定*嵌入时回到这个问题。

## 9.8 从噪声测量中鲁棒恢复稀疏信号

在上一节中，我们的重点是从一个欠定方程组中恢复稀疏解。在问题公式化中，我们假设获得的观测中没有噪声。在从较简单场景中获得一些经验和洞察后，我们现在将注意力转向更现实的任务，即不确定性因素介入的场景。一种不确定性可能源于噪声的存在，此时我们的观测模型回归到标准回归形式：

**y** = *X***θ** + **η**,

(9.34)

其中 *X* 是我们熟悉的非方 *N* × *l* 矩阵。从公式 (9.34) 恢复 **θ** 的稀疏感知公式化可以表示为：

```
min_{θ ∈ R^l} ||θ||_1, s.t. ||y - Xθ||_2² ≤ ε,
```

(9.35)

这与公式(9.8)中给出的 LASSO 任务一致。这种表述隐含地假设噪声是有界的，且相应的取值范围由 `ϵ` 控制。可以考虑许多不同的变体。例如，一种可能性是最小化 `∥⋅∥₀` 范数而非 `∥⋅∥₁` 范数，尽管这会失去后者的计算优雅性。另一种途径是将约束中的欧几里得范数替换为另一种范数。

除了噪声的存在，还可以从另一个角度来看待前面的表述。未知参数向量 `θ` 可能并非严格稀疏，但它可能由少数大分量组成，而其余分量很小且接近零，但不一定等于零。这种模型失配可以通过允许 `y` 偏离 `Xθ` 来适应。

在这种稀疏解恢复的宽松设定下，关于 `ℓ₀` 和 `ℓ₁` 解的唯一性和等价性概念不再适用。取而代之，现在变得重要的问题是解的*稳定性*。为此，我们关注计算上具有吸引力的 `ℓ₁` 任务。定理 9.3 的对应表述现在如下。

### 定理 9.4

*假设感知矩阵 `X` 满足 `δ₂ₖ < √2 - 1` 的 RIP 条件，对于某个 `k`。则公式(9.35) 的解 `θ*` 满足以下不等式（[22,23]）：*

```
‖θ - θ*‖₂ ≤ C₀k^(-1/2)‖θ - θₖ‖₁ + C₁√ϵ
```

(9.36)

*其中常数 `C₁`、`C₀` 和 `θₛ` 定义见定理 9.3。*

这也是一个优雅的结果。如果模型是精确的且 `ϵ = 0`，我们得到公式(9.32)。如果不是，模型中的不确定性（噪声）项越高，我们对解的模糊性就越大。还要注意，对解的模糊性取决于真实模型与 `θₖ` 的偏离程度。如果真实模型是 `k` 稀疏的，不等式右边的第一项为零。`C₁`、`C₀` 的值取决于 `δ₂ₖ`，但它们很小，例如接近五或六 [23]。

这里的重要结论是：*采用 `ℓ₁` 范数及相关的 LASSO 优化来求解逆问题（正如我们在第 3 章中指出的，这类问题通常倾向于病态）是稳定的，并且在恢复过程中噪声不会被过度放大*。

## 9.9 压缩感知：随机性的荣耀

本章的部署方式大致遵循了稀疏感知参数估计领域演变过程中的发展序列。我们有意遵循这条路径，因为这也表明了科学在大多数情况下是如何演进的。起点具有相当浓厚的数学色彩：在稀疏约束下，以数学上可处理的方式（即使用凸优化）来建立欠定线性方程组解的条件。最终，一系列个体贡献的积累揭示了：如果未知量是通过随机选择的数据样本进行感知的，则该解可以（唯一地）恢复。这一发展反过来催生了一个具有浓厚理论兴趣且对实际应用产生巨大影响的新领域。这个新兴领域被称为*压缩感知*或*压缩采样*（CS），它改变了我们关于如何高效感知和处理信号的观点。

### 压缩感知

在 CS 中，目标是直接获取尽可能少的样本，这些样本编码了获得压缩信号表示所需的最小信息量。为了演示这一点，让我们回到第 9.4 节讨论的数据压缩示例。在那里，曾评论说“经典”压缩方法相当不合常规，因为首先使用信号的所有（即 *l* 个）样本，然后对它们进行处理以获得 *l* 个变换值，最后仅使用其中一小部分进行编码。在 CS 设定中，程序变为以下过程。

设 *X* 为 *N* × *l* 感知矩阵，它作用于（未知）信号向量 **s**，以获得观测值 **y**；设 Ψ 为字典矩阵，描述信号 **s** 接受稀疏表示的域，即：

**s** = *Ψ***θ**, **y** = *X***s**.

假设 **θ** 的分量中至多有 *k* 个非零，若组合矩阵 *X*Ψ 满足 RIP，且观测数 *N* 足够大（由公式 (9.33) 中的界决定），则可通过以下优化任务获得：

```
min_{θ ∈ R^l} ||θ||_1, s.t. y = XΨθ
```

注意：**s** 无需存储，一旦 **θ** 已知，随时可获得。此外，正如我们即将讨论的，存在一些技术允许直接从模拟信号 *s*(*t*) 获取观测值 *y*[*n*]，*n* = 1, 2, …, *N*，而无需先获得其采样（向量）版本 **s**！因此，从这个角度来看，CS 将数据采集和压缩步骤融合在了一起。

获得感测矩阵 `X` 有多种不同的方法，它们会导出乘积 `XΨ`，该乘积满足 RIP。可以证明（问题 9.19），如果 `Ψ` 是正交规范矩阵，且 `X` 是一个随机矩阵，其构造方式如第 9.7.2 节末尾所述，那么乘积 `XΨ` 将满足 RIP，前提是满足 (9.33)。获得满足 RIP 的组合矩阵的另一种方法是考虑另一个正交规范矩阵 `Φ`，其列与 `Ψ` 的列具有低相干性（两个矩阵间的相干性定义见公式 (9.25)，其中 `x[i]^(c)` 的位置现在由 `Φ` 的一列取代，`x[j]^(c)` 的位置由 `Ψ` 的一列取代）。例如，`Φ` 可以是 DFT 矩阵而 `Ψ = I`，反之亦然。然后从 `Φ` 中均匀随机选取 `N` 行来构成公式 (9.37) 中的 `X`。换句话说，对于这种情况，感测矩阵可以写为 `RΦ`，其中 `R` 是一个 `N × l` 矩阵，用于均匀随机抽取 `N` 行。感测矩阵与基矩阵之间的非相干性（低相干性）概念与 RIP 密切相关。这两个矩阵越不相干，RIP 成立所需的观测数量就越少（例如，[21,79]）。从另一个角度看，非相干性意味着 `Φ` 的行不能用 `Ψ` 的列稀疏表示。结果表明，如果感测矩阵 `X` 是按第 9.7.2 节所述形成的随机矩阵，那么 RIP 以及与任意 `Ψ` 的非相干性都将以高概率得到满足。

当我们说所有前面陈述的理论都可以推广到更一般类型的信号时，情况变得更好了，这些信号不一定是稀疏的，也不一定能用字典原子稀疏表示，它们被称为*可压缩*信号。如果一个信号向量在某个基下的展开仅包含少数几个大的参数 `θ[i]`，而其余参数都很小，则称该信号向量为可压缩的。换句话说，信号向量在某个基下是*近似*稀疏的。显然，这是实践中最有趣的情况，因为精确稀疏极少（如果有的话）出现。重述第 9.8 节中使用的论点，该情况下的 CS 任务可以表述为

```
\min_{\mathbf{\theta} \in \mathbb{R}^{l}} \ \ \ \ \left\| \mathbf{\theta} \right\|_{1},\text{s.t.} \ \ \ \ \left\| \mathbf{y} - X\Psi\mathbf{\theta} \right\|_{2}^{2} \leq \epsilon,
```

如果用乘积 `XΨ` 代替 `X`，第 9.8 节所述的一切对该情况也同样适用。

### 备注 9.9

*   CS 中的一个重要性质是，提供观测值的感测矩阵可以独立于矩阵 `Ψ` 来选择，即信号在其中稀疏表示的基/字典。换句话说，感测矩阵可以是“通用”的，可用于提供观测值以重构任意稀疏或可稀疏表示的信号（在任意字典中），前提是不违反 RIP。

### 9.9.1 降维与稳定嵌入

*   每个观测值 `y[n]` 是信号向量与感测矩阵 `X` 的一行 `x[n]^T` 进行内积运算的结果。假设信号向量 `s` 是模拟信号 `s(t)` 采样过程的结果，`y[n]` 可以通过将 `s(t)` 与对应于 `x[n]` 的感测波形 `xn` 进行内积运算（积分）直接获得，这是一个很好的近似。例如，如果 `X` 由 ±1 构成，如第 9.7.2 节所述，则 图 9.10 所示的配置会产生 `y[n]`。除了避免计算和存储 `s` 的 `l` 个分量之外，这种方法的一个重要方面是乘以 ±1 是一个相对简单的操作。它等同于改变信号的极性，并且可以通过使用反相器和混频器来实现。这是一个在实践中可以以比采样高得多的速率执行的过程。图 9.10 所示的采样系统被称为*随机解调器* [58,91]。它是流行的模数（A/D）转换架构之一，这些架构利用 CS 理论以远低于经典采样所需的速率进行采样。我们稍后将回到这个话题。

#### 降维与稀疏恢复的视角

我们将从另一个角度来阐述本章迄今为止的内容。在两种情况下——无论是未知量是高维空间 $\mathbb{R}^l$ 中的 $k$-稀疏向量，还是信号 $\mathbf{s}$ 在某个字典中（近似）稀疏表示（$\mathbf{s} = \mathbf{\Psi}\boldsymbol{\theta}$）——我们都选择在低维空间（$\mathbb{R}^N$，即观测空间 $\mathbf{y}$）中工作。这是一个典型的降维任务（参见第 20 章）。

任何（线性）降维技术的主要任务是选择合适的矩阵 $X$，它决定了向低维空间的投影。一般来说，从 $\mathbb{R}^l$ 投影到 $\mathbb{R}^N$（其中 $N < l$）总会丢失信息，因为我们无法从其投影 $\boldsymbol{\theta}_N \in \mathbb{R}^N$ 中恢复任意向量 $\boldsymbol{\theta}_l \in \mathbb{R}^l$。确实，取任意向量 $\boldsymbol{\theta}_{l-N} \in \text{null}(X)$，它位于（满行秩）$X$ 的 $(l-N)$ 维零空间中（参见第 9.5 节）。那么所有向量 $\boldsymbol{\theta}_l + \boldsymbol{\theta}_{l-N} \in \mathbb{R}^l$ 在 $\mathbb{R}^N$ 中具有相同的投影。

然而，本章发现的关键在于：如果原始向量是稀疏的，则可以精确恢复它。这是因为所有 $k$-稀疏向量并不分布在 $\mathbb{R}^l$ 的任意位置，而是位于其一个子集中，即*子空间并集*，每个子空间的维度为 $k$。如果信号 $\mathbf{s}$ 在字典 $\mathbf{\Psi}$ 中是稀疏的，那么就必须在 $\mathbb{R}^l$ 所有可能的 $k$ 维子空间的并集中搜索它，这些子空间由 $\mathbf{\Psi}$ 的 $k$ 个列向量张成 [8,62]。

当然，即使涉及稀疏向量，也没有任何投影能保证唯一恢复。保证的前提是低维空间中的投影是*稳定嵌入*。稳定嵌入必须保证：如果 $\boldsymbol{\theta}_1 \neq \boldsymbol{\theta}_2$，则它们的投影也保持不同。但这还不够。稳定嵌入还必须保证距离（近似）保持不变；即高维空间中相距较远的向量，其投影也相距较远。这种性质保证了对噪声的鲁棒性。

贯穿本章推导和讨论的充分条件，能保证从 $\mathbb{R}^N$ 中的投影恢复位于 $\mathbb{R}^l$ 的稀疏向量，这些条件正是保证稳定嵌入的条件。RIP 及其对 $N$ 的相关界给出了 $X$ 的条件，从而实现稳定嵌入。我们在相关小节中评论了 RIP 的这一范数保持性质。理论得出的一个有趣事实是：我们可以通过随机投影矩阵实现这种稳定嵌入。

降维随机投影并非新事物，且已在模式识别、聚类和数据挖掘中得到广泛应用（参见例如 [1,13,34,82,87]）。大数据时代的到来重燃了人们对随机投影辅助数据分析算法（例如 [55,81]）的兴趣，主要有两大原因。首先，在低维空间中进行数据处理计算量更轻，因为它涉及的矩阵或向量运算所用参数更少。此外，通过结构良好的矩阵将数据投影到低维空间，其计算成本显著低于通用矩阵-向量乘法所暗示的成本 [29,42]。这些方法所需的计算能力降低，使其在处理海量数据时极具吸引力。第二个原因是存在随机化算法，它们访问数据矩阵的次数（通常为固定次数）远少于常规方法的访问次数 [28,55]。当全部数据无法放入快速内存，必须从硬盘等慢速存储设备分块访问时，这一点至关重要。在这种情况下，计算时间往往主要取决于内存访问的成本。

压缩感知（CS）的核心思想也已在模式识别领域得到利用。在该应用中，完成低维子空间中的信息挖掘活动后，无需返回原始高维空间。由于模式识别的重点在于识别物体/模式的类别，只要不存在与类别相关的信息损失，这项任务就可在观测子空间中完成。文献 [17] 利用压缩感知论据表明，如果数据在原始高维空间中近似线性可分且数据具有稀疏表示（即使是在未知基下），那么随机投影到观测子空间能保留线性可分的结构。

*流形学习* 是随机投影也已应用的另一领域。流形通常是嵌入在高维（环境）空间中的非线性 *k* 维曲面。例如，球面是三维空间中的二维流形。文献 [7,96] 将压缩感知的基本原理推广到位于空间 ℝ^l 的 *k* 维子流形上的信号向量。文中表明，如果选择投影矩阵 *X* 和足够数量 *N* 的观测值，则在投影矩阵 *X* 作用下，相应的子流形在观测子空间中具有稳定嵌入；即成对欧几里得距离和测地距离在投影映射后近似保持不变。更多相关内容可参见所给参考文献及例如 [8]。我们将在第 20 章讨论流形学习任务。

### 9.9.2 次奈奎斯特采样：模拟到信息转换
