
## Lemma 1

Assume that the loss `L(θ(x), y)` is convex in its first argument and that there exists a `λ ∈ ℝ^n` where `λ ≥ 0` and `λ^⊤ 1 = 1` such that the target distribution is exactly equal to the mixture of source distributions, i.e., `Q_T = Σ_{i=1}^n λ_i Q_S^i`. Set the target predictor as the following convex combination of the optimal source predictors

``` 
$\begin{array}{r} {\theta_{T}(x) = \sum\limits_{k = 1}^{n}\frac{\lambda_{k}Q_{S}^{k}(x)}{\sum\limits_{j = 1}^{n}\lambda_{j}Q_{S}^{j}(x))}\theta_{S}^{k}(x).} \\ \end{array}$
```

Recall the pseudo-labeling loss (10). Then, for this target predictor, over the target distribution, the unsupervised loss induced by the pseudo-labels and the supervised loss are both less than or equal to the loss induced by the best source predictor. In particular,

``` 
$\begin{array}{r} {\mathcal{L}(Q_{T},\theta_{T}) \leq \min\limits_{1 \leq j \leq n}\;\mathcal{L}(Q_{T},\theta_{S}^{j}).} \\ \end{array}$
```

Let `α = arg min_{1 ≤ j ≤ n} ℒ(Q_T, θ_S^j)`. Additionally, this inequality is strict if the entries of `λ` are strictly positive and there exists a source `i` for which the strict inequality `ℒ(Q_S^i, θ_S^i) < ℒ(Q_S^i, θ_S^α)` holds.

Before going into the proof, we will discuss how does this lemma translates to `DECISION` and how it motivated us to analyze `DECISION-mlp`.

The key difference between `DECISION` and the predictor in Lemma 1 is the algorithm's combination rule, which fine-tunes the feature extractors of each source model unlike Lemma 1. However, each source has an individual weight which is agnostic to the target data, whereas Lemma 1 uses different weights per input instance. The intuitive justification for choosing this input-agnostic weighting strategy is provided below.

由于缺乏源数据，无法获取源分布的信息，因此采用最不具信息的分布——即根据**最大熵原理**（Principle of Maximum Entropy）选择**均匀分布**（uniform distribution）作为源分布（Jaynes, 1957）。这种均匀性假设适用于目标支持集 `𝒳`。接下来，算法会将源分布在目标支持集 `𝒳` 上的限制进行考虑。数学上，假设 `Q_S^k(x) = c_k 𝒰(x)` 在支持集 `x ∈ 𝒳` 上成立，其中 `c_k` 是一个缩放因子，反映源 `k` 的相对贡献，而 `𝒰(x)` 的取值为 1。将该分布代入 Lemma 1 中的组合规则，得到 `θ_T(x) = Σ_{k=1}^n (λ_k c_k / Σ_{j=1}^n λ_j c_j) θ_S^k(x)`：

``` 
$\begin{array}{ll} {\theta_{T}\left( x \right)} & {= \sum\limits_{k = 1}^{n}\frac{\lambda_{k}Q_{S}^{k}\left( x \right)}{\sum\limits_{j = 1}^{n}\lambda_{j}Q_{S}^{j}\left( x \right)}\theta_{S}^{k}\left( x \right)} \\ & {= \sum\limits_{k = 1}^{n}\frac{\lambda_{k}c_{k}\mathcal{U}\left( x \right)}{\sum\limits_{j = 1}^{n}\lambda_{j}c_{j}\mathcal{U}\left( x \right)}\theta_{S}^{k}\left( x \right)} \\ & {= \sum\limits_{k = 1}^{n}\frac{\lambda_{k}c_{k}}{\sum\limits_{j = 1}^{n}\lambda_{j}c_{j}}\theta_{S}^{k}\left( x \right)} \\ & \\ \end{array}$
```

(13)

这一项中 `λ_k` 和 `c_k` 组成的权重项 `α_k` 在 `DECISION` 中起关键作用。下一步是将 `θ_T` 与 `α_k` 以及 `ϕ_S^k` 一同用于求解优化问题（12）。因此，`DECISION` 会返回一个满足 Lemma 1 界限的有利源假设组合，前提是源分布均匀。但如果不假设源分布均匀，则可以通过估计 `Q_S^k` 来最小化目标风险，这将在下一节的拟议框架 `DECISION-mlp`（Fig. 3）中讨论。

## 7: Source distribution dependent weights (`DECISION-mlp`)

模型聚合方案中的混合权重（Lemma 1）以及 Mansour et al. (2009) 和 Hoffman et al. (2018a) 都依赖于源分布和目标样本。由于缺乏源数据，均匀源分布的假设导致了 Algorithm 1。然而，若不假设源分布，仍可通过 MLP 估计其分布。假设有 `n` 个 MLP `ℳ_S^k`（`k = 1, 2, …, n`）来估计 `n` 个源分布（Fig. 3）。目标特征通过对每个样本分别通过特征编码器，并将它们拼接成长度为 `d` 的向量，其中 `d = Σ_{i=1}^n d_i`。若目标样本为 `x_T^i`，则拼接向量 `ϕ(x_T^i)` 可表示为 `ϕ(X_T^i)^⊤ ∈ ℝ^d`。随后，`ϕ(x_T^i)` 依次输入所有 MLP，得到 `n` 个标量 `{ℳ_S^k(ϕ(X_T^i))}_{k=1}^n`，这些标量类似于 Lemma 1 中的 `λ_k Q_S^k(x)`。经过归一化后，这些标量模拟了 `α` 的函数形式，既依赖于源分布，也依赖于目标样本。简言之，若第 `i` 个样本在第 `j` 个源上对应的权重为 `α_j^i`，则有：

``` 
$\begin{array}{r} {\alpha_{j}^{i} = \frac{\mathcal{M}_{S}^{j}(\phi(x_{T}^{i}))}{\sum\limits_{k = 1}^{n}\mathcal{M}_{S}^{k}(\phi(x_{T}^{i}))}} \\ \end{array}$
```

(14)

在此新设定下，损失函数稍作修改。设 `ℒ_ent′`、`ℒ_div′` 和 `ℒ_pl′` 分别为修正后的熵、多样性和伪标签损失，则有：

``` 
$\begin{array}{r} {\mathcal{L}_{\text{ent}}^{\prime} = - \mathbb{E}_{x_{T}^{i} \in \mathcal{D}_{T}}\left\lbrack {\sum\limits_{j = 1}^{K}\delta_{j}(\theta_{T}(x_{T}^{i}))\log(\delta_{j}(\theta_{T}(x_{T}^{i})))} \right\rbrack} \\ \end{array}$
```

(15)

其中 `θ_T(x_T^i) = Σ_{j=1}^n α_j^i θ_S^j(x_T^i)`。

``` 
$\begin{array}{r} {\mathcal{L}_{\text{div}}^{\prime} = \sum\limits_{j = 1}^{K} - {\overset{-}{p}}_{j}^{\prime}\log{\overset{-}{p}}_{j}^{\prime}} \\ \end{array}$
```

(16)

其中 `p̄_j′ = 𝔼_{x_T^i ∈ 𝒟_T}[δ_j(θ_T(x_T^i))]`。

``` 
$\begin{array}{r} {\mathcal{L}_{\text{pl}}^{\prime}(Q_{T},\theta_{T}) = - \mathbb{E}_{x_{T}^{i} \in \mathcal{D}_{T}}\sum\limits_{k = 1}^{K}1\{ ŷ_{T}^{\prime} = k\}\log\delta_{k}(\theta_{T}(x_{T}^{i})).} \\ \end{array}$
```

(17)

其中 `ŷ_T′` 的计算方式与 `ŷ_T` 相同，但使用了修正后的 MLP 权重。

总体修正目标函数为：

``` 
$\begin{array}{r} {\mathcal{L}_{tot}^{\prime} = \mathcal{L}_{\text{ent}}^{\prime} - \mathcal{L}_{\text{div}}^{\prime} + \lambda\mathcal{L}_{\text{pl}}^{\prime}} \\ \end{array}$
```

(18)

which gives rise to a new optimization problem as follows:

``` 
$\begin{array}{ll} {\operatorname{minimize}\limits_{{\{\phi_{S}^{j}\}}_{j = 1}^{n},{\{\mathcal{M}_{S}^{j}\}}_{j = 1}^{n}}\quad} & \mathcal{L}_{tot}^{\prime} \\ {\text{subject\\ to}\\quad} & {\alpha_{j}^{i} = \frac{\mathcal{M}_{S}^{j}(\phi(x_{T}^{i}))}{\sum\limits_{k = 1}^{n}\mathcal{M}_{S}^{k}(\phi(x_{T}^{i}))},} \\ \quad & {\alpha_{j}^{i} \geq 0,} \\ \quad & {\sum\limits_{j = 1}^{n}\alpha_{j}^{i} = 1,\forall j \in \{ 1,2,\ldots,n\},\forall i \in \{ 1,2,\ldots,n_{T}\}} \\ \quad & \\ \end{array}$
```
