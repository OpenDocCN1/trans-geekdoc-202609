
### 数据探索在数据挖掘项目中的重要性

| 项目 | 数据探索的重要性 |
| --- | --- |
| 理解数据特征 | 数据探索有助于我们获得数据集特征的洞见。它允许我们理解数据分布、范围、变异性和潜在的数据质量问题。通过探索数据，我们可以识别离群值、缺失值、数据不一致或其他可能影响数据质量和有效性的异常。 |
| 变量选择 | 理解数据允许我们识别用于数据挖掘任务的相关变量。通过分析变量之间的关系、其分布以及对目标变量的潜在影响，我们可以对在建模过程中包含或排除哪些变量做出明智决策。 |
| 数据预处理和清洗 | 数据探索对于识别和解决数据质量问题非常有用。我们可以检测并处理缺失值、离群值、重复项或不一致的数据。可以根据探索阶段获得的见解执行填充、离群值检测或数据转换等数据处理任务。有效的数据清洗和准备可以提高模型性能并获得更可靠的结果。 |
| 识别模式和关系 | 探索数据允许我们识别变量之间的潜在模式、趋势或关系。通过可视化数据、应用统计指标或进行探索性数据分析技术，我们可以发现有意义的见解并理解数据的底层结构。这些见解指导了合适机器学习方法的选择，并帮助我们提高预测模型的预测能力。 |
| 假设和局限性 | 通过探索数据，我们可以识别违反特定机器学习算法所需假设的任何情况。这种意识使我们能够对某些技术的适用性做出明智决策，并避免建模过程中的潜在陷阱或偏差。 |
| 新发现 | 数据探索可以激发新发现的产生。通过观察数据中的模式或趋势，我们可能会产生新的潜在关系进行进一步调查。探索期间获得的这些初步见解可以指导随后的建模和分析，带来新的发现和研究方向。 |

探索数据有两种方法：可视化和统计探索。可视化允许我们通过不同类型的图表查看数据趋势和模式，并从数据中收集有用信息。这种方法易于使用，并可以整合到经理或高管的商业智能仪表板中。通过可视化可以非常快速地观察模式或趋势。市场上有许多可视化工具，如 `Tableau`、`Power BI` 和 `SAS Viya`。这些应用程序允许我们根据需求添加和自定义图表和图形。如果我们有大数据，数据可以实时通过仪表板，我们可以看到感兴趣变量在不同时间或随时间推移的模式。这些工具提供了显示最新信息的动态可视化工具。在书中，我主要关注一些我们可以用于分析目的以探索数据的图表。这些图表是半动态的，因为某些图表工具允许我们旋转图表并从不同角度查看。它们为我们提供了开发良好预测模型所需的信息。

![](img/ufig4_1.jpg)

对于数据挖掘而言，仅靠可视化可能是不够的。统计探索可以定量输出的形式为我们提供有用信息。它们包括变量的描述性统计，允许我们理解数据中变量的特征。此外，统计探索还提供了关于目标变量与预测器之间相关性的初步信息。将可视化与统计结合可以兼顾之长。我将向你展示如何使用结合方法来探索和理解数据。

### 数据描述

在数据探索中需要记住的一个重要点是，我们不能在不知道数据中包含哪些变量及其属性的情况下就直接开始构建图表和图形。原因是我们将不知道应该使用何种类型的图表以及如何解释输出结果。因此，在运行任何可视化之前，我们首先需要获取有关数据集的基本信息，特别是变量数量、变量描述和变量标度。这些信息将帮助我们决定应该使用什么类型的图表来理解数据。

在本章中，我使用了 `airline recommendation`（航空公司推荐）数据示例来演示可以使用 SAS Enterprise Miner 的各种可视化类型。首先，让我们来看看这个数据集的参数和特征。

### 案例研究 – 航空公司推荐

![](img/icon_10.jpg)

在此案例研究中，对美国多家航空公司的乘客进行了一项大规模调查。乘坐特定航空公司从一个出发地飞往另一个目的地的乘客被要求就他们的飞行体验以及是否会向他人推荐该航空公司进行调查。他们提供了人口统计学信息和飞行体验，包括出发地和目的地州、过去的飞行次数、旅行目的、机场消费金额以及价格敏感性。乘客调查数据与航空公司状态和飞行变量整合在一起，包括飞行距离、飞行时间、起飞和到达延迟以及航班取消。该项目旨在预测目标变量，即乘客对航空公司的推荐。我们希望确定哪种模型最能预测这个目标变量，哪些变量是重要的预测因子。预测将帮助航空公司高管制定策略以改进他们的运营和服务并吸引更多乘客。

**变量名称**：由于变量名在实际分析和结果中使用，它们应该清晰且简洁。变量名应该足够清晰以便我们识别该变量。同时，它也应该是短的，以免名称在输出中被截断。许多软件应用程序为变量名设置了长度限制。我非常建议不要在变量名中使用空格或特殊字符（`@#$%^&*`）。原因是 SAS Enterprise Miner 等软件不允许空格和特殊字符，如果我们在变量名中检测到这些问题，将给出错误信息。编程软件（如 `R` 或 `Python`）也有相同的要求。其他软件可能更灵活，但如果我们想将模型与 Python 平台整合，就会产生更多的错误。为了分隔变量名中的单词，我们使用下划线（`_`）而不是空格。

![](img/ufig4_2.jpg)

**变量标签/描述**：可以在描述中提供变量细节。在某些应用程序中，它被称为 `labels`。描述或标签是为了向用户提供变量更详细的描述。如你在 Table 4.2 中所示，标签清晰地解释了每个变量，并包含了测量单位，如年、分钟或英里。标签有助于用户更清楚地理解变量，因为变量名往往很短或使用缩写。变量描述没有限制。尽管如此，我们应该尽量清晰简洁，以避免混乱或误导。具有用户界面（UI）的软件应用程序，如 SAS Enterprise Miner、SPSS Modeler 或 Rapid Miner，通常允许我们选择在变量名旁边显示标签。因此，如果变量名不够清晰，我们始终可以参考标签来完全理解变量。此外，为了报告目的，我们还可以选择在输出中显示标签而不是变量名。在这种情况下，冗长的标签可能会给报告带来问题，因为它们会增大输出表格并使其难以放入报告。此外，冗长的标签也为图表的展示带来了挑战。因此，我们需要仔细选择标签。

**标度**：用于衡量变量的标度对我们的分析非常重要，特别是当我们在建模步骤中确定合适的机器学习算法时。Chapter 2 详细描述了我们拥有的不同变量标度。基本上它们包括名义、二进制、序数或间距。如 Table 4.2 所示，有一个二进制目标变量、七个名义/二进制预测因子和十一个间距预测因子。注意 `price_sensitivity` 使用了 Likert 标度，我们假设该变量各级别之间的间隔是相等的。因此，我们选择将其视为间距变量（关于 Likert 标度的详细讨论请参见 Chapter 2）。

**角色**：最后一个重要信息是变量的角色。基本上，变量有两个主要角色：目标（Target）和输入（Input）。我们需要识别哪些变量是目标变量（我们想要预测的变量），哪些变量是输入（也称为预测因子，即我们用于预测的变量）。在我们的示例中，`recommend` 是具有二进制标度的目标变量，而其他都是预测因子。此外还有一些额外的角色，包括 ID（指示变量）、Time ID（时间标识符）、Rejected（排除分析的变量）、Text（包含文档文本的变量）以及其他。目前，我们主要关注目标角色和输入角色。

![](img/icon_4.jpg)

通过我们每天收集的大数据，可视化是一种强大的工具，可以帮助我们回顾数据趋势和模式，而无需查看原始数据和一些带有数字的描述性统计。即使用户没有数据分析或统计学背景，`数据可视化`也能让他们轻松地查看和理解数据。在许多行业中，组织会开发业务智能仪表板，允许用户快速选择他们想要查看的关键变量或关键性能指标 (KPI)，并生成代表数据趋势或模式的图表。操作人员使用这些工具监控日常运营活动；决策者则利用可视化来制定策略并做出业务决策。尽管如此，重要的是要关注什么（KPI 或指标）以及如何解释结果。

可视化分析应用如 `Tableau`、`Spotfire`、`SAS Visual Analytics` 和 `Microsoft Power BI` 为用户提供了许多功能。无论我们使用哪种工具，它们通常都会使用几种常见的图表类型进行可视化。我将介绍一些常见的图表类型、如何创建它们以及如何解释结果。我将向你展示如何使用 `SAS Enterprise Miner` 创建图表。但请注意，你也可以使用自己熟悉的其他工具来探索数据。如前提到的，在本书中，数据可视化只是 SEMMA 过程中的一步。因此，我们将以半动态模式使用这些图表，而不是你通常在智能仪表板中看到的全动态模式。

我将在 `SAS Enterprise Miner` 中使用两个主要的可视化工具：`Graph Explorer node` 和 `MultiPlot node`。它们都列在顶部菜单栏的 `Explore Tab` 下，因为数据可视化是 SEMMA 过程中的 `Explore` 步骤。

## 柱状图和直方图

![](img/icon_9.jpg)

柱状图和直方图是数据可视化中最常用的图形工具。它们都使用条形（垂直或水平）来展示结果。那么，它们之间的区别是什么？`Table 4.3` 总结了这两种图形工具之间的一些区别。柱状图适用于分类变量，而直方图用于连续变量。我们将深入研究这些图表类型，并学习在何时使用哪种。

#### 表 4.3 柱状图与直方图的区别

| 项目 | 柱状图 (Bar Charts) | 直方图 (Histograms) |
| --- | --- | --- |
| 数据类型 | 柱状图用于显示分类数据。类别或组显示在 x 轴上，柱体的高度或长度代表与每个类别相关的频率或百分比。 | 直方图适用于连续数据。数据被划分为区间或箱（bins），柱体的高度代表落在每个区间内的数据点的频率。 |
| X 轴表示 | 在柱状图中，x 轴代表离散的类别或组。每个类别通常由单独的柱体表示。 | 在直方图中，x 轴代表所测量连续变量的数值范围或区间。区间是连续且相邻的，形成一个连续的刻度。 |
| 数据呈现 | 柱状图对于比较不同类别之间的数据非常有效。它们显示了不同的类别并比较它们的频率。 | 直方图显示连续变量内值的分布情况。它们提供了关于数据形状、中心趋势和离散性的见解。 |
| 柱体放置 | 在柱状图中，柱体之间通常有间隙相互分离，以强调类别之间的区别。 | 在直方图中，柱体通常相邻放置，没有间隙，因为区间是连续的并形成连续的刻度。 |
| 轴标签 | 柱状图为 x 轴上的每个类别使用标签，以指示特定的组或类别。 | 直方图在 x 轴和 y 轴上都使用标签。x 轴标签代表测量变量，y 轴标签代表每个区间内数据点的频率。 |

### 柱状图

基本上，柱状图用于分类变量，并呈现每个类别或每个层级的频率或百分比。它非常容易理解和解释。请注意，百分比对于比较目的效果更好，而频率可以告诉我们每个类别中的案例数量。

![](img/ufig4_4.jpg)

我使用 `Graph Explorer node` 为我们的“航空公司推荐”（airline recommendation）数据集创建了柱状图。请注意，这种方法允许我们根据意愿选择和自定义图表，但我们必须一次创建一个图表。有一种方法可以为数据集中的所有变量创建图表，我稍后向你展示那种方法。

在 `SAS Enterprise Miner` 中按照以下步骤操作：

1. 打开项目 `AirlineProject`。
2. 创建一个新的 Diagram 并命名为 `Explore`。
3. 从 `Explore` 选项卡，将 `Graph Explorer node` 拖入工作区并将其连接到数据源节点。
   ![](img/ufig4_5.jpg)
4. 运行 `Graph Explorer node`。
5. 打开 `Results`。
6. 选择绘图图标 ![](img/ufig4_6.jpg) 或进入 `View/Plot`。
7. 选择 `Bar` 并点击 `Next`。
8. 选择变量 *recommendation*，并将 `Role` 更改为 `Category`。
9. 对于 `Response statistics`，选择 `Frequency`。
   ![](img/ufig4_7.jpg)
10. 点击三次 `Next`。
11. 点击 `Finish`。将生成柱状图。此柱状图显示频率。要显示百分比，你只需要在第 9 步中选择 `Percentage`。

`Figure 4.1` 显示了目标变量 *recommendation* 的频率和百分比的柱状图。请注意，在这些图表中，使用的是标签而不是变量名。这就是为什么你看到 *Recommend the airline* 而不是 *recommendation*。由于目标变量是一个二分类变量（是/否），图表显示这两个层级的频率和百分比。正如我们所见，52.7% 的乘客推荐该航空公司，而 47.3% 不推荐。

### 图形格式化

为了更改图形属性（如颜色、格式、标题、轴、值或图例），我们使用 `Graph Properties`。只需在图表任何地方点击右键并选择 `Graph Properties`。会弹出的新窗口，允许我们配置图表。基本上，你可以更改以下内容：

* `Graph`: 选择具有不同背景和色调的图表样式。
* `Bar`: 更改柱状图中柱的颜色选项；设置柱宽；显示柱索引（变量层级）；在柱中显示响应统计。
* `Axes`: 格式化垂直和水平轴；添加轴标题；配置刻度；并选择轴范围。
* `Title/Footnote`: 显示或隐藏图表标题、子标题或脚注。
* `Legend`: 格式化图表图例；显示或隐藏图例；选择图例布局。

### 两个变量的 2D 或 3D 柱状图

如果我们想绘制两个分类变量以及它们之间的关系，可以使用 2D 柱状图或 3D 柱状图。例如，我们想根据乘客的航空公司状态查看航空公司推荐情况。

为两个变量创建柱状图：

* 遵循上一节中的相同步骤操作。
* 对于 2D 柱状图：在第 8 步中，将 *recommendation* 的 `Role` 更改为 `Category` 并为 *airline_status* 选择 `Group`。
* 对于 3D 柱状图：在第 8 步中，将 *recommendation* 的 `Role` 更改为 `Category` 并为 *airline_status* 选择 *Series*。

图 4.2 显示了两个变量：`recommendation` 和 `airline_status` 的二维和三维柱状图。如你所示，这些柱状图根据航空公司状态的类别分解了目标变量的百分比。在这种情况下，三维柱状图从三维角度呈现数据，更容易跨类别进行比较。我们可以解读为：在推荐该航空公司的乘客中，大多数是蓝卡会员（30%），其次是银卡会员（15%）。然而，有更多蓝卡会员乘客不推荐该航空公司（40%），而只有约 5% 的银卡乘客不推荐该航空公司。换句话说，蓝卡乘客更有可能不推荐航空公司，而银卡乘客更有可能推荐该航空公司。
