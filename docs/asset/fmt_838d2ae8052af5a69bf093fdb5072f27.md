**A.** `DNS amplification`（DNS 放大攻击）

**B.** `DNS server hijacking`（DNS 服务器劫持）

**C.** `SSRF`

**D.** `Metasploit NOPS module`

**A.** `DNS amplification` 攻击正如其名：攻击者利用递归 `DNS` 用 `DNS` 响应淹没目标。基本上，这个坏人建立了一个僵尸网络，并在准备就绪时，让僵尸系统发送 `DNS` 解析请求，伪装成来自目标。`DNS` 执行了它应该做的事，而目标被 `DNS` 响应淹没。

![Image](img/w.jpg) `B` 是错误的，因为 `DNS server hijacking` 指的是攻击者实际上攻破 `DNS` 服务器，并将所有响应路由到恶意网站，而不是原始的 `DNS` 条目。

![Image](img/w.jpg) `C` 是错误的，因为在服务器端请求伪造（`SSRF`）攻击中，攻击者通过让面向网络的服务器代表其发送请求来绕过对内部服务器的限制访问；内部服务器由于信任面向网络的服务器而做出响应，攻击者获得了数据。
