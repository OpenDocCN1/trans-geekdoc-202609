## 4.5.7. 使用 SAM 优化 EVIL

在本节中，我们首先简要描述了通过 SAM 优化以用于 OOD 泛化的 EVIL 实现（EVIL-SAM）。然后，尽管之前发现平坦度与 OOD 泛化之间存在正交性 [139, 221]，我们讨论了 SAM 的一些属性，并证明了为什么结合 EVIL 和 SAM 可以获得卓越的性能。

### EVIL-SAM 的实现。通常，我们的 EVIL 可以通过最小化以下目标来使用 SAM 进行优化：

```
\min_{\theta, ||\epsilon||_2\le\rho} \mathcal{L}(\theta + \epsilon; x, y). \quad (4.10)
```

具体而言，SAM 试图在 `ρ` 半径邻域内计算最优参数扰动 `ε* = arg max_{ε} \mathcal{L}(θ+ε; x, y)`，以最大化增加损失值 `\mathcal{L}`。通过应用 `ε*`，损失变化 `\mathcal{L}(θ+ε*; x, y) - \mathcal{L}(θ; x, y)` 被称为*锐度*，它指示了损失函数的平坦程度。直观上看，更平坦的损失函数显示出更好的泛化特性，输入空间中的轻微偏移不会显著改变损失值。因此，SAM 已经取得了良好的分布内（ID）泛化性能 [224, 158, 210, 159, 169]。为了将 SAM 引入 EVIL，我们只需要在计算最优 `ε*` 之前将我们的掩码 `m` 应用于参数扰动 `ε`。这一过程不仅排除了虚假特征，还减轻了 SAM 的计算负担。结果，SAM-EVIL 可以为不变性学习实现低锐度。

**讨论。** SAM 取得了良好的 ID 结果，但其 OOD 性能相当有限 [139, 221]，这仍然未得到解释。如表 4.5 所示，在 ID 场景下，SAM 相比 ERM 表现出巨大的有效性，但在 OOD 设置下，它仅达到了与 ERM 相当的结果，在某些情况下甚至如此。在我们看来，SAM 的局限性是由错误地扰动变体参数引起的，这鼓励了对虚假特征的拟合。具体，在 OOD 问题中，不变特征和虚假特征都会激活。确保对 `θ_inv` 扰动的鲁棒性（即低锐度）有助于提取不变特征。然而，通过扰动 `θ_var`，低锐度 `\mathcal{L}(θ + ε*; x, y) - \mathcal{L}(θ; x, y)` 表示增强与标签信息相关的特征。因此，SAM 无法提取不变特征，因为它对虚假特征敏感，损害了 OOD 泛化结果。幸运的是，我们的 EVIL 可以通过过滤掉与分布噪声相关的变体参数来完美解决这个问题。因此，SAM 可以进一步用于增强提取不变特征的鲁棒性。其有效性和效率在第 4.5 节中证明。
