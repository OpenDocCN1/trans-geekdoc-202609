# 附录 D 反例函数 *f*

我们这里的目标是证明以下结论：

**命题 D.1.** *对于任何全递归函数 `h`，均不存在 `h ≻ f`。*

**证明思路。** 该论证背后的思想如下：假设存在一个全递归函数（例如 `h`）主于反例函数 `f`。那么，我们要在反例函数 `f` 中识别出一个增长快速的片段，使其无限次地超过 `h`。

我们该如何进行呢？我们使用准平凡机器。选取某个主于 `h` 的函数 `g`。我们将尝试在 `f` 的值的子集上“克隆”该函数 `g` —— 或者更好，我们将证明 `g` 的存在就像已经克隆在 `f` 中一样。我们为此使用了准平凡机器。

我们该如何进行呢？我们构造一个可计数的准平凡机族 `Q_n`，使得 `f` 在这些机器上的值给出：

```
f(c(n)) = g(n)
```

`c(n)` 是一个原始递归函数。由于根据构造，`g(n) > h(n)`，现在我们有 `g(c(n)) > h(n)`。

# 附录 E. BGS 类集

我们在这里需要 BGS 类（见 Baker *et al.*, 1975）多项式机器集：

```
<M_m, |x|^a + a>
```

其中我们将图灵机 `M_m` 耦合到一个由多项式 `|x|^a + a` 调节的时钟上，即它在对 `x` 的操作执行 `|x|^a + a` 步后停止 `M_m`，其中 `x` 是机器的二进制输入，`|x|` 是其位长。

BGS 类是由如描述的与时钟耦合的图灵机的递归枚举构造的（即另一个图灵机，它在伙伴机器运行了指定的步数次数后将其关闭）。

BGS 类具有以下属性：

- BGS 类中的每台机器都是多项式图灵机。（显然，根据构造即是如此。）
- 每一台多项式图灵机都有一个模拟它的 BGS 机器。

事实上，给定一个特定的多项式机器，将有*无限多个* BGS 机器模拟它。并且：

## 命题 E.1. BGS 类是递归的。

（这与所有多项式机器集甚至不是递归枚举的这一形成了对比。）

这里将使用更通用的机器-时钟耦合：

```
<M_m, |x|^{(a)} + f(a)) -> M_{c(m, |f|, a)}
```

它的哥德尔数由 `c(m, |f|, a)` 给出，根据 `s-mn` 定理它是原始递归的，且 `f` 至少直观上是递归的。

**备注 E.2.** 注意我们可以有一个 `c`，使得对于参数 `a, b`，如果 `a < b`，则 `c(... a ...) < c(... b ...)`。

它是 BGS 类的推广。它还满足：

- 上述描述的 BGS 类推广中的每台机器都是多项式图灵机。（显然，根据构造即是如此。）
- 每一台多项式图灵机都有一个广义 BGS 机器模拟它。

广义 BGS 类也是递归的。

## 附录 F. 示例

作为一个例子，回想 `P < NP` 由一个 `Π_2` 算术语句给出，它是形式为“每个 `x` 都存在一个 `y` 使得 `P(x,y)`”的句子，其中 `P(x,y)` 是原始递归的。对于包含足够算术的理论 `S`，`S` 证明一个 `Π_2` 句子 `ξ` 当仅当相关的 Skolem 函数 `f_ξ` 被 `S` 证明为全递归的。对于 `P < NP`，Skolem 函数就是我们一直称的反例函数。

**备注 F.1.** 然而，我们可以制造出无限多个反例函数。为什么会这样？对于许多充分且合理的理论 `S`，我们可以构建一个递归的（可计算的）*函数序列* $^{14}$ `f_0, f_1, ..., f_k, ...`，具有一个无限的 `S`-可证明全递归函数集合，使得 `f_0` 被 `f_1` 主，`f_1` 被 `f_2` 主，`...` ，以此类推。

对于每个函数 `f_k`，我们可以形成一个类 BGS 的集 `BGS^k`，其中时间多项式图灵机中的时钟被一个多项式限制：

```
|x|^{f_k(n)} + f_k(n)
```

其中 `|x|` 表示机器的二进制输入 `x` 的长度。我们可以考虑递归集：

```
\bigcup_{k} BGS^k
```

所有此类集的集合。每个 `BGS^k` 包含所有多项式机器（时间多项式图灵机）的代表。现在，如果不存在这样的 `g`，但存在主于每个 `f_k` 的函数 `g_k`，而序列 `g_0, g_1, ...` 在 `S` 中无界（即增长方式如 `S` 中的序列 `F_0, F_1, ...` 一样），会怎样。

$^{14}$这样的“函数序列”存在且可以被显式构造。

## 奇异 BGS^F 机器

现在令 `F` 为一个快速增长的直观全算法函数。我们考虑已经描述的奇异 BGS^F 机器，即由对对 `(m, a)` 编码的多项式机器，它们编码了具有边界 `|x|^{F(a)} + F(a)` 的图灵机 `M_m`。由于边界时钟也是一个图灵机，现在与 `M_m` 耦合，存在一个原始递归映射 `c`，使得：

```
M_{m, |x|^{F(a)} + F(a)} -> M_{c(m,|F(a)|)}
```

其中 `M_{c(m,|F(a)|)}` 是所有图灵机序列中的一个多项式机器。我们以同样的方式得到一个 `g`，并得出结论。

**证明。** 在 D.1 中，使用哥德尔编码原始递归函数 `c` 给出证明中使用的准平凡机的哥德尔数。
