
# 术语表

## P

**packet filtering firewall**

: 配置了数据包过滤规则的防火墙，根据源地址、目的地址或端口号等因素允许或拒绝客户端访问。

**packet sniffing attacks**

: 一种网络攻击，攻击者使用数据包嗅探器监听网络流量，寻找以明文模式跨网络发送的密码、用户名等项目，或信用卡等敏感财务信息。

**pairing process**

: 将两个蓝牙设备连接在一起的过程。

**panning**

: 使摄像头左右平移、上下倾斜或俯仰的过程。

**passive controls**

: 到位但不根据任何操作进行调整的控制措施。

**passive infrared (PIR) detector**

: 使用传感器外壳中的透镜机制，检测传感器覆盖的水平扇区内红外能量任何变化的探测器。这种探测器对静止物体不敏感，但会对视野内横向发生的快速变化做出反应。

**passive RFID tags**

: 由 RFID 读取器发射的电磁能量供电并允许进行认证的标签。

**passphrase**

: 用于控制访问的一系列文字，很像密码，但通常字符长度更长。

**password**

: 用作认证工具的秘密单词或随机字符串。

**password attacks**

: 任何在最初不知道正确密码的情况下，通过密码提示成功认证的密码尝试。

**Password Authentication Protocol (PAP)**

: 一种与 PPP 配合使用的认证协议，利用密码进行验证。

**password capturing**

: 一种在密码传输认证时查看并保存（捕获）密码的技术。

**password cracking**

: 为日后使用而尝试从存储的数据或传输中的数据恢复密码的过程。

**password encryption**

: 获取标准密码并对其应用算法，使其对嗅探器、破解者或其他窃听者变得无意义的过程。

**password management policy**

: 为管理网络环境中用户密码而制定的策略。

**password manager**

: 存储和组织用户密码的软件应用程序。

**password-authenticated key agreement (PAKE)**

: 一种交互式方法，允许两个或多个实体基于一方对密码的知识建立加密密钥。

**patches**

: 已发布分发的操作系统或应用程序的通用改进。许多补丁和更新纯粹是外观改进和便捷的附加功能，而其他则是针对特定病毒、发现的威胁或弱点而设计的关键安全升级。

**PathPing**

: 许多 Windows 系统中自带的一个实用程序，结合了 `ping` 和 `traceroute` 命令行工具。

**penetration test**

: 以发现安全弱点为目标对网络进行测试的过程。

**permissions**

: 对特定数据和资产的定义特权和授权。

**persistent cookie**

: 将保留在计算机硬盘上直到达到指定过期日期的 Cookie。也称为永久 Cookie。

**personal area network (PAN)**

: 一种结合 PDA、手机、数码相机、PC、笔记本电脑和打印机等个人设备的网络类型。

**pharming**

: 一种恶意活动，将不知情的用户重定向到伪造网站，以期获取个人信息。

**phishing**

: 一种社会工程学技术，通过伪装成可信组织来获取敏感信息（通常是登录凭证或信用卡数据）。这些攻击通常涉及引导用户访问看起来合法的虚假网站的电子邮件。

**photoelectric sensor**

: 一种检测可见或不可见光束并对接收光强度变化做出反应的光学控制装置。光电束装置利用此功能，将窄光束瞄准感兴趣区域（如停车场闸口）。当光束被中断时，光电装置会发出警报，或者在车库门安全系统的情况下，停止或反转自动车库门的升降电机。

**physical intrusion detection system**

: 旨在检测并发出入侵信号的任何系统，包括运动传感器、读卡器、摄像头和警报器。

**physical security**

: 关注保护物理边界和财产的任何过程或设备。

**piconet**

: 由最多八个设备组成的小型蓝牙网络。

**PII**

: 个人身份信息 (PII) 是任何能够识别个人身份的信息。PII 示例包括名和姓、家庭住址、社会安全号码、出生日期、指纹以及其他可将一个个体与另一个个体区分开的信息。

**piggybacking**

: 社会工程师要求目标“帮忙开门/刷卡”，从而在无需提供凭证的情况下进入受限区域的行为。

**ping**

: 用于评估能否到达另一个 IP 主机的网络实用程序。`ping` 实用程序将向目标主机发送互联网控制消息协议 (ICMP) 请求数据包并等待响应，测量往返时间和任何数据包丢失。

**ping flood attack**

: 一种简单的 DoS 攻击，攻击者用 ICMP 回显请求（ping）数据包淹没受害者。

**pinhole lens**

: 一个非常小的孔，可能由针制成，将光线强制成平行线以形成清晰图像的透镜。

**point-of-sale (POS) terminals**

: 用于零售交易发生的时间和地点的智能联网终端。

**policies**

: 个人或企业采用的规则和程序。

**port scan**

: 探测或扫描服务器、客户端或主机以查找开放端口的过程。

**port scanner**

: 一种对网络设备进行探测以查找开放端口的软件应用程序。

**port-based VLAN**

: 以太网交换机上被定义为网段的一系列端口。

**PoSeidon Portable Operating System Interface (POSIX)**

: 为标准化 UNIX 和类 UNIX 操作系统的变体而开发的一组互操作性标准。符合 POSIX 标准的系统（UNIX、Linux 和 Apple macOS 系统）支持某种类型的 ACL，用于管理传统的 UNIX 文件访问权限。

**power line carrier (PLC)**

: 利用电力线作为主电力公司、其变电站和智能电表之间传输介质的通信。

**Power over Ethernet (PoE)**

: 这是通过 UTP 网线获取电力的过程，而非来自专用电源。这用于智能设备，如 VoIP 电话。

**Presentation zone**

: 在分区安全模型中，Presentation zone（呈现区/展示区）是将 Application zone（应用区）与最外层安全层（通常是互联网）分隔开的区域，也是组织用户网段所在的位置。Presentation zone 还用于放置公共接口，例如提供公共信息的 Web 服务器，以及组织的传输安全工具和结构。

**Pretty Good Privacy (PGP)**

: 一种广泛使用的 UNIX 加密工具。该工具同时执行私钥和公钥加密/解密，并提供一种非常强大的数据保护方法。

**pretexting**

: 一种社会工程学形式，指伪装成他人以获取私人信息的做法。

**promiscuous mode**

: 一种用于监听介质上传输流量的模式。它是非混杂模式的对立面。

**Privacy Rule**

: 旨在限制个人受保护健康信息可被使用或披露的情形的规则。

**Private Encrypted File System (PEFS)**

: 用于 UNIX 的堆叠加密文件系统。

**private key**

: 在密码学中，仅指定接收者知道的加密/解密密钥。

**Private VLAN (PVLAN) attacks**

: 一种网络攻击，涉及攻击者向 PVLAN 发送数据包，这些数据包包含目标计算机的目标 IP 地址和 PVLAN 路由器的 MAC 地址。交换机看到目标 MAC 地址，并将数据包转发到路由器的交换机端口（一种可以与任何端口通信的混杂端口类型）。路由器随即将数据包导向目标主机。

**privilege escalation**

: 利用漏洞使未经身份验证的用户获得提升的管理访问权限的行为。

**privilege management**

: 通过权限管理策略，为管理员提供关于如何实施组织权限的指导方针。访问控制权限可以基于角色（RBAC）、自主（DAC）或强制（MAC）。

**procedures**

: 执行操作的既定方式，常用于强制执行策略。

**process hazard analysis (PHA)**

: 用于评估特定工业过程中潜在危害。在美国，PHA 分析由职业安全与健康管理局（OSHA）强制要求，旨在协助潜在危险过程操作员确定和排序其过程的操作风险。

**process variable (PV)**

: 在过程中受控的动态变量。

**profile-based anomaly detection systems**

: 使用数学算法监控正常数据流量并开发一组规则配置文件，描述该系统正常流量的样子的系统。开发的配置文件反映了对用户过去行为的评估，并配置为在偏离这些行为达到一定水平（或阈值）时发出信号。

**programmable logic controller (PLC)**

: 可编程逻辑控制器（PLC）是专门设计用于执行工业控制功能的智能数字计算设备，例如开启和关闭阀门、开关和继电器以控制过程。

**programmable zones**

: 可编程以包含单个保护点（如运动探测器）的区域，或者可将多个点组合到单个区域中。

**promiscuous port**

: 配置为能够与任何其他端口通信的端口，通常在 VLAN 实例中。

**proportional control**

: 一种提供更精细控制方法的控制方案，其中输出本质上是模拟的，因此可以从最小值变化到最大值。控制器提供的输出水平基于 PV 与设定点之间的比例差异。

**proportional plus integral (PI) controller**

: 一种将比例控制应用于设定点值与测量过程变量值之差的控制方案。每种控制模式都可以调整，以向输出添加恰到好处的各模式水平。

**proportional plus integral plus derivative (PID)**

: 一种处理三个不同参数的控制器，分别代表当前误差、过去误差的累积以及对未来误差的预测。

**protocols**

: 一组管理网络通信如何进行的规则。为了使设备能够在网络上相互通信，它们必须都使用相同的网络协议。

**proxy filtering firewalls**

: 配置为过滤掉不需要的数据包的服务器。在此过滤过程中，每个数据包都会被拆解、评估并重组，使这种连接类型比其他防火墙类型慢得多。

**proxy server**

: 一种充当屏障的服务器，因为它允许客户端建立通过代理路由的间接网络连接。

**psychological social engineering**

: 攻击者利用心理学和人性弱点设计多种不同攻击，诱使人们相信其希望他们相信的内容，并放弃平时不会透露的重要信息的过程。

**public key**

: 一种可被获取并用于允许任何人加密发送给特定用户消息的加密密钥。

**public key certificates**

: 验证加密消息发送者即其声称身份的数字凭证。

**public key encryption (PKE)**

: 一种采用两个密钥确保加密数据安全的加密技术——公钥和私钥。公钥（人尽皆知）用于加密数据，私钥或密钥（仅指定接收者知晓）用于解密。

**public key infrastructure (PKI)**

: 一种支持公钥和证书分发的基础设施，旨在基于 CA 的信息实现可信连接和安全数据交换。

**public switched telephone network (PSTN)**

: 一种使用物理线缆互连并在发送方和接收方之间传输话级信号的系统。也称为普通老式电话系统（POTS）。

## Q

**quality of service (QoS)**

: 允许根据特殊规则或策略对网络流量进行优先级划分和差别化处理。QoS 的常见用途是确保 VoIP 电话系统始终拥有足够的带宽用于电话服务，无论网络多么繁忙。

**quid pro quo**

: 一句拉丁语，意为“以物易物”或“交换条件”。

## R

**race condition**

: 当攻击者利用多用户/多任务环境中连续事件的时序，在事件之间插入恶意代码到系统中时，就存在**竞争条件**。

**radio frequency identification (RFID)**

: RFID 系统利用自供电的 RFID 标签，可用作信标来追踪位置或验证邻近性。

**rainbow tables**

: 包含数百万个哈希密码的预生成表，用于通过比对来破解用户账户的密码。

**reconnaissance**

: 黑客熟悉目标并开始寻找潜在途径进入目标关键基础设施的第一步，无论是手动还是数字化方式。黑客通常会花费更多时间对目标进行**侦察**和研究，而不是实际利用漏洞。

**red team**

: 就渗透测试而言，这是一个独立小组，负责对指定组织的网络发起挑战或进行测试。

**reflection servers**

: 用于 DDoS 攻击，发送伪造的回显请求，并将回显应答指向受害者。

**regress**

: 就安全而言，该术语用于描述重新进入财产的合法权利。

**relay**

: 一种机电开关设备，用于控制电路的运行。

**remote access control**

: 一种设计特性，要求对试图从远程位置访问安全区域或计算机系统的用户身份进行认证。

**remote access monitoring**

: 当事件或事故发生时，用于通知监督安全人员的系统。

**remote access trojan (RAT)**

: 一种恶意软件程序，为系统提供后门，并可从远程位置授予管理控制权。

**Remote Authentication Dial In User Service (RADIUS)**

: 一种网络协议，提供集中式 AAA 协议（认证、授权和审计）。

**remote monitoring**

: 从远程位置或控制室对设备进行监控或测量。

**remote notification systems**

: 当存在报警条件时，这组系统将协调并通知相关方。

**remote telemetry unit (RTU)**

: 部署在流程或一组流程中的选定位置的小型智能控制单元，用于从不同传感器收集数据并发送命令以控制继电器输出。

**repeater**

: 一种网络硬件设备，用于扩展网络的范围和覆盖距离。

**replay attack**

: 一种网络攻击，攻击者重放或延迟已记录的传输以获取访问权限。

**rerouting attack**

: 一种网络攻击，试图将流量从其有效目的地重定向（重新路由）到一个虚假目的地。

**reverse proxy server**

: 一种处理 Web 资源公共请求，然后将其转发给一个或多个服务器的服务器。

**right**

: 由公认的权威来源授予某人或某群体的合法特权或许可。

**risk**

: 价值对象遭受损失的可能性。也可表示为与不确定性的故意交互。**风险**也可计算为一种可向组织内部和外部利益相关者传达的量化指标。

**risk assessment**

: 一个系统性过程，包括了解风险事件在组织网络不同领域发生的可能性及其造成的影响。

**risk mitigation**

: 采取必要步骤，降低风险敞口的程度和/或其发生的可能性。

**risk tolerance level**

: 个人或企业认为可容忍的风险水平。

**role-based access control (RBAC)**

: 一种使用工作角色来区分权限和特权的访问控制方法。

**rootkits**

: 一种旨在在不被检测到的情况下获取计算机系统管理控制权的软件类型。Rootkit 可能存在于硬件或软件中，通过攻击 BIOS、引导加载程序、操作系统内核，有时还包括应用程序或库来实现。

**router flood attacks**

: 路由器容易受到洪水攻击，此类攻击旨在耗尽其所有或大部分资源，从而使其失去功能。

**routers**

: 网络连接设备，与交换机不同，可跨不同网段转发信息。这使路由器能够通过称为路由的过程将不同网络连接在一起。

**routing**

: 选择在网络上或网络之间传输数据的最佳路径的过程。

**routing protocol**

: 路由器用于确定数据传输的适当路径的一组规则。

**routing table**

: 路由器用于存储和更新路由信息的数据库。

**RS-232 asynchronous serial communication standard**

: 一种用于串行通信传输数据的标准。

**rule**

: 在网络中，要移动数据包通过设备，必须在设备上显式创建一条规则，以将所需的协议端口转发（或映射）到局域网中的专用 IP 地址和端口。

**rule-sets**

: 通常基于数据源和目标信息、数据类型或数据内容的规则。它们用于控制何种类型的信息可以在安全区域之间移动。

**rule-based access control (RBAC)**

: 一种基于规则的访问控制模型，规则根据账户持有者在组织中的角色分配给账户。规则是角色的基本要素。规则定义角色可以执行的操作。也称为自动化配置。

**rule-based anomaly detection**

: 一种检测方法，通过分析审计记录根据过去的使用模式生成规则。系统随后监控流量，寻找与创建的规则不匹配的模式。

## S

**safety instrumented system (SIS)**
