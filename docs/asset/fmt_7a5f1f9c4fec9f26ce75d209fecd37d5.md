
在数学上定义向量空间之前，让我们先理解笛卡尔积运算符（`×`）和映射运算符（`→`）。两个集合 `A` 和 `B` 的笛卡尔积，记为 `A × B`，是所有有序对 `(a, b)` 的集合，其中 `a ∈ A` 且 `b ∈ B`。在 `A` 和 `B` 上定义笛卡尔积的另一种方式是 `A × B = {(a, b) | a ∈ A and b ∈ B}`。映射运算符将一个集合的每个元素映射到另一个集合 `b` 的一个元素，记为 `A → B`。

## 向量空间

向量空间是指在实数或复数域上（记为 `𝔽`，`= ℝ` 表示实数，`= ℂ` 表示复数）的一个向量集合 `V`，连同加法和标量乘法两种运算，满足八条公理。让我们正式定义向量上的加法和标量运算：

*   **加法或向量加法（加法封闭性）**：定义为 `+ : V × V → V`，输入任意两个向量 `v ∈ V` 和 `w ∈ V`（向量用小写粗体字母表示，如 `u` 或带箭头的小写字母如 `u→`），输出第三个向量 `u ∈ V`，记为 `u = v + w`，其中 `u` 称为向量 `v` 与 `w` 的和。

*   **标量乘法（标量乘法封闭性）**：定义为 `⋅ : 𝔽 × V → V`，取任意标量 `a ∈ 𝔽` 和任意向量 `v ∈ V`，输出向量 `u = a v`，其中 `u ∈ V`。

让我们讨论加法和标量乘法运算必须遵循的八条公理。考虑向量 `u, v, w ∈ V` 和标量 `a, b ∈ 𝔽`：

*   **加法结合性**：`(u + v) + w = u + (v + w)`

*   **加法交换性**：`u + v = v + u`

*   **加法单位向量**：`∃ o ∈ V`（称为零向量），使得 `v + o = v`，`∀ v ∈ V`

*   **加法逆向量**：`∀ v ∈ V, ∃ –v ∈ V`（称为加法逆元），使得 `v + (–v) = o`，其中 `o` 是加法的单位元

*   **标量与域乘法的相容性**：`a(b v) = (ab) v`，`∀ a, b ∈ 𝔽, ∀ v ∈ V`

*   **标量乘法单位元**：`1 v = v`，其中 `1` 表示 `𝔽` 中的乘法单位元

*   **标量乘法对向量加法的分配性**：`a(u + v) = a u + a v`，`∀ a ∈ 𝔽, ∀ u, v ∈ V`

*   **标量乘法对标量（域）加法的分配性**：`(a + b)u = a u + b u`，`∀ a, b ∈ 𝔽, ∀ u ∈ V`

> **注意：** 标量乘法不应与标量积（也称为内积或点积）混淆。

**欧几里得空间 `ℝⁿ` 的例子是向量空间**：考虑欧几里得空间中的 `u = (a₁, a₂, …, aₙ) ∈ ℝⁿ` 和 `v = (b₁, b₂, …, bₙ) ∈ ℝⁿ`，其中加法定义为 `u + v = (a₁ + b₁, a₂ + b₂, …, aₙ + bₙ)`，标量乘法对于 `s ∈ 𝔽` 定义为 `s u = (s a₁, s a₂, …, s aₙ)`。这两种运算满足加法和标量乘法的封闭性。它们也满足八条公理，零向量 `o = (0, 0, …, 0)`，加法逆元 `–u = (–a₁, –a₂, …, –aₙ)`。因此，`ℝⁿ` 欧几里得空间是向量空间。

**实数的例子**：实数集合，`a ∈ ℝ`，具有标准的乘法和加法。零向量将是 `o = 0`，加法逆元将是 `–a`。

**矩阵的例子**：所有矩阵 `A[m×n]` 的集合形成向量空间，其中矩阵的加法和标量乘法定义见“基本矩阵运算”节。每个 `A[m×n]` 都被视为该向量空间中的一个向量。验证这两种运算是否满足所有八条公理。

**l¹ 序列空间的例子**：l¹ 序列空间被定义为所有其级数绝对收敛的序列的集合，即 `∑|xₙ| < ∞`。两个序列的加法是对应元素的逐元素相加，标量乘法是逐元素乘以一个标量。l¹ 序列空间是一个向量空间，其中每个序列是一个向量。绝对收敛级数的加法是收敛的，收敛级数的标量乘法仍然是收敛的。验证这些运算是否满足所有八条公理留给读者。这个向量空间不是有限维空间。序列的范数可以定义为有限和 `∑|xₙ|`，由于绝对收敛，这总是有限的。因此，l¹ 序列空间是一个无限维赋范线性空间。该空间的无限基集合是所有无限序列 `e⁽ⁱ⁾` 的集合，其第 `i` 个元素为 1，所有其他元素为 0。这类似于 `ℝⁿ` 标准基的推广。

**例子**：所有实系数多项式的集合形成一个无限维向量空间，其中每个多项式是一个向量。该向量空间的基是只有一项的多项式集合：`xⁿ : n = 0, 1, 2, …`。每个多项式都可以表示为该基集合中多项式的有限线性组合。

**例子**：L²[a, b]：区间 `[a, b]` 上所有平方可积实值函数的集合，即函数集合 `f : [a, b] → ℝ`，使得 `∫|f(x)|² dx < ∞`，形成一个向量空间。这个函数集合形成一个向量空间。我们定义函数 `f` 和 `g` 的加法为平方可积函数 `h = f + g`，其中 `h(x) = f(x) + g(x)`，函数的标量乘法定义为 `c f(x)`。

向量空间定义了向量加法和标量乘法，但未定义向量的长度、向量间的距离或向量间的角度。为了赋予向量间这些参数以意义，需要在向量空间上定义额外的结构，如范数向量空间和内积空间。

## 范数向量空间

范数向量空间是定义了范数的向量空间。范数表示向量的“长度”，该向量可以是矩阵、函数或序列等任意抽象对象。我们已经在欧几里得空间中定义了称为欧几里得范数的范数。现在，让我们将该概念推广到任意向量空间。向量的**范数**记为 `‖v‖`，必须具有以下性质：

*   非负性：∀ `v ∈ V`，`‖v‖ ≥ 0`

*   非零向量的正范数值：`‖v‖ = 0 ⇔ v = o`，其中 `o` 是向量空间中的加法单位元（零向量）

*   齐次性：`‖αv‖ = |α| ‖v‖`

*   **三角不等式成立**：`‖u + v‖ ≤ ‖u‖ + ‖v‖`

*   范数的性质

*   平行四边形定律

```
‖u + v‖² + ‖u - v‖² = 2(‖u‖² + ‖v‖²)
```

范数可以通过以下方式转化为距离度量：

```
d(u, v) = ‖u - v‖
```

这称为**由范数诱导的度量**。一般来说，距离度量定义为一个函数，接受两个向量并输出它们之间的距离。两点间的距离必须始终非负。从 `a` 到 `b` 的距离应与从 `b` 到 `a` 的距离相同；这称为距离的对称性。距离的另一个重要性质是三角不等式，即如果有三个向量 `u`、`v`、`w`，则由这些向量形成的三角形中，任意两边距离之和必须大于第三边。我们可以用范数表示这些性质如下：

*   `‖u – v‖ ≥ 0`

*   `‖u – v‖ = 0` 当且仅当 `u = v`

*   对称性：`‖u – v‖ = ‖(–1)(v – u)‖ = ‖v – u‖`

*   三角不等式：`‖u – v‖ ≤ ‖u – w‖ + ‖w – v‖`

## 实数的范数

实数集合也构成一个平凡的向量空间。实数的范数可定义如下。该定义是否遵循范数的全部四条性质？验证任务留给读者作为练习。

```
‖x‖ = |x|
```

欧几里得空间是赋予了欧几里得范数的范数线性空间。欧几里得空间中还定义了其他称为 `l^p` 范数的范数。

## `l^p` 范数

向量 `x = (x₁, x₂, ..., xₙ)` 的 `l^p` 范数定义为：

```
‖x‖_p = (|x₁|^p + |x₂|^p + ... + |xₙ|^p)^(1/p)
```

其中 `p ∈ ℝ` 且 `p ≥ 1`。

当 `p=1` 时，这简化为：

```
‖x‖_1 = |x₁| + |x₂| + ... + |xₙ|
```

任何范数均可用于定义两向量间的距离，因为范数引入了由 `d(u,v) = ‖u – v‖` 给出的距离度量。

`l¹` 范数引入了**曼哈顿距离**。

```
d(u, v) = ‖u - v‖_1 = Σ|u_i - v_i|
```

曼哈顿城市的街道呈网格布局。从一点移动到另一点，必须沿这些形成网格的道路行驶。在仅能按网格格式移动的情况下，计算点之间距离称为**曼哈顿距离**。

## 最大范数

当 `p → ∞` 时，`l^p` 范数提供向量 `u` 的 `l^∞` 范数或**最大范数**，定义如下：

```
‖u‖_∞ = max(|u₁|, |u₂|, ..., |uₙ|)
```

请验证 `l^p` 范数是否遵循范数定义的全部四条性质。

> **注意：向量 `u = (a₁, a₂, …, aₙ)` 与 `v = (b₁, b₂, …, bₙ)` 之间的闵可夫斯基距离定义为 `p ∈ ℤ`（整数）时如下。对于 `p ≥ 1`，其公式与 `p` 范数相同。**
>
> ```
> dist(u,v) = (|a₁ – b₁|^p + |a₂ – b₂|^p + … + |aₙ – bₙ|^p)^(1/p)
> ```
>
> 对于 `p ≥ 1`，它满足距离度量的全部四条性质。当 `p < 1` 时，它在三角不等式性质上失效。
>
> ```
> dist((0,0), (1,1)) > dist((0,0), (0,1)) + dist((0,1), (1,1))
> ```

设序列空间记为 `l^p`，该集合定义为：

```
l^p = { (x₁, x₂, ...) | Σ|x_i|^p < ∞ }
```

对于 `1 ≤ p ≤ ∞` 的范数，可通过将 `p` 次幂项的有限和扩展为 `p` 次幂级数的无限和，在 `l^p` 序列空间上定义。因此，**序列空间 `l^p` 是一个范数线性空间**，其中范数 `‖⋅‖_p` 定义为：

```
‖x‖_p = (Σ|x_i|^p)^(1/p)
```

类似地，对于函数空间 `L^p`，函数 `f ∈ L^p` 的范数 `‖⋅‖_p` 定义为：

```
‖f‖_p = (∫|f(x)|^p dx)^(1/p)
```

## 矩阵范数

由于矩阵也可视为向量空间中的向量，因此也为矩阵定义了范数。存在各种矩阵范数，其中我们将讨论重要的矩阵范数。

类似于向量的 `L^p` 范数，可为矩阵定义 `L[p,q]` 范数。矩阵 `A[m×n]` 的 `L[p,q]` **范数** 定义如下：

```
‖A‖_{p,q} = (Σ_j (Σ_i |a_ij|^p)^(q/p))^(1/q)
```

**弗罗贝尼乌斯范数**：在矩阵范数 `‖A‖_{p,q}` 中取 `p = q = 2`，可得 `L[2,2]` **范数**，也称为**弗罗贝尼乌斯范数**或**希尔伯特-施密特范数**。

```
‖A‖_F = (Σ_i Σ_j |a_ij|²)^(1/2)
```

**示例**：图像可表示为像素值矩阵。我们可以使用弗罗贝尼乌斯范数比较两幅图像的接近程度。

***范数球***：正如欧几里得范数使用欧几里得球定义点的邻域，抽象向量空间中的任意范数均可定义范数球：

```
B(v, r) = { u ∈ V | ‖u - v‖ < r }
```

因此，在函数空间 `L^p` 中，我们将函数 `f` 的邻域定义为：

```
B(f, ε) = { h ∈ L^p | ‖h - f‖_p < ε }
```

即紧密逼近函数 `f` 的所有函数 `h` 的集合。

范数定义了向量的长度、向量间的距离及距离的少数性质，但未定义抽象向量间的角度。让我们讨论提供向量空间中向量间角度意义的内积空间。

## 内积

内积是欧几里得空间中点积概念的推广，记为 `⟨u, v⟩`，并对 `u, v ∈ V` 满足四条性质：

*   分配律：`⟨u + v, w⟩ = ⟨u, w⟩ + ⟨v, w⟩`

*   线性性：`⟨αu, v⟩ = α⟨u, v⟩`

*   对称性或交换律：`⟨u, v⟩ = ⟨v, u⟩`

*   **正定性**：若 `o` 是向量空间 `V` 中加法的单位元，则 `⟨v, v⟩ = 0` 当且仅当 `v = o`，否则 `⟨v, v⟩ > 0`

内积自然诱导出向量 `u ∈ V` 的关联范数（长度），定义为 `‖u‖ = √⟨u, u⟩`。若范数由内积引入，则该范数线性空间称为**内积空间**。有了范数的定义，可定义向量 `u, v ∈ V` 间的距离为 `distance(u, v) = ‖u – v‖`。此外，内积空间中范数定义还导出以下性质：

*   柯西-施瓦茨不等式

    ```
    |⟨u, v⟩| ≤ ‖u‖ ‖v‖
    ```

*   正交性：若 `⟨u, v⟩ = 0`，则两向量 `u, v ∈ V` 正交。几何上，正交即垂直。

*   勾股定理

    ```
    ‖u + v‖² = ‖u‖² + ‖v‖²  (当 u, v 正交时)
    ```

**欧几里得空间 `ℝⁿ` 的示例**：考虑 `u = (a₁, a₂, …, aₙ) ∈ ℝⁿ` 与 `v = (b₁, b₂, …, bₙ) ∈ ℝⁿ`，其中点积定义为 `u ⋅ v = a₁b₁ + a₂b₂ + … + aₙbₙ`。可验证点积满足内积映射的全部四条性质。因此，`ℝⁿ` 欧几里得空间以点积为内积构成内积向量空间；`⟨u, v⟩ = u ⋅ v`。

**实数示例**：实数集合 `a, b ∈ ℝ` 以标准乘法为内积 `⟨a, b⟩ = a * b`。

## 实际数据集上的应用

Roland Fisher 在 1938 年发表的论文中发布了一个数据集，包含三种鸢尾花各 50 个样本。每个花样本测量了四个特征（单位：厘米）：萼片长度、萼片宽度、花瓣长度、花瓣宽度。我们使用 TensorFlow 框架将花卉数据表示为向量；setosa、virginica 和 versicolor 分别代表标签 0、1 和 2。因为每朵花由四个特征表示，所以代表花的向量属于 `ℝ⁴`。以下代码提供了加载鸢尾花数据的步骤。随后将数据集中的少量样本复制到 TensorFlow 数组中以供进一步分析。

```
import tensorflow as tf
import tensorflow_datasets as tfds
import numpy as np
iris_ds = tfds.load('iris', split='train')  # load Iris dataset
SAMPLE_SIZE = 6   # consider few samples from the dataset
iris_ex = iris_ds.take(SAMPLE_SIZE)   # consider first few samples from the dataset
# Tensor array to store dataset samples
tf_arr = tf.TensorArray(tf.float32, size=0, dynamic_size=True, clear_after_read=False)
index = 0
for sample in iris_ex:
    feat = sample["features"]
    label = sample["label"]
    tf_arr = tf_arr.write(index, feat)  # Add sample to array
    index = index + 1
    vec_norm = tf.norm(feat)  # Calculate norm of the vector
    tf.print("label=", label, ' vector v', index, '=', feat, " Euclidean Norm=", vec_norm, sep="")
```

for ref_index in range(0, SAMPLE_SIZE):

        vec_sub = tf.math.subtract(vec_ref, vec)
