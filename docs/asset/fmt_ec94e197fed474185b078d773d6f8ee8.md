
```
min_G max_D J(G,D) := E_{p_r(x)}[ln D(x)] + E_{p_z(z)}[ln(1 - D(G(z)))].
```

(19.12)

根据期望的定义，我们可以写成

### GAN 目标函数推导

$$J(G, D) = \int_{\mathbf{x}} p_r(\mathbf{x})\ln(D(\mathbf{x}))d\mathbf{x} + \int_{\mathbf{z}} p_{\mathbf{z}}(\mathbf{z})\ln(1-D(G(\mathbf{z})))d\mathbf{z} = \int_{\mathbf{x}} (p_r(\mathbf{x})\ln(D(\mathbf{x})) + p_g(\mathbf{x})\ln(1-D(\mathbf{x})))d\mathbf{x}$$

![Equation](img/si83.png)

其中下标 $g$ 代表与**生成器**输出相关的分布。固定函数 $G$（等价于固定概率分布函数 $p_g$），通过对被积函数关于函数 $D$ 求导并令其等于零，可以很容易地推导出判别器输出概率函数 $D$ 的最优值（问题 19.3）。很容易证明：

$$D^* = \frac{p_r}{p_r + p_g}$$

![Equation](img/si85.png) (19.13)

因此，将上述最优值代入公式 (19.12)，极大极小博弈中关于 $G$ 的代价函数被重新表述为

$C(G): = \mathbb{E}_{p_{r}(\mathbf{x})}\ \left\lbrack \ln\frac{p_{r}(\mathbf{x})}{p_{r}(\mathbf{x}) + p_{g}(\mathbf{x})} \right\rbrack + \mathbb{E}_{p_{g}(\mathbf{x})}\ \left\lbrack \ln\frac{p_{g}(\mathbf{x})}{p_{r}(\mathbf{x}) + p_{g}(\mathbf{x})} \right\rbrack,$

![Equation](img/si86.png)(19.14)

其中上式是 $p_{g}$ 的函数。回顾 KL 散度的定义（第 2.5.2 节和 12.7 节），公式 (19.14) 可紧凑地重写为

$C(G) = \text{KL}(p_{r}||p_{r} + p_{g}) + \text{KL}(p_{g}||p_{r} + p_{g}),$

![Equation](img/si87.png)

正如我们所知，KL 散度关于其参数*不对称*。除以 2 进行归一化，并考虑到 KL 散度的定义，上式可轻松重写为

$C(G) = - \ln 4 + \text{KL}\left( p_{r}||\frac{p_{r} + p_{g}}{2} \right) + \text{KL}\left( p_{g}||\frac{p_{r} + p_{g}}{2} \right),$

![Equation](img/si88.png)

或

$$C(G) = -\ln 4 + 2JS(p_r \| p_g)$$

其中 $JS$ 表示 $p_r$ 和 $p_g$ 之间的 **Jensen-Shannon 散度**，定义如下：

因此，如公式 (19.15) 所示，与生成器相关的成本 $C(G)$ 取决于真实数据的 $p_r$ 与生成器实现的 $p_g$ 之间的 JS 散度。可以很容易地验证，与 KL 散度不同，JS 散度是对称的。正如文献 [180] 所推测的，正是使用了这种散度（而非 KL 散度），使得 GANs 相较于传统的基于最大似然的方法具有了优势。

可以很容易地看出，JS 散度是非负的，当且仅当 $p_r = p_g$ 时达到最小值。因此，公式 (19.12) 中定义的极大极小任务的解，在判别器 $D$ 由公式 (19.13) 给出、且生成器 $G$ 极小化公式 (19.15) 时得到：

换句话说，当生成器学会了真实数据的分布，而判别器 $D$ “困惑”且无法区分真假数据时，博弈达到最优。

#### GAN 训练中的问题

在前一小节中，已经确立了 GANs 的最优性。然而，问题远未解决。主要原因在于，最优性分析是在概率函数空间中进行的。但在实践中，我们使用参数化模型来近似上述目标，这正是问题产生的根源。事实上，正如 **算法 19.2** 所示，实践中优化是通过参数优化进行的，涉及的梯度通过反向传播计算，更新遵循某种基于梯度的优化方案。然而，并发更新生成器和判别器的参数以求解非凸优化任务，并不一定意味着该方案会收敛到最优博弈解。

观察公式 (19.15) 及其推导过程，人们会预期：将判别器训练至接近其最优（使得 $\boldsymbol{\theta}_g$ 上的成本函数能很好地近似公式 (19.15)），然后对 $\boldsymbol{\theta}_g$ 应用梯度步骤，是正确的做法。然而，实践中情况并非如此。随着判别器的改进，生成器的更新反而变差。文献 [6] 对这一现象给出了解释。这种“奇怪”行为的核心在于：$p_r$ 和 $p_g$ 的**参数化**近似位于低维流形上，这使得它们很难共享公共支撑集（输入空间中两个函数均取非零值的区域）。这在 **图 19.5** 中有所说明。结果，训练好的判别器并未达到公式 (19.15) 所述的成本，而是实现了零误差，即它能完美区分真假数据。这导致成本降为零，且关于 $\boldsymbol{\theta}_g$ 的梯度变得极其微小，使得通过 JS 成本训练 GANs 变得困难。训练时，必须决定判别器训练到何种程度。换言之，在训练中存在不准确性与梯度消失之间的权衡。

![图 19.5 在三维空间中，两条直线是低维（线性）流形。它们极不可能共享公共交点。因此，若 $p_r$ 限制在一条线上、$p_g$ 限制在另一条线上，这两个分布极不可能共享非微不足道的支撑集。](img/gr005.jpg)

**图 19.5** 在三维空间中，两条直线是低维（线性）流形。它们极不可能共享公共交点。因此，若 $p_r$ 限制在一条线上、$p_g$ 限制在另一条线上，这两个分布极不可能共享非微不足道的支撑集。

训练 GAN 相关的另一个问题是所谓的*模式崩塌*。这意味着虽然生成器可能会“欺骗”判别器，但生成器产生的是“相同”的输出。似乎生成器陷入了一个“微小”的区域，导致输出的多样性很低。这可能是因为生成器无法充分学习数据分布，它只关注其中的一部分，而忽略了其他部分。

为了规避上述缺陷，已经提出了许多技巧和方法（参见例如 [108,163,203]）。文献 [146] 引入了卷积生成网络。文献 [128] 采用最小二乘论据来设计 GAN。文献 [98] 中，判别器估计真实样本比生成样本更真实的概率，而不是估计其为真实样本的概率。文献 [118] 基于竞争性训练程序采用了模型组合的概念，该程序将数据分布分割为多个分量，这些分量可由独立的生成模型很好地逼近。

#### Wasserstein GAN

文献 [7] 通过所谓的分布间*Wasserstein 距离*，系统性地解决了在低维流形中匹配 `p_r` 和 `p_g` 的任务。首先证明了当在低维流形中学习分布时，衡量分布间差异的散度必须具有特定性质。JS 散度和 KL 散度都不具备这些性质。相反，Wasserstein 距离在此背景下是一个合适的度量。

两个分布 `p_r` 和 `p_g` 之间的 Wasserstein 距离，或称*土方距离*（EMD），定义为

```
W(p_r, p_g) = inf_{γ ∈ Π(p_r, p_g)} E_{(x,y) ~ γ} [||x - y||]
```

(19.16)

尽管上述定义对不熟悉的读者可能看起来有点复杂，但它非常讲得通；`Π(p_r, p_g)` 是*所有*联合分布的集合，这些联合分布针对随机向量，其边缘分布分别等于 `p_r` 和 `p_g`。直观上，期望值表示为了将 `p_r` 转换为 `p_g`，需要从 `x` 向 `y` 转移多少概率质量。它们的距离对应于所有可能的联合分布中的“最小”值。^(130)

在实践中，公式 (19.16) 不易直接实现。一种替代方法是通过其对偶公式，即 Kantorovich–Rubinstein 对偶性（例如 [190]），由下式给出：

```
W(p_r, p_g) = sup_{||f||_L < 1} { E_{p_r(x)}[f(x)] - E_{p_g(x)}[f(x)] }
```

(19.17)

其中 `||f||_L < 1` 表示所有 1-Lipschitz 函数（另见第 8.10.2 节），`f : X ↦ ℝ`，即

|*f*(**x**[1]) − *f*(**x**[2])| < ||**x**[1] − **x**[2]||, ∀**x**[1], **x**[2] ∈ 𝒳.

![Equation](img/si98.png)

因此，两个分布之间的瓦萨斯坦概率距离，以公式 (19.17) 的形式给出，即关于所有可能的 1-利普希茨函数，针对这两个分布，均值差异中的“最大值”。

根据公式 (19.17) 设计 GAN，使得该设置不同于围绕公式 (19.11) 中代价演变而来的设置。目标不再是设计一个二分类器（判别器）来区分真实数据与生成数据，而是设计一个利普希茨函数 *f*。后者通过一组参数 **θ**[*f*]![Equation](img/si99.png) 利用深度神经网络进行参数化，即 *f*(**x**; **θ**[*f*])![Equation](img/si100.png)。通过求解以下任务来估计相应参数：

```
\max\limits_{\mathbf{\theta}_{f}}\left\{ \mathbb{E}_{p_{r}(\mathbf{x})}\ \left\lbrack f(\mathbf{x};\mathbf{\theta}_{f}) \right\rbrack - \mathbb{E}_{p_{\mathbf{z}}(\mathbf{z})}\ \left\lbrack f(G(\mathbf{z};\mathbf{\theta}_{g});\mathbf{\theta}_{f}) \right\rbrack \right\}.
```

![Equation](img/si101.png)

固定参数 **θ**[*f*]![Equation](img/si99.png)，定义生成器的参数 **θ**[*g*]![Equation](img/si102.png) 通过最小化上述括号中的差值来估计。请注意，该梯度仅取决于第二项，因为第一项与 **θ**[*g*]![Equation](img/si102.png) 无关。随着训练过程中损失函数的降低，瓦萨斯坦距离变小，生成器的输出也越来越接近真实数据分布。瓦萨斯坦 GAN 方案概述见 **算法 19.3**。

##### 算法 19.3

**瓦萨斯坦 GAN 算法**

*   初始化 **θ***f*)![Equation](img/si103.png) 和 **θ***g*)![Equation](img/si64.png)。
*   将小批量大小设置为 *K*。
*   将函数参数 **θ**[*f*]![Equation](img/si99.png) 的迭代次数设置为 *m*。
*   设置裁剪参数 *c*；该参数负责处理利普希茨条件。通常，*c* = 0.01![Equation](img/si104.png)。

###### 算法流程

当 **θ**[*f*] 和 **θ**[*g*] 尚未收敛时，执行以下操作：

1.  **For** `t = 1, 2, …, m`，**Do**
    1.  从 `p_z(z)` 中采样 **z**^((*i*))，`i = 1, 2, …, K`。
    2.  从 `p_r(x)` 中采样 **x**^((*i*))，`i = 1, 2, …, K`。
    3.  计算梯度：
        ```
        ∇_{θ_f} { (1/K) ∑_{i=1}^K [ f(x^{(i)}; θ_f) - f(G(z^{(i)}; θ_g); θ_f) ] }
        ```
    4.  通过梯度**上升**方案更新 **θ**[*f*]：
        ```
        θ_f ← θ_f + η ∇_{θ_f} { ... }
        ```
    5.  将数值裁剪到区间 `[-c, c]` 内。
2.  **End For**
3.  从 `p_z(z)` 中采样 **z**^((*i*))，`i = 1, 2, …, K`。
4.  计算梯度。

##### 那么该用哪个算法

到目前为止，在我们关于 GAN 的讨论中，我们重点关注了两种可能的算法，并提供了许多其他替代方案的参考文献。Wasserstein GAN 帮助我们概述了学习分布（隐式或显式）任务中潜在的一些重要问题，在该任务中，学习过程最常发生在低维流形上。读者和任何从业者可能会想知道哪种算法是“最好”的，或者更适合用于实际应用。

与数据生成相关的主要问题之一是，能够通过评估生成模式的质量来测试生成器的性能。评估性能的主要问题在于无法显式计算分布 `pg`。因此，不能采用诸如似然函数之类的经典代价。在当前背景下，尝试在高维空间中对其进行近似似乎存在问题（例如，[92]）。为此，已提出了相关度量。

所谓的*初始分数*（IS）建立在这样一个概念之上：一个好的模型应该生成样本，当由独立的预训练分类器（通常是初始网络，见第 18.12.4 节）评估时，类别分布具有低熵。换句话说，给定一张生成的图像，它应该看像训练集中可用类别中的**有且仅有一个**类别。因此，分类器预测的类别概率应该在正确类别处急剧达到峰值。同时，生成的样本应表现出较大的变异性 [163]，并且应以相等的概率分布到所有类别中。

*Fréchet 初始距离*（FID）关注一种度量，该度量量化了通过初始网络在特征空间中进行特定嵌入后，真实数据样本与生成数据样本之间的差异 [76]。假设嵌入数据服从多元高斯分布，则通过相应高斯分布之间的 Fréchet 距离来量化这两个分布之间的距离 [46]。

文献 [121] 提出了关于各种 GAN 的比较实验研究。在那里的发现，使用包括前面提到的质量度量在内的多种度量，似乎并不支持任何一种提出的 GAN 优于其他 GAN。据报道，大多数模型在经过仔细的超参数调优、更高的计算预算和随机重启后，都能达到相似的分数。各种方法、算法和应用的综述见文献 [67] 等。
