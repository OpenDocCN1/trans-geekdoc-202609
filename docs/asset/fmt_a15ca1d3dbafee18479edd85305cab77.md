
# 1. Colony: Avalanche 上最佳 DeFi 项目

我们 DeFi 项目列表顶端是 Colony 项目。Colony 是第一个社区驱动的基金。该项目已经获得了 Avalanche 基金的支持和投资，因此它本质上是一个 Avalanche 项目。简单来说，Colony 是一组智能合约，为组织的本质功能提供框架。除了资金，该项目还涵盖了组织的所有权、结构和权限。

那么，如何开始？你首先需要代币。DeFi 应用（如 Colony）运行在带有原生代币的网络上。你可以通过交易所使用的代币代码识别这些代币。购买代币后，你需要将它们移动到你控制的支持 Colony 的钱包中。你将使用这些代币转移资金。尽管如此，你仍希望选择手续费最低的网络，因为移动资金会产生交易费用。

此外，要小心网络，确保你选择了正确的网络。做好研究以避免陷入诈骗。在网络上，你会遇到不同类型的服务，其中最流行的是去中心化交易所（DEX）。你也可以提供流动性以换取利息，或者贷款资金收取利息。可能性是无限的。

你只需要将与 DeFi 协议兼容的钱包连接到支持的网络并登录你的账户即可。

Colony 已与 Avalanche 建立了联系，并预计将共享交易机会，为在在该平台上构建项目奠定基础。该项目的主要特点是基于社区的。此外，它还包含一个监管框架，允许投资者熟悉 Avalanche 生态系统，从而通过新的市值刺激其增长。从项目开始，该项目就获得了一个初始社区。

此外，它将与 Avalanche 以及生态系统中的其他关键参与者合作。需要记住，Avalanche 的生态系统是为了 DeFi 开发的。Colony 项目将通过完全去中心化的交易所和民主化的金融世界帮助实现 Avalanche 的愿景。其中一个原因是，Colony 为 Avalanche 网络上的新型去中心化应用提供了一个激励基础。

虽然资金至关重要，但 Colony 的成功取决于营销、势头、技术专家和人脉网络。此外，Colony 会产生适当的维持和价值，因为其投资将通过空投、质押奖励和回购机制回馈社区。现在，Colony 有两个互补的支柱。第一个是评估此前机构及其投资者无法接触的早期交易。

Colony 的核心团队将执行该项目严格的投资流程，该团队由加密行业的专家组成。因此，这些股权专家将使用严格的分析报告审查并评估有潜力的项目。接下来，Colony 的投资公司网络将通过让 Avalanche 协议上的构建者做好市场准备来提高资金效率。

因此，一旦项目完成第一阶段，它将不必再担心筹集资金，而是专注于开发。第二个支柱是 DAO（去中心化自治组织）。其主要目标是深化 Avalanche 生态系统内的流动性，并使用质押来增强网络的健康安全。这一支柱还旨在通过专门的索引捕捉 Avalanche 增长的 DeFi 资产。

总体而言，Colony Bridge 接了 DeFi 和传统金融，通过其社区利用 Avalanche 网络上的价值创造。其初始索引发售（IDO）计划于 2021 年第四季度进行。因此，CryptoMint Capital 与 Colony Lab 建立了投资者合作伙伴关系。他们最近推文中提到：“Avalanche 生态系统正在增长，Colony Lab 为生态系统提供资金。”

# 2. Aave: 去中心化金融平台

Aave 是另一个去中心化金融平台，用户可以在那里借贷各种加密货币。该平台通过池实现的智能合约促进点对借贷。人们寻求出借加密货币以赚利息，或为了此进行借贷。Aave 构建在以太坊上。智能合约管理所有资产，用户依靠一系列算法和网络来运行。

你不再需要仅仅信任银行或金融机构来照顾你的资金。

## 特性

Aave 旨在让金融服务更易获得，这意味着你可以在没有银行、经纪监管的情况下进行借贷。总之，你正在投资拥有话语权的技术。目前，该平台有 26 种不同的加密货币可以存款以赚利息，25 种可以借贷。存款和借贷的一些选项包括 `ETH`、`LINK` 和 `LEND` 等。

值得知道，大多数加密都是像 `USDC` 这样的稳定币。在 Aave 网站上，你可以看到每种加密货币的借贷利率。本质上，Aave 使用算法根据利用率建立当前费率。例如，如果池中剩下的加密货币不多，利率就会高，这样更多人就可以存款加密货币。

另一方面，如果任何加密货币被利用，利率就会低，这样更多人就可以借贷。Aave 有两种不同的 DeFi 代币。第一个是 `AAVE`，它是 Aave 协议的原生治理代币。当你购买 `AAVE` 代币时，等同于购买公司的股票。因此，你可以对可能改变协议方向的改进提案投票。

第二个 Aave 代币是 `aTokens`，它们是贷款者用于收集存款利息的计息代币。利息直接在你的钱包中积累，这些代币与你存款资产的价值按 1:1 的比例挂钩。在 Aave 上可以获得的最流行的贷款之一是闪电贷（flash loan），你可以用它利用加密货币中的套利机会。闪电贷不需要抵押。然而，你需要在几秒内的同一笔交易中偿还贷款。如果交易内未付款，交易将回滚。Aave 协议有 16 个代币的上限。代币的管理在一个供使用的合约中。此外，质押是 Aave 的另一个特性。这是一个安全模块，你可以在其中质押代币作为保险。例如，如果 Aave 上的某种稳定币失去了与美元的挂钩，可以使用 30% 的安全资金来支付损失。自 Aave 在 2020 年推出以来，你可以使用该平台借贷真实资金。

# 3. Fantom: 数字资产、dApps 与智能合约

以太坊是第一个提供智能合约的加密货币。然而，它一直面临拥堵问题和高交易费用。结果是开发了几个替代方案，提供更快速、成本低的交易。其中一个替代方案是 Fantom，一个用于 dApps 和数字资产的开源智能合约平台。该平台简化了合成资产的借入、贷款和交易。你只需要访问你的数字钱包，存入代币，就可以开始赚钱。

## 特性

Fantom 正在崛起，因为它有一种网络架构为区块链三难题提供了一个可行的解决方案。它旨在提供安全性、稳定性和去中心化的稳定平衡。该平台非常快，其速度源于一种被称为 Lachesis 的独特共识机制。得益于此，交易几乎是瞬时完成。因此，作为一个启用智能合约的区块链，它是 dApp 开发的健壮环境。

Fantom 高效的交易处理确保交易在一到两秒内结算。它每秒可以处理数千次交易，而且费用通常只有几分钱。Fantom 平台的交易量在五月份超过三百万次也不奇怪。Fantom 对去中心化金融（De-Fi）至关重要，而且不需要治理机构。

它的基础设施通过其 `aBFT（异步拜占庭容错）` POS 共识机制连接在一起。结果是，它可以维持整个网络的运行效率。通过每年只需 35 美元订阅 Blank Slate Media 社区报来支持当地新闻。Fantom 的共识机制 `aBFT` 验证网络上的数据和交易。结果是，它可以信任且透明的方式达成一致。再次，`aBFT` 网络结构可以在保护网络安全性的同时最大化速度。

Fantom 因其高吞吐量和速度被用于支付。它也是链上治理和治理活动的理想选择。这意味着，如果你拥有 `FTM` 网络上的代币，你将能够通过链上治理对改进提案进行投票、提议更改并执行决策。

你的影响力将取决于你所持有的 `FTM` 数量。Fantom 适用于质押奖励。在这里，你可以获得最低 3.79% 的年化收益率（`APR`），最高可达 11.59%。`APR` 取决于你质押的 `FTM` 数量以及总锁定期限。此外，Fantom 还用于支付网络费用和补偿验证者。

尽管费率非常低，但 Fantom 支付交易费用以及创建新网络和智能合约所需的费用。`FTM` 也用于支付那些保持平台运行免黑客和诈骗并验证交易的验证者。Fantom 拥有集成的 DeFi 栈，允许用户使用 `FTM` 代币铸造 `fUSD`。`fUSD` 是 Fantom 的原生稳定币，与美元 1:1 挂钩。

你可以使用它对 176 种代币和合成资产进行交易、借贷，包括 `fETH` 和 `fBTC`。截至 2021 年 11 月 17 日，Fantom 的交易价格为 2.03 美元。其在交易所的 24 小时交易量约为 $748,138,557.20。

# 4. Pancake Swap：最流行的去中心化平台

Pancake Swap 是另一个新兴的去中心化金融协议。这个 DeFi 项目在一年前推出，基于币安智能链作为自动做市商。像 `Aave` 一样，Pancake Swap 是一个交易流动性提供者。截至 10 月底，Pancake Swap 用户在该去中心化交易所（DEX）上质押了超过五十亿美元。

与 `Uniswap` 等竞争对手相比，且市值仅为四十亿美元，Pancake Swap 极具划算。

## 特性

有许多原因说明 Pancake Swap 是代币持有者的便利选择。首先，Pancake Swap 构建在币安 `BEP-2` 之上。币安是全球最大的加密货币交易所，日均交易额平均达 270 亿美元。其次，该平台由领先的智能合约安全公司 `CertiK` 审计。因此，它比未经审计的 DeFi 项目更值得信赖。在 Pancake Swap 上，你可以无需中介交易代币和加密货币，并保持代币的托管。

尽管 Pancake Swap 运行在币安上，但它并不由币安控制。该服务非常类似于 `Uniswap` 或以太坊 DEX。Pancake Swap 用于运行币安智能链上的 `BEP-20` 代币。然而，你可以通过币安桥从其他平台引入代币。从那里，你可以将其转换为 `BEP-20` 代币并在 Pancake Swap 上使用。Pancake Swap 使用自动做市商（`AMM`）模型，该模型依赖于用户资金池。

用户将资金存入池中获得 `LP` 代币。你可以使用这些代币取回你的交易费用份额，并将代币锁定在流动性池中盈利。此外，你可以使用代币兑换你需要的币。在 Pancake Swap 上，你还可以挖掘 `CAKE` 和 `SYRUP` 等代币。`CAKE` 是你在锁定 `LP` 代币后获得的第一个奖励。现在，你可以质押 `CAKE` 代币以获得 `SYRUP`。有了 `SYRUP` 代币，你将获得更多功能，如治理代币或可用作票据目的的代币。Pancake Swap 的另一个特性是它提供了游戏化的体验。例如，你可以押注 `BNB` 的价格在特定时间范围内是会上涨还是下跌。在该功能中，用户可以购买门票，希望能赢得一次 `CAKE` 大奖。此外，Pancake Swap 还提供了多种兔子主题的 NFT。另外，还有 `IFO`（初始农场发行）销售，可以从新兴项目购买新币。使用 Pancake Swap 需要加密钱包。该去中心化平台支持 `Math Wallet`、`Trust Wallet`、`Binance Wallet` 甚至 `MetaMask`。尽管 `MetaMask` 是以太坊钱包，但它可以配置为与币安智能链配合。

Pancake Swap 与 `Uniswap` 和 Sushiswap（以太坊最大的 DEX）一样非常流行。如果以太坊继续经历高交易费用和拥堵，Pancake Swap 有望在竞争对手手中获得更大的市场份额。

# 5. The Graph：去中心化索引是未来

The Graph (`GRT`) 是一种用于从区块链查询和索引数据的去中心化协议。它的运行方式类似于 Google 索引网络信息以提高可访问性。类似地，The Graph 索引来自以太坊和 Fiona 等区块链的数据。此前，The Graph 只能索引以太坊数据。

然而，自 NEAR 区块链以来，它开始在非以太坊的区块链上运行。

## 特性

The Graph 将数据分组为开放 API 即 `subgraphs`。这一过程使得开发者很容易通过 The Graph 进行查询。因为它使数据变得可用，它为 DEX 等应用程序提供了高效运行的数据支持。开发者使用 The Graph 获取价格和用户信息等数据。截至 2021 年 11 月，该协议运行在 25 个网络上。The Graph Foundation 为在 The Graph 上构建的项目发放资助。尽管如此，它将继续发布资助。

此外，它支持索引来自以太坊、`POA` 和 IPFS 的数据。`Aragon`、`Synthetix`、`Uniswap`、`Balancer`、`Gnosis` 等许多 dApp 已经部署了 1,700 多个子图。`GRT` 的流行度正在增长，其当前价格为 0.65 美元，24 小时交易量为 $136,511,855。The Graph 预计到 2026 年收入将增长 +212.52%。

# 关于元宇宙的进一步解释

但这些观点中没有一个是对核心理念至关重要的。从最广泛的来说，元宇宙被理解为一个视觉丰富的虚拟空间，具有某种程度的真实性，人们可以在那里工作、玩耍、购物、社交——简而言之，就是人类在现实生活中喜欢一起做的事情（或者更准确地说，在互联网上）。元宇宙的支持者经常将“临场感”（presence）这一概念视为定义性因素：感觉自己真的在那里，并且感觉其他人也真的和你在一起。

这种版本的元宇宙可能已经以视频游戏的形式存在了。但还有另一种元宇宙的定义，它超越了我们所知的虚拟世界。这种定义实际上并没有描述元宇宙，而是解释了为什么每个人都认为它如此重要。这个定义并不是关于对未来的愿景或某种新技术。

相反，它回顾了过去以及现在常见的互联网和智能手机技术，并假设必须发明元宇宙来取代它们。具有影响力的风险投资家马修·巴尔（Matthew Ball）曾撰写过关于元宇宙的文章，他将其描述为“移动互联网的一种成功或状态”。

（马克·扎克伯格，他去年将自己的公司 Facebook 改名为 Meta，并表示元宇宙将是其重心，他也使用了一个几乎相同的短语；显然，巴尔的话对硅谷的思维具有极大影响。）还记得智能手机如何彻底改变技术、经济和社会本身吗？元宇宙被认为是一个同等的分水岭，许多企业都想抢占先机。

巴尔的愿景中有很多待挑战的地方，但最大的是他的主张：元宇宙将像互联网一样，是一个开放的、可操作的单一网络。这是一个非常高的要求。不过我们想得太早了。

## 关于元宇宙的进一步解释

简而言之：看。我们已经确定这个术语已经存在了 30 年，而不仅仅是虚构。对于某些人来说，它已经成为企业未来愿景的一部分。在 20 世纪 90 年代的第一次 VR 热潮期间，英国的研究人员建立了一个 VR 商店，它与 2017 年的一段视频惊人地相似。

除了营销噱头和概念证明之外，类元宇宙的虚拟世界存在的时间与它们的数量一样长（即历史悠久）。那些要在元宇宙中结婚的人将获得任何几十年来关注在线游戏的人的认可。最著名的世界之一，也许是最接近元宇宙理想的，是第二人生（Second Life），这是一个于 2003 年启动的“在线平台”。

第二人生很大程度上类似于早期大型在线游戏（如《魔兽世界》），但去掉了所有的游戏元素：战斗、任务、奖励。它履行了人们对未来元宇宙的设想，让虚拟人物在虚拟空间中相互聚会。他们享受现实世界体验的虚拟版本，从会议到夜店活动。

用户创建自己的内容和服务，并与他人进行交易。这里有一个虚拟经济，拥有自己的货币，这种货币可以与现实世界的货币进行交换。第二人生几乎是教科书式的元宇宙，如果这种东西存在的话。另一个值得注意但被遗忘的早期元宇宙例子是 PlayStation Home。

索尼为 PlayStation 3 打造的注定的虚拟社交枢纽于 2008 年推出，并于 2015 年关闭。它没有取得任何成功，而且对普通用户来说似乎毫无意义，但它是一个高度企业化的元宇宙——与无政府的、社区驱动的第二人生相反——可能是什么样子的有趣例子。

它包含大量广告和单向购买机会，没有太多其他可做的；它痛苦于在你的 PS3 界面中紧邻着更丰富、更有趣的虚拟世界（即游戏本身）。但其艺术风格那种整洁、平淡、乌托邦式的未来主义，显然预示了扎克伯格最近的元宇宙演示。这就是公司认为我们梦想呈现的样子。当然，现实可能更接近混乱、有时甚至肮脏的第二人生。

给人类一个构建不受限制的世界的机会，他们就会带着品牌或其他而来。这应该被视为对元宇宙的警告，或者是机会。

## 元宇宙的突然认可

在过去的几年里，有少数因素导致其处于技术和思维的前沿。之一是元宇宙的一些愿景已经成熟了。虚拟现实在 90 年代作为“史蒂芬森崩溃”经历了首次步履蹒跚，而现在，它已经是现实了。

已经有了廉价且质量良好的头设备，包括像 Quest 这样的独立设备。Facebook 在 2014 年购买 Oculus 是扎克伯格可能走向的早期迹象。另一个是区块链，这种可以理解且持久的技术让货币和 NFT 成为可能。

NFT 在过去一年中成为爱好者、高层高管以及（奇怪的是）艺术界某些部分的痴迷，它们可以实现元宇宙内虚拟物品的所有权。需要注意的是，在不使用区块链的情况下，同样可以“拥有”甚至交易游戏和虚拟空间（包括第二人生）中的物品——但这通常受限于许可协议。

NFT 提供了不同的（但相似的）提供所有权的方法。无论如何，NFT 的独特性和所谓的可移植性让元宇宙的支持者们非常兴奋。元宇宙趋势中另一个同样重要的因素是新冠肺炎疫情，它改变了全球范围内的生活方式。

随着人们在 Zoom 会议上花费大量时间进行工作，以及由于人们在不离开家中舒适和安全感的情况下寻求进入更丰富多彩、更真实的环境，导致视频游戏的使用率飙升，科技公司寻找桥接这两种需求以利用这一局势的方法是顺理成章的。2021 年底，Facebook 的品牌重塑及其“以元宇宙为中心”的声明落定了定音。

从那时起，这个词的出现频率日益增加——至少在商业界是如此。政府和政治领域可能需要一段时间才能跟上，因为他们正关注于如何遏制科技巨头的权力，以及如何减轻社交媒体对社会的负面影响——这种影响是一个持续存在的问题。无聊！

它们是围绕人们想去的虚拟场所形成的持久性社区——例如《魔兽世界》或《使命召唤：战区》。微软的思维在这里具有一致性。2014 年，在 Facebook 收购 Oculus 左右的时期，微软收购了 Mojang 及其极其受欢迎的游戏《我的世界》（Minecraft）。《我的世界》凭借其社交性、创造性和深度可定制的玩法，经常被引用为类元宇宙游戏；值得注意的是，微软并没有试图在自己的平台上强行推独家；它将《我的世界》视为一个本身就有价值的平台。
