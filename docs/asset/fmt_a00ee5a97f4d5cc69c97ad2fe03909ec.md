
* `m < M - 1`。如果 `A` 由对应于最大的 `m` 个特征值的特征向量作为列构建，则 `J3y < J3x`。
* 然而，所得值 `J3y` 是可能的最大值。

## 决策树分类原理

从根节点开始，通过一系列连续的决策路径，直到到达叶节点。每个叶节点与**单个**类别相关联。点到类别的分配根据相应叶节点的标签进行。这种分类类型在概念上简单且易于解释。例如，在医学诊断系统中，可能从"体温是否高？"这个问题开始。如果是，第二个问题可以是："鼻子是否流涕？"该过程持续进行，直到就疾病做出最终决定。此外，树结构在构建人工智能推理系统中也很有用[37]。例如，基于某些（高层）特征值的一系列相关问题推导出特定对象的存在，可以导致对图像中描绘的场景或物体的识别。

一旦树建立完成，分类就变得简单直接。主要挑战在于如何利用训练数据集中蕴含的信息来构建树。设计树时面临的主要问题如下：

* 应采用哪种分裂准则？
* 何时停止树的生长并将节点声明为最终节点？
* 叶节点如何与特定类别关联？

除了上述问题，还有其他问题将在后面讨论。

### 分裂准则

我们已经说明，每个节点提出的问题类型如下：

Is `x[i] < a`?

目标是为阈值 `a` 选择一个合适的值。假设从根节点开始，树已生长到当前节点 `t`。每个节点 `t` 关联训练数据集 `X` 的一个子集 `X[t] ⊆ X`。这是在树中前序节点进行测试后，存活到达该节点的训练点集合。例如，在图 7.13 中，属于类别 `ω[1]` 的许多点将不参与节点 `t[1]`，因为它们已在先前标记的叶节点中被分配。分裂准则的目的是根据节点 `t` 处特定问题的答案，将 `X[t]` 分裂为两个**不相交**的子集，即 `X[tY]` 和 `X[tN]`。对于每次分裂，以下均成立：

```
X[tY] ∩ X[tN] = ∅, X[tY] ∪ X[tN] = X[t].
```

每个节点的目标是选择要测试的特征以及对应阈值 *a* 的最佳值。采用的原则是做出选择，使得每次分裂产生的集合 *X*<sub>tY</sub>、*X*<sub>tN</sub> 比 *X*<sub>t</sub> 更具“类同质性”。换句话说，两个后代集合中的数据必须比祖先集合表现出对特定类别的更高偏好。

例如，假设 *X*<sub>t</sub> 中的数据包含属于四个类别 *ω*<sub>1</sub>、*ω*<sub>2</sub>、*ω*<sub>3</sub>、*ω*<sub>4</sub> 的点。其思路是执行分裂，使得 *X*<sub>tY</sub> 中的大部分数据属于 *ω*<sub>1</sub>、*ω*<sub>2</sub>，而 *X*<sub>tN</sub> 中的大部分数据属于 *ω*<sub>3</sub>、*ω*<sub>4</sub>。在采用的术语中，*X*<sub>tY</sub> 和 *X*<sub>tN</sub> 应比 *X*<sub>t</sub> 更“纯净”。

因此，我们必须首先选择一个衡量“杂质度”的准则，然后计算阈值并选择要测试的特定特征，以最大化节点杂质度的降低。例如，量化节点 *t* 杂质度的常用度量是“熵”，定义如下：

```
I(t) = - ∑_{m=1}^{M} P(ω_m|t) log_2 P(ω_m|t),  (7.73)
```

其中 log<sub>2</sub>(·) 是以 2 为底的对数。*I*(*t*) 的最大值出现在所有概率相等时（最大杂质度），最小值为零，出现在只有一个概率值为 1 而其余为 0 时。概率近似计算为：

```
P(ω_m|t) = N_t^m / N_t,  m = 1,2,…,M,
```

其中 *N*<sub>t</sub><sup>(m)</sup> 是 *X*<sub>t</sub> 中属于类别 *m* 的点的数量，*N*<sub>t</sub> 是 *X*<sub>t</sub> 中点的总数。将数据分成两个集合后，节点杂质度的降低定义为

#### 信息增益与分裂准则

$$
\Delta I(t) = I(t) - \frac{N_{tY}}{N_{t}}I(t_{Y}) - \frac{N_{tN}}{N_{t}}I(t_{N})
$$

其中 $I(t_{Y})$ 和 $I(t_{N})$ 分别是两个新子集关联的不纯度。目标是选择特定特征 $x_{i}$ 和阈值 $a_{t}$，使得 $\Delta I(t)$ 最大化。这将定义节点 $t$ 的两个新后代节点 $t_{N}$ 和 $t_{Y}$，从而使树增长两个新节点。

##### 阈值搜索方法

对于每个特征 $x_{i}$（$i = 1, 2, \dots, l$），对该特征在训练集 $X_{t}$ 中取值 $x_{in}$（$n = 1, 2, \dots, N_{t}$）进行排序。然后定义一系列对应的阈值 $a_{in}$，取为连续不同 $x_{in}$ 值的中点。测试每个阈值导致的不纯度变化，保留实现最大下降的那个。对所有特征重复此过程，最终保留使最大下降最优的特征-阈值组合。

##### 基尼指数

除了熵，还可使用其他不纯度度量指标。一种流行的替代指标是**基尼指数**，其定义为：

$$
I(t) = \sum_{m=1}^{M} P(\omega_{m}|t) \left( 1 - P(\omega_{m}|t) \right)
$$

当某个概率值为 1 其余为 0 时，该指数为 0；当所有类别等概率时，取得最大值。

##### 停止分裂规则

生长决策树时，何时停止生长是一个关键问题。可采用以下策略之一：

1. 设定阈值 $T$，若所有可能分裂的最大 $\Delta I(t)$ 均小于 $T$，则停止分裂该节点。
2. 当 $X_{t}$ 的基数小于某个数值时停止。
3. 若节点“纯净”（即其中所有点均属于单一类别），则停止。

### 类别分配规则

一旦节点 `t` 被声明为叶节点，就会被分配一个类别标签；通常这是基于多数投票原则完成的。也就是说，它被分配 `X[t]` 中大多数数据所属的那个类别的标签。

### 树的剪枝

经验表明，生成一棵树并使用停止规则在实践中并不总是效果良好；生成过程可能过早停止，也可能导致树的规模变得非常大。一种常见的做法是先将树生长到较大规模，然后采用剪枝技术来消除节点。可以使用不同的剪枝准则；一个流行的准则是将错误概率的估计与复杂度度量指数相结合（参见 [2,31]）。

### 备注 7.6

* 决策树的显著优势之一在于它们能自然地处理数值型和分类型变量的混合。此外，它们能很好地适应大规模数据集。而且，它们能有效地处理缺失变量。在许多领域中，并非每个模式的所有特征值都是已知的。这些值可能未被记录，或者获取成本过高。最后，由于其结构简单，它们易于解释；换句话说，人类有可能理解学习算法输出结果背后的原因。在某些应用中，例如金融决策，这是一项法律要求。
* 另一方面，树分类器的预测性能不如其他方法好，例如支持向量机和神经网络，它们分别将在第 11 章和第 18 章中介绍。
* 与树分类器相关的一个主要缺点是它们是 `unstable`（不稳定）的。也就是说，训练数据集的微小变化可能导致树结构发生巨大差异。其原因在于树分类器的层次性质。发生在树高层节点处的错误会一直向下传播到其下方的所有叶节点。
* `Bagging`（自助聚合）[3] 是一种可以降低方差并改善泛化误差性能的技术。其基本思想是利用 `bootstrap` 技术，通过从 `X` 中有放回地均匀采样，创建训练集 `X` 的 `B` 个变体 `X[1], X[2], …, X[B]`。针对每个训练集变体 `X[i]`，构建一棵树 `T[i]`。对给定点进行分类的最终决策，倾向于由大多数子分类器 `T[i], i = 1, 2, …, B` 预测的类别。
* `Random forests`（随机森林）将 bagging 的思想与随机特征选择相结合 [5]。其与 bagging 的区别在于决策树的构建方式。每个节点的分裂特征是在 `F randomly`（F 个随机）选定的特征集合中选择最优的，其中 `F` 是用户定义的参数。据报道，这种额外引入的随机性对性能提升有显著效果。
* 随机森林通常具有非常好的预测准确性，并已被用于许多应用，包括通过微软流行的 Kinect 传感器进行人体姿态识别 [34]。
* 除了上述方法外，最近贝叶斯技术也被建议并用于稳定树的性能（参见 [8,44]）。当然，使用多棵树的效果是失去了树的一个主要优势，即其相当容易的可解释性。
* 除了 OBCT 理论外，还提出了通过不平行于坐标轴的超平面来实现特征空间更一般的划分。这可以通过以下类型的问题实现：`∑_{i=1}^{l} c_i x_i < a` 是否成立？这可以带来更好的空间划分。然而，训练过程变得更加复杂（参见 [35]）。
* 决策树也被提出用于回归任务，尽管成效较小。其思路是将空间划分为若干区域，预测基于观测输入向量所在区域的输出值的平均值进行；这种平均方法的一个后果是，当从一个区域移动到另一个区域时缺乏平滑性，这是回归树的一个主要缺点。区域的划分是基于 `LS`（最小二乘）方法 [19] 执行的。

## 7.9 组合分类器

到目前为止，我们已经讨论了多种分类器，更多方法将在第 13、11、18 和 19 章中介绍，涉及支持向量机、贝叶斯方法以及神经/深度网络。缺乏经验的从业者/研究者面临的显而易见的问题是“该用哪种方法？”不幸的是，没有确定的答案。此外，当数据规模较小时，选择方法的问题变得更难。本节的目标是讨论通过组合不同学习器而受益的技术。

### 免费午餐定理

基于有限规模训练集的任何分类器设计，以及一般而言任何学习方案的设计，其目标都是提供良好的泛化性能。然而，不存在与上下文无关或与用法无关的理由来支持某一种学习技术优于另一种。每个学习任务（由可用数据集表示）都会表现出对特定学习方案的偏好，该方案适合手头特定问题的特性。在某个问题上表现最好的算法，在另一个问题上可能表现很差。这一实验发现在理论上由机器学习的所谓 `no free lunch theorem`（免费午餐定理）[43] 所证实。

这项重要定理指出，在对*所有可能的*数据生成分布取平均时，每种分类算法在训练集之外的数据上都会产生*相同的错误率*。换句话说，在更一般的背景下，不存在普遍最优的学习算法。然而，请注意，这些结果仅在对所有可能的数据生成分布取平均时才成立。另一方面，如果在设计学习器时，我们利用了关于我们感兴趣的特定数据集细节的先验知识，那么我们就可以设计出一种在该数据集上表现良好的算法。

在实践中，应尝试从可用的调色板中选取不同的学习方法，每种方法都针对特定任务进行优化，并使用独立于训练集的数据集测试其泛化性能，例如采用留一法或其变体（第 3 章）。然后保留并使用在特定任务上得分最高的方法。

为此，已经有许多主要工作致力于将不同的分类器与不同的数据集进行比较，并通过使用不同的统计指标来衡量“平均”性能，以量化每个分类器针对数据集的整体性能。

### 一些实验比较

方法的实验比较总是带有浓厚的历史色彩，因为随着时间的推移，新方法不断涌现，而且可以获得更新、更大的数据集，这可能会改变结论。在本小节中，我们展示了一些已完成的大型项目的样本，这些项目的目标是将不同的学习器进行比较。由于深度神经网络的出现，今天的形势可能有所不同；然而，从这些先前项目中获得的知识仍然有用且令人启发。

最早比较不同分类器性能的努力之一是 Statlog 项目 [27]。文献 [7,26] 总结了两项后续工作。在前者中，17 种流行的分类器在 21 个数据集上进行了测试。在后者中，采用了 10 种分类器和 11 个数据集。结果验证了前面所说的：不同的分类器在不同的数据集上表现更好。然而，据报道，提升树（第 7.11 节）、随机森林、装袋决策树和支持向量机在大多数数据集中名列前茅。

神经信息处理系统研讨会（NIPS-2003）基于五个数据集组织了一次分类竞赛。竞赛结果总结在文献 [18] 中。该竞赛侧重于特征选择 [28]。在一项后续研究 [22] 中，增加了更多分类器。在所考虑的分类器中，一种贝叶斯类神经网络方案（第 18 章）名列前茅，尽管其运行时间需求显著更高。其他考虑的分类器包括随机森林和提升法，其中树和神经网络被用作基分类器（第 7.10 节）。与贝叶斯类分类器相比，随机森林也表现良好，且计算时间低得多。

### 分类器组合方案

提高性能的一种趋势是组合不同的分类器并利用它们各自的优势。一个支持这种方法的观察是：在测试期间，存在一些模式，即使针对特定任务的最佳分类器也无法预测其真实类别。相反，这些相同的模式可以被其他分类器正确分类，尽管这些分类器的整体性能较差。这表明不同分类器之间可能存在互补性，组合可以带来比最佳（单一）分类器更高的性能。回顾第 7.8 节提到的装袋法，它是一种分类器组合类型。

## 7.10 提升方法

*提升*方法用于设计学习机器的起源可追溯至 Valiant 和 Kearns 的工作 [23,40]，他们提出了这样一个问题：弱学习算法（即比随机猜测略好一些的算法）能否被*提升*为一个具有良好性能指标的强学习算法。此类技术的核心在于*基学习器*，它是一个弱学习器。提升包含一个迭代方案，在每一步中，基学习器使用不同的训练集进行最优计算；当前迭代的数据集是根据迭代获得的数据分布生成的，或者通常是通过对训练样本进行加权来生成的，每次使用不同的一组权重。后者的计算是为了考虑到当前迭代步骤为止所达到的性能。最终学习器是通过所有*分层*设计的基学习器的*加权平均*获得的。因此，提升也可以被视为一种组合不同学习器的方案。

事实证明，给定足够多的迭代次数，可以显著改善弱学习器的（较差）性能。例如，在某些分类情况下，随着迭代次数的增加，训练误差可能趋于零。这确实非常有趣。通过对训练数据的适当操作来训练弱分类器（事实上，加权机制识别出难分样本——即那些持续分错的样本——并对它们给予更多重视），可以获得一个强分类器。当然，正如我们将要讨论的，训练误差可能趋于零这一事实*并不*一定意味着测试误差也会趋于零。

### AdaBoost 算法
