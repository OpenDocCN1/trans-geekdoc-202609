
$$e_{nj}^{r - 1} := \sum_{k = 1}^{k_{r}} \delta_{nk}^{r} \theta_{kj}^{r},$$

![Equation](img/si157.png) (18.28)

最终我们得到：

$$\delta_{nj}^{r - 1} = e_{nj}^{r - 1} f^{\prime}(z_{nj}^{r - 1}).$$

![Equation](img/si158.png) (18.29)

剩下的唯一计算是 `f` 的导数。对于 logistic sigmoid 函数的情况，很容易证明其等于（问题 18.2）：

$$f^{\prime}(z) = a f(z)(1 - f(z)).$$

![Equation](img/si159.png) (18.30)

推导已完成，梯度下降反向传播方案总结在算法 18.2 中。

### 算法 18.2：梯度下降反向传播算法

#### 初始化

1.  将所有突触权重和偏置随机初始化为较小但非极小的值。
2.  选择步长 `μ`。
3.  设置 `y[nj]⁰ = x[nj]`，`j = 1, 2, …, k[0] := l`，`n = 1, 2, …, N`。

![Equation](img/si160.png)

#### 重复；每次重复完成一个周期

1.  **对于** `n = 1, 2, …, N`，**执行**：
    1.  **对于** `r = 1, 2, …, L`，**执行**；前向计算。
        1.  **对于** `j = 1, 2, …, k[r]`，**执行**
            1.  根据公式 (18.14) 计算 `z[nj]^(r)`。
            2.  计算 `y[nj]^(r) = f(z[nj]^(r))`。
        2.  **End For**
    2.  **End For**
    3.  **For** `j = 1, 2, …, k[L]`，**Do**；反向计算（输出层）。
    4.  根据公式 (18.21) 计算 `δ[nj]^(L)`。
    5.  **End For**
    6.  **For** `r = L, L−1, …, 2`，**Do**；反向计算（隐藏层）。
        1.  **For** `j = 1, 2, …, k[r]`，**Do**
        2.  根据公式 (18.29) 计算 `δ[nj]^(r−1)`。
        3.  **End For**
    7.  **End For**
    8.  **End For**
    9.  **For** `r = 1, 2, …, L`，**Do**；更新权重。
        1.  **For** `j = 1, 2, …, k[r]`，**Do**
        2.  根据公式 (18.18) 计算 `Δθ[j]^(r)`。
        3.  更新 `θ[j]^(r) = θ[j]^(r) + Δθ[j]^(r)`。
        4.  **End For**
    10. **End For**
2.  **End For**
3.  *Until* 满足停止准则。

反向传播算法有多位奠基人。该算法的普及与经典文献 [171] 相关，该文献提供了算法的推导过程。然而，该算法在文献 [216] 中已更早被推导出来。反向传播的思想也出现在文献 [23] 的最优控制背景中。

#### 备注 18.3

*   已提出多种标准用于终止反向传播算法。一种可能是跟踪代价函数的值，当其小于预选阈值时停止算法。另一种途径是检查梯度值，当梯度变小时停止；这意味着权重值在迭代间变化不大（参见例如 [106]）。
*   与所有梯度下降方案一样，步长 `μ` 的选择至关重要；它必须足够小以保证收敛，但不能太小，否则收敛速度会减慢。选择很大程度上取决于具体问题。自适应步长 `μ`（其值取决于迭代次数）也是流行的替代方案，稍后将讨论。
*   由于神经网络问题的高度非线性本质，参数空间中的代价函数通常具有复杂的地形，存在多个局部极小值，算法可能陷入其中。如果某局部极小值足够深，相关解可能是可接受的。然而，情况并非总是如此，算法可能陷入浅层极小值从而导致糟糕的解。理想情况下，应多次随机重新初始化权重并保留最佳解。初始化必须谨慎进行；我们稍后将讨论此问题。关于深度网络背景下局部极小值与全局极小值的讨论见第 18.11.1 节。

#### 逐模式/在线方案

算法 18.2 中讨论的方案属于*批量*类型，即参数/权重每轮更新一次，也就是在所有 *N* 个训练样本都已呈现给算法之后进行更新。另一种途径是*逐模式*版本；对于这种情况，每当一个新的训练样本出现在输入端时，权重就会更新一次。有时，此类方案被称为*在线*。然而，我们将避免使用该术语，因为它通常指的是考虑流式数据且观测值持续流入的情况，而不是拥有一个固定大小的训练集，其中数据点会被反复考虑、一轮接一轮。在线算法已在第 5 章和第 8 章中进行过探讨。另一个近期更常用于描述此类算法的名称是*随机*优化。这让人联想到第 5 章介绍的随机逼近法，其中为了最小化期望损失，单个观测值被顺序用于更新未知参数/权重的估计值。当然，请记住，在真正的随机梯度下降中，*不*存在数据复用（即一轮接一轮），且假设数据以流式方式到达，收敛是*渐近*实现的。

当数据中存在冗余或训练样本非常相似时，逐模式版本能更好地利用训练集。批量模式中采用的平均操作会浪费资源，因为对相似模式对梯度的贡献进行平均并不会增加太多信息。相反，在逐模式实现中，所有样本都能得到同等利用，因为每个训练样本都会触发一次更新。

逐模式导致收敛轨迹不够平滑；然而，这种随机性可能有助于算法跳出局部极小值。

#### 小批量方案

一种中间方式，即每 *K* < *N* 个样本执行一次参数更新，也已被考虑在内，这被称为*小批量*或*随机小批量*。然而，此类方案通常简称为随机。小批量大小 *K* 的选择受多种因素影响，且取决于应用、具体数据以及可用的计算能力。

例如，如果批量大小非常小，多核架构将得不到充分利用。此外，当使用 GPU 时，采用 2 的幂次方作为小批量大小可以提供更好的运行时间。对于这种情况，一些典型值范围为 16 到 256，具体取决于训练集的大小。另一方面，使用较小的小批量大小可能具有正则化效果，这是由于在梯度计算中隐式添加了噪声。然而，在这种情况下，出于稳定性原因，必须对步长使用较小的值，这可能会增加总体训练时间。

批量和小批量方案对梯度计算具有平均效应。文献 [186] 建议向训练数据添加一个小的白噪声序列，这可能有助于算法跳出不良的局部极小值。

为了在逐模式/小批量方案中进一步利用随机性，建议在新一轮开始前，将呈现给算法的数据顺序随机化（参见例如 [69]）。这在批量模式中没有意义，因为更新是在所有数据都被考虑之后才进行的。这种数据的随机打乱“打破”了连续样本可能存在的潜在相关性，使得连续的梯度计算相互独立。这种相关性可能是由于生成数据时遵循的特定实验协议造成的。虽然建议每轮都打乱数据，但当使用大型数据集时（例如数十亿量级），这可能不切实际。在这种情况下，即使仅在开始时进行一次数据打乱也是有益的。

如今，在大数据训练集的深度学习背景下，小批量方案似乎是大多数应用的首选。

所有梯度下降方案及其随机变体中的一个主要问题是选择步长或*学习率* *μ*。正如我们从第 5 章所知，如果其值较小，学习曲线会很平滑，但收敛可能很慢。相反，如果其值相对较大，学习曲线往往会振荡，但收敛可能更快，前提是该值不会大到导致算法发散。在实践中，时变步长更为合适，且符合随机梯度的基本原理。可以采用各种策略，但这些策略更多是工程上的“技巧”，而非理论分析的结果。建议用户首先参考以往研究者/实践者在类似情况下的做法，并以此经验为起点。

一种可能的策略是开始训练时采用线性递减的步长，然后在若干次迭代后切换为固定步长。例如，可以采用如下规则：

```
μ[i] = (1 − a[i])μ[0] + a[i]μ[I],
```

其中 *a*[*i*] = *i*/*I*，针对某个固定的迭代次数 *I*。在第 *I* 次迭代之后，步长固定。现在的问题是设置参数 *μ*[0]、*μ*[*I*] 和 *I*。在实践中，必须先监控若干次迭代的学习曲线，并相应地调整参数值，以在初始迭代向收敛移动的快慢之间以及防止不稳定性之间做出权衡。

### 18.4.2 基本梯度下降方案的变体

基础梯度下降方案继承了梯度下降算法家族的所有优点（每次迭代步骤的计算需求低）和所有缺点（收敛慢），正如本书第 5 章首次介绍的那样。为了加快收敛速度，投入了大量的研究精力，并提出了大量基础梯度下降反向传播方案的变体。在本节中，我们提供了一些方向，这些方向在当前版本编写时似乎是实践中的趋势。

为简单起见，在推导出反向传播下降方案后，让我们摒弃指代层和相应层中特定神经元的索引 *r* 和 *j*。取而代之的是，将使用包含网络所有参数的参数/权重向量 **θ**。此外，学习算法第 *i* 次迭代时的相应估计将用 **θ**^((*i*)) 表示。

令 ℒ(*y*, **x**, **θ**) 为采用的损失函数。后者衡量真实输出 *y* 与相应预测值 *ŷ* 之间的偏差，后者取决于相应的输入 **x** 以及定义网络的参数 **θ**。所有训练点上的代价函数由下式给出：

```
$J(\mathbf{\theta}) = \sum\limits_{n = 1}^{N}\mathcal{L}(y_{n},\mathbf{x}_{n},\mathbf{\theta}).$
```

如果采用批处理，则在每次迭代中使用上述代价函数的梯度来更新参数，即 $\frac{\partial J(\mathbf{\theta})}{\partial\mathbf{\theta}}$，这涉及*所有*训练点。也就是说，每个周期仅执行一次参数向量更新。在另一极端，如果采用逐模式方案，则在每次迭代中，根据当前输入-输出对处计算出的损失函数梯度来估计更新，即 $\frac{\partial\mathcal{L}(y_{n},\mathbf{x}_{n},\mathbf{\theta})}{\partial\mathbf{\theta}}$。也就是说，在这种情况下，每个周期可获得 *N* 次参数更新。

小批量操作需要更详细的阐述。假设数据集被分成 *M* 个小批量，每个大小为 *K*。显然，*N* 应该是 *K* 的倍数。假设数据已随机打乱，则在当前迭代周期中，*N* 个输入-输出数据对将按以下顺序出现在算法中：

```
$\underset{1\text{st mini-batch}}{\underbrace{(y_{(1)},\mathbf{x}_{(1)}),\ldots,(y_{(K)},\mathbf{x}_{(K)})}}\ldots\underset{M\text{th mini-batch}}{\underbrace{(y_{((M - 1)K + 1)},\mathbf{x}_{((M - 1)K + 1)}),\ldots,(y_{(N)},\mathbf{x}_{(N)})}},$
```

正如我们在第 18.2 节中已经指出的那样，由于数据打乱，这里使用符号 $(i) \in \{1, 2, \ldots, N\}$。因此，在一个周期内，将执行 $M$ 次更新，每次更新涉及不同代价函数的梯度；这是因为每次都会考虑不同的小批量，即

$\frac{\partial J^{(m)}(\mathbf{\theta})}{\partial\mathbf{\theta}},\ m = 1,2,\ldots,M,$

$J^{(m)}(\mathbf{\theta}): = \sum\limits_{k = 1}^{K}\mathcal{L}\left( y_{((m - 1)K + k)},\mathbf{x}_{((m - 1)K + k)},\mathbf{\theta} \right).$

在后续内容中，为了简化符号，我们将使用一个通用符号 $\frac{\partial J}{\partial\mathbf{\theta}}$ 来表示前面讨论的所有三种可能情况下的梯度运算。代替 $J$ 位置的函数的真实值将取决于 (a) 具体方案（即批量、小批量、逐模式）和 (b) 当前迭代步骤，因为每一步涉及的样本不同（例如，在随机版本中）。

#### 带动量项的梯度下降

在保持梯度下降基本原理不变的前提下，提高收敛速率的一种方法是采用所谓的*动量项* [62,214]。修正项以及更新递推公式现在变为

$$
\Delta\mathbf{\theta}^{(i)} = a\Delta\mathbf{\theta}^{(i - 1)} - \mu\frac{\partial J}{\partial\mathbf{\theta}}\bigg|_{\mathbf{\theta}^{(i - 1)}},\quad \mathbf{\theta}^{(i)} = \mathbf{\theta}^{(i - 1)} + \Delta\mathbf{\theta}^{(i)}
$$

(18.33)

从 $\Delta\mathbf{\theta}^{(0)}$ 的初始值开始，例如 **0**。梯度通过反向传播计算，*a* 是所谓的*动量因子*。换句话说，该算法既考虑了前一迭代步骤中使用的修正量，也考虑了当前的梯度计算。其效果是在代价函数表现出低曲率的区域增加步长。当连续多个梯度指向完全相同的方向时，步长会隐式地增加。假设梯度在例如 *I* 次连续迭代中近似恒定，则可以证明（习题 18.3），使用动量项后，相应的修正量变为

$$
\Delta\mathbf{\theta} \approx - \frac{\mu}{1 - a}\mathbf{g},
$$

(18.34)

其中 **g** 是 *I* 次连续迭代步骤中的梯度值。也就是说，步长已按因子 $\frac{1}{1 - a}$ 增加。*a* 的典型值在 0.5 到 0.9 之间。实质上，使用动量项有助于抑制收敛轨迹的之字形摆动，如第 5 章所述（参见 图 5.9）。据报道，使用动量项可使收敛速度提高高达两倍 [187]。经验表明，与随机模式相比，使用动量因子对批处理模式的帮助更大。

##### 与迭代相关的步长

如果让步长随迭代进程而变化，则会得到前一版本的一种启发式变体。一种规则是根据当前迭代步骤的代价函数比前一步骤大还是小来改变其值。设 $J^{(i)}$ 为当前迭代计算出的代价值。若 $J^{(i)} < J^{(i-1)}$，则学习率按因子 $r_i$ 增加。另一方面，如果新值比前一个值大的因子超过 *c*，则学习率按因子 $r_d$ 减小。否则，学习率保持不变。所涉及参数的典型值为 $r_i = 1.05$，$r_d = 0.7$，和 $c = 1.04$。对于代价值增加的迭代步骤，建议将动量因子 *a* 设为零 [207]。

此类技术也称为 `adaptive momentum`（自适应动量），更适合批处理，因为对于在线版本，代价函数的值往往会在迭代之间振荡。

##### 对每个权重使用不同的步长

为每个单独的权重采用 `different step size`（不同的步长）有利于提高收敛速度；这赋予了算法更好地利用代价函数在参数空间中沿每个方向依赖关系的自由度。文献 [91] 建议：如果某权重对应的梯度值在两次连续迭代中具有相同的符号，则增加与该权重关联的学习率。反之，如果符号发生变化，则减小学习率，因为这表明可能存在振荡。

在后续内容中，将讨论更多近期的方案，这些方案使用与迭代相关且因权重而异的步长。

###### Nesterov 动量算法

Nesterov 算法 [143] 的一个变体在 [197] 中被提出。修正项的更新规则变为
