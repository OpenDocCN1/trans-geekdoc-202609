### 错误与异常

*异常* 是在 Java 程序执行期间发生的错误条件。例如，如果你用零除以一个整数，将抛出 `ArithmeticException`。如果你使用负数组索引，将抛出 `ArrayIndexOutOfBoundsException`。

*未检查异常* 是由 Java 的标准异常处理方法自动处理的异常，这些方法会终止执行。如果尝试用 0 除以一个整数，或数组索引越界等，将抛出此异常。该异常告诉你现在需要修复代码！

*已检查异常* 是指你提供代码来处理异常的情况，要么是 `try`/`catch`/`finally` 语句，要么是显式的 `throw new...Exception` 子句。这些异常不一定是由代码错误引起的。例如，意外的文件结束可能是由于网络连接中断。已检查异常不在 AP Java 考纲范围内。
