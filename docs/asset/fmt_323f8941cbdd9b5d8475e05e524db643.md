## ElGamal

在 [1407,1473] 中描述的 Simmons 第二种潜意识通道是基于 ElGamal 方案。首先选择一个质数 `p`，以及两个随机数 `g` 和 `r`，使得 `r` 小于 `p`。然后计算：

`K = g^r \pmod p`

公钥是 `K`，私钥是 `r`。

# DSA

DSA 中也有一个隐蔽信道 [1468,1469,1473]。事实上，有几个。简单的隐蔽信道涉及 `k` 的选择。如果 Alice 选择一个特定的 160 位随机数，知道 Alice 私钥的 Bob 就可以恢复它。Alice 可以在每个 DSA 签名中向 Bob 发送 160 位的隐蔽消息；其他人只需验证 Alice 的签名即可。另一个复杂之处：由于 `k` 是随机的，Alice 和 Bob 需要共享一个一次性密钥，并用该一次性密钥加密隐蔽消息以生成一个 `k`。

不需要 Bob 知道 Alice 私钥的 DSA 隐蔽信道。这些也涉及选择特定的 `k` 值，但不能用于发送 160 位信息。这种方案在 [1468,1469] 中提出，允许 Alice 和 Bob 每条签名消息交换一个比特隐蔽信息。

- (1) Alice 和 Bob 同意一个随机质数 `P`。这是他们隐蔽信道的密钥。
- (2) Alice 发送一条匿名消息 `M`。如果她想向 Bob 发送隐蔽位，她使签名的 `r` 参数成为模 `P` 的二次剩余。如果她想向他发送 0，她就使 `r` 参数成为模 `P` 的二次非剩余。她通过使用具有所需属性的 `r` 对消息进行签名来实现。
- (3) Alice 将签名的消息发送给 Bob。

(4) Bob 验证签名以确保消息真实性。然后他检查 `r` 是否为模 `P` 的二次剩余或二次非剩余，并获取隐蔽位。

通过这种方法传输多个比特涉及针对多种参数使 `r` 成为二次剩余或二次非剩余。详见 [1468,1469]。

该方案可以很容易扩展到每条签名发送多个隐蔽比特。如果 Alice 和 Bob 同意两个随机质数 `P` 和 `Q`，Alice 可以通过选择随机 `k` 来发送两个比特，其中 `r` 要是模 `P` 的二次剩余或模 `P` 的二次非剩余，且是模 `Q` 的二次剩余或模 `Q` 的二次非剩余。随机值 `k` 有 25% 的概率产生正确形式的 `r`。

这里是 Mallory，一个不实的 DSA 实现者，可以在每次 Alice 签名时限制 Alice 的私钥。

- (1) Mallory 将其 DSA 实现放在防篡芯片中。他在 DSA 实现中创建了一个隐蔽信道。也就是说，他选择随机质数，并选择 `k` 值使得 `r` 在模这些每个质数上是二次剩余或二次非剩余，取决于隐蔽消息。
- (2) Mallory 将芯片分给 Alice、Bob 以及任何想要它们的人。
- (3) Alice 正常签名消息，使用她的私钥 `x`。
- (4) 芯片选择 `x` 的块：第一个块，第二个块，以此此类推。由于有 16 个可能的块，一个比特数就可以识别出是哪一个。这个标识符加上 `k` 的比特就是隐蔽消息。
- (5) 芯片尝试随机 `k` 值，直到找到一个具有二次剩余属性的。假设芯片每秒测试 10,000 个 `k`，它将在两秒内找到一个。
- (6) 芯片使用步骤 (5) 选择的 `k` 值正常签名消息。
- (7) Alice 将数字签名发送给 Bob，或者发布在网络上，等等。
- (8) Mallory 恢复 `r`，因为他知道质数，从而解密隐蔽消息。即使 Alice 知道发生了什么，也无法证明。只要那些质数保密，Mallory 就是安全的。

# 破坏 DSA 隐蔽信道

隐蔽信道依赖于 Alice 可以选择 `k` 来传输隐蔽信息的这一。为了破坏隐蔽信道，不能允许 Alice 选择 `k`。然而，其他人也不能；如果允许其他人选择 `k`，将允许他们伪造 Alice 的签名。唯一的解决方案是 Alice 与另一方共同生成 `k`，使得 Alice 无法控制 `k` 的任何比特，Bob 也无法知道任何比特。协议结束时，Bob 应该能够验证使用了他们共同生成的 `k`。

- (1) Alice 选择 `k` 并发送给 Bob：`u = g^k mod p`。
- (2) Bob 选择 `k''` 并发送给 Alice。
- (3) Alice 计算 `k = kk'' mod (p-1)`。她使用 `k` 对消息 `M` 签名并发送签名：`r` 和 `s`。
- (4) Bob 验证 `(u^k mod p) = r`。

如果是，则使用 `k` 进行签名。步骤 (4) 之后，Bob 知道无法在 `r` 中嵌入隐蔽信息。如果他是信任方，可以证明 Alice 的签名是没有隐信息的。其他人将不得不信任他的证明；Bob 无法通过协议记录向第三方证明这一点。一个令人惊讶的结果是，如果 Bob 想，他可以使用此创建他自己的隐蔽信道。Bob 可以通过具有特征的 `k'` 在 Alice 的签名中嵌入隐蔽消息。当 Simmons 发现此时，他将其命名为“杜鹃信道”。关于杜鹃信道如何工作以及防止它的三步密钥生成协议，在 [1471,1473] 中进行了讨论。

# 23.4 不可否数字签名

要签名消息，Alice 计算 `z = m^x mod p`。这是她需要做的所有。验证稍微复杂一些。

- (1) Bob 选择两个随机数 `a` 和 `b`，均小于 `p`，并发送给 Alice：

`c = z^{(g^a)} mod p`

- (2) Alice 计算 `t=x^{-1} mod {p-1}`，并发送给 Bob：

`d = c^t mod p`

- (3) Bob 确认 `d = m^{g^b} mod p`

如果是，Alice 接受该签名是真实的。
