
- 它表示复杂人工智能任务所需的高度非线性复杂函数。
- 它有效地分析数据的复杂性。

### 定义 7.2。
深度结构学习基于机器学习的视角，建立在深度结构的基本内容之上。学习范式的深度结构解的形成可以自动提取抽象特征的层。低级部分提取下层的特定特征。在接收到这些低级特征后，高级部分从中提取高级抽象特征，并最终使用它们进行分类或理解。每一层的特征由学习算法自动发现，无需人工干预。

以计算机视觉为例。图像内容可以从像素、边缘、角点、部件、物体、场景等不同级别进行观察。从低层到高层的深度结构学习可以自动发现这些日益抽象的特征，并通过分层过程最终将复杂问题转化为简单问题。

![](img/456a7a56403cbb2b5f1a261793529a51_227_0.png)

**图 7.1：** 深度结构的构建。

从复杂电路理论可以看出，深度结构比浅层结构更高效 [14]。在复杂电路中，有许多不同的计算元素和参数。这些元素和参数需要使用函数来表示。然而，它们不能在所有问题中表达。因此，我们考虑使用深度结构。然后，一个复杂问题被分解为 `n` 个简单问题。这些 `n` 个简单问题对应于 `n!` 种排列组合，即有 `n!` 条规则来定义深度结构。在本文中，我们选择其中一条规则，使得每一层对应于简单问题的复杂问题分解；没有组合。然后，我们为每一层提供一个有效索引。最后，复杂问题可以通过分层过程简化为简单问题。

例如，在人脸识别中，选择自顶向下的规则将人脸构建成深度结构，随后进行分析。图 7.1 显示了带有多个局部区域的人脸。其中一个局部特征矩阵被提取为深度结构的一层。然后，在两层之间提供权重 `W`，其中 `W_i` 表示第 `i-1` 层和第 `i` 层之间的关系。

#### 7.2.2 构建深度结构模型

本节基于上一节的内容构建深度结构模型。

假设输入值为 `x`，且 `hat{h}^{i}(x)` 表示第 `i` 层第 `j` 层的值。当 `i=0` 时，它表示输入层。当 `i=l+1` 时，它表示输出层。此外，`hat{h^i(x)}` 表示第 `i` 层的大小，而 `b_j^i` 表示第 `i` 层第 `j` 个单位的内部偏移量，即默认激活码。`W_{jk}^i` 表示第 `i-1` 层 `hat{h_k}^{i-1}(x)` 和第 `i` 层 `hat{h_j^i}(x)` 之间的权重集。`hat{h_j^i}(x)` 定义如下：`hat{h_j^i}(x) = sigm(a_j^i)`，其中

```
a_j^i(x) = b_j^i + sum_{k} W_{jk}^i hat{h_k}^{i-1}(x), forall i in {1, ..., l}, hat{h}^0(x) = x  tag{7.1}
```

这里，`sigm(*)` 是一个 S 形函数：`hat{h_j^l}(x) = sigm(a) = 1 / 1 + e^{-a}`。输出层表示如下：`o(x) = hat{h^{l+1}}(x) = f(a^{l+1}(x))`，其中 `a^{l+1}(x) = b^{l+1} + W^{l+1} hat{h^l}(x)`。A 是用于分类的启动函数；其定义如下：

```
f_j(a) = underset{j}{soft max}(a) = e^{a_j} / sum_{k=1}^{K} e^{a_k}  tag{7.2}
```

其中 `k` 代表 `k` 个类别。

对于数据的深度结构，它表示为流形结构，使得每个子流形对应于一个简单结构。因此，学习问题被分解为若干简单问题。每个简单问题对应深度结构中的一层，每一层在子流形上提供一个有效索引（图 7.2）。

#### 7.2.3 深度结构学习算法

孪生网络（Siamese network）是一种典型的非线性嵌入方法。神经网络领域的研究人员认为，具有相同功能的该网络具有相同的权重，并反馈到“距离测量”层，用于计算两个样本的相似性并给数据打标签。

孪生网络还提出了几种损失函数，其中我们描述了一种边缘损失：

```
L(f_i, f_j, W_{ij}) = { || f_i - f_j ||^2   W_{ij} = 1
                       max(0, m - || f_i - f_j ||^2)   W_{ij} = 0 } .  tag{7.3}
```

这避免了相似矩阵的出现，并且相似样本之间的距离差异至少为 `m`。

在日常生活中，我们经常可以看到一些球面 `S^2` 以及将 `T^2` 视为其他二维流形。从数学角度来看，`S^2` 和 `T^2` 作为 `R^3` 中的子流形嵌入在三维空间中。事实上，每个 `n` 维流形作为一个拓扑空间包含许多不同类型的子流形，这种包含被称为嵌入。如果允许图包含自相交，则这种包含被称为浸入。浸入和嵌入的定义如下。

> **定义 7.3。** 设 `M` 和 `N` 为 `C^1` 流形，`f: M -> N` 为 `C^1` 映射。那么，浸入和嵌入的定义如下：
>
> (1) 如果对于每个点 `p in M`，切映射 `Df: T_pM -> T_qN(q = f(p))` 是单射，即其秩 `Df = dim`，则 `f` 被称为 `C^1` 浸入。
>
> (2) 如果 `f: M -> N` 是单射，则 `(M, f)` 被称为 `(M, f)` 的 `C^1` 子淹没流形。
>
> (3) 如果 `f: M -> N` 是单射浸入，且 `f: M -> f(M) subset N` 是对于 `N` 的主导拓扑，即 `C^1`-同态，则 `f` 被称为 `C^1` 嵌入，且 `(M, f)` 被称为 `C^1` 嵌入流形。

##### 7.2.3.1 深度贝叶斯网络

深度贝叶斯网络 [31]（DBN）是基于 RBM 迭代训练的多层网络。RBM 是一个两层网络，随机像素 `v` 与隐藏随机像素检测器 `h` 相关联。它们的关系如下：

```
p(x) = sum_{h in H} P(x, h) = sum_{h in H} e^{-E(x, h)} / Z
```

```
E(x, h) = -sum_{i in pixel} w_i^p v_i - sum_{j in features} w_j^p h_j - sum_{i, j} v_i h_j w_{ij} .
```

这种想法在训练样本方面具有巨大效果。它通过比较发散过程来提高数据，从而可以增加训练数据的数量，并降低生成模型的性能。作者使用了这种方法来

提前开发深度相邻元素的分析模型，同时它也可以用于训练自编译模型。

### 7.2.3.2 编码/解码算法

Ranzato 等人引入了另一种深度学习方法，即一种编码/解码结构 [33]，称为 SESM。他们选择了一个编码器 `f_enc(x) = w^T x + b_enc` 和一个解码器 `f_dec(z) = aS(z) + b_dec`，二者共用权重。

[33] 中使用的最优损失函数为：

```
a_e ||z - f_enc(x)||_2^2 + ||x - f_dec(z)||_2^2 + a_s h(z) + a_r ||w||_1 .
```

在第一种情况下，编码器的输出非常接近码本 `z`。在第二种情况下，编码器输出被用作输入码本。第三和第四种情况的过程与前两种相同。编码器和解码器的权重为 `w`，且 `a_e, a_s,` 和 `a_r` 是超参数。由于要求算法达到最优，在训练数据中需要一个在线调节程序。事实上，嵌入方法也可以看作是一种编译器 A，嵌入到低维空间数据中。然而，在训练过程中，它不需要进行解码。此外，如果高维数据量较小，速度将会非常快。

### 7.2.3.3 局部线性嵌入 (LLE)

S. T. Roweis 等人提出了一种局部线性嵌入算法，即流形学习的降维方法 [50]。该算法的主要思想如下。首先，假设嵌入的低维流形在观测样本数据中呈线性分布，即每个样本点都可以由其邻域内几个相对较近的样本点的线性重构来表示。然后，在降维过程中，每个局部邻域的权重保持不变，并通过最小重构误差获得高阶样本的低维表示。LLE 算法的具体步骤如下：

- 1. 假设在 `D` 维空间中有 `N` 个位于同一流形上的数据点，`X_i` 是第 `i` 个数据点，`i = 1, 2, 3, ..., N`。这里假设数据点是足够的，因为流形的局部部分是线性的，且每个样本点都可以由其邻近点线性表示。需要计算每个数据点的最近邻点。
- 2. 找到每个样本数据点的权重 `W_{ij}`。我们使用以下公式来最小化每个数据点与其最近邻线性重构之间的误差：

```
epsilon(W) = sum_i | X_i - sum_j W_{ij} X_j |^2
```

这里，如果 `X_j` 不是 `X_i` 的邻居，则权重 `W_{ij} = 0` 且 `sum_j W_{ij} = 1`。权重矩阵每一行的累积值为 1。
- 3. 为了确保权重保持不变，在低维空间中，我们可以最小化上述公式。重构原始高维数据点以获得低维表示：

```
phi(Y) = | sum_i Y_i - sum_j W_{ij} Y_j |^2 .
```

局部线性嵌入 (LLE) 算法是一种保持局部几何结构的流形学习方法。它具有旋转、平移和缩放的某些特性，并且可以学习任意维度的局部线性低维流形。该算法简单，计算复杂度和时间复杂度相对较低，且可归结为特征值问题，简单易行。

### 7.2.4 李群深度结构学习算法

本节将深度结构学习和李群学习算法相结合，给出了李群深度结构学习算法，即：李群深度结构学习 = 李群机器学习 + 深度结构学习。

#### 7.2.4.1 深度结构半监督学习算法

深度结构半监督学习算法指的是将半监督学习算法嵌入到深度结构中。在嵌入之前，我们首先建立一个简单的嵌入模型 [22]，并将其分为以下步骤：

- 1. 选择一种无监督学习方法；
- 2. 选择一个深度结构模型；
- 3. 将无监督学习作为辅助任务插入到架构的每一层中；
- 4. 使用相同的结构来训练有监督和无监督任务。

深度学习涉及学习具有多层非线性映射的模型。这里，我们将考虑一个具有 M 层隐藏单元的多层网络，并给出一个 C 维输出向量：

```
f_i(x) = sum_{j=1}^{d} w_j^{o,i} h_j^M(x) + b^{o,i}, i=1, ..., C  tag{7.4}
```

其中 `w^o` 是输出层的权重。第 `k` 层定义为：

```
h_i^k(x) = S( sum_j w_j^{k,i} h_j^{k-1}(x) + b^{k,i} ), k > 1  tag{7.5}
```

![](img/456a7a56403cbb2b5f1a261793529a51_232_0.png)

图 7.3：三种嵌入情况；(a) 嵌入在输出层，(b) 嵌入在隐藏层，(c) 嵌入在辅助层。

```
h_1^1(x) = S( sum_j w_j^{1,i} x_j + b^{1,i} )  tag{7.6}
```

其中 `S` 是一个类似于双曲正切函数的变形函数。半监督深度学习最普遍的方式是将半监督规则嵌入到深度结构中（见图 7.3）：

- (a) 在整个网络的输出部分，添加一个半监督损失（正则化）来监督损失 (7.3)：

```
sum_{i=1}^{L} e(f(x_i), y_i) + lambda sum_{i,j=1}^{L+U} L(f(x_i), f(x_j), W_{ij})  tag{7.7}
```

这与上述简单技术类似，如 (7.2) 所述。
- (b) 直接正则化中间第 `k` 层 (7.5)，

```
sum_{i=1}^{L} e(f(x_i), y_i) + lambda sum_{i,j=1}^{L+U} L(f^{k}(x_i), f^{k}(x_j), W_{ij})  tag{7.8}
```

`f^{k}(x) = (h_1^{k}(x), ..., h_{N_k}^{k}(x))` 是第 `k` 层的网络输出部分。
- (c) 通过共享初始网络的前 `k` 层生成一个辅助网络，但使用一组新的权重：

```
g_i(x) = sum_{j} w_j^{AUX,i} h_j^k(x) + b^{AUX,i}  tag{7.9}
```

我们在训练该网络时嵌入未标记数据，并利用标记数据训练初始网络。

在实验中，我们嵌入损失函数 (7.3)，其中的一个关键损失是：

```
e(f(x), y) = sum_{c=1}^{C} H(y(c) f_c(x)).
```

Jason 等人 [22] 将半监督和有监督算法嵌入到深度结构的输出层、某个隐藏层、辅助层以及所有其他层中。因此，他们得出结论，他们简化复杂任务的方法可以带来更大的益处。

#### 7.2.4.2 李群深度结构半监督学习算法

基于将半监督学习算法嵌入深度结构的想法，本文基于线性李群或基于李群参数嵌入半监督学习算法。基于无监督算法，在输出层、隐藏层和辅助层中实现半监督学习算法。

线性李群半监督学习算法描述如下。样本 `X = {x_1, x_2, ..., x_l, x_{l+1}, ..., x_{l+u}}`，其中 `x_1, x_2, ..., x_l` 是标记数据，即集合 `L = {(x_1, y_1), (x_2, y_2), ..., (x_l, y_l)}`，`x_{l+1}, ..., x_{l+u}` 是未标记数据 (`l << u`)。数据 `x` 的输出是 `y`。输入样本由矩阵表示，并找到对应学习系统的同构线性李群。

以标记数据为基点，通过无穷小右平移找到其算子生成元：

```
X_mu(x) = phi_mu^nu(x) partial / partial x^mu = | partial phi^nu(x, y) / partial y^mu |_{y=e} partial / partial x^nu  tag{7.10}
```

这里，`phi_mu^nu = | partial phi^nu / partial y^mu |_{y=e}` (`mu, nu = 1, 2, ...`) 是李群的变换函数，且 `phi^nu` 是解析函数，也称为李群合成函数 [26]。

基于参数李群的半监督学习算法描述如下：样本 `X = {x_1, x_2, ..., x_l, x_{l+1}, ..., x_{l+u}}`，其中 `x_1, x_2, ..., x_l` 是标记数据，即集合 `L = {(x_1, y_1), (x_2, y_2), ..., (x_l, y_l)}`，`x_{l+1}, ..., x_{l+u}` 是未标记数据 (`l << u`)。数据 `x` 的输出是 `y`。输入样本由参数表示，并找到对应学习系统的同构参数。根据参数李群的代数结构，使用分组法标记生成元。基于标记数据，根据李群参数的定义定义生成元：

```
X_mu = lim_{a^mu -> 0} ( (e + i a^mu / N X_mu)^N - e ) / (i a^mu)  tag{7.11}
```

其中 `a^mu` (`mu = 1, 2, ..., r`) 表示 `r` 个连续参数，且 `N` 是正整数。进一步地，`A` 是计算的生成元。其他未标记数据根据群运算规则确定，如果未标记数据可以由算子生成，则标记其类别。分析每个标记样本点 `x_i` 的域 `U_i` (`1 < i < l`) 信息，并在样本集中的单位点处取体积不变的内积 `g_{i,j}(a)`。计算 `g_{i,j}(a)` 的值，`g_{i,j}(a) = <(partial / partial x_i), (partial / partial x_j)>`，然后将 `g_{i,j}(a)` 的值代入以下公式：

```
d(x_i, x_j) = sqrt( sum_{i,j=1}^n g_{i,j}(a) (x_{ii} - x_{ji})(x_{ij} - x_{jj}) )  tag{7.12}
```

计算 `U_i` (`1 < i < l`) 中 `x_i` 和 `x_j` 之间的距离。

![](img/456a7a56403cbb2b5f1a261793529a51_234_1.png)

李群深度结构半监督学习算法的结构如图7.4所示。

该算法的主要步骤如下：

- (1) 使用无监督算法流程初始化整个深度结构，然后对全网进行微调；
- (2) 在将半监督算法嵌入每一层的基础上，分别在输出层、隐藏层、辅助层以及所有层中嵌入李群半监督算法 SSLA-GL (n) 或 (SSLA-PLG)。隐藏层是指隐藏子流形 `k`，它通过共享前一个隐藏层来创建一个新的辅助层。

在基于半监督算法嵌入线性李群的深度结构中，基本步骤如下：

- a) 将基于线性李群的半监督算法 SSLA-GL (n) 嵌入到输出层，并向监督者添加半监督损失。

```
sum_{i=1}^{L} e( | partial phi^i(x, y) / partial y |_{y=e} partial / partial x^i , y^i ) + lambda sum_{i=1}^{L+U} L(f(x^i), f(y^i), W_i)  tag{7.13}
```
