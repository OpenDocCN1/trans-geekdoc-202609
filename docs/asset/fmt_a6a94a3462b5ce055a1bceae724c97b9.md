# NETiVM IP 地址方案

现在是讨论 NETiVM 环境内使用的 IP 地址的好时机。该环境对所有带有 /24 子网掩码的系统均使用 RFC 1018 私有 IP 地址。这些地址被分配在 `10.5.x.x` 范围内。第一个 `x` 是网络地址，用于区分内部网络、DMZ 和外部网络。第二个 `x` 是主机地址：`10.5.2x` 地址分配给内部系统，`10.5.1x` 系统位于 DMZ 内部，`10.5.0x` 系统位于你的局域网（LAN）之外，可用于模拟安全内网、外网网或通过互联网连接。

大多数机器只有一个以太网接口，但防火墙 `fw.example.net` 和 `base.example.net` 除外。防火墙有三个接口：IP 为 `10.5.0.254` 的 `eth0`，IP 为 `10.5.1.254` 的 `eth1`，以及 IP 为 `10.5.2.254` 的 `eth2`。这些分别是用于过滤外部、DMZ 和内部系统的接口。

你的 OpenSE 基础系统 `base.example.net` 有四个重要的接口：`tap0`、`tap1`、`tap2` 和 `eth0`。正如你可能猜到的那样，`tap0` 连接外部网络，`tap1` 连接 DMZ，`tap2` 连接内部局域网。虽然起初看起来可能很困惑，但其实就像 0, 1, 2 一样简单。

这让我们看到了基础系统上的 `eth0` 接口。它用于连接 NETiVM 环境之外，通常对应于主机计算机上 VMware Player 的 `VMnet8` 接口。主机上 `VMnet8` 接口的 IP 地址将与你的基础系统处于同一子网。如果你好奇为什么你的基础系统 `eth0` 目前没有分配 IP 地址，那是因为你在第 3 步中断开了 VMware 网络适配器。

- 4. 输入 `exit` 两次。

5. 从任务栏中选择窗口列表并选择 extra Terminal 1。

6. 使用用户 root 登录，并在提示时输入 root 密码。注意，你已经在外部机器上安装了一个功能完备的 Nmap 端口扫描器。

8. 通过输入 `nmap -sS base.example.net` 执行基础 TCP SYN 扫描。注意 Nmap 足够智能，能够注意到三个 `tap` 接口并默认对 `tap0` 进行扫描，因为它在同一子网内。

9. 回到 `exa` 系统并输入 `nmap -sL 10.5.0.0/24 | less`，密切关注结果。按空格键滚动。

```

Interesting ports on base.example.net (10.5.0.1).
Not shown: 999 closed ports
PORT STATE
53/tcp open
MAC Address: CE:70:04:53:CE:21 (Unknown)
```

![](img/7868547987f5920cfe632b85047c64af_681_0.png)

此步骤执行简单的列表扫描（List scan），显示位于指定范围内的可用目标。在这种情况下，由于 /24 CIDR，该范围是 `10.5.0.x`，等同于 `255.255.255.0` 子网掩码。从扫描可以看出，外部系统比你最初认为的要多。注意，列表扫描在技术上并不是扫描，它只是对指定的 IP 范围执行了反向 DNS 查询。

## A18: 端口扫描

在本实验中，你将使用 Nmap 安全扫描器深入研究端口扫描。本实验展示了通过使用像 Nmap 工具可以从网络中获取的海量信息中的一小部分。

Nmap 的命名非常贴切，因为它是一个网络映射器，通常被称为安全/端口扫描器。Nmap 由一个自称 Fyodor 的黑客创建，是同领域最受欢迎的工具。它适用于几乎每一种操作系统。Nmap 通过操作原始 IP 数据包，通过 TCP/IP 活动栈指纹识别提供许多种结果。它可以检测 IDS/IPS 设备和防火墙，甚至提供有关目标系统上所使用的操作系统、服务和应用程序的信息。需要注意的是，虽然 Nmap 这样的工具确实会被黑帽用于不法目的，但在白帽对网络进行审计和渗透测试时，它在白帽手中是是无价的资产。顺便提一下，这段描述仅仅触及 Nmap 能力的冰角——它已经发展到包含更多极其强大的工具，如 Nping、Ncat 以及极具价值的 Nmap 脚本引擎 (NSE)，后者是多个黑帽战术和 Defcon 攻术的话题。本实验不需要额外的软件，因为 Nmap 已经安装在你的 BaseSUSE 以及各种 Debian 系统上。

- 1. 打开 VMware Player，加载 NetiVM 虚拟机。

- 2. 连接 VMware 网络适配器。这将为你提供访问互联网的权限。

- 3. 从基础系统打开 Firefox 浏览器。

- 4. 在地址栏输入 `nmap.org/usage`：
