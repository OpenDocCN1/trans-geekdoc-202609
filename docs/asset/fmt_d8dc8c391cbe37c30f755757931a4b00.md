
多重分形谱的宽度 `Δa` 是信号最强奇异性与最弱奇异性之间的差值，反映了电路信号多重分形特征的强度；多重分形特征越强，`Δa` 的值越大；对于对应极值点的奇异性指数 `a0 (fmax = f(a0))`，它反映了电路信号的随机性，随机性越大，`a0` 越大；最大概率子集与最小概率子集的分形维数之差 `Δf = f(amax) - f(amin)`，反映了电路信号最大和最小峰值频率的变化，若该值小于0，表明最大概率子集的数量大于最小概率子集的数量，反之亦然。通过上述分析可以看出，多重分形谱参数能够定量地反映故障信号在不同状态下的内在特征；因此，提出四个特征参数作为电路故障状态识别参数。

从图3可以看出，原始信号经过EEMD处理后，得到多个IMF分量。通过相关性计算选择不存在模态混叠的IMF分量。然后，计算这些IMF分量的累积偏差，接着通过滑动窗口切割累积偏差序列以获得 `N-S + 1` 个子序列，再通过对这些子序列进行多项式拟合计算均方误差函数和 `q` 阶波动函数，最后通过 `q` 阶波动函数获得故障信号的多重分形谱，从而计算多重分形谱参数作为特征值输入支持向量机。

![](img/e4200cc4308edaf8913e513b0f96dbb6_468_0.png)

## 4. 仿真实验

### 4.1. 实验流程

图4给出了基于EEMD改进MFDFA的模拟电路故障诊断流程图。

基于EEMD改进MFDFA的模拟电路故障诊断步骤如下：

- (1) 向待测电路施加激励信号，通过灵敏度分析选择故障元件，并采集不同故障模式下的输出响应用于信号预处理。
- (2) 对采集的信号数据进行EEMD分解，以获得每个IMF分量。
- (3) 使用改进的MF-DFA处理每个IMF分量，以获得故障信号多重分形谱的宽度、极值、维数差和广义Hurst指数波动均值，从而构成故障特征向量。
- (4) 使用“一对一”方法扩展SVM进行多分类。
- (5) 将训练样本输入分类器进行训练，并使用训练好的分类器对故障数据进行分类和诊断。

## 5. 结论

针对模拟电路故障信号的非线性和非平滑性导致模拟电路故障诊断特征提取困难的问题，提出了一种基于EEMD的改进型MFDFA故障诊断方法。为了避免信号混叠问题，使用EEMD分解对每个故障信号进行预处理，以获得三个无模式混淆的本征模函数（IMF）分量，然后对获得的IMF分量进行改进的多重分形去趋势波动分析（MF-DFA）处理，以获得多重分形谱。由于对应不同故障特征的多重分形谱具有不同的形状、分布和极点位置，因此可用于表征不同类型的电路故障。随后，本文利用从多重分形谱中获得的 `Af` 和 `h(q)` 构成特征向量，最后使用支持向量机（SVM）分析方法对故障特征进行分类。结果证明，所提出的基于EEMD改进的MFDFA故障特征提取方法表现出良好的性能。
