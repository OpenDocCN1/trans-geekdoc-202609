**选项 C 错误。** 虽然定期备份对于数据恢复至关重要，但它们不能直接确保虚拟机处于安全配置。

**选项 D 错误。** 多因素身份验证是访问资源的重要措施，但它不能确保虚拟机以安全配置部署。

### 问题 350
一家跨国公司正在其不同国家的数据中心部署一组新服务器。应该采取以下哪项步骤，以确保服务器免受潜在威胁？

(A) 设置监控系统以向 IT 团队报告异常活动
(B) 部署公司未来可能需要的所有应用程序
(C) 使用服务器的默认配置以维护制造商的最佳实践
(D) 禁用服务器上任何不必要的服务和端口

**解析 350。正确答案：D. 禁用服务器上任何不必要的服务和端口。** 在设置新服务器时，减少攻击面至关重要。禁用不必要的服务和端口可以确保服务器上只运行必要的的服务，减少潜在漏洞。

**选项 A 错误。** 虽然监控对于安全至关重要，但在设置监控系统之前，更重要的是加固服务器以减少漏洞。监控应该是加固措施的补充。

**选项 B 错误。** 部署公司未来可能需要的所有应用程序可能会引入不必要的漏洞和开销。最好只安装精简的内容。

**选项 C 错误。** 依赖服务器的默认配置是有风险的，因为它可能未针对组织的特定需求进行调整，且可能开启必要的端口。

### 问题 351
在分析公司 Web程序的漏洞时，安全团队参考特定的 CVE 以了解漏洞详情。他们进一步评估 CVSS 分数以决定修复的紧急性。以下哪项最能描述 CVE 和 CVSS 的用途？

- (A) CVE 提供严重评分，而 CVSS 为漏洞提供唯一标识
- (B) CVE 和 CVSS 都提供用于划分漏洞的评分机制
- (C) CVE 提供唯一标识，而 CVSS 提供标准的严重评分
- (D) CVE 和 CVSS 是所有应用程序的监管要求

**解析 351。正确答案：CVE 提供唯一标识，而 CVSS 提供标准的严重评分。** CVE（常见漏洞与披露）为漏洞提供了标准的标识符，确保了清晰的通信和参考。CVSS（漏洞评分系统）提供了一种评估漏洞严重程度的标准方法，使组织能够优先修复。

**选项 A 错误。** 恰恰相反。CVE 提供唯一标识，而 CVSS 提供严重评分。
