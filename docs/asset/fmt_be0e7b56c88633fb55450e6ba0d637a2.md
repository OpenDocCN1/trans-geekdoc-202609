## 9.1 简介

在第 3 章中，正则化的概念被引入作为一种工具，用于解决机器学习中通常遇到的许多问题。通过收缩最小方差无偏 (MVU) 估计量的范数来提高估计量的性能、防止过拟合、应对病态条件以及为欠定方程组提供解，这些都是正则化提供成功答案的一些显著例子。其中一些优势通过岭回归概念得到了演示，其中平方误差和代价函数按权衡原理与期望解的平方欧几里得范数相结合。

在本章和下一章中，我们的兴趣将集中在欧几里得范数的替代方案上，特别是将围绕 `ℓ₁` 范数展开；这是构成向量的各分量绝对值之和。虽然通过代价函数的 `ℓ₁` 范数正则化来寻求问题的解自 1970 年代以来就已为人所知并被使用，但花了近三十年才成为压缩感知背景下大量研究关注的焦点。该问题的核心在于一个欠定线性方程组，它通常接受无限多个解。然而，在许多情况下，有一条额外的信息可用：我们要估计的真实模型是稀疏的；即其只有少数坐标是非零的。事实证明，大量常用应用都可以归入这种场景，并能从稀疏建模中受益。

除了其实际意义外，稀疏感知学习还为科学界提供了新颖的理论工具和解决方案，解决了几年前似乎难以解决的问题。这也是该领域成为一门跨学科研究领域的原因，涵盖了来自数学、统计学、机器学习和信号处理等领域的科学家。此外，它已经应用于从生物医学到通信和天文学等许多领域。在本章和接下来的章节中，我努力以统一的方式呈现贯穿该领域的基本概念和思想。目的是为读者提供一个概览，了解在理论和算法前沿发生的主要贡献，这些贡献已巩固为一个独特的科学领域。

在本章中，重点是介绍与稀疏感知学习技术相关的主要概念和理论基础。我们首先回顾各种范数。然后我们继续建立利用少于相应空间维度的观测值来恢复稀疏向量（或在变换域中稀疏的向量）的条件。几何学在我们的方法中发挥着重要作用。最后，介绍了一些将稀疏性与采样理论联系起来的理论进展。在本章末尾，将讨论一个关于图像去噪的案例研究。

## 9.2 寻找一种范数

数学家们在提出各种范数以赋予线性空间结构方面发挥了极大的想象力。泛函分析中使用的最流行的范数中包括 `ℓₚ` 范数。为了适应我们的需求，给定向量 `θ ∈ ℝˡ`，其 `ℓₚ` 范数定义为

### Lp 范数定义

$$ \left\| \mathbf{\theta} \right\|_{p} := \left( \sum\limits_{i = 1}^{l}|\theta_{i}|^{p} \right)^{1/p}. \tag{9.1} $$

当 $p = 2$ 时，得到欧几里得范数或 $\ell_2$ 范数；当 $p = 1$ 时，公式 (9.1) 给出 $\ell_1$ 范数，即：

$$ \left\| \mathbf{\theta} \right\|_{1} = \sum\limits_{i = 1}^{l}|\theta_{i}|. \tag{9.2} $$

若令 $p \to \infty$，则得到 $\ell_\infty$ 范数。设 $|\theta_{i_{\max}}| := \max\{|\theta_1|, |\theta_2|, \dots, |\theta_l|\}$，注意到：

$$ \left\| \mathbf{\theta} \right\|_{\infty} := \lim\limits_{p\rightarrow\infty}\left( |\theta_{i_{\max}}|^{p}\sum\limits_{i = 1}^{l}\left( \frac{|\theta_{i}|}{|\theta_{i_{\max}}|} \right)^{p} \right)^{1/p} = |\theta_{i_{\max}}|. \tag{9.3} $$

即 $\|\boldsymbol{\theta}\|_\infty$ 等于 $\boldsymbol{\theta}$ 坐标绝对值的最大值。可以证明，对于 $p \ge 1$，所有 $\ell_p$ 范数都是真正的范数；即满足函数 $\mathbb{R}^l \mapsto [0, \infty)$ 要被称为范数必须遵守的四个要求：

1. $\|\boldsymbol{\theta}\|_p \ge 0$，
2. $\|\boldsymbol{\theta}\|_p = 0 \iff \boldsymbol{\theta} = \mathbf{0}$，
3. $\|\alpha\boldsymbol{\theta}\|_p = |\alpha|\|\boldsymbol{\theta}\|_p, \forall \alpha \in \mathbb{R}$，
4. $\|\boldsymbol{\theta}_1 + \boldsymbol{\theta}_2\|_p \le \|\boldsymbol{\theta}_1\|_p + \|\boldsymbol{\theta}_2\|_p$。

第三个条件强制范数函数为（正）齐次，第四个条件是三角不等式。这些性质也保证了任何作为范数的函数也是凸函数（问题 [9.3]）。严格来说，如果我们在公式 (9.1) 中允许 $p > 0$ 取小于 1 的值，所得函数就不是真正的范数（问题 9.8），但我们仍可称之为范数，尽管我们知道这是对范数定义的滥用。一个将在本章中大量使用的有趣情况是 $\ell_0$ 范数，它可以作为 $p \to 0$ 时的极限获得：

```
\|\boldsymbol{\theta}\|_0 := \lim_{p \to 0} \|\boldsymbol{\theta}\|_p^p = \lim_{p \to 0} \sum_{i=1}^l |\theta_i|^p = \sum_{i=1}^l \chi_{(0,\infty)}(|\theta_i|),
``` (9.4)

其中 $\chi_{\mathcal{A}}(\cdot)$ 是关于集合 $\mathcal{A}$ 的特征函数，定义为

$$

\chi_{\mathcal{A}}(\tau): = \begin{cases} 

1, & \text{若 } \tau \in \mathcal{A}, \\ 

0, & \text{若 } \tau \notin \mathcal{A}. 

\end{cases}

$$

也就是说，$\ell_0$ 范数等于相应向量中非零分量的个数。很容易验证该函数不是真正的范数。确实，它不具备齐次性，即 $\|\alpha\boldsymbol{\theta}\|_0 \neq |\alpha|\|\boldsymbol{\theta}\|_0$，$\forall |\alpha| \neq 1$。图 9.1 显示了二维空间中对应于 $\|\boldsymbol{\theta}\|_p = 1$ 的等值曲线，其中 $p = 0, 0.5, 1, 2$ 和 $\infty$。可以观察到，对于欧几里得范数，等值曲线呈圆形；而对于 $\ell_1$ 范数，则呈菱形。我们分别称它们为 $\ell_2$ 球和 $\ell_1$ 球，这里稍微“滥用”了球的含义。^(⁶¹)

![图 9.1 \left\| \mathbf{\theta} \right\|_{p} = 1Equation 时的等值曲线，针对二维空间中的各种 p 值。观察到对于 ℓ0 范数，相应的值覆盖两个轴，但不包括点 (0,0)。对于 ℓ1 范数，等值曲线是一个菱形，而对于 ℓ2（欧几里得）范数，它是一个圆。](img/gr001.jpg)

## 9.3 最小绝对收缩和选择算子（LASSO）

图 9.2 展示了 `|θ|^p` 的图形，即向量各分量对 `ℓ_p` 范数的单独贡献，针对不同的 `p` 值。观察可知：(a) 对于 `p < 1`，图形上方形成的区域（超图，见第 8 章）不是凸集，这验证了我们之前所说的，即相应函数不是真正的范数；(b) 对于自变量值 `|θ| > 1` 的情况，`p ≥ 1` 的值越大且 `|θ|` 的值越大，相应分量对范数的贡献就越高。因此，如果在正则化方法中使用 `ℓ_p` 范数（`p ≥ 1`），数值较大的分量会成为主导分量，优化算法将集中于这些分量，通过惩罚使其变小以便降低总代价。对于值 `|θ| < 1` 的情况则相反；`ℓ_p`、`p > 1` 范数倾向于将此类分量的贡献推向零。`ℓ_1` 范数是在 `p ≥ 1` 中唯一一个即使对于 `|θ| < 1` 的小值也能保持相对较大值的范数，因此，数值较小的分量仍能在优化过程中发挥作用，并可通过被推向更小的值而受到惩罚。因此，如果在公式 (3.41) 中用 `ℓ_1` 范数替代 `ℓ_2` 范数，*只有那些在正则化代价函数中真正对减小模型拟合误差测度项有显著贡献的参数向量分量会被保留，其余将被强制为零*。对于 `0 ≤ p < 1`，同样的趋势也存在，但更为激进。极端情况是考虑 `ℓ_0` 范数时。即使分量从零处的微小增加也会使其对范数的贡献变大，因此优化算法在使某元素非零时必须非常“谨慎”。

图 9.2 观察到超图，即图形上方的区域，对于 `p < 1` 的值是非凸的，表明相应的 `|θ|^p` 函数是非凸的。`p = 1` 是保持凸性的最小值。还要注意，对于较大的 `p > 1` 值，`|θ| < 1` 的小值对相应范数的贡献变得微不足道。

简而言之，在所有真正的范数（`p ≥ 1`）中，`ℓ_1` 是唯一一个“尊重”小值的范数。其余 `p > 1` 的 `ℓ_p` 范数只是挤压小值使其变得更小，主要关注大值。我们马上会回到这一点。

### 正则化方法的进一步理由

在第 3 章中，我们讨论了采用正则化方法来增强估计器性能的一些好处。在本章中，我们将看到并研究更多理由来证明使用正则化的合理性。

#### 估计器的解释能力

第一个理由涉及估计器的**解释**能力。例如，在回归任务中，我们希望选择那些在输出变量形成中起最重要作用的 `θ` 分量 `θ[i]`。如果参数数量 `l` 很大，而我们想集中关注最重要的参数，这一点就非常重要。在分类任务中，并非所有特征都有信息量，因此人们希望保留最有信息量的特征，并使信息量较小的特征等于零。

另一个相关问题是：我们预先知道参数向量的某些分量为零，但不知道是哪些。现在，上一节末尾的讨论变得更有意义了。我们能否在正则化时，使用一个合适的范数来辅助优化过程：

(a) 揭示这些零值，或

(b) 更强调那些在正则化代价函数中对减小拟合误差项起决定性作用的最显著分量，并将其余分量设为零？

虽然 `ℓ[p]` 范数（`p < 1`）似乎是此类正则化的自然选择，但它们非凸的性质使得优化过程变得困难。`ℓ[1]` 范数是最“接近”它们的，却保留了凸性这一计算上极具吸引力的特性。

#### ℓ[1]范数的历史应用

`ℓ[1]` 范数长期以来一直用于此类问题。在 20 世纪 70 年代，它被用于地震学 [27, 86]，那里反射的信号指示了各种地球底层的变化，是一个稀疏信号，即极少数值相对较大，其余则微小且无关紧要。此后，它被用于解决不同应用中的类似问题（例如 [40, 80]）。然而，可以追溯到两篇论文，它们为 `ℓ[1]` 范数引起的强烈兴趣提供了催化火花。一篇来自统计学界 [89]，讨论了 LASSO 任务（据我们所知，首次在 [80] 中提出），将在下文讨论；另一篇来自信号分析界 [26]，提出了基追踪，将在后面章节讨论。

#### 回归任务中的应用

我们首先处理熟悉的回归任务：

```
y = Xθ + η,  y, η ∈ ℝ^(N),  θ ∈ ℝ^(l),  N ≥ l
```

并通过由 `ℓ[1]` 范数正则化的平方误差和代价，获得未知参数向量 `θ` 的估计，即对于 `λ ≥ 0`，

```
θ̂ := arg min_{θ ∈ ℝ^l} L(θ, λ)  (9.5)
```

$$

\widehat{\boldsymbol{\theta}} = \arg\min_{\boldsymbol{\theta} \in \mathbb{R}^{l}} \left( \sum_{n=1}^{N} \left( y_n - \mathbf{x}_n^T \boldsymbol{\theta} \right)² + \lambda \lVert \boldsymbol{\theta} \rVert_1 \right) = \arg\min_{\boldsymbol{\theta} \in \mathbb{R}^{l}} \left( \left( \mathbf{y} - X\boldsymbol{\theta} \right)^T \left( \mathbf{y} - X\boldsymbol{\theta} \right) + \lambda \lVert \boldsymbol{\theta} \rVert_1 \right).

$$
