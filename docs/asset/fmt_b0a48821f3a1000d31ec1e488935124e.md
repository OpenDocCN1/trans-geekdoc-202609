
### 备注 18.6

*   **深层 RNN**：除了包含单层状态的基本 RNN 网络外，还提出了涉及多层状态（一层叠在另一层之上）的扩展（参见，例如 [155]）。

*   **双向 RNN**：顾名思义，在双向 RNN 中，存在两个状态变量，即一个记为 $\overset{\rightarrow}{\mathbf{h}}$，向前传播；另一个记为 $\overset{\leftarrow}{\mathbf{h}}$，向后传播。这样，输出就取决于过去和未来两者（参见，例如 [56]）。

### LSTM 网络：信息流控制

LSTM 网络具有内置能力，可通过称为 `gates`（门）的非线性元件来 `control`（控制）信息流入和流出系统的 `memory`（记忆/存储单元）。这些门通过 logistic sigmoid 非线性函数和一个乘法器来实现。从算法角度来看，这些门等同于对相关信息流施加 `weighting`（加权）。权重位于 `[0,1]` 范围内，并取决于激活 sigmoid 非线性函数的相关变量的值。换句话说，信息的加权（控制）是在 `context`（上下文）中进行的。根据这种基本原理，网络具有敏捷性，能够遗忘已被使用且不再需要的信息。

基本 LSTM 单元/单位如图 18.36 所示。它围绕两组变量构建，这两组变量堆叠在向量 `**s**` 中，称为细胞状态或单元状态，以及向量 `**h**` 中，称为隐藏变量向量。LSTM 网络建立在该基本单元的连续 `concatenation`（拼接/串联）之上。对应于时间 `n` 的单元，除了接收输入向量 **x**[n] 外，还从上一阶段接收 **s**[n − 1] 和 **h**[n − 1]，并将 **s**[n] 和 **h**[n] 传递给下一阶段。

![Figure 18.36 The LSTM unit. Note that in this case, there are two types of memory-related variables that are propagated, i.e., the cell state vector, s, and the hidden variables vector, h. The involved bias vectors are not shown to unclutter notation.](img/gr036.jpg)

图 18.36 LSTM 单元。请注意，在这种情况下，有两类与记忆相关的变量被传播，即细胞状态向量 `***s***` 和隐藏变量向量 `***h***`。为使符号表示简洁明了，未显示涉及的偏置向量。

相关的更新方程总结如下，

#### LSTM 核心公式

$$
\mathbf{f} = \sigma\left( U^{f}\mathbf{x}_{n} + W^{f}\mathbf{h}_{n - 1} + \mathbf{b}^{f} \right),\\
\mathbf{i} = \sigma\left( U^{i}\mathbf{x}_{n} + W^{i}\mathbf{h}_{n - 1} + \mathbf{b}^{i} \right),\\
\widetilde{\mathbf{s}} = \tanh\left( U^{s}\mathbf{x}_{n} + W^{s}\mathbf{h}_{n - 1} + \mathbf{b}^{s} \right),\\
\mathbf{o} = \sigma\left( U^{o}\mathbf{x}_{n} + W^{o}\mathbf{h}_{n - 1} + \mathbf{b}^{o} \right),\\
\mathbf{s}_{n} = \mathbf{s}_{n - 1} \circ \mathbf{f} + \mathbf{i} \circ \widetilde{\mathbf{s}},\\
\mathbf{h}_{n} = \mathbf{o} \circ \tanh(\mathbf{s}_{n})
$$

其中 `∘` 表示向量或矩阵之间的逐元素乘积（Hadamard 积），即 `(\mathbf{s} \circ \mathbf{f})[i] = s[i]f[i]`。

`σ` 表示 Logistic Sigmoid 函数。

观察到单元状态 `s` 将直接信息从上一时刻传递到下一时刻。该信息首先由第一个门控制，根据 `f` 中的元素进行调节，这些元素的取值范围为 [0,1]，取决于当前输入和从上一阶段接收到的隐变量。这就是我们之前所说的，即加权在“**上下文**”中进行调整。接下来，新信息（即 $\widetilde{\mathbf{s}}$）被加到 **s**[n − 1] 上，这也由第二个 Sigmoid 门网络（即 `i`）控制。因此，保证了来自过去的信息以直接方式传递到未来，这有助于网络记忆信息。事实证明，与基本 RNN 结构相比，这种类型的记忆能更好地利用数据中的长距离依赖关系。隐变量向量 `h` 由单元状态以及输入和前一状态变量的当前值共同控制。所有涉及的矩阵和向量都通过训练阶段学习得到。注意，有两条与 **h**[n] 相关的线。右侧的一条通向下一阶段，顶部的一条用于在时刻 *n* 通过（例如）Softmax 非线性函数提供输出 ${\widehat{\mathbf{y}}}_{n}$，这与公式 (18.68) 中的标准 RNN 类似。

除了前面讨论的 LSTM 结构外，还提出了许多变体。关于不同 LSTM 和 RNN 架构的广泛比较研究可参见文献 [59,95]。

RNN 和 LSTM 已成功应用于广泛领域，如语言建模（如 [196]）、机器翻译（如 [124]）、语音识别（如 [57]）、用于生成图像描述符的机器视觉（如 [97]）以及 fMRI 数据分析以掌握相关脑网络中的时间动态（如 [180]）。例如，在语言处理中，输入通常是一个词序列，这些词被编码为数字（这些是指向可用词典的指针）。输出是待预测的词序列。训练期间，设定 **y**[n] = **x**[n + 1]。即网络被训练为非线性预测器，见第 19.3.2 节。

## 18.13.2 Attention and memory

神经网络中 `attention` 机制的使用有着相当长的历史（参见如 [37]）。顾名思义，“注意力”概念借鉴了人类注意力机制的思想。例如，我们的视觉系统赋予我们能力，使我们能更多地关注场景中驻留的最重要信息；这些信息处于*上下文*中；即它取决于我们想要寻找的内容。在机器学习中，已经提出了许多不同的模型来实现注意力概念。

最流行的路径之一是对输出所依赖的各种变量应用一种加权（变换）类型。这些权重在训练期间被*学习*。让我们以 RNN 为例。在其基本形式中，正如之前讨论的，输出 ${\widehat{\mathbf{y}}}_{n}$ 依赖于对应的状态向量 **h**[n]。然而，尽管状态向量编码/总结了直到最近时刻 *n* 的系统记忆，但这不一定是某些任务所需最重要的信息。事实上，假设在机器语言翻译系统的长输入序列中，最近的状态向量是获得可靠输出最具代表性的信息，这是相当不合理的。一个典型的例子是从日语翻译成英语时，日语句子的最后一个词可能对其英语翻译的第一个词具有高度预测性。同样在生活中，我们在特定时刻决定采取什么行动很大程度上取决于我们过去的总体经验。然而，过去某些特定经验的影响可能比最近的经验强得多。

为了处理此类情况，可以采用注意力机制，使时刻 *n* 的输出依赖于直到时刻 *n* 所有先前状态向量的*加权组合*，并让系统在学习阶段学习权重值。因此，在训练期间，系统将决定输出应基于哪条最重要的信息。也就是说，系统学会“关注”最重要的上下文信息。

例如，输出向量可以修改为依赖于所有先前计算的状态向量，即

```
${\widehat{\mathbf{y}}}_{n} = f\left( \sum\limits_{i = 1}^{n}\alpha_{ni}\mathbf{h}_{i} + \mathbf{c} \right),$
```

其中 `α[n_i]` 是时刻 `n` 对应的权重。上述结合所有先前状态向量的思想已在文献 [6] 所述的机器翻译系统中得到采用，尽管其形式略有不同（另见第 19.3.2 节）。

图 18.37 摘自前述文献，阐释了采用加权机制的基本原理。法语单词为输入，英语单词为对应的输出序列。相应注意力权重的值以像素形式可视化；权重越大，像素越白。例如请注意，输出单词 “produce” 是对三个连续时刻的信息加权得到的结果，这三个时刻对应单词 “peut plus produire”，而单词 “destruction” 对应两个单词，即 “la destruction”。

![Figure 18.37 The values of the attention weights in grayscale, showing the degree of dependence of the words in the output sequence (English) to those of the input sequence (French) (from [6]). Note, for example, that in order to produce the word “Syria,” the network “attends” the words “La Syrie.”](images/B978044329238500024X/gr037.jpg)

图 18.37 灰度图显示了注意力权重的值，反映了输出序列（英语）中的单词对输入序列（法语）中单词的依赖程度（源自 [6]）。例如请注意，为了生成单词 “Syria”，网络会 “关注” 单词 “La Syrie”。

在文献 [220] 中，带有注意力机制的网络被用于图像描述的自动生成。在所述系统中，采用一种 CNN 网络的变体来生成一组特征向量。每个特征向量对应原始图像的一个 `portion`（区域）。这一步骤相当于原始图像的一个 `encoding`（编码）阶段。这些向量进而被用于形成 LSTM 网络的输入序列，其中采用了注意力权重。该网络被训练以根据 LSTM 状态计算输出单词的概率。图 18.38 摘自 [220]，展示了模型在生成单词时 “关注” 的图像部分。

将注意力机制集成到模型中的一个有趣之处在于，可以追踪模型的行为以及输出信息是如何形成的；当网络的可解释性问题变得重要时，这很有用。也就是说，理解网络做出决策的 “原因” 和 “方式”。关于相关讨论，请参阅例如 [179]。

实现注意力的不同路径也是可能的。在文献 [58] 中，提出了所谓的 `neural Turing machine`（NTM，神经图灵机），其中记忆模块与神经网络（前馈或 LSTM）并行应用。一种 `learnable`（可学习）的注意力机制被用于有选择地对记忆进行读写。涉及强化学习技术的 NTM 扩展见文献 [224]。在文献 [194,217] 中，由输入数据生成的记忆被允许在产生输出前被读取多次。这类似于基于记忆内容进行多步推理；即基于输入的 “故事” 进行推理。

## 18.14 对抗样本

在本版编撰之时，深度神经网络在性能和准确率方面处于最先进水平，往往可与人类相媲美，有时甚至超越人类。然而，我们似乎尚不具备断言这些模型真正 “理解” 其 “学会” 执行的任务的地位；尽管例如它们可以在分类任务中以极高的概率预测正确标签。文献 [200] 表明，可以构造 `adversarial`（对抗）样本，`consistently`（持续/稳定地）欺骗机器学习模型。“对抗性” 一词意味着可以有意在输入集的模式上施加 `small worst-case`（微小的最坏情况）扰动，从而导致模型以高概率预测错误标签。最有趣的是，这种微小噪声扰动的添加，在图像情况下（如 [200]）几乎难以被人眼察觉，在音乐情况下（如 [100,192]）几乎难以被人耳察觉。图 18.39（摘自 [200]）总共展示了九幅图像。一个神经网络（AlexNet）已被训练用于识别图像内容。左侧三幅图像取自相应的测试集，均被正确识别。中间的图像是添加到左侧对应图像上的噪声图像。结果图像显示在右侧。人类预测正确标签毫无困难。然而，AlexNet 将这三幅图像全部分类为 “ostrich, struthio camelus”（鸵鸟）类别！

![Figure 18.39 The images on the left have been classified correctly. All the images on the right have been classified as “ostrich, Struthio camelus”! The images in the center show the noise (after some magnification) added to obtain the images on the right (example taken from [200]).](images/B978044329238500024X/gr039.jpg)

图 18.39 左侧的图像已被正确分类。右侧的所有图像均被分类为“鸵鸟，Struthio camelus”！中间的图像显示了添加的噪声（经过一定放大），正是这些噪声产生了右侧的图像（示例取自 [200]）。

生成对抗样例有多种方法。在 [200] 中，采用了一种优化任务，寻找能导致标签改变的最小扰动。在 [54] 中，扰动沿着代价函数关于输入模式的梯度符号方向进行。在 [138] 中，提出了一种构造 `universal`（通用）微小扰动的方法，该扰动能以高概率导致数据集中所有图像被误分类。

看来，这种“奇怪”行为的核心在于输入空间的高维性。通常情况下，人们预期在学习任务中，`smoothness`（平滑性）假设是成立的。也就是说，对于足够小的正数 `ϵ` 和输入模式 `x`，我们预期对于任意满足 `||v|| ≤ ϵ` 的 `v`，模式 `x' := x + v` 会以高概率被分配到与 `x` 相同的类别。高维性对平滑性条件的影响在线性分类器的情况下很容易看出（参见例如 [54]）。设训练好的分类器由其参数 `θ` 描述。给定输入模式 `x`，标签根据内积 `θ^(T)x` 的符号计算。对于 `x'` 的情况，内积由 `θ^(T)x' = θ^(T)x + θ^(T)v` 给出。现在让我们有意设定 `v = ± ϵ sgn(θ)`，其中符号操作以逐元素的方式作用。结果发现

```
θ^T x' = θ^T x + θ^T v = θ^T x ± ε∑_{i=1}^{l}|θ_i|.
```

因此，如果输入维度 `l` 很大，相应内积值之间预期会出现较大偏差，这可能导致 `x` 和 `x'` 被预测为不同的标签。简而言之，线性与高维性的结合违反了平滑性假设。

当例如采用 `ReLU` 或涉及的非线性在其线性区域工作时，上述解释可以推广到深度网络。文献 [45,138] 提供了一种解释对抗现象的替代几何观点。文中指出，对抗样例的核心在于一些独特的几何属性，这些属性与施加的扰动以及决策边界不同部分之间的几何相关性有关。他们的分析展示了一般随机噪声与最坏情况对抗扰动之间的区别。
