
# Windows 网络命令

- `/release`：向 DHCP 服务器发送 DHCPRELEASE 消息以释放当前的 DHCP 配置，并丢弃所有适配器（未指定适配器）或在包含 `Adapter` 参数时针对特定适配器的 IP 配置。
- `/renew`：为所有适配器（未指定适配器）或在包含 `Adapter` 参数时针对特定适配器刷新 DHCP 配置。此参数仅适用于配置为自动获取 IP 地址的带有适配器的计算机。
- `/flushdns`：刷新 DNS 客户端缓存内容。在 DNS 故障排除期间，可以使用此过程丢弃缓存中的负条目以及任何其他条目。
- `NETSH`：命令行脚本实用程序，允许管理员显示或修改网络配置。
- `NETSTAT`：报告 TCP 连接、监听表和接口统计信息。
- `PING`：通过发送 ICMP Echo 请求消息验证 IP 连通性。
- `TRACERT`：通过发送 ICMP Echo 请求消息确定到目的地的路径。

## A8：购买 Wi-Fi 天线

正确的放置和天线选择对于为 Wi-Fi 客户端获得最佳性能和安全性至关重要。在接入点上安装更好的天线可以极大地增加范围。接入点带有固定的、可拆卸或内部天线。如果天线是可拆卸的，安装人员可以将其替换为提供不同增益或传输模式的天线。带有内部天线的无线路由器不允许你更换天线以获得更强的信号。对于这些系统，可以安装带电源的信号中继器来扩大范围。在对无线网络做出明智决策时，管理员必须了解可用的技术。有特殊的认证，CAS 必须熟悉天线类型和分贝。你这里的重点是根据无线现场勘测确定的需求，将接入点的可拆卸天线替换为更好的天线。

全向天线在小型办公室、家庭办公（SOHO）企业级接入点中很常见。无线信号向所有方向（360°）辐射。其形状在顶部和底部扁扁的，两侧信号较强。这更像一个甜圈而不是球体。天线被认为像棒子，有时被称为“胶鸭”（rubber ducks），因为它们具有弹性且涂有橡胶。出厂安装的全向天线通常增强约 3 分贝（dB）的信号。2 GHz 频段的范围认为约为 100 米。相同的天线通常用于 5 GHz 频段的传输。你可以将其比作带有灯罩的台灯的光。全向天线通常用于对多点连接。

天线增益（增加）用分贝测量。分贝尺度是一个对数刻度，用于表示一个功率值与另一个功率值之间的比例。分贝越高，信号输出越强。

方向是传输模式的形状。对天线的一个很好的比喻是手电筒中的反射器。反射器将光束集中并加强在特定方向，类似于八木天线或碟形天线对 Wi-Fi RF 信号的作用。定向天线有不同的样式和形状。天线并不放大或增强信号；它只是重定向从发射器接收到的能量。定向天线可以将更多能量集中在一个方向，而在所有其他方向较少。随着定向天线增益的增加，信号传输的角度减小。定向天线提供更大的范围，但覆盖角度会减小。这就像带有反射器的台灯产生的光锥。

定向 Wi-Fi 天线有三种基本类型：

- 贴片式或面板式天线向单方向广播，通常用于多个用户。
- 八木天线用于远距离点对点连接，通常位于建筑之间。
- 抛物面（如卫星天线）或网格天线具有非常窄的 RF 能量，必须仔细对准接收天线。它们聚焦成几乎像激光一样的窄波束，用于户外建筑之间的远距离点对点连接。

2. 通过选择左侧的 Computer Networking Antennas（计算机网络天线）缩小范围。
3. 继续选择 2.4 GHz 和三星或以上的评价来更具选择性。
4. 通过右上角的下拉菜单选择 Low to High（价格从低到高）对天线进行排序。
5. 10 美元以下你会看到几种胶鸭全向天线。由于信号损耗高，它们通常不使用电缆，而是直接连接到无线路由器或 AP。
6. 向下滚动查看一些较贵的天线。你会看到一些面板式和抛物面定向天线。
7. 20 美元以下你会看到几种胶鸭全向天线。由于信号损耗高，它们通常不使用电缆，而是直接连接到无线路由器或 AP。

## A9：云端配置

运行在租赁硬件上的虚拟服务器为测试或在 Web 上提供快速部署资源提供了一种极佳的方法。这是一个快速变化的领域，因此你可能需要寻找与指定的不同的站点。

Google Compute Engine 是一个提供在 Google 基础设施（池化服务器和存储）上运行虚拟机的服务。你可以在这里看到一个如何设置功能 Web 服务器的视频：

等等，链接是：

目前的一些云提供商包括 Amazon、Google、HP、IBM、Microsoft、Red Hat 和 VMware。熟悉他们提供的服务是一个好主意。大多数系统都将有让你注册其服务“免费”试用的方法。可能需要有效的电子邮件帐户和信用卡信息。购物并比较一下，本周谁提供的自助服务优惠最好？

美国国家标准与技术研究院（NIST）开发了许多重要的 IT 标准。对云计算等当前主题进行一些研究：

http://csrc.nist.gov/publications/PubPS.html

NIST 目前关于云的定义指出，“云计算是一种模型，能够通过便利的按需网络访问共享的可配置资源池（例如网络、服务器、存储、应用程序和服务），并能够以最少的管理工作或服务提供商交互快速配置和释放。”

这种云模型促进了可用性并由五个基本特征组成：

- 按需自服务
- 广网访问
- 资源池
- 快速弹性
- 可计量（计量）服务

云的三种服务模型为：

- 云软件服务 (SaaS)
- 云平台服务 (PaaS)，一种在弹性云环境中自动执行应用程序栈托管、配置、部署和管理的云应用程序平台
- 云基础设施服务 (IaaS)

四种常见的云部署模型为：

- 私有云
- 社区云
- 公有云
- 混合云

以下是云的关键赋能技术：

- 高速广域网
- 强大且廉价的服务器计算机
- 针对通用硬件的高性能虚拟化
