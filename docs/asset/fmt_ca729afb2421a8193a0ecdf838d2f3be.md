### TCP 连接扫描 (-sT)

TCP 连接扫描（TCP connect scan）是确定端口活动最可靠的方法，它会执行完整的 TCP 三次握手，如图 10.9 所示。TCP 连接扫描的缺点是，确认应用程序是否存在所需的流量要大得多，并且可能会被入侵检测系统（IDS）注意到。它的优点是，在 TCP 连接扫描之后，我们能够确定确定某个应用程序是否真的存在。

## 边界规避扫描

在扫描系统或网络网段时，Nmap 有许多不同的选项可以使用；其中某些选项旨在规避防火墙，这正是前面提到的控制位发挥用场的地方。在 Nmap 扫描器中激活不同控制位的扫描类型如下：

- **ACK 扫描 (-sA)**：这会开启 ACK 位。这种扫描将向目标系统发送一个 ACK，希望防火墙会假设攻击者与目标系统之间已经存在一个通信通道。
- **Fin 扫描 (-sF)**：这种扫描开启 FIN 位，该位本应出现在有状态 TCP 会话的结束时。向目标系统发送一个 FIN，希望防火墙会假设攻击者与目标系统之间已经存在一个通信通道。无状态防火墙通常只过滤 SYN 数据包，因此无关的 FIN 可能会被忽略。
- **空包扫描 (-sN)**：“空（Null）”攻击是指发送 TCP 数据包时将所有控制位设置为零。将数据包发送到目标系统，希望某些东西会对数据包产生反应——最好是目标系统。无状态防火墙通常只过滤 SYN 数据包，因此这个空包可能会被忽略。
- **圣诞树扫描 (-sX)**：圣诞树攻击是开启 TCP 数据包中每一个标志位（flag）的攻击。由于激活所有控制位的数据包在 TCP 协议没有任何意义，无状态防火墙可能会允许攻击通过，因为它们通常只过滤 SYN 数据包，并且可能没有寻找这种类型的异常。这四种扫描都用于检测处于激活的系统和协议，但它们是通过不符合标准通信实践的方式操纵 TCP 协议来实现的。

## 被动操作系统指纹识别

被动识别目标系统的操作系统需要大量的耐心。被动操作系统指纹识别的目标是隐蔽地捕获包含窗口大小和生存时间（TTL）信息的 TCP 数据包，然后通过分析数据包手动猜测操作系统。问题是，对网络的被动攻击有时是困难的——除非目标系统需要直接与攻击系统通信（这使得攻击超出了“被动”的定义），或者攻击系统能够收集跨网络传输的所有数据包，否则没有简单的方法获取所需的数据。
