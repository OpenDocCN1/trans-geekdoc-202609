该优化也分两步进行。首先，`a` 被视为固定，我们针对 `**θ**` 进行优化，

```
\mathbf{\theta}_{\mathbf{i}} = \arg\min\limits_{\mathbf{\theta}}\sum\limits_{n = 1}^{N}w_{n}^{(i)}\exp\left( - y_n a\phi(\mathbf{x}_n;\mathbf{\theta}) \right),

```

观察到 $w_n^{(i)}$ 既不依赖于 $a$ 也不依赖于 $\phi(\mathbf{x}_n; \boldsymbol{\theta})$；因此它可以被视为与样本 $n$ 相关联的权重。此外，其值完全取决于前几次递归获得的结果。

我们现在将重点转移到公式 (7.89) 中的代价上。优化取决于基分类器的具体形式。然而请注意，损失函数呈指数形式。此外，基分类器是二元的，因此 $\phi(\mathbf{x}; \boldsymbol{\theta}) \in \{-1, 1\}$。如果我们假设 $a > 0$（稍后我们将回到这一点），则公式 (7.89) 的优化很容易被看出等价于

$$

\boldsymbol{\theta}_i = \arg\min_{\boldsymbol{\theta}} P_i,

\tag{7.91}

$$

其中

$$

P_i := \sum_{n=1}^N w_n^{(i)} \chi_{(-\infty,0]}\left( y_n \phi(\mathbf{x}_n; \boldsymbol{\theta}) \right),

\tag{7.92}

$$

而 $\chi_{(-\infty,0]}(\cdot)$ 是 0-1 损失函数。^(⁴⁸)

计算出最优 $\boldsymbol{\theta}_i$ 后，根据各自的定义可以容易地建立以下关系：

$$

\sum_{y_n \phi(\mathbf{x}_n; \boldsymbol{\theta}_i) \leq 0} w_n^{(i)} = P_i

\tag{7.93}

$$

以及

$$

\sum_{y_n \phi(\mathbf{x}_n; \boldsymbol{\theta}_i) > 0} w_n^{(i)} = 1 - P_i.

$$

将公式 (7.93) 和 (7.94) 与公式 (7.88) 和 (7.90) 相结合，可轻易证明

```
a_i = \arg\min_a \left\{ \exp(-a)(1 - P_i) + \exp(a)P_i \right\}.
```

对 `a` 求导并令其为零，可得

```
a_i = \frac{1}{2}\ln\frac{1 - P_i}{P_i}.
```

注意，如果 `P[i] < 0.5`，则 `a[i] > 0`，这在实践中是预期的情况。一旦估计出 `a[i]` 和 `θ[i]`，下一次迭代的权重即可通过以下公式轻易给出

```
w_n^{(i + 1)} = \frac{\exp(-y_n F_i(\mathbf{x}_n))}{Z_i} = \frac{w_n^{(i)}\exp(-y_n a_i \phi(\mathbf{x}_n; \mathbf{\theta}_i))}{Z_i},
```

其中 `Z[i]` 为归一化因子。

$Z_{i} := \sum\limits_{n = 1}^{N}w_{n}^{(i)}\exp\left( - y_{n}a_{i}\phi(\mathbf{x}_{n};\mathbf{\theta}_{i}) \right).$

![Equation](img/si363.png)(7.98)

观察权重的形成方式，可以掌握 AdaBoost 算法的主要秘密之一：与训练样本 **x**[n] 相关的权重相对于其在上一次迭代中的值会增加（减少），具体取决于该模式未能（成功）被正确分类。此外，减少（增加）的百分比取决于 *a*[i] 的值，它控制着在最终分类器构建中的相对重要性。在连续迭代中持续失败的难分样本，在其参与加权经验误差值时会获得更高的重要性。对于 AdaBoost 的情况，可以证明训练误差倾向于以指数速度趋于零（问题 7.18）。该方案总结在 算法 7.1 中。

#### 算法 7.1

##### AdaBoost 算法

*   **初始化：** $w_{n}^{(1)} = \frac{1}{N},\ i = 1,2,\ldots,N$

*   **初始化：** $i = 1$

*   **重复**

    1.  通过最小化 *P*[i] 计算 $\phi( \cdot ;\textit{\textbf{θ}}_{i})$ 中的最优 **θ**[i]；(7.91)

    2.  计算最优 *P*[i]；(7.92)

    3.  $a_{i} = \frac{1}{2}\ln\frac{1 - P_{i}}{P_{i}}$

    4.  $Z[i] = 0$

    5.  **对于** $n = 1$ 到 *N* **执行**

        *   $w_{n}^{(i + 1)} = w_{n}^{(i)}\exp\left( - y_{n}a_{i}\phi(\textit{\textbf{x}}_{n};\textit{\textbf{θ}}_{i}) \right)$

2. *Z*[*i*] = *Z*[*i*] + *w*[*n*]^((*i* + 1))

6. **End For**

7. **For** *n* = 1 to *N* **Do**

    1. *w*[*n*]^((*i* + 1)) = *w*[*n*]^((*i* + 1)) / *Z*[*i*]

8. **End For**

9. *K* = *i*

10. *i* = *i* + 1

* 直到满足终止条件。

* $f( \cdot ) = \text{sgn}\left( \sum_{k = 1}^{K}a_{k}\phi( \cdot ,\boldsymbol{\theta}_{k}) \right)$

##### 对数损失函数

在 AdaBoost 中，采用了指数损失函数。从理论角度来看，这可以通过以下论证来证明。考虑指数损失函数关于二元标签 *y* 的均值

𝔼[exp(−*yF*(**x**))] = *P*(*y* = 1)exp(−*F*(**x**)) + *P*(*y* = −1)exp(*F*(**x**))。 (7.99)

对 *F*(**x**) 求导并令其为零，我们可以很容易地得到公式 (7.99) 中的最小值出现在

$F_{\ast}(\mathbf{x}) = \arg\min\limits_{f}\mathbb{E}\left\lbrack \exp\left( - yf \right) \right\rbrack = \frac{1}{2}\ln\frac{P(y = 1|\mathbf{x})}{P(y = - 1|\mathbf{x})}.$

右边比率的对数称为*对数几率*比。因此，如果将公式(7.88)中的最小化函数视为公式(7.99)中均值的经验近似，则完全证明了将公式(7.83)中函数的符号视为分类规则是合理的。

与指数损失函数相关的一个主要问题，正如在图 7.14 中很容易看到的那样，就是它根据各自的边界值（定义如下），对错误分类的样本赋予了很大的权重：

$m_{x} := |yF(\mathbf{x})|.$

请注意，点离决策面（$F(\mathbf{x}) = 0$）越远，$|F(\mathbf{x})|$ 的值就越大。因此，位于决策面错误一侧（$yF(\mathbf{x}) < 0$）且距离较远的点会被赋予（指数级）较大的值，与其他点相比，它们在优化过程中的影响力较大。因此，在存在离群点的情况下，指数损失不是最合适的选择。事实上，在这样的环境中，AdaBoost 的性能可能会急剧下降。

### Boosting 的多类推广与正则化

*   文献 [13, 15] 提出了 Boosting 方案的多类推广。文献 [10] 推导了 AdaBoost 方案的正则化版本，以施加稀疏性。考虑了不同的正则化方案，包括 `ℓ₁`、`ℓ₂` 和 `ℓ∞`。最终结果是一族坐标下降算法，它们融合了前向特征诱导和后向剪枝。文献 [33] 提出了一个引入先验知识的版本。所谓的 `AdaBoost*ν*` 在文献 [29] 中被引入，其中显式地考虑了边界。

*   请注意，Boosting 的基本原理同样可以很好地应用于涉及相应损失函数的回归任务，例如平方误差损失函数。平方误差的一个鲁棒替代方案是绝对误差损失函数 [16]。

*   Boosting 技术吸引了该领域研究人员的极大关注，旨在解释其在实践中的良好表现及其相对免疫过拟合的特性。尽管训练误差可能变为零，但这仍不一定意味着发生了过拟合。首次尝试的解释是基于关于相应泛化性能的界限。推导出的界限与迭代次数 `K` 无关，并用边界来表示 [32]。然而，这些界限往往非常宽松。另一种解释可能在于这样一个事实：每次优化仅针对单组参数进行。感兴趣的读者可参考文献 [4, 6, 15] 之后的讨论，这对理解该问题非常有启发。

### 示例 7.5

考虑一个 20 维的二分类任务。第一类（`ω₁`）的数据点源自两个高斯分布之一，其均值分别为 `μ₁₁ = [0, 0, …, 0]ᵀ`、`μ₁₂ = [1, 1, …, 1]ᵀ`，而第二类（`ω₂`）的数据点源自均值为 `μ₂ = [0, …, 0, 1, …, 1]ᵀ`（10 个零后跟 10 个一）的高斯分布。所有分布的协方差矩阵均等于 20 维单位矩阵。训练集和测试集各包含 300 个点，其中 200 个来自 `ω₁`（每个分布 100 个），100 个来自 `ω₂`。

对于 AdaBoost，基分类器选为 `stump`（桩分类器/决策树桩）。这是一种非常朴素的树类型，仅包含一个节点，特征向量 `x` 的分类仅基于其某一个特征的值，例如 `xᵢ`。因此，若 `xᵢ < a`，其中 `a` 为合适的阈值，则 `x` 被归为 `ω₁` 类。若 `xᵢ > a`，则归为 `ω₂` 类。关于在分类器中使用哪个特定特征 `xᵢ` 的选择是随机进行的。这种分类器产生的训练错误率略优于 0.5。AdaBoost 算法在训练数据上运行了 2000 步迭代。图 7.15 验证了训练错误率极快地收敛到零这一事实。即使训练错误率变为零后，测试错误率仍持续下降，随后在 0.15 左右趋于稳定。

## 7.11 提升树

在第 7.9 节对各种方法的实验比较讨论中，曾指出提升树是分类和数据挖掘中最强大的学习方案之一。因此，有必要花更多时间研究这一特殊类型的提升技术。

树模型在第 7.8 节中已介绍。基于我们现在掌握的知识，不难看出树的输出可以紧凑地写为：

$$T(\mathbf{x};\mathbf{\Theta}) = \sum\limits_{j = 1}^{J}{\widehat{y}}_{j}\chi_{R_{j}}(\mathbf{x}) \tag{7.103}$$

其中 $J$ 是叶节点的数量，$R_{j}$ 是树施加的空间划分后与第 $j$ 个叶节点关联的区域，$\widehat{y}_{j}$ 是与 $R_{j}$ 关联的相应标签（回归的输出/预测值），$\chi$ 是我们熟悉的特征函数。参数集合 $\mathbf{\Theta}$ 由 $(\widehat{y}_{j}, R_{j}),\ j = 1, 2, \dots, J$ 组成，这些参数在训练期间估计得出。可以通过选择适当的代价函数获得这些参数。此外，通常采用次优技术来构建树，如第 7.8 节所述。

在提升树模型中，基分类器由一棵树组成。例如，示例 7.5 中使用的树桩是基树分类器的一个非常特殊的情况。在实践中，可以使用规模更大的树。当然，规模不能太大，以使其更接近弱分类器。通常建议 $J$ 的值在 3 到 8 之间。

$$F(\mathbf{x}) = \sum\limits_{k = 1}^{K}T(\mathbf{x};\mathbf{\Theta}_{k}) \tag{7.104}$$

其中

$$T(\mathbf{x};\mathbf{\Theta}_{k}) = \sum\limits_{j = 1}^{J}{\widehat{y}}_{kj}\chi_{R_{kj}}(\mathbf{x})$$
