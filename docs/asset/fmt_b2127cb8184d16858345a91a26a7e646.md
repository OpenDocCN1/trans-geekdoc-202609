## 9.8 资源分配与调度

在 RPA 的背景下，这被集成在不同任务之间实时高效地分配计算、网络和存储资源的过程中。SARSA 是流行的强化学习（RL）算法之一，能够提供有效的动态资源分配，并学习和适应任务需求及可用性的变化。本节将详细解释在 RPA 系统中通过 SARSA 进行资源分配的应用，以确保卓越的卓越性能。

SARSA 是一种同策略（on-policy）强化学习算法，智能体从其当前策略下的动作中进行学习，并不断更新其状态-动作价值函数`Q(S, A)`。在资源分配中使用 SARSA 的核心目标是确定最优策略，以最小化系统延迟、最大化吞吐量，并根据任务实时处理效率平衡资源利用率。在 RPA 系统中，资源分配是指将可用资源（无论是计算能力、网络带宽还是内存）分配给任务的过程，且所有过程受任务优先级、资源可用性和实时性能的限制。SARSA 算法更新动作价值函数`Q(S, A)`的方式如下：

```
Q(S[t], A[t]) ← Q(S[t], A[t]) + α(R[t] + γQ(S[t+1], A[t+1]) - Q(S[t], A[t])) (9.18)
```

其中`S[t]`是时间`t`的状态，代表系统的当前配置；`A[t]`是在时间`t`的动作，代表资源分配决策；`R[t]`是在状态`S[t]`下执行动作`A[t]`后获得的即时奖励。`γ`是折扣因子，用于赋予未来奖励权重；`α`是学习率，决定了智能体从新经验中更新知识的程度。`Q(S[t], A[t])`是动作价值函数，代表在状态`S[t]`下采取动作`A[t]`的预期累积奖励。在 SARSA 中，状态`S[t]`代表系统的当前状况，包括可用资源和任务状态。一个状态可以用与资源分配相关的关键性能指标（KPIs）和系统状态变量向量来表示：

```
S[t] = [TaskQueue Length, Available Resources, Task Priorities, CPU usage, Memory usage, Network latency, Task Completion Time] (9.19)
```

其中`TaskQueue Length`代表等待资源分配的任务数量，`Available Resources`表示当时可用的计算能力、内存和网络带宽，`Task Priorities`显示分配给任务的优先级级别并影响其分配，`CPU usage`和`Memory usage`反映负载，`Network latency`代表由于网络引起的延迟，`Task Completion Time`衡量任务所需的时间。通过将状态表示为向量，SARSA 可以评估任务的性能。

SARSA 中的资源分配`A(t)`指资源如何分发。在 RPA 系统中，`A(t)`可以根据优先级和资源时间决定将哪些资源分配给任务的决策。SARSA 中的奖励函数应当反映目标，例如最小化系统延迟、最大化吞吐量和资源利用率。一种可能的奖励函数可以定义为：

```
A(t) = [TaskQueue Length, Available Resources, Task Priorities, CPU usage, Memory usage, Network latency, Task Completion Time] (9.20)
```

注：此处原文公式中误将`S[t]`为`A[t]`，根据上下文应为状态。其中`S[t]`指系统状态，`A[t]`是动作，`R[t]`是奖励。SARSA 智能体更新其动作价值函数`Q(S, A)`以反映动作的结果，从而指导未来的决策。通过最小化任务完成时间和延迟以及增加资源利用率，SARSA 学习如何优化分配资源，从而提高系统性能。

局部邻域搜索是禁忌搜索（Tabu search）的一种。每一个可行解`A` $\in$ `Ω`都有有一组对应的邻域，`M(A)` ⊆ `Ω`，其中`Ω`是所有可能解的集合。从 S 执行到`B′`以到达一个结果`A′` $\in$ `M(A)`，这种动作被称为一种“移动（move）”。即使这样做会导致目标函数或适应度函数的下降，TS 也会从一个解决方案移动到其最佳接受邻域。这是一种非贪婪的禁忌搜索动作（参见算法 1），它可以防止陷入局部最优状态。正在研究的技术被标记为“禁忌”或“禁止”，以避免循环和陷入局部极值。这些最近访问过的替代方案在迭代过程中被存储在一个名为“禁忌列表”（Tabu list）的列表中。在继续之前，始终会根据禁忌列表进行检查。如果在禁忌列表中发现了移动，则技术进入下一次迭代；否则，舍弃该移动。当满足一组条件（如目标水平或标准）时，特定解决方案的表状态可能会被覆盖。为了增强搜索，有时会使用强化和多样化策略。在第一个示例中，搜索更多地集中在可行域的潜在区域。在第二种方案中，努力考虑整个搜索字段大部分区域选项。表 9.1 列出了 TS 算法的参数。

### 9.9.1 鲸鱼优化算法

鲸鱼优化算法（WOA）用于提高模型的清晰度和性能。鲸鱼的行为启发了 WOA。它们的探索风格被称为“泡网捕食法”。大翅鲸使用一种捕猎技术，在水面上通过形成泡网来捕捉食物。它们沿着形状像数字“6”的路径游泳形成这个网。目标猎物或最优解的近似值是目前 WOA 中的最佳候选解。其他个体将努力改进位置。
