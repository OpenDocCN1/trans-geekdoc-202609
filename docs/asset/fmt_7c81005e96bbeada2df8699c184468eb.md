
### 8.3.3 加速鲁棒特征算法 (SURF)

计算机视觉中的局部特征检测器和描述符 `SURF` 已获得专利。物体识别、图像配准、分类和 3D 重建仅是众多应用中的几个 [14]。它与 `SIFT`（尺度不变特征变换）描述符相关。根据 `SURF` 开发者的说法，基本版本比 `SIFT` 快得多，并且能够处理更多的图像变化。

`SURF` 可以产生 Hessian 斑点检测器行列式的近似整数表示，该检测器利用之前计算的积分图和三次整数运算来发现感兴趣的内容。局部 Haar 小波响应之和作为感兴趣区域的区分特征。这些也可以使用积分图像进行计算。`SURF` 描述符已用于定位和识别物体、个人和脸部，用于生成 3D 场景、跟踪物体以及识别感兴趣点。

为了生成相同大小但带宽更低的图像，将图像转换为坐标，然后使用多分辨率金字塔技术通过高斯金字塔或拉普拉斯金字塔形状重建。结果是原始图像获得了一种被称为 `Scale-Space`（尺度空间）的独特模糊效果，确保了感兴趣点独立于尺度。该策略的三个主要部分是匹配、定位感兴趣区域以及定位邻近邻域。

`SURF` 使用方形滤波器来近似高斯平滑。使用积分图像对平方后的图像进行过滤要快得多。

```
$S\left( {x,y} \right) = \sum\limits\_{i = 0}^{x}{\sum\limits\_{j = 0}^{y}{I\left( {i,j} \right)}}$ (8.2)
```

积分图像允许通过仅四次评估来快速计算矩形框内的整个原始图像。`SURF` 使用基于 Hessian 理论的斑点检测器来寻找感兴趣的位置。Hessian 矩阵的行列式揭示了位置周围区域的变化程度，通过最大化该值来选择点。

由于你必须比较不同尺寸下看到的图像以寻找关系，因此可以在不同尺寸下找到感兴趣点。其他特征识别技术通常将 `scale space` 描述为金字塔型图像。金字塔的下一层是通过对经过高斯滤波器滤波的图像进行下采样构建的。结果是创建了许多具有不同掩码比例的层或阶梯。

```
$\sigma\_{approx} = current\mspace{9mu} filter\mspace{9mu} size\mspace{9mu} X\mspace{9mu}\frac{base\mspace{9mu} filter\mspace{9mu} scale}{base\mspace{9mu} filter\mspace{9mu} size}$ (8.3)
```

尺度空间的每个八八度（代表尺度的倍增）都由一组响应图组成。`SURF` 中 99 个滤波器的输出决定了尺度空间的最低层。与以前的方法相比，`SURF` 通过采用各种尺寸的框形滤波器来缩放空间。它不是不断降低图像尺寸，而是通过增大滤波器尺寸来检查尺度。根据前面的说明，99 滤波器输出是尺度 `s = 1.2` 的初始尺度层，这与尺度 `s = 1.2` 的高斯尺度相当。为了创建后续层，使用逐渐增大的掩码对图像进行滤波。结果生成了尺寸为 99、155、212、272 等滤波器。在 333 邻域内，采用非极大值抑制来定位图像中的感兴趣点。

## 9.1 引言

使用云计算进行数据存储至关重要。主要的关注点是分类文档以及已经放入云存储中的数据类型。数据安全和隐私是额外的问题。在消费的所有方面，云计算资源和服务的利用都是至关重要的。在决定保护系统数据的可行方法时，可以在理解数据安全需求之前和之后都采用精确的分布式计算数据保护计划。

云计算的概念允许了一个共享的可编程计算机资源池，这些资源可以以最少的行政劳动或与服务提供者的接触来快速构建和释放 [1]。云计算基础设施包括正确实现云计算架构所需的硬件和软件组件。云计算的其他名称还包括公用计算和按需计算。为了展示云计算的工作原理，客户端设备可以通过网络从远程物理服务器、数据库和工作站访问数据和云应用。

## 9.2 云计算

云计算是一项不断发展的技术，既是技术现实也是社会现实。目前人们只能推测为新范式开发基础设施以及哪些应用可以转换。对于用户的这种技术转型取决于通过海量存储数据提供的服务、收集数据以及他们没有权限的系统上的软件，预计将产生重大的经济、社会、伦理和法律影响 [2]。

客户端可以在网络和应用程序服务器的帮助下后端存储数据。资源复用使得云计算变得廉价。结果是云消费者为服务提供者支付得更少。应用程序数据以特定且独立设备的方式保留在需要它们的地方附近；这种数据存储策略可能会提高安全可靠性，同时降低传输成本。

云计算是一种广泛的、实用的、按需的网络访问可配置计算资源池（例如连接、数据中心、采集系统）的模型，这些资源可以根据较少的管理工作或服务提供商交互快速配置和释放。这种云计算模型由三种服务模型、四种部署方法和五个关键标准组成，它促进了可用性 [3]。

### 9.2.1 云计算面临的挑战

*   在其他基础设施上安装和运行当前云平台的应用可能会导致维护挑战、设置困难和更多的支出 [4]。
*   在云中消耗大量信息的应用程序需要大量的网络容量，这是高昂的。低吞吐量远低于云应用程序预期的计算性能。
*   在云环境中工作时，数据安全是一个基本的考虑因素。云服务最关注的问题之一是客户必须对自己的数据负责，而并不是所有的云计算服务提供商都能确保完全的数据隐私。透明度和控制方法的丧失、身份管理的丢失、数据滥用和云配置错误都是常见原因。
*   当你将负载移动到云端时，云服务与本地基础设施之间可能会出现兼容性。
*   终端用户应该期望良好的质量，这是他们的首要任务之一。由于整个云生态系统都在虚拟环境中显示，云服务供应商（CSP）必须履行其承诺。
*   云计算的可靠性并不总是 24 小时提供。在某些情况下，云服务发生过中断 [5]。

### 9.2.2 深度学习

监督学习是机器学习的一种，使计算机能够以概念层次的角度理解环境，并通过经验获取知识。由于计算机通过经验获取，因此计算机交互操作员不需要显式地提供计算机所需的所有信息。概念层次允许机器通过从简单概念构建大概念来学习大概念；描述这些结构的图将有多个层 [6]。

深度学习利用了模仿人类大脑的复杂算法集合。这能够处理文本、图像和文档等非结构化数据。机器学习是人工智能（`AI`）的一个子集。深度学习是机器学习中特别困难的元素。

### 9.2.3 医疗保健

机器学习正在迅速成为各种疾病关键的诊断和预后工具。深度学习基于机器学习方法，处理复杂的输入-输出映射。深度神经网络是一种处理和分析医疗数据的流行技术，因为其有效性以及与人类大脑运作方式的相似性。除了诊断，深度学习还用于跟踪疾病的发展、创建个性化治疗方案以及管理患者。保存特定患者海量数据的能力正在彻底改变医疗行业，但收集的数据量太大，人类无法进行分析。精准医疗（涉及为患者提供个体化护理）使机器学习成为可能，机器学习赋予了计算机从数据中自动识别模式并进行推理的能力。

机器学习被应用于许多行业，包括汽车、制造业和零售业。深度学习和机器学习算法的进步使得许多实用的预测成为可能，特别是对股票价格、房屋价值和贷款违约的估算。此外，还有各种格式的数据可用于机器学习的预测。随着数据量的增加，机器学习有很大的进步空间，未来的预测也将因此变得越来越准确。

*   处理医疗数据面临着许多困难，其中之一是数据对机器学习模型可能具有因果关系。当数据中的一个特征导致了另一个特征的发生时，这种关系被认为具有高因果性。这就是“因果关系（causation）”一词的含义。
*   大多数机器学习算法都假设每个特征与其他相互独立，互不导致对方的发生，反之亦然。当特征之间存在强烈的因果关系时，这一前提就会受到挑战。
*   尽管机器学习算法潜力巨大，但医学领域仍然需要大量数据才能从中充分获益。医学照片形式的数据量相当少，使得难以对其进行广泛检查。
*   此外，可用数据并未以适用于机器学习的方式进行标记。要为机器学习对海量数据分类，实际上需要花费时间。

### 9.2.5 机器学习在健康关注中的应用

*   个性化治疗是医疗行业中学习算法最重要的用途之一。它通过评估患者的病历、症状和检查结果，帮助医疗机构提供定制化的患者护理。在医疗和医学研究中使用机器学习，医生可以开发专门的疗法，并针对患者的特定疾病提供药物。
*   机器学习的使用可以提高医疗效率，可能导致成本节约。例如，医疗保健中的机器学习可能用于开发更好的编程或临床记录管理算法。结果，浪费在医疗系统内部重复性任务的时间和资金可能会减少。
*   深度学习和机器学习都实现了计算机视觉这一突破性领域。这得到了微软内部眼睛计划（Microsoft Inner Eye Initiative）的认可，该计划创建了用于图像分析的评估方法。
*   如果个人健康与预测分析相结合，个性化治疗不仅可能更加成功，而且有利于进一步的研究和增强疾病评估。

## 9.2.6 患者数据维护

鉴于信息的快速发展，许多医院除了存档外，正转向永久数据的数值化存储。外科医生时间有限、复杂、模糊且高风险的判断对患者结果有重大影响。启发式方法、个人偏好和假设演绎推理通常主导着临床判断。传统的决策支持系统和预测分析面临各种挑战，导致准确性不理想且需要耗时的人工信息处理 [8]。
