## 16.2 实现各个模块

让我们仔细观察如何在程序中实现遗传算法的基本方面：生存游戏、交配过程（伙伴选择）、重组和变异。起初，我们将讨论简单的解决方案，将更高级的技术留到后面的章节。

为了简单起见，我们假设染色体采用二进制字符串的形式，例如`[1 1 0 1 1 0 0 1]`，其中每个位代表某个属性，存在则位值为 1，不存在则为 0。因此，在简化的“派”问题中，第一个位可能表示饼皮有多厚，第二个位可能表示填充物是黑色，以此类推。

### 初始种群

创建初始种群的最方法将采用随机数生成器。有时，工程师可以依靠某些知识来帮助创建优于随机生成个体的初始染色体。

### 生存游戏

遗传算法假设有一种方法可以计算每个样本生存概率。在某些应用中，这些概率可以通过实际实验、让个体样本相互竞争来确定。在其他领域，适应度是由用户指定的评估函数计算的，其值取决于染色体的属性。如果染色体代表一个分类器，适应度函数可以依赖于分类器正确标记的训练示例的百分比。

![image](img/image102.png)![image](img/image112.png)个体的生存是由概率决定的。以下是在计算机程序中实现这种“幸运轮”的方法。让`Fi`表示第`i-th`个样本的适应度（fitness），让`F = ∑ Fi`为所有个体适应度值的总和，然后将这些值排列在区间`[0; F]`之上。生存过程通过随机数生成器进行建模，该生成器返回`[0; F]`中的某个值`r`：被`r`“命中”的子区间的序号即指向了幸存者。该原理如图 16.2 所示，对于一个包含四个样本的小种群，如果随机数落在第三个区间，则选择第 3 个个体。如果命运想要有 20 个样本存活，它就必须生成 20 个随机数，通过这些随机数在区间`[0; F]`中所在的位置来确定幸存者。

虽然适应度较小的样本很可能被淘汰，但适应度较高的个体可能会多次出现在幸存者池中。生物学家会对这种“克隆”想法皱皱眉，但在计算机程序员的务实世界里，同一个个体可以“存活”两次、三次甚至很多次。

## 长寿与不朽个体

该算法的缺点之一是，非常优秀的有机体可能会被价值较低的后代取代，有用的基因可能会消失。为了防止这种情况发生，某些计算机程序会将最好的样本连同后代一起复制到新代中。例如，程序可能直接在新生代中插入 20% 的最佳幸存者，然后通过对前 95% 的个体应用重组和变异算子创建剩余的 80%，完全忽略底部的 5%。这样，不仅最好的样本能活得更久（甚至变得“不朽”），程序还将剔除一些纯靠运气存活的极弱个体。
