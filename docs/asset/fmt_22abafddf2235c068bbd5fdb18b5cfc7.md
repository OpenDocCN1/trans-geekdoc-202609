
# OpenCV 在病理图像分析中的应用

`OpenCV` 是 `Python` 中用于图像处理的计算机视觉模块。在 `OpenCV` 中检查正常上皮组织和 OSCC 阳性组织的病理图像以提取口腔正常上皮细胞和鳞状细胞的细胞核。使用 `OpenCV` 应用的方法包括`自适应阈值`、`Sobel 滤波`、`Otsu 方法`、`Canny 边缘检测`和`分水岭`。这些图像分割算法是参数化方法并在 `OpenCV` 中编程。这些传统的特征提取方法应用于组织病学图像以检测图像上的感兴趣区域。然而，细胞核的准确勾勒是临床医生诊断 OSCC 疾病的关注。因此，需要数据密集型计算框架根据大小、形状、颜色、纹理和强度等结构属性来分割特征并勾勒细胞。值得注意的是，在 OSCC 的调查中使用深度神经网络使计算病理变得可靠。在检查 WSI 时，角形成和角质珍珠的形成确认了 OSCC 的急性严重性。异常核形成同心层，也称为上皮珍珠。在图 11.2b 和图 11.6b 中看到的同心层是角质珍珠。在图 11.2a 中看到的细胞岛或重叠细胞群是角形成。下一节描述了深度神经网络在 OSCC 自动检测和分级案例研究中的重要性。

一种返回前景类和背景像素强度阈值的自动计算以 Nobuyuki Otsu 命名。该算法使用公式 11.4 寻找类间方差：

`τ² = γ(b)² + γ(f)²` (11.4)

其中 `τ²` 表示颜色差，`γ(b)` 和 `γ(f)` 表示根据像素概率属于某一类的像素数量。在图像上执行的水平 `δ(x)` 和垂直导数 `δ(y)` 滤波操作由公式 11.5 给出。滤波器的图像分析在公式 11.6 中用图像 `I` 表示。

\delta_{x} = \begin{bmatrix} 1 & {-1} \\ 1 & {-1} \end{bmatrix},\delta_{y} = \begin{bmatrix} {-1} & {-1} \\ 1 & 1 \end{bmatrix} \tag{11.5}
$$

## 基于阈值的特征提取算法

基于阈值的特征提取算法通过使用固定值作为全局参数对图像区域的像素强度进行量化，以提取背景和前景。然而，这些方法在执行时间和内存利用上较高。为了克服这些问题，可以使用相邻像素的统计数据，如公式 11.1–11.3 所示。

$$
I_{\text{intensity}} = \left\{\begin{matrix} \mu \\ \sigma \\ \delta^{+} \\ \delta^{-} \end{matrix}\begin{matrix} \text{像素强度的平均值} \\ \text{像素强度的中位数} \\ \text{像素值的最大值} \\ \text{像素值的最小值} \end{matrix} \right\} \tag{11.1}
$$

`I_threshold = (δ⁺ + δ⁻) / 2` (11.2)

$$
\text{自适应阈值 } z(x,y) = \left\{\begin{matrix} 0 & g(x,y) < I_{\text{threshold}} \\ 1 & g(x,y) > I_{\text{threshold}} \end{matrix} \right. \tag{11.3}
$$

像素的平均和中位数统计数据用于定位相邻像素。基于强度级的像素分布可以使用公式 11.1 进行估计。阈值是最大和最小像素强度的平均值。使用动态阈值分割图像特征的计算是 `z(x,y)` 根据公式 11.3 进行更新的。自适应阈值方法图像分割的步骤见图 11.3、图 11.4、图 11.5。

然而，这些图像分割算法局限于内存读写访问。为了克服这些固有的算法复杂性，最近大多数研究都集中在深度神经网络架构的开发，以阐明应用于卷积神经网络（`CNN`）自动特征提取的 AI 概念。下一节将解释用于癌症诊断的深度神经网络的系统计算。

# 用于癌症诊断的深度神经网络

传统特征提取方法的异常通常是由于噪声数据引起的误差。像素级量化可能导致对图像区域边界的误读。这些实际问题可以通过利用深度卷积神经网络的学习能力来消除。`CNN` 的能力在于其从表示中学习的能力，这是深度学习者的主要意义。与浅层网络不同，深度架构在解决从非线性输入中学习特征的问题具有优势。使用 `OpenCV` 进行特征勾勒在像素量化、像素计数和基于区域的边界方面存在问题。这些未使用机器学习（`ML`）技术的特征提取过程会导致异常检测。相反，可以设计深度网络来利用特征表示技术。此外，通过影响 AI 的迁移学习概念，可以迁移不同特征的层次。最近的研究报告了通过修改参数和超参数调优对卷积网络（`CNN`）进行的创新。`CNN` 在分类和分割中的卓越性能已使深度 `CNN` 成为口腔鳞状癌（OSCC）鉴别诊断的基准架构（Salvi et al. 2021; Shavlokhova et al. 2021）。

# 口腔病理学鉴别诊断

计算病理学的作用是利用深度神经网络在肿瘤细胞诊断以及癌症与非癌症组织区分方面的潜力。细胞核的准确勾勒是自动诊断的基础任务。在细胞核表征的情况下，重点是：

1. **细胞核分割**
2. **语义分割**

# 11.5.7 性能评估指标

令 `α` 和 `β` 为两个集合，集合的基数表示为 `|α|`、`|β|`。

## 11.5.7.1 Dice 相似性系数 (DSC)

分割相似性得分由公式 11.14 给出。

```
DSC = 2|α∩β| / (|α| + |β|) (11.14)
```

## 11.5.7.2 交并比 (IOU)

Jaccard 指数或 `IOU` 是语义分割过程中常用的指标。令 `α` 和 `β` 为两个集合，集合中重叠区域与并集区域面积之比用于衡量两个有限集合之间的相似性，如公式 11.15 所示。

```
IOU(α,β) = |α∩β| / (|α| + |β| − |α∩β|) (11.15)
```

## 11.5.7.3 混淆矩阵 (CM)

实际值与预测值的表格表示为混淆矩阵。该矩阵能够展示分类准确的实例数量 `X`。图 11.15 显示了 CNN 模型报告的混淆矩阵。

![图 11.15 混淆矩阵.](img/Fig11_15.jpg)

**图 11.15** 混淆矩阵。

## 11.5.7.4 准确率

它是真阳性 (TP) 和真阴性 (TN) 实例 `X` 之和与所有实例和的比，如公式 11.16 所示。

```
Accuracy = (X_TP + X_TN) / (X_TP + X_TN + X_FP + X_FN) (11.16)
```

## 11.5.7.5 F1 分数

`F1` 通过关联精确率（Precision）和召回率（Recall）来衡量测试结果的准确性，如公式 11.17 所示。

```
F1 = 2 × (Precision × Recall) / (Precision + Recall) (11.17)
```

# 11.6 数字病理学中的研究挑战

深度神经网络在区分全组织切片 (WSI) 中异常鳞状细胞癌与正常细胞方面具有巨大潜力（Tanriver et al. 2021）。然而，基于颜色、形状、大小、纹理和强度等形态特征对细胞核进行准确勾定仍处于早期阶段。因此，文献尚未解决考虑像素级计算的语义分割问题，以协助医生鉴别诊断以及对鳞状细胞癌进行分级。

# 11.7 结论

人工智能（AIML）在计算病理学中的作用近期得到了确立。这极大激励了作者在本研究中介绍计算机视觉和 AI 深度学习概念的重要性。本章介绍了医学科学中用于口腔鳞癌诊断的病理学原理。通过草图说明了正常与异常上皮细胞的区分。通过数据集解释了导致角化和角质珠形成的 OSCC 的严重程度和发育阶段。通过数据字典解释了 OSCC 的自动分化和分级分析。解释了从不同数据集的患者队列中收集的样本。深度 CNN 用于 OSCC 鉴别诊断的流程通过关于模型公式、与性能评估措施和指标拟合的案例研究进行了说明。此外，研究人员在近期工作中关注了考虑了形状、大小、颜色、纹理和强度等形态特征的细胞核准确勾定。满足病理学家此类需求的工作流仍留待未来工作。
