
# 互操作性在多个领域均有需求

互操作性在多个领域均有需求，其中之一是价值链至关重要的领域，如贸易金融、航空、供应链、医疗保健等。单一区块链无法满足一笔交易的所有需求。这解释了为何需要多个网络，因为每个网络提供不同的价值，同时能与其他网络正常通信，确保私有网络数据可路由至相关网络以执行不同交易。

这将无需进行一对一集成即可执行。以全球供应链为例，实物商品可在参与者之间以更少摩擦流转。区块链领域也需要这一特性——即在区块链网络之间转移数字资产，而无需创建冗余数据或为第三方开辟新市场。

借助区块链技术，脱节的供应链管理系统实际上可以以更低成本、更安全的方式实现互操作。振兴供应链的迫切需求是利益相关者利用区块链技术的驱动因素之一，因为该技术具备这些特性。已有多篇有趣的论文致力于互操作性研究，其中最详尽的是由世界经济论坛（WEF）发布的。他们用“孤岛化的巴尔干化”来形容区块链现状。

## 区块链互操作性的几种方法

区块链互操作性主要有两种方法——`网络模型`和 `API`。组织可以通过一种称为“混搭”应用的方法，让区块链网络相互连接。区块链网络无需与每个网络的应用程序编程接口（API）交互，只需与一个统一的 API 接口交互即可。混搭应用可在智能合约和数据模型中定义多种能力。

然而，从根本上说，它将作为连接所有网络的粘合因素。但从长远来看，混搭可能不是组织互操作性的最佳选择，尽管它们不预设治理结构，这反而使其便捷且灵活。

### 网络的网络模型

许多专家认为，构建互操作性的最佳方法之一是采用`网络的网络模型`。这涉及共同制定行业标准，并探索一种网络的网络架构，允许其他行业网络围绕其汇聚。您可以将区块链网络组织视为一个相互连接的网络“网”。这种结构使公司能够连接并与各种解决方案执行交易，开启跨解决方案的互操作性市场，而不受单一网络的限制。

目前大多数互操作性解决方案主要提供跨无许可区块链的链互操作性。它们使用加密导向工具，如中继链（或侧链）、时间哈希锁和公证人方案。但关注点正日益从无许可区块链间的链互操作性，转向私有网络与公共区块链之间、或不同私有网络之间的互操作性解决方案。

区块链项目实现互操作性的一种策略是使用一个独立的区块链，作为桥接器实现跨链通信。您可以将其视为位于两个区块链网络中间的第三条区块链。该第三方区块链维护两个独立区块链之间消息传递和交易活动的带时间戳且加密保护的账本。使用链下或中间件系统也是促进不同系统间互操作性的另一优秀策略。这是一种非区块链解决方案，利用状态通道、预言机和原子交换等工具。我们之前已讨论过几种流行的互操作性解决方案。

日益增多的互操作性解决方案最终将改变人们对区块链的看法。这种态度转变将有助于说服网络认识到无缝数据交换对区块链领域成功的重要性。互操作性无疑将成为区块链领域的颠覆性变革。关于提供互操作性解决方案的不同区块链项目的更多信息，请翻阅第七章。

# 企业级区块链解决方案数量激增

随着区块链成熟，我们也将见证企业级区块链解决方案数量的显著增加。如果您不确定企业级区块链的含义，它是私有区块链的另一种称呼，指中心化所有者部署分布式账本。随着加密货币影响力持续扩大并获得更高知名度，企业也在探索区块链为其业务运营带来的效益。

全球各地的公司正在证明，借助区块链技术，它们可以降低日常运营成本、提高效率并确保数据安全。预计到 2023 年，企业对数字账本技术的投资将达到 160 亿美元。将这一数字与 2019 年约 27 亿美元的支出相比，您会同意区块链领域在未来几年将见证剧烈增长。

正如许多专家预测，将引领企业级区块链解决方案的行业是银行和金融服务业。这显然归因于数字账本在其会计运营中的适用性，以及数字货币的颠覆性影响。除了银行和金融服务，分布式账本技术的应用在其他行业也日益普及，我们已经讨论过其中一些——医疗保健、制药供应链、供应链管理等。

技术信心的增长呈现稳步上升趋势。事实上，Gartner 调查数据显示，2020 年有 14% 的企业区块链项目进入生产阶段，与 2019 年记录的 5% 相比有了显著提升。

# 非同质化代币（NFT）时代

虽然我们大多数人现在将比特币视为法币的完美数字化答案，但 NFT 也正成为收藏品的数字化回应。通过出售 NFT 致富的人名单持续增长，例如 Jack Dorsey 出售其第一条推文获得高达 290 万美元。或许 Beeple 的艺术品以 6900 万美元售出，是迄今为止售价最高的 NFT 之一。许多人认为 NFT 只是某种没有现实价值事物的怪异首字母缩写。另一方面，许多投资者缺乏对其含义的良好理解。未来我们可能会看到的趋势之一是 NFT 的流行度将进一步提升。那么，NFT 到底意味着什么？

它只是`非同质化代币`的另一个名称，与存储在数字账本中、代表某种有形事物的数据有关。它可以代表一张音乐专辑、一件艺术品以及不同种类的数字文件。这是对 NFT 含义的直接定义。因此，如果你购买了一个 NFT，你本质上购买的是一个代币的数字记录所有权，你可以将其转移到数字钱包中。区块链是确认任何给定代币作为所有权证明的数字账本。与其他区块链中代币可能代表货币单位（如以太坊区块链上的 `Ether`）不同，NFT 中的代币代表完全不同的东西。

例如，当有人购买 Beeple 的艺术品时，买家支付的是一枚授予其拥有该特定艺术品权利的代币。但同样重要的是要知道，实际版权仍归原始所有者所有。那么，最初为什么要购买它呢？有人购买艺术品有几个原因。可能是买家只是想在艺术品变得更受欢迎时立即转手。其他人可能只是买入并转售，以从投资中获利。

你现在应该已经了解的一点是，NFT 与加密货币完全不同。两者唯一的主要共同点是它们都存储在数字账本——区块链上。这正是相似之处的终点。就 NFT 而言，每个代币都具有独特的价值，你无法用另一个同等价值的代币来交换它。加密货币的价值就像法币一样是统一的，这意味着牙买加的一张 100 美元钞票，其价值与法国或英国的一张相同。你可以在世界任何地方以相同的价格交换一枚比特币。但两个 NFT 代币的价值可能不同。

同质化资产被视为可以轻松互换其单位的物品，货币就是同质化资产的完美例子。你甚至可以用两张 50 美元纸币兑换一张 100 美元纸币，其价值保持不变。但非同质化资产的情况并非如此，根据同质化资产的定义，你可以轻松猜出其含义。非同质化资产具有独特特征，这也意味着我们无法用其他任何东西互换它们。NFT 的示例包括：

*   游戏内物品
*   域名
*   限量版时尚系列拥有的特殊运动鞋
*   数字形式的独特艺术品
*   授予所有者参加活动权限的优惠券
*   数字收藏品
*   文章
*   体育精彩集锦
*   表情包
*   发布的专栏
*   病毒式传播的照片

## 为什么 NFT 如此流行？

它们不仅仅是即将很快消退的新潮流。有趣的是，它们已经存在了大约半个十年，尽管其流行是近期的发展。为什么 NFT 最近的流行度增加了？导致 NFT 流行度增加的因素之一是疫情。此外，比特币和其他加密货币价值的上升在 NFT 的流行中发挥了重要作用。

自 2020 年以来，`ETH` 的价格飙升，任何人都可以用 `ETH` 购买 NFT 的一部分，在某些情况下甚至可以购买完整的一个。但随着 `ether` 价值的持续增加，所有者的购买力也随之增加。NFT 的独特性是它们将在未来几年继续存在的主要原因。事实上，任何购买 NFT 的人都将拥有一件没有其他人能够拥有的物品，除非所有者刻意复制它。

任何人都可以购买棒球卡、绘画以及其他他人可以轻易复制的类似作品。但 NFT 的不同之处在于，它们为买家提供了对艺术品或任何其他物品的真正唯一所有权，这对许多人极具吸引力。事实是，随着区块链技术也成为一种首选的所有权证明手段，NFT 的流行度将继续增加。

寻求接触不同资产组合的投资者应关注该资产类别中的更多机会，无论是通过单个 NFT 还是管理基金。但同样重要的是，要考虑选择 NFT 涉及的风险，以避免选错。如果你有兴趣购买 NFT，那么你应该做好功课，也可以等待并观察 NFT 领域成熟后再参与。

以下是 NFT 是什么以及如何工作的总结：

*   每个铸造的 NFT 代币都拥有唯一标识符。
*   每个代币都归某人所有，且很容易验证此信息。
*   与加密货币和法币不同，NFT 代币无法直接与其他代币互换。
*   如果你拥有一个 NFT，你可以轻松证明所有权。
*   其他人无法操纵它。你可以选择永远持有你的 NFT 代币，因为区块链技术保证了你的资产安全。
*   如果你决定出售，作为原始创作者，你将享受转售版税。
*   当你决定创建一个 NFT 时，也很容易证明是你创建的。
*   每当你出售你的 NFT，你都能获得版税。
*   作为 NFT 的创作者，你也可以决定其稀缺性。
*   可以在点对点或 NFT 市场上出售你的 NFT。你完全不受限于单一平台，也不需要中介。

流行的 NFT 平台包括 `OpenSea`、`Superfarm`、`Rarible`、`Ethernity` 等。

# 区块链即服务（BaaS）

我们一直在讨论不同的区块链趋势和区块链行业的未来。正如《福布斯》2020 年第二届“区块链 50 强”榜单所强调的，区块链即服务软件和平台是极具前景的区块链趋势之一。大量提供区块链即服务的项目已进入该领域，这实际上包括 `IBM`、`Amazon` 和 `Microsoft` 等大牌。这些第三方服务的出现是一个相对较新的发展，特别是在同样处于早期阶段的区块链领域。

这些第三方服务的创建无疑是由于对托管去中心化软件服务的需求不断增加，以促进行业增长。`Fortune Business Insights` 的可用数据显示，BaaS 行业有望在 2027 年达到约 250 亿美元的估值。这清楚地表明了增长，因为 2019 年这一数字为 19 亿美元——在 2020 年至 2027 年的预测期内，复合年增长率（CAGR）为 39.5%。

事实上，记录显示零售和电子商务细分市场很可能采用 BaaS 解决方案，且最高增长率很可能发生在同一预测期内。

## 理解 BaaS

### BaaS（区块链即服务）概述

BaaS 的一个直观定义是：它是一种基于云的服务，允许用户在利用区块链技术的同时创建其数字产品。你也可以将 BaaS 视为软件即服务的分布式账本版本，全球各地的企业订阅此服务并获得对基于云的软件的访问权限。数字产品的示例包括去中心化应用，以及其他无需完整区块链平台的设置要求即可运行的服务。

### BaaS 工作原理详解

这涉及一个流程，即第三方公司为其他用户安装、托管甚至维护区块链网络。这一方（也被视为外部服务提供商）决定建立所有必需的区块链技术以及基础设施，并以此收取费用。外部服务提供商将处理维护和基础设施问题。

事实是，区块链即服务提供商的角色就像网络托管提供商一样。它们提供一个平台，让客户可以利用其基于云的解决方案。此外，BaaS 协助各类组织在云服务提供商管理和运维的区块链平台上开发和托管区块链应用以及智能合约。它们提供支持服务，如合适的资源分配、带宽管理、数据安全功能和托管要求。

这项服务的优势在于，企业无需烦恼管理和运营区块链的日常复杂性。相反，它们现在可以主要专注于核心业务活动，而由 BaaS 提供商处理底层技术的顺畅运行。

### 区块链即服务的重要性

企业利用区块链技术的兴趣与日俱增，然而，大多数企业面临着创建、配置甚至运营区块链所涉及的运营开销和技术复杂性。此外，区块链基础设施的维护通常是一大障碍。就搭建和维护基础设施而言，区块链需要巨额投资，与其他传统数据库相比，它通常更加消耗资源。

我还要补充一点：区块链需要巨大的带宽和大量的能源。因此，BaaS 为全球企业提供了巨大价值，并最近因多种原因获得了显著的关注。对于大多数组织而言，将云服务与 BaaS 结合可能会非常有价值。企业可以通过定制集成，凭借 BaaS 的个性化灵活性，解决其大部分痛点。BaaS 解决方案可以帮助它们以一种直接的方式解决围绕成本、效率和透明度的复杂挑战。

这将显著降低企业级区块链应用的准入门槛。公司可以轻松利用区块链技术的所有优势——问责制、信任最小化、透明度提升和数据安全。它们将享受这些益处，而无需开发自己的区块链生态系统。事实上，它们甚至不必投资所需的计算资源。那么，BaaS 领域的主要参与者是谁呢？

BaaS 的流行吸引了一些最大科技公司的注意，因为其中大多数现在都已设立专门部门，专注于 BaaS 的集成和推广。进入区块链即服务领域的其他公司还包括一些最成功的云服务提供商。在 BaaS 领域运营的公司名单中位居前列的包括：

*   Microsoft
*   Corda
*   Accenture
*   Stratis
*   Amazon
*   Baidu
*   IBM
*   Alibaba
*   SAP
*   Huawei
*   Oracle
*   Infosys

除了这些大玩家，我们还有一些较小的创新型区块链即服务公司，其中许多目前总部设在美国。这些创新的 BaaS 公司将分布式账本集成到其日常技术中，其中一些包括 Factom、Blockstream、Dragonchain、PayStand 以及其他若干公司。

# 区块链专家需求激增

分布式账本技术仍是一项新技术，该领域需要更多的启蒙和教育。区块链已扩展至不同行业，每天都在涌现更多用例。这也意味着将需要更多的人了解这项技术。

当然，区块链专家的数量正在增加，但区块链实施的增长迅速，这将导致对区块链专家的需求急剧上升。许多大学和学院正在加大力度以满足这一需求。此外，全球各地的组织也不甘落后，它们正通过专门针对区块链平台开发和管理的培训计划，努力开发现有人才。

然而，具备正确技能的毕业生产出速度不足以满足需求。像 IBM 这样的公司已表达了对区块链人才数量不足的担忧，甚至将这种情况称为现有公司采用区块链技术的“重大阻碍”。Coin Rivert 于 2018 年透露，区块链专家的需求同比增长了 2,000%，该数据源自 Upwork.com。

# 在日益去中心化的世界中的政府监管

审视区块链技术的架构，无疑能解释其对传统机构以及传统监管和治理方法固有的挑战原因。从我们迄今为止的讨论中可以看到，企业级区块链显著增加。这迄今为止使得传统治理和监管机制成为可能。

然而，随着无许可或公共分布式账本技术的使用增加，我们可能会面临更多挑战。监管区块链是不可能的，试图监管它们就像试图监管人们系统上（无论在线还是离线）的所有账本。然而，区块链技术的底层用例肯定会受到监管。世界各国政府将与来自不同司法管辖区的各种监管机构及其他相关方合作来实施这一点。

尽管目前尚无针对区块链技术的精确治理机制组合，但当有可用方案时，它极有可能涉及“监管杠杆”的组合，通过拉动这些杠杆来确定适当的平衡。

区块链监管面临一些关键两难困境。例如，我们都知道监管对于保护用户同时确保安全至关重要。然而，过度监管最终可能会扼杀创新，尤其是在金融领域。这也解释了为什么目前关于区块链监管的对话应当持续进行，以确保其治理的各个方面得到妥善解决，尤其是涉及隐私和安全时。渴望采用去中心化商业模式的国家可能会对其现有法律框架进行若干修改。
