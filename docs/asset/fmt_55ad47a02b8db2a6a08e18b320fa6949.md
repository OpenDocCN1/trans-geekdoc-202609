## 问题 131

SecureTech Corp 是一家处理敏感客户数据的公司，正在重新设计其主办公室入口以增强安全性。他们希望确保一次只有一个人获得访问，即使有多人尝试使用单张授权的访问卡进入。以下哪个选项可以实现这一目的？

- (A) `CCTV` 摄像头
- (B) 步道间 (Mantrap)
- (C) 生物识别扫描仪
- (D) 运动探测器

解释 131. **正确答案：B. 步道间。** 步道间（也称为访问控制门室）是一种物理安全访问控制系统，由一个带有两组互锁门的小空间组成。第一扇门必须在第二扇门打开之前关闭，以确保一次只有一个人通过。这种设计防止了尾随（`tailgating`）或搭便（`piggybacking`），即未经授权的人员试图紧跟在授权人员后面进入安全区域。

选项 A 错误。虽然 `CCTV` 摄像头可以进行监控和记录，但它们无法在物理上阻止多人同时进入。

选项 C 错误。生物识别扫描仪根据物理特征验证身份，但不能从物理上限制进入某区域的人数。

选项 D 错误。运动探测器识别运动，但不能防止尾随或搭便。

- (C) 分布式拒绝服务（`DDoS`）防护
- (D) 蜜罐网（Honeynet）

解析 147。正确答案：D。蜜罐网。蜜罐网本质上是一个蜜罐网络。它设计用于吸引攻击者，让他们认为自己正在攻击真实网络，而实际上他们的策略技术正在被观察和分析。

选项 A 错误。防火墙集群是共同工作的防火墙组，旨在提高可靠性和性能。它不是作为吸引攻击者的诱骗系统。

选项 B 错误。虚拟局域网（`VLAN`）用于在物理网络内创建逻辑分段网络的协议，提高了性能和安全性。它不是诱骗系统。

选项 C 错误。分布式拒绝服务（`DDoS`）防护解决方案侧重于识别和缓解大规模网络服务可用性的尝试。它们不会为攻击者提供欺骗性环境。

## 问题 148

IT 管理员 David 注意到几台公司移动设备即使在连接到公司 `Wi-Fi` 时流量也异常。他怀疑这些设备可能在后台使用移动数据。David 应该实施以下哪种解决方案以确保公司设备在办公室运行时使用公司 `Wi-Fi` 进行数据传输？

- (A) 对所有设备开启飞行模式
- (B) 设置 `Wi-Fi` 白名单
- (C) 实施移动设备管理（`MDM`）策略优先考虑 `Wi-Fi`
- (D) 在办公室区域禁用蜂天线

解析 148。正确答案：C。实施移动设备管理（`MDM`）策略优先考虑 `Wi-Fi`。`MDM` 解决方案允许管理员对移动设备执行策略。通过实施优先考虑 `Wi-Fi` 的策略连接后，David 可以确保公司设备在可用时使用企业 `Wi-Fi` 网络，从而减少蜂窝数据流量。

选项 A 是错误的。虽然开启飞行模式会切断蜂窝数据，但它还会禁用所有其他形式的（包括 `Wi-Fi`），导致设备无法用于预期用途。

选项 B 是错误的。设置 `Wi-Fi` 白名单并防止设备使用蜂窝数据。它仅限制了设备可以连接的 `Wi-Fi` 网络。

选项 D 是错误的。禁用蜂窝天线是一种激进措施，可能会影响附近的其他设备和服务。根据当地法规，这种做法可能是不切实际且可能违法的。

## 问题 149

一所大学正寻求改造其无线网络，以为学生和教员工提供安全访问。IT 部门希望有一种利用中心化服务器验证用户凭据并与现有目录服务集成的认证方法。他们应该选择哪种认证协议？

- (A) 预共享密钥 (`PSK`)
- (B) 轻量级扩展认证协议 (`LEAP`)
- (C) 扩展认证协议-传输层安全协议 (`EAP-TLS`)
- (D) 共享密钥挑战

解析 149. 正确答案：C. 扩展认证协议-传输层安全协议 (`EAP-TLS`)。
