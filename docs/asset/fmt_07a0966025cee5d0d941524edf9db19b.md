
注意力函数可以描述为将一个查询和一组键值对映射到一个输出，其中查询、键、值和输出均为向量。输出计算为值的加权和。换句话说，输出即为上下文向量。我们可以将注意力层的组成部分视为如下：

* “查询”是直到时间步 `t` 的最后一个解码器隐藏状态。
* “值”是编码器的输出，即编码器的所有隐藏状态。“查询”关注所有的“值”。
* 我们可以用一些“键”来表示值，并将查询与键进行比较，而不是直接与值比较。

这类似于文档搜索或检索。搜索 YouTube 视频时，我们传递一个文本查询。该查询文本与各种视频描述（键）进行比较，并检索相关视频（值）。对于目前讨论的注意力类型，我们有值=键。通过这种公式化，之前所有的评分函数只有两个参数，即查询和值：

![](img/2631.jpg)

例如，我们可以按如下方式实现 `BahdanauAttention`：

```
class BahdanauAttention(tf.keras.layers.Layer):
    def __init__(self, units):
        super(BahdanauAttention, self).__init__()
        self.W1 = tf.keras.layers.Dense(units)
        self.W2 = tf.keras.layers.Dense(units)
        self.va = tf.keras.layers.Dense(1)

    def call(self, query, values):
        # query shape: [batch_size, hidden_size],
        # values shape: [batch_size, inp_seq_len, hidden_size]
        query = tf.expand_dims(query, 1)
        scores = self.va(tf.nn.tanh(self.W1(query) + self.W2(values)))
        attention_weights = tf.nn.softmax(scores, axis=1)
        context_vector = attention_weights * values
        context_vector = tf.reduce_sum(context_vector, axis=1)
        return attention_weights, context_vector
```

## 语言翻译模型

给定一种源语言（例如法语）的文本序列，任务是将其转换为一种目标语言（例如英语）。自然语言固有的歧义性和灵活性导致源文本到另一种语言不存在单一的**最佳翻译**。这使得语言翻译问题极具挑战性。经典的语言翻译模型要么基于规则，要么基于统计。基于规则的模型由语言学家开发，此类规则的集合非常庞大。统计方法是数据驱动的，利用源语言和目标语言的句对集合，将源语言的短语或子句转换为目标语言。这被称为**统计机器翻译**（**SMT**）。当神经网络模型应用于此任务时，其表现优于上述两种方法。

我们可以从 [`www.manythings.org/anki/`](http://www.manythings.org/anki/) 下载法英数据集，其中包含双语句对。

文本可以视为单词序列。假设某种语言的词汇表中有 N 个单词；我们可以用 1 到 N 的数字来表示它们。因此，源句子是一个整数索引序列。我们必须将这些整数转换为独热编码向量。通常 N 会非常大，转换为独热编码会导致高维稀疏向量。为避免此问题，单词通过查找矩阵转换为稠密向量表示，该矩阵包含维度为 ![](img/2635.jpg) 的 N 个稠密向量。此查找矩阵称为*嵌入矩阵*，其维度称为*嵌入维度*。我们将在下一章 NLP 中更详细地讨论嵌入矩阵。

以下是编码器的代码。该模型接收一个整数序列作为输入，并在第 8 行使用 `Embedding` 层将整数序列转换为稠密向量序列，随后由 RNN（或 GRU）处理。请参考以下代码：

```
class Encoder(tf.keras.Model):
    def __init__(self, vocab_size,
                 embedding_dim,
                 enc_units, batch_sz):
        super(Encoder, self).__init__()
        self.batch_sz = batch_sz
        self.enc_units = enc_units
        self.embedding = tf.keras.layers.Embedding(vocab_size,
                                                   embedding_dim)
        self.gru = tf.keras.layers.GRU(self.enc_units,
                                       return_sequences=True,
                                       return_state=True,
                                       recurrent_activation='sigmoid')
    def call(self, x, hidden):
        x = self.embedding(x)
        output, state = self.gru(x, initial_state=hidden)
        return output, state
    def initial_hidden_state(self):
        # Generating encoder initial states as all zeros
        return tf.zeros((self.batch_sz, self.enc_units))
```

```
# Decoder with attention
class Decoder(tf.keras.Model):
    def __init__(self, vocab_size,
                 embedding_dim,
                 dec_units, batch_sz):
        super(Decoder, self).__init__()
        self.batch_sz = batch_sz
        self.dec_units = dec_units
        self.embedding = tf.keras.layers.Embedding(vocab_size,
                                                   embedding_dim)
        self.gru = tf.keras.layers.GRU(self.dec_units,
                                       return_sequences=True,
                                       return_state=True,
                                       recurrent_activation='sigmoid')
        self.fc = tf.keras.layers.Dense(vocab_size)
        self.attention = BahdanauAttention(dec_units)

    def call(self, x, hidden, enc_output):
        # enc_output (batch_size, max_length, hidden_size)
        # hidden (batch_size, hidden size)
        attention_weights, context_vector = self.attention(hidden,
                                                           enc_output)
        x = self.embedding(x)
        # Concatenating previous output with contx_vec
        x = tf.concat([tf.expand_dims(context_vector, 1), x], axis=-1)
        output, state = self.gru(x)
        output = tf.reshape(output, (-1, output.shape[2]))
        x = self.fc(output)
        return x, state, attention_weights

    def initialize_hidden_state(self):
        return tf.zeros((self.batch_sz, self.dec_units))
```

```
def loss_function(self, real, pred):
    loss_ = tf.nn.sparse_softmax_cross_entropy_with_logits(
                labels=real, logits=pred)
```

现在，让我们讨论使用教师强制的训练步骤。我们使用了两个特殊标记“`<start>`”和“`<end>`”分别表示源语言或目标语言中句子的开始和结束。例如，法语句子“*Comment ça va?*”可转换为序列 `[<start>, 'comment', 'ça', 'va', '?', <end>]`。我们使用了 `tf.keras.preprocessing.text.Tokenizer` 将句子转换为序列，如代码片段 10.9 所示。我们将使用教师强制来训练网络。因此，解码器的输入将是来自目标语言的真实输入，而非模型在上一步预测的输入。这在**代码 10.9 第 36 行**中展示；在代码 10.9 中，我们有一个循环来遍历整个解码器序列。我们通过用零填充序列，确保批次中每个序列的长度相同。

```
class NMTModel:
    def __init__(self,
                 vocab_size_in,
                 embedding_dim_in,
                 vocab_size_out,
                 embedding_dim_out,
                 enc_units,
                 dec_units,
                 batch_size,
                 inp_lang_tokenizer,
                 targ_lang_tokenizer
                 ):
        super(NMTModel, self).__init__()
        self.inp_lang_tokenizer = inp_lang_tokenizer
        self.targ_lang_tokenizer = targ_lang_tokenizer
        self.batch_size = batch_size
        self.encoder = Encoder(vocab_size_in + 1,
                               embedding_dim_in, enc_units, batch_size)
        self.decoder = Decoder(vocab_size_out + 1,
                               embedding_dim_out, dec_units, batch_size)
        self.optimizer = tf.keras.optimizers.Adam()


    @tf.function
    def train_step(self, inp, targ):
        loss = 0
        hidden = self.encoder.initial_hidden_state()
        with tf.GradientTape() as tape:
            enc_output, enc_hidden = self.encoder(inp, hidden)
            # final encoder states are taken as initial decoder states
            dec_hidden = enc_hidden
            # Passing '<start>' token as first token to decoder
            dec_input = tf.expand_dims(
                [self.targ_lang_tokenizer.
word_index['<start>']]*self.batch_size, 1)
            for t in range(1, targ.shape[1]) :
                # passing enc_output to the decoder
                predictions, dec_hidden, _ = self.decoder(
                    dec_input, dec_hidden, enc_output)
                loss += self.loss_function(targ[:,t], predictions)
                # using teacher forcing
                dec_input = tf.expand_dims(targ[:,t], 1)
        batch_loss = (loss / int(targ.shape[1]))
        variables = self.encoder.variables + self.decoder.variables
        gradients = tape.gradient(loss, variables)
        self.optimizer.apply_gradients(zip(gradients, variables))
        return batch_loss
```
