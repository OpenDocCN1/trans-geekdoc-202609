
纹理属性是宿主图像的重要空间特征之一，它与`HVS`有显著的关系。分析此属性有助于识别宿主图像中的高纹理块，以高不可感知性、高鲁棒性和低内存占用承载水印。由于纹理没有正式的数学定义，且每个特征没有精确的级别来区分宿主图像中的纹理块和非纹理块，因此常用于分析纹理属性的各种特征是无形的且不确定的。因此，`MCDM`方法可以通过解决该不确定性问题并识别高纹理块来帮助进行图像水印的决策。

判断图像的分块是否具有纹理可以表示为一个决策问题，其中分块集合被视为可能备选方案的集合，需要使用纹理特征作为准则集进行评估。构建决策矩阵，并应用`TOPSIS`方法，根据与理想解（最高纹理）的接近程度对所有可能备选方案进行排序。选择具有最高接近度值（包括最佳值）的一定比例的备选方案用于水印嵌入。

本节提出了两种基于`TOPSIS`方法的鲁棒图像水印方法。第一种方法[`22`]是半盲图像水印，第二种方法[`23`]是盲图像水印。这两种方法使用四个特征/准则（偏度、峰度、熵和`DC`系数）来分析宿主图像每个分块（备选方案）的纹理性质。然后，使用`TOPSIS`方法根据纹理幅度对所有分块进行排序。之后，所提出的方法选择`10%`的高纹理块来嵌入水印。该过程增强了即使在几何攻击（如裁剪、旋转、仿射变换和平移）下也能证明宿主图像来源的能力。

这两种方法共享纹理分析阶段，但在嵌入和提取过程的实现上有所不同。图像的纹理分析主要基于`TOPSIS`方法，以识别更适合嵌入水印的高纹理块。纹理分析阶段在下一小节中介绍。随后介绍所提出的嵌入和提取过程。

所提出的基于`TOPSIS`方法的图像水印的伪代码如算法`(1)`所示。

### 15.4.1 使用TOPSIS方法的纹理分析

为了检测宿主图像中高度纹理的位置，可以应用`TOPSIS`方法基于定义的准则评估所有可能的备选方案，并根据与理想解的接近程度对其进行排序。该方法还通过使用不同的权重向量，为衡量每个使用特征对纹理分析结果的重要性和影响提供了一种实用方法。使用`TOPSIS`方法的纹理分析包括以下步骤。

- **步骤1：** 首先，根据水印的大小，将大小为`M × M`的宿主图像划分为一组不重叠的`L × L`块（备选方案）。宿主图像必须为灰度图像，其位深度等于`8`（所有像素的取值范围为`0`到`255`）。

- **步骤2：** 使用公式`15.1`至`15.4`计算每个分块的纹理特征，包括`DC`、偏度、峰度和熵。

- **步骤3：** 构建决策矩阵`X`，其中宿主图像的块(`b₁,...,b₍M/L×M/L₎`)表示备选方案集，纹理特征（`DC`、偏度、峰度和熵）表示属性（准则）集。该矩阵的条目是所有备选方案的无形属性的数值。决策矩阵的示例如下所示。

| 备选方案/准则 | DC | 偏度 | 峰度 | 熵 |
|---|---|---|---|---|
| b1 | 271.3 | -1.86 | 3.18 | 4.81 |
| b2 | -45.69 | -0.12 | -0.60 | 4.80 |
| ⋮ | ⋮ | ⋮ | ⋮ | ⋮ |
| bM/64×M/64 | -131.2 | 1.36 | 4.61 | 6.2 |

- **步骤4：** 对决策矩阵应用`TOPSIS`方法，根据与理想解`C_i^+`的接近程度对所有块进行排序。通过该步骤，所提出的模型使用公式`15.6`作为归一化方法，而不是公式`15.5`或`15.7`，因为`DC`、偏度和峰度特征的数值范围可能为负或正，而归一化步骤的目标是将所有数值归一化为`[0–1]`范围内的正值。这实际上允许对给定属性进行比较。另一方面，所提出的模型建议分配多个权重向量（`WV`）来评估所提出模型在不同情况下的性能。定义了五个权重向量如下：第一个向量为所有特征分配相同的权重，而其他每个向量为其中一个使用的特征分配高权重值，如下所示：

  - *`WV1`* = `<1/4, 1/4, 1/4, 1/4>` 为所有特征分配相同的权重值。
  - *`WV2`* = `<3/4, 1/12, 1/12, 1/12>` 为`DC`系数分配高权重值，其他特征具有相同的权重值。
  - *`WV3`* = `<1/12, 3/4, 1/12, 1/12>` 为偏度特征分配高权重值，其他特征具有相同的权重值。
  - *`WV4`* = `<1/12, 1/12, 3/4, 1/12>` 为峰度特征分配高权重值，其他特征具有相同的权重值。
  - *`WV5`* = `<1/12, 1/12, 1/12, 3/4>` 为熵特征分配高权重值，其他特征具有相同的权重值。

通过使用不同的`WV`分析所提出方法的性能，可以通过比较所有情况下获得的结果来衡量每个特征的重要性。此外，这一建议引入了一种方法，以定义哪种`WV`更适合纹理分析过程，并可能推荐给其他研究人员。

- **步骤5：** 选择前`10%`的具有最高接近度的块作为嵌入水印的首选块，以具有高不可感知性和高鲁棒性。

## 15.4.2 方法1：使用空间像素的半盲图像水印

第一种图像水印方法首先应用纹理分析阶段来识别前`10%`的高纹理块，用于水印嵌入过程。然后，它使用线性插值技术在原始图像`I`中实现水印嵌入，并使用线性插值的逆形式从受攻击的含水印图像`I_wa`中提取受攻击的水印。由于该方法在水印提取过程中需要原始水印，因此属于半盲水印。

第一种方法的总体框架如图15.4所示，嵌入和提取过程将在以下小节中介绍。

图15.4 方法1的总体框架。

图15.4显示，原始图像被划分为一组不重叠的块，构建决策矩阵并利用`TOPSIS`方法进行处理，以识别前`10%`的高纹理块用于嵌入水印。嵌入过程使用线性插值进行，结果是含水印图像`I_w`。然后，通过通信介质将`I_w`和纹理块的索引传输到接收端。接收方提取嵌入的水印以验证图像的来源。接收方假定，由于通信介质中存在各种攻击，他接收到的是受攻击的图像。使用线性插值逆形式的提取过程用于提取受攻击的水印。通过测量原始水印与提取出的受攻击水印之间的相似度，可以证明图像的真实性。

### 15.4.2.1 水印嵌入过程

使用文献[`24`]提出的线性插值技术将水印嵌入到选定的块中。该技术很有用，因为它通过选择合适的插值因子，能够在不可感知性和鲁棒性之间进行权衡。式(`15.19`)给出了线性插值技术，算法2给出了水印嵌入过程的伪代码。

#### 算法2 水印嵌入的伪代码

```text
1. **input:** host image I of size M × M, the selected textured blocks by the TOPSIS method B, original watermark image w of size L × L, and interpolation factor t = 0.99
2. dividing I into L × L, the result is n blocks
3. **for** i ← 1 to n **do**
4. **if** block_i ∈ the set of textured blocks B, block_i ∈ I **then**
   block_{i_w} ← (1 − t)w + t × block_i : t ∈ ]0, 1[  (15.19)
5. **end if**
6. **end for**
7. **output:** watermarked image (I_w)
```

### 15.4.2.2 水印提取过程

嵌入过程结束后，得到的含水印图像`I_w`将通过公共网络发送给接收方，并且会暴露在不同类型的攻击之下。因此，接收到的图像是受攻击的含水印图像`I_wa`，必须应用提取过程，通过从`I_wa`中提取受攻击的水印集合`w_a`来证明图像的来源。应用式(`15.20`)所给出的线性插值技术的逆形式，算法3给出了受攻击水印提取过程的伪代码。

#### 算法3 水印提取的伪代码

```text
1. **input:** attacked watermarked image I_wa of size M × M, the original watermark image w of size L × L, the selected textured blocks by the TOPSIS method B, and interpolation factor t
2. dividing I_wa into L × L, the result is n blocks
3. **for** k ← 1 to n **do**
4. **if** block_k ∈ the set of textured blocks B **then**
   w_a ← (1/t)w − ((1−t)/t) × block_k : t ∈ ]0, 1[  (15.20)
5. **end if**
6. **end for**
7. **output:** set of attacked watermarks (w_a)
```

## 15.4.3 方法2：使用空间像素的盲图像水印

第二种图像水印方法同样从纹理分析阶段开始，以识别前`10%`的高纹理块用于水印嵌入过程。然后，它使用每个选定块的贴近度值来实现嵌入和提取过程。同时，它使用最大贴近度值为盲水印定义公钥`α`。公钥的值根据式(`15.21`)计算。

`α ← max(closeness) / 100 × w`  (`15.21`)

其中，`w`是原始水印。

### 15.4.3.1 水印嵌入过程

该方法提出了一种新的嵌入技术，使用选定纹理块的贴近度系数。式(`15.22`)给出了嵌入方程，算法4给出了水印嵌入过程的伪代码。

#### 算法4 水印嵌入的伪代码

```text
1. **input:** the host image I of size M × M, the indexes of selected textured blocks B, the closeness values of B, and the original watermark image w of size L × L
2. dividing I into L × L, the result is n blocks
3. **for** s ← 1 to n **do**
4. **if** block_I(s) ∈ the set of textured blocks B **then**
   block_{I_w}(s) ← block_I(s) + closeness(block_I(s)) / 100 × w  (15.22)
5. **end if**
6. **end for**
7. **output:** watermarked image (I_w)
```

### 15.4.3.2 水印提取过程

水印嵌入完成后，应用提取方程(`15.23`)从受攻击的含水印图像中提取水印。首先，接收方运行纹理分析阶段，以求出受攻击纹理块的贴近度值，提取过程使用这些贴近度值和公钥`alpha`（`α`）来提取受攻击的水印。受攻击水印提取过程的伪代码如算法5所示。

如式(`15.23`)所示，提取过程是盲的。实际上，接收方仅使用公钥`alpha`（`α`）即可提取受攻击的水印，而无需了解原始水印或原始图像的任何信息。此外，提取过程中使用的公钥`alpha`（`α`）不是固定的。对于每个宿主图像，都会生成一个新密钥。这提高了水印过程对抗暴力攻击的鲁棒性。
