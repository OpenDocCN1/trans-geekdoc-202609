# 附录 B 定义

| 术语 | 定义 |
| --- | --- |
| 访问控制 | 一种防止未经授权使用信息系统资源的服务（[信息保证技术框架 [IATF], 2000](#B9781597494250000269.xhtml#ref1)）。 |
| 访问控制列表 | 在主体和对象之间实施任意和/或强制访问控制的机制（IATF, 2000）。 |
| 可审计性 | 一种安全目标，要求实体的行为能够唯一地追溯到该实体。这支持了不可否认性、威慑、故障隔离、入侵检测与防御以及事后恢复和法律行动（IATF, 2000）。 |
| 应用层防火墙 | 一种防火墙系统，其服务由维护完整 `TCP` 连接状态和排序的进程提供；应用层防火墙通常会重新对流量，使其看起来源自主机。 |
| 应用接口 | 应用用于与网络建立联系的标准调用和数据格式集。 |
| 身份验证 | 旨在建立消息或发送者有效性的安全措施。 |
| 授权 | 确定允许哪些类型活动的过程。 |
| 可用性 | 按需可访问和可用的属性。 |
| 标幅抓取 | 在建立连接时，捕获横幅信息（如应用程序类型和版本）的过程。 |
| 认证与认可 | 认证是对中间系统（`IS`）和其他保护措施的技术和非技术安全特征的全面评估，该评估支持认可过程，以确定特定设计和实现满足某一组特定要求的程度。 |
| 挑战/响应 | 一种身份验证技术，服务器向用户发送一个不可预测的挑战，用户使用某种形式的身份令牌计算响应。 |
| 通用标准 | 信息技术安全通用标准是一份安全功能和保证要求的目录，它在国家信息保证计划中起着核心作用。 |
| 机密性 | 一种防止未经授权泄露存储在计算机中、传输在本地网络中或在公共互联网上传输的信息的服务。 |
| 隐蔽通道 | 任何可以被进程利用以违反系统安全策略的方式传输信息的通信通道。 |
| 隐蔽测试 | 在组织信息技术（`IT`）人员不知情的情况下，但在高层管理完全知情并许可的情况下，使用隐蔽方法进行的测试。 |
| 深度防御 | 一种安全方法，需要多层保护为系统建立适当的安全态势；该策略基于以下概念：攻击必须渗透贯穿整个系统的多层防护才能成功。 |
| 数字证书 | 将主体身份与其公钥绑定的结构。证书颁发机构（`CA`）发布并对数字证书进行数字签名。 |
| 自主性访问控制 (Discretionary Access Control) | 一种非基于策略的方法，根据资源所有者的决策来限制对系统文件和对象的访问 (IATF, 2000)。 |
| 尽职调查 (Due Diligence) | 在执行某活动（如渗透测试）时所需的谨慎和小心。 |
| 封装安全载荷 (Encapsulating Security Payload) | 此消息报头旨在提供多种安全服务的组合，提供机密性、数据源身份认证、无连接完整性、防重放服务以及有限的流量机密性 (IATF, 2000)。 |
| 外部安全测试 (External Security Testing) | 从组织安全边界之外进行的安全测试 (NIST, 2008)。 |
| 漏报 (False Negative) | 当存在漏洞时未发出警报。 |
| 误报 (False Positive) | 错误地指示存在漏洞的警报 (NIST, 2008)。 |
| 防火墙 (Firewall) | 在两个或多个网络之间强制边界的系统或系统组合 (IATF, 2000)。 |
| 哈希 (Hash) | 在数据上计算的用于检测错误或篡改的值 (IATF, 2000)。 |
| 基于主机的安全 (Host-Based Security) | 防止单个系统免受攻击的技术；基于主机的安全取决于操作系统和版本 (IATF, 2000)。 |
| 识别与身份认证 (Identification & Authentication) | 对某种程度保证的实体的识别 (IATF, 2000)。 |
| 内部攻击 (Insider Attack) | 源自受保护网络内部的攻击 (IATF, 2000)。 |
| 完整性 (Integrity) | 一种安全目标，产生防止故意或无意破坏数据完整性或系统完整性尝试的要求 (IATF, 2000)。 |
| 入侵检测 (Intrusion Detection) | 手动或通过对网络上日志或其他可用信息的软件专家系统来检测入侵或入侵企图 (IATF, 2000)。 |
| 入侵检测系统 (Intrusion Detection System) | 一种检测和识别主机及网络上未经授权或异常活动的系统；这通过创建审计记录并根据入侵阈值检查对审计日志来实现 (IATF, 2000)。 |
| 入侵防御 (Intrusion Prevention) | 通过对网络上可用信息的软件专家系统拦截入侵或入侵企图。 |
| 恶意软件 (Malware) | 意在破坏或拒绝访问系统的恶意软件。 |
| 强制性访问控制 (Mandatory Access Control) | 一种基于策略的控制方法，用于限制对系统文件/对象的访问，其中由管理员而非资源所有者做出影响或源自访问控制策略的访问决策 (IATF, 2000)。 |
| 网络发现 (Network Discovery) | 在网络上发现活动并有响应的主机、识别弱点并学习网络如何运行的过程 (NIST, 2008)。 |
| 网络嗅探 (Network Sniffing) | 一种监控网络通信、解码协议并检查报头和负载以获取感兴趣信息的被动技术。它既是一项审查技术，也是一种目标识别和分析技术 (NIST, 2008)。 |
| 操作系统指纹 (Operating System Fingerprinting) | 分析目标发送的数据包特征（如数据包报头或监听端口），以识别目标上使用的操作系统 (NIST, 2008)。 |
| 公开测试 (Overt Testing) | 在组织信息技术（IT）人员知情并同意的情况下进行的安全测试 (NIST, 2008)。 |
| 校验位 (Parity) | 用于确定数据块是否被更改的位 (IATF, 2000)。 |
| 被动测试 (Passive Testing) | 不涉及与目标进行任何直接交互的安全测试 (NIST, 2008)。 |
| 密码破解 (Password Cracking) | 获取存储在计算机系统或通过网络传输的密码的过程 (NIST, 2008)。 |
| 渗透测试 (Penetration Testing) | 模拟攻击的安全测试。渗透测试通常使用真实攻击者使用的工具和技术，以绕过安全功能，并发现单个或多个系统中的漏洞 (IATF, 2000)。 |
| 基于边界的安全 (Perimeter-Based Security) | 通过控制网络进出点来确保安全的方法 (IATF, 2000)。 |
| 钓鱼 (Phishing) | 一种数字社会工程，利用看似真实的电子邮件诱骗用户提供信息 (NIST, 2008)。 |
| 端口扫描器 (Port Scanner) | 远程确定系统哪些端口开启的程序 (NIST, 2008)。 |
| 代理 (Proxy) | 代表用户执行的软件代理。代理通常接受用户的连接，判断 `IP` 地址是否允许，并进行额外的身份认证，然后代表用户完成连接 (IATF, 2000)。 |
| 非法设备 (Rogue Device) | 网络中未经授权的节点 (NIST, 2008)。 |
| 测试规则 (Rules of Engagement) | 关于执行安全测试的详细指南和限制。测试规则在测试开始之前建立，授权测试团队无需额外许可即可执行定义的活动 (NIST, 2008)。 |
| 清理 (Sanitization) | 对内容进行更改以符合其所在敏感等级的要求 (IATF, 2000)。 |
| 社会工程学 (Social Engineering) | 基于欺骗目标地的用户或管理员的攻击；攻击通常由攻击者致电用户并冒充授权用户，以尝试非法访问系统 (IATF, 2000)。 |
| 木洛马 (Trojan Horse) | 看起来功能正常但实际上包含后门或攻击程序的软件实体 (IATF, 2000)。 |
| 虚拟机 (Virtual Machine) | 允许单个宿主机运行一个或多个客体操作系统的软件 (NIST, 2008)。 |
| 病毒 (Virus) | 自复制代码段；病毒可能包含或不包含攻击程序或后门 (IATF, 2000)。 |
| 蠕虫 (Worm) | 在内存或网络中自我传播，而不一定修改程序。蠕虫与病毒相似，因为它具有复制能力，但与病毒的区别在于它不寻找宿主 (IATF, 2000)。 |
