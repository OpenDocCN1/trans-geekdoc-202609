## IPConfig

`ipconfig` 命令通常是你对系统进行网络配置时从工具箱中拿出的下一个工具。可以从这个工具中获得大量的知识。

互联网协议（Internet Protocol）是一套规定数据如何在互联网或其他网络上传输的规则。路由功能本质上创建了我们所知并喜爱的互联网。

IP 的功能是从源主机获取数据包，并根据包中的 IP 地址将其传递到正确的目标主机。发送的数据包含两个部分：头部（`header`）和负载（`payload`）。头部包含让信息到达其应去处的信息。负载是你希望另一个主机拥有的内容。

在实验 1.2 中，你将使用 `ipconfig` 命令。

## Tracert

现在你已经知道网络上的所有机器都需要一个 IP 地址。我住在科罗拉多州的丹佛，而我最好的朋友之一 Ryan 住在新墨西哥州的阿尔伯格基。当我向他发送消息时，信息并没有直接到达他的家里，而是经过了“跳数”（hops）——这些跳是我们之间的路由器。

`tracert` 是一个实用的诊断工具。它使用 `ICMP` 数据包确定从丹佛到阿尔伯格基的路由。你可能在 `ping` 命令中见过 `ICMP`——`ICMP` 是网络设备用于发送操作信息或错误消息的互联网协议之一。除了 `ping`，路径上的每台路由器都会将 `TTL` 值减 1 并转发数据包，给你中间路由器的时间。`tracert` 会打印数据包传输的轨迹。为什么这是你工具箱的重要部分？这是发现数据包在网络何处阻塞的方法。防火墙可以配置为过滤数据包，如果数据包被丢弃，将显示为星号。当你有许多通往同一目的地的路径时，这是一个很好的工具。

> **注意**：如果你使用的是 Linux 或 Mac，你将需要使用 `traceroute`。`tracert` 和 `traceroute` 命令基本上是一回事。区别在于你使用的操作系统。在 Linux 中命令发送的是 `UDP` 包。在 Windows 中发送的是 `ICMP echo`。

## NetStat

数学统计学是为了解决问题而收集、组织和展示数据。当你分析统计数据时，你将使用概率来修复问题。例如，在一个有 23 个人的房间里，两个人拥有同一个生日的概率是 50%。在网络安全中，生日攻击（birthday attack）是一种利用生日统计学方法的加密攻击。这种攻击可以用于找到哈希函数中的冲突。在我们网络世界中，学习你的网络统计非常有价值。

`netstat` 是一个实用工具，用于显示网络连接（入站和出站）、路由表以及作为协议统计的其他细节。它将帮助你衡量网络流量并诊断网络速度慢的问题。听起来不错对吧？从网络安全的角度来看，你能多快判断哪些端口对入站连接开放？哪些端口当前在使用中？现有连接的当前状态是什么？

`netstat` 命令的输出用于显示设备上所有连接的当前状态。这是配置和故障排除的重要部分。`netstat` 还有许多参数来回答上一段提出的问题。关于这里讨论的参数，需要记住的一点是当你将它们输入 `cmd` shell 时，例如，当我教我的 Metasploit 课程时，我们通过 `Meterpreter` shell 启动代理并扫描另一个网段。（这听起来可能像胡乱语，但请读完这本书。）你如何知道被入侵的系统上到底发生了什么？使用 `netstat` 命令和选项 `-a`（所有）以及 `-n`（地址和端口），你将获得此机器进行的所有活动网络会话列表，如图 1.8 所示。

## PuTTY

到目前为止讨论的工具都是嵌入在你的操作系统中的。这个工具需要你付出更多的努力。`PuTTY` 是一个免费、开源的终端仿真器、串行控制台和网络传输程序。它最初为 Windows 编写，也可以用于其他操作系统。`PuTTY` 是一个功能极其强大的工具，它允许你安全地访问另一台计算机，并且极有可能是 Microsoft Windows 平台上广泛使用的 `SSH` 客户端。

我相信在行业内工作了一段时间的 IT 专业人员会忘记我们曾经经历过。我们不断向自己的知识库中增加知识和经验，并感叹：“每个人都应该知道。”作为一名教育者，我不允许这样做。我的工作是向你展示如何使用工具中所有闪闪的东西。我能听到有些人说：“在你提到 `SSH` 的时候我就被你折服了！”

安全 `SSH` 是一种网络协议，用于在未加密的网络上创建加密通道。互联网是不安全的。你不希望你的数据在 Web 上自由悬挂供所有人看到！`SSH` 为管理员提供了一种安全的方法，通过强身份验证和安全的加密数据传输来访问远程系统。作为管理员，我有时的职责之一是管理我无法访问或物理上接触的计算机——从一台计算机向另一台计算机执行命令或移动文件。`SSH` 是大多数主机支持的协议。`SSH` 服务器默认运行在 `TCP` 端口 22 上。

如前文所述，`SSH` 创建了一个加密通道进行通信。`SSH` 的第一个版本于 1995 年发布。当时布拉德·派特是“最性感男人”，梅尔·吉布森的《勇敢的心灵》获得最佳影片，而 `Match` 是全新的且唯一的在线约会网站。从那时以后发生了很多变化。多年来，`SSH1` 被发现了几个缺陷，它不再被使用。当前的 `SSH2` 于 2006 年被采用，使用了更强的加密算法来提高安全性。到目前，`SSH2` 还没有可利用的漏洞，尽管有传言说国家安全局（`NSA`）可能解密 `SSH2` 流量。
