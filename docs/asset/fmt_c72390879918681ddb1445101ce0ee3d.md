
一个可能的收敛准则是检查 $\|\boldsymbol{\xi}^{(j+1)} - \boldsymbol{\xi}^{(j)}\| < \epsilon$ 是否成立，其中 $\epsilon$ 为某个用户定义的常数。使用 EM 预设处理联合 PDF $p(\mathcal{X}, \mathcal{X}^{(l)}; \boldsymbol{\xi})$ 在计算上是可行的。例如，当在指数族 PDF 范围内工作时，E-step 可能只需要计算潜在变量的少数几个统计量。指数族分布在计算上很方便，将在第 12.8 节中更详细地讨论。

### 备注 12.3

*   EM 算法由 Arthur Dempster、Nan Laird 和 Donald Rubin 在 1977 年的开创性论文 [12] 中提出并命名。该论文推广了先前发表的结果，例如 [2,38]，并作为统计学中的强大工具产生了重大影响。完整的收敛性证明见 [47]。相关讨论见例如 [29]。
*   可以证明 EM 算法收敛到 $p(\mathcal{X}; \boldsymbol{\xi})$ 的一个（通常是局部）最大值，这正是我们最初的目标。似然函数永不减小。其收敛速度比牛顿型搜索技术的二次收敛要慢，尽管在最优点附近可能实现加速。然而，该算法的收敛过程平稳，其复杂度比牛顿型方案更具吸引力，且不涉及矩阵求逆。感兴趣的读者可参考例如 [14,30,33,43] 获取更多信息。
*   EM 算法可以修改以获得 MAP 估计。为此，M-step 改为（问题 12.4）

    $$
    \boldsymbol{\xi}^{(j + 1)} = \arg\max_{\boldsymbol{\xi}}\left\{ \mathcal{Q}(\boldsymbol{\xi},\boldsymbol{\xi}^{(j)}) + \ln p(\boldsymbol{\xi}) \right\}, \tag{12.42}
    $$

    其中 $p(\boldsymbol{\xi})$ 是与 $\boldsymbol{\xi}$ 相关的先验 PDF（如果将其视为随机向量）。
*   EM 算法可能对初始点 $\boldsymbol{\xi}^{(0)}$ 的选择敏感。在实践中，可以从不同的初始点多次运行算法，并保留最佳结果。根据应用的不同，也使用过其他初始化程序。
*   **缺失数据**：EM 算法也可用于处理观测训练数据中部分数值缺失的情况。缺失值可被视为隐变量，并通过对其进行边缘化来完成似然函数的最大化。只有当数据是*随机缺失*时，此类过程才有意义；即缺失数据的原因是一个随机事件，且不依赖于未观测样本的值。

## 12.6 高斯混合模型

到目前为止，我们已经看到了许多可用于对未知随机向量 `x ∈ ℝ^(l)` 的分布进行建模的 PDF。然而，所有这些模型都将 PDF 限制在特定的函数项上。混合建模提供了自由，将未知 PDF `p(x)` 建模为不同分布的线性组合，即

```
p(x) = ∑_{k = 1}^{K} P_k p(x|k),
```

(12.53)

其中 `P_k` 是对特定贡献 PDF `p(x|k)` 进行加权的参数。为保证 `p(x)` 是一个 PDF，加权参数必须为非负且和为一 `(∑_{k = 1}^{K} P_k = 1)`。公式 (12.53) 的物理解释是：我们得到一组 `K` 个分布，`p(x|k), k = 1, 2, …, K`。每个观测值 `x[n], n = 1, 2, …, N` 都是从这 `K` 个分布中的某一个中抽取的，但我们不知道是从哪一个抽取的。我们所知道的只是一组参数 `P_k, 1, 2, …, K`，每个参数提供了样本从相应 PDF `p(x|k)` 中抽取的概率。可以证明，对于足够大的*混合数* `K` 以及对所涉混合成分的适当选择，可以任意精度地逼近任何连续 PDF。

混合建模是涉及潜变量的典型任务，即获得的观测值所源自的 PDF 的标签 `k`。在实践中，每个 `p(x|k)` 都是从已知的 PDF 族中选择的，并通过一组参数进行参数化，公式 (12.53) 可重写为

```
p(x) = ∑_{k = 1}^{K} P_k p(x|k; ξ_k),
```

(12.54)

任务是估计`P[k]`和`ξ[k]`，其中`k = 1, 2, …, K`，基于一组观测值`x[n]`，其中`n = 1, 2, …, N`。观测值集合`X = {x[n], n = 1, …, N}`构成不完整集，而完整集`{X, K}`包含样本对`(x[n], k[n])`，`n = 1, …, N`，其中`k[n]`是`x[n]`所来自的分布（PDF）的标签。此类问题的参数估计自然适合通过 EM 算法处理。我们将通过高斯混合模型的使用来演示该过程。

令

```
p(x|k; ξ[k]) = p(x|k; μ[k], Σ[k]) = N(x|μ[k], Σ[k]),
```

为简单起见，我们假设`Σ[k] = σ[k]²I`，`k = 1, …, K`。我们进一步假设观测值是独立同分布的。对于这种建模，以下成立：

*   完整数据集的对数似然由下式给出：

### 对数似然函数

$$
\ln p\left( \mathcal{X},\mathcal{K};\mathbf{\Xi},\mathbf{P} \right) = \sum\limits_{n = 1}^{N}\ln p(\mathbf{x}_{n},k_{n};\mathbf{\xi}_{k_{n}}) = \sum\limits_{n = 1}^{N}\ln\left( p(\mathbf{x}_{n}|k_{n};\mathbf{\xi}_{k_{n}})P_{k_{n}} \right).
$$

![Equation](img/si219.png) (12.55)

#### 符号定义

我们使用以下符号表示法：

**Ξ** = [**ξ**[1]^(*T*), …, **ξ**[*K*]^(*T*)]^(*T*), **P** = [*P*[1], *P*[2], …, *P*[*K*]]^(*T*), 以及 **ξ**[*k*] = [**μ**[*k*]^(*T*), *σ*[*k*]²]^(*T*)。

![Equation](img/si220.png)

换言之，通过 EM 算法需要估计的决定性参数包括所有高斯混合成分的均值和方差，以及相应的混合概率。

#### 后验概率

*   隐离散变量的后验概率由下式给出：

$$
P(k|\mathbf{x};\mathbf{\Xi},\mathbf{P}) = \frac{p(\mathbf{x}|k;\mathbf{\xi}_{k})P_{k}}{p(\mathbf{x};\mathbf{\Xi},\mathbf{P})},
$$

![Equation](img/si221.png) (12.56)

*   其中

$p(\mathbf{x};\mathbf{\Xi},\mathbf{P}) = \sum\limits_{k = 1}^{K}P_{k}p(\mathbf{x}|k;\mathbf{\xi}_{k}).$

![Equation](img/si222.png)(12.57)

我们现在拥有 EM 算法所需的所有要素。从 $\mathbf{\Xi}^{(0)}$ 和 $\mathbf{P}^{(0)}$ 开始，第 $(j + 1)$ 次迭代包含以下步骤：
