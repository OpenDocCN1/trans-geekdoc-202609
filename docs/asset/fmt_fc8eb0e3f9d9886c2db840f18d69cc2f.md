# 第 4 章 搭建你的实验室

## 引言

Дело право, толко гляди прямо. 俄罗斯谚语：“最好的答案是行动。”(Mertvago, 1995) 对于那些对学习如何进行`渗透测试`（或者如果你想显得“酷”一点，就是黑客）的人来说，有很多工具可用，但可以安全练习的目标非常少——更不用说合法目标了。对许多人来说，学习渗透策略是通过攻击互联网上的系统来实现的。虽然这提供了大量的机会和目标，但也是非法的。许多人因此入狱或支付巨额罚款和赔偿——这一切都是为了黑进网站。对于那些想要合法学习渗透测试的人来说，唯一的实际选择是创建一个渗透实验室。对于许多人来说，特别是网络领域的新手，这可能是一项艰巨的任务。此外，创建用于练习的真实场景还增加了难度，特别是对于那些不知道真实场景是什么样子的的人来说。这些障碍往往足以让许多人放弃学习如何开展 `PenTest` 项目。本章和下一章将讨论如何搭建不同的渗透实验室，并提供模拟真实的场景，提供学习（或提高）专业渗透测试员所用技能的机会。

对个人实验室的需求非常高——即使是专业的渗透测试员也会在家里搭建小型个人实验室来进行实验。需要注意的是，个人实验室与专业实验室之间是有区别的。专业实验室即使由个人维护，也可以用于识别和报告发现的漏洞。对于那些对维护专业实验室感兴趣的读者，应该跳到标题为“企业实验室”的章节。该章节将侧重于创建一个供个人使用的小型实验室，在那个环境中可以学习和复现不同的黑客技术，但许多安全特性会被放宽。个人实验室的主要目标几乎纯粹是为了教育目的，通常用于复制或创建利用程序。这与用于攻击企业资产的企业实验室不同。

## 保持简单

在尝试保持个人实验室小型化时，成本通常是保持其规模较小且易于管理的驱动因素。除非需要包含大量设备，否则可以使用虚拟机（`VM`）应用程序运行在单一系统中。此外，没有必要维护大型应用程序库。需要时可以下载开源应用程序，而且小型实验室中的系统可以轻松重新配置。除非个人实验室保留了任何敏感数据，否则可以消除许多安全控制，包括本章提到的安全问题。然而，如果实验室使用了无线连接，则应该保留访问控制。

## 设备

虽然渗透测试实验室可以使用旧的计算机设备，但旧设备具有通常不被考虑的额外成本，包括时间和电力。一个仅关注应用程序和操作系统（`OS`）攻击的个人实验室不需要任何先进的网络设备，但需要一个更强大的计算平台来处理同时运行的多个 `VMs`。在进行暴力破解或密码攻击时，更快的处理速度是有益的——这是旧系统并不总是能提供的。虽然旧系统更容易获得（总有人想把他们的旧电脑送给我），但它们实际上可能帮得不反。

提示：我发现我只需要用一台良好的笔记本电脑和 `VMware Player` 作为虚拟机引擎，就可以进行所有的应用程序和操作系统渗透测试。过去，我使用只能一次运行一个镜像的旧系统，这需要我维护多个系统；所有系统都会产生大量的热量并消耗大量的电力。凭借今天的技术，寻找更便宜、更环保的替代方案才有意义。

## 软件

对于创建个人实验室的人来说，一个优势在于在如今的信息技术环境中，企业网络中许多应用程序都是开源的，容易且免费获取。专利软件（包括 `OSes`）则是另一回事。在个人实验室中，需要做一个艰难的选择——是坚持使用开源应用程序，还是根据需要购买应用程序。虽然 `Microsoft Developer Network` 为许多 `Microsoft` 产品提供年度订阅，从长远来看可能是一个具有成本效益的替代方案，但仍然可以在网上购买旧版本的应用程序和操作系统。在某些情况下也可以免费下载试版。除非需要获取专利软件（例如复制新发现的漏洞），否则开源软件通常足够学习黑客技术，包括系统、应用程序、数据库和 Web 攻击。获取软件另一种方法是访问 `VMware`并在 `www.vmware.com/appliances/` 下载一些包含应用程序的预构建 OS 镜像。这些“虚拟设备”可以作为实验室中的目标，它们还提供了练习书中后文描述的渗透测试方法的机会。

注意：使用开源工具还有其他缺点——其中之一就是应用程序支持。大型商业工具通常会有支持人员快速响应你的问题和需要解决的故障（考虑到它们通常很昂贵，它们最好是这样）。开源工具通常没有这种支持——相反，大多数问题必须通过 wiki 页面或散落在互联网上的各种论坛进行搜索。

# 公司实验室

许多公司仍然未将安全视为提高利润的一种，并且不愿意建立公司级的渗透测试团队。这些组织通常简单地外包安全审计，并且可能外包也可能不包渗透测试。然而，许多公司正在采用不同的观点，它们正在创建风险评估小组来评估公司资产。本节将讨论具有公司支持的渗透测试实验室。公司实验室的功能与实验室不同。个人实验室的目标通常纯粹是为了教育。公司实验室包含各种黑客工具的系统，以便渗透工程师能够攻击公司资产，寻找可利用的漏洞。人们预期渗透工程师已经知道如何进行攻击和攻破漏洞，因此很少创建练习实验室。在工程师需要测试漏洞程序的情况下，通常会为渗透测试团队提供镜像生产环境的测试网络。维护和修补扫描并攻击公司资产的系统至关重要，而且通常是公司政策的强制要求。除了补丁之外，必须对系统访问进行严格控制。在渗透测试期间收集的信息极其敏感，对收集数据的未经授权访问不仅会危及目标系统，还会危及整个公司。有许多不同的方法可以防止对公司渗透实验室系统的未经授权访问，包括防火墙、访问控制和一次性密码。渗透系统周围的架构将根据公司的业务需求和渗透测试期间收集数据的敏感性而异。

## 内部实验室

在硬件和软件方面，内部和外部渗透实验室之间没有太大区别。这两者的区别在于可访问性。内部实验室位于公司的内网中，内网通常对网络资产和服务器的访问限制较少。公司网络内部的渗透测试通常比外部渗透测试获得更大的成功，主要因为系统管理员之间存在一种普遍观点，认为公司员工应该是值得信任的。内部渗透测试的目的是识别易受来自“内部威胁”攻击的漏洞。内部攻击并不仅仅归因于员工——有权访问内部服务器的承包商和供应商都是内部威胁的一部分。

**注意** 尽管好莱坞喜欢在电影情节中使用邪恶黑客入侵公司网络，但现实情况大不相同。大多数攻击（无论是有意的还是无意的）都来自员工或承包商的系统，并从公司网络内部发起，而不是从外部。渗透测试应该包含内部和外部渗透测试，以确保所有安全漏洞都被识别。

## 外部实验室
