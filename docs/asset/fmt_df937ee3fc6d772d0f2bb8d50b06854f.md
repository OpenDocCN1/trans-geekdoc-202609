
为了简单起见，我们放宽了符号表示法，不再显式依赖 `*a*`、`*b*`、`*c*` 和 `*d*`。我们将在需要时把它们重新引入。变分 EM 算法包含三个子步骤，分别对应公式 (13.26) 中的每个因子。从 `𝔼[*β*]`、`𝔼[*α*[*k*]]`、`*k*` = 0, …, `*K*` − 1 的某些初始猜测开始（稍后将清楚为何我们需要从这些开始）^(⁹⁰)

### E-步骤 1a

根据公式 (13.15) 的通用更新形式，我们有

```
ln *q*[**θ**]^((*j* + 1))(**θ**) = 𝔼[*q*[**α**]^((*j*))*q*[*β*]^((*j*))]\[ln*p*(**y**,**θ**,**α**,*β*)\] + constant
```

其中现在

```
ln *p*(**y**, **θ**, **α**, *β*) = ln (*p*(**y**|**θ**,**α**,*β*)*p*(**θ**,**α**,*β*)) = ln (*p*(**y**|**θ**,*β*)*p*(**θ**|**α**)*p*(**α**)*p*(*β*))
```

其中已考虑到给定 `***θ***` 的值后，**y** 与 **α** 相互独立。利用公式 (13.22) 和 (13.25) 以及一些简单的代数运算，我们得到

$$
\ln p(\mathbf{y},\mathbf{\theta},\mathbf{\alpha},\beta) = \ln\frac{\beta^{N/2}}{(2\pi)^{N/2}} - \frac{\beta}{2}\|\mathbf{y} - \Phi\mathbf{\theta}\|^{2} - \frac{1}{2}\sum_{k = 0}^{K - 1}a_{k}\theta_{k}^{2} + \sum_{k = 0}^{K - 1}\ln\sqrt{\frac{\alpha_{k}}{2\pi}} + \ln p(\mathbf{\alpha}) + \ln p(\beta)
$$

或

$$
\ln p(\mathbf{y},\mathbf{\theta},\mathbf{\alpha},\beta) = - \frac{\beta}{2}\|\mathbf{y} - \Phi\mathbf{\theta}\|^{2} - \frac{1}{2}\sum_{k = 0}^{K - 1}a_{k}\theta_{k}^{2} + \text{constant}
$$

其中“constant”（常数）包含所有不依赖于 `θ` 的项，因为在此步骤中我们的目标是估计 `θ` 的函数。展开公式 (13.29) 并关于 `β` 和 `α` 取期望，考虑到 `q[β]^{(j)}(β)` 和 `q[α]^{(j)}(α)` 已知，我们得到

#### 数学推导

$$
\ln q_{\mathbf{\theta}}^{(j + 1)}(\mathbf{\theta}) = \mathbb{E}_{q_{\beta}^{(j)}q_{\mathbf{\alpha}}^{(j)}}\left\lbrack \ln p(\mathbf{y},\mathbf{\theta},\mathbf{\alpha},\beta) \right\rbrack + \text{constant} = - \frac{1}{2}\mathbb{E}[\beta]\mathbf{\theta}^{T}\Phi^{T}\Phi\mathbf{\theta} - \frac{1}{2}\mathbb{E}[\beta]\mathbf{y}^{T}\mathbf{y} + \mathbb{E}[\beta]\mathbf{\theta}^{T}\Phi^{T}\mathbf{y} - \frac{1}{2}\mathbf{\theta}^{T}A\mathbf{\theta} + \text{constant}
$$

其中定义

$$
A \equiv \text{diag}\{\mathbb{E}[\alpha_0],\dots,\mathbb{E}[\alpha_{K-1}]\}
$$

为简化符号，我们使用了

$$
\mathbb{E}[\beta] \equiv \mathbb{E}_{q_{\beta}^{(j)}}[\beta] \quad \text{and} \quad \mathbb{E}[\alpha_k] \equiv \mathbb{E}_{q_{\mathbf{\alpha}}^{(j)}}[\alpha_k], \quad k = 0, 1, 2, \dots, K-1.
$$

很容易注意到，公式(13.30)的右侧关于`θ`呈二次型，因此`q_θ^(j+1)(θ)`是高斯分布；要完全确定它，只需计算相应的均值和协方差（精度）矩阵。

重新排列公式(13.30)中的项，我们得到

```
ln q_θ^(j+1)(θ) = - 1/2 θ^T (A + E[β] Φ^T Φ) θ + E[β] θ^T Φ^T y + constant
```

根据上一章附录中的公式(12.114)、(12.116)和(12.117)（可通过书籍网站获取），其结果为

`q_θ^(j+1)(θ) = N(θ | μ_θ^(j+1), Σ_θ^(j+1))` (13.32)

`Σ_θ^(j+1) = (A + E[β] Φ^T Φ)^(-1)` (13.33)

以及

`μ_θ^(j+1) = E[β] Σ_θ^(j+1) Φ^T y` (13.34)

在第一次迭代步骤中，`𝔼[β]` 和 `𝔼[α[k]]` 由其初始值提供。对于后续迭代，它们必须与 `q[β]^(j)` 和 `q[α]^(j)` 一起获得。请注意，后验概率 `p(θ|y)` 的近似（公式 (13.32)）结果呈高斯分布，尽管我们并未假设它是这样。这是所采用概率密度函数（PDF）特定形式的结果，这些函数源自指数族分布。
