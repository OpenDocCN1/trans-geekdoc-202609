
从黑客的角度来看，字典攻击的优势在于它是一种非常快速且高效的攻击类型，因为它所做的只是读取文件内容——密码破解软件无需进行任何数学计算。字典攻击的劣势在于，如今大多数密码都是复杂密码，即它们要求包含字母、数字和符号。这使得字典攻击失效，因为那些密码不是字典单词。

### 暴力破解攻击

暴力破解攻击是一种密码攻击，涉及使用密码破解软件通过数学计算尝试每一种可能的密码。通常，黑客会配置密码破解软件，设定诸如字符数量以及是否使用字母、数字和符号等要求。

从黑客的角度来看，暴力破解攻击的优势在于它非常有效——只要有足够的时间，它就能破解系统上的密码。暴力破解攻击的劣势在于完成它所需的时间。由于可能的密码数量巨大，破解密码可能需要数年时间才能完成！

![Images](img/job.jpg)

**您可以使用密码破解工具来评估网络上密码的复杂性，但请记住，黑客行为是非法的——无论出于何种原因。请务必在生产环境中运行任何攻击工具之前，获得高层管理人员的书面许可。**

## 混合攻击

另一种密码攻击称为混合攻击。混合攻击涉及密码破解软件使用字典文件，但在软件尝试了字典文件中的一个单词后，它会尝试修改该单词。破解软件将使用的修改示例包括在单词后附加数字，以及可能替换字符。例如，尝试单词 "house" 后，软件将尝试 "house1"、"house2" 等。常见的字符替换场景包括将单词中的 "a" 替换为 "@" 符号，将 "L" 替换为数字 "1"，将 "o" 替换为 "0"。图 4-11 显示了使用 LC4 进行密码审计的结果。请注意，有几个密码是通过字典攻击破解的，但用户 user5 的密码是通过混合攻击破解的。

### 密码喷射

密码喷射是一种针对用户账户的攻击类型，涉及攻击者将常用密码发送给许多不同的账户，以查看是否有任何账户正在使用该常用密码。

![Image](img/exam.jpg)

**针对 Security+ 认证考试，请了解密码喷射。还要知道，如果您查看日志文件时发现同一个密码被用于不同的账户名，这可能是密码喷射攻击。如果您发现同一个用户账户在短时间内被用于不同的登录尝试，这表明是字典攻击或暴力破解攻击，而不是密码喷射攻击。**

### 彩虹表

`Rainbow tables`（彩虹表）用于加快执行暴力破解攻击的过程。回想一下，暴力破解攻击可能需要非常长的时间。为了加快进程，黑客可以生成一个彩虹表，这是一个根据彩虹表生成器给定的标准生成的、包含所有数学上可能的密码的文件。彩虹表在黑客执行攻击时很有用，因为计算结果已经在表（文件）中；黑客只是在读取文件。因此，黑客获得了暴力破解攻击的复杂性，却拥有了字典攻击的速度。

### 明文/未加密

另一种常见的密码攻击称为 `known-plaintext attack (KPA)`（已知明文攻击），或未加密攻击。在已知明文攻击中，黑客知道密码的明文值（称为 crib）及其对应的加密版本（称为 ciphertext，密文）。有了这些信息，黑客便可以着手破解加密密钥和其他密码。

## 加密攻击和概念

在第 2 章 中，您已了解了机密性和完整性概念，在第 12 章 和 13 章 中，您将了解更多关于这些加密服务的内容，但本节我想向您介绍针对加密服务的攻击。

### 生日攻击

`birthday attack`（生日攻击）是一种针对哈希函数执行的攻击类型。研究发现，如果您尝试足够多的数据输入，您会发现两个不同的数据输入会生成相同的哈希值。这被称为生日攻击，因为该理论基于这样一个事实：当您选择一大群随机的人时，您会发现有人拥有相同的出生日期。

### 冲突攻击和降级攻击

哈希协议已知会产生冲突，即两段不同的数据产生相同的哈希值。哈希值的位数越高，两段不同数据产生相同哈希值的几率就越小。

降级攻击是一种加密攻击，攻击者强制两个系统之间的网络连接放弃高质量的加密协议，转而使用安全性较低的加密协议。攻击者这样做是为了增加破解较弱加密通信的机会。

## 在线攻击与离线攻击

如前所述，密码攻击可以是在线的，也可以是离线的。在 `online attack`（在线攻击）中，黑客尝试针对活动系统破解密码。这样做的问题是黑客有被检测到并导致账户锁定的风险。如果黑客能将用户账户数据库的副本复制到 U 盘上，黑客就可以将其带走并尝试 `offline`（离线）破解密码。

黑客不仅面临在线攻击被检测到的风险，而且通常没有足够时间在线执行完整的密码攻击，因此将账户密码的副本离线复制并在家中舒适地尝试破解，对黑客非常有利，因为不涉及时间限制。

## 其他密码攻击术语

涉及密码攻击领域时，为了准备 Security+ 认证考试，你应该熟悉许多术语。以下是你应该了解的其他密码攻击术语：

- **重放** 密码重放攻击是指黑客窃听通信并捕获从客户端系统发送到服务器的密码哈希值。一旦黑客获得哈希值，他们就会利用它冒充原始客户端并访问服务器。

- **弱实现** 密码可以加密以保护明文值，但有时加密执行得并不完美。例如，Windows 密码在 SAM 数据库中经过哈希处理，但它们被拆分为两个七字符的哈希值。这使得黑客能非常容易地判断某人是否使用了少于八个字符的密码，因为这些密码的哈希值的最后一部分将是相同的。

## 防止密码攻击

了解如何在你的环境中防止密码攻击，是任何安全专业人员的重要技能。

为防止针对系统的字典攻击，你必须实施强密码策略并要求用户使用复杂密码。`复杂密码`是指包含大小写字母混合、并使用数字和符号的密码。你还应确保用户创建的密码长度至少为八个字符。

实施密码复杂性无法保护系统免受暴力破解攻击，因此你必须实施账户锁定策略来防范此类攻击。如果你使用`账户锁定策略`，在发生一定次数的错误登录后，账户将被锁定，直到管理员解锁前无法使用。大多数公司实施的账户锁定策略会在第三次错误登录尝试后锁定账户。账户锁定策略消除了执行暴力破解攻击所需的时间；在第三次错误登录尝试后，账户即被锁定。

![Image](img/exam.jpg)

**针对 Security+ 认证考试，请记住：密码复杂性是针对字典攻击的对策，而账户锁定策略是针对暴力破解攻击的对策。**

关于密码策略和账户锁定策略，有一点必须理解：如果黑客正在执行离线密码攻击，这些策略将不起任何作用。在`离线密码攻击`中，黑客获得对系统的物理访问权限，将用户账户数据库复制到闪存驱动器，并带走数据库。随后黑客在自己的家中发起攻击，那里没有你的密码策略或账户锁定策略。黑客破解出密码后，便可使用发现的用户名和密码访问系统。

![Image](img/exam.jpg)

**离线密码攻击是指黑客将用户账户数据库从你的系统复制到闪存驱动器并带走，以便进行密码破解。在此示例中，密码攻击不会被阻止，因为在黑客的位置不存在密码策略或账户锁定策略。**

以下是一些流行的密码审计和破解工具：

- **LC4** 一款非常流行的密码审计工具，可用于访问 Microsoft 网络上的用户密码。它可以对密码执行字典、暴力破解和混合攻击。

- **Cain & Abel** 一款功能强大的密码破解程序。Cain & Abel 的优势在于它可免费下载，并能捕获网络上的密码，然后使用字典或暴力破解攻击破解这些密码。

- **NAT** NetBIOS 认证工具是一个小程序，允许你对 Windows 系统执行字典攻击。

- **Brutus** Brutus 的独特之处在于它可以通过不同的互联网应用程序（如 HTTP、FTP、POP3 和 Telnet 等）封装密码攻击。

- **John the Ripper** 一款非常流行的字典和暴力破解工具，可在 Windows 或 Linux 上运行。

# 认证总结

在本章中，你学习了当今计算环境中发生的不同类型的攻击。请务必为 Security+ 考试掌握这些攻击。以下列表总结了你所学的不同攻击类型：

- 不同类型的攻击包括社会工程学攻击、网络攻击、密码攻击和应用程序攻击。

- 社会工程学攻击是通过电话或电子邮件等社交联系方式发起的攻击，黑客试图诱骗你破坏安全性。

- 网络攻击涉及黑客跨越网络入侵系统。网络攻击的示例包括嗅探、DoS、DDoS 和中间人攻击（以前称为中间人攻击）。

- 三种类型的密码攻击分别是：字典攻击，使用字列表文件作为密码；暴力破解攻击，通过数学计算所有潜在密码；混合攻击，修改字列表文件中的条目。

- 保护环境免受社会工程学攻击的最佳方法是教育用户了解社会工程学，并培训他们在收到此类联系时该如何应对。

### 识别网络攻击

**4.** ![Image](img/boxt.jpg) **C.** 拒绝服务攻击涉及黑客通过用流量过度负担系统，导致系统无法执行其工作角色。DoS 攻击可能导致系统崩溃或变慢。

![Image](img/boxx.jpg) **A、B** 和 **D** 不正确。中间人/路径攻击（MITM）是指黑客将自己置于两个系统之间，并能够查看对话的所有部分。欺骗攻击是指黑客更改源地址，使数据看起来像是来自其他人。端口扫描攻击是指黑客扫描您的系统以查找开放端口。

**5.** ![Image](img/boxt.jpg) **D.** 当黑客将自己置于两个系统之间，在将流量转发给真实目标之前接收所有流量的副本时，这就是中间人/路径攻击（MITM）。

![Image](img/boxx.jpg) **A、B** 和 **C** 不正确。DDoS 攻击是分布式拒绝服务攻击，涉及黑客使用多个系统执行拒绝服务攻击。拒绝服务（DoS）攻击涉及黑客通过用流量使系统过载，导致系统无法执行其工作角色。网络钓鱼攻击涉及黑客诱骗用户导航到错误的网站并输入用户账户信息供黑客查看。

**6.** ![Image](img/boxt.jpg) **B.** 系统上的 `hosts` 文件用于将域名解析为 IP 地址，如果黑客获得对此文件的访问权限，可利用它将您引导至错误的网站。

![Image](img/boxx.jpg) **A、C** 和 **D** 不正确。`sam` 文件存储 Windows 系统上的用户账户，`lmhosts` 文件用于将 NetBIOS 名称解析为 IP 地址，`services` 文件用于将端口号与友好名称（如 HTTP）进行匹配。
