关于计算机安全、网络安全或信息系统安全，最重要的一点是：无论你实施多少防火墙和访问控制方法，如果没有物理安全，一旦黑客获得对系统的物理访问权限，大多数控制措施都可被绕过。例如，如果你不将 Web 服务器锁在安全位置并限制对该位置的访问，未经授权的人员可能走到系统前，从启动盘（`DVD` 或 `USB` 驱动器）引导，然后清除系统管理员密码。密码一旦被清除，未经授权的个人即可重启系统，以无密码方式登录，并拥有对系统的完全管理权限。

本章将介绍物理安全相关的概念，并帮助你备考 `Security+` 考试中的相关题目。让我们先回顾一下你已学过的几个物理安全要点。

所有关键系统（如服务器、路由器和交换机）都应放置在安全位置——通常称为*服务器机房*。服务器机房应上锁，并应监控人员进出。在服务器机房内，服务器、路由器和交换机应放置在服务器机柜中，且机柜门应上锁，以进一步控制谁有权物理接触这些关键系统。务必锁好每个系统的机箱盖，防止硬件组件被盗。大多数系统还具有机箱入侵检测功能，可在 `CMOS` 芯片中启用，以便在有人打开机箱盖时发出警报。

在保护服务器机房内的设备时，确保所有服务器都设置了 `CMOS` 密码，并将启动顺序更改为仅从硬盘引导。这有助于防止他人从启动盘引导并加载其他操作系统。

还要保护服务器机房内的路由器和交换机。确保禁用交换机上所有未使用的端口，以免未经授权的系统连接到交换机。使用交换机的端口安全功能，使只有适当的系统能连接到特定端口。此外，对于路由器和交换机，务必在控制台端口和辅助端口配置密码，确保无人能连接到交换机或路由器并更改配置。

服务器机房应只有一个入口，且持续受监控，不应有窗户。作为额外的安全层，最好将服务器机房设在人员访问受限的区域。

### 设施顾虑

# 选择商业地点时，请调研您考虑的区域

与设施安全相关的关键问题之一是您考虑区域的犯罪率。如果某个区域犯罪率较高，那么在那里建设或租赁可能就不合理，因为您的组织可能会遭受资产被盗或损坏——更重要的是，您的员工在这样的区域可能不安全。

除了犯罪率，另一个考量因素是该区域是否位于洪水区。请调查该区域洪水及其他自然灾害的历史记录，因为在易发灾区建设设施可能不值得冒这个险。

选择设施时要考虑的另一点是，急救服务（如救护车和消防部门）到达该区域需要多长时间。如果该区域难以到达，则会给您的员工和客户带来潜在的安全风险。

为设施配备带有备用电源（如电池）的应急照明装置（参见图 14-1）至关重要。该电池无需很大或提供长时间供电；它只需为应急灯供电，以便人员能安全撤离大楼。

## 门、窗与墙

建设设施时，请确保规划设施出入口的位置，使其能受到严密监控，并务必为员工提供安全的出入口。在高安全环境中，所有入口附近都应设有安保前台，以便安保人员监控人员进出。

务必确保通往安全区域的入口使用安全门，且门铰链带有不可拆卸的销钉。同时确保每扇门都装有推杆锁（panic bar），以便在紧急情况下轻松打开。

核实墙体是从真实地板延伸至真实天花板，而不是使用隔断来划分不同房间。如果使用的隔断未从真实地板延伸至真实天花板，则入侵者可能通过门上方的爬行空间（参见图 14-2）或地板下方进入安全区域。

![Image](img/f0588-01.jpg)

**图 14-2**  

确保安全区域的墙体从真实地板延伸至真实天花板。

如果设施内确实有通风管道或公用设施隧道，建议在这些区域安装运动传感器，以便在有人利用它们破坏设施安全时及时知晓。以下是一些常见的运动探测器类型：

- **闭路传感器** `closed-circuit sensor` 形成一个电路，当电路断开时触发警报，表明有人进入该区域。这通常用于窗户（带有细小导线），这样如果窗户被砸碎，电路就会断开并发出警报信号。

- **压力垫传感器** 您也可以使用压力垫，在下班后激活，这样如果入侵者进入设施并踩在材料上，警报就会响起。

- **接近传感器** `proximity sensor` 会发射并监测一个磁场。当有人靠近时，入侵者的移动会改变磁场的频率。系统检测到此变化并触发警报。这种运动传感器容易产生大量误报。

- **光电传感器** `photoelectric sensor` 会从发射器向接收器发射一束光。当入侵者遮挡光束时，会触发警报。

## 安全顾虑

物理安全的很大一部分在于确保您为员工创造了一个安全的环境。例如，您需要确保设施和停车场拥有适当的照明以阻止窃贼。以下是一些增加安全性的物理安全组件的其他示例：

- **标识** 确保设施拥有适当的标识，标明所有出口，以便员工在紧急情况下能迅速找到出口。

- **逃生路线** 确保已规划好逃生路线，以应对火灾或洪水等紧急情况。

- **逃生计划** 制定逃生计划并传达给所有员工。

- **演练** 定期进行演练（如消防演练），以测试逃生计划以及所有员工使用适当逃生路线的及时性。

- **测试控制** 测试所有安全控制措施以确保其有效性。例如，务必定期测试火灾报警器和灭火器。

#### 围栏与人员

物理安全的第一道防线位于设施场地的周界。在高安全环境中，控制谁能进入组织财产至关重要，甚至在他们到达大楼之前。控制对组织财产访问的两种最常用方法是周界围栏和警卫。

##### 周界围栏

在高安全环境中，应考虑在财产周界周围设置围栏，以阻止入侵者闯入。有了周界围栏，你就迫使任何想进入设施的人都必须通过主大门，在那里你可以对进出设施的每个人实施安全检查。

![Image](img/exam.jpg)

**针对认证考试，请知悉：为阻止蓄意入侵者，推荐的围栏高度为 8 英尺，顶部加装朝向入侵者、呈 45 度角的带刺铁丝网。**

围栏的高度取决于你的目标。如果你想阻止偶然入侵者，通常会选择 3 到 4 英尺高的围栏。请记住，4 英尺高的围栏很容易翻越，因此如果你想阻止偶然攀爬者，推荐的围栏高度是 5 到 7 英尺。蓄意入侵者不会在翻越 7 英尺高的围栏上遇到麻烦，所以要阻止此类入侵者，推荐的围栏高度是 8 英尺，顶部加装三道朝向入侵者、呈 45 度角倾斜的带刺铁丝网。

##### 警卫

当你在财产周界周围实施围栏时，你需要设置一个安检关卡，安排警卫检查进出场地的所有人员。关卡警卫将核实访客是否受邀前往该设施，然后通常发给他们一张“访客”工牌，要求始终佩戴。员工进入设施时需要出示员工工牌以获取访问权限。工牌上将有员工姓名和照片。

关卡警卫将监控离开设施的人员，并设法确保设备不被盗走。在物理安全计划中增加安保警卫还有一个额外好处：警卫可以识别异常活动。我曾与一位客户交谈，他说如果员工带着笔记本电脑或其他计算机设备离开，这些设备会在出门时在关卡处被核实。警卫会核实该员工是否被允许携带设备离开，并让他们在登记表上签字。这是为了防止公司资产内部被盗。

根据组织所需的安全级别，你可能会在整个设施内安排警卫，以确保不发生安全事件。警卫应接受培训，留意在设施内行走的所有人员是否佩戴工牌，并盘问任何没有工牌的人。在我曾获得访客工牌的一个客户设施中，授权我进入的那位先生告诉我将工牌别在左侧。该组织严格要求所有人员将工牌佩戴在同一位置，以便安保人员轻松查看工牌。

##### 机器人哨兵

作为物理安全计划的一部分，你可以包含哨兵机器人，这些是配备高清摄像头的移动机器人。这些机器人可用于巡逻场地并在巡逻时录制视频。你也可以获得配备夜视和运动检测功能的哨兵机器人，当检测到运动时，它们可向你的手机发送通知。

##### 前台接待

大多数公司都有前台接待区，你必须先在那里登记，才能越过接待区进入设施内部。在这种情况下，你通常在前台登记，然后在接待区等待，直到你的联系人来接你。你可能需要将访客工牌别在衬衫显眼处，以便安保人员识别你是访客。

## 双人完整性/控制

关于物理安全的另一个重要概念是双人完整性 (TPI) 控制。通过 TPI，公司要求两人在场才能访问特定资产，从而保护其资产或数据。这允许每个人在资产被使用时验证安全程序是否得到遵循。

#### 硬件锁/锁类型

控制对设施或房间访问的最流行方法之一是在门上实施锁定系统。传统锁（也称为物理锁）易于撬开，且易受撞匙攻击。`撞匙` 是一种被锉薄以适配锁芯的普通钥匙——将钥匙插入锁芯并向外拔出一档。当敲击钥匙时，会导致锁芯内的销钉对齐，从而打开门。

你可以购买防撬锁（成本较高），这能提供额外的安全性，即锁不易被破坏，但如今大多数公司在高安全环境中使用电子锁定系统。电子锁定系统的两种常见类型是电子钥匙系统和电子组合锁。使用 `电子钥匙系统` 时，员工会获得一个编码了其访问代码的 `令牌` 设备。当员工将令牌在电子传感器前刷过时，门就会解锁（参见 图 14-3）。

![Image](img/f0594-01.jpg)

**图 14-3**

使用令牌和电子传感器进入设施

使用 `电子锁`（也称为 `电子组合锁`）时，员工在锁上输入个人识别号 (PIN) 以获取访问权限。我见过一种电子键盘，在按下开始按钮之前按钮上没有数字。一旦按下开始按钮，系统会随机生成数字的排列位置，因此如果有人观察你的手指位置，也无法帮助他们猜出访问代码。电子组合锁也称为 `密码锁`。

无论使用哪种电子锁定系统，组织都可以根据访问代码控制员工有权进入哪些区域。这些系统还可以记录访问日志，包括员工访问设施或设施不同区域的日期和时间。

锁定区域也可通过 `生物识别` 访问，它利用你自身的特征来开门。例如，你可以通过视网膜扫描、语音识别或指纹读取来开门。

# 物理安全控制

## 线缆锁

另一种类型的锁是*线缆锁*，用于锁定笔记本电脑、显示器、台式机和投影仪等设备。例如，您可以使用线缆锁将前台接待员的台式电脑和显示器固定在桌子上，这样当无人在场时，他人不易随意拿走设备。

## 访问系统

组织可以通过多种称为访问系统的方法来控制对设施的访问。本节介绍您在 Security+ 考试中可能会遇到的一些常见访问系统。

访问系统的组件可被视为故障安全型或故障保密型。两者的区别如下：

- **故障安全** 故障安全设备在发生故障时不会执行任何导致危害的操作。例如，如果锁发生故障，它默认为解锁状态，以便人员进出。这也称为*故障开放*，因为门将默认处于打开状态。

- **故障保密** 故障保密设备在发生故障时确保设备处于安全状态。例如，如果锁发生故障且为故障保密锁，它将默认为锁定状态。这也称为*故障关闭*，因为门将默认处于锁定状态且无法打开。

## ID 徽章

如前所述，在高安全环境中，员工必须佩戴显示姓名和照片的 ID 徽章。组织的安全策略还可能要求员工始终保持 ID 徽章可见，这意味着他们必须将徽章显眼地佩戴在衣服或挂绳上。

进入某些区域可能需要将 ID 徽章在读卡器上刷卡。徽章通常带有磁条，存储员工访问代码。如果员工被授权访问该物理区域，门将打开。ID 徽章还可能包含芯片，用于存储身份识别信息，例如用于控制对系统和资源访问的数字证书。
