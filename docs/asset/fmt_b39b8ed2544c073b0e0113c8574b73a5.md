
与归一化类似，白化可以提高机器学习算法的性能。前面的代码已对原始数据 `X` 进行投影以获得投影后的 `Xrot`；即 `Xrot` 的特征相互独立，然后执行除以标准差的操作以完成白化操作。由于原始数据仅为 2 维，为了观察白化操作的效果，未对数据进行降维。

```
Xwhite = Xrot / np.sqrt(S + 1e-5)    # 白化操作：将数据特征除以
                                     # 标准差，使所有特征具有相似的方差
plt.plot(Xwhite[:,0],Xwhite[:,1],'o')
plt.axis('equal')
plt.show()
```

## 5.2 参数调试

### 5.2.1 权重初始化

对于回归问题，模型的权重通常初始化为 0。对于神经网络，如果权重参数初始化为 0，一层中的所有神经元将学习到相同的参数；即一层中的所有神经元是同一个函数。神经网络退化为每层仅有一个神经元的线性序列（如图 5-21 所示）。

**图 5-21** 神经网络退化为每层仅有一个神经元的线性序列

**图 5-22** 2 层神经网络

以图 5-22 所示的 2 层神经网络为例。由于初始权重值为 0，隐藏层和输出层中所有神经元的输入权重值均为 0。假设同一层神经元的激活函数相同：

`a^[2] = g(a^[1]W^[2] + b^[2])`

反向推导时，可得：

`∂L/∂a^[1] = ∂L/∂z^[2] (W^[2])^T = ∂L/∂a^[2] g'(z^[2]) (W^[2])^T`

`∂L/∂W^[2] = (A^[1])^T ∂L/∂z^[2] = (A^[1])^T ∂L/∂a^[2] g'(z^[2])`

因此，隐藏层中每个神经元的 `∂L/∂a_i^[1]` 都相同。同理，`∂L/∂W_i^[w]` 也相同。以此类推，每一层都相同。

因为同一层中每个神经元的模型参数梯度 `dW` 将相同。当使用 `W = W - lr * dW` 更新模型参数时，每个参数 `W` 也将完全相同。再次迭代时，同一层中每个神经元的输出又相同，因此反向推导时梯度 `dW` 仍相同。无论迭代多少次，同一层中所有神经元都具有相同的权重参数；即它们表示同一个函数；即它们都是对称的。

显然，这种神经网络的表达能力非常有限，每层中的多个神经元毫无意义。神经网络应打破这种对称性，使每个神经元从输入中提取不同的特征。解决方法是给这些权重赋予随机初始化值。从上述反向推导公式可知，偏置参数 `b` 对模型参数和输入的梯度计算没有影响。因此，通常只需随机初始化权重参数，并将偏置参数设为 0 即可。上述简单神经网络可按如下方式初始化其模型参数：

```
W1 = np.random.randn(2,2)*0.01 
b1 = np.zeros((1,2))
W2 = np.random.randn(2,1)*0.01 
b2 = np.zeros((1,1))
```

将权重参数乘以一个较小的数，类似于数据归一化预处理，使神经元的加权求和输出不会过大，因为对于较大的值 `x`，激活函数 `sigmoid(x)` 或 `tanh(x)` 处于饱和状态；即该点的导数（梯度）接近 0，激活函数梯度过小会导致反向推导过程中模型参数的梯度变得越来越小，导致模型参数更新缓慢，这就是**梯度消失**问题。根据反向推导，过大的值也会使梯度变得非常大；即**梯度爆炸**。

权重初始化值是否越小越好？因为神经元输入的梯度（如 `∂L/∂a^[1]`）与权重（`W^[2]`）成正比，过小的权重参数也会使关于输入的梯度过小，这在反向推导过程中也会导致“梯度消失”。如果权重参数的初始值过小，例如接近 0，也会在一定程度上导致上述神经元的对称性问题。因此，通常权重参数用均值为 0、标准差为 0.01 的高斯分布进行初始化。

上述初始化权重的神经元输出方差将随输入值的数量而变化。神经元输出的方差不应取决于输入值数量的常数值。否则，随着层数增加，方差会越来越大。为此，可将权重参数除以输入数量的平方根，使神经元输出的方差归一化为 1；即代码 `w = np.random.randn(n)/sqrt(n)` 初始化权重参数，其中 `n` 是该神经元的输入值数量。

如果 `x = (x[1], ..., x[i], ..., x[n])` 是一个输入样本，`n` 是其特征值的数量，`z` 是神经元的输出值，则 `z` 的方差与 `x` 的方差关系如下：

```
Var(z) = Var(∑ᵢⁿ wᵢ xᵢ)
       = ∑ᵢⁿ Var(wᵢ xᵢ)
       = ∑ᵢⁿ [E(wᵢ)]² Var(xᵢ) + E[xᵢ]² Var(wᵢ) + Var(xᵢ) Var(wᵢ)
```

最后一个等式应用了方差的性质：如果两个随机变量 `X`、`Y` 独立，则：

`Var(XY) = [E(X)]² Var(Y) + [E(Y)]² Var(X) + Var(X) Var(Y)`

假设输入和权重的均值为 0，即 `E[x[i]] = E[w[i]] = 0`，则：

$$

\begin{matrix} 

Var(z) & = \sum\limits_{i}^{n} Var(x_{i}) Var(w_{i}) \\ 

& = (n Var(w)) Var(x) \\ 

\end{matrix}

$$

输出值的方差 `Var(z)` 不仅与输入值的方差 `Var(x)` 和权重的方差 `Var(w)` 成正比，还与输入值 `x[i]` 的数量 `n` 成正比。

当输出方差等于输入方差时，即 `Var(z) = Var(x)`，也就是说输入数据 `x` 通过神经元后，输出方差不会变大或变小，从而使神经元的输入和输出保持稳定。

为了使 `Var(z) = Var(x)`，`Var(w)` 应为 $\frac{1}{n}$。根据 `Var(aX) = a² Var(X)`，如果 `w` 从标准正态分布采样，则 `Var(w) = 1`，将 `w` 乘以常数 $a = \frac{1}{\sqrt{n}}$，则 `Var(aw) = a² Var(w) = 1`。因此，权重可以用以下代码初始化：

```
w = np.random.randn(n) * sqrt(1.0/n) 
```

根据类似的分析，一些论文提出了其他不同的参数方法，例如 Glorot 将标准正态分布的权重参数 `w` 乘以 $\sqrt{2/(n_{in} + n_{out})}$，使得 `Var(w) = 2/(n[in] + n[out])`，其中 `n[in]`、`n[out]` 分别是网络层的输入和输出向量。其目的是使梯度在反向传播过程中方差不变。当然，这两项的结合会相互影响，导致正向和反向推导的方差实际上都会发生变化。

权重也可以服从均匀分布：$w \sim U\lbrack - \frac{\sqrt{6}}{\sqrt{n_{in} + n_{out}}}, \frac{\sqrt{6}}{\sqrt{n_{in} + n_{out}}}\rbrack$，et al. 提出的这种权重初始化方法称为 **Xavier 初始化**，其代码实现如下：

```
import numpy as np
import math

def calculate_fan_in_and_fan_out(tensor):
    if len(tensor.shape) < 2:
        raise ValueError("tensor with fewer than 2 dimensions")
    if len(tensor.shape) == 2:
        fan_in, fan_out = tensor.shape
    else:  # F, C, kH, kW
        num_input_fmaps = tensor.shape[1]   # size(1)  F, C, H, W
        num_output_fmaps = tensor.shape[0]  # size(0)
        receptive_field_size = tensor[0][0].size
        fan_in = num_input_fmaps * receptive_field_size
        fan_out = num_output_fmaps * receptive_field_size   
    return fan_in, fan_out

def xavier_uniform(tensor, gain=1.):    
    fan_in, fan_out = calculate_fan_in_and_fan_out(tensor)
    std = gain * math.sqrt(2.0 / float(fan_in + fan_out))
    bound = math.sqrt(3.0) * std  
    tensor[:] = np.random.uniform(-bound, bound, tensor.shape)

def xavier_normal(tensor, gain=1.):
    fan_in, fan_out = calculate_fan_in_and_fan_out(tensor)
    std = gain * math.sqrt(2.0 / float(fan_in + fan_out))
    tensor[:] = np.random.normal(0, std, tensor.shape)
```

其中，函数 `calculate_fan_in_and_fan_out()` 用于计算网络层（神经元）的输入特征数和输出特征数，`gain` 是权重的可选缩放因子，默认为 1。

对于使用 ReLU 作为激活函数的神经元，目前更常用 Kaiming He 的权重初始化方法，即将标准正态分布采样的权重乘以 $\sqrt{2/n}$，代码如下：

```
w = np.random.randn(n) * sqrt(2.0/n) 
```

对于使用 ReLU 激活函数的网络层，其偏置参数 `b` 建议设置为非零常数（如 0.01），这可以使该激活函数在训练开始时影响梯度，但将偏置设置为非零值是否真的能提高算法性能尚无定论。

以下是 Kaiming 方法的实现代码：

```
def calculate_gain(nonlinearity, param=None):   
    linear_fns = ['linear', 'conv1d', 'conv2d', 'conv3d', 'conv_transpose1d', 'conv_transpose2d', 'conv_transpose3d']
    if nonlinearity in linear_fns or nonlinearity == 'sigmoid':
        return 1
    elif nonlinearity == 'tanh':
        return 5.0 / 3
    elif nonlinearity == 'relu':
        return math.sqrt(2.0)
    elif nonlinearity == 'leaky_relu':
        if param is None:
            negative_slope = 0.01
        elif not isinstance(param, bool) and (isinstance(param, int) or isinstance(param, float)):           
            negative_slope = param
        else:
            raise ValueError("negative_slope {} not a valid number".format(param))
        return math.sqrt(2.0 / (1 + negative_slope ** 2))
    else:
        raise ValueError("Unsupported nonlinearity {}".format(nonlinearity))
        
def kaiming_uniform(tensor, a=0, mode='fan_in', nonlinearity='leaky_relu'):
    fan_in, fan_out = calculate_fan_in_and_fan_out(tensor)
    if mode == 'fan_in':       
        fan = fan_in
    else: 
        fan = fan_out
        
    gain = calculate_gain(nonlinearity, a)
    std = gain / math.sqrt(fan)
    bound = math.sqrt(3.0) * std  
    tensor[:] = np.random.uniform(-bound, bound, tensor.shape)

def kaiming_normal(tensor, a=0, mode='fan_in', nonlinearity='leaky_relu'):
    fan_in, fan_out = calculate_fan_in_and_fan_out(tensor)
    if mode == 'fan_in':     
        fan = fan_in
    else: 
        fan = fan_out
    
    gain = calculate_gain(nonlinearity, a)
    std = gain / math.sqrt(fan)
    bound = math.sqrt(3.0) * std  # Calculate uniform bounds from standard deviation    
    tensor[:] = np.random.normal(0, std, tensor.shape)
```

`calculate_gain()` 用于 Kaiming He 方法（也称 Kaiming 方法或 He 方法）中的某个系数。例如，ReLU 的值为 $\sqrt{2}$，tanh 的值为 5.0/3。`kaiming_uniform()` 和 `kaiming_normal()` 分别使用均匀分布和高斯分布随机值的 Kaiming 方法。

以下函数 `kaiming()` 根据参数选择 `kaiming_uniform()` 或 `kaiming_normal()` 方法：

```
def kaiming(tensor, method_params=None):
    method_type, a, mode, nonlinearity = 'uniform', 0, 'fan_in', 'leaky_relu'
    if method_params:
        method_type = method_params.get('type', "uniform")
        a = method_params.get('a', 0)
        mode = method_params.get('mode', 'fan_in')
        nonlinearity = method_params.get('nonlinearity', 'leaky_relu')
    if method_type == "uniform":
        kaiming_uniform(tensor, a, mode, nonlinearity)
    else:
        kaiming_normal(tensor, a, mode, nonlinearity)   
```
