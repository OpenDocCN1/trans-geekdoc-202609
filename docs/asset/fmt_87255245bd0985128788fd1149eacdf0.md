## 13.1 简介

随着大数据的出现，医疗记录变得越来越大且更加复杂，但它们尚未得到优化。常见的情况是发现使用相同标识符和姓名的重复记录。这些记录存储在医疗架构的不同网络和目录中 [[1]](#C_018_c13.xhtml#r13_1)。由于医疗数据高度敏感，数据安全变得至关重要，以防止安全漏洞和非法活动。如果未经授权的用户获得患者信息，该信息可能被出售给对手或从医院泄露。患者的个人信息可能会在公共领域暴露 [[2]](#C_018_c13.xhtml#r13_2)，[[3]](#C_018_c13.xhtml#r13_3)。为了成功管理医疗保健，保护患者数据至关重要。包含更多易被篡改的个人和敏感数据的分布式网络，可以使用区块链技术进行保护。更新或向区块链添加交易的唯一方式是通过哈希值；这也确保了现有交易无法被篡改 [[4]](#C_018_c13.xhtml#r13_4)。

制药行业现已成为任何国家的重要资产，因为它确保了药品和其他医院必需品的适当供应。制药行业现在正演变为传统和现代工业概念的结合体 [[5]](#C_018_c13.xhtml#r13_5)，[[6]](#C_018_c13.xhtml#r13_6)。这些行业拥有非常复杂的工作环境。对制药行业进行优化、控制和监控以实现安全和可持续的工作非常重要。区块链是一项非常安全的技术，可用于供应链（SC）以及数据完整性管理。在制药行业中使用区块链将带来各种解决方案，可实现行业的完整性和安全性 [[7]](#C_018_c13.xhtml#r13_7)，[[8]](#C_018_c13.xhtml#r13_8)。区块链具有非常特定的数据结构。此外，它可高效用于追踪和监控。区块链的使用将有助于通过确保传输中和存储中的数据完整性，使制药行业更加可靠。本文力求涵盖区块链的关键方面，以提升制药行业。

总之，本文的主要贡献如下：

*   本文展示了医疗保健和制药行业的演变。
*   本文展示了区块链应对医疗生态系统的贡献及其与追踪和监控的相关性。
*   本文审视了医疗保健和制药行业的各种关键挑战及其利用区块链的解决方案。

## 13.2 医疗保健及其演变

由于医疗保健行业的快速发展，生活质量得到了提高，因此具有重要的社会意义。医疗保健领域解决实际健康问题，进而有助于提高生活质量 [9]。通过使用计算机执行任务，如共享一致信息、临床培训与诊断协作、计算机化医疗记录系统以及大数据分析，医疗保健系统已取得显著进步 [10, 11, 12]。

医疗保健系统已发展壮大，并帮助制药行业变得更具竞争力，克服了诸多挑战 [13]。为了更好地管理医疗记录，用户（如医生、社工和护士）可为患者提供更高质量的护理。通过计算机，可采用多种方法来帮助组织和管理患者护理所需的信息 [11, 13, 14]。

计算机中预先存储的数据可提供关于患者状况的重要医疗信息。这些数据可被组织并用于调查疫情以及不同地区的医疗设施。不同领域的研究人员利用这些数据来理解现象并克服特定挑战 [11]。由于这些信息涉及患者的个人信息，必须严格保密。患者个人信息泄露给公众可能会对医疗机构的声誉产生负面影响 [11]。为避免不道德或尴尬的情况，必须保护患者的临床信息，防止其被泄露。

区块链技术激励了各种研究人员和专业人士寻找解决方案，以创建更安全、更可靠的医疗保健系统 [12, 15, 16]。除了区块链的不可篡改性、透明性和可靠性外，其他因素还能缓解医疗保健中与患者数据相关的隐私和完整性问题 [15, 17]。基于区块链的医疗保健系统仍面临需克服的困难 [18]。由于网络的核心特性未被明确规定，很难追踪信息可访问性背后的相互关联 [19]。控制和管理药品分销是区块链的众多应用方式之一，这可通过在供应链的所有阶段实施区块链来实现 [20, 21, 22]。除了打击假冒药品外，区块链还有助于防止药品转移和盗窃 [21]。值得注意的是，根据 Dash 等人 [23] 的研究，国际商业机器公司 (IBMC) 的一项研究表明，约 16% 的医疗管理人员计划在其工作环境中将区块链作为解决方案实施。此外，56% 以上的医疗高管计划优先实施区块链。总而言之，区块链可在各种医疗领域场景中发挥作用并受到追捧 [24]。有必要分析其后续的优势、劣势、机会和威胁。具体而言，该技术揭示了许多可为未来技术带来隐私和安全的关键点 [25]。Babenko 等人 [25] 通过提供简要的系统性领域评估、所调查的实施搜索约束的简要讨论以及一些与该主题相关的工作，简要讨论了这些系统的优缺点。物联网 (IoT) 技术结合区块链在医疗保健领域也得到非常有效的应用。Cai 等人 [26] 讨论了去中心化应用 (DApps) 在特定加密货币中的众多分发场景，并检查了区块链的一些基本特征。它提供了与医疗保健相关的当前区块链工作的深度分析。相比之下，本研究提供了区块链在各种场所实施的全面概述，并描述了其可能性。

## 13.3 区块链技术的作用

一项名为区块链的先进技术于 2008 年左右随加密货币启动 [27, 28]。最近，区块链在医疗保健、政府、金融、交通和其他领域执行一些精确任务。利用这项新技术，用户资产可被更高效、更安全地记录 [18]。Rouhani 等人 [29] 调查表明，它也可被理解为一种基于分布式账本理念的点对点 (P2P) 网络，并可被视为一种去中心化技术。区块链数据结构通过将每个区块与指向创世区块的加密哈希指针相链接，按时间顺序链接区块。因此，默克尔树 (MT) 将区块内的交易分组并分发到各节点 [30]。

比特币、莱特币和以太坊等加密货币已向公众开放 [28]。这些理念促成了其他类型加密货币和基于区块链技术的发展。Hoy 等人 [31] 将先进的区块链技术分类为区块链 1.0、2.0 和 3.0。区块链的第一阶段以比特币等加密货币的到来为特征（Berentsen [28]），并伴随着简单资产转移系统的出现而同时推出。随着区块链 2.0 的出现，创新协议（智能合约）变得可见 [32]，并发现了新的使用方式，如贷款、房地产基金和其他投资。区块链的演进阶段是区块链 3.0，它适用于金融和社会的其他领域，如科学、制药和艺术。去中心化、不可篡改性、分布式账本、透明性、隐私性和智能合约是区块链的特征 [33, 34]。

加密货币（如 `bitcoin` 和 `Ethereum`）的出现增加了人们对区块链和智能账本研究的兴趣。区块链技术以一种可靠且绝对的方式累积和共享分布式数据，无需中介即可进行数据共享。它不需要交易确认集中化 [35, 36]。在区块链中，透明性使得跨网络访问基于账本的交易变得更加简单；网络可以连接来自多个节点的不同算力，因此其计算速度极快 [37]。区块链包含各种技术和设施。简述如下。

*   **哈希密码学**：区块链使用 `SHA256` 哈希添加交易。这是由美国国家安全局（NSA）创建的，具有 64 位字符代码、单向加密、确定性函数、增强计算和雪崩效应以抵抗碰撞。哈希算法也需要是确定性的。
*   **分布式 P2P 网络**：跨多个用户分发和更新数据。交易通过网络传输。
*   **共识协议**：区块链网络拥有各自的共识协议，该协议决定允许哪些用户进行交易。
*   **不可变账本**：区块链网络记录所有交易，共享账本无法被第三方访问或修改。
*   **挖矿**：奖励由源自 `nonce` 值的哈希值决定，为了获得奖励，矿工必须拥有高算力。

区块链网络可以复制到另一个不同的位置，以便与学者、合作机构或其他相关组织（如保险提供商）共享医疗数据。区块链是一个由连接的计算机组成的网络，它们共享数据并确保其准确性、可靠性和一致性。因此，区块链可以在一个位置填充数据，并分发到同一网络上的另一个或多个额外位置。此外，这些新位置将数据传输到整个网络，最终允许位置访问分发给整个网络中每个人的最新数据。

### 13.3.1 区块链网络的类型

存在几个不同的区块链群组，每个群组都有其特征，反映了网络行为。就区块链的特性而言，Gautam 等人 [38] 描述了区块链的分类。区块链的类型枚举如下。

*   **公有区块链**：所有节点间保持交易透明。网络中的任何节点均可使用共识机制验证区块链交易。网络管理员无需授权即可允许该节点加入。此类网络内的节点能够以前所未有的水平进行通信与协作。`Bitcoin` 和 `Ethereum` 等加密货币即此类网络的示例 [34]。
*   **许可区块链**：该网络中的节点仅在获得组织事先授权后才被允许加入结构，该组织也控制其交易 [34]。由于访问该网络上的内容需要认证过程，因此提供了更高程度的保密性。Multichain Platform (MP) 是此类平台的一个示例 [39]。
*   **联盟区块链**：由于由一个群体管理且加入网络需要认证，因此与许可区块链共享部分特征。其特点是极少数验证节点可通过预定义功能验证交易。在此类网络中，验证交易需要选定节点间的相互同意，从而创建新区块并完成流程 [40]。

### 13.3.2 区块链中的有效性验证流程

区块链被用于许多算法实现中，其中算法（如 `proof-of-work (PoW)`）将区块链验证过程定义为挖矿 [28]。共识算法确定节点为验证区块必须遵循的规则。它遵循交易应执行的顺序，以确保验证节点从所有节点接收到满意的响应。区块可基于这些决定插入链中 [40, 41]。区块链已成为更可靠的网络，归功于旨在验证区块的共识协议。医疗区块链的分析需要以下提及的关键协议。

*   **PoW**：在此认证过程中，多个节点解决加密谜题（即矿工）。节点可通过找到解决方案来创建有效区块以进行交易并验证它。还值得注意的是，某些 `PoW` 实现（如 `Bitcoin`）会向获胜者提供奖励 [28]。在医疗场景中，它可用于检查有效交易。
*   **权益证明**：选择验证者时会考虑其在网络中的参与度。该节点将通过验证拥有更多代币的区块来确定区块的真实性 [42, 43]。这可以识别涉及的节点是医疗系统中的有效用户还是入侵者。
*   **实用拜占庭容错 (PBFT)**：该系统中的节点分为两类：客户端和服务端。`PBFT` 通过多个过程验证交易，例如客户端节点向提供商节点请求交易。服务提供商节点广播交易以决定是否接受。节点在获得服务端节点对交易的接受后广播就绪消息。在这种情况下，只要许多节点批准交易，它就会进入“确认警报”阶段；节点确认交易后，向其他节点发送消息以验证其行为，最后发送方收到响应，确认交易是否有效 [43, 44]。

### 13.3.3 面向医疗生态系统的区块链

在医疗行业，区块链的采用已分为多个阶段。在初始阶段，区块链可直接供医疗服务提供商访问；现有的医疗信息技术（IT）系统追踪并存储所有临床数据。区块链网络的应用程序接口（API）利用患者 ID 传输各种患者数据。智能合约允许在区块链系统中执行入账转移。每笔区块链网络上的交易均使用患者公共 ID（非个人信息）。不可变账本将区块链接在一起。然后，为每笔交易分配一个唯一标识符。因此，医疗服务提供商通过 API 发起挖矿过程或查询处理。区块数据库中可用的信息仅包括患者的非可识别特征，包括性别、年龄和疾病。通过分析临床数据可发现新见解。最后，患者若希望披露身份，也可选择与其医疗服务提供商共享私钥。这样，提供商即可访问患者数据，进而针对已识别症状提供护理或解决方案。任何没有患者私钥的人都无法访问数据，因此数据保持机密。

### 13.3.4 制药领域的区块链：挑战与机遇

#### 医疗保健领域的区块链挑战

区块链是一个多学科概念，这使其更适合应用于多个领域，尽管区块链存在多种局限性和挑战 [18]。目前正在进行多项研究，以减弱或克服这些因素的影响。在医疗保健领域，区块链技术面临诸多挑战，其中一些如下所述。

##### 13.3.4.1 吞吐量
