## 17.5 冒泡排序

冒泡排序是一种按升序或降序对数据结构进行排序的算法。在此算法中，以嵌套方式使用两个循环。内层循环确保将最大或最小元素放置在数据结构的开头或末尾。外层循环的迭代次数等于数据结构中的元素数量。我们将编写一个程序，从用户处读取 5 个整数，将它们放入数组，并使用冒泡排序按升序对数组进行排序。

```go
/*使用冒泡排序对数组排序*/
/*包声明*/
package main

/*导入语句 - 导入 fmt、strconv 包*/
import (
	"fmt"
	"strconv"
)

/*强制性的 main 函数*/
func main() {
	/*声明变量*/
	var arr [5]int
	/*声明两个循环计数器*/
	var i, j int
	/*声明一个变量临时存储作为字符串的数字*/
	var num_str string
	/*提示用户输入 5 个元素，使用 for 循环*/
	for i = 0; i < 5; i++ {
		fmt.Printf("\n 请输入索引 %d 处的元素: ", i)
		fmt.Scanln(&num_str)
		/*将 num_str 转换为整数*/
		num, err := strconv.Atoi(num_str)
		/*将 num 赋值给 arr[i]*/
		arr[i] = num
		/*将 err 赋值给空标识符*/
		_ = err
	}
	fmt.Printf("\n 原始数组: %d\n", arr)
	arr_length := len(arr)
	/*冒泡排序*/
	for i = 0; i < arr_length; i++ {
		for j = 0; j < i; j++ {
			if arr[j] > arr[j+1] {
				temp := arr[j]
				arr[j] = arr[j+1]
				arr[j+1] = temp
			}
		}
	}
	fmt.Printf("\n 排序后的数组: %d\n", arr)
}
```
