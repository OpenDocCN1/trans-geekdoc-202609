
4. 将小波系数 `W[j]` 乘以 `G~`。

5. 将较低分辨率 `C[j]` 处的信号系数乘以 `H~`。

6. `W[j]G~ + C[j]H~` 的逆傅里叶变换给出系数 `C[j-1]`。

7. `j = j - 1` 并返回步骤 3。

使用带限缩放函数允许在每个尺度上减少采样并限制计算复杂度。

WT 已广泛用于 EEG 信号分析。其在癫痫发作检测（特别是针对新生儿）、神经元电位建模以及 EP 和 ERP 检测中的应用将在本书相应章节中讨论。

### 4.5.2 同步挤压小波变换

同步挤压小波变换（SSWT）已作为一种后处理技术被引入，以增强通过应用 WT 获得的 TF 频谱 [\[23\]](#c04.xhtml#c4-bib-0023)。假设输入 `f(t)` 是纯谐波信号（`f(t) = Acos(ωt)`），利用 Plancherel 定理，从 (4.20) [\[23\]](#c04.xhtml#c4-bib-0023) 推导出以下方程：

```
W(a, b) = ∫_{-∞}^{∞} f(t) a^{-1/2} ψ̅((t-b)/a) dt = 1/(2π) ∫_{-∞}^{∞} f̂(ε) a^{1/2} ψ̂̅(aε) e^{ibε} dε = 1/(4π) ∫_{0}^{∞} [δ(ε-ω) + δ(ε+ω)] a^{1/2} ψ̂̅(aε) e^{ibε} dε = A/(4π) a^{1/2} ψ̂̅(aω) e^{ibω}
```
(4.59)

上述方程（式 4.59）中的一个假设是所选母小波集中在正能量范围内，这意味着 `ψ̂(ε) = 0`，对于 `ε < 0`。如果 `ψ̂(ε)` 集中在 `ε = ω [0]` 附近，则 `W(a, b)` 集中在 `a = ω [0]/ω` 附近。这分布在水平线的一个区域上（例如 `a = ω [0]/ω`）。在 `ω` 与输入信号的实际瞬时频率（IF）几乎但不完全相似的情况下，`W(a, b)` 具有非零能量。通过同步挤压，其思路是将该能量从 `ω` 处移开。SSWT 中提出的方法旨在重新分配更接近实际 IF 的频率位置，以获得增强的频谱。为此，首先计算候选 IF。对于这些 IF，`W(a, b) ≠ 0`：

```
ω(a, b) = -i (W(a, b))^{-1} ∂/∂b W(a, b)
```
(4.60)

考虑选定的纯谐波信号 `f(t) = Acos(ωt)`，很容易观察到 `ω(a, b) = ω`。候选瞬时频率被用来恢复实际频率。因此，采用了一种重分配技术，利用 `(b, a) ⇒ (b, ω(a, b))` 将时域映射到时频域。在此基础上，`W(a, b)` 的每个值（在离散值 `a[k]` 处计算）被重分配到 `T[f] (ω[l], b)` 中，如以下方程（Eq. 4.61）所示：

```
T_f(ω_l, b) = (Δω)^{-1} ∑_{a_k: |ω(a_k, b) - ω_l| ≤ Δω/2} W(a_k, b) a_k^{-3/2} (Δa)_k
```
(4.61)

其中 `ω[l]` 是最接近原始点 `ω(a, b)` 的频率，`∆ω` 是频率箱 `[ω_l - 1/2 Δω, ω_l + 1/2 Δω]` 的宽度，`∆ω = ω[l] − ω[l − 1]`，且 `(∆a)[k] = a[k] − a[k − 1]`。`T[f] (ω[l], b)` 表示在连续频率箱中心 `ω[l]` 处的同步挤压变换。对于每个固定的时间点 `b`，应使用 Eq. (4.103) 估算所有尺度的重分配频率。对于每个期望的 `ω[l]` 瞬时频率，`T[f] (ω[l], b)` 通过对所有 `W(a[k], b)` 求和来计算，条件是重分配频率 `ω(a[k], b)` 与 `ω[l]` 之间的距离必须在指定的频率箱宽度 (`∆ω`) 之内。已证明原始信号可以在同步挤压过程后重构 [\[23\]](#c04.xhtml#c4-bib-0023)。
