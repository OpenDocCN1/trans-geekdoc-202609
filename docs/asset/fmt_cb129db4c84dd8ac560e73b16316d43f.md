## 简介

黑客攻击通常指未经授权侵入网络或计算机，通常由一名或多名“黑客”实施。然而，黑客可以是任何人，他们的活动不一定是恶意的或未经授权的才算作黑客攻击。黑客攻击可以指利用技能以聪明的方式实现目标。他们可以是像你我这样的个人。他们可以单独行动，也可以受雇于组织，为好或为坏服务。通常，他们试图修改安全系统以实现其目标。

许多组织雇佣黑客作为其员工的一部分。这些黑客利用他们的技能来发现组织安全中的漏洞。这样做是为了发现并修复弱点，防止恶意黑客攻破安全系统。

### 黑客类型

白帽、黑帽和灰帽指的是黑客与他们攻击的系统之间的关系。

#### 黑帽黑客

“黑帽”一词源于西部电影，其中坏人戴黑帽子，好人戴白帽子。黑帽黑客是指试图未经授权进入系统或网络，并出于恶意原因加以利用的个人。黑帽黑客没有任何许可或授权来攻击其目标。他们试图通过破坏安全系统、更改网站和网络的功能或关闭系统来造成损害。他们这样做通常是为了窃取或获取密码、财务信息和其他个人数据。

#### 白帽黑客

另一方面，白帽黑客被视为好人，他们与组织合作以增强系统的安全性。白帽黑客有权在规定的交战规则内接触目标并对其进行攻击。白帽黑客通常被称为道德黑客。该人员专精于道德黑客工具、技术和方法论，以保护组织的信息系统。与黑帽黑客不同，道德黑客在合法获许的情况下利用安全网络并寻找后门。白帽黑客总会披露他们在公司安全系统中发现的每一个漏洞，以便在恶意行为者利用这些漏洞之前进行修复。Facebook、Microsoft 和 Google 等财富 50 强公司也使用白帽黑客。

#### “灰帽”黑客

灰帽黑客以黑帽黑客的方式利用网络和计算机系统，但没有任何恶意意图，会向执法机构或情报机构披露所有漏洞和弱点。通常，灰帽黑客在网上冲浪并侵入计算机系统，以通知管理员或所有者其系统/网络包含一个或多个必须立即修复的漏洞。灰帽黑客也可能勒索被黑客攻击者，提出以微薄的费用修复缺陷。

## 最流行的黑客技术——社会工程学

社会工程学是网络安全专业人员用来谈论我们所有人都容易遭受数据窃取的多种方式的通用术语。社会工程学通常是指利用人类乐于助人的本能来达到犯罪目的的过程。社会工程学问题已经演变多年，但今天它是网络攻击和网络恐怖主义的主要来源。通过技术缺陷安装的恶意软件仅占 3% 的实例，而社会工程学攻击高达 97%。黑客攻击模式已从针对软件或硬件转变为更专注于人类漏洞。

### 不同类型的社会工程学攻击

#### 网络钓鱼

91% 的数据泄露以网络钓鱼的形式出现，使其成为被利用最多的社会工程学形式。网络钓鱼是一种网络犯罪，通过向目标发送电子邮件，诱骗个人提供个人信息、银行和信用卡详情、电子邮件或社交媒体账户密码或其他机密信息。网络钓鱼骗局通常表现出以下特征：

*   试图获取个人信息、密码或其他银行相关详情。
*   发送缩短的链接，重定向到可以追踪你详细信息的受感染网站。
*   结合紧迫感、威胁或恐惧，操纵受害者在思考前做出反应。

这种社会工程学攻击的一个完美例子是 2018 年美国报税日后一个月发生的网络钓鱼骗局，当时犯罪分子发送误导性电子邮件索要纳税申报详情。这是为了获取账户访问权并利用信息提交欺诈性纳税申报。

#### 冒充

网络犯罪分子经常寻找攻破系统的最薄弱环节，而最薄弱的环节往往是人类。冒充需要付出大量努力来了解目标并规划攻击，因此这是最不常见的社会工程学形式。冒充者为实施攻击可能承担的一些常见角色包括 IT 高管、经理、审计师或同事。通常，冒充攻击针对具有权威的角色，因为当人们收到来自权威人士的要求共享信息的请求时，他们会立即行动，而不验证发件人的真实身份。尽管与其他形式的社会工程学攻击相比，冒充攻击并不常见，但 2017 年此类攻击激增了近 400%。

#### 语音钓鱼

语音钓鱼，或称 vishing，作为一种社会工程学形式正在快速增长。语音钓鱼攻击是指攻击者致电目标组织，试图通过电话获取信息和凭证。另一种语音钓鱼骗局是攻击者试图让电话另一端的人在其电脑上执行某些操作。这些操作包括运行桌面脚本和查看受感染的网站。这些攻击难以监控和追踪，不幸的是，在人力资源部门、客户服务、销售和市场营销等部门工作的员工极易受到这些攻击。从 2012 年到 2016 年，一群网络犯罪分子实施了大规模的 IRS 语音钓鱼骗局。在这四年里，美国有 15,000 多名受害者因这一复杂的骗局损失了“数亿美元”，且 50,000 多人的个人信息遭到泄露。

#### 短信钓鱼

短信钓鱼是“SMS phishing”（短信网络钓鱼）的混成词，类似于网络钓鱼，但通过短信实施。短信钓鱼犯罪分子通常向通过各种黑帽技术（如网络爬虫、数据泄露或随机号码生成器）获取的联系号码发送信息。骗子发送的信息使用不同技术诱导你分享他们想要的信息。他们可能承诺提供理想产品的优惠券或折扣，或者冒充你的银行以验证你的账户详情。你也可能收到来自“5000”等可疑号码或其他与电子邮件转短信服务相关的号码发来的短信，这些可能是自动化的。据 NBC Nightly News 报道，一起短信钓鱼骗局试图诱骗受害者通过电话输入私人信息来激活新信用卡。在另一起短信钓鱼骗局中，用户被告知其在线账户即将过期，需要通过在假网站上输入密码来续订账户。

## 常见黑客工具

为了实施完美的黑客攻击，黑客会实施各种各样的技术，例如：

### Rootkit（根工具包/隐藏工具）

Rootkit 是一套程序或软件工具集，允许威胁行为者获得远程访问权限，以控制与互联网交互或连接的计算机系统。最初，Rootkit 的开发是为了在系统中打开一个后门以修复特定的软件问题。不幸的是，黑客现在利用该程序破坏合法操作员或用户对操作系统的控制。在受害者系统中安装 Rootkit 有多种方法，最著名的是社会工程学和网络钓鱼攻击。一旦安装了 Rootkit，它就会秘密允许黑客访问和控制系统，给他们机会瘫痪系统或窃取关键数据。

### 键盘记录器

这是一种专门设计的工具，用于记录系统上按下的每一个按键。键盘记录器通过在通过计算机键盘输入时挂钩 `API`（应用程序编程接口）来记录每一个按键。记录的文件随后被保存，其中包括用户名、网站访问详情、截图、打开的应用程序等数据。只要输入，键盘记录器就能捕获信用卡号、个人消息、手机号码、密码和其他详细信息。通常，键盘记录器以恶意软件的形式到达，允许网络犯罪分子窃取敏感数据。

### 漏洞扫描器

漏洞扫描器对网络、计算机、通信系统等中的各种系统弱点进行分类和检测。这是道德黑客用来寻找潜在漏洞并立即修复的最常见做法之一。另一方面，黑帽黑客也可以使用漏洞扫描器来检查系统的潜在弱点，以便利用系统。

## 黑客和罪犯常用的软件

除了使用不同的攻击技术从用户和组织那里破解和窃取密码外，网络犯罪分子倾向于使用密码破解和解密软件。以下是一些流行的软件：

### John The Ripper (JTR)

该软件旨在破解一些最复杂的密码，因为它可以“离线”破解密码。JTR 接受不同的文本字符串样本，通常称为“字典”，其中包含字典中常见的复杂和流行单词或之前破解过的真实密码。该工具同时使用密钥和加密算法，并将输出与加密字符串进行比较。JTR 还可用于对字典攻击执行各种变体。

### Aircrack-ng

该工具/软件用于破解无线密码；由训练有素的用户使用时效果非常好。Aircrack-ng 是一款 802.11 WPA-PSK 和 WEP 密钥破解软件，当在监听模式下捕获到足够的数据包时，可以恢复密码。在渗透测试和审计无线网络方面经验丰富的专业人士可以从该软件中获得最佳效果。

### Cain and Abel

这款极其流行的工具通常简称为“Cain”。其核心是 Cain and Abel 密码破解工具，用于恢复 Microsoft Windows 的密码，但也可被全球的黑客和罪犯用作密码破解工具。

### THC Hydra

该工具与 JTR 类似，不同之处在于 THC Hydra 在线工作。这款黑客工具支持多种网络协议，如 `LDAP`、`SSH`、`VNC`、`Mail` (`IMAP`、`POP3` 等)、`SMB` 和数据库。THC Hydra 是一款必不可少的黑客工具，用于登录稳定的网络，使用字典和暴力攻击破解登录页面中复杂的强密码。

## 常见密码破解技术

### SQL 注入攻击

结构化查询语言 (`SQL`) 旨在利用数据库中的数据。SQL 注入是一种网络攻击，它通过 `SQL` 语句针对数据库以欺骗系统。这种攻击通过网站界面执行，试图通过数据库发出 `SQL` 命令以窃取用户名、密码和其他数据库信息。编码不善的 Web 应用程序和网站容易受到 SQL 注入攻击，因为这些基于 Web 的应用程序包含用户输入字段（如搜索和登录页面、产品和支持请求表单、评论部分等），这些字段脆弱且易于通过操纵代码进行攻击。

### 分布式拒绝服务攻击 (DDoS)

DDoS 是一种恶意攻击，它扭曲正常流量以进入服务器，淹没网络流量（导致拒绝服务）。它就像交通堵塞堵塞道路，阻止正常交通到达目的地。易于连接网络的设备（如计算机、物联网设备、手机等）容易受到 DDoS 攻击。

### 猜密码游戏

顾名思义，这种技术完全依赖于猜测用户的密码。像“password”、“qwerty”、“admin”、“default”、你的名字，甚至你的生日等密码常被用作默认密码。如果用户未更改默认密码，或在设置新密码时粗心大意，则很容易被黑客攻击。

### 暴力破解攻击

暴力破解攻击是黑客和网络犯罪分子针对 Web 应用程序最常用的技术之一。此类攻击的主要重点是使用试错技术猜测用户的密码或个人识别号 (`PIN`)，以获取用户账户的访问权限。暴力破解攻击会有条不紊地尝试一个接一个的密码，直到攻击者成功登录目标账户。例如，攻击者将使用自动化工具尝试 Password，然后是 Password1、Password2、Password3 等，并在定义的键空间（a-z、A-Z、0-1 等）内迭代每一个可能的选项。通过使用机器人在几秒钟内测试大小写字母和数字的随机组合以生成你账户的正确密码，攻击者可以访问你的账户！还有一种称为反向暴力破解攻击的类似技术，攻击者不是黑客攻击特定用户，而是尝试使用单个常用密码攻击多个账户。

### 字典攻击

字典攻击使用预定义的字典，通过系统化过程针对单个用户名或整个组织的用户名以获取系统访问权限。由于许多用户经常使用字典中常见的基本单词作为密码，因此黑客使用此方法获得访问权限的可能性很高。几乎每种语言（真实和虚构）都有字典文件，甚至按流派或主题分类。例如，如果你的服务器名为 Gandalf，那么包含《指环王》书籍和电影中的单词和语言的中土世界字典文件可能会很有效。阻止字典攻击的最佳方法是使用多词（随机组合的小写、大写字符和数字）密码。
