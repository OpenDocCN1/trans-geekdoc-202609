获得一个量子群实际上是对代数进行变形或量子化，即改变代数结构使得该代数不再满足交换律。然而，某些其他结构及其性质保持不变。该过程可以在图 17.6 中描述如下。可以从群上的代数及其变形的以下几个方面来考虑：

- 2. 连续函数 `C(G)`。如果 `G` 是一个拓扑群（由 Woronowicz 提出）；
- 3. 形式幂级数（由 Drinfeld 提出）；
- 4. 量子包络代数（由 Jimbo 提出）；
- 5. 形式化的指数序列（更准确地说，指数序列环的形态在 h 中且为自由代数。当 h = 0 时，它满足类似于 `U(g)` 的某些相关性。从这个环中，可以提取 `U_q(g)`，由 Drinfeld 提出）。

### 17.5.3.1 函数代数的量子化

#### 定义 17.22
结合 `K`-代数 `A_0` 的交换性被量子化，这依赖于参数 `ħ` 的变换，即 `K[[ħ]]`-代数 `A` 的一种组合，使得

- (1) 作为 `K[[ħ]]`-mod `A` 拓扑自由；
- (2) 作为 `K`-代数 `A` 的组合，我们有 `A/ħ A ≅ A_0`。

注意，如果给定一个量子化 `A`，`A_0` 等价于 `A/(ħ A)`，你可以在 `A_0` 上定义一个括号（泊松括号）`{,}` 如下：

```
{ \overline{a} , \overline{b} } = < \overline{a b - b a} > / ħ , ∀ a , b ∈ A ,
```

其中 `\overline{a}` 表示在模同态 `A → A/ħ A` 下的像，依此类推。泊松括号满足

```
{ a , b c } = { a , b } c + b { a , c } , ∀ a , b , c ∈ A_0 (17.11)
```

其中算子 `b ↦ { a , b }` 对于代数复 `A_0` 是一个微分算子。这表明 `A_0` 将这些括号带入一个泊松代数。如果要求通过上述方法获得的 `A_0` 上的泊松括号是原始泊松括号，我们就得到了泊松代数的量子化，这在量子力学中有着悠久的历史。

**例 17.1.** 考虑双代数 `M = Fun( \overline{M} , (n , K) )`。为了获得其量子化，设 `\overline{M}` 是在 `K[[ħ]]` 上由 `n^2` 个元素 `\breve{X}_{ij} (i , j = 1 , 2 , ⋯ , n)` 生成的结合代数，满足以下关系：

```
\breve{X}_{ij} \breve{X}_{ik} = q^{-1} \breve{X}_{ik} \breve{X}_{ij} , ∀ j < k ,
\breve{X}_{ij} \breve{X}_{kj} = q^{-1} \breve{X}_{kj} \breve{X}_{ij} , ∀ i < k ,
\breve{X}_{ij} \breve{X}_{kl} = \breve{X}_{kl} \breve{X}_{ij} , if i < k , j > l ;
\breve{X}_{ij} \breve{X}_{kl} - \breve{X}_{ki} \breve{X}_{ij} = (q^{-1} - q) \breve{X}_{il} \breve{X}_{kj} , if i < k , j < l . (17.12)
```

这里，`q = e^{π i / 2}`，且 `char K = 0`。容易看出，`\overline{M}` 作为结合代数的量子化即为 `M`。事实上，`\overline{M}` 或 `M` 是一个双代数量子化，`\overline{M}` 上的乘法和乘法映射定义为：

```
Δ( \breve{X}_{ij} ) = Σ_k \breve{X}_{ik} ⊗ \breve{X}_{kj} and ε( \breve{X}_{ij} ) = δ_{ij} . (17.13)
```

通过这种方式，`\overline{M}` 定义了 `M(n, k) - M_q(n, K)` 的一些量子化。我们还得到了 `GL(n, k)` 和 `SL(n, k)` 的量子一般线性群 `GL_q(n, k)` 以及量子特殊线性群 `SL_q(n, k)`，而上述两个霍普夫代数表示为 `Fun(GL_q(n, K))` 和 `Fun(SL_q(n, K))`。

我们也可以将 `q` 视为 K 的非零元素。当 `q ≠ 1` 时，`Fun(GL_q(n, K))` 和 `Fun(SL_q(n, K))` 既不是交换的，也不是结合交换的。

### 17.5.3.2 李代数的量子化

在经典群论中，李代数起着极其重要的作用，因此预计量子群理论中存在类似于李代数的结构，这引导了对量子代数的研究。另一方面，李代数的通用包络代数是剩余交换的霍普夫代数，因此它也可以用来用量子交换代替霍普夫代数来量子化霍普夫代数。

#### 定义 17.23
`K`-代数 `C_0` 的量子化，其中 `C_0` 依赖于参数 h 的变形，这是一个 `K([h])`-代数 `C`。那么，

- (1) 作为 `K([h]) - mod C` 拓扑自由；
- (2) 作为 `K`-代数 `A`，有 `C/hC ≃ C_0`。

## 17.5.4 量子群的表示

在下文中，我们将分别从函数代数和量子包络代数的角度详细阐述量子群的表示。

### 17.5.4.1 函数代数的概念

中国数学家王建盘与美国弗吉尼亚大学的 Brian Parshall 教授合作，利用量子代数的视角对量子线性群的表示进行了深入的研究，并提出了量子线性群的表示。他们使用的一个重要方法是表示的限制与诱导，其中诱导函子具有一些在代数群中已知的性质，如左正合性、普适映射性质、张量积恒等式以及保持单射性。最后一个性质可用于证明 G 模型具有足够的射影对象，从而可以引入各种上同调，例如固定点上同调。

必须指出的是，在此视角下提出的方法不能推广到除了量子一般线性群 `GL_q(n, k)` 和量子特殊线性群 `SL_q(n, k)` 之外的量子子群。

### 17.5.4.2 量子包络代数的视角

如上所述，当 `q` 不是单位根时，与单一李群相关的量子群表示论问题主要归因于量子包络代数的表示论。由于量子包络代数出现得早于相应量子群函数代数的精确定义，而且因为量子包络代数的表示本质上是代数表示，其数学理论早已足够完善以用于研究。不仅在时间上远远早于函数代数的代数表示理论研究，而且在量子包络代数的理论广度上也是如此。根据量子包络代数的思想，我们可以研究所有 `U_q(g)` (`g` 是单一李代数) 的表示论。根据函数代数的概念，我们只能处理 `GL_q(n, k)`（但这个群很难用量子包络代数来处理）和量子特殊线性群 `SL_q(n, k)`。

从量子包络代数关于量子群表示的视角来看，值得一提的是，H. H. Andersen 及其合作者法国数学家 P. Polo 和 Winks，根据代数表示论建立了一套更系统的 `\hat{U}_q(g)` 表示论，并从量子群表示的观点来看，它更容易被量子群理论所接受，包括被物理学家接受。

## 17.6 纤维丛

#### 定义 17.24
一个纤维丛 `(E, M, π)` 由底流形 `M` 和丛空间 `E` 组成，并且在纤维丛 `E` 和底流形 `M` 之间存在一个投影变换 `π: E → M`。相应的逆变换在 `M` 上的每个点 `x` 产生纤维 `F_x`，`π^{-1}: x → F_x`。纤维 `F_x` 是一个称为通过 `x` 点的纤维的 `k`-维向量空间。

#### 定义 17.25
设 `E` 和 `M` 是两个光滑流形，`π: E → M` 是一个光滑满射，`V = R^q` 是一个 `q`-维向量空间。如果在 `M` 上存在一个开覆盖 `{U_α, α ∈ I}` 和一组映射 `{ψ_α; α ∈ I}`，它们满足以下条件：

- (1) `∀ α ∈ I`，映射 `ψ_α` 是从 `U_α × R^q` 到 `π^{-1}(U)` 的光滑同胚，并且对于任何 `p ∈ U_α, y ∈ R^q` 有

`π ∘ ψ_α(p, y) = p .`

- (2) 对于任何固定的 `p ∈ U_α`，令

`ψ_{α, p}(y) = ψ_α(p, y), ∀ y ∈ R^q`

### 向量丛与联络

则映射 `ψ_{α,p} : R^q → π^{-1}(p)` 是一个同胚映射，且当 `p ∈ U_α ∩ U_β ≠ ∅` 时，映射

`g_{βα}(p) = ψ^{-1}_{β,p} ∘ ψ_{α,p} : R^q → R^q`

是一个线性同构，即 `g_{βα}(p) ∈ GL(q)`；

(3) 当 `U_α ∩ U_β ≠ ∅` 时，映射 `g_{βα} : U_α ∩ U_β → GL(q)` 是光滑的。`(E, M, π)` 被称为光滑流形 `M` 上秩为 `q` 的向量丛，其中 `E` 称为总空间，`M` 称为底流形，映射 `π : E → M` 称为丛投影。

为方便起见，向量丛 `(E, M, π)` 也简记为 `π : E → M` 或 `E`。在以下讨论中，除非另有说明，纤维丛均指向量丛。

向量丛 `E = ∪_{x ∈ M} F_x` 是底流形 `M` 上所有点的纤维的并集，它是以流形 `M` 为参数的向量空间族。局部区域可以表示为参数空间 `U` 与向量空间 `F` 的拓扑乘积 `U × F`，但丛的整体不能通常表示为普通的拓扑乘积。

纤维丛是流形乘积的推广。直观上，向量丛 `E` 是流形乘积与纤维结合的结果。在结合时，要求纤维的线性结构保持不变。纤维中的 `n`-维向量称为截面。例如，球面的内蕴几何可以看作嵌入三维欧几里得空间中的二维黎曼流形。在纤维丛的语言中，这个球面称为底空间，球面上每一点的切平面是纤维，逆映射 `π^{-1}`（将球面上的每一点对应到切平面中的向量，即定义在球面上的二分量向量场）是截面。平移矢量坐标微分变化的扩张系数是联络。
