我们首先从一般马尔可夫链的一些基本概念开始。任何此类链由其初始状态和**转移算子** `k(x \to x')` 定义——即从 `x` 开始转移到 `x'` 的概率。现在我们运行马尔可夫链 `t` 步，`π_t` 是在 `t` 时状态处于 `x` 的概率。同样，`π_{t+1}(x')` 是在 `t+1` 时处于状态 `x'` 的概率。给定 `π_t(x)`，我们可以通过对系统在 `t` 时可能处于的所有状态转移到 `x'` 的概率求和，计算出 `π_{t+1}(x')`：

转移算子

`π_{t+1}(x') = \sum_{x} π_t(x)k(x \to x').`

如果 `π_t = π_{t+1}`，我们称该链达到了**平稳分布**。我们将此平稳分布称为 `π`；其定义方程为

平稳分布

`π(x') = \sum_{x} π(x)k(x \to x')` 对于所有的 `x'`。(13.11)

### 遍历性

转移算子 `k` 是**遍历的**——也就是说，每个状态都可以到达其他任何状态，且没有严格周期性的循环——对于给定的 `k`，有一个分布 `π` 满足该方程。

方程 (13.11) 可以理解为：每个状态的期望“流出”（即其当前的“人口”）等于所有状态的期望“流入”。满足这种关系的一种显而易见的方法是任意两个状态之间的期望流量在两个方向上相同；即：

`π(x)k(x \to x') = π(x')k(x' \to x)` 对于所有的 `x`。(13.12)

### 详细平衡

当方程成立时，我们称 `k(x \to x')` 与 `π(x)` 满足**详细平衡**。一种特殊情况是自环 `x = x'`，即从状态到其自身的转移。在这种情况下，详细平衡变为 `π(x)k(x \to x) = π(x)k(x \to x)`，这对于任何平稳分布 `π` 和任何转移算子 `k` 都是平凡成立的。

我们可以通过对方程 (13.12) 中的 `x` 求和，来证明详细平衡意味着简单性。我们有

```
\sum_{x} π(x)k(x \to \mathbf{x}') = \sum_{x} π(x)k(x \to \mathbf{x}') = π(\mathbf{x}') \sum_{x} k(\mathbf{x}' \to x) = π(\mathbf{x}')
```

其中最后一步遵循从 `\mathbf{x}'` 的转移必然发生。

# Gibbs 采样的有效性

我们现在将证明 Gibbs 采样返回了后验概率的一致估计。基本断言是显而易见的：Gibbs 采样过程的平稳分布恰好是给定证据的无证据变量的后验分布。这一显著特性源于 Gibbs 采样过程从状态移动到状态的具体方式。

Gibbs 采样的通用定义是：选择一个变量 `X_i`，然后根据所有其他变量的当前值对其条件采样。（当应用于贝叶斯网络时，我们利用另一个事实：对所有变量进行条件采样等同于对变量的马尔可夫边界进行条件采样，如第 437 页所示）。我们将用 `X` 来表示这些其他变量（证据变量除外）；它们在当前状态下的值为 `x`。

为了写出 Gibbs 采样的转移算子 `k(x \to x')`，需要考虑三种情况：

- 1. 状态 `x` 和 `x'` 在两个或更多变量上不同。在这种情况下，`k(x \to x') = 0`，因为 Gibbs 采样只改变单个变量。

- 2. 状态在一个变量 `X_i` 上不同，其值从 `x_i` 变为 `x'_i`。此类情况发生的概率为 `k(x \to x') = k(x_i, \mathbf{x}_{-i} \to x'_i, \mathbf{x}_{-i}) = \rho(i)P(x'_i | \mathbf{x}_{-i})`。

- 3. 状态 `x = x'`。在这种情况下，可以选择任何变量，但采样过程产生的值与变量已有的值相同。

## Metropolis-Hastings 采样

Metropolis-Hastings 采样或 MH 采样可能是最实用的 MCMC 算法。与吉尔斯采样类似，MH 设计用于根据目标概率 `π(x)` 生成样本 `x`；在贝叶斯网络的情况下，我们希望 `π(x)=P(x|e)`。模拟退火（132页），MH 在采样的每次迭代中包含三个阶段：

- 给定当前状态 `x`，从提议分布 `q(x'|x)` 中采样一个新的 `x'`。

- 根据接受概率接受或拒绝 `x'`：

```
a(x'|x) = \min \left(1, \frac{π(x')q(x|x')}{π(x)q(x'|x)}\right)
```

如果提议被拒绝，状态将保持在 `x`。MH 的转移由这两个步骤组成。注意，如果提议被拒绝，链将留在相同状态。提议分布正如其名称所示，用于提出下一个状态 `x'`。例如，`q(x'|x)` 可以定义为：

- 以 0.95 的概率执行吉尔斯采样以生成 `x'`。

- 否则，通过运行 458 页的加权采样算法来生成 `x'`。

这种提议分布导致 MH 在新状态处（假设它被接受）从头开始“重新启动”过程。通过这种策略，它解决了吉尔斯采样卡在状态空间某一部分且无法到达其他部分的问题。你可能会问，MH 如何使用这种奇特的提议分布实际上能收敛到正确答案。MH 的奇妙之处在于，只要生成的转移是遍历的，收敛到正确分布是有保证的。

这一性质源于接受概率的定义方式。与吉尔斯采样一样，当 `x \neq x'` 时，自循环满足详细平衡，只有当提议被接受时才会发生这种转移：

```
k(x\to x') = q(x'|x)a(x'|x).
```

采样证明详细平衡意味着从 `x` 到 `x'` 的流量 `π(x)k(x\to x')` 等于从 `x'` 到 `x` 的流量。在代入上述 `k \to x'` 的表达式后，证明是非常简单的：

```
π(x)q(x'|x)a(x'|x) = π(x)q(x'|x) \min\left(1, \frac{π(x')q(x|x')}{π(x)q(x'|x)}\right) \quad \text{(}a(\cdot|x) \text{ 的定义)}
\quad = \min\left(π(x)q(x'|x), π(x')q(x|x')\right) \quad \text{(相乘)}
\quad = π(x)q(x'|x) \min\left(1, \frac{π(x')q(x|x')}{π(x)q(x'|x)}\right) \quad \text{(除掉)}
\quad = π(x')q(x|x')a(x')
```

在接受的数学性质上，MH 需要关注的重要部分是接受概率中的比率 `π(x')/π(x)`。如果提议的新状态比当前状态概率高，它一定会被接受。（我们暂时忽略了 `q(x'|x)/q(x|x')` 项，该项是为了确保详细平衡，并在许多状态空间由于对称性等于 1。）如果提议的状态比当前状态概率低，被接受的概率会比例下降。

因此，设计提议分布的一个准则是让被提议的新状态具有可能的。从吉尔斯分布 `P(X_{-i})` 进行吉尔斯采样意味着，生成 `X_i` 的任何特定值的概率与其概率直接成正比（练习题 13.GIBM 要求你证明吉尔斯采样是接受概率为 1 的 MH 特殊情况）。

另一个准则是确保链良好混合，这有时意味着提议到状态空间不同部分的大范围移动。在上面的示例中，偶尔使用加权采样在新状态处重新启动链起到了这一作用。

除了设计提议分布的自由外，MH 还有两个使其具有实用性的额外性质。首先，接受计算中的后验概率 `π(x)=P(x|e)` 仅以比率 `π(x')/π(x)` 的形式出现是非常幸运的。计算 `P(x|e)` 正是我们正试图使用 MH 来近似的计算。

第二个性质是后验概率只需要确定常数因子即可。这是因为常数在比率 `π(x')/π(x)` 中抵消了。具体来说，由于 `P(x|e) = \frac{P(e|x)P(x)}{P(e)}` 且 `P(e)` 独立于 `x'`，那么 `\frac{π(x')}{π(x)} = \frac{P(e|x')P(x')/P(e)}{P(e|x)P(x)/P(e)} = \frac{P(e|x')}{P(e|x)} \cdot \frac{P(x')}{P(x)}`。这非常有用，因为 `P(e)` 往往很难直接计算，而 `P(e|x)` 和 `P(x)` 通常是可以处理的。第二个性质是提议分布必须容易采样。例如，我们可以使用以 `x` 为中心的均匀分布或均值为 `x` 的高斯分布。只要提议覆盖状态空间，算法就会收敛到目标分布。

## 因果网络

考虑一个可以想象的最简单的贝叶斯网络：单一的“火（Fire）→ 烟（Smoke）”。它告诉我们火和烟这两个变量可能相互依赖，因此需要指定先验概率 `P(Fire)` 和条件概率 `P(Smoke|Fire)` 以确定联合分布 `P(Fire,Smoke)`。然而，这也可以反向的“火 ← 烟”同样地表示，使用根据贝叶斯法则构建的 `P(Smoke)` 和 `P(Fire|Smoke)`。然而，这两个网络是等价的（传递相同的信息）这一想法会让大多数人感到不适甚至抵触。既然我们知道火导致了烟，而不是相反，它们怎么可能传递相同的信息呢？

换句话说，我们从经验和科学理解中清楚地知道，烟不会阻止火，而灭火会停止烟。我们期望通过它们之间箭头的方向性来表示这种不对称性。但如果反过来只是让它们变得等价，我们又如何希望在形式上表示这种重要性呢？

因果网络（有时称为因果图）的设计是为了表示因果网络，并利用这种不对称性获取因果信息。其核心思想是通过超越概率依赖的考虑来决定方向性，这涉及到一种不同类型的判断。我们不再像在普通贝叶斯网络中询问专家烟和火在概率上是否依赖，而是问：哪一个对另一个有反应？是烟对火反应，还是火对烟反应？

这听起来可能有点神秘，但可以通过“赋值（assignment）”的概念来精确化。如果根据我们对关于火的信息给烟分配一个值，我们就画一根从火指向烟的箭头。此外，如果我们判断给火分配了一个依赖于其他变量的真值，我们就不画指向烟的箭头 ← Smoke。换句话说，变量 `X_j` 的值 `x_j` 由方程 `X_i = f(OtherVariables)` 决定的，如果 `X_j \to X_i`，我们就画一个箭头。

## 结构方程

方程 `X_i=f(X_j)` 是结构方程，因为它描述了自然界中的一种机制，这种机制展开了概率，且对环境的运动和局部变化保持不变。

为了理解这一点，考虑图13.15中喷水器的修改版本。例如，为了表示一个损坏的喷水器，我们只需从网络中删除所有与喷水器节点相关的边。为了表示被罐覆盖的草坪，我们只需删除箭头 Rain（雨）→ Grass（草坪）。因此，环境中机制的任何局部重构都可以通过简单的修改，转化为网络拓扑的同构重构。更复杂的变换需要网络按照因果顺序构建。这种局部稳定性对于表示动作或干预尤为重要，这是我们下一个要讨论的话题。

### 13.5.1 表示动作：do算子

再次考虑图13.23(a)中的喷水器故事。根据贝叶斯网络的标准语义，五个变量的联合分布由五个条件分布的乘积给出：

```
P(c,r,s,w)=P(c)P(r|c)P(s|c)P(w|r,s)P(g|w)
```

其中我们用每个变量的首字母缩写了变量名称。作为一个结构方程组，模型看起来如下：

```
C = fc(Uc)
R = fr(C,Ur)
S = fs(C,Us)
W = fw(R,S,Uw)
G = fc(W,Ug)
```

其中，在不失一般性的情况下，`fc` 可以是恒等函数。这些方程中的 `U` 变量代表未建模的变量，也称为误差或扰动，它们扰动了每个变量与其父之间的函数关系。例如，`Uw` 可能代表喷水器和雨之外另一个潜在的湿度源——也许是晨露或消防直升机。如果所有 `U` 变量都是具有适当先验的相互独立随机变量，那么方程(13.14)中的联合分布可以用方程(13.15)中的结构方程精确表示。因此，一个随机关系系统可以通过一个确定性关系系统来捕获，每个关系都受到外生扰动的影响。

## do计算法 (Do-calculus)

例如，假设我们开启喷水器——即我们（根据定义，不依赖于模型）干预以使喷水器为真。在 do 计算法中，这涉及到关于火的赋值给烟赋值，这意味着喷水器不再依赖于是否下云。火和烟的关系是因果网络的一部分，这写为 `do(Sprinkler=true)`。因此我们从结构方程中删除 `S=fs(C,Us)` 并将其替换为 `S=true`，从而得到：

```
C = fc(Uc)
R = fr(C,Ur)
S = true
W = fw(R,S,Uw)
G = fc(W,Ug)
```

(13.16) 从这些方程我们得到了在 `do(Sprinkler=true)` 条件下的剩余变量的联合分布：

`P(c,r,w|do(S)) = P(c,r,g)` (13.17)

这对应于图13.2(b)中的变形网络。从方程(13.17)，我们可以看到概率变化的变量是喷水器的后代。注意作用于动作 `do(Sprinkler=true)` 与观测 `Sprinkler=true` 之间的区别。原始网络告诉我们，下云时喷水器不太开启，因此如果我们观测到喷水器已开启，会降低下云的概率。如图13.2(b)所示，切断天气与喷水器之间的因果链接可以防止影响从喷水器回流。类似的方法是分析具有变量 `X_1, ..., X_n` 的通用因果网络中 `do(X_j=x_{jk})` 的影响。该网络对应于通常定义的联合分布（见方程(13.2))：

```
P(X_1, ..., X_n) = \prod_{i=1}^n P(X_i|parents(X_i)).
```

(13.18) 应用 `do(X_j=x_{jk})` 后，新的联合分布 `P_{X_j}` 简单地选择了 `X_j` 的公式：

```
P_{X_j}(X_1, ..., X_n) = \prod_{i \neq j} P(X_i|parents(X_i)) \times \begin{cases} P(X_j|parents(X_j)) & \text{if } X_j=x_{jk} \\ 0 & \text{if } X_j \neq x_{jk} \end{cases}
```

(13.19) 这是由于将 `X_j` 设置为特定值 `x_{jk}` 对应从结构方程中删除 `X_j=f_j(parents(X_j),U_j)` 并将其替换为 `X_j=x_{jk}`。通过更复杂的代数运算，可以推导出设置变量 `X_i` 的公式：
