
可以看到，`else if` 是语法错误。因此，由于 `elseif` 和跟在 `else` 表达式后面的 `if`，不会产生任何歧义。

## @goto 和 @label 非结构化跳转

结构化分支（如 `if…elseif…else`）是编程语言中条件执行的首选模式。然而，一些语言拥有额外的 `goto` 语句，用于将执行分支跳转到代码中的特定位置。Julia 通过宏 `@goto` 和 `@label` 提供了此类功能。它们有以下限制：

1.  它们被限制在特定的代码块内。`@goto` 只能跳转到同一代码块作用域内的 `@label`。
2.  它们不能跨函数使用。不过，异常非常适合用于执行栈中的跨函数场景。
3.  它们影响代码的可读性。因此，通常不在大多数结构化编程语言中使用。

结构化分支与迭代的结合，使得非结构化跳转在大多数 Julia 程序中变得多余。以下代码使用 `@goto` 和 `@label` 计算 1 到 10 的连续整数和：

```julia
julia> begin
           s = 0
           n = 10
           @label loop
           s = s + n
           n = n - 1
           if n > 0
               @goto loop
           end
           s
       end
55
```

同样的逻辑使用 `for` 循环迭代执行会简单得多：

```julia
julia> s = 0
0

julia> for i = 1:10
           s = s + i
       end

julia> s
55
```

显然，迭代执行的语法比通过非结构化跳转实现序列求和要简单得多。

## for 循环迭代执行

虽然我们通过非结构化跳转和 goto 实现了代码的迭代执行，但作为高级语言，Julia 提供了特定的语言结构来辅助迭代执行。最常见的是 `for` 和 `while`，我们将在接下来回顾它们。

```julia
julia> s = 0;

julia> for i = 1:10
           s = s + i
       end

julia> s
55
```

在前面的代码片段中，我们从 1 枚举到 10 并将值加到 `s` 上。在 `for` 循环中，参数 `i` 被赋值为一个步长为 1 的 `Range` 对象 `1:10`。这也可以写成 `1:1:10`，表示 `<initial value>:<step size>:<final value>`。现在如果我们修改代码，只加奇数值：

```julia
julia> s = 0;

julia> for i = 1:2:10
           println(i)
           s = s + i
       end
1
3
5
7
9

julia> s
25
```

可以看到，将范围对象的步长改为 2 就足以达到预期结果。

### continue 与 break 控制流

现在让我们在求和时忽略所有能被 3 整除的数字。

```julia
julia> s = 0;

julia> for i = 1:10
           if i % 3 == 0
               continue
           end
           println(i)
           s = s + i
       end
1
2
4
5
7
8
10

julia> s
37
```

在这种情况下，`continue` 用于跳过所有能被 3 整除的数字，使其不加到 `s` 上。`continue` 确保表达式后续的代码块被排除在计算之外，而迭代器保持活跃；而在代码中使用 `break` 将终止循环。

```julia
julia> s = 0;

julia> for i = 1:10
           if i % 3 == 0
               break
           end
           println(i)
           s = s + i
       end
1
2

julia> s
3
```

### 遍历通用序列与多重迭代

不仅是 `Range` 对象，`for` 还可以用于其他具有迭代器的序列对象。我们将在后面的章节查看迭代器接口时更详细地讨论这一点。这是一个使用 `for…in` 语法的示例：

```julia
julia> for i in [5 10 15]
           println(i)
       end
5
10
15
```

单个 `for` 循环可以迭代多个 `Range` 对象。其效果将是迭代这些范围的笛卡尔积，左侧指定的为外层循环。

```julia
julia> for i=1:3, j=1:2
           println((i, j))
       end
(1, 1)
(1, 2)
(2, 1)
(2, 2)
(3, 1)
(3, 2)
```

内层范围也可以受外层范围值的影响。

```julia
julia> for i=1:3, j=1:i
           println((i, j))
       end
(1, 1)
(2, 1)
(2, 2)
(3, 1)
(3, 2)
(3, 3)
```

这里的 `for` 循环是单个循环，遇到 `break` 语句时会终止。`break` 不会像嵌套 `for` 循环那样仅终止内层循环。

# Julia 控制流：循环与异常处理

## for 循环嵌套与 break 行为

在 Julia 中，`for` 循环可用于迭代器和范围对象。以下示例展示了嵌套循环中 `break` 的不同行为：

```julia
julia> for i=1:3, j=1:2
           println((i, j))
           if i == j
               break
           end
       end
(1, 1)
```

```julia
julia> for i=1:3
           for j=1:2
               println((i, j))
               if i == j
                   break
               end
           end
       end
(1, 1)
(2, 1)
(2, 2)
(3, 1)
(3, 2)
```

第一个示例中，`break` 直接跳出了最外层循环；第二个示例中，`break` 仅跳出内层循环。

## while 循环

`while` 循环更灵活，可作用于任意条件。只要条件为真，循环就会持续执行。通用语法如下：

```julia
while <Boolean_condition is true>
    <loop>
end
```

例如计算 1 到 10 的和：

```julia
julia> s, n = 0, 10
julia> while n > 0
           s = s + n
           n = n - 1
       end
julia> s
55
```

与 `for` 循环一样，可使用 `continue` 跳过本次迭代，用 `break` 终止循环。

## do-while 循环的变通实现

`while` 循环在开头判断条件。若需无条件执行一次循环体，再在末尾判断条件决定是否继续（即 `do...while` 结构），Julia 目前不直接支持，但可通过变通实现：

```julia
skip_eval = true
while skip_eval || Boolean_condition_is_true
    if skip_eval
        skip_eval = false
    end
    loop
end
```

示例：持续读取 REPL 输入，直到输入 `q` 为止：

```julia
julia> skip_eval, ch = true, Char(0)
(true, '\0')
julia> println("press q <enter> to end the loop")
press q <enter> to end the loop
julia> while skip_eval || ch != 'q'
           skip_eval = false
           ch = read(stdin, Char)
       end
a
q
```

## 异常处理

当程序出现异常状况，执行函数可能无法返回有效值或使程序恢复。Julia 提供 `try...catch` 机制捕获异常并恢复执行。

### 基本语法

```julia
julia> try
           sqrt(-1)
       catch e
           println(e)
       end
DomainError(-1.0, "sqrt will only return a complex result if called with a complex argument. Try sqrt(Complex(x)).")
```

- 预期可能抛出异常的代码放在 `try` 后。
- 异常处理代码放在 `catch` 后。
- `end` 结束 `try` 块。

若无 `try...catch`，REPL 会打印默认错误信息和堆栈跟踪：

```julia
julia> sqrt(-1)
ERROR: DomainError with -1.0:
sqrt will only return a complex result if called with a complex argument. Try sqrt(Complex(x)).
Stacktrace:
 [1] throw_complex_domainerror(::Symbol, ::Float64) at .\math.jl:33
 [2] sqrt at .\math.jl:573 [inlined]
 [3] sqrt(::Int64) at .\math.jl:599
 [4] top-level scope at REPL[10]:1
```

Julia 内置多种标准异常类型，如 `ErrorException`、`DomainError`、`ArgumentError`、`BoundsError` 等，均派生自抽象类型 `Exception`。

### 重新抛出异常

使用 `rethrow()` 可将捕获的异常继续向上传播：

```julia
julia> try
           sqrt(-1)
       catch e
           rethrow()
       end
ERROR: DomainError with -1.0:
sqrt will only return a complex result if called with a complex argument. Try sqrt(Complex(x)).
Stacktrace:
 [1] throw_complex_domainerror(::Symbol, ::Float64) at .\math.jl:33
 [2] sqrt at .\math.jl:573 [inlined]
 [3] sqrt(::Int64) at .\math.jl:599
 [4] top-level scope at REPL[11]:2
```

### 抛出自定义异常

可用 `throw` 抛出任意对象作为异常，不一定非要是 `Exception` 类型：

```julia
julia> try
           throw(1)
       catch e
           println(typeof(e))
       end
Int64
```

### 最佳实践

- 异常仅用于处理**异常状况**；常规控制流请用 `if...else` 等结构。
- 异常处理有显著性能开销，请谨慎使用，仅在必要时启用。

当资源正在使用时，异常情况可能会强制突然退出函数执行；在这种情况下，资源无法被回收。`finally` 子句确保代码在正常执行和异常条件下都能执行，从而确保资源被回收。在示例中，即使发生异常，文件句柄 `f` 也会被关闭，就像没有异常时一样。

```julia
julia> f = open("file")
julia> try
           b = read(f)
       finally
           close(f)
       end
```

## 异常对象和栈追踪

如此精细的架构中，异常对象增加了什么价值？它们会影响执行速度，因为每次发生栈展开时，都需要验证异常对象。它们提供的主要优势之一是能够追踪发生异常的栈位置。因此，可以获得错误传播的追踪。其次，异常对象的形成提供了提供关于错误的充足信息的能力。

