## 8.7 无限多个闭凸集：在线学习情形

在我们迄今为止的讨论中，我们假设闭凸（性质）集的数量 $K$ 是有限的。为了落入它们的交集（可行集），必须循环投影到所有集合上，或者并行执行投影。这种策略对于在线处理场景并不吸引人。在每个时间瞬间，都会出现一对新的观测值，从而定义一个新的性质集。因此，在这种情况下，可用的凸集数量会增加。访问所有可用集合会使复杂度随时间变化，经过一段时间后，所需的计算资源将变得无法控制。

另一种观点在文献 [101–103] 中被提出，随后在文献 [76, 104, 105] 中得到扩展。这里的主要思想是：在每个时间瞬间 $n$，接收一对输出-输入训练样本，并构建一个（性质）闭凸集 $C[n]$。时间索引 $n$ 可无限增长。然而，在每个时间瞬间，仅考虑最近构建的 $q$ 个（用户定义参数）性质集。换句话说，参数 $q$ 定义了时间上的一个*滑动窗口*。在每个时间瞬间，投影/松弛投影都在这个时间窗口内执行。其基本原理如图 8.22 所示。因此，投影所针对的集合数量不随时间增长，其数量保持有限，并由用户固定。开发出的算法是 POCS 并行版本的衍生品，称为*自适应投影次梯度法*（APSM）。该方案可被视为经典 POCS 框架的在线版本。我们将在回归的背景下描述该算法。遵循第 8.6 节的讨论，随着每一对 $(y[n], \mathbf{x}[n]) \in \mathbb{R} \times \mathbb{R}^{(l)}$ 变得可用，构建一个超平板 $S[\epsilon, n]$，$n = 1, 2, \dots$，目标是找到一个 $\boldsymbol{\theta} \in \mathbb{R}^{(l)}$ 使其位于所有这些性质集的交集中，从任意初始值 $\boldsymbol{\theta}[0] \in \mathbb{R}^{(l)}$ 开始。

![图 8.22 在时刻 n，使用性质集 Cn−q+1,…,Cn，而在时刻 n + 1，考虑集合 Cn−q+2,…,Cn+1。因此，所需的投影数量不随时间增长。](img/gr022.jpg)

图 8.22 在时刻 $n$，使用性质集 $C[n-q+1], \dots, C[n]$，而在时刻 $n+1$，考虑集合 $C[n-q+2], \dots, C[n+1]$。因此，所需的投影数量不随时间增长。

### 算法 8.2：APSM 算法

**初始化**

1.  选择 $\boldsymbol{\theta}[0] \in \mathbb{R}^{(l)}$。

2.  选择 $q$；每个时间瞬间待处理的性质集数量。

#### 算法流程

##### 初始阶段 ($n = 1, 2, \dots, q-1$)

**For** $n = 1, 2, \dots, q-1$ **Do**；初始阶段，即 $n < q$。

1.  **选择权重** $\omega_{1}, \dots, \omega_{n}$：满足 $\sum_{k=1}^{n} \omega_{k} = 1, \omega_{k} \geq 0$。

2.  **选择步长** $\mu[n]$。

    更新公式：

    $$

    \mathbf{\theta}_{n} = \mathbf{\theta}_{n-1} + \mu_{n}\left( \sum\limits_{k=1}^{n} \omega_{k} P_{S_{\epsilon,k}}(\mathbf{\theta}_{n-1}) - \mathbf{\theta}_{n-1} \right)

    $$

    (8.37)

**End For**

##### 稳态阶段 ($n = q, q+1, \dots$)

**For** $n = q, q+1, \dots$ **Do**

1.  **选择权重** $\omega[n], \dots, \omega[n-q+1]$；通常取 $\omega_{k} = \frac{1}{q}, k = n-q+1, \dots, n$。

2.  **选择步长** $\mu[n]$。

    更新公式：

    $$

    \mathbf{\theta}_{n} = \mathbf{\theta}_{n-1} + \mu_{n}\left( \sum\limits_{k=n-q+1}^{n} \omega_{k} P_{S_{\epsilon,k}}(\mathbf{\theta}_{n-1}) - \mathbf{\theta}_{n-1} \right)

    $$

    (8.38)

**End For**

现在可以在区间 `(0, 2*M_n)` 内选择外推参数，以保证收敛。对于公式 (8.39) 的情况：

```
M_n = \sum_{k = n - q + 1}^{n} \frac{\omega_k \| P_{S_{\epsilon,k}}(\mathbf{\theta}_{n - 1}) - \mathbf{\theta}_{n - 1} \|²}{\| \sum_{k = n - q + 1}^{n} \omega_k P_{S_{\epsilon,k}}(\mathbf{\theta}_{n - 1}) - \mathbf{\theta}_{n - 1} \|²}.
```

请注意，该区间不同于公式 (8.27) 中有限个集合情况下所报告的区间。对于与公式 (8.38) 相关的前几步迭代，上述公式中的求和从 `k = 1` 开始，而不是从 `k = n - q + 1` 开始。

回顾一下，`P_{S_{\epsilon,k}}` 是公式 (8.34)–(8.35) 中给出的投影运算。请注意，这是一个通用方案，可应用于不同的性质集。所需做的只是更改投影算子。例如，如果考虑分类问题，我们所要做的就是将 `S_{\epsilon,n}` 替换为半空间 `H_n^+`，该半空间由数对 `(y_n, \mathbf{x}_n) \in \{-1, 1\} \times \mathbb{R}^{(l + 1)}` 定义，如第 8.6.2 节所述，并使用公式 (8.13) 中的投影（参见 [78,79]）。此时，必须强调的是，原始的 APSM 形式（例如 [103,104]）更为通用，可涵盖广泛的凸集和函数。

图 8.23 从几何上演示了 APSM 算法。我们假设每个时刻用于投影的超薄板数量为 `q = 2`。每次迭代包含：

*   `q` 次投影，可并行执行，

*   它们的凸组合，以及

*   更新步骤。

##### 8.7.1 APSM 的收敛性

APSM 收敛性的证明略显技术性，感兴趣的读者可参考相关文献。在此，我们可以通过几何图解来直观地证明其在特定假设下的收敛性。这种几何解释是 APSM 收敛性随机方法的核心，该方法在文献 [23] 中提出。

假设噪声是有界的，且存在一个真实的 `θ[o]` 生成数据，即

`y[n] = x[n]^(T) θ[o] + η[n]`。 (8.40)

根据假设，

`|η[n]| ≤ ϵ`。

因此，

`|x[n]^(T) θ[o] − y[n]| ≤ ϵ`。

因此，`θ[o]` 确实位于所有形式为

`|x[n]^(T) θ − y[n]| ≤ ϵ`

的超平板的交集中，此时问题可行。问题是，即使在 `n → ∞` 渐近意义上，人们能多大程度地接近 `θ[o]`。例如，如果交集的体积很大，即使算法收敛到该交集边界上的一点，这也不一定能说明该解与真实值 `θ[o]` 有多接近。文献 [23] 中的证明确立了：在关于观测序列的一些一般性假设以及噪声有界的条件下，该算法使估计值*任意接近*于 `θ[o]`。

要理解证明背后的技术细节，请回顾关于超平板主要有两个几何问题：(a) 其方向，由 `x[n]` 决定；(b) 其宽度。在有限维空间中，根据简单几何可知超平板的宽度等于

```
d = (2ϵ) / ||x[n]||.
``` (8.41)

这是以下事实的直接推论：距离 (54)

`x^(T) θ − y = 0`，

等于

```
|x^(T) θ̃ − y| / ||x||.
```

确实，令 $\overline{\mathbf{\theta}}$ 为定义超平板的两个边界超平面之一（例如，`x[n]^(T)θ − y[n] = ϵ`）上的一点，并考虑它到另一个超平面（`x[n]^(T)θ − y[n] = −ϵ`）的距离；则可直接得到公式 (8.42)。

图 8.24 显示了两个不同方向的四个超平板（一个用实线表示，一个用虚线表示）。红色超平板比黑色的更窄。此外，所有四个超平板必然都包含 `θ[o]`。如果 `x[n]` 随机变化，使得任何方向都可能出现，那么以高概率且对于任何方向，范数也可以取较小以及任意大的值，此时直觉表明 `θ[o]` 周围交集的体积将变得任意小。关于 APSM 算法的进一步结果可参见，例如，[82,89,103,104]。

![图 8.24 对于每个方向，超平板的宽度与 ‖xn‖ 成反比。在本图中，||xn|| < ||xm||，尽管两个向量指向同一方向。不同方向和宽度的超平板的交集使得它们在 θo 附近的交集体积变得任意小。](img/gr024.jpg)

图 8.24 对于每个方向，超平板的宽度与 `‖x[n]‖` 成反比。在本图中，`||x[n]|| < ||x[m]||`，尽管两个向量指向同一方向。不同方向和宽度的超平板的交集使得它们在 `θ[o]` 附近的交集体积变得任意小。

#### 一些实用提示

APSM 算法需要设置三个参数，即 `ϵ`、`μ[n]` 和 `q`。事实证明，该算法对这些参数的选择并不特别敏感：

*   **参数 `μ[n]` 的选择** 在概念上类似于 LMS 算法中步长的选择。特别地，`μ[n]` 越大，收敛越快，但稳态误差底噪越高。在实践中，步长大约等于 `0.5 M[n]` 将导致较低的稳态误差，尽管收敛速度相对较低。相反，如果选择较大的步长，大约为 `1.5 M[n]`，则算法享有更快的收敛速度，尽管收敛后的稳态误差会增加。

*   **关于参数 `ϵ`**，典型的选择是设置 `ϵ ≈ √2 σ`，其中 `σ` 是噪声的标准差。在实践中（参见，例如，[47]），已表明该算法对该参数相当不敏感。因此，只需对噪声标准差有一个 *粗略* 的估计即可。

*   **关于 `q` 的选择**，这类似于第 5 章中 APA 所用的 `q`。`q` 越大，收敛越快；然而，较大的 `q` 值会增加复杂度以及收敛后的误差底噪。在实践中，相对较小的 `q` 值，例如 `l` 的一小部分，与归一化最小均方 (NLMS) 算法相比，可以显著提高收敛速度。有时可以从相对较大的 `q` 值开始，一旦误差减小，`q` 可以取较小的值以获得更低的误差底噪。

*   值得注意的是，APA 中长度为 `q` 的滑动窗口内的历史数据复用是通过 `q × q` 矩阵的求逆来实现的。在 APSM 中，这是通过一系列 `q` 次投影来实现的，从而使复杂度线性依赖于 `q`；此外，这些投影可以并行执行。此外，APA 倾向于对噪声的存在更敏感，因为投影是在超平面上进行的。相反，对于 APSM 情况，投影是在超平板上进行的，这隐式地照顾了噪声（例如，[102]）。
