
## 簇分配与训练

否则，如果 `$c(M, cluster) \le confidence_{threshold}$` 且 `$cluster \le cluster_{threshold}$`，则该簇被传递给 CLI。

为了训练簇分配模型，一致性损失较低，并如下所示：

```
$L = L_{cluster} + L_{consistency}$
L_{consistency} = \frac{1}{2} \sum y_{ij}log_{ij}$
L_{consistency} = 0.5 \times (L_{consistency}(Left Branch) + L_{consistency}(Right Branch))$
```

数据生成和训练在 PyTorch 中实现，使用了 Adam 优化器，`$\beta_1=0.9$`，`$\beta_2=0.999$`，学习率和批量大小为 64，用于创建从 `$10^{-3}$` 到 341 的合成簇数据。使用 A100 GPU 进行训练。训练了 50 个 epoch，Nanopore 实验使用了 80 个 epoch，每个实验包含 M 个簇，每个簇平均 N 条读取。

## 序列重建算法

该算法是一种使用 DNN 低置信度的序列重建算法。算法接收一个簇并决定重建其序列。如果簇的置信度低，或者 DNN 对这些序列的预测不正确，则将簇发送到 CLI。我们构建时不使用 DNN 提供的推理，也不使用关于一致性和合成错误率的先验知识。算法直接根据获取的簇进行工作。

首先，取簇的第一个读取，然后通过动态规划计算第一个读取与簇中任何其他读取的距离。这一步用于估计对齐情况。基于此计算，算法创建了编辑器操作向量（删除、插入和替换），描述了如何使用编辑操作将第一个读取转换为簇中的任何其他读取。编辑器版本返回了簇中每种错误发生次数及其位置的估计。然后，算法根据这些错误估计创建一个无无环图。

## 参数优化与评估

针对准确性与运行时间权衡的优化由 `$confidence_{threshold}$` 和 `$cluster_{threshold}$` 的值控制，并在试点测试期间进行。DNN 在 Illumina 数据集上的性能良好，但还不够。因此，我们使用了从 0.1 到 0.3 的 `$confidence_{threshold}$`，而 DNN 在 Nanopore 单流上的性能需要额外的机制来确保信息的成功检索和稳健的安全裕量。我们选择了 1% 的安全裕量，产生了 `$confidence_{threshold}$` 为 0.7，`$cluster_{threshold}$` 为 4 值。评估在补充信息中提供的测试数据集上进行。

## 实验方法

在测序之前，我们使用标准 Q5 高保真聚合聚合酶（New England Biology, M0495）进行了 12 次循环的 PCR 扩增。对于 Illumina 测序，使用带有 v9.1 流池的 Oxford Nanopore MinION 对双端读取（paired-reads）进行了合并。Goldman, N., 等《走向一致性和合成错误率》（Towards the consistency and synthesis error rates）。
