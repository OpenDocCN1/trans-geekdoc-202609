
*   **For** `r = 1, 2, …, R`，**Do**；在实践中，`R = 3` 次迭代已足够。

    1.  **For** `j = 0, 1, 2, …, 9`，**Do**

        1.  **For** `i = 1, 2, …, I`，**Do**

        2.  

            ```
            c_ij = exp(b_ij) / sum_{k=0}^{9} exp(b_ik)
            ```

        3.  **End For**

        1.  

            ```
            s_j = sum_{i=1}^{I} c_ij * u_hat_{j|i}
            ```

        2.  

            ```
            v_j = (||s_j||² / (1 + ||s_j||²)) * (s_j / ||s_j||)
            ```

        1.  **For** `i = 1, 2, …, I`，**Do**

        2.  

            ```
            b_ij <- b_ij + v_j^T * u_hat_{j|i}
            ```

        3.  **End For**

    2.  **End For**

*   **End For**

*   **Return** `v[j]`，`j = 0, 1, …, 9`。

算法的一大特点是输出胶囊 `v_j`，通过迭代调整其与上一层变换后的输出/胶囊的*相似性*或*一致性*来生成。这是通过更新 `b_ij` 来实现的，其更新方式根据 `v_j` 与 `û_{j|i}` 之间的相似性（内积）来“加强”或“削弱”它们的值。请注意，每次迭代开始时都将 `b_ij = 0`，即它们从耦合系数的等概率值开始。也就是说，每个 `i` 相对于所有类别具有相等的概率。然后，根据计算出的输出与相应变换后的输入胶囊之间的匹配程度来更新它们的值。简而言之，耦合系数将信息从低层*路由*到高层。较大的 `c_ij` 值意味着第 `i` 个低层胶囊与上层第 `j` 个胶囊的连接更强。重要的是要强调，耦合系数的值*不是*通过试图最小化代价函数的反向传播来调整的。代价函数通过梯度的反向传播，用于调整 `W_ij` 矩阵的元素以及卷积的滤波器。动态路由算法是生成输出的算法。在*训练*和*测试*期间均是如此，给定 `W_ij` 矩阵的值。正如算法 18.4 所示，似乎三次迭代就足够了。

在文献 [174] 中，还结合了公式 (18.76) 中的损失，使用了*基于重构的正则化项*，以形成训练数据上的代价。训练期间，与正确类别 `k` 相关联的输出胶囊 `v_k` 被提供给一个全连接网络作为输入，该网络充当解码器以重构相应的输入。训练全连接网络的损失函数是输入图像像素与输出之间平方差之和，使用 Sigmoid 输出非线性。也就是说，用于训练胶囊网络的损失函数变为：

```
loss = ℒ + a × reconstruction error
```

其中 `ℒ` 由公式 (18.76) 给出，且 `a = 0.005`。

文献 [174] 中针对 MNIST 数据集进行数字识别的实验验证了输出胶囊的不同维度（共 16 个）与输入数字的不同特征相关联，例如粗细、倾斜度和宽度。在文献 [76] 原始工作的扩展中，动态路由算法采用了 EM 类型的参数。

尽管胶囊网络为小型数据集（如 MNIST）提供了最先进的结果，但它们在大型数据集上的性能仍有待验证。目前，似乎它们已被 Transformer 网络（第 19 章）所取代。然而，有趣的是，它们与 Transformer 共享一些显著特征。首先，它们通过 `W` 矩阵执行变换，此外，向高层的路由基于相似性度量。未来将决定此类网络是否仍有发挥空间！

## 18.16 深度神经网络：一些结束语

深度架构主题自本世纪初以来一直是研究热点，且兴趣持续增长。在单章中不可能涵盖所有技术、所有算法变体及相关文献，特别是在特定应用框架内。前几节回顾了主要方向和算法，它们构成了脊柱，围绕其开发了大量变体。此外，作者认为前文讨论的技术和模型构成了基础知识，初学者掌握这些后方能深入。一些相关的教程论文见 [36, 73, 115, 178]。第 19 章介绍了机器学习的一些最新进展，它们建立在我们之前讨论的许多概念之上。

下面重点介绍一些进一步的概念，这些概念在本书当前版本编写时极具研究价值，并似乎提供了改进前文所呈现的基本概念和架构性能的途径。

### 迁移学习

*迁移学习* 并非新概念；它已存在多年。已开发并应用于不同应用的各种方法和概念（例如见 [147, 209, 215]）。我们此处旨在阐述主要概念，而非深入探讨多年来提出的各种技术的详细细节。

正如本章多处所述，深度神经网络目前代表了机器学习的最先进水平。深度网络已应用于几乎所有科学领域，在许多情况下提供人类级甚至超人类的性能（例如参见文献 [96, 169, 202]）。

然而，训练此类网络需要海量的标注数据。收集和标注数据以构建大型数据集是一项相当繁琐的任务。有时大型数据集确实存在且开放公开，例如 ImageNet-1K [35]，它包含 120 万张图像和 1000 个类别。但通常它们是专有的或获取成本高昂。例如，许多语音相关数据集即属此类。此外，在许多应用中，获取大型数据集根本不可能，例如在 X 射线成像和 fMRI 等医学相关应用中，原因之一是难以获得大量对应各类疾病（如恶性肿瘤）的图像，因为患病人群属于少数。

与这种对海量训练数据集的需求形成对比的是，人脑每次面对新情况时不需要从头开始训练。人类拥有将从一种情境（任务）获得的知识和经验迁移到另一个足够相似情境的固有机制。此类机制主要在潜意识层面运作。例如，学会骑自行车后，相关知识和经验可迁移至学习骑摩托车或开汽车。

机器学习中的迁移学习是绕过孤立任务学习范式的方法论。其目标是开发技术，以利用从一个任务学到的知识应用于另一个相关任务。

为演示该概念，让我们聚焦于图像识别领域的一个示例。假设有人有兴趣训练网络以自动识别和表征 X 射线成像中的肿瘤。如前所述，难以获取大量训练数据。然而，图像无论其具体类型如何，都共享许多特征。换言之，包含狗、汽车或肿瘤的图像均由边缘、基本形状、光强变化等组合形成。事实上，正如我们在 18.12.3 节末尾所述，CNN 中各层的目的是学习与此类信息相关的表示，并通过层层递进形成的特征对其进行编码。回顾我们对 CNN 的讨论，卷积层学习特征。最后一层卷积层的特征作为输入呈送给网络的全连接部分，其输出提供相关预测。

在我们的示例中，迁移学习的思路是“借用”先前通过大型图像数据集（如 ImageNet）训练所学的卷积层架构及其相关参数。然后，固定这些参数，仅使用可用的 X 射线图像训练网络中全连接部分的参数（见图 18.30）。换言之，我们使用通过不同类型图像训练网络产生的相同特征。然后，这些特征被用于使用特定任务数据集训练全连接网络。因此，我们将先前在图像相关任务中获得的知识迁移过来，以促进类似任务的学习。网络训练所基于的第一个任务通常称为源任务，知识迁移至的第二个任务称为目标任务。

另一种场景是将通过源任务预先学习的参数作为初始值，而非固定它们，并使用目标任务的 X 射线图像重新训练整个网络。根据应用和目标任务的数据规模，可以设计各种场景和组合。

总之，主要思想如下。使用针对源任务获取的数据训练（或使用预训练）深度网络，源任务的可用数据集足够大以支持相应训练。固定低层参数（或将其作为初始值），并使用目标任务较小规模的数据集训练高层参数（例如参见文献 [163]）。如果特定目标应用任务的数据规模很小，可使用简单的单输出层，例如 Softmax 或线性 SVM。

### 多任务学习

迁移学习中任务间的信息共享是顺序进行的。首先通过在源任务上训练学习参数；然后，利用获得的参数集，通过其关联的数据集学习目标任务。

在所谓的多任务学习中，多个不同任务被同时学习。多任务学习可视为一种归纳学习，通过将偏置嵌入学习任务来迁移知识。从某种意义上说，这在概念上类似于使用正则化项，其目的是将解偏向正则化项施加的约束。在多任务学习背景下，每个涉及任务的模型被训练以使其解偏向其他任务。事实证明，与单独在每个任务上训练模型相比，在多任务框架中训练网络能增强网络模型对过拟合的鲁棒性。

正如迁移学习一样，多任务学习的思想并不新鲜；在不同学习器的背景下已存在多年（例如参见文献 [2, 26]）。在已提出的大量技术中，这里将重点介绍两条在深度网络框架中更流行的路径（更多近期综述参见文献 [170] 和 [223]）。

在所谓的硬参数共享方法中，若干隐藏层被所有任务共享。同时，允许若干（输出）层为特定任务专用。这在图 18.43 中以示意方式展示。所有层（包括共享层和任务专用层）的参数被同时学习。在这样的训练概念中，过拟合倾向被降低。这是自然的，因为同时学习多个任务使获得的表示能捕获所有任务的信息，从而降低了对任何特定任务过拟合的倾向。此类多任务的一个应用例如在计算机视觉中，每个任务的目标可能是预测不同物体的标签。当图像中存在多个物体且任务是检测物体类别及其边界框时，该设置也非常方便。

### 几何深度学习

本章讨论的背景设定是指处于欧几里得空间中的数据。确实，我们提到的所有例子都是图像、视频和时间序列信号/序列数据。此外，CNN 中的基本操作是卷积，它被定义为在图像和时间序列上的操作。然而，在许多科学领域中，底层结构是非欧几里得的。此类例子包括存在于社交网络中的信息、通信中的传感器网络以及 fMRI 中的大脑网络，仅举几例。处理此类数据时，我们不再拥有序列数据或图像所具有的规律性。卷积的定义必须被修改和扩展，以包含与非欧几里得域（如图和流形）几何相关的信息。此类数据的处理超出了本章的范围。感兴趣的读者可参考例如文献 [20]、[219] 中的教程及其参考文献。

### 开放问题

毫无疑问，深度神经网络作为一种技术已经彻底改变了机器学习学科。然而，正如我们在本章各处所评论的，它们并非没有缺点。读者应了解并警惕这些缺点，主要有两个原因。首先，缺点必然定义了研究课题，包含许多具有挑战性和趣味性的问题。因此，缺点也有其积极的一面；它们构成了机遇。科学和技术是演化过程，没有任何单一方法或理论能一蹴而就地解决所有问题。第二个原因是，我们应该学会不“盲目崇拜”这一新工具，并将其视为解决所有问题的灵丹妙药。

正如本章其他部分已经指出的，深度神经网络已达到与人类相当的准确性性能，在某些情况下甚至展示了超人类的性能；然而，这些报告的结果来自精心策划的数据集。同时，深度神经网络可能被对抗样本欺骗，而明智的人类不会。此外，当这些模型应用于“真实”现实世界，并面临与训练集中所代表条件截然不同的情况时，这种令人印象深刻的性能可能不再成立。而且，报告的准确率是在显著的高计算成本下获得的，使用了耗能设备（如 GPU），且训练需要海量数据。这些数据集有时是开放的，但在许多情况下属于私有财产。

深度神经网络面临我们所谓的获取结果的*可解释性*问题。尽管在这一方向上已有进展（例如见 [144] 及其参考文献），但该问题远未解决。任何机器学习系统的设计都应让用户能够跟进每个预测/决策背后的基本原理，即能够回答“为什么这个人被诊断为癌症？”这类问题。

深度神经网络遭受所谓的*灾难性遗忘* [131]。当人类大脑学习任务 A 时，它可以泛化并学习第二个任务 B，而不遗忘 A。现有的深度网络在学习新任务 B 时，倾向于遗忘之前的任务 A。对于序列或增量学习至关重要的任务，这是一个主要缺点，例如手势识别、网络流量分析，或移动机器人中的人脸和物体识别等应用，这些场景要求网络必须在现场及时进行更新。这是一个正在进行的研究课题（例如见 [157] 及其参考文献）。

深度神经网络存在显著的参数冗余（例如 [38]）。据报道，在某些情况下，可以移除超过 95% 的参数而不牺牲性能。这是本章中报道的剪枝技术的基础。这也是一个正在进行的研究课题（例如见 [121,148] 及其参考文献）。

深度神经网络在低功耗设备（如手机、机器人和自动驾驶汽车所需的设备）上扩展性不佳。每天进行数十亿次预测具有巨大的能量成本。如前所述，GPU 是耗能设备。实时预测往往比深度神经网络所能提供的水平低几个数量级。因此，压缩和效率是深度学习研究中一个重要的关注课题（例如见 [107,121,148] 及其参考文献）。在被称为“边缘 AI”背景下的*联邦*学习，是这一方向上的另一条路径；见例如 [17,153]。

任何学习器的泛化性能一直是我们在本书各处关注的焦点。然而，包括深度神经网络在内的机器学习方法的泛化能力，与人类相比仍然非常有限，甚至与许多动物相比也是如此。自然智能擅长迁移知识，不仅仅是从一个数据点到另一个数据点（从同一分布采样），而是从一个问题到另一个问题。机器学习中的训练是在独立同分布（i.i.d.）收集的数据上进行的。相反，当人类进行泛化时，他们利用因果信息，包括对世界的干预、领域偏移和时间结构。此类信息超越了分布学习，涉及结构信息和推理形式。第 15.3.2 节介绍了一些关于因果性的提示。因果表征学习是一项主要的研究活动，其主要目标是从低层观测中发现高层因果变量；见例如 [175]。目前，关于大语言模型（LLMs）（第 19.4 节）是否能学会推理并“发现”因果关系以及程度如何，存在公开辩论；见例如 [102]。

简而言之，虽然对未来做预测应谨慎，但我可以预测，在几年内，将需要新版本来涵盖这一激动人心领域正在“发生”的持续研究进展。
