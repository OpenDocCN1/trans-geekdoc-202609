
`Pass-To`例程随后需要为传球选择速度和方向。虽然对于人类——即使是具有足球专家的人——给学习智能体提供这种高层建议相对容易，但要编写确定踢球速度和方向的规则以最大化控球概率是非常困难的，甚至是可能的。同样，选择正确的队友接球或移动到可以接球的位置也显而易见。部分程序提供了通用的脚架——复杂行为的整体骨架和结构组织——而学习过程则解决了细节。

我们考虑的强化学习最后方法被称为策略搜索。在某些方面，策略搜索是本章中最简单的方法：其核心思想是随着性能的改进不断不断调策略。

让我们从策略本身开始。记住`π`是一个从状态到动作的函数。我们主要感兴趣的是参数少于状态空间的参数化表示。例如，我们可以通过每个动作的参数化 Q 函数来表示`π`，并采取值最大的动作：

```
π(s) = max_{a} Q_hat_0(s, a)
```

每个 Q 函数可以是线性网络（如上一节所示），也可以是深度神经网络等非线性函数。策略搜索将调整参数`θ`以改进策略。注意，如果策略是由 Q 函数表示的，那么策略搜索产生了一个学习 Q 函数的过程。这个过程与 Q-learning 不同！

在函数近似的学习中，算法找到一个`θ`的值使得`Q_hat_0`“接近”`Q*`。然而，两种方法找到的值可能存在巨大差异。例如，近似 Q 函数`Q_hat_0(s,a) = Q*(s,a)/100`提供了最优性能，即使它完全不接近`Q*`。另一个明显的例子是`π(s)`使用（例如）深度 10 的前瞻并配合近似效用函数`U_hat_0`计算时。

对于公式 (23.13) 给出的策略表示的一个问题是，当参数是离散的时，策略是不连续的。也就是说，存在某些`θ`值，使得`θ`的微小变化会导致策略切换到另一个动作。这意味着策略的值可能发生不连续的变化。

### 随机策略

连续的，这使得基于梯度的搜索变得困难。由于如此，策略方法通常使用随机策略表示`π_θ(s,a)`，它指定了在状态`s`下选择动作的概率。一种常用的表示方法是 softmax 函数：

```
π_θ(s,a) = e^{βθ(s,a)} / Σ_{a'} e^{βθ(s,a')}.
```

参数`β>0`调节 softmax 的“软度”；当`β`的值相对于 Q 值之间的差异很大，softmax 趋于于硬最大（hard max），而当`β`接近 0 时，softmax 趋于于动作的均匀随机选择。对于所有有限的`β`，softmax 都是`θ`的可微函数；因此，策略值（它连续依赖于动作选择概率）是`θ`的可微函数。

### 策略值

现在我们来看改进方法。最简单的情况是确定性策略和确定性环境。令`ρ(θ)`为策略值，即执行`π`时的期望回报（reward-to-go）。如果我们能推导出`ρ(θ)`的闭式表达式，那么我们就有了一个标准的优化问题，如第 4 章所述。只要`ρ(θ)`是可微的，我们就可以遵循梯度`∇ρ(θ)`。或者，如果`π`没有闭式解，我们可以通过简单执行并观察累积奖励来评估`ρ`。我们可以通过爬山法遵循经验梯度——即评估每个参数微小增量时策略值的变化。在通常的限制条件下，这个过程将收敛到策略空间中的局部最优。

### 策略梯度

当环境（或策略）是非确定的，可以进行爬山法，这需要较小`Δθ`的`ρ(θ)`和`ρ(θ+Δθ)`。问题在于，每次试验的总奖励可能会剧烈波动，因此从少数试验中估计策略值将非常不可靠；尝试比较两个估计值会更加不可靠。一种解决方案是运行大量试验，测量样本方差并利用它确定是否运行了足够的试验，以获得`ρ(θ)`改进方向的可靠指示。遗憾的是，这对于许多实际问题是不切行的，因为这些试验可能是昂贵的、耗时的，甚至可能是危险的。

对于非确定策略`π_θ(s,a)`的情况，可以直接从在`θ`下执行的试验结果获得`θ`处的梯度估计`∇ρ(θ)`。为了简单起见，我们将在回合环境中的情况下推导出这种估计，其中每个动作都在`s_0`采取。在这种情况下，策略值只是奖励的期望值，我们有

```
∇ρ(θ) = ∇_θ Σ_a R(s_0,a_0)π_θ(s_0,a) = Σ_a R(s_0,a_0)∇_θπ_θ(s_0,a).
```

现在我们执行一个简单的技巧，该和可以通过由`π_θ(s_0,a)`定义的概率分布生成的样本来近似。假设我们总共有`N`次试验，第`j`次试验采取的动作是`a_j`。

```
∇ρ(θ) = R(s_0,a_j)∇_θπ_θ(s_0,a_j) / π_θ(s_0,a_j) ≈ (1/N) Σ_{j=1}^N R(s_0,a_j)∇_θπ_θ(s_0,a_j) / π_θ(s_0,a_j).
```

因此，策略值的真实梯度由涉及每次试验中动作选择概率的项之和来近似。对于序列化情况，这推广为：

```
∇_θ p(θ) ≈ Σ_{j=1}^{N} u_j(s) ∇_θ π_0(s,a_j) / π_0(s,a_j).
```

对于每个状态`s`，其中`a_j`是第`j`次试验，`u_j(s)`是从状态`s`之后接收的总奖励。所得算法被称为 REINFORCE，由 Williams (1992) 提出；它在每个`θ`处使用大量试验的爬山法有效得多。然而，它要慢得多。考虑以下情况：给定两个策略，哪个最好？策略可能有不同的真实回报，例如`-2%`和`+6%`，因此找出哪一个是重要的。一种方法是让每个策略与“交易员”进行若干局并测量它们的收益。正如我们所见，这种方法的问题是每个策略的收益取决于获得好牌还是坏牌而剧烈波动。使用随机采样来比较策略时也会出现相同的问题。更好的解决方案是让每个程序执行相同的序列。这种思想被称为相关采样（correlated sampling），可以应用于可以重复序列的环境中的策略搜索。它被算法 Pegasus (Ng and Jordan, 2000)，这是实现自主的首批算法之一（见图 23.9(b)）。可以证明，确保策略值良好的序列数量仅取决于策略空间的复杂度，而不取决于底层领域。

### 模仿学习与逆强化学习

某些领域非常复杂，以至于很难为强化学习定义奖励函数。我们希望自动驾驶汽车做什么？它显然不应该花太长时间到达目的地，但应该尽可能快速行驶而不超速。它应该避免让乘客太颠簸，但在紧急情况下可以刹车。等等。决定给这些因素分配多少权重是一项困难的任务。更糟糕的是，我们遗忘了一些重要因素，例如考虑其他驾驶员的。忽略某个因素会导致对遗漏的因素赋予极端值——为了最大化剩余因素。

一种方法是在模拟中进行大量测试，注意问题行为并修改奖励函数以消除这些行为。另一种方法是寻找关于适当奖励函数的额外信息。其中一个来源已经是优化（或说接近优化）该奖励函数的代理的行为——在这种情况下是专家人类驾驶员。

模仿学习的大领域研究是在给定专家行为示例的情况下“像那样”学习良好行为的过程。至少有两种方法处理模仿学习问题。第一种我们在章节开头简单讨论过的：假设环境是观测的，我们对观察到的动作对使用监督学习来学习策略`π(s)`。这被称为模仿学习。它在机器人领域取得了一些成功（见第 973 页），但存在脆弱性问题：与训练集的微小偏差都会导致随时间增长的错误并最终导致失败。模仿学习在最好的情况下复制老师的性能，而不是描述他们在做什么（可能有些人之间会使用贬义词“拟人化”或“人性化”，这是一种更贬义的含义）。其含义是学习者并不理解为什么或如何执行任何动作。

模仿学习的第二种方法是理解为什么：观察专家的动作（以及结果状态），并找出专家正在最大化的奖励函数。然后我们可以根据该奖励函数推导出最优策略。人们预计这种方法可以通过相对少的专家行为示例产生稳健策略；毕竟，强化学习领域的基础是奖励函数而非策略或值，是任务中最简洁、稳健且可迁移的。此外，如果学习者考虑到专家可能的非最优性，那么通过优化真实奖励的近似可能比专家做得更好。我们称之为逆强化学习（IRL）：通过观察策略来学习，而不是通过观察奖励来学习策略。

给定专家的动作，如何找到专家的奖励函数？让我们假设专家是在理性的行动。在折扣奖励中，我们似乎在寻找一个奖励函数`R*`，使得专家策略下的期望奖励高于（或至少等于）其他可能的策略。

遗憾的是，将有很多满足此约束的奖励函数；其中一种是`R*(s,a,s') = 0`，这在没有任何奖励的情况下使得任何策略都是理性的。这种方法的另一个问题是假设奖励函数是不现实的。这意味着例如，一个观察着李世石做出败局棋步的机器人，AlphaGo 会认为李世石输掉游戏是明智的。为了避免`R*(s,a,s')=0`解释任何行为，以贝叶斯的方式会有帮助（参见第 21.1 节）。假设我们观察到数据`d`并令`h_R`为`R`是真实奖励函数的假设。那么根据贝叶斯规则，我们

```
P(h|d) = αP(d|h)P(h).
```

> ^7 根据第 559 页的公式 (16.9)，奖励函数`R'(s,a,s')=R(s,a,s') + γΦ(s)`与`R(s,a,s')`具有完全相同的策略，因此我们恢复的奖励函数仅限于可能的形状函数`Φ(s)`的加。这并不是一个问题，因为使用`R'`的机器人行为与使用“正确” R 的机器人一样。

## 第 23.6 节 学徒制与逆强化学习

现在，如果先验概率`P(h_R)`基于简单性，那么假设`R=0`的得分会相当不错，因为 0 显然是简单的。然而，对于`R=0`的假设，`P(d|h_R)`项是微乎其微的，因为如果假设成立，它无法解释为什么专家选择那个特定的行为空间是最优的。另一方面，对于一个具有唯一策略或较少等效最优策略的奖励函数`R`，`P(d|h_R)`将高得多。

为了考虑到专家偶尔会犯错，我们简单地应用`P(d|h_R)`，使得即使`d`来自于与`R`相比略次优的行为，其值也非零。一个典型的假设是——必须说明，这是为了数学上的方便而非对实际数据的忠实——即一个智能体的 Q 函数`Q(s,a)`选择时不是根据确定性策略`π(s)=argmax Q(s,a)`，而是根据方程 (23.4) 中 softmax 分布定义的随机策略。这有时被称为玻尔兹曼理性（Boltzmann rationality），因为在统计力学中，玻尔兹曼分布中的状态概率与其能级呈指数相关。

文献中有几十种 RL 算法。最简单的之一是特征匹配。它假设奖励函数可以写为特征的加权线性组合：

```
R_0(s,a') = Σ_{i=1}^{∞} θ_i f_i(s,a') = θ · f
```

例如，驾驶领域的特征可能包括速度、超过限速的速度、加速度、与最近障碍物的距离等。回想第 557 页的 (16.2)，从状态`s_0`开始执行策略`π`的效用定义为：

```
π*(s) = E Σ_{t=0}^{∞} γ^t R(S_t, π(S_t), S_{t+1})
```

其中期望`E`是对于由`s`和`π`决定的概率分布。由于`R`被假设为特征的线性组合，我们可以将其重写为：

```
π*(s) = E Σ_{t=0}^{∞} γ^t Σ_{i=1}^{∞} θ_i f_i(S_t, π(S_t), S_{t+1})
= E Σ_{i=1}^{∞} θ_i Σ_{t=0}^{∞} γ^t f_i(S_t, π(S_t), S_{t+1})
= Σ_{i=1}^{∞} θ_i μ(π) = θ · μ(π)
```

我们在执行策略`π`时定义了特征期望`μ(π)`。例如，如果`f_1`是车辆的超速（超过限速），那么`μ(π)`就是整个轨迹的时间折扣平均速度。关于特征期望的关键点是：如果策略`π`产生的特征期望与专家策略`π_E`匹配，那么根据奖励函数，`π`就与专家一样。现在我们无法测量专家策略的精确值，但可以使用观测轨迹上的平均值来近似它们。因此，我们需要找到参数`θ_j`，使得由参数的策略的特征期望与观测轨迹上的专家策略匹配。以下算法在任何所需的误差范围内实现了这一点：

- 选择一个初始默认策略`π^(0)`。
- 对于`j=1, 2, ...`，直到收敛：
- 找到参数`θ^(j)`，使得策略`π^(j)`优于`π^(0), ..., π^(j-1)`，根据期望效用`u^(l,j)-μ(π)`。
- 令`π^(j)`为奖励函数`R^(j)=θ^(j) · f`的最优策略。

该算法收敛到一个与专家值接近的策略。它只需要`O(n log n)`次迭代和`O(n)`次专家演示，其中`n`是特征的数量。机器人可以通过观察专家动作来学习多体领域中其他智能体使用的策略，无论是对抗性的还是协作性的。最后，逆强化学习可以用于科学探索（而不考虑智能体设计），以更好地理解人类和动物的行为。RL 中的一个关键假设是，“专家”在单智能体 MD 中根据某种奖励函数以最优（或接近最优）的方式运行。如果学习者通过单向镜观察专家，那么这个假设是合理的。例如，假设一个机器人正在医学院通过人类专家学习成为外科医生。逆 RL 算法会假设人类以最优方式手术，就像机器人不在一样。那么会发生什么：人类医生被要求机器人像其他医学生一样快速学习，因此她会大大修改自己的行为。解释她在做什么；指出要避免的，例如切口太深或缝合太紧；以防手术期间发生意外。在单独执行手术时，这些行为没有任何意义，因此逆 RL 算法无法解释底层的奖励函数。相反，我们需要将这种情况理解为第 17.2.5 节描述的双人协助游戏。
