
除了单变量分布，我们还需要多变量的分布。用逗号连接。例如，`P(Weather,City)` 表示 `Weather` 和 `City` 的组合。这是一个 `4×2` 的概率表，被称为 **Weather 和 City 的联合概率分布**。我们也可以混合变量和值；`P(sun,City)` 是表示非晴天的两个元素的向量。

这种符号表示比其他方式要简洁得多。例如，`Weather` 和 `City` 所有可能值的乘积规则（见公式 12.4）可以写为一个单一方程：

```
P(Weather,City) = P(Weather|City)P(City)
```

而不是这 `4×2=8` 个方程（使用缩写 `W` 和 `C`）：

```
P(W=sun∧C=true) = P(sun|C=true)P(C=true)
P(W=rain∧C=true) = P(rain|C=true)P(C=true)
P(W=cloud∧C=true) = P(cloud|C=true)P(C=true)
P(W=snow∧C=true) = P(snow|C=true)P(C=true)
P(W=sun∧C=false) = P(sun|C=false)P(C=false)
P(W=rain∧C=false) = P(rain|C=false)P(C=false)
P(W=cloud∧C=false) = P(cloud|C=false)P(C=false)
P(W=snow∧C=false) = P(snow|C=false)P(C=false)
```

作为退化情况，`P(sun,City)` 没有值，因此是一个零维向量，我们可以将其看作标量。

现在我们已经定义了命题和概率断言的语义，并给出了部分：为了完成语义，我们需要知道词汇是什么以及如何判断一个命题在某个世界中是否成立。我们直接从命题逻辑的语义中借用，如下。可能世界被定义为对所有考虑的随机变量赋值赋值。

很容易看出，这满足了可能世界互斥且穷尽的原则（练习题 12.EXEX）。例如，如果随机变量是空洞、牙痛和天气，那么就有 `2×2×4=16` 种可能的世界。此外，在这些世界中，任何给定命题的真值都可以通过我们用于命题逻辑的递归真值方法轻松确定（见第 236 页）。

注意，某些变量可能是冗余的，因为它们的值在所有情况下都可以从其他变量的值获得。例如，在双骰子世界中，*双数*（`Doubles`）变量正是 `Die1=Die2` 的情况。将*双数*作为随机变量之一（加上 `Die1` 和 `Die2`），似乎会将可能世界的数量从 36 增加到 72，但当然这 72 种中的有一半在逻辑上是不可能的，概率为 0。

根据上述对可能世界的定义，概率完全由所有随机变量的联合分布决定——这被所谓的**全概率分布**。例如，给定*空洞、牙痛和天气*，联合分布为 `P(Cavity, Toothache, Weather)`。该分布可以表示为一个具有 16 个条目的 `2×2×4` 表。因为每个命题的概率都是所有可能世界的和，因此全联合分布原则上可以计算任何命题的概率。我们将在 12.3 节中看到如何操作的示例。

## 12.2.3 概率公理及其合理性

概率的基本公理（方程 (12.1) 和 (12.2)）暗示了对逻辑相关命题赋予的相信程度之间的关系。例如，我们可以推导出命题概率与其否定形式概率之间熟悉的关系：

```
P(¬A) = ∑_{ω ∈ ¬A} P(ω) = ∑_{ω ∉ A} P(ω) = ∑_{ω ∈ Ω} P(ω) - ∑_{ω ∈ A} P(ω) = 1 - P(A)
```

通过方程 (12.2) 根据 (12.1) 和 (12.2) 对前两项分组得出。

我们还可以推导出析取概率的著名公式，有时被称为**包含斥原理**：

```
P(A ∨ B) = P(A) + P(B) - P(A ∧ B)
```

该规则通过注意这一点得到修正：`a` 成立的情况加上 `b` 成立的情况了所有 `a∨b` 的情况；但两个计数之和重复了它们的交集，所以我们需要减去 `P(a ∧ b)`。

方程 (12.1) 和 (12.5) 在数学天才安德烈·哥尔莫哥夫的历史中被称为**哥尔莫哥夫公理**，他展示了如何从这样的基础建立概率论，以及如何处理连续变量带来的困难。虽然方程 (12.2) 带有定义色彩，但它揭示了公理确实限制了代理对相关命题可能拥有的相信程度。这类似于比逻辑代理不能同时相信 `A`、`B` 和 `(¬A ∧ B)`。然而，概率的陈述并不直接指向世界，而是指向代理的知识状态。那么，为什么代理不能持有这些信念集（即使它们违反了哥尔莫哥夫公理）呢？

```
P(A)=0.4  P(B)=0.3  P(A ∨ B)=0.8.
```

困难包括*维特利*集（`Vitali` set），它是区间 `[0,1]` 内一个定义良好但没有良好定义的子集。

## 边缘化 (Marginalization)

这个过程被称为边缘化，或求和——因为我们对其他变量的每个可能值的概率进行求和，从而将它们从方程中移除。我们可以为任何变量集 `Y` 和 `Z` 写出通边缘化规则：

```
P(Y) = ∑_{z} P(Y, Z=z)
```

其中 `Σ` 对变量集 `Z` 所有可能的取组合进行求和。在方程中，我们可以通过 `P(Y, Z)` 得到 `P(Y, Z=z)`。对于龋齿（`Cavity`）例子，方程 (12.7) 对应以下方程：

```
P(Cavity) = P(Cavity, toothache, catch) + P(Cavity, ~catch)
+ P(Cavity, ~toothache, catch) + P(Cavity, ~toothache, ~catch)
= (0.108, 0.016) + (0.012, 0.064) + (0.072, 0.144) + (0.008, 0.576)
= (0.2, 0.8).
```

## 条件化 (Conditioning)

使用乘积规则（方程 (12.4)），我们可以将方程 (12.7) 中的 `P(Y, z)` 替换为 `P(Y|z)P(z)`，得到规则条件形式：

```
P(Y) = ∑_{z} P(Y|z)P(z).
```

边缘化和条件化证明对所有涉及概率表达式的推导都有用。在大多数情况下，我们感兴趣的是给定其他变量证据的情况下，计算某些变量的条件概率。可以通过使用 (12.3) 获取无条件概率的表达式，然后从全联合分布中评估该表达式来找到条件概率。例如，我们在有牙痛证据的情况下计算龋齿的概率，如下：

```
P(cavity|toothache) = P(cavity ∧ toothache) / P(toothache)
= (0.108 + 0.012) / (0.108 + 0.012 + 0.016 + 0.064) = 0.6.
```

为了检查一下，我们还可以计算在有牙痛的情况下没有龋齿的概率：

```
P(~cavity|toothache) = P(~cavity ∧ toothache) / P(toothache)
= (0.016 + 0.064) / (0.108 + 0.012 + 0.016 + 0.064) = 0.4.
```

这两个值之和为 1.0，正如理应的。注意项 `P(toothache)` 在这两个计算中都在分母上。如果变量 `Cavity` 有超过两个值，它将出现在所有计算的分母中。事实上，我们可以将其作为分布 `P(Cavity, toothache)` 的归一化常数，确保其和为 1。在处理概率的整个章节中，我们使用 `α` 来表示此类常数。用这种表示法，我们可以将两个方程合并为一个：

```
P(Cavity|toothache) = α P(Cavity, toothache)
= α [P(Cavity, toothache, catch) + P(Cavity, toothache, ~catch)]
= α [(0.108, 0.016) + (0.012, 0.064)] = α (0.12, 0.08) = (0.6, 0.4).
```

## 12.4 节 独立性 (Independence)

换句话说，即使我们不知道 `P(toothache)` 的值，也可以计算 `P(Cavity|toothache)`！我们暂时忘记因子 `1/P(toothache)`，并将龋齿和无龋齿的值相加，得到 0.12 和 0.08。这些是正确的比例，它们之和不是 1，因此我们通过将每一项除以 `0.12+0.08` 来归一化，得到真实的概率 0.6 和 0.4。归一化证明是概率计算中一种非常有用的捷径，既能让计算更容易，又能让我们继续进行概率评估（因为 `P(toothache)` 不可用）。从示例中，我们可以提取出一个通用的推理程序。在查询单个变量 `X` 的情况下（在示例中是 `Cavity`）。令 `E` 为证据变量列表（在示例中仅为 `Toothache`），`e` 为这些变量的观测值列表，`Y` 为未观测变量（在示例中是 `Catch`）。查询是 `P(X|e)` 且可以求值为：

```
P(X|e) = α P(X,e) = α ∑_{Y} P(X,e),
```

其中求和涵盖所有可能的 `y`（即未观测变量的所有可能的取值组合）。注意变量 `E` 和 `Y` 构成了该的完整变量集，`P(X,e)` 是来自全联合分布的概率子集。在给定可操作的全分布的情况下，(12.9) 可以回答离散变量的概率查询。它的扩展性不好；对于由 `n` 个变量描述的领域，推理会产生一个大小为 `O(2^n)` 的输入表，并花费 `O(2^n)` 时间处理表格。在现实问题中，`n` 很容易达到 100，使得 `O(2^n)` 变得不可行——一个拥有 `2^100` 条目的表格！问题不仅在于内存和计算：而且在于这 `10^30` 个概率中的每一个都必须从示例中估估计，所需的示例数量将是天文数字。由于这些原因，表格形式的全分布很少用作构建系统的实用工具。相反，它应该被视为构建更有效方法的理论基础，就像表格是第 7 章中 `DPLL` 等实用算法的基石一样。本章的剩余部分介绍了一些为第 13 章开发现实系统做准备所需的思想。

让我们使用图 12.3 中的全分布添加第四个变量 `Weather`。全联合分布变为 `P(Toothache, Catch, Cavity, Weather)`，它有 `2×2×2×4=32` 条目。它包含了图 12.3 显示的四个“部分”，对于每种天气。这些变量与原始三变量表格 `P(toothache,cavity)` 有什么关系？我们可以使用乘积规则（方程 (12.4)）：

```
P(toothache,cavity,weather) = P(weather|toothache,cavity)P(toothache,cavity).
```

![](img/e36752d03ef526fc4a8db735be2d_15_0.png)

**图 12.4** 使用绝对独立性将大分布分解为较小分布的示例。(a) 天气和牙科问题是独立的。(b) 硬币抛掷是独立的，不影响牙科变量。因此，以下断言是合理的：

```
P(toothache, catch, cavity) = P(cavity). (12.10)
```

从这里，我们可以推出：

```
P(toothache, catch, cavity) = P(weather)P(toothache, catch).
```

对于 `P(Toothache, Catch, Weather)` 中的每一个条目都有类似的方程。方程 (12.10) 中使用的属性被称为**独立性**（也称为**边缘独立性**）和**绝对独立性**。特别是天气独立于个人的牙科问题。比例 `a` 和 `b` 之间的独立可以写为：

```
P(a|b) = P(a)  P(b|a) = P(b)  P(a ∧ b) = P(a)P(b). (12.11)
```

这些都相等（练习 12.NDI）。变量 `X` 和 `Y` 之间的独立可以写为（如下），因为所有都是等价的：

```
P(X|Y) = P(X)  P(Y|X) = P(Y)  P(X,Y) = P(X)P(Y).
```

独立性假设通常基于对领域的知识。正如牙痛-天气示例所示，它们可以极大地减少指定全分布所需的信息量。

## 第 12.5 节 贝斯法则及其应用

当可用时，独立性断言可以帮助减小定义域表示的大小和推理问题的复杂性。遗憾的是，通过独立性对变量集合进行完全分离是非常稀见的。只要两个变量之间存在联系（即使是间接的），独立性就无法成立。此外，即使是独立的子集也可能很大——例如，牙科可能涉及几十种疾病和数百种症状，而所有这些都是相互相关的。为了处理这类问题，我们需要比直接的独立性概念更微妙的方法。

在第 408 页，我们定义了积（公式 12.4）。它实际上可以写成两种形式：

```
P(a ∧ b) = P(a|b)P(b)     P(a ∧ b) = P(b|a)P(a).
```

将两个右边项相等并除以 `P(a)`，我们得到：

```
P(b|a) = P(a|b)P(b) / P(a)   12.12
```

该方程被称为**贝斯法则**（也称为贝斯定律或贝叶斯定理）。这个简单的方程为大多数现代 AI 系统的概率性能提供了模型。

对于多变量，贝斯法则的更一般情况可以用 `P` 记法表示如下：

```
P(Y|X) = P(X|Y)P(Y) / P(X)
```

与之前一样，这表示一组方程，每个方程处理变量的特定值。我们还需要在某些背景证据上使用更通用的条件概率。
