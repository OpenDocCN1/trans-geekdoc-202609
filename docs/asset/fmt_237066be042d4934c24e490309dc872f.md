
```
$$\frac{S}{N} = -10\log_{10} n \sum_{i=1}^{n} \frac{1}{y_i^2}}$$ (4.1)
```
其中 `y` 代表观测测量值，`n` 代表进行的实验试验总数。按照公式 (4.2) [17] 计算信噪比以计算每个参数的单独影响：
```
$C_i = \frac{R}{\sum RI} \times 100\%$ (4.2)
```
此处，`R` 表示极差，即每个参数水平下对应的最小信噪比与最大信噪比之间的差值。计算此范围可以识别出产生最高信噪比的特定参数。因此，这种识别有助于预测最优参数，使最终输出与所需属性之间的偏差最小化。

### 4.4.5 开发响应面模型

```
$MaxStress = 12.574 + 1.192 \times A + 0.882 \times B + 4.712 \times C - 0.545 \times D$
```
在该模型中，层厚的影响最显著，占比 65.27%，其次是 `(B)` 打印密度占 12.47%，以及 `(A)` 填充类型占 8.05%，所有因素共同决定了整体拉伸强度。

## 4.5 结论

在本章中，我们使用田口响应面法（RSM）实验研究了七个3D打印参数对FDM打印的PLA样本拉伸强度的影响，用以选择最优参数。在我们的工作中，我们简单地利用田口正交表结合方差分析（ANOVA）和响应面法，并在使用`Cubican Style®`的简单FDM3D打印过程中，考虑了填充样式、打印密度、层厚、喷嘴速度、挤出率、扫描角和外壳温度。

根据S/N比分析和基于OA L18（21³6）田口方法的ANOVA分析，我们确定层厚是提高拉伸强度的最重要的参数，其次是打印密度（65.27%和12.47%）。这藻通过`Minabit`商业软件和额外的验证实验得到了证实。本研究结果表明，在使用传统的田口方法或ANOVA时，可以设置3D打印机参数以获得更高的拉伸强度。重要的是，这些发现有助于教师和学生更好地理解参数设置对打印样本拉伸强度结果的影响。
