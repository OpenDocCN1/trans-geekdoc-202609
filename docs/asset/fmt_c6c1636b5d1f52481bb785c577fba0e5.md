# 7. 字符串 (Strings)

我们已经遇到过字符串了对吧？嗯，我认为它们是非常有趣的数据类型。这就是为什么我决定专门用一小章来介绍它们。

## 插值 (Interpolation)

字符串是程序员对应用程序变量中存储的文本序列的名称。让我们给一个变量赋值一个字符串来复习一下。

示例 01：不同的人使用不同的引号。

```php
<?php
// 使用单引号的字符串。
$panda = 'Pandas rule!';
// 使用双引号的字符串。
$panda = "Pandas rule!";
// 输出。
echo $panda;
```

好了，我知道第二行是多余的。我把它留在那儿是为了提醒你，有两种不同类型的引号可以包裹字符串值。

那么，既然我们有两个选择，区别在哪里呢？总不能仅仅是为了清晰度吧？我的意思是，在我看来它们看起来都都一样简洁。

嗯，其实是有区别的。包含在双引号中的字符串值要聪明一点点。它们拥有一种单引号兄弟无法做到的技巧，这被称为**字符串插值**（String interpolation）。

这个术语听起来很糟糕，对吧？它非常令人困惑。它简单意味着我们可以在字符串内部嵌入值。让我们来看看它的实际效果。

示例 02：字符串插值。

```php
<?php
// 设置一个字符串。
$value = 'pandas';

// 单引号。
$first = 'We love $value!';

// 双引号。
$second = "We love $value";

// 输出。
var_dump($first);
var_dump($second);
```

我们将尝试向两种类型的字符串中通过变量名插入变量。让我们查看输出这两种类型字符串的结果。

示例 03：输出。

```php
string(15) "We love $value!"
string(15) "We love pandas!"
```

如你所见，使用单引号时，变量名就像字符串的一部分一样呈现出来。然而，在双引号字符串中，我们的变量名已经被替换成了变量的值。

哇！这超级有用。不是吗？

我想给你一点小建议。最好将插值包裹在`{ 这种大括号 }`中。这会让插值变得整洁得多，而且你会发现当你开始使用数组时，它的工作效果会更好。

这是一个例子。

示例 04：更整洁的字符串插值。

```php
<?php
// 设置一个字符串。
$value = 'pandas';
// 插入值。
$result = "We love {$value}!";
// 输出。
var_dump($result);
```

整洁多了，不是吗？坚持使用大括号吧。相信我，你会慢慢爱上它们的。

## 拼接 (Concatenation)

拼接是将两个字符串首尾相接的过程。就像制作珠子项链，或者人类蜈蚣……噢，我的天呐。让我们来看看这个过程的实际操作示例。

示例 05：字符串拼接。

```php
<?php
// 第一个值。
$first = 'Pandas are';
// 第二个值。
$second = 'awesome!';
// 拼接。
var_dump($first . $second);
```

我们创建两个字符串值，然后输出拼接的结果。在 PHP 中，我们使用点`.`字符来执行拼接。让我们来看看结果，好吗？

示例 06：输出。

- Pandas are awesome!

太棒了！我们的字符串已经粘在了一起。我们可以根据需要拼接任意数量的值。这里有一个例子。

示例 07：更多值。

```php
<?php

$first = 'Pandas';
// 第二个值。
$second = 'are';
// 第三个值。
$third = 'completely';
// 第四个值。
$fourth = 'awesome!';
// 拼接。
var_dump($first . $second . $third . $fourth);
```

我们还可以拼接不同类型的变量；PHP 会简单地将它们视为字符串。为了证明这一点，让我们拼接一个字符串和一个浮点数值。


## 9. 类型强制转换 (Casting)

事情并不总是按照你的计划进行，不是吗？变量的类型也不总是正确的。幸运的是，在 PHP 中，我们可以使用称为“强制转换”的方法将一种数据类型强制转换为另一种数据类型。

## 基础用法

假设我们有一个包含以下内容的字符串。

示例 01：这里没有新内容。

```php
<?php
$Panda = '3';
```

当然，它是一个 3，但在 PHP 内部它存储为字符串，并将其视为字符串。我们可以通过转储（dump）值来看到这一点。如果我们对`$Panda`变量使用`var_dump()`，我们将得到以下输出：

示例 02： 输出：

```
string(1) "3"
```

看，PHP 是知道的。当然，当你对上述字符串进行算术运算时，PHP 会在内部将值转换为数值类型，但如果我们想自己进行转换呢？如果我们想确保变量持有的是整数呢？这正是强制转换很有用的地方。

在 PHP 中，有很多函数可以帮助进行转换，但由于我们还没有开始学习函数，让我们先使用现有的方法吧。我们可以通过指定过程将一个值转换为另一种数据类型。听起来很复杂，但实际上非常简单。让我们来看一个代码示例。

示例 03：转换为整数。

```php
<?php
$spanda = '3';

// 转换为整数。
$spanda = (int) $spanda;

// 转储结果。
var_dump($spanda);
```

我们在第一行设置了数字的字符串表示。在下一行中，我们使用`(int)`加上放在括号之间的任何数据类型。我们决定它应该是一个整数，所以我们在强制转换括号中提供了`int`。我们也可以以更快速、更整洁的方式提供类型！

示例 04： 输出。

```
int(3)
```

太棒了！我们的 panda 现在是一个整数而不是字符串。我们要不要尝试将字符串转换为浮点数（float）吗？你能猜出语法是什么吗？

示例 05：转换为浮点数。

```php
<?php
$spanda = '3';

// 转换为浮点数。
$spanda = (float) $spanda;

// 转储结果。
var_dump($spanda);
```

没错，我们只需用`float`代替`int`即可。让我们看看结果。

示例 06： 输出。

```
float(3)
```

太棒了！我们的值现在是一个浮点数。转换也可以反向操作。如果我们想将一个浮点数值表示为字符串，可以使用下面的示例。

示例 07：转换为字符串。

```php
<?php
$panda = 3.4567;

// 转换为字符串。
$panda = (string) $panda;

// 转储结果。
var_dump($panda);
```

如果我们转储结果，会发现`$panda`的值现在是一个字符串了。

示例 08： 输出。

```
string(6) "3.4567"
```

这些强制转换示例实现的效果显而易见。我想这就是我们预期的。不过，数组稍微困难一点。你认为如果我们尝试将字符串转换为数组会发生什么？当我们遇到这类问题时，写一小段代码进行实验总是有意义的。在日常工作中，我有时会忘记复杂的转换会发生什么，我会构建一个小的片段来确认我的理解。

示例 09：转换为数组。

```php
<?php
$panda = 'Lushui';

// 转换为数组。
$panda = (array) $panda;

// 转储结果。
var_dump($panda);
```

我们使用数组类型来转换为数组。那么，发生了什么？

示例 10： 输出。

```
array(1) {
  [0=>string(6) "Lushui"
}
```

噢，这很有意思！看起来 PHP 将我们的字符串封装在一个索引数组中。在其他语言中，这样的语句可能会将我们的字符串拆分为字符（字母）数组，但 PHP 没有字符类型的概念，因此它处理该语句的方式略有不同。
