
# 擦除介质

擦除介质以不可恢复的方式覆盖或丢弃数据。对于硬盘驱动器和其他磁性介质，这可以通过一系列写入（通常是 `1` 或 `0`）到驱动器上的每个存储位置（位）来完成。各种工具（如 Darik's Boot and Nuke (DBAN)）将对整个磁盘执行多次遍历，以尝试确保没有数据残留。事实上，数据残留（即事后仍留在磁盘上的数据）是一个重大问题，特别是对于使用磨损均衡算法将驱动器的磨损分散到比列出容量更大的空间上的 SSD 和其他闪存介质。使用写入所有可访问位置的传统驱动器擦除工具擦除 SSD 将会遗漏磁盘上因磨损均衡过程而可能保留数据副本的区域。

幸运的是，能够使用这些驱动器内置的安全 `Erase` 命令的工具有助于确保残留数据不是问题。在许多情况下，一个更好的解决方案是在驱动器的整个生命周期内使用全盘加密，然后在数据准备报废时直接丢弃加密密钥。除非您的组织面临高级威胁，否则这种方法很可能会使数据无法被即使是相当高级的恶意行为者恢复。

由于擦除驱动器可能会出现问题，因此销毁驱动器是希望消除数据丢失或泄露风险的组织的常用选择。将驱动器粉碎、粉碎或焚烧，使得无法恢复任何数据，这是一种选择，第三方供应商专门提供此类服务，并为每个被销毁的资产（驱动器或系统）提供文档记录。尽管这会导致部分潜在可回收价值的损失，但对于做出此决定的组织来说，在风险计算中，较旧驱动器的剩余价值远低于单次违规的成本。

# 文件操作和其他有用的命令行工具

与 Linux 和 Unix 系统及设备上的文件进行交互是许多安全专业人员熟悉的任务。快速从文件收集信息、操作文件、更改其权限或仅仅是搜索文件的能力，可以在成功处理事件、识别问题或加快操作任务方面发挥关键作用。Security+ 考试重点关注六种命令行工具：

*   **`head`**：显示文件开头部分的命令。默认情况下，它将显示文件的前 10 行，使其成为快速查看文件内容的实用工具。您可以使用 `-n` 标志更改显示的行数，并通过在命令行中包含多个文件来显示多个文件的行。要查看名为 `example.txt` 的文件的前 15 行，请输入：`head -n 15 example.txt`。

*   **`tail`**：与 `head` 命令非常相似，但默认情况下它显示文件的最后 10 行。`tail` 常用于查看最近的日志条目或文件中正在变化的其他数据。与 `head` 一样，您可以添加 `-n` 标志来显示任意数量的行，但在许多情况下最有用的模式是 `-f` 标志，它会跟踪变化。使用 `tail -f` 将显示文件随变化而更新的内容。与 `head` 一样，您也可以同时监控多个文件。

*   **`cat`**：concatenate（连接）的缩写，可用于将文件输出到标准输出（您的控制台）或将文件追加到其他文件。输入 `cat example.txt` 将在控制台显示 `example.txt` 的内容。输入 `cat more.txt > example.txt` 将把 `more.txt` 的内容添加到文件 `example.txt` 中。`cat` 命令还有许多其他有用的功能，您可以通过 [shapeshed.com/unix-cat](http://shapeshed.com/unix-cat) 上通俗易懂的示例了解它们。

*   **`grep`**：一种搜索工具，允许您搜索与提供的文本或正则表达式匹配的模式。在其最基本的形式中，您可以通过输入 `grep 'word' /file/location` 来搜索单词，将 `word` 替换为您要查找的单词或文本字符串，将 `/file/location` 替换为您要搜索的文件或目录位置。`grep` 命令有许多方便的功能，例如 `-A` 和 `-B` 选项，当提供一个数字作为输入时，它们将在匹配模式之后或之前打印指定数量的行。这使得 `grep` 成为快速搜索日志和其他文本文件以查找特定信息的理想工具。还有许多其他有用的 `grep` 标志，因此如果您还不熟悉 `grep` 的基础知识，我们建议您花些时间阅读手册页或 `grep` 教程。

*   **`chmod`**：允许您使用符号或数字表示法设置文件和目录的权限。要为 `example.txt` 设置读、写和执行权限，您可以发出命令 `chmod 777 example.txt`。您也可以通过输入 `chmod +rwxrwxrwx example.txt` 设置相同的权限。了解如何设置特定权限以及如何读取权限（参见图 11.4），对于确保文件和目录安全至关重要。

# 脚本、安全传输和 Shell

您端点安全工具包中的另一组有用工具是 Shell 和脚本语言。连接到命令行界面或在本地系统上使用它，然后执行我们刚才探讨的文件操作命令等，提供了控制和管理系统的强大能力。Security+ 考试关注远程访问以及您应该了解的两种脚本环境。

安全 Shell，或 **`SSH`**，是一种用于连接系统的加密协议，通常通过命令行进行。SSH 也是使用 SSH 协议创建该连接的客户端的名称。一旦通过 SSH 连接，您就可以在您正在使用的系统所运行的任何 Shell 环境中发出命令。

Windows 系统拥有一个内置的管理、自动化和脚本语言工具，称为 **`PowerShell`**。PowerShell 脚本和命令允许从命令行管理和配置 Windows 系统。PowerShell 可以报告系统的当前状态，对本地和远程系统进行更改，并具有许多其他功能，使其成为攻击者和防御者都青睐的工具。

像 **`Python`** 这样的脚本语言也被用于系统管理和维护任务，以及通过自动化为用户提供解决复杂任务的强大方式。尽管 Python 变得越来越普遍，但 **`Perl`** 和其他语言仍然被用于脚本编写和作为软件包的一部分，特别是针对 Linux 和基于 Unix 的系统。

Security+ 考试在本节中重点关注的最后一个工具是 **`OpenSSL`**。OpenSSL 不是 Shell，也不是脚本语言。相反，就像 SSH 一样，OpenSSL 是 TLS 协议的一种实现，常用于保护其他服务。OpenSSL 的 TLS 实现用于 HTTPS 流量；每当需要以受保护的方式通过网络发送流量，而通过 SSH 或 VPN 连接建立隧道并不合适时，OpenSSL 很可能是一个合理的替代方案。作为安全专业人员，您需要知道 OpenSSL 经常被用来封装这种流量，因此您会在许多地方遇到嵌入式的 OpenSSL。

Security+ 考试期望您知道如何使用 OpenSSL 作为评估组织安全性的一部分。对于安全分析师来说，这通常包括寻找需要安全通信但缺失的地方，或 OpenSSL 配置错误的地方。这意味着您需要了解为什么要使用它，并了解它带来的有助于提高组织通信安全性的功能。TLS 协议的关键要素之一是它提供了临时 RSA 密钥交换以创建完美前向保密。换句话说，只有在知道密钥时才能解密会话，并且临时密钥是在两个系统之间通信开始时生成的。因此，当两个以前可能从未通信过的系统需要安全通信时，使用 OpenSSL 和 TLS 是理想的解决方案。网站一直在为此目的使用 TLS，您对托管网站或其他服务的系统进行的安全评估——在这些系统中，系统可能需要在没有额外配置或事先通信的情况下安全通信——应将 OpenSSL 和 TLS 识别为一种安全选项。

配置错误或不当配置的 OpenSSL 安装将允许使用弱加密套件，可能允许降级攻击，从而导致数据泄露。请考虑 OpenSSL 允许的加密选项集是否符合贵组织的需求，即使 OpenSSL 是为您正在审查的 Web 或其他服务配置的。

# 保护嵌入式和专用系统

安全从业者每天都会遇到传统计算机和服务器，但随着智能设备、嵌入式系统和其他专用系统持续被构建到从家用电器、建筑物、车辆甚至服装的各种事物中，组织的攻击面正以新的方式增长。无论这些系统出现在何处，都需要将其视为组织整体安全态势的一部分来考虑。

## 嵌入式系统

嵌入式系统是内置在其他设备中的计算机系统。工业机械、家用电器和汽车都是您可能遇到嵌入式系统的地方。嵌入式系统通常高度专用，运行定制的操作系统，并具有向用户公开的非常特定的功能和接口。然而，在越来越多的情况下，它们可能嵌入一个相对强大的系统，具有 Wi-Fi、蜂窝网络或其他无线接入，运行 Linux 或类似的、更熟悉的操作系统。

许多嵌入式系统使用**实时操作系统 (RTOS)**。`RTOS` 是一种操作系统，当优先处理传入数据而非使用操作系统中断或等待正在处理的任务完成后再处理数据时使用。由于嵌入式系统广泛用于响应必须迅速的工业流程，因此使用实时操作系统以最大限度地减少操作系统接受数据和处理任务速度的差异量。

`Security+` 考试大纲重点关注其列为嵌入式系统的三种特定类型的系统。第一种是**树莓派**。树莓派是单板计算机，这意味着它们在单块板上拥有计算机系统的所有功能，包括网络连接、存储、视频输出、输入、CPU 和内存。树莓派设备提供了一个相对强大的计算平台，并且可以运行多种操作系统，包括 Linux 和 Windows。树莓派设备更有可能被用于个人开发或小规模定制用途，而不是作为工业或商业嵌入式系统核心的大规模部署。

类似地，`Security+` 考试大纲列出的第二种设备是**Arduino**。与树莓派不同，Arduino 不被视为单板计算机。相反，它们属于一类称为**微控制器**的计算机。它们包含一个低功耗 CPU、少量内存和存储，并提供输入和输出功能。它们常用于原型设计与传感器、电机、照明和类似基本功能交互的设备。与树莓派不同，Arduino 没有内置有线或无线网络连接，因此由于缺乏直接物理访问，减少了其攻击面。

大纲中直接提到的最后一种嵌入式系统是**现场可编程门阵列 (FPGA)**。FPGA 是一种计算机芯片，可以通过编程重新设计其工作方式，使其成为可定制的芯片。选择使用 FPGA 的制造商可以对其进行编程，以比传统专用芯片更高的效率执行特定任务。单个 FPGA 本身不是嵌入式系统。系统可能将 FPGA 作为嵌入式系统中的一个组件或作为其中的可编程处理器进行集成。如果嵌入式系统集成了 FPGA，您需要知道它可能被重新编程。

除了 `Security+` 考试大纲涵盖的三种系统类型之外，嵌入式系统有多种形式，并且可以完全嵌入，以至于您可能没有意识到您正在查看的设备中嵌入了一个系统。作为安全专业人员，您需要能够评估嵌入式系统安全性，并确定方法以确保它们在不导致系统本身故障或遭受不可接受的性能下降的情况下，保持安全且可用于其预期目的。

评估嵌入式系统的方法与评估传统计算机系统大致相同：

1.  确定嵌入式系统的制造商或类型，并获取关于它的文档或其他资料。
2.  确定嵌入式系统如何与外界交互：它是连接到网络、其他嵌入式设备，还是仅具有键盘或其他物理接口？
3.  如果设备确实提供网络连接，请识别通过该网络连接提供的任何服务或访问权限，以及如何保护这些服务或连接本身。
4.  了解设备如何更新、补丁是否可用、如何以及何时安装这些补丁；然后确保有一个符合设备威胁模型和使用要求的补丁周期。
5.  记录当设备发生安全问题或妥协时贵组织将采取的措施。能否恢复正常？如果设备因该问题脱机会发生什么？如果设备故障或需要退出服务，是否会发生关键的健康、安全或运营问题？
6.  记录您的发现，并确保适当的实践包含在贵组织的操作程序中。

随着越来越多的设备出现，这项工作需要越来越多的时间。提前介入流程，使安全性作为采购流程的一部分被考虑进去会有所帮助，但许多设备可能只是作为其他采购的一部分出现。

## SCADA 和 ICS

工业和制造系统通常使用两个术语之一来描述。**工业控制系统 (ICS)** 是工业自动化的广义术语，而**数据采集与监视控制系统 (SCADA)** 通常指运行电力和水分配或其他覆盖大面积区域系统的大型系统。由于术语重叠，它们经常互换使用。

SCADA 是一种系统架构，它结合了数据采集和控制设备、计算机、通信能力以及用于控制和监控整个架构的界面。SCADA 系统通常用于运行复杂的制造和工业流程，在这些流程中，监控、调整和控制整个流程的能力对成功至关重要。

图 11.5 显示了 SCADA 系统的简化概览。您将看到远程遥测单元 (RTU) 从传感器收集数据，可编程逻辑控制器 (PLC) 控制并从机器或机器人等工业设备收集数据。数据被发送到系统控制和监控控制台，允许操作员查看正在发生的事情并管理 SCADA 系统。这些功能意味着 SCADA 系统通常用于工业和制造环境，以及能源行业监控工厂，甚至物流行业跟踪包裹和复杂的分拣及处理系统。

### 保护嵌入式和专用系统

由于 ICS 和 SCADA 系统将运行通用操作系统的通用计算机与带有嵌入式系统和传感器的工业设备相结合，因此它们呈现出复杂的安全概况，供安全专业人员进行评估。在许多情况下，必须将它们作为单独的组件来处理，以确定其独特的安全需求，包括定制的工业通信协议和专有接口等。一旦这些单独的组件被绘制并理解，它们的交互以及整个系统或主要组件的安全模型就可以被设计和管理。

在保护此类复杂系统时，需要牢记的一个关键点是，它们在设计时往往未考虑安全性。这意味着增加安全措施可能会干扰其功能，或者安全设备可能不适合添加到该环境中。在某些情况下，隔离和保护 ICS、SCADA 和嵌入式系统是你能采用的最有效的安全模型之一。

### 保护物联网

**物联网 (IoT)** 是一个宽泛的术语，用于描述用于自动化、传感、安全和类似任务的网络连接设备。IoT 设备通常是一种嵌入式系统，但许多设备利用机器学习、AI、云服务和类似功能等技术来提供“智能”特性。

IoT 设备带来许多安全和隐私问题，安全分析师必须了解这些常见问题：

*   不良的安全实践，包括弱默认设置、缺乏网络安全（防火墙）、暴露或易受攻击的服务、数据传输缺乏加密、弱认证、使用嵌入式凭据、不安全的数据存储，以及其他各种不良实践。
*   短暂的支持生命周期——IoT 设备可能不会被修补或更新，导致它们在大部署生命周期内都可能处于易受攻击状态。
*   供应商数据处理实践问题，包括许可和数据所有权顾虑，以及在设备所有者不知情的情况下，向供应商的员工和合作伙伴以及政府和其他机构泄露数据的可能性。

尽管存在这些安全顾虑，传感器、楼宇和设施自动化设备、可穿戴设备以及其他智能设备等 IoT 设备仍在持续普及。安全专业人员必须同时考虑其组织采购的 IoT 设备，以及员工和访客可能带入其设施的设备。

## 专用系统

你需要为 Security+ 考试考虑的嵌入式系统的最后一类是专用系统：

*   **医疗系统**，包括医院和医生办公室中的设备，可能联网或具有嵌入式系统。心脏起搏器、胰岛素泵和其他体外或植入式系统等医疗设备也可能遭到攻击，针对通过蓝牙攻击心脏起搏器的漏洞利用代码已在野外存在。
*   **智能电表**被部署用于追踪公用事业使用情况，并带有由公用事业公司管理的无线控制网络。由于电表现在可以远程访问和控制，它们提供了新的攻击面，可能会干扰电力、水或其他公用事业，或提供有关设施或建筑物的信息。
*   **车辆**，从汽车到飞机甚至海上船舶，现在都已联网，且经常直接连接互联网。如果它们没有得到妥善保护，或者支持它们的后端服务器和基础设施存在漏洞，攻击者可以接管、监控或以其他方式严重影响它们。
*   **无人机和自动驾驶汽车**，以及类似的车辆，可能通过互联网或无线指挥信道进行控制。加密其指挥和控制信道，并确保它们在连接互联网或网络时具有适当的控制措施，对其安全至关重要。
*   **VoIP 系统**包括后端服务器以及部署在组织内各办公桌和工作地点的 VoIP 电话和设备。电话本身是一种嵌入式系统，拥有可成为攻击目标且可能易受攻击的操作系统。一些电话还提供允许直接远程登录或管理的接口，使其容易受到来自 VoIP 网络的攻击。分割网络以保护潜在易受攻击的 VoIP 设备、定期更新它们以及应用设备的基线安全标准，有助于保持 VoIP 系统安全。
*   **打印机**，包括多功能打印机（MFP），通常内置网络连接。无线和有线网络接口提供对打印机的直接访问，且许多打印机具有不良的安全模型。打印机已被用作访问受保护网络的入口点、反射和放大攻击的工具，以及收集信息的手段。事实上，MFP、复印机和其他扫描并可能存储来自传真、打印件和复印件信息的设备，使这些设备除了作为易受攻击的网络设备可充当攻击中的反射器和放大器，或作为攻击者的跳板点的风险外，还成为潜在的重大数据泄露风险。
*   **监控系统**，如摄像头系统和用于安全但也联网的相关设备，可能为攻击者提供窥视设施或组织内部情况的视角。摄像头提供通常可通过 Web 界面访问的嵌入式接口。
*   默认配置、漏洞、缺乏修补等问题在专用系统中很常见，这与其他嵌入式系统非常相似。当你评估专用系统时，既要考虑如何限制这些潜在问题的影响，也要考虑为你的组织处理它们所需的管理、行政和事件响应流程。

### 通信考量

许多嵌入式和专用系统运行在传统有线和无线网络不可用的环境中。作为安全专业人员，你可能需要考虑用于嵌入式系统的不同类型的连接。

蜂窝连接，包括现有的 LTE 和其他第四代技术以及较新的 5G 网络连接，可以在 Wi-Fi 网络无法工作的许多位置为嵌入式系统提供高带宽访问。由于第三方蜂窝供应商负责连接，使用蜂窝连接的嵌入式系统需要得到保护，以使蜂窝网络不对其运行构成威胁。确保它们不通过蜂窝连接暴露易受攻击的服务或应用程序，对其安全至关重要。构建保护措施以防止网络漏洞利用跨越内部安全边界（如无线连接与本地控制总线之间的边界）也是一项必要的设计特性。

物理上保护内置在蜂窝设备中的用户身份模块（SIM）可能非常重要。关于 SIM 卡被取出并被重新利用的案例（包括被获取后产生巨额数据费用）经常见诸媒体。SIM 卡克隆攻击还可能允许攻击者冒充嵌入式系统，从而以受信任系统的身份发送和接收信息。
