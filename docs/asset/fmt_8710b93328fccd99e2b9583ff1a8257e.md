
## 更新

然后，你对自行车的位置进行新的观测或测量。由于你的视线模糊，这个测量是不完美的。卡尔曼滤波将你的预测与这个新的、带噪声的测量相结合，对自行车的速度和位置给出一个新的且改进的推测。它通过权衡预测和测量的置信度来实现。如果你的预测通常是可靠，它会更信任预测；如果测量通常是准确的，它会更多地依赖测量。

卡尔曼滤波的妙之处在于它如何平衡这两者（预测和测量）来调整它的推测。随着时间的推移，随着它获得更多信息，它将越来越擅长预测它正在跟踪的任何物体的状态。这就像逐渐调整眼镜以更清楚地看到自行车，帮助你对它的速度做出更准确的推测，即使测量并不完美。

闷湿指数衡量人类感知热度的程度的指标。它旨在表达温度和湿度的综合影响如何感知。它相当于温暖环境下的风寒指数（Wind Chill Factor）。

计算该指数的公式只需要两个输入：相对湿度和温度，如下所示：

![](img/eq-1.jpg)

从不随时间变化的函数中计算新信息是进行传感器融合最直接的方法。然而，简单并不意味着容易；来自多个源的数据必须同时可用且不能损坏。

一旦我们从每个房间获得舒适指数，就是时候生成建筑层面的舒适评分了。我们可能会倾向于对所有房间的室内空气质量指数（IAQI）取平均值并输出。然而，我们需要考虑建筑级评分的目标，即向利益相关者实时告知避难所的舒适。舒适度基于人类感知。假设该得分等同于一项调查的结果，让所有客人在 0 到 5 之间对其舒适度进行评分。我们必须给人数较大的房间更大的权重，以便在公式中反映这一点。所有人共享的公共区域也是如此。舒适的公共区域也会影响整个人群的感知。我们将添加一个因子，将其乘以每个房间的闷湿指数。以下公式将计算该因子：

`Fn = G / R`

其中 `G` 是居住在该房间的客人人数，`R` 是该避难所的平均房间大小。

例如，在一个平均房间大小为 4 的避难所中，一个六人的房间权重为 `6/4 = 1.5`。同一避难所内一个四人的空间权重为 `4/4 = 1`。同一避难所内一个双人的房间权重为 `2/4 = 0.5`。

这三个卧室的舒适指数（假设第一个房间得分为 15 分，第二个为 23 分，第三个为 40 分）为：

`((1.5 x 15) + (1 x 23) + (0.5 x 40))/3 = 21.8`

## 商业建筑中的温度剖面分析

### 问题定义

一家最近翻修的商业建筑所有者希望在实施新的暖、通风和空调 (`HVAC`) 系统之前，为每个楼创建一个温度剖面。他们需要详细了解建筑每个楼的温度分布来实现这一目标。该项目的 `HVAC` 设计师邀请您的专业知识来安装临时无线传感器网络。这些传感器应该帮助捕捉全面的温度剖面，显示楼图上的温度分布以及其在一天中随时间的变化率。

鉴于这是一个临时设置，在部署传感器网络时保持成本效益至关重要。主要的挑战是在不安装过数量传感器的情况下，为每层楼创建一个具有代表性的温度剖面。传感器的数量及其在楼图中的位置必须仔细考虑。一方面，我们不需要在每个角落和缝隙都放置传感器，因为传感器融合允许我们推断未测量区域的数据。另一方面，传感器融合无法在没有输入的情况下生成数据，因此在每个被剖析的空间中，至少必须有一个或两个传感器捕捉温度变化。

下图说明了该用例中正在开发的概念：在位置的不同区域放置多个传感器，以及一个生成推断读数的传感器融合模块 `Block`：

![](img/figure_6.8.png)

图 6.8：概念图（温度剖面分析）

### 解决方案

解决方案涉及安装一个无线传感器网络，捕捉每个楼的温度数据。为每个楼层创建独立设置有两个优点。第一个是传感器融合算法将更简单，因为它不需要处理和管理来自不同楼层的数据。通常，空气处理单元独立控制每个楼层，因此每个楼层一个温度剖面是有意义的。第二个原因是，低功耗传感器网络难以穿过厚实的混凝土板。每楼层的独立设置消除了这个问题。一旦我们有了某楼层的设置，就可以根据需要在许多楼层上复制。每个温度传感器将战略性地放置，代表一个温度区域。例如，一个传感器将放在窗边，另一个放在厨房，另一个放在入口。

传感器融合解决方案的分析部分使用卡尔曼滤波（`Kalman filter`）来估计每个区域的实际温度变化率。

### 数据采集

获取同一楼层的多次读数带来了一个有趣的挑战，即保持所有设备同步到同一时间戳。微控制器没有用于精确长时间计时的专用实时时钟 (`RTC`)；相反，它们有计时器。这些计时器计算来自 `MCU` 的机器周期数并推断一秒的长度。问题在于这充其只是一个近似；时间经常会偏移，因为微控制器正在使用其核心执行其他任务。每个微控制器都添加了一个名为 `RTC` 的专用时钟作为外设来解决这个问题。实时时钟使用专用晶体以高精度测量时间的流逝，并且通常带有集成电池，即使在微控制器重位或关闭时也能跟踪时间。一旦安装了 `RTCs`，您需要确保所有 `RTCs` 具有的时间和日期。为了实现这一点，其中一个传感器每分钟广播一次时间戳。其余传感器将根据该时间戳更新它们的 `RTC`。

每个传感器将其原始读数和时间戳存储在 `SD 卡` 上，以便在温度剖面完成后进行分析。训练集由来自建筑楼层六个不同区域的 1008 小时的读数。参考下图：

## 处理

在此用例中，我们将使用卡尔曼滤波来计算测量区域的真实温度（记住传感器是有噪声的）和温度变化率。温度变化率高的区域无法容易保持温度。相反，温度变化率低的区域表明该空间温度不会剧烈波动。分析并不试图解释为什么会这样；它只是显示了这种情况正在发生。更深入的热力学分析（这超出了本书的范围）可能会揭示附近的窗户、隔热、地板材料或空间形状可能导致温度波动的根本原因。

传感器融合算法的工作原理如下：

1. 我们使用多输入卡尔曼滤波器将每个传感器读取值与其相邻读取值结合起来。这种方法的的原理是对每个读取值进行一次预测，并根据参与聚合的传感器数量进行相应次数的修正。这样，每个传感器都独立贡献以计算真实的温度状态。图 6.10 显示了原始读取值。输出是一个代表给定空间修正温度的单一时间序列。我们将该时间序列输入到下一步。参考下图：

![](img/figure_6.10.png)

图 6.10：多传感器输入（温度分析）

2. 使用上一步的输出，我们通过确定温度随时间变化的导数来计算温度变化率。这是通过计算当前温度与预测温度之间的差，并除以这两个状态之间的时间间隔来实现。该过程使用了卡尔曼滤波器，其中状态转移矩阵包含了将变化率预测转换为当前状态的微分方程，然后使用最新的测量值进行修正。图 6.11 展示了第一阶段融合（融合 1）的输出及其导数（融合 2）。导数的物理含义是房间保持温度的能力。工程师利用这些信息来设计 HVAC（暖空调）设备并进行建筑改进。

陀螺仪读取值的主要用途之一是确定无人机的姿态，即空间中任何时刻的方向。准确的姿态信息对于稳定飞行和有效操控至关重要。然而，设计团队在测试阶段遇到了巨大的挑战。他们观察到陀螺仪的角度读取值在飞行过程中随时间漂移。随着飞行的进行，漂移变得越来越严重，最终导致读取值不可靠，无人机无法使用。

### 解决方案

团队正在探索一种传感器融合解决方案来解决角度漂移问题。传感器融合是一种结合多个传感器数据以提高整个系统准确性的方法。在这种情况下，建议的解决方案涉及使用加速度计读数来修正陀螺仪数据中的漂移。通过将加速度计数据与陀螺仪读数相结合，团队旨在对无人机的俯仰角（pitch）和横滚角（roll）实现更稳定、准确的测量。这种修正对于确保无人机的可靠性能和运行稳定性至关重要。

惯性测量单元（IMU）的读数将被发送到运行 `Kalman filter` 的微控制器，该滤波器将根据一组加速度计的实时数据修正陀螺仪读数。输出将是指示实际 `Roll` 和 `Pitch` 角的修正后信号。该信号将发送到无人机的中央控制器。
