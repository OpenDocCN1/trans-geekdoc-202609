### 答案 111-220

#### 第 111 题
一家中等规模的公司遭受了数据泄露。调查显示，来自竞争竞争对手的攻击者利用配置不当的防火墙，获得了对公司数据库的未经授权访问。根据执行者的属性，如何描述这一威胁执行者最为准确？

- (A) 利用物理访问的内部执行者
- (B) 滥用权限的内部执行者
- (C) 使用社会工程学的外部执行者
- (D) 利用技术漏洞的外部执行者

解析 111. 正确答案：D. 利用技术漏洞的外部执行者。攻击者来自受害者组织外部（一家竞争对手），并利用技术问题（防火墙配置不当）获得访问。这将其归类为利用技术漏洞的外部执行者。

选项 A 错误。攻击者来自竞争对手公司，并未在受害者组织内部利用物理访问。因此，该描述与场景不符。

选项 B 错误。场景中没有提到任何内部执行者或滥用权限的行为。相反，它描述的是一个来自竞争对手的外部攻击者。

选项 C 错误。虽然攻击者是外部的，但场景并未描述任何使用社会工程学的情况。相反，攻击者利用了技术漏洞（防火墙配置不当）。

#### 第 112 题
某中等规模公司的财务官（CFO）Sophia 接到一个自称来自 IT 部门的人的电话。通话者要求她提供关键系统更新的登录详细信息。Sophia 怀疑有异，挂断了电话并联系了 IT 部门，该部门确认没有打过此类电话。Sophia 可能经历了哪种类型的攻击？

- (A) 语音钓鱼 (Vishing)
- (B) 网络钓鱼 (Phishing)
- (C) SQL 注入
- (D) 跨站伪造 (CSRF)

解析 112. 正确答案：A. 语音钓鱼。语音钓鱼是一种诈骗者利用电话误导个人披露个人信息或凭据的攻击。

选项 B 错误。网络钓鱼通常是尝试通过欺骗性电子邮件获取敏感信息，而不是语音电话。

选项 C 错误。SQL 注入是一种试图在数据库中执行恶意语句的攻击。它与电话无关。

选项 D 错误。跨站伪造 (CSRF) 是一种攻击类型，攻击者欺骗受害者提交恶意请求。

#### 第 113 题
在事件响应期间，IT 团队发现了一种恶意软件，该软件会收集有关军事项目的信息并将数据发送到位于另一个国家的服务器。哪种类型的威胁执行者可能参与了此类网络间谍活动？

- (A) 不满的员工
- (B) 国家级 (Nation-state)
- (C) 钓鱼攻击者 (Phishing artist)
- (D) 黑客主义者 (Hacktivist)

解析 113. 正确答案：B. 国家级。专门针对军事项目的恶意软件是网络间谍活动的特征，这是国家级常用的战术。他们有动机收集情报并可能获得相对于他的优势。

选项 A 错误。虽然不满的员工可能有损害公司的动机，但他们的攻击通常更具针对性，且可能比仅仅篡改网站更具破坏性。

选项 C 错误。钓鱼攻击者侧重于欺骗个人泄露个人或财务信息。他们通常没有兴趣或资源来收集特定的军事数据。

选项 D 错误。黑客主义者通常受意识形态、环境或政治事业的驱动。简单的网站篡改，尤其是带有幽默表情包的篡改，并不是他们活动的典型特征。

#### 第 114 题
某公司的网站被临时用一个幽默表情包篡改了，但没有敏感数据被盗取，也没有造成重大损害。攻击者留下了一条信息，炫耀他们成功的攻击。哪种类型的威胁执行者最可能是这种攻击的者？

- (A) 内部威胁
- (B) 持续性威胁 (APT)
- (C) 技术不足攻击者 (Unskilled attacker)
- (D) 国家级

解析 114. 正确答案：C. 技术不足攻击者。通常被称为“脚本小子”（script kiddies），这类人往往只是为了炫耀或娱乐而进行简单的篡改。

选项 A 错误。内部威胁是指组织内部的人员。

选项 B 错误。持续性威胁 (APT) 通常涉及高度组织性和隐蔽性的攻击。

选项 D 错误。国家级执行者通常具有更复杂的战略目标。

#### 第 115 题
一家新公司最近发布了脸识别技术。一位研究人员在没有恶意意图的情况下发现了该技术的漏洞。该研究人员这种行为的主要动机是什么？

- (A) 反对脸识别的理念
- (B) 通过勒索公司获取利益
- (C) 出于对安全的考虑
- (D) 旨在损害公司声誉

解析 115. 正确答案：C. 出于对安全的考虑。研究人员在没有恶意意图的情况下负责任地披露漏洞，通常是为了改进安全。

选项 A 错误。研究人员并非反对脸识别技术，而是发现了漏洞。

选项 B 错误。没有证据表明研究人员试图勒索公司。相反，他们负责任地披露。

选项 D 错误。研究人员并非为了损害公司声誉，而是为了协助改进安全。

#### 第 116 题
网络管理员 Mike 发现一个设备直接连接到位于机房的公司主交换机。该设备正试图捕获网络流量。这种未知设备可能是哪种攻击？

- (A) 非法访问点
- (B) VLAN 跳跃
- (C) 端口镜像
- (D) ARP 注入

解析 116. 正确答案：C. 端口镜像。端口镜像是交换机上的一种方法，将一个端口（或整个 VLAN）看到的网络包发送到另一个交换端口的网络监控连接。攻击者可以使用这种方法捕获并分析流量，而不干扰原始数据包的流。

选项 A 错误。非法访问点是在未经网络管理员授权的情况下安装在网络上的无线访问点。场景描述的是有线连接。

选项 B 错误。VLAN 跳跃是访问通常无法访问的不同 VLAN 数据的方法。场景重点是捕获流量，而不是跨 VLAN。

选项 D 错误。ARP 注入是攻击者向本地网络发送虚假 ARP 信息的攻击类型。这与连接到交换机的未知设备没有直接相关。

#### 第 117 题
XYZ Corp 的员工 Alex 在公司停车场发现了一个未知的 U 盘。出于好奇，Alex 将该设备插入了他的工作站。几乎立即，他的杀毒软件检测到尝试执行恶意软件。Alex 可能遭遇了哪种攻击？

- (A) 间人攻击
- (B) 恶意孪生 (Evil Twin)
- (C) 鱼叉式网络钓鱼
- (D) U 盘投放攻击

解析 117. 正确答案：D. U 盘投放攻击。U 盘投放攻击涉及将受感染了恶意软件的可移动设备（如 U 盘）遗留在可以发现的地方，供无意的人发现并使用。一旦设备被插入接入计算机后，它可能会执行 USB 恶意软件或脚本。

**选项 A 是错误的。** 中间攻击（Man-in-the-Middle Attack）涉及攻击者在双方未察觉的情况下，秘密地拦截并可能篡改两个实体之间的通信。这与 USB 设备无关。
