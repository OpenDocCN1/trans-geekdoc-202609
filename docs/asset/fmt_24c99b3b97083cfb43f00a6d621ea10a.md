密钥恢复和控制是一个必须解决的问题。一种基本的恢复和控制方法是 $n$ 中的 $m$ 控制。这种方法旨在确保没有人拥有完全控制权；它与双重控制密切相关。如果 $n$ 个管理员具有执行某项过程的权限，必须由其中 $m$ 人进行身份验证；$m$ 中的 $n$ 控制要求物理现场。这里有一个例子：假设有四个人可以访问存档服务器，并且必须有两人在场才能完成访问。在这种情况下，$m = 2$，$n = 4$。这将确保没有个人可以破坏安全系统或获得访问权限。

## PKI 世界中的信任

信任在小型组织中不是问题，但在大型组织内部以及与客户、第三方之间进行通信需要开发一套可行的信任模型。组织通常遵循几种著名的信任模型，例如单一权威信任、分层信任或信任网。

每种模型都有其优缺点，作为 CASP，你可能会被要求为组织推荐一种方法。你应该记住，虽然单一权威模型简单，但并不适用于大型组织；如果它由公司管理，与其他实体之间的交叉认证可能会成为问题。分层模型通常由商业实体提供。虽然它要稳健得多，但会有持续的费用。

最后是信任网，它是所有模型中最不复杂的。它可能对于个人或小组来说效果良好，但它的信任级别较低。你会为你的公司选择哪种模型？

## 加密解决方案的实现

本章节是否让你思考了密码学的各种使用方法，以及它对安全专业人员有多大的价值？我希望是这样的。现在真正的问题是，既然你已经掌握了一些加密解决方案，加密强度应该是多大，你可能会在哪些地方应用这些加密解决方案。

**磁盘加密** 磁盘加密可以使用硬件或软件对整个硬盘或卷进行加密。这种技术在今天至关重要。只要想一下个人在移动设备和平板电脑上存储了多少敏感信息。这些物品很容易丢失或被盗。常见的磁盘加密产品包括 BitLocker 和 AxCrypt。

**块加密** 块加密以固定大小的位组来保护数据。我们之前讨论过的一个块加密示例是 DES ECB。DES 以 64 字节为块对数据进行加密。

**文件加密** 你不需要加密整个硬盘或卷。在某些情况下，你可能只需要加密特定文件。可用于文件加密的产品示例包括 AxCrypt 和 PGP。

**记录加密** 数据库有一个共同的攻击面。如果你在数据库中存储敏感信息，你可能想加密整个数据库，或者只加密特定的记录。例如，在医疗机构中，你可能想保护持有社会安全号码或其他个人信息的记录，只让医疗 ID 和医疗记录开放给医院工作人员。

**端口加密** 某些服务比其他服务更安全。例如，Telnet（端口 23 TCP）以明文发送数据，而 Secure Shell（SSH，端口 22）则使用加密。另一个例子是 HTTP，因为 80 端口是明文，而 HTTPS 使用的是 443 端口。

这些示例说明密码学是安全专业人员可以使用最有价值的工具之一，但必须考虑强度、性能和可用性之间的权衡。每种加密解决方案都有优点和局限性。组织必须进行适当的风险评估，以确定威胁程度以及每个资产所需的保护程度。这种评估对于决定所使用的技术类型具有重要意义。数据是仅在几分钟内有效的吗，例如买卖股票的订单？尚未开始生产的下一代战斗机的机密数据吗？数据存储在何处？它对其他人有多价值？它将保持价值的时间是多久？

即使信息不需要加密解决方案来提供隐私，你可能仍然需要可以帮助保护信息的控制措施。其中一种技术就是*数字权利管理 (DRM)*。DRM 是一整套旨在保护数字内容的技术。例如，你可能在自己的设备上阅读这本书的副本，这并不意味着出版商想向你的百个好朋友提供免费副本！这正是 DRM 的初衷：它帮助防止在线侵权，并帮助版权所有者保持对信息的控制。

接下来，你需要考虑在何处构建防护。密码学可以用于许多不同情况以构建真正的深层防御。如果你参考 TCP/IP 模型来考虑密码学，你可以看到加密解决方案的应用范围，从应用层一直到物理帧。让我们从 TCP/IP 栈的顶部开始，逐层向下推导，重点介绍几种加密解决方案，然后查看隐身术的概念。

## 应用层加密

以下应用层协议只是可以用于增加机密性、完整性或不可否赖性的少数示例：

- **安全外壳 (SSH)** SSH 是一种提供安全远程访问的 Internet 应用程序。它是 FTP、Telnet 和伯克利“r”工具的替代品。SSH 默认使用 TCP 端口 22。
- **安全超文本传输协议 (S-HTTP)** S-HTTP 是 HTTP 的超集，旨在用于提供与网络服务器的安全通信。S-HTTP 是一种无连接协议，旨在安全地发送单条消息。
- **完美隐私 (PGP)** PGP 由 Phil Zimmermann 于 1991 年开发，用于提供隐私和身份验证。随着时间的推移，它演变成了 OpenPGP 和 GnuPG 等开放标准。PGP 构建了一个信任网，该网络随着用户签名并发布其密钥而发展。PGP 的目标是成为“普通人的加密”。HushMail 和 Veridis 等流行程序都是基于 PGP 的。
- **GNU 隐私守护者** 免费听起来不错吗？如果你和我们很多人一样，答案是肯定的，这时 GNU 隐私守护者 (GPG) 就登场了。它是 PGP 的授权免费版本。其理念是提供一个所有人都可以使用的 PGP 版本。与 PGP 类似，GPG 使用混合加密，并结合了对称和非对称加密的优点。对称部分用于加密解密，非对称部分用于密钥交换。
- **S/MIME** 对于那些不愿使用 PGP 的人，电子邮件安全还有另一个选择。该解决方案是 S/MIME（安全/多用途互联网邮件扩展）。S/MIME 是 MIME 数据公钥加密和签名的标准。S/MIME 提供两个基本服务：数字签名和消息加密。S/MIME 是保护电子邮件的流行解决方案，并内置在大多数电子邮件软件程序中，如 Microsoft Outlook 和 Thunderbird。
- **安全远程访问** 各种应用程序可用于安全远程访问，如 SSH、远程桌面协议 (RDP) 和虚拟桌面协议 (VDP)。

## 密码身份验证协议 (PAP)

我在此包含了 PAP，但不应该使用它。它充其量仅仅是微不足道的。PAP 是不安全的，用户名和密码是以明文传输的。

## 挑战握手认证协议 (CHAP)

CHAP 是比 PAP 更合适的选择，因为它向客户端发送了一个仅使用一次的随机值。客户端和服务器都知道预定义的秘密密码。客户端使用该随机值、随机数（nonce）和秘密密码，并计算出一个单向哈希值。CHAP 的握手过程如下：

- a. 用户从客户端向服务器发送登录请求。
- b. 服务器向客户端发回挑战（challenge）。
- c. 挑战被加密后发回服务器。
- d. 服务器比较来自客户端的值，并且如果信息匹配，则授予授权。

## 点对点隧道协议 (PPTP)

PPTP 由两个部分组成：维护虚拟连接的传输层和确保机密性的加密层。它可以以 40 位或 128 位的长度运行。

## 隐写术 (Steganography)

隐写术是隐藏写作的科学。它与密码学的相似之处在于，尽管两者都旨在保护信息，但实现这一目标的方式不同。通过密码学，你可以看到信息，但不应该能够识别出那是什么。例如，你可能会嗅探客户端和服务器之间的 SSL 连接，但数据将是杂乱无章且没有太大价值的。然而，通过隐写术，数据是隐藏的。这就是为什么隐写术被描述为将信息隐藏在消息、图像或文件等容器中的实践。

隐写术需要两个元素：容器和要隐藏的数据。容器是你嵌入数据的介质。选择合适的容器是一个重要的决定，因为它是决定隐写技术有效性的很大部分。因此，发送者可能会使用 CASP 标志的图像文件，并通过更改每个数据字节的最低有效位（LSB）来调整颜色。这种变化是如此微妙，以至于不是专门刻意寻找它的人不太可能注意到。使用图形是隐藏数据最流行的方法之一。一些常见的容器有：

- 图像
- 音频文件
- 视频文件
- Office 文档

显然，音频和视频文件比大多数图像提供了更多的存储空间，仅仅因为它们的尺寸可以大得多。800 MB 的视频文件并不罕见。寻找或恢复隐写数据被称为隐写分析（steganalysis）。一些常见的隐写分析技术包括以下：

### 仅隐写 (Stego-only)

仅有隐写内容供分析。

### 已知隐写 (Known-stego)

原始内容和隐写内容均供审查。

### 已知消息 (Known-message)

隐藏的消息和对应的隐写图像是已知的。

### 禁用或主动分析 (Disabling or Active Analysis)

在通信过程中，主动攻击者会更改覆盖层。

为了让事情更加困难，使用隐写术的人可能不仅隐藏数据，还对其进行加密。在这些情况下，恢复数据可能非常困难，因为你不仅必须找到数据，还要破解加密算法。

## 核心能力

能够描述对于给定的解决方案哪种加密解决方案是。加密解决方案大致分为对称加密、非对称加密、混合加密和哈希。每种方案提供了特定的解决方案，如隐私性、认证、完整性和不可否认性。

能够描述 PKI（公钥基础设施）的基本操作并理解高级 PKI 概念。PKI 允许互不相知的双方在不安全的公共网络上进行通信。此类通信可以用于安全、私密地交换数据或用于电子商务。PKI 系统利用公钥和私钥。密钥通过受信任的证书权威进行共享。

了解应用于 PKI 时，通配符（wildcard）等术语的含义。通配符证书允许购买者在一个域名上保护无限数量的子域名证书。优点是你只需要购买和维护一个证书。但缺点是你在多个网站和私有服务器上使用了同一个证书和私钥。

能够描述传输加密。传输加密是 IPSec 可以运行的两种模式之一。当使用 IPSec 传输加密时，只有每个 IP 包的数据部分或负载（payload）被加密。这使得 IP 头部保持不变并以明文发送。

能够描述数字签名。数字签名是使用发送者私钥加密的哈希值。它用于认证和完整性校验。

能够描述哈希。哈希指的是一类算法，这些算法在提供完整性和认证方面非常有用。哈希算法通过获取变长度的数据并将其压缩成称为哈希值的固定长度值来工作。

能够描述代码签名。代码签名是对可执行文件和脚本进行数字签名的过程，以确认软件作者。代码签名还保证代码在通过哈希签名后未被更改或损坏。

了解不可否认性（non-repudiation）的工作原理。不可否认性是验证身份证明的能力。它用于确保数据发送者获得送达证明，并确保接收者确认发送者的身份。

能够定义伪随机数生成的概念。伪随机数生成器是生成近似随机数属性序列的算法。

能够解释完全正向安全性（perfect forward secrecy）。完全正向安全性基于这样一个概念：单个密钥的泄露将允许攻击者仅访问受单个密钥保护的数据。

了解隐写术（steganography）的目的和用途。隐写术是一种隐藏写作的形式。隐写术允许用户在容器内部隐藏信息。常见的容器包括图像、音乐文件、视频甚至微软 Office 文档。

**定义术语**混淆（confusion）和扩散（diffusion）。混淆发生在明文与密钥之间的关系极其复杂，以至于攻击者无法通过更改明文来确定密钥。扩散是指当明文的变化导致分布在整个密文中的多处变化的过程。
