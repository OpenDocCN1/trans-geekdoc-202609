## Bootstrap 中的表格示例

用于在 Bootstrap 中创建表格的一些类有 `.table`、`.table-responsive`、`.table-bordered`、`.table-striped`、`.table-hover` 等。

### .table-responsive

用于创建响应式表格。表格在小设备上会水平滚动。

### .table-striped

用于为表格添加斑马纹。

### .table-bordered

用于为表格添加边框。

### .table-hover

用于在表格行上启用悬停状态，即鼠标悬停时会自动出现灰色背景。

### .table-condensed

用于通过将内边距减半使表格更紧凑。
