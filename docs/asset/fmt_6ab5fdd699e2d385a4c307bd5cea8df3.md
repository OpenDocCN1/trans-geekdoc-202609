### 27.3.2 关键量子原理

#### 27.3.2.1 量子比特

量子信息的单位是“量子比特”，它描述了最简单的量子系统状态（如光子的偏振态）中可以存储的量子信息量。`qubit` 是二维复向量中的单位向量 [\[12\]](#c27.xhtml#ref12)。

#### 27.3.2.2 Qsup

量子力学的基石是 `Qsup` 概念。根据这一理论，任何两个（或多个）量子态都可以叠加来创建另一个有效的量子态，这与传统物理学中波的方式非常。另一方面，每个量子态也可以被看作两个或多个不同状态的组合。从数学上说，它指的是薛罗谔方程 \[5, 7\] 解的特性。解的线性组合也是解，因为薛罗谔方程具有线性形式。

量子系统波特性的物理观测现象的一个例子是双缝实验中电子束的干涉峰。这种模式与经典波衍射获得的模式非常相似。

量子 \[5, 6\]叠加原理是物体所有可能状态之和。在 `QC` 的情况下，我们处理与 `qubit` 关联的状态，它可以是由正交向量 `|0⟩ = ( 1 0 )` 和 `|1⟩ = ( 0 1 )` 跨的二维向量空间中的任何单位向量。`qubit` 的一般状态由：`|ψ⟩ = α|0⟩ + β|1⟩` ，其中 `∝2+ β2 = 1`。

让我们考虑 0 和 1 对应于经典计算中熟悉的 0 位和 1 位。

这里 `|0>` 是狄拉克符号，表示通过测量转换为经典逻辑时将始终给出结果 0 的量子态。同样，`|1>` 是始终会转换为 1 的态。

我们发现单个 `qubit` 可以以这两个位（即 0 和 1）的叠加态形式存在，在信息处理期间，每个位具有特定的振幅 \\[7\]](#c27.xhtml#ref7)。

对于 `qubit` 0 和 1，测量概率既不可能是 0.0 也可能是 1.0，且多次测量永远不会产生相同的结果。

量子隐形传是一种在两个系统之间传输量子信息的方法。包含在叠加态中的信息通过经典通信和链路传输到另一个位置。尽管这具有吸引力，但不应被误认为是传输或复制宏观对象的手段。为了描述量子传传的过程，我们假设发送端（`Tx`）将量子比特 `a` 的完整通用态传输给接收端（`Rx`）。

首先，`Tx`和`Rx`共享一对纠缠的 `bc` 量子比特，其中 `Tx` 拥有纠缠对中的 `b`，`Rx` 拥有 `c`。然后 `Tx` 共同测量 `ab`，产生两个经典比特，并通过经典通道传输到 `Rx`。测量破坏了 `Tx` 上的两个量子比特，但由于 `b` 和 `c` 之间的纠缠，现在量子比特 `c` 有关于 `a` 的信息。`Rx` 可以根据接收到的两个经典比特对 `c` 进行变换，从而完全重建 `a` 状态 [\[7\]](#c27.xhtml#ref7)。

研究人员已首次成功对粒子实现了量子隐形传。这一成就可能导致量子计算（QC）和安全通信的进步。

在量子隐形传中，粒子量子态的信息从一个位置传输到另一个位置，而无需物理上移动粒子。量子态是描述粒子的所有信息的集合。

研究人员能够在不破坏态的情况下，将粒子的量子态传越整个房间。这项研究是开发量子互联网的重要一步，量子互联网将比现在的互联网安全得多。图 27.3 显示了量子密钥分模型。

## 27.4 量子军事应用 [23, 25]

人类活动的许多方面都可能受到量子技术的巨大影响。国防工业就是一个很好的例子。当代战争的所有方面都可能受到量子的影响。第二次革命 Q 战略是武器的变革。量子战争（`QW`）是在战斗中使用量子技术。它引入了新的学说、场景和伦理，同时影响了所有领域的情报、安全和防御能力。以下材料介绍了量子技术在几个方面的军事、安全和太空领域的潜在应用；军事应用是对公众开放的 [\[3\]](#c27.xhtml#ref3)。

量子计算（QC）有三个关键组成部分：量子比特、量子处理器和量子算法。量子比特是量子信息的 Basic 单位。它是一个二态量子系统，可以代表 0、1 或任何其他二态系统。量子处理器是操纵量子比特的物理设备。量子算法是一组指令，告诉量子处理器应该如何处理量子比特。

### 嘈噪声中尺度量子计算

人们常说 `Qcom`（量子计算机）比经典计算机更快速、更强大。但一项新研究发现，在某些情况下，`Qcom` 的速度可能比经典计算机慢。这项由布里斯托大学的量子计算专家领导的研究发现，当使用 `Qcom` 解决需要大量数据的问题时，它们 de 运行速度可能比经典计算机慢。研究人员表示，这是因为 `Qcom` 必须将所有数据存储在它们的内存中，而内存是有噪声的。相比之下，经典计算机可以将数据存储在独立的内存单元中，这样速度更快。

这些发现可能对 `Qcom` 的发展产生影响，因为它们表明 `Qcom` 可能无法做到。

容错量子计算是一种量子计算，即使在存在错误或故障的情况下也能保持其准确性和功能。这是通过使用冗余和纠错码来保护系统的量子态来实现的。容错量子计算对于需要可靠量子计算的应用至关重要，例如安全通信和密码学。图 27.4 显示了量子战争的表示形式，图 27.5 显示了各国对 `Qcom` 的支出。

## 27.5 量子加密的应用 [20, 21]

#### 银行业：保护敏感客户信息 [15]

银部门的数据已通过 ID Quantique (IDQ) 的量子通信成功地了保护 [8, 9]。安全对于银行业至关重要，因为银行必须在保障敏感个人客户数据的同时，确保实时交易数据的可用性。IDQ 成功使用量子随机数生成器（`QRNG`）为安全应用和加密活动生成密钥，包括身份验证、数字签名和安全访问控制。

#### 金融行业：保护关键业务数据 [16]

银行业先进的安全网络采用了量子通信。使用 IDQ 的 `Cerberis QKD` 系统，英国的 Colt Technologies and Services Group 与 IDQ 合作，为瑞士日内瓦的公司和金融机构提供了安全的关键骨干连接。客户对加密密钥和关键任务数据具有完全控制权，而 Colt 负责管理网络。客户数据通过独立线路传输，而许多客户的量子密钥在单根光纤上进行复用。该方法包含了密钥和网络冗余。

#### 信用卡行业：保护客户信用卡信息。

信用卡安全耗资巨昂。每年信用卡被盗每年给全球造成的损失高达 140 亿美元，其中美国占了一半。想一下 2013 年 Target 的数据泄露事件。这次数据泄露涉及超过 4000 万份信用卡信息以及客户姓名和地址，成本超过了 2.5 亿美元。

信用卡可以通过量子通信进行加密和保护以免受此类攻击。基于量子计算的新信用卡加密研究可能会使磁条和 EMV（欧洲芯片、万事达、维萨卡）信用卡技术过时，从而解决这一问题。研究人员已将 `Qcryp` 作为一种完全不可破解的信用卡方法提出。

#### 彩票和在线游戏 [17]

必须确保绝对的随机性，因为在线游戏和彩票都使用随机数来保证中奖概率的公平。通过其 `QRNG`，IDQ 已成功地为全球各种企业提供真随机数生成。这种 `QRNG` 产生的随机数是不可预测且无法复制的。瑞士彩票运营商 Loterie Romande 使用 `Quantis QRNG` 用于其开奖活动，是使用随机数生成器的企业之一。顶级游戏整合商之一是奥地利的 Novomatic。

#### 其他应用 [18]

私营部门的金融信息以及国家安全信息已被 `Qcryp` 保护。其安全性已得到检查和确认。在这里，我们讨论了 `Qcryp` 的近期和未来的用途。

物理层使用 `Qcryp` 进行加密利用了量子力学的特性。然而，后量子和抗量子加密的努力仍在创建依赖于数学难题的加密技术，而 `Qcom` 并不擅长解决这些问题。

#### 极安全投票

鉴于发达国家和发展中国家普遍存在的政治动荡，增加投票的安全性是必要的。瑞士自 2007 年以来一直在 `Qcryp` 进行联邦和地方选举的安全投票。在日内瓦的一个中央计票点，投票已通过加密 [1]。然后使用专用光纤链路将结果发送到远程数据存储。数据传输中最脆弱的部分（即选票从计票站到中央存储的过程中）是不可破解的。投票结果受 `Qcryp` 保护。由于几个国家选举舞的增加，这项技术将迅速普及 [9]。

#### 太空安全通信

Quintessence Labs 正在为 NASA 开发一个项目，以满足卫星与宇航员之间安全通信的需求。该项目的目标是开发一种无论对手拥有什么工具或信息都能确保通信安全的协议。项目还包含了对“静态”数据和传输中数据的保护要求。从长期来看，这将提高宇航员在轨道上的安全性，理想情况下减少对微小速度提升之外进一步改进的需求 [9, 10]。

#### 智能电网

有人认为美国电网是网络攻击最暴露的目标之一。事实上，美国一些大型公司正“不断”遭受网络敌对的攻击。通过公共数据网络调节智能电网，员工可以使用小型加密设备发送完全安全的信号。为了提高效率，智能电网对于平衡供需是必要的。此外，在采取安全措施时，它们比传统的电网安全得多 [4]。
