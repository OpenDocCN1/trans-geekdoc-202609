
# 问题 49。
某中型公司发现其移动设备经常被未经访问，导致敏感数据泄露。公司决定实施新的安全策略以保护数据。以下哪种措施最能有效防止这种情况？

- (A) 强制使用复杂的磁盘加密
- (B) 实施移动设备管理（MDM）
- (C) 增加设备的物理强度
- (D) 限制设备访问频率

## 解释 49。
正确答案：A. 强制使用复杂的磁盘加密。强制使用复杂的磁盘加密可以确保即使设备丢失或被未经访问，敏感数据也无法被读取，这是防止数据泄露最有效的措施之一。

**选项 B 错误。** 虽然移动设备管理（MDM）可以帮助管理设备并实施安全策略，但在防止设备被盗取后数据泄露方面，不如加密直接。

**选项 C 错误。** 增加设备物理强度可以防止物理损坏，但无法防止设备在被盗后后数据被泄露。

**选项 D 错误。** 限制设备访问频率可以解决流量问题，但无法防止设备被非法访问后的数据泄露。

# 问题 50。
一家公司面临着由于员工使用公共 Wi-Fi 导致的数据被截获风险。公司希望实施一种技术来确保数据传输的安全。以下哪种措施最合适？

- (A) 要求员工使用虚拟专用网络（VPN）
- (B) 禁用所有无线网络
- (C) 提高防火墙的强度
- (D) 使用更长的 WiFi 密码

## 解释 50。
正确答案：A. 要求员工使用虚拟专用网络（VPN）。虚拟专用网络（VPN）可以创建加密通道，确保数据在公共 Wi-Fi 上传输时不被第三方截获或窃听。

**选项 B 错误。** 禁用 Wi-Fi 会导致员工无法连接网络，在现代办公环境中通常不是可行的解决方案。

**选项 C 错误。** 提高防火墙强度可以防止未经授权的访问，但无法防止在无线传输过程中数据被截获。

**选项 D 错误。** 使用更长的 WiFi 密码可以增加破解难度，但无法保护数据传输过程中的安全性。

公司的交换机。以下哪些措施最有效地加固这些网络交换机以免受可能的攻击？

- (A) 为所有连接的设备分配静态 IP 地址
- (B) 为交换机访问实施强密码策略
- (C) 升级交换机以支持 10Gbps 以备未来扩展
- (D) 自定义交换机的 LED 颜色以便于识别

## 解析 53。
正确答案：B. 为交换机访问实施强密码策略。加固交换机涉及减少其对未经授权的访问和潜在滥用的脆弱性。实施强密码策略可以确保只有授权的人员才能访问和配置交换机。

**选项 A 错误。** 虽然分配静态 IP 地址可能有助于网络管理，但它并从本质上无法加固交换机免受潜在攻击。

**选项 C 错误。** 升级交换机的速度能力（例如支持 10Gbps）是性能增强，与加固或安全没有直接关系。

**选项 D 错误。** 自定义 LED 颜色与物理识别有关，不会提高交换机的安全状况。

# 问题 54。
你公司的一位开发者对无服务器架构的可扩展性优势感到兴奋，并使用它部署了一个新服务。然而，你发现即使在服务未使用时，该服务的账单也增加了。以下哪项可能是导致因素？

- (A) 无服务器函数被意外事件持续触发
- (B) 服务器硬件过旧
- (C) 负载均衡器配置错误
- (D) 组织缺乏内容分发网络 (CDN)

## 解析 54。
正确答案：A. 无服务器函数被意外事件持续触发。无服务器架构根据函数调用的次数和执行时间收费。如果存在意外事件（例如恶意请求或配置错误的触发器）持续调用无服务器函数，可能会导致意外之外的成本。

选项 B 错误。在无服务器架构中，服务器硬件管理的责任在于服务提供商。客户从硬件细节中被抽象出来。

选项 C 错误。负载均衡器配置错误可能会影响可用性或性能，但与无服务器部署中意外的成本激增没有直接关系。

选项 D 错误。虽然 CDN 对优化内容交付非常有价值，但它们与无服务器架构中意外之外的函数调用的成本影响没有直接关系。

**选项 A 错误。** 惩罚措施和合规后果通常列在政策或程序中，而不是指南中。

# 问题 56。
安全经理 Lisa 正在审查公司现有的政策，发现没有一份详尽的文档来概述组织在保护信息资产方面的立场、期望和承诺。Lisa 应该优先创建哪项来填补这一空白？

- (B) 信息安全策略
- (C) 可接受使用策略
- (D) 数据备份策略

正确答案：B. 信息安全策略。信息安全策略是一份基础性文档，为整个组织的信息安全提供了一个框架。它涵盖了组织在保护数据和 IT 资产方面的愿景、原则和责任。

**选项 A 错误。** 应急响应计划侧重于安全事件发生后应采取的步骤。它没有详细说明组织对信息安全的整体立场。

**选项 C 错误。** 可接受使用策略提供了关于员工应如何使用公司资源的指南，但它没有提供对组织保护信息资产承诺的全面概述。

**选项 D 错误。** 虽然数据备份策略对于数据可用恢复至关重要，但它没有传达组织对信息安全的更广泛视角和承诺。

# 问题 57。
金融科技公司 GlobalFin 开发了一个新的移动银行应用程序。为了避免任何法律纠纷，GlobalFin 在全球范围内推出该应用程序之前应该最关注以下哪些法律考量？

- (A) 确保应用程序符合全球数据隐私法
- (B) 确认配色方案符合所有国家的品牌法规
- (C) 为应用程序中使用的所有图像获取版权
- (D) 确保应用程序的名称在任何语言中都不具有冒犯性

## 解析 57。
正确答案：A. 确保应用程序符合全球数据隐私法。对于移动银行应用程序而言，确保符合全球数据隐私法至关重要。不同地区对于如何处理、存储和处理用户数据有不同的要求和法规。

选项 B 错误。虽然品牌建设和配色方案对营销很重要，但它们通常不是像数据隐私法那样的受严格法律监管的对象。

选项 C 错误。虽然获取版权很重要，但银行应用程序的首要法律关注点是数据隐私。

选项 D 错误。虽然确保应用程序名称不冒犯是一项良好的做法，但银行应用程序的主要法律关注点将是数据隐私。

# 问题 58。
在微服务架构中，每个服务应根据特定原则进行设计，以确保它执行特定任务并通过定义的接口与其他服务交互。这指的是哪种原则？

- (A) 最小权限原则
- (B) 单一职责原则
- (C) 开闭原则
- (D) 零信任模型

## 解析 58。
正确答案：B. 单一职责原则。单一职责原则规定，类或模块（在微服务背景下，即服务）只有一个更改的原因，意味着它应该有一个工作或职责。在微服务中，这确保每个服务只做好一件事，并通过接口与其他交互。

选项 A 错误。最小权限原则是确保用户或服务仅具有执行任务所需的权限而非更多。它并不是专门针对服务的设计。

选项 C 错误。开闭原则是一个设计原则，认为软件实体应对扩展开放但对修改关闭。虽然与软件设计相关，但它不是指导微服务设计的主要原则。

选项 D 错误。零信任模型是一种安全概念，无论组织内部还是外部，默认都不被信任。它不是微服务设计的特定原则。

# 问题 59。
XYZ 公司正在定义其 IT 资产的清晰角色和职责。在一次会议期间，团队讨论了对特定 IT 系统内数据负主要责任、并作为任何相关决策的主要联系人的个人。以下哪个角色最符合此描述？

- (A) 系统管理员
- (B) 数据保管员
- (C) 系统所有者
- (D) 终端

## 解析 59。
正确答案：C. 系统所有者。系统所有者（有时称为数据所有者）通常对特定 IT 系统内的数据负责。他们承担确保数据机密性、完整性和可用性的主要责任，并作为相关系统决策的主要联系人。

选项 A 错误。系统管理员负责 IT 系统的日常管理、运营和支持但通常不会对其中包含的数据做出高级决策。

**选项 B 错误。** 数据托管者（Data custodian）通常负责实施数据所有者（Data owner）定义的控制和流程。他们可能处理数据管理的实际事务，但他们通常不会对数据做出全局决策。

**选项 D 错误。** 终端用户为了工作功能利用数据或系统，但通常对数据的整体管理和保护没有决策责任。

# 问题 60。
一家拥有单一物理网络基础设施的组织希望将其财务部的流量与人力资源部的流量分开。他们不想建立完全全新的物理网络，但希望确保来自一个部门的数据包与另一个部门的混合。该组织应该实施什么？

- (A) 物理隔离网络 (Air-gapped network)
- (B) DMZ（非军事化区）
- (C) VLAN（虚拟局域网）
- (D) VPN（虚拟专用网络）

## 解释 60。
**正确答案：C. VLAN（虚拟局域网）。** VLAN 允许网络管理员在物理网络内部创建一个逻辑网络。这种逻辑划分可以隔离不同部门的流量，确保来自一个 VLAN 的数据包不会与另一个混合，从而有效地将它们隔离。

选项 A 错误。物理隔离网络是物理隔离的网络，需要建立新的物理网络。

选项 B 错误。DMZ 是私有网络和外部网络之间的缓冲区。它无助于划分内部网络内部的流量。

选项 D 错误。VPN 用于在不安全的网络上创建安全连接。它不会对单个物理网络内部的流量进行逻辑划分。

# 问题 61。
一家中型公司遭受了数据泄露。调查显示，一名来自竞争对手的攻击者利用配置不当的防火墙获取了对公司数据库的未授权访问。根据行为者的属性，如何描述该威胁行为者最为合适？

- (B) 滥用权限的内部攻击者
- (C) 使用社会工程学的外部攻击者
- (D) 利用技术漏洞的外部攻击者

解释 61. 正确答案：D. 利用技术漏洞的外部攻击者。攻击者来自受害者组织之外（竞争对手），并利用技术问题（防火墙配置错误）获取访问权限。这将其归类为利用技术漏洞的外部攻击者。

选项 A 错误。攻击者来自竞争对手公司，没有利用受害者组织内部的物理访问。因此，该描述与场景不符。

选项 B 错误。场景没有提到任何内部攻击者或滥用权限的行为。相反，它描述的是一个来自竞争对手的外部攻击者。

选项 C 错误。虽然攻击者是外部的，但场景没有描述任何使用社会工程学策略的情况。相反，攻击者利用了技术漏洞（防火墙配置错误）。

# 问题 62。
一家全球性公司在过去中经历了多次 IT 事件，包括由于自然灾害和网络攻击导致的停机。CEO 希望确保组织的 IT 基础设施能够抵御破坏性事件，或从这些事件中快速恢复。以下哪项最能概括这一需求？

- (A) 采用零信任架构 (Zero Trust Architecture)
- (B) 实施严格的密码策略
- (C) 建立强调韧性的业务连续性计划 (BCP)
- (D) 定期更新防火墙规则

解释 62. 正确答案：C. 建立强调韧性的业务连续性计划 (BCP)。

在此语境下，韧性（Resilience）是指 IT 基础设施在破坏性事件后快速恢复并继续运行的能力。专注于韧性的业务连续性计划将帮助组织准备、响应并从自然和人为事件中恢复。

**选项 A 错误。** 零信任架构强调不信任边界内外的任何用户或系统，但它没有直接解决针对破坏性事件的韧性问题。

**选项 B 错误。** 虽然密码策略对于安全至关重要，但它们并不是以确保应对破坏性事件的韧性为中心。

**选项 D 错误。** 更新防火墙规则对于阻止意外流量和潜在威胁至关重要，并不直接解决 IT 基础设施应对重大破坏性事件的韧性。

# 问题 63。
一家公司面临多次未经授权的人员进入办公室的情况。以下哪种预防性安全控制对于防止未经授权的物理访问最有效？

- (A) 为网络流量实施日志监控解决方案
- (B) 在所有出入口处安装视频监控摄像头
- (C) 为员工进行定期的安全意识培训
- (D) 为网络访问实施多身份验证系统

解释 Explanation 63. 正确答案：B. 在所有出入口处安装视频监控摄像头。在所有出入口处安装视频监控摄像头起到预防控制的作用，因为被检测和录像的风险增加，威慑了未经授权的人员尝试访问。

选项 A 错误。实施日志监控解决方案是一种检测性控制，可以提供网络活动的的洞察，但不能防止未经授权的物理访问。

选项 C 错误。进行定期的安全意识培训是一种预防措施，但其主要重点是让员工意识到安全风险和最佳实践，而不是直接防止未经授权的物理访问。

选项 D 错误。实施多身份验证系统是针对未经授权数字访问的预防性控制，但不解决防止未经授权物理访问的问题。

# 问题 64。
在检测到网络遭到未经授权入侵后，某金融机构希望实施一种将受损系统恢复到已知良好状态的控制。以下哪项是最合适的纠正控制？

- (A) 在整个网络实施入侵检测系统 (IDS)
- (B) 频繁更新防火墙规则
- (C) 从经验的备份中恢复系统
- (D) 为用户启用多身份验证

解释 64. 正确答案：C. 部署红外 (IR) 传感器。红外传感器检测红外辐射，例如人体发出的热量。这使得它们在检测人类入侵者时特别有效，即使在完全黑暗的情况下也能根据其发出的体热进行检测。

选项 A 带有 LED 灯的摄像头可以提供视觉监控，但它们依赖光线产生图像，在完全黑暗的情况下可能不如红外传感器那样有效地检测入侵者。

选项 B 错误。超声波运动传感器通过声波检测运动而非体热，这使得它们在区分人类者和其他移动物体时效率较低。

选项 D 错误。RFID 门禁读器控制入口处的访问，但不会根据设施内部的体热检测人类入侵者。

# 问题 65。
一家处理分类信息的组织正在实施网络基础设施，以确保最高水平的数据安全。CISO 建议使用一种网络配置，确保系统完全与不安全的网络和任何外部连接断开。以下哪项描述了这种配置？

- (A) DMZ（非军事化区）
- (B) VPN（虚拟专用网络）
- (C) VLAN（虚拟局域网）
- (D) 物理隔离网络 (Air-gapped network)

# 解析 65。
正确答案：D. 空隙网络。

物理隔离网络是指在物理上与不安全网络隔离的网络。物理隔离网络上的计算机无法与非隔离的计算机通信，且未连接到外部网络或互联网，从而确保了最高级别的数据安全。

选项 A 错误。DMZ（脱毒区）是私有网络与外部网络（通常是互联网）之间的缓冲区。它的设计目的是提供额外的安全层，但不能保证完全隔离。

选项 B 错误。VPN（虚拟专用网络）用于在不安全的网络（如互联网）上建立安全连接。它们对传输的数据进行加密，但在物理上并不隔离网络。

选项 C 错误。VLAN（虚拟局网）是物理网络内部逻辑分段的网络。它允许在二层网络中分离广播域，但不能提供与其他网络的完全物理隔离。

# 问题 66。
一家小型企业发现其网站遭到未经授权的访问。攻击者使用默认登录凭据获取了访问。这种攻击表明威胁者具有什么样的复杂程度和能力？

- (A) 具有基础技能的脚本小子 (Script kiddie)
- (B) 利用高级技术的专家级攻击者
- (C) 具有战略目标的国家级攻击者
- (D) 针对高价值资产的有组织犯罪集团

解析 66. 正确答案：A. 具有基础技能的脚本小子。使用默认登录凭据进行未经授权的访问通常表明其复杂程度较低，因为这种方法非常基础，且几乎不需要任何技术技能。此类攻击者通常被称为“脚本小子”，他们通常使用现成的工具或脚本来利用已知漏洞，而并不完全理解其原理。

选项 B 错误。专家级攻击者可能会利用更高级的技术，而不会仅仅依赖默认凭据。

选项 C 错误。虽然国家级攻击者具备发起复杂攻击的能力，但将默认登录凭据作为未经授权访问的主要方法，与此类攻击者通常采用的复杂方法不符。

选项 D 错误。有组织犯罪集团，特别是针对高价值资产的集团，会采用比仅仅使用默认登录凭据更复杂的技术。

# 问题 67。
为了威慑潜在的网络罪分子不要攻击其在线商店，一家电子商务公司正在考虑各种安全措施。以下哪项作为**威慑控制 (deterrent control)** 的效果最有效？

- (A) 在网站上显示第三方安全认证密封
- (B) 使用 Web 应用防火墙 (WAF)
- (C) 每月进行一次漏洞评估
- (D) 将客户数据存储在加密数据库中

解析 67. 正确答案：A. 在网站上显示第三方安全认证密封。在网站上显示第三方安全认证密封起到威慑控制的作用。它向潜在攻击者传递了一个信息，即该网站的安全措施获得了认可，这可以阻碍他们尝试攻击。

选项 B 错误。使用 Web 应用防火墙 (WAF) 是一种**预防控制 (preventive control)**。它负责过滤、监控和拦截恶意 Web 流量。虽然它有助于防御网络威胁，但它并不是对攻击者可见的威慑手段。

选项 C 错误。每月进行漏洞评估 是一种**检测控制 (detective control)**。它通过识别漏洞来增强安全态势，但对潜在攻击者不起威慑作用。

选项 D 错误。将客户数据存储在加密数据库中是一种**预防控制**，可以确保未经授权的人员无法访问或理解存储的数据。它保护了数据，但不能威慑潜在的网络罪分子。

# 问题 68。
一位系统管理员正在为一个新的 Web 应用程序设置身份验证系统。以下哪些安全控制属于**技术类**，并能确保用户在获得访问权限之前证明自己的身份？

- (A) 实施安全意识培训计划
- (B) 对新员工进行背景检查
- (C) 使用多因素身份验证 (MFA)
- (D) 建立洁桌面政策

解析 68. 正确答案：C. 使用多因素身份验证。多因素身份验证是一种技术控制，要求用户在获得访问权限之前提供两个或更多证据（因素）。它提供了额外的安全层，以确保用户确实是他们所称的身份。

选项 A 错误。实施安全意识培训计划是一种**管理控制 (administrative control)**，因为它涉及教育员工安全最佳实践，而不是使用技术措施来强制执行。

选项 B 错误。进行背景检查是种**管理控制**，因为它涉及在雇佣潜在员工之前对他们进行审查。这一过程并不会直接执行技术措施。
