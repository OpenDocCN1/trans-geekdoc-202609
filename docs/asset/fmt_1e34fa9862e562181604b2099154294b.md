许多公司使用此功能来重命名本地 Administrator 账户，并为工作站指定唯一密码，这是一种降低权限和防止未经授权访问的快速安全修复。随着公司更新网络，组策略文件被迁移，有时管理员会忘记它们曾设置过这些内容，或者这些设置由于时间太久而被遗忘了。

微软在 MS14-025 中修复了这个问题，如果你尝试使用 Microsoft GUI 来指定 `cPassword` 值，你将收到拒绝访问的对话框。
