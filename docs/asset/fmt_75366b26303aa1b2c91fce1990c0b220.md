
# 解析 288
正确答案：B. 风险阈值 (`Risk threshold`)。风险阈值是组织愿意接受的特定风险水平。在这种情况下，DeltaCorp 愿意接受高达 `500,000` 美元的潜在损失，将其标记为他们的阈值。

选项 A 是错误的。风险偏好是一个更广泛的术语，反映了组织在追求其目标时愿意接受总体风险水平。它更多是关于战略意图，而不是具体的数字。

选项 D 是错误的。风险评估是识别、分析和评估风险的过程。它不是一个具体的数字或阈值。

# 问题 289

- (D) 限制访问数据的管理员数量

正确答案：C. 实现数据分类和标记程序。通过实施数据分类和标记程序，组织可以明确识别哪些数据受监管，确保采取了适当的控制、访问权限和保护措施。这有助于根据分类制定清晰的数据处理准则，从而实现合规。

# 问题 290
一家组织正在考虑更换其全球分支的防火墙。IT 总监希望解决方案能够对数据包进行状态检测、应用程序级过滤，并集成威胁情报馈送以更新威胁意识。以下哪种方案最符合需求？

- (A) 状态检测检测防火墙
- (B) 代理服务器

- (D) 下代防火墙 (`NGFW`)

## 解析 290
正确答案：D. 下代防火墙 (`NGFW`)。下一代防火墙 (`NGFW`) 设计用于提供传统的防火墙功能（如状态检测），同时也具有高级功能，如应用程序级过滤以及集成威胁情报馈送的能力。这使得 `NGFW` 适用于需要多层安全的现代复杂环境。

选项 C 错误。Web 应用防火墙（`WAF`）专门保护应用程序免受针对性攻击。虽然很有价值，但它提供的功能和集成范围不如 `NGFW` 广泛。

# 问题 298
在例行漏洞评估中，`TechInc` 在其系统中发现了一个漏洞，如果被利用将允许攻击者修改现有的用户账户，包括权限。这种分类最符合该漏洞？

- (A) 权限提升漏洞 (`Elevation of privilege vulnerability`)
- (B) 泄露漏洞 (`Disclosure vulnerability`)
- (C) 重放漏洞 (`Replay vulnerability`)
- (D) 远程代码执行漏洞 (`Remote code execution vulnerability`)

## 解析 298
正确答案：A。权限提升漏洞。权限提升漏洞允许攻击者在系统内增加权限，通常会赋予他们比预预期更多的访问权限。场景描述了用户账户及其权限可以被修改的情况，这与该分类相符。

选项 B 错误。泄露漏洞涉及对信息的未经授权的访问，但不涉及对用户权限或数据的修改。

选项 D 错误。远程代码执行漏洞允许攻击者在目标系统上执行任意命令或代码。虽然这些可能非常严重，但给定的场景专门描述的是权限更改，而不是任意代码执行。
