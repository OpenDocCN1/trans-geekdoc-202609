## 机器学习中的应用智能决策

## 7.1 引言

在生物医学实验中，研究人员必须处理大规模数据库，其中维度灾是一个是一个严重的问题。我们在实验阶段处理微阵列数据集，其中监测了数百万个基因。许多研究人员采用了不同的工具；然而，微阵列技术是基因表达监测的首选方法。文献综述明确表明，微阵列分类技术在识别癌症方面发挥了显著作用 [1–4]。在微阵列数据集中，样本量很小但包含高维数据，因此很难处理用于获取测试结果的各种现有方法，而且这些方法的效果往往并不理想。因此，我们需要可靠的挖掘方法来识别原始数据库中的冗余特征。为此，在预处理阶段需要特征选择。我们可以通过特征选择技术识别出最优特征集。主要使用两种基本技术：过滤（filter）和包装（wrapper）。在过滤方法中，特征选择是根据不同的约束条件进行的，即基于训练集内在特征的特征行为或特征内容；而在包装方法中，它利用了分类器的性能。由于它使用了目标值，特征选择算法提供了更好的性能，但计算开销很大。许多研究人员使用了各种包装方法，例如禁忌搜索 (`TS`)、和谐搜索 (`HS`) [8]、差异演化 (`DE`) [6]、粒子群优化 (`PSO`) [7]、遗传算法 (`GA`) [5]、人工蜂群 (`ABC`) [9] 和蚁群优化 (`ACO`) [10]。

在本研究中，我们提出了一种基于元启发方法的二进制打乱青蛙跳跃算法，用于高维微阵列数据集的特征选择。在第一阶段（预处理阶段），我们从原始数据中提取了前 250 个基因，并提取了由二进制打乱青蛙跳跃算法识别的相关基因子集。我们在每个区间内提取了 25 个基因子集。使用 `K-近邻` (`KNN`) 分类器来评估分类准确性，并进行了进一步检查。

本文的其余部分安排如下：7.2 节提供了关于元启发方法特征选择方法的文献综述。7.3 节描述了使用二进制打乱青蛙跳跃算法的提议方法。7.4 节介绍了详细的设置。7.5 节给出了实验结果。7.6 节总结了全文工作。

## 7.2 现有知识

许多研究人员在特征选择领域使用了多种方法。以下技术被大多数人采用，例如禁忌搜索 (`TS`)、和谐搜索 (`HS`) [8]、差异演化 (`DE`) [6]、粒子群优化 (`PSO`) [7]、遗传算法 (`GA`) [5]、人工蜂群 (`ABC`) [9] 和蚁群优化 (`ACO`) [10]。但在某些情况下，由于过早收敛，它们会导致局部最优。为了避免这一局限性，使用了基于元启发方法的打乱青蛙跳跃算法 (`SFLA-META`)。

为了解决特征选择，[13] 提出了一种“基于骨架粒子群优化的特征选择算法”。定性结果显示，提议方法的分类准确率达到了 87.5%。[14] 提出了混合蚁群特征选择算法 (`ACOFS`)。根据结果分析，该提议方法在蚂蚁搜索的探索与开发之间保持了有效平衡，增强了蚁群优化的全局搜索能力，以实现特征选择问题的高质量解决方案。实验测试结果表明，`ACOFS` 在生成减小子集（显著特征）方面表现卓越，并提高了分类准确率。

黄等人 [15] 提出了一种基于粒子群优化和支持向量机 (`PSO-SVM`) 的混合方法，通过设置核参数来解决特征子集选择问题。为了最小化计算成本，利用 Web 服务技术开发了一个数据挖掘系统。实验结果表明，提议方法以高分类准确率识别了特征。为了提高 `SFL` 算法的全局搜索，Dash 等人 [16] 提出了一种对立学习方法。该算法改进了局部搜索并增加了多样性。提议算法在十种不同的基准优化函数上进行了测试。

在 [17] 中，作者将 `SFLA` 作为一种元启发方法，并应用于许多组合问题。该方法无法获得全局最优且容易掉入局部最优。因此，提出了一种具有莱维飞行的新 `SFLA`，并在 30 个基准函数上进行了测试。结果分析显示其性能更好。

本文献综述启发了我们基于元启发方法的二进制打乱青蛙跳跃算法 (`BSFLA-META`) 用于微阵列数据集的降维。我们提出了一种名为 `BSFLA-PSO` 的新型混合优化方法，通过结合 `PSO` 的快速收敛速度和二进制 `SFLA` 的全局搜索策略，将 `PSO` 引入 `SFLA`。二进制 `SFLA` 中的青蛙跳跃没有长度限制，有助于青蛙跳出局部最优。

经过洗牌过程，整个种群中适应度最差的青蛙会被 `PSO` 搜索到的最佳解替换，这有助于种群更有效地进化。

## 7.4 特征选择方法

### 7.4.1 洗牌青蛙跳跃算法与粒子群优化 (SFLA-PSO)

洗牌青蛙跳跃算法（`SFLA`）是 Eussuf 和 Lansey 在 2003 年提出的近期进化算法（EA）或元启发式算法。它是社会行为 `PSO` 和基于遗传的仿生算法的结合。一个由 `NP` 个青蛙组成的种群代表初始解。个体解 `X_i` 由 `Z` 维向量 `x_i = (x_{i1}, x_{i2}, ..., x_{iZ})` 表示，其中 `i ∈ {1, 2, ..., NP}`。定义了每个青蛙的目标函数评估，并根据它们的适应度值对青蛙进行降序排列。整个种群被分为 `m` 个成员块（memplexes）。这是一种完全循环类型的活动，第一只青蛙进入第一个成员块；第二只青蛙进入第二个成员块，……第 `m` 只要青蛙进入第 `m` 个成员块，而第 `m+1` 只青蛙则进入第一个成员块 [18]。在寻找食物时，青蛙之间的通信以两种方式进行：簇间通信或簇内通信。簇内通信也称为局部探索，簇间通信则称为全局通信 [19]。根据适应度值，适应度最好的青蛙标记为 `x_b`，适应度最差的标记为 `x_w`。在进化过程中，适应度最差的青蛙更新其位置，以便其向最优解移动。

```
$Z = r*(x_0 - x_w)
```

```
$x_{w(update)} = x_w + Z_i \leq Z_{max}
```

这里，`r` 代表在 0 和 1 之间变化的随机数，`Z_{max}` 是考虑青蛙位置的最大长度，而 `x_{w(new)}` 则根据旧值 `x_{w(old)}` 进行更新。如果没有改进，则 `x_w` 保持不变，并被随机生成的解替换。在执行洗牌后，每个成员块会执行 `L_{max}` 次迭代。

Kennedy 和 Eberhart [2005] 提出了一种基于种群的优化算法。每个种群由 `NP` 个粒子组成，称为群（swarm）。第 `i` 个位置的位置和值在 `Z` 维中表示，这决定了搜索空间。位置值表示为 `x_i = (x_{i1}, x_{i2}, \dots, x_{iz})`，速度值表示为 `v_i = (v_{i1}, v_{i2}, \dots, v_{iz})`。目标函数是评估每个粒子性能的主要标准。粒子之前访问过的位置表示为 `p_i = (p_{i1}, p_{i2}, \dots, p_{ic})`，每个个体群的最佳之前位置表示为 `p_g = (p_{g1}, p_{g2}, \dots, p_{gc})`。让“itr”代表迭代次数。因此，群的速度可以表示为：

```
$v_i^{itr+1} = w * v_i^{itr} + c_1 * r_1 * (p_i^{itr} - x_i^{itr})
```

```
$x_i^{itr+1} = x_i^{itr} + v_i^{itr+1}
```

其中，`w` 是惯性权重，`c_1, c_2` 是学习因子，`r_1, r_2` 是在 0 到 1 之间的随机数。（注：此处原文公式部分似乎有断层，翻译时已根据上下文逻辑进行了对齐）。

*(注：由于提供的英文文本在 PSO 公式描述和 BSFLA-PSO 算法部分结尾不完整或存在重复，我已按照原文逻辑进行了尽可能翻译。)*

1. 用随机解初始化种群。
2. 评估每个解的适应度。
3. 将种群划分为成员块。
4. 对于每个成员块，使用 `SFLA` 进行局部搜索。
5. 使用 `PSO` 进行全局搜索。
6. 用最佳解更新种群。
7. 重复直到满足停止标准。

## 7.5.3 本实验研究中使用的分类器详述及评估指标

在这项实验研究中，我们使用了三种不同的分类器——`SVM`、`ANN` 和 `K-近邻` 来识别特征数据子集。根据以下标准对不同分类器的性能进行了比较：

- 真阳性 (`True-pos`)；
- 假阳性 (`Fal-pos`)；
- 真负性 (`True-neg`)；
- 假阴性 (`Fal-neg`)。

根据这些标准，我们计算了准确率、灵敏度和特异性的不同性能评估。

```
Accuracy = \left[ \frac{True-pos + True-neg}{Total no of sample} \right] *100
```

```
Sensitivity = \left[ \frac{True-pos}{True-pos + False-neg} \right] *100
```

```
Specificity = \left[ \frac{True-neg}{True-neg + False-neg} \right] *100
```
