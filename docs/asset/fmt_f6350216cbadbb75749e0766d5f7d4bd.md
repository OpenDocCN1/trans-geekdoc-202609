####### 3D 多层 CMOS-ReRAM 加速器可扩展性分析

由于神经网络处理需要频繁读取网络权重，因此将内存读取延迟优化配置设置为生成 ReRAM 内存架构。通过采用 3D 实现，仿真结果表明，与 2D 实现相比，内存读取和写入带宽分别显著提高了 51.53% 和 6.51%。对于较少数量的隐藏节点，读/写带宽仍有提升，但瓶颈转移到了内存逻辑控制的延迟上。
