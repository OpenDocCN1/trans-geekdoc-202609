在编写实现该分类器的计算机程序时，工程师不能忘记决定如何标记恰好位于超平面上的稀有示例——这种情况发生在表达式等于 0 的时候。通常做法是随机选择一个类别，或者倾向于选择在训练集中代表性更多的那个类。

### 低计算成本

注意这种方法的计算成本较低。虽然 1-NN 分类器需要评估许多距离并搜索最小的一个，而线性分类器只需要确定一个简单表达式的符号。

如果 $\sum_{i=0}^{n} w_i x_i > 0$，则分类器“假设”该样本为正例，否则 $\sum_{i=0}^{n} w_i x_i \le 0$。图 4.2 提醒我们，只有当支持该类的累积证据超过 0 时，分类器才会将 $x$ 标记为正类。

最后，我们假设 $c(x) = 1$ 的样本与 $c(x) = 0$ 的样本线性可分。这意味着存在一个线性分类器可以正确标记所有训练样本，即 $h(x) = c(x)$。机器学习的任务就是找到权重 $w_i$ 以实现这一点。

## 从错误中学习

这是线性分类器归纳最常用方法的本质。假设我们已经有一个分类器的中间版本（即使是不完美的）。当给呈现一个训练样本 $x$ 时，分类器返回其标签 $h(x)$。如果该标签与真实类别不同，即 $h(x) \neq c(x)$，那么那是因为权重并不完美；因此，必须以可能纠正这一错误的方式对它们进行修改。

以下是修改权重的方法。假设真实类别为 $c(x) = 1$。

在这种情况下，$h(x) = 0$ 只有在 $\sum_{i=0}^{n} w_i x_i < 0$ 时才会发生，这意味着权重太小了。如果我们增加权重，那么和 $\sum_{i=0}^{n} w_i x_i$ 可能会超过 0，使得返回的标签变为正，从而从而正确。注意，只需增加 $x_i = 1$ 的属性权重足够了；当 $x_i = 0$ 时，$w_i$ 的值并不重要，因为任何数乘以零仍然为零：$0 \cdot w_i = 0$

同样，如果 $c(x) = 0$ 且 $h(x) = 1$，则应该减少所有 $x_i = 1$ 属性的权重，以便使和有降至零以下的机会，$\sum_{i=0}^{n} w_i x_i < 0$。

## 权重调整公式

总之，训练样本 $x$ 的呈现可能导致三种不同的情况。基于“从错误中学习”的技术根据下表对此做出响应：

| 情况 | 操作 |
| --- | --- |
| $c(x) = 1$ 且 $h(x) = 0$ | 增加每个 $x_i = 1$ 属性的 $w_i$ |
| $c(x) = 0$ 且 $h(x) = 1$ | 减少每个 $x_i = 1$ 属性的 $w_i$ |
| $c(x) = h(x)$ | 不执行 |

有趣的是，所有这些操作都是通过一个公式完成的：

```
w_i = w_i + \alpha \cdot (c(x) - h(x)) \cdot x_i
```

(4.10)

让我们来看这个权重调整公式的基本方面。

1. **正确的操作**。如果 $c(x) = h(x)$，括号中的项为 $(c(x) - h(x)) = 0$，使得 $w_i$ 保持不变。如果 $c(x) = 1$ 且 $h(x) = 0$，括号中的项为 $1$，因此权重增加。如果 $c(x) = 0$ 且 $h(x) = 1$，括号中的项为负值，权重随之减少。
2. **仅影响相关权重**。如果 $x_i = 0$，要加到第 $i$ 个权重上的项 $\alpha \cdot (c(x) - h(x)) = 0$。这意味着该公式仅在 $x_i = 1$ 时才会影响 $w_i$。
3. **变化幅度**。这由学习率 $\alpha$ 控制，其用户设置的值从区间 $(0; 1]$ 中选择。

注意，权重的修改是加性的，意味着一个项被加到权重的之前值上。在第 4.3 节中，我们将讨论另一种可能性：乘法公式。

## 感知机学习算法

方程 (4.10) 成了感知机学习算法的核心。过程由表 4.1 中的伪代码总结。原理很简单。一旦权重被初始化为较小的随机值，就会一个接一个呈现训练样本。在每个样本之后，分类器的每个权重都会接受 (4.10) 的处理。最后一个样本意味着一个训练轮（epoch）的完成。除非分类器现在标记了整个训练集，否则学习器将返回第一个样本，从而开始第二个，依此类推。通常，需要几轮才能达到目标。

### 表 4.1 感知机学习算法

假设：两个类别 $c(x) = 1$ 和 $c(x) = 0$ 是线性可分的。

1. 初始化所有权重 $w_i$ 为较小的随机数。选择合适的学习率 $\alpha \in (0; 1]$。
2. 对于每个训练样本 $x = (x_1...x_n)$，其类别为 $c(x)$：
    1. 如果 $\sum_{i=1}^{n} w_i x_i > 0$，令 $h(x) = 1$，否则令 $h(x) = 0$。
    2. 使用公式 $w_i = w_i + \alpha \cdot (c(x) - h(x)) \cdot x_i$ 更新每个权重。
    3. 如果对于训练样本都有 $c(x) = h(x)$则停止；否则返回第 2 步。

第一个是一组（随机）初始权重。不同的初始化可能会导致不同的训练轮数（epochs）数量。大多数情况下，分类器的初始版本几乎是毫无用处的，在过程收敛到某些有用结果之前，需要大量的训练。然而，有时第一个版本可能相当不错，只需一个 epoch 就能解决问题。在极端情况下，尽管可能性微乎其微，存在这种可能：随机数生成器创建一个能够无错误地标记所有训练样本的分类器，因此不需要任何训练。

# 4.3 乘法规则：WINNOW

![image](img/chapter_title_below.png)

感知机学习通过应用加法规则来响应分类器的错误，即给权重加上正项或负项。一个显而易见的替代方案是乘法规则，权重通过相乘而不是相加。这种方法已被 WINNOW 采用，这是一种由表 4.3 中的伪代码总结的算法。

### 原理与公式

通用场景与上一节相同。给出一个训练样本 `x`，分类器返回关于该样本标签的假设 `h.x/`。学习者将此假设与已知标签 `c.x/` 进行比较。如果两者不同，`c.x/ \ h.x/`，则属性 `xi \ 1` 的权重将按如下方式修改（其中 `˛ > 1` 是用户设置的参数）：

| 情况 | 操作 |
| --- | --- |
| `c.x/ = 1` 此时 `h.x/ = 0` | `wi = ˛wi` |
| `c.x/ = 0` 此时 `h.x/ = 1` | `wi = wi\=˛` |
| `c.x/ = h.x/` | 不操作 |
