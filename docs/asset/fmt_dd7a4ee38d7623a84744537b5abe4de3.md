
海什末（Alhazen）几乎比 Cover 和 Hart 的神经网络算法提前近千年了某些方面，但彼特·哈特（Peter Hart）认为这种直觉可以追溯到更远，可能一直到我们穴居的祖先。为了说明他的观点，他从我们已经遇到过的简单数学开始。考虑 2D 向量和`xy`平面。`xy`平面上每个由点`(x, y)`给出的点都是向量，一个从原点`(0, 0)`指向`(x, y)`的箭头。3D`xyz`坐标系也是如此：每个向量都是从`(0, 0, 0)`指向`(x, y, z)`的箭头。同样，一个 3D 向量只是 3D 空间中的一个点。这可以扩展到任意维度。字母表很快就用完了，因此习惯上使用`[x1, x2, x3, …, xd]`来表示`d`维向量。现在的关键是将向量与模式联系起来。

假设我们正在看一张 7×9 的图像，总共 63 个像素，每个像素可以是白色（0）或黑色（1）。你可以通过将某些像素设为黑色另一些像素设为白色，轻松地使用这种图像描出 0 到 9 的数字。每幅图像或模式都可以写成一个向量`[x1, x2, …, x63]`：一组包含 63 个数字，每个数字要么是 0 要是 1。我们只是将每个 7×9 图像转换成了 63 维向量。

![](img/p153_01.png)

现在，如果你在平板电脑的触摸屏上看到一个空白的 7×9 网格，并要求用手指画出数字 2 或数字 8 会怎样？每当你画一次数字时，网格中的某些方格会变成黑色，而另一些则保持白色。然后，该模式被存储为一个长 63 位的数字。你这样做几次，然后把平板电脑交给别人，他们也同样这样做。许多人轮流生成数据，很快，你就有了数百个代表两个手写数字 2 和 8 的向量样本。从数学角度上说，每个模式都是 63 维向量空间中的一个点。问自己一个问题：给定每个向量都是点（这是机器学习看待向量的方式），这些向量在那个超维空间中将如何聚类？

嗯，我们大多数人画数字 2 的方式会非常相似，但每次尝试可能与另一次略有不同，即使这些画是由同一个人完成的。（因为我们使用的是黑白像素，画作之间的差异可能并不显著，但如果例如，手指压力将每个像素转换为灰度上的某种东西并赋予它一个 0 到 255 之间的数字，那么差异就会大得多。但让我们用 0 和 1 表示黑白吧。）因此，每当模式 2 被存储为一组 63 个数字时，它就代表一个向量，一个与代表其他手写 2 的向量大致位于相同位置的点。现在，代表所有手写 2 的点将在 63 维空间中彼此聚在一起。数字 8 也是如此。但这两个数字的区别足够大，构成数字 2 聚类的向量将位于 63D 空间的一个区域，而数字 8 的向量聚类将在其他地方。

假设触摸屏还会为每个模式生成一个标签，将其标记为 2 或 8。我们现在做的是生成一个样本数据集，每个向量都有一个关联标签。现在我们面临的问题——或者准确地说，任何机器学习算法面临的问题是：给定一个新的未标记或未分类的模式，算法能否判断出它是 2 还是 8？

在算法上，人们可以做非常简单的事情。只需将新的、未标记的向量绘制成点即可。在 63D 空间中找到离它最近的点。如果最近的点标签为 2，那么新点也可能是 2。如果最近的邻居是 8，那么新成员最可能是 8。“这就是最近邻居规则。这就是穴居人的直觉：如果它们看起来相似，那么它们可能就很相似。”

尽管有穴居人和海什末的开创性工作，最近邻居规则的首次数学提到出现在 1951 年德克萨斯州兰德福菲尔德美国空军航空医学学院的一份技术报告中。作者是 Evelyn Fix 和 Joseph L. Hodges, Jr.。 1940 年，Fix 来这里工作了。

> 他们带来了困难但有时有趣的问题。实验室的每项要求都强调紧迫性；问题的实际解决方案意味着确定最优计划、该计划和那个计划成功的概率、数字以及更多的数字。当时不存在高速计算机；所有的数值工作都必须在台式计算器上完成，消耗大量的时间和精力。凭借非凡的能量和办成并办好工作的特殊精神，Evelyn`Fix`在一群学生和一些教师家属的帮助下，在机器前日夜工作，以便所需的结果能按时传输，通常发送到纽约，有时直接发送到英国。在这些年里，Evelyn 还继续自己的学习并向学生授课。

Fix 的努力她在统计学和概率论的实际应用方面获得了宝贵的专业知识。她于 1948 年获得博士学位并留在伯克利，享受了许多富有成效的合作。其中之一与 Hodges 的合作，产生了 1951 年的技术报告。

最近邻算法在其最简单的形式，本质上是绘制出新的数据点，并计算它与初始数据集中的每个数据点的距离，这个初始数据集可以被视为训练数据。（在我们的范围内，我们将使用`Euclidean distance`测量方法。）如果距离新数据最近的数据点是黑色三角形，则新数据被分类为黑色三角形；如果它是灰色圆，则新数据被分类为灰色圆。就是这么简单。接下来的两个面板显示了如何根据其最近邻对新数据点进行标记。（新数据点用星形表示，但颜色颜色为灰色或黑色，取决于它被分类为灰色圆还是黑色三角形。）原始数据集与上一个面板所示的相同。

注意非线性边界如何将坐标空间划分为两个以上的灰白区域。在误分类的黑色三角形周围有一个小小的“岛屿”。如果新数据点位于该小岛屿内，它将被分类为黑色三角形，尽管它被灰色圆包围。

我们看到的是机器学习研究人员所**过拟合**（overfitting）的例子。我们的算法过拟合了数据。它找到了一个甚至不忽略单个错误离群值的边界。发生这种情况是因为算法只关注一个最近邻。然而，有一个简单的解决办法可以解决这个问题。我们可以简单增加与新数据点比较的最近邻数量。邻居的数量必须是奇数（例如，三、五或更多）。为什么要用奇数？嗯，因为如果是偶数，我们可能会出现平局，那是没用的。奇数确保我们能得到答案，无论对错。这假设我们只处理可以聚类为两类的数据（在这种情况下，是灰色圆和黑色三角形）。

这是相同数据集，但现在算法寻找三个最近邻，并根据多数投票对新数据点进行分类：

![](img/p161_01.png)

非线性边界不再对圆中间唯一的孤立三角形给予过度关注。如果新数据点落在这个孤立三角形附近，它仍然会被分类为圆，因为该三角形会被周围的圆投票掉。边界变得平滑了些；它没有为了解释数据中的噪声（在我们的案例中，就是那个误分类的三角形）而扭曲。与我们仅使用一个最近邻得到的边界相比，使用更多最近邻的这种平滑边界更有可能正确分类新数据点。这种算法被认为对未见数据具有更好的泛化能力。（尽管有一个灰色圆最终落在了边界的错误侧。我们稍后会讨论这些违规者。）

这是另一个例子（参见面板），考虑到最近邻的数量增加到了七个。对于相同的初始数据集，非线性分离边界的形状略有不同。

![](img/p162_01.png)

但请注意一个至关重要的一点。如果你检查算法使用七个最近邻实现的非线性边界，你会发现虽然错误的三角形落在属于圆的区域，但它的影响在很大程度上被削弱了。这是好事，因为错误的三角形是“噪声”，一个在训练数据中意外被误分类为三角形的圆。但不幸的是，有一个圆落在属于三角形的区域内。然而，这个圆在训练数据中被正确分类了，却落在了边界的错误侧。这就是如果你不想过拟合所必须付出的代价。以边界为特征的分类器——可能会误分类训练数据集中的某些数据点。尽管训练数据中出现了一些错误，但这种做法之所以是有意义的，因为当你使用它未见过的数据来测试这个分类器时，它产生的错误可能比你使用过拟合了训练数据的分类器要少得多。现在只需记住这一点即可；我们稍后会对比过拟合与泛化进行更深入的分析。

尽管这个算法如此简单，但确定其效能所需的数学知识（就算法在分类新数据时产生错误的概率）绝非简单。彼得·哈特（Peter Hart）回忆道，最初很难开发所需的直觉来证明该算法可以收敛到结果，并且与`Bayes optimal classifier`（贝叶斯最优分类器，正如我们所见，这是机器算法能做到的最好）相比表现良好。当然，`Bayes optimal classifier`是一个理想化模型，因为它假设可以获得数据的底层概率分布，或者是对此类分布的最优估计。`NN`算法运行在另一个极端。人们拥有的只是数据，算法对底层分布几乎不做任何假设，事实上也几乎无知。例如，它没有假设数据遵循某种均值和方差的`Gaussian`（高斯）分布。

于是，哈特确实做到了：他变得更聪明了。

# 引言

我们可以领略 Hart 想要转化为严谨结果的直觉。（实际的定理和证明对我们来说稍微有点晦涩。）让我们回到这两种企鹅：阿望利企鹅和巴纹企鹅，以及一个特征：喙深（见图）。

如果你可以获取这两个底层分布，那么给定一个新的未分类的企鹅及其喙深，你可以使用贝叶斯定理简单地计算出给定喙深的情况下企鹅是阿望利企鹅的概率，以及它是巴纹企鹅的概率。假设对于某个特定的喙深，该企鹅是阿望利企鹅的概率为 0.75，巴纹企鹅为 0.25。对于贝叶斯最优分类器，每次都是概率更高的胜出。该算法始终会将新企鹅分类为阿望利企鹅，尽管有 25% 的概率可能是错误的。

最近邻算法又是怎样的？这里是 1-最近邻（或 1-NN）规则作用的心理图。它在新数据点的相邻邻域内寻找代表阿望利企鹅和巴纹企鹅的点。如果算法可以访问所有代表这两类企鹅的可能点，那么在附近的数据点中，75% 将是阿望利企鹅，25% 是巴纹企鹅。但我们只有一小部分企鹅样本。而 1-NN 算法必须根据这个有限的数据集做出决定。这就像它有一枚有偏斜的硬币，75% 的时间出现正面，25% 的时间出现反面。当然，这枚硬币是特定于一个新的未分类企鹅的喙深：正面代表它是阿望利企鹅；反面代表它是巴纹企鹅。所以，与贝叶斯最优分类器（总是声称它是阿望利企鹅）不同，1-NN 规则会在四分之一的时间里说新企鹅是阿望利企鹅，在分之一的时间里说是巴纹企鹅。凭借这种直觉，Hart 最终确定了建立 1-NN 规则错误下界和上界所需的数学，并将其扩展到 k-最近邻，即 k-NN 规则。这是一个开创性且令人难忘的结果。上面的图表显示了贝叶斯最优分类器的错误概率（或风险）与 NN 分类器之间的比较。

## k-NN 算法

k-NN 算法的表现无法优于贝叶斯最优分类器（虚线，即下界）。对于 1-NN 和大量样本数据 (n)，算法错误风险的上界显示为实线抛物线：它的表现绝不会更差。但随着 k 的增加，且 k/n 保持较小值，分类器的性能开始接近贝叶斯最优分类器：抛物线变得平缓，并更贴近虚线。

再次，其直觉原理大致如下：随着你收集的样本越来越多，新数据点的相邻邻域内将布密代表阿望利企鹅和巴纹企鹅的数据点。对于我们的例子来说，新数据点周围的局部区域将有 75% 的阿望利企鹅和 25% 的巴纹企鹅。

## 实现细节

k-NN 算法之所以异常成功，既是因为它的有效性，也是因为它的简单性。从编写代码的人的角度来看，这里有一些伪代码来解释它需要多么少的工作。（我们暂时沿用阿望利企鹅和巴纹企鹅，即两个类别和两个特征；算法可以很容易扩展到包含两个以上的类别和任意数量的特征。）

### 步骤 1

存储所有样本数据的实例。

* 每只企鹅都是向量`[x1, x2]`，其中`x1`=喙深，`x2`=喙长。整个数据集存储在矩阵`X`中，其中`X`有`m`行（企鹅数量）和`n`列（特征数量）。

* 每只企鹅还关联一个标签`y`，其值为 -1（阿望利企鹅）或 1（巴纹企鹅）。因此，存储所有对应标签的`y`是一个`m`维向量。

### 步骤 2

给定一个代表未分类企鹅的新数据点，形式为包含喙深和喙长的向量`x [x1, x2]`，执行以下操作：

* 计算新数据点到原始数据集`X`中每个数据点的距离。这给了我们一个包含`m`个距离的列表`d`。

* 按距离增加的顺序对列表`d`进行排序（第一个元素距离最小，最后一个元素距离最大）。

* 在排序`d`的同时，同步调整`y`的元素，以便相应的标签（-1 或 1）与排序列表中的每个企鹅保持关联。

### 步骤 3

取排序列表`d`的前`k`个元素。这些代表了`k`个最近邻。收集与这些最近邻关联的标签（-1 或 1）。统计 1 的数量和 -1 的数量。

### 步骤 4

如果 1 的数量多于 -1，则新数据点的标签为 1（巴纹企鹅）；否则它是阿望利企鹅。

这种简单的算法能实现什么？你在互联网上被要求购买的那些东西又是怎样的呢？如果某些公司（此处不点名）想向你推荐购买某些书籍或观看某些电影，它们可以通过将你表示为某个高维空间中的一个向量（基于你对书籍或电影的喜好），找到你的最近邻居，看看他们喜欢什么，然后将那些书籍或电影推荐给你。甚至连果蝇也被认为使用了这种方法。

`k-NN`算法最重要的特征之一是它是一个所谓的**非参数模型**。回想一下感知机（perceptron）。一旦你使用某些初始训练数据集训练好模型，感知机就可以简单地通过其权重向量`w`来表征。该向量的元素数量等于定义感知器的参数数量。这个数字并不依赖于训练数据量。你可以用一百个或一百万个数据实例来训练感知机，但在训练结束时，超平面仍然由`w`定义。

相比之下，非参数模型没有固定的参数数量。`k-NN`模型就是一个例子。你基本上存储了所有的训练数据实例（无论一百个还是百万个），并在对新数据进行推断时使用所有实例。不幸的是，这正是`k-NN`算法最大的担忧之一。随着数据集规模的爆炸，使用`k-NN`进行推断需要越来越多的计算能力和内存，以至于可能变得慢得令人难以接受且消耗资源。

还有一个显而见的缺点，由于数据在极高维空间中的奇异行为。我们三维的大脑完全无法理解所有可能出现的问题。

### 维度灾难

在他 1957 年的著作《动态规划》（*Dynamic Programming*）序言中，美国应用数学家理查德·贝尔曼（Richard Bellman）讨论了处理极高维数据的问题，并提出了“维度灾咒”这一概念。

有很多方法可以理解这种灾咒。让我们从简单的开始。取一个可以用特征描述的数据样本：取值在 0 到 2 之间的值。假设代表数据样本值的随机变量是均匀分布的，这意味着随机变量可以以等概率取 0 到 2 之间的任何值。

注意，特征值介于 0 和 1 之间的空间区域仅占了总空间的四分之一。（在 1D 空间中，它占据了总线段长度的一半。）因此，现在你很可能在这个空间区域（即单位正方形）中发现更少的数据样本。（在上面的示例图中，20 个点中只有 4 个落在了我们指定的区域内。）

让我们进入三维。现在有三个特征，每个特征的值都可以在 0 到 2 之间的任何地方。我们仍然对特征介于 0 到 1 之间的空间体积感兴趣；该体积是单位立方体。在 3D 情况下，感兴趣的体积现在是总体积的八分之一。因此，如果你在总体积（一个边长为 2 个单位的立方体）上均匀地绘制 20 个数据样本，你在单位立方体中找到的数量将剧减。（在下所示示例中，只有 2 个是黑点；灰点位于外部。）

![](img/p171_01.png)

ML 算法可以被认为经常检查此类空间体积的方法，以便观察例如一个数据点是否类似于另一个。这些数据通常是从某些底层分布中随机采样的。在我们特征值介于 0 到 2 之间的玩具示例中，当维度（或描述一个数据点所需的特征数量）增加时，例如增加到 1,000 或 10,000 或更多，在单位超立方体内找到数据点的概率会迅速降低。（单位超立方体的每边长度等于 1。）当然，这假设我们只坚持 20 个分布在这一极高维空间中的随机抽取样本；在这种情况下，高维空间中的单位超立方体可能没有任何数据。正如巴黎德卡特大学的 Julie Delon 在关于该主题的话中所说：“在高维空间中，没有人能听见你的尖叫。”

减轻问题的一种方法是增加数据样本的数量（这样在你的邻范围内就有人听到你的尖叫）。不幸的是，为了让解决方案生效，这个数字必须随着维度的指数级增长，因此该方法力不从心。
