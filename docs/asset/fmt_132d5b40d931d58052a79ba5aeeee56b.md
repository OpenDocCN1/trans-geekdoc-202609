
# 玻璃球颜色与温度对应

玻璃球有不同的颜色，指示触发玻璃球爆裂并打开喷头的天花板温度。使用的颜色包括橙色（135°F/57°C）、红色（155°F/68°C）、黄色（175°F/79°C）、绿色（200°F/93°C）和蓝色（286°F/141°C）。`NFPA 13：喷水灭火系统安装标准`描述了这些喷头使用的颜色惯例。请参见 [`www.nfpa.org/codes-and-standards/all-codes-and-standards/list-of-codes-and-standards/detail?code=13`](https://www.nfpa.org/codes-and-standards/all-codes-and-standards/list-of-codes-and-standards/detail?code=13)。

## 干式管道

**干式管道**系统也使用闭式喷头：区别在于管道内充满压缩空气。只要管道内保持足够的气压，阀门就会保持关闭以阻挡水流。当干式喷头开启时，管道内气压下降，阀门随之打开并向该喷头供水。

干式管道常用于水可能结冰的区域，例如停车库。

## 淋喷系统

**淋喷系统**类似于干式管道，不同之处在于喷头是开放的，且比干式管道喷头更大。管道在正常大气压下是空的；一个淋喷阀阻挡水流。当火灾报警器（可能监测烟雾或火焰传感器）触发时，阀门开启。

## 预作用系统

**预作用**系统是湿式、干式或淋喷系统的组合，需要两个独立的触发条件才能释放水流。单联锁系统在火灾报警触发时将水释放进管道。水在喷头开启后喷出。双联锁系统使用压缩空气（同干式管道）：只有当火灾报警触发**且**喷头开启时，水才会充满管道。

预作用系统用于博物馆等区域，因为意外喷水会造成昂贵损失。双联锁系统用于冷冻库等寒冷区域，以防止管道冻结。

## 手提灭火器

所有手提灭火器都应标明其设计扑灭的火灾类型。

手提灭火器应足够小巧，以便任何可能需要使用的人员都能操作。这意味着那些老式的黄铜大型灭火器不属于推荐的控制措施。

使用“PASS”法用手提灭火器扑灭火灾：

*   **Pull the pin**（拔掉保险销）
*   **Aim low**（对准根部/低处瞄准）
*   **Squeeze the pin**（握压把手/压柄）—— *注：原文为 "Squeeze the pin"，标准 PASS 步骤通常为 "Squeeze the handle/lever"（握压把手/压柄）*
*   **Sweep the fire**（左右扫射火源）

# 考试目标总结

在本（庞大的）领域中，我们首先描述了基本的逻辑硬件、操作系统和软件安全组件，以及如何利用这些组件来设计、架构和评估安全计算机系统。理解这些基本问题对信息安全专业人员至关重要。

随后我们转向密码学，其历史可追溯至古代，但仍深深植根于现代世界，为静态和动态数据提供安全保障。现代系统如`公钥基础设施 (PKI)`通过使用对称、非对称和基于哈希的加密，将所有密码学组件整合在一起，以提供机密性、完整性、认证和不可抵赖性。你已了解这些组件如何协同工作：速度较慢且强度较弱的非对称密码（如 `RSA` 和 `Diffie-Hellman`）用于交换速度更快、强度更高的对称密钥（如 `AES` 和 `DES`）。对称密钥作为会话密钥，用于加密短期会话，例如通过 `HTTPS` 进行的 Web 连接。数字签名采用公钥加密和哈希算法（如 `MD5` 和 `SHA-3`），提供不可抵赖性、发送方认证和消息完整性。理解这些概念及本章讨论的其他概念，并将它们综合应用，对于通过考试至关重要。

最后，物理安全隐含于大多数其他安全控制中，却常被忽视。在实施来自所有 8 个知识领域的控制措施时，我们必须始终寻求平衡。所有资产都应受到跨越多个领域的多层纵深防御控制的保护。例如，文件服务器可通过策略、程序、访问控制、补丁管理、防病毒、操作系统加固、门锁、墙体、暖通空调 (`HVAC`) 和灭火系统（以及其他控制）进行保护。应对所有必须受保护的资产进行彻底且准确的风险评估。注意确保没有遗漏或忽视任何领域或控制措施。
