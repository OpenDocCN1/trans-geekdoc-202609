## 22.7 无监督学习和迁移学习

我们到目前为止讨论的深度学习系统基于监督学习，这需要为每个示例标记目标函数的值。尽管此类系统可以达到很高的测试集准确率（例如ImageNet竞赛的结果），但对于相同的任务通常比人类需要更多标记数据。例如，孩子只需要看一张长鹿的照片，而不是成千上万张。显然，我们的深度学习故事缺少了什么；事实上，我们目前的监督深度学习方法使得某些任务完全无法实现，因为标记数据的需求超过了人类（或宇宙）的供应。此外，即使在任务可行的情况下，标记大型集合也需要稀缺且昂贵的人力。

由于这些原因，人们对减少对标记数据依赖的一些学习范式感兴趣。正如我们在19节看到的，这些范式包括*无监督学习、迁移学习和表示学习*。无监督算法仅从比标记示例更丰富的无标记输入学习。无监督学习通常产生生成模型，而不是简单的预测此类数据的标签。迁移学习算法需要一些标记示例，但可以通过学习不同任务的标记示例来提高性能，使其能够利用更多数据。表示学习算法需要一些标记示例，但通过同时也学习无标记示例进一步提高性能。本节涵盖无监督和迁移学习的深度方法；表示学习也是深度学习社区的活跃研究领域，到目前为止开发的技术在实践中尚未证明广泛有效，因此我们不涵盖它们。

### 22.7.1 无监督学习

无监督算法都有相同的总目标：给定一组输入$x$，并构造一个良好拟近$f$的函数$h$。无监督算法从无标记示例的训练集中学习两点。在这里我们描述算法可能尝试做的事情。第一是学习表示——例如，图像的新特征，使得识别图像中的物体变得更容易。第二是学习生成模型——通常以概率分布的形式存在，从它可以生成新样本。（21节中学习贝叶斯网络的算法属于这一类。）

假设我们学习一个联合模型$P_w(x,z)$，其中$z$是一组无监督变量，表示空间中数据$x$的内容。根据本节的精神，我们定义$z$变量的含义；模型自由地将$z$与$x$关联。对于在手写数字图像上训练的模型可能会使用$z$空间中的一个方向表示笔画的粗细，另一个表示墨水颜色，另一个表示背景颜色，以此类推。对于脸部图像，学习算法可能会选择一个方向表示性别，另一个方向捕捉是否戴眼镜，如图22.9所示。

概率模型$P_w(x,z)$实现了表示学习（它从原始$x$向量构造了有意义的$z$向量）和生成模型：如果我们对$z$进行积分，就得到$P_w(x)$。

## 概率PCA：一个简单的生成模型

关于$P_w(x,z)$可能采取什么形式已经有很多建议。最简单的之一是**概率主成分分析（PPCA）**模型。在PPCA模型中，$z$从均值为零球形高斯分布中选取，然后通过应用权重矩阵$W$并添加球形高斯噪声从$z$生成$x$：

```
$P(z) = \mathcal{N}(z;\mathbf{0},I)$
$P_w(x) = \mathcal{N}(x;\mathbf{W}z,\sigma^2I)$
```

可以通过最大化数据的似然性来学习权重$W$（以及可选的噪声参数$\sigma^2$），似然性给出：

```
$P_w(x) = \int P_w(x,z)dz = \mathcal{N}(x;\mathbf{0},\mathbf{WW}^T+\sigma^2I)$ (22.16)
```

对于$W$的最大化可以通过梯度方法或高效的迭代EM算法完成。一旦学习了$W$，就可以使用方程(22.16)直接从$P_w(x)$生成新的数据样本。此外，根据方程(22.16)概率极低的新观测值$x$可以被标记为潜在的异常。

使用PCA时，我们通常假设$z$的维度远小于$x$的维度，因此模型学习如何尽可能用少量的特征来解释数据。通过计算$\hat{z}$（$P_w(z)$的期望），可以提取这些特征以用于标准分类器。

从概率PCA模型生成数据是简单的：首先从其固定的高斯先验中采样$z$，然后从均值为$Wz$的高斯分布中采样$x$。正如我们很快看到的，许多生成模型类似于此类，但使用的是模型定义的复杂映射，而不是从$z$到$x$空间的线性映射。

> 7 标准PCA涉及对原始输入数据拟合一个多变量高斯分布，然后选择该椭圆分布的最长轴——即主成分。

### 自动编码器

许多无监督深度学习算法都基于自动编码器的思想。自动编码器是一个包含两个部分的模型：一个将$x$映射到表示$\hat{z}$的编码器，以及一个从表示$\hat{z}$映射到观测数据$x$的解码器。一般而言，自动编码器是一个参数化函数$f$，解码器是一个参数化函数$g$。训练模型使得$x \approx g(f(x))$，因此编码过程通过解码过程被大致反转。$f$和$g$可以是与单个矩阵相乘的简单线性模型，也可以由深度神经网络表示。

简单的自动编码器是线性自动编码器，其中$f$和$g$都是共享权重矩阵$W$的线性函数：

```
$\hat{z} = f(x) = Wx$
$g(\hat{z}) = W^T\hat{z}$
```

训练该模型的方法之一是最小化平方误差$\sum_j ||x_j - g(f(x_j))||^2$，使得$x \approx g(f(x))$。其思想是训练$W$，使得低维的$\hat{z}$保留尽可能多的信息来重构高维数据$x$。这种线性自动编码器被证明与主成分分析（PCA）密切相关。当$z$是$m$维时，矩阵$W$应该学习跨数据的$m$个分量——即正交方向，或数据协方差矩阵中特征值最大的特征向量——这与PCA完全相同。

PCA模型是一个对应于线性自动编码器的简单生成模型。这种对应关系表明，可能有一种方法使用更复杂的自动编码器来捕捉生成模型更复杂的特征。变分自动编码器（VAE）引入了变分方法来近似复杂概率模型中的后验分布，在这些模型中，求和或积分大量的隐藏变量是不可行的。其思想是使用从易处理的分布族中抽样的变分后验$Q(z)$作为真实后验的近似。例如，我们可能从具有对角协方差矩阵的高斯分布族中选择$Q$，并将其优化到尽可能接近真实后验分布$P(z|x)$。

对于我们的目的而言，“尽可能接近”的概念由KL散度定义，$D_{KL}(Q(z)||P(z|x)) = \int Q(z) \log \frac{Q(z)}{P(z|x)} dz$，它是$Q$和$P$之间对数比的平均值（相对于$Q$）。然后我们可以定义数据似然的变分下界$\mathcal{L}$（有时称为证据下界，或ELBO）：

```
$\mathcal{L}(z,x) = \log P(x) - D_{KL}(Q(z)||P(z|x))$
```

我们可以看到$\mathcal{L}$是$P(x)$的下界，因为KL散度是非负的。变分自动编码器提供了在深度学习设置下进行变分学习的方法。变分学习涉及相对于$P$和$Q$的参数最大化$\mathcal{L}$。对于变分自动编码器，解码器$g(z)$被解释为定义$\log P(x|z)$。
