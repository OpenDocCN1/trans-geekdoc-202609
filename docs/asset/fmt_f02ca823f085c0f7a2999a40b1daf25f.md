**1.** 公司聘请你作为安全团队的一员。公司正在针对移动设备实施新的政策和程序。下列哪项**不是**推荐的做法？

**A.** 制定 BYOD（自带设备）策略，并确保所有员工都了解并知晓该策略。

**B.** 将应用程序加入白名单，并确保所有员工都了解并知晓这些程序。

**C.** 允许越狱和 root 的设备接入网络，前提是员工已签署了相关政策。

**D.** 实施 MDM（移动设备管理）。

![Image](img/r.jpg)**C.** 自带设备（BYOD）和移动设备管理（MDM）正成为安全管理员日益头疼的问题。BYOD 是指员工可以将自己的智能手机、平板电脑和移动设备带到工作中并作为企业网络的一部分使用。移动设备管理（通常通过包含移动设备厂商功能的第三方产品来实现）是管理和保护内部移动设备使用的一种努力。

显然，移动设备进出网络会导致各种安全问题，可以采取许多常识性的步骤来解决。允许 root 或越狱设备——本质上这些设备可能安装了任何数量（无论有意还是无意）的问题——并不是明智之举。

![Image](img/w.jpg)

A、B 和 D 都是错误的，因为这些都是关于移动设备使用和管理的良好建议。其他良好的建议还包括：确保所有设备都启用了屏幕锁定密码、使用加密（针对传输中和静态数据问题）、确保业务数据和个人数据之间有清晰的界限、实施防病毒软件以及确保操作系统和补丁都是最新版本。

**A.** Aircrack

**C.** BBProxy

**D.** Paros Proxy

[www.praetoriang.net/presentations/blackjack.html](https://www.praetoriang.net/presentations/blackjack.html)

![Image](img/w.jpg)

A、B 和 D 都是错误的，因为这些工具没有用于黑莓攻击尝试。`Aircrack` 用于无线网络加密破解，而 `Paros` 是一个代理服务，但它们都不用于黑莓攻击攻击。`BBCrack` 并不存在。

### 4. 哪种类型的越狱允许用户级访问但不允许 iBoot 级访问？

![Image](img/w.jpg)

![Image](img/w.jpg)

### 8. 下列哪种是蓝牙中拒绝所有配对请求的模式？

**A.** 非配对（Non-pairing）

**B.** 不可发现（Non-discoverable）

**C.** 混杂（Promiscuous）

**D.** 蓝牙夹（Bluejack）

![Image](img/r.jpg) **A.** 当你在考试中遇到简单的问题时，庆祝一下吧。蓝牙有两种配对模式和三种发现模式。配对——与请求的设备配对的决定——可以开启（配对模式，接受所有请求）或关闭（非配对模式，拒绝所有请求）。发现——响应搜索请求并让查询端知道设备在线可用的决定——可以是完全开启（可发现模式，响应来自所有人的请求）、部分开启（有限可发现模式，仅在短时间内响应）或完全关闭（不可发现模式，从不回答查询）。

![Image](img/w.jpg) **B** 是错误的，因为不可发现是一种发现模式，而不是配对模式。

![Image](img/w.jpg) **C** 是错误的，因为“混杂”在这种语境下没有意义。

![Image](img/w.jpg) **D** 是错误的，因为蓝牙夹（Bluejack）指的是一种蓝牙攻击，攻击者可以利用目标手机的联系人，导致向目标发送匿名且未经请求的消息。
