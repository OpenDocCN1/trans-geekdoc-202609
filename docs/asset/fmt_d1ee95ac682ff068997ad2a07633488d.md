2.     z = layers.Input(shape=noise_dim)
3.     x = layers.Dense(units=4*4*1024)(z)
4.     x = layers.Reshape((4,4,1024))(x)
5.     for filter_size in [512,256,128,3]:
6.         x = layers.Conv2DTranspose(filters=filter_size,
7.                 kernel_size=5, strides=2, padding='same')(x)
8.         x = layers.LeakyReLU(0.2)(x)
9.         x = layers.BatchNormalization()(x)
10.        return Model(inputs = z, outputs=x)

1. def discriminator():
2.     img = layers.Input(shape=[64,64,3])
3.     x = layers.Conv2D(filters=128, kernel_size=5, strides=2,
4.                 padding='same')(img)
5.     for filter_size in [256, 512,1024]:
6.         x = layers.Conv2D(filters=filter_size, kernel_size=5,
7.                 strides=2, padding='same')(x)
8.         x = layers.LeakyReLU(0.2)(x)
9.         x = layers.BatchNormalization()(x)

## GAN 训练实现与挑战

### 损失函数

```python
cross_entropy = tf.keras.losses.BinaryCrossentropy(from_logits=True)

def discriminator_loss(real_output, fake_output):
    real_loss = cross_entropy(tf.ones_like(real_output), real_output)
    fake_loss = cross_entropy(tf.zeros_like(fake_output), fake_output)
    total_loss = real_loss + fake_loss
    return total_loss

def generator_loss(fake_output):
    return cross_entropy(tf.ones_like(fake_output), fake_output)
```

### 梯度计算

为了计算更新参数所需的梯度，我们可以使用两个梯度带：一个用于生成器，另一个用于判别器，因为它们是分别更新的。这两个带将分别用于计算相对于判别器参数和生成器参数的梯度，如以下代码所示：

```python
noise_dim = 100
G = generator(noise_dim)
D = discriminator()
noise = tf.random.normal([BATCH_SIZE, noise_dim])

with tf.GradientTape() as gen_tape, tf.GradientTape() as disc_tape:
    generated_images = G(noise, training=True)
    real_output = D(images, training=True)
    fake_output = D(generated_images, training=True)

    gen_loss = generator_loss(fake_output)
    disc_loss = discriminator_loss(real_output, fake_output)

gradients_of_G = gen_tape.gradient(gen_loss, G.trainable_variables)
gradients_of_D = disc_tape.gradient(disc_loss, D.trainable_variables)
```

## GAN 训练挑战

尽管从理论上证明了 GAN 的收敛性，但在实践中，达到这种极大极小博弈的均衡状态相当困难。通常，GAN 训练会遭遇三类问题：

1.  模型不收敛，且由于具有连续高维参数的非凸目标，训练过程不稳定。

2.  **模式崩溃**：生成器产生的图像种类很少，但图像质量很好，因此能够欺骗判别器。但这样的生成器毫无用处，因为它无法表征复杂的真实世界数据分布。生成器的所有输出都趋向于判别器当前认可为真实图像的单一点。一个可能的原因是，当我们相对于生成器进行最小化，然后相对于判别器进行最大化时，我们保持判别器不变，使得空间中的单个区域成为最可能为真实的点。

3.  生成器梯度消失导致训练缓慢。拥有一个完美的判别器时，模型对来自生成器的所有图像将有 `D(x) = 0`；因此，呈现给生成器的梯度为零，生成器不会发生任何更新。

## 缓解 GAN 训练问题的解决方案

以下是一些缓解 GAN 训练问题的技术：

### 特征匹配

可以约束生成器生成与真实数据某些描述性统计量（如均值和方差）相匹配的数据。我们使用一个额外的目标来训练生成器，使其匹配判别器中间层特征的期望值。这将防止判别器过拟合并缓解梯度消失问题。设 `f(x)` 表示判别器中间层的激活值。对于 DCGAN，我们可以取网络末端的任意全连接稠密层。生成器目标函数中的新项为 ![](img/2883.jpg)。

设 `conv2d_2` 为判别器中拥有 512 个滤波器的第二个卷积层的名称。我们可以将此层用作 `f(x)`，如以下代码所示，并更新生成器损失：

```python
from tensorflow.keras import Model
intermediate_D = Model(D.inputs, D.get_layer('conv2d_2').output)

def generator_loss(real_output, fake_output):
    features_fake = tf.reduce_mean(intermediate_D(fake_output))
    features_real = tf.reduce_mean(intermediate_D(real_output))

    return cross_entropy(tf.ones_like(fake_output), fake_output) \
        + tf.square(tf.norm(features_fake - features_real))
```

### 小批量判别

为避免模式崩溃，我们可以让判别器模型组合查看多个生成样本，而不是孤立地查看单个样本。其思想是：真实数据集的随机样本将拥有一组多样化的图像，因此真实图像的一个小批量将是多样化的。因此，如果我们以某种方式测量真实随机样本的图像的批内相似度，我们应该得到一个非常低的相似度分数。如果生成器足够好，来自生成器的样本也应具备这些特征。为了测量批内相似度，取判别器中间层的输出 `f(x)`，然后使用随机投影（如保距操作）将层输出投影到低维空间。

*   **在判别器和生成器中均使用类别标签信息**：条件 GAN 意味着生成器和判别器都可以基于某种辅助信息 `y` 进行条件化。这里，`y` 可以是类别标签或来自其他模态的数据。例如，`y` 可以是自由文本形式的图像描述，或结构化形式，或者 `y` 可以是图像类别。

## Wasserstein GAN (WGAN)

WGAN 基于我们在 *第 4 章：基础统计与概率论* 中遇到的两个分布 `images/2911.jpg` 和 `images/2912.jpg` 之间的 Wasserstein 距离或 **Earth Movers’ (EM) 距离（土方距离）**。我们已经看到，使用极大极小目标训练 GAN 等价于最小化 JS 散度：`images/2913.jpg`。WGAN 将优化问题重新表述为真实分布与生成分布之间 Wasserstein 距离的最小化：`images/2914.jpg` 和 `images/2915.jpg`。EM 距离是连续的，且几乎处处可导（即不可导点的集合非常少）。因此，我们可以将判别器训练至最优，并避免梯度消失问题。
