
在处理 (3.1) 中述的问题之前，注意，如果其中没有非负约束，该问题将相当简单。具体来说，最优性的必要条件是所有点的所有导数都相等。为了证明，假设相反 `f1'(x1) < f2'(x2)`。那么逐渐增加 `x1` 并相应地减少 `x2` 仍然满足等式的约束，因为会导致目标函数的减少。请注意，由于两个函数都是凸的，这种变化的大小在 `xi` 达到两个导数重合的点之前是有界的。当变量趋于无穷大时导数趋于无穷（或负无穷）的假设意味着该过程是可行的。总而言之，`xi` (`1 ≤ i ≤ n`) 成为最优解的必要条件是：对于某个常数 `c`，`f(xi) = c` (`1 ≤ i ≤ n`)。另一个显而易见的提到是，如果没有约束 `∑_{i=1}^n xi = 1`，那么最优解自然是 `xi = 0` (`1 ≤ i ≤ n`)。

这个问题的简化版给出的启示是：如果 `x1, x2 > 0`，则 `f1'(x1) ≠ f2'(x2)`。此外，如果考虑一个可行的 `f1'(x1) < f2'(x2)`，则希望增加 `x1` 并相应地减少 `x2`，直到两个导数重合。因此，必要的约束 `x2 ≥ 0` 可能并不限制 `x2` 的减少，可能需要在 `x2 = 0` 时停止。从这里我们学到，当 `x1 > 0` 且 `x2 = 0` 时最优性的必要条件是 `f1'(x1) ≤ f2'(0)`，而不是 `f1'(x1) = f2'(0)`。我们接下来展示这如何导出计算最优解的方法。

### 3.2.1 变量的逐渐增加

观察尝试 `xi = 0, 1 ≤ i ≤ n`。这是一个很好的选择，但它不满足约束 `∑_{i=1}^n xi = 1`。因此，至少有一个变量需要大于零。不失一般性地假设为了简单起见，所有不等式都是严格的。`f1'(0) ≤ f2'(0) ≤ … ≤ fn'(0)`，第一个从零开始增加的变量是 `x1`：由于一个变量的（无穷小）增加导致目标函数的增加是最小的。在这里，应该增加哪个 `xi` 呢？注意，`x1` 的增加意味着 `f1'(x1)`。然而，增加应该持续到 1 或者达到点 `x1 < 1`（此时 `f1'(x1) = f2'(0)`），以先者为准。在前种情况下，我们得出 `x1=1` 且 `xi=0, 2 ≤ i ≤ n` 是最优解。在后一种，我们还没有完成。我们仍然需要在保持这两个函数导数相等的情况下增加 `x1` 和 `x2`。我们这样做，直到 `x1+x2` 等于该值，或者公共导数等于 `f2'(0)`，以先者为准。在前种情况下，我们获得了最优解（注意 `xi = 0, 3 ≤ i ≤ n`）。在后一种，我们需要引入 `x3`。我们可以同时增加这三个变量，同时保持所有公共和 `x1+x2+x3` 等于 1，或者直到公共导数 `fi'(xi), 1 ≤ i ≤ 3` 等于 `f3'(0)`，以先者为准。当活动变量的和等于 1 时，停止该过程。注意，如果使用了 `xn`，则当 `f'i(xi) = λ` (`1 ≤ i ≤ n`)，对于某个常数 `λ` 且 `∑_{i=1}^n xi = 1` 时，停止增加函数。

**备注。** (3.1) 中提规划的最优解可能是 `x1 = 1` 且 `xi = 0, 2 ≤ i ≤ n`。当 `f'1(1) ≤ f'i(0), 2 ≤ i ≤ n` 时此类。最后，我们需要函数 `f1(x)` 的增长率小于所有其他函数的相应增长率。在实践中，获得凸函数是非常稀见的。然而，相反假设函数 `fi(x), 1 ≤ i ≤ n` 是凹的，即 `f''i(x) < 0, 1 ≤ i ≤ n`（但它们仍然是增加的）。在这里，增长率是负的，因此 `f1(x1)` 设置为比 `xi = 0` 更高的值，与将任何值设置为大于 0 相比，现在增加它更有价值。在这种情况下，最优解是 `x1 = 1` 且 `xi = 0, 2 ≤ i ≤ n`。换句话说，问题的性质决定了一个变量主导了其他变量。

### 3.2.2 选择活动变量

上述步骤得出结论，最优解具有以下属性：存在某些 `i, 1 ≤ i ≤ n`，使得 `f'j(xj) = λ` (`1 ≤ j ≤ i`) 对于某个 `λ`，且 `∑_{j=1}^i xj = 1`。如果提前知道 `i` 的值，问题将简化求解关于 `i` 个变量 `xj, 1 ≤ j ≤ i` 的非线性方程组。注意其中一个方程是 `∑_{j=1}^i xj = 1`。如何找到 `i` 的值？上一节的步骤提示了以下算法：首先尝试 `i=1`，`x1=1`。然后检查 `f'1(1) ≤ f'2(0)`。如果是，则达到了最优解。否则，寻找 `x1` 和 `x2`，使得 `f'1(x1) = f'2(x2)` 且 `x1+x2=1`。然后检查 `f'1(x1) < f'3(0)`。如果是，则获得最优解。否则，引入 `x3`，直到 `xn` 被引入，当所有 `f'j(xj)` 相等时 (`1 ≤ j ≤ n`)。显然，仍然需要满足约束 `∑_{j=1}^n xj=1`。这导致了一个唯一的最优解。

### 3.2.3 示例：加权变量方差最小化

设 `Xi` 为方差为 `σi^2, 1 ≤ i ≤ n` 的随机变量。假设它们独立且具有公共均值。在采样和预测中，都关注以下优化问题：

```
min_{wi, …, wn} Var(∑_{i=1}^n wi Xi),  s.t. ∑_{i=1}^n wi = 1.
```

实际上解得到了均值的最小方差无偏估计。目标函数很容易等于 `∑_{i=1}^n wi^2σi^2`。这是一个单变量均为凸的目标函数。此外，这些单变量函数在零点具有相同的导数。因此，如上一节所述，当所有 `wiσi^2` (`1 ≤ i ≤ n`) 具有相同的值，得到最优解。这意味着最优权重 `wi` (`1 ≤ i ≤ n`) 与方差成反比。因此，对于某个常数 `C`，`wi = C/σi^2, 1 ≤ i ≤ n`。常数 `C` 派生于等式约束 `∑_{i=1}^n wi = 1`。现在可以直接得出

```
wi = σi^2 / ∑_{j=1}^n σj^2,  1 ≤ i ≤ n.
```

注意非负约束是冗的。最后，很容易看出最优方差等于

```
∑_{i=1}^n 1/σi^2
```

即 `n` 个方差的调和平均值除以 `n`。根据最优性的定义，这比 `(1/n)∑_{i=1}^n σi^2`（即 `n` 个方差的算术平均值除以 `n`）更好，后者是我们给所有 `n` 个估计赋值时会得到的。这一事实说明了不同类型均值之间的不等性（见 (1.5)）。

### 3.2.4 示例：多项分布的 MLE

假设总体中的每个个体概率 `pk` (`1 ≤ k ≤ K`) 属于 `K` 个类别中的类别 `k`。取 `N` 个个体的随机样本。设 `Nk` 为这 `N` 个采样个体中属于类别 `k` 的随机数量。那么，

```
P(Nk=nk, 1 ≤ k ≤ K) = N! / (∏_{k=1}^K nk!) * pk^{nk},
```

只要 `nk ≥ 0` 且 `∑_{k=1}^K nk=N`。注意 `K=2` 的特殊情况是著名的二项分布。假设对 `pk` (`1 ≤ k ≤ K`) 的 MLE 感。因此，希望求解以下约束优化问题：

```
max_{pk, 1 ≤ k ≤ K} ∏_{k=1}^K pk^{nk}
s.t. ∑_{k=1}^K pk=1, pk ≥ 0,  1 ≤ k ≤ K,
```

或者等于最大化上述目标函数的对数：

```
max_{pk, 1 ≤ k ≤ K} ∑_{k=1}^K nk log pk,   (3.2)
s.t. ∑_{k=1}^K pk=1, pk ≥ 0,  1 ≤ k ≤ K.
```

`nk log pk` 是一个凹函数，其导数等于 `nk/pk` (`1 ≤ k ≤ K`)，注意到我们面对的是极大化问题，如果 `nk ≥ 1` (`1 ≤ k ≤ K`)，我们得出在最优解下

```
nk/pk = C,  1 ≤ k ≤ K,
```

对于某个常数 `C`，或者等于

```
pk ∝ nk,  1 ≤ k ≤ K.
```

约束 `∑_{k=1}^K pk=1` 结合 `∑_{k=1}^K nk=N` 的事实，意味着 MLE 为

```
nk/N,  1 ≤ k ≤ K.   (3.3)
```

## 3.3 队列示例

在本文未列出的某些假设下（细节请参见例如 [13, p. 61]），众所周知，对于一个到达速率为 `λ` 的泊松到达过程且服务均值为 `μ^{-1}` 的指数服务时间的单服务器队列，当 `λ < μ` 时，平均队列长度等于：

```
λ / (μ - λ). (3.4)
```

该值在 `λ` 中包含了服务时间。注意，`λ/(μ-λ)` 是关于 `λ` 和 `μ` 的凸函数。此外，它对 `λ` 单调递增，对 `μ` 单调递减。同时，`1/(μ-λ)` 是单个客户在系统中的平均时间（包括服务时间）。它是其两个变量中每一个的凸函数。在接下来的两个节中，我们将考虑关于多服务器队列的优化问题。

### 3.3.1 服务率的最优分布

假设存在一组 `n` 个服务器。已知服务器 `i` 的到达速率为 `λi`，`1 ≤ i ≤ n`。假设总服务率 `μ` 需要分配给这 `n` 个服务器。为了稳定性，需要 `μ > ∑_{i=1}^n λi`。用 `xi` 表示专门用于服务器 `i` 的服务率决策变量，`1 ≤ i ≤ n`。则最小化 `n` 个队列长度和的优化问题为：

```
min_{x1,…,xn} ∑_{i=1}^n λi/(xi - λi), s.t. ∑_{i=1}^n xi = μ,  xi > λi,  1 ≤ i ≤ n.
```

显然，`0 < xi < μi, 1 ≤ i ≤ n`。因此，最优解中导数相等的要求导致：

```
λi / (xi - λi)^2 = α,  1 ≤ i ≤ n,
```

对于某些 `α`。由此得出：

```
xi = λi + √λi / √α,  1 ≤ i ≤ n.   (3.5)
```

通过利用约束 `∑_{i=1}^n xi = μ`，我们可以解出 `√α` 并得到：

```
√α = (∑_{i=1}^n √λi) / (μ - ∑_{i=1}^n λi).
```

将此代入 (3.5)，我们得出：

```
xi = λi + (μ - ∑_{j=1}^n λj) * (√λi / ∑_{j=1}^n √λj),  1 ≤ i ≤ n.   (3.6)
```

这种最优分配可以表述为：首先，服务器 `i` 的速率应保证稳定性，即大于 `λi`。这是 (3.6) 中 `1 ≤ i ≤ n` 的第一项。一旦确定这一点，下一个问题是在 `n` 个服务器之间分配 `μ - ∑_{i=1}^n λi` 的速率。(3.6) 给出的答案是。如果约束为 `∑_{i=1}^n xi ≤ μ`，最优解仍然满足 `∑_{i=1}^n xi = μ`。

## 数据科学中的连续优化

不失一般性，假设服务器从快到慢排序为：`μ1 ≥ μ2 ≥ … ≥ μn`。显然，对于 `1 ≤ i ≤ j ≤ n` 的服务器对，如果 `xi = 0` 是最优解的一部分，那么自然 `xj = 0`。此外，注意 `lim_{xi→μi} fi(xi) = ∞`，因此上界 `xi < μi` (`1 ≤ i ≤ n`) 在最优解中永远不会取紧。假设前 1 个服务器是开启的，而其他不是，即 `xj > 0, 1 ≤ j ≤ i` 且 `xj = 0, i+1 ≤ j ≤ n`。注意 `i` 的下界是 `min_{1≤i≤n}(∑_{j=1}^i μj - λ)`。此外，注意最优解下 `i=n`（所有服务器开启）的可能性并未排除。那么，应用公共导数：

```
f'(xj) = 1 / (μj - xj)^2 = αi,  1 ≤ j ≤ i,
```

其中 `αi` 是最优到达率下的公共导数。因此：

```
xj = μj - √μj / √αi,  1 ≤ j ≤ i,
```

这结合约束 `∑_{j=1}^i xj = λ` 得到解：

```
xj = μj - (√μj / ∑_{k=1}^i √μk) * (∑_{k=1}^i μk - λ),  1 ≤ j ≤ i,   (3.8)
```

以及

```
xj = 0,  i+1 ≤ j ≤ n.
```

事实证明：

```
αi = (∑_{j=1}^i √μj)^2 / (∑_{j=1}^i μj - λ)   (3.9)
```

为了完整性，注意该解的目标函数值等于：

```
∑_{j=1}^i xj / (μj - xj) = αi * ( (∑_{j=1}^i √μj) / (∑_{j=1}^i μj - λ) )^{-2}  (此处原文公式逻辑可能有误，按原文翻译) …
```

*(注：根据指令，我仅翻译文本，原文公式保持原样。但根据上下文，此处应为描述与 `αi` 的关系)*

对 `λ` 求导该值并得到 `αi` 并不是偶然。这种导数捕捉了总服务率的微小变化对目标函数的影响。将在第 4.4 节讨论敏感性问题。注意最优目标 (3.10) 对 `μ` 的导数等于：

```
αi * ( (∑_{j=1}^i √μj) / (∑_{j=1}^i μj - λ) ) - 1,  1 ≤ k ≤ i.
```

这个值需要是负的，意味着投资在已开启服务器上是更划的。
