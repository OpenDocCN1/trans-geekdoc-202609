
# 联邦学习分类与协作式联邦学习在医疗领域的应用

Google 于 2016 年引入联邦学习（FL）作为一种前沿的机器学习（ML）策略 [1]，旨在解决当数据分布在众多客户端时训练集中式机器学习模型的问题。这种策略将解决客户端向 Google 发送大量数据的问题。提出的解决方案是向每个设备发送一个本地模型，为该客户端计算最优参数，并将计算出的权重发送回服务器。中央节点将聚合所有参数，对其求平均，并创建一个全局模型。在客户端之间分发一个小型模型，为海量数据传输场景下生成最优模型铺平了道路。联邦学习是一种 ML 方法，其中机器学习模型由位于不同站点的不同数据集创建，而无需共享训练数据。因此，个人数据将保留在客户端（医院、影像中心等）手中，降低了个人数据泄露的可能性。当生成的数据过大，无法集中传输和处理时，这种方法非常有用。由于在联邦学习中，医院和其他医疗组织等多方参与者在不共享数据的情况下训练模型，这在数据隐私是主要关注点且组织可能不愿共享敏感信息的医疗行业中非常有用。

## 水平联邦学习

水平联邦学习（基于样本的联邦学习）适用于数据集共享相同特征空间但样本空间不同的场景。这也称为同质联邦学习。在医疗领域，各医院的数据在样本上有所不同（数据来自不同患者），但特征相同，即患者信息 [3]。因此，这对应于水平联邦学习。

## 垂直联邦学习

在垂直联邦学习（基于特征的联邦学习）中，两个或多个数据集共享相同的样本空间，但特征空间不同。此类型也称为异质联邦学习。例如，如果我们收集同一组用户不同成像模态的相关数据，则对应于垂直联邦学习。

## 联邦迁移学习

在联邦迁移学习 [4] 中，特征空间之间没有相似性，而是任务相关，它基于其他领域的知识为某一领域构建模型。图 1 展示了不同类型的联邦学习方法。

联邦学习的数据来自多家医院/影像中心，数据种类繁多——不同医院的患者性别比例、年龄分布和种族各不相同 [5]。因此，从多源数据生成的模型比单一医院数据生成的模型更可靠。这是联邦学习的一大优势。另一个优势是，我们知道 AI 模型部署需要定期更新模型。因此，放射科医生定期标注数据以重新训练模型是必要的。然而，有了联邦学习，即使一些放射科医生忙于患者病例，也可以利用从其他医院接收的数据构建模型；这减轻了使用单个站点数据训练的负担。此外，随着新医院的加入协作，模型会自动扩展，这是一个额外优势，因为无需手动扩展系统。

医疗领域的协作式联邦学习可视为一种分布式隐私感知模型，其中数据不集中化，它使 `N` 个客户端（在本例中为医院/影像中心）能够使用去中心化数据构建深度学习（`DL`）模型或机器学习（`ML`）模型。敏感医疗数据驻留在客户端本身。从数学上建模，联邦学习可表示为：

$$
\min_{\mathbf{x}} F(\mathbf{x}), \text{ where } F(\mathbf{x}) := \sum_{k=1}^{n} p_k F_k(x)
$$

其中 `n` 为参与的客户端总数，`F[k]` 为第 `k` 个客户端的目标函数，`p[k]` 为每个客户端的影响权重，满足 `p[k] >= 0` 且 $\sum_{k=1}^{n} p_k = 1$。

在协作式联邦学习中，每个参与者自行训练模型，然后将训练好的模型发送至服务器。服务器将更新后的模型发送给所有参与者，参与者随后可使用共享模型训练全局模型并用于预测。这在识别医疗数据模式时特别有用。协作式联邦学习的一大优势是允许组织在比单独训练大得多的数据集上训练模型。这提高了模型准确性，并将带来更好的结果。此外，数据不在参与者间直接共享，因此敏感信息不被暴露。通过协作式联邦学习改善患者护理和结果，可更好地推动机器学习在医疗行业的应用。现在让我们看看联邦学习对不同利益相关者的益处。临床医生将从联邦学习方法中获益最大，因为异质数据用于训练，模型偏差会更小。对于居住在偏远地区的患者，全局训练模型将为获得更好的治疗提供途径 [6]。对于医院而言，即使是小型医院也有机会参与模型创建，并将获得更新后的模型。

## 2. 联邦学习在癌症诊断中的作用

癌症是全球主要死亡原因之一，受影响部位包括乳腺、肺、结肠和直肠、前列腺、皮肤等。当正常细胞转化为肿瘤细胞时，癌症便会发生，且通常分阶段发展，即从癌前病变到恶性肿瘤。若能早期发现，该疾病可有效治疗和治愈。X 光、CT 扫描、MRI 扫描和超声是一些用于诊断肿瘤的影像检查。已提出许多 `ML` 和 `DL` 技术用于肿瘤检测，分割技术用于从 MRI 图像中分割肿瘤。但为此目的训练 `ML`/`DL` 模型需要涵盖各种解剖结构、病理报告和输入数据的广泛数据库。

一些研究人员已将联邦学习应用于脑肿瘤相关研究。在文献 [7] 中，作者针对脑肿瘤分割提出了一种名为 `SU-Net` 的联邦学习架构，并使用来自 Kaggle 的“脑部 MRI 分割”数据集进行研究。他们在非联邦场景和由五个客户端组成的联邦场景中均实现了该网络，并将该架构与其他几种深度学习架构进行了比较。结果显示，在联邦场景下，`AUC`（曲线下面积）和 `DSC`（Dice 相似性系数）分别为 99.8% 和 78.7%，均高于非联邦场景。在文献 [8] 中，联邦学习使用包含经诊断为胶质瘤患者的 MRI 脑部扫描图像的 BraTS 数据集实现。胶质瘤是一种影响大脑和脊髓的肿瘤。他们的仿真结果显示，即使在数据集不平衡的情况下，联邦环境中也能达到 99% 的模型准确率。在文献 [9] 中，提出了一种深度学习框架 `3D-Unet` 模型，并通过从 10 家不同机构收集数据，在两种场景下评估了性能；研究人员发现，通过在不同机构间共享数据，模型达到了 99% 的准确率。

乳腺癌是影响女性的主要癌症类型之一。但如果能早期发现，则可降低死亡率。医生建议进行 X 射线乳腺钼靶检查以用于检测和随访。通过使用联邦学习，增加了数据集规模，并利用来自多个机构的异构图像进行研究。联邦学习被用于利用乳腺钼靶数据进行乳腺密度分类。他们使用 Cohen 线性加权 Kappa 系数在本地和联邦学习环境下评估性能，联邦学习模型取得了更好的性能 [10]。文献 [11] 提出了一种称为记忆感知课程联邦学习的 FL 变体，用于乳腺癌分类，该方法通过使用数据调度器惩罚错误预测，可极大地影响局部模型的一致性。在该方法中，他们结合了无监督域适应以应对域偏移。研究使用了来自不同客户端的三个数据集。

前列腺癌是影响男性的主要癌症类型之一。当某些腺体快速生长并从前列腺扩散到身体其他部位时，就会发生前列腺癌，且基于早期症状检测该癌症较为困难。为了在早期阶段进行检测，我们可以使用联邦学习。在文献 [45] 中，Yan 等人使用 `cycleGAN` 网络进行模型创建，利用来自八家不同机构的医学图像进行研究，在前列腺癌分类中实现了 98% 的准确率和 99% 的 `AUC`。研究人员研究了自适应联邦学习在皮肤肿瘤检测场景中的效果 [12]，并使用 `ISIC 2019` 数据集验证模型准确率。在此，作者使用各种边缘设备（如皮肤镜、激光显微镜和皮肤检查仪）收集的数据，这些数据被上传至云端进行训练和分类。在文献 [13] 中，提出通过从五家不同机构收集图像，利用联邦学习进行甲状腺结节肿瘤检测。实现了五种不同的深度学习架构，并在使用联邦学习前后进行了比较。他们展示了尽管存在数据异质性，联邦学习在保护数据隐私的前提下表现更好。在文献 [14] 中，提出了一种用于喉癌患者的 `Cox` 模型，并使用来自三个不同国家患者的数据作为输入。

文献 [15] 提出了一种用于癌症图像分析的加密联邦学习方法，采用同态加密。在此，权重在发送到服务器前会被加密。服务器将在这些加密值上执行模型创建，并将更新后的模型参数发送给客户端进行解密。只有相应的客户端知道解密密钥，因此服务器无法从客户端推断任何数据。因此，为敏感患者信息增加了一层安全保障。由于一切都在加密环境中进行，处理个人数据信息时，同态加密是最佳选择。为确保用于肿瘤检测的 FL 系统的问责制和公平性，可利用区块链技术。医学图像分割是癌症诊断中的重要功能。它是从医学图像中识别感兴趣区域（`ROI`）的过程。医学图像形式多样，部分文献专注于分割任务。对于脑肿瘤分割，文献 [16] 在 MRI 图像中实现了 `U-Net` 架构，并采用基于卷积神经网络的架构完成此任务。他们报告的 Dice 得分为 85%，并发现随着协作增加，得分显著提高。对于前列腺癌检测，文献 [17] 使用联邦学习采用 `3D 各向异性混合网络` 对 MRI 图像进行分割。当采用来自三家机构的数据进行研究时，他们获得了 88.9% 的 Dice 得分。

## 3. 联邦学习在 COVID-19 诊断中的作用

过去几年，COVID-19 大流行影响了世界各地人们的健康和机能。该疾病症状多种多样，从发烧或寒战、咳嗽、头痛、咽喉痛、味觉或嗅觉丧失、流鼻涕到呼吸短促或呼吸困难。但感染 COVID-19 肺炎的患者会发展为急性呼吸窘迫综合征（`ARDS`），即肺泡充满液体导致呼吸衰竭的状态，此类患者需要呼吸机辅助呼吸。主要筛查诊断方法是使用胸部 X 射线，机器学习和深度学习方法、计算机视觉在医疗领域的胸部 X 射线分类中做出了重大贡献 [18]。但我们知道，在机器学习或深度学习中，训练数据的收集、确保数据的隐私和安全是一大挑战。在此背景下，我们可以使用联邦学习来确保包括医学图像在内的医疗数据的隐私和安全。联邦学习被应用于与 COVID-19 相关的多种用例，如基于 CT 图像的 COVID 检测、死亡率预测、临床结局预测、基于 X 射线的 COVID 检测以及密集人群中的口罩检测 [3]。图 3 展示了利用来自不同医院和放射科中心的 X 射线，在 COVID-19 诊断中应用 FL 的具体场景。

他们使用的数据集是公开在 Kaggle 上的 COVIDx 数据集，其中 13,703 张图像用于训练模型，1,579 张图像用于测试模型。数据集中有三个标签：normal（正常）、covid pneumonia（新冠肺炎）和 non-covid pneumonia（非新冠肺炎）。实验分别在使用联邦学习和不使用联邦学习的情况下进行，观察到 `ResNet18` 架构在两种情况下均表现出最佳性能。观察到 `ResNeXt` 表现良好，而 `MobileNet_v2` 拥有较少的参数量。研究结论认为，文献 [20] 和 [22] 中讨论的模型最适合用于 Covid-19 诊断。

### 基于融合的联邦学习方法

文献 [4] 提出了一种基于融合的联邦学习方法，该方法通过根据客户端的训练时间选择性地挑选参与客户端，提高了服务器创建的全局模型的效率和性能。他们使用了从收集的数据集中获取的 3326 张图像，并将其划分为 2800 张用于训练，526 张用于测试。实验设置使用了三个客户端和一个服务器，客户端使用 `GhostNet`、`ResNet50` 和 `ResNet101` 三种模型进行本地训练，且模型使用六个不同的数据集进行训练。他们还为每个客户端使用了不同规模的数据集，分别为 600 张、900 张和 1300 张图像。对这些模型的准确率、训练时间和通信效率进行了分析，并应用了动态融合以通过减少模型上传次数来降低通信开销。为每个客户端分配特定的训练和模型创建时间；如果参与的客户端未在规定时间内完成，则服务器将在没有该客户端输入的情况下继续进行模型更新。此外，如果某客户端的性能比其上一轮次更差，则该客户端会请求服务器跳过该轮次的聚合。

### EXAM 联邦学习方法

文献 [2] 提出了一种名为 EXAM（Electronic Medical Record (EMR) chest X-ray AI Model）的联邦学习方法，用于预测 Covid-19 患者的临床结果。他们从全球 20 家机构收集数据，训练一个模型，利用实验室参数、生命体征和胸部 X 光片等各种参数，预测有症状的 Covid-19 患者未来的氧气需求。

### 区块链技术与联邦学习的结合

区块链技术与联邦学习相结合，开发了一种用于检测 Covid-19 的模型 [23]。该框架使用数据归一化技术对从各医院收集的数据值进行归一化，并采用基于胶囊网络的分割和分类来检测受 Covid-19 影响的患者。对于数据归一化，执行了空间归一化和信号归一化。空间归一化涉及 CT 扫描的大小和分辨率。CT 扫描仪的信号归一化过程处理每个体素的强度，这基于肺窗。研究使用了包含 34,006 个 CT 扫描切片（图像）的数据集，这些切片属于 89 例 Covid-19 感染患者。这种基于区块链的联邦学习网络从各种放射科中心和拥有不同类型 CT 扫描仪的多家医院协同学习。他们使用 `SegCaps` 算法 [44] 进行图像分割，并使用胶囊网络进行泛化。为确保隐私，医院仅与区块链网络共享梯度，区块链网络聚合梯度，服务器生成全局模型后，将更新后的模型分发给参与机构。实质上，在联邦环境中，在保持数据隐私的前提下，发生了来自各个本地模型的权重聚合。

### 利用区块链确保问责制与公平性

为确保问责制和公平性，引入了区块链技术 [24]。在 Covid-19 检测场景中，医院提供的 X 光图像细节不会被披露。因此，模型无法检查谁提供了可信数据，也无法确定哪些客户端正在投毒全局模型。通过将区块链技术与联邦学习相结合，使模型在上述场景中具备了问责制。如果训练数据或训练方法存在偏差，则会出现公平性问题。如果用于各种疾病模型创建的图像数量不同，则存在偏倚的可能性。在 Covid-19 情况下，正常 X 光图像的数量将多于阳性病例的 X 光图像。因此，存在可能导致模型不公平的偏倚风险。在这种情况下，区块链技术将提供更好的解决方案。文献 [25] 在联邦学习方法中利用深度强化学习，考察用于 Covid-19 研究的物联网设备的资源可用性和信任评分，以用于客户端选择。

### 聚类联邦学习在自动 Covid-19 诊断中的作用

在聚类联邦学习中，设备被组织成簇。每个簇基于其数据训练一个本地模型，服务器聚合它们以获得全局模型。然后将全局模型广播回每个簇中的设备，用于更新其本地模型。此过程重复进行，通过允许客户端获得更专业化的模型，可以达到大于或等于传统联邦学习的性能。Junaid 等人 [26] 在边缘计算网络中评估了聚类联邦学习在自动 Covid-19 诊断中的作用。边缘计算有助于在数据生成位置附近（如患者处的移动设备或医院的本地服务器）处理、分析和存储数据。将聚类联邦学习与边缘计算相结合的关键动机是从多模态数据中学习单一模型，例如，两种模态可能是 CT 图像和超声图像。研究使用了包含 X 光和超声图像的 2109 张图像，其中 80% 的数据用于训练，20% 用于测试，并采用了修改后的 `VGG-16` 架构。

### 基于遗传算法的聚类联邦学习
