## 6.3 LS 估计量的统计性质

第 3 章曾针对随机实参数这一特殊情况，简要涉及了 LS 估计量的一些统计性质。在此，我们将在更一般的背景下探讨这一问题。假设存在一个真实的（但未知的）参数向量 `θ[o]`，根据模型生成输出（因变量）随机变量（堆叠在随机向量 `y ∈ ℝ^(N)` 中）：

```
y = Xθ[o] + η
```

其中 `η` 是一个*零*均值噪声向量。请注意，我们假设 `X` 是固定且非随机的；即输出变量 `y` 的随机性完全源于噪声。在上述假设下，以下性质成立。

### LS 估计量是无偏的

参数的 LS 估计量由下式给出：

```
θ̂_LS = (X^T X)^(-1) X^T y = (X^T X)^(-1) X^T (X θ_o + η) = θ_o + (X^T X)^(-1) X^T η
```

#### LS 估计量的协方差矩阵

除了前面采用的假设外，设

$$\mathbb{E}\left\lbrack \boldsymbol{\eta}\boldsymbol{\eta}^{(T)} \right\rbrack = \sigma_{\eta}^{2}\mathbf{I},$$

即产生噪声样本的源是白色的。根据协方差矩阵的定义，我们得到

$$\Sigma_{\widehat{\boldsymbol{\theta}}_{LS}} = \mathbb{E}\ \left\lbrack (\widehat{\boldsymbol{\theta}}_{LS} - \boldsymbol{\theta}_{o}){(\widehat{\boldsymbol{\theta}}_{LS} - \boldsymbol{\theta}_{o})}^{T} \right\rbrack,$$

并将公式 (6.6) 中的 $\widehat{\boldsymbol{\theta}}_{LS} - \boldsymbol{\theta}_{o}$ 代入，可得

##### 协方差矩阵推导

$$

\Sigma_{\hat{\theta}_{LS}} = \mathbb{E} \left[ (X^T X)^{-1} X^T \boldsymbol{\eta} \boldsymbol{\eta}^T X (X^T X)^{-1} \right] = (X^T X)^{-1} X^T \mathbb{E}[\boldsymbol{\eta} \boldsymbol{\eta}^T] X (X^T X)^{-1} = \sigma_{\eta}² (X^T X)^{-1}.

$$
