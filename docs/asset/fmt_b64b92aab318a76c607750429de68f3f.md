# 引言

机器学习的概念源于人工智能，是一个完整的研究领域。它专注于开发自动化程序，从数据中获取知识，以做出诊断或预测。机器学习依赖于这样一个概念，即机器可以学习、识别趋势并在最少人工干预的情况下提供决策。这些机器随着经验而改进，并构建支配学习过程的原则。

机器学习有许多用途，例如营销、语音和图像识别、智能机器人、网络搜索等。机器学习需要大型数据集来训练模型并获得准确的预测。存在不同类型的机器学习，通常分为两类：监督学习或无监督学习。其他算法可以被标记为半监督学习或强化学习。

监督学习主要用于从分类或已标记的数据集中学习，而不是预测未知数据集的标签。相比之下，当训练数据集既未分类也未标记时，使用无监督学习，用于研究函数如何描述数据集中的隐藏模式。半监督学习结合使用了分类和未分类的数据集。强化是一种依赖试错过程的方法，通过识别环境中最准确的行为来提高其性能。

理解机器学习不是解决任何当前问题的万能方法至关重要。某些问题可以通过稳健的方法解决，而不需要依赖机器学习。对于数据较少且目标值可以通过确定性方法轻松定义的问题，在这种情况下，当很容易确定并编写驱动目标值的规则时，机器学习不是最佳遵循方法。

当无法制定规则来定义目标值时，机器学习的使用效果最好。例如，图像和语音识别就是机器学习最佳用例的完美范例。例如，图像具有许多特征和像素，简单的人类任务很难实现以识别图像。人类可以在视觉上识别并对图像进行分类。但是如何积累经验，但它们从何处学习呢？答案很简单——数据，这是驱动机器学习的燃料。没有数据，就没有机器学习。

另一个问题是——如果机器学习最早在 1959 年就被提到，为什么花费了这么长时间才成为主流？其主要原因是机器学习需要巨大的计算能力，更不用说能够存储海量数据的硬件了。直到最近几年，我们才实现了实践机器学习所需的。

## 机器学习与传统编程有何不同？

传统编程涉及将输入数据馈给机器，连同一个编写好的、经过测试的程序，以生成某些输出。而在机器学习中，输入数据和输出数据会在初始阶段（称为学习阶段）被输入机器。从那里开始，机器将自己完成编程工作。

如果现在听起来没意义，请不要担心。随着你深入阅读这本指南，一切都会变得豁然开朗。

## 为什么我们需要机器学习

如今，机器学习受关注的程度远超你的想象。它的主要用途之一是自动化需要人类智能的任务。机器只能通过机器学习来复制这种智能。

企业使用机器学习来自动化任务，以及自动化处理和创建数据分析模型。某些行业严重依赖海量数据，并利用这些数据来优化运营和做出正确的决策。机器学习使得创建模型来处理和分析大量的复杂数据并提供准确的结果成为可能。这些模型是可扩展且精确的，并且运行快速，允许企业在利用其巨大力量和提供的机会的同时，规避已知和未知的风险。

机器学习在现实世界中的许多用途包括文本生成、图像识别等，这些范围不断扩大，确保了机器学习专家成为极受追捧的人才。

### 机器学习是如何工作的？

机器学习模型被喂入历史数据，称为训练数据。它们从数据中学习，然后构建一个预测算法，对一组完全不同的数据（称为测试数据）进行输出预测，这些测试数据是作为输入给系统的。模型的准确性完全取决于数据的质量以及提供的数据量——优质数据越多，结果和准确性就越好。

假设我们有一个需要预测的非常复杂的问题。与其编写复杂的代码，不如将数据交给机器学习算法。这些算法会开发逻辑并提供预测。

### 机器学习从过去到现在的

如今，我们看到了许多机器学习运行的证据，例如自然语言处理和自动驾驶汽车（仅举两例）。尽管，机器学习已经存在了 70 多年，但一切都追溯到 1943 年。神经心理学家沃伦·麦卡洛（Warren McCulloch）和数学家沃尔特·皮茨（Walter Pitts）发表了一篇关于神经及其工作方式的论文。他们随后创建了一个电路模型，产生了第一个神经网络。

艾·图灵（Alan Turing）在 1950 年提出了图灵测试。这项测试用于判断计算机是否拥有真正的智能，通过测试需要计算机欺骗人类使其相信自己是一个人类。

亚瑟·塞缪尔（Arthur Samuel）在 1952 年编写了第一个计算机学习程序，这是一个跳棋游戏，计算机玩得越多就会变得越好。它通过研究动作，确定哪些动作属于获胜策略，然后将这些动作应用于自己的程序。

1957 年，弗兰克·罗森布特（Frank Rosenblatt）设计了感知器，这是一种模拟人类大脑思维过程的计算机神经网络。十年后，创建了一种名为“最近邻”的算法。这种算法允许计算机开始模式识别，尽管在当时非常基础。这对于销售员规划路线是非常理想的，确保他们所有的访问都能最短时间内完成。

巨大的变化是在 20 世纪 90 年代显而易见的。工作正在从几乎完全由知识驱动的方法转向更多数据驱动的方法。科学家们开始创建程序，允许计算机分析海量数据，从结果中学习并得出结论。

1997 年，由 IBM 创建的“深蓝”（Deep Blue）成为第一个在自己擅长领域击败世界冠军的计算机象棋手。该程序搜索了可能的步法，利用其计算能力选择最佳方案。仅仅十年后，杰弗里·辛顿（Geoffrey Hinton）创造了“深度”学习一术语，用以描述允许计算机识别图像和视频中文本和物体的新算法。

2012 年，亚历克斯·克里泽夫斯基（Alex Krizhevsky）与伊利亚·苏特斯维弗（Ilya Sutskever）以及杰弗里·辛顿共同发表了一篇论文。这篇具有影响力的论文描述了一种可以显著降低识别系统中错误率的计算模型。与此同时，Google 的 X Lab 开发出可以自主浏览 YouTube 视频并选择其中含有猫视频的算法。

2016 年，Google DeepMind 的人员创建了 AlphaGo 来下中国古代游戏——围棋，并与世界冠军李世石进行对决。AlphaGo 在五场比赛中击败了现任世界冠军四。

最后，2020 年发布了 GPT-3，这可能是世界上最强大的语言模型。该模型由 OpenAI 发布，可以生成功能完备的代码、编写创意小说、撰写良好的业务备忘录等等，其应用场景仅限于想象力。

## 机器学习基本概念

机器学习提供了许多功能，最突出的是以下这些：

- **自动化** —— 大多数邮箱账户都有垃圾邮件文件夹，你所有的垃圾邮件都会出现在那里。你可能会质疑邮箱提供商是如何知道哪些邮件是垃圾邮件的，答案是机器学习。在算法被教会识别垃圾邮件后，整个过程就是自动化的。

- **能够自动化重复任务**是机器学习最出特性之一。全球许多企业正在使用它来处理文书自动化。以金融领域为例，每天都需要执行大量数据密集且重复的任务，而机器学习承担了大部分工作，通过自动化提高了速度，并为重要的任务释放了员工时间。

- **更好的客户体验** —— 良好的客户关系对企业至关重要，有助于提升品牌忠诚度和提高参与度。企业实现这一点的最佳方式是提供更好的服务和客户体验。机器学习在这两个方面都发挥了作用。想想你在网上看到广告或访问购物网站时。大多数时候，这些广告与你搜索过的内容有关，购物网站会根据之前的搜索或购买推荐产品。机器学习是这些极其准确的推荐系统的背后，并确保我们能为每个用户定制体验。在服务方面，大多数企业使用聊天机器人来确保 24/7 全天候。有些机器人非常智能，客户甚至没有意识到不是在真人聊天。

- **自动化数据可视化** —— 如今，个人和企业每天产生海量数据，例如 Google、Facebook 和 Twitter。想想这些公司每天产生的数据量是巨大的。这些数据可以用于可视化关系，使企业能够做出有利于及其客户的决策。通过自动化数据可视化平台，企业可以从数据中获得有用见解，并利用它们改进客户体验和服务。

- **BI（商业智能）** —— 当机器学习的特性与数据分析（特别是大数据）相结合时，公司更容易找到问题的解决方案，并利用其发展业务和增加利润。几乎每个行业都在使用这种机器学习来提高运营效率。

## Pandas

Pandas 是一个用于管理和展示数据的库。“Pandas”这个名称源于术语“面板数据”（panel data），指的是 Pandas 创建类似于表格的序列的能力。

Pandas 可以将结构化数据组织为 dataframe（数据帧），这是一个二维数据结构（表格数据集），带有标记的行和列，类似于电子表格或 SQL 表。你还可以使用 Pandas 将外部数据集导入为 dataframe 而不影响源文件，因为修改是在你的开发环境中进行的。

## NumPy

NumPy 经常与 Pandas 结合使用，是“数值型 Python”的缩写。单独使用时，NumPy 用于管理多维数组和矩阵、合并和切分数据集，并提供了一系列数学函数，包括最小、最大、标准差和方差。

## Scikit-learn

Scikit-learn 是通用机器学习的核心库。它提供了一个丰富的浅层算法库，包括逻辑回归、决策树、线性回归、梯度提升等，以及广泛的评估指标（如平均绝对误差），以及数据划分方法（包括划分验证和交叉验证）。

Scikit-learn 还用于执行许多项重要的机器学习任务，包括训练模型以及使用训练好的模型预测测试数据。

## Matplotlib

Matplotlib 是一个可视化库，你只需要几行代码即可生成散点图、直方图、饼图、柱图、误差图和其他可视化图表。虽然 Matplotlib 提供了对线条样式、字体属性、颜色、轴和属性的详细控制，但默认的视觉呈现没有其他可视化库那样突出和专业，通常与 Seaborn 主题配合使用。

## Seaborn

Seaborn 是一个基于 Matplotlib 的流行 Python 可视化库。该库带有许多内置可视化主题和复杂的视觉技术，包括因变量和自变量的颜色可视化、复杂的热图、聚类图和矩阵对图（pairplots）。Seaborn 的预格式化视觉设计与 Matplotlib 的定制性相结合，生成出版级的可视化变得简单。

其他流行的可视化库还包括 Plotly（一个交互式可视化 Python 库）和 Cufflinks（直接与 Pandas 数据帧连接以创建图形和图表）。

## TensorFlow

如果不介绍 Google 的 TensorFlow，对流行机器学习库的总结将是不完整的。虽然 Scikit-learn 提供了一系列广泛的流行浅算法，但 TensorFlow 是深度学习和人工神经网络（ANN）的首选库。

TensorFlow 创建于 Google，支持各种先进的数值计算技术。通过在具有多达数个 GPU 实例的网络上分布计算，TensorFlow 支持高级算法，包括无法在单个服务器上运行的神经网络。

遗憾对于 Mac 用户来说，TensorFlow 仅兼容 Nvidia 显卡，而 Mac OS X 现在已不再提供此类显卡。Mac 用户仍然可以在 CPU 上运行 TensorFlow，但需要在云端运行工作负载以访问 GPU。

## 机器学习中的 Python

为了使用机器学习，我们需要一种能够向机器提供指令的编程语言。在本节中，我们将学习 Python 语言的基础知识、如何安装和启动 Python。我们还将学习一些 Python 语法以及运行用于机器学习的 Python 库的一些工具。首先，为什么要用 Python 而不是其他语言？

## 为什么用 Python 进行机器学习？

Python 是一种广泛使用的编程语言，原因有很多。主要原因之一是它是免费开源语言，这意味着每个人都可以使用。虽然它是免费的，但它是基于社区的，这意味着它由社区开发和支持以改进该语言。人们使用 Python 的其他原因包括：

1) 作为语法简单的可读语言，质量很高，

2) 可以移植到任何操作系统（例如 Windows、Unix）而无需极少修改，

3) 执行速度：Python 不需要编译，运行速度比类似的语言更快，

4) 集成：这意味着 Python 可以与其他程序集成，并被 C 和 C++ 调用。

Python 的另一个优势是自动的内存管理，且不需要声明变量。此外，Python 允许开发图形用户界面（GUI）、数据库编程、互联网脚本等许多应用程序。在本节中，我们将重点关注如何进行机器学习应用以及如何开始 Python。

## 如何开始 Python

Python 是一种脚本语言，与任何其他编程语言一样，需要一个解释器。后者是一个执行其他程序的程序。正如其名称所示，它作为计算机硬件的解释器来执行 Python 语言的指令。Python 以软件包的形式提供，可以从 Python 网站下载：`www.python.org`。在安装 Python 时，解释器通常是一个可执行程序。注意，如果你使用 UNIX 和 Linux，Python 可能已经安装，并且可能在 `/usr` 目录下。现在你已经安装了 Python，让我们探索一下如何运行一些基础代码。

要运行 Python，你可以打开操作系统的提示符（在 Windows 上打开 DOS 控制台）并输入 `python`。如果不起作用，意味着你的 Shell 路径环境变量中没有 `python`。在这种情况下，你应该输入 Python 可执行文件的完整路径。在 Windows 上，它看起来应该类似于 `C:\Python3.7\python`，在 UNIX 或 Linux 上，它安装在 `bin` 文件夹中：`/usr/local/bin/python`（或 `/usr/bin/python`）。

当你启动 Python 时，它会提供两行信息，第一行是使用的 Python 版本，如下例所示：

```
Python 3.7.1 (default, Dec 10 2018, 22:54:23) [MSC v.1915 64 bit (AMD64)]: Anaconda, Inc. on win32
```
