
# 推论 2.1
*对于非负整数* $k$，*存在* $\boldsymbol{R}$ *中的一个元素* $a_{k}$ *与之对应，它定义了非负整数集* $\mathbf{R}_{0} = \boldsymbol{R} \cup \{0\}$ *上的一个函数* $a$，*即*

$$\pmb{a} \colon \mathbb{N}_{0} \rightarrow \pmb{R},\ k \mapsto a_{k}$$

*对于非负整数* $n$，*令*

$$b_{n} = \sum_{k=0}^{n} \left[\begin{array}{c}n\\k\end{array}\right]_{q} a_{k} \text{ .} \tag{2.6}$$

*那么，*

$$a_{n} = \sum_{k=0}^{n} (-1)^{n-k} q^{\left(\begin{array}{c}n-k\\2\end{array}\right)} \left[\begin{array}{c}n\\k\end{array}\right]_{q} b_{k} \tag{2.7}$$

*反过来，假设* $b$ *是一个定义在* $\mathbb{N}_{0}$ *上且值域为* $\boldsymbol{R}$ *的函数：*

$$\pmb{b} \colon \mathbb{N}_{0} \rightarrow \pmb{R},\ k \mapsto b_{k}$$

*对于任意非负整数* $n$，*由 (2.7) 定义* $a_{n}$，*(2.6) 成立。*

*证明。* 设 `V` 为 `F_q` 上的无穷维向量空间。对于 `V` 的任意 `n` 维子空间 `W`，定义 `R` 中的元素 `a_n` 与之对应。这定义了一个定义在 `Lf(V)` 上且值域为 `R` 的函数。

$$\pmb{a} \colon \mathrm{Lf}\ (V) \rightarrow \pmb{R},\ \ W \mapsto \pmb{a}(W) = \pmb{a}_{d i m \ W}$$

对于任意 `W ∈ L_f(V)`，设 `dim W=n`。设 `U` 为 `W` 的子空间，并规定

`b(W)=\sum_{U \subseteq W} a(U)`

显然，若 `dim W=dim W'`，则 `b(W)=b(W')`。令 `b_dim W=b(W)`。由于 `W` 中 `k` 维子空间的数目为 `\left[\begin{array}{l}n \\k\end{array}\right]_{q}`，则 (2.8) 等价于 (2.6)。

由 (2.8) 并根据命题 2.2，

`a(W)=\sum_{U \subseteq W} b(U) \mu(U, W)`

根据定义，`a(W)=a_dim W`，`b(U)=b_dim U`。当 `dim W=n`，`dim U=k` 时，我们有 `μ(U, W)=(-1)^{n-k} q^{\binom{n-k}{2}}`。因此，可以从 (2.9) 推导出 (2.7)。

相反，根据

`b: L_f(V) → R`，`W ↦ b(W)=b_dim W`，

定义一个定义在 `L_f(V)` 上且值域为 `R` 的函数 `b`。对于任意 `W ∈ L_f(V)`，通过 (2.9) 定义 `a(W)`，其中 `U` 是 `W` 的子空间。当 `dim W=dim W'` 时，我们有 `a(W)=a(W')`。设 `dim W=n`，`dim U=k, 0 ≤ k ≤ n`。则 (2.9) 等价于 (2.7)，并根据命题 2.2，可以从 (2.9) 推导出 (2.8)，进而从 (2.8) 推导出 (2.6)。

## 命题 2.4
*设* `x` *为未定元，* `n` *为非负整数。则，*

$\prod_{i=0}^{n-1}\left(x-q^{i}\right)=\sum_{m=0}^{n}(-1)^{n-m} q^{\binom{n-m}{2}}\left[\begin{array}{l}n \\m\end{array}\right]_{q} x^{m}$

## 定义 2.16
设 `q` 为素数幂，`n` 为非负整数，`x` 为不定元。多项式

`g_n(x)=(x-1)(x-q) ⋯ (x-q^{n-1})`，若 `n ≥ 1`，

以及

`g_0(x)=1`

称为高斯多项式。那么，

$g_{n}(x)=\sum_{m=0}^{n}(-1)^{n-m} q^{\binom{n-m}{2}}\left[\begin{array}{l}n \\m\end{array}\right]_{q} x^{m}$

基于高斯求反公式。

## 命题 2.5
设 `q` 为素数幂，`n` 为非负整数，`x` 为未定元。则，

$$x^{n}=\sum_{k=0}^{n}\left[\begin{array}{c} n \\ k \end{array}\right]_{q} g_{k}(x) .$$

## 定义 2.17
设 `P` 为一个包含最小元素 `0` 的偏序集，且对于 `a ∈ P`，若 `l(0, a)` 存在，即从 `0` 到 `a` 的链可以细化为一条极大链。若包含 `a` 的极大链具有相同的有限长度，则称其为 `a` 的秩，记为 `r(a)`。若任意 `x ∈ P` 都有秩 `r(x)`，则称 `P` 具有秩函数 `r: P → N_0`，其中 `N_0` 是所有非负整数的集合。我们有时说 `P` 由 `r` 赋予秩。

容易理解，包含若干样本的集合 `P` 可以根据对偶假设用对偶性来表示，其中每个待学习的实例可以用特定值来表示。在这里，秩函数也可以被视为轨道极限的最大可能长度，轨道长度 `≤ r(x)`。

## 命题 2.6
设 `P` 为一个包含最小元素 `0` 的偏序集，并假设对于任意 `a, b ∈ P` 且 `a < b`，从 `a` 到 `b` 的链可以细化为一条极大链。若 `P` 满足 ID 条件，则 `P` 上存在秩函数 `r: P → N_0`。那么，(1) `r(0) = 0`，(2) 若 `a < b`，则 `r(b) = r(a) + 1`。反过来，若存在定义在 `P` 上且值域为 `N_0` 的函数 `r`，且满足 (1)，(2)，则 `P` 满足 ID 条件，且 `r` 是 `P` 上的秩函数。

*证明。* 假设 `P` 满足 ID 条件。对于任意 `a ∈ P`，由于从 `0` 到 `a` 的链可以细化为极大链，且它们的长度相等；因此，`l(0, a)` 必须存在。根据定义 2.17，`r(a) = l(0, a)`，且 `r: P → N_0` 是 `P` 上的秩函数。显然，(1) 成立。设 `a < b`。假设 `r(a) = n` 且

$$0 < a_{1} < a_{2} < \cdots < a_{n} = a$$

是 `0, a` 的极大链。那么，

$$0 < a_{1} < a_{2} < \cdots < a_{n} < b$$

是 `0, b` 的极大链，`r(b) = n + 1 = r(a) + 1`，即 (2) 成立。

现在，设 `r: P → N_0` 为满足 (1)，(2) 的函数。设 `a, b ∈ P` 且 `a < b`。假设

$$a = a_{0} < a_{1} < a_{2} < \cdots < a_{n} = b,$$

$$a = a_{0}^{l} < a_{1}^{l} < a_{2}^{l} < \cdots < a_{m}^{l} < b$$

是两条 `a, b` 的极大链。根据 (2)，

$$r(b) = r(a_{n}) = r(a_{n-1}) + 1 = \cdots = r(a_{0}) + n = r(a) + n,$$

$$r(b) = r(a_{m}^{l}) = r(a_{m-1}^{l}) + 1 = \cdots = r(a_{0}^{l}) + m = r(a) + m.$$

因此，`n=m`。这证明了 `P` 满足 JD 条件。`P` 的秩函数记为 `r'`。对于任意 `a ∈ P`，设

$0 < a_1 < a_2 < \cdots < a_n = a$

为 `0, a` 的极大链。根据定义 2.17，`r'(a)=n`。由于 `r` 满足 (1) 和 (2)，

`r(a) = r(a_n) = r(a_{n-1}) + 1 = ⋯ = r(0) + n = n`

那么，`r=r'`，即 `r` 是 `P` 的秩函数。

样本数据集 `P` 以矩阵形式表示。秩函数的计算，即计算对学习有用样本的数目，或在给定原始样本集经过某种映射变换后的数目，即新样本集 `P'` 的成员数目，可以被获得。$\square$

## 定义 2.18
设 `P` 为一个具有最小元素 `0` 和最大元素 `1` 的有限偏序集，且设 `P` 具有秩函数 `r`。那么，

$X(P, x) = \sum_{a \in P} \mu(0, a) x^{r(1) - r(a)} \qquad (2.11)$

称为 `P` 上的特征多项式。

注：在此，特征多项式可以被理解为学习子空间中样本的多项式表示。

### 2.1.5 LML 中的格
如第 1.1 节所述，学习子空间（具体学习问题）可以描述为包含若干节点的有向图或树。它是一种格结构，具有从初始状态到目标状态的路径（从根节点开始到叶节点的树分支）。路径上的节点关系不能任意交换。它体现在具体问题中，可以理解为节点中待学习的样本（分类），其中指定的算子是最优的，即有利于获得最优轨道。为了有效生成目标轨道，引入格（网格）的思想如下。

## 定义 2.19
若 `L` 中任意两个元素都有上界和下界，则 LML 中的样本数据按格排序。元素 `a` 和

`a ∨ b = sup {a, b}, a ∧ b = inf {a, b}`。

`a ∨ b` 读作 `a` 与 `b` 的上确界（join），而 `a ∧ b` 读作 `a` 与 `b` 的下确界（meet）。

当格 `L` 包含有限个元素时，它被称为有限格。

容易看出，`∨` 和 `∧` 是 `L` 的两个代数运算，对于 `L` 中的任意元素 `a, b, c`，以下性质成立：

- L1: `a ∨ b = b ∨ a, a ∧ b = b ∧ a` (交换律)；
- L2: `(a ∨ b) ∨ c = a ∨ (b ∨ c), (a ∧ b) ∧ c = a ∧ (b ∧ c)` (结合律)；
- L3: `a ∨ a = a, a ∧ a = a` (幂等律)；
- L4: `(a ∨ b) ∧ a = a, (a ∧ b) ∨ a = a` (吸收律)。

## 定义 2.20
设 `L` 为一个格，`S` 为 `L` 的非空子集。如果 `S` 在 `L` 的 `∧` 和 `∨` 运算下封闭，则称 `S` 为 `L` 的子格。利用 1.2 中给出的例子，`{m₃₂₁, m₃₂, m₃}` 是一个格，其上确界和下确界分别为 `m₃₂₁` 和 `m₃`。`{m₃₂₁, m₃₂}` 是 `{m₃₂₁, m₃₂, m₃}` 的子格。

## 定义 2.21
设 `L` 和 `L'` 为两个格，具有运算 `∨, ∧, ∨', ∧'`，设 `φ` 为从 `L` 到 `L'` 的双射。如果

`φ (a ∨ b) = φ(a) ∨' φ(b), φ (a ∧ b) = φ(a) ∧' φ(b)`,

则称 `φ` 为从 `L` 到 `L'` 的格同构映射。`L` 和 `L'` 同构，记为 `L ≅ L'`。

在学习过程中，由于算子（除法规则）的使用不同，会出现起始状态相同的路径，这意味着从某个状态出发，虽然路径不同，但最终状态相同。正如俗话所说，“条条大路通罗马”。如果你能通过路径变换找到一个函数 `φ` 得到另一条路径，那么这两条路径是同构的。至于选择哪条路径，取决于生成该路径的代价。

## 定义 2.22
格 `L` 被称为半模格。如果对任意 `a, b ∈ L`，

`a ≺ a ∨ b ⇒ b ≺ a ∨ b ,                       (2.12)`

则格 `L` 被称为下半模格。如果对任意 `a, b ∈ L`，

`b ≺ a ∨ b ⇒ a ≺ a ∨ b ,                          (2.13)`

则格 `L` 被称为上半模格。

## 定义 2.23
在包含最小元素 `0` 的格 `L` 中，覆盖 `0` 的元素称为 `L` 的原子。

## 定义 2.24
包含最小元素 `0` 的格 `L` 被称为原子格，且对于每个 `a ∈ L\{0}`，`a` 是 `L` 中某些原子的上界，即 `a = sup {p ∈ L; 0 ≺ p ≤ a}`。

## 定义 2.25
如果格 `L` 是一个不含无限链的半模原子格，则称 `L` 为几何格。

## 命题 2.8
*在几何格* `L` *中，对于任意* `x ∈ L \ {0}`，`*x` 是有限个原子的上界。*

*证明.* 假设存在 `x ∈ L \ {0}`，且 `x` 不是有限原子的上界。由于 `L` 是原子格，`x` 必须是无穷原子集 `A` 的上确界。那么，对于任意 `i = 2, 3, ⋯`，总存在 `p_i ∈ A`，使得

$$p_i \not\leq p_1 \vee p_2 \vee \cdots \vee p_{i-1}$$

考虑到 `L` 是具有最小元素 `0` 的半模格。我们有

$$0 < \cdot p_1 < \cdot p_1 \vee p_2 < \cdots < \cdot p_1 \vee p_2 \vee \cdots \vee p_{i-1} < \cdot p_1 \vee p_2 \vee \cdots \vee p_{i-1} \vee p_i < \cdots$$

这与 `L` 不包含无限链相矛盾。

以人脸识别为例，如第 1.2 节所述，我们从不同视角将眼睛、鼻子和嘴巴的局部特征刻画为两个偏序结构。用矩形区域表示这些局部特征时，它们不能交换以形成格结构的关系。一旦确定了图形的主键，它们不可交换的优先关系便形成一种格结构。一旦确定了图形的关键点，要从局部特征寻找额外特征，我们需要考虑两者之间的位置关系。如果嘴和鼻子的邻域相连，我们可以通过计算它们的交集和连接来确定另一部分的位置。 $\square$

## 2.2 LML 子空间轨道生成格学习算法
结论：根据给定的偏序集（即格）的基本概念，形成了 LML 子空间轨道生成格理论。在此基础上，本节介绍了用于轨道生成的广度优先、深度优先和启发式学习算法以及一些验证示例。

### 2.2.1 LML 子空间轨道生成格
轨道的形成可以从两个方向考虑：(1) 从给定的样本集合逐渐“到”目标函数以生成轨道；(2) 从目标函数反向回到样本集也可以生成所需的轨道。已证明可以通过包含关系和反包含关系找到子空间的偏序。

设样本数据映射到新数据集 `F_q`，即 `q` 个元素的有限域，其中 `q` 是素数幂。设 `F_q^n` 为 `F_q` 上的 `n` 维行向量空间。在 `F_q^n` 的所有子空间组成的集合 `L(F_q^n)` 中，子空间的偏序 `⊇` 通过包含关系确定，称为通过包含关系确定 `L(F_q^n)` 的偏序 `⊇`。那么，`L(F_q^n)` 对于所求的偏序 `⊇` 构成一个偏序集，记为 `L_O(F_q^n)`。在该偏序集中，存在 `F_q^n` 的子空间 `X` 和 `Y`：

$$X \vee Y = \cap \left\{ Z \in \mathrm{L}\left(\mathbb{F}_q^n\right) \mid X \cup Y \subset Z \right\}, X \wedge Y = X \cap Y.\tag{1}$$

因此，`L_O(F_q^n)` 是一个格，`0` 是其最小元素，`1` 维子空间是其原子，子空间的维度是其秩函数。
