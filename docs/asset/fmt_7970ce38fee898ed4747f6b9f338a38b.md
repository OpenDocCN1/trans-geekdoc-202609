
大多数网站加密了登录过程，但随后的请求在明文 URL 中带有用户的 Cookie。这些信息没有加密。如果网站加密整个用户会话，这就不会是一个风险。那么为什么网站不加密呢？原因可能是加密流量给运行网站的公司带来了更多的运营负担。对于高流量网站，它们需要昂贵的硬件来加速加密过程。另一个可能是加密也复杂化了来自合法执法机构请求的合法拦截。使用 `Cookie Cadger` 是获取 LinkedIn 等其他凭据的一种简单方法。运行该程序需要 `winzip`、`Wiener` 和 `Java`。

## 跨站脚本 (XSS)

XSS 是一种针对动态生成页面的注入类型，将恶意脚本注入到原本良的内容中。态势感知要求用户在点击疑网站时保持谨慎。这里有一个 XSS 示例：`index.php?name=<script>alert('hacked')</script>`

## 跨站请求伪造 (CSRF)

CSRF 是另一种客户端攻击，发生在恶意网站欺骗已通过验证的用户时。练习 8.5 展示了这种攻击的影响有多大。

## SQL 注入

攻击者寻找并利用易受 SQL 注入的数据库。SQL 注入发生在攻击者能够通过 SQL 注入漏洞向查询中插入 SQL 语句时。这允许攻击者利用系统上不安全的代码并将命令直接传递给数据库。这使得攻击者能够利用其权限执行各种活动。许多 SQL 注入攻击针对信用卡信息或其他敏感信息。

## 缓冲区溢出

缓冲区溢出发生在程序或进程试图在缓冲区中存储比其设计容量更多的数据时。想象你有一个 8 盎司的杯，并试图倒入 12 盎司的咖啡。它无法全部装下。当未验证缓冲区大小时，就会发生分配缓冲区的溢出。这可能导致段错误或错误。如果攻击者知道自己在做什么，他们可以尝试在栈上加载数据，并强制返回指针加载他们的代码。在这种情况下，攻击者能够在受害计算机上加载他们的代码。在 C 语言中，某些函数包括 `strcpy`、`gets`、`scanc`、`printf` 和 `strcat` 都是脆弱的。CASP 应该理解，在使用了 C 语言的情况下，应尽可能检查代码是否存在漏洞函数。如果您想了解更多信息，请查看 Aleph One 写的《Smashing the Stack for Fun and Profit》，地址：http://insecure.org/stf/smashstack.html。

防御缓冲区溢出的一种方法是实施“减速带”（speed bump）。这就是微软 `/GS` 编译时标志的作用。`/GS` 开在缓冲区和返回地址之间提供了一个虚拟的减速带。如果发生溢出，`/GS` 将负责防止其执行。

# 钓鱼

这是一种欺诈过程，通过在电子通信中冒充可信的实体，试图获取用户名、密码和信用卡详情等敏感信息。与之密切相关的是鱼叉式钓鱼（spear-phishing），它针对特定的个人或信息子集。通过为员工提供培训可以减少这两种威胁。必须教终端用户在共享敏感信息时保持谨慎。

# 间谍软件

任何秘密收集用户互联网使用情况信息的软件应用程序，然后通过发送与用户互联网使用历史类似的广告软件和弹出广告来利用这些信息。间谍软件会给公司带来巨额损失。

# 主叫 ID 伪造

伪造主叫 ID 的行为使得攻击者想要的任何号码显示为主叫者。VoIP 系统和在线服务使其变得非常容易。这种威胁很难防御，但如果你对这种情况感到不安，你随时可以在几分钟后回拨用户。这种技术可以用于检测使用伪造主叫 ID 的假电话，有时会导致警察和特种警察队（SWAT）进入目标住所，因为他们使用了一种被称为“特警误报”（swatting）的技术——例如由于虚假的人质情况进行的假电话。

# 预付欺诈

这种攻击也被称为尼日利亚洗钱计划。其概念基本上是你把银行账户发给他们，他们会乐意与你分享数百万美元。当然，我在开玩笑。这个想法是获取你的银行账户并抽空账户。应该对用户进行此类威胁教育，并在情况发生前识别它。

# 拒绝服务 (DoS)

当攻击者消耗你计算机上的资源用于其非预期用途时就会发生，从而阻止为了合法目的正常使用你的网络资源。这些攻击可以针对特定服务。SYN 洪水（SYN flood）被用于瘫痪 Web 服务器。完全的网络饱和可以阻止你的流量到达目的地。DoS 在有形和无形收益方面给公司带来成本。停机会导致销售损失和声誉受损。

# 分布式拒绝服务 (DDoS)

与 DoS 类似，攻击从多个和分布式的 IP 设备发起。DDoS 更难防御，因为它源自许多不同的设备，因此更难识别攻击者。这类攻击可以通过僵尸网络发起，并可能为了报仇、勒索或政治或黑客动机而发起。公司甚至可能付钱以防止成为 DDoS 的目标，正如报道所示：

https://www.boxbusiness.com/technology/2014/04/07/cyber-shakedown-hackers-unleash-mafia-style-extortion/

# 会话劫持

当黑客接管客户端和服务器之间建立的会话时就会发生。这些攻击可能由于加密薄弱或管理不善而发生。形势意识需要用户注意他们正在远程连接的服务类型以及他们所处的位置。在咖啡馆或机场等公共场所的用户需要使用额外的保护机制。使用经典工具 `hunt` 进行会话劫持的良好教程位于 www.binghamton.edu/~steflik/cs455/sessionhijacking.htm。

# 中间人攻击

当攻击者拦截并可能修改两个用户之间传输的数据时就会发生中间人攻击。这些攻击会给公司带来损失，因为攻击者可能会获取专有信息、公司机或未来的计划和项目。

# 逻辑炸弹

一种危险的攻击，因为它等待预定的事件或时间来执行其有效负载。形势意识是防御此类攻击的最佳手段。我的意思是，如果任何程序员或其他访问代码的个人被解雇或受到警告，这可能是一个问题。需要对代码或应用程序进行审查以标记此类攻击。这些攻击通常由内部人员或不满的员工发起；因此，应该使用良好的管理控制，例如职责分离和最小权限原则。

# 新兴威胁与问题

如果说有什么是不变的，那就是攻击者不断寻找新的攻击方法。自 2000 年以来，出现了一系列新兴威胁。新兴威胁是指那些变得日益突出且在过去未见的威胁。这些威胁包括：

- **僵尸网络**：一组受黑客控制的僵尸程序；这些机器人或僵尸可能被用于发送垃圾邮件、安装木马、尝试抛售式股票操纵，甚至发起 DDoS 攻击。终端用户可能会被访问恶意网站、点击错误的邮件附件，甚至是在点击社交网络网站上的链接。僵尸网络的共同点是，它们的设计初衷是为了赚钱。例如，2011年4月，Coreflow僵尸网络根据美国法院的命令被关闭。该僵尸网络曾用于从毫无备的受害者身上偷取美元。你可以在 http://arsstechnica.com/policy/news/2011/04/fbi-vs-coreflow-botnet-round-one-goes-to-the-fds.ars 阅读更多信息。图8.7展示了僵尸网络命令控制的一个示例。

### 恐吓软件 (Scareware)

这些是几类有限或没有益处的软件，它们通过不道德的营销手段出售给消费者。恐吓软件已经增长多年，并蔓到了 Mac 系统。恐吓软件的设计目的是恐吓你，从而购买虚假或恶意软件。

![](img/7868547987f5920cfe632b85047c64af_492_0.png)

大多数基于金融的犯罪攻击都会利用“钱骡”（money mule）。钱骡无非是将被盗的资金或货物从一个国家转移到另一个国家或从一个人转移到另一个人。大多数人在被捕后装作不知，声称他们不知道自己在做错事。在一个案例中，美国检察官指控了37名嫌疑钱骡，他们参与了与 Zeus 僵尸网络相关的非法活动。你可以在 www.theregister.co.uk/2010/09/30/zeus_money_mules_charged/ 阅读更多信息。

### 短信诈骗 (SMiShing)

一种犯罪活动形式，利用手机的短信（短消息服务）和社会工程技术来发送虚假短信，旨在欺骗用户点击虚假链接。

### 智能手机攻击

手机正成为一个日益增长的目标。智能手机比几年前强大得多，今天，它们是非常小巧且功能强大的计算机。尽管多年来一直对手机病毒、蠕虫和僵尸程序发出警报，但这些威胁尚未以主要方式显现。几个因素导致了此类恶意软件的进展慢于预期。这些因素包括带宽限制、市场碎片化，以及手机生命周期比电脑短得多。

阻碍此类恶意软件传播的因素正在发生变化。更多的智能手机供应商从仅提供语音服务转向增加数据量。像 iPhone 这样的平台占据了智能手机市场的大份额。必须记住，许多威胁是以渐进的方式演变的。昨天的概念证明可能变成明天的主流攻击。App Store 中以及某些 Android 应用程序中甚至出现过恶意应用程序的例子。其中一些被用于跟踪用户，而另一些则旨在记录用户活动。对于那些决定在供应商边界之外运行的人（例如对手机越狱的人），还存在其他风险。越狱是移除智能手机供应商实施的限制的过程，这些限制控制着操作系统以及可以加载的程序。

### 搜索引擎投毒 (Search Engine Poisoning)

搜索引擎投毒或黑帽 SEO 是一种技术，攻击者通过这种技术确保他们的网站出现在查询结果列表的高，从而将用户重定向到受感染的站点。

### 恶意软件工具包 (Crimeware Kits)

恶意软件工具包是完整的攻击工具包，为那些缺乏技术专长来发起钓鱼和恶意攻击的准犯罪分子提供了所需的一切。这些工具包由一个构建器（builder）组成，使用户能够创建能够进行网页注入的恶意软件。基础工具包的价格约为 1000 美元或更多并不罕见。你可以将基础工具包比作购买 Windows 8.1 简化版；如果你想要更多功能，可以升级到 Windows 8.1 旗舰版。恶意软件工具包的工作方式非常相似。支付额外费用，你可以购买 Explorer 或 Firefox 表单抓取器、加密插件，甚至是远程键盘记录器。这些工具包附带了用户手册、管理控制面板和用于验证工具包的序列号。

### 点击劫持 (Clickjacking)

这种在线威胁正在不断增加，其工作原理是隐藏链接或按钮的真实目的。如果黑客可以欺骗你点击一个看起来无害的链接，受害者实际上执行了完全不同的内容，通常会导致任意代码的远程执行。

在过去的几年里，终端用户的云存储选择成倍增加。其中许多基于云的服务为普通用户免费提供或以低成本提供。这里列出的只是其中少数此类服务：

- Microsoft OneDrive
- Google Cloud Storage
- Apple 的 iCloud

如果你的公司决定在工作场所允许社交网络，它应该由一项规定了哪些允许、哪些不允许的政策来控制。你还应该针对这些服务提供一些基础培训和最佳实践，说明哪些允许不允许。这些应该包括：
