**选项 A 错误。** 备份和恢复库存系统是一种被动且效率的方法。它无法提供实时库存更新。

**选项 B 错误。** 依赖客户报告库存差异不是主动的，可能会导致负面的的客户体验和潜在的销售损失。

**选项 D 错误。** 手动更新既耗时又容易产生人为错误，并且不支持实时库存水平同步。

# 问题 459
在经历一系列钓鱼攻击后，BetaTech 公司的 IT 部门注意到几名员工在使用可以猜测的密码。安全团队决定建议使用密码管理器来帮助员工创建和记住强密码。在这种背景下，使用密码管理器的**主要**益处是什么？

- (A) 密码管理器自动更新操作系统
- (B) 密码管理器可以生成并存储复杂密码
- (C) 密码管理器总是能防止钓鱼攻击
- (D) 密码管理器允许在多个平台重复使用强密码

解析 459。 **正确答案：B. 密码管理器可以生成并存储复杂密码。** 密码管理器可以自动生成符合各种标准的复杂密码（例如长度、使用特殊字符、避免易于猜测的术语），并安全地存储它们。这有助于用户为使用的每个服务维护强且唯一的密码，而无需记住每一个密码。

**选项 A 错误。** 密码管理器的设计目的是生成、检索和存储复杂密码，而不是为了更新操作系统。

**选项 C 错误。** 虽然密码管理器可以通过安全存储密码并在识别的网站上自动填充来帮助降低成功钓鱼攻击的风险，但它们并不总是能防止钓鱼攻击，特别是用户被欺骗在假网站上输入凭据时。

**选项 D 错误。** 密码管理器的主要益处之一是确保用户为每个应用程序或服务都有唯一的密码。在多个平台重复使用密码（即使是强密码）也会带来安全风险。

# 问题 460
某公司的在线零售网站面临 DDoS 攻击，导致了严重的停机。他们目前的设置是在部署缓解措施之前对流量峰值进行手动验证。未来哪种变化可以**最有力**提高公司对此类攻击的反应时间？

- (A) 教育用户报告网站加载缓慢的情况
- (B) 每小时手动备份网站数据
- (C) 部署具有自动 DDoS 缓解功能的 Web 应用防火墙 
- (D) 增加网站带宽以处理流量峰值

解析 460。 正确答案：C. 部署具有自动 DDoS 缓解功能的 Web 应用防火墙。部署具有自动 DDoS 缓解功能的 Web 应用防火墙 (WAF) 可以立即检测并缓解攻击流量，与等待手动验证相比，显著提高了了对攻击的反应时间。

选项 A 错误。依赖用户报告加载缓慢是被动的，不能保证对 DDoS 攻击做出快速响应。

选项 B 错误。备份网站数据对于恢复很重要，但它不能防止或缓解活跃的 DDoS 攻击，也无法提高反应时间。

选项 D 错误。仅仅增加带宽可能不足以防御 DDoS 攻击。攻击者仍然可以溢出增加后的容量，而且它没有解决快速检测和缓解的需求。
