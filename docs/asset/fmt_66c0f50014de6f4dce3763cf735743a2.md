
where `card{⋅}` denotes the cardinality of the set. In other words, the number of zero components of the unique minimizer cannot be smaller than the dimension of the null space of `X`. Indeed, if this were not the case, the unique minimizer could have fewer zero elements than the dimension of `null(X)`. This means one could always find a `z ∈ null(X)` that is zero at the same locations where the unique minimizer has zero components, while not being identically zero, i.e., `z ≠ 0` (Problem 9.12). However, this would violate (9.22), which holds as a strict inequality in the case of uniqueness.

#### Definition 9.1

A vector `θ` is called `k`-sparse if it has at most `k` nonzero components.

#### Remark 9.3

*   If the minimizer of (9.21) is *unique*, then it is a `k`-sparse vector with
    `k ≤ N`.
*   This is a direct consequence of Remark 9.2 and the fact that for the matrix `X`:
    `dim(null(X)) = l − rank(X) = l − N`.
*   Hence, the number of nonzero elements of the unique minimizer is at most equal to `N`. All the previously stated results become clear if one resorts to a geometric interpretation.

Then the solution lies in the two-dimensional (hyper)plane described by the above equation. To obtain the minimum `ℓ₁` solution, we keep increasing the size of the `ℓ₁` ball. (⁶³)

Note that uniqueness is related to the specific geometry and orientation of the affine set, which is the set of all possible solutions of the underdetermined system of equations. For the squared `ℓ₂` norm, the solution is always unique. This is due to the (hyper)spherical shape formed by the Euclidean norm. Mathematically speaking, the squared `ℓ₂` norm is a strictly convex function. This is not the case for the `ℓ₁` norm, which is convex but not strictly convex (Problem 9.13).

This example is very instructive. *If we sense (observe/measure) an unknown parameter vector with the appropriate sensing (input) data, the true value of the parameter vector can be revealed using the `ℓ₁` norm, even though the system of equations is underdetermined, provided the true parameter is sparse.* This becomes our new objective, namely to investigate whether the above statement can be generalized, and under what conditions. In this case, the choice of the regression variables (which we call sensing vectors), and hence the input matrix (which we will increasingly refer to as the sensing matrix), acquires additional importance. It is not enough for the designer to care only about the rank of the matrix, i.e., the linear independence of the sensing vectors. One must ensure that the corresponding affine set of solutions has such an orientation that its contact with the `ℓ₁` ball (as the ball grows from zero until it meets the plane) is "gentle"; that is, they meet at a single point, and more importantly, at the *correct* point, which represents the true value of the sparse parameter vector.

Usually in practice, the columns of the input matrix `X` are normalized to unit `ℓ₂` norm. Although the `ℓ₀` norm is insensitive to the values of the nonzero components of `θ`, the `ℓ₁` and `ℓ₂` norms are not. Therefore, in attempting to minimize the respective norm while satisfying the constraints, components corresponding to columns of `X` with high energy (norm) will be favored over others. Consequently, the latter become more likely candidates to be driven to zero. To avoid this, the columns of `X` are normalized to unity by dividing each element of the column vector by its respective (Euclidean) norm.

## 9.6 Uniqueness of the ℓ₀ Minimization Solution

Our primary objective is to derive *sufficient* conditions that guarantee the uniqueness of the `ℓ₀` minimization solution, defined in Section 9.5.

### Definition 9.2

The **spark** of a full-rank `N × l` (`l ≥ N`) matrix `X`, denoted by `spark(X)`, is the **minimum** number of **linearly dependent** columns of `X`.

According to the above definition, *any* `m < spark(X)` columns of `X` are necessarily **linearly independent**. The spark of a square, `N × N`, full-rank matrix equals `N + 1`.

### Remark 9.5

*   Contrary to the rank of a matrix (which can be easily determined), its spark can only be obtained by a combinatorial search over all possible column combinations of the matrix (see, e.g., [15, 37]). The concept of spark has been used in the context of sparse representations, termed the "unique representation property" (see [53]). The name "spark" was coined in [37]. An interesting discussion relating this matrix metric to metrics used in other disciplines is given in [15].
*   Note that the concept of "spark" is related to the concept of the minimum Hamming weight of a linear code in coding theory (e.g., [60]).
