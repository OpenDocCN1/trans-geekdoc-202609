
Quorum 兼容 `Raft` 以及 `Istanbul BFT`——一种 BFT 共识的变体。与 CFT 算法（使用区块提议者或领导者决定是否批准区块）不同，`Istanbul BFT` 算法要求对每个区块进行多次投票。使用 BFT 时，网络能够处理三分之一节点的故障。因此，在竞争对手或其他网络参与者不可信的情况下，可以使用 `Istanbul BFT`。大多数在其平台上提供 Quorum 的 BaaS 供应商（如 `Alibaba` 和 Microsoft `Azure`）均使用 `Istanbul BFT` [19]。

## 选择区块链即服务合作伙伴的标准

如今市场上有多家 BaaS 供应商。然而，选择最佳平台需要广泛的研究和分析。由于市场缺乏适当的指南和最佳实践，选择过程颇具挑战性。选择供应商时应考虑以下几个重要因素 [32]：

*   **过往记录**：组织在选择供应商时，应选择在 BaaS 部署方面拥有丰富经验的供应商。可通过查察其投资组合、主要现有客户、审计结果和客户见证来获取供应商的过往经验。
*   **质量承诺**：质量承诺是组织为成功实施项目必须考虑的关键因素，因为低质量的基础设施可能导致业务失败。当消费者信任并购买产品和服务时，服务提供商应为其客户提供最优质的服务。因此，组织必须确保供应商遵守质量、既定流程和标准。
*   **易用性**：用户友好的流程和系统显著影响业务成果。因此，企业应确保启用区块链的系统易于员工采用。
*   **集成性**：除了多层业务流程、工作流等，公司应采用可与系统集成且不干扰遗留网络的 BaaS。
*   **流程控制**：考虑实施计划是否涵盖任何安全漏洞。控制数据流、计算资源、主动监控工具等几项关键控制，对于维护一个能抵御黑客攻击的安全环境至关重要。谈到分布式账本，组织应争取最稳健的结果。
*   **后端服务**：后端服务——主流技术和流行服务功能的集成——应进行广泛评估。企业应关注数据安全、成本控制、集成和流程控制等功能。
*   **快速配置**：快速配置有助于快速部署区块链网络，同时将过程中的风险降至最低。Web 浏览器差异、防火墙、数据库、硬件和应用服务器等障碍使网络快速部署变得复杂。因此，企业应确保 BaaS 供应商能有效、高效地部署和管理区块链环境，且错误或缺陷极少。
*   **数据安全**：企业必须确保数据受到保护，并保持在 BaaS 供应商建立的平台边界内。
*   **成本控制**：企业还应审查供应商提供的定价和部署后支持选项。选择订阅价格合理的供应商，与评估隐性费用并根据预算限制做决定同等重要 [2]。

## BaaS 平台

如前几节所述，BaaS 模式使组织能享受智能合约平台的优势，而服务提供商通常处理基础设施。下文讨论几家可与企业集成的热门商业 BaaS 供应商。

### IBM BaaS

`IBM` 于 2017 年在 `IBM Cloud` 上提供基于 `Hyperledger Fabric` 的 BaaS 解决方案，此后推出了两个平台版本：`IBM Blockchain Platform 2.5.2` 和 `IBM Blockchain Platform for IBM Cloud`。`IBM Blockchain Platform 2.5.2` 允许在任何 `Kubernetes` 平台上部署区块链组件，而 `IBM Blockchain Platform` 仅允许部署在 `IBM Cloud Kubernetes` 集群上 [18]。`Kubernetes` 在 `IBM BaaS` 架构中充当基础设施 [22]。开发人员可借助 `Bluemix` 创建区块链应用程序。使用 `Bluemix`、`Hyperledger Fabric` 和 `IBM Cloud`，用户可开发 `DevOps` 并部署 `Chaincode`。同时，可使用 `Chaincode` 维护业务逻辑，`Chaincode` 使用 `Go` 和 `Node.js` 编写。`IBM BaaS` 智能合约支持 `JavaScript`、`Go` 和 `Java` 语言 [27]。`IBM` 区块链平台支持各种运营工具，以确保对平台的治理和灵活性 [22]。用户对区块链组件的操作、治理和实施拥有完全控制权。`IBM BaaS` 解决方案的主要目标是为企业提供高可用性、开箱即用的企业级就绪状态和灾难恢复选项 [27]。

### Oracle

`Oracle` 提供基于 `Hyperledger Fabric` 的 `Oracle Blockchain Cloud Services (OBCS)`，这是一个开源平台。

#### BaaS 解决方案概览

##### Oracle BaaS

Oracle 提供的 BaaS 解决方案具有两大核心能力：开箱即用的沙箱环境和独立软件供应商。开箱即用的沙箱环境面向开发者。独立软件供应商 (ISV) 使区块链技术的部署变得简单，无论是在入网引导还是智能合约生成方面，且不受供应商限制 [27]。平台采用基于组合的架构，这意味着所有系统和流程均设计为支持 API 启用。Oracle 区块链云服务运行在一个验证节点和账本的区块链网络上，通过执行代表业务逻辑的智能合约来响应查询。外部应用程序可通过客户端 SDK 或 REST API 调用交易或运行查询。达成共识后，交易将被添加到区块中。交易透明且共享，但可根据其等级限制访问权限。此前，排序节点由一组 Kafka 和 Zookeeper 机器集群管理。然而，该架构在应用于云环境时日益显得资源密集。因此，推出了共识插件 RAFT 来管理排序服务，并使其做好面向企业级生产网络的准备。借助 RAFT，一组排序节点协同工作，基于动态领导者模型创建排序区块。因此，成员组织的参与最为公平和统一，即使节点数量庞大亦是如此。此外，Oracle 还提供更优质的加密服务以保护敏感信息 12, [16]。

### Microsoft Azure BaaS

作为与 Consensys（一家领先的云计算服务提供商）合作的一部分，Microsoft 也于 2015 年底在其 Azure 平台上提供了以太坊区块链即服务 (EBaaS)。Azure BaaS 支持 Ethereum、Corda、Quorum 和 Hyperledger Fabric [27]。借助 Azure BaaS，客户还可部署带有分布式账本的企业级模板，且无需承担费用。然而，当在区块链上构建应用程序时，客户需自行负责开发和成本。Microsoft Azure 在 BaaS 方面提供三种产品：Azure 区块链服务、Azure 区块链工作台和 Azure 区块链开发工具包 [12]。

#### Azure 区块链服务

Azure 区块链服务是一项完全托管的区块链服务，允许客户在几分钟内创建和运行区块链网络。Azure 以简化的形式为基础设施管理和网络治理提供完整的端到端解决方案，并内置联盟网络。Azure 区块链服务支持 Ethereum Quorum 账本，采用伊斯坦布尔拜占庭容错共识机制。客户无需关心底层基础设施，可专注于应用开发和业务逻辑。作为其退役计划的一部分，Azure 区块链服务将于 2021 年 9 月由 Consensys 的 Quorum 区块链服务取代 [28]。

#### Azure 区块链工作台 (ABW)

Azure 区块链工作台是一组 Azure 服务，允许企业开发和管理区块链应用程序，并将其业务流程跨组织传递。Microsoft 的 Azure 区块链工作台促进了区块链应用程序的开发，使开发人员能将精力集中在构建业务逻辑和智能合约上。Azure 区块链工作台因其集成能力而广受欢迎，这些能力利用工作台的 Web 应用程序和 REST API 简化了区块链应用程序的创建。通过这些 API，客户可以替换不同的分布式账本技术、存储产品和数据库。此外，ABW 可与所有主流 Microsoft 产品集成，包括 Excel、SharePoint、Office 365 等。

#### Azure 区块链开发工具包 (ABDK)

区块链开发工具包包含代码示例，是一个旨在与 Azure 服务集成的 GitHub 存储库。作为 Azure 平台的一部分，Microsoft 提供了一个基于 Microsoft 无服务器技术并与 Microsoft 及第三方 SaaS 集成的区块链开发工具包。除了能够连接到多个数据源外，Azure 区块链开发工具包还可与遗留应用程序和协议集成，例如 Excel、Office 365 等。借助 Azure 区块链工作台和 Azure 区块链开发工具包提供的 RESTful API，与区块链节点交互从未如此简单和安全 [12]。

### Amazon AWS BaaS

借助 Amazon Managed Blockchain，AWS 提供了一个完全托管的平台即服务，用于利用开源分布式账本技术（如 Ethereum 或 Hyperledger Fabric）构建和部署区块链网络。该平台为客户提供多种实例类型选择，具有可定制的计算和内存容量，以适应其区块链应用程序需求。网络启动通过 AWS 区块链模板执行。网络可用后，Managed Blockchain 的投票 API 将允许成员就网络参与进行投票。随着新成员的加入，Managed Blockchain 提供启动和配置多个对等区块链的能力，这些节点将处理交易请求并存储账本副本。作为托管区块链生态系统的一部分，AWS 密钥管理服务充当证书颁发机构。因此，加入 Managed Blockchain 的新用户无需设置硬件安全模块。凭借网络可扩展性，网络可适应增加的交易量和负载。此外，新成员无需特殊硬件即可加入云端。Amazon Managed Blockchain 作为 Hyperledger Fabric 框架的一部分，用于增强“排序服务”，从而在区块链网络间建立信任。量子账本数据库 (QLDB) 记录区块链上所有未提交的交易，确保透明且安全的排序服务 [12]。

### Alibaba BaaS

Alibaba Cloud 是当今市场上最著名且专利最丰富的供应商之一。其 BaaS 平台基于 Alibaba Cloud 容器服务的 Kubernetes 集群构建，支持 Hyperledger Fabric、Ethereum 和金融级区块链技术蚂蚁链。除了支持公有部署外，该基础设施还支持私有部署。借助 Alibaba Cloud 区块链即服务，用户可创建生产级区块链环境，并可图形化管理运维操作。

得益于其分布式数据中心，Alibaba BaaS 在全球范围内提供服务。由于联盟区块链网络建立在多租户隔离原则之上，每个参与者均可独立管理其资源。此外，部署简单易行，易于与其他云服务和产品集成，并拥有灵活的生态系统，可支持广泛的应用程序和插件。Alibaba Cloud 区块链即服务包含默认的 Anti-DDoS 基础防护服务。供应商提供的额外服务包括产品溯源、供应链金融和数据资产追踪，以跟踪数据所有权。该供应商提供的服务可定制以满足特定业务需求，同时保持先进的安全性和隐私保护 [1]。

## BaaS 业务用例

企业发现，订阅服务而非自建平台，是利用技术的一种更具成本效益且通常更有效的方式。同样，BaaS 使项目能够快速从概念验证阶段扩展到全面生产阶段。以下是一些值得注意的 BaaS 解决方案用例，展示了该解决方案为何既通用又宝贵：

### 利用 Amazon Managed Blockchain 实现食品溯源：雀巢

雀巢是世界上最大的食品饮料公司之一，也是世界上最大的咖啡生产商，其分销网络覆盖 190 多个国家。供应链透明度对消费者至关重要，因为他们有兴趣了解食品的生产和加工地点。在比较消费者价值和行业需求时，利用实时数据收集查看从农场到包装的整个过程，以及共享咖啡品鉴的不同属性（如产地、种植园类型、咖啡种类、烘焙程度等）变得越来越重要。

#### 雀巢与 Amazon Managed Blockchain
