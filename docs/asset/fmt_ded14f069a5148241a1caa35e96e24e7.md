
系数的大小，特别是高阶项的系数，非常大。这意味着模型已经对高阶项进行了一些微调，以便能够扭曲并为训练数据制作出完美拟合的多项式。因此，我们可以通过限制系数的大小来缓解这个问题。这是通过在 SSE 最小化中添加类似 `||w||_2` 或 `||w||_2²` 的约束来实现的，如下所示。使用拉格朗日乘数技巧，我们向 SSE 添加一个正则化项来控制过拟合，使得要最小化的误差函数采取以下形式：

`SSE + λ||w||_2²`

我们可以选择 `||w||_2` 为欧几里得范数或 `||w||_2²`，在这种情况下，我们仍然有闭式解：`w = (X^T X + λI)^{-1} X^T y`。这种正则化项的选择在机器学习文献中称为**权重衰减**，在顺序学习算法中也是如此；它使权重取接近零的小值。这在统计文献中也称为**岭回归**。参数 `λ` 是一个必须仔细选择的超参数。以下代码展示了 9 次多项式的岭回归，其中我们选择 `λ = 0.01`。非常小的 `λ` 值允许模型精细地拟合每个数据点上的噪声，从而抵消了正则化的效果。

```
1. from sklearn.linear_model import Lasso, Ridge
2. reg = Ridge(alpha=0.01).fit(features, y)
3. line = reg.predict(features)
```

如果我们选择 `||w||_2` 为 `||w||_1` 范数，则称该回归为**Lasso 回归**。它具有将某些系数 `w_j` 驱动为零的特性；如果我们选择 `λ` 足够大，这将导致一个稀疏模型，其中相应的基函数变得冗余。

> **注意**：过拟合是 MLE 的一个不幸特性，可以通过正则化或贝叶斯参数估计来缓解。在贝叶斯估计中，由于我们将先验信念纳入优化，它自然包含正则化项。感兴趣的读者可参阅延伸阅读[2] 第 3 章 第 3.3 节。

## 偏差-方差权衡

正如我们在合成数据情况下所见，完美模型是 `y = sin(2πx)`。通常，我们可以假设回归函数是对未知函数 `f(x)` 的估计，使得：`y = f(x) + ε`，其中 `ε ~ N(0, σ²)`。将我们的线性回归模型表示为 `ŷ = w^T φ(x)`，点 `x` 处的期望平方误差为：`E[(ŷ - f(x))²]`。这里，`ŵ` 作为样本值的函数可被视为一种统计量，它估计真实的模型参数 `w`。利用前面讨论的偏差-方差分解，我们可以将其重写为 `Bias²` 和 `Variance` 之和，即 `E[(ŷ - f(x))²] = Bias²(ŷ) + Var(ŷ)`：

`E[(ŷ - f(x))²] = (E[ŷ] - f(x))² + E[(ŷ - E[ŷ])²]`

这里，`E[ŷ]` 是样本统计量 `ŷ` 的估计。`ŵ` 的估计基于某个数据集 `D`。因此，我们需要多个数据集来计算这些期望。对于合成 `sin` 数据集，我们可以生成多个数据集，并通过控制正则化参数 `λ` 来改变模型复杂度，观察偏差和方差之间的关系。**图 5.8** 在 `ln λ` 中描绘了这一点：

![](img/biasVarTradeoff_3.jpg)

**图 5.8：** *作为模型容量函数的偏差-方差权衡*

我们生成了 200 个大小为 25 的数据集，并用不同的正则化参数 `λ` 拟合单独的岭正则化模型。我们使用了 11 次多项式基函数作为基础模型。随着 `λ` 的变化，我们得到具有不同容量的模型，因为较高的 `λ` 值会使高阶项的系数可以忽略不计，因此我们最终得到更简单的模型，这可能导致欠拟合数据。同样，在最左侧，我们有非常低的 `λ` 值，这允许高阶项有较大的系数，导致过拟合。从 **图 5.8** 的模型容量图中可以看到，`E[(ŷ - f(x))²]` 的最小值出现在 `ln λ = -4.5` 左右，这接近于在测试数据上给出最小误差的值。以下是此偏差-方差权衡的代码。此处使用的 sin 函数定义在 **图 5.7** 之前的代码部分中。

```
1. datasets = [sin(25) for i in range(200)]
2. d = 11; bias_vars = {};
3. for lam in np.linspace(0.001, 1.1, 100):
4.     preds = []; biases = []; variances = []; sses = [];
5.     for X, y in datasets:
6.         polynomial_features = PolynomialFeatures(degree=d)
7.         features = polynomial_features.fit_transform(
8.             np.expand_dims(X, axis=1))
9.         reg = Ridge(alpha=lam).fit(features, y)
10.        line = reg.predict(features)
11.        preds.append(line)
12.        sses.append(np.mean(np.square(line - np.sin(2*np.pi*X))))
13.    E_y = np.mean(np.array(preds), axis=0)
14.    bias_square = np.mean(np.square(E_y - np.sin(2*np.pi*X)))
15.    variance = np.mean(np.square(line - E_y))
16.    tot = bias_square + variance
17.    test_error = np.mean(sses)
18.    bias_vars[np.math.log(lam)] = {'$bias²$+variance': tot,
19.        '$bias²$': bias_square, 'variance': variance,
20.        'test_error': test_error}
21. pd.DataFrame(bias_vars).transpose().plot()
```

在实践中，我们只见过单个观测数据集。那么，我们如何利用这种偏差-方差权衡来选择最优超参数 `λ` 呢？我们可以使用 k 折交叉验证或留一法验证，通过实验选择最佳的 `λ`。

## 逻辑回归

对于分类问题，因变量是离散的，因此**线性模型**中的正态性假设不成立。所以我们不能直接应用线性回归模型进行分类。如果我们能转换因变量使其取连续值，也可以在转换后验证正态性假设。假设我们的因变量是二元的，即我们有一个二分类问题。类别标签可以写为 `y ∈ {0, 1}`。我们可以将其视为概率：当类别标签为 1 时，`P(y=1|x)`，对于 `y=0` 时，`P(y=0|x)`。然而，概率值必然位于区间 `[0, 1]` 内，因此不能假设为正态分布。我们知道优势比可以取任意正实值，并通过以下公式与概率相关：有利于类别 1 的优势比 `odds = P(y=1|x) / P(y=0|x)`。现在，对数优势比或 logit `log(odds)` 可以在 `(-∞, ∞)` 中取任意实值。利用这种变换，我们得到线性模型：

`log(P(y=1|x) / P(y=0|x)) = w^T φ(x)`

`P(y=1|x) = σ(w^T φ(x))`

> **注意**：`σ(z) = 1 / (1 + exp(-z))` 函数称为**Sigmoid 函数**，呈 S 形，其取值范围为 (0,1)。我们将类别 `y=1` 的后验概率表示为因变量线性组合的 Sigmoid 函数。

为了可视化这一点，我们将通过仅获取鸢尾花数据集（**virginica** 和 **versicolor**）类别作为目标，**花瓣长度**作为唯一因变量来预测这两个类别，来考虑一个单因变量的二分类示例。以下代码展示了我们在上一章创建的鸢尾花数据框上的这些数据准备步骤：

```
1. df_sample = df[((df['flower']=='virginica') | (df['flower']=='versicolor'))][['petal length (cm)', 'flower']]
2. # convert to binary labels
3. df_sample['y'] = df_sample['flower'].apply(lambda x: 1.0 if x=='virginica' else 0.0)
4. df_sample.plot.scatter(x="petal length (cm)", y='y', marker='*')
```

**图 5.9 (左)** 显示数据图，**图 5.9 (右)** 显示 y 值如何围绕 S 形 Sigmoid 曲线分散：

![](img/logistic_1.jpg)

**图 5.9：** *逻辑回归*

y 值围绕 Sigmoid 曲线的分散程度始终 < 1。因此，现在我们满足了正态性假设，在方差界限下，恒定方差假设也在很大程度上得到了满足。

我们现在可以通过最小化以下内容来找到线性方程的系数：

平方误差和：`∑(y_i - σ(w^T φ(x_i)))²`。然而，这很难优化，因为它是一个 `non-convex`（非凸）函数。我们也可以通过标准的 `MLE`（极大似然估计）技术来估计参数。在这里，`y_i` 是二元的，可以被视为服从伯努利分布的随机变量。

因此，对数似然采取以下形式：

`∑[y_i log(σ(w^T φ(x_i))) + (1-y_i) log(1-σ(w^T φ(x_i)))]`

`L(w) = -∑[y_i log(σ(w^T φ(x_i))) + (1-y_i) log(1-σ(w^T φ(x_i)))]` 被称为 `binary cross entropy`（二元交叉熵）误差或损失函数。我们将需要 `sigmoid` 函数的导数：

`σ'(z) = σ(z)(1-σ(z))` 以最大化 `L(w)`。

设置：

`y_n = σ(w^T φ(x_n))`

量 `y_n` 表示 `y_n` 属于类别 1 的概率，从现在起我们将其表示为 `t_n`。在向量形式中，我们可以将 `E(w)` 的梯度写为：

`∇E(w) = Φ^T (y - t)`

其中 `Φ` 是 `N × M` 设计矩阵，其第 `n^(th)` 行由 `φ(x_n)^T` 给出，`y` 表示概率预测向量 `y`。

这不是一组线性方程，因此我们不能像线性回归那样通过求逆系数矩阵来求解并得到闭式解。`sigmoid` 函数使其成为非线性方程。然而，`E(w)` 函数在此处是凹的，正如我们稍后将看到的，因此它有一个唯一的最小值。从一组随机权重 `w^(0)` 开始，我们迭代地更新权重如下：

`w^(τ+1) = w^(τ) - η ∇E(w^(τ))`

这里，`η` 是学习率。这与线性回归的情况形式非常相似。

> **注意：** 我们可以通过检查其海森矩阵是否为正定来检查 `E(w)` 的凸性。海森矩阵可以写为 `H = Φ^T R Φ` 请参阅进一步阅读部分[8]，其中 `R` 是一个 `N × N` 对角矩阵，其元素为 `y_n(1-y_n)`，因为 `y_n = σ(w^T φ(x_n))`。由于对角矩阵的每个元素均为正，因此海森矩阵是正定的。`logL` 可以通过一种基于海森矩阵的高效迭代技术 `Newton-Raphson`（牛顿-拉夫逊法）来最小化，更新公式为 `w^(new) = w^(old) - H^{-1} ∇E(w)`。

## 多类别逻辑回归

逻辑回归可以通过构建 `K-1` 个二元分类器扩展到多类别分类，每个分类器将第 `k^(th)` 类中的点与不在该类中的点分开。这被称为**One-vs-Rest (OvR)**（一对其余）方案。为此，我们可以选择一个类作为枢轴类，例如最大的类别标签 `K`，并建模属于类别 `k` 与属于类别 `K` 的几率对数如下：

`log(P(C_k|x) / P(C_K|x)) = w_k^T φ(x)`

两边同时取指数：

`P(C_k|x) / P(C_K|x) = exp(w_k^T φ(x))`

由于 `∑_k P(C_k|x) = 1`，将所有 `K-1` 个方程相加，我们得到：

`P(C_K|x) = 1 / (1 + ∑_{k=1}^{K-1} exp(w_k^T φ(x)))`

另一种公式是假设类别变量服从多项分布。使用贝叶斯定理，我们可以写为：

`P(C_k|x) = exp(w_k^T φ(x)) / ∑_j exp(w_j^T φ(x))`

其中 `w_K = 0`。这个归一化指数 `exp(w_k^T φ(x)) / ∑_j exp(w_j^T φ(x))` 用 `softmax` 表示，也称为 `softmax function`（Softmax 函数），因为我们可以将其视为一个平滑的“`max`”函数：如果 `w_k^T φ(x) >> w_j^T φ(x)`，则 `softmax ≈ 1` 和 `softmax ≈ 0`。

与我们将几率对数建模为线性函数的逻辑回归相比，我们表示 `P(C_k|x) = softmax(w_k^T φ(x))`。这里，`w_k` 表示对应第 `k^(th)` 类的权重。

现在，我们可以将每个数据点 `x_n` 的类别标签 `t_n` 表示为 1-of-K 表示或独热编码，代表具有 `K` 个类别的多项随机变量的一个实现。目标向量是一个 `N × K` 矩阵 `T`，似然由下式给出：

`L(W) = ∏_n ∏_k y_{nk}^{t_{nk}}`

其中 `y_{nk} = P(C_k|x_n)`。`E(W) = -∑_n ∑_k t_{nk} log y_{nk}` 函数称为**categorical-cross-entropy**（类别交叉熵）误差或损失函数。`softmax` 的导数（雅可比矩阵）由 `∂y_{nk}/∂a_{nj} = y_{nk}(δ_{kj} - y_{nj})` 给出，其中 `δ_{kj}` 表示 `K × K` 单位矩阵的第 `k,j` 个条目。利用这一点，我们可以计算 `E(W)` 关于其中一个权重向量 `w_k` 的梯度：

`∇_{w_k} E(W) = ∑_n (y_{nk} - t_{nk}) φ(x_n)`

## 泊松回归

泊松回归类似于逻辑回归，不同之处在于因变量是遵循泊松分布的观测计数。因此，`Y` 的可能值为非负整数：0, 1, 2, 3 等。泊松回归的一个应用示例是研究与各种环境条件和稀释度相关的细菌计数。显然，因变量打破了正态性条件，因此我们需要应用某种变换。使用对数变换，我们可以使用线性模型来建模因变量均值的对数。

假设我们有一个包含 `n` 个观测值 `y_i` 的样本，它们可以被视为独立的泊松随机变量 `Y_i`，具有 `E[Y_i] = λ_i`，并且我们可以将均值 `λ_i` 的对数建模为因变量 `x_i` 的线性函数。那么，我们有以下模型：

`log(λ_i) = w^T φ(x_i)`

我们可以使用 `MLE` 来估计参数 `w`。数据的对数似然由下式给出：

`log L(w) = ∑_i (y_i log(λ_i) - λ_i - log(y_i!))`

`∇log L(w)` 的梯度采取与逻辑回归相似的形式：

`∇log L(w) = ∑_i (y_i - λ_i) φ(x_i)`

此外，`log L` 是一个凸函数，可以使用梯度下降或其他基于梯度的方法（如 `Newton-Raphson`）进行优化。

在泊松分布中，我们有 `E[Y] = Var[Y] = λ`，所以，我们假设等离散。即均值和方差相等：`E[Y] = Var[Y]`。但在实践中，看到 `overdispersion`（过度离散）即 `Var[Y] > E[Y]` 的情况非常常见。**Negative Binomial (NegBin)**（负二项）模型可以以额外参数为代价容纳过度离散和欠离散。

> **注意：** 在提到的所有四种线性模型变体（线性、逻辑、泊松、负二项）中，我们可以看到一个共同模式：
>
> *   响应变量 `y` 遵循指数族分布（例如二项、泊松、多项、正态）
> *   一个线性模型通过链接函数 `g` 将响应变量的期望联系起来，使得 `g(E[y]) = w^T φ(x)` 和 `E[y] = g^{-1}(w^T φ(x))` 满足 `E[y] = μ`。
>
> 这种表示被称为**Generalized Linear Model (GLM)**（广义线性模型）。进一步阅读[9]中提到的 Python `statsmodel glm` 包提供了所有这些线性模型变体的实现。

## 线性模型的可解释性

线性模型易于解释，这使它们非常流行。我们可以证明模型为何有效，并深入洞察数据中隐藏的模式，这些模式可以为通过特征工程或探索更新的数据源来进一步改进模型播下种子。我们将从最简单的线性模型开始，其恒等基函数 `φ(x) = x` 为直线：`ŷ = w_0 + w_1 x` 这里，`ŷ` 表示目标变量的预测值，`y` 表示目标的真实值。预测误差为 `ε = y - ŷ`。这里，`ŵ` 表示系数的 `MLE` 估计。显然，`ŵ_0` 和 `ŵ_1` 都是随机变量，因为它们是目标随机变量 `y` 的函数。根据模型假设，`y = w_0 + w_1 x + ε`，因此 `ŵ = (X^T X)^{-1} X^T y`。将 `y = w_0 + w_1 x + ε` 代入 `MLE` 估计 `ŵ = (X^T X)^{-1} X^T y` 中，我们得到：

`ŵ = w + (X^T X)^{-1} X^T ε`

系数 `ŵ_1` 可以像之前一样计算：

`ŵ_1 = ∑(x_i - x̄)(y_i - ȳ) / ∑(x_i - x̄)²`

现在：

`E[ŵ_1] = w_1`

该系数代表直线的斜率，即预测变量值每变化一个单位，目标变量 `y` 变化的因子。
