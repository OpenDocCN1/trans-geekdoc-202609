
为了演示目的，我们只对文本字段进行了编码。在实际编码中，你必须对每个允许用户输入信息的表单元素进行编码。如果你现在加载页面并在文本字段中输入 `<script>alert('Hacked');</script>`，你会发现提交表单时，警报框不再弹出。相反，你会在表单下方得到以下输出：

`You entered <script>alert('Hacked');</script> into the text field.`

`<script>` 和 `</script>` 被视为普通文本，没有 HTML 意义。

如果你在网页上右键点击并选择“查看网页源代码”，你会在 `</form>` 标签下方看到这一行 `You entered &lt;script&gt;alert('Hacked');&lt;/script&gt; into the text field.`。这显示了 `<` 和 `>` 字符的编码。

## 8.2 `$_SESSION`

到目前为止，本章涵盖了很多内容。在之前关于 PHP 表单处理的节中，你学习了 `$_GET` 和 `$_POST` 超全局变量。在本节中，我们将讨论另一个全局变量 `$_SESSION`。在 PHP 中，会话（session）是一种可以在多个页面间访问的信息存储方式；这些信息存储在 `$_SESSION` 超全局中。与 `$_GET` 和 `$_POST` 超全局变量一样，`$_SESSION` 超全局是一个关联数组。该数组存储在服务器上，并在会话持续期间对网站上的所有页面可用。为了演示会话的使用，我们需要创建两个页面：`session.php` 和 `session2.php`。我们现在就开始。

首先，在 `htdocs` 中创建一个名为 `session.php` 的新文件，并向其中添加以下代码（添加行号是为了参考）：

```php
1 <?php
2 session_start();
3
4 $_SESSION['myFavFood'] = 'Pizza';
5 $_SESSION['myFavDrink'] = 'Cola';
6 $_SESSION['myFavColor'] = 'Orange';
7
8 #updating a session variable
9 $_SESSION['myFavDrink'] = 'Beer';
10
11 #deleting a session variable
12 unset($_SESSION['myFavColor']);
```

在这里，我们在第 2 行使用名为 `session_start()` 的内置函数来启动一个新会话。如果尚未创建会话，该函数将创建一个新会话；如果已存在，则恢复当前会话。每个创建会话都与自动生成的唯一会话 ID 相关。创建会话后，我们分别使用 `'myFavFood'`、`'myFavDrink'` 和 `'myFavColor'` 作为键将字符串 `'Pizza'`、`'Cola'` 和 `'Orange'` 存储到 `$_SESSION` 超全局中。接下来，我们在第 9 行通过为其分配一个新字符串来更新 `$_SESSION['myFavDrink']` 的值。最后，在第 12 行，我们使用另一个名为 `unset()` 的内置函数来删除 `$_SESSION` 超全局中的一个元素。要使用此函数，我们将想要销毁的元素名称传递给函数。元素被销毁后，我们将无法再次访问它。

接下来，让我们在 `htdocs` 中创建另一个名为 `session2.php` 的文件，并向其中添加以下代码：

```php
<?php
session_start();
echo '<BR>Food: '.$SESSION['myFavFood']; 
echo '<BR>Drink: '.$SESSION['myFavDrink']; 
echo 'Color: '.$SESSION['myFavColor']; 
```

在这里，我们通过调用 `session_start()` 函数开始恢复当前会话。每当我们想要访问 `$_SESSION` 超全局时，都需要调用此函数。接下来，我们使用三个 `echo` 语句输出存储在 `$_SESSION` 中的值。

现在，我们准备好演示会话是如何工作的。要做到这一点，首先在浏览器中加载 `session.php`。这样做时，`session.php` 会启动一个新的会话并将数据存储到 `$_SESSION` 超全局中。接下来，在浏览器中加载 `session2.php`。你得到了什么？取决于你的 PHP 服务器设置，你将得到类似所示的输出：

`Food: Pizza`

`Drink: Beer Notice : Undefined index: myFavColor in …session2.php on line 6`

`Color:`

注意我们为 “myFavColor” 收到了未定义索引提示？这是因为我们在 `session.php` 中使用 `unset()` 函数删除了 `$_SESSION['myFavColor']`。除此之外，我们成功地获取了 `$_SESSION['myFavFood']` 和 `$_SESSION['myFavDrink']` 的值。这两个值分别在 `session.php` 的 `$_SESSION` 中存储并在 `session2.php` 中获取。这演示了我们如何使用 `$_SESSION` 超全局在不同的页面之间存储数据。理解了吗？

除了创建和存储会话数据外，我们还可以销毁会话。我们通常在用户退出网站时这样做。销毁会话，我们使用另一个名为 `session_destroy()` 的内置函数。要查看此函数如何工作，请在 `htdocs` 中创建一个名为 `session3.php` 的新文件并向其中添加以下代码：

```php
<?php
session_start();
session_destroy();
```

如上述代码所示，我们需要销毁会话之前调用 `session_start()` 函数来恢复现有会话。接下来，在浏览器中加载 `session3.php`；这会销毁当前会话。最后，再次在浏览器中加载 `session2.php`。你会得到所有索引 “myFavFood”、“myFavDrink” 和 “myFavColor”均为未定义的输出。这表明会话已不存在。

## 8.3 `$_COOKIE`

太棒了！我们来到了本章的最后一个主题 - Cookie。Cookie 是另一种存储信息的方式，信息可以在网站的多个页面之间进行访问。它本质上是一个存储在用户计算机上的小型文本文件（这与数据存储在服务器上的 session/会话相反）。

由于 Cookie 存储在用户的计算机上，因此你不应该使用 Cookie 来存储敏感数据，因为恶意用户可能会对其进行操纵。此外，用户的浏览器也可能会禁用 Cookie。因此，如果要存储的信息至关重要或敏感，你应该使用 session 代替 Cookie。

要创建一个 Cookie，我们使用 `set_cookie()` 函数。与在第 3.3 节中介绍的 `header()` 函数类似，`set_cookie()` 函数必须在脚本生成任何输出之前调用。如果你没有这样做，将会得到“Cannot modify header information headers already sent”（无法修改已发送头部信息）的警告，且 Cookie 将无法设置。你的代码在本地计算机上运行时可能可能正常工作，但当你将其上传到托管公司的服务器时，它将失效。

`set_cookie()` 函数最多接受七个参数；只有第一个是强制性的。我们通常为函数提供前三个参数，即 Cookie 的名称、Cookie 的值以及 UNIX 时间戳格式的过期日期。让我们来看一个示例。在 `htdocs` 中创建一个名为 `cookie.php` 的文件并添加以下代码：

```php
<?php  

setcookie('userName', 'Joy', time() + 120); #modifying a cookie  

setcookie('userAge', 25, time() + 3600); setcookie('userAge', 26, time() + 3600); #deleting a cookie  

setcookie('userLevel', 3, time() + 3600); setcookie('userLevel', 3, time() - 3600); 
```

在这里，我们设置了三个 Cookie：`userName`、`userAge` 和 `userLevel`。对于第一个 Cookie (`userName`)，它的值和过期日期分别为 'Joy' 和 `time() + 120`。`time()` 是一个内置函数，用于提供当前的 Unix 时间戳；`time() + 120` 意味着 Cookie 将在设置 120 秒（即 2 分钟）后过期。

接下来，我们有 `userAge` Cookie。这个 Cookie 被设置了两次。当一个 Cookie 被设置多次时，新的 Cookie 会覆盖之前的。因此，`userAge` 的值从 25 更新为 26。

最后，我们有 `userLevel` Cookie。这个 Cookie 的初始过期时间为 `time() + 3600`。然而，它随后被更新为过期时间 `time() - 3600`。当 Cookie 的过期时间在过去时，它会被删除。

现在让我们来看如何访问这些每一个 Cookie。我们使用 `$_COOKIE` 超全局变量来实现。在 `htdocs` 中创建另一个名为 `cookie2.php` 的文件并添加以下代码：

```php
<?php  

echo 'User Name is.'$_COOKIE['userName']; echo '<BR>User Age is.'$_COOKIE['userAge']; echo 'User Level is.'$_COOKIE['userLevel']; 
```

我们现在准备好测试我们的脚本了。首先，在浏览器中运行 `cookie.php`。当你这样做时，你将看到结果。

在构造函数内部，我们分别用 `$pId`、`$pTitle` 和 `$pRentalPrice` 的值初始化 `$id`、`$title` 和 `$rentalPrice`。注意上面代码中的新关键字 `$this` 吗？我们将在下一节学习创建对象时再解释这个关键字。现在，只需要知道，每当我们想在类内部访问类的属性和方法时，我们需要使用 `$this` 关键字，后跟 `->` 运算符。接下来，让我们为我们的 `Movie` 类添加一个普通方法（即非魔术方法）。在 `construct()` 方法之后（但在 `Movie` 类的结束大括号之前）添加以下方法：

```php
public function conversion($country){
  $rate = 1;
  switch($country){
    case 'UK':
      $rate = 0.76;
      break;
    case 'Japan':
      $rate = 110;
      break;
  }
  return round($rate*$this->rentalPrice, 2); }
```

在这里，我们定义了一个名为 `conversion()` 的方法。该方法有一个参数 `$country` —— 并根据 `$country` 的值将美元转换为镑或日元。在方法内部，我们声明并初始化了一个名为 `$rate` 的变量，并使用 `switch` 语句根据 `$country` 的值更新其值。接下来，我们将 `$rate` 与 `$rentalPrice` 属性相乘（`$rate*$this->rentalPrice`），并将结果作为参数传递给名为 `round()` 的内置函数。该函数接受两个参数，并将第一个参数舍入到第二个参数指定的精度。在我们的方法中，我们将乘积保留到 2 位小数。最后，我们使用 `return` 关键字返回 `round()` 函数的结果。

在方法内部，注意我们没有使用 `$this` 关键字来访问 `$country` 和 `$rate` 吗？这是因为 `$country` 是一个参数，而 `$rate` 是一个局部变量（即在方法内部定义的变量）。换句话说，它们不是类的属性。我们只在访问类属性和方法时才使用 `$this` 关键字。例如，我们使用 `$this` 关键字来访问 `$rentalPrice` 属性。明白了吗？一旦你将 `conversion()` 方法添加到 `Movie` 类中，我们的类就完整了。我们现在准备好使用这个类了。为了做到这一点，我们需要从它创建一个对象。

### 9.3 创建对象

要创建一个对象，我们使用 `new` 关键字。对象也被称为类的实例，创建对象的过程被称为类的实例化。在 Bracket 中创建一个新文件并将其保存为 `chap9.php`，到你的 htdocs 文件夹中。在 `chap9.php` 中添加以下代码：

```php
<?php
include 'Movie.php';
$mov1 = new Movie('N0001', 'Lusso', 4.99);
```

在这里，我们首先使用 `include` 语句包含 `Movie.php`（包含 `Movie` 类的代码）。接下来，我们使用 `new` 关键字创建一个名为 `$mov1` 的 `Movie` 对象，并将 `'N0001'`、`'Lusso'` 和 `4.99` 作为参数传递给 `construct()` 方法。

由于 `construct()`一个魔术方法，我们不通过它的名称调用它。相反，当我们创建一个新的 `Movie` 对象时，PHP 会自动寻找 `construct()` 方法并为我们执行。还记得我们 `Movie` 类构造函数中的 `$this` 关键字吗？`$this` 指向当前对象。当我们使用语句 `$mov1 = new Movie('N0001', 'Lusso', 4.99)` 创建 `$mov1` 时，`$this` 指向 `$mov1`。换句话说，当 PHP 执行构造函数时，构造函数中的语句：

```php
$this->id = $pId;
```

变为

```php
$mov1->id = 'N0001';
```

结果是值 `'N0001'` 被赋值给 `$mov1` 的 `$id` 属性。构造函数中的另外两个赋值语句也是如此。因此，值 `'Lusso'` 和 `4.99` 分别赋值给 `$mov1` 的 `$title` 和 `$rentalPrice` 属性。接下来，让我们使用下面的语句创建名为 `$mov2` 的第二个 `Movie` 对象：

```php
$mov2 = new Movie('P0002', 'Junior', 5.99);
```

当 PHP 创建 `$mov2` 并调用构造函数时，`$this` 指向 `$mov2`。因此，构造函数中的语句：

```php
$this->id = $pId;
```

变为

```php
$mov2->id = 'P0002';
```

构造函数中的另外两个赋值语句也是如此。结果是值 `'P0002'`、`'Junior'` 和 `5.99` 分别赋值给 `$mov2` 的 `$id`、`$title` 和 `$rentalPrice` 属性。明白了吗？很好！继续。

### 9.4 访问类成员

创建对象后，我们可以使用对象名和 `->` 运算符来访问它的属性和方法。例如，要在 `chap9.php` 中访问 `$mov1` 的属性和方法，我们使用下面的代码：

```php
echo $mov1->title.'<BR>';
echo $mov1->conversion('Japan').'<BR>';
```

在这里，我们首先使用 `->` 运算符访问 `$mov1` 的 `$title` 属性。接下来，我们使用 `->` 运算符调用 `conversion()` 方法，并将 `'Japan'` 作为参数。将上述代码添加到 `chap9.php`（在实例化语句之后）并加载页面，你将得到：

```
Lusso
548.9
```

非常直观吧？

现在，假设我们要访问 `Movie` 类中的 `DISCOUNT` 常量，该怎么做？访问类常量不使用 `->` 运算符。相反，我们使用 `::` 运算符。这是因为类常量与类属性不同；它们每个类分配一次，而不是每个对象一次。这意味着同一类的所有对象（在我们示例中的 `$mov1` 和 `$mov2`）共享相同的常量。换句话说，即使有 100 个 `Movie` 对象，也只有一个内存用于存储 `DISCOUNT` 常量。要访问 `Movie` 类中的 `DISCOUNT` 常量，在 `chap9.php` 中添加以下代码：

```php
echo Movie::DISCOUNT.'<BR>';
echo $mov1::DISCOUNT.'<BR>';
echo $mov2::DISCOUNT.'<BR>';
```

如果你运行上述代码，你会得到：

```
10
```

三次。这表明可以使用类名（Movie）或对象名（$mov1 或 $mov2）来访问类常量。这三者都都提供了相同的值，因为它们访问的是同一个内存位置。

### 9.5 访问修饰符

现在我们知道如何创建对象并使用这些对象访问类成员，让我们讨论一下之前跳过的概念：`public` 和 `private` 关键字。这两个关键字被称为访问修饰符；它们是守门员，控制我们可以在哪里访问特定的类成员。`public` 类成员可以在任何地方访问，而 `private` 类成员只能在定义的类内部访问。在我们的 `Movie` 类中，有两个 `public` 属性（`$title` 和 `$rentalPrice`）和一个 `private` 属性（`$id`）。之前，我们学习了在 `chap9.php` 中访问 `$mov1` 的 `$title` 属性。由于 `$title` 是公有类属性，我们在 `chap9.php` 中访问它没有遇到问题。现在，让我们尝试访问 `$id` 属性。添加这一行：

```php
echo $mov1->id.'<BR>';
```
