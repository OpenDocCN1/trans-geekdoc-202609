
# 决策树的缺点

决策树的缺点是，每个决策边界都是强制性的二分拆分。它没有细微差别。每个决策要么是是，要么是否，要么是 1 或 0。此外，决策标准一次只能考虑单个变量，不能是多个输入变量的组合。决策树无法进行增量更新。这意味着，一旦在训练集上训练了树，就必须将其丢弃并创建一个新树来处理新的训练数据。

# 集成方法

集成方法解决了许多树的局限性。本质上，集成方法使用多棵树来提高输出的准确性。有两种主要的集成方法——包法（bagging）和提升（boosting）。

## 包法

包法集成方法（称为自助聚合）旨在减少决策树的方差。训练数据被随机分成若干子集，每个子集用于训练一棵决策树。所有树的结果取平均值，提供了比任何单一树更稳健的预测准确性。

## 提升

提升集成方法类似于多级火箭。火箭的主助推器为车辆提供大量的惯性。当燃料耗尽时，它会分离，第二级将其加速度与已经赋予火箭的惯性相结合，依此类推。对于决策树来说，第一棵树在训练数据上运行并产生输出。下一棵树使用前一树的输出作为其输入。当输入存在误差时，赋予它的权重使得下一个树更有可能识别并至少部分缓解这一错误。运行的最终结果是从一系列弱学习器中产生一个强学习器。

# 线性回归

线性回归方法的基础是假设输出（数值）可以表示为输入变量集（也是数值）的组合。一个简单的例子可能像这样：

```
x = a1y1, a2y2, a3y3…
```

其中 `x` 是输出，`a1...an` 是赋予每个输入的权重，`y1...yn` 是输入。

线性回归模型的优势在于它在评分和性能方面可以表现良好。它还具备增量学习的能力。线性回归模型的缺点是它假设输入特征是线性的，而事实可能并非如此。必须通过数学对输入进行线性测试。

# K-Means 聚类算法

K-Means 聚类算法可对讨论相似概念的结果进行分组。因此，算法会将所有讨论作为动物的洲洲豹的结果归类为一类，将讨论作为汽车的 Jaguar 归类为另一类，将讨论作为操作系统的 Jaguar 归类为第三类，依此类推。

# 神经网络

我们在上面已经详细介绍了神经网络。神经网络的优势在于它们能够学习输入和输出之间的非线性关系。

# 贝叶斯网络

贝叶斯网络产生输出和输入之间的概率关系。这种网络要求所有数据都是二值化的。贝叶斯网络的优势包括高可扩展性和支持增量学习。我们在书的前早期部分更详细地讨论了贝叶斯模型。特别是这种机器学习方法特别擅长分类任务，例如检测邮件是否为垃圾邮件。

# 机器学习与机器人技术

首先，我们需要定义一个机器人。它们是机器，通常可以通过计算机进行编程，能够在没有干预的情况下执行一系列复杂的动作。机器人可以嵌入其控制系统，也可以由外部设备控制。在流行文学和电影中，许多机器人被设计得像人类，但事实上，它们通常是为了执行特定任务而设计的，这种需求决定了它们的外观。机器人伴我们我们几乎和计算机一样久。乔治·德沃尔在 1954 年发明了第一种数字操作和可编程的机器人，称为 `Unimate`。1961 年，通用汽车购买了它用于抬运热金属压铸件。就像计算机一样，机器人改变了我们的社会。它们的力量、灵活性以及持续完美执行重复任务的能力证明了巨大的收益。尽管它们对制造业造成了某些冲击，导致许多人失业，但它们在社会中的崛起提供的就业机会远大于夺取的。

目前使用的机器人可以分为几类：

## 工业机器人/服务机器人

这些机器人可能很熟悉。你可能在电视或自动化工厂的视频中见过它们。它们通常由一个一个或多个关节的“手臂”组成，末端带有夹爪或操作设备。它们最早出现在汽车工厂。它们被固定在一个位置，无法移动。工业机器人见于制造和工业场所。服务机器人的设计与工业机器人基本相同，但出现在制造领域之外。

### 教育机器人

这些机器人被用作教学工具或用于教育目的。早在 20 世纪 80 代，教室就带着“乌龟”引入了机器人，学生可以在那里使用 `Lego` 编程语言对它们进行训练。还有可以购买的机器人套装，如 `Lego Mindstorm`。

### 模块机器人

模块机器人由几个协同工作的独立单元组成。它们可以是相同的，也可以在设计上有一个或多个变化。模块机器人能够组合形成允许它们执行任务的形状。模块机器人系统的编程当然比单个机器人复杂，但大学和企业环境的持续研究表明，这种设计方法在许多应用中优于单一大型机器人。与群体智能（见下文）相结合，模块机器人证明非常擅长解决问题。

### 协作机器人

协作机器人设计用于与人类工作。它们大部分是工业机器人，包含了安全功能，以确保它们在执行分配的任务时不会伤害任何人。这种协作机器人的极佳例子是 `Baxter`。Baxter 于 2012 年引入，被设计为编程完成简单任务，但在与人类接触时会停止移动。当然，上述所有示例都不需要人工智能。当机器人结合机器学习时，研究人员使用术语“机器人学习”。这一领域在至少四个重要领域具有深远影响：

- **视觉**：机器学习允许机器人视觉上感知环境并理解它们所看到的内容。不需要预先编程，机器人就可以理解并分类新物品。
- **抓取**：结合视觉，机器学习允许机器人处理它们从未见过的环境物品。过去，在工厂里，每当机器人预计与不同形状的物体交互时，都需要编程如何处理。有了机器学习，机器人具备自动导航新形状和大小的能力。
- **运动控制**：借助机器学习，机器人能够在环境中移动并避开障碍以继续执行它们分配的任务。
- **数据**：机器人现在能够理解物理和逻辑数据模式，并根据这些模式做出反应。

## 工业机器人的示例

将机器学习应用于机器人的一个例子是沿着传送带接收箱的工业机器人。因为是固定的，这些箱往往会有偏差。传统上，对这些形状容差较小的机器人将无法正确抓取。通过机器学习算法，机器人现在能够实时适应不同的形状并成功抓取箱。另一个工业示例是拥有 90000 个不同零件的工厂。教机器人如何处理这么多物品是不可能的。通过机器学习，机器人可以接收它将要处理的新零件图像，并自己确定处理它们的方法。2019 年，预计全球有 600 万机器人正在服务。这比 2015 年有所增加。随着越来越多的机器人结合机器学习算法，这个数字肯定会爆炸。

### Series 和 DataFrame

你可以将 `Series` 视为一个带标签的一维数组。这些标签帮助你通过标签来理解该系列中的单个元素。
