
## 函数值与闭包

```go
// squares 返回一个函数，每次调用该函数都会返回下一个平方数。
func squares() func() int {
    var x int
    return func() int {
        x++
        return x * x
    }
}

func main() {
    f := squares()
    fmt.Println(f()) // "1"
    fmt.Println(f()) // "4"
    fmt.Println(f()) // "9"
    fmt.Println(f()) // "16"
}
```

函数 `squares` 返回另一个类型为 `func() int` 的函数。调用 `squares` 会创建一个局部变量 `x` 并返回一个匿名函数，每次调用该匿名函数时，它都会递增 `x` 并返回其平方。第二次调用 `squares` 将创建第二个变量 `x` 并返回一个新的匿名函数，该函数递增这个新变量。

`squares` 示例表明函数值不仅仅是代码，还可以拥有状态。匿名内部函数可以访问并更新外部函数 `squares` 的局部变量。这些隐藏的变量引用就是我们将函数归类为引用类型以及函数值不可比较的原因。像这样的函数值是使用一种称为*闭包*的技术实现的，Go 程序员经常用这个术语来指代函数值。

这里我们再次看到一个变量的生命周期不由其作用域决定的例子：变量 `x` 在 `squares` 返回后仍存在于 `main` 中，即使 `x` 隐藏在 `f` 内部。

## 匿名函数示例：拓扑排序

作为一个略带学术性的匿名函数示例，考虑计算一系列计算机科学课程的序列，使其满足每门课程的先修要求。先修要求在下面的 `prereqs` 表中给出，它是一个从每门课程到必须在其之前完成的课程列表的映射。

`gopl.io/ch5/toposort`

```go

    "algorithms": {"data structures"},
    "calculus":   {"linear algebra"},

    "compilers": {
        "data structures",
        "formal languages",
        "computer organization",
    },

    "data structures":       {"discrete math"},

```

这种问题称为**拓扑排序**。从概念上讲，先修信息形成了一个有向图，每个课程一个节点，从每门课程到其依赖的课程有边。该图是无环的：不存在从一门课程出发又能回到自身的路径。我们可以使用深度优先搜索遍历该图来计算一个有效序列，代码如下：

点击此处查看代码图像

```go
func main() {
    for i, course := range topoSort(prereqs) {
        fmt.Printf("%d:\t%s\n", i+1, course)
    }
}

func topoSort(m map[string][]string) []string {
    var order []string
    seen := make(map[string]bool)
    var visitAll func(items []string)

    visitAll = func(items []string) {
        for _, item := range items {
            if !seen[item] {
                seen[item] = true
                visitAll(m[item])
                order = append(order, item)
            }
        }
    }

    var keys []string
    for key := range m {
        keys = append(keys, key)
    }

    sort.Strings(keys)
    visitAll(keys)
    return order
}
```

当匿名函数需要递归时，如本例所示，我们必须先声明一个变量，然后将匿名函数赋值给该变量。如果这两个步骤在声明中合并，函数字面量将不在变量 `visitAll` 的作用域内，因此它将无法递归调用自身：

点击此处查看代码图像

```go
visitAll := func(items []string) {
    // ...
    visitAll(m[item]) // compile error: undefined: visitAll
    // ...
}
```

## 链接提取示例

让我们回到 `findLinks` 示例。我们已将链接提取函数 `links.Extract` 移至其自己的包中，因为我们将在第 8 章中再次使用它。我们用一个直接向 `links` 切片追加的匿名函数替换了 `visit` 函数，并使用 `forEachNode` 处理遍历。由于 `Extract` 只需要 `pre` 函数，它为 `post` 参数传递了 `nil`。

点击此处查看代码图像

`gopl.io/ch5/links`

```go
// Package links provides a link-extraction function.
package links

import (
    "fmt"
    "net/http"

    "golang.org/x/net/html"
)

// Extract makes an HTTP GET request to the specified URL, parses
// the response as HTML, and returns the links in the HTML document.
func Extract(url string) ([]string, error) {
    resp, err := http.Get(url)
    if err != nil {
        return nil, err
    }
    if resp.StatusCode != http.StatusOK {
        resp.Body.Close()
        return nil, fmt.Errorf("getting %s: %s", url, resp.Status)
    }

    doc, err := html.Parse(resp.Body)
    resp.Body.Close()
    if err != nil {
        return nil, fmt.Errorf("parsing %s as HTML: %v", url, err)
    }

    var links []string
    visitNode := func(n *html.Node) {
        if n.Type == html.ElementNode && n.Data == "a" {
            for _, a := range n.Attr {
                if a.Key != "href" {
                    continue
                }
                link, err := resp.Request.URL.Parse(a.Val)
                if err != nil {
                    continue // ignore bad URLs
                }
                links = append(links, link.String())
            }
        }
    }
    forEachNode(doc, visitNode, nil)
    return links, nil
}
```

此版本不是将原始的 `href` 属性值追加到 `links` 切片，而是将其解析为相对于文档基础 URL `resp.Request.URL` 的 URL。生成的 `link` 采用绝对形式，适合在调用 `http.Get` 时使用。

## 广度优先爬虫

网络爬虫的核心是一个图遍历问题。`topoSort` 示例展示了深度优先遍历；对于我们的网络爬虫，我们将至少最初使用广度优先遍历。在第 8 章中，我们将探索并发遍历。

下面的函数封装了广度优先遍历的本质。调用者提供一个初始的 `worklist` 项列表和一个为每个项调用的函数值 `f`。每个项由字符串标识。函数 `f` 返回一个新项列表以追加到 worklist。当所有项都被访问后，`breadthFirst` 函数返回。它维护一个字符串集合以确保没有项被访问两次。

点击此处查看代码图像

`gopl.io/ch5/findlinks3`

```go
// breadthFirst calls f for each item in the worklist.
// Any items returned by f are added to the worklist.
// f is called at most once for each item.
func breadthFirst(f func(item string) []string, worklist []string) {
    seen := make(map[string]bool)
    for len(worklist) > 0 {
        items := worklist
        worklist = nil
        for _, item := range items {
            if !seen[item] {
                seen[item] = true
                worklist = append(worklist, f(item)...)
            }
        }
    }
}
```

正如我们在第 3 章中简要解释的那样，参数 `f(item)...` 会导致 `f` 返回的列表中的所有项被追加到 worklist。

在我们的爬虫中，项是 URL。我们将提供给 `breadthFirst` 的 `crawl` 函数打印 URL，提取其链接，并返回它们以便它们也被访问。

点击此处查看代码图像

```go
func crawl(url string) []string {
    fmt.Println(url)
    list, err := links.Extract(url)
    if err != nil {
        log.Print(err)
    }
    return list
}
```

为了启动爬虫，我们将使用命令行参数作为初始 URL。

点击此处查看代码图像


### 5.6.1 警示：捕获迭代变量

在本节中，我们将探讨 Go 语言词法作用域规则的一个陷阱，它可能导致令人惊讶的结果。我们强烈建议你在继续之前先理解这个问题，因为即使是经验丰富的程序员也可能掉进这个陷阱。

考虑一个必须创建一组目录稍后再删除它们的程序。我们可以使用一个函数值的切片来保存清理操作。（为简洁起见，本示例省略了所有错误处理。）

```go
var rmdirs []func()
for _, d := range tempDirs() {
    dir := d               // 注意：必要！
    os.MkdirAll(dir, 0755) // 同时创建父目录
    rmdirs = append(rmdirs, func() {
        os.RemoveAll(dir)
    })
}

// ...做一些工作...

for _, rmdir := range rmdirs {
    rmdir() // 清理
}
```

你可能会疑惑，为什么我们将循环变量 `d` 赋值给循环体内的一个新局部变量 `dir`，而不是像下面这个微妙的错误变体那样直接将循环变量命名为 `dir`：

```go
var rmdirs []func()
for _, dir := range tempDirs() {
    os.MkdirAll(dir, 0755)
    rmdirs = append(rmdirs, func() {
        os.RemoveAll(dir) // 注意：错误！
    })
}
```

原因是循环变量作用域规则的后果。在上述程序中，`for` 循环引入了一个声明变量 `dir` 的新词法块。该循环创建的所有函数值都“捕获”并共享同一个变量——一个可寻址的存储位置，而非某一特定时刻的值。`dir` 的值在连续迭代中被更新，因此当清理函数被调用时，`dir` 变量已被现已完成的 `for` 循环多次更新。因此 `dir` 保存的是最后一次迭代的值，结果导致对 `os.RemoveAll` 的所有调用都会尝试删除同一个目录。

通常，为解决此问题而引入的内部变量——示例中的 `dir`——会被赋予与其复制的外部变量完全相同的名称，从而产生外观奇特但至关重要的变量声明，如下所示：

```go
for _, dir := range tempDirs() {
    dir := dir // 声明内部 dir，初始化为外部 dir
    // ...
}
```
