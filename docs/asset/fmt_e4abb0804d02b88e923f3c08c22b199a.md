Windows 可以作为 IPsec 服务器，路由器和其他服务器也是如此。主要问题是 CPU 使用率以及计算能力应该在何处。这种考虑导致了 IPsec 设备的兴起，这些是专门为系列通信执行 IPsec 功能的硬件设备。根据连接数、网络带宽等，这些设备对于小型办公室或家庭办公室可能非常廉价，但对于大型企业级实现可能非常昂贵。

### AH 和 ESP

IPsec 使用两种协议来提供流量安全：

- 身份认证头部（AH）
- 封装安全载荷（ESP）

对于密钥管理和交换，存在三种协议：

- 互联网安全关联和密钥管理协议（ISAKMP）
- Oakley
- 安全密钥机制（SKEMI）
- 互联网密钥管理（IKMP）
- 互联网密钥交换（IKE）

IPsec 不定义特定算法，也不要求特定方法。IPsec 是一个开放框架，允许厂商实现行业标准算法。这种灵活性是 IPsec 的关键。IPsec 使用以下：

- 节点之间的 Diffie-Hellman 交换
- 批量加密算法，如`IDEA`和`3DES`用于加密数据
- 密钥哈希算法，如`HMAC`以及传统的哈希算法，如`MD5`和`SHA-1`用于数据包级认证
- 作为双方数字 ID 的数字证书

为了提供流量安全，为 IP 数据报定义了两个头部扩展。AH 添加到 IP 数据报时，确保了数据的完整性并确保数据源的真实性。通过保护 IP 头部中不变的元素，AH 保护 IP 地址并实现了数据源认证。ESP 为数据包的高层协议部分提供安全服务，而不是 IP 头部。

**考试要点** IPsec AH 保护完整性，但不提供私密性。IPsec ESP 提供机密性，但不保护数据包的完整性。为了同时涵盖隐私性和完整性，可以同时使用这两个头部。

AH 和 ESP 可以单独使用或结合使用，取决于所需的安全级别和类型。它们也与 IPsec 协议的传输模式和隧道模式配合。在传输模式下，两个通信端点主要为上层协议提供安全。加密和解密发生的端点位于通信通道的源和目的地。对于传输模式下的 AH，原始 IP 头部暴露的，但其内容通过数据包中的 AH 块受到保护，如图 3-7 所示。对于传输模式下的 ESP，数据内容通过加密受到保护，如图 3-8 所示。

隧道（Tunneling）是将数据封装封装协议内部的手段，该协议仅在隧道的入口和出口点被理解。这为隧道内的传输提供了安全性，因为外部观察者无法破解数据包内容，甚至无法识别通信双方的身份。`IPsec`具有隧道模式，可以用于跨公共网络的服务器到服务器之间的通信。虽然隧道端点被称为`servers`，但这些设备可以是路由器、专用设备或服务器。在隧道模式下，隧道端点仅用新的 IP 头部封装整个数据包以指示端点，并对此新数据包的内容进行加密。真实的源和目的信息包含在内部 IP 头部中，该头部在隧道中是加密的。外层 IP 头部包含隧道端点的地址。

如前所述，`AH`和`ESP`可以在隧道模式下使用。在隧道模式下使用`AH`时，外层 IP 头部部的部分将获得与传输模式相同的头部保护，而整个内部数据包都受到保护。这在图 3-9 中所示。`ESP`为隧道数据包的内容（即来自初始发送者的整个数据包）提供相同的加密保护，如图 3-10 所示。在隧道模式下，`AH`和`ESP`共同可以为整个数据包提供完整保护，如图 3-11 所示。`AH`和`ESP`的特定组合在`IPsec`中被称为安全关联（SA）。

在`IPv4`中，`IPsec`是一个附加组件，其接受由厂商驱动。它不是原始`IP`的一部分——这是原始`IP`的短视设计缺陷之一。在`IPv6`中，`IPsec`集成到`IP`中，并在所有数据包上都是原生的。它的使用仍然是可选的，但其协议套件中的包含将确保厂商解决方案在符合`IPv6`标准时具有互操作性。

`IPsec`在其安全过程中使用加密密钥，并作为协议系列的一部分具有手动和自动密钥分发。包含了手动密钥分发，但它只在小型、静态环境中实用，无法扩展到企业级实现。密钥管理的默认方法`IKE`是自动的。`IKE`验证参与`IPsec`的每个对端并协商安全策略，包括会话密钥的交换。`IKE`在对端之间创建一个安全隧道，然后通过该通道为`IPsec`协商`SA`。这分为两个阶段：第一阶段建立通道，第二阶段建立`SA`。

### SNMP

简单网络管理协议（`SNMP`）是管理基于`IP`网络上设备的标准。`SNMP`是一种应用层协议，是`IP`协议族的一部分，用于管理和监控设备，包括网络设备、计算机以及连接到`IP`网络的其他设备。

### SSH

安全外壳（`SSH`）协议是一种加密的远程终端。`SSH`是一个加密的远程终端。

简单网络管理协议（`SNMP`）是管理基于`IP`网络上设备的标准。`SNMP`是一种应用层协议，是`IP`协议族的一部分，用于管理和监控设备，包括网络设备、计算机以及连接到`IP`网络的其他设备。

安全外壳（`SSH`）协议是一种加密的远程终端。

域名服务（`DNS`）是一种将名称转换为 IP 地址的协议。
