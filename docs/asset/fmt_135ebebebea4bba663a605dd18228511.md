
为了评估 `ARIMA`、`Prophet` 和 `LSTM` 模型在预测方面的有效性，计算了多个误差指标，包括平均绝对误差 (`MAE`)、`MSE`、`RMSE` 和平均绝对百分比误差 (`MAPE`)。这些常见的性能指标被用于比较 `ARIMA`、`Prophet` 和 `LSTM` 模型。令 `y` 为表示序列 `x` 未来值的向量，定义为 `y` = `x̃` = [`x[T]` `x[T+1]`…`x[T+k]`]。这里 `y[i]` 和 `ỹ[i]` 分别表示实际值和预测值。误差指标定义如下（Bişkin & Çifci, 2021; Kırbaş, 2019）：

```
${MAE} = \frac{1}{n}\sum\limits_{i = 0}^{n - 1}\left| {y_{i} - \widetilde{y}}_{i} \right|`
```

(4.7)

```
${MSE} = \frac{1}{n}\sum\limits_{i = 0}^{n - 1}\left( {y_{i} - \widetilde{y}}_{i} \right)^{2}`
```

(4.8)

```
${RMSE} = \sqrt{\frac{1}{n}\sum\limits_{i = 0}^{n - 1}\left( {y_{i} - \widetilde{y}}_{i} \right)^{2}}`
```

(4.9)

```
${MAPE} = \frac{1}{n}\sum_{i = 0}^{n - 1}{\left| \frac{{y_{i} - \widetilde{y}}_{i}}{y_{i}} \right| \times 100}.`
```

## 4.5 结果与讨论

对 `ARIMA`、`Prophet` 和 `LSTM` 模型在土耳其里泽省 2004–23 年期间的月降雨时间序列数据上的预测性能进行了评估。数据被分为训练集和测试集，其中 2004 年 1 月至 2021 年 12 月的数据用于模型训练，剩余的 2022 年 1 月至 2023 年 10 月的数据用于评估。基于原始月降雨数据以及使用窗口大小为 3 个月和 5 个月的移动平均滤波器预处理后的数据，进行了三次实验。

`Fig. 4–7` 描绘了将 `LSTM` 模型应用于里泽月降雨数据时，损失值随训练轮数变化的曲线。损失值衡量模型在训练期间预测输出与真实目标输出之间的差异。损失越低表示性能越好，目标是尽可能将其最小化。在该图中，蓝色线条追踪了 `LSTM` 模型参数在每个轮次根据训练数据迭代更新时损失的演变情况。可以看出，初始时损失较高，但在连续的训练周期中损失稳步下降，达到最小值后趋于平稳。这种行为表明 `LSTM` 网络正在利用反向传播和梯度下降优化有效地学习输入时间序列中的模式。随着训练的进行，模型改进了捕捉过去与未来降雨值之间时间关系的能力。值得注意的是，损失在前 10 个轮次内急剧下降，此后下降速率开始趋于平稳。这表明大部分学习发生在早期，之后收益递减。它为确定理想的训练轮次数以避免过拟合提供了参考。
