### Question 201
一家国际银行正在为其客户建立一个新的在线门户，以便其访问财务报表。银行应该实施何种措施来确保客户浏览器与银行服务器之间传输的财务数据保持机密？

- (A) 对所有财务报表使用文件级加密
- (B) 实现 Web 应用防火墙 (WAF)
- (C) 为门户使用安全套接层 (SSL) 或传输层安全 (TLS)
- (D) 将所有财务数据存储在加密数据库中

**Explanation 201.** 正确答案：C. 为门户使用安全套接层 (SSL) 或传输层安全 (TLS)。SSL/TLS 旨在保护传输中的数据。通过加密加密客户浏览器和银行服务器之间的数据，它可以确保数据在传输过程中的机密性。

选项 A 错误。文件级加密对于静态数据非常有效，但不能保护客户端和服务器之间传输中的数据。

选项 B 错误。虽然 WAF 可以提供针对 Web 攻击的保护，但它本身并不对传输中的数据进行加密。

选项 D 错误。将财务数据存储在加密数据库中可以保护静态数据，但不能确保传输到客户端的数据的机密性。

### Question 202
一家拥有多个分支机构的跨国组织希望简化 WAN 连接并降低成本，同时确保办公室之间的数据传输保持安全。哪种技术最符合他们的需求？

- (A) VLAN
- (B) MPLS
- (C) SD-WAN
- (D) DMZ

**Explanation 202.** 正确答案：C. SD-WAN。软件定义广域网 (SD-WAN) 使企业能够利用任何传输服务的组合（包括 MPLS、LTE 和宽带互联网服务），安全地将用户连接到应用程序。SD-WAN 可以通过使用成本的互联网连接来降低成本，并简化 WAN 管理。

选项 A 错误。VLAN（虚拟局域网）用于将局域网划分为不同的广播域，但它无法促进 WAN 连接或降低 WAN 成本。

选项 B 错误。MPLS（多协议标签交换）是一项可能昂贵的 WAN 技术。虽然它提供了可靠且快速的连接，但没有提供 SD-WAN 那样的成本效益或灵活性。

选项 D 错误。DMZ（非军事化区）是组织内部网络与外部不可信网络之间的缓冲区。它与 WAN 连接或降低成本无关。

### Question 203

- (B) 从免费证书机构获取证书
- (C) 生成自签名证书
- (D) 使用来自另一个应用程序的共享证书

**Explanation 203.** 正确答案：C. 生成自签名证书。Laura 可以生成自签名证书而无需证书机构。虽然自签名证书会在面向的应用程序中引起信任问题（因为它们没有由认可的 CA 签名），但对于可以告知用户并手动建立信任的内部应用程序来说，它们是适当的。

选项 A 错误。依赖明文 HTTP不会为应用程序提供任何加密或安全性，使其极易受到攻击。

选项 B 错误。虽然从证书机构获取证书是一个有效选项，但考虑到场景强调了不使用 CA，这并非最佳选择。

选项 D 错误。使用来自另一个应用程序的共享证书会引入安全风险，不是推荐的做法。

### Question 204
一家知名技术公司最近发布了一系列新路由器。在短时间内，安全研究人员发现其中一些路由器包含在制造过程中嵌入的恶意芯片。这种事件最可能代表了与供应链哪种方面的漏洞？

- (C) 硬件供应商的嵌入破坏
- (D) 供应商背景检查不充分

**Explanation 204.** 正确答案：C. 硬件供应商的嵌入破坏。硬件供应商背景下的供应链漏洞可能涉及在制造过程中引入恶意组件或芯片。在这种场景中，路由器中恶意芯片的存在反映了由于硬件供应商被破坏导致的漏洞。

选项 A 错误。场景围绕的是硬件破坏，而不是软件外包。

选项 B 错误。虽然服务提供者采用最新的安全实践非常重要，但此场景中的漏洞归由于硬件破坏，而不是过时的安全实践。

选项 D 错误。虽然供应商背景检查很重要，但此场景强调的是源于硬件制造过程的漏洞，而不是供应商的筛选过程。

### Question 205
一家跨国公司正在各国扩大业务。公司决定根据地理位置限制对内部网络的访问，以确保只有特定国家的员工可以访问

某些数据。以下哪项方案是实现此要求的最合适解决方案？

- (A) 部署带有多因素身份验证的 VPN
- (B) 在所有公司设备上使用 MAC 地址过滤
- (C) 实现基于地理位置的访问控制系统
- (D) 为公司的 Wi-Fi 网络设置特定区域 SSID

**解析 205. 正确答案：C. 实现基于地理位置的访问控制系统。** 基于地理位置的访问控制系统可以确定用户的物理位置，并根据预定义的地理边界授予或拒绝访问。该方案最适合根据特定国家的要求限制访问。

**选项 A 错误。** 虽然带有多因素身份验证的 VPN 提高了安全性，但它从本质上并不会根据地理位置限制访问。

**选项 B 错误。** MAC 地址过滤是根据设备硬件地址限制访问，而不是根据地理位置。

**选项 D 错误。** 特定区域 SSID 可能限制某些区域的 Wi-Fi 访问，但它们无法在更广泛范围内执行地理位置限制。

### 问题 206
TechGuard Inc. 和 CloudSecure 是两家网络安全公司，正在考虑合作开展一个新的云安全项目。两家公司都将为合作伙伴关系带来自己的技术和方法。在启动合作项目之前，他们应该确定哪种协议来定义他们的合作条款、角色和共同责任？

- (A) 不保密协议 (NDA)
- (B) 服务水平协议 (SLA)
- (C) 合作伙伴协议 (BPA)
- (D) 意向备忘录 (MOU)

**解析 206. 正确答案：C. 合作伙伴协议 (BPA)。** 合作伙伴协议 (BPA) 概述了实体之间合作的细节，详细说明了角色、责任、财务安排以及该关系的其他关键条款。鉴于 TechGuard Inc. 和 CloudSecure 正在形成具有共同角色和责任的伙伴关系，BPA 是最合适的。

**选项 A 错误。** NDA 专门关注共享信息的机密性，而不是合作伙伴关系的更广泛条款。

**选项 B 错误。** 服务水平协议 (SLA) 侧重于提供的服务标准和质量，详细说明了性能指标和不合规的惩罚，而不关注伙伴关系的细节。

**选项 D 错误。** MOU 表示双方之间的共同意图和理解，但可能无法像 BPA 那样提供业务伙伴关系的详细条款和条件。

### 问题 207
一个安全团队最近升级了入侵检测系统 (IDS)。升级后，系统没有标记出任何入侵，尽管入侵尝试是经常发生的。这种情况最好被描述为：

- (A) 真阴性 (True negative)
- (B) 假阴性 (False negative)
- (C) 真阳性 (True positive)
- (D) 确认反馈

**解析 207. 正确答案：B. 假阴性。** 当系统未能检测到实际存在的威胁或漏洞时，就会发生假阴性。在这种情况下，IDS 没有检测到真实的入侵尝试，这可能导致未被检测到的泄露。

**选项 A 错误。** 真阴性意味着系统正确识别出那里没有入侵，而且那里确实没有入侵。这与描述的情景符，因为预期会有入侵尝试。

**选项 C 错误。** 真阳性意味着威胁或漏洞被正确识别出来并且确实存在。由于没有检测到任何入侵，因此这不是真阳性。

**选项 D 错误。** “确认反馈”不是与漏洞检测相关的标准术语，不适用于描述的情景。

### 问题 208
CyberTech Inc. 是一家网络安全咨询公司，正与潜在客户 MedCorp 讨论协助开发一个新的安全的医疗记录系统。作为该流程的一部分，MedCorp 将与 CyberTech 共享敏感的患者数据。在共享此类信息之前应该签署哪种协议以确保机密性？

- (C) 不保密协议 (NDA)

**解析 208. 正确答案：C. 不保密协议 (NDA)。** NDA（不保密协议）专门设计用于保护双方共享的机密信息。它确保接收方不会披露或误用提供的信息。鉴于 MedCorp 将共享的患者数据具有敏感性，NDA 是至关重要的。

**选项 A 错误。** MOU 表示双方之间的共同意图和理解，但专门针对共享信息的机密性。

**选项 B 错误。** 服务水平协议 (SLA) 主要关于要提供的服务水平，详细说明了性能指标和不合规的惩罚。它本质上并不关注数据机密性。

**选项 D 错误。** 工作单 (WO) 或工作说明 (SOW) 详细说明了项目的细节，从任务到里程碑，但没有直接涉及共享数据的机密性。

### 问题 209
在分析服务器日志时，IT 安全分析师 Mike 注意到一个熟悉的文档经常被访问。经过调查，他意识到该文档是安全团队故意放置的，没有实际数据，但被密切监控。该文件的目的最有可能是：

- (A) 作为数据丢失时的冗余副本
- (B) 作为诱饵吸引并检测未经授权的访问
- (C) 维护所有用户活动记录以供审计
- (D) 加密并发送给客户作为样本

**选项 A 错误。** 冗余副本或备份是为了防止因意外问题导致的数据丢失，但它们不会作为诱饵被监控。

### 问题 210
TechCo 在对其数据库系统实施重大安全更新后，经历了意外的停机和系统不兼容问题。CISO 希望确保未来此类事件可以被快速解决。在部署更新之前，TechCo 应该准备好以下哪些措施来减轻此类事件的影响？

- (A) 所有更新的完整列表
- (B) 自动化系统恢复工具
- (C) 回滚计划 (Backout plan)
- (D) 更新的详细用户手册

**解析 210. 正确答案：C. 回滚计划。** 回滚计划是一种预先安排的策略或程序，用于在更改产生不利影响时撤销对系统所做的更改。在类似的情况下，即重大更新引起了意外之外的问题，回滚计划允许组织将系统恢复到之前的稳定状态。

**选项 A 错误。** 虽然拥有所有更新的完整列表对于文档和审计很有帮助，但它不能直接帮助减轻不利更新的影响。

**选项 B 错误。** 自动化系统恢复工具可能有助于撤销更改或恢复系统。然而，回滚计划更特定于撤销更新或更改过程中所做的更改，因此在这种语境下更合适。

**选项 D 错误。** 更新的详细用户手册对于培训和故障排除很有益，但它不能作为撤销意外不利更改的直接目的。

### 问题 211
TechFirm 准备与一个客户启动一个新项目，重点是实施网络安全基础设施的改造。他们希望列出项目所需的特定任务、交付物、时间表和资源。哪种类型的协议最能涵盖这些细节？

- (B) 合资协议 (Joint venture agreement)
- (C) 主服务协议 (MSA)

**选项 A 错误。** MOU 是一种更通用的协议，表示双方的意向，但它没有深入探讨特定项目的具体任务或交付物。

### 问题 212
某大型公司的 IT 部门正在对其虚拟化基础设施进行漏洞评估。他们发现了一个潜在威胁：VM 内部的用户可以与主机系统交互并可能破坏它。这种漏洞通常被称为什么？

- (A) VM 克隆 (VM cloning)
- (B) VM 快照 (VM snapshotting)
- (C) VM 逃逸 (VM escape)
- (D) VM 迁移 (VM migration)

**解析 212. 正确答案为：C。VM 逃逸。** 当攻击者在 VM 上运行代码，使其突破 VM 的隔离环境并访问主机系统时，就会发生 VM 逃逸。

虚拟机（VM）逃逸是指利用虚拟化软件中的漏洞，允许控制 VM 的攻击者突破隔离环境并访问主机系统。这可能导致同一主机上的其他 VM 或底层基础设施被破坏的风险。

**选项 A 错误。** VM 克隆是创建 VM 的完全副本的过程。它不涉及突破 VM 的隔离环境。

**选项 B 错误。** VM 快照涉及创建 VM 的某个点副本，可用于备份或恢复。它与逃离 VM 无关。

**选项 D 错误。** VM 迁移是指将 VM 从一个主机移动到另一个主机的过程，通常用于负载均衡或硬件维护。它不涉及突破 VM 的隔离环境。

### 问题 213
某大型组织正在考虑部署一种解决方案，允许员工使用个人设备安全地远程访问公司资源。该组织希望解决方案能够提供强身份验证并确保数据在传输过程中保持机密。应该采用哪种技术？

- (A) Kerberos
- (B) 远程桌面服务 (RDS)
- (C) 远程访问 VPN (Remote Access VPN)
- (D) SNMP

**解析 213. 正确答案为：C。远程访问 VPN。** 远程访问 VPN 提供从远程设备到组织内部网络的安全连接。它使用加密来确保数据机密性，并可以配置强身份验证方法。

**选项 A 错误。** Kerberos 是一种身份验证协议，使用票证（tickets）允许节点在网络中证明自己的身份。虽然它提供了强身份验证，但它本身并不提供带加密通信的远程访问解决方案。

**选项 B 错误。** 远程桌面服务 (RDS) 允许用户访问远程桌面或应用程序。虽然它可以被加密，但它并不总是确保传输过程中的加密，特别是当没有与 VPN 等技术配合使用时。

**选项 D 错误。** SNMP（简单网络管理协议）用于管理和监控网络设备。它与为用户提供安全的远程访问无关。

### 问题 214
ZetaTech 的安全分析师正在收集与与其行业相关的新兴威胁和漏洞信息。以下哪种方法最适合获取关于潜在安全问题的实时、持续更新的数据？

- (A) 仅依赖自动化内部漏洞扫描器

- (C) 订阅 OSINT 威胁馈送
- (D) 定期检查公司的防火墙日志

**解析 214. 正确答案为：C。订阅 OSINT 威胁馈送。** OSINT（开源情报）威胁馈送提供实时信息，并持续更新有关潜在安全问题的数据。

**选项 A 错误。** 虽然自动化内部漏洞扫描器对于识别组织基础设施内部漏洞很有价值，但它们无法提供有关新兴威胁的实时数据。

**选项 B 错误。** 手动渗透测试是定期的，无法对威胁提供持续更新。

### 问题 215
Lucy 在进行安全评估时发现，当她输入一个远大于输入字段设计处理长度的字符串时，特定应用程序会崩溃。这可能允许她在应用程序的上下文中执行任意代码。Lucy 试图利用哪种漏洞？

- (A) SQL 注入 (SQL Injection)
- (B) 跨站脚本 (XSS)
- (C) 缓冲区溢出 (Buffer Overflow)
- (D) 目录遍历 (Directory Traversal)

**解析 215. 正确答案为：C。缓冲区溢出。** 缓冲区溢出漏洞发生在写入缓冲区的数据超过该缓冲器的边界时，可能会覆盖相邻内存。如果成功成功，可能会导致任意代码执行。

缓冲区溢出是指应用程序向缓冲区写入的数据超过其能承载的内容，导致多余的数据溢到相邻的内存空间。当这种情况发生时，攻击者可以覆盖内存的特定部分，可能导致任意代码执行、应用程序崩溃或数据损坏。

**选项 A 错误。** SQL 注入涉及将恶意 SQL 语句注入输入字段中执行，旨在操纵数据库。它与缓冲区边界或内存溢出无关。

**选项 B 错误。** 跨站脚本 (XSS) 允许攻击者将恶意脚本注入其他用户查看的网页中。虽然这是一种类似于缓冲区溢出的输入验证缺陷，但 XSS 专门针对网络浏览器内的脚本执行，不涉及溢出缓冲区边界。

**选项 D 错误。** 目录遍历攻击旨在访问存储在 Web 根文件夹之外的文件和目录。它们不涉及溢出缓冲区边界或溢内存。
