## Hello World

我们将从最基础的代码示例开始 —— 一个 Golang 的 “Hello World” 程序示例。

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello World!")
}
```

我们用来运行程序的命令是：

`go run Chapter-4/Hello-World/main.go`

第一行：

`package main`

在 Go 中，我们使用保留关键字 `package`，然后指定包名；在本例中，包名为 `main`。入口点包必须是 `main` 才能启动 Go 程序。

声明包之后，我们将使用关键字 `import` 声明导入，并指定要导入的包。在本例中，我们使用的包名是 `fmt`。

我们可以用同样的方式声明多个包：

```go
import (
    "fmt"
    "os"
)
```

声明完包和导入后，我们可以声明类型、常量、方法和函数。在示例中，我们在 `main` 包中声明了一个名为 `main` 的函数，这是程序的入口点。

我们通过使用关键字 `func` 来声明函数，然后指定函数名、参数，用 `{` 开启作用域，用 `}` 关闭作用域。

`main()` 函数作为 Go 程序的入口点起着至关重要的作用，程序从此开始执行。它不是一个普通函数；它是启动程序进程的运行点，对任何 Go 应用程序都必不可少。

最后一行：

`fmt.Println("Hello World!")`

这行代码的功能是打印字符串 `Hello World!`。我们使用了 `Println` 函数，它是 `fmt` 包内的一个函数。

另一个重要且保留的函数（除了 `main`）是 `init()`。它会在程序启动时运行；它是唯一在 `main()` 之前运行的函数。

## 变量

在 Go 中有三种声明变量的方式。

第一种方式如下：

`var emptyMessage string`

这里，我们声明关键字 `var`，然后是变量名 `emptyMessage`。在示例中，该变量的类型为 string。

也可以在声明时给变量赋值：

`var message string = "This is a message"`

请注意，如果我们不像第一个示例那样给它一个初始值，它将获得一个默认值。每种基本数据类型都有不同的默认值，指针为 `nil`，结构体为空结构体值。我们将在本章后面详细说明基本数据类型的默认值。

第二种声明变量的方式是让 Go 编译器自行推断变量类型。

`var inferredMessage = "This is an inferred message"`

在该示例中，我们不必声明 `string`。Go 编译器从语法中推断出了它。

在 Go 中声明变量的第三种方式是使用 `:=`。

`alsoInferredMessage := "This is also an inferred message"`

这里，我们不必声明关键字 `var` 或 `string`，只需 `:=` 即可。

在 Go 中，变量在运行时不能改变其类型，因为 Go 是一门静态编程语言，正如我们在 *第 2 章，Go 的可用性* 中所见。

除非我们希望它们是公开的（此时为 PascalCase），否则 Go 中变量、函数、映射、结构体以及我们声明的所有内容的约定均为 camelCase。我们将在本章讨论访问修饰符。

## 基本数据类型

让我们看看这段代码块：

```go
package main

import "fmt"

func main() {
    message := "This is a message"
    fmt.Println(message)
    var zero int
    fmt.Println(zero)
    number := 42
    fmt.Println(number)
    var pi float64 = 3.14
    fmt.Println(pi)
    var booleanVar bool
    fmt.Println(booleanVar)
    trueBooleanVar := true
    fmt.Println(trueBooleanVar)
}
```

Go 中有四种基本数据类型 —— `string`、`boolean`、`float32`（也包括 `float64`）和 `int`（也包括 `int8`、`int16`、`int32`、`int64`、`uint`、`uint8`、`uint16`、`uint32`、`uint64`）。

*   `string` 用于文本。默认值为空文本 `""`。
*   `int` 用于整数。默认值为 `0`。
*   `float32` 用于浮点数。默认值为 `0`。
*   `bool` 用于 `true` 或 `false`。默认值为 `false`。

正如我们之前所见，我们可以在不声明类型的情况下声明变量，但类型会被推断。Go 会选择最方便的类型。例如，如果我们希望变量是 `int8` 而不是 `int`，我们必须显式声明。否则，Go 编译器会选择 `int`。

## 注释

注释有两种类型：

*   单行
*   多行

这是一个单行示例：

```go
func main() {
    // This is simple comment
}
```

这是一个多行示例：

```go
/*
This is a multi-line comment
*/
fmt.Println("Hello World!")
```

单行注释使用 `//`，多行注释以 `/*` 开始，以 `*/` 结束。

## 运算符

让我们在这里列举 Go 中所有运算符的示例。Go 中的运算符与其他编程语言非常相似。

```go
package main

func main() {
    // 算术运算符
    x := 5 + 5  // 10
    x = 5 - 5   // 0
    x = 5 * 5   // 25
    x = 5 / 5   // 1
    x = 5 % 5   // 0
    x++         // 6
    x--         // 5

    // 比较运算符
    y := 5 == 5 // true
    y = 5 != 5  // false
    y = 5 > 5   // false
    y = 5 < 5   // false
    y = 5 >= 5  // true
    y = 5 <= 5  // true

    // 逻辑运算符
    a := true && true  // true
    a = true && false  // false
    a = true || true   // true
    a = true || false  // true
    a = !true          // false
    a = !false         // true

    // 位运算符
    b := 5 & 5  // 5
    b = 5 | 5   // 5
    b = 5 ^ 5   // 0
    b = 5 << 5  // 160
    b = 5 >> 5  // 0

    // 赋值运算符
    c := 5
    c += 5  // 10
    c -= 5  // 5
    c *= 5  // 25
    c /= 5  // 5
}
```

## 循环

Go 语言中有多种循环方式；它们都使用 `for` 关键字。使用 `break` 跳出循环，使用 `continue` 进入下一次迭代。

```go
func main() {
	// for 循环：包含初始化、条件、后置语句
	for i := 0; i < 5; i++ {
		println(i)
	}

	// for 循环：仅包含条件，类似 "while"
	i := 0
	for i < 5 {
		println(i)
		i++
	}

	// for 循环：无条件，类似 "while true"
	i = 0
	for {
		println(i)
		i++
		if i >= 5 {
			break
		}
	}

	// for 循环：配合 continue
	for i := 0; i < 5; i++ {
		if i%2 == 0 {
			continue
		}
		println(i)
	}

	// for 循环：配合 range
	s := []int{1, 2, 3}
	for k, v := range s {
		println(k, v)
	}
}
```

注意 Go 中没有 `while` 关键字。实现 while 循环只需使用 `for`（带或不带条件）。

最后一个 `range` 示例是 Go 特有的。`range` 关键字让我们可以遍历数组、切片、映射等可迭代类型。

## 数组

Go 中声明数组有两种方式：

```go
func main() {
	// 声明一个包含 5 个整数的数组
	var a = [5]int{1, 2, 3, 4, 5}
	// 声明一个长度自动推断的数组
	var b = [...]int{1, 2, 3}
}
```

第一个示例（`var a = [5]int{1, 2, 3, 4, 5}`）显式指定长度为 5。第二个示例（`var b = [...]int{1, 2, 3}`）由编译器推断长度。当然，也可以不使用 `var` 关键字，直接用 `:=` 简短声明。

Go 数组只能存储同一类型元素，且长度不可变。

## 切片

切片与数组非常相似，但更加灵活。切片长度可在运行时动态改变，是 Go 的核心优势之一。声明切片的方式如下：

```go
mySlice := []string{"nir", "david"}
```

语法与数组几乎相同，但无需声明大小（或用 `...` 推断）。另一种声明方式是使用 `make` 关键字：

```go
mySlice := make([]type, length, capacity)
```

`length` 表示切片当前包含的元素数量，`capacity` 表示底层数组从切片第一个元素起的容量。`capacity` 始终大于或等于 `length`。

用于获取数组、切片长度和容量的两个内置函数是 `len`（长度）和 `cap`（容量）。

```go
slice := make([]int, 2, 5)
fmt.Println(slice)  // [0 0]
fmt.Println(len(slice))  // 2
fmt.Println(cap(slice))  // 5
```

切片/数组的一个便捷操作是切片截取。示例如下：

```go
myArray := [5]int{1, 2, 3, 4, 5}
slice = myArray[1:4] // 从索引 1 到 4（不包含 4）
fmt.Println(slice) // [2 3 4]
```

## 函数

Go 函数支持返回多个不同类型的参数：

```go
func myFunction(amount int, prefix string) string {
	return fmt.Sprintf("%s: %d", prefix, amount)
} // Input: 5, "nir" | Output: "nir: 5"

func multipleReturns(prefix string, amount int) (string, int) {
	amount++
	return fmt.Sprintf("%s: %d", prefix, amount), amount
} // Input: "nir", 5 | Output: "nir: 6", 6

func namedReturnValues(prefix string, amount int) (result string, newAmount int) {
	amount++
	result = fmt.Sprintf("%s: %d", prefix, amount)
	newAmount = amount
	return
} // Input: "nir", 5 | Output: "nir: 6", 6
```

第一个示例（`myFunction`）展示了使用 `func` 和 `return` 关键字的简单函数。第二个示例（`multipleReturns`）展示多返回值函数。第三个示例（`namedReturnValues`）展示具名返回值函数（单个具名返回值也合法）。

Go 函数的一个重要特性是 `defer`。`defer` 关键字注册的函数会在外层函数执行完毕后执行。示例如下：

```go
func functionWithDefer() {
	defer fmt.Println("This will be printed last")
	fmt.Println("This will be printed first")
} 
// Output: 
// This will be printed first
// This will be printed last

func functionWithMultipleDefers() {
	defer func() {
		fmt.Println("This will be printed last")
	}()
	defer fmt.Println("This will be printed second")
	fmt.Println("This will be printed first")
}
// Output:
// This will be printed first
// This will be printed second
// This will be printed last
```

示例直观地说明了 `defer` 的执行顺序（后进先出）。

在 Go 中，函数是一等公民，可作为参数传递、作为返回值返回、赋值给变量。这支持高阶函数和函数式编程模式。

## 映射

Go 映射用于存储键值对数据。`map` 的零值是 `nil`。映射持有对底层哈希表的引用。声明映射及常用操作如下：

```go
fruitsPrices := map[string]int{
	"orange": 10,
	"apple":  20,
	"banana": 15,
}

fmt.Println(fruitsPrices) // Output: map[apple:20 banana:15 orange:10]

// 添加键值对
fruitsPrices["mango"] = 25
fmt.Println(fruitsPrices) // Output: map[apple:20 banana:15 mango:25 orange:10]

// 删除键值对
delete(fruitsPrices, "orange")
fmt.Println(fruitsPrices) // Output: map[apple:20 banana:15 mango:25]

// 获取值
fmt.Println(fruitsPrices["apple"]) // Output: 20

// 获取不存在的键（返回类型零值）
fmt.Println(fruitsPrices["grapes"]) // Output: 0 (int 的零值)

// 检查键是否存在
price, ok := fruitsPrices["grapes"]
fmt.Println(price, ok) // Output: 0 false

// 遍历映射
for fruit, price := range fruitsPrices {
	fmt.Printf("%s: %d\n", fruit, price)
} // Output: apple: 20 banana: 15 mango: 25 (顺序不固定)

fmt.Println(len(fruitsPrices)) // Output: 3

// 创建空映射
emptyMap := make(map[string]int)
fmt.Println(emptyMap) // Output: map[]
```

## Switch 语句

使用 `switch` 语句从多个代码块中选择一个执行。Go 中不需要 `break` 关键字；每个 `case` 默认自动终止。若需穿透到下一个 `case`，使用 `fallthrough` 关键字。典型示例：

```go
func main() {
	printString("b") // b
	printString("a") // a b
}

func printString(str string) {
	switch str {
	case "a":
		println("a")
		fallthrough
	case "b":
		println("b")
	default:
		println("default")
	}
}
```

若无 `case` 匹配，则执行 `default` 分支。
