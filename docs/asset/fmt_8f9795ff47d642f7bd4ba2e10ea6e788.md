我教的大部分内容都是通过视频会议与客户进行虚拟化教学的。虚拟化培训中最困难的事情是提高学生的参与度。他们看不到我，我也看不见他们。我没有阅读肢体语言的能力。我看不到他们困惑时眼角的皱纹。我也看不见他们何时起身去拿咖啡，或者被电子邮件和电话分散了注意力，因此学生的参与度是关键。在“无漏洞管理”课程的对话中，围绕着网络安全哲学，即从攻击者的角度来看你和你的生态系统。我问：“渗透测试人员或黑客下载什么作为他们的首选操作系统？”我很惊讶于许多蓝队人员从未听说过 `Kali Linux`。在它更名为 `Kali` 之前我就一直在用它，那时它还叫 `Backtrack`。

`Kali Linux` 于 2013 年发布，是名为 `Backtrack` 的免费 Linux 发行版的重写版。`Backtrack` 基于 `Knopix OS` 开发，而 `Kali Linux` 基于 `Debian OS`，并由 `Offensive Security` 资助和维护。`Kali Linux` 保持免费，并提供广泛的无线设备支持。`Backtrack` 的启动是为了满足 `Mati Aharoni` 的需求，他需要一个工具来应对无法携带硬件笔记本电脑的任务，因为电脑在任务结束后会被收回。`Mati` 是 `Kali Linux` 的创始人和核心开发者，也是 `Offensive Security` 的首席技术官。有趣的是，`Kali` 是带来自我死亡的印度教女神。我认为这个软件的名字起得恰恰当。

我们在书中检查了许多工具，现在我们到了我最喜欢的工具之一。`Kali` 中的某些工具在书中有专门的章节介绍，例如 `Metasploit Framework`、`Nmap`、`Wireshark` 和 `Burp`。掌握任何技能或工具的最好方法都是实践。你可以采取的一种方法是将这些工具加载到你的计算机上，并使用它们来检查你的个人系统。这是一个非常好的介绍，但扩展性不佳。我们大多数人的私有网络中没有许多系统，可能无法充分发挥这些工具的用处。你可以使用这些工具来检查 `Google`、`Yahoo!` 或网络上的其他某些生产系统，但这样做的一个主要问题是你没有权限这么做。这可能会让你陷入很多法律纠纷。另一种替代方案，也是我最常用的方法，是使用虚拟化。

## 虚拟化

虚拟化是系统管理员多年来在数据中心使用的一种技术，它是云计算基础设施的核心。这项技术允许计算机的物理资源（`CPU`、`内存`、`硬盘`、`显卡`等）被虚拟机（`VMs`）共享。想想过去，单一物理硬件平台——服务器——专用于单一服务器应用程序，例如作为 `Web` 服务器。事实证明，典型的 `Web` 应用程序服务器并没有充分利用服务器上可提供的许多底层硬件资源。为了讨论起见，让我们假设运行在我们其中某台物理服务器上的 `Web` 应用程序利用了 30% 的硬件资源。这意味着 70% 的硬件资源被闲置了。

## 优化 Kali Linux

我做的第一件事就是养成每次打开 `Kali Linux` 时都更新它的习惯。`Offensive Security` 每天从 `Debian` 获取四次更新。这确保了补丁和更新每天都会整合到 `Kali Linux` 中。保持系统更新，并使其成为你日常工作的一部分。当操作系统加载时，打开终端并运行 `apt-get update`，如图 14.15 所示。当该过程完成并返回命令提示符后，运行 `apt-get dist-upgrade`（同样如图 14.15 所示）。

![](img/e8e965b6c3537819be0d570febb3fc1d_227_0.png)

图 14.15：通过终端更新 Kali Linux
