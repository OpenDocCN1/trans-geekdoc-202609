
如图 1-16 所示：

![](img/file219.png)

**图 1-16** 乘积矩阵中第 2 行第 1 列的元素是第一个矩阵第 2 行向量与第二个矩阵第 1 列向量的点积

两个向量的点积可以用矩阵乘法表示。设 `x` 和 `y` 为两个列向量，则：

`x ⋅ y = x^(T)y = y^(T)x`

若用 `A[i, :]` 表示矩阵 `A` 第 `i` 行的行向量，用 `B[:, j]` 表示矩阵 `B` 第 `j` 列的列向量，则 `c[i, j] = A[i, :]B[:, j]`。

向量是特殊的矩阵，因此矩阵与向量的乘积也属于矩阵乘法。例如，若 `A[m×n]` 乘以列向量 `x[n×1]`：

$$
A x = \begin{bmatrix} a_{1,:} \\ a_{2,:} \\ \vdots \\ a_{m,:} \end{bmatrix}x = \begin{bmatrix} a_{1,:}x \\ a_{2,:}x \\ \vdots \\ a_{m,:}x \end{bmatrix} = \begin{bmatrix} a_{11}x_{1} + a_{12}x_{2} + \cdots + a_{1n}x_{n} \\ a_{21}x_{1} + a_{22}x_{2} + \cdots + a_{2n}x_{n} \\ \vdots \\ a_{m1}x_{1} + a_{m2}x_{2} + \cdots + a_{mn}x_{n} \end{bmatrix}
$$

`Ax` 是一个列向量，其每个元素都是 `A` 的一行与 `x` 相乘（点积）的结果。

可以证明：

- 矩阵乘法满足结合律：`(AB)C = A(BC)`
- 矩阵乘法与加法满足分配律：`A(B + C) = AB + AC`

可以使用 NumPy 的 `dot()` 函数或 `ndarray` 的 `dot()` 方法来计算向量的点积和矩阵的乘积。NumPy 的 `dot()` 函数接受两个多维数组并执行多维数组的点积（乘法）运算。

```
numpy.dot(a, b, out=None)
```

如果指定了输出参数 `out`，则结果将输出到 `out` 中。

以下代码对比了逐元素乘法 `*` 与点积（乘法）的区别：

```
a = np.array([1, 3])
b = np.array([2, 5])
print("a*b:", a*b)
print("dot(a,b):", np.dot(a,b))         # 两个向量的点积是一个值（标量）
```

```
a*b: [ 2 15]
dot(a,b): 17
```

可以看出，两个向量的逐元素乘法结果仍是一个向量，而两个向量的点积是一个值（标量）。

矩阵与向量的乘法需要注意对应轴的元素数量是否一致，例如：

### 4 广播机制

广播是一种强大的机制，它使 NumPy 能够对形状不同的数组执行算术运算。例如，我们可以用一个数字和一个数组进行运算。这相当于将这个数字变成一个与该数组大小相同的数组，然后进行逐元素运算。例如，下面的 `a+3` 等价于 `a + np.array([[3,3],[3,3]])`。如图 1-17 所示：

![](img/file220.png)

**图 1-17** `a+3` 等价于 `a + np.array([[3,3],[3,3]])`

```
a = np.array([[1,2],[3,4]])
print(a)

print(a+3)
print(a + np.array([[3,3],[3,3]]))
```

```
[[1 2]
 [3 4]]
[[4 5]
 [6 7]]
[[4 5]
 [6 7]]
```

同样，数字与张量的减法、乘法、除法等也执行这种广播计算。

```
print(a*3)
print(a/3)
```

```
[[ 3  6]
 [ 9 12]]
[[0.33333333 0.66666667]
 [1.         1.33333333]]
```

同样，二维数组 `a` 也可以与以下一维数组 `b` 进行运算：

```
b = np.array([1,2])
print(a+b)
```

```
[[2 4]
 [4 6]]
```

在 `a+b` 中，因为 `b` 的轴 `axis=0` 只有 1 个元素（1 行），而 `a` 的轴 `axis=0` 有 2 个元素（2 行），`a+b` 等价于沿 `axis=0` 重复堆叠 `b` 成与 `a` 同样大小的数组，然后进行运算。如图 1-18 所示。

![](img/file221.png)

**图 1-18** `a+b` 等价于沿 `axis=0` 重复堆叠 `b` 成与 `a` 同样大小的数组，然后相加

NumPy 的广播实际上并不执行上述的重复堆叠和重新计算过程，而是直接按照这一概念的计算过程进行广播计算。这节省了内存并提高了效率。

```
a = np.array([[1],[2],[3]])   # a 是形状为 (3,1) 的二维数组
b = np.array([4,5])           # b 是形状为 (2,) 的一维数组
print(a)
print(b)
print(a+b)
```

```
[[1]
 [2]
 [3]]
[4 5]
[[5 6]
 [6 7]
 [7 8]]
```

`a` 是形状为 `(3,1)` 的二维数组，`b` 是形状为 `(2,)` 的一维数组。一维数组可以视为形状为 `(2,1)` 的张量，也可以视为形状为 `(1,2)` 的张量。`a+b` 需要匹配 `a` 和 `b` 的形状，`(2,1)` 和 `(3,1)` 的第一个轴 (`axis=0`) 显然不匹配，所以 `b` 将被视为形状为 `(1,2)` 的张量，因为只有单个元素的轴可以匹配任意数量的轴。因此 `a+b` 是两个二维数组 `(3,1)` 和 `(1,2)` 的相加。元素数量为 1 的轴将被升级为具有相同数量元素的数组，即两个形状为 `(3,2)` 的二维数组，如图 1-19 所示，然后进行逐元素计算。也就是说，广播总是将轴上元素较少的扩展为与元素较多的相同大小。

![](img/file222.png)

**图 1-19** 两个二维数组 (3,1) 和 (1,2) 的相加被升级为两个二维数组 (3,2) 的相加

两个数组进行运算时，广播的规则为：

#### 广播规则

- 如果数组的秩不同，使用 1 来扩展秩较小的数组，直到两个数组具有相同的秩。例如，秩为 0 的数字与秩不为 0 的数组进行运算时，会将该数字扩展为与数组相同的形状。
- 如果两个数组在某个维度（轴）上的长度相同，或者其中一个数组在该维度上的长度为 1，则称这两个数组在该维度上是兼容的。
- 如果两个数组在所有维度上都兼容，则可以使用广播。广播时，将长度为 1 的每个轴扩展为长度不为 1 的数组对应轴的长度。

## 1.3 微积分

本节介绍函数、极限、函数导数等微积分基本概念。

### 1.3.1 函数

关于函数，有不同的定义和描述，例如：

- 函数描述了一个变量对另一个变量的依赖关系。自变量称为**自变量**，因变量称为**因变量**。
- 函数是从一个变量到另一个变量的映射。即函数将一个变量映射到另一个变量。
- 函数是一种输入到输出的变换。即函数接受一个输入变量并产生一个输出变量。

这些定义从不同侧面描述了两个变量之间的函数关系。例如，正方形的面积 `s` 取决于其边长 `e`。自变量（如边长 `e`）称为**自变量**，因变量（如面积 `s`）称为**因变量**。面积 `s` 对边长 `e` 的依赖关系可表示为 `s = e²`。这种依赖关系也可视为映射关系：`e → s`，即边长 `e` 映射到面积 `s`。也可视为输入-输出变换 `s(e)`，即输入边长 `e`，输出一个面积值 `s(e)`。

两个变量之间的函数关系非常常见，例如温度是时间的函数，每一刻都有一个温度值。股票价格是时间的函数，每一刻都有一个股价。运动物体的速度是时间的函数，运动物体在每一刻都有特定的速度。身高是年龄的函数，房价是房屋大小的函数，等等。

在机器学习中，将函数理解为输入-输出变换更为容易。如果用字母 `x` 表示输入变量，用字母 `f` 表示函数，用 `f(x)` 表示输入 `x` 时函数 `f` 产生的输出值。

`x → f → f(x)`

有时，从 `x` 生成 `f(x)` 的过程可以用计算器表达，例如：`f(x) = 2x + 1`。输入值 `x = 3`，产生输出值 `f(3) = 2 * 3 + 1 = 7`。

常数 `c` 也可视为函数 `f(x) = c`，称为**常数函数**。

如果 `x`、`f(x)` 是两个标量（数字），它们可以表示为二维笛卡尔坐标平面上的坐标点 `(x, f(x))`。通过在二维笛卡尔坐标平面上绘制该函数关系的许多坐标点，可以更清晰地观察函数如何将一个 `x` 变换为 `f(x)`。这些点形成的图形称为**函数曲线**。

有时用 `y` 等字母表示输出值 `f(x)`。

以下代码通过在 `[0, 10]` 中采样一些 `x` 值获得对应的 `f(x) = 2x + 1` 值，并通过绘制这些点 `(x, f(x))` 可以在直角坐标系中更清晰地理解 `x` 和 `f(x)` 之间的关系。

```python
import numpy as np
import matplotlib.pyplot as plt
%matplotlib inline 

x = np.arange(-3, 3, 0.1) #
y = 2*x+1

plt.scatter(x, y, s=6) 
plt.legend(['f(x)=2x+1'])

plt.show() 
```

### 1.3.2 四则运算与复合运算

复杂函数可以通过简单函数的四则运算和复合运算来构建。

#### 四则运算

四则运算是指对两个函数进行加、减、乘、除运算以构建新函数的过程。如果有两个函数 `f(x)`、`g(x)`，这两个函数分别将 `x` 变换为 `f(x)`、`g(x)`：

`f : x → f(x)`  

`g : x → g(x)`

如果定义一个新的变换关系，将每个 `x` 变换为 `f(x) + g(x)`，那么这就是一个新的函数关系：

`x → f(x) + g(x)`

这个新函数：`x → f(x) + g(x)` 称为原两个函数的**和函数**。

例如：`y = x²` 和 `y = e^x` 可以通过加法生成新函数 `y = x² + e^x`。对于 `x = 2`，该新函数的函数值为 `y = 2² + e² = 4 + e²`。

以下代码绘制这 3 个函数的曲线：

```python
import numpy as np
import matplotlib.pyplot as plt
%matplotlib inline 

x = np.arange(-2, 2, 0.1) #
y = x**2 
y2 = np.exp(x) 
y3 = x**2 + np.exp(x) 

plt.plot(x, y)
plt.plot(x, y2) 
plt.plot(x, y3) 
plt.legend(['$x²$','$e^x$','$x²+e^x$'])

fig = plt.gcf()
fig.set_size_inches(4, 4, forward=True)
#plt.axis('equal')
plt.xlim([-3,3])
plt.show() 
```

**图 1-22** 函数 `x²` 和 `e^x` 及其和函数 `x² + e^x` 的曲线

同样，可以通过 `-`、`*`、`/` 构造差函数 `f(x) - g(x)`、积函数 `f(x) * g(x)` 和两个函数的商函数 `f(x)/g(x)`。

#### 复合运算

由于函数是一种变换或输入输出装置，将一个量 `x` 输入函数 `g` 会产生输出 `g(x)`，再将这个 `g(x)` 作为另一个函数 `f` 的输入，产生 `f(g(x))`。

`x → g → g(x) → f → f(g(x))`

将一个函数的输出作为另一个函数的输入，构成了一个新的变换或新函数。这个新函数是由原始的两个函数 `g` 和 `f` 通过变换串联形成的复合函数，可记为 `f ∘ g : x → f(g(x))`，即 `f ∘ g(x) = f(g(x))`。

例如，`g(x) = -x`，`f(x) = e^x`，则 `f ∘ g(x) = f(g(x)) = e^(-x)`。另一个例子是 `g(x) = e^x`，`f(x) = x²`，则 `f ∘ g(x) = f(g(x)) = (e^x)²`。复合函数的计算代码如下：

```
y = np.exp(x)**2
```
