## 2.4.4 性能结果分类时间

对拍摄的图像进行分类是指分类的总时间以及单个图像分类所需时间的乘积。计算分类时间的公式如公式 2.7 所示。

```
T_C = n * t[classifying single image] (2.7)
```

在 (2.7) 中，`T_C` 表示分类总时间，`n` 代表样本图像，`t` 取为单个乳腺图像分类时间。整个过程的时间复杂性以毫秒 (ms) 表示 [25]。

### 时间复杂的示例数学计算

#### CWFE-DL
样本输入图像数量为 20 个，单个图像处理时间的乘积为 1.1 毫秒。处理所需总时间的计算如下：

```
T_C = 20 * 1.1 ms = 22 ms
```

#### Deep CNN
假设样本输入数量为 20。`Deep CNN` 技术对单个图像的分类时间为 1.7 ms。该值应用于下面的计算：

```
T_C = 20 * 1.7 ms = 34 ms
```

#### CNNI-BCC
假设输入图像数量为 20。`CNNI-BCC` 的单图像分类方法为 1.4ms。总时间的计算如图 2.8 所示。

**图 2.8** 时间复杂度。

```
T_C = 20 * 1.4 ms = 28 ms
```

为了评估图像分类的时间复杂度，所提的 `CWFE-DL` 技术和现有方法在 `MATLAB` 中实现，样本图像范围为 20–200。将所提 `CWFE-DL` 的时间复杂度实验结果与 `Deep CNN` 和 `CNNI-BCC` 进行比较。在考虑 20 张乳腺图像时，所提的 `CWFE-DL` 技术将 20 个输入图像分类为正常或异常需要 22 ms。而 `Deep CNN` 和 `CNNI-BCC` 分需要 34 ms 和 28 ms。根据这些结果，`CWFE-DL` 方法的时间复杂度低于其他方法。时间复杂性的图表表示如图 2.9 所示。

**图 2.9** 耗时比较结果。

图 2.9 描绘了从乳腺医学影像中提取的 20–200 数量范围内的乳腺图像导致的三种方法的时间复杂度。在疾病预测中，使用 `CWFE-DL` 技术比现有技术最小化了时间复杂度。`CWFE-DL` 技术旨在通过实施分类帮助医疗保健行业的专家通过癌症识别恶性肿瘤。`CWFE-DL` 技术使用 `Coiflet 小波变换` 进行特征提取。`Coiflet 小波变换`最初通过两级变换将输入图像分解为不同的子方法。之后，使用 `Coiflet 小波系数` 结合尺度函数和`小波函数` 提取形状、大小和纹理。`Deep CNN` 分为 20%，`CNNI-BCC` 为 11%，结果显示 `CWFE-DL` 减少了耗时。

# 2.5 结论

名为 `CWFE-DL` 的有效方法用于预测乳腺疾病。本章通过弱学习器和投票方案提高了精度。`CWFE-DL` 技术最小化了疾病预测的时间。基于分类结果，`CWFE-DL` 准确预测了癌症。各种分析和结果显示乳腺医学影像。
