
It is easy to see that forward chaining is **sound**: every inference is essentially an application of Modus Ponens. Forward chaining is also **complete**: every entailed atomic sentence will be derived. The easiest way to see this is to consider the final state of the inferred table (after the algorithm reaches a **fixed point** where no new inferences are possible). The table contains true for each symbol inferred during the process, and false for all other symbols. We can view the table as a logical model; moreover, *every definite clause in the original KB is true in this model.* To see this, assume the opposite, namely that some clause *a*[1]⋀…⋀*a*[*k*] ⇒ *b* is false in the model. Then *a*[1] ⋀… ⋀ *a*[*k*] must be true in the model and b must be false in the model. But this contradicts our assumption that the algorithm has reached a fixed point! We can conclude, therefore, that the set of atomic sentences inferred at the fixed point defines a model of the original KB. Furthermore, any atomic sentence q that is entailed by the KB must be true in all its models and in this model in particular. Hence, every entailed atomic sentence q must be inferred by the algorithm.

2. 变量和值的顺序（如在第 6.3.1 节中看到的 CSPs）：我们简单的 DPLL 实现使用任意的变量顺序，总是先尝试值为 true 的情况。度量启发法（参见第 216 页）建议选择在剩余句子中出现频率最高的变量。

4. 随机重启（如在第 124 页中看到的爬坡算法）：有时一个运行似乎没有进展。此时，我们可以从搜索树顶部重新开始，而不是尝试继续。重启后，变量和值选择会产生不同的随机选择。第一次运行中学习的条款会在重启后保留，并有助于削减搜索空间。重启并不保证能更快找到解，但能降低解的时间方差。

5. 聪明索引（在许多算法中适用）：DPLL 本身以及现代求解器中使用的加速技术，需要对诸如“变量 X 的第 i 个位置出现为正字面量的句子集合”进行快速索引。由于算法只关心尚未被之前变量赋值满足的句子，因此索引结构必须在计算过程中动态更新。

在有了这些增强后，现代求解器能够处理数千万变量的问题。它们彻底改变了硬件验证和安全协议验证等领域，这些领域以前需要繁琐的、手工引导的证明。

#### **7.6.2 本地搜索算法**

本书迄今为止介绍了多种本地搜索算法，包括爬坡算法（`HILL-CLIMBING`，见第 122 页）和模拟退火（`SIMULATED-ANNEALING`，见第 126 页）。这些算法可以直接应用于满足性问题，前提是选择合适的评估函数。因为目标是找到满足所有句子的赋值，计数不满足句子数量的评估函数即可。事实上，这就是在约束满足问题（CSP）中使用的 `MIN-CONFLICTS` 算法所使用的度量（第 221 页）。所有这些算法在完整赋值空间中移动，每次翻转一个符号的真值。该空间通常包含许多局部最小值，为了逃离这些最小值，需要各种形式的随机性。近年来，研究重点在于寻找贪心性与随机性之间的良好平衡。

最简单且有效的算法之一是 `WALKSAT`（见图 7.18）。在每次迭代中，算法选择一个不满足的句子，并选择句子中的一个符号进行翻转。它在两种方式中随机选择翻转哪个符号：（1）最小冲突步（`minconflicts`），该步骤旨在最小化新状态下不满足句子的数量；（2）随机步（`random walk`），随机选择要翻转的符号。

当 `WALKSAT` 返回一个模型时，输入句子确实是可满足的；当返回`failure`时，有两种可能原因：句子不可满足，或者需要给算法更多时间。如果设置`max_flips` = ∞ 且 *p* > 0，`WALKSAT` 最终会返回一个模型（如果存在），因为随机步会最终找到解。然而，如果`max_flips`为无穷大且句子不可满足，算法将永不终止！

> **Figure 7.18** 用随机翻转变量值检查可满足性的 `WALKSAT` 算法。存在许多算法的变体。

因此，`WALKSAT` 最适用于预期解存在的情况——例如，文中第 3 章和第 6 章讨论的问题通常有解。相反，`WALKSAT` 不能总是检测不可满足性，这在判断蕴含时是必要的。例如，代理人不能*可靠*地使用 `WALKSAT` 证明在 wumpus 世界中方块是安全的。它只能说：“我思考了一个小时，没能想出一个方块*不是*安全的情境。”这可能是一个经验性的安全指示，但绝不是证明。

#### **7.6.3 随机 SAT 问题的景观**

有些 SAT 问题比其他问题更难求解。所谓*容易*的问题可以被任何旧算法解决，但由于我们知道 SAT 是 NP 完全问题，至少有些问题实例必须需要指数时间。在第 6 章中，我们看到一些令人惊讶的发现。例如，*n*皇后问题——曾被认为对回溯搜索算法来说很棘手——发现本地搜索方法（如 `minconflicts`）可以轻松解决。这是因为解在赋值空间中非常密集，任何初始赋值都保证在附近存在解。因此，*n*皇后问题之所以容易，是因为它**过度约束**（underconstrained）。

***

UNDERCONSTRAINED

***

当我们观察以合取范式（CNF）形式出现的可满足性问题时，过度约束的问题指句子中约束变量的句子相对较少。例如，下面是一个随机生成的 3-CNF 句子，包含五个符号和五个句子：

> (¬*D* ⋁ ¬*B* ⋁ *C*) ⋀ (*B* ⋁ ¬*A* ⋁ ¬*C*) ⋀ (¬*C* ⋁ ¬*B* ⋁ *E*)
>
> ⋀ (*E* ⋁ ¬*D* ⋁ *B*) ⋀ (*B* ⋁ *E* ⋁ ¬*C*).

这十六个 32 种可能的赋值中有六个是该句子的模型，因此平均而言只需两次随机猜测即可找到一个模型。这是一个容易的可满足性问题，这类过度约束问题也是如此。另一方面，过度约束的问题句子数量相对于变量数量很多，往往没有解。

要超越这些基本直觉，我们必须明确随机句子的生成方式。符号 `CNFk`表示一个*k*-CNF 句子，包含*m*个句子和*n*个符号，句子是从所有包含*k*个不同字面量（正或负）的句子中**不重复**地均匀、独立地选择的。

给定一个随机句子的来源，我们可以测量可满足性的概率。Figure 7.19(a) 将 `CNF3` 的概率——即包含 50 个变量和每条子句 3 个文字的句子——作为子句/符号比 *m*/*n* 的函数绘制。如我们预期，在 *m*/*n* 较小时，可满足性的概率接近 1，而在 *m*/*n* 较大时，概率接近 0。概率在 *m*/*n* = 4.3 附近下降相当陡峭。经验表明，“悬崖”（cliff）大致保持在同一位置（对于 *k* = 3），并且随着 *n* 的增大，悬崖变得越来越尖锐。理论上，**可满足性阈值猜想**指出，对于每个 *k* ≥ 3，存在一个阈值比值 *r*[*k*]，使得当 *n* 趋于无穷大时，对 `CNFk` 的可满足性概率在阈值以下的所有 *r* 中变为 1，在阈值以上的所有 *r* 中变为 0。该猜想仍未被证明。

### 7.7. AGENTS BASED ON PROPOSITIONAL LOGIC

本节汇集我们已学习的内容，构建使用命题逻辑的 Wumpus World 代理。第一步是让代理在尽可能大的程度上推断其感知历史所描述的世界状态。这需要编写一个完整的逻辑模型，描述动作的效果。我们还展示了代理如何高效地跟踪世界，而无需在每次推理时回溯到感知历史。最后，我们展示了代理如何利用逻辑推理构建保证能够实现目标的计划。

#### **7.7.1 The current state of the world**

正如本章开头所述，逻辑代理通过从关于世界的知识库（knowledge base）中的句子推断应做什么。知识库由公理（一般关于世界的知识）和从代理在特定世界中获得的感知句子组成。本节关注推断 Wumpus World 中的当前状态——我在第几格，该格是否安全，等等。

我们在 Section 7.4.3 开始收集公理。代理知道起始格没有坑（`¬P[1,1]`）和没有獾（`W[1,1]`）。此外，对于每个格子，它知道该格是否有风（breeze）当且仅当相邻格子有坑；该格是否有臭味（smell）当且仅当相邻格子有獾。因此，我们包含大量形式的句子：
