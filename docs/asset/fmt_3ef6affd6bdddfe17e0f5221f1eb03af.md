## 4.1 常量

PHP 中的常量与数学中的常量相似。记得我们在数学课中学过的数字 3.14159（保留 5 位小数）吗？这个数字被称为 Pi（π），它的值永远不会改变。就像数学中的 Pi 一样，我们可以在 PHP 中定义常量并给它们命名以便方便引用。要做到这一点，我们使用一个名为 `define()` 的内置函数。一旦我们定义了常量，就不允许更改它的值。要使用 `define()` 函数，我们需要向函数传递两个参数（用逗号分隔）——常量的名称（用引号传递）和值。常量的名称默认对大小敏感，并由字母、数字或下划线组成。然而，它必须以字母或下划线开头。在命名常量时使用全大写是一种惯例。让我们来看例子。

```php
define("BASIC_MEMBER", 111020);
echo BASIC_MEMBER;
echo '<BR>';
define("BASIC_MEMBER", 16932);
echo BASIC_MEMBER;
```

在这里，我们定义了一个名为 `BASIC_MEMBER` 的常量，并将其值指定为 `111020`。接下来，我们通过它的名称引用它并使用 `echo` 语句输出它的值。在输出值之后，我们尝试重新定义 `BASIC_MEMBER` 并将其值改为 `16932`。最后，我们再次输出它的值。如果你运行上面的代码，你将得到以下输出：

`111020

Notice : Constant BASIC_MEMBER already defined in ...

111020`

如果你仔细研究输出，你会发现我们在第一次定义之后没有成功更改 `BASIC_MEMBER` 的值。因此，当我们再次输出它时，它的值仍然是 `111020`。明白了吗？很好！在上面的示例中，请注意我们在输出值时没有将 `BASIC_MEMBER` 包在引号内。如果我们使用引号（例如 `echo 'BASIC_MEMBER';`），我们将得到输出 `BASIC_MEMBER` 而不是我们想要的结果。

## 4.2 变量

接下来，让我们进入变量。

变量用于在程序中存储数据。它们有名称，并在需要时更改其值。

与常量一样，变量名也需要遵循某些命名规则。首先，变量名必须以 `$` 符号开头。在该符号之后，名称不能以数字开头，只能包含字母、数字和下划线（`A-z`、`0-9` 和 `_`）。像 `$userName`、 `$age1` 和 `$user_email` 这样的名称是合法的，而像 `$4ever`（以数字开头）、 `$unit+NY`（包含 `+` 符号）和 `$var 1`（包含空格）这样的名称是不允许的。

接下来，变量名是对大小敏感的；`$userName` 与 `$username`。最后，变量名应该具有意义。使用 `$x`、 `$y` 和 `$z` 等变量来存储用户的姓名、年龄和密码会让你的代码变得混乱且不直观。虽然不是强制性的，但你绝对应该使用更有意义的名称，如 `$name`、 `$age` 和 `$password` 以提高代码的可读性。

在 PHP 中，变量有两种常用的命名风格。我们可以使用驼峰命名（camel case）或下划线（underscores）。驼峰命名是将复合词写成混合大小写的做法，每个单词（除第一个外）以大写字母开头（例如 `$thisIsAVariable`）。另一种常见风格是使用下划线（`_`）来分隔单词（例如 `$this_is_a_variable`）。选择哪种风格取决于个人喜好。更重要的是在整个代码中保持一致。在本书中，我们将为变量使用 `camelCase`。在 PHP 中声明变量时，我们编写如下代码：

```php
$x = 7;
```

在这里，我们声明了一个名为 `$x` 的变量并给它赋值为 `7`。给变量赋值被称为“对变量进行赋值”。在声明变量时给它赋一个初始值被称为“初始化变量”。这在 PHP 中并不是强制的。然而，不这样做被认为是一种坏习惯，因为可能会导致脚本出现意料之外的行为。当我们声明并初始化一个变量时，PHP 会在服务器存储空间上分配特定的区域来存储这些数据。随后你可以通过引用名称来访问并修改这些数据。例如，要显示 `$x` 的值，我们写道 `echo $x;`。

这将输出 `7`。

如果我们想改变 `$x` 的值，只需给它赋一个新值。例如，

```php
$x = 5;
echo $x;
```

这会更新 `$x` 的值并并输出 `5` 作为新输出。在上面的示例中，注意当我们使用 `echo` 语句时，没有将 `$x` 包在引号内。通常情况下，在使用 `echo` 语句时我们不会将常量、变量或函数的名称包含在引号中。这是因为 `echo` 语句会将引号内的任何内容视为文本或 HTML 代码，并将其原样输出。例如，如果我们写道 `echo '$x';`，

我们将得到

`$x`

作为输出。唯一的例外是包含在双引号中的变量名。如果我们将变量名包含在双引号中，`echo` 语句不会原样输出变量名。相反，它会将该名称替换为该变量的值并输出该值。例如，如果我们写道 `echo 'The value is $x.';`，

```php
echo '<BR>';
echo "The value is $x.";
```

我们将得到 `The value is $x. The value is 5.` 作为输出。当我们使用单引号时，`echo` 语句原样输出文本。相比之下，当我们使用双引号时，它会将 `$x` 替换为它的值。懂了吗？

## 5 PHP 中的运算符

PHP 带有许多可以与变量使用的运算符。让我们先讨论赋值运算符。

1. 赋值运算符

4.5.2 算术运算符

接下来，让我们讨论算术运算符。这些运算符用于执行基础算术运算。它们包括加法（`+`）、减法（`-`）、乘法（`*`）、除法（`/`）、取模（`%`）和幂（`**`）运算符。假设你有

```php
$x = 5;
$y = 2;
```

`$x + $y` 得到 `7`，`$x - $y` 得到 `3`，`$x*$y` 得到 `10`，`$x/$y` 得到 `2.5`，`$x%$y` 得到 `1`，因为取模运算符给出 `5` 除以 `2` 的余数，而 `$x**$y` 得到 `25`。

我们得到 25，因为幂运算符给了我们 5 的 2 次方的值。

### 4.5.3 复合赋值运算符

除了上述的算术运算符外，我们还有一组将算术运算与赋值结合的运算符。假设你有一个变量 `$x = 5;`，并且你想给 `$x` 加 3，你可以这样操作：

```php
$x = $x + 3;
```

赋值总是从右向左进行的。因此，右侧的表达式（`$x + 3`）首先被求值，得到 `5+3`。然后这个值被赋值回左侧的变量 `$x`。换句话说，`$x` 的值变成了 8。

除了 `$x = $x + 3;` 之外，我们还可以使用 `+=` 运算符。该运算符是赋值运算符与加法运算符的简写。如果你写：

```php
$x = 5;
$x += 3;
echo $x;
```

你将得到输出 8。`$x += 3` 仅仅意味着 `$x = $x + 3`。
