
输入门允许 LSTM 通过选择性地允许或阻塞信息来处理长时间依赖关系并理解序列统计中的相关样式 [2]。

随后，通过前一个细胞状态的构建和输入门的补充（1 – 输入门输出）增加输出。通过保留长期依赖关系并选择性地添加新记录，这种混合修改了移动状态。

#### 2.3.2.3.1.5 输出状态

基于更新后的细胞状态，长短期记忆（`LSTM`）网络中的输出门决定了后续隐藏状态。以下是输出门特征的证据：

- `Sigmoid 激活`：输出门的输入由之前的隐藏状态和当前输入组成。这些输入经过 sigmoid 激活函数的处理，生成 0 到 1 之间的值。这些值充当门的作用，决定了更新后的细胞状态中有多少量应该输出到输出。接近 1 的值表示“暴露这些记录”，而接近 0 的值则意味着“掩盖这些数据”。

- `逐元素相乘`：经过 `tanh` 变换的更新细胞状态随后通过 sigmoid 输出进行精细化缩放。进入下一个隐藏状态的值通过这种乘法确定。

输出门通过从更新的细胞状态中选择性地显示相关信息，创建相应的隐藏状态。通过这种技术，LSTM 能够从序列事实中识别并提取关键模式，以产生独特的预测 [3]。

### 2.3.2.4 生成对抗网络 (GAN)

一种称为生成对抗网络（`GAN`）的深度学习架构由两个对抗训练的神经网络组成：判别器和生成器。使用 GAN 可以产生模拟特定数据集的新数据样本 [1]。

##### 2.3.2.4.1 生成对抗网络 (GAN)：架构

###### 2.3.2.4.1.1 生成器

生成器的任务是产生与实际数据分布相似的虚假数据样本（如照片）。它使用随机噪声作为输入，在训练过程中创建越来越好的数据样本。生成器通常包含一个或多个层，为了提高数据空间分辨率，经常使用转置卷积层 [1]。

###### 2.3.2.4.1.1.1 生成器架构

- `输入层`：从随机噪声向量（`z`）中随机采样的类高斯基础分布。

- `隐藏层`：一系列隐藏层，通常是转置卷积层或全连接层，逐渐将输入中的噪声转换为类似于真实数据的数据。

- `输出层`：最后一层生成创建的数据样本，例如图像。

###### 2.3.2.4.1.2 判别器

判别器的任务是区分真实数据样本和虚假样本。在接受来自生成器的数据以及真实数据样本后，它为每个输入分配一个真实概率。判别器接受训练以增强其区分真数据和伪数据的能力 [1]。

###### 2.3.2.4.1.2.1 判别器架构

- `输入层`：数据样本，可能是真实的（来自原始数据集）或伪造的（由生成器创建）。

- `隐藏层`：判别器像生成器一样，使用隐藏层处理输入数据，经常利用卷积层或全连接层。

- `输出层`：最后一层生成一个概率分数，显示输入是否真实。通常，它使用 sigmoid 激活函数生成 0 到 1 之间的值。

###### 2.3.2.4.1.3 训练过程（对抗训练）

在训练期间，生成器和判别器之间进行着游戏。生成器试图提供与真实数据几乎相同的数据以欺骗判别器。判别器的目标是区分真实和错误数据。这种竞争动态使得每个网络随着时间的推移不断改进 [1]。

## 2.4 激活函数和损失函数

### 2.4.1 激活函数

深度学习神经网络的一个至关重要的部分是激活能力。它们提供了非线性版本，有助于理解复杂的模式并提供额外的准确预测。在深度学习中，通过激活能力可以实现以下目标：

- `定义非线性`：

- 如果没有激活能力，神经网络可能仅仅是其输入的线性组合。用于影响神经元输出并引入非线性的数学操作被称为激活能力。如果没有这种非线性，网络无法近似记录中复杂的非线性能力。

- `促进复杂的表示`：

- 借助激活函数，神经网络可以检查并构建记录中复杂的能力和分层抽象。图像识别中的边缘、纹理、形状和更高级的思维，或自然语言处理中的抽象模式，都应该是这些能力的示例。

#### 2.4.1.1 常见激活函数

1. i. `Sigmoid 函数（逻辑激活）`

- Sigmoid 平滑 0 到 1 范围内的输入值。它经常被用作神经网络的激活函数，为二分类问题添加非线性 [5]。

- `输出范围`：(0, 1)

- `公式`：`1 / (1 + e(-x))`

- 具有用于二分类输出的历史。

- 一种将输入限制在 0 到 1 之间的 S 形曲线。

- 存在梯度消失问题。

2. ii. `双曲正切函数`

- 双曲正切将输入值压缩在 -1 到 1 之间，功能与 sigmoid 相似。它经常用于 LSTM 和 RNN 中处理以零为中心的数据。

- `输出范围`：(-1, 1)

- `公式`：`tanh(x) = (e(x) - e(-x)) / (e(x) + e(-x))`

- 其零中心特征使其与 sigmoid 相似。

- 也存在梯度消失问题 [4]。

3. iii. `ReLU（线性单元）`

- 当 ReLU 被激活时，直接输出正输入；否则输出零。它的流行源于对稀疏表示的促进以及易于使用。

- `输出范围`：0, ∞)

- `公式`：`ReLU(x) = max(0, x)`

- 由于其有效性和简单性，它是最常用的激活函数。

- 实验观察到它可以加速训练收敛。

- 然而，当某些神经元死亡时，可能会遇到“死亡 ReLU”问题。

4. iv. `Leaky ReLU（带漏的线性单元）`

- 通过允许负输入产生产生微小的正梯度，Leaky ReLU 避免了神经元输出零的死亡 ReLU 问题。它在处理负输入值的同时解决了 ReLU 的缺点。

- `输出范围`：(-∞, ∞)

- `公式`：`Leaky ReLU(x) = x if x > 0, else a * x`（其中“a”是一个较小的正常数，通常为 0.01）

- 允许负输入产生微小梯度，这解决了死亡 ReLU 问题。防止了神经元完全失活 [[5]。

### 2.4.2 损失函数

一种通常被称为代价函数或目标特征的损失特性（loss characteristic），是小工具设备学习中深度神经网络社区模型训练方法的重要部分。真实目标值（地面真值）与期望值（模型输出）之间的不准确性或差异就是测量的对象。这种损失特征通过显示版本运行的好坏程度来告知掌握方式，因此，最小化它到目前是训练过程中的首要目标 [6]。让我们仔细观察损失能力：

### 2.4.2.1 损失函数的用途

- **衡量误差：** 特别用于区分真实目标值与模型预测值之间差异的损失特征。损失将随误差成比例增加。

- **引导优化：** 在学习过程中，通过修改版本的权重和偏置来限制损失。这些修改是通过使用梯度下降等优化技术完成的，这些技术计算损失函数相对于参数的梯度。

- **指定目标：** 根据任务的类型（例如，分类、回归或生成式建模），损失函数的选择设定了模型的特定学习目标。

### 2.4.2.2 损失函数的类型

#### 2.4.2.2.1 回归损失函数

当目标是预测连续数值时，会使用回归损失函数。

1. i. **均方误差 (MSE) 损失：**

2. MSE 是一种额外的指标，用于计算预测值与观测值之间平方差的平均值。虽然它比 MAE 对离群值（异常）更敏感，但它对较大误差的惩罚更严厉，这通常会导致训练优化景观更加平滑。

   - **公式：** `MSE = (1/n) * Σ (yᵢ – ŷᵢ)²`，其中 `n` 是数据点数量，`ŷᵢ` 是预测值，`yᵢ` 是真实值。

   - 常用于常见的回归问题。

   - 突出了较大的误差并关注离群值 [6]。

3. ii. **平均绝对误差 (MAE) 损失：**

   MAE 指标衡量了预测值与实际值之间的平均绝对差异。它提供了一个直观、易懂的平均预测误差指标。

   - **公式：** `MAE = (1/n) * Σᵢ – ŷᵢ|`，其中 `n` 是数据点数量，`ŷᵢ` 是预测值，`yᵢ` 是真实值。

   - 衡量预测值与值之间的平均绝对差。

   - 与 MSE 相比，较不受离群值影响 [7]。

#### 2.4.2.2.2 分类损失函数

这些用于分类任务，其目标是将数据点分配到离散类别。

1. i. **二分类交叉熵损失（对数损失）：**

2. 二分类问题使用的损失函数之一是二分类交叉熵。它通过衡量预测概率与实际二分类结果之间的差异，鼓励模型减少每个实例期望值与实际值之间的差异。

   - **公式：** `BCE = –Σ (yᵢ * log (ŷᵢ) + (1 – yᵢ) * log (1 – ŷᵢ))`，其中 `ŷᵢ` 代表类别 1 的期望概率，`yᵢ` 代表真实类别（0 或 1）。

   - 用于需要二分类任务的任务。

   - 计算期望类别概率与实际类别分布之间的差异 [7]。

3. ii. **分类交叉熵损失（Softmax 损失）：**

4. 涉及多个类别分类的任务使用分类交叉熵。它通过衡量期望类别概率与实际类别分布之间的差异，鼓励模型分配更高的概率概率。

   - **公式：** `CCE = –Σ (yᵢ * log (ŷᵢ))`，其中 `yᵢ` 是 one-hot 编码的真实类别，`ŷᵢ` 是预测类别概率。

   - 用于多类别任务。

   - 惩罚 [7]。

#### 2.4.2.2.3 生成损失函数

这些用于如生成对抗网络（GAN）和变分自编码器（VAE）等生成模型。

1. i. **GAN 损失：**

2. GAN 使用两部分损失函数：

3. **生成器损失：** 指示生成器欺骗判别器的能力。

4. **判别器损失：** 指示判别器区分人工真实样本的能力。

5. ii. **变分自编码器 (VAE) 损失：**

6. VAE 使用组合损失：

   - **重建损失：** 为了鼓励模型准确重建输入，重建损失衡量输入与重建输出之间的差异。

   - **KL 散损失：** 当潜变量偏离指定分布（通常为高斯分布）时惩罚潜空间 [7]。

取决于问题的性质和使用的数据类型，必须选择合适的损失函数。选择最佳损失函数需要在解释性、稳健性和数据集特性之间进行权衡。不同的损失函数突出了性能的各个方面。通常通过实验和领域知识来选择合适的损失函数。

## 2.5 反向传播与梯度下降

### 2.5.1 反向传播

深度学习的一个重要部分是熟悉被称为反向传播的方法，有时称为“误差反向传播”，它用于训练神经网络。为了提供可靠的预测，最小化目标损失特征并修改社区的权重和偏置至关重要 [6]。以下是反向传播规则的详细说明：

1. i. **前向传播：**

前向传播是反向传播的初步阶段。在此期间，神经网络接收输入并通过将其传递到输出层来做出预测。每一层通过计算其输入的加权和并使用激活特性产生其输出。6]

2. ii. **计算损失：**

在前向跳跃后，将神经网络的输出与精确目标值进行比较。使用损失特征（也称为代价特性）来确定预测与实际目标之间的误差或差异。根据具体处理的任务，可能会选择包含均方误差的回归或交叉熵的分类的损失函数。

3. iii. **后向传播（反向传播）：**

反向传播（也称为后向传播）反向传播技术的第一部分是后向传播，包括从输出层返回输入层时计算损失的梯度（导数），并考虑版本的参数（权重和偏置）。

4. iv. **链式法则：**

使用链式法则来计算梯度。它指出复合特征的导数等于其因子函数导数的乘积。在神经网络的上下文中，损失相对于单层参数的梯度可以通过链式后续层的梯度来计算。

## v. 梯度计算：

对于每一层，梯度的计算分两个步骤进行：

*   **局部梯度计算：**

    局部梯度是应用于该层的激活函数的加权和加权导数。它衡量了该层输出对加权和变化的变化的敏感程度。

*   **误差反向传播：**

    损失相对于加权和的梯度通过将局部梯度与损失相对于该层输出的梯度（在上一层中计算）相乘得到。

*   **权重和偏置更新：**

    在计算梯度后，每一层的权重和偏置将以最小化损失的方向进行更新。通常使用如梯度下降等优化算法来执行此更新。控制优化过程中步长的学习率超参数也控制了更新的大小。

## vi. 迭代过程：

步骤 1 到 6 会针对预定义的轮次（epochs）数量反复重复执行，或者直到损失收敛到可以接受的水平。随着模型不断获得使用训练数据改进其预测的能力，它会不断调整参数以最小化损失。[8]

## vii. 随机梯度下降 (SGD)：

随机梯度下降是实践中确实被使用的梯度下降的一个版本。它被频繁使用，在每个新发布时计算梯度，并随机选择一个微批（mini-batch）训练示例。在优化过程中引入随机性有助于防止陷入局部最优。

这是神经网络领域的核心规则；反向传播的有效性使得深度和复杂模型的训练成为可能。它是许多程序中深度获取有效性知识的关键，包括强化学习、自然语言处理和图像流行化。

### 2.5.2 梯度下降

在训练期间，神经网络的权重和偏置通过一种称为梯度下降的基础优化方法进行更新。其核心目标是限制一个确定的损失特征，该特征衡量了模型版本的预测输出与数据集实际目标值之间的差异。关于用于深度学习的梯度下降算法的详细解释见下文 [10]。

### i. 初始化：

参数（权重和偏置）在整个学习过程中首先初始化为较小的随机值。神经网络的行为通过这些参数来定义。

### ii. 前向传播

前向传播是在整个学习过程中将输入信息通过神经网络传输的技术。每一层都会计算网络输入的加权和，然后使用激活特征生成该层的输出。层层递进，前向传播一直持续直到获得理想的输出。[10]。

### iii. 计算损失：

前向传播完成后，将神经网络的输出与真实目标值进行比较。在比较预期输出与真实目标时，使用损失特征（也称为代价函数）计算误差或差异。均方误差（MSE）是回归中常见的损失特征，而交叉熵（原文为 move entropy）用于分类 [10]。

### iv. 梯度计算：

梯度计算，即损失函数相对于模型参数的导数，是梯度下降的基础。梯度展示了改变参数将如何改变损失。由于它允许将复合函数的导数写为各个分函数导数之和，因此使用微积分中的链式法则来计算梯度。梯度显示了为了减少损失而对神经网络应做的每个参数修改的大小和方向 [11, 12]。

### v. 更新参数：

在计算梯度后，神经网络的权重和偏置将以最小化损失的方向进行更新。通常使用如梯度下降等优化算法来执行此更新。控制优化过程中步长的学习率超参数也控制了更新的大小。

## vi. 迭代过程：

步骤 1 到 6 会针对预定义的轮次（epochs）数量反复重复执行，或者直到损失收敛到可以接受的水平。随着模型不断获得使用训练数据改进其预测的能力，它会不断调整参数以最小化损失。

## vii. 随机梯度下降 (SGD)：

随机梯度下降是实践中确实被使用的梯度下降的一个版本。它被频繁使用，在每个新发布时计算梯度，并随机选择一个微批（mini-batch）训练示例。在优化过程中引入随机性有助于防止陷入局部最优。

深度学习中使用的许多优化技术，结合微批梯度下降、adam、RMSprop 等，都是构建在梯度下降的概念之上的 [16, 17]。优化方法和超参数（包括学习率）的选择在深度神经网络中是非常重要的。
