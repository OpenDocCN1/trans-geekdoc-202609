
# 典型无线客户端 VPN 解决方案

在典型的无线客户端 VPN 解决方案中，无线客户端首先连接到无线网络。无线网络可能已实施前文讨论的一些安全预防措施，例如禁用 SSID 广播、启用 `WPA2` 或配置 MAC 过滤。关键在于，如果授权无线客户端连接到无线网络，它们仍然无法访问公司资源，因为它们尚未通过 VPN 连接。在连接到无线网络并获取 IP 地址后，无线客户端将通过 VPN 软件访问网络。VPN 软件将对用户进行身份验证，并创建一条加密隧道，以保护从客户端传输到企业网络的数据。

# 考试内幕

## 保护无线网络

Security+ 认证考试要求你了解无线网络和安全最佳实践。保护无线网络至关重要，因为未经授权的个人无需亲身进入你的大楼即可访问网络。未经授权的人员可能坐在大楼外的车里，甚至在隔壁的办公大楼里。

以下是保护无线网络时需要记住的要点：

- 为管理员账户设置密码。
- 更改 SSID。
- 禁用 SSID 广播。
- 使用 MAC 过滤。
- 使用 `WPA2` 或 `WPA3` 配置加密。
- 将接入点放置在大楼中心位置。
- 降低功率电平以控制无线信号传播距离。
- 在高安全环境中使用 VPN 解决方案。

### 无线网络漏洞

现在你已经了解了一些保护无线网络的常见做法，我想讨论一下黑客在无线攻击中利用的无线网络常见漏洞。以下是现实世界中需要记住的一些关键漏洞，同时也是 Security+ 认证考试的重点。

#### 数据泄漏、干扰/阻塞和数据包嗅探

由于无线网络流量通过空气传输，因此容易受到干扰和数据包嗅探。以下是关于无线漏洞的注意事项：

- **数据泄漏** 电子元件始终会释放辐射，有人可能会收集电气元件的辐射并将其拼凑成可读数据。
- **干扰/阻塞** 如前所述，你可能会因无绳电话等设备而遇到无线网络干扰。这是一个安全问题，因为干扰可能导致无线网络瘫痪，这违反了可用性（还记得第 2 章中关于 CIA 的讨论吗）。
- **数据包嗅探** 任何拥有无线网卡和嗅探器的人都可以轻松捕获无线数据。请务必加密所有无线通信以保护机密数据。

![Image](img/exam.jpg)

> **针对 Security+ 考试，请记住无线网络面临的风险包括数据泄漏、干扰和阻塞以及数据包嗅探。你可以通过实施法拉第笼或 TEMPEST 系统来缓解这些风险。两者均用于阻止信号传出特定区域。**

#### 网络寻踪和网络标记

无线网络的另一个常见漏洞是网络寻踪，即有人开着车带着笔记本电脑四处游荡，试图定位可连接的无线网络。

另一个你应该了解的与网络寻踪相关的术语是*网络标记*。在网络标记中，当有人发现无线网络时，他们会在建筑物外用粉笔画上符号，通知网络寻踪社区的其他成员该建筑内存在无线网络。通过网络标记，不同的符号代表所发现无线网络的配置。例如，图 9-8 显示了三种不同的符号：开放网络（允许任何人连接）、带有 SSID 的封闭网络，以及使用 WEP 的安全网络。每个符号上方标注 SSID，下方标注带宽。

#### SSID 广播

我们讨论的另一个常见漏洞是 SSID 广播。启用 SSID 广播后，人们很容易找到你的无线网络并尝试连接。将 SSID 更改为一个与网络用途不明显相关的名称，并在无线路由器上禁用 SSID 广播。

#### WPS 攻击和重放攻击

对于无线网络，还有两种需要熟悉的攻击类型：WPS 攻击和重放攻击。以下概述了这两种不同类型的攻击：

- **WPS 攻击** Wi-Fi Protected Setup（WPS，Wi-Fi 保护设置）是几年前推出的一项无线安全功能，允许用户输入 PIN 码（位于无线路由器背面）以连接到无线网络。使用 PIN 码后，SSID 和 `WPA2` 加密密钥将自动配置。创建此安全功能是为了让对无线网络知之甚少的家庭用户能够轻松创建和加入其无线网络。2011 年，WPS 中发现了一个漏洞，允许攻击者对 WPS PIN 码执行暴力破解攻击。
- **重放攻击** 重放攻击是无线网络中常见的一种攻击类型，黑客试图破解加密密钥。为了破解加密密钥，黑客必须产生足够的流量，以便破解工具执行破解。黑客不必等待无线接收点接收足够的流量，而是可以使用嗅探器捕获流量并重新发送或重放该流量。

#### 蓝牙劫持和蓝牙窃取

在第 5 章中，我们讨论了蓝牙设备的漏洞。两种常见的漏洞是蓝牙劫持和蓝牙窃取：

- **蓝牙劫持** 利用蓝牙无线协议向其他支持蓝牙的设备（如手机和平板电脑）发送未经请求的消息
- **蓝牙窃取** 通过从支持蓝牙的设备复制数据来利用该设备

#### 非法接入点和邪恶双生子

非法接入点是组织面临的严重漏洞，也是你需要为 Security+ 认证考试熟悉的内容。场景是这样的：你已经保护了网络环境，但网络安全很容易被员工连接无线路由器到网络从而破坏，以便他们在公司食堂吃午餐时能连接网络并访问互联网。

在此示例中，员工没有意识到他们通过将无线路由器连接到网络而给公司资产带来了风险。这被视为网络的非法接入点，因为它是网络管理员不知情的未授权设备。

![Image](img/exam.jpg)

> **针对考试，请记住非法接入点是网络的巨大漏洞。你应该使用 `Acrylic WiFi`、`Cain & Abel` 或 `Kismet` 等软件定期执行无线扫描，以定位任何非法无线接入点。**

值得注意的是，在企业网络中，无线控制器用于集中配置整个网络中的无线接入点。它们也可用于检测和阻止网络上的非法接入点。

黑客可以从笔记本电脑的无线连接安装一个流氓接入点，并使该笔记本电脑设备看起来像是一个有效的接入点。这被称为*evil twin*（邪恶双胞胎），对黑客的好处是客户端会连接到黑客的伪造接入点，以为它是一个有效的无线网络。在此无线网络上发送的所有数据都将发送到黑客的笔记本电脑，黑客可以在其中捕获并读取数据。

![Images](img/job.jpg)

**为了帮助保护公司系统免受邪恶双胞胎攻击，请为所有连接到公司系统的无线客户端使用 VPN 解决方案。VPN 将通过使用加密隧道在无线客户端和公司服务器之间传输数据来保护传输安全。**

## 安装注意事项

安装和管理无线网络时，您需要考虑许多安装因素。这包括执行站点勘测、确定接入点的最佳位置以及使用 `Wi-Fi` 分析仪等工具等任务。

### 执行站点勘测

定期执行无线现场勘测非常重要，以识别连接到网络的任何非法无线设备。组织内的员工通常会将无线路由器连接到办公室的网络端口，然后将公司工作站连接到该无线路由器。员工这样做通常是为了能使用笔记本电脑或平板电脑等移动设备连接到公司网络。

这种配置的弊端在于它给公司带来了巨大的安全风险。公司实施的所有物理安全措施都将失效，因为黑客可以通过员工连接到网络的无线路由器获得网络访问权限！请务必定期使用无线扫描器进行现场勘测，这能让你识别办公室内的非法无线路由器或接入点。

### Wi-Fi 分析仪

`Wi-Fi` 分析仪是一种用于执行无线网络发现及其特征分析的工具，例如其工作信道、安全类型、信号强度、所经历的任何噪声和干扰以及数据速率。安全专业人员在执行现场勘测时会使用 `Wi-Fi` 分析仪。

### 其他安装注意事项

安装和管理无线网络时还应考虑许多其他因素。以下是一些额外的注意事项：

- **热力图** 许多 `Wi-Fi` 分析仪都具备创建热力图的功能，热力图是设施布局的图形化视图，使用不同颜色显示覆盖建筑物不同区域的信号强度。例如，红色区域可能表示极佳的信号强度，蓝色可能表示极弱的信号强度，而白色可能显示盲区，即没有信号强度的区域。
- **信道重叠** 如果你的区域内有多个无线网络，可能会遇到来自其他运行在同一信道上的无线设备的干扰。使用无线分析仪检测其他无线网络并识别其信道，然后将你的无线信道更改为非重叠信道以避免干扰。
- **WAP 放置** 如前所述，你需要仔细规划接入点的最佳位置，以便在网络内实现最大覆盖范围。
- **控制器和接入点安全** 请务必实施无线控制器或接入点支持的最佳安全协议，并尽可能实施更多安全功能。这包括使用 `WPA2`/`WPA3` 加密、实施 `MAC` 过滤以及调整信号功率电平。对于企业网络，请考虑使用 `802.1X`，以确保客户端在获得无线网络访问权限前由 `RADIUS` 服务器进行身份验证。

# 认证目标 9.03

## 配置无线网络

在本节中，你将学习配置无线接入点和无线客户端的步骤。请务必熟悉设置类型，但要注意不同品牌和型号的无线路由器，其屏幕和步骤会有所不同。

请注意，本节将介绍无线路由器的典型配置设置。屏幕和命令特定于所使用的品牌和型号。如果你手边没有无线路由器但想尝试其中一些步骤，可以使用 `D-Link` 模拟器：<https://support.dlink.ca/emulators/wbr2310/index.htm>。这提供了所有设置屏幕，让你无需设备即可尝试配置无线路由器的步骤。

### 配置接入点

无线接入点有两种不同形式。*胖接入点*是一种独立的接入点，可以单独配置，也可以通过无线控制器配置。胖接入点连接到交换机，以便无线客户端能访问网络。*瘦接入点*无法作为独立设备单独配置。瘦接入点由*无线控制器*配置，而无线控制器现在是以太网交换机的一部分。与一堆独立接入点相比，使用无线控制器搭配瘦接入点的好处在于，你可以从无线控制器向接入点推送配置，从而实现对无线功能和安全性的更集中管理。

拿到无线路由器后，首先将互联网调制解调器连接到无线路由器的 `WAN` 端口。然后可以将网络上的任何有线系统连接到路由器交换机部分的四个端口中的任意一个，如图 9-9 所示。请记住，如果这只是一个无线接入点，而不是具有无线接入点功能的无线路由器，那么该无线接入点将只有一个网络端口，用于连接到有线网络。

连接好所有设备并给路由器供电后，你需要执行一些基本配置步骤以确保设备安全。我要强调的是，仅仅插上电源，无线路由器就已经在工作并允许无线客户端访问网络了。你需要控制谁可以连接到无线网络！以下部分概述了一些可更改的基本设置。

#### 管理员密码

第一步是更改无线路由器的管理员密码。此密码由制造商默认设置，任何人都能通过快速 `Google` 搜索找到默认密码。要更改管理员密码，你需要启动 `Web` 浏览器并输入无线路由器的 `IP` 地址。`IP` 地址通常是 `192.168.1.1` 或 `192.168.0.1`，具体取决于制造商。

输入 `IP` 地址后，系统会提示你登录。在我的示例中，我使用的是 `D-Link DIR-615` 无线路由器，初次开箱时其管理员账户没有密码。要登录路由器，请确保用户名选择 `Admin`，然后输入密码，如果不知道密码则留空。点击 `Log In` 按钮登录到无线路由器的管理页面。
