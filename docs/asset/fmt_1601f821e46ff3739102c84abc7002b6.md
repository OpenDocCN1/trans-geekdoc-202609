下界泛函 ℱ(*q*[𝒳^(*l*)], *q*[**θ**], **ξ**) 依赖于三个项。遵循交替优化的原理，在每一步迭代中，我们将冻结其中两个项，并对剩余的一个项进行最大化，以交替的方式进行。通过将相应的、适当定义的 KL 散度设为零，将针对某个分布来优化下界泛函。为此，例如，让我们以一种稍微不同且更方便的形式重写公式 (13.6)。定义量 *p̃* 为

*   注意 `q(X^(l), θ)` 是后验概率 `p(X^(l), θ|X)` 的估计，且每个因子都是给定观测值 `X` 条件下相应的后验估计，例如 `q_θ(θ) ≈ p(θ|X)`。

*   •  注意，PDF 的分解意味着独立性。因此，如果手头的数据不满足这种情况，恢复出的近似可能不是底层数据结构的忠实表示。因此，选择特定的分解必须谨慎进行。在实践中，可能不得不使用多种替代方案并保留最佳的一个。然而，计算复杂度是硬币的另一面，必须在权衡博弈中加以考虑。一般来说，分解变分方法倾向于提供比真实后验 PDF 更紧凑的近似（例如 [47]）。

*   •  回顾我们在第 12.3 节中关于模型选择和奥卡姆剃刀原则的讨论。这是我们致力于针对不同模型最大化证据以实现复杂度-精度权衡的出发点。然而，由于求助于近似解（即使我们忽略收敛到局部最大值的问题，这某种程度上可以通过使用不同的初始化来绕过），我们并非最大化证据本身，而是最大化其下界；一般来说，后者并不紧致。其紧致程度取决于 KL 散度，遗憾的是，后者无法轻易计算。因此，如果将下界用于模型选择，必须谨慎对待 [7]。

*   •  变分贝叶斯推断最早由 [25] 提出，随后被应用于从机器学习到解码等多个领域（例如 [7,26,31–33,35]）。

*   •  *在线版本*：变分贝叶斯算法的在线版本最早由 [73] 提出。文中采用了指数族分布，证明了基于变分贝叶斯理念的参数更新等同于步长为 1 的自然梯度下降法（关于自然梯度见第 8.12 节）。文献 [28] 进一步讨论了这种等价性，并类似地提出了一种随机近似算法，以便并行处理数据块。文献 [86] 还提出了一种用于稀疏线性回归建模背景下参数估计的在线变分贝叶斯算法。

### 13.2.1 概率分布指数族的情况

仔细观察公式 (13.12) 和 (13.13)，可以清楚地看到，变分贝叶斯 EM 算法的实际应用取决于 `ln p(𝒳, 𝒳^(l)|θ; ξ)` 期望值的计算可行性。现在让我们来看看当采用指数族的 PDF 模型时，迭代步骤所采取的形式。

假设完整数据集中的样本 `(x[n], x[n]^(l))`，`n = 1, 2, …, N` 是独立同分布的。则

```
p(𝒳, 𝒳^l|θ) = ∏_{n=1}^N p(x_n, x_n^l|θ).
```

(13.16)

我们进一步假设 `p(x[n], x[n]^(l)|θ)` 属于指数族（第 12.8 节），即

### 数学公式推导

*p*(**x**[*n*], **x**[*n*]^(*l*) | **θ**) = *g*(**θ**)*f*(**x**[*n*], **x**[*n*]^(*l*)) exp(**ϕ**^(*T*)(**θ**)**u**(**x**[*n*], **x**[*n*]^(*l*))).

![Equation](img/si55.png) (13.17)

我们还为 **θ** 采用了相应的共轭形式先验，即

*p*(**θ** | *λ*, **v**) = *h*(*λ*, **v**)(*g*(**θ**))^(*λ*) exp(**ϕ**^(*T*)(**θ**)**v**).

![Equation](img/si56.png) (13.18)

参数 *λ*、 **v** 构成 **ξ**，将被视为固定，因为我们目前的重点是跟进 *q*[𝒳^(*l*)] 和 *q*[**θ**] 随迭代进展而获得的具体函数形式。因此我们放宽了对这些参数的符号依赖。

### E-步骤 1a

根据公式 (13.12)，我们有

```
q_{\mathcal{X}^{l}}^{(j + 1)}(\mathcal{X}^{l}) \propto \exp\left( \mathbb{E}_{q_{\mathbf{\theta}}^{(j)}}\ \left\lbrack \ln p(\mathcal{X},\mathcal{X}^{l}|\mathbf{\theta}) \right\rbrack \right) = \exp\left( \mathbb{E}_{q_{\mathbf{\theta}}^{(j)}}\ \left\lbrack \sum\limits_{n = 1}^{N}\ln p(\mathbf{x}_{n},\mathbf{x}_{n}^{l}|\mathbf{\theta}) \right\rbrack \right) = \prod\limits_{n = 1}^{N}\exp\left( \mathbb{E}_{q_{\mathbf{\theta}}^{(j)}}\ \left\lbrack \ln p(\mathbf{x}_{n},\mathbf{x}_{n}^{l}|\mathbf{\theta}) \right\rbrack \right),
```

![Equation](img/si58.png)

由此可知

```
q_{\mathbf{x}_{n}^{l}}^{(j + 1)}(\mathbf{x}_{n}^{l}) \propto \exp\left( \mathbb{E}_{q_{\mathbf{\theta}}^{(j)}}\ \left\lbrack \ln p(\mathbf{x}_{n},\mathbf{x}_{n}^{l}|\mathbf{\theta}) \right\rbrack \right),
```

![Equation](img/si59.png)
