### theHarvester

`theHarvester` 是用于枚举给定主机或 IP 地址 DNS 信息的工具。它可以查询多个数据源，包括百度、Google 和 LinkedIn。

```
omar@kali:~$ theharvester -h
Usage:theharvester options

         -d: 要搜索的域名
         -b: 数据源: baidu, bing, bingapi, dogpile, google, googleCSE, googleplus, google-profiles, linkedin, pgp, twitter, vhost,virustotal, threatcrowd, crtsh, netcraft, yahoo, all
      -s: 从结果 X 开始（默认: 0）
      -v: 通过 DNS 解析验证主机名并搜索虚拟主机
      -f: 将结果保存为 HTML 和 XML 文件（两者都要）
      -n: 对发现的所有范围执行 DNS 反向查询
      -c: 对域名进行 DNS 暴力破解
      -t: 执行 DNS TLD 扩展发现
      -e: 使用此 DNS 服务器
      -l: 限制处理的结果数量（bing 从 50 个结果变为 50 个，google 从 100 变为 100，pgp 不使用此选项）
       -h: 使用 SHODAN 数据库查询发现的主机

Examples:
        theharvester -d microsoft.com -l 500 -b google -h myresults.html
        theharvester -d microsoft.com -b pgp
        theharvester -d microsoft -l 200 -b linkedin
```

### Shodan

Shodan 是一种针对连接到设备的搜索引擎。Shodan 持续扫描互联网，并通过其网站 ([`www.shodan.io`](https://www.shodan.io)) 和 API 向用户公开搜索结果。攻击者可以使用此工具识别互联网上存在漏洞且暴露的系统（例如，配置错误的 IoT 设备、基础设施设备）。渗透测试人员可以使用此工具收集有关暴露在互联网上的潜在漏洞系统的信息，而无需主动扫描他们的目标。图 10-5 显示了针对暴露在互联网上的 Cisco Smart Install 设备的 Shodan 搜索结果。

### Maltego

从公开记录中收集信息是流行的被动侦察工具之一。它支持许多第三方集成。Maltego 有多个版本，包括社区版（免费）以及多个商业版 Maltego 客户端和服务器选项。你可以从 [`www.paterva.com`](https://www.paterva.com) 下载并获取有关 Maltego 的信息。Maltego 可用于查找有关公司、个人、帮派、教育机构、政治运动组织、宗教团体等的信息。Maltego 将查询实体组织在实体面板（Entity Palette）中，搜索选项被称为 `transforms`（转换）。图 10-6 显示了针对个人实体（在本例中针对本书的合作者 Omar Santos）的搜索结果截图。结果具有层级结构，你可以对结果（实体）进行额外的查询/搜索。

在 Maltego 转换枢（Transform Hub）中，你可以选择可以与 Maltego 集成的免费和商业产品。例如，你可以将 Maltego 与 Shodan 或一个名为 HaveIBeenPwned 的网站集成，该网站允许你查询某个人或电子邮件地址是否在数据泄露中被曝光（并可能收集从此类泄露中窃取的凭据）。数十种额外的工具和商业产品都可以与 Maltego 集成，如图 10-7 所示。

## Recon-ng
