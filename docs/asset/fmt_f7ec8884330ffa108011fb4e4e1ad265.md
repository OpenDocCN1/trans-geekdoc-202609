
```python
data = read_csv(filename, names=names)

data.plot(kind='density', subplots=True, layout=(3,3), sharex=False)

pyplot.show()
```

### 箱线图

查看每个属性分布的另一种实用方法是使用箱线图（boxplots）。箱线图通过绘制中位数线以及第 25 百分位数和第 75 百分位数周围的箱体来总结每个属性的分布。须线提供了数据分布的概念并显示了离群值（大于四分位距 `IQR` 1.5 倍的值）。

### 箱线图示例

```python
from matplotlib import pyplot
from pandas import read_csv

filename = "pima-indians-diabetes.csv"
names = ['preg', 'plas', 'pres', 'skin', 'test', 'mass', 'pedi', 'age', 'class']

data = read_csv(filename, names=names)
data.plot(kind='box', subplots=True, layout=(3,3), sharex=False, sharey=False)
pyplot.show()
```

我们可以看到，属性的分布可能是不同的。某些属性如 `age`、`test` 和 `skin` 似乎向较小值偏态。

## 多变量图

本节提供了显示变量间交互作用的图表。相关性图指示了变量之间变化的趋势。如果变量以相同方向变化，它们正相关。如果它们以相反方向变化（一个上升，一个下降），它们就是负相关。你可以计算每对属性之间的相关性，这被称为相关性矩阵。然后你可以绘制相关性矩阵，了解哪些变量之间具有高相关性。这非常有用，因为如果存在高度相关的输入变量，某些机器学习算法（如线性回归）性能可能会很差。

### 矩阵图

```python
filename = 'pima-indians-diabetes.data.csv'
names = ['preg', 'plas', 'pres', 'skin', 'test', 'mass', 'pedi', 'age', 'class']

data = read_csv(filename, names=names)
correlations = data.corr()

# plot correlation matrix
fig = pyplot.figure()
ax = fig.add_subplot(111)
cax = ax.matshow(correlations, vmin=-1, vmax=1)
fig.colorbar(cax)

ticks = numpy.arange(0, 9, 1)
ax.set_xticks(ticks)
ax.set_yticks(ticks)
ax.set_xticklabels(names)
ax.set_yticklabels(names)

pyplot.show()
```

我们可以看到矩阵是对称的，即矩阵的左下角与右上角相同。这很有用，因为我们可以在一张图中看到同一数据的两种视图。我们还可以看到，从左上角到右下角的对角线上，每个变量彼此都是完全相关的（正如你预期的那样）。

### 散点矩阵

散点图通过二维空间中的点显示两个变量之间的关系，每个轴代表一个属性。你可以为每对属性创建一个散点图。将所有图绘制在一起被称为散点矩阵。散点图对于发现结构关系非常有用。

# 为机器学习准备数据

机器学习算法会对你的数据做出假设。通常情况下，通过这种方式准备数据，以最好地向你打算使用的机器学习算法暴露问题的结构是一个非常好的主意。在本章中，你将学习如何使用 `scikit-learn` 在 Python 中为机器学习准备数据。完成本节后，你将学会如何缩放数据、标准化数据、归一化数据以及二值化数据。

## 数据预处理的必要性

你几乎总是需要对数据进行预处理。这是一个关键步骤。困难之处在于，不同的算法对数据有不同的假设，并且可能需要不同的转换。此外，即使你遵循了所有规则并准备了数据，有时算法在不经过预处理的情况下也能取得更好的结果。通常，我建议为数据创建许多不同的视图和转换，然后对数据集的每个视图运行一些算法。这将帮助你找出哪些数据转换可能更好地揭示你问题的整体结构。

## 数据转换

在本节中，你将学习 4 种不同的机器学习数据预处理方案。每个方案都使用了 Pima 印度人糖尿病数据集。每个方案都遵循相同的结构：

1. 从 URL 加载数据集。
2. 将数据集拆分为机器学习的输入变量和输出变量。
3. 对输入变量应用预处理转换。
4. 汇总数据以显示变化。

`scikit-learn` 库提供了两种转换数据的标准用法。它们在不同的情况下都很有用。转换的计算方式使得它们可以应用于你的训练数据以及未来可能拥有的任何数据样本。`scikit-learn` 文档提供了关于如何使用不同方法的信息：

- `fit()` 和 `transform()`
- 组合的 `fit_transform()`

你将使用 `fit()` 函数准备数据的参数。随后，你可以在相同的数据上再次使用 `transform()` 函数进行建模，或者对可能出现的新数据使用。组合的 `fit_transform()` 是一个你可以用于单个任务的便利方法。如果你对绘图感兴趣，这可能会有用。

### 缩放数据

当你的数据包含不同尺度的属性时，机器学习算法将从将属性缩放到相同尺度中获益。这通常被称为归一化，且属性通常被缩放到 0 到 1 之间的范围。这对于机器学习核心使用的优化算法（如梯度下降）非常有用。对于对输入进行加权的算法（如回归和神经网络）以及使用距离度量的算法（如 k-最近邻）也有用。你可以使用 `scikit-learn` 中的 `MinMaxScaler` 来缩放你的数据。

```python
# 缩放数据（0 到 1 之间）
from pandas import read_csv
from numpy import set_printoptions
from sklearn.preprocessing import MinMaxScaler

filename = 'pima-indians-diabetes.data.csv'
names = ['preg', 'plas', 'pres', 'skin', 'test', 'mass', 'pedi', 'age', 'class']

dataframe = read_csv(filename, names=names)
array = dataframe.values

# 将数组拆分为输入和输出组件
X = array[:, 0:8]
Y = array[:, 8]

scaler = MinMaxScaler(feature_range=(0, 1))
rescaledX = scaler.fit_transform(X)

# 汇总转换后的数据
set_printoptions(precision=3)
```

### 标准化数据

标准化是一种有效的技术，可以将具有高斯分布以及不同均值和标准差的属性转换为均值为 0、标准差为 1 的标准高斯分布。它最适用于假设输入变量符合高斯分布且在缩放数据上表现更好的技术，如回归和线性判别分析。你可以使用 `scikit-learn` 中的 `StandardScaler` 来标准化数据。

```python
# 标准化数据（0 均值，1 标准差）
from sklearn.preprocessing import StandardScaler
from pandas import read_csv
from numpy import set_printoptions

filename = 'pima-indians-diabetes.data.csv'
names = ['preg', 'plas', 'pres', 'skin', 'test', 'mass', 'pedi', 'age', 'class']

dataframe = read_csv(filename, names=names)
array = dataframe.values

# 将数组拆分为输入和输出组件
X = array[:, 0:8]
Y = array[:, 8]

scaler = StandardScaler().fit(X)
rescaledX = scaler.transform(X)

# 汇总转换后的数据
set_printoptions(precision=3)
print(rescaledX[0:5])
```

### 归一化数据

`scikit-learn` 中的归一化是指将每个观测值（行）缩放到长度为 1（在线性代数中称为单位范数或长度为 1 的向量）。这种方法对于具有不同尺度属性的稀疏数据集（包含零）使用对输入加权的算法（如神经网络）和使用距离度量的算法（如 k-最近邻）有用。你可以使用 `scikit-learn` 中的 `Normalizer` 在 Python 中归一化数据。

```python
# 归一化数据（长度为 1）
from sklearn.preprocessing import Normalizer
from pandas import read_csv
from numpy import set_printoptions

filename = 'pima-indians-diabetes.data.csv'
names = ['preg', 'plas', 'pres', 'skin', 'test', 'mass', 'pedi', 'age', 'class']

dataframe = read_csv(filename, names=names)
array = dataframe.values

# 将数组拆分为输入和输出组件
X = array[:, 0:8]
Y = array[:, 8]

scaler = Normalizer().fit(X)
normalizedX = scaler.transform(X)

# 汇总转换后的数据
set_printoptions(precision=3)
print(normalizedX[0:5, :])
```

### 二值化数据

你可以使用二值阈值转换数据。所有高于阈值的值标记为 1，所有等于或低于阈值的值标记为 0。这被称为数据的二值化或数据的阈值处理。当你想要将概率转换为数值时，这可能非常有用。在特征工程中，你想添加具有意义的新特征时，这也很有用。你可以使用 `scikit-learn` 中的 `Binarizer` 在 Python 中创建新的二值属性。

```python
# 二值化
from sklearn.preprocessing import Binarizer
from pandas import read_csv
from numpy import set_printoptions

filename = 'pima-indians-diabetes.data.csv'
names = ['preg', 'plas', 'pres', 'skin', 'test', 'mass', 'pedi', 'age', 'class']

dataframe = read_csv(filename, names=names)
array = dataframe.values

# 将数组拆分为输入和输出组件
X = array[:, 0:8]
Y = array[:, 8]

binarizer = Binarizer(threshold=0.0).fit(X)
binaryX = binarizer.transform(X)

# 汇总转换后的数据
set_printoptions(precision=3)
print(binaryX[0:5, :])
```
