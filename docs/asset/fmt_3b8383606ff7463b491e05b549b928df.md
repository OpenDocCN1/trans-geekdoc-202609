
它是另一个开源、面向业务的机器学习框架。它使得通过数学方法应用预测分析变得更容易，从而根据精确数据做出判断。利用数据洞察进行机器人训练得到了开源 Breed 技术的支持，该技术还支持数据库无关性。得益于 REST API，可以从任何其他源代码或脚本访问或嵌入 H2O 的 Java 核心。机器学习专家可以扩展 H2O 以与现代编程语言和技术配合。机器学习开发者除了分析保险、广告技术、风险、医疗保健和欺诈外，还将其应用于客户智能。

### 1.2.5.1 使用 H2O 的优点

H2O 具有自适应性。

使用 H2O 进行自动机器学习是高效的。对于具有各种编程经验的程序员来说，使用它非常简单。

### 1.2.5.2 使用 H2O 的缺点

H2O 框架的扩展性太差。

### 1.2.6 Theano

Theano 是一个构建在 NumPy 之上的机器学习库，是最快的库之一。它使用 CUDA 和 Python 开发，并根据 BSD 许可证发布。它允许用户优化机器学习应用中的数学表示，并被程序员用于处理多维数组。GPU 和 CPU 平台都可以用于 Theano；然而，当使用后者时，它可以提供更快的结果。这种机器学习方法在 GPU 架构上使用时，执行任务的速度可以快 140 倍。名为 Theano 的流行机器学习软件在物流和财务过程中有广泛用途。

Theano 提供了单元测试和验证工具。支持指数函数和对数函数。可以自动避免缺陷。CPU 和 GPU 架构都能处理数据密集型任务。

### 1.2.6.1 使用 Theano 的缺点

它的编译时间明显长于 TensorFlow。

### 1.2.7 Shogun

它是一个非常古久且老老的开源机器学习库。它集成了多种数据格式和机器学习方法。它用 C++ 编写，并与 C++ 实现了惊人的集成。由于它对 C++ 极其友好，因此在教育和学习领域很受欢迎。Shogun 还展示了与 Python、C#、Java、Lua、R 和 Ruby 等其他语言的兼容性。程序员利用 Shogun 为使用机器学习的应用程序处理海量数据。在广泛的系统上，开发者可以进行回归、分类或探索性分析活动。机器学习开发者在 NLP、教学和研究项目的工作中使用 Shogun。

Shogun 在快速原型设计中的适用性，以及其自适应和用户驱动的特性都是其优点。

### 1.2.7.1 使用 Shogun 的缺点

与 TensorFlow 或 Caffe 相比，Shogun 没有同等水平社区支持。

## 1.3 基于深度学习的电子健康记录

电子健康记录（EHRs）和深度学习（DL）近年来都已成为主要的科技进展，并越来越多地应用于临床前药物发现领域。在这种背景下，EHR 在提供海量数据方面起着至关重要的作用。

## 1.4 深度学习在临床前药物发现中的作用

DL 用于分析临床前药物发现中的 EHR 数据。DL 算法通过为分析 EHR 数据提供强大且高效的解决方案，正在改变临床前药物发现的领域。近年来，DL 算法已成功应用于医疗保健行业的各种应用中，包括 NLP、图像分类和患者预后预测。

### 1.4.1 卷积神经网络

卷积神经网络（CNNs）是一种专门为图像分类任务设计的神经网络。它们被用于从 EHR 数据中提取和分析医学图像，例如 X 光、CT 扫描和 MRI 图像。CNNs 训练用于识别图像中的特定模式，这些模式可用于预测疾病、诊断状况和评估疗效。

### 1.4.2 循环神经网络

循环神经网络（RNNs）是一种专门为序列数据设计的神经网络。它们被用于处理 EHR，EHR 通常包含大量的顺序数据点，例如实验室检测结果、患者生命体征和用药医嘱。RNNs 可以分析顺序数据以预测未来事件，例如疾病进展或患者预后。

### 1.4.3 长短期记忆网络

长短期记忆网络（LSTM networks）是一种 RNN，专门设计用于处理序列数据中的长期依赖关系。它们被用于分析临床前药物发现中的 EHR 数据，以识别患者数据随时间变化的模式和关系。LSTM 还被用于预测患者预后，如再次入院医院或死亡。

## 1.4.4 生成对抗网络 (GANs)

GANs 是一种神经网络，由两个部分组成：生成器和判别器。它们被用于生成合成电子健康记录（EHR）数据，这些数据可用于训练机器学习算法并评估它们的性能。GANs 还可以用于填充 EHR 中的缺失数据，这是临床前药物发现中的一个常见问题。

### 1.4.5 自动编码器

自动编码器是一种神经网络，用于从复杂数据中识别并提取有意义的特征。它们被用于分析临床前药物发现中的 EHR 数据，以识别预测患者结果（如药效或毒性）的最重要特征。

总之，在临床前药物发现中整合 EHR 和深度学习（DL）算法是一项具有前景的发展，有望改变药物的发现、开发和批准方式。深度学习算法通过为分析 EHR 数据提供强大高效的解决方案，在临床前药物发现领域发挥着至关重要的作用。这些算法已成功应用于医疗保健行业的各种领域，包括自然语言处理（NLP）、图像分类和患者结果预测。随着 EHR 和深度学习算法的不断进步，药物发现的未来是光明的，对改善人类健康具有巨大希望。

## 1.5 数据收集与管理

数据收集是关键过程，因为它是分析的基础。为了获得医疗保健行业的整体视图，应从所有方面提取数据，如医生详情、患者信息、健康记录、健康设备、医院、暴发地点、传播模式等 [15,16]。

简而言之，医疗相关数据通过问卷调查、实验室观察和临床文档收集。在当前的数字时代，研究人员可以通过移动应用程序和网络论坛收集数据。

### 1.5.1 数据类型

从医疗保健行业收集的数据分为两种：原始数据和次级数据。原始数据是直接从患者那里收集的原始数据。原始数据的关键来源包括显示疾病相关参数的 X 光图像、患者或医生的调查和问卷以及记录的健康数据。这些数据还包括关于患者的关键信息，如身高、体重、血压、血型等；次级数据是指从标准数据库中提取的数据，这些数据库由世界卫生组织等标准监管机构以及州和中央政府统计部门组成。

### 1.5.2 数据收集方法

1. **数据众筹**

   通过共享平台，可以从全球范围内各种贡献者处收集广泛的数据。这有助于实现数据多样性，这对更好地训练模型是所需的。但对收集的数据质量没有保证，而数量是可以满足的。数据收集方法见图 1.5。

2. **私有方式**

   尽管这种方法非常传统，当我们需要从目标贡献者处获取敏感和隐私数据时，它是非常有效的。这仅适用于构建较小的数据。

3. **现有数据集**

   当需要获取高质量的数据时，使用现有数据集是更好的选择。现有的标准数据集具有预处理和清洗的数据样本。这可能具有易实施和数据收集成本最低模式的优点。

4. **自动化工具**

   使用开发的软件工具从在线数据源和社交媒体收集数据。当需要收集次级数据时，这是更好的数据收集选择。它是数据收集快速模式之一。

随机数据收集并不是构建标准数据集。在收集数据时，质量至关重要。收集的样本数据必须是整个类型人群的适当代表。数据的完整性应当得到保护。收集的数据可能是各种类别，如连续数据、分类数据研究数据。在各种信息技术的帮助下，手动调查和问卷被基于软件的工具取代。基于移动和 Web 的应用程序广泛流行，并迅速覆盖大众。在这个数字时代，数据收集变得更容易，而定性数据的选择是关键。保持收集的原始数据不变是最佳实践。

## 1.6 临床研究中深度学习的操作障碍

- 深度学习算法的准确性取决于用于训练模型的数据量。再次，对更多医疗数据有需求。
- 尽管大多数医院记录现在都是电子记录，但获取医疗数据会违反隐私。
- 保持医疗数据安全至关重要。
- 数据可视化是关键部分，因为大部分收集的健康数据具有多维特征。
- 缺乏健康数据的适当文档。
- 缺乏处理电子数据的熟练医疗人员。
- 全范围内缺乏系统和政策的整合。
- 患者和护理人员犹豫于使用他们的健康数据进行实验分析。
- 缺乏处理健康数据的强政策框架。
- 人体行为是不可预测的，尽管预测取决于收集的数据。
- 用户和患者社区内部缺乏信任。
- 基于机器学习的健康诊断会导致健康不平等。
- 数据在患者数据来源的性别和国籍方面缺乏明确。

## 1.8 药物递送中的临床试验

临床试验是开发和将新药推向市场过程的关键步骤。它们被用于在受控环境中测试新药的安全性和有效性，并提供相关数据，向监管机构证明该药物在其预期用途上是安全有效的。药物递送是制药行业中一个快速发展的领域，其目标是通过开发新的创新方法将药物递送人体，以提高药物的有效安全性 [20,21]。这包括使用新类型的递送系统，如纳米颗粒、脂质体或微球，以及开发新的给药途径，如吸入或经皮给送。药物递送的临床试验旨在测试新递送系统或给药途径以及药物本身的安全性和有效性。这些试验通常涉及许多受试者，并分为几个阶段 [22]。

### 1.8.1 第一阶段

第一期试验通常是在人体上测试新药或递送系统的第一步。这些试验通常针对少数健康志愿者进行，旨在测试药物或递送系统的安全性，并确定最佳剂量。

### 1.8.2 第二阶段

第二期试验通常在较多数量的受试者中进行，旨在测试药物或递送系统在治疗特定疾病方面的有效性。这些试验还提供了关于安全性的额外信息，以及最佳给药剂量和给药方案的信息。

### 1.8.3 第三阶段

第三期试验通常是大型、多中心的试验，在许多受试者中进行，旨在确认药物或递送系统的有效性和安全性。这些试验还提供了关于药物或递送系统长期安全性和有效性的重要信息。在三期临床试验之后，数据将发送给 `FDA` 进行审查，并决定是否批准该药物供一般使用。

### 1.8.4 第四阶段

还存在第四期临床试验，即上市后研究，在药物或递送系统被监管机构批准使用后进行。这些试验旨在提供关于药物或递送系统长期安全性和有效性的额外信息，并收集药物在真实世界环境中使用的数据。需要注意的是，药物在临床试验中的成功率很低。估计进入临床试验的药物中，只有约 12% 最终获得了监管机构的批准。药物开发阶段如图 1.6（ch01.xhtml#fig1_6）所示。

图 1.6 药物开发阶段。

总的来说，药物递送中的临床试验是开发和将新药推向市场过程的关键步骤。这些试验旨在测试新递送系统、给药途径以及药物本身的安全性和有效性。这些试验产生的数据用于向监管机构证明该药物在其预期用途上是安全有效的。

## 1.9 深度学习在医疗保健中的应用

`DL` 是一种使用多层神经网络来学习数据中复杂模式的机器学习。它已被应用于许多领域，包括医疗保健，并有望改变我们诊断和治疗疾病的方式。`DL` 在医疗保健领域最有前景的应用之一是医学影像。`DL` 算法可以训练用于识别医学影像（如 `CT scans` 或 `MRIs`）中的模式，这些模式指示了特定的疾病或状况。例如，一个 `DL` 算法可以训练用于识别 `CT scans` 中的肿瘤，或在 `MRI` 中检测阿尔茨海默症的早期迹象。这可以导致更准确、更快速的诊断，以及更早发现疾病 [23]。

`DL` 在医疗保健中应用的另一个领域是 `NLP`。`NLP` 是一种人工智能，允许计算机理解和处理人类语言 [24]。在医疗保健中，`NLP` 可以从 `EHRs` 和其他医疗文档（如临床笔记和出院摘要）中提取信息。这可以用于改善患者护理和人口健康管理，并支持研究 [25]。`DL` 也被用于药物发现和开发。通过分析来自各种来源的大量数据（如基因组数据、药物药效数据和临床试验数据），`DL` 算法可以帮助识别新的药物靶点并预测药物药效。这有助于加速药物开发过程，并发现新颖且更有效的药物 [26]。

除了上述之外，`DL` 还用于医疗保健的其他领域，例如：

*   预测建模：`DL` 可用于预测患者结果，例如再住院的可能性或患特定疾病的风险 [27]。
*   个性化医疗：`DL` 可以分析基因组数据和其他患者信息，以制定个性化治疗方案。
*   远程医疗：`DL` 可以分析远程医疗咨询的视频和音频数据，以改进对患者的远程诊断和治疗。医疗保健应用如图 1.7（ch01.xhtml#fig1_7）所示。

图 1.7 ML/DL 在医疗保健中的应用。

尽管 `DL` 在医疗保健中有许多潜在益处，但也存在一些需要解决的挑战。主要挑战之一是需要大量高质量数据来训练 `DL` 算法 [28]。另一个挑战是 `DL` 模型缺乏可解释性，这使得难以理解模型为何做出某个特定决策。总的来说，`DL` 通过提高诊断的准确性和速度，以及支持研究和药物开发，具有彻底改变医疗保健的潜力。然而，还需要更多研究来解决深度 `DL` 在医疗保健中的挑战，并充分实现其潜力 [29,30]。

## 1.10 结论

在本章中，我们讨论了 `DL` 在药物递送中的重要性，以及用于改进药物递送和医疗管理的预测模型。`EHR` 在健康信息技术中起着重要作用；基于早期记录的疾病预测和药物将赋予更大的价值。数据管理对于所有应用都关键，而医疗保健更是，因为必须处理大量的混合数据集。在智能决策临床试验中，基于 `EHR`、个人健康记录和电子病历记录，可以使用不同的 `DL` 和机器学习技术提取数据，以实施更好的药物递送系统。
