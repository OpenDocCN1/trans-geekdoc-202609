
在扩展路径中，发生反向操作。通道数减少，特征图尺寸增加，与收缩路径对称。为实现这一点，块 #6 到 #9 中的每一个均包含一个 2 倍的上采样操作，后接一个将通道数减半的 `2 × 2` 卷积操作。收缩路径中计算出的特征图被复制并与扩展路径中相应的特征图拼接，随后接两个级联的残差卷积层（例如 `3 × 3` 卷积）。因此，块 #6 计算出 128 个尺寸为 `16 × 16` 的通道，依此类推，直到最后一个块计算出 16 个尺寸为 `128 × 128` 的通道。输出的 `128 × 128` 图像通过一个额外的 `1 × 1` 卷积（第 18.12.2 节）形成，该卷积在 16 个 `128 × 128` 特征图上计算加权平均。

当 U-Net 用于扩散模型背景下时，需要一些与时间相关的额外信息。描述 U-Net 的参数 `θ` 在反向过程中由所有时间步共享。然而，正如我们之前在多处讨论过的，网络的输出（例如 `ϵ_θ(x_t, t)`）显式地依赖于时间 `t`。在扩散模型中，时间携带与输入噪声退化程度相关的重要信息。因此，时间信息应显式地提供给网络。采用在 Transformer 背景下讨论过的位置嵌入方法（第 19.3.4 节）来实现这一目标。为此，时间被编码为用户定义维度的向量，并将此信息传递给 U-Net 的每个阶段。此外，对于每个块，都需要通过线性网络进行额外的投影，以将时间向量嵌入维度与相应 U-Net 层的维度相匹配。时间信息以加法方式被相应的特征图利用。

此外，在大多数扩散模型实现中，在两个连续的残差块之间会采用一个额外的注意力层（第 19.3.5 节）。例如，在文献 [85] 中，该层被添加在相应 U-Net 实现中 `16 × 16` 特征图分辨率之后。^(¹⁴⁴)

### 19.7.3 噪声条件评分网络

除了前面讨论的 DDPM，用于构建扩散模型的其他方法也已被开发出来。[172] 中提出的 `噪声条件评分网络` (NCSN) 其根源在于 [93]。在一般设定下，给定一个概率分布 `q(x)`，其 Stein `评分函数` 定义为 `∇_x ln q(x)`。请注意，梯度是一个指向概率密度函数 (pdf) `q(x)` 增长最快方向的向量（参见例如第 5.2 节）。因此，如果目标是从该分布中采样，利用这一信息将随机抽取的样本 `x⁰` 移向高密度区域的样本是合理的。这一过程可以通过物理学中称为 `朗之万动力学` 的方式迭代进行，描述如下：

```
x^(i) = x^(i - 1) + (γ/2) ∇_x ln q(x^(i - 1)) + √γ ε_i, i = 1,2,…,N,
```

其中 `ε_i ~ N(0, I)`。起始点 `x^((0))` 从先验分布中采样，`γ > 0` 是一个控制变量，用于调整所涉项的相对大小。可以证明，当 `N → ∞` 且 `γ → 0` 时，`x^((N))` 的分布等于 `q(x)` 的分布。因此，在某些一般正则性条件下，`x^((N))` 成为来自 `q(x)` 的精确样本 [172]。

然而，由于 `q(x)` 未知，必须求助于近似方法。在扩散模型的语境下，`q(x)` 指的是与观测输入样本相关联的概率密度函数（pdf）。遵循此类模型的基本原理，所需的近似是通过根据方差序列 `σ[1]² < σ[2]² < … < σ[T]²`，经由一系列添加噪声的步骤，逐步扰动给定的观测点 `x[0]` 来实现的。一个典型的模型遵循高斯形式的条件分布 `q(x[t]|x[0])`，即 `N(x[t]|x[0], σ[t]²I)`，`t = 1, 2, …, T`。为了采样目的，前述的高斯假设可表示为

```
x[t] = x[0] + σ[t]ϵ,  ϵ ∼ N(0, I).
```

(19.73)

噪声条件评分网络是一种深度神经网络，它被训练用来*估计*评分函数 `∇[x[t]] ln q(x[t]|x[0])`。理想情况下，人们希望获得 `∇[x[t]] ln q(x[t])` 的估计值，但这在一般情况下计算上是不可行的。因此，我们依赖相应的条件分布，就像我们在 DDP 模型中所做的那样。由于高斯假设，即 `N(x[t]|x[0], σ[t]²I)`，很容易证明

$$

\nabla_{\mathbf{x}_t} \ln q(\mathbf{x}_t | \mathbf{x}_0) = - \frac{\mathbf{x}_t - \mathbf{x}_0}{\sigma_t²}

$$

![Equation](img/si622.png)

考虑到公式 (19.77)，我们得到

$$

\nabla_{\mathbf{x}_t} \ln q(\mathbf{x}_t | \mathbf{x}_0) = - \frac{1}{\sigma_t} \mathbf{\epsilon}, \quad t = 1, 2, \ldots, T.

$$

![Equation](img/si623.png)

记第 $t$ 步神经网络（如 U-Net）的输出为 $\mathbf{s}_{\boldsymbol{\theta}}(\mathbf{x}_t, t)$，该网络通过最小化代价函数进行训练，

$$

J(\boldsymbol{\theta}) = \frac{1}{T} \sum_{t=1}^{T} \lambda_t \mathbb{E}_{\mathbf{x}_0 \sim q(\mathbf{x}_0)} \mathbb{E}_{\boldsymbol{\epsilon} \sim \mathcal{N}(0,I)} \left[ \|\boldsymbol{\epsilon} + \sigma_t \mathbf{s}_{\boldsymbol{\theta}}(\mathbf{x}_t, t)\|² \right],

$$

![Equation](img/si625.png) (19.74)

其中 $\lambda_t$ 为加权序列（已吸收公式 (19.78) 中的 $\sigma_t$），且 $\mathbf{x}_t$ 由公式 (19.77) 给出。注意，这与公式 (19.74) 相对应，后者同样建立了这两种方法之间的桥梁；另请参阅 备注 19.12。

训练完成后，获得参数的最优值 `θ*`。当在第 `t` 步将样本 `x[t]` 应用于神经网络的输入时，网络的输出 `s_θ*(x[t], t)` 提供了 `∇_x[t] ln q(x[t])` 的相应估计。

### 19.7.4 基于随机微分方程的生成建模

在前面讨论的两种构建扩散模型的方法中，输入数据的扰动是通过*有限*数量的噪声分布来执行的。文献 [173] 提出了一种替代方法，采用一系列*连续*的分布，这些分布根据扩散过程随时间演化。该方法建立在一个随机微分方程 (SDE) 基础之上，该方程将数据点逐步扩散为随机噪声。此外，相应的 SDE 是不可训练的，也不依赖于数据。事实证明，该过程可以通过反向时间 SDE 来逆转，该反向 SDE 将噪声重塑为数据以生成样本。

### 19.7.5 超越基础模型：讨论

在当前版本书籍编写之时，扩散模型的研究与应用前沿正发生着一场“变革”。我们的目的并非详尽综述相关文献，而是呈现当前研究与应用聚焦的一些基本方向。若需更广泛的文献综述，可参考例如 [41]、[200]、[115]。

上述三种基础扩散模型的一个主要缺点是其采样速度较慢，实际应用中需要许多步骤。文献 [198] 指出，生成模型难以同时满足三个要求：a) 样本质量，b) 模式覆盖，c) 采样速度。

生成对抗网络（GANs）（第 19.2.5 节）能快速生成高质量样本，但表现出较低的模式覆盖。这可能是因为其对抗学习过程不易扩展至复杂多模态分布的建模。变分自编码器（VAEs）（第 19.2.6 节）表现出较广的模式覆盖和快速采样，但往往饱受低样本质量之苦。扩散模型作为基于似然的模型，不表现出模式崩溃，能生成令人惊讶的高质量样本，且拥有广泛的模式覆盖。然而，其采样速度较低，需要数千次网络评估。例如，从 DDPM 采样 5 万张 `32 × 32` 大小的图像需要 20 小时，而在 Nvidia 2080 Ti GPU 上使用 GAN 完成相同任务只需不到一分钟。当涉及 `256 × 256` 大小的图像时，使用扩散模型在同一 GPU 上需要 1000 小时；详见 [174]。关于不同生成模型家族比较性能的进一步讨论，可参见 [44]。

扩散模型研究的一大重点在于解决采样速度缺陷。例如，文献[198]指出，扩散网络中缓慢采样的根本原因在于去噪步骤中的高斯假设，该假设仅对小步长有效。为克服此问题，文献提出采用更复杂的多模态分布，并通过 GAN 实现。据称，这种方法在不牺牲样本质量和多样性的前提下，实现了更快的采样速率。

文献[105]建议不再固定前向（扩散）过程，而是对其进行参数化，并与模型其余部分联合优化。这种原理使扩散模型更接近 VAE。据称，通过这种方式学习噪声调度可提升似然，并可减少扩散步数。

文献[174]引入了*去噪扩散隐式模型*（DDIM）的概念，移除了 DDPM 中使用的马尔可夫假设。采用非马尔可夫建模可对应*确定性*生成过程，进而实现更快的高质量采样。

文献[164]将蒸馏概念（第 19.6.6 节）与前述 DDIM 相结合。该算法通过将缓慢的教师扩散模型蒸馏到更快的学生模型中，迭代地将所需采样步数减半。

文献[131]提出对反向路径中的方差进行参数化，而非像 DDPM 那样将其固定，并在训练期间学习参数。同时，采用余弦噪声调度替代 DDPM 中的线性调度。据称，这些简单修改带来的似然提升有利于更快的采样。

文献[157]为在保持高样本质量的同时支持在有限计算资源上训练，将扩散模型应用于预训练自编码器的潜在空间。自编码器提供了一个低维表示空间，该空间在感知上等同于数据空间。

加速采样的另一方向是通过所谓的*一致性模型*（如文献[171]、[122]）。这些模型基于概率流 ODE 原理，学习将任意时刻的任意点映射到轨迹的起点。换句话说，给定一个概率流 ODE，轨迹上的任意点（如`x[t1]`、`x[t2]`、`x[t3]`）均可直接（即单步）映射到原点`x[0]`。“一致性”之名源于施加的约束：模型经过训练，使其在同一轨迹上的不同点输出保持一致。据称，这在不牺牲迭代采样优势的情况下，带来了显著的计算节省。

文献[124]建议提前终止扩散过程，并从非高斯分布开始反向去噪。后者的采样可通过预训练的 GAN 或 VAE 完成。这样可显著减少所需的去噪步数。

高效 ODE 求解器背景下的采样加速任务见文献[119]、[120]等。文献[101]结合相关理论发现，对多种采样器进行了比较。

### 19.7.6 条件扩散模型

目前的重点在于所谓的*无条件*样本生成。换言之，模型*无约束*，可自由探索从输入数据中学到的所有模式。例如，用于生成数字的无条件模型会从所有类别中随机生成数字。然而，有时希望对模型施加条件，使其仅从特定类别生成样本。在所谓的*条件模型*中，可控制生成样本的类别或其他属性。例如，在计算机视觉中，条件模型用于操控图像合成过程。本小节旨在总结设计条件扩散模型时当前流行的一些基本方向。

更正式地说，任务变为构建未知输入概率密度函数在给定`c`条件下的近似`p_θ(x[0]|c)`，即`q(x[0]|c)`，其中`c`表示约束。主要问题在于如何在扩散模型中实现这一点。为此，已提出多种技术。我们首先关注类条件模型，其中约束`c`指代类别标签`y`。其他类型的约束将稍后讨论。

#### 类条件模型

对于类条件模型，首先想到的一种直接方法是获取与类别相关的向量嵌入。也就是说，类别信息被编码为一个向量，并投影到合适的维度，与时间嵌入一起输入到 U-Net 的各个层中。人们可以想到多种将类别信息与 U-Net 各层中计算出的特征图相结合的方法，例如 [44]。在这些修改下，U-Net 返回类条件估计值，即 `μ_θ(x_t, t, y)` 或 `ϵ_θ(x_t, t, y)`。

前述原始公式的一个缺点是，学习到的模型可能会弱化其训练所依赖的相关条件信息。为此，提出了引导模型，它们提供了更显式地控制可用条件相关信息的能力。

##### 分类器引导

在 [44] 中，提出在噪声样本 `x_t` 上训练一个分类器 `p_ϕ(y|x_t, t)`，其中 `y` 表示类别标签变量。训练好分类器后，利用梯度 `∇_x_t ln p_ϕ(y|x_t, t)` 来*引导*反向过程从任意类别 `y` 进行采样。在采样期间，用以下公式替换公式 (19.75) 中的 `μ_θ_*(x_t, t)`：

```
μ̂_θ_*(x_t, t, y) = μ_θ_*(x_t, t) + γ Σ_θ_*(x_t, t) ∇_x_t ln p_ϕ_*(y|x_t, t)
```

(19.78)

其中，在导出公式(19.75)的假设下，`Σθ* = σ[t]²I`。项 `γ > 0` 是用户定义的梯度缩放因子，可对性能产生有益作用。请注意，在公式(19.82)右侧的第二项中，我们可以等价地写为：

```
γ∇[x[t]]ln pϕ* = ∇[x[t]]ln (pϕ*)^(γ)。
```

对于 `γ > 1`，分布 `(pϕ*)^(γ)` 比最优训练的分类器 `pϕ*` 更尖锐，因为较大的值被指数放大了。因此，使用更大的缩放因子 `γ`，关注点会更多地转向分类器的模式，这有可能有利于生成保真度更高但多样性较低的样本 [44]。

分类器是在由相应扩散模型相同的加噪分布产生的样本上训练的。训练完成后，根据公式(19.82)，分类器被纳入扩散模型的采样过程中。
