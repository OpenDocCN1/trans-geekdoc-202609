
# 问题 150
一所大学正寻求改造其无线网络，以为学生和教员工提供安全访问。IT 部门希望有一种利用中心化服务器验证用户凭据并能与现有目录服务集成的认证方法。他们应该考虑哪种认证？

- (A) 预共享密钥 (PSK)
- (B) 轻量级扩展认证协议 (LEAP)
- (C) 扩展认证协议-传输层安全协议 (EAP-TLS)
- (D) 共享密钥挑战

## 解析 150
**正确答案：C. 扩展认证协议-传输层安全协议 (EAP-TLS)。** `EAP-TLS` 通过使用数字证书对客户端和服务器进行认证提供了强大的安全性。它与 `RADIUS` 服务器配合工作，允许对用户凭据进行中心化管理，并与现有目录服务无缝集成。

**选项 A 是错误的。** 预共享密钥 (PSK) 不涉及用于认证的中心化服务器。相反，所有设备都使用单一共享密钥，这对于大型大学环境来说可能不具备扩展性，也不够安全。

**选项 B 是错误的。** 虽然 `LEAP` 通过 `RADIUS` 服务器提供中心化认证，但它存在已知的漏洞，可能无法提供该大学所寻求的安全水平。

**选项 D 是错误的。** 共享密钥挑战不是标准的无线认证协议。在实践中，基于共享密钥（如 `PSK`）的挑战如果密钥被泄露，可能会受到攻击。

# 问题 151
CyberGuard LLC 是一家网络安全公司，在行业内地位稳定，回报持续。领导层决定不追求激进的增长策略，而是选择维持目前的市场份额和运营规模。他们对微小风险持开放态度，但避免重大中断。如何最好描述 CyberGuard LLC 的风险偏好？

- (A) 扩张型
- (B) 中性型
- (C) 保守型
- (D) 激进型

## 解析 151
**正确答案：B. 中性。** 中性风险偏好意味着组织既不为了高回报而激进追求风险，也不完全避免风险。鉴于 CyberGuard LLC 寻求维持现状并对微小风险持开放态度，他们的风险偏好可以归类为中性。

**选项 A 是错误的。** 扩张型风险偏好表示组织愿意接受更高的风险以获得可能更高的的回报，这与 CyberGuard LLC 的策略不符。

**选项 C 是错误的。** 虽然 CyberGuard LLC 处事谨慎，但他们的立场并非完全反对承担风险。保守型偏好意味着他们规避大多数风险，但他们对微小风险是开放的。

**选项 D 是错误的。** 激进型意味着有强烈意愿承担重大风险，这并不是描述中 CyberGuard LLC 所具备的立场。

# 问题 152
在公司基础设施遭受一系列网络攻击后，IT 团队决定部署一种看起来像是网络合法部分，但实际上被刻意隔离并监控的解决方案。他们打算在这一隔离环境中检测并分析恶意活动。他们最可能实施哪种技术？

- (A) 网络分
- (B) 蜜罐 (Honeypot)
- (C) DMZ (非军事化区)
- (D) 沙箱 (Sandboxing)

## 解析 152
**正确答案：B. 蜜罐。** 蜜罐是故意设置的，看似网络的合法部分，但它是被隔离并经过严密监控的。其目的是吸引攻击者并观察他们的行为，从而对潜在威胁和对手所采用的方法提供洞察。

**选项 A 是错误的。** 网络分是将网络划分为较小的子网络。虽然这可以通过限制攻击者对特定分的访问来增强安全性，但它并不作为吸引攻击者的诱饵。

**选项 C 是错误的。** `DMZ` (非军事化区) 是作为互联网和组织内部网络缓冲的子网。虽然它可以包含外部用户访问的服务器，但其主要目的不是作为诱饵，而是提供一层保护。

**选项 D 是错误的。** 沙箱是一种安全机制，允许程序在独立环境中运行，以防止它们影响整个系统。它用于测试和分析潜在的恶意软件，而不是诱捕攻击者。

# 问题 153
贵组织正在考虑与软件供应商 TechVendor Inc. 合作。在确定协议之前，您希望确保其应用程序的安全性。哪种方法可以直接评估其系统防御潜在网络威胁的健壮性？

- (A) 进行内部安全意识培训
- (B) 查看他们过去的审计报告
- (C) 实施严格的防火墙规则
- (D) 对其应用程序进行渗透测试

**正确答案：D. 对其应用程序进行渗透测试。** 渗透测试是一种主动方法，通过模拟来自外部或内部恶意人员的攻击来评估应用程序的安全性。它直接衡量了应用程序中可能被攻击者利用的漏洞。

**选项 A 是错误的。** 虽然安全意识培训对于教育员工安全最佳实践至关重要，但它不能直接评估外部供应商应用程序的安全性。

**选项 B 是错误的。** 过去的审计报告可以提供供应商安全态势的有价值见解，但它们无法像渗透测试那样的提供实时评估。

**选项 C 错误。** 实施防火墙规则是一种保护措施，但它不能评估供应商应用程序的当前安全性。

# 问题 154
某电子商务平台最近遭受了数据泄露，攻击者利用 cookie 冒充用户会话。安全分析师的任务是建议保护用户 cookie 的措施。以下哪种措施可以确保 cookie 在用户浏览器和服务器之间安全传输？

- (A) 将 cookies 存储在数据库中
- (B) 为 cookies 设置 "Secure" 属性
- (C) 增加 cookie 的过期时间
- (D) 对 cookie 内容进行 Base64 编码

## 解释 154
**正确答案：B. 为 cookies 设置 "Secure" 属性。** "Secure" 属性可确保 cookie 仅通过安全的、加密的 HTTPS 连接发送。通过实施此属性，cookie 将不会在未加密的 HTTP 连接上传输，从而降低了被攻击者拦截的风险。

**选项 A 错误。** 将 cookies 存储在数据库中并不一定能确保客户端和服务器之间 cookie 传输的安全。这更多是关于存储安全，而不是传输安全。

**选项 C 错误。** 增加 cookie 的过期时间实际上会增加攻击者利用 cookie 的机会窗口，使其成为一种不安全的做法。

**选项 D 错误。** `Base64` 编码不是加密；它只是将二进制数据以 ASCII 字符串格式表示的方法。编码可以被轻易反转，提供的安全性很低或没有。

# 问题 157
Tech Enterprises 计划发布一款新产品。作为产品创建的一部分，他们从多个供应商采购了组件。安全团队的任务是评估与供应链相关的风险。从多个供应商采购组件时，以下哪种风险是最令人担忧的？

- (A) 跟踪多个供应商产品保修细节的困难
- (B) 由于供应商交付时间不一导致产品组装时间增加
- (C) 引入不安全或被破坏组件的可能
- (D) 需要多个采购订单，导致文书工作增加

## 解释 157
**正确答案：C. 引入不安全或被破坏组件的可能。** 当从多个供应商采购组件时，一个或多个组件存在漏洞或被破坏的风险增加，从而影响整个产品的安全性。

组件的完整性和安全性在产品开发中至关重要，特别是当这些组件是来自各种供应商的供应链的一部分时。如果某个供应商的安全措施松散或遭到破坏，他们提供的组件可能会向制成品中引入漏洞，影响其整体安全态势，并可能导致数据泄露或其他网络威胁。

**选项 B 错误。** 产品组装时间和供应商交付时间表是物流和运营问题，不是与供应链供应商相关的主要的安全风险。

**选项 D 错误。** 管理多个采购订单是业务流程挑战，而不是主要的安全问题。

# 问题 158
安全分析师 John 注意到连接到公司无线网络的未授权设备增加。为了找出原因，他意识到无线接入点仍在使用一种旧的加密标准。可能在使用哪种已知易于被破解的过时加密标准？

- (A) WPA3
- (B) WEP
- (C) WPA2-PSK
- (D) AES

## 解释 158
**正确答案：B. WEP。** 有线传输 `WEP` 是无线网络的一种旧且过时的加密协议。它有多个已知漏洞，被认为是不安全的，使得攻击者更容易破解。

**选项 A 错误。** `WPA3` 是无线网络的一种较新且更安全的加密协议，被认为是对以前标准的重大改进。

**选项 C 错误。** `WPA2-PSK`（带有预共享密钥的 WiFi 保护）比 `WEP` 更安全。虽然它仍然可能被针对，但它不像 `WEP` 那样容易破解。

**选项 D 错误。** `AES`（高级加密标准）是一种加密标准，而不是无线加密协议。它通常用于 `WPA2` 和 `WPA3` 中以保护无线数据。

# 问题 160
TechBank 刚刚在市中心开了一家新分行。由于位置原因，管理层担心设施可能受到车辆攻击。TechBank 可以采用以下哪种物理安全措施来专门威慑此类攻击？

**选项 A 错误。** 虽然监控摄像头可以监控和记录活动，但它们不能作为防止车辆攻击的物理屏障。

# 问题 161
一家金融机构的高安全性数据中心对其主入口有一套认证系统。如果系统遇到意外错误，该机构希望确保在系统修复之前，没有任何能够访问数据中心。认证系统应该被设置为哪种配置？

- (A) 故障旁路（Fail-open）
- (B) 故障闭锁（Fail-closed）
- (C) 故障安全（Fail-secure）
- (D) 故障被动型（Fail-passive）

## 解析 161
**正确答案：B. 故障闭锁（Fail-closed）。** 故障闭锁也称为故障安全，是一种模式，即如果系统发生故障，它将默认拒绝所有请求，有效地“关闭”访问。在高安全环境中，通常优于这种模式，以防止在系统故障期间发生任何未经授权的访问。

**选项 A 错误。** 故障旁路与该机构所希望的相反。在故障旁路场景下，如果系统发生故障，它将默认允许所有请求。

**选项 C 错误。** 虽然“故障安全”是“故障闭锁”的另一个术语，但在选项中同时使用这两个术语会让考生产生困惑。在这种背景下，选项 B 是更合适的选择。

**选项 D 错误。** 故障被动型在认证失败模式背景下并不是标准术语。故障旁路和故障闭锁（或故障安全）是主要的认可术语。

# 问题 162
CyberSecure Inc. 正在评估潜在安全泄露对其主服务器的财务影响。公司估计，该服务器的泄露将由于数据恢复、费用和罚款而导致 500,000 美元的直接财务损失。以下哪项最能代表这一估算？

- (A) 年均发生率 (ARO)
- (B) 总拥有成本 (TCO)
- (C) 单次损失期望 (SLE)
- (D) 年化损失期望 (ALE)

## 解析 162
**正确答案：C. 单次损失期望（SLE）。** 单次损失期望（SLE）代表每次风险发生时预期的货币损失。在这种情况下，公司正在估计单次泄露事件导致的直接财务损失。

**选项 A 错误。** 年均发生率（ARO）代表预计事件在一年内发生的频率，而不是单次事件的成本。

**选项 B 错误。** 总拥有成本（TCO）指的是在整个周期内拥有特定资产或解决方案的完整成本，而不是单次事件的成本。

**选项 D 错误。** 年化损失期望（ALE）是一个基于 SLE 和 ARO 计算出的值，代表预期的年度损失。

# 问题 163
一家大型电子商务公司希望确保其新开发的应用程序在部署到生产环境之前不包含任何代码漏洞。他们希望捕获任何软件缺陷，特别是可能导致潜在安全风险的缺陷。他们应该采用以下哪种方法？

- (A) 运行时应用程序自保护 (RASP)
- (B) 对运行中的进行渗透测试
- (C) 静态代码分析
- (D) 用户验收测试 (UAT)

## 解析 163
**正确答案：C. 静态代码分析。** 静态代码分析涉及在不执行应用程序的情况下对代码进行分析，侧重于检测漏洞、编码缺陷或其他潜在安全威胁，使其成为所呈现场景的合适方法。

**选项 A 错误。** 运行时应用程序自保护（RASP）关于关实时的应用程序监控和保护，这不会是部署前漏洞检查的首选。

**选项 B 错误。** 对运行中的应用程序进行渗透测试涉及在应用程序上线或运行时对其进行测试，这在寻求识别部署前阶段的漏洞时可能不利。

**选项 D 错误。** 用户验收测试（UAT）侧重于确定软件是否满足业务需求并为终端用户正常运行。它不强调发现安全漏洞。

**选项 D 错误。** 门卡读取器是访问控制的一种形式，但它们本身不强制双重授权检查。

# 问题 165
XYZ 公司 最近实施了一种持续评估公司威胁格局的安全解决方案，监控新兴风险并立即警报安全团队。这种评估模型允许团队快速调整安全态势。他们正在使用哪种类型的风险评估？

- (A) 一临时
- (B) 定期
- (C) 动态
- (D) 持续

## 解析 165
**正确答案：D. 持续。** 持续风险评估涉及对风险进行持续监控，使组织能够对变化做出反应。

**选项 A 错误。** 一次性风险评估针对特定事件或目的，并非打算定期执行。

**选项 B 错误。** 定期风险评估按计划间隔（如每年或每两年一次）进行，不是持续性的。

**选项 C 错误。** 动态评估可以适应变化的环境或因素，但“动态”并没有特指像“持续”那样的监控。

# 问题 166
一家软件开发公司正在评估其应用程序中新发现漏洞的相应风险。在查看日志并模拟潜在攻击后，安全团队估计该漏洞在明年被利用的概率为 0.25。此概率表示什么？

- (A) 该漏洞在明年被利用的概率为 4 分 1
- (B) 该漏洞明年肯定会被利用四次
- (C) 该漏洞在过去一年被利用了 25 次
- (D) 每四位客户都会利用该漏洞。

## 解析 166
**正确答案：A. 该漏洞在明年被利用的概率为 4 分 1。** 0.25 的概率表示 25% 的几率，或 4 分 1 的发生可能性。

**选项 B 错误。** 概率值并不预测发生的确切次数，而是事件发生的可能性。

**选项 C 错误。** 给出的概率数字是对未来风险的估算，而不是过去事件的计数。

**选项 D 是错误的。** 所提供的概率不是关于客户的，而是关于漏洞被利用的几率。
