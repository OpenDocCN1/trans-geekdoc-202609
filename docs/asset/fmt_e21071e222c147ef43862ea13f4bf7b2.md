![Equation](img/si432.png)

且更新递归变为

```
w[n] = (I - C (C^(H) C)^(-1) C^(H)) (w[n-1] + μ u[n] e[n]^(∗)) + C (C^(H) C)^(-1) g.
```

![Equation](img/si433.png)

请注意，$(I - C(C^H C)^{-1} C^H)$ 是由约束定义的超平面的交集（仿射集）上的正交投影矩阵（回想一下 $C(C^H C)^{-1} C^H$ 是由 $\mathbf{c}_i, i = 1, 2, \dots, m$ 张成的子空间上的相应投影矩阵）。可以很容易地验证，在每次迭代步骤中，$\mathbf{w}_n$ 都满足约束条件。该算法初始化为 $\mathbf{w}_1 = C(C^H C)^{-1} \mathbf{g}$。如果目标是最小化输出功率，则必须在 $e_n$ 中将期望响应设置为零，即 $d_n = 0$。

## 5.12 非平稳环境下 LMS 的跟踪性能

我们已经讨论了 LMS 的收敛行为，并对其他已讨论算法做了相关评论。如前所述，收敛是一种*瞬态*现象；即它关注从初始启动点到稳态的时期。对于平稳环境（即未知参数向量以及涉及的随机变量/过程的底层统计特性保持不变的环境），稳态也已进行过讨论。

现在我们将重点转移到真实（但未知）参数向量/系统发生变化的情况。这会影响输出观测值，进而影响其统计特性。请注意，输入的统计特性也可能发生变化。然而，我们不打算考虑此类情况，因为分析可能会变得相当复杂。我们的目标是研究 LMS 的*跟踪*性能，即算法跟踪未知参数向量变化的能力。请注意，跟踪是一种*稳态*现象。换句话说，我们假设已经过去了足够长的时间，以至于初始条件的影响已被遗忘，不再对算法产生任何影响。跟踪敏捷性和收敛速度是算法的两个*不同*属性。一个算法可能收敛快，但*不一定*具有良好的跟踪性能，反之亦然。稍后我们将看到此类情况。

我们讨论的设置将类似于第 5.5.1 节。根据那里的讨论，我们考虑实数据情况；类似的结果也适用于复值线性估计场景。然而，与公式 (5.38) 中采用的模型相反，这里采用了一个*时变*模型，使用以下假设。

**假设 1**。输出观测值根据以下模型生成：

```
y_n = \mathbf{\theta}_{o, n-1}^T \mathbf{x} + \eta
``` (5.72)

这与 LMS 中使用的预测模型一致，在时刻`n`。也就是说，未知的参数集是一个时变集合。输入向量`x`以及噪声变量`η`的统计特性被假定为与时间无关，这也是我们未使用时间索引的原因；等价地说，在输入为随机过程`u[n]`的情况下，假定它是*平稳*的。此外，输入变量被假定与零均值噪声变量`η`相互独立。而且，`η`的连续样本是方差为`σ[η]²`的独立同分布（白噪声序列）。到目前为止，我们并未超出第 5.5.1 节所述的假设 1 太多。

### 假设 2

时变模型遵循随机游走变化，表示为

```
θ[o, n] = θ[o, n − 1] + ω
```

随机向量`ω`假定为零均值，协方差矩阵为

```
E [ω ω^(T)] = Σ[ω]
```

请注意，随机游走的方差随时间无限增长；通过递归应用公式(5.73)即可轻易证明。

该模型的一个变体使用起来会更合理，即

```
θ[o, n] = a θ[o, n − 1] + ω
```

其中`|a| < 1` [106]。然而，分析会变得更加复杂，因此我们将坚持使用公式(5.73)中的模型。毕竟，我们这里的目标是突出并初步接触跟踪的概念，并了解其对稳态失调的影响。

### 假设 3

同第 5.5.1 节一样，我们假定`c[n − 1] := θ[n − 1] − θ[o, n − 1]`与`x`和`η`独立。这一次，我们还将假定`c[n]`与`ω`独立。

回顾公式(5.46)，时刻`n`的超额 MSE 由下式给出

```
J[exc, n] = trace{Σ[x] Σ[c, n − 1]}
```

因此，我们现在的目标是计算时变模型情况下的`Σ[c, n − 1]`。很容易看出，公式(5.35)的对应式现在变为

```
c[n] = (I − μ x x^(T)) c[n − 1] + μ x η − ω
```

采用前述的三个假设，以及对 **x** 的 *Gaussian* 假设，并遵循与推导 Eq. (5.40) 完全相同的步骤，我们得到

```
Σ[c, n] = Σ[c, n−1] − μΣ[x]Σ[c, n−1] − μΣ[c, n−1]Σ[x]
        + 2μ²Σ[x]Σ[c, n−1]Σ[x] + μ²Σ[x]trace{Σ[x]Σ[c, n−1]}
        + μ²σ[η]²Σ[x] + Σ[ω].
```

(5.75)

注意，如果涉及复数数据，唯一的区别是右边第四项不乘以 2（参见 Problem 5.14）。该方程控制 `Σ[c, n]` 的演变，进而可提供超额 MSE 误差。

对于较小的 `μ` 值，会得到一种更方便的形式，此时上式右边的第四项和第五项可以忽略，因为它们相对于 `μΣ[x]Σ[c, n−1]` 很小。此外，在稳态下，`Σ[c, n] = Σ[c, n−1] := Σ[c]`，对两边取迹，我们得到（回顾 `trace{A + B} = trace{A} + trace{B}` 和 `trace{AB} = trace{BA}`）

![Equation](img/fx017.jpg)

(5.76)

注意，这正是基于更严谨的能量守恒理论 [83] 得出的相同近似。

将公式 (5.76) 与公式 (5.51) 进行比较；在当前设定下，存在另一个与噪声相关的项，它使模型围绕其均值漂移。因此，（a）超额均方误差（MSE）是由 LMS 无法精确获得最优值所导致的；（b）存在一个额外的项，用于衡量其“惯性”，即无法足够快地跟踪模型的变化。这是当前讨论得出的最重要结论。在时变环境中，失调度会增加。此外，观察公式 (5.76) 以及 `μ` 的影响，可以发现 `μ` 的较小值对第一项有有利影响，但会增加第二项的贡献。对于相对较大的 `μ` 值，情况则相反。这是很自然的。小步长使算法有机会在平稳环境下更好地学习，但算法无法足够快地跟踪变化。因此，`μ` 的选择应是权衡的结果。将公式 (5.76) 中的超额误差最小化，很容易得到

```
\mu_{\text{opt}} = \sqrt{\frac{\text{trace}\{\Sigma_{\omega}\}}{\sigma_{\eta}^{2}\text{trace}\{\Sigma_{x}\}}}.
```

![Equation](img/si456.png)

然而请注意，这种 `μ` 的选择仅具有理论意义。在实践中，系统的时变特性几乎不可能与所采用的模型相对应；由于分析的复杂性，后者被选择为一个简单的模型，以简化数学运算。此外，为了简化分析，采用了许多假设。在实践中，`μ` 的选择更多地基于用户的实践经验（经过实验），而非基于理论。然而，理论已经指出了收敛速度与跟踪速度之间的权衡。

关于非平稳环境下在线/自适应方案性能的更严格数学分析，可参考文献 [16,38,47,61,70,83]。第 6 章的 示例 6.3 中给出了演示 LMS 与其他算法跟踪性能对比的仿真结果，该章介绍了递归最小二乘（RLS）算法。

## 5.13 分布式学习：分布式 LMS

我们的关注点现在转向一个在过去几年中日益重要的问题。越来越多的应用场景中，数据由不同的传感器/数据集接收或驻留，这些传感器/数据集在空间上是分布式的。然而，所有这些空间分布式信息都必须被利用以实现一个共同目标，即执行一项*共同估计/推理*任务。我们将此类任务称为*分布式*或*去中心化*学习。该问题的核心在于*协作*的概念，这是交换学习经验/信息以达成共同目标/决策的过程的另一种说法。人类社会因协作而生存（因缺乏协作而消亡）。

分布式学习在许多生物系统中很常见，其中没有单个个体/智能体处于主导地位，但群体表现出高度的智能（我们人类称之为本能）。例如，观察鸟群编队飞行和蜂群迁徙筑巢的方式。

除了社会学和生物学，科学和工程也利用了分布式学习的概念；*无线传感器网络*（WSN）就是一个典型例子。WSN 最初被建议作为空间分布式自主传感器，用于监测物理和环境条件，如压力、温度和声音，并协作将其数据传递给中心单元。虽然 WSN 最初是由军事应用驱动的，但如今它们面向多种多样的应用，如交通控制、国土安全与监视、医疗保健和环境建模。每个传感器节点都配备了板载处理器，以便在本地执行一些简单的处理并传输所需的*部分*处理后的数据。由于能量和带宽限制，传感器/节点的特点是处理、存储和通信能力较低 [1,104]。

分布式学习应用的其他典型例子包括对社交网络中个体关联方式的建模与研究、复杂电网上路径的建模、认知无线电系统以及模式识别；所有这些应用的共同特征是数据在每个单独的节点/智能体中被*部分*处理，处理后的信息按照*某种协议*传递给网络。

不熟悉的读者可能会问的一个显而易见的问题是：为什么不只使用一个节点/智能体及其本地驻留的信息来执行推理任务。当然，答案是我们可以通过利用整个网络中可用的数据/信息获得更好的估计/结果。这引出了*共识*的概念。

根据《美国传统词典》，“共识”被定义为“一个群体作为一个整体所达成的意见或立场”；即共识是保证群体内部达成“被接受的一致”的过程。“被接受的一致”这一术语并非唯一定义。在某些情况下，这可能指*一致*决定；在其他情况下，它指*多数表决*规则。在某些情况下，所有智能体的意见权重相等，而在其他情况下，则根据某些相对重要性度量施加不同的权重。然而，在所有情况下，任何基于共识的过程的本质都是相信与每个智能体/个人单独行动的过程相比，能达成一个“更好”的决定。

在本节中，我们关注*参数估计*任务。每个单独的智能体通过数据的“本地”采集过程获取部分信息。虽然每个智能体访问不同的数据集，但它们共享一个共同目标，即估计*同一组*未知参数。该任务将以协作方式完成。然而，可以采用不同的协作场景。

### 5.13.1 协作策略

在分布式学习中，每个单独的智能体在图中表示为一个节点。节点之间的边表示相应的智能体可以交换信息。无向边表示信息可以双向交换，而有向边表示允许的信息流方向。^(³⁴)

#### 集中式与去中心化网络

在这种合作场景下，节点将其测量值传送给中央 `fusion` 单元进行处理。获得的估计值可以传回每个节点。图 5.22 说明了拓扑结构。在 图 5.22A 中，所有节点直接连接到融合中心，用方框表示。在 图 5.22B 中，部分节点可直接链接到融合中心，而其他节点则将其测量值传送给相连的邻居节点，后者再将接收到的以及本地可用的观测/测量值传递给相邻节点或融合中心。这种合作策略的主要优势在于融合中心能计算出最优估计，因为它能访问所有可用信息。然而，这种最优性是以若干缺点为代价获得的，例如增加的通信成本和延迟，尤其是在大型网络中。此外，一旦融合中心故障，整个网络就会瘫痪。而且，在某些应用中涉及隐私问题。例如，当数据涉及医疗记录时，节点不愿发送可用的（训练）数据，而是倾向于传送某些本地获得的处理后信息。为克服集中式处理场景的缺点，已提出了不同的分布式处理方案。

![图 5.22 方框表示融合中心。(A) 所有节点直接与融合中心通信。(B) 部分节点直接连接融合中心。其他节点将自己的数据传给相邻节点，依此类推，直到信息到达融合中心。连接线越粗，表示通过相应链路传输的数据量越大。](img/gr022.jpg)

#### 去中心化网络

在此场景下，不存在中央融合中心。处理在每个节点 `locally` 进行，利用本地接收的测量值，随后每个节点将本地获得的估计值传送给其邻居节点，即与其相连的节点。这些链路在相应图中表示为边。存在不同的去中心化方案。

*   **增量/环形网络**：这些方案要求存在一条 `cyclic path`^(³⁵) 

    ![图 5.23 (A) 增量或环形拓扑。信息流遵循一条循环路径。(B) 对应扩散策略的拓扑。每个节点与共享边的节点通信信息。](img/gr023.jpg)

    图 5.23 (A) 增量或环形拓扑。信息流遵循一条循环路径。(B) 对应扩散策略的拓扑。每个节点与共享边的节点通信信息。

*   **自组织网络**：根据这种合作理念，节点在每次迭代中执行本地数据采集和处理。然而，环形路径的约束被移除了。每个节点将信息传送给与其共享边的邻居节点；通过这种方式，信息在整个网络中 `diffused` 扩散。此类方案的一个优势是，即使某些节点发生故障，运行也不会停止。此外，网络拓扑不必固定。为这些“额外优势”付出的代价是，收敛后获得的最终性能劣于其增量对应方案和集中式处理。这是自然的，因为在每次迭代中，每个节点只能访问有限量的信息。图 5.23B 示出了自组织网络拓扑的一个例子。

除了上述方案，还存在许多变体。例如，每个节点的邻居可能以概率方式变化，这在每次迭代中引入了信息扩散方式的随机性 [33,60]。

在本节中，我们的重点将放在扩散方案上。我们的目的是为读者提供围绕 LMS 方案的基本技术示例，而非全面涵盖分布式学习，后者本身就是一个拥有悠久历史的独立领域；关于从经典到近期贡献的参考文献示例，请参见 [9,19,29,51,76,95,107]。除了分布式推断，许多与网络拓扑和图上学习相关的方面，在新兴的 `complex networks` 领域背景下正受到广泛关注；请参见 [18,37,87,89,100] 及其参考文献。

### 5.13.2 扩散 LMS

考虑一个包含 *K* 个智能体/节点的网络。每个节点与其邻域内的节点交换信息。给定图中的节点 *k*，令 𝒩<sub>k</sub> 为与该节点共享边的节点集合；此外，节点 *k* 本身也包含在 𝒩<sub>k</sub> 中。这构成了 *k* 的邻域集合。我们将该集合的基数表示为 *n*<sub>k</sub>。图 5.24 展示了一个包含六个节点的图。例如，节点 *k* = 6 的邻域为 𝒩<sub>6</sub> = {2, 3, 6}，基数 *n*<sub>6</sub> = 3。集合 𝒩<sub>k</sub> 的基数也称为节点 *k* 的*度*。相反，节点 *k* = 6 和 *k* = 5 不是邻居，因为它们没有通过边直接相连。为本节需要，我们假设该图是*强连通*的；即，存在至少一条边路径连接任意一对节点。

![图 5.24 对应于在扩散策略下运行的网络的图。红色虚线圈出了节点 k = 6 的邻域节点。](img/gr024.jpg)

图 5.24 对应于在扩散策略下运行的网络的图。红色虚线圈出了节点 *k* = 6 的邻域节点。

网络中的每个节点都能访问一个局部数据采集过程，该过程提供训练数据对<sup>(36)</sup>：

*y*<sub>k</sub> = **θ**<sub>o</sub><sup>T</sup>**x**<sub>k</sub> + *η*<sub>k</sub>,  *k* = 1, 2, …, *K*,  (5.77)

其中 **x**<sub>k</sub> 和零均值噪声变量 *η*<sub>k</sub> 通常在每个节点服从*不同*的统计特性。我们稍后将讨论此类应用。

单独对待每个节点，最小化*局部*代价函数的 MSE 最优解：

*J*<sub>k</sub>(**θ**) = 𝔼 [|*y*<sub>k</sub> − **θ**<sup>T</sup>**x**<sub>k</sub>|²],

将由相应的正规方程给出，涉及相应的协方差矩阵和互相关向量；换句话说，

**Σ**<sub>**x**<sub>k</sub></sub> **θ**<sub>*</sub> = **p**<sub>k</sub>.  (5.78)

回想一下，对于回归模型的情况，**θ**[*] = **θ**[*o*]，并且所有节点得出相同的解。毫无疑问，如果统计量 `Σ[x[k]]`、**p**[k]、*k* = 1, 2, …, *K* 已知，我们就可以到此为止。然而，我们已经知道情况并非如此，在实践中它们必须被估计。或者，必须求助于迭代技术来学习统计量以及未知参数。这就是必须考虑所有节点的地方，以便从分布在网络中的所有观测值中获益。因此，一个更自然的采用准则是

```
J(θ) = ∑_{k=1}^{K} J_k(θ) = ∑_{k=1}^{K} E[ |y_k - θ^T x_k|² ].
```

(5.79)

使用我们迄今为止多次采用的标准论证，很容易看出未知 **θ**[*o*] 的（公共）估计将作为以下方程的解给出

```
(∑_{k=1}^{K} Σ_{x_k}) θ_* = ∑_{k=1}^{K} p_k.
```

让我们以公式 (5.79) 中的全局代价作为起点，应用梯度下降优化方案，

```
θ^{(i)} = θ^{(i-1)} + μ ∑_{k=1}^{K} (p_k - Σ_{x_k} θ^{(i-1)}),
```

(5.80)

由此通过用瞬时观测值替换期望并将迭代步骤与时间更新相关联，得到相应的随机梯度方案，使得

$\\mathbf{\\theta}\_{n} = \\mathbf{\\theta}\_{n - 1} + \\mu\\sum\\limits\_{k = 1}^{K}\\mathbf{x}\_{k}(n)e\_{k}(n),e\_{k}(n) = y\_{k}(n) - \\mathbf{\\theta}\_{n - 1}^{T}\\mathbf{x}\_{k}(n),$

![Equation](img/si480.png)
