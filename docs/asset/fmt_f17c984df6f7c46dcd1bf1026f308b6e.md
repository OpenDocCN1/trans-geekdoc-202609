#### B.4.2.1 主成分分析 (PCA)

为了进行主成分分析，或者说——获取数据集中一组特征的主成分，可以使用 `sklearn.decomposition` 库中的 `PCA` 函数。然而，特征应该经过标准化（即转换为均值为 0、方差为 1 的单位缩放），这可以使用 `sklearn.preprocessing` 库中的 `StandardScaler` 函数。以下是使用鸢尾花（iris）数据集的代码。PCA 应该应用于预测变量。目标变量/类别变量可以用于可视化主成分。

```python
>>> import pandas as pd
>>> import matplotlib.pyplot as plt
>>> from sklearn import datasets
>>> from sklearn.decomposition import PCA
>>> from sklearn.preprocessing import StandardScaler
>>> iris = datasets.load_iris()
>>> predictors = iris.data
>>> predictors = StandardScaler().fit_transform(predictors)
>>> pca = PCA(n_components=2)
>>> princomp = pca.fit_transform(predictors)
>>> princomp_ds = pd.DataFrame(data=princomp, columns=['PC 1', 'PC 2'])
>>> princomp_ds
```

### B.5.1.1 朴素贝叶斯分类器

对于朴素贝叶斯分类器的实现，使用了 `sklearn.naive_bayes` 中的 `GaussianNB` 库。下面是该实现的完整代码。

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score
from sklearn.naive_bayes import GaussianNB
data = pd.read_csv("apndcts.csv")
predictors = data.iloc[:, 0:7]  # 提取预测变量 …
target = data.iloc[:, 7]        # 分离目标/类别变量 …
predictors_train, predictors_test, target_train, target_test = train_test_split(predictors, target, test_size=0.3, random_state=123)
gnb = GaussianNB()
# 首先用输入数据集（其训练数据部分）训练模型/分类器
model = gnb.fit(predictors_train, target_train)
# 使用训练好的模型进行预测
prediction = model.predict(predictors_test)
# 检查预测准确率的时间 …
accuracy_score(target_test, prediction, normalize=True)
```

**输出准确率：**

0.90625

### B.5.1.5 SVM 分类器

实现 SVM 分类器使用了 `sklearn` 框架中的 `svm` 库。下面是该实现的完整代码。

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score
from sklearn import svm
data = pd.read_csv("apndcts.csv")
predictors = data.iloc[:, 0:7]  # 提取预测变量 …
target = data.iloc[:, 7]        # 分离目标/类别变量 …
predictors_train, predictors_test, target_train, target_test = train_test_split(predictors, target, test_size=0.3, random_state=123)

# 首先用输入数据集（其训练数据部分）训练模型/分类器
model = svm_model.fit(predictors_train, target_train)
# 使用训练好的模型进行预测
prediction = svm_model.predict(predictors_test)
# 检查预测准确率的时间 …
accuracy_score(target_test, prediction, normalize=True)
```

**输出准确率：**

0.78125
