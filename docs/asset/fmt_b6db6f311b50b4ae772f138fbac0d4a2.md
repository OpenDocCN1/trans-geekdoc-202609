
这是我们第二次提到图模型的学习。第一次是在 16.3.2 节末尾。获取未知参数最自然的方法是最大化联合概率分布的似然/证据。由于我们的任务涉及观测变量和未观测变量，EM 算法是首先想到的方法。然而，将利用 HMM 中潜在的独立性，以提出一个高效的学习方案。未知参数集 `Θ` 包括：(a) 初始状态概率 `P[k]`，`k = 1, …, K`；(b) 转移概率 `P[ij]`，`i, j = 1, 2, …, K`；以及 (c) 与观测相关的概率分布中的参数 `θ[k]`，`k = 1, 2, …, K`。

#### 期望步

根据第 12.4.1 节提出的一般方案（用 `Y` 代替 `𝒳`，用 `X` 代替 `𝒳^(l)`，用 `Θ` 代替 `ξ`），在第 (`t` + 1) 次迭代中，我们必须计算

```
𝒬(Θ, Θ^(t)) = 𝔼[ln p(Y, X; Θ)],
```

其中 `𝔼[·]` 是关于 `P(X|Y; Θ^(t))` 的期望。由公式 (16.32)–(16.35) 可得

```
ln p(Y, X; Θ) = ∑_{k=1}^K (x_{1,k} ln P_k + ln p(y_1|k; θ_k))
              + ∑_{n=2}^N ∑_{i=1}^K ∑_{j=1}^K (x_{n-1,j} x_{n,i}) ln P_{ij}
              + ∑_{n=2}^N ∑_{k=1}^K x_{n,k} ln p(y_n|k; θ_k),
```

因此，

$$

\mathcal{Q}(\Theta,\Theta^{(t)}) = \sum_{k = 1}^{K}\mathbb{E}[x_{1,k}]\ln P_{k} + \sum_{n = 2}^{N}\sum_{i = 1}^{K}\sum_{j = 1}^{K}\mathbb{E}[x_{n - 1,j}x_{n,i}]\ln P_{ij} + \sum_{n = 1}^{N}\sum_{k = 1}^{K}\mathbb{E}[x_{n,k}]\ln p(\mathbf{y}_{n}|k;\mathbf{\theta}_{k}).

$$

![Equation](img/si283.png)(16.52)

现在让我们回顾公式 (16.49) 以得到

$$

\mathbb{E}[x_{n,k}] = \sum_{\mathbf{x}_{n}}P(\mathbf{x}_{n}|Y;\Theta^{(t)})x_{n,k} = \sum_{\mathbf{x}_{n}}\gamma(\mathbf{x}_{n};\Theta^{(t)})x_{n,k}.

$$

![Equation](img/si284.png)

请注意 `x[n, k]` 只能是零或一；因此，其均值将等于 `x[n]` 的第 `k` 个元素 `x[n, k] = 1` 的概率，我们将其表示为

𝔼\[`x[n, k]`\] = `γ(x[n, k] = 1; Θ^(t))`.

![Equation](img/si287.png)(16.53)

回顾一下，给定 `Θ^(t)`，`γ(·; Θ^(t))` 可以通过前面描述的和积算法高效计算。以类似的方式并利用公式 (16.51) 中的定义，我们可以写出

```
𝔼[x_{n-1,j}x_{n,i}] = ∑_{x_n}∑_{x_{n-1}}P(x_n,x_{n-1}|Y;Θ^{(t)})x_{n-1,j}x_{n,i}
                   = ∑_{x_n}∑_{x_{n-1}}ξ(x_n,x_{n-1};Θ^{(t)})x_{n-1,j}x_{n,i}
                   = ξ(x_{n-1,j}=1,x_{n,i}=1;Θ^{(t)}).
```

![Equation](img/si290.png)(16.54)

注意，`ξ(·,·; Θ^(t))` 给定 `Θ^(t)` 时，也可以作为和积算法的副产品高效计算。因此，我们可以将 E 步总结为

$$

\mathcal{Q}(\Theta,\Theta^{(t)}) = \sum\limits_{k = 1}^{K}\gamma(x_{1,k} = 1;\Theta^{(t)})\ln P_{k}\quad + \sum\limits_{n = 2}^{N}\sum\limits_{i = 1}^{K}\sum\limits_{j = 1}^{K}\xi(x_{n - 1,j} = 1,x_{n,i} = 1;\Theta^{(t)})\ln P_{ij}\quad + \sum\limits_{n = 1}^{N}\sum\limits_{k = 1}^{K}\gamma(x_{n,k} = 1;\Theta^{(t)})\ln p(\mathbf{y}_{n}|k;\mathbf{\theta}_{k}).

$$

![Equation](img/si292.png)(16.55)

#### 最大化步骤

在此步骤中，只需求出关于 `P[k]`、`P[ij]` 和 `θ[k]` 的导数/梯度并将它们设为零，即可获得新的估计值，这些估计值将构成 `Θ^(t+1)`。请注意，`P[k]` 和 `P[ij]` 是概率；因此，它们的最大化应受到约束，以便

$$

\sum_{k=1}^{K} P_k = 1 \quad \text{and} \quad \sum_{i=1}^{K} P_{ij} = 1, \quad j = 1,2,\ldots K.

$$

![Equation](img/si296.png)

![](img/fx010.jpg)

`θ[k]` 的重估计取决于相应分布 `p(y[n]|k; θ[k])` 的形式。例如，在高斯情形中，参数为均值和协方差矩阵的元素。在这种情况下，如果用 `γ` 代替后验概率，我们得到的迭代与高斯混合模型问题（见公式 (12.60) 和 (12.61)）所得的迭代完全相同。

总之，训练 HMM 包含以下步骤：

1.  初始化 `Θ` 中的参数。
2.  运行和积算法以获得 `γ(·)` 和 `ξ(·, ·)`，使用当前的参数估计值集。
3.  按照公式 (16.56) 和 (16.57) 更新参数。

步骤 2 和 3 中的迭代将持续进行，直到满足收敛准则，如在 EM 算法中一样。这种迭代方案也称为 *Baum–Welch* 算法或 *前向-后向* 算法。除了用于训练 HMM 的前向-后向算法外，文献中还有许多替代算法，旨在简化计算或提高性能。例如，可以推导出一种更简单的训练算法，专门针对用于计算最优路径的 Viterbi 方案（如 [63,72]）。此外，为了进一步简化训练算法，我们可以假设状态观测变量 `y[n]` 是离散化（量化）的，并且可以从 `L` 个可能值的有限集合 {1, 2, …, `L`} 中取值。这在实践中通常是如此。此外，假设第一个状态也是已知的。例如，这适用于如图 16.17 所示的左至右模型。在这种情况下，我们不需要计算初始概率的估计值。因此，待估计的未知参数为转移概率和概率 `P_y`，`r = 1, 2, …, L`，`i = 1, 2, …, K`，即从状态 `i` 发射符号 `r` 的概率。

**Viterbi 重估计**：该算法的目标是获得最佳路径并计算沿该路径的相关代价，记为 `D`。在语音文献中，该算法也称为 *分段 k-means 训练* 算法 [63]。

**定义**：

*   `n[i|j]` := 从状态 `j` 到状态 `i` 的转移次数。
*   `n[·|j]` := 从状态 `j` 发出的转移次数。
*   `n[i|·]` := 终止于状态 `i` 的转移次数。
*   `n(r|i)` := 观测值 `r ∈ {1, 2, …, L}` 与状态 `i` 联合出现的次数。

**迭代**：

##### 初始条件

假设未知参数的初始估计值。

##### 步骤 1

从可用的最佳路径，重新估计新的模型参数为

```
P^(new)(i|j) = n_{i|j} / n_{·|j}
P_y^(new)(r|i) = n(r|i) / n_{i|·}
```

##### 步骤 2

对于新的模型参数，获得最佳路径并计算相应的总体代价 `D^(new)`。将其与前一次迭代的代价 `D` 进行比较。如果 `D^(new) - D > ε`，则设置 `D = D^(new)` 并转到步骤 1。否则停止。

Viterbi 重估算法可被证明收敛于对潜在观测的适当刻画 [14]。

##### 备注 16.4

###### 缩放

概率 `α` 和 `β` 小于 1，随着迭代的进行可能会取非常小的值。在实践中，其计算值的动态范围可能超过计算机的表示范围。通过适当的缩放可以有效处理这一现象。如果在 `α` 和 `β` 上都正确地执行此操作，则缩放的效应会相互抵消 [63]。

###### 训练数据集不足

通常，学习 HMM 参数需要大量的训练数据。相对于 HMM 模型的状态数，观测序列必须足够长。这将保证所有状态转移都出现足够多的次数，以便重估算法学习其各自的参数。如果情况并非如此，已经设计出许多技术来应对该问题。欲了解更详细的处理，读者可参考 [8,63] 及其中的参考文献。

### 16.5.3 判别式学习

*判别式学习* 是另一条备受关注的途径。请注意，EM 算法是在“隔离”状态下优化*单个* HMM 关于未知参数的似然度；即不考虑建模其他词汇（在语音识别的情况下）或存储在数据集中的其他模板/原型的其余 HMM。这种方法与我们在第 3 章中定义的生成式学习一致。相反，判别式学习的本质是优化参数集，使模型在训练集上达到最优判别（例如，基于错误概率准则）。换句话说，描述不同统计模型（HMM）的参数是以*组合*方式而非单独地进行优化。目标是根据某一准则，使不同的 HMM 模型尽可能截然不同。这一直是一个热门的研究方向，并围绕着导致凸或非凸优化方法的各种准则开发出了许多技术（例如，参见 [33] 及其中的参考文献）。

#### 备注 16.5

除了本节所述的基本 HMM 方案外，还提出了许多变体以克服其某些缺陷。例如，替代建模路径涉及一阶马尔可夫性质，并提出模型将相关性扩展到更长的时间跨度。

*   在*自回归 HMM* [11] 中，在图 16.15 所示的基本 HMM 方案的观测节点之间添加了链接；例如，`y[n]` 不仅链接到 `x[n]`，而且如果模型将相关性延伸至距离两个时间瞬间之外，它还与 `y[n−2]`、`y[n−1]`、`y[n+1]` 和 `y[n+2]` 共享直接链接。
*   文献 [56] 在*段建模*的背景下引入了一个不同的概念。根据该模型，每个状态被允许发射，比如说，`d` 个连续的观测值，它们构成一个段。该段的长度 `d` 本身是一个随机变量，并与概率 `P(d|k), k = 1, 2, …, K` 相关联。通过这种方式，相关性是通过构成该段的样本的联合分布引入的。
*   **可变持续时间 HMM**：HMM 的一个严重缺陷（在实践中常被观察到）与自转移概率 `P(k|k)` 有关，后者是与 HMM 相关的模型参数之一。请注意，模型处于状态 `k` 持续 `d` 个连续瞬间（初始转移到该状态以及 `d−1` 次自转移）的概率由下式给出：

```
P_k(d) = (P(k|k))^(d−1)(1−P(k|k)),
```

*   其中 `1−P(k|k)` 是离开该状态的概率。在许多情况下，这种指数形式的状态持续时间依赖关系是不现实的。在可变持续时间 HMM 中，`P_k(d)` 被显式建模。可以采用不同的 `P_k(d)` 模型（参见例如 [46,68,72]）。
*   隐马尔可夫建模是机器学习中最强大的工具之一，除了语音识别外，已被广泛应用于大量应用中。仅举几例，部分参考文献包括生物信息学领域的 [9]、通信领域的 [16,36]、光学字符识别 (OCR) 领域的 [4,73] 以及音乐分析/识别领域的 [40,61,62]。关于 HMM 的进一步讨论，请参见例如 [8,64,72]。

## 16.6 超越 HMM：讨论

在本节中，将探讨前文讨论过的隐马尔可夫模型的一些显著扩展，以满足那些状态数量巨大或齐次性假设不再成立的应用需求。

### 16.6.1 阶乘隐马尔可夫模型

在之前考虑的 HMM 中，系统动态通过潜变量描述，其图形表示为一条链。然而，对于某些应用，这种模型可能过于简单。HMM 的一个变体涉及 `M` 条链，而不是一条链，其中每条潜变量链独立于其他链随时间展开。因此，在时刻 `n`，涉及 `M` 个潜变量，记为 `x[n]^(m)`，`m = 1, 2, …, M` [17, 34, 81]。观测值作为组合发射出现，所有潜变量均参与其中。对于 `M = 3` 的相应图形结构如图 16.20 所示。正如图形模型所暗示的，每条链各自独立发展。此类模型被称为**阶乘 HMM**（FHMM）。

一个显而易见的问题是：为什么不通过增加可能状态的数量来使用单条潜变量链？事实证明，这种朴素的方法会导致复杂度激增。以 `M = 3` 为例，其中每个潜变量的状态数均为 10。每条链的转移概率表需要 10² 个条目，总计 300 个，即 `P[i j]^(m)`，`i, j = 1, 2, …, 10`，`m = 1, 2, 3`。此外，可实现的状态组合总数为 10³ = 1000。若要通过单条链实现相同数量的状态，将需要一个包含 (10³)² = 10⁶ 个条目的转移概率表！

![图 16.20 具有三条潜变量链的阶乘 HMM。](img/gr020.jpg)

令 `𝕏[n]` 为 `M` 元组（`x[n]¹, …, x[n]^(M)`），其中每个 `x[n]^(m)` 仅有一个元素等于 1（指示某一状态），其余为零。则

```
$P(\mathbb{X}_{n}|\mathbb{X}_{n - 1}) = \prod\limits_{m = 1}^{M}P^{(m)}\left( \mathbf{x}_{n}^{(m)}|\mathbf{x}_{n - 1}^{(m)} \right).$
```

在文献 [17] 中，观测值采用了高斯分布，即

#### 阶乘隐马尔可夫模型

观测模型由下式给出：

$$

p(\mathbf{y}_{n}|\mathbb{X}_{n}) = \mathcal{N}\left( \mathbf{y}_{n} \middle| \sum\limits_{m = 1}^{M}\mathcal{M}^{(m)}\mathbf{x}_{n}^{(m)},\Sigma \right),

$$

其中

$$

\mathcal{M}^{(m)} = [\boldsymbol{\mu}_{1}^{(m)},\dots,\boldsymbol{\mu}_{K}^{(m)}], \quad m = 1, 2, \dots, M,

$$

是包含与每个状态相关联的均值向量的矩阵，且协方差矩阵假定为已知且对所有状态均相同。联合概率分布由下式给出：

$$

p(\mathbb{X}_{1}\dots\mathbb{X}_{N},Y) = \prod\limits_{m = 1}^{M}\left( P^{(m)}\left( \mathbf{x}_{1}^{(m)} \right)\prod\limits_{n = 2}^{N}P^{(m)}\left( \mathbf{x}_{n}^{(m)}|\mathbf{x}_{n - 1}^{(m)} \right) \right) \times \prod\limits_{n = 1}^{N}p(\mathbf{y}_{n}|\mathbb{X}_{n}).

$$

### 16.6.2 时变动态贝叶斯网络

隐马尔可夫模型以及阶乘隐马尔可夫模型是齐次的；因此，其结构和参数在整个时间过程中保持固定。然而，对于许多底层关系以及系统结构模式随时间演变而发生变化的应用来说，这种假设并不令人满意。例如，基因相互作用不会在一生中保持不变；一个物体在多个摄像头中的外观也在持续变化。对于那些由参数描述、且参数值在某个区间内缓慢变化的系统，我们已经在前几章中讨论了许多替代方案。图模型理论提供了研究具有混合参数集（离散和连续）系统的工具；此外，图模型也适用于非平稳环境的建模，其中也涉及阶跃变化。
