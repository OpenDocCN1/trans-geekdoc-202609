
现在，利用公式 12 从 `d'` 导出 `d'`，过程如下。

由公式 12

```
d' = 2 * d + LSB(d')        (15)
```

将 `d' = 9` 代入公式 15

```
9 = 2 * 4 + 1               (16)
```

因此，扩展后的差值 (`d'`) 被重写。首先检查差值是否可扩展。对于可扩展的差值，通过修改 LSB 进行扩展。在此修改后，可扩展差值可进一步改变以嵌入另一比特信息。这称为多层嵌入。扩展后的差值在整数平均值下进行改变。整数平均值在整数变换中不被改变。借助该整数平均值，在提取过程中可无损恢复原始像素值。因此，整数变换实现了可逆嵌入。

## 利用平面内差值嵌入的改进整数变换

Tian (2003) 提出了一种利用上述整数变换的 MLDHS。它通俗地称为 DE 方法。该方案工作流程如下。

1.  **步骤 1：** 从图像中的连续像素形成像素对，并利用整数变换转换该像素对。例如，考虑像素对 `(208, 203)`。根据上述整数变换：

    ```
    x = 208, y = 203
    平均值 (m) = floor((208 + 203) / 2) = 205
    差值 (d) = 208 - 203 = 5.
    ```

    现在，从像素对 `(x, y)` 获得 `(m, d)` 对。这称为正向整数变换。

2.  **步骤 2：** 扩展差值以在像素对 `(x, y)` 内嵌入水印比特 (`b`)。这是通过用水印比特 (`b`) 修改差值 (`d`) 来完成的。例如 `b = 1`，根据公式 10 获得修改后的差值 (`d'`) 如下：

    ```
    d' = 2 * d + b = 2 * 5 + 1 = 11.
    ```

3.  **步骤 3：** 利用修改后的差值生成含水印像素。应用逆整数变换获得修改后的像素对。对于步骤 1 和 2 中的示例：

    ```
    x' = m + floor((d' + 1) / 2) = 205 + (12 / 2) = 211.
    y' = m - floor(d' / 2) = 205 - (11 / 2) = 200.
    ```

    获得修改后的像素对 `(x' = 211, y' = 200)`。因此，水印被嵌入图像中。现在，将此 `(x', y')` 发送给接收方。

4.  **步骤 4：** 接收方收到 `(x', y')` 后，对 `x = x'` 和 `y = y'` 重复步骤 1。`x' = 211` 和 `y' = 200`：

    ```
    平均值 (m) = floor((211 + 200) / 2) = 205
    差值 (d) = 211 - 200 = 11.
    ```

5.  **步骤 5：** 读取 (`d`) 的最低有效位以获取水印信息。

    ```
    LSB(d) = LSB(11) = 1 → 此处提取出水印。
    ```

6.  **步骤 6：** 通过将 `d` 修改为 `d / 2` 来恢复原始像素对。

    ```
    d' = floor(d / 2) = floor(11 / 2) = 5.
    x = m + floor((d' + 1) / 2) = 205 + floor((5 + 1) / 2) = 208.
    y = m - floor(d' / 2) = 205 - floor(5 / 2) = 203.
    ```

因此，无需任何信息损失即可提取水印和原始像素对。实验发现，对于较小尺寸的水印，MLDHS 并不脆弱。当该方案应用于具有各种尺寸水印的眼底图像时，该方案仅能在一个颜色平面上进行更改。其余颜色平面保持不变。

当 MLDHS 应用于眼底图像时，如表 1 所示，对于水印尺寸从 10000 到 100000 的情况，它仅改变眼底图像的红色颜色平面。

它不会改变其他颜色平面。水印无法感知在其他颜色平面（绿色和蓝色）中所做的修改。因此，MLDHS 在脆弱性方面失败了。然而，可以增加大小（容量）使方案变得脆弱。增加容量直接影响不可感知性。文献调查表明，脆弱性取决于选择图像位置进行嵌入的方式。与有序选择不同，如果随机选择位置，则可以提高脆弱性。这意味着以一种方式选择位置，当尝试篡改图像时，嵌入的水印也会发生变化（Poonkuntran, Rajesh & Eswaran, 2009e）。因此，一种新的位置选择策略已被引入 MITWS。它被称为**平面内差值嵌入**。它选择跨颜色平面的像素对，而不是单一颜色平面中的连续像素。因此，在嵌入水印时，MITWS 修改两个颜色平面以提高脆弱性，如表 2 所示。因此，新引入的平面内差值嵌入策略提高了 MITWS 的脆弱性。

容量、篡改检测和篡改定位是 MLDHS 中发现的其他局限性。对于给定尺寸为 256×256 的眼底图像，MLDHS 每层最多可嵌入 128×128 位。原因是它连续选择像素对。在 MITWS 中，像素对是跨平面形成的。因此，MITWS 每层最多可嵌入 256×256 位。因此，MITWS 中的新像素选择策略提高了容量。然而，篡改定位和检测尚未由 MITWS 解决。上述讨论的颜色特征和带有新像素选择策略的修正整数变换被选为本章提出的 MITWS 设计的关键技术。

## 修正整数变换水印方案 (MITWS)

原始眼底图像 (`I`) 在 MITWS 中以 24 位或 3 字节的 RGB 颜色给出。每个字节包含两个半字节。左半字节包含字节中的最高值，而右半字节包含字节中的最低值。由于半字节值用 4 位表示，在区间 `[0, 15]` 内产生 16 个不同的十进制值。

此区间用于识别图像中像素的主色和次色。对于 RGB 中的给定像素，颜色索引计算如下：

![Mathtype978-1-7998-2701-6.ch006.m21](img/ch006.m21.svg) (17)

其中 `Color Value = {Red, Green, Blue}`。包含最小索引值的颜色被选为主色，其他为次色。像素的主色保持不变，其余像素颜色被用于整数变换进行嵌入。MITWS 中的整数变换工作如下。对于 8 位灰度像素对 `(x, y)`，`(x, y) ε Z`，`0 ≤ Z ≤ 255`，整数平均值 `m` 和差值 `d` 定义如下：

`m = floor((x + y) / 2)` (18)

`d = x - y` (19)

逆变换定义为：

`x' = m + floor((d + 1) / 2)` (20)

`y' = m - floor(d / 2)` (21)

差值 (`d`) 通过使用水印位 `b` 进行扩展，以创建扩展差值 (`d'`)。

`d' = 2 × d + b` (22)

其中 `d'` 是嵌入水印位 (`b`) 后的修正差值。

提取过程是可逆的，它无需任何信息损失即可提取秘密数据和原始图像。对于多层嵌入，选择相同的像素对进行进一步的数据嵌入。在此，某些差值可能无法长时间保持可扩展性（Tian, 2003）。提取过程需要图像中像素主色的信息。原因是像素的主色在嵌入过程中未被改变。这意味着主色中未隐藏任何信息，且在该过程中保持不变。像素的次色通过整数变换进行修改以嵌入水印。此时，像素的实际颜色特征发生变化，并在提取过程中从含水印图像中移除水印后恢复。如果没有先验信息，在提取过程中也很难对主色和次色进行分类。

为避免此问题，单独创建了**颜色分类映射 (CCM)**，并随含水印图像一起发送。`CCM` 包含二进制值 `{0, 1}`。`0` 表示该颜色为主色，在嵌入过程中未被改变。`1` 表示该颜色为次色，在嵌入过程中被改变。对于图像中的一个像素，为红、绿、蓝各主色平面生成一个 3 位代码。图像中的可扩展像素对也可通过此 `CCM` 轻松识别。对于不可扩展像素，`CCM` 为 `000`。

然后，提取过程变得简单。提取过程接收含水印图像和 `CCM`。`CCM` 识别像素的次色。这些像素值被送入公式 18 和 19 以求得 `m` 和 `d`。然后，通过读取像素对中像素间差值的最低有效位 (LSB) 来提取嵌入在像素对中的水印或秘密信息。其他步骤按第 4.4.2 节讨论的进行。

因此，MITWS 使用平面内差值嵌入和像素颜色特征进行嵌入和提取。

```
PSNR (I, I[E]) = 10 Log[10] [(2^(depth)-1)² / MSE]  (25)
```

![Mathtype978-1-7998-2701-6.ch006.m26](img/ch006.m26.svg)  (26)

其中 MSE 为均方误差，i=0 到 M-1，j=0 到 N-1。实验发现 MITWS 对任意大小的水印（容量）均具有可逆性。MITWS 产生的 PSNR 为 100%，从而保证了可逆性。这证实了因嵌入而在原始图像中所做的更改因整数变换而完全可恢复。

### 篡改检测、篡改定位与脆弱性实验

本实验根据文献调查 (Muharemagic & Furht, 2004; Poonkuntran & Rajesh, 2014) 选取了 11 种攻击。包括抖动攻击、几何攻击和滤波攻击。这些攻击广泛针对图像认证 (Muharemagic & Furht, 2004)。攻击说明如下：

*   **Jittering Attack（抖动攻击）**：抖动攻击是任何类型水印系统常见的攻击。它通过以不易察觉的方式改变像素值或复制像素值来修改图像的像素值。因此，此类攻击在外部不会引起任何怀疑。在正常视觉下，人类无法察觉这些差异。实验中抖动等级建模为 5% 到 95% 的 5 的倍数。

*   **Average（均值滤波）**：返回图像的均值滤波输出。均值滤波可使用大小为 (M x N) 的掩码完成。M 指行数，N 指列数。实验使用 3x3 掩码大小。

*   **Disk（圆盘滤波）**：返回图像的圆形均值滤波输出。通过掩码和圆半径完成。掩码大小基于所用圆的半径定义。若圆半径为 R，则掩码大小为 (2xR+1) x (2xR+1)。实验使用的圆半径为 5。

*   **Gaussian（高斯滤波）**：返回图像的旋转对称高斯低通滤波输出。通过掩码和 sigma 值两个参数完成。实验使用 3x3 掩码大小和默认 sigma = 0.5。

*   **Laplacian（拉普拉斯滤波）**：用近似二维拉普拉斯算子形状操作图像并返回输出。拉普拉斯的近似形状由称为 alpha 的参数控制。实验使用 3x3 掩码大小和默认 alpha=0.2。

*   **Log（高斯拉普拉斯滤波）**：返回图像的旋转对称高斯拉普拉斯滤波输出。实验使用的掩码大小为 5×5。默认 sigma = 0.5。

*   **Motion（运动滤波）**：返回运动滤波器的输出。运动滤波器用 l 个像素的线性运动和逆时针 theta 度角的相机卷积图像近似。对于水平和垂直运动，滤波器变为向量。默认 l 为 9，默认 theta 为 0，对应水平移动 9 个像素。实验使用滤波器的默认值。

*   **Prewitt（Prewitt 边缘滤波）**：返回图像的 Prewitt 边缘滤波输出。

*   **Sobel（Sobel 边缘滤波）**：返回图像的 Sobel 边缘滤波输出。

*   **Unsharp（反锐化掩模）**：返回图像的 3x3 反锐化对比度增强滤波输出。

*   **Rotate（旋转）**：将图像绕其中心点逆时针或顺时针旋转 angle 度。旋转图像使用双线性插值计算。最终旋转图像被裁剪以适应原始图像大小。实验使用两个角度值 25° 和 75°。

对于上述所有攻击，实验均使用参数的默认值。原因是默认值规定了所有攻击的稳定行为。此外，这些是攻击的最低要求。

如果方案对攻击的最低要求是脆弱的，那么该方案对攻击的其他等级要求必定也是脆弱的。
