## Hypertext Transfer Protocol (HTTP)

互联网上使用的协议，允许客户端从 Web 服务器请求网页，并允许客户端与这些 Web 服务器进行交互。HTTP 是一种无状态协议，意味着 Web 服务器不知道客户端请求或未请求的内容，也无法跟踪请求过特定内容的用户。该系统不允许与 Web 服务器进行良好的交互，但确实允许检索存储在网站上的 HTML 页面。

## Hypertext Transfer Protocol Secure (HTTPS)

HTTP 的安全版本，允许您连接到网站并使用安全套接字层 (SSL) 以加密格式接收和发送内容。HTTPS 最常用于电子商务网站，允许您发送个人信息，而无需担心互联网黑客查看这些信息，尤其是信用卡号和其他机密数据。您可以通过网站地址以 `https://` 开头而非 `http://`（常规 HTTP 协议）来判断是否正在使用 HTTPS。HTTPS 正在使用的另一个迹象：在浏览器中，状态栏或地址栏中会出现一把锁，表示正在使用安全连接。由于加密和解密过程会降低连接速度，因此 HTTPS 不用于整个电子商务网站，只有包含个人信息的页面才使用 HTTPS。

# 术语表

## Internet layer

**Internet layer** TCP/IP 层，负责处理从一台计算机到另一台计算机的通信。它接受来自传输层的发送数据请求。Internet 层由两个协议组成：`Internet Protocol`（`IP`）和 `Internet Control Message Protocol`（`ICMP`）。

## Internet Message Access Protocol (IMAP)

**Internet Message Access Protocol (IMAP)** 类似于 POP 的协议，允许客户端从邮件服务器检索消息。（IMAP 已迭代至第四版，即 `IMAP4`。）IMAP 允许为将邮件存储在邮件服务器以外的位置而检索电子邮件。IMAP 可与 `Microsoft Outlook` 配合使用，以检索电子邮件并将其存储在本地 PC 的数据文件中。

## Internet Protocol (IP)

**Internet Protocol (IP)** 一种通用协议，建立跨网络传输数据的机制。为 TCP/IP 套件内的所有其他协议提供数据包传递服务。

## Internet Protocol (IP) address

**Internet Protocol (IP) address** 在网络上唯一标识一台计算机。`IPv4` 地址长 32 位，采用点分十进制表示法。`IPv6` 地址长 128 位，采用十六进制格式。

## Internet Protocol Security (IPSec)

**Internet Protocol Security (IPSec)** 一种安全协议，旨在加密 IP 流量并执行认证服务。

## internetwork

**internetwork** 网络的网络，如 Internet。中继器、网桥和路由器是用于将各个 LAN 链接在一起以形成更大 internetwork 的设备。另请参见 `bridge` 和 `router`。

## intrusion detection system (IDS)

**intrusion detection system (IDS)** 检测可疑活动并通知管理员的设备或软件。

## intrusion prevention system (IPS)

**intrusion prevention system (IPS)** 检测可疑活动、采取纠正措施并通知管理员的设备或软件。

## IP

**IP** 参见 `Internet Protocol`。

## ipconfig

**ipconfig** 一种 Windows 命令行工具，用于查看和排查 TCP/IP 设置。

## kernel

**kernel** 也称为微内核，指操作系统中的核心代码。这是操作系统最重要的部分，负责系统上的所有功能，如创建、管理和调度线程。

## kernel mode

**kernel mode** 也称为特权模式，可直接访问硬件。过去作为用户模式组件运行的某些 Windows 组件现在作为内核模式组件运行。这些组件包括 `Windows Manager`、`Graphics Device Interface`（`GDI`）和图形设备驱动程序。

## key distribution center (KDC)

**key distribution center (KDC)** Kerberos 中的一项服务，负责提供会话票据。

## kilobits per second (Kbps)

**kilobits per second (Kbps)** 每秒 1024 位的数据传输速度。

## lag

**lag** 网络性能下降，通常由对可用带宽的需求增加引起。

## LAN

**LAN** 参见 `local area network`。

## lease duration

**lease duration** 指定 DHCP 客户端可以使用 IP 地址的时长，超过此时限必须向 DHCP 服务器续租。此期限可设置为无限期或预定期限。您可以选择将作用域配置为为 DHCP 客户端保留特定 IP 地址，甚至为网络上未启用 DHCP 的系统保留地址。

## least significant bit

**least significant bit** 组成字节的 8 位中最右边的位。注意，组成字节的 8 位中最左边的位称为 `most significant bit`。

## lmhosts file

**lmhosts file** 位于客户端硬盘驱动器上的文本文件，有助于将 NetBIOS 名称映射到 IP 地址。

## load

**load** 网络上存在的数据量。也称为网络流量。

## local area network (LAN)

**local area network (LAN)** 由任意两台或更多计算机组成，它们连接在一起以在小范围内（通常不超过单栋建筑）进行通信。另请参见 `virtual local area network`。

## local groups

**local groups** 位于 Windows 系统本地 SAM 数据库中的组，用于分配对该系统资源的权限。

## log off (or log out)

**log off (or log out)** 按照终止与系统会话的过程操作。

## log on (or log in)

**log on (or log in)** 按照登录网络的过程操作，以便访问文件和其他网络信息。当您有权访问网络时，即称为已登录。

## loopback address

**loopback address** 任何以 `127.x.x.x` 开头的地址，用于验证 TCP/IP 软件栈已加载并在系统上正常运行。

## MAC

**MAC** 参见 `Media Access Control`。

## MAC address

**MAC address** 也称为硬件地址，是一个 12 位十六进制数（由数字 0-9 和字母 A-F 组成），分配给网卡。地址由两部分组成：第一部分标识供应商；第二部分是该网卡唯一的序列号。考试中无需了解这些数字如何细分，只需知道该地址是什么即可。

## mandatory access control (MAC)

**mandatory access control (MAC)** 基于员工的许可级别和分配给资源的数据分类标签来控制资源访问。

## mandatory logon

## mantrap

**mantrap** 两扇门之间的区域，第二扇门在第一扇门关闭前不会打开。Mantrap 旨在防止有人在您开门后尾随潜入设施。

## media access card

## Media Access Control (MAC)

**Media Access Control (MAC)** 数据链路层的一个子层，决定哪台计算机可以发言以及何时发言。

## megabits per second (Mbps)

**megabits per second (Mbps)** 每秒 1,048,576 位的通信速率，用于测量吞吐量或通信速度。

## member server

**member server** 属于域一部分但未安装 Active Directory 的 Windows 服务器。

## memory

**memory** 信息的临时存储空间。物理内存是 `RAM`（随机存取存储器）；虚拟内存是充当额外 RAM 的硬盘空间。

## Microsoft Challenge Handshake Authentication Protocol (MS-CHAP)
