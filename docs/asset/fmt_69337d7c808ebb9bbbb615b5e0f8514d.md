
# 模型评估与选择最佳实践

## 比较多个指标
比较多个指标提供了对模型性能更全面的理解，特别是当不同指标强调不同方面时，如下：

- 不要依赖单一指标（如`accuracy`或`R²`）。
- 使用组合指标，**分类**：`precision`、`recall`、`F1`分数、`AUC` **回归**：`MAE`、`RMSE`、`R2`

这提供了模型优势和权衡的良好视角。

## 考虑部署因素
除了准确率，部署因素（如效率和资源限制）对选择正确模型起着至关作用，概述如下：

- 评估推理时间、模型大小和内存使用，特别是对于效率至关重要的实时或边缘应用。
- 如果一个准确率稍低的模型更轻、更快，它可能更合适。

## 使用自动化评估工具
自动化评估工具简化了模型评估，提供可视化、监控和实验跟踪以支持明智决策，如下：

- 工具如：
  - **Yellowbrick**：用于模型诊断的可视化。
  - **Eidently AI**：实时模型监控和公平性检查。
  - `MLflow`：跟踪模型实验、指标和版本有助于标准化和可视化多次运行之间的比较。

### AI 小贴士——让 ChatGPT 执行
- 为三个分类器的`precision`、`recall`和`F1`分数生成并对比图表。
- 使用`MLflow`记录并比较多个回归模型。
- 使用`Yellowbrick`可视化多个模型的分类报告。

这些工具可以自动化比较工作流并提供直观的见解，帮助你有信地选择最合适的模型。

# 以人为中心的评估

机器学习指标并非孤立存在；你的模型做出的每种预测都会影响现实世界中的系统、流程或个人。有效的评估必须超越数字，结合对领域及其风险的语境理解。

根据用例的不同，不同类型的错误会带来不同的后果。例如：

### 医疗保健
在医疗应用中，错误预测的代价可能是致命的，这使得某些指标比其他指标更重要，如下所示：

- **假阴性**（例如，未能检测出疾病）可能会延迟治疗或导致危生命的后果。
- **指标优先级**：最大化`recall`（敏感性）以捕捉每一个阳性病例，即使以增加更多假阳性为代价。

### 垃圾邮件检测
在垃圾邮件检测场景中，减少假警报是维持可用性和信任的关键，这将重点转向`precision`，解释如下：

- **假阳性**（例如，将合法邮件标记为垃圾邮件）虽然令人厌恼，但通常是可逆的。
- **指标优先级**：优化`precision`以避免过度标记并提高用户体验。

### 欺诈检测
欺诈检测需要在捕捉欺诈活动与保持用户满意度之间进行仔细权衡，这使得`F1`分数等平衡指标至关重要，概述如下：

- **假阴性**可能导致欺诈未被检测到并造成损失。
- **假阳性**可能会不必要的阻塞合法交易，令用户感到沮丧。
- **指标优先级**：使用`F1`分数或与业务目标一致的自定义成本函数平衡`precision`和`recall`。

# 核心总结

始终将评估指标与特定领域的风险和利益相关者的影响对齐。一个技术上准确的模型只有在它为服务的人和系统做出正确权衡时才具有价值。

### AI 小贴士——让 ChatGPT 执行
- 为医疗分类任务**定义成本敏感指标**。
- **调整阈值**以最小化信用风险评分中的假阴性。
- **解释在人机协作系统**（`human-in-the-loop`）中应优先考虑哪个指标。

通过将定量评估与以人为中心的思维相结合，你可以确保你的模型在正确、伦理和操作上都是一致的。
