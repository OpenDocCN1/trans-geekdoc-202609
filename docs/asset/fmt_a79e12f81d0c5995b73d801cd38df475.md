### 基于主机的 IDS 和基于主机的 IPS

配置系统安全的另一部分是在系统上安装并配置*基于主机的入侵检测系统 (HIDS)* 或*基于主机的入侵防御系统 (HIPS)*。基于主机的 IDS 负责监控系统上的活动，并针对任何可疑活动向您发出警报；而基于主机的 IPS 监控可疑活动，然后采取纠正措施，例如将系统锁定或禁用网络通信。关于 HIDS/HIPS 要记住的关键点是，它仅监控安装了该软件的系统上的活动。如果您想监控五个不同系统上的活动，则需要在每个系统上安装 HIDS/HIPS。

HIDS/HIPS 软件通过查看系统的不同区域来监控可疑更改。以下是 HIDS/HIPS 监控的一些关键区域：

- **内存** HIDS/HIPS 可以监控内存区域，并监视在系统上执行的可疑程序。
- **系统文件** HIDS/HIPS 可以对系统文件生成哈希值并将其存储在数据库中。当访问或执行系统文件时，HIDS/HIPS 可以计算该文件的新哈希值，并将其与数据库中存储的值进行比较，以确定文件是否被篡改。
- **日志文件** 许多应用程序将活动记录到日志文件中，HIDS/HIPS 可以读取这些文件以查找可疑活动。
- **文件系统** HIDS/HIPS 可以监控文件的多种更改，例如权限、所有者、文件大小和最后访问时间的更改。
- **连接** HIDS/HIPS 可以监控到系统的连接，并查找未经授权的连接，甚至针对系统的端口扫描。

您将在第 19 章中了解更多关于监控和审计的内容，但请理解，HIDS/HIPS 可以通过分析日志文件中发生的事件，或通过捕获正常活动的*基线*来检测可疑流量，任何异常（偏离正常活动）均被视为可疑。

## 考试内幕

**监控加密流量**

对于认证考试，请记住基于网络的 IDS (NIDS) 的一个局限性是：如果您正在加密网络流量，NIDS 将无法根据其认为可疑的内容分析该流量，因为 NIDS 无法解读该信息。

HIDS 是安装在系统上的软件，因此它可以监控涉及与该系统进行加密通信的活动。运行 HIDS 软件的系统会解密加密通信，然后记录活动；HIDS 只需查看系统上的未加密日志即可识别可疑活动。

您将在下一章了解另一种类型的入侵检测系统——基于网络的 IDS (NIDS)。NIDS 通过分析网络流量并将其与识别可疑流量的特征码进行比较，来识别可疑活动。关于 HIDS 与 NIDS 相比要记住的关键点是：如果网络流量被加密，NIDS 将无法检测可疑流量。使用 HIDS 的一个强项是，无论网络流量是否加密都无关紧要，因为 HIDS 不会查看那里来识别问题。

### 补丁管理

安装在我们计算机上的应用程序和操作系统是由人类开发的，因此极有可能在拥有优秀功能的同时，也被编程进了一些错误。这些程序代码中的错误（称为漏洞）可能被个人发现并利用，从而接管您的系统或网络。这被称为网络攻击或系统攻击，具体取决于整个网络被接管还是仅单个系统被接管。

软件和操作系统制造商始终在寻找其代码中的漏洞。他们修复这些错误，并以修复程序、补丁或更新的形式发布修正。通过此过程可以防止许多网络攻击。您通常会通过制造商的网站获取这些修复程序和更新。例如，Microsoft 操作系统具有 Windows Update 功能，该功能会访问 Microsoft 的更新网站并扫描您的系统以查找需要安装的任何更新。可以通过右键单击“开始”菜单并选择“控制面板”|“系统和安全”|“Windows Update”来运行此 Windows Update 功能。Windows Update 确定系统所需的更新后，您的系统将从 Windows Update 站点下载这些更新（请参见图 7-9）。

### 安全热修复

安全热修复是一项关键的安全更新，应尽快应用到您的系统中，因为该漏洞会使系统面临严重的安全风险。

### Windows Server 更新服务

在一台系统上运行 Windows Update 不是问题，但如果您必须管理 500 台系统，并确保每台系统都通过最新的补丁和热修复保持最新状态，该怎么办？微软创建了 **Windows Server 更新服务 (WSUS)**，它允许您创建一台 WSUS 服务器，并将更新从互联网下载到 WSUS 服务器。然后您可以在一些测试系统上测试这些更新的安装，以验证更新不会与这些系统上的任何应用程序冲突；接着您可以将更新推送到那 500 台系统。

WSUS 有许多优势；首先，您可以从互联网将更新下载到一台中心计算机，而不必让每台系统都从互联网下载。这通过避免每个人执行下载来帮助维护可用带宽。WSUS 的另一个优势是客户端只会接收您已批准的更新。之所以会这样，是因为您会将每个客户端配置为从 WSUS 服务器检索更新，而不是从互联网检索。一旦您在 WSUS 服务器上批准了更新，客户端就会通过 WSUS 自动获取更新。网络上的客户端不会下载任何未经批准的更新。同样重要的是要注意，使用 WSUS 时，安装是由系统本身执行的，而不是由已登录的用户执行。这很重要，因为用户通常没有安装软件的权限。

### 配置防病毒软件

### 配置反垃圾邮件软件/垃圾邮件过滤器

垃圾邮件是未经请求的电子邮件。发件人通常从供应商处获取您的电子邮件地址，这些供应商会在您访问其网站并填写表单时收集您的电子邮件地址。垃圾邮件发送者还可以在互联网上搜索网页以查找电子邮件地址。

贵组织务必在电子邮件服务器上实施垃圾邮件过滤软件，以便在大多数垃圾邮件试图进入组织时将其拦截。我曾与一位客户交谈，其垃圾邮件过滤器报告显示每天有 40,000 条邮件被拦截，无法进入公司邮件服务器。

公司还可以购买*一体化安全设备*，该设备负责执行多种功能，如公司防火墙、入侵检测系统，以及针对试图进入网络的电子邮件的病毒扫描器和垃圾邮件过滤器。一体化安全设备通常放置在网络边界，以阻止恶意流量进入网络。一体化安全设备通常具有以下功能：

### URL 过滤器

内置于安全设备中的 URL 过滤器可以限制员工可以访问的网站。这是阻止常见社交网站（如 [Facebook.com](http://Facebook.com)）的典型方法，以免员工在公司时间浪费在这些网站上。

### 内容检查

安全设备的内容检查功能允许设备查看数据包内容（称为有效载荷），并根据数据包中发现的信息过滤流量。例如，黑客可能希望阻止应用程序中的某些命令，例如上传到 FTP 服务器的能力。

### 恶意软件检查

一体化安全设备还可以内置恶意软件防护，保护网络免受病毒、广告软件、垃圾邮件和其他形式的恶意软件侵害。

### 间谍软件和广告软件

间谍软件是加载在您系统上并监视您互联网活动的软件，广告软件是加载在您系统上并弹出广告推广产品和网站的软件。这两类软件在过去几年中已成为互联网的公害。它们最常在您浏览恶意或被黑客攻击的网站时被加载到您的系统上。

反间谍软件（和反广告软件）是您可以用来从系统中清除这些麻烦入侵者的软件。可用于清除此类恶意软件的产品包括 Spybot、Ad-Aware 和 Microsoft 的 Windows Defender。反间谍软件已像防病毒软件一样普及，较新的反间谍软件产品的许多功能与防病毒软件相同，例如实时保护和计划扫描。Windows Defender 包含以下功能：

- Antivirus and anti-malware
- Real-time protection
- Scheduled scans
- Browser hijack protection
- Automatic updates of malicious software definitions

值得注意的是，Microsoft 多年来经历了多个版本的反恶意软件演变，始于 Windows Defender。随后公司开始推广名为 Microsoft Security Essentials 的防病毒软件，并在 Windows 8.1 中更新了 Windows Defender，使其包含防病毒软件以及反间谍软件功能，从而使其成为一款功能齐全的反恶意软件工具。

### 网络钓鱼过滤器和弹出窗口拦截器

在 Chapter 4 中，您了解了不同类型的攻击，包括网络钓鱼攻击。请记住，网络钓鱼攻击是指黑客向您发送电子邮件，将您引导至特定公司（如银行）的虚假网站。

实施网络钓鱼过滤器和弹出窗口拦截器以保护系统免受网络钓鱼攻击和弹出窗口中运行的恶意代码侵害至关重要。您可以寻找第三方应用程序来获取网络钓鱼过滤器和弹出窗口拦截器，但重要的是要知道，大多数现代网络浏览器都内置了这些功能。

#### 配置网络钓鱼过滤器和弹出窗口拦截器

您的网络浏览器预装了网络钓鱼过滤器和弹出窗口拦截器，可保护您免受钓鱼网站和烦人弹窗的侵害。要在 Microsoft Edge 中配置弹出窗口拦截器，请转到“Settings and More (…)”菜单，然后选择“Settings | Cookies and Site Permissions | Pop-Ups and Redirects”。默认情况下会阻止弹出窗口和重定向，请注意您可以添加站点以允许其弹出窗口和重定向。如果您知道该站点安全但使用少量弹窗显示内容，则可能希望执行此操作。

为了帮助保护您的系统免受钓鱼网站侵害，并防止其他恶意软件从网站下载，Microsoft 创建了 SmartScreen Filter 功能并将其内置到 Microsoft Edge 中。当您访问某个站点时，SmartScreen Filter 会根据已知的钓鱼网站检查该站点。如果该站点已知包含可疑内容，则会显示警告。您可以在 Edge 中通过选择“Settings and More (…) | Help and Feedback | Report Unsafe Site”手动将某个站点报告为钓鱼网站或恶意网站。
