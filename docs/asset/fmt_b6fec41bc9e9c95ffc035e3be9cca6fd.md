正确答案：C 在受控环境中测试补丁。在部署或分发补丁之前（特别是针对关键漏洞），在受控环境中进行测试是关重要的。这可以确保补丁不会引入新问题，并能够有效解决漏洞。

**选项 A 错误。** 在不经过测试的情况下立即在所有公司系统上部署补丁可能会导致意想不到的问题，甚至加剧问题。

**选项 B 错误。** 向媒体通知漏洞，特别是在漏洞得到有效解决之前且没有协调的披露计划的情况下，可能会导致恐慌并被恶意攻击者潜在利用。

**选项 D 错误。** 提供补偿是响应性的，不能直接解决漏洞。识别漏洞后的首要目标应该是处理并缓解它。

## 问题 405
在发生重大安全事件后，DeltaTech 实施了多个安全补丁以解决其基础设施中的漏洞。为了确保这些补丁的有效性，DeltaTech 的主要下一步应该是？

- (A) 在网络边界部署额外的防火墙
- (B) 为所有员工提供网络安全培训
- (C) 重新扫描系统以检查漏洞是否已有效解决
- (D) 更改组织内所有用户的密码

### 解释 405
正确答案：C 重新扫描系统以检查漏洞是否已有效解决。实施安全补丁后，必须重新扫描系统以确保识别出的漏洞已得到有效解决且补丁已正确实施。

**选项 A 错误。** 虽然防火墙对安全至关重要，但部署防火墙与验证新实施补丁的有效性没有直接关系。

**选项 B 错误。** 为员工提供网络安全培训至关重要，但它不能验证所应用补丁的成功。

**选项 D 错误。** 在破解后更改用户密码可能是必要步骤，但不能验证补丁是否成功解决了漏洞。

## 问题 406
一家电子商务公司正在推出一款新应用程序以方便在线支付。IT 部门希望立即收到任何应用程序错误或对应用程序代码库未经授权的修改。他们应该实施以下哪些工具？

- (A) Web 应用防火墙 (`WAF`)
- (B) 应用程序性能监控 (`APM`)
- (C) 域名系统 (`DNS`) 监控工具
- (D) 网络流分析器

### 解释 406
正确答案：B 应用程序性能监控 (`APM`)。`APM` 工具旨在监控应用程序性能，并能检测错误。

**选项 A 错误。** `WAF` 通过过滤流量保护 Web 应用程序，它并不监控代码更改。

**选项 C 错误。** `DNS` 监控工具关注的是可用性和安全性，不监控应用程序错误。

**选项 D 错误。** 网络流分析器检查数据流但不监控代码完整性。
