
PCA 的处理方式与 Fisher 线性判别 (FLD) 方法（第 7 章）有相似之处。它们都依赖于矩阵的特征结构，这些矩阵以某种方式编码了（协）方差信息。然而，请注意 PCA 是一种*无监督*方法，这与作为*有监督*方法的 FLD 形成对比。因此，PCA 执行降维以保留数据变异性（方差），而 FLD 则保留类别可分性。图 20.3 演示了所得（超）平面的差异。

![Figure 20.3 The case of a two-class task in the two-dimensional space. PCA computes the direction along which the variance is maximally retained after the projections of the data on it. In contrast, FLD computes the line so that the class separability is maximized.](img/gr003.jpg)

图 20.3 二维空间中两类任务的情况。PCA 计算数据投影到其上后方差最大保留的方向。相反，FLD 计算使类别可分性最大化的直线。

*   *多维缩放* (MDS) 是另一种线性技术，用于投影到低维空间，同时满足某些约束。给定集合 $\mathcal{X} \subset \mathbb{R}^{(l)}$，目标是投影到低维空间，使得内积得到最优保留；即代价

$$
E = \sum\limits_{i}\sum\limits_{j}\left( \mathbf{x}_{i}^{T}\mathbf{x}_{j} - \mathbf{z}_{i}^{T}\mathbf{z}_{j} \right)^{2}
$$

最小化，其中 `z_i` 是 `x_i` 的像，求和遍历 $\mathcal{X}$ 中所有训练点。该问题类似于 PCA，可以证明解由 Gram 矩阵的特征分解给出，^(¹⁵⁶)

*   关于这些问题的更多内容可参见 [29,60]。正如我们将在第 20.9 节中很快看到的，MDS 保持距离的主要思想以某种方式被用于许多最近开发的非线性降维技术中。

### 监督 PCA

在基本 PCA 的一个变体中，称为**监督 PCA** [16,195]，回归或分类中的输出变量（取决于手头的问题）与输入变量一起使用，以确定主方向。

### 信息检索背景下的应用

为了将我们之前的发现置于信息检索的背景下，假设有一幅可用的图像，并且想要知道图像中描绘的是什么人。假设该人的图像在数据集中，处理过程如下：

(a) 对图像进行向量化；

(b) 将其投影到由前 *m* = 100 个特征向量所张成的子空间上；

(c) 在这个低维空间中搜索，以欧几里得范数的意义识别数据集中最接近的向量化图像。

通常，最好识别出最相似的 5 或 10 幅图像，并根据欧几里得距离（或任何其他距离）相似度对它们进行排序。随后，可以检索存储在数据集/数据库中的姓名及所有相关信息。

在信息检索中，数据集中的每幅图像都可以用相应的主成分得分向量来存储。

### 示例 20.2：PCA 图像压缩

本例演示了 PCA 在图像压缩中的应用。在上一个示例中，PCA 是跨数据库的不同图像执行的。这里，重点将放在单幅图像上。

图像的像素值存储在一个 *l* × *N* 矩阵 **X** 中，该矩阵的列被视为观测向量 **x**[*n*] ∈ ℝ^(*l*)，*n* = 1, 2, …, *N*。注意，**X** 需要沿行进行零均值化，因此计算均值向量 $\bar{\mathbf{x}}$ 并从每一列中减去。然后，获得对应于 *m* 个最大特征值（1 ≤ *m* < *l*）的特征向量，既可以通过样本协方差矩阵，也可以直接通过 SVD 获得。利用公式 (20.22) 中 PCA 的矩阵分解公式，**X** 的压缩表示（包含 *m* 行而非 *l* 行）由下式给出：

```
Z^(m) = [u_1, ..., u_m]^T X
```

其中维度 *m* 已明确引入符号中。因此，只需要 `Z^(m)` 和 **u**_1, …, **u**_m 即可通过公式 (20.21) 获得均值减去后的 **X** 的估计值。最后，为了重建图像，需要将均值向量 $\bar{\mathbf{x}}$ 加回到每一列中（参见公式 (20.23)）。

基于 PCA 的图像压缩的有效性将借助图 20.7 中左上角所示图像进行演示。该图像为正方形，具有 `l = N = 400`。对于任意选定的 `m`，压缩比易于计算：原图像有 `400 × 400` 个值，压缩后仅需存储矩阵 `Z^(m)` 和特征向量 `u[1], …, u[m]` 的 `2 × m × 400` 个值，加上均值向量 `\overline{x}` 的 400 个值。这相当于 `400 : (2m + 1)` 的压缩比。不同压缩率下的重建图像及原始图像与重建图像之间对应的 MSE 如图 20.7 所示。

## 20.4 典型相关分析

PCA 是一种专注于*单个*数据集的降维技术。然而，在许多情况下，必须处理多个数据集，尽管它们可能源自不同来源，但彼此密切相关。例如，医学成像中的许多问题都属于这一范畴。一个典型案例出现在脑活动研究中，可使用不同模态，如脑电图（EEG）、功能性磁共振成像（fMRI）或结构性 MRI。每种模态均可捕获不同类型的信息，以互补方式利用所有模态大有裨益。因此，可将相应实验数据适当融合，以更好地描述产生数据的脑活动。另一个涉及多个数据集的场景是：虽使用单一模态，但有不同受试者的测量数据可用；因此联合分析结果有助于得出最终结论（见如 [56]）。

*典型相关分析*（CCA）是文献 [96] 开发的一种用于联合处理两个数据集的经典技术。我们的出发点是：当涉及两组随机变量（两个随机向量）时，它们的相关性值*确实取决于*随机向量所处的坐标系。CCA 的目标是为每组变量寻找一对线性变换，使得变换后的变量具有*最大相关性*。

假设我们有两组随机变量，分别构成两个随机向量的分量：`x ∈ ℝ^p` 和 `y ∈ ℝ^q`。对应的观测值集合分别为 `x_n, y_n, n = 1, 2, …, N`。遵循逐步过程（正如我们对 PCA 所做的那样），我们将首先计算一对方向，即 `u_x,1, u_y,1`，使得投影到这些方向上的相关性最大化。

令 `z_x,1 := u_x,1^T x` 和 `z_y,1 := u_y,1^T y` 为线性变换（投影）后的（零均值）随机变量。注意，这些变量是 PCA 中所谓主成分的对应物。对应的相关系数（归一化协方差）定义为：

```
ρ := E[z_x,1 z_y,1] / √(E[z_x,1²] E[z_y,1²])
   = E[(u_x,1^T x)(y^T u_y,1)] / √(E[(u_x,1^T x)²] E[(u_y,1^T y)²])
```

或者

$$
\rho := \frac{\mathbf{u}_{x,1}^{T}\Sigma_{xy}\mathbf{u}_{y,1}}{\sqrt{(\mathbf{u}_{x,1}^{T}\Sigma_{xx}\mathbf{u}_{x,1})(\mathbf{u}_{y,1}^{T}\Sigma_{yy}\mathbf{u}_{y,1})}},
$$

其中

$$
\mathbb{E} \left\lbrack \begin{bmatrix} \mathbf{x} \\ \mathbf{y} \end{bmatrix} \lbrack \mathbf{x}^{T}, \mathbf{y}^{T} \rbrack \right\rbrack := \begin{bmatrix} \Sigma_{xx} & \Sigma_{xy} \\ \Sigma_{yx} & \Sigma_{yy} \end{bmatrix}.
$$

注意，根据各自的定义，我们有 $\Sigma_{xy} = \Sigma_{yx}^{T}$。当期望不可用时，协方差将被相应的样本协方差值所替代。这是实践中最常见的情况，因此我们将坚持这种做法，并使用带“帽子”的符号。此外，很容易验证相关系数对缩放是不变的（例如改变 $\mathbf{x} \to b\mathbf{x}$）。因此，关于方向 $\mathbf{u}_{x,1}$ 和 $\mathbf{u}_{y,1}$ 最大化它，可以等价地转化为以下约束优化任务：

![](img/fx005.jpg)

将公式 (20.27)–(20.29) 与公式 (20.2) 和 (20.3) 中定义 PCA 的优化任务进行比较。对于 CCA，必须计算两个方向，且约束涉及加权的 $\hat{\Sigma}$-范数，而不是欧几里得范数。此外，PCA 最大化的是方差，而 CCA 关注的是两个涉及向量在新轴上的投影之间的相关性。

采用拉格朗日乘数法，公式 (20.27)–(20.29) 对应的拉格朗日函数由下式给出

$$
L(\mathbf{u}_x, \mathbf{u}_y, \lambda_x, \lambda_y) = \mathbf{u}_x^T \widehat{\Sigma}_{xy} \mathbf{u}_y - \frac{\lambda_x}{2} \left( \mathbf{u}_x^T \widehat{\Sigma}_{xx} \mathbf{u}_x - 1 \right) - \frac{\lambda_y}{2} \left( \mathbf{u}_y^T \widehat{\Sigma}_{yy} \mathbf{u}_y - 1 \right).
$$

对 $\mathbf{u}_x$ 和 $\mathbf{u}_y$ 求梯度并令其为零，我们得到（问题 20.2）：

$\lambda_x = \lambda_y := \lambda$

以及

$$
\widehat{\Sigma}_{xy} \mathbf{u}_y = \lambda \widehat{\Sigma}_{xx} \mathbf{u}_x, \tag{20.30}
$$

$$
\widehat{\Sigma}_{yx} \mathbf{u}_x = \lambda \widehat{\Sigma}_{yy} \mathbf{u}_y. \tag{20.31}
$$

解后一个方程求 $\mathbf{u}_y$ 并代入第一个方程，我们最终得到

$\widehat{\Sigma}_{xy}\widehat{\Sigma}_{yy}^{-1}\widehat{\Sigma}_{yx}\mathbf{u}_x = \lambda^2 \widehat{\Sigma}_{xx}\mathbf{u}_x$

以及

$$
\mathbf{u}_y = \frac{1}{\lambda}\widehat{\Sigma}_{yy}^{-1}\widehat{\Sigma}_{yx}\mathbf{u}_x,
$$

当然，这假设 $\widehat{\Sigma}_{yy}$ 可逆。此外，假设 $\widehat{\Sigma}_{xx}$ 也可逆，我们最终得到以下特征值-特征向量问题：

$(\widehat{\Sigma}_{xx}^{-1}\widehat{\Sigma}_{xy}\widehat{\Sigma}_{yy}^{-1}\widehat{\Sigma}_{yx})\mathbf{u}_x = \lambda^2\mathbf{u}_x$。

因此，轴 $\mathbf{u}_{x,1}$ 可作为上述矩阵乘积的一个特征向量获得。考虑到公式 (20.30) 和约束条件，相应的相关性最优值 $\rho$ 等于

$\rho = \mathbf{u}_{x,1}^T\widehat{\Sigma}_{xy}\mathbf{u}_{y,1} = \lambda\mathbf{u}_{x,1}^T\widehat{\Sigma}_{xx}\mathbf{u}_{x,1} = \lambda$。

因此，选择 $\mathbf{u}_{x,1}$ 作为对应最大特征值 $\lambda^2$ 的特征向量，可得到最大相关性。

特征向量 $\mathbf{u}_{x,1}, \mathbf{u}_{y,1}$ 称为*归一化典型相关基向量*，特征值 $\lambda^2$ 称为平方*典型相关*，投影 $z_{x,1}, z_{y,1}$ 称为*典型变量*。

现在可以进一步推广上述思想，计算一对子空间：span{$\mathbf{u}_{x,1}, …, \mathbf{u}_{x,m}$} 和 span{$\mathbf{u}_{y,1}, …, \mathbf{u}_{y,m}$}，其中 $m \le \min(p, q)$。实现这一目标的一种方法是分步进行，类似于 PCA 的做法。假设已计算出 $k$ 对基向量，则第 $k + 1$ 对通过求解以下约束优化任务获得：

```
max_{u_x, u_y} u_x^T Σ̂_xy u_y,
```

约束条件：

$\mathbf{u}_x^T\widehat{\Sigma}_{xx}\mathbf{u}_x = 1, \mathbf{u}_y^T\widehat{\Sigma}_{yy}\mathbf{u}_y = 1$

$\mathbf{u}_x^T\widehat{\Sigma}_{xx}\mathbf{u}_{x,i} = 0, \mathbf{u}_y^T\widehat{\Sigma}_{yy}\mathbf{u}_{y,i} = 0, i = 1, 2, …, k.$
