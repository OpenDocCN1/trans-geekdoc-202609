## 结构

我们考虑三个相互作用的种群，每个种群的数量由变量 `x, y, z > 0` 表示（参见 Nicolis and Prigogine, 1977, p. 460）。该模型的动力学给出：

```
$\dot{x} = \kappa x(N_0 - y - z) - \delta x,$
$\dot{y} = \kappa y(N_0 - y - z) - \delta y,$
$\dot{z} = f(x, y) - \delta z. (6)$
```

这里 `f(x,y) = \alpha z(y - z)` 是一项。希腊字母代表正系数；`$N_0$` 是资源的最大水平。`y+z` 被理解为在“工作类”`y` 和（小尺寸的）“战士类”`z` 之间，`x` 是“中间类”，被“战士”在同一个生态位内捕食。

稳定性分析显示平衡态 `x_0, y_0, z_0 = 0` 是不稳定的。考虑 `x_0, y_0=0; z=0`（没有战士类）或 `x_0=0; y_0=0`（没有中间类）。中间类生存的条件是：

```
$\kappa(N_0 - y_0 - z_0) - \delta > 0.$
```

由于 `z_0` 是很小的，如果工人 `y_0` 是大尺寸种群或者战士非常有攻击性（`z_0 \gg 0`），则 `x` 将消失。记得 Lotka-Volterra (LV) 系统

```
$\dot{x} = -x + \alpha y,$
$\dot{y} = +y - \beta x,$
```

描述了两个相互作用的种，可以通过简单的变量替换等价：

```
$u = \log x$
$v = \log y,$
```

源自哈密顿函数 `H`（此处未显式；参见 Nicolis and Prigogine, 1977），使得有：

```
$\dot{u} = -\partial H/\partial v,$
$\dot{v} = +\partial H/\partial u.$
```

此外，由于 `H` 是系统的的第一积分，由于 LV 系统只有闭轨道，我们可以通过正则变换将其谐振子系统：

```
$\xi = -\eta$
$\dot{\eta} = +\xi.$
```

这些结果将是我们的起点。

关于 SAT 的定义（以及满足性问题的详细介绍），请参见 Machtey 和 Young (1979)；关于 BGS 多项式图机的递归集，请参见 Baker 等人 (1975)。简而言之，SAT 是所有可满足的合取范式 (cnf) 布尔表达式的集合，而 BGS 是一个多项式图机的递归集，包含了每个可以想象的图灵机的仿真。

### 完全反例函数，直观思想

完全反例函数 `f` 定义如下：设 `$\omega$` 编码图灵机的枚举。同样通过标准代码将 SAT 映射到 `$\omega$`：

- `n \in \omega` 不是多项式机，`f(n) = 0`。
- `f(n)` = SAT 的第一个实例 `x`，使得该机器无法输出 `x` 的满足行，加 1，即 `f(n) = x + 1`。

否则 `f(n)` 未定义，即对于 `n` P = NP 成立。

`f` 将证明其增长速度至少与 Busy Beaver 函数一样快，因为它在峰值处停止了所有递归函数。证明这一事实的思路如下：

- 使用 `s-m-n` 理论来获取一组待定义的“准平凡机”的无限族的哥德数。这些图灵机的表格涉及非常大的数字，目标是为每个准平凡机中的该值获取一个紧凑代码，以便它们的哥德数处于序列 `c(0), c(1), c(2), \dots` 中，其中 `c` 是原始递归的。
- 然后在 BGS 多项式图机序列中添加所需的时钟，并得到对的哥德数。我们可以将该序列嵌入到所有图灵机的序列中。
- 注意我们正在处理的多项式机子集（直观上）是所有图灵机集的递归子集。更准确地说，如果在 `S` 中形式化一切，那么句子“这些准平凡机的哥德数集是所有图灵机哥德数集的递归子集”的形式化版本在 `S` 的算术标准模型成立，反之亦然。然而，`S` 可能无法证明或否定该断言，也就是说，此类断言有时是独立的。我们在所需的的多项式机集上定义反例函数，并将它们与相似限制下的快速增长全递归函数进行比较。
