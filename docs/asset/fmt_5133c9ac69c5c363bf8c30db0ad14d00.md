
# 无线网络与移动设备安全

## 认证协议

### EAP-TLS
**Extensible Authentication Protocol-Transport Layer Security (EAP-TLS，可扩展认证协议-传输层安全)** 实现了基于证书的身份验证以及设备和网络的相互认证。它在客户端和网络设备上都使用证书来生成密钥，然后用于通信。由于在大量客户端设备上部署和管理证书的挑战，EAP-TLS 的使用频率较低。

### EAP-TTLS
**EAP Tunneled Transport Layer Security (EAP-TTLS，隧道传输层安全可扩展认证协议)** 扩展了 EAP-TLS，与 EAP-TLS 不同，它不要求客户端设备拥有证书即可创建安全会话。这消除了 EAP-TLS 为分发和管理终端证书所需的开销和管理工作，同时仍为设备提供 TLS 支持。EAP-TTLS 部署的一个顾虑是，EAP-TTLS 可能需要在某些设备上安装额外软件，而提供类似功能的 PEAP 则不需要。EAP-TTLS 确实支持一些安全性较低的认证机制，这意味着有时可能会因特定要求而实施它。

## RADIUS 联合认证

当组织希望协同工作时，RADIUS 服务器可以联合起来，允许来自其他组织的个人使用其母组织的账户和凭据向远程网络进行身份验证。这样联合 RADIUS 服务器要求作为联盟的一部分在 RADIUS 服务器之间建立信任。许多高等教育机构为无线网络提供名为 `eduroam` 的联合认证服务，允许来自任何 eduroam 机构的学生、教职员工在任何其他支持 eduroam 的组织进行身份验证并使用网络。当然，如果存在多个 RADIUS 域，RADIUS 服务器也可以在单个组织内联合。

## 管理安全移动设备

组织使用各种各样的移动设备，范围从手机和平板电脑到更专业的设备。当您考虑组织应如何处理它们时，您需要为部署和管理模型进行规划，是否将使用移动设备管理工具，以及将实施哪些安全选项和设置。

### 移动设备部署方法

当组织使用移动设备时，一个重要的设计决策是将选择哪种部署和管理模型。最常见的选项是 BYOD（自带设备）；CYOD（自选设备）；COPE（公司所有、个人启用）；以及完全公司所有。

这些选项归结为几个常见问题。首先，谁拥有、选择并支付设备及其连接计划的费用？其次，设备如何被管理和支持？第三，数据和应用程序如何被管理、保护和保障？

BYOD 将控制权交给最终用户，因为他们选择并管理自己的设备。在某些 BYOD 模型中，组织可能会使用有限的管理功能，例如远程擦除电子邮件或特定应用程序的能力，但 BYOD 的控制和管理模型在很大程度上基于用户。此选项为组织提供的安全性和监督要少得多。

#### 移动设备部署模型

##### CYOD（自选设备）

在 CYOD 模型中，组织支付设备费用，通常也支付蜂窝网络套餐或其他连接费用。用户选择设备，有时从首选选项列表中选择，而不是自带他们想用的任何设备。在此类 CYOD 设计中，支持更容易，因为只会遇到有限数量的设备类型，这也可以使安全模型更容易建立。由于 CYOD 仍将设备留在用户手中，安全性和管理可能仍不那么标准化，尽管这可能会有所不同。

##### COPE（企业拥有，个人启用）

在 COPE 模型中，设备归公司所有并由公司管理。COPE 认识到用户不太可能想随身携带两部手机，因此允许在企业设备上进行合理的个人使用。该模型允许组织更全面地控制设备，同时仍允许个人使用。

##### 完全企业拥有

完全由企业拥有和管理的设备是受控程度最高的环境，通常更类似于带有完整控制和管理套件的企业 PC。这是选项中最不友好的，因为企业选择和管理的设备将满足企业需求，但通常缺乏更以最终用户为中心的设计的灵活性。

##### 实施考量

尽管这些是常见的描述，但实际实施差异很大，每种解决方案之间的界限可能很模糊。这些不是硬性规定，而是组织移动设备部署模型的起点示例，可以帮助推动安全、管理和运营实践的讨论。在实际使用中，审视这些实践的最佳方式是将其视为基于组织需求、能力和实际使用情况的一个光谱的一部分。

##### 支持技术

一项可以帮助使移动设备部署更安全的关键技术是使用 `virtual desktop infrastructure (VDI)`（虚拟桌面基础设施），允许相对低安全性的设备访问安全的托管环境。使用 `VDI` 允许设备用户连接到远程环境，执行操作，然后返回设备的正常使用。容器化工具也可以帮助将设备在工作和个人使用环境之间分隔开，允许在设备上运行工作容器或个人容器，而不会混合数据和访问权限。

### 移动设备管理

移动设备可能难以管理，特别是由于操作系统限制、硬件制造商之间的差异、运营商设置和操作系统版本。许多移动设备旨在供个人使用，没有更多面向业务的设备和软件通常拥有的广泛内置控制。当你加上各种各样的设备部署模型时，安全从业者在日益以移动设备为中心的环境中面临真正的挑战。

因此，当管理员和安全专业人员需要管理移动设备时，他们经常求助于 `mobile device management (MDM)`（移动设备管理）或 `unified endpoint management (UEM)`（统一端点管理）工具。`MDM` 工具专门针对 Android 和 iOS 手机、平板电脑和其他类似系统等设备。`UEM` 工具将移动设备、台式机和笔记本电脑以及许多其他类型的设备结合在一个管理平台中。

第三类工具称为 `mobile application management (MAM)`（移动应用程序管理）工具，专门关注部署到移动设备上的应用程序。常见功能包括应用程序交付、配置、更新和版本管理、性能监控和分析、日志记录和数据收集，以及与用户和身份验证相关的各种控制。尽管一些组织在使用 `MAM` 产品，但随着功能更全面的 `MDM` 和 `UEM` 工具接管市场以提供对移动设备的更多控制，它们变得不那么常见。

无论你选择哪种类型的工具，你的组织都可以使用许多功能来确保移动设备及其包含的数据安全。虽然以下列表不是 `MDM`、`UEM` 和 `MAM` 工具中每个可用功能的完整列表，但你需要了解它们每一个，以及为什么你可能想要拥有它，以便为考试做好准备。

#### 关键 MDM/UEM/MAM 功能

##### 应用程序管理

应用程序管理功能对于允许企业控制应用程序非常重要。这些功能可能包括将特定应用程序部署到所有设备；限制可安装的应用程序；远程添加、删除或更改应用程序及其设置；或监控应用程序使用情况。

##### 内容管理

内容管理（有时称为 `MCM`，即移动内容管理）确保对组织文件（包括移动设备上的文档和媒体）的安全访问和控制。移动设备部署的一个主要关注点是组织数据和个人数据在 `BYOD` 和共享使用设备上的混合。内容管理功能将业务数据锁定在受控空间中，然后帮助管理对该数据的访问。在许多情况下，这需要使用 `MDM` 在移动设备上的应用程序来访问和使用数据。

##### 远程擦除功能

当设备丢失或被盗，或所有者不再受雇于组织时，会使用远程擦除功能。了解完全设备擦除与只能擦除部署到设备上的组织数据和应用程序的擦除工具之间的区别很重要。在个人拥有设备的环境中，如果使用远程擦除并擦除了设备，可能会产生责任和其他问题。同时，带有确认流程（让你在成功时知道）的远程擦除是帮助保护组织数据的重要组成部分。

##### 地理定位和地理围栏

地理定位和地理围栏功能允许你利用手机的位置来决定其操作。一些组织可能只允许企业平板电脑在企业设施内使用，以减少在其建筑物外被盗或数据访问的可能性。其他组织可能希望设备在离开已知区域时自行擦除。除了我们在日常生活中习惯的地图和类似工具的许多地理定位用途外，地理定位还可以帮助定位丢失的设备。

##### 屏幕锁、密码和 PIN 码

屏幕锁、密码和 PIN 码都是防止未经授权访问的正常设备安全模型的一部分。屏幕锁定时间设置是基本移动设备安全中最常设置的安全选项之一。就像台式机和笔记本电脑一样，移动设备管理工具还设置密码长度、复杂度以及密码或 PIN 码必须更改的频率等内容。

##### 生物识别

生物识别技术在现代设备上广泛可用，指纹和面部识别是最广泛采用和部署的。生物识别可以集成到移动设备管理功能中，以便你可以为特定设备部署用户的生物识别认证，并利用生物识别因素实现额外的安全性或易用性。

#### 上下文感知身份验证

上下文感知身份验证超越了 PIN 码、密码和生物识别技术，以更好地反映用户行为。上下文可能包括位置、使用时间以及其他各种行为要素，这些要素可以决定用户是否应该能够登录。

#### 容器化

容器化是处理设备上工作与个人使用场景分离的日益普遍的解决方案。使用安全容器来运行应用程序、存储数据，并以其他方式保持设备使用的独立性，可大大降低交叉污染和暴露的风险。在许多 MDM 模型中，应用程序使用封装器来运行，有助于保持它们的独立性和安全性。在其他模型中，则会根据需要运行完整的容器化环境。

#### 存储分段

存储分段也可用于将个人数据和业务数据分开。这可能是单独的卷，甚至是需要特定应用程序、封装器或容器才能访问的单独加密卷。事实上，存储分段和容器化或封装技术通常结合使用，以更好地实现应用程序和分离。

#### 全设备加密 (FDE)

全设备加密 (FDE) 仍然是确保被盗或丢失的设备不会导致数据泄露的最佳方式。当与远程擦除功能和强身份验证要求相结合时，FDE 可以提供设备抵抗数据盗窃的最大可能性。

#### 推送通知

推送通知在这里似乎是个奇怪的入选项，但向设备发送消息在许多场景中都很有用。您可能需要提醒用户注意某个问题，或要求他们执行某项操作。或者您可能想与捡到丢失设备的人沟通，或告诉小偷该设备正在被追踪！因此，从中心位置发送消息的能力可以成为 MDM 或 UEM 系统中的一个有用工具。

#### MDM 和 UEM 控制

MDM 和 UEM 工具还为用户行为提供了一套丰富的控制。它们可以启用封闭或受管的第三方应用商店，或限制用户从操作系统或您部署的设备原生应用商店下载和使用的内容。它们还可以监控固件更新和版本，包括固件空中下载 (OTA) 更新是否已应用，以确保打补丁工作的发生。

当然，用户可能会尝试通过为其设备获取 Root 权限或越狱来绕过这些控件，以便旁路加载（从 microSD 卡手动安装或通过 USB 线缆安装）程序，甚至安装自定义固件。MDM 和 UEM 工具将通过检查已知良好的固件和软件来检测这些活动，并且它们可以对设备上安装的应用程序应用允许列表或阻止列表。

#### 服务和功能控制

控制可以使用哪些服务和设备功能，甚至可以在哪里使用它们，也是许多组织依赖的一项功能。限制或禁止使用摄像头和麦克风以及 SMS、MMS 和富通信服务 (RCS) 消息，有助于防止安全区域的数据泄露。限制外部媒体和 USB On-The-Go (OTG) 功能的使用（该功能允许设备充当 USB 外部设备（如相机或存储设备）的主机）也有助于限制设备被滥用的可能性。MDM 和 UEM 工具通常还允许管理员控制照片和其他可能嵌入有关拍摄或创建位置的 GPS 数据的文档的 GPS 标记功能。使用位置数据的能力可以是一个有用的隐私控制，也可能是组织文档流程的一部分要求。

#### 无线连接控制

管理员可能还想控制设备如何使用其无线连接。这可以采取限制设备可以连接到哪些 Wi-Fi 网络、阻止它们形成或加入自组无线网络，以及禁用网络共享和成为无线热点的能力的形式。蓝牙和 NFC 控制也有助于防止设备以不符合组织安全模型的方式被使用，例如用作支付方式或访问设备。

#### 运营商解锁

Security+ 考试大纲中列出的执行和监控的最后一项是运营商解锁。`Carrier unlocking` 允许手机与其他蜂窝网络提供商一起使用。监控设备的运营商解锁状态不是常见的 MDM 功能，通常在运营商层面处理。

### 专用移动设备安全工具

保护移动设备还涉及操作系统和硬件安全。Security+ 考试列出了两种特定的安全技术，它们是移动设备安全功能的具体示例。

#### microSD 硬件安全模块 (HSM)

第一种是 microSD 硬件安全模块 (HSM)。就像本书其他地方讨论的硬件安全模块一样，microSD HSM 是一种采用极小外形规格的硬件密钥管理和公钥基础设施 (PKI) 工具。事实上，此类 HSM 不仅以 microSD 卡的形式提供，还以 USB、SIM 和其他外形规格提供。

与其他 HSM 一样，这些设备提供密钥创建、备份和恢复以及管理服务，并支持公钥身份验证和其他加密工具。当然，这些设备本身并无用处，需要配合应用程序使用。

#### SEAndroid

考试涉及的第二种特定技术是 SEAndroid。SEAndroid 是适用于 Android 设备的安全增强型 Linux 版本。SEAndroid 提供了在 Android 设备上强制实施强制访问控制的能力。这意味着所有类型的 Android 进程都可以得到更好的隔离，从而限制漏洞利用，并有助于保护系统服务、系统和应用程序数据以及日志。

像许多安全系统一样，任何未明确允许的操作都会被拒绝——这是一种默认拒绝系统。SEAndroid 在强制模式下运行，该模式会记录发生的任何权限拒绝事件，并强制执行它们。SEAndroid 允许在 Android 设备上实施广泛的策略。

## 摘要

### 无线网络安全

构建安全网络始于了解组织可能选择部署的无线连接选项。虽然 Wi-Fi、蜂窝网络和蓝牙几乎无处不在，但其他技术如 RFID、红外和 NFC 也内置在设备和系统中。这些技术可以构建成点对点或点对多点网络，了解哪些技术在发挥作用以及它们如何连接设备，是设计网络的第一步。

一旦知道需要保护哪种无线技术，您必须了解针对无线技术和协议的常见攻击，以及针对网络的特定常见攻击。非法接入点、邪恶双生和解关联攻击是攻击 Wi-Fi 网络的方法，蓝牙窃取和蓝牙骚扰针对蓝牙。干扰攻击，或向网络发送大量流量使其无法通过，可针对大多数射频甚至红外网络实施。

考虑到技术和攻击，接下来进行网络设计，包括使用现场勘测来了解网络将要部署的环境。热力图显示信号传播，有助于设备放置。如何保护控制器和接入点也很重要，关注点范围从补丁和维护到通过受保护的通道或网络进行安全远程访问。

网络设计完成后，安全性和身份验证选项是设计的下一层。WPA2 和 WPA3 提供加密功能和部署模型，允许用户使用预共享密钥 (WPA2-PSK) 或唯一密码，以及连接到 RADIUS 服务器以允许使用组织凭据的企业模型。EAP 及其众多变体允许根据硬件支持和特定的身份验证需求进行选择。

### 移动设备安全

最后，必须保障移动设备的安全。部署模式范围从允许用户自带设备的 BYOD 流程，到完全由企业拥有的模式，后者将为特定目的锁定的设备部署到最终用户手中。设备还需要被管理，这正是移动设备管理工具发挥作用的地方。它们提供广泛的功能，作为安全专业人员，你需要了解这些功能。

## 考试要点

**现代企业依赖多种类型的无线连接。** 组织和个人有许多无线连接选项。设备可能通过蜂窝网络连接，这将网络控制权交给了蜂窝提供商。`Wi-Fi` 广泛用于以高速将设备连接到组织网络，在提供企业安全协议的安全性的同时，允许轻松移动。`NFC` 和 `RFID` 提供短距离、相对低带宽的数据交换，用于支付、ID 卡和库存标签等许多其他用途。红外线虽然在某些领域仍在使用，但由于其视线要求和在许多情况下的带宽限制，不太流行。

**针对无线网络的常见攻击利用协议和人为行为中的漏洞。** 邪恶双生伪装成合法网络，而流氓接入点是连接在您网络内部的设备，允许攻击者绕过您的安全边界。`Bluejacking` 向 `Bluetooth` 设备发送未经请求的消息，而 `bluesnarfing` 侧重于窃取联系人和其他数据。针对 `Wi-Fi` 的协议攻击可能导致取消关联，导致系统重新连接，并允许攻击者捕获有用数据或欺骗用户或系统连接到邪恶双生。`Jamming` 攻击用噪声或不需要的信号淹没网络，导致中断或断开连接。

**安全的无线网络设计考虑现有网络和物理空间。** 现场勘测包括使用工具对设施进行实地巡查，这些工具可以识别现有的无线网络和接入点以及信号强度和其他有助于绘制位置的详细信息。网络设计考虑信道间距、接入点放置，甚至在放置接入点时考虑建筑物的构成。

**加密和认证协议提供无线安全。** 现代 `Wi-Fi` 网络中同时使用 `WPA2` 和 `WPA3`。这些协议提供简单的认证模型（如 `WPA2` 的预共享密钥模式）和依赖 `RADIUS` 服务器使用组织凭据提供用户登录的企业认证模型。设备经常被配置为使用可扩展认证协议（`EAP`）的一种变体，该变体支持组织的安全需求，并受部署的无线设备支持。

**保护底层无线基础设施需要强大的网络设备管理和安全实践。** 除了这些协议之外，控制器和接入点必须受到保护。与其他网络设备一样，控制器和 `AP` 需要定期打补丁和更新，并必须安全配置。它们还必须具有受保护的管理接口，并应配置为记录和报告网络、其自身状态以及安全问题或潜在问题。

**管理移动设备依赖部署方法和管理工具。** 部署方法包括自带设备（`BYOD`）；自选设备（`CYOD`）；企业拥有、个人启用（`COPE`）；和企业拥有（`COBO`）。组织在选择部署模型时，需要评估每种方法的风险和收益。一旦做出决定，可以使用移动设备管理（`MDM`）或统一端点管理（`UEM`）工具以多种方式配置、保护、管理和控制设备，从部署应用程序到在设备丢失或被盗时安全擦除设备。您需要了解 `MDM` 和 `UEM` 产品的功能和局限性，以及它们可以管理的设备和操作系统。
