
LSTM 包含独特的记忆单元结构以及门控，这些门控将输入特征转换为数据中序列模式建模的参数。更具体地说，它们利用三个计算门控——输入门、遗忘门和输出门，每个在缓解 RNN 潜在问题（如梯度消失）方面都有不同的用途 (Feng et al., 2024)。LSTM 在患者结局的短期和长期预测，以及理解医疗数据中的时间趋势方面已特别显示出鼓舞前景的结果，它们仍然是医疗保健交付和公共卫生领域待探索的关键架构。值得注意的是，LSTM 在基于 EHR 的分析中的成功应用需要对模型超参数进行仔细的训练和调整，包括隐藏单元或记忆单元的数量、学习率和序列长度，以及架构配置，如正则化技术、网络层数和参数 (Ashfaq et al., 2019)。

## 1.5 EHR 数据预处理

EHR 包含了在就诊和治疗期间获得的患者健康状况信息。在深度学习模型直接应用于 EHR 数据之前，需要进行数据可视化和预处理，以确保分析的完整模型更好的性能。数据可视化和预处理提高了数据质量，并使数据更适用于分析。EHR 最必要的预处理步骤之一是归一化或标准化，这些都是实值变换。

### 1.5.1 数据清洗

为了确保深度学习模型在分析 EHR 数据时的正常性能，必须对数据的临床和财务方面进行验证。机器学习模型构建的第一关键步骤是数据清洗，研究人员已建立数据提取、转换和加载作为适当的数据清洗步骤。

深度学习的成功取决于数据质量；如果数据包含错误，最终结果将是不准确的 (Landi et al., 2020)。数据准备的核心原则如下：准确性、未编码值和缺失值。准确性涉及记录匹配和去重，解决并找到冗余或引用同一原始数据实体的记录。数据清洁的另一个关键因素是未编码值。数据可能缺少特定值的代码，且值只能以非结构化的格式存在 (Ashfaq et al., 2019; Shickel et al., 2018)。数据清洗能够使数据结构化。最后，缺失值对于解码 EHR 数据也是重要的；应用领域知识可以解决这个问题。简而言之，数据提取、转换和加载是影响深度学习结果的严谨数据清洗过程。良好的数据可以创建支持决策的信息 (Guo et al., 2021)。

### 1.5.2 EHR 特征工程

研究人员分析了心脏患者的处方记录，以预测谁需要手术，谁可以继续药物。他们检查了对临床指南的遵循情况。通过关联算法发现了常见的药物子序列。然后他们使用两种模型将患者疾病状态视为马尔可夫模型，计算疾病进展或恶化的概率。他们还考虑了药物剂量、发药期、时长和依从性，以构建预测疾病状态的特征 (Guo et al., 2020)。

其他研究人员提取了具有 WHO 解化学代码的药物信息。他们使用 Cox 比例风险模型通过关联规则特征选择来描述疾病状态。随后，他们比较了支持向量机、lasso、分类回归树和朴素贝叶在预测疾病状态方面的性能 (Gong et al., 2021)。

这一步骤有几个原因。首先，EHR 特征在时间、单位和值范围上可能不同，导致重要特征被忽略。其次，这些值的实际范围和尺度影响深度学习训练算法的有效性。我刚才讨论的数据清洗涉及修正由错误输入和缺失值产生的异常值。当预处理后的 EHR 数据不符合分析需求时，所用学习模型的效率就会降低 (Guo et al., 2021; Si et al., 2021)。深度学习算法对输入值非常敏感，这种敏感性对于不平衡的 EHR 数据来说并不理想。此外，预处理步骤如归一化和标准化有时会与深度学习模型产生冲突。一项研究中的研究人员专注于针对特定数据类型或目标定制的预处理技术。数据结构和选定的预处理方法决定了哪种预处理方法更合适。数据处理的需求源于 EHR 数据分析中的需求、理论框架和实验过程 (Chintala, 2024)。

数据归一化和标准化是使用深度学习（DL）模型进行电子健康记录（EHR）数据分析预处理中的两种常用步骤。然而，这些技术通常被交叉使用。归一化是将数据缩放到 0 到 1 之间特定范围的过程，当参数具有可比性并且可以通过缩放到相同的初始范围进行修改时，通常首选这种方法；在某些情况下，归一化可以转换为标准化。相反，标准化是将数据转换为均值为 0 且结果数据方差为 1 的过程，对于减少学习过程中的偏差非常有效。深度学习模型的输入数据应经过缩放，使其具有相同的格式，以便深度学习模型高效收敛 (Mohsen et al., 2022)。

关于何时对数据集使用归一化或标准化并没有固定的规则。对于用于深度特征表示诊断疾病的医疗数据，在将其输入深度学习模型之前进行归一化通常是良好的做法，以确保最佳性能。在某些模型中，标准化可以带来更低的验证损失和更快的收敛 (Feng et al., 2024)。此外，标准化在减少模型训练所需的迭代次数方面表现出色，也能实现快速收敛。

## 1.6 模型评估与可解释性

### 1.6.1 模型评估

必须开发并使用适当的性能指标来评估模型做出准确预测的能力。模型评估通常采用各种指标，如准确率、灵敏度或召回率、特异性和 AUC（受试者工作曲线下的面积），用于评估模型在给定测试值对灵敏度与 1-特异性（假阳性率）之间寻找最佳平衡的性能。AUC 是诊断工具性能最重要的参数指标；AUC 大于 0.7 的模型被认为具有预测性。其他性能指标包括精确率、F1 分数、阳性和阴性预测值以及精确率-召回率曲线。混淆矩阵（也称为点命中图）总结了某一标准的真阳性率与真阴性率，或真阳性率与假阳性率之间的矩阵 (Chintala, 2024; Goldstein et al., 2024)。

当通过此类分类错误或混淆矩阵衡量模型的预测或分类性能时，可以根据不同的截点推导出灵敏度、特异性、错误率和准确率等性能指标。通过这种方式，可以评估模型的全局性能，而不受任何特定阈值或截止值的限制；小数据集上通过标准训练策略拟合的模型很容易过拟合。交叉验证通常用于稳健的模型评估和比较。例如，对一组 `N` 个点进行 `k × m` 交叉验证涉及将集合分成 `k` 个互斥且大小相等的块，每个块标记为 `Si`，并重新进行 `m` 次模型调优和拟合。可以根据评估、确认和验证的结果，基于其广泛聚合的性能得出关于模型的综合结论 (Mohsen et al., 2022; Negro-Calduch et al., 2021)。从系统的角度来看，评估模型在特定类别上的性能也具有意义。

### 1.6.2 可解释性

解释深度学习模型仍然具有挑战性。这些技术许多的设计是为了优化模型或从神经激活中获得更多见解。层激活可以识别感兴趣的特征；这种分析在计算机视觉中是可能的。然而，在临床叙述中，只有句子或纯时间戳可用，可以建立基于规则的关系。在分析训练的输入时，某些回归方法估算了 (Si et al., 2021) 的行为。

使用不同的方法和指标提供了模型性能的通用估计。但这种专家解释至关重要，因为在医疗保健领域，关乎生命。生成知识的透明度促进了相互的理解和接受。医疗保健中的此类解释有助于建立对预测模型的信任。模型评估仅反映宏观属性 (Guo et al., 2021)。总之，用于生存分析的神经网络与传统的统计方法相比显示出潜在优势。

### 1.6.3 EHR 数据分析模型的性能指标

对于用于 EHR 数据分析的深度学习模型，选择合适的性能指标是必要的。在本节中，我将详细阐述有助于模型评估的关键指标，并考虑到提供临床结果见解的常用指标。这些指标的改进表明模型层面存在有益的优化。我将进一步讨论召回率和 F1 分数，在数据不平衡时（患者特定模型中常见的情况），这两者是衡量临床有效性的关键标准。性能指标的选择提供了与医学背景一致的解释。除了性能指标外，模型还应与合适的范式进行比较，以衡量其成功 (Guo et al., 2020)。

## 1.7 EHR 数据分析中的伦理与隐私考量

健康数据特别敏感，严格的关于隐私和安全的伦理考量应约束其分析和使用。知情同意一直是收集人类数据的一个长期伦理原则，而数据所有权是一个相关的法律问题。这些原则必须得到适当处理。

在使用回顾性电子健康记录（EHR）数据时，必须确保患者提供了知情同意、数据经过匿名化处理，或者获得了批准。患者组织、专业学会和个人研究人员已经建立了数据管理的最佳实践指南，以减轻对患者的伤害（Hossain et al., 2023）。不出所料的是，要联系患者并请求知情同意几乎是不可能的，因此几乎所有的临床信息学研究都使用了去标识化或匿名化的数据。维护隐私和安全还扩展到临床丰富数据集的发布，这些数据集可能很容易关联回个人。另一个加入辩论的伦理问题是，当数据被链接并用于二次目的时，如何才能确保并维护数据的机密性。此外还有一个更广泛的问题，患者是否应该在签署知情同意后放弃对其数据使用的任何权利（Ashfaq et al., 2019）。

深度学习（DL）模型必须限制偏差，并在不同的患者群体中提供相同的性能，以改善所有人的整体健康状况。同样，为了不同目的整合和使用 EHR 数据（特别是用于 DL 模型的开发）必须符合相关法规。在未获得必要批准的情况下共享数据，可能会导致新计划的被阻止，以及其他研究人员失去访问 EHR 数据的权限。采集和存储敏感信息的人需要验证信息安全实践，并确保他们已尽一切努力防止未经授权的访问（Goldstein et al., 2024）。

身份盗用可能导致严重后果，包括导致患者放弃治疗，这可能对其健康造成严重损害。鉴于大量的安全漏洞案例，越来越多的隐私倡导者强调数据隐私措施需要透明度和问责制。差分隐私和合成数据等技术旨在展示给定数据集的真实隐私程度，并为攻击者访问数据集设定上限（Negro-Calduch et al., 2021）。最重要的是，伦理和法律考虑必须为医疗健康分析的创新提供框架，因为没有了信任和诚信，利益相关者之间的合作将面临风险。

### 1.7.1 EHR 与患者隐私

为了实现医疗保健领域内及以外电子健康信息的交换，必须满足综合监管要求，包括信息规范和保护。这涉及遵循最小数据集和标准医疗计费代码。虽然用户认证至关重要，但如果法律未涵盖，患者信息的隐私和机密性也必须符合机构要求。因此，为了有效利用 DL 系统处理医疗健康任务，EHR 数据的处理必须符合相关的联邦法规（Si et al., 2021）。对于在资助项目相关的特定部门或组织单位之外共享或传输的个人健康信息（PHI），进行加密至关重要；使用强密码和单登录以消除对密码文件的需求；并每年为出版管理团队的所有成员更改密码。在项研究中，很大比例的患者对其医疗记录的隐私和完整性非常担心，许多人希望在数据被存储和使用之前给予同意（Hossain et al., 2023）。

EHR 数据现在在广泛的网络中定期共享并访问，因此确保这些数据的隐私和安全尤为重要。例如，医生和其他医疗保健人员越来越多地被从仅仅提供护理转变为对该护理进行计费；因为医疗服务是根据所提供服务的医疗代码进行报销的，EHR 越来越多地被链接到医疗编码应用程序。考虑到这些因素，EHR 数据分析必须严格遵守联邦法规。需要注意的是，数据隐私法目前处于变动状态。已经提出了某些草案形式的变更，一旦实施，将改变现有法规的定义和范围（Ashfaq et al., 2019）。然而，在本文写作时，这些尚未提交美国国会或获得批准。

医疗保健提供者还必须提供隐私和安全的培训，包括定义行政、研究和认证目的接受使用策略。各种 EHR 数据分析任务具有潜在利益，包括改善患者护理和机构成本。护理或研究环境中的所有参与者都有责任遵守最佳实践和法律。法规规定了基本规则和所需的最小保护，以支持各种医疗健康任务（Shickel et al., 2018）。

- 随着深度学习在医疗健康领域变得普遍，与 EHR 数据相关的计算和数据资源将会增加。对潜在数据分析任务和高性能计算资源感兴趣的雇主必须确保他们意识到任何医疗欺诈和信任损失都可能导致法律行动。数据科学家接受有关隐私的相关法规额外培训（Mohsen et al., 2022）。

### 1.7.2 患者隐私与数据安全

用于 EHR 数据的 DL 模型必须遵循相关的隐私和安全指南及法律。某些措施包括通过删除或掩盖用于研究的 EHR 数据去标识化、向记录添加噪声以及应用加密方法来实现隐私与效用之间的平衡。其他方法包括差分隐私、安全多方计算、同态加密和安全执行环境（Negro-Calduch et al., 2021）。

此外，允许将数据安全机制定义并动态绑定到应用程序的框架将使执行特殊数据用例变得更容易，因为组织可以在不同的数据处理过程中实施不同的安全策略。这些安全机制应包括传输中加密、使用中保护、访问控制和安全监控。基于异常的入侵检测和机器学习驱动的关联系统可帮助定位安全违规的源，并建立数据分析监控工具以方便数据质量测试、合规性和审计访问。尽管 EHR 数据包含患者敏感信息，但隐私和安全措施不应阻止组织内部及组织之间的 EHR 数据交换（Alaboud et al., 2023）。这些措施有助于建立对交换的信任，提高其可用性，限制有害风险并识别信息交换的影响。

### 1.7.3 EHR 数据分析中的偏差与公平性

评估模型公平性并避免种族、性别和其他敏感属性的偏见，需要仔细的数据预处理、模型训练和公平性评估。在数据预处理阶段，一个基本问题是记录中存在缺失，这可能是由数据收集决策导致的。直接删除与种族或性别相关的特征会导致模型评估偏差，甚至对代表性的群体产生歧视。保护患者并确保模型公平性的方法之一是为患者提供机会控制，让他们自行匿名化记录，从而控制向第三方发布数据（Chintala, 2024; Hossain et al., 2023）。

将患者生成的隐私整合到 DL 模型架构中，带来了处理比现实数据更松散特征结构的技术挑战。DL 模型即使面对经过患者操纵的特征，也应该经过充分信息的设计以实现良好的预测。具体而言，公平性感知模型可能需要额外的输入，例如与人口统计无关的子特征空间，以确保患者的人口统计特征不被模型学习或使用（Goldstein et al., 2024）。

## 1.8 DL 在 EHR 领域的未来方向和新兴趋势

多年来，医疗保健领域技术的使用一直在快速演进。随着医疗提供者对技术的依赖日益增加，全球 AI 驱动的健康市场正经历显著增长。DL 技术正被不遗力地探索在 EHR 中的应用，以优化患者护理管理。当与预测分析结合使用时，DL 为个性化医疗开启了大门。随着治疗时间、药物相关成本、死亡率和并发症的减少，患者的生活质量将得到极大提高。在数据利用方面，持续学习模型可以提供 EHR 数据的实时利用。

### 1.8.1 复杂医疗数据中的 DL

尽管存在疑虑，医疗保健系统的利益相关者正关注 DL 在 EHR 方面的潜在应用。每个领域都有自己的挑战。目前，还没有透明的算法能够解释来自复杂医疗数据的 DL 预测。医疗系统与技术公司之间的合作正在形成，以开发能够利用 EHR 数据预测并改善患者结果的 DL 模型（Negro-Calduch et al., 2021）。

虽然 DL 应用目前正在解决各种临床挑战，但研究人员正在探索其他多种新兴领域。例如，可穿戴技术已用于急诊部门评估阿片类使用障碍，以及用于重监护室准备时间的新型预测模型，这部分由于 EHR 数据在研究和患者护理实践中的利用呈现象级增长。DL 模型的另一个相关用途是分析中风研究中临床试验患者选择的动态（Alaboud et al., 2023）。

### 1.8.2 医疗保健中的联邦学习

最近，一种新型隐私增强型机器学习范式——联邦学习应运而生，能够在去中心化的数据源上训练机器学习模型。每个机构都使用其本地数据训练模型，然后对模型进行聚合以获得全局模型，并将其共享给每个参与者。联邦学习允许在保留 EHR 模型隐私性的同时，仍保留研究患者数据的能力，因为每个数据源对其自己的数据保留控制权，且数据从未进行集中汇总。这允许在不跨不同实体共享敏感健康信息的情况下，从外部训练机器学习模型（Negro-Calduch et al., 2021）。

人们对在 EHR 数据分析中使用联邦学习的兴趣日益增加，广泛应用包括分析医疗工作人员的接种率、利用 DL 医学图像评估伤性脑损伤的严重程度、针对血肿患者的预测模式以及识别早期阿尔茨海默症的临床和分子通路。在这种模型中，个人数据留在隐私墙后，而不会发送到中央服务器。相反，算法根据数据做出个体预测，然后对这些预测进行聚合或组合成全局模型（Goldstein et al., 2024; Guo et al., 2021）。通过这种方式，个人信息永远离开其设备。在医院预测医学的情况下，用户变成了医院，且数据保持隐私。

实际应用包括 `TensorFlow`，该工具可用于怀孕研究，允许西班牙和意大利中心之间进行训练而不交换患者数据。结果是联邦学习使得能够在无法在其他训练的项目上进行大规模训练（Chintala, 2024）。联邦学习减少了合作项目和可行性研究中专家之间接触的需要。它允许全球专家利用不同医院的数据协作寻找解决方案；这种方法还支持模型向临床应用的转化。最初，在国际队列上训练模型可以利用多样化的经验，以适应当地需求（如英国的需求），而无需解决国际患者数据的伦理问题。与技术问题有关，研究人员确定了机器学习在医疗保健中的潜在益处，以及在医疗保健领域实施联邦学习的伦理和监管框架（Si et al., 2021）。

医疗保健领域的联邦学习确保数据保持本地化并在维护知情同意的同时利用全局模型的聚合知识。这种方法支持开发治疗慢性或罕见疾病的系统，从模型设计到临床试验或干预都遵循伦理和合规原则。法国的一个临床神经病和风湿病联邦学习框架已取得进展，旨在根据大量 EHR 诊断患者，但尚未从技术可行性阶段移动到运营部署。

在过去的十年中，尽管深度学习取得了巨大进展，但医疗健康领域在模型可靠性和适应性方面仍面临着特殊挑战。这些挑战主要源于临床环境中对模型决策可解释性的需求。从业人员通常面临着监管或机构的压力，必须确保模型做出的每项决策都具有临床意义且理由充分。此外，医疗保健中预测方法的采用取决于非专业人士能够多容易地理解、验证并对模型预测提供反馈 (Guo et al., 2021)。

到目前为止，深度学习在多种临床预测问题上的准确性上领先，包括图像分析、时间序列预测和患者结局预测。然而，其在检测过程中缺乏可解释性是医疗领域的一个根本性问题。基于数千个特征的患者分层和预估结果使得人们难以理解这些结果与患者可以管理的内容之间的关系。模型的行为是不透明的，而且由于 `EHR` 数据涉及多个任务，制定关于模型如何在任务之间切换的规则可能是具有挑战性的，甚至是不可能的 (Afshar et al., 2023)。由于泛化和领域迁移的局限性，在无法监测罕见但关键的患者亚群体预测行为的情况下，很难知道一个视觉主导的模型在这些患者结局的独特方面表现如何。
