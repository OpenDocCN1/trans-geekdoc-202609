
在 BERT ([43]) 中，同样使用单个 transformer block 栈。然而，与 GPT 不同，其 block 结构类似于 19.3.3 节中完整 encoder-decoder transformer 的 encoder block。即，在 block 的相应层中采用（完整的）self-attention。这显然使 BERT 模型成为 *bidirectional*，每个 token 同时关注过去和未来的 token。例如，在将微调应用于 token 级任务（如问答）时，这很有益处，因为必须结合两个方向的上下文，参见 [43]。

本节旨在阐述 BERT 背后的总体原理，更详细的描述可参考相关文献。图 19.15 显示了一个简化框图，聚焦于输入输出变量。BERT 的内部结构由若干类似于图 19.10 中 encoder block 的 block 组成。

![Figure 19.15 The first input token is the special classification token, 〈CLS〉, and the corresponding output is denoted as c. For some applications, more than two sentences are used, e.g., sentence A and sentence B, separated by the special token 〈SEP〉.](img/gr015.jpg)

Figure 19.15 第一个输入 token 是特殊分类 token 〈CLS〉，对应的输出记为 `c`。某些应用使用两个以上句子，例如句子 A 和句子 B，由特殊 token 〈SEP〉 分隔。

然而，BERT 引入了一些新特性。具体而言：

*   引入特殊分类 token ⟨CLS⟩，添加在每个输入 token 序列的开头；见图 19.15。对应该特殊 token 的最终状态/嵌入/表示向量（即最后一个 block 的输出），在图 19.15 中记为 `c`，用作分类任务中整个序列的 *aggregate class* 表示。

### BERT 的特殊标记与嵌入

*   BERT 还使用另一个特殊标记 `⟨SEP⟩` 来分隔输入序列的各个部分。对于某些应用，输入由一对句子组成，例如在问答任务中。在图 19.15 中，一个句子（记为“A”）包含 *N* 个标记，`x[n]^(A)`，`n = 1, 2…, N`。另一个句子（记为“B”）包含 *M* 个标记，`x[m]^(B)`，`m = 1, 2…, M`。注意 `x[n]^(A)` 和 `x[m]^(B)` 是作为网络输入呈现的嵌入向量。

*   在 BERT 中，除了词汇嵌入和位置嵌入外，还使用第三种嵌入来提供句子信息。这种嵌入也是在预训练期间学习的。因此，在 BERT 中，句子相关信息由以下两部分提供：a) `⟨SEP⟩` 符号，用于分隔两个句子；b) 句子嵌入。因此，对于每个标记，最终的输入嵌入是三个项的求和结果，这与包含两项的公式 (19.30) 形成对比。句子嵌入向量对于句子“A”（或“B”）中的所有标记都是相同的，即 `s[A]`（`s[B]`）。

### 19.5.1 预训练

回顾第 19.3.10 节，在预训练期间，解码器的目标是给定当前和之前的标记来预测序列中的下一个词。之所以使用预测，是因为对于特定位置而言，所有未来的标记都被*掩码*了。然而，在 BERT 中，整个序列是同时可用的，且注意力分数涉及所有过去和未来的位置。为了克服这个问题，BERT 采用了一种非常古老的技术，称为*完形填空任务*；参见 [179]。随机选择一些输入标记并将其掩码，例如，它们被特殊标记 `⟨MASK⟩` 替换。训练的目标变为*预测*原始词汇表中（独热表示）对应于被掩码嵌入的真实词汇*仅限于被掩码位置*。借用图 19.9 中用于解码器的理念，最后一个块的输出向量（对应于被掩码的输入嵌入）通过一个额外的网络，该网络包含一个线性变换，后接 softmax 非线性激活。因此，对应于被掩码词的输出被转换为 *l* 维（词汇表大小）的概率向量，在训练期间它们被最优地“推向”预测对应原始词的 ID。损失函数的形成遵循与推导公式 (19.45) 类似的逻辑。因此，组成 BERT 的单个 Transformer 块堆栈同时充当编码器和解码器。通过随机掩码进行训练在第 19.6 节中进一步讨论。

除了掩码外，BERT 还采用另一种预训练途径，称为*下一句预测*（NSP）。正如 [43] 中指出的，许多 NLP 任务（如问答）基于理解两个句子之间的*关系*，这不容易通过预测性语言建模直接捕捉。为了促进关系学习，在*二分类*“下一句预测”任务的背景下，输出嵌入向量 `c` 被调用。为此，从语料库中提取的若干训练样本句子对（设为“A”和“B”）被提供给输入。在这些样本的 50% 中，句子“B”是下一句（标签 `ISNEXT` 或 1），其余 50% 中，句子“B”从语料库中随机选择（标签 `ISNOTNEXT` 或 0）。对于训练，`c` 首先被线性变换为二维向量，然后 softmax 非线性激活将两个元素中的每一个转换为概率。网络被训练以最优地解决这个二分类任务。

### 19.5.2 微调

在微调期间，最后一个（顶层）Transformer 块的输出向量被用作输入，馈送给一个用新参数集 `w` 描述的额外网络。在特定下游任务的框架内，通过*端到端*优化网络来进行训练，即相对于额外参数 `w` 以及定义 BERT Transformer 的参数 `θ` 进行优化。预训练期间学到的最优参数集（例如 `θ[*]`）被用作微调期间反向传播算法的相应初始估计值。注意在微调阶段输入标记不被掩码。

#### 微调中的 BERT 嵌入

在微调过程中，输出 BERT 嵌入的利用方式取决于相应任务的性质。例如，对于分类相关任务，如蕴含关系判断或情感分析，会使用输出 `c ∈ ℝ^(d_m)`。假设下游任务涉及 `K` 个类别，那么构建在 `c` 之上的额外网络由以下部分组成：

a) 一个变换矩阵，记为 `W ∈ ℝ^(K × d_m)`，它输出一个 `K` 维向量 (`Wc`)，随后是

b) 一个作用于该向量元素上的 softmax 非线性函数 (`Softmax(Wc)`)，将其转换为类别概率。

另一方面，对于问答任务，则利用对应于构成句子 "B" 的嵌入的输出向量。该任务的目标是从句子 "B" 中提取出特定部分，该部分极有可能是句子 "A" 所包含问题的答案。更多细节请参见 [43]。

### 19.5.3 Transformer：一些总结性评论

继 BERT 和 GPT 系列*大语言模型* (LLMs) 取得成功之后，出现了许多具有类似能力的模型和软件包（例如 [150]、[38]、[187]）。所有这些模型在广泛的应用中均表现出了“令人钦佩”的最先进性能，例如问答、翻译、单词重组、执行算术运算、基础推理、程序代码生成、文章学习，以及生成往往难以与“普通”人创作的散文区分开来的文本（例如 [147]、[90]、[94]）。

除了自然语言处理 (NLP)，Transformer 还被用于广泛的应用，包括但不限于计算机视觉（例如 [99]）、语音/音频处理与学习（例如 [109]）、生物学（例如 [64]）、音乐生成（例如 [205]）、医疗健康（例如 [113]）、天气预报（例如 [21]）以及人生事件预测（例如 [165]）。在所有这些领域，它们的应用相比之前的最先进技术均带来了显著的性能提升。它们强大的学习能力点燃了一股将此类机器学习模型应用于人类活动几乎所有方面的新浪潮，范围涵盖科学技术、服务业、工业，以及游戏、教育和人际网络。

一个有趣且重要的问题是理解并解释这些模型为何表现出如此令人印象深刻的学习和性能能力。这是一个正在进行且充满挑战的研究课题，仍有许多悬而未决的问题。关于在各种应用中应用 LLMs 的详细报告——指出了能力、局限性及可能的未来研究方向——可参见，例如 [28]。

另一方面，鉴于上述报告的能力，除了这些模型提供的优势外，它们还因恶意行为者的滥用而带来许多*社会和伦理*威胁。生成的文本可能会传播与性别、种族、宗教、政治观点和人类价值观相关的刻板印象和偏见。此外，此类模型可能产生包含错误信息的不可靠内容；换句话说，它们遭受“幻觉”困扰（参见，例如 [63]）。许多相关文章、声明和讨论——往往观点对立——由知名专家发表在新闻和社交媒体上，涉及潜在危险及可能的最小化威胁措施。此类措施可能源于技术本身，和/或通过监管相关平台使用的适当法律框架实现。世界知名专家对此类问题的观点总结可参见，例如 [175]。由两位顶尖 AI 专家汇编的有趣诗意观点见 [25]。

## 19.6 自监督学习

在前几节中，重点在于 Transformer，讨论围绕自然语言处理（NLP）任务展开。我们已经指出，在预训练阶段（也称为代理任务），通过使用无标签数据，Transformer 网络可以生成其输入的更新后的高效上下文表示。随后，预训练好的 Transformer 可用于监督学习框架，以应对各种专门任务，即下游任务。

预训练阶段的学习是通过下一个词预测或掩盖部分输入词嵌入来实现的。在后一种情况下，相关参数被优化以使网络预测被掩盖的词。这种通过无标签数据进行的训练类型也称为自监督学习，原因我们稍后将讨论。

现在提出的问题是，此类技术是否可用于文本以外的其他模态，例如图像、语音、音频、视频等。在 NLP 任务中，涉及的词嵌入/Token 是序列化且离散的。但在计算机视觉任务的图像或语音信号中，以及许多其他类型的信号模态中，情况并非如此。图像中的像素在连续区间取值，且非序列化。音频信号具有序列性质，但其幅度在连续区间内变化。

由于涉及数据模态的不同性质，多年来针对自监督学习开发了不同的技术，这些技术可能使用 Transformer，也可能不使用。在回顾此类学习任务的一些基本方向之前，让我们首先定义何为自监督。到目前为止，我们使用该术语的方式较为宽泛。

### 19.6.1 无监督学习与自监督学习的对比

代理任务期间的预训练是通过使用无标签数据执行的。本书迄今为止，将此类任务称为无监督学习，参见例如第 12.6 节。自监督学习在哪些方面与无监督任务不同，以至于“值得”一个不同的名称？正如我们在第 1 章中已讨论的，典型的无监督任务包括聚类、流形学习、概率分布学习。所有这些任务共同的目标是学习结构，例如潜在的隐含规律性和统计依赖关系。无监督任务的学习不同于监督学习。在后者中，对于`每个输入样本`都存在一个对应的`目标`值，训练目标是优化网络参数，使预测输出在某种意义上接近相应的目标。

在`自监督学习`（SSL）中，没有可用的标签数据，而是从可用的无标签样本中`构建`目标值。不同技术遵循不同路径来获取目标/标签。例如，回顾在 `BERT` 中，目标是真实词的独热向量编码，它们对应于输入序列中的被掩盖 Token。因此，可以将自监督学习视为一类介于监督学习和无监督学习之间的学习方法。

与监督学习相比，利用大量无标签数据进行训练的威力源于这样一个事实：SSL 提取可用数据的`通用表示`，这些表示随后可`跨许多任务`使用。这与试图专注于特定任务需求的监督学习形成对比。例如，文献 [138] 开展了一项研究，旨在将 SSL 与儿童通过通用学习机制（无实质性归纳偏置）获取基本视觉类别的方式联系起来。虽然在当前版本书籍编纂时，要完全掌握 SSL 背后的原理和原因还为时过早，但研究发现通过 SSL 学到的输入数据表示往往对对抗样本、标签损坏和输入扰动更具鲁棒性，例如文献 [75]、[62]。最后，请注意监督学习的一个主要缺点是需要标注数据，这是一个成本特别高的过程，尤其是在使用海量数据集时。

自监督学习在机器学习中并非新事物。我们的目的不是回顾多年来提出的所有技术和路径，而是专注于 SSL 的一些基本方向，这些方向在当前版本时似乎更受欢迎。近期关于 SSL 方法的相关综述见文献 [13]、[49]、[96]、[117] 等。

### 19.6.2 代理任务

自监督学习的第一阶段是代理任务，其目的是通过无标签样本训练一个`编码器`（预训练），以生成输入数据的信息丰富编码/表示。本节的目标是描述一个涵盖大多数建议方法的通用方案。当然，一如既往，可能存在偏离这一总体基本原理的特定方法，参见例如 备注 19.11。

任何自监督技术的主要部分是从无标签样本中`创建`输出目标/标签。我们通常将这些构建的目标称为`伪标签`。更正式地，假设输入包含一组 `N` 个无标签向量，$\mathcal{X} = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_N\}$。例如，在 NLP 任务中，这些可能是对应输入词序列的 `N` 个 Token 向量。在计算机视觉问题中，它们可能对应构成图像的 `N` 个矢量化连续补丁。在语音处理任务中，这些可能是对应语音信号分割后 `N` 个连续窗口中时间样本的向量。当输入数据作为单个实体单独处理时，例如每个样本是一个馈送多层感知机输入的单个向量，或一个馈送卷积网络输入的图像数组，则 $N = 1$，输入集 $\mathcal{X}$ 是一个单例集。因此，我们讨论的阶段涵盖了更一般的建模，其中编码器可以是 Transformer（$N > 1$）、卷积神经网络或全连接前馈网络。

代理任务的主要步骤是：

#### 1. 选择编码器（也称为骨干网络）

选择一个编码器（也称为骨干网络）将输入 `x[n]` 映射到一组相应的编码器输出向量 `h[n]`，即：

```
x[n] ↦ h[n] = fθ
```

请注意，编码器实现的等效（向量）映射函数是由一组参数 `θ` 来参数化的。输入向量在呈现给编码器之前，首先经历另一种变换，这是非常常见的。例如，回想一下在 BERT 中，部分输入标记会被掩码，这属于一种变换。因此，在更一般的设定下，我们可以写为：

```
x_n ⟼ x̃_n ⟼ h_n = f_θ(x̃_n), n = 1,2,...,N.
```

#### 2. 收集变换后的输入

将所有变换后的输入收集到一个集合 `X̃ = {x̃_1, x̃_2, ..., x̃_N}` 中，我们可以简洁地写为：

```
H = f_θ(X̃),
```

其中 `H = {h[1], h[2], ..., h[N]}`。该过程在图 19.16 的上支路中以示意图形式展示。
