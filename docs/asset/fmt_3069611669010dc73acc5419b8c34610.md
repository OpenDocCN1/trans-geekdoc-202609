# 术语表

## connectionless communication

一种通信形式，目标计算机在接收到信息时不会通知源计算机。这种通信被认为是不可靠的，因为没有通知指示数据已被接收。由于跟踪已发送数据和另一端已接收数据涉及的开销，无连接通信可能比面向连接的通信更快。

## connection-oriented communication

一种通信形式，通过使用序列号和确认号确保数据从发送方可靠地传送到接收方。消息中的每一段数据都被分配一个序列号，接收方使用该号码确认数据的接收。

一种错误检查形式，涉及将一个字节或一组字节通过数学算法运行，以产生一个位或字节来表示数据（即 CRC）。CRC 值随数据一起传输。当数据到达目的地时，接收方通过相同的数学算法运行它。结果与原始 CRC 进行比较，如果匹配，接收计算机假定数据是正确的。如果不匹配，接收方必须丢弃数据并重试。
