P{a_1} = (a_1 a_1^T / ||a_1||²) x,

让我们将前面报道的线性代数结果应用于公式 (5.61) 和 (5.62) 的 APA 情况，并将它们重写为

**θ**[n] = (I − X[n]^(T)(X[n]X[n]^(T))^(−1)X[n])**θ**[n − 1] + X[n]^(T)(X[n]X[n]^(T))^(−1)**y**[n].

右边的第一项是投影 `P[{x[n], …, x[n − q + 1]}]^⊥(θ[n − 1])`。这是最自然的。根据相应仿射集的定义，作为超平面的交集

**x**[n − i]^(T)**θ** − y[n − i] = 0, i = 0, …, q − 1.

![Equation](img/si294.png)

每个向量`x[n-i]`都与相应的超平面**正交**（图 5.13）（问题 5.11）。因此，将`θ[n-1]`投影到所有这些超平面的交集上，等价于投影到一个仿射集上，该仿射集与所有`x[n]`、…、`x[n-q+1]`**正交**。注意矩阵`X[n]^(T)(X[n]X[n]^(T))^(-1)X[n]`是将向量投影到由`x[n]`、…、`x[n-q+1]`张成的子空间上的投影矩阵。第二项考虑了我们投影其上的仿射集不包含原点，而是平移到了空间中的另一个点这一事实，其方向由`y[n]`决定。图 5.15 说明了 `l=2` 和 `q=1` 的情况。因为 `θ[n-1]` 不在直线（平面）`x[n]^(T)θ - y[n] = 0` 上，其方向由 `x[n]` 定义，从几何上可知（且易于验证）它到这条直线的距离为 $s = \frac{|\mathbf{x}\_{n}^{T}\mathbf{\theta}\_{n - 1} - y\_{n}|}{||\mathbf{x}\_{n}||}$。此外，`θ[n-1]` 位于直线的负侧，因此 `x[n]^(T)θ[n-1] - y[n] < 0`。因此，考虑到所涉及向量的方向，结果表明

##### 数学推导

$$

\Delta\mathbf{\theta} = \frac{y_{n} - \mathbf{x}_{n}^{T}\mathbf{\theta}_{n - 1}}{||\mathbf{x}_{n}||}\frac{\mathbf{x}_{n}}{||\mathbf{x}_{n}||}.

$$

![Equation](img/si306.png)

因此，对于这种特定情况，修正公式

$$

\mathbf{\theta}[n] = \mathbf{\theta}[n-1] + \Delta\mathbf{\theta}

$$

![Equation](img/si307.png)

与 APA 的递归公式一致。

### 5.6.1 归一化 LMS (NLMS)

NLMS 是 APA 在 $q=1$ 情况下的特例（参见 图 5.13）。由于其广泛应用，我们单独对其进行介绍，总结见 算法 5.3。

#### 算法 5.3：归一化 LMS

*   **初始化**

    1.  $\mathbf{\theta}[-1] = \mathbf{0} \in \mathbb{R}^{(l)}$，或任意其他值。

    2.  选择 $0 < \mu < 2$，以及一个较小的值 $\delta$。

*   **For** $n = 0, 1, 2, \dots$ **Do**

    1.  $e[n] = y[n] - \mathbf{\theta}[n-1]^{(T)}\mathbf{x}[n]$

    2.  $$

        \mathbf{\theta}_{n} = \mathbf{\theta}_{n - 1} + \frac{\mu}{\delta + \mathbf{x}_{n}^{T}\mathbf{x}_{n}}\mathbf{x}_{n}e_{n}

        $$

*   **End For**

NLMS 的计算复杂度为 $3l$ MADs。若满足

$$

0 < \mu < 2.

$$

则保证 NLMS 稳定。

## 5.7 复值情况

在第 4.4 节中，当

$$y[n] \in \mathbb{C} \text{ and } \mathbf{x}[n] \in \mathbb{C}^{(l)},$$

时，引入了估计任务的*广义线性*公式来处理不满足循环性条件的复值数据。广义线性估计器的输出由下式给出

$$\widehat{y}_n = \mathbf{\varphi}^{H}\widetilde{\mathbf{x}}_n,$$

其中

$$\mathbf{\varphi} := \begin{bmatrix} \mathbf{\theta} \\ \mathbf{v} \end{bmatrix} \quad \text{and} \quad \widetilde{\mathbf{x}}_n = \begin{bmatrix} \mathbf{x}_n \\ \mathbf{x}_n^{\ast} \end{bmatrix},$$

$\mathbf{\theta}, \mathbf{v} \in \mathbb{C}^{(l)}$。MSE 代价函数为

$J(\mathbf{\varphi}) = \mathbb{E} \left[ \middle| y_{n} - \mathbf{\varphi}^{H}{\widetilde{\mathbf{x}}}_{n}|^{2} \right],$

![Equation](img/si316.png)

遵循类似于第 5.3.1 节的标准论证，关于 `φ` 的最小值由以下方程的根给出：

$\Sigma_{\widetilde{x}}\mathbf{\varphi} - \begin{bmatrix} \mathbf{p} \\ \mathbf{q}^{\ast} \\ \end{bmatrix} = 0\text{~or~}\mathbb{E} \left[ {\widetilde{\mathbf{x}}}_{n}{\widetilde{\mathbf{x}}}_{n}^{H} \right]\mathbf{\varphi} = \mathbb{E} \left[ {\widetilde{\mathbf{x}}}_{n}y_{n}^{\ast} \right].$

![Equation](img/si317.png)

### 广义线性 LMS

采用 Robbins–Monro 方案并将 `μ[n]` 的值固定为常数，我们得到

$\mathbf{\varphi}_{n} = \mathbf{\varphi}_{n - 1} + \mu{\widetilde{\mathbf{x}}}_{n}e_{n}^{\ast},e_{n} = y_{n} - \mathbf{\varphi}_{n - 1}^{H}{\widetilde{\mathbf{x}}}_{n}.$

![Equation](img/si318.png)

将 `φ[n]` 和 ${\widetilde{\mathbf{x}}}_{n}$ 分解为其分量，即得广义线性 LMS。

#### 算法 5.4：广义线性 LMS

*   **初始化**

    1.  `θ[−1] = 0`, `v[−1] = 0`

    2.  选择 `μ`。

#### 算法步骤

*   **For** `n = 0, 1, …` **Do**

    1.  `e[n] = y[n] − θ[n−1]^(H) x[n] − v[n−1]^(H) x[n]^(*)`

    2.  `θ[n] = θ[n−1] + μ x[n] e[n]^(*)`

    3.  `v[n] = v[n−1] + μ x[n]^(*) e[n]^(*)`

*   **End For**

请注意，关于 LMS 稳定性条件的所有论述在此同样适用，前提是将 `Σ[x]` 替换为 `Σ[x̃]`。对于循环对称变量，我们令 `v[n] = 0`，从而得到*复线性 LMS*。

### 广义线性 APA

令 `φ[n]` 和 `x̃[n]` 定义如前所述。由此得到广义线性 APA；其详述见算法 5.5（问题 5.12）。

#### 算法 5.5：广义线性 APA

*   **Initialize**

    1.  `φ[−1] = 0`

    2.  Choose `μ`。

*   **For** `n = 0, 1, 2, …` **Do**

    1.  `e[n]^(*) = y[n]^(*) − X̃[n] φ[n−1]`

    2.  `φ[n] = φ[n−1] + μX̃[n]^(H)(δI + X̃[n]X̃[n]^(H))^(−1)e[n]^(*)`

*   **结束循环**

注意

```
X̃_n = [x̃_n^H; ⋮; x̃_{n-q+1}^H] = [x_n^H, x_n^T; ⋮; x_{n-q+1}^H, x_{n-q+1}^T]
```

且 `φ[n] ∈ ℂ^(2l)`。对于循环变量/过程，通过设置

```
X̃_n = X_n = [x_n^H; ⋮; x_{n-q+1}^H]
```

和

`φ[n] = θ[n] ∈ ℂ^l`，

可得复线性 APA 结果。

## 5.8 LMS 的变体

除了前面回顾的三种基本随机梯度下降方案外，多年来还提出了许多变体，旨在提高性能或降低复杂度。下面描述了一些值得注意的例子。

### 符号误差 LMS

该算法的更新递归变为（例如，[17,30,63]）

**θ**[*n*] = **θ**[*n* − 1] + *μ* csgn[*e*[*n*]^*] **x**[*n*]

其中复数 *z* = *x* + *jy* 的复符号函数定义为

csgn(*z*) = sgn(*x*) + *j* sgn(*y*)。

如果此外 *μ* 被选为 2 的幂，则递归变为*无乘法*，且仅需 *l* 次乘法来计算误差。结果表明，该算法在随机逼近意义上最小化了以下代价函数：

*J*(**θ**) = 𝔼 [|*y* − **θ**^(*H*) **x**|]

对于足够小的 *μ* 值，稳定性得到保证 [83]。

### 最小均值四次方 (LMF) 算法

该方案最小化以下代价函数：

*J*(**θ**) = 𝔼 [|*y* − **θ**^(*H*) **x**|⁴]

相应的更新递归由下式给出：

**θ**[*n*] = **θ**[*n* − 1] + *μ* |*e*[*n*]|² **x**[*n*] *e*[*n*]^*。

文献 [101] 已表明，如果噪声源是亚高斯的，最小化误差的四次方可能会导致一种在线方案，其在收敛速度和超额 MSE 之间的折衷比 LMS 更好。在亚高斯分布中，概率密度函数 (PDF) 图的尾部衰减速度比高斯分布更快。LMF 可被视为一种具有时变步长的 LMS 版本，步长等于 *μ* |*e*[*n*]|²。因此，当误差较大时，步长增加，这有助于 LMF 更快收敛。另一方面，当误差较小时，等效步长减小，从而导致较低的超额 MSE 值。这一想法在噪声为亚高斯时效果很好。然而，在存在离群值的情况下，LMF 倾向于变得不稳定。这也是可以理解的，因为对于非常大的误差值，等效步长变得非常大，导致不稳定。例如，当噪声遵循具有高尾部的分布时，即相应的 PDF 曲线衰减速率低于高斯分布，如超高斯分布的情况。关于 LMF 分析的结果可参见 [69, 70, 83]。对于足够小的 *μ* 值，算法的鲁棒性和稳定性得到保证 [83]。

### 变换域 LMS

我们已经指出，LMS 的收敛速度在很大程度上取决于协方差矩阵的条件数 $\left( \frac{\lambda_{\max}}{\lambda_{\min}} \right)$；这将在下面的示例中很快得到演示。

#### 变换域技术

变换域技术利用某些变换（如 `DFT` 和 `DCT`）的去相关特性，以对输入变量进行去相关。当输入包含随机过程时，我们称此类变换对输入过程进行“预白化”。此外，在涉及的变量属于随机过程的情况下，可以利用时移特性并采用分块处理技术；通过每个时间瞬间处理一块数据样本，可以利用某些变换的高效实现（如快速傅里叶变换 `FFT`）来降低总体复杂度。此类方案适用于涉及长滤波器的应用。例如，在某些应用（如回声消除）中，通常会遇到几百阶的滤波器 [10,39,53,66,68]。

设 `T` 为复域中的酉变换，表示为 `T T^H = T^H T = I`。

定义

```
x̂_n = T^H x_n,
```

并将变换矩阵 `T^H` 应用于 算法 5.4 中相应递推式的两边，针对广义线性 LMS，得到

```
θ̂_n = θ̂_{n-1} + μ x̂_n e_n^*,
```

其中

```
θ̂_n = T^H θ_n.
```

注意

```
e_n = y_n - θ_{n-1}^H x_n = y_n - θ_{n-1}^H T T^H x_n = y_n - θ̂_{n-1}^H x̂_n.
```

因此，误差项不受影响。注意到目前为止，我们尚未取得实质性进展。确实，

```
Σ[x̂] = T^H Σ[x] T
```

这是一个相似变换，不影响矩阵 `Σ[x]` 的条件数；从线性代数可知，这两个矩阵共享相同的特征值（问题 5.13）。现在让我们选择 `T = Q^T = Q`，其中 `Q` 是由 `Σ[x]` 的标准正交特征向量组成的酉矩阵。对于这种情况，`Σ[ˆx] = Λ`，这是一个对角矩阵，其对角线元素为 `Σ[x]` 的特征值。在后续内容中，我们修改公式 (5.65) 中的变换域 LMS，以便根据以下场景对每个分量使用不同的步长：

```
θ̂_n = θ̂_{n-1} + μΛ^{-1} x̂_n e_n^*
```

(5.67)

这等价于

```
θ̄_n = θ̄_{n-1} + μ x̄_n e_n^*
```

(5.68)

其中

```
θ̄_n := Λ^{1/2} θ̂_n
```

和

```
x̄_n := Λ^{-1/2} x̂_n
```

注意误差不受影响，因为 `θ̄_n^H x̄_n = θ̂_n^H x̂_n`。我们现在已经实现了最初的目标，因为

$$

\Sigma_{\overline{x}} = \Lambda^{- 1/2}\Sigma_{\widehat{x}}\Lambda^{- 1/2} = \Lambda^{- 1/2}\Lambda\Lambda^{- 1/2} = I.

$$

![Equation](img/si358.png)

也就是说，$\Sigma_{\overline{x}}$ 的条件数等于 1。在实践中，由于特征值分解任务的复杂性，这种技术难以应用；更重要的是，必须知道 $\Sigma[x]$，而在在线实现中并非如此。在实践中，我们采用近似白化输入的酉变换 $T$，例如 DFT 和 DCT。然后，公式 (5.67) 被以下公式替代：

$$

{\widehat{\mathbf{\theta}}}_{n} = {\widehat{\mathbf{\theta}}}_{n - 1} + \mu D^{- 1}{\widehat{\mathbf{x}}}_{n}e_{n}^{\ast},

$$

![Equation](img/si360.png)

其中 $D$ 是对角矩阵，其元素为 ${\widehat{\mathbf{x}}}_{n}$ 各分量的方差，即

$$

[D]_{ii} = \mathbb{E} \left[ (\hat{x}_{n}(i))^{2} \right] = \sigma_{i}^{2}, \quad i = 1, 2, \dots, l,

$$

![Equation](img/si362.png)
