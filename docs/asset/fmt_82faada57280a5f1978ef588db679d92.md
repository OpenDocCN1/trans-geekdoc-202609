
同时，在机器学习系统中，输入对象 `$A$` 经过一个或多个模块处理，它们可以变成输出对象 `$B$`。在这个过程中，每对对象之间的态射是互斥的。换句话说，如果 `$A \neq A'$` 或 `$B \neq B'$`，`$\mathcal{C}(A, B)$` 和 `$\mathcal{C}(A', B')$` 是互斥的。这满足了机器学习范畴的定义。因此，机器学习系统可以构成一个范畴。 $\square$

同样，可以定义机器学习的对偶范畴。设 `$\mathcal{C}$` 是一个机器学习范畴，保持 `$\mathcal{C}$` 的对象不变，并将 `$\mathcal{C}$` 中态射的方向反转形成新的机器学习范畴。我们称之为 `$\mathcal{C}$` 的对偶范畴，记为 `$\mathcal{C}^{\mathrm{op}}$`（当且仅当 `$f \in \mathcal{C}(B, A)$` 时，`$f \in \mathcal{C}^{\mathrm{op}}(A, B)$`）。

设 `$P$` 是关于机器学习范畴 `$\mathcal{A}$` 的一个命题，即命题 `$P$` 的条件和结论由机器学习范畴 `$\mathcal{A}$` 中的对象和态射组成。如果将命题 `$P$` 中的所有状态反转，我们可以获得一个新命题 `$P^{*}$`，称为命题 `$P$` 的对偶命题。从命题 `$P$` 很容易看出，机器学习范畴 `$\mathcal{A}$` 成立当且仅当对偶命题 `$P^{*}$` 涉及机器学习范畴 `$\mathcal{A}^{\mathrm{op}}$`。那么，对于任何机器学习范畴 `$\mathcal{A}$`，都有 `$(\mathcal{A}^{\mathrm{op}})^{\mathrm{op}} = \mathcal{A}$`，从而得到对偶原理。

## 示例 15.1

上一章给出的学习问题用范畴思想描述为：解集、训练样本集、目标函数集和新问题集是学习问题范畴 `$\mathbb{C}$` 中的对象族 `ob $\mathbb{C}$`。四个态射的函数集对应于它们之间的态射：解集是对象 `A`，训练样本集是对象 `B`，目标函数集是对象 `C`，新问题集是对象 `D`。执行系统、标识符、泛化设备和实验生成器分别是态射 `f`、`g`、`h` 和 `k`，其中 `g ∈ $\mathbb{C}(A, B)$`，`h ∈ $\mathbb{C}(B, C)$`，`k ∈ $\mathbb{C}(C, D)$`，以及 `f ∈ $\mathbb{C}(D, A)$`。

根据定理 15.1，机器学习范畴具有以下运算规则：

- (a) 复合律：如果 `A`、`B`、`C ∈ ob $\mathbb{C}$`，`f ∈ $\mathbb{C}(A, B)$`，`g ∈ $\mathbb{C}(B, C)$`，则存在唯一的 `gf ∈ $\mathbb{C}(A, C)$`，称为 `f` 和 `g` 的复合；
- (b) 结合律：如果 `A`、`B`、`C`、`D ∈ ob $\mathbb{C}$`，`f ∈ $\mathbb{C}(A, B)$`，`g ∈ $\mathbb{C}(B, C)$`，`h ∈ $\mathbb{C}(C, D)$`，则 `h(gf) = (hg)f`；
- (c) 恒等态射：对于每个对象 `A`，存在一个态射 `1_A ∈ $\mathbb{C}(A, A)$`，使得对于任何 `f ∈ $\mathbb{C}(A, B)$` 和 `g ∈ $\mathbb{C}(C, A)$`，都有 `f 1_A = f` 和 `1_A g = g`。

## 示例 15.2

以决策树学习为例，证明机器学习的可行性。

决策树学习是一种近似离散值目标函数的方法，它可以表示为决策树。实例的分类主要通过将实例从根节点排列到叶节点来完成。以经典决策树 ID3 算法为例进行分析。

对于学习范畴、数据集、对象和样本集，以及对象之间显而易见的态射，采用完整的 ID3 学习算法。我们不再深入细节。下面只演示核心算法。

将整体样本集设为学习范畴 `$\mathbb{C}$` 的对象 `X`。样本集由实例组成，实例由属性-值对表示。对应于样本集的整个属性集合是学习范畴 `$\mathbb{C}$` 的对象 `Q`，生成的决策树是学习范畴 `$\mathbb{C}$` 的对象 `T`。

- `f_1`：确定属于同一类的叶节点样本集 `∈ Mor $\mathbb{C}$`，`f_1: X → M`；
- `f_2`：判断节点属性是否为空 `∈ Mor $\mathbb{C}$`，`f_2: Q → M`。

计算训练样本中每个属性的熵 `g_1`：`Entropy(S) ≡ ∑_{i=1}^{c} -p_i log_2 p_i ∈ Mor $\mathbb{C}$`。设 `E` 为对应于整个属性集的熵集 `∈ ob $\mathbb{C}$`，`g_1: Q → E`。

利用上述状态获得的熵集对象，我们可以通过态射 `g_2` 获得对应的信息增益对象：`Gain(S, A) ≡ Entropy(S) - ∑_{v ∈ Value(A)} |S_v| / |S| Entropy(S_v) ∈ Mor $\mathbb{C}$`，即 `g_2: E → G`，`G ∈ ob $\mathbb{C}$` 是每个属性的信息增益对象。

最后，选择信息增益对象中对应元素的最大信息增益值，并记录对应元素的信息值（属性名，属性值）。根据态射 `h`：`max ∑_{i,j} Gain(X_{i}, Q_{ij}) ∈ Mor $\mathbb{C}$`，我们可以看到 `h: G → M`。对象 `M` 是具有最高信息增益的属性集合。因此，可以获得下一个节点，并更新决策树对象 `T`。通过循环计算直到生成叶节点，得到最终的决策树。

## 示例 15.3

贝叶斯学习算法也可以定义为机器学习范畴。

这里，我们以贝叶斯学习的经典算法，即 EM 算法，作为一个特例来证明贝叶斯学习算法可以表示为机器学习范畴。

EM 算法用于许多问题框架，需要估计描述基准概率分布的一组参数 `θ=⟨μ_{1},μ_{2},...,μ_{k}⟩`。这可以被视为机器学习范畴 C 中的未知参数对象 `U`。给定可以从该分布中观察到的所有数据，所有数据可以写成 `k+1` 元组 `⟨x_{i}, z_{i 1}, z_{i 2},..., z_{ik}⟩`，记为 `Y`；只能观察 `x_{i}`。`X=⟨x_{1},..., x_{m}⟩` 表示同一实例中可观察到的数据。那么，`Y=X ∪ Z` 表示所有数据。未观察到的数据对象 `Z` 可以视为一个随机变量，其概率分布依赖于未知参数对象 `U` 和已知数据对象 `X`。

假设当前假设 `h` 是假设集对象 `H`。对象 `H'` 表示最大似然假设集，对象 `Q` 是后验概率集。以下两个步骤对应于机器学习范畴中的两个态射，可以描述 EM 算法的过程：

- (1) 估计步骤：使用当前假设对象 `H` 和观察数据对象 `X` 来估计对象 `Y` 上的概率分布以计算对象 `Q`，计算过程可以由态射 `f` 表示。

`f: H X → Q`

(2) 最大化步骤：用使对象 *Q* 最大化的最大似然假设对象 *H'* 替换当前假设对象 *H*。使用同态表示如下：

```
g: Q → H'
```

在此，同态 `f` 可以具体简化为 `f: E[ln P(Y|h).* |h, X,]`，而同态 `f'` 也可以由同态 `f': ∫ log(L(θ | X, y)) f(y | X, θ')dy` 表示。我们可以定义同态 `g` 可以简化为 `g: arg max_{h}^{'} Q`。此外，机器学习领域的对象和同态满足复合运算律、结合律和单位同态。因此，偏差学习算法也是一个机器学习范畴。

## 15.2.2 学习表达式的范畴表示

首先，我们使用范畴来表示简单的表达式，例如 `y = x^2, x ∈ R`。该表达式包含两个集合：定义域和值域。因此，我们可以在范畴 C 中定义两个对象 `A, B`，其中定义域定义为 `A`，值域表示为 `B`，并且该表达式可以表示为一个范畴：

```
f: A ↦ B , f is the corresponding morphism to 𝔠(A, B) . (15.1)
```

对于学习问题中的表达式，我们可以从学习问题的标准描述中逐步获得它们。在文献[1]中，定义了任务类 `P` 的性能指标 `T`。如果针对 `T` 的计算机程序使用 `P` 来测量其作为经验 `E` 的性能，则称该计算机程序是从经验 `E` 中学习。我们可以将学习任务简化为发现理想目标函数的可操作描述，这可以通过学习表达式的形式来完成。

对象 `A` 是训练样本的初始状态集，对象 `B` 是中间状态，对象 `M` 是最终输出状态。然后，学习过程可以表示为：

```
f: A ↦ B, g: B ↦ C . (15.2)
```

`f, g` 是对应对象的同态。根据范畴的复合运算律和结合律，

```
gf: A ↦ C (15.3)
```

## 15.2.3 学习表达式函子的范畴表示

从上一节可以看出，学习过程可以表示为学习表达式范畴的抽象代数结构。不同的学习过程属于同一个代数结构。因此，不同的学习过程之间存在同态关系，这形成了表达式之间的映射机制，即存在映射 `φ: X → Y` 满足 `φ (u · v) = φ (u) · φ (v)`。

**定义 15.10.** 假设 `𝕮` 和 `𝔻` 是学习表达式范畴。学习表达式函子 `F : 𝕮 → 𝔻` 由两个映射组成：

`ob 𝕮 → ob 𝔻 : A ↦ F(A)` (15.7)

`Mor 𝕮 → Mor 𝔻 : f ↦ F(f)` (15.8)

解释：

- (1) 代表两个学习表达式范畴中对象之间的映射，将属于 `𝕮` 的每个对象 `A` 映射到属于 `𝔻` 的另一个对象 `B`，`B = F(A)`；
- (2) 代表两个学习表达式范畴中同态之间的映射，将属于 `𝕮` 的每个同态 `f` 映射到属于 `𝔻` 的另一个同态 `g`，可以表示为 `g = F(f)`，并满足 `F(gf) = F(g)F(f)`。

`𝕮`，`𝔻` 是学习表达式，`F : 𝕮 → 𝔻` 是学习表达式函子。对于 `𝕮` 中的任意对象对 `A, B` 和 `f, g ∈ 𝕮(A, B)`，我们有

`F(f) = F(g) ⇒ f = g`

即 `F` 在 `𝕮(A, B)` 中保持局部性。如果 `𝕮(A, B) → 𝔻(F(A), F(B))` 是单射，则学习表达式函子 `F` 是忠实的学习表达式函子。

如果对于任意 `g ∈ 𝔻(F(A), F(B))`，都存在 `f ∈ 𝕮(A, B)` 满足 `F(f) = g`，即 `F` 在 `𝕮(A, B)` 中保持局部性，并且进一步，如果 `𝕮(A, B) → 𝔻(F(A), F(B))` 是满射，则学习表达式函子 `F` 是全的学习表达式函子。

**定理 15.2.** 学习表达式范畴之间存在函子。

*证明.* 设 `𝕮, 𝔻` 为学习表达式范畴。`W, X, B, M ∈ ob𝕮`，`W', X', B'`，`M' ∈ ob𝔻`，`f, g, h' ∈ Mor𝕮`，`f', g', h' ∈ Mor𝔻`。学习表达式范畴中的对象由训练样本集确定，且条件 (15.7) 显然成立：

`(W, X, B, M) → F (W', X', B', M')` .

假设 `·` 是同态之间的算子，且映射 `F: X → Y` 满足 `F(u · v) = F(u) · F(v)`。

```
\begin{align*}
F(f \cdot f') &= F\left(\left(W \times X \to B\right) \cdot \left(W' \times X' \to B'\right)\right) \\
&= F\left(\left(W \times X \to B\right) \cdot \left(F(W) \times F(X) \to F(B)\right)\right) \\
&= F\left(W \times X \to B\right) \cdot F\left(F(W) \times F(X) \to F(B)\right) \\
&= F(f) \cdot F(f')
\end{align*}
```

因此，学习表达式满足同态映射。

综上所述，两个学习表达式范畴之间存在学习表达式函子，即学习表达式范畴之间存在范畴论中的映射。这为进一步研究学习表达式范畴之间的映射机制提供了理论基础。
