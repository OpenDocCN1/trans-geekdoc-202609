
*   **本质安全** 是指设备或系统的设计使得在发生电源或组件故障时，受控工艺将保持在其安全状态（开或关）。例如，示例工艺中的燃气控制阀应选用本质安全型（失信号时移至关闭位置），即任何时候失去控制器信号都会关闭。这将确保在发生任何故障时，进入罐体的燃气流量被切断。

*   **故障安全锁定** 是指设备或系统的设计使得在发生电源或组件故障时，受控工艺将进入其最安全的状态。

由于安全控制器主要是一种安全设备，其主要职责之一是在发生安全事件时提供适当的通知。当控制器从其安全传感器之一接收到有效输入信号时，它会根据其编程（以及所需的应急响应类型）评估呈现的条件，并在必要时向报警器（警笛或铃铛）发送适当的报警信号。它还可以激活任意数量的视觉指示器，如闪光灯、操作员面板灯或控制面板上的图标。

控制器还可以根据其编程与指定的安全和监督联系人（安全主管、监控服务或应急服务）进行通信。这些系统设计为在无人值守时做出反应。它们可以使用以下几种方法之一来实现这一点：

*   **拨号电话连接**：使用电话拨号器通过标准电话线提醒远程安全联系人存在危险状况。

*   **蜂窝信道**：使用蜂窝信道向指定的安全或监督联系人发送预设的短信。

*   **基于 IP 的通知**：使用 IP 网络（如互联网）通知指定的安全和监督人员有关危险状况。

### 冗余系统

组件和系统**冗余** 是工业安全中最基本的实践之一。我们已经确定了本章介绍的简单工艺示例中代表**单点故障** 的几个关键组件。SIS 由不同于过程控制系统的组件组成，原因在于当过程控制系统中的组件发生故障时，SIS 必须介入并接管控制。如果两个系统使用同一设备，则两个系统都会失效。

例如，为了解决本章前面确定的与工艺相关的危险，我们可以考虑向系统添加多个传感器：

*   储罐外部的燃气检测传感器
*   储罐内部的火焰检测传感器
*   储罐内部的压力传感器
*   储罐内部的安全温度传感器

在每种情况下，这些传感器相对于原始设计中的过程控制传感器都是冗余的。

可添加到工艺中以缓解潜在危险的基本执行器包括：

*   电磁控制阀上游的手动关断阀
*   手动阀和过程控制阀之间的安全关断阀
*   储罐壳体上的安全泄压阀

与拟议的安全传感器一样，这些额外的执行器相对于原始过程控制系统设计中的执行器也是冗余的。

### 紧急停车系统

**紧急停车系统 (EMSs)** 是一种特定类型的 SIS，旨在最大限度地减少某些紧急状况的后果。它们在预防安全层运行，并采取行动防止火灾、化学品泄漏或爆炸等危险事件发生。作为系统，它们由 ESD 传感器、ESD 控制器和 ESD 执行器组成。

#### 火气系统

*火气系统* *(FGSs)* 是 SIS 的一部分，运行在缓解安全层，旨在限制 ESD 事件的后果。它们在 SIS 中实施，以持续监控工厂活动，并在发生危险状况时启动适当的动作。例如，如果 FGS 检测到可燃气体（如图 1.29 中用于加热储罐的气体）、有毒气体、烟雾、火焰或过热，它可能会发出视觉和听觉警报，并启动灭火系统和/或过程停车。

在我们的简单过程中，FGS 将使用位于供气管道沿线间隔处和接头处的气体泄漏检测装置。控制器可以是编程执行 SIS 功能的 `PLC`，也可以是专用 FGS 控制器。图 1.30 说明了在我们的示例过程中实施简单 FGS 的情况。

![FIGURE 1.30 Adding an FGS to the system](img/c01f030.png)

**FIGURE 1.30** 向系统添加 FGS

控制器的选择通常基于过程的规模。`PLC` 往往更适合中大型安装（涉及 25 个以上传感器），而专用控制器更适合中小型安装。`PLC` 控制器实施和变更的成本相对较低且灵活。此外，`PLC` 能够在分布式控制环境中与其他控制器通信。专用控制器安装和维护相对容易，通常不需要编程。

与 ESD 系统不同，火气系统可能非常复杂且高度分布式。然而，它们对工厂安全至关重要，其效率和可靠性不仅是工厂操作员关注的重点，也是环保和商业保险机构关注的重点。

#### 工业泄漏检测

FGS 的主要组件之一是*泄漏检测器*。这些设备被添加到 SIS 中，用于检测危险气体、化学品和液体的泄漏。它们广泛应用于各类工业过程，用于任何盛装可能泄漏的液体或气体的设备中。

工业环境中可用的泄漏检测器类型很多。每种类型采用不同的物理原理来检测泄漏并将其转换为信号：

*   *流体积聚检测器*：此类检测器使用两个独立的探针来检测探针之间积聚的过量流体的存在，这些流体在探针之间形成闭路条件。
*   *电阻变化检测器*：此类泄漏检测器使用电化学传感器来检测设备周围流体或气体的存在或浓度水平。当流体或气体混合物的化学成分发生变化时（例如管道外部周围空气中混入了气体），探针的电阻会发生变化，控制器会感应到这种变化。
*   *差压流量检测器*：此类检测器测量导管（如管道）中两点之间的压力差。如果导管是密闭的，两点之间不应有压力差。然而，如果测量点之间的压力发生变化，则假定发生了泄漏。

图 1.31 描绘了一个简单的差压检测系统。气体管道在管道的两个点上开孔取压。在该图示中，两个测量点之间存在一个正在被监测泄漏的管道接头。取压点连接到一个中心带有柔性隔膜的密封容器的两侧。隔膜通过机械方式连接到一个可动开关触点。

![FIGURE 1.31 A simple differential pressure detection system](img/c01f031.png)

**FIGURE 1.31** 简单的差压检测系统

只要上游和下游压力相同，隔膜就会保持在容器中间，可动触点不会接触固定开关触点。因此，传感电路保持断开。然而，如果下游取压点压力下降，上游取压点较大的压力会将隔膜向图中右侧推动。当压力差足够大时，可动触点将与固定触点接触，传感器电路随即闭合。

此时，安全控制器将执行其指定的 `SIF`，这可能包括发出听觉警报、启动一个或多个视觉警示以及关闭安全阀。

#### 燃烧器管理系统

正如我们的过程示例所示，燃气燃烧器广泛用于工业过程中加热气体和液体。为了保障储罐外部燃气输送系统的安全，部署了燃气泄漏检测器来监测管道沿线区域。然而，燃气泄漏检测器在我们过程示例的储罐内部用处不大。

燃烧器区域本应有燃气，但必须以精确的方式加以控制，以确保系统安全运行。假设燃烧器上的火焰熄灭了。燃气传感器会检测到燃烧器区域涌入的燃气，安全控制器会采取行动切断燃气流量。

那么，如何以安全的方式重新点燃燃烧器？这必须同时具备燃气和火焰才能实现。然而，安全传感器/控制器会继续保持阀门关闭，直到燃气传感器指示该区域不再有燃气。因此，使用*燃烧器管理系统* *(BMSs)* 来确保过程控制系统中燃烧器的安全启动、运行和停车。图 1.32 描绘了简单 BMS 的组件。

![FIGURE 1.32 A simple BMS](img/c01f032.png)

**FIGURE 1.32** 简单的 BMS

这个简单系统始于一个称为*引燃器*的小型装置。这是一种始终在主燃烧器附近维持小火焰的设备。引燃器火焰指向火焰传感器——通常是热电偶——每当火焰作用于传感器时，它就会产生电信号。

安全控制器利用热电偶的电信号使故障关闭型安全阀保持开启。如果引燃器火焰不存在，*安全阀*将关闭。该阀门位于手动切断阀下游，原过程控制阀上游。

该点火系统旨在将小型点火源维持在主燃烧器附近，以便当过程控制阀打开并向燃烧器供气时，燃气能够点燃，而不会在燃烧器装置周围积聚。当过程控制器关闭过程控制阀以限制流向燃烧器的燃气时，点火器将保持点燃状态。当过程需要更多热量时，控制器可以打开燃烧器的控制阀，使其以安全的方式点燃。

要点燃点火器，操作员必须手动覆盖关闭的安全阀，向点火器机构引入燃气。此外，他们还必须向点火器组件提供火源以启动它。火焰传感器检测到点火器火焰后，安全控制器应接管系统控制权。火源通常是某种类型的电火花发生器。

当然，工业安全环境中实际的 BMS 部署往往比此处展示的简单设计复杂得多。然而，它们都采用传感器、控制器和执行器，这些设备经过设计和选择，旨在执行与本示例相同的功能。

#### 振动监测

本章 GICSP 认证目标中列出的最后一个 SIS 子系统是*振动监测系统*。这些系统通常被添加到工业设备上，以监测运动机械是否有即将发生故障的迹象。过度振动是机器开始出现劣化迹象的信号之一。通过监测振动量，组织可以就何时维修或更换机器做出明智的决策。

所有运动机械都会在一定程度上产生振动。然而，随着其运动部件老化，它们会逐渐剧烈振动。被称为*加速度计*的设备被安装在旋转机械上，以随时间监测其振动模式。记录的振动模式可以与之前的时间点进行比较，以确定机器磨损的速率。

图 1.33 展示了向 FGS 系统添加应急排风扇装置。如果 FGS 系统检测到燃气泄漏，风扇装置将被激活以将烟雾排出该区域。驱动风扇的电机是安全系统的关键部件，但在安全测试之外很少或从不使用。因此，必须保持其处于良好工作状态，以备紧急情况时使用。该图还展示了向排风扇电机添加振动传感器系统，以便通过定期测试跟踪其状况。

![图 1.33 添加振动检测系统](img/c01f033.png)

**图 1.33** 添加振动检测系统

振动检测系统还用于测试或监测人体健康和安全系统。在美国，OSHA 技术手册 (OTM) 涵盖了三个与人体相关的振动监测领域。例如，某些需要人工操作的设备可能会接受振动监测。这通常是为了确保机器的运行不会超过建议的振动限值，从而使操作员暴露于可能损害人体的振动水平。

## 第 2 章：ICS 架构

## 简介

在上一章中，您了解了典型工业/公用事业控制系统的基本组件。本章将以这些介绍性主题为基础，描述标准 ICS 架构。特别是，它将汇集与运营 OT 架构相关的四大知识领域：

*   Communication media（通信介质）
*   Field device architecture（现场设备架构）
*   Industrial network protocols（工业网络协议）
*   IT network protocols（IT 网络协议）

在上一章的介绍中，提到 OT 网络往往与企业和小型企业环境中发现的 IT 网络截然不同。例如，正如您已知，工业制造和公用事业网络中使用的许多连接和计算设备与企业网络中常见的设备有很大不同。特别是，工业/公用事业网络中使用的 OT 网络包含不同类型的过程控制设备，如 `programmable logic controllers` (`PLCs`) 和 `remote terminal units (RTUs)`。

这些环境在软件领域也差异巨大。在工业网络环境中，企业网络中运行在 Windows 和 Linux 操作系统上的业务应用程序已被提供 `supervisory control and data acquisition (SCADA)` 和 `man-machine interface (MMI)` 功能的过程控制应用程序所取代。

即使网络通信也可能与企业网络中遇到的截然不同。虽然 `CATx` 双绞线布线、Ethernet 协议和 `TCP/IP` 在企业环境中广泛使用，但其他协议和技术（如 `RS-485` 串行通信链路、Modbus 网络和 SONET 环形广域网）也存在，以及多种无线技术。

## 网络传输介质

数字数据通过网络 `communication media` 从一个网络设备传输到另一个网络设备。用于在网络设备之间移动数据的传输介质基本上有三种通用类型：

*   Copper wire（铜线：双绞铜缆和同轴电缆）
*   Light waves（光波：光纤电缆和红外光）
*   Wireless radio frequency (RF) signals（无线射频 (RF) 信号：WiFi、WiMAX、Bluetooth、ZigBee、Z-Wave）
