## 爱因斯坦记号

## 张量的点积

对于计算两个向量的点积（或内积），我们会计算 ![](img/574.jpg) ![](img/575.jpg)。我们能否将**点积**的定义推广到张量？二阶张量与一阶张量的点积与矩阵与列向量的矩阵乘法相同。输出的阶将是向量，即输出的阶为 ![](img/576.jpg)。一阶张量与二阶张量的点积通过计算矩阵转置与列向量的矩阵乘法获得，我们再次得到一个一阶张量。

相匹配阶的两个矩阵相乘将得到另一个矩阵，即 2 阶张量 = 2 + 2 – 2。因此，两个二阶张量的张量点积是另一个二阶张量。因此，`p` 阶和 `q` 阶两个张量点积的输出阶为 ![](img/577.jpg) 一个 `p` + `q` – 2 阶张量。这种张量点积的概念可以进一步推广到高阶张量：在指定维度上进行点积，同时保持所有其他维度固定。

假设我们有两个张量 ![](img/578.jpg)，阶数分别为 ![](img/579.jpg)。假设我们想沿 `k` 个轴计算点积，其中 ![](img/580.jpg)。那么，我们必须指定 ![](img/581.jpg) 的哪 `k` 个轴用于计算点积，输出张量的阶将为：![](img/582.jpg)。这在 `NumPy` 和其他深度学习框架（如 `TensorFlow` 和 `PyTorch`）中作为 “Tensordot” 操作实现。应用点积的轴称为*收缩轴*。输出张量的形状由第一个张量的非收缩轴组成，后跟第二个张量的非收缩轴。以下代码展示了如何使用 NumPy 计算张量点积：

```
1. import numpy as np
2. A = np.arange(24).reshape(4,2,3)
3. B = np.ones(12).reshape(2,3,2)
4. k=2 #num contraction axes
5. order_output = len(A.shape)+len(B.shape)-2*k
6. # Dot product of last k(=2) axes of A and first k axes of B
7. out1 = np.tensordot(A, B, axes=[[1, 2],[0, 1]])
8.
9. # what is happening inside tensordot
10. out2 = np.zeros(A.shape[:-k]+B.shape[k:])
11. for p in range(4):
12.     for s in range(2):
13.         for q in range(2):
14.             for r in range(3):
15.                 out2[p, s]+=A[p,q,r]*B[q,r,s]
16. np.equal(out1, out2)
```

**图 3.13** 显示了输入输出张量。第 10-15 行展示了如何使用嵌套循环沿选定的 k 个轴计算点积。这种计算非常慢，但有助于我们清楚地理解 `Tensordot` 操作内部实际发生了什么。然而，Tensordot 的实际实现并非使用嵌套循环，而是经过优化，为我们提供了一种计算速度快得多的方法。
