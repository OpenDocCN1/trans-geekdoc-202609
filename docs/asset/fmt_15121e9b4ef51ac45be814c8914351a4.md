# 人机通信

如果你想有用、激励且有趣，就必须创建真正的认知。认知是一种通过获取知识的心理过程，IBM 可以它们识别为可以理解、推理、学习并预期互的系统。为了实现这一点，认知系统将分析大量数据以构成明智的、环境感知的持续与用户连接。理解、推理、学习，有各种人类元素：

* **良好**：应用程序将根据预训练来分类和组织信息。
* **更好**：应用程序能够从实时源分类和组织信息。
* **最佳**：应用程序将带来用户的预期，并直接响应它们，创建对您的需求和背景有益的建议。

## 部分。输出：自然响应

推理应用程序通过轻松提供存储在其知识库中的真实信息来与程序进行智能通信。通过其关于用户的经验，认知应用程序将超越准确翻译，并给出更受欢迎的宏观回答。推理可以认为是应用程序通过感知、知识和动机具有认知通信的能力。如果一个稳定的知识库产生了智能响应，如果应用程序没有服务个人并以某种方式考虑您的背景，它不是认知的。单通信在同时使用具有更多能力，但认知应用程序将根据其目前学习的内容编写响应，并根据程序对该特定的的改进未来的答案。推理是一种基于上下文和历史知识具有智能通信的应用：

* **良好**：应用可以生成针对领域或定向问题空间的预定义响应。它在创建响应时不必使用感知或动机能力，而是依赖预训练知识。
* **更好**：它创建丰富的响应，并在创建响应时依赖感知、动机和知识能力。
* **最佳**：它将带来用户的预期，并直接响应它们，创建对您的需求和背景有益的建议。

## 学习

在有交互的地方，认知应用程序根据程序的响应更新他们关于程序、当前数据和世界的知识。存在用户在不检查内容的情况下立即点击建议的链接的情况。认知系统通常根据个人和集体历史经验的发现来更新与人的互动方式。它们记住过去的通信，并根据这些研究调整调整响应。学习被认为是应用程序解释用户响应并随时间推移应用知识：

* **良好**：应用程序将允许用户训练预包信息。
* **更好**：应用程序通过用户通信和行为学习。
* **最佳**：应用程序自行更新其知识库，无需任何用户干预。
