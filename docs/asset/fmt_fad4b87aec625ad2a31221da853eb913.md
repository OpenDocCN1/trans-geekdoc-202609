
# 12.4.1 资产与漏洞

人员通常会将其 QML 模型部署在 `Azure Quantum`、`Amazon Marketplace` 和 `Google Cloud` 等云提供商处，以评估在噪声环境下的稳健性/性能。包括 `IonQ`、`D-Wave`、`IBM` 和 `Rigetti` 在内的许多公司都是如此。硬件特性和设计（例如量子比特数量、耦合映射以及其他方面）在不同云服务提供商之间可能存在差异。云服务提供商的调度器可能会使用共享相同耦合映射的不同硬件。不仅如此，像 `ibmq london` 和 `ibmq santiago` 等较小硬件的耦合映射可能会适配到 `ibmq rochester` 等具有更高量子比特数的较大硬件上。由于用户可以定义自己的耦合映射架构，他们可以在量子云中进行操作。云端的终端用户很难区分看起来非常相似的耦合映射。因此，第三方云提供商可能会为任务分配较差的硬件，导致量子电路的性能不佳和/或收敛时间变慢。

此外，软件在真实硬件上的成功取决于编译过程。`D-Ocean`、`Wave`、`IBM`、`Rigetti` 等在内的许多公司提供了量子硬件编译器。其他公司（如 `Orquestra` 和 `tKet`）也开发了自己的软件来补充这些专有产品。随着人们对量子计算兴趣的持续增长，在不久的将来，由于优化方法的增强，可能会出现几个具有增强性能的第三方编译器。然而，这些来自声誉较低的组织的编译器在未来可能会引起隐私和安全问题。

在 QML 电路中嵌入敏感私有财产：使用实际量子硬件构建和测试 `QNN` 电路是一种常见做法，每个电路都使用不同的 `PQC` 或角度编码方案。这些电路可能会被发送到第三方编译器处以寻求提高速度/效率，由于第三方可以访问电路设计，这使得敏感的知识产权面临风险。

# 12.4.2 攻击模型与防御不可靠的硬件分配器

如前所述，当为了节省资金或满足虚假广告的比特或量子硬件标准而使用第三方提供的不稳定量子计算机时，QML 模型的性能可能会严重下降。如果将新的 QML 架构或算法发送到不可信任的编译器，知识产权（例如所采用的 `ansatz`、参数数量、`QNN` 的层数以及输入嵌入类型）可能会被获取。为了污染训练并提供假阳性，攻击者可能会向 `QNN` 中插入恶意组件。在获得这些编译器提供的性能优势的同时，保护知识产权免受不良编译器的侵害，是 [\[23\]](#c12.xhtml#ref23) 中描述方法的目标。他们提出了一种方法，设计者在不同时间将量子电路片段发送给单个编译器或多个编译器，然后将这些片段重新组合形成最终电路。对 152 个电路的广泛分析表明，拆编译技术可以完全保护知识产权（IP），也可以在仅需少量额外工作（不超过 6%）的情况下增加重构复杂度。[\[28\]](#c12.xhtml#ref28) 在电路中引入了虚假的 `SWAP` 门，以防止软件在不可信任的第三方编译器进行操纵或伪造时正常运行。由于量子芯片的操作不像经典芯片那样是可预测的，攻击者无法逆向工程量子电路并预测 `SWAP` 门的位置。他们开发了一种全变分距离（TVD）方法。

# 故障注入攻击

单个操作的门误差与同时发生的两个独立操作的门误差可能会不同。串扰（Crosstalk）是这种故障的术语。根据 [\[18\]](#c12.xhtml#ref18) 中提出的研究，并行门操作的错误率可能是单门的三倍。此外，最近已证明 [\[5\]](#c12.xhtml#ref5)，外部攻击者可以通过反复使用 `CNOT` 门驱动量子比特，向运行在相同硬件上的另一个用户的软件中植入故障。Saki *等人.* [\[5\]](#c12.xhtml#ref5) 研究的一种方法是在用户程序之间插入隔离/缓冲区比特，以减少此类攻击量子电路和分类器的风险。这有效意味着当 `QNN` 电路在该处使用时，另一个程序无法在硬件的相邻量子比特上运行。周围的量子比特被用作缓冲区或隔离比特以防止这种情况发生。以浪费几个量子比特为代价，他们的分析表明，缓冲区比特可以将可靠性提高高达 1.87 倍。

机器学习技术已渗透到现代生活的几乎每一个方面，使其成为攻击和防御系统研究的重点关注领域。考虑到近期对量子机器学习（QML）研究兴趣的日益增加，我们研究了量子机器学习的安全机遇、脆弱性、威胁及应对措施。我们讨论了 QML 在识别 PCB（印刷电路板）缺陷方面的某种潜在安全用途，并建议了保护半导体供应链的进一步应用领域，包括识别硬件木马和检测拆旧芯片。此外，我们还讨论了 QML 的脆弱性以及各种攻击类型和缓解策略。

# 摘要

网络安全作为计算机科学的一个领域，是全球各国投入程度最大的领域之一。预计到 2021 年底，各国在网络安全方面的支出将超过 1 万亿美元。近期显示，约有 45% 的网络攻击是成功的。计算机取证是 21 世纪最受青睐的职业之一。网络取证是指从设备中收集和存储数据的过程，这些数据可以在法庭上提交给法官。数字取证有多种形式，其中包括磁盘取证、网络取证和无线取证等。本研究的目的是探索全球网络安全和网络取证领域的未来趋势，寻找改进现有技术的方法，并创造新技术以捕获全球范围内臭名昭著的黑客。研究方法将主要包括教育人们他们在在线世界中所面临的威胁，同时评估现状，并预测这两个巨大领域的未来发展。这项研究如果实施，将通过保护个人数据并鼓励人类在各自的领域实现其最大潜力，确保在线世界成为一个更加安全的地方。

**关键词：** 网络安全，网络取证，钓鱼，中间人攻击 (MITM)

# 13.1 引言

网络安全是一个全球领先国家大量投入的领域，它基本上是保护信息（无论是个人还是组织）免受盗窃、软件或硬件损坏等的过程。近年来，网络犯罪 [1, 2] 已成为公众熟悉的话题。现在显而易见，随着近年来技术的进步，网络攻击也随之增加。黑客一直在寻找新方法来渗透系统，无论是通过病毒、恶意软件还是钓鱼攻击。网络攻击有多种形式，如恶意软件、钓鱼攻击和中间人（MITM） [3, 4] 攻击等。

* **恶意软件 (Malware)**：这是一种全球范围内非常流行的软件，能够执行各种形式的恶意任务，包括未经授权访问特定网络以及监视用户以获取其登录信息。勒索软件属于此类恶意软件，被频繁使用，负责加密用户文件并向用户索要以恢复访问权限。

* **钓鱼攻击 (Phishing)**：这种攻击使用频率最高，且非常容易实施。通常情况下，用户会收到一封伪装成合法组织（如政府部门甚至电信公司）的邮件，要求用户提供个人信息。这可以通过电话、信息服务甚至通过电子邮件进行。

* **中间人攻击 (Man-in-the-middle-attack, MITM)**：这种攻击通常涉及黑客监听两人或双方之间的对话，以窃取个人信息或凭据。由于现在邮件采用了端到端加密，第三方介入变得不可能，中间人攻击现在不再那么常见。

* **网络取证 (Cyber Forensics)**，也称为数字取证或计算机取证，是数字取证的一个分支，负责从计算机或手机等设备中收集证据，然后将这些证据转化为物理证据并提交给法官。对网络取证的需求日益增长。它是当今瞬息万变的世界中一种演进的力量。它为检察官提供了违规行为的证据，包括搜索历史、电子邮件日志或罪犯留下的任何其他数字足迹等简单信息。其主要应用是打击各种犯罪，包括黑客攻击和拒绝服务（DOS） [5]。

网络取证遵循非常系统的方法。其中涉及的过程包括：

* **对受调查的假设计算机系统进行数字复制**：此过程包括获取调查系统的副本。

* **验证并认证数字副本**：为了确保数据不丢失，调查人员对收集的数据进行验证和认证。

* **确保复制数据的有效性**：在当今不断变化的世界中，这种演进的力量确保数据是有效的。

* **恢复已删除的文件**：黑客可能会尝试删除他们的数字足迹，使得检察官难以起诉。因此，检察官必须检索数据。

* **使用关键词搜索特定数据**：当检察官在法庭提交案件时，关键词的使用非常有用。它使检察官能够快速获取信息。

* **创建技术报告**：这是调查的最后步骤，准备一份可以提交给法官的清晰技术报告。它清楚地定义了罪犯及其违法行为。
