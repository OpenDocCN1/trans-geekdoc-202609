
![Equation](img/si252.png)

向量 $\mathbf{w}_2$ 和 $\mathbf{w}_1$ 分别指向从 PCA 分析获得的主轴和次轴方向。根据 PCA，最具信息量的方向沿主轴 $\mathbf{w}_2$，即方差最大的那个方向。然而，根据 ICA 分析，投影最有趣的方向是 $\mathbf{w}_1$ 的方向。确实，沿这些方向获得的每个独立成分（IC）$z_1, z_2$ 的峰度分别为

$$\kappa_4(z_1) = -1.7, \quad \kappa_4(z_2) = 0.1,$$

![Equation](img/si258.png)

因此，在主轴（PCA）方向上的投影导致变量的概率密度函数（PDF）接近高斯分布。在次轴方向上的投影导致变量的 PDF 偏离高斯分布（呈双峰模态），并且从分类的角度来看，这是最有趣的一个。通过观察图形可以很容易地验证这一点；在方向 $\mathbf{w}_2$ 上投影会导致类别重叠。

## 20.6 字典学习：$k$-SVD 算法

*过完备字典*的概念及其在建模真实世界信号中的重要性已在第 9 章中介绍。我们再次回到这个主题，这次是在一个更一般的设定下。在那里，假设字典是已知的，且原子是预先选定的。在本节中，考虑了该任务的盲版本；即字典的原子是未知的，必须从观测数据中估计。回想一下，ICA 也是这种情况；然而，这里将调用稀疏性论据，而不是 ICA 所用的独立性概念。赋予字典自由以适应每次特定输入的需求，与预选原子的字典相比，可以带来性能的提升。

我们的出发点是观测到的 $l$ 个随机变量根据线性模型用 $m > l$ 个潜在变量来表示

**x** = *A***z**，**x** ∈ ℝ^(*l*)，**z** ∈ ℝ^(*m*)，

且 *A* 为未知的 *l* × *m* 矩阵。通常 *m* ≫ *l*。即使 *A* 已知且固定，也不需要特殊的数学技巧就能看出该任务没有唯一解，因此必须向问题中引入约束。为此，我们将采用促稀疏约束，正如我们在本书各处已讨论的那样。

设 **x**[*n*]，*n* = 1, 2, …, *N*，为将构成唯一可用信息的观测值。任务是获取字典的原子（即 *A* 的列）以及假定为稀疏的潜在变量；也就是说，我们将为输入观测值（向量）建立稀疏表示。毫无疑问，达到该目标有不同的途径。我们将重点关注最广为人知且使用最广泛的方法之一，即 *k-SVD*，该方法在文献 [4] 中提出。

令 *X* := [**x**[1], …, **x**[*N*]]，*A* := {**a**[1], …, **a**[*m*]}，和 *Z* := [**z**[1], …, **z**[*N*]]，其中 **z**[*n*] 为与输入 **x**[*n*] 对应的潜在向量，*n* = 1, 2, …, *N*。字典学习任务被表述为以下优化问题：

```
min_{A,Z} ||X - AZ||_F² subject to ||z_n||_0 <= T_0 for n = 1, ..., N
```

其中 *T*₀ 为阈值，||·||₀ 表示 ℓ₀ 范数，详见第 9 章。这是一个非凸优化任务，通过迭代方式执行；每次迭代包含两个阶段。在第一阶段中，假设 *A* 固定，针对 **z**[*n*]，*n* = 1, 2, …, *N* 进行优化。在第二阶段，假设潜在向量固定，针对 *A* 的列进行优化。

在 *k*-SVD 中，采用了略有不同的原理。在针对 *A* 的列进行优化时（一次一列），也会同步更新 *Z* 的部分元素。这是 *k*-SVD 与更标准优化技术的关键区别；在实践中，这似乎能带来性能提升。

### 阶段 1

假设 *A* 已知且固定为从上一次迭代获得的值。则相关的优化任务变为

$$

\min_{Z} \quad \|X - AZ\|_{F}^{2}, \text{s.t.} \quad \|\mathbf{z}_{n}\|_{0} \leq T_{0}, \quad n = 1,2,\ldots,N,

$$

![Equation](img/si270.png)

根据弗罗贝尼乌斯范数的定义，这等价于求解 *N* 个不同的优化任务，

$$

\min_{\mathbf{z}_{n}} \quad \|\mathbf{x}_{n} - A\mathbf{z}_{n}\|^{2},

$$

![Equation](img/si271.png)(20.66)

s.t. $\|\mathbf{z}[n]\|_{0} \leq T[0], \quad n = 1, 2, \ldots, N$.

![Equation](img/si272.png)(20.67)

如果考虑以下优化任务，则会达到类似的目标：

$$

\min_{\mathbf{z}_{n}} \quad \|\mathbf{z}_{n}\|_{0}, \text{s.t.} \quad \|\mathbf{x}_{n} - A\mathbf{z}_{n}\|^{2} < \epsilon, \quad n = 1,2,\ldots,N,

$$

![Equation](img/si273.png)

其中 *ϵ* 是一个作为误差上界的常数。

(20.66) 和 (20.67) 中的任务可以通过第 10 章中考虑的任意一种 $\ell_{0}$ 最小化求解器来求解，例如 `OMP`。这一阶段称为*稀疏编码*。

**阶段 2**：这一阶段称为*码本更新*。在阶段 1 中获得了 $\mathbf{z}_{n}, n = 1, 2, \ldots, N$（针对固定的 *A*）之后，现在的目标是针对 *A* 的列进行优化。这是在*逐列*基础上实现的。假设我们当前考虑 $\mathbf{a}_{k}$ 的更新；这是通过最小化（平方）弗罗贝尼乌斯范数 $\|X - AZ\|_{F}^{2}$ 来进行的。为此，我们可以将乘积 *AZ* 写成秩一矩阵之和，即

$AZ = \left\lbrack \mathbf{a}_{1},\ldots,\mathbf{a}_{m} \right\rbrack\left\lbrack \mathbf{z}_{1}^{r},\ldots,\mathbf{z}_{m}^{r} \right\rbrack^{T} = \sum\limits_{i = 1}^{m}\mathbf{a}_{i}\mathbf{z}_{i}^{rT},$

![Equation](img/si277.png)(20.68)

其中 $\mathbf{z}_{i}^{rT}$，$i=1,2,\ldots,m$，是 $Z$ 的*行*。请注意，在上述求和中，索引 $i=1,2,\ldots,k-1$ 对应的向量在当前迭代步骤的第二阶段固定为其最近更新的值，而对应 $i=k+1,\ldots,m$ 的向量则固定为上一迭代步骤可用的值。这种策略允许使用最近更新的信息。我们现在将针对秩一外积矩阵 $\mathbf{a}_{k}\mathbf{z}_{k}^{rT}$ 进行最小化。观察到该乘积除了涉及 $A$ 的第 $k$ 列外，还涉及 $Z$ 的第 $k$ 行；两者都将被更新。秩一矩阵的估计旨在使以下式子最小化：

$\|\mathbf{E}_{k}-\mathbf{a}_{k}\mathbf{z}_{k}^{rT}\|_{F}^{2},$

![Equation](img/si282.png)(20.69)

其中

$E_{k} := X - \sum\limits_{i = 1,i \neq k}^{m}\mathbf{a}_{i}\mathbf{z}_{i}^{rT}.$

![Equation](img/si283.png)

换句话说，我们寻求在 Frobenius 范数意义下 $E_{k}$ 的最佳秩一近似。回顾第 6 章（第 6.4 节），其解由 $E_{k}$ 的 SVD 给出。然而，如果那样做，无法保证从第一阶段更新中嵌入 $\mathbf{z}_{k}^{r}$ 的任何稀疏结构会被保留。根据 $k$-SVD，这是通过聚焦于活动集来绕过的，即仅涉及其非零系数。因此，我们首先搜索 $\mathbf{z}_{k}^{r}$ 中非零系数的位置，并令

*ω*[*k*] := {*j*[*k*], 1 ≤ *j*[*k*] ≤ *N*: *z*[*k*]^(*r*)(*j*[*k*]) ≠ 0}。

![Equation](img/si286.png)

然后，我们构造简化向量 ${\\widetilde{\\mathbf{z}}}\_{k}^{r} \\in \\mathbb{R}^{|\\omega\_{k}|}$，其中 |*ω*[*k*]| 表示 *ω*[*k*] 的基数，该向量仅包含 **z**[*k*]^(*r*) 的非零元素。稍加思考可知，在写出 *X* = *A**Z* 时，当前感兴趣的列 **a**[*k*]（作为相应线性组合的一部分）仅对 *X* 的列 **x**[*j*[*k*]]、*j*[*k*] ∈ *ω*[*k*] 有贡献。随后，我们收集 *E*[*k*] 的相应列来构造一个降阶矩阵 *Ẽ*[*k*]，该矩阵包含与 **z**[*k*]^(*r*) 的非零元素位置相关联的列，并选择 $\\mathbf{a}\_{k}{\\widetilde{\\mathbf{z}}}\_{k}^{rT}$ 以使以下式子最小化：

```
||Ẽ_k - a_k z̃_k^{rT}||_F².
```

![Equation](img/si294.png)(20.70)

执行 SVD 分解，`Ẽ[k] = U D V^T`，**a**[k] 设置为对应最大奇异值的 **u**[1]，且 `z̃_k^r = D(1,1) v_1`。因此，字典的原子以*归一化*形式获得（回顾 SVD 理论可知 `||u[1]|| = 1`）。随后，为 `z̃_k^r` 获得的更新值被放置在 **z**[k]^(r) 中的相应位置。后者现在拥有的零元素数量至少与之前一样多，因为 **v**[1] 中的某些元素可能为零。简单的论证（问题 20.3）表明，在每次迭代中误差都会减小，且算法收敛到局部最小值。该算法的成功取决于贪婪算法在第一阶段提供稀疏解的能力。正如我们从第 10 章所知，对于与 `l` 相比足够小的稀疏度水平 `T[0]`，贪婪算法效果良好。

总之，*k*-SVD 算法的每个迭代步骤包含以下计算步骤。

*   •  将 `A^((0))` 初始化为列向量归一化为单位 `ℓ[2]` 范数。

*   •  设置 `i = 1`。

*   •  *阶段 1*：求解 (20.66) 和 (20.67) 中的优化任务，以获得稀疏编码表示向量 **z**[n]，`n = 1, 2, …, N`；可使用为此任务开发的任何算法。

*   •  *阶段 2*：对于 `A^((i−1))` 中的任意列 `k = 1, 2, …, m`，按以下方式更新它：

    1.  –  识别从阶段 1 计算得到的矩阵 *Z* 的第 *k* 行中非零元素的位置。

    2.  –  选取 `E[k]` 中对应 *Z* 的第 *k* 行非零元素位置的列，形成降阶误差矩阵 `Ẽ[k]`。

    3.  –  对 `Ẽ[k]` 执行 SVD 分解：`Ẽ[k] = U D V^T`。

    4.  –  更新 `A^(i)` 的第 `k` 列为对应最大奇异值的特征向量，即 `a[k]^(i) = u[1]`。

    5.  –  通过将值 `D(1, 1)v[1]^T` 嵌入其第 `k` 行的非零位置来更新 `Z`。

*   •  如果满足收敛准则则停止。

*   •  否则，`i = i + 1`，并继续。

### 为什么叫 `k`-SVD？

名字中的 SVD 部分显而易见。然而，读者可能会好奇前面的“`k`”代表什么。正如文献 [4] 所述，该算法可被视为第 12 章介绍的 `k`-means 算法（算法 12.1）的一种推广。在那里，我们可以将代表每个簇的均值视为字典的代码字（原子）。在 `k`-means 学习的第一阶段，给定每个簇的代表后，会执行稀疏编码方案；即每个输入向量被分配到单个簇。因此，我们可以将 `k`-means 聚类视为一种稀疏编码方案，它将一个潜在向量与每个观测值相关联。请注意，每个潜在向量仅有一个非零元素，指向相应输入向量根据到所有簇代表的最小欧氏距离所分配的簇。这是与 `k`-SVD 字典学习的一个主要区别，在后者中，每个观测向量可以与多个原子相关联；因此，相应潜在向量的稀疏度可以大于一。此外，基于输入向量到簇的分配，在 `k`-means 算法的第二阶段，会执行簇代表的更新，并且每个代表仅使用分配给它的输入向量。这在精神上也类似于 `k`-SVD 第二阶段发生的情况。区别在于每个输入观测可能与多个原子相关联。正如文献 [4] 指出的，如果设定 `T[0] = 1`，`k`-means 算法可以从 `k`-SVD 得出。

### 字典学习与字典可识别性

字典学习是通过公式 (20.64)–(20.65) 中的 `ℓ[0]` 范数引入的。在更一般的设定中，字典学习任务表述如下：

```
minimize with respect to A ∈ 𝒜 and Z {||X − AZ||[F]² + λg(Z)}
```

(20.71)

其中 `g(Z)` 是矩阵 `Z` 元素的稀疏性促进函数。例如，

```
g(Z) = ∑_{i=1}^{m} ∑_{j=1}^{N} |Z(i,j)|
```

(20.72)

且 `λ` 为正则化参数。集合 `𝒜 ⊆ ℝ^(l×m)` 为紧约束集。例如，通常我们假设 `A` 的列具有单位范数。这保证了*尺度不变性*。确实，假设 `A, Z` 是一个解，若不使用任何约束，对于任意 `c` 值，集合 `A' = (cA), Z' = (1/c Z)` 也将是一个解。其他约束也可用于结合关于可用数据的额外先验知识（参见，例如，[85]）。

在实践中，解决方案包含两个阶段，这与 `k-SVD` 类似。假设在迭代步骤 `i` 时 `A^(i)` 已知，首先进行关于代码向量的最小化，即：

#### 阶段 1

```
Z^(i) = min_Z { ||X - A^(i)Z||_F² + λ g(Z) }.
```

然后，固定 `Z^(i)`，代码本更新结果为：

#### 阶段 2

```
A^(i + 1) = min_{A ∈ 𝒜} ||X - A Z^(i)||_F².
```

在最后一个方程中，稀疏促进项不参与其中，因为它与 `A` 无关。假设 `g(Z)` 为凸函数，则在每个阶段求解一个凸优化任务。此类问题被称为*双凸*问题，意指通过固定代价函数中的一个参数，关于另一个参数的优化问题变为凸问题。该优化任务的解可通过不同途径获得；例如，通过极大化-最小化（MM）技术或 ADMM 方案（第 8.14 节）；具体应用案例在各种约束条件下可参见，例如，[80, 140, 196]。

求解字典学习任务是一个非凸优化问题。一个重要的相关问题是相关局部极小值的刻画。这一任务是我们所说的*可识别性*的另一面。换句话说，假设存在一个生成数据的字典，能否将其恢复？知道该问题的答案在许多应用中至关重要。例如，在源定位任务中，字典的原子与涉及信号的到达方向相关。此外，在 fMRI 中（参见第 20.11 节），字典的原子提供与大脑激活区域相关神经元的时间响应有关的信息。文献 [86] 表明，在与稀疏性相关的特定假设下，字典学习任务中的最小化代价函数以高概率在生成数据的字典周围拥有*有保证的*局部极小值。此外，也推导出了此类极小值存在所需的充分样本数量上界。

#### 字典学习中的替代路径与相关方法

*   **通往 `k`-SVD 的替代路径：** 已有人提出了用于字典学习的、通往 `k`-SVD 的替代路径。例如，文献 [73] 提出了一种称为最优方向法的字典学习技术，它在字典更新步骤上与 `k`-SVD 不同。具体而言，该方法通过直接最小化 Frobenius 范数来更新整个字典。

*   **概率方法：** 文献 [126, 143] 采用了概率论证，利用拉普拉斯先验来强制稀疏性。正如第 13 章（第 13.5 节）所讨论的，所涉及的积分在解析上难以处理，因此使用近似来绕过这一障碍。在前者中，使用了被积函数的最大值；在后者中，采用了后验的高斯近似来处理积分。

*   **变分技术：** 文献 [82] 调用了变分界技术（参见第 13.9 节）。

*   **正交基的并集：** 文献 [125] 提出的方法与 `k`-SVD 有一些相似之处，因为它也围绕 SVD 展开，但字典被约束为正交基的并集。这可能带来计算优势；另一方面，`k`-SVD 对字典原子不施加任何约束，从而在输入建模方面提供了更大的自由度。另一个区别在于 `k`-SVD 引入的逐列更新。

*   **比较研究：** 文献 [4] 给出了 `k`-SVD 与其他方法更详细的比较研究。

*   **矩阵分解视角：** 字典学习本质上是一个矩阵分解问题，其中对右矩阵因子施加了某种类型的约束。这种方法可被视为一类更广泛的受约束矩阵分解方法的一种表现形式，该类方法允许施加多种类型的约束。此类技术包括正则化 PCA，其中在左、右因子上施加函数和/或稀疏性约束 [12, 190, 200]，以及结构化稀疏矩阵分解 [14]。

*   **在线与分布式方案：** 除前述算法外，还提出了若干 *在线* 和 *分布式* 字典学习方案。

    *   文献 [127] 开发了 `k`-SVD 算法的一个分布式版本。

    *   文献 [149] 提出了一个基于云的 `k`-SVD 版本，侧重于大数据应用。

    *   文献 [182] 描述了一种采用受 EXTRA 优化方案启发的论证（在第 8.15 节简要讨论）的字典学习算法。

    *   文献 [49] 中，各个智能体/节点学习字典的不同部分，这种方法也适用于大数据应用。

    *   文献 [139] 提出了一种用于字典学习的在线算法，文献 [53] 提出了一种具有可证明收敛到平稳点特性的分布式设置在线版本。

    *   文献 [62] 考虑了涉及一组通用约束的、随时间变化的有向图上的去中心化情况，其中多种矩阵分解方案作为特例出现。

#### 示例 20.5：基于字典学习的图像去噪
