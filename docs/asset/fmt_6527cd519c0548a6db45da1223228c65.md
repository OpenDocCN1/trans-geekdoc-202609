- 2. 利用以下公式计算欧几里得距离：

```
$d(p, q) = \sqrt{\sum_{i=1}^n (q_i^2 - p_i^2)} \quad (5.1)$
```

其中：

- **p, q**: 欧几里得 n 空间中的两点
- **qi, pi**: 从空间起点开始的欧几得向量
- **n**: 平面承载的轴数

因此，一次比较的欧几里得距离 [15,16] 可以如下所示计算：

```java
$x_1 = \sqrt{(500-2)^2 + (10-11)^2 + (500-19)^2 + (10-18)^2} = 692.4088388$
```
