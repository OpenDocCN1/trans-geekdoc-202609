## 随机梯度下降

我们在第 3 章：向量微积分中已经看到了回归/分类问题误差函数的表述。这些函数是某种形式的对数似然，可以分解为 N 个训练样本的某种逐样本损失函数之和：

```
E(w) = (1/N) ∑_{n=1}^N L(f(x_n; w), y_n)
```

在梯度下降算法中，我们随机初始化权重并根据梯度信息不断更新权重。因此，对于这些加性损失函数，我们需要计算每个训练样本处的梯度值。随着训练集规模增长到数十亿个样本，执行单次梯度步骤所需的时间变得过长。SGD 背后的直觉是梯度是一个期望。该期望可以用一小组样本来近似估计。具体来说，在算法的每一步，我们可以从训练集中均匀抽取一个小批量样本。为简单起见，假设小批量大小为 1。现在，在每一步 `t` 选择一个随机样本点 `x_n`，并通过以下方式更新权重：

```
w_{t+1} = w_t - η ∇E_n(w_t)
```

梯度的期望由以下公式给出：

```
E[∇E_n(w)] = ∇E(w)
```

我们可以互换梯度和期望的顺序，如果 `f` 是一个光滑或连续可微的函数。对于神经网络，这个假设是成立的，因为只要我们在每一层使用可微的非线性函数，所有层函数都是连续可微的。现在，选择 `n` 的概率是 `p(n)`。因此，根据期望的定义，我们有：

`E[∇f(x)] = ∇E[f(x)]`

因此，`∇E[f(x)] = E[∇f(x)]`

让我们尝试将 SGD 应用于*图 6.3*中描述的两层神经网络的训练，其中预测输出是一个标量 `ŷ`。

## 计算误差导数

我们想要计算梯度 `∇_W E`，其中 `W` 是表示网络所有 `N` 层权重的权重张量。任何误差函数 `E` 都依赖于预测输出 `ŷ`（以及给定的常数目标 `y`），因此利用导数的链式法则，我们可以写成：

`∇_W E = (∂E/∂ŷ) * (∂ŷ/∂W)`

由于 `ŷ = L^(N)(...L¹(x)...)`，我们可以将 `∂ŷ/∂W` 写为 `∏(∂L^(l)/∂L^(l-1))`。误差 `E` 关于任意层输出张量 `L^(l)` 的偏导数记为 `δ^(l)`。由于导数的链式法则（使用向量场的矩阵形式链式法则，因为 `E` 依赖于层的复合），`δ^(l)` 和 `δ^(l+1)` 之间存在递归关系：

`δ^(l) = (J^(l+1))^T δ^(l+1)`

其中 `J^(l+1)` 是雅可比矩阵。

我们可以写成 `L^(l+1) = a(L^(l))`，其中 `a` 是第 `l+1` 层的激活函数。因此：

`δ^(l) = (J_a^(l+1))^T δ^(l+1)`

像其他任何递归关系一样，必须定义递归开始的基本情况。在这里，递归从最后一层开始。我们可以将误差函数 `E` 视为一层 `L^(N+1)`，从而定义基本情况：

`δ^(N+1) = ∂E/∂ŷ`

现在，回到误差导数，我们可以用 `δ^(l)` 来表示它们：

`∂E/∂W^(l) = δ^(l+1) * (∂L^(l+1)/∂W^(l))`

关于对应层的权重向量。

**示例**：如果 `L^(l+1)` 是一个具有 `n` 个输出神经元和 `m` 个输入的 Sigmoid 层，我们可以将层函数写为 `L^(l+1) = σ(W^(l+1) x + b^(l+1))`。这里，`x` 是层 `L^(l)` 的输入向量。

因此，`J^(l+1)` 将由以下雅可比矩阵的乘积给出：

`J^(l+1) = diag(σ'(W^(l+1) x + b^(l+1))) * W^(l+1)`

这里，`∂L^(l+1)/∂W^(l+1)` 表示一阶张量对二阶张量的导数。该导数将是一个三阶张量，正如*第 3 章：向量微积分*中张量微积分部分所讨论的。我们可以用张量外积运算 `⊗` 和爱因斯坦求和约定来表示，如下所示：

`∂L^(l+1)_k/∂W^(l+1)_ij = σ'(z_k) * x_i * δ_kj`

Sigmoid 函数的导数 `σ'(z) = σ(z)(1 - σ(z))`。因此：

`∂L^(l+1)_k/∂W^(l+1)_ij = σ(z_k)(1 - σ(z_k)) * x_i * δ_kj`

利用外积的性质：`(a ⊗ b)(c ⊗ d) = (a·c)(b⊗d)`，前面的点积简化为以下形式：

`∂E/∂W^(l+1) = δ^(l+1) ⊗ (σ'(z) ⊙ x)`

***注意：误差函数 `E` 关于对应层权重 `W^(l)` 的导数可以写成来自下一层的梯度消息 `δ^(l+1)` 与该层激活函数关于权重向量的导数 `∂L^(l+1)/∂W^(l)` 的乘积。这里，`∂L^(l+1)/∂W^(l)` 是特定于层的雅可比矩阵，不依赖于任何其他层。因此，`∂E/∂W^(l)` 依赖于来自上层的导数消息，而不依赖于来自下层的消息。***

对于使用 SGD 计算误差导数，我们需要计算训练样本子集（或小批量）上的误差函数导数，然后计算小批量上的平均误差。在之前的计算中，我们计算了单个样本的导数。一个小批量可以表示为一个矩阵，其每一行代表批量中的一个训练样本。因此，`x` 现在是一个二阶张量，相应的层输出 `L^(l)` 也将是一个二阶张量。

因此，偏导数将按如下方式改变：

`δ^(l) = (J^(l+1))^T δ^(l+1)`（批量版本）

`∂L^(l+1)/∂W^(l+1)`（批量版本）

现在：

`∂E/∂W^(l+1) = (X^(l))^T (δ^(l+1) ⊙ σ'(Z^(l+1)))`

因此：

`∂E/∂W^(l+1) = (X^(l))^T (δ^(l+1) ⊙ σ'(Z^(l+1)))`

利用外积的性质：`(A ⊗ B)(C ⊗ D) = (A·C) ⊗ (B·D)`，前面的点积简化为以下形式：

`∂E/∂W^(l+1) = (X^(l))^T (δ^(l+1) ⊙ σ'(Z^(l+1)))`

我们知道点积 `e_i^T e_j = δ_ij`，因为它是矩阵的 Frobenius 范数，该矩阵只有 `(i,j)` 元素为 1，所有其他元素为 0：

`||E_ij||_F = 1`

让我们实现一下，然后将其与任何深度学习库计算的导数进行比较。在以下代码中，我们将首先使用 TensorFlow 实现 Sigmoid 层：

```python
1. import tensorflow as tf
2. batch_size = 2
3. tf.random.set_seed(42)
4. # create a Sigmoid layer with 4 output neurons
5. layer = tf.keras.layers.Dense(4, activation=tf.nn.sigmoid)
6. # create an input tensor with 3 neurons and batch size = batch_size
7. x = tf.random.normal([batch_size, 3])
8. z = layer(x)
```

输出张量 `z` 的形状为 `(2, 4)`。使用前面的层导数公式，让我们计算层输出关于层权重的导数，可以通过 `layer.kernel` 属性访问。层权重是随机初始化的。以下代码描述了这一点：

```python
1. b1, b2 = tf.eye(2).numpy()
2. # create the unit tensors ek and ej
3. e1, e2, e3 = tf.eye(3).numpy()
4. f1, f2, f3, f4 = tf.eye(4).numpy()
5.
6. # Compute Derivative
7. jacobian = None
8. y = tf.matmul(x, layer.kernel).numpy()
9. for b, eb in enumerate([b1, b2]):
10.     for k, ek in enumerate([f1, f2, f3, f4]):
11.         for j, ej in enumerate([e1, e2, e3]):
12.             tmp = tf.tensordot(ej, ek, axes=0)
13.             u = x[b][j] * tf.nn.sigmoid(y[b][k]) * (1 - tf.nn.sigmoid(y[b][k])) * ek
14.             v = tf.tensordot(eb, u, axes=0)
15.             if jacobian is None:
16.                 jacobian = tf.tensordot(v, tmp, axes=0)
17.             else:
18.                 jacobian += tf.tensordot(v, tmp, axes=0)
19. print(jacobian)
```

该计算仅使用 TensorFlow 梯度带进行一步，如下所示：

```python
1. with tf.GradientTape(persistent=True) as tape:
2.     z = layer(x)
3. jacobian = tape.jacobian(z, layer.kernel)
4. print(jacobian)
```

## 反向传播算法

让我们采用之前介绍的三层神经网络。在上一章的线性回归部分，我们了解到 `E` 是均方误差，由 `E = 1/2 ||ŷ - y||²` 给出。这里，`L¹` 是前一层的输出。此外，误差函数将针对大小为 `B` 的样本小批量进行计算。因此，我们可以用层函数来表示 `E` 如下：

`E = 1/2 ∑_b ||L^(N)(x_b) - y_b||²`

*   `∂E/∂ŷ = ŷ - y`，因此，
*   `δ^(N+1) = ŷ - y`
*   `δ^(l) = (W^(l))^T δ^(l+1) ⊙ σ'(z^(l))`

这是我们为线性回归获得的相同梯度，唯一的区别在于 `L¹` 在那里是一个固定函数。

接下来，让我们计算 `∂E/∂W^(l)`。

由于 `L^(l+1)` 是一个线性层，此处的 `W^(l+1)` 是一个连接第 `l` 层中 `n` 个神经元与第 `l+1` 层中 `m` 个神经元的权重矩阵；因此，`L^(l+1) = W^(l+1) L^(l)`。

*   `∂L^(l+1)/∂W^(l+1) = L^(l) ⊗ I`
*   `∂E/∂W^(l+1) = δ^(l+1) ⊗ L^(l)`

假设第 `l+1` 层使用 `tanh` 激活函数

`δ^(l+1) = (W^(l+2))^T δ^(l+2) ⊙ (1 - tanh²(z^(l+1)))`

该表达式的推导方式与我们推导 Sigmoid 层导数的方式相同，只是将 Sigmoid 导数替换为 tanh 导数。

我们现在拥有计算梯度下降算法所需梯度步长所需的所有梯度：`∂E/∂W^(l)`。

现在，我们将使用 TensorFlow 实现这些内容。首先，我们使用函数式 API 创建模型，如下面的代码所示：

```python
1. inp_vector = tf.keras.layers.Input(shape=(3,), name='input')
2. x = tf.keras.layers.Dense(units=4, activation='tanh',
3.                           name='hidden', use_bias=False)(inp_vector)
4. x = tf.keras.layers.Dense(units=1, activation='linear',
5.                           name='output', use_bias=False)(x)
6. model = tf.keras.Model(inputs=[inp_vector], outputs=x)
7. print(model.summary())
```

现在，像以前一样使用梯度带，我们可以直接计算损失函数关于两层中两个权重张量（`model.trainable_variables`）的梯度。这在下面的代码中展示：

```python
1. batch_size=5
2. X = tf.random.uniform([batch_size, 3])
3. Y = tf.random.uniform([batch_size, 1])
4.
5. def mse(y_true, y_pred):
6.     return 1/2*tf.reduce_mean(tf.square(y_true-y_pred))
7.
8. with tf.GradientTape(persistent=True) as tape:
9.     y_pred = model(X)
10.    loss = mse(Y, y_pred)
11. gradient = tape.gradient(loss, model.trainable_variables)
```

**表 6.2：** *所有层的误差导数计算（反向传播误差导数）*

这被称为**反向传播算法**。之所以这样命名，是因为我们向后传递信息。

***注意：前表中使用的爱因斯坦求和表示在各个反向梯度计算步骤中计算出的雅可比矩阵之间的张量点积。对于 `∂E/∂W^(l+1)` 的计算，我们没有使用推导出的张量外积公式；而是使用了 TensorFlow 梯度带 API 以保持代码简洁。我们已经展示了如何为 Sigmoid 激活实现张量点积公式，对于 tanh 激活，可以遵循相同的步骤来实现。***

到目前为止，我们只讨论并实现了三层网络的算法，但这可以轻松扩展到任意层数。我们可以使用该算法训练非常深的神经网络。对于任意一对非线性隐藏层 `L^(l)` 和 `L^(l+1)`，让我们看看计算 `∂E/∂W^(l)` 的步骤。假设网络中有 *K* 层：

1.  选择一个随机训练样本（或小批量）。
2.  通过网络执行前向计算并计算误差 E。
3.  计算输出层的 `δ^(N+1)`，即 `∂E/∂ŷ`。
4.  计算关于层权重的误差导数 `∂E/∂W^(l)`。
5.  回退一层 `l = l - 1`。
6.  使用递推关系计算 `δ^(l)`。
7.  重复步骤 4 到 6，直到到达输入层。

TensorFlow 等深度学习框架使用计算图来记忆网络中的变量依赖关系，从而记住前向计算的顺序。然后按相反的顺序遍历该图来计算导数。此过程也称为 `自动微分`。

## 训练神经网络的挑战

反向传播算法可用于训练具有大量隐藏层和每层众多节点的任何深度神经网络。然而，在实践中，我们首先需要解决许多挑战。以下列出了一些挑战及其缓解方法，以实现成功的训练。

### SGD 训练缓慢

随着网络层数的增加，大多数情况下我们会发现学习非常缓慢，这可以通过观察训练过程中损失函数下降的速率来判断。SGD 最适合凸优化问题，在这类问题中我们拥有凸误差面和唯一的全局极小值。在这些问题中，沿着负梯度方向迈出小步可以确保我们到达全局极小值。在前面的章节中，我们已经讨论了深度非线性神经网络误差面的复杂性。除此之外，还有与误差面复杂性相关的其他一些挑战：

*   **病态条件**：矩阵的*条件数*是最大奇异值与最小奇异值的比率。病态矩阵是指条件数很高的矩阵。这表明矩阵的少数几行彼此高度相关。如果我们拥有病态数据集，那么由其定义的误差面在一个或多个方向上相对平坦，而在其他方向上则弯曲陡峭。这会导致 SGD 收敛非常缓慢。可以通过监控梯度范数的平方来识别此问题。

*   **悬崖与梯度爆炸**：对于具有高度非线性激活函数的极深神经网络，误差面可能包含极其陡峭、类似悬崖的区域，如 图 6.7 所示。SGD 算法沿负梯度方向移动可能会因从悬崖上大跨步跳下而使权重偏离极远。这会误导算法，使其在我们非常接近极小值时反而远离极小值。缓解此风险的一种方法是裁剪梯度范数，即设定梯度范数的最大允许值。如果 `||g|| > threshold`，则通过重新缩放梯度为 `g * (threshold / ||g||)` 来防止梯度爆炸。图 6.7 描绘了一个假设的二维误差面在极小值附近存在悬崖及梯度裁剪的情况：

    ![](img/Image44113.jpg)

    **图 6.7：** *误差面中的悬崖与 SGD 中的梯度裁剪*

*   **权重初始化**：开始训练时，必须初始化层权重。初始点的选择会影响算法的收敛性。此外，网络中的各层必须具有不同的初始化以打破对称性，否则所有层将获得相同的梯度更新，最终学习到相同的函数。通常，偏置初始化为 0，权重初始化为随机数。这些随机数不应过大，因为这会导致非常大的值传递给 Sigmoid 等激活函数，后者输出值为 1 且在较高输入值处梯度极低。因此，学习变得非常缓慢。用低值初始化的权重会被激活函数映射为 0，面临类似的梯度平坦问题。存在各种启发式权重初始化方法，如 `Xavier 初始化`、`He 初始化`。建议参阅*延伸阅读 [1]*、*[2]*。

## SGD 的改进

误差函数具有高曲率区域和微小但一致的梯度。这是由于海森矩阵的病态条件和 SGD 的方差导致的，在这些区域学习可能会大幅减慢。以下是改进 SGD 的两类技术。

## 动量法
