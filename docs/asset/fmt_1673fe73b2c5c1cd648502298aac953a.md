
知识产权分为四类：专利、版权、商标和贸易秘密。当发明者开发了一种新型且实用的工艺或物品并获得专利时，专利将赋予持有者制造、使用、市场化和销售该工艺或物品的独家权利。版权是原始创造性表达的有形表现，无论是书籍、音乐作品、绘画甚至是建筑设计。版权保护延伸到已出版和未出版的作品。需要注意的是，根据“公平使用”原则，任何基于受版权保护作品的批评、评论或教学都可以作为侵犯版权的理由。商标也被称为品牌名称。它是企业用来区分自身或其产品与其他区别的独特术语或名称。与希望公众了解的商标不同，贸易秘密是关于公司如何生产某物的受特殊保护的数据。贸易秘密与其他知识产权形式的不同在于，其细节通常不向任何注册方或其他方披露。

![Images](img/00009.jpeg)

**注意** 知识产权法律因国家而异。例如，美国专利局颁发的专利提供的保护仅在美国领土内有效。因此，了解你运营所在地的当地知识产权法律对于了解法律保护的内容至关重要。

## 极光行动

2010 年，Google 披露其遭受了一场复杂的攻击，该攻击似乎有两个不同的目标：监控人权活动者的电子邮件通信，以及获取对敏感源代码的控制权。该行动被确定为名为“极光行动”（Operation Aurora）的大行动的一部分，与 Adobe、Juniper Networks、Northrop Grumman 和摩根士丹等知名公司的其他安全漏洞和知识产权盗窃有关。攻击者使用了 Internet Explorer 的零日漏洞、加密隧道和巧妙的混淆方法，表明这是一个 APT（高级持续性威胁）攻击者。该漏洞允许恶意软件加载到公司计算机上，此时知识产权就可以从网络中外泄。尽管有关攻击的细节有限，但 Google 声称此次行动的责任是中国政府。作为直接结果，尽管中国的互联网用户数量是美国的两倍以上，Google 仍在中国关闭了其搜索引擎服务。

## 公司机密

关于公司内部运营的信息被称为`corporate confidential information`（公司机密信息）。这可能包括关于公司架构即将变化的通信邮件、营销活动的细节，或任何其他可能不适合公开消费的信息。公司机密信息通常被称为`proprietary information`（专有信息）。你经常会在公司文件上看到标记，指示分发应受到严格控制。

### 会计数据

有关公司的财务数据需要像其他敏感数据一样进行特殊处理和保护，即使它可能不会泄露健康或个人数据。在某种程度上，财务数据提供了对组织状况的洞察，并应该以此对待。公司政策和法律指导可能规定处理和存储信息的通用程序，但你应该采取额外步骤，将会计数据与公司内部没有知情需求的人隔离开来。

### 合并与收购

关于公司即将进行的合并与收购的数据是一种敏感公司信息，其滥用通常与欺诈和阴谋有关。如果由于恶意行为者导致有关即将收购的信息被过早披露，可能会对两家公司的财务状况产生严重后果。即将被收购的公司可能会受到操纵或失去其竞争优势。如果员工因为对公司财务或尚未公开的待定收购的特权知识而交易上市公司的股票，他就触犯了一项名为`insider trading`（内幕交易）的严重犯罪，这既涉及民事处罚也涉及刑事处罚。证券交易委员会的公平披露规定强制，如果有关公司的特殊知识披露给某一个股东，则必须向公众披露。

## 章节复

无论组织规模大小，你都会成为攻击者的目标。攻击者开展其活动的方式在不断演变。个人行为者、活动团体和国家国家获取恶意软件的能力比以往任何时候都容易得多。问题不再是你*是否*会发生事故，而是*何时*发生。忽视这一事实将使你和你的组织处于危险境地。对事件的妥当规划将向你的客户、利益相关者和关键领导层表明你重视安全，并增强他们对业务系统的信心。如果发生事件，你的准备将使你能够快速识别损害范围，因为你已经识别了需要特殊处理和保护的数据，包括 PII（个人身份信息）、PHI（个人健康信息）、知识产权、公司机密信息以及你组织的财务信息。然而，准备不仅仅是安全团队的努力。这意味着你协助组织领导层传达安全策略的目标，以及员工支持该策略的作用的重要性。除了获得更顺畅恢复的好处外，针对特殊数据拥有完善的事件处理流程可能会在你的组织因未能保护敏感数据而被诉法庭时保护你免受民事或刑事程序的程序。一旦你获得了组织领导层对应急响应计划的支持，你就需要随着威胁的演变继续对其进行完善和改进。如果某一天你需要执行该计划，你将拥有信心和支持来应对挑战。

### 数字取证

`Digital forensics`（数字取证）是指收集和分析数据的过程，以确定事件发生以及是如何发生的。`forensics` 一词可以定义为一种论证练习，因此数字取证分析师的工作构建基于事实的论证来解释事件是合合理的。安全事件的调查并不非进入法庭，但几乎无法预测它是否会进入。这意味着我们应该对待每一次数字取证调查，就像它最终将面临刑事案件级别的审查标准一样。我们都知道，在尝试让关键进程恢复上线时，这并不总是可能的。美国国家司法学院确定了指导每项调查的以下三个原则：

* 为保护和收集数字证据而采取的操作不应影响该证据的完整性。

* 进行数字证据检查的人员应经过此类目的培训。

* 与数字证据的封存、检查或传输相关的活动应被记录、保存并可供审查。

#### 调查的阶段

取证调查像许多其他标准化流程一样，可以分为几个阶段。在这种情况下，我们通常识别四个阶段：封存（seizure）、获取（acquisition）、分析（analysis）和报告（reporting）。封存是控制犯罪现场和潜在证据物品状态的过程。获取是以法律允许的方式保留证据。分析在受控环境中进行，且在不不当污染证据的情况下。最后，目标是产生一份完整、准确且无偏见的报告。

**注意** 我们将数字取证分为四个阶段——封存、获取、分析和报告，尽管许多组织通过合并封存和获取将其简化为三个阶段。

#### 封存

封存的目标是确保犯罪者和调查人员都不会对证据进行任何更改。一个虽然过于简单但具有说明性的例子是，在发生谋杀的区域放置黄色“犯罪现场”胶带并派守，这样这样杀手无法回来捡带有他们指纹的弹壳。显然，数字犯罪现场的不同之处在于，当调查人员试图收集证据时，犯罪者可能继续隐形地出现在现场并做出更改。

**控制犯罪现场**

无论犯罪现场是物理的还是数字的，控制谁接触犯罪证据对于确保其完整性至关重要。以下是保护犯罪现场时应该采取的一些步骤：

* 仅允许授权人员进入现场。

* 确保每个参与技术任务的人员都接受了针对其角色的培训并获得了证书。

* 记录在犯罪现场现场的人员。

* 记录最后与系统交互的人员。

* 如果犯罪现场确实被污染了，请予以记录。污染可能不会导致推导出的证据失效，但会使案件调查变得更具挑战性。

你可以采取的最重要的步骤之一是*不要*关闭你不需要关闭的任何设备。这一规则唯一的通用例外是：你非常确定有一个运行中的进程正在蓄意破坏证据。保持设备运行有很多原因，但其中关键的一点是，内存取证（即对计算设备的主存储单元进行数字取证）在过去几年中发生了巨大的变化。虽然威胁攻击者可能会安装隐藏进程、连接或文件的根内核程序（rootkits），但在运行的内存中隐藏踪迹几乎是不可能的。此外，越来越多的恶意软件从不直接接触文件系统，而是完全存在于内存中。在未先获取内存内容的情况下关闭设备，可能会导致无法准确还原事件。

![Images](img/00009.jpeg)

**注意** 为了获取易失性内存，你可能需要对计算机进行一些更改，这通常包括连接外部设备和执行程序。只要你记录了你所做的一切，这就不应导致证据在法庭上不可接受。

另一个重要（尽管看似平凡）的步骤是记录设备周围的整个物理环境。一个简单的方法是对现场拍摄大量照片。这里列出了你通常想要拍摄的特定。无论你是否拍照，都应该记录笔记，不仅描述环境，还要描述你的团队获取证据时采取的每一个动作。

* 显示运行程序的电脑桌面（如果设备已解锁）

* 连接到设备的外围设备（例如 U 盘和外部硬盘）

* 设备的紧邻环境（例如物理桌面）

* 设备的近邻环境（例如房间或隔间）

### 战地故事：一画胜于千言……

我们曾与一位联邦执法探员谈论犯罪现场摄影的最佳实践。他描述了一个案件，他搜查了一名嫌疑人的家并缴获了大量证据，包括几十张 CD 盘。当他们试图获取硬盘内容时，发现它受到强力全盘加密的保护。他们向嫌疑人索要密码，但嫌疑人高兴地告诉他们他不知道。我们的朋友不可置信地询问这怎么可能。嫌疑人回答说，他从未背过密码，因为那只是每张 CD 盘标题的第一个字母。令他恐惧的是，我们的朋友意识到他没有拍摄任何显示这些 CD 盘顺序的照片，而这些磁盘在处理过程中被弄乱了。

### 监管链

### 服务器

对服务器进行取证分析与工作站需要处理额外的问题。首先，可能无法将服务器离线并移至安全的分析室。相反，你可能别选择在现场进行简要分析。*现场取证*（live forensics，或现场响应）是在在整个调查期间保持运行的设备上进行数字取证。我们在之前描述在关闭设备之前捕捉易失性内存内容的重要性时，已经提到了相关问题。如果你无法将服务器从生产环境中移除，那么最好的办法就是捕捉其内存内容和感兴趣的文件（例如日志文件）。

处理服务器时的另一个考虑因素是，它们的存储空间（主存和次要存）通常比工作站多得多。这保证了过程会更长，但也可能需要特殊工具。例如，如果你的服务器使用冗余廉价阵列（RAID），你可能需要专用工具来处理这些磁盘。除了硬件差异，你还需要考虑运行在服务器上的软件的特定架构。Microsoft Exchange Server 拥有许多帮助取证调查员的功能，但该人员必须熟悉 Exchange 复杂的架构。这一点对于数据库管理系统（DBMS）和公司内部 Web 应用同样适用。

### 移动设备

如今，犯罪调查中不包含移动设备取证已属罕见。虽然这在企业世界较少见，但你应该意识到移动设备带来的独特挑战。主要挑战是，除非你关闭电源，否则设备将继续与网络通信（我们已经说过这可能不是个好主意）。这意味着犯罪分子可以远程删除设备或对其进行篡改。解决此问题的方法是将设备放入法拉笼容器中，防止其通过无线电通信。法拉笼袋具有吸收射频（RF）能量并重新分配的特殊属性，可以防止容器内设备与外部之间的通信。显然，在你缴获设备后，你还需要一个更大的法拉笼设施来对设备进行分析。

#### 提取

`Forensic acquisition` 是从扣收的证据中提取数字内容以便对其进行分析的过程。这通常被称为对硬盘进行取证镜像，但实际上包含的内容不仅于此。你想要提取内容的主要原因是你希望在证据的副本上进行分析，而不是在原始证据上。在整个过程中，保持原始证据的完整性至关重要。为了以一种保护和保存证据的方式获取原始数字证据，通常认为以下步骤是最佳实践：

### 1. **准备目标媒体。** 你需要一个地方来存储被扣收证据的数字内容。该目标可以是移动式硬盘或存储区域网络（SAN）。你必须确保目标介质没有任何可能污染证据的内容。做到此点的最佳方法是使用固定模式的 1 和或 0 覆盖介质，对其进行安全擦除。

### 2. **防止原始数据发生变化。** 仅仅将设备连接到计算机或复制器这一操作，通常会导致其内容发生微小但可能具有重大影响的变化。为了防止任何变化，你必须使用写保护机制，例如硬件写保护器（在本章稍后部分将描述）。某些取证采集软件产品支持基于软件的写保护，但使用物理保护器几乎总是更好的。

### 3. **对原始证据进行哈希处理。** 在复制任何内容之前，你应该对原始证据进行加密哈希处理。大多数产品支持`MD5`和`SHA-1`哈希。尽管这些协议已被证明容易受到碰撞攻击且不再建议用于通用，但我们尚未看到法院在刑事审判中对其可采性提出过异议。

### 4. **复制证据。** 各种应用程序都可以让你对数字介质进行取证复制，包括 Linux 系统中资老的`dd`工具。这些应用程序的共同点是它们对整个源介质执行完全二进制拷贝。仅复制文件是不够的，因为你可能无法获取删除或未分配空间中的相关数据。

### 5. **验证采集结果。** 复制完成后，对副本进行加密哈希处理并与原始数据进行比较。只要它们匹配，你就可以对副本进行分析，并确保它与原始完全相同。
