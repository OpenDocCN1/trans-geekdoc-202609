
### 定义 2.2.
设 `M` 为状态集，代表学习过程中的各种状态（包括初始状态和目标状态）`{m_0, m_1, ...}`，其中 `m_i` (`i = 0, 1, ...`) 是学习过程中不同时刻的状态。

### 定义 2.3.
设 `T_i` 为操作算子，代表学习过程中的一种状态操作。该算子的每次操作使学习问题从一种状态转移到另一种状态。从初始状态 `m_0` 到目标状态 `m_g` 所使用的操作算子序列 `T_0, T_1, ..., T_{g-1}` 是学习问题的一个解。

进一步地，`G_n` 是状态转移函数集合；`G_n = {T_0, T_1, ...}` 表示学习过程中的每一步（操作算子）集合，或者可以理解为学习问题在不同阶段的完成程度的表示。

### 定义 2.4.
学习子空间：特定学习问题的空间描述，即学习空间的子集，包括学习该问题的所有可能学习路径。它由四元组 `⟨M, G_n, P, C⟩` 表示，其中 `P` 是样本数据集，即要学习的对象，`C` 是目标函数，`M` 是状态集，`G_n` 是状态转移函数集。

### 定义 2.5.
设 `E` 为从一种状态到另一种状态的学习问题的代价。当整个学习过程的总代价 `∑_{i=0}^{g-1} E(T_i)` 最小时，所得到的轨道（路径）即为最优轨道。

### 定义 2.6.
轨道：已经学习过的对象构成一条路径，即学习路径；它是学习过程的一种几何描述。学习子空间中必然存在一条涵盖学习过程中一系列学习操作（算子）的学习路径。它由三元组 `(L(M), F, E)` 表示，其中 `L(M)` 代表学习路径经过的状态集，且 `L(M) ⊂ M`；`F` 代表学习路径中使用的状态转移函数集，且 `F ⊂ G_n`；`E` 是轨道学习代价。

所有轨道构成整个学习子空间；状态子集及其使用的算子构成一个轨道，一个轨道构成一个偏序链。

### 定义 2.7.
目标轨道：能够正确分类样本数据的最优（近似最优）学习路径，即期望由学习算法从学习子空间中选择的学习函数（集合），是解决学习问题的目标。

学习的目的是寻找从初始状态到目标状态的最优路径。如果将每个状态视为一个节点，学习子空间可以用有向图表示。该图不一定是完全连接的，即某些状态可能无法到达另一个状态，但在连通状态下，每条边代表一个算子，可以实现状态的操纵（即通过连通性实现状态的转移）。当解决特定问题时，可以根据不同的问题为算子设置特定的代价。如果存在一条从初始状态（节点）指向目标状态（节点）的路径，则表示目标状态的学习问题是可解的。在图结构中，树是一种特殊的有向图，任意两个节点之间只有一条路径。树只有一个起始节点（根节点），且树的路径没有回路。因此，树避免了有向图中无法到达目标状态的情况（只要存在目标状态）。树的每个分支形成一个偏序集，构成一个轨道，终端（叶）节点是最大（最小）节点。当然，某些状态可以同时由其他状态生成，即学习子空间是图（或网络）结构，而树是对其的一种特殊描述。根据节点间的连接关系，可以使用相应的矩阵来表示节点间的代价，通过矩阵元素的值来表示。我们在李群中将每个群表示为矩阵，并通过不同群的性质和操作实现解决问题的过程，这可以在李群学习问题中观察到，并通过映射的结构进行研究。李群的学习问题可以从图结构中进行研究。

### 定理 2.2.
*现实问题可以由学习子空间描述，且学习子空间包含所有可能的轨迹。如果问题是可解的，则必须从中找到一条学习路径，以及最优（近似最优）学习路径 [18]。*

*证明。* 学习问题被映射到对应的学习子空间。从问题的初始状态出发，在学习过程中，针对轨道划分的每一步，描述当前状态的所有可能下降状态，并根据确定最佳状态的具体标准进行进一步划分，直到找到目标轨道，这确保了我们能够找到期望的轨道。需要注意的是，在具体的学习算法中，考虑到计算时间和存储空间，在大规模学习问题中通常不会扩展所有状态，但无论它是全局优化问题还是局部优化问题，都必须根据学习问题的信息找到最优（近优）轨道。

在处理学习问题时，我们不仅要找到目标，还要找到最优路径（最小成本）。只要目标轨道存在，当目标轨道被找到时，该轨道生成算法被称为可接受的。

学习过程可以描述为不同的状态，状态转换可以通过操作（算子）来实现。因此，从初始状态到目标状态必须存在一条路径；存在多条路径，且至少有一条路径相对于其他路径是最短（最优）的。

在学习算法中，为了生成描述树或图结构的学习子空间的节点顺序，我们可以考虑以下两种情况：深度优先和广度优先。广度优先算法逐层生成学习子空间，即只有当某一层的状态完全生成后，才会转移到下一层。由于广度优先必须扩展到该层的所有状态后才能进入下一层，首个生成的状态会首先被扩展，因此广度优先算法可以确保找到从初始状态到目标状态的最短路径。因此，第二次到达某个状态时，路径长度必须大于或等于之前到达该状态的路径长度，因为一条好的路径不会多次进入同一个状态；当第二次到达某个状态时，它只是放弃该路径。相比之下，在深度优先算法的情况下，当生成一个状态时，在其兄弟状态之前，必须生成其所有子状态和子状态的 descendant 节点。在学习子空间的生成中，深度优先算法尽可能深入。它不仅生成该状态的 descendant 状态，还可以考虑其兄弟状态。深度优先确保首次遇到某状态的路径是到达该状态的最短路径。对于任何状态，都有可能找到到达它的另一条路径。如果路径的长度（或成本）对学习至关重要，当多次遇到相同状态时，应保留最短路径。对于全局生成，广度优先算法必须能够找到最佳路径。深度优先算法在局部生成解决方案；虽然其学习效率较高，但不一定能找到最佳路径。

由于广度优先会扩展每一层的所有状态，因此需要足够的空间来存储这些状态节点。当使用深度优先时，节点沿单一路径向下生成，只有当没有下降状态时，才考虑另一条路径。这种方法不利于通过最优路径从初始状态到达目标状态，且对于许多问题，生成的深度可能无限深或容易跟随无利可图的路径。因此，在轨道生成过程中，广度优先和深度优先方法具有某种盲目性。因此，为了有效识别学习轨道，需要一些与特定学习领域相关的特殊信息，即启发式信息 [3]，它引导这一学习过程朝着最有希望的方向进行。 □

### 定义 2.8.
设 `f(x)` 为估值函数，它表示从初始状态 `m_0` 到目标状态 `m_g` 的状态 `x` 的最优轨道的成本估计。一般形式为 `f(x) = g(x) + h(x)`，其中 `g(x)` 是从初始状态 `m_0` 到状态 `x` 实际支付的成本，`h(x)` 是从状态 `x` 到目标状态 `m_g` 的最优轨道的估计成本，也称为启发式函数。

我们使用估值函数来确定在每次状态扩展中最有可能到达目标状态的扩展状态。它可能会沿着被认为最有希望的某个边缘区域向外扩展。利用启发式信息，我们可以从初始状态找到到目标状态的最优路径。由于无需盲目扩展所有可能的状态，因此只需沿着最有希望的状态到达目标状态即可。因此，生成的范围相对较小，且所需的存储空间也相对较小。

根据学习的具体性与一般性之间的关系，学习子空间表示为偏序形式。偏序集的最大元是学习子空间中最一般的点，即描述为零的点。这样的点对学习示例没有任何限制；因此，它可以描述任何东西。偏序的最小元是学习子空间中最具体的点，即它对应于学习样本（样本本身可以被视为一个具体概念）。

因此，学习样本集 `P` 被视为标准化为偏序，并根据需要映射到对应的学习子空间，以便它可以对应于合理的操作算子集 `F` (`F ⊂ G_n`)。然后，我们使用偏序集理论来概述这类学习问题。

### 定义 2.9.
设 LML 样本数据集 `P` 为一个非空集，`≽` 为定义在 `P` 上的二元关系。若满足公理 P01–P03，则 `P` 称为偏序集，`≽` 称为 `P` 上的偏序（简称序）。

- P01: 对于任意 `x ∈ P`，不存在 `x ≽ x`；
- P02: 对于任意 `x, y ∈ P`，若 `x ≽ y` 且 `y ≽ x`，则 `x = y`；
- P03: 对于任意 `x, y, z ∈ P`，若 `x ≽ y` 且 `y ≽ z`，则 `x ≽ z`。

若在上述三个公理的基础上，也满足公理 P04，则 `P` 称为全序集或链，且 `≽` 称为 `P` 上的全序。

- P04: 对于任意 `x, y ∈ P`，`x ≽ y` 和 `y ≽ x` 中至少有一个成立。

设 `T` 为偏序集 `P` 的子集，`m ∈ T`，若不存在 `x ∈ T` 使得 `m ≺ x`（`m ≻ x`），则称 `m` 为 `T` 的最大元（或最小元）。若对于所有 `x ∈ T`，`m ≽ x`（`m ≼ x`），则称 `m` 为 `T` 的上界（或下界）。若 `u ∈ P`，对于所有 `x ∈ T`，即 `u ≽ x`（或 `u ≼ x`），则称 `u` 为 `T` 的上界（或下界）。注意，`T` 的上界（或下界）不一定属于 `T`。若 `u` 是 `T` 的上界，且对于 `T` 的任意上界 `v` 都有 `v ≽ u`，则称 `u` 为 `T` 的上确界，`T` 的下确界也可类似定义。根据 P02（注：原文此处标号有误，应指 P02 的反身性或 P03 的传递性，通常序关系上确界唯一由序的性质保证），若 `T` 有上界（或下界），则上界（或下界）必须唯一，记为 `sup T`（或 `inf T`）。同样，`T` 的上确界（或下确界）不一定属于 `T`。

若 `x, y ∈ P` 且 `x ≽ y`，其中 `[x, y] = {z ∈ P | x ≽ z ≽ y}`，则 `[x, y]` 称为以 `x` 和 `y` 为端点的区间，且 `x ≺ y`。

若 `x, y ∈ P`，`x ≺ y`，且不存在 `z ∈ P` 使得 `x ≺ z ≺ y`，则称 `y` 覆盖 `x`，记为 `x ≺≺ y`。

示例中的样本集 `P` 是一个偏序集，且 `m_3` 是它的一个子偏序集。进一步地，`m_321` 是 `m_3` 的最小元和下界，`[m_321, m_3]` 称为区间，且 `m_32` 覆盖 `m_321`。

例如，在人脸识别中，使用眼睛、鼻子、嘴巴等局部特征来识别人脸。这些特征从不同角度进行研究。当从上往下看，即考虑“高于”的位置关系来描述偏序 `≽` 时，我们得到 眼睛 `≽` 鼻子 `≽` 嘴巴。相反，在从下往上的观察情况下，我们得到 嘴巴 `≽` 鼻子 `≽` 眼睛。当然，这些局部特征通常呈矩形。从独立个体观察的角度看，它们彼此分离，即没有交集。然而，从邻域观点来看，它们是连续的，即它们的并集构成整张脸。

作为另一个例子，我们考虑构成程序的语句 `a_1`， `a_2`，...， `a_i`，...， `a_n`。语句具有特定的执行顺序，且大多数语句之间存在关系，即仅当执行语句 `a_i` 时，才能执行语句 `a_{i+1}` 并得到相应结果，这种语句之间的执行顺序可以定义为偏序。在程序执行期间，某些语句的顺序可以改变，或者可以使用其他语句来实现，但在局部（子）块（如 `a_i … a_j`）中，它们通常处于偏序关系中，即“之前”。进一步地，`[a_i, a_j]` 称为区间，且 `a_{i+1}` 覆盖 `a_i`。

### 定义 2.10.
设 LML 样本数据集 `P` 为一个偏序集，`P'` 为 `P` 的一个非空子集。显然，`P'` 对于 `P` 的偏序来说也是一个偏序，称为 `P` 的子偏序集。

包含有限数量元素的链（即全序集）称为有限链；否则称为无限链。

若偏序集 `P` 的子偏序集 `S` 是一个链，则 `S` 称为 `P` 的链。

设 `P` 为偏序集，`x`，`y ∈ P`，且 `x < y`。若存在 `x = x_0`，`x_1`，…，`x_n = y`，使得

```
x = x_0 < x_1 < x_2 < … ≤ x_n = y   (2.1)
```

其中 `x` 称为链的起点，`y` 称为终点，称为 `x`，`y` 链，`n` 称为其长度。

若 `x_i ≺ x_{i+1}`，则链 (2.1) 称为 `x`，`y` 的最大链。若

```
x = x'_0 < x'_1 < x'_2 < … < x'_m = y   (2.2)
```

也是以 `x` 为起点、`y` 为终点的链，且每个 `x_i` (`1 ≤ i ≤ n`) 都出现在 (2.2) 中，则 (2.2) 称为 (2.1) 的细化。假设以 `x` 为起点、`y` 为终点，以 `y` 为终点的链可以细化为最大链，且以 `x` 为起点、`y` 为终点的最大链的最大长度存在，记为 `d(x, y)`。显然，`d(x, x) = 0`。若以 `x` 为起点、`y` 为终点的链不能细化为最大链，或者以 `x` 为起点、`y` 为终点的最大链的长度无最大值，定义 `d(x, y) = ∞`。若以 `x` 为起点、`y` 为终点的链可以细化为最大链，且以 `x` 为起点、`y` 为终点的最大链长度相等，令 `l(x, y) = d(x, y)`，并称从 `x` 到 `y` 为“长”。

在上述判断狗是否危险的例子中，`m_321 < m_3 < P` 是以 `m_321` 为起点、`P` 为终点的链，且它可以细化为 `m_321 < m_32 < m_3 < P`。

在学习问题中，虽然样本数据有时非常大，但研究对象往往是有限的。设 `x` (`x_0`) 为样本的初始状态，`x_1 … x_{n-1}` 为学习过程中生成的状态，`Y(x_n)` 为目标状态，`n` 为生成的轨道长度。若以轨道长度作为度量，(2.2) 在轨道 (2.1) 的形式上优于 (2.1)，因此以每种状态下生成的价格为标准，比较两者的成本。`d(x, y)` 是学习轨道的最大可能长度。

### 定义 2.11.
若对于任意 `a, b ∈ P`，且 `a < b`，所有以 `a` 为起点、`b` 为终点的最大链都具有相同的有限长度，则称偏序 `P` 满足 Jordan-Dedekind 条件，简称 `JD` 条件。

当状态 `a` 到状态 `b` 的状态不同（或不完全相同）但轨道上的状态数量相同，即轨道长度不变时，满足 `JD` 条件。
