
```
(1.1) x_i^{t+1} = x_i^t + v_i^{t+1}
```

其中 `t` 是代数，`v_i^{t+1}` 和 `x_i^t` 分别表示第 `i` 个粒子的速度和位置；`ω` 被称为惯性权重 [74]，`c_1` 和 `c_2` 是加速度系数 [75]，`r_1^t` 和 `r_2^t` 是两个在 `[0, 1]` 范围内随机生成的向量，其中 `n` 是搜索空间的维度；`pbest_i^t` 和 `gbest^t` 分别表示第 `i` 个粒子的个体最优和群体的全局最优。运算符 `⊙` 是哈达玛积，对两个相同大小的向量进行逐元素乘法。

## 1.4 总结

本章概述了优化问题如何随着科学、工程和工业的现代化而变化。随着优化问题变得日益复杂，研究人员尝试从自然界中寻找可能的解决方案，以开发自然启发的优化算法，例如进化算法（`EAs`），这是一个代表性的族。

然后，本章根据决策变量的数量或目标的数量，对不同类型的大规模优化问题进行了总结。本书主要关注具有大量决策变量的 `MOPs`，即大规模多目标/许多-多目标优化问题（`LSMOPs`）。

一方面，为了为求解 `LSMOPs` 定制 `EAs`，相关工作与 `MOEAs` 具有密切联系。虽然传统的 `MOEAs` 是为了解决决策变量规模较小的问题而开发的，但其背后的核心机制为进化大规模多目标优化的进一步发展奠定了基础。另一方面，在处理大规模决策变量时，也从单目标优化文献中借鉴了思想。特别是，“分治”策略是处理决策变量最具代表且有效的方法之一。当与 `EAs` 结合时，“分治”策略通常在基于决策变量分组方法的基础上，在 `CC` 框架内部实现。

本书的其余部分结构如下：第 2 章介绍了进化大规模多目标优化的某些背景知识；第 3 章和第 4 章分别介绍了针对通用和稀疏大规模多目标优化的若干代表性 `EAs`；第 5 章–第 9 章介绍了进化大规模多目标优化在复杂网络社区检测、物流调度、电力系统、放射治疗计划和深度学习等领域的若干代表性应用。

# 2 演化大规模多目标优化

## 2.1 引言

大规模多目标优化问题（`LSMOPs`）是指既具有大量决策变量又具有多个冲突目标的优化问题子集。这类问题广泛存在于许多应用中。例如，在旨在最小化链路间密度和最大化链路内度的社区检测中，网络节点数量通常在万级以上 [1, 2]。在旨在最小化网络复杂性和最大化预测精度的深度神经网络训练中，通常有数百万权重需要训练 [3]。同样，逻辑调度问题 [4, 5]、电力系统 [6]、放射治疗计划 [7] 以及许多其他现实应用也显示出了 `LSMOPs` 的特征。

目前，对于 `LSMOPs` 的变量数量尚未形成统一意见，这些数量可能有所不同。在书中，`LSMOPs` 被定义为具有至少两个冲突目标的优化问题。通常，`LSMOPs` 比具有少数决策变量的问题更难处理。一方面，随着变量数量的增加，多目标演化算法（`MOAs`）容易过早收敛到局部最优 [8]。另一方面，随着变量数量的扩大，决策变量之间交互的概率增加，使得景观变得更加复杂 [9]。

在过去的几十年里，大量的精力集中在研究大规模单目标问题（`LSOPs`）上。许多测试问题是为大规模单目标 [10]–[14] 设计的。解决 `LSOPs` 的方法也取得了显著进展，主要包括基于分解和非基于分解的方法 [15]–[17]。最近，随着计算能力的提高，人们越来越关注使用多目标演化算法（`MOEAs`）来解决 `LSMOPs`。虽然设计了不同类型的大规模多目标基准测试问题，但一些有前景的 `MOEAs` 也针对解决 `LSMOPs` 定制。此外，某些具有特定属性的 `LSMOPs` 被广泛研究，特别是具有稀疏最优解的问题。稀疏大规模多目标优化问题，即稀疏 `LSMOPs`，是指一类 Pareto 最优解中的决策变量大部分为零值的 `LSMOPs`。作为 `LSMOPs` 的一个新兴研究课题，一些基准测试问题和许多 `MOEAs` 也针对稀疏 `LSMOPs` 开发 [18]。

本章其余部分的结构如下：第 2.2 节给出了大规模多目标优化的基准测试问题，第 2.3 节介绍了评估 `MOEAs` 解决 `LSMOPs` 性能的常用指标。第 2.4 节介绍了为稀疏大规模多目标优化量身定制的测试问题，随后在第 2.5 节中介绍了一种可以同时评估解收敛性、稀疏性和多样性的性能指标。最后，第 2.6 节以简要总结结束本章。

## 2.2 大规模多目标优化测试问题

在本节中，首先给出一些与多目标优化相关的基本概念。然后，我们将介绍一些用于大规模多目标优化的测试问题。

### 2.2.1 基本概念

为了更好地模拟现实世界的问题，基准测试套件应该尽可能捕捉许多问题特征，包括适应度景观、变量交互、Pareto 前沿几何形状、目标函数的可分性等。下文将详细介绍一些与大规模多目标测试问题相关的基本概念。

- `适应度景观`。求解多目标优化问题的目标是在决策空间中获得一组折中解，而这些解的质量通常在目标空间中进行评估。从决策空间到目标空间的映射定义了适应度景观。

![图 2.1 单峰函数和多峰函数的示例](images/c02f001.png)

**图 2.1** 单峰函数和多峰函数的示例。(a) 最小化 `f(x) = x² - 1`，`x ∈ [-5, 5]`。(b) 最小化 `f(x) = x² + sin(10πx)`，`x ∈ [-5, 5]`。

- `模态`。模态与目标函数的局部最优解数量有关。具体来说，如果一个目标函数有多个局部最优解，则称为`多峰的`；如果只有一个最优解，则称为`单峰的`。图 2.1 提供了单峰函数和多峰函数的示例。通常，多峰函数比单峰函数更难优化，因为解容易陷入多峰函数中的局部最优解。

![图 2.2 欺骗性函数和有偏的多目标优化问题的示例](images/c02f002.png)

**图 2.2** 欺骗性函数和有偏的多目标优化问题的示例。(a) 最小化 `f(x) = -0.9x² + (5|x|^0.001/5^0.001)²`，`x ∈ [-5, 5]`。(b) 最小化 `f_1(x_1, x_2) = x_1^5 + x_2`，`f_2(x_1, x_2) = x_1^5 + 1 - x_2`，`x_1, x_2 ∈ [0, 1]`。

- `欺骗性`。对于多峰函数，存在一种特殊情况，即欺骗性函数，它至少有两个最优解，即一个真最优解和一个欺骗性最优解。此外，大部分搜索空间必须倾向于欺骗性最优解。图 2.2(a) 给出了欺骗性函数的示例。

- `偏差`。偏差属性用于描述决策空间中均匀分布的解样本是否映射到目标空间中均匀分布的解集。如果不是，则从帕累托集到帕累托前沿的映射就被认为是`有偏的`。

- `退化`。不同多目标优化问题的帕累托前沿几何形状通常是多样化的（例如：线性、凹、凸、不连通和混合）。在这些几何形状中，存在一种特殊的帕累托前沿，即退化帕累托前沿，其维度低于其嵌入的目标空间维度。例如，在双目标优化问题中，由若干点组成的前沿是退化的，而由曲线组成的前沿不是退化的。在三目标优化问题中，由曲线组成的前沿是退化的，而由二维曲面组成的前沿则不是退化的。图 2.3 提供了不同几何形状的帕累托前沿示例。

- `不可分性`。不可分性描述了决策变量之间的依赖关系。如果满足以下条件，则认为决策变量 `x_k` 在目标函数 `f(x)` 上是`可分的`：

  ```
  (2.1) f(x) < f(x′) ⇒ f(y) < f(y′)
  ```

  其中 `x = (x_1, …, x_k, …, x_n)`，`x′ = (x_1, …, x_k, …, x_n)`，`y = (y_1, …, y_k, …, y_n)`，`y′ = (y_1, …, y_k, …, y_n)` 是四个不同的决策向量。否则，决策变量 `x_k` 在目标函数 `f(x)` 上是`不可分的`。如果每个决策变量都是可分的，则对应的目标函数就是可分目标。相反，如果每个决策变量都是不可分的，则对应的目标函数就是不可分目标。一种特殊情况是不可分变量只与某些决策变量相互作用，此时对应的目标函数是部分可分目标。

### 2.2.2 多目标测试问题

在早期，针对大规模多目标优化的算法性能通常在最初为多目标优化设计的问题上测试，例如 Zitzler、Deb 和 Thiele（ZDT）基准集 [19]、Deb、Thiele、Laumanns 和 Zitzler（DTLZ）基准集 [20] 以及游鱼群（WFG）基准集 [21]。

作为最早为多目标优化设计的基准集之一，ZDT 基准集包含六个双目标测试问题 [19]。它们具有相同的结构，并由三个函数组成，即：分布函数 `f_1`、距离函数 `g` 和形状函数 `h`：

```
(2.2) Minimize F(x) = (f_1(x_1), f_2(x)),
      subject to f_2(x) = g(x_2, …, x_n) h(f_1(x_1), g(x_2, …, x_n)),
      where x = (x_1, …, x_n).
```

分布函数 `f_1` 用于维持多目标优化算法（`MOEA`）的多样性，它只与 `x` 的第一个变量相关。函数 `g(x)` 与其余 `n-1` 个变量相关。函数 `h` 决定了帕累托前沿的形状，其输入为 `f_1(x_1)` 和 `g(x)`。从表中可以看出，ZDT 问题在帕累托前沿和景观方面具有多样性，但在目标函数可分性上都是可分的。

尽管 ZDT 基准被广泛用于评估 `MOEA` 的性能，但 ZDT 测试问题的一个局限性是它们是不可扩展的。考虑到现实世界中的许多问题具有三个或更多目标，且 `MOEA` 需要证明其有效性，Deb 等人提出了另一个基准集，即 DTLZ 基准集 [20]。所有的 DTLZ 问题都遵循一种通用设计，其中前 `M-1` 个变量定义了帕累托前沿，剩余的 `n-M+1` 个变量控制收敛性。七个 DTLZ 测试问题的 `n` 和 `M` 信息如表 2.2 所示，值得注意的是，在问题公式中，最后 `n-M+1` 个变量被表示为 `x_M`。从表中可以看出，DTLZ 基准集比 ZDT 基准集捕捉了更多样化的特征。例如，虽然 DTLZ 测试问题具有退化的帕累托前沿和偏置景观，但 ZDT 测试问题并未捕捉到这些问题特征。此外，从问题公式可以看出，每个 DTLZ 测试问题都可以扩展到任意数量的目标。但是，所有的 DTLZ 测试问题在目标函数可分性上仍然是可分的。

除了 ZDT 和 DTLZ 基准测试套件外，其他一些基准测试套件也被用于大规模多目标优化的性能评估。例如，在 WFG 基准套件 [21] 中，某些问题引入了决策变量相互作用，这使得它们与现实世界的问题更加一致。BT 基准套件 [22] 专门用于测试多目标进化算法（`MOEAs`）求解具有偏差景观的多目标优化问题的性能。在九个 BT 测试问题中考虑了两种偏差，即位置相关的偏差和距离相关的偏差。MaF 基准套件 [23] 设计用于评估 `MOEAs` 在三个目标以上问题上的性能。在 15 个 MaF 测试问题中，捕捉了现实应用中广泛存在的各种问题特征。

尽管上述介绍的基准套件有效促进了演化多目标优化的研究，且其中一些被用作大规模多目标优化的测试问题，但大多数都是通过在目标空间中引入困难来设计的。很少有考虑到巨大决策空间带来的挑战。具体而言，一方面，某些问题在决策空间中不具有可扩展性；另一方面，虽然某些问题可以扩展到任意数量的决策变量，但决策变量是可分离的，没有复杂的变量相互作用。因此，它们不适用于评估 `MOEAs` 求解大规模多目标优化问题（`LSMOPs`）的性能，但这些问题在许多实际应用中广泛存在。为此，专门为大规模多目标优化设计了一些基准测试问题，这些将在第 2.2.3 节中详细介绍。
