
# 数据科学家和机器学习执业人员在不同的特征工程活动上花费了大量时间

选择正确的特征对于机器学习模型的成功起着至关重要的作用。显而易见，特征构建扩展了特征空间，而特征提取和特征选择则减小了特征空间。

## 4.2 特征转换

构建良好的特征空间是任何机器学习模型成功的关键先决。然而，通常并不清楚哪个特征更重要。因此，数据集中的所有可用属性都被用作特征，并将识别重要特征的任务留给学习模型。这绝对不是一种可行的方法，特别是对于某些领域，例如医学图像分类、文本分类等。如果必须训练模型来将文档分类为垃圾邮件或非垃圾邮件，我们可以将文档表示为词袋。那么，特征空间将包含跨越所有文档的所有唯一单词。这将很容易成为包含几十万个特征的特征空间。如果我们开始在单词中加入双词（`bigrams`）或三词（`trigrams`），特征数量将达到百万级。为了解决这个问题，特征转换派上了用场。特征转换被视为降维的有效工具，从而提升机器学习模型的性能。总体，特征转换有两个不同的目标：

* 实现数据集中原始特征的最佳重建
* 在学习任务中实现最高效率

### 你知道吗？

在自然语言处理领域，`n-gram` 是文本块或文档中连续的 `n` 个项目。使用数字前缀，大小为 1 的 `n-gram` 称为单词（`unigram`，即单个单词），大小为 2 的称为双词（`bigram`，即两个词的短语），大小为 3 的称为三词（`trigram`，即三个词的短语）等等。

### 4.2.1 特征构建

特征构建涉及将给定的输入特征集转换以生成一组更强大的新特征。为了更清楚地理解，让我们以一个房地产数据集为例，该数据集包含特定区域内所有公寓的详情。

数据集有三个特征——公寓长度、公寓宽度和公寓价格。如果它被用作回归问题的输入，此类数据可以作为回归模型的训练数据。因此，给定训练数据，模型应该能够预测价格未知或刚上市的公寓的价格。然而，使用公寓的长度和宽度作为预测器，不如使用公寓面积要方便得多且更有意义，而面积并不是数据集中现有特征。因此，可以将这样的特征，即 `apartment area`（公寓面积），添加到数据集中。换句话说，我们将三维数据集转换为四维数据集，将新“发现”的特征公寓面积添加到原始数据集中。这在图 4.2 所示。

#### 4.2.2.1 主成分分析

正如我们所见，每个数据集都有多个属性或维度——其中许多属性之间可能具有相似性。例如，人的身高和体重通常是密切相关的。如果身高较高，通常体重也较高，反之亦然。所以，如果一个数据集具有身高和体重两个属性，显然预计它们会有很大的相似性。通常情况下，相关属性或特征的数量越少，任何机器学习算法的表现就越好。换句话说，机器学习成功的关键在于特征的数量较少，且彼此之间的相似性非常低。这是主成分分析（`PCA`）特征提取技术的主要指导哲学。

在 `PCA` 中，从原始特征中提取出一组性质上非常不同的新特征。因此，`n` 维特征空间被转换为 `m` 维特征空间，其中维度之间是正交的，即彼此完全独立。为了理解正交性的概念，我们必须回溯并深入研究线性代数中的向量空间概念。

我们都知道，向量是一个既有大小又有方向的量，因此它可以确定欧几里得空间中一点相对于另一个点的位置（即二维、三维或“n”维）。

```
![images](img/100-1.png) 其中，`a[i]` 代表 `n` 个标量，`u[i]` 代表基向量。
```

`n` 维向量空间中向量的正交性可以看作是二维空间中向量垂直的扩展。两个正交的向量之间是完全无关或相互独立的。因此，将一组向量转换为对应的基向量集有助于将向量分解为若干个独立组件。

现在，让我们将这一概念扩展到数据集的特征空间。特征向量可以转换为基向量的向量空间，这些基向量被称为主成分。这些主成分就像基向量一样，彼此是正交的。因此，一组可能具有相似性的特征向量被转换为一组完全无关的主成分。然而，主成分捕获了原始特征空间的变异性。此外，导出的主成分数量就像基向量一样，比原始特征集少得多。

`PCA` 的目标是进行转换，使得：

1. 新特征是彼此区分的，即新特征（即主成分）之间的协方差为 0。
2. 主成分按照其捕获的数据变异性顺序生成。因此，第一个主成分应该捕获最大的变异性，第二个主成分应该捕获次高的变异性，以此类推。
3. 新特征或主成分的方差和等于原始特征的方差和。

`PCA` 基于数据集协方差矩阵的特征值分解过程。以下是需要遵循的步骤：

1. 首先，计算数据集的协方差矩阵。
2. 然后，计算协方差矩阵的特征值。
3. 具有最大特征值的特征向量代表方差最大的方向。因此，这有助于识别第一个主成分。
4. 具有次高特征值的特征向量代表数据剩余方差最大的方向，且与第一个方向正交。因此这有助于识别第二个主成分。
5. 依此类推，识别具有前 `k` 个特征值的前 `k` 个特征向量，以获得 `k` 个主成分。

其中，`U` 和 `V` 是正交矩阵，`U` 是一个 `m` × `m` 矩阵，`V` 是一个 `n` × `n` 矩阵，而 ∑ 是一个 `m` × `n` 矩形对角矩阵。∑ 的对角线元素被称为矩阵 `A` 的奇异值。`U` 和 `V` 的列分别称为矩阵 `A` 的左奇异向量和右奇异向量。

`SVD` 通常用于 `PCA`，前提是已经去除了每个变量的均值。由于并不总是建议移除数据属性的均值，特别是当数据集是稀疏的（如文本数据所示），`SVD` 是这些情况下降维的良好选择。

数据矩阵的 `SVD` 预期具有以下突出特性：

1. 属性中的模式由右奇异向量（即 `V` 的列）捕捉。
2. 实例之间的模式由左奇异向量（即 `U` 的列）捕捉。
3. 奇异值越大，它所代表的矩阵 `A` 部分及其关联向量就越大。
4. 使用等式获取具有 `k` 个属性的新数据矩阵：
   `D`′ = `D` × [`v[1]`, `v[2]`, …, `v[k]`]
   因此，维度被降低到 `k`。

`SVD` 经常用于文本数据背景下。

#### 4.2.2.3 线性判别分析

线性判别分析（`LDA`）是另一种类似于 `PCA` 或 `SVD` 的常用特征提取技术。`LDA` 的目标与其相似之处在于，它意图将数据集转换为低维特征空间。然而，与 `PCA` 不同，`LDA` 的重点不在于捕捉数据集的变化性。相反，`LDA` 关注类可别性，即根据类可别性分离特征，以避免机器学习模型的过拟合。

与计算数据集协方差矩阵特征值的 `PCA` 不同，`LDA` 计算类内和类间散度矩阵的特征值和特征向量。以下是遵循的步骤：

1. 计算每个类的均值向量。
2. 计算类内和类间散度矩阵。
3. 计算 `S[W]`^(-¹) 和 `S[B]` 的特征值和特征向量，其中 `S[W]` 是类内散度矩阵，`S[B]` 是类间散度矩阵。

## 4.3 特征子选择

特征选择无疑是任何机器学习项目中最关键的预处理活动。它意图选择系统属性或特征的子集，这些特征对机器学习活动做出最有意义的贡献。让我们快速讨论一个实际示例来理解特征选择背后的哲学。假设我们正尝试根据对相似学生的历史信息来预测学生的体重，这些信息记录在“学生体重”数据集中。学生体重数据集具有学号（`Roll Number`）、年龄、身高和体重等特征。我们可以很好地理解，学号对于预测学生体重没有任何关系。因此，我们可以消除学号特征，并构建一个特征子集在该机器学习问题中进行考虑。该特征子集将比全集产生更好的结果。这一点在图 4.8 中已有描述。

### 4.3.1 高维数据中的问题

随着数字领域的快速创新，产生的数据量已增加到难以置信的程度。同时，存储技术领域的突破使得大量数据的存储变得非常廉价。这进一步激励了对极大型和高维数据集的存储和挖掘。

#### 思考点

“高维”指的是某些数据集中存在的高数量变量、属性或特征，在 DNA 分析、地理信息系统（`GIS`）、社交网络等领域尤为如此。高维空间通常有成百或上千个的维度或属性，例如，DNA 微阵列数据可以有多达 450,000 个变量（基因探针）。

与此同时，两个新应用领域经历了剧烈发展。一个是生物医学研究，包括从微阵数据中选择基因。另一个是文本分类，处理来自社交网络网站、电子邮件等的海量文本数据。第一个领域即生物医学研究产生的数据集特征数量达到数万。来自不同来源的文本也具有极高的维度。在一个嵌入了数千文档的大语料库中，代表数据集特征的词标记也可以达到数万。从这类高维数据获取见解对于任何机器学习算法来说都是一个巨大的挑战。一方面，需要大量的计算资源和大量的时间。另一方面，由于数据中存在不必要的噪声，无论是监督还是无监督机器学习任务，模型的性能都会急剧下降。此外，在极大量特征上构建的模型可能非常难以理解。因此，有必要选取特征子集而不是全集。

特征选择的目标是三个方面的：

* 拥有更快且更具效益（即需要更少计算资源）的学习模型
* 提高学习模型的效率
* 更好地理解底层模型

### 4.3.2 特征选择的关键驱动力——特征相关性和冗余

#### 4.3.2.1 特征相关性

在监督学习中，输入数据集即训练数据集带有类标签。基于训练数据集归纳模型——以便归纳模型可以为新的未标记数据分配类标签。每个预测变量都预期为决定类标签的值贡献信息。如果一个变量没有贡献任何信息，则认为它是无关的。如果对预测的信息贡献很小，该变量被称为弱相关。剩余对预测任务有显著贡献的变量被称为强相关变量。

在无监督学习中，没有训练集或标记数据。它通过对相似的数据实例进行分组，并根据不同变量的值来评估数据实例的相似性来实现。某些变量对于判断数据实例的相似性或差异性无法提供任何有用信息。因此，这些变量在分组过程中没有产生显著的信息贡献。在无监督机器学习任务的语境下，这些变量被标记为无关变量。

为了直观理解，我们可以考虑在本节开头讨论过的学生数据集的简单例子。一个学生的学号（`Roll number`）对于预测学生的 `Weight`（体重）没有提供任何显著信息。同样，如果我们正尝试将学术能力相似的学生归为类，`Roll number`（学号）确实无法提供任何信息。因此，在预测学生 `Weight` 的监督任务或对学术水平相似的学生进行分类的无监督任务背景下，`Roll number` 这一变量是完全无关的。

在机器学习任务背景下，任何无关的特征在选择特征子集时都是剔除的候选对象。我们可以根据具体情况考虑是否剔除弱相关特征。

### 4.3.2.2 特征冗余

某个特征提供的信息可能与一个或多个其他特征提供的信息相似。例如，在节前提到的体重预测问题中，`Age`（年龄）和 `Height`（身高）特征都提供了相似的信息。这是因为随着 `Age` 的增加，`Weight` 预计随之增加。同样，随着 `Height` 的增加，`Weight` 预计也会增加。此外，`Age` 和 `Height` 相互增长。因此，在 `Weight` 预测问题的背景下，`Age` 和 `Height` 提供了相似的信息。换句话说，无论特征 `height` 是否作为特征子集的一部分存在，学习模型给出的结果几乎相同。同样，如果没有 `age` 作为预测变量的一部分，学习模型的输出结果也大大相同。在一种一个特征与另一个特征相似的情况下，该特征在学习问题背景下被认为是具有潜在冗余的。

所有具有潜在冗余的特征都是最终特征子集的剔除候选对象。在一组潜在冗余的特征中，只有少数具有代表性的特征会被认为是最终特征子集的一部分。

简而言之，特征选择的主要目标是移除所有无关特征，并选取一个对于潜在冗余特征的代表性子集。这在特定的学习任务背景下产生了一个有意义的特征子集。

现在，问题是如何找出哪些特征是无关的，或者哪些特征具有潜在冗余。为此，使用了多种衡量方法，其中一些在下一个小节中将被介绍。

### 4.3.3 特征相关性和冗余性的衡量标准

#### 4.3.3.1 特征相关性的衡量标准

如前所述，特征相关性通过特征贡献的信息量衡量。对于监督学习，互信息被认为是衡量特征对类别标签值贡献的良好指标。这就是为什么它是特征与类别变量相关性的良好指标。特征的互信息越高，该特征越相关。互信息的计算公式如下：

```
MI(C, f) = H(C) + H(f) - H(C, f)
```
