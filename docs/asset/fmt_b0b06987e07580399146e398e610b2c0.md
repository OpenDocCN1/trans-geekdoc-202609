
# 术语表

## S

### 安全连接建立
: 一个在远程主机与本地设备或计算机之间创建安全连接的过程，通过该连接，未加密的流量可通过加密通道传输。

### 有状态包过滤防火墙
: 收集网络连接信息并维护动态状态表的防火墙，这些状态表用于后续连接，使端口能够根据包过滤规则定义进行开启和关闭。

### 无状态包过滤防火墙
: 更多地充当 `ACL` 作用的防火墙。它们不跟踪两台计算机之间连接的状态；但是，它们将数据包与过滤规则进行比较。

### 存储区域网络 (SAN)
: 一种基于网络的存储系统，在主机上表现为本地连接的存储。

### 流密码
: 一种对称密钥密码，一次转换一个明文字符。

### Stuxnet (震网病毒)
: 一种针对可编程逻辑控制器的病毒，该控制器指导伊朗核计划离心机的操作。

### 子网
: 一个隔离的网络，最终属于一个更大的网络的一部分。

### 超级 Cookie
: 一种安全漏洞利用，旨在通过测量或利用系统或其硬件的间接效应，从系统收集信息或影响程序执行。比其他类型 Cookie 更难移除的第三方 Cookie。许多此类 Cookie 不使用传统的 Cookie 存储方法，而是使用本地浏览器 `HTML5` 数据库存储，甚至 `Adobe Flash` 数据存储。

### 数据采集与监视控制系统 (SCADA)
: 一种分布式控制系统架构，提供两个不同的功能——数据采集（输入）和监视控制功能（输出）。用于监控并提供对机器和过程的高级控制。

### 监控设备
: 用于集中管理一组远程本地控制设备的设备。

### 监管密码
: 用于建立可用于访问 `CMOS` 设置实用程序的密码。

### 交换端口窃取
: 一种改变交换机流量方向的技术，导致交换机将本应发送给其他接收者的流量发送给攻击者。

### 基于交换机的虚拟化
: 一种通过托管交换机实现的网络虚拟化过程，用于将 `SAN` 设备连接在一起。这些设备也位于用户和存储网络之间，但可能采用不同的技术来提供存储管理功能。

### 切换器
: 用于多摄像头监控系统的设备。它们允许将多个摄像头与单个显示器一起使用。

### 对称密钥
: 一种加密算法将使用相同的密钥执行加密和解密。

### SYN 洪水攻击
: 一种拒绝服务攻击形式，攻击者利用 `TCP` 握手过程（使用 `SYN` 和 `ACK` 消息在两个主机之间建立可靠连接）进行攻击。

## T

### 标记数据包
: 在数据包头部插入了 `VLAN ID` 以标识数据包属于哪个 `VLAN` 的数据包。

### 尾随
: 类似于“搭便车”，社会工程学攻击者的最终目标是进入公司或组织的未授权区域。此方法涉及在不知情人员身后溜进，从而在未经其明确知晓的情况下获得访问权限。

### 有形财产安全
: 传统上称为物理安全，包含保护物理边界和财产。

### 泪滴攻击
: 一种 `DoS` 攻击，向目标系统发送分片数据包。旧版操作系统在其 `TCP/IP` 重组机制中存在缺陷，导致分片数据包重叠并使主机崩溃。

### 遥测
: 为了远程监控而自动进行的测量数据无线传输。

### Telnet
: 一种应用层客户端-服务器协议，可在计算机（或设备）与任何远程 `Telnet` 服务器之间建立 `TCP` 连接，以允许基于文本的通信。

### 领域强化
: 一种物理安全方法，采用结构、系统和设备来防止未经授权的进入，并明确区分公共区域和私有区域。

### 威胁
: 实施意图造成痛苦、伤害、损害或其他敌对行动的潜在可能性。

### 威胁主体
: 拥有知识、能力和意图发起攻击的个人、团体、软件或硬件设备。也称为威胁行为体。

### 威胁识别过程
: 一种预防措施，旨在记录可能产生风险因素并影响网络数据机密性、完整性和可用性的漏洞。

### 威胁向量
: 攻击者可能用于到达期望目标的方法。

### 基于阈值的异常检测系统
: 旨在随时间跟踪特定事件发生次数，并在事件数量超过预定数量时生成入侵警告的 `IDS` 系统。

### 绝密
: 通常为三级安全许可中的最高级别。

### 拓扑
: 网络连接结构的物理和/或逻辑定义。

### 追踪 Cookie
: 放置在主机计算机上的非恶意文本文件，旨在追踪用户的网页浏览习惯。

### 透明代理
: 一种代表主机通信且不修改请求的代理服务器，这与大多数代理服务不同。用户通常甚至不知道自己正在使用透明代理。

### 传输层安全 (TLS)
: `SSL` 协议的继任者，`TLS` 是一种通过加密应用程序间通信来确保隐私的协议。

### 特洛伊木马
: 伪装成合法应用程序的恶意软件，诱使用户使用它们；虽然它们功能正常，但启动应用程序时会启动恶意代码。

### 中继链路
: 一种指定用于处理和组合多个流量信号的通信链路，通常连接到其他网络设备，旨在整合物理端口使用。

### 可信平台模块 (TPM)
: 许多计算机主板设计中内置的微芯片，用于存储加密信息，如加密密钥（也称为启动密钥）。

### 可信 VPN
: 不使用加密隧道技术，而是信任底层网络在认证之外处理安全性的 `VPN`。

### TrustedGrub
: 一个能够检测并支持 `Linux` 系统中 `TPM` 功能的 `Linux` 模块。它是 `Grub` 引导加载程序的可下载扩展，已为此目的进行了修改。

### 隧道技术
: 一个允许远程用户在建立 `Internet` 连接后安全连接到内部资源的过程。这是通过使用数据传输加密来保护传输中的数据来实现的。

### 双因素认证
: 一个基于“你知道什么”、“你拥有什么”或“你是谁”，需要两个不同因素才能授予授权的过程。

### 双人控制
: 一种要求两个用户必须相互审查并批准对方工作以完成项目的实践。虽然这对许多任务可能不切实际，但对于实施它的任务提供了高级别的安全性。

## U

### UDP 洪水攻击
: 一种类似于 `ping` 洪水攻击的 `DoS` 攻击，使用 `UDP` (User Datagram Protocol) 数据包。

### 未授权访问
: 个人在没有拥有适当凭据的情况下获得对服务、应用程序、网络或设备的访问权限。

### 单向安全网关
: 用于在具有不同安全分级的网络或网段之间创建单向连接。

### 统一威胁管理 (UTM) 设备
: 集网关、防病毒、防火墙、入侵防御和检测服务于一体的安全设备。

### 通用即插即用 (UPnP)
: 一种零配置网络架构，可在不同品牌和类型的网络硬件之间带来一定程度的兼容性。虽然主要旨在帮助非专业的家庭网络用户，但一些非消费级硬件制造商也支持 UPnP。

### UNIX
: UNIX 操作系统系列提供模块化、多任务、多用户的操作系统环境，最初是为在大型机和小型计算机上运行而开发的。UNIX 操作系统的专有版本包括多种 BSD（Berkeley Software Distribution，伯克利软件发行版）变体，以及 Apple 的 macOS 和 iOS 操作系统和 Google 的 Android 操作系统。

### UNIX 文件系统
: 这是为原始 UNIX 操作系统设计的第一种文件结构，至今仍在 UNIX 及其衍生版本中使用。该文件系统标准的结构呈现统一的树形结构，从称为根目录（`/`）的主目录开始。

### 解锁状态监控
: 状况监控系统可在特定大门或门被解锁（授予访问权限）时进行记录和发出信号，指示并记录授予了哪种类型的访问权限。

### 无标签数据包
: 未在数据包头部插入 VLAN ID 的数据包。

### 更新
: 提高操作系统可靠性、安全性或易用性的服务包或补丁。操作系统更新最可靠的来源是操作系统制造商。某些更新可能会使操作系统更方便，但不一定更安全。

## V

### 变焦镜头
: 包含多个可移动元件的光学组件，允许改变监控摄像头的有效焦距 (EFL)。与变焦镜头（zoom lens）不同，变焦镜头（varifocal lens）在每次变更时都需要重新聚焦。如果配备变焦镜头，可根据用户偏好在多个毫米设置下进行聚焦。

### 视频监控系统
: 大多数商业安全系统的重要组成部分。该系统利用摄像头进行预防和恢复。

### 虚拟访问控制列表 (VACL)
: 过滤进入 VLAN 的流量，以及过滤 VLAN 成员之间流动的流量的访问列表。

### 虚拟局域网 (VLAN)
: 在数据链路层进行隔离的软件配置网络。

### 虚拟专用网络 (VPN)
: 远程用户可以通过公共网络（如 Internet）连接到专用网络，然后进行身份验证并在专用网络上执行任务，就像直接连接一样。它使用户能够跨公共网络与另一台设备通信，就像在专用网络中一样，从而确保安全性。

### 病毒
: 旨在在本地计算机环境中复制和传播的恶意软件程序。这最常发生在用户从 Internet 下载程序或打开电子邮件附件时。

### 语音钓鱼
: 利用电话进行网络钓鱼攻击。

### VLAN 跳跃攻击
: 这些攻击也称为交换机欺骗攻击，涉及攻击者向交换机发送动态中继协议 (DTP) 请求，将攻击者的端口配置为中继连接。配置完成后，该连接会将所有 VLAN 中的流量路由给攻击者。

### VLAN 中继协议攻击
: 这些攻击针对思科的二层 VLAN 中继协议 (VTP)。该协议提供跨整个网络的交换机之间自动 ISL/802.1Q 中继配置，以便它们可以共享数据包。VTP 的自动化特性默认提供对网络所有 VLAN 的访问。它可用于从网络中添加或删除 VLAN。这使得带有中继端口的交换机容易受到攻击。

### 漏洞
: 可能允许攻击者访问网络资产的任何弱点。

### 漏洞评估
: 识别和确定网络或系统中已知漏洞优先级的过程。

### 漏洞模拟器
: 用于渗透测试的训练模拟器。

### 漏洞扫描器
: 基于数据库的工具，旨在搜索计算机中已识别并添加到数据库中的已知漏洞。它们旨在评估计算机系统、网络和应用程序。

## W

### 武器化阶段
: 将收集的信息应用于创建用于发动攻击的工具的阶段。

### Web 代理
: 代表主机或主机网络访问 Web 的计算机或服务器。

### Web 服务器
: 企业用于托管网页以在 Internet 上宣传其组织的服务器。这些是直接与 Internet 打交道的前端服务器。

### 鲸钓攻击
: 一种针对高知名度最终用户（如企业高管、政客或名人）的个性化网络钓鱼形式。就像任何网络钓鱼攻击一样，鲸钓攻击的目标是通过伪造的电子邮件和其他社会工程学手段，诱骗个人泄露个人或公司信息和数据。

### 白盒
: 一种渗透测试，其目标是模拟恶意内部威胁，此类威胁将深知客户的关键网络基础设施并拥有访问凭据，而非破坏其功能。

### 白帽黑客
: 利用其在攻破和渗透计算机网络及安全系统方面的专业知识，用于良好、道德且最重要的是合法目的的黑客。

### 白队
: 监督并了解渗透测试的小组。有时称为蓝队。
