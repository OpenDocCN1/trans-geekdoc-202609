
该模型属于一类更通用的模型，称为*随机波动率*模型，其中过程的方差本身是随机分布的。此类模型用于金融数学中对衍生证券（如期权）进行建模。状态变量称为*对数波动率*。我们假设两个噪声序列均为相互独立的独立同分布（i.i.d.）高斯分布，均值为零，方差分别为 $\sigma_{\eta}^{2}$ 和 $\sigma_{v}^{2}$。模型参数 $\alpha$ 和 $\beta$ 分别称为*波动率冲击的持久性*和*模态波动率*。采用的参数值为 $\sigma_{\eta}^{2} = 0.178$，$\sigma_{v}^{2} = 1$，$\alpha = 0.97$，和 $\beta = 0.69$。

本示例的目标是生成一个观测序列，然后基于这些样本预测状态（假设状态未知）。为此，我们生成一个包含 $N = 2000$ 个粒子的序列，每个时刻的状态变量被估计为生成粒子的加权平均值，即

$${\widehat{x}}_{n} = \sum\limits_{i = 1}^{N}W_{n}^{(i)}x_{n}^{(i)}.$$

![Equation](img/si251.png)

使用了 SIR 算法 17.5 和 算法 17.6 的辅助滤波器方法。建议分布为

$$q(x_{n}|x_{n-1}) = \mathcal{N}(x_{n}|\alpha x_{n-1},\sigma_{\eta}^{2}).$$

![Equation](img/si252.png)

## 粒子滤波器权重更新推导

### 重要性权重定义

粒子 $i$ 在时刻 $n$ 的重要性权重定义为：

$$w_{n}^{(i)} = \frac{p(\mathbf{x}_{n}^{(i)}|\mathbf{y}_{1:n})}{q(\mathbf{x}_{n}^{(i)}|\mathbf{y}_{1:n})} \tag{17.52}$$

### 建议分布的常见选择

建议分布的一个常见选择是：

$$q(\mathbf{x}_n|\mathbf{y}_{1:n}) = p(\mathbf{x}_n|\mathbf{y}_{1:n-1}) \tag{17.53}$$

### 权重更新规则

将公式 (17.53) 和 (17.50) 代入公式 (17.52)，得到权重的更新规则：

$$w_{n}^{(i)} \propto p(\mathbf{y}_n|\mathbf{x}_{n}^{(i)}) \tag{17.54}$$
