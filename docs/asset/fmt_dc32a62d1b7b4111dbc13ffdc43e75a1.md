## 端口扫描（Port Scanning）

端口扫描允许运行探测的人确定目标计算机上运行哪些服务。端口与 TCP 和 UDP 相关。虽然应用程序可以在非标准端口运行，但建立端口号作为事实标准。共有 65536 个端口，分为已知端口（0–1024）、注册端口（1024–49151）和动态端口（49151–65535）。常见的端口扫描技术包括：

- **TCP 全连接扫描**：尝试完成 TCP 三次握手的所有步骤。
- **TCP SYN 扫描**：半开放扫描，设计用于更具隐蔽性。这种扫描同样可能被检测。开放端口回复 SYN/ACK，关闭端口响应 RST/ACK。
- **TCP FIN 扫描**：向目标端口发送一个 FIN 数据包。关闭端口应该发送 RST。

### TCP XMAS 扫描

该技术开启了 FIN、URG 和 PSH 标志。关闭的端口应该返回 RST。

> 注意：在美国进行端口扫描并不违法，但预先获得许可始终是最佳实践。

最知名的端口扫描工具之一是 Nmap。该程序适用于 Windows 和 Linux，并提供命令行和基于图形界面（GUI）的应用程序。另一个流行的端口扫描工具是 SuperScan，这是一个由 Foundation 开发的基于 Windows GUI 的扫描器。它可以扫描 TCP 和 UDP 端口，并执行 ping 扫描。此外还有 THC-Amap，它是首批采用新端口扫描方法的端口扫描工具之一。THC-Amap 存储了一组响应，它可以向端口发送这些响应，以交互方式诱导其做出响应。THC-Amap 使用这种技术查找特定端口上运行的程序。

### 指纹工具

一旦映射了开放和关闭的端口，安全评估团队对目标系统上运行的程序有了初步了解，但团队可能不知道托管目标系统的是哪种操作系统。操作系统指纹可以确定运行的是什么操作系统。执行操作系统指纹有两种方法。第一种选择是被动指纹；第二种是主动指纹。

被动指纹是数据包嗅探。检查数据包中可以确定操作系统的某些特征。以下是用于操作系统指纹的四个常用检查项：

- **IP TTL 值**：不同的操作系统在出站数据包中使用唯一的 TTL 值。
- **TCP 窗口大小**：操作系统厂商对初始窗口大小使用不同的值。
- **IP DF 选项**：并非所有的操作系统都以相同的方式处理分片。
- **IP TOS 选项**：服务类型是一个 3 位字段，控制特定数据包的优先级。同样，并非所有厂商都以此相同的方式实现此选项。

第二种技术主动操作系统指纹通过向目标构建并发送异常的数据包设置，希望触发能够识别其身份的响应。尽管主动指纹更准确，但它没有被动指纹那样隐蔽。这里列了一些主动指纹技术的示例：

- **初始序列数（ISN）采样**：这种指纹技术通过寻找 ISN 中的模式来工作。虽然某些系统使用真正的随机数，但其他系统（如 Windows）按固定增量增加数字。
- **IPID 采样**：许多系统简单地为发送的每个数据包增加 IPID 值。其他系统（如 Windows）则每个数据包增加 256。
- **服务类型**：这种指纹类型微调 ICMP 端口不可达消息并检查 TOS 字段中的值。某些使用 0，其他则返回不同的值。
- **TCP 选项**：在这里不同厂商以不同方式支持 TCP 选项。通过发送设置了不同选项的数据，响应将开始显示服务器的指纹。
- **分片处理**：这种指纹技术利用了不同操作系统处理分片数据包的方式不同。RFC 1191 规定 MTU 通常设置在 68 到 65,535 字节之间。

为此目的设计的工具包括：

- **Paf**：运行在 Linux 或 Windows 上的被动操作系统指纹工具。
- **Xprobe2**：主动操作系统指纹的示例，Xprobe2 依赖模糊签名匹配。指纹结果会被汇总，并向用户提供一个分数，告知目标机器操作系统的概率。
- **Nmap**：Nmap 既是端口扫描器也是主动指纹工具。

指纹工具被用于识别操作系统。这是渗透测试过程中的重要步骤。一旦识别了操作系统，就可以开始搜索已知漏洞。

## 主动漏洞扫描工具

主动漏洞扫描器用于扫描内部或外部计算机的漏洞。某些漏洞评估工具是开源的而另一些是商业性的，可能需要年度订阅费用。这些工具可以分为三大类：

**源代码扫描器**：源代码扫描器可用于辅助代码审查。如果你在软件产品开发期间拥有代码，这些工具提供了发现常见问题和缺陷的能力。RAFS 和 Flip 是此类两个工具。源代码扫描器可以检测缓冲区溢出、竞态条件、权限提升和受污染输入等问题。虽然这些工具很有帮助，但它们可能会产生大量的误报。这些工具擅长发现未执行适当边界检查的特定函数。如前所述，C 语言中的函数不检查缓冲区大小，例如 `scanf()`、`strcpy()`、`bcopy()`、`vsprintf()` 和 `gets()`。

**系统扫描器**：最后一类扫描器是系统级的。当有工具可以探测整个网络时，为什么要检查应用程序？系统扫描器可以针对单个地址或地址范围运行。系统扫描器的主要优势是它们可以扫描漏洞。Nessus、SAINT 和 Retina 都是系统扫描器的示例。

## 协议分析工具

*协议分析器*或嗅探器是嗅探和捕捉网络流量的硬件或软件应用程序。出于讨论目的，我们将范围限制在软件嗅探器上。嗅探器通过将主机的网卡设置为混杂模式来工作。混杂模式下的网卡可以接收其能看到的所有数据，而不仅仅是发送给它的数据包。嗅探器工作在 OSI 模型的数据链路层。嗅探器捕获线上的所有内容并将其记录下来供日后审查。它们允许用户查看数据包包含的所有数据，甚至是某些人可能希望保持私密的信息。许多旧协议（如 FTP 和 Telnet）通过明文发送用户名和密码。任何拥有嗅探器的人都可以拦截这些数据并轻松重复利用。

如果主机连接到集线器，则可以进行被动嗅探。在交换机网络上进行嗅探时，被称为主动嗅探，因为交换机会分段流量，并知道哪些特定端口发送流量，同时将其与其他所有端口屏蔽。交换机为想要出于合法或非法原因而嗅探流量的人设置了障碍。

**交换机端口分析器（SPAN）**：由于交换机会交换流量，因此不再通过在单个端口上附加混杂模式设备来监控所有流量。为了克服这一局限性，交换机制造商开发了被称为端口镜像、交换机镜像或在 Cisco 交换机上称为 SPAN 的解决方案。扩展端口允许用户不仅看到发往其特定端口的流量，还能看到交换机转发的所有流量。此功能使得交换机可以配置为：当数据被转发到交换机上的任何端口时，它也会被转发到 SPAN 端口。这种功能与嗅探器以及如 Snort 等 IDS 设备配合使用时是一个非常强大的特性。

## 地址解析协议（ARP）泛洪与中毒

尽管端口镜像对交换机专业人员有效，但攻击者可能会尝试在没有设备管理权限的情况下从交换机获取相同的功能。针对交换机的获取同级别控制的攻击可以通过 ARP 泛洪或中毒来实现。在 ARP 泛洪中，攻击者发送数千个带有不同物理地址的伪造数据包。其目的是填充交换机的内存并强制其像集线器一样工作。泛洪攻击在过去并不常见，因为大多数现代交换机都会防止这种攻击。

另一种方法是使用 ARP 中毒。回顾一下，ARP 将已知的 IP 解析为未知的物理地址。ARP 通过在网络中广播消息来确定主机的第 2 层物理地址。目标 IP 地址处的主机发送包含其 MAC 地址的响应包。一旦初始 ARP 事务完成，源设备就会缓存 ARP 响应，该响应用于发送到指定 IP 地址的数据包的第 2 层头部。

ARP 中毒是通过向主机发送未请求的 ARP 响应来实现的。这种伪造的 ARP 信息允许攻击者将流量重定向到其设备并成为中间人；任何发往合法资源的流量都会通过攻击系统发送。

## 密码破解工具

密码破解是检索并尝试解密存储在计算机系统或通过系统传输的加密密码的过程。密码破解工具可以通过三种基本方式之一测试密码的强度：字典破解、混合破解和暴力破解。

**字典密码破解**：字典密码破解从字典或词列表中提取单词，以尝试发现用户的密码。字典攻击使用预定义的字典来查找加密密码与加密字典单词之间的匹配项。许多时候，密码审计可以在很短时间内恢复用户的密码。如果密码是众知的字典词汇，字典破解就能成功。

**混合密码破解**：混合密码破解使用字典或词列表，并在其前后添加字符或数字以尝试破解用户的密码。

**暴力破解**：暴力破解使用字母、数字和字符的各种组合来尝试破解用户的密码。对加密密码进行暴力破解可能需要几分钟、几小时、几天、几个月甚至数年，取决于密码的复杂程度。缩短时间需要更快的 CPU 或使用分布式计算。

历史上，这三种方法被认为是安全的，因为破解它们需要太长时间。这种理论随着名为彩虹表的更新密码破解技术的出现而不再完全成立。彩虹表技术由 Philippe Oechsl 开发，利用了时间换内存。它通过预计算所有可能的密码来实现。一旦这个耗时过程完成，密码及其对应的值将存储在一个名为彩虹表的文件中。加密密码可以快速与表中对比。

以下是一些密码破解程序的示例：

- **John the Ripper**：适用于 Windows 和 Linux 的密码破解程序，John the Ripper 可以破解常见的 Kerberos、AFS 和 Windows 哈希。
- **Lophtrack**：自 1997 年以来的密码破解程序，Lophtrack 可以从本地机器或远程机器提取哈希，并从本地网络嗅探密码。
- **Cain & Abel**：Cain & Abel（简单称为 Cain）是一种多功能密码破解工具，可以执行各种任务，包括 Windows 枚举、嗅探和密码破解。Cain 使用字典、暴力破解和彩虹表方法。
- **Ophcrack**：Ophcrack 是一种实现彩虹表的密码破解工具。它有几个可以下载的表，你也可以在网上搜索其他的。

![](img/7868547987f5920cfe632b85047c64af_353_0.png)

密码破解技术不断进步。一个例子是使用 GPU 进行密码破解。你可以获取亚马逊云端的 GPU，加载你的彩虹表，并快速破解密码。还有一些非彩虹表的密码收集计划，例如 `https://crackstation.net/`。这个网站只是一个集合，但规模很大，而且由于人们在输入密码，它正在建立一个人们可能使用的密码库。

模糊测试（Fuzzing）是一种黑盒软件测试技术。它通过自动向程序输入多个经过特殊构造的迭代来工作，旨在触发内部错误或漏洞，并可能导致程序崩溃。此类程序错误和崩溃表明存在安全漏洞，稍后可以对其进行研究和修复。模糊测试的巨大优势在于测试设计极其简单，且对系统行为没有预设假设。模糊测试工具的一些示例包括：

- **SPIKE**：来自 Immunity 公司的一系列模糊器集合。
- **SPIKEFile**：由 iDefense 开发的另一种用于攻击 ELF（Linux）二进制文件的文件格式模糊器。
- **WebFuzzer**：针对 Web 应用漏洞的模糊器。
- **eFuzz**：一种针对奇异 HTML 标签的通用 TCP/IP 协议模糊器。它还会自动启动浏览器。
- **Mangle**：用于生成奇异 HTML 标签的模糊器。
- **Tag Brute Force**：用于对 ActiveX 应用进行模糊测试。
- **IP Stack Integrity & Stability Checker（ISIC）**：ISIC 用于测试 IP 栈及其组件协议栈（如 TCP、UDP 和 ICMP）的稳定性。ISIC 生成大量目标协议的伪随机包以测试其响应。

## 无线工具

802.11 无线连接是渗透测试期间经常审查的内容。无线网络因其低成本和便利性而变得流行。谁想要铺设 1,000 英尺长的电缆呢？无线网络最初通过有线等效隐私（WEP）进行保护。WEP 使用 RC4 加密算法对数据进行加密。密钥限于 40 位或 104 位。这提供的加密级别有限，相对容易被破解。这些弱点导致了名为 WiFi 保护访问（WPA）的短期解决方案的开发。WPA 要安全得多，因为它使用了临时密钥完整性协议（TKIP）。2004 年，IEEE 批准了无线安全的下一次升级，即 WPA2。它的正式名称为 802.11i。此项无线安全标准使用了高级加密标准（AES）。WPA2 支持高达 256 位的密钥长度。在无线评估期间可以使用多种工具。这里列出了几种：

- **Kismet**：一个基于 Linux 的 802.11 无线嗅探器，可以监控和嗅探来自无线网络的原始包，Kismet 可以检测标准和隐藏的网络名称，并分析非信标的隐藏网络。
- **NetStumbler**：一个基于 Windows 的 GUI 工具，使用无线扫描仪，NetStumbler 的工作原理是在所有通道上发送持续的广播包。
- **LinkFerret**：一个基于 Windows 的应用程序，设计用于嗅探 802.11 网络流量。

HTTP 拦截器（HTTP Interceptors）是可以用于评估和分析流量的程序。客户端浏览器和 Web 之间传递的所有明文信息都是可见的。如果应用程序在没有加密的情况下明文传输密码，你可以轻松看到它。拦截器通过代理 Web 客户端和 Web 服务器之间的流量来工作。它们会拦截返回的每一个 HTTP 和 HTTPS 请求。当拦截代理允许普通用户查看“内部机制”并更好地开始理解应用程序是如何传递数据的时，它就变得极其有用。例如：

- 密码是否加密了？
- 输入参数是否经过了检查？
- 从客户端接收的数据是否经过了验证？
- 是否使用了客户端处理？
- Cookie 是否包含会话信息？
