
该算法的复杂度为 `𝒪(q*l)`。`q` 的值越大，收敛速度越快，但代价是复杂度更高。文献 [77] 中，为了降低复杂度对 `q` 的依赖，引入了*子维度*投影的概念，其中对 `q` 个超平板的投影可限制在当前可用估计中最显著参数的方向上。对 `q` 的依赖现变为 `𝒪(q*k[n])`，其中 `k[n]` 是当前可用估计的稀疏度，在算法运行几步后会远低于 `l`。每次迭代步骤的总复杂度为 `𝒪(l) + 𝒪(q*k[n])`。这允许使用较大的 `q` 值，与 `𝒪(l)` 相比仅需极小的额外计算开销，即可使算法性能接近自适应加权 LASSO。

#### 投影到加权 ℓ₁ 球

投影到 ℓ₁ 球等价于软阈值操作。投影到加权 ℓ₁ 范数会导致软阈值的轻微变化，每个分量具有不同的阈值。下文给出了加权 ℓ₁ 球这一更一般情况的迭代步骤。证明略显技术性且冗长，此处不予给出。该证明在文献 [76] 中首次通过纯几何论证推导得出，未使用经典拉格朗日乘数法。文献 [46] 则针对 ℓ₁ 球的情况使用了拉格朗日乘数法。ℓ₁ 球投影的高效计算此前已在文献 [100] 中以更一般的背景进行过处理。

回顾第 8 章讨论的投影定义，给定球外一点 `θ ∈ ℝˡ ∖ B_ℓ₁[w, ρ]`，其在加权 ℓ₁ 球上的投影为点 `P_B_ℓ₁w,ρ ∈ B_ℓ₁[w,ρ] := {z ∈ ℝˡ: ∑ᵢ₌₁ˡ wᵢ|zᵢ| ≤ ρ}`，该点在欧几里得意义上最接近 `θ`。若 `θ` 位于球内，则其与投影重合。给定权重和 `ρ` 的值，以下迭代可求得该投影。

**算法 10.5**

##### 投影到加权 ℓ₁ 球 B_{ℓ₁}[w, ρ] 上

1. 构造向量 `[|θ₁|/w₁, …, |θₗ|/wₗ]ᵀ ∈ ℝˡ`。

2. 将上述向量按非递增顺序排序，使得 `|θ_{τ(1)}|/w_{τ(1)} ≥ … ≥ |θ_{τ(l)}|/w_{τ(l)}`。符号 `τ` 代表排序操作隐式定义的排列。请记住逆排列 `τ⁻¹`，它表示元素在原始向量中的位置索引。

3. `r₁ := l`。

4. 令 `m = 1`。当 `m ≤ l` 时，执行：

    1. **(a)** `m* := m`。

    2. **(b)** 在满足以下条件的 `j ∈ {1, 2, …, rₘ}` 中找到最大的 `j*`：

       ```
       |θ_{τ(j)}| / w_{τ(j)} > (∑_{i=1}^{rₘ} w_{τ(i)}|θ_{τ(i)}| - ρ) / (∑_{i=1}^{rₘ} w_{τ(i)}²)
       ```

    3. **(c)** 若 `j* = rₘ`，则跳出循环。

    4. **(d)** 否则设置 `r[m + 1] := j*`。

    5. **(e)** 将 `m` 增加 1 并返回步骤 4a。

5. 构造向量 `\widehat{\mathbf{p}} \in \mathbb{R}^{r_{m_{\ast}}}`，其第 `j` 个分量（`j = 1, ..., r[m*]`）由下式给出：

   ```
   \widehat{p}_j := |\theta_{\tau(j)}| - \frac{\sum_{i = 1}^{r_{m_{\ast}}} w_{\tau(i)} |\theta_{\tau(i)}| - \rho}{\sum_{i = 1}^{r_{m_{\ast}}} w_{\tau(i)}²} w_{\tau(j)}.
   ```

6. 使用逆映射 `\tau^{-1}` 将元素 `\hat{p}[j]` 插入到 `l` 维向量 `\mathbf{p}` 的 `\tau^{-1}(j)` 位置，`\forall j \in {1, 2, ..., r[m*]}`，其余位置填零。

7. 所需投影为 `P[B[\ell_1][\mathbf{w}, \rho]](\mathbf{\theta}) = [sgn(\theta_1)p_1, ..., sgn(\theta_l)p_l]^{(T)}`。

##### 备注 10.3

###### 广义阈值规则

投影到 $\ell_1$ 球和加权 $\ell_1$ 球上，通过适当执行的软阈值操作施加凸稀疏诱导约束。SpAPSM 框架中的最新进展 [78,109] 允许用*广义阈值*替换 $P_{B_{\ell_1}[\rho]}$ 和 $P_{B_{\ell_1}[\mathbf{w},\rho]}$，该广义阈值建立在 SCAD、非负门控以及对应于*非凸* $\ell_p$ ($p < 1$) 惩罚的多种阈值函数概念之上。此外，已证明此类广义阈值 (GT) 算子是非线性映射，*其不动点集是子空间的并集*，即位于任何稀疏促进技术核心的非凸对象。对于较低的 $q$ 值，此类方案非常有用，可以在可比的复杂度水平下改进基于 LMS 的 AdCoSaMP 获得的性能。

###### 时变信号

## 10.5 学习稀疏分析模型

到目前为止，我们的讨论一直集中在信号本身是稀疏的，或者可以在合成模型中用字典原子稀疏表示的信号领域，正如公式 (9.16) 所引入的那样，即

$\mathbf{s} = \sum\limits_{i \in \mathcal{I}}\theta_{i}\mathbf{\psi}_{i}.$

事实上，大多数研究活动都集中在合成模型上。这可能部分归因于合成建模路径能提供一种更具直观吸引力的结构，用字典的元素（原子）来描述信号的生成。回顾第 9.9 节，在合成模型中稀疏性假设是施加在 `θ` 上的，相应的优化任务分别在 (9.38) 和 (9.39) 中针对精确和含噪情况进行了表述。
