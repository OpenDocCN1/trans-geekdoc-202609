# 第4章 人工智能在智能分布式处理与大数据挖掘中的应用

Fazal Wahab, Anwar Shah, Inam Ullah, Deepak.

## 4.1 引言

全球范围内观察到数据收集量的剧增。这种数据洪流（也被称为大数据）迫使人们开发更稳健的分析方法。本章旨在阐明人工智能（AI）在数据挖掘和分布式处理中的重要性。以下是人工智能在大数据和分布式处理中的应用。

### 4.1.1 人工智能在大数据中的应用

人工智能与大数据的融合已经改变了企业分析和可视化数据的方式。随着越来越多的企业采用AI驱动策略，这种趋势只会加速。

### 4.1.2 提高数据处理的效率

由于数量、多样性和速度的原因，今天的数据对传统处理技术带来了巨大挑战。然而，人工智能算法可以自动化并加速数据处理中的许多步骤[1]。使用机器学习（ML）和自然语言处理（NLP）等AI技术进行数据预处理和清洗可以减少噪声并提高数据质量。此外，人工智能算法允许有效的索引和查询，从而实现更快速的检索。

### 4.1.3 实现尖端分析

大数据挖掘的目标是从海量集中发现可操作的洞察。人工智能算法擅长处理复杂的数据处理任务，为企业开启了新的途径[2]。例如，机器学习算法可以快速准确地识别趋势和异常值、预测结果并建议下一步。人工智能驱动的分析允许企业做出基于的决策、增强运营并发现未开发的机会。

### 4.1.4 实现按需信息处理

在数据流快速变化的时代（如银行、医疗保健和物联网），实时数据处理对于许多应用至关重要。大规模数据的处理依赖于流挖掘和深度学习（DL）等AI方法。在这些算法的帮助下，企业能够实时检测并响应数据中的异常或意外模式。人工智能的实时数据处理有助于主动决策、降低风险和提高效率[3]。

### 4.1.5 分布式处理

由于大数据通常存储在多个系统中，因此需要稳健的并行处理解释机制。分布式计算框架和并行处理算法是提高数据密集型应用扩展性和性能的AI技术示例。通过人工智能，企业可以将处理任务分配给多个节点或集群，从而高效处理大数据[4]。

### 4.1.6 数据提取与可视化的自动化

手动提取和表示数据可能耗时且容易出错。通过AI方法实现的提取将显著提高从各种来源提取结构化和非结构化数据的效率。例如，计算机视觉领域的算法可以分析和解释视觉数据。收集的信息随后可以使用由AI驱动的数据可视化工具以交互式且用户友好的格式呈现，从而改进数据理解和随后的决策。

大数据技术在各种背景下得到了广泛应用，已成为推动现代文明发展的最具影响力的动力之一，特别是在增强和虚拟环境中 [1]。自象形符号和原始文字时代以来，数据的产生就没有停止过，自从我们进入新的当代数据时代，存储在数字格式中的数据量呈指数级增长。这一趋势可以追溯到今天。在本章中，将对大数据技术的最新突破进行详细评估。

数据库知识发现（KDD）展现了从数据集中提取相关且可用信息的卓越能力。信息技术的快速发展以及随之而来的数据使得这种能力得以实现。KDD在现实生活中有很多应用，并导致了若干种不同挖掘任务的发展 [2]，包括聚类、关联规则挖掘（ARM）和轮廓检测等。新发现的信息从总体上可以分类为项目集、序列模式、线性指南、图以及许多引人入胜的趋势 [7]。这是因为数据和应用中的多样化需求导致了这些新信息的发现。关系数据库在其存储模式中被整齐地组织和约束，这是小数据的特征。分析少量数据的传统方法并不复杂，且基于不同主体之间的关系型数据库模型 [4]。仓库中保留的相对不重要的数据通常可以被整体理解。“大数据”这一术的出现，是因为我们的数字世界中存在着来自广泛领域和资源（包括商业、社交网络、工业等）的非关系、复杂且非结构化的大量数据。产生可理解的小量数据是大数据的首要目标。大规模数据的可用性为多个行业的重大发展开启了大门。总而言，数据技术和海数据技术与传统数据工具是互补的。大数据仍然是一个基本概念，也是整个宇宙中最最近的争议话题之一 [5]。

在我们工作的科学和研究领域中，海量数据改变了我们过去进行研究的方式，也改变了我们现在控制大量复杂且往往无法获取的数据时进行研究和分析的方式。大数据挖掘是一项新的科学突破，并不断改进以更好地服务我们 [6]。随着资源共享日益增长的发展，分布式系统正在开发中，这些分布式系统可以被用于加速计算 [7]。利用复杂技术从海量数据中获取信息的实践被称为数据挖掘或 DM。它在现实世界中有着广泛的实际应用。然而，传统的DM算法假设数据是收集在一个地方的、是内存驻留的，且是不变的 [8]。当你只有少数可用资源时，管理和处理海量数据可能是是具有挑战性的。例如，海量数据可以在短时间内产生并存储在多个站点 [9]。大量数据的可用性为各个领域的重大进展铺平了道路。总的来说，数据技术和海数据技术与标准信息分析器是互补的。尽管如此，大数据仍然是数据世界讨论的主题 [10]。

电子业务中的决策过程变得更加复杂和困难，主要因为大量的记录和随之而来的信息过载 [11–13]。为了在各种应用中实施更有效的新技术，必须对大数据技术的演变有坚实的理解。近年来，虚拟现实的各种用途受到了广泛关注。元宇宙是虚拟现实领域最具创新性的概念之一。数字孪生和其他相关技术用于在分布式的三维元宇宙中生成真实世界的反映 [14]。

## 4.2 大数据挖掘中的挑战

由于数据的异构性、速度、体量和真实性，DM 面着许多困难。大数据的巨大规模要求开发能够高效处理海量信息的创新方法和算法。传统的DM技术往往难以跟上大数据的巨大规模和复杂本质。此外，由于数据生成的实时性，必须解决一些挑战以保证快速的处理和分析。多种数据类型可能包含结构化、半结构化和非结构化数据，这进一步增加了挖掘过程的复杂性。验证数据的完整性（这与其真实性、可靠性和质量相关）仍然是一个重大挑战 [15]。

商业世界的研究人员和专家一直在构建可以扩展到管理海量数据的DM算法，以解决这些问题。使用分布式处理框架、并行计算和前沿ML算法等技术，可以快速高效地处理大量数据 [16–19]。

## 4.4 分布式系统与数据挖掘

分布式系统的研究属于计算机科学中被称为分布式计算的学科范畴 [23]。分布式系统是指系统的各个组件托管在通过网络连接的独立计算机上的系统。这些计算机可以通过向任何系统发送消息来相互通信并协调活动 [24]。共同目标可以通过组件间的相互作用来实现。分布式系统的特征在于具有三个重要特性：组件的并发运行、其缺乏集中时钟，导致各个组件之间发生分解 [26]。还有许多其他类型的分布式系统，例如基于面向服务的架构（SOA）、对等网络技术（P2P）以及大规模交互在线游戏 [26]。分布式程序是专门为运行在分布式系统中而创建的计算机程序，创建此类程序的过程被称为分布式编程 [27]。消息传递机制有不同的实现类型，某些类似于远程过程调用（RPC）连接器、消息队列和 HTTP [28]。利用不同的计算机系统协作解决计算问题是分布式计算的另一种定义。在分布式计算中，问题被划分为若干个较小的任务，每个任务被分配给一台或多台机器。分布式系统的扩展架构如图 4.2 所示。

## 4.5 大数据挖掘的机遇

大数据中包含的海量信息为在各个领域运营的企业和组织创造了巨大的前景。海量数据的挖掘使其更容易发现有价值的洞察、趋势和相关性，所有这些都能驱动战略决策。当组织利用包括深度学习（DL）和机器学习（ML）在复杂的分析方法时，就可以发现隐藏模式、进行预测分析并改进业务流程 [20, 29–31]。挖掘大量数据还可能为客户提供个性化服务、开展更具针对性的营销活动并提高运营效率。在当今数据驱动的经济中，成功实施海量数据挖掘技术的企业比其竞争对手具有显著优势 [21, 32, 36]。

### 4.5.1 大数据挖掘应用

大数据挖掘的应用非常多。分布式处理和大数据挖掘都为从大型复杂数据集中获取有意义的洞察提供了巨大的潜力。此外，大数据挖掘在许多行业中改进物流、优化供应链和提高运营效率方面至关重要。

- **营销领域：** 大数据挖掘允许公司研究行为、划分目标并制定营销活动。
- **社交媒体平台：** 社交媒体平台利用大数据挖掘监控用户交互、情感分析和趋势识别。
- **健康领域：** 医疗健康大数据挖掘有助于监测、疾病预测和个性化治疗。根据统计，全球数据量预计每年增长三倍。根据预测，全球健康数据存储市场预计将从2020 年的30.8 亿美元增长到2027 年的61.2 亿美元 [37]。

### 4.5.2 大数据技术趋势

基于大规模数据的技术现在对于企业的成功至关重要，大数据技术在多年来取得了显著进展，现在几乎存在于我们日常生活的方方面 [50]。专门从事在线零售的公司（如阿里巴巴、亚马逊和沃尔玛等）正利用尖端的数据挖掘技术为客户提供个性化的购物体验和购买建议。涉及收发货的公司（包括联邦快递、UPS 和 CSX Transport 等）已经采用了基于传感器的大数据技术和机器学习（ML）方法论来提高“最后一公里交付”的效率。

### 4.5.3 大数据挖掘中使用的工具

存储海量数据并不困难；相反，处理大数据最具挑战性的方面是如何将这些海量数据转化为有价值的东西。“大数据”一词描述了对多种类型数据的收集和处理，包括组织化的、半组织化的、非结构化的以及无方向的数据库 [51]。这类数据可能会占用大量的存储空间，在现代以拍字节（PB）、艾字节（EB）或泽字节（ZB）为单位，并需要专门的工具来管理如此巨大的容量。

如今的许多企业（包括 Google 和 Facebook）都在处理大数据。Google 并不采用传统的数据处理方法，而是使用专门的大数据工具来编辑、保留和检查收集到的流数据。此外，还有几种不同的数据工具可能用于收集、评估和解释各种复杂且独特的数据类型 [52]。一些最强大的开源大数据工具——Hadoop、MapReduce、NoSQL 将在本节中介绍。

- (i) NoSQL：该程序除了传统的 SQL 方法外，还使用新的和替代策略来查询和检索大量、复杂、不完整且无关的数据集 [53]，该数据集可以远程维护在云端数据集的许多虚拟机上。“Not Only SQL”（不仅是 SQL）一词是指该工具结合了两个部分。
