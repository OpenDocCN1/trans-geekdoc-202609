
### 12.1.3 因子分析的识别问题

*   **权重上的稀疏性促进先验** 我们可以不预先指定 `W` 中哪些条目为零，而是使用 $\ell_1$ 正则化 (Zou et al. 2006)、ARD (Bishop 1999; Archambeau and Bach 2008) 或尖峰-平板先验 (Rattray et al. 2009) 来鼓励条目为零。这称为**稀疏因子分析**。这不一定确保唯一的 MAP 估计，但确实鼓励可解释的解。见第 13.8 节 TODO。

*   **选择一个启发性的枢轴网格** 有一系列启发式技术试图找到旋转矩阵 `R`，可用于修改 `W`（以及随后的潜在变量）以尝试提高可解释性，通常通过鼓励它们（近似）稀疏。一种著名的策略称为 **varimax** (Kaiser 1958)。

*   **对潜在因子使用非高斯先验** 在第 12.6 节中，我们将讨论如何用非高斯分布替换 `p(z_i)` 可以使我们有时唯一地识别 `W` 以及潜在变量。这种方法称为 **ICA**。

#### 12.1.4 因子分析器混合模型

FA 模型假设数据存在于低维线性流形上。实际上，大多数数据最好用某种形式的低维弯曲流形来建模。我们可以用分段线性流形来近似弯曲流形。这提出了以下模型：设第 `k` 个维度为 `L_k` 的线性子空间由 `W_k` 表示，对于 `k = 1:K`。

假设我们有一个潜在指示器 `q_i ∈ {1, ..., K}` 指示我们应该使用哪个子空间来生成数据。然后我们从高斯先验中采样 `z_i` 并将其通过 `W_k` 矩阵（其中 `k = q_i`），并添加噪声。更准确地说，模型如下：

$$p(q_i | \theta) = \text{Cat}(q_i | \pi) \tag{12.13}$$

$$p(z_i | \theta) = \mathcal{N}(z_i | 0, I) \tag{12.14}$$

$$p(x_i | q_i = k, z_i, \theta) = \mathcal{N}(x_i | W_k z_i + \mu_k, \Psi) \tag{12.15}$$

这被称为**因子分析器混合模型**（MFA）(Hinton et al. 1997)。

另一种思考这个模型的方式是作为高斯混合模型的低秩版本。具体来说，该模型需要 `O(KLD)` 个参数，而不是全协方差高斯混合模型所需的 `O(KD²)` 个参数。这可以减少过拟合。事实上，MFA 是高维实值数据的一个很好的通用密度模型。

请注意，这些更新适用于标准 EM。鉴于 ECM，这种计算的一种快得多的形式描述在 (Zhao and Yu 2008) 中。

#### 12.1.6 使用缺失数据拟合 FA 模型

在许多应用中，例如协同过滤，我们会遇到缺失数据。用 EM 方法拟合 FA/PPCA 模型的一个优点是它很容易扩展到这种情况。然而，如果缺失信息过多，过拟合可能会成为一个问题。因此执行 MAP 估计或使用贝叶斯推断。详情请参阅 (Ilin and Raiko 2010) 等。

#### 12.1.5 因子分析模型的 EM 算法

下面我们给出结果而不做证明。推导过程可见 (Ghahramani and Hinton 1996a)。要获得单变量分析器的结果，只需在下面的公式中设置 `ric = 1` 和 `c = 1`。在第 12.2.4 节中，我们将看到拟合 PPCA 模型时这些公式的进一步简化，届时结果将具有特别简单和优雅的解释。

在 E 步中，我们使用以下公式计算数据点 `i` 对组 `k` 的后验责任：

```
rik = p(qi = k | xi, θ) ∝ πk N(xi | µk, Wk Wk^T + ψk)  (12.16)
```

`zi` 的条件后验分布由下式给出：

```
p(zi | xi, qi = k, θ) = N(zi | µik, Σik)  (12.17)
Σik ≜ (I + Wk^T ψk^−1 Wk)^−1  (12.18)
µik ≜ Σik Wk^T ψk^−1 (xi − µk)  (12.19)
```

在 M 步中，通过定义以下量，同时估计 `µk` 和 `Wk` 最为直接：

```
W̃k = (Wk, µk)  (12.20)
z̃ = (z, 1)  (12.21)
bik = E[z | xi, qi = k] = E[(µik; 1)]  (12.22)
Cik = E[zz^T | xi, qi = k]  (12.23)
```

```
(E[zz^T | xi, qi = k]  E[z | xi, qi = k]) = E[z | xi, qi = k]^T 1  (12.24)
```

然后 M 步如下：

```
π̂k = 1/N ∑ rik  (12.25)
W̃k = (∑ rik xi bik^T) (∑ rik xi Cik)^−1  (12.26)
Ψ̂ = 1/N diag ∑ rik (xi − W̃k bik) xi^T  (12.27)
```

### 12.2 主成分分析 (PCA)

考虑一个 FA 模型，其中我们约束 `Ψ = σ²I`，且 `W` 为正交矩阵。可以证明 (Tipping and Bishop 1999)，当 `σ² → 0` 时，该模型退化为传统的（非概率）主成分分析 (PCA)，也称为 Karhunen-Loève 变换。`σ² > 0` 的变体称为概率 PCA (PPCA) (Tipping and Bishop 1999)，或合理 PCA (Roweis 1997)。

#### 12.2.1 经典 PCA

##### 12.2.1.1 定理陈述

经典 PCA 的组合视角总结在以下定理中。

**定理 12.1。** 假设我们需要寻找一组 `L` 个正交基向量 `wj ∈ RD`，以及相应的得分 `zi ∈ RL`，使得我们最小化平均重构误差

```
J(W, Z) = 1/N ∑ ||xi − x̂i||²₂  (12.28)
i=1
```

其中 `x̂i = W zi`，受约束于 `W` 是正交的。等价地，我们可以将此目标写为如下形式

```
J(W, Z) = 1/N ||X − W Z^T||²_F  (12.29)
```

其中 `Z` 是一个 `N × L` 矩阵，其列为 `zi`，`||A||_F` 是矩阵 `A` 的 Frobenius 范数，定义为

```
||A||_F ≜ √(∑∑ a²_ij) = tr(A^T A)  (12.30)
i=1 j=1
```

标准做法是先标准化数据，或者等价地，使用相关矩阵而不是协方差矩阵。

最优解通过设置 `Ŵ = VL` 获得，其中 `VL` 包含经验协方差矩阵中具有最大特征值的 `L` 个特征向量，

```
Σ̂ = 1/N ∑ xi xi^T. （为符号简便，我们假设 xi 均值为零。）
i=1
```

此外，数据的最优低维编码由 `zi = W^T xi` 给出，这是数据在特征向量张成的列空间上的正交投影。图 12.1(a) 展示了 `D = 2` 和 `L = 1` 时的一个示例。倾斜的线是向量 `w1`；这被称为第一主成分或主方向。数据点 `xi ∈ R²` 被正交投影到这条线上以获得 `zi ∈ R`。这是对数据的最佳 1 维近似。（我们稍后将讨论图 12.1(b)。）

#### 12.2.2 奇异值分解 (SVD)

我们已经用协方差矩阵的特征向量刻画了 PCA 的解。然而，还有一种基于奇异值分解 (SVD) 的求解方法。这本质上将特征向量的概念从方阵推广到了任意矩阵。

![](img/image_rsrc1RU.jpg) (a)

![](img/image_rsrc1RV.jpg) (b)

**图 12.1：** `D = 2` 和 `L = 1` 时 PCA 和 PPCA 的示意图。圆圈是原始项目，叉号是重构。红星是数据均值。(a) PCA。点被正交投影到线上。(b) PPCA。投影不再是正交的：重构向数据均值（红星）收缩。

主方向是数据显示最大方差的方向。这意味着 PCA 可能会被那些仅因测量尺度而导致方差高的方向误导。因此

**定理 12.2. (SVD)。** 任何矩阵都可以分解如下

```
X = U Σ V^T  (12.31)
N×D  N×N  N×D  D×D
```

其中 `U` 是一个 `N × N` 矩阵，其列正交归一化（即 `U^T U = I`），`V` 是 `D × D` 矩阵，其行和列正交归一化（即 `V^T V = V V^T = ID`），`Σ` 是一个 `N × D` 矩阵，包含主对角线上的 `r = min(N, D)` 个奇异值 `σ ≥ 0`，其余位置填充 `0`。

这展示了如何将矩阵 `X` 分解为三个矩阵的乘积：`V` 描述数据空间中的一组正交基，`U` 描述余域中的一组正交基，`σ` 描述 `V` 中的向量被拉伸多少以得到 `U` 中的向量。由于最多有 `D` 个奇异值（假设 `N > D`），`U` 的最后 `N − D` 列无关紧要，因为它们将乘以 `0`。经济型 SVD 或精简 SVD 避免计算这些无用元素。

让我们用 `Û Σ̂ V̂^T` 表示这种分解。如果 `N > D`，我们有

```
X = Û Σ̂ V̂^T  (12.32)
N×D  N×D  D×D  D×D
```

如图 12.2(a) 所示。如果 `N < D`，我们有

```
X = Û Σ̂ V̂^T  (12.33)
N×D  N×N  N×N  N×D
```

计算经济型 SVD 需要 `O(ND min(N, D))` 时间 (Golub and van Loan 1996, p254)。

特征向量与奇异向量的联系如下：

```
U = evec(X X^T)  (12.34)
V = evec(X^T X)  (12.35)
Σ² = eval(X X^T) = eval(X^T X)  (12.36)
```

证明请阅读 MLAPP 第 12.2.3 节。由于特征向量不受矩阵线性缩放的影响，我们看到 `X` 的右奇异向量等于经验协方差 `Σ̂` 的特征向量。此外，`Σ̂` 的特征值是平方奇异值的缩放版本。

然而，PCA 和 SVD 的联系更深。从公式 12.31，我们可以得到一个

![](img/image_rsrc1RW.jpg) (a)

![](img/image_rsrc1RX.jpg) (b)

**图 12.2：** (a) 非方阵 `X = U Σ V^T` 的 SVD 分解。`Σ` 的阴影部分及所有非对角项均为零。`U` 和 `Σ` 中的阴影条目在经济型版本中不计算，因为它们不是必需的。(b) 秩为 `L` 的截断 SVD 近似。

```
||X − XL||_F ≈ σL  (12.38)
```

此外，可以证明 SVD 提供了矩阵的最佳秩 `L` 近似（最佳指在最小化上述 Frobenius 范数的意义上）。让我们将其联系回 PCA。设 `X = U Σ V^T` 为 `X` 的精简 SVD。我们知道 `Ŵ = V`，并且

```
Ẑ = X W, 所以
Ẑ = U Σ V^T V = U Σ  (12.39)
```

此外，最优重构由 `X̂ = Z W` 给出，所以我们发现

```
X̂ = U Σ V^T  (12.40)
```

这正是截断 SVD 近似！这是 PCA 是数据最佳低秩近似这一事实的另一种表述。

#### 12.2.3 概率 PCA

**定理 12.3. ((Tipping and Bishop 1999))。** 考虑一个因子分析模型，其中 `Ψ = σ²I` 且 `W` 是对称的。观测数据对数似然由下式给出

```
log p(X | W, σ²I) = -N/2 ln|C| - 1/2 ∑ xi^T C⁻¹ xi  (12.41)
i=1
```

其中 `C = W W^T + σ²I` 且 `Σ = 1/N ∑ xi xi^T = 1/N X X^T`。（为符号简便起见，我们预期聚焦信息。）对数概率的极大值由下式给出

```
Ŵ = V (Λ - σ²I)^(1/2) R  (12.42)
```

其中 `R` 为任意 `L×L` 对称矩阵，`V` 为 `D×L` 矩阵，其列为 `Σ` 的前 `L` 个特征向量，`Λ` 为对应的对角特征值矩阵。在不失一般性的前提下，我们可以设定 `R = I`。此外，噪声方差的 MLE 由下式给出

```
σ̂² = 1/(D-L) ∑ λj  (12.43)
j=L+1
```

即与被丢弃维度相关的平均方差。因此，当 `σ² → 0` 时，有 `Ŵ → V`，正如经典 PCA 中那样。那 `Ẑ` 呢？很容易看出，关于潜在变量的后验由下式给出

```
p(zi | xi, θ) = N(zi | F⁻¹ Ŵ^T xi, F⁻¹)  (12.44)
F ≜ Ŵ^T Ŵ + σ²I  (12.45)
```

（不要混淆 `F = Ŵ^T Ŵ + σ²I` 与 `C = Ŵ Ŵ^T + σ²I`。）因此，当 `σ² → 0` 时，我们发现 `Ŵ → V`，`F → I` 且 `zi → V^T xi`。这样，后验均值是通过将数据正交投影到 `V` 的列空间上获得的，正如传统 PCA 中那样。然而请注意，如果 `σ² > 0`，后验均值**不是**正交投影，因为它会在一定程度上向先验均值收缩，如图 12.1(b) 所示。这听起来像是一个不好的性质，但它意味着生成的样本将更接近总体数据均值，`µ = x̄`。

#### 12.2.4 PCA 的 EM 算法

尽管拟合 PCA 模型的典型方法使用特征向量技术或 SVD，但我们同样可以使用 EM，这最终将具有一些我们将在下文讨论的优势。PCA 的 EM 依赖于 PCA 的概率公式。然而，正如 (Roweis 1997) 所示，该算法在零噪声极限 `σ² = 0` 下仍能工作。令 `Z̃` 为一个 `L×N` 矩阵，沿其列存储后验均值（低维表示）。

类似地，令 `X̃ = X^T` 沿其列存储原始数据。根据公式 12.44，当 `σ² = 0` 时，我们有

```
Z̃ = (W^T W)⁻¹ W^T X̃  (12.46)
```

这构成了 E 步。注意这只是数据的一个正交投影。

根据公式 12.26，M 步由下式给出

```
W = (∑ xi E[zi]^T) (∑ E[zi] E[zi]^T)⁻¹  (12.47)
i=1 i=1
```

其中我们利用了当 `σ² = 0` 时 `Σ = cov[zi | xi, θ] = 0` 这一事实。 (Tipping and Bishop 1999) 表明 EM 算法唯一的稳定不动点是全局最优解。也就是说，EM 算法收敛到一个解，其中 `W` 跨越的线性子空间与由前 `L` 个特征向量定义的子空间相同。然而，如果我们需要 `W` 是正交的，并按特征值降序包含特征向量，我们必须对结果矩阵进行正交化（这可以高效完成）。或者，我们可以修改 EM 以直接给出主基（Ahn and Oh 2003）。当 `D = 2` 且 `L = 1` 时，该算法有一个简单的物理类比 (Roweis 1997)。考虑一些连接在 `R²` 中的弹簧，它们连接到一根刚性杆上，杆的方向由向量 `w` 定义。令 `zi` 为第 `i` 个弹簧连接杆的位置。请参阅 MLAPP 图 12.11 以获取示意图。除了这种令人满意的直观解释外，PCA 的 EM 相比特征向量方法还具有以下优势：

*   **EM 可以更快**。具体而言，假设 `N, D >> L`，EM 的主要开销是 E 步中的投影操作，因此总时间为 `O(T LND)`，其中 `T` 是迭代次数。这比直接特征向量方法所需的 `O(min(ND², DN²))` 时间快得多，尽管更现代的特征向量技术（如 Lanczos 算法）的运行时间与 EM 相当。

*   **EM 可以在线执行**，即我们可以随着数据流入更新对 `W` 的估计。

*   **EM 可以以简单的方式处理缺失数据**（参见第 12.1.6 节）。

*   **EM 可以扩展以处理 PPCA/FA 模型的混合**。

*   **EM 可以修改为变分 EM 或变分贝叶斯 EM，以拟合更复杂的模型**。

### 12.4 面向分类数据的 PCA

在本部分中，我们考虑将因子分析模型扩展到观测数据为分类型而非实值型的情况。即，数据具有结构 `yij ∈ {1, ..., C}`，其中 `j = 1 : R` 是观测到的响应变量的数量。我们假设每个 `yij` 由一个潜在变量 `zi ∈ RL` 生成，该变量服从高斯先验，并通过 softmax 函数变换：

```
p(zi) = N(zi | 0, I)  (12.48)
p(yi | zi, θ) = ∏ Cat(yir | S(Wr^T zi + w0r))  (12.49)
r=1
```

其中 `Wr ∈ RL` 是响应 `j` 的因子载荷矩阵，`W0r ∈ RM` 是响应 `r` 的偏置项，且 `θ = (Wr, W0r)R`。（我们确实需要一个显式的偏置项，因为将 `zi` 的一个分量钳制为 1 在计算后验协方差时可能会引起问题。）与因子分析一样，我们将先验均值设为 `µ0 = 0`，先验协方差设为 `V0 = I`，因为我们可以通过改变 `w0j` 来捕捉非零均值，通过改变 `Wr` 来捕捉非单位协方差。我们将此称为分类 PCA。相关模型的讨论请参见第 27 章 TODO。
