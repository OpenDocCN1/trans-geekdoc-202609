# 关于作者

当我 7 岁的儿子向他的二年级同学介绍我时，他表达得最到位：“我妈妈教好人如何把坏人隔在他们的电脑之外。她有一把蓝色的光剑。”

我已经在技术行业工作了 20 多年，担任过从营销、培训到网页开发和硬件的各种职位。我曾在一家私立小学/初中担任 IT 总监，并在路易斯安纳州立大学教授研究生课程的技术讲师。我曾为世界 500 强企业提供过培训和咨询，并拥有工作和培训美国国防部的实战经验，专注于高级网络安全。
