
# 术语表

## A

### ISA-99 / IEC 62443
: 一组国际自动化学会标准，定义了在工业自动化和控制系统环境中实施安全的程序。该标准以四个类别的形式存在，涉及通用安全概念度量、系统所有者策略和程序、安全系统设计（使用区域和管道方法实施安全）以及系统安全产品或组件。

### 影响评估与分析
: 确定哪些单独威胁对组织构成危险的业务功能，以便实施适当的主动措施。

### 带内
: 一种虚拟化方案，将设备置于存储服务器和磁盘阵列之间的直接路径上。此配置消除了在每台服务器上安装设备相关软件的需求，而带外配置则需要。

### 事件响应策略
: 旨在为物理灾难、网络灾难或安全攻击情况下的人员职责、时间、地点提供指导的组织策略。

### 工业过程控制器
: 根据其内部配置或编程，基于输入的当前状态产生输出条件的控制设备。这些设备可以是独立的或联网的，也可以是模拟或数字性质的。示例包括 `PLC`、`RTU`、`IED`、模拟控制器等。

### 工业/公用事业风险评估
: 面向工业和公用事业流程的风险评估，包含许多与企业网络中使用的不同的风险分析工具。特别是，面向 OT 环境的风险评估必须包含过程危害分析 (`PHA`)。

### 基础设施安全
: 应用于为企业、组织或社会运营所需的基本物理和组织结构提供安全保障的物理安全举措。

### 入口权限
: 个人进入财产的权利。

### 内部周界
: 通常涉及墙壁、门和窗户等物理屏障的周界——根据外部周界的背景，这些屏障可以是外部的，也可以是内部的。

### 输入设备
: 用于将信息引入电子设备的设备。

### 输入传感器
: 收集关于待控制系统信息的设备。

### 输入/输出控制器
: 将输入和输出连接到中央控制设备（如微处理器或 `CPU`）的设备或系统。智能电表中负责在电表的其他系统组件与外部世界之间提供物理连接兼容性的部分。

### 内部威胁
: 存在于网络内部的威胁类型，有时表现为员工。

### 无形财产安全
: 保护非物理性质财产（如电子数据、专利和商标）的过程。

### 积分控制
: 一种控制策略，应用基于微积分的算法于测量变量/设定点差值，以重置控制器的比例动作。

### 智能电子设备
: 提供直接接口以监控和控制过程中的不同传感器和执行器，并能直接与监控控制器、本地 `RTU` 或其他 `IED` 通信的设备。

### 智能传感器
: 将传感装置与 `A/D` 电路和嵌入式微处理器封装在一起，以便能直接与控制器、主控制器或其他类型的控制系统通信的传感器。

### 控制中心间通信协议
: 全球公用事业用于 `SCADA` 主服务器之间、公用事业控制中心之间以及跨广域网的公用事业之间进行实时数据通信的协议。

### 内部安全
: 基础设施安全的最内层；涉及监控内部周界内的区域。

### 互联网号码分配局
: 负责监督 `IP` 地址分配和 `DNS` 根区域管理的组织。

### 互联网工程任务组
: 互联网协议的主要标准机构作为一个大型开放的国际社区运作，该社区由网络设计师、运营商、供应商和研究人员组成，他们关注互联网架构的演进和互联网的顺畅运行。

### 互联网网关
: 用于将网络连接到始终在线的宽带互联网连接的路由器。

### 互联网密钥交换 (IKE)
: 用于在 `IPSec` 中建立安全关联的协议。

### 物联网
: 由具有网络连接功能且能与其他物体通信以收集和交换数据的日常物理对象组成的网络。

### 互联网协议安全 (IPSec)
: 一种常用于 `VPN` 的开放标准，实际上采用一套协议对 `IP` 通信进行加密和认证。

### 互操作性
: 一家公司制造的设备与另一家公司相关设备进行接口连接的能力。

### 内部网
: 单个组织范围内的本地或受限网络。

### 入侵者
: 未经授权访问其无权访问资产的人员。

### iOS
: 苹果的移动操作系统，旨在支持苹果的 `iPhone` 和 `iPad` 产品线。虽然 `iOS` 与 `macOS` 共享许多结构，但它与 `macOS` 应用程序不兼容。

### IP 地址欺骗
: 使用伪造的源 `IP` 地址创建 `IP` 数据包以隐藏身份的过程。

### IP 阻断
: 一种安全形式，阻止特定 `IP` 或 `IP` 范围建立连接。

### IP 摄像头
: 具有 `IP` 地址的数字互联网协议 (`IP`) 设备，可直接连接到网络或互联网，而非直接连接到主机控制器或计算机。

### IP 头部操纵
: 一种用于更改 `IP` 或 `TCP` 网络数据包头部部分所含信息的技术，旨在隐藏用户在网络上的身份。

### IPSec
: 用于建立安全通信的协议套件。`IPSec` 采用 `AH` 和 `ESP` 对每个 `IP` 数据包进行认证和加密。

### IPv4
: 以 `XXX.YYY.ZZZ.AAA` 数字格式存在的互联网地址。每个地址由四个用点 (`.`) 分隔的 8 位字段组成。

### IPv6
: 一种较新的 `IP` 寻址协议，旨在应对可用 `IPv4` 地址短缺的问题。在 `IPv6` 下，`IP` 地址已扩展至 128 位，采用十六进制格式，用冒号 (`:`) 分隔。

### ISO 15408
: 信息技术安全评估通用标准国际标准。

### ISO 2700xx
: 一组 `ISO` 信息安全管理体系标准，旨在为管理层提供保护资产安全的能力。

## 隔离
: 用于隔离或分离网络各部分的物理或逻辑分段。

## J

### 干扰
: 在设备或网络运行的同一频率上故意发射的任意噪声流。

### JFFS2
: `Android` 默认的日志闪存文件系统（版本 2）。此文件系统版本取代了 `YAFFS2`（Yet Another Flash File System），成为早期内核版本中使用的默认 `Android` 闪存文件系统。

## K

### Kerberos
: 一种网络认证协议，涉及受信任的第三方票据授予服务器 (`TGS`) 以认证客户端/服务器交互。

### 内核文件
: 操作系统的基本逻辑文件，负责为中央处理器解释从软件程序获得的命令。

### 无钥匙遥控器
: 一种无线钥匙链设备，可用于锁定、解锁和报警设备。

### 键盘
: 通常配备一组数字按钮的输入设备。键盘用于对各种访问控制和管理设备进行编程、控制和操作。

### 密钥
: 就密码学而言，加密密钥是用于加密或解密信息的数据字符串。加密密钥可以基于仅为加密和解密数据的软件所知的秘密字符串，也可以是随机生成的。也可能是已知因素和随机因素的组合。

### KillerBee
: 用于利用 `ZigBee` 和其他 `802.15.4` 网络的框架。`KillerBee` 提供嗅探、数据包解码和操纵以及注入技术。

## L

### 梯形逻辑图
: 一种常用于定义大多数控制功能的开关和继电器触点的电气图类型。

### 延迟
: 输入系统到达预期输出的延迟。

### 第 7 层攻击
: 一种专注于应用层的 `DDoS` 攻击，通常针对网站的特定区域，旨在耗尽资源。

### 保护层分析 (LOPA)
: `LOPA` 是一种基于规则的 `PHA` 工具，用于为不同的工业处理系统创建风险评估和降低策略。该程序采用通过 `HAZOP` 过程发现的信息和建议的筛选值，然后生成一组用于风险降低的防护措施以供实施。

### 最小权限
: 一种功能，即每个用户仅被授予执行其工作角色所需的访问级别。

### 轻量级目录访问协议 (LDAP)
: 一种用于查询和修改目录服务提供程序中项目的应用协议。`LDAP` 提供单一登录系统，可实现对多种服务的访问。

### 本地防火墙
: 安装、配置并实施在网络主机上的软件防火墙。

### 锁定状态监控
: 一项允许安全主管确认门已锁定的功能。除了监控门或闸的锁定状态外，状态监控系统还可提供门或闸保持锁定的时长和时间段等详细信息。

### 锁定策略设置
: 允许管理员实施密码策略以防止攻击者通过暴力攻击反复尝试访问系统的策略。

### 逻辑炸弹
: 附加在合法程序上的计算机代码，与其他恶意软件非常相似。该代码处于空闲状态，直到特定的逻辑事件发生，之后可能会产生有害影响。

### Logjam 攻击
: 一种针对 `Diffie-Hellman` 密钥交换的安全漏洞，诱使连接使用 `DHE Export` 密码套件。

### 照度等级
: 物体表面接收光通量的度量。一勒克斯约等于一米距离处一支蜡烛照射在一平方米上的光照量。

## M

### MAC 地址
: 媒体访问控制 (`MAC`) 地址是连接到网络的每个设备的唯一标识符。这些地址通常由制造商分配给设备并存储在其固件中。

### MAC 地址过滤
: 一种过滤技术，要求将静态 `MAC` 地址手动输入到内容可寻址存储器 (`CAM`) 表中，或要求指定端口上允许的最大设备数量。

### MAC 地址表
: 一种板载内存结构，托管交换机在其中收集 `MAC` 地址信息以跟踪连接到它们的设备。当它们与这些设备交互时，交换机会在其 `MAC` 地址表中记录其 `MAC` 信息。

### MAC 重复攻击
: 一种网络攻击，攻击者将自己的 `MAC` 地址更新为目标的 `MAC` 地址。这会导致交换机将流量转发到两个位置。也称为 `MAC` 克隆攻击。

### MAC 泛洪
: 一种用于破坏网络交换机安全性的技术。连接到交换机端口的攻击者向交换机接口发送大量伪造的 `MAC` 地址，导致交换机广播帧。

### MAC 地址学习
: 连接设备与连接到其物理端口的其他设备交互，并读取消息头以获取发送和接收设备的 `MAC` 地址的过程。此信息连同其端口信息一起记录在 `CAM` 表中。

### MAC spoofing
: 一种用于更改网络上设备出厂分配的 `MAC` 地址的技术。

### malicious proxy servers
: 用于多种目的的代理服务器，包括恶意软件投放、广告注入和简单的信息收集。虽然这些代理服务器可能不会传递你的 `IP` 地址，但它们会知晓你的 `IP` 地址，并可能将该信息用于其他目的。

### malware
: 描述任意数量的侵入式软件程序的术语，旨在具有恶意性质。

### man-in-the-middle (MITM) attacks
: 一种网络攻击，涉及攻击者创建到两个或多个受害者的链接，以拦截它们之间移动的消息。

### managed switches
: 具有内置可编程管理功能的设备，使管理员能够为其配置特定的网络环境。

### mandatory access control (MAC)
: 一种访问控制类型，利用操作系统来确定哪些用户或组可以访问文件、文件夹和其他资源。

### manipulated variable
: `ICS` 正在控制的变量，如温度、压力、液位等。

### man-machine interface (MMI)
: 界面的交互部分，为人工操作员提供屏幕工具以调整或覆盖控制指令。

### masquerade attack
: 一种攻击，涉及攻击者假冒另一个系统的身份。

### MDK3
: 一种渗透测试工具，用于利用常见的 `802.11` 协议弱点。

### meaningful use
: 以可在质量和数量上显著衡量的方式使用经认证的 `EHR` 技术。

### mesh network
: 一种去中心化的拓扑结构，其中每个节点都为网络中继数据。

### metadata
: 描述或定义数据的信息。该术语用于描述所有可能被视为记录次要目的的数据。通常，`metadata` 被认为是自动生成的、通常嵌入的数据，由信息系统创建以补充甚至验证记录。

### Metasploit
: 一种渗透测试框架，用于识别和验证网络漏洞，包括模拟利用人为漏洞的攻击。它是最流行的开源渗透测试框架之一。

### microcontroller
: 位于单个集成电路上的小型计算机。

### Modbus TCP/IP
: 带有 `TCP` 接口的 `Modbus RTU` 协议。

### Modbus
: 互连智能工业控制设备的事实标准通信协议。`Modbus` 是一种串行通信协议，专门开发用于为工业控制应用提供网络功能。

### motion detectors
: 一种检测移动物体的设备，通常集成在基础设施安全系统中。

### multifactor authentication (MFA)
: 一种访问控制方法，要求以下至少两项：知识、持有和固有特征。

### MultiSpeak
: 一项规范，是企业应用程序互操作性的关键行业通用标准。

## N

### Nagios
: 最知名的网络监控工具之一，有助于确保系统、应用程序和进程正常运行。

### nation-state
: 一个地理区域，包含在一个政府下生活、共享相同历史、语言或传统的一群人。

### National Institute of Standards and Technology (NIST)
: 负责开发网络安全框架、医疗设备安全以及《工业控制系统 (`ICS`) 安全指南》的联邦技术机构。

### natural access control
: 利用自然设计元素（如结构和景观）引导人们进出空间的过程。

### need-to-know policy
: 一种限制员工对整个网络系统了解程度的过程。它类似于职责分离策略。

### neighborhood area network (NAN)
: 常用于智能电表网络，`NAN` 可为一小组 `WLAN` 提供网络连接。

### Network Address Translation (NAT)
: 将一个网络中使用的 `IP` 地址转换为另一个网络中已知的 `IP` 地址。

### network analyzer
: 渗透测试人员用来监听网络流量的工具，查找以明文模式跨网络发送的密码和用户名，或信用卡等敏感财务信息等项目。也称为 `packet sniffer`。

### network-attached storage (NAS)
: 一种虚拟化存储系统，在网络中提供存储和文件系统结构。

### network connectivity devices
: 具有连接功能的设备，如 `routers`、`hubs`、`switches` 和 `bridges`。

### network firewall
: 一种防火墙，通过授予或拒绝受信网络和非受信网络之间特定流量的访问权限，对整个网络执行安全防护。

### network hardening
: 保护网络所涉及的所有过程和技术。

### network monitoring tools
: 可用于确保服务器或其他设备正常启动并运行的任何工具。

### network packet
: 在网络上路由的数据单元。

### network segmentation
: 将网络分离或拆分为一个或多个子网的过程，使每个子网成为独立的网段。

### network topologies
: 第 1 层物理（或逻辑）连接策略，分为四种基本配置：`star`、`bus`、`ring` 和 `mesh`。

### network virtualization
: 创建基于软件的管理实体的过程，利用硬件和软件网络资源以及网络功能。

### network vulnerability scanner
: 用于扫描网络中不同类型的常见漏洞，如系统错误配置和默认密码使用。

### Nikto
: 一款开源 `Web` 服务器扫描器，可识别 `Web` 服务器上的问题。

### NIST 800-82 r2, “Guide to Industrial Control System (ICS) Security”
: 一份为工业控制系统实施网络安全提供指南的文档。

### nmap
: 一款流行的安全扫描工具，用于枚举网络。

### No eXecution (NX) bit
: `CPU` 中用于将内存区域分离为不同用途区域的技术。例如，一块内存区域可专门留作存储处理器指令代码，而另一块区域可标记为仅用于数据存储。

### NTFS permissions
: 新技术文件系统权限，可设置用户可对指定文件或文件夹执行的操作参数。

## O

### OAuth
: 一种认证协议，允许应用程序代表用户行事，而无需共享密码。

### On/Off control
: 仅基于测量变量与参考变量之间关系的控制方案。输出条件只能假设两种状态——完全开启或完全关闭。这种控制由 `on/off` 设备（如 `relays` 和 `electrical switches`）提供。

### open loop control
: 一种不观察反馈输出以调整其所控制过程的过程。因此，在这些系统中，控制器没有机制通过调整输入电平来将过程变量的值控制在指定水平。

### Open Platform Communications (OPC)
: （此处原文仅有标题，无定义内容）

### open systems interconnection (OSI) model
: 用于定义和描述网络环境中通信功能的主要网络模型。

### Open Vulnerability and Assessment Language (OVAL)
: 一种安全社区标准，用于传达配置、漏洞、补丁级别等安全信息。`OVAL` 本质上是一组 `XML` 模式，描述了一种语言，提供评估网络资源安全漏洞所需的详细信息。

### open/close conditions
: 报警传感器的状态或条件，指示“打开”为关闭状态，“关闭”为触发状态。

### OpenVAS
: 开放漏洞评估系统，一个由多种服务和工具组成的开源框架，提供漏洞扫描和管理功能。

### outer perimeter
: 给定区域或边界的第一道防线，可以是物理或逻辑性质的。

### out-of-band
: 虚拟化设备安装在网络和存储系统之间的实际数据路径之外。一种发生在特定电信频带之外的通信方法。发送多信道消息或信令的另一种方式。

### overlay networks
: 在另一个物理或底层网络之上构建网络的情况。

### owner
: 资产的合法拥有者。

### owning group
: `Linux` 权限术语，指共同拥有数据访问权限的一组用户。

### owning user
: `Linux` 权限术语，指拥有数据控制权和访问权的个人。

## P

### packet analyzer
: 用于分析网络流量的计算机程序。也称为数据包嗅探器。

### packet filtering
: 基于源/目的地址、逻辑端口或协议，对网络数据包进行通过或阻止的过程。
