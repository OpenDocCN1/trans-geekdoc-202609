
# 函数极值与梯度下降法

## 函数极值的定义

函数 `y = f(x)` 在某点 `x[0]` 处取得**最小值**：意味着存在某个正数 `ϵ`，使得对于区间 `(x[0] − ϵ, x[0] + ϵ)` 内的每个 x 都满足 `f(x[0]) ≤ f(x)`。`x[0]` 称为函数的**最小值点**，`f(x[0])` 称为函数的**最小值**。

函数 `y = f(x)` 在某点 `x[0]` 处取得**最大值**：意味着存在某个正数 `ϵ`，使得对于区间 `(x[0] − ϵ, x[0] + ϵ)` 内的每个 x 都满足 `f(x) ≤ f(x[0])`。`x[0]` 称为函数的**最大值点**，`f(x[0])` 称为函数的**最大值**。

最小值和最大值统称为**极值**，最小值点和最大值点统称为**极值点**。

如果函数 `f(x)` 定义域内的所有 x 都满足 `f(x[0]) ≤ f(x)`，则 `x[0]` 称为函数的**全局最小值点**，`f(x[0])` 称为函数的**全局最小值**。

如果函数 `f(x)` 定义域内的所有 x 都满足 `f(x) ≤ f(x[0])`，则 `x[0]` 称为函数的**全局最大值点**，`f(x[0])` 称为函数的**全局最大值**。

也就是说，全局最小值是全局范围内的一个最小值，全局最大值是全局范围内的一个最大值。全局最小值和最大值统称为**全局最优**，全局最小值点和最大值点统称为**全局最优点**。

## 函数极值的必要条件

**函数极值的必要条件**：如果 `x[0]` 是函数 `f(x)` 的极值点，且函数在 `x[0]` 处可导，则 `f'(x[0]) = 0` 必须成立。极值点处的导数值必须为 0。

例如，前面的函数 `f(x) = x²` 在 `x = 0` 处取得最小值（当然也是全局最小值）且可导，所以在 `x = 0` 处其导数值 `f'(0) = 2 × 0 = 0` 必须为 0。

这个命题很容易证明。如果 `x[0]` 是函数 `f(x)` 的极值点，则存在一个区间 `(x[0] - ϵ, x[0] + ϵ)` 满足 `f(x[0]) ≤ f(x)`，所以 `f(x) - f(x[0]) ≥ 0`，而：

```
f'(x_0) = lim_{Δx → 0} Δy/Δx = lim_{Δx → 0} (f(x_0 + Δx) - f(x_0))/Δx = lim_{Δx → x_0} (f(x) - f(x_0))/(x - x_0)
```

当 x 从左、右两侧趋向于 `x[0]` 时，`Δx` 分别是负数和正数，而分子始终为正。从右侧 x 趋向于 `x[0]`，其极限值应 `≥ 0`。从左侧 x 趋向于 `x[0]`，其极限值应 `≤ 0`，且该极限存在，所以其值只能是 0。

根据极限公式，也可以找到一条规律。如果 `x[0]` 处的导数是正数，说明函数 `f(x)` 在该点附近单调递增，即如果 `x[1] < x[2]`，则 `f(x[1]) < f(x[2])`，即 `f(x)` 随 x 的增大而增大。或者如果 `Δx` 是正数，则 `Δy` 也是正数。例如，`y = f(x) = x²` 的导数是 `f'(x) = 2x`。当 x 大于 0 时，导数为正。因此，函数曲线单调递增；当 x 小于 0 时，导数均为负数，因此，函数曲线单调递减，即如果 `x[1] < x[2]`，反而 `f(x[1]) > f(x[2])`。

例如，函数 `f(x) = x³ - 3x² - 9x + 2`，令其导数 `f'(x) = 0`：

```
f'(x) = 0  ⇒  (x³ - 3x² - 9x + 2)' = 0  ⇒  3x² - 6x - 9 = 0  ⇒  x² - 2x - 3 = 0  ⇒  x[1] = -1, x[2] = 3
```

可以得到两个导数为 0 的点 `x[1] = -1`，`x[2] = 3`。该函数及其导函数 `f'(x)` 的单调变化如图 2-1 所示：

**图 2-1** `f'(x) > 0`，函数单调递增，`f'(x) < 0`，函数单调递减

在区间 `(-∞, -1]` 中，`f'(x)` 为正数，所以函数 `f(x)` 单调递增；在区间 `(-1, 3)` 中，`f'(x)` 为负数，所以函数 `f(x)` 单调递减；在区间 `[3, ∞)` 中，`f'(x)` 为正数，所以函数 `f(x)` 单调递增。

下面的代码绘制了该函数及其导函数的曲线，可以更直观地看到单调变化和极值点情况。

显然，函数极值的必要条件可以推广到多元函数，即对于多元函数 `f(x[1], x[2], ⋯, x[n])`，如果函数在某点 `x* = (x[1]*, x[2]*, ⋯, x[n]*)` 取得极值，且该点梯度存在（即所有偏导数存在），则该点的梯度必为 0（即各偏导数值均为 0）。即：

```
∂f(x_1, x_2, ⋯, x_n)/∂x_i |_{x*} = 0,  i = 1, 2, ⋯, n
```

## 2.2 梯度下降法

对于一元函数 `f(x)`，如果在某点 `x` 附近有一个微小变化 `Δx`，则 `f(x)` 的变化 `f(x + Δx) - f(x)` 可以用微分形式表示为：

`f(x + Δx) - f(x) ≃ f'(x)Δx`

即在 `x` 附近，如果 `Δx` 和 `f'(x)` 同号，则 `f'(x)Δx` 即 `f(x + Δx) - f(x)` 为正数。如果 `Δx` 和 `f'(x)` 异号，则 `f'(x)Δx` 即 `f(x + Δx) - f(x)` 为负数。如果 `Δx = -αf'(x)`（其中 `α` 为一个较小的正数），则 `f(x + Δx) - f(x) = -αf'(x)²` 为负数，即 `f(x + Δx)` 的值会比 `f(x)` 小。换句话说，`x` 沿着 `f'(x)` 的反方向 `-f'(x)` 移动 `Δx`，其函数值 `f(x + Δx)` 比原来的 `f(x)` 小。

如图 2.4 所示，函数 `f(x) = x² + 0.2` 在 `x = 1.5` 处的函数值 `f(x)` 为 2.45，导数值 `f'(x)` 为 3.0，为正数，指向 `f(x)` 定义域上 `x` 轴的正方向，即 x 轴，如图中长箭头所示。

![](img/file24.png "fig:")

**图 2-4** `f'(1.5) = 3.0 > 0`，`Δx` 与 `f'(x)` 同号移动，函数值增大，反之函数值减小

令 `α = 0.15`，`Δx = -αf'(x) = -0.45`，沿着这个 `Δx` 移动 `x`（图中蓝色箭头方向）到 `x_new = x + Δx = 1.05`，得到新 `x = 1.05` 处的 `f(1.05)` 函数值为 1.3025，即图中曲线上蓝色点的 y 坐标值。因为 `Δx` 与 `f'(x)` 方向相反（一正一负），所以这个 `f(1.05)` 必定比原来的 `f(1.5)` 小。

就这样不断重复这个过程，即 `x` 沿着其导数 `f'(x)` 的反方向（`-f'(x)`）移动微小增量 `-αf'(x)`，就能到达新的 `x_new = x - αf'(x)`，这个新 `x_new` 的函数值 `f(x_new)` 必定比之前的函数值 `f(x)` 小。随着 `x` 接近最小值点的 `x` 值，导数 `f'(x)` 也接近 0（因为函数极值点 `x*` 的导数 `f(x*) = 0`），`x` 移动的增量 `Δx` 也越来越接近 0。

这就是**梯度下降法**的思想，即从一个初始 `x` 开始，用下面的公式不断更新 `x` 的值：

`x = x - αf'(x)`

对于当前的 `x`，沿着其负导数（梯度）方向（即 `-f'(x)`）移动 `x`，可以使 `f(x)` 不断变小。理想情况下，到达使 `f(x)` 最小的 `x`，此时 `f'(x) = 0`。再迭代更新 `x`，`x` 的值也不再变化。如图 2-5 所示，`x` 不断迭代更新，使其不断逼近极值点。

![](img/file25.png "fig:")

**图 2-5** `x` 沿 `-f'(x)` 移动，函数值不断减小

当然，这种移动的步长（即 `-αf'(x)`）不能太大，因为根据导数的定义，上述近似公式仅适用于 `x` 附近。如果移动步长太大，可能会跳过 `x` 的最优值，导致 `x` 的值不断来回震荡。如图 2-6 所示。

![](img/file26.png "fig:")

**图 2-6** `x` 的变化量 `-αf'(x)` 过大，函数值将会震荡

梯度下降法是寻找近似最优解。为了避免无限迭代，可以使用以下方法来检查是否足够接近最优解：

*   导数（梯度）`f'(x)` 的绝对值足够小。
*   迭代次数已达到预设的最大迭代次数。

以下是梯度下降法的代码，其中参数 `df` 用于计算函数 `f(x)` 的导数 `f'(x)`，`x` 是变量的初始值，`alpha` 是学习率，`iterations` 表示迭代次数，`epsilon` 用于检查 `df=f'(x)` 的值是否接近 0。

```python
def gradient_descent(df, x, alpha=0.01, iterations=100, epsilon=1e-8):
    history = [x]
    for i in range(iterations):
        if abs(df(x)) < epsilon:
            print("The gradient is small enough!")
            break
        x = x - alpha * df(x)
        history.append(x)
    return history
```

该梯度下降函数将迭代过程中所有更新的 `x` 保存在 Python 列表对象 `history` 中并返回该对象。

对于上述函数 `f(x) = x³ – 3x² – 9x + 2`，其导数 `f'(x) = 3x² – 6x – 9`。如果想求 `x = 1` 附近函数 `f(x)` 的最小值，可以调用此函数 `gradient_descent()`：

```python
df = lambda x: 3*x**2 - 6*x - 9
path = gradient_descent(df, 1., 0.01, 200)
print(path[-1])
```

```
The gradient is small enough!
2.999999999256501
```

得到 `f(x)` 的极值点 `x = 2.999999999256501`。可以绘制迭代过程中 `x` 对应的曲线上的点：

```python
f = lambda x: np.power(x, 3) - 3*x**2 - 9*x + 2
x = np.arange(-3, 4, 0.01)
y = f(x)
plt.plot(x, y)

path_x = np.asarray(path) # .reshape(-1, 1)
path_y = f(path_x)
plt.quiver(path_x[:-1], path_y[:-1], path_x[1:] - path_x[:-1], path_y[1:] - path_y[:-1], scale_units='xy', angles='xy', scale=1, color='k')
plt.scatter(path[-1], f(path[-1]))
plt.show()
```

**图 2-7** `x` 逐渐收敛到最小值点

其中，matplotlib 的 `quiver` 函数可以用箭头绘制速度向量，其函数格式为：

```
quiver([X, Y], U, V, [C], **kw)
```

其中 `X`、`Y` 为 1D 或 2D 数组，表示箭头的位置，`U`、`V` 为相同的 1D 或 2D 数组，表示箭头的速度（向量）。其他参数请参考官方文档。

对于多元函数，梯度下降法的原理相同，只是用梯度代替导数。

`f(x + Δx) − f(x) ≃ ∇f(x)Δx`

以下是来自维基百科的 Beale 函数。

`f(x, y) = (1.5 − x + xy)² + (2.25 − x + xy²)² + (2.625 − x + xy³)²`

该函数的全局最小值为 `(3, 0.5)`。可以使用以下 Python 代码计算函数值：

```python
f = lambda x, y: (1.5 - x + x*y)**2 + (2.25 - x + x*y**2)**2 + (2.625 - x + x*y**3)**2
```

要绘制该曲面，首先在 `x` 和 `y` 轴上取一些均匀分布的坐标值：

```python
xmin, xmax, xstep = -4.5, 4.5, .2
ymin, ymax, ystep = -4.5, 4.5, .2
x_list = np.arange(xmin, xmax + xstep, xstep)
y_list = np.arange(ymin, ymax + ystep, ystep)
```

然后根据上述 `x_list` 和 `y_list` 使用 `np.meshgrid()` 函数获取其交点处的网格点 `(x, y)`，并计算这些网格坐标点对应的函数值：

```python
x, y = np.meshgrid(x_list, y_list)
z = f(x, y)
```

最后，可以调用 `plot_surface()` 函数绘制该曲面：

```python
ax.plot_surface(x, y, z, norm=LogNorm(), rstride=1, cstride=1,
                edgecolor='none', alpha=.8, cmap=plt.cm.jet)
```

完整代码如下：

```python
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D
from matplotlib.colors import LogNorm
import random

%matplotlib inline

f = lambda x, y: (1.5 - x + x*y)**2 + (2.25 - x + x*y**2)**2 + (2.625 - x + x*y**3)**2

minima = np.array([3., .5])
minima_ = minima.reshape(-1, 1)

xmin, xmax, xstep = -4.5, 4.5, .2
ymin, ymax, ystep = -4.5, 4.5, .2
x_list = np.arange(xmin, xmax + xstep, xstep)
y_list = np.arange(ymin, ymax + ystep, ystep)
x, y = np.meshgrid(x_list, y_list)
z = f(x, y)

fig = plt.figure(figsize=(8, 5))
ax = plt.axes(projection='3d', elev=50, azim=-50)

ax.plot_surface(x, y, z, norm=LogNorm(), rstride=1, cstride=1,
                edgecolor='none', alpha=.8, cmap=plt.cm.jet)
ax.plot(*minima_, f(*minima_), 'r*', markersize=10)

ax.set_xlabel('$x$')
ax.set_ylabel('$y$')
ax.set_zlabel('$z$')

ax.set_xlim((xmin, xmax))
ax.set_ylim((ymin, ymax))

plt.show()
```
