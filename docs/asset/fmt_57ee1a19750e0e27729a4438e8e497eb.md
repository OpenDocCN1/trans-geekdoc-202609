网络基础设施安全是当今组织安全的重要组成部分。这涉及确保连接员工计算机与服务器的网络尽可能安全，以抵御来自网络内外的威胁。

前几章重点介绍了保护单个系统的措施，这非常重要，但你也需要确保连接这些系统的网络尽可能安全。为了给这些系统创建安全的网络基础设施，必须采取`分层安全`方法（也称为`纵深防御`），这包括使用防火墙保护网络基础设施，同时确保使用入侵检测系统来识别可疑的网络流量。

本章将介绍防火墙、入侵检测系统和网络访问控制等主题。你将在 Security+ 认证考试中接受这些技术的测试，因此请确保你熟悉本章内容。

### 认证目标 8.01

#### 理解防火墙

在本节中，你将了解防火墙、代理服务器和其他用于创建安全网络基础设施的安全设备。防火墙和代理服务器是当今网络环境中最常见的两种设备，因为它们负责确保网络外部的未授权人员（如互联网上的用户）无法访问你的网络。

##### 防火墙

防火墙旨在通过分析到达防火墙的数据包并确定每个数据包是否被允许通过，来保护防火墙一侧的系统免受另一侧系统的攻击。你将在防火墙上配置规则，指示防火墙允许哪些流量通过、阻止哪些流量。

> **针对 Security+ 考试，请了解防火墙属于保护性控制的示例，因为它们配置有规则来控制哪种类型的流量可以进入网络。本章还将讨论入侵检测系统（IDS），通常它被视为一种检测性控制——除非它是`主动`IDS，在这种情况下它被称为`入侵防御系统（IPS）`，稍后将详细介绍！**

例如，作为一般规则，你应该将防火墙配置为阻止所有流量，即不允许任何流量通过。配置了“默认”阻止所有流量的规则后，你可以配置规则例外，允许特定流量通过。例如，如果你有一台要暴露在互联网上的 Web 服务器，你会阻止除 TCP 80 端口（Web 服务器流量运行的端口）之外的所有流量（如图 8-1 所示）。

在深入讨论防火墙之前，我必须强调防火墙主要分为两大类。`基于主机的防火墙`是安装在系统上用于保护该单一系统的软件。`基于网络的防火墙`部署在网络边缘，控制允许进出网络的流量。本章重点介绍基于网络的防火墙。

###### 防火墙类型

防火墙随着时间的推移不断发展，对于 Security+ 认证考试而言，了解多年来出现的不同类型的防火墙非常重要。

**包过滤防火墙（无状态）** 第一种类型是包过滤防火墙，也称为`无状态防火墙`。包过滤防火墙可以根据源或目标 IP 地址以及源或目标端口号来阻止或允许流量（称为过滤流量），如图 8-2 所示。

配置包过滤防火墙时，你需要指定控制允许哪种类型的流量通过防火墙以及阻止哪种流量的规则。使用包过滤防火墙时，规则可以根据源地址、目标地址、协议以及源和目标端口地址来过滤流量。

> **包过滤防火墙根据数据包报头中的字段过滤流量，例如源和目标 IP 地址以及源和目标端口号。**

包过滤防火墙被称为`无状态检测防火墙`，因为它仅根据数据包的报头（源/目标 IP 地址或源/目标端口号）来允许或拒绝流量。攻击者可以修改数据包报头中的地址以符合防火墙上设置的规则，随后防火墙就会允许该数据包进入网络。

**有状态包检测防火墙** 乍看之下包过滤防火墙似乎是一种很棒的防火墙类型，但它们并不够智能，因为黑客很容易伪造数据包使其符合防火墙规则。例如，如果你在包过滤防火墙上开放 80 端口，任何目标为 80 端口的数据包都将绕过防火墙。

与包过滤防火墙一样，`有状态包检测防火墙`可以根据源和目标 IP 地址或端口号过滤流量，但它还能查看会话的上下文，判断数据包是否应该在会话的该阶段被接收。如果防火墙接收到的数据包处于正确的会话上下文中且符合某条规则，它将允许该数据包进入网络。有状态包检测防火墙也使用规则过滤流量，但它们足够智能，能够了解会话的上下文。

有状态包检测防火墙了解会话上下文的一个例子是：如果黑客尝试向目标端口 80 发送恶意命令，但未先执行三次握手，防火墙会判定“不行，抱歉，你不允许进入，因为我没看到我们建立了连接”。有状态包检测防火墙知道在 TCP 通信发生前，需要进行三次握手。

> **有状态包检测防火墙通过第 3 层和第 4 层报头过滤流量（类似于包过滤防火墙，即无状态防火墙），此外还能通过了解会话特定阶段预期的数据包来过滤流量。**

###### 应用层防火墙

下一种防火墙类型是应用层防火墙，它实现了包过滤防火墙和状态包检测防火墙的功能，但也可以基于数据包的载荷数据过滤流量。

应用层防火墙不仅实现了包过滤和状态包检测功能，还能检查数据包中的应用程序数据，即所谓的 `payload`（载荷）。这意味着应用层防火墙可以拒绝包含可疑命令的数据包。例如，应用层防火墙可以检查目标端口是否为 80，同时确保没有正在执行 HTTP `put` 命令。或者防火墙可以确保数据是从 FTP 服务器下载的 (`get`)，而不是上传 (`put`) 到服务器（见图 8-4）。

> **应用层防火墙可以基于数据包的数据部分（称为载荷数据）过滤流量。这使得防火墙能够控制哪些类型的操作或命令可以通过数据包的载荷穿过防火墙。**

##### 其他防火墙类型

多年来，防火墙领域不断发展。以下是针对 Security+ 考试需要记住的关于防火墙和防火墙类型的其他重要要点：

- **Web 应用防火墙** `Web 应用防火墙 (WAF)` 是一种应用层防火墙，允许你控制哪些 HTTP 消息可以到达你的 Web 服务器或 Web 服务。控制 HTTP 消息使你能够防御针对 Web 服务器的常见攻击。WAF 与普通网络防火墙的区别在于，WAF 专注于分析 HTTP 流量，而网络防火墙分析所有网络流量。

- **下一代防火墙** `下一代防火墙 (NGFW)` 执行类似状态包检测防火墙的包过滤功能，但也执行深度包检测 (DPI)，这允许防火墙检查数据包的数据部分，并根据数据包的数据采取行动。NGFW 还具有入侵防御功能，允许其根据数据包中发现的头部和数据阻止可疑流量。

- **统一威胁管理** 寻找 `统一威胁管理 (UTM)` 系统，为组织提供一体化安全解决方案。UTM 系统是多功能设备，具有防火墙功能、入侵检测和防御、反垃圾邮件、防病毒和内容过滤等功能。

- **开源与专有** 在考察防火墙解决方案时，你可以选择支持多种不同平台的开源解决方案，也可以选择公司的专有解决方案。

- **硬件与软件** 防火墙可以是连接到不同网段的硬件设备，允许其过滤从一个网段到另一个网段的流量；也可以是运行在系统上的软件，过滤可以通过该系统的流量。

- **设备型与主机型与虚拟型** 你可以使用设备型防火墙、主机型防火墙或虚拟防火墙。设备型的优势在于它是一个独立设备，具有多个接口，通常还附带其他安全功能，如入侵防御功能。主机型防火墙是可运行在不同硬件配置系统上的软件，这在设备型防火墙上可能无法实现。虚拟防火墙是安装在虚拟机中的防火墙软件，可用于保护网络或一组虚拟机。

> **针对 Security+ 考试，了解 WAF、NGFW 和 UTM 防火墙设备之间的区别。**

##### 使用 IPTables 作为防火墙

防火墙的一个重要示例是 IPTables，这是 Linux 中一个非常强大的防火墙功能，取代了较旧的 IPChains 功能。IPTables 这个名字源于控制允许什么流量进入或离开系统，或转发到另一个系统的规则表。

IPTables 使用三个主要表：

- **Input（输入）** 此表控制允许什么流量通过网卡进入 Linux 系统。
- **Output（输出）** 此表控制允许什么流量通过网卡离开 Linux 系统。
- **Forward（转发）** 如果你想将数据包从 Linux 系统转发到另一个系统，则使用此表。

要查看表列表，可以在 Linux 中使用 `iptables -L` 命令。请注意图 8-5 中我有三个表，并且每个表都有默认策略 ACCEPT。这意味着，默认情况下，Linux 允许所有流量进入或离开系统。

如果你想更改 INPUT 表的默认策略，可以使用带有 `-P` 开关的 `iptables` 命令，然后指定默认规则。以下命令用于将 INPUT 表的默认策略更改为 DROP 所有流量：

```
iptables -P INPUT DROP
```

更改表的默认规则（称为策略）后，你可以通过向表追加规则来开始添加例外。在以下示例中，`iptables` 结合 `-A` 用于向 INPUT 表追加一条规则。该规则允许任何源 IP 地址为 10.0.0.1 的 TCP 流量、任何目标地址（源端口范围为 1024 到 65535）以及目标端口地址为 80 的流量通过防火墙。以下命令展示了如何向防火墙添加规则（注意 `-j` 是指定 ACCEPT 或 DROP 动作的方式）：

```
iptables -A INPUT -p tcp -s 10.0.0.1 --sport 1024:65535 -d 0/0 --dport 80 -j ACCEPT
```

##### 家用路由器上的防火墙功能

大多数家庭用户和小型企业使用所谓的“家用路由器”在其网络与 Internet 之间建立高速连接。这些家用路由器的优点在于它们是多功能设备，既是 NAT 设备，也是防火墙设备，并提供 URL 过滤功能，以限制网络上的用户可以访问哪些网站。

默认情况下，家用路由器通常会阻止所有源自 Internet 的流量，因此如果你想在网络内部托管自己的网站，就必须在家用路由器的防火墙上打开其端口。以下是在我的 D-Link DIR-615 路由器上使用的步骤供参考：

1. 启动 Web 浏览器并导航到路由器的内部 IP 地址（通常为 `192.168.0.1`）。
2. 选择页面顶部的“Advanced”链接。
3. 选择屏幕左侧的“Port Forwarding”链接。
4. 进入 Port Forwarding 屏幕后，你可以在防火墙上配置规则，将目标为特定端口的数据包转发给网络内部的某个系统。要允许入站 Web 流量访问你的 Web 服务器，请将以下信息输入到相应字段中（参见 图 8-6）：
   - **Name:** HTTP
   - **IP Address:** `192.168.1.3`（你希望将流量转发到的内部系统的 IP 地址）
   - **TCP:** `80`（流量目标端口；如果流量基于 UDP，也可指定 UDP 端口）
5. 输入规则的所有信息后，单击“Apply”按钮以应用更改。

##### 防火墙拓扑

接下来讨论防火墙拓扑。防火墙的常见配置包括双宿主、屏蔽主机和屏蔽子网防火墙。

###### 双宿主主机防火墙

双宿主主机防火墙由一台具有两个物理网络接口的计算机组成，充当两个网络之间的网关。服务器的路由功能被禁用，以便安装在系统上的防火墙软件可以处理所有流量管理。通常在此系统上运行防火墙软件或代理服务器软件，以将数据包从双宿主系统的一侧传递到另一侧。你必须小心，不要在用作双宿主系统的网络操作系统中启用路由；否则，你将绕过防火墙软件，仅仅是在路由数据。图 8-7 显示了双宿主主机防火墙配置。

###### 屏蔽主机防火墙

许多人认为屏蔽主机防火墙配置比双宿主防火墙更安全。在此配置中，你在双宿主主机和公共网络之间放置一台屏蔽路由器。这使你能在数据包到达双宿主防火墙之前提供包过滤，从而增加一层额外的网络安全。然后，双宿主系统可以运行防火墙软件或代理服务器软件，为该配置提供额外的安全性。图 8-8 显示了屏蔽主机配置。

###### 屏蔽子网防火墙

屏蔽子网防火墙配置通过进一步将内部网络与公共网络隔离，将安全性提升到一个新的水平。在内部网络和双宿主防火墙之间放置一台额外的屏蔽路由器。这提供了两个额外的安全级别。首先，通过在内部添加屏蔽路由器，你可以保护双宿主防火墙主机免受内部来源的攻击。其次，由于攻击者必须穿越的层数增加，外部攻击变得困难得多。通常，外部屏蔽路由器将配置为将通过过滤规则的任何数据发送到双宿主防火墙，后者将对入站流量执行更多测试。入站流量通过双宿主系统执行的测试后，可能会被发送到内部屏蔽路由器，在那里对数据包执行额外的测试。内部屏蔽路由器通常配置为仅接受来自双宿主防火墙的数据，确保黑客无法跳过外部防火墙层。图 8-9 显示了屏蔽子网防火墙配置。
