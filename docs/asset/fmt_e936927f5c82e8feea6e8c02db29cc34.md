
没有任何单一途径能够管理物联网面临的全方位威胁。需要一种“全都要”的方法来增强数字隐私和安全。人们越来越认识到，这种多中心方法是更优的前进路线。这种多层次、多用途、多功能和跨部门的模型由诺贝尔奖得主埃莉诺·奥斯特罗姆（Elinor Ostrom）和文森特·奥斯特姆（Vincent Ostrom）教授在内的学者支持，它通过展示自组织、多尺度网络监管的益处，并考察国家和私人控制在多大程度上与社区管理并存，挑战了正统。正如文森特·奥斯特姆教授最初解释的那样，“多中心政治系统将由：(1) 许多相互独立的自主单位组成，(2) 选择考虑到他人的方式行动，(3) 通过合作、竞争、冲突和冲突解决的过程。”在许多方面，这种治理模型已应用于从管理市中心警察局到适应气候变化甚至减少碎片的各种集体行动问题，考虑到涉及的众多多样化参与者，它非常适合处理动态（且往往是）物联网问题。这些问题的示例包括`Domain Name System`，技术社区为此开发了一项安全升级，但由于“它需要大多数网站采用”，该升级在二十多年后仍未实施。没有任何治理系统是完美的，多中心主义也有其局限性，例如对僵局和缺乏明确层级的担忧。但这种方法可以作为促进某种程度网络和平的总体运动的一部分，有助于有关“物联网安全”的辩论向更有成效的方向发展。

多中心治理的一个重要方面是自律。在某些情况下，自律的能力比成文法律（black letter law）更能、更快地适应快速变化的技术和社会力量。它也比命令与控制型的监管更高效、更具成本效益，尽管考虑到此类努力是自愿的且受市场力量（例如不断变化的消费者需求）的影响，它并非万灵药。只需回顾`Facebook`的改革承诺及其未能实现的失败，就能明白为什么停止互联网平台自治理的呼声正日益受到关注。尽管如此，如前`FTC`主莫琳·奥尔豪森（Maureen Ohlhausen）等监管人员仍支持允许物联网供应商进行自律，这一观点在美国参议院的一项决议中得到了反映，该决议强调了私营部门在开发和监管物联网应用中的核心作用，以及决策者对该问题的高度重视程度。

然而，自治理的失败并非定局。事实上，一些人认为，尽管数据泄露事件频发且几乎没有采取任何惩罚或纠正措施，但在网络安全方面实际上并没有出现市场失灵。另一些人指出，泄露发生后股价并未出现持续下跌，或者对转用收集到的数据缺乏惩罚，这些都是市场未能考虑到松散网络安全的例子。这在很大程度上取决于所涉及社区的类型，以及其有效通信、冲突解决、规范制定以及执行奥斯特姆设计原则（`Ostrom Design Principles`）中列出的集体规则的能力。这类在线社区的种类层出不穷——在`IoT`背景下以及更广泛的范围内都是——它们成功自律的潜力同样存在，而这很大程度上取决于所考虑的`IoT`制造商群体的规模和范围。在其中一些社区中，例如`eBay`或`Facebook`——Murray教授将其描述为“洛克式”，因为用户已将权力移交给中央管理员——某种程度的民主治理可以与既定权威共存，例如通过赋予用户监管和报告错误行为的权力。这种局面可以与所谓的卢梭式社区进行比较，在卢梭式社区中，权力保持去中心化；这仍然是许多`IoT`背景下的现状。然而，由于其规模巨大且极其复杂，这种群体往往是无效的。但是，如果此类社区能够参考互联网工程任务组（`Internet Engineering Task Force`）工作组或欧盟（`EU`）的《通用数据保护条例》（`GDPR`）的案例，增加协作并创建行业行为准则，那么权力可能不需要像在`Facebook`等洛克式社区那样被集中。这可以通过形成微社区来建立信任来实现，例如金融服务联合`Security Operations Center`。

多中心主义理论家（包括Elinor Ostrom教授）赞扬了管理公共资源背景下小型自组织社区的益处，人类学证据也证实，当人类群体规模保持相对较小时，它们在某些指标上的运行效率更高。然而，微社区可能会忽略其他利益、利益相关者及其行动的更广泛影响。为了克服这种冷漠，这些社区必须对结果有明确的投入以实现良好治理，这可以通过教育用户了解网络威胁以及他们帮助管理威胁的权利来实现。

`IoT`包含了这两种类型的社区，但一种倾向于有机、自下而上治理的混合模型可能最合适，这种模型由小型小组组成，其中中央协调发挥作用，制定并执行最佳实践，并防止搭便车者，从而增强`IoT`安全。这种自律具有“适应快速技术进步”的灵活性，可以说比通常采取渐进式改变的成文法更好、更快。它与替代的“一刀切”方法相比，也可能具有更高的效率和成本效益，同时培养了公民美德。尽管如此，它只是一个庞大且复杂的拼图的一部分，这就是为什么自治理只是多中心治理的一个组成部分。然而，正如Murray教授所说的，这并不意味着它不那么重要：“在网络空间中，决定权似乎掌握在社区手中。我们有权控制自己的命运。”一个试图创建此类社区的组织是`Consumer Reports`，自1936年成立以来，它一直处于消费者产品测试和倡导改进的前沿。最近，2017年3月，`Consumer Reports`发布了其`Digital Standard`，该标准旨在“衡量产品、应用程序和服务的隐私和安全性……让消费者成为数字市场的主人”。一旦`Digital Standard`成熟，它将赋予消费者选择符合严格隐私和安全标准的产品（包括`IoT`背景下）的能力。随着时间的推移，该`Standard`有望帮助市场运行更高效。它通过奖励那些重视网络安全和数据隐私的公司，并对那些不重视这些的公司进行惩罚（通过较低的评分，从而导致收入减少）来实现。这些努力已经产生了影响，例如它们帮助揭露了怀孕和生育类应用`Glow`中的隐私风险。随着`Digital Standard`的不断完善和全球化，可能会进一步影响全球`IoT`隐私和安全标准的轨迹和速度。据报道，`Consumer Reports`正在与欧洲同事合作协调其`Standard`，这可能导致围绕`IoT`背景下网络安全尽职调查的更多规范制定工作。然而，鉴于美国和欧盟在`IoT`治理方面不同的监管立场，障碍仍然存在。

## 美国监管`IoT`的方法是什么？

美国政府长期以来倾向于一种很大程度上是自愿的、特定行业的方法来管理隐私和网络安全威胁，这与下文讨论的欧盟等其他司法管辖区不同，后者更倾向于更全面的措施。`IoT`治理也不例外这一趋势。总体而言，联邦网络安全法在很大程度上尚未准备好缓解`IoT`背景产生的安全或隐私问题。治理漏洞非常常见，正如我们所看到的，只有其中一部分被相关的州法律和国际法填补。

对更全面的法律框架或监管体系的需求，源于保护消费者的同时增强消费者信心的重要性。消费者因物联网（IoT）设备产生的安全风险和漏洞而遭受的影响数不胜计，每种情况可能都需要不同的政策应对。例如，允许访问个人信息可能会对个人生计产生不利影响，范围从信用评分到个人安全不等。此外，除了消费者信任外，“同意”也是在不断发展的物联网世界中经常出现的问题，正如第4章介绍的那样。特别是关于“公平信息实践原则（FIPPs）”的适用性已引发了辩论，这些原则包括通知、访问、选择、准确性、数据最小化、安全性和问责，以及它们是否应该适用于物联网领域。此外，“同意”还与消费者保护法中涉及`privacy-policy`的方面有关，这是另一个尚未准备好应对相互关联的网络安全和隐私问题的领域。例如，传感器设备能够以独特的方式通过导致（无论有意还是无意）的歧视来对消费者福利产生负面影响。这是因为公众对新技术有需求，但“同意”可能无法为消费者提供保障。

`FTC`对其权限的解释允许其对网络安全不达标的公司进行惩罚，前提是这些公司暗示或广告其使用了某些网络安全措施，或者它们运营于医疗保健等高风险的关键性基础设施领域。`FTC`的解释已获得法院的支持。因此，它继续对`Facebook`和`Equifax`等网络安全标准松散的公司进行调查，发布和解令，要求这些公司“在未来20年内建立并维护一个接受独立审计的综合安全计划”。它还针对数据泄露的`Wyndham Hotel`、由于安全摄像头缺陷的`TRENDNet`以及由于其路由器和云服务问题的`ASUSTek`发布了此类指令。`FTC`还发布了非约束性指导意见，以帮助公司应对物联网安全，鼓励它们：

1. 在设计之初就将安全构建到设备中，而不是作为设计过程的事后考虑；
2. 培训员工关于安全性的知识，并确保在组织的适当水平进行安全管理；
3. 确保在聘用外部服务提供商时，这些提供商有能力维持合理的安全，并对提供商进行合理的监督；
4. 当识别出安全风险时，考虑“深度防御”策略，即使用多层安全来防御特定风险；
5. 采取措施防止未经授权的用户访问消费者的设备、数据或存储在网络上的个人信息；
6. 在整个预期生命周期内监控连接设备，并在可行的情况下提供安全补丁以涵盖已知风险。

它还建议公司采用`NIST网络安全框架`（`CSF`）。总而言之，`FTC`建议“采用整体方法处理网络安全和所有面向消费者的软件开发工作，结合‘隐私设计’策略，以应对数据收集、使用、访问、存储和最终安全删除数据的整个生命周期”。

相比之下，`FCC`发布了针对物联网的法规，例如关于物联网设备制造的管理。要求因设备而异，但最近`FCC`推出了相关法规，旨在缩小消费者预期与实际安全功能之间的差距。此外，`FCC`有权对不合规行为处以高达75,000美元的罚款。

另一方面，隶属于商务部的NIST在前总统奥巴马于2013年国情咨文中宣布行政命令，要求该机构制定网络安全和隐私框架后，采取了行动。最初的设想是让NIST与行业伙伴合作，制定一个自愿性的“网络安全框架”，企业可以采用该框架来更好地保护关键基础设施。该框架的1.0版本——《改进关键基础设施网络安全框架》（`NIST CSF`）于2014年2月发布，其支持者认为，该框架旨在“协调共识标准和行业最佳实践，提供一种灵活且具有效益的增强网络安全的方法，帮助关键基础设施的所有者和运营者评估并管理网络风险。”`NIST CSF`由三个主要部分（框架核心、配置文件和分级）组成，自首次发布以来，其下载量超过五十万，证明了它的广受欢迎；而且它通过帮助组织“识别、实施和改进网络安全实践，并为内外部通信网络安全问题建立通用语言”，在明确美国及境外的网络安全问责标准方面产生了影响。事实上，`NIST CSF`在理论上是“自愿的”，但在实践中日益成为强制要求，正如特朗普政府2017年强制所有联邦机构使用该框架的那样。从英特尔到芝加哥大学，各种机构都利用`NIST CSF`创建了企业级热力图、应对已知风险并确保持续的问责制。即使是交通部也利用`NIST CSF`来评估车辆网络安全，尽管他们发现该框架必须经过大幅调整才能在开发实用的车辆安全控制方面发挥作用。

这些案例凸显了`NIST CSF`的灵活性和影响力，这促使NIST在2018年4月发布了`NIST CSF`的1.1版本。正如商务部长威尔伯·罗斯（Wilbur Ross）所认为的那样，“这应该是每家公司的第一道防线”。新版本具有重大改进，包括在身份验证、供应链网络安全和漏洞披露方面，尽管它仍然最好被视为网络安全的底线而非天花板。例如，它并没有特别关注物联网（IoT）问题，而许多人（包括美国商会）希望NIST在其《网络物理系统框架》之外对该领域进行更详细的探讨，因为该框架被认为不够具体（或对用户不够友好），无法像`NIST CSF`对关键基础设施保护的影响那样对物联网产生同样的影响。响应这一呼召，NIST发布了一份物联网网络安全基准草案，并在截至本文撰写时正在收集反馈。

即使这些机构共同行动，它们也没有权限应对物联网面临的全方位网络威胁，即使利用如疏忽、违约和侵犯隐私等现有的普通法诉求也是如此。联邦层面的改革建议层出不穷，尽管某些领域一直对物联网特定立法持抵制态度。前联邦贸易委员会（FTC）主席埃迪丝·拉米雷斯（Edith Ramirez）似乎支持这样观点，即“物联网”是事物自我监管的代名词。然而，FTC鼓励国会制定旨在激励采纳隐私和安全最佳实践的自律计划。这些实践将防止未经授权的访问个人信息，这些访问是“强效、灵活且技术中立的”，但包含了定义明确的数据收集。FTC还发起了一项行动（最初与奥巴马政府合作），作为更广泛的消费者权利法案的一部分，为信息受损的消费者提供联邦违约通知。其他改革建议还包括《2017年物联网网络安全法案》，该法案要求向美国政府销售产品的供应商：(1) 确保其设备“是可以修补的”，(2) 确保它们“不包含已知漏洞”，(3) 它们“依赖标准协议”，以及 (4) 它们“不包含硬编码密码”。然而，该法案对物联网这样一个庞大的领域并未采取“一刀切”的方法。事实上，如果行业提供了“等同或更严格的设备安全要求”，则可以用来替代上述规定。该法案未能通过，但其跨党派赞助人——包括来自弗吉尼亚州的马克·华纳（Mark Warner）——拒绝放弃，他们提交了《2019年物联网（IoT）网络安全改进法案》，该法案截至本文撰写时尚未颁布，但其值得关注之处在于它缩小了“物联网设备”的定义（例如排除了智能手机和个人电脑），并从建立最低标准转向指导NIST为“联邦政府拥有或控制的”物联网产品的“恰当使用和管理”提供建议，以包含最低标准。

其他法案也被提出来以提高物联网安全，包括《2017年物联网消费者TIPS法案》，旨在帮助FTC提升消费者的网络卫生，以及《SMART物联网法案》，该法案将强制商务部“对行业现状进行研究”。后者的法案在众议院以一致通过票通过，但未被参议院受理。美国责任署（GAO）建议美国政府进一步采取措施以减少漏洞，包括：(1) 为国家和全球网络空间制定并执行一项“更全面”的战略，(2) 缓解全球供应链风险，以及 (3) 确保新兴技术的安全性。GAO还支持在美国建立类似于GDPR的隐私制度。

在州层面，加利福尼亚州长期以来一直是环境法和数据隐私等迥异领域的规范创业者，如今再次处于具有国家重要性的紧迫事项的前沿，这次是关于物联网（IoT）的治理。具体而言，加利福尼亚州在2018年底通过了`SB-327`（《连接设备安全法》），该法要求从2020年开始，“任何直接或间接连接互联网的设备制造商必须为其配备‘合理’的安全功能，以防止未经授权的访问、修改或信息泄露。”“合理”的安全功能并未被明确定义，但总而言之，制造商被期望提供免受未经授权访问、修改或信息泄露的保护，例如通过要求唯一密码来避免诸如Mirai僵尸网络之类的攻击。尽管有人认为该法律在追究物联网制造商责任方面做得不够，或者批评其关注于增加新的安全功能而非移除不安全的因素，但这是在采取基于风险的方法处理物联网安全和隐私方面迈出的一步，在相关的NIST、FTC和FCC行动及倡议的背景下，应当予以考虑。例如，NIST国家网络安全卓越中心（`NCCoE`）一直与FIDO联盟合作（这是一个由200多家国际公司组成的非营利标准组织），旨在消除密码并转向更安全的身份验证方式，以防止物联网风险。加利福尼亚州并非孤单，正如在`chapter 7`中进一步讨论的那样——俄亥俄州正在通过提供诉讼避风港，来激励投资于网络安全最佳实践和框架的公司。

时间将证明加利福尼亚州监管物联网设备的方法将有多受欢迎，而且如果其他州采取竞争性的方法，将会有治理挑战需要考虑。但如果历史有任何可资借鉴之处——特别是如果国会继续无法颁布诸如《2019年物联网网络安全改进法案》之类的改革——那么物联网治理的中心（如同数据隐私一样）可能会变成萨克拉门托、北京和布鲁塞尔。

谁拥有你的数据？你对这个问题的回答在很大程度上取决于地理位置，甚至你的邮政编码。如果你是一个欧盟公民，那么正如我们所看到的，消费者在决定谁可以收集、分析并从其个人信息中获利方面处于主导地位。在中国的等其他司法管辖区，尽管通过《个人信息安全规范》努力扩展隐私权利，但隐私权仍然有限。由于`chapter 1`中探讨的网络主权学说，最终是政府拥有中国公民的数据，这一事实通过一项允许警察在没有正当程序的情况下搜索大数据和个人信息的新法变得清晰可见。在美国，正如律师们喜欢说的那样，这取决于情况。例如，加利福尼亚州的居民从2020年起不仅将享受更强大的物联网保护，而且根据一项名为《加利福尼亚消费者隐私法案》（`CCPA`）的透明度法，可能拥有美国最强大的隐私权利，该法包含至少六项隐私权利，包括：访问、可携带性、删除、披露、易退出以及当这些权利被侵犯时的私人诉讼权。尽管这很大程度上是一项自律法（而且在最初通过时充斥着起草错误和逻辑不一致），但该法律仍然引起了波澜，从夏威夷州到密西西比州有六个州正在考虑类似的立法，促使国会对对比联邦法律产生了新的兴趣，以免加利福尼亚的方法因其市场规模而成为国家默认。尽管如此，即使是CCPA也逊于欧洲的数据隐私和网络安全保护，这些保护不仅对欧洲新兴的IoT产生了重大影响，对全球的数据治理也产生了影响；现在已有一百多个国家实施了综合性数据保护法。因此，值得详细考虑一下GDPR。

首先，需要介绍一些背景。GDPR旨在取代20世纪90年代的欧盟《数据保护指令》，并推动欧盟向数字单一市场（`DSM`）迈进。类似于NIST网络安全框架（CSF），它“依赖于各种现有的标准、指南和实践，使关键基础设施提供者实现韧性”，DSM综合了关于安全和数据保护的倡议。最重要的是，DSM将其方法集中在对数据经济（数据自由流动、责任分配、所有权、互操作性、易用性和访问性）的考量上，并承诺解决互操作性和标准化问题”，而这对于提升物联网设备的安全和隐私至关重要。

在此基础之上，GDPR是一项庞大的监管制度，旨在建立一种在整个欧盟范围内一致的消费者保护方法。它包含了一系列要求，从确保数据可移植性和同意，到强制要求企业在获知数据泄露事件后72小时内进行通报，并进行事后分析以确保类似情况不再发生。

其他要求还包括：对于使用个人数据进行的每种类型的处理，都必须获得肯定的、“特定、知情且明确的同意”（这导致了例如冗长且复杂的服务条款的消亡），并防止那些没有足够严厉的隐私法律的第三方国家收集和传输欧盟公民的数据。此外，它还强制要求合规企业任命数据保护官来监督对GDPR的合规情况。
