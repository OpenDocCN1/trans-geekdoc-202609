### 解读结果

完成漏洞扫描后，至关重要的是您要花些时间查看结果，以判断系统是否安全。如果系统不安全，您将需要提出改进安全性的建议。以下列表概述了改进安全性可能采取的一些行动：

#### 卸载软件

漏洞扫描器可能会在扫描后报告你安装了易受攻击的软件。如果该软件未被使用，你可以选择卸载它；如果正在使用，则应为其打补丁。

#### 禁用服务

漏洞扫描器可能会识别出正在运行但通常不被公司使用的常见服务。在这种情况下，你需要禁用这些服务，并将其启动类型设置为“Disabled”。

#### 更新补丁

大多数漏洞评估软件会扫描缺失的补丁。请做好准备，可能会发现缺失某些补丁，并需要测试和安装它们。

#### 更改设置

漏洞评估软件可能会识别出系统上的一些常见配置错误。因此，你通常需要查看设置并更改它们以提高系统安全性。

以下是关于 Security+ 认证考试中漏洞评估的一些关键点：

#### 被动测试安全控制

与渗透测试（主动测试）不同，漏洞评估被视为被动测试，因为它不会真正尝试攻破系统。

#### 识别漏洞

漏洞评估将识别网络和系统中易受攻击的区域。

#### 识别安全控制的缺失

漏洞评估将识别缺失的安全控制。例如，它会识别你是否未在文件夹上配置权限，或者系统上是否未安装防火墙。

#### 识别常见配置错误

漏洞扫描器可能识别出的最重要项目之一是系统配置错误，导致系统更容易受到攻击。

渗透测试人员有许多工具可用于对公司进行侦察（分析）以及信息和系统发现。以下是渗透测试人员常用的一些侦察和发现工具。

### 发现工具

有许多工具用于发现网络上的系统、系统的 IP 地址、网络连接以及互联网上关于公司的公开信息。以下是考试需要了解的发现工具列表。

- **`tracert`/`traceroute`**  
  用于追踪数据包在网络中采取的路径。当数据包到达路由器时，会发回响应，让你知道数据包经过了多少个路由器。示例用法：`tracert www.gleneclarke.com`。

- **`nslookup`/`dig`**  
  `DNS` 查找工具；`nslookup` 在 `Windows` 和 `Linux` 系统上都很常见，而 `dig` 则在 `Linux` 系统上。

- **`ipconfig`/`ifconfig`**  
  分别用于显示 `Windows` 系统或 `Linux` 系统上的 `TCP/IP` 设置。

- **`netstat`**  
  用于查看系统上打开的端口列表，或查看连接到该系统的主机。要查看所有打开的端口，请使用 `netstat -na`。

- **`theHarvester`**  
  一种 `OSINT` 工具，用于从公共互联网源收集员工电子邮件地址、域名、服务器名称和系统开放端口。

##### Ping 工具与扫描器

评估网络的一部分是定位正在运行的系统、运行系统上打开的端口以及可能存在的漏洞。以下是用于 ping 网络上的系统、进行端口扫描和漏洞扫描的工具。

- **`ping`/`pathping`**  
  `ping` 和 `pathping` 都用于测试与远程系统的连通性，但 `pathping` 会显示数据包经过的每一跳。示例用法：`ping 192.168.1.1` 和 `pathping 192.168.1.1`。

- **`hping`**  
  `hping` 是一种允许你构造数据包以绕过防火墙的 ping 工具。例如，如果系统阻止 `ICMP` 数据包，导致你无法 ping 通该系统，你可以使用 `hping` 并指定 `TCP` 协议和一个你认为会开放的端口，以便 ping 消息能穿过防火墙。

- **`IP` 扫描器**  
  `IP` 扫描器用于对网络执行扫描，以检测哪些系统正在运行及其 `IP` 地址。

- **`nmap`**  
  一种常见的网络扫描器，可以执行 ping 扫描以识别系统、端口扫描、横幅抓取和系统枚举。这是考试中必须了解的最常用工具之一！

- **`Nessus`**  
  `Nessus` 是一种常见的漏洞扫描器，用于扫描系统并报告任何漏洞。漏洞报告在渗透测试期间非常有用，因为它还可以让你了解漏洞的 `CVSS` 评分以及是否存在针对它的漏洞利用代码。

##### 无线扫描器/破解工具

当今网络上常用的一组工具是无线扫描器和无线破解工具。无线扫描器是一种可用于发现范围内的无线网络及其特征的工具。例如，使用无线扫描器，你可以看到 `SSID` 名称、信道、使用的加密类型（`WEP`/`WPA2`）和信号强度。无线扫描器的例子包括 `Windows` 上的 `Acrylic Wi-Fi` 和 `Linux` 上的 `Kismet`。

无线破解工具是一种用于破解 `WEP` 或 `WPA2` 保护的无线网络加密密钥的工具。像 `Aircrack-ng` 套件这样的工具可用于捕获无线流量（`airodump-ng`），一旦捕获到足够的流量，即可破解无线加密（`aircrack-ng`）。

##### 蜜罐、蜜网和蜜文件

## 蜜罐

另一种流行的安全评估方法是在网络上设置蜜罐。**蜜罐**是放置在网络上的系统，旨在吸引黑客攻击，而不是让黑客入侵您的生产系统。蜜罐的主要目标是为您争取时间，以便在黑客获得网络访问权限时进行应对。

必须像配置其他系统一样配置蜜罐，并务必遵循安全最佳实践来加固和保护系统。一些 IT 专业人员认为蜜罐应该容易被攻破，但如果太容易，黑客会怀疑这是一个蜜罐。您也希望蜜罐难以破解，因为这会让黑客花费更长时间来入侵，从而给您更多时间来检测入侵者！

确保蜜罐启用了高级别的审核和日志记录，以便捕获黑客执行的所有活动。为了保护日志，请将其写入始终受保护的远程系统。

![Image](img/exam.jpg)

> **蜜罐是了解零日漏洞利用的绝佳方式。** 零日漏洞利用是指未知且难以防范的漏洞利用，因为您不知道该漏洞利用的存在。当您设置蜜罐且黑客使用零日漏洞利用时，蜜罐上的日志文件会让您了解相关情况。

**蜜罐网络**与蜜罐非常相似，因为它旨在引诱黑客，但蜜罐网络是一个由伪造系统组成的完整网络，用于跟踪黑客的活动。

**蜜饵文件**是您留在系统上以诱使攻击者打开的文件。例如，您可以在桌面上放置一个名为 `password.txt` 的文本文件。如果系统被攻破且攻击者打开了该文件，则会发送警报，告知您有人打开了该文件。

![Image](img/exam.jpg)

> **针对 Security+ 考试，请记住蜜饵文件是设计用来诱使攻击者打开的文件。这会触发警报，表明有人在系统上。**

## 其他网络工具

渗透测试人员可能会不时使用许多不同的网络工具。以下是一些更常见的网络工具：

- **`netcat`**  
  用于在系统上打开端口并让进程在该端口上运行。渗透测试人员通常使用它在已被利用的系统上打开后门。

- **`ARP`**  
  用于显示和管理本地系统上 ARP 缓存的内容。

- **`route`**  
  `route` 命令用于修改系统的路由表。

- **`cURL`**  
  客户端 URL（`cURL`）是一种工具，用于使用 URL 和 HTTP、HTTPS、FTP、FTPS 等互联网协议在不同系统之间传输文件。

- **`sn1per`**  
  Sn1per 是一种用于扫描系统漏洞的工具。它结合了 whois、ping、`nmap` 以及针对系统的漏洞利用等功能。

- **`scanless`**  
  一种匿名端口扫描器，可以从许多不同的扫描站点为您执行端口扫描。运行命令时指定要使用的扫描器名称（例如 `scanless -s pingeu -t 192.168.1.1`）。您可以使用 `scanless -l` 查看扫描器列表。

- **`dnsenum`**  
  用于收集特定 DNS 区域的 DNS 记录。

- **`Cuckoo`**  
  一种沙箱环境，允许您运行恶意软件。`Cuckoo` 会向您报告恶意软件在系统上采取的操作。

## 文件操作

由于大多数安全测试工具和框架都在 Linux 上运行，渗透测试人员需要知道用于执行基本文件操作的工具。以下是 Linux 中一些常见的文件操作工具：

- **`head`**  
  一种 Linux 命令，用于报告文件的开头内容（默认前十行）。

- **`tail`**  
  类似于 `head` 命令，但此 Linux 命令用于在屏幕上打印最后十行。

- **`cat`**  
  用于在 Linux 中显示一个或多个文本文件的内容。

- **`grep`**  
  用于在文件中搜索特定字符串。

- **`chmod`**  
  用于更改文件的权限。

- **`logger`**  
  允许您向 `/var/log/syslog` 文件添加日志条目。

  一种安全 Shell 环境，用于通过安全通道获得对系统的远程访问。

  一种安全库，应用程序可用它通过网络建立安全通信通道。

## 数据包捕获与重放

数据包捕获软件或嗅探程序的目的是**被动地**捕获网络上传输的流量，以便查看或分析该流量。在执行安全评估时使用嗅探器的目的是查看是否可以捕获以明文形式在网络上发送的敏感信息。如果您发现数据包捕获中包含密码和其他敏感信息（如图 20-11 所示），则应建议组织加密网络流量。

> **多年前，当我在一家大型全国性公司工作时，员工被告知他们的电子邮件在网络上是加密的。几年后，我们发现我们的电子邮件实际上并未加密——服务器管理员以为他们启用了加密，但不知何故并未启用，且从未验证过。我们之所以发现这一点，只是因为一些正在学习如何监控流量的培训人员发现了正在传输的公司经理的电子邮件。使用数据包嗅探器是验证数据在传输过程中是否真正加密的好方法。**

以下是一些可用于捕获网络数据包的常用工具：

- **`Wireshark`**  
  可能是最常用的数据包捕获工具，可从 [wireshark.org](http://wireshark.org) 免费下载。您可以捕获网络上的数据包、过滤数据包并对其进行分析，以确定网络上的活动。

- **`tcpdump`**  
  一种用于捕获流量的 Linux 命令。例如，您可以使用以下命令在屏幕上显示捕获的数据包：`tcpdump -i eth0`，其中 `-i eth0` 是用于捕获流量的接口。

- **`tcpreplay`**  
  一种用于在网络上重放捕获流量的 Linux 命令。流量首先使用 `tcpdump` 捕获，然后可以使用 `tcpreplay` 在网络上重新发送。

# 安全评估章节总结

在本章中，你学习了执行安全评估的相关知识，主要有两种评估类型——渗透测试和漏洞评估。备考 Security+ 考试时，请牢记以下要点：

- 可执行不同类型的评估，例如威胁评估、配置评估、漏洞扫描和渗透测试。

- 渗透测试被视为主动测试，因为你实际尝试攻破系统并绕过安全控制。漏洞评估是一种被动测试，仅识别系统配置中的安全问题。

- 可使用 `Kali Linux`（前身为 BackTrack）和 `Metasploit` 等工具进行渗透测试，以及 `John the Ripper` 等密码破解工具。

- 可使用多种不同技术来确定安全问题。你可以对公司创建的应用程序执行代码审查，对创建的解决方案执行设计审查以确保其满足初始需求，或对系统执行架构审查以确保其为安全环境。

- 渗透测试应遵循黑客攻击流程的步骤。

- 确保已起草法律文件并由所有相关方签署，授予你执行渗透测试的许可。

- 可使用多种工具执行评估，例如端口扫描器、网络嗅探器、漏洞扫描器、无线扫描器、无线破解工具和蜜罐。

通过深入理解本章呈现的材料，你将轻松应对考试中的安全评估问题。此处呈现的材料不仅对考试至关重要，在你顺利通过考试并继续从事安全专业工作后也将至关重要。

## 理解评估类型

- **风险评估** 涉及识别资产、识别针对这些资产的威胁、确定威胁优先级，然后确定如何缓解这些威胁。

- **配置评估** 涉及审查系统配置并识别安全关注领域。这可能是手动漏洞评估的一部分。**漏洞评估** 通常涉及运行软件来识别安全问题，例如缺失补丁和不良配置。

- **渗透测试** 是一种主动测试，涉及测试人员尝试通过绕过安全控制来攻破系统。应起草并签署法律文件，授予你执行渗透测试的许可。

- **未知环境测试**（formerly known as a black box test，以前称为黑盒测试）涉及在未获得环境任何信息的情况下执行安全评估。**已知环境测试**（formerly known as a white box test，以前称为白盒测试）涉及在已获得配置和网络设置所有详细信息的情况下执行评估。

- 应对公司创建的任何应用程序执行 **代码审查**。

## 执行安全评估

- **漏洞扫描** 是一种被动测试，用于识别系统漏洞，例如缺失补丁和不良配置。
