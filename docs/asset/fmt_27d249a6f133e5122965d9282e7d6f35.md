
`DenseNet` 中的每一层除了接收自身的特征图外，还会接收来自所有之前层的额外输入。由于获取了所有之前层的特征图，该网络具有较少的通道，带有增长率 `k` 作为每层额外通道数的 `3×3` 卷积，以及批次归一化（`BN`）和 `ReLU`。

神经网络的总层数由 `DenseNet-201` 中的 `201` 表示。各种层的组合是 `DenseNet201` 的常见构建方式。它由两个稠密块（`1×1` 和 `3×3` 卷积）、五个卷积和池化层、三个过渡层、一个分类层和三个过渡层组成。

### 14.3.3.5 EfficientNetB6

2019 年开发了 `EfficientNet`。尽管它的学习率比 `ResNet` 稍慢，这是它的缺点，但认为它对于我们的应用具有足够的计算速度和准确性。CNN 通常通过使用模型扩展来增强。性能随着网络深度的增加而提高。可以根据需要增加或减少节点数量来开发有效的模型。然而，这些调整需要手动进行，在多次尝试后，可以利用超参数构建更优的 CNN。

## 14.4 方法论

在神经网络中，神经元和突触连接到数学模型中以模拟人类大脑。本质上，`DL` 使用 `CNN` 层训练模型。本研究分析了五种不同 `DL` 模型区分典型和异常乳腺 X 光图像的能力。所提的研究比较了五种不同模型的性能，包括 `VGG19`、`ResNet50V2`、`InceptionResNetV2`、`DenseNet201` 和 `EfficientNetB6`，并按照以下步骤实施。

**第一阶段：** 数据预处理

**第二阶段：** 使用 `DDSM` 和 `INbreast` 数据集通过迁移学习训练五种不同类型的模型（`VGG19`、`ResNet50V2`、`InceptionResNetV2`、`DenseNet201`、`EfficientNetB6`）

**第三阶段：** 测试并预测良性或恶性图像

**第四阶段：** 使用标准指标比较这五种模型的性能

### 14.4.1 第一阶段：数据预处理

数据库中的乳腺 X 光图像包含各种不良的视觉特征、噪声和伪影，使它们成为会降低分类准确性的低质量图像。为了从 `DL` 模型获得准确的结果，数据集中的输入图像经过了伪影去除、图像缩放和数据增强的预处理。在这项研究中，使用阈值技术 `[30]` 去除伪影并将原始图像缩小为 `224×224` 像素。

数据分类的关键要素，也是 `ML` 和 `DL` 模型最重要的方面是特征提取。特征描述了与各种疾病相关的模式。在 `DL/ML` 模型的训练阶段，这些特征提取组件对于确定数据样本的类别标签至关重要。因此，为了精确预测，训练数据集应该包含大量代表良性和恶性乳腺 X 光检测的数据集。带有和不带数据增强的图像总数如表 14.2 所示。对于所有实验，传统的数据增强通过重缩、剪切范围、缩放范围、验证划分和水平翻转完成。数据增强用于提高模型在训练和测试数据集上的性能。此外，`DL` 模型需要大量信息以便在训练测试期间获得更好的理解。

### 14.4.4 第四阶段：性能分析

${Accuracy} = \frac{TP + TN}{TP + TN + FP + FN} \times 100$ (14.1)

${Recall} = \frac{TP}{TP + FN} \times 100$ (14.3)

$F1 - {Score} = 2 \times \frac{precion \ast recall}{precion + recall}$ (14.4)
