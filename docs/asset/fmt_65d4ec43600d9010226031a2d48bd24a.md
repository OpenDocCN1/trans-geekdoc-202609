### 前向传播

当我们向网络输入一个示例 `x.x1;:::; xn/` 时，其属性值将沿着连接传递给神经元。值 `xk` 与连接关联的权重相乘，第 `j` 个隐藏神经元接收到的输入为加权和 `Pk w xk`，并将和通过 sigmoid 函数![image](img/image172.png).2/`f(Pk w xk)`。然后，第 `i` 个输出神经元接收来自隐藏神经元的加权和![image](img/image172.png).2/![image](img/image112.png)，并再次通过传递函数。这就是获取第 `i` 个输出的方法。

这种将属性值从网络输入传播到输出的过程被称为前向传播。每个类都分配有一个自己的输出神经元，第 `i` 个输出神经元返回的值解释为支持第 `i` 类的证据量。例如，如果三个输出神经元得到的值为 `y.0:2; 0:6; 0:1/`，分类器将给给定示例标记为第二类，因为 `0.6` 大于 `0.2` 和 `0.1`。

## 5.2 神经网络的误差

![image](img/chapter_title_below.png) 

我们将训练多层感知机（即寻找其权重）的技术解释推迟到后后的章节。在解决这个问题之前，有必要通过仔细观察分类方法以及评估这种分类准确率的方法来做好准备工作。

![image](img/image112.png)![image](img/image341.png)

### 错误率

假设一个已知类别为 `c.x/` 的训练样本 `x` 被输入到一个现有版本的多层感知机。前向传播步骤确定了标签 `h.x/`。如果 `h.x/ != c.x/`，则发生了错误。这种情况也可能发生在其他样本上，我们想知道这种情况发生的频率。我们想知道错误率——即对于给定的样本集，通过错误数量除以样本数量得到的比例。例如，如果分类器误分类了 200 个样本中的 30 个，则错误率为 `30/200 = 0.15`。

然而，这无法提供网络分类性能的完整视图。错误率未能反映的是 sigmoid 函数衡量每个误差大小的能力。

![image](img/image133.png)![image](img/image141.png)![image](img/image112.png)

一个例子将阐明这一点。假设我们有两个不同的网络可以选择，每个网络都有三个输出神经元，分别对应标记为 `C1`；`C2` 和 `C3` 的类别。假设对于某个样本 `x`，第一个网络的输出为 `y1.x/ = <0.5; 0.2; 0.9/`，第二个网络的输出为 `y2.x/ = <0.6; 0.6; 0.7/`。这意味着两者都会将 `x` 标记为第三类，`h1.x/ = h2.x/ = C3`。如果正确答案是 `c.x/ = C2`，那么两个都错了，但这种误差看起来并不相同。读者会注意到，第一个网络对类别为 `C3` “非常确定”（因为 `0.9` 明显大于另外两个输出 `0.5` 和 `0.2`），而第二个网络的确定性较低，其输出值的差异（`0.6`、`0.6` 和 `0.7`）非常小，以至于人们怀疑 `C3` 仅仅是靠运气获胜的。由于对错误类别的承诺程度较弱，第二个网络在某种程度上比第一个网络错得更少。

这种情况可以通过更合适的误差函数——均方误差（MSE）来捕捉。

![image](img/image112.png)![image](img/image112.png)![image](img/image724.png)

### 目标向量

在继续定义均方误差之前，我们必须引入另一个重要概念：目标向量，它同样依赖于具体的样本 `x`。我们将其记为 `t.x/`。在具有 `m` 个类别的领域中，目标向量 `t.x/ = <t1.x/; ...; tm.x/` 包含 `m` 个二进制。如果样本属于第 `i` 类，则 `ti.x/ = 1`，且该向量中的所有其他元素均为 `tj.x/ = 0`（其中 `j != i`）。例如，假设存在三个不同的类别 `C1`；`C2` 和 `C3`，已知 `x` 属于 `C2`。在理想情况下，第二个神经元应该输出 `1`，另外两个神经元应该输出 `0`。因此，目标是 `t.x/ = <t1; t2; t3> = <0; 1; 0>`。

### 均方误差

均方误差通过输出向量元素与目标向量元素之间的差异定义：

![image](img/image201.png)![image](img/image201.png)![image](img/image380.png)![image](img/image357.png)

```
MSE = 1/N Σ (ti - yi)²  (5.3)
```

![image](img/image457.png)

在计算网络的 `MSE` 时，我们必须为每个输出神经元建立其输出与目标向量对应元素之间的差异。注意括号中的项 `(ti - yi)` 被平方了，以确保负差异不会从正差异中被减去。

回到上面提到的两个网络的例子，如果目标向量是 `t.x/ = <0; 1; 0/`，那么这些就是均方误差：

![image](img/image515.png)

```
MSE1 = 1/3 (0.5-0)² + (0.2-1)² + (0.9-0)² = 0.46

MSE2 = 1/3 (0.6-0)² + (0.6-1)² + (0.7-0)² = 0.30
```
