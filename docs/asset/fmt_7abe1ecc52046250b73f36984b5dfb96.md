
5. 源信号估计为 `ŝ(t) = Û^(H) Ŵ x(t)`，或混合矩阵 `A` 估计为 `Â = Ŵ^# Û`，其中上标 `^#` 表示 Moore–Penrose 伪逆。

快速独立分量分析算法（FICA）[[71]](#c05.xhtml#c5-bib-0071) 是另一种非常流行的 BSS 技术，它根据峰度逐个提取信号。事实上，该算法使用了一种独立性准则，利用估计源的非高斯性。在某些旨在去除尖峰伪迹的场合，例如从同步 EEG-fMRI 记录中去除 fMRI 伪迹，应用迭代 fICA 并随后对伪迹分量进行通货紧缩（deflation）可获得极佳效果 [[83]](#c05.xhtml#c5-bib-0083)。此类典型信号如图 5.3 所示。

实际上，fICA 最大化负熵，负熵表示一个分布与具有相同均值和方差的高斯分布之间的距离，即：

(5.17)
```
Neg(y) ≃ {E[f(y)] − E[f(y_Gaussian)]}^2
```
其中 `f` 是评分函数 [[3]](#c05.xhtml#c5-bib-0003)，`Neg` 代表负熵。正如前面提到的，这等价于最大化峰度。因此，代价函数可以简单定义为：

(5.18)
```
J(w) = −1/4 |k_4(y)| = −β/4 k_4(y)
```
![Figure 5.3 A sample of an EEG signal simultaneously recorded with fMRI.](img/c05f003.gif)

**图 5.3** 同时用 fMRI 记录的 EEG 信号样本。

其中 `k_4(y)` 是峰度，`β` 是峰度的符号。应用标准梯度下降法来最小化代价函数，可得：

(5.19)
```
w(n+1) = w(n) − μ [∂J(w)/∂w]_{w=w(n)}
```
其中

(5.20)
```
−μ [∂J(w)/∂w]_{w=w(n)} = μ(n) φ(y(n)) x(n)
```
这里 `μ(n)` 是学习率：

(5.21)
```
φ(y_i) = β (m̂_4(y_i) / m̂_2^3(y_i)) [ (m̂_2(y_i) / m̂_4(y_i)) y_i^3 − y_i ]
```
以及 `m̂_q(y_i) = E[y_i^q(n)]`，这是实际源信号 `q`^(th) 阶矩的估计值。由于 fICA 逐个提取源信号，因此遵循一个通胀过程，从混合信号中排除已提取的源信号。该过程通过以下方式迭代重构混合信号：

(5.22)
```
x_{j+1} = x_j − w̃_j y_j,  j = 1, 2, ...
```
其中 `w̃_j` 通过最小化以下代价函数来估计：

(5.23)
```
J(w̃_j) = 1/2 E[ Σ_{p=1}^{n_r} x_{j+1,p}^2 ]
```
其中 `n_r` 是剩余混合信号的数量。
