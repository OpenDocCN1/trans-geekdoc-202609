
# 关于 CyberSAR 项目的问答

## 问：你正在与 SecDev 基金会研究……并介绍一下“CyberSAR”项目？

**答：** SecDev 基金会是一个非营利性“智库兼执行库”，致力于促进全球公民社会的数字安全和机会。

该基金会直接执行项目，支持欧亚地区、中东、北非以及东南亚的公民社会组织、妇女、青年和弱势群体。

`CyberSAR` 项目是这些努力之一。有趣的是，`CyberSAR` 项目的技术研究部分借鉴了由剑桥大学高级网络研究小组（`ANRG`）率先开发的跨学科方法论。`ANRG` 于 9/11 悲剧事件发生六个月后成立，旨在应对人们急需新方法来解决当前全球不安全局势中特征性的——不稳定性和不确定性的迫切需求。

`ANRG` 研究了技术网络与社会网络之间的联系，以及其对全球安全、政治、发展和冲突转型的影响。`ANRG` 项目共享一种共同的方法论，该方法结合了利用技术方法对网络进行审视和制图，同时在语境化、实地民族志方面培养了成熟的专业知识。

2006 年，`ANRG` 搬到了加拿大并成为 `SecDev Group`，一家数字风险咨询公司。2008 年，我在 `Citizen Lab` 与 `SecDev Group` 合作，在那里我们发现了一个运行在中国南方信号情报基地的基础间谍网络，该网络已渗透进全球联合国、北约、政府部门、外交使馆和公民社会的机器中。

2011 年，`SecDev Group` 联合创始人 `Rafal Rohozinski` 和 `Deirdre Collings` 成立了 `SecDev` 基金会，作为一个独立的非营利组织。

## 问：你正在完成牛津大学博士学位时进行这项研究吗？

**答：** 是的，牛津大学网络安全 `CDT` 项目最创新的功能之一就是强调与行业伙伴合作解决现实世界的安全问题。

从第一年开始，我就与行业和公民社会组织（如 `iIGHT Partners`，后被 `FireEye` 收购）合作，解决“棘手问题”，例如追踪来自中国和俄罗斯的持续性威胁、新疆的预测性警察监控平台，以及中国的复杂系统工程方法论。

这些每一次经历都贡献了我对 NGO 网络安全实践的核心博士论文的理解：“语境下的数字不安全”。

## 问：你们是如何检测这些 NGO 恶意软件事件的？

**答：** `CyberSAR` 项目已在中亚的 NGO 部署了 20 多个 `Zeroint` 安装（一种通过情报驱动的方法和安全启发式来主动防御企业内部及云端高级网络威胁——包括恶意软件的 `SaaS` 解决方案），并计划在高加索和东欧的其他 NGO 和媒体实体部署更多实例。

`Zeroint` 是 `SecDev Group` 开发的被动 `DNS` 系统，可检测包括恶意软件在内的数字威胁。使用 `Zeroint` 可以看到网络上的活跃恶意软件连接，并中断其与命令控制基础设施的通信。

## 问：请多介绍一下你们的大数据方法？

**答：** 好，利用 `Zeroint` 收集的数据，我们正在进行一项准实验，以衡量 `CyberSAR` 干预的功效。该实验使用稳健的方法论，对 `DNS` 请求应用时间序列分析，以追踪样本组织干预后的数字行为变化。在主导师兼牛津培训中心副主任 `Joss Wright` 博士的建议下，该方法论借鉴了流行病学研究和公共卫生干预的最佳实践。该实验的假设是：`CyberSAR` 干预加强了 NGO 的整体数字安全态，衡量标准是安装在 NGO 网络上的云端 `DNS` 防火墙拦截的恶意软件攻击数量。

研究收集参与数字安全干预的 NGO 的 `DNS` 请求，并将一小部分受益组织治疗组与 `DNS` 流量进行对比。

第二组尚未进行干预的组别。结果的分析将基于对 `DNS` 流量的中断时间序列（`C/ITS`）分析，以衡量治疗组和控制组中与已知或未知的网络威胁行为相关的检测异常数量。中断时间序列（`ITS`）分析是一种“准实验”设计，用于通过回归模型评估干预措施的纵向效应，而在这种设计中，随机化是不可选的方案。

该项目在 `ITS` 设计中增加了一个控制组，以产生 `C/ITS` 分析。这种方法在现实评估中至关重要，因为准实验发生在一个复杂且动态的社会技术环境中，在这些环境中，一系列随时间变化的混因素可能是未被测量的或未知的。此外，我们还使用了多基准线设计，即干预在不同的时间发生在不同的实地。

## 问：你们发现了什么结果？

**答：** 实际上，实验正在进行中，在中亚的多个实地正在进行数据收集。

我们已经与信任的伙伴分享了项目实验设计的报告，以及设计和运行实验过程中的早期发现，并向一个关注公民社会组织网络安全的学术研讨会提交了论文，在论文中，我们强调了设计和评估现实网络安全干预措施时的若干挑战和考虑。

## 问：你提到过从公共卫生干预中借鉴了方法。你认为这种方法对其他网络安全问题有价值吗？

**答：** `ITS` 研究设计越来越多地应用于流行病学，以评估公共卫生干预的效力。

当代学术网络安全话语向类比推理的转变，出现了挑战网络空间持续优先考虑国家安全关注逻辑的模态，包括将全球公共卫生模型应用于数字安全，特别是当重点是减少会使社区内其他人面临风险的不安全用户行为时。

流行病学范式也出现在处理网络安全的文献中，这种范式在网络安全文献中普遍存在。我们已经与信任的伙伴分享了项目实验设计的报告，以及设计和运行实验过程中的早期发现，并向一个关注公民社会组织网络安全的学术研讨会提交了论文，在论文中，我们强调了设计和评估现实网络安全干预措施时的若干挑战和考虑。
