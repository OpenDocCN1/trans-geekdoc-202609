### 3.1.10 数据归一化

特征的归一化过程非常简单：首先计算所有样本关于该特征的平均值，然后计算所有样本该特征围绕平均值的离散程度（即标准差），最后将所有样本的该特征减去其均值并除以标准差。

$$x \leftarrow \frac{x - \text{mean}(x)}{\text{stddev}(x)}$$

其中 `x` 是一组数字，`mean(x)` 是 `x` 中数字的平均值，`stddev(x)` 是 `x` 中数字的标准差（均方差）。例如，有一组特征值：{-5, 6, 9, 2, 4}，其平均值为：

```python
mean = (-5 + 6 + 9 + 2 + 4) / 5 = 3.2
```

从所有特征值中减去该平均值得到偏差，并计算这些偏差的平方：

$$

\begin{matrix}

(-5 - 3.2)^2 = 67.24 \\

(6 - 3.2)^2 = 7.84 \\

(9 - 3.2)^2 = 33.64 \\

(2 - 3.2)^2 = 1.44 \\

(4 - 3.2)^2 = 0.64

\end{matrix}

$$

然后，计算标准差 `stddev`：

$$\text{stddev} = \sqrt{(67.24 + 7.84 + 33.64 + 1.44 + 0.64)/5} = 4.71$$

对于之前的 `X2`，可以使用以下代码计算每个特征的均值（`mean`）和均方差（`stddev`）：

```python
mean = np.mean(X2, axis=0)
stddev = np.std(X2, axis=0)
print(mean)
print(stddev)
X2 = (X2 - mean) / stddev
print(X2)
```

## 3.2 模型的评估

### 3.2.1 欠拟合与过拟合

当机器学习的假设函数（统计模型）过于简单，无法充分表达样本数据特征与目标值之间的关系时，无论怎么训练，得到的模型函数都无法很好地预测，即输入数据特征得到的预测值与实际值之间的误差会很大。模型函数不能很好地拟合训练数据，这称为**欠拟合**（Underfitting）。例如，对于上述温度和压力问题，如果用线性函数表示温度与压力的关系，最后得到的线性函数拟合误差会非常大。当人工添加特征并用 3 次多项式表示温度与压力的关系时，可以更好地拟合训练数据，损失函数的误差值从 0.06623333 降低到 5.489e-5，因为 3 次多项式比 1 次线性多项式具有更强的表达能力。
