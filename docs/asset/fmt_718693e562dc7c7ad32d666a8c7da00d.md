## A.4.1 留出（Holdout）

在监督学习中，开始建模的第一步是加载输入数据，留出部分输入数据作为测试数据，并将另一部分作为构建模型的训练数据。以下是执行此操作的标准步骤。

```r
inputdata <- read.csv("btissue.csv")
split = 0.7 # 输入数据划分为训练集和测试集的比例。划分值 = 0.7 表示 70% 的数据将作为训练数据，即保留 30% 的输入数据作为测试数据
set.seed(123) # 此步骤是可选的，用于结果的可复现性
trainIndex <- createDataPartition(y = inputdata$class, p = split, list = FALSE) # 将数据分层随机划分为训练集和测试集
train_ds <- inputdata[trainIndex,]
test_ds <- inputdata[-trainIndex,]
```

### 注意

当我们执行数据留出时（即将输入数据划分为训练集和测试集），每个集合选择的记录是随机选取的。因此，显而易见，执行相同的代码可能会导致不同的训练集。训练出的模型也会所不同。在 R 中，有一个 `set.seed` 函数，它用于设置用于选取记录的随机数生成器的起点。这确保了每次都使用特定序列的随机数，因此每次都会选取相同的记录（即具有相同序列的记录），并以相同的方式训练模型。这对于结果的可复现性至关重要，即每次运行同一个机器学习程序都会生成相同的一组结果。代码如下：

```r
set.seed(5)
```

### A.4.5.3 无监督学习 - 聚类

正如我们所见，聚类质量有两种流行的指标：纯度和轮廓系数。纯度只有在数据集类别标签已知时才能计算。另一方面，轮廓系数可以针对任何数据集计算。

#### 纯度

我们将使用 Kaggle 发布的腰痛症状数据集（https://www.kaggle.com/sammy123/lower-back-pain-symptoms-dataset）。`spine.csv` 数据包含 310 个观测值和 13 个属性（12 个数值预测变量，1 个二分类属性）。

```r
library(fpc)
data <- read.csv("spine.csv") # 加载 Kaggle 数据集
data_wo_class <- data[, -length(data)] # 聚类前从数据集中分离类别属性
class <- data[, length(data)] # 将类别属性存储在独立变量中供以后使用
dis = dist(data_wo_class)^2
res = kmeans(data_wo_class, 2) # 可以使用其他聚类算法

# 定义一个自定义函数来比较类值与原始类别值并计算匹配率
ClusterPurity <- function(clusters, classes) {
  sum(apply(table(classes, clusters), 2, max)) / length(clusters)
}
ClusterPurity(res$cluster, class)
```

**输出**

```
[1] 0.6774194
```

#### 轮廓系数

使用 R 库 `cluster` 来查找/绘制所形成簇的轮廓系数。下面的代码使用 `k-means` 算法对 `spinem.csv` 数据集（与 `spine.csv` 相同但删除了目标变量）进行聚类，然后计算其轮廓系数。

```r
library(cluster)
data <- read.csv("spinem.csv")
sil <- silhouette(res$cluster, dist(data))
fviz(sil)
```

```r
dis = dist(data)^2
res = kmeans(data, 2) # Can use other clustering algorithms too
sil_width <- silhouette(res$cluster, dis)
sil_summ <- summary(sil_width)

sil_summ$avg.width # Returns silhouette width of the overall data set
```

## A.5.3 特征子集选择

特征子集选择是一个深入的研究的话题。有许多方法可以选择特征子集以提高模型性能。本文无法涵盖所有此类方法。然而，仅对于基础特征选择功能，可以使用 R 语言的 `FSelector` 包。

```r
library(FSelector)
data <- iris
feat_subset <- cfs(Species ~ ., data) # 使用相关性和熵度量对连续和离散数据选择特征子集
```

以下是一个在应用于模型训练之前执行特征子集选择的程序。

```r
library(caret)
library(FSelector)
inputdata <- read.csv("apndcts.csv")
split = 0.7
set.seed(123)
trainIndex <- createDataPartition(y = inputdata$class, p = split, list = FALSE)
train_ds <- inputdata[trainIndex,]
test_ds <- inputdata[-trainIndex,]
feat_subset <- cfs(class ~ ., train_ds) # Feature selection done
class <- train_ds$class
train_ds <- cbind(train_ds[feat_subset], class) # Subset training data created
class <- test_ds$class
test_ds <- cbind(test_ds[feat_subset], class) # Subset test data created
train_ds$class <- as.factor(train_ds$class)
test_ds$class <- as.factor(test_ds$class)
# 在此处应用决策树分类器。任何其他模型也可以应用 ……
model <- train(class ~ ., method = "rpart", data = train_ds)
predictions <- predict(model, test_ds, na.action = na.pass)
cm <- confusionMatrix(predictions, test_ds$class)
cm$overall['Accuracy']
```

### 注意

`FSelector` 包包含了关键函数，如朴素贝叶斯（Naive Bayes）和支持向量机（SVM）。

#### A.6.1.3 决策树分类器

为了实现此分类器，可以使用 `caret` 包中的 `train` 函数并配合参数 `method = "rpart"` 来指示 `train` 函数将使用决策树分类器。可选情况下，也可以使用 `rpart` 包中的 `rpart` 函数。完整代码如下。

```r
library(caret)
library(rpart)
inputdata <- read.csv("apndcts.csv")
split = 0.7
set.seed(123)
trainIndex <- createDataPartition(y = inputdata$class, p = split, list = FALSE)
train_ds <- inputdata[trainIndex,]
test_ds <- inputdata[-trainIndex,]
train_ds$class <- as.factor(train_ds$class)
test_ds$class <- as.factor(test_ds$class)
model <- train(class ~ ., method = "rpart", data = train_ds, prox = TRUE)
predictions <- predict(model, test_ds, na.action = na.pass)
cm <- confusionMatrix(predictions, test_ds$class)
cm$overall['Accuracy']
```

**输出：**

```
0.8387097
```
