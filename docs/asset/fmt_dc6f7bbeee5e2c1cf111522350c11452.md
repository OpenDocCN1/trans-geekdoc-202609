# 服务器虚拟化的安全劣势

任何优点通常伴随着缺点，虚拟化也不例外。虚拟化增加了额外的复杂性。有很多书籍解释了如何管理 Microsoft 服务器，但虚拟化可能导致你使用 Microsoft 服务器作为宿主机，上面运行着几个 Linux 和 Unix 虚拟机，或者在单台 Linux 机器上运行多个 Microsoft 系统。这种新的复杂性可能会导致难以排故障的问题。与托管多家公司虚拟机的单台物理服务器相关的漏洞包括数据混合。作为 CASP 候选人，你必须考虑你的云提供商采取了哪些措施来确保你的数据没有与其他公司的数据混合。如果发生了混合并导致数据泄露，你的数据可能会受到影响。当一个平台托管多家公司的虚拟机时，还可能出现安全问题。这些包括：

- **平台配置错误**：如果平台配置错误，可能会对驻在单一平台上的所有虚拟系统造成灾难性的后果。

虚拟化还需要额外的技能。虚拟化软件和在虚拟环境中工作所需的工具给管理员增加了额外负担，他们需要学习一些新知识。服务器虚拟化的安全劣势也出现在 1 型、2 型和基于容器的系统中。一个真实存在的问题是性能降低。我曾见过一台加载了五台虚拟机的低端服务器，它消耗了大量资源。结果是整体性能很差。

虚拟局域网（VLAN）用于分段网络流量。VLAN 为组织提供了许多益处，因为它们允许在管理上连接到交换机定义端口的网络用户和资源进行分段。VLAN 减少了网络拥塞并增加了带宽。VLAN 导致更小的广播域。

VLAN 不需要隔离在单一交换机上。VLAN 可以跨越整个组织中的多个交换机。扩展 VLAN 是通过干道协议实现的。干道协议将 VLAN 传播到整个区域，而访问端口只接受单个 VLAN 的流量。干道协议通过封装以太帧工作。两种常见的干道协议是 `802.1q` 和 Cisco 的私有干道协议。

Cisco 的交换机链路（`ISL`）封装了以太帧，但它不是所有厂商都使用的标准。`802.1q` 标准在以太帧内部放置信息。生成树协议（`STP`）是另一种可以在 VLAN 内使用的协议。`STP` 用于防止网络环路、构建活动路径并为路径或链路提供备份路径。

![](img/7868547987f5920cfe632b85047c64af_228_0.png)

如果不使用 `STP`，就会发生网络环攻击。这种攻击很容易启动；攻击者只需要连接属于同一交换机和同一 VLAN（同一广播域）的端口。当网络处于循环模式时，会在该 VLAN 内无限广播，泛洪交换机上的每个端口。这种攻击可能是恶意启动，也可能只是错误的电缆连接。

CASP 考试候选人应该对 VLAN 有基本的了解，因为它们在保护交换机端口组广播域方面起着重要作用。这直接涉及到安全拓扑，因为特定的子网可以分配给不同的端口组，通过路由或应用访问控制列表（`ACL`）。例如，开发域可以与生产域分离。VLAN 还可以用于隔离安全级别较低的网络部分。这种深度防御技术可以使用特定的 VLAN 来增加针对嗅探、密码攻击和劫持攻击的额外保护。虽然 VLAN 分隔可以被破解，但这增加了一层挡住大多数普通攻击者的防御。

针对 VLAN 的另一种潜在攻击是 VLAN 跳跃。VLAN 跳跃可以定义为攻击者尝试向属于其他 VLAN 的主机发送数据。这是通过给数据打上与其所属不同的 VLAN ID 标签来实现的。VLAN 标签是放置在以太帧内部的额外字段。例如，`802.1Q` 标签使用放置在源 MAC 和目的之间的 32 位字段。

头部中的 `Etheretype` 字段。这种攻击可以通过两种方式之一发起：交换机欺骗（`switch spoofing`）或双标签标记（`double tagging`）。

当攻击者能够在交换机和攻击者之间创建干链路（`trunk link`）时，就会发生交换机欺骗。这允许攻击者与该交换机配置的所有 VLAN 中的主机通信，从而使攻击者能够多个 VLAN 的流量。第二种技术双标签标记发生在攻击者在传输中的数据包前面添加两个 VLAN 标签时。头部会被剥离，并添加第二个伪造头部。伪造的 VLAN 头部指示数据帧的目标是第二个目标 VLAN上的主机。这种技术允许攻击主机绕过用于在逻辑上隔离主机之间的第 3 层安全措施。

## 虚拟网络与安全组件

正如服务器可以虚拟化一样，其他网络活动和组件如交换机、防火墙、无线控制器、代理和路由器也可以进行虚拟化。硬件虚拟化可以提供许多优势，例如网卡汇聚、负载均衡、内容缓存以及冗余/网络故障转移保护。以下是网络设备最常用的组件：

### 集群（Clustering）

集群是将计算机分组，用于提供比冗余服务器更高的可用性。冗余服务器在被需要时才等待，而集群服务器则积极参与响应服务器负载。如果集群中的一台服务器发生故障，其余服务器可以接管。服务器农可以被用作集群。此类集群可用于复杂任务，或在过去可能使用超级计算机的实例。

### 网格计算（Grid Computing）

这种技术与集群类似，但也称为分布式计算，其区别在于它没有中央控制，可用于需要海量计算能力的进程。网格计算与集群的不同之处在于，网格计算机可以随意添加或移除自身。网格计算不受中心化控制，因此不应考虑需要高安全性的进程。

### 交换机（Switches）

虚拟交换机的功能与物理交换机相同，但允许在同一台主机上存在多个交换机。与物理交换机相比，虚拟交换机具有某些安全优势。假设攻击者获取了虚拟系统的 `root` 级权限。下一步可能是将网卡设置为混杂模式（`promiscuous mode`）。虚拟交换机的默认设置是拒绝混杂模式。这种技术可以防止攻击者嗅探流量并监视网络。

### 防火墙（Firewalls）

虚拟防火墙可以运行在专门的虚拟安全设备上，也可以运行在客户虚拟机上。它与物理防火墙相同，只是运行在虚拟化环境内部。

### 无线控制器（Wireless Controllers）

这些设备与其他虚拟化网络服务共存，可以在利用克隆和快照等虚拟机特性的同时，降低硬件成本。

### 代理（Proxies）

虚拟代理在需要时才推迟加载带宽密集型资源的成本。

### 路由器（Routers）

虚拟路由器的运行方式与物理路由器相同。其真正的优势在于可以为物理路由器提供备份，或者能够提供额外的故障容错层。

## 注意事项（NOTE）

硬件虚拟化的一个很好的例子是虚拟路由器冗余协议（`VRRP`）。在需要高可用性时使用 `VRRP`。它使用可以转发到物理路由器的虚拟路由器。

    - 入侵检测系统 (`IDS`)

    - **实施链路安全。** 链路安全通常用于 VLAN。其概念是根据 MAC 地址阻止二层设备。根据 MAC 地址阻止设备可以有效防止其向任何连接的设备传播恶意流量。

# 网络附属存储 (NAS)

网络附属存储 (`NAS`) 是一种包含或带有一个或多个硬盘插槽的技术。这些硬盘用于网络存储。`NAS` 类似于直接访问存储 (`DAS`)，但 `DAS` 仅仅是一个系统的扩展，并且没有网络功能。

**SAN** 存储网络行业协会 (`SNIA`) 将 *`SAN`* 定义为“一种由各种存储元件、存储设备、计算机系统和/或设备组成的数据存储系统，加上所有的控制软件，所有设备通过网络高效、协调地进行通信”。`SAN` 与 `NAS` 类似。一个大区别是，`NAS` 在客户端看来是一个文件服务器或独立系统。而 `SAN` 在客户端操作系统看来像是一个本地磁盘或卷，可以根据需要进行格式化并在本地使用。

**虚拟 SAN (VSAN)** *虚拟 `SAN` (`VSAN`)* 是一种在物理连接到同一 SAN 交换架构（`fabric`）的设备之间提供隔离的 SAN。`VSAN` 有时被称为交换虚拟化。（交换架构可以定义为 SAN 的结构）。`VSAN` 的开发是为了支持单台交换机上的独立虚拟网络能力。`VSAN` 通过允许不同 `VSAN` 上的用户共享任何虚拟 SAN，而无需合并 SAN 交换架构，从而提高了汇聚性并简化了管理。
