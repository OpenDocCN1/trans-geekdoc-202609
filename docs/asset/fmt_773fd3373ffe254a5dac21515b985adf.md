### 2.5 联合概率分布

给定一个多元随机变量或随机向量 `X ∈ ℝ^D`，联合概率分布是一个概率分布，它给出了 `X_1, X_2, ..., X_D` 每一个落在为该变量指定的特定范围或离散值集合中的概率。对于只有两个随机变量的情况，这称为二元分布，但该概念推广到任意数量的随机变量，给出多元分布。联合概率分布可以用联合累积分布函数表示，或者用联合概率密度函数（针对连续变量）或联合概率质量函数（针对离散变量）表示。

#### 2.5.1 协方差与相关性

**定义 2.6.** 两个随机变量 `X` 和 `Y` 之间的协方差衡量 `X` 和 `Y` 的（线性）相关程度。协方差定义为：

```
cov[X,Y] ≜ E[(X - E[X])(Y - E[Y])]  (2.26)
       = E[XY] - E[X]E[Y]
```

**定义 2.7.** 如果 `X` 是一个 `D` 维随机向量，其协方差矩阵定义为以下对称、半正定矩阵：

```
cov[X] ≜ E[(X - E[X])(X - E[X])^T]  (2.27)
```

```
Σ = ( var[X_1]   Cov[X_1,X_2]   ...   Cov[X_1,X_D] )
    ( Cov[X_2,X_1] var[X_2]     ...   Cov[X_2,X_D] )
    ( ...          ...           ...   ...          )
    ( Cov[X_D,X_1] Cov[X_D,X_2]  ...   var[X_D]     )  (2.28)
```

（`Σ` 是对称的）。对角协方差矩阵有 `D` 个参数，非对角项为 0。球形或各向同性协方差 `Σ = σ² I_D` 有一个自由参数。

#### 2.5.3 多元 Student's t 分布

**定义 2.8.** `X` 和 `Y` 之间的（Pearson）相关系数定义为：

```
corr[X,Y] ≜ Cov[X,Y] / √(var[X], var[Y])  (2.29)
```

相关矩阵的形式为：

```
R ≜ ( corr[X_1,X_1] corr[X_1,X_2] ... corr[X_1,X_D] )
    ( corr[X_2,X_1] corr[X_2,X_2] ... corr[X_2,X_D] )
```

## 2.5 相关系数

相关系数可以被视为 `X` 和 `Y` 之间**线性关系**程度的度量，参见 Figure 2.6。

**不相关并不意味着独立**。例如，设 `X ~ U(-1,1)` 且 `Y = X²`。显然 `Y` 依赖于 `X`（事实上，`Y` 完全由 `X` 决定），但可以证明 `corr[X,Y] = 0`。Figure 2.6 展示了一些这方面的显著实例。这显示了一些数据集，其中 `X` 和 `Y` 之间存在明显的依赖关系，但相关系数为 0。随机变量之间更广泛的依赖度量是**互信息**，参见 Section TODO。

#### 2.5.2 多元高斯分布

**多元高斯分布**或**多元正态分布**（MVN）是连续变量最常用的联合概率密度函数。我们将在第 4 章详细探讨 MVN；此处仅给出一些定义和图示。

`D` 维 MVN 的 pdf 定义为：

```
N(x|μ,Σ) ≜ 1/(2π)^(D/2) |Σ|^(-1/2) exp[-1/2 (x-μ)^T Σ^(-1) (x-μ)]
```

其中 `μ = E[X] ∈ R^D` 是**均值向量**，`Σ = Cov[X]` 是 `D×D` **协方差矩阵**。归一化常数 `(2π)^(D/2) |Σ|^(1/2)` 仅确保 pdf 积分为 1。

Figure 2.7 绘制了三种不同类型协方差矩阵在 2D 下的 MVN 密度图。一个**满协方差矩阵**有 `D(D+1)/2` 个参数（除以 2 是因为对称性）。

## 2.5.3 学生 t 分布

**学生 t 分布**的 pdf 定义为：

```
T(x|μ,Σ,ν) ≜ Γ((ν+D)/2) / (Γ(ν/2) (νπ)^(D/2) |Σ|^(1/2)) [1 + 1/ν (x-μ)^T Σ^(-1) (x-μ)]^(-(ν+D)/2)
```

其中 `Σ` 称为**尺度矩阵**（因为它通常不是协方差矩阵），且 `V = νΣ`。该分布比高斯分布有**更厚的尾部**。`ν` 越小，尾部越厚。当 `ν → ∞` 时，分布趋向于高斯分布。该分布具有以下性质：

```
mean = μ, mode = μ, Cov = ν/(ν-2) Σ
```

#### 2.5.4 狄利克雷分布

**Beta 分布**的多元推广是**狄利克雷分布**，其**支撑集**是**概率单纯形**，定义为：

```
S_K = {x : 0 ≤ x_k ≤ 1, ∑_{k=1}^K x_k = 1}
```

pdf 定义如下：

```
Dir(x|α) ≜ 1/B(α) ∏_{k=1}^K x_k^(α_k-1) I(x ∈ S_K)
```

其中 `B(α_1, α_2, ..., α_K)` 是 **Beta 函数**向 `K` 个变量的推广：

```
B(α) ≜ ∏_{k=1}^K Γ(α_k) / Γ(α_0), where α_0 ≜ ∑_{k=1}^K α_k
```

Figure 2.8 展示了 `K=3` 时狄利克雷分布的一些图示，Figure 2.9 展示了一些采样的概率向量。我们看到 `α_0` 控制分布的**强度**（峰值有多尖），而 `α_k` 控制峰值发生的位置。例如，`Dir(1,1,1)` 是**均匀分布**，`Dir(2,2,2)` 是以 `(1/3,1/3,1/3)` 为中心的**宽分布**，`Dir(20,20,20)` 是以 `(1/3,1/3,1/3)` 为中心的**窄分布**。如果所有 `k` 的 `α < 1`，我们会在单纯形的边缘得到**尖峰**。为将来参考，该分布具有以下性质：

```
E[x_k] = α_k/α_0, mode[x_k] = (α_k-1)/(α_0-K), var[x_k] = α_k(α_0-α_k) / (α_0²(α_0+1))
```

### 2.6 随机变量变换

如果 `X ~ P()` 是某个随机变量，且 `Y = f(X)`，那么 `Y` 的分布是什么？这是本节要解决的问题。

#### 2.6.1 线性变换

假设 `g()` 是一个**线性函数**：`g(x) = Ax + b`。

首先，对于均值，我们有：

```
E[y] = E[Ax + b] = A E[x] + b
```

这被称为**期望的线性性**。对于协方差，我们有：

```
Cov[y] = Cov[Ax + b] = A Σ A^T
```

#### 2.6.2 一般变换

如果 `X` 是**离散随机变量**，我们可以通过简单地对所有满足 `f(x) = y` 的 `x` 求**概率质量**和来确定 `y` 的 pmf：

```
p_Y(y) = ∑_{x:g(x)=y} p_X(x)
```

如果 `X` 是**连续的**，我们不能使用公式 2.42，因为 `p_X(x)` 是**密度**而不是 pmf，我们不能对密度求和。相反，我们使用 cdf：

```
F_Y(y) = P(Y ≤ y) = P(g(X) ≤ y) = ∫_{g(X)≤y} f_X(x) dx
```

我们可以通过对 cdf 求导来确定 `Y` 的 pdf：

```
f_Y(y) = f_X(x) |dx/dy|
```

这称为**变量代换公式**。我们将其证明留作练习。

例如，假设 `X ~ U(-1,1)`，且 `Y = X²`。则 `p_Y(y) = 1/(2√y)`。

##### 2.6.2.1 多元变量代换 *

设 `f` 为函数 `f: R^n → R^n`，且 `y = f(x)`。则其**雅可比矩阵** `J` 由下式给出：

```
J_{x→y} ≜ [∂y_i/∂x_j] = 
[ ∂y_1/∂x_1 ... ∂y_1/∂x_n ]
[ ...           ...           ]
[ ∂y_n/∂x_1 ... ∂y_n/∂x_n ]
```

`|det(J)|` 衡量**单位立方体**在应用 `f` 时体积变化了多少。如果 `f` 是**可逆映射**，我们可以利用逆映射 `y→x` 的雅可比来定义变换变量的 pdf：

```
p_y(y) = p_x(x) |det(∂x/∂y)| = p_x(x) |det(J_{y→x})|
```

#### 2.6.3 中心极限定理

给定 `N` 个随机变量 `X_1, X_2, ..., X_N`，每个变量**独立同分布**（简称 **iid**），且每个具有相同的均值 `μ` 和方差 `σ²`，则：

```
(∑_{i=1}^N X_i - Nμ) / (√N σ) ~ N(0,1)
```

这也可以写为：

```
(X̄ - μ) / (σ/√N) ~ N(0,1), where X̄ ≜ 1/N ∑_{i=1}^N X_i
```

### 2.7 蒙特卡洛近似

通常，使用变量代换公式计算随机变量函数的分布可能很困难。一个简单但强大的替代方法如下。首先，我们从分布中生成 `S` 个样本，称它们为 `x_1, ..., x_S`。（有许多生成此类样本的方法；一种用于高维分布的流行方法称为**马尔可夫链蒙特卡洛**或 **MCMC**；这将在第 TODO 章解释。）给定这些样本，我们可以使用 `{f(x_s)}_{s=1}^S` 的**经验分布**来近似 `f(X)` 的分布。这称为**蒙特卡洛近似**，以欧洲以其豪华赌场闻名的城市命名。

我们可以使用蒙特卡洛方法来近似随机变量任何函数的**期望值**。我们只需抽取样本，然后计算函数应用于样本的**算术平均值**。这可以写为：

```
E[g(X)] = ∫ g(x) p(x) dx ≈ 1/S ∑_{s=1}^S f(x_s)
```

### 2.8 信息论

#### 2.8.1 熵

具有分布 `p` 的任意变量 `X` 的熵，记作 `H(X)` 或有时记作 `H(p)`，是其**不确定性**的度量。具体而言，对于具有 `K` 个状态的离散变量，其定义为

```
H(X) = −∑_{k=1}^K p(X = k) log2 p(X = k)  (2.50)
```

通常我们使用以 2 为底的对数，此时单位称为 **比特**（bit，binary digit 的缩写）。假设我们使用以 `e` 为底的对数，单位称为 **奈特**（nat）。具有最大熵的离散分布是均匀分布（证明见第 XXX 节）。因此，对于一个 `K` 元离散变量，当 `p(x = k) = 1/K` 时熵最大；在这种情况下，`H(X) = log2 K`。相反，熵最小（为零）的分布是将所有质量集中在一个状态上的任意 Delta 函数。这种分布没有不确定性。

可以证明（Cover and Thomas 2006），交叉熵是指当我们使用模型 `q` 来构建码本时，对来自分布 `p` 的源进行编码所需的平均比特数。因此，普通熵 `H(p) = H(p,p)`（定义见 §2.8.1 节）是在我们使用真实模型时的平均比特数，所以 KL 散度就是这两者之间的差异。换句话说，KL 散度是由于我们使用分布 `q` 而非真实分布 `p` 来编码数据而导致的额外平均比特数。额外比特数这一理解应能说明 `KL(p||q) ≥ 0`，且仅当 `q = p` 时 KL 散度等于零。

我们现在给出这一重要结果的证明。

**定理 2.1.（数据差异/不等式）** `KL(p||q) ≥ 0`，当且仅当 `p = q` 时取等号。

这一结果的一个重要推论是，具有最大熵的离散分布是均匀分布。

#### 2.8.2 KL 散度

衡量两个概率分布 `p` 和 `q` 差异的一种方法称为 **Kullback-Leibler 散度**（KL 散度）或相对熵。其定义如下：

```
KL(P||Q) = ∑_x p(x) log2 q(x)  (2.51)
```

仅当 `P` 和 `Q` 均归一化为 1 且 `q(x) = 0` 蕴含 `p(x) = 0` 对所有 `x` 成立（绝对连续）时，KL 散度才有定义。如果公式中出现 `0 ln 0`，它被解释为零，因为 `lim_{x→0} x ln x = 0`。

我们可以将其重写为

```
KL(p||q) = ∑_{k=1}^K p(x) log2 p(x) − ∑ p(x) log2 q(x)
         = H(p,q) − H(p)  (2.52)
```

其中 `H(p,q)` 称为**交叉熵**。

#### 2.8.3 互信息

**定义 2.9.** **互信息**（MI）定义如下：

```
I(X;Y) = KL(P(X,Y) || P(X)P(Y))
       = ∑_x ∑_y p(x,y) log (p(x,y) / (p(x)p(y)))  (2.54)
```

对于概率密度函数（pdf），求和号替换为积分。我们有 `I(X;Y) ≥ 0`，当且仅当 `P(X,Y) = P(X)P(Y)` 时取等号。即，若变量相互独立，则 MI 为零。

为了深入理解 MI 的含义，将其用联合熵和条件熵重新表达会有所帮助。可以证明上述表达式等价于以下形式：

```
I(X;Y) = H(X) − H(X|Y)  (2.55)
       = H(Y) − H(Y|X)  (2.56)
       = H(X) + H(Y) − H(X,Y)  (2.57)
       = H(X,Y) − H(X|Y) − H(Y|X)  (2.58)
```

其中 `H(X)` 和 `H(Y)` 是边缘熵，`H(X|Y)` 和 `H(Y|X)` 是条件熵，`H(X,Y)` 是 `X` 和 `Y` 的联合熵，见图 2.10。

![图 2.10：一对具有互信息 I(X;Y) 的相关子系统 X,Y 的边缘熵 H(X)、H(Y)、联合熵 H(X,Y) 和条件熵。](img/image_rsrc1R4.jpg)

直观上，我们可以将 `X` 和 `Y` 之间的 MI 解释为观察 `Y` 后关于 `X` 的不确定性的减少，或者对称地，观察 `X` 后关于 `Y` 的不确定性的减少。

一个与 MI 密切相关的量是**点互信息**（PMI）。对于两个事件（而非随机变量）`x` 和 `y`，其定义为

```
PMI(x,y) = log (p(x,y) / (p(x)p(y))) = log (p(x|y) / p(x)) = log (p(y|x) / p(y))  (2.59)
```

这衡量了这些事件共同发生与偶然预期之间的差异。显然，`X` 和 `Y` 的 MI 仅仅是 PMI 的期望值。

有趣的是，我们可以将 PMI 重写如下：

```
PMI(x,y) = log (p(x|y) / p(x)) = log (p(y|x) / p(y))  (2.60)
```

这是将先验 `p(x)` 更新为后验 `p(x|y)` 所获得的信息量，或者等价地，将先验 `p(y)` 更新为后验 `p(y|x)` 所获得的信息量。
