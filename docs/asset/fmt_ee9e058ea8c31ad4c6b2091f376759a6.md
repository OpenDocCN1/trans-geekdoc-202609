
该指标最适用于数据集中各类别近乎平衡的情况。然而，如果类别分布不均衡，仅凭准确率可能会具有误导性。例如，在一个 95% 的元素属于某一类别的数据集中，一个天真地对所有输入都预测为多数类别的模型仍然可以达到 95% 的准确率，尽管它并未学到数据底层模式的任何有意义的信息。

### Precision

Precision，也称为阳性预测值，衡量的是阳性预测的准确性。它是正确预测的阳性观测值与总预测阳性数的比率。Precision 的公式为：

\\\[ \\text{Precision} = \\frac{\\text{True Positives}}{\\text{True Positives} + \\text{False Positives}} \\\]

Precision 在假阳性成本很高的场景中特别有用。例如，在垃圾邮件检测中，假阳性（将合法邮件标记为垃圾邮件）比假阴性（未能检测到垃圾邮件）更成问题。因此，在这种情况下，更高的 Precision 是可取的。

### Recall

Recall，也称为敏感性或真正率，衡量模型在数据集中找到所有相关案例的能力。它定义为正确预测的阳性观测值与实际类别为阳性的所有观测值的比率。Recall 的公式为：

\\\[ \\text{Recall} = \\frac{\\text{True Positives}}{\\text{True Positives} + \\text{False Negatives}} \\\]

Recall 在漏掉一个阳性实例的后果远比错误预测额外阳性更严重的情况下至关重要。例如，在严重疾病的医学诊断中，出现假阳性（预测有病而实际无病）是可以再次复查的，比出现假阴性（疾病存在却未检测到）更可接受。

### F1 Score

虽然 Precision 和 Recall 都非常重要，但它们通常存在反向关系。提高 Precision 通常会降低 Recall，反之亦然。这被称为 Precision-Recall 权衡。为了解决这一权衡，使用 F1 Score 来平衡 Precision 和 Recall。F1 Score 是 Precision 和 Recall 的调和平均数，对两个指标赋予同等权重。F1 Score 的公式为：

\\\[ \\text{F1 Score} = 2 \\times \\frac{\\text{Precision} \\times \\text{Recall}}{\\text{Precision} + \\text{Recall}} \\\]

F1 Score 在需要平衡 Precision 和 Recall 且不均衡的类别分布可能使准确率成为不太有用的指标的情况下特别有用。较高的 F1 Score 表明分类器在 Precision 和 Recall 方面都具有稳健的性能，这在类别分布不均时尤其理想。

Accuracy、Precision、Recall 和 F1 Score 这些指标各自服务于独特的目的，并为机器学习模型的性能提供不同的见解。根据预测建模任务的具体要求和后果，可能优先考虑不同的指标。例如，在两种分类错误（假阳性和假阴性）成本相等的模型中，F1 Score 可能是最相关的指标。相比之下，在一种错误成本更高的模型中，Precision 或 Recall 可能更相关。因此，深入理解这些指标使数据科学家和机器学习工程师能够为其模型选择合适的评估策略，确保其与业务目标和现实世界运营需求保持一致。

### Confusion Matrix

混淆矩阵 CONFUSION MATRIX 是一种特定的表格布局，可用于可视化算法的性能，通常是用于机器学习分类任务的监督学习算法。矩阵本身有助于通过将实际目标值与模型预测的值进行比较来可视化分类器的准确性。它是衡量召回率、精确率、特异性、准确率以及最重要的分类器误分类率的有力工具。

混淆矩阵被组织成一个包含两行两列的表格，报告假阳性、假阴性、真阳性和真阴性的数量。这种格式使得很容易看出系统是否在混淆两个类别（即经常将一个类别错误标记为另一个）。在二分类中，仅涉及两个类别，矩阵提供了对分类器所犯错误及其错误类型的简单而全面的洞察。

在二分类器的上下文中，混淆矩阵中表示的四个术语至关重要。‘真阳性’（TP）是分类器正确预测阳性类别的情况。‘真阴性’（TN）是分类器正确预测阴性类别的情况。‘假阳性’（FP）发生在模型错误预测阳性类别时（也称为“I 型错误”）。最后，‘假阴性’（FN）是模型错误预测阴性类别的情况（也称为“II 型错误”）。

从混淆矩阵中可以计算出多个性能指标。最直接的指标是准确率，它评估模型的整体正确性，定义为真阳性和真阴性之和与案例总数之比。然而，准确率单独使用可能具有误导性，尤其是在类别分布不平衡的情况下。这就是混淆矩阵派生的其他指标发挥作用的地方，例如 Precision 和 Recall。Precision（或阳性预测值）衡量阳性预测的准确性。它是真阳性与真阳性和假阳性之和的比率。Recall（或敏感性）衡量模型检测阳性实例的能力，定义为真阳性与真阳性和假阴性之和的比率。

另一个可以从混淆矩阵中得出的重要指标是 F1 Score，它是 Precision 和 Recall 的调和平均数。该分数同时考虑了假阳性和假阴性，在类别不平衡时特别有用。F1 Score 比准确率更能衡量性能，尤其是在类别标签分布不均时。特异性（或真阴性率）是另一个指标，表示分类器识别阴性结果的有效性，计算为真阴性与真阴性和假阳性之和的比率。

混淆矩阵也可以扩展到多类分类问题。在这种情况下，矩阵的维度将与预测的类别数量相匹配。矩阵的每一行代表实际类别中的实例，而每一列代表预测类别中的实例。这种设置有助于识别不仅总体错误，还能识别哪些类别被相互混淆。

在实际应用中，混淆矩阵在医学诊断、垃圾邮件过滤和欺诈检测等领域被广泛使用，在这些领域中，错误的后果可能很严重。在这些领域中，了解错误类型（I 型或 II 型）并最大限度地减少它们至关重要。例如，在医学诊断中，假阴性（预测疾病不存在而实际存在）可能比假阳性（预测疾病存在而实际不存在）更危险。

此外，混淆矩阵及其派生的指标对于调整模型参数至关重要。通过分析矩阵，数据科学家可以决定是否调整分类器的阈值以提高 Recall 或 Precision，具体取决于任务的要求。这在 Precision 比 Recall 更重要或反之亦然的场景中特别有用。

总之，混淆矩阵不仅仅是评估分类器准确性的工具，也是改进模型的指南。通过提供对分类器所犯错误性质的详细洞察，它为诊断机器学习模型中的问题并对其进行改进以获得更好性能奠定了基础。其在推导多种性能指标方面的实用性使其成为每个机器学习从业者工具箱中不可或缺的工具。

### ROC 和 AUC

`RECEIVER OPERATING Characteristic` (`ROC`) 和 Area Under the Curve (`AUC`) 是用于评估机器学习模型，特别是分类问题中模型的两个重要指标。`ROC` 是一种图形图，它展示了二元分类系统在判别阈值变化时的诊断能力。该曲线是通过在各种阈值设置下绘制真阳性率 (`TPR`) 与假阳性率 (`FPR`) 得到的。`TPR` 也被称为灵敏度、召回率或检测概率，而 `FPR` 也被称为误报概率，可以计算为 (1 - 特异性)。

`ROC` 曲线提供了一种在不考虑决策成本背景的情况下在各种模型中选择最佳模型的工具。该曲线通常用于二元分类以研究分类器的输出。为了生成 `ROC` 曲线，会调整二元分类器的阈值设置以衡量真阳性率与假阳性率之间的权衡。对于完美的分类器，`ROC` 曲线将穿过图的左上角，表示 100% 的真阳性率和 0% 的假阳性率。对于随机猜测，`ROC` 曲线将是从左下角到右上角的对角线。

`AUC` - Area Under the Curve - 是用于评估二元分类器性能的第二个指标。`AUC` 衡量从 (0,0) 到 (1,1) 整个 `ROC` 曲线下方的整个二维面积。这提供了跨所有可能分类阈值的性能综合度量。`AUC` 的值范围从 0 到 1。预测 100% 错误的模型 `AUC` 为 0.0；预测 100% 正确的模型 `AUC` 为 1.0。`AUC` 特别有用，因为它是对分类器性能的单一数值总结。如果你随机挑选一个正例和一个负例，`AUC` 表示你的分类器将正例的预测概率分配得高于负例的可能性。

使用 `ROC` 和 `AUC` 的主要优点之一是它们与响应者比例的变化无关。这非常有用，因为在现实场景中，数据中正负结果的比例可能会变化，但 `ROC` 和 `AUC` 提供了不受此影响的准确性度量。这在模型选择的初步阶段特别有用，我们希望识别最有前景的模型。

此外，`ROC` 曲线对于可视化和基于其相对于假阳性率的性能选择模型也很有用，这在许多实际应用中至关重要。例如，在医学诊断中，假阴性可能意味着未检测到疾病，这可能很危险，而假阳性可能意味着不必要的警报，可能只会造成轻微的伤害或不便。`ROC` 曲线有助于根据特定应用的需求在这两者之间找到良好的平衡。

然而，`ROC` 和 `AUC` 并非没有局限性。如果数据中存在较大的类别不平衡，它们可能会对算法的性能呈现过于乐观的看法，而这在现实场景中很常见。这是因为 `ROC` 曲线可能显示出对类别有出色的分离能力，而实际上分类器可能只是很好地预测了多数类。在这种情况下，精确率-召回率曲线可能是模型评估的更合适的工具。

此外，虽然 `AUC` 提供了用于对模型进行排名的有用指标，但它并不能传达模型在真阳性和假阳性之间所做的具体权衡的信息。因此，虽然 `AUC` 可用于比较模型，但不应单独用于决定分类器的操作点（即决策从一个类别更改为另一个类别的阈值）。决策阈值需要根据特定应用背景下假阳性和假阴性的成本来选择。

总之，`ROC` 和 `AUC` 是评估二元分类模型性能的强大工具。它们提供了一种稳健的度量，有助于在不受数据集类别分布影响的情况下进行模型选择和性能比较。然而，它们应与其他指标和特定领域的考虑因素结合使用，以确保所选模型不仅在理论上，而且在实际应用中也能表现良好。

### 平均绝对误差和均方误差

IN MACHINE LEARNING, Mean Absolute Error (`MAE`) 和 Mean Squared Error (`MSE`) 是用于评估回归模型性能的最常用指标之一。这些指标提供了模型预测与实际数据匹配程度的定量度量，这对于评估模型准确性并指导模型参数的改进至关重要。

平均绝对误差 (`MAE`) 是一种模型评估指标，它对预测值和实际值之间的绝对差值求和，提供了一个预测误差的直接度量。`MAE` 的公式为：

\\\[ \\text{MAE} = \\frac{1}{n} \\sum\_{i=1}^{n} |y\_i - \\hat{y}\_i| \\]

其中 \\( y\_i \\) 表示实际值，\\( \\hat{y}\_i \\) 表示预测值，\\( n \\) 是观测值的数量。`MAE` 特别有用，因为它易于解释；它提供了误差幅度的直接平均值。`MAE` 的单位与被预测的目标变量的单位相同。较低的 `MAE` 值表示具有更好预测精度的模型，因为它表明与实际值的偏差更小。

然而，`MAE` 的一个局限性是它不能区分大误差和小误差，因为它对实际值的偏差一视同仁。这有时会成为问题，尤其是在大误差特别不希望出现的情况下。

均方误差 (`MSE`) 另一方面，通过在平均之前对预测值和实际值之间的差异进行平方来解决 `MAE` 的一些局限性。`MSE` 的公式为：

\\\[ \\text{MSE} = \\frac{1}{n} \\sum\_{i=1}^{n} (y\_i - \\hat{y}\_i)² \\]

`MSE` 中误差的平方意味着较大的误差会对总误差指标产生不成比例的更大影响。因此，`MSE` 比 `MAE` 更敏感于异常值和大误差。这种特性使得 `MSE` 在大误差特别不希望出现且应受到更严厉惩罚时成为有用的指标。然而，由于误差被平方，`MSE` 不在与原始数据相同的单位中，这有时会使解释不太直观。

`MAE` 和 `MSE` 都是负向评分，这意味着值越低越好，零表示完美拟合。在实践中，使用 `MAE` 还是 `MSE` 的选择通常取决于问题的具体背景和数据的性质。如果大误差更关键，则 `MSE` 可能是首选指标。如果需要更通用和稳健的误差指标，则 `MAE` 可能更合适。

还值得注意的是，`MAE` 和 `MSE` 都容易受到数据集中特征尺度差异的影响。这可能导致误差指标被具有较大尺度的特征所主导。为缓解这种情况，在应用这些指标之前，对数据进行归一化或标准化是常见做法。

在机器学习模型优化过程中，除了作为独立的评估指标外，`MAE` 和 `MSE` 通常也被用作优化过程的一部分。许多算法，例如 `linear regression` 和 `neural networks`，可以将这些指标用作在训练过程中最小化的损失函数。在此上下文中，`MSE` 通常更受青睐，因为它可微分，从而促进基于梯度的优化方法的使用，而基于梯度的优化方法是许多类型机器学习模型训练的核心。

此外，`MSE` 相对于模型参数的导数比 `MAE` 更容易计算，而 `MAE` 由于绝对值运算可能存在不连续性。这种计算上的便利性通常使 `MSE` 在依赖梯度下降或其变体进行优化的复杂模型中使用更具吸引力。

最终，在机器学习中将 `MAE` 和 `MSE` 作为指标或损失函数进行选择的选择，应由手头应用的具体要求和约束来指导。理解这些指标的行为及其对模型性能的影响，对于开发针对其预期任务进行良好调优的有效机器学习解决方案至关重要。

## Log-Loss

`LOG-LOSS`，也称为逻辑损失或交叉熵损失，是一种用于评估分类器准确性的性能指标。它在预测事件发生概率时特别有用。与准确率或精确率等其他指标不同，`Log-Loss` 通过考虑预测的不确定性提供了对模型性能的更深入见解。该指标通常用于二元分类任务，但可以扩展到多类分类场景。

在二元分类中，目标变量通常被建模为 `Bernoulli` 随机变量（取值为 0 或 1）。`Log-Loss` 函数通过量化真实标签与预测结果概率之间的差异来衡量预测中的不可预测性或熵。对于 `N` 个观测值集合，`Log-Loss` 定义为：

```
L(y, p) = -1/N * Σ [y_i * log(p_i) + (1 - y_i) * log(1 - p_i)]
```

其中 `y_i` 表示第 `i` 个观测值的实际标签，`p_i` 表示第 `i` 个观测值属于正类的预测概率。函数的对数分量会惩罚假阳性和假阴性，但当预测概率与实际标签相差很大时，其影响会显著更大。例如，当事件被预测为几乎确定会发生（`p_i ≈ 1`）而实际上未发生（`y_i = 0`）时，由于对数项趋近于负无穷，会产生高惩罚。

`Log-Loss` 的本质是惩罚错误分类，但对错误方向上高置信度的惩罚更大。这一特性使其在预测概率至关重要的模型中特别有用，例如风险评估或医学诊断。`Log-Loss` 越低越好，完美模型具有 `0` 的 `Log-Loss`。然而，对于现实世界模型而言，实现 `0` 的 `Log-Loss` 在实践中是不可能的，这表明预测具有绝对确定性。

`Log-Loss` 在机器学习领域也很关键，因为它在模型优化中发挥作用，特别是那些输出概率的模型。许多机器学习算法，包括 `logistic regression` 和 `neural networks`，可以配置为在训练过程中最小化 `Log-Loss`。这种优化有助于校准模型，使预测概率尽可能接近数据的实际底层概率。最小化 `Log-Loss` 通过使预测概率与真实概率保持一致，从而带来更可靠、更稳健的模型。

此外，在类别分布不平衡的场景中，`Log-Loss` 比准确率等其他指标更受青睐。在这种情况下，准确率可能具有误导性，因为它可能反映底层类别分布而非模型做出准确预测的能力。例如，在 90% 实例属于一个类别的数据集中，总是预测多数类别的朴素模型将达到 90% 的准确率，尽管它没有学习到数据中有意义的信息。相比之下，`Log-Loss` 会惩罚朴素预测中隐含的确定性，从而更诚实地评估模型的性能。

然而，`Log-Loss` 并非没有局限性。一个显著的缺点是它对接近 0 和 1 的预测概率的敏感性。如果模型对错误分类过于自信，`Log-Loss` 将会由于接近零的数字的对数趋近于无穷大而分配极端惩罚。这有时会导致模型训练中的问题，例如过拟合，其中模型学习在训练数据上降低 `Log-Loss`，以牺牲对新数据的泛化能力。因此，在最小化 `Log-Loss` 时，监控过拟合迹象并采用正则化和交叉验证等技术至关重要。

总之，`Log-Loss` 是评估机器学习中分类器，特别是输出概率的分类器的强大指标。它量化预测的不确定性并根据置信水平惩罚错误分类的能力，使其成为开发预测模型中的宝贵工具。尽管它对极端概率预测敏感，但当谨慎使用并与其他模型验证技术结合使用时，`Log-Loss` 可以显著增强机器学习模型的性能和可靠性。

## Custom metrics for specific applications

在机器学习的领域中，模型的有效性通常使用标准指标如准确率、精确率、召回率和 `F1 score` 来评估。然而，这些传统指标可能并不总是与某些应用的具体目标或运营要求完全一致。这种不一致需要开发定制指标，这些指标专门用于衡量机器学习模型在其预期应用背景下的性能。定制指标旨在封装应用程序领域的独特方面、运营细微差别和业务影响，从而更准确地衡量模型在现实场景中的表现。

例如，在为金融交易设计的机器学习应用中，主要目标可能不仅仅是准确预测市场走势方向，还包括在最小化风险的同时最大化财务回报。标准指标如准确率或精确率并不能直接考虑财务表现。在这种情况下，像 `expected return` 这样的定制指标，结合正确预测的概率与潜在的财务收益或损失，可能更合适。该指标不仅评估预测的正确性，还评估其经济影响，使模型的评估标准与应用程序的财务目标保持一致。

同样，在医疗保健应用中，特别是预测诊断中，假阴性（即在存在疾病时未能诊断出疾病）的成本可能显著高于假阳性。在这里，可以设计定制指标，使假阴性的权重高于假阳性。例如，可以使用加权错误指标，其中分配给假阴性的权重高于假阳性。这将鼓励开发优先最小化成本更高的错误的模型，使指标与关键的医疗保健结果保持一致。
