
黑盒测试通常从各种侦察手段开始，以收集尽可能多的公司信息。通常可以根据员工的电子邮件地址生成用户凭证，致电公司服务台重置员工密码即可轻松获得网络访问权限。随后，渗透测试人员会尝试以下几种场景之一。

第一种场景涉及在公司现场停留较长时间，进入大厅并将以太网线连接到未受保护的端口。甚至更大胆的专业人员可能会携带装有渗透软件的电池供电`树莓派`，将其植入通常拥有大量以太网端口的工作间或会议室。

一旦接入网络，设备会“回连”，从而获得网络访问权限。通过社会工程学手段最近获取的一组用户凭证，渗透测试人员随即开始深入挖掘网络。

## 实施攻击

在协商并达成渗透测试参数后，攻击过程遵循第 5 章“ICS 网络安全要素”中描述的攻击杀伤链阶段。

1.  **侦察**：此阶段通过各种活动寻找目标网络结构和配置中的可利用漏洞。这包括扫描网络硬件和软件攻击面，以及使用物理和逻辑社会工程学方法识别可能的攻击向量。

2.  **武器化**：识别出攻击向量和攻击面后，需评估成功渗透并利用已发现漏洞的可能性。这些信息允许渗透测试人员设计攻击策略，并组装可用于利用那些成功可能性高的漏洞的工具。

3.  **投递**：入侵的这一部分可能是即时的，也可能持续一段时间。网络被渗透后，下一个问题是：现在你已进入内部，该做什么？是立即激活载荷，还是在内部寻找更多机会？在渗透测试场景中，此答案通常在合同协议中指定。

4.  **安装与利用**：此时渗透测试通常进入安装漏洞利用代码并执行攻击策略的阶段。这可能涉及安装后门，为渗透测试人员提供网络或计算设备的命令与控制功能。可以安装不同类型的恶意软件，包括木马、僵尸网络节点或勒索软件。

5.  **目标行动**：此攻击阶段涉及探索利用前期识别出的漏洞所创造的选项。黑帽黑客可以潜伏在网络中，窃取公司机密、信用卡信息、患者医疗数据等。这通常涉及各类欺骗攻击、键盘记录器、会话劫持等。攻击者也可利用访问权限降级、中断、拒绝或摧毁目标资产。这通常涉及病毒、拒绝服务（`DoS`）/分布式拒绝服务（`DDoS`）攻击、中间人（`MitM`）攻击、广播风暴等。

## 渗透测试文档记录

对渗透测试人员而言，`文档记录`至关重要，它能决定测试的成败，也能让你避免严重麻烦。例如，如果你受雇于某组织进行网络渗透测试，除了发现和建议外，拥有可交付的有形成果至关重要。

即使你是内部渗透测试人员，也需要生成清晰准确的文档，以教育管理层并指导负责组织安全的技术人员。有句老话：“如果没记录下来，就等于没发生。”遗憾的是这句话是真理，因为网络安全专业人员产出的大量成果是供客户阅读的技术文档和报告。

报告撰写或许不是世界上最令人兴奋的事，但它必不可少，应给予最高度重视，因为报告中包含的信息通常高度敏感，甚至属于机密。

报告面向对象为行政级高管和 IT 人员。报告副本及接收人也应记录在案。主副本应存放在存放其他贵重信息的高度安全场所。

对渗透测试人员而言，记录所做的一切和讨论的一切至关重要。无论是通过截图、数据转储、数据包捕获还是其他方式，支持你主张的文档越多，你的论据就越有力。

除了收集数据，渗透测试人员还需确保记录详尽的笔记，以便公司 IT 人员能复现任何发现。清晰的笔记也能帮助报告撰写者回顾细节，确保报告清晰简练。

## 向客户汇报

应为客户创建`渗透测试报告`。报告格式应易于阅读，包含页码，并具备专业报告或白皮书的其他特征。虽然这些报告不对外发布（**绝不应**发布），但全程保持专业至关重要，应避免使用任何可能妨碍读者理解的俚语术语。创建专业渗透测试报告涉及几个关键部分：

## 报告结构

### 执行摘要

执行摘要的目标受众应为公司的高管团队。本部分旨在相对非技术性，以便高管了解发生了什么以及为何需要变更。请记住，高管大多关注数字和金额，因此他们会想了解风险以及为何应投资于安全。

### 工作范围

工作范围将包含公司提供的任何信息以及评估的实施方式。它还将详细说明测试的具体目标和渗透测试的禁区。建议包含测试前确立的交战规则，以便高管和 IT 人员理解报告中为何以及如何能够针对这些系统。

### 项目目标

此部分看似冗余，但请记住，参与本报告的某些高管可能是首次接触，因此重申目标非常重要，以确保所有人达成共识。请注意，许多人不“懂技术”，可能不理解为何他们会参与本报告。然而，报告理应帮助他们看到风险分析和涉及的资金，并理解安全是每个人的责任。

### 假设

由于客户可能在测试开始前提供技术信息，因此做出某些假设是可以接受的，以便受众理解您的思维过程及得出特定结论的方式。

### 时间线

时间线可视为交战规则的一部分，定义了测试窗口的开始和结束日期。它还能让 IT 人员大致了解何时可能发生事件；若事件发生在该窗口之外，则绝非渗透测试人员所为。

### 发现摘要

发现摘要是客户高管的得力工具。优秀的摘要应包含以下内容：

- 统计数据
- 影响
- 风险评估

### 详细发现

详细发现部分的目标受众为公司的顶级 IT 人员。后续部分的信息将包含任何有助于理解发现的要素，包括图表和图形。

## 漏洞

本部分应列出每个漏洞的以下信息：

- 漏洞（可以是名称或简短描述）
- 威胁等级
- 影响
- 风险
- 附带详细信息的分析
- 缓解漏洞的建议

### 解决方案与建议

本部分汇总详细发现以及整体漏洞列表的影响和风险。此信息可用于量化漏洞的影响，以防发生事件导致信息泄露。

### 结束语

结束语部分是作者添加最终想法、建议并总结整体测试的地方。

## 安全测试工具

在上一章中，您了解了安全评估（或风险识别）的漏洞扫描和评估阶段中常见的三项活动。回顾一下，它们包括：

- **数据包嗅探**：使用数据包分析器，白帽捕获网络中移动的数据包，记录它们，然后解码其原始数据。随后可分析这些数据，实际上是在监视网络用户。

- **端口扫描**：使用端口扫描工具，渗透测试人员探测网络服务器和设备的开放端口以寻找可利用之处。他们还可以识别主机上运行的服务以进行潜在利用。

- **漏洞扫描**：使用`网络漏洞扫描器`套件，渗透测试人员扫描组织网络中的各类常见漏洞，如系统错误配置和默认密码使用，以及生成畸形数据包以制造 `DoS` 攻击。

这些及其他网络测试工具使白帽能更轻松地审计网络，以了解其资源、评估风险、评估漏洞，并制定缓解（或利用）这些风险和漏洞的计划。

### 数据包嗅探器

`数据包嗅探器`（也称为`数据包分析器`或`协议分析器`）是一种软件监控工具，用于扫描通过它的网络流量。运行这些工具的计算设备通常插入网络，使网络流量流经它，从而实时捕获数据包，如图 9.7 所示。当网络流量通过分析器时，分析器会“嗅探”数据包，寻找混杂活动或仅记录发生的情况。

数据包/协议分析器需要两个网络接口，以便在流量流经时检查网络活动。因为它们不需要巨大的 CPU 资源，支持两个以太网接口的旧笔记本电脑可能是理想选择。性能监控产品也可在旧硬件上运行，是利用闲置老旧计算机硬件的好方法。

![图 9.7 数据包分析器工具](img/c09f007.png)

**图 9.7** 数据包分析器工具

### 网络枚举/端口扫描

无论遇到何种情况，优秀的安全从业者（或黑客）首先做的都是`枚举`网络。这意味着绘制网络图以确定网络上有什么，从而知道能发现哪些主机。

执行此操作可发现各类信息，包括网络上可能存在不应存在的设备。例如，假设您是医院的网络安全工程师，正在进行例行网络扫描。得益于映射和枚举软件，您发现网络上连接了一个`Raspberry Pi`，如图 9.8 所示，这绝对不应该存在。

![图 9.8 网络枚举](img/c09f008.png)

**图 9.8** 网络枚举

因为您了解网络的设置，且三层交换机拥有特定的 DHCP 范围，所以能精准定位设备连接的交换机。您能迅速禁用交换机上的该端口。在本案例中，准确掌握网络资产使您察觉到一个严重的安全问题。

枚举网络的方法和工具多种多样。`Nmap`是最常见的此类工具之一，可用于扫描各种规模的网络，以查找不同类型的网络信息，如每个主机运行的操作系统、潜在的开放端口，或特定网络上的主机。

图 9.9 展示了`Nmap`工具生成的输出，用于映射网络和收集信息。本例中，使用命令`nmap 10.0.0.0/24 -O`生成了网络扫描结果，并尝试揭示设备的操作系统。

![图 9.9 Nmap 输出](img/c09f009.png)

**图 9.9** Nmap 输出

如您所见，此次扫描发现一台运行 OS X 或 iOS 且开放多个端口的设备。从攻击者角度看，若您能在设备上安装`Nmap`并将其置于网络中，将获得极佳的网络视野。

以下是其他值得注意的网络枚举工具：

- **NBTscan**：一种基于 CLI 的信息枚举实用程序，可从目标网络检索用户列表、设备列表、共享列表、名称列表、组/成员列表和密码信息。

#### 工具介绍

*   **DumpSec**：基于 GUI 的工具，提供目标文件系统的权限列表和审核设置，以及用户、组和复制数据。

*   **Legion**：基于 GUI 的实用程序，扫描 IP 地址范围以查找共享资源，如文件、目录、打印机等。

*   **Netcat**：基于 CLI 的计算机网络实用程序，执行枚举和端口扫描活动。除了枚举任务，`Netcat` 还可以使用 TCP 或 UDP 协议连接到目标主机的端口、监听指定端口以接受入站连接、跨网络传输文件以及在目标上执行脚本。一个名为 `Ncat` 的类似工具包含在 `NMAP` 实用程序套件中。虽然不是 `Netcat` 的衍生品，但 `Ncat` 的用法相似。

#### 端口扫描

**端口扫描器** 是设计用于探测计算设备开放逻辑端口及其关联服务的软件工具。图 9.10 展示了攻击者用于定位并利用目标设备（如服务器或端点）漏洞的工具之一。

![图 9.10 端口扫描](img/c09f010.png)

**图 9.10** 端口扫描

端口扫描器通过网络连接向目标主机发送服务请求。这些请求被发送到一系列知名端口值，以识别目标上运行的网络服务。一种称为 **端口扫掠** 的端口扫描形式用于扫描网络环境中响应特定端口的设备，例如响应端口 530（*远程过程调用，RPC*）的计算机。

对于网络管理员而言，端口扫描应被视为攻击序列中可能的第一步。在刚才的示例中，如果黑客定位到此类端口，他们便可开始准备利用该端口的攻击，以利用与之关联的潜在漏洞。在端口扫描与漏洞扫描相结合的情况下，管理员应将后续攻击视为迫在眉睫。

#### 漏洞扫描

**网络漏洞** 扫描器包用于扫描企业中的不同类型的常见漏洞（如系统错误配置和默认密码使用），如 图 9.11 所示。某些扫描器还能通过生成畸形数据包来创建拒绝服务（`DoS`）攻击。

![图 9.11 漏洞扫描](img/c09f011.png)

**图 9.11** 漏洞扫描

网络安全专业人员和黑客都使用这些工具来识别漏洞或获取未经授权的访问。它们在识别以下类型的漏洞方面尤为有价值：

*   网络上的活动主机（包括可能隐藏在网络中的主机）
*   易受攻击的活动端口和服务
*   与操作系统服务器应用程序相关的漏洞

所有漏洞扫描器都是数据库驱动的工具，旨在搜索计算机中已识别并添加到数据库中的已知漏洞。因此，它们的有效性仅取决于其最近一次更新。基于此原因，必须在使用前更新所有漏洞扫描器。

虽然使用漏洞扫描器耗时且消耗资源，但这却是持续安全的重要组成部分，因为它允许尽快解决发现的漏洞，理想情况下是在它们被发现并被利用之前。

有许多免费和商业产品，以及不断增长的服务行业可提供这些监控服务。免费产品是很好的起点，因为它们通常易于设置且不需要大量资源。以下是一些值得考虑的产品：

*   **Nagios** (`www.nagios.org`) 可能是最知名的仍有免费版本的网络监控工具，但它已发展为提供功能齐全的商业企业版。该项目的一个分支 `Icinga` 是一个开源替代品，其功能比 `Nagios` 免费版更全面。这两款产品都拥有大量监控、报告和通知选项，最适合正常运行时间监控，但也可监控性能。

*   **SolarWinds** (`www.solarwinds.com/network-performance-monitor`) 提供功能极其强大的商业网络性能监控产品（NPM），它是其 Orion 平台的一部分。虽然该产品价格略高，但功能强大，可监控正常运行时间、性能、流量和利用率，并提供大量报告、图表和通知选项。

*   **Microsoft Network Monitor** (`https://docs.microsoft.com/en-us/troubleshoot/windows-server/networking/network-monitor-3`) 是一款数据包分析器，可帮助您查看流量流并排查网络问题。正如您所料，该产品在与专有 Microsoft 协议交互方面表现出色，但也支持大多数常见公共协议。

*   **Wireshark** (`wireshark.org`) 是一款成熟的开源跨平台网络协议分析器。它可能是最知名的协议分析器，支持几乎所有协议，且可在几乎任何平台上运行。

*   **Wireshark**（如 图 9.12 所示）是一款用于捕获并随后分析流量以发现和排查网络问题的宝贵工具。它利用网络适配器的 **混杂模式** 功能工作。此模式使网络适配器能够监听通过线缆（或无线网络适配器的无线电波）传输的流量。分析器软件随后收集所有数据包并将其组织成图形化的有用系统，供用户筛选信息。

    ![图 9.12 Wireshark](img/c09f012.png)

    **图 9.12** Wireshark

    它可用于了解给定网络上使用的协议。该工具易于使用，但需要经验和实践才能准确分析其产生的结果。

*   **Snort** (`snort.org`) 是一个开源、跨平台的入侵检测系统，提供实时流量分析、数据包记录和协议分析，以及对蠕虫、端口扫描和漏洞利用尝试的主动检测。这对于实时监控网络非常有用。它非常适合识别探测和攻击，但也可充当网络嗅探器。`Snort`（如 图 9.13 所示）是具有公共服务的网络的优秀产品。

    ![图 9.13 Snort](img/c09f013.png)

    **图 9.13** Snort

*   **Nmap**（如 图 9.14 所示）是一个开源、跨平台的网络映射实用程序，用于网络发现操作、安全审计操作和创建网络资产清单。它还用于执行网络监控功能和跟踪升级计划。这是一款用于检查和分析网络以及发现端口和版本的优秀产品。

    ![图 9.14 Nmap 实用程序](img/c09f014.png)

    **图 9.14** Nmap 实用程序

*   **Nikto** (`https://cirt.net/nikto2`) 是一个开源 Web 服务器扫描器，可识别 Web 服务器上的问题。该工具可对 Web 服务器执行全面测试，检查 6,700 多种安全威胁。`Nikto` 预装在 Kali Linux 发行版的漏洞分析类别中，或可从 GitHub 站点 (`https://github.com/sullo/nikto`) 获取。

## 安全工具与渗透测试概述

### 开源漏洞扫描与渗透测试框架

*   **OpenVAS** (`openvas.org`) 是一款适用于 Linux 和 Windows 的开源漏洞扫描器，它是现已商业化的 Nessus 最后一个免费版本的分支。作为一个完整的漏洞管理解决方案，该工具使用 SCAP，可以执行多种网络漏洞测试 (NVT) 并查找常见漏洞和暴露 (CVE)。该产品有一定的学习曲线，但它是一款备受推崇且功能强大的工具，值得考虑。

*   **Metasploit** (`metasploit.com`) 是最流行的开源渗透测试框架之一。它适用于 Windows 和 Linux 环境。它通常用于识别和验证网络漏洞，包括模拟利用人为漏洞的攻击，如图 9.15 所示。Metasploit 还可用于对发现的网络漏洞的响应进行优先级排序。

    ![图 9.15 Metasploit 操作](img/c09f015.png)

    **图 9.15** Metasploit 操作

*   **浏览器利用框架** (`beefproject.com`) 是另一款著名的开源渗透测试工具，但它专注于通过 Web 浏览器进行的 Web 承载攻击。BeEF 适用于 macOS、Windows 和 Linux。

其他值得评估的安全产品包括 Nessus、Core Impact 和 Nexpose。还有专用的硬件解决方案，如 nGenius 的 Netscout，为监控网络服务和性能提供严肃的解决方案。每个网络都应始终启用某种形式的监控，每个网络管理员也都应有权访问可靠的数据包嗅探工具。

上述提到的软件工具对黑客和网络工程师同样有用。网络工程师可能会使用它们来发现其网络设备的各种问题。然而，对黑客而言，这些信息可能更具启示性。他们使用这些工具开始描绘网络的拓扑结构、哪些系统在使用哪些协议，甚至可能发现包含敏感信息的未加密数据。
