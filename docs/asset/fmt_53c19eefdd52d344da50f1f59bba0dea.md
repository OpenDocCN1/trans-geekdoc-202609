### 与 GmrB 的对话

以下是与黑客 GmrB（也称为 GloriousBeast）的对话。他曾在 PasteBin 和其他暗网论坛上非常流行，因其发布的关于如何隐藏数据和加密文件的教程而闻名。

这段对话是在深网社交网络 Galaxy9 上联系 GmrB 后，通过 IRC 聊天进行的。

- 告诉我更多关于你如何在在线和离线状态移动信息？你倾向于如何加密数据？
- 我使用 `Steghide`，这是一个在图像中隐藏信息的命令行工具。隐藏任何类型文件的信息只需几秒钟。有些人称其为“数字隐写术”。隐写是将数据隐藏在肉眼可见的地方，即在照片或音频轨道等文件中。对于 JPEG 或 GIF 等图像文件，对于任何不清楚其包含隐藏数据的人来说，它看起来就像一张普通的图片。这种方法在言论自由受压的国家特别有用。它类似于用于查找图像或音频文件是否为原始文件的数字水印。

- 告诉我更多关于你如何如何在在线和离线状态移动信息？你倾向于如何加密数据？
- 答. 最常用的技术被称为最低有效位（Least Significant Bit，简称 LSB）。LSB 过程通过改变字节的最后几个位来编码消息，这在图像等领域特别有用，在图像中每个像素的红、绿、蓝值由位（一个字节）表示，十进制范围为 0 到 255，二进制范围为 00000000 到 11111111。例如，将一个纯红色像素的最后两个位从 11111111 改为 11111101，仅会将红色值从 255 变为 253，这在肉眼看来造成了几乎无法察觉的颜色变化，但仍然允许我们在图片内部编码数据。如果你已经有了良好的编程和数学基础，你也可以设计自己的算法。

Q. 良好的数字隐写术的基础是什么？
- 答. 加密和压缩。数据加密增加了一层额外的安全性，压缩则允许你在你的“隐藏文件”中放入更多信息。

Q. 在文件中隐藏数据的更简单的方法是什么？
- 答. 使用 `Steghide`。

Q. 你能详细说明一下安装它的步骤吗？例如，如果用户正在运行 Kali Linux，它将如何工作？
答. 好的，打开终端并输入：

```
apt-get install steghide
```

然后输入：

```
steghide embed -ef secretFile -cf outputFile -sf outputFile -z compressionLevel -e scheme
```

记得使用正确的参数，这里是最近更新的 `steghide` 参数列表：

- `-ef` 指定你想要隐藏的文件路径。你可以在载体文件中嵌入任何类型的文件，包括 Python 脚本或 shell 文件。
- `-cf` 是数据嵌入其中的文件。这被限于 BMP、JPEG、WAV 和 AU 文件。
- `-sf` 是一个可选参数，指定输出文件。如果省略此参数，原始载体文件将被你的新隐写文件重写。
- `-z` 指定压缩级别，范围在 1 到 9 之间。如果你不想压缩文件，请使用参数 `-Z`。
- `-e` 指定加密类型。`Steghide` 支持多种加密方案，如果默认省略此参数，`Steghide` 将使用 128 位 AES 加密，你也可以选择不加密。

Q. 有个示例吗？
- 答. 输入这个：

```
steghide embed -ef SECRETMESSAGE.txt -cf YOURIMAGE.jpg -e none -Z
```

该示例没有使用任何加密或压缩，仅仅是用来展示 `Steghide` 如何工作的测试。执行 `steghide` 命令后，系统会提示你设置密码。密码将允许你之后提取嵌入的数据。

要提取图像中隐藏的 `SECRETMESSAGE.txt`，使用以下命令：

```
steghide extract -sf stegoFile outputFile
```

一旦运行此命令，系统将提示你输入之前创建的相同密码。然后提取的文件将是 `out`。有时你可以通过 `https://images.google.com/` 找到隐藏信息，如果你正试图安全地隐藏数据，这可不太好……
