# 主机加固

主机加固可以描述为一系列执行的步骤，旨在删除不需要的服务和功能，使攻击者更难成功攻击计算机。因为在加固过程中很容易忽略某些细节，公司应采用标准方法论来加固计算机和设备。不同的操作系统（如 Mac、Linux 和 Windows）需要不同的安全基准。此外，工作站的主机设置与服务器不同。

![](img/7868547987f5920cfe632b85047c64af_274_0.png)

加固系统的几种良好技术包括使用操作系统厂商基准和工具，如微软基准安全分析器 (MBSA)、美国标准与技术研究院 (NIST) 标准、信息和相关系统控制目标 (CIS) 基准以及国家安全局 (NSA) 加固指南。

尽管这看起来是一个简单的概念，但良好的安全实践始于物理安全。如果攻击者可以物理上访问系统，那么控制它将是一件易事。系统应该受到物理保护。训练用户在未使用时关闭系统是一项基本控制，同时实施密码保护的屏幕保护程序和自动注销。主机应该被加固，以便在操作系统完全启动之前就是安全的。可以使用以下几项目作为启动加载程序保护：

- **安全启动 (Secure Boot)**：由 PC 行业成员开发的安全标准，旨在确保你的 PC 使用设备制造商信任的软件启动。

- **测量启动 (Measured Launch)**：该方法与 TPM 和安全启动过程配合，确定是否允许加载操作系统以及哪些部分可以执行。

- **IMA**：完整性测量体系 (IMA) 由 IBM 开发，用于验证 Linux 操作系统的完整性和信任。

- **BIOS/UEFI**：统一扩展固件接口 (UEFI) 是每台 Windows 8 计算机的配置。UEFI 是 BIOS 的替代或扩展，类似于在最终操作系统启动之前运行的操作系统。它旨在阻止 rootkit 和其他可能控制 BIOS 系统的恶意软件。

保护网络设备和主机计算机代表了多层安全方法。在加固主机系统时，你应该检查的一些通用领域包括：

- **使用应用程序白名单和黑名单**：白名单可以定义为授予访问权限的实体列表。黑名单则相反；它列出无法访问的内容。将白名单视为隐式的“不允许所有”（除非添加到列表中），而将黑名单视为隐式的“允许所有”（除非添加到列表中）。

# 实施安全/组策略

微软在引入 Windows 2000 时创建了组策略。你可以将组策略视为用户配置设置和计算机配置设置的组合，这些设置可以链接到活动目录中的对象。这些策略应用于用户和计算机。组策略允许安全管理员在数百台计算机上维护一致的安全配置。在组策略中设置安全选项时，以下初始安全设置专门涉及“账户策略”和“本地策略”节点。账户策略包含密码策略、账户锁定策略和 Kerberos 策略。本地策略适用于审计策略、用户权限和安全选项。

## 标准操作环境

标准操作系统是在整个组织范围内使用的标准构建版本。其优势之一是降低了总拥有成本 (TCO)。然而，真正的优势在于配置的一致性。当需要更新或需要安全补丁时，统一的环境使得这种标准化镜像更容易进行测试。

> 最新的安全补丁应尽快经过测试，然后尽快安装在主机系统上。唯一的例外是立即应用这些补丁会干扰业务需求。

> 请记住安全与性能的五个 P：适当的计划（Proper Planning）可以防止糟糕的性能（Poor Performance）和安全问题（and security issues）。

## 修复已知漏洞

构建安全基线是主机安全的良好开始，但一个大关注的领域是修复已知漏洞。为了跟进这一过程，你应该定期运行漏洞评估工具。诸如 Nessus、SAINT 和 Retina 等漏洞评估工具设计为每周或每月运行一次，以寻找已知漏洞和问题。识别这些问题并及时修补有助于降低整体攻击风险。

### 使用警告横幅

*警告横幅*（Warning banners）是简短的消息，告知用户有关使用应用程序和服务的特定策略和程序。警告横幅可以是启动屏幕、弹出窗口或消息框，用于告知用户特定规则。警告横幅至关重要，因为它们告知用户可能被允许也可能不被允许的特定行为活动。由于警告横幅说明了特定行为的状态，消除了用户的借口，从而可以记录违规。警告横幅应包含被认为是适当的使用、预期以及对不合规的惩罚。

![](img/7868547987f5920cfe632b85047c64af_278_0.png)

安全专业人员在决定使用横幅显示哪些服务或应用程序时，应咨询其法律部门。法律、人力资源和管理部门在选择特定措辞之前，应仔细考虑公司及其用户的需求。

### 使用受限接口

*受限接口*（A restricted interface）是一个规定了在该环境中可用程序、菜单、应用程序、命令或功能的配置。这种技术允许安全管理员控制用户可以访问的内容。这种技术被认为是受限接口，是因为用户只能提供的接口。在现代操作系统中，单个接口可以跟随管理员控制的任何桌面或笔记本电脑。

### 配置专用接口

专用接口是为特定流量设计的端口。例如，许多公司将无线局域网放在专用接口上，并与其他流量隔离。

### 使用带外网卡

带外网卡（Out-of-Band NIC）是指配置为专用管理通道的网络卡。

### 管理接口的配置

管理接口设计用于管理可能关闭或无响应的计算机。管理接口利用网络连接到硬件，而不是连接到操作系统或登录壳。管理接口通常使用带外网卡。

### 管理数据接口

数据接口用于数据库生成过程模板。过程模板是可重复的集合。它们允许系统集成人员和其他处理类似类型的数据。

## 资产管理

资产管理是组织、跟踪和支持公司资产的过程。公司对技术的依赖比过去大得多。为了充分利用这些技术，公司必须了解自己拥有什么以及如何管理。该过程的第一步是组织所有的资产。接下来，对技术进行跟踪。最后，通过 IT 变更管理支持技术。IT变更管理是一种用于控制系统和程序更改的正式化流程。这包括硬件、软件和应用程序配置。如果没有有效的变更管理程序，就会发生未经授权的更改，并危及组织安全。不受控制的变更管理还会导致操作在未测试或未知的状态下进行。管理的步骤如下：

1. 提交变更请求。

2. 获得变更请求。

3. 测试变更并记录发现。

4. 实施变更。

5. 向公司管理层报告变更。

任何建议的更改都必须仔细检查，以确保建议的修改不对流程产生负面影响。

变更管理应该有一个回滚路径，以便在变更失败时可以撤销。

## 数据外泄

数据外泄是指未经授权将数据从计算机传输出去。许多组织对外围设备实施了控制或限制，以解决数据外泄问题。这些措施包括对 USB、蓝牙和火线（FireWire）的控制。

USB 已经获得了巨大的市场份额。USB 克服了传统串行接口的局限性。USB 2.0 设备的通信速度高达 480 Mbps，而 USB 3.0 设备的理论速率为 4.8 Gbps。多可以串联高达 127 个设备。USB 用于闪存、摄像头、打印机、外部硬盘甚至智能手机。USB 具有广泛的产品支持，许多设备在连接后会立即被识别。USB 的竞争标准是火线，或 IEEE 1394。这种设计常见于许多 Apple 计算机，但也出现在数字音视频设备中。这些技术的问题在于它们可以被攻击者利用。例如，人们认为震网病毒（Stuxnet）是通过 USB 闪盘传输到伊朗核设施的。
