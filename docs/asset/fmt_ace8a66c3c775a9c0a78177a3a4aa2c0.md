#### 3.1 主观图像质量评估

主观图像质量评估是人类专家就图像性质提供观点的产物。但结果可能因人而异。在使用直方图的任意计算中，确定图像的准确性。直方图易于测量，且常适用于基于硬件的经济型实现，因此可有效用于图像增强目的。这使得直方图成为实时处理图像的常用方法。直方图是以图形形式表示图像的示意图，横坐标为 0–255 范围内的灰度值，纵坐标为频率。直方图按灰度级分为四个基本特征：亮、暗、高对比度 [⁸⁴]

对于暗图像，直方图的分量集中在现有灰度级的低侧（即接近 0 值）。同理，亮图像直方图的元素偏向灰度级的高端。高对比度图像的直方图覆盖了灰度级的宽频谱。像素分布不太远离。高质量多见于高对比度图像。

#### 3.2 客观图像质量评估
