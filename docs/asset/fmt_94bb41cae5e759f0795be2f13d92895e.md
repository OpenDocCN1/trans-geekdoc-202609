
当牛顿在 1687 年出版《自然哲学原理》时，这一切还没有被正式理解为向量分析的开端。然而，他的同代人戈特里德·威廉·莱布尼茨（Gottfried Wilhelm Leibniz，1646–1716）对这种新的思考方式已经略有端倪。1679 年，莱布尼茨在给另一位著名的同代人克里斯蒂亚安·惠格斯（Christiaan Huygens）的信中写道：“我相信我找到了一种方法……我们能够用字符来表示图形甚至是运动，正如代数表示数字或大小一样。”

还有另一种表示向量的方法。如果我们限制在二维空间，想象一个沿 x 轴长度为 1 的向量 `i`，以及一个沿 y 轴长度为 1 的向量 `j`。注意 `i` 和 `j` 是小写加粗的；这表示它们是向量。因此，`i` 可以被看作一个从 (0, 0) 指向 (1, 0) 的箭头，而 `j` 可以看作一个从 (0, 0) 指向 (0, 1) 的箭头。它们的模均为 1，也被称为单位向量。基于此，笛卡尔坐标中的向量 (4, 3) 和 (2, 6) 分别可以写为 `4i + 3j` 和 `2i + 6j`。这等于说向量 (4, 3) 沿 x 轴 4 个单位，沿 y 轴 3 个单位，而向量 (2, 6) 沿 x 轴 2 个单位，沿 y 轴 6 个单位。使用 `i` 和 `j` 是表示向量的简写。同样重要的一点是，单位向量仅仅是模为 1 的向量；它并不一定位于某些坐标空间的垂直轴上。

这些思想也适用于更高维，我们将会讨论这一点。目前，掌握 2D 向量的数学运算及其相应的几何意义，将极大地帮助我们理解它们的高维对应物在机器学习中的作用。

点积告诉我们关于两个向量的另一个信息是它们是否相互垂直（正交）。如果它们相互垂直，那么 (90°) 的余弦等于零。因此，无论向量的长度如何，它们的点积，或者向量 `b` 在向量 `a` 上的投影，始终为零。相反，如果两个向量的点积为零，它们就是相互垂直的。

如果我们使用另一种表示向量的方法（即使用它们分量），并且不知道两个向量之间的角，我们该如何计算点积？

假设 `a = a1i + a2j` 且 `b = b1i + b2j`。那么：

```
a.b = (a1*i + a2*j).(b1*i + b2*j) = a1*b1 × i.i + a1*b2 × i.j + a2*b1 × j.i + a2*b2 × j.j
```

注意方程中的第二项和第三项结果为零。向量 `i` 和 `j` 是正交的，所以 `i.j` 和 `j.i` 为零。此外，`i.i` 和 `j.j` 都等于 1。我们剩下的只是一个标量：

```
a.b = a1*b1 + a2*b2
```

### 机器与向量

如果你觉得这一切与机器学习、感知机和深度神经网络都非常遥远，请放心，并非如此。它是情节的核心。我们正向那里走，尽管是跨越式的，但每一步都踩在坚实的石头上。

是时候重新审视感知机并从向量的角度来思考它了。意图是通过几何直觉来理解数据点和感知器的权重如何表示为向量，以及当感知器试图寻找将数据点分为两类的线性超平面时发生了什么。这涉及到使用向量的点积来寻找数据点到超平面的距离。

回顾感知器的通用方程，如果如果加权和加上偏置项 `b` 大于 0，感知器输出 1；否则输出 -1。

我们对使用的符号进行了细微的变化：函数 `g` 的参数现在是一个向量；在上一章中，因为还没有引入向量的概念，我们直接使用 `g(x)`。让我们留在二维情况，数据点由 `(x1, x2)` 给出，感知器的权重由 `(w1, w2)` 给出。感知机首先计算加权和：

```
w1*x1 + w2*x2
```

我们之前对感知机算法的观察表明，它试图找到一个将坐标空间分为两个部分的超平面。因此，感知机是在寻找或学习一组适当的权重。这些权重构成一个向量 `w`，它与超平面正交。当你改变感知机的权重时，你实际上改变了 `w` 的方向，从而改变了超平面的方向，而超平面始终与 `w` 垂直。适用于 `w` 的特性也适用于处于相同方向的单位向量 `u`。因此，重新表述感知机作用的一种方式是：它在寻找向量 `w`，这等同于它在寻找对应的垂直超平面。

现在考虑位于阴影区域或不在阴影区域的数据点。每个数据点由 `(x1, x2)` 给出，也可以被看作一个向量。那么，加权和 `w1*x1 + w2*x2` 等于表示数据点的向量与权重向量之间的点积。请注意，如果数据点位于超平面上（在 2D 情况下是一条直线），那么向量 `(x1, x2)` 将与 `w` 正交，使得点积等于零。下方 显示了数据点与权重向量点积的图形化视图。为了方便起见，我们将单位长度的权重向量。这在概念上没有改变任何东西，但简化了数学计算。让我们从由数据点 (3, 1) 给出的向量 `a` 开始。

由于 `w` 是单位向量，它与 `a` 的点积等于 `a` 在虚线上的投影。`a` 落在垂直于超平面的直线上的点，衡量了点 (3,1) 到超平面的距离。

更通地说，这些数组被称为矩阵（matrices），它们包含数字的行和列。例如，如果有 `m` 行 `n` 列，那么我们就有一个所谓的 `m × n` 矩阵（读作“m 乘 n 矩阵”）。向量是矩阵的一种特殊形式，只有一行或一列：`m=1` 或 `n=1`。我们之前见过了这些，只是还没有引入“矩阵”这个词。但向量本质上就是这样：只有一列或一行的矩阵。这里有一个两个单列矩阵相加得到第三个单列矩阵的例子。

注意，这正是如果你用单位向量 `i` 和 `j` 来表示向量时会得到的值。如果 `a = a11*i + a12*j` 且 `b = b11*i + b21*j`，那么：

```
a.b = (a11*i + a12*j) . (b11*i + b21*j)
⇒ a.b = a11*b11*i.i + a11*b21*i.j + a12*b11*j.i + a12*b21*j.j
⇒ a.b = a11*b11 + a12*b21
```

使用矩阵而非箭头来表示向量，还有另一个非常酷的地方：你只需要操作数字，就能得到点积的标量值，而无需担心它们之间角度的余弦。这意味着，如果你有一组数据点（每个点由一个向量表示），并且你想找到它们到由权重向量 `w` 特征的超面的相对距离，你只需要计算每个数据点与 `w` 的点积即可获得所需的信息。

如果其中一个数据点位于超平面上，它与权重向量的点积为零，这意味着该数据点与权重向量正交，它到超平面的距离为零。
