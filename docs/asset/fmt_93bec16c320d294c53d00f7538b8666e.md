
```python
def convolve3d(X, K, P=(0,0), S=(1,1)): 
    C, H, W = X.shape
    C, F_h, F_w = K.shape
    P_h, P_w = P[0], P[1]
    S_h, S_w = S[0], S[1]   
    h = (H + 2 * P_h - F_h) // S_h + 1
    w = (W + 2 * P_w - F_w) // S_w + 1
    Y = np.zeros((h, w))            # convolution output
    if P_h != 0 or P_w != 0:  
        X_padded = np.pad(X, [(0,0), (P_h, P_h), (P_w, P_w)], mode='constant')
    else:
        X_padded = X
    for i in range(h):     # Loop over every pixel of the image  
        hs = i * S_h
        for j in range(w):   
            ws = j * S_w
            # element-wise multiplication of the kernel and the image
            Y[i, j] = (K * X_padded[:, hs:hs+F_h, ws:ws+F_w]).sum()        
    return Y
```

## 6.1.5 池化

与卷积类似，**池化**也使用固定形状的窗口（称为**池化窗口**）对齐数据并计算数据窗口的输出值。不同于卷积对输入数据与卷积核的加权求和，池化直接计算数据池化窗口中元素的最大值或平均值。如图 6-29 所示，使用 3×3 窗口从输入二维（图像）矩阵的左上角开始“从上到下，从左向右”滑动，每滑动到一个位置，输出当前池化窗口对应数据窗口中元素的最大值，以生成最终的结果矩阵。此过程称为**最大池化**。

图 6-29 3×3 窗口对 6×6 矩阵（图像）执行池化，生成尺寸为 4×4 的结果图像

当然，也可计算池化窗口中的平均值作为输出值。此池化运算称为**平均池化**。平均池化的工作方式与最大池化类似，只是对数据窗口中的元素求平均而非取最大值。

与卷积运算一样，池化运算的窗口通常为正方形。上述池化运算的步长为 1，即每次移动一个像素。池化运算的步长通常与池化窗口的长度或宽度相同。

如图 6-30 所示，池化运算的窗口长度和步长均为 3，在 6×6 上执行池化运算，生成 2×2 的结果图像，而原始图像尺寸为 6×6。

图 6-30 3×3 池化窗口，步长为 3 对 6×6 执行池化运算，生成 2×2 的结果图像

池化的主要目标是缓解卷积运算对位置的过度敏感。池化层可保留原始图像的主要特征，步长大于 1 的池化运算可指数级缩小图像尺寸并生成更小的特征图，从而减少后续层的计算量并提高计算效率。

与使用卷积核卷积输入数据所有通道的卷积运算不同，池化通常对每个通道单独执行池化运算。因此，输出通道数与输入数据相同，如图 6-31 所示：若输入为 64 通道，输出也为 64 通道，即每个输入通道生成一个输出通道。

图 6-31 池化针对每个通道，池化运算不改变通道数

与卷积运算一样，池化运算不仅有步长，还会在池化前填充原始图像。类似于卷积运算，可编写以下代码对单通道输入数据 `X` 执行池化运算：

```python
def pool2d(X, pool, stride=(1,1), padding=(0,0), mode='max'):
    pool_h, pool_w = pool
    S_h, S_w = stride
    P_h, P_w = padding
    # fill
    if P_h or P_w:
        X_padded = np.pad(X, [(P_h, P_h), (P_w, P_w)], mode='constant')
    else:
        X_padded = X
```

##### 执行池化操作

```python
Y_h, Y_w = (X.shape[0] - pool_h + 2 * P_h) // S_h + 1, (X.shape[1] - pool_w + 2 * P_w) // S_w + 1

Y = np.zeros((Y_h, Y_w), dtype=X.dtype)

for i in range(Y.shape[0]):
    hs = i * S_h
    for j in range(Y.shape[1]):
        ws = j * S_w
        if mode == 'max':  # 最大池化
            Y[i, j] = X[hs: hs + pool_h, ws: ws + pool_w].max()
        elif mode == 'avg':
            Y[i, j] = X[hs: hs + pool_h, ws: ws + pool_w].mean()

return Y
```

```python
def pool(X, pool, stride=(1, 1), padding=(0, 0), mode='max'):
    pool_h, pool_w = pool
    S_h, S_w = stride
    P_h, P_w = padding

    if P_h or P_w:
        X_padded = np.pad(X, [(0, 0), (P_h, P_h), (P_w, P_w)], mode='constant')
    else:
        X_padded = X

    Y_h, Y_w = (X.shape[1] - pool_h + 2 * P_h) // S_h + 1, (X.shape[1] - pool_w + 2 * P_w) // S_w + 1
    Y = np.zeros((X.shape[0], Y_h, Y_w), dtype=X.dtype)

    print(X.shape)
    print(Y.shape)

    for c in range(Y.shape[0]):
        for i in range(Y.shape[1]):
            hs = i * S_h
            for j in range(Y.shape[2]):
                ws = j * S_w
                if mode == 'max':
                    Y[c, i, j] = X[c, hs: hs + pool_h, ws: ws + pool_w].max()
                elif mode == 'avg':
                    Y[c, i, j] = X[c, hs: hs + pool_h, ws: ws + pool_w].mean()

    return Y
```

## 6.2 卷积神经网络

前面神经网络的神经元都是所谓的**全连接**神经元。每个神经元将直接计算所有输入特征的加权和。对于全连接神经网络，输入样本数据必须表示为一维向量，这不适合处理图像等多维数据。虽然多维数据可以展平为一维向量，但存在效率低、无法捕捉多维数据内部结构等缺点。以卷积运算为神经元的卷积神经网络是此类数据的最佳选择。2012 年，AlexNet 使用卷积神经网络赢得了 ImageNet 竞赛，这使处于低谷的神经网络重焕生机，也标志着神经网络从传统的低层神经网络向基于深层神经网络的深度学习过渡。近年来，作为深度学习核心的卷积神经网络研究取得了大量新进展，涌现出各种改进的卷积神经网络结构，如 GoogleNet、ResNet（残差网络）等。

### 6.2.1 全连接神经元与卷积神经元

全连接网络的每个全连接神经元直接对所有输入特征执行加权求和运算，因此每个神经元中的权重数量（不含偏置）与输入特征的数量一样多。过多的权重参数不仅消耗更多内存，还会使模型函数复杂且容易过拟合。如果输入样本是多维张量（如多通道图像），输入全连接神经元时需要将其展平为一维张量，这会破坏数据本身的空间结构，不利于提取样本的内在结构特征。

与全连接神经元不同，**卷积神经元**使用卷积核对输入样本执行卷积运算，卷积核的参数数量通常远少于样本的特征数量。例如，对于一个 3 × 64 × 64 的彩色图像，卷积神经元使用大小为 3 × 4 × 4 的卷积核，该卷积神经元仅有 48 个参数。与全连接神经元相比，卷积神经元的权重参数较少，有助于防止过拟合。此外，全连接神经元仅产生单个输出值。因此，全连接网络层需要许多全连接神经元来提取足够的特征，而卷积神经元则产生包含多个输出值的特征图。由卷积神经元组成的卷积网络层只需要少量的卷积神经元。

如图 6-33 所示，与仅输出一个值的全连接神经元不同，卷积核沿着输入“从上到下，从左到右”移动。每当卷积核窗口与一个数据窗口对齐时，就会生成一个输出值。卷积核沿着输入数据移动，产生许多按原始数据规律排列的输出值。这些规律排列的输出值称为**特征图**。输入多通道图像输出单通道特征图。卷积运算可以保留并捕捉原始数据相邻数据（像素）之间固有的空间结构关系。即能更好地捕捉数据的内在特性，提高神经网络函数的质量。

**图 6-33** 与卷积神经元的卷积核窗口对齐的数据窗口生成一个输出值，卷积核窗口沿着输入数据移动，生成的一系列规律排列的输出值构成一个输出特征图。一个卷积核将生成多个特征图。

对于多通道输入张量，卷积神经元的运算可用以下公式表示：

$$a_{i',j'} = g\left(\sum_{k = 0}^{F_k - 1}\sum_{i = 0}^{F_h - 1}\sum_{j = 0}^{F_w - 1}w_{i,j,k}x_{i + i',j + j',k} + b\right)$$

与前面的神经元一样，每个卷积神经元也有一个偏置 `b` 和一个激活函数 `g`。卷积运算的结果也经过激活函数变换后输出。虽然卷积神经元的通道数与输入相同，但其分辨率通常远小于输入图像。

### 6.2.2 卷积层与卷积神经网络

在神经网络中，如果某一层的神经元全是卷积神经元，则该层神经元称为**卷积层**。如果某层有 `k'` 个神经元，每个神经元的激活函数和偏置分别记为 `g[k']`、`b[k']`。如果输入是多通道三维张量 `x[u, v, c]`，权重矩阵是四维张量，可记为 `w[i, j, k, k']`。则输出第 `k'` 个特征图中 `(i', j')` 像素值的计算公式为：

$$a_{i',j',k'} = g_{k'}\left(\sum_{k = 0}^{F_k - 1}\sum_{i = 0}^{F_h - 1}\sum_{j = 0}^{F_w - 1}w_{i,j,k,k'}x_{i + i',j + j',k} + b_{k'}\right)$$

对于多通道输入，每个通道数相同的卷积神经元产生一个输出特征图。如果一个卷积层有 `k'` 个神经元，将生成 `k'` 个特征图或 `k'` 个输出通道。即卷积层中的多个卷积神经元将生成相同数量的特征图，如图 6-34 所示。对于 3 通道输入数据，2 个卷积神经元输出 2 通道的特征图（其中每个圆圈代表一个卷积神经元）。正如全连接层的输出可作为下一全连接层的输入，一个卷积层输出的多通道特征图可作为下一个卷积层的多通道输入。
