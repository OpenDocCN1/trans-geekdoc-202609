
在两个 `n`-gram 图 `G^(i)` 和 `G^(j)` 之间，存在一个称为**值相似度**（VS）的对称归一化相似度函数。该度量量化了两个图之间公共边的比率，同时考虑了公共边权重的比率。在该度量中，每条匹配边 `e` 在图 `G^(i)` 和 `G^(j)` 中分别具有权重 `w[e]^(i)` 和 `w[e]^(j)`，其对 VS 的贡献量为 `VR(e) / max(|G^(i)|, |G^(j)|)`，其中 `|·|` 表示关于边数量的基数，且

```
VR(e) := min(w_e^i, w_e^j) / max(w_e^i, w_e^j).
```

(11.101)

不匹配的边无贡献（考虑到对于边 `e ∉ G^(i) (G^(j))`，我们定义 `w[e]^(i) = 0 (w[e]^(j) = 0)`）。该方程表明**值比率**（VR）取值范围为 `[0, 1]`，且具有对称性。因此，VS 的完整方程为

### 相似度度量

$$\\text{VS}(G^{i},G^{j}) = \\frac{\\sum_{e \\in G^{i}}\\frac{\\text{min}(w_{e}^{i},w_{e}^{j})}{\\text{max}(w_{e}^{i},w_{e}^{j})}}{\\text{max}(|G^{i}|,|G^{j}|)}.$$

对于共享许多具有相似权重的边的图，VS 的取值接近 1。`VS = 1` 表示被比较的图之间**完全匹配**。对于图 11.19 和图 11.20 中所示的两个图，VS 的计算返回值为 `VS = 0.067`（请验证）。

在我们的案例研究中，VS 将被用于构建 SVM 核分类器，以便将文本分配（分类）给其作者。我们必须在此强调，VS 函数是一个相似度函数，而**非**核函数。幸运的是，正如文献 [6, 定理 3] 中定义的那样，在特定数据集上的 VS 是一个 `(\u03b5, \u03b3)`-良好相似度函数，因此这允许将其作为核函数使用，这与我们在第 11.5.2 节中关于字符串核的论述一致。

值得注意的是，给定文本的 VSM 表示，也可以在字符串上使用任意基于向量的核。此外，已有多项工作使用*字符串核*[69]，以避免原始字符串与其 VSM 等价形式之间转换时的任何信息损失。在本例中，我们演示了如何通过适当的核函数，将甚至复杂的表示与 SVM 相结合。

我们用于考察该组合有效性的数据集是 UCI 存储库 [5] 中 [Reuter_50_50 数据集](https://archive.ics.uci.edu/ml/datasets/Reuter_50_50) 的一个子集。该数据集包含来自 50 位不同作者的 2500 篇训练文本和 2500 篇测试文本（每位作者 50 篇训练文本和 50 篇测试文本）。

*   首先，我们使用了 `ngg2svm` 命令行工具^(⁸²)
*   给定核矩阵，我们可以使用 `LibSVM` 软件 [24] 来设计分类器，而无需关心原始文本，仅依赖预计算的核值。
