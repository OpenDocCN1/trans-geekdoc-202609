
| BigQuery Spark 连接器 | | 适用于 Google BigQuery 的 Apache Spark SQL 连接器。该连接器支持将 Google BigQuery 表读取到 Spark 的 `DataFrames` 中，并将 `DataFrames` 写回 BigQuery。这是通过使用 Spark SQL `Data Source API` 与 BigQuery 通信来完成的。 |

| 结合 Dataproc 使用 Cloud Bigtable | | 对于任何需要 Apache HBase 的 Apache Spark 或 Hadoop 用例，Bigtable 都是一个绝佳的选择。Bigtable 支持 Apache HBase API，因此可以轻松地将 Bigtable 与 Dataproc 结合使用。 |

| Pub/Sub Lite Spark 连接器 | | Pub/Sub Lite Spark 连接器支持将 Pub/Sub Lite 作为输入源，用于默认微批处理和实验性连续处理模式下的 Apache Spark Structured Streaming。 |

所有 Cloud Dataproc 集群均内置了用于 Hadoop 的 BigQuery 连接器，以便您可以轻快地在 Cloud Dataproc 与 BigQuery 之间读写数据。

#### Cloud Composer

创建、运行和管理工作流的方式有多种，例如运行 Cron 任务、使用 Cron 作业、编写脚本和创建自定义应用。每种方法都有利弊。更重要的是，上述所有方法都存在管理开销。这就是我们推出 Cloud Composer 的原因，它是一项全代管式数据工作流编排服务，允许您编写、调度和监控流水线。Cloud Composer 基于 Apache Airflow 构建，流水线使用 Python 配置为有向无环图 (DAG)。

它支持混合云和多云架构，无论工作流流水线位于本地、多个云中，还是完全在 Google Cloud 内部，均可对其进行管理。

Cloud Composer 提供与 Google Cloud 产品的端到端集成，包括 BigQuery、Dataflow、Dataproc、Datastore、Cloud Storage、Pub/Sub 和 Vertex AI Platform，让用户能够完全自由地编排其流水线。

#### 在不同环境中将模型训练作为作业运行

Vertex AI 支持两种类型的训练：

*   **AutoML：** AutoML 让您能够以极少的技术工作量创建和训练模型。我们在 第 4 章“选择合适的 ML 基础设施”中详细介绍了 AutoML。

*   **自定义训练：** 自定义训练让您能够创建针对目标结果进行优化的训练应用。您可以完全控制训练应用的功能。具体而言，您可以以任何目标为对象，使用任何算法，开发自己的损失函数或指标，或进行任何其他自定义。在以下章节中，我们将重点介绍使用 Vertex AI 进行自定义训练。

##### Vertex AI 训练工作流

使用 Vertex AI，您可以使用以下选项为 AutoML 或自定义模型创建训练作业或训练资源：

*   **训练流水线：** 训练流水线是 Vertex AI 中主要的模型训练工作流。您可以使用训练流水线创建 AutoML 训练的模型或自定义训练的模型。对于自定义训练模型，训练流水线可编排自定义训练作业和超参数调优，并包含添加数据集或将模型上传到 Vertex AI 以用于预测服务等额外步骤。图 8.17 显示了 Vertex AI 控制台中的训练流水线。

    ![FIGURE 8.17 Vertex AI 控制台中的训练 ¶ 来源：Google LLC.](img/c08f017.png)

    **图 8.17** Vertex AI 控制台中的训练 ¶ 来源：Google LLC。

*   **自定义作业：** 自定义作业指定 Vertex AI 如何运行您的自定义训练代码，包括工作器池、机器类型以及与您的 Python 训练应用和自定义容器相关的设置。自定义作业仅用于自定义训练模型，而非 AutoML 模型。当您创建自定义作业时，您需要指定 Vertex AI 运行训练代码所需的设置。

*   **超参数调优作业：** 超参数调优通过在一系列试验中优化指标值，搜索超参数值的最佳组合。超参数调优仅用于自定义训练模型，而非 AutoML 模型。我们将在本章后面的“超参数调优”部分介绍这一点。

训练始于数据集。在 Vertex AI 中，您有两种存储和管理数据集的选择：
