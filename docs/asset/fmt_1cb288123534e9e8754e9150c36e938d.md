
如果不满足条件（如果至少有一个乘积小于 10），则从样本获得的估计值分布将无法在不损失准确性的情况下用正态分布近似。

12.2 节和 12.3 节将详细说明正态分布近似如何帮助我们建立对归纳分类器测量性能的信心。

![image](img/image277.png)插图

让我们检查在表 12.1 的情况下这些条件是如何满足的。我们知道原始总体中 1 的比例是由随机数生成器决定的：`p = 0.8`。让我们从大小为 `n = 10` 的样本开始。事实证明没有任何条件满足，因为 `np = 10 * 0.8 = 8 < 10` 且 `n(1-p) = 10 * 0.2 = 2 < 10`。因此，这种大小样本中的比例分布无法用正态分布近似。

在第二次尝试中，样本量增加到 `n = 30`。结果，我们得到 `np = 30 * 0.8 = 24 ≥ 10`，这意味着条件 12.1 被满足。但同时，`n(1-p) = 30 * 0.2 = 6 < 10`，所以没有满足条件 (12.2)。即使在这里，正态分布也没有提供准确的近似。

如果我们将样本量增加到 `n = 60`，情况就会改变。通过计算，我们可以很容易地确定 `np = 60 * 0.8 = 48 ≥ 10` 且 `n(1-p) = 60 * 0.2 = 12 ≥ 10`。两个条件都满足了，因此得出结论，这种大小样本中的比例分布可以用正态分布近似。

#### p 的影响

注意正态分布的适用性如何受到 `p`（总体中 1 的比例）的影响。很容易看出，对于不同的 `p` 值，为了满足条件，需要不同的样本量。如果 `p` 为 0.5，较小的尺寸就足够；但比例偏离 0.5 越远，需要的样本越大。

为了更好地理解这在实践中意味着什么，回想在 `p = 0.8` 的情况下我们发现 `n = 60` 的样本量是足够的。但是，如果我们决定在相同大小 `n = 60` 的样本上进行估计，但在比例更高的领域，例如 `p = 0.95` 呢？在这种情况下，我们会意识到 `n(1-p) = 60 * 0.05 = 3 < 10`，这意味着条件 (12.2) 未满足，这种大小样本中的比例分布无法用正态分布近似。为了在该领域满足该条件，我们需要至少 `n = 200` 的样本量。由于 `200 * 0.05 = 10`，我们恰好及格了。顺便提一下，由于这两个条件 (12.1) 和 (12.2) 的对称性，在 `p = 0.05` 代替 `p = 0.95` 的领域，同样需要最小尺寸 `n = 200`。

#### 分布的参数

让我们回到采样估计 1 比例的尝试。我们现在知道，如果样本足够大，不同样本所做的估计分布可以用正态分布近似，其均值等于如果进行此类实验时在整个总体中观察到的（理论）1 的比例。

### `n` 的影响；递减收益

请注意标准误差的值与样本量 `n` 是方向相反的。具体来说，样本越大，标准误差越低，反之亦然。因此在 `n = 50` 且 `p = 0.80` 的情况下，我们得到的 `sE = 0.06`。如果我们使用更大的样本，例如 `n = 100`，那么分布就会变得更窄，不同样本中的比例将倾向于接近 `p`。

话虽如此，我们也应该意识到增加样本量会带来收益递减。让我们用一个简单的例子来说明这一观点。上一段的计算说服了我们，当样本从 `n = 50` 增加到 `n = 100`（翻倍）时，我们成功地将 `sE` 减少了两个百分点，从 6% 降到 4%。如果我们对 `n = 1000` 进行相同的计算，得到的 `sE` 为 `0.013`，而 `n = 2000` 得到的 `sE` 为 `0.009`。换句话说，将样本量从 1000 翻倍到 2000，我们仅将 `sE` 减少了 `0.004`，即 0.4 个百分点。

### 识别感兴趣的区间

并不是所有的区间都同样重要。对于分类器评估，我们感兴趣的是那些以均值 `p` 为中心的区间。例如，工程师可能想知道在 `[p - a; p + a]` 范围内会有多少百分比的值。相反，她可能想知道包含 95% 所有值的区间（同样以 `p` 为中心）的大小有多大。

![image](img/image305.png)

严格来说，这类问题可以通过数学分析来回答。幸运的是，我们不需要自己进行数学计算，因为别人已经做过了，我们可以利用他们的发现。一些最实用的结果显示在表 12.2 中。在这里，左列列出了被称为“置信水平”的百分比；对于其中的每一个水平，右列规定了包含给定百分比数值的区间。注意，区间的长度由 `z^*` 表征，即 `p` 左右各侧的标准差倍数。因此，更正式地说，该区间定义为 `[p - z^*a; p + z^*a]`。

![image](img/image524.png)![image](img/image600.png)

以下是该表的实际用途。假设我们想知道包含 95% 数值的区间有多大。这个百分比位于第三行。我们可以看到右侧的数字是 `1.96`，这被解释为告诉我们 95% 的值位于区间 `[p - 1.96sacc; p + 1.96sacc]` 中。同样，68% 的值位于区间 `[p - a; p + a]`——这是我们从表的第一行中学到的。

让我们来看看在评估分类准确率时如何运用这些知识。假设所有测试集的大小相同为 `n`，并且假设该大小满足条件 (12.1) 和 (12.2)，这些条件允许我们使用正态分布。我们已经知道，在许多独立测试集上测量的分类准确率的平均值将收敛于理论准确率，即通过对所有可能的示例测试分类器所得到的准确率。

提醒自己正态分布假设究竟有什么用可能是一个主意。具体来说，如果分布是正态的，那么我们可以使用表 12.2，从此我们学习以 `p` 为中心包含给定百分比数值的区间大小。

## 选择置信水平

在上述讨论的示例中，请求的置信水平为 95%，这是一个相当常见的选择。如果选择另一个置信水平，将得到一个不同的置信区间。因此，对于 99%，表 12.2 给出的 `z^*` 为 `2.58`，置信区间为 `[0.85 - 0.09; 0.85 + 0.09] = [0.76; 0.94]`。注意，这个区间比 95%置信水平的区间要长。

![image](img/image112.png)![image](img/image014.png)

这是意料之中的：真实的理论分类准确率落在较长区间内的概率更高。相反，理论值落在某个较窄区间内的概率较低。因此，对于 68%的置信水平（且标准误差四舍五入后 `sacc` 为 `0.04`），置信区间为 `[0.85 - 0.04; 0.85 + 0.04] = [0.81; 0.89]`。

重要的是，我们不能忘记，即使在 99%的置信水平下，也无法绝对确定理论值一定会落在相应的区间内。仍然有 1%的概率使得测量值落在该区间之外。

### 另一个参数：样本量

读者现在已经理解了置信区间的长度取决于标准误差，而标准误差反过来取决于测试集的大小 `n`（参见等式 (12.3)）。本质上，测试集越大，支持测量值的证据就越强，因此置信区间也就越窄。这就是为什么我们说误差范围与训练集大小之间存在反比关系**：随着训练集大小的增加，误差范围随之减小。

之前，我们提到更高的置信水平会导致更长的置信区间。如果我们认为这个区间太大，可以通过更大的测试集（即更大的 `n` 值）来缩短它，这会减小测量值标准误差的数值。

如果我们想将误差范围限制在某个最大值范围内，有一种方法可以用来决定测试集应该有多大。以下是计算误差范围的公式：

```
M = z* * sacc
sacc = sqrt(p.(1-p)/n)
```

![image](img/scene_break.png) 

![image](img/image284.png)(12.6)

![image](img/image363.png)![image](img/image213.png)

通过解该方程求 `n`（针对特定的 `M`、`p` 和 `z*` 值），将得到我们所需的测试集大小。

### 结语

我们使用最简单的性能指标——分类准确率，解释了为给定置信水平建立置信区间的方法。然而，该方法的适用范围要广泛得多：任何代表比例的变量的不确定性都可以被量化。在机器学习的背景下，我们可以使用相同的方法建立对第 11 章中任何性能指标的置信度，无论是精确率、召回率还是其他数量。

![image](img/image228.png)![image](img/image059.png)

但我们必须谨慎操作以确保正确。首先，我们不能忘记，只有在满足条件 (12.1) 和 (12.2) 的情况下，给定数值的分布才能近似正态分布。其次，我们必须确保在使用等式 (12.3) 计算标准误差时理解 `n` 的含义。例如，读者记得精确率是用公式 `NTP / (TP + FP)` 计算的：即在所有被分类器标记为正例的样本中，真正例的百分比。这意味着我们处理的是大小为 `n` (`NTP + NFP`) 的样本中的真正例比例。在召回率和其他性能指标的情况下，也必须进行类似的考虑。
