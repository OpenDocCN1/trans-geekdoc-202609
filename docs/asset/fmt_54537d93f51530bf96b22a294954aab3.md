
*   **预测**，其中基于直到并包括时间瞬间 `n` 的信息，获得时刻 `n + τ, τ > 0` 的估计值。

为了使上述定义更贴合本章迄今为止所述内容，以时变情况为例，其中时间瞬间 `n` 的输出变量为 `y[n]`，其值取决于相应输入向量 `x[n]` 中包含的观测值。在滤波中，后者只能包含在时间瞬间 `n, n − 1, …, 0` 接收到的观测值。这种索引集合的限制直接与*因果性*相关。相反，在平滑中，除了过去时刻外，还包含未来时刻，即 `…, n + 2, n + 1, n, n − 1, …`。

本书的大部分精力将花在涉及时间信息时的滤波上。原因在于这是最常遇到的任务，而且用于平滑和预测的技术在本质上与滤波相似，通常只需微小修改。

在信号处理中，滤波一词通常用于更具体的语境，指*滤波器*的操作，它作用于输入随机过程/信号（`u[n]`），将其转换为另一个过程（`d[n]`）；参见第 2.4.3 节。注意，我们已切换为第 2 章引入的、用于表示随机过程的符号。我们倾向于对随机过程和随机变量保持不同的符号，因为对于随机过程，滤波任务获得了特殊的结构和性质，正如我们即将看到的。此外，尽管两种情况下涉及的方程数学表述最终可能相同，但我们认为让读者记住生成数据的底层机制是不同的，这是有益的。

## 4.7 一些典型应用

最优线性估计/滤波已应用于统计学习的广泛多样化应用中，例如回归建模、通信、控制、生物医学信号处理、地震信号处理和图像处理。在后续章节中，我们将介绍一些典型应用，以便读者掌握前面所述理论如何用于解决实际问题的主要基本原理。在所有情况下，均假设所涉及的随机过程具有宽平稳性。

### 4.7.1 干扰消除

在干扰消除中，我们可以获得两个信号的混合，表示为 `d[n] = y[n] + s[n]`。理想情况下，我们希望去除其中一个，例如 `y[n]`。我们将它们视为相应随机过程/信号的实现，即 `d[n]`、`y[n]` 和 `s[n]`。为实现这一目标，唯一可用的信息是另一个信号，例如 `u[n]`，它与不需要的信号 `y[n]` 在统计上相关。例如，`y[n]` 可能是 `u[n]` 的滤波版本。图 4.9 说明了这一点，其中展示了所涉及随机过程的相应实现。

![图 4.9 说明干扰消除任务的基本框图。](img/gr009.jpg)

图 4.9 说明干扰消除任务的基本框图。

过程 `y[n]` 是未知系统 `H` 的输出，其输入由 `u[n]` 激励。任务是通过获取其冲激响应的估计值来建模 `H`（假设它是已知阶数的线性时不变系统）。然后，当模型由相同的输入 `u[n]` 激励时，模型的输出将是 `y[n]` 的一个近似。我们将使用 `d[n]` 作为目标/期望响应过程。假设未知系统 `H` 的阶数为 `l`，则 `w[0], …, w[l−1]` 的最优估计由正规方程给出：

```
Σ[u] w[*] = p.
```

然而，

```
p = E [u[n] d[n]] = E [u[n] (y[n] + s[n])] = E [u[n] y[n]],
```

因为相应的输入向量 `u[n]` 和 `s[n]` 被认为在统计上是独立的。也就是说，问题的上述表述导致了与期望响应为信号 `y[n]`（即我们想要消除的信号！）时相同的正规方程。因此，我们模型的输出将是 `y[n]` 的一个近似值（在均方误差意义上），记为 `ŷ[n]`，如果从 `d[n]` 中减去它，所得到的（误差）信号 `e[n]` 将是 `s[n]` 的一个近似。该近似的优劣取决于 `l` 是否是 `H` 的真实阶数的一个良好“估计”。方程 (4.54) 右侧的互相关可以通过计算相应的样本均值来近似，特别是在 `s[n]` 缺失的时段内。在实际系统中，通常采用这种实现的在线/自适应版本，正如我们将在第 5 章中看到的那样。

干扰消除方案已广泛应用于许多系统，如噪声消除、电话网络中的回声消除和视频会议，以及生物医学应用，例如为了消除胎儿心电图中的母体干扰。

### 4.7.2 系统辨识

系统辨识在本质上类似于干扰消除任务。请注意，在图 4.9 中，基本上是对未知系统进行建模。然而，那里的重点在于复现输出 `y[n]`，而非系统的冲激响应。

在系统辨识中，目标是对未知被控对象的冲激响应进行建模。为此，我们可以获取其输入信号以及其输出的*含噪*版本。任务是设计一个模型，使其冲激响应逼近未知被控对象的冲激响应。为实现这一点，我们对一个线性滤波器进行最优设计，该滤波器的输入与激励被控对象的信号相同，其期望响应为被控对象的含噪输出（参见图 4.11）。相关的正规方程为

```
Σ[u] w[*] = E[u[n] d[n]] = E[u[n] y[n]] + 0,
```

假设噪声 `η[n]` 与 `u[n]` 统计独立。因此，再一次，所得的正规方程就如同我们向模型提供了一个等于未知被控对象无噪输出的期望响应，即表示为 `d[n] = y[n]`。因此，模型的冲激响应被估计为使其输出在均方误差（MSE）意义上接近未知被控对象的真实（无噪）输出。系统辨识在许多应用中具有重大意义。在控制领域，它用于驱动相关的控制器。在数据通信中，它用于估计传输信道，以构建所传输数据的最大似然估计器。在许多实际系统中，都实现了系统辨识方案的在线版本，我们将在后续章节中讨论。

![图 4.11 在系统辨识中，模型的冲激响应被最优估计，使得输出在均方误差（MSE）意义上接近未知被控对象的输出。红线表示误差被用于滤波器未知参数的最优估计。](img/gr011.jpg)

### 4.7.3 去卷积：信道均衡

注意：在取消任务中，目标是从未知系统 `H` 中“移除”（过滤后的）输入信号 `u[n]`。在系统辨识中，重点在于（未知的）系统本身。在**去卷积**中，重点在于未知系统的输入。也就是说，我们现在的目标是以 MSE 最优意义恢复一个（延迟的）输入信号 `d[n] = s[n - L]`，其中 `L` 是以采样周期 `T` 为单位的延迟。该任务也称为**反系统辨识**。术语**均衡**或**信道均衡**用于通信领域。去卷积任务是在图像去模糊的背景下在第 4.6 节中引入的。在那里，关于*未知*输入过程的所需信息是通过近似获得的。在当前框架中，这可以通过发送训练序列来实现。
