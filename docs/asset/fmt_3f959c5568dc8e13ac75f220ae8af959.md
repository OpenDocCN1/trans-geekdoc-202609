# 157. Bash 脚本逻辑修正

一名渗透测试人员正在分析一个脚本，以确定为什么该脚本没有返回预期的正确结果。预期结果应为 `True`。

```
root:~# cat ./myscript.sh
#!/bin/bash
source=10
let dest=5+5
if [ 'source' = 'dest' ]; then
   echo "True"
else
   echo "False"
fi
#End of File
root:~# ./myscript.sh
False
```

通过审查脚本，测试人员如何纠正错误以返回正确结果？（选择两项。）

1.  将 `fi'` 改为 `'Endlf`
2.  移除 `dest=5+5` 前面的 `let`
3.  将 `\=` 改为 `\-eq`
4.  将 `\='source'\*` 和 `'dest'` 改为 `"$source"` 和 `"$dest"`
5.  将 `'else'` 改为 `'elif`
