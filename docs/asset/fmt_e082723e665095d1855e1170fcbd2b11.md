
`pose` 矩阵左上角的 3×3 子矩阵等于新的旋转矩阵 `R`。从 `pose` 最后一列顶部的 3×1 子矩阵，我们得到一条射线原点，即相机旋转后的世界坐标，其中 `r` 是两个坐标系之间的距离。我们使用 `pose` 矩阵将 `X⃗[c]` 转换为 `X⃗[w]` 以供查询点使用。在模型训练期间，所有查询点和射线原点都通过第 04 个单元格中最后一个函数定义的函数进行位置编码。超参数 `L` 是编码函数的数量。查询点和射线原点的 `L` 值分别设置为 6 和 4。在下面的方程中，`q` 是一批查询点，批量大小为 `B`，其中 `L` = 6 为编码函数的数量。`q` 的坐标乘以 2π2⁰ 后，sin 函数对其逐元素作用，cos 函数也对其逐元素作用。这两个三角函数的运算结果被追加到 `q` 后面，构建一个包含九个元素的列表：[`q`，sin(2π2⁰`q`)，cos(2π2⁰`q`)]，频率为 2⁰。

```
sin(2π2ⁱq) = sin(2π2ⁱ [ q_x1 q_y1 q_z1; q_x2 q_y2 q_z2; ...; q_xB q_yB q_zB ]) i ∈ [0, (L - 1)]
```

`q` 的位置编码结果列表被拼接以获得形状为 `B`×(3+3×2×`L`) 的张量，作为第 05 个单元格中定义的 MLP 模型的两个输入之一。有了上述背景信息，应该很容易理解附录 K 中列出的 tiny NeRF 项目代码。我的代码受 [Bmild](https://github.com/bmild/nerf/blob/master/tiny_nerf.ipynb) 启发。模型训练时间约为 125 分钟（每条射线 128 个查询点），PSNR 值约为 28.5。训练好的 MLP 模型随后由第 13 个单元格中的代码保存。保存的模型文件大小为 301 kB。运行第 14 个单元格中的代码，我们可以加载保存的模型，在距离 `r` 约为 4 处的任意 `θ` 和 `φ` 角度合成一张乐高图像。图 12.7 中右侧显示的图像是以下代码的输出。您可以更改以下函数第一行中 theta、phi 和 `r` 的值，以查看不同的合成图像。为了提高合成图像的质量，我们需要增加每条射线上的采样点，但我们会面临 GPU 显存限制和模型训练时间的问题。现在有许多新的 NeRF 算法使我们能够实时重建照片级真实感视频。计算机视觉的发展非常迅速。当您阅读本书时，书中的一些技术可能已经过时了。

### 12.3 通过 2D 高斯泼溅介绍 3D 高斯泼溅

# 3D Gaussian Splatting 模型训练

3D Gaussian splatting 的模型训练非常简单。事实上，这种新技术并不涉及神经网络模型。我们只需要训练一个包含许多参数的拟合函数，这些参数会在模型训练过程中更新。

你可以使用手机或无人机拍摄某物周围的照片（如雕塑、埃及金字塔、埃菲尔铁塔，甚至温哥华市中心的建筑），以此开始你的 3D Gaussian splatting 项目。随后，你可以使用 [Colmap](https://colmap.github.io/) 或其他免费软件，从照片中获取物体表面 3D 点的点云文件。

3D Gaussian splatting 项目的代码会将这些点初始化为 3D Gaussian 橄榄球。在模型训练期间，根据方程（12.5），数百万个橄榄球会被投影到某个相机位置的共轭平面上。这个过程称为“光栅化”（rasterization）。GPU 会对所有橄榄球到共轭平面的距离进行排序。共轭平面上每个 16x16 像素的“瓦片”（tile）作为一个批次，供 GPU 计算该瓦片上的预测图像。相机在该位置拍摄的图像被用作真值（ground truth）。L1 损失函数和结构相似性指数（SSIM）损失函数用于计算预测图像与真值之间的差异。

在模型训练期间，每个橄榄球的位置、大小、方向、颜色和不透明度将根据损失函数对部分橄榄球参数的梯度进行更新。如果某个橄榄球的不透明度足够低（或透明度足够高），该橄榄球将被删除；如果损失函数对某橄榄球位置坐标的梯度范数足够大，该橄榄球将被克隆，且在克隆出的橄榄球尺寸足够大时，这两个相同橄榄球的尺寸将被缩小。此过程将针对所有真值图像重复，以调整每个橄榄球的位置、大小、方向、颜色和不透明度。最终，我们可以在物体周围的任意视角看到逼真的预测图像。

唯一的问题是，模型训练需要海量的 GPU 内存，以使用数百万个 3D Gaussian 重建逼真的 3D 场景。我的 RTX 2060 GPU（6 GB 显存）在项目 12.3.1 中只能处理 3536 个 2D Gaussian。在撰写本章时，[LUMA](https://lumalabs.ai/interactive-scenes) AI 提供免费网络服务，用户可上传照片并下载由其照片训练的 3D Gaussian splatting 模型。我只能用一个 2D Gaussian splatting 项目来演示这项新技术的概念。我的代码受 [OutofAi](https://github.com/OutofAi/2D-Gaussian-Splatting/blob/main/2D_Gaussian_Splatting.ipynb) 启发。

图 12.8A 中的真值图像经项目 12.3.1 代码处理，获得了包含 3536 个 2D Gaussian 的合成图像。我花费约 1.5 小时获得了足够好的输出，结构相似性指数（SSIM）达到 0.882。SSIM 最早由 IEEE 论文（Wang *et al* 2004）于 2004 年提出。它优于上一节使用的 PSNR，因为其取值范围在 \[0,1\] 之间。

`Cell 02` 中定义的 SSIM 损失函数基于 [kornia](https://kornia.readthedocs.io/en/latest/losses.html) 库中一个类的实例。该损失函数的值等于 `(1-SSIM)/2`。若预测图像与其真值完全匹配，则 SSIM = 1 且 loss = 0。SSIM 损失的最大值为 0.5。

# Cell 05 中的模型训练代码

`Cell 05` 中的代码用于模型训练。在前 2000 个 epoch 中，模型训练速度约为每 epoch 1.5 秒。随着越来越多的高斯球被优化以合成图像，速度会变得非常慢。程序会因“内存不足”问题而中断。或者，如果你发现程序运行非常缓慢，可以随时中断程序。

## 检查点机制

如果输出中的高斯球数量超过 1000 个，`Cell 05` 中的代码会每 100 个 epoch 为我们保存一个检查点。通过将 `Cell 02` 第 25 行末尾的三个单引号移动到第 11 行前面，我们可以从之前的检查点继续训练模型，再训练 1000 个 epoch。当我们第一次使用检查点时，需要将 `Cell 01` 中的 `densification interval`（稠密化间隔）参数改为 100。使用检查点可以加快模型训练速度。

## 3D 高斯泼溅技术的进展

虽然 3D 高斯泼溅技术仍处于起步阶段，但其在计算机视觉 3D 图形领域的前景是毋庸置疑的。原始的 3D 高斯泼溅只能处理静态 3D 场景。高斯泼溅技术推出三个月后，已有七篇[论文](https://github.com/MrNeRF/awesome-3D-gaussian-splatting#dynamics-and-deformation)发表，提出了用于可动画化（Luiten *et al* 2023，Li *et al* 2023）3D 高斯泼溅的智能算法。

## SuGaR 方法

**SuGaR**（Guédon 和 Lepetit 2023）是一种用于从 3D 高斯泼溅表示中进行高效 3D 网格重建和高质量网格渲染的新方法。SuGaR 通过操作网格而非高斯球本身，使得使用传统软件能够轻松地对高斯球进行编辑、雕刻、绑定、动画制作、合成和重新打光。使用 SuGaR 获取此类可编辑网格以进行逼真渲染只需几分钟，同时还能提供更好的渲染质量。
