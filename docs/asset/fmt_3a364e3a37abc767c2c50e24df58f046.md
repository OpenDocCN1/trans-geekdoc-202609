## 指数分布

指数分布是另一种常用的连续分布。它常用于表示事件之间经过的时间。

服从指数分布的连续随机变量 X 的密度函数记为 `X ~ Exp(λ)`，λ > 0，定义如下：

```
f(x) = λe^(-λx) for x ≥ 0
```

**示例**：机票通常提前预订，一般来说，我们提前预订机票的天数取决于诸如行程是否有计划、是否为假期、价格是否会飙升等因素。观察发现，旅客提前购买机票的天数服从指数分布，平均为 15 天。

## 随机变量的数学期望

随机变量 X 的概率分布告诉我们 X 取特定值或落在特定区间的可能性。在实践中，更易于解释的信息是随机变量取值的平均值。例如，一家公司可能对其即将推出的新产品的平均利润感兴趣；儿科医生可能对 5 岁儿童的平均身高和平均体重感兴趣。随机变量的平均值也称为随机变量的**数学期望**，记为 `E[X]`。

离散随机变量的期望值是所有可能值的加权平均，由下式给出：

```
E[X] = Σ x * P(X = x)
```

对于连续随机变量，我们必须用积分代替求和，得到定义：

```
E[X] = ∫ x * f(x) dx
```

**示例**：设 X 表示一个人在高层建筑中等待电梯的时间（分钟）。这里，X 是一个连续随机变量，具有以下分布：

```
f(x) = x * e^(-x) for x ≥ 0
```

X 的期望值由下式给出：

```
E[X] = ∫ x * f(x) dx = 1
```

因此，该建筑中等待电梯的期望时间为 1 分钟。读者可以绘制该密度函数，观察到在这种情况下最大密度也在 `x = 1` 处。

我们可以计算前面讨论的已知概率分布的随机变量的期望。这在下表中展示：

| **分布(X)** | **均值或 E[X]** | **方差 E[(X – E[X])²]** |
| --- | --- | --- |
| `X ~ Bernoulli(p)` | `p` | `p(1 – p)` |
| `X ~ Binomial(n;p)` | `np` | `np(1 – p)` |
| `X ~ Poisson(λ)` | `λ` | `λ` |
| `X ~ N(μ, σ²)` | `μ` | `σ²` |
| `X ~ Exponential(λ)` | `1/λ` | `1/λ²` |
| `X ~ Uniform(a,b)` | `1/2(a + b)` | `1/12(b – a)²` |

**表 4.3：** *几种常用分布的均值和方差*

我们也可以定义随机变量函数 `g(X)` 的期望值，如下所示：

```
E[g(X)] = Σ g(x) * P(X = x)  (离散)
E[g(X)] = ∫ g(x) * f(x) dx   (连续)
```

对于 `g(X) = (X - μ)^r`，`g(X)` 的期望称为 X 关于均值的 r 阶矩。特别地，如果 `r = 2`，则 `g(X)` 的期望称为随机变量的**方差**，常记为 `σ²`。

```
Var(X) = E[(X - μ)²] = E[X²] - (E[X])²
```

以下是期望的几个性质：

*   **期望是线性算子。** 因此，随机变量线性组合的期望由下式给出：
    *   `E[X + Y] = E[X] + E[Y]`
    *   `E[aX] = aE[X]` 对任意常数 a 成立。
*   **相互独立随机变量乘积的期望**如下：
    *   `E[XY] = E[X]E[Y]`
    *   `E[g(X)h(Y)] = E[g(X)]E[h(Y)]`
