## 理解特征工程

将特征工程视为一种协助机器学习模型像您自己一样理解数据集的方式。正如艺术家雕去大理石块中不必要的部分以呈现杰作，特征工程仔细选择、改变并创建数据的新侧面，以揭示其隐藏的模式。

特征工程旨在调整和改进模型中的预测变量，以便模型能更好地发现预测变量与响应变量之间有意义的关系。“工程”一词暗示了一种有目的地修复性能问题和改进预测的方法。知道在模型中表示特征有不同的方式，并意识到某些方式比其他方式效果更好，这是特征工程的核心。因此，特征工程成为制作优化模型有效性的数据表示的实践。它承认我们向模型呈现数据的方式会显著影响其预测能力。重要的是要注意，多种因素共同影响模型的有效性。例如，如果一个预测变量与响应变量缺乏有意义的关系，那么该预测变量的表示方式就变得无关紧要。

特征工程可能会带来一些挑战，因为它依赖于数据分析技能、领域专业知识和一定程度的直觉的结合。特征创建中常见的陷阱是倾向于直接使用现成的数据，而不咨询相关专家、进行彻底研究或进行探索性思考。忽视这些关键步骤，可能会导致忽略本可显著影响模型性能的重要预测变量。

在深入进行特征转换之前，彻底探索和清理数据集至关重要。这一初始步骤包括：

*   检查数据：检查几行数据以了解其结构、内容和潜在问题。
*   检查基本统计量：计算描述性统计量（例如均值、中位数、标准差）以识别异常并发现初步模式。
*   可视化数据：创建散点图、直方图和其他可视化图表，以识别从数值摘要中可能不明显的模式和异常。可视化应贯穿转换过程始终，用于评估变更的影响并验证假设。

众所周知的谚语“垃圾进，垃圾出”在机器学习中同样适用。这意味着生成模型的质量在很大程度上取决于输入数据。想象一下你在建造一座城堡。坚固、放置得当的砖块使施工过程顺利，最终城堡坚固耐用。但如果你使用歪斜、形状不规则的砖块，你将需要更复杂、更精巧的设计才能达到同样的稳定性。同样，在机器学习中，特征的质量直接影响你构建的模型。好的特征，如信息丰富且相关的数据，使训练模型更容易，并产生更准确、更高效的模型。相反，差的特征需要复杂的模型，且往往表现不佳。

在为机器学习模型准备数据时，我们经常对其进行转换，使其更兼容、更有信息量。这个过程称为数据转换，是特征工程的关键部分。以下是转换特征的主要原因：

## 转换数值数据

假设我们要预测客户是否会点击网站上展示的特定广告。两个关键特征可能是：

*   **广告展示次数**：范围可能从 1 到 1000，数字越大表示曝光越多。
*   **用户上次点击广告以来的时间**：数值可能从几分钟到几个月不等，时间越短表示兴趣越高。

原始数字固然好，但它们并不能讲完整的故事。对机器学习算法而言，这些只是两列数字。以下是转换它们如何释放隐藏洞察的方法：

*   **展示次数对数缩放**：用户看到广告 10 次与 1000 次的差异，远大于 500 次与 600 次的差异。对数缩放压缩了展示次数的大范围，使较小的变化对模型更具影响力。
*   **上次点击时间分箱**：将时间分组为“一天内”、“1-3 天”和“一周以上”等桶，可捕捉用户兴趣随时间的变化。这有助于模型理解近期点击比久远点击更相关。

转换数值变量不仅仅是操纵数字；而是利用我们对问题和数据的理解，以一种对模型有意义的方式呈现它们。这就像说算法的语言，让它们通过我们的眼睛看世界并做出更好的预测。

转换数值数据没有放之四海而皆准的方法。最佳技术取决于您的特定数据集和模型需求。实验、探索，并不断自问：我如何引导这些数字揭示我数据中的真实故事？

**特征缩放**确保每个特征都对模型的学习过程有意义地贡献，无论其原始尺度如何，从而更准确地表征潜在数据模式。

### Min-max 缩放

**Min-max 缩放（归一化）**将特征转换到标准范围，通常在 0 和 1 之间。Min-max 缩放通过从每个数据点减去特征的最小值，然后除以最大值和最小值的差值来工作。数学上可表示为：

```
x' = (x - xmin) / (xmax - xmin)
```

其中 `x'` 是缩放后的值，`x` 是原始值，`xmin` 代表特征的最小值，`xmax` 代表特征的最大值。

当特征分布大致均匀且数据中不存在显著异常值时，这种缩放方法效果特别好。极端值会显著拉伸缩放范围，将大多数数据点压缩到一个狭窄区域。如果特征分布偏态或有长尾，min-max 缩放可能不是最佳选择。

让我们定义一个名为 `min_max_scaling` 的函数，它接受一个数据向量作为输入并返回数据的缩放版本。然后，我们通过对温度值应用 min-max 缩放来创建一个新列 `Temperature_Scaled`，将其转换为 0 到 1 之间的标准化尺度。

```r
# Min-Max scaling function
min_max_scaling <- function(x) {
  (x - min(x)) / (max(x) - min(x))
}

# Apply Min-Max scaling to the Temperature column
forest_fires$Temperature_Scaled <- min_max_scaling(forest_fires$Temperature)

# Distribution of the Scaled Temperature

```

### 分箱

数值数据分箱是指将连续变量转换为离散的类别或区间，从而将其从定量属性变为定性属性。此过程可以识别线性模型可能遗漏的特征与目标变量之间潜在的非线性关系。此外，分类特征比数值特征更易于解释和说明。然而，分箱固有地涉及粒度的损失。请仔细权衡细节与泛化之间的取舍。分箱过少会过度简化模式；分箱过多会使分析复杂化并降低模型的泛化能力。您可以尝试不同的分箱大小并可视化结果，以确保分割的意义性。

当选择对数值特征应用分箱时，必须明确定义边界设置并确定分箱类型。两种常见的分箱方法包括：

*   等宽分箱
*   分位数分箱

#### 等宽分箱

等宽分箱是一种简单直接的分箱技术，它将数值特征的范围划分为宽度相等的箱。它通常是一种简单直观的方法，但也必须考虑其对不同数据分布的适用性。等宽分箱可能对异常值敏感，因为极端值会不成比例地影响分箱边界。现在，我们将把连续的温度值分为四个箱。

```r
# 定义分箱数量
num_bins <- 4

# 为温度数据创建分箱
forest_fires$temp_bins <- cut(forest_fires$Temperature, breaks = num_bins, labels = FALSE)

# 将 temp_bins 转换为因子
forest_fires$temp_bins <- as.factor(forest_fires$temp_bins)
```

此处，`cut()` 函数根据先前定义的 `num_bins` 为 'Temperature' 特征创建分箱。在函数调用中，`breaks=num_bins` 表示沿温度轴所需的分割数量。`labels=FALSE` 意味着生成的水平接收默认的整数分配（1, 2, ..., n_bins）。`temp_bins` 列中的值被转换为因子。

```r
# 带分箱线的温度分布
ggplot(forest_fires, aes(x = Temperature, fill = temp_bins)) +
  geom_histogram(binwidth = 1, color = "black", boundary = 0) +
  geom_vline(xintercept = seq(min(forest_fires$Temperature), max(forest_fires$Temperature), length.out = num_bins + 1),
             linetype = "dashed", color = "darkred", linewidth = 0.8) +
  scale_fill_brewer(palette = "Set2") +
  labs(x = "Temperature",
       y = "Frequency",
       fill = "Temperature Bins") +
  theme_bw()
```

#### 分位数分箱

虽然等宽分箱将特征范围划分为大小均匀的区间，但分位数分箱采取了不同的方法，确保每个箱包含大致相同数量的观测值。这使其特别适合处理偏态或分布不规则的数据。它处理范围内密度变化的数据，确保每个箱具有相似的重要性。下面的代码对 Temperature 列执行分位数分箱。

```r
# 对 Temperature 列执行分位数分箱
forest_fires$temperature_quantile_bins <- cut(forest_fires$Temperature,
                                              breaks = quantile(forest_fires$Temperature),
                                              labels = FALSE,
                                              include.lowest = TRUE)

# 将分位数分箱转换为因子
forest_fires$temperature_quantile_bins <- as.factor(forest_fires$temperature_quantile_bins)
```

此处，通过设置 `breaks=quantile(forest_fires$Temperature)`，我们确保每个类别中包含相同数量的样本。下图显示了分位数分箱下的温度分布。
