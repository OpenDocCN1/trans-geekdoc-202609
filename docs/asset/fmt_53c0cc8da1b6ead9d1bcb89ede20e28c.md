
如果两个最近邻居是正类而其余三个是负类，那么 `x` 被归类为正类，因为 `†^C = 1 + 5 > †^(\-) = 4 + 3`。

## 3.6 移除危险示例

对于分类过程而言，每个训练示例的值可能不同。有些是其所代表类别的典型，有些则不然，而另一些完全具有误导性。这就是为什么在训练集上训练之前对其进行预处理通常是一件好事：移除被怀疑用处较小的示例。

预处理训练集的具体方法由图 3.7 所示的两个基本观察指导。首先，一个标记为某一类但被另一类示例包围的示例可能是类别标签噪声的结果。其次，来自两类边界区域的示例是不可靠的，因为其属性值中微小的噪声就会导致其位置发生错误偏移，从而影响分类。在这两种情况下，这些示例最好被移除。

### Tomek Links（Tomek 连接）技术

然而，在移除罪魁祸首之前，必须先检测到它。一种方法是使用 Tomek Links 技术，该技术以几十年前首次使用它的数学家名字命名。如果一对示例 `x` 和 `y` 同时满足以下三个要求，则认为形成了一个 Tomek Link：

1. `x` 是 `y` 的最近邻居
2. `y` 是 `x` 的最近邻居
3. `x` 的类别与 `y` 的类别不同。

由于这些条件是边界示例以及被另一类包围的示例的特征，因此从训练集中移除所有此类对是有意义的。但这可能还不够。有时，移除现有的 Tomek Links 只产生新的链接，因此必须重复该过程。

该算法由表 3.5 中的伪代码总结，图 3.8 显示了几个 Tomek Link 的实例。请注意，这里只有这三个；没有其他示例对符合被称为 Tomek Link 的标准。

有一个值得提到的副作用：一旦训练集被清理，就可以减少投票邻居的数量（`k`），因为使用 `k > 1` 的主要原因是减轻噪声的负面影响——而移除 Tomek Links 减少了这种影响。甚至可能 `1-NN` 分类器现在达到使用整个训练集的 `k-NN` 分类器的性能。

### 局限性

没有完美。Tomek Links 技术无法识别所有误导性示例；相反，某些被移除的示例可能是“无辜”的，因此本应该保留。尽管如此，经验表明移除 Tomek Links 通常会提高数据的整体质量。

# 3.7 移除冗余示例

![image](img/chapter_title_below.png)

某些训练示例对分类性能产生负面影响，但我们仍然想摆脱它们。问题是，它们也没有降低错误率；只会增加计算成本。

![image](img/image412.png)![image](img/image078.png)冗余示例 在一个具有 `10⁶` 个训练示例并由 `10⁴` 个属性描述的领域中寻找最近邻（这种领域并不罕见），依赖 `Euclidean` 距离的程序必须执行 `10⁶` × `10⁴` = `10¹⁰` 次算术运算。当任务是一次分类数千个对象时（这同样并非不可能），算术运算的数量是 `10¹⁰` × `10³` = `10¹³`。这是一个巨大的数字。

幸运的是，训练集通常是冗余的，从某种意义上说，即使删除某些训练示例，`k-NN` 分类器的行为也不会改变。有时，大部分示例可以被无忧地移除，因为它们只增加了分类成本，而不影响分类性能。图 3.9 左上角所示领域就是这种情况。

![image](img/image102.png)![image](img/image306.png)一致子集 为了减少冗余，我们想用其一致子集 `S` 替换训练集 `T`。在我们的上下文中，如果用 `S` 替换 `T` 不影响 `k-NN` 分类器返回的类别标签，则称 `S` 是 `T` 的一致子集。然而，这种定义并不实用，因为我们不知道 `k-NN` 分类器在未来的示例上如何使用 `T` 或 `S`。因此，让我们修改标准：如果用 `S` 替换 `T` 不影响 `k-NN` 分类器返回的类别标签，则 `S` 被视为 `T` 的一致子集。

# 3.8 总结与备注

![image](img/chapter_title_below.png)

- 在分类对象 `x` 时，`k-NN` 分类器在训练集中找到与 `x` 最相似的 `k` 个示例，然后选择这些示例中最常见的类别标签。
- `k-NN` 分类器的行为很大程度上取决于如何计算向量之间的相似性。建立向量 `x` 和 `y` 之间相似性的简单方法可能是使用通过公式得到的几何距离：

![image](img/image457.png)![image](img/image135.png)d(x; y) = q†^n

![image](img/scene_break.png)

d(xi; yi) (3.5)

本质上，对于连续属性我们使用 `d(xi; yi) = (xi - yi)²`，对于离散属性，如果 `xi = yi` 则令 `d(xi; yi) = 0`，如果 `xi ≠ yi` 则令 `d(xi; yi) = 1`。

- 如果描述示例的许多属性是无关的，`k-NN` 分类器的性能就会很差。另一个问题是属性值的缩放，后者可以通过将属性值归一化到单位区间来缓解。
- 某些示例是有害的，因为它们出现在训练集中会增加错误率。另一些示例是冗余的，它们只会增加计算成本而不提高分类性能。应该移除有害和冗余示例。
- 在某些应用中，每个最近邻都有相同的票数。在其他应用中，票数会根据示例到分类对象的距离进行加权。

### 历史说明

最近邻分类器的想法最初由 Fix 和 Hodges [27] 提出，但首次系统分析是由 Cover 和 Hart [20] 以及 Cover [19] 提供的。随后，Dasarathy 的著作 [21] 进行了详尽的处理。这里描述的加权 `k-NN` 分类器由 Dudani [23] 提出。寻找训练集一致子集的最早技术由 Hart [35] 描述——本章介绍的是其微调版本。Tomek Links（Tk 连接）的概念源于 Tomek [89]。

# 第 4 章：类间边界：线性与多项式分类器

用 n 维实例空间中的点来表示训练示例时，我们可能会发现正示例倾向于聚集在与负示例占据的不同的区域。这一观察激发了另一种分类方法。与其早期范式使用的概率和相似性，我们不如尝试识别划分两个类的决策面。一种非常简单的方法是使用线性函数。更灵活的是高阶多项式，它们能够定义复杂的类间边界。然而，必须谨慎处理这些。

本章介绍了从布尔属性示例推导线性分类器的两种简单机制，然后讨论了如何将其应用于更通用的领域，例如具有数值属性和多个类别的领域。整个思想随后扩展到多项式分类器。

## 4.1 核心

首先，让我们限制在属性为真或假的布尔领域。为了让这些属性参与代数运算，我们将用整数表示它们：真为 1，假为 0。

### 线性分类器

在图 4.1 中，一个示例标记为正类，其余三个标记为负类。在特定情况下，这两个类可以通过以下方程定义的线性函数进行分离：

```
-1.2 + 0.5x1 + x2 = 0 (4.1)
```
