# 2. 特征子集选择

特征变换将数据转换为新的特征，这些特征可以表示底层的机器学习问题。

特征变换有两种变体：

1. 特征构建
2. 特征提取

特征构建过程发现特征之间关系的缺失信息，并通过创建额外的特征来扩展特征空间。

特征提取是指使用某些函数映射，从原始特征集中提取或创建一组新特征的过程。

机器学习中常用的一些流行的特征提取算法有：

1. 主成分分析 (`PCA`)
2. 奇异值分解 (`SVD`)
3. 线性判别分析 (`LDA`)

特征子集选择旨在从完整的特征集中衍生出一个特征子集。它不会生成新特征。

特征选择的目标有三个方面：

1. 获得更快且更具成本效益（即对计算资源的需求更少）的学习模型
2. 提高学习模型的效率
3. 更好地理解生成数据的底层模型

特征选择旨在移除所有无关的特征，并从潜在冗余的特征中选取具有代表性的子集。这在特定的学习任务背景下产生了有意义的特征子集。

特征相关性通过根据相对熵测量的特征信息增益来指示。

特征冗余性基于多个特征贡献的相似信息，通过特征与特征之间进行衡量：

1. 相关性
2. 距离（闵可夫斯距离，例如曼哈顿距离、欧几里得距离等是最常用的测量）
3. 其他基于系数的方法 (`Jaccard`、`SMC`、`余弦相似度` 等)

特征选择的主要方法有：

1. 过滤 (Filter)
2. 包装 (Wrapper)
3. 混合 (Hybrid)
4. 嵌入 (Embedded)

## 5.2 统计工具在机器学习中的重要性

在机器学习中，我们通过使用名为“训练数据”的限制数据集训练系统，并根据训练数据的置信水平，我们期望机器学习算法能够描述更大量的实际数据集的行为。如果我们对一组事件的子集（称为“样本”）进行观测，那么在将样本结果归于整个集合或总体时，将会存在某些不确定性。因此，问题在于如何利用对样本集的有限知识来以某种置信度预测真实集合的行为。数学家们意识到，即使某些知识是基于样本的，只要我们知道与之相关的不确定性程度，就可以以优化的方式使用，而不会导致知识的丢失。参考图 5.1

**图 5.1** 知识与不确定性

概率论为量化这种知识的不确定性提供了数学基础。由于关于训练数据的知识是以 `interdependent` 特征集的形式出现，在本章稍后讨论的条件概率理论（特别是 `Bayes theorem`）构成了推导训练数据所需置信水平的基础。

## 5.3 概率的概念 —— 频率主义和贝叶斯解释

概率的概念并不新奇。在日常生活中，我们在许多地方都使用概率的概念。例如，当我们谈论投掷硬币时得到正面和反面的概率相等时，我们实际上是想说如果投掷硬币很多次，硬币落在正面的次数将与落在反面的次数相同。这是概率的 `frequentist` 解释。这种解释代表了事件的长期频率。概率的另一个重要解释试图量化某些事件的不确定性，因此关注的是信息而非重复试验。这被称为概率的 `Bayesian` 解释。以同样的投掷硬币例子为例，其解释为——当我们下次投掷硬币时，硬币落在正面或反面的概率是相等的。

贝叶斯解释之所以能够对事件的不确定性建模，是因为并不预期事件的长期频率发生。例如，如果我们必须计算巴西赢得 2018 年足球世界杯决赛的概率，该事件只能发生一次，不能通过反复重复来计算其概率。尽管如此，我们应该能够量化关于该事件的不确定性，而只有当我们以贝叶斯的方式解释概率时这才是可能的。给出更多面向机器学习的例子，我们正在为一个大客户启动一个新的软件实施项目，并根据过去类似项目的数据计算该项目进入客户升级流程的概率；或者我们想根据相似特征患者中此类病例的概率分布，计算肿瘤为良性或恶性的概率。在所有这些情况下，都不可能对事件进行重复试验，而贝叶斯概念对于计算不确定性是有效的。因此，在本书中，我们将关注贝叶斯解释，以开发我们的机器学习模型。无论我们采用何种解释，概率的基本公式始终保持不变。

让我们来看一个例子，根据发件人姓名识别邮件是否为垃圾邮件的概率。我们经常收到包含 `bulk`、`mass` 等词汇的邮件，因此我们希望机器学习代理为我们标记这些垃圾邮件以便于删除。

同样，假设发件人名称为 `mass` 或 `bulk` 的邮件是垃圾邮件的可靠性概率为 80%，误报率为 10%，即即使邮件不是垃圾邮件，代理也会将其标记为垃圾。此外，我们知道只有 0.4% 的总邮件是垃圾邮件。

**解：** 令 `x` 为当发件人名称为 `mass` 或 `bulk` 时标记为垃圾邮件的事件，`y` 为某些邮件确实是垃圾邮件的事件。所以，`p(x=1|y=1) = 0.8` 是标记为垃圾的概率。
