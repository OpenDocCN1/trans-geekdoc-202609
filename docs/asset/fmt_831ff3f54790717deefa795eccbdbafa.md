
# 多信号分类（`MUSIC`）方法

多信号分类（`MUSIC`）方法 [42] 取决于基于子空间的方法，用于引入的射频系统帮助确定呼吸频率。该研究的作者使用红外视觉传感器监测呼吸。许多研究人员创建了与呼吸监测类似的睡眠监测方法。为了追踪呼吸率，他们追踪了胸部和腹部肌肉的活动，并对鼻部区域进行红外扫描。后续研究论文涵盖了创建和部署一种适应、可扩展且廉价的无线传感器医疗系统，用于远程监测多个关键生理参数。

# 脑电图（EEG）监测

脑电图（EEG）监测 [43] 可以通过无线 EEG 设备在临床环境之外进行，这允许患者不受限制地进行正常生活。然而，使用此类设备收集、加密并将 EEG 数据传输到后端会消耗大量能量。目前，EEG 有多种患者监测模型。

# 基于面部的分析

基于面部的分析已用于疼痛检测和抑郁监测。这项工作 [44,45,46] 使用基于特征的方法，利用面部表情进行疼痛检测。使用 `Prkachin` 和 `Solomon` 疼痛强度指标来评估不同程度的疼痛强度，以便识别和研究疼痛。除了闭上眼睛外，该矩阵还考虑了许多与面部表情相关的方面，如抬眉、压眉和紧绷肌肉。研究人员始终关注每一个患者，正如前所述，所有系统和程序中都创建了各种医疗系统以高效地监控患者的健康。为了读取和记录各种指标，这些建立的系统需要在人的床上或身体上安装传感器或设备，这成本很高，且患者并不喜欢。很少有科学家实验过基于视觉的技术；相反，他们大多使用红外或深度摄像头来跟踪呼吸、识别跌倒和跟踪睡眠 [47,48,49]。也创建了基于面部表情的系统；然而，该系统需要一个睁着眼睛的摄像头。研究人员使用运动和姿态数据，来确定睡眠状态和身体部位的关键点。

图像区域填充有边界框，我们需要从中选择正确的边界框进行患者器官监测。从患者图像中使用带有置信度评分的非极大抑制技术（`NMS`）选择正确的边界框是最佳选择。该技术根据交并比（`IoU`）的比较为每个边界框产生置信度评分，为大多数器官产生各种分辨率的边界框。`AX-YOLO V5` 可以并行处理不同尺寸的边界框并从图像中提取特征。由于这种并发过程，在有效检测边界框时可能会发生一些损失。通过以下公式评估损失函数：

```
B(l)  =  B(l)[cl]  +  B(l)[r]  +  B(l)[m] (7.1)
```

在公式 7.1 中，`B(l)` 代表从边界框评估的损失函数，`B(l)[cl]` 表示分类过程中的分类损失，`B(l)[r]` 代表回归损失，`B(l)[m]` 是图像掩码损失函数。`B(l)[cl]` 可以通过公式计算：

```
B(l)cl  = −  loglog prob[T] (7.2)
```

在公式 7.2 中，`T` 代表边界框检测的真实性，`prob` 表示各种边界框的概率值，表示为 `prob = (p[i], p[i+1], p[i+2],…p[i+n])`。回归损失可以计算为：

```
B(l)r  =  ∑[a] (7.3)
```

其中 `R={a,c,b,h}` 是实际框，`G^T` 是集合 `T` 的绿色框。

在公式 7.3 中，`L1` 表示：

```
L1  =  0.5x (7.4)
```

在公式 (7.1) 中，`B(l)[m]` 表示掩码过程的总体损失，输出为：

```
B(l)[m] = 1/k² ∑_{xy} [S_{xy}logQ_{xy}^T + (1 - S_{xy}^T)] (7.5)
```

在公式 7.5 中，`S` 代表实际掩码，用红色边界框 `{0,1}` 表示，`Q^T` 代表预测框，用绿色表示。

`T` = {1, `D` > `d`[`p`]; 0, `Otherwise`} (7.7)

`Body` = {1, `if` `V`[`i` = 1]^(`n`) = 1; 0, `Otherwise`} (7.8)

## 7.4 数据集

NTU RGB+D 125 数据集展示了所创建的方法如何在各个位置定位人体的关键点。重要元素被进一步组织成人体骨架和六个器官。找到关键点后，利用关键点的相关数据对成对距离进行检查。根据时间规定识别患者的困难程度。

建议的实验使用 Radeon RX 5500 XT 8GB GPU、32GB DDR3 内存和 Intel Core i7-7700 处理器进行。使用图形处理器可以缩短用于目标检测模型的训练时间。凭借数百万视频样本和 62 个动作捕获，NTU RGB+D 125 是一个包含 RGB+D 人体动作识别的大型数据集。数据集中的每个样本都包含深度图序列、红外电影、RGB 视频和 3D 骨骼数据。每个 RGB 视频帧的分辨率为 2560×1440 像素，而 IR 视频帧的分辨率为 640×480 像素。所提系统由数据集中的 3D 彩色图片确定患者的健康问题。

## 7.5 用于不适检测的 AX-YOLOv5 算法实现

1. 从 NTU RGB+D 数据集获取输入。
2. 应用 Maxout 技术对输入图像进行预处理以降低维度。
3. 提出有效区域（即使用 `AX-YOLOv5` 时输入图像中的 `ROI`）。
4. 此步骤持续应用于非极大值抑制技术（`NMS`）以检测目标。
5. 通过 `IoU` 技术检测重叠物体的边界框。
6. 步骤 3、4 重复以预测不适。
7. 通过欧里得距离公式监测图像帧。
8. 当欧里得距离大于阈值 `T` 时视为不适，否则为舒适。

## 7.7 性能指标

指标分为两类：回归指标和分类指标。回归指标通常处理连续值。同样，分类指标仅考虑离散值。这两种指标适用于监督学习模型。从这些指标中可以轻松识别不适误差。

### 7.7.1 回归指标

#### 7.7.1.1 平均绝对误差 (MAE)

该指标计算预测值与实际值之间的绝对误差。预测不适的情况通过等式 7.10 测量。

$MAE = \frac{1}{M}\sum\limits_{j = 1}^{M}\left| {x_{j} - \widehat{x}_{j}} \right|$ (7.10)

#### 7.7.1.2 均方偏差 (MSD)

该指标寻找实际值之间的关系。它通过平方函数自动消除负值。如果模型预测出现误差，结果将会显示误差。这是患者健康识别的另一种误差检测形式，通过等式 7.11 测量。

$MSD = \frac{\sum{({x_{j} - \widehat{x}_{j}})}^{2}}{M}$ (7.11)

#### 7.7.1.3 均方根误差 (RMSE)

该指标使用欧里得距离预测误差，即均方偏差的平方根。器官的活动性可以通过欧里得距离公式进行监测。通过等式 7.12 计算。

$RMSE = \sqrt{\left( {MSD} \right)}$ (7.12)

### 7.7.2 分类指标

分类指标仅产生真或假形式的离散输出。分类下有多种指标可以评估模型性能。

#### 7.7.2.1 准确率

准确率 (`A`) 是分类下的一个指标，它能够准确预测不适的正确位置，通过从总观测值中预测真实预测来实现。这由等式 7.13 表示。

$A = \frac{True\mspace{9mu} Predictions}{Total\mspace{9mu} Observations}$ (7.13)

其中真实预测 = TN + TP，总观测值 = TP + TN + FP + FN

根据上述因素，衍生出了许多性能目标，包括 `TP`、`FP`、`accuracy`、`precision` 和 `recall`。图 7.3 和 图 7.4 显示了典型的 `TP`、`FP` 以及每个身体器官的损失率。

#### 7.7.2.2 交并比 (IoU)

`IoU` 是一种用于衡量目标检测预测准确性的评估指标，它通过边界框的交集面积除以边界框的并集面积来计算。该方法在目标检测中被广泛使用。其计算方法见于公式 7.14：

$IoU = \frac{Area\mspace{9mu} of\mspace{9mu} Intersection\mspace{9mu} of\mspace{9mu} boxes}{Area\mspace{9mu} of\mspace{9mu} Union\mspace{9mu} Boxes}$ (7.14)

阈值 (`T`) 设置为 0.5，`IoU = 1` 为最大值。

```
if the value of IoU >= T, then the prediction is correct
or else the prediction is incorrect (i.e., the patient is not identified efficiently).
```

图中 y 轴显示了所系统的 `AP`、`PPV`、`TPR` 和 `accuracy` 值，而 x 轴显示了各种身体器官。精确率、召回率和准确率随每个身体和器官的运动而变化。通过检测患者运动、关键点和身体器官，可以看出该系统产生了准确的发现。所有测试视频序列的准确率都高于 91%。同样，系统的 `PPV` 速率很高，这表明大多数检测到的关键点和身体器官运动值与真实值的坐标值匹配。在精确率约等于 70% 时产生相同的结果，并表征了大多数情况下的系统整体性能。

#### 7.7.2.3 预测正值 (PPV)

通常，预测预测值可以通过错误矩阵确定，如图 7.8 所示。

$PPV = \frac{True\mspace{9mu} Positive}{Predicted\mspace{9mu} Positive}$ (7.15)

其中 `True Positive` = `TP`，`Predicted Positive` = `TP + FP`
