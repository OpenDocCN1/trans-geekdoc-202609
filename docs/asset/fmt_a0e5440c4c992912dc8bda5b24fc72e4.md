
### 3.9.3 关键函数说明

- `np.linalg.norm(...)`：计算相减得到的向量的欧几里得范数（模）。在 2D 空间中，这等同于寻找 `point1` 和 `point2` 之间的直线距离。
- `distance`：存储两点之间计算出的欧几里得距离。在数学术语中，2D 空间中点 `(p1, q1)` 和 `(p2, q2)` 之间的欧几里得距离 `(Ed)` 由公式 1 给出：

`Ed = sqrt((p2 - p1)^2 - (q2 - q1)^2)` (1)

5. `Calculate_metrics(path, speed)` 函数：使用公式计算路径长度、转角、能量消耗和完成时间：

```
path[length] = distance(prev[point], current[point])   (2)
turning[angle] = np.arccos(...)                        (3)
energy[consumption] = distance(prev[point], current[point])  (4)
completion[time] += distance(prev[point], current[point]) / speed  (5)
```

6. 避开 NFZ 的 TSP：为此，首先实现贪心算法以找到避开 NFZ 的最优 TSP 遍历。随后，让 UAV 从第一个航点开始，并使用公式迭代选择最近的未访问航点，同时避开 NFZ：

```
nearest[point] = min(unvisited, key = lambda point: distance(current[point], point))  (6)
```

最后，本文提供了一种基于网格的无人机（UAV）覆盖路径规划技术，该技术结合了贪心算法以规避禁区（NFZ）。该技术通过航点有效引导无人机并动态规避 NFZ，确保了路径覆盖的安全性和最优性。正如往返遍历演示所示，该方法有效地减少了路径长度、转弯角度、能量消耗和完成时间。性能数据和图表说明了贪心算法的成功性，并展示了其在遵守 NFZ 限制的同时提供理想路径的能力。本文为与 NFZ 相关的现实情况提供了一种可行的解决方案，与传统算法相比具有更高的性能，从而推进了无人机路径规划领域的发展。
