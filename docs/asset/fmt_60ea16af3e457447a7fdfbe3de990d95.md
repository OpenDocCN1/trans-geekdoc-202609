
# 代价函数的优化

代价函数的优化一直是贯穿全书的一个反复出现的主题。在第 5 章中，介绍了梯度下降优化算法并概述了其部分收敛性质。随后，讨论了用于在线、逐样本模式下优化损失函数期望的随机逼近框架。梯度下降方案和在线优化原理构成了许多已被提出并用于训练前馈神经网络的优化算法的核心。我们之所以需要在神经网络的背景下专门讨论这些算法，是因为这些网络的 `多层` 结构带来了必须在应用现成的优化方案之前加以理解的困难。

在神经网络框架下处理代价函数（如公式 (18.6) 所示）的最小化时，一个主要困难在于其 `非凸性`。凸函数在第 8 章中已有讨论。在那里指出，对于凸函数的情况，每一个局部极小值也是全局极小值。例如，回顾图 8.3 中典型的凸函数图形。根据函数极小值的定义，我们知道在该点梯度（在最简单的单参数空间中即导数）变为零。函数梯度变为零的点被称为 `临界点` 或 `驻点`。

然而，如果函数不是凸的，驻点可能属于以下三类之一：(a) 局部极小值（极大值），(b) 全局极小值（极大值），或 (c) 鞍点；参见一维空间情况下的图 18.10。所有这些驻点在神经网络中都很重要。局部极小值是代价值 `J(θ[l])` 在 `θ[l]` 周围区域内变为最小的点。全局极小值 `θ[g]` 是满足 `J(θ[g]) ≤ J(θ)`，∀`θ` ∈ ℝ 的点。鞍点 `θ[s]` 既不是极小值也不是极大值，但其导数（一般情况下为梯度）等于零。

To which minimum, out of the many, the algorithm will converge, depends on the point from which the algorithm was initialized. However, if the value of the cost at a local minimum, e.g., J(θl), is not much larger than that of the global minimum, i.e., J(θg), then θl can be a satisfactory solution in practice.](img/gr010.jpg)

图 18.10 非凸函数除了全局极小值外，通常还包含若干局部极小值和鞍点。算法将收敛到众多极小值中的哪一个，取决于算法初始化的起始点。然而，如果某局部极小值处的代价值（例如 `J(θ[l])`）并不比全局极小值处的代价值（即 `J(θ[g])`）大很多，那么 `θ[l]` 在实践中可以是一个令人满意的解。

当采用梯度下降方案来最小化非凸代价函数时，算法可能收敛到局部极小值或全局极小值。以图 18.10 为例。回顾第 5 章，梯度下降算法在一维情况下的更新规则变为

```
θ(new) = θ(old) − μ dJ/dθ|θ(old)
```

迭代从任意初始点 $\theta^{(0)}$ 开始。如果当前迭代时算法位于点 $\theta_{\text{old}} = \theta_1$，则它将向局部最小值 $\theta_l$ 移动。这是因为 $\theta_1$ 处代价函数的导数等于 $\phi_1$ 的切线，该值为负（角度为钝角），因此更新 $\theta_{\text{new}}$ 将向右移动，朝向局部最小值 $\theta_l$。相反，如果算法从不同的点初始化，且当前位于 $\theta_{\text{old}} = \theta_2$，则更新将朝向全局最小值 $\theta_g$ 移动，因为此时导数等于 $\phi_2$ 的切线，该值为正（角度为锐角）。正如我们从第 5 章了解到的，步长 $\mu$ 的选择对算法的收敛至关重要。

在多维空间的实际问题中，局部最小值的数量可能很大，因此算法可能会收敛到一个局部最小值。然而，这不一定是坏消息。如果这个局部最小值足够深，即该点的代价函数值 $J(\theta_l)$ 不比全局最小值处达到的值 $J(\theta_g)$ 大太多，那么收敛到这样的局部最小值可能对应一个良好的解。在实践中，处理非凸代价函数时，必须小心如何初始化算法。我们稍后将讨论这个问题。此外，当参数空间维度变大时（深度网络即属于这种情况），局部最小值、全局最小值和鞍点之间的相互作用将在第 18.11.1 节中讨论。

## 18.4.1 梯度下降反向传播方案

采用可微激活函数后，我们准备好开发用于最小化代价函数的梯度下降迭代方案。我们将在一个通用框架中构建该任务。

设 $(\mathbf{y}[n], \mathbf{x}[n])$，$n = 1, 2, \dots, N$ 为训练样本集。注意我们假设有多个输出变量，组装成一个向量。我们假设网络包含 $L$ 层；$L-1$ 个隐藏层和一个输出层。每一层包含 $k_r$，$r = 1, 2, \dots, L$ 个神经元。因此，（目标/期望）输出向量为：

$$

\mathbf{y}[n] = [y_{n1}, y_{n2}, \dots, y_{n k_L}]^T \in \mathbb{R}^{k_L}, \quad n = 1, 2, \dots, N.

$$

为了进行数学推导，我们还将输入节点的数量表示为 $k_0$；即 $k_0 = l$，其中 $l$ 是输入特征空间的维数。

令 $\mathbf{\theta}[j]^{(r)}$ 表示与第 $r$ 层中第 $j$ 个神经元相关的突触权重向量，其中 $j = 1, 2, \dots, k[r]$ 且 $r = 1, 2, \dots, L$，偏置项包含在 $\mathbf{\theta}[j]^{(r)}$ 中，即

$\mathbf{\theta}[j]^{(r)} := [\theta[j0]^{(r)}, \theta[j1]^{(r)}, \dots, \theta[j k[r-1]]^{(r)}]^T$。 (18.9)

突触权重将相应神经元与第 $k[r-1]$ 层的所有神经元连接起来（见图 18.11）。梯度下降方案的基本迭代步骤写为

```
θ_j^(r)(new) = θ_j^(r)(old) - μ ∂J/∂θ_j^(r)
```

参数 $\mu$ 是用户定义的步长（也可以与迭代次数有关），$J$ 表示代价函数。

图 18.11 第 $r$ 层第 $j$ 个神经元的连接及其相关变量；$y[k]^{(r-1)}$ 是第 $(r-1)$ 层第 $k$ 个神经元的输出，$\theta[jk]^{(r)}$ 是连接这两个神经元的相应权重。为表示方便，已省略索引 $n$ 的依赖关系。

更新公式 (18.10) 和 (18.11) 构成了用于优化的梯度下降方案的一对公式（例如第 5 章）。如前所述，前馈神经网络的困难源于其多层结构。为了计算公式 (18.11) 中*所有*层中*所有*神经元的梯度，必须遵循两个计算步骤。

*   **前向计算**：对于给定的输入向量 $\mathbf{x}[n]$，$n = 1, 2, \dots, N$，使用参数（突触权重）的当前估计值（$\mathbf{\theta}[j]^{(r)}(\text{old})$）并计算所有层中所有神经元的输出，记为 $y[nj]^{(r)}$；在图 18.11 中，为使符号简洁，已省略索引 $n$。

*   **后向计算**：利用上述计算出的神经元输出以及输出层已知的目标值 $y[nk]$，计算代价函数的梯度。这涉及 $L$ 个步骤，即与层数相同。算法步骤序列如下：

### 反向计算步骤

1.  计算代价函数关于最后一层神经元参数的梯度，即 $\frac{\partial J}{\partial\mathbf{\theta}_{j}^{L}}$，其中 $j = 1, 2, \dots, k[L]$。

2.  **对于** $r = L - 1$ **到** 1，**执行**

    1.  计算与第 $r$ 层神经元相关参数的梯度，即 $\frac{\partial J}{\partial\mathbf{\theta}_{k}^{r}}$，其中 $k = 1, 2, \dots, k[r]$。这些梯度基于上一步计算出的、关于第 $r+1$ 层参数的所有梯度 $\frac{\partial J}{\partial\mathbf{\theta}_{j}^{r+1}}$（其中 $j = 1, 2, \dots, k[r+1]$）。

3.  **结束循环**

反向计算方案是求导链式法则的直接应用。它从计算与最后一层（输出层）相关的导数这一初始步骤开始，该步骤非常直接。随后，算法在层级结构中“向后流动”。这是因为多层网络的本质：输出逐层形成为函数的函数。

确实，让我们关注第 $r$ 层第 $k$ 个神经元的输出 $y_{k}^{(r)}$。则有

$$

y_{k}^{(r)} = f(\mathbf{\theta}_{k}^{(r)T}\mathbf{y}^{(r-1)}), \quad k = 1, 2, \dots, k[r],

$$

其中 $\mathbf{y}^{(r-1)}$ 是包含前一层 $r-1$ 所有输出的（扩展）向量，$f$ 表示非线性函数。基于上述公式，下一层第 $j$ 个神经元的输出由下式给出

$$

y_{j}^{r + 1} = f\left( \mathbf{\theta}_{j}^{r + 1^{T}}\mathbf{y}^{r} \right) = f\left( \mathbf{\theta}_{j}^{r + 1^{T}}\begin{bmatrix} 1 \\ f\left( \Theta^{r}\mathbf{y}^{r - 1} \right) \\ \end{bmatrix} \right),

$$

![Equation](img/si121.png)

其中 $\Theta^{(r)} := [\boldsymbol{\theta}_{1}^{(r)}, \boldsymbol{\theta}_{2}^{(r)}, \dots, \boldsymbol{\theta}_{k_{r}}]^{(T)}$ 表示其行为第 $r$ 层权重向量的矩阵。人们很容易发现我们之前所谓的“函数的函数”。显然，随着我们在层级中向前推进，这种情况会持续下去。这种函数套函数套函数的结构是神经网络多层特性的副产品，它是一种高度非线性运算，导致了计算梯度的复杂性，这与我们在前几章学习的其他学习器形成对比。

然而，人们很容易发现，计算定义输出层参数的梯度并不存在任何困难。确实，最后一层第 $j$ 个神经元的输出（实际上就是相应的当前输出估计值）写作

$$

\hat{y}_{j} := y_{j}^{(L)} = f(\boldsymbol{\theta}_{j}^{(L^{T})}\mathbf{y}^{(L - 1)}).

$$

![Equation](img/si123.png)

由于 $\mathbf{y}^{(L - 1)}$ 在前向传播计算后已知，对 $\boldsymbol{\theta}_{j}^{(L)}$ 求导是直接了当的；此处不涉及函数套函数运算。这就是为什么我们从顶层开始，然后向后移动的原因。

鉴于其历史重要性，将给出反向传播算法的完整推导。对细节不感兴趣的读者可在初读时跳过这一部分。

对于反向传播算法的详细推导，采用平方误差损失函数作为示例，即

$$

J(\boldsymbol{\theta}) = \sum_{n = 1}^{N}J_{n}(\boldsymbol{\theta}),

$$

![Equation](img/si126.png)(18.12)

和

$J_{n}(\mathbf{\theta}) = \frac{1}{2}\sum\limits_{k = 1}^{k_{L}}\left( {\widehat{y}}_{nk} - y_{nk} \right)^{2}$

其中 $\widehat{y}_{nk}$，$k = 1, 2, \dots, k_{L}$，是网络相应输出节点提供的估计值。我们将它们视为相应向量 ${\widehat{\mathbf{y}}}_{n}$ 的元素。

### 梯度的计算

令 $z_{nj}^{(r)}$ 表示当模式 $\mathbf{x}_{n}$ 作用于输入节点时，第 $r$ 层中第 $j$ 个神经元的线性组合器在时刻 $n$ 的输出（参见图 18.11）。则可写为

$z_{nj}^{r} = \sum\limits_{m = 1}^{k_{r - 1}}\theta_{jm}^{r}y_{nm}^{r - 1} + \theta_{j0}^{r} = \sum\limits_{m = 0}^{k_{r - 1}}\theta_{jm}^{r}y_{nm}^{r - 1} = \mathbf{\theta}_{j}^{r^{T}}\mathbf{y}_{n}^{r - 1}$

其中根据定义

$\mathbf{y}_{n}^{(r - 1)} := \left[1, y_{n1}^{(r - 1)}, \dots, y_{n k_{r - 1}}^{(r - 1)}\right]^{(T)}$

且 `y[n0]^(r) ≡ 1, ∀ r, n`，且 `θ[j]^(r)` 已在公式 (18.9) 中定义。对于输出层的神经元，`r = L`，`y[nm]^(L) = ŷ[nm], m = 1, 2, …, k[L]`，而对于 `r = 1`，我们有 `y[nm]⁰ = x[nm], m = 1, 2, …, k[0]`；即 `y[nm]⁰` 被设置为等于输入特征值。

因此，我们现在可以写成

```
∂J_n / ∂θ_j^r = ∂J_n / ∂z_nj^r * ∂z_nj^r / ∂θ_j^r = ∂J_n / ∂z_nj^r * y_n^(r-1).
```

![Equation](img/si140.png)(18.16)

现在让我们定义

```
δ_nj^r := ∂J_n / ∂z_nj^r.
```
