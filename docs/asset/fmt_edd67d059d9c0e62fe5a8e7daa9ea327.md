
# 均衡器与噪声消除示例

**均衡器**的目标是通过减轻任何（不完美的）色散通信信道施加在发射信号上的所谓**符号间干扰**（ISI）来恢复发射的信息符号；除了 ISI，加性噪声也存在于发射的信息比特中（参见示例 4.2）。均衡器如今“无处不在”；在我们的手机、调制解调器等设备中。图 4.12 展示了均衡器的基本方案。均衡器经过训练，使其输出尽可能接近延迟某个时滞 `L` 后的发射数据比特；该延迟用于解释信道-均衡器系统施加的总延迟。去卷积/信道均衡是除通信之外许多应用的核心，如声学、光学、地震信号处理和控制。信道均衡任务将在下一章中结合决策反馈均衡运行模式下的在线学习进行讨论。

## 示例 4.1

### 噪声消除

噪声消除应用如图 4.13 所示。关注信号是过程 `s[n]` 的一个实现，它被噪声过程 `v₁(n)` 污染。例如，`s[n]` 可能是驾驶舱内飞行员的语音信号，而 `v₁(n)` 是麦克风位置处的飞机噪声。我们假设 `v₁(n)` 是一阶 AR 过程，表示为：

```
v₁(n) = a₁v₁(n - 1) + η[n].
```

![图 4.13 噪声消除器的框图。所示信号是文中使用的相应随机信号的实现。以受污染信号作为期望响应，最优滤波器的输出是噪声分量的估计。](img/gr013.jpg)

图 4.13 噪声消除器的框图。所示信号是文中使用的相应随机信号的实现。以受污染信号作为期望响应，最优滤波器的输出是噪声分量的估计。

随机信号 `v₂(n)` 是一个噪声序列^²²：

```
v₂(n) = a₂v₂(n - 1) + η[n].
```

请注意，`v₁` 和 `v₂` 都是由同一个噪声源 `η[n]` 生成的，该噪声源被假设为方差为 `σ²_η` 的白噪声。例如，在飞机中可以假设不同点的噪声是由一个“公共”源引起的，特别是对于附近的位置。

本例的目标是计算噪声消除器的权重/参数估计值，以便以最优方式（均方误差意义下）从混合信号 `s[n] + v₁` 中去除噪声 `v₁`。假设消除器为二阶。

消除器的输入为 `v₂`，期望响应为混合信号 `d[n] = s[n] + v₁`。为了建立正规方程，我们需要计算 `v₂` 的协方差矩阵 `Σ₂`，以及输入随机向量 `v₂` 与 `d[n]` 之间的互相关向量 `p₂`。

因为 `v₂` 是一阶 AR 过程，回顾第 2.4.4 节，其自相关序列由下式给出：

```
r₂(k) = (a₂^k * σ²_η) / (1 - a₂²),  k = 0,1,...
```

因此，

$$
\Sigma_{2} = \begin{bmatrix} r_{2}(0) & r_{2}(1) \\ r_{2}(1) & r_{2}(0) \end{bmatrix} = \begin{bmatrix} \frac{\sigma_{\eta}^{2}}{1 - a_{2}^{2}} & \frac{a_{2}\sigma_{\eta}^{2}}{1 - a_{2}^{2}} \\ \frac{a_{2}\sigma_{\eta}^{2}}{1 - a_{2}^{2}} & \frac{\sigma_{\eta}^{2}}{1 - a_{2}^{2}} \end{bmatrix}.
$$

![Equation](img/si220.png)

接下来，我们将计算互相关向量。我们有

#### 公式推导

$p_2 = \mathbb{E}[v_2 d[n]] = \mathbb{E}[v_2(s[n] + v_1)] = \mathbb{E}[v_2 v_1] + 0 = \mathbb{E}[(a_2 v_2 + \eta[n])(a_1 v_1 + \eta[n])] = a_2 a_1 p_2 + \sigma^2_\eta$,

或者

$$p_{2}(0) = \frac{\sigma_{\eta}^{2}}{1 - a_{1}a_{2}}.$$ (4.56)

我们利用了 `𝔼[v₂η[n]] = 𝔼[v₁η[n]] = 0` 这一事实，因为 `v₂` 和 `v₁` 递归地依赖于先前的值，即 `η(n − 1), η(n − 2), ...`，并且 `η[n]` 是一个白噪声序列，因此相应的相关值为零。此外，由于平稳性，`𝔼[v₂v₁] = 𝔼[v₂v₁]`。

互相关向量的另一个值为

##### 推导过程

$$
p_{2}(1) = \mathbb{E}[v_{2}(n - 1)d_{n}] = \mathbb{E}[v_{2}(n - 1)(s_{n} + v_{1}(n))] = \mathbb{E}[v_{2}(n - 1)v_{1}(n)] + 0 = \mathbb{E}[v_{2}(n - 1)(a_{1}v_{1}(n - 1) + \eta_{n})] = a_{1}p_{2}(0) = \frac{a_{1}\sigma_{\eta}^{2}}{1 - a_{1}a_{2}}.
$$

![Equation](img/si228.png)

通常很容易证明

$$
p_{2}(k) = \frac{a_{1}^{k}\sigma_{\eta}^{2}}{1 - a_{1}a_{2}},\quad k = 0,1,\ldots.
$$

![Equation](img/si229.png) (4.57)

回想一下，因为这些过程是实值的，协方差矩阵是对称的，意味着 `r₂(k) = r₂(−k)`。此外，为了使公式 (4.55) 成立（回想 `r₂(0) > 0`），必须有 `|a₂| < 1`。根据 `v₁(n)` 的自相关过程的类似论证，`|a₁| < 1` 也成立。

因此，噪声消除器的最优权重由以下正规方程组给出：

```
[ σ²_η/(1 - a₂²)    a₂σ²_η/(1 - a₂²) ] [w] = [ σ²_η/(1 - a₁a₂) ]
[ a₂σ²_η/(1 - a₂²)  σ²_η/(1 - a₂²)   ]      [ a₁σ²_η/(1 - a₁a₂) ]
```

注意，消除器最优地从混合信号 `s[n] + v₁(n)` 中“移除”了与输入 `v₂(n)` 相关的分量；观察到 `v₁(n)` 基本上充当了期望响应。

图 4.14A 显示了相应随机信号 `d[n]` 的一个实现 `d[n] = s[n] + v₁`，其中 `s[n] = cos(ω₀n)`，`ω₀ = 2 * 10^(-3) * π`，`a₁ = 0.8`，且 `σ²_η = 0.05`。图 4.14B 是 `s[n] + v₁ - d̂(n)` 在 `a₂ = 0.75` 时的相应实现。消除器的相应权重为 `w* = [1, 0.125]^(T)`。图 4.14C 对应 `a₂ = 0.5`。观察可知，`v₁` 和 `v₂` 之间的互相关越高，获得的结果就越好。

![图 4.14 (A) 示例 4.1 的含噪正弦信号。(B) 强相关噪声源 v1 和 v2 的去噪信号。(C) 相关性较弱的噪声源获得的去噐信号。](img/gr014.jpg)

图 4.14 (A) 示例 4.1 的含噪正弦信号。(B) 强相关噪声源 `v₁` 和 `v₂` 的去噪信号。(C) 相关性较弱的噪声源获得的去噪信号。

## 示例 4.2

### 信道均衡

考虑图 4.12 中的信道均衡设置，接收机感知到的信道输出由下式给出：

`u[n] = 0.5*s[n] + s[n - 1] + η[n].`

目标是设计一个包含三个抽头的均衡器 `w = [w[0], w[1], w[2]]^(T)`，使得

`d̂[n] = w^(T)u[n]`

并利用期望响应序列 `d[n] = s[n − 1]` 来估计未知抽头。已知 `𝔼[s[n]] = 𝔼[η[n]] = 0` 且

`Σ[s] = σ²_s I`, `Σ[η] = σ²_η I`。

注意，对于期望响应，我们使用了延迟 `L = 1`。为了更好地理解使用延迟的原因，且不深入过多细节（对于经验丰富的读者，请注意信道是非最小相位的，例如 [41]），观察到在时刻 `n`，方程 (4.58) 中 `u[n]` 的主要贡献来自符号 `s[n − 1]`，其权重为 1，而采样值 `s[n]` 的权重为 0.5；因此，从直观角度来看，在时刻 `n` 收到 `u[n]` 后，尝试获得 `s[n − 1]` 的估计值是最自然的。这证明了使用延迟的合理性。

## 4.8 算法方面：Levinson 算法和格-梯形算法

本节的目标是介绍求解公式 (4.16) 中正规方程的高效算法方案。^(²³)

回顾线性代数知识，求解含有 `l` 个未知数的 `l` 个一般线性方程组，需要 `O(l³)` 次运算（乘法和加法 [MADS]）。利用与随机过程相关的自相关/协方差矩阵的丰富结构，将推导出一种具有 `O(l²)` 次运算的算法。将考虑更一般的复值情况。

```
u_n = [ 0.5  1    0    0 ] [ s_n     ] + [ η_n     ] := H s_n + η_n,
      [ 0    0.5  1    0 ] [ s_{n-1} ]   [ η_{n-1} ]
      [ 0    0    0.5  1 ] [ s_{n-2} ]   [ η_{n-2} ]
                            [ s_{n-3} ]   [ η_{n-3} ]
```

![Equation](img/si262.png)(4.59)

其结果为

`Σ[u] = 𝔼[u[n]u[n]^(T)] = H σ²_s H^(T) + Σ[η] = σ²_s H H^(T) + σ²_η I`。

![Equation](img/si263.png)

读者可以很容易地验证这与之前的结果相同。然而请注意，公式 (4.59) 让人联想到线性回归模型。此外，请注意矩阵 `H` 的特殊结构。此类矩阵也称为*卷积*矩阵。这种结构是由 `u[n]` 的元素是第一个元素的时移版本这一事实强加的，因为输入向量对应于一个随机过程。这正是接下来将被利用的性质，用于推导求解正规方程的高效方案。

输入随机向量的自相关/协方差矩阵（针对零均值过程）已在公式 (4.17) 中定义。也就是说，它既是厄米特矩阵，又是半正定矩阵。从现在开始，我们将假设它是正定矩阵。与复宽平稳过程相关的 `ℂ^(m×m)` 中的协方差矩阵由下式给出：

```
Σ_m = [ r(0)     r(1)     ⋯     r(m-1)   ]
      [ r(-1)    r(0)     ⋯     r(m-2)   ]
      [ ⋮        ⋮        ⋱     ⋮        ]
      [ r(-m+1)  r(-m+2)  ⋯     r(0)     ]
    = [ r(0)     r(1)     ⋯     r(m-1)   ]
      [ r*(1)    r(0)     ⋯     r(m-2)   ]
      [ ⋮        ⋮        ⋱     ⋮        ]
      [ r*(m-1)  r*(m-2)  ⋯     r(0)     ],
```

其中性质

```
r(i) := E[u[n] u[n-i]*] = E[(u[n-i] u[n]*)*] := r*(-i)
```

我们放宽了 `Σ` 对 `u` 的符号依赖，转而显式地标明了矩阵的阶数，因为从现在起这将是一个非常有用的索引。

我们将采用递归方法，我们的目标是用 `m-1` 阶的最优解 `w[m-1]` 来表示 `m` 阶的最优滤波器解，从现在起将其表示为 `w[m]`。

```
Σ_m = [ Σ_{m-1}       J_{m-1} r_{m-1} ]
      [ r_{m-1}^H J_{m-1}   r(0)       ]
```
