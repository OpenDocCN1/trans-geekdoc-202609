
❑ 音乐推荐：根据用户的收听历史生成个性化播放列表。

## 11. Forecasting Algorithms（预测算法）

预测算法基于历史数据预测未来数值。`ARIMA`、`指数平滑`、`LSTM` 等时间序列方法常用于金融、天气、销售等领域的趋势预测。精准的预测有助于战略规划和决策。

## 11.1 ARIMA (AutoRegressive Integrated Moving Average)

### Main Concept

`ARIMA` 通过自回归（AR）、差分（I）和移动平均（MA）三个组成部分，对时间序列进行预测，广泛应用于多个领域。

### Main Purpose

通过捕获数据的时序结构，分析并预测时间序列。

### When to Use It

❑ 当时间序列数据呈平稳或可通过差分使其平稳时。

❑ 用于基于历史值预测未来值。

❑ 适用于存在趋势和季节性、经过必要变换后的数据。

### Real-World Examples

❑ 经济：预测 GDP、失业率、股价等宏观指标。

❑ 金融：预测股价、市场指数、利率等。

❑ 销售预测：基于历史销售数据估算未来销量。

❑ 天气预测：预测温度、降水量等气象指标。

### Math Background

![](img/image-FLH7Q20P.png)

![](img/image-43Z89936.png)

### Loss Function

![](img/image-G5CKQF6U.png)

### Steps in ARIMA

❑ Identification（识别）：利用自相关函数（ACF）和偏自相关函数（PACF）确定 p、d、q 的取值。

❑ Estimation（估计）：估计 AR 与 MA 组件的参数。

❑ Diagnostic Checking（诊断检查）：检查模型残差是否为白噪声。

❑ Forecasting（预测）：使用模型对未来值进行预测。

### Pros and Cons

**Pros：**

⇨ 对短期预测效果好。

⇨ 能够处理带有趋势和季节性的多种时间序列。

⇨ 统计学领域已相当成熟、易于理解。

**Cons：**

 需要数据平稳或通过差分实现平稳。

 配置合适的 p、d、q 参数可能较为复杂。

 对非线性模式或大规模数据表现不佳。

## 11.2 SARIMA (Seasonal ARIMA)

### Main Concept

`SARIMA` 是在 `ARIMA` 基础上显式支持季节性的时间序列模型，结合季节性差分与非季节性 `ARIMA` 组件，同时建模季节性和非季节性模式。

### Main Purpose

分析并预测具备季节性的时间序列，捕获趋势和季节两个组成部分。

### When to Use It

❑ 当时间序列数据具有明显的季节性时。

❑ 当处理具有明确季节性模式的时间序列数据时。

❑ 基于过去值（包括季节性波动）预测未来值。

❑ 适用于具有趋势、季节性和其他周期性行为的数据。

### Real-World Examples

❑ 零售销售预测：预测在节假日期间会出现季节性峰值的月度销售。

❑ 天气预测：预测温度、降水等气象变量，这些变量表现出季节性变化。

❑ 电力需求：预测电力消耗，其具有季节性变化。

❑ 旅游业：预测游客到访量，通常遵循季节性模式。

### Math Background

![](img/image-WL6YPEK7.png)

![](img/image-9QXAR9QQ.png)

### SARIMA Model

`SARIMA(p,d,q) (P,D,Q) s`

- `p`：非季节性 AR 部分的阶数。
- `d`：非季节性差分的阶数。
- `q`：非季节性 MA 部分的阶数。
- `P`：季节性 AR 部分的阶数。
- `D`：季节性差分的阶数。
- `Q`：季节性 MA 部分的阶数。
- `s`：季节性周期的长度。

❑ 识别：使用自相关函数（ACF）和部分自相关函数（PACF）图等工具确定 p、d、q、P、D、Q、s 的值。

❑ 估计：估计非季节性和季节性组件的参数。

❑ 诊断检查：检查模型的残差，确保它们是白噪声。

❑ 预测：利用模型对未来值进行预测。

### Pros and Cons

**Pros：**

⇨ 有效捕获季节性和非季节性模式。

⇨ 为复杂季节性时间序列提供全面的预测框架。

⇨ 在时间序列分析中已被广泛理解和使用。

**Cons：**

 需要仔细识别和调谐许多参数。

 计算开销大，尤其是在长季节周期时。

 解释和诊断模型可能复杂。

## 11.3 SARIMAX（季节性 ARIMA 与外生变量）

### Main Concept

`SARIMAX` 是 `SARIMA` 的扩展，加入了外生变量（预测器）以模拟外部因素对时间序列的影响。它同时包含季节性和非季节性组件，以及外部回归器，提供更全面的预测模型。

### Main Purpose

通过捕捉时间结构和外部变量的影响，分析和预测时间序列数据。

### When to Use It

❑ 处理具有季节性模式且受外部因素影响的时间序列数据时。

❑ 预测未来值，且外部变量在预测中起重要作用。

❑ 适用于存在趋势、季节性和外部影响的数据。

### Real-World Examples

❑ 经济：预测国内生产总值（GDP），并加入利率、通胀等外部指标。

❑ 销售预测：预测销售额，并考虑营销支出和经济指标。

❑ 天气预测：预测天气模式，加入地理因素等外部变量。

❑ 能源需求：预测电力消耗，考虑温度、人口增长等外部变量。

❑ 诊断检查：检查模型残差，确保它们是白噪声。

❑ 预测：利用模型预测未来值，并纳入外生变量。

### Pros and Cons

**Pros：**

⇨ 捕获季节性和非季节性模式。

⇨ 考虑外部变量的影响，提高预测准确性。

 需要仔细识别和调谐许多参数。

## 11.4 Exponential Smoothing（指数平滑）

### Main Concept

指数平滑是一种时间序列预测方法，对过去观测值使用加权平均，权重随观测值的年龄指数衰减。该技术适用于短期预测。

### Main Purpose

通过给近期观测更大权重，同时仍考虑历史数据，预测未来值。

### When to Use It

❑ 处理可能存在趋势或季节性的时间序列数据。

❑ 短期预测，近期数据更能反映未来趋势。

❑ 适用于无显著季节性（简单指数平滑）或具有趋势和季节性（Holt‑Winters）的数据。

### Real-World Examples

❑ 库存管理：根据历史销售预测未来库存需求。

❑ 金融：预测股价或经济指标。

❑ 能源消耗：预测未来电力使用量。

❑ 天气预报：短期天气预测。

### Math Background

![](img/image-528N32O8.png)

![](img/image-32H92L59.png)

![](img/image-8AZW3M73.png)

### Steps in Exponential Smoothing

❑ 模型选择：选择合适的指数平滑模型（简单、Holt 或 Holt‑Winters）。

❑ 参数估计：使用优化技术估计平滑参数（α、β、γ）。

❑ 模型拟合：将模型拟合到历史数据上。

❑ 诊断检查：检查模型残差，确保它们是白噪声。

❑ 预测：利用拟合模型预测未来值。

### Pros and Cons

**Pros：**

⇨ 实现简单，易于部署。

⇨ 对短期预测有效。

⇨ 可处理带有趋势和季节性的数据（Holt‑Winters）。

**Cons：**

 假设线性关系，对非线性模式表现不佳。

 需要选择并优化多个参数。

 由于依赖近期数据，长期预测可能不准确。

## 11.5 DeepAR

### Main Purpose

预测具有复杂模式（包括季节性、趋势和非线性关系）的时间序列数据，同时给出不确定性估计。

### When to Use It

❑ 处理大量相关的时间序列数据集。

❑ 需要概率预测并关注置信区间的场景。

❑ 适用于模式复杂、非线性的时间序列数据。

### Real-World Examples

❑ 零售：预测多个门店和商品的产品需求。

❑ 金融：预测股价和金融指标。

❑ 能源：预测不同地区的电力需求。

❑ 医疗：预测患者就诊人数或疾病爆发。

❑ 模型验证：使用验证集验证模型，以调整超参数。

### Main Purpose

构建和预测时间序列数据，其中底层过程随时间变化，利用概率框架考虑参数不确定性。

### When to Use It

- 处理表现出非平稳性或结构变化的时间序列数据时。
- 需要量化预测不确定性的概率性方法。
- 适用于具有趋势、季节性和其他动态行为的时间序列。

### Real-World Examples

- 金融：建模和预测股价或经济指标的变化趋势。
- 医疗：跟踪和预测疾病进展或患者生命体征。
- 工程：预测系统故障或动态系统的维护需求。
- 环境科学：建模和预测气候变量或污染水平。
