
# 转向作用主题 [64]，作用分为乘法作用（乘积模型）和加法作用（求和模型）

在加法模型中，当不存在作用时，两个或多个因素作用于事件的效应等于单独作用效应之和。在乘法模型中，当不存在作用时，两个或多个因素作用于事件的效应等于这些因素单独作用效应的乘积。根据之前的流行病学文献 [65]，乘法作用表示统计效应，而作用进一步暗示了生物学效应。鉴于临床研究通常没有孤立的影响，研究多个特征对结果变量的相互影响是临床研究的一个方向。这一方面在公共卫生研究中变得更加突出。同样，乘法作用和加法作用并不一定共存。然而，在我们的研究中，两个因素之间乘法和加法作用的同时显著性被用作临床研究的有意义的标准。换句话说，两个特征必须同时满足统计学显著乘法和加法作用的标准，具有统计学和生物学意义。这种对结果变量合并效应的评估对于临床研究至关重要。为了评估乘法作用的显著性，可以设定 0.05 的假设检验标准。然而，评估加法作用需要满足三个标准：作用引起的相对风险（AP）和协同指数（S）。当不存在作用时，RI 和 AP 的置信区间包含 0，且 S 的置信区间应包含。

评估临床影响因素的加法和乘法模型对疾病预测和诊断具有重要意义，特别是在流行病学统计研究和 COVID-19 疫情之后。计算加法作用同样重要，因为它对公共卫生具有影响。我曾个人对高尿酸血和高血压等慢性病因素进行作用分析；结合我的经验，让我们用一个简单的例子来说作用研究的重要性。

假设某人群参加了一个聚会活动，其中一些人的状况良好而另一些则不然。聚会活动是感染 COVID-19 的风险因素，我们希望干预以加强对 COVID-19 的控制。为了优化管理、激励和惩罚等资源的使用以实现最大影响，我们需要考虑乘法和加法作用模型。假设我们应用作用理论来研究基础健康状况和参加聚会会对 COVID-19 感染风险产生的合并效应。假设在该研究中，没有基础健康状况的参加聚会的个人之间的乘法作用表示反向乘法作用，这意味着对于有基础健康状况的人来说，参加聚会的感染风险比不参加更高。然而，仅依赖乘法作用的结果会忽视健康状况的人群，并可能识别出错误的高风险组。现在，假设我们使用加法作用算法，它指示正性加法作用，解释了对于有基础健康状况的人来说，干预聚会可以产生更大的健康收益。因此，探索因素作用可以指导临床和预防决策，允许高效分配资源以实现最佳结果。全面分析乘法和加法模型以获得最可靠的研究结果是关键的。随着传染病的广泛发生，与因素作用相关的统计研究将不可增加。希望这项研究能为未来的传染病防控工作提供宝贵的见解。这是本文最重要的贡献之一。

# 基于 Transformer 模型的巴西葡萄牙语乳腺磁共振医学记录自动 BI-RADS 分类

Ricardo de Oliveira, Bruno Menezes, Júnia Ortiz 和 Erick Nascimento

# 摘要

本章旨在通过深度学习和自然语言处理（NLP），根据乳腺影像报告和数据系统（BI-RADS）分类，对临床报告进行词法、句法和语义分析，提出一种乳腺磁共振成像文本记录的分类模型。该模型是基于预训练的 `BERTimbau` 模型（在巴西葡萄牙语中训练的 `BERT`，基于 `Transformer` 的双向编码表示）的迁移学习开发的。数据集由巴西葡萄牙语的医学报告组成，分为六类：不确定；正常或接近正常；良性发现；可能良性发现；可疑发现；高癌症风险；既往恶性病变。本文实现并比较了以下模型：随机森林、`SVM`、朴素贝叶斯、以及微调和未微调的 `BERTimbau`。`BERTimbau` 模型结果更好，且在微调后性能更优。

**关键词：** BI-RADS，深度学习，Transformers，BERTimbau，葡萄牙语 NLP
