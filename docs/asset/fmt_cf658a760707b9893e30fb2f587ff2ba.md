## Abstract

量子计算在近年来经历了巨大的增长。量子机器学习（通常称为 QML）是量子计算中一个迷人的主题，它利用高维希尔伯特空间从较少的输入中获取更丰富的表示。这样做是为了有效解决具有挑战性的学习任务。尽管该语言日益流行，但目前对 QML 安全性的研究还并不多。在研究中，我们分析了 QML 在硬件安全方面的前景。此外，我们暴露了 QML 的漏洞和攻击模型的设计，以及修复这些问题的最佳实践。

**关键词:** 量子计算、硬件安全、量子神经网络、攻击与防御

## 12.1 引言

从其所提供的可能性来看，量子计算代表了计算机构想和构建方式的根本性范式转变。尽管量子计算仍处于处于阶段，但科学界正在寻找量子计算机，希望它们能够在新材料和药物发现等领域提供计算优势（也称为量子优越性）[15, 16]。通过量子机器学习（QML）的应用，未来某一天利用噪声量子计算机实现量子优势是有可能的。QML 可用于改变现有的图像分类系统。此前已经创建了多种基于参数化量子电路（`PQC`）的 QML 模型，这些模型通常被称为量子神经网络（`QNN`）[26]。由于 `QNN` 拥有数据编码电路（`PQC`）和测量操作，典型的 `QNN` 可以被训练用于执行常见的机器学习（`ML`）任务，如分类、回归、分布创建等等。目前尚不清楚 QML 和 `QNNs` 是否能够防御恶意攻击者，或者它们是否成功修补了现有的安全漏洞。考虑到量子计算在安全领域广泛且辉煌的历史，这可能会是一个巨大的冲击。由于系统防御者和攻击者都越来越多地转向 ML 技术来保护和利用硬件，我们研究了 QML 如何为硬件安全问题的解决方案贡献力量。很大程度上，这归因于硬件供应链中普遍存在的威胁，例如盗版、木马植和操纵。在任务关键型系统中，基于 ML 的检测技术的微小不准确就可能危及硬件安全。因此，研究 QML 这种极大增强的 ML 模型至关重要。对抗性样本通过对有效输入数据进行细微更改来构建，可以欺骗量子分类器（对抗性输入操纵）。印刷电路板（`PCB`）缺陷分类已成为 PCB 行业的迫切需求，因为 PCB 缺陷会对系统性能/安全产生重大影响。

为此，我们探索了 QML 模型可能面临的风险以及保护它们的方法。研究将采用以下格式：量子计算和 `QNN` 的基础知识将在第 12.2 节中介绍，随后在第 12.3 节中讨论 QML 的安全应用，在第 12.4 节中介绍几种 QML 漏洞和攻击模型，最后在第 12.5 节中给出结论。

## 12.2 量子计算基础

### 12.2.1 量子比特、量子门与测量

量子比特是量子计算机最基础的组件之一，通常利用微波脉冲为其提供必要的能量。这是一个二级系统，能够以量子态的形式存储信息。量子比特可以于传统比特。另一方面，量子比特可以存在一种被称为“叠加”的状态中，即“0”和“1”的同时混合。这与传统比特不同，传统比特只能存在两种状态之一：要么是“0”，要么是“1”。从数学上讲，量子比特的状态由态向量 `|ψ| = a |0 + b |1` 表示，其中 `|a|²` 和 `|b|²` 分别代表“0”和“1”的概率（因此，`|a|² + |b|² = 1`）。目前有几种不同的量子比特技术可用[20]。

量子门是修改量子比特状态的操作，正是这些操作使得量子比特能够进行计算。量子门的一个示例是允许量子比特执行计算的操作，这种用于单个比特或一组比特的量子门被称为 NOT 门（例如，离子阱中的脉冲、超导量子比特中的脉冲等）。单个量子电路可以包含许多门。目标基用于确定量子态。量子计算的许多实现限制在量子比特的测量值上（例如，泡利量子比特中的 Z 脉冲）。量子计算的基石之一是算符期望值。算符期望值 `⟨O⟩` 被数学定义为 `⟨ψ|O|ψ`，其中 `|ψ` 是矢量。算符的边界是量子比特的范围。例如，泡利 Z 算符只有两个特征值：1 和 -1。由于这种原因，量子比特的泡利 Z 期望值将在 `[-1, 1]` 之间波动，取决于当前状态。

### 12.2.2 量子噪声

在原理上，量子计算机应该比经典计算机更快地完成一系列任务，但在实践中到为止尚未如此。相干故障是由量子比特只能保持其状态一段时间引起的。这是导致量子计算机的许多不同错误和噪声之一。由于量子门是通过微波或激光脉冲实现的，当这些脉冲无法有效创建或应用时，就会发生门故障。当在分离比特上执行多个门时，会发生串扰误差，而当 `|0` 状态的量子比特被测量为 `|1` 时，会发生测量错误。这些错误的发生频率取决于使用的比特和硬件，并可能降低分类器的效率，导致结果偏差和安全问题增加。

### 12.2.3 量子神经网络 (QNN)

`QNN` 适当输入输出可以通过优化参数化量子电路（也称为 `PQC`）的参数来获得。量子神经网络（QNNs）通常由三个部分组成：i) 参数化电路，ii) 测量操作，iii) 将经典数据编码为量子数据的电路。科学文献[26] 提到了许多不同的编码技术。注意：连续变量的输入特征通常被编码为量子比特沿适当轴的旋转（角度编码）。这可以被看作比特的旋转。结果，需要 `n` 个量子比特来编码 `n` 个经典属性。图 12.1 展示了处于叠加态的量子比特在读取状态时会将经典特征 `f1` 存储为 `RZ(f1)`。利用一系列旋转是实现多个连续变量编码的另一种方法。

### 参数化量子电路 (PQC)

参数电路包括纠缠操作和单比特的参数化旋转。涉及所有比特以生成纠缠态的多比特活动被称为“纠缠操作” [[17]](#c12.xhtml#ref17)。解空间的探索是使用下下文讨论的单比特参数化技术来。量子神经网络（QNN）中的参数层将纠缠与单比特旋转操作相结合。在过去的几年里，人们投入了大量工作来确定哪种 PQC 设计对于 QNN 是优的。表达能力、纠缠能力、有效维度以及其他多种指标已用于 PQC 技术的排名 [[1]](#c12.xhtml#ref1), [27]](#c12.xhtml#ref27)。根据这些描述符的支持者的说法，这些描述符的值与量子电路的可训练性相关。在确定哪种 PQC 架构最适用于特定的量子机器学习（QML）用例时，这些解释可能会有所帮助。

### 代价函数

为了确定 QNN 电路的输出状态，有必要跟踪组成计算基的比特状态。在对网络进行训练时，会向其呈现一个从收集的数据中导出的代价函数 [[1]](#c12.xhtml#ref1), [25]](#c12.xhtml#ref25)。[[1]](#c12.xhtml#ref1) 通过在 Pauli-Z 基对 QNN 模型中的所有比特进行测量，发现 `Class 0` 与获得偶偶性的概率相关，而 `Class 1` 与获得奇偶性的概率相关。最后，模型在训练过程中通过交叉熵损失进行改进。[[2]](#c12.xhtml#ref2) 的作者利用单比特的 Pauli-Z 期望值来通过均方误差（MSE）损失训练二分类器（-1 与类 1 关联，而 +1 与类 0 相关）。论文 [[10]](#c12.xhtml#ref10) 的作者通过将 QNN 输出整合到普通神经网络中，并使用二交叉熵损失函数训练普通神经网络，能够提高普通神经网络的性能。

### 训练

Adam [[12]](#c12.xhtml#ref12) 和 Adagrad [[8]](#c12.xhtml#ref8) 方法只是用于训练 QNN 的基于梯度的优化程序的两个示例。也可以使用其他的基于梯度的优化程序。在应用这些解决方案之前，你首先需要确定 QNN 输出相对于电路参数的梯度 [[6]](#c12.xhtml#ref6), [24]](#c12.xhtml#ref24)。参数移规则（parameter-shift rule）是计算梯度时一种经过检验且可靠的方法 [[6]](#c12.xhtml#ref6), [24]](#c12.xhtml#ref24)。经典的有限差法在理论上与参数移规则相似。然而，当参数很多时，无梯度优化器的效果可能不理想。

## 安全应用

本节深入探讨 QML 的潜在应用，专注于 PCB 分类。

### PCB 缺陷分类

### 概述

打印电路板（有时被称为 PCB）是几乎所有现代设备的核心组件。然而，由于可用技术的局限性，在 PCB 制造过程中无法保证 100% 的合格率。由于 PCB 的生产经常外包给第三方承包商以降低成本，这些板很容易受到攻击。为了演示如何利用 QML，我们提供了一种混合量子-经典模型。应用 [[3]](#c12.xhtml#ref3) 中描述的策略，我们首先利用卷积自动编码器降低维度。

### 卷积自动编码器 (CAE)

自动编码器（通常称为 AE）是一种特定的前馈神经网络。它们利用编码器网络将输入转换为维度较少的代码，然后使用解码器网络以原始形式重建输出。我们使用输入与重建输出之间的差作为反馈信号，以便对网络进行训练（例如 MSE 损失）。在从照片中提取纹理信息时，CAE 使用的布局比 AE 使用的更有效。在 CAE 中，编码过程从一个或多个卷积层开始。解码块的最后步骤是卷积转置层和反卷积层。一个全连接 AE 位于中心，其最深层由较少的神经元细胞组成。编码器块训练完成后，它可以独立使用来推导输入数据的低维表示。图 12.2 展示了 CAE 如何在此此研究项目（用于分类 PCB 缺陷）中使用的视觉图。最后层 `ConvTranspose2d` 使用 `Sigmoid` 激活函数，其中 `d` 代表潜空间的维度。

CAE 和 QNN 都可以视为在混合网络中运行的独立网络（图 12.2）。为了让 `CAE` 学习低维的数据表示，我们使用初始图像数据集对其进行训练。训练编码器网络是为了从图像数据中提取特征。这些提取出的特征和图像说明在训练期间被输入到典型的 QNN 中，用于最终分类。这种特定模型被称为 `CAE+QNN`。在处理 QNN 或量子滤波器时，可以实现多种不同的编码策略、参数化电路配置和评估策略。由于 [\[3\]](#c12.xhtml#ref3) 提出的 plithon 框架提供了大量的此类选择，QNN 的可学习性 [\[27\]](#c12.xhtml#ref27) 会受到影响。尽管如此，我们仍然来自 [\[11\]](#c12.xhtml#ref11) 的 `PQCircuit-16` 以及 QNN 中量子比特的 `Z` 基测量，并结合了使用单个量子比特编码单个特征的技巧（图 12.1）。可教的最大参数层数也被限制为两层。输入由 QNN 提供到全连接层 [\[10\]](#c12.xhtml#ref10)。神经元的输出总数区分了不同的类别。

### 数据集

我们选择了北京大学人机交互开放实验室公布的增强 PCB 缺陷数据集，以便对原始数据集应用增强技术，这使我们能够生成该数据集。这些技术是通过选取数据集实现的。使用 Photoshop 和其他 Adobe 产品可能会导致六种不同的故障。数据集缺陷包括漏孔、鼠咬孔、开路、短路、毛刺和杂质铜。集合中共有 10,668 张分辨率为 600 x 600 像素的照片。这些图像可能包含也不包含许多缺陷，但它们都属于同一类。我们使用故障提取创建了一个包含 21,664 张图片的更大数据集用于 PCB 缺陷分类研究（图 12.3），每张图片的大小测量为 32 x 32 像素。关于每种故障所拍摄的平均图片数量的更多详细信息可以在表 12.1 中找到。首先，我们使用缺陷的数据集训练了卷积自动编码器（`Train:Test = 70:30`）。通过在之前学习的潜维度（`d` = 4）模型上训练 QNN，我们生成了两个额外的较小分类数据集，一个包含 3 个类，另一个包含 6 个类（用于分类）。

### 训练设置/指标

我们的 `CAE` 使用来自 PCB 缺陷数据集的 15,165 个样本进行训练，潜维度为 4。采用的损失函数是 `Mean Squared Error` (`MSE`），并使用 `Adam` 作为优化器。通过使用 50 的批量大小、25 的轮数时长和百分之零一的学习率，可以获得一些令人印象深刻的结果。通过对样本数据进行测试，经过训练的 `CAE` 的特征集被缩小（`d` = 4）。在数据削减之后，原始数据集被分为两组每组 2,000 个样本（3 类和 6 类）。最后，这些数据集将用于 QNN 的开发和验证（70:30 分）。QNN 模型的有效性可以根据其在训练数据集和验证数据集上实现的平均准确率进行评估[\[4\]](#c12.xhtml#ref4)。模型的泛化能力通过验证准确率显示，而训练能力通过训练过程显示。在模型训练过程中，我们采用了基于梯度的 `Adagrad` 优化器 [\[21\]](#c12.xhtml#ref21)。如图 12.1 所示，我们使用角度编码技术为每个量子比特编码一个经典特征。因此，我们为四个特征的数据集使用了四个量子比特。我们将 4 量比特模型中的参数层数减少到两层。我们训练了 QNN 十次迭代。`Sparse Categorical Cross Entropy` 是损失函数；`Adagrad` 是优化器；学习率为 0.5；批量大小为 32。

利用量子力学中的叠加、隧穿效应和纠缠等概念，量子机器学习（QML）已经展现出良好的前景，表明即使在嘈杂中等规模量子（NISQ）技术下，它也可能很快超越其经典先驱。这是因为 QML 具有利用隧穿效应的能力。QML 模型能够利用大型量子系统的高维希尔伯特空间，以便更好地理解在分类过程中可能呈现统计模式的复杂特征空间。然而，与复杂的传统的机器学习模型一样，QML 模型也包含资源，因此容易受到操纵。在较小范围内，研究表明，随着分类空间维度的增加，分类器抵抗意外变化的能力会降低。由于 QML 模型利用了量子系统的高维性，这引起了量子计算/量子机器学习研究者的兴趣。在这里，我们讨论了围绕 QML 知识产权（IP）的安全漏洞、攻击向量以及性能和可靠性问题。
