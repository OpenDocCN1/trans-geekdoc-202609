
# 扩散模型理论与实现

## 后验分布的高斯性质

注意，真实后验 `q(x_{t-1}|x_t)` 在计算上是不可处理的，因为必须积分掉对 `x_0` 的依赖，而相应的分布是未知的。然而，在给定 `x_0` 的条件下，它变为高斯分布（参考文献 [85] 和 Problem 19.7），即：

```
q(x_{t-1}|x_t, x_0) = N(x_{t-1} | μ̃_t(x_t, x_0), β̃_t I)
```

(19.61)

其中：

$$

\widetilde{\boldsymbol{\mu}}_t(\mathbf{x}_t, \mathbf{x}_0) = \frac{\sqrt{\overline{\alpha}_{t-1}}\beta_t}{1 - \overline{\alpha}_t}\mathbf{x}_0 + \frac{\sqrt{\alpha_t}(1 - \overline{\alpha}_{t-1})}{1 - \overline{\alpha}_t}\mathbf{x}_t \tag{19.62}

$$

和

$$

\widetilde{\beta}_t = \frac{1 - \overline{\alpha}_{t-1}}{1 - \overline{\alpha}_t}\beta_t \tag{19.63}

$$

其中 $\overline{\alpha}_t$ 之前已定义（公式 (19.58)）。

因此，$L_{t-1}$ 中的 KL 散度可以根据关于高斯分布的通用结果以闭式形式计算。^(¹⁴³)

$$

\text{KL}(p_{1}||p_{2}) = \frac{1}{2}\left\lbrack {(\mathbf{\mu}_{2} - \mathbf{\mu}_{1})}^{T}\Sigma_{2}^{- 1}(\mathbf{\mu}_{2} - \mathbf{\mu}_{1}) + \text{trace}\left\{ \Sigma_{2}^{- 1}\Sigma_{1} \right\} - \ln\frac{|\Sigma_{1}|}{|\Sigma_{2}|} - l \right\rbrack,

$$

![Equation](img/si552.png)(19.64)

*   其中 $|\\cdot|$ 表示相应的行列式。现在让我们做一个简化假设，这稍后也将很有用。假设反向路径中条件分布的协方差矩阵是对角的、预先固定的且独立于 `$\\boldsymbol{\\theta}$`，例如，

$$\\boldsymbol{\\Sigma}_{\\boldsymbol{\\theta}}(\\mathbf{x}[t], t) = \\sigma[t]^{2}\\mathbf{I}.$$

![Equation](img/si554.png)(19.65)

*   然后，很容易看出结合公式 (19.66)、(19.68) 和 (19.69)，我们得到

$$

\text{KL}\left( q(\mathbf{x}_{t - 1}|\mathbf{x}_{t},\mathbf{x}_{0})||p_{\mathbf{\theta}}(\mathbf{x}_{t - 1}|\mathbf{x}_{t}) \right) = \frac{1}{2\sigma_{t}^{2}}||{\widetilde{\mathbf{\mu}}}_{t}(\mathbf{x}_{t},\mathbf{x}_{0}) - \mathbf{\mu}_{\mathbf{\theta}}(\mathbf{x}_{t},t)||^{2} + C,

$$

![Equation](img/si555.png)(19.66)

*   其中 `C` 是一个与 `θ` 无关的常数，且 `|| ⋅ ||` 表示欧几里得范数。因此，训练的目标变为估计 `θ`，以便在欧几里得范数的意义上，将模型条件分布的均值 `μ_θ` 尽可能“推”向 `μ̃_t`。

*   在实践中，通常采用一个由 `θ` 参数化的神经网络，例如 `f_θ(⋅)`，其输入包含 `x_t` 的样本，并对其进行训练，使其输出 `μ_θ(x_t, t) := f_θ(x_t)` 在欧几里得范数的意义上接近目标 `μ̃_t(x_t, x_0)`。换句话说，训练任务变得等同于一个非线性回归问题。如果协方差矩阵不是固定的而是参数化的，类似的论点也成立，[169]。

*   **L₀**：该项可解释为重构项，用于预测给定第一步潜在变量条件下原始数据样本的对数概率。该项在公式 (19.22) 的 VAE 中扮演相同角色。由于条件分布的高斯性质，该分量也可用闭式计算。对于公式 (19.69) 的情况，显而易见，最小化 **L₀** 等同于强制 **μ_θ(x₁, 1)** 在欧几里得范数意义上接近 **x₀**。

代价函数通过对所有观测值取平均获得，即 **𝔼[x₀ ∼ q(x₀)][L[x₀]]**，在实践中通过对所有观测输入样本取样本均值得到。

## 简化模型

前文引入的模型简化，即 **Σ_θ(x[t], t) = σ[t]²I**，在文献 [85] 中得到了进一步利用。序列 **σ[t]²** 有不同的可能选择。一种可能是设定 **σ[t]² = β[t]**，这使得反向路径涉及的协方差矩阵等于前向过程涉及的协方差矩阵。该假设导出公式 (19.70)，训练简化为调整时间步 *t* 神经网络的输出 **μ_θ(x[t], t)** 以预测 **μ̃_t(x_t, x_0)**。现在让我们详细阐述一下公式 (19.70)。

结合公式 (19.59) 和 (19.66) 并经过一些代数运算（习题 19.8），可得

```
μ̃_t(x_t, x_0) = (1/√a_t) (x_t - (β_t/√(1 - ā_t)) ε)
```

![Equation](img/si567.png) (19.67)

其中 `ϵ` 是从标准高斯分布中抽取的噪声样本向量，用于获得 `x_t`（公式 (19.59)）。回顾一下，训练的目标是估计 `μ_θ`，以便在给定样本 `x_t` 作为相关神经网络输入的情况下，最优地预测公式 (19.71) 中对应的 `μ̃_t`。因此，在文献 [85] 中，建议使用以下重参数化，

```
μ_θ(x_t, t) = (1 / √a_t) (x_t - (β_t / √(1 - ā_t)) ε_θ(x_t, t))
```

![Equation](img/si568.png) (19.68)

其中 `ε_θ(x_t, t)` 是一个函数逼近器（通过神经网络实现），旨在根据 `x_t` 预测公式 (19.71) 中的 `ϵ`。将公式 (19.71) 和 (19.72) 代入公式 (19.70)，可得

```
L_{t-1} = λ_t ||ε - ε_θ(x_t, t)||²,    λ_t := β_t² / (2 σ_t² a_t (1 - ā_t))
```

![Equation](img/si570.png) (19.69)

其中 `x_t` 是根据公式 (19.59) 采样得到的，`λ_t` 是一个加权序列。

请注意，尽管 `λ[t]` 保证了最优性，但在实践中，对于某些时间步 `t`，它可能会取得相对较大的值（回想一下 `σ[t]² = β[t]`）。文献 [85] 指出，设置 `λ[t] = 1` 可获得良好的性能。对于加权序列，也提出了其他更“花哨”的选择，参见例如 [37]。

待最小化的代价函数源自公式 (19.64) 中的界，在对所有观测值 `x[0]` 取期望之后得到。此外，请注意，关于 `q(x[t]|x[0])` 的条件期望等同于根据公式 (19.59) 对 `p(ϵ) = N(ϵ|0, I)` 取期望。因此，对于简化模型的情况，第二个分量对代价的贡献变为

```
∑_{t=2}^{T} E_{x_0 ~ q(x_0)} E_{ϵ ~ N(0,I)} [ λ_t || ϵ - ϵ_θ(x_t, t) ||² ]
```

(19.70)

其中 `x[t]` 根据公式 (19.59) 用 `ϵ` 表示。在实践中，期望由样本均值代替。文献 [85] 建议，不必对时间 t 求和各项，而是可以使用均匀采样在 `[1, T]` 中随机选择一个时间索引，并基于对应的项执行参数更新。关于噪声的第二个期望由单个样本近似。算法 19.4 总结了训练步骤。术语 `f_θ(·)` 表示参数化神经网络的输出。

### 算法 19.4：训练 DDP 模型

**重复**

1. `x[0] ~ q(x[0])`；新的输入观测值。
2. `t ~ U[1, T]`；均匀离散分布。
3. `ϵ ~ N(0, I)`；从标准高斯分布采样。

#### 扩散模型训练算法步骤

4.  **前向过程采样**：

    $$

    \mathbf{x}_t = \sqrt{\bar{\alpha}}_t \mathbf{x}_0 + \sqrt{1 - \bar{\alpha}_t} \boldsymbol{\epsilon}

    $$

    在时间步 $t$ 生成带噪样本（公式 19.59）。

5.  **神经网络预测**：

    $$

    \boldsymbol{\epsilon}_{\boldsymbol{\theta}}(\mathbf{x}_t, t) = f_{\boldsymbol{\theta}}(\mathbf{x}_t)

    $$

    输出神经网络对噪声的预测。

6.  **计算梯度**：

    $$

    \Delta \boldsymbol{\theta} = \nabla_{\boldsymbol{\theta}} \|\boldsymbol{\epsilon} - \boldsymbol{\epsilon}_{\boldsymbol{\theta}}(\mathbf{x}_t, t)\|²

    $$

    计算参数梯度。

7.  **参数更新**：

    $$

    \boldsymbol{\theta}_{\text{new}} = \boldsymbol{\theta}_{\text{old}} - \mu \Delta \boldsymbol{\theta}

    $$

    使用学习率 $\mu$ 更新参数。

*   **直到收敛**

## 采样过程（反向过程）

训练通过任意反向传播类算法执行。一旦训练完成并获得最优参数 $\boldsymbol{\theta}^*$，即可通过反向过程生成样本。反向路径采样的核心围绕公式 (19.61) 及其重参数化展开，得到：

$$

\mathbf{x}_{t-1} = \boldsymbol{\mu}_{\boldsymbol{\theta}^*}(\mathbf{x}_t, t) + \sigma_t \mathbf{z}

$$

(19.71)

其中 `z` ∼ 𝒩(0, I)，且 `μ_θ*[x]` 由公式 (19.72) 给出。然而，现在样本 `x_t` 是通过反向过程中的采样生成的。对于步骤 `t = 1`，我们将样本 `x_0` 设置为等于 `μ_θ*(x_1, 1)`；请参阅文献 [85] 中的相关讨论，同时也回顾一下，在训练期间 `x_0` 是后者均值的目标值（公式 (19.64) 中的项 `L_0`）。算法 19.5 总结了这些步骤。

### 算法 19.5：DDPM 反向过程的采样

*   `x_T` ∼ 𝒩(0, I)；从标准高斯分布中采样。
*   **对于** `t = T, T − 1, …, 2`，**执行**
    1.  `z` ∼ 𝒩(0, I)；从标准高斯分布中采样。
    2.  `x_{t-1} = (1/√a_t)(x_t - β_t/√(1 - ā_t) ε_θ*(x_t, t)) + σ_t z`；公式 (19.75)
*   **结束循环**
1.  $x_0 = \underset{\mu_{\theta_*}(x_1,1)}{\underbrace{\frac{1}{\sqrt{a}_1}\left( x_1 - \frac{\beta_1}{\sqrt{1 - \bar{a}_1}} \right)\epsilon_{\theta_*}(x_1,1)}}$
    *   返回一个新样本 **x**[0]。

### 备注 19.12

*   正如文献 [85] 所指出的，将公式 (19.73) 中的 $\lambda_t$ 设为 1 等同于优化一个*加权*变分近似下界，这会降低与较小 $t$ 值相关项的贡献。这些项源自包含少量噪声的扩散输入样本。因此，对它们给予相对较少的关注有助于优化算法专注于对应较大 $t$ 值的噪声更大的版本。
*   对公式 (19.58) 中高斯分布的对数求梯度，不难发现

    ```
    ∇_{x_t} q(x_t | x_0) = - (x_t - √(ā_t) x_0) / (1 - ā_t) = - ε / √(1 - ā_t).
    ```

用文字表述，在训练 `ϵ_θ(x_t, t)` 以最优估计样本 `ϵ` 的同时，它隐式地提供了负梯度的估计，乘以相应的标准差，即 `- √(1 - ā_t) ∇_{x_t} q(x_t | x_0)`。我们将在第 19.7.3 节回到这一点。

# 19.7.2 神经网络实现

训练的目标是学习神经网络的参数，记为 `f_θ(·)`。网络的输入是前向过程中生成的相应潜在（扩散）变量的样本 `x_t`，`t = 1, 2…, T`。网络经过训练，使得在每个时间步，相应的输出能预测关联的目标。例如，对于 `t > 1`，输出-目标对为 `(μ_θ(x_t, t), μ̃_t(x_t, x_0))` 或 `(ϵ_θ(x_t, t), ϵ)`。

定义神经网络的参数 `θ` 由*所有*时间步*共享*。原则上，任何输入和输出维度相同的神经网络都可以使用。然而，在实践中使用的最流行架构之一是 U-Net [158] 或其变体。扩散网络背景下 U-Net 的框图示意见图 19.24。图中的每个块代表网络的一个阶段。U-Net 是一种卷积网络（第 18.12 节），采用收缩路径后接扩展路径，形似 U 字形。换句话说，网络每个阶段的输出特征图通过下采样，尺寸变得越来越小，直到某个最小值。然后，以与下采样对称的方式进行上采样。U-Net 的一个关键特性是存在跳跃连接（图 19.24 中的虚线），将信息从下采样阶段传递到相应的上采样阶段。可以将收缩路径视为编码器。图中间的最小尺寸特征图（块 #5）编码/学习“驻留”在输入数据中的信息，这对相关预测任务很重要，参见例如 [168]。U-Net 的输入和输出具有相同的维度。

![Figure 19.24 A typical variant of the U-Net used in diffusion networks: U-Net accepts as input the noisy images, xt (e.g., of dimensions 128 × 128), and outputs predictions, ϵθ(xt,t), of the same dimensions (e.g., 128 × 128). The U-Net consists of a contracting path of residual convolutional layers followed by an expansive one (U-shape). As the size of the feature maps keeps decreasing (increasing) the number of channels keeps increasing (decreasing). Feature maps from the contractive path are copied and concatenated with feature maps in the expansive path (dotted lines). The bottom line indicates the time positional vector embedding, which is passed to the convolutional layers after appropriate projections to match the dimensions of the corresponding computed feature maps.](img/gr024.jpg)

#### 图 19.24 扩散网络中使用的典型 U-Net 变体

U-Net 接受带噪图像 `x_t` 作为输入（例如尺寸为 128 × 128），并输出相同尺寸的预测值 `ϵ_θ(x_t, t)`（例如 128 × 128）。U-Net 由残差卷积层的收缩路径和随后的扩展路径组成（呈 U 形）。随着特征图尺寸不断减小（增大），通道数不断增加（减小）。来自收缩路径的特征图被复制并与扩展路径中的特征图拼接（虚线）。底部的线条表示时间位置向量嵌入，经过适当的投影以匹配相应计算出的特征图维度后，被传递给卷积层。

收缩路径中的每个块由两个连续的残差卷积层（例如 3 × 3 卷积）组成，后接一个 ReLU 激活函数和一个下采样操作。后者通过池化操作（2 × 2 最大池化）执行。在每个下采样步骤中，计算出的特征图每个维度的大小减半，而特征通道数翻倍。因此，以图中的情况为例，假设输入图像为 128 × 128，块 #1 计算出 16 个尺寸为 128 × 128 的特征图（通道）。经过下采样后，这些特征图尺寸减小至 64 × 64，并作为输入提供给块 #2。块 #2 计算出 32 个尺寸为 64 × 64 的特征图，经过下采样后尺寸减小至 32 × 32，成为块 #3 的输入。遵循这一逻辑，块 #3 计算 64 个尺寸为 32 × 32 的特征图，块 #4 计算 128 个尺寸为 16 × 16 的特征图，中间的块 #5 输出 256 个尺寸为 8 × 8 的特征图。
