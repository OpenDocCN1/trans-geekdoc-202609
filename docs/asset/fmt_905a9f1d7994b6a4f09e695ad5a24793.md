# 第 3 章

安全 ICS 架构

## 简介

在上一章中，您了解了用于构建基本*运营技术 (OT)*网络结构的组件。本章将以这些基本信息为基础，解释这些组件是如何组织起来以生成安全的 OT 网络架构。这将涉及两个主要主题领域：

* 网络分段与安全分区
* 无线安全

如前所述，生产工厂的最佳*网络安全设计*是将 OT 网络和 IT 网络在逻辑和物理上都相互隔离，且不提供从互联网通往 OT 网络的路径。这将降低远程攻击者通过 IT 网络访问 OT 网络所带来的风险。

一个隔离的工业过程控制网络通常是一个相对安全可靠的网络环境。威胁通常仅限于自然和人为事故、物理访问攻击，以及不满员工相关的恶意活动。这些网络通常与互联网没有连接，而互联网是众多潜在威胁的来源。此外，它们基于的设备和软件，知晓并精通这些技术的人员比企业界的对应技术要少得多。

当在 ICS 运营技术与企业 IT 网络之间建立连接时，OT 网络的风险等级会显著增加。这是由于 IT 网络及其互联网连接向 OT 网络呈现了额外的攻击向量。因此，对于互联的 OT 和 IT 网络，通常采用的最佳安全选项是将企业 IT 网络与 OT 网络之间的网络连接限制在单一接触点，如图 3.1 所示。

![图 3.1 连接 OT 和 IT 网络](img/c03f001.png)

**图 3.1** 连接 OT 和 IT 网络

IT 功能已成为 OT 网络不可或缺的一部分，以提供关键接口和交互。IT/OT 网络互操作性正越来越多地被用于通过监控、记录保存、维护、规划和工作调度来最大化流程生产力。当然，与这些扩展/集成网络相关的网络威胁也在同步增加。

## 边界防护

随着行业持续推进 IT/OT 互联，目标变为在两个网络之间建立*边界防护*，允许所需信息在网络间移动，同时保护 OT 网络免受 IT 网络、非 ICS 人员和互联网相关威胁的侵害。

幸运的是，企业网络环境已经创建了许多可用于此目的的边界防护设备和技术。这些设备和技术包括：

* 访问控制策略
* 网关
* 路由器
* 防火墙
* 入侵检测系统 (IDS)
* VLAN
* 加密与隧道
* 杀毒软件和反恶意软件产品
* 网络隔离与分段技术
* DMZ（非军事区）
* 代理

列表中提到的所有项目都可以且应该应用于保护 ICS 免受外部世界的威胁。

### 防火墙

互联网段之间最常见的第一道防线是*防火墙*。这些设备由硬件和软件组合而成，用于控制不受信任或安全性较低的网络与受保护网络之间的网络流量。这是通过监控网络流量并对其应用访问规则来实现的，以允许授权流量通过。

防火墙可以通过各种方式在不同的网络布局中实现。防火墙可能是专用的*硬件防火墙设备*，也可能是内置在路由器或交换机中的功能，或者是实现在具有多个以太网接口的计算机中。它甚至可以是像其他应用程序一样安装在主机计算机上的纯*软件防火墙*。许多网络设备提供防火墙和安全功能，以及其他网络功能。

在企业或工业网络环境中，IT 管理员控制防火墙的安装和配置。网络防火墙的优势在于，它使管理员能够控制流向其网络上所有连接设备的信息流，如图 3.2 所示。

![图 3.2 网络防火墙](img/c03f002.png)

**图 3.2** 网络防火墙

用于 OT 环境的防火墙通常是专门构建的，用于专门监控 OT 流量，并允许或拒绝进入 OT 或其子网的流量。许多 IT 防火墙供应商在其产品中提供 OT 专用功能。使用防火墙进行 OT 安全的主要挑战在于实施适当的防火墙规则，以提供特定环境所需的保护。

防火墙通常充当网关设备，对网络应用程序和协议进行身份验证并授予访问权限。它们也可以配置为充当代理服务器、提供网络地址转换，并充当 DHCP 服务器。防火墙通常不仅过滤入站流量，还过滤出站流量。

配置好的防火墙将使用定义的规则提供*数据包过滤*，以拒绝或接受入站和出站数据包。这配置起来可能更具挑战性，但有效的*防火墙规则*对大多数网络的安全至关重要。

*数据包过滤防火墙*可以通过路由器建立，方法是配置数据包过滤规则，根据源地址、目的地址或端口号等因素允许或拒绝客户端访问。有两种类型的数据包过滤防火墙需要考虑：*静态数据包过滤*和*有状态数据包过滤*。

*静态*或*无状态数据包过滤防火墙*不跟踪两个设备之间连接的状态。它们的运作方式与任何*访问控制列表 (ACL)*大致相同。这使得这类防火墙比其他防火墙选项稍快一些。它们也往往相对便宜且易于维护。相反，静态数据包过滤防火墙提供的安全功能比其他防火墙选项少。

*有状态数据包过滤防火墙*确实跟踪实体之间的连接状态。这些防火墙收集网络连接信息并维护*动态状态表*，用于后续连接。如图 3.3 所示，这使得端口可以根据需要打开和关闭。一旦客户端完成通信会话，有状态数据包过滤防火墙就会关闭所用的特定端口，直到再次被请求。

较新的防火墙还将提供*服务质量 (QoS)*功能，允许根据特殊规则或策略对网络流量进行优先级划分和差别化处理。QoS 的一个常见用途是确保 VoIP 电话系统始终拥有足够的带宽用于电话服务，无论网络多么繁忙。

某些应用程序对延迟更为敏感，使用 QoS 可以确保这些应用程序始终拥有足够的优先级以维持数据包流向它们，从而防止连接中断。QoS 也可以是在繁忙网络上公平共享或分配带宽的一种方式。某些防火墙会将这种流量管理与 QoS 分开，但它们是相似的概念。

较新的防火墙被称为*下一代防火墙*（*NGFW*），它们是将传统防火墙的功能（数据包过滤、状态检测和 VPN 感知及其他功能）与*深度包检测*（*DPI*）、内置入侵防御系统、来自外部来源的威胁情报以及应用程序感知/控制相结合的网络设备。

防火墙通常部署在 OT 和 IT 网络之间，以限制过程控制设备与组织企业网络计算系统之间的流量。将防火墙放置在此位置提供了两个重要功能：安全性和性能提升。防火墙可配置为对进入和离开 OT 网络的数据包移动提供高度控制。这反过来又减少了网络上非必要流量的水平，从而允许期望流量获得更高的吞吐量。本地防火墙可以安装在单个控制设备上（或其前端）。

安装边界保护设备时，应始终将其配置为默认拒绝所有流量，然后实施 `whitelisting` 策略，仅 `allow` 例外情况下所需的连接和流量。通常，这涉及防止授权与未授权的源/目的地址对之间的通信。

用于边界保护服务的防火墙应始终配置为根据源/目的地址、端口和服务阻止所有未经授权的通信。

您还应注意，配置不当的防火墙可能会向 OT 网络通信中注入延迟，这可能会对其控制功能产生不利影响。虽然这在 IT 网络中通常不易察觉，但在 OT 网络中却可能造成灾难性后果。必须小心配置与 OT 网络关联的防火墙，使其不会给通信增加任何绝对必要之外的流量负担。

### 使用非军事区

某些组织将其网络的一部分专门用于一种称为*非军事区*或*DMZ*的安全结构。DMZ 是一个独立的边界网络，它将一个网络与另一个网络隔离开来，同时允许访问面向外部的专用资源。图 3.7 显示了典型的 DMZ 实现。

![FIGURE 3.7 A DMZ](img/c03f007.png)

**图 3.7** DMZ

如图所示，选定的服务器和其他资源被放置在 DMZ 中。这些资源被称为*堡垒主机*。堡垒主机可以是防火墙、路由器、服务器，或一组未受另一防火墙保护的计算机。

DMZ 通常用于在企业网络和 OT 网络之间提供隔离。DMZ 在两种网络类型之间创建了一个中立区域，根据组织的安全策略规范，限制企业网络与外部的信息交换。

企业网络需要访问的任何 ICS 服务器都应放置在 OT/IT DMZ 中，并且只有这些服务器应可从企业网络访问，如图 3.8 所示。防火墙中打开的端口应仅为企业网络所需特定通信绝对必需的端口。

![FIGURE 3.8 Minimum ICS/IT network connectivity](img/c03f008.png)

**图 3.8** 最小 ICS/IT 网络连接

对 DMZ 的访问由一个或多个防火墙控制。在*单防火墙 DMZ*中，如图所示，防火墙必须是一个*多宿主*设备，能够提供三个独立的网络接口：

* 一个用于企业网络的接口
* 一个用于 ICS 网络的接口
* 一个用于 DMZ 网络的接口

多宿主单防火墙 DMZ 通常优于其他安全结构，因为它们的实施成本相对较低。然而，在这种配置中，防火墙会成为整个网络的单点故障。如果防火墙被攻破，攻击者就获得了对整个网络的访问权限。只需要一个配置不当、留有开放端口的防火墙即可遭受攻击。

在*双防火墙 DMZ*中，如图 3.9 所示，防火墙位于 DMZ 的两侧，用于过滤内部网与 DMZ 之间以及 DMZ 与互联网之间移动的流量。这些防火墙用于将公共流量路由到 DMZ，将内部网络流量路由到内部网。

双防火墙 DMZ 配置提供了更高级别的安全性，因为攻击者必须攻破多个设备才能危及内部网。如果他们成功攻破了第一个防火墙，他们只能获得对 DMZ 中面向公共资源的访问权限。

![FIGURE 3.9 A dual firewall DMZ](img/c03f009.png)

**图 3.9** 双防火墙 DMZ

所有发往 ICS 的入站流量都应通过 DMZ 路由。ICS 防火墙还应配置为提供出站过滤，以防止伪造的 IP 数据包离开 DMZ。回想一下，伪造通信常用于 DoS 攻击。防火墙必须配置为检查出站数据包，以确保其 `source IP addresses` 符合 DMZ 的要求。如果不符合，则丢弃该数据包。

### 代理

## 代理服务器

`proxy` 是一种屏障，可防止外部人员进入局域网，并防止内部人员直接连接到外部资源，如图 3.10 所示。相反，它允许客户端建立通过它路由的间接网络连接。客户端连接到代理服务器，可能需要有意识的身份验证，也可能不需要，并请求来自另一台服务器的资源。代理服务器将通过从其自身的缓存副本返回请求的资源，或将请求转发给另一台服务器（在可能修改请求之后）来处理该请求。

![图 3.10 代理服务器的操作](img/c03f010.png)

**图 3.10** 代理服务器的操作

发送到互联网的所有寻址信息都将使用代理服务器的 IP 地址。由于未使用请求资源的客户端的 IP 地址，外部入侵者无法访问本地主机。

代理过滤是一个比数据包过滤复杂得多的过程。在此过滤过程中，每个数据包都会被拆解、评估并重新组装，这使得这种类型的连接比其他防火墙类型慢得多。代理过滤防火墙被配置为查看完整的数据包，以检查一致性、应用程序类型和适当的端口。试图通过这些端口传输到客户端的数据必须与代理过滤防火墙的预期相匹配，否则未知数据包将被丢弃，连接将中断。

如图 3.11 所示，可以安装代理服务器，通过充当中介来隔离 OT 网络与企业网络产生的外部请求，从而提供边界保护。代理阻止了对 OT 网络的直接连接，并处理确定哪些被请求的资源应被处理的任务。

![图 3.11 使用代理服务器进行边界保护](img/c03f011.png)

**图 3.11** 使用代理服务器进行边界保护

`纵深防御策略` 是指包含多种不同的重叠安全机制，可将攻击者攻破单一机制的影响降至最低。在本章后续章节中，您将了解 IT 和 OT 环境中的安全分区概念。这些概念最终将构建成 `Purdue ISA-95 参考架构`。这些概念将扩展以包含 `IIoT` 和 `云服务` 变体。

除了这些示例中描述的 DMZ、路由器和防火墙外，IT 和 OT 网络都应采用下一节讨论的安全拓扑策略之一，以最大化整体纵深防御策略。

### 安全拓扑

如前所述，OT 和 IT 网络的意图和操作截然不同。OT 系统需要 `实时数据`，而 IT 网络则不需要。OT 网络关注可用性、完整性，然后是机密性 (AIC)，而 IT 网络旨在首先提供机密性，其次是完整性，最后是可用性 (CIA)。

同样，在这两个网络上进行的活动类型从根本上讲是相互对立的。IT 网络旨在创建、存储和操作数据，而 OT 网络旨在提供实时测量和控制功能。

当 IT 环境中发生延迟时（例如屏幕上显示 Windows 沙漏在旋转），用户生产力会下降。然而，如果类似的延迟发生在 OT 环境中，后果将不堪设想：

* 生产中断。
* 产品不符合质量标准，必须报废。
* 生产设备损坏或毁坏。
* 人员受伤或死亡。

IT 企业网络通常比其 OT 对应网络代表大得多的安全风险。OT 网络倾向于运行在比 IT 网络使用的更冷门的设备、操作系统、应用程序和网络上。此外，历史上 OT 网络从未以任何方式连接到公共互联网。

由于 OT 网络的 AIC 特性，必须小心不要向该网络部分引入会在需要时延迟数据移动和访问的安全功能。这包括添加防病毒/反恶意软件产品、缓慢的防火墙/代理服务，或入侵检测/防御 (IDS/IPS) 设备和服务等典型的企业措施。然而，有许多方法可以使连接网络的 IT 侧更安全，从而使 OT 网络更安全。

安全的 IT 网络设计通常将网络段组织成多层安全结构。刚才介绍的每种网络安全结构都可能是给定组织网络设计的一部分。此外，组织网络的某些部分（如其内部网）可能根据与每个段相关的安全需求细分为多个段。

连接到网络的所有智能设备都必须具有能够将设备连接到网络传输介质的 `网络接口适配器`。这包括提供插头和插座等物理连接方案，以及提供设备与跨传输介质（电缆或无线电波）传输的信号之间的电气兼容性。

此外，网络通常包含其他 `连接设备`，用于将网络的不同部分连接在一起并执行不同的网络管理功能。这些连接设备通常是交换机或路由器。在大型或复杂的网络中，您可能还会发现称为 `网桥` 的设备，用于互连网络的各个部分。

虽然每个设备都提供物理连接，但它们也各自具有特定的操作方法，使其适合用于特定的网络应用。在某些情况下，功能更多的设备可用于执行功能较少的设备的功能。

### 网络交换机

`网络交换机` 是在 OSI 模型第 2 层运行的连接设备。^(\*) 它们旨在将 `网络设备` 连接在一起以形成局域网。`企业网络` 通常采用交换机组合来分割网络并建立高效的数据流量。它们可以与其他网络连接设备结合使用，也可以通过主干布线直接连接到服务器室。

例如，一家跨越办公楼多层的公司可能会在每层楼使用单独的交换机，为该楼层的所有设备提供连接。各楼层的交换机也将通过交换机或路由器相互连接。图 3.12 显示了典型的网络交换机连接方案。

交换机收集 MAC 地址信息以跟踪连接到它们的设备。当它们与这些设备交互时，会将其 MAC 信息记录在一个称为 `MAC 地址表` 的板载内存结构中。

当交换机在其某个 `端口` 接收到网络信息包时，如果知道接收者的地址，它可以将该信息定向发送给预期的接收者。如果地址未知，交换机将向其所有端口 `广播` 该信息。由于通过交换机传输的信息通常仅发送到预期端口，因此整个网络的性能得到了极大提高。

## 交换机和 VLAN

交换机还可用于创建逻辑上安全的 `虚拟局域网` (`VLAN`)。`VLAN` 是一种安全拓扑，通过限制网络数据包的移动，使其仅在指定端口之间传递，从而限制网络流量的可见性。

网络交换机通常根据其配置选项分为两类。`非托管交换机` 是 `即插即用` (`PnP`) 设备，不包含任何用户配置选项。这些设备通常价格低廉，旨在用于家庭和小型办公室环境，因此极少在企业 IT 网络中发现。
