## NumPy 索引矩阵生成与卷积索引计算

### 基础索引生成

```python
import numpy as np

kH, kW = 2, 2

i0 = np.repeat(np.arange(kH), kW)  # 行下标 [0,1] 沿列方向重复：[0,0,1,1]
print(i0)

j0 = np.tile(np.arange(kW), kH)    # 列下标 [0,1] 沿行方向拼接：[0,1,0,1]
print(j0)
```

输出结果：

```
[0 0 1 1]
[0 1 0 1]
```

利用 `i0` 和 `j0` 的组合索引，可以获得左上角数据块的元素。

### 索引矩阵构造函数

```python
def idx_matrix(H, W):
    a = np.empty((H, W), dtype='object')
    for i in range(H):
        for j in range(W):
            a[i, j] = str(i) + str(j)
    return a
```

以 4×4 矩阵 `x` 为例：

```python
x = idx_matrix(4, 4)
print(x)
print(x[i0, j0])
```

输出结果：

```
[['00' '01' '02' '03']
 ['10' '11' '12' '13']
 ['20' '21' '22' '23']
 ['30' '31' '32' '33']]
['00' '01' '10' '11']]
```

### 多通道数据块索引

对于多通道数据块，每个通道对应元素的行、列下标相同。以 2 通道左上角数据块为例（如图 6-49 所示）。

**图 6-49** 通道 2 左上角数据块的行列下标

一般地，对于通道数为 `C` 的左上角数据块，其元素的行列下标可通过以下代码生成：

```python
i0 = np.repeat(np.arange(kH), kW)
i0 = np.tile(i0, C)
j0 = np.tile(np.arange(kW), kH * C)
```

当 `C=2` 时运行该代码：

```python

i0 = np.repeat(np.arange(kH), kW)
```

### 跨度坐标与完整索引计算

要生成原始数据张量中所有数据块元素的坐标，不仅需要知道每个数据块相对于其左上角 (0,0) 的行列下标，还需根据跨度 `S` 增加偏移量以获得最终正确的行列坐标。

若特征图被划分为 `oH × oW` 个数据块，这些数据块相对于左上角数据块的偏移称为**跨度坐标**。例如划分为 3×3 共 9 个数据块，当跨度 `S=1` 时，这 9 个数据块的行（高度）列（宽度）跨度坐标如下（如图 6-50 所示）。

**图 6-50** 跨度坐标

这些跨度坐标同样可使用生成数据块内元素行列坐标的代码来生成：

```python
oH, oW = 3, 3
i1 = S * np.repeat(np.arange(oH), oW)
j1 = S * np.tile(np.arange(oW), oH)
print(i1)
print(j1)
```

输出结果：

```
[0 0 0 1 1 1 2 2 2]
[0 1 2 0 1 2 0 1 2]
```
