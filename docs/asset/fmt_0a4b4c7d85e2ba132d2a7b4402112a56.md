#### `String` 对象的比较

比较 `String` 对象有两种方法：

**1.** 使用从 `Object` 类继承并重写以执行正确操作的 `equals` 方法：

```
if (string1.equals(string2)) ...
```

如果 `string1` 和 `string2` 是相同的字符串，则返回 `true`，否则返回 `false`。

**2.** 使用 `compareTo` 方法。`String` 类有一个 `compareTo` 方法：

```
int compareTo(String otherString)
```

它按字典（词典）顺序比较字符串：

- 如果 `string1.compareTo(string2) < 0`，则 `string1` 在字典中排在 `string2` 之前。
- 如果 `string1.compareTo(string2) > 0`，则 `string1` 在字典中排在 `string2` 之后。
- 如果 `string1.compareTo(string2) == 0`，则 `string1` 和 `string2` 相同。（此测试是 `string1.equals(string2)` 的一种替代方案。）

请注意 Java 区分大小写。因此，如果 `s1` 是 `“cat”` 而 `s2` 是 `“Cat”`，`s1.equals(s2)` 将返回 `false`。

字符根据其在 ASCII 表中的位置进行比较。你只需要知道所有数字排在所有大写字母之前，而大写字母又排在所有小写字母之前。因此 `“5”` 排在 `“R”` 之前，后者又排在 `“a”` 之前。两个字符串的比较方式如下：从每个字符串的左端开始，逐字符比较，直到到达两个字符串首次不同的字符，即第 *k* 个字符。如果 `s1` 的第 *k* 个字符排在 `s2` 的第 *k* 个字符之前，则 `s1` 排在 `s2` 之前，反之亦然。如果字符串的字符完全相同，只是 `s1` 比 `s2` 先结束，则 `s1` 排在 `s2` 之前。以下是一些示例：
