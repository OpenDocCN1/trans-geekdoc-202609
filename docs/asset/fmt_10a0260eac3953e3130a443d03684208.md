
验证技术如`hold-out`和交叉验证（见第 4 章）可以用于引导模型选择，但它们需要适应无监督设置（具体而言，对于聚类模型没有新的数据误差 `$E_{pp}$`）。例如，对于作为概率生成式模型的`GMM`，可以使用留出验证集来找到合适的的 `$M$` 值。也就是说，我们留出不用于模型聚类的验证数据 `x_val`。然后，我们在剩余数据上对若干个不同的 `$M$` 值训练不同的模型，并评估每个候选模型中的留出似然 `p(x_val^i)_{i=1}^n|\hat{\theta})`。最后选择最佳留出似然的模型作为最终的聚类模型。

这为我们提供了一种选择 `$M$` 的系统方法；然而，在预测模型的无监督背景下，最小化数据（预测）误差通常是模型的最终目标，因此基于此进行评估是有意义的。在聚类背景下，我们想要的并不一定是最小化新数据上的“聚类损失”。此外，聚类通常被用于通过寻找少数几个簇（每个簇内的数据点具有相似特征）来获得有关数据的见解。因此，只要模型对数据点产生了连贯且有意义的分组，即使后者的验证损失更好，我们也倾向于选择较小的模型而非较大的。

## 10.3 深度生成模型

为了给非高斯模型奠基础，让我们使用简单的高斯分布：

```
$p(x) = N(x|\mu, \Sigma)$
```

该模型的参数是均值向量和协方差矩阵 `θ = {μ, Σ}`，它们可以通过极大似然法从训练数据 `{x_i}_{i=1}^n` 中学习。正如我们上面讨论过的，这引导我们通过样本均值估计 `μ`，通过样本协方差估计 `Σ`，但只有一个类别。

由于高斯随机向量的线性变换也是高斯分布，因此 (10.19) 的等效表示是引入一个样本为 `x` 的随机变量 `z`，它遵循生成分布：

```
$p_z(z) = N(z|0, I)$
```

然后通过线性变量替换表示 `x`：

```
$x = \mu + Lz.$
```

这里 `L` 是任何满足 `LL^T = Σ` 的矩阵。注意，在这种表示中，分布 `p_z(z) = N(z|0, I)` 采用了非常简单且通用的形式，与模型参数无关。

因此，我们感兴趣的问题可以表述为：给定来自分布 `p(x)` 的样本训练数据 `{x_i}_{i=1}^n`，学习该分布的参数化模型。

## 10 生成式模型与从无标记数据中学习

参数转移到了变换 (10.20b)。具体而言，我们可以使用另一种重参数化 `θ={μ, L}`，它直接定义了线性变换。模型 (10.19) 和 (10.20) 是等价的，我们尚未通过这种重构实现任何新东西。后者为我们提供了一个非线性泛化。具体而言，我们可以将 `x` 的分布建模为高斯随机变量的变换：

```
$p_{\theta}(z) = N(z|0, I)$,
$x = f_{\theta}(z)$,
```

其中 `f_θ` 是某个参数函数。注意，我们从高斯分布可以看出，由于非线性变换，`x` 的隐含分布将是非高斯的。事实上，通过考虑复杂且灵活的非线性变换，我们可以以这种方式对任意复杂的分布建模。

这种方法的挑战在于如何从数据中学习参数。遵循极大似然法，我们想要解决：

```
$$\hat{\theta} = \arg max p(\{x_i\}|\theta) = \arg max \sum_{i=1}^n \ln p(x_i|\theta)$$
```

因此，我们仍然需要*评估* `x` 的似然来学习参数，但该似然并没有在模型定义 (10.21) 中显式给出。

为了取得进展，我们首先假设 `f_θ: ℝ^p → ℝ^p` 是可逆函数，其逆函数为 `h_θ(x) = f_θ^{-1}(x) = z`。注意这个 `z` 与 `x` 维度相同。在此假设下，我们可以使用概率密度函数的变量换公式写成：

```
$p(x|\theta) = |\nabla h_{\theta}(x)| p_z(h_{\theta}(x))$,
```

其中

```
$\nabla h_{\theta}(x) = \begin{pmatrix} \frac{\partial h_{\theta}(x)}{\partial x_1} & \dots & \frac{\partial h_{\theta}(x)}{\partial x_p} \\ \vdots & \ddots & \vdots \\ \frac{\partial h_{\theta}(x)}{\partial x_1} & \dots & \frac{\partial h_{\theta}(x)}{\partial x_p} \end{pmatrix}$,
```

是 `h_θ(x)` 的所有偏导数的 `p × p` 矩阵，称为雅可比矩阵，而 `|∇ h_θ(x)|` 是其行列式的绝对值。将此表达式代入极大似然问题 (10.22)，我们就可以这样学习模型：

```
$$\hat{\theta} = \arg max \sum_{i=1}^n \ln |\nabla h_{\theta}(x_i)| + \ln p_z(h_{\theta}(x_i))$,
```

其中损失函数的两项都由模型定义 (10.21) 。这为我们提供了一个从数据中学习基于变换的生成模型的实用方法，尽管我们有以下观察：

- 1. 逆映射 `h_θ(x) = f_θ^{-1}(x)` 需要显式可用，因为它是损失函数的一部分。

- 2. 雅可比行列式 `|∇ h_θ(x)|` 需要是可计算的。在一般情况下，计算 `p × p` 矩阵行列式的（实际算法）计算开销随 `p` 的立方级增长。对于高维问题，这会导致难以巨大的巨大计算瓶颈，除非雅可比具有某些可以用来加速计算的特殊结构。

## 10.3 生成式模型

3. 正向映射 `f_θ` 不进入损失函数，因此原则上我们9可以在不显式定义该函数的情况下学习模型（只需知道它存在即可）。然而，如果我们想使用该模型从 `p(x)` 生成样本，那么也需要对正向映射进行显式评估。事实上，从模型 (10.21) 采样的方法是首先采样一个标准高斯分布 `z`，然后通过映射传播以获得样本 `x=f_θ(z)`。

设计既满足这些条件，又足够灵活以准确描述高维概率分布的参数化函数并非易事。通常会使用基于神经网络的模型，但为了满足可逆性和计算可行的性的要求，需要特殊的网络架构。这涉及例如，限制映射 `f_θ`，使其逆映射的雅可比矩阵变成三角矩阵，在这种情况下，行列式是容易计算的。

在利用神经网络设计这种基于变换的模型时，有一个观察是：为了确保网络每一层独立的可逆性和可行性，假设 `f(x)` 是可逆的具有 `L` 层，其中第 `l` 层对应于函数 `f^{(l)}: ℝ^p → ℝ^p`。我们可以写成 `f(x) = f^{(L)} ∘ f^{(L-1)} ∘ … ∘ f^{(1)}(x)`，其中 `∘` 表示函数的复合。这仅仅是数学上的捷径，表示一个 `L` 层网络的评估是通过首先找到层的逆，然后将结果传播到第二层，依此类推，直到我们获得最终输出 `L`。`f` 的逆通过反向应用逐层逆函数获得，`h_θ(x) = h_θ^{(1)} ∘ h_θ^{(2)} ∘ … ∘ h_θ^{(L)}(x)`，其中 `h_θ^{(l)}` 是 `f^{(l)}` 的逆。此外，通过微分式法则和行列式的乘法，我们可以雅可比表示为：

```
|\nabla f_{\theta}(x)| = \prod_{i=1}^{L} |\nabla h_{\theta}^{(i)}(x)|, \quad x^{(i)} = h_{\theta}^{(i+1)} \circ h_{\theta}^{(i+2)} \circ \dots \circ h_{\theta}^{(L)}(x).
```

这意味着只需要设计每个 `f^{(l)}` 使其可逆且具有可计算的雅可比。实现这一点有很多。我们可以通过堆叠多个层来构建更复杂的模型，计算成本随层数线性增长。利用这种属性的模型被称为归一流（normalizing flows）。其思想是数据点 `x` “流”一系列变换 `f^{(1)}, f^{(2)}, …, f^{(L)}`。

文献中提出了许多此类流架构，例如生成网络。

## 生成网络

生成网络的思想是使用判别器来评估合成样本的质量。在实际的学习算法中，引入人类来判断合成样本 x' 是不可行的。相反，生成网络的思想是学习一个辅助分类器来生成模型，它承担了游戏中判别器的角色。具体而言，我们使用一个二分类器 `g_φ(x)`，它接收一个数据点（以图像作为输入）并输出它是合成生成的概率，即

```
g_{\phi}(x) = p(y = 1|x).
```

这里，`φ` 表示辅助分类器的参数，它们与生成模型的参数 `θ` 不同。分类器按照常例学习，以最小化其分类损失：

```
\phi = \arg min_\phi [L(y, g_{\phi}(x'))].
```

其中期望值相对于上述过程生成的随机变量 `y` 和 `x'`。注意，这变成了一个监督二分类问题，标签是作为游戏的一部分被自动生成的。

## 10.3 深度生成模型

进入流程的第三步，我们希望更新定义生成模型的映射 `f_θ(z)`，使得生成的样本尽可能让判别器拒绝为伪造。在某种意义上，这是整个过程中最重要的一步，也是我们学习生成模型的地方。这是通过与辅助分类器的完成的，生成模型的目标是在 `θ` 上最大化分类损失 (10.27)。

```
$$\max_{\theta} \mathbb{E}[L(1, g_{\theta}(f(x)))] + \mathbb{E}[L(-1, g_{\theta}(x_i))]$$
```

这导致了一个所谓的极大最小问题（minimax problem），两个对抗者为了同一个目标竞争，一个试图最小化它，另一个试图最大化它。通常通过随机梯度优化交替更新 `θ` 和 `η` 来解决这个问题。我们在方法 10.4 中提供了此类算法的伪代码。

### 学习生成对抗网络

- **数据：** `T = {x_i}_{i=1}^n`，初始参数 `θ` 和 `η`，学习率和批量大小 `n_b`。

- **结果：** 生成模型 `f_θ(z)`

- repeat

  for `t = 0, …, T_critic` do

    从训练数据中采样小批量 `{x_i}_{i=1}^{n_b}`

    独立地从 `𝒩(0, I)` 采样小批量 `{z_i}_{i=1}^{n_b}`

    计算梯度 `ĝ_critic = Σ_{i=1}^{n_b} ∇_η L(1, g_η(f_θ(z_i))) + L(-1, g_η(x_i))`

    更新判别器：`η ← η - γ ĝ_critic`

  end

  从 `𝒩(0, I)` 独立采样小批量 `{x_i}_{i=1}^{n_b}`

  计算梯度 `ĝ_gen = Σ_{i=1}^{n_b} ∇_θ L(1, g_η(f_θ(z_i)))`

  更新生成器：`θ ← θ + γ ĝ_gen`

until convergence

### 从生成对抗网络中采样

- **数据：** 生成模型 `f_θ(z)`

- **结果：** 合成样本 `x'`

- 1 采样 `z' ~ 𝒩(0, I)`

- 2 输出 `x' = f_θ(z')`

从优化的角度来看，极大最小问题比解决纯最小化问题更具挑战性，因为相互竞争的力量可能导致振荡行为。人们已经对上述流程开发了许多修改和变体，其中为了稳定优化并获得高效的学习算法。尽管如此，这是使用生成对抗网络的缺点之一，例如，可以通过直接似然关系学习的归一化流——等等，可以通过直接似然关系学习的归一化流。相关的生成生成模型 `f_θ(z)` 它隐含了定义分布 `p(x|θ)`，它仍然可以用于评估某些新观测数据点 `x` 的似然性 `p(x|θ)`。访问这种显式似然性在某些应用中非常有用，例如，在学习到的模型 `p(x)` 下推断观测 `x` 的合理性。

## 10.4 表征学习与降维

深度生成模型 `x = f_θ(z)` 定义了观测数据点 `x` 与该数据点的某些潜在表示 `z` 之间的关系。“潜在”（隐藏）一词在这里指的是 `z` 并不被直接观测，但它仍然携带了关于数据的有用信息。给定映射 `f`（一旦建立了映射，只需知道潜在变量 `z` 就能重构数据点 `x`，只需计算 `x = f_θ(z)` 即可）。变量 `z` 通常也被称为（潜在）代码，而映射称为解码器，我们用它来重构数据。现代机器学习（特别是深度学习）的很大一部分都涉及到坐标 `x_i, i=1,...,p` 之间复杂的依赖关系。换句话说，在“原始数据空间”中，每个坐标 `x_i` 可能并不携带有用信息，但当我们把跨 `x` 的有意义模式组合时，这就是我们想要学习的。典型的例子是（再次）当 `x` 对应于图像时，单个像素值对于图像内容的信息量很小，但深度神经网络可以学习识别特征，并解决许多非平凡的任务。在自然语言处理中也可以找到类似的例子，其中 `x_i` 可能对应文本中的一个字符，但只有我们将所有字符组合成 `x`，才能理解文本的语义含义。通过这些例子，可以认为深度学习的成功归于其学习学习高维数据有用表征的能力。对于神经网络的监督学习（如第 6 章所述），表征学习通常是隐式的，并与分类同时进行。在这种情况下，我们对所谓的潜在表征没有明确的定义。与深度生成模型不同，如上述，潜在表征是模型的显式部分。然而，直接从数据学习表征的可能性并不是生成模型所有的。在本节中，我们将引入一种无监督学习方法，称为自编码器（auto-encoder）。自编码器通过将数据映射到低维潜在代码来实现降维。我们将从主成分分析（PCA）推导，并展示它如何被视为自编码器的一个特例。

### 自编码器

对于许多高维问题，假设数据的有效维度小于观测维度是合理的。也就是说，如果我们把数据压缩为 `q` 维表征 `z，p` 维的大部分信息可以被保留。例如，在生成对抗网络的语境下（见第 10.3 节），潜在变量 `z` 的维度可以远小于 `x`。在这种情况下，生成样本的有效维度是 `q`。我们能创建一个向另一个方向的映射吗？也就是说，如果我们取一个数据点 `x`，可以使用编码器 `z = h_θ(x)` 压缩其潜在表征。如果我们通过解码器输入该表征，将得到数据点的重构 `x̂ = f_θ(z)`。通常，这不会等同于 `x`，因为我们强迫编码器将数据压缩为低维表征。这通常会导致解码器无法补偿的信息损失。然而，我们可以通过最小化训练数据上的重构误差来让模型尽可能地近似恒等映射。例如，使用平方误差学习训练目标：

```
$$\min_{\theta} \sum_{i=1}^n \|x_i - f_{\theta}(h_{\theta}(x_i))\|^2$$
```

对于这种方法变得意义来说，`q < p` 是重要的，否则我们只是在学习一个恒等映射。然而，当 `q` 小于 `p` 时，它将鼓励编码器将数据压缩为低维向量，同时尽可能保留实际信息以实现准确重构。换句话说，编码器被强制学习数据的有用表征。

当使用网络参数化编码器解码器映射时，自编码器也可以看是一个神经网络，中间有一个“瓶颈层”来表示潜在代码。我们在图 10.10 中展示了这一点。
