
| 正确进行数据采样 | 通过正确的采样方法，我们可以获得对目标总体具有泛化能力的数据集；即我们的数据集与目标总体具有相同的趋势和特征。如果我们使用带有偏差的偏差训练样本，那么我们的模型也会产生偏差。使用高质量且可泛化的数据集来训练模型可以帮助我们避免过拟合。 |
| --- | --- |
| 获取大型数据集 | 训练预测模型需要大量数据，特别是某些机器学习算法需要大量数据才能正常工作。样本量较小的数据集可能导致模型拟合不佳。足够的样本量可以增加模型的解释力，特别是当模型中包含许多变量时。拥有大型数据集还允许我们将数据集拆分为多个子样本用于验证。然而，我们应该注意不要过度训练模型，否则会导致过拟合。 |
| 良好地清洗数据 | 训练模型需要干净的数据集。记住，“垃圾进，垃圾出”。我们的预测模型优坏取决于输入数据。包含过多噪声和无关信息的数据可能导致模型训练不佳，因为机器学习算法试图考虑所有的噪声和虚假信息，从而导致预测能力下降。我们应该仔细检查数据，纠正任何错误，并移除过度噪声和无关的预测变量。我们还应该处理缺失值和离群值，并在需要时移除具有过多缺失值或离群值的预测变量。数据清洗是数据挖掘中最耗时的步骤。它可能占整个项目时间的 60–80%。 |
| 正确地划分数据 | 将数据集划分为若干个子样本以训练和验证模型至关重要。通过使用正确的划分方法，我们可以确保这些子样本与原始数据集具有相同的趋势和特征。因此，我们可以最大限度地减少模型训练和验证过程中的偏差，从而避免过拟合。 |
| 保持数据的平衡 | 如我们之前讨论的，高度不平衡的数据集往往会导致过拟合，因为机器学习算法可能会将所有情况误认为负例。虽然预测准确率看起来足够高，但模型实际上未能预测出事件，这使其无效。使用不平衡的数据集是过拟合的主要原因之一。如果数据集不平衡，我们需要进行重采样以平衡响应比例。 |
| 使用多个模型拟合指标 | 有多个模型拟合指标，每个指标都衡量模型拟合的一个方面。如果我们依赖于某一个指标，结果可能会产生误导。通过使用使用多个指标，我们可以全面且正确地评估模型拟合情况，并制定改进它的策略。 |
| 使用成本敏感学习 | 在现实中，分类错误的成本通常是不相同的。在大多数情况下，假阴性的成本远高于假阳性的成本。因此，我们不应仅仅根据预测准确率来选择模型。通过在模型评估中引入分类错误成本的权重，我们可以选择总成本最低的模型。这种方法允许我们找到最适用于现实情况的模型，从而最小化过拟合。 |
| 使用集成模型 | 有时，即使我们尝试了各种机器学习方法，也找不到一个最适用于我们数据的单一模型。此外，这些模型之间甚至可能意见不。在这种情况下，我们应该尝试使用集成模型，它结合多个模型的预测来创建一个单一的共识预测。集成模型通常比组成它的单个模型更准确。 |

## 模型可靠性与有效性

![](img/ufig6_7.jpg)我们通常收到的一个重要问题是关于模型的质量。具体来说，我们是否有一个可靠且有效的预测模型？那么，模型可靠性和有效性之间的区别是什么？可靠性和有效性的概念似乎很简单，这些术语在统计和研究方法材料中经常被使用。然而它们很少被清晰地描述和解释，特别是在数据挖掘领域。理解它们之间的区别至关重要，这允许我们正确地衡量和评估它们。我将从数据挖掘的背景出发简单地解释这些概念，让你理解它们为什么重要。

![](img/ufig6_8.jpg)本质上，可靠性反映了模型的内部一致性，而有效性指示了模型的准确性。简单来说，一个可靠的模型在我们用不同数据集上运行它时，应该提供一致的结果。而一个有效的模型应该对目标变量产生准确的预测。两者都很重要。但可靠性并不保证有效性。因此，我们必须对两者进行评估。仍然困惑吗？让我们来看一个简单的例子，使用秤测量一袋 25 磅大米的重量。一个可靠的秤在多次测量中会给我们一致的重量数字。但并不意味着秤是有效的。例如，我们用秤称了十次那袋米，每次秤给出的读数都非常一致，在 22.1 到 22.8 磅之间。正如你所看到的，这个秤非常可靠，但不准确，因为它偏差了约 2 磅。因此，我们只有可靠性而没有有效性。我们想要一个既可靠又能给出 25 磅准确读数的秤。

你可能会问：这是否意味着有效性（`valid`）也意味着具有可靠性（`reliability`）？答案是定的。然而，在我们多次测量重量之前，我们并不知道。例如，我们买了一个全新的秤，第一次测量给出了 25 磅的准确读数。听起来很棒，对吧？但为了确定，我们必须重复测量几次。如果它多次产生准确的读数，那么它就是一个好秤。另一方面，如果我们持续收到不一致的读数，那么这台秤既不可靠也不有效。在数据挖掘中，我们之前讨论过的过拟合情况就是：模型在训练样本上产生了良好的预测，但在其他数据集上失败了。因此，评估模型的可靠性和有效性至关重要。在实现可靠性之前，我们无法确认整体模型的有效性。换句话说，为了实现模型有效性，模型必须一致地对目标变量产生准确的预测。本质上，模型有效性等同于预测能力。图 6.3 展示了我们具有模型可靠性但没有有效性的情况。

![图 6.3 模型可靠性和有效性。](img/fig6_3.jpg)

图 6.3 模型可靠性和有效性。

在清晰理解可靠性和有效性区别之后，下一步是学习如何评估预测模型的可靠性和有效性。注意，我们不能分两个独立的过程来完成，因为模型拟合指标被用于这两个用途。可靠性和有效性的评估必须在同一个过程中进行，尽管我们需要为可靠性和有效性提供单独的证据。

### 模型可靠性与有效性评估流程

![](img/icon_7.jpg)按照以下步骤评估预测模型的可靠性和有效性。

1. 将样本划分为子样本，包括训练样本、验证样本和测试样本。推荐的划分比例为 60:40，这意味着 60% 用于训练，20% 用于验证，20% 用于最终测试。
2. 根据所选的机器学习方法配置预测模型（我们将在接下来的章节介绍每种方法的细节）。
3. 使用训练样本训练模型。然后使用验证样本验证模型。大多数数据挖掘程序都会自动运行这一步。
4. 使用预先定义的适当指标评估训练样本的模型拟合情况（接下来的章节将提供模型拟合指标的细节）。如果模型拟合满意，则跳转到第 5 步。否则，返回第 2 步重新配置模型。
5. 使用指标比较训练样本和验证样本之间的模型拟合指标。
6. 如果比较显示训练样本和验证样本之间具有一致性，那么我们可以得出具有模型可靠性的结论。注意，一致性的水平取决于研究背景和研究人员的证明。尽管如此，如果差异小于 5%，我们可以认为可靠性是可接受的。**结论：实现了模型可靠性。**
7. 如果没有实现模型可靠性，调整第 1 步和第 2 步中的采样和建模过程以解决问题。解决方案可能包括重采样数据、重新配置模型、使用替代的机器学习方法或使用集成模型。重复步骤 2-5，直到实现可靠性。
8. 评估验证样本的全完整模型拟合指标，以确认整体模型拟合情况（为此目的可以添加更多指标）。如果模型拟合满意，则跳转到第 9 步。否则，需要进一步调整以提高模型性能。
9. 评估测试样本的模型拟合情况作为最终评估。如果模型在该样本上显示出良好的拟合，那么我们就实现了模型有效性。**结论：实现了模型有效性。**

### 如何报告模型可靠性和有效性结果？

![](img/icon_4.jpg)假设我们已经完成了预测建模过程并同时实现了模型可靠性和有效性。我们如何有效地报告这些结果？由于上述过程是迭代的，不建议展示所有步骤的结果，因为这可能会使结果比应有的更加复杂，并给读者带来困扰。我建议按照以下步骤清晰且有效地展示结果。注意，这些步骤适用于训练了多个模型的项目。

1. 如果有多个模型，展示模型比较结果。在这些比较中使用验证样本的关键模型拟合指标，并解释模型拟合是否满意以及原因。注意，虽然如上述流程所示，我们需要首先评估训练样本的模型拟合情况，但没有必要单独报告结果。由于验证样本用于验证模型，因此验证结果对于读者理解经过验证的模型拟合指标至关重要。
2. 根据模型比较结果确定初步的“冠军模型”（`champion model`）。使用多个模型拟合指标来确认这一选择。
3. 展示训练、验证和测试样本之间模型拟合指标的比较，并解释这些样本之间的结果是否可靠以及原因。在这一步中，仅关注冠军模型。如果我们有一致的结果，就可以得出实现了模型可靠性的结论。
4. 提供额外的模型拟合指标以对模型拟合进行完整评估。确认冠军模型具有良好的模型拟合。
5. 凭借验证样本良好的模型拟合指标和模型可靠性，我们可以得出实现了模型有效性的结论。总体，冠军模型具有良好的预测能力。
6. 报告并解释冠军模型的结构、变量之间的关系以及变量重要性。

### 模型比较

![](img/ufig6_10.jpg)在数据挖掘中，我们的目标是从大型噪声数据中发现未知模式。这意味着挖掘数据并查看它们告诉了我们什么。我们从数据中发现的模式通常是变量之间现有文献不存在的新关系或新的预测因子。为了这个目的，很难预先哪种机器学习方法和哪些模型配置效果最好。最好的机器学习模型本质上取决于数据。我们的目标是找到最符合数据的模型。因此，使用复杂或先进的方法并不能保证我们拥有最好的模型。

![](img/ufig6_11.jpg)让我们来看图 6.4 中展示的一个假设场景。假设我们为给数据集构建了两个模型。一个模型使用先进的机器学习方法，例如神经网络（右侧的模型）。该模型生成了预测变量与目标变量之间的非线性关系，并且看起来非常拟合数据。另一个模型使用简单的方法，即线性回归，它显示了预测变量与目标变量之间的线性关系（左侧的模型）。在模型训练过程中，根据预测准确性，线性回归模型的模型拟合程度可能不如神经网络模型。然而，如果我们通过散点图直观地查看数据，很容易检测到数据遵循线性模式。这意味着，虽然线性回归模型简单得多，但它比神经网络模型更好地捕捉到了这种模式。当我们使用验证样本运行这两个模型时，我们发现回归模型始终能产生良好的模型拟合效果。另一方面，与训练结果相比，神经网络在验证样本上的模型拟合度低得多。这里发生了什么？原因是神经网络模型存在过拟合问题，因为它试图在训练过程中解释数据中的噪声并将这些噪声纳入模型中，而没有考虑到这些噪声主要是噪声。这就是为什么它在训练模型上获得了近乎完美的模型拟合，但当我们用验证样本运行该模型时，它无法做出准确的预测。因此，该模型衍生出的复杂非线性模式并没有捕捉到数据的实际模式。我们可以得出结论：该模型不可泛化性，意味着它的预测能力很差。在这种情况下，线性回归模型是更好的。

### 模型比较步骤

按照以下步骤构建并比较模型：

1. 使用适用于给定数据的不同机器学习方法和配置，开发并训练多个预测模型。
2. 使用训练样本和验证样本运行这些模型。
3. 选择用于筛选的模型拟合指标。
4. 使用确定的指标比较模型并选择冠军模型。
5. 检查冠军模型的模型拟合情况，看是否令人满意。如果不满意，则对现有模型的配置进行调整，或考虑添加新模型。
6. 重复步骤 1-5，直到获得满意的冠军模型。
7. 使用测试样本评估冠军模型的模型拟合情况，以确认其预测能力。

## 关联模型的模型拟合指标

![](img/icon_5.jpg)模型拟合指标用于评估我们训练的模型与数据的拟合程度。它是通过预测的准确性或误差来衡量的。对于连续目标变量关联模型，我们可以将这些指标分为误差衡量和图表。误差衡量允许我们对拟合情况进行数值评估，而图表允许我们直观地检查拟合情况。

### 预测误差衡量

误差衡量了我们训练的模型偏离数据的程度。通常，误差越小，模型越准确。统计学中有许多误差衡量方法，从简单的到复杂的都有。使用所有方法是多余的且没必要的，因为其中某些方法非常相似。我描述了一些常见的衡量方法并推荐了最实用的。以下公式展示了这些常见的误差衡量方法以及如何使用实际值、预测值和平均值计算这些误差。

```
平方误差和 (SSE)
SSE = sum(Actual - Predicted)²
```

### 回归平方和 (SSR)

SSR = (预测值 - 平均值)$²$ 的和

### 总平方和 (SST)

SST = (实际值 - 平均值)$²$ 的和

### 平均绝对误差 (MAE)

```
$$MAE = \frac{\left. Sum~of~ \middle| Actual - Predicted \right|}{sample~size}$$
```

### 均方误差 (MSE)

```
$$MSE = \frac{Sum~of~\left( Actual - Predicted \right)^{2}}{sample~size}$$
```

### 均方根误差 (RMSE)

```
$$RMSE = \sqrt{\frac{Sum~of~\left( Actual - Predicted \right)^{2}}{sample~size}}$$
```

### 平均绝对百分比误差 (MAPE)

```
$$MAPE = \frac{Sum~of~\left| \frac{Actual - Predicted}{Actual} \right|}{sample~size}$$
```

### 相对平方误差 (RSE)

```
$$RSE = \frac{Sum~of~\left( Actual - redicted \right)^{2}}{Sum~of~\left( Actual - Mean \right)^{2}} = \frac{SSE}{SST} = \frac{Unexplained~Variance}{Total~Variance}$$
```

### 模型解释力 (EP)

```
$$EP = ~1~ - ~RSE = \frac{Explained~Variance}{Total~Variance}$$
```

我们可以注意到，`SSE`、`SSR` 和 `SST` 是其他误差指标的重要组成部分，尽管它们没有被用作最终的模型拟合指标。因此，我将它们的含义描述如下：

- 误差平方和 (`SSE`) – 未未解释的方差：数据与模型预测值之间的距离。
- 回归平方和 (`SSR`) – 已解释的方差：平均值与模型预测值之间的距离。
- 总平方和 (`SST`) – 总方差：数据与平均值之间的距离。

注意，在这些指标中，平均值是数据集中实际值的平均数，它代表了在我们不使用任何模型时的预期预测值。图 6.5 以线性回归为例，说明了 `SSE`、`SSR` 和 `SST` 之间的关系。

![](img/icon_4.jpg)让我们来讨论一些流行的模型拟合指标。平均绝对误差 (`MAE`) 是所有绝对误差的平均值，代表了实际值与预测值之间的平均距离。`MAE` 易于解释，因为它告诉了我们与目标变量相同尺度的平均绝对误差。`MAE` 的主要缺点是它以相同的方式对待所有误差，不对大误差进行惩罚。均方误差 (`MSE`) 与 `MAE` 类似，但我们使用的是误差的平方而不是绝对误差。`MSE` 是所有平方误差的平均值。`MAE` 和 `MSE` 关键区别在于，由于误差是平方的，`MSE` 会在更大程度上惩罚大误差。在某些情况下，惩罚大误差可能是重要的，因为我们可以优先选择误差较小的模型。因此，`MSE` 能更好地捕捉模型拟合情况。`MSE` 的缺点是它使用了误差的平方值，这与数据的尺度不相同。均方根误差 (`RMSE`) 通过使用 `MSE` 的平方根解决了这个问题，使得 `RMSE` 与数据具有相同的尺度。出于这个原因，我推荐使用 `RMSE`。
