### 10.3.3 区块链构建阶段

DT 与区块链的集成保证了数据完整性、追踪、不可篡改性和安全性等关键特性。与 DT 的构建、策略、规则和操作相关的所有数据都可以安全地维护在区块链中。区块链架构分为三类：私有链、公有链和联盟链。访问权限、共识确定和不可篡改性取决于所采用的架构类型。在我们提出的基于 DT 的预测性维护框架中，不同机器部件的状态信息需要由不同的组织进行追踪。因此，基于联盟的架构更为合适。

联盟链是私有链和公有链的混合形式。显示实时机器部件当前状态的 DT 的传感器数据需要在区块链中维护以进行预测性维护。它可以确保参与预测性维护的不同组织成员之间的数据问责、安全性和透明度。在所提出的框架中，构建了两个区块链以提高学习模型的效率：数字孪生区块链（`DTBC`）和实时机器区块链（`RBC`）。`RMBC` 携带带有从实时物理实体获取的数据区块链以供维护，而 `DTBC` 包含了从 DT 获取信息的区块。

#### 10.3.3.1 RMBC 的构建

### 10.3.4 深度学习模型的构建

为了对从实时物联网机器中收集的序列数据及其数字实体（即数字孪生集合）的时间关系建模，所提框架考虑了基于`RNN`的学习模型。为了预测故障并识别需要及时维护的模式，需要对描述不同时期收集的机器部件状态的数据进行更长时间的依赖关系建模。为了预测机器运行行为的异常，需要识别预期目标特征与机器当前行为之间的差异。

所提框架通过两种类型的区块链`RMBC`和`DTBC`提供了这种支持。`DTBC`提供了机器的预期行为。预测性维护的另一个要求是找到状态信息序列之间的关系。令 `$s_t$` 为机器在时间'`t`'的状态，`$s_{t-1}$` 为机器在时间'`t-1`'的状态。在分析 `$s_t$` 以以预测维护需求或故障概率时，也必须考虑'`t-1`'时刻的机器状态知识，即 `$S_{t-1}$`。通过同样考虑之前的'`n`'个状态信息（如 `$S_{t-1,t-2}, S_{t-3\dots t-n}$`），可以提高预测任务的精确性。因此，长短期记忆（`LSTM`）神经网络被认为是所提预测性维护的合适学习模型。

`LSTM`可以使用从过去数据中获得的知识对当前输入进行分析和分类。`LSTM`可以决定哪些信息值得关注。`LSTM`的架构有四个门，以支持基于长期依赖关系的学习。这些门决定了学习、忘记、记忆和使用什么。学习门（Learning gate）接受当前状态 `$C_t$` 和之前的短记忆记忆 `$SM_{t-1}$` 作为输入。它决定哪些信息是相关的，并仅保留用于预测的学习。使用权重矩阵 `$(M_n)$` 的学习门 `$(lg)$` 操作如下：

```
$Learning Matrix (L_t) = \tanh(M_n [SM_{t-1}, S_t]) + bias\_n$
```
