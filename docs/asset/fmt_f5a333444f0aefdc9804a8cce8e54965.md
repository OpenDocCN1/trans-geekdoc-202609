## If-Else 语句

```
If condition:
    Things to do when you meet the first condition
    Things to do when you meet the second condition.
    ...
    Things to be done when nth conditions are met
else:
    Things to do when the first conditions are not met
    Things to do when second conditions are not met
    ...
    Things to do when nth conditions are not met
```

为了帮助大家更好地理解 `if-else` 语句的用法，接下来我们将通过一个案例演示 `if-else` 语句的功能。

### 示例：if-else 语句

```
Ticket = 1  # with 1 for tickets, 0 for no tickets
if ticket == 1:
    print("you can get on the train if you have a ticket")
    print("I can finally see home")
else:
    print("No tickets, no boarding")
    print("Dear, I'll see you next time")
```

将变量 `ticket` 的值设为 `0` 并再次运行程序。如果你能通过实际编码练习，将会深入理解条件语句。

## If 嵌套

当我们乘坐火车或地铁时，必须先买票。只有买了票才能进站安检。只有通过安检才能正常乘车。在乘坐火车或地铁的过程中，后一个判断条件建立在前一个判断的基础上。针对这种情况，可以使用 `if` 嵌套。

`If` 嵌套是指在一个 `if` 或 `if-else` 语句中包含另一个 `if` 或 `if-else` 语句，其嵌套格式如下：

```
if conditions1:
    // What to do if condition 1 is met
    // things that meet condition 1
    if conditions2:
        things are done to meet condition 2
```

在上述格式中，我们可以根据实际开发需求，选择为外层 `if` 和内层 `if` 使用 `if` 语句还是 `if-else` 语句。

## 循环语句

在现实生活中，存在许多循环过程。例如，红绿灯的交替变化就是一个重复的过程。在程序中，如果想要重复某些操作，可以使用循环语句，也称为循环。Python 提供了两种循环语句：`while` 循环和 `for` 循环。我们现在将详细讨论这两种语句。

### While 循环

`while` 循环的基本格式如下：

```
While condition:
    Enter the logic
    Output results
```

如果条件满足，则执行循环语句。当条件表达式为 `True` 时，程序执行循环语句。需要注意的是，在 `while` 循环中，也要注意冒号和缩进。此外，Python 中没有 `do-while` 循环。

如果我们希望循环无限进行，可以通过将条件表达式设置为始终为 `True` 来实现无限循环。无限循环对于服务器上客户端的实时请求非常有用。接下来，通过一个案例演示具体代码。

#### 示例：while 循环

```
value = 1
While value == 1:  # expression is always True
    input = int(give("enter a number:"))
    print("The number you entered is:", input")
```

### For 循环

Python 中的 `for` 循环可以遍历任何项目序列，例如列表或字符串。`for` 循环的基本格式如下：

```
For variable in sequence:
    loop statement
```

例如，使用 `for` 循环遍历列表；示例代码如下：

```
for result in [62, 1, 32]:
    print(result)
```

**输出结果：**

```
62
1
32
```

在上述示例中，`for` 循环可以逐个显示列表中的值。考虑到我们使用的值范围经常变化，Python 提供了内置的 `Range` 函数来生成数字序列。`for` 循环中 `range` 函数的基本格式如下：

```
for result in range(get, set):
    Enter logic here
```

执行循环语句：当程序执行 `for` 循环时，循环计时器变量 `result` 被设置为 `start`，然后执行循环语句。`result` 依次被设置为 `start` 和 `end` 之间的所有值。每设置一个新值，循环语句就执行一次。

在整数中，能被 2 整除的数称为偶数。现在，我们将开发一个程序来计算 1 到 100 之间所有偶数的和。

#### 示例：计算 1 到 100 之间偶数的和

```
first = 0
Output = 0
while i < 101:
    if first % 2 == 0:
        sum Output += first
    first += 1
Print("the sum of even numbers between 1 and 100 is: %s" % first")
```

### While 嵌套

它仅表示在一个 `while` 循环中嵌套另一个 `while` 循环。`while` 嵌套的格式如下：

```
While condition 1:
    When condition 1 is met, do 1
    {
        while condition 2:
            When condition 2 is met, do 2
    }
```

上述格式的相关说明如下：

1.  当循环条件 1 满足时，执行条件 1 满足时要做的事情。此时可能会有机会执行内部嵌套的循环。
2.  当循环条件 2 满足时，执行条件 2 满足时要做的事情，直到内部的 `while` 循环结束。
3.  当循环条件 2 不满足时，执行完外部循环要做的事情后，外部的 `while` 循环结束。

# 第 12 章：Python 面向对象编程

现实世界中存在各种形式的事物，这些事物之间也存在各种联系。在程序中，使用对象来映射现实事物，利用对象之间的关系来描述事物之间的关系。这种思想就是面向对象范式。

当我们谈论面向对象编程时，自然会想到面向过程编程。面向过程编程是分析解决问题的步骤，然后在使用不同方法时，用函数逐一实现这些步骤。面向对象编程是将解决问题的实体分解为多个对象，建立对象的目的不是为了逐一完成，而是为了在解决整个问题的过程中描述事物的行为。

以下通过一个五子棋的例子来说明面向过程和面向对象编程的区别。

首先，使用面向过程范式：

1. 开始游戏
2. 玩家 1 先行
3. 绘制画面
4. 判断结果
5. 玩家 2 回合
6. 绘制画面
7. 判断结果
8. 返回步骤 2
9. 输出最终结果

上述步骤分别由函数实现，使用面向过程范式解决问题。

面向对象设计从另一种思维方式解决问题。当使用面向对象思维实现五子棋时，整个五子棋游戏可以分为三类对象，如下所示。

1. 黑白双方：代表两名玩家
2. 棋盘系统：负责绘制画面
3. 规则系统：负责判断犯规、胜负等事项

在上述三类对象中，第一类对象（黑白双方）负责接收用户输入并通知第二类对象（棋盘系统）在棋盘上绘制棋子，而第三类对象（规则系统）对棋盘进行判断。

面向对象编程保证了功能的统一性，从而使代码更易于维护。例如，如果我们现在想在面向过程范式中添加悔棋功能，那么输入、判断、显示的一系列步骤都需要改动。甚至步骤之间的循环都需要大规模调整，非常麻烦。如果使用面向对象开发，只需修改棋盘对象即可。棋盘对象保存了黑白双方的棋谱，只需简单回溯，无需修改显示和规则。同时，整个对象函数的调用顺序不会改变，其变化仅是局部的。因此，与面向过程相比，面向对象编程更便于后期的代码维护和功能扩展。

## 类和对象

在面向对象编程中，最重要的两个核心概念是类和对象。对象是现实生活中具体的事物，它们看得见、摸得着。例如，你手中的这本书就是一个对象。与对象相比，类是抽象的，它是对一群具有相同特征和行为事物的统称。例如，小时候母亲对我说：“儿子，你要以那种人为榜样！”这里的“那种人”指的是一群成绩优秀、有礼貌的人。他们具有相同的特征，所以被称为“同类”人。

### 类与对象的关系

俗话说“物以类聚，人以群分”，我们将具有相似特征和行为的事物的集合统称为类，如动物、飞机等。例如，玩具模具可以看作是类，每个玩具看作是对象，因此玩具模具与玩具的关系可以看作是类与对象的关系。

类用于描述多个对象的共同特征，是对象的模板。对象用于描述现实中的个体，它是类的实例。由此可见，对象是根据类创建的，一个类可以对应多个对象。

### 类的定义

在日常生活中，要描述一类事物，需要说明其特征以及用途。例如，描述人类这类实体时，通常需要给这类事物一个定义或名称。人的特征包括身高、体重、性别、职业等。人的行为包括跑步、说话等。人的特征与行为的结合可以完整地描述人类。

面向对象程序的设计思想基于此设计，在类中包含事物的特征和行为。其中，事物的特征作为类的属性，事物的行为作为类的方法，对象是类的实例。因此要创建对象，首先需要定义类。

类由 3 部分组成。

1. **类名**：类的名称，首字母必须大写，例如 `Person`。
2. **属性**：用于描述事物的特征，例如人具有姓名、年龄等特征。
3. **方法**：用于描述事物的行为，例如人具有说话、微笑等行为。

在 Python 中，可以使用 `class` 关键字声明类，基本语法格式如下：

```
class {此处输入实体名称}:
    # 这是类的属性
    # 类的方法
```

以下是示例代码：

```
class Vehicle:
    # attribute
    # Method
    def drive(self):
        Print ("-drivinf Automobile--")
```

在上例中，使用 `class` 定义了一个名为 `Vehicle` 的类，其中包含一个 `drive` 方法。从示例可以看出，方法的格式与函数相同。主要区别在于方法必须显式声明一个 `self` 参数，并位于参数列表的开头。`Self` 代表类的实例（对象）本身，可用于引用对象的属性和方法。`self` 的具体用法将在后面结合实际应用介绍。

### 从类创建对象

如果程序要完成具体功能，光有类是不够的，还需要根据类创建实例对象。在 Python 程序中，可以使用以下语法创建对象：

```
对象 {此处输入实体名称} = 类 {此处输入类名} ()
```

例如，创建驾驶类的对象 `Vehicle`，示例代码如下：

```
vehicle = driving()
```

在上述代码中，`vehicle` 是一个变量，可用于访问类的属性和方法。要给对象添加属性，可以使用以下语法。

```
对象 {此处输入实体}. 新 {此处输入属性名} = 值
```

例如，使用 `vehicle` 为驾驶类的对象添加颜色属性。示例代码如下：

```
vehicle.color = "black"
```

接下来，通过一个完整的案例演示如何创建对象、添加属性和调用方法。请仔细阅读，消除所有疑惑。

#### 示例 Sport.py

## 构造方法和析构方法

在 Python 程序中，提供了两个特殊方法：`__init__()` 和 `__del__()`，分别用于初始化对象的属性和释放类占用的资源。本节主要详细介绍这两个方法。

### 构造方法

在前面定义类的示例中，我们动态地为 `Barcelona` 引用的对象添加了颜色属性。试想，如果再创建一个 `Football` 类对象，需要以“对象名.属性名”的形式添加属性。每创建一个对象，就需要添加一次属性，非常麻烦。

为了解决这个问题，可以在创建对象时设置属性。Python 提供了一个名称固定为 `__init__`（两个下划线开头，两个下划线结尾）的构造方法。创建类的实例时，系统会自动调用构造方法来初始化类。

为了让大家更好地理解，以下通过案例演示如何使用构造方法进行初始化。

#### 示例：使用构造方法.py

```
# 定义类
class Football:
    # 构造方法
    def __init__(kick):
        Color = "blue"
    # 犯规
    def foul(self):
        print ("%s Barcelona color is " (self.color))

# 创建对象并用变量 car 保存其引用
football = Football()
football.foul()
```

在示例中，第 4-5 行重新实现了 `__init__()` 方法，为 `Football` 类添加了颜色属性并赋值为 "blue"，并在 `foul` 方法中访问颜色属性的值。无论创建多少个 `Football` 对象，颜色属性的初始值默认都是 "blue"。

如果想在对象创建后修改属性的默认值，可以通过在构造方法中传递参数来设置属性值。以下案例演示如何使用带参数的构造方法。

#### 示例：使用带参数的构造方法.py

```
# 定义类
class Football:
    # 构造方法
    def __init__(kick):
        Color = "blue"
    # 犯规
    def foul(self):
        print ("%s Barcelona color is " (self.color))

# 创建对象并用变量 car 保存其引用
football = Football()
football.foul()

# 创建对象并用变量 bmw 保存其引用
realmadrid = color ("white")
realmadrid.color()
```

在示例中，第 4 至 5 行自定义了带参数的构造方法，将参数的值赋给颜色属性，确保颜色属性的值随参数接收的值而变化，然后仍在 toot 方法中访问颜色属性的值。

### 析构方法

前面介绍了 `__init__()` 方法。创建对象时，Python 解释器会默认调用 `__init__()` 方法。删除对象以释放类占用的资源时，Python 解释器会默认调用另一个方法，即 `__del__()` 方法。

接下来通过案例演示如何使用析构方法释放占用的资源。

#### 示例：使用析构方法.py

```
# 定义类
class Football
    def __init__(team, color, name):
        team.name = name
        team.color = color
    def __del__(team):
        print("--------del--------")

Realmadrid = team ("white", 1)
```

在示例中，定义了一个名为 `Person` 的类，在 `__init__()` 方法中设置颜色和队伍的初始值，在 `__del__()` 方法中添加打印语句，然后使用自定义构造方法创建 `Person` 类的对象。程序结束时，其占用的内存空间将被释放。

那么，我们能手动释放空间吗？可以，使用 `Del` 语句删除对象并释放其占用的资源。在示例末尾添加以下代码：

```
del realmadrid
print("---------1---------")
```

从结果可以观察到，程序在输出 "1" 之前输出了 "del"。这是因为 Python 具有自动垃圾回收机制。当 Python 程序结束时，Python 解释器会检测当前是否有内存空间需要释放。如果有 `del` 语句，会自动删除；如果已手动调用 `del` 语句，则不会自动删除。

## 什么是控制流语句？
