- 在分页函数中添加一些代码跳转到第一页或最后一页。例如，如果有 14 页，用户在第 8 页，且范围是 7，它看起来应该是这样：

```
<PREV] 1 [5] [6] [7] 8 [9] [10] [11] ... [14] NEXT >
```

A：用以下代码段替换相应的代码行：

```php
if ($range > 1) {
  $pagelinks .= "<a class='pagenumlink' href='<?php echo $currpage-1; ?>'>$1</a>...";
} else {
  $pagelinks .= "&nbsp;&nbsp;";
}
if ($range < $numpages) {
  $pagelinks .= "..<a class='pagenumlink' href='<?php echo $currpage+1; ?>'>" . $page . "." . $numpages . "</a>...";

  $pagelinks .= "&nbsp;&nbsp;";
}
```

# 快速参考

在本附录中，我们列出了一些笔记。

## 显示到浏览器

要显示文本，使用以下语法：

```php
<?php
echo "text";
?>
```

## 设置值

要设置变量，使用以下语法：

```php
<?php
$variable = "value";
?>
```

## 传递变量

有三种方法传递变量：

```php
<?php
$name = array("firstname"=>"Albert", "lastname"=>"Einstein", "age"=>124);
echo $name["firstname"];
?>
```

或者

```php
<?php
$name["firstname"] = "Albert";
$name["lastname"] = "Einstein";
$name["age"] = 124;
?>
```

## 数组

如果没有键，可以这样设置数组的值：

```php
<?php
$flavor[] = "blue raspberry";
$flavor[] = "root beer";
$flavor[] = "pineapple";
?>
```

## if 语句

要使用 `if`，使用以下语法：

```php
<?php
if ($condition) {
  // code
}
?>
```

或者

```php
<?php
if ($condition) {
  // code;
}
?>
```

## else 语句

要使用 `else`，使用以下语法：

```php
<?php
if ($condition) {
  // code;
} else {
  // code;
}
?>
```

## 嵌套 if 语句

你可以通过使用以下语法使用嵌套 `if`：

```php
<?php
if ($condition1) {
  if ($condition2) {
    // code;
  }
} else {
  // code
} //记得使用 == 来表示相等
?>
```

## 包含文件

要包含文件，使用以下语法：

```php
<?php
include "header.php";
?>
```

## 使用函数

可以使用以下语法创建并调用函数：

```php
<?php
function functionname() {
  // code
}
functionname(); //调用函数以执行
?>
```

## for

你可以使用以下语句按指定的次数执行代码块：

```php
<?php
for ($n = 0; $n <= 10; $n=$n+1){
  //这些行会在当值 'n'
  // 小于或大于 10 时执行
  echo $n;
  echo "<br>";
}
?>
```

## foreach

你可以使用 `foreach` 语句对指定数组中的每个值应用相同的代码块：

```
foreach ($arrayvalue, as $currentvalue) {
    // 只要 $arrayvalue 中还有值，这些行代码就会执行
    echo $currentvalue;
    echo "<br>\n";
}
```
