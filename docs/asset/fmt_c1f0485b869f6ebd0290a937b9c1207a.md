### 第一个人工神经元

感知器的根源于 1943 年由论文，作者是一个意想不到的组合：一位四十岁的哲学神经科学家和一个无家可归的少年。沃·麦库洛（Warren McCulloch）带着这些问题在 1941 年从耶尔大学搬到伊利诺伊大学，在那里他遇到了一个才华横溢的少年沃尔特·皮茨（Walter Pitts）。这个年轻人已经是有造诣的逻辑学家（著名数学逻辑学家鲁道夫·卡纳普的弟子”）。

在那项工作中，神经元的细胞体通过其树枝状投影（称为树触）接收输入。细胞体对这些输入进行计算。然后，根据计算结果，可能会沿着另一个较长的投影（称为轴）发送电信号。该信号沿着轴传输到达分支末端，在那里它传递给相邻神经元的树触。过程如此。以这种方式连接的神经元形成了生物神经网络。

麦库洛和皮茨将此转化为一个简单的计算模型。在这个麦库洛-皮茨模型的简单版本中，`x1`和`x2`可以是 0 或 1。在形式符号中，我们可以说：

> `x1, x2 ∈ {0, 1}`

这应该读作`x1`是集合 {0, 1} 的元素，且`x2`是集合 {0, 1} 的元素；`x1`和`x2`只能取 0 或 1 的值，不能取其他值。神经元的输出`y`通过首先对输入求和，然后检查该和是否大于等于某个阈值`theta`（`θ`）来计算。如果是，`y`等于 1；如果不是，`y`等于 0。

> `sum = x*1 + x*2`

> `If sum ≥ θ: y = 1`

> `Else: y = 0`

将此推广到任意输入序列`x1`, `x2`, `x3`, …, `xn`，我们可以写出这种简单神经元的形式化数学描述。首先，我们定义函数`g(x)`——读作“g of x”，这里的`x`是输入集合（`x1`, `x2`, `x3`, …, `xn`）——它对所有输入进行求和。然后，我们定义函数`f(g(x))`——同样读作“f of g of x”——它接收求和结果并进行阈值处理以生成输出`y`：如果`g(x)`小于某个值`θ`，则输出为 0；如果`g(x)`大于或等于`θ`，则输出为 1。

利用上述的单个神经元，我们可以设计一些基础的布尔逻辑门（例如 AND 和 OR）。在与 AND 逻辑门中，如果`x1`和`x2`都等于 1，则输出`y`应为 1；否则输出应为 0。在这种情况下，设置`θ` = 2 即可实现。现在，只有当`x1`和`x2`都为 1 时，输出`y`才会为 1（只有此时`x1` + `x2`才会大于或等于 2）。你可以调整`θ`的值来设计其他逻辑门。例如，在 OR 门中，如果`x1`或`x2`其中一个为 1，输出应为 1；否则输出应为 0。那么`θ`应该是多少呢？

简单的 MCP 模型可以扩展。你可以增加输入的数量。你可以让输入具有“抑制性”，这意味着`x1`或`x2`可以被乘以 −1。如果神经元的其中一个输入是抑制性的，且你设置了合适的阈值，那么无论所有其他输入的值如何，神经元将始终输出 0。这允许你构建更复杂的逻辑。通过互连多个神经元，使一个神经元的输出作为另一个神经元的输入也是如此。

这一切虽然令人惊叹，但具有局限性。McCulloch-Pitts (MCP) 神经元是一个计算单元，你可以通过组合它来创建任何类型的布尔逻辑。鉴于所有数字计算在本质上都是这种逻辑操作的序列，你基本上可以混合组合 MCP 神经元来执行任何计算。这在 1943 年是一个非凡的论断。McCulloch 和 Pitts 论文的数学根源是显而易见的。这篇论文只有三个参考文献——Carnap 的《语言的逻辑句法》；David Hilbert 和 Wilhelm Ackermann 的《理论逻辑基础》；以及 Whitehead 和 Russell 的《数学数学原理》——其中任何一个都与生物学无关。McCulloch-Pitts 论文中推导出的严谨结果是不容怀疑的。然而，结果仅仅是一台可以计算而不能学习的机器。特别是`θ`的值必须通过人工工程设计；神经元无法检查数据并计算出`θ`。

Rosenblatt 的感知器（perceptron）能引起如此轰动并不意外。它可以从数据中学习权重。然而，这些权重编码了关于数据模式的某些知识（无论多么微小），并以某种方式记忆了它们。

### 从错误中学习

Rosenblatt 的学术成就经常让他的学生大叹观口。George Nagy 于 1960 年来到纽约州伊萨卡的康奈尔大学跟随 Rosenblatt 攻读博士学位，他回忆起两人有一次散步，期间他们谈到了立体视觉。Rosenblatt 对该主题的精通程度让 Nagy 叹服不已。“通常情况下与他交谈，很难不感到自己很天真。”

Rosenblatt 的少年心态在一次公路旅行中差点让两人陷入麻烦。他与 Nagy 必须从伊萨卡去芝加哥参加一个会议。Rosenblatt 还没有写好他想要发表的论文，所以他让 Nagy 开车，自己则工作。Nagy 从未拥有过汽车，几乎也不会开车，但他还是同意了。“不幸的是，我同时在几条车道上行驶，一名警察拦住了我们，”Nagy 说。Rosenblatt 告诉警察他是一个教授，是让他的学生开车。“警察笑着说：‘你不是教授，你是个学生。’”幸运的是，Rosenblatt 身上带着足够的论文来说服了警察他的身份，警察放行了两人。Rosenblatt 开完剩下的路程到达芝加哥，并在那里熬通宵打好了论文，在第二天进行了演讲。“他能做到这些事，”Nagy 告诉我。

当 Nagy 到达康奈尔大学时，Rosenblatt 已经构建了 Mark I 感知器；我们在序言中看到 Rosenblatt 在 1958 年就做到了这一点，并引发了《纽约时报》的报道。Nagy 开始研究下一台机器，名为 Tobermory（以 H. H. Munro，又名 Saki 创建的会说话猫命名），这是一种用于语音识别的硬件神经网络。与此同时，Mark I 感知器和 Rosenblatt 的思想已经吸引了大量的关注。

1958 年夏天，康奈尔航空实验室的《研究趋势》杂志编辑专门奉献了一整期杂志介绍 Rosenblatt（根据编辑的话，“因为 Rosenblatt 博士的文章具有非凡意义”）。文章标题为“他对大脑的强调并不令人意外”。Rosenblatt 曾师从于 James Gibson，他是视觉感知领域的巨头之一。他还仰仰 McCulloch 和 Pitts，以及 Donald Hebb，后者是一位在 1949 年引入生物神经元学习模型的心理学家。“他总是非常评价他们，”Nagy 说。这里的“学习”指的是学习数据中的模式，而不是我们所理解的高级认知。虽然 McCulloch 和 Pitts 开发了神经元模型，但人工神经元网络无法学习。作为一名心理学家，Rosenblatt 并没有在硬件或软件上实现他想法所需的计算能力。因此他借用了康奈尔航空实验室的 IBM 704，那是一台重达五吨的巨兽。合作证明了成效。

但到底什么是感知器，它是如何学习的？在最简单的形式下，感知器是一个增强的神经元。感知器的计算如下：

```
sum = w1*x1 + w2*x2 + b
If sum > 0: y = 1
Else: y = -1
```

更通用的数学表达式为：与之前 MCP 模型的主要区别在于，感知器的输入不需要是二进制（0 或 1），而是取任何值。此外，这些输入与其相应的权重相乘，因此我们现在有一个加权和。此外还有一个额外的项`b`，即偏置。输出`y`是 -1 或 +1（而不是 MCP 神经元中的 0 或 1）。

一旦感知机学习了`w1`、`w2`的正确值以及偏置项，它就准备好进行预测了。给定另一个人的体重和身高——这个人并不在原始数据集中，因此这并不是一个简单的查表就能解决的问题——感知机可以将此人分类为肥胖或非肥胖。当然，这个模型基于一些假设，其中许多假设与概率分布有关，我们将在随后的章节中介绍。但感知机提出了一个基本假设：它假设在被分类为肥胖的人和非肥胖的人之间存在一个清晰的线性分界。

在这个简单示例的语境下，如果你在 xy 图上画出人们的体重和身高，以体重作为 x 轴，身高作为 y 轴，使得每个人都是图上的一个点，那么“清晰分界”的假设就意味着存在一条直线，将代表肥胖的点与代表非肥胖的点隔开。如果是这样，则称该数据集是线性可分的。

以下是感知机学习过程的图化展示。我们从两组数据点开始，一组的特征是黑圆圈（`y` = `+1`，肥胖），另一组是黑三角形（`y` = `−1`，非肥胖）。每个数据点由一对值（`x1, x2`）表征，其中`x1`是以公斤为单位的个人体重，沿 x 轴绘制，`x2`是以厘米为单位的身高，沿 y 轴绘制。

感知机从权重`w1`、`w2`和初始化为零的偏置开始。权重和偏置代表 xy 平面上的一直线。感知机尝试寻找一条分离线（由其权重和偏置的一组值定义），试图对点进行分类。在开始，它正确分类了某些点，错误分类了另一些。两次错误尝试显示为灰色虚线。在这种情况下，你可以看到在一次尝试中，所有点都在虚线的侧，因此三角形被正确分类，但圆圈不是；在另一次尝试中，它正确分类了圆圈，但错误分类了一些三角形。感知机从错误中学习并调整其权重和偏置。在对数据进行多次迭代后，感知机最终发现了其权重和偏置项的至少一组正确值。它找到了一条勾勒簇边界的线：圆圈和三角形位于两侧。这显示为一条实黑线，将坐标空间划分为两个区域（其中一个被涂成灰色）。感知机学习到的权重决定了线的斜率；偏置则决定了线距离原点的距离或偏移量。

一旦感知机学习了个人物理特征（体重和身高）与该个人是否肥胖（`y` = `+1` 或 `−1`）之间的相关性，你就可以提供一个训练期间未使用的数据的体重和身高，感知机就可以告诉你这个人是否应该被分类为肥胖。当然，现在感知机在学习了权重和偏置后正在做出它的最佳预测，但预测可能是错误的。你能找出原因吗？试着看能不能。

四元数是奇特的实体，它们与我们无关。但为了创建用于处理四元数的代数，哈密顿（Hamilton）开发了一些其他的数学思想，这些思想已成为机器学习的核心。特别是，他引入了“标量”（scalar）和“向量”（vector）这两个语。

考虑一个走了五英里的人。根据这个陈述，关于这个人做了什么，我们唯一能说的由一个数字表示：即步行距离。这是一个标量，一个独立的数字。现在，如果告诉我们这个人是朝东北方向走了五英里，我们就会得到两条信息：距离和方向。这可以用一个向量来表示。因此，向量既有长度（模），又有方向。在下面的图中，该向量是一个模为 5 的箭头。

如果你仔细观察这个向量，你会发现它有两个分量：一个沿`x-axis`，另一个沿`y-axis`。这等同于说这个人向正东方向走了四英里，向正北方向走了三英里。代表实际行走的向量是一个从`(0, 0)`指向`(4, 3)`的箭头，它同时给出了方向和距离。向量的模仅仅是向量和其在`x-`和`y-`轴上的分量所形成的直角三角形的斜边长度。因此，向量的模或长度等于 ![images/p028_02.png]。

从向量的角度进行思考，而不使用正式的方法来表示和处理它们，这早于哈密顿。例如，在 17 世纪 60 年代后期，艾萨·牛顿（Isaac Newton）就已经使用几何方法来思考加速度和力等类向量的实体。牛顿第二定律指出，物体所受的加速度与作用于其上的力成正比，且物体的加速度与力的方向相同。牛顿在《自然哲学原理》（*Principia*）中关于牛顿定律的第一条推论指出：“一个物体受两个合力作用，将描述出一个四边形的对角线，这与它受这两个分离力作用时所描述的边是同时。”

为了理解向量加法，我们可以回到那个走了五英里的人，他由一个从`(0, 0)`指向`(4, 3)`的向量表示。到达目的地后，这个人向更靠北的方向转向，使得他在坐标平面上到达了`(6, 9)`：他实际上又向正东方向走了两英里，向正北方向又走了六英里。这由第二个向量表示，即一个从`(4, 3)`画到`(6, 9)`的箭头。这个新向量的`x`分量为`2`，`y`分量为`6`。这个人走过的总距离是多少？在`xy`坐标空间中，从原点到最终目的地的净距离是多少？这张图向你展示了这两个答案：
