## 第四章：高级过滤技术

在之前的章节中，我们探索了 SQL 的基础知识并学习了如何使用 `SELECT` 语句检索数据。在本章中，我们将深入研究使用 `WHERE` 子句的高级过滤技术。这些技术将允许您对数据库表执行更复杂和精确的查询。到本章结束时，您将对比较运算符、逻辑运算符、通配符运算符以及如何有效地将它们组合起来有扎实的理解。

### 第 1 节：比较运算符

比较运算符用于比较值并在 `WHERE` 子句中定义条件。它们允许您根据相等、不等和其他比较来过滤数据。以下是一些常用的比较运算符：

- 等于：`=`
- 不等于：`<>`
- 大于：`>`
- 小于：`<`
- 大于或等于：`>=`
- 小于或等于：`<=`

示例：

```sql
SELECT * FROM employees
WHERE salary > 50000;
```

在此示例中，我们检索 `employees` 表中 `salary` 列大于 50000 的所有记录。

### 第 2 节：逻辑运算符

逻辑运算符允许您在 `WHERE` 子句中组合多个条件以创建更复杂的过滤条件。常用的逻辑运算符有：

- `AND`：如果所有指定条件都为真，则返回记录。
- `OR`：如果任何指定条件为真，则返回记录。
- `NOT`：否定一个条件，返回不满足指定条件的记录。

示例：

```sql
SELECT * FROM products
WHERE category = 'Electronics' AND price < 1000;
```

在此示例中，我们检索 `products` 表中 `category` 列为 'Electronics' 且 `price` 列小于 1000 的所有记录。

### 第 3 节：通配符运算符

通配符运算符用于匹配文本或字符串值中的模式。当您想要搜索部分匹配给定模式的值时，它们特别有用。常用的通配符运算符有：

- `%`：匹配任意字符序列（零个或多个）。
- `_`：匹配任意单个字符。

示例：

```sql
SELECT * FROM customers
WHERE last_name LIKE 'Sm%';
```

在此示例中，我们检索 `customers` 表中 `last_name` 列以 'Sm' 开头的所有记录。

### 第 4 节：组合运算符

为了创建更复杂的过滤器，您可以在 `WHERE` 子句中组合多个比较运算符、逻辑运算符和通配符运算符。这允许您根据特定需求构建复杂条件。

示例：

```sql
SELECT * FROM orders
WHERE (order_date >= '2022-01-01' AND order_date <= '2022-12-31')
  AND (status = 'Shipped' OR status = 'Delivered');
```

在此示例中，我们检索 `orders` 表中 `order_date` 介于 2022 年内的记录，且 `status` 为 'Shipped' 或 'Delivered'。

### 第 5 节：NULL 值

在 SQL 中，`NULL` 表示缺失或未知数据。在处理 `NULL` 值时，使用特殊运算符：

- `IS NULL`：匹配 `NULL` 值。
- `IS NOT NULL`：匹配非 `NULL` 值。

示例：

```sql
SELECT * FROM employees
WHERE department IS NULL;
```

在此示例中，我们检索 `employees` 表中 `department` 列包含 `NULL` 值的所有记录。

通过理解和应用这些高级过滤技术，您可以构建更复杂和精确的查询。这使您能够从数据库表中提取所需确切的数据。在下一章中，我们将探讨连接表，从而能够将来自多个表的数据组合到单个结果集中。

## 第5章：连接表

在之前的章节中，我们专注于从单个表中查询数据。然而，许多现实场景需要将多个表中的数据组合起来。在本章中，我们将探讨 SQL 中连接表的概念。连接表允许您合并相关数据并获得信息的全面视图。到本章结束时，您将了解不同类型的连接、如何使用公共列连接表以及如何从已连接的表中检索数据。

### 第1节：理解表连接

表连接基于两者之间的相关列将两个或多个表的行组合起来。最常见的连接类型有：

- 内连接：仅返回表之间的匹配行。
- 左连接：返回左表的所有行以及右表中匹配的行。
- 右连接：返回右表的所有行以及左表中匹配的行。
- 全外连接：返回两个表中的所有行，包括未匹配的行。

### 第2节：内连接

`INNER JOIN` 将具有指定列中匹配值的两个表的行组合起来。内连接的语法如下：

```sql
SELECT columns
FROM table1
INNER JOIN table2
ON table1.column = table2.column;
```

示例：

```sql
SELECT orders.order_id, customers.customer_name
FROM orders
INNER JOIN customers
ON orders.customer_id = customers.customer_id;
```

在此示例中，我们从 `orders` 表检索 `order_id`，从 `customers` 表检索 `customer_name`，并通过公共列 `customer_id` 将它们连接起来。

### 第3节：左连接

`LEFT JOIN` 返回左表的所有行以及右表中匹配的行。如果没有匹配，则右表的列包含 `NULL` 值。左连接的语法如下：

```sql
SELECT columns
FROM table1
LEFT JOIN table2
ON table1.column = table2.column;
```

示例：

```sql
SELECT customers.customer_name, orders.order_id
FROM customers
LEFT JOIN orders
ON customers.customer_id = orders.customer_id;
```

在此示例中，我们从 `customers` 表检索 `customer_name`，从 `orders` 表检索 `order_id`。所有客户都会被包含在内，即使他们没有任何订单。未匹配的 `order_id` 将具有 `NULL` 值。

### 第4节：右连接

`RIGHT JOIN` 返回右表的所有行以及左表中匹配的行。如果没有匹配，则左表的列包含 `NULL` 值。右连接的语法如下：

```sql
SELECT columns
FROM table1
RIGHT JOIN table2
ON table1.column = table2.column;
```

示例：

```sql
SELECT customers.customer_name, orders.order_id
FROM customers
RIGHT JOIN orders
ON customers.customer_id = orders.customer_id;
```

在此示例中，我们从 `customers` 表检索 `customer_name`，从 `orders` 表检索 `order_id`。所有订单都会被包含在内，即使没有对应的客户。未匹配的 `customer_name` 将具有 `NULL` 值。

### 第5节：全外连接

`FULL OUTER JOIN` 返回两个表中的所有行，包括未匹配的行。如果没有匹配，则相应表的列包含 `NULL` 值。全外连接的语法如下：

```sql
SELECT columns
FROM table1
FULL OUTER JOIN table2
ON table1.column = table2.column;
```

示例：

```sql
SELECT customers.customer_name, orders.order_id
FROM customers
FULL OUTER JOIN orders
ON customers.customer_id = orders.customer_id;
```

在此示例中，我们从 `customers` 表检索 `customer_name`，从 `orders` 表检索 `order_id`。所有客户和订单都会被包含在内，未匹配的客户-订单对将填充 `NULL` 值。

### 第6节：组合多个连接

您可以通过扩展查询中的连接子句来连接两个以上的表。这允许您在一个结果集中从多个相关表中检索数据。以下是一个示例：

```sql
SELECT orders.order_id, customers.customer_name, products.product_name
FROM orders
INNER JOIN customers
ON orders.customer_id = customers.customer_id
INNER JOIN order_items
ON orders.order_id = order_items.order_id
INNER JOIN products
ON order_items.product_id = products.product_id;
```

在此示例中，我们从 `orders` 表检索 `order_id`，从 `customers` 表检索 `customer_name`，从 `products` 表检索 `product_name`。我们使用 `order_items` 表中的对应 ID 连接表。

### 第7节：别名

连接表时，为表或列分配别名以提高简洁性和可读性会很有用。别名是在特定查询内分配给表或列的临时名称。以下是一个示例：

```sql
SELECT c.customer_name, o.order_id
FROM customers AS c
LEFT JOIN orders AS o
ON c.customer_id = o.customer_id;
```

在此示例中，我们将别名 `c` 分配给 `customers` 表，将别名 `o` 分配给 `orders` 表。这简化了查询并使引用表变得更容易。

通过理解和应用表连接，您可以从多个表中合并数据并检索全面的信息。无论您需要组合相关数据还是从数据库中提取特定见解，连接都是一个强大的工具。在下一章中，我们将探讨聚合函数，它允许您在 SQL 查询中执行计算并汇总数据。

## 第6章：聚合函数和分组数据

在之前的章节中，我们学习了如何从多个表中检索和连接数据。在本章中，我们将探讨 SQL 中聚合函数的概念。聚合函数允许您对一组值执行计算并以有意义的方式汇总数据。此外，我们还将介绍分组数据，以便根据特定标准进一步分析和操作信息。到本章结束时，您将对 `COUNT`、`SUM`、`AVG`、`MAX` 和 `MIN` 等聚合函数以及如何使用 `GROUP BY` 子句对数据进行分组有深入的理解。

### 第1节：COUNT

`COUNT` 函数用于计算列中的行数或非 `NULL` 值的数量。它通常用于计算表中的总记录数。以下是基本语法：

```sql
SELECT COUNT(column)
FROM table;
```

示例：

```sql
SELECT COUNT(*) FROM customers;
```

在此示例中，我们检索 `customers` 表中的总记录数。

### 第2节：SUM

`SUM` 函数计算数值列中值的总和。它通常用于计算总计或累计和。以下是语法：

```sql
SELECT SUM(column)
FROM table;
```

示例：

```sql
SELECT SUM(price) FROM orders;
```

在此示例中，我们计算 `orders` 表中 `price` 列的总和。

### 第3节：AVG

`AVG` 函数计算数值列的平均值。它提供指定数据的平均值。以下是语法：

```sql
SELECT AVG(column)
FROM table;
```

示例：

```sql
SELECT AVG(age) FROM employees;
```

在此示例中，我们计算 `employees` 表中员工的平均年龄。

### 第4节：MAX

`MAX` 函数从列中检索最大值。它用于查找数据集中的最高值。以下是语法：

```sql
SELECT MAX(column)
FROM table;
```

示例：

```sql
SELECT MAX(salary) FROM employees;
```

在此示例中，我们从 `employees` 表中检索最高薪资。

### 第5节：MIN

`MIN` 函数从列中检索最小值。它用于查找数据集中的最低值。以下是语法：

```sql
SELECT MIN(column)
FROM table;
```

示例：

```sql
SELECT MIN(quantity) FROM inventory;
```

在此示例中，我们从 `inventory` 表中检索最小数量。

### 第 6 节：GROUP BY

`GROUP BY` 子句用于基于一个或多个列对数据进行分组。它允许您在每个组内聚合和汇总数据。以下是语法：

```sql
SELECT column1, column2, ..., aggregate_function(column)
FROM table
GROUP BY column1, column2, ...;
```

示例：

```sql
SELECT category, COUNT(*)
FROM products
GROUP BY category;
```

在此示例中，我们按产品类别对产品进行分组，并计算每个类别中的产品数量。

### 第 7 节：HAVING

`HAVING` 子句用于根据特定条件过滤组。它的工作原理与 `WHERE` 子句类似，但作用于分组后的数据。以下是语法：

```sql
SELECT column1, column2, ..., aggregate_function(column)
FROM table
GROUP BY column1, column2, ...
HAVING condition;
```

示例：

```sql
SELECT category, AVG(price)
FROM products
GROUP BY category
HAVING AVG(price) > 1000;
```

在此示例中，我们按类别对产品进行分组，计算每个类别内的平均价格，并仅检索平均价格高于 1000 的类别

在本章中，我们探索了 SQL 中聚合函数的强大功能。我们学习了如何使用 `COUNT`、`SUM`、`AVG`、`MAX` 和 `MIN` 对数值数据进行计算并获得有用的汇总。此外，我们发现了 `GROUP BY` 子句，它允许我们基于特定列对数据进行分组，并在每个组内应用聚合函数。`HAVING` 子句进一步使我们能够根据条件过滤组。

通过利用聚合函数和对数据进行分组，您可以获得有价值的见解，并以更有意义的方式分析数据。这些技术在处理大型数据集以及需要对数据子集进行计算时特别有用。

## 第 7 章：SQL 中的数据操作

在前几章中，我们专注于从数据库表中检索和分析数据。在本章中，我们将探讨 SQL 数据操作的核心方面。数据操作涉及在数据库表中插入、更新和删除记录。了解这些操作对于有效地维护和修改数据至关重要。到本章结束时，您将对如何使用 SQL 语句操作数据有扎实的理解。

### 第 1 节：插入数据

`INSERT` 语句用于向表中添加新记录。它允许您为每个列指定值或从另一个表插入数据。以下是基本语法：

```sql
INSERT INTO table (column1, column2, ...)
VALUES (value1, value2, ...);
```

示例 1：

```sql
INSERT INTO customers (customer_name, email, phone)
VALUES ('John Smith','john@example.com','555-1234');
```

在此示例中，我们向 `customers` 表插入一条新记录，并为 `customer_name`、`email` 和 `phone` 列指定值。

### 示例 2：

```sql
INSERT INTO customers (customer_name, email, phone)
SELECT name, email, phone
FROM old_customers;
```

在此示例中，我们通过从 `old_customers` 表选择数据向 `customers` 表插入记录。`SELECT` 语句中的列名应与目标表的列名匹配。

### 第 2 节：更新数据

`UPDATE` 语句用于修改表中的现有记录。它允许您同时更新特定列或多个列。以下是基本语法：

```sql
UPDATE table
SET column1 = value1, column2 = value2, ...
WHERE condition;
```

示例：

```sql
UPDATE employees
SET salary = salary * 1.1
WHERE department = 'Sales';
```

在此示例中，我们通过将工资提高 10% 来更新 `Sales` 部门员工的 `salary` 列。

### 第 3 节：删除数据

`DELETE` 语句用于从表中删除记录。它允许您指定条件以删除特定行或从表中删除所有行。以下是基本语法：

```sql
DELETE FROM table
WHERE condition;
```

示例 1：

```sql
DELETE FROM customers
WHERE customer_id = 5;
```

在此示例中，我们删除 `customers` 表中 `customer_id` 等于 5 的记录。

示例 2：

```sql
DELETE FROM orders
WHERE order_date < '2022-01-01';
```
