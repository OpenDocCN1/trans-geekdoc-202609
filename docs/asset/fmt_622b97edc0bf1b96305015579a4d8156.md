
# 句子

句子是由一个或多个单词组成的语法单位，用于表达独立的陈述、疑问、请求、命令、感叹等，且通常包含主语和谓语。句子通常以大写字母开头，并根据其类型以适当的标点符号结尾。请参阅下图：

# 文档与文本语料库

以书面、印刷或数字化文本文件形式存在的句子集合称为文本 `document`（文档）。文档的集合称为文本 `corpus`（语料库）。它通常由书面文本主体组成，常以数字化形式存储。随着时间的推移，针对各种 NLP 任务构建了许多大型文本语料库。

# 语言的语义结构

研究语言意义的学科称为语义学。含义相近的单词可以在数据库中链接在一起，这对于理解语言意义非常有用。在英语等语言中，两个意义相同的单词可能因时态、数等不同而拼写不同。在法语等语言中，指代不同性别的形容词也会使用不同的拼写。语言中最小的有意义且句法正确的单位称为 `lemma`（词元/引导词）或 `lexeme`（词汇项）。

单词的含义可能因其在句子中的位置和上下文而改变。存在拼写或发音相同但含义不同的单词，称为 `homonyms`（同音异义词/同形异义词）。例如，在 ‘a cricket bat’（板球球拍）和 ‘a bat which is seen at night’（夜间可见的蝙蝠）这两个短语中，单词 ‘bat’ 含义不同。这类词之间的关系称为 `homonymy`（同音异义/同形异义现象）。`Capitonyms`（大小写异义词）是拼写相同但首字母大写时含义不同的单词。例如，五月 和短语 ‘may be’（可能）。`Synonyms`（同义词）是拼写不同但含义相同的单词。`Polysemes`（多义词）类似于同音异义。如果一个词可用于表达不同含义，则它是多义的。这两个概念的区别非常微妙。如果你听到（或读到）两个发音（或书写）相同但含义不完全相同的词，我们必须判断它到底是两个不同的词（同音异义词），还是一个词在两种不同方式下的使用（多义词）。多义词的例子是 “Good man” 与 “Good artist”。前者中 “good” 描述道德品质，后者描述技能水平。

# WordNet

WordNet 是一个词汇数据库，包含如前所述的单词间语义关系，涵盖 200 多种语言，将同义词归类为同义词集，并附带简短定义和用法示例。其主要用途在于自动文本分析和人工智能应用。

# 文本预处理

从文本中以计算方式提取上述句法和语义结构作为文本特征的过程称为文本预处理。这些结构帮助我们将非结构化文本文档转化为结构化的向量化形式，可用于训练模型以解决文本分类、文本摘要、问答等各类 AI 问题。以下是应用于任意文本数据进行特征提取的几种标准文本预处理技术：

*   **句子分割**：将文本拆分为句子的过程也称为句子分段。这主要是一种基于规则的方法；例如，句子必须以大写字母开头，并以特定的标点符号结尾。

*   **词元化**：这是将句子拆分为其组成词语的过程。在此过程中，标点字符会被拆分并分离为独立的词元。这些也是基于规则的，我们可以指定使用正则表达式拆分词元的规则，也可以使用标准的语法规则进行拆分。

*   **文本清洗**：文本中常见的词汇，如常用动词、连词，例如 `{ a, an, and, but, how, in, is, are, on, or, the, what, will }` 称为 `stopwords`（停用词），会从词元列表中移除。转小写、移除特殊字符、空白字符也是常见的预处理步骤。

*   **词形还原**：移除词的词缀以获取词的基本形式。这种基本形式必须是一个语义正确的单词。通常使用类 WordNet 的数据库来对单词进行词形还原。例如，以下所有单词 `{connection, connections, connective, connected, connecting}` 都源自词根 ‘connect’，而 ‘connect’ 是它们的词元。

*   **词干提取**：词干提取类似于词形还原，不同之处在于输出不必是一个有意义的单词。这是一种基于规则的方法。Porter 词干提取器是一种流行的基于规则的词干提取算法。

*   **子词词元化**：将单词进一步分割成不必具有任何意义的小块，称为子词词元化。这是为了解决 `Out Of Vocabulary` (`OOV`，词表外) 词汇而需要的。假设我们从语料库中提取了所有单词，我们称之为该语料库的 `vocabulary`（词汇表/词表）。我们仅基于这些单词构建文本特征，文本模型也以这些特征作为输入。现在，给定用于训练模型推理的新文本，如果该文本包含不在我们词表中的新单词，我们称之为 OOV 词。如果我们有子词词元，则可以将新单词拆分为子词元，这些子词元属于我们的词表。许多最先进的 NLP 模型都使用这种词元化技术。我们详细讨论了一种子词词元化方法。

*   **词性标注**：词性标签也可以作为文本的特征使用。

在各种编程语言中都有多种文本预处理库。在 Python 中，我们有 `nltk`、`genism`、`scikit-learn`。建议读者参阅“进一步阅读”部分中的 `[1]`、`[2]` 以获取详细示例。NLTK 文档 `[3]` 也提供了大量入门示例。

# 文本模型

*“所有模型都是错的，但有些是有用的！”* ——这是统计学中的一句名言，通常归功于统计学家乔治·博克斯。这在 NLP 领域同样适用。存在各种文本模型，每种模型适合解决文本中的特定问题。没有任何单一模型能够代表文本结构的所有方面。例如，如果我们想通过查看某些关键词来判断一封邮件是否为垃圾邮件，垃圾邮件中通常出现的关键词和关键短语可能很有用。因此，对于这个问题，将文本建模为词袋就足够了。我们可能不需要考虑书面文本中的结构细节。然而，如果我们想分析关于一部电影或新发布产品的评论是正面还是负面，我们可能需要利用文本中更深层的语义和句法关系。

文本模型可以在所有层级构建：文档级、句子级、段落级和单词级。如果我们想比较或分类一组文档，我们会倾向于使用文档级文本模型。对于构建聊天机器人，我们需要构建句子或短语级模型，能够跟踪对话上下文并提供期望的回复句子。

# 词袋模型

从给定的文本文档出发，我们应用前面讨论的标准预处理技术，每个文档被表示为一个无序的单词列表，即文档中出现的已处理单词。这种表示形式不捕捉文本的任何句法或语义属性。这是最简单的文本模型。将无序单词列表转换为数值表示有多种方法，具体讨论如下。

# 向量空间模型

给定从文档中提取的 BoW，我们可以为文档创建一个特征向量，其中每个特征是一个单词，特征的值应反映该单词在文档中的出现情况和重要性。整个文档被表示为一个特征向量，每个特征向量对应向量空间中的一个点。该向量空间的维度为 `V`，其中 `V` 是词汇表的大小。这里，词汇表是基于整个语料库构建的。

## 基于计数或布尔值

给定一个文档语料库，我们可以将每个文档表示为一个向量。假设整个语料库中有 V 个唯一单词。那么，每个文档将被表示为一个 V 维向量。我们称 V 为语料库的 `vocabulary`（词汇表/词表）大小。词汇表中的每个单词代表向量中的一个特征。如果词汇表中的某个单词 w 未出现在特定文档中，则对应的特征值为零；否则，特征值为该单词在特定文档中出现的次数，即词频。*表 11.1* 展示了一个包含两个文档及其对应词频向量的语料库示例。语料库中共有七个唯一单词。

## 词频-逆文档频率

基于计数或布尔值的模型赋予语料库中所有单词同等的重要性。可能存在一组单词在语料库中更频繁，且几乎出现在每个文档中。这些单词可能无法为语料库中的文档提供任何重要特征。相反，仅在极少数文档中出现的稀有单词可能提供一些区分性特征。文档频率是指包含某个单词的文档数量。**逆文档频率** 记为 **IDF**，其计算方法是将语料库中文档总数除以每个词项的文档频率，然后对结果应用对数缩放。我们可以给每个词项的文档频率加 1，以防止仅出现在一个文档中的词项以及语料库中不存在的词项导致 idf = 0，这也能防止计算 `idf` 时出现除零错误。`term frequency`（词频）是词项在文档中的计数，因此我们用 `idf` 加权词频，从而得到每个词项的 tf-idf，公式如下：

# 潜在语义索引模型

向量空间模型无法处理自然语言中的两个经典问题：*同义词* 和 *多义词*。在信息检索的语境下，我们需要将文本查询与文档集合进行匹配，查询应匹配包含同义词的文档，而不应匹配包含多义词的文档。仅靠向量空间模型无法做到这一点。在向量空间模型中获得的文档-词项矩阵 `C` 可以通过奇异值分解修改为低秩近似矩阵 `C[k]`。这为语料库中的每个文档产生了一种新的表示。我们也可以将查询投射到这种低秩表示中，从而在此低秩表示中计算查询-文档相似度分数。这个过程称为 **潜在语义索引** (**LSI**)。这种低秩近似在余弦相似度意义上保持距离不变，即在原始向量空间中相似的两个文档，在由 LSI 定义的低维子空间中也应当相似或接近。让我们通过 *图 11.2* 所示的一个小型文档语料库来更好地理解这一点：

# 主题模型

任何文本文档都包含关于某个主题的信息，如科学、技术、娱乐、健康、体育、商业、政治等。文档可能包含多个主题，但极不可能包含所有可能的主题。

给定一个文档语料库（如新闻文章），我们总是可以为其分配一个或多个主题。这些主题可以表示为词袋。例如， *图 11.4* 展示了一个讨论四个主题的示例文档：艺术、预算、儿童和教育。这些主题中的每一个都可以与文档中的某些词相关联。同一个词可能出现在两个不同的主题中。例如，“state” 一词可能出现在“州”和“教育”两个主题中。通过查看多个文档并分析各主题下文档间的词频，可以最好地完成词到主题的分配。这种将文本文档表示为主题混合物的方法称为 *主题模型*。这些模型将主题表示为用 `z` 表示的潜在变量。我们将在接下来的两节中讨论两种类型的主题模型。请参考下图：

# 概率生成模型：潜在狄利克雷分布

现在，基于将文本文档视为来自少数几个主题的词的混合物这一视角，我们可以将朴素词袋模型增强为一种称为 **潜在狄利克雷分布** (**LDA**) 的概率生成模型。这基于狄利克雷分布，因此得名 LDA。

主题模型的基本思想是文档被表示为主题（潜在）的混合物，每个主题由词分布表征。因此，我们可以假设文档中的 *每个* 词都是通过两阶段采样过程生成的：

1.  从主题分布中选择一个主题。
2.  根据描述该主题的词分布，从该主题中选择词。

现在，主题分布必须从语料库中学习。假设有限数量的主题 M，我们可以将主题分布建模为多项式分布（在 *第 4 章，概率论* 的 *多元分布* 部分讨论过）。M 个类别的多项式分布将有 M 个参数 ![](img/2674.jpg)，其中 ![](img/2675.jpg)。我们如何找到这些 ![](img/2676.jpg)？我们没有分配给每个文档的主题，因此不能直接进行主题频率计数，并将每个主题的概率分配为每主题计数与总主题计数的比率。因此，我们采用贝叶斯方法。我们将为参数 ![](img/2676.jpg) 假设一个先验分布。这必须是一个连续分布，因为 ![](img/2676.jpg) 是连续变量，而且我们必须用约束 ![](img/2679.jpg) 来限制分布的样本。*狄利克雷分布* 记为 ![](img/2680.jpg) 具有这一性质，其中 ![](img/2681.jpg) 是一个 M 维向量。这在 *图 11.5* 中针对参数 ![](img/2682.jpg) 的各种值进行了描绘。
