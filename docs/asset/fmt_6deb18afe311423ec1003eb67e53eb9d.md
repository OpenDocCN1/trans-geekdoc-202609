
# 模型并行性

模型并行性具有明显的优势。它可用于训练无法仅放入单个 GPU 的模型。例如，假设我们有 10 个 GPU，想要训练一个简单的 `ResNet50` 模型。我们可以将前五层分配给 GPU 1，第二组五层分配给 GPU 2，依此类推，最后五层分配给 GPU 10。在训练期间，每次迭代中，前向传播必须先在 GPU 1 中完成，GPU 2 等待来自 GPU 1 的输出。前向传播完成后，我们计算位于 GPU 10 中的最后几层的梯度，并更新 GPU 10 中那些层的模型参数。然后梯度反向传播到 GPU 9 中的前几层。每个 GPU/节点就像工厂流水线上的一个隔间；它等待来自前一个隔间的产品，并将自己的产品发送到下一个隔间。请参阅图 7.2，其中模型被拆分到各个 GPU 上。

![图 7.2 模型并行性](img/c07f002.png)

**图 7.2** 模型并行性

增加深度学习模型的规模（层和参数）可提高复杂视觉模型的准确性。然而，单个 GPU 内存能容纳的最大模型规模是有限的。训练大型深度学习模型时，GPU 内存限制可能成为瓶颈。因此，可以使用模型并行性来克服在单个 GPU 上训练模型的相关限制。你可以将模型（层）拆分到多个 GPU 上。

你可能希望将训练扩展到一台机器上的多个 GPU、网络中的多台机器（每台机器有 0 个或多个 GPU）或 Cloud TPU。`tf.distribute.Strategy` 是一个用于跨多个 GPU、多台机器或 TPU 分发训练的 TensorFlow API。（请参阅 `www.tensorflow.org/guide/distributed_training`。）使用此 API，你只需极少的代码更改即可分发现有模型和训练代码。表 7.1 解释了在 TensorFlow 中哪些策略受支持以及适用场景。

## 循环神经网络

循环神经网络（RNN）旨在处理数据序列。它们已被证明对于自然语言处理问题非常有效，在这些问题中，文本序列作为输入提供给模型。RNN 在时间序列预测和语音识别方面也取得了一定的成功。最流行的 RNN 类型是长短期记忆（LSTM）网络。LSTM 可用于模型中以接受一系列输入数据并进行预测，例如分配类标签或预测序列中的下一个数值或数值。

神经网络使用随机梯度下降进行训练，要求你在设计和配置模型时选择一个损失函数。损失是一个数字，指示模型在单个示例上的预测有多糟糕。如果模型的预测完美，损失为零；否则，损失更大。训练模型的目标是找到一组权重和偏置，使其在所有示例上的平均损失较低。损失函数是神经网络的重要组成部分之一。损失无非是神经网络的预测误差。而计算损失的方法称为损失函数。简单来说，损失用于计算梯度。而梯度用于更新神经网络的权重。

### 使用哪种损失函数

重要的是，损失函数的选择与神经网络输出层中使用的激活函数直接相关。这两个设计要素是相互关联的。表 7.2 根据 ML 问题总结了损失函数。

**表 7.2** 基于 ML 问题的损失函数总结

| | 输出 | 输出层配置或激活函数 | 损失函数 |
|---|---|---|---|
| 回归问题 | 数值输出 | 一个具有线性激活单元的节点 | 均方误差 (MSE) |
| 二分类问题 | 二元结果 | Sigmoid 激活单元 | 二元交叉熵、分类合页损失和平方合页损失 (Keras) |
| 多分类问题 | 单标签多类 | Softmax 激活函数 | 分类交叉熵（用于独热编码数据）和稀疏分类交叉熵（用于整数） |

以下是 TensorFlow 多分类的示例代码片段。模型在输出层中必须为每个类别设置一个节点，并使用 softmax 激活函数。损失函数 `sparse_categorical_crossentropy` 适用于整数编码的类标签（例如，某一类为 0，下一类为 1 等）。

```
#### define model
model = Sequential()
model.add(Dense(10, activation='relu', kernel_initializer='he_normal', input_shape=(n_features,)))
model.add(Dense(8, activation='relu', kernel_initializer='he_normal'))
model.add(Dense(3, activation='softmax'))

#### compile the model
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
```

### 梯度下降

梯度下降算法计算起始点处损失曲线的梯度。损失的梯度等于曲线的导数（斜率）。梯度既有大小又有方向（向量），且始终指向损失函数最陡峭上升的方向。梯度下降算法沿着负梯度的方向迈出一步，以尽可能快地减少损失。

### 学习率

正如我们所知，梯度向量既有方向又有大小。梯度下降算法将梯度乘以一个称为学习率（有时也称为 `step size`）的标量，以确定下一个点。例如，如果梯度大小为 2.5 而学习率为 0.01，则梯度下降算法将选取距离前一个点 0.025 的下一个点。

### 批次

在梯度下降中，批次是指在单次迭代中用于计算梯度的示例总数。到目前为止，我们假设批次是整个数据集。非常大的批次可能会导致即使是单次迭代也需要很长的计算时间。

### 批次大小

批次大小是批次中的示例数量。例如，SGD 的批次大小为 1，而小批量的批次大小通常在 10 到 1,000 之间。批次大小在训练和推理期间通常是固定的；不过，TensorFlow 允许动态批次大小。

### 轮次

一个轮次意味着使用所有训练数据训练神经网络的一次迭代。在一个轮次中，我们恰好使用所有数据一次。一次前向传递和一次后向传递合计为一次传递。一个轮次由一个或多个批次组成。

### 超参数

我们介绍了损失、学习率、批次大小和轮次。这些是在训练 ML 模型时可以更改的超参数。大多数机器学习程序员会花费相当多的时间来调整学习率。

*   如果选择的学习率太小，学习将花费太长时间。
*   相反，如果指定的批次大太大，模型计算可能需要更多时间。

#### 调整批次大小

以下是调整批次大小的最佳实践：

*   较小的小批量大小（不要太小）通常不仅比大批量大小导致训练算法的迭代次数更少，而且总体准确性更高；即在相同的训练时间内，神经网络性能更好。我们的平行坐标图也使一个关键的权衡变得非常明显：较大的批次大小训练时间较短，但准确性较低。
*   如果批次大小太小，训练会震荡；如果太大，训练将花费很长时间。
*   然而，使用较小的批次大小可以让梯度在每个轮次中更新更频繁，这可能导致每个轮次的损失减少更多。此外，使用较小批次训练的模型泛化能力更好。

#### 调整学习率

实现理想的学习率非常重要，原因如下：

*   过低和过高的学习率都会导致时间和资源的浪费。

##### 学习率与训练成本

* 学习率越低，训练时间越长。
* 训练时间越长，云 GPU 成本越高。
* 学习率过高可能导致模型无法准确预测。
* 学习率过小会导致训练耗时极长；过大则会导致训练过程震荡发散。

### 迁移学习

根据维基百科定义，*迁移学习*（https://en.wikipedia.org/wiki/Transfer_learning）是机器学习（ML）中的一个研究问题，侧重于存储解决某一问题时获得的知识，并将其应用于不同但相关的问题。例如，学习识别汽车获得的知识可应用于识别卡车。在深度学习中，迁移学习是一种技术：首先在一个与目标问题相似的问题上训练神经网络模型，然后将训练好的模型中的一层或多层用于在目标问题上训练的新模型中。

迁移学习是一种节省时间或获得更好性能的优化手段。

* 可以使用可用的预训练模型，作为训练自己模型的起点。
* 迁移学习使你能够针对数据量较少的问题开发模型。

### 半监督学习

半监督学习（SSL）是第三种学习类型。它是一种机器学习问题，涉及少量标记样本和大量未标记样本。半监督学习是一种 `machine learning` 方法，在训练期间将少量 `labeled data` 与大量未标记数据相结合。它介于 `unsupervised learning`（无标记训练数据）和 `supervised learning`（仅有标记训练数据）之间。

#### 何时需要半监督学习

当你没有足够的标记数据来生成准确模型，且没有资源获取更多数据时，可以使用半监督技术来扩大训练数据规模。

例如，假设你正在为一家大型银行开发欺诈检测模型。部分欺诈案例是已知的，但其他欺诈实例却在不知不觉中溜走了。你可以用已知的欺诈实例标记数据集，但其余数据将保持未标记状态。你可以使用半监督学习算法对数据进行标记，并用新标记的数据集重新训练模型。然后，将重新训练的模型应用于新数据，利用监督机器学习技术更准确地识别欺诈。然而，无法验证算法生成的标签是否 100% 准确，导致结果不如传统监督技术可靠。

以下是一些用例：

* 欺诈检测或异常检测
* 聚类
* 语音识别
* 网页内容分类
* 文本文档分类

#### SSL 的局限性

在极少量标记数据和大量未标记数据的情况下，半监督学习在分类任务中显示出良好效果。但这并不意味着它适用于所有任务。如果标记数据部分不能代表整体分布，该方法可能会失效。

### 数据增强

神经网络通常拥有大量参数。你需要向机器学习模型展示成比例的示例数量以获得良好性能。此外，所需参数数量与模型执行任务的复杂度成正比。

训练神经网络需要大量数据示例。在大多数用例中，很难找到包含大量示例的相关数据集。因此，为了获取更多数据或示例来训练神经网络，你需要对现有数据集进行微小改动——例如翻转、平移或旋转。神经网络会将这些视为不同的图像。这就是*数据增强*，即在数据有限的情况下，使用合成修改后的数据（方向、翻转或旋转）来训练神经网络。

即使你拥有大量数据，增加数据集中相关数据的数量也会有所帮助。在 ML 流水线中应用增强主要有两种方式：离线增强和在线增强。

#### 离线增强

在离线增强中，你预先执行所有必要的转换，从本质上增加数据集的大小。这种方法适用于相对较小的数据集，因为数据集大小会按你执行的转换数量等比例增加。例如，通过旋转所有图像，可以将数据集大小增加 2 倍。

#### 在线增强

在在线增强中，你在将小批量数据馈送给机器学习模型之前，对其执行数据增强转换。这也称为*即时增强*。这种方法适用于大数据集，因为你会将小批量数据馈送给模型。

以下列表包含一些针对图像的数据增强技术：

* 翻转
* 旋转
* 裁剪
* 缩放
* 高斯噪声（添加适量噪声以增强学习能力）
* 平移
* 条件生成对抗网络（GANs），将一个域中的图像转换为另一个域中的图像
* `Transfer learning`，在数据稀缺时给模型更好的机会

### 模型泛化及处理过拟合与欠拟合的策略

训练神经网络模型时，存在两个重要概念：

* **偏差：** 偏差是模型平均预测值与我们试图预测的正确值之间的差异。它实际上是训练数据的误差率。误差率高则偏差高，误差低则偏差低。高偏差模型很少关注训练数据，过度简化模型。
* **方差：** 测试数据的误差率称为方差。误差率高称为高方差，误差率低称为低方差。高方差模型过度关注训练数据，无法泛化到未见过的数据。因此，此类模型在训练数据上表现很好，但在测试数据上误差率很高。

训练一个能很好地泛化到新数据的深度神经网络是一个具有挑战性的问题。容量太小的模型无法学习问题，而容量太大的模型会过度学习并过拟合训练数据集。这两种情况都会导致模型泛化能力差。

#### 偏差-方差权衡

你需要找到合适的平衡，避免过拟合或欠拟合数据。如果模型过于简单且参数很少，则可能具有高偏差和低方差。如果模型拥有大量参数，则会具有高方差和低偏差。这种复杂性的权衡就是偏差与方差之间存在权衡的原因。

欠拟合可以通过增加网络容量（权重）轻松解决，但过拟合需要使用专门技术。请参考 `www.geeksforgeeks.org/underfitting-and-overfitting-in-machine-learning` 了解更多。

#### 欠拟合

欠拟合模型无法充分学习问题，在训练数据集上表现不佳，在测试或验证数据集上也不理想。在偏差-方差权衡背景下，欠拟合模型具有高偏差和低方差。无论训练数据中的具体样本如何，它都无法学习问题。导致模型欠拟合的原因有以下几点：

*   用于训练的数据未经过清洗。
*   模型具有高偏差。

过拟合模型的性能在训练数据集中未见过的样本上变化很大。以下是一些减少欠拟合的方法：

*   增加模型复杂度。
*   通过特征工程增加特征数量。
*   从数据中移除噪声。
*   增加轮数或延长训练时长以获得更好的结果。

#### 过拟合

模型过度学习了训练数据，导致在新的未见样本上，甚至在训练数据集样本中添加统计噪声时，性能变化很大。过拟合模型具有低偏差和高方差。针对过拟合模型主要有两种处理思路：

*   通过在更多样本上训练网络来减少过拟合。
*   通过改变网络结构和参数的复杂度来减少过拟合。

以下是一些避免过拟合的方法：

*   正则化技术：下一节将详细解释。
*   `Dropout`：训练期间以概率方式移除输入。
*   `Noise`：训练期间向输入添加统计噪声。
*   `Early stopping`：监控模型在验证集上的性能，当性能下降时停止训练。
*   数据增强。
*   交叉验证。

参考此链接了解避免过拟合的 10 种方法：`www.v7labs.com/blog/overfitting`。

### 正则化

正则化发挥作用，将学习到的估计值向 0 收缩。换句话说，它通过添加惩罚项来调整损失函数，防止系数过度波动，从而降低过拟合的风险。

L1 和 L2 是两种常见的正则化方法。当你试图减少特征时使用 L1，当你寻求稳定模型时使用 L2。表 7.3 总结了这两种技术的区别。

**表 7.3** L1 与 L2 正则化的区别

| L1 正则化 | L2 正则化 |
| --- | --- |
| L1 正则化，也称为 L1 范数或套索（在回归问题中），通过将参数向 0 收缩来对抗过拟合。这会使某些特征变得多余。因此，如果你有大量特征，这非常适合特征选择。 | L2 正则化，或 L2 范数或岭回归（在回归问题中），通过强制权重变小但不使其恰好为 0 来对抗过拟合。 |
| L1 正则化惩罚权重绝对值之和。 | L2 正则化惩罚权重平方和。 |
| L1 正则化内置特征选择功能。 | L2 正则化不执行特征选择。 |
| L1 正则化对异常值具有鲁棒性。 | L2 正则化对异常值不具鲁棒性。 |
| L1 正则化有助于特征选择和减小模型规模，从而得到更小的模型。 | L2 正则化始终能改善线性模型的泛化能力。 |

本节介绍了正则化。接下来我们将介绍训练神经网络时反向传播可能出错的常见方式及正则化对策：

*   **梯度爆炸：** 如果网络中的权重非常大，则较低层的梯度将涉及许多大项的乘积，导致梯度过大而无法收敛。批量归一化和降低学习率有助于防止梯度爆炸。
*   **ReLU 单元死亡：** 线性整流激活函数，简称 `ReLU`，是一种线性函数，如果输入为正则直接输出输入，否则输出 0。隐藏层使用整流函数的网络称为整流网络。一旦 `ReLU` 单元的加权和低于 0，该单元可能会卡住。它输出 0 激活值，不对网络输出做任何贡献，且在反向传播期间梯度无法再通过它流动。由于梯度来源被切断，`ReLU` 的输入可能永远无 longer 变化足以使加权和重新回到 0 以上。降低学习率有助于防止 `ReLU` 单元死亡。
*   **梯度消失：** 较低层（更接近输入层）的梯度可能变得非常小。当较低层的梯度向 0 消失时，这些层训练得非常慢，或者根本不训练。`ReLU` 激活函数有助于防止梯度消失。
*   **Dropout 正则化：** 这种正则化类型对神经网络很有用。它通过在单个梯度步骤中随机“丢弃”网络中的单元激活值来工作。丢弃得越多，正则化越强：
    *   `0.0` = 无 Dropout 正则化。
    *   `1.0` = 丢弃所有内容。模型什么也学不到。
    *   `0.0` 和 `1.0` 之间的值 = 更有用。
