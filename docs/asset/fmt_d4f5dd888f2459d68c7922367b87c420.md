
其中 $f_{\bot}$ 是 $f$ 正交于 $A$ 的部分。由再生性质可得

$$
f(\mathbf{x}_{m}) = \left\langle f, \kappa( \cdot , \mathbf{x}_{m}) \right\rangle = \left\langle \sum_{n = 1}^{N} \theta_{n} \kappa( \cdot , \mathbf{x}_{n}), \kappa( \cdot , \mathbf{x}_{m}) \right\rangle = \sum_{n = 1}^{N} \theta_{n} \kappa(\mathbf{x}_{m}, \mathbf{x}_{n}),
$$

我们利用了这样一个事实：`⟨f[⊥], κ(⋅, x[n])⟩ = 0`，`n = 1, 2, …, N`。换句话说，公式 (11.17) 中的展开保证了在训练点处，`f` 的值不依赖于 `f[⊥]`。因此，公式 (11.16) 中对应经验损失的第一项*不*依赖于 `f[⊥]`。此外，对于所有的 `f[⊥]`，我们有

```
Ω(‖f‖²) = Ω(‖∑_{n=1}^{N} θ_n κ(⋅, x_n)‖² + ‖f_⊥‖²) ≥ Ω(‖∑_{n=1}^{N} θ_n κ(⋅, x_n)‖²).
```

因此，对于*任意*选择的 `θ[n]`，`n = 1, 2, …, N`，公式 (11.16) 中的代价函数在 `f[⊥] = 0` 时取得最小值。因此，该断言得证。 □

该定理最早见于文献 [61]。文献 [2] 探讨了该定理成立的条件，并推导了相关的充分必要条件。该定理的重要性在于：为了关于 `f` 优化公式 (11.16)，需使用公式 (11.17) 中的展开，并关于参数的*有限*集合 `θ[n]`，`n = 1, 2, …, N` 进行最小化。

请注意，在高维/无限维空间中工作时，正则化项的存在几乎无法避免；否则，由于仅使用有限数量的数据样本进行训练，所得解将遭受过拟合。正则化对泛化性能及相关解的稳定性的影响已在许多经典论文中得到研究（例如，[18,39,79]）。

通常，常会添加一个偏置项，并假设最小化函数具有以下表示形式：

`f̃ = f + b`， (11.18)

$f( \cdot ) = \sum\limits_{n = 1}^{N}\theta_{n}\kappa( \cdot ,\mathbf{x}_{n}).$

(11.19)

在实践中，使用偏置项（它不参与正则化）被证明可以提高性能。首先，它扩大了搜索解的函数类，并可能带来更好的性能。此外，由于正则化项 $\Omega(\|f\|²)$ 施加的惩罚，最小化器会将函数在训练点处取得的值推向更小的值。$b$ 的存在试图“吸收”其中的一部分作用（例如，参见 [112]）。

## 11.7 核岭回归

岭回归在第 3 章中已被引入，并在第 6 章中得到更详细的阐述。在这里，我们将在一般 RKHS 中陈述该任务。所遵循的路径是将为线性模型开发的技术推广到更一般 RKHS 的典型途径。

我们假设由训练集 `(y[n], x[n]) ∈ ℝ × ℝ^(l)` 表示的数据生成机制，是通过非线性回归任务建模的：

`y[n] = g(x[n]) + η[n], n = 1, 2, …, N.`

`κ : ℝ^(l) × ℝ^(l) ↦ ℝ.`

受表达式定理的启发，我们采用以下展开：

```
f(x) = ∑_{n = 1}^{N} θ_n κ(x, x_n).
```

根据核岭回归方法，涉及的未知参数通过以下任务进行估计：

$$
\widehat{\mathbf{\theta}} = \arg\min_{\mathbf{\theta}} J(\mathbf{\theta}), \quad J(\mathbf{\theta}) := \sum_{n=1}^{N} \left( y_{n} - \sum_{m=1}^{N} \theta_{m} \kappa(\mathbf{x}_{n}, \mathbf{x}_{m}) \right)^{2} + C \langle f, f \rangle,

(11.24)

$$

$$

(11.25)

其中

$$

## 11.8 支持向量回归

尽管平方误差损失函数（与最小二乘法相关）有其优点，但并不总是优化的最佳准则。在存在非高斯长尾噪声（即相对较大值的概率不可忽略）的情况下，因此会有更多的噪声*离群值*，平方误差准则对误差的平方依赖会偏向与离群值存在相关的值。回顾第 3 章，在白高斯噪声假设下，最小二乘法等价于最大似然估计。此外，在此假设下，最小二乘估计量达到克拉美-罗界，并成为最小方差估计量。然而，在其他噪声场景下，必须寻找替代准则。

Huber [54] 研究了在存在离群值情况下的优化任务，其目标是获得一种选择损失函数的策略，使其最好地“匹配”噪声模型。他证明了，假设噪声具有对称概率密度函数（PDF），最优极大极小策略^(⁷⁸) 为：

```
ℒ(y, f(x)) = |y − f(x)|
```

这导出了*最小模*方法。从第 5.8 节可知，该损失函数的随机梯度在线版本导出了符号误差 LMS。Huber 还表明，如果噪声包含两个分量，一个对应高斯分布，另一个对应任意 PDF（保持对称），则在极大极小意义上最好的损失函数由下式给出

$$
\mathcal{L}\left( y,f(\mathbf{x}) \right) = \begin{cases} 
\epsilon|y - f(\mathbf{x})| - \frac{\epsilon^{2}}{2}, & \quad\text{if}\quad|y - f(\mathbf{x})| > \epsilon, \\ 
\frac{1}{2}|y - f(\mathbf{x})|^{2}, & \quad\text{if}\quad|y - f(\mathbf{x})| \leqslant \epsilon, 
\end{cases}
$$

对于某个参数 $\epsilon$。这被称为 Huber 损失函数，如 图 11.10 所示。一种可以近似 Huber 损失函数的损失函数，正如我们将看到的，它具有一些良好的计算特性，即所谓的*线性 $\epsilon$* 不敏感损失函数，定义如下（另见第 8 章）

$$
\mathcal{L}\left( y,f(\mathbf{x}) \right) = \begin{cases} 
|y - f(\mathbf{x})| - \epsilon, & \quad\text{if}\quad|y - f(\mathbf{x})| > \epsilon, \\ 
0, & \quad\text{if}\quad|y - f(\mathbf{x})| \leqslant \epsilon, 
\end{cases}
$$

(11.28)

如 图 11.10 所示。注意当 $\epsilon = 0$ 时，它与绝对值损失函数一致，并且对于 $\epsilon < 1$ 的小值，它接近 Huber 损失。另一个版本是*二次 $\epsilon$* 不敏感损失函数，定义如下

$$
\mathcal{L}\left( y,f(\mathbf{x}) \right) = \begin{cases} 
|y - f(\mathbf{x}))|^{2} - \epsilon, & \quad\text{if}\quad|y - f(\mathbf{x})| > \epsilon, \\ 
0, & \quad\text{if}\quad|y - f(\mathbf{x})| \leqslant \epsilon, 
\end{cases}
$$

(11.29)

当 `ϵ = 0` 时，这与平方误差损失相吻合。对应的图形如 图 11.10 所示。请注意，前面讨论的两个 `ϵ`-不敏感损失函数保留了其凸性质；然而，它们不再在所有点上都可微。

### 11.8.1 线性 `ϵ`-不敏感最优回归

现在让我们采用公式 (11.28) 作为损失函数来量化模型拟合优度。我们将处理公式 (11.23) 中的回归任务，对 `f` 采用线性模型，即

`f(x) = θ^(T)x + θ[0]`

一旦我们获得以内积运算表示的解，`f` 落在 RKHS（再生核希尔伯特空间）中的更一般解将通过核技巧获得；即内积将被核函数计算所替代。

现在让我们引入两组*辅助*变量。如果

`y[n] − θ^(T)x[n] − θ[0] ≥ ϵ`

定义 `ξ̃[n] ≥ 0`，使得

`y[n] − θ^(T)x[n] − θ[0] ≤ ϵ + ξ̃[n]`

请注意，理想情况下，我们希望选择 `θ, θ[0]`，使得 `ξ̃[n] = 0`，因为这将使损失函数中相应项的贡献等于零。此外，如果

*y*[*n*] − **θ**^(*T*)**x**[*n*] − *θ*[0] ≤ − *ϵ*

定义 *ξ*[*n*] ≥ 0，使得

**θ**^(*T*)**x**[*n*] + *θ*[0] − *y*[*n*] ≤ *ϵ* + *ξ*[*n*]。

我们再次希望选择未知参数集，使得 *ξ*[*n*] 为零。

我们现在准备好围绕相应的经验代价来构建最小化任务，该代价由 **θ** 的范数正则化，并用辅助变量表示为^(⁷⁹)

```
minimize J(θ, θ₀, ξ, ξ̃) = ½‖θ‖² + C(∑_{n=1}^N ξ_n + ∑_{n=1}^N ξ̃_n),
```

约束条件为 *y*[*n*] − **θ**^(*T*)**x**[*n*] − *θ*[0] ≤ *ϵ* + *ξ̃*[*n*]，*n* = 1, 2, …, *N*，

**θ**^(*T*)**x**[*n*] + *θ*[0] − *y*[*n*] ≤ *ϵ* + *ξ*[*n*]，*n* = 1, 2, …, *N*。

$\quad\widetilde{\xi_{n}} \geqslant 0,\ \xi_{n} \geqslant 0,\ n = 1,2,\ldots,N.$

(11.33)

在进一步讨论之前，有必要做一些解释。

*   辅助变量 $\widetilde{\xi_{n}}$ 和 $\xi[n]$，$n = 1, 2, \ldots, N$，它们衡量相对于 $\epsilon$ 的超额误差，被称为*松弛变量*。请注意，根据 $\epsilon$ 不敏感原理，绝对值小于或等于 $\epsilon$ 的误差对代价函数的贡献为零。前述优化任务试图估计 $\boldsymbol{\theta}$、$\theta_{0}$，使得误差值大于 $\epsilon$ 和小于 $-\epsilon$ 的贡献最小化。因此，(11.30)–(11.33) 中的优化任务等价于最小化正则化经验风险函数

$$
\frac{1}{2}||\boldsymbol{\theta}||^{2} + C\sum\limits_{n = 1}^{N}\mathcal{L}\left( y_{n},\boldsymbol{\theta}^{T}\boldsymbol{x}_{n} + \theta_{0} \right),
$$
