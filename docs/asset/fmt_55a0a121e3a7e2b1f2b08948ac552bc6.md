# 第 4 章：选择合适的 ML 基础设施

在本章中，我们将讨论针对不同类型数据进行训练以及各种部署场景的硬件要求。硬件要求取决于您选择的机器学习 (ML) 算法类型、训练方法（自定义、AutoML 或预训练）以及数据类型。

通常，用于视频和图像的 ML 模型在每个训练循环中需要大量计算，包括矩阵乘法、加法、减法和微分。这些操作在非常大的矩阵上执行，有时每个数据点可能高达数兆字节。当您拥有数百万个数据点时，这对传统的通用 CPU 来说就成了一个问题。因此，GPU（最初用于视频渲染或游戏机）被重新用于训练 ML 模型。后来，Google 创建了称为张量处理单元 (TPU) 的定制 ASIC，其性能表现更佳。这些技术最初应用于视频和图像，随后应用于自然语言处理任务。它们极大地提高了翻译、文本分类以及一般文本到文本问题（模型的输入和输出均为文本）的性能。

第一种方法是使用任何可用的、现成的预训练模型。这些模型已经由 Google 在大型数据集上训练完成。这些预训练模型已部署完毕，可通过 API 直接使用。Google 管理这些模型的部署；因此，作为用户，您只需考虑调用 API 的次数。

使用预训练模型最大的优势在于易用性，以及您能以多快的速度将 ML 融入您的应用程序。在这种情况下，您无需考虑算法、训练方法、训练硬件、部署硬件、可扩展性等。

预训练模型应是您的首选。请仔细考虑预训练模型，并评估它是否适合您的用例。您可以先在应用程序中使用预训练模型，如果认为需要更好的模型，再转向 AutoML 或自定义模型。

预训练模型被成千上万的用户使用，面对数百万的请求，它们由一个工程师团队维护。在所有希望在应用程序中使用 ML 的用户中，大多数会选择预训练模型。图 4.1 以金字塔形式展示了这些模型。您会注意到底层（宽阔的一层）代表使用预训练模型的用户数量。

您甚至不必是 ML 工程师就能使用预训练模型。任何开发者都可以通过 API 使用预训练模型。它们可以通过 Python、Java 和 Node.js SDK 轻松使用。我们将在本章后面提供可用预训练模型的详细列表。

使用预训练模型时，您无需预配任何云资源，仅通过 API 使用。这称为*无服务器*方式，您将根据向 API 发出请求的次数付费。部分 API 提供免费层级。这是预训练模型通过 API 使用如此流行的原因之一。

现在，虽然预训练模型对大多数用户效果良好，但有时可能不适合您。这是最方便的选项，但也是可定制性最低的。假设您使用 Vision API 对植物进行分类，但现在想识别植物的确切亚种。虽然 Vision API 可以提供数千个标签，但它可能没有植物亚种的名称。在这种情况下，您可以考虑下一个选项：AutoML。

Vertex AI AutoML 是一种使用您自己的数据构建您自己的模型的方法。有些流行的机器学习问题已被研究数十年并被深入理解。这些问题（例如图像分类和文本翻译）过去被多次使用，所有的细微差别和变体都已被识别。AutoML 会选择最佳的 ML 算法，它唯一需要的就是数据。就像“只需加水”的蛋糕粉，AutoML 可以被视为“只需加数据”。然后您需要对数据进行格式化并进行质量控制。

与预训练模型不同，您需要为训练和部署模型预配云资源实例。在训练时，您必须决定要预配多少小时的实例时间；在部署期间，您将决定模型是部署在云端、现场设备（如 Android 手机）还是其他物联网设备上。我们将在本章后面查看硬件预配选项。

AutoML 是图 4.1 中金字塔的第二层，通常是希望使用自己的数据训练模型的用户的去处。AutoML 赋予您构建自己模型的能力，同时不需要 ML 专家团队来构建它们。

假设您发现您的用例独一无二，且没有可用的 AutoML。在这种情况下，您可以在 Vertex AI 中使用自定义模型。这是图 4.1 金字塔的顶层，它为您提供了算法选择、硬件配置和数据类型方面的极大灵活性。之所以将其置于金字塔顶端，是因为这种灵活性；但同时，它的基数也最小，因为拥有使用自定义模型专业知识的客户数量很少。我们将在本章后面介绍这种训练方法的硬件配置选项。

作为客户，您可以通过 Web 控制台（或 CLI、Python、Java 或 Node.js SDK）在几分钟内开始使用这些模型。

任何试图使用机器学习解决问题的开发者，都应首先检查 Google Cloud 平台上是否有可用的预训练模型，如果有，则应使用它。

*   Translation AI
*   Speech-to-Text 和 Text-to-Speech

除了预训练模型，Google Cloud 还提供针对特定问题的解决方案平台，这些平台包含预训练模型，并支持对现有模型进行调优：

*   Document AI

### Vision AI

Vision AI 为您提供便捷的 ML 算法访问权限，用于处理图像和照片，无需构建完整的机器学习基础设施。使用此服务，您可以执行图像分类、检测物体和人脸，以及通过光学字符识别 (OCR) 识别手写文字。

您也可以在浏览器中通过 `https://cloud.google.com/vision` 快速试用该服务。在生产环境中，通常将图像上传到服务或指向图像 URL 进行分析。

当您使用浏览器试用服务时，会获得四种类型的预测，如图 4.2 所示。首先，您会看到照片中检测到的物体。

### Video AI

此 API 拥有预训练的机器学习模型，可识别视频中的物体、地点和动作。它适用于存储的视频，也适用于流式视频（实时返回结果）。

您可以使用此服务识别视频中 20,000 多种不同的物体、地点和动作。您可以将结果作为视频中的元数据，用于从视频目录中搜索视频。例如，您可以使用该服务标记体育视频，并具体识别运动类型。您还可以处理直播流；例如，如果您有一个监控交通的街道摄像头，可以统计通过路口的汽车数量。

以下是 Video AI 的几个用例示例：

*   **用例 1：** 此 API 可用于构建视频推荐系统，利用 API 生成的标签和用户的观看历史。这使您能够基于视频内部细节（而不仅仅是外部元数据）进行推荐，从而极大地提升用户体验。
*   **用例 2：** 另一个用例是利用 API 的元数据为视频档案创建索引。这非常适合拥有 PB 级未索引数据的大众媒体公司。
*   **用例 3：** 插入视频中的广告有时可能与视频内容完全无关。这是另一个用例，您可以通过比较视频内容的时间段特定标签和广告内容来改善用户体验。

### Natural Language AI

Natural Language AI 使用预训练的机器学习模型从非结构化文本中获取洞察。其提供的主要服务包括实体提取、情感分析、语法分析和通用分类。

实体提取服务可识别人名、组织名、产品名、事件、地点等实体。如果找到相关链接，该服务还会用 Wikipedia 文章链接等额外信息丰富实体。尽管实体提取听起来像个简单问题，但它是一项非同小可的任务。例如，在句子 “Mr. Wood is a good actor” 中，需要相当的理解能力才能判断 “Mr. Wood” 是一个人名，而不是一种木材。

情感分析为每个句子、每个实体和整段文本提供带幅度的正面、负面或中性评分。语法分析可用于识别词性、词间依存关系、词 lemma 和文本形态。最后，它还将文档分类到 700 多个预定义类别之一。详情请参阅 `https://cloud.google.com/natural-language`。

以下是 Natural Language AI 的一些用例：

*   **用例 1：** 衡量客户对特定产品的情感。使用实体分析从电子邮件、聊天记录和社交媒体等文档中查找重要详情，并对这些实体进行情感分析，以了解客户对特定产品的看法。
*   **用例 2：** 使用 Healthcare Natural Language API 理解医疗文本特有的详情，如临床记录或医疗研究文档。您可以用它提取药物、剂量和病症等医疗洞察，构建强大的医疗应用。注意：Healthcare Natural Language API 独立于 Google 的 Natural Language AI。

### Translation AI

使用 Translation AI 可检测 100 多种语言（从 Afrikaans 到 Zulu），并翻译列表中任意语言对。它采用 Google 神经机器翻译 (GNMT) 技术，该技术由 Google 率先开发，现已成为行业标准。详情请参阅 `https://ai.googleblog.com/2016/09/a-neural-network-for-machine.html`。

此服务分 Basic 和 Advanced 两个级别。两者有很多区别，但主要区别在于 Advanced 版本可以使用 *glossary*（源语言到目标语言的术语映射字典），还可以翻译整个文档（PDF、DOC 等）。价格也有差异。

您可以翻译 ASCII 或 UTF-8 格式的文本。此外，还可以使用 Media Translation API 实时翻译音频，通常用于流媒体服务。

Media Translation API（独立于 Translation API）可直接将源语言音频翻译为目标语言音频。这有助于低延迟流式应用并快速扩展。

#### 语音转文本和文本转语音

## AutoML

AutoML（自动化机器学习）是自动化模型训练耗时任务的过程。AutoML 适用于流行、易懂且切实可行的机器学习问题，如图像分类、文本分类、翻译等。作为用户，您只需提供数据并配置一些设置，其余的训练过程将实现自动化。您可以利用易于使用的 Web 控制台，或使用 Python、Java 或 Node.js SDK 来启动 AutoML 训练作业。

针对许多数据类型和用例都提供了 AutoML 训练。我们可以将它们大致分为四类：

*   结构化数据
*   图像/视频
*   自然语言
*   推荐 AI/零售 AI

### 面向表格或结构化数据的 AutoML
