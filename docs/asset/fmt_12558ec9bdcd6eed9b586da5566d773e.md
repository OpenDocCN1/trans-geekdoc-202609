## 1.1.6 函数

Python 通过关键字 `def` 定义函数，给一段程序块起一个名字，然后可以通过函数名调用并执行该函数块中的代码。例如：

```python
def hwdong():
    print("My youtube channel is: ", "hwdong")             # 调用内置函数 print()
    print("My station B number is: hw-dong")
    print("My blog is: https://hwdong-net.github.io")
```

调用该函数 `hwdong()`：

```python
hwdong()
print()            # 调用内置函数 print()
hwdong()
print()            # 调用内置函数 print()
hwdong()
```

```
My youtube channel is: hwdong
My B station number is: hw-dong
My blog is: https://hwdong-net.github.io

My youtube channel is: hwdong
My B station number is: hw-dong
My blog is: https://hwdong-net.github.io
    
My youtube channel is: hwdong
My B station number is: hw-dong
My blog is: https://hwdong-net.github.io
```

函数可以有参数，这样在调用函数时，可以将相应的参数传递给该函数，例如下面的计算 `x**n` 的函数：

```python
def pow(x, n):    
    ret = 1
    for i in range(n): # 0, 1, 2, ..., n-1
        ret *= x # ret = ret * x
    return ret                     # "return ret" 返回函数的值
```

由关键字 `return` 表示的语句称为返回语句，函数执行到 `return` 时返回（结束函数执行），并可以返回一个值。

调用该函数可以将两个实参传递给函数的形参 `x` 和 `n`。例如：

```python
print(pow(3, 2))    # 3 传给 x，2 传给 n
print(pow(2, 4))
```

```
9
16
```

函数 `pow()` 调用的返回值被传递给函数 `print()` 以打印出返回值。

函数的参数可以有默认值。如果调用函数时未提供对应的参数，该参数将使用其默认值。

```python
def pow(x, n=2):   
    ret = 1
    for i in range(n):
        ret *= x
    return ret
```

该函数参数 `n` 的默认值为 2，即计算 `x**2`。调用该函数时，可以向形参 `n` 传递实参，也可以不传递。

```python
print(pow(3.5))     # 3.5 传给 x，n 的默认值为 2
print(pow(3.5, 3))
```

### 函数内部的语句与递归

函数内部可以包含调用其他函数的语句。函数也可以在内部调用自身，这种函数称为**递归函数**。下面是一个计算正整数 `n` 阶乘的函数：当 `n=1` 时直接返回 1，否则将 `n!` 转换为 `n*(n-1)!`。

```python
def fact(n):
    if n == 1:                 # 如果 n 等于 1，直接返回值 1
        return 1
    return n * fact(n - 1)     # 如果 n 大于 1，返回 n 与 fact(n-1) 的乘积

fact(4)                        # 输出: 24
```

```
24
```

当然，也可以使用循环来计算 `n! = 1 * 2 * 3 * ... * n`。

```python
def fact(n):
    ret = 1
    i = 1
    while i <= n:
        ret *= i
        i += 1
    return ret

fact(4)                        # 输出: 24
```

```
24
```

### 全局变量与局部变量

定义在函数外部的变量称为**全局变量**，定义在函数内部的变量称为**局部变量**。全局变量属于全局命名空间，函数的局部变量属于函数的局部命名空间。不同命名空间中可以存在同名变量而互不冲突。函数不能直接访问外部全局变量，例如：

```python
global_x = 6

def f():
    x = 3
    global_x = 5
    print(x, global_x)

f()    
print(global_x)
```

```
3 5
6
```

函数内部的语句 `global_x = 5` 并未修改外部全局变量 `global_x`，而是定义了一个指向对象 5 的局部变量 `global_x`，这对外部全局变量 `global_x` 没有影响。因此，函数 `f()` 执行结束后，内部局部变量被销毁，全局变量 `global_x` 仍为 6。

如果想在函数内部访问并修改全局变量，需要使用关键字 `global` 在函数内部声明该变量为全局变量，例如：

```python
global_x = 6

def f():
    global global_x
    x = 3
    global_x = 5
    print(x, global_x)

f()    
print(global_x)
```

```
3 5
5
```

函数内部的 `global_x` 被声明为外部全局变量 `global_x`。修改它即修改外部全局变量 `global_x`。因此，函数 `f()` 执行后的输出语句打印的是 5 而不是 6。

修改全局变量的另一种方式是将全局变量作为参数传递给函数，但该全局变量必须是非基本类型的对象。因为当基本类型对象作为参数传递时，函数形式参数引用的是实际参数引用对象的副本，而非同一对象。例如：

```python
global_x = 6
a = [1, 2, 3]

def f(y, z):    
    x = 3
    y = 5
    z[0] = 10
    print(y)
    print(z)
    
f(global_x, a)    
print(global_x)
print(a)
```

```
5
[10, 2, 3]
6
[10, 2, 3]
```

如图 1-4 所示，当 `global_x` 传递给 `y` 时，`y` 引用的是 `global_x` 指向对象的副本，而非同一对象；当 `a` 传递给 `z` 时，`z` 与 `a` 引用的是同一对象。

### 匿名函数 / Lambda 函数

对于简短的函数，可以使用关键字 `lambda` 定义一个无函数名的函数，例如：

```python
lambda arguments: expression
```

该函数没有函数名，但有参数 `arguments`。

```python
lambda x: x ** 2
```

通常使用 `=` 运算符给这个 lambda 函数起一个名字，例如：

```python
double = lambda x: x ** 2
```

通过 `double` 引用调用匿名函数：

```python
double(3.5)
```

```
12.25
```

定义在另一个函数内部的函数称为**嵌套函数**。
