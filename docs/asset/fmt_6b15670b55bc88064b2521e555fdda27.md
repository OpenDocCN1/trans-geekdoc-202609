### 引言

《网络空间对话》是关于互联网世界安全与隐私现状的见解集，是对一些最常用的 OSINT（开源情报）工具的简要介绍，并对来自 ICS（工业控制系统）、APT（高级持续性威胁）以及在线/深网成员组织的关键人物进行了精选采访。本书旨在为安全专业人员以及对数据库设计、隐私与设计安全以及深网成员组织（包括 Cicada 3301、The Unknowns、Anonymous 等）感兴趣的系统管理员介绍安全、OSINT 与深网中隐藏且复杂的世界之间的关系。

在编写此书期间，我很快意识到需要包含关于在线对话（包括加密聊天和邮件）的互联网世界安全与隐私现状的见解，对一些最常用的开源情报工具进行简要介绍，以及对工业控制系统（ICS）、高级持续性威胁（APT）和黑客行动主义者的关键人物进行采访。

在制作此书的过程中，我意识到需要包含有关安全防御侧的黑客/破解者的见解，他们通过创造性地克服系统限制来获得意想不到的结果。

所呈现的画面是一个迷人的情景，网络空间正变得与“物理空间”极其相似；越来越多的人和组织对隐私、信任和共享信息感到担忧，这涉及明网和所谓的“深网”。

本书旨在为安全专业人员以及对数据库设计、隐私与设计安全感兴趣的系统管理员介绍安全、开源情报与深网中隐藏且复杂的世界之间的关系。

在暗网中寻找信息并不困难。可以通过搜索引擎找到暗网网站列表。Hidden Wiki 就是其中一个列表。然而，许多搜索引擎并不可靠或已过时。Ahmia 搜索引擎是一个更好的替代方案，因为它过滤了恶意内容。

搜索暗网需要更谨慎的心态。如果一个网站看起来好得不可真实，请务必小心。可以使用 Tor 浏览器浏览匿名网络。

Hidden Wiki 是暗网的另一个起点。它提供了各个类别网站的链接。然而，Hidden Wiki 经常离线或包含失效链接。如果网站无法解析，请重试。

Ahmia 搜索系统可以在未安装 Tor 软件的情况下查询；但要访问网站，您需要使用支持 Tor 的设备。明网 URL 为 `https://ahmia.fi`；洋葱站点地址为 `#msydqltz2kerzdg.onion`。Ahmia 代码是一个托管在 GitHub 上的开源项目。

Ahmia 从芬兰运营，自称是“面向 Tor 匿名网络居民的搜索引擎”。

该系统不维护 IP 协议过滤器，并记录结果以拦截儿童色情链接。

Grams 位于 `http://grams7enuf7jmdl.onion`。一位爱好者将 Grams 解释为“暗网上的谷歌”。在 2014 年的一次采访中，Grams 的系统管理员表示，Grams 利用了一种专利搜索技术，该技术可以显示来自电子商务网站以及其他类型暗网网站的结果。

用户可以将网站添加到 Grams 系统中进行索引并纳入系统。

Grams 不支持索引色情内容。该过程似乎是由一家东欧货币服务机构运营的。Grams 提供了独特的属性；例如供应商和产品搜索，以及用户友 Flow 功能，该功能允许使用纯英语定位特定的暗网网站。2015 年，研究小组使用 Grams 在一次大宗货物运送后找到了 Pappy Van Winkle 威士忌……

相关性的缺失凸显了 Grams 给调查人员带来的问题。

Grams 在引导研究人员找到暗网网站上完整的免费书籍方面做得非常出色。

该服务对药物相关网站的索引非常好。得益于 Flow 服务的加入，只要调查人员知道网站标题，就能轻松定位特定的暗网网站。

我发现 Grams 能够产生有用的结果，但它包含了无关的、离题的结果，使得必须对结果页面进行人工检查。与其他暗网搜索系统配合使用时，Grams 是可以的。

Not Evil 位于 `https://hss3uro2hsxfogfq.onion`，是 TorSearch 和 Evil Wiki 的重新品牌。链接经过了过滤。相关性算法会考虑用户点击的内容。Not Evil 的运营者保持低调。该服务不接受暗网广告。该系统允许用户通过名为“Ned”的聊天机器人与另一个 not Evil 用户开始安全对话，“Ned”是 Evil Drone 的缩写。not Evil 系统在 Tor 内部包含一个“聊天”功能。可以使用聊天机器人或匿名用户开始有关查询的对话。此外，not Evil 会显示索引中匹配查询的目数量。除了搜索外，系统还提供了 not Evil 系统索引的链接数量。最后，not Evil 提供了一个应用程序编程接口（API），以便将 not Evil 的性能集成到其他应用程序中。

Onion Link 可以在 `http://onion.city` 找到。这个暗网搜索系统之所以引人入胜，是因为它似乎使用了谷歌自定义搜索功能以及 Ahmia 索引来创建结果。根据对 Onion Link 搜索结果的研究分析，索引包含约 20,000 个暗网网站。大约六年前，谷歌曾运营过暗网网站，但随后该网站下线了。从那时起，谷歌没有披露过有关其暗网活动的信息。谷歌的确投资了 Recorded Future，这是一家索引暗网内容的公司。研究小组提出的一个假设是，谷歌可能会为了其研究并支持其谷歌支持的 Recorded Future 工作而索引某些暗网内容。在 2016 年底，根据我们的评估查询，谷歌对胶水网站（glue websites）的索引有所减少。

Torch 搜索系统提供了一个搜索框、暗网广告以及一个想要在 Torch 系统上投放广告的链接。请注意，在该截图中，Torch 报告其索引包含约 500,000 个暗网页面，比其他引擎少约三分之一。Torch 是低调的暗网搜索程序之一。该系统的一个有用功能是词汇高亮。搜索系统产生的相关性评分使其能够发现索引网站中词汇出现的频率。列表条目显示了 Torch 索引子系统访问网站的日期。Torch 暗网搜索非常有用。我们建议在沙箱内部使用它。

免费暗网搜索方法为访问许多暗网网站提供了便捷、简单的途径。然而，没有任何一个系统是没有严重缺陷的。我开发的方法涉及编写查询，然后在本章讨论的五个搜索系统运行该查询。我下载了前五组结果并将它们合并。然后我访问了与我们正在调查的特定问题最相关的暗网网站。显而易见的是，执行手动查询和结果分析所需的时间和精力是一种负担。

操作系统或应用程序等软件存在缺陷。软件可以通过文档到达。

向执法部门创建的用于收集个人信息的应用程序或表单提供数据。目前有许多变体，并且通常会引入新的变体。输入到伪造或被捕获网站的数据，调查人员可以实时以未加密的形式访问。哪些暗网网站是由执法部门运营的？哪些是由坏分子运行的？研究小组获得了一份包含约 150 个以多种形式存在的网站列表。被捕获的网站可以使用不同的暗网地址在网上存在。一种策略是要求执法部门为通过该网站的订单请求次要和主电子邮件地址、电话号码，或主和备用收货地址。更复杂的方法涉及创建看起来像暗网应用程序的移动应用程序。

“多重利用法”利用了受调查小组控制的暗网网站、不同的感染向量（表单、应用程序、电子邮件等）以及可能从坏分子的计算机迁移到该坏分子所知的其他人员计算机的病毒。

混合方法可以使用通过网络传播的应用程序。这种方法可能将对坏分子计算设备的远程访问管理与特定的软件相结合，当受感染设备的用户使用 Signal（一种加密消息程序）或制作用于分发和销售的视频时，该软件会执行特定操作。

如果受感染的计算机用于维护暗网网站，恶意软件可以插入到主机服务器中并在该远程服务器上执行特定操作。结合方法使得调查人员能够访问网络上的一个或多个服务器，并获取与跨两个或多个计算设备及其网络的违法行为有关的信息。

Kali 包含超过 300 预装工具。结合下文讨论的 Metasploit，具备适当计算机技能的调查人员可以破解暗网，然后进一步进入嫌疑计算机、存储设备或移动设备。

适用于执法和情报工作的应用程序包括 SQL 注入、拒绝服务攻击等。

SQL 注入是一种 Web 应用程序漏洞，攻击者可以在其中提交数据库 SQL 命令，从而暴露后端数据库。Kali 允许在可以访问用户计算机或服务器时使用手动方法。Kali 允许使用 SQLMap（另一个开源工具）发动攻击。SQLMap 简化了检测和利用 SQL 注入漏洞以及渗透服务器的过程。

Kali 支持从数据库检索数据并访问底层文件系统。Kali 也可用于盲注。在这种方法中，判断网站是否易受到 SQL 注入。如果是，程序员可以探测网站以查找数据库的表、列和记录。一旦探测返回积极结果，程序员就可以编写脚本遍历各种可能性。提供的代码示例帮助程序员将 Kali 作为针对单个网站或一组感兴趣的网站进行盲注的阶段。

### Maltego

Maltego 分析并显示关系，提供了一个对个人、公司、事件和其他实体的俯瞰视角。核心概念是关系的可视化让调查人员或分析师查看信息及其关联。

Metasploit 是黑客软件的集合，最初是基于 Metasploit 框架的开源黑客工具。

该黑客工具包含数百个模块（软件程序）。远程漏洞利用允许 Metasploit 程序员开发能够利用浏览器、操作系统以及如 Adobe Flash 等第三方应用程序漏洞的程序。FBI 使用 Metasploit 开发了其 Torpedo 程序。FBI 采用的方法似乎利用了 Adobe 的软件。FBI 在 Web 之上建立了一个直接连接；也就是说，在 Tor 之外的连接。该链接成为了 FBI 收集用户信息的途径。

Nmap（或网络映射器）是一个用于网络发现和安全审计的免费开源（[许可证]）工具。一些技术专家发现它对于网络资产盘、处理服务更新计划以及监控主机或服务的运行时间等任务非常有用。

Nmap 运行在 Linux、Windows 和 Mac OS X 上。它位列 FreshSource.net 仓库前 10 程序之一，该仓库包含超过 30,000 个程序。Nmap 项目的主要目标是帮助让互联网更安全，并为管理员/审计员/黑客提供用于探索其网络的先进工具。由于完整的源代码可用，开发者可以修改 Nmap 以执行更专门的功能。Nmap 处理 IP 数据包以确定网络上有哪些可用主机、这些主机提供哪些服务、运行着什么操作系统（以及操作系统版本）、使用了什么类型的数据包过滤器/防火墙以及数十种其他特性。

Nmap 除了命令行 Nmap 界面外，还包含图形用户界面查看器（Zenmap）、一个灵活的数据传输、重定向和调试工具（Ncat）、一个比较结果的工具（Ndiff）以及一个数据包生成和响应分析工具（Nping）。

Nmap 非常灵活：它支持数十种创新技术，用于映射充满 IP 过滤器、防火墙、路由器和其他障碍的网络。这包括许多端口扫描机制（涵盖 TCP 和 UDP）、操作系统检测、版本检测、Ping 扫描（ping sweeps）等等。Nmap 已用于扫描跨越数百的大型网络。

### 引言

2016 年 Darpa 目录中的几款应用程序包括 Dossier Stack、Formasaurus 和 HSPProbe。

Dossier Stack 是以库的形式交付的智能软件。程序调用该库来执行某些以实体为中心的操作。实体可以包括人物、地点、企业名称、别名以及其他重要标识符。Dossier Stack 使程序员能够构建主动搜索应用程序。这些应用程序可以通过监控和捕获用户的行为来学习用户需求。开发者的商业软件使得利用概率推理算法挖掘海量信息流并连接实体成为可能。程序员是 Diffeo，这是一家成立于2012 年的初创公司，吸了 MIT 和 MetaCarta 的经验。John Frank [84] 该公司的领域是爬取网络并为唯一实体创建知识图谱。其理念是以更具教养的方式精炼人、地、组织和命名事物之间的关系。Diffeo 集成了 Basis Tech 的语言工具，并使用了 SAP 的内存数据库技术。

Formaratus 是一个提供网页信息的软件组件。该 Python 包判断路径是登录页、搜索框、注册、密码找回、邮件列表还是联系表单。该系统使用机器学习，因此该组件输出的精确性随时间推移而增加。Hyperion Gray 是其他 Memex 模块的程序员，包括 Frontera（一个网络爬虫程序）和 Scrapy-Docker hub，此外还有管理索引程序。

Tor 隐藏服务探测器 HSPProbe 是一个多线程 Python 应用。该软件使用了 Stem，这是一个 Tor 的 Python 控制器。Stem 允许程序使用 Tor 的控制协议对 Tor 编写脚本，或构建可以确定 Tor 隐藏服务状态并提取隐藏支持材料的组件。HSPProbe 设计用于利用协议错误代码，在无法到达覆盖的服务时决定采取什么行动。HSPProbe 测试 Tor 秘密服务（Onion 地址）是否在预定义的一系列端口上监听。

此外，程序还会确定秘密服务何时通过其他协议进行通信。程序员/用户提供待探测的 Onion 地址列表，HSPProbe 输出结果列表。由于暗网（Dark Web）提供了加密，Tor 用户认为它比表面网（Surface Web）更有匿名性。加密是可以被破解的。

凭借大量的计算资源，大多数研究人员会发现 256、512 或 1024 位密钥的加密是无法破解的。当更快速或更先进的计算机可用时，快速解密可能会成为常态。
