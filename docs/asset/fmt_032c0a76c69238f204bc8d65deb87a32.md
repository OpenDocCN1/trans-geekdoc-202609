## 凭据窃取 (Credential Harvesting)

凭据窃取是一种获取凭据的攻击，涉及伪造 AP 或网络门户来诱导用户输入凭据。可以使用`Ettercap`等工具进行此类社会工程攻击。例如，攻击者可能会伪造 Twitter 网站，当用户访问该网站时，会获取其凭据。这种攻击的另一种工具是社会工程工具（SET），你在第 4 章（ch04.xhtml#ch04）中学习过。

## 蓝牙劫持 (Bluejacking) 与蓝牙窃取 (Bluesnarfing)

蓝牙劫持是一种利用范围内有漏洞的蓝牙设备进行的攻击。攻击者通过蓝牙向受害者发送未经请求的消息。vCard 可以包含姓名、地址、电话号码、电子邮件地址以及相关的网页 URL。这是通过对象交换（OBEX）协议完成的。

**注意**

你可以在此处找到关于蓝牙劫持的精彩论文：[`publ.eu/jsi/2017-116-8/articles/72.pdf`](http://publ.eu/jsi/2017-116-8/articles/72.pdf)。

另一种蓝牙攻击是蓝牙窃取。蓝牙窃取是为了未经授权访问设备信息，例如日历、联系人列表、电子邮件和短信、图片或视频。这种攻击还可以用于获取设备的设备识别码（IMEI）。然后攻击者可以在用户不知情的情况下将呼入电话和短信重定向到另一个设备。

示例 5-22 显示了如何使用`bluesnarfer`工具获取地址为`DE:AD:BE:EF:12:23`的蓝牙设备的名称（`omar_phone`）。

```
root@kali:~# bluesnarfer -b DE:AD:BE:EF:12:23 -i

device name: omar_phone
```

## 低功耗蓝牙 (BLE) 攻击

许多 IoT 设备使用 BLE 进行通信。BLE 通信容易受到路径攻击，攻击者可以修改系统之间的 BLE 消息。拒绝服务（DoS）攻击对 BLE 实现也会产生问题。多项研究已经演示了不同的 BLE 攻击。例如，俄亥俄州立大学的研究人员发现了不同的指纹攻击，这些攻击允许攻击者揭示 BLE 设备的设计缺陷和错误配置。有关此研究的细节可以在此处找到：[`dl.acm.org/doi/pdf/10.1145/3319535.3354240`](https://dl.acm.org/doi/pdf/10.1145/3319535.3354240)。

无线射频识别（RFID）是一种利用电磁场来识别和跟踪带有电子存储信息的标签的技术。RFID 标签分为主动式和被动式两种。被动式标签使用 RFID 读器提供的能量（通过射频波），而主动式标签具有本地电源，并可以在更远的距离内工作。许多机构/组织使用 RFID 标签来跟踪库存，或用于进入建筑或房间的胸卡。RFID 标签甚至可以植入动物或人体中，以读取存储在标签中的特定信息。

低频（LF）RFID 标签和设备的工作频率在`120kHz`到`140kHz`之间，它们在短于 3 英尺的距离交换信息。高频（HF）RFID 标签和设备工作在`13.56MHz`频率，并在 3 到 10 英尺的范围内交换信息。超高频（UHF）RFID 标签和设备的工作频率在`860MHz`到`960MHz`之间（区域性），并在长达 30 英尺的距离内交换信息。

针对 RFID 设备通常会有几种攻击：

*   攻击者只需靠近个人或标签，即可使用如`Proxmark3`（[`proxmark.com`](https://proxmark.com)）等 RFID 读器秘密窃取 RFID 信息（如胸卡或标签）。
*   攻击者可以创建并克隆 RFID 标签（过程称为`RFID 克隆`）。他们可以使用克隆的 RFID 标签进入建筑或特定房间。
*   攻击者可以在建筑或房间内的 RFID 卡读器后面安装盗刷器。
*   攻击者可以使用放大天线执行 NFC 放大攻击。攻击者还可以使用放大天线在较远的距离内泄露少量数据，例如密码和加密密钥。

### 密码喷洒

`密码喷洒 (Password spraying)`是一种凭据攻击，攻击者根据常用系统或应用程序带有默认密码的用户名列表对登录进行暴力破解（即尝试多次进行身份验证）。例如，攻击者可以尝试使用词表中的许多用户名通过`password1`单词进行登录。

类似的攻击是凭据填充（Credential stuffing）。在这种类型的攻击中，攻击者对在之前的破解泄露中暴露的用户名和密码进行自动化注入。你可以在[`owasp.org/www-community/attacks/Credential_stuffing`](https://owasp.org/www-community/attacks/Credential_stuffing)了解更多关于凭据填充攻击。

### 漏洞链

大多数复杂的攻击利用多个漏洞来破坏系统。攻击者可能会针对已知或零日漏洞将多个利用程序“链”（即使用多个）利用程序，以破坏系统、窃取、修改或损坏数据。
