# 7 用于恶意软件检测的流分析

DOI: [10.1201/9781003081845-12](https://doi.org/10.1201/9781003081845-12)

## 7.1 简介

对于数据挖掘/数据科学界而言，挖掘/分析不断增长的流式数据是一大挑战。流数据分类存在三个主要问题。首先，存储并使用所有历史数据进行训练是不切实际的，因为这将需要无限的存储空间和运行时间。其次，数据中可能存在概念漂移，即数据的潜在概念可能随时间变化。第三，新类别可能在流中演变出现。文献中有许多现有解决方案解决前两个问题，例如单模型增量学习算法 [CHEN2008, HULT2001, YANG2005] 和集成分类器 [KOLT2005, MASU2008a, WANG2003]。然而，大多数现有技术无法检测流中的新类别。另一方面，我们的方法能同时处理概念漂移并检测新类别。

传统分类器只能正确分类那些它们已接受过训练的类别的实例。当新类别出现在流中时，属于该类别的所有实例都会被错误分类，直到该新类别被专家人工识别，并利用该类别的标记实例训练出新模型为止。我们的方法通过在传统分类器中融入新类别检测器来解决这一问题，从而无需人工干预即可识别新类别的出现。所提出的新类别检测技术可使各领域的许多应用受益，例如网络入侵检测和信用卡欺诈检测。例如，在入侵检测问题中，当发生一种新型入侵时，我们不仅要能检测出这是一次入侵，还要能识别出这是一种新型入侵。有了入侵类型信息，人工专家就能更深入地分析入侵、寻找补救措施、提前设置警报，并使系统更加安全。

## 7.2 流挖掘

### 7.2.1 架构

我们提出了一种创新的方法来检测新颖类别。它在几个方面不同于传统的新颖性（或异常/离群值）检测技术。首先，传统的新颖性检测技术[MARK2003、ROBE2000、YEUN2002] 通过假设或建立正常数据模型，并简单地将偏离“正常”点的数据点识别为离群值/异常值来工作。但我们的目标不仅是检测单个数据点是否偏离正常性，还要发现一组离群值之间是否存在强关联。其次，传统的新颖性检测器可以被视为“单类”模型，它仅区分正常和异常数据，但无法区分两种不同类型的异常。但我们的模型是“多类”模型，意味着它可以区分不同类别的数据，同时可以检测新颖类别数据的存在，这是传统分类器与新颖性检测器的独特结合。

我们的技术通过自适应集成分类方法处理概念漂移，该方法维护一个包含 `M` 个分类器的集成 `L`，用于对未标记数据进行分类。数据流被划分为大小相等的块，以便每个块可以容纳在内存中并在线处理。一旦数据块被标记，我们立即从中训练一个分类模型。如果有必要，新训练的模型将替换集成中的现有模型之一。因此，集成不断演化，反映流中最新的概念。

我们新颖类别检测技术的核心概念是每个类别必须具有一个重要属性：属于同一类别的数据点应该彼此更接近（内聚性），并且应该远离属于其他类别的数据点（分离性）。每当一个新的数据块出现时，我们首先检测那些与训练数据*良好分离*的测试实例（即离群值）。然后应用过滤以移除可能由概念漂移导致的离群值。最后，如果我们在这些过滤后的离群值中发现强内聚性，我们就宣布发现了一个新颖类别。当新颖类别的真实标签到达并使用标记实例训练新模型时，现有集成将用该模型进行更新。因此，模型集成不断地通过新类别得到丰富。我们的架构如图 7.2 所示。

![图 7.2 架构。](img/fig7_2.jpg)

我们假设数据流被划分为大小相等的块。该系统的核心是一个包含 `M` 个分类器的集成 `L`：`{L[1], …, L[M]}`。当一个新的未标记数据块到达时，集成被用于检测该块中的新颖类别。如果检测到新颖类别，则识别出属于该新颖类别的实例并相应地进行标记。该块中所有其他实例，即未被识别为新颖类别的实例，使用多数投票进行分类。一旦数据块被标记，它就被用来训练一个分类器，该分类器替换集成中的现有分类器之一。在训练期间，我们创建*已用*空间的清单。

我们有几项贡献。首先，我们提供了对新颖类别特征的详细理解，并提出了一种新技术，该技术可以在数据流存在概念漂移的情况下检测新颖类别。其次，我们建立了一个框架，用于将新颖类别检测机制融入传统分类器中。最后，我们将该技术应用于合成和真实世界数据，获得了比最先进的流分类算法好得多的结果。

### 7.2.2 相关工作

我们的工作与流分类和新颖性检测均有关联。流数据分类领域已有大量研究。主要有两种方法：单模型分类和集成分类。已有一些单模型技术被提出以适应概念漂移 [CHEN2008, HULT2001, YANG2005]。然而，我们的技术采用的是集成方法。已有多种用于流数据挖掘的集成技术被提出 [KOLT2005, MASU2008a, WANG2003]。这些集成方法更新当前概念仅需简单操作，且被发现能稳健地处理概念漂移。尽管这些技术能高效处理概念漂移，但它们均无法检测数据流中的新颖类别。相比之下，我们的技术不仅能处理概念漂移，还能检测数据流中的新颖类别。在此意义上，我们的技术也与新颖性检测技术相关。

[MARK2003] 中详细讨论了关于新颖性检测的综合性研究。作者将新颖性检测技术分为两类：统计方法和基于神经网络的方法。我们的技术属于统计方法。统计方法又分为参数化和非参数化两类。参数化方法假设数据分布是已知的（例如高斯分布），并尝试估计该分布的参数（如均值和方差）。如果任何测试数据落在模型正常参数范围之外，则将其判定为新颖 [ROBE2000]。我们的技术是一种非参数化方法。像 Parzen 窗法 [YEUN2002] 这样的非参数化方法估计训练数据的密度，并拒绝密度超出特定阈值的模式。基于 K 近邻 (K-NN) 的新颖性检测方法也是非参数化的 [YANG2002]。所有这些新颖性检测技术仅考虑基于某些适当度量（如距离、密度等），测试实例是否与训练数据足够接近（或足够远）。我们的方法不同之处在于，我们不仅考虑与正常数据的分离度，还考虑异常值之间的内聚性。此外，我们的模型将新颖类别同化到现有模型中，这使其能够将该类别的未来实例与其他类别区分开来。另一方面，新颖性检测技术仅记忆“正常”趋势，并不关心异常实例之间的相似性或差异性。

数据流挖掘领域的一项近期工作 [SPIN2007] 描述了一种聚类方法，可同时检测概念漂移和新颖类别。该方法假设只有一个“正常”类别，所有其他类别均为新颖类别。因此，如果有多个类别被视为“正常”或“非新颖”，该方法可能效果不佳。我们的方法可以处理任意数量的现有类别。这使得我们的方法在检测新颖类别方面比 [SPIN2007] 更有效，实验结果也证明了这一点。

### 7.2.3 我们的方法

我们提出了一种新颖技术，用于在概念漂移数据流中检测新类别。大多数新颖性检测技术要么假设不存在概念漂移，要么为单个“正常”类别建模并将所有其他类别视为新颖。但我们的方法能够在存在概念漂移的情况下检测新颖类别，即使模型包含多个“现有”类别。此外，我们的新颖类别检测技术是非参数化的，即不假设数据具有任何特定分布。我们还通过实证表明，我们的方法在分类准确率和处理速度方面均优于最先进的基于数据流的新颖性检测技术。

读者可能会认为，为了检测新颖类别，我们实际上是在检查是否形成了新簇，因此检测过程可以在无监督下进行。但监督对于分类是必要的。没有外部监督，两个独立的簇可能被视为两个不同的类别，尽管它们并非如此。反之，如果一个数据块中出现多个新颖类别，如果这些实例的标签从未被揭示，它们可能被视为单个新颖类别。在未来的工作中，我们希望将我们的技术应用于多标签实例领域。我们的方法如 图 7.3 所示。

### 7.2.4 新颖类别检测概述

算法 7.1 概述了我们技术的摘要。数据流被划分为等大小的数据块。最新的数据块（无标签）作为输入提供给算法。首先，它检测数据块中是否存在任何新颖类别（第 1 行）。术语“新颖类别”将在稍后定义。如果发现新颖类别，我们将检测属于该类别的实例（第 2 行）。然后我们使用集成 `L` = {`L`[1], …, `L`[`M`]} 对不属于新颖类别的实例进行分类。当数据块获得标签后，使用该数据块训练一个新分类器 `L`'。然后，根据 `M` + 1 个分类器 `L` ∪ {`L`'} 在最新标记数据块上的准确率，选择最佳的 `M` 个分类器来更新现有集成。

从现在起，我们的算法将被称为“MineClass”，代表在数据流中挖掘新颖类别。MineClass 适用于任何基础学习器。唯一特定于学习算法的操作是 `Train-and-create-inventory`。我们将针对两种基础学习器演示此操作。

### 7.2.5 使用的分类器

我们将新颖性检测技术应用于两种不同的分类器：决策树和 K-NN。我们在集成中保留 `M` 个分类模型。对于决策树分类器，每个模型是一棵决策树。对于 K-NN，每个模型通常是训练数据集合本身。然而，存储所有原始训练数据在内存上效率低下，且使用它们对未标记数据进行分类在时间上效率低下。我们通过用训练数据构建 `K` 个簇，保存簇摘要作为分类模型，并丢弃原始数据，从而同时降低了时间和内存需求。该过程在 [MASU2008b] 中有详细解释。簇摘要此后称为“伪点”。由于我们仅存储和使用 `K` 个伪点，时间和内存需求均成为 `K`（一个常数）的函数。此处采用的聚类方法是一种基于约束的 `K`\-均值聚类，该约束是在最小化簇内离散度的同时最小化簇杂质。如果一个簇仅包含来自单一类别的实例，则认为该簇是纯净的。每个簇的摘要由质心和簇中各类别数据点的频率组成。分类通过从测试点找到最近的簇质心，并将频率最高的类别分配给测试点来完成。

## 7.3 新颖类别检测的细节

### 7.3.1 定义

我们从“新颖”和“现有”类别的定义开始。

**定义 7.1：** **(现有类别和新颖类别)** 设 `L` 为当前的分类模型集成。如果集成中至少有一个模型 `L`[`i`] ∈ `L` 是用类别 `c` 的实例训练的，则类别 `c` 为现有类别。否则，`c` 为新颖类别。

我们假设任何类别都具有以下基本属性（属性 7.1）：

**属性 7.1：** *一个数据点应当更接近其自身类别的数据点（内聚性），并远离其他类别的数据点（分离性）*。

我们的主要假设是：属于类别 `c` 的实例由底层生成模型 `Θ[c]` 生成，且每个类别中的实例是独立同分布的。基于这一假设，我们可以合理地论证：彼此接近的实例应当由同一模型生成，即属于同一类别。我们现在通过 图 7.4 展示使用决策树进行新颖类别检测的基本思想。我们引入 `已用空间` 的概念来表示被任意实例占据的特征空间，引入 `未用空间` 来表示未被实例占据的特征空间。

![图 7.4 (a) 决策树和 (b) 对应的特征空间划分。FS(X) 表示由叶节点 X 定义的特征空间。阴影区域显示每个分区的已用空间。(c) 一个新颖类别（用 x 表示）到达未用空间。](img/fig7_4.jpg)

图 7.4 (a) 决策树和 (b) 对应的特征空间划分。FS(X) 表示由叶节点 X 定义的特征空间。阴影区域显示每个分区的已用空间。(c) 一个新颖类别（用 x 表示）到达未用空间。

根据性质 7.1（分离性），新颖类别必须到达未用空间。此外，新颖类别的实例之间必须存在强内聚性（例如接近性）。因此，我们的方法遵循以下两个基本原则：跟踪决策树中每个叶节点的已用空间，以及寻找落入未用空间中的测试实例之间的强内聚性。

### 7.3.2 新颖类别检测

我们遵循两个基本步骤进行新颖类别检测。首先，训练分类器，以创建并保存已用空间的清单（第 7.2 节 中描述）。这是通过聚类并将聚类摘要保存为“伪点”来完成的。其次，利用这些伪点检测测试数据中的异常值，如果异常值之间存在强内聚性，则宣告发现新颖类别。

#### 7.3.2.1 训练期间保存已用空间清单

创建清单的总体思路是对训练数据进行聚类，并将聚类质心和其他有用信息保存为伪点。这些伪点用于跟踪已用空间。这种聚类的具体方式可能因基学习器而异。例如，对于决策树，聚类在树的每个叶节点处进行，因为我们需要分别跟踪每个叶节点的已用空间。对于 第 7.2 节 中讨论的 K-NN 分类器，则利用已有的伪点来存储清单。

值得注意的是，`K`-均值聚类似乎是保存决策边界和计算异常值的最佳选择。基于密度的聚类也可用于检测异常值，但存在若干问题。首先，我们必须在叶节点保存所有原始数据点以应用聚类。其次，聚类过程将耗费平方时间，而 `K`-均值仅需线性时间。最后，我们必须为每个待测试的数据块运行聚类算法。然而，`K`-均值算法中参数 `K` 的选择对总体结果有一定影响，这将在实验结果中讨论。

##### 7.3.2.1.1 聚类

我们为每个数据块构建总共 `K` 个聚类。对于 K-NN，我们利用使用该方法全局创建的现有聚类。对于决策树，聚类在每个叶节点局部进行，具体如下。假设 `S` 为数据块大小。在决策树训练期间，当我们到达叶节点 `l[i]` 时，在该叶节点构建 `k[i] = (t[i]/S)*K` 个聚类，其中 `t[i]` 表示最终落入叶节点 `l[i]` 的训练实例数量。

##### 7.3.2.1.2 存储聚类摘要信息
