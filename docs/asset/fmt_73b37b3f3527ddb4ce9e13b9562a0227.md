
前面的两个条件相互冲突，LASSO 估计量无法同时满足这两个神谕条件。相关证明在技术上较为复杂，此处不再赘述。感兴趣的读者可参考前文给出的参考文献获取。然而，在继续之前，了解正则化参数为何在任何情况下都必须比 $n$ 增长得更慢是很有启发性的。在不过于严格的数学意义上回顾一下，LASSO 解源自公式 (9.6)。这可以写为

```
0 \in - \frac{2}{n}\sum_{i = 1}^{n}\mathbf{x}_{i}y_{i} + \frac{2}{n}\left( \sum_{i = 1}^{n}\mathbf{x}_{i}\mathbf{x}_{i}^{T} \right)\mathbf{\theta} + \frac{\lambda_{n}}{n}\partial\left\| \mathbf{\theta} \right\|_{1},
```

其中我们将两边同时除以了 $n$。当 $n \to \infty$ 时取极限，如果 $\lambda_n/n \to 0$，则仅剩前两项；这正是选择无正则化的平方误差和作为代价函数时所得到的结果。回顾第 6 章，在这种情况下，解在渐近意义上收敛^(⁶⁶)

## 10.4.2 自适应范数加权 LASSO

有两种方法可以解决上述冲突。一种是将 $\ell_1$ 范数替换为非凸函数，这可以得到同时满足神谕性质的估计量 [55]。另一种是通过将 $\ell_1$ 范数替换为*加权*版本来对其进行修改。回顾一下，第 10.3 节讨论加权 $\ell_1$ 范数是作为一种辅助优化过程揭示稀疏解的手段。而这里引入加权 $\ell_1$ 范数的概念，则是为了满足神谕性质的必要要求。这由此引出了*自适应时域与范数加权 LASSO*（TNWL）估计，其定义为

### 加权最小二乘估计

```
\widehat{\mathbf{\theta}} = \arg\min_{\mathbf{\theta} \in \mathbb{R}^{l}} \left\{ \sum_{j = 1}^{n} \beta^{n - j} \left( y_{j} - \mathbf{x}_{j}^{T} \mathbf{\theta} \right)^{2} + \lambda_{n} \sum_{i = 1}^{l} w_{i,n} |\theta_{i}| \right\},
```

其中 $\beta \le 1$ 作为遗忘因子，用于跟踪缓慢变化。时变加权序列记为 $w_{i,n}$。存在不同的选项。文献 [127] 中，在 $\beta = 1$ 的平稳环境下，证明了如果

```
w_{i,n} = \frac{1}{|\theta_{i}^{\text{est}}|^{\gamma}},
```

其中 $\theta_{i}^{\text{est}}$ 是由*任意* $\sqrt{n}$-一致估计量（如无正则化最小二乘法）获得的第 $i$ 个分量的估计值，那么对于特定的 $\lambda_{n}$ 和 $\gamma$ 选择，相应的估计量同时满足神谕性质。加权 $\ell_{1}$ 范数背后的主要推理是：随着时间的推移，$\sqrt{n}$-一致估计量提供越来越好的估计，真实支撑集之外索引（零值）对应的权重被放大，而真实支撑集内索引对应的权重收敛到有限值。这有助于算法同时定位支撑集并获得大系数的无偏（渐近）估计。

加权序列的另一种选择与*平滑截尾绝对偏差 (SCAD)* [55, 128] 相关。其定义为

```
w_{i,n} = \chi_{(0,\mu_{n})}(|\theta_{i}^{\text{est}}|) + \frac{\left( \alpha\mu_{n} - |\theta_{i}^{\text{est}}| \right)_{+}}{(\alpha - 1)\mu_{n}}\chi_{(\mu_{n},\infty)}(|\theta_{i}^{\text{est}}|),
```

其中 $\chi(\cdot)$ 代表特征函数，$\mu_{n} = \lambda_{n}/n$，且 $\alpha > 2$。基本上，这对应于一个二次样条函数。文献 [128] 指出，如果 $\lambda_{n}$ 的选择使其增长速度快于 $\sqrt{n}$ 且慢于 $n$，则带有 $\beta = 1$ 的自适应 LASSO 可同时满足两个神谕条件。

文献 [3] 提出了一种用于求解 TNWL LASSO 的时变自适应方案。公式 (10.24) 中自适应 LASSO 的代价函数可写为

```
J(\boldsymbol{\theta}) = \boldsymbol{\theta}^{(T)}R_{n}\boldsymbol{\theta} - \boldsymbol{r}_{n}^{(T)}\boldsymbol{\theta} + \lambda_{n}\|\boldsymbol{\theta}\|_{1,w_{n}}
```

其中

```
R_{n} := \sum_{j=1}^{n}\beta^{n-j}\mathbf{x}_{j}\mathbf{x}_{j}^{T},\quad \mathbf{r}_{n} := \sum_{j=1}^{n}\beta^{n-j}y_{j}\mathbf{x}_{j}
```

且 $\|\boldsymbol{\theta}\|_{1,\mathbf{w}_n}$ 为加权 $\ell_1$ 范数。从第 6 章可知，且很容易看出：

```
R_n = \beta R_{n-1} + \mathbf{x}_n\mathbf{x}_n^T, \quad \mathbf{r}_n = \beta\mathbf{r}_{n-1} + y_n\mathbf{x}_n.
```

![Equation](img/si260.png)

对于一般结构的矩阵，上述两种更新的复杂度均达 $\mathcal{O}(l^2)$ 次乘加运算。一种替代方案是更新 $R_n$ 和 $\mathbf{r}_n$，然后在每个时刻 $n$ 利用任意标准算法求解一个凸优化任务。然而，由于其过高的计算成本，这不适用于实时应用。文献 [3] 开发了一种坐标下降算法的时递归版本。正如我们在第 10.2.2 节所见，坐标下降算法在每次迭代步骤中更新一个分量。在文献 [3] 中，迭代步骤与时间更新相关联，这始终是在线算法的情况。每当接收到一个新的训练对 $(y_n, \mathbf{x}_n)$，未知向量的单个分量就会被更新。因此，在每个时刻，必须求解一个标量优化任务，其解以闭式给出，从而导致一个简单的软阈值操作。坐标技术的缺点之一是每个系数每 $l$ 个时刻更新一次，对于较大的 $l$ 值，这会减慢收敛速度。文献 [3] 中也讨论了应对这一缺点的基本方案变体，称为在线循环坐标下降时加权 LASSO (OCCD-TWL)。该方案的复杂度为 $\mathcal{O}(l^2)$ 阶。如果输入序列为时间序列，则可节省计算量，并可利用 $R_n$ 和 RLS 的快速更新方案。然而，如果并行使用 RLS 类算法，整体方案的收敛可能会减慢，因为 RLS 类算法必须先收敛，才能为权重提供可靠的估计，如前所述。
