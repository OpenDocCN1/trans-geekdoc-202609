### 密码

密码是您的第一道防线。它们必须强健，且便于最终用户输入和记忆。密码应满足以下要求：

1.  密码不应包含世界上任何字典中的单词，也不应是知名人物或机器（收音机/电视等）的名称。
2.  密码应由最终用户自创的口令短语组成。例如，如果我编造短语“The satellite will launch in 30 minutes”，我的密码就变成每个单词的首字母和我输入的数字。因此上述密码为 `tswli30m`。此密码易于记忆，因为用户自创了短语，且易于输入。如果您愿意，也可以包含特殊字符（如 `!`、`#` 或 `&`）。如果黑客使用破解程序，这种类型的密码也很难被破解。
3.  密码长度应至少为八位字符。即使黑客在高端机器上使用破解程序，破解八位字符密码所需的时间也比七位字符长得多。大多数黑客缺乏耐心，会停止破解过程，转而寻找更容易的目标。
4.  每 30 天更换一次密码。最长可用 60 天，但这会增加风险。如果有人专门针对您的系统进行破解，并使用高端机器进行处理，允许 60 天会增加黑客成功的可能性。如果使用强密码，在 30 天内破解几乎是不可能的。
5.  系统管理员应使用密码破解程序，如 `L0phtCrack` ([`www.helpnetsecurity.com/2012/09/30/l0phtcrack/`](https://www.helpnetsecurity.com)) 和 `John The Ripper` ([`www.openwall.com/john/`](https://www.openwall.com))（含 NT 扩展）。

### SAM 文件

限制对 SAM 文件的访问至关重要。物理锁定服务器是防止他人携带软盘走近服务器、启动 DOS 以获取 SAM 或从修复文件夹复制备份 `SAM_` 的唯一途径。

`SYSKEY.SAM` 加密增强功能也应启用。`SYSKEY` 建立 128 位加密密钥，而非服务器默认提供并使用的 40 位密钥。可通过选择“开始菜单 | 运行”并输入 `syskey` 进行配置。

### 入侵检测系统

入侵检测系统（IDS）应安装在您的网络中，部署层级可为主机级、子网级、部门级或企业级。我建议组合使用 `ISS RealSecure`、`CMDS`、`Cisco NetRanger` 和 `Checkpoint Firewall-1`（或 `Cisco PIX`）。我建议将这四者结合使用，因为厂商间已合作，所有产品能够互相“通信”和交互，并可生成一份集中报告。

### BO/BO2K

`BO/BO2K` 具有以下特征：

*   `BO` 默认文件名为 [`spacel.exe`, `boserve.exe`, `boconfig.exe`]
*   `BO2K` 默认文件名为 `bo2k.exe`、`bo2kcfg.exe`、`bo2kgui.exe`、`UMGR32.EXE`、`bo_peep.dll`、`bo3des.dll`。
*   基于 UDP 运行。
*   `BO` 默认端口为 `31337`。
*   `BO2K` 默认配置为监听 TCP 端口 `54320` 或 UDP `54321`，将自身复制到 `%systemroot%` 下名为 `UMGR32.exe` 的文件，并作为名为“Remote Administration Service”的服务安装。这些值可通过随程序附带的 `bo2kcfg.exe` 实用程序进行修改。
*   一个名为 `Saran Wrap` 的 `BO` 插件将 `BO` 隐藏在现有的标准 `InstallShield` 安装包中，使其更容易诱骗系统用户执行。另一个名为 `Silk Rope` 的插件将 `BO` 与另一个无害的可执行文件链接，但双击一次即可同时启动两者，并在后台静默安装 `BO`。尽管尚未发现，但携带 `BO` 的宏病毒可能即将出现。

## 第 12 章 铁路运输

DOI: [10.1201/9781003134817-12](https://doi.org/10.1201/9781003134817-12)

我再次指出，`Alstom`（`Alstom.com`）在铁路交通领域的网络安全方面是一位卓越的领导者。下面我们简要查看他们的产品，但您也应查阅他们的优秀白皮书：[`www.alstom.com/sites/alstom.com/files/2020/09/15/Whitepaper%20Cybersecurity.pdf`](https://www.alstom.com)

首先，由于术语的历史使用，关于何时使用工业控制系统（Industrial Control System，ICS）和监控控制与数据采集系统（Supervisory Control and Data Acquisition，SCADA）的争论仍在继续，尚未结束。如果您在工业自动化领域工作了数十年，那么这对您来说很明确。但这里讨论的并不仅仅是行业专业人士。有人会说 SCADA 是 ICS 的子集。然而，对公众、各政府委员会成员以及媒体（在线、报纸、杂志、广播、电视）而言，SCADA 这一术语已经广为人知并被广泛使用。因此，我在此坚持使用 SCADA 这一术语。

铁路系统本质上是一个滚动的 SCADA 系统（列车本身），它与路边设备（位于列车外部的设备，安装在我们称之为“小屋”的盒子中，以及铁路轨道旁的其他设备……受摄像头等监控）以及通信系统交互。铁路控制中心（RCC）负责列车监控和控制，卫星、基站也参与其中。此处不再展开更多细节，足以供网络取证用途。

我也想提及信息技术（IT）和运营技术（OT）这两个术语。OT 指的是用于管理 ICS/SCADA 系统的计算机网络/系统，而 IT 指的是用于商业/行政管理的计算机网络/系统。我可以指出，区分 IT 与 OT 的主要方式是：如果 IT 服务器/计算机/系统出现问题，可能只需重启或打补丁；但如果 OT 服务器/计算机/系统出现问题，则不能简单“重启”或“打补丁”，后果可能是人员伤亡、工厂爆炸、核设施灾难（如冷却系统失效）、污水处理厂公共供水被污染或列车脱轨。铁路系统根据您当前关注的系统部分，既包含 IT 网络也包含 OT 网络。您还可以引入物联网（IoT）概念，因为铁路系统中也嵌入了 IoT 设备。IoT 设备是物理硬件/软件实体（例如传感器），它们通过互联网进行监控、控制和数据交换。
