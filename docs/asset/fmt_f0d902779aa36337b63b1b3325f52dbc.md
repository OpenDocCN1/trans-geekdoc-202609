### 26. 下列哪项是攻击者利用 Shellshock 漏洞最常用的方法之一？

**C.** 表单字段输入操纵

**D.** 通过利用 CGI（通用网关接口）的 Web 服务器

![Image](img/r.jpg) **D.** 我敢打大赌注，你一定会在考试中看到 Shellshock——甚至可能出现几次。Shellshock（也称为 Bashdoor）利用了 `bash` shell 中的一个功能，该功能旨在允许环境变量设置配置。基本上，有人在 2014 年在玩 `bash` 的时候，发现他们可以向环境变量配置的命令行提交中添加任意命令。如果攻击者在漏洞系统上输入类似的内容：

```bash
env val='() [ :;}; echo BADCOMMAND' bash -c "echo REALCOMMAND"
```

`BADCOMMAND` 将在真实命令之前执行。

根据赛门克（[www.symantec.com/connect/blogs/shellshock-all-you-need-know-about-bash-bug-vulnerability](https://www.symantec.com/connect/blogs/shellshock-all-you-need-know-about-bash-bug-vulnerability)）的，“最可能的攻击路径是通过利用 CGI（通用网关接口）的 Web 服务器，这是广泛用于生成动态 Web 内容的系统。攻击者可能利用 CGI 向漏洞的 Web 服务器发送格式错误的环境变量。因为服务器使用 Bash 来解释该变量，它也将运行附加在其上的任何恶意命令。” Shellshock 的其他利用途径还包括：

*   **OpenSSH**: “强制命令”功能（当用户登录时运行固定命令，即使用户请求了不同的命令）可以在 Shellshock 中被利用。

*   **DHCP**: 某些 DHCP 客户端具有将命令传递给 `bash` shell 的能力——例如在连接到 Wi-Fi 网络期间。这可以在 Shellshock 中被利用。

*   **Qmail**: 如果使用 `bash` 处理电子邮件消息，服务器处理外部输入的方式可能会在 `bash` 中产生可利用的。

## 7 无线网络攻击

本章包含涉及：

- 描述无线网络架构和术语

- 识别无线网络类型和身份验证形式

- 描述无线加密算法

- 识别无线攻击方法和工具

无线网络图标通常显示为某种向外发射圆圈（或半圆）的信标，就像波浪延伸到大气中无声地拍打岸岸一样。这完全恰当，因为这一切实际上都始于夏威夷。至少我们讨论的无线数据网络是如此。*真实*的故事可以追溯到 1888 年。

在竞争“柏林奖”（该奖项为证明詹姆斯·克拉克·麦克斯韦的光电磁理论而提出的挑战）时，德国物理学家海因里希·鲁道夫·赫尔兹证明了电波的存在（并在此过程中创造了第一个个人造电波）。在短短六年内，他的电波技术作为一种新的通信形式——电报而爆发增长，电线随处可见用于点对点通信。不久之后，意大利发明家古列尔莫·马可尼开始研究电波本身，并发现他可以扩展信号，将其从电报线中解放出来，并利用它传输声音。

在第二次世界大战期间，美国曾使用无线电波进行`data`传输——这在当时是首创。但现代无线数据网络的出现源于战后的一种推测，即无线电波可以用于更巨大的领域。1971 年，诺曼·阿布拉姆森（Norman Abramson）和夏威夷大学的一个研究小组开始寻找无线传输中一个大答案：是否可以使用无线传输在多个节点之间进行数据通信，同时为节点提供一种有序的方式让它们轮流发送数据？相对来说，数据传输似乎很容易，但如果有几个节点同时有数据要发送，它们该如何轮流，并避免接收端出现一堆乱码呢？

于是，“ALOHAnet”诞生了，这是历史上第一个数据包交换随机访问网络——我补充一下，无论是否有线缆都是如此。ALOHAnet 最初由七台计算机组成，并成为世界上首个无线局域网（WLAN）。尽管起源于谦微且规模较小，但在 1972 年连接到 ARPANET 后，ALOHAnet 开启了网络领域的新纪元，并彻底改变了世界。

所以，下次当有人访问你家并感谢你让他们使用你的 Wi-Fi 时，给他们递上花环并告诉他们：“*‘A’ole pilikia*（不客气）。”毕竟，既然你大方到愿意分享，不如用无线语言说一句“不客气”吧。
