在最初学习如何规划和建立防御位置时，士兵被要求离开自己的外围，像对手一样去检查拟议的防御位置。在许多情况下，一个最初看起来完全合理的战壕会被证明是显而易见且脆弱的；或者结果发现，如果攻击者躲在特定的树或岩石后面，防御者将无法向他们射击。正如作者们愿意从个人经验中承认，这通常是一次大开眼界、尽管有些尴尬的练习。

从对手的角度来看，成功行动的第一步是深思熟虑的侦察工作。尽可能获取目标网络的信息不仅可以让攻击者对你的网络有良好的了解，还可能在开始攻击时让工作变得容易得多。许多信息源完全免费。这对于对手来说特别有利，因为只需要投入时间就能获得目标的全概况。

### 开源情报

对于对手来说，在不直接接触目标的情况下获取信息几乎总是更优的。为什么？因为他们接触得越少，留给防御者和调查人员发现的指纹（或日志记录）就越少。在理想情况下，对手可以在无需触碰目标的情况下获得成功破解目标所需的所有信息。`被动侦察`是在不与目标交互的情况下收集目标信息的过程。`开源情报`（`OSINT`）是从公开来源收集数据的过程。

---

**考试提示**：`passive reconnaissance` 和 `open source intelligence` 术语在某些语境下有细微差别，但它们都用于收集有关任何个人、组织或网络的大量信息。请注意，这些许多操作符是为了允许用户精炼他们的搜索。

关于网络的另一个有用信息源是维持互联网运行所需的多个注册机构。可路由的互联网协议（IP）地址以及域名都需要在全球范围内唯一，这意味着必须有某种机制来确保没有两个实体使用相同的 IP 地址或域名。我们作为一个全球社区，管理这种去冲突的方式是通过接下来描述的非营利公司来实现的。这些公司提供了有关组织在网络空间中足迹的一些有用细节。

### 域名系统

如果没有域名系统（`DNS`），互联网无法按照今天的方式运行。尽管`DNS`是现代网络中的关键组成部分，但许多用户对其存在及其对 Web 正常功能的重要性并不知情。`DNS`是负责将域名（例如[www.google.com](http://www.google.com)）与其服务器的 IP 地址（或地址）关联的机制，反之亦然。没有`DNS`，你必须为你想要访问的任何网站记忆并输入完整的 IP 地址，而不是使用易记的统一资源定位符（`URL`）。管理员通过在命令行中使用`nslookup`、`host`和`dig`等工具来排查 `DNS` 和网络问题。攻击者也可以使用相同的工具来询问 `DNS` 服务器，以推导出有关网络的信息。在某些情况下，攻击者可以自动化此过程，以跨越许多 `DNS` 服务器，这种做法被称为`DNS 采集`（DNS harvesting）。

---

**注意**：`DNS` 区域传输是由客户端发起的——无论是来自二级 `DNS` 服务器还是网络主机。由于 `DNS` 数据可被用于绘制整个网络的地图，因此只允许授权的主机请求完整传输是至关重要的。这是通过实施访问控制列表（`ACLs`）来实现的。`绝不`允许向未识别的设备进行区域传输。

每当域名被注册时，注册人都会提供有关该组织的详细信息供公开。这可能包括名称、电话和电子邮件联系信息、域名系统细节以及邮寄地址。可以使用名为`WHOIS`（读作 `who is`）的工具查询这些信息。`WHOIS` 同时提供命令行和网页版本，可以是事件响应人员和网络工程师的有效工具，但它也是垃圾邮件发送者、身份窃贼以及任何试图获取目标个人和技术信息的攻击者的有用信息收集工具。例如，图 1-2 显示了来自 `ICANN` `WHOIS` 网页服务的返回的报告。你应该意识到，某些注册商（你注册网站时通过的服务）提供`隐私`注册服务，在这种情况下，查询返回的是注册商的信息而不是注册人的。虽然这可能对于限制组织的暴露很有用，但代价是，在紧急情况下可能很难联系到该组织。

### 招聘网站

提供就业服务的网站对信息收集者来说是福音。想想看：用户自愿提交各种个人数据、完整的职业历史，甚至还有一些个人偏好。除了提供个人识别特征外，这些网站通常还包含成员在更大网络中角色的指示。由于许多账户通常通过电子邮件地址识别，对于攻击者来说，自动化收集这些电子邮件地址轻而易举，这种做法被称为`电子邮件采集`（e-mail harvesting）。攻击者可以利用此来获益，例如，利用业务联系人来撰写更具说服力的钓鱼邮件。

### 社交媒体

社交媒体网站也是个人信息的极具针对性的来源。与招聘网站一样，攻击者可以使用公开信息获取有关个人或公司的信息。从个人页面获取的在线线索使攻击者能够进行`社交媒体画像分析`，即利用目标的偏好和模式来确定其可能的行为。画像分析对于希望利用精准广告的在线广告商来说是一个关键工具。这些信息对于攻击者也有用，可以识别组织中哪些用户可能更容易成为`社会工程`攻击的受害者，在这种攻击中，入侵者欺骗受害者透露敏感信息或以损害系统安全性。

许多攻击者知道进入网络的最佳路线是通过疏忽或未经过训练的员工。在社会工程活动中，攻击者利用欺骗手段（通常受对其目标建立画像的影响）来操纵目标执行不符合其最佳利益的行为。这些攻击有多种形式——从看似来自合法来源的高级钓鱼邮件到请求额外个人信息的电话。钓鱼攻击仍然是网络防御者面临的挑战，因为它们变得越来越具有说服力，经常使收件者泄露敏感信息。

## 主动侦察

有时，从开源情报（OSINT）中获取的信息会激发攻击者与目标网络进行交互的兴趣。此时，攻击者可能对目标的拓扑结构、网络上可能存在其他主机、各种操作系统或可用服务没有很好的了解。在本节中，我们将讨论攻击者如何使用主动技术获取更完整的网络图的几种方法。

### 扫描

`Scanning` 是一种通过试探并记录响应来获取网络或设备更多细节的方法。自互联网早期以来，攻击者一直在扫描目标试图寻找突破口，从被称为 `war dialing`（战争拨号）的技术开始。通过使用设备顺序自动拨打号码列表并听响应，攻击者可以判断对面是人还是机器。`Host scanning` 是通过发送消息并根据响应对系统进行分类或采取探测措施，并发现系统细节的有效方法。扫描器通常分为：网络映射器、主机（端口）扫描器和 Web 应用漏洞扫描器。

### 网络映射

`network mapping` 的目标是理解网络的拓扑结构，包括非军事化区。在网络映射期间使用的这些操作统称为 `topology discovery`。创建网络图的第一步是通过执行“扫射”找出存在哪些设备。与之前的 `war dialing` 示例类似，网络扫射是通过向每个设备发送消息并记录响应来实现的。对此的一种流行工具是 Network Mapper，更常被称为 `nmap`。在执行网络扫射时，`nmap` 的默认行为是发送 `ICMP Echo Request`、指向端口 443 的 `TCP SYN`、指向端口 80 的 `TCP ACK` 以及 `ICMP Timestamp Request`。这四种方法中任何一种的成功响应都是该地址正在使用的证据。`nmap` 还具有 `traceroute` 功能，允许它通过巧妙操控数据包的生存时间（TTL）值来映射各种复杂的网络。映射网络后，攻击者可能拥有网络清单，但可能想要填充细节。

### 端口扫描

`Port scanners` 是旨在探测主机或服务器以确定哪些端口开启的程序。它们对于管理员来说是重要的工具。这种枚举主机提供的各种服务的方法是 `service discovery` 的手段之一。它允许攻击者通过洞察目标上运行的服务来为粗略轮廓添加细节。因为连接网络的设备通常在 `80` 和 `25` 等已知端口上运行服务，端口扫描是获取这些设备信息的可靠来源。根据响应时间、响应类型和其他标准，扫描软件可以识别正在运行哪些服务——某些软件甚至可以提供 `OS fingerprinting`（操作系统指纹识别）来识别设备的操作系统。然而，识别操作系统并不是完美的，因为软件用于检测的依赖值可能会根据网络配置和其他设置而改变。有了扫描器提供的信息，攻击者可以更有针对性选择哪种攻击可能最有效。

**考试提示**：操作系统指纹识别不是一门精确的科学。你不应该仅仅因为扫描器将其识别为某个操作系统，就断定主机正在运行该系统。

### Web 应用漏洞扫描

`web application vulnerability scanner` 是一种扫描 Web 应用程序以确定安全漏洞的自动化工具。流行的实用程序中包含了常见的测试，例如 SQL 注入、命令注入、跨站脚本和服务器配置不当的测试。随着多年应用程序使用量的增加，利用漏洞攻击的频率也随之增加。这些扫描器非常有用，因为它们会自动检查网络上许多系统的许多类型漏洞。扫描通常基于现有的已知漏洞数据库，因此在使用此类扫描器时考虑这一点很重要。尽管从严格定义上说漏洞扫描器没有提供识别现有漏洞之外的任何功能，但某些扫描器提供了额外的关联功能或可以使用插件和 API 扩展功能。

### 捕获数据包

想象你正坐在去进城的火车上。你注意到两个商人正坐在和你同一节车厢里并聊天。你坐在他们听力范围之外，但根据他们的肢体语言和对话动态，你知道其中一个正在向另一个推销想法，这是一个非常敏感的话题。其中一个显然是供应商，另一个是要求苛刻的客户。在这种情况下，你可以在没有实际听到他们讨论的任何内容的情况下，对他们的关系做出强有力的假设，如果你再靠近几英尺，你可能记录下他们交易的丰富细节。

在网络中，从源到目的地移动的数据（如果不是目标本身）可能会揭示大量关于通信主机的信息。如果流量是以明文传输的——意味着节点之间没有使用加密——那么任何穿越网络的内容在被截获时都可以被完整地读取。密码、图像、文本和声音都可以从明文传输的流量中轻松恢复——从而凸显了加密的重要性。但仅仅是访问流量移动的方式就可以揭示存在哪些类型的机器。

捕获网络上的原始流量需要专门设计的软件来拦截和解释通过监控接口的流量。这种软件被称为`packet sniffer`（数据包嗅探器）或`network analyzer`（网络分析器），它记录观察到的数据包并记录事务。数据包嗅探器可能会记录数据包的内容，或者只记录一部分称为`header`（头部，或关于数据的数据），以确定流在源和目的之间的流量类型。我们将在本章稍后讨论一种名为 `Wireshark` 的流行网络协议分析器及其命令行版本 `TShark`。`Wireshark` 和类似的工具允许运行它们的机器在`promiscuous mode`（混杂模式）下监控连接的网络，在这种模式下，网卡会监听所有流量，无论这些流量是否是给该机器的。数据包的头部将包含源和目的的信息，网卡会忽略任何不是发给自己的数据包。所有的 Internet 协议版本 4（`IPv4`）和版本 6（`IPv6`）数据包都以头部信息开头。`IPv4` 头部的大小可变（在 20 到 60 字节之间），标准 `IPv4` 数据包的总尺寸最大为 65,535（`2¹⁶`）字节。虽然 `IPv6` 的最大数据包尺寸与 `IPv4` 相同，但 `IPv6` 的头部尺寸固定为 40 字节。无论哪种情况，捕获头部信息与整个数据流之间都有巨大的大小差异，因此在设置数据包捕获时必须提供更大的存储选项。全捕获的主要优势是能够重构交换的内容（文本、视频、音频或图像）。当然，如果攻击者直接访问目标机器，他可以通过将数据包嗅探器设置为记录指定主机接口上的所有流量数据，从而捕获从目标机器到网络上其他主机的所有流量。在没有直接访问主机的情况下，必须采取额外步骤来收集流量。嗅探流量的设置取决于所涉及的网络类型，我们将在下一节讨论软件和硬件要求。

## 特殊考虑因素

在选择执行主动侦察活动的方法时，必须考虑许多变量。例如，目标是有线网络还是无线网络、虚拟还是物理基础设施、内部还是外部主机，以及本地部署还是云环境，这些都会产生不同影响。在接下来的章节中，我们将讨论你应该记住的一些突出问题，特别是当你参加 `CSA+` 考试时。

### 有线网络考虑因素

在某种程度上，有线网络比其无线兄弟更安全，仅因为它们需要物理上的接近或接触才能从中获取任何信息。显然，由于大多数主机与开放互联网的广泛连接（尽管是通过某种保护机制），这种优势被部分抵消了。

### 分用器

对网络基础设施的物理访问应始终被严格控制，因为环境为全流量捕获提供了最佳选择，并可能对网络安全态势造成破坏。通过物理方式访问网络，数据包捕获的一种常用方案是网络分用器。第一种被称为`passive tap`（被动分用器），不需要额外的电源。在铜介质中，这种分用器将与电缆中的线路建立直接连接，并分割线路上的信号，使得功率继续流向目的地，但有足够的功率引导到分用器供嗅探器使用。
