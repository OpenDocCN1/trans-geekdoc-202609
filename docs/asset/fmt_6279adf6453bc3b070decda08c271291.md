
# Transformer 架构与 BERTimbau 研究

Transformer 架构已成为自然语言处理的主导架构，在不同任务中频繁优于卷积和循环神经网络 [14]。预训练模型可以在通用或专家数据集上进行训练，因此可以轻松适应具有卓越性能的任务。该架构特别有利于大型语料库的预训练，能够提高后续任务（如文本分类、语言理解等）的准确率。
