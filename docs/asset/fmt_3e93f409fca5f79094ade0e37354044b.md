**选项 A 错误。** 提前通知所有员工该活动将违背测试目的，因为他们会预期收到钓鱼邮件，因此更有可能识别并报告它。

**选项 C 错误。** 为点击模拟钓鱼链接的员工提供奖励会鼓励风险行为，并且与提高安全意识的目标背道而驰。

**选项 D 错误。** 虽然回顾以前往活动的结果可以提供见解，但它不是确保当前活动成功的最有效的第一步。

**问题 398。** 一个组织计划部署一个新应用程序，该程序可以从内部网络和互联网访问。该程序将仅通过 HTTPS 通信。安全管理员被要求配置防火墙以允许必要的流量。管理员应该配置以下哪项？

(A) 允许端口 21 并阻塞所有其他端口

(B) 允许端口 443 并阻塞所有其他端口

(C) 允许端口 80 并阻塞所有其他端口

(D) 允许端口 23 并阻塞所有其他端口

**解析 398。** **正确答案：B. 允许端口 443 并阻塞所有其他端口。** HTTPS 主要使用端口 443 进行安全通信。因此，允许端口 443 并阻塞所有其他端口将确保网络应用程序的安全运行。

**选项 A 错误。** 端口 21 用于 FTP（文件传输协议），与 HTTPS 无关。

**选项 C 错误。** 虽然端口 80 用于 HTTP，但它不提供 HTTPS 在端口 443 上所提供的加密功能。

**选项 D 错误。** 端口 23 用于 Telnet，与安全通信无关。

**问题 399。** XYZ 公司的 IT 部门非常希望防止用户更改系统设置（例如更改防火墙配置）。他们的大多数基础设施基于 Windows 操作系统。以下哪是实现这一目标的最有效方法？

(A) 使用 SELinux 强制执行的访问控制

(B) 利用组策略 (Group Policy) 设置并强制与系统设置相关的策略

(C) 部署第三方软件解决方案锁定系统设置

(D) 实施用户培训计划，指导用户遵循系统设置的最佳实践

**解析 399。** **正确答案：B. 利用组策略 (Group Policy) 设置并强制与系统设置相关的策略。** 组策略在 Active Directory 环境中为操作系统、应用程序和用户设置提供集中管理和配置。这可以用于在 Windows 环境中强制执行特定的系统设置策略。

**选项 A 错误。** SELinux（增强型 Linux）主要用于 Linux 环境以实施强制访问控制。对于主要基于 Windows 的基础设施并不合适。

**选项 C 错误。** 虽然可能存在第三方解决方案，但利用组策略等内置功能通常更简洁、更具成本效益且高效。

**选项 D 错误。** 虽然用户培训至关重要，但在不实施技术控制的情况下仅依赖培训，对于防止用户更改系统设置是无效。
