### 2. 二分类交叉熵损失

对于二分类问题，输出层只有一个逻辑回归神经元，输出样本属于某一类别（如类别 1）的概率，所有样本的概率输出形成向量 `f`，训练样本的目标值用 1 或 0 表示样本属于哪一类。所有样本目标值组成的向量用 `y` 表示。则交叉熵损失为：

$$

\begin{matrix} 

L(f, y) = \frac{1}{m}\sum\limits_{i = 1}^{m}L_{i}(y^{(i)}, f^{(i)}) = - \frac{1}{m}\sum\limits_{i = 1}^{m}\left\lbrack y^{(i)}\log(f^{(i)}) + (1 - y^{(i)})\log(1 - f^{(i)}) \right\rbrack \\ 

= - \frac{1}{m}\text{np.sum}(y \log f + (1 - y)\log(1 - f)) 

\end{matrix}

$$

其中 $y^{(i)}$ 取值为 1 或 0，表示样本所属类别，$f^{(i)}$ 表示样本属于取值为 1 的类别的概率。

二分类交叉熵损失可以通过以下代码计算：

```python
- (1./m) * np.sum(np.multiply(y, np.log(f)) + np.multiply((1 - y), np.log(1 - f)))
```

例如：

```python
# https://towardsdatascience.com/neural-net-from-scratch-using-numpy-71a31f6e3675
f = np.array([0.1, 0.2, 0.5])  # 三个样本对应类别 1 的概率
y = np.array([0, 1, 0])        # 对应 3 个样本的分类
m = y.shape[0]

loss = - (1./m) * np.sum(np.multiply(y, np.log(f)) + np.multiply((1 - y), np.log(1 - f)))
print(loss)                                                 
```

```
0.8026485362172906
```

为了防止 `f` 或 `1-f` 取值为 0 导致 `log()` 函数异常，可以在对数计算中加入一个极小量 $\epsilon$，因此可以写出如下的二分类交叉熵损失函数：

```python
def binary_crossentropy(f, y, epsilon=1e-8):
    # np.sum(y*np.log(f+epsilon)+ (1-y)*np.log(1-f+epsilon), axis=1)   
    m = len(y)
    return - (1./m) * np.sum(np.multiply(y, np.log(f + epsilon)) + np.multiply((1 - y), np.log(1 - f + epsilon)))    

binary_crossentropy(f, y)
```

```
0.8026485091802541
```

### 3. 多分类交叉熵损失

上述是二分类问题的交叉熵损失，可以推广到 2 类以上的多分类问题。$f_c^{(i)}$ 表示第 $i$ 个样本属于第 $c$ 个类别的概率，$y_c^{(i)}$ 用 1 或 0 判断第 $i$ 个样本是否属于类别 $c$，即独热向量 $y^{(i)}$ 表示样本目标值。根据第 3 章的 Softmax 回归可知，多个样本的交叉熵损失如下：

$$L(f, y) = \frac{1}{m}\sum\limits_{i = 1}^{m}L_{i}(\mathbf{y}^{(i)}, \mathbf{f}^{(i)}) = - \frac{1}{m}\sum\limits_{i = 1}^{m}\sum\limits_{c = 1}^{C}y_{c}^{(i)} \cdot \log(f_{c}^{(i)}) = - \frac{1}{m}\sum\limits_{i = 1}^{m}y^{(i)} \cdot \log(f^{(i)})$$

例如，若为 3 分类问题（$C=3$），某样本的 $f^{(i)}$ 和 $y^{(i)}$ 值为：

$$

\begin{matrix} 

f^{(i)} = \begin{bmatrix} f_{1}^{(i)} & f_{2}^{(i)} & f_{3}^{(i)} \end{bmatrix} = \begin{bmatrix} 0.3 & 0.5 & 0.2 \end{bmatrix} \\ 

y^{(i)} = \begin{bmatrix} y_{1}^{(i)} & y_{2}^{(i)} & y_{3}^{(i)} \end{bmatrix} = \begin{bmatrix} 0 & 0 & 1 \end{bmatrix} 

\end{matrix}

$$

该样本的真实类别为第 3 类，预测值表示样本属于三个类别的概率。对该样本，其交叉熵损失为：

$$- (0 \times \log(0.3) + 0 \times \log(0.5) + 1 \times \log(0.2)) = -\log(0.2)$$

交叉熵损失仅取决于对应真实类别的项。

因此，若所有样本的目标值均为独热向量，对 $m$ 个样本，$\mathcal{L}(f, y)$ 可写为向量化的哈达玛积形式：

$$\mathcal{L}(f, y) = - \frac{1}{m}\text{sum}(\mathbf{y} \odot \log(\mathbf{f}))$$

在 NumPy 代码中可写为：

```python
-(1./m) * np.sum(np.multiply(y, np.log(f)))
```

例如，对于 $m=2$ 个样本，Softmax 输出 $F$ 与样本目标值（独热向量）矩阵 $Y$ 如下：

$$

\begin{matrix} 

F = \begin{bmatrix} 0.2 & 0.5 & 0.3 \\ 0.4 & 0.3 & 0.3 \end{bmatrix} \quad 

Y = \begin{bmatrix} 0 & 0 & 1 \\ 1 & 0 & 0 \end{bmatrix} 

\end{matrix}

$$

以下代码计算这 2 个样本的交叉熵损失：

```python
def cross_entropy_loss_onehot(F, Y):
    m = len(F)  # F.shape[0]
    return -(1./m) * np.sum(np.multiply(Y, np.log(F)))

F = np.array([[0.2, 0.5, 0.3], [0.4, 0.3, 0.3]])
Y = np.array([[0, 0, 1], [1, 0, 0]])
cross_entropy_loss_onehot(F, Y)
```


如果每个样本的目标值不使用独热向量表示，而是用整数表示样本属于哪一类。对于 $C$ 分类问题，这些整数值为 $0, 1, 2, \dots, C-1$，如用整数 2 表示样本属于第 3 类。此时样本的交叉熵损失为 $f^{(i)}$ 中对应分量的负对数值（即下标为 2 的类别 $f_2^{(i)}$），即 $-\log f_2^{(i)}$。

对于用整数表示样本目标类别的情况，多分类交叉熵损失为：

$$\mathcal{L}(f, y) = \frac{1}{m}\sum\limits_{i = 1}^{m}L_{i}(y^{(i)}, f^{(i)}) = - \frac{1}{m}\sum\limits_{i = 1}^{m}\log(f_{y^{(i)}}^{(i)})$$

其中 $y^{(i)}$ 表示第 $i$ 个样本所属类别对应的整数值（下标）。

因此，可以定义如下的多分类交叉熵计算函数：

```python
def cross_entropy_loss(F, Y, onehot=False):
    m = len(F)              # F.shape[0] 样本数量
    if onehot:
        return -(1./m) * np.sum(np.multiply(Y, np.log(F)))
    else: 
        return - (1./m) * np.sum(np.log(F[range(m), Y]))  # F[i] 中对应 Y[i] 类别的对数值
```

在以下代码中，`F` 是 2 个样本的输出，每个样本的输出向量有 3 个分量，表示样本属于 3 个类别的概率，目标 `Y` 的第 $i$ 个分量表示第 $i$ 个样本对应的类别下标值（如 0, 1, 2）。

```python

Y = np.array([2, 0])                               # 第 1 个样本属于第 2 类，第 2 个样本属于第 0 类
```

$$ \mathcal{L}(f, y) = \frac{1}{m}\sum\limits_{i = 1}^{m}L_{i}(y^{(i)}, f^{(i)}) + \lambda\sum\limits_{l = 1}^{L} \parallel W^{[l]} \parallel_{2}^{2} $$

### 4.1.7 基于数值梯度的神经网络训练

与回归问题一样，具有特定结构的神经网络函数完全由神经元的参数（权重参数和偏置参数）决定，不同的参数代表不同的具体神经网络函数。

对于一组样本，我们希望找到能最好地拟合这些样本的神经网络参数，即确定一个能最好地响应样本特征与目标值之间关系的神经网络函数。寻找最佳神经网络参数的过程与任何机器学习模型训练过程相同，都是寻找使某个损失最小化的模型参数。具体来说，就是通过求解损失函数的最小化问题来确定神经网络的模型参数。这个过程称为**神经网络训练**。

神经网络的训练与回归模型的训练相同，都使用梯度下降法迭代更新模型参数，直到算法收敛到足够程度或达到最大迭代次数。梯度下降法需要计算损失函数关于模型参数的偏导数。神经网络通常包含许多层，每层有许多神经元，每个神经元包含许多模型参数。计算偏导数比回归问题更复杂。

上文讨论了神经网络的前向计算和损失函数的计算，在梯度下降算法中可以使用数值梯度来近似解析梯度。接下来，为之前的 2 层神经网络实现一个完整的神经网络训练和预测算法。

<https://www.bogotobogo.com/python/scikit-learn/Artificial-Neural-Network-ANN-5-Checking-Gradient.php>

在线性回归中，模型参数通常初始化为 0，但如果神经网络模型中的权重参数初始化为 0，神经网络的神经元最终会收敛，即所有神经元的模型参数将相同，而每层有多个神经元。一个神经元等同于一个神经元，这极大地降低了神经网络的表达能力，使得难以获得令人满意的神经网络。因此，权重通常随机初始化，研究人员提供了多种不同的神经网络权重初始化方法。

通常，神经网络的偏置初始化为 0，权重参数从高斯分布等分布中随机采样。如果某层神经元的数量为 $n^{(l)}$，上一层的输出值数量为 $n^{(l-1)}$，则该层的神经元权重矩阵 $W^{(l)}$ 是一个 $n^{(l-1)} \times n^{(l)}$ 矩阵，可以用以下 Python 代码初始化：

```python
Wl = np.random.randn(n_l_1, n_l) * 0.01
```

即将标准正态分布的所有随机值乘以 0.01。

假设上述双层神经网络的输入特征数量为 `n_x`，中间层和输出层的神经元数量分别为 `n_h` 和 `n_o`，函数 `initialize_parameters()` 完成所有模型参数的初始化并返回一个字典对象。

```python
import numpy as np

def initialize_parameters(n_x, n_h, n_o):
    np.random.seed(2)            # 固定种子，使得每次运行此代码时
                                 # 随机数的值始终相同
  
    W1 = np.random.randn(n_x, n_h) * 0.01
    b1 = np.zeros((1, n_h))
    W2 = np.random.randn(n_h, n_o) * 0.01
    b2 = np.zeros((1, n_o))
    
    assert (W1.shape == (n_x, n_h))
    assert (b1.shape == (1, n_h))
    assert (W2.shape == (n_h, n_o))
    assert (b2.shape == (1, n_o))
    
    parameters = [W1, b1, W2, b2]
    return parameters
```

编写前向计算函数 `forward_propagation(X, parameters)`：

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def forward_propagation(X, parameters):     
    W1, b1, W2, b2 = parameters       
   
    Z1 = np.dot(X, W1) + b1    # Z1 shape： (3,2)(2,4)+(1,4)=>(3,4)  
    A1 = np.tanh(Z1)
    Z2 = np.dot(A1, W2) + b2   # Z2 shape： (3,4)(4,3)+(1,3)=>(3,3) 
    # A2 = sigmoid(Z2)  
   
    assert(Z2.shape == (X.shape[0], 3))
    return Z2
```
