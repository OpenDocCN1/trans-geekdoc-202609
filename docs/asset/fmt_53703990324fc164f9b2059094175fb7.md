
# 物理安全与弹性基础设施

在设施内部，物理安全像技术安全实现一样分层部署。可使用许多物理控制；Security+ 考试大纲包含考试所需熟悉的具体示例。接下来几页我们将探讨每个主题。

**工牌** 在物理安全中可扮演多种角色。除了通过磁条和射频识别（RFID）访问系统用于入口访问控制外，工牌通常还包含照片和其他信息，可让人员和保安快速确定持卡人身份、应有的区域或访问权限，以及是员工还是访客。这也使工牌成为社会工程学攻击的目标，攻击者试图获取、复制或伪造工牌以绕过安检。工牌常与 **邻近读卡器** 配合使用，后者利用 RFID 查询工牌，无需将其插入或刷过磁条读卡器。

## 报警与报警系统

**报警**和报警系统用于检测并警示问题，包括未授权访问、环境问题和火灾。报警系统可以是本地监控或远程监控，其复杂性和功能可能差异很大。正如基于计算机的系统发出的警报一样，过于频繁或频率过高的报警很可能会被员工忽视、禁用或绕过。事实上，一些渗透测试人员甚至会想办法让报警反复触发，这样当他们进行渗透测试并触发报警时，员工不会感到惊讶，也不会去调查渗透测试人员实际触发的那个报警！

## 灭火系统

**灭火系统**是安全系统的重要组成部分，通过降低灾难性火灾的可能性来增强弹性。最常见的灭火系统类型之一是喷淋系统。主要有四种类型，包括湿式喷淋系统，其中始终充满水；干式喷淋系统，平时为空，需要时才注水；预作用喷淋系统，当检测到潜在火灾时注水，随后在特定喷头被热量激活时释放水流；以及淹没式喷淋系统，平时为空且喷头敞开，激活后会覆盖整个区域。

基于水的喷淋系统并非常用的唯一灭火系统类型。气体灭火剂通过置换氧气、降低热量或阻止氧气与物质燃烧，常用于数据中心、金库和艺术博物馆等水可能不是可行或安全选择的区域。化学灭火剂（包括湿式和干式）也被使用；例如机库使用的泡沫灭火系统，以及家庭和其他场所使用的干粉灭火器。

## 标识牌

**标识牌**乍看之下可能不像是一种安全控制，但有效的标识牌可以发挥多种作用。它可以提醒授权人员他们身处安全区域，未经授权的人员不得进入，如发现应上报。标识也可作为威慑控制，例如写着“仅限授权人员”的标牌。然而，与许多其他威慑控制一样，标识只能防止那些可能随意违反标牌所示规则的人，无法阻止那些主动寻求绕过组织安全控制的人。

## 门禁前室

一些组织使用门禁前室（通常称为**人员锁**或**气闸**）作为一种手段，以确保只有授权人员才能进入安全区域，并防止攻击者利用“尾随”攻击进入不该去的地方。门禁前室是一对门，两者都需要某种形式的授权访问才能打开（参见 图 9.2）。第一扇门在授权后打开并关闭，只有在其关闭后，想要进入的人员才能提供授权以打开第二扇门。这样，跟在后面的人（尾随）就会被发现，并推测会被要求离开或被上报。

## 锁

**锁**是你将遇到的最常见的物理安全控制之一。常见部署的锁类型多种多样，从使用钥匙、按钮或其他密码输入机制的传统物理锁，到使用指纹等生物识别标识符的锁，再到连接计算机系统、配备读卡器或关联密码的电子机械锁。锁可用于保护空间和设备，或限制能够解锁它们的人员。线缆锁是确保计算机或其他硬件设备不被从某处移走的常用解决方案。

尽管锁被大量使用，但它们对大多数有决心的攻击者并非真正的威慑。如果攻击者有时间并能接触到锁，锁可能会被绕过、撬开或以其他方式破坏。因此，锁不被视为真正的物理安全控制。安全专业人士中有一句常见的话：“锁只能管住诚实的人。”

## 保安

在需要或有益于人工交互的区域会使用安保人员。保安能够做出技术控制系统无法做出的决策，并能通过提供检测和响应能力来发挥额外作用。保安通常安排在接待区、巡逻设施，或驻守在可访问摄像头和其他传感器的安保监控中心。

访客日志是配合安保人员常用的一种控制措施。保安可以验证个人身份，确保其仅进入应去的区域，并确保其已签署访客日志且签名与档案或身份证上的签名一致。虽然这些都可能被伪造，但警觉的安保人员能显著提高设施的安全性。

安保人员也带来自身的挑战；人可能会犯错，社会工程学攻击可能说服保安违反政策，甚至协助攻击者。保安成本相对较高，需要持续支付薪资，而技术安全控制通常只需较低的安装和维护成本。因此，在大多数组织中，保安仅在有特定需求利用其能力的地方部署。

## 摄像头与传感器

摄像头系统是常见的物理安全控制形式，允许安全从业者和其他人实时观察发生的情况，并录制区域视频供日后调查或其他原因使用。摄像头类型广泛，包括黑白、红外和彩色摄像头，每种类型适用于特定场景。除了摄像头类型，分辨率、是否配备变焦镜头、是否具备云台/俯仰/变焦（PTZ）功能，都是决定其预期用途效果及成本的因素。Security+ 考试重点关注两种摄像头功能：

*   **动作识别**摄像头在检测到移动时激活。这类摄像头在移动相对不频繁的区域特别有用。动作识别摄像头有助于节省存储空间，通常具有缓冲区，当识别到移动时会检索缓冲内容，从而保留移动开始前几秒的视频；这样你就能看到发生的一切。
*   **物体检测**摄像头及类似技术可检测特定物体，或监视特定区域的变化。这类摄像头有助于确保物体未被移动，并能检测枪支或笔记本电脑等特定类型的物体。

另一种摄像头系统是闭路电视（CCTV），它在屏幕上显示摄像头捕捉的画面。一些 CCTV 系统也包含录制功能，随着技术融合，摄像头系统与 CCTV 系统的界限日益模糊。

摄像头并非组织和个人部署的唯一传感器系统类型。常见的传感器系统包括运动、噪音、湿度和温度检测传感器。运动和噪音传感器用作安全传感器，或根据占用情况开启/关闭环境控制系统。温度和湿度传感器有助于维护数据中心环境及其他需要精细环境控制的区域，也可用于其他监控目的。

## 强化安全区域与安全区域

### 安全区域与数据销毁

组织经常需要特定区域的安全性高于其其他空间或区域。数据中心是大多数组织最明显的安全区域之一，金库和保险箱也是如此，它们受到保护以确保未经授权的人员无法进入。金库通常为房间大小且就地建造，而保险箱则较小且便携，或者至少是可移动的。数据中心和金库通常设计有安全且冗余的环境控制、访问控制以及额外的安全措施，以确保其持续安全。

除了内置于数据中心的安全功能外，环境控制（包括使用`热通道`和`冷通道`）也关乎其安全容纳服务器和其他设备的能力。`热通道/冷通道`设计将进气口和排气口交替放置在相邻通道，以确保气流正常，使数据中心设计人员知道在哪里提供冷气以及在哪里处理排气。

在某些情况下，会实施双人完整性控制方案等管理控制来保护保险箱或金库。在双人控制方案中，两名受信任的员工必须协同工作以提供访问权限——使用双钥匙、密码或访问控制因素的两个部分。这一策略可能让你从许多军事电影中感到熟悉，在这些电影中，核武器只有在两个人同时插入钥匙并转动后才能发射。

物理控制（如`法拉第笼`）可为系统提供额外的隔离，它能屏蔽电磁场。`法拉第笼`是由导电网格构成的外壳，可分散无线设备信号的电荷，从而阻断信号。高安全设施可能被建造为`法拉第笼`，或者内部设有`法拉第笼`，以防止手机和其他电子及无线通信发生。`法拉第笼`有时也用于允许在内部测试无线设备，而不影响其他生产网络和设备。

网络安全在安全区域中也发挥作用，包括使用屏蔽子网（也常称为非军事区[`DMZ`]）。屏蔽子网可以是网络的逻辑或物理段，用于容纳可被外部世界或其他安全性较低的群体访问的系统。屏蔽子网依赖防火墙等网络安全设备提供分段，限制进出屏蔽子网的流量，从而保持高安全区域的安全。图 9.3 展示了一个屏蔽子网的示例。

组织使用的网络和其他电信线路也容易受到攻击。这就是`受保护的电缆分发`方案发挥作用的地方。如果组织担心攻击者窃听电缆或试图通过任何方式访问电缆，他们可能会部署各种电缆保护技术。尽管这些技术在大多数环境中相对罕见，但政府设施和其他极高安全级别的设施可能会使用锁具、安全电缆管道和槽道、防篡改密封，甚至能通过压力变化、屏蔽导电性变化或其他技术检测访问尝试的管道和电缆。

当网络安全不足时，可采用`气隙`设计。`气隙`设计物理隔离网络段，从而防止网络连接。`气隙隔离`的网络要求数据必须物理传输，通常在经过仔细检查和批准后才能进入安全区域。

### 安全数据销毁

当数据达到其生命周期末期时，销毁包含该数据的介质是一项重要的物理安全措施。安全数据销毁有助于防止数据泄露，包括垃圾箱搜寻等故意攻击，以及通过重复使用介质、系统或其他数据存储设备导致的无意丢失。表 9.2 列出了纸质记录以及硬盘、磁带、基于闪存的设备甚至完整计算机等介质最常见的销毁选项。

**表 9.2** 安全数据销毁选项

| 销毁方法 | 说明 | 备注 |
| --- | --- | --- |
| **焚烧** | 通常在高温焚烧炉中进行。主要用于纸质记录，尽管某些焚烧炉可能支持电子设备。 | 通常通过第三方服务在场外进行；不留下可恢复的材料。 |
| **粉碎** | 可在现场进行；使用工业粉碎机可处理纸张或设备。 | 传统碎纸机可能允许恢复文档，即使是交叉切割粉碎的文档。对于高安全环境，可能需要焚烧或制浆。 |
| **制浆** | 将纸质文档分解为木浆，去除墨水。材料可回收。 | 彻底销毁文档以防止恢复。 |
| **粉粹** | 将设备分解为极小碎片以防止恢复。 | 输出材料的大小决定了数据恢复的可能性；粉粹通常产生极小的材料碎片。 |
| **消磁** | 从磁带和硬盘等传统磁性介质中磁性擦除数据。 | 仅对磁性介质有效；对固态硬盘、闪存介质、光学介质或纸张无效。 |

物理销毁是确保数据销毁最安全的方式，但在商业环境中，非破坏性选项通常更受青睐，以便重复使用介质或设备。当潜在暴露风险较低，或残留数据暴露风险对组织而言并非重大关切时，可使用安全驱动器或介质擦除选项。

许多组织选择实施的用于安全销毁的最后一个选项是使用第三方解决方案。合同文档和设备销毁公司将取走敏感文档和介质并在其设施内粉碎，或在现场执行相同服务。组织可选择经过详尽记录的销毁流程，包括设备照片和按设备出具的销毁认证，具体取决于其安全需求。第三方销毁服务适合许多具有典型安全需求的组织，因为它们确保适当的销毁，而无需内部投资工具和时间来安全销毁介质和系统。

# 摘要

构建弹性基础设施是确保系统和服务可用性的关键部分。冗余系统、网络及其他基础设施和能力有助于提供这种弹性。同时，地理分散、电源保护，甚至技术和供应商的多样性等技术，在保持组织在线和运行方面可发挥关键作用。

存储弹性可能涉及`RAID`，了解常见的`RAID`级别及其含义对安全分析师很有用。备份（无论是到磁带、磁盘还是第三方存储服务）有助于确保在系统或驱动器发生故障时数据不丢失。你应该了解完全备份、差异备份和增量备份的区别。快照（复制某一时间点的系统状态）和镜像（用于复制完整系统）也被用作备份和克隆系统的方式。

您如何应对中断或问题以及如何从中恢复，可能意味着快速恢复在线与长时间离线之间的区别。

现代基础设施通常依赖非持久化系统，这些系统使用软件或镜像定义的原始版本来构建和扩展系统，并在不需要时将其关闭并销毁。最后已知的良好保存点和镜像也可用于恢复到事件或问题发生之前的时间点。

可扩展性可以是垂直的，即上线更大、更强大的系统或设备；也可以是水平的，即增加更多较小的系统。云和虚拟化环境的使用日益增加，意味着越来越多的基础设施被设计为利用水平可扩展性。水平可扩展的基础设施通常利用负载均衡器和其他工具将流量导向系统，从而允许升级、替换和移除可能存在问题的系统。

灾难恢复站点用于恢复运营，其中热站点已构建完毕并完全准备就绪，温站点等待数据和人员投入运营，冷站点提供电力和连接但需要付出巨大努力和部署技术才能上线。在任何恢复事件中，了解恢复顺序将有助于根据依赖关系和关键性，以合理的顺序将系统和服务恢复上线。

保持组织的物理安全也有助于保护它们。为了威慑潜在的恶意行为者同时保护组织，站点安全涉及使用工业伪装使设施不太可能成为目标，以及物理安全控制，如围栏、防撞柱、照明、工牌和入口访问系统、警报、灭火系统，甚至标识。即使是数据中心、机房和保险柜等区域也会接受额外的控制，以满足其更高的安全需求。

# 考试要点

## 冗余构建弹性

冗余系统、网络甚至数据中心是确保可用性的关键要素。冗余设计需要解决组织面临的风险和优先级，以确保在成本和能力之间做出最佳权衡。地理分散；多路径网络；负载均衡器；网卡组合；电源保护和冗余；`RAID`；备份；以及技术、系统和平台的多样性，都是构建和确保弹性的方法。

## 当故障发生时，响应和恢复至关重要

故障不可避免，因此您需要知道如何响应。非持久化和最后已知的良好配置允许您返回到受信任或之前的状态。可扩展性，无论是通过更多系统实现水平扩展，还是通过更强大的系统实现垂直扩展，都能提供更多资源来处理负载。水平可扩展性允许您添加和移除更多系统或服务，从而提供额外的灵活性。拥有灾难恢复站点，如热、温或冷站点，或冗余的云或托管位置，可以帮助确保您的组织能更快地恢复运营。拥有预先确定的恢复顺序可提供指导，说明基于依赖性或对组织的重要性，什么需要优先恢复上线。

## 物理安全控制是第一道防线

保护站点安全涉及使用工业伪装等技术，以及围栏、照明、警报、标识、防撞柱、访问控制门禁通道、摄像头和其他传感器等安全控制。通过使用锁、工牌和警卫确保只有获许可的人员才能进入，有助于防止未经授权的访问者。灭火和其他环境控制可使系统和设备免受自然灾害或人为灾害造成的风险。

## 数据生命周期的终结可能需要安全销毁

当设备或介质报废时，可能需要安全销毁以防止数据丢失。存在多种技术，包括焚烧、粉碎或制浆纸质介质，或粉碎、粉碎消磁设备和磁性介质。使用适当的解决方案将有助于防止系统或介质报废或出售时数据泄露。第三方执行这些服务，并可提供销毁收据和其他文档，以确保销毁工作妥善完成，而无需组织自行维护该能力。
