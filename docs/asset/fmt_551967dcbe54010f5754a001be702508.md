
其中 $\widehat{\sigma}_{\text{ML}}^2$ 表示方差的最大似然估计（问题 3.22）。因此，参数 $b$ 的物理意义在于它量化了我们对未知方差的先验估计。这也与第 3.7 节所述内容一致；如果高斯分布中未知参数是方差，则 $\widehat{\sigma}_{\text{ML}}^2$ 是方差的充分统计量。可以很容易地证明，如果 $\sigma^2$ 已知，关于 $\mu$ 的共轭先验是高斯分布（问题 12.10）。

### 12.8.1 指数族与最大熵方法

除了与指数族相关的计算优势外，还有另一个理由证明其广泛流行的合理性。假设我们得到一组观测值，$x_n \in \mathcal{A}_x \subseteq \mathbb{R}$，$n = 1, 2, \dots, N$，这些观测值取自一个函数形式未知的分布。我们的目标是估计未知的概率密度函数（PDF）；然而，我们要求它满足某些经验期望，这些期望由可用的观测值计算得出，即

$$
\widehat{\mu}_i := \frac{1}{N}\sum_{n=1}^{N}u_i(x_n), \quad i \in \mathcal{I},
$$

(12.89)

其中 $\mathcal{I}$ 是一个索引集，而 $u_i: \mathcal{A}[x] \mapsto \mathbb{R}, i \in \mathcal{I}$ 是特定函数。例如，若 $u_i(x) = x$，则 $\hat{\mu}_i$ 即为样本均值。在这种情况下，为概率密度函数（PDF）采用参数函数形式并尝试针对未知参数进行优化（例如通过极大似然法）是不明智的；因为通常我们无法知道所采用的函数形式是否能与现有的经验期望相符合。

最大熵（ME）方法（有时称为原则）提供了一种可能的途径，用于在可用约束条件集的限制下估计未知的概率密度函数 [21]。根据该方法，待最大化的代价函数是与概率密度函数相关联的*熵*（第 2.5.2 节），即

$$
H := -\int_{\mathcal{A}[x]} p(x) \ln p(x) \, dx. \tag{12.90}
$$

根据香农信息论，众所周知，熵是不确定性或随机性的度量。在可用约束条件下，针对 $p(x)$ 最大化熵将得到最随机的概率密度函数。从另一个角度来看，这种过程保证了未知概率密度函数的估计仅采用最少的假设，即仅采用可用的约束条件集。就我们的情况而言，最大熵估计方法表述如下：

针对 $p(x)$ 最大化 $-\int_{\mathcal{A}[x]} p(x) \ln p(x) dx$，约束条件为 $\mathbb{E}[u_i(x)] = \int_{\mathcal{A}[x]} p(x) u_i(x) dx, i \in \mathcal{I}. \tag{12.91}$

除了上述约束条件集之外，还必须考虑一个显而易见的约束，以保证 $p(x)$ 的积分等于 1，即

$$
\int_{\mathcal{A}[x]} p(x) \, dx = 1.
$$

对于离散变量的情况，所涉及的积分将被求和运算所取代。求解 (12.91) 中的优化任务，结果表明（问题 12.15）

## 12.9 组合学习模型：概率视角

在第 7.9 节中介绍了通过利用不同学习器的个体特性来组合它们以提升整体性能的思想。我们现在通过概率论证重返这一任务。从教学角度来看，本节也很有用，能让读者进一步熟悉 EM 算法的使用。

我们的出发点是数据分布在输入空间的不同区域。因此，为每个区域拟合不同的学习模型似乎是合理的。这一想法让人联想到第 7 章中讨论的决策树。在那里，执行了输入空间的轴对齐（线性）分割。在这里，输入空间将通过超平面（也可推广到更一般的超曲面）以一般位置进行分割。此外，主要区别在于在 CART 中，分割属于硬性决策规则。在当前设定中，我们采取更宽松的态度，将考虑软性概率分割，这是以牺牲一些可解释性为代价的。

ME 估计呈指数形式：

```
p̂(x) = C exp( ∑_{i ∈ I} θ_i u_i(x) )
```

参数 `θ[i]`，`i ∈ I`，是优化任务中使用的拉格朗日乘子，其值由约束条件决定，并用可用的经验期望 `μ̂[i]`，`i ∈ I` 来表示。如果除了显而易见的（归一化）约束外不使用其他约束，且 `A[x] = [a, b] ⊂ R`，则得到的 PDF 是均匀分布，`p(x) = C`；确实，这是最随机的一个，因为它对任何特定值区间都不表现出偏好。如果使用两个约束，使得 `u1 = x` 和 `u2 = x²`，则得到的 PDF 是高斯分布，因为指数呈二次形式（见本章附录）。换句话说，高斯分布是在与均值和方差相关的两个约束条件下最随机的 PDF。注意，尽管我们专注于实值随机变量，但一切都可平凡地推广到向量值情况。关于 ME 方法和问题的替代观点的有趣讨论见文献 [42]。

本节组合方案的基本概念如图 12.12 所示。通常将这 $K$ 个学习器中的每一个称为*专家*。我们建模方法的核心在于所谓的*门控*函数 `gk`，*k* = 1, 2, …, *K*，它们控制每个专家对最终决策的重要性。这些函数在训练阶段与参数集 `θ[k]`、*k* = 1, 2, …, *K* 一起被最优调整，后者分别对专家进行参数化。在一般情况下，门控函数是输入变量的函数。我们将这种建模类型称为*专家混合模型*。相比之下，这些是参数而非函数的特殊组合类型，即 `gk = g[k]`，将被称为*学习器混合*。我们将重点关注后一种情况，并在回归和分类任务的背景下，使用线性模型来介绍该方法。

### 12.9.1 线性回归模型的混合

我们的出发点是每个模型都是一个线性回归模型 `θ[k]`，*k* = 1, 2, …, *K*，其中假设输入空间的维度已增加一以容纳截距项，并且输出变量根据我们熟悉的方程与输入相关联：

`y[k] = θ[k]^(T)x + η`

其中 `η` 是一个方差为 `σ[η]²` 的白高斯噪声源，并假设对所有模型通用；推广到更一般的情况可以直接获得。对于广义线性模型，`x` 可以简单地用非线性映射 `ϕ(x)` 替换。我们假设门控参数被解释为概率，并将其表示为 `g[k] = P[k]`。

在上述假设下，采用了以下混合模型：

```
p(y; Ξ, P) = Σ_{k = 1}^{K} P_k N( y | θ_k^T x, σ_η² )
```

其中

**Ξ** = [**θ**₁ᵀ, …, **θ**ₖᵀ, *σ*²_η]ᵀ，**P** = [*P*₁, …, *P*ₖ]ᵀ

是使用训练点集合 (*y*ₙ, **x**ₙ)，*n* = 1, 2, …, *N* 在训练阶段待估计的未知参数向量。由于每个模型被设计为“负责”空间中的一个区域，因此相应的参数应使用来自相应区域的输入样本进行训练；但请注意，这些区域是未知的，也必须在训练期间学习。这类似于高斯混合建模的任务；回想一下，在训练期间，每个观测值都通过隐变量的使用与特定的混合成分相关联。在当前设置中，每个输入样本将与特定的学习器相关联。因此，我们当前的任务与第 12.6 节中处理的任务是近亲，我们可以遵循类似的步骤来推导结果。然而，为了多样化，将采取一条略有不同的路径。这稍后也将被证明是有用的，同时也更适合当前公式所使用的术语。我们将引入一组新的*潜在*变量 *z*ₙₖ ∈ {0, 1}，*k* = 1, 2, …, *K*，*n* = 1, 2, …, *N*，而不是使用高斯混合建模中的索引 *k*ₙ。如果 *z*ₙₖ = 1，则样本 **x**ₙ 由专家 *k* 处理。同时，对于每个 *n*，*z*ₙₖ 仅对单个 *k* 值等于 1，其余均为 0。我们现在可以写出*完整*训练数据集的似然函数。⁽⁸⁹⁾

```
p(y, Z; Ξ, P) = ∏_{n=1}^{N} ∏_{k=1}^{K} ( P_k N( y_n | θ_k^T x_n, σ_η² ) )^{z_nk}
```

其中 `y` 为输出观测值向量，`Z` 为相应潜变量矩阵。对数似然可直接写为

$$
\ln p(\mathbf{y},Z;\mathbf{\Xi},\mathbf{P}) = \sum\limits_{n = 1}^{N}\sum\limits_{k = 1}^{K}z_{nk}\ln\left( P_{k}\mathcal{N}\left( y_{n}|\mathbf{\theta}_{k}^{T}\mathbf{x}_{n},\sigma_{\eta}^{2} \right) \right).
$$
