
是一个 `d` 维特征空间，`n` 是样本总数。我们考虑一个对抗学习问题，其中对手修改恶意数据以逃避检测，从而达到其预谋目标。对手有自由仅通过向 `x[i] | y[i] = 1` 添加非零位移向量 `δi`，沿任意方向移动恶意数据（`y[i] = 1`）。也就是说，目标是学习一个假设 `H`，使其能抵御通过添加非零位移向量 `δ` 来修改恶意数据的对抗攻击。例如，在垃圾邮件过滤中，对手可能向垃圾邮件添加正常词汇以击败垃圾邮件过滤器。另一方面，对手将无法修改合法邮件。

我们不对对手对学习系统的了解做具体假设。相反，我们仅假设修改恶意数据存在权衡或成本。例如，对手常采用的一种实用策略是，在特征空间中将恶意数据移动到尽可能接近良性数据频繁出现的位置。然而，对手只能在不完全丧失恶意数据效用的前提下修改其位置。如果对手在特征空间中将数据点移离其自身类别太远，可能不得不牺牲原始数据点的大量恶意效用。例如，在信用卡欺诈检测问题中，攻击者可能选择用被盗信用卡消费“合适”的金额来模仿合法购买。这样做会让攻击者损失一些潜在利润。

### 10.4.2 对抗攻击模型

我们提出两种攻击模型：*自由范围* 和 *受限*，每种模型都对对手已知信息的程度做出了简单且现实的假设。这两种模型在以下方面的含义不同：(i) 对手对良性数据的了解程度，以及 (ii) 因修改恶意数据而导致的效用损失。*自由范围* 攻击模型假设对手有自由将数据移动到特征空间中的任意位置。*受限* 攻击模型是一种更保守的攻击模型。该模型基于这样的直觉构建：对手不愿让数据点在特征空间中偏离其原始位置太远。原因是较大的位移往往意味着恶意效用的损失。

#### 10.4.2.1 自由范围攻击

在此模型中，对手可将恶意数据移动到域中的任意位置。对手所需的唯一知识是每个特征的有效取值范围。

设 `x[j]^(max)` 和 `x[j]^(min)` 分别为数据点 `x[i]` 的第 `j` 个特征——`x[ij]`——所能取得的最大值和最小值。就所有实际目的而言，我们假设 `x[j]^(max)` 和 `x[j]^(min)` 都是有界的。例如，对于高斯分布，它们可设为 0.01 和 0.99 分位数。由此产生的范围将覆盖大多数数据点并丢弃少数极端值。攻击随后被限制为以下形式：

`Cf − x[ij]) ≤ δ[ij] ≤ Cf − x[ij]), ∀j ∈ [1, d]`

其中 `C[f] ∈ [0,1]` 控制攻击的激进程度。`C[f] = 0` 表示无攻击，而 `C[f] = 1` 对应允许数据移动范围最宽的最激进攻击。更正式地，自由范围攻击模型可定义如下：

```
arg min_{w,b,ξ_i,t_i,u_i,v_i} 1/2 ||w||² + C Σ_i ξ_i
s.t. ξ_i ≥ 0
     ξ_i ≥ 1 - y_i · (w · x_i + b) + t_i
     t_i ≥ Σ_j C_f (v_ij (x_j^max - x_ij) - u_ij (x_j^min - x_ij))
     u_i - v_i = 1/2 (1 + y_i) w
     u_i ≥ 0
     v_i ≥ 0
```

此攻击模型的巨大优势在于，就数据修改而言，它足够通用以涵盖所有可能的攻击场景。当与学习模型配对时，该组合将针对最严重的攻击产生良好性能。然而，当存在轻微攻击时，学习模型会变得过于“多疑”，其性能也会相应下降。接下来，我们提出一种更现实的攻击模型，其中显著的数据篡改会受到惩罚。

#### 10.4.2.2 受限攻击

在此模型中，对手可将恶意数据移动得更接近目标点。设 `x[i]` 为对手旨在篡改的恶意数据点。设 `x[i]^(t)`（一个 `d` 维向量）为对手希望将 `x[i]` 推向的潜在目标。对手根据其对良性数据分布的估计来选择 `x[i]^(t)`。理想情况下，对手会为每个 `x[i]` 优化 `x[i]^(t)`，以最小化篡改成本并最大化可达成的目标。最优选择 `x[i]^(t)` 是理想的，但通常需要大量关于特征空间的知识，有时还需要了解学习算法的内部运作 [DALV2004]。更现实的是，对手可将 `x[i]^(t)` 设为良性数据的估计质心、从观测到的良性数据中采样的数据点，或从估计的良性数据分布生成的人工数据点。请注意，若对手对良性数据知之甚少，`x^(t)` 可能是个粗略猜测；若对手知晓训练数据的确切构成，则可能是非常准确的。

在大多数情况下，对手无法按意愿将 `x[i]` 改为 `x[i]^(t)`，因为 `x[i]` 可能会失去太多恶意效用。因此，对于 `d` 维特征空间中的每个属性 `j`，我们假设对手添加

`δ[ij] to x[ij]`

其中

`|δ[ij]| ≤ |x[ij]^(t) − x[ij]|, ∀ j ∈ d`

此外，我们对属性 `j` 的位移量设定上界如下：

`0 ≤ (x_ij^t - x_ij) δ_ij ≤ (1 - C_δ |x_ij^t - x_ij| / (|x_ij| + |x_ij^t|)) (x_ij^t - x_ij)²`

其中 `C[δ] ∈ [0, 1]` 为常数，建模因移动 `δ[ij]` 导致的恶意效用损失。此攻击模型基于 `x[ij]` 与 `x[ij]^(t)` 彼此相距多远，规定了对手可将 `x[ij]` 向 `x[ij]^(t)` 推多远。

项

`1 - C_δ |x_ij^t - x_ij| / (|x_ij| + |x_ij^t|)`

为 `δ[ij]` 最多可占 `x[ij]^(t) − x[ij]` 的百分比。当 `C[δ]` 固定时，`x[ij]` 越接近 `x[ij]^(t)`，按百分比计 `x[ij]` 被允许向 `x[ij]^(t)` 移动得越多。反之亦然。`x[ij]` 与 `x[ij]^(t)` 相距越远，`|δ[ij]|` 将越小。例如，当 `x[ij]` 和 `x[ij]^(t)` 位于原点两侧（即一正一负）时，若 `C[δ] = 1`，则不允许任何移动（即 `δ[ij] = 0`）。此模型在伪装数据恶意性与保留其恶意效用之间取得平衡。`(x[ij]^(t) − x[ij]), δ[ij] ≥ 0` 确保 `δ[ij]` 与 `x[ij]^(t) − x[ij]` 同向移动。`C[δ]` 与数据修改后的恶意效用损失相关。`C[δ]` 设定对手为突破决策边界愿牺牲多少恶意效用。较大的 `C[δ]` 意味着较小的恶意效用损失，而较小的 `C[δ]` 建模更大的恶意效用损失。因此，较大的 `C[δ]` 导致攻击较不激进，而较小的 `C[δ]` 导致攻击更激进。

如图 10.3(a)所示，此攻击模型对良好分离的数据效果极佳。当两类数据均靠近分离边界时（如图 10.3(b) 所示），略微改变属性值即足以将数据推过边界。请注意，两图中的 `X` 和 `Y` 轴均为特征（如图 10.2 所示）。此外，图 10.3(a) 中 `X` 和 `Y` 轴范围为 −0.2 至 0.2，而图 10.3(a) 中 `X` 轴范围为 −0.25 至 0.25，`Y` 轴范围为 −0.3 至 0.3（详见 [ZHOU2012]）。在这种情况下，即使 `C[δ]` 设为 1，上述模型的攻击与所需相比仍过于激进。我们虽可允许 `C[δ] > 1` 以进一步降低攻击激进度，但为求简洁和更直接的控制，我们改为直接对 `|x[ij]^(t) − x[ij]|` 应用折扣因子 `C[ξ]` 以建模攻击的严重程度：

`0 ≤ (x_ij^t - x_ij) δ_ij ≤ C_ξ (1 - |x_ij^t - x_ij| / (|x_ij| + |x_ij^t|)) (x_ij^t - x_ij)²`

其中 `C[ξ] ∈ [0, 1]`。较大的 `C[ξ]` 产生更大量的数据移动，较小的 `C[ξ]` 设定更窄的数据移动限制。结合这两种情况，*受限攻击*模型如下：

`0 ≤ (x_ij^t - x_ij) δ_ij ≤ C_ξ (1 - C_δ |x_ij^t - x_ij| / (|x_ij| + |x_ij^t|)) (x_ij^t - x_ij)².`

## 10.5 对抗性 SVM 学习

我们现在针对上一节讨论的两种攻击模型，分别提出一种对抗性支持向量机模型（AD-SVM）。我们假设对手无法修改无害数据。请注意，该假设可以放宽，以建模无害数据也可能被篡改的情况。

### 10.5.1 针对自由范围攻击模型的 AD-SVM

我们首先考虑自由范围攻击模型。合页损失模型如下：

```
h(w, b, x_i) = {
    max_δ_i ⌊1 - (w · (x_i + δ_i) + b)⌋ +   if y_i = 1
    ⌊1 + (w · x_i + b)⌋ +                   if y_i = -1
}
s.t.    δ_i ≺ C_f (x^max - x_i)
        δ_i ≻ C_f (x^min - x_i)
```

其中 `δ_i` 是 `x_i` 的位移向量，`≺`、`≻` 表示分量级不等式。

遵循标准 SVM 风险公式，我们得到：

```
arg min_{w,b}  Σ_{i|y_i=1} max_δ_i ⌊1 - (w · (x_i + δ_i) + b)⌋ +
               Σ_{i|y_i=-1} ⌊1 + (w · x_i + b)⌋ +
               μ ||w||²
```

合并正负实例的情况，这等价于：

```
arg min_{w,b}  Σ_i max_δ_i ⌊1 - y_i(w · x_i + b) - ½(1 + y_i)w · δ_i⌋ +
               μ ||w||²
```

请注意，当选择 `δ_i` 以最小化其对间隔的贡献时，即可获得 `x_i` 的最坏情况合页损失，即：

```
f_i = min_δ_i ½(1 + y_i)w · δ_i
s.t.    δ_i ≺ C_f (x^max - x_i)
        δ_i ≻ C_f (x^min - x_i)
```

其中 `δ_i` 是 `x_i` 的位移向量，`≺`、`≻` 表示分量级不等式。

这是一个关于 `w` 和 `δ_i` 的不相交双线性问题。在这里，我们关心的是在给定 `w` 的情况下，发现 `δ_i` 的最优赋值。我们可以将双线性问题归约为关于 `u_i ∈ ℝ^d`、`v_i ∈ ℝ^d` 的以下非对称对偶问题，其中 `d` 是特征空间的维度：

```
g_i = max - Σ_j C_f (v_ij (x_j^max - x_ij) - u_ij (x_j^min - x_ij))
或
g_i = min Σ_j C_f (v_ij (x_j^max - x_ij) - u_ij (x_j^min - x_ij))
s.t.    (u_i - v_i) = ½(1 + y_i)w
        u_i ≻ 0
        v_i ≻ 0
s.t.    (u_i - v_i) = 1(1 + y_i)w
```

SVM 风险最小化问题可重写如下：

```
arg min_{w,b,t_i,u_i,v_i}  ½||w||² + C Σ_i ⌊1 - y_i · (w · x_i + b) + t_i⌋ +
s.t.    t_i ≥ Σ_j C_f (v_ij (x_j^max - x_ij) - u_ij (x_j^min - x_ij))
        u_i - v_i = ½(1 + y_i)w
        u_i ≻ 0
        v_i ≻ 0
```

通过添加松弛变量和线性约束以消除合页损失的非可微性，我们可以将问题重写如下：

```
arg min_{w,b,ξ_i,t_i,u_i,v_i}  ½||w||² + C Σ_i ξ_i
s.t.    ξ_i ≥ 0
        ξ_i ≥ 1 - y_i · (w · x_i + b) + t_i
        t_i ≥ Σ_j C_f (v_ij (x_j^max - x_ij) - u_ij (x_j^min - x_ij))
        u_i - v_i = ½(1 + y_i)w
        u_i ≻ 0
        v_i ≻ 0
```

### 10.5.2 针对受限攻击模型的 AD-SVM

对于受限攻击模型，我们修改合页损失模型，并遵循相同步骤求解：

```
h(w, b, x_i) = {
    max_δ_i ⌊1 - (w · (x_i + δ_i) + b)⌋ +   if y_i = 1
    ⌊1 + (w · x_i + b)⌋ +                   if y_i = -1
}
s.t.
(x_i^t - x_i) ∘ δ_i ≺ C_ξ (1 - C_δ |x_i^t - x_i| / (|x_i| + x_i^t)) ∘ (x_i^t - x_i)^∘2
(x_i^t - x_i) ∘ δ_i ≻ 0
```

其中 `δ_i` 表示对 `x_i` 的修改，`≺` 为分量级不等式，`∘` 表示分量级运算。

通过求解以下最小化问题，可获得最坏情况合页损失：

```
f_i = min_δ_i ½(1 + y_i)w · δ_i
s.t.    (x_i^t - x_i) ∘ δ_i ≺ C_ξ (1 - C_δ |x_i^t - x_i| / (|x_i| + |x_i^t|)) ∘ (x_i^t - x_i)^∘2
        (x_i^t - x_i) ∘ δ_i ≻ 0
```

我们将双线性问题归约为关于 `u[i]` ∈ ℝ^(`d`)、`v[i]` ∈ ℝ^(`d`) 的以下非对称对偶问题，其中 `d` 是特征空间的维度。

$$

\begin{array}{l}

g_{i} = \max -\sum_{j}{e_{ij}u_{ij}} \\

g_{i} = \min \sum_{j}{e_{ij}u_{ij}} \\

s.t.\quad (- u_{i} + v_{i}) \circ (x_{i}^{t} - x_{i}) = \frac{1}{2}({1 + y_{i}})w \\

\quad u_{i} \succ 0 \\

\quad v_{i} \succ 0

\end{array}

$$

SVM 风险最小化问题可重写如下：

$$

\underset{}{\begin{array}{l}

\underset{w,b,t_{i},u_{i},v_{i}}{\text{arg min}}\quad\frac{1}{2}\left\| w \right\|^{2}+C\sum_{i}\left\lfloor 1-y_{i}\cdot\left( w\cdot x_{i}+b \right)+t_{i} \right\rfloor_{+} \\

s.t.\quad t_{i}\geq\sum_{j}e_{ij}u_{ij} \\

\quad\left. (-u_{i}+v_{i} \right)\circ\left. (x_{i}^{t}-x_{i} \right)=\frac{1}{2}{(1+y_{i})}w \\

\quad u_{i} \succ 0 \\

\quad v_{i} \succ 0

\end{array}}

$$

在消除合页损失的非可微性后，我们可以将问题重写如下：

$$

\begin{array}{l}

\underset{w,b,\xi_{i},t_{i},u_{i},v_{i}}{\text{arg min}}\quad\frac{1}{2}\left\| w \right\|^{2} + C\sum_{i}\xi_{i} \\

s.t.\quad\xi_{i} \geq 0 \\

\quad\xi_{i} \geq 1 - y_{i} \cdot \left( {w \cdot x_{i} + b} \right) + t_{i} \\

\quad t_{i} \geq \sum_{j}{e_{ij}u_{ij}} \\

\quad\left( {- u_{i} + v_{i}} \right) \circ \left( {x_{i}^{t} - x_{i}} \right) = \frac{1}{2}{({1 + y_{i}})}w \\

\quad u_{i} \succ 0 \\

\quad v_{i} \succ 0

\end{array}

$$

## 10.6 实验

### 10.6.1 我们的方法

我们在人工数据集和真实数据集上测试 AD-SVM 模型。在实验中，我们随着攻击严重程度的增加，考察 AD-SVM 模型的鲁棒性。在针对受限攻击的 AD-SVM 模型中，我们令 `x[i]^(t)` 为良性数据的质心。我们还尝试将 `x[i]^(t)` 设为训练集或测试集中随机选取的良性数据点，结果相似。由于篇幅限制，我们不报告后者的结果。

实验中使用的测试数据上的攻击通过以下模型进行模拟：

`δ[ij] = fattack`

其中 `x[i]^(_)` 是从测试集中随机选取的一个良性数据点，`f[attack] > 0` 设定了对手将测试数据移向目标良性数据点的限度。通过控制 `f[attack]` 的值，我们可以在模拟中规定攻击的严重程度。测试数据上的实际攻击特意设计为不匹配 AD-SVM 中的攻击模型，以免结果产生偏差。对于 AD-SVM 所考虑的攻击模型中的每个参数 `C[f]`、`C[δ]` 和 `C[ξ]`，我们随着 `f[attack]` 的增加尝试了不同的值。这使我们能够在没有攻击以及攻击比模型预期严重得多的所有情况下，测试我们的 AD-SVM 模型的鲁棒性。我们将我们的 AD-SVM 模型与标准 SVM 和单类 SVM 模型进行比较。我们使用 `CVX` 实现了 AD-SVM 算法——一个用于指定和求解凸规划的包 [GRAN2011]。使用 SVM 和单类 SVM 的实验是用 `Weka` 实现的 [HALL2000]。

### 10.6.2 人工数据集实验
