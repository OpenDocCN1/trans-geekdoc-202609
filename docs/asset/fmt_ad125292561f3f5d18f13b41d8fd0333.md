## 15.2 基本概念

### 15.2.1 球形中性理论集 (SPHERICAL NEUTROSPHIC SET)

首先，在 `$\mathbb{X}$` 上计算为 `A = {(A_r(p), A_i(p), A_f(p)) : p in X}` 的 SNS 满足以下属性：

- (i) `A_r(p), A_i(p), A_f(p) in [0,1]`
- (ii) `0 <= A_r(p) + A_i(p) + A_f(p) <= 1`
- (iii) `0 <= A_r(p)^2 + A_i(p)^2 + A_f(p)^2 <= 1`，对于所有 `p in $\mathbb{X}$`

`$\mathbb{X}$` 上的 SNS 族记为 `SPH_N_S($\mathbb{X}$)`。

### 15.2.2 SNS 的运算

设 `$\mathcal{M}$` 和 `$\mathcal{L}$` 是 `$\mathbb{X}$` 上任意两个 `SPH_N_S`。那么

- (i) `$\mathcal{M}^c = {\mathcal{M}(p), 1-\mathcal{M}(p), \mathcal{M}(p) : p in $\mathbb{X}$}` 是 `$\mathcal{M}$` 的补集
- (ii) `$\mathcal{M}\Pi\mathcal{L} = {<$\mathcal{M}(p) \wedge \mathcal{L}(p), \mathcal{M}(p) \wedge \mathcal{L}(p), \mathcal{M}(p) \vee \mathcal{L}(p)>}$`
- (iii) `$\mathcal{M}\Pi\mathcal{L} = {<$\mathcal{M}(p) \vee \mathcal{L}(p), \mathcal{M}(p) \vee \mathcal{L}(p), \mathcal{M}(p) \wedge \mathcal{L}(p)>}$`
- (iv) `O_{SNS} = {(0,0,1) : p in $\mathbb{X}$}` 是 `$\mathbb{X}$` 上的空 `SPH_N_S`
- (v) `I_{SNS} = {(1,0,0) : p in $\mathbb{X}$}` 是 `$\mathbb{X}$` 上的全 `SPH_N_S`

### 15.2.3 SNS 之间的相似性量

两个 `SPH_N_S_s` 与 `$\mathcal{H}$` 之间的相似性定义为 `$\varrho(\mathcal{G}, \mathcal{H}) = (\varrho_w(\mathcal{G}, \mathcal{H}), \varrho_i(\mathcal{G}, \mathcal{H}), \varrho_f(\mathcal{G}, \mathcal{H}))$`，其中 `$\varrho: SPH_N_S(\mathbb{X}) \times SPH_N_S(\mathbb{X}) \to [0,1]$` 满足以下属性：

- (i) `$\varrho(\mathcal{G}, \mathcal{H}) = \varrho(B, A)$`
- (ii) 对于所有 `$\mathcal{G}, \mathcal{H} in SPH_N_S(\mathbb{X})$`，若 `A=B` 则 `$\varrho(\mathcal{G}, \mathcal{H}) = 1_{SNS}$`
- (iii) `$\varrho_w(\mathcal{G}, \mathcal{H}) >= 0$` 且 `$\varrho_i(\mathcal{G}, \mathcal{H}) >= 0$`
- (iv) 如果对于所有 `$\mathcal{G}, \mathcal{D} in SPH_N_S(\mathbb{X})$` 有 `$\mathcal{G} \subseteq \mathcal{D}$`，则 `$\varrho(\mathcal{G}, \mathcal{H}) >= \varrho(\mathcal{G}, \mathcal{D})$` 且 `$\varrho(\mathcal{H}, \mathcal{D}) >= \varrho(\mathcal{G}, \mathcal{D})$`

其中 `$\varrho_w(\mathcal{G}, \mathcal{H}), \varrho_i(\mathcal{G}, \mathcal{H})$` 和 `$\varrho_f(\mathcal{G}, \mathcal{H})$` 分别代表 `$\mathcal{G}$` 与 `$\mathcal{H}$` 之间的 `$\mathbb{T}, \mathbb{I}$` 和 `$\mathbb{F}$` 相似性程度。

## 使用球形中性相似性进行 MCDM 建模

### 15.2.4 三角函数相似性量

设 `$\mathcal{M}$` 和 `$\mathcal{L}$` 是 `$\mathbb{X}$` 上任意两个 `SPH_N_S`。那么三种正切、余弦和余切相似性量定义为：

- (i) `TAN_S($\mathcal{M}, \mathcal{L}$) = 1/n sum_{i=1}^{n} [tan(pi/2)|$\mathcal{M}_i(p_i) - \mathcal{L}_i(p_i)$| + |$\mathcal{M}_f(p_i) - \mathcal{L}_f(p_i)$| + |$\mathcal{M}_g(p_i) - \mathcal{L}_g(p_i)$|]`
- (ii) `COT_S($\mathcal{M}, \mathcal{L}$) = 1/n sum_{i=1}^{n} [cot(pi/4)|$\mathcal{M}_i(p_i) - \mathcal{L}_i(p_i)$| + |$\mathcal{M}_f(p_i) - \mathcal{L}_f(p_i)$| + |$\mathcal{M}_g(p_i) - \mathcal{L}_g(p_i)$|]`
- (iii) `COS_S($\mathcal{M}, \mathcal{L}$) = 1/n sum_{i=1}^{n} $\mathcal{M}_i(p_i) \cdot \mathcal{L}_i(p_i) + |$\mathcal{M}_f(p_i) \cdot \mathcal{L}_f(p_i)$| + |$\mathcal{M}_g(p_i) \cdot \mathcal{L}_g(p_i)$| / sqrt($\mathcal{M}_i(p_i)^2 + \mathcal{L}_i(p_i)^2$) \cdot sqrt($\mathcal{M}_f(p_i)^2 + \mathcal{L}_f(p_i)^2$)`
