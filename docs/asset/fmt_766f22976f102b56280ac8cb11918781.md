
在 `μ_i ∈ (0, 2)` 时收敛（在无限维空间中为弱收敛），需满足一些一般条件，并假设次梯度是有界的。证明略显技术性，感兴趣的读者可参考例如 [70,82] 获取。

毋庸赘述，除了前面讨论的主要方案外，还存在许多变体；相关综述请见 [82]。

### 8.10.3 凸优化的在线学习

第 5 章和第 6 章的重点是平方误差损失函数框架下的在线学习。引入在线学习的原因之一是赋予算法跟踪潜在统计特性随时间变化的潜力。另一个原因是在随机逼近理论的背景下，当代价函数涉及期望时，应对未知的统计特性。此外，当可用训练数据的数量和输入空间的维数变得非常大，超出了当今存储、处理和网络设备所能承受的负载时，在线算法就显得尤为重要。交换信息现在变得廉价，数据集已积累了海量数据。这使得批处理技术对于海量数据集的学习任务变得不切实际。一次处理一个数据点的在线算法现已成为不可或缺的算法工具。

回顾第 3.14 节，给定损失函数 `ℒ`，机器学习任务的最终目标是最小化期望损失/风险，在参数建模的背景下可写为

#### 经验风险最小化与随机近似

`J(θ) = 𝔼 ℒ(y, f[θ)] := 𝔼 [ℒ(θ, y, x)].`

![Equation](img/si368.png) (8.64)

相反，给定一组 `N` 个训练点，则最小化相应的经验风险函数，

$$J_{N}(\mathbf{\theta}) = \frac{1}{N}\sum\limits_{n = 1}^{N}\mathcal{L}(\mathbf{\theta}, y_{n}, \mathbf{x}_{n}).$$

![Equation](img/si369.png) (8.65)

在此背景下，次梯度方案将采取以下形式

$$\mathbf{\theta}^{(i)} = \mathbf{\theta}^{(i - 1)} - \frac{\mu_{i}}{N}\sum\limits_{n = 1}^{N}\mathcal{L}_{n}^{\prime}\left( \mathbf{\theta}^{(i - 1)} \right),$$

![Equation](img/si370.png)

其中为简化符号，我们使用了

`ℒ_n := ℒ(θ, y[n], x[n]).`

![Equation](img/si371.png) (8.66)

因此，在每次迭代中，必须计算 `N` 个次梯度值，对于较大的 `N` 值而言，这在计算上是繁琐的。一种解决方法是采用随机近似论证，如第 5 章所述，并得出相应的在线版本，

`θ[n] = θ[n − 1] − μ[n]ℒ[n]′(θ[n − 1]),`

![Equation](img/si372.png) (8.67)

现在迭代索引 `i` 与时间索引 `n` 重合。有两种不同的方式来看待公式 (8.68)。要么 `n` 取集合 `[1, 2, …, N]` 中的值并周期性循环直到收敛，要么让 `n` 无界增长。对于非常大的 `N` 值，后者非常自然，从现在起我们将专注于这种情况。此外，如果存在缓慢的时间变化，这种策略也能应对。请注意，在在线公式中，每个时间瞬间都涉及一个*不同的*损失函数，我们的任务变成了*渐近*最小化。此外，必须研究渐近*收敛性质*以及相应的*收敛条件*。很快，我们将介绍一种分析在线算法性能的强大工具，即*遗憾分析*。

对于第 8.10.2 节中讨论的每一种优化方案，我们都可以写出其在线版本。给定损失函数序列 `ℒ[n]`，`n = 1, 2…`，通用投影子梯度方案的在线版本变为

```
θ[n] = P_C(θ[n − 1] − μ[n]g[n]),  n = 1, 2, 3, …. (8.68)
```

在更一般的设定中，与约束相关的凸集也可以随时间变化；换句话说，我们可以写成 `C[n]`。例如，这种带有时变约束的方案已在稀疏感知学习背景下得到发展，其中使用加权 `ℓ[1]` 球代替了 `ℓ[1]` 球 [47]。这对加速算法收敛有着真正显著的效果（见第 10 章）。

#### AdaGrad 算法

另一个例子是所谓的*自适应梯度*（AdaGrad）算法 [38]。投影算子在更一般的背景下通过马氏距离定义，即

```
P_C^G(x) = min_{z ∈ C} (x - z)^T G (x - z),  ∀x ∈ ℝ^l. (8.69)
```

代替 `G`，使用所计算子梯度外积之和的平方根，即

```
G_n = ∑_{k=1}^n g_k g_k^T,
```

其中 `g[k] = ℒ[k]'(θ[k − 1])` 表示时刻 `k` 处的次梯度。此外，使用同一矩阵来加权梯度修正，该方案具有如下形式：

```
θ[n] = P_C(θ[n − 1] − μ[n]G[n]^(−1/2)g[n]).
```

使用（时变）加权矩阵考虑了早期迭代中观测到的数据几何特性，从而实现了更具信息量的基于梯度的学习。为了节省计算量，`G[n]` 的结构被设为对角形式。文献 [38] 讨论了不同的算法设置，并研究了该算法的收敛性质。该算法启发了许多当前深度学习中流行的版本，另请参阅第 18.4.2 节。

#### 示例 8.8：LMS 算法

假设

```
ℒ_n(θ) = 1/2 (y_n − θ^T x_n)²，
```

并设定 `C = ℝ^(l)` 和 `μ[n] = μ`。则公式 (8.69) 变为我们熟悉的 LMS 递推公式：

```
θ[n] = θ[n − 1] + μ(y[n] − θ[n − 1]^T x[n])x[n]，
```

其收敛性质已在第 5 章中讨论。

### 8.11 遗憾分析

在处理迭代学习算法时，主要的精力都集中在收敛性问题上；即算法收敛到何处、在何种条件下收敛，以及以多快的速度收敛到其稳态。第 5 章的很大一部分内容集中在 LMS 的收敛性质上。此外，在本章中，当我们讨论各种基于次梯度的算法时，也报告了收敛性质。

一般来说，分析在线算法的收敛性质往往是一项相当艰巨的任务，而经典方法不得不采用许多假设，有时这些假设相当强。典型的假设涉及数据的统计性质（例如，数据是独立同分布的，或者噪声是白噪声）。此外，可能还假设生成数据的真实模型是已知的，和/或算法已到达参数空间中接近极小值点的区域。

最近，一种替代方法论已被开发出来，它绕过了对上述假设的需求。该方法论围绕 `累积损失` 的概念展开，该概念已在第 5 章第 5.5.2 节中介绍。该方法称为 `遗憾分析`，其诞生归功于博弈论与学习理论之间相互作用的发展（参见，例如，[21]）。

#### 累积损失与遗憾分析

累积损失定义为：

$$

\mathcal{L}_{\text{cum}}(N) := \sum_{n=1}^{N} \mathcal{L}(y_n, \widehat{y}_n).

$$

令 $f$ 为一个**固定**预测器。则在线算法相对于 $f$ 的**遗憾**，当运行至时间瞬间 $N$ 时，定义为：

![Equation](img/fx029.jpg)(8.76)

“遗憾”这一名称源自博弈论，意指算法或学习者（机器学习术语）在回顾时，因未遵循固定预测器 $f$ 的预测而感到多么“后悔”。预测器 $f$ 也称为**假设**。此外，若 $f$ 从一组函数 $\mathcal{F}$ 中选取，该集合称为**假设类**。

在线算法运行 $N$ 个时间瞬间时，相对于函数族 $\mathcal{F}$ 的遗憾定义为：

$$

\text{Regret}_N(\mathcal{F}) := \max_{f \in \mathcal{F}} \text{Regret}_N(f).

$$

![Equation](img/si406.png)(8.77)

在遗憾分析背景下，目标变为设计一种在线学习规则，使得相对于最优固定预测器的遗憾较小；即学习者的遗憾应随迭代次数 $N$ **次线性**（慢于线性）增长。次线性增长保证了学习者遭受的**平均**损失与最优预测器的平均损失之差将渐近趋于零。

对于线性函数类，我们有：

$$

\widehat{y}[n] = \boldsymbol{\theta}[n-1]^{(T)}\boldsymbol{x}[n],

$$

![Equation](img/si407.png)

损失可写为：

$$

\mathcal{L}(y[n], \widehat{y}[n]) = \mathcal{L}(y[n], \boldsymbol{\theta}[n-1]^{(T)}\boldsymbol{x}[n]) := \mathcal{L}_n(\boldsymbol{\theta}[n-1]).

$$

![Equation](img/si408.png)

将公式 (8.77) 适配至上述符号，可得：

$$

\text{Regret}_N(\mathbf{h}) = \sum_{n=1}^{N} \mathcal{L}_n(\boldsymbol{\theta}_{n-1}) - \sum_{n=1}^{N} \mathcal{L}_n(\mathbf{h}).

$$

![Equation](img/si409.png)(8.78)

其中 `h ∈ C ⊆ ℝ^l` 是集合 `C` 中寻求解的一个*固定*参数向量。

在继续之前，值得注意的是累积损失是基于学习者所遭受的损失，针对 `y[n], x[n]`，使用的是估计值 `θ[n−1]`，后者是在包括时刻 `n−1` 在内的数据上训练得到的。数据对 `(y[n], x[n])` 未参与其训练。从这个角度来看，累积损失符合我们防止过拟合的愿望。

在遗憾分析框架中，遵循的路径是利用所采用损失函数的凸性，推导出遗憾的上界。我们将通过一个案例研究来演示该技术，即简单次梯度算法的在线版本。
