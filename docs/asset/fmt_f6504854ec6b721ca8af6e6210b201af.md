
此外，如果 `cov_f` 取决于 `x` 和 `x'` 之间距离的*大小*（即，`||x - x'||`），则该高斯过程称为*齐次*。从现在开始，我们将假设 `μ[x] = 0`。在进一步讨论之前，让我们建立另一个与第 11 章的联系。

### 13.12.1 协方差函数与核函数

对于任意 `N` 和*任意* `N` 个点的集合，`x[(1)], …, x[(N)]`，相应的协方差矩阵定义为

`Σ = E[f f^(T)]`，

其中

`f := [f(x[(1)]), …, f(x[(N)])]^(T)`，

其元素由下式给出

`[Σ][ij] = cov[f(x[(i)]), x[(j)])], i, j = 1, 2, …, N.`

因为 `Σ` 是半正定矩阵，这保证了协方差函数是一个*核*函数（第 11.5.1 节）。为了强调这一点，从现在开始我们将使用以下符号：

`cov_f = κ(x, x')`，

协方差矩阵变为相应的*核矩阵*，记为 `K`（第 11 章）。这种符号的改变将使与 RKHS（再生核希尔伯特空间）的联系显而易见。高斯过程中使用的一些典型核函数示例如下：

*   **线性核**：

    `κ(x, x') = x^(T) x'.`

    注意，该核不对应平稳过程。

*   **平方指数核或高斯核**：

    $$
    \kappa(\mathbf{x},\mathbf{x}^{\prime}) = \exp\left( - \frac{{\|\mathbf{x} - \mathbf{x}^{\prime}\|}^{2}}{2h^{2}} \right),
    $$

    其中 `h` 是决定过程*长度尺度*的参数。`h` 的值越大，距离 `d = ||x - x'||` 相隔的两点的“统计”相似性（更强的相关性）就越大。

*   **Ornstein–Uhlenbeck 核**：

    $$
    \kappa(\mathbf{x},\mathbf{x}^{\prime}) = \exp\left( - \frac{\|\mathbf{x} - \mathbf{x}^{\prime}\|}{h} \right).
    $$

*   **有理二次核**：

#### 13.12.1 协方差核

$$
\kappa(\mathbf{x},\mathbf{x}^{\prime}) = \left( 1 + \frac{{\|\mathbf{x} - \mathbf{x}^{\prime}\|}^{2}}{2\alpha h^{2}} \right)^{-\alpha},\quad\alpha > 0,h > 0
$$

其中 `α` 和 `h` 分别被称为*尺度混合*和*长度尺度*参数。

回顾第 2 章，随机过程首次在那里被介绍，平稳协方差函数/核的傅里叶变换是相应随机过程的功率谱；根据定义，过程的功率谱是在频域中的非负函数。这为构建随机过程的核提供了一种途径；即，取频域中正函数的逆傅里叶变换。此外，原则上，第 11.5.2 节中讨论的所有核构建规则，也都可以应用于构建协方差函数。例如，高斯过程的一种流行核选择是

$$
\kappa(\mathbf{x},\mathbf{x}^{\prime};\mathbf{\theta}) = \theta_{1}\exp\left( - \sum\limits_{m = 1}^{M}\frac{{(x_{i} - x_{i}^{\prime})}^{2}}{2h_{i}^{2}} \right) + \theta_{2},
$$

其中 `θ[1]`、`θ[2]` 是定义该过程的超参数。

文献 [94] 中引入了*谱混合*（SM）核的概念。这些核是通过对功率谱密度（即核的傅里叶变换）在频域中用高斯混合建模而导出的。然而，对任意平稳核的精确近似需要大量的混合成分。这增加了需要估计的超参数数量，并在优化任务中带来严重的计算挑战。在文献 [99] 和 [42] 中，高斯混合中涉及的平均频率和方差参数被适当地固定为网格中的预选值，优化仅针对混合展开中高斯成分的权重进行，从而产生了*网格谱混合*（GSM）核。文献 [81] 将 GSM 核扩展以处理多维数据。

### 13.12.2 回归

假设我们得到一组输入观测值集合 `X`，即 `X = {x_1, …, x_N}`。回顾第 12.2 节，贝叶斯回归任务的主要目标是获得两个概率密度函数（PDF），

`p(y|X)` 和 `p(y|x, y, X)`，

其中

`y = f + η`，`y := [y_1, …, y_N]^T`，

以及

`y = f(x) + η`，

且 `f` 定义于公式 (13.137) 中。这两个 PDF 中的第一个是输出变量的联合概率密度，这些变量由 `X` 中的输入点生成；相关的随机性源于 `f` 以及噪声 `η`。第二个 PDF 指的是在给定 `x` 的值和训练数据 `(y_n, x_n)`，`n = 1, 2, …, N` 的情况下，对 `y` 的值进行预测。正如我们在第 12.2 节中所做的那样，我们将省略 `X` 以简化符号。

假设 `f(·)` 为零均值高斯过程，则 `f` 服从零均值、协方差矩阵为 `K` 的联合高斯分布，该矩阵由协方差函数/核函数 `κ(·, ·)` 决定，即

`p(f) = N(f|0, K)`。

此外，设 `η` 为零均值、协方差矩阵为 `Σ_η`，且独立于 `f(·)`；在不失一般性的前提下，令 `Σ_η = σ_η² I`。因此，

`p(y|f) = N(y|f, σ_η² I)`。

然后，完全遵循第 12.2 节中相同的论证，我们得到

`p(y) = N(y|0, K + σ_η² I).` (13.139)

从两个独立高斯变量之和也是高斯分布这一事实，以及均值和协方差矩阵可直接从公式 (13.138) 获得这一事实来看，这也是显而易见的。

要获得 `p(y|x, y)`，我们可以使用公式 (13.139) 并递归地应用它。在此将可用观测值的数量 `N` 显式地引入符号中也会很有用，并写为

```
y_{N + 1} = [y; y_N], y_N := [y_1, ..., y_N]^T.
```

根据公式 (13.139)，`y_{N + 1}` 服从高斯分布

`p(y_{N + 1} | 0, Σ_{N + 1})`，

其中

`Σ_{N + 1} := K_{N + 1} + σ_η² I_{N + 1}.`

然后，根据乘法法则，我们有

```
p(y|y_N) = p(y_{N + 1}) / p(y_N).
``` (13.140)

然而，由于联合 PDF 是高斯分布，公式 (13.140) 中的条件分布也是高斯分布。通过对矩阵 `Σ_{N + 1}` 进行分块（参见第 12 章附录，公式 (12.134) 和 (12.133)），可以计算出相应的均值和方差。

$$
\Sigma_{N + 1} = \begin{bmatrix} {\kappa(\mathbf{x},\mathbf{x}) + \sigma_{\eta}^{2},} & {\mathbf{\kappa}^{T}(\mathbf{x})} \\ {\mathbf{\kappa}(\mathbf{x}),} & \Sigma_{N} \end{bmatrix},\quad\mathbf{\kappa}(\mathbf{x}): = {\lbrack\kappa(\mathbf{x},\mathbf{x}_{1}),\ldots,\kappa(\mathbf{x},\mathbf{x}_{N})\rbrack}^{T},
$$

即，

(13.141)

将公式 (13.141) 与公式 (11.27) 进行比较。考虑到 `Σ[N] = K[N] + σ_η² I`，对于适当选择的 `C` 和 `σ_η²`，`μ_y` 与核岭回归得到的 `ŷ` 相同。然而，现在我们也获得了关于结果估计量相应方差的信息。

此时，回顾第 12.2.3 节中参数建模的贝叶斯回归任务很有意思，并要记得对于零均值先验 `p(θ)`，公式 (12.20) 中得到的均值与岭回归提供的均值相同，前提是 `λ` 选择得当。

###### 超参数处理

正如我们已经陈述的，核函数可以用某些参数（设为 `θ`）来表示，而这些参数反过来又必须从数据中估计得出。处理此任务有多种方法。首先想到的是通过求梯度并令其为零，针对 `θ` 优化得到的参数化对数似然 `ln p(y; θ)`。另一种方法是假设参数的先验分布，并使用贝叶斯论证将它们积分掉。这种积分通常难以处理，必须使用近似技术，例如蒙特卡洛方法（第 14 章）。毋庸置疑，这两种技术都有各自的缺点。优化对数似然是一个非凸任务，通常无法保证全局最大值。另一方面，蒙特卡洛技术往往计算量大，需要许多迭代才能收敛。关于这些问题的更多内容见文献 [68]。

###### 计算考量

为了降低与 `Σ_N` 求逆相关的 `O(N³)` 计算负荷，已经提出了许多近似技术。一种可能的途径是*稀疏高斯过程*；在这些方法中，通过使用一组有限基函数的展开来近似完整的高斯过程模型。例如，通常使用集合 `κ(x, u_m)` 作为基，其中 `u_m`，`m = 1, 2, …, M ≪ N`，是输入样本的一个子集，称为*活跃集*。此类技术可将计算量降低到 `O(M²N)` 的量级（例如 [67]）。也提出了其他不要求活跃集必须是训练样本子集的替代方案（例如 [40,79]）。文献 [90] 提出了一种变分稀疏方法，旨在缓解增大活跃集规模时遇到的问题。

高斯过程方法的一种变体是赋予其遗忘过去样本的能力，以适应时变环境；该方法在文献 [63,92] 中作为第 11 章讨论的核 RLS 算法的替代方案被提出。其他变体则通过输出变量的变换，使高斯模型适用于更广泛的问题 [41,78]。

在文献[72]中，利用高斯过程与卡尔曼滤波之间的联系，通过引入随机微分方程获得了解，这使得复杂度对时间的依赖变为线性。

最后，文献[44]提供了相关技术的扩展综述。

### 13.12.3 分类

与回归任务相反，在噪声和所涉及随机过程均服从高斯假设的情况下，分类任务变得更为复杂。在第 13.7 节中，采用了公式(13.68)给出的参数形式的逻辑回归。在高斯过程的背景下，模型变为

$$
P(\omega_{1}|\mathbf{x}) = \frac{1}{1 + \exp\left( - f(\mathbf{x}) \right)} = \sigma\left( f(\mathbf{x}) \right),
$$

其中 `f(x)` 现在将被视为一个高斯随机过程，与核函数 `κ(⋅, ⋅)` 相关联。给定一组训练样本 `(y[n], x[n])`，`n = 1, 2, …, N`，`y[n] ∈ {0, 1}`，并遵循第 13.7 节中的相同论证，我们现在可以写出

$$
P(\mathbf{y}|\mathbf{f}) = \prod\limits_{n = 1}^{N}\sigma{(f_{n})}^{y_{n}}{(1 - \sigma(f_{n}))}^{1 - y_{n}},
$$

其中 `f[n] := f(x[n])`，且

`p(f) = N(f|0, K).`

请注意，`P(y|f)` 不再是高斯分布，且为获得 `P(y)` 和/或 `P(y|x, y)` 所需的积分无法进行解析计算。存在多种执行近似的方法。一种途径是求助于 `p(f(x)|y)` 的拉普拉斯近似（参见第 12.3 节）[93]。另一种是使用蒙特卡洛技术 [54]。文献 [20] 采用变分方法来获得 logistic sigmoid 函数的边界，并用高斯乘积来近似相应的乘积。文献 [58] 使用了期望传播方法。

关于高斯过程的进一步阅读材料，感兴趣的读者可参考经典文献 [68]。
