## 15.3.2 关于因果关系的一些提示

贝叶斯网络中有向链接的存在*并不*一定反映从父节点到子节点的因果关系。^(¹¹¹)

让我们回到示例 15.1。虽然 GNP 和教育质量相关，但不能说 GNP 是教育制度的原因。毫无疑问，原因是多方面的，例如政治制度、社会结构、经济制度、历史原因和传统，所有这些都需要考虑在内。事实上，示例中关联三个变量的图结构可以反转。我们可以反向收集数据；获得概率 `P(x₃ = UN)`、`P(x₃ = LP)`、`P(x₃ = HP)`，然后是条件概率 `P(x₂|x₃)`（例如 `P(x₂ = HE|x₃ = UN)`），最后是 `P(x₁|x₂)`（例如 `P(x₁ = HGP|x₂ = HE)`）。原则上，此类数据也可以从人群样本中收集。在这种情况下，生成的 BN 仍将包含三个节点，如图 15.4 所示，但箭头方向反转。这也是合理的，因为给定教育水平的情况下，某人来自富国或穷国的概率独立于其工作。此外，这两种模型对于任何联合事件都应产生相同的联合概率分布。因此，如果箭头方向表示因果关系，那么这一次将是教育制度对 GNP 具有因果关系。出于上述相同理由，这无法得到证实。话虽如此，这并不一定意味着因果关系在 BN 中不存在，或者了解它们不重要。相反，在许多情况下，在构建 BN 时，有充分的理由努力揭示潜在的因果关系。

让我们对此详细阐述一下，看看为什么利用任何潜在的因果关系会对我们有益。以图 15.5 中的 BN 为例，它关联疾病的有无与两项医学检查的结果。令 `x₁` 表示疾病的有无，`x₂`、`x₃` 表示两项检查可能产生的离散结果。

![Figure 15.5 Three possible graphs relating a disease, x1, to the results of two tests, x2,x3. (A) The dependencies in this graph comply with common sense. (B) This graph renders x2,x3 statistically independent, which is not reasonable. (C) Training this graph needs an extra probability value compared to that in (A).](img/gr005.jpg)

**图 15.5 关联疾病 `x₁` 与两项检查结果 `x₂`、`x₃` 的三种可能图。(A) 该图中的依赖关系符合常识。(B) 该图使 `x₂`、`x₃` 在统计上相互独立，这是不合理的。(C) 训练该图比 (A) 需要一个额外的概率值。**

图 15.5A 中的 BN 符合我们的常识推理，即 `x₁`（疾病）导致 `x₂` 和 `x₃`（检测）。然而，仅*简单地*查看可用概率是无法推断出这一点的。这是因为概率定律是*对称*的。即使 `x₁` 是原因，一旦 `P(x₁, x₂, x₃)` 和 `P(x₂)` 可用，我们仍然可以计算 `P(x₁|x₂)`，即：

```
P(x₁|x₂) = P(x₁,x₂)/P(x₂) = ∑_{x₃}P(x₁,x₂,x₃)/P(x₂).
```

之前，为了说明 `x₁` 导致 `x₂` 和 `x₃`，我们使用了一些*额外*的信息/知识，称之为常识推理。请注意，在这种情况下，训练需要三个概率值的知识，即 `P(x₁)`、`P(x₂|x₁)` 和 `P(x₃|x₁)`。现在让我们假设选择图 15.5B 中的图模型。这一次，忽略因果关系导致了错误的模型。该模型使 `x₂` 和 `x₃` 相互独立，这显然不可能。它们仅应在给定 `x₁` 的条件下*有条件*独立。让 `x₂` 和 `x₃` 保持为 `x₁` 的父节点的唯一合理方法是添加一条额外的链接，如图 15.5C 所示，这在两者之间建立了关系。然而，要训练这样一个网络，除了三个概率值 `P(x₂)`、`P(x₃)` 和 `P(x₁|x₂, x₃)` 之外，还需要知道一个额外概率的值，即 `P(x₃|x₂)`。因此，在构建 BN 时，了解任何潜在的因果方向总是有益的。此外，还有其他原因。例如，这可能与*干预*有关，干预是指改变变量状态以研究其对其他变量相应影响的动作；因为变化沿因果方向传播，只有当网络按因果层级构建时，这种研究才成为可能。例如，在生物学中，人们非常有兴趣了解哪些基因影响其他基因的激活水平，以及预测开启或关闭某些基因的效果。

因果性的概念并不容易，哲学家们为此争论了几个世纪。虽然我们这里绝无意涉足这一问题，但引用两位著名哲学家的观点颇具趣味。

根据大卫·休谟的观点，因果性不是现实世界的属性，而是心智的一个概念，帮助我们解释对世界的感知。休谟（1711–1776）是一位苏格兰哲学家，以其哲学经验主义和怀疑论而闻名。他最著名的著作是《人性论》，与理性主义哲学学派相反，他主张人性主要由欲望而非理性支配。

根据伯特兰·罗素的观点，因果律与物理定律无关，物理定律是对称的（回顾我们之前关于条件概率的陈述），并不指示因果关系。例如，牛顿万有引力定律可以用以下任意形式表示：

```
B = mg  or  g = B/m  or  m = B/g,
```

仅观察它们，无法推断出任何因果关系。伯特兰·罗素（1872–1970）是一位英国哲学家、数学家和逻辑学家。他被认为是分析哲学的奠基人之一。在与 A.N. 怀特海德合著的《数学原理》中，他们试图将数学建立在数理逻辑基础之上。他还是一位反战活动家和自由主义者。

前述挑衅性的论点受到朱迪亚·珀尔著作 [38] 的启发，我们提供这些论点是为了说服读者阅读此书；读者只会变得更明智。珀尔对该领域做出了多项重大贡献，并于 2011 年荣获图灵奖。

尽管仅凭物理定律或概率无法推断因果关系，但识别因果关系的方法已经被开发出来。一种方法是进行*受控*实验；可以改变一个变量的值，并研究该变化对另一个变量的影响。然而，这必须以受控方式进行，以确保所引起的效应不是由其他相关因素导致的。

除了实验之外，还做出了巨大努力，旨在从非实验证据中发现因果关系。在现代应用中，例如用于基因表达的微阵列测量或 fMRI 脑成像，涉及的变量数量轻易就能达到数千量级。对这类任务进行实验是不可能的。在 [38] 中，因果概念与所获得的可能 DAG 结构的极小性概念相关联。这种观点将因果性与奥卡姆剃刀原则联系起来。最近，有人尝试通过比较所有假设因果方向上变量给定其直接原因的条件分布，并选择最合理的一个来推断因果性。该方法建立在一些平滑性论据之上，这些论据支撑着给定原因时效应的条件分布，并将其与效应/原因的边缘分布进行比较 [43]。在 [24] 中，一个用于推断因果性的有趣替代方案建立在柯尔莫戈夫复杂性理论的论据之上；通过比较与相关分布关联的字符串的最短描述长度来验证因果性。有关更多信息，感兴趣的读者可参考例如 [42] 及其参考文献。

## 15.3.3 d-分离

一组随机变量之间的依赖性和独立性在理解其统计行为方面起着关键作用。此外，正如我们已经评论过的，它们可以被利用来大幅减轻求解推理任务的计算负荷。

根据 BN 结构 *G* 的定义和性质，我们知道某些独立性成立，并且可以通过父子链接直接观察到。现在提出的问题是：图的结构是否施加了额外的独立性，使其对任何在 *G* 上分解的联合概率分布都成立。揭示额外的独立性为设计者提供了更大的自由度，以更激进地处理计算复杂性问题。

我们将通过观察在节点 x 处可用的概率证据能否传播并影响我们对另一个节点 y 的确定性，来解决在网络中搜索条件独立性的任务。

### 串联或头尾相连

这种节点连接类型如图 15.6A 所示。x 上的证据将影响对 y 的确定性，进而影响对 z 的确定性。反方向（从 z 开始传播到 x）也成立。然而，如果 y 的状态已知，则 x 和 z 变为（条件）独立。在这种情况下，我们说 y *阻断* 了从 x 到 z 的路径，反之亦然。当节点的状态固定/已知时，我们称该节点为*实例化*。

![图 15.6 三种不同的连接类型：(A) 串联，(B) 发散，(C) 汇聚。](img/gr006.jpg)

**图 15.6 三种不同的连接类型：(A) 串联，(B) 发散，(C) 汇聚。**

### 发散或尾尾相连

在这种连接类型中，如图 15.6B 所示，证据可以从 y 传播到 x，从 y 传播到 z，也可以经由 y 从 x 传播到 z 和从 z 传播到 x，除非 y 被实例化。在后一种情况下，y *阻断* 了从 x 到 z 的路径，反之亦然。即，给定 y 的值，x 和 z 变得独立。例如，若 y 代表“流感”，x 代表“流鼻涕”，z 代表“打喷嚏”，如果我们不知道某人是否患流感，流鼻涕就是一种可以改变我们对其患流感确定性的证据；这进而改变我们对其打喷嚏的信念。然而，如果我们知道某人患了流感，看到流鼻涕就不会提供关于打喷嚏的额外信息。

### 汇聚或头头相连或 ν 结构

这种连接类型比前两种稍微微妙一些，如图 15.6C 所示。来自 x 的证据不传播到 z，因此无法改变我们对 z 的确定性。了解关于 x 的信息对 z 一无所知。例如，设 z 表示两个国家中的任意一个（如英国和希腊），x 表示“季节”，y 表示“多云天气”。显然，知道季节无法说明国家的情况。然而，掌握了一些关于多云天气 y 的证据后，知道是夏季会提供改变我们对国家确定性的信息。这符合我们的直觉。知道是夏季且天气多云*解释掉*了该国家是希腊的可能性。这就是我们有时将这种推理称为*解释掉*的原因。解释掉是一种称为*因果间推理* 的通用推理模式的实例，其中同一效应的不同原因可以相互作用；这是人类非常常见的推理模式。

对于这种特定的连接类型，通过 y 的*任一*后代提供的证据也能实现解释掉。图 15.7 通过一个例子说明了这种情况。掌握关于下雨的证据也将建立一条路径，使得关于季节（国家）x (z) 的证据改变我们对国家（季节）z (x) 的确定性。

![图 15.7 掌握关于天气多云或下雨的证据，在“季节”和“国家”节点之间建立了信息流动的路径。](img/gr007.jpg)

**图 15.7 掌握关于天气多云或下雨的证据，在“季节”和“国家”节点之间建立了信息流动的路径。**

总而言之，让我们强调这里的微妙之处。对于前两种情况，头尾相连和尾尾相连，如果节点 y 被实例化，即其状态被揭示给我们，则路径被阻断。然而，在头头相连的情况下，当概率证据在 y 或其*任一*后代处变得可用时，x 和 z 之间的路径会*“打开”*。

### 定义 15.3

设 *G* 为一 BN 结构，且 *x*[1], …, *x*[*k*] 构成一条节点链。设 *Z* 为 *观测* 变量的一个子集。若满足以下条件，则称链 *x*[1], …, *x*[*k*] 在给定集合 *Z* 的条件下是 *活跃的* ：

*   每当链中存在汇聚连接 *x*[*i* − 1] → *x*[*i*] ← *x*[*i* + 1] 时，则 *x*[*i*] 或其后代节点之一在 *Z* 中；
*   链中的任何其他节点均不在 *Z* 中。

换句话说，在一条活跃链中，概率证据可以从 *x*[1] 流向 *x*[*k*]，反之亦然，因为不存在能阻断此信息流的节点（连接）。

### 定义 15.4

设 *G* 为一 BN 结构，且 *X*、*Y*、*Z* 为 *G* 中三个互不相交的节点集合。若给定 *Z* 时，任意节点 *x* ∈ *X* 与 *y* ∈ *Y* 之间不存在活跃链，则称 *X* 和 *Y* 给定 *Z* 是 *d-分离* 的。若非 *d*-分离，则称它们是 *d*-连接 的。

换句话说，若两个变量 *x* 和 *y* 被第三个变量 *z* *d*-分离，则观测 *z* 的状态会阻断任何从 *x* 到 *y* 以及从 *y* 到 *x* 的证据传播。即，*d*-分离蕴含 *条件独立性*。此外，以下极其重要的定理也成立。

### 定理 15.3

*设* (*G*, *p*) *为一 BN。对于任意三个互不相交的节点子集* *X*、*Y*、*Z*，*每当 X 和 Y 给定 Z 是 d-分离时，对于每一对* (*x*, *y*) ∈ *X* × *Y*，*在 p 中 x 和 y 给定 Z 是条件独立的。*

该定理的证明见文献 [45]。换句话说，该定理保证了 *d*-分离在任意分解于 *G* 上的概率分布中均蕴含条件独立性。注意，遗憾的是，逆命题不成立。可能存在无法通过 *d*-分离识别的条件独立性（例如，习题 15.5）。然而，对于大多数实际应用，逆命题也成立。不满足该定理逆命题的分布数量微乎其微（见例如 [25]）。图中所有 *d*-分离的识别可通过多种高效算法实现（例如 [25, 32]）。

### 例 15.2

考虑图 15.8 的 DAG *G*，连接两个节点 *x*、*y*。显然这些节点非 *d*-分离且构成一条活跃链。考虑以下分解于 *G* 上的概率分布：

```
P(y = 0 | x = 0) = 0.2,  P(y = 1 | x = 0) = 0.8,
P(y = 0 | x = 1) = 0.2,  P(y = 1 | x = 1) = 0.8.
```

可以很容易地验证 `P(y|x) = P(y)`（独立于 `P(x = 1)` 和 `P(x = 0)` 的值），并且变量 x 和 y 是独立的；这无法通过观察 `d`-分离来预测。然而请注意，如果我们稍微扰动条件概率的值，那么所得到的分布将拥有与 `d`-分离所预测的同样多的独立性，即在本例中为零。事实上，这是一个更普遍的结果。如果我们有一个在图上分解的分布，该分布具有相应 `d`-分离无法预测的独立性，那么一个微小的扰动几乎总是会消除它们（例如，[25]）。

![Figure 15.8 This DAG involves no nodes that are d-separated.](img/gr008.jpg)
