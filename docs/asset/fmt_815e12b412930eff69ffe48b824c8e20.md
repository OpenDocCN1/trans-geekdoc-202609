
也许应该注意到，一些先进的权重变化公式能够反映“当前趋势”。例如，实现“动量”（momentum）是非常流行的：如果最后两次权重变化均为正值（或均为负值），那么增加权重变化步长是有意义的；相反，如果一个正变化之后是一个负变化（反之亦然），则应该减小步长以防止越界。

### 训练过度

多层感知器与多项式分类器共享一个不良特性。从理论上讲，它们能够模拟任何决策边界，这使得它们容易过拟合训练数据。读者记得，过拟合通常意味着对噪声训练样本进行完美分类，这不可避免会导致未来性能表现令人失望。

对于小型多层感知器，这个问题并不那么痛苦；它们不够灵活，无法过拟合。但随着隐藏神经元数量的增加，网络获得了灵活性，过拟合可能变成一个真正的问题。然而，正如我们在下一节中学到的，这并不意味着我们应该总是倾向于小型网络！

有一种简单的方法可以发现训练过程是否达到了“过拟合”阶段。如果训练集足够大，我们可以留一部分用于测试。在每个 epoch 之后，都会测量测试数据上的误差。

# 5.7 总结与历史评述

- 多层感知器的基本单元是`neuron`（神经元）。`neuron` 接受输入的加权和，并对该和进行传递函数处理。可以使用几种不同的传递函数。本章中选定的是由以下等式定义的 `sigmoid` 函数，其中 `†` 是输入的加权和：

```
f.† = 1 / (1 + e\-†)
```

通常，所有神经元都使用相同的传递函数。

- 本章描述的多层感知器的简单版本由一个输出层和一个隐藏层神经元组成。相邻层之间的神经元之间是全连接的；但同一层中的神经元之间没有连接。输入网络的示例通过前向传播到输出端，在原理上实现了以下函数：

```
yi = f(.X w¹/)f(.X w²/)xk//
```

这里，`w^(.1/)` 和 `w^(.2/)` 分别是输出神经元隐藏神经元的权重，`f` 是 `sigmoid` 函数。

- 多层感知器的训练通过名为`误差反向传播`（backpropagation of error）的技术完成。对于每个训练示例，该技术首先建立每个神经元对网络整体误差的责任，然后根据这些责任更新权重。

以下是责任的计算方法：
输出神经元：`ı(.1/) = yi.1 - yi`
隐藏神经元：`ı(.2/) = hj.1 - hj/ P ı(.1/)wij`

以下是权重的更新方法：

```
output layer: w^(.1/) = w^(.1/) + ı(.1/)hj

hidden layer: w^(.2/) = w^(.2/) + ı(.2/)xk
```

- 这里讨论了误差反向传播的某些方面。其中，最的是计算成本、局部极值的存在、自适应学习率以及如何确定隐藏层大小的问题。

- 另一种方案是径向基函数（`RBF`）网络。对于隐藏层神经元的传递函数，使用了 `gaussian` 函数。输出层神经元通常使用 `step function`（原理上是线性分类器），或者仅仅是输入的线性函数。

- 在 `RBF` 网络中，每个 `gaussian` 中心与一个训练示例对应。如果此类示例太多，可以进行随机选择。在这个简单集合中，`gaussian`的标准差被设置为 `a²`。

- RBF 网络中的输出层神经元可以通过感知器学习进行训练。只需要训练一层权重。

- 有时，支持向量机（`SVM`）的思想被应用于隐藏神经元的输出。所得工具随后被称为基于 RBF 的 SVM。

### 历史评述

神经网络的研究曾因 `Minsky` 和 `Papert` 提出的怀疑观点而受到著名的推迟。这些作者表达的悲观态度可能是 `Bryson` 和 `Ho` 的早期神经网络训练版本被很大程度上忽视的主要原因，`Werbos` 一次独立的成功尝试也很快遭遇了同样的命运。只有在 `Rumelhart` 和 `McClelland` 出版具有里程碑意义的著作后（该算法被独立地重新发明），人工神经网络领域才成为一门受尊敬的科学学科。多层感知器的逐渐增长是由 `Ash` 提出的。径向基函数的思想最早由 `Broomhead` 和 `Lowe` 在神经网络环境中提出。
