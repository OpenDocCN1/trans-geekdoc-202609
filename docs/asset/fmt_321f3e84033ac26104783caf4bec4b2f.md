## 2. 问题描述

为了更具体地说明该问题并有效展示本章所讨论方法的先进进展，我们概述了代表底层3D世界的动力学模型表述。我们还解释了如何从数据中学习该模型，以及如何使用动力学模型构建问题。

### 2.1. 动力学模型学习

目标是学习一个3D环境的动力学模型，用于预测当智能体应用特定动作时环境将如何发生变化。假设我们有一个通过与环境交互收集的数据集 $\mathcal{D} = (y_t, u_t)$。在这种情况下，$y_t$ 代表在时间 $t$ 获取的原始感知信息，本质上充当环境的（部分）观测。这些感知数据由高维视觉观测（例如 RGB 图像和深度图）组成，预计包含完成下游交互任务所需的必要信息。$u_t$ 表示在时间 $t$ 应用的相应动作。

接着，一个感知模型 $z_t = g(y_{t'}, u_{t'-1})$ 将从时间 $t'$ 的序列观测 $y_{t'}$ 到当前时间 $t$ 及其相应的动作 $u_{t'-1}$ 映射到时间 $t$ 的环境潜表示 $z_t$。必须再次强调，$z_t$ 的选择会影响整个系统的结构。我们必须考虑 $z_t$ 应该采取哪些特定形式，以及物体和环境应该在何种抽象层次上进行表示。表示应该包含关于底层环境规划和控制任务的足够信息。在本章中，我们讨论了各种方案，例如关键点、粒子和神经场。

一旦我们获得了场景表示 $z_t$，我们就学习由 $\theta$ 参数化的动力学模型 $f_\theta$，将其作为真实动力学的代理。该模型以表示 $z_t$ 和动作 $u_t$ 为输入，产生时间 $t+1$ 刻动作结果导致的新表示：

$z_{t+1} = f_\theta(z_t, u_t)$

为了优化模型以实现准确的未来预测，我们的目标是找到最小化这种仿真误差的参数 $\theta$，从而减少预测与实际表示 $z^*$ 之间的长期差异：

$\mathcal{L}(\theta) = \sum_t ||z_{t+1}^* - f_\theta(z_t, u_t)||_2^2$

为了获得更好的泛化性，我们应该仔细考虑如何表征底层物理世界的结构，以及我们应该使用哪类模型（例如，线性模型、卷积神经网络或图神经网络），特别是在建模由多种材料制成的物体的动力学时。此外，为了适应结构和参数不可直接观测的场景，我们需要考虑如何表征底层物理世界的结构，并以在线方式从数据进行建模。

### 2.2. 基于模型的规划

为了证明所学的模型的适用性，我们展示了如何有效地利用这些模型进行基于模型的规划。具体而言，使用相同的符号，我们的目标是最小化目标函数 $\sum_t c(y_t, u_t)$ 基于观测 $y_t$ 和动作 $u_t$：

```
z_t = g(y_{t'}, u_{t'-1})
z_{t+1} = f_\theta(z_t, u_t)
u_t = \pi(z_t)
```

问题定义包含了三个关键组件：将观测映射到表示 $z_t$ 的感知模块、预测系统演化的动力学模型，以及导出信号的控制模块。为了解决这个问题，我们需要利用学习到的表示和动力学模型，同时考虑有效性和效率之间的权衡。此外，在机器人上部署系统时，必须探索感知-控制循环并考虑到实际限制。解决这些问题的进展需要考虑整体系统设计。

## 3. 相关工作

### 3.1. 动态场景的2D表示

关于具身交互任务的像素学习的大量文献可以大致分为两类：预测整个图像空间动力学的$^{12,13,17,98}$，以及从2D观测预测低维潜状态动力学的$^{26,97}$。虽然图像空间方法比较通用，但在长程预测中往往会导致模糊。对于潜空间动力学，需要对潜状态 $z_t$ 正则化策略，以避免所有观测映射到一个常数向量。Wetter 等人⁹³ 和 Nerner 等人⁶采用了自动编码器架构，并通过重构损失正则化潜状态 $z_t$。Agrawal 等人¹¹通过同时训练正向和反向动力学来正则化潜空间，而 Yan 等人³⁷则在潜状态上使用对比损失。

Kulkarni 等人³⁵则考虑了以2D关键点形式存在的更具结构的潜空间。他们证明了冻结视觉模型并将关键点表示作为无模型强化学习（RL）算法的输入，可以提高在游戏上的性能。在这些方法中，我们在本章介绍的方法考虑了不同抽象层次的显式3D结构。这允许对底层动力学进行基于物理且可解释的建模，我们证明这种方法在建模长程场景演化和完成各种交互任务方面更为有效。

### 3.2. 动态场景的3D表示

为了使用具有3D结构的模型，可以利用体素网格作为神经场景表示⁵⁸,⁶⁹,⁷⁸,⁸⁹,¹⁰⁰，其他研究尝试从图像预测粒子集或网格⁴²,⁹²,⁹⁸，或使用自动编码器模型嵌入显式3D表示以学习作为底层3D场景表示的潜空间⁸²,⁹⁵。此外，Sitzmann 等人⁷⁹提出通过可微渲染器利用带姿态的2D图像学习3D形状和外观的隐式表示。

为了利用3D表示建模场景的动态变化，研究人员通过3D关键点³⁴或网格²²探索了物体级变形。场景级变形可以通过将输入坐标传输到具有隐式流场或时变编码的神经隐式表示来建模¹¹,³⁹,⁴⁶,⁵⁹,⁶³,⁶⁵,⁶⁷,⁸⁸,⁹⁶。然而，这些工作通常不考虑动作输入，往往仅拟合一条轨迹，无法处理不同的初始条件和外部动作输入。这种限制限制了它们在下游规划和控制任务中的用途。

在本章介绍的作品中，我们探索了将外部动作整合到学习动力学模型的方法。这种方法能够处理各种初始条件和输入动作，使其更适用于为具身智能体合成控制信号。

### 3.3. 基于物理的动力学建模

几十年来，基于物理的仿真方法在动态场景建模方面稳步发展。基于第一原理或物理的模型（如 Hogan 和 Rodriguez³⁰ 以及 Zhou 等⁹⁹ 所示）依赖于已物体模型并模拟它们的相互作用。为了将这些模型用于下游任务，研究人员建立了通过基于物理模拟器进行微分的技术，旨在为反向估计和优化提供解析梯度⁹,¹⁴,⁸⁴,⁸⁶。一些研究利用来自这些模拟器的解析梯度来解决控制问题，例如工具操作和工具使用规划⁸⁷。尽管取得了这些进展，能够为变形物体提供解析梯度的模拟器研究仍然较少。最近，Schenck 和 Fox⁷¹ 提出了 SPNets 以从基于位置的流体模拟器中提取梯度，Hu 等³¹ 开发了一种新的可微编程语言，专门用于为各种变形和动态场景构建高性能的可微模拟器。

然而，我们需要开发一种全面的、能够模拟日常生活中所有物体和相互作用的基于物理的模拟器。这些模型在泛化到新或未知物体方面也面临挑战，并且需要外部状态估计系统。此外，在许多复杂的现实场景中，全状态估计可能是困难甚至是不可能的。这些限制阻碍了基于物理模型的应用。因此，开发能够利用代理与环境交互收集的数据从视觉观测中学习模型的方法是非常重要的。

### 3.4. 具身智能应用的动力学学习
