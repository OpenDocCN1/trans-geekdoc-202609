## 使用循环

Listing 1.2 显示 `loop1.py` 的内容，演示如何遍历 NumPy 数组和 Python 列表的元素。

### Listing 1.2: loop1.py

```python
import numpy as np
list = [1,2,3]
arr1 = np.array([1,2,3])
for e in list:
    print(e)
for e in arr1:
    print(e)
```

Listing 1.2 初始化变量 `list`，它是一个 Python 列表，同时初始化变量 `arr1`，它是一个 NumPy 数组。Listing 1.2 的下一部分包含两个循环，分别遍历 `list` 和 `arr1` 的元素。可以看到，两个循环的语法完全相同。执行 Listing 1.2 的输出如下：

1 2 3 1 2 3

Listing 1.3 显示 `append1.py` 的内容，演示如何向 NumPy 数组和 Python 列表中追加元素。

### Listing 1.3: append1.py

```python
import numpy as np

```

Listing 1.3 初始化变量 `list`（Python 列表）和变量 `arr1`（NumPy 数组）。Listing 1.3 的输出如下：

Listing 1.4 显示 `append2.py` 的内容，演示另一种向 NumPy 数组和 Python 列表中追加元素的示例。

### Listing 1.4: append2.py


## Other Useful NumPy Methods

除了本节前面代码示例中展示的 NumPy 方法之外，以下（通常命名直观）的 NumPy 方法也非常有用。

`np.zeros()` 方法用 0 值初始化数组。

`np.ones()` 方法用 1 值初始化数组。

`np.empty()` 方法用 0 值初始化数组。

`np.arange()` 方法提供一系列数字。

`np.shape()` 方法显示对象的形状。

`np.reshape()` 方法非常有用！

`np.linspace()` 方法在回归中很有用。

`np.mean()` 方法计算一组数字的平均值。

`np.std()` 方法计算一组数字的标准差。

虽然 `np.zeros()` 和 `np.empty()` 都用 0 初始化二维数组，但 `np.zeros()` 所需的执行时间更少。你也可以使用 `np.full(size, 0)`，但该方法是三种方法中最慢的。

`reshape()` 方法和 `linspace()` 方法分别用于更改数组的维度和生成一系列数值，非常有用。`reshape()` 方法出现在 TensorFlow 代码中，而 `linspace()` 方法用于生成线性回归中的一组数字（将在第 8 章讨论）。`mean()` 和 `std()` 方法用于计算一组数字的平均值和标准差。例如，你可以使用这两个方法来调整高斯分布中的值，使其平均值为 0，标准差为 1。这个过程称为标准化高斯分布。

## Arrays and Vector Operations

Listing 1.12 显示了 `array_vector.py` 的内容，说明如何对 NumPy 数组中的元素执行基于向量的操作。

### Listing 1.12: array_vector.py

```python
import numpy as np
a = np.array([[1,2], [3, 4]])
b = np.array([[5,6], [7,8]])
print('a:     ', a)
print('b:     ', b)
print('a + b: ', a+b)
print('a - b: ', a-b)
print('a * b: ', a*b)
print('a / b: ', a/b)
print('b / a: ', b/a)

print('a.dot(b):',a.dot(b))
```
