变量就像我们存储信息的容器。你可以向变量中放入一个值，稍后使用它。在 PHP 中，我们使用 `$` 符号来表示变量。这是一个示例。

```php
<?php
$name = "John";
echo $name;
```

在这个示例中，`$name` 是变量，“John”是存储在其中的值。我们可以随时更改变量的值。

```php
<?php
$name = "John";
$name = "Jane";
echo $name;
```

变量可以持有不同类型的数据，例如整数、字符串和布尔值。

```php
<?php
$age = 25;
$name = "Alice";
$is_student = true;
```

我们还可以在数学表达式中使用变量。

```php
<?php
$x = 10;
$y = 20;
$sum = $x + $y;
echo $sum;
```

### 示例 08：多重赋值。

```php

$firstPanda = $secondPanda = $thirdPanda = 1337;
```

上面的代码段看起来有点疯狂，但如果你从左到右读，它就更有意义。`$thirdPanda` 被赋值为值 1337，接着 `$secondPanda` 被赋值为 `$thirdPanda` 的值，最后 `$firstPanda` 被设置为 `$secondPanda` 的值。这意味着所有变量都被设置为了最终的数值。很酷炫，对吧？
