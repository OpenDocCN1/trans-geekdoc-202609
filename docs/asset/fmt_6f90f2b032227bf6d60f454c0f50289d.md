
# 1. 网络安全概述

## 1.1 网络安全 (Network Security)

保护网络免受未经授权的访问。正在开发许多工具来实施网络安全框架。

## 1.2 云安全 (Cloud Security)

几乎所有大小的组织都使用云。由于所有重要数据的传输和存储都在那里完成，因此必须对其妥善保护。云提供商必须使用新工具来保护其数据。

## 1.3 应用安全 (Application Security)

Web 应用安全已成为最薄弱环节。网页被篡改并被错误使用。但新出现的最新工具将帮助人们保护其网页和其他应用程序不落入不法之手。

## 1.4 基础设施安全 (Infrastructure Security)

为关键基础设施（如应急、国防、商业部门等）提供的安全。

## 1.5 网络安全需求

网络安全的一些基本要求是：

a) **人员 (People)**：每个人都负责防止威胁。他们必须掌握所有风险的最新解决方案。

b) **流程 (Processes)**：记录在案的流程必须说明职责、管理和规则。必须定期查看。

c) **技术 (Technology)**：必须安装最新技术以最大限度地减少网络威胁。确保此类软件的安装不会给计算机或任何数字设备带来进一步威胁。

## 1.6 收益

网络安全允许我们正确处理资产并保护它们免受滥用。它在 [4] 中提供了许多如下收益：

- 对所有信息和网络始终有保护。
- 严禁未经授权的访问。
- 它可以防止各种病毒、恶意病毒、恶意软件、蠕虫等其他影响整个系统的威胁。
- 最大限度减少因攻击导致系统或网络崩溃的可能性。

## 1.7 复杂性

网络安全也有一些阴暗面。一些缺点 [5] 包括：

- 对普通人来说非常昂贵。
- 需要对网络软件/硬件进行正确配置。错误的配置可能会阻止合法访问。
- 定期保持软件更新至关重要。
- 由于安全威胁是无限的，需要更多的专业知识来实施安全策略以确保资产安全。

# 2. 将人工智能应用于网络安全

AI 是一个重要领域，可以与网络安全相结合，以实施卓越的安全策略。许多组织正在采用基于 AI 的系统，这些系统分析入站和出站流量，协助网络安全人员识别各种威胁并采取必要行动解决它们。如果没有 AI，就无法实现那些通过分析事物进行自我学习的网络安全工具。

为了实现这种功能，需要训练数据集。基于这些训练数据集，可以开发出新的自动化 AI 工具，以增强当前网络安全方案的有效性 [8, 10]。

我们解释了如何使用 AI 保护资产免受各种网络攻击的影响 [9]。

## 2.1 基于 AI 的身份验证

密码是提供身份验证的一种通用方法，在安全方面非常脆弱。由于由于原因，基于生物识别的身份验证方案被广泛使用。但由于技术的进步，攻击者也可以破坏基于生物识别的安全方案 [6]。

例如：脸部识别系统无法检测不同发型的同一张脸。这种身份验证方案会被攻击者通过社交媒体获取不同的图片来破解。通过使用 AI，可以增强基于生物识别的认证，并消除传统方案存在的各种困难。AI 可通过识别关键关联和模式来创建用户面部的复杂模型。苹果声称，有了这项技术，欺骗 AI 并用另一个脸打开设备的概率只有百万分之一。基于 AI 的软件还可以在不同情况下工作，并支持新发型、戴帽子或眼镜等变化。

## 2.2 使用 AI 检测网络钓鱼

这是攻击者用于获取合法用户信息的一种最常用的网络攻击。基于 AI 的系统能够扫描钓鱼源并做出比人类专家更快的决策。基于 AI 的软件还可以被训练以区分虚假和合法网站 [6]。

## 2.3 基于 AI 的行为分析

基于 AI 的行为分析是处理网络攻击的一种很有前景的方法。`ML` 算法的使用可以产生一种模型，根据你使用设备的方式创建行为模式来学习和分析你的行为。它还记录并分析你的打字方式、打字速度、鼠标点击、浏览、滚动模式等。任何时候如果 AI 识别出与你的标准模式不符的异常行为，就可以判断这些活动是由未经授权的用户进行的。

## 2.4 基于 AI 的恶意软件检测

恶意软件检测一直是网络安全人员面临的持续挑战。传统的恶意软件检测方案是基于特征的，也依赖静态和动态分析。由于恶意代码量增长，对新型恶意软件有巨大需求。

检测方案。`ML` 技术可以被用于恶意软件检测。大部分研究工作集中在实现分析框架、获取静态特征以及恶意软件家族分类上。基于 `ML` 的恶意软件检测系统的主要弱点是它们依赖虚拟环境来分析样本。

这一特性不仅影响了运行性能，还会危及整个系统，因为样本需要被执行。由于恶意软件具有适应性行为，准确检测恶意软件是不可能的。因此，必须开发一些创新的基于 `AI` 的算法来执行有效的恶意软件检测。Irina Baptista 等人提出的基于无监督学习的图像恶意软件检测技术。这种提出的技术比传统的恶意软件检测方案具有更高的准确性和更好的检测率。

# 结论

在本章中，我们解释了数字化程度的提高要求网络安全策略，以保护数字世界免受各种网络攻击。我们还解释了在当数字世界的需求，`AI` 在有效实施各种网络安全方案中的作用。由于 `AI` 在网络安全领域的表现优异，它在对立的角度也发挥着最佳作用。这意味着 `AI` 也被攻击者利用来发起各种智能攻击，除非开发了强大的安全策略，否则这些攻击很难被检测。`AI` 在攻击者手中会造成极端破坏，并对网络安全构成更强大的威胁。因此，必须在该方向进行越来越多的研究以克服此类情况。

## 1.1 用于 IDS 的数据挖掘

数据挖掘是从海量信息文件中发现奇奇数据的过程。基本上，更准确地说，该术语指的是在一个考虑了估计、人工智能、`AI`、数据库科学和数据恢复等先进技术的系统中 [2]。在这里，数据处理的某些特定事项可以被添加到一个可识别的干扰结构中：

* 从告警数据中移除常规开发，以允许对真实攻击进行评估。
* 识别虚假告警生成器和"糟糕"的传感器标记。
* 发现发现真实攻击的异常活动。
* 识别长期、一致的模型（不同的 IP 地址，相同的活动）。

### 1.1.1 用于 IDS 的数据挖掘技术

数据挖掘策略在 `IDS` 中起着关键作用。意外的数据准备方法（如分类、聚类、关联规则挖掘）通常用于通过感知和分析系统数据来存储有关中断的信息。以下描绘了不同的数据挖掘方法：

A. *分类*：入侵定位技术可以被视为一个分类问题。它将每个事件分组为正常或特定类型的干扰（攻击）。其主要目标是从具有类别标记的训练样本中获益，预测新或已不明显的信息实例的类别。训练集中的实例具有名称。基本上，建立了一棵特征树（也称为决策树）来预测特定事件所属的类别。

### B. 关联规则

该策略从海量数据集中查找经常发生的项目集。关联规则挖掘发现了属性之间的联系。Lee 提出了用于识别入侵的关联关系深度挖掘的构想。该系统最初与所谓的市场篮子调查有关，旨在发现杂货店客户购物行为的规律性。

### C. 聚类

一种用于在未标记信息中发现模式的无监督机器学习系统。它用于标记信息并将其分成若干组，每组由非常相似的个体组成。

来自不同组的个体将相互不同。不同的聚类方法包括基于密度的策略、基于网格的技术、基于模型的技术、划分策略和层次策略。

## 1.2 IDS 中的数据挖掘算法

以下给出了 IDS 中通用执行的最常用的数据挖掘算法。

### 1.2.1 决策树

著名的机器学习策略。决策树学习使用 `Decision` 作为预测模型，将对某个事体的感知映射到关于该事体的目标价值。

决策树学习是一种通常用于数据处理的方法。其目标是构建一个模型，以预测受许多数据因素影响的目标变量值。决策树也被用于入侵识别。树通过优化经过高度特征化标准的维护树，为每个选择节点挑选最佳方案。其中一种规则是利用信息来识别尺寸关系。

**关注点：**

1. 构建不需要任何空间信息。
2. 可以处理高维信息。
3. 表示直观。
4. 准备好处理数值和离散数据。

**负担：**

1. 构建不需要任何空间信息。
2. 输出特征必须是整数。
3. 限于单一输出质量。
4. 决策树算法具有敏感性。
5. 由数值数据索引生成的树可能是非常复杂的。

### 1.2.2 贝叶斯系统分类器

贝叶斯系统是一种编码感兴趣因素之间概率连接的策略。贝叶斯系统代表了计算机网络检测和防御攻击的新方法；在 IDS 中使用贝叶斯系统解决了大部分与 IDS 相关的问题。该系统有时用于与数学计划相关的入侵识别。

**有利情况：**

1. 朴素贝叶斯分类器简化了计算。
2. 应用于大型数据库时表现出高准确性和速度。

**缺点：**

1. 类条件独立性假设。
2. 缺乏可用的似然信息。

### 1.2.3 K-近邻

k-最近邻算法 (`k-NN`) 是一种用于分类和回归的非参数策略，根据特征空间中 k 个最近训练示例来预测样本的"质量"或类别成员。它是一种懒学习，能力仅在局部进行估计，所有计算推迟到最后。k-最近邻管理是所有机器学习算法中最好的之一：分类问题通过其邻居的多数投票进行调查，将物体分配给其 k 个最近邻居中最常见的分类。通常，它被用于与相关的数学计划的入侵检测（异常识别）。

**关注点：**

1. 分析上可处理。
2. 执行简单。
3. 使用局部信息，可以产生高度自适应的行为。
4. 易于并行执行。

**负担：**

1. 大容量需求。
2. 对维度灾难非常敏感。
3. 刻画测试元组的速度缓慢。

### 1.2.4 人工神经网络

人工神经网络是由生物感官系统驱动的计算模型。神经网络既用于异常入侵发现，也用于恶意入侵检测。对于异常入侵识别，神经网络被建模以发现系统客户的正常特征，并从客户建立的行为中构建具有重要意义的变化。在恶意入侵识别中，神经网络将从系统流中获取信息并学习是否存在入侵示例。用于入侵检测的 `NN` 以两种不同的方式实现。主要方法是将神经网络部分整合到伙伴级现有或更改的特征框架中。第二种方法将神经网络作为独立的恶意入侵检测框架。

**关注点：**

1. 它需要较少正式的数据准备。
2. 隐式地能够检测障碍和自主因素之间复杂的非线性关系。
3. 对噪声信息具有高抗性。
4. 备有多种准备算法。

**负担：**

1. "黑箱"性质。
2. 更大的计算权重。
3. 容易过拟合。
4. 它需要很长的准备时间。

### 1.2.5 支持向量机

支持向量机被认为是入侵识别框架的重要程序。它是一种用于分类分类和回归的机器学习算法执行。一些标准的 `SVMs` (`Support Vector Machines`) 是数据排序的强大设备，它们通过将二分类分配到高维元素空间中的两个不相交的半空间之一（对于非线性分类）以及问题的主输入空间（对于线性分类）来指示二分类。

**关注点：**

1. 高度准确。
2. 能够显示复杂的非线性分类边界。
3. 比其他算法更不容易过拟合。

**不便之处：**

1. 在大规模任务中，高算法复杂性和所需的二次计算程序具有广泛的内存需求。
2. 部分的选择很困难。
3. 准备和测试的速度都中等。

### 1.2.6 K-Means 聚类

`K-Means` 算法是一种详尽的划分聚类算法，通常由于其简单快速而被使用。它使用欧几里德距离作为相似性量。硬聚类意味着数据索引中的项目在任何时刻只能在一个组中。它是一种聚类算法，根据其元素值将元素聚集到 k 个不相交的组中，目标是相同簇中的元素具有相似的属性，不同簇中的元素具有不同的属性。该算法的领先用于准备可能包含正常和异常流量且无需预标记的数据。

**关注点：**

1. 易于实现。
2. 连接到大型数据集时具有高精度和更快的执行。

**缺点：**

1. 创建空簇的概率。
2. 簇的数量具有先验性。
3. 有一个全局簇，它工作得不好。不同的初始划分可能导致几个最后的组。
4. 对于（原始数据中）不同大小和不同厚度的簇效果不佳。
