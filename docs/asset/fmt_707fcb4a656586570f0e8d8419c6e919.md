
在每一步中，标量积的数量减半，因此信号被平滑。利用此过程，构建了滤波器组的第一部分。为了恢复原始数据，Mallat 利用了正交小波的性质，但通过引入另外两个滤波器 `h̃` 和 `g̃`，即共轭滤波器，该理论已推广到一大类滤波器。恢复通过以下公式执行：

(4.33)
```
C_j(k) = 2 ∑_l [ C_{j+1}(l) h̃(k + 2l) + w_{j+1}(l) g̃(k + 2l) ]
```

其中 `w_{j+1}` 是本节后面定义的尺度 `j + 1` 处的小波系数。为了精确恢复，共轭滤波器必须满足两个条件：

**反混叠条件**：

(4.34)
```
H(ω + 1/2) H̃(ω) + G(ω + 1/2) G̃(ω) = 0
```

**精确恢复**：

(4.35)
```
H(ω) H̃(ω) + G(ω) G̃(ω) = 1
```

在分解过程中，输入依次与两个滤波器 `H`（低频）和 `G`（高频）进行卷积。每个结果函数通过抑制每两个样本中的一个来进行抽取。高频信号被保留，我们用低频信号进行迭代（图 4.7 左侧）。在重构过程中，我们通过在每个样本之间插入一个零来恢复采样，然后与共轭滤波器 `H̃` 和 `G̃` 进行卷积，将结果输出相加，并将结果乘以 2。我们迭代到最小尺度（图 4.7 右侧）。正交小波对应于受限情况，即：

#### 4.5.1.5 使用傅里叶变换的小波变换

考虑连续小波的标量积 `c0 = ⟨f(t), φ(t − k)⟩`。如果 `φ(t)` 的带宽限制在采样频率的一半，则数据采样正确。分辨率 `j = 1` 处的数据为：

(4.43)
```
c₁(k) = ⟨f(t), ½ φ(t/2 − k)⟩
```

我们可以用一个频率响应为 `H(ω)` 的离散时间滤波器，从 `c0` 计算出集合 `c1`：

(4.44)
```
H(ω) = { Φ(2ω)/Φ(ω)  if |ω| < ωc
       { 0            if ωc ≤ |ω| < ½
```

且对 `∀ ω` 和 `∀ integer m` 有：

(4.45)
```
H(ω + m) = H(ω)
```

因此，系数的估计值为：

(4.46)
```
C_{j+1}(ω) = C_j(ω) H(2^j ω)
```

截止频率在每一步都减少 2 倍，从而允许样本数量按此因子减少。尺度 `j + 1` 处的小波系数为：

(4.47)
```
w_{j+1} = ⟨f(t), 2^{-(j+1)} ψ(2^{-(j+1)} t − k)⟩
```

它们可以直接从 `C[j]` 通过以下公式计算：

(4.48)
```
W_{j+1}(ω) = C_j(ω) G(2^j ω)
```

其中 `G` 是以下离散时间滤波器：

(4.49)
```
G(ω) = { Ψ(2ω)/Φ(ω)  if |ω| < ωc
       { 0            if ωc ≤ |ω| < ½
```

关系式 (4.34) 和 (4.35) 也必须满足。一大类紧支集小波函数均可使用。已提出许多组滤波器，特别是用于编码 [[22]](#c04.xhtml#c4-bib-0022)。研究表明，这些滤波器的选择必须以缩放函数和小波函数的正则性为指导。复杂度与 `N` 成正比。该算法提供一个包含 `N` 个元素的金字塔结构。

#### 4.5.1.6 重构

数据可从其小波系数中逐步重构，从最低分辨率开始。在每个尺度上，我们计算：

(4.51)
```
C_{j+1} = H(2^j ω) C_j(ω)
```

(4.52)
```
W_{j+1} = G(2^j ω) C_j(ω)
```

我们利用已知的 `C[j + 1]`、`W[j + 1]`、`h` 和 `g` 来求解 `C[j]`。然后通过最小化以下表达式来恢复 `C_j(ω)`：

(4.53)
```
P_h(2^j ω) |C_{j+1}(ω) - H(2^j ω) C_j(ω)|² + P_g(2^j ω) |W_{j+1}(ω) - G(2^j ω) C_j(ω)|²
```

此处采用最小二乘估计器。`P_h(ω)` 和 `P_g(ω)` 是权函数，允许对 `C_j(ω)` 的恢复给出通用解。`C_j(ω)` 的关系式形式为：

(4.54)
```
C_j(ω) = C_{j+1}(ω) H̃(2^j ω) + W_{j+1}(ω) G̃(2^j ω)
```

其中共轭滤波器的表达式为：

(4.55)
```
H̃(ω) = (P_h(ω) H^*(ω)) / (P_h(ω) |H(ω)|² + P_g(ω) |G(ω)|²)
```

(4.56)
```
G̃(ω) = (P_g(ω) G^*(ω)) / (P_h(ω) |H(ω)|² + P_g(ω) |G(ω)|²)
```

很容易看出，这些滤波器满足式 (4.35) 中给出的精确重构条件。实际上，式 (4.55) 和 (4.56) 给出了该方程的通用解。在该分析中，香农采样条件始终得到满足。不存在混叠，因此反混叠条件 (4.76) 并非必要。

如果我们选择：

(4.57)
```
G(ω) = √(1 - |H(ω)|²)
```

这对应于小波是两个分辨率平方差的情况：

(4.58)
```
|Φ(2ω)|² = |Φ(ω)|² - |Φ(2ω)|²
```
