
# 加密货币与用户体验

把它们变现并购买你所需的一切 Patti Smith, 1975

加密货币是区块链第一个真正成功的用例，因此如果我不详细研究它们，将是我的失职。在本章中，我将探讨加密货币爱好者和开发者在将加密货币——这种新形式的货币、资产或无论你如何称呼它——推向大众时所面临的问题。

## 加密货币故事

在过去的三几年里，比特币多次出现在媒体上，所以大多数人都听过它。其中有些人甚至读过其他加密货币，或者可能研究过这本书的主题：区块链，即让加密货币运行的底层引擎。但对于大多数人来说，这种接触相当有限。

比特币、以太坊、USDT、Ripple、比特币现金、Link、币币、莱币、Dot 和卡尔达：这些是市值排名前名的加密货币，在本书时它们的总价值约为 3 万亿美元。这是 IBM 市值的三倍以上。显而易见，随着时间的推移，它们确实已经了一项大事业。然而，还有数百种加密货币，一旦你开始计算以太坊区块链和其他公共链上存在的代币，数量就会变得惊人地巨大。我估计我们目前有数千个。没有人能完全理解所有的货币，或者掌握每一个的目的（如果真的有的话）。然而，十年前，它们中一个一个都不。看起来某些确实将长期存在，越来越多的人将不得不熟悉它们。它们已经成为我们金融格局的一部分。

但为什么会有这么多？它们是做什么的？这和传统货币、语言（人类语言和编程语言）甚至宗教是一样的故事。人类似乎更容易接受分裂和分离，而不是重新组合和统一。加密货币和区块链代币也不例外。

## 局部之和

互联网、点对点网络、密码学以及我之前提到的许多其他计算机发明，为我们提供了实现去中心化金融的工具——交易不需要银行或信用卡公司允许交换发生，而且可以比简单的直接扣款或定期订单更具自动化程度。

由于区块链是上述所有发明的合成，具有这些惊讶的涌现属性，我相信通过这些加密货币、代币以及所谓的智能合约（实际上是下一代直接扣款和定期订单，更多将在智能契约中讨论），它注将在去中心化金融中占据核心角色。然而，正如新技术总是那样，加密货币的现状意味着对于普通用户来说存在许多风险。仍然很容易犯错并将巨额资金发送给错误的人，甚至发送到虚无中。很难理解到底发生了什么。

作为对比：第一批生产的汽车对于今天的驾驶员来说是无法驾驶的。新发明需要时间来成熟，缺陷需要被发现并修复，用户与技术之间的界面需要演变，最重要的是：在普通人脑海中形成一个模型，让他们能够处理新技术。简而言之，用户体验需要成熟。这完全取决于观众。

## 用户体验

那么，什么是这种“用户体验”，或者从业者所说的 UX 呢？嗯，线索就在名字里：`user`（用户）：指使用产品、机器或服务的人；`experience`（体验）：发生在你身上并影响你感受的事物——剑津词典 [\[64\]](#text00027.html#a3W3)

体验的水平取决于用户的技能组。供软件开发人员或 IT 系统管理员使用的东西看起来非常不同，而且比供交易员、投资者或公司高管使用的东西要复杂得多。如果是为了你那位古怪的波西米亚阿姨，它必须更简单、更可靠。

想一下摩托车上的控制杆和旋钮与轻飞机驾驶舱内的那些之间的区别。前者比后者简单得多，因为飞行员在三维空间内导航，而摩托车手几乎在二维空间内导航。尽管比两三年前好得多，但加密货币的用户体验仍然很糟糕。用户面对的是一个飞机驾驶舱，而它本应该像一辆摩托车（或自行车）。我从 2009 年底开始关注加密货币，理解区块链是如何工作的，以及驱动它的数学是如何使用的，然而，每当我必须进行一次重大的加密货币交易时，我仍然感到心提到了嗓子眼。

## 直观模型

回到汽车类比：在下面的图中，你可以看到 19 世纪末一位衣着整洁的亨利·福特坐在他的四轮车上，那是制造的第一批汽车之一。注意，汽车没有方向盘。相反，它有一个像船一样的操纵杆。

```
图 15：1896 年坐在四轮车上的福特
```

早期的汽车制造商必须从零开始界面，因此在我们最终确定熟悉的方向盘、档杆以及加速器、刹车和离合器踏板（方便的 CBA 顺序）之前，有很多不同的尝试。操纵杆失败是因为它对大多数人反直觉：你向左拉它是为了向右转。方向盘更有意义：你向右转它就向右转。我们的孩子看到我们开车、玩游戏，所以当他们坐在真汽车方向盘后时，他们已经理解了这种模型，这种模型已经根深蒂固以至于这个事实本身被忘了。或者换句话说：我想向右走，所以我把方向盘向右转，汽车就向右转。这就很简单。

### 引擎盖下

然而，在车身下方隐藏着各种机械装置：`pinion gear` 顺时针旋转，`rack` 向左移动，`tie rods` 拉或推 `steering arms`，`wheels` 绕着 `kingpins` 移动。你对最后那句话走神了吗？我知道我在写的时候也是。你不需要知道 `pinion gears`、`racks`、`tie rods`、`steering arms` 和 `kingpins` 是什么也能让汽车向你想要的方向行驶。界面向你隐藏了这一切，几十年的工程确保了（希望）事情不会出错。例如，该系统设计旨在确保轮子事情不会出错。

私钥就像银行卡的 PIN 码，但它们长得多，因此更难猜测。第三是加密货币钱包的“助记短语”。你可以将其视为一个“主密钥”，允许你生成任意数量的加密货币地址，每个地址都有自己的公地址和私钥。如果你的软件钱包丢失了（例如在拍摄鲸鱼时手机掉进海里），助记短语可以加载到新手机上新的钱包软件副本中，你所有的旧地址及其私钥都可以重新创建。
