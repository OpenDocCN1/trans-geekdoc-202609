
其中 $\Psi = \Phi$。公式 (9.14) 称为*分析*方程，公式 (9.15) 称为*合成*方程。

利用此类变换进行压缩，利用了这样一个事实：自然界中许多信息丰富的信号，可以根据信号的模态，在适当选择的基中*紧凑地*表示。通常，此类基的构建试图“模仿”人类大脑为感知这些信号而进化出的感觉系统；我们知道，自然界（与现代人类相反）不喜欢浪费资源。标准的压缩任务包含以下阶段：(a) 通过分析步骤公式 (9.14) 获得 $\widetilde{\mathbf{s}}$ 的 $l$ 个分量；(b) 保留其中最显著的 $k$ 个分量；(c) 对这些值以及它们在变换向量 $\widetilde{\mathbf{s}}$ 中的相应位置进行编码；(d) 在需要时（存储或传输后），通过合成方程（公式 (9.15)）获得（近似）原始信号 $\mathbf{s}$，其中用 $\widetilde{\mathbf{s}}$ 的 $k$ 个最显著分量代替 $\widetilde{\mathbf{s}}$，这些是被编码的分量，而其余分量设为零。然而，直到最近，这种压缩过程中存在一些非正统之处。人们处理（变换）具有 $l$ 个坐标的大信号向量，而在实践中 $l$ 可能相当大，然后只使用一小部分变换系数，其余的则直接忽略。此外，还必须存储/传输最终被编码的那些大系数的相应位置。

由此自然引出一个问题：由于合成方程中的 $\widetilde{\mathbf{s}}$ 是（近似）稀疏的，能否通过一条替代路径来计算它，而不必走公式 (9.14) 中的分析模型？这里的问题是探究是否可以用一种更具信息量的方式对可用原始数据进行采样，使得少于 $l$ 个样本/观测值就足以恢复所有必要信息。理想情况是通过 $k$ 个此类样本来恢复它，因为这是显著自由参数的数量。另一方面，如果这听起来有点极端，能否获得 $N$（$k < N \ll l$）个此类与信号相关的测量值，从中最终恢复出 $\mathbf{s}$？事实证明，这种方法是可行的，它导致了在未知目标向量在某个域中是稀疏这一约束下，*欠定*线性方程组的求解。

当采用比正交基更一般的展开类型（即所谓的*过完备字典*）时，此类技术的重要性变得更加明显。字典 [65] 是一组参数化波形的集合，它们是离散时间信号样本，表示为向量 $\boldsymbol{\psi}_i \in \mathbb{C}^l$，$i \in \mathcal{I}$，其中 $\mathcal{I}$ 是整数索引集。例如，DFT 或离散小波变换（DWT）矩阵的列构成一个字典。这两个都是所谓的*完备*字典的例子，它们由 $l$ 个（正交归一）向量组成，即数量等于信号向量的长度。然而，在许多实际情况下，使用此类字典非常受限。让我们以一段来自新闻媒体或视频的音频信号为例，该信号需要被处理。这通常由不同类型的信号组成，即语音、音乐和环境声。对于这些信号中的每一种类型，在分析展开中可能有不同的信号向量更为合适。例如，音乐信号的特点是具有强烈的谐波成分，使用正弦波似乎最利于压缩；而对于语音信号，Gabor 类型的信号展开（由不同时间位置上足够窄的脉冲加权的各种频率的正弦波组成 [31,87]）可能是更好的选择。处理图像时也适用同样的情况。图像的不同部分，如平滑区域或包含锐利边缘的部分，可能需要不同的展开向量集以获得最佳整体性能。为了满足此类需求，更近期的趋势是使用*过完备*字典。例如，可以通过将不同的字典连接起来获得此类字典，例如将 DFT 和 DWT 矩阵连接起来，得到一个组合的 $l \times 2l$ 变换矩阵。或者，可以对字典进行“训练”，以有效地表示一组可用的信号样本，这一任务通常称为字典学习 [75,78,90,100]。在使用此类过完备字典时，合成方程采取以下形式

$$
\mathbf{s} = \sum\limits_{i \in \mathcal{I}}\theta_i\boldsymbol{\psi}_i.
$$ (9.16)

注意，现在分析是一个不适定问题，因为字典的元素 $\{\boldsymbol{\psi}_i\}_{i \in \mathcal{I}}$（通常称为*原子*）不是线性独立的，并且不存在一组唯一的参数 $\{\theta_i\}_{i \in \mathcal{I}}$ 来生成 $\mathbf{s}$。此外，我们预期这些参数中的大多数为（接近）零。注意，在这种情况下，$\mathcal{I}$ 的基数大于 $l$。这必然导致具有无限多解的欠定方程组。现在提出的问题是，我们能否利用这些参数大多数已知为零这一事实，从而得出唯一解？如果可以，在什么条件下这样的解是可能的？我们将在第 20 章回到学习字典的任务。

除了前面的例子，还有许多情况是由于物理和技术约束，我们无法获得足够多的测量值，从而导致欠定方程组。MRI 成像就是这种情况，将在 10.3 节中详细介绍。

## 9.5 寻找最稀疏解

受上一节讨论的启发，我们现在将注意力转向通过在解上施加稀疏性约束来求解欠定方程组的任务。我们将在回归的背景下建立理论框架，并将坚持采用为此任务采用的符号。此外，我们将专注于实值数据情况以简化阐述。该理论可以很容易地推广到更一般的复值数据情况（参见，例如，[64,99]）。假设我们得到一组观测/测量值，$\mathbf{y} := [y_1, y_2, \dots, y_N]^T \in \mathbb{R}^N$，根据线性模型

$\mathbf{y} = X\boldsymbol{\theta}$，$\mathbf{y} \in \mathbb{R}^N$, $\boldsymbol{\theta} \in \mathbb{R}^l$, $l > N$，

(9.17)

其中 $X$ 是 $N \times l$ 输入矩阵，假设其为满行秩，即 `rank(X) = N`。我们的出发点是无噪声情况。公式 (9.17) 中的线性方程组是欠定的，并接受无限多解。可能解的集合位于 $N$ 个超平面的交集中

$\{\boldsymbol{\theta} \in \mathbb{R}^l : y_n = \mathbf{x}_n^T \boldsymbol{\theta}\}$, $n = 1, 2, \dots, N$。

根据几何知识，$N$ 个非平行超平面的交集（在我们的情况下，由 $X$ 被假设为满行秩保证，因此 $\mathbf{x}_n, n = 1, 2, \dots, N$ 线性独立）是一个维数为 $l - N$ 的平面。例如，三维空间中两个（非平行）（超）平面的交集是一条直线，即维数等于一的平面。更正式地说，所有可能解的集合，记为 $\Theta$，是一个*仿射*集。仿射集是线性子空间经过常向量平移后的结果。让我们进一步探讨这一点，因为稍后我们将用到它。

设 `X` 的零空间记为 `null(X)`（有时记为 `𝒩(X)`），它被定义为线性子空间

`null(X) = {z ∈ ℝ^l : Xz = 0}`。

显然，如果 `θ[0]` 是方程 (9.17) 的一个解，即 `θ[0] ∈ Θ`，那么很容易验证 `∀θ ∈ Θ`，有 `X(θ − θ[0]) = 0`，或者说 `θ − θ[0] ∈ null(X)`。结果，

`Θ = θ[0] + null(X)`，

且 `Θ` 是一个仿射集。我们还从线性代数基础知（且易于证明；见问题 9.9）满行秩矩阵 `N × l`（`l > N`）的零空间是一个维数为 `l − N` 的子空间。图 9.7 说明了二维空间中一条观测的情况，即 `l = 2` 和 `N = 1`。解集 `Θ` 是一条直线，它是穿过原点的线性子空间（即 `null(X)`）的平移。因此，如果想要在仿射解集 `Θ` 中所有点里选取*单个*点，则必须施加一个额外的约束/先验知识。

### $\ell_2$ 范数最小化器

我们的目标现在变为在（仿射集）$\Theta$ 中选取一个对应于最小 $\ell_2$ 范数的点。这等价于求解以下约束任务：

$$
\min_{\boldsymbol{\theta} \in \mathbb{R}^{l}} \quad \left\| \boldsymbol{\theta} \right\|_{2}^{2}, \text{s.t.} \quad \boldsymbol{x}_{n}^{T}\boldsymbol{\theta} = y_{n}, \quad n = 1,2,\ldots,N.
$$

![Equation](img/si121.png) (9.18)

我们已经从第 6.4 节知道（也可以通过使用拉格朗日乘数法重新推导；见问题 9.10），前述优化任务接受一个以闭式给出的*唯一*解，即

$$
\widehat{\boldsymbol{\theta}} = X^{T}\left( X X^{T} \right)^{-1}\boldsymbol{y}.
$$

![Equation](img/si122.png) (9.19)

该解的几何解释见 图 9.7A，针对 $l = 2$ 和 $N = 1$ 的情况。欧几里得范数球的半径不断增大，直到它接触包含解的平面。这一点是具有最小 $\ell_2$ 范数的点，或者等价地说，是离原点最近的点。等价地，点 $\widehat{\boldsymbol{\theta}}$ 可以被视为 $\boldsymbol{0}$ 在 $\Theta$ 上的（度量）投影。

最小化 $\ell_2$ 范数以求解欠定线性方程组已被用于各种应用。与我们最相关的是在使用函数（向量）的过完备字典进行展开以确定未知参数的背景下 [35]。该方法的一个主要缺点是它**不保持稀疏性**。即使真实模型向量 $\boldsymbol{\theta}$ 有零值，也无法保证公式 (9.19) 中的解会给出零值。此外，该方法是*分辨率受限*的 [26]。这意味着即使字典中特定原子可能有尖锐的贡献，这也不会体现在得到的解中。这是由于 $XX^{T}$ 提供的信息是全局性的，以一种“平均”方式包含字典中的所有原子，最终结果倾向于平滑掉个别贡献，尤其是在字典过完备时。

#### $\ell_0$ 范数最小化器

现在我们将注意力转向 $\ell_0$ 范数（再次指出，这属于对范数定义的滥用），并将稀疏性作为我们获取解的新旗帜。现在的任务变为

```
min_{θ ∈ ℝˡ} ||θ||₀, s.t. xₙᵀθ = yₙ, n = 1,2,…,N,
```

即从位于所有可能解所构成的平面上的所有点中，找到*最稀疏*的那个，也就是非零元素个数最少的那个。事实上，这种方法符合*奥卡姆剃刀*原则的精神——它对应着能够解释所获得观测值的最少参数个数。现在提出的问题是：

*   该问题的解是否唯一，以及在什么条件下唯一？
*   能否在现实的时间内以足够低的复杂度获得解？

我们将第一个问题的答案推迟到后面讨论。至于第二个问题，消息不太好。在一组线性约束下最小化 $\ell_0$ 范数是一项组合性质的任务，事实上，该问题通常是 NP-hard 的 [72]。解决该问题的方法是考虑 `θ` 中所有可能的零元素组合，移除公式 (9.17) 中 `X` 相应的列，并检查方程组是否得到满足；保留非零元素个数最少的那些作为解。这种搜索技术表现出的复杂度与 `l` 呈指数级依赖关系。图 9.7A 说明了单观测（约束）情况下，构成最小化 $\ell_0$ 范数解集的两个点（(1.5, 0) 和 (0, 1)）。

#### $\ell_1$ 范数最小化器

当前任务由下式给出

```
min_{θ ∈ ℝˡ} ||θ||₁, s.t. xₙᵀθ = yₙ, n = 1,2,…,N.
```

图 9.7B(图 9.7B)展示了该几何结构。$\ell_1$ 球不断增大，直到与可能解的仿射集相切。对于这一特定几何结构，解为点 (0, 1)，这是一个稀疏解。正如我们在第 9.2 节的讨论中所见，在所有 $p \ge 1$ 的 $\ell_p$ 范数中，$\ell_1$ 范数是唯一一个与促稀疏性的（非凸）$\ell_p$“范数”（$p < 1$）有一定相似性的范数。此外，我们也曾指出，当相应数值较小时，$\ell_1$ 范数倾向于鼓励零值出现。接下来，我们将陈述一个引理，以更正式的方式确立这一偏好零值的性质。$\ell_1$ 范数最小化任务也称为*基追踪*，它被建议用于根据过完备字典的原子来分解向量信号 [26]。

$\ell_1$ 最小化问题可以转化为标准线性规划（LP）形式，随后可通过调用任何相关方法求解；单纯形法和较新的内点法是两种可能的选择（参见，例如 [14,33]）。确实，考虑如下 LP 任务：

```
min_x c^T x, s.t. Ax = b, x ≥ 0.
```

要验证我们的 $\ell_1$ 最小化问题可以转化为上述形式，首先注意到任意 $l$ 维向量 $\boldsymbol{\theta}$ 可以分解为

$\boldsymbol{\theta} = \boldsymbol{u} - \boldsymbol{v}$, $\boldsymbol{u} \ge 0$, $\boldsymbol{v} \ge 0$.

确实，例如当以下情况成立时，该等式成立：

$\boldsymbol{u} := \boldsymbol{\theta}_+$, $\boldsymbol{v} := (-\boldsymbol{\theta})_+$,

#### $\ell_1$ 范数最小化解的刻画

**引理 9.1**

公式 (9.17) 中欠定线性系统解的仿射集 $\Theta$ 中的元素 $\boldsymbol{\theta}$ 具有最小 $\ell_1$ 范数，当且仅当满足以下条件：

$$
\left| \sum_{i: \theta_i \neq 0} \text{sgn}(\theta_i) z_i \right| \leq \sum_{i: \theta_i = 0} |z_i|, \quad \forall \mathbf{z} \in \text{null}(X).
$$ (9.22)

此外，当且仅当对于所有 $\mathbf{z} \neq 0$，(9.22) 中的不等式为严格不等式时，$\ell_1$ 最小化解是唯一的（参见例如 [74] 和问题 9.11）。
