## 第 11 章：端点安全

### 1. B

### 2. C
列出的服务包括：

- 21 – FTP
- 22 – SSH
- 23 – Telnet
- 80 – HTTP
- 443 – HTTPS

#### 1. 安全协议
在这些服务中，`SSH` 和 `HTTPS` 是远程 Shell 访问和 HTTP 的安全选项。尽管安全模式 FTP (`FTP/S`) 可能运行在 TCP 21 上，但没有足够的信息可以确定，且如有必要，可使用 `HTTPS` 进行安全文件传输。因此，Naomi 的最佳选择是禁用所有三个可能不安全的协议：FTP、Telnet 和 HTTP。

#### 2. DLP 与数据分类
使用 `DLP` 保护数据需要数据分类，以便 `DLP` 知道应保护哪些数据以及对其应用什么策略。定义数据生命周期有助于防止数据保留时间过长，并通过限制需要保护的数据量来提高数据安全性，但这不是 `DLP` 部署的必要部分。加密所有敏感数据可能意味着 `DLP` 无法识别它，且可能不适合其使用方式。使用创建者或所有者标记所有数据可能很有用，但不是 `DLP` 推广所必需的——相反，了解数据的分类更为重要。

#### 3. 蜂窝设备威胁
`SIM` 卡物理被盗是蜂窝连接设备可能面临的威胁。使用集成 `SIM` 而非可拆卸 `SIM`，或使 `SIM` 卡在没有付出巨大努力的情况下难以或无法访问，可能会有所帮助。虽然克隆 `SIM` 卡以帮助破解一次性密码系统是一种真实存在的攻击，但 `IoT` 设备通常不使用蜂窝连接来呈现一次性密码，因为不涉及用户。窄带和基带答案在此场景中均不构成担忧。

#### 4. MFP 安全
`MFP`（多功能打印机）可能包含来自复印或扫描的敏感数据；某些 `MFP` 具有内置硬盘或其他大容量存储，可长期保留数据。它们通常网络安全能力薄弱，使其在某些网络攻击中可作为反射器或放大器。幸运的是，如果 `MFP` 支持用于 Web 访问的 `TLS` 等协议，则它们支持合理安全的协议实现，以保障数据传输安全。

#### 5. 应用程序控制
允许列表应用程序将仅允许在系统上安装特定的许可程序。拒绝列表应用程序将阻止安装指定的应用程序。加固应用程序不是特定类别的工具，尽管加固脚本正在使用中，而 `HIPS` 是主机入侵防御系统。

#### 6. EDR 系统
端点检测和响应 (`EDR`) 系统为系统提供监控、检测和响应能力。`EDR` 系统从端点采集数据并将其发送到中央存储库，在那里可以对其进行分析以发现问题和妥指标 (`IOC`)，或用于事件响应活动。`IAM` 是身份和访问管理，`FDE` 是全盘加密，`ESC` 不是常用的安全首字母缩略词。

#### 7. 片上系统
片上系统 (`SoC`) 是一种芯片，它将完整计算机的大部分功能构建在其中。事实上，大多数 `SoC` 都将 CPU、内存、输入/输出和存储作为芯片的一部分。将显示器添加到芯片中不太常见，但在智能手机、智能手表和其他设备中，添加 `SoC` 可访问并输出的显示器非常常见。

#### 8. Windows 脚本环境
`PowerShell` 是 Windows 系统的原生脚本环境。虽然可以安装 `Python` 和 `Bash`，但它们不是操作系统的自动组成部分。`CMD.exe` 将启动命令提示符，但它不是脚本环境。

#### 9. 车辆网络
控制器局域网 (`CAN`) 是一种专用于车辆的标准，旨在允许微控制器、传感器和车辆的其他组件进行通信。`Zigbee` 是一种用于家庭自动化和类似短距离用途的无线协议，不适合在车辆中使用。窄带描述的是信道，而非总线类型，`SoC` 总线是为本题编造的。

#### 10. Arduino 安全
Arduino 是一种微控制器，由于默认形式的 Arduino 没有内置有线或无线网络，Hui 应专注于设备的物理安全。

#### 11. IP 地址方案
组织应使用专门分配给该组织的 IP 地址，或 `RFC 1918` 地址（不可在互联网路由的地址）。这意味着不需要寻址方案来避免使用另一个组织的 IP 地址。IP 地址方案常用于在子网中工作时避免 IP 地址耗尽。相同的跟踪意味着它们在进行资产和系统清单时很有帮助，因为它们有助于将网络上的设备与已知的物理系统匹配。最后，为默认网关和其他常见网络组件一致地使用相同的 IP 地址，意味着支持人员不必在每个位置或网络中学习独特的配置。

#### 12. SCADA 系统
`SCADA`（数据采集与监视控制系统）是一种系统架构，它将数据采集和控制设备与通信方法及接口相结合，以监督复杂的工业和制造过程，就像公用事业中使用的那些一样。`SIM`（用户身份模块）是用于识别手机的小卡；`HVAC` 代表供暖、通风和空调；`AVAD` 是为本题编造的。

#### 13. 实时操作系统 (RTOS)
实时操作系统 (`RTOS`) 是一种操作系统，旨在在数据馈送给操作系统时对其进行处理，而不是像运行其他进程和程序那样延迟处理。当进程或程序对延迟敏感（如果响应不立即发生可能会出现延迟）时，会使用实时操作系统。`MFP` 是多功能打印机，`HIPS` 是主机入侵防御系统，`SoC` 是片上系统——这是硬件，可能运行 `RTOS`，但答案未提及 `SoC` 运行哪种类型的操作系统。

#### 14. 嵌入式系统约束
嵌入式系统有广泛的物理外形规格，使其能够放置在许多不同类型的系统和设备中。正如 Security+ 考试大纲所述，嵌入式系统的常见约束包括电源、计算、网络、加密、无法打补丁、认证、范围、成本和隐含信任。
