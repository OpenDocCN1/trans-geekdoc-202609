
调用 `coinflip` 的结果将与每个 case 的值进行比较。Case 从上到下依次求值，因此第一个匹配的 case 会被执行。可选的 default case 在其他 case 都不匹配时匹配；它可以放在任何位置。Case 不会像 C 语言那样自动贯穿到下一个（尽管存在一个很少使用的 `fallthrough` 语句可以覆盖此行为）。

`switch` 语句不需要操作对象；它可以只列出 case，每个 case 是一个布尔表达式：

```go
func Signum(x int) int {
    switch {
    case x > 0:
        return +1
    default:
        return 0
    case x < 0:
        return -1
    }
}
```

这种形式称为*无标签 switch*；它等同于 `switch true`。

与 `for` 和 `if` 语句一样，`switch` 可以包含一个可选的简单语句——短变量声明、增量或赋值语句，或函数调用——可用于在测试前设置值。

`break` 和 `continue` 语句修改控制流。`break` 使控制流在最内层的 `for`、`switch` 或 `select` 语句（稍后将介绍）之后的下一条语句恢复执行，正如我们在第 1.3 节中所见，`continue` 使最内层的 `for` 循环开始其下一次迭代。语句可以被标记，以便 `break` 和 `continue` 可以引用它们，例如一次跳出多层嵌套循环或开始最外层循环的下一次迭代。甚至还有一个 `goto` 语句，尽管它是为机器生成的代码准备的，而非程序员常规使用。

## 命名类型

`type` 声明使得为现有类型命名成为可能。由于结构体类型通常很长，因此它们几乎总是被命名。一个熟悉的例子是为二维图形系统定义 `Point` 类型：

```go
type Point struct {
    X, Y int
}
var p Point
```

类型声明和命名类型将在第 2 章中介绍。

### 指针

Go 提供了指针，即包含变量地址的值。在某些语言中（特别是 C），指针相对不受约束。在其他语言中，指针被伪装成“引用”，除了传递它们之外没什么可做的。Go 采取了一个中间立场。指针是显式可见的。`&` 运算符生成变量的地址，`*` 运算符获取指针指向的变量，但不支持指针运算。我们将在第 2.3.2 节中解释指针。

### 方法和接口

方法是与命名类型关联的函数；Go 的不寻常之处在于方法可以附加到几乎任何命名类型上。方法将在第 6 章中介绍。接口是抽象类型，它们让我们能够根据具体类型拥有的方法，以相同的方式对待不同的具体类型，而不关心它们如何表示或实现。接口是第 7 章的主题。

### 包

Go 自带了一个庞大的标准库，包含许多有用的包，Go 社区也创建并分享了更多。编程往往更多的是关于使用现有的包，而不是编写自己的原创代码。全书中，我们将指出几十个最重要的标准包，但还有许多我们因篇幅所限未提及，我们也无法为任何包提供类似完整参考手册的内容。

在着手编写任何新程序之前，最好先看看是否已存在一些包能帮你更轻松地完成工作。你可以在 `https://golang.org/pkg` 找到标准库包的索引，在 `https://godoc.org` 找到社区贡献的包。`go doc` 工具使这些文档可轻松从命令行访问：

```bash
$ go doc http.ListenAndServe
package http // import "net/http"

func ListenAndServe(addr string, handler Handler) error

    ListenAndServe listens on the TCP network address addr and then
    calls Serve with handler to handle requests on incoming connections.
...
```

### 注释

我们已经提到了程序或包开头的文档注释。在每个函数声明之前编写注释以指定其行为也是良好的风格。这些约定很重要，因为它们被 `go doc` 和 `godoc` 等工具用来定位和显示文档（§10.7.4）。

对于跨越多行或出现在表达式或语句内部的注释，还有其他语言熟悉的 `/* ... */` 表示法。这种注释有时用于文件开头的大段解释性文本，以避免每行都写 `//`。在注释内部，`//` 和 `/*` 没有特殊含义，因此注释不能嵌套。

# 2. 程序结构

在 Go 中，与其他任何编程语言一样，人们从一小组基本构造构建大型程序。变量存储值。简单表达式通过加法、减法等操作组合成更大的表达式。基本类型聚合成数组和结构体等聚合类型。表达式用于语句中，其执行顺序由 `if` 和 `for` 等控制流语句决定。语句被分组成函数以实现隔离和复用。函数被收集到源文件和包中。

我们在上一章中看到了其中大多数的示例。在本章中，我们将更详细地介绍 Go 程序的基本结构元素。示例程序故意保持简单，以便我们专注于语言本身，而不被复杂的算法或数据结构分心。

## 2.1 名称

Go 函数、变量、常量、类型、语句标签和包的名称遵循一条简单规则：名称以字母（即 Unicode 视为字母的任何字符）或下划线开头，后面可以跟任意数量的字母、数字和下划线。大小写敏感：`heapSort` 和 `Heapsort` 是不同的名称。

Go 有 25 个*关键字*，如 `if` 和 `switch`，它们只能在语法允许的地方使用；不能用作名称。

### Go 关键字与声明

#### 关键字

```text
break        default      func         interface    select
case         defer        go           map          struct
chan         else         goto         package      switch
const        fallthrough  if           range        type
continue     for          import       return       var
```

此外，还有约三十个*预声明*名称，如 `int` 和 `true`，用于内置常量、类型和函数：

| 类别 | 名称 |
| :--- | :--- |
| **Constants** | `true` `false` `iota` `nil` |
| **Types** | `int` `int8` `int16` `int32` `int64` |
| | `uint` `uint8` `uint16` `uint32` `uint64` `uintptr` |
| | `float32` `float64` `complex128` `complex64` |
| | `bool` `byte` `rune` `string` `error` |
| **Functions** | `make` `len` `cap` `new` `append` `copy` `close` `delete` |
| | `complex` `real` `imag` |
| | `panic` `recover` |

这些名称并非保留字，因此你可以在声明中使用它们。我们将看到少数重新声明它们合理的场景，但要警惕潜在的混淆。

#### 作用域与可见性

如果实体是在函数内部声明的，它对该函数是*局部*的。如果是在函数外部声明，则在其所属包的所有文件中均可见。名称首字母的大小写决定了其跨包边界的可见性。若以大写字母开头，则为*导出*的，意味着它在自己的包之外可见且可被访问，如 `fmt` 包中的 `Printf`。包名本身总是小写。

名称长度无限制，但 Go 程序的惯例和风格倾向于短名称，尤其是作用域较小的局部变量；你更可能看到名为 `i` 的变量，而非 `theLoopIndex`。通常，名称的作用域越大，其命名应越长且越有意义。

在风格上，Go 程序员组合单词形成名称时使用“驼峰命名法”；即首选内部大写字母，而非内部下划线。因此标准库中有 `QuoteRuneToASCII` 和 `parseRequestLine` 这样的函数名，但绝不会有 `quote_rune_to_ASCII` 或 `parse_request_line`。像 ASCII 和 HTML 这样的首字母缩略词的字母始终保持相同大小写，因此函数可能称为 `htmlEscape`、`HTMLEscape` 或 `escapeHTML`，但不应为 `escapeHtml`。

## 2.2 声明

*声明*为程序实体命名，并指定其部分或全部属性。主要有四种声明：`var`、`const`、`type` 和 `func`。本章讨论变量和类型，常量见第 3 章，函数见第 5 章。

Go 程序存储在一个或多个以 `.go` 结尾的文件中。每个文件以 `package` 声明开头，说明该文件属于哪个包。随后是任意 `import` 声明，然后是类型、变量、常量和函数的*包级*声明序列，顺序不限。例如，下面的程序声明了一个常量、一个函数和几个变量：

```go
// Boiling prints the boiling point of water.
package main

import "fmt"

const boilingF = 212.0

func main() {
    var f = boilingF
    var c = (f - 32) * 5 / 9
    fmt.Printf("boiling point = %g°F or %g°C\n", f, c)
    // Output:
    // boiling point = 212°F or 100°C
}
```

常量 `boilingF` 是包级声明（`main` 也是），而变量 `f` 和 `c` 局限于 `main` 函数。每个包级实体的名称不仅在包含其声明的源文件中可见，而且在该包的所有文件中均可见。相比之下，局部声明仅在声明它们的函数内可见，甚至可能仅在函数的一小部分内可见。

函数声明包含名称、参数列表（由调用者提供值的变量）、可选的结果列表，以及函数体（定义函数功能的语句）。若函数无返回值，则省略结果列表。函数执行从第一条语句开始，直到遇到 `return` 语句或到达无结果函数的末尾。随后控制权及任何结果返回给调用者。

我们已见过不少函数，后续还有更多，包括第 5 章的详细讨论，此处仅作概述。下面的 `fToC` 函数封装了温度转换逻辑，使其仅定义一次却可在多处使用。这里 `main` 调用了它两次，使用两个不同局部常量的值：

```go
// Ftoc prints two Fahrenheit-to-Celsius conversions.
package main

import "fmt"

func main() {
    const freezingF, boilingF = 32.0, 212.0
    fmt.Printf("%g°F = %g°C\n", freezingF, fToC(freezingF)) // "32°F = 0°C"
    fmt.Printf("%g°F = %g°C\n", boilingF, fToC(boilingF))   // "212°F = 100°C"
}

func fToC(f float64) float64 {
    return (f - 32) * 5 / 9
}
```

## 2.3 变量

`var` 声明创建特定类型的变量，赋予其名称，并设置初始值。每个声明的通用形式为：

```
var name type = expression
```

类型或 `=` `expression` 部分可以省略，但不能同时省略。若省略类型，则由初始化表达式推断。若省略表达式，初始值为该类型的*零值*：数字为 `0`，布尔值为 `false`，字符串为 `""`，接口和引用类型（切片、指针、映射、通道、函数）为 `nil`。数组或结构体等聚合类型的零值是其所有元素或字段的零值。

零值机制确保变量始终持有其类型的明确定义值；Go 中不存在未初始化变量。这简化了代码，且往往在无需额外工作的情况下保证边界条件的合理行为。例如：

```go
var s string
fmt.Println(s) // ""
```

将打印空字符串，而非导致错误或不可预测行为。Go 程序员常致力于使复杂类型的零值具有意义，以便变量一诞生即处于有用状态。

可在单个声明中声明并可选初始化一组变量，配合匹配的表达式列表。省略类型允许声明不同类型的多个变量：

```go
var i, j, k int                 // int, int, int
var b, f, s = true, 2.3, "four" // bool, float64, string
```

初始化表达式可以是字面值或任意表达式。包级变量在 `main` 开始前初始化（§2.6.2），局部变量在函数执行遇到其声明时初始化。

一组变量也可通过调用返回多值的函数来初始化：

```go
var f, err = os.Open(name) // os.Open returns a file and an error
```

### 2.3.2 指针

*变量* 是一块包含值的存储区域。通过声明创建的变量由一个名字标识，例如 `x`，但许多变量仅通过诸如 `x[i]` 或 `x.f` 之类的表达式来标识。所有这些表达式都读取变量的值，除非它们出现在赋值语句的左侧，在这种情况下会给变量赋予一个新值。

*指针* 值是一个变量的 *地址*。因此，指针是存储值的位置。并非每个值都有地址，但每个变量都有。通过指针，我们可以 *间接* 地读取或更新变量的值，而无需使用甚至知道该变量的名字（如果它确实有名字的话）。

如果一个变量声明为 `var x int`，表达式 `&x`（“`x` 的地址”）将产生一个指向整数变量的指针，即类型为 `*int` 的值，读作“指向 int 的指针”。如果这个值被称为 `p`，我们就说“`p` 指向 `x`”，或者等价地说“`p` 包含 `x` 的地址”。`p` 所指向的变量写作 `*p`。表达式 `*p` 产生该变量的值，即一个 `int`，但由于 `*p` 表示一个变量，它也可能出现在赋值语句的左侧，在这种情况下赋值会更新该变量。

```go
x := 1
p := &x         // p, of type *int, points to x
fmt.Println(*p) // "1"
*p = 2          // equivalent to x = 2
fmt.Println(x)  // "2"
```

聚合类型变量的每个组成部分——结构体的字段或数组的元素——也是一个变量，因此也拥有地址。

变量有时被描述为 *可寻址* 的值。表示变量的表达式是唯一可以应用 *取地址* 操作符 `&` 的表达式。

任何类型指针的零值都是 `nil`。如果 `p` 指向一个变量，则测试 `p != nil` 为真。指针是可比较的；当且仅当两个指针指向同一个变量或两者都是 nil 时，它们才相等。

```go
var x, y int
fmt.Println(&x == &x, &x == &y, &x == nil) // "true false false"
```

函数返回局部变量的地址是完全安全的。例如，在下面的代码中，由对 `f` 的这次特定调用创建的局部变量 `v` 即使在调用返回后仍将继续存在，指针 `p` 仍将引用它：

```go
var p = f()

func f() *int {
    v := 1
    return &v
}
```

每次调用 `f` 都会返回一个不同的值：

```go
fmt.Println(f() == f()) // "false"
```

因为指针包含变量的地址，将指针参数传递给函数使得函数能够更新被间接传递的变量。例如，此函数增加其参数所指向的变量的值，并返回该变量的新值，以便可在表达式中使用：

```go
func incr(p *int) int {
    *p++ // increments what p points to; does not change p
    return *p
}

v := 1
incr(&v)              // side effect: v is now 2
fmt.Println(incr(&v)) // "3" (and v is 3)
```

每当我们获取一个变量的地址或复制一个指针时，我们都会为同一个变量创建新的 *别名* 或标识方式。例如，`*p` 是 `v` 的别名。指针别名很有用，因为它允许我们在不使用变量名的情况下访问变量，但这是一把双刃剑：要找到所有访问某个变量的语句，我们必须知道它的所有别名。不仅仅是指针会创建别名；当我们复制其他引用类型的值时，如切片、映射和通道，甚至包含这些类型的结构体、数组和接口，也会发生别名现象。

指针是 `flag` 包的关键，该包利用程序的命令行参数来设置分布在整个程序中的某些变量的值。为了说明这一点，这个早期 `echo` 命令的变体接受两个可选标志：`-n` 导致 `echo` 省略通常会打印的尾随换行符，而 `-s sep` 导致它使用字符串 `sep` 的内容分隔输出参数，而不是默认的单个空格。因为这是我们的第四个版本，所以该包称为 `gopl.io/ch2/echo4`。
