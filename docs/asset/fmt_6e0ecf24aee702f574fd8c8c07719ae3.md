
*   `NaiveBayes` 执行经典贝叶斯预测，做出所有属性相互独立的朴素假设。详见第 6.2.3 节。

*   `NaiveBayesMultinomial` 多项式朴素贝叶斯分类器详见第 6.2.4 节。

### 12.2.4 决策树

*   `HoeffdingTree` 适用于无变化数据流的决策树诱导器，详见第 6.3.2 节。要在叶节点使用多数类学习器，请使用 `HoeffdingTree -l MC`。

*   `DecisionStump` 仅含单个内部节点的决策树，因此仅测试一个属性来预测实例。

*   `HoeffdingOptionTree` Hoeffding 选项树，详见第 7.6.1 节。可以选择放置在叶节点的分类器类型：多数类、朴素贝叶斯或自适应朴素贝叶斯。默认选择自适应朴素贝叶斯，因为它往往能给出最佳结果；它监控多数类和朴素贝叶斯预测器的错误率，并跟踪近期实例上表现较好的预测器进行切换。要在叶节点使用多数类学习器运行实验，请使用 `HoeffdingOptionTree -l MC`。

*   `HoeffdingAdaptiveTree` 适用于演变数据流的决策树诱导器，详见第 6.3.5 节。

*   `AdaHoeffdingOptionTree` 适用于流式数据的自适应 Hoeffding 选项树，叶节点使用自适应朴素贝叶斯分类器 [38]。自适应 Hoeffding 选项树 是一种具有以下改进的 Hoeffding 选项树：每个叶节点存储当前错误的估计值，使用 `α` = 0.2 的 EWMA 计数器进行估计。投票过程中每个节点的权重与其错误的倒数平方成正比。

### 12.2.6 函数分类器

*   `MajorityClass` 始终预测在训练数据中观察到频率最高的类别。

*   `NoChange` 它预测用于训练模型的最后一个实例中观察到的类别。

*   `Perceptron`，单感知机分类器。以增量方式执行经典的多类感知机学习。

### 12.2.7 漂移分类器

*   `SingleClassifierDrift` 用于处理概念漂移数据流的分类器，基于使用变化检测器来监控分类器的错误。当变化检测器发出警告信号时，会创建一个新分类器；当发出变化信号时，当前分类器将被新分类器替换。这是 Gama 等人 [114] 提出的 DDM 方法中的策略，详见第 5.3.4 节。可以使用多种漂移检测方法：

    *   `CusumDM` 和 `PageHinkleyDM`，见第 5.3.2 节。

    *   `DDM`，见第 5.3.4 节。

    *   `EDDM`，基于分类错误间距离的估计分布，见文献 [22]。

    *   `ADWINChangeDetector`，见第 5.3.5 节。

    *   `EWMAChartDM`，基于使用指数加权移动平均（EWMA）控制图 [216]，见第 5.3.4 节提及。

    *   `GeometricMovingAverageDM`，基于使用几何移动平均估计。

    *   `HDDM_A_Test` 和 `HDDM_W_Test`，基于使用 Hoeffding 界，见文献 [44]。

    *   `SEEDChangeDetector`，基于检测波动率偏移，见文献 [136]。

    *   `SeqDrift1ChangeDetector` 和 `SeqDrift2ChangeDetector`，第一个基于比较滑动窗口中的数据和存储库中的数据，第二个基于比较水库中的数据和存储库中的数据，见文献 [196, 220]。

    *   `STEPD`，基于使用比例相等的统计检验，见文献 [186]。

### 12.2.8 主动学习分类器

*   `ActiveClassifier` 用于主动学习的分类器，旨在在不请求超过其预算允许的标签数量的前提下学习一个准确的模型。该分类器可以使用多种显式处理概念漂移的主动学习策略，详见第 6.8 节。

## 13 使用命令行

如前一章所述，MOA 方法和任务既可以通过 GUI 使用，也可以使用 CLI。对于分类和回归，GUI 中使用的任务命令可以直接在 CLI 中使用。在本章中，我们将展示如何从命令行运行这些任务以及其他任务。

运行任务就像从命令行调用 `moa.DoTask` 命令一样简单。例如，要运行 `LearnModel` 任务，只需输入

```java
java -cp moa.jar -javaagent:sizeofag.jar moa.DoTask LearnModel
```

……参数……

在接下来的章节中，我们将看到这种用法的具体示例。

### 13.1 分类和回归的学习任务

第一个示例将命令 MOA 训练 `HoeffdingTree` 分类器并创建一个模型。`moa.DoTask` 类是命令行运行任务的主类。它将接受任务名称以及任何适当的参数。我们将使用的第一个任务是 `LearnModel` 任务。`-l` 参数指定学习器，在本例中为 `trees.HoeffdingTree` 类。`-s` 参数指定用于学习的数据流，在本例中为 `generators.WaveformGenerator`，生成一个三类学习问题。`-m` 选项指定用于训练学习器的最大示例数，在本例中为 1,000,000 个示例。`-O` 选项指定一个文件以输出生成的模型：

```java
java -cp moa.jar -javaagent:sizeofag.jar moa.DoTask \
LearnModel -l trees.HoeffdingTree \
-s generators.WaveformGenerator -m 1000000 -O model1.moa
```

这将创建一个名为 `model1.moa` 的文件，其中包含训练期间诱导的树模型。

### 13.2 分类和回归的评估任务

下一个示例将评估模型，以计算其在使用不同随机种子生成的一组示例上的准确性。`EvaluateModel` 任务获得加载上一步生成的模型所需的参数，使用随机种子 2 生成新的波形流，并在另外 1,000,000 个示例上进行测试：

```java
java -cp moa.jar -javaagent:sizeofag.jar moa.DoTask \
"EvaluateModel -m file:model1.moa \
-s (generators.WaveformGenerator -i 2) -i 1000000"
```

请注意使用括号的嵌套参数。任务描述周围添加了引号，否则操作系统可能会被括号搞混。

评估后将输出以下统计信息：

```text
classified instances = 1,000,000
classifications correct (percent) = 84.474
Kappa Statistic (percent) = 76.711
```

请注意，上述两个步骤可以合二为一，避免创建外部文件，如下所示：

```java
java -cp moa.jar -javaagent:sizeofag.jar moa.DoTask \
"EvaluateModel -m (LearnModel -l trees.HoeffdingTree \
-s generators.WaveformGenerator -m 1000000) \
-s (generators.WaveformGenerator -i 2) -i 1000000"
```

MOA 将在内存中创建并使用分类器，而不将其存储在文件中。

### 13.3 分类和回归的学习与评估任务

`EvaluatePeriodicHeldOutTest` 任务将在定期间隔使用留出测试集拍摄性能快照的同时训练模型。以下命令创建一个 CSV 文件，在 `WaveformGenerator` 数据上训练 `HoeffdingTree` 分类器，保留前 100,000 个示例用于测试，总共训练 100,000,000 个示例，并每 1,000,000 个示例在留出集上测试一次：

```java
java -cp moa.jar -javaagent:sizeofag.jar moa.DoTask \
"EvaluatePeriodicHeldOutTest -l trees.HoeffdingTree \
-s generators.WaveformGenerator \
-n 100000 -i 100000000 -f 1000000" > dsresult.csv
```

为了进行比较，可以在同一个问题上训练一个使用 10 棵决策树的 Bagging 学习器：

```java
java -cp moa.jar -javaagent:sizeofag.jar moa.DoTask \
"EvaluatePeriodicHeldOutTest -l (OzaBag -l trees.HoeffdingTree \
-s 10) -s generators.WaveformGenerator \
-n 100000 -i 100000000 -f 1000000" > htresult.csv
```

MOA 中实现的另一种评估方法是交错测试后训练。它能生成随时间变化更平滑的准确率图表，因为每个单独的示例对总体平均值的意义越来越小。下面是一个 `EvaluateInterleavedTestThenTrain` 任务的示例，它创建一个 CSV 文件，在 `WaveformGenerator` 数据上训练 `HoeffdingTree` 分类器，总共训练和测试 100,000,000 个示例，并每 1,000,000 个示例记录一次准确率：

```java
java -cp moa.jar -javaagent:sizeofag.jar moa.DoTask \
"EvaluateInterleavedTestThenTrain -l trees.HoeffdingTree \
-s generators.WaveformGenerator \
-i 100000000 -f 1000000" > htresult.csv
```

### 13.4 比较两个分类器

假设我们要比较两个分类器的学习曲线：决策树桩和霍夫丁树。首先，我们必须执行 `EvaluatePeriodicHeldOutTest` 任务，以便在定期间隔使用留出测试集拍摄性能快照的同时训练模型。以下命令创建 CSV 文件，在 `WaveformGenerator` 数据上训练 `DecisionStump` 和 `HoeffdingTree` 分类器，使用 1,000 个示例进行留出测试，总共训练 100,000 个示例，并每 10,000 个示例测试一次：

## 14 使用 API

可以通过调用 MOA 的 API 从外部 Java 代码中使用 MOA。在 Java 应用程序中使用 MOA 的生成器、方法和任务非常容易。在本章中，我们将展示如何使用 MOA API 并在程序中包含流式机器学习功能。我们假设读者具备基本的 Java 和面向对象编程知识。

### 14.1 MOA 对象

MOA API 提供的基本对象包括：

*   `Task`（任务）：MOA 中的所有任务都遵循此接口。所有将结果写入文件的任务必须扩展 `MainTask` 并实现 `doMainTask` 方法。

*   `InstanceStream`（实例流）：MOA 中使用的流使用此接口。要使用流，请调用 `prepareForUse` 进行准备，然后调用 `nextInstance` 从流中获取每个新实例。

*   `Classifier`（分类器）：分类器应扩展 `AbstractClassifier`。要使用分类器，首先调用 `prepareForUse` 进行准备，然后使用 `trainOnInstance` 通过新实例训练模型，或使用 `getVotesForInstance` 获取实例的分类预测。

### 14.2 选项

#### MOA 类与选项处理

带有参数或选项的 MOA 类必须继承 `AbstractOptionHandler` 类。这些选项可以是以下类型：

*   **Integer**：`IntOption` (name, char, purpose, default Value, min Value, max Value)
*   **Float**：`FloatOption` (name, char, purpose, default Value, min Value, max Value)
