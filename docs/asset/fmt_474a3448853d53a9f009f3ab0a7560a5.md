```
# Read the dataset
spice_consumption <- read.csv("Spice_Consumption.csv")

# Arrange the data in descending order of Value and subset the top 10 countries
spice_top10 <- spice_consumption %>%
  arrange(desc(Value)) %>%
  slice_head(n = 10)
```

条形图的 `ggplot2` 模板遵循一个直观的结构。我们将创建一个条形图来可视化香料消费量最高的前 10 个国家。

```
# Distribution of Spice Consumption
ggplot(spice_top10, aes(x = Country, y = Value)) +
  geom_bar(stat = "identity")
```

`ggplot()` 函数为图形创建一个空白画布，而 `aes()` 函数定义数据的美学映射。在本例中，我们将 `Country` 列映射到 x 轴，将 `Value` 列映射到 y 轴。最后，`geom_bar()` 函数向图形添加条形图，使用 `stat = "identity"` 参数指定我们要使用实际数值渲染条形。

垂直条形图的一个常见问题是，标识每个条形的标签可能占据大量水平空间，导致图表中文本重叠且难以辨认。上图显示一些国家名称重叠，无法轻松阅读。解决此问题的一种方法是旋转 x 轴标签。然而，这种方法往往会导致图形外观别扭，需要图表下方过多的空间，同样难以阅读。

```
# Distribution of Spice Consumption
ggplot(spice_top10, aes(x = Country, y = Value)) +
  geom_bar(stat = "identity") +
  theme(axis.text.x = element_text(angle = 90, vjust = 0.5, hjust = 1))
```

![](img/Figure7.3.png)

图 7.3：香料消费量条形图

`ggplot2` 代码片段中的最后一条命令通过更改字体属性来修改 x 轴标签的外观。`theme()` 函数可自定义绘图的各种视觉样式方面。在本例中，`axis.text.x` 参数指定我们要修改 x 轴标签。`element_text()` 使用以下参数为 x 轴标签创建一个新的文本元素：

*   `angle = 90`：将文本顺时针旋转 90 度，使其垂直排列。
*   `vjust = 0.5`：调整文本的垂直对齐方式。在此语境下，它使标签垂直居中。
*   `hjust = 1`：调整文本的水平对齐方式。值为 1 表示右对齐。

解决条形图中长标签挑战的一种更有效方法，通常是交换 x 轴和 y 轴，使条形呈水平方向。这种重新定向缓解了标签重叠的问题，并提供了更清晰、更节省空间的数据表示。

要在 `ggplot2` 中实现此解决方案，我们可以使用 `coord_flip()` 函数，它交换 x 轴和 y 轴，将垂直条形图转换为水平条形图。这解决了 x 轴标签拥挤的问题，并提供了更美观的数据表示。

```
# 香料消费量分布
ggplot(spice_top10, aes(x = Country, y = Value)) +
  geom_bar(stat = "identity") +
  coord_flip()
```

![](img/Figure7.4.png)

图 7.4：香料消费量条形图

无论条形是垂直还是水平排列，其排列顺序都至关重要。随机或任意的排列会导致混淆，使图表不够直观。在 R 中，默认排列是标签的字母顺序，这并不总是组织数据最有意义的方式。以香料消费量图表为例，按香料消费量的顺序重新排列条形更有意义。通过以这种方式重新排列条形，我们可以创建更有效的可视化效果，帮助读者一目了然地理解数据。

```
# 香料消费量分布
ggplot(spice_top10, aes(x = fct_reorder(Country, Value), y = Value)) +
  geom_bar(stat = "identity", fill = "steelblue3") +
  labs(title = "Spice Consumption",
       x = "Country",
       y = "Spice Consumption (kt)") +
  coord_flip() +
  theme_bw()
```

![](img/Figure7.5.png)

图 7.5：香料消费量条形图

让我们探讨一下上述代码中用于更有意义、更易解释地呈现数据的一些新函数和参数。

*   `fct_reorder(Country, Value)`：这是 `forcats` 包的一部分，用于根据 `Value` 列中的值重新排序 `Country` 因子的水平。这意味着条形图中的条形将按香料消费量递减的顺序排列。
*   `fill = "steelblue3"`：此参数指定用于填充图表中条形的颜色。此处，`fill` 参数设置为 `"steelblue3"`。
*   `labs()` 函数为绘图的坐标轴和标题添加标签。它将绘图标题设置为 Spice Consumption，x 轴标签设置为 Country，y 轴标签设置为 Spice Consumption (kt)。
*   `theme_bw()` 函数为绘图应用黑白主题。`ggplot2` 中的 `theme_` 函数是一组允许用户自定义绘图视觉外观的函数。`ggthemes` 包通过提供具有特定样式的其他预定义主题，扩展了 `ggplot2` 中的主题选项。您可以轻松地将这些主题应用于 `ggplot2` 绘图，以获得美观的外观。

必须注意的是，只有当条形所代表的类别没有自然顺序或层级时，我们才应重新排列条形。如果类别已经有意义地排序（例如，如果我们的分类变量是有序因子），则建议在可视化中保留该顺序。

### 直方图

直方图是连续数据分布的图形表示。直方图是通过将 x 轴划分为等距的区间（称为箱）来创建的。直方图中每个条形的高度代表落在相应箱内的数据点数量。这创建了一个显示数据频率分布的图表，揭示了数据在数值范围内的分布情况。

它们可以告诉我们数据是对称的、向左或向右偏斜的，还是有多个峰值。这些信息对于识别数据中的模式和离群值至关重要。离群值是不遵循其余数据总体模式的观测值，可能表明错误、异常或有趣的现象。通过检查直方图，我们可以轻松发现离群值，并决定它们是否值得进一步调查。

在 `ggplot2` 中，您可以使用 `binwidth` 参数设置区间的宽度。尝试不同的箱宽以找到最能说明数据潜在结构的最佳区间大小至关重要。您也可以选择使用 `bins` 参数指定箱的数量，默认设置为 30。

现在，我们将从 FAOSTAT 导入一个营养不良指标数据集，并创建 173 个国家营养不良患病率的直方图。联合国粮农组织（FAO）将营养不良患病率（PoU）定义为一个估计值，代表常规食物摄入量低于维持正常、活跃和健康生活所需的膳食能量水平的人口百分比。以下代码生成直方图以可视化 2021 年营养不良患病率的分布。

```
# 读取数据集
undernourishment <- read.csv("undernourishment_data.csv")

# 筛选 2021 年数据
undernourishment_2021 <- undernourishment %>% filter(Year == 2021)

# 营养不良患病率分布
ggplot(undernourishment_2021, aes(x = Value)) +
  geom_histogram(binwidth = 2, fill = "steelblue3", color = "black") +
  labs(title = "Prevalence of Undernourishment",
       x = "Prevalence (%)",
       y = "Frequency") +
  theme_bw()
```

![](img/Figure7.6.png)

图 7.6：营养不良患病率分布

> **注意：** 在 FAO 数据集中，营养不良率低于 2.5% 的国家和地区被归类为 2.5%。

此处，`geom_histogram(binwidth = 2, fill = "steelblue3", color = "black")` 使用 `geom_histogram()` 向绘图添加直方图层。它将 x 轴划分为宽度为 2 的箱，并用 `"steelblue3"` 填充每个箱；每个箱的边框为黑色。

要在直方图的每个条形上方添加计数标签，可以使用统计变换函数 `stat_bin()`。它允许我们直接在相应条形顶部显示每个箱内的频率计数。这一简单的添加可以提供对潜在分布更精确的理解。它还可以帮助您准确比较不同箱以及跨不同数据集的情况。

```
# 营养不良患病率分布
ggplot(undernourishment_2021, aes(x = Value)) +

  labs(title = "Prevalence of Undernourishment",
       x = "Prevalence (%)",
       y = "Frequency") +
  stat_bin(aes(label = after_stat(count)),
           binwidth = 2,
           geom = "text", vjust = -0.5, color = "black", size = 3) +
  theme_bw()
```

### 可视化比例

有效传达一个群体、实体或数量分解为其组成部分是数据可视化中的常见任务。无论是描绘人口中的性别分布，还是选举中不同政党的得票份额，可视化比例在数据探索和沟通中都起着至关重要的作用。它帮助观众理解不同部分如何构成整体。

#### 饼图

饼图长期以来一直是比例或百分比的首选可视化方式，广泛用于商业演示和报告。其圆形布局和比例切片使其成为说明不同组成部分如何贡献于整体的流行选择。饼图能提供比例分布的总体概念，特别是在处理少量类别时。然而，数据科学家经常因以下几个缺点而批评饼图：

*   **难以比较比例**：当处理众多类别时，使用饼图比较比例变得越来越困难。
*   **人类感知局限**：人眼不适合准确判断饼图切片的相对大小，尤其是在处理小切片时。
*   **不利于突出变化**：饼图不适合可视化比例随时间或不同条件下的变化。

现在，让我们使用 `ggplot2` 创建一个饼图，以直观地描绘全球饥饿的地理分布。虽然 `ggplot2` 没有专门用于饼图的 `geom`，但我们可以通过变通方法创建一个。我们可以使用 `geom_bar()` 构建一个只有一个条形的堆叠条形图，然后使用 `coord_polar()` 将图表转换为圆形布局，从而得到一个饼图。可以把它想象成获取一个常规条形图并将其弯曲成一个圆，从而得到一个切片代表不同类别的饼图。

绘图中使用的默认坐标系是笛卡尔坐标系，其中每个点由其独立的 x 和 y 坐标定义。然而，还有两种额外的坐标系可用：专为绘制空间数据设计的 `coord_quickmap()`，以及利用极坐标的 `coord_polar()`。

让我们创建一个如下所示的简单饼图：

```r
hunger_2021 <- read.csv("hunger_2021.csv")

# Pie chart
ggplot(hunger_2021, aes(x = "", y = Value, fill = Region)) +
  geom_bar(stat = "identity", width = 1, color = "white") +
  coord_polar(theta = "y")
```

![](img/Figure7.9.png)

**图 7.9：饼图**

在这种情况下，我们通过在引号中指定空字符串来留空 x 轴。饼图切片基于 `Value` 变量绘制，每个切片根据相应的 `Region` 着色。默认情况下，它按类别的字母顺序逆时针绘制切片。`coord_polar(theta = "y")` 将绘图的坐标系设置为极坐标，这适合饼图。`theta = "y"` 表示每个切片的角度由 y 变量（`Value`）决定。

现在，如果你仔细观察上图，可能会注意到图表背景中有一些多余的东西。让我们去除它们，使其看起来更整洁。我们将通过函数 `theme_void()` 移除数字和网格线。可以把它想象成擦除除切片本身之外的所有内容。为了使切片突出，我们将通过在 `geom_bar()` 中添加 `color` 并根据营养不良人口规模重新排序图表，为每个切片添加边框。下图显示了各地区营养不良人口的分布。

```r
# Pie Chart displaying the undernourished population across different regions
ggplot(hunger_2021, aes(x = "", y = Value, fill = fct_reorder(Region, Value))) +
  geom_bar(stat = "identity", width = 1, color = "white") +
  coord_polar(theta = "y") +
  theme_void() +
  theme(legend.position = "bottom") +
  labs(title = "Undernourished People by Region", fill = "Region") +
  scale_fill_brewer(palette = "Set3") +
  geom_text(aes(x = 1.7, label = ifelse(Value >= 30, paste(Region, "\n", round(Value, 0), "M"), "")),
            position = position_stack(vjust = 0.5),
            size = 3, show.legend = FALSE)
```

![](img/Figure7.10.png)

**图 7.10：各地区营养不良人口分布**

让我们了解上述命令中使用的额外组件：

*   **布局与主题**
    *   `theme_void()`：移除不必要的背景元素，以获得更整洁的展示。
    *   `theme(legend.position = "bottom")`：将图例置于底部，以提高可读性。
*   **标签与颜色**
    *   `labs(title = "Undernourished People by Region", fill = "Region")`：为图表添加标题，并将填充（颜色）图例标记为 Region。
    *   `scale_fill_brewer(palette = "Set3")`：从 Set3 调色板中选择颜色调色板用于切片颜色。
*   **添加文本标签**
    *   `geom_text`：向图表添加文本标签。
    *   `aes(x = 1.7, label = ifelse(Value >= 30, paste(Region, "\n", round(Value, 0), "M"), ""))`：设置 x 位置和标签文本。标签有条件；如果 `Value` 大于或等于 3000 万，标签包含 Region 和 Value（四舍五入到最接近的整数并附加 M）；否则为空字符串。
    *   `position_stack(vjust = 0.5)`：将标签垂直居中定位在每个切片内。
    *   `size = 3`：设置文本大小。
    *   `show.legend = FALSE`：从图例中隐藏文本标签。

上图显示，亚洲是遭受饥饿人群的主要地区，2021 年有 4.14 亿人，占营养不良总人口的 56%。非洲拥有约 37%（2.71 亿）营养不良人口，而拉丁美洲和加勒比地区约占 6%（4600 万）。
