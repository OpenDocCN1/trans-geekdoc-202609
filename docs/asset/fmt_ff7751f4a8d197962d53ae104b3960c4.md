
本节讨论无向图模型上高效的推理技术。因此，即使我们的起点是 BN，我们也假设在推理任务之前它已被转换为无向图。我们将从图模型的最简单情况——由节点链组成的图——开始。这将帮助读者掌握精确推理方案背后的基本概念。值得注意的是，一般而言，图模型中的推理任务是一个 NP-hard 问题 [10]。此外，已证明对于一般 BN，将近似推理精确到所需的位数也是一个 NP-hard 任务 [11]；即所需时间随精度位数呈指数级增长。然而，正如我们将在许多实践中常见的案例中看到的那样，通过利用相关分布的底层独立性和因子分解特性，可以避免计算时间呈指数级增长。

感兴趣的推理任务包括 (a) 计算似然，(b) 计算涉及变量的边缘分布，(c) 计算条件概率分布，以及 (d) 寻找分布的众数。

项 $\mu_b(x_j)$ 是对 $x_{j+1}, x_{j+2}, \dots, x_l$ 求积后求和的结果，而项 $\mu_f(x_j)$ 则是对 $x_1, x_2, \dots, x_{j-1}$ 求积后求和的结果。在每个迭代步骤中，通过对一个变量的所有可能值求和，该变量被*消除*。遵循类似的论证可以很容易地证明，任意位置 $x_j$ ($2 \le j \le l-1$) 处的边缘分布由以下公式获得（问题 15.13）：

$$P(x_{j}) = \frac{1}{Z}\mu_{f}(x_{j})\mu_{b}(x_{j}),\quad j = 2,3,\ldots,l - 1.$$

(15.42)

其思路是执行一次正向和一次反向消息传递操作，存储这些值，然后计算任意感兴趣的边缘分布。总计算代价将为 $\mathcal{O}(2K²l)$，而不是朴素方法的 $K^{(l)}$。

我们仍然需要计算归一化常数 `Z`。这可以通过对公式 (15.42) 两边求和来轻松完成，这需要 `𝒪(K)` 次操作，

```
Z = \sum\limits_{x_{j} = 1}^{K}\mu_{f}(x_{j})\mu_{b}(x_{j}).
```

到目前为止，我们已经讨论了边缘概率的计算。现在让我们将注意力转向它们的条件对应物。我们从最简单的情况开始，例如计算 `P(x[j]|x[k] = \hat{x}[k])`，`k ≠ j`。也就是说，我们假设变量 `x[k]` 已被观测，其值为 `\hat{x}[k]`。计算条件概率的第一步是恢复联合概率 `P(x[j], x[k] = \hat{x}[k])`。这是相应条件概率的一个归一化版本，随后可通过以下方式获得：

```
P(x_{j}|x_{k} = {\widehat{x}}_{k}) = \frac{P(x_{j},x_{k} = {\widehat{x}}_{k})}{P({\widehat{x}}_{k})}.
```

#### 树结构无向图模型

在积累了开发链式结构高效推理算法的经验并掌握了基本原理后，我们将关注点转向更一般的情况：涉及**树结构**无向图模型的情形。

树是一种图，其中任意两个节点之间仅存在一条链/路径；因此，图中不存在环路。图 15.24A 和 15.24B 展示了树的两个示例。树可以是有向的，也可以是无向的。注意，在有向树中，任意节点仅有一个父节点，且存在单个无父节点的**根节点**。此外，由于有向树中不存在拥有两个父节点的子节点，道德化步骤（将有向图转换为无向图）不会增加额外的连接。唯一的变化是将边变为无向。

![Figure 15.24 Examples of (A) directed and (B) undirected trees. Note that in the directed one, any node has a single parent. In both cases, there is only a single chain that connects any two nodes. (C) The graph is not a tree because there is a cycle.](img/gr024.jpg)

**图 15.24** (A) 有向树和 (B) 无向树的示例。注意在有向树中，任意节点仅有一个父节点。在两种情况下，连接任意两个节点的链均唯一。(C) 该图不是树，因为存在环路。

树具有一项重要性质，这对我们当前的需求至关重要。设树图为 $T$，它由顶点/节点集合 $V$ 和连接节点的边集合 $E$ 组成，即 $T = \{V, E\}$。考虑任意节点 $x \in V$ 及其所有邻居节点的集合，即所有与 $x$ 共享一条边的节点。记该集合为

$$\mathcal{N}(x) = \{y \in V : (x, y) \in E\}.$$

观察图 15.24B，我们有 $\mathcal{N}(x) = \{y, u, z, v\}$。然后，对于集合中的**每个**元素 $r \in \mathcal{N}(x)$，定义子图 $T[r] = \{V[r], E[r]\}$，使得该子图中的**任意**节点均可通过**不经过** $x$ 的路径从 $r$ 到达。在图 15.24B 中，与元素 $(y, u, z, v)$ 中每一个相关联的子图均用虚线圈出。根据树的定义，容易推断这些子图中的每一个也是一棵树。此外，这些子图是**不相交**的。换句话说，一个节点（例如 $x$）的**每个**邻居节点均可视为一棵子树的**根**，且这些子树互不相交，没有公共节点。这一性质将使我们能够将大问题分解为若干较小的问题。而且，每个较小的问题本身也是一棵树，可进一步以相同方式分解。我们现在已具备推导树上高效推理方案的所有基本要素（回顾一下，将大问题分解为一系列小问题是链式结构消息传递算法的核心）。不过，让我们首先引入因子图的概念。原因在于，使用因子图使我们能够处理一些更一般的图结构，例如**多树**。

有向多树是一种虽然无环路，但子节点可能拥有多个父节点的图。图 15.25A 展示了一个多树示例。道德化步骤后会出现不利情况：父节点“联姻”导致产生环路，我们**无法**在有环图中推导出**精确**推理算法（见图 15.25B）。然而，若将原始有向多树转换为因子图，所得的二部实体将具有树结构，不涉及环路（见图 15.25C）。因此，我们之前关于树结构的论述均适用于这些因子图。

### 15.7.3 求和-乘积算法

我们将通过一个示例，采用“自底向上”的方法开发树结构中精确推断的算法。一旦理解了基本原理，即可轻松得到推广形式。让我们考虑图 15.26 的因子树。因子节点用大写字母和方框表示，每个因子节点关联一个势函数。其余为变量节点，用圆圈表示。假设我们要计算边缘概率 `P(x[1])`。节点 `x[1]` 作为变量节点，仅与因子节点相连。我们将图分割为与 `x[1]` 相连的因子节点数量相同的（树）子图（本例中为三个）。在图中，这些子图分别被圈出，其根节点分别为 A、H 和 G。回顾一下，联合概率 `P(x)` 由所有势函数的乘积给出，每个势函数关联一个因子节点，再除以归一化常数 `Z`。聚焦于感兴趣的节点 `x[1]`，该乘积可写为

```
P(x) = (1/Z) * ψ_A(x_1, x_A) * ψ_H(x_1, x_H) * ψ_G(x_1, x_G)
```

其中 `x[A]` 表示 `T[A]` 中所有变量对应的向量；向量 `x[H]` 和 `x[G]` 定义方式类似。函数 `ψ_A(x_1, x_A)` 是 `T[A]` 中所有因子节点关联势函数的乘积，`ψ_H(x_1, x_H)` 和 `ψ_G(x_1, x_G)` 以类似方式定义。则感兴趣的边缘概率由下式给出

$P(x_{1}) = \frac{1}{Z}\sum\limits_{\mathbf{x}_{A} \in V_{A}}\sum\limits_{\mathbf{x}_{H} \in V_{H}}\sum\limits_{\mathbf{x}_{G} \in V_{G}}\psi_{A}(x_{1},\mathbf{x}_{A})\psi_{H}(x_{1},\mathbf{x}_{H})\psi_{G}(x_{1},\mathbf{x}_{G}).$

![Equation](img/si277.png)(15.46)

我们将重点关注以 A 为根的子树，记为 $T[A] := \{V[A], E[A]\}$，其中 $V[A]$ 代表 $T[A]$ 中的节点，$E[A]$ 代表相应的边集。因为这三个子树是不相交的，所以我们可以将公式 (15.46) 中的前一个表达式拆分为

$P(x_{1}) = \frac{1}{Z}\sum\limits_{\mathbf{x}_{A} \in V_{A}}\psi_{A}(x_{1},\mathbf{x}_{A})\sum\limits_{\mathbf{x}_{H} \in V_{H}}\psi_{H}(x_{1},\mathbf{x}_{H})\sum\limits_{\mathbf{x}_{G} \in V_{G}}\psi_{G}(x_{1},\mathbf{x}_{G}).$

![Equation](img/si281.png)(15.47)

注意 `x[1] ∉ V[A] ∪ V[H] ∪ V[G]`。在保留符号 `ψA` 以表示子树 `T[A]` 中所有势函数的乘积（`T[H]` 和 `T[G]` 同理）的情况下，让我们用符号 `f` 来表示因子节点各自的势函数，如图 15.26 所示。因此，我们现在可以写成

$$
