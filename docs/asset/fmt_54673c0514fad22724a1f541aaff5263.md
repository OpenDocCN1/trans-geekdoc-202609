## 1.3 相关工作

拒绝服务（DoS）攻击已被广泛认为是互联网的严峻威胁。攻击者通过向目标网络涌入大量流量，导致网络服务不稳定或完全不可用。识别这些攻击对于防止其再次发生至关重要。为了完成这项任务，必须评估隐藏、模拟或伪造攻击的可利用性。在信息技术领域，这被称为信息学回溯劣势（informatics Trace back disadvantage）。数据包标记是通过路由器在沿沿攻击路径传输的数据包中放入自标识性数据来实现的。在 PPM 路由器中，数据包用概率分布进行标记。受害者节点接收到的标记数据包数量决定了其重建攻击路径的能力。我们发现，在分析 PPM 中所有路由器的特定标记概率效能时，来自远程路由器的标记数据包极有可能被下游路由器注意到。整体结果是数据包数量减少，而数据量却增加。通过允许每个路由器调节标记概率，可以实现更均匀的分布。动态技术的目标是在确定路由器在攻击路径中的位置时考虑位移因素。然而，许多方法依赖于底层协议，需要使用路由器来管理关于庞大网络中潜在受害的数据。这增加了路由器的开销并消耗了大量时间。正如本研究所示，我们非常希望提出一种方法，根据信息头内部的 8 位 TTL 字段动态设置标记概率值，该字段可以直接被路由器访问，无需外部协助。我们可以使用预测的 TTL 值作为确定数据包放置在攻击路径何处的技术，并利用 TTL 值作为对数据包所覆盖距离的估算来推导出标记概率值。我们创建了一个用户友好的计算机，通过模拟各种测试场景来模拟该算法。我们的动态方案在路由器和目标端消耗更少资源的同时，更精确地重建攻击路径，这是成功的。该方案预期的主要优势是其简单性和低路由器开销，但通过采用产生相似结果并在广泛攻击范围内性能优于静态方法的动态方法，可能会获得巨大的价值。

### 1.3.1 概率数据包标记 (PPM)

新方法具有增加网络开销、路由器处理和节点处理的潜力。近年来出现了许多备受关注的解决方案，包括使用概率数据包标记（PPM）。在该领域引入副学学习以扩展概率数据包标记主题，该主题极大减少了重建攻击者路径所需的数据包数量。

#### 1.3.1.1 DoS 攻击

拒绝服务（DoS）攻击可能证明是网络连接的严重障碍。如果将伪造的 IP 地址反射回其原始源，就可以避免某些拒绝服务攻击，从而对犯罪者进行惩罚或对攻击进行研究。为了对抗拒绝服务攻击，设计了 IP 回溯算法以允许概率数据包标记（PPM）。

与选定数据包标记和电子消息方案相比——由于攻击者伪造了数据包中的标记字段，这些方案难以回溯——Kihong Park *等人* [\[1\]](#c01.xhtml#ref1) 计划概率数据包标记（因其效能和实现能力而受到关注）将带来显著的投资回报（ROI）。

#### 1.3.1.2 FDPM

根据 Yang Xiang *等人* [\[2\]](#c01.xhtml#ref2)，提出了一种名为柔性确定性标记（FDPM）的独特策略，用于处理大规模 IP 回溯攻击，这在未来可能有效减少 DDoS 攻击的受害性。在 DDoS 攻击期间，目标站点或网络持续受到虚假 IP 数据包的轰炸。IP 回溯技术允许您将 IP 数据包追溯到其源点。FDPM 通过为追踪 IP 数据包提供多个可调选项（包括概率数据包标记 PPM 和确定性数据包标记 DPM）改进了数据包追踪。

#### 1.3.1.3 通过扩展 ns2 建立仿真环境

开发用于在各种网络条件和恶意攻击模式下测量回溯 IP 地址所需时间的模拟环境和方法论至关重要。本文提供了各种 PPM 算法的比较，以及如重建攻击者路径所需的数据包数量、计算质量和误报率等指标。

为了模拟各种 PPM 方法，Li *等人* [\[3\]](#c01.xhtml#ref3) 使用了 ns2 的扩展版，结合攻击性拓扑结构和流量。该模拟技术也可用于测试模拟 DDoS 攻击对各种 PPM 系统的影响。

## 1.4 提议的方法

### 动态概率数据包标记

标记信息丢失、攻击路径重构困难、精确率低等问题，是概率数据包标记（PPM）最常见的后果之一。本研究利用了一种替换技术（DPPM），它进一步改进了原始预防方法（PPM）的性能。我们并没有建议固定的标记概率，而是先确定数据包是否被标记，然后从可用可能性中选择最可接受的标记概率。DPPM 的采用可能解决 PPM 的大部分技术难题。DPPM 在大多数领域都优于 PPM，仅有一个例外。

由于公共计算机的广泛使用和网络基础设施的扩展，互联网对现代生活以及社会经济领域产生了巨大影响。犯罪行为变得日益普遍，导致了巨大的财务损失。极易实施的分布式拒绝服务（DDoS）攻击对通信基础设施造成了破坏。针对互联网协议（IP）的监控技术可用于追踪补救攻击所需证据的传递。

拒绝服务（DoS）攻击是一种延迟或限制资源流的攻击。拒绝服务攻击也可以由人为错误、审美缺陷或计算机代码漏洞触发。资源不当利用的另一个例子是时间敏感任务的延迟。在这一定义领域，有资源测量、处理能力、磁盘空间和内存以及静态内存结构的示例。在 ANSI 2000 中等精度中，攻击（不应成功的攻击）被称为量子（安全）违背。由于 DoS 攻击的基础已经奠定，可以使用它。

### 1.4.1.1 直接 DDoS 攻击

大量的供应主机试图在发送攻击流量的同时防止受害者消耗资源或拒绝受害者访问资源。关联级代理是被黑客的服务器，用于在与 DDoS 攻击关联发送攻击流量（也称为守护进程、僵尸或机器人）。主节点是一组被标记为此类类的过时代理。DDoS 网络由一组链接的主节点代理集合组成，它们都已准备好在 DDoS 攻击期间帮助攻击者。直接 DDoS 攻击和反射攻击是两种分布式拒绝服务（DDoS）攻击。

### 1.4.1.2 分布式 DDoS 攻击

由于许多供应主机在发送攻击流量的同时试图关闭或篡改受害者提供的资源，攻击经常被延迟。在 DDoS 攻击期间，会利用被劫持的主机来传输攻击流量。主节点是一个具有过时代理集的受损主机操作。在 DDoS 攻击背景下，DDoS 网络定义为一组链接的主节点代理的分级集合，帮助攻击者以更少的精力组织 DDoS 攻击。反射攻击和直接命中是两种 DDoS 攻击。

### 1.4.1.3 反射 DDoS 攻击

在供应科学领域，从属僵尸（代理）将包含受害者地址的数据包提供给毫无防备的第三方，这些第三方相继地向受害者（未受感染的计算机，如 Web 服务器、DNS 服务器等）发送回复。（淹没受害者）反射攻击可以影响至少两个个人。由于需要额外的设备和涉及更大的带宽，反射攻击将更具破坏性。它也更难追踪。

## 1.5 修正概率数据包标记的回溯机制

互联网捕获了银行、商业、交通、医疗保健和通信等许多关键基本服务的部分或全部服务。根据当前数据，约有 4 亿主机连接到互联网，目前目前有超过 40 亿互联网用户。因此，任何网络中断对许多人来说都是极其不便的。DoS 攻击的性影响引起了科学家和研究人员的关注，导致了各种痛苦的过程。另一方面，对需要成千万台受损 PC 的高度分布式 DoS 系统的攻击大多数失败了。防御拒绝服务（DoS）攻击的关键阶段是回溯科学。

数据包标记技术用于以随机方式加密路由器内部数据包的边缘数据。之后，受害者通过已知受害情况使用康复方法构建攻击路径。在过去，科学领域规划了若干回溯程序。主要研究了概率数据包标记（PPM）方法。在一种极 PPM 技术中，路由器概率地在数据包上盖上其标识数据，允许目标通过组合几个具有相似特征的数据包来重建网络路径。由于终止条件没有明确指定，PPM 规则在现有系统中存在各种问题。有必要拥有必要的配置信息。

### 1.5.2 数据包标记

PPM 不需要消耗路由器存储资源，尽管在攻击树重建之前，它通常需要受害者接收一个超大数据包。另一方面，工作方案中用于攻击树恢复的数据包数量可能较低。尽管如此，工作计划在路由器上需要大量的负载和巨大的机箱空间。现在针对当前的溯源信息处理协议示例，让我们考虑添加 `RIHT`：一种混合信息处理溯源主题，通过计算 `p.mark` 值来查找数据流并寻找攻击。这项涉及到大量的计算，需要大量的时间。

### 1.5.3 路径选择

路径描述了指定的数据包或文件如何从交付点到达目的地。所有路由器的上行接口必须检测并存储在接口表中。接口表可以描述所选的源和目的。

### 1.5.4 数据包发送

在包或文件处理中，数据包交付如下：数据包通过提供的路由从源 LAN 到目的 LAN。当目的 LAN 接收数据包时，将检查其是否已送达。

### 1.5.5 数据包标记与日志

在每个数据包头部上，有一个五位区域设计为计数器。在我们的示例中，如果路由器决定以特定概率采样数据包 `P`，则 `P.counter` 设置为一，在路由器上保存某些数据，并将数据包最终发送到相邻路由器。因此，计数器值越高，攻击路径上的路由器存储 `P` 数据就越多。句话说，在攻击树恢复后，具有高计数器值的数据包是有利的。因此，如果我们倾向于以概率方式将高计数器值的数据包相对于低计数器值的数据包。

### 1.5.6 路径重建

在使用 `Formula 3` 时，数据包到达目的地后，它将检查确定是否是从正确的上行接口广播的。如果检测到攻击，攻击将尝试重建路由。路径重建是为持续供应发现新路径的过程，结果是产生一个无法被攻击的目的地。

现在的每一次重大网络攻击都包含 DoS 或 DDoS 攻击。虽然相对容易发生，但可能会造成重大损害。DoS 攻击消耗大量的系统资源，导致用户无法使用常规服务。虽然电子邮件已成为最流行的通信模式，但 DDoS 攻击正变得越来越常见。

Lee 和 Fung 展示了如何利用主要基于公钥活动的认证方法进行 DoS 攻击。目前正在考虑许多针对 DoS 攻击的替代防御。Su *et al.* 设计了一种基于估计的相关攻击流量源初始特征的互联网策略，以限制 DDoS 攻击的危害。

Huang *et al.* 计划使用关联奖励、协作过滤和协作缓存来帮助 DDoS 攻击的受害者。因此，攻击源的位置至关重要。因为在路由器向当前协议发送数据包后，源地址并未被移除，我们选择不在攻击数据包的科学协议头中接受源地址。

## 1.6 结论

良好的包标记策略可以减少追踪胜利路径所需的数据包数量，并缩短识别错误者真实源的时间。数据包标记技术有两种：静态概率标记和动态概率主题。在 PPM 中，我们并不总是能从远程路由器获取足够的标记包，这在 IP 跟踪中引起许多问题，并延长了重建受害者的时间。我们开发动态概率替换方法的目标是在短时间内从远程路由器产生足够数量的标记包，以便进行更快、更可靠的溯源。
