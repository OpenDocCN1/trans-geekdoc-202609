### 3. 以下是在事件响应期间调取的的 HOSTS 文件：

以下哪种描述最能描述该 HOSTS 文件？

**A.** 机器上尝试访问 [mybank.com](https://www.mybank.com) 检查银行账户的用户将被重定向到一个中国 IP 地址。

**B.** 机器上尝试访问 [google.com](https://www.google.com) 的用户将收到 HTTP 400 状态码。

**C.** 机器上尝试访问 [gmail.com](https://www.gmail.com) 的用户将重定向到本地主机。

![Image](img/r.jpg) **A.** HOSTS 文件既是美之杰作，也是恐怖工具，这取决于你如何看待它。在任何 Windows 系统检查匹配名称请求的 IP DNS 之前，它会先检查 `HOSTS` 文件。例如，当用户在浏览器中输入 [www.mybank.com](https://www.mybank.com) 并按下 `ENTER` 时，Windows 会检查 `HOSTS` 文件查看是否存在 `mybank.com` 的映射。如果有，用户就会转到那里。如果没有，Windows 将向 DNS 请求一个要使用的 IP 地址。因此，如果你编辑了自己的 `HOSTS` 文件，你就可以自己避开许多广告流网站（只需将它们重定向到 localhost），并确保你的孩子不会意外进入他们不该去的地方。如果你拿到了目标的 `HOSTS` 文件，你就可以将他们发送到任何你想去的地方。

在这个示例中，似乎有人获取了这台特定机器的 `HOSTS` 文件，并对其进行了编辑，将一些常见的 URL 请求发送到中国的 IP 地址。也许他们设置了这些站点的伪造版本以获取凭据。或者他们只是想对用户进行 DoS 攻击。无论如何，访问 mybank.com、[google.com](https://www.google.com)、[gmail.com](https://www.gmail.com)、[amazon.com](https://www.amazon.com) 或 [facebook.com](https://www.facebook.com) 的尝试都会立即重定向到列出的中国 IP。用户避免这种情况的方法是使用 IP 地址而不是命名的 URL。

噢，还有一件事：我们如何知道它是中国 IP 地址？当然是通过 `Whois`，你可以在那里确定 `220.181.0.0/19` 网段分配给了 CHINANET（中国电信）。

![Image](img/w.jpg) **B** 是错误的，因为无法判断是否会出现 400 返回码（这意味着服务器由于明显的客户端错误，例如请求语法不正确、无效的请求消息帧或欺骗性的请求路由，而无法或拒绝处理请求）。如果请求是有效的（它应该是有效的），并且服务器能够将该请求注册为有效（这再次取决于坏人在那个特定 IP 上设置了什么），则不会返回 400 错误。

![Image](img/w.jpg) **C** 和 **D** 是错误的，因为这两者都不符合 `HOSTS` 文件条目中所采取的操作。

### 5. 以下哪项将从 NTFS 数据流中提取可执行文件？

**A.** `cat file1.txt:hidden.exe > visible.exe`

**B.** `more file1.txt | hidden.exe > visible.exe`

**C.** `type notepad.exe > file1.txt:hidden.exe`

**D.** `list file1.txt$hidden.exe > visible.exe`

![Image](img/r.jpg) **A.** 这是正确的语法。`cat` 命令将可执行文件直接提取到你执行该命令的文件夹中。NTFS 文件流（file streaming）允许你将几乎任何文件隐藏在任何其他文件之后，使其在目录搜索中变得不可见。该文件可以是一个文本文件，用于提醒你回到目标时需要采取的步骤，甚至可以是一个你以后可以空闲运行的可执行文件。以 NTFS 文件流形式存在的备用数据流（ADS）是 Windows 原生 NTFS 的一项功能，用于确保与 Apple 文件系统（称为 `HFS`）的兼容。在考试时要小心——你会看到 ADS 和 NTFS 文件流交替使用。顺便提一下，Windows 7 和 Windows 10 机器上没有 `cat` 命令（你需要 Linux 模拟器或类似的工具在这些机器上使用 `cat` 命令）。此外，你可以使用 `c:\> (more<file1.txt:hidden.exe) > output.txt` 作为另一种选择。这将读取隐藏流的输出并将其写入 `output.txt` 文件，而无需使用 `cat`。

![Image](img/w.jpg) **B** 是错误的，因为这不是正确的语法。在提取文件时没有管道（`|`）函数，且 `more` 命令用于显示文本文件的内容，而不是从 ADS 中提取可执行文件。

![Image](img/w.jpg) **C** 是错误的，因为这不是正确的语法。此选项将显示隐藏文本文件的内容——也许你已经在其中存储了指令以备后用。

### 6. 在 Linux 机器上使用哪个命令允许用户对特定文件拥有所有权限、组只读、其他所有人只读？

A. `chmod 411 file1`

B. `chmod 114 file1`

C. `chmod 117 file1`

D. `chmod 711 file1`

E. `chmod 744 file1`

![Image](img/r.jpg) **E.** 你需要了解一些基础 Linux 命令才能通过这次考试，我可以保证你会看到一道关于 `chmod` 的题目。Linux 中的文件权限通过使用每个 rwx 组的二进制等价值来分配：读等于 4，写等于 2，执行等于 1。要累计权限，将这些数字相加：`4` 是只读，`6` 是读写，在其中加上执行权限结果为 `7`。顺便提一下，如果你用二进制思考，这些数字的定义同样简单：`111` 等于十进制的 `7`，每个开启的位分别代表读、写和执行。将位设置为 `101` 则会开启读取、关闭写入并开启执行；其十进制等价值为 `5`。

![Image](img/w.jpg) **A, B, C,** 和 **D** 都是我们想要实现的实现的错误语法：`411` 等于只读、执行和执行，`114` 是后者的反过来，`117` 等于执行、执行和全权限，而 `711` 是其反过来。
