
## 示例：Rosenbrock 函数

```
∇f(x, y) = [-2(1 - x) - 400x(y - x²), 200(y - x²)]^T
```

以下是最速下降法的一些优缺点：

*   可从任意起始点收敛到局部最小值
*   收敛有时可能非常缓慢

直观上，最速下降法似乎是最小化函数的最佳方向。但事实并非如此！更通用的搜索方向被定义为线性方程组 `B * p = -∇f(x)` 的解，其中 `B` 是正定矩阵。为了使该解成为有效的搜索方向，它必须满足 `p^T * ∇f(x) < 0`。由于 `B` 的正定性，此条件成立。一个特例是选择 `B` 为 `x_k` 处的 Hessian 矩阵。如果 Hessian 矩阵在 `x_k` 处是正定的，这被称为 **Newton’s method（牛顿法）**。牛顿法的主要缺点是求 Hessian 矩阵逆矩阵的计算成本，以及确保 Hessian 逆矩阵为正定矩阵的成本。*Figure 3.20* 展示了牛顿法的收敛情况：

## 带约束的函数优化：拉格朗日乘数法

约束是对变量取值施加的限制，即优化问题的解被限制在函数定义域的一个子集内。例如，在经济学问题中，我们可能希望在约束 `g(x) = 0` 下最大化效用函数 `f(x)`。如果约束形式复杂，求解约束优化将非常困难。然而，对于某些较简单的约束形式，例如约束代表一条曲线或一个曲面，则可以用拉格朗日乘数法求解。

假设标量场 `f(x)` 在受约束于 `g(x) = 0` 时取得相对极值，其中 `g: R^n -> R^m`，则存在标量 `λ` 使得：

```
∇f(x) + λ^T ∇g(x) = 0
```

这些标量 `λ_i` 称为 *Lagrange multipliers（拉格朗日乘数）*；每个约束对应一个乘数。我们假设标量场 `f` 和约束条件均为可微函数。让我们从几何角度理解这一点。

设 `T(x, y, z)` 表示三维空间中的标量场温度函数。我们想要找到曲线 C 上的最大温度值。我们可以将 C 表示为两个曲面 `g_1(x, y, z) = 0` 和 `g_2(x, y, z) = 0` 的交集。因此，我们必须求解以下约束优化问题：

```
maximize T(x, y, z) subject to the constrains g_1(x, y, z) = 0 and g_2(x, y, z) = 0
```

梯度向量 `∇g_1` 和 `∇g_2` 必须分别垂直于对应的曲面，如 *Figure 3.21* 所示。在极值点，梯度向量 `∇T` 垂直于曲线 C。假设 C 由矢量值函数表示：

```
r(t) = [x(t), y(t), z(t)]^T
```

设 `T(t)` 表示曲线上的温度。最大温度值在 `dT/dt = 0` 或 `∇T · r'(t) = 0` 处达到。因此，`∇T` 必须垂直于曲线的切线 `r'(t)`，即垂直于曲线。

现在，由于三个向量 `∇T`、`∇g_1`、`∇g_2` 在极值点都垂直于曲线，它们必须位于同一平面内。所以，如果 `∇g_1`、`∇g_2` 是 **linearly independent（线性无关）**，我们可以写成 `∇T + λ_1∇g_1 + λ_2∇g_2 = 0`。请参考下图：

![](img/Figure-3.21.jpg)

**Figure 3.21:** *Constraint gradient and gradient of objective*

利用拉格朗日乘数，我们可以将约束优化问题转化为无约束问题。这个无约束问题多出 `m` 个待优化变量：乘数 `λ_i`。我们可以最小化函数：

```
L(x, λ) = f(x) + λ^T g(x)
```

该技术将广泛应用于我们在机器学习中将遇到的许多约束优化问题中。其中之一是机器学习模型的正则化，我们将在下一章讨论。

## 不等式约束下的优化

我们可以将优化问题写成如下一般形式：

```
minimize f(x) subject to g_i(x) = 0, i = 1...m
```

这里只有等式约束，对此我们可以应用拉格朗日乘数技巧。但如果有不等式约束如 `h_j(x) ≤ 0`，我们可以通过引入称为 *slack variables（松弛变量）* 的额外变量，将不等式约束转化为等式约束。

```
h_j(x) + s_j^2 = 0
```

假设 `s_j` 表示对应每个不等式约束的 `n` 个松弛变量。这些是正量，使得 `h_j(x) + s_j^2 = 0`。这样，我们将不等式约束转化为等式约束，并再次使用拉格朗日乘数将问题转化为无约束优化问题。此外，松弛变量为正。

```
L(x, λ, μ, s) = f(x) + Σ λ_i g_i(x) + Σ μ_j (h_j(x) + s_j^2)
```

其中 `μ_j ≥ 0`。

## 拉格朗日对偶函数

**Lagrange dual function（拉格朗日对偶函数）** `L` 定义为对于给定乘数 `λ, μ` 的任何值，Lagrangian 的最小值。

```
g(λ, μ) = inf_x L(x, λ, μ)
```

假设 `x` 是该问题的可行解，即 `g_i(x) = 0` 和 `h_j(x) ≤ 0`；则：

```
L(x, λ, μ) = f(x) + Σ λ_i g_i(x) + Σ μ_j h_j(x) = f(x)
```

因此，对于最优可行解 `x*`：

```
g(λ, μ) ≤ f(x*)
```

根据下确界定义：

```
g(λ, μ) ≤ f(x*) for all λ, μ with μ ≥ 0
```

此外，根据上确界定义，我们有：

```
sup_{λ, μ: μ ≥ 0} g(λ, μ) ≤ f(x*)
```

因此，我们得到一个新的优化问题：

```
maximize g(λ, μ) subject to μ ≥ 0
```

这称为与原始约束优化问题（称为 *primal problem（原始问题）*）相关的 *dual problem（对偶问题）*。我们称 `g(λ, μ)` 为 **Lagrange dual function**。

原始问题和对偶问题的最优值必须始终满足以下条件：

```
d* ≤ p*
```

这称为 *weak duality（弱对偶性）*。假设上述等式成立，则称为 *strong duality（强对偶性）*。当目标函数和约束具有特定形式，即它们是 *convex functions（凸函数）* 时，就会发生这种情况。在下一节中，我们将讨论凸函数和凸函数的优化。机器学习中遇到的许多优化问题都可以表述为凸优化问题。

## 凸函数

我们在上一章已经讨论过凸集。如果标量场 `f(x)` 的定义域是凸集，且对于任意两点 `x, y ∈ dom f` 和 `θ ∈ [0, 1]` 都有以下成立，则称其为凸函数：

```
f(θx + (1-θ)y) ≤ θf(x) + (1-θ)f(y)
```

如果 `– f` 是 **convex（凸）**，我们定义 `f` 为 **concave（凹）**。

**Examples:**

*   `e^{ax}` 对任意实数 `a` 为凸函数，`log(x)` 为凹函数。
*   `R^n` 中的每个范数都是凸函数，因为任何有效范数都遵循三角不等式：`||x + y|| ≤ ||x|| + ||y||`
*   `R^n` 中的 max 函数是凸函数。
*   几何平均函数，`(∏ x_i)^{1/n}`
*   `R^n` 中的负熵函数是凸函数。
*   函数 `log(det(X))` 是凹函数。

## 凸函数的性质

以下是凸函数的一些有用性质：

### First order conditions（一阶条件）

假设 `f` 是可微标量场；则 `f` 是凸函数当且仅当 `f` 的一阶泰勒近似低估 `f`。即对于定义域内的任意两点 `x, y ∈ dom f`：

```
f(y) ≥ f(x) + ∇f(x)^T (y - x)
```

这是凸函数一个非常重要的性质，也易于证明。假设 `f` 是凸函数，令 `y = x + tΔx`；则对于定义域内的任意两点 `x, y`，根据凸性性质有：

```
f(x + tΔx) ≤ (1-t)f(x) + tf(x + Δx)
```

当 `t -> 0` 趋于极限时，上式右边的比率表示 *f* 在 `Δx` 方向上的方向导数，因此可以写为 `∇f(x)^T Δx`。这证明了一阶条件。我们也可以从一阶条件推导出逆命题，即 *f* 的凸性。有兴趣的读者可参考文献 [4] 了解证明。

> **注意：** 如果 `∇f(x) = 0`，则对于凸函数有 `f(y) ≥ f(x)`。因此，x 是该函数的全局最小值。所以，凸函数的任何驻点都是全局最小值。这一性质使得凸优化问题成为一类特殊的问题。

### 二阶条件

假设 *f* 是二阶可微的，且其海森矩阵或二阶导数 `∇²f(x)` 存在。当且仅当其海森矩阵为半正定时，*f* 为凸函数，即 `∇²f(x) ⪰ 0`，对定义域内所有的 *x* 均成立。从几何角度来看，我们可以认为 *f* 表示一个曲面；那么，鉴于其凸性，该曲面必须具有正曲率。

> **提示：** 一阶和二阶条件对凹函数同样适用，只需做以下修改：
>
> *   任何驻点都是全局最大值
> *   当且仅当 `∇²f(x) ⪯ 0` 时，*f* 为凹函数，对定义域内所有的 x 均成立

**示例**：二次函数 `f(x) = (1/2)x^T P x + q^T x + r`。我们有 `∇f(x) = Px + q` 和 `∇²f(x) = P`。因此，根据二阶条件，当 `P ⪰ 0` 时 f 为凸函数。

**示例**：最小二乘目标函数 `f(x) = ||Ax - b||^2`。我们有 `∇f(x) = 2A^T(Ax - b)` `∇²f(x) = 2A^T A` 对任意 A 都是凸的，因为 `A^T A` 是实对称矩阵，因此是正定的。

### 凸函数在一条线上的限制

函数 `f(x)` 是凸函数，当且仅当函数 `g(t) = f(x + tv)` 是凸函数，其中 `x + tv ∈ dom f` 在 *f* 的定义域内，t 是实数。**示例：** 函数 `f(X) = log det X`。

```
g(t) = log det (X + tV)
     = log det X + log det (I + t X^{-1/2} V X^{-1/2})
```

这里 `λ_i` 是 `X^{-1/2} V X^{-1/2}` 的特征值。

### 詹森不等式

如果 f 是凸函数，则对于 `θ_i ≥ 0, Σ θ_i = 1`，

```
f(Σ θ_i x_i) ≤ Σ θ_i f(x_i)
```

## 凸优化

凸优化问题具有以下形式：

```
minimize f_0(x) subject to f_i(x) ≤ 0, i=1..m, h_i(x) = 0, i=1..p
```

这里，目标函数 *f* 和不等式约束是凸的，等式约束是线性的或仿射的：`h_i(x) = a_i^T x + b_i`。

凸优化问题的一个基本性质是**任何局部最优解也是（全局）最优解**。在强凸性假设下，即存在正常数 *m*、*M* 使得 `mI ⪯ ∇²f(x) ⪯ MI`，上述讨论的梯度下降算法可以被证明对于无约束凸优化问题收敛到全局最小值。

> **注意：** 海森矩阵 `∇²f(x)` 的条件数由 M/m 界定，梯度下降算法收敛所需的迭代次数 N 也由 M/m 界定。我们有关系式 `N ∝ M/m`。

对于有约束凸优化，我们可以使用拉格朗日乘数法将其转化为无约束优化问题。在那里，在不等式约束上称为 Slater 条件的某些基本假设下，强对偶性成立。

### Slater 条件

存在 *f* 定义域内的 *x*，使得严格不等式成立：`f_i(x) < 0` 和 `h_i(x) = 0`。这样的点也称为*严格可行解*。

> **注意：** Slater 定理指出，如果 Slater 条件成立，则凸优化将具有强对偶性，即拉格朗日对偶的最大值将等于目标函数的最小值：`d* = p*`。这一性质可以为任何迭代优化算法提供停止准则。如果我们迭代地达到一点 `x` 使得 `f_0(x) - g(λ, μ) ≤ ε`，那么我们可以保证我们接近最优解，即 `f_0(x) - p* ≤ ε`。

强对偶性还给了我们某些必要且充分的条件，有助于解析地求解优化问题。这些将在下一节讨论。

## Karush-Kuhn-Tucker 条件 (KKT)

假设某优化问题满足强对偶性。设该问题为满足 Slater 条件的凸优化：

```
minimize f_0(x) subject to f_i(x) ≤ 0, h_i(x) = 0
```

当且仅当 `x*` 和 `(λ*, μ*)` 是原始问题和对偶问题的解，`x*` 和 `(λ*, μ*)` 满足以下条件：

*   `f_i(x*) ≤ 0`，（原始可行性条件）
*   `h_i(x*) = 0`，（原始可行性条件）
*   `λ* ≥ 0`，（对偶可行性条件）
*   `λ*_i f_i(x*) = 0`（互补松弛性条件）
*   点 `x*` 使 `L(x, λ*, μ*)` 最小化，因此我们必须有以下*平稳条件*：

```
∇f_0(x*) + Σ λ*_i ∇f_i(x*) + Σ μ*_i ∇h_i(x*) = 0
```

这些条件称为**Karush-Kuhn-Tucker (KKT) 条件**。

> **注意：** 对于任何具有可微目标函数和约束函数的优化问题（凸或非凸），只要强对偶性成立，任何一对原始和对偶最优点都必须满足 KKT 条件。

这些 KKT 条件在 **支持向量机** (**SVM**) 等机器学习模型中发挥着重要作用。SVM 将机器学习分类问题表述为凸优化，并利用拉格朗日对偶性和 KKT 条件来求解优化问题。我们在概率论章节中也将看到拉格朗日乘数法在求解许多优化问题中的应用。

## 结论

在本章中，我们介绍了向量和张量函数的微分学。我们利用它们引入了向量和张量函数的优化理论。在本书的其余部分，我们将在讨论的几乎所有算法中使用这些概念。在下一章中，我们将讨论 AI 理论赖以建立的另一个重要支柱——概率论，它量化了 AI 问题中自然产生的不确定性，并为我们提供了处理不确定性的数学工具。

## 重点回顾

*   任何单变量可微函数都可以利用一阶泰勒级数展开在局部用一条线来近似。
*   对于多变量函数，我们必须计算方向导数，因为函数值随我们远离某一点的方向不同而变化。沿坐标轴的方向导数称为*偏导数*。
*   所有方向导数的存在并不意味着标量场在给定点处连续。
*   如果全导数在某点存在，则函数在该点可微，这意味着该函数可以在该点用线性变换进行局部近似。
