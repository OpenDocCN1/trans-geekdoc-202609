## 按人类方式对 IP 地址进行排序

```php
natsort($a);
```

使用 `sort()` 对 IP 地址进行排序并不真正有效，因为如果按字符串排序，'100.200.300.400' 小于 '50.60.70.80'（而且这甚至不是一个有效的 IP 地址，但这不是重点）。此外，字符串中不仅仅包含数字，因此数值排序也不起作用。

```php
<?php
$a = array('100.200.300.400', '100.50.60.70',
    '100.8.9.0');

echo implode(' < ', $a);
?>
```

*使用自然顺序字符串比较对 IP 地址进行排序 (`natsort.php`)*

在这种情况下需要的是所谓的自然排序，这是由 Martin Pool 的 Natural Order String Comparison 项目在 `http://sourcefrog.net/projects/natsort/` 实现的。在 PHP 的 `natcasesort()` 函数中使用了该算法。根据描述，它按“人类方式”排序。当区分大小写时，可以使用 `natsort()`。前述代码展示了后者函数。

**注意**

内部，`natsort()` 使用 `strnatcmp()`（而 `natcasesort()` 使用 `strnatcasecmp()`），它对两个字符串进行“自然”比较。通过多次调用此函数，数组元素会被排列到正确顺序。

## 对任何内容进行排序

```php
function compare($a, $b) {
    return $a - $b;
}

$a = array(4, 1345, 31, 222);
usort($a, 'compare');
echo implode(' < ', $a);
```

如果你不想局限于 PHP 提供的标准排序功能，你可以编写自己的排序算法。内部，PHP 使用 Quicksort 算法对数组中的值进行排序。为此，PHP 必须知道两个值是否相等；在后一种情况下，PHP 需要找出哪个值更大。因此，要实现自定义排序，只需要一个接受两个参数并返回的函数：

- 如果第一个参数小于第二个参数，则返回负值
- 如果两个参数相等，则返回 0
- 如果第二个参数小于第一个参数，则返回正值

此函数的名称必须作为字符串传递给 `usort()`！其余工作由 PHP 完成，如代码所示。那里使用的比较函数是一种非常简单的数值排序方法。通过减去两个值，函数返回所需的值：如果第一个参数大于第二个参数，则返回正数，如果两个参数相等则返回 0，否则返回负数。

> **注意**
>
> Quicksort 算法是排序元素最快的算法之一。对 n 个元素进行排序时，最多使用 n² 次比较；然而，平均只需要 n log n 次比较，使其非常快速。Quicksort 使用分而治之的策略：它将问题拆分为几个较小的子问题，可以递归解决。有关该算法的更多信息可在 `http://en.wikipedia.org/wiki/Quicksort` 找到。

## 使用外语进行排序

对于这种特殊情况，PHP 没有特殊的排序方法；然而，你可以使用 `strnatcmp()` 来模拟此行为。其思想是为某些特殊字符定义新的顺序；在比较函数中，你然后使用它来确定哪个字符“更大”，哪个字符“更小”。

你首先需要一个可以对单个字符进行排序的函数：

```php
function compareChar($a, $b) {
    $characters = 'AAÀÁÄBCÇDEÉÈFGHIÌÍJKLMNOÒÖÓPQRSTUÙÜÚVWXYZ';
    $characters .= 'aaàáäbcçdeèéfghiìíjklmnoòöópqrstuùüúvwxyz';
    $pos_a = strpos($characters, $a);
    $pos_b = strpos($characters, $b);
    if ($pos_a === false) {
        if ($pos_b === false) {
            return 0;
        } else {
            return 1;
        }
    } elseif ($pos_b === false) {
        return -1;
    } else {
        return $pos_a - $pos_b;
    }
}
```

然后，主排序函数逐字符调用 `compareChar()`，直到找到差异为止。如果没有找到差异，则较长的字符串被认为是“更大”的一个。如果两个字符串完全相同，则返回 0。本段开头的代码展示了 compare 函数。该代码的结果如预期，Frans < Frédéric < Froni。

## 将效果应用于所有数组元素

```
$a = array_map('sanitize', $a);
```

有时，数组中的数据在使用前必须进行预处理。在第4章中，你将看到如何对通过HTML表单来自用户的数据在使用前进行净化。为此，必须处理每个数组元素。

```php
<?php
function sanitize($s) {
    return htmlspecialchars($s);
}

$a = array('harmless', '<bad>', '>>click here!<<');
$a = array_map('sanitize', $a);
echo implode(' ', $a);
?>
```

*将 `htmlspecialchars()` 应用于数组的所有元素（`array_map.php`）*

然而，你并不需要编写繁琐的 `for`/`foreach`/`while` 循环；PHP 为此提供了内置功能。第一种可能是使用 `array_map()`。它接受一个数组（第二个参数），并将该数组中的每个元素提交给一个回调函数（第一个参数，以字符串形式传递）。最后返回数组，所有元素都被回调函数的相关返回值替换。

在前面的列表中，数组中的所有值都使用 `htmlspecialchars()` 转换为 HTML。

但是，如果数组是嵌套的，策略就必须稍作改变。这时可以使用递归函数。如果数组元素是字符串，则进行 HTML 编码。如果是数组，则递归函数对该数组调用自身。以下代码实现了这一点，图2.6显示了结果。

```php
<?php
function sanitize_recursive($s) {
	if (is_array($s)) {
		return(array_map('sanitize_recursive', $s));
	} else {
		return htmlspecialchars($s);
	}
}

$a = array(
	'harmless' =>
		array('no', 'problem'),
	'harmful' =>
		array('<bad>', '--> <worse> <--')
	);

$a = sanitize_recursive($a);

echo '<pre>' . print_r($a, true) . '</pre>';
?>
```

## 过滤数组

```
array_filter($values, 'checkMail')
```

假设你获得了一堆值——来自 HTML 表单、文件或数据库——并希望选择其中哪些值实际可用，哪些不可用。你可以再次调用 `for`、`foreach` 或 `while` 来找出感兴趣的内容，或者你可以让 PHP 完成大部分工作。在后一种情况下，你需要熟悉函数 `array_filter()`。它接受两个参数——第一个是要过滤的数组，第二个是函数名（以字符串形式），用于检查数组元素是否合格。这个验证函数在成功时返回 `true`，否则返回 `false`。下面是一个非常简单的电子邮件地址验证函数（有关此主题的讨论，请参阅第1章“操作字符串”）。

```php
<?php
function checkMail($s) {
    $ampersand = strpos($s, '@');
    $lastDot = strrpos($s, '.');
    return ($ampersand !== false &&
            $lastDot !== false &&
            $lastDot - $ampersand >= 3);
}
?>
```

```php
$values = array(
    'valid@email.tld',
    'invalid@email',
    'also@i.nvalid',
    'also@val.id'
);
echo implode(', ', array_filter($values,
    'checkMail'));
?>
```

# 日期和时间

大多数时候，PHP 5 的日期和时间功能用于打印当前日期和时间——以表明网页是最新的（你会惊讶于有多少大型网站实际使用这一点）。但除此之外，在 PHP 中处理日期和时间还提供了许多其他可能性，其中大部分你将在本章中找到。

首先，看一下 PHP 中最可能用于处理日期的函数——`date()` 似乎是合适的。这个函数可以获取当前日期（或任意日期）并提取关于它的一些信息，例如，今天是几号，是上午还是下午，以及根据那个相当失败的市场营销噱头“Swatch Internet Time”现在是什么时间。为此，你调用 `date()` 并提供一个字符串作为第一个参数。这个字符串可以包含一系列格式化符号，如表3.1所示（PHP手册在 `http://php.net/date` 处带有更多示例的列表）。每个符号都被相应的日期/时间值替换。

### 表3.1 `date()` 的格式化符号

| 符号 | 描述 |
|--------|-------------|
| a | am或pm |
| A | AM或PM |
| B | Swatch Internet Time（介于000和999之间） |
| c | ISO 8601格式的日期 |
| d | 月份中的日期（从01到31） |
| D | 星期几（从Mon到Sun） |
| F | 月份（从January到December） |
| g | 小时（从1到12） |
| G | 小时（从0到23） |
| h | 小时（从01到12） |
| H | 小时（从00到23） |
| i | 分钟（从00到59） |
| I | 日期是否在夏令时（1）或不是（0） |
| j | 月份中的日期（介于1和31之间） |
| l | 星期几（从Sunday到Saturday） |
| L | 日期是否在闰年（1）或不是（0） |
| m | 月份（从01到12） |
| M | 月份（从Jan到Dec） |
| n | 月份（从1到12） |
| O | 与GMT的差异（例如，+0100表示提前一小时） |
| r | RFC 2822格式的日期 |
| s | 秒（从00到59） |
| S | 月份中日期的序数后缀（st、nd、rd、th） |
| t | 所给月份的天数（从28到31） |

| 符号 | 描述 |
| --- | --- |
| U | 纪元值（自1970年1月1日格林尼治标准时间午夜以来的秒数） |

函数 `date()` 非常强大，提供了广泛的使用方式。然而，特别是如果你有本地化内容，你需要一些好的短语。在本章中，你将找到许多这样的短语。

PHP的日期和时间函数在PHP手册中有自己的一节。你可以在 `http://php.net/datetime` 找到关于 `date()` 及其相关函数的更多信息。

## 在 `date()` 中使用文本


>
