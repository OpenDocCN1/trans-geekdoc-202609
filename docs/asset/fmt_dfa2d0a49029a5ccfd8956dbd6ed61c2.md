![Image](img/w.jpg) **B** 是错误的，因为`白帽黑客`是好人之一——为了特定目的而雇佣的伦理黑客。

### 14. 下列哪些项是钓鱼邮件的特征？（选择所有适用项。）

* **A.** 它没有通过你的名字称呼你。

* **B.** 它包含拼写错误的单词或语法错误。

* **C.** 它包含伪造的链接。

* **D.** 它来自未经证的来源。

![Image](img/r.jpg) **A, B, C, D.** EC-Council 在其多个 CEH 版本中保留的目标之一是，引用原话，是为了“理解钓鱼攻击”。为了考试学习的官方大纲部分涵盖了深度检测钓鱼邮件，所有的答案都是邮件可能不合法的特征。首先，现在大多数向客户发送邮件的公司都会通过你的*名字*来称呼你，有时还会通过账号。以“亲爱的客户”或类似的话开头的邮件可能是情况不对劲的指标。

来自企业的拼写错误和语法错误通常也是明显的破绽，因为公司在发布项目之前会尽力对内容进行校对。虽然偶尔会出现一些失误（在互联网上搜索其中一些；它们真的很有趣），但那些绝对是例外而非常态。

可以通过将鼠标悬停在链接上（或通过查看其属性）来找到伪造的链接。链接文本可能显示为 `www.yourbank.com`，但超链接属性将你导向某个你不想访问的 IP 地址。

最后，任何来自“未经证实的来源”的邮件都可以且应该被审慎对待。什么让某个成为未经证实的来源？这取决于观察者的眼光。在很多情况下，它仅仅是一个你不认识或以前没见过的地址（或人）。在其他情况下，它与你所熟悉的邮件地址看起来非常相似，但事实证明是恶意的。

在任何一种情况下，你个人和组织安全的最佳办法都是：不要点击。邮件来自谁、它的语法是否完美、链接看起来是否合规，这些对你来说并不重要——只要养成完全不点击邮件中链接的习惯就好。相信我，你和你的组织会安全。

顺便提一下，虽然这些都是考试题的完美答案，但不要让它们主宰你考试之外的日常生活。一封编写完美、语法正确、包含真实链接且来自你信任的人的邮件*可能仍然*钓鱼攻击的一部分。在不知道链接确切是什么以及它会带你去何处之前，永远不要点击邮件中的链接——无论你认为信息是谁发的，无论它写得有多好。最后，如果你收到一封内容准确、通过你的名字称呼你、带有真实链接且看起来确实真实的钓鱼邮件，你可能真的遇到麻烦了。每个人都会收到带有“点击此处获取免费物品”的烦人“垃圾”邮件。然而，如果你收到一封包含你的名字和识别细节并投递给你的邮件，那么说明有人专门针对你。

![Image](img/r.jpg) **A, B, C, D.** 所有答案都是正确的，但让我们先开门见山：你永远无法采取任何措施来完全有效地让*所有*社会工程攻击无形于形。你可以采取一些措施来限制它们，此列表中的方法确实在这方面有所帮助，但如果一个组织用“我们有强大的安全策略和极好的用户教育”来应对社会工程问题，可能会面临很高的离职率。

信息分类被视为一种强有防御措施，因为信息（以及对信息的访问）是根据敏感性的严格定义进行存储和处理的。在政府/国防（DoD）领域，你会看到机密（Confidential）、秘密（Secret）和绝机密（Top Secret）之类的标签。在商业领域，你可能会看到公开（Public）、敏感（Sensitive）和机密（Confidential）。我可以专门写一章介绍 DoD 和商业标签之间的区别，并争论各种访问控制方法的细微之处，但我们仅限于本章以及你需要的内容。顺便提一下，如果对这些信息的访问执行以及在存储或传输过程中的保护松散，那么信息分类对你将毫无用处。

强有的安全策略在本章前面已经介绍过，因此我不再在这里浪费太多篇幅了。你必须拥有一套良好的策略来帮助防止各种安全故障；然而，你不能*依赖*它作为唯一的防御措施。

根据 EC-Council 的说法，用户教育不仅是一种可行的社会工程防御措施，而且它是你能采取的最佳措施。任何读过这本书且在生产环境、企业级网络上花过时间教育用户的人，现在可能都在尖叫，因为结果有时充其量是参差不齐。然而，链条中的弱点*确实*是用户，所以我们必须尽力教育用户应该观察什么，以及在看到时该如何做。没有比受教育良好的用户更好的防御了（我所说的“受教育良好”是指绝对拒绝参与社会工程尝试的用户）。只是世界上这样的人并不多。
