
## 导数推导

$$
\begin{matrix}
\sigma'(x) & = (\frac{1}{1 + e^{-x}})' = \frac{1' * (1 + e^{-x}) - 1 * (1 + e^{-x})'}{(1 + e^{-x})^2} \\
& = \frac{- (1 + e^{-x})'}{(1 + e^{-x})^2} = \frac{- 0 - (e^{-x})'}{(1 + e^{-x})^2} = \frac{- (e^{-x})(-x)'}{(1 + e^{-x})^2} \\
& = \frac{e^{-x}}{(1 + e^{-x})^2} = \frac{1 + e^{-x} - 1}{(1 + e^{-x})^2} = \frac{1}{1 + e^{-x}} - \frac{1}{(1 + e^{-x})^2} \\
& = \frac{1}{1 + e^{-x}}(1 - \frac{1}{1 + e^{-x}}) = \sigma(x)(1 - \sigma(x))
\end{matrix}
$$

下面的代码绘制 `σ'(x)` 的函数曲线：

```python
import numpy as np
import matplotlib.pyplot as plt
%matplotlib inline

def sigmoid(x):
    return 1/(1+np.exp(-x))

x = np.arange(-7, 7, 0.1)
y = sigmoid(x)
dy = sigmoid(x)*(1-sigmoid(x))

plt.plot(x, y)
plt.plot(x, dy)

plt.legend(['$\sigma(x)$','$\sigma\'(x)$'])
plt.xlabel('x')
plt.ylabel('y')
plt.show()
```

![](img/file17.png "fig:")

**图 1-29** `σ(x)`、`σ'(x)` 的函数曲线

可以看出，`σ'(x)` 的函数曲线是一个钟形曲线，对所有 `x`，`σ'(x) > 0`，且在 `x=0` 处导数值最大。因为 `σ(0)(1 - σ(0)) = 0.5 * 0.5 = 0.25`，当 `x` 趋向无穷大时，导数值趋向于 0。导数值的大小表明函数值随自变量变化的快慢。因此，`σ(x)` 在 `x = 0` 处变化最快，当趋向无穷大时，函数值的变化越来越慢。

根据导数的定义，上述四则运算法则和复合函数链式求导法则很容易证明。感兴趣的读者可以自行证明或参考微积分教材。

### 1.3.5 计算图、前向计算、反向传播求导

通过四则运算和复合运算从简单函数构造出一个函数的过程，可以用上述图 1-29 表示，图中的节点表示四则运算或复合运算。该图也展示了输入自变量 `x` 给该函数计算函数值（函数输出）的过程。这个图称为**计算图**，根据形成该图的过程计算输入变量的输出函数值的过程称为**前向计算**。从图中可以看出，求导过程正好是前向计算过程的逆过程，因此称为**后向计算**或**反向传播计算**。

![](img/file228.png)

**图 1-30** 前向计算（实线）与反向求导计算（虚线）示意图

如图 1-30 所示，前向计算过程是从 `x` 经过函数 `g` 得到 `g(x) = x²`，再经过函数 `f` 得到 `f(g) = sin(g) = sin(x²)`。

`x → g → g(x) = x² → f → f(g) = sin(g) = sin(x²)`

反向传播求导过程为：

`f → f'(g) → f'(g) = sin'(g) = cos(g)`

`g → g'(x) → g'(x) = (x²)' = 2x`

`f'(x) = f'(g) * g'(x) = cos(g) * (x²)' = cos(g) * 2x = cos(x²) * 2x`

反向传播求导是神经网络（深度学习）的核心且最关键的基础。如果理解了反向求导，就能轻松理解深度学习的算法原理。

### 1.3.6 多元函数的偏导数与梯度

有时自变量 `x` 是由多个分量组成的向量，而不是单个值，即 `x = (x[1], x[2], ..., x[n])` 包含多个分量 `x[j]`。将这种自变量 `x` 映射为单个数值因变量的函数 `f(x)` 称为**多元函数**，可表示为 `f : ℝⁿ → ℝ`。

`f(x)` 对 `x` 的每个分量 `x[j]` 的导数称为偏导数，记作 `∂f/∂xⱼ`，它反映了 `f(x)` 关于该分量 `x[j]` 的变化率。

`∂f/∂xⱼ = lim(Δxⱼ→0) [f(x₁,...,xⱼ + Δxⱼ,...,xₙ) - f(x₁,...,xⱼ,...,xₙ)] / Δxⱼ`

也就是说，偏导数是将其他变量视为常数，将 `x[j]` 视为变量，这样该函数就是一元函数，它对 `x[j]` 的导数称为原函数对 `x[j]` 的偏导数。

例如，若 `f(x, y) = 2x + y²`，其自变量包含 2 个分量 `x` 和 `y`，该函数为多元函数，自变量 `(x, y)` 映射为函数值 `f(x, y)`，即 `f : (x, y) → (2x + y²)`。该函数对 `x`、`y` 的偏导数为：

`∂f/∂x = ∂(2x + y²)/∂x = d(2x)/dx = 2`

`∂f/∂y = ∂(2x + y²)/∂y = d(y²)/dy = 2y`

`f(x)` 对 `x` 的梯度 `∇ₓf(x)` 是 `f(x)` 对 `x` 的每个分量 `x[j]` 的偏导数组成的向量：

`∇ₓf(x) = df/dx = (∂f/∂x₁, ..., ∂f/∂xⱼ, ..., ∂f/∂xₙ) ∈ ℝⁿ`

在上例中，`f(x, y) = 2x + y²` 关于 `(x, y)` 的梯度 `∇₍ₓ,ᵧ₎f(x, y) = (2, 2y)`。在特定点 `(2,3)` 处的梯度为 `(2, 6)`。

在不引起混淆的情况下，`f(x)` 对 `x` 的梯度 `∇ₓf(x)` 常简写为 `∇f(x)`。

对于 `x` 的一个微小增量 `Δx = (Δx[1], Δx[2], ..., Δx[n])`，`f(x)` 的增量 `f(x + Δ) - f(x)` 可近似为梯度 `∇f(x)` 与 `x` 的增量 `Δx` 的点积。

`f(x + Δ) - f(x) ≃ ∇f(x) ⋅ Δx`

通常，梯度写成行向量的形式：

`∇ₓf(x) = (∂f/∂x₁, ..., ∂f/∂xⱼ, ..., ∂f/∂xₙ) ∈ ℝⁿ`

而 `f(x)`、`x` 写成列向量的形式：

$$
\begin{matrix}
x = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix}
\quad
\Delta x = \begin{bmatrix} \Delta x_1 \\ \Delta x_2 \\ \vdots \\ \Delta x_n \end{bmatrix}
\end{matrix}
$$

然后梯度向量与增量向量的点积可以写成矩阵乘积的形式：

`f(xx + Δ) − f(xx) ≃ ∇f(xx)Δx = Δxx^(T)∇ff(xx)^(T)`

如果梯度也写成列向量，梯度向量与增量向量的点积可以写成矩阵乘积：

`f(xx + Δ) − f(xx) ≃ ∇f(xx)^(T)Δx = Δxx^(T)∇ff(xx)`

如果自变量写成行向量形式，梯度写成列向量形式，即：

`xx = (x[1], x[2], ⋯, x[n])`

`Δxx = (Δx[1], Δx[2], ⋯, Δx[n])`

```
∇f f(x x) = (∂f/∂x_1, ∂f/∂x_2, ⋯, ∂f/∂x_n)^T
```

但：

`f(xx + Δ) − f(xx) ≃ Δxx∇f(xx)`

如果梯度 `∇[x]ff(xx)`、`f(xx)`、`xx` 都写成行向量形式，则：

`f(xx + Δ) − f(xx) ≃ ∇f(xx)Δx^(T) = Δxx∇ff(xx)^(T)`

对于多元函数 `f(xx)`，如果自变量 `xx` 写成矩阵形式，则 `f(xx)` 关于 `xx` 的梯度，虽然是一个向量，但有时写成与 `xx` 形状相同的矩阵形式，这样容易知道哪个偏导数对应哪个变量，即：

```
f'(x x) = dy/dx x = [ ∂y/∂x_11  ∂y/∂x_21  ⋯  ∂y/∂x_n1
                      ∂y/∂x_12  ∂y/∂x_22  ⋯  ∂y/∂x_n2
                      ⋮          ⋮          ⋱  ⋮
                      ∂y/∂x_1n  ∂y/∂x_2n  ⋯  ∂y/∂x_nn ]
```

将梯度、自变量、因变量写成行向量、列向量还是矩阵，完全取决于哪种形式更有利于你推导相关公式。如果 `xx` 写成矩阵形式且梯度写成矩阵形式，看起来会更一致。

#### 示例 1

对于多元函数 `F(x, y, z) = x + 2y² + 3z³`，有：

`∇F(x, y, z) = (1, 4y, 9z²)`

在特定点 (2,3,4) 处的梯度为 `(1, 4 * 3, 9 * 4²) = (1, 12, 144)`。在此点附近，如果自变量有一个微小增量 `(Δx, Δy, Δz)`，则：

`F(2 + Δx, 3 + Δy, 4 + Δz) − F(2, 3, 4) ≃ 1 * Δx + 12 * Δy + 144 * Δz`

#### 示例 2

假设 `y = w[1] * x[1] + w[2] * x[2] + ⋯ + w[n] * x[n] + b`，若 `y` 视为 `w = (w[1], w[2], …, w[n])` 的函数，则 `dy/dw = (x_1, x_2, ..., x_n)`；若 `y` 视为 `x = (x[1], x[2], …, x[n])` 的函数，则 `dy/dx = (w[1], w[2], …, w[n])`；若 `y` 视为 `b` 的函数，则 `dy/db = 1`。

如果 `ww` 写成列向量而 `xx` 写成行向量，则 `y = xxww`，若梯度写成行向量，则 `∂y/∂xx = ww^T`，`∂y/∂ww = xx`。

如果 `ww` 和 `xx` 都写成列向量形式，且梯度写成行向量形式，则 `y = ww^(T)xx = xx^(T)ww`，此时 `∂y/∂xx = ww^T`，`∂y/∂ww = xx^T`。

可以证明，导数的四则运算和链式法则对梯度也成立。设 f, g 为两个从 ℝ^(n) 到 ℝ 的实值函数，则：

##### 线性法则

`(αf + βg)'(x) = ∇(αf + βg)(x) = αf'(x) + βg'(x) = α∇f + β∇g(x)`

##### 乘积法则

`(fg)'(x) = ∇(fg)(x) = f'(x)g(x) + f(x)g'(x) = g(x)∇f(x) + f∇g(x)`

##### 链式法则

设 g 为从 ℝ^(n) 到 ℝ 的实值函数，f 为从 ℝ 到 ℝ 的实值函数，对某 `xx ∈ ℝ^(n)`，`g(xx)` 的值为 `z`，若 `xx` 为列向量且梯度为行向量形式，则有：

`(f ∘ g)'(xx) = ∇(f ∘ g)(xx) = f'(z)g'(xx) = f'(z)∇g(xx)`

若 `xx` 为行向量且梯度为列向量形式，则：

`(f ∘ g)'(xx) = ∇(f ∘ g)(xx) = g'(xx)f'(z) = ∇g(xx)f'(z)`

即两种不同形式的链式法则顺序恰好相反。

#### 示例 3

若 `g((x_1, x_2)^T) = 3x_1 + 2x_2³`，`f(z) = z²`，则 `(f ∘ g)((x_1, x_2)^T) = (3x_1 + 2x_2³)²`。所以：

`(f ∘ g)'(xx) = f'(z)∇g(x) = 2z * (3, 6x[2]²) = 2 * (3x[1] + 2x[2]³) * (3, 6x[2]²) = (18x[1] + 12x[2]³, 36x[1]x[2]² + 24x[2]⁵)`

若变量为行向量且梯度为列向量，`g(x[1], x[2]) = 3x[1] + 2x[2]³`，`f(z) = z²`，则 `(f ∘ g)(x[1], x[2]) = (3x[1] + 2x[2]³)²`。所以：

```
(f ∘ g)'(x x) = ∇g(x)f'(z) = [ 3
                                 6x_2² ] 2z = [ 3
                                                  6x_2² ] 2 * (3x_1 + 2x_2³) = [ 18x_1 + 12x_2³
                                                                                     36x_1x_2² + 24x_2⁵ ]
```

#### 示例 4

假设 `y`、`ŷ` 是 ℝ^(n) 中的两个向量，可以用它们欧氏距离的平方来定义这两个向量之间的误差（距离），例如用以下公式表示两个向量之间的误差 `E(y, ŷ)`：

```
E(y y, ŷ ŷ) = 1/2 ||y y - ŷ ŷ||_2² = 1/2((y_1 - ŷ_1)² + (y_2 - ŷ_2)² + ⋯ + (y_n - ŷ_n)²)
```

`E(y y, ŷ ŷ)` 关于 `yy` 的梯度为 `(y y - ŷ ŷ)^T`。

### 1.3.7 向量值函数的导数与雅可比矩阵

如果有多个函数：

```
f_1: x → f_1(x)
f_2: x → f_2(x)
⋮
f_m: x → f_m(x)
```

它们可以写在一个列向量中：

```
f f(x) = [ f_1(x)
           f_2(x)
           ⋮
           f_m(x) ]
```

这些组合在一起的函数称为**向量值函数**。输入一个 `x`，每个函数产生一个函数值 `fi`，这些函数值构成上述右侧的向量。

例如，有 3 个函数：`f1 = x²`，`f2 = e^x`，`f3 = ax`，它们构成一个向量值函数：

```
f f(x) = [ f_1(x)
           f_2(x)
           f_3(x) ] = [ x²
                        e^x
                        ax ]
```

输入一个 `x` 值，如 3，产生 3 个值：`[ 9, e³, 3a ]^T`

由 m 个一元函数组成的向量值函数是实数集 ℝ 到 ℝ^(m) 的映射（变换）`ff(x) : ℝ → ℝ^(m)`。如果在某点 `x`，每个函数 `fi` 关于 `x` 的导数存在，将这些导数汇集成一个向量，称为向量值函数关于自变量 `x` 的导数，可写作 `Dff(x)`：

##### 向量值函数的导数

$$
\begin{matrix} 
Df f(x) = f f^{\prime}(x) = \frac{df f}{dx} = \begin{bmatrix} \frac{df_{1}}{dx} \\ \frac{df_{2}}{dx} \\ \vdots \\ \frac{df_{m}}{dx} \\ \end{bmatrix} \in \mathbb{R}^{m \times 1} 
\end{matrix}
$$

向量值函数的导数是一个包含 m 个元素的向量。

如果向量值函数的自变量 *x* 是一个包含多个变量的向量，这样的向量值函数称为多元向量值函数。设自变量个数为 n，函数个数为 m。这是一个从 $\mathbb{R}^{(n)}$ 到 $\mathbb{R}^{(m)}$ 的映射（变换） **f** : $\mathbb{R}^{(n)} \to \mathbb{R}^{(m)}$。输入 n 个自变量的值，输出 m 个实数。

多元向量值函数的每个函数 $f_i(x)$ 都是一个多元函数。在某点 *x* 处，如果每个函数 $f_i(x)$ 都有关于 *x* 的梯度，将这些梯度向量堆叠在一起得到一个矩阵，称为雅可比矩阵：

$$
\begin{matrix} 
Df f(x) = f f^{\prime}(x) = \frac{df f}{dx} = \begin{bmatrix} 
\frac{\partial f_{1}}{\partial x_{1}} & \frac{\partial f_{1}}{\partial x_{2}} & \cdots & \frac{\partial f_{1}}{\partial x_{n}} \\
\frac{\partial f_{2}}{\partial x_{1}} & \frac{\partial f_{2}}{\partial x_{2}} & \cdots & \frac{\partial f_{2}}{\partial x_{n}} \\
\vdots & \vdots & \ddots & \\
\frac{\partial f_{m}}{\partial x_{1}} & \frac{\partial f_{m}}{\partial x_{2}} & \cdots & \frac{\partial f_{m}}{\partial x_{n}} \\
\end{bmatrix} \in \mathbb{R}^{m \times n}
\end{matrix}
$$

这是一个 $m \times n$ 矩阵，其中每一行是一个函数的梯度。

通常，自变量和向量值函数写作列向量，每个函数的梯度写作行向量。但本书将自变量和向量值函数都写成行向量的形式，即：

$f(x) = (f_1(x), f_2(x), \cdots, f_m(x))$

$x = (x_1, x_2, \cdots, x_n)$

但此时雅可比矩阵为：

$$
\begin{matrix} 
Df f(x) = f f^{\prime}(x) = \frac{df f}{dx} = \begin{bmatrix}
