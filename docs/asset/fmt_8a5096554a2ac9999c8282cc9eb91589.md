
# 问题 106
在例行更新期间，Web 服务器应用程序需要重启。管理员**首先**应该做什么，以确保客户端连接在重启期间不会被突然中断？

- (A) 将导入流量重定向到备份服务器
- (B) 增加服务器内存
- (C) 手动终止所有活跃的客户端会话
- (D) 检查应用程序是否有可用补丁

**解释 106.** 正确答案：A. 将导入流量重定向到备份服务器。通过重定向导入流量，可以确保客户端不会被突然断开，而可以在主服务器重启期间在备份服务器上继续活动。

**选项 B 错误。** 增加服务器内存可能会提高性能，但不能解决服务重启的即时问题。

**选项 C 错误。** 手动终止客户端会话会导致突然断开，这正是管理员试图避免的。

**选项 D 错误。** 虽然检查补丁很重要，但它并不能解决确保客户端连接在服务重启期间不被中断的问题。

# 问题 107
Carlos 负责管理大学的 IT 服务。该大学有许多部门，每个部门都有自己的子域名：`arts.university.com`、`science.university.com` 和 `sports.university.com`。Carlos 想要一种既能确保 HTTPS 安全又成本效益的解决方案。然而，他对潜在风险表示警惕。使用通配证书（Wildcard Certificate）用于大学的子域名可能有什么缺点？

- (A) 它只能保护一个子域名
- (B) 如果被破解，所有子域名都面临风险
- (C) 它仅验证域名所有权，不验证组织身份
- (D) 它是可用的最贵证书

**解释 107.** **正确答案：B. 如果被破解，所有子域名都面临风险。** 通配证书的主要担忧是如果其私钥被泄露，将危及所有相关子域的安全。这构成了巨大风险，因为单个密钥的暴露可能导致所有子域遭受潜在攻击或滥用。

**选项 A 错误。** 通配证书可以保护单个域名下的多个子域名。

**选项 C 错误。** 对于域验证（DV）证书确实如此，但通配证书也可以提供组织验证（OV）版本，从而确保组织身份。

**选项 D 错误。** 通配证书并不一定是最贵的。成本取决于验证级别和颁发机构。

# 问题 108
您的组织正准备升级一个支持电子商务应用程序的数据库服务器。变更管理文档的审查显示，多个应用程序依赖此特定的数据库服务器来实现各种功能。为了确保升级过程顺畅且无中断，**首先**应该采取以下哪些步骤？

- (A) 立即升级数据库服务器以利用新功能
- (B) 对数据库服务器进行备份
- (C) 识别并测试所有依赖于该数据库服务器的应用
- (D) 通知用户升级期间可能出现的停机时间

**解释 108.** **正确答案：C. 识别并测试所有依赖于该数据库服务器的应用。** 在做出更改之前（特别是对于具有多个依赖项的系统），了解完整范围至关重要。

**选项 A 错误。** 在不考虑依赖关系的情况下立即升级可能会导致不可预见的的中。

**选项 B 错误。** 虽然备份服务器是一项良好的实践，但应该先识别依赖关系以规划升级。

**选项 D 错误。** 通知用户是必不可少的，但应该先理解潜在的影响。

# 问题 109
在最近发生数据泄露后，一家跨国公司正在评估其加密实践。首席安全官（CSO）确定，由于运营规模，手动管理密钥已变得过于复杂。哪种工具**最好**能够在确保稳健安全的同时解决 CSO 的顾虑？

- (A) 密码管理系统
- (B) 安全文件传输协议 (SFTP)
- (C) 可信平台模块 (TPM)
- (D) 密钥管理系统 (KMS)

**解释 109.** **正确答案：D. 密钥管理系统 (KMS)。** 密钥管理系统专门用于以集中和自动的方式处理加密密钥的生成、分配、轮换和终止。对于大型组织，使用 KMS 可以简化安全管理。

**选项 A 错误。** 虽然密码管理系统有助于处理和存储密码，但它没有提供密钥管理所需的全面功能。

**选项 B 错误。** SFTP 是用于在网络上安全传输文件的协议，而不是用于管理密钥。

**选项 C 错误。** 虽然 TPM 为单个设备提供硬件级安全，但它并非用于企业级密钥管理。

# 问题 110
在一次季度审查中，一家物流公司的 IT 团队决定更改负载均衡器的配置，以便在服务器之间更好地分配流量。更改后出现了一系列技术问题，影响了面向客户的应用程序。在排除故障时，发现网络图没有更新以反映这些更改。在这种情况下，没有更新图表的**主要**后果是什么？

- (A) 服务器可能需要硬件升级
- (B) 公司可能需要回到旧的负载均衡器配置
- (C) 增加了排除故障的时间和复杂性
- (D) 客户可能会选择其他物流公司

**解释 110.** 正确答案：C. 增加了排除故障的时间和复杂性。准确且最新的文档（包括网络图）对于有效的故障排除至关重要。如果没有这些，IT 团队可能会花费额外的时间来理解系统的现状，从而延迟问题的解决。

**选项 A 错误。** 虽然在某些情况下可能需要升级服务器，但这不是图表过时的直接后果。

**选项 B 错误。** 回到旧配置可能是一个可能的解决方案，但主要问题是由于文档过时导致排除复杂性增加。

选项 D 是错误的。虽然客户流失风险可能是长期技术问题导致的间接后果，但过时图表的直接关注点在于对故障排除的影响。
