```
s(t) = ∑_n s(nT) sinc(Ft - n),
```

其中 `sinc` 为采样函数：

```
sinc(t) = sin(πt) / (πt).
```

虽然这一直是信号采集设备发展的驱动力，但新兴应用日益增长的复杂性要求越来越高的采样率，这是当今硬件技术无法满足的。例如在宽带通信中，由 Shannon 界决定的转换速度变得越来越难以实现。因此，旨在通过利用信号的*潜在结构*来降低采样率的低速采样替代方案引起了强烈兴趣。例如，在许多应用中，信号仅包含少数频率或频带；参见图 9.11 以获取示意图。在这种情况下，以奈奎斯特速率采样是低效的。这是一个由许多作者研究的老问题，催生了当频谱中非零频带的位置已知时允许低速采样的技术（参见例如 [61,93,94]）。CS 理论激发了研究，去探讨频带位置（载波频率）事先未知的情况。此类极具实际应用价值的典型应用在于认知无线电领域（例如 [68,88,103]）。

图 9.11 模拟信号 `s(t)` 的傅里叶变换，该信号在频域中是稀疏的；只有有限数量的频段对其频谱内容 `S(Ω)` 有贡献，其中 Ω 代表角频率。奈奎斯特理论保证，以大于或等于最大 `Ω[max]` 两倍的频率进行采样，足以恢复原始模拟信号。然而，该理论并未利用与信号在频域中稀疏结构相关的信息。

以低于奈奎斯特速率对模拟信号进行采样的过程被称为*模拟到信息*采样或*亚奈奎斯特*采样。让我们重点关注两种最流行的基于 CS 的 A/D 转换器。第一种是*随机解调器*（RD），它首次见于文献 [58]，随后在文献 [91] 中得到了改进和理论发展。RD 的基本配置如图 9.10 所示，它旨在以亚奈奎斯特速率获取稀疏多音信号，即具有稀疏 DFT 的信号。这意味着信号包含少数频率分量，但这些分量被限制为对应于整数频率。文献 [91] 指出了这一局限性，并根据文献 [24] 提出的通用框架和/或文献 [45] 描述的启发式方法寻求了潜在解决方案。此外，更精细的 RD 设计，如*随机调制预积分器*（RMPI）[102]，有潜力处理在任意域中稀疏的信号。

另一种备受关注的基于 CS 的亚奈奎斯特采样策略是*调制宽带转换器*（MWC）[68,69,71]。MWC 在获取如图 9.11 所示的多频带信号方面非常高效。这一概念也已扩展以适应具有不同特性的信号，例如由短脉冲组成的信号[66]。文献 [59] 中的深入研究揭示了 RD 和 MWC 采样架构之间的异同。

请注意，RD 和 MWC 均在时间上对信号进行均匀采样。文献 [97] 采用了一种不同的方法，从而实现了更容易的实现。具体而言，避免了预处理阶段，并直接从原始信号中获取在时间上非均匀分布的样本。总共获得的样本比奈奎斯特采样少。然后调用基于 CS 的重构，根据样本值和时间信息来恢复所考虑的信号。与基本 RD 情况一样，非均匀采样方法适用于在 DFT 基下稀疏的信号。从实际角度来看，仍存在许多与硬件实现相关的问题或多或少地涉及上述所有方法，并有待解决（参见例如 [9,25,63]）。

亚奈奎斯特采样的另一条途径涉及一类不同的模拟信号，称为*多脉冲*信号，即由一串短脉冲组成的信号。稀疏性现在指的是时域，此类信号甚至可能不是带限的。这类信号可在许多应用中遇到，如雷达、超声、生物成像和神经信号处理（参见例如 [41]）。一种称为*有限创新率采样*的方法，将具有每秒 `k` 个自由度的模拟信号通过一个线性时不变滤波器，然后以每秒 `2*k` 个样本的速率进行采样。重构是通过求解高阶多项式的根来执行的（参见例如 [12,95] 及其参考文献）。文献 [66] 利用 CS 理论论点和 Gabor 函数展开来处理亚奈奎斯特采样任务；假设信号由少数持续时间有限但形状和时间位置未知的脉冲之和组成。更多相关内容可参见 [43,51,70] 及其参考文献。

## 9.10 案例研究：图像去噪

我们已经讨论了压缩感知（CS）作为稀疏感知学习的一个显著应用。除了获得广泛关注的 CS 之外，许多经典的信号处理和机器学习任务也适合通过稀疏性相关论证进行高效建模。两个典型例子如下：

*   **去噪**：信号去噪的问题在于，我们得到的不是实际信号样本`Ỹ`，而是相应观测值`y`的噪声版本；即`y = Ỹ + η`，其中`η`是噪声样本向量。在稀疏建模框架下，未知信号`Ỹ`被建模为基于特定已知字典`Ψ`的稀疏表示，即`Ỹ = Ψθ`。此外，字典允许是冗余的（过完备）。然后去噪过程分两步实现。

*   首先，通过`ℓ₀`范数最小化器或任何 LASSO 公式获得稀疏表示向量`θ`的估计值，例如：

```
θ̂ = arg min_{θ ∈ R^l} ||θ||₁,
```

(9.40)

```
s.t.      ||y − Ψθ||₂² ≤ ε.
```

(9.41)

其次，真实信号的估计计算为 $\widehat{\mathbf{y}} = \Psi\widehat{\mathbf{\theta}}$。在第 20 章中，我们将研究字典并非固定且已知，而是从数据中估计得到的情况。

*   **线性逆问题**：此类问题属于更广泛的*信号恢复*范畴，比去噪更进一步。现在，可用的观测值不仅包含噪声，还是真实信号样本的*失真*版本；即 $\mathbf{y} = H\widetilde{\mathbf{y}} + \mathbf{\eta}$，其中 *H* 是一个已知的线性算子。例如，*H* 可能对应图像的模糊点扩散函数，如第 4 章所述。然后，类似于去噪示例，假设原始信号样本可以用过完备字典高效表示，则通过任意稀疏性促进方法，利用 *H*Ψ 代替 (9.41) 中的 Ψ 来估计 $\widehat{\mathbf{\theta}}$，并得到真实信号的估计为 $\widehat{\mathbf{y}} = \Psi\widehat{\mathbf{\theta}}$。

*   除了去模糊，属于此公式化范畴的其他应用还包括图像修复（如果 *H* 代表相应的采样掩码）、断层扫描中的逆拉东变换（如果 *H* 包含平行投影集合）等。更多细节请参见例如文献 [49]。

在本案例研究中，探讨了基于上述稀疏冗余公式化的图像去噪任务。我们的出发点是图 9.13A 所示的 256 × 256 图像。随后，图像被零均值高斯噪声污染，导致图 9.13B 所示的含噪版本，对应的峰值信噪比 (PSNR) 等于 22 dB，其定义为

```
PSNR = 20 log_10 ( m_I / sqrt(MSE) ),
```

(9.42)

其中 *m*[*I*] 是图像的最大像素值，`MSE = (1/N_p) || I - Ĩ ||_F²`，其中 *I* 和 *Ĩ* 分别是含噪和原始图像矩阵，*N*[*p*] 等于像素总数，并采用了矩阵的 Frobenius 范数。

![Figure 9.13 Denoising based on sparse and redundant representations.](img/gr014.jpg)

图 9.13 基于稀疏冗余表示的去噪。

去噪可以一次性应用于整幅图像。然而，就内存消耗而言，一种更高效的做法是将图像分割成尺寸远小于图像尺寸的图像块；在我们的例子中，我们选择了 12 × 12 的图像块。然后对每个图像块分别执行去噪，步骤如下：第 *i* 个图像块按字典序重塑形成一个一维向量，`y[i] ∈ ℝ¹⁴⁴`。我们假设每个图像块都可以用一个过完备字典来表示，如前所述；因此，去噪任务等价地围绕 (9.40)–(9.41) 进行表述。用 `ỹ_i` 表示无噪图像的第 *i* 个图像块。剩下的工作是选择一个能稀疏表示 `ỹ_i` 的字典 `Ψ`，然后根据 (9.40)–(9.41) 求解稀疏向量 `θ`。

众所周知，图像通常表现出稀疏的 DCT 变换，因此字典的一个合适选择是用按字典序重塑的冗余 2D-DCT 原子填充 `Ψ` 的列 [49]。这里使用了 196 个这样的原子。给定图像的维度，有一种构建此类字典的标准方法，详见习题 9.22。**同一个**字典用于**所有**图像块。重塑为 12 × 12 块的字典原子如图 9.14 所示。

![图 9.14 对应 12 × 12 图像块尺寸的 2D-DCT 字典原子。](img/gr015.jpg)

图 9.14 对应 12 × 12 图像块尺寸的 2D-DCT 字典原子。

一个自然产生的问题是使用多少个图像块。一种直接的方法是将图像块并排铺设以覆盖整幅图像。这是可行的；然而，这很可能导致多个图像块边缘出现分块效应。一种更好的做法是让图像块重叠。在重建阶段（`ŷ = Ψθ̂`），因为每个像素被不止一个图像块覆盖，所以每个像素的最终值取所有相关图像块对应预测值的平均值。该方法在我们例子中的结果如图 9.13C 所示。达到的 PSNR 高于 28 dB。
