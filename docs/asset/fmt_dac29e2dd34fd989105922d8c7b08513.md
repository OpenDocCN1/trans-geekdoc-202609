
![Equation](img/si315.png) (15.63)

在这种表述下，得出了算法的以下**最大求和**版本。很容易看出，公式 (15.59) 和 (15.60) 现在变为以下形式

![](img/fx011.jpg)

代替叶节点发送的初始消息的公式 (15.51) 和 (15.52)，我们现在定义

$$
\mu_{x \rightarrow f} = 0 \text{ and } \mu_{f \rightarrow x} = \ln f(x).
$$

![Equation](img/si316.png) (15.66)

请注意，在消息流完成一次传递后，`P(x)` 的最大值已经获得。然而，人们也关心使最大值发生时对应的 `x*` 值，即

```
x* = argmax_x P(x).
```

这通过一个反向消息传递过程来实现，该过程与我们迄今为止讨论的略有不同，称为回溯。

**回溯**：假设 `x1` 是被选中作为根节点的节点，消息流在此“汇聚”。根据公式 (15.61)，我们得到

```
x1* = argmax_x1 μ_fa→x1(x1) μ_fg→x1(x1) μ_fh→x1(x1).
```

(15.67)

一个新的消息传递流现在开始，根节点 `x1` 将获得的最优值传递给与其相连的因子节点。让我们跟随这条消息传递流，穿过子树 `T[A]` 的节点。

*   **节点 A**：它从节点 `x1` 接收 `x1*`。

    1.  **最优值的选择**：回顾一下

    $$
    \mu_{f_{a}\rightarrow x_{1}}(x_{1}) = \max\limits_{x_{2},x_{3},x_{4}} f_{a}(x_{1},x_{2},x_{3},x_{4}) \mu_{x_{4}\rightarrow f_{a}}(x_{4}) \times \mu_{x_{3}\rightarrow f_{a}}(x_{3}) \mu_{x_{2}\rightarrow f_{a}}(x_{2}).
    $$

    ![Equation](img/si321.png)

    因此，对于 *x*₁ 的不同值，将导致 (*x*₂, *x*₃, *x*₄) 出现不同的最优值。例如，假设在我们的离散变量设置中，每个变量可以取四个可能值之一，即 *x* ∈ {1, 2, 3, 4}。那么，如果 *x*₁* = 2，假设得到的最优值为 (*x*₂*, *x*₃*, *x*₄*) = (1, 1, 3)。另一方面，如果 *x*₁* = 4，则最大化可能导致 (*x*₂*, *x*₃*, *x*₄*) = (2, 3, 4)。然而，通过节点 *x*₁ 处的最大化获得了 *x*₁* 的一个*特定*值后，我们选择三元组 (*x*₂*, *x*₃*, *x*₄*) 使得

    $$
    (x_{2 \ast},x_{3 \ast},x_{4 \ast}) = \arg\max\limits_{x_{2},x_{3},x_{4}}f_{a}(x_{1 \ast},x_{2},x_{3},x_{4})\mu_{x_{4}\rightarrow f_{a}}(x_{4}) \times \mu_{x_{3}\rightarrow f_{a}}(x_{3})\mu_{x_{2}\rightarrow f_{a}}(x_{2}).
    $$

    ![Equation](img/si329.png) (15.68)

    1. 因此，在第一遍过程中，获得的最优值必须存储起来，以便在第二遍（反向）过程中使用。

    2. **消息传递**：节点 A 将 `x[4*]` 传递给节点 `x[4]`，将 `x[2*]` 传递给节点 `x[2]`，将 `x[3*]` 传递给节点 `x[3]`。

* **节点 `x[4]`** 将 `x[4*]` 传递给节点 D 和 E。

* **节点 D**

    1. **最优值的选择**：选择 `(x[7*], x[8*])` 使得

    $$
    (x_{7 \ast},x_{8 \ast}) = \arg\max\limits_{x_{7},x_{8}}f_{d}(x_{4 \ast},x_{7},x_{8})\mu_{x_{7}\rightarrow f_{d}}(x_{7})\mu_{x_{8}\rightarrow f_{d}}(x_{8}).
    $$

    ![Equation](img/si334.png)

    1.

    2. **消息传递**：节点 D 分别将 $(x_{7\ast}, x_{8\ast})$ 传递给节点 $x_{7}$ 和 $x_{8}$。

这种类型的流向所有叶节点扩散，最终得到

$$
\mathbf{x}_{\ast} = \arg\max\limits_{\mathbf{x}}P(\mathbf{x}) \tag{15.69}
$$

人们可能会想，为什么不像使用求和-乘积规则那样使用类似的两阶段消息传递，并恢复每个节点 $i$ 的 $x_{i\ast}$。如果最优解 $\mathbf{x}_{\ast}$ 是唯一的，这是可行的。如果不是这种情况，并且我们有两个最优值，假设为 $\mathbf{x}_{\ast}^{1}$ 和 $\mathbf{x}_{\ast}^{2}$，它们是由公式 (15.69) 得出的，那么我们就有无法获得它们的风险。为了说明这一点，让我们以四个变量 $x_{1}, x_{2}, x_{3}, x_{4}$ 为例，每个变量取离散集合 $\{1, 2, 3, 4\}$ 中的值。假设 $P(\mathbf{x})$ 没有唯一的最大值，最优的两个组合是

$(x_{1\ast}, x_{2\ast}, x_{3\ast}, x_{4\ast}) = (1, 1, 2, 3) \tag{15.70}$

和

$(x_{1\ast}, x_{2\ast}, x_{3\ast}, x_{4\ast}) = (1, 2, 2, 4)$.

![Equation](img/si344.png) (15.71)

这两者都是可以接受的，因为它们对应于最大值 $P(x_{1}, x_{1}, x_{3}, x_{4})$。回溯过程保证给出这两者中的任意一个。相反，使用两阶段消息传递可能会导致值的组合，例如，

$(x_{1\ast}, x_{2\ast}, x_{3\ast}, x_{4\ast}) = (1, 1, 2, 4)$,

![Equation](img/si346.png) (15.72)

这不符合最大值。请注意，此结果本身的基本原理是正确的。它为每个节点提供了一个可能产生最优解的值。确实，在搜索 $P(\mathbf{x})$ 的最大值时，节点 $x_{2}$ 可以取值 1 或 2。然而，我们想要找到的是所有节点的正确*组合*。这由回溯过程保证。

##### 备注 15.3

*   最大乘积（最大求和）算法是著名的维特比算法 [46] 的推广，该算法已广泛应用于通信 [17] 和语音识别 [39] 中。该算法已被推广到树结构图上的任意可交换半环（例如，[1,13]）。

##### 示例 15.4

考虑 图 15.28A 的 BN。所涉及的变量为二元变量，{0, 1}，各自的概率为

`P(x = 1) = 0.7`, `P(x = 0) = 0.3`, `P(w = 1) = 0.8`, `P(w = 0) = 0.2`, `P(y = 1 | x = 0) = 0.8`, `P(y = 0 | x = 0) = 0.2`, `P(y = 1 | x = 1) = 0.6`, `P(y = 0 | x = 1) = 0.4`, `P(z = 1 | y = 0) = 0.7`, `P(z = 0 | y = 0) = 0.3`, `P(z = 1 | y = 1) = 0.9`, `P(z = 0 | y = 1) = 0.1`, `P(ϕ = 1 | x = 0, w = 0) = 0.25`, `P(ϕ = 0 | x = 0, w = 0) = 0.75`, `P(ϕ = 1 | x = 1, w = 0) = 0.3`, `P(ϕ = 0 | x = 1, w = 0) = 0.7`, `P(ϕ = 1 | x = 0, w = 1) = 0.2`, `P(ϕ = 0 | x = 0, w = 1) = 0.8`, `P(ϕ = 1 | x = 1, w = 1) = 0.4`, `P(ϕ = 0 | x = 1, w = 1) = 0.6`.

计算组合 `x*`, `y*`, `z*`, `ϕ*`, `w*`，其结果为联合概率的最大值：

```
P(x, y, z, ϕ, w) = P(z|y, x, ϕ, w)P(y|x, ϕ, w)P(ϕ|x, w)P(x|w)P(w) = P(z|y)P(y|x)P(ϕ|x, w)P(x)P(w),
```

这是贝叶斯网络（BN）施加的因子分解。

![Figure 15.28 (A) The Bayesian network of Example 15.4; (B) its moralized version, where the two parents of ϕ have been connected; and (C) a possible factor graph.](img/gr028.jpg)

```
f_a(x, y) = P(y|x)P(x),
f_b(y, z) = P(z|y),
f_c(ϕ, x, w) = P(ϕ|x, w)P(w),
```

显然：

```
P(x, y, z, ϕ, w) = f_a(x, y)f_b(y, z)f_c(ϕ, x, w).
```

注意，在这种情况下，归一化常数 `Z = 1`。因此，根据之前的定义，这些因子函数取值为：
