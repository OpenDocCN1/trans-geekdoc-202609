
由于 PDO 设计为与旧版 MySQL 服务器兼容（这些版本不支持预处理语句），你必须显式禁用模拟。否则，你将失去使用预处理语句通常带来的防注入优势。

另一个需要注意的设计妥协是默认的错误处理行为。如果不另行配置，PDO 不会显示任何 SQL 错误的迹象。

强烈建议将其设置为“异常模式”，因为在编写持久化抽象层时（例如：违反 `UNIQUE` 约束时抛出异常），这能提供额外的功能。
