
## 与协作数据相关的主要挑战之一是零售商与客户之间的时间滞后

雀巢利用 AWS 通过实施 **Amazon Managed Blockchain (AMB)** 来避免时间滞后，以此作为邀请供应商协作实现供应链透明化的一种手段。雀巢快速构建原型，并与 Amazon Web Services 共同出资，为溯源打造了一个概念验证，以高效加速其创新。

### 从农场到消费者的溯源链

溯源链包含五个层级的信息流：

1.  咖啡在农场经过处理后被运送至分级设施。
2.  咖啡在烘焙前移交给经纪人，此时将确定烘焙程度。
3.  当产品在包装设施完成包装时，烘焙过程结束，此时会记录包装供应商和制造信息。
4.  包装完成后，产品被运输给承运商，承运商存储分销商和零售商的信息。
5.  流程结束时，完成客户补充环节，其中记录了与产品销售相关的所有信息。

在 **Amazon Managed Blockchain Services** [36] 的帮助下，雀巢得以简化公司使用的技术基础设施，从而专注于为业务增值、支持农民和烘焙商，并为消费者提供卓越的口味体验。在雀巢实施 **Amazon Managed Blockchain** 有助于改善其咖啡口味和可及性，并帮助消费者了解其购买产品的来源。雀巢选择 **Amazon Managed Blockchain** 的主要原因在于其低成本、易用性、与其他 AWS 组件的集成能力，以及支持 **Hyperledger Fabric**。实时数据协作使雀巢能够通过将消费者与咖啡工艺相连接，从而提供优质的咖啡体验。通过 **Amazon Managed Blockchain**，客户可以在区块链上追踪其产品从农场到消费者的全过程 [14]。

使用 **Amazon Managed Blockchain**，所有交易都以透明、不可篡改和可验证的方式存储，使各方能够以更受信任、更高效的方式进行交互，无论是否存在中心化权威。在供应链中使用这项技术最重要的优势之一，是能够立即检测到错误、渎职或任何篡改行为，并在必要时解决问题。雀巢跨其各个品牌采用区块链验证作为解决方案。由于其不可篡改性，区块链可用于验证食品溯源及其生产环境 [36]。

## 利用 Azure Blockchain Service 管理发行商版税信息

视频游戏行业近年来经历了快速扩张。除了编程，视频游戏还需要音乐、特效和图形。为便于提供版税信息，实施了一个基于区块链的解决方案。客户获取账单的时间已从 45 天缩短至几分钟。尽管视频游戏经历了快速增长，但用于补偿游戏发行商的财务报告系统依然依赖一种老派的会计模型，即使用电子表格来计算和核对游戏版税。Xbox 财务部门于 2018 年采用区块链技术，以消除处理游戏发行商版税的耗时流程，并使版税信息更易获取。随着区块链技术的出现，数字账本现在可以更轻松地连接。

得益于其防篡改的特性，数字账本通过提高透明度和使系统更易用，便利了交易记录。基于区块链的解决方案支持智能数字合约，它们在交易发生时自动执行，将复杂的版税协议逻辑编码化。嵌入式逻辑增强了所有人对公平、准确付款的信心 [25]。通过利用 **Azure blockchain service**，Xbox 团队能够轻松管理智能合约并管控与不同游戏发行商的版税关系。该服务简化了发行商备注管理并监控网络健康状况。与非托管账本相比，**Azure blockchain service** 显著减少了基础设施安全和维护所涉及的工作量，实现了更高的支付效率。得益于这项技术的实施，发行商获取游戏销售数据变得轻而易举，且获取数据的等待时间大幅缩短。从 **Azure blockchain service** 检索到的信息涉及哪些游戏销售良好，以及哪些游戏目前在市场上处于流行趋势。

利用 **Microsoft Azure Blockchain** 技术，**Blockchain-as-a-Service (BaaS)** 服务构建在 **Microsoft Azure** 平台之上。凭借这些功能，设置权限、监控和维护网络，以及管理成员凭证变得更加容易。在智能合约的帮助下，通过应用编码逻辑，可以获取数字内容并即时计算版税 [25]。因此，财务交易可以定期追踪，使预测和报告更加有效，并让消费者能够专注于其核心竞争力。企业资源规划会计分录现在可以直接从区块链生成。此外，人工智能技术被集成到合约创建过程中，并托管在 **Microsoft Azure** 上 [7]。

## 全球航运商业网络 Oracle Blockchain-as-a-Service：CargoSmart

**CargoSmart** —— 一个全球运输管理系统 —— 开始尝试区块链解决方案，以改进复杂的供应链流程，在物流行业创建数字货运单据。通过使用该平台，发货人和海关办事处可以更高效地协作，构建一个低延迟的不可篡改审计追踪。处理单据涉及多个流程和程序，包括过时的纸质流程、广泛的技术能力范围，以及通过 `electronic data interchange (EDI)` 和电子邮件等不同格式共享单据。

**CargoSmart 区块链平台** 旨在简化货运单据流程，最大限度地减少冲突，缩短单据准备时间，并避免额外的海关罚款。因此，消除了整合、验证和管理在各种单据中重复的航运信息所需的时间，从而使物流流程更加高效和准确。通过与 **Oracle Blockchain Cloud Services** 合作，**CargoSmart** 创建了 **Global Shipping Business Network (GSBN)**，帮助公司高效创建区块链网络，以进行更可靠、更安全的交易 [8]。据 **CargoSmart** 首席执行官 Steve Siu 表示：“区块链倡导联盟概念，因此我们邀请发货人、货代、承运人和码头参与” [16]。凭借去中心化治理、互操作性和企业级架构，该平台适合监控全球货运，并在所有利益相关者之间进行组织和追踪 [8]。

**GSBN 平台** 为航运行业提供单一信息来源，具有以下特征：

*   **开放且可扩展**：合作网络可开发软件并连接到联盟网络，以增强数据互操作性和业务效率。
*   **透明度**：点对点软件允许数据管理者与其他货运投资者共享透明的记录，使他们能够针对重要里程碑快速采取行动，并保持货物在供应链中流动。
*   **标准的数字基线**：一个被广泛接受、值得信赖且全面的数字模型为高度协作的计划和商业智能提供了基础 [16]。

## 提出的 BaaS 平台

为了解决商业区块链即服务系统固有的一些缺陷，研究人员引入了下文所述的 BaaS 系统。所有这些提出的 BaaS 系统有一个共同目标——保持区块链的主要属性：不可篡改性、去中心化、持久性和可审计性 [31, 40]。

### 功能区块链即服务

*功能即服务*（FaaS），也称为无服务器计算，是一种快速且灵活地将应用程序部署到云端的方式。功能区块链即服务模型基于功能即服务。与传统 BaaS 模型相比，功能 BaaS 模型是一种无服务器架构，具有多项优势。此外，功能即服务（FaaS）模型的稳健性和层级特性可以轻松适配 FBaaS 模型。该架构由基础设施层、组件层、服务层和业务逻辑层组成：基础设施层由操作系统和构建于 AWS 之上的物理集群组成，且不使用 Amazon Lambda 函数；组件层实现认证和授权等基本功能；服务层实现存储和交易等主要功能；业务逻辑层提供广泛且复杂的服务 [9]。

### NutBaaS

NutBaaS 平台通过云计算环境提供区块链相关服务。这些服务包括监控和网络部署、智能合约测试和智能合约分析。NutBaaS 系统使开发者能够专注于业务逻辑。“Nut”（坚果）这个名字指的是提供一个“坚硬”的屏障（如坚果壳般）来保护区块链开发者的应用程序。NutBaaS 由资源层、服务应用层和业务层组成。区块链服务的实现通常需要实现资源层；即存储、数据库和网络。NutBaaS 架构的核心是 NutBaaS 服务层，它实现了绝大多数基于区块链的基础和复杂服务。虽然应用层为技术带来了构建单个应用程序的可能性，但业务层侧重于探索更多适合利用该技术创造额外业务成果的场景 [40]。

### 全谱区块链即服务

FSBaaS 集成了私有链和联盟链，构建于 *Blockchain Lite*（一种中心化的基于私有云的区块链平台）和 Hyperledger Fabric（一种分布式、开放且安全的区块链基础设施）之上。FSBaaS 不将用户限制于仅使用一种类型的区块链系统，而是允许用户结合私有区块链系统和大型联盟网络的最佳特性。全谱 BaaS 架构由区块链租户、区块链节点、业务网络和业务网络解决方案组成。该平台为租户提供了一种灵活的方式，通过统一的编程原则接口和 RESTful API 访问两种区块链运行时 [31]。

### 新型区块链即服务

*新型 BaaS*（NBaaS）是一个旨在改进基于 PaaS 的 BaaS 相关局限性的提出模型。NBaaS 中有几个不同的区块链组件，包括节点、网络成员、由排序节点进行的交易排序，以及区块链的客户端部分（用户在网络上操作的地方）。定义可部署组件对于连接区块链实例至关重要 [31]。作为 NBaaS 的一部分，可部署组件可以以一种促进可审计性和去中心化的方式进行部署，然而，NBaaS 无法防止租户和提供商之间的串通 [40]。

### 统一区块链即服务

uBaaS 解决方案是厂商中立的，意味着它们不绑定任何特定的云基础设施提供商。通过使用一个与后端服务通过应用程序编程接口（API）网关通信的前端用户界面，用户可以构建和配置基于区块链的应用程序。此外，uBaaS 支持部署即服务，消除了锁定特定云平台的需求；支持设计模式，有助于设计智能合约；并支持数据管理，以应对区块链的可扩展性和安全性挑战 [31]。

### 公共区块链即服务

作为一个旨在提供安全环境、专注于隐私和分布式平等的平台，*Versus* 开发了公共区块链即服务（PBaaS）。通过使用 PBaaS，任何项目都可以通过支付报价金额（而非公证费用）来启动其区块链组件，从而拥有算力和跨链交易。每条链都是独立的且可定制的。跨链交易是发展整个网络的重要组成部分，因为它们允许活动在链之间自由流动以减少拥堵。要创建一条链，必须拥有 *VersusID*。Versus 的多条区块链将允许流行货币和代币的兑换，从而使能力不局限于单一区块链 [34]。

尽管上述提出的 BaaS 系统具有相似的目标，但它们所解决的挑战没有重叠。这些研究的主要目标是使 BaaS 系统通用化和通用化，而非为了其性能 [31]。

## BaaS 治理

当参与方较少时，治理问题应该更容易解决。BaaS 环境下治理的一个关键方面与参与者有关，如下节所述。

### 许可链

BaaS 应用程序通常涉及私有区块链（专用于特定用途或应用）和/或许可区块链（限制为一组参与者）。分布式账本技术并非总是必要的，特别是在活动更加中心化或某些实体拥有更多管理权限的情况下。数据库可能就足够了，因为审计数据库日志可以提供可接受的保证。通过不可变性和完整性约束可以提供进一步的保证——例如，`secure audit34` 和 `forward integrity35` 已为仅追加数据存储开发，足以满足审计和跟踪应用程序的需求。

在涉及许多参与者的情况下（如大型商业网络），使用分布式账本技术（DLT）更有意义。当各方计划监督彼此的活动，或各方希望拥有一定程度的自主权（如定义个人利益和功能）时，分布式账本（DL）可能很有用。根据参与者的风险偏好、信任顾虑和权力平衡，DLT 可能是合适的，也可能是不合适的。主要云服务提供商除了提供更通用的云服务外，还提供 BaaS 组件。

### 链下控制

#### DL 的治理

DL 治理的一个关键方面是由谁决定其运作方式。BaaS 由多方组成——包括服务提供商和租户——每一方都有不同的利益和激励。类似于 BaaS 服务的 SaaS 服务涉及 BaaS 提供商在建立 DLT 基础设施方面发挥更大的作用。BaaS 租户可能需要考虑提供商是否可以单方面更改软件；客户复刻提供商软件以供重用的能力；租户、提供商或其他参与者如何更改账本；最后，提供商是否提供运行在另一个社区运行的区块链之上的分布式账本。一般来说，当租户的情况类似于 PaaS [[30]](#ch23.xhtml#r549) 时，他们将对其 DLT 基础设施拥有更大的控制权。

## 总结与结论

本章介绍了云计算概念，旨在使读者能够更深入地了解区块链即服务的云基础设施。IBM、微软、亚马逊、SAP 和甲骨文等许多大型实体为组织提供了在云端开发区块链应用程序的能力。因此，部署 BaaS 不需要大量的技术知识和基础设施，并且随着业务增长可实现可扩展性。简要讨论了金融和供应链领域的几个业务用例，以帮助读者更好地理解某些商业 BaaS 平台的底层架构。

## 核心概念

*   云计算描述了互联网及其基础设施的使用。云计算包含五个关键属性、四种部署模型和三种服务模型。
*   云计算的五个基本特征是——按需服务、广泛的网络访问、资源池化、快速弹性和可度量服务。云系统是一种按使用付费的系统。云计算使客户能够根据需求自动快速地向上或向下扩展。广泛的网络访问使云客户能够在不遇到带宽瓶颈的情况下使用云服务。资源池化使云能够通过大量的资本投入和来自庞大客户群的收入保持财务上的可行性。
*   云部署模型可分为四类——公有云、私有云、混合云和社区云模型。公有云是指所有主要资源均可供愿意为服务付费的公众使用的云，而私有云则供某个组织专用。混合云是私有云和公有云的混合。社区云或亲和云平台通常由具有相似业务目标的社区群体共享。
*   根据客户需求，云计算提供基础设施即服务、平台即服务和软件即服务。提供 IaaS 的云服务提供商提供硬件相关资源，客户最终负责逻辑资源。PaaS 模型为客户构建应用程序提供平台。SaaS 模型提供所有 IaaS 和 PaaS 功能，以及完全或部分创建的特定软件。
*   云服务提供商、客户、用户、访问安全代理和监管机构在云计算中发挥着至关重要的作用。云计算解决方案的优势包括节省成本、减少前期 IT 开支、提供防止数据丢失的备份服务，以及其对多租户的支持使得在多个用户之间共享服务器和应用程序变得容易。
*   BaaS 概念指的是一种基于云的“即服务”解决方案，旨在促进区块链平台的实施，允许用户从中央云托管和管理区块链应用程序。
*   组织可以通过订阅服务提供商基于任何分布式账本技术（如以太坊、Hyperledger Fabric、R3 Corda、Chain Core 或 Quorum）提供的区块链服务来建立 BaaS 平台。应建立服务级别协议，以确保区块链基础设施按照客户的规格进行开发。
*   BaaS 提供多项优势，包括节省成本和时间、降低人员成本、易用性、定价和客户支持。隐私和数据合规性、选项有限以及资源匮乏是 BaaS 目前面临的一些挑战。
*   区块链即服务架构分为四层——应用层、中间件、框架和基础设施层。BaaS 服务通常实现崩溃容错 (CFT) 或拜占庭容错 (BFT) 共识机制。
*   目前市场上有多家 BaaS 提供商。一些可与企业集成的最流行的商业 BaaS 提供商包括 IBM BaaS、甲骨文、微软 Azure BaaS、亚马逊 AWS BaaS、阿里巴巴、埃森哲、百度和华为。选择 BaaS 服务提供商时，应考虑以下因素：过往经验、易用性、质量承诺、集成和流程控制。
*   区块链技术研究人员正在提出多个非商业 BaaS 平台，即功能型 BaaS、NutBaaS、全谱 BaaS、新型 BaaS、统一 BaaS 和公共 BaaS，以保持区块链的不可篡改性、去中心化、持久性和可审计性等关键属性。
*   BaaS 治理指导参与 BaaS 平台的参与者。涉及的主要有两类参与方——许可链或私有链以及链下控制。
