# 关于系列丛

生成式 AI 是现代历史上最具破坏性的技术之一，具有从根本上改变教育的潜力（无论好坏）。本系列丛将探讨生成式 AI 与从幼儿到成人不同学习者教育研究与实践交叉的前沿话题。
