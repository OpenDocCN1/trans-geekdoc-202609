## 答案解析

### 1. 以下哪项描述是正确的？

**A.** `Kismet` 可以安装在 Windows 上，但不能安装在 Linux 上。

**B.** `NetStumbler` 可以安装在 Linux 上，但不能安装在 Windows 上。

**C.** `Kismet` 无法监控 `802.11n` 网络流量。

**D.** `NetStumbler` 无法监控 `802.11n` 网络流量。

**D.** 这个问题不仅过于困惑且针对特定工具，而且几乎就是你会在考试中看到的题目类型。`Kismet` 和 `NetStumbler` 都是具有检测和嗅探能力的无线监控工具。`NetStumbler` 是 Windows 特有的，而 `Kismet` 几乎可以安装在任何设备上。它们在监控 `802.11a`、`b` 和 `g` 网络方面表现出色，但 `NetStumbler` 无法处理 `802.11n`。`Kismet` 甚至可以作为你无线网络的 `IDS`！关于这一点，最后一个有趣的小知识——`Kismet` 在提取管理包方面做得更好。Windows 系统上的许多无线卡不支持监听模式，在提取管理包和控制包时面临困难。

**A, B, 和 C** 是错误的，因为它们是虚假陈述。`Kismet` 可以安装在任何地方，`NetStumbler` 是 Windows 特有的且在 Linux 上可用，而 `Kismet` 可以监控 `802.11n` 网络。

### 2. 以下哪项使用 48 位的初始化向量？（多选）

**A.** `WEP`

**B.** `WPA`

**C.** `WPA2`

**D.** `WEP2`

**B, C.** 从 `WEP` 升级到 `WPA` 的改进之一是将初始化向量 (`IV`) 从 24 位扩展到 48 位。虽然这看起来只是是选项的简单倍增，但你必须记住，每增加一个位都会以指数级增加密钥空间。`IV` 提供机密性和完整性。无线加密算法使用它来计算完整性检查值 (`ICV`)，并将其附加在数据负载末尾。然后将 `IV` 与密钥结合并输入算法（`WEP` 使用 `RC4`，`WPA` 使用 `AES`）。`IV` 的长度决定了可能创建的加密值的总数。增加到 48 位增加了整体安全性。

**A** 是错误的，因为 `WEP` 使用 24 位的 `IV`。在 `WEP` 中，尽管这个数字看起来很大，但黑客在几小时内就能获取足够的 `IV` 来破解密钥。

**D** 是错误的，因为不存在 `WEP2`。

### 3. 以下哪项描述是正确的？（多选）

**A.** `WEP` 使用 TKIP 进行共享密钥加密。

**B.** `WEP` 使用 `RC4` 进行共享密钥加密。

**C.** `WPA2` 使用 `RC4` 进行共享密钥加密。

**D.** `WPA` 使用 TKIP 和 AES 加密。

**B, D.** `WEP` 使用 24 位的初始化向量和 `RC4` 来“加密”数据传输，尽管这样说让我感到厌恶，因为这真的是一个误名。`WEP` 设计为基础加密仅是为了模拟有线网络的“安全性”——因此有了 Wired Equivalent Privacy 中的“Equivalent”（等同于）。它从未旨在作为真正的加密保护。`WPA` 在两个方面进行了改进。首先，通过使用临时密钥性协议 (`TKIP`)，共享密钥加密得到了极大增强。简而言之，用于加密的密钥是临时性的，并且每 10000 个包更换一次。此外，`WPA2` 使用 NIST 批准的加密算法 `AES` 作为选择算法。

**A** 是错误的，因为 `WEP` 不使用 TKIP。

**C** 是错误的，因为 `WPA2` 不使用 `RC4` 作为加密算法。

### 4. 你建议使用哪种方法防止未经授权的无线设备访问网络资产？

**A.** `无线访问控制列表`

**B.** `无线干扰器`

**C.** `无线分析仪`

**D.** `无线接入点`

![Image](img/r.jpg) **A.** 在提供的选项中，只有访问控制列表（ACL）是合理的。这正是访问控制列表的设计初衷：通过确保只有经过授权的设备*可以*连接，你确保了未经授权的设备无法连接（或至少采取措施避免其连接）。在这里顺带提一下，不要将无线入侵防御系统（`WIPS`）与 `ACL` 混淆。`WIPS` 会监控你的 `traffic`，并且像更广为人知的网络入侵防御系统一样，会根据流量分析、阈值和警报采取措施防止入侵。最后，对于这类问题，通过排除法可以帮你很轻松地辨别出答案。

![Image](img/w.jpg) **B** 是错误的，原因显而易见。是的，你会阻止未经授权的连接，但你也会阻止*所有*连接——甚至包括来自授权设备的连接。如果是那样的话，为什么还要开启无线功能呢？现在，我能听到你们某些人在尖叫说干扰可以在受限制的地理空间内用于控制访问，但请相信我，`ECC` 将干扰器视为一种切断一切的攻击工具。在考试时，你最好也这样看待它。

![Image](img/w.jpg) **C** 是错误的，因为分析器不会以任何方式影响访问。

![Image](img/w.jpg) **D** 是错误的，因为这不是 `WAP` 的意图。虽然你可以在设备上配置某些东西（比如，我敢说，一个 `ACL`），但设备本身的设计是为了*访问*点。

### 5.

在度假期间，Joe 收到一个来自身份警报服务的电话，通知他的两个账户在过去一小时内被访问了。当天早些时候，他将笔记本电脑连接到 `McDonald’s` 的无线热点并访问了那两个账户。以下哪项是针对 Joe 最可能的攻击？

**A.** 未经授权的关联

**B.** 蜜罐访问点 (Honeyspot access point)

**C.** 恶意访问点

**D.** 干扰信号

![Image](img/r.jpg) **B.** 有时 `EC-Council` 会创建并使用冗余术语，所以不要因为这个极其烦人的细节而怪我。在这种情况下，Joe 很可能在买早咖啡时连接了他认为是合法的 `McDonald’s` 免费 Wi-Fi，并检查了相关账户。然而，餐厅内（或附近）的攻击者使用与餐厅相同的 `SSID` 搭建了另一个无线网络。这种做法被称为蜜罐攻击。

![Image](img/w.jpg) **A** 是错误的，因为未经授权的关联攻击利用的是所谓的软访问点——某些移动设备中嵌入的无线局域网射电，这些射电可能会无意中启动并被攻击者用于访问企业网络。

![Image](img/w.jpg) **C** 是错误的，但差一点点。蜜罐攻击的核心理念是攻击者设置了某种恶意访问点来诱骗人们连接。然而，这属于一个答案比另一个答案更准确的情况。`EC-Council` 明确将蜜罐攻击列为一种独立的恶意攻击类型，因此你需要以这种方式记住它。

![Image](img/w.jpg) **D** 是错误的，因为干扰攻击寻求对整个信号进行 `DoS`（拒绝服务），而不是一定是为了从中窃取任何东西。

### 6.

一个攻击者正试图破解 `WEP` 密码以获取网络访问。在对 `wlan0` 开启监听模式并创建一个监控接口（`mon 0`）后，她输入了以下命令：

```
aireplay –ng -0 0 –a 0A:00:2B:40:70:80 –c mon0
```

她试图实现什么？

**A.** 通过检查包含 `WEP` 代码的取消认证包响应来获取 `WEP` 访问代码

**B.** 使用取消认证包产生大量的网络流量

**C.** 确定接入点的 `BSSID`

**D.** 发现网络隐藏的 `SSID`

![Image](img/w.jpg) **B.** 在 `802.11` 标准中，有几种不同的管理类型帧在使用：包括从信标帧、关联请求到探测请求的所有内容。这些管理帧之一就是取消认证包，它基本上会切断客户端与网络的连接。然后客户端必须重新连接——而且会很快这样做。这种活动背后的构思想是产生大量流量进行捕获，以便识别出 `WEP` 访问代码（从客户端尝试重新关联到所有飞速而来的新 `ARP` 包，因为许多机器在断开网络后会丢弃其 `ARP` 缓存）。记住 `WEP` 内的初始化向量相对短（24 位）且被频繁重复，因此任何破解密码的尝试通常需要大约 15,000 个数据包。你可以随着时间收集这些包，但产生流量可以快得多地实现这一点。关于这一点最后一点必须说明：这种攻击同样很容易导致针对主机和相关 `AP` 的拒绝服务攻击，所以要小心。

![Image](img/w.jpg) **A** 是错误的，因为对 `deauth` 包的响应并不以明文形式包含 `WEP` 访问代码。如果是那样，攻击者一开始就没必要费精力生成这么多流量了——一个简单的包就足以破解所有安全。

![Image](img/w.jpg) **C** 是错误的，因为基本服务集标识符 (`BSSID`）是 `AP` 的 `MAC` 地址。它通常很容易通过任何方法获得（例如使用 `airodump`），并且并不是发送多个取消认证包的原因。某些网络的 `BSSID` 是隐藏的（称为*cloaking*），但其他工具（`airmon` 和 `airodump`）可以提供帮助。

![Image](img/w.jpg) **D** 是错误的，因为即使 `SSID` 被“隐藏”，并不意味着它实际上隐藏了；它仅意味着没有广播。`SSID` 仍然包含在 `AP` 发出的每一个包中，发现它非常容易。

### 7.

哪种无线标准在 2.4GHz 频率范围内工作速率为 54Mbps？

**A.** 802.11a

**B.** 802.11b

**C.** 802.11g

**D.** 802.11n

![Image](img/r.jpg) **C.** `802.11` 系列标准识别了各种无线问题，例如客户端通信的顺序、认证规则、数据传输、包大小、消息如何编码为信号等。802.11g 结合了“a”和“b”标准的优点，而没有那么多的缺点。它速度很快（54Mbps），与 `802.11b` 客户端向下兼容，并且没有受到 `802.11a` 面临的覆盖区域限制。然而，考虑到它在 2.4GHz 范围内运行，可能会有一些干扰问题要处理。不仅你的网络周围周围有大量的竞争网络在发射信号（有时在同一信道上），你还必须考虑蓝牙设备、无线电话甚至婴儿监视器，它们可能会对无线信号产生干扰（由于干扰）。此外，微波炉恰好运行在 2.45GHz——正处于该范围的正中央。

![Image](img/w.jpg) **A** 是错误的，因为 802.11a 的速率为 54Mbps，但使用的是 5GHz 频率范围。802.11a 的主要缺点是频率范围本身——因为频率较高，网络范围受到限制。相比之下，802.11b 客户端可以分布在较远的距离上，而 802.11a 客户端通信速度快得多，但距离必须更近。加上设备成本的增加，这导致 802.11a 未能完全接受为事实标准。尽管如此，出于安全考虑，它可能不是一个坏选择。使用它的人很少，甚至没人寻找它，而且它较小的范围可能有助于你防止信号泄露到建筑之外。最后，导致距离限制的并非高频率本身，而是常见的建筑材料和传播问题与频率之间的相互作用。这非常复杂，但如果你感兴趣并且有时间的话，你会发现这个话题非常非常有意思。

![Image](img/w.jpg) **B** 是错误的，因为 802.11b 在 2.4GHz 频率范围内工作，速率为 11Mbps。它比“a”和“g”慢，但在发布后不久就成为了无线网络的事实标准。价格和网络范围促成了这一点。

![Image](img/w.jpg) **D** 是错误的，因为 802.11n 在 2.4 到 5 GHz 的频率范围内工作速率为 100Mbps+。它通过多输入多输出（MIMO）天线实现了这一速率。

### 8.

团队发现了一个配置了 WEP 加密的接入点（AP）。为了破解 WEP 尝试对 AP 进行伪认证，需要什么？（选择所有适用项。）

* **A.** 捕获的认证数据包

* **B.** AP 的 IP 地址

* **C.** AP 的 MAC 地址

* **D.** SSID

![Image](img/r.jpg) **C, D.** 破解 WEP 通常归结为捕获大量数据包并运行一些数学魔法来破解密钥。如果你想通过向 AP 发送伪认证数据包来产生流量，你需要 AP 的 MAC 地址和 SSID 来进行尝试。

![Image](img/w.jpg) **A** 和 **B** 是错误的，因为伪认证数据包不需要这些信息。当然，你可以捕获并重放整个认证数据包，但它没有多大作用，而且完全不需要 IP 地址。

### 9.

列出的工具中，哪一个是是被动发现工具？

* **A.** Aircrack

* **B.** Kismet

* **C.** NetStumbler

* **D.** Netsniff

![Image](img/r.jpg) **B.** 这样的问题可能有点棘手，取决于它的措辞；然而，根据 EC-Council 的说法，Kismet 作为真正的被动网络发现工具工作，并带有包注入功能。以下来自 `www.kismet.net`：“Kismet 是 802.11 二层网络检测器、嗅探器和入侵检测系统。Kismet 可以与任何支持原始监控（`rfmon`）模式的无线卡配合，并且（在适当硬件下）可以嗅探 802.11b、802.11a、802.11g 和 802.11n 流量。Kismet 还支持允许嗅探其他介质的插件。”你可能在考试中还会看到关于 Kismet 的另外两个重点：第一，它通过信道跳跃尝试发现尽可能多的网络。第二，它具有嗅探数据包并将其保存为 `Wireshark` 或 `tcpdump` 可读日志文件的能力。

![Image](img/w.jpg) **D** 是错误的，因为 Netsniff 被作为干扰项包含，并不是一个有效的工具。

### 10.

### 11.

关于 TKIP，以下哪些陈是正确的？（选择所有适用项。）

* **A.** 临时密钥完整性协议（TKIP）每 10,000 个数据包强制更改密钥。

* **B.** 临时密钥完整性协议确保密钥在会话期间不会。

* **C.** 临时密钥完整性协议是 WEP 的不可组成部分。

* **D.** 临时密钥完整性协议是 WPA 的不可组成部分。

![Image](img/r.jpg) **A, D.** TKIP 是无线安全的一大进步。它不再像 WEP 那样在与客户端会话期间保持单一密钥并重复使用，而是每 10,000 个数据包左右更改密钥。此外，密钥在可扩展身份验证（EAP）认证会话期间往返传输，以证明客户端属于 AP，反之亦然。TKIP 出现于 WPA。

![Image](img/w.jpg) **B** 和 **C** 只是陈述。TKIP 不维护单一密钥（它频繁更改），并且它是 WPA（以及 WPA2）的一部分，而不是 WEP。

### 12.

关于 SSID，以下哪些陈述是正确的？（选择所有适用项。）

* **A.** SSID 长度总是 32 个字符。

* **B.** SSID 最大 32 个字符。

* **C.** 关闭广播可以防止 SSID。

* **D.** SSID 是 AP 的每个数据包头部的一部分。

* **E.** SSID 为网络提供了重要的安全性。

* **F.** 在 ESS 内的 AP 之间移动需要多个 SSID。

![Image](img/r.jpg) **B, D.** 服务集标识符（SSID）在你的考试中只有一个唯一的实际功能：识别。它在任何形式、形状或结构上都不是安全特性，它的设计目的仅是区分一个接入点的网络与另一个——这也是它包含在所有数据包中的原因之一。SSID 最大可达 32 个字符，但不必那么长（事实上，你可能会发现大多数都不是那么长）。

![Image](img/w.jpg) **A** 是错误的，因为 SSID *必须*是 32 个字符。它们*可以*是，但不必填满 32 个字符的空间。

![Image](img/w.jpg) **C** 是错误的，因为“隐藏” SSID 实际上并不起什么作用。它仍然是每个数据包头部的一部分，因此发现它相对容易。
