#### 算法 2.2：轨道生成深度优先算法

**`Orbit-depth–first`**（轨道-深度优先）

- **数据结构：**
  - `levelcount`：为每一层计数的整数数组
  - `weight-structure stack`（权重结构堆栈）
  - 每个 `w` 权重结构包含：
    - `ω=⟨ω_1, …, ω_l⟩`：权重向量
    - `level`：`ω` 的层级
    - `from`：标记父级数值的整数
    - `i`：下一个待测试的索引

- **输入：**
  - `m=⟨m_1, …, m_I⟩`：控制权重
  - `D`：Dynkin 矩阵
  - `l`：G 的秩
  - `maxlevel`：计算轨道的最大层级

- **输出：** 权重向量列表 `ω=⟨ω_1, …, ω_l⟩` 及四个相关整数
  - 第一个整数表示 `ω` 在列表中的位置
  - 第二个整数表示 `ω` 的层级
  - 第三和第四个整数表示权重向量及 `ω` 的计算

- **过程：**
  1. 令 `level`= 0，`levelcount[level]`= 1，`i`= 1；
  2. 令 `from`= 1；// 父级数值的位置
  3. 令 `to`= 1；// 新权重值的位置，即已计算权重的总数
  4. 输出 `m`；// 初始状态，即尚未学习的原始样本集合
  5. 将 `m`，`level`，`from`，`i` 放入堆栈；
  6. 当 (`堆栈非空`) 时
     - 从堆栈中弹出 `ω`，`level`，`from`，`i`；
     - 当 (`i ≤ l`) 时
       - 如果 (`ω_i > 0`)
         - 如果 (`v_j ≥ 0` 对于 `i < j ≤ l` 成立)
           - //存储 `v` ?
           - 如果 (`i = 1 ≤ \bar{j}`)
             - 从堆栈中弹出 `ω`，`level`，`from`，`i + 1`；// 然后返回到 `ω`
           - `level` `+-`；
           - `levelcount[level]` `+-`；
           - 输出 `v`，`level`，`from`，`i`，`to`；
           - 如果 (`level ≥ max level`) 跳出 `while` 循环；
           - 将 `v` 复制到 `ω`；// 继续 `ω = v` 的轨道
           - 令 `i` 等于 `D_{\bar{j}}` 中的第一个元素；
         - 否则
           - `i +-`；
         - 结束如果
       - 结束如果
       - 否则
         - `i +-`；
       - 结束如果
     - 结束当
     - 结束当

**算法 2.5：规划选择算法：**

```
SELECT-RULE (G_n)
```
(1) 从规则集 `G_n` 中选择两个规则，让每个规则由一组可能不同的特征属性表示，`T_i = { k1, k2, …, kn }` 和 `T_j = { k'1, k'2, …, k'm }`，并标记选定的规则，表明它们已被比较。
(2) 计算相似度函数 `simi(T_i, T_j) = 1 - dist(T_i, T_j) / max-dist`。这里，根据类似性的不同属性对判断的重要性与贡献是不同的。根据类似性特征的不同特性，为不同的特征属性分配不同的权重，以确定重要性和贡献，可以定义带加权特征属性的正则相似度函数。
```
simi(T_i, T_j) = |T_i ∩ T_j| / |T_i| = Σ_{ki ∈ T_i ∩ T_j} Wi / Σ_{ki ∈ T_i} Wi
```
`// 根据相似度函数的值，我们可以看到规则的相似度，其中 dist(Ti, Tj) 是规则 Ti 和 Tj 之间的距离，max-dist 是规则集中的最大距离，wi 是 Ti 的特征属性权重。根据经验和实际情况，仅需确定各种特征属性的相关性。`
(3) 否则，重新选择比较规则，直到规则集中的规则都被比较，并结束算法。

对于监督学习，学习者输入带有标记（或输出值）的训练集（或输入）。样本通常以属性向量的形式给出，因此输入空间是 `R^n` 的子集。一旦给定了输入向量，就可以为该问题选择一定数量的假设函数集，其中线性函数最容易理解，应用也最简单。它可以以对偶形式表示。然而，复杂的实际应用需要比假设空间中的线性函数更具表达能力；它们需要比线性函数更具表达能力的空间。换言之，目标的概念通常不能由给定属性的简单线性函数生成。相反，我们应该寻找更抽象的数据特征进行研究。将数据映射到高维空间增加了线性学习者的计算能力，而对偶空间的扩展使得此步骤的隐式操作成为可能。对偶形式表示学习者的优势在于，可调参数的数量不依赖于表示中输入属性的数量。在具体的学习实践中，存在一些具体的学习问题。首先，学习算法可能效率低下，例如出现局部极小值的情况。其次，输出规模的假设往往过大而不切实际。第三，如果学习示例的数量有限，过大的假设函数类别将导致过拟合和泛化能力差。第四，学习算法通常受大量参数控制；参数的选择通常通过启发式参数调整过程完成，使得学习系统难以使用且不可靠 [10]。
