
### 3. L 满足非相干性质。

### 4. 正则化参数 `λ` 为常数，取值为 `λ = 1 / √l_max`。

### 5. 满足 `rank(L) ≤ C l_min / (ln l_max)²`（**`l_min = min(l₁, l₂)`**），其中 `C` 为常数。

换言之，基于矩阵 `M` 的*所有*元素，已知 `M` 为两个未知矩阵 `L` 和 `S` 之和，前者为低秩，后者为稀疏，PCP 以概率近乎 1 精确恢复 `L` 和 `S` 两者，无论 `S` 的元素幅值有多大，前提是 `r` 和 `k` 均充分小。

前述任务的适用性非常广泛。例如，PCP 可用于求取 `M` 的低秩近似。与标准 PCA（SVD）方法不同，PCP 在异常值存在时具有鲁棒性且不敏感，因为异常值通过 `S` 的存在得到了自然建模。注意，异常值本质上是稀疏的。因此，上述任务广为人知，称为*通过核范数最小化实现的鲁棒 PCA*。（已知更经典的 PCA 技术对异常值敏感，过去曾提出许多替代方法以实现其鲁棒化（例如，[98,109]）。

当 PCP 作为一种鲁棒 PCA 方法时，关注的矩阵是 `L`，而 `S` 代表异常值。然而，PCP 同时估计 `L` 和 `S`。稍后将讨论，当关注焦点转移到稀疏矩阵 `S` 本身时，另一类应用也能得到良好适配。

#### 备注 20.8

*   正如 `ℓ₁` 最小化是稀疏建模中组合 `ℓ₀` 最小化问题最紧凸松弛，核范数最小化是 NP-hard 秩最小化任务最紧的凸松弛。除了核范数，还提出了其他启发式方法，例如对数行列式启发式 [74] 和最大范数 [76]。
*   作为秩最小化方法的核范数是与迹相关代价的推广，后者常用于控制领域的半正定矩阵秩最小化 [133]。确实，当矩阵为对称且半正定时，`M` 的核范数为特征值之和，因此等于 `M` 的迹。此类问题出现于例如秩最小化任务涉及协方差矩阵以及半正定托普利兹或汉克尔矩阵时（参见，如 [74]）。

### 20.10.3 矩阵补全与鲁棒 PCA 的应用

涉及这些技术的应用数量日益增加，其详尽阐述超出了本书的范围。接下来，将有选择地讨论一些关键应用，以揭示这些方法的潜力，同时帮助读者更好地理解其背后的概念。

#### 矩阵补全

矩阵补全问题出现的一个典型应用是*协同过滤*任务（例如 [167]），这对于构建成功的推荐系统至关重要。假设一群人对他们喜欢的产品提供了评分。随后，可以填充一个包含评分的矩阵，其中每一行对应不同的个体，列对应产品。以产品为不同电影的情况为例。相关矩阵必然是部分填充的，因为所有客户都看过所有电影并提交了评分的情况并不常见。矩阵补全为以下问题提供了一个潜在的肯定答案：我们能否预测用户会给尚未观看的电影打多少分？这是推荐系统的任务，旨在鼓励用户观看可能符合其偏好的电影。著名的 Netflix 奖^(¹⁶³) 竞赛的具体目标

上述问题为建立我们对矩阵补全任务的直觉提供了良好的契机。首先，个人对电影的偏好或品味通常由少量因素决定，例如性别、出演演员和产地大洲。因此，一个完全填充评分的矩阵预计将是一个低秩矩阵。此外，显然每个用户至少需要对一部电影进行过评分，才有希望填补其在所有电影上的评分。对每部电影也是如此。这一要求符合第 20.10.1 节中关于唯一性的第二个假设；即每行和每列至少需要知道一个条目。最后，设想一个用户根据与其他用户完全不同的标准对电影进行评分。例如，该用户可能随机打分，或者根据电影标题的首字母打分。该特定用户的评分无法用建模其他用户评分的奇异向量来描述。因此，对于这种情况，矩阵的秩会增加一，且该用户的偏好将由一组额外的左、右奇异向量来描述。然而，相应的左奇异向量将仅在对应该用户专用行的位置包含一个非零分量，而右奇异向量将包含归一化为单位范数的该用户评分。这种情形符合矩阵补全问题中之前讨论的关于唯一性的第三点。除非知道该特定用户的所有评分，否则矩阵无法被完全补全。

矩阵补全的其他应用包括系统辨识 [128]、从运动中恢复结构 [46]、多任务学习 [10] 和传感器网络定位 [136]。

#### 鲁棒 PCA/PCP

在协同过滤任务中，与矩阵补全相比，鲁棒 PCA 提供了一个额外的属性，这在实践中可能至关重要。即允许用户甚至篡改部分评分，而不影响低秩矩阵的估计。每当评分过程涉及非严格受控环境中的许多个体时，似乎都会出现这种情况，因为其中一些人偶尔会以临时性甚至恶意的方式提供评分。

PCP 的首批应用之一是在视频监控系统中（例如 [36]），其背后的主要思想被证明很受欢迎，并可扩展到许多计算机视觉应用。以摄像机记录一系列帧为例，这些帧由纯静态背景和包含少量移动物体（如车辆和/或个人）的前景组成。监控录像中的一项常见任务是从背景中提取前景，例如为了检测任何活动，或进行进一步处理，如人脸识别。假设连续帧按字典顺序转换为向量，然后作为列放入矩阵 `M` 中。由于背景的存在，即使背景可能因光照变化等原因略有变化，连续列也预期高度相关。因此，背景对矩阵 `M` 的贡献可以建模为一个近似低秩矩阵 `L`。另一方面，前景中的物体表现为“异常”，对应每帧中仅一小部分像素，即矩阵 `M` 每列中有限数量的条目。此外，由于前景物体的运动，这些异常的位置很可能从 `M` 的一列变到下一列。因此，它们可以建模为一个稀疏矩阵 `S`。

## 20.11 案例研究：fMRI 数据分析

在大脑中，涉及动作、感知、认知等的任务，是通过若干所谓的*功能脑网络*（FBN）的同时激活来执行的，这些网络通过适当的相互作用以有效地完成任务。此类网络通常与低级大脑功能相关，并被定义为若干个*分离的*专业化小脑区，这些脑区可能分布在整个大脑中。对于每个 FBN，所涉及的分离脑区定义了*空间图谱*，这表征了特定的 FBN。此外，这些脑区无论其解剖学上的远近，都表现出*强*功能连接性，这表现为这些区域激活时间模式的强相干性。此类功能脑网络的例子包括视觉、感觉运动、听觉、默认模式、背侧注意和执行控制网络 [148]。

*功能性磁共振成像*（fMRI）[131] 是一种强大的无创工具，用于检测随时间变化的大脑活动。最常见的是，它基于*血氧水平依赖*（BOLD）对比度，这转化为检测激活脑区中含氧血液血流动力学流的局部变化。这是通过利用含氧血红蛋白与脱氧血红蛋白不同的磁学特性来实现的。检测到的 fMRI 信号同时在空间（三维）和时间（一维）域中记录。空间域通过三维网格分割为边长 3-5 毫米的基本立方体，称为*体素*。通常，一次完整的体积扫描由 64 × 64 × 48 个体素组成，并在一到两秒内采集完成 [131]。依赖于充分的后处理，可有效补偿可能的时间滞后和其他伪影 [131]，因此可以相当准确地假设每次采集都是瞬时完成的。对应单次扫描的总共 `l` 个体素值，被收集到一个扁平化的（行）一维向量 `x[n] ∈ ℝ^l` 中。考虑 `n = 1, 2, …, N` 次连续采集，全部数据被收集在一个数据矩阵 `X ∈ ℝ^(N×l)` 中。因此，`X` 的每一列 `i = 1, 2, …, l` 代表对应第 `i` 个体素值随时间的演变。每一行 `n = 1, 2, …, N` 对应在相应时刻 `n` 所有 `l` 个体素上的激活模式。

记录的体素值源于若干 FBN 的累积贡献，其中每一个 FBN 都遵循特定的时间模式被激活，这取决于大脑正在执行的任务。上述过程可根据数据矩阵的以下分解进行数学建模：

```
X = ∑_{j=1}^m a_j z_j^T := AZ
```

其中 `z_j ∈ ℝ^l` 是一个稀疏潜变量向量，代表第 `j` 个 FBN 的空间图谱，仅在对应于与特定 FBN 相关的脑区位置上具有非零值，而 `a_j ∈ ℝ^N` 代表相应 FBN 的激活*时间进程*。该模型假设有 `m` 个 FBN 被激活。为了更好地理解上述模型，以仅激活一组脑区（一个 FBN）的极端情况为例。此时矩阵 `X` 可写为

```
X = a_1 z_1^T := [a_1(1); a_1(2); ...; a_1(N)] [..., *, ..., *, ..., *] (l voxels)
```
