
`prefix="His age is "`

`age=14`

`sentence=prefix + age.to_s`

`puts sentence`

Ruby 能够使用 `cgi` 模块中的 `CGI.escape` 函数执行 URL 编码。以下是执行该任务的示例代码：

```ruby
require 'cgi'

url = "Chapple & Seidl"
encodedurl = CGI.escape(url)

puts "Original URL: ", url
puts "Encoded URL: ", encodedurl
```

如果你运行这段代码，你会注意到编码后的字符串与之前的示例略有不同，它使用 `+` 符号返回“Chapple+%26+Seidl”，而不是使用 `%20` 字符串来表示空格。这些在功能上是等效的。

### Python

Python 处理拼接的方式与 Ruby 相同。在名称拼接脚本中，唯一的微小区别是将 Ruby 的 `puts` 函数改为 Python 的 `print` 函数：

```python
first="Mike "
last="Chapple"
name=first + last
print(name)
```

Python 也不会隐式地将整数转换为字符串。就像你在 Ruby 中使用 `to_s` 方法显式执行此转换一样，你在 Python 中也使用 `str()` 函数来实现相同的操作：

```python
prefix="His age is "
age=14
sentence=prefix + str(age)
print(sentence)
```

与 Ruby 一样，Python 需要一个单独模块来执行 URL 编码。你应该使用在 `urllib.parse` 库中的 `quote_plus` 函数。在 Python 中执行 URL 编码的代码如下：

```python
import urllib.parse

url = "Chapple & Seidl"
encodedurl = urllib.parse.quote_plus(url)

print("Original URL: ", url)
print("Encoded URL: ", encodedurl)
```

#!/usr/bin/perl

## 流程控制

在任意一种语言中，我们都可以将基本脚本编写为一系列按顺序执行的命令。例如，以下 Python 脚本运行端口扫描，查找 `192.168.1.0/24` 网络中监听端口 `22` 连接的系统：

```python
import nmap

scanner = nmap.PortScanner()
scanner.scan('192.168.1.0/24', '22')
print("Scan complete")
```

此脚本由四行组成，Python 将按顺序执行它们。它从第一行开始，导入 `Nmap` 模块。一旦该命令完成，第二行创建一个端口扫描器，第三行使用该端口扫描器运行网络扫描。最后，第四行向用户打印扫描完成的消息。

尽管我们刚才查看的示例脚本按顺序运行，但并非每个脚本都如此。流程控制机制为开发人员提供了一种改变程序流程的方法。在以下各节中，我们将介绍两种流程控制技术：条件执行和循环。

### 条件执行

*条件执行*允许开发人员编写仅在满足特定逻辑条件时才执行的代码。最常见的条件执行结构是 `if..then..else` 语句。该语句的一般思想总结在以下伪代码中：

```
if (logical_test1) then
     command1
else if (logical_test2) then
     command2
else if (logical_test3) then
     command3
else
     command4
```

其工作原理如下。当程序到达此代码段时，它首先检查 `logical_test1` 是否为真。如果为真，则执行 `command1`，整个代码语句完成，不再执行任何额外检查。如果 `logical_test1` 为假，则程序检查 `logical_test2`。如果为真，则执行 `command2`。如果 `logical_test2` 为假，程序检查 `logical_test3`。如果该测试为真，则执行 `command3`。如果所有三个逻辑测试都为假，则执行 `else` 子句中的 `command4`。
