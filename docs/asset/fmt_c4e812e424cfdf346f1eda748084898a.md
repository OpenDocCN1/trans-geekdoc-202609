
# 入侵防御系统

入侵防御系统主要有两大类。`host-based intrusion prevention system (HIPS)`（基于主机的入侵防御系统）负责监控单个系统上的活动，通常通过查看日志、识别该系统上的可疑活动，然后采取纠正措施。`network-based intrusion prevention system (NIPS)`（基于网络的入侵防御系统）负责监控所有网络活动（不仅仅是单个系统上的活动），识别可疑网络流量，然后采取纠正措施。

## 带内与带外

在 IDS 和 IPS 的语境中，`in-band`（带内）是指内联放置的 IPS，这意味着流量必须通过它才能到达目标系统。这允许 IPS 不仅监控，而且在流量可疑时阻断流量。`Out-of-band`（带外）是指仅通过接收流量副本的方式监控网络中传输流量的 IDS/IPS。在这种情况下，IDS 只能触发警报或向管理员发送可疑流量通知。

## 分析

分析引擎是 IDS 中对收集到的流量进行分析的组件。分析引擎使用你在 IDS 上配置的规则来确定什么被视为可疑流量。规则中的动作告诉 IDS 如何响应可疑流量。

## 误报与漏报

在评估 IDS 时，请务必与产品供应商核实误报和漏报的可能性。如果某 IDS 产生大量误报，那可是坏消息，因为这意味着 IDS 会在不该触发警报时触发，或在该触发警报时却不触发。请为 Security+ 考试了解以下误报结果：

- **误报** 误报是指 IDS 报告存在可疑活动（阳性），但实际上并不存在（错误的假设）。简单来说，IDS 报告了可疑活动，但该活动并未发生。

- **漏报** 漏报是指 IDS 未发现任何可疑活动，但这同样是错误的——实际上确实发生了可疑活动！简单来说，IDS 未能检测到实际发生的可疑活动，因此也未进行报告。

## 欺骗与干扰

检测入侵的另一种方法是使用一些诱饵，抓住攻击者的现行，收集关于他们的信息，并减缓他们对生产系统的攻击。你可以结合使用蜜罐、蜜网和蜜文件等技术，吸引黑客的注意力，将他们引入陷阱！

### 蜜罐与蜜网

`蜜罐` 是一种放置在专用网络或 DMZ 中的系统，旨在将黑客从生产系统引开，转向蜜罐。黑客会花费时间尝试入侵蜜罐，而与此同时，你正在记录其活动，并让安装在蜜罐上的基于主机的 IDS 向你发送关于黑客存在的通知。

大多数公司都会犯一个错误，即不保护蜜罐，因为他们希望黑客能入侵它，但如果你让黑客太容易就攻破了蜜罐，黑客可能会察觉到陷阱而离开。至关重要的是，你要通过加固蜜罐来挑战黑客，并实施安全控制，使该系统看起来似乎具有价值。

另一个常见的安全术语是 `蜜网`，它是一个完整的网络，旨在伪装成生产网络，但其唯一目的就是将黑客从真正的生产网络中引开。

### 蜜文件

`蜜文件` 是放置在系统上的文件，用于诱使黑客打开它。当文件被打开时，你可以触发发送警报，通知你这一事实，从而让你知道系统上有人。例如，你可以在桌面上放置一个名为 `passwords.txt` 的文件，诱使攻击者以为你有一个包含所有密码的文件。当黑客打开该文件时，会发出警报，通知你该文件已被打开。

### DNS 污水池

`DNS 污水池` 是指 DNS 服务器针对已知恶意的 URL 或域名，响应虚假的 IP 地址信息。这些虚假 IP 地址被发送给客户端，使客户端无法连接到已知的恶意地址。

### 虚假遥测

`遥测` 是为监控目的而收集的数据。某些应用程序允许你生成虚假遥测数据，这些数据可能是关于基础设施、服务器和客户端的信息。可以生成虚假遥测数据，以测试使用遥测数据的解决方案。

- **网络分流器/端口分流器** 您也可以使用网络分流设备（也称为*端口分流器*），这是一种可连接到网络的硬件，并提供端口以将监控系统连接到该设备。

# 网络设计与管理原则

子网划分、网段和 `VLAN` 等核心网络设计要素构成了网络安全基础设施的很大一部分。在本节中，您将了解核心网络技术的重要性及其与安全的关系。

## 网络分段

网络分段是网络安全的重要组成部分，涉及在网络内创建不同的较小网络，称为*网段*。其好处是您可以在每个网段之间放置路由器或防火墙，从而控制允许在网段之间传递的流量。我们用于网络内部流量传输的术语是*东西向流量*。对于高安全环境，您可以决定不将某些网段连接在一起——从而将某个网段与网络其余部分隔离，以确保无法与该网段通信。作为参考，*南北向流量*代表来自网络外部的流量，例如互联网流量进入网络。绘制图表时，外部网络（如互联网）位于图表顶部，而您的网络位于外部网络以南。一旦进入您的网络，网段之间的流量即视为东西向流量。

### 子网划分用于分段

每个网段都需要自己的 IP 地址块，以便路由器在网段之间路由流量。子网划分是将 IP 地址块逻辑划分为较小网络块的过程。网络管理员通常进行子网划分以匹配物理网络结构。例如，如果您的公司有一个网络地址（如 `216.83.11.0`），但有两个由路由器连接的不同物理网络，则需要将该网络地址分解为两个不同的网络地址，称为*子网*。

要将网络地址分解为两个（或更多）子网，您需要操作该网络 ID 的子网掩码。在本例中，默认子网掩码为 `255.255.255.0`。要划分为两个网络，我需要将子网掩码最后一个八位字节的第一位转换为 `1`。这将得到一个新的子网掩码 `255.255.255.128` 和两个子网，称为 `216.83.11.0` 子网和 `216.83.11.128` 子网。

我知道这是对您 `Network+` 时代子网划分知识的快速回顾，但关键在于子网划分具有安全优势：一旦将某人分配到一个逻辑子网（IP 地址范围），除非您有路由器在网络之间路由，否则他们只能与该 IP 地址范围内的其他系统通信。

### 物理分段

在通信上实施控制的另一种方法是将网络分解为多个物理网段。根据目标不同，可以通过几种不同方式创建网段：

- **多个冲突域** 如果您的目标是拥有多个冲突域，则可以使用网桥、交换机或路由器对流量进行分段。这些设备上的每个接口都会创建一个冲突域，即一组其数据可能相互冲突的系统。每个冲突域也称为一个网段，其安全优势在于：默认情况下，位于某网段上的黑客监控流量只能捕获该网段上的流量。

- **多个广播域** 如果您想控制广播消息在网络上的传播范围，可以使用路由器将网络分解为多个广播域。使用路由器将网络分解为多个广播域的好处是，您可以在路由器上使用访问控制列表（`ACL`）来控制允许进入或离开每个广播域的流量（参见图 8-15）。

### 虚拟化

如今的虚拟化产品允许您使用虚拟网络对流量进行分段。通过虚拟网络，您可以将虚拟机（`VM`）放置在不同的网段上，并控制哪些 `VM` 可以相互通信。

### 气隙

在网络分段的语境下，*气隙*是一个概念术语，意味着一个网络与另一个网络没有任何连接点。例如，在高安全环境中，可能存在一个机密网络和一个非机密网络。由于机密网络的敏感性，两个网络之间不应有任何物理连接，从而形成气隙。

## 网络交换机

### 网络交换机安全特性

网络交换机为网络环境提供了强大的安全性。首先，网络交换机的设计初衷是过滤流量，仅将数据发送到交换机的目标端口。这意味着使用交换机可以防止他人轻松监控网络通信。交换机还有许多其他功能来增强网络安全：

#### 第二层与第三层

交换机可以是第二层交换机，也可以是第三层交换机。第二层交换机不具备任何路由功能；它只是一个交换机，旨在仅将流量发送到帧的第二层头部中包含的目标 MAC 地址。这被称为*介质访问控制 (MAC) 过滤*。第三层交换机本质上是交换机和路由器的合二为一。第三层交换机上既有交换机端口，也有少量路由器端口，旨在将数据发送到另一个网络。

#### 端口安全

您可以通过配置端口安全来控制哪些系统可以连接到交换机的端口。启用端口安全后，您可以将特定系统的 MAC 地址与该端口关联。只有具有该 MAC 地址的系统才能连接到该端口。

#### 环路保护

环路可能导致网络崩溃，因此拥有防止网络环路的方法至关重要。路由器使用数据包的生存时间 (TTL) 值来确定何时将数据包从网络中移除。交换机通过实施环路预防协议（如生成树协议 (STP)）来防止第二层环路。当您将交换机连接在一起（这会导致网络环路）时，STP 会动态选择环路中涉及的一个端口，并将其置于阻塞状态以消除环路。

#### 洪水防护

洪水防护通常是防火墙或路由器上的一项功能，允许您控制并阻断发送到您网络的恶意流量，例如洪水攻击。洪水流量的一个常见示例是 SYN 洪水攻击，黑客向您网络上的端口发送大量 SYN 报文。洪水防护会识别此类流量，阻止其进入网络，并防止拒绝服务 (DoS) 攻击。

#### 广播风暴防护

使用交换机，您可以利用 VLAN 创建不同的网络段，也称为*广播域*。这样做可以限制广播风暴的影响，因为广播报文被限制在 VLAN 内。

#### 网桥协议数据单元 (BPDU) 防护

交换机使用一种称为生成树协议的协议来防止网络环路。它们通过每 2 秒在网络上发送 BPDU 帧来发现可能存在的任何环路。连接到网络的黑客可能会通过发送自己的 BPDU 帧来执行中间人攻击。为了应对这种情况，您可以在端口上启用 BPDU 防护，这样如果交换机检测到 BPDU 报文，就会将该端口置于“错误禁用状态”。此功能应在所有连接用户工作站的端口上启用。

#### 动态主机配置协议 (DHCP) 嗅探

DHCP 嗅探是您可以在交换机上启用的一项功能，它允许交换机检测未经授权连接到您网络的流氓 DHCP 服务器。
