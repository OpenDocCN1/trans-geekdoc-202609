### 添加新列

来自 `dplyr` 包的 `mutate()` 函数用于根据现有列在 DataFrame 中创建新列。它将 DataFrame 作为第一个参数，后续参数指定要添加的新列。

`mutate()` 的一个关键方面是它会创建一个包含额外列的新 DataFrame，而不是就地修改原始 DataFrame。这是一个宝贵的特性，因为它允许用户保留原始数据的记录，并应用多重转换而不会覆盖它。

如何创建一个代表百万人口数的新变量？

*   `# 添加新列, population_millions`
*   `gapminder_population <- gapminder %>%`
*   `mutate(population_millions = population / 1000000)`
*   
*   `# 添加新列, population_millions`
*   `gapminder_population2 <- gapminder %>%`
*   `mutate(population_millions = round(population / 1000000, 2))`

它通过 `mutate()` 函数创建了一个名为 `population_millions` 的新列，方法是将现有的 `population` 列除以 1,000,000，并使用 `round()` 函数将结果四舍五入到小数点后两位。该命令返回一个 DataFrame `gapminder_population2`，包含原始 Gapminder DataFrame 的所有列以及一个新列 `population_millions`，其中包含每个国家以百万为单位的人口数。

如何提取国家名、年份、预期寿命、洲和地区，并识别哪些国家位于亚洲？

*   `# 提取国家名、年份、预期寿命、洲和地区，并识别国家是否位于亚洲`
*   `gapminder_is_asia <- gapminder %>%`
*   `select(country, year, life_expectancy, continent, region) %>%`
*   `mutate(is_asia = ifelse(continent == "Asia", 1, 0))`
*   
*   `View(gapminder_is_asia)`

该命令使用 `mutate()` 函数添加了一个名为 `is_asia` 的新列。新列包含值 1 或 0 的二进制值，具体取决于该国家是否位于亚洲。使用基础包中的 `ifelse()` 函数来分配二进制值。如果 `continent` 的值为 Asia，则分配值 1；否则设置为 0。

该变量有助于分析和比较亚洲国家与区域外国家之间的趋势和模式。

### 处理因子

在 R 中使用因子的一个主要优势是，它提供了一种保留数据底层顺序的方法，这对于分析和可视化可能是必要的。例如，假设你有一个客户满意度评分数据集，评分范围为 1 到 5，其中 1 代表非常不满意，5 代表非常满意。如果你将此变量存储为因子，R 将保留水平的顺序，这对于计算汇总统计量非常重要。

在本节中，你将使用 `forcats` 包，它是 R 中 tidyverse 套件的一部分，为处理因子提供了额外的功能。例如，它允许轻松操作因子水平和标签，并提供重新排序和重命名因子水平的函数。

如何计算每个洲的观测值数量？

*   `# 检查因子变量 continent 的 levels 属性`
*   `levels(gapminder$continent)`
*   `## "Africa" "Americas" "Asia" "Europe" "Oceania"`
*   
*   `# 计算每个洲的观测值数量`
*   `continent_count <- fct_count(gapminder$continent)`
*   
*   `View(continent_count)`
*   `## f n`
*   `## Africa 2907`
*   `## Americas 2052`
*   `## Asia 2679`
*   `## Europe 2223`
*   `## Oceania 684`
*   
*   `# 通过设置参数 sort 为 TRUE 对结果排序，并通过 prop 参数显示比例`
*   `continent_count_sorted <- fct_count(gapminder$continent, sort = TRUE, prop = TRUE)`
*   
*   `View(continent_count_sorted)`
*   `## f n p`
*   `## Africa 2907 0.276`
*   `## Asia 2679 0.254`
*   `## Europe 2223 0.211`
*   `## Americas 2052 0.195`
*   `## Oceania 684 0.0649`

`fct_count()` 返回一个包含两列的 DataFrame：因子水平及其在输入向量中对应的频率。在本例中，它将返回一个包含 Gapminder 数据集中唯一洲及每个洲出现次数的 DataFrame。

如何向 continent 变量添加新水平？

我们数据集中的变量之一是 `continent`，它包含每个国家所属洲的信息。现在，假设你注意到 `continent` 变量中缺少 Antarctica（南极洲），并且你想将其添加到因子水平中。一种方法是使用 `forcats` 包中的 `fct_expand()` 函数。

*   `# 向 continent 变量添加 "Antarctica"`
*   `gapminder$continent <- fct_expand(gapminder$continent, "Antarctica")`
*   
*   `# 检查 continent 的水平以验证 Antarctica 是否已添加`
*   `levels(gapminder$continent)`
*   
*   `## "Africa" "Americas" "Asia" "Europe" "Oceania" "Antarctica"`
*   
*   `# 计算每个洲的观测值数量`
*   `fct_count(gapminder$continent)`
*   `## A tibble: 6 x 2`
*   `## f n`
*   `## <fct> <int>`
*   `## Africa 2907`
*   `## Americas 2052`
*   `## Asia 2679`
*   `## Europe 2223`
*   `## Oceania 684`
*   `## Antarctica 0`

> **注意：** 如果 Antarctica 水平已存在于 continent 变量中，`fct_expand()` 不会再次添加它。相反，它只会返回水平保持不变的原始因子。

如何从 continent 变量中删除未使用的水平？

要从 continent 变量中删除未使用的水平，可以使用 `fct_drop()` 函数。具体操作如下：

*   `# 从 continent 变量中删除未使用的水平`
*   `gapminder$continent <- fct_drop(gapminder$continent)`

现在，如果你重新检查 continent 的水平，会注意到未使用的水平 Antarctica 已被移除。

*   `levels(gapminder$continent)`
*   `## "Africa" "Americas" "Asia" "Europe" "Oceania"`

如何将 Asia 移动到 continent 列的第二位？

在某些场景中，重设因子水平变得至关重要，因为它允许你更改分类变量水平的顺序，这可能会影响统计函数和数据可视化的行为。

例如，如果你有一个代表一周中日期的因子变量，水平的默认顺序将是按字母顺序排列（即 Friday、Monday、Saturday、Sunday、Thursday、Tuesday、Wednesday）。然而，假设你想按一周中日期的顺序来分析或可视化数据。在这种情况下，有必要将因子水平重新排序以反映日期的逻辑顺序（即 Monday、Tuesday、Wednesday、Thursday、Friday、Saturday、Sunday）。

*   `# 将 Asia 移动到第二位`
*   `gapminder$continent <- fct_relevel(gapminder$continent, "Asia", after = 1)`
*   
*   `levels(gapminder$continent)`
*   `## "Africa" "Asia" "Americas" "Europe" "Oceania"`

此命令将通过将水平 Asia 移动到第一个默认水平之后的第二位来修改 `continent` 列。参数 `after` 指定了水平应移动到的位置。

### 处理缺失值

符号 `NA`（不可用）在 R 中用于表示缺失值，而不可能的值（如除以零）则用非数字 (`NaN`) 表示。

函数 `is.na()` 用于检查对象是否包含由 `NA` 表示的任何缺失值，而 `is.nan()` 用于测试对象是否包含任何 `NaN` 值。

例如，要检查 `infant_mortality` 变量中的缺失值，可以使用以下代码：

*   `# infant_mortality 列中的缺失值数量`
*   `sum(is.na(gapminder$infant_mortality))`
*   `## 1453`

这将给出 `infant_mortality` 变量中缺失值的总数。我们可以对其他变量使用相同的代码来检查缺失值。要逐列了解数据集中缺失值的数量，可以使用以下代码：

*   `# gapminder 数据集每列的缺失值数量`
*   `colSums(is.na(gapminder))`
*   `## country year infant_mortality life_expectancy fertility`
*   `## 0 0 1453 0 187`
