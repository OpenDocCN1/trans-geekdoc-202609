
# 从 PHP 7 升级到 PHP 8

从 PHP 7 升级到 PHP 8 对许多开发者和项目来说是一个重要步骤。PHP 8 引入了多项改进语言的变更，但可能需要对现有代码库进行调整。在本节中，我们将探讨平滑迁移的关键考量因素和步骤。

## 1.4.1. 已弃用的功能

PHP 8 弃用并移除了一些 PHP 7 中可用的功能和函数。识别并更新代码库以移除或替换这些已弃用功能至关重要。示例包括：

*   **已移除的函数**：`create_function()` 和 `each()` 等函数已在 PHP 8 中移除。你需要寻找替代方案或重构代码。
*   **已弃用的扩展**：某些扩展（如 `mcrypt`）已被弃用并移除。确保你的应用程序不再依赖这些扩展，并使用现代替代方案。

## 1.4.2. 兼容性检查

在迁移到 PHP 8 之前，检查现有代码的兼容性至关重要。你可以使用 `PHP Compatibility Checker` 等工具扫描代码库中的潜在问题。该工具可识别已弃用的函数、不兼容的扩展和其他兼容性问题。

## 1.4.3. 类型声明

PHP 8 引入了更严格的类型声明，包括指定联合类型和返回类型的能力。检查你的函数和方法签名，确保它们符合新的类型声明要求。这增强了代码清晰度，并有助于防止类型相关错误。

## 1.4.4. JIT 编译器

PHP 8 的即时编译（JIT）编译器可以显著提升 CPU 密集型任务的性能。然而，它可能并不适用于所有类型的应用程序。评估你的应用程序负载，并确定启用 JIT 编译器是否能带来明显的性能提升。

## 1.4.5. 空值安全运算符

新的空值安全运算符（`?->`）简化了空值处理。在适当的地方更新代码以利用此运算符，减少冗长的空值检查。

## 1.4.6. 测试

彻底的测试在迁移过程中至关重要。编写单元测试和集成测试，确保代码在 PHP 8 中正常运行。测试应用程序的性能，以评估 PHP 8 升级的影响。

## 1.4.7. 第三方依赖

检查项目中使用的第三方库和包的更新。确保这些依赖兼容 PHP 8，或在必要时寻找替代包。

## 1.4.8. 错误处理

PHP 8 对错误处理和报告引入了变更。熟悉新的错误类型和报告选项。更新你的错误处理策略以适应这些变更。

## 1.4.9. PHP 配置

检查你的 PHP 配置（`php.ini`），并根据 PHP 8 的需要更新设置。注意与已弃用功能、错误处理和性能设置相关的变更。

## 1.4.10. 发布策略

仔细规划你的发布策略。考虑先在预发布环境中部署 PHP 8，以便在更新生产环境之前识别并解决任何问题。

## 1.4.11. 持续监控

迁移到 PHP 8 后，持续监控应用程序的性能、错误日志和安全性。准备好解决应用程序在 PHP 8 环境中运行时可能出现的任何问题。

## 1.4.12. 文档

更新项目文档以反映 PHP 8 的要求和代码行为的任何变更。这确保你的团队和未来的贡献者了解项目中 PHP 8 的特定方面。

从 PHP 7 迁移到 PHP 8 可能是一个复杂的过程，但周密的计划和测试将帮助你平滑过渡到最新版本的 PHP，在利用其新功能和性能改进的同时，保持应用程序的可靠性。

## 2.1. 全新 JIT 编译器：概念与优势

PHP 8 引入了一项名为即时编译（JIT）编译器的开创性功能，有望显著提升 PHP 应用程序的性能。在本节中，我们将深入探讨 JIT 编译器，探索其概念及其为 PHP 生态系统带来的优势。

### 2.1.1. 理解 JIT 编译

JIT 编译是各种编程语言中用于提高代码执行速度的一种技术。JIT 编译器不是逐行解释源代码，而是在代码执行前将其翻译成机器码。然后由 CPU 直接执行该机器码，这比解释源代码要快得多。

在 PHP 8 中，JIT 编译器通过获取频繁执行的 PHP 代码块（称为“追踪”）并将其编译为优化的机器码来工作。这些追踪会在脚本执行期间即时被识别和编译。这种方法旨在加速 PHP 代码中 CPU 密集型部分的执行。

### 2.1.2. JIT 编译器模式

PHP 8 为 JIT 编译器提供了两种模式：

1.  **追踪 JIT**：在此模式下，JIT 编译器识别频繁执行的追踪并对其进行编译。追踪 JIT 旨在提高 CPU 密集型工作负载的性能。
2.  **函数 JIT**：此模式专注于编译整个函数，而不仅仅是追踪。它有利于减少函数调用的开销，并提高 I/O 密集型工作负载的性能。

### 2.1.3. 在 PHP 8 中配置 JIT

您可以在 `php.ini` 配置文件中配置 JIT 编译器。以下是启用 JIT 编译器并设置其参数的示例：

```ini
[jit]
jit=on
jit_buffer_size=64M
```

在本例中，`jit=on` 启用 JIT 编译器，而 `jit_buffer_size=64M` 指定 JIT 缓冲区的大小。JIT 缓冲区大小决定了分配多少内存用于存储编译后的代码追踪。

### 2.1.4. JIT 编译的优势

PHP 8 中的 JIT 编译器提供了多项优势：

*   **性能提升**：主要优势之一是性能提升，特别是对于 CPU 密集型任务。复杂的数学计算和循环能从 JIT 编译中显著受益。
*   **降低 CPU 使用率**：通过将频繁执行的代码编译为机器码，降低了 CPU 使用率，使您的 PHP 应用程序更加高效。
*   **循环优化**：循环通常是 JIT 编译优化的目标。PHP 8 可以为循环生成优化的机器码，加快其执行速度。
*   **兼容性**：JIT 编译器旨在与现有 PHP 代码无缝协作，确保与您的 PHP 应用程序兼容。

### 2.1.5. 注意事项与警示

虽然 JIT 编译器提供了显著的性能改进，但仍需注意以下事项：

*   **内存使用**：启用 JIT 编译器可能会增加内存使用量，因为编译后的代码追踪存储在内存中。请留意内存限制，尤其是在共享主机环境中。
*   **预热时间**：JIT 编译器可能有一段短暂的预热时间，在此期间它会识别并编译频繁执行的代码。对您 PHP 应用程序的初始请求可能无法获得完整的性能收益。
*   **兼容性**：确保您的 PHP 代码与 PHP 8 及 JIT 编译器兼容。某些扩展和函数可能无法按预期工作。

总之，PHP 8 的 JIT 编译器是该语言的一项强大补充，为 CPU 密集型工作负载提供了显著的性能改进。通过理解其概念并进行适当配置，您可以充分发挥 JIT 编译的潜力来优化您的 PHP 应用程序。

## 2.2. 联合类型及其应用

PHP 8 引入了联合类型的概念，这是对语言类型系统的重大增强。联合类型允许变量或参数接受多种数据类型的值，为函数签名和参数验证提供了更大的灵活性。

### 2.2.1. 理解联合类型

联合类型通过使用竖线 `|` 在类型声明中分隔多个类型来表示。例如，一个同时接受整数和浮点数的参数可以声明如下：

```php
function processNumber(int|float $number) {
    // 函数逻辑
}
```

在本例中，`$number` 参数可以接受 `int` 或 `float` 数据类型的值。这意味着您可以将整数或浮点数作为参数传递给 `processNumber` 函数。

### 2.2.2. 联合类型的优势

联合类型在 PHP 开发中提供了多项优势：

*   **改进函数签名**：联合类型使函数签名更具表现力和准确性。您无需使用 `mixed` 等通用类型或仅依赖文档，即可精确指定参数或返回值可接受的类型。
*   **增强类型安全**：联合类型有助于在开发早期捕获类型相关错误。如果您尝试向函数传递不兼容的类型，PHP 将生成类型错误，从而提供更好的类型安全性。
*   **降低代码复杂度**：通过显式指定接受的类型，您可以减少函数内部复杂条件检查的需求，从而编写出更整洁、更易维护的代码。

### 2.2.3. 可空联合类型

除了联合类型，PHP 8 还允许可空联合类型。您可以通过在接受的类型列表中添加 `null` 关键字来表示联合类型为可空。例如：

```php
function processNullableString(string|null $text) {
    // 函数逻辑
}
```

在这种情况下，`$text` 参数可以接受 `string` 或 `null`。可空联合类型在处理可选参数或可能具有空值的属性时特别有用。

### 2.2.4. 方法签名中的联合类型

联合类型也可用于类和接口中的方法签名。以下是一个带有联合类型参数的类方法示例：

```php
class Calculator {
    public function add(int|float $a, int|float $b): int|float {
        return $a + $b;
    }
}
```

在本例中，`add` 方法可以接受 `int` 和 `float` 类型作为参数，并返回相同联合类型的值。

### 2.2.5. 类型兼容性

使用联合类型时，理解类型兼容性至关重要。例如，如果函数期望参数类型为 `int|float`，您可以传递 `int`、`float`，甚至可以隐式转换为任一类型的值。

```php
function processNumber(int|float $number) {
    // 函数逻辑
}

processNumber(42);    // 有效：int
processNumber(3.14);  // 有效：float
processNumber("42");  // 有效：字符串可隐式转换为 float
```

但是，传递不同类型的值（如无法转换为数字的字符串）将导致类型错误。

```php
processNumber("hello"); // 无效：字符串无法转换为 int|float
```

联合类型提供了一种强大的机制，以类型安全的方式处理多种数据类型。它们增强了代码清晰度，降低了类型相关错误的可能性，并有助于构建更健壮的 PHP 应用程序。

## 2.3. 命名参数及其用法

命名参数是 PHP 8 引入的一项新功能，可增强函数和方法调用的可读性和灵活性。本节探讨命名参数的概念，并演示如何在 PHP 代码中有效利用它们。

### 2.3.1. 什么是命名参数？

在传统的函数和方法调用中，参数是根据其在参数列表中的位置传递的。命名参数允许您通过参数名称指定参数，从而明确哪个参数对应哪个形参。当处理具有许多参数或可选参数的函数时，这尤为宝贵。

### 2.3.2. 使用命名参数

要使用命名参数，只需在调用函数或方法时提供参数名，后跟冒号 `:` 和参数值。以下是一个基本示例：

```php
function greet(string $name, string $message) {
    echo "Hello, $name! $message";
}

// 使用命名参数调用函数
greet(name: "Alice", message: "How are you?");
```

在本例中，我们在调用 `greet` 函数时显式指定了参数名 `name` 和 `message`。这提高了代码的可读性，特别是在函数拥有许多参数或复杂的参数顺序时。

### 2.3.3. 命名参数的优势

命名参数提供了多项优势：

*   **清晰性**：命名参数通过显式指示每个参数的用途，使函数调用更加不言自明。
*   **灵活性**：你可以按任意顺序提供参数，这在函数拥有可选参数或大量参数时特别有用。
*   **可读性**：代码变得更具可读性和可维护性，特别是对于参数众多的函数。你无需记住确切的顺序；只需查看参数名即可。
*   **避免错误**：命名参数有助于防止意外地将错误的值传递给参数，从而减少潜在的 Bug。

### 2.3.4. 组合使用命名参数和位置参数

PHP 8 允许你在函数调用中混合使用命名参数和位置参数。但是，位置参数必须位于命名参数之前。以下是一个示例：

```php
function greetUser(string $name, string $message, string $greeting = "Hello") {
    echo "$greeting, $name! $message";
}

// 使用位置参数和命名参数
greetUser("Alice", "How are you?", greeting: "Hi");
```

在本例中，我们首先对 `$name` 和 `$message` 参数使用位置参数，随后对 `$greeting` 参数使用命名参数。这种灵活性使你能够根据特定需求调整函数调用。

### 2.3.5. 默认值与命名参数

使用命名参数时，你可以轻松覆盖默认参数值。如果参数有默认值，你可以使用命名参数为该参数指定不同的值。当你想对某些参数使用默认值但更改其他参数时，这特别有用。

```php
function sendMessage(string $recipient, string $message, bool $urgent = false) {
    // 使用指定的紧急程度发送消息
}

// 使用命名参数发送紧急消息
sendMessage(recipient: "Bob", message: "Meeting canceled", urgent: true);

// 使用默认紧急程度发送非紧急消息
sendMessage(recipient: "Alice", message: "See you at 2 PM");
```

### 2.3.6. 最佳实践

虽然命名参数增强了代码的可读性和灵活性，但必须审慎使用：

*   将命名参数保留用于参数数量显著、具有可选参数或参数顺序复杂的函数。
*   命名参数时，请使用描述性强且有意义的名称，以阐明其用途。
*   在整个代码库中遵循一致的命名约定，以确保可读性和可维护性。

命名参数是 PHP 8 的一项宝贵补充，使你的代码更具表现力且更易于理解。它们为函数调用提供了更大的灵活性，并在处理具有许多参数或可选参数的函数时有助于防止错误。

## 2.4. PHP 8 中的属性：语法与用法

PHP 8 引入了属性，它提供了一种向类、函数、属性等添加元数据或注解的方式。在本节中，我们将探讨 PHP 8 中属性的语法和用法，在其他编程语言中也称为注解。

### 2.4.1. 什么是属性？

属性在其他语言中常被称为注解，是一种向代码元素附加额外信息的方式。它们提供了一种标准化且结构化的方式来标记代码，用于各种目的，如文档生成、验证或框架特定的功能。

属性包含在方括号 `[]` 中，并放置在它们所注解的代码元素之前。它们由一个名称组成，并可选择性地包含括号中的参数。

### 2.4.2. 创建自定义属性

你可以在 PHP 8 中通过定义一个类并使用 `#[Attribute]` 属性对其进行标记来创建自定义属性。该类可以拥有属性、构造函数和方法，以提供属性的功能。以下是一个自定义属性的示例：
