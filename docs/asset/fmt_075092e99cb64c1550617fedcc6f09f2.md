
⇔ (if and only if)。句子 `W[1,3] ⇔ ¬W[2,2]` 是**双条件**句。**其他书**中也写作 ≡。

Figure 7.7 提供了命题逻辑的正式语法；如果你不熟悉 BNF 记号，请参阅第 1060 页。BNF 语法本身是**模糊**的；包含多个运算符的句子可以通过语法在多种方式上解析。为了消除歧义，我们为每个运算符定义**优先级**。**否定**运算符（`¬`）优先级最高，这意味着在句子 `¬A ⋀ B` 中，`¬` 绑定得最紧，使其等价于 `(¬A) ⋀ B` 而不是 `¬(A ⋀ B)`。（算术符号的写法相同：`−2+4 = 2`，而不是 `−6`。）如果有疑问，请使用括号以确保正确的解释。方括号与圆括号含义相同；选择哪种仅为了让人更易阅读句子。

### 7.4.2 Semantics

在指定了**命题逻辑**的**语法**后，我们现在指定其**语义**。语义定义了在特定**模型**下判断句子真假的规则。在命题逻辑中，一个**模型**仅仅为每个命题符号指定**真值**——**true** 或 **false**。例如，如果知识库中的句子使用了命题符号 `P[1,2]`、`P[2,2]` 和 `P[3,1]`，则一个可能的模型是

> `m[1] = {P[1,2] = false, P[2,2] = false, P[3,1] = true}`.

## TRUTH VALUE

在三个命题符号的情况下，共有 2³ = 8 种可能的模型——正如 Figure 7.5 所描绘的那样。请注意，这些模型是**纯数学**对象，与 **wumpus 世界** 没有必然联系。`P[1,2]` 仅是一个符号；它可能表示“[1,2] 存在坑”，也可能表示“我今天和明天在巴黎”。

**命题逻辑的语义** 必须说明如何在任意模型下计算任意句子的真值。这通过**递归**实现。所有句子都由原子句子和五个**连接词**构成；因此，我们需要说明如何计算原子句子的真值，以及如何计算由每个连接词构成的句子的真值。原子句子很简单：

> • `True` 在每个模型中都为真，`False` 在每个模型中都为假。

> • 除了原子命题符号外，其他命题符号的真值必须在模型中直接指定。例如，在前面提到的模型 `m[1]` 中，`P[1,2]` 为假。

对于复杂句子，我们有五条规则，适用于任何子句 `P` 和 `Q` 在任意模型 `m`（这里 “iff” 表示 “当且仅当”）：

> • `¬P` 为真 **当且仅当** `P` 在 `m` 中为假。

> • `P ⋀ Q` 为真 **当且仅当** `P` 和 `Q` 在 `m` 中均为真。

> • `P ⋁ Q` 为真 **当且仅当** `P` 或 `Q` 在 `m` 中至少有一个为真。

> • `P ⇒ Q` 在 `m` 中为假 **仅当** `P` 为真 且 `Q` 为假。

> • `P ⇔ Q` 为真 **当且仅当** `P` 和 `Q` 在 `m` 中均为真 或均为假。

## TRUTH TABLE

规则也可以用**真值表**表示，真值表指定了复杂句子在其各组成部分的真值所有可能赋值下的真值。五个连接词的真值表在 Figure 7.8 中给出。根据这些表，我们可以在任意模型 `m` 下递归计算任意句子 `s` 的真值。例如，句子 `¬P[1,2] ⋀ (P[2,2] ⋁ P[3,1])` 在 `m[1]` 中的评估结果为 `true ⋀ (false ⋁ true) = true ⋀ true = true`。Exercise 7.3 要求你编写算法 `PL-TRUE?(s, m)`，该算法计算命题逻辑句子 `s` 在模型 `m` 中的真值。

> ![image](img/00179.jpg)

> **Figure 7.8** 真值表为五个逻辑连接词。例如，要计算当 `P` 为真、`Q` 为假时 `P ⋁ Q` 的值，先在左侧找到 `P` 为真且 `Q` 为假的那一行（第三行），然后在该行对应的 `P⋁Q` 列中查找结果：true。

真值表中 “且”、“或” 和 “否定” 的真值表与我们对英语单词 “and”, “or”, “not” 的直觉相符。主要的混淆点在于 `P ⋁ Q` 在 `P` 为真 或 `Q` 为真（甚至两者都为真）时为真。另一种连接词 “exclusive or” (“xor” 缩写) 在两个析取式均为真时返回假。关于独占或的符号没有共识，一些选择包括 `⋁`、`≠` 或 `⊕`。

**蕴含**的真值表可能不符合人们对 “`P` implies `Q`” 或 “如果 `P` 则 `Q`” 的直观理解。一方面，命题逻辑不要求 `P` 和 `Q` 之间存在因果关系或关联。例如，“5 是奇数 implies 东京是日本的首都” 在命题逻辑中是一个真句子（在常规解释下），尽管在英语中显得很奇怪。另一个混淆点是，只要前件为假，任何蕴含句都是真。例如，“5 是偶数 implies Sam 是聪明” 是真，无论 Sam 是否聪明。这看似荒谬，但如果把 “`P ⇒ Q`” 理解为 “如果 `P` 为真，我声称 `Q` 为真；否则我不声称任何内容”，那么只有当 `P` 为真 且 `Q` 为假时，该句才为假。

**双条件** `P ⇔ Q` 为真 **当且仅当** `P ⇒ Q` 和 `Q ⇒ P` 都为真。在英语中常写作 “`P` if and only if `Q`”。许多 **wumpus 世界** 的规则最好用 `⇔` 表示。例如，一个方格是 **清爽** *if* 一个相邻方格有坑，且一个方格是 **清爽** *only if* 一个相邻方格有坑。因此我们需要双条件：

> `B[1,1] ⇔ (P[1,2] ⋁ P[2,1])`,

其中 `B[1,1]` 表示 [1,1] 存在微风。

### 7.4.3 A simple knowledge base

在定义了命题逻辑的语义后，我们可以为 **wumpus 世界** 构建一个**知识库**。我们首先关注 **不可变** 的方面，mutable 部分稍后再讨论。目前，我们需要为每个 `[x, y]` 位置定义以下符号：

> `P[x,y]` 为真 当且仅当 `[x, y]` 存在坑。

> `W[x,y]` 为真 当且仅当 `[x, y]` 存在 **wumpus**（死或活）。

> `B[x,y]` 为真 当且仅当 代理在 `[x, y]` 感知到微风。

> `S[x,y]` 为真 当且仅当 代理在 `[x, y]` 感知到臭味。

我们编写的句子足以推导 `¬P[1,2]`（[1,2] 没有坑），如在第 7.3 节 非正式讨论中所作。我们为每个句子标记 `R[i]` 以便引用：

> • [1,1] 位置没有坑：
>
> `R[1] : ¬P[1,1]`.

> • 一个方格是 **清爽** **当且仅当** 一个相邻方格存在坑。此规则必须为每个方格陈述；目前仅包括相关的方格：
>
> `R[2] : B[1,1] ⇔ (P[1,2] ⋁ P[2,1])`.
>
> `R[3] : B[2,1] ⇔ (P[1,1] ⋁ P[2,2] ⋁ P[3,1])`.

> • 先前的句子在所有 wumpus 世界中均为真。现在我们为代理人所在的特定世界中前两个被访问的方格加入了微风感知，从而导致如 Figure 7.3(b) 所示的情况。
>
> `R[4] : ¬B[1,1]`.
>
> `R[5] : B[2,1]`.

### 7.4.4 A simple inference procedure

Our goal now is to decide whether `KB ⊨ α` for some sentence `α`. For example, is `¬P[1,2]` entailed by our `KB`? Our first algorithm for inference is a model-checking approach that is a direct implementation of the definition of entailment: enumerate the models, and check that `α` is true in every model in which `KB` is true. Models are assignments of true or false to every proposition symbol. Returning to our wumpus-world example, the relevant proposition symbols are `B[1,1]`, `B[2,1]`, `P[1,1]`, `P[1,2]`, `P[2,1]`, `P[2,2]`, and `P[3,1]`. With seven symbols, there are 2⁷ = 128 possible models; in three of these, `KB` is true (Figure 7.9). In those three models, `¬P[1,2]` is true, hence there is no pit in [1,2]. On the other hand, `P[2,2]` is true in two of the three models and false in one, so we cannot yet tell whether there is a pit in [2,2].

Figure 7.9 reproduces in a more precise form the reasoning illustrated in Figure 7.5. A general algorithm for deciding entailment in propositional logic is shown in Figure 7.10. Like the `BACKTRACKING-SEARCH` algorithm on page 215, `TT-ENTAILS?` performs a recursive enumeration of a finite space of assignments to symbols. The algorithm is `sound` because it implements directly the definition of entailment, and `complete` because it works for any `KB` and `α` and always terminates—there are only finitely many models to examine.

Of course, “finitely many” is not always the same as “few.” If `KB` and `α` contain `n` symbols in all, then there are 2^(`n`) models. Thus, the time complexity of the algorithm is `O(2^(n))`. (The space complexity is only `O(n)` because the enumeration is depth-first.) Later in this chapter we show algorithms that are much more efficient in many cases. Unfortunately, propositional entailment is co-NP-complete (i.e., probably no easier than NP-complete—see Appendix A), so *every known inference algorithm for propositional logic has a worst-case complexity that is exponential in the size of the input*.

## 7.5 PROPOSITIONAL THEOREM PROVING

So far, we have shown how to determine entailment by *model checking*: enumerating models and showing that the sentence must hold in all models. In this section, we show how entailment can be done by **theorem proving**—applying rules of inference directly to the sentences in our knowledge base to construct a proof of the desired sentence without consulting models. If the number of models is large but the length of the proof is short, then theorem proving can be more efficient than model checking.

## THEOREM PROVING

Before we plunge into the details of theorem-proving algorithms, we will need some additional concepts related to entailment. The first concept is **logical equivalence**: two sentences `α` and `β` are logically equivalent if they are true in the same set of models. We write this as `α ≡ β`. For example, we can easily show (using truth tables) that `P ⋀ Q` and `Q ⋀ P` are logically equivalent; other equivalences are shown in Figure 7.11. These equivalences play much the same role in logic as arithmetic identities do in ordinary mathematics. An alternative definition of equivalence is as follows: any two sentences `α` and `β` are equivalent only if each of them entails the other:

## LOGICAL EQUIVALENCE

> `α ≡ β` if and only if `α ⊨ β` and `β ⊨ α`.
