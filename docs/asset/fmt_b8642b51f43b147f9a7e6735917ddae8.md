### 1.5.2 无监督学习

与监督学习不同，无监督学习中没有标记数据可以学习，也不进行预测。在无监督学习中，目标是获取数据集并发现其中的分组或模式。因此，无监督学习通常被称为描述性模型。无监督学习的一个关键应用是客户细分。

聚类是无监督学习的主要类型。它旨在将相似的对象聚集在一起。属于同一个簇的对象是非常相似的，而属于不同簇的对象则非常不同。聚类的目标是发现数据的内在分组，如图 1.7 所示。常用的相似性度量之一是距离。如果两个数据项之间的距离较小，则被认为是同一个簇的一部分。同样，如果数据项之间的距离很大，通常不属于同一个簇。这被称为基于距离的聚类。图 1.8 展示了高层面的聚类过程。

### 1.5.3 强化学习

我们见过婴儿在没有任何先验知识的情况下学会走路。我们经常好奇他们是如何做到的。他们以一种相对简单的方式这样做。首先他们注意到周围有人走路，例如父母或周围的任何人。他们理解必须一次使用一条腿走路。走路时，他们有时会撞到障碍物倒下，而有时又能平畅地避开凹凸不平。

同样，机器经常学会自主执行任务。让我们通过孩子学习走路的例子来理解。要尝试实现的动作是走路，孩子是智能体，而孩子尝试行走的地方类似于环境。它试图提高完成任务的表现。当成功完成子任务时，会给予奖励。当子任务执行不正确时，显然不给予奖励。这种过程一直持续到机器能够完成整个任务的执行。这种学习过程被称为强化学习。图 1.10 捕捉了强化学习的高层过程。

## 1.6 不宜使用机器学习解决的问题

机器学习不应应用于那些人类处理非常高效或需要人类频繁干预的任务。例如，空中交通管制是一项非常复杂的任务，需要人类的高度参与。与同时，对于可以使用传统编程范式实现的简单任务，使用机器学习是没有意义的。例如，简单的规则驱动或基于公式的应用程序（如价格计算器引擎、纠纷跟踪应用等）不需要机器学习技术。

只有当业务流程存在缺陷时，才应该使用机器学习。如果任务已经过优化，引入机器学习将无法证明其投资回报的合理性。

在训练数据不足的情况下，机器学习无法有效使用。这是因为，在训练数据量较小的情况下，坏数据的影响会呈指数级恶化。为了保证预测或推荐的质量，训练数据应该是足够大的。

## 1.7 机器学习的应用

只要有大量的历史数据，就可以使用机器学习从数据中生成可操作的洞察。尽管机器学习在每个业务领域以多种形式被采用，但我们在下面涵盖了三个主要领域，旨在让大家了解可以使用机器学习执行哪些类型的操作。

### 1.7.1 银行与金融

在银行业，欺诈交易（尤其是与信用卡相关的交易）非常普遍。由于交易量和速度极快，全球几乎所有领先银行都实施了高性能的机器学习解决方案。这些模型基于实时运行，即在欺诈交易发生的瞬间就能被发现并阻止。这有助于避免在处理客户对这些欺诈交易提出的纠纷时产生大量的运营麻烦。

银行客户经常会收到其他竞争银行提供的优厚方案。更高的银行利率、更低的贷款手续费、零余额储蓄账户、无透支罚金等方案旨在吸引客户转到竞争银行。此外，有时客户会因为银行服务质量差而失去动力，并转向竞争银行。机器学习有助于防止或至少减少客户流失。描述性学习和预测性学习都可以用于减少客户流失。使用描述性学习，可以发现问题的特定环节，即特定的银行、特定的区域或特定类型的业务（如汽车贷款）流失率最高的地方。显然，这些是问题区域，需要进一步调查以发现并修复根源。使用预测性学习，可以识别出可能很快离开银行的易感客户。可以采取适当行动确保这些客户留下来。

### 1.7.2 保险

保险业是数据密集型行业。因此，机器学习在保险行业被广泛使用。保险行业中使用机器学习两个主要领域是新客户入驻期间的风险预测和理赔管理。在客户入期间，需要根据历史信息预测新客户的风险状况。根据预测的风险量为客户生成报价。

### 1.7.3 医疗健康

可穿戴设备的数据为机器学习提供了丰富的来源。一旦出现问题，可以向个人和医疗提供者发送警告。机器学习结合计算机视觉在医学影像诊断中也起着至关重要的作用。

## 1.8 机器学习中的先进语言/工具

与不同机器学习任务相关的算法众所周知，可以使用任何语言/平台实现。然而，某些语言和工具是专注于实现机器学习而开发的。下面涵盖了其中几个被广泛使用的工具。

### 1.8.1 Python

Python 是机器学习社区广泛采用的最流行的开源编程语言之一。它由 Guido van Rossum 设计，并于 1991 年首次发布。Python 的参考实现 `CPython` 由 Python 软件基金会管理，这是一个非营利组织。

Python 拥有强大的高级数学功能库 (`NumPy`)）、算法和数学工具库 (`SciPy`) 以及数值绘图库 (`matplotlib`)）。在这些库的基础上，有一个名为 `scikit-learn` 的机器学习库，它包含了各种分类、回归和聚类算法。

### 1.8.2 R

R 是一种用于统计计算和数据分析的语言。它是一种开源语言，在学术界非常受欢迎——特别是在统计学家和数据挖掘者中。R 被认为是 `S` 语言的变体，`S` 是贝尔实验室开发的 GNU 项目。目前，它由 R 统计基金会支持。

R 是一种非常简单的编程语言，为机器学习的不同阶段提供了大量的库。在流行程度上突出的一些库包括 `plyr`/`dplyr`（用于数据转换）、`caret`（分类和回归训练）、`RJava`（便于与 Java 集成）、`tm`（用于文本挖掘）、`ggplot2`（用于数据可视化）。

### 1.8.3 Matlab

MATLAB (矩阵实验室) 是一种受许可的商业软件，对广泛的数值计算提供强大的支持。MATLAB 在工业界和学术界拥有庞大的用户群。MATLAB 由 `MathWorks` 开发，这是一家成立于 1984 年的公司。作为一种专有软件，MATLAB 的开发更加专业，经过了严格的测试，并拥有完善的文档。

MATLAB 还对统计函数提供了广泛的支持，并内置了大量的机器学习算法。它还能够通过集群和云端上的并行处理，扩展到处理大规模数据集。

## 1.8.4 SAS

SAS（早期名为“统计分析系统”）是另一种受许可的商业软件，为机器学习功能提供强力支持。SAS 由 `SAS Institute` 使用 C 语言开发，于 1976 年首次发布。

SAS 是一个由不同组件组成的软件套件。基础的数据管理功能嵌入在 `Base SAS` 组件中，而其他组件如 `SAS/INSIGHT`、`Enterprise Miner`、`SAS/STAT` 等则帮助实现与数据挖掘和统计分析相关的专门功能。

## 1.8.5 其他语言/工具

还有许多其他支持机器学习功能的语言和工具。`SPSS`（原名为社会科学统计软件包）归 `IBM` 所有，是一个支持专门数据挖掘和统计分析的流行软件包。`SPSS` 最初在社会科学的统计分析中非常流行（正如其名称所示），现在在其他领域同样流行。

`Julia` 发布于 2012 年，是一种用于数值分析和计算科学的开源、采用自由许可的编程语言。它融合了 `MATLAB`、`Python`、`R` 以及其他用于机器学习的编程语言的所有优点，因此它正获得机器学习开发社区的持续关注。`Julia` 的另一个大优势是它能够实现高性能的机器学习算法。

## 1.9 机器学习面临的问题

机器学习是一个相对较新且仍在不断演变的领域。此外，机器学习工具和技术的研究水平及使用情况在不同之间存在巨大差异。不同国家的法律法规、文化背景、人们的情感成熟度不相同。这些因素使得机器学习的使用以及由机器学习使用产生的问题非常不同。

机器学习引发的最大恐惧和问题与隐私及其泄露有关。学习的主要重点是分析数据（包括过去和现在的数据），并从数据中得出洞察。这些洞察可能涉及个人，而揭示的事实可能足够隐私以保持保密。此外，不同的人在信息共享方面有不同的偏好。有些人可能愿意公开分享某种程度的信息，但另一些人可能不愿向所有朋友分享，而将其限制在家庭成员范围内。经典的例子如出生日期（不是具体的某一天，而是整个日期）、与家人约会的照片、教育背景等。有些人会在 `Facebook` 等社交平台上与所有人分享这些信息，而另一些人则不会，或者如果分享了，也可能仅限朋友可见。当使用这些信息实现机器学习算法时，人们可能会无意中感到不悦。例如，如果存在一种利用信息的学习算法。

## 1.10 总结

- 机器学习吸收了从经验中学习的哲学。

- 基础的机器学习过程可以分为三个部分：

    - **输入**：利用过去的数据作为未来的基础。

    - **抽象**：以总结的方式表示输入数据。

    - **泛化**：将抽象的表表示进行泛化，以形成决策。

- 机器学习可以分为三类：

    - **监督学习**：也称为预测学习。目标是根据先验信息预测类别/值。例如：肿瘤是恶性的还是良性的、房产等领域的价格预测。

    - **无监督学习**：也称为描述性学习，通过对相似对象分组来发现未知对象中的组或模式。例如：客户细分、推荐系统。

    - **强化学习**：机器学会行动以实现给定目标。例如：自动驾驶汽车、智能机器人。

- 机器学习已被多个领域采用，如银行金融服务、保险、医疗健康、生命科学。

- 实现机器学习的一些常用平台包括 `Python`、`R`、`MATLAB`、`SAS` 和 `SPSS`。

- 应用机器学习之前需要进行关键考虑。

## 2.1 引言

在上一章中，我们接触了机器学习。在开始阶段，我们预览了机器学习作为一种演进技术的历程。这一切始于著名计算机科学家艾兰·图灵（Alan Turing）的假设——机器可以学习并变得智能。在后的几十年里，通过阿瑟·萨缪尔（Arthur Samuel）、弗兰克·罗森布特（Frank Rosenblatt）、约翰·霍普菲尔（John Hopfield）、克里斯托夫·沃金斯（Christopher Watkins）、杰弗里·辛顿（Geoffrey Hinton）等许多其他计算机科学家的突破性创新，将神经网络、循环神经网络、强化学习、深度学习等概念推向了新的高度。与此同时，IBM 和 Google 等机构不断应用机器学习。从 IBM 的 `Deep Blue` 击败世界象棋冠军加里·卡斯波夫（Gary Kasparov）开始，到 IBM 的 `Watson` 在 Jeopardy 竞赛中击败两位人类冠军，Google 也开启了一系列机器学习创新。`Google Brain`、`Sibyl`、`Waymo`、`AlphaGo` 程序——都是机器学习的高级应用，将该技术提升了几个台阶。现在，我们可以看到机器学习技术在生活的方方面无处不在。

我们还看到了人类学习的类型，以及它们在某些方面与机器学习的类型（监督、无监督和强化学习）的联系。正如我们所看到的，监督学习意味着从过去的数据（也称为训练数据）中学习，这些数据具有已知的值或类别。机器从过去的数据“学习”或“训练”，并为未知数据（称为测试数据）分配类别或值。这有助于解决与预测相关的问题。这与婴儿通过父母的指导或学生通过老师的指导进行的人类学习非常相似。因此，机器的监督学习可以被视为从人类输入的引导式学习。无监督机器学习没有待标记的数据可供学习。它试图在未标记的数据中寻找模式。。这就像人类试图将形状相似的物体聚集在一起。这种学习不受标记标记的指导，而是利用从标签本身获得的知识。最后不是最的是强化学习，其中机器尝试通过惩罚/奖励机制进行自学——这与人类自学发生的方式非常相似。

最后，我们看到了机器学习在银行金融、保险和医疗保健等不同领域的应用。欺诈检测是一个关键业务案例，在全球几乎所有银行中实施，并主要使用机器学习。新客户的风险预测是保险行业另一个类似的案例，也发现了机器学习的应用。在医疗保健领域，疾病预测广泛使用了机器学习，特别是在发达国家。
