### 随机实验

实验是指产生结果的活动。可能有不同数量的可能结果。例如，掷骰子是一个有六种可能结果的实验。如果一个实验有不止一种可能结果，并且无法预先预测结果（即在实验进行之前），则称为**随机实验**。我们只有在掷骰子之后才知道骰子的结果！

#### 基本概率恒等式

若 `A` 和 `B` 为两个事件，则：

*   `P(not A) = P(A') = 1 – P(A)`
*   `P(A ∩ B)' = P(A' ∪ B')`，概率的德摩根定律
*   `P(A ∪ B)' = P(A' ∩ B')`，概率的德摩根定律
*   `P(A ∪ B) = P(A) + P(B) – P(A ∩ B)`
*   `P(A and not B) = P(A ∩ B') = P(A) – P(A ∩ B)`
*   `P(exactly one of A,B) = P((A and Not B)or (B and not A)) = P((A ∩ B’)U (A’ ∩ B)) = P(A) + P(B) – 2P(A ∩ B)`

### 全概率公式

所以，`P(A) = Σ P(A ∩ H[i])`

`P(A ∩ H[i]) = P(A|H[i]) P(H[i])`

### 贝叶斯定理

设 A 和 B 为两个事件，且 `P(B) > 0`；根据概率乘法法则，我们有：

`P(A|B) = P(A ∩ B) / P(B) = P(B|A) P(A) / P(B)`

这称为贝叶斯法则。正如你所见，这不过是乘法法则的另一种写法，但该法则在机器学习理论中有着广泛的应用。

这里，`P(A)` 代表事件 A 发生的*先验*信念。设 B 为另一个相关事件。了解事件 B 的发生会提供关于事件 A 的更多信息，我们称条件概率 `P(A|B)` 为*后验*概率。

让我们考虑一个针对特定疾病的医学检测示例：

*   A = 从人群中随机抽取的人患有该疾病的事件。
*   B = 一个人检测呈阳性的事件（无论其是否真正患病）。
*   已知检测灵敏度为 95%，即检测可能在 5% 的情况下漏检真正的患者。该检测有 5% 的*假阴性率*，即 `P(B|A) = 0.95`。
*   已知检测特异性为 97%，即 3% 的无病健康人检测结果呈阳性，或者检测有 3% 的*假阳性率*，即 `P(B| not A)` 或 `P(B|A') = 0.03`。

调查数据显示，人群中患有该疾病的比例约为千分之二十。这给出了该疾病的先验概率，即 `P(A) = 20/1000 = 0.02`。

现在，在这 20 个患者中，20x0.95 = 19 人将通过医学检测呈阳性。此外，在 1000-20 = 980 个健康人中，3% 将呈阳性，即 29.4 人将呈阳性。因此，总共有 19 + 29 = 48 人在 1000 人中通过该检测呈阳性。这给出了检测呈阳性的无条件概率 `P(B) = 0.048`。

现在，已知一个人检测结果呈阳性，其真正患病的概率是 `P(A|B) = 0.395`，即 39.5%。这是贝叶斯法则的一个简单应用。

***注意：`P(B)` 也可以使用全概率公式计算。我们有两个互斥且穷尽的事件 A 和 A’（A 的补集），根据全概率公式，`P(B) = P(B|A) P(A) + P(B|A') P(A') = 0.95 × 0.02 + 0.03 × 0.98 = 0.0484`。***

贝叶斯定理也可以推广到 n 个事件的集合。设 U 为样本空间。设 `H[1], H[2], ..., H[n]` 为*互斥且穷尽的事件*，使得 `∪ H[i] = U`。设 B 为 U 中任意事件且 `P(B) > 0`。则：

`P(H[i]|B) = P(B|H[i]) P(H[i]) / Σ P(B|H[j]) P(H[j])`

### 贝叶斯决策理论

贝叶斯决策理论是解决分类问题的一种基本统计方法。它基于贝叶斯定理，衡量将输入分配给给定类别的风险。让我们尝试通过一个简单的例子来理解这一点，该例子灵感来源于 Duda 和 Hart 关于模式识别的书（*延伸阅读 [4]*）。在一个鱼类包装厂，传送带上的鱼根据鱼的种类被人工分拣到不同的箱子中。假设他们发运两种鱼：“*海鲑鱼*”或“*海鲈鱼*”。他们想利用机械臂实现自动化，机械臂可以从传送带上抓取鱼并将其放入相应的箱子。第一步是构建一个分类器，判断传送带上的鱼是什么类型。

设 A 为鱼是“*海鲑鱼*”的事件；则 A’ 代表“*海鲈鱼*”。我们假设发现鲑鱼的类*先验概率*是已知的。这可能基于特定季节或捕鱼区域的可用百分比等。

*   **情况 1**：除类先验外没有其他信息可用。那么，如果 `P(A) > P(A')`，我们判定为“*鲑鱼*”，否则判定为“*海鲈鱼*”。
*   **情况 2**：我们得到了一个可以测量鱼体颜色深浅的传感器。此外，我们知道两种鱼的颜色深浅分布，如 图 4.10 所示，该分布是通过测量人工分拣鱼样本的颜色深浅获得的。由此，我们也得到了给定鱼类别下颜色深浅值的条件概率，即已知鱼是“*海鲈鱼*”时，颜色深浅值(L)在范围 `L < 6` 内的概率为 `P(L < 6|A') = (15 + 7 + 7 + 6)/50 = 0.7`。同理，已知鱼是“*鲑鱼*”时，`P(L < 6|A) = (1 + 2 + 3 + 4)/50 = 0.2` 且 `P(L ≥ 6|A) = (6 + 7 + 7 + 15)/50 = 0.7`。

现在，利用贝叶斯法则，我们可以计算反向条件概率，即已知来自传感器的颜色深浅值，某种特定鱼类的概率。

`P(A|L) = P(L|A) P(A) / P(L)`

分母对于两个类别相同；因此，我们可以预测分子值较大的类别为最可能的类别。请参考下图：

![](img/figure-4.09.jpg)

**图 4.10：** *基于每种鱼类 50 个样本计算的颜色深浅度量直方图*

如果 `P(L|A) P(A) > P(L|A') P(A')`，则鱼为鲑鱼，否则为海鲈鱼。

或者 `P(L|A) / P(L|A') > P(A') / P(A)`，则鱼为鲑鱼，否则为海鲈鱼。

这里，`θ` 是先验概率比或发现鲑鱼的赔率（已知），与 `P(L|A) / P(L|A')` 的比值，后者是颜色深浅度量的*似然比*。

### 随机变量与简单变量有何不同？

对于简单变量，我们无法说明该变量取某个给定值的可能性有多大，也无法说明其值落在各个范围内的可能性有多大，因为变量没有与之关联的概率。对于随机变量（r.v.），存在一个关联的概率测度，它告诉我们变量取某个特定值或某个特定范围值的可能性有多大。关于变量的这一额外信息将随机变量与简单变量区分开来，它表示为另一个函数，称为离散随机变量的**概率质量函数（P.M.F）**和连续随机变量的**概率密度函数（P.D.F）**。
