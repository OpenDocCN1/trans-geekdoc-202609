
归一化，通常也称为 min-max 缩放，是最简单的方法之一，涉及将特征的范围重新缩放到 `[0, 1]` 或 `[-1, 1]`。min-max 缩放的一般公式通常表示为 `(X - X_min) / (X_max - X_min)`，其中 `X_max` 和 `X_min` 分别是特征的最大值和最小值。当我们需要有界范围时，该方法被广泛使用，并且在应用于不假设数据分布的算法时非常有效，例如 `K-Nearest Neighbors` 和 `Neural Networks`。

数据缩放的另一种常见技术是标准化。与归一化不同，标准化不会将值限制在特定范围内，这对于假设数据以零为中心且方差处于同一数量级的某些算法可能很有用。该过程涉及从每个特征中减去均值并除以标准差。标准化的结果（或 Z-score 归一化）是特征将被重新缩放，使其具有标准正态分布的特性，其中 `μ = 0` 且 `σ = 1`，其中 `μ` 是均值（平均值），`σ` 是均值的标准差。

标准化受异常值影响小于 min-max 归一化。这使其成为假设数据呈正态分布的算法的更好选择，例如 `Logistic Regression`、`Linear Discriminant Analysis` 和 `Gaussian Naive Bayes`。特征的尺度对于其他基于距离且需要欧几里得距离的算法也很重要，例如 `Support Vector Machines` (`SVM`) 和 `K-Means clustering`。

`Robust Scaler` 是另一种对异常值稳健的缩放技术。该方法使用中位数和四分位距进行缩放，从而确保如果数据集中存在异常值，它们不会像在 min-max 缩放或标准化中那样影响缩放转换。当数据包含大量异常值或需要减少异常值对特征缩放的影响时，该技术特别有用。

`MaxAbsScaler` 是另一种缩放技术，按每个特征的最大绝对值缩放每个特征，以将数据转换到范围 `[-1, 1]` 内。这种缩放推荐用于已经以零为中心且没有异常值的数据。

缩放和归一化会显著影响机器学习算法的性能。例如，许多使用梯度下降方法进行优化的算法（例如 `linear regression`、`logistic regression` 和 `neural networks`）如果特征经过缩放和归一化，则收敛速度会更快。同样，使用距离度量的算法，如 `k-nearest neighbors` 和 `SVM`，如果所有特征都缩放到相同范围，则可以获得更好的结果。

同样重要的是，仅将缩放器拟合到训练数据，而不是整个数据集。这种做法对于避免模型训练过程中的数据泄漏至关重要。拟合缩放器到训练数据后，应将其用于转换训练集和测试集（或新数据），以便机器学习模型正确执行。

然而，必须理解，缩放和归一化并不总是能提高每种类型机器学习算法的性能。例如，`Decision trees` 和 `random forests` 对特征的尺度不敏感，因为它们的分割决策基于顺序而不是特定值。因此，对这些算法应用缩放或归一化可能不会带来任何显著好处，并且可能是不必要的步骤。

总之，虽然数据归一化和缩放是机器学习中预处理的强大技术，但其应用应根据数据的具体背景和所使用模型的类型来考虑。了解每种算法的性质和基础数据对于决定是否应用这些技术以及如何有效应用它们至关重要。

# Feature selection and feature engineering

`FEATURE SELECTION AND` feature engineering 是机器学习工作流程预处理阶段的两个关键步骤。这两个过程都旨在通过提高输入数据的质量来改进机器学习模型的性能。特征选择涉及从数据集中选择最有用的特征以降低维度和提高模型性能。另一方面，特征工程涉及从现有特征中创建新特征，以更好地捕捉数据中的潜在模式。

## 特征选择与特征工程

### 特征选择

特征选择主要在于尽可能识别并移除无关和冗余的信息。这一过程不仅有助于降低建模的计算成本，还有助于提升模型的性能。特征选择有多种技术，可大致分为三类：`filter methods`、`wrapper methods` 和 `embedded methods`。

`filter methods` 应用统计度量为每个特征分配评分；特征根据这些评分进行排序，然后选择排名靠前的特征，或丢弃排名靠后的特征。

`wrapper methods` 则使用不同特征子集评估多个模型，并根据特定标准选择表现最佳的组合。

`embedded methods` 在模型训练过程中执行特征选择，且特定于某些类型的模型，如 `decision trees` 和 `LASSO regression`。

### 特征工程

与此同时，特征工程是一门艺术，涉及理解数据的底层结构以及数据所来自的领域。目标是构建新的特征，使机器学习算法工作得更好。这一过程可包括编码分类数据、处理缺失值、归一化和缩放数据，以及生成交互特征等任务，这些特征可提供额外上下文或帮助揭示不那么明显且易于发现的模式。有效的特征工程可显著提升模型准确性，尤其是在复杂的数据集上，其中变量之间的关系是非线性的或不明显的。

#### 数值变量的转换

特征工程中一种常见技术是数值变量的转换。这可能涉及缩放或归一化数据，以确保数值落在相似范围内。对于对输入数据尺度敏感的模型而言，这一点尤为重要，例如 `support vector machines` 或 `k-nearest neighbors`。

#### 分类变量的编码

另一种技术是分类变量的编码。由于大多数机器学习模型是代数的，这意味着它们只能解释数值。诸如 `one-hot encoding` 或 `label encoding` 等技术可用于将分类变量转换为可提供给机器学习算法的格式。

#### 交互特征

交互特征是特征工程的另一个方面，其中通过组合两个或多个现有特征来创建新特征。这可以像简单地将特征彼此相加、相乘或相除一样简单。例如，在房地产数据集中，人们可能不仅独立考虑 `number of rooms` 和 `total square feet` 特征，还可以查看它们的比率作为新特征，这可以体现每间房的空间，可能对预测房价是一个有价值的见解。

#### 时间和空间特征

在时间和位置相关的的数据集中，也可对时空特征进行工程化。例如，从日期时间戳中提取星期几、月份或一天中的时间部分，可为预测随时间变化的模式提供有用见解。在空间数据中，位置之间的距离或在特定地理层级上的聚合对于交付服务中的需求预测或房地产定价模型等任务至关重要。

## 挑战

虽然特征选择和特征工程是机器学习数据预处理中的强大工具，但它们也伴随着挑战。对特征过度工程化可能导致模型复杂、可解释性较差且更容易过拟合。同样，激进的特征选择可能会导致丢失对模型有用的重要信息。因此，必须在模型简洁性的需求与从数据中捕获足够复杂性以做出准确预测的要求之间取得平衡。

## 结论

总之，特征选择和特征工程是机器学习项目成功的关键步骤。它们需要对数据的统计属性以及应用领域的上下文知识有深入的理解。做得正确时，这些过程可显著增强机器学习模型的性能，使其在解决现实世界问题时更高效、更有效。

### 处理不平衡数据

处理不平衡数据是机器学习中的常见挑战，尤其是在分类问题中，其中一个类别的实例数量显著超过一个或多个其他类别的实例数量。这种不平衡可能导致模型偏向多数类，从而导致对少数类的分类性能不佳。这是有问题的，因为通常少数类更受关注，例如在欺诈检测、医疗诊断或罕见事件预测等情况下。

解决不平衡数据集的一个基本策略是重采样。重采样可以是欠采样多数类或过采样少数类。欠采样涉及减少多数类中的示例数量以匹配少数类计数。虽然这有助于平衡类别分布，但也会导致潜在有价值的数据丢失，这可能使学习过程效果降低。过采样另一方面涉及复制少数类的实例以平衡多数类。诸如 `SMOTE` (`Synthetic Minority Over-sampling Technique`) 等技术更进一步，通过创建合成样本而不是简单复制现有样本。`SMOTE` 使用少数类实例的最近邻来创建新的合成实例，这有助于提供比简单复制更多的泛化。

另一种处理不平衡数据的方法是修改现有算法，使其对少数类更敏感。这可以通过在成本敏感学习中为误分类类别引入不同成本来实现。例如，可以将更高的成本分配给误分类少数类相比多数类。这种方法迫使模型更加关注少数类。诸如 `Decision Trees`、`SVMs` 和 `Logistic Regression` 等算法可被调整以直接将其成本纳入学习过程。

集成方法，如 `Random Forests` 和 `Boosted Trees`，对不平衡数据集也有效。这些方法构建多个模型并聚合其预测。例如集成方法 `Balanced Random Forest`，涉及修改标准 `Random Forest` 算法以在每个自助样本中平衡类别分布。同样，`AdaBoost` 可被调整以更关注少数类的实例，通过调整错误分类实例的权重，使算法在后续迭代中更关注难以分类的实例。

异常检测技术在少数类不仅更小而且定义也不明确的场景中特别有用。这些技术专注于建模什么是正常的，然后将新实例与该模型进行测试，看看它们是否显著偏离，从而将其标记为异常（潜在的少数类实例）。这种方法与典型分类不同，因为它旨在构建类别之间的边界，而是检测偏离常态的情况。

高级方法如聚类也可在使用分类之前用于不平衡数据集。聚类有助于识别类内的子组，这些子组可能具有不同的分布。然后可以在这些聚类上训练单独的分类器，或使用聚类特定的特征来增强分类模型。这种方法有助于理解数据的底层结构，并相应地定制模型以更好地处理不平衡。

Moreover, evaluation metrics play a crucial role in the development of models trained on imbalanced datasets. Traditional metrics like `accuracy` are not suitable as they can be misleading. For instance, in a dataset where 95% of the data belongs to the majority class, a naive model that always predicts the majority class will achieve 95% `accuracy`, despite having no predictive power on the minority class. Alternative metrics such as `Precision`, `Recall`, `F1-score`, and the Area Under the ROC Curve (`AUC-ROC`) provide more insight into the model's performance across different classes. The `AUC-ROC`, in particular, measures the ability of a model to discriminate between the classes at various threshold settings, which is crucial for imbalanced datasets.

Finally, the choice of method to deal with imbalanced data can depend heavily on the specific context of the problem, including the size of the dataset, the degree of imbalance, the importance of the minority class, and the particular characteristics of the data. Often, a combination of the aforementioned strategies rather than a single approach proves to be more effective in handling imbalanced datasets in practical applications.

# Data transformation techniques

`DATA TRANSFORMATION` is a critical process in machine learning that involves modifying raw data into a format that is more suitable for building and training machine learning models. This process not only helps in improving the accuracy of models but also in enhancing their efficiency and effectiveness in making predictions. There are several data transformation techniques used in machine learning, each serving a unique purpose and applicable in different scenarios.

One common technique is normalization, which adjusts the scale of the data so that it fits within a specific range, typically 0 to 1, or -1 to 1. This is particularly useful in cases where the dataset features vary widely in scale, as large scale discrepancies can cause machine learning algorithms to behave poorly or converge too slowly. Normalization ensures that each feature contributes approximately proportionately to the final prediction. A popular method of normalization is `Min-Max scaling`, which rescales the feature to a fixed range based on the minimum and maximum values. Another method is `Z-score normalization`, where the mean of the data is adjusted to 0 and the standard deviation to 1.

Standardization is another crucial data transformation technique. Unlike normalization, standardization does not bind values to a specific range, which might be necessary for models that assume that the data is normally distributed, like logistic regression and linear regression. Standardization transforms the data to have zero mean and a variance of one, making it easier for the training process to converge. This technique is particularly useful when dealing with features that exhibit different units of measure, as it removes the units and transforms the data into a pure number, facilitating the comparison and combination of different data sources.

Encoding is essential when dealing with categorical data. Most machine learning models are designed to work with numerical data, and encoding techniques transform categorical data into numeric formats. One common method is `label encoding`, where each category is assigned a unique integer. However, this can introduce a new problem of ordinality, where the model might misinterpret the numerical values as having some form of hierarchy or order. To overcome this, one-hot encoding can be used, which creates a new binary column for each category level. There are also more sophisticated encoding methods like `mean encoding` or using embedding layers, which can capture more complex relationships and are particularly useful in deep learning models.
