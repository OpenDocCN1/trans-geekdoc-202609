### 7.3 存内计算设备

本节将介绍可同时用于存储和计算的 ReRAM 交叉阵列设备。它将被用于支持 CMOS-ReRAM 存内计算加速器。第 7.2 节讨论的带有量化的大规模深度 ResNet 将被映射到其上。

#### 7.3.1 ReRAM 交叉阵列

ReRAM [62] 是一款面向未来的存内计算设备。ReRAM 的不同电阻状态可在计算时代表不同参数。除了作为存储内存工作外，ReRAM 交叉阵列还可用于执行逻辑运算 [263]，特别是基于点积的卷积。

[258, 259] 等先前工作通常选择仅有两种非易失性状态的两端子 ReRAM 器件：高电阻态（HRS）和低电阻态（LRS）来构建存内架构，如图 7.4(a) 所示。然而，当应用网络变得更深、更复杂时，两端子计算导致 ReRAM 交叉阵列性能受限，同时牺牲了网络精度。为实现所提出的 4-bit ResNet-50，我们采用 [270] 中的 ReRAM 模型，该模型具有多位电阻状态。所提出的 ReRAM 器件状态由置位电压 `![image](img/ch07_si90.gif)` 的分布决定。

#### 7.3.2 定制化 DAC 与 ADC 电路

To accommodate multi-bit networks on the ReRAM crossbar, we customized the designs of 4-bit DAC and ADC respectively, as shown in Fig. 7.5(a) and (b). To save area, the DAC is implemented using a resistor-resistor (R2R) structure with a compact Opamp buffer. Compared to traditional resistor dividers, R2R uses uniform resistance values, which is beneficial for achieving better matching. The Opamp buffer adopts a feedforward structure to minimize current consumption and achieve fast settling. Under a voltage bias of approximately `1.2V` and a current bias of `100μA`, the total Opamp current consumption is less than `50μA`, achieving a `100MHz` unity-gain bandwidth. Meanwhile, an ADC scheme similar to [271] is adopted to reduce switching power, which uses an asynchronous SAR to minimize area and energy.

#### 7.3.3 In-Memory Computing Architecture

Based on the developed 4-bit ReRAM crossbar devices and novel DAC/ADC circuits, we propose a CMOS-ReRAM in-memory computing accelerator, as shown in Fig. 7.6, where both storage and computation are implemented within the memory cells.

```
Figure 7.6 In-memory accelerator architecture based on 4-bit ReRAM crossbar for 4-bit quantized ResNet-50
```

In this architecture, data-logic pairs are laid out in a distributed manner, and data transfer between data blocks, logic blocks, and the external scheduler is maintained by a control bus. Therefore, logic blocks can read data locally and write back to the same data block after logic computation is completed [237]. Consequently, the huge communication burden between the memory and the general-purpose processor is alleviated, as most data transfers are completed within the data-logic pairs. Based on this in-memory computing architecture using the 4-bit CMOS-ReRAM accelerator, we will further introduce the strategy for mapping the proposed 4-bit quantized ResNet-50 onto it.
