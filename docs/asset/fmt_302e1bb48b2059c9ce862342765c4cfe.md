
先验的存在至关重要。正则化项“迫使”潜在变量的后验分布足够宽泛。例如，我们不希望同一类别的两个不同图像/样本被映射到潜在空间中两个不同且相距甚远的区域；即我们不希望它们对应的概率密度函数（PDF）非常窄、方差很小，且均值相差很大。我们的愿望是将同一类别的每个输入样本通过潜在变量映射/编码到潜在空间中一个足够小的区域内，使其彼此“足够接近”。我们的愿望是构建一个在局部尺度上对于相同样本足够平滑的潜在空间。事实上，我们的目标应是构建尽可能紧密（稠密堆积）的编码，同时仍保持不同类别之间的区分度（簇形成）。这将有利于在生成新样本时在不同类别之间进行平滑插值。此外，这种由 KL 项促进的稠密编码堆积，将极大地有助于根据标准高斯先验 `N(0, I)` 对潜在变量进行采样，并使解码器能够成功解码和生成样本。

一旦确定了所涉及分布的参数形式，剩下的工作就是针对未知参数最大化 `F`。考虑到采用的模型是前馈神经网络，优化任务所需的梯度是在反向传播框架下计算的。为此，引入了以下“技巧”，参见例如 [103]。

### 重参数化技巧

反向传播算法要求计算公式 (19.22) 中损失函数的梯度。正如我们即将看到的，KL 散度项不存在计算问题。相反，右侧第一项需要更多关注。在反向传播算法的每一步中，计算相应的梯度需要针对后验 PDF `q` 的当前估计进行平均运算。然而，事实证明，遵循标准论证（例如 [20]）通过从 `q` 中采样来获得相应平均梯度值的估计，会导致高方差的估计，使该方法相当不切实际，例如 [103]。

前述困难通过所谓的重参数化技巧得以绕过。其思路是将每一个潜在变量视为以下两方面的函数：a) 定义相应分布的参数（本例中为高斯分布）以及 b) 一个处理相关随机性的独立辅助随机变量。例如，在高斯分布的情况下，定义参数是均值和方差（协方差矩阵）。辅助随机变量可以服从简单的 PDF（例如高斯或均匀分布）。只需该函数是可微的。在当前语境下，隐含的变换是线性的，涉及的随机潜在变量表示为

```
z[i] = μ[i] + σ[i]ε[i], i = 1, 2, …, m,
```

其中 `ε[i]` 是均值为零、方差为单位的相应辅助随机变量。将 `ε[i], i = 1, 2, …, m` 堆叠成随机向量 `ε ∈ ℝ^(m)`，则对应于 `x[n]` 的潜在随机向量可写为

```
z[n] = μ[n] + σ[n] ⊙ ε,
```

其中 `σ[n]` 是由相应的 *m* 个方差组成的向量，⊙ 表示逐元素乘法。要抽取潜在变量的样本，即 `z[n]^(k)`，*k* = 1, 2, …，只需抽取辅助变量的相应样本 `ϵ^(k)` 即可。因此，在抽取 *K* 个连续样本后，公式 (19.22) 中损失函数的第一项可以用相应的样本均值来近似，即

```
A_n := E_q[ln p(x_n|z;θ)] = (1/K) ∑_{k=1}^K ln p(x_n|z_n^(k);θ)
```

其中

```
z_n^(k) = μ_n + σ_n ⊙ ϵ^(k).
```

回顾条件概率 *p* 是高斯分布，其对数可以直接计算。项 `A[n]` 是 `θ` 和 `ϕ` 的函数（通过 `μ[n]` 和 `σ[n]`）。使用重参数化技巧，相关估计量的方差大幅降低。因此，*K* 不需要取很大的值。实际上，仅抽取一个样本，即 *K* = 1，在大多数情况下似乎就足够了。

公式 (19.22) 右边的第二项对于高斯概率密度函数可以解析计算。考虑到先验 `p(z)` 是零均值、单位方差的标准高斯分布，经过相关代数运算^(¹³²) 后可以证明，

###### 备注 19.4

$B_{n} := - \text{KL}\left( q(\mathbf{z}|\mathbf{x}_{n};\boldsymbol{\phi}) \| p(\mathbf{z}) \right) = \frac{1}{2}\sum\limits_{i = 1}^{m}\left( 1 + \ln(\sigma_{ni}^{2}) - \mu_{ni}^{2} - \sigma_{ni}^{2} \right).$

项 $B_{n}$ 是 $\boldsymbol{\phi}$ 的函数，通过所涉及的均值和方差体现。代价函数通过对所有输入样本求和形成，即

$\mathcal{L}(\boldsymbol{\phi},\boldsymbol{\theta}) = \sum\limits_{n = 1}^{N}(A_{n} + B_{n}),$

并通过反向传播算法关于 $\boldsymbol{\phi}$ 和 $\boldsymbol{\theta}$ 进行最小化。通常采用小批量算法变体。

一旦训练完成，可通过多种方式进行采样以生成样本。可以从标准高斯先验 $p(\mathbf{z})$ 中采样，然后将生成的潜在变量向量通过编码器，通过对条件分布采样来生成样本。有时，也可以不对条件分布采样，而是将生成的样本设为相应条件分布的均值，因为这是实现解码器的神经网络的预测输出（公式 (19.19)）。然而，从先验 $p(\mathbf{z})$ 采样通常会导致样本质量相当低。另一种选择是从通过对所有输入样本 $\mathbf{x}_{n}$ 平均学习到的后验 $q(\mathbf{z}|\mathbf{x}_{n};\boldsymbol{\phi})$ 得到的分布中采样潜在变量。这不再是高斯分布，而是高斯混合模型，能更具代表性地反映潜在空间中的真实分布。另一方面，如果想从单个类别生成样本，例如 MNIST 数据集中的数字“3”，则可以通过从相应的学习后验 $q(\mathbf{z}|\mathbf{x}_{n};\boldsymbol{\phi})$ 中抽取样本，在潜在空间中进行采样。

尽管与 GAN 相比 VAE 更易于训练，但实验证据表明，当 VAE 用于生成图像时，获得的图像往往比通过 GAN 生成的图像更模糊。文献 [185] 使用 Wasserstein 距离替换代价函数中的 KL 散度来训练 VAE，据报告这对获得的性能有积极影响。另一条研究路线是沿着 GAN 和 VAE 的融合方向进行的，旨在结合两者的优点；参见例如 [126]、[129]。另一条路径是构建具有潜在变量层次结构的 VAE。在这方面，潜在变量被解释为从其他更高层级的变量生成；参见例如 [104]。条件 VAE 在文献 [170] 中被提出。

### 正规化流

我们已经处理了许多不同的生成网络。在第 19.7 节中，我们将讨论扩散模型家族。**正规化流** 也是该方法家族的成员。它们是试图将概率分布**拟合** 到输入数据的概率模型。因此，与 VAE 类似，正规化流围绕似然目标概念演变，以获得相关模型定义参数的估计。

正规化流建模的核心在于一个基础分布，例如 `p_z(z)`，它可以轻松采样，如标准高斯分布。此外，假设输入数据样本 `x` 是通过一个作用于从 `p(z)` 中抽取的样本 `z` 的参数化**可逆** (向量值) 函数/变换生成的，即：

```
x = f(z; θ) and z = f^(-1)(x; θ).
```

根据第 2.2.5 章，公式 (2.45)，相应的 PDF 相关联为：

```
p_x(x) = p_z(z) / |det(J(x; z))| |_{z = f^(-1)(x)},  (19.25)
```

其中 `J(·; ·)` 是相应的雅可比矩阵。例如，对于标量随机变量，前面的公式变为：

```
p_x(x) = p_z(z) / |dx/dz| |_{z = f^(-1)(x)}.
```

现在的挑战是获得这样一个可逆变换。为此，可以调用多层网络，相关的定义参数 `θ` 在训练期间学习。代价函数是通过公式 (19.25) 在一组观测样本 `x[n]`，`n = 1, 2, …, N` 上计算的似然函数。

可逆性是通过审慎选择网络的层（流）来施加的。每一层，*k* = 1, 2, …, *K*，都实现了一个相应的*可逆*变换 `fk`。整体函数 `f` 和 `f^(−1)` 作为各个单独函数的复合而得出，即：

```
f = fK.…)), and f^(−1) = f[1]^(−1)(f[2]^(−1)(…f[K−1]^(−1)(f[K]^(−1))…))
```

且 `θ` := [`θ[1]^(T)`, …, `θ[K]^(T)`]^(T)。换句话说，一旦参数学习完成，输入分布 `px` 的近似就以*逐步*层层递进的方式实现，起始于（例如）标准高斯概率密度函数。设计归一化流的关键在于对这些可逆函数进行建模和选择。为此，已经提出了各种方法和技术。更多细节请参见，例如，[139] 及其参考文献。

## 19.3 Transformers

到目前为止，我们的讨论围绕三个建模概念展开，它们作为构建深度网络的基本工具：全连接前馈神经网络、卷积网络和循环神经网络。现在，我们将关注转向被称为 *transformers* 的最新趋势。所谓 Transformer 网络背后的主要基本原理是注意力机制，该机制已在 18.13.2 节中介绍并使用过。在当前版本编撰之际，Transformers 构成了深度学习领域的*最先进水平*。为了阐述实现此类网络的基本思想和相关架构，我们将沿着历史发展脉络，从自然语言处理（NLP）应用领域切入。

### 19.3.1 自然语言处理：入门

本小节的目标非常谦逊，其目的是提供与*自然语言处理*（NLP）学科相关的一些最基本的定义和概念，以便引入 Transformers。毕竟，对 NLP 领域更广泛的阐述将需要一本专门的书籍，参见，例如，[58]。

自然语言处理被广泛定义为一门科学领域，其目标是利用计算机对自然语言（如语音和文本）进行自动操作（处理、分析和综合）。在 11.15 节中，讨论了一个关于紧密相关的作者身份识别主题的案例研究。在那里，定义并使用了词袋和 n-gram 等许多术语，用于 SVM 分类的上下文中。

对于我们当前的需求，起点是指词汇表中包含的单词在计算机中的表示。我们将假设每个单词由单个向量表示。例如，在所谓的*one-hot*（独热）表示/编码中，每个单词对应一个特定的 one-hot 向量。这些向量的维度*l*等于相应 NLP 任务中使用的词汇表中的单词数量。目前，用于训练所谓的大语言模型（LLMs）（见第 19.5.3 节）的典型词汇表大小可以达到 30000 个单词的量级。

按照惯例，每个单词（包括标点符号和特殊符号，假设共 30000 个）被分配一个介于 1 和 30000 之间的特定数字/索引，并由相应的 one-hot 向量表示。后者包含*l* − 1 个等于 0 的元素，唯一的非零元素等于 1。数值 1 位于等于该单词在词汇表中索引的向量维度位置。例如，如果第*n*个单词（*n* = 1, 2, …, *l*）在词汇表中的索引用*l*[*n*] ∈ {1, 2, …, *l*}表示，则相应的 one-hot 表示形式如下：

```
\mathbf{x}_{n} = \overset{l}{\overset{︷}{\left\lbrack 0,\ldots,0,\underset{l_{n}}{\underset{︸}{1}},0,\ldots,0 \right\rbrack^{T}}} \in \mathbb{R}^{l},\ n = 1,2,\ldots,l,
```

其中 1 位于向量的*l*[*n*]维度。请注意，语言词汇表中现有单词的数量可能远大于用于实际目的的 30000 个。例如，希腊语作为一种古老语言，据估计大约有 100000 个单词和 300000 个含义。

我们讨论的舞台将是*神经机器翻译*（NMT）任务，这是自然语言处理学科的一个子主题。让我们以法语短语“Je suis étudiant”为例，其英文翻译为“I am a student。”该法语短语由三个单词组成，每个单词由一个 one-hot 向量表示，即**x**[1], **x**[2], **x**[3]。将短语分解为单个单词通常称为*tokenization*（分词），单个单词/向量称为*tokens*（词元）。

```
⟨SOS⟩, x[1], x[2], x[3], ⟨EOS⟩.
```

同样，输出序列（即翻译成英文的短语）表示为：

```
⟨SOS⟩, y[1], y[2], y[3], y[4], ⟨EOS⟩,
```

其中输出序列也采用了 one-hot 向量表示。请注意，输入和输出序列中向量/词元的维度可能不同，因为两个词汇表（例如法语和英语）通常大小不同。

在实践中，通常使用所谓的*嵌入*，而不是独热向量。也就是说，每个独热向量通过与*嵌入矩阵*相乘，被投影到一个低维空间中，即 **x**[*n*]^′ = *E***x**[*n*]，其中 *E* 维度适当，其元素在训练过程中学习得到。输出序列也使用类似的嵌入。除了相应维度的减少（这导致涉及的网络参数大幅减少）之外，这种嵌入还可以利用不同单词之间存在的进一步语义关系，参见例如 [19]。

### 19.3.2 RNN、Transformer 与上下文概念

在任何 NLP 任务中，输入数据由一系列*标记*/向量组成。与顺序数据的情况一样（参见第 18.13 节），输入标记在序列中出现的特定顺序至关重要。从略微不同的角度来看，给定一个短语，每个单词的*位置*（短语标记化后每个标记的位置）对于理解该短语的含义非常重要。此外，短语中每个单词的具体含义通常取决于*上下文*；即含义取决于短语中存在哪些单词，以及它们以何种*相对位置*出现。让我们举两个例子来说明这一点，因为我们所说的“上下文”将在后续章节的讨论中发挥重要作用。

> “The *animal* did not eat the food because *it* was not hungry.”
>
> 在上述短语中，“it”指代“animal”。
>
> “The animal did not eat the *food* because *it* was rotten.”
>
> 在上述短语中，“it”指代“food”。

因此，根据上下文，“it”获得不同的含义，因为它指代不同的实体。^(¹³⁴)

另一个例子如下：

> “I arrived at the *bank* after crossing the *river*.”
> “I arrived at the *bank* after crossing the *road*.”

因此，“bank”的含义取决于上下文而有所不同。^(¹³⁵)

直到 2017 年左右，NLP 任务的趋势是使用 RNN，因为它们擅长处理顺序数据；参见第 18.13 节。^(¹³⁶)

![图 19.8 双向 RNN 用作编码器。对于编码器的每个阶段 *t* (*t* = 1, 2, …, *N*)，计算两个状态向量。前向向量 (${\overset{\rightarrow}{\mathbf{h}}}_{t}$) 从左向右传播，后向向量 (${\overset{\leftarrow}{\mathbf{h}}}_{t}$) 从右向左传播。在解码器中，每个阶段 *n* 被馈送一个相应的上下文向量 **c**[*n*]。后者是编码器所有时间瞬间/阶段的组合状态向量（${\overset{\rightarrow}{\mathbf{h}}}_{t}$ 和 ${\overset{\leftarrow}{\mathbf{h}}}_{t}$ 的拼接）的线性组合。系数 *α*[*nt*] (*t* = 1, …, *N*) 在训练过程中学习得到。图示聚焦于解码器的第 *n* 个阶段以简化说明，并假设总共有 *N*′ 个阶段。](images/B9780443292385000251/gr008.jpg)

与阶段/时间相关的上下文向量 **c**[*n*] (*n* = 1, 2, …, *N*′) 定义为：

```
\mathbf{c}_{n} = \sum\limits_{t = 1}^{N}\alpha_{nt}\mathbf{h}_{t},
```

加权系数由以下公式给出：

$$

\alpha_{nt} = \frac{\exp(e_{nt})}{\sum_{k = 1}^{N}\exp(e_{nk})},\ \text{with}\ e_{nt} = \phi(\mathbf{h}_{t}^{T}\mathbf{h}_{n - 1}^{\prime}),

$$

其中 $\phi$ 是通过神经网络实现的非线性函数，其参数在训练过程中被“学习”得到。编码器第 $t$ 个阶段的输出状态向量 $\mathbf{h}[t]$，由相应的前向（$\overset{\rightarrow}{\mathbf{h}}_{t}$）和后向（$\overset{\leftarrow}{\mathbf{h}}_{t}$）状态向量拼接而成。变量 $e[n t]$ 称为*对齐*模型，它衡量编码器在时刻 $t$ 的状态向量与解码器在时刻 $n - 1$ 的状态向量匹配得有多好，即它们有多相似。注意，相似度是通过相应向量的内积来度量的。
