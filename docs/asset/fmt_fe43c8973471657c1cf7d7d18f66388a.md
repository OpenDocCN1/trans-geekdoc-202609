## Polyaxonfile

`Polyaxonfile` 是任何 Polyaxon 训练任务中最重要的组件。它包含了任务应如何运行的规范。Polyaxon 文件可以使用 YAML、JSON 和 Python 编写，部分可以使用 Go、Typescript 和 Java 编写。我们将使用 YAML 来编写我们的 `Polyaxonfiles`。Polyaxonfile 规范主要有两种类型：组件（component）和操作（operation）。我们将查看组件级 Polyaxonfile。

组件级 `Polyaxonfile` 可以接受很多参数作为输入。以下是最重要的几个参数：

- Polyaxon 规范版本。这通常设置为 `Component` 或 `operation`。
- 组件的描述，可用于在仪表板上轻松过滤组件。
- 运行组件时提供的用户参数。它具有以下子参数：
  - `name`
  - `type`
  - 参数的默认值
  - 告知该参数是否为可选的标志。
- 组件的运行时规范。它具有以下子参数：
  - 训练任务的类型（单机或分布式）
  - 将运行训练任务的主 Kubernetes 容器的规范。

还有其他几个参数。它们的细节可以在 Polyaxon 官方文档中找到。

## 安装 NVIDIA GPU

请求额外 GPU 配额的步骤可以在 Google Cloud 官方文档中找到。

我们将创建一个与我们用于仅 CPU 任务的节点池分开的自动伸缩 GPU 节点池。这有助于我们充分利用自动伸缩功能。该节点池能够根据是否需要 GPU 高效地扩展或缩小规模。这使其成为在 GKE 上使用 GPU 最具成本效益的方式。要创建 GPU 节点池，我们运行以下命令：

```bash
gcloud container node-pools create POOL_NAME \
--accelerator type=GPU_TYPE,count=AMOUNT \
--zone COMPUTE_ZONE \
--cluster CLUSTER_NAME \
--num-nodes NUM_NODES \
--min-nodes MIN_NODES
--max-nodes MAX_NODES \
--enable-autoscaling
```

**注意**：并不是所有的 GPU 类型在所有计算区域都可用。要检查每个区域可用 GPU 列表，请运行以下命令：

```bash
gcloud compute accelerator-types list
```

在创建 GPU 节点池后，我们需要在节点上安装 NVIDIA 驱动程序。Google 使其变得非常简单，如下：

```bash
kubectl apply -f https://raw.githubusercontent.com/GoogleCloudPlatform/container-engine-accelerators/master/nvidia-driver-installer/cos/daemonset-preloaded.yaml
```

这需要几秒钟完成，之后我们的 GPU 节点池即可使用。

## 在 Polyaxon 上训练时使用 GPU

现在我们的 GPU 节点池已就绪，我们可以使用它来训练图像分类模型。为了实现这一点，我们将利用 `polyaxon run` 命令的文件覆盖机制。这允许我们使用 CPU 或 GPU 来训练模型，而无需反复编辑 `polyaxonfile`。为了实现这一点，我们需要两个 polyaxon 文件。在这种情况下，它们是 `polyaxonfile.yml` 和 `polyaxonfile_gpu.yml`。

要仅使用 CPU 进行训练，我们将执行以下命令：

```bash
polyaxon run -f polyaxonfile.yml
```

要使用 GPU 进行训练，我们使用以下覆盖机制向运行规范中添加 GPU 请求：

```bash
polyaxon run -f polyaxonfile.yml -f polyaxonfile_gpu.yml
```

这将添加/替换原始 polyaxon 文件中 `nvidia.com/gpu` 参数的值。

## 回归指标

回归用于因变量是连续的情况，例如房屋价格、薪水等。回归指标的一个常见问题是预测的规模，由于这个原因，它是具有开放解释性的；例如，如果我们预测的是通常以百万计的房屋价格，我们可以说 ± 2 万美元是一个很好的预测；然而，对于规模在 5 万到 10 万左右的薪水，± 2 万就太大了。

在接下来的章节中，我们将看到一些用于捕捉回归模型性能的常用指标。

## 平均绝对误差 (MAE)

平均绝对误差或 MAE 是一种流行的指标，因为误差得分的单位与所预测的目标值的单位一致。

MAE 的计算方法是实际值与预测值之绝对值的平均值。

## MSE 和 RMSE

均方误差（Mean Squared Error，MSE）也是最常用的指标。它也是最小二乘回归问题中的损失函数。误差（实际值减去预测值）被平方后加到 `MSE` 中。这样做的好处是它可以放大较大的误差。计算 `MSE` 的公式如下：

## 分类指标

到为止，我们讨论了回归指标和 KPI，这是监督学习的一种类型。另一类监督学习是分类，我们将详细讨论衡量这些模型性能的 KPI。在进入指标本身之前，我们需要理解混淆矩阵，它使我们能够计算这些 KPI 或指标。

## 混淆矩阵

混淆矩阵是一种表格结构或二维矩阵。在一个轴上绘制实际值，在另一个轴上绘制预测值。在图中，水平轴是预测值，垂直轴是真实值或实际值，所示：

![](img/image-6ck7flp7.jpg)

图 7.2：混淆矩阵

混淆矩阵用于二分类；然而，该概念可以扩展到多分类。在这种情况下，0 和 1 是感兴趣的标记或类别；例如，客户是否流失，或者某人是否会购买（用是或否的标记表示）。在客户流失的情况下，客户流失的记录被视为正例，未流失的被视为负例。

以下术语与混淆矩阵相关：

- **真正例 (True Positives)**：这些是我们预测为正类且该案例确实属于正类的情况。
- **真负例 (True Negatives)**：这些是我们预测为负类且该案例确实属于负类的情况。
- **假正例 (False Positives)**：这些是我们预测为正类但该案例实际上属于负类的情况。
- **假负例 (False Negatives)**：这些是我们预测为负类但该案例实际上属于正类的情况。

在多分类中，这些值可以使用“一个对所有”（one vs all）的逻辑转换为二分类问题来计算；例如，如果我们有猫、狗、兔子三个类别，为了计算“猫”类别的上述四个值，你可以将猫设为 1，将狗和兔子设为 0。我们将在本章的 Python Notebook 中展示多分类混淆矩阵。

需要注意的是，根据所选择的概率阈值，相同输出的混淆矩阵可能会发生变化。在 `sklearn` 包中，二分类的默认概率阈值为 0.5。低于此值的任何值都被视为负类，高于此值为正类。根据业务问题，可以更改此概率阈值。从混淆矩阵派出的其他指标将在后续章节中讨论。

## 准确率 (Accuracy)
