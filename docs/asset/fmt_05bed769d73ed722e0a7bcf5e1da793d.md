
# 训练神经网络的关键因素：网络大小与正则化

训练神经网络的一个关键因素是确定网络的大小。大小直接与要估计的参数数量相关。关于前馈神经网络，涉及两个问题：第一个涉及层数，另一个涉及每层的神经元数量。正如我们将在第 18.11 节讨论的那样，许多理由支持使用两个以上的隐藏层。此类网络包含大量参数，容易受到过拟合的影响，这会影响学习器的泛化性能。应对过拟合的一种途径是通过正则化。多年来，已经提出了各种正则化方法。下面给出简要介绍和一些指导原则。我们将在第 18.11.1 节从不同角度在深度网络的背景下回到过拟合和泛化问题。

## 权重衰减

这条路径指的是通过权重的平方欧几里得范数进行典型的代价函数正则化。不是最小化代价函数 `J(θ)`，而是使用其正则化版本，例如（如文献 [71]）：

```
J'(θ) = J(θ) + λ||θ||².
```

![Equation](img/si304.png) (18.47)

我们已经在岭回归的背景下，于第 3 章中讨论过，将偏置项包含在正则化范数中并非良好的做法，因为这会影响估计量的平移不变性。一种更合理的正则化方式是从范数中移除偏置项。尽管这种简单类型的正则化有助于提升网络的泛化性能，且在某些情况下可能已足够，但总体而言，它并非最合适的方法。

除了平方欧几里得范数，还可以在公式 (18.47) 中使用其他范数。例如，一种替代方案是采用 `ℓ₁` 范数。从第 9 章我们知道，后一种范数能促进稀疏性。在训练大型网络时，这是一个受欢迎的特性，因为它可以将信息量较小的参数推向零。

多年来，人们提出了应用正则化代价函数的各种场景。一种场景是将每一层的所有参数（不包括偏置）分组，并应用公式 (18.47)，为每个组使用不同的正则化常数。另一种场景是单独处理每个神经元的参数。另一条路径是将正则化视为将范数约束为小于一个预选值（第 3 章）。这被证明等价于在与该范数相关的球体上进行投影步骤，例如 `ℓ₂` 球（见第 8 章），从而导致一个归一化操作（见文献 [74]）。

## 权重消除

除了使用权重的范数，另一种方法涉及将更一般的函数用于正则化项，即：

```
J′(θ) = J(θ) + λh(θ).
```

例如，文献 [213] 使用了以下函数：

```
h(θ) = ∑_{k=1}^{K} θ_k² / (θ_h² + θ_k²),
```

其中 `K` 是所涉及参数的总数，`θ_h` 是一个预选的阈值。仔细观察该函数可知，若 `θ_k < θ_h`，惩罚项会迅速趋近于零。相反，对于 `θ_k > θ_h` 的值，惩罚项趋向于 1。通过这种方式，不太重要的权重被推向零。该方法也出现了许多变体（见例如文献 [173]）。

## 基于灵敏度分析的方法

文献 [112] 提出了所谓的*最优脑损伤*技术。通过二阶泰勒展开，对代价函数关于权重进行了扰动分析。

### 正则化方法

#### 二阶泰勒展开近似

目标函数 $J$ 的二阶泰勒展开式为：

$$
\delta J = \sum_{i = 1}^{K}g_{i}\delta\theta_{i} + \frac{1}{2}\sum_{i = 1}^{K}h_{ii}\delta\theta_{i}^{2} + \frac{1}{2}\sum_{i = 1}^{K}\sum_{j = 1,j \neq i}^{K}h_{ij}\delta\theta_{i}\delta\theta_{j},
$$

其中

$$
g_{i} := \frac{\partial J}{\partial\theta_{i}},\quad h_{ij} := \frac{\partial^{2}J}{\partial\theta_{i}\partial\theta_{j}}.
$$

假设 Hessian 矩阵为对角矩阵，且算法在最优点附近运行（梯度为零），则可近似设定：

$$
\delta J \approx \frac{1}{2}\sum_{i = 1}^{K}h_{ii}\delta\theta_{i}^{2}.
$$

#### 最优脑损伤法

该方法工作流程如下：

1.  使用反向传播算法训练网络。经过几个迭代步骤后，冻结训练。
2.  计算每个权重的 **saliencies**（显著性），定义为：
    $$
    s_{i} = \frac{h_{ii}\theta_{i}^{2}}{2},
    $$
    移除显著性较小的权重。显著性基本上衡量了如果移除（设为零）相应权重对代价函数的影响。
3.  继续训练，每隔几次迭代重复该过程，直到满足停止准则。

在文献 [64] 中，计算完整的 Hessian 矩阵，从而提出了 **optimal brain surgeon**（最优脑外科医生）方法。注意，移除连接的正则化技术也称为 **pruning**（剪枝）技术。

#### 早停法

**Early stopping**（早停法）是一种概念原始但在实践中特别有用的避免过拟合技术。其核心思想是：当测试误差开始增加时停止训练。

经过多个 epoch 的训练，训练误差可能收敛到很小的值，但这通常是过拟合的信号，而非良好解的标志。根据早停法，训练进行若干迭代后冻结，使用当前的权重/偏置估计在验证/测试数据集上评估网络并计算代价函数值。随后恢复训练，重复上述过程。当测试集上计算的代价函数值开始增加时，停止训练。

早停法常与其他正则化策略结合使用。即使使用修改目标函数的正则化策略，停止训练的决定也不能仅基于训练误差。

#### 噪声注入正则化

训练期间存在噪声的正则化效应自 1990 年代初以来已为人所知。向输入样本添加额外噪声有多种方式（例如文献 [16]）。这等价于通过添加一个作为正则化项的额外项来修改代价函数。

另一种选择是在训练过程中估计参数时向参数添加噪声（参见例如文献 [139]）。将噪声视为参数上的微小扰动，并采用输出的一阶泰勒展开，可以证明这等同于在代价函数中添加一个额外的正则化项。较大的梯度值会受到惩罚，这促使算法收敛到参数空间中对微小变化相对不敏感的解。

除了前两种可能性之外，还存在试图应对带噪输出标签的策略。这被称为*标签平滑*（参见例如文献 [201]）。

#### 通过人工扩充数据集进行正则化

正如本书各部分（例如第 3 章）所讨论的，过拟合的原因在于模型未知参数数量的大小（容量）相对于训练集的大小而言过大。在保持模型固定的同时增加训练数据的数量，对过拟合问题有积极作用。然而，带标签的数据并不总是容易获得。在这种情况下以及某些应用中，一种出路是人工生成“假”数据并将其作为训练集的一部分使用。例如，在目标识别和 OCR 等任务中，可以通过对现有图像应用旋转、平移和缩放等线性变换，生成许多目标或数字和字母的复制品。在文献 [92] 中，数据增强也已应用于语音识别。稍后，在第 19 章中，我们将讨论如何人工生成数据的更新技术。

## Dropout

这种用于正则化深度网络的技术遵循的概念与我们之前讨论的不同。其起源借鉴了组合学习器的概念，正如第 7.8 节和第 7.9 节所讨论的，特别是装袋法的基本原理。然而，Dropout 巧妙地修改了装袋法的基本思想，使其更高效并适用于大型网络。

“Dropout”指的是在神经网络中丢弃隐藏层和输入层中的单元/节点。在训练算法的每次迭代中，会移除一定数量的节点（连同它们相关的传入和传出连接）。剩余节点的参数根据更新规则进行更新。换句话说，在每个迭代步骤中，仅更新参数的一个*子集*，而其余参数（与被移除节点相关的参数）则冻结在从上一次迭代获得的当前可用估计值上。由剩余节点组成的子集定义了原始较大网络的一个*子网络*。该过程如图 18.15 所示。图 18.15A 展示了完整网络。图 18.15B 中，待移除的节点以红色显示，连同其所有传入和传出连接。图 18.15C 中，当前迭代中待更新的子网络仅涉及灰色节点。红色节点已被移除，其相关参数的估计值冻结在前一次迭代获得的值上，且在当前步骤中*不更新*。图中，被移除的节点之一是输入节点，其余位于隐藏层。

![图 18.15 (A) 完整网络。(B) 待移除节点以红色显示，连同所有传入和传出连接。(C) 红色节点已移除。其相关参数估计值冻结在前一次迭代获得的值上，且在当前迭代步骤中不更新。](img/gr015.jpg)

图 18.15 (A) 完整网络。(B) 待移除节点以红色显示，连同所有传入和传出连接。(C) 红色节点已移除。其相关参数估计值冻结在前一次迭代获得的值上，且在当前迭代步骤中不更新。

节点的移除是按概率进行的。即每个节点以概率 *P* 被保留。通常，隐藏层的 *P* 值等于 0.5，输入层节点设为 0.8。对于具有 *K* 个节点的网络，可能的子网络总数为 2^(*K*)。这对于实际中常见的大 *K* 值来说确实是一个很大的数字。但请记住，各子网络之间存在高度的参数*共享*，需学习的参数总数等于构成原始网络的参数数量。

一旦训练阶段完成且反向传播算法收敛，获得的估计值将乘以相应的概率 *P*。这相当于对所有已训练的可能子网络进行平均操作（见文献 [74]）。可以证明（例如文献 [55,74]），对于具有一个隐藏层和 *K* 个节点、带有用于计算类标签概率的 Softmax 输出单元的网络，使用平均网络等同于取所有 2^(*K*) 个可能网络预测的标签概率分布的几何平均。在文献 [212] 中表明，将 Dropout 理论应用于线性回归任务等同于具有每个模型参数不同正则化权重的 ℓ2 正则化。然而，这种等价性不适用于一般的深度网络。

### 关于 Dropout 为何有效的启发式解释

关于 Dropout 为何有效的启发式解释见文献 [74]。Dropout 减少了神经元的共适应，因为在每次迭代中，不同神经元集合的参数都会被更新。因此，网络被“迫使”学习更鲁棒的特征。换句话说，网络在学习时，每次都有部分结构缺失。文献 [221] 给出了一个更令人满意的理论解释，其中表明 Dropout 技术等同于在深度高斯过程中具有特定先验的近似变分推断。

在当前版本编写时，Dropout 技术似乎是最流行的正则化方法，并已应用于广泛的应用中（例如见文献 [183]）。此外，使用 Dropout 并不妨碍将其与其他类型的正则化相结合（见文献 [74]）。毋庸置疑，该方法并非“灵丹妙药”，也有其缺点。一个主要缺点是通常必须训练大得多的网络，以弥补正则化施加的容量损失。此外，训练需要更多的迭代次数。一个 Dropout 网络的训练时间通常比相同架构的标准神经网络长两到三倍。为此，除了前文提到的方案外，还提出了计算效率更高的替代方案（例如见文献 [208, 210]）。

# 18.8 设计深度神经网络：总结

到目前为止，在我们的讨论中，我们已经涉及了在为特定应用构建深度神经网络时必须面对的许多挑战。毫无疑问，从业者在运行代码之前（通常使用现成的软件包）必须做出许多关键决策。

采用神经网络架构并选择相关超参数，仍然是一项带有浓厚工程色彩的任务。将此任务比作在开发出相关复杂软件包之前构建复杂电路的任务，并不算过分。工程师必须采用许多技巧，这些技巧更多是源于经验而非理论。本节的目的是总结并汇总必须遵循的主要挑战和一些通用技巧。

*   仔细思考手头的问题；在构建网络之前，尝试理解其特殊性以及数据的性质、统计特性和目标。在确信已理解手头的问题之前，避免过早地开始摆弄算法。
*   审视数据，确保数据收集良好且高度代表该问题。确保不存在偏向某些决策或类别的“偏见”。特别值得关注的偏见，也是最难识别的偏见，是那些发生在潜意识层面并由社会刻板印象驱动的偏见，例如与性别、种族、宗教和社会阶层相关的问题。
*   确保为隐藏单元和输出单元使用合适类型的非线性函数。正确的选择也取决于具体问题，尽管我们已经针对“典型”情况提出了一些建议。然而，“典型”不一定意味着“必须”。
*   确保选择正确的损失函数来优化数据。相关问题之前已讨论过。不过，人们可以更有创造性地使用更适合手头问题的其他损失函数。不应仅局限于书中给出的寥寥几个例子。在机器学习发展的几十年里，许多替代方案已被提出并用于各个科学界，其中特定应用的损失函数可能更合适。
*   选择网络规模是第一个挑战，即决定层数和每层的节点数。如果网络太大，即使使用正则化也可能不足以应对过拟合问题。如果太小，性能可能会很差。在某些情况下，可能需要重新考虑并尽可能获取更多数据。在开始开发架构之前，建议搜索其他人在类似情况和设置下做了什么。在寻找“最佳”规模时，常见的做法是将可用数据集分成三部分，即 `training`（训练）集、`validation`（验证）集和 `test`（测试）集。

## 实用建议

*   验证集用于训练期间，评估不同模型（超参数调优）的比较性能，这些模型是在训练集上训练的。这是一个“混合”集合，在训练阶段作为独立集合辅助设计者选择模型。最终性能的评估完全通过测试集完成，测试集在训练期间未以任何方式参与。验证集不应与第 3 章讨论的交叉验证方法混淆。由于计算时间限制，当涉及大数据集时，无法采用此类技术。此外，当有大数据集可用时，可以将数据集拆分为不同部分以服务不同目的。
*   对于将要使用的每种算法，必须仔细选择所用随机梯度优化器的超参数。例如，必须跟踪算法收敛的演变，并可能需要重新考虑已做出的选择。小批量大小的选择也应仔细进行，以满足优化算法的需求，同时利用运行算法的特定架构的计算特性。
*   仔细初始化参数，并适当归一化网络获得的值，例如通过批量归一化。之前已给出指导原则。然而，指导原则是为了提供帮助，可能还需要更加小心和富有想象力。
*   采用正则化。为此，必须尝试 Dropout 中移除节点的概率或涉及的正则化参数（如果涉及其他方法）。
*   现代神经网络架构包含数百万个参数；然而，其涉及的计算具有高度并行性。GPU 是相对廉价且普遍的硬件设备，能够承担大规模计算并行化，因为它们包含数千个核心。因此，获取多个 GPU 是一项极其必要的投资。随着 GPU 显存容量的增加（或使用多个 GPU），可以增加小批量大小，从而加快训练速度（由于并行化），并通常获得更好的收敛性（由于大批量）。
*   在实现和运行算法时，利用他人在类似设置中获得的经验。此外，请记住该领域仍在发展中，新结果和技术可能随时出现。因此，密切关注最新进展。
*   切勿以“黑箱”理由运行算法。尝试理解每个超参数的含义及其如何影响性能。

给从业者的最后一个建议，我一直对学生反复强调：**理解后再运行**。

# 18.9 前馈神经网络的通用近似性质

在第 18.3 节中，讨论了基于 McCulloch-Pitts 神经元构建的三层前馈神经网络的分类能力。随后，为了可微性，我们采用了激活函数的平滑版本。现在的问题是，我们能否对这类网络的预测能力说些更多内容。事实证明，已经产生了一些强有力的理论结果，为在实践中使用神经网络提供了支持（例如，参见文献 [33,47,79,87]）。

让我们考虑一个**两层**网络，包含一个隐藏层，涉及 S 型非线性，并带有一个单输出**线性**节点。网络的输出则写为

$$
\widehat{g}(\mathbf{x}) = \sum\limits_{k = 1}^{K}\theta_{k}^{o}f\left( \mathbf{\theta}_{k}^{h^{T}}\mathbf{x} \right) + \theta_{0}^{o},
$$

其中向量 $\mathbf{\theta}_{k}^{(h)}$ 由定义第 $k$ 个隐藏神经元的突触权重和偏置项组成，上标“$o$”指代输出神经元。随后以下定理成立。

**定理 18.1**

设 $g(\mathbf{x})$ 为在紧致集上定义的连续函数。对于任意给定的 $\epsilon > 0$，存在一个具有 $K$ 个隐藏神经元的两层网络 $\widehat{g}(\mathbf{x})$，使得

$$
|g(\mathbf{x}) - \widehat{g}(\mathbf{x})| < \epsilon, \quad \forall \mathbf{x} \in S.
$$
