
文献 [113] 综述了条件概率的 `kernel embedding`（核嵌入）概念，作为解决图模型中挑战性问题的一种手段。`kernelization`（核化）概念也已在 `tensor-based`（基于张量）模型的背景下得到扩展 [50, 107, 132]。文献 [49] 综述了基于核的假设检验。文献 [120] 在扩散映射框架下讨论了核在流形学习中的应用。文献 [81] 综述了关于核技术性能随维度、信噪比和局部误差棒变化的分析任务。文献 [119] 提供了一组与基于核的方法和应用相关的文章集合。

### 11.10.4 超参数的选择

与 SVM/SVR 相关的主要问题之一是参数 `C` 的选择，它控制损失项和代价函数中正则化参数的相对影响。尽管已有一些开发理论工具以进行相应优化的努力，但在实践中存活下来的路径是针对测试数据集的交叉验证技术。使用不同的 `C` 值训练模型，并选择在测试集上产生最佳性能的值。

另一个主要问题是核函数的选择。不同的核会导致不同的性能。让我们仔细看看公式 (11.17) 中的展开式。可以将 `κ(x, x[n])` 视为一个函数，用于度量 `x` 和 `x[n]` 之间的**相似性**；换句话说，`κ(x, x[n])` 将 `x` 与训练样本 `x[n]` 进行**匹配**。如果 `κ(x, x[n])` 在 `x[n]` 周围的一个小区域内取相对较大的值，则称该核为局部核。例如，当使用高斯核时，`κ(x, x[n])` 远离 `x[n]` 的贡献会以指数级快速衰减，这取决于 `σ²` 的值。因此，`σ²` 的选择至关重要。如果待逼近的函数是平滑的，则应采用较大的 `σ²` 值。相反，如果函数在输入空间中剧烈变化，高斯核可能不是最佳选择。事实上，如果在这种情况下使用高斯核，必须拥有大量训练数据，以便足够密集地填充输入空间，从而能够获得对该函数足够好的近似。这引出了机器学习中另一个关键因素，即训练集的大小。后者不仅取决于输入空间的维度（维度灾难），还取决于未知函数经历的变化类型（例如，参见 [12]）。在实践中，为了选择合适的核函数，通常使用不同的核，并通过交叉验证为特定问题选择“最佳”的一个。

一条研究路线是根据先验知识或通过某种优化路径，设计与手头数据相匹配的核（例如，参见 [29, 65]）。在第 11.13 节中，我们将讨论使用多个核的技术，旨在最优地结合它们各自的特性。

### 11.10.5 多类泛化

SVM 分类任务是在二分类任务的背景下引入的。更一般的 `M` 类情况可以通过多种方式处理：

#### 一对其余

求解 `M` 个二分类问题。每次，使用不同的 SVM 将其中一个类别与所有其他类别进行分类。因此，估计出 `M` 个分类器，即：

```
fm = 0, m = 1, 2, …, M,
```

这些分类器经过训练，使得对于 `x ∈ ω[m]` 有 `fm > 0`，否则 `fm < 0`。分类通过以下规则实现：

```
assign x in ω_k: if k = argmax_m f_m(x).
```

#### 多类分类方法

*   **一对多**：根据这种方法，空间中可能存在多个区域，使得多个判别函数得分为正值（例如，[123]）。此外，这种方法的另一个缺点是所谓的*类别不平衡*问题；这是由以下事实引起的：某一类别中的训练点数量（该类别包含来自`M - 1`个类别的数据）可能比其他类别中的点数量大得多。与类别不平衡问题相关的问题在[123]等文献中有讨论。

*   **一对一**：根据这种方法，通过成对考虑所有类别，求解`M(M - 1) / 2`个二分类任务。最终决策基于多数表决规则。

*   在[128]中，SVM 的基本原理被扩展为同时估计`M`个超平面。然而，这种技术最终导致大量参数，数量等于`N(M - 1)`，这些参数必须通过单一的最小化任务来估计；这对于大多数实际问题来说是相当困难的。

*   在[34]中，多类任务是在纠错码的背景下处理的。每个类别与一个二进制码字相关联。如果码字选择得当，错误恢复能力就“嵌入”到了过程中（另见[123]）。关于多类分类方案的比较研究，见例如[41]及其参考文献。

*   **除法与 Clifford 代数**：SVM 框架也已扩展以处理复数和超复数数据，既用于回归也用于分类，使用除法代数或 Clifford 代数[8]。在[124]中，考虑了四元数 RKH 空间的情况。

*   一种针对复值数据更通用的方法，利用*广义线性估计*以及*纯复核*的概念，已在[14]中提出。在该文中，证明了任何复数 SVM/SVR 任务等价于求解两个利用特定实核的实数 SVM/SVR 任务，该实核由所选的复核生成。此外，在分类情况下，证明了所提出的框架固有地将复空间分割为四部分。这自然地导致求解四类任务（四分类），而不是实数 SVM 的标准二类场景。这种基本原理可用于多类问题作为分裂类场景。

## 11.11 计算考量

一般来说，求解二次规划任务需要`O(N³)`次操作和`O(N²)`内存空间。为了应对这种需求，设计了多种分解技术（例如，[22, 55]），将任务“分解”为一系列较小的任务。在[59, 88, 89]中，*序列最小优化*（SMO）算法将任务分解为仅包含两个点的问题序列，这些问题可以解析求解。此类方案的高效实现导致经验训练时间在`O(N)`和`O(N².3)`之间缩放。

[74, 75]中推导的方案将任务视为简化凸包之间的最小距离点搜索，最终得到一种迭代方案，将训练点投影到超平面上。与[59, 88]相比，该方案导致更高效的实现；此外，最小距离搜索算法具有内置的增强并行性。

并行实现问题也在[21]中讨论。关于复杂性和精度的问题在[53]中报告。在后者中，推导出了多项式时间算法，为包括 SVM 分类器在内的一类 QP 问题产生具有保证精度的近似解。

处理顺序到达数据的 SVM 任务增量版本也已出现（例如，[26, 37, 100]）。在后者中，每次迭代考虑一个新点，并通过添加/移除样本相应地更新先前选定的支持向量集合（活动集合）。

应用于原始问题公式的在线版本也已被提出。在[84]中，遵循一种迭代加权 LS 方法，交替进行权重优化和成本约束强制。一种结构和计算上都很简单的方案，名为*SVM 原始估计次梯度求解器*（PEGASOS），已在[105]中提出。该算法是一种应用于公式(11.60)中正则化经验合页损失函数的迭代次梯度形式（另见第 8 章）。对于线性核的情况，该算法表现出非常好的收敛性质，并在`O(1 / ε)`次迭代中找到`ε`精确解。

在[43, 56]中，求解凸任务的经典*割平面*技术已被用于原始域中的 SVM 上下文中。由此产生的算法非常高效，特别是对于线性 SVM 情况，复杂度变为`O(N)`阶。

在[125]中，引入了*核心向量机*（CVM）的概念以获得高效解。该方法背后的主要概念是计算几何中的*最小包围球*（MEB）。然后使用一组点子集，称为*核心集*，来实现对 MEB 的近似，该近似在优化过程中被使用。

文献[27]开展了一项比较研究，对比了在原始域和对偶域中求解 SVM 任务的情况。该论文的发现指出，对于线性和非线性情况，这两条路径效率相当。此外，当目标是求得近似解时，选择原始任务可以提供某些优势。另外，在原始域中工作还具有通过联合优化调节超参数的优势。求助于对偶域的主要优势之一，是可以将任务表述为内积的形式。然而，通过适当利用再现核定理，这在原始域中也是可能的。我们将在第 11.12.1 节看到此类示例。

最近，文献[42]提出了一种用于分布式处理的 SVM 版本。在文献[99]中，SVM 任务利用随机投影法在一个子空间中求解。

## 11.12 随机傅里叶特征

在第 11.11 节中，讨论了多种技术，旨在应对计算负载及其随训练数据点数`N`的变化规模，这在 SVM 的背景下尤为重要。此外，许多基于核的方法的核心——如核岭回归（第 11.7 节）和高斯过程（将在第 13.12 节讨论）——在于核矩阵的求逆，该矩阵已在第 11.5.1 节中定义。后者维度为`N × N`，由训练样本集合中所有可能的核函数评估对构成，即`κ(x[i], x[j])`，`i, j = 1, 2, …, N`。一般而言，求逆一个`N × N`矩阵需要`O(N³)`次代数运算，随着`N`的增加，这变得难以应对。在此背景下，已提出多种技术，旨在降低相关计算成本。此类方法的示例见文献[1,45]，其中采用随机投影来“丢弃”单个元素或整行矩阵，以形成相关的低秩或稀疏矩阵近似。

文献[91]提出了一种减轻计算负载任务的替代“视角”。该方法的核心在于绕过通过核函数隐式映射到更高（可能无限）维空间，即`ϕ(x) = κ(⋅, x)`，这构成了任何基于核方法的脊柱（第 11.5 节）。取而代之的是，执行到*有限维*空间`ℝ^D`的显式映射，即

```
x ∈ 𝒳 ⊆ ℝ^l ↦ z(x) ∈ ℝ^D.
```

然而，该映射是以一种“深思熟虑”的方式完成的，使得在此`D`维空间中两个向量的内积约等于核函数的相应值，即

```
κ(x, y) = ⟨ϕ(x), ϕ(y)⟩ ≈ z(x)^T z(y), ∀ x, y ∈ 𝒳.
```

为了建立这种近似，调用了谐波分析中的 Bochner 定理（例如[96]）。为了在不求助于数学细节的情况下掌握该定理背后的主要基本原理，让我们回顾一下第 2.4.3 节中的功率谱密度（PSD）概念。平稳过程的 PSD 被定义为其自相关序列的傅里叶变换，在那里已被证明它是一个实值非负函数。此外，其积分是有限的（公式(2.125)）。虽然那里给出的证明遵循了一条相当“实用”且概念化的路径，但一个更严格的数学证明揭示，这一结果是自相关序列正定性质（公式(2.116)）的直接副产品。

在这一思路下，关于 PSD 所述的一切对于平移不变核函数的傅里叶变换同样适用。众所周知，核函数是正定的（第 11.5.1 节）。此外，平移不变性质，即 `κ(x, y) = κ(x − y)`，可视为平稳性的等价形式。由此可证，平移不变核的傅里叶变换是非负实函数，且其积分有限。经过适当归一化，积分值恒可设为 1。因此，平移不变核函数的傅里叶变换可视作概率密度函数（PDF），即积分为 1 的非负实函数。

设 `κ(x − y)` 为平移不变核，`p(ω)` 为其（多维）傅里叶变换，即

```
p(ω) = 1/(2π)^l ∫_{ℝ^l} κ(r) e^{-j ω^T r} dr.
```

然后，通过逆傅里叶变换，我们得到

```
κ(x − y) = ∫_{ℝ^l} p(ω) e^{j ω^T (x − y)} dω.   (11.89)
```

将 `p(ω)` 解释为 PDF 后，公式 (11.89) 右侧即为相应的期望，即

```
κ(x − y) = 𝔼_ω[ e^{j ω^T x} e^{−j ω^T y} ].
```

利用欧拉公式^(⁸⁰) 可消除复指数项：

```
z_{ω,b}(x) := √2 cos(ω^T x + b),   (11.90)
```

其中 **ω** 是遵循 *p*(**ω**) 的随机向量，*b* 是在 [0, 2π] 上均匀分布的随机变量。随后很容易证明（习题 11.12）

*κ*(**x** − **y**) = 𝔼[**ω**, *b*]*z*[**ω**, *b**z***ω**, *b*],

其中期望是针对 *p*(**ω**) 和 *p*(*b*) 计算的。上述期望可通过以下方式近似：

```
κ(x - y) ≈ (1/D) ∑_{i=1}^{D} z_{ω_i,b_i}(x) z_{ω_i,b_i}(y)
```

其中 (**ω**[*i*], *b*[*i*])， *i* = 1, 2, …, *D*，是从相应分布中独立同分布生成的样本。

我们现在拥有了所有必要要素，可以基于上述发现定义一个合适的映射。

*   **步骤 1**：生成 *D* 个独立同分布样本 **ω**[*i*] ∼ *p*(**ω**) 和 *b*[*i*] ∼ 𝒰(0, 2π)， *i* = 1, 2, …, *D*。

*   **步骤 2**：执行以下映射到 ℝ^(*D*)：

### 随机傅里叶特征映射

$$

\mathbf{x} \in \mathcal{X} \longmapsto \mathbf{z}_{\Omega}(\mathbf{x}) = \sqrt{\frac{2}{D}}\left[ \cos(\mathbf{\omega}_{1}^{T}\mathbf{x} + b_{1}),\ldots,\cos(\mathbf{\omega}_{D}^{T}\mathbf{x} + b_{D}) \right]^{T}.

$$

![Equation](img/si454.png)

上述映射定义了原始核的内积近似，即：

$$

\kappa(\mathbf{x} - \mathbf{y}) \approx \mathbf{z}_{\Omega}(\mathbf{x})^{(T)}\mathbf{z}_{\Omega}(\mathbf{y}),

$$

![Equation](img/si455.png)

其中，根据定义：

$$

\Omega := \begin{bmatrix} \mathbf{\omega}_{1} & \mathbf{\omega}_{2} & \ldots & \mathbf{\omega}_{D} \\ b_{1} & b_{2} & \ldots & b_{D} \end{bmatrix}.

$$

![Equation](img/si456.png)

一旦执行了此映射，就可以调用任何线性建模方法在有限维空间中工作。例如，可以使用第 3.8 节中的岭回归任务，而不是求解核岭回归问题。然而，现在涉及的待求逆矩阵维度为 $D \times D$ 而非 $N \times N$，当 $N$ 足够大时，这可以带来显著的计算增益。

$D$ 的选择由用户定义且依赖于具体问题。文献 [91] 中推导了相关的精度界限。对于精度在 $\epsilon$ 范围内的平移不变核近似，只需要 $D = \mathcal{O}(d\epsilon^{-2}\ln\frac{1}{\epsilon^{2}})$ 个维度。在实践中，根据数据集的不同，$D$ 取值在几十到几千的范围内，似乎足以获得相比于一些经典方法显著的计算增益。

### 备注 11.6

*   **Nyström 近似**：获得核矩阵低秩近似的另一种流行且众所周知的技术称为 Nyström 近似。

*   设 $\mathcal{K}$ 为 $N \times N$ 核矩阵。然后从 $N$ 个点中随机选择 $q < N$ 个点。可以使用各种采样场景。结果表明，存在一个秩为 $q$ 的近似矩阵 $\widetilde{\mathcal{K}}$，使得

$$

\widetilde{\mathcal{K}} = \mathcal{K}_{nq}\mathcal{K}_{q}^{-1}\mathcal{K}_{nq}^{T}

$$

![Equation](img/si461.png)

其中 $\mathcal{K}_{q}$ 是与 $q$ 个点子集相关的可逆核矩阵，$\mathcal{K}_{nq}$ 包含与前 $q$ 个点相关的 $\mathcal{K}$ 的列 [130]。推广及相关理论结果见 [36]。若用近似矩阵 $\widetilde{\mathcal{K}}$ 代替原始核矩阵 $\mathcal{K}$，内存需求从 $N²$ 降至 $\mathcal{O}(Nq)$，$\mathcal{O}(N³)$ 阶的运算可降至 $\mathcal{O}(Nq²)$。

### 11.12.1 RKHS 中的在线与分布式学习

处理 RKHS 中的在线算法时，一个主要缺点是内存增长问题。这是表示定理（第 11.6 节）的直接后果：估计函数展开式中的项（核）数量随 $N$ 增长。因此，大多数在线版本的重点在于设计特设技术以减少展开项数。通常这些技术围绕字典概念：根据某准则审慎选择一组点子集，随后用于相关展开。在此思路下，已提出各种 LMS（[68,94]）、RLS（[38,126]）、APSM 和 APA（[108–112]）、PEGASOS（第 8.10.3 节，[62,105]）算法的核版本。此类算法的更详尽论述可从本书网站“Additional Material”部分下载（关联当前章节）。

相反，若采用随机傅里叶特征（RFF）原理，可绕过内存增长问题。RFF 框架提供了理论上令人满意的方法，无需诉诸限制内存增长的特设技术。在 RFF 方法中，只需为 $\boldsymbol{\omega}$ 和 $b$ 随机生成 $D$ 个点，再使用标准 LMS、RLS 等算法。RFF 框架的威力在分布式环境下的在线学习中更显著：迄今开发的所有基于字典的方法均失效，因为字典需在节点间交换，目前尚无切实可行的方法被提出。

RFF 方法在在线学习（特别是分布式环境）中的应用见 [16,17]，其中也讨论了相关理论收敛问题。文中报告的仿真对比结果揭示了可获得的性能增益。$D$ 取几百似乎已足够，且只要不太小，性能对其取值不敏感。

## 11.13 多核学习

所有基于核的算法流程面临的一个主要问题是合适核的选择及其定义参数的计算。通常通过交叉验证完成：在独立于训练数据的验证集上使用若干不同核（见第 3 章了解不同验证方法），选取表现最好的一个。显然这不是通用方法；耗时且理论上不吸引人。理想情况是拥有一组不同核（也包括同一核不同参数的情况），让优化过程决定如何选择合适的核或核的组合。这就是通常称为*多核学习*（MKL）的研究活动范围。为此，已提出多种 MKL 方法处理若干基于核的算法方案。完整综述超出本书范围。此处简要概述与本章内容相关的 MKL 主要方向。详见 [48] 了解各技术的比较研究。

开发高效 MKL 方案的早期尝试之一见于文献 [65]，其中作者考虑了核矩阵的线性组合，即 $K = \sum_{m = 1}^{M}a_{m}K_{m}$。

由于我们要求新的核矩阵必须是正定的，因此在优化任务中施加一些额外约束是合理的。例如，可以采用通用约束 $K \succeq 0$（该不等式表示半正定性），或更严格的约束，例如对所有 $m = 1, \dots, M$ 都有 $a_{m} > 0$。此外，还需要对最终核矩阵的范数进行约束。因此，MKL SVM 任务可以表述为

```
minimize with respect to K ω_C(K), subject to K ⪰ 0, trace{K} ≤ c,
```
