
# 无线安全协议与威胁

## 无线安全协议演进

从 20 世纪 90 年代中期开始，无线技术得到了快速部署。因此，无线安全问题需要解决。第一种加密标准无线等效隐私（`WEP`）开发于 90 年代后期，它是一个基础且有缺陷的协议。它的局限性要求无线网络进行重大改进才能被认为是安全的。从那时起出现了两种主要协议：Wi-Fi 保护（`WPA`）和 `WPA2`。`WPA2` 与 `802.11i` 同义，它是目前推荐使用的标准（图 19.2）。

### 有线等效隐私 (WEP)

`WEP` 于 1997 年作为原始 `802.11` 标准的一部分被开发出来。`WEP` 的目标是通过使用 `CRC-32` 校验和和 `RC4` 提供与有线网络同级别的安全性。`CRC-32` 是一种用于检测数据变化的完整性工具。`RC4` 是一种加密方法，在 2001 年被监听网络的攻击者利用来截获所使用的密钥。无线安全中使用的密钥称为预共享密钥，或 `PSKs`。`PSKs` 由客户端和 `AP` 共享，并用于身份验证。

2004 年，发现了足够的漏洞，导致 `WEP` 被正式谴责。2005 年，美国联邦调查局（`FBI`）能够在不到 3 分钟内轻松渗透一个受 `WEP` 保护的网络。2007 年，在一次针对 `T.J.Maxx` 的大型黑客攻击后，发现主要企业在使用名昭臭的脆弱且过时的 `WEP` 标准。

### Wi-Fi 保护 (WPA)

`WPA` 在发现 `WEP` 漏洞后，作为一种快速的链路层安全修复而创建的。它并不是一个完美无缺的解决方案，而是开发更完整的 `WPA2` 期间使用的临时解决方案。

#### 临时密钥完整性协议 (TKIP)

加密通过使用预共享密钥技术 `TKIP` 来实现。`TKIP` 基于 `RC4`，每个数据包都会生成一个不同的 128 位密钥（不像 `WEP` 技术，它的密钥较短且对于每个 `AP` 是静态的）。这对抗完整性攻击，因为每个数据包都有自己唯一的密钥。此外，数据包必须按正确顺序被 `AP` 接受。最后，`TKIP` 使用额外的 64 位消息完整性检查（`MIC`），命名为 `Michael`，这是对 `WEP` 的 `CRC` 的改进。`Michael` 的目标是防止攻击者更改数据。不幸的是，黑客仍然能够更改数据包。由于 `TKIP` 基于旧的 `WEP` 技术，已被认定为不安全并被取消。

#### 扩展身份验证协议 (EAP)

`EAP` 是一种在 `WPA` 中首次引入的用户验证框架。与仅使用 MAC 地址进行验证的 `WEP` 不同，`EAP` 使用各种验证方法来验证用户。EAP 的示例包括令牌卡、公钥加密和一次性密码。当用户尝试连接网络时，`AP` 将通过验证服务器（如 `RADIUS`）确认用户身份。`RADIUS` 代表远程拨号用户服务，被互联网服务提供商（`ISPs`）用于验证用户名和密码。

#### 轻量级扩展身份验证协议 (LEAP)

实现 `EAP` 的方法有很多。`LEAP` 是 Cisco 系统开发的专有方法。它基于 `MS-CHAP`，这是一种已被认为不安全的微软验证协议。`LEAP` 方法很流行但相当脆弱。Cisco 建议任何使用 `LEAP` 的用户都应具有复杂的密码。由于 `LEAP` 仅在基于 Cisco 的网络设备上工作，它与非 Cisco 产品兼容。

#### 保护扩展身份验证协议 (PEAP)

`PEAP` 是 `EAP` 内部的一种封装形式。封装是用于在两个单元之间构建通信的方式。在特定情况下，`PEAP` 既封装又加密安全访问传输，使其无法被轻易拦截和解码。`PEAP` 由微软、Cisco 系统和 RSA 安全创建。

#### 无线传输层安全 (WTLS)

`WTLS` 是无线应用协议（`WAP`）版本 1.1 的安全级别。`WTLS` 提供了 WAP 设备的隐私、数据完整性和身份验证。`WTLS` 确保设备与服务器之间的连接是安全的并加密数据传输。`WTLS` 在很大程度上基于 `TLS`，但针对移动设备进行了调整。`TLS` 和 `WTLS` 都在 OSI 模型的会话层（第 5 层）初始化，并在表示层（第 6 层）运行。

WTLS 主要依靠数据包大小压缩，以及 Web 内容开发者创建独立的 WAP 网页（这些网页内容较少且可以在 WAP 格式运行）。今天，`WAP 2.0` 浏览器已经支持 HTML 格式。设备处理能力的提高以及无线/蜂窝网络传输能力的提升，使得更强大的移动设备能够以原始格式显示网页，而无需使用 WAP。

随着 `WAP 2.0` 在 2002 年发布，`WTLS` 被 `TLS` 代替。服务器不再需要解密来自 `WTLS` 的数据并使用安全套接层（`SSL`）重新加密，可以直接接受 `TLS` 传输，不再需要经过切换加密类型的额外步骤。

## Wi-Fi 安全设置 (WPS)

`WPA` 的一个主要缺陷是引入了 `WPS`。`WPS` 让经验较少的计算机用户能够使用 `WPA` 来保护他们的网络。要向网络添加新设备，用户可以使用八位 PIN 方法。遗憾的是，这些 PIN 码很容易通过暴力破解破解，从而导致 `WPS` 极不安全。为了避免这一漏洞，应该禁用 `WPS`。

### WPA2

`WPA2` 于 2004 年实施，基于新开发的 `802.11i` 标准。`802.11i` 和 `WPA2` 术语通常通用。`WPA2` 主要有两种类型：个人版或企业版。个人使用涉及 `PSKs` 且不需要认证服务器。企业场景使用 `EAP` 并涉及客户端（请求者）、`AP`（认证器）和认证服务器。

`802.11i` 还定义了健壮安全网络 (`RSN`)，它主要通过四次握手和组密钥握手引入并实现安全性。`RSN` 通过认证和密钥确保网络通信和数据传输的安全性。如果设备之前通过了认证，它将加入健壮安全网络关联 (`RSNA`)。`WPA2` 的缺点之一是某些旧硬件可能无法兼容新协议，或者需要升级固件。来自 Wi-Fi 联盟的测试和认证确保了网络是 `WPA2` 安全的，且设备获得 Wi-Fi 标志必须完成此项工作。在使用 `WPA2` 时，使用多种密钥对流量进行加密，如图 19.3 所示。

它始于成对主密钥 (`PMK`)，该密钥由主会话密钥 (`MSK`) 派生。客户端和 `AP` 都知道 `PMK`，目标将其转换为加密的临时密钥。`PMK` 启动四次握手，然后产生单播成对临时密钥 (`PTK`) 或组组临时密钥 (`GTK`)。四次握手是一种分四步建立安全连接的方法。它允许 `AP` 和客户端证明他们知道这些密钥，而无需实际说出它们。

`WPA2` 过程从 `AP` 和客户端选择它们都支持的安全方法开始。这包括认证方法的类型（例如 `802.1X`——也称为 `EAPOL` [局域网上的扩展认证协议] 或 `PSK`）和安全协议（例如 `CCMP` 和 `TKIP`）。这里的选择取决于使用场景（个人或企业）。接下来，`AP` 请求客户端的身份，在认证成功后，创建一个 `PMK`。在两个设备都知道 `PMK` 后，开始四次握手（图 19.4）。

`AP` 向客户端发送第一条消息，称为 `ANonce`。这是一个随机生成的仅使用一次的认证数字。客户端随后据此生成 `PTK`（加密密钥集）。接下来，客户端发送受 `MIC` 保护的 `SNonce`（仅使用一次的请求者/客户端数字），然后 `AP` 回传其计算出的、受 `MIC` 保护的 `PTK` 和 `GTK`（用于单播和组播流量）。最后，客户端向 `AP` 发送确认消息，确认其已准备好进行加密通信。成对和组（临时）密钥由 `CCMP` 协议用于确认完整性和机密性。如果需要更新 `GTK`，则会发生类似的组密钥握手。

`WPA2` 安全性最注目的目的是强制要求使用 `AES-CCMP` 算法。它代表高级加密标准计数模式密码块链消息认证码协议。这种强加密协议确认了消息的完整性和机密性。`CCMP` 基于 `AES`，是对 `TKIP` 的改进。`WPA2` 不再使用 `TKIP`，但设置了一个可以使其与旧 `TKIP` 设备兼容的选项。这是出于兼容性考虑，但由于 `TKIP` 的存在仍存在网络安全风险。`WPA2` 使用与 `WPA` 部分讨论的类似的 `EAP` 认证方法。

`WPA2` 比早期的无线协议更安全、更先进。它消除了中间人 (`MitM`) 攻击以及数据包认证伪造的担忧。`PMK` 缓存允许客户端无需重新认证即可轻松重连。它在支持所有 WPA 功能的同时增加了更强的加密和认证。

与大多数技术一样，`WPA2` 并不完美。物理层攻击仍然是一个问题，链路层劫持也是担忧。虽然攻击者可能无法读取包中的数据，但他们可以分析未加密的控制帧来获取有用信息。`WPA2` 还容易受到 `DoS` 攻击和 MAC 地址欺骗。`WPA2` 最严重的漏洞被称为 Hole196。该漏洞允许知道 `GTK` 的内部人员向不知情的用户插入并发送错误的 `GTK` 数据包。然后攻击者就可以解密其他用户的数据，发现其 Wi-Fi 的漏洞，并使整个设备陷入危险。

## 其他安全考虑

除了广泛使用的协议外，安全无线网络的基本技术包括修改默认 `SSID` 配置和 MAC 地址过滤。为了安全无线网络，不应广播 `SSID`。这样，用户必须知道名称才能尝试连接。还应更改默认 `SSID` 以防止黑客猜测名称。MAC 地址过滤涉及配置 `AP` 仅允许根据 MAC 地址通过的设备接入。然而，这并非万无一失，因为攻击者可能发现已批准的 MAC 地址并伪造该地址。

物理安全是一个至关重要的基础考虑因素。如果无线设备不安全，那么无线网络就是不安全的。首先，每个设备都应该放置在接触不到的地方，或者被锁起来。监控摄像头应该放置在重要设备上，以监控任何可疑活动。还应该考虑地理位置，因为自然灾害可能对网络设备构成威胁。物理保护无线网络设备的方法有很多种，但至少提供一些物理保护是非常重要的。

最后，应该实施 `WIDPS` 来监控网络上的流量，并向管理员警报任何可疑活动。入侵防御和检测系统有不同的类型，但 `WIDPS` 是专门针对无线网的。这些系统能够查看流量和协议，以判断流量是否合法。如果检测到异常流量，可以配置为尝试停止该流量。即使没有其他功能，它至少会保留流量活动的日志。该系统能够完成的一些工作包括重置连接、阻止某些流量或丢弃数据包。

## 无线网络的威胁

不遵循上一节讨论的受认可无线安全协议可能会导致 WLAN 基础设施易受到攻击。由于无线网络利用射频（`RF`）作为信息传输的介质，对安全和不安全的 WLAN 都有许多威胁。无线网络之所以由于连接设备的移动性、低成本以及涉及硬件较少而变得像今天这样流行，这并不意外；然而，随着无线网络在企业和个人环境中的普及，由于基础设施的性质，网络威胁面临着日益增长的挑战。无线安全的增长与技术本身一样快。即使按照上一节中提到的通过 `WPA2` 安全 WLAN 的标准，攻击将是我们社会中一个固有的问题。本节将专门介绍没有安全防护措施的弱网络的风险，以及目前 WLAN 中存在的常见攻击类型。

在寻找可被黑入的网络时，攻击者通常会寻找那些没有使用 `WPA2` 或之前讨论的其他安全协议保护其 `802.11` WLAN 的网络。他们的希望是发现那些正使用这些安全协议进行加密和保护的确切网络信息。攻击者的共同目标是与无线接入点关联，这可以启动许多种不同的攻击。`SSIDs`、`MAC addresses`、默认配置、使用的网络加密协议以及物理安全中的缺陷都是攻击者试图获取或发现的常见信息类别。

有多种攻击方法用于获取私有网络信息，允许攻击者访问 WLAN。通常，这些攻击可以分为五类：机密性、访问控制、完整性、可用性和身份验证。这五类有助于划分攻击的类型，但由于攻击的组合，取决于要获取何种类型的信息，类别之间将存在重叠。本节将揭示无线网络的一些最大漏洞以及威胁 WLAN 的常见攻击类型。

### 机密性攻击

机密性攻击的目标是通过被动攻击或主动攻击，获取通过 WLAN 传输的私有信息。一旦黑客能够获取这些敏感信息，攻击就会进一步恶化。

为了拦截跨无线网络发送的敏感数据，会使用常用的被动攻击方法。由于其非侵入性的本质，被动攻击很难被检测。利用被动攻击的攻击者只是在一段时间内观察传输的数据，而不对数据进行任何更改。窃听和流量分析是常见的被动攻击类型，黑客会在这些攻击中利用各种“嗅探”工具从弱或不安全的网络中拦截信息。这是今天公共无线网络或热点常见的一个重大问题，在 `RF` 信号范围内的攻击者可以从建筑外捕获跨越不安全网络的传输。

与被动攻击不同，主动攻击是一种攻击类型，黑客会实际获取拦截的数据，以某种方式对其进行处理，并将其嵌入网络或通信流中。今天 WLAN 上两种非常常见的主动攻击是 `MitM` 和 `evil twin AP`。这两种攻击通常都基于非法 `AP` 的设置，即在网络中建立一个未经授权的 `AP`，该 AP 通常与无线网络的合法 `AP` 共享相同的 `SSID` 信息和配置。这在企业环境中已成为挑战，因为非法 `AP` 并不总是出于恶意意图设置的。

员工经常会配置连接到企业网络的非法 `AP`，因为与公司的合法 `AP` 相比，他们办公位置接收到的信号较弱。`evil twin AP` 只是对具有恶意意图的非法 `AP` 的名称。攻击者将尝试让 `STA`（任何连接到网络的设备）与非法 `AP` 关联。一旦发生这种情况，攻击者可能从 `STA` 与非法 `AP` 的通信中获取敏感凭据或信息。由于难以区分 `evil twin AP` 和公司的合法 `AP`，终端用户或 `STA` 很容易与虚假 `AP` 关联。大多数公司现在频繁监控和审计网络上任何非法 `AP` 的设置，因为无法辨别配置意图的不同。

如前所述，如果攻击者能够成功在无线网络上设置非法 `AP`，他们就可以执行 `MitM` 攻击。这是一种主动攻击，黑客会实际作为虚假 `AP` 放置在两个通信节点之间，并等待敏感信息的传输，从而允许他们拦截消息。通过这样做，攻击者通常不会被察觉，通信设备认为它们仍然在相互通信。

### 访问控制攻击

访问控制攻击用于通过一系列尝试突破网络过滤器和防火墙，获取无线网络的未经授权访问。如前所述，某些攻击会在五个类别之间重叠，访问控制攻击显示了这种重叠。由于需要进入 `AP` 的攻击性质，`evil twin AP` 的设置完全可以归类为访问控制类别，也可以归类为机密性类别。尽管如此，为了讨论起见，如果攻击者在获得网络未经授权访问后寻求获取机密信息，我们将将其视为机密性攻击。

#### 漫游攻击 (Wardriving)

最常见的访问控制攻击类型之一是漫游攻击。这种攻击涉及通过在车辆行驶并嗅探网络，尝试访问未加密或安全防护不善的网络。漫游攻击者通常会利用全球定位系统（`GPS`）对一个区域进行绘制，以便嗅探该区域的 `APs`。在完成区域绘制后，他们可以沿着路线识别每个网络的漏洞或弱点。车辆上通常会配备一台安装了软件的笔记本电脑（通常是免费软件），允许攻击者监听无线网络的广播并将数据捕获到他们的设备上。`NetStumbler`、`Kismet` 和 `Kismac` 是目前用于漫游攻击的几种软件工具。需要注意的是，漫游攻击或嗅探无线 `APs` 并不是犯罪，但当发生实际的信息窃取或未经授权访问 `WLAN` 时，这种行为就变成了犯罪行为。图 19.5 显示了任何执行此类攻击的车辆中常见的典型漫游攻击工具包。

另一种访问控制攻击是 `MAC` 欺骗。这种特定攻击允许攻击者使用之前提到的嗅探工具来寻找并访问网络。其目标是搜索从 `AP` 发出的网络 `MAC` 地址并对其进行“欺骗”。如果攻击者成功欺骗了 `MAC` 地址，他们将尝试让数据包路由到他们的设备而不是实际的网络主机。与关于此主题的其他讨论类似，可以通过有效的端口安全方法来避免这种攻击。图 19.6 描述了如何进行 `MAC` 地址欺骗。

到目前讨论的两种访问控制攻击也可以称为非法访问攻击。这种攻击被视为该类别内其他攻击的伞，因为从技术上讲，它们都涉及在执行攻击之前获取 `WLAN` 的未经授权访问。这种攻击就像名称一样简单。它是一种个人在没有适当身份验证的情况下获取网络的攻击。

## 结论

无线技术在过去的几十年中呈现爆炸式增长。由于我们现在的大量数据都在网上并可以通过无线传输，因此安全性的不可破性至关重要。`CIA` 三要素模型概述了安全预期：机密性、完整性和可用性。这些内容的实现变得越来越困难，但对于无线网络的保护来说也变得越来越重要。到目前，保护网络的最佳方法是结合这里概述的各种努力，其中最重要的是 `WPA2` 的实施。

讨论的攻击和展示的案例研究说明了为什么必须强力且正确地实施无线安全——一个微小的配置错误就会导致巨大的漏洞。这就是为什么风险评估如此重要。频繁的渗透测试和持续的监控是组织可以采取以确保其安全水平标准的简单步骤。无论网络有多安全，总有人会在另一端试图渗透它。组织中的每个人都有责任保持网络安全；毕竟，链条的强度取决于其最弱的环节。
