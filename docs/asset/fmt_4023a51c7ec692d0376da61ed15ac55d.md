现在让我们建立在公式(13.116)中的后验 DP 公式之上。为此，将遵循文献[83]提供的推理。在观测到样本**θ**[1], …, **θ**[*n*]之后，我们关注下一次抽取**θ**[*n* + 1]，并将计算该样本落在区间*T*内的概率。为简化符号，让我们用*G*′表示后验*G*|**θ**[1], …, **θ**[*n*]。然后我们写出

在上述表述中，括号内的项之所以这样写，是为了提醒我们其离散概率的性质，即各项之和为 1。

最后一个公式引出了如下的物理解释。考虑一个空盒，并假设 `θ` 中的每个值对应一种唯一的颜色。此外，我们拥有可数无限个球。从基础分布中随机选取一种颜色，即 `θ[i] ∼ G[0]`，并将球涂成相应的颜色。球涂色后，将其放入盒中，盒中现有一个球。在第二步中，我们拿起一个新球，然后要么 (a) 以概率 `\frac{\alpha}{\alpha + 1}` 选取一种新颜色 `θ[2] ∼ G[0]`，将其涂上相应颜色并放入盒中，要么 (b) 以概率 `\frac{1}{\alpha + 1}` 将球涂成盒中已有球的相同颜色，然后将其放入盒中。现在盒中有两个球。重复上述步骤。因此，在第 (`n` + 1) 步时，盒中包含 `n` 个球。我们拿起一个新球，然后要么 (a) 以概率 `\frac{\alpha}{\alpha + n}` 选取一种新颜色 `θ[n + 1] ∼ G[0]`，涂上新球并将其放入盒中，要么 (b) 以概率 `\frac{n}{\alpha + n}` 从盒中的 `n` 个球中随机选取一个，用其颜色涂新球；涂色后，也将其放入盒中，盒中将包含 `n` + 1 个球。文献 [10] 利用这一解释证明了 DP 过程的存在性。

有两个重要性质。注意到随着 `n` 增加，从盒中选取颜色的概率 `\frac{n}{\alpha + n}` 相对于从 `G[0]` 选取颜色的概率 `\frac{\alpha}{\alpha + n}` 不断增大。因此，对于长序列，我们将越来越多地选取先前使用过的颜色，这些颜色将被重复使用。这证明了该过程的离散性质。

另一个重要性质是，生成一系列颜色的概率，即 **θ**[1], …, **θ**[*n*] 等于以任意顺序生成这些颜色的概率。也就是说，

*P*(**θ**[1], …, **θ**[*n*]) = *P*(**θ**[*π*(1)], …, **θ**[*π*(*n*)])

![Equation](img/si467.png)

其中 *π*(·) 表示 {1, 2, …, *n*} 中数字的任意排列。这类序列被称为可交换的（有关深入讨论请参见文献 [36]）。

图 13.15 展示了浓度参数 *α* 取两个不同值时的不同实现情况。基分布是均值为零、方差为单位的标准高斯分布。使用了两个不同的浓度参数值，并对每个值进行了三次不同的抽取。对于较小的值 *α* = 1，只有少量离散概率质量存活下来。这是自然的，因为在公式 (13.117) 中，当 *α* 的值较小时，右侧两项中第一项的显著性较小。因此，选择先前生成值的概率较大。当 *α* 取较大值时，情况相反。在后一种情况下，仅当 *n* 变得相对较大时，第一项的显著性才会变小。因此，会有更多的概率质量存活下来。

#### 中餐馆过程再探

我们已经评论过 DP 的离散性质。此外，公式 (13.117) 中的规则意味着抽取产生的值具有聚类结构。如前所述，连续抽取（颜色）会反复选取先前抽取的值。令 **θ**[1]^(\*), …, **θ**[*K*[*n*]]^(\*) 为 *n* 次连续抽取后存活下来的 *K*[*n*] 种颜色。令 *n*[1], …, *n*[*K*[*n*]] 为每种颜色对应的出现次数。则公式 (13.117) 可重写为

$$\\mathbf{\\theta}\_{n + 1}|\\mathbf{\\theta}\_{1},\\ldots,\\mathbf{\\theta}\_{n} \\sim \\frac{\\alpha}{\\alpha + n}G\_{0} + \\frac{n}{\\alpha + n}\\left( \\frac{1}{n}\\sum\\limits\_{i = 1}^{K\_{n}}n\_{i}\\delta\_{\\mathbf{\\theta}\_{i}^{\\ast}}(\\mathbf{\\theta}) \\right).$$

![Equation](img/si474.png)

观察可知，上述公式直接导出了公式 (13.111)（如果将其应用于第 *n* 位顾客而非第 *n* + 1 位顾客）。确实，我们要么选择一种新颜色（在 CRP 情况下为桌子），要么选择第 *i* 种先前已选的颜色，其概率为 $\\frac{n\_{i}}{\\alpha + n}$，*i* ≤ *K*[*n*]。回顾第 13.11.1 节，根据此规则，聚类的期望数量按 *α*ln *n* 增长。

得到 CRP 的另一种途径是将其作为有限混合建模的极限情况（*K* → ∞），通过采用参数为 *α*/*K* 的狄利克雷先验来实现（参见，例如，\[23,74\]）。

**聚类分配具有可交换性**：CRP 的一个重要方面是，特定聚类的概率不依赖于顾客到达的顺序，并且在重新洗牌顾客后保持不变，仅表现为桌子标签的一个排列（参见问题 13.22）。换句话说，这意味着在 图 13.14 中，重要的是例如顾客 #1、#4、#5 坐在同一张桌子旁，而顾客 #3 独自坐在一张桌子旁。桌子的编号并不重要。
