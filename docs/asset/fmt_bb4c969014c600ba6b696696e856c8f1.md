
假设 `X` 对于某个足够小的值 `δk` 和未知向量的稀疏度 `k` 满足 RIP。另假设观测值是精确的，即 `y = Xθ`。由于 `X` 的近正交性质，有 `X^T y = X^T X θ ≈ θ`。因此，直觉表明，在第一次迭代步骤中，选择 `X^T y` 中幅度最大的 `t` 个分量（`t` 为用户定义参数）作为稀疏目标向量非零位置的指示，这是不无道理的。这一推理在所有后续步骤中延续，在第 `i` 次迭代中，残差 `e^(i−1) := y − X θ^(i−1)` 取代了 `y` 的位置，其中 `θ^(i−1)` 表示第 `(i−1)` 次迭代时目标向量的估计。基本上，这可以被视为 OMP 的一种推广。然而，正如我们即将看到的，这两种机制之间的差异更为本质。

### 算法 10.2：CSMP 方案

1. 选择 `t` 的值。
2. 初始化算法：`θ⁰ = 0`，`e⁰ = y`。
3. 对于 `i = 1, 2, ...`，执行以下操作：

#### (a) 获取当前支撑集：

```
S^{(i)} := \text{supp}\left( \mathbf{\theta}^{(i - 1)} \right) \cup \left\{ \frac{\text{模值最大的 } t \text{ 个分量的索引}}{\text{来自 } X^{T}\mathbf{e}^{(i - 1)}} \right\}。
```

#### (b) 选择活动列：

根据 `S^{(i)}` 构建 `X^{(i)}` 以包含 `X` 的活动列。显然，`X^{(i)}` 是一个 `N × r` 矩阵，其中 `r` 表示支撑集 `S^{(i)}` 的基数。

#### (c) 更新参数向量估计：

求解最小二乘问题

```
\widetilde{\mathbf{\theta}} := \arg\min_{\mathbf{z} \in \mathbb{R}^{r}} \| \mathbf{y} - X^{(i)}\mathbf{z} \|_{2}^{2}。
```

1. 获取 `\widehat{\mathbf{\theta}}^{(i)} \in \mathbb{R}^{l}`，其包含 `\widetilde{\mathbf{\theta}}` 的 `r` 个元素，分别位于支撑集指示的位置，其余元素为零。

#### (d) `\mathbf{\theta}^{(i)} := H_{k}\left( {\widehat{\mathbf{\theta}}}^{(i)} \right)`。

映射 `H_{k}` 表示*硬阈值*函数；即，它返回一个包含参数中模值最大的 `k` 个分量的向量，其余分量强制置零。

#### (e) 更新误差向量：

`\mathbf{e}^{(i)} = \mathbf{y} - X\mathbf{\theta}^{(i)}`。

该算法要求输入稀疏度 `k`。迭代将持续进行，直到满足停止准则。`t` 的值决定了步骤 1 和 3a 中幅值最大的元素，其取决于具体算法。在压缩采样匹配追踪算法中，`t = 2k`（问题 10.3）；而在子空间追踪算法中，`t = k`。

阐述了通用方案后，与 OMP 的一个主要区别变得显而易见。在 OMP 中，每次迭代步骤仅选择一列。此外，该列将在所有后续步骤中保留在活动集合中。如果由于某些原因这不是一个好的选择，该方案将无法从这种错误决策中恢复。相比之下，支撑集（因此 `X` 的活动列）在 CSMP 中会持续更新，随着更多信息的积累和迭代的推进，算法有能力纠正先前的错误决策。文献 [33] 表明，如果观测值是精确的（`y = Xθ`），那么只要 `X` 满足 `δ[3k] < 0.205` 的 RIP 条件，SP 就能在有限次迭代步骤内恢复 `k` 稀疏的真实向量。如果观测值含有噪声，已推导出性能界限，其在 `δ[3k] < 0.083` 时成立。对于 CoSaMP，已推导出 `δ[4k] < 0.1` 时的性能界限。

### 10.2.2 迭代收缩/阈值（IST）算法

这类算法也有悠久的历史（例如见 [44,69,70,73]）。然而，在“早期”，大多数开发出的算法都带有一定的启发式色彩，并未建立起与优化代价函数的明确联系。后来的尝试则得到了关于收敛性和收敛速度等问题的可靠理论论证的支持 [31,34,50,56]。

该算法家族的通用形式与经典线性代数中用于逼近大型线性方程组解的迭代方案（称为*平稳迭代*或*迭代松弛*方法）有着惊人的相似性。数值分析中的经典 Gauss-Seidel 和 Jacobi 算法（例如 [65]）可被视为该家族的成员。给定一个包含 `l` 个方程和 `l` 个未知数的线性系统 `z = Ax`，第 `i` 步的基本迭代具有以下形式：

```
x^(i) = (I - QA)x^(i-1) + Qz = x^(i-1) + Qe^(i-1),  e^(i-1) := z - Ax^(i-1),
```

这并不令人惊讶。它与大多数数值解迭代方案具有相同的形式。矩阵 `Q` 的选择是为了保证收敛，不同的选择会导致不同的算法，各有优缺点。事实证明，这种算法形式也可以应用于欠定方程组 `y = Xθ`，只需进行“微小”的修改，这是由目标向量的稀疏性约束所施加的。这导致了以下迭代计算的通用形式：

**θ**^((*i*)) = *T**i*) + *Q***e**^((*i* − 1))), **e**^((*i* − 1)) = **y** − *X***θ**^((*i* − 1))

从 **θ**^((0)) 的初始猜测开始（通常 **θ**^((0)) = **0**，**e**^((0)) = **y**）。在某些情况下，*Q* 可以设为与迭代相关。函数 *T*[*i*] 是一种非线性阈值处理，以*逐项*方式应用，即*逐分量*。根据具体方案，这可以是硬阈值函数，记作 *H*[*k*]，也可以是软阈值函数，记作 *S*[*α*]。硬阈值处理，正如我们已知，保留向量中最大的 *k* 个分量不变，并将其余分量设为零。软阈值处理在第 9.3 节中已介绍。幅值小于阈值 *α* 的所有分量被强制置零，其余分量的幅值减小 *α*；即向量 **θ** 的第 *j* 个分量，经软阈值处理后变为

```
(Sα)[j] = sgn(θ[j])(|θ[j]| − α)[+].
```

根据 (a) *T*[*i*] 的选择，(b) 参数 *k* 或 *α* 的具体值，以及 (c) 矩阵 *Q*，会出现不同的实例。*Q* 最常见的选择是 *μX*^(*T*)，主迭代的通用形式变为

### 迭代收缩阈值算法（IST）及其变体

#### 迭代公式

```
\widehat{\mathbf{\theta}} = S_{\lambda/c}\left( \widetilde{\mathbf{\theta}} + \frac{1}{c}X^{T}(\mathbf{y} - X\widetilde{\mathbf{\theta}}) \right). \tag{10.8}
```

在迭代公式中，`\widetilde{\mathbf{\theta}}` 被选为先前获得的估计值；通过这种方式，试图使新估计值接近前一个估计值。该过程直接导出了我们在公式 (10.2) 中的通用方案，使用参数为 `\lambda/c` 的软阈值处理。可以证明，这种策略收敛于原始 LASSO 问题的一个极小化解。文献 [56] 使用优化理论中的 *majorization-minimization*（极大化-极小化）技术得到了相同的算法。因此，从这个角度来看，IST 算法族与属于凸优化类别的算法有着紧密的联系。

#### SpaRSA 算法

文献 [118] 提出了 *sparse reconstruction by separable approximation*（可分离近似稀疏重构，SpaRSA）算法，这是标准 IST 方案的一种修改。其出发点是公式 (10.3)；然而，乘法因子 `\frac{1}{2\mu}` 不再是常数，而是根据某个规则允许在迭代过程中变化。这导致了算法收敛速度的加快。
