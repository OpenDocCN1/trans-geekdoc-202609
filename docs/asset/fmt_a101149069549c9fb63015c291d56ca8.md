
通常，给定学习系统中的观测集，目标结果根据知识库中的知识进行求解。我们假设观测集是紧连接的，因此我们可以在观测集的单元点取一个在自同构 `Ad(G)` 作用下不变的内部积 `⟨ , ⟩`。我们取一组标准正交基，然后使用左平移将它们扩展为观测集的左不变向量场，从而可以在观测集的每一点唯一地设置内部积。这个内部积正是该点切空间的标准正交基，从而形成一个黎曼空间。

由于正交向量场的左不变性，所有左平移都是黎曼空间的等距变换。由于内部积的不变性，所有右平移都是等距变换。设 `T_g(G)` 为单点切空间，`𝔤` 为 `G` 的李代数，`T_a(G)` 为任意样本点 `a` 的切空间，`dl_a`，`dr_a` 为左变换，`l_a` 为右变换，且 `r_a` 为切空间之间的诱导线性映射。因此，我们得到如图 1.5 所示的以下几何模型结构。

### 算法 1.12：李群机器学习等距变换算法

**初始化：** `(X, τ)` 是一个拓扑空间，`x ∈ X`

**输入：** 样本集 `X = {x_1, x_2, …, x_n ∈ ℝ^D}`

**输出**：`Y = {y_1, y_2, …, y_n ∈ ℝ^d}`，`d < D`

- (1) 输入样本集 `X = {x_1, x_2, …, x_n ∈ ℝ^D}`，`X` 满足李群结构。
- (2) 寻找在 `X` 的李代数 `𝔤` 上，自同构 `Ad(G)` 作用下的不变内部积：`⟨Ad(𝔤)x_1, Ad(𝔤)x_2⟩ = ⟨x_1, x_2⟩`，`x_1, x_2 ∈ 𝔤`，`𝔤 ⊂ G`。
- (3) 给出一组标准正交基 `{X_i; 1 ≤ i ≤ n}`，`⟨X_i, X_j⟩ = δ_ij`。使用左变换将 `{X_i; 1 ≤ i ≤ n}` 转换为 `X` 上的左不变向量场，记为 `X_i`。这用于建立黎曼空间结构。
- (4) 在此黎曼空间中，对 `X` 进行左（或右）平移线性变换，构成样本集的等距变换 `φ`：`X → Y`，`Y = {y_1, y_2, …, y_n ∈ ℝ^d}`，`d < D`。

测地线是黎曼流形中最基本且最重要的概念之一。它是黎曼流形中的局部最短路径，对于研究高维空间中的流形作为一种测量手段非常重要。在微分流形中，由于流形是局部欧几里得的，直接计算测地线的距离非常困难。因此，通常用切平面代替流形的较小部分，从而将测地线的计算转化为二维平面中的欧几里得距离计算。

在李群机器学习中，假设样本空间 `G` 嵌入到微分流形 `M` 中。对于任意样本 `a`，学习过程确定一个映射 `x_a: G ⊃ U_a → V_a ⊂ ℝ^D`，其中 `(U_a, x_a)` 被称为 `M` 在点 `a` (`a ∈ U_a`) 处的邻域坐标系，`U_a` 是点 `a` 的坐标邻域，`V_a` 是 `ℝ^D` 的开集。

**定义 1.18.** 设 `(M, X)` 是一个微分流形，其中 `X` 是 `U` 上的局部坐标系，`r_j: ℝ^D → ℝ` 是 `ℝ^D` 上的第 `j` 个坐标函数，即 `r_j(a_1, a_2, …, a_n) = a_j`。那么，`x` 的第 `j` 个坐标函数是 `x_j: U → ℝ`，即 `x_j = r_j ∘ x`。

**定义 1.19.** 设 `(M, X)` 是一个微分流形，`a ∈ M`，`C^∞(M, a, ℝ)` 是 `a` 邻域内实值函数的集合。那么，点 `a` 处的切向量是一个映射，即 `v: C^∞(M, a, ℝ) → ℝ`。如果 `x` 是 `a` 邻域内的局部坐标系，则存在一个实值 `n` 元组 `(a_1, a_2, …, a_n)`。对于每个 `f ∈ C^∞(M, a, ℝ)`，这个 `n` 元组满足

$$ v(f)=\sum_{i=1}^{n} a_{i} \left. \frac{\partial}{\partial r_{i}}(f \circ x_{i}^{-1}) \right|_{x(a)} \quad (1.1) $$

点 `a` 处所有切向量 `M` 的集合表示为 `T_a(M)`，这意味着 `M` 是点 `a` 的切空间。如果 `x: U → ℝ^D` 是点 `a` 处的坐标系，且 `⟨∂/∂x_i⟩` 是点 `a` 处 `x_i` 的方向向量，则 `{⟨∂/∂x_1⟩, ⟨∂/∂x_2⟩, …, ⟨∂/∂x_n⟩}` 是切空间 `T_a(M)` 的坐标基。如果内部积 `g_{i,j}(a)=⟨⟨∂/∂x_i⟩, ⟨∂/∂x_j⟩⟩` 是 `U` 上的可微函数，则点 `a` 和 `b` 之间的距离

切空间中的距离为

$\mathrm{D}(a,\, b) = \sqrt{\sum_{i, j=1}^{n} g_{i,j}(a)(a_i - b_i)(a_j - b_j)} \ . \tag{1.2}$

因此，在李群机器学习中，基于测地距离的学习算法的基本步骤可以总结如下。

### 算法 1.13：李群机器学习的测地距离算法

**初始化：** `(X,τ)` 是一个拓扑空间，`x ∈ X`

**输入：** 样本点 `a`

**输出：** 坐标邻域内所有点与 `a` 之间的距离

1. 生成样本点 `a` 的邻域 `U_a`。
2. 分析样本集中 `a` 的邻域信息，在不变内积 `g_{i,j}(a)` 下取一个自同构，并计算 `g_{i,j}(a)` 的值。
3. 将得到的值 `g_{i,j}(a)` 代入公式 `(1.2)` 以计算 `U_a` 中每个点与 `a` 之间的距离。
4. 输出所有距离值（距离越小，待学习的结果越接近）
