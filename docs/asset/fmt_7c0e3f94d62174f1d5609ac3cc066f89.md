
# 网格计算

网格计算通常利用设备当前不需要用于自身需求的闲置 CPU 周期，并将它们集中用于网格计算资源的目标。虽然来自每台单个计算机的这些少量闲置周期对整体任务可能意义不大，但汇总起来却非常可观。SETI@HOME 是网格计算的一个著名例子：它是“基于加州大学伯克利分校的一个科学实验，利用连接互联网的计算机搜寻地外文明（SETI）” [\[22\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0115)。

## 对等网络

*对等*（P2P）网络改变了经典的客户端/服务器计算机模型。根据数据需求，任何系统都可以充当客户端、服务器或两者兼有。与大多数技术一样，大多数 P2P 网络在设计上对知识产权保持中立。也就是说，P2P 网络经常被用来下载商业音乐和电影，往往侵犯了知识产权所有者的权利。去中心化的对等网络具有弹性：没有可以被下线的中心服务器。

最早的 P2P 系统之一是最初的 Napster，它于 1999 年首次亮相。它旨在允许音乐共享，并且是部分对等的：下载以 P2P 方式进行，但中央索引服务器（用户可在其中搜索特定歌曲、专辑和艺术家）采用经典的客户端/服务器设计。

这种设计为代表音乐产业的律师提供了一个阿喀琉斯之踵：如果中央索引服务器被关闭，用户将无法定位音乐。这正是 2001 年发生的事情。在此期间及之后设计的许多 P2P 协议（包括 Gnutella 和 BitTorrent）都是去中心化的。如果你有一个拥有 10,000 个系统的 Gnutella 网络，其中任何 1000 个下线，你现在就拥有一个拥有 9000 个系统的 Gnutella 网络。

除了知识产权问题，完整性是 P2P 网络的一个关键关注点。在没有中央数据存储库的情况下，用户有什么保证能接收到合法数据？加密哈希是一种关键控制措施，应用于验证从 P2P 网络下载的数据的完整性。

### 瘦客户端

*瘦客户端*比普通计算机系统更简单，不包含硬盘驱动器、完整操作系统、本地安装的应用程序等。它们依赖中央服务器，由中央服务器提供应用程序并存储相关数据。瘦客户端允许集中管理应用程序及其数据，以及升级、打补丁、数据存储等相关的安全成本。瘦客户端可以是基于硬件的（如无盘工作站）或基于软件的（如瘦客户端应用程序）。

#### 无盘工作站

*无盘工作站*（也称为无盘节点）包含 CPU、内存和固件，但没有硬盘驱动器。无盘设备包括 PC、路由器、嵌入式设备等。内核和操作系统通常通过网络加载。硬件 UNIX X 终端是无盘工作站的一个例子。

无盘工作站的 BIOS 开始正常的 POST 过程，加载 TCP/IP 协议栈，然后使用引导协议 (`BOOTP`) 或动态主机配置协议 (`DHCP`) 等协议下载内核和操作系统。`BOOTP` 过去常用于 UNIX 无盘工作站。`DHCP` 将在第 5 章，第 4 领域：通信和网络安全中讨论，它比 `BOOTP` 具有更多功能，提供额外的配置信息，如默认网关和 DNS 服务器。

#### 瘦客户端应用程序

*瘦客户端应用程序*通常运行在具有完整操作系统的系统上，但使用 Web 浏览器作为通用客户端，提供对从瘦客户端服务器下载并在浏览器中运行的健壮应用程序的访问。这与“胖”应用程序形成对比，“胖”应用程序存储在本地，通常伴有本地存储的数据，且有时具有复杂的网络需求。

瘦客户端可以简化客户端/服务器和网络架构及设计，提高性能，并降低成本。所有数据通常存储在瘦客户端服务器上。网络流量通常使用 HTTP（TCP 端口 80）和 HTTPS（TCP 端口 443）。客户端必须修补浏览器和操作系统以维护安全，但瘦客户端应用程序在服务器端打补丁。`Citrix ICA`、`2X ThinClientServer` 和 `OpenThinClient` 是瘦客户端应用程序的例子。

### 嵌入式系统和物联网

嵌入式系统是执行有限功能集的计算机，这与执行各种功能的通用系统（如运行 Windows 11 的台式计算机）不同。嵌入式系统的例子包括 HVAC（暖通空调）控制器、医疗设备（如心脏监护仪或静脉滴注泵）、ATM 和“智能”家电。“嵌入式”部分意味着它们显然不是计算机：一台“智能”洗碗机在外观上与不包含计算机的旧式机械洗碗机基本相同。

物联网 (IoT) 是指连接互联网的小型设备，如婴儿监视器、恒温器、收银机、家电、灯泡、智能电表、健身监测仪和汽车。许多此类设备通常可直接通过互联网访问。这些是联网的嵌入式系统。它们的风险更大，因为它们可能通过网络被攻破：非联网嵌入式设备需要物理访问才能被攻破。

你可能把“智能”电视当作一台电视（确实如此），但它很可能也在运行像 Linux 这样的服务器操作系统。这些设备可能带来重大安全风险：默认凭据很常见，企业管理工具通常缺失，甚至像打补丁这样简单的问题也可能很难（甚至不可能）解决。供应商通常发布基础操作系统补丁的速度相当慢，并且通常会终止对仍在广泛使用的设备的支持。

### 分布式系统和边缘计算系统

分布式系统将来自多个位置的计算机组合在一起，并将它们视为一个逻辑系统。例如：数百万人访问 `https://google.com` 似乎都在访问同一个系统，但实际上涉及数千台地理位置分布的服务器。STI Partners 定义分布式计算为：“分布式计算是指跨分布式计算频谱中的不同位置移动工作负载的能力。如下所示，这包括传统云（私有或公有）、边缘以及潜在的终端设备中的位置” [\[24\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0125)。

分布式计算使用一系列系统，从集中式基于云的系统到本地边缘系统（位于客户站点内或附近）。边缘计算是分布式计算的一个组成部分，旨在将数据推送到网络边缘（并更接近客户）。这允许更快的下载速度、低网络延迟，并可以利用本地 CPU 执行复杂计算（而不是将数据上传到中心位置进行处理）。内容分发网络 (CDN) 是边缘计算的早期形式，将在第 5 章，第 4 领域：通信和网络安全中讨论。

### 工业控制系统 (ICS)

工业控制系统 (ICS) 是发电、制造和自动化等行业使用的计算机。历史上，工业控制系统中使用的协议（如 `Modbus`）均为明文且相当不安全。这种风险曾因这些系统（过去）通常与互联网隔离，并依赖串行通信（很像调制解调器）在一个设施内进行通信而得到缓解。多年来，这种情况已发生相当大的变化，这些系统现在通常连接到互联网。以前使用串行线路的协议（如 `Modbus`）已更新为使用 `TCP/IP`（`Modbus TCP`）。不幸的是，`Modbus TCP` 是明文的，需要加密隧道才能安全传输。

Dong-Ho Kang、Byoung-Koo Kim、Jung-Chan Na 对 `Modbus` 进行了如下描述：*Modbus 中不存在安全要素。任何能够访问 Modbus 服务器的攻击者都能够读写现场设备，以及重启设备和运行诊断命令。Modbus 协议的简单性以及免费 Modbus 客户端的广泛可用性，使得攻击 Modbus 服务器变得相对简单* [\[25\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0130)。

#### 重要 ICS 术语

*   **数据采集与监视控制系统 (SCADA)：** SCADA（即数据采集与监视控制）系统是指一个由若干远程终端单元（或 RTU）组成的系统，这些单元采集现场数据并通过通信系统连接回主站。

*   **远程终端单元 (RTU)：** RTU（有时称为远程遥测单元）顾名思义，是一个独立的数据采集和控制单元，通常基于微处理器，用于监控和控制距离中央站较远位置的设备。

*   **分布式控制系统 (DCS)：** 在 DCS 中，数据采集和控制功能由若干基于微处理器的分布式单元执行，这些单元位于受控设备附近或采集数据的仪表附近 [\[26\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb261)。

*   **可编程逻辑控制器 (PLC)：** 一种小型、模块化的固态计算机，带有用于执行特定任务的定制指令。PLC 用于工业控制系统 (ICS) 的各种行业，已很大程度上取代了机械继电器、鼓式定序器和凸轮定时器 [\[27\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0135)。

# 系统漏洞、威胁和对策

系统威胁、漏洞和对策描述了安全架构和设计漏洞，以及可能危害系统安全的相应利用手段。我们还将讨论降低相关风险的对策或缓解措施。

## 电磁辐射

*电磁辐射* 是指从电子系统逸出的能量，在特定情况下可被远程监控。能量包括电磁干扰，将在本章后面讨论。

《Wired Magazine》在文章“解密的 NSA 文件揭示 TEMPEST 秘史”中讨论了电子辐射的发现：“那是 1943 年，一位贝尔电话工程师正在研究美国政府最敏感、最重要的战时机械之一——贝尔电话 131-B2 型……然后他注意到了一些奇怪的事情。实验室远处，一个独立的示波器养成了一个习惯：每当电传打字机加密一个字母，它就会尖峰一次。仔细检查后，这些尖峰可以转译为该机器正在处理的明文消息。尽管他当时可能并不知情，但这位工程师刚刚发现了所有信息处理机器都会将其秘密发送到电磁以太中” [\[28\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0140)。

基于这一发现，开发了 *TEMPEST*（并非首字母缩写，而是美国国家安全局的一个代号），作为一项屏蔽计算机设备电磁辐射的标准。

## 隐蔽信道

*隐蔽信道* 是指任何违反安全策略的通信。安装在系统上的恶意软件用于定位个人身份信息 (PII)（如信用卡信息）并将其发送到恶意服务器所使用的通信信道，就是隐蔽信道的一个例子。隐蔽信道有两种具体类型：*存储信道* 和 *时序信道*。

隐蔽信道的对立面是 *公开信道*：符合安全策略的授权通信。

### 隐蔽存储信道

存储信道示例使用共享存储（如临时目录）来允许两个主体相互发送信号。设想 Alice 是拥有最高机密许可的主体，而 Bob 是拥有机密许可的主体。Alice 拥有她想与 Bob 共享的最高机密信息，但强制访问控制 (MAC) 系统会阻止她这样做。

Bob 可以看到 Alice 临时文件的大小，但看不到内容。他们制定了一种代码：1 兆字节文件意味着战争迫在眉睫（标记为最高机密的数据），0 字节文件意味着“一切安全”。Alice 在临时目录中维护一个 0 字节文件，直到战争迫在眉睫时将其改为 1 兆字节文件，从而向 Bob 发送信号，违反了系统的 MAC 策略。

### 隐蔽时序信道

隐蔽时序信道依赖系统时钟来推断敏感信息。隐蔽时序信道的一个例子是不安全的登录系统。该系统配置为：如果用户输入正确的用户名但密码错误，或用户名和密码均错误，则提示“用户名或密码错误”。这样做是为了防止外部攻击者推断真实用户名。

我们这个不安全的系统在用户输入错误用户名/错误密码时会立即打印“用户名或密码错误”，但当用户输入正确用户名但密码错误时，会有轻微延迟（由于检查加密哈希所需的时间）。这种时序延迟允许攻击者推断哪些用户名是正确或错误的，违反了系统的安全设计。

#### 后门

*后门* 是系统中的一种捷径，允许用户绕过安全检查（如用户名/密码认证）进行登录。攻击者在攻破系统后通常会安装后门。例如，攻击者通过利用缺失补丁导致的漏洞获得系统的 Shell 访问权限。攻击者希望保持访问权限（即使系统打了补丁），因此她安装了一个后门以允许未来的访问。

*维护钩子* 是一种后门；它们是系统设计人员和程序员安装的捷径，旨在允许开发人员在开发期间绕过正常的系统检查，例如要求用户认证。如果维护钩子保留在生产系统中，就会成为安全问题。

## 恶意代码

*恶意代码* 或 *恶意软件* 是攻击应用程序或系统的任何类型软件的统称。恶意代码有多种类型；病毒、蠕虫、特洛伊木马和逻辑炸弹都可能对目标系统造成损害。

零日漏洞利用是指没有供应商提供的补丁的恶意代码（威胁）（意味着存在未修补的漏洞）。

### 计算机病毒

计算机病毒是不会自动传播的恶意软件：它们需要载体（通常是人）。它们经常通过软盘传播，以及（最近更多地）通过便携式 USB (通用串行总线) 内存传播。这些设备可能被物理携带并插入多台计算机。

病毒类型包括：

*   **宏病毒：** 使用宏语言编写的病毒（如 Microsoft Office 或 Microsoft Excel 宏）

*   **引导扇区病毒：** 感染 PC 引导扇区的病毒，确保病毒在系统启动时加载

### 恶意软件类型

*   **Stealth virus（隐形病毒）**：一种对操作系统和其他防护软件（如杀毒软件）隐藏自身的病毒。

*   **Polymorphic virus（多态病毒）**：一种在感染新系统时改变其签名的病毒，试图逃避基于签名的杀毒软件。

*   **Multipartite virus（多重病毒）**：一种通过多种传播媒介传播的病毒，也称为 multipart virus。

### Worms（蠕虫）

Worms 是能够自我传播（独立扩散）的恶意软件。“Worm”一词由 John Brunner 于 1975 年在科幻小说 *The Shockwave Rider* 中创造。Worms 通常通过两种方式造成破坏：一是它们携带的恶意代码；二是由于激进的自我传播导致网络可用性丧失。Worms 引发了历史上一些最具破坏性的网络攻击。

第一个大规模传播的蠕虫是 1988 年的 Morris worm，由 Robert Tappan Morris, Jr. 编写。此后出现了许多互联网蠕虫，包括 2003 年的 Blaster worm、2004 年的 Sasser worm、2008 年及以后的 Conficker worm 等。

### Trojans（特洛伊木马）

Trojan（也称为 Trojan horse）是一种执行双重功能的恶意软件：一种是良性功能（如游戏），另一种是恶意功能。该术语源自维吉尔史诗 *The Aeneid* 中描述的特洛伊木马。

### Rootkits（Rootkit/Rootkit 工具包）

Rootkit 是一种替换内核和/或操作系统部分组件的恶意软件。用户态 Rootkit 在大多数系统的 Ring 3 下运行，替换“用户空间”中的操作系统组件。常被 Rootkit 替换的二进制文件包括 Linux/UNIX 系统上的 `ls` 或 `ps` 命令，或 Microsoft Windows 系统上的 `dir` 或 `tasklist`。

内核态 Rootkit 替换内核，或加载恶意的可加载内核模块。内核态 Rootkit 在大多数操作系统的 Ring 0 下运行。

### Packers（加壳工具）

Packers 提供可执行文件的运行时压缩。原始 exe 被压缩，并将一个小型的可执行解压缩器添加到 exe 头部。执行时，解压缩器解包压缩的可执行机器码并运行它。

Packers 是一种中立技术，用于减小可执行文件体积。许多类型的恶意软件使用 Packers，可用于逃避基于签名的恶意软件检测。常见的 Packer 是 UPX (Ultimate Packer for eXecutables)，可在 [`upx.github.io/`](https://upx.github.io/) 获取。

### Logic Bombs（逻辑炸弹）

*Logic bomb* 是一种在满足逻辑条件时触发的恶意程序，例如处理一定数量的交易后，或在特定日期（也称为 time bomb/定时炸弹）。蠕虫等恶意软件通常包含逻辑炸弹，表现出一种行为，然后在特定日期和时间改变策略。

Roger Duronio 在因年度奖金纠纷心生不满后，成功针对其雇主 UBS PaineWebber 部署了逻辑炸弹。他在 2000 台 UBS PaineWebber 系统上安装了逻辑炸弹，由 2002 年 3 月 4 日上午 9:30 的日期和时间触发：“这一天，公司 2000 台服务器宕机，导致全国约 17,000 名经纪人无法进行交易。近 400 家分支机构受到影响。文件被删除。备份在运行几分钟内也宕机了” [\[29\]](#Ch004_107-223_B9780443187346000076_2.xhtml#bb0145)。

Duronio 的代码运行了命令 `/usr/sbin/mrm –r / &`（一个递归删除根分区（包括所有文件和子目录）的 UNIX shell 命令）。他被判处联邦监狱 8 年零 1 个月有期徒刑。

### Antivirus Software（杀毒软件）

Antivirus software 旨在预防和检测恶意软件感染。基于签名的杀毒软件使用已知恶意软件的静态签名。基于启发式的杀毒软件使用基于异常的检测，尝试识别恶意软件的行为特征，如修改引导扇区。

## Server-Side Attacks（服务端攻击）

*Server-side attacks*（也称为 service-side attacks/服务侧攻击）是从攻击者（客户端）直接发起针对监听服务的攻击。攻击过程如 Fig. 4.20 所示，`evil.example.com` 对监听在 TCP 445 端口的 `bank.example.com` 发起攻击。
