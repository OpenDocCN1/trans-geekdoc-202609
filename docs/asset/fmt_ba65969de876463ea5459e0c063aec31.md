子类型与其他变量之间表现出相关性，这使得在许多情况下无法平衡它们并使文本数量保持相似。我已经解释了为什么无法通过年代学来平衡子类型。我将在本章末尾讨论这一点，作者的性别情况也是如此的。这种“不希望的相关性”`Schö 2017a, 226`可以被看作是文学甚至是人文数据类别之间的一种内在现象。另一个与子类型显示出强关联的变量是作者，这一类别被绘制在图 15 的热图中，仅绘制了出现频率最高的五个标签。

统计学通常不是目标`Evans 1996, 14`，但在人文科学领域可能有所不同。在文学、艺术史、神学或哲学以及许多情况下包括语言学等领域，最常见的目标是分析较小的数据集不超过一百个案例，这些案例对文化产生了深远影响。样本将包含总体中的所有实例；换句话说，总体和样本是完全等的，因此研究人员可以在其数据中使用描述性统计学`Evans 1996, 25–26`。

对于 1880 年至 1939 年间的西班牙小说案例，我考虑的最大文本总体是 MdLE。我并不主张这个总体是同类作品中最大的。其他可能性可能意味着尝试获取至少在一部文学手册来自一个封闭列表中提到的所有小说，甚至是于 1880 年至 1939 年间由西班牙作者在西班牙出版的原创小说。这些可以被视为该时期最大的小说总体，尽管它们具有很高的研究价值，但对于博士论文来说，获取它们的成本太高了。因此，我使用我所能获取的最大的记录总体作为基础。

### 3.1.7 选择标准

### 3.1.8 数字化步骤

该语库使用 XML 编码如 `Percillier 2017` 建议，采用文本编码倡议 TEI，由 `Ajen 2015`；`Schöch 2017` 建议。从输入格式通常为 HTML 或类似格式到 TEI 的步骤通过 Python 脚本实现，主要使用正则表达式。在未找到标记的情况下，我使用了 Abbyy 公司的 OCR 软件 `FineReader` 和 `Recognition Service` 处理的 PDF 文档。它们被导出为 HTML 文件¹⁷，并接入了前述工作流的其他部分。

一旦 TEI XML 格式正确，`div` 元素将使用 `type` 属性进行编码，以区分内部的不同文本级别，其可能的值如下：

- section: 比章更小的单位¹⁸
- master: 文本最常见的划分每个文件中的必项¹⁹
- part: 比章更大的单位章的整体
- division: 部分的整体²⁰

将数字源的目录与 XML 文件的数字目录在 Oxygen XML Editor 软件中称为 `outlier` 进行对比，以控制文件在转换过程中是否丢失了文本段落。对于由项目数字化的文本，还对 PDF 进行了检查以避免错误并标记文本元素，如诗歌或浮动文本。
