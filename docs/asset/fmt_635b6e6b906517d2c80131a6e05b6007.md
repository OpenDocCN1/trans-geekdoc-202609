# Web 服务器与应用程序攻击

- 描述 Web 服务器和 Web 应用攻击

- 识别 Web 服务器和应用程序漏洞

- 识别 Web 应用黑客工具

1863 年春天，战场上正形成一种失衡。在弗雷德里克格堡战役获胜后，罗伯特·E·李将军和“石墙”杰克逊在弗吉尼亚州的钱纳尔斯斯维尔及周边聚集了约 6 万人的、规模庞大的南方联军。然而，约瑟夫·胡克少将指挥着一支约 13 万人的联邦军，并接到了林肯总统的直接命令，要消灭南方联军。因此，他根据当前的军事战略制定了一项行动计划，利用其优势远大的兵力向敌人进军。从任何角度来看，这都将是北方的一场大胜。

然而，李将军并非以遵守严格的战斗规则而闻名。当胡克集结兵力准备正面进攻时，李做了一件在当时是前所未有的事情：他将本就处于劣势的军队分为三组。他留下了区区的 1 万人迎击正面冲击，但将另外 5 万人分成两组，去包围并侧翼进攻联邦军。通过南方联军的一系列不可思议的胜利，以及北方对手完全犹豫且令人困惑的决策，这场战斗成为了一部关于在重逆境中获胜的教科书，同时也展示了战场上头脑与策略的力量。

你可能会问，这和我们有什么关系呢？通过改变攻击重心，李将军成功地取得了历史上最出人意料的军事胜利之一。在渗透测试中，你也可以这样做，将精力集中在目标强大的防御可能忽略的区域：他们的 Web 应用程序和服务器（是的，我知道这很老套，但请听我的没错吧）。企业和公司就像那支联邦军，针对你的防御层层层，看似无懈可击。但大多数可以通过它们面向公众的 Web 前端（这些前端可能包含也可能不包含适当的安全措施）以及定制的内部 Web 应用程序进行侧翼包。本章完全关于 Web 服务器和应用程序，以及你如何利用它们。毕竟，如果目标要信任它们，为什么不看一眼呢？

![Image](img/examp.jpg)

### 学习技巧

Web 服务器和应用程序黑客攻击占你考试内容的整 16%，因此显然值得你投入大量的学习精力。我希望告诉你们，背诵术语和关键词就足以通过这些问题，但现在情况已不再如此。ECC 想要确保你彻底了解 Web 服务器和应用程序，因此他们增加了题目的难度。某些题目将以场景的形式出现，你可能需要结合多个领域的知识来推导出正确答案。一些非常特定的问题甚至涉及脚本编写，看起来会非常困难；然而，如果你只需记住协议、端口和基础网络知识，你通常可以迎刃解。

熟悉你的攻击方法，包括 `CSRF`、`CPP`、`HTTP response splitting`，当然还有 `XSS`、`SQL injection` 和 `URL tampering`（以及其他所有）。确保在 `HTTP` 上花些时间并熟悉它。考试的另一个必知知识点是 `OWASP`——了解它是什么、它的作用，以及它的 Top 10 列表。

**A.** http-methods 脚本的使用语法为 `nmap --script http-methods <target>`，其中 `<target>` 是目标系统的 IP。根据 Nmap 的支持页面（[`nmap.org/nsedoc/scripts/http-methods.html`](https://nmap.org/nsedoc/scripts/http-methods.html)），此脚本“通过发送 OPTIONS 请求发现 HTTP 服务器支持的选项并列出潜在风险方法。它测试未在 OPTIONS 头中提到的方法并查看其是否被实现。除了 501/405 之外的任何输出都表示该方法不在 400 到 600 范围内。如果响应在该范围内，则将其与随机生成的方法的响应进行比较。在此脚本中，“潜在风险”方法是指除 GET、HEAD、POST 和 OPTIONS 之外的所有方法。”你还可以使用附加参数（如 `url-path`）来进一步优化结果。例如，上述语法显示 PUT 为风险方法的输出可能如下所示：
