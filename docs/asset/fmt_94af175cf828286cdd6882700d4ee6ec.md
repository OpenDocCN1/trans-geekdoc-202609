
&= -2\boldsymbol{p} + 2\boldsymbol{\Sigma}_x \boldsymbol{\theta} = \boldsymbol{0}

\end{aligned}

$$

或写作：

![Equation](img/fx001.jpg) \tag{4.5}

其中输入-输出互相关向量 $\boldsymbol{p}$ 由下式给出（脚注 17）：

$$\boldsymbol{p} = \left[ \mathbb{E}[x_1 y], \dots, \mathbb{E}[x_l y] \right]^T = \mathbb{E}[\boldsymbol{x} y] \tag{4.6}$$

相应的协方差矩阵由下式给出：

$$\boldsymbol{\Sigma}[\boldsymbol{x}] = \mathbb{E} [\boldsymbol{x} \boldsymbol{x}^T].$$

![Equation](img/si14.png)

因此，最优线性估计器的权重/参数是通过一个线性方程组获得的，前提是协方差矩阵是*正定*的，因此它可以被求逆（附录 A）。此外，在这种情况下，解是*唯一*的。相反，如果 $\boldsymbol{\Sigma}[\boldsymbol{x}]$ 是奇异的，因此无法求逆，则存在无穷多解（问题 4.1）。

详述如公式 (4.2) 所定义的代价函数 $J(\boldsymbol{\theta})$，我们得到

$$J(\boldsymbol{\theta}) = \sigma[y]^2 - 2\boldsymbol{\theta}^T\boldsymbol{p} + \boldsymbol{\theta}^T\boldsymbol{\Sigma}[\boldsymbol{x}]\boldsymbol{\theta}.$$

![Equation](img/si16.png)(4.7)

加上并减去项 $\boldsymbol{\theta}_*^T\boldsymbol{\Sigma}[\boldsymbol{x}]\boldsymbol{\theta}_*$ 并考虑到公式 (4.5) 中 $\boldsymbol{\theta}_*$ 的定义，很容易看出

![Equation](img/fx002.jpg)(4.8)

其中

$$J(\boldsymbol{\theta}_*) = \sigma[y]^2 - \boldsymbol{p}^T\boldsymbol{\Sigma}[\boldsymbol{x}]^{-1}\boldsymbol{p} = \sigma[y]^2 - \boldsymbol{\theta}_*^T\boldsymbol{\Sigma}[\boldsymbol{x}]\boldsymbol{\theta}_* = \sigma[y]^2 - \boldsymbol{p}^T\boldsymbol{\theta}_*.$$

![Equation](img/si19.png)(4.9)

是在最优解处达到的最小值。从公式 (4.8) 和 (4.9) 可以得出以下备注。

**备注 4.1**

*   最优值 $\boldsymbol{\theta}_*$ 处的代价总是小于输出变量的方差 $\mathbb{E}[y^2]$。这由 $\boldsymbol{\Sigma}[\boldsymbol{x}]$ 或 $\boldsymbol{\Sigma}[\boldsymbol{x}]^{-1}$ 的正定性质保证，这使得公式 (4.9) 右边的第二项总是正的，除非 $\boldsymbol{p} = 0$；然而，互相关向量只有在 $\boldsymbol{x}$ 和 $y$ 不相关时才为零。在这种情况下，至少就 MSE 准则而言，人们无法通过观察 $\boldsymbol{x}$ 的样本来对 $y$ 做出任何预测，因为 MSE 准则涉及的信息仅限于二阶统计量。在这种情况下，误差方差（与 $J(\boldsymbol{\theta}_*)$ 重合）将等于方差 $\sigma[y]^2$；后者是 $y$ 围绕其（零）均值的“内在”不确定性的度量。相反，如果输入-输出变量相关，那么观察 $\boldsymbol{x}$ 就能消除与 $y$ 相关的部分不确定性。

*   对于除最优 $\boldsymbol{\theta}_*$ 以外的任何 $\boldsymbol{\theta}$ 值，误差方差都会增加，正如公式 (4.8) 所暗示的那样，这是由于 $\boldsymbol{\Sigma}[\boldsymbol{x}]$ 的正定性质。图 4.1 展示了由公式 (4.8) 中的 $J(\boldsymbol{\theta})$ 定义的代价函数（MSE）曲面。对应的等值轮廓线如 图 4.2 所示。通常情况下，它们是椭圆，其轴由 $\boldsymbol{\Sigma}[\boldsymbol{x}]$ 的特征结构决定。对于 $\boldsymbol{\Sigma}[\boldsymbol{x}] = \sigma^2\boldsymbol{I}$，其中所有特征值都等于 $\sigma^2$，轮廓线为圆（问题 4.3）。

## 4.3 几何视角：正交性条件

对上述内容的一个非常直观的理解来自于随机变量的几何解释。读者可以很容易地验证，随机变量的集合在实数（和复数）域上构成一个*线性空间*。确实，如果 $x$ 和 $y$ 是任意两个随机变量，那么对于每个 $\alpha \in \mathbb{R}$，$x + y$ 以及 $\alpha x$ 也是随机变量。^(¹⁸)

### 内积性质

*   **对称性**：$\mathbb{E}[xy] = \mathbb{E}[yx]$
*   **线性性**：$\mathbb{E}[(\alpha_1 x_1 + \alpha_2 x_2)y] = \alpha_1 \mathbb{E}[x_1 y] + \alpha_2 \mathbb{E}[x_2 y]$
*   **正定性**：$\mathbb{E}[x^2] \ge 0$，等号成立当且仅当 $x = 0$。

由此该内积诱导的范数为：

$$

\| x \| := \sqrt{\mathbb{E}[x^2]},

$$

它与标准差一致（假设 $\mathbb{E}[x] = 0$）。

从现在起，给定两个不相关的随机变量 $x, y$（即 $\mathbb{E}[xy] = 0$），我们称它们为**正交**，因为它们的内积为零。我们现在可以将正交性定理应用于我们感兴趣的任务，该定理源自我们熟悉的有限维（欧几里得）线性（向量）空间。

现在让我们重写方程 (4.1) 为：

$$

\hat{y} = \theta_1 x_1 + \dots + \theta_l x_l.

$$

因此，随机变量 $\hat{y}$（现解释为向量空间中的一个点）是该空间中 $l$ 个元素的线性组合。因此，变量 $\hat{y}$ 必然位于由这些点张成的子空间中。相反，真实变量 $y$ 通常不位于该子空间中。因为我们的目标是获得一个能很好地近似 $y$ 的 $\hat{y}$，我们必须寻找使误差范数 $e = y - \hat{y}$ 最小的特定线性组合。这种特定的线性组合对应于 $y$ 向由点 $x_1, x_2, \dots, x_l$ 张成的子空间上的**正交**投影。这等价于要求

```
𝔼[(y - Σᵢ₌₁ˡ θᵢ xᵢ) xₖ] = 0,  k = 1,2,…,l
```

(4.10)

误差变量与每个点 $x_k$（$k = 1, 2, \dots, l$）正交，因此将正交于相应的子空间。这在图 4.3 中说明。这种选择保证了由此产生的误差具有最小范数；根据范数的定义，这对应于最小均方误差（MSE），即最小 $\mathbb{E}[e^2]$。

![图 4.3 将 y 投影到由 x₁, x₂ 张成的子空间（阴影平面）上，保证 y 和 ŷ 之间的偏差对应于最小 MSE。](img/gr003.jpg)

图 4.3 将 $y$ 投影到由 $x_1, x_2$ 张成的子空间（阴影平面）上，保证 $y$ 和 $\hat{y}$ 之间的偏差对应于最小 MSE。

(4.10) 中的方程组现在可以写为

```
𝔼 [ (y - Σᵢ₌₁ˡ θᵢ xᵢ) xₖ ] = 0,  k = 1,2,…,l
```

或

```
Σᵢ₌₁ˡ 𝔼[xᵢ xₖ] θᵢ = 𝔼[xₖ y],  k = 1,2,…,l
```

(4.11)

这导出了方程 (4.5)。

这就是这组优雅方程被称为**正规方程**的原因。另一个名称是**维纳-霍普夫方程**。严格来说，维纳-霍普夫方程最初是在因果估计任务的背景下为连续时间过程推导的 [49,50]；关于讨论请参见 [16,44]。

**诺伯特·维纳**（1894–1964）是一位数学家和哲学家。他在 17 岁时获得哈佛大学数理逻辑博士学位。第二次世界大战期间，他在一项机密工作中独立于柯尔莫哥洛夫奠定了线性估计理论的基础。后来，维纳参与了自动化、人工智能和认知科学领域的开创性工作。作为一名和平主义者，他在冷战时期备受猜疑。

### 备注 4.2

*   迄今为止，在我们的理论发现中，我们假设 $\boldsymbol{x}$ 和 $y$ 是联合分布（相关）的变量。如果此外我们假设它们根据线性回归模型呈线性关系，

    $\boldsymbol{\theta}_* = \boldsymbol{\theta}_o^1$

    其中

    ```

    ```

*   换句话说，最小均方误差估计器识别出 $\boldsymbol{\theta}_o$ 的前 $l$ 个分量。

## 4.4 复值变量的推广

迄今所述一切均可推广至复值变量。然而，这涉及一些微妙之处，这也是我们选择单独处理该情况的原因。复值变量在许多应用中非常常见，例如在通信领域，如文献 [41] 所示。

给定两个实值变量 $(x, y)$，既可以将它们视为二维空间中的矢量量 $[x, y]^T$，也可以将它们描述为一个复变量 $z = x + jy$，其中 $j^2 := -1$。采用后一种方法的好处是可以利用复数域 $\mathbb{C}$ 中可用的运算，即乘法和除法。此类运算的存在极大地便利了代数操作。回顾一下，在矢量空间中并未定义此类运算。^(¹⁹)

假设我们有一个复值（输出）随机变量

$$y := y_r + jy_i \tag{4.13}$$

和一个复值（输入）随机矢量

$$\boldsymbol{x} = \boldsymbol{x}_r + j\boldsymbol{x}_i. \tag{4.14}$$

量 $y_r, y_i, \boldsymbol{x}_r$ 和 $\boldsymbol{x}_i$ 均为实值随机变量/矢量。目标是计算一个由复值参数矢量 $\boldsymbol{\theta} = \boldsymbol{\theta}_r + j\boldsymbol{\theta}_i \in \mathbb{C}^l$ 定义的线性估计器，以最小化相应的 MSE，

$$\mathbb{E}[|e|^2] := \mathbb{E}[ee^*] = \mathbb{E}[|y - \boldsymbol{\theta}^H \boldsymbol{x}|^2]. \tag{4.15}$$

观察公式 (4.15)，不难发现，在复变量的情况下，两个复值随机变量之间的内积运算应定义为 $\mathbb{E}[xy^*]$，以保证由内积隐含的范数 $\| x \| = \sqrt{\mathbb{E}[xx^*]}$ 是一个有效量。应用与之前相同的正交条件，我们重新推导出如公式 (4.11) 所示的正规方程，

$$\boldsymbol{\Sigma}_x \boldsymbol{\theta}^* = \boldsymbol{p},$$

![Equation](img/si71.png) (4.16)

其中协方差矩阵和互相关向量现在由下式给出

$$\boldsymbol{\Sigma}[\boldsymbol{x}] = \mathbb{E} [\boldsymbol{x}\boldsymbol{x}^H],$$

![Equation](img/si72.png) (4.17)

$$\boldsymbol{p} = \mathbb{E} [\boldsymbol{x}y^*],$$

![Equation](img/si73.png) (4.18)

注意，式 (4.16)–(4.18) 也可以通过最小化式 (4.15) 得到（问题 4.6）。此外，式 (4.9) 的对应式由下式给出

$$J(\boldsymbol{\theta}_*) = \sigma[y]^2 - \boldsymbol{p}^H\boldsymbol{\Sigma}[\boldsymbol{x}]^{-1}\boldsymbol{p} = \sigma[y]^2 - \boldsymbol{p}^H\boldsymbol{\theta}_*.$$

![Equation](img/si74.png) (4.19)

利用式 (4.13) 和 (4.14) 中的定义，式 (4.15) 中的代价函数可写为

$$J(\boldsymbol{\theta}) = \mathbb{E}[|e|^2] = \mathbb{E}[|y - \hat{y}|^2] = \mathbb{E}[|y_r - \hat{y}_r|^2] + \mathbb{E}[|y_i - \hat{y}_i|^2],$$

![Equation](img/si76.png)(4.22)

公式 (4.22) 揭示了复数符号背后的真实含义；即其*多通道*性质。在多通道估计中，我们被给予不止一组输入变量，即 $\boldsymbol{x}_r$ 和 $\boldsymbol{x}_i$，并且我们希望联合生成不止一个输出变量，即 $\hat{y}_r$ 和 $\hat{y}_i$。公式 (4.22) 可以等价地写为

$$
