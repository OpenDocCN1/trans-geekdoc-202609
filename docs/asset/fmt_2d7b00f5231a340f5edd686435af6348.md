## 11.4 Cover 定理：线性二分法中空间的容量

我们已经通过逼近理论的论证，证明了用一组固定的非线性函数来展开未知非线性函数的方法是合理的。尽管该框架完美契合回归任务（输出取值于区间 $\mathbb{R}$），但这些论证并不适合分类任务。在后一种情况下，输出值具有离散性质。例如，在二分类任务中，$y \in \{1, -1\}$，只要预测值 $\hat{y}$ 的符号正确，我们并不关心 $y$ 和 $\hat{y}$ 有多接近。在本节中，我们将介绍一个优雅而强有力的定理，它证明了以公式 (11.1) 的形式展开分类器 $f$ 是合理的。只需从另一个角度审视公式 (11.1) 即可。

考虑 $N$ 个点，$\mathbf{x}[1], \mathbf{x}[2], \dots, \mathbf{x}[N] \in \mathbb{R}^{(l)}$。如果这 $N$ 个点中**不存在** $l+1$ 个点位于同一个 $(l-1)$ 维超平面上，则称这些点处于**一般位置**。例如，在二维空间中，任意三个点不允许共线。

### 定理 11.1

**Cover 定理**

记 $\mathcal{O}(N, l)$ 为利用所有可能的组合，由 $(l-1)$ 维超平面将 $N$ 个点分为两类所能形成的分组数量，其值由下式给出（参见 [31] 和问题 11.1）：

$$

\mathcal{O}(N,l) = 2\sum\limits_{i = 0}^{l}\begin{pmatrix} {N - 1} \\ i \\ \end{pmatrix},

$$

其中

$$

\begin{pmatrix} {N - 1} \\ i \\ \end{pmatrix} = \frac{(N - 1)!}{(N - 1 - i)!i!}.

$$

将点分成两类的每一种分组也称为（线性）*二分法*。图 11.3 说明了 *N* = 4 个点在二维空间中的情况。观察可能的分组有 [(ABCD)]、[A, (BCD)]、[B, (ACD)]、[C, (ABD)]、[D, (ABC)]、[(AB), (CD)] 和 [(AC), (BD)]。每个分组被计算两次，因为它可以属于 *ω*₁ 类或 *ω*₂ 类。因此，分组总数为 14，等于 𝒪(4, 2)。注意，*N* 个点分成两组的所有可能组合数为 2^*N*，在本例中为 16。未计入 𝒪(4, 2) 的分组是 [(BC), (AD)]，因为它不能被线性分离。注意，如果 *N* ≤ *l* + 1，则 𝒪(*N*, *l*) = 2^*N*。即所有可能的两类组合都是线性可分的；在二维空间中验证 *N* = 3 的情况。

图 11.3 四个点在二维空间中线性可分的两类分组数为 𝒪(4, 2) = 14 = 2 × 7。

根据前面的定理，给定 *l* 维空间中的 *N* 个点，将这些点分成两个*线性*可分类的概率为

![Equation](img/fx001.jpg)(11.6)

为了直观展示这一发现，令 *N* = *r*(*l* + 1)，并用 *r* 表示概率 *P*_N^(*l*)，其中 *l* 取固定值。结果图如图 11.4 所示。观察到有两个不同的区域。一个在点 *r* = 2 的左侧，一个在右侧。在点 *r* = 2 处，即 *N* = 2(*l* + 1)，概率始终为 1/2，因为 𝒪(2*l* + 2, *l*) = 2^(2*l* + 1)（问题 11.2）。注意，*l* 的值越大，从一个区域到另一个区域的过渡就越陡峭。因此，对于高维空间，只要 *N* < 2(*l* + 1)，将点分成两类的任意分组*线性可分*的概率趋于 1。

## 11.5 再生核希尔伯特空间

考虑定义在集合^(⁶⁹) 上的实值函数的线性空间 ℍ

### 定义 11.1

如果存在一个**核**函数

*κ* : 𝒳 × 𝒳 ↦ ℝ

具有以下性质，则希尔伯特空间 ℍ 称为**再生核希尔伯特空间**（RKHS）：

*   对于每个 **x** ∈ 𝒳，*κ*(⋅, **x**) 属于 ℍ；
*   *κ*(⋅, ⋅) 具有所谓的**再生性质**，即

![Equation](img/fx002.jpg) (11.8)

用文字来说，核函数是一个包含两个参数的函数。将其中一个参数的值固定为，比如说 `x ∈ 𝒳`，那么核就变成了一个单参数函数（与点 `⋅` 相关联），且该函数属于 `ℍ`。再现性质意味着 `ℍ` 中任意函数 `f ∈ ℍ` 在任意 `x ∈ 𝒳` 处的值，等于 `f` 与 `κ(⋅, x)` 在 `ℍ` 中进行的相应内积。

再现性质的一个直接推论是，如果我们令 `f(⋅) = κ(⋅, y), y ∈ 𝒳`，则有

```
⟨κ(⋅, y), κ(⋅, x)⟩ = κ(x, y) = κ(y, x).
```

**定义 11.2**

设 `ℍ` 为一个 RKHS，其对应的核函数为 `κ(⋅, ⋅)`，`𝒳` 为一个元素集合。则映射

![Equation](img/fx003.jpg)

被称为*特征映射*，空间 `ℍ` 被称为*特征空间*。

换句话说，如果 `𝒳` 是我们的观测向量集合，特征映射将每个向量映射到 RKHS `ℍ`。注意，一般来说，`ℍ` 可以是无限维的，且其元素是函数。也就是说，每个训练点都被映射为一个函数。在 `ℍ` 为有限维 `K` 的特殊情况下，其像可以表示为等价向量 `ϕ(x) ∈ ℝ^(K)`。从现在起，将处理一般的无限维情况，并将像表示为函数 `ϕ(⋅)`。

现在让我们看看，选择将特征映射从原始空间执行到高维 RKHS 中，我们获得了什么。设 `x, y ∈ 𝒳 ⊆ ℝ^(l)`。则相应映射像的内积写为

```
⟨ϕ(x), ϕ(y)⟩ = ⟨κ(⋅, x), κ(⋅, y)⟩,
```

![Equation](img/si92.png)

或

![Equation](img/fx004.jpg)

换句话说，在我们的问题中采用这种类型的映射，我们可以通过在原始低维空间中进行函数求值，以一种非常高效的方式在 `ℍ` 中执行内积运算！这一性质也被称为*核技巧*，它极大地简化了计算。正如稍后将变得明显的那样，在实践中利用这一性质的方式涉及以下步骤：

1.  （隐式地）将输入训练数据映射到一个 RKHS

**x**[*n*] ↦ *ϕ*(**x**[*n*]) ∈ ℍ, *n* = 1, 2, …, *N*.

![Equation](img/si93.png)

2.  在 ℍ 中求解一个涉及像 *ϕ*(**x**[*n*])、*n* = 1, 2, …, *N* 的*线性*估计任务。

3.  将求解未知参数的算法表示为以下形式的内积运算：

⟨*ϕ*(**x**[*i*]), *ϕ*(**x**[*j*])⟩, *i*, *j* = 1, 2, …, *N*.

![Equation](img/si96.png)

4.  用核函数计算替换每一个内积，即：

⟨*ϕ*(**x**[*i*]), *ϕ*(**x**[*j*])⟩ = *κ*(**x**[*i*], **x**[*j*]).

![Equation](img/si97.png)

显然，不需要对数据执行任何显式映射。只需在最后一步执行核运算即可。请注意，*κ*(⋅, ⋅) 的具体形式不影响分析。一旦推导出用于预测 *ŷ* 的算法，就可以为 *κ*(⋅, ⋅) 使用不同的选择。正如我们将看到的，*κ*(⋅, ⋅) 的不同选择对应于不同类型的非线性。图 11.6 说明了该过程背后的基本原理。在实践中，上述列出的四个步骤等同于 (a) 在原始（低维欧几里得）空间中工作，并用内积表示所有运算，以及 (b) 在最后一步用核函数计算替换内积。
