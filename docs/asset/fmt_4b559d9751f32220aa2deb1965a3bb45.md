
# 常量

常量使用 `const` 关键字声明，作用域与变量相同。运行时常量不可修改。常量类型包括数字、字符（rune）、字符串、布尔值。（关于 rune 详见参考资料 5）。示例：

```go
const str string = "const string"

const (
	_ = iota
	one
	two
	three
)

func main() {
	println(str)       // string
	// str = "new string" // 编译错误：cannot assign to str
	println(one)   // 1
	println(two)   // 2
	println(three) // 3
}
```

首先，声明常量字符串很直观。示例中显式写了 `string` 类型，其实可省略。

其次是 `iota` 示例。`iota` 是 Go 中的常量生成器，初始值为 0，每行递增 1，常用于声明枚举常量，保持代码可读性。

### 包

Go 中的包是将程序划分为较小部分的一种方式。Go 编译器附带了几个广泛通用且流行的标准包。这些包包括 `fmt`、`log`、`net`、`strconv`、`strings`、`sync`、`testing`、`os`、`math`、`errors` 等。

我们可以在 [`pkg.go.dev/`](https://pkg.go.dev/) 探索所有可公开使用的 Go 包。

正如 Hello World 简介中提到的，我们在文件开头使用 `import` 关键字导入包。此外，我们还可以选择重命名包，如下所示：

```go
import (
	f "fmt"
	"math"
)
```

我们将 `fmt` 重命名为 `f`。Go 中包的命名约定是简短的，主要为单个单词（如名词）。除了 a-z 和数字外，包名称中唯一可用的字符是 `_`。

Go 中的命名对于包外部的访问或查看至关重要。它由变量的首字符是否为大写决定（函数、常量、结构体等同理）。

```go
const myName = "jack" // 不公开
const MyName = "jack" // 公开
```

要开展项目工作，我们需要初始化一个新模块。为此，我们需要运行类似以下的命令：

```bash
go mod init github.com/nir/mymodule
```

它将创建一个名为 `go.mod` 的新文件，其中包含模块名称、Go 版本、整个包以及我们在该模块中使用的版本。

在声明我们想要使用的模块后，`go.mod` 文件应如下所示：

```go
module github.com/OrangeAVA/Microservices-with-Go

go 1.21.0

require (
	github.com/gin-gonic/gin v1.9.0
)
```

要下载包，我们应该运行：

```bash
go mod download
```

它将创建/更新一个名为 `go.sum` 的文件，该文件维护项目中使用的依赖项的校验和。`go.sum` 文件确保项目在后续构建中使用完全相同版本的依赖项，从而提高构建过程的可重现性和安全性。我们无需更改或编辑此文件，因为它由 Go 工具链自动生成。

有时，我们可能会在包需求后遇到 `// indirect`。当我们在项目中不直接使用该模块，但我们的某个依赖项依赖它时，就会发生这种情况。

一个方便的命令可以帮助我们仅包含所需的导入：

```bash
go mod tidy
```

此命令会移除所有我们未使用的依赖项。

关于项目结构有许多实践和用例。我们将详细阐述重要的几种。更详细的文件结构见参考资料。以下是 Go 项目标准的关键文件和目录树。

正如我们之前所见，启动 Go 项目必须拥有 `go.mod` 和 `go.sum` 文件。除了这些文件外，还有三个关键目录：`cmd`、`internal` 和 `pkg`。

*   **`cmd` 目录** - 包含我所有代码的入口点，每个程序的目录名称应与二进制文件的名称匹配。
*   **`pkg` 目录** - 需要包含所有可以与其他服务共享的代码。这应包含对其他服务有用的通用代码。请注意，当我们使用单体仓库工作时，通常所有服务只有一个 `pkg` 目录，并且每个服务内部没有 `pkg` 目录。
*   **`internal` 目录** - 服务内部使用的私有包。

### 结构体

Go 的结构体是字段的类型化集合。Go 中的结构体用于创建记录。

以下是我们在 Go 中声明结构体的方式：

```go
type user struct {
	name  string
	email string
}
```

声明结构体时，我们只能声明结构体字段。创建结构体的另一种方式是通过嵌入结构体：

```go
type admin struct {
	user
	level string
}
```

这里，我们将 `user` 结构体嵌入到 `admin` 结构体中。要创建结构体的新实例，我们需要声明它并包含其参数；如果缺少某个参数，将赋予该参数的默认值。

```go
u1 := user{
	name:  "john",
	email: "john@gmail.com",
}
fmt.Printf("%+v\n", u1) // {name:john email:john@gmail.com}
```

Go 中没有用于创建结构体的内置构造函数。Go 中创建结构体的约定是通过函数，如果该函数是公开的，则应具有 `new` 或 `New` 前缀，例如：

```go
func newUser(name string) user {
	return user{
		name:  name,
		email: fmt.Sprintf("%s@gmail.com", name),
	}
}

u2 := newUser("jack")
fmt.Printf("%+v\n", u2) // {name:jack email:jack@gmail.com}
```

我们声明了一个名为 `newUser` 的函数，它仅接受 `name`，并由此生成 email。我们可以使用任何我们认为合适的功能。让我们看一个声明嵌入结构体的示例：

```go
a := admin{
	user: user{
		name:  "john",
		email: "john@gmail.com",
	},
	level: "super",
}
fmt.Printf("%+v\n", a) // {user:{name:john email:john@gmail.com} level:super}
```

要访问/修改结构体实例的值，我们可以这样做：

```go
u3 := newUser("amanda")
fmt.Printf("%+v\n", u3) // {name:amanda email:amanda@gmail.com}
fmt.Println(u3.name)    // amanda - 我们访问 user 结构体的 name 字段
u3.name = "ruth"        // 我们更改 user 结构体 name 字段的值
fmt.Printf("%+v\n", u3) // {name:ruth email:amanda@gmail.com}
```

Go 支持在结构体类型上定义方法。这意味着我们在与结构体相同的作用域内声明函数并将其分配给结构体。让我们看一个例子：

```go
func (u user) Print() {
	fmt.Printf("Name: %s, Email: %s\n", u.name, u.email)
}
```

我们在与 `user` 结构体相同的作用域内声明了 `Print` 方法。请注意，此示例是作为值接收者的结构体方法。我们也可以将方法定义为结构体的指针接收者，以便该方法可以修改结构体字段。例如：

```go
func (u *user) ChangeEmail(email string) {
	u.email = email
}
```

### 组合

组合让我们通过组合更简单的部分来创建复杂的事物，使我们的代码更加模块化和灵活。Go 中不存在继承特性。让我们观察一个组合的例子：

```go
type Animal struct {
	Sound string
}

func (a *Animal) Speak() {
	println(a.Sound)
}

type Cat struct {
	Animal // 嵌入
}

type Dog struct {
	Animal // 嵌入
}

func main() {
	cat := Cat{Animal{"Meow"}}
	cat.Speak() // Meow
	dog := Dog{Animal{"Woof"}}
	dog.Speak() // Woof
}
```

我们实现了一个带有 `Speak` 方法的 `Animal` 结构体。我们还创建了两个不同的结构体 `Cat` 和 `Dog`，它们都嵌入了 `Animal` 结构体。通过这样做，这些结构体继承了 `Animal` 结构体的所有属性和方法。

### 接口

Go 中的接口与其他语言略有不同。在 Go 中，接口仅包含方法签名，不包含字段。我们无法在 Go 中创建接口实例，但可以声明一个变量，将其赋值为满足接口方法签名的某个类型。让我们看看下面的例子：

```go
type Person struct {
	Name string
}

func (m Person) Print() {
	fmt.Println(m.Name)
}

type DogPerson struct {
	Name string
}

type PrintInterface interface {
	Print()
}

var PrintableObject PrintInterface = Person{}
var PrintableObject2 PrintInterface = DogPerson{} // 这将在编译时抛出错误
```

我们声明了一个名为 `PrintInterface` 的接口，包含 `Print()` 签名。当我们声明 `PrintableObject` 时，这是可行的，因为 `Person` 结构体实现了 `Print` 方法。另一方面，当我们尝试声明 `PrintableObject2` 时，会导致编译错误，因为 `DogPerson` 结构体不满足 `PrintInterface` 接口。

Go 语言中一个至关重要且广泛使用的接口是“空接口”。“空接口”是一种指定零个方法的类型，如下所示：`interface{}`

```go
var i interface{}
```

或者

```go
var myName interface{}
```

空接口之所以独特，是因为它可以容纳任何类型的值（每种类型至少实现了 0 个方法）。其主要用途是处理未知情况，我们将在本书中多次遇到此类情况。

### 函数选项模式

之所以决定专门关注此模式而非其他设计模式，主要有两个原因。第一个原因是，此设计模式在 Go 语言环境中相对独特，也是我们能想到的最常用的设计模式之一（也许单例模式或适配器模式更流行）。

该模式有助于清晰、精确地构建 `struct`。这是因为 Go 不支持重载（重载会创建同名但签名不同的函数）。此外，Go 的函数中没有可选参数。

这两个事实（不支持重载和可选参数）会使构建 `struct` 变得非常困难。构建结构体时，如果有许多配置（通常表示为可选参数），代码会变得一团糟。函数选项模式允许我们创建一个单一的结构体构造函数，它接收必需参数和一个可选参数列表。使用此模式的步骤如下：

1.  创建你想要的 `struct`。
2.  创建一个类型，其名称为结构体名称加上 `Option` 后缀（`{structName}Option`），定义为 `func(*{structName})`。
3.  创建构造函数 `New{structName}`，包含必需参数，并添加 `options …{structName}Option`，返回 `*{structName}`。
4.  为每个选项创建一个自定义函数。惯例是用 `With` 作为前缀命名这些函数。

让我们通过示例说明这些步骤；我们创建了一个购物客户端结构体，如下所示：

```go
type ShoppingClient struct {
    endpoint    string
    apiKey      string
    userId      string
    shouldRetry bool
    timeout     time.Duration
}
```

第二步是创建选项类型：

```go
type ShoppingClientOption func(*ShoppingClient)
```

现在，我们可以编写构造函数，如下所示：

```go
func NewShoppingClient(endpoint string, options ...ShoppingClientOption) *ShoppingClient {
    client := &ShoppingClient{
        endpoint: endpoint,
    }
    for _, option := range options {
        option(client)
    }
    return client
}
```

请注意，如果我们不提供任何选项，字段将获得其默认值，除了 `endpoint`（这是必需字段）。剩下的就是创建选项函数。
