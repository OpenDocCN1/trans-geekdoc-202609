
具有`k`个值的特征`X[j]`将示例集`X`划分为`k`个子集`X[1], ..., X[k]`。对于实值特征，数值被划分为若干区间，以便这些区间与离散特征一起处理。二叉决策树总是分裂为左、右两个分支。对于数值，使用阈值`t`即`x[j] ≤ t`。根据诸如信息增益之类的质量准则选择最佳特征`X[j]`或最佳阈值`t`：

```
Gain(X[j]) = I(X) - Σ (|X[i]| / |X|) * I(X[i])
```

信息增益是按`X[j]`分割前后示例熵的差值。它是针对每个子树处的特定示例集计算的。

信息增益越高，特征离根节点越近。从这个意义上说，树中的位置似乎表明了特征重要性。然而，选定特征的顺序*不是*精确的特征加权算法。特别是，树路径上的相关特征不共享重要性，而是将其相加。因此，它们违反了备选特征权重之和必须为常数的条件，该常数与实际使用的备选特征数量无关。这一条件很重要，因为它保证了一组备选特征并不比单个特征更重要[271]。

决策树学习器对样本到达的顺序不具备鲁棒性。因此，在其原始形式下，它们不适用于数据流。针对数据流场景，引入了`VeryFastDecisionTree`(VFDT)方法[146]。它们很高效，因为运行时间与特征数量成正比；此外，流的样本不被存储，而是仅被处理一次。开始时，会在节点处保留一部分观测样本。对这些样本评估分裂标准。要求排名靠前的特征之间的差异大于某个*ϵ*。继续读取额外样本并评估分裂标准，直到达到Hoeffding界。从那时起，节点处仅存储聚合统计量。Hoeffding界保证独立随机变量的和或差极不可能偏离期望值超过一个常数。这里它表明：以概率1−*δ*，在看到*n*个样本后，评估值（如信息增益）比次优特征大*ϵ*的特征，确实也是未来样本的最佳分裂标准。*ϵ*可按如下方式计算：

### 3.4.2 实现与硬件考量

决策树及其集成具有如上所述的统计或PAC学习描述。这一抽象层面由算法挑战及其在各种硬件上的实现来补充。最高性能由`gradient-boosted trees`实现。实现`XGBoost`是一种真正可扩展的算法，它使用外部内存，并利用梯度下降优化（参见3.2.1节）在GPU上并行处理训练[119]。

其他方法优化学习模型的应用或评估。如果训练可能在大型计算中心运行，但学习模型要应用于物理实验的实际环境中（如`Cherenkov Telescope Array`(CTA)或`IceCube`），这尤为重要。模型的执行在运行时间和内存方面均受限。针对快速推理，已开发出大型决策树集成的遍历方法[242]。为了优化数据布局并增强缓存使用，已开发出执行决策树的概率视角[107]。该改进基于系统地使用树使用统计量。研究了决策树的两种不同实现，即优化的if-then-else树和优化的路径布局。这些实现能更好地利用计算架构，应考虑用于资源受限的实时应用。第1卷的7.3.3节提供了更多信息，并解释了如何为特定计算架构生成优化代码。

机器学习模型通常会经过压缩或量化，以减少资源占用。对于决策树，子树剪枝的方法从一开始就已被提出[319]。此外，集成成员的选择也受到关注，例如[371]，但这是一个活跃的研究领域。在部署树模型之前，值得确定合适的剪枝方法。

## 3.5 神经网络

神经网络自诞生起就备受关注。在此，我们将介绍该领域的结构，并指引部分文献供进一步学习。

神经网络通常是——最常见为无环的——有向图，其节点按层组织。输入层由输入特征的节点`x[i]`组成。输出层给出网络的结果`y`，或拥有多个所谓的`heads`，每个head是多项式神经网络中的一个目标。输入层和输出层之间的层称为`hidden layers`（隐藏层）。具有隐藏层的神经网络称为深度神经网络（DNN）。图3.2展示了一个神经元，包含求和后的传入节点权重以及非线性激活函数，此处为修正线性单元，其计算公式为`ReLU(z) = max{0, z}`。其他激活函数包括sigmoid、tanh和softmax。单个这样的神经元也称为感知机。拥有多个此类感知机的层则称为多层感知机（MLP）。后续层节点间的连接方式可能是前一层的每个节点都与下一层的每个节点相连，从而形成全连接层。也存在层间连接较少的网络类型。由于推理过程将计算值从传入信号传递到下一个隐藏层，直到到达输出层，因此它是前馈神经网络。如果计算还包含反馈连接，则该神经网络称为循环网络。

“神经网络”一词源于这样一种想法：加权求和与非线性激活函数的组合让人联想到生物神经元细胞。事实上，人脑的神经元细胞在接收来自输入神经元的足够强信号时会被激活。然而，神经元细胞比我们此处称为“神经元”的简单数学函数复杂得多。此外，大脑也比简单的神经元层拼接复杂得多。因此，不应将神经网络误解为生物大脑的合适模型。

### 3.5.1 DNN的架构

DNN由一系列层组成，每层可执行不同的计算。当我们提到`architecture`（架构）时，指的是特定的层序列，不考虑用于训练该架构的优化算法或数据。

最基础的层类型称为`dense layer`（稠密层/全连接层）；它将权重矩阵`W`与传入值的完整向量`![](img/b_9783110785968-003_ingr_064.png)`相乘，并可能加上偏置项`b ∈ ℝ`。然后将加权和输入非线性激活函数`u`，使得稠密层的输出为`u(W^⊤h + b)`，如图3.2所示。权重矩阵随后在学习过程中被优化，非线性函数使模型能够学习数据中的非线性依赖关系。然而，稠密权重矩阵`W`给模型引入了大量参数，其训练在资源消耗方面可能是低效的。

### 3.5.2 DNN的鲁棒性

神经网络在许多方面都很脆弱。一方面，架构上的微小变化可能导致预测性能的巨大变化。另一方面，数据上的微小变化可能极大地改变神经网络的分类。著名的例子是那些难以察觉变化的图像，却输出了完全不同的类别[362]。优化导致最差准确率的最小变化被称为**对抗攻击**。已经研究了多种扰动类型，不仅针对数据，还针对被感知的物理对象。在[154]中，一些贴纸被贴在停车标志上，结果被分类为“限速45”。为了使神经网络更鲁棒，发明了防御机制。最近，开发出了针对特定扰动证明鲁棒性的保证[132]。最后，鲁棒性也可能指数据分布的变化[124]。

### 3.5.3 深度学习理论

已证明，具有*n*个节点的单隐藏层神经网络是任何可测函数的通用逼近器，假设激活函数*Ψ* : ℛ → [0, 1]拥有可数多个不连续点[203]。隐藏节点的数量通常未知，但取决于待逼近的函数。在最坏情况下，每个输入配置需要一个隐藏节点，即如果我们只有一个隐藏层，隐藏节点的数量呈指数级增长。应用`VCdim`（见3.3.1节），证明了DNN样本复杂度的界，该界同时取决于网络的深度和宽度。更深的模型每层所需的隐藏节点更少。这是更深网络的优势[364]。DNN的复杂性可以在不涉及层宽度的情况下展示，但通常取决于其深度。对于`![](img/b_9783110785968-003_ingr_068.png)*d`层，以及矩阵*W*[1], ..., *W[d]*，复杂性已通过*W[j]*的Frobenius范数至多为*M[F]*(*j*)和*m*来展示，如[181]中的例子所示：

表征DNN的一种方法是通过与贝叶斯模型的类比。已证明，带有dropout的DNN的推断近似于高斯过程，因此贝叶斯模型的不确定性解释了DNN的dropout[174]。贝叶斯模型估计DNN模型的不确定性。然而，它们扩展性不佳。因此，提出了**谱归一化神经高斯过程**，它用高斯过程替换输出层，并在训练中包含权重归一化[251]。

### 3.5.4 解释

可解释AI已针对各类黑盒算法进行了研究[187]。选择边界示例或根据学习模型显示特征重要性，可在不查看训练过程的情况下解释学习到的模型。然而，如果解释仅指代代理模型，而非学习并部署的模型本身，它们实际上并未解释学习结果[177]。模型无关方法由验证和解释DNN的方法加以补充。特别是对于科学数据，我们要对真实过程建模，建模过程本身必须是可信的。
