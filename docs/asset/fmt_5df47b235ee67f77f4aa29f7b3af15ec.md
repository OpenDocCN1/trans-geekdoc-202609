### 数学严谨性

让我们最后做一点说明。数学中的一个常见理解是所有可能事件的概率之和为 1：如果一个实验可以有`N`种不同的结果，如果`Pi`是第`i`个结果的概率，那么$\sum_{i=1}^{N} Pi = 1$。很容易验证，`Eq. (2.7)`对于任何`m`的值都满足这一条件。假设我们正在处理硬币抛掷领域，那里只有两种可能的结果。如果先验估计之和为 1（`nheads + ntails = 1`），那么在给定`Nheads + Ntails = Nall`的情况下，我们推导出如下：


## 2.4 如何处理连续属性

到为止，我们的考虑仅限于假设离散值的属性，通过相对频率或`m-estimate`来估计它们的概率。然而，这还不够。在许多应用中，我们会遇到从连续领域获取值的属性（如年龄、价格或重量）。这时，相对频率就是不实际的。虽然很容易确定 ![image](img/image112.png) 工程专业学生是男性的概率为`0.7`，但该学生体重为`184.5`磅的概率不能那样容易指定：由于不同的重量值是无限的，任何一个值的概率都是微乎其微的。

### 连续属性的离散化

一种可能是离散化。简单的“技巧”是将属性的原始域一分为二；例如，将`age`替换为布尔属性`old`，当`age > 60`时为`true`。

如果这样构造的阶梯函数看起来太粗糙，我们可以将原始域划分为更多——即更短的——区间，只要每个桶中的数量足够。如果训练集无限大，理论上我们可以不断缩小区间的长度，直到它们变得无限小。这样得到的结果将不再是阶梯函数，而是一个连续函数，如图 2.3 所示。其解释源于它的创建方式：`p(x)`的高值表示靠近`x`的示例很多；相反，`p(x)`的低值告诉我们`x`附近的年龄很少。这就是为什么我们称`p(x)`为概率密度函数，并通常倾向于使用其缩写`pdf`。

## 2.5 高斯“钟形”函数：标准 pdf

![image](img/chapter_title_below.png) 

近似`pdf`的方法之一是使用上一节中的离散化技术。或者，我们可以利用已知适用于许多现实情况的标准化模型。也许其中最流行的是高斯函数，它以这位伟大的德国数学家命名。

![image](img/image112.png)![image](img/image112.png) 形状及其描述它的公式

图 2.3 中的曲线是一个例子；它的形状揭示了为什么人们将其称为“钟形函数”。曲线在均值`µ`处达到最大值，并随着`x`远离`µ`而优雅地下降。我们可以预期这种模型是`x = 99.7`华度的密度。用数学表达式，高斯函数由以下公式定义，其中`e`是自然对数的底：

```
p.x/ = k · e^{-(x-µ)² / 2a²}
```

(2.10)

![image](img/image602.png) 注意`x`与`µ`的差异越大，曲线越陡；这取决于`a²`。方差越大曲线越平坦；相反，较小的方差定义了越窄的曲线。系数`k`的任务是使钟形函数的面积等于 1，正如理论要求的那样。这种情况发生在：

```
k = 1/(a · sqrt(2π))
```

### 设置参数值

为了在使用该模型近似`pdf`时，我们只需要估计参数值`µ`和`a²`。这很容易。假设`ci`在训练示例中有`m`个代表。如果`xi`是给定属性的值，那么均值和方差分别使用以下公式计算：

```
µ = 1/m * sum_{i=1}^m xi
a² = (1/(m-1)) * sum_{i=1}^m (xi-µ)²
```

(2.11)

22

![image](img/357.png) 简单来说，高斯中心`µ`通过训练示例的算术平均值获得，而方差通过与`µ`之间差值的平均值获得。注意在计算方差时，我们除以`m-1`，而不是预期的`m`。其目的是补偿`µ`本身只是一个估计值的事实。因此，方差应该比除以`m`时略大。当然，这只有在训练集较小时才重要：对于`m`，`m`和`m-1`之间的差异是可以忽略的。

## 2.6 使用高斯集合近似 PDF

虽然钟形函数在许多现实领域中是近似`pdf`的良好机制，但它并不是万能药。某些变量并不是这样变化的。只需考虑一个混合了小学生及其父母的组的体重分布。如果我们使用离散化方法创建`pdf`，我们将观察到两个峰：一个属于孩子，另一个属于成人。如果事实证明父亲体重分布在比母亲更高的均值周围，则可能有三个峰。

组合高斯函数

无疑，单个钟形函数会误导这种情况。但如果我们把两个或多个组合在一起呢？如果我们知道示例的多样来源，我们可以为每个来源创建一个单独的高斯函数，然后将钟形函数叠加在一起。这能解决我们的问题吗？

诚实的回答是：“是的，在那种理想情况下是这样的”。但在现实中，很少能够获得关于不同来源的先验知识。更好的解决方案是将体重值划分为许多随机组。在极端情况下，我们甚至可以让每个示例自成为一个“组”，然后根据该示例的体重值识别出一个高斯中心，从而获得`m`个钟形函数（对应`m`个示例）。
