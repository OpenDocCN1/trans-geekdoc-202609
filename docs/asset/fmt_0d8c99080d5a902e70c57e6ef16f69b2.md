
*   **零协方差**：表明变量间无线性关系。它们的变化在任何特定方向上都无一致关联。但必须认识到，这不一定意味着不存在关系。关系可能是非线性的，或受分析未捕捉的其他因素影响。

`cov()` 函数计算两个向量之间的协方差。重要的是要注意，协方差提供了关系方向的洞察，但不提供关联强度。这就是相关性的作用，它提供一个从 -1 到 +1 的标准化分数来量化关系强度。

相关性衡量两个变量之间线性关系的强度和方向。这有助于分析师识别一个变量的变化是否与另一个变量的变化相关联。相关性为 -1 表示完全负相关（反向变动），0 表示无线性关系，+1 表示完全正相关（同向变动）。越接近 -1 或 +1 的值表明关系越强，而越接近 0 的值表明关联越弱或不存在。识别这些关系对于进行预测和理解数据中观测模式背后的驱动因素至关重要。`cor()` 函数计算两个向量之间的相关系数。

考虑一个城市 Uber 乘车数据集。每个数据点包含行驶距离（公里）和对应的乘车时长（分钟）。距离与时间之间的正相关意味着，平均而言，较长的距离与较长的乘车时长相关联。

### 机器学习基础

机器学习通过赋能翻译应用和自动驾驶汽车等技术，彻底改变了我们生活的各个方面。机器学习为问题求解、问答以及内容/图像创作提供了一种通用的方法。它使系统能够预测客户流失、估算行程时长、推荐电影、自动补全句子、总结书籍或生成图像。

机器学习是利用历史数据训练模型以做出有价值的预测或生成内容的过程。模型是各变量间存在关系的数学表示或规范。

设想一个场景，任务是开发一个金融交易欺诈检测系统。在传统方法中，人们可能依赖基于规则的系统和预定义标记来标记潜在的欺诈活动。这种常规方法需要根据历史欺诈模式制定复杂的规则，涉及对各种欺诈指标的深入理解。该过程可能耗时较长，且存在忽视新出现的、不符合预设规则的欺诈手段的风险。

另一方面，采用机器学习方法涉及使用包含各种交易特征及其对应欺诈标签的海量数据集来训练模型。机器学习模型从数据中学习模式和异常，从而能够适应新的和以前未见过的欺诈模式。与传统方法静态且受规则束缚的性质不同，机器学习模型擅长识别那些可能未被显式编程的新欺诈模式。

面对新交易时，机器学习模型可基于学习到的模式自主评估欺诈的可能性。这种自主性提供了一种更动态、更适应性强的解决方案，因为模型无需人工干预更新预定义规则，即可适应新出现的欺诈趋势。

机器学习在以下各种场景中极具优势：

*   **需要大量微调或复杂规则集的问题**
    在现有解决方案涉及冗长规则列表的情况下，机器学习算法提供了一种精简的替代方案。机器学习将复杂的规则集整合为高效的模型，提高了代码清晰度和性能。
*   **涉及波动环境的问题**
    机器学习系统展现出对变化数据和环境的适应性。它们从新信息中学习的能力使其能够调整和进化，在条件多变的场景中尤为宝贵。
*   **无满意传统解决方案的复杂问题**
    机器学习擅长解决常规方法难以提供有效解决方案的复杂问题。

机器学习问题界定的第一步是确定机器学习是否为解决特定问题的正确方法。这涉及评估问题的特征，并判断机器学习能否有效解决该问题。如果机器学习合适，第二步是用机器学习术语界定问题。这包括将问题分解为几个部分、识别相关特征和标签，以及定义机器学习算法寻求优化的目标函数。

#### 机器学习问题定义与数据要求

#### 何时使用机器学习

虽然有人认为机器学习（ML）是一种适用于所有类型业务问题的通用工具，但现实是 ML 是为解决特定问题而设计的专用工具。必须避免在更简单的非 ML 方法足以解决问题时，实施复杂的 ML 解决方案。

为确保 ML 是最佳方法，请在投资 ML 替代方案前，彻底评估现有非 ML 解决方案的性能。请考虑以下问题以确定是否需要 ML 解决方案：

*   **量化预期改进**：与现有（已优化的）非 ML 解决方案相比，ML 解决方案能否带来显著影响？较小的收益可能意味着应坚持当前方法。
*   **成本对比**：审视 ML 解决方案相关的短期和长期费用。ML 实施可能在计算资源和时间方面产生巨大成本。
*   **成本效益论证**：在大型系统中，即使 ML 带来的微小改进也能转化为显著收益，从而抵消实施和维护成本。
*   **维护考量**：ML 模型通常需要专人负责监控、重新训练和潜在调试。评估团队是否具备长期维护所需的资源和专业知识。

#### 训练数据质量要求

用于训练的数据质量在决定模型准确性和有效性方面起着至关重要的作用。为创建稳健可靠的模型，数据应具备以下关键特征：

*   **数据量与相关性**：数据集中相关且有价值的示例越多，模型越稳健。更大的数据集为模型提供了更广泛的泛化空间，并提升其预测能力。
*   **数据收集可靠性**：数据收集流程应当合理，并应尽力减少数据录入、存储和处理过程中的错误。一致可靠的数据集使模型能够学习有意义的模式，降低偏差风险。
*   **标注准确性**：虽然大型数据集中难免存在少量标注错误，但高比例的错误标签会严重损害模型性能。确保标注准确对于构建产生可信预测的模型至关重要。
*   **真实世界代表性**：数据集应尽可能贴近被建模的真实场景。这意味着要捕捉实际环境中发生的相关事件、用户行为和其他现象。这样模型才能适应现实世界的变化和变体，在预测时表现更佳。

满足这些数据要求对于创建强大且可靠的预测性 ML 模型不可或缺。

#### 特征预测能力

为使模型生成准确预测，数据集中的特征必须具备显著的预测能力。特征与其对应标签之间的相关程度直接影响其预测准确性。相关性越高，该特征作为给定标签的可靠预测指标的可能性越大。

在**医疗患者再入院预测**场景中，不同特征表现出不同程度的预测能力。`previous_hospitalizations`、`medication_compliance` 和 `age` 等特征可能具有较高的预测能力。既往住院次数可反映患者健康史，`medication_compliance` 反映治疗依从性，`age` 可成为预测再入院风险的关键因素。另一方面，`patient_gender` 和 `day_of_week` 等特征预测能力可能较低。

然而，必须认识到特征的预测能力可能依赖于上下文。在医疗保健的特定子领域中，通常预测能力较低的特征可能变得更有影响力。因此，理解特征相关性在不同语境或领域中的动态性质，对于构建准确且符合语境的预测模型至关重要。

#### 选择 ML 模型类型

决定使用哪种类型的 ML 模型并非“一刀切”的情况。模型的输出需要满足您期望的结果。因此，第一个关键问题是：**什么样的输出能有效解决我的问题？**

*   如果目标涉及**分类**或**数值预测**，预测性 ML 可能是合适的选择。
*   如果任务涉及**生成新内容**、**翻译语言**或**创建类人对话**，生成式 AI 将是恰当的选择。

接下来，您需要定义关键绩效指标（`KPIs`），以衡量 ML 实施的成功与否。这些 `KPIs` 应与项目目标对齐，并传达最重要的方面，如提升用户体验、增加参与度或促进适当行动。成功指标示例包括：

*   **参与度**：追踪用户与平台交互的时长、推荐项目的点击次数或回访频率。
*   **转化率**：监控采取期望行动的用户比例，如购买产品、注册服务或完成任务。
*   **时间节省**：评估 ML 实施在多大程度上减少了用户搜索相关内容或解决问题所花费的时间。
*   **成本效益**：计算利用 ML 技术实现的成本节约。此评估可能需要对比实施 ML 系统的支出与传统人工流程的相关成本。

### 机器学习系统类型

机器学习系统可以根据其学习方法进行分类，这决定了它们如何进行预测或生成内容：

*   监督学习
*   无监督学习
*   强化学习
*   生成式 AI

#### 监督学习

在监督学习中，算法在包含输入数据和相应输出标签的数据集上进行训练。目标是让算法学习输入数据与正确输出标签之间的关系，从而能够对新的、未见过的数据做出准确预测。之所以称为“监督”学习，是因为人类向算法提供带标签的数据，引导其走向正确的解决方案。

监督学习包含两类任务：回归和分类。

##### 回归
