1. `N × l` 感知矩阵 `X` 由以下方式形成：
    1. (a) 不同的独立同分布实现，元素取自高斯分布 `𝒩(0, 1/N)`，
    2. (b) 不同的独立同分布实现，取自 `ℝ^N` 中单位球上的均匀分布，也称为均匀球面集合，
    3. (c) 不同的独立同分布实现，元素取自伯努利型分布，
    4. (d) 部分傅里叶矩阵的不同独立同分布实现，每次使用不同的 `N` 行集合。

2. `k` 稀疏目标向量 `θ[o]` 通过以概率 `p = k/l` 随机选择（至多）`k` 个非零元素的位置来形成，并根据统计分布（如高斯、均匀、双指数、柯西）填充非零元素的值。

*   `α := N/l`，这是问题不确定性的归一化度量，

## 10.3 稀疏感知主题的变体

在我们迄今为止的探讨中，我们已经涉及了源自主流理论发展的稀疏感知学习的许多方面。然而，也出现并发展了许多变体，旨在解决具有更特殊结构的问题和/或提出替代方案，这些方案通过满足特定应用的需求，有助于在实践中提升性能。这些变体侧重于公式 (9.6) 中的正则化项，和/或拟合误差测度项。再次强调，该方向的研究活动非常活跃，我们的目的仅是强调可能的替代方案，并让读者了解从基础理论中衍生出的各种可能性。

在许多任务中，先验已知目标信号/向量中的非零参数成组出现，并非随机分布在所有可能的位置。一个典型的例子是互联网电话中的回声路径，其中冲动响应的非零系数倾向于聚集在一起（参见 图 9.5）。其他“结构化”稀疏的例子可见于 DNA 微阵列、MIMO 信道均衡、传感器网络中的源定位、脑磁图以及神经科学问题（例如，[1,9,10,60,101]）。正如机器学习中始终如此，能够将先验信息融入优化过程，只会有助于提升性能，因为估计任务在寻找最优解的过程中得到了外部辅助。

*组 LASSO* [8,59,97,98,117,122] 解决的是非零分量先验已知成组出现的任务。未知向量 `θ` 被划分为 `L` 个组，即，

```
θ^(T) = [θ[1]^(T), …, θ[L]^(T)]^(T)
```

每组的大小预先确定为 `s[i]`，`i = 1, 2, …, L`，且满足 `∑_{i=1}^L s_i = l`。回归模型随后可以写为

```
y = Xθ + η = ∑_{i=1}^L X_i θ_i + η
```

其中每个 `X_i` 是 `X` 的一个子矩阵，包含相应的 `s_i` 列。组 LASSO 的解由以下正则化任务给出：

其中 `‖θ_i‖₂` 是 `θ_i` 的欧几里得范数（而非平方范数），即

```

```

换句话说，在标准 LASSO 公式中构成 `ℓ₁` 范数的 `θ` 的各个分量，现在被每个单独块的能量平方根所取代。在这种设定下，当它们对最小二乘（LS）误差测度项的贡献不显著时，被强制为零的不是各个分量，而是它们的*块*。有时，这种类型的正则化被称为 `ℓ₁/ℓ₂` 正则化。`θ ∈ ℝ³` 的 `ℓ₁/ℓ₂` 球示例可见于 图 10.6B，并与 图 10.6A 中描绘的相应 `ℓ₁` 球进行对比。

除了传统的组 LASSO（常被称为*块稀疏*）之外，研究工作还致力于开发包含更精细*结构稀疏*模型的学习策略。这样做主要有两大原因。首先，在许多应用中，未知参数集 `θ` 表现出一种无法用块稀疏模型捕捉的结构。其次，即使 `θ` 是块稀疏的，标准分组 `ℓ₁` 范数也需要关于 `θ` 分区的信息。这在实践中可能相当受限。采用重叠组已被提出作为一种可能的解决方案。假设每个参数至少属于一个组，此类模型导致的优化任务在许多情况下并不难求解，例如，通过求助于近端方法 [6,7]。此外，通过使用适当定义的重叠组 [71]，允许的稀疏模式可被约束形成*分层*结构，例如在多尺度（小波）分解中遇到的连通有根树和子树。在 图 10.6C 中，展示了一个重叠组的 `ℓ₁/ℓ₂` 球示例。

除了上述方向外，将压缩感知原理扩展以处理结构稀疏性，导出了*基于模型的*压缩感知 [10,26]。`(k, C)` 模型允许 `k` 稀疏信号的显著参数最多出现在 `C` 个簇中，其大小未知。在第 9.9 节中曾指出，寻找 `k` 稀疏解是在维度为 `k` 的子空间并集中进行的。对目标解施加特定结构将搜索限制在这些子空间的一个子集中，并使其中许多子空间不再参与搜索。这显然简化了优化任务。文献 [27] 从图模型角度考虑了结构稀疏性，文献 [110] 引入了 C-HiLasso 组稀疏模型，该模型允许每个块本身具有稀疏结构。扩展限制等距性质（RIP）至块 RIP 的理论结果已得到发展并报道（参见例如 [18,83]），在算法方面，提出了贪婪算法的适当修改，以提供结构稀疏解 [53]。

在文献[24]中，建议用加权版本来替代`ℓ₁`范数。为了证明这种选择的合理性，让我们回顾一下示例 9.2 以及使用`x` = [2, 1]ᵀ感知“未知”系统的情况。我们已经看到，通过“吹胀”`ℓ₁`球，得到了错误的稀疏解。现在让我们将公式(9.21)中的`ℓ₁`范数替换为其加权版本，

```
‖θ‖₁,𝑤 := 𝑤₁|θ₁| + 𝑤₂|θ₂|, 𝑤₁, 𝑤₂ > 0
```

并设定`𝑤₁ = 4`和`𝑤₂ = 1`。图 10.7A 展示了等值曲线`‖θ‖₁,𝑤 = 1`，以及由标准`ℓ₁`范数产生的曲线。加权曲线在垂直轴周围被尖锐地“捏紧”，且`𝑤₁`的值相比`𝑤₂`越大，相应的球体就会越尖锐。图 10.7B 展示了当“吹胀”加权`ℓ₁`球时会发生什么。它将首先接触点(0, 1)，该点即为真实解。基本上，我们所做的是“挤压”`ℓ₁`球，使其更多地与包含（稀疏）解的坐标轴对齐。就我们的例子而言，任何权重`𝑤₁ > 2`都能奏效。

现在考虑加权`ℓ₁`范数的一般情况，

![Equation](img/fx003.jpg) (10.16)

权重的理想选择应为

### 迭代加权 ℓ₁ 范数最小化算法

```
w_j = { 1/|θ_{o,j}|,  θ_{o,j} ≠ 0,
      { ∞,            θ_{o,j} = 0,
```

其中 `θ[o]` 是目标真实向量，且我们隐含假设 0 ⋅ ∞ = 0。换句话说，参数越小，相应的权重越大。这是合理的，因为较大的权重会在最小化过程中强制相应参数趋向于零。当然，在实践中真实向量的值是未知的，因此建议在最小化过程的每次迭代中使用其估计值。由此产生的方案形式如下。

#### Algorithm 10.3

1.  **初始化权重为单位值**，`w[j]⁰ = 1`，`j = 1, 2, …, l`。

2.  **最小化加权 ℓ₁ 范数**，

    `θ^(*i*) = arg min[θ ∈ ℝ^(*l*)] ‖θ‖[1, *w*] s.t. y = Xθ`。

3.  **更新权重**

    `w_j^(*i* + 1) = 1 / (|θ_j^(*i*)| + ε), j = 1,2,…,l.`

4.  **当满足停止准则时终止**，否则返回步骤 2。

常数 `ε` 是一个用户定义的小参数，用于在系数估计取非常小的值时保证稳定性。请注意，如果权重具有恒定的预选值，该任务保持其凸性质；当权重发生变化时，这不再成立。值得注意的是，如果将公式 (9.6) 的正则化项中的 `ℓ₁` 范数替换为 `∑_{j=1}^l ln(|θ_j| + ε)`，可以得到这种直观激励的加权方案。图 10.8 显示了一维空间中相应的图，以及 `ℓ₁` 范数的图。对数函数的图让人想起 `ℓₚ` “范数”（0 < `p` < 1）以及第 9.2 节中的评论。这不再是一个凸函数，之前给出的迭代方案是 Majorization-Minimization 过程的结果，旨在求解由此产生的非凸任务 [24]（问题 10.6）。
