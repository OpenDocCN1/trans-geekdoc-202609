
###### 步幅

通常，卷积操作沿被卷积数据逐元素滑动卷积核。因此，长度为 `n` 的数据与长度为 `K` 的卷积核进行有效卷积的长度为 `n-K+1`。这种每次仅滑动一个元素的卷积操作使得结果数据长度与原始数据几乎相同。卷积核沿原始数据滑动的元素数量称为**步幅** 或**跨度**。有时为了生成更小的卷积结果数据，常使用大于 1 的步幅滑动卷积核。如图 6-9 所示。

**图 6-9 步幅为 1 和步幅为 2 的卷积**

注意，卷积核的"步幅"为 `S`，长度为 `K` 的卷积核可在长度为 `n` 的数据上滑动 `(n-K)/S` 次。除初始卷积外，每次滑动可再执行一次卷积操作，因此总共可执行 `(n-K)/S+1` 次卷积操作。例如：`n=10, K=3, S=2`，可执行的卷积操作次数为 `(10-3)/2+1 = 4`。

若原始数据长度为 `n`，左右填充长度之和为 `P`，则填充后数据长度为 `n+P`。因此可执行的卷积操作次数为 `(n+P-K)/S+1`，即最终结果数据长度为 `(n+P-K)/S+1`。

上述卷积函数可轻松改写以处理带步幅的卷积操作。

### 6.1.2 一维信号的卷积

卷积用于处理一维信号或二维图像等数据，可以去除数据中的噪声或获取数据中包含的某些特征。

例如，下面生成两组数字 `x` 和 `y`。`x` 是在 `[0, 2*π]` 上均匀分布的一组数字（100 个），`y` 是对应正弦曲线 `sin(x)` 附近的数字（即 `y` 是正弦波的带噪采样）：

```python

import matplotlib.pyplot as plt

x = np.linspace(0, 2*np.pi, 100)

```

### 6.1.3 二维卷积

各种电子设备的显示屏之所以能显示丰富多彩的文字和图像内容，是因为显示屏本身由一些像素组成，这些像素按行列排列形成一个矩形。在计算机中，任何图像都由像素矩阵表示。图像中的像素数量称为图像的**分辨率**。例如，图像分辨率 `1024 * 768` 表示图像矩形在宽度和高度方向上的像素数分别为 1024 和 768。计算机中由像素矩阵表示的这种图像称为**数字图像**。如图 6-13 所示，它是一幅分辨率为 `170 * 225` 的图像。

图 6-13 分辨率为 170 * 225 的蒙娜丽莎图像

数字图像中每个位置的像素包含表示颜色信息的数据。对于彩色图像，它可能包含红色（R）、绿色（G）、蓝色（B）和透明度（A）等多个值。对于黑白图像，它是一个表示亮度的值。这些值通常用字节（8 位二进制）整数表示，即每个值的范围是 `[0, 255]`。黑白图像是此类整数的矩阵，而彩色图像可以看作是每种颜色对应的矩阵叠加而成，每种颜色的矩阵称为一个**通道**。例如，一幅图像由红色（R）、绿色（G）和蓝色（B）三幅彩色图像叠加而成。

图 6-14 彩色图像由 3 个通道的彩色图像叠加而成

就像一维信号一样，对于二维图像矩阵，也可以使用一组权重来处理其中的数据。例如，使用一个比图像小的矩阵（通常称为 `kernel`）与原图像进行卷积（即加权求和）。

如图 6-16 所示，假设左侧是一个 6×6 大小的矩阵（图像），中间是一个 3×3 大小的矩阵，代表卷积核。根据“从上到下，从左到右顺序沿图像滑动，对遇到的每个图像窗口，使用卷积核进行加权求和，将生成一个值”的方式使用卷积核矩阵。例如，用卷积核与图像左上角窗口元素加权求和，得到的值为：

```
2*(-1)+ 3*0+ 0*1+ 6*(-2)+ 0*0+ 4*2+ 8*(-1)+ 1*0+ 0*1 = -14
```

继续将卷积核逐像素向右移动，依次生成新值：

```
3*(-1)+ 0*0+ 7*1+ 0*(-2)+ 4*0+ 7*2+ 1*(-1)+ 0*0+ 3*1 = 20
0*(-1)+ 7*0+ 9*1+ 4*(-2)+ 7*0+ 2*2+ 0*(-1)+ 3*0+ 2*1 = 7
```

图 6-16 6x6 二维矩阵数据与 3x3 卷积核的有效卷积产生 4x4 大小的矩阵

这是一种有效卷积方法，最终生成一个 `4*4` 的矩阵。

如果用 `x[i, j]` 表示二维矩阵（如图像矩阵）第 i 行第 j 列的元素，用 `w[m, n]` 表示卷积核第 m 行第 n 列的权重，用 `a[i, j]` 表示结果矩阵第 i 行第 j 列的元素，则二维矩阵的卷积运算公式如下：

$a_{i,j} = \sum\limits_{m = 0}^{F_{h}}\sum\limits_{n = 0}^{F_{w}}w_{m,n}x_{i + m,j + n}\qquad$

即将卷积核窗口与数据矩阵的 (i, j) 位置对齐，然后与数据窗口中对应的数据进行加权求和。例如，上面示例中的 `a[1, 1]` 计算如下：

$$

\begin{matrix}

a_{1,1} & {= \sum\limits_{m = 0}^{F_{h}}\sum\limits_{n = 0}^{F_{w}}w_{m,n}x_{1 + m,1 + n}} \\

& {= w_{0,0}x_{1,1} + w_{0,1}x_{1,1 + 1} + w_{0,2}x_{1,1 + 2}} \\

& {\quad w_{1,0}x_{1 + 1,1} + w_{1,1}x_{1 + 1,1 + 1} + w_{1,2}x_{1 + 1,1 + 2}} \\

& {\quad w_{2,0}x_{1 + 2,1} + w_{2,1}x_{1 + 2,1 + 1} + w_{2,2}x_{1 + 2,1 + 2}} \\

& {= w_{0,0}x_{1,1} + w_{0,1}x_{1,2} + w_{0,2}x_{1,3}} \\

& {\quad w_{1,0}x_{2,1} + w_{1,1}x_{2,2} + w_{1,2}x_{2,3}} \\

& {\quad w_{2,0}x_{3,1} + w_{2,1}x_{3,2} + w_{2,2}x_{3,3}} \\

\end{matrix}

$$

假设数据矩阵 X 的行数和列数分别为 h 和 w，卷积核 K 的行数和列数分别为 `F[h]` 和 `F[w]`，则“有效卷积”操作生成的结果矩阵的行数和列数分别为 `h - F[h] + 1` 和 `w - F[w] + 1`。以下是二维矩阵（图像）进行“有效卷积”操作的代码实现：

```python
def convolve2d(X, K):
    h, w = K.shape
    Y = np.zeros((X.shape[0] - h + 1, X.shape[1] - w + 1))
    for i in range(Y.shape[0]):
        for j in range(Y.shape[1]):
            Y[i, j] = (X[i: i + h, j: j + w] * K).sum()
    return Y
```

其中 X 为输入二维矩阵（图像），K 为卷积核矩阵，Y 为结果矩阵（图像）。即以 `(i, j)` 为起始的图像窗口 `X[i: i + h, j: j + w]` 与卷积核 K 进行逐元素乘积 `X[i: i + h, j: j + w] * K` 并求和 `X[i: i + h, j: j + w] * K.sum()`。当 `(i, j)` 沿图像滑动时，即可得到结果矩阵的一系列元素值。

使用以下代码测试该函数：
