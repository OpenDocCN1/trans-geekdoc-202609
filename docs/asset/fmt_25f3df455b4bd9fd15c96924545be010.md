
除了`+=`运算符，我们还有`-=`运算符，它将`-`运算符与赋值运算符结合。同样适用于上一节中提到的所有算术运算符。因此，`$x -= 4`等同于`$x = $x - 4`，`$x *= 2`等同于`$x = $x*2`，依此类推。

### 4.5.4 增减运算符

最后但同样重要的是，让我们来谈谈增（`++`）和减（`--`）运算符。这些运算符将变量的值加减 1 并返回新值。让我们尝试一些代码（添加行号以便参考）。

```php
1 $q = 3;
2 echo "<BR>$q<BR>";
3 echo ++$q;
```

如果你运行上面的代码，将得到以下输出：

```
3
4
```

第 2 行使用`echo`语句输出`$q`的原始值。第 3 行执行了以下操作：

1. 将`$q`的值加 1
2. 输出`$q`的新值

因此，我们得到了输出 4。`++`运算符被称为递增运算符。它可以放置在变量名的之前（称为前递增）或之后（后递增）。尝试将上面的第 3 行改为`echo $q++;`并重新运行代码，你将得到

```
3
3
```

这次的输出是这个。感到惊讶吗？这是因为第 3 行现在执行的是以下操作：

1. 输出`$q`的原始值。
2. 将`$q`的值加 1

换句话说，这两个任务（递增和输出）的执行顺序反过来了。递增是在`echo`语句执行后完成的（因此后递增）。为了证明`$q`确实增加了，你可以在第 3 行之后再次`echo`它的值。这次你会得到输出 4。明白了吗？

除了递增运算符，我们还有递减运算符（`--`）。该运算符由两个减号组成，并将变量的值减 1。它也可以作为前递减或后递减运算符使用。

## 5.1 字符串

字符串指的是一段文本。在 PHP 中，字符串必须包含在单引号或双引号中。例如，如果我们写：

在 PHP 中，你可以使用连接运算符（`.`）组合多个字符串。让我们看这个例子：

```php
$areacode = "(28)";
$contact = '+1' . $areacode . '23456';

```

在这里，我们两次使用连接运算符将字符串 '+1'、变量`$areacode`和字符串 '23456' 组合在一起。我在连接运算符前后添加了空格，以便你可以清楚地看到这三个部分；不需要添加这些空格。连接后，我们将新字符串赋值给变量`$contact`并使用`echo`语句输出它的值。如果你运行上面的代码，将得到

```

```

输出。

### 5.1.1 常用的字符串函数

接下来，让我们讨论 PHP 中常用的字符串函数。PHP 带有许多用于处理字符串的内置函数。大多数函数在执行任务后返回结果。我们可以将结果赋值给变量，或使用`echo`语句直接显示。某些函数允许我们提供参数来修改函数的行为。下面的示例讨论了最常用的函数。

#### `strlen()`

`strlen()`函数返回字符串的长度。示例：

```php
$str1 = 'Good Day!';
echo strlen($str1);
```

输出：`9`

在这里，我们定义变量`$str1`并将字符串 'Good Day!' 赋值给它。接下来，我们将`$str1`传递给`strlen()`并使用`echo`语句显示结果。我们得到输出 9，因为 4 ('Good') + 1 (' ') + 3 ('Day') + 1 ('!') = 9。

#### `strtolower()`, `strtoupper()`

`strtolower()`和`strtoupper()`函数分别将字符串转换为小写和大写，并返回新字符串。原始字符串没有改变。示例：

```php
$str2 = 'Hello World';
$str3 = strtolower($str2);
$str4 = strtoupper($str2);
echo '<BR>'.$str2;
echo '<BR>'.$str3;
echo '<BR>'.$str4;
```

在这里，我们定义变量`$str2`并将字符串 'Hello World' 赋值给它。接下来，我们将`$str2`传递给`strtolower()`和`strtoupper()`，并将结果赋值给`$str3`和`$str4`。最后，我们使用三个`echo`语句输出`$str2`、`$str3`和`$str4`的值。在每种情况下，我们都与变量连接了`<BR>`，以便输出从新行开始。如果你运行上面的代码，将得到

```
Hello World
hello world
HELLO WORLD
```

#### `trim()`

`trim()`函数默认从字符串的开头端移除空格。你可以通过传递第二个参数指定要移除的字符。示例 1：

```php
$str5 = ' is ';
echo 'PHP'.$str5.'Fun';
echo 'PHP'.trim($str5).'Fun';
```

输出：

```
PHP is Fun
PHPFun
```

在这里，我们首先将`$str5`与字符串 'PHP' 和 'Fun' 连接，并使用`echo`语句输出生成的字符串。我们得到输出 "PHP is Fun"。接下来，我们使用`trim()`函数移除`$str5`中的空格，并再次与 'PHP' 和 'Fun' 组合。我们得到输出 "PHPFun"。

示例 2：

```php
$str6 = '\*\*Hello\*\*World\*\*';
echo trim($str6, '\*');
```

输出：`Hello**World`

在这里，我们将`'\*'`作为第二个参数传递给`trim()`函数。结果是从`$str6`的开头和结尾移除了星号（而不是空格），我们得到输出 "Hello**World"。

#### `substr()`

`substr()`函数返回一个子串。要使用此函数，我们需要向它传递两个参数——提取子串的字符串以及开始提取的位置。我们还可以传递第三个参数来指定要提取的子串长度。如果不提供此参数，函数将从指定的起始位置提取到字符串末尾的子串。字符串中的位置从 0 开始，而不是 1。例如，如果我们有一个字符串 'ABCDEF'，'A' 在位置 0，'B' 在位置 1，依此类推。位置也可以是负数。如果是负数，则从字符串末尾计数。在 'ABCDEF' 中，'F' 在位置 -1，'E' 在位置 -2 等。示例：

```php
$str7 = 'ABCDEF';
echo substr($str7, 2);
echo substr($str7, -3);
echo substr($str7, 2, 1);
```

输出：

```
CDEF
DEF
C
```

在第三个示例中，我们通过向`substr()`传递第三个可选参数来指定子字符串的长度。由于我们指定的长度为 1，因此我们得到了“C”作为输出。明白了吗？我们已经涵盖了 PHP 中的几个字符串函数。要查看所有可用字符串函数的完整列表，你可以访问页面 https://www.php.net/manual/en/ref.strings.php 。

## 2. 使用字符串表示日期

接下来，让我们学习使用字符串来表示日期。为了实现这一点，我们使用名为`strtotime()`的内置函数。

### 2.1 `strtotime()` 函数

如名所示，`strtotime()`函数将字符串转换为时间。它接受一个描述特定日期（和时间）的字符串，并尝试将其转换为时间戳。如果你传递给函数一个无法转换的字符串，它将返回`false`。另一方面，如果你传递一个它能够转换的字符串，它将解析该字符串并返回 UNIX 时间戳。UNIX 时间戳是一个整数，表示自 1970 年 1 月 1 日 00:00:00 UTC 以来的秒数。

例如，如果你运行语句：

```
echo strtotime("next Monday");
```

你将得到类似 `1587340800` 的结果。这提供了下周一（撰本文时）的 UNIX 时间戳。`strtotime()`函数非常智能，能够将各种英语文本日期描述转换为 UNIX 时间戳。例如，它转换如 `"now"`、`"tomorrow"`、`"next Monday"`、`"15 Nov 2019"` 或 `"+1 week"` 等字符串没有问题。虽然该函数很容易，但你可能会同意，它返回的时间戳在大多数情况下并不实用。如果你想为日期或时间获取更有意义的格式，可以使用另一个名为`date()`的内置函数。

### 2.2 `date()` 函数

`date()`函数接受一个可选的时间戳，并将时间戳格式化为更易读的字符串。如果没有提供时间戳，它将格式化当前时间戳。假设我们想格式化当前时间之后 10 小时的时间戳，可以使用下面的语句：

```
echo date('d-M-Y', strtotime("+ 10 hours"));
```

在这里，我们向函数传递了两个参数。第一个参数指定了我们希望如何格式化时间戳。为了这一点，我们使用一个由标点符号和预定义字符组成的字符串（定义见 https://www.php.net/manual/en/function.date.php）。在我们的示例中，我们使用了字符串 `'d-M-Y'`。字符 `'d'` 表示我们希望日期以两位数字的形式表示，必要时使用前导零（例如，3 会输出为 03）。字符 `'M'` 和 `'Y'` 表示我们希望月份和年份分别用三个字母文本（例如 Jan）和四位数字表示。最后，标点符号 `'-'` 表示我们希望用连字符分隔日、月、年。在指定了所需的格式后，我们向`date()`函数传递了第二个参数`strtotime("+ 10 hours")`。该参数是可选的，指定了我们希望函数格式化的日期。如果你运行上面的`echo`语句，你将得到类似 `03-Apr-2020` 的输出。

这提供了现在（撰本文时）之后 10 小时的日期。明白了吗？

### 2.3 设置时区

上面的小节讨论了 PHP 中许多内置日期/时间函数中的两个。虽然大多数这些函数都很容易使用，但请注意，它们的结果受到我们 PHP 服务器中设置的时区的影响。例如，虽然

### 5.3.4 从数组删除元素

除了向数组添加元素外，我们还可以从中删除元素。一种方法是使用`array_splice()`函数。要使用此函数，我们需要向它传递两个参数 - 要从中删除元素的数组以及开始删除元素的位置。我们还可以传递第三个参数来指定要删除的元素数量。如果不提供此参数，函数将删除从指定起始位置到数组结束的所有元素。让我们来看一些示例。

#### 示例 1

$colors = array("red", "black", "pink", "white");
array_splice($colors, 2);

#### 示例 2

$awardwinners = array("Gold"=>"Max", "Silver"=>"Boots", "Bronze"=>"Dora");
array_splice($awardwinners, 1);

在这里，我们想要`array_splice()`从`$awardwinners`中删除所有元素，从位置 1（包括该元素）开始。`$awardwinners`变成了 `("Gold"=>"Max")`。

#### 示例 3

$pets = array("corgi", "poodle", "golden retriever", "jack russell");
array_splice($pets, 1, 2);

在这里，我们想要从`$pets`中删除 2 个元素，从位置 1（包括该元素）开始。`$pets`变成了 `("corgi", "jack russell")`。
