#### 3.4.1 具体实现

我们的 SharpDRO 需要两个反向阶段，时间复杂度是普通训练的两倍，为了高效计算锐度，请参考 [166, 167, 168, 170]。在第一步中，我们在推理期间记录每个数据的标签预测 `p`，并计算损失 `L`。此外，在第一次反向传播中，我们存储计算出的梯度 `∇L(θ)`。进一步，通过添加 `ε*`，我们使用扰动模型计算第二个标签预测 `p̂`，该预测进一步用于计算锐度正则化 `R`。

> ^1 这里的界意味着我们的 SharpDRO 能够在 `1/ε` 次迭代内收敛到 `ε`-驻点。

定理 1（非形式化）。假设损失函数 `L` 是 `l`-Lipschitz 平滑的，在第二个变量 `ω` 上满足 `μ`-Łojasiewicz (PL) 条件，并且梯度具有无偏估计且方差为 `σ²`，我们可以得到 `T` 次迭代期间的收敛率：

```
$\sum_{t=0}^{T-1} \mathbb{E}\|\nabla L^*(\theta_t)\|^2 \le 320 \sqrt{\frac{3\kappa^4l(\mathbb{E}L^*(\theta_0)-\min_{\theta}\mathbb{E}L^*(\theta))+\sigma^2}{MT}} = O\left(\frac{\kappa^2}{\sqrt{MT}}\right)$
```

其中条件数 `κ=l/μ`，且 `M` 表示样本批次（这里我们可以选择 `M=1`）。
