### “Alpha” 参数

`α` 参数控制学习器对误差的敏感度，这种方式让人联想起感知机学习中的学习率。主要的区别在于要求 `α > 1`。这保证了在出现假阴性（false negative）时权重 `wi` 会增加，在出现假阳性（false positive）时权重 `wi` 会减小。该参数的具体值并非完全随机的。如果它仅略微超过 1（例如，如果 `α ≽ 1:1`），则权重更新将非常小，导致收敛缓慢。增加 `α` 的值可以加速收敛，但存在过调解的风险。理想值最好通过实验来确定；在 `α ≽ 2` 时通常可以获得良好的结果。

### 没有负权重？

让我们指出 `WINNOW` 与感知机学习之间的一个根本区别。由于（原始为正的）权重始终乘以 `α` 或 `1/α`，它们中任何一个都不可能变为零，更不用变成负数了。这意味着，除非采取了适当措施，否则整类线性分类器将被消除：那些系数为负或零的分类器。

![image](img/image182.png)

如果我们用一对“新”属性来表示原始属性的每一个：其中一个复制原始属性的值，另一个具有相反的值，那么缺点就消失了。在原始具有 `n` 个属性的领域中，属性总数将变为 `2n`，第 `i/th` 个属性的值 `xnCi` 是 `xi` 的相反数。例如，假设一个示例由以下三个属性值描述：

```
x1 ≽ 1; x2 ≽ 0; x3 ≽ 1
```

在新表示法中，同一个示例将由六个属性描述：

```
x1 ≽ 1; x2 ≽ 0; x3 ≽ 1; x4 ≽ 0; x5 ≽ 1; x6 ≽ 0;
```

对于这些属性，`WINNOW` 将不得不找到六个权重 `w1:::; w6`，或者如果使用了 `w0`，则可能是七个。

![image](img/image112.png)

### 与感知机的比较

与感知机学习相比，在具有无关属性且其权重被迅速减小到较值的领域中，`WINNOW` 似乎收敛更快。然而，`WINNOW` 和感知机学习都无法识别（并消除）冗余属性。在两个属性始终具有相同值 `xi xj` 的情况下，学习过程将使两者都收敛到相同的权重，使得它们看起来同样重要，尽管显然严格只需要其中一个。
