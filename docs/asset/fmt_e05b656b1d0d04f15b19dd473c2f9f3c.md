### 7.11.4 基于词嵌入层的 Seq2Seq 模型

#### 1. 词嵌入层

Word2Vec 词向量化通过一个单独的训练过程，学习将词表中的一个词索引映射为比词表长度更低维的向量。也就是说，根据 Word2Vec 学习到的权重矩阵，利用词索引获取该矩阵对应的行。

词嵌入是指将词向量化结合到具体问题的模型中，即在具体问题的网络模型前面加一个嵌入层。该嵌入层的参数是词向量化的矩阵，用于将词索引映射为词向量，但该矩阵的参数最初是随机的，需要在模型训练过程中学习。也就是说，词向量化和具体问题的模型结合在一起进行训练。

该嵌入层是一个没有激活函数和偏置的全连接线性层。它是一个简化的线性层。代码如下：

```python
def one_hot(size, indices, expend=False):
    x = np.eye(size)[indices.reshape(-1)]
    if expend:
        x = np.expand_dims(x, axis=1)
    return x

class Embedding():
    def __init__(self, num_embeddings, embedding_dim, _weight=None):
        super().__init__()
        if _weight is None:
            self.W = np.empty((num_embeddings, embedding_dim))
            self.reset_parameters()
            self.preTrained = False
        else:
            self.W = _weight
            self.preTrained = True
        self.params = [self.W]
        self.grads = [np.zeros_like(self.W)]

    def reset_parameters(self):
        self.W[:] = np.random.randn(*self.W.shape)

    def forward(self, indices):
        num_embeddings = self.W.shape[0]
        x = one_hot(num_embeddings, indices).astype(float)
        self.x = x
        # Z = np.matmul(x, self.W)
        Z = self.W[indices, :]
        return Z

    def __call__(self, indices):
        return self.forward(indices)

    def backward(self, dZ):
        x = self.x
        dW = np.dot(x.T, dZ)
        dx = np.dot(dZ, np.transpose(self.W))
        self.grads[0] += dW
        return dx
```

因为 `Embedding` 层的权重参数也是需要学习的模型参数，所以在反向推导时，也需要计算损失函数关于 `Embedding` 层权重参数的梯度，即 `self.embedding.backward(dinput_t)`。反向推导归结为每个时刻 `t` 的求导。需要知道此时刻 `t` 的输入 `self.embedding.x`。因此，在正向计算过程中，有必要保存每个时刻 `Embedding` 层的输出 `self.embedded_x.append(self.embedding.x)`。
