
正如在本章之前讨论的，统计学在机器学习中的一个重要应用是基于集合随机样本的概率模型对集合或总体得出结论。例如，根据某些随机肿瘤病例的恶性样本测试结果，我们想要估计所有肿瘤中恶性的比例，从而对医生关于每个肿瘤病例是否需要进行活检提供建议。正如我们可以理解的，如果我们可以获得不同的随机样本，可能会给出不同的估计。为了方便理解，以下是本节使用的某些术语：

- **总体 (Population)** 是一个有限集合。
- **随机样本 (Random sample)** 是从总体中抽取的样本。
- **抽样分布 (Sampling distribution)** 是样本的分布。

### 5.9.1 有回抽样 (Sampling with replacement)

在有回抽样的情况下，从总体中抽取样本时，每个对象在被抽取后都会返回总体中。这意味着如果从总体中抽取了 `n` 个样本，由于重复是允许的，抽样大小为 `n` 且总体大小为 `N`，那么抽样数量为 `n`。

此外，每个样本的概率是 `N^n`。

例如，让我们从 3 个患者中选取 2 个患者的样本（允许重复），可能的组合如下：

`(A, B), (A, C), (B, A), (B, C), (C, A), (C, B)`

这意味着这样的样本数量为 `3² = 9`。

### 5.9.2 无回抽样 (Sampling without replacement)

在无回抽样的情况下，在选取下一个对象之前，不将选取的对象返回总体。这意味着从总体大小为 `N` 的总体中选取 `n` 个样本，重复是不允许的。

在我们先的例子中，从 3 个患者中选取 2 个患者（不允许重复），可能的无组合如下：

`(A, B), (A, C), (B, C)`

这意味着样本数量为 3。

### 5.9.3 样本的均值与方差 (Mean and variance of sample)

让我们考虑总体 `N` 中均值为 `μ`、标准差为 `σ` 的随机变量 `X`。无回抽样的 `n` 样本将产生 `n` 个值 `x[1], x[2]….., x[n]`。当样本是有回抽样时，这些值是相互独立的，可以被视为 `n` 个独立随机变量 `X[1], X[2], ..., X[n]` 的值，每个变量均值为 `μ`，方差为 `σ²`。样本均值是一个随机变量 `X̄`，如下：

`X̄ = (1/n) * Σ(x[i])`

由于 `X̄` 是随机变量，它也具有如下总体参数：

`E[X̄] = μ`
`Var(X̄) = σ²/n`

对于较大的 `n`，如果 `X` 近似于正态分布，那么 `X̄` 也服从正态分布。

当样本是无回抽样时，对于随机变量 `X` 的样本值 `x[1], x[2]….., x[n]` 不是独立的。样本均值 `X̄` 的均值为 `μ[X̄]`，方差为 `σ[X̄]²`，公式如下：

`μ[X̄] = μ`
`σ[X̄]² = (σ²/n) * ((N - n)/(N - 1))`

其中，`N` 是总体大小且 `n < N`。此外，如果 `X` 是正态分布，那么 `X̄` 也具有正态分布。

现在，根据中心极限定理，如果基于有限总体的随机变量样本量足够大，则样本均值近似服从正态分布，无论总体的分布如何。在采样的大多数实际应用中，当样本量足够大时（经验法则 ≥ 30），样本均值近似服从正态分布。此外，当从大总体中抽取随机样本时，可以假设值 `x[1]`、`x[2]`……、`x[n]` 是相互独立的。这种独立性假设是概率论应用于统计推断的关键之一。我们使用“总体远大于样本量”或“总体相对于其样本量很大”等术语来表示总体足够大，以至于样本之间相互独立。在实践中，如果 `n/N ≤ 0.05`，则可以假设独立性。

## 5.10 假设检验

在处理随机变量时，常见的情况是我们必须根据具有随机性质的观测或数据做出某些决策或选择。处理这些情况的解决方案被称为决策理论或假设检验，它在现实生活中是一个被广泛使用的过程。正如我们之前讨论的，机器学习的核心组件是使用基于样本的训练数据，这些数据可以代表更大量的实际数据，而且估计结果在多大程度上可以与训练数据的行为相关是至关重要的，以便对实际数据做出决策。因此，假设检验是机器学习不可或缺的一部分。

从统计学的角度来说，假设是对关于随机变量概率律的假设。例如，取随机变量的随机样本 `(X[1], …, X[n])`，其关于参数 `κ` 的概率密度函数（pdf）由 `f(x, κ) = f(x[1], x[2], …, x[n]; κ)` 给出。我们检验假设 `κ = κ[0]` 对于 `κ = κ[1]`。在这种情况下，假设 `κ = κ[0]` 称为零假设，记作 `H[0]`。假设 `κ = κ[1]` 称为备择假设，记作 `H[1]`。

`H[0]: κ = κ[0]`

`H[1]: κ = κ[1]`

简单假设是指所有参数都指定了精确值的假设，例如本例中的 `H[0]` 或 `H[1]`。但如果参数没有精确值，例如 `H[1]: κ ≠ κ[1]`，则 `H[1]` 是复合假设。

假设检验的概念是用于验证假设的决策过程。我们可以通过将观测空间（例如 `R`）划分为两个区域——`R[0]` 和 `R[1]` 来解释决策过程。如果 `x = (x[1], …, x[n])` 是观测集，那么如果 `x ∈ R[0]`，则决策倾向于 `H[0]`；如果 `x ∈ R[1]`，则决策倾向于 `H[1]`。区域 `R[0]` 称为接受区域，因为零假设被接受，而 `R[1]` 是拒绝区域。根据观测空间中的两个区域，共有 4 种可能的决策：

1. `H[0]` 是真的；接受 `H[0]` ➔ 这是一个正确的决策
2. `H[0]` 是真的；拒绝 `H[0]`（意味着接受 `H[1]`）➔ 这是一个错误的决策
3. `H[1]` 是真的；接受 `H[1]` ➔ 这是一个正确的决策
4. `H[1]` 是真的；拒绝 `H[1]`（意味着接受 `H[0]`）➔ 这是一个错误的决策

因此，我们可以看到存在 2 种正确和 2 种错误决策以及相应的行动。错误决策可以称为：

- **第一类错误**：当 `H[0]` 为真时拒绝 `H[0]`（或接受 `H[1]`）。这种情况的例子是肿瘤的恶性检测，将良性肿瘤接受为恶性肿瘤并开始相应的治疗。这也被称为 `Alpha`，即将好解释为坏。
- **第二类错误**：当 `H[1]` 为真时拒绝 `H[1]`（或接受 `H[0]`）。这种情况的例子是肿瘤的恶性检测，将恶性肿瘤接受为良性肿瘤且不开始治疗。这也被称为 `Beta`，将坏解释为好，可能会产生更具破坏性的影响。

第一类错误和第二类错误的概率为：

`P[I] = P(D[1]|H[0]) = P(x ∈ R[1]; H[0])`
`P[II] = P(D[0]|H[1]) = P(x ∈ R[0]; H[1])`

其中，`D[i] (i = 0, 1)` 表示决策接受 `H[i]` 的事件。`P[I]` 也记作 `α`，称为显著性水平，而 `P[II]` 记作 `β`，称为检验功效。在这里，`α` 和 `β` 与其他并不独立，因为它们代表来自同一个决策问题的事件概率。因此，在样本量固定的情况下，通常一种类型错误的减少会导致另一种错误的增加。虽然减少两种类型的错误都是理想的，但这只有通过增加样本量来实现。在假设检验的所有实际应用中，四种可能的结果和行动方案都与相对重要性或特定成本相关，因此最终目标可以是降低总成本。

因此，正确决策的概率为：

`P(D[0]|H[0]) = P(x ∈ R[0]; H[0])`
`P(D[1]|H[1]) = P(x ∈ R[1]; H[1])`

## 5.11 蒙特卡洛近似

尽管我们讨论了随机变量的分布函数，但在实际情况下，使用变量换元公式来计算它们是非常困难的。蒙特卡洛近似为此提供了一个简单但强大的替代方案。让我们先从分布中生成 `S` 个样本，作为 `x[1], …, x[S]`。对于这些样本，我们可以通过使用集合 `{f(x[s])}_{s=1}^S` 的经验分布来近似 `f(X)` 的分布。

原则上，蒙特卡洛方法可以解决任何具有概率解释的问题。我们通过大数定律可知，由某些随机变量期望值描述的积分可以通过取独立样本的经验均值（或样本均值）来近似。随机变量概率分布的马尔可夫链蒙特卡洛 (`MCMC`) 是一种采样器，其核心思想是设计一个具有规定概率分布的马尔可夫链模型。蒙特卡洛技术现在广泛应用于统计学和机器学习。使用蒙特卡洛技术，我们可以通过从总体中抽取样本，然后计算应用于函数的算术平均值来近似随机变量任何函数的期望值，如下：

```
E[f(X)] ≈ (1/S) * Σ f(x[s])
```

这也被称为蒙特卡洛积分，比在固定网格点上评估函数的数值积分更容易计算。蒙特卡洛只在概率不可忽略的地方评估函数。

对于不同的函数 `f()`，可以获得某些重要量的近似：

- `E[X] ≈ (1/S) * Σ x[s]`
- `Var(X) ≈ (1/S) * Σ (x[s] - E[X])²`
- `P(X ∈ A) ≈ (1/S) * Σ I(x[s] ∈ A)`
- `median{ x[1], …, x[S] } → median(X)`

## 5.12 总结

1. 频率概率解释代表事件的长期频率，而贝叶斯概率解释试图量化某些事件的不确定性，因此关注信息而非重复试验。
2. 根据贝叶斯规则 `p(A|B) = p(B|A) * p(A) / p(B)`。
3. 离散随机变量用概率质量函数（pmf）表示 `p(x) = p(X = x)`。
4. 连续随机变量用概率密度函数（pdf）表示 `p(x) = p(X = x)`。
5. 随机变量 `X` 的累积分布函数（cdf）可以通过 `F(x) = P(X ≤ x)` 计算。
6. 随机变量 `X` 求均值的公式为：
   - 当 `X` 为离散时：`E[X] = Σ x * p(x)`
   - 当 `X` 为连续时：`E[X] = ∫ x * p(x) dx`
7. 寻找随机变量 `X` 方差的方程为 `Var(X) = E[(X - μ)²] = E[X²] - (E[X])²`。
8. 当我们处于试验结果仅为“成功”或“失败”的特定情况时，随机变量 `X` 的行为可以用伯努利分布来表示。
9. 如果进行了 `n` 次相互独立的伯努利试验，且 `X` 代表这 `n` 次试验中成功的次数，那么 `X` 被称为二项分布随机变量。
10. 为了对投掷 `K` 面骰子的结果进行建模，或者对于结果多可能的实验，我们可以使用多项分布。
11. 泊松随机变量具有广泛的应用，因为当 `n` 很大且 `p` 较小且 `np` 处于中等规模时，它可以作为参数为 `(n, p)` 的二项分布的近似。
12. 均匀分布、高斯（正态）分布、拉普拉斯分布是少数重要的连续随机分布的例子。
13. 如果随机实验的样本空间 `S` 中有两个随机变量 `X` 和 `Y`，那么这一对 `(X, Y)` 被称为双变量随机变量。
14. 两个随机变量 `X` 和 `Y` 之间的协方差衡量了 `X` 和 `Y` 相关（线性）相关的程度。
15. 根据中心极限定理，无论单个 `X[i]` 的分布如何，对于较大的 `n`，其和 `S[n] = X[1] + … + X[n]` 的分布近似于正态分布。
16. 在假设检验中：
    - **第一类错误**：当 `H[0]` 为真时，拒绝 `H[0]`（或接受 `H[1]`）。
    - **第二类错误**：当 `H[1]` 为真时，拒绝 `H[1]`（或接受 `H[0]`）。
17. 使用蒙特卡洛方法，我们可以通过简单从随机变量的总体中抽取样本，然后计算应用于样本的函数算术平均值，来近似随机变量任何函数的期望值。

## 第 6 章

## 贝叶斯概念学习

### 本章目标

分类的概率原理是机器学习算法的一个重要领域。在现实生活中，我们的决策受到我们对某一事件的先验知识或信念的影响。因此，如果我们知道在过去观察到其他事件时，该事件确实发生过，那么在某些情况下，一个原本极可能不发生的事件可能会被我们认真考虑发生。同样的概念也应用于机器学习，并使用了本章讨论的贝叶斯定理及相关算法。前几章讨论的概率概念在本章中被广泛使用。

## 6.1 引言

在上一章中，我们讨论了概率的规则，以及概率、分布函数和假设检验原理在机器学习领域的可能用途。在本章中，我们将讨论贝叶斯定理的细节，以及它如何为机器学习概念提供基础。该技术源于 18 世纪数学家托马斯·贝叶斯（Thomas Bayes）的工作。他开发了被称为贝叶斯方法的基础数学原理，这些方法描述了事件发生的概率，更重要的是描述了当额外信息可用时，应该如何修正概率。

## 6.2 为什么贝叶斯方法非常重要？

贝叶斯学习算法（如朴素贝叶斯分类器）是解决某些类型学习问题的非常实用方法，因为它们可以计算假设的显式概率。在许多情况下，它们与其他学习算法（包括决策树和神经网络算法）同样具有，甚至表现更好。
