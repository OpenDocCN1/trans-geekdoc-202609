
在深度神经网络（DNNs）架构的设计方面，早期的工作致力于手动设计各种神经架构。这类架构的示例包括`ResNet`[\[13\]](#c09.xhtml#c09-bib-0013)、`DenseNet`[\[14\]](#c09.xhtml#c09-bib-0014)以及`GoogLeNet`[15, 16]。由于手工构建神经架构对人类领域知识和专业技能的要求，自从在[\[17\]](#c09.xhtml#c09-bib-0017)首次出现以来，一种名为神经架构搜索（NAS）的热门研究方向应运而生。为了解决 NAS 任务，NAS 采用了多种优化技术以产生高性能的架构，包括强化学习（RL）[18, 19]、梯度优化[20, 21]、贝叶斯优化[\[22\]](#c09.xhtml#c09-bib-0022)以及其他[\[23\]](#c09.xhtml#c09-bib-0023)。

作为一类基于种群的启发式算法，进化算法（EAs）已被证明在解决神经网络（NNs）的权重优化（即 NNs 的训练）和 DNNs 的架构搜索（即 NAS）方面是有效的。与基于梯度的 NNs 训练方法以及 NAS 的其他优化方法相比，EAs 由于具有吸引人的探索能力，对局部最优更不敏感[\[11\]](#c09.xhtml#c09-bib-0011)，并且在处理多目标时不需要额外的超参数就能表现更好[\[24\]](#c09.xhtml#c09-bib-0024)，这可以为决策提供一组潜在的解决方案。尽管如此，对于 EAs 来说，解决 DNN 的大规模优化问题（例如训练 DNNs）仍然困难[\[11\]](#c09.xhtml#c09-bib-0011)，因为 EAs 遭受了搜索维度扩展性差的困扰；此外，让 EAs 解决 NAS 任务也具有挑战性，因为为 NAS 为 EAs 备好有效的编码方案和遗传算子并非易事，而 EAs 的种群特征进一步使得 NAS 需要更多的计算资源。这促使许多研究人员致力于改进 EAs 以解决深度学习中的大规模多目标优化问题，本章介绍了两种最前沿的 EAs 用于解决深度学习的两种典型多目标优化问题：用以训练 DNNs 的梯度引导多目标 EA（称为`GEMONN`）和用于搜索 DNNs 神经架构的基于动作命令的代理辅助多目标 EA（称为`ACEncoding`）。

## 9.2 用于训练深度神经网络的梯度引导多目标进化算法

为了为 NNs 获得更好的权重，研究者提出了许多 EAs 用于训练 NNs [10, 11, 25, 26, 27, 31, 32, 33, 8, 34]。例如，Whitley 等人[\[27\]](#c09.xhtml#c09-bib-0027)采用了遗传算法来优化权重，结果证明了其在训练 NNs 方面的竞争力。Montana 和 Davis[\[26\]](#c09.xhtml#c09-bib-0026)通过定制的遗传算法训练了前馈 NNs。尽管 EAs 在训练 NNs 方面上具有优越性，但由于维度灾难，它们在解决 DNNs 方面的效率较低[\[32\]](#c09.xhtml#c09-bib-0032)。为了解决这一问题，一些尝试通过增强 EAs 在训练大规模 NNs 方面的扩展性来实现。Gong 等人[\[31\]](#c09.xhtml#c09-bib-0031)提出了一种仅考虑偏置的双目标 EA，因为偏置是控制稀疏性的主要因素；Liu 等人[\[10\]](#c09.xhtml#c09-bib-0010)通过限制权重值为`0`或`1`来缩小搜索空间，提出了一种逐层进化方法来优化网络；Sun 等人[\[11\]](#c09.xhtml#c09-bib-0011)开发了一种单目标 EA 来优化 DNNs，将权重优化转换为正交空间的优化；Such 等人[\[33\]](#c09.xhtml#c09-bib-0033)使用并行计算设备增强 EAs 在训练 DNNs 方面的扩展性，从而在单机上有效优化数百万个权重；Cui 等人[\[8\]](#c09.xhtml#c09-bib-0008)通过结合 SGD 和 EA 提出了一种优化权重的进化方法，其中 EA 增强了 SGD 的稳定性。大多数训练大规模 NNs 的进化方法通过减少搜索空间（即待优化的权重数量）来解决维度灾难，但这可能会错过最优区域并增加陷入局部最优的概率[\[34\]](#34)。

为了弥补这一局限性，本节介绍了一种用于训练 DNNs 的梯度引导进化方法（称为`GEMONN`），它可以利用梯度下降（GD）和 EAs 的优点。提出的交叉操作是一种梯度引导模拟二进制运算符[\[35\]](#c09.xhtml#c09-bib-0035)，称为`gSBX`，用于优化 DNNs 的权重。`gSBX`的搜索方向被定义为与父代相同，以便在优化 DNNs 权重时平衡开发与探索。随后，将`gSBX`嵌入到多目标进化算法中训练 DNNs，同时最小化训练损失和网络稀疏性。为了验证该方法的性能，采用`GEMONN`训练四类 NNs 的权重，即`AE`、`SAE`、`LSTM`和`CNN`。实验结果表明，`GEMONN`能够在 EAs 在训练具有数百万权重的大规模神经网络方面的扩展性。

在接下来，我们首先给出神经网络训练的形式定义，然后阐述用于训练 DNNs 的`GEMONN`。最后，展示并讨论`GEMONN`与先进网络训练方法之间的实验对比。

### 9.2.1 多目标神经网络训练的问题化

给定一个训练集`D`和一个网络`net`，EAs 通常通过最小化以下双目标优化问题来搜索权值的最优值和/或最优架构[36–38][\[9\]](#c09.xhtml#c09-bib-0009)：

(9.1) $$\min_{x} F(x) = \left\{\begin{aligned} f_1(x) &= f_{complexity}(net, x), \\ f_2(x) &= f_{loss}(net, D, x), \end{aligned}\right\}$$ 

其中`x`是所有待优化的权重集合，`f_1(x)`表示具有权重`x`的`net`的复杂度，`f_2(x)`表示`net`在样本`D`中所有样本上的平均训练损失。在实践中，网络复杂度可以通过非零权重的数量或权重绝对值之和来衡量，而训练损失可以是分类误差或重构误差。由于每个解包含两个目标值，解的质量通常由帕累托支配关系（Pareto dominance relation）决定。具体而言，当且仅当以下条件成立时，称解`x_1`Pareto 支配解`x_2`，记为`x_1 ≺ x_2`：

(9.2) $$\left\{\begin{aligned} \forall i=1, \dots, m, f_i(x_1) &\le f_i(x_2), \\ \exists j=1, \dots, m, f_j(x_1) &< f_j(x_2), \end{aligned}\right\}$$

### 9.2.2 深度神经网络的梯度引导进化多目标训练

#### 9.2.2.1 动机

尽管现有的进化算法在训练神经网络方面表现良好，但大多数在优化 DNN 中大量权重时都会遇到困难[11]。这些方法的局限性主要归因于它们采用的降维策略，这些策略通常在某种程度上可以解决维度灾难，但容易陷入局部最优[34]。因此，由于进化算法（EAs）在大规模优化中的搜索能力限制，这些方法必须减少优化的权重数量[32]。此外，还有一些方法[8, 31]直接将进化算法与梯度下降（GD）结合，在原始搜索空间中进行搜索，权重通过传统的遗传算子和梯度下降连续更新。然而，进化算法在大规模优化问题上的可扩展性差的问题仍然解决。换句话说，这些方法中的进化算法只能保证群体中的最佳适应度不退化，而梯度下降则主要负责在原始搜索空间中寻找更好的解。

为了更好地理解传统遗传算子的局限性，图 9.1 展示了遗传算子与梯度下降（GD）在优化多峰函数时搜索行为的差异，函数为`f(x)`。具体而言，以常用的遗传算子模拟二进制交叉（SBX）[\[35\]](#c09.xhtml#c09-bib-0035)在图 9.1(a)中为例，生成的后代解分布在父代`x`的两侧，因为`SBX`随机决定搜索方向并允许探索更多未知区域。换句话说，`SBX`导致了许多不必要的搜索尝试，在高维搜索空间中优化 DNN 的权重时这一问题变得更加严重。相比之下，GD 方法表现出更好的开发能力，因为搜索方向始终与`x`的梯度相反，如图 9.1(b)所示。然而，不合适的步长（由学习率决定）可能会使`x`陷入局部最优。

**图 9.1** 模拟二进制交叉 (SBX) 和梯度下降在最小化问题`f(x)`上的。(a) 遗传算子 (SBX) 生成后代解。(b) 梯度下降生成的后代解。(c) 将 SBX 与梯度下降结合生成的后代解。

如图 9.1(c)所示，`SBX`的弱点（即它只在预期方向上生成后代解）可以通过`GD`来修复。反之，梯度方法对局部最优的脆弱性可以通过遗传算子来缓解。具体而言，在遗传算子中引入梯度信息可以引导搜索行为向有前景的方向移动，同时生成多个后代解可以显著减少陷入局部最优的概率，并提高`GD`的探索能力。此外，这种组合消除了对学习率的使用，而学习率难以预定义或适应。遵循上述基本思想，下面将介绍一种针对 DNN 的梯度引导搜索方法。与通常为特定类型 DNN 设计的现有相比，提出的方法适用于不同类型的 DNN。

#### 9.2.2.2 模拟二进制交叉

近年来，针对实数编码遗传算法（EAs）提出了许多交叉算子，如`SBX`、`UNDX`[\[40\]](#c09.xhtml#c09-bib-40)和`DE`[\[41\]](#c09.xhtml#c09-bib-41)。在这些交叉算子中，`SBX`在大多数问题上表现更好[\[42\]](#c09.xhtml#c09-bib-42)。因此我们采用`SBX`作为基础遗传算子，它被广泛应用于连续优化问题。形式上，给定具有`n`个变量的两个父代`x_1`和`x_2`，`SBX`通过(9.3)生成后代解`c_1`和`c_2`：

```
c1^i = (1 + beta) * x1^i + (1 - beta) * x2^i / 2,
c2^i = (1 - beta) * x1^i + (1 + beta) * x2^i / 2,
1 <= i <= n
```

其中`x_1^i`表示决策向量`x_1`的第`i`个变量，`beta`是一个需要每个维度重新生成的随机值。
