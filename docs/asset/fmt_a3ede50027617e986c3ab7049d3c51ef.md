
```math
ℓ(θ) = log P(D | θ)
     = log ∑_z P(D, z | θ)
     = log ∑_z P(D | z, θ) P(z | θ)
     = log ∑_z \frac{P(z | D, θ^(t-1)) P(D | z, θ) P(z | θ)}{P(z | D, θ^(t-1))}
     = log ∑_z P(z | D, θ^(t-1)) \frac{P(D | z, θ) P(z | θ)}{P(z | D, θ^(t-1)) P(D | θ^(t-1))} P(D | θ^(t-1))
     ≥ ∑_z P(z | D, θ^(t-1)) log \frac{P(D | z, θ) P(z | θ)}{P(z | D, θ^(t-1)) P(D | θ^(t-1))}
     = ∑_z P(z | D, θ^(t-1)) log \frac{P(D | z, θ) P(z | θ)}{P(z | D, θ^(t-1))} - log P(D | θ^(t-1))
```


由于期望完全数据对数似然 `Q` 是通过丢弃 `B(θ, θ^(t-1))` 中关于 `θ` 为常数的项而得到的，因此它也是 `ℓ(θ)` 的一个下界的下界。

```math
    = \arg \max_θ [ℓ(θ^(t-1)) + ∑_z P(z | D, θ^(t-1)) log \frac{P(D | z, θ) P(z | θ)}{P(z | D, θ^(t-1)) P(D | θ^(t-1))}]
```

##### 11.4.11.1 F 函数的极大化-极大化算法

**定义 11.1。** 给定隐变量 Z 的概率分布为 `˜(Z)`，定义 F 函数如下：

```
˜ ˜ F(P,θ) = E ˜[logP(X,Z|θ)] + H(P) (11.34)
```

其中 `H(P) = −E ˜[log ˜P(Z)]`，即 `˜P(Z)` 的熵。

假设 `θt−1` 是第 (t−1) 次迭代中 `θ` 的估计，`˜t−1` 是第 (t−1) 次迭代中 `˜P` 的估计。则第 t 次迭代的两个步骤为：

1. 固定 `θt−1`，寻找使 `F(˜P, θt−1)` 极大化的 `˜t`；

2. 固定 `˜t`，寻找使 `F(˜Pt, θ)` 极大化的 `θt`。

**引理 11.1。** 对于固定的 `θ`，仅存在一个分布 `˜Pθ` 使 `F(˜P, θ)` 极大化：

```
˜Pθ(Z) = P(Z|X,θ) (11.35)
```

**证明。** 给定固定的 `θ`，我们可以得到使 `F(˜P, θ)` 极大化的 `˜θ`。我们构造拉格朗日函数：

```
˜ log ˜Pθ(Z)
L(˜P, θ) = E ˜[logP(X,Z|θ)] − E ˜[P] + λ(1 − ∑P(Z))
Z
```

对 `˜Pθ(Z)` 求偏导数，得到：

```
∂L/∂˜Pθ(Z) = logP(X,Z|θ) − log ˜Pθ(Z) − 1 − λ
```

令其等于 0，可得 `λ = logP(X,Z|θ) − log ˜θ(Z) − 1`。

然后我们可以推导出 `˜Pθ(Z)` 与 `P(X,Z|θ)` 成正比：

```
P(X,Z|θ) = e1+λ ˜Pθ(Z)
˜Pθ(Z) = P(X,Z|θ) / e1+λ
∑P(X,Z|θ) = 1
Z
⇒ e1+λ = ∑P(X,Z|θ) = P(X|θ)
Z
⇒ ˜Pθ(Z) = P(X,Z|θ) / P(X|θ) = P(Z|X,θ)
```

**引理 11.2。** 若 `˜Pθ(Z) = P(Z|X,θ)`，则：

```
˜F(P, θ) = logP(X|θ) (11.37)
```

**定理 11.2.** EM 算法的一次迭代可以实现为 F 函数的极大化-极大化。

**证明。**

(1) 根据引理 11.1，可得 `˜Pt(Z) = P(Z|X,θt−1)`。

(2) 根据上述，可得：

```
˜F(Pt, θ) = E ˜t[logP(X,Z|θ)] + H(Pt)
= ∑P(Z|X,θt−1)logP(X,Z|θ) + H(Pt)
Z
= Q(θ, θt−1) + H(Pt)
```

且 `˜Pθ` 关于 `θ` 连续。则使 `F(˜Pt, θ)` 极大化的 `θt` 为：

```
θt = arg max F(Pt, θ) = arg max Q(θ, θt−1)
θ θ
```

##### 11.4.11.2 广义 EM 算法 (GEM)

在上述 EM 算法的公式化中，`θt` 被选为使 `Q(θ, θt−1)` 极大化的 `θ` 值。虽然这确保了 `ℓ(θ)` 最大程度地增加，但可以将极大化的要求放宽为仅增加 `Q(θ, θt−1)`，即 `Q(θt, θt−1) ≥ Q(θt−1, θt−1)`。这种仅增加而不一定极大化 `Q(θt, θt−1)` 的方法称为**广义期望极大化 (GEM)** 算法，在极大化困难的情况下通常很有用。GEM 算法的收敛性与 EM 算法类似。

### 11.5 潜变量模型的模型选择

使用 LVM 时，我们必须指定潜变量的数量，这控制着模型复杂度。特别是对于混合模型，我们必须指定 K，即聚类的数量。选择这些参数是模型选择的一个例子。下面我们讨论一些方法。

#### 11.5.1 概率模型的模型选择

第 5.3 节讨论的最优贝叶斯方法是选择边际似然 `K = arg maxk p(D|k)` 最大的模型。这存在两个问题。首先，对 LVM 计算边际似然相当困难。实践中，可以使用简单的近似，如 BIC（参见例如 Fraley and Raftery 2002）。或者，我们可以使用交叉验证似然作为性能度量，尽管这可能很慢，因为它需要拟合每个模型 F 次，其中 F 是 CV 折数。第二个问题是需要在潜在的大量模型中搜索。通常的方法是对所有候选 K 值进行穷尽搜索。然而，有时我们可以将模型设置为最大规模，然后依靠贝叶斯奥卡姆剃刀的力量来消除不需要的组件。第 TODO 21.6.1.6 节将展示一个例子，届时我们将讨论变分贝叶斯。另一种方法是在模型空间中进行随机采样。传统方法（如 Green 1998, 2003; Lunn et al. 2009）基于可逆跳 MCMC，使用出生移动来提议新中心，使用死亡移动来消除旧中心。然而，这可能很慢且难以实现。一种更简单的方法是使用狄利克雷过程混合模型，它可以使用吉布斯采样进行拟合，但仍允许无限数量的混合成分；详见第 TODO 25.2 节。也许令人惊讶的是，这些基于采样的方法可能比单独评估每个 K 质量的简单方法更快。原因在于为每个 K 拟合模型通常很慢。相比之下，采样方法通常能快速确定某个 K 值较差，因此无需在后验的该部分浪费时间。

#### 11.5.2 非概率方法的模型选择

如果我们不使用概率模型怎么办？例如，如何为 K-means 算法选择 K？由于这不对应概率模型，因此没有似然，所以上述方法都无法使用。似然的一个明显代理指标是重构误差。定义使用模型复杂度 K 对数据集 D 的平方重构误差如下：

```
E(D, K) ≜ 1/N ∑|xi − x̂i|² (11.38)
|D| i=1
```

对于 K-means，重构由 `xi = µzi` 给出，其中 `zi = arg mink ||xi − µk||²`，如第 11.4.2.6 节 TODO 所述。在监督学习中，我们总是可以使用交叉验证在不同复杂度的非概率模型之间进行选择，但无监督学习则不然。最常用的方法是绘制训练集上的重构误差随 K 变化的曲线，并尝试识别曲线中的肘部或拐点。

# 因子分析

## 12.1 因子分析模型

我们看到因子分析（FA）使用低秩分解来近似可见向量的协方差矩阵：

$$p(z_i) = \mathcal{N}(z_i | 0, I) \tag{12.4}$$

$$p(x_i | z_i, \theta) = \mathcal{N}(x_i | W z_i + \mu, \Psi) \tag{12.5}$$

$$C = \text{cov}[x] = W W^T + \Psi \tag{12.6}$$

如果观测值也是连续的，即 $x_i \in \mathbb{R}^D$，我们可以对似然使用高斯分布。就像在线性回归中一样，我们假设均值是（隐藏）输入的线性函数，从而得到：

$$p(z_i) = \mathcal{N}(z_i | \mu_0, \Sigma_0) \tag{12.1}$$

$$p(x_i | z_i, \theta) = \mathcal{N}(x_i | W z_i + \mu, \Psi) \tag{12.2}$$

这仅使用 $O(LD)$ 个参数，这在具有 $O(D²)$ 个参数的全协方差高斯分布和具有 $O(D)$ 个参数的对角协方差之间提供了灵活的折中。注意，如果我们不限制 $\Psi$ 为对角矩阵，我们可以将 $\Psi$ 简单地设为全协方差矩阵；然后我们可以设置 $W = 0$，在这种情况下不需要潜在因子。

其中 $W$ 是一个 $D \times L$ 矩阵，称为**因子载荷矩阵**，$\Psi$ 是一个 $D \times D$ 协方差矩阵。我们取 $\Psi$ 为对角矩阵，因为模型的全部意义在于强制 $z_i$ 来解释相关性，而不是将其内置到观测值的协方差中。这个整体模型称为**因子分析**（FA）。$\Psi = \sigma² I$ 的特殊情况称为**概率主成分分析**（PPCA）。这个名称的原因稍后将变得明显。

#### 12.1.1 FA 是多元正态分布的低秩参数化

FA 可以被认为是一种使用少量参数在 $x$ 上指定联合密度模型的方法。要理解这一点，请注意根据公式 4.39，诱导的边缘分布 $p(x_i | \theta)$ 是高斯分布：

$$p(x_i | \theta) = \int \mathcal{N}(x_i | W z_i + \mu, \Psi) \mathcal{N}(z_i | \mu_0, \Sigma_0) dz_i = \mathcal{N}(x_i | W \mu_0 + \mu, \Psi + W \Sigma_0 W^T) \tag{12.3}$$

#### 12.1.2 潜在因子的推断

$$p(z_i | x_i, \theta) = \mathcal{N}(z_i | \mu_i, \Sigma_i) \tag{12.7}$$

$$\Sigma_i = (\Sigma_0^{-1} + W^T \Psi^{-1} W)^{-1} \tag{12.8}$$

$$= (I + W^T \Psi^{-1} W)^{-1} \tag{12.9}$$

$$\mu_i = \Sigma_i [W^T \Psi^{-1} (x_i - \mu) + \Sigma_0^{-1} \mu_0] \tag{12.10}$$

$$= \Sigma_i W^T \Psi^{-1} (x_i - \mu) \tag{12.11}$$

注意在 FA 模型中，$\Sigma_i$ 实际上与 $i$ 无关，因此我们可以用 $\Sigma$ 表示它。计算此矩阵需要 $O(L³ + L² D)$ 时间，计算每个 $\mu_i = \mathbb{E}[z_i | x_i, \theta]$ 需要 $O(L² + LD)$ 时间。$\mu_i$ 有时被称为**潜在得分**或**潜在因子**。

#### 12.1.3 不可识别性

就像混合模型一样，FA 也是不可识别的。要理解这一点，假设 $R$ 是一个任意的正交旋转矩阵，满足 $R R^T = I$。让我们定义 $\tilde{W} = W R$，那么这个修改后矩阵的似然函数与未修改矩阵的相同，因为 $\tilde{W} \tilde{W}^T + \Psi = W R R^T W^T + \Psi = W W^T + \Psi$。从几何上讲，用正交矩阵乘以 $W$ 就像在生成 $x$ 之前旋转 $z$。为了确保唯一解，我们需要移除 $L(L-1)/2$ 个自由度，因为这是 $L \times L$ 正交矩阵的数量。

总的来说，FA 模型有 $D + LD - L(L-1)/2$ 个自由参数（不包括均值），其中第一项来自 $\Psi$。显然我们要求这小于或等于 $D(D+1)/2$，这是无约束（但对称）协方差矩阵中的参数数量。这给出了 $L$ 的上界：

$$L_{\text{max}} = D + 0.5(1 - \sqrt{1 + 8D}) \tag{12.12}$$

例如，$D = 6$ 意味着 $L \le 3$。但我们通常从不选择这个上界，因为它会导致过拟合（参见第 12.3 节关于如何选择 $L$ 的讨论）。不幸的是，即使我们设置 $L < L_{\text{max}}$，我们仍然无法唯一识别参数，因为旋转模糊性仍然存在。不可识别性不影响模型的预测性能。然而，它确实影响载荷矩阵，从而影响潜在因子的解释。由于因子分析常用于发掘数据中的结构，因此需要解决这个问题。以下是一些常用的解决方案：

*   **强制 $W$ 为正交规范化** 解决识别性问题最清晰的方法可能是强制 $W$ 为正交规范化，并按相应潜在因子方差的降序排列列。这是 PCA 采用的方法，我们将在第 12.2 节讨论。结果不一定更具可解释性，但至少是唯一的。

*   **强制 $W$ 为下三角矩阵** 实现识别性的一种方法，在贝叶斯社区很流行（例如 Lopes and West 2004），是确保第一个可见特征仅由第一个潜在因子生成，第二个可见特征仅由前两个潜在因子生成，依此类推。例如，如果 $L = 3$ 且 $D = 4$，对应的因子载荷矩阵由下式给出：

    $$W = \begin{pmatrix} w_{11} & 0 & 0 \\ w_{21} & w_{22} & 0 \\ w_{31} & w_{32} & w_{33} \\ w_{41} & w_{42} & w_{43} \end{pmatrix}$$

    我们还要求 $w_{jj} > 0$ 对于 $j = 1:L$ 成立。这个受约束矩阵中的参数总数是 $D + DL - L(L-1)/2$，等于可唯一识别参数的数量。这种方法的缺点是前 $L$ 个可见变量（称为**奠基变量**）影响潜在因子的解释，因此必须仔细选择。
