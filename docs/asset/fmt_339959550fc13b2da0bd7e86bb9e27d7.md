
## 20. 抽象 (Abstracts)

在之前的章节中，我们学习了如何使用继承在类之间共享公共属性和方法，有效地创建一个模板。在本章中，我们将基于之前的知识继续学习。感到兴奋吗？让我们直接开始吧。

## 抽象类 (Abstract Classes)

对于某些类来说，它们的唯一目的是提供公共的属性和方法。它们为此而生。当它们在晚上睡觉时，梦的都是这个。

它们永远无法被实例化，因为它们本身没有意义。考虑以下类，为了清晰起见，我将它们留空了。

**示例 01：类继承。**

虽然`Animal`类可能为`Panda`（熊猫）、`Owl`（猫头鹰）和`Giraffe`（长颈鹿）类提供许多共享特征，但直接实例化是没有意义的。我们的`Animal`类是抽象类的典型例子。让我们把它变成抽象类吧。

## 抽象 (Abstracts)

### 示例 02：抽象类 Animal。

```php
<?php

abstract class Animal {

    /**
     * 动物是否很棒（都是如此）。
     *
     * @var boolean
     */
    private $awesome = true;

    /**
     * 获取 awesome 属性。
     *
     * @return boolean
     */
    public function isAwesome() {
        return $this->awesome;
    }

}
```

在上面的示例中，我们仅通过在类定义开头使用`abstract`关键字将类声明为抽象类。其他所有内容应该看起来都很熟悉。如果我们扩展这个类，我们所有的动物都会继承`isAwesome()`方法。

让我们尝试直接实例化`Animal`类。

### 示例 03：创建一个新的 Animal 实例。

```php
$animal = new Animal();
```

当我们执行代码时会发生什么？

### 示例 04：输出。

```
Fatal error: Cannot instantiate abstract class Animal in <file> on line <line>.
```

现在我们的类被标记为抽象类，它不再可以被实例化。这是符合预期的，因为该类只有一个目的，就是为其他类提供功能。

## 抽象方法 (Abstract Methods)

抽象方法用在抽象类内部。再次，使用`abstract`关键字来定义抽象方法。让我们从一个示例开始。

**示例 05：一个抽象方法。**

```php
<?php

abstract class Animal
{
    abstract public function makeNoise();
}
```

我们在作用域之前使用`abstract`关键字定义了一个名为`makeNoise()`的新方法。你会注意到`makeNoise()`方法没有方法体，而是直接以分号结束。

多么毫无意义的方法！

你说得对。就其本身而言，它确实毫无意义。事实上，抽象方法甚至无法被调用。那么为什么要费心呢？嗯，抽象方法与所有扩展它的类形成了一种类型的“合同”。它在告诉 PHP：“任何扩展此类的类**必须**定义一个`makeNoise()`方法。”让我们通过添加另一个类来演示这一点。

**示例 06：扩展 Animal 类。**

```php
<?php

abstract class Animal
{
    abstract public function makeNoise();
}

class Dog extends Animal
{
}
```

我们在`Dog`类中扩展了基类`Animal`。让我们尝试实例化一个新的`Dog`，好吗？

### 示例 07：创建一个新的 dog 实例。

```php
$dog = new Dog;
```

现在我们只需执行代码然后……哦不不。

### 示例 08：输出。

```
PHP Fatal error: Class Dog contains 1 abstract method and must therefore be declared abstract or implement the remaining methods (Animal::makeNoise) in <file> on line <line>.
```

幸运的是，我一直觉得 PHP 错误很容易理解。PHP 正在告诉我们我们的`Dog`类包含一个来自基类`Animal`的抽象方法`Animal::makeNoise`。

PHP 给了两个选项。首先，我们可以让`Dog`类也变成抽象类，这意味着它同样无法被实例化。这不是我们想要的，因为该类只有一个目的，即为其他类提供功能。第二个选项是实现该方法。让我们通过这种方式来完善。

**示例 09：实现 makeNoise 方法。**

```php
<?php

class Dog extends Animal
{
    public function makeNoise()
    {
        echo "Woof!";
    }
}
```

通过实现方法，该类不再是抽象的。我们现在可以实例化了。

**示例 10：实例化一个 dog。**

```php
$dog = new Dog();
```

输出：

```
Woof!
```

## 21. 接口 (Interfaces)

在之前的章节中，我们学习了如何使用继承在类之间共享公共属性和方法，有效地创建一个模板。

**示例 01：抽象类。**

```php
<?php

abstract class Animal
{
    echo 'I am!';
    abstract function sleep();
}
```

接口与抽象类非常相似，但它们不能包含逻辑。它们纯粹是为了定义类必须做什么。

**示例 02：接口。**

```php
<?php

interface PandaInterface
{
    /**
     * Eat food.
     */
    public function eat($food);

    /**
     * Poop!
     */
    public function poop();

    /**
     * Sleep time!
     */
    public function sleep($time);
}
```

我们使用`interface`关键字定义接口。像抽象类一样，它们不能被实例化。虽然不是强制的，但在名称后添加`Interface`后缀是一个良好的习惯。

**示例 03：实现接口。**

```php
<?php

class Panda implements PandaInterface
{
    public function eat($food)
    {
        echo "Eating $food...";
    }

    public function poop()
    {
        echo "Pooping...";
    }

    public function sleep($time)
    {
        echo "Sleeping for $time hours...";
    }
}
```

通过实现接口，`Panda`类不再是抽象的。我们现在可以实例化它。

**示例 04：实例化一个 panda 实例。**

```php
$panda = new Panda();
$panda->eat('bamboo');
$panda->poop();
$panda->sleep(8);
```

输出：

```
Eating bamboo...
Pooping...
Sleeping for 8 hours...
```

## 多态 (Polymorphism)

多态是一个糟糕的词，但是一种极佳的技术。我在网上找到的所有解释都复杂且令人恐惧。相反，让我们从一个示例开始。我们将利用我们的`PandaInterface`。它强制实现三个方法。

**示例 05：实际中的多态。**

```php
<?php

class Panda implements PandaInterface
{
    public function eat($food)
    {
        echo "Eating $food...";
    }

    public function poop()
    {
        echo "Pooping...";
    }

    public function sleep($time)
    {
        echo "Sleeping for $time hours...";
    }
}

class Bear implements PandaInterface
{
    public function eat($food)
    {
        echo "Eating $food...";
    }

    public function poop()
    {
        echo "Pooping...";
    }

    public function sleep($time)
    {
        echo "Sleeping for $time hours...";
    }
}

$animals = [
    new Panda(),
    new Bear()
];

foreach ($animals as $animal) {
    $animal->eat('food');
    $animal->poop();
    $animal->sleep(8);
}
```

多态的优之处在于，只要它们实现了相同的接口，我们就可以将不同的对象视为相同的类型。这使得我们的代码更加灵活且易于扩展。

### 示例 06: PandaInterface 接口。

```php
<?php

interface PandaInterface
{
    /**
     * 吃食物！
     */
    public function eat();

    /**
     * 泄便！（通常在吃之后。）
     */
    public function poop();

    /**
     * 睡觉时间！
     */
    public function sleep();
}
```

我剥离了一些参数以简化示例。让我们创建两个实现此接口的类。这是第一个。

### 示例 07: RedPanda 类。

```php
<?php

class RedPanda implements PandaInterface
{
    /**
     * 吃一些食物！
     */
    public function eat()
    {
        echo "The red panda eats some fruit.\n";
    }

    /**
     * 泄便！（通常在吃之后。）
     */
    public function poop()
    {
        echo "The red panda takes a poop.\n";
    }

    /**
     * 睡觉时间！
     */
    public function sleep() {
      echo "The red panda sleeps up a tree.\n";
    }
}
```

接下来，我们有第二个类来代表大熊猫。

### 示例 08: GiantPanda 类。

```php
<?php

class GiantPanda implements PandaInterface {
    /**
     * 吃一些食物！
     */
    public function eat() {
      echo "The giant panda eats some bamboo.\n";
    }

    /**
     * 泄便！（通常在吃之后）。
     */
    public function poop() {
      echo "The giant panda takes a giant poop.\n";
    }

    /**
     * 睡觉时间！
     */
    public function sleep() {
      echo "The giant panda sleeps on the ground.\n";
    }
}
```

## 接口

是时候创建一个新类了。我们将称称为 ZooKeeper（动物园员）。这个类没有继承任何其他类，也没有实现任何接口。

### 示例 09: ZooKeeper 类。

```php
<?php

class ZooKeeper
{
    /**
     * 照顾熊猫。
     *
     * @param PandaInterface $panda
     * @return void
     */
    public function care(PandaInterface $panda)
    {
        // 执行熊猫的操作。
        $panda->eat();
        $panda->poop();
        $panda->sleep();
    }
}
```

`ZooKeeper`类包含一个照顾熊猫的单一方法。我们没有直接对`RedPanda`或`GiantPanda`类进行类型提示，而是对接口本身进行了类型提示。

这意味着，任何实现了`PandaInterface`接口的类都可以作为参数传递给`care()`方法。不仅如此，由于我们直接对接口进行了类型提示，我们可以确定传递给方法的实例将拥有三个方法：`eat()`、`poop()`和`sleep()`。

让我们尝试一下我们的`ZooKeeper`类。

### 示例 10: 成为一名动物园员。

```php
<?php

// 创建熊猫实例
$redPanda = new RedPanda;
$giantPanda = new GiantPanda;

// 创建动物园员。
$keeper = new ZooKeeper;

// 照顾两只熊猫。
$keeper->care($redPanda);
$keeper->care($giantPanda);
```

首先，我们实例化两个熊猫的实现。接下来，我们创建了一个新的`ZooKeeper`实例。最后，我们调用了两次`care()`方法，传递了两个熊猫实现。

让我们检查结果。

### 示例 11: 输出。

- 小熊猫吃了一些水果。
- 小熊猫拉了一次便。
- 小熊猫爬上树去睡觉。
- 大熊猫吃了一些竹子。
- 大熊猫拉了一次大便。
- 大熊猫在地上睡觉。

你看到，我们拥有的是什么种类的熊猫并不重要。只要它符合熊猫的正确形状，我们就能确定它能吃、睡觉和泄便。类型提示接口是我们对这些方法存在的保证。

多态。一个简单的概念，却是一个复杂的世界！它也极其有用。假设你写了一个`Tax`类，它需要将一些税收信息写入长期数据存储器。我们可以创建一个带有`read()`和`write()`方法的`DataStoreInterface`。这样，我们就可以创建写入磁盘、写入数据库或写入远程文件系统的数据存储器，而它们都是可以互换的。我们可以让用户来决定。这就是创建优秀应用程序的方法。这就是力量。
