# 5 草药与常规药物相互作用的预测建模

Pooja Khurana, Richa Gupta, Deepak Kumar, and Devendra Kumar

DOI: [10.1201/9781003467281-6](https://doi.org/10.1201/9781003467281-6)

## 5.1 引言

草药通常被认为是合成药物的天然且安全的替代品，几个世纪以来传统医学的基石。在过去的几十年里，在全球范围内日益普及，许多人在接受处方药物治疗的同时加入了草药疗。草药和常规药物疗法代表了两个不同但相互关联的医疗支柱，各自具有独特的历史意义和治疗价值 (Dong, 2013)。

草药治疗根于跨越千年、文化和文明的传统医疗实践，涵盖广泛的健康状况。草药使用植物源材料，如叶子、根部、树皮、花和种子，草药通常制成茶、酊剂、提取物、粉末或胶囊。它们可能包含具有多种药理作用的复杂生物活性化合物混合物 (Saad et al., 2017)。另一方面，常规药物疗法包含了通过现代药物研究过程开发的合成或半合成化合物；这些药物在批准临床使用之前经过了安全性、有效性和质量控制的严格测试。常规药物通常针对疾病发病机制相关的特定分子通路或生物靶标，并由医疗专业人员根据证据指南和监管标准进行处方。

然而，两者结合的增长趋势引发了人们对常规药物与草药之间潜在相互作用的关注——草药-药物相互作用（HDIs），这可能会损害药效、增强毒性或导致不可预见的副作用。尽管草药成分是天然的，但它们可能与代谢和介导药物作用的相同酶、受体和转运体相互作用。随着在临床实践中使用常规药物配合草药变得越来越普遍，理解 HDI 已变得至关重要。这些相互作用会深地影响治疗效果、患者安全和医疗结果，凸显了阐明其机制的重要性 (Izzo and Ernst, 2009)。

在本章中，我们探讨了预测建模的数学方法，重点介绍了当前的应用、挑战和未来方向。

## 5.2 HDI 预测建模的数学方法

### 5.2.1 机器学习算法

ML 算法是基于数据集预测相互作用的强大工具。

#### 5.2.1.1 支持向量机

支持向量机（SVMs）是强大的监督机器学习模型，主要用于分类和回归。在分类中，它们被用于根据输入特征区分类别。例如，在药学领域，SVM 可以根据特征对草药与药物之间的相互作用进行分类 (Burbidge et al., 2001)，如下：

```
f(x) = \sum_{i = 1}^{n}\alpha_{i}y_{i}K(x_{i},x) + b
```

(5.1)

其中

- `f(x)` 是预测输入样本 `x` 类别标签的决策函数。
- `\alpha_{i}` 是在 SVM 训练期间获得的系数。
- `y_{i}` 是训练样本的类别标签。
- `K(x_{i},x)` 是计算 `x` 与第 `i` 个训练样本 `x_{i}` 之间性的核函数。
- `b` 是偏置项。

#### 5.2.1.2 随机森林

随机森林（RF）是一种集成学习技术，它在训练期间构建多棵决策树，并通过对树进行多数投票来进行预测。这种方法在分类任务中比单一决策树更准确，因为它降低了过拟合风险。RF 通过为每棵树创建不同的数据和特征子集来工作，有助于模型捕捉数据集中的复杂模式。值得注意的是，RF 更好地预测了 HDI 并比传统方法更准确 (Shi et al., 2019)。

```
y(x) = \frac{1}{N}\sum_{i = 1}^{N}T_{i}(x)
```

(2)

其中

- `y(x)` 是 `x` 的预测类别标签。
- `N` 是森林中决策树的数量。
- `T_{i}(x)` 是第 `i` 棵决策树对 `x` 的预测。

#### 5.2.1.3 逻辑回归

逻辑回归是一种广为人知的线性模型，经常用于二分类问题。与预测连续结果的线性回归不同，逻辑回归侧重于估计事件属于两个类别之一的概率。它使用逻辑函数（或 sigmoid 函数）来确保预测值落在 `0` 和 `1` 之间，代表概率。这使其成为处理需要二元结果任务的实用工具，例如 `yes/no` 或 `true/false` 场景。在 `HDIs` 领域，逻辑回归用于根据关键输入特征（如药物的 `types` 类型、剂量 `dosage_amounts` 或特定的 `patient_attributes` 患者属性）来预测相互作用发生的概率（Ramos-Esquivel et al., 2017; Bazrafshani et al., 2023）。值得注意的是，尽管该模型非常简单，但其清晰解释结果和高效处理大型数据集的能力使其成为广泛使用的技术，特别是在医疗保健和其他需要二分类任务的领域：

```
p(y = 1 \mid x) = \frac{1}{1 + e^{- {({\beta_{0} + \beta_{1}x_{1} + \beta_{2}x_{2} + \ldots + \beta_{n}x_{n}})}}}
```

(3)

其中

- `p(y = 1 \mid x)` 是给定输入特征 `x` 的情况下，类别标签 `p(y = 1 \mid x)` 为 `y` 的概率。
- `β[0]`，`β[1]`，`…β[n]` 是逻辑回归模型的系数。
- `x[1]`，`x[2]`，`…x[n]` 是输入特征。

### 5.2.2 药代动力学/药效动力学模型

药代动力学/药效动力学（`PK/PD`）模型是药理学中的关键工具，用于理解药物浓度（药代动力学）与其对生理的影响（药效动力学）之间的动态相互作用。这些模型有助于预测药物如何被吸收、分布、代谢和排泄，以及这些因素与药物的治疗效果或副作用之间的关系。`PK/PD` 模型对于模拟常规药物和草本化合物在体内的行为特别有价值，能够对协同效应、毒性或药物效力降低做出更好的预测。研究人员已多种 `PK/PD` 模型，包括房室模型、基于生理的药代动力学 (`PBPK`) 模型和基于人群的 `PK` 模型，以模拟和预测相互作用，并更好地结合草本补充剂和处方药相关的风险。

### 5.2.3 房室模型

房室模型将人体分为不同的房室，即不同的生理或解剖区域，如血液、组织和器官。药物在这些房室之间的运动通过微分方程描述，允许研究人员模拟药物在身体不同区域的吸收、分布、代谢和消除。对于 `HDIs`，房室 `PK/PD` 模型已用于模拟草本-药物化合物的浓度-时间曲线（Sharan et al., 2012; Colom et al., 2011）。这些模型通过考虑代谢（身体如何分解化合物）、分布（药物在房室间如何移动）和排泄（身体如何排出物质）等关键因素来预测相互作用。本质上，它们有助于理解草本和药物化合物在合用时如何相互作用，揭示潜在的药物有效性或毒性。公式 (4) 给了一个单房室 `PK` 模型：

```
\frac{dC}{dt} = - k \cdot C
```

(4)

其中

- `C` 是房室中药物的浓度。
- `k` 是消除速率常数。

### 5.2.4 PBPK 模型

基于生理的药代动力学模型是先进工具，它们将生理信息与药物特定参数相结合，以预测随时间变化的药物浓度。与传统模型不同，PBPK 建模通过整合器官体积、血流速度等详细信息，对药物在体内的行为提供了更全面的机理理解。PBPK 模型在研究 `HDIs` 时特别有价值，因为它们考虑了影响药物行为的关键因素，例如影响药物可用性的蛋白结合、决定药物分解速度的代谢过程，以及促进或阻碍药物跨越不同器官细胞膜的转运蛋白作用。通过考虑这些变量，PBPK 建模允许研究人员模拟草本化合物和药物在体内相互作用的真实情景。PBPK 模型是增强草本与常规药物联合治疗安全有效性的重要资源（Huang, 2012; Vieira and Huang, 2012; Huang et al., 2020）。公式 (5) 给出了基础 PBPK 模型：

```
\frac{dC}{dt} = \frac{D}{V} - k_{elim~} \cdot C
```

(5)

其中

- `D` 是药物剂量。
- `V` 是分布容积。
- `k[elim]` 是消除速率常数。

#### 5.2.4.1 人群 PK 模型

人群 `PK` 模型是药理学中的重要工具，旨在解释个体之间药物浓度的差异。这些模型考虑了不同因素如何影响暴露反应，使医疗保健人员能够准确预测不同人群的药物浓度。通过纳入年龄、性别、体重、遗传因素和合并用药等变量，人群模型提供了关于这些因素如何影响吸收、分布、代谢和排泄的见解。

此外，PK/PD 模型通过识别为个体患者定制的最优治疗策略，促进了药物方案的优化。通过评估剂量和给药时间等因素如何影响药效，医疗专业人员可以增强治疗效果并提高患者安全性。最终，这些模型在最小化副作用和最大化治疗效果方面发挥了无价工具的作用，为更安全、更有效的医疗实践做出贡献。

### 5.2.5 网络分析

网络分析是 HDI（中药-药物相互作用）预测建模中采用的一种非常有效的方法，用于揭示和理解草药化合物、药物与生物学靶点之间复杂的关系。这种方法涉及构建和评估代表跨多个生物组织水平（如分子水平、细胞水平和系统水平）的相互作用的网络。通过这种方式，网络分析可以对 HDI 的底层机制提供深层见解，帮助预测草药制剂与传统药物之间的潜在相互作用。这使得药物开发和临床应用均能够做出更明智的决策，提高患者安全性和治疗效果。用于 HDI 预测建模的网络分析技术示例列如下：

#### 5.2.5.1 药物-靶点相互作用网络

药物-靶点相互作用网络展示了药物与其分子靶点（包括受体、酶或转运蛋白）之间的关系。研究人员通过整合来自不同来源的数据并进行分析，以识别由于共享生物学靶点或通路而可能发生的潜在 HDI。这种方法允许研究人员预测传统方法无法显现的相互作用，有助于理解草药化合物与药物联合用药时产生的影响。

```
W_{ij} = \frac{1}{1 + e^{-\beta \cdot S_{ij}}}
```

（7）

其中

- `W_{ij}` 是权重。
- `S_{ij}` 是相似性评分。
- `\beta` 是控制 sigmoid 函数斜度的参数。

#### 5.2.5.2 网络

HDI 网络描绘了草药化合物与药物之间的相互作用。通过整合关于草药成分、药物、代谢酶、共享的靶点和代谢通路的数据，这些网络可以预测协同效应或对抗的相互作用。这种全面的视角对于减少副作用和优化治疗至关重要，有助于实现更安全、更有效的医疗实践。Borse et al., 2019; Das et al., 2023。

#### 5.2.5.3 通路分析

通路分析是通过将草药化合物和药物映射到通路来预测 HDI 影响的关键工具。这种方法涉及识别受相互作用影响的关键通路，有助于理解机制和结果。通过检查这些网络的结构和动态，研究人员可以预测有益或有害的相互作用，确保治疗策略的安全：

```
p = \frac{n_{overlap}}{n_{background}}
```

（9）

其中

- `p` 是富集值。
- `n_{overlap}` 是共享基因的数量。
- `n_{background}` 是基因的总数。

## 5.3 HDI 的预测建模

### 5.3.1 数据预处理与特征选择

数据预处理在 HDI 预测建模中至关重要，确保数据的质量和相关性。这包括通过处理缺失值、删除重复项和处理异常值来清洗数据集。Kumar et al., 2024。此外，特征选择对于识别与 HDI 有关的信息丰富的特征同时降低维度至关重要。常用的单变量特征选择、递归特征消除和特征重要性排序等技术用于从包含草药药物信息的异构数据集中选择相关特征。Guyon and Elisseeff, 2003。

### 5.3.2 模型开发与验证

模型开发涉及使用各种算法和技术（如机器学习、统计建模和集成方法）构建预测模型。Singhal et al., 2022。这些模型旨在预测草药化合物与药物相互作用的可能性和结果。随后采用验证技术来评估开发模型的性能，确保其准确性和泛化能力。利用交叉验证、留出验证和外部验证等技术来评估模型性能并防止过拟合。Hastie et al., 2005。

### 5.3.3 集成异构数据源

整合异构数据源涉及结合来自多个来源的数据，包括分子数据库、文献和实验研究，以创建一个用于分析的统一数据集 (Boadh et al., 2022)。诸如数据融合、基于本体的集成和语义网等技术用于协调和整合异构数据源，能够对中药相互作用（HDI）进行整体分析，并有助于识别相关特征和预测模式 (Sokolov et al., 2013)。

### 5.3.4 模型解释性与说明性

解释性和说明性是 HDI 预测建模的关键方面，有助于理解 HDI 的底层机制，并为模型预测提供透明的解释。特征重要性分析、Shapley 相加性解释（SHAP）、局部可解释模型无关解释（LIME）和模型可视化等技术用于解释和说明影响 HDI 的因素。通过获得底层机制的洞解，利益相关者可以就中药和药物治疗优化以及个性化医疗方案做出明决策 (Lundberg and Lee, 2017)。这些方法 (Figure 5.2) 在开发准确、可靠且可解释的 HDI 预测模型方面发挥着至关重要的作用。通过系统地采用这些方法，研究人员可以推进对 HDI 的理解，并促进安全有效的中药和药物治疗的发展。

### 5.4 HDI 预测建模应用

HDI 的预测建模在各种应用中具有巨大的前景，为医疗保健的不同领域提供了宝贵的见解和支持。接下来我们将讨论预测建模的一些关键应用。

#### 5.4.1 临床决策支持系统

预测模型在临床决策支持系统中发挥着重要作用，帮助医疗专业人员就患者护理做出明智决策。这些先进系统分析大量的患者数据，例如病史、人口统计学、药物简介和其他相关信息，以预测潜在 HDI 的可能性，并向临床医生提供实时警报，显著增强了患者安全。它们不仅有助于预防不良事件，还有助于优化治疗方案，确保更个性化、更有效的护理。此外，通过早期识别潜在风险，医疗提供者可以定制治疗方案以满足患者需求，改善整体结果 (Nong et al., 2022)。随着技术的演进，预测模型与临床环境的整合将继续加强患者护理，降低风险并提高医疗服务的效率。

#### 5.4.2 药物研发与再利用

预测建模是药物发现和开发领域不可或缺的工具，因为它有助于识别植物化合物与传统药物之间的潜在相互作用。通过利用计算模型，研究人员可以分析分子结构、药理特性和生物通路，以预测 HDI 的可能性和可能的结果。这些数据提供了宝贵的见解，使科学家能够优先考虑有前景的候选化合物，设计更安全的药物组合，甚至将现有药物重新开发用于新的治疗目的。这些模型的使用显著加快了药物开发过程，减少了将有效疗法引入市场的时间和资源。此外，预测建模有助于扩大治疗选择，通过最大限地减少副作用，为患者提供更个性化、更安全的治疗。因此，它在推进药物研究和改善医疗结果方面发挥着关键作用 (Abbas et al., 2021)。

#### 5.4.3 个性化医疗与精准剂量
