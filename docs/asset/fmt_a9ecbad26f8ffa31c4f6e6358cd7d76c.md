# 16 基于量子安全的 VQA 图像过滤

**Avni Burman, Bhushan Bawaskar, Harsh Dindorkar 和 Hrithik Surjan**

*印度印多尔，Shri Vaishnav Vidyapeeth Vishwavidyalaya 科学工程系*

## 摘要

随着`VQA`（视觉问答）应用的日益广泛，许多应用已被运出，目前也有几项关于 VQA 的研究正在进行。在 VQA 中，我们构建并训练系统以对提供的数据（即图像和问题）给出正确答案。我们需要向模型提供图像和问题，但在直接融合问题（`Qi`）和图像（`Vi`）的特征元素时，存在许多问题，如图像和问题中的噪声。如果给定的图像有噪声，就没有准确性 [3]。这两个元素（`Qi`、`Vi`）不在同一个空间。为了解决这个问题，我们引入了图像过滤、差分网络及其融合。在当今世界，数据就是一切，保护数据应该是我们的首要任务。因此，为了保护 VQA，我们引入了 `RSA` 算法。`RSA` 算法将确保 VQA 免受任何入侵，并维护其真实性。

**关键词：** 视觉问答 (VQA)、差分网络 (DN)、图像过滤、中值滤波、rsa 算法、密码学、量子安全

## 16.1 引言

VQA [1, 2] 近年来由于其众多用途而蓬勃发展。该模型有效地合并了来自照片和问题的特征组件以完成 VQA 任务。构建一个能够响应图像和自然语言提交的查询的计算机系统，是 VQA 研究领域的重点 [1, 2]。最近，VQA 作为一种可以替代视觉测试的 AI 活动而受到关注。

图像使用线性和非线性算法进行过滤。图像过滤使得有利的图像处理活动变得可行。过滤器可以减少图像中不需要噪声和其他不良元素。与线性滤波器不同，非线性滤波器 [3] 的运行不同。非线性滤波器 [3] 的结果偏离了上述规则。均值滤波器是最容易使用的滤波器之一。图像的均值滤波器是平均平滑的。通过用每个像素周围像素的平均值替换，噪声被掩盖在图像背景中。[图 16.1] 显示了视觉问答系统。

某些 VQA 应用需要完全安全的敏感数据，因此需要维护数据的机密性、完整性和可用性 (CIA) [6, 7]。因此，为了确保安全，我们需要具有多个密钥的现代加密技术。

[8–10] `RSA` 算法由 Rivest、Shamir 和 Adleman 于 1978 年开发；因此名为 `RSA`。该算法使用非对称加密。作为一种非对称密码，它可以使用公钥和私钥运行，这是两个独立的密钥。从名称可以看出，公钥分给所有人，而私钥保持保密。`RSA` 使用质数，由于这种方法使用的整数足够大，因此解决起来很有挑战。RSA 密钥可能是 1024 或 2048 位，但研究人员认为超过 1204 密钥很快就会被破解。

量子加密利用量子物理原理创建一个更安全、更可靠的系统。没有人可以绕过这种机制而不让通信发送者或接收者察觉。由于无法在不引起注意的情况下测量系统的量子状态，量子加密依赖于光子及其底层量子特征来创建一个不可破解的加密系统。

[10–14] 量子加密提供了各种益处：

1. 安全通信
2. 它基于物理定律，使得量子加密更安全、更复杂。
3. 提供多种增加安全的方法。
4. 如果未经授权的用户尝试读取加密数据，量子状态就会发生改变并修改用户的预期结果。

量子加密的一些局限性是：

1. 光子在传输过程中可能会改变偏振，这可能会增加错误率。
2. 量子加密的最大范围在 400km 到 500km 之间。
3. 量子加密使用光纤链路和中继器。
4. 在量子通道中无法向两个或多个位置发送密钥。

## 16.2 相关工作

在研究了不同的概念后，我们了解到 VQA 的巨大应用，它以图像的形式生成关于问题的答案，模型高效地融合了来自图像和问题的特征元素。

当特征元素直接相互融合时，解决方案很大程度上忽略了以下两点：

1. `Vi` 和 `Qi` 是否在同一空间。
2. 如何减少 `Vi` 和 `Qi` 中的观测噪声。

因此，特征元素之间的差异 [7, 8]，例如 (`Vi − Vj`) 和 (`Qi − Qj`)，而差异操作将有助于减少观测噪声。在论文中，我们给出了一个图像和一个相关问题。现有 VQA 模型的基本结构由三个阶段组成：(i) 对图像和问题进行加密；(ii) 融合加密后的图像和问题元素；(iii) 对融合结果排序以获得答案。线性模型的融合表示为 `ViQi`，双线性模型表示为 `ViQj`。论文提到，差异操作可以有效减少 `Vi` 和 `Qi` 中潜在的观测噪声；让我们假设 `δ` 是特征元素 `Vi` 和 `Vj` 的噪声，那么 `(Vi + δ) − (Vj + δ)` 就能有效过滤噪声。

基于整数分解的算法的著名示例之一是 RSA，它是于 1978 年基于公钥加密概念提出的。该算法非常出色，启发了其他研究人员在密码学领域工作，并以 RSA 为基础提出了各种新的加密算法。

量子密码学起源于 Bennett、Bassard 和 Wiesner。后来，许多人对量子密码学和量子密钥分发做出了贡献。因此，在该模型中提出了差分网络（`DN`）和基于差分网络的融合（`DF`）。由于对神经网络进行了深入研究，引入了许多不同的方法来解决 VQA 任务。在这里，我们使用了“基于注意力的模型” [17, 18]。在该模型中，选择了输入信息中重要且有用的部分。在这里，我们使用该模型来验证差分网络的效率。量子密码学最基本的方法之一是量子密钥分发。光子流用于量子计算传输数据。这些光子具有称为“自旋”的特性。自旋可以分类为水平、垂直、45 对角或 45°对角。直角方案用于水平和垂直滤波器，而对角系统用于两个对角滤波器 [8, 9]。

在视觉问答（VQA）中，直接融合图像特征元素（`Vi`）和问题元素（`Qi`）时（即 `ViQi`），存在一些噪声和空间问题。因此，研究人员提出了一种差分网络，并借此使用了基于差分的融合方法。首先，当模型获取图像及其对应的问题时，问题和图像将分别使用 `GRU` 和 `RCNN` 进行编码。完成双方编码后，通过差分网络产生一个不同的方程；然后他们继续进行，并使用`differential network`融合应用融合机制。因此，在完成所有操作后，模型能够减少这些问题并正确回答。

### 提出的解决方案

除了差分网络外，我们还引入了一种名为“基于 VQA 的图像过滤”的应用或技术。

在基于视觉问答的模型中，我们给它一张图像和一个对应的问题。但在整个直接融合过程中，我们面临的主要问题是图像中的噪声没有减少，而且我们提供的输入图像可能存在噪声。

因此，在进一步处理之前，我们引入了图像过滤技术。基本上，过滤是一种用于减少噪声的技术，这些噪声可能是图像中的椒盐噪声或脉冲噪声。有许多用于过滤或减少图像噪声的技巧。它们可以分为线性滤波器和非线性滤波器，两种类型的工作方式不同。非线性滤波器进一步分为`Min filter`（最小滤波）、`Max filter`（最大滤波）和`Median filter`（中值滤波）。我们使用了`median filter`，因为它对于减少图像中的椒盐噪声非常有用。因此，如果图像有噪声，它可以有效减少，此时像素值被相邻像素的中值取代；此外，中值滤波是去除盐噪声的最佳方法之一。在完成图像过滤后，我们的图像将继续后续处理。图像将通过`RCNN`进行编码，相应的问题也将通过`GRU`进行编码。在对图像和问题进行编码后，继续进行，我们使用了`Differential Network`，它将获取图像和问题特征元素之间的差异，因为它们处于相同的空间，差异方程会更加合理，而且如果存在噪声，它们会被有效地忽略。此之后，将进行基于差分网络的融合，图像和问题的特征元素将得到融合。在完成所有这些任务后，我们的模型将提供更准确的答案。图 16.6 显示了指纹图像。

例如，图 16.6 显示了两个不同的指纹。在第一张图中，我们可以清楚地看到原始指纹有很多噪声，在应用了基于`median filter` 的 VQA 图像过滤技术后，右侧的指纹现在没有噪声了。

`RSA` 算法使用对数函数来保持计算足够的复杂性以抵抗暴力破解，同时保持足够的简洁以便部署后快速运行。`RSA`还可以加密解密通用信息以安全交换数据，并处理数字签名验证。上面的图像显示了`RSA`算法的整个过程。关于此点的更多将在下一节中解释。

## 16.6 结果分析

在基于 VQA 的差分网络中，输出是通过融合问题和答案产生的，借助基于 VQA 的`Differential Network fusion`，它可以忽略噪声。在加入我们的技术或应用后，它将产生更准确的输出，因为图像中的噪声之前已经通过`基于 VQA 的图像过滤`技术进行了过滤，而且为了向授权用户获得更安全的输出，我们使用了加密和解密技术，即`RSA`算法，它根据不同的公钥和私钥对文本进行加密和解密（例如，公钥就像人的邮箱 ID，而私钥可以是该人的密码，只有他自己知道）；它安全高效地锁定了整个过程。

## 16.7 结论

VQA 是一个关于构建计算机系统来回答图像中提出的问题的研究领域。但在融合过程中观察到了某些问题，例如噪声没有减少、未能达到准确率以及特征元素不在同一模态中。

有很多算法是量子密钥分发的先进版本，例如相干单向（`COW`）量子密钥分发，旨在涵盖原始量子密钥分发算法的缺点。

因此，在这篇研究论文中，除了差分网络模块和基于差分网络的融合外，我们还提出了一种名为“图像过滤”的技术。这种技术帮助我们在可用数据集上取得了更准确、更符合实际的结果。在加入我们的技术后，我们得到的结果更加有效且无噪声。我们使用了`Median Filter`技术，确保了图像的无噪声和高质量。使用`Median Filter`的原因是它是一种非线性滤波器，有助于减少椒盐噪声。为了传输敏感的 VQA 信息需要很强的安全性，而量子方法允许我们保护敏感信息。`RSA`算法是最好且最安全的加密算法之一。由于其极高的安全性，它是不可破解的，我们宝贵的 VQA 信息将免受未经授权的用户和其他威胁的影响。
