
参数推断的贝叶斯方法在第 3 章中已作介绍。与我们已涵盖的其他参数估计方法相比，贝叶斯方法采取了一种截然不同的观点。未知参数集被视为随机变量，而不是一组固定（但未知）的值。正如第 3 章所指出的，这是一个革命性的想法，最初由贝叶斯提出，随后由拉普拉斯进一步发展。即使在两个多世纪之后，假设一个物理现象/机制由一组随机参数控制，似乎仍然显得奇怪。然而，这里有一个微妙之处。将底层参数集视为随机变量 `θ`，我们并非真正暗示它们具有随机性。相关的随机性，以先验分布 `p(θ)` 的形式体现，包含了我们在接收任何测量/观测之前，关于其值的*不确定性*。换而言之，先验分布代表了我们对不同可能值的*信念*，尽管其中只有一个是真实的。从这个角度来看，概率以一种更“开放”的方式被看待，即作为不确定性的度量，正如第 2 章开头所讨论的。

回顾一下，从数据中学习参数是一个逆问题。基本上，我们所做的就是从“效应”（观测）推导“原因”（参数）。贝叶斯定理可以被视为在概率背景下表达的一种反演过程。确实，给定由未知参数集控制的一组观测值，设为 `X`，我们可以写出：

```
p(θ|X) = p(X|θ)p(θ) / p(X)。
```

换句话说，描述给定“效应”下的“原因”的后验 PDF `p(θ|X)`，是用描述给定“原因”下的“效应”的条件 PDF `p(X|θ)` 来表示的。上述反演所需的一切，仅仅是对先验 PDF `p(θ)` 有一个猜测。这一项在统计界引发了多年的巨大争议。然而，一旦有了一个合理的先验猜测，与替代途径相比，贝叶斯方法的许多优势便会显现出来。后者包含那些将参数确定性地视为未知值常数的方法，它们也被称为*频率派*技术。该术语源于对概率的更经典看法，即将概率视为可重复事件发生的频率。这类方法的一个典型例子是极大似然方法，它通过最大化 `p(X; θ)` 来估计参数值；后者概率密度函数（PDF）的值完全由一系列实验中获得的观测值控制。

这是专门讨论贝叶斯学习的两章中的第一章。我们阐述了贝叶斯推断背后的主要概念和哲学。我们介绍了期望最大化（EM）算法，并将其应用于一些典型的机器学习参数建模任务，如回归、混合建模和专家混合模型。最后，介绍了指数族分布，并讨论了共轭先验的概念。

## 12.2 回归：贝叶斯视角

线性回归任务的贝叶斯推断处理在第 3 章中已作介绍。在本章中，我们超越基本定义，揭示并利用贝叶斯哲学为研究这一重要机器学习任务提供的各种可能性。让我们首先总结第 3 章的发现，然后以此为基础进行构建。^(⁸⁴)

回顾前几章介绍的（广义）线性回归任务，即：

```
y = θ^T φ(x) + η = θ_0 + ∑_{k=1}^{K-1} θ_k φ_k(x) + η,
```

(12.1)

其中 $y \in \mathbb{R}$ 为输出随机变量，$\mathbf{x} \in \mathbb{R}^{(l)}$ 为输入随机向量，$\eta \in \mathbb{R}$ 为噪声干扰，$\boldsymbol{\theta} \in \mathbb{R}^{(K)}$ 为未知参数向量，且

$$\boldsymbol{\phi}(\mathbf{x}) \coloneqq [\phi_1(\mathbf{x}), \dots, \phi_{K-1}(\mathbf{x}), 1]^{(T)}$$

其中 $\phi_k, k = 1, \dots, K-1$ 为某些（固定的）基函数。正如我们已知，此类函数的典型例子可以是高斯函数、样条函数、单项式及其他。我们得到一组包含 $N$ 个输出-输入训练点的集合，$(y_n, \mathbf{x}_n), n = 1, 2, \dots, N$。在当前设定中，我们假设相应的（未观测到的）噪声值 $\eta_n, n = 1, 2, \dots, N$ 是均值为零、协方差矩阵为 $\Sigma_\eta$ 的联合高斯分布随机变量的样本，即，

$$p(\boldsymbol{\eta}) = \frac{1}{(2\pi)^{N/2}|\Sigma_\eta|^{1/2}}\exp\left( - \frac{1}{2}\boldsymbol{\eta}^{T}\Sigma_\eta^{-1}\boldsymbol{\eta} \right) \tag{12.2}$$

其中 $\boldsymbol{\eta} = [\eta_1, \eta_2, \dots, \eta_N]^{(T)}$。

### 12.2.1 最大似然估计量

最大似然（ML）方法在第 3 章中已作介绍。根据该方法，未知参数集被视为确定性向量变量 $\boldsymbol{\theta}$，它参数化了描述观测输出向量的概率密度函数（PDF）

$$\mathbf{y} = \mathbf{\Phi}\boldsymbol{\theta} + \boldsymbol{\eta} \tag{12.3}$$

其中

```
\Phi = \begin{bmatrix} 
\mathbf{\phi}^{T}(\mathbf{x}_{1}) \\ 
\mathbf{\phi}^{T}(\mathbf{x}_{2}) \\ 
\vdots \\ 
\mathbf{\phi}^{T}(\mathbf{x}_{N}) 
\end{bmatrix}
```

(12.4)

和

**y** = [*y*[1], *y*[2], …, *y*[*N*]]^(*T*)。

在公式 (3.61) 中，简单地用 Φ 替换 *X*，即可将 ML 估计改为

```
\widehat{\mathbf{\theta}}_{ML} = \left( \Phi^{T}\Sigma_{\eta}^{- 1}\Phi \right)^{- 1}\Phi^{T}\Sigma_{\eta}^{- 1}\mathbf{y}.
```

(12.5)。

对于方差相等且不相关的噪声样本这一简单情况 *σ*[*η*]² (*Σ*[*η*] = *σ*[*η*]²*I*)，公式 (12.5) 变得与最小二乘 (LS) 解相同

```
\widehat{\mathbf{\theta}}_{ML} = \left( \Phi^{T}\Phi \right)^{- 1}\Phi^{T}\mathbf{y} = \widehat{\mathbf{\theta}}_{LS}.
```

(12.6)。

ML 方法的**一个主要缺点**是它容易过拟合，因为它不关心那些试图“学习”特定训练集细节的复杂模型，正如第 3 章中已经讨论的那样。

### 12.2.2 MAP 估计器

根据最大后验概率 (MAP) 方法，未知参数集被视为随机向量 **θ**，对于给定的一组输出观测值 **y**，其后验概率表示为

```
p(\mathbf{\theta}|\mathbf{y}) = \frac{p(\mathbf{y}|\mathbf{\theta})p(\mathbf{\theta})}{p(\mathbf{y})},
```

(12.7)

其中 $p(\boldsymbol{\theta})$ 为相关先验 PDF。我们已从符号中省略了对 $\mathcal{X}$ 的依赖，以使其看起来更简洁。我们强调输入集合 $\mathcal{X} = \{\boldsymbol{x}_1, \dots, \boldsymbol{x}_N\}$ 被视为固定的，因此与输出随机变量 $\boldsymbol{y}$ 相关的所有随机性均源于噪声源。假设先验和条件 PDF 均为高斯分布，^(⁸⁵)

```
p(\boldsymbol{\theta}) = \mathcal{N}(\boldsymbol{\theta}|\boldsymbol{\theta}_0, \Sigma_\theta) \tag{12.8}
```

以及

```
p(\boldsymbol{y}|\boldsymbol{\theta}) = \mathcal{N}(\boldsymbol{y}|\Phi\boldsymbol{\theta}, \Sigma_\eta), \tag{12.9}
```

其中已使用了公式 (12.2) 和 (12.3)，后验 $p(\boldsymbol{\theta}|\boldsymbol{y})$ 也呈高斯分布，其均值向量为

```
\boldsymbol{\mu}_{\theta|y} := \mathbb{E}[\boldsymbol{\theta}|\boldsymbol{y}] = \boldsymbol{\theta}_0 + (\Sigma_\theta^{-1} + \Phi^T \Sigma_\eta^{-1} \Phi)^{-1} \Phi^T \Sigma_\eta^{-1} (\boldsymbol{y} - \Phi\boldsymbol{\theta}_0). \tag{12.10}
```

因为高斯分布的最大值与其均值重合，所以我们有

```
\widehat{\boldsymbol{\theta}}_{\text{MAP}} = \mathbb{E}[\boldsymbol{\theta}|\boldsymbol{y}]. \tag{12.11}
```

在本章附录中，提供了公式 (12.10) 的解析证明。^(⁸⁶)

```
\widehat{\boldsymbol{\theta}}_{\text{MAP}} = (\lambda I + \Phi^T \Phi)^{-1} \Phi^T \boldsymbol{y}, \tag{12.12}
```

其中我们设定了 $\lambda := \frac{\sigma_{\eta}^{2}}{\sigma_{\theta}^{2}}$。我们已经从第 3 章知道，`λ` 的值对于估计器关于均方误差（MSE）性能的表现至关重要。现在的主要问题变成了如何为 `λ` 选择一个好的值，或者在更一般的情况下为 `Σ[θ]`、`Σ[η]` 选择好的值。在实践中，采用交叉验证方法（第 3 章）；测试不同的 `λ` 值，并选择导致最佳 MSE（或其他某些准则）的那个值。然而，这是一个计算成本高昂的过程，特别是对于涉及大量参数的复杂模型。此外，这种过程迫使我们只使用一部分可用数据进行训练，以保留其余数据用于测试。读者可能会想，为什么我们不利用训练数据同时针对未知参数向量 `θ` 和正则化参数进行优化。让我们以中心化数据（`θ[0] = 0`）的简单岭回归情况为例。代价函数包含两项，一项依赖于数据并度量拟合优度，另一项仅依赖于未知参数，

`J(θ, λ) = ||y − Φθ||² + λ||θ||²`。

显而易见，唯一能使*训练数据集上的*平方误差拟合（经验损失）达到最小的 `λ` 值是 `λ = 0`。任何其他 `λ` 值都会导致 `θ` 的估计值使平方误差项取得更大的值；这是很自然的，因为对于 `λ ≠ 0`，优化过程还必须顾及额外的正则化项。只有当采用*测试数据集*时，`λ ≠ 0` 的值才会导致总体 MSE（而非经验 MSE）下降。

### 12.2.3 贝叶斯方法

贝叶斯回归方法试图克服先前提到的与过拟合相关的缺点。所有涉及的参数都可以在训练集上进行估计。在此思路下，参数将被视为随机变量。同时，因为主要任务现在变成了推断描述未知参数集的概率密度函数（PDF），而不是获得单个向量估计，所以人们可以掌握更多信息。话虽如此，这并不意味着贝叶斯技术必然不需要交叉验证；仍需交叉验证来评估其整体性能。我们将在第 12.3 节末尾的备注中进一步评论这一点。

正如我们所知，起点与最大后验概率（MAP）估计相同，特别是公式 (12.7)。然而，我们不只是取公式 (12.7) 分子的最大值，而是将利用整个 `p(θ|y)`。这里的大多数奥秘在于分母 `p(y)`，它基本上是归一化常数，

![Equation](img/fx001.jpg)(12.14)

正如我们很快将看到的，`p(y)` 中隐藏的信息远不止计算 `p(θ|y)` 所需的那样。公式 (12.14) 的困难在于，通常无法解析地计算该积分。在这种情况下，必须求助于近似技术以获得所需信息。为此，有许多可用的方法，本书的很大一部分专门用于研究它们。更具体地说，已提出并将考虑以下方法：

*   拉普拉斯近似法，见第 12.3 节；

在本节研究的情况下，假设 `p(y|θ)` 和 `p(θ)` 均为高斯分布，`p(y)` 可以解析地求得；结果表明联合分布 `p(y, θ)` 也是高斯分布，因此边缘分布 `p(y)` 也是高斯分布。所有这些都在本章附录中详细展示。确实，如果我们在附录的公式 (12.146) 和 (12.151) 中令 `z → θ`、`t → y` 以及 `A → Φ`，对于公式 (12.3) 的回归模型、公式 (12.8) 的先验 PDF 以及公式 (12.2) 的噪声模型，我们得到

```
p(y) = N(y|Φθ[0], Σ[η] + ΦΣ[θ]Φ^(T)).
```

此外，后验 `p(θ|y)` 也是高斯分布，

```
p(θ|y) = N(θ|μ[θ|y], Σ[θ|y]),
```

其中 `μ[θ|y]` 由公式 (12.10) 给出，协方差矩阵源自公式 (12.147)，在进行适当的符号替换后，即

```
Σ[θ|y] = (Σ[θ]^(−1) + Φ^(T) Σ[η]^(−1) Φ)^(−1).
```

公式 (12.16) 中的后验 PDF 概括了在获得观测值 `y` 后我们关于 `θ` 的知识。因此，我们对 `θ` 的不确定性得到了降低，这也是公式 (12.16) 与公式 (12.8) 中先验 PDF 不同的主要原因；后者仅代表我们的初始猜测。公式 (12.17) 中的协方差矩阵提供了关于我们对 `θ` 不确定性的信息。如果公式 (12.16) 中的高斯分布在其均值 `μ[θ|y]` 周围非常宽阔，则表明尽管接收了观测值，但关于 `θ` 仍存在很大的不确定性。这可能是由于 (a) 问题的性质，例如高噪声方差，这由 `Σ[η]` 传达；(b) 观测值的数量 `N` 可能不足；和/或 (c) 建模不准确，这由公式 (12.17) 中的 `Φ` 传达。如果后验 PDF 在其均值周围呈尖峰状，则情况相反。

正如我们在第 3 章中已经陈述的，贝叶斯哲学提供了直接推断输出变量的方法，在许多应用中，输出变量是关注的量；给定输入向量，任务是预测输出。在这种情况下，估计未知 `θ` 的值只是达到目的的手段。为了直接构建预测任务而不涉及 `θ`，必须对 `θ` 的贡献进行积分。在已知后验 `p(θ|y)` 的情况下，给定一个新的输入向量 `x`，对于公式 (12.1) 中的回归模型，给定观测值集合的输出变量 y 的条件 PDF 可写为

```
p(y|x, y) = ∫ p(y|x, θ) p(θ|y) dθ.
```

注意，我们使用了 `p(y|x, y, θ) = p(y|x, θ)`，因为对应于新样本 `x` 的 y，在给定 `θ` 的值条件下，与训练集 `X` 相关的观测变量 `y` 是条件独立的。正如已经陈述的，严格来说，后验本应表示为 `p(θ|y; X)` 以表明其对输入训练样本的依赖。然而，为了避免符号繁杂，已省略了对 `X` 的依赖。
