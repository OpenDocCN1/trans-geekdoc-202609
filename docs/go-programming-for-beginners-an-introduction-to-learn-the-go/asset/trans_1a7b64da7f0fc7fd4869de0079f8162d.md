

# 12. 数组

数组是相似项目的集合。在编程术语中，Go 语言中的数组是一种包含相同数据类型项目的数据结构。数组内的每个项目称为数组元素（或简称元素）。可以使用元素在数组中的位置来引用该元素，该位置称为索引。数组索引从 0 开始，到比数组大小小 1 的位置结束（大小 – 1）。例如，如果我们有一个包含 10 个元素的数组，该数组的第一个元素将位于 0，第二个位于索引 1，第三个位于索引 2，……，最后一个元素将位于索引 9。

在 Go 编程语言中，可以使用以下语法声明数组：

```
var <数组变量> [<数组大小>] <数据类型>
```

示例：

```
var array1 [5] int
var msg [3] string
var x [10] float64
```

一旦声明了数组，其元素将获得零值（数值数组将保存 0，字符串数组将保存空字符串）。可以使用由访问操作符（`[]`）括起来的索引来访问单个元素。这样，您可以设置（也可以检索/打印）数组的单个元素。

这是一个示例：

```
/*声明一个大小为 5 的 int 数组。第一个索引是 0，最后一个索引是 4*/
var num_array [5] int

/*将索引 0 处的元素设置为 15*/
num_array[0] = 15

/*将索引 1 处的元素设置为 -35*/
num_array[1] = -35

/*将索引 2 处的元素设置为 0*/
num_array[2] = 0

/*将索引 3 处的元素设置为 68*/
num_array[3] = 68

/*将索引 4 处的元素设置为 18*/
num_array[4] = 18
```

我们现在将编写一个程序，在其中创建一个整数数组，设置元素值并将它们打印出来。可以使用动词 `%v` 或 `%d` 打印整个数组。打印单个元素与打印任何其他整数变量相同：

```
/*数组演示 1*/
/*包声明*/
package main

/*导入语句 - 导入 fmt 包*/
import (
    "fmt"
)

/*强制的 main 函数*/
func main() {
    /*声明一个包含 7 个整数的数组*/
    var arr [7] int

    /*设置所有元素的值*/
    arr[0] = 83
    arr[1] = -34
    arr[2] = 55
    arr[3] = 97
    arr[4] = -24
    arr[5] = -11
    arr[6] = 46

    /*打印整个数组*/
    fmt.Printf("\n数组 arr:\n\n%v\n", arr)

    /*打印索引和对应的值*/
    fmt.Printf("\n索引 0 处的值: ==> %d", arr[0])
    fmt.Printf("\n索引 1 处的值: ==> %d", arr[1])
    fmt.Printf("\n索引 2 处的值: ==> %d", arr[2])
    fmt.Printf("\n索引 3 处的值: ==> %d", arr[3])
    fmt.Printf("\n索引 4 处的值: ==> %d", arr[4])
    fmt.Printf("\n索引 5 处的值: ==> %d", arr[5])
    fmt.Printf("\n索引 6 处的值: ==> %d\n", arr[6])
}
```

也可以在声明时使用以下语法初始化数组：

```
var <数组变量> = [<可选大小>] <数据类型> {<用逗号分隔的元素>}
```

示例：

```
var arr1 = [] int {-3, 0, 3}
var arr2 = [6] float32 {0.36, -0.25, 0.01, -0.67, 0.88, 0.73}
```

数组可以是任何数据类型。初始化数组时，可以指定大小，也可以不指定。大小将根据您在初始化时设置的元素数量自动确定。在程序的任何位置，您都可以使用函数 `len(<数组变量>)` 来确定数组的大小。此外，每次手动访问元素可能不是最佳方式——循环在处理数组方面做得很好。

这是一个演示这些概念的示例：

```
/*数组演示 3*/
/*包声明*/
package main

/*导入语句 - 导入 fmt 包*/
import (
    "fmt"
)

/*强制的 main 函数*/
func main() {
    /*声明一个包含 10 个字符串的数组并初始化*/
    var country = [] string {"USA", "UK", "India", "Brazil", "South Africa", "Argentina", "New Zealand", "Russia", "Morocco", "Latvia"}

    /*打印整个数组*/
    fmt.Printf("\n数组 country:\n\n%v\n", country)

    /*使用 for 循环打印索引和对应的值*/
    /*使用 len 函数获取数组的大小*/
    size := len(country)

    for i := 0; i < size; i++ {
        fmt.Printf("\n索引 %d 处的值: ==> %s", i, country[i])
    }
    fmt.Printf("\n")
}
```

让我们再看几个编程示例，以更好地理解数组。这是一个示例，它从用户处获取 5 个整数作为输入并将其保存在数组中，计算这些整数的总和和平均值：

```
/*数组输入*/
/*包声明*/
package main

/*导入语句 - 导入 fmt 包*/
import (
    "fmt"
    "strconv"
)

/*强制的 main 函数*/
func main() {
    /*声明变量*/
    var arr [5] int
    var sum int = 0
    var num_str string

    /*声明一个变量来存储平均值*/
    var avg float32

    /*提示用户输入 5 个元素，使用 for 循环*/
    for i := 0; i < 5; i++ {
        fmt.Printf("\n请输入索引 %d 处的元素: ", i)
        fmt.Scanln(&num_str)

        /*将 num_str 转换为整数*/
        num, err := strconv.Atoi(num_str)

        /*将 num 赋值给 arr[i]*/
        arr[i] = num

        /*将 err 赋值给空标识符*/
        _ = err

        /*持续计算总和*/
        sum += arr[i]
    }

    /*计算平均值*/
    avg = float32(sum) / 5.0
    fmt.Printf("\n数组 arr:\n%v\n总和: %d\n平均值: %f\n", arr, sum, avg)
}
```

让我们编写一个程序，从用户处获取 5 个整数作为输入，将它们保存在数组中并反转该数组：

```
/*反转数组*/
/*包声明*/
package main

/*导入语句 - 导入 fmt, strconv 包*/
import (
    "fmt"
    "strconv"
)

/*强制的 main 函数*/
func main() {
    /*声明变量*/
    var arr [5] int
    var num_str string

    /*提示用户输入 5 个元素，使用 for 循环*/
    for i := 0; i < 5; i++ {
        fmt.Printf("\n请输入索引 %d 处的元素: ", i)
        fmt.Scanln(&num_str)

        /*将 num_str 转换为整数*/
        num, err := strconv.Atoi(num_str)

        /*将 num 赋值给 arr[i]*/
        arr[i] = num

        /*将 err 赋值给空标识符*/
        _ = err
    }

    fmt.Printf("\n原始数组:\n%v\n", arr)

    /*反转数组*/
    for i := 0; i < 5 / 2; i++ {
        temp := arr[i]
        arr[i] = arr[4 - i]
        arr[4 - i] = temp
    }

    fmt.Printf("\n反转后的数组:\n%v\n", arr)
}
```
