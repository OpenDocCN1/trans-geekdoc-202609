# 11.3 Cybersecurity and Security

There are many problems in the future if there are hidden flaws in the network. When a business needs an ethical hacker, often a penetration test can uncover vulnerabilities in its network [6]. They have a unique toolkit that they completely test and observe the network.

The first penetration tester will do survey the network. There are two types of survey, passive and active. When you are passive, you are not creating a footprint or alerting the network to be under attack. This includes sniffing and information gathering.

Active includes probing the network for information such as open ports, details about the operating system, hosts, and the locations of routers. Reconnaissance allows the tester to gain information on the system that they can use later to find exploits for vulnerabilities in the host's systems. With reconnaissance, the tester uncovers that information, so it is a key part of the process.
