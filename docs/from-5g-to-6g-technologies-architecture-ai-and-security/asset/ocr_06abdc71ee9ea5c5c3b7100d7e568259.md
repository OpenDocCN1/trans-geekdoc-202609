# 2.11.5 High-Capacity Backhaul Connectivity for 6G Wireless

A backhaul is a network that connects the core to the access network. Prevailing backhaul networks have dedicated fiber, microwave, satellite links at times, copper, and mmWave[61]. Backhaul connectivity with satellite links relies on the availability of options. A high-capacity backhaul network is an important part of 5G systems. It gives the 5G systems capacity to exchange a considerable volume of data traffic between core and access networks. Minus a high-capacity backhaul network, the communication system fails to operate, even with access networks backing Gbps communication between the user equipment and access networks. With a low-capacity backhaul network, there will be a bottleneck in the system [62]. The entrance of 6G into some promises almost zero bottlenecks.
