# 2.3 Heterogeneous Networks

Heterogeneous networks, also referred to HetNet, are a very important aspect of the movement of cellular technology. A HetNet is made up of different types of wireless stations that claim to provide high-quality services to all of us. With the growing number of users and the amount of data required in cellular services, something has to be done for the future. A heterogeneous network consists of macro base stations, small cells distributed antenna systems (DAS), and Wi-Fi access points. There are three types of cell base stations in a mobile network that can be used in a HetNet. A macro base station is the backbone, and can be placed on rooftops or towers covering large areas and many. Another type of cell used is the micro base station, which can be used in indoor or outdoor areas. The pico base cell can also be used in a heterogeneous network, and generally takes over when a user moves. An smaller portion of a HetNet is a femtocell. The femtocell is generally a small access point that improves cellular service in a home or office via the internet.
