# 8.10.2 Physical Layer Security as a Means of Confidentiality

When moving from 5G to 6G, the sixth generation is meant to enhance the key performance that the first generation provided. It will enable more demanding applications than augmented reality and holographic projection mentioned previously, to ultra-sensitive applications.
The main focus of integrating ML in 6G networks is wireless communications. Sixth-generation wireless communications are considered to be the backbone of digital transformation because they will provide a sense of ubiquitous, reliable, and near-instant wireless connectivity for humans and machines (Figure 8.6).
ML techniques rely on a central server, such as the central nervous system in the body. This leads to them vulnerability to security threats such as a single point of failure. Traditional centralized machine learning techniques might not be suitable for the sixth generation, where federated learning can assist. Federated learning acts as a private, distributed.
There is a specific procedure that needs to be followed to implement federated learning in a 6G world. The procedure of federated learning-based architecture is divided into three phases:

+   1) Initialization in phase one. The devices evaluate service requests and will be able to decide whether to register with the nearest cloud for that is required. This cloud-based training will be able to pretrained or initialize global models to all of selected devices.
2) Next is the training phase. This phase deals with the selection of each device and trains a global model on local dataset. The meaning of this is to obtain the updated global model for each iteration.
3) In the aggregation phase, the cloud updates on the model of devices for aggregation. Afterward, a new model is obtained for the next iteration.
