Going 5G with satellite and terrestrial integration is what starts to get interesting. Using this will provide coverage to all of the Earth - sky, ocean, and even parts of space. With LEOs, GEOs, and MEOs working harmony this is achievable. The overall idea behind 6G is to provide seamless communication with anytime anywhere. 6G is supposed to be a mobile communication system that will provide the compatible standards needed for the interaction with satellites. This includes terminal, frequency, and network architecture, platform, and resource management integrations well. However, similar to the deal with 5G networks to implement this, there are still technical problems when dealing with integrating the satellites with terrestrial networks for 6G. The network is going to be three-dimensional when we integrate satellite and terrestrial communications, it is going to be managed by well. Network coordination and management are very important in this aspect, and it is going to be multilayer. This means it needs to cover management for each layer, from the highest to the lowest terrestrial and end users. Satellites also have a limited capacity, which means it is going having to be a balance of the capacity of the satellite and the quality of service, the more it holds, the more it gets.

The communication between satellites is also an issue, especially with the routing aspect of it. If they end up as an end-user who is unable to access a terrestrial station, then their message might have to hop between many different satellites, which could be a problem. This means there needs to research into superior routing for links between satellites.
The just alone are not enough. There are also going to high altitude platforms (HAPS), aircraft, and drones that act as stations and terminals for the network. Figure 8.2 for an amazing depiction of 6G network architecture using the satellites, HAPS, and other technologies.

Another enabling key for 6G networks would be doubt security mechanisms. The vision for 6G networks is to have everything connected and with that many personal data on the same network. This poses concerns for the security, privacy, and overall trustworthiness of the network. There are going to have to be creative and innovative cryptographic techniques to accommodate the vast vulnerable of data that will on the network. It would be completely irresponsible to allow the network to put up without any preventive measures in place. There is also use of blockchain technology to help with security for 6G networks. Blockchain is a DLT where cryptography and hash functions are used to form a chain of data blocks, created when an event occurs [9] and verified in a decentralized way using consensus algorithms. Blockchain technologies were originally made for cryptocurrencies to provide safe and secure transactions. Using it in 6G networks will no doubt prove useful and allow for the safe transmission of data. Blockchain
