# Wake Sleep Algorithm

# Wake sleep

+   - Parametrized inference model $q_{\phi}(\mathbf{z}|\mathbf{x})$\n- Wake phase:\n  - minimize $KL(q_{\phi}(\mathbf{z}|\mathbf{x}) || p_{\theta}(\mathbf{z}|\mathbf{x}))$ wrt. $\theta$\n  - $\mathbb{E}_{q_{\phi}(\mathbf{z}|\mathbf{x})} [\nabla_{\theta} \log p_{\theta}(\mathbf{x}|\mathbf{z})]$\n- Sleep phase:\n  - minimize $KL(p_{\theta}(\mathbf{z}|\mathbf{x}) || q_{\phi}(\mathbf{z}|\mathbf{x}))$ wrt. $\phi$\n  - $\mathbb{E}_{p_{\theta}(\mathbf{z},\mathbf{x})} [\nabla_{\phi} \log q_{\phi}(\mathbf{z},\mathbf{x})]$\n  - low variance\n  - Learning with generated samples of $\mathbf{x}$\n- Two objective, not guaranteed to converge

# Variational EM

+   - Variational distribution $q_{\phi}(\mathbf{z}|\mathbf{x})$\n- Variational M step:\n  - minimize $KL(q_{\phi}(\mathbf{z}|\mathbf{x}) || p_{\theta}(\mathbf{z}|\mathbf{x}))$ wrt. $\theta$\n  - $\mathbb{E}_{q_{\phi}(\mathbf{z}|\mathbf{x})} [\nabla_{\theta} \log p_{\theta}(\mathbf{x}|\mathbf{z})]$\n- Variational E step:\n  - minimize $KL(q_{\phi}(\mathbf{z}|\mathbf{x}) || p_{\theta}(\mathbf{z}|\mathbf{x}))$ wrt. $\phi$\n  - $q_{\phi}^* \propto \exp[\log p_{\theta}]$ if with closed-form\n  - $\nabla_{\phi} \mathbb{E}_{q_{\phi}} [\log p_{\theta}(z, x)]$\n    - need variance-reduce in practice\n  - Learning with real data $\mathbf{x}$\n- Single objective, guaranteed to converge
