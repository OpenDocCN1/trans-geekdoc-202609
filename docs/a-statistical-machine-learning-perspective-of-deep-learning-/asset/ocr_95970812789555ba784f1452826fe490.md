# # GANs vs VAEs side by side

|  | GANs (InfoGAN) | VAEs |
|---|---|---|
| Generative distribution | $p_\theta(x\mid y)=\begin{cases}p_{g_\theta}(x)&y=0\\p_{data}(x)&y=1.\end{cases}$ | $p_\theta(x\mid z,y)=\begin{cases}p_\theta(x\mid z)&y=0\\p_{data}(x)&y=1.\end{cases}$ |
| Discriminator distribution | $q_\phi(y\mid x)$ | $q_*(y\mid x)$, perfect, degenerated |
| $z$-inference model | $q_\eta(z\mid x,y)$ of InfoGAN | $q_\eta(z\mid x,y)$ |
| KLD to minimize | $\min_\theta \mathrm{KL}\left(p_\theta(x\mid y)\parallel q^r(x\mid z,y)\right)$<br>~ $\min_\theta \mathrm{KL}(P_\theta\parallel Q)$ | $\min_\theta \mathrm{KL}\left(q_\eta(z\mid x,y)q_*(y\mid x)\parallel p_\theta(z,y\mid x)\right)$<br>~ $\min_\theta \mathrm{KL}(Q\parallel P_\theta)$ |
