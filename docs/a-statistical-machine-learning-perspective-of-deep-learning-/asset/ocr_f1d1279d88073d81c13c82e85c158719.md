# Wake Sleep Algorithm

+   - Free energy:
+   
+     $F(\boldsymbol{\theta}, \boldsymbol{\phi}; \boldsymbol{x}) = -\log p(\boldsymbol{x}) + KL(q_{\phi}(\mathbf{z}|\boldsymbol{x}) \| p_{\theta}(\mathbf{z}|\boldsymbol{x}))$
+   - WS works around the difficulties with the sleep phase approximation
+   - Minimize the following objective → sleep phase
+   
+     $F'(\boldsymbol{\theta}, \boldsymbol{\phi}; \boldsymbol{x}) = -\log p(\boldsymbol{x}) + KL(p_{\theta}(\mathbf{z}|\boldsymbol{x}) \| q_{\phi}(\mathbf{z}|\boldsymbol{x}))$
+   
+     $\max_{\phi} \mathbb{E}_{p_{\theta}(z,x)} [\log q_{\phi}(\mathbf{z}|\boldsymbol{x})]$
+   
+     $\max_{\phi} \mathbb{E}_{q_{\phi}(z|x)} [\log p_{\theta}(\boldsymbol{x},\mathbf{z})]$  
+     - “Dreaming” up samples from $p_{\theta}(\boldsymbol{x}|\mathbf{z})$ through top-down pass
+     - Use the samples as targets for updating the inference model
+   - (Recent approaches other than sleep phase are developed to reduce the variance of gradient estimate: slides later)
