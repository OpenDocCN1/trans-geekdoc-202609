# Reparameterized gradient

+   - Optimize \(\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\phi}; x)\) wrt. \(\boldsymbol{\phi}\) of \(q_{\boldsymbol{\phi}}(z\mid x)\)
+     - Recap: gradient estimate with log-derivative trick:

\[\nabla_{\boldsymbol{\phi}}\mathbb{E}_{q_{\boldsymbol{\phi}}}[\log p_{\boldsymbol{\theta}}(x,z)] = \mathbb{E}_{q_{\boldsymbol{\phi}}}[\log p_{\boldsymbol{\theta}}(x,z)\,\nabla_{\boldsymbol{\phi}}\log q_{\boldsymbol{\phi}}]\]

+   - High variance: \(\nabla_{\boldsymbol{\phi}}\mathbb{E}_{q_{\boldsymbol{\phi}}}[\log p_{\boldsymbol{\theta}}] \approx \mathbb{E}_{z_i\sim q_{\boldsymbol{\phi}}}[\log p_{\boldsymbol{\theta}}(x,z_i)\,\nabla_{\boldsymbol{\phi}}q_{\boldsymbol{\phi}}(z_i\mid x)]\)
+     - The scale factor \(\log p_{\boldsymbol{\theta}}(x,z_i)\) can have arbitrary large magnitude

+   - gradient estimate with *reparameterization trick*

\[z \sim q_{\boldsymbol{\phi}}(z\mid x) \quad\Longleftrightarrow\quad z=g_{\boldsymbol{\phi}}(\epsilon,x), \qquad \epsilon\sim p(\epsilon)\]

\[\nabla_{\boldsymbol{\phi}}\mathbb{E}_{q_{\boldsymbol{\phi}}(z\mid x)}[\log p_{\boldsymbol{\theta}}(x,z)] = \mathbb{E}_{\epsilon\sim p(\epsilon)}\left[\nabla_{\boldsymbol{\phi}}\log p_{\boldsymbol{\theta}}\left(x,z_{\boldsymbol{\phi}}(\epsilon)\right)\right]\]

+   - (Empirically) lower variance of the gradient estimate
+   - E.g., \(z\sim\mathcal{N}(\boldsymbol{\mu}(x),L(x)L(x)^T)\quad\Longleftrightarrow\quad\epsilon\sim\mathcal{N}(0,1),\;z=\boldsymbol{\mu}(x)+L(x)\epsilon\)
