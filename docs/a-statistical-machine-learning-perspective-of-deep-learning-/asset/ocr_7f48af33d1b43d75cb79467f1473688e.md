# Recap: Variational Inference

Maximize the variational lower bound $\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\phi}; \boldsymbol{x})$, or equivalently, minimize free energy

$F(\boldsymbol{\theta}, \boldsymbol{\phi}; \boldsymbol{x}) = -\log p(\boldsymbol{x}) + KL(q_{\phi}(\boldsymbol{z}|\boldsymbol{x}) || p_{\theta}(\boldsymbol{z}|\boldsymbol{x}))$

+   - E-step: maximize $\mathcal{L}$ wrt. $\phi$ with $\boldsymbol{\theta}$ fixed
+     $\max_{\phi}\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\phi}; \boldsymbol{x}) = \mathbb{E}_{q_{\phi}(\boldsymbol{z}|\boldsymbol{x})}[\log p_{\theta}(x|\boldsymbol{z})] + KL(q_{\phi}(\boldsymbol{z}|x)||p(z))$
+     - If with closed form solutions
+       $q_{\phi}^*(z|x) \propto \exp[\log p_{\theta}(x,z)]$
+   - M-step: maximize $\mathcal{L}$ wrt. $\boldsymbol{\theta}$ with $\phi$ fixed
+     $\max_{\theta}\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\phi}; \boldsymbol{x}) = \mathbb{E}_{q_{\phi}(\boldsymbol{z}|\boldsymbol{x})}[\log p_{\theta}(x|\boldsymbol{z})] + KL(q_{\phi}(\boldsymbol{z}|x)||p(z))$
