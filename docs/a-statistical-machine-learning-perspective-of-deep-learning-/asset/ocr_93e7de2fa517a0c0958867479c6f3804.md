# VAEs vs. Wake-sleep

+   - Wake sleep algorithm
+     Wake : $\max_{\theta} \mathbb{E}_{q_{\lambda}(h|x)p_{data}(x)} [\log p_{\theta}(x|h)]$
+     Sleep : $\max_{\lambda} \mathbb{E}_{p_{\theta}(x|h)p(h)} [\log q_{\lambda}(h|x)]$
+   - Let $h$ be $z$, and $\lambda$ be $\eta$
+     $\Rightarrow \max_{\theta} \mathbb{E}_{q_{\eta}(z|x)p_{data}(x)} [\log p_{\theta}(x|z)]$, recovers VAE objective of optimizing $\theta$
+   - VAEs extend wake phase by also learning the inference model ($\eta$)
+     $\max_{\theta,\eta} \mathcal{L}^{vae}_{\theta,\eta} = \mathbb{E}_{q_{\eta}(z|x)p_{data}(x)} [\log p_{\theta}(x|z)] - \mathbb{E}_{p_{data}(x)} [\text{KL}(q_{\eta}(z|x)||p(z))]$
+     - Minimize the KLD in the original variational free energy wrt. $\eta$
+     - Stick to minimizing the wake-phase KLD wrt. both $\theta$ and $\eta$
+     - Do not involve sleep-phase objective
+     - Recall: sleep phase minimizes the *reverse* KLD in the variational free energy
