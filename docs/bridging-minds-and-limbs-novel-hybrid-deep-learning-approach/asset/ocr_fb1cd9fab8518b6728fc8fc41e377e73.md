# 2. Materials and methods

# 2.1. Hardware and software

# 2.1.1. OpenBCI

OpenBCI is an open-source, cost-effective, and programmable platform for monitoring cardiac, muscle, and electroencephalography (EEG). The OpenBCI board, powered by a 3-6 DC battery, facilitates EEG acquisition. This chip utilizes the integrated ADS1299 chip, which supports eight-channel EEG acquisition with a sampling rate of 244Hz. The digital-to-analog converter (ADC) also supports flexible sampling rates from 250 samples per second (ps) to 1000 ps and has a common mode rejection (CMR) exceeding 120 dB. Furthermore, the chip contains an internal referenced voltage and an on-board oscillator.

The OpenBCI board establishes a connection to a PC (11th Gen Intel(R) Core(i7)-11800H @ 2.30 GHz, 16 GB RAM, Windows 10) via-

Fi.

To account for physiological variations in head, we used a stereoscopic mesh cap (Tencubic, Qinjiao) in place of the 3D-printed helmet fitted with the OpenBCI system. The cap accommodates 20 disco slots according to the arrangement of the head system, allowing for the integration of gold electrodes. We used conductive paste to the electrodes to enhance signal quality during EEG acquisition.

# 2.1.2. Software

The OpenBCI team provides a software system called the OpenBCI Graphical User Interface (GUI), which facilitates data acquisition and transfer from various OpenBCI boards. However, the GUI cannot perform real-time analysis, necessitating the use of third-party software for analysis. During experiments to ensure safety and seamless execution, we developed a custom software using Python and the Flow library for data streaming, processing, and visualization of mental data.

The process begins with a communication interface to configure the board parameters. Once configured, the stream is commanded to initiate data acquisition. Simultaneously, the GUI tailored to show the motor imagery tasks to the subject. Each trial is shown on the GUI, which then automatically closes, signaling the end of the acquisition. Data and corresponding labels are then saved and imported into MATLAB for analysis.

# 2.2. Experimental design

Ten healthy-right handed participants (8 males and 2 females, age = 29 ± 3.7 years) with no experience using Brain Computer Interface (BCI) systems participated in this study.

We conducted the experiments in an office environment with stable lighting. The experiment was divided into five sessions, with 20 trials each. Each session lasted 45 minutes. Participants sat in chairs close to a computer screen. In each trial, as shown in Fig. 2, an arrow appeared on the screen to indicate the direction, either left or right arrow, displayed for four seconds. During this time, the participants were instructed to imagine the movement (e.g., lifting the left leg when an arrow appeared) while remaining still.

To ensure an equal number of left and right limb imagery trials, we used a structured arrangement strategy. A randomly selected left or right arrow was presented, followed by a four-second rest. The trial within the block was followed by another rest period. This alternating sequence was repeated throughout the session, ensuring that both left and right were used an equal number of times to prevent predictable patterns.

The experiment consisted of three sessions, each session composed of 50 trials (25 blocks for each imagery task), and between sessions were given a 5-10 minute break to minimize fatigue before starting the next session.
