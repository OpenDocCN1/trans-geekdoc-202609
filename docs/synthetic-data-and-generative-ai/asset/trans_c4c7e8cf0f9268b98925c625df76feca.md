### 8.4.3 幅度恢复

如前所述，模糊回归，尤其是基于中位数的方法，在信号处理中充当低通滤波器。这并不奇怪：毕竟它能去除噪声。事实上，它可用作一种数据压缩技术。因此，预测值的方差低于观测值，且 [表 8.1](#Chp008_131-145_B9780443218576000126.xhtml#t0010) 或 [图 8.3](#Chp008_131-145_B9780443218576000126.xhtml#f0020) 中的斜率 `β` 远小于 1。为纠正这一“问题”，必须对预测值进行标准化，使其均值和方差与训练集中观测响应的均值和方差相匹配。简而言之，预测值必须重新校准。因此，均方误差不是评估性能的好指标。此外，此处 R 平方是相关系数的平方，但不等于 `1 - S_S[res]/S_S[tot]`![图片](images/B9780443218576000126/si58.png)，这与传统回归中两者一致的情况不同。

平滑时间序列时也会出现同样的现象。移动平均可用于预测或插值。它还能去除部分噪声，并降低信号幅度。真实值与移动平均的散点图将显示出斜率同样急剧下降的现象。同样可采用相同策略进行修正，且不会影响以观测值与预测（平滑）值之间相关系数平方衡量的 R 平方。

## 8.5 练习

第一个练习旨在证明一个基本结果：在特定条件下，本章描述的模糊回归技术是一种精确插值技术。该证明不涉及初等算术以外的数学知识，而是需要跳出框架的思维。第二个练习涉及另一种简单、数值稳定的插值技术，这次基于部分分式。先修要求是微积分基础课程，以理解并解决该问题。第三个练习探讨验证集的替代方案。第四个练习是向高维空间的推广。

### 练习 8.1

**用于插值的模糊回归**。

设 (`x[1]`, `y[1]`, `z[1]`), …, (`x[n]`, `y[n]`, `z[n]`)![图片](images/B9780443218576000126/si59.png) 为训练集点。我们使用包含 `M = n`![图片](images/B9780443218576000126/si40.png) 个样条的样条系统。每个样条由 `r` 个训练集点唯一确定。第 `k` 个样条（`k = 1, …, n`![图片](images/B9780443218576000126/si60.png)）始终包含 (`x[k]`, `y[k]`, `z[k]`)![图片](images/B9780443218576000126/si61.png)。换句话说，`L[k](x[k], y[k]) = z[k]`![图片](images/B9780443218576000126/si62.png)。证明当 `s → ∞`![图片](images/B9780443218576000126/si39.png) 时，在任意训练集位置 (`x`, `y`)![图片](images/B9780443218576000126/si26.png) 处基于权重的预测值 `z[w]`![图片](images/B9780443218576000126/si44.png) 等于该位置的观测值 `z`。

#### 解答

当 `s = ∞`![图片](images/B9780443218576000126/si63.png) 时，若 (`x`, `y`) = (`x[k]`, `y[k]`)![图片](images/B9780443218576000126/si65.png) 为训练集点位置，则 `w[k](x, y) = 1`![图片](images/B9780443218576000126/si64.png)，否则为 0。如果多个训练集点具有相同的 (`x`, `y`)![图片](images/B9780443218576000126/si26.png) 但不同的 `z` 值，则该位置 (`x`, `y`)![图片](images/B9780443218576000126/si26.png) 处的预测值 `z[w]`![图片](images/B9780443218576000126/si44.png) 将是这些 `z` 值的平均值。这是因为乘积公式 [(8.2)](#Chp008_131-145_B9780443218576000126.xhtml#deq5) 中至少有一个因子等于零，因此乘积为零。

要完成证明，必须仔细检查公式 [(8.1)](#Chp008_131-145_B9780443218576000126.xhtml#deq4)。假设 (`x`, `y`) = (`x[k]`, `y[k]`)![图片](images/B9780443218576000126/si65.png)。如果 `i ≠ k`![图片](images/B9780443218576000126/si66.png)，公式 [(8.1)](#Chp008_131-145_B9780443218576000126.xhtml#deq4) 中的第 `i` 项为零，因为每个内积中至少有一个因子为零。但如果 `i = k`![图片](images/B9780443218576000126/si67.png)，两个乘积均等于 1，因此 `L[k](x, y) = z[k]`![图片](images/B9780443218576000126/si68.png)。

### 练习 8.2

**用于插值的部分分式**。

这对时间序列插值可能特别有用。假设 `f` 是一个光滑、缓慢增长的偶函数，且当 `t` 为正整数时 `f(t)`![图片](images/B9780443218576000126/si69.png) 已知。则 `f(t)`![图片](images/B9780443218576000126/si69.png) 在实轴上处处唯一确定。简而言之，若已知 `t = 0, 1, 2`![图片](images/B9780443218576000126/si70.png) 等处的 `f(t)`![图片](images/B9780443218576000126/si69.png)，则存在整个函数的精确插值公式。该公式为

```
f(t) = \frac{\sin\pi t}{\pi} \cdot \left\lbrack \frac{f(0)}{t} + \phi^{\prime}(t)\sum\limits_{k = 1}^{\infty}{( - 1)}^{k}\frac{f(k)}{\phi(t) - \phi(k)} \right\rbrack,
```

![图片](images/B9780443218576000126/si71.png)(8.5)

当 `ϕ(t) = t²`![图片](images/B9780443218576000126/si72.png)，`ϕ'(t) = 2t`![图片](images/B9780443218576000126/si73.png) 为关于 `t` 的导数时，该公式特别适用，且

```
f(t) = \sum\limits_{k = 0}^{\infty}\alpha_{k}\cos\beta_{k}t,\text{~with~}|\beta_{k}| < \pi.
```

![图片](images/B9780443218576000126/si74.png)(8.6)

本练习旨在证明公式 [(8.5)](#Chp008_131-145_B9780443218576000126.xhtml#deq8) 在适当条件下的有效性，并将其应用于狄利克雷 η 函数 `η(σ + i t)`![图片](images/B9780443218576000126/si75.png) 的实部 [[维基](https://en.wikipedia.org/wiki/Dirichlet_eta_function)]，例如 `σ = 0.8`![图片](images/B9780443218576000126/si76.png) 和 `0 < t < 30`![图片](images/B9780443218576000126/si77.png) 的情况。与 [练习 8.1](#Chp008_131-145_B9780443218576000126.xhtml#enun0010) 中的插值技术不同，公式 [(8.5)](#Chp008_131-145_B9780443218576000126.xhtml#deq8) 仅提供近似值，尽管是极佳的近似。若包含所有无限项，该近似即为精确值。它可用于**时间序列分解** [[2]](#Chp008_131-145_B9780443218576000126.xhtml#br0010)。一个潜在应用是将逐小时温度预测细分为 5 分钟增量。

#### 解答

关于该插值公式及其推广的详细讨论，见 [此处](https://mathoverflow.net/questions/376081/infinite-partial-fraction-expansions-to-compute-fractional-iterations-and-recurr)。注意，狄利克雷 η 函数的实部（与**黎曼假设**密切相关）为

```
\Re\lbrack\zeta(\sigma + it)\rbrack = \sum\limits_{k = 1}^{\infty}{( - 1)}^{k + 1}\frac{\cos(t\log k)}{k^{\sigma}},\quad\sigma > 0.
```
