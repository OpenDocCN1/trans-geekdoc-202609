
我现在解释肘部信号强度（[图 18.7](#Chp018_361-386_B9780443218576000229.xhtml#f0060) 中红色条形的高度）是如何计算的。首先，计算函数 `v'(m)`![Image](images/B9780443218576000229/si161.png) 的一阶和二阶差分：`δ[1](m) = v'(m−1) − v'(m)`![Image](images/B9780443218576000229/si169.png) 适用于 `m > 1`![Image](images/B9780443218576000229/si170.png)，以及 `δ[2](m) = δ[1](m−1) − δ[1](m)`![Image](images/B9780443218576000229/si171.png) 适用于 `m > 2`![Image](images/B9780443218576000229/si172.png)。肘部信号的强度在位置 `m > 1`![Image](images/B9780443218576000229/si170.png) 处为 `ρ[1](m) = max[0, δ[2](m+1) − δ[1](m+1)]`![Image](images/B9780443218576000229/si173.png)。我使用了 `ρ[1](m)`![Image](images/B9780443218576000229/si174.png) 的阻尼版本，即 `ρ[2](m) = ρ[1](m)/m`![Image](images/B9780443218576000229/si175.png)，以青睐拥有少数大簇的簇结构，而非众多小簇。较大的簇总是可以使用相同的聚类算法分解为多个簇。包含公式、图表和布朗运动模拟在内的数据位于我 GitHub 仓库中的电子表格 `PB_inference.xls` 内，[此处](https://github.com/VincentGranville/Point-Processes/tree/main/Spreadsheets)。请参阅 `Elbow_Brownian` 选项卡。您可以修改电子表格中以橙色高亮显示的参数：在本例中，单元格 `B16` 中的 `γ`。注意，`λ` 在单元格 `B17` 中设置为 `Γ(1+γ)`![Image](images/B9780443218576000229/si176.png)。

## 18.7 给初学者的建议

在本节中，我为机器学习初学者提供指导。读完本书并完成配套课程（包括成功完成学生项目）后，您应该已深入接触最重要的主题，其中许多在本书中都有详细介绍。此时，您应该能够自主继续学习——这即使对于顶尖专家也是一个永无止境的过程——特别是借助第 [18.7.1](#Chp018_361-386_B9780443218576000229.xhtml#s0140) 节提供的建议。

### 18.7.1 入门与学会如何学习

第一步是在笔记本电脑上安装 `Python`。虽然可以改用 `Jupyter` 笔记本 [[Wiki](https://jupyter.org/)]，但此选项功能有限，无法让您获得在专业商业环境中编写和测试正式代码的完整体验。安装好 `Python` 后，您可以在 `Python` 内部通过命令提示符使用指令 `python -m pip install jupyter` 来安装 Notebook，请见[此处](https://www.geeksforgeeks.org/how-to-install-jupyter-notebook-in-windows/)。您可能希望将其安装在笔记本电脑的虚拟机上：请见 `VMware` 虚拟机安装[此处](https://www.vmware.com/products/workstation-player.xhtml)。或者您可以通过 `Google Colab` 远程访问 Notebook，请见[此处](https://colab.research.google.com/notebooks/)和[此处](https://colab.research.google.com/)。

安装 `Python` 取决于您的系统。请访问官方 `Python.org` 网站[此处](https://www.python.org/downloads/)以开始并下载 `Python`。在我的 Windows 笔记本电脑上，我首先安装了 `Cygwin` 环境（安装方法见[此处](https://www.cygwin.com/)）以模拟 Unix 环境。这样，我就可以使用 `Cygwin` 窗口代替 Windows 命令提示符 [[Wiki](https://en.wikipedia.org/wiki/Cmd.exe)]。好处是它能识别 Unix 命令。`Cygwin` 的替代方案是 [Ubuntu](https://ubuntu.com/download)。您也可以使用 [Anaconda](https://www.anaconda.com/products/distribution) 环境。

无论哪种方式，您都需要将第一个 `Python` 程序保存为文本文件，例如 `test.py`。要运行它，请在命令窗口中输入 `Python test.py`。您需要熟悉基本的文件管理系统，以便根据需要创建文件夹和子文件夹。很快，您将需要在机器上安装 `Python` 库。最常用的包括 `pandas`、`scipy`、`seaborn`、`numpy`、`random` 和 `matplotlib`。您也可以创建自己的库，如第 [5.4.3](#Chp005_83-102_B9780443218576000096.xhtml) 节所示。在您的 `Python` 脚本中，仅使用所需的库。通常，它们列在代码开头，如下例所示：

#### 18.7.1.1 获取帮助

使用 `Python` 或任何编程语言学习更多知识和解决新问题的最简单方法之一是利用互联网。例如，当我用 `Python` 设计声音生成算法时（见第 [18.1](#Chp018_361-386_B9780443218576000229.xhtml#s0010) 节），我搜索了“Python sound processing”等关键词。我很快发现了许多从简单到高级的库和教程。随着时间推移，您会发现一些持续提供适合您需求的解决方案的网站，并倾向于坚持使用它们，直到您“进阶”到下一个专业水平并使用新资源。

重要的是要查看在线发布代码人员的资历，以及这些帖子的发布时间有多近。您必须甄别多个来源，识别出那些不好或过时的来源。通常，最好的建议来自讨论论坛上针对某些用户提供的解决方案而发布的简短评论。当然，您也可以发布自己的问题。这里有两个值得长期关注的宝贵来源：`GitHub` 和 `StackExchange`。`LinkedIn` 和 `Reddit` 上也有许多 `Python` 群组。最终，在花费一些时间搜索 `Python` 声音库后，我找到了不需要任何特殊库的解决方案：`numpy` 可以处理声音文件。我在互联网上发现所需一切只花了几个小时。

最后，随 `Python` 库附带的官方文档可能很有用，特别是如果您想使用特殊参数并了解内部工作原理（及局限性），而不仅仅是将它们作为具有默认设置的黑箱使用。例如，在研究时间序列的无模型参数估计（使用优化技术）时，我很快发现了 `Scipy` 库中的 `curve_fit` 函数。它在我的异常数据集上效果不佳（见第 [1.3.3.2](#Chp001_1-34_B9780443218576000059.xhtml) 节）。我在官方在线文档中发现了几个提高性能的设置。结果仍不令人满意（在我的案例中由于数值不稳定），我搜索了替代方案，发现群体优化技术（`curve_fit` 的一种替代方案）可在 `Pyswarms` 库中找到。最终，在这些库上使用丰富的合成数据进行测试，可以让您找到最适合您数据的方案。

我还提供与本书相关的课程，请见[此处](https://mltechniques.com/2022/09/29/course-intuitive-machine-learning/)。这是另一种学习更多知识并获得问题解答的途径。另请参阅第 [14.4.3](#Chp014_259-276_B9780443218576000187.xhtml) 节，了解我如何逐步解决新问题并找到相关代码。

#### 18.7.1.2 超越 Python

`Python` 已成为机器学习的标准语言。熟悉 `R` 编程语言将使您在就业市场上更具竞争力。第 [18.2](#Chp018_361-386_B9780443218576000229.xhtml#s0030) 节将向您展示如何在 `R` 中创建视频和更美观的图表。最后，机器学习专业人士至少应了解 `SQL` 的基础知识，因为许多工作仍涉及处理传统数据库。
