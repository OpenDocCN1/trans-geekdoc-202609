
这是通过 RGBA 颜色方案中的 A 分量实现的：它代表颜色的不透明度或透明度，允许通过 `α-compositing` 算法 [[Wiki](https://en.wikipedia.org/wiki/Alpha_compositing)] 进行颜色混合。RGBA 中的字母 A 以相关的 `α` 命名，该分量有时被称为 `α` 通道。该技术还允许您轻松区分高密度和低密度区域，由亮度决定，即重叠点上计算出的累积透明度级别。简而言之，它本身就执行密度估计！

对于类似的应用，请参阅 [图 18.5](#Chp018_361-386_B9780443218576000229.xhtml) 中的“发光图”。另请参阅第 [5](#Chp005_83-102_B9780443218576000096.xhtml) 章中描述的基于分形 GPU 的分类技术，及其相关视频 [此处](https://mltechniques.com/2022/03/31/very-deep-neural-networks-explained-in-40-seconds/)。

最后，数据点位于一条非周期轨道上，随着时间的推移覆盖一个稠密区域，见 [图 4.4](#Chp004_61-82_B9780443218576000084.xhtml#f0040)。因此，[图 4.5](#Chp004_61-82_B9780443218576000084.xhtml#f0045) 和 [图 4.6](#Chp004_61-82_B9780443218576000084.xhtml#f0050) 中的数据点是从该轨道采样的（实际上是 3 条轨道：红、蓝和黄），使它们在轨道上大致等距分布。可以使用类似于第 [6.3.1](#Chp006_103-111_B9780443218576000102.xhtml) 节中描述的重加权技术的方法来获得完美的间距。如果没有仔细采样，点的分布如 [图 4.7](#Chp004_61-82_B9780443218576000084.xhtml#f0055) 所示：轨道曲率更明显的地方，或更接近相关洞的地方，点密度较高。随着时间增加，平均密度变低，即随着越来越多的视频帧被显示。

轨道显示在 [图 4.7](#Chp004_61-82_B9780443218576000084.xhtml#f0055) 中。相关视频可在 [此处](https://www.youtube.com/watch?v=aub5am1YjIs) 找到。视频的额外价值在于它展示了点如何随时间缓慢填满一个稠密区域。还请注意与彗星视频的类比，其中太阳扮演吸引子的角色，但彗星永远不会穿过太阳（至少在模拟中）。这里，附着在轨道上的洞扮演太阳的角色。但一个巨大的区别是轨道是非周期性的。

### 练习 4.1

*点分类*。[图 4.6](#Chp004_61-82_B9780443218576000084.xhtml#f0050) 中的一个点具有 RGB 分量 (155, 105, 100)![Image](images/B9780443218576000084/si33.png)。它属于红、蓝或黄簇的概率是多少？

#### 解答

设 `p[r]`、`p[b]`、`p[y]`![Image](images/B9780443218576000084/si34.png) 为相关概率。它们满足

```latex
$M^{T} = \left( \begin{array}{rrr} {255\ } & {0\ } & 0 \\ {0\ } & {0\ } & 255 \\ {255\ } & {255\ } & 0 \\ \end{array} \right)^{T} \cdot \left( \begin{array}{r} p_{\text{r}} \\ p_{\text{b}} \\ p_{\text{y}} \\ \end{array} \right) = \left( \begin{array}{r} 155 \\ 105 \\ 100 \\ \end{array} \right).$
```

![Image](images/B9780443218576000084/si35.png)

通过求解上述系统获得解 `p[r] = 50/255`、`p[b] = 100/255`、`p[y] = 105/255`![Image](images/B9780443218576000084/si36.png)。矩阵 `M` 的第一行对应红色，第二行对应蓝色，第三行对应黄色 RGB 向量。 □

### 4.2.3.3 数学背景：黎曼假设

我所谓的数据点是狄利克雷 η 函数 `η(σ + it)`![Image](images/B9780443218576000084/si37.png) [[Wiki](https://en.wikipedia.org/wiki/Dirichlet_eta_function)] 的值，在 `t > 0`![Image](images/B9780443218576000084/si38.png) 的采样值处计算，针对 `m = 3`![Image](images/B9780443218576000084/si39.png) 个 `σ` 值，即 `σ[0] = 0.50`![Image](images/B9780443218576000084/si40.png) 对应红点，`σ[1] = 0.75`![Image](images/B9780443218576000084/si41.png) 对应蓝点，`σ[2] = 1.25`![Image](images/B9780443218576000084/si42.png) 对应黄点。复参数的符号 `σ + it`![Image](images/B9780443218576000084/si43.png) 在数论中已确立，我决定保留它。对该问题感兴趣的数学家会阅读本章，使用不同的符号会使我的表述别扭，并可能让他们感到困惑。

`η` 函数返回一个由以下定义的复值

```latex
$\Re\lbrack\eta(\sigma + it)\rbrack = \sum\limits_{k = 1}^{\infty}{(-1)}^{k + 1} \cdot \frac{\cos(t\log k)}{k^{\sigma}},\Im\lbrack\eta(\sigma + it)\rbrack = \sum\limits_{k = 1}^{\infty}{(-1)}^{k + 1} \cdot \frac{\sin(t\log k)}{k^{\sigma}},$
```

![Image](images/B9780443218576000084/si44.png)(4.1)

其中 ℜ、ℑ![Image](images/B9780443218576000084/si45.png) 分别代表实部和虚部。就我们的目的而言，不需要复数理论知识。实部和虚部只是二维向量的两个分量，实部在水平轴（X 轴）上，虚部在垂直轴（Y 轴）上。第 [4.3.2](#Chp004_61-82_B9780443218576000084.xhtml#s0070) 和 [4.3.3](#Chp004_61-82_B9780443218576000084.xhtml#s0075) 节中 Python 代码中用于 `η` 函数实部和虚部的符号分别是 `etax[n]` 和 `etay[n]`。这里 `n = 0`![Image](images/B9780443218576000084/si46.png) 对应 `σ = σ[0]`![Image](images/B9780443218576000084/si47.png)，`n = 1`![Image](images/B9780443218576000084/si48.png) 对应 `σ = σ[1]`![Image](images/B9780443218576000084/si49.png)，`n = 2`![Image](images/B9780443218576000084/si50.png) 对应 `σ = σ[2]`![Image](images/B9780443218576000084/si51.png)。时间参数 `t` 是 Python 代码中的全局变量，每次迭代递增，从 `t = 0`![Image](images/B9780443218576000084/si8.png) 开始。
