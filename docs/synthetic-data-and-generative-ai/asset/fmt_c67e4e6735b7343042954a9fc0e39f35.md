
Again, `η` is the angle determining the orientation of the shape. The point density, visible to the naked eye, is much higher on the right side of the shape on the left plot in [Fig. 6.2](#Chp006_103-111_B9780443218576000102.xhtml#f0015). This is even more pronounced on the lower part. As a result, the centroid (orange dot; dark gray in print version) attracted to the dense area of the curve. Once this effect is corrected by the weight function, the new centroid (gray dot) now appears well “centered”. Note that the weight function `w[t]`![Image](images/B9780443218576000102/si21.png), pictured in [Fig. 6.3](#Chp006_103-111_B9780443218576000102.xhtml#f0020), is bimodal. It was chosen to integrate to one, thus it represents a probability distribution on `T = [0, 1]`![Image](images/B9780443218576000102/si39.png).

## 6.4 Shape comparison

I start with a correlation metric based on the mathematical theory developed so far. I then discuss its strengths and weaknesses, and how to improve it. A full implementation on a real data set is investigated in Section [6.5](#Chp006_103-111_B9780443218576000102.xhtml#s0050). I use the notation `ρ[t]`, `φ[t]`![Image](images/B9780443218576000102/si29.png) for the first shape, and `ρ[t]′`, `φ[t]′`![Image](images/B9780443218576000102/si40.png) for the second. Assuming the parametric polar equations are such that (possibly after an appropriate transformation) `φ[t] = φ[t]′`![Image](images/B9780443218576000102/si41.png) for `t ∈ T`![Image](images/B9780443218576000102/si19.png), then define

```
γ = ∫[T](ρ[t] − ρ[t]′)² dt = ∫[T]ρ[t]² dt + ∫ρ[t]′² dt − 2∫[T]ρ[t]ρ[t]′ dt = 2 − 2λ
```

![Image](images/B9780443218576000102/si42.png)

where

```
λ = ∫[T]ρ[t]ρ[t]′ dt
```

![Image](images/B9780443218576000102/si43.png)

It follows from [(6.3)](#Chp006_103-111_B9780443218576000102.xhtml#deq10) that `0 ≤ λ ≤ 1`![Image](images/B9780443218576000102/si44.png). Furthermore, the two shapes are identical (up to a scaling factor and translation vector) if and only if `λ = 1`![Image](images/B9780443218576000102/si45.png). The correlation `λ` measures how close the two shapes are from each other. It relies on the fact that `φ[t] = φ[t]′`![Image](images/B9780443218576000102/si41.png). It this assumption is mildly violated, the classifier may still work on simple data sets, for instance, to recognize the letters of the alphabet. But it may fail is the discrepancy between `φ[t]`![Image](images/B9780443218576000102/si46.png) and `φ[t]′`![Image](images/B9780443218576000102/si47.png) is significant.

It is not always possible to satisfy `φ[t] = φ[t]′`![Image](images/B9780443218576000102/si41.png) for complicated shapes consisting of multiple arcs. But it can always be done for closed, convex shapes. Also, if the shapes are identical but rotated, usually `λ ≠ 1`![Image](images/B9780443218576000102/si48.png). The coefficient `λ` depends on the orientation angles `η`, `η′`![Image](images/B9780443218576000102/si49.png) of each shape, illustrated in formula [(6.1)](#Chp006_103-111_B9780443218576000102.xhtml#deq2). For this reason, `λ` is also denoted as `λ(η, η′)`![Image](images/B9780443218576000102/si50.png).

To circumvent this problem, one can use

```
\lambda^{*} = \min\limits_{\eta,\eta^{\prime}}\lambda(\eta,\eta^{\prime}).
```

![Image](images/B9780443218576000102/si51.png)

Then the two shapes are identical, up to the scaling factors, translation vectors, and orientations, if and only if `λ* = 1`![Image](images/B9780443218576000102/si52.png). Due to symmetry, one can set `η = 0`![Image](images/B9780443218576000102/si53.png). In practice, the metric `-log(1-λ)`![Image](images/B9780443218576000102/si54.png) or `-log(1-λ*)`![Image](images/B9780443218576000102/si55.png) is used instead. See [\[4\]](#Chp006_103-111_B9780443218576000102.xhtml#br0020) for a general reference on shape correlation.

Of course, it is always possible to compare two shapes by comparing their signatures, see [\[2\]](#Chp006_103-111_B9780443218576000102.xhtml#br0010). One way to do it is as follows. For each point `P[t]`![Image](images/B9780443218576000102/si56.png) on the first shape signature, find its closest neighbor `Q[t]`![Image](images/B9780443218576000102/si57.png) on the second shape signature, and compute the distance `D[t]`![Image](images/B9780443218576000102/si58.png) between these two points. Then compute

```
D = ∫[T]D[t] dt
```

![Image](images/B9780443218576000102/si59.png)

Repeat the operation by swapping the roles of the first and second shape: for each point `Q[t]′`![Image](images/B9780443218576000102/si60.png) on the second shape signature, find its closest neighbor `P[t]′`![Image](images/B9780443218576000102/si61.png) on the first shape signature, and compute the distance `D[t]′`![Image](images/B9780443218576000102/si62.png) between these two points. Then compute

```
D′ = ∫[T]D[t]′ dt
```

![Image](images/B9780443218576000102/si63.png)

If `D = 0`![Image](images/B9780443218576000102/si64.png), the first shape is a subset of the second shape. If `D′ = 0`![Image](images/B9780443218576000102/si65.png), the second shape is a subset of the first shape. If `D = D′ = 0`![Image](images/B9780443218576000102/si66.png), the shapes are identical. Thus `δ = min(D, D′)`![Image](images/B9780443218576000102/si67.png) is a metric measuring shape similarity. It is closely related to the `Hausdorff distance` [[Wiki](https://en.wikipedia.org/wiki/Hausdorff_distance)], albeit less sensitive to outliers.

### 6.4.1 Shape classification

Now that we have a metric to compare two shapes, we can use it as a similarity measure to perform shape classification. If shapes `S[1]`![Image](images/B9780443218576000102/si68.png) and `S[2]`![Image](images/B9780443218576000102/si69.png) have `-log(1-λ) > α`![Image](images/B9780443218576000102/si70.png), we may write `S[1] ∼ S[2]`![Image](images/B9780443218576000102/si71.png) to mean that they are equivalent (very similar). In this case, `α = 8`![Image](images/B9780443218576000102/si72.png) is a good threshold. In character recognition, if you have a training set with thousands of hieroglyphs, you can use this technique to classify any new hieroglyph as equivalent to one or more in your training set, or as yet uncategorized (a brand new one, or one so poorly written that it is not recognizable).
