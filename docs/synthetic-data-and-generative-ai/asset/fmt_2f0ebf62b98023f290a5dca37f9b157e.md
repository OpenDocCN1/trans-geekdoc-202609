
where `∇θ`![Image](images/B9780443218576000059/si57.png) is the gradient operator with respect to `θ` [[Wiki](https://en.wikipedia.org/wiki/Gradient)], and `λ` is called the **Lagrange multiplier** [[Wiki](https://en.wikipedia.org/wiki/Lagrange_multiplier)]. This is a classic constrained convex optimization problem. The top part of [(1.2)](#Chp001_1-34_B9780443218576000059.xhtml#deq2) consists of a system of `d + 1`![Image](images/B9780443218576000059/si40.png) equations with `d + 2`![Image](images/B9780443218576000059/si53.png) unknowns `θ[0]`, …, `θ[d]`![Image](images/B9780443218576000059/si58.png), and `λ`. The bottom part is a single equation with `d + 1`![Image](images/B9780443218576000059/si40.png) unknowns `θ[0]`, …, `θ[d]`![Image](images/B9780443218576000059/si58.png). Combined together, it constitutes a system of `d + 2`![Image](images/B9780443218576000059/si53.png) equations with `d + 2`![Image](images/B9780443218576000059/si53.png) unknowns. Note the analogy with **Lasso regression** [[Wiki](https://en.wikipedia.org/wiki/Lasso_\(statistics\))] when `η(θ) = θ^T θ − 1`![Image](images/B9780443218576000059/si43.png), that is, when `θ^T θ = 1`![Image](images/B9780443218576000059/si59.png).

The **mean squared error** (MSE) relative to a particular `θ` is defined as

$$
\text{MSE}(\theta) = \frac{1}{n}\sum\limits_{k = 1}^{n}g^{2}(W_{k},\theta) \geqslant \text{MSE}(\theta^{\ast}).
$$

![Image](images/B9780443218576000059/si60.png)(1.3)

Now define the R-squared with respect to `θ` as

$$
R^{2}(\theta) = 1 - \frac{\text{MSE}(\theta^{\ast})}{\text{MSE}(\theta)}.
$$

![Image](images/B9780443218576000059/si61.png)(1.4)

It follows immediately that `0 ≤ R²(θ) ≤ 1`![Image](images/B9780443218576000059/si62.png). A perfect fit corresponds to `MSE(θ*) = 0`![Image](images/B9780443218576000059/si63.png) (the whole cloud residing on the shape). In that case, if `θ ≠ θ*`![Image](images/B9780443218576000059/si64.png) and the optimum `θ*`![Image](images/B9780443218576000059/si10.png) is unique, then `R²(θ) = 1`![Image](images/B9780443218576000059/si65.png).

In traditional linear regression, the R-squared is defined as `R²(θ*)`![Image](images/B9780443218576000059/si66.png) where `θ*`![Image](images/B9780443218576000059/si67.png) is the optimum `θ` for the base model. The base model corresponds to all the coefficients `θ[i]`![Image](images/B9780443218576000059/si68.png) attached to the independent variables set to zero, except the one attached to the intercept. In other words, in the base model, the predicted `Y` is constant, equal to the empirical mean of `Y`. As a result, `MSE(θ*) = Var[Y]`![Image](images/B9780443218576000059/si69.png), the empirical variance of `Y`. A consequence is that `R²(θ*)`![Image](images/B9780443218576000059/si66.png) is the square of the correlation between the observed response `Y`, and the predicted response of the full model.

Backward compatibility with traditional linear regression works as follows. The standard univariate regression corresponds to `g(w, θ) = wθ = θ[0]y + θ[1]x + θ[2]`![Image](images/B9780443218576000059/si70.png), with the constraint `θ[0] = −1`![Image](images/B9780443218576000059/si17.png). Thus `g(w, θ) = 0`![Image](images/B9780443218576000059/si12.png) if and only if `y = θ[1]x + θ[2]`![Image](images/B9780443218576000059/si71.png). This generalizes to multivariate regression as well. A more elegant formulation in the new methodology is to replace the constraint `θ[0] = −1`![Image](images/B9780443218576000059/si17.png) by the symmetric constraint `θ[0]² + θ[1]² + θ[2]² = 1`![Image](images/B9780443218576000059/si72.png). Note that `w` is a row vector and `θ` is a column vector.

### 1.2.2 Upgrades to the model

By a model, I mean the general setting of the method: there is no probabilistic model involved in this discussion. **Prediction intervals** [[Wiki](https://en.wikipedia.org/wiki/Prediction_interval)] for the individual error `g(W[k], θ*)`![Image](images/B9780443218576000059/si73.png) at each data point `W[k]`![Image](images/B9780443218576000059/si74.png) (or for the estimated response attached to `Y[k]`![Image](images/B9780443218576000059/si75.png), if there is an independent variable) and confidence regions [[Wiki](https://en.wikipedia.org/wiki/Confidence_region)] for `θ*`![Image](images/B9780443218576000059/si10.png) can be obtained via resampling and bootstrapping [[Wiki](https://en.wikipedia.org/wiki/Bootstrapping_\(statistics\))]. This is also true for points outside the training set.

Also, the squares can be replaced by absolute values, as in **quantile regression** [[Wiki](https://en.wikipedia.org/wiki/Quantile_regression)], to minimize the impact of outliers and for scale preservation: if a variable is measured in years, then squares are expressed in squared years, a metric that is meaningless. This leads to a modified, better metric to assess the quality of the fit, replacing the R-squared. See Section [7.4](#Chp007_113-129_B9780443218576000114.xhtml) about “performance assessment” in Chapter [7](#Chp007_113-129_B9780443218576000114.xhtml), for alternatives to the R-squared. The goodness-of-fit (say, the R-squared) should be measured on the validation set [[Wiki](https://en.wikipedia.org/wiki/Training,_validation,_and_test_data_sets)] even though `θ*`![Image](images/B9780443218576000059/si10.png) is computed on a subset of the training set: this is a standard practice, called cross-validation [[Wiki](https://en.wikipedia.org/wiki/Cross-validation_\(statistics\))], illustrated on synthetic data in Chapter [8](#Chp008_131-145_B9780443218576000126.xhtml) about fuzzy regression.

Now, let us get back to the R-squared. In standard linear regression, the R-squared is defined as `R²(θ*)`![Image](images/B9780443218576000059/si66.png) via formula [(1.4)](#Chp001_1-34_B9780443218576000059.xhtml#deq4), where `θ*`![Image](images/B9780443218576000059/si67.png) is the optimum `θ` for the base model (the predicted response is constant, equal the mean of `Y` for the base model). In the new methodology, there may be no response. Still, the definition of `R²`![Image](images/B9780443218576000059/si76.png) extends to that situation, and is compatible with the traditional version. What is more, it leads to many possible `R²`![Image](images/B9780443218576000059/si76.png), one for each submodel (not just the base model), and this is true too for the standard regression. A submodel corresponds to adding constraints on the parameter vector `θ` or, in other words, working with a subset of the parameter space. Let `θ*`![Image](images/B9780443218576000059/si67.png) be the optimum for a specific submodel, while `θ*`![Image](images/B9780443218576000059/si10.png) is the optimum for the full model. Then the definition of `R²`![Image](images/B9780443218576000059/si76.png), depending on `θ*`![Image](images/B9780443218576000059/si67.png), is unchanged. It could not be any simpler!
