
## 17.3

本节涵盖一大类函数，从截断修正狄利克雷级数入手，以评估轨道中空洞的状态。随后我在第[17.3.2](#Chp017_329-360_B9780443218576000217.xhtml#s0070)节回到无限欧拉乘积，但这次不是像第[17.2.2](#Chp017_329-360_B9780443218576000217.xhtml#s0045)节那样针对全体素数集合，而是针对源自加法数论的无限子集。这些函数中有些在`σ` > `σ[0]`![Image](images/B9780443218576000217/si99.png)时无零点，其中（比如说）`σ[0]` = 5/6![Image](images/B9780443218576000217/si132.png)。因此它们满足GRH的一个较弱版本，称为拟GRH。第[17.3.3](#Chp017_329-360_B9780443218576000217.xhtml#s0095)节讨论没有欧拉乘积的非狄利克雷函数，但就轨道及其空洞而言，它们的行为类似于狄利克雷η函数`η(z)`![Image](images/B9780443218576000217/si29.png)。这里`P`是全体素数集合，但附着在`p^(-z)` = `σ^(-z)`cos(`t`log`p`) − `i``σ^(-z)`sin(`t`log`p`)![Image](images/B9780443218576000217/si133.png)上的正弦和余弦现在被小波取代。第[17.3.4](#Chp017_329-360_B9780443218576000217.xhtml#s0100)节处理模仿素数整数行为的非整数素数（甚至矩阵），称为Beurling素数。它们也带有欧拉乘积，相应的狄利克雷级数现在称为德德金ζ（或η）函数。第[17.3.5](#Chp017_329-360_B9780443218576000217.xhtml#s0105)节处理随机狄利克雷函数：其趣点在于相应的（随机）欧拉乘积在$\frac{1}{2} < \sigma \leqslant 1$![Image](images/B9780443218576000217/si134.png)时收敛，尽管是条件收敛。因此它们满足GRH的一个概率版本，特别是当$\sigma > \frac{1}{2}$![Image](images/B9780443218576000217/si17.png)时无零点。

### 17.3.1 有限狄利克雷级数

公式[(17.1)](#Chp017_329-360_B9780443218576000217.xhtml#deq2)包含一个有限（欧拉）乘积。然而，左边对应的级数却是无限的。这里我讨论一种不同的方法，即当`P`是全体素数集合时，使用仅包含完整狄利克雷级数前`n`项的有限版本。新函数定义为

$\eta(z,\beta,n) = \sum\limits_{k = 1}^{n}\delta_{k}\lambda_{k}p_{k}^{- z},$

![Image](images/B9780443218576000217/si135.png)(17.8)

其中`λ[k]` = 1/`k`![Image](images/B9780443218576000217/si136.png)对所有`k`成立，除了`k` = 2![Image](images/B9780443218576000217/si137.png)。系数`λ[2]`![Image](images/B9780443218576000217/si138.png)记为`β`。这里，若`k`为奇数则`δ[k]` = 1![Image](images/B9780443218576000217/si42.png)，否则`δ[k]` = −1![Image](images/B9780443218576000217/si44.png)。如果`n`无限且`β` = 1/2![Image](images/B9780443218576000217/si139.png)，则`η(z, β, n)`![Image](images/B9780443218576000217/si140.png)与标准狄利克雷η函数重合。

尽管级数项数有限，但这种方法困难得多。与第[17.2.1](#Chp017_329-360_B9780443218576000217.xhtml#s0035)节不同，没有简单的乘积（有限或无限）来表示截断的`η`函数。虽然第[17.2.1](#Chp017_329-360_B9780443218576000217.xhtml#s0035)节的方法带有浓厚的数论色彩，但这里我们处理的是逼近与数值分析。然而，`n` = 3![Image](images/B9780443218576000217/si141.png)的情况是平凡的：轨道填满一个环。空洞是一个以(1, 0)![Image](images/B9780443218576000217/si142.png)为中心的圆，而非原点。轨道的内外边界都是圆，半径已知。完整解答见[练习17.4](#Chp017_329-360_B9780443218576000217.xhtml#enun0030)。

但一般情况复杂得多。当然，对应有限欧拉乘积的级数产生的轨道具有一个半径>0的实心空洞，始终包含原点，且当显示完整的无限轨道时不会收缩为单点。但该级数总是有无限多项。随着截断级数项数增加，仅保留前`n`项且`β` = 1/2![Image](images/B9780443218576000217/si139.png)时，当`n` ≥ 5![Image](images/B9780443218576000217/si143.png)足够小时空洞消失，仅在`n` > 50![Image](images/B9780443218576000217/si144.png)时重新出现。此后空洞一直保持到`n` = ∞![Image](images/B9780443218576000217/si145.png)。随着`n`增加，空洞最终在X轴上向左移动，以包含原点。例如，在![Image](images/B9780443218576000217/fx002.jpg)处，原点位于空洞内。这是基于在`σ` = 0.90![Image](images/B9780443218576000217/si146.png)下目视检查轨道，配合![Image](images/B9780443218576000217/fx003.jpg)得出的；见[图17.6](#Chp017_329-360_B9780443218576000217.xhtml#f0035)。

对于没有空洞的小`n`值，增加`β`是重新在轨道中引入空洞的一种方法，如[图17.5](#Chp017_329-360_B9780443218576000217.xhtml#f0030)所示。这为探索RH提供了一条可能的新路径：使用大`n`，令`β` > 1/2![Image](images/B9780443218576000217/si147.png)（`β`越大，空洞越大），并让`β` → 1/2![Image](images/B9780443218576000217/si148.png)当`n` → ∞![Image](images/B9780443218576000217/si125.png)时。在[练习17.4](#Chp017_329-360_B9780443218576000217.xhtml#enun0030)中，我讨论了一些保证对于小`n`值存在包含原点的空洞的条件。

### 17.3.2 具有无限多素数和空洞的非平凡情况

现在，让我们回到欧拉乘积。因此，相关的狄利克雷级数（乘积的展开）总是包含无限多项，即使乘积是有限的。对于给定的`σ`，为了得到一个包含原点的空洞，使轨道与原点的距离在所有时刻`t`都⩾ `ρ`，必须满足以下条件：

$\rho = \prod\limits_{p \in P}\frac{1}{1 + p^{- \sigma}} > 0.$

![Image](images/B9780443218576000217/si150.png)(17.9)

这在第[17.2.2.1](#Chp017_329-360_B9780443218576000217.xhtml#s0050)节开头简要讨论过。注意，此要求与函数`χ`无关。如果乘积是有限的（即集合`P`是有限的），或`σ` > 1![Image](images/B9780443218576000217/si19.png)，或`σ` < 1![Image](images/B9780443218576000217/si9.png)且`P`是无限但足够稀疏以使乘积收敛，则满足该条件。本节讨论后一种情况。
