

## 12.2 随机游走与布朗运动

### 12.2.1 二维广义随机游走

在某种意义上，这与之前研究的例子相似，偏离迭代对数律导致了异常模式：要么振荡非常强，要么非常弱。请注意，此处执行的所有模拟均由离散随机游走组成，而非时间连续的布朗运动。它们非常逼近布朗运动，但由于现代计算机（至少截至目前）是“数字”而非“模拟”式的，一切都被分解为比特，因此本质上是离散的，尽管颗粒度极大。

在一维情况下，我们从 `S[0] = 0`![Image](images/B9780443218576000163/si3.png) 和 `S[n] = S[n-1] + R[n] θ[n]`![Image](images/B9780443218576000163/si94.png) 开始，其中 `n = 1, 2`![Image](images/B9780443218576000163/si95.png)，以此类推。如果 `R[n]`![Image](images/B9780443218576000163/si96.png) 独立同分布（iid），服从期望为 `1/λ`![Image](images/B9780443218576000163/si97.png) 的指数分布，且 `θ[n] = 1`![Image](images/B9780443218576000163/si98.png)，则生成的过程是在 ℝ⁺![Image](images/B9780443218576000163/si99.png) 上具有强度函数 `λ` 的平稳**泊松点过程** [[Wiki](https://en.wikipedia.org/wiki/Poisson_point_process)]；`R[n]`![Image](images/B9780443218576000163/si96.png) 是连续的**到达间隔时间**。如果 `θ[n]`![Image](images/B9780443218576000163/si100.png) 独立同分布，满足 `P(θ_n = 1) = P(θ_n = -1) = 1/2`![Image](images/B9780443218576000163/si101.png)，且独立于 `R[n]`![Image](images/B9780443218576000163/si96.png)，则会得到一种完全不同类型的过程，经过适当重缩放后，它代表一维时间连续的**布朗运动**。有关一般参考文献，请参见 [[2]](#Chp012_229-241_B9780443218576000163.xhtml#br0010)，[[3]](#Chp012_229-241_B9780443218576000163.xhtml#br0015)。

我将其推广到二维，具体如下。从 `(S[0], S[0]') = (0, 0)`![Image](images/B9780443218576000163/si102.png) 开始。然后使用递归公式生成点 `(S[n], S[n]')`![Image](images/B9780443218576000163/si103.png)，其中 `n = 1, 2`![Image](images/B9780443218576000163/si95.png)，以此类推：

```
S[n] = S[n-1] + R[n] cos(2π θ[n])   (12.4)
```

![Image](images/B9780443218576000163/si104.png)

```
S[n]' = S[n-1]' + R[n] sin(2π θ[n])   (12.5)
```

![Image](images/B9780443218576000163/si105.png)

其中 `θ[n]`![Image](images/B9780443218576000163/si100.png) 在 `[0, 1]`![Image](images/B9780443218576000163/si37.png) 上均匀分布，半径 `R[n]`![Image](images/B9780443218576000163/si96.png) 通过以下公式生成：

```
R_n = (1/λ) * (-log(1 - U_n))^γ   (12.6)
```

![Image](images/B9780443218576000163/si106.png)

其中 `U[n]`![Image](images/B9780443218576000163/si107.png) 在 `[0, 1]`![Image](images/B9780443218576000163/si37.png) 上均匀分布。此外，`λ > 0`![Image](images/B9780443218576000163/si108.png)，随机变量 `U[n], θ[n]`![Image](images/B9780443218576000163/si109.png) 相互独立。如果 `γ > -1`![Image](images/B9780443218576000163/si110.png)，则 `E[R_n] = (1/λ) Γ(1 + γ)`![Image](images/B9780443218576000163/si111.png)，其中 `Γ` 是**伽马函数** [[Wiki](https://en.wikipedia.org/wiki/Gamma_function)]。为了标准化该过程，我使用 `λ = Γ(1 + γ)`![Image](images/B9780443218576000163/si112.png)。因此，`E[R[n]] = 1`![Image](images/B9780443218576000163/si113.png)，且如果 `γ > -1/2`![Image](images/B9780443218576000163/si114.png)，

```
Var[R_n] = Γ(1 + 2γ) / Γ²(1 + γ) - 1
```

![Image](images/B9780443218576000163/si115.png)

我们有以下情况：

*   如果 `γ = 1`![Image](images/B9780443218576000163/si116.png)，则 `R[n]`![Image](images/B9780443218576000163/si96.png) 服从指数分布。
*   如果 `-1 < γ < 0`![Image](images/B9780443218576000163/si117.png)，则 `R[n]`![Image](images/B9780443218576000163/si96.png) 服从**弗雷歇分布**。如果此外 `γ > -1/2`![Image](images/B9780443218576000163/si114.png)，则其方差有限。
*   如果 `γ > 0`![Image](images/B9780443218576000163/si118.png)，则 `R[n]`![Image](images/B9780443218576000163/si96.png) 服从**韦伯分布**，方差有限。

有趣的是，弗雷歇分布和韦伯分布是**极值理论**中三个**吸引子分布**中的两个。

由点 `(S[n], S[n]')`![Image](images/B9780443218576000163/si103.png) 组成的二维过程是一种特殊类型的随机游走。随机变量 `R[n]`![Image](images/B9780443218576000163/si96.png) 代表连续增量的（可变）长度。在适当重缩放下，假设 `R[n]`![Image](images/B9780443218576000163/si96.png) 的方差有限，它趋于时间连续的二维布朗运动。然而，如果 `Var[R[n]] = ∞`![Image](images/B9780443218576000163/si119.png)，它可能不会收敛到布朗运动。相反，它非常类似于**莱维飞行** [[Wiki](https://en.wikipedia.org/wiki/L%C3%A9vy_flight)]，并产生强聚类结构，聚类之间间隔明显。参见 [图 12.4](#Chp012_229-241_B9780443218576000163.xhtml#f0025)，基于 `γ = -1/2`![Image](images/B9780443218576000163/si120.png)，`λ = 8`![Image](images/B9780443218576000163/si121.png)，展示了二元序列 `{(S[n], S[n]')}`![Image](images/B9780443218576000163/si122.png) 的前 ![Image](images/B9780443218576000163/fx005.jpg) 个点。

莱维飞行对 `R[n]`![Image](images/B9780443218576000163/si96.png) 使用**莱维分布** [[Wiki](https://bit.ly/3rV7mrq)]，该分布同样具有无限期望和方差。连同**柯西分布**（同样具有无限期望和方差），它是为数不多的**稳定分布** [[Wiki](https://en.wikipedia.org/wiki/Stable_distribution)] 之一。此类分布是适应版**中心极限定理**（CLT）的吸引子，就像高斯分布是标准 CLT 的吸引子一样。关于该主题有一本写得很好的开创性著作，即格涅坚科和柯尔莫戈罗夫合著的《独立随机变量和的极限分布》 [[5]](#Chp012_229-241_B9780443218576000163.xhtml#br0025)。

有关布朗运动及相关过程的简单介绍，请参阅 Kyle Siegrist 的网站 [RandomServices.org](https://www.randomservices.org/)，特别是关于标准布朗运动的章节，[点此查看](https://www.randomservices.org/random/brown/Standard.xhtml)。第 [12.2.1](#Chp012_229-241_B9780443218576000163.xhtml#s0050) 节讨论的过程在我的著作《随机过程与仿真：机器学习视角》[[7]](#Chp012_229-241_B9780443218576000163.xhtml#br0035) 中得到了进一步探讨。

### 12.2.2 积分布朗运动与特殊自回归过程

[图 12.5](#Chp012_229-241_B9780443218576000163.xhtml#f0030) 中展示的布朗运动由简单的时间离散**自回归时间序列** [[Wiki](https://en.wikipedia.org/wiki/Autoregressive_model)] 生成。因此，基础过程具有自相关性，但如果自相关结构足够弱，极限（重缩放后）仍为标准布朗运动，因此是完全随机的。

该自回归（AR）模型由初始条件 `S[1], ..., S[p]`![Image](images/B9780443218576000163/si123.png) 和递归公式驱动：

```
S[n] = a[1] S[n-1] + ... + a[p] S[n-p] + e[n]
```
