

## 4.1 简介

我从图 [4.2](#Chp004_61-82_B9780443218576000084.xhtml#f0030) 和 [4.3](#Chp004_61-82_B9780443218576000084.xhtml#f0035) 开始。这是一幅彗星绕太阳运行的模拟图，彗星具有不同的速度、轨道朝向和离心率。目的是评估碰撞风险。这些图片无法很好地呈现所涉及的所有维度。因此我制作了两个视频，可在[此处](https://www.youtube.com/watch?v=GD_ZPb48lmk)（展示轨道）和[此处](https://www.youtube.com/watch?v=CeYmsBdfrHM)（展示彗星属性和碰撞）观看。视频增加的维度远不止一个——即时间——有助于理解系统的力学机制。

本章旨在向您介绍丰富的可视化技术，重点关注使用 Python 构建的 GIF 动画和视频。例如，彗星视频可以呈现静态图片难以展示的多个维度：任意时刻的彗星位置、每颗彗星的相对速度、速度变化（加速度）、彗星接近太阳时大小的变化、彗星间的相互作用（视在碰撞）、轨道的任何变化（朝向或离心率），或成分的任何变化（分配给彗星的颜色）。静态图片擅长展示大小、轨道路径和彗星成分。我们可以使其更通用一些，用 3D 形式展示运动。无论如何，我们都可以轻松展示 17 个维度。彗星视频中呈现的 17 个维度包括：

- 空间和时间中的位置（3 或 4 个维度）
- 彗星成分或类型，以及成分变化（2 个维度，分类变量）
- 彗星大小及其变化（2 个维度，此处为分类/分箱变量）
- 彗星速度和加速度，包括加速度变化（3 个维度）
- 轨道朝向（旋转角）和离心率，以及这些指标的变化（4 个维度）
- 每个轨道的周期，以及碰撞（2 个维度）
- 任意时刻的彗星数量（1 个维度）

虽然传统的时间序列图也能展示所有这些特征，但视频传达的信息更引人入胜，能提供强有力的视觉洞察。注意，在我的视频中，任何特定彗星的轨道、大小和成分都是静态的。我用颜色表示速度和离心率：红色 = 快，绿色 = 高离心率，紫色 = 快 + 高离心率，白色 = 标准。此外，大小（大或小）与到太阳的最大距离有关：小点代表永久停留在靠近太阳处的彗星。

本章其余部分重点介绍四个应用：任意维度的预测区间、监督分类、处理混沌函数时梯度下降等算法的收敛性，以及空间时间序列（彗星演示）。在某些情况下，使用视频有帮助，而在其他情况下则不然。所有 Python 可视化均使用 `RGB`（红/绿/蓝）颜色模型 [[Wiki](https://en.wikipedia.org/wiki/RGB_color_model)]。它可以表示 3 个维度。其中一个视频使用 `RGBA` 模型 [[Wiki](https://en.wikipedia.org/wiki/RGBA_color_model)]，允许您添加透明度或不透明度。这在显示重叠簇时特别有用：当红色簇与绿色簇重叠时，交叉部分呈黄色（红 + 绿 = 黄）。我还使用 `antialiasing`（抗锯齿）[[Wiki](https://en.wikipedia.org/wiki/Anti-aliasing)] 使轮廓看起来平滑而非像素化。最后，我使用一种压缩技术（`FFmpeg`，[[Wiki](https://en.wikipedia.org/wiki/FFmpeg)]）来减小 GIF 动画的体积。

在未来的文章中，我将为视频添加与整个系统行为相关的配乐。声音（振幅、频率、纹理）可以轻松增加 3 个维度。例如，它可以表示任意时刻宇宙的局部温度、密度和大小。

### 4.2.1 空间时间序列

这里我讨论 [4.1 节](#Chp004_61-82_B9780443218576000084.xhtml#s0010) 中介绍的彗星可视化。所有轨道均为椭圆形。这些轨道是二元连续时间序列，换句话说，就是空间时间序列。当我们查看椭圆的参数方程时，这一点将变得显而易见。以原点为中心、未倾斜的椭圆的笛卡尔方程为

$$\frac{x^{2}}{a^{2}} + \frac{y^{2}}{b^{2}} = 1,$$

![Image](images/B9780443218576000084/si1.png)

其中 `a`, `b` > 0![Image](images/B9780443218576000084/si2.png)。离心率定义为 $\epsilon = \sqrt{|a^{2} - b^{2}|}$![Image](images/B9780443218576000084/si3.png)。当 `ϵ` = 0![Image](images/B9780443218576000084/si4.png) 时，椭圆为圆。如果 `ϵ` 很大，椭圆会变得细长。在所有情况下，“水平”椭圆有两个焦点：(`g[x]′`, `g[y]′`) = (0, `ϵ`)![Image](images/B9780443218576000084/si5.png) 和 (`g[x]`, `g[y]`) = (0, −`ϵ`)![Image](images/B9780443218576000084/si6.png)。由于旋转对称性，不失一般性，我仅考虑水平椭圆，并忽略第二个焦点。椭圆的参数方程为

`x[0](t) = a ⋅ cos(v t + τ)`, `y[0](t) = b ⋅ sin(v t + τ)`,

![Image](images/B9780443218576000084/si7.png)

其中 `v` 是彗星的速度，`t` 代表时间，`τ` 决定 `t` = 0 时彗星的初始位置![Image](images/B9780443218576000084/si8.png)。然后我应用角度为 `θ` 的旋转。参数 `θ` 称为轨道朝向。现在椭圆的参数方程变为

`x(t) = x[0](t) cos θ − y[0](t) sin θ`, `y(t) = x[0](t) sin θ + y[0](t) cos θ`,

![Image](images/B9780443218576000084/si9.png)

其感兴趣的焦点变为 (`g[x]`, `g[y]`) = (`g[x]′ cos θ − g[y]′ sin θ`, `g[x]′ sin θ + g[y]′ cos θ`)![Image](images/B9780443218576000084/si10.png)。

现在，我希望太阳位于原点，让彗星绕太阳旋转。这是通过从 (`x(t)`, `y(t)`)![Image](images/B9780443218576000084/si12.png) 中减去向量 (`g[x]`, `g[y]`)![Image](images/B9780443218576000084/si11.png) 来实现的。最后，有 `m` 颗彗星，标记为 0, …, `m` − 1![Image](images/B9780443218576000084/si13.png)。符号 (`x[n](t)`, `y[n](t)`)![Image](images/B9780443218576000084/si14.png) 表示第 `n` 颗彗星在时间 `t` 的位置，其中 0 ≤ `n` < `m`![Image](images/B9780443218576000084/si15.png)。时间均匀采样：每个采样值在视频中生成一帧，包含 `m` 个点，每颗彗星一个。

参数 `τ`, `θ`, `v`, `a`, `b`![Image](images/B9780443218576000084/si16.png)，更准确地说是 `τ[n]`, `θ[n]`, `v[n]`, `a[n]`, `b[n]`![Image](images/B9780443218576000084/si17.png)（因为每个轨道有一组），都是随机生成的。然而，对于符合宇宙定律（例如开普勒定律）的真实模拟，应对这些参数施加若干约束。例如，彗星接近太阳时速度应增加。此外，忽略了引力相互作用。事实上，正因如此，真实轨道并非真正周期性的，这与模拟中的情况不同。

### 4.2.2 任意维度的预测区间
