
我在 Python 代码的第 [1.3.4.4](#Chp001_1-34_B9780443218576000059.xhtml#s0100) 节中包含了 **K-means clustering** 方法 [[Wiki](https://en.wikipedia.org/wiki/K-means_clustering)]。这里我将 `Kmeans` 与我的方法进行比较，使用两个数据集，每个数据集包含 `n` = 1000 个点和两个重叠的簇。基于底层混合模型的理论簇中心分别为 0.5 和 1.0。数据集如图 [1.5](#Chp001_1-34_B9780443218576000059.xhtml#f0040) 和 [1.7](#Chp001_1-34_B9780443218576000059.xhtml#f0050) 所示。

在具有显著簇重叠的挑战性数据上，我的方法经常优于 `Kmeans`。然而，在严重倾斜的数据上，你需要公式 [(1.10)](#Chp001_1-34_B9780443218576000059.xhtml#deq15) 中的两个指数 `p[A]`、`p[B]`，而不仅仅是 `p`，才能获得最佳性能。当使用 (`p[A]`, `p[B]`) = (3, 1) 时，我的方法表示为 (3, 1)。同样，当 (`p[A]`, `p[B]`) = (1, 1) 或 (2, 1) 时，我的方法分别表示为 (1, 1) 和 (2, 1)。直观上，模型 (3, 1) —— 与默认版本 (1, 1) 相比 —— 允许你通过用较小的 `p[A]` 惩罚其对 `MSE` 的贡献，来减少高度主导簇 `A` 的影响。由于问题的对称性，模型 (3, 1) 和 (1, 3) 产生相同的最优中心（标签互换），并在最优处具有相同的 `MSE`。与整个数据集质心重合的单簇参考模型称为“base”模型。一种替代方案是在 base 模型中使用 **medoid** [[Wiki](https://en.wikipedia.org/wiki/Medoid)] 而不是质心。

本节剩余部分除了模型比较外，重点在于自动检测默认模型 (1, 1) 是否足以适应特定数据集，或者是否应改用 (2, 1) 或 (3, 1) 生成的簇中心。决策基于第 [1.3.4.2](#Chp001_1-34_B9780443218576000059.xhtml#s0090) 节开头定义的 `MSE`。然而，即使对于相同的 `θ` 和同一数据集，比较 `MSE(1,1)` 和 `MSE(1,3)` 也是无意义的。这就是我们面临的挑战。

为了解决这个问题，我首先计算所有方法和两个数据集的 `MSE(1,1)` 和 `MSE(3,1)`。我跳过了 `MSE(2,1)`，因为它产生的解与 `MSE(3,1)` 相似。结果汇总在表 [1.3](#Chp001_1-34_B9780443218576000059.xhtml#t0020) 中（针对第一个数据集）和表 [1.4](#Chp001_1-34_B9780443218576000059.xhtml#t0025) 中（针对第二个数据集）。向量 `θ*(1,1)` = (`θ_A*(1,1)`, `θ_B*(1,1)`) 包含根据模型 (1, 1) 确定的两个最优中心（给定数据集）。相同的符号 `θ*(3,1)` 用于模型 (3, 1)。

表 [1.3](#Chp001_1-34_B9780443218576000059.xhtml#t0020) 和 [1.4](#Chp001_1-34_B9780443218576000059.xhtml#t0025) 中的红色条目（印刷版为浅灰色）对应模型 (1, 1) 和 (3, 1) 的最优值。第一个数据集中模型 `M(1,1)` 的中心（表 [1.3](#Chp001_1-34_B9780443218576000059.xhtml#t0020)），以及第二个数据集中模型 `M(3,1)` 的中心（表 [1.4](#Chp001_1-34_B9780443218576000059.xhtml#t0025)），比 `Kmeans` 产生的中心更接近真实值 0.5 和 1.0。然而，要声称我的方法优于 `Kmeans`，你需要一种机制来决定何时 `M(1,1)` 或 `M(3,1)` 是最佳拟合。这仍在进行中。作为起点，以下论据提供了决策的经验法则：

- 对于第一个数据集，在整个数据集质心（base 模型）处评估的 `MSE(1,1)` 优于（低于）在 `θ*(3,1)` 处评估的值，表明 `θ*(3,1)` 在这里不是一个很好的解。因此，在这种情况下应优先选择默认模型 (1, 1) 而非 (3, 1)。
- 对于第二个数据集，在质心处评估的 `MSE(1,1)` 大约等于在 `θ*(3,1)` 处评估的值，表明 `θ*(3,1)` 并不那么差，至少不如前一种情况那么差。因此，在这种情况下不应自动排除模型 (3, 1)。这也表明该数据集比前一个更具挑战性。
