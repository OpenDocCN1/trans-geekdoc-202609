
# 数学推导与练习

## 预备推导

- `χ^⋆(p[k]) = +1`![Image](images/B9780443218576000217/si354.png) 如果 `m[k]`![Image](images/B9780443218576000217/si347.png) 是偶数，否则 `χ^⋆(p[k]) = -1`![Image](images/B9780443218576000217/si355.png)。

此外，`p^(-z) = [cos(t log p[k]) + i sin(t log p[k])] ⋅ p^(-σ) → χ^⋆(p[k]) p^(-σ)`![Image](images/B9780443218576000217/si356.png) 当 `t → ∞`![Image](images/B9780443218576000217/si357.png) 时。因此对于欧拉乘积，使用上述讨论的特殊 `t`（`m[1], …, m[d]`![Image](images/B9780443218576000217/si358.png) 的函数）和 `z = σ + i t`![Image](images/B9780443218576000217/si2.png)，我们有

### 公式 (17.17)

$$
L_P(z,\chi)\rightarrow\prod_{k=1}^{d}\frac{1}{1 - \chi^{\star}(p_k)\chi(p_k)p_k^{-\sigma}} \in \mathbb{R}\quad\text{as }t\rightarrow\infty.
$$

![Image](images/B9780443218576000217/si359.png)(17.17)

如果 `∑[p ∈ P] p^(-σ) = ∞`![Image](images/B9780443218576000217/si360.png)，那么当 `d → ∞`![Image](images/B9780443218576000217/si62.png) 时，公式 [(17.17)](#Chp017_329-360_B9780443218576000217.xhtml#deq39) 中的乘积可以任意逼近任意正值。实际上，`d[k] = χ^⋆(p[k])`![Image](images/B9780443218576000217/si361.png) 可以看作在某种特殊的记数系统中（实数）`L[P](z, χ)`![Image](images/B9780443218576000217/si107.png) 的第 `k` 个二进制数字。你可以使用类似于基数 2 中标准二进制数字的技术来计算 `d[k]`![Image](images/B9780443218576000217/si362.png)，即 **贪心算法** 的一个版本 [[Wiki](https://en.wikipedia.org/wiki/Greedy_algorithm)]。要任意逼近零，一种方法是选择函数 `χ^⋆`![Image](images/B9780443218576000217/si349.png) 使得 `χ^⋆ χ = -1`![Image](images/B9780443218576000217/si363.png)。

## 注记

在计算 `S(χ^⋆)`![Image](images/B9780443218576000217/si364.png) 时，我隐式地使用了以下事实。首先，如果 `k` 的质因数分解为 `k = p[1]^(a[1])⋯p[d]^(a[d])`![Image](images/B9780443218576000217/si365.png)，则 `cos(t log k) = cos(a[1] t log p[1] + ⋯ + a[d] t log p[d])`![Image](images/B9780443218576000217/si366.png)。递归使用 `cos(α + β) = cos α cos β - sin α sin β`![Image](images/B9780443218576000217/si367.png)，利用所有正弦为零以及 `cos(a[i] t log p[i]) → cos(a[i] m[i] π) = [χ^⋆(p[i])]^(a[i])`![Image](images/B9780443218576000217/si368.png) 当 `t → ∞`![Image](images/B9780443218576000217/si357.png) 时这一事实，可得 `cos(t log k) → [χ^⋆(p[1])]^(a[1])⋯[χ^⋆(p[d])]^(a[d]) = χ^⋆(k)`![Image](images/B9780443218576000217/si369.png)。

## 练习 17.6：形式为 x³ + y² 的整数的密度

**问题陈述：** 证明形式为 `x³ + y²`![Image](images/B9780443218576000217/si161.png) 的第 `k` 个整数渐近大于 `k^(6/5)`![Image](images/B9780443218576000217/si170.png)。

### 解答

设 `v(n)`![Image](images/B9780443218576000217/si371.png) 为满足 `x³ + y² ≤ n`![Image](images/B9780443218576000217/si373.png) 的格点 `(x, y)`![Image](images/B9780443218576000217/si372.png) 的数量，其中 `x, y`![Image](images/B9780443218576000217/si164.png) 为正整数。估计 `v[n]`![Image](images/B9780443218576000217/si374.png) 是 **加性数论** [[Wiki](https://en.wikipedia.org/wiki/Additive_number_theory)] 中的一个经典问题，推广了 **高斯圆问题** [[Wiki](https://en.wikipedia.org/wiki/Gauss_circle_problem)]。这类问题的解法如下。设 `S[1], …, S[m]`![Image](images/B9780443218576000217/si375.png) 为 `m` 个正整数无限集合，`v[i](n)`![Image](images/B9780443218576000217/si376.png) 为 `S[i]`![Image](images/B9780443218576000217/si377.png) 中小于 `n` 的元素个数。设 `v(n)`![Image](images/B9780443218576000217/si371.png) 为满足 `x[1] + ⋯ + x[m] ≤ v(n)`![Image](images/B9780443218576000217/si380.png) 的格点 `(x[1], …, x[m])`![Image](images/B9780443218576000217/si378.png) 的数量，其中 `x[i] ∈ S[i]`![Image](images/B9780443218576000217/si379.png)。如果 `v[i](n) ∼ a[i] n^(b[i]) (log n)^(-c[i])`![Image](images/B9780443218576000217/si381.png) 其中 `0 < b[i] ≤ 1`![Image](images/B9780443218576000217/si382.png)，`c[i] ≥ 0`![Image](images/B9780443218576000217/si383.png) 且 `a[i] > 0  (i = 1, …, m)`![Image](images/B9780443218576000217/si384.png)，则

$$
v(n) \lesssim \frac{\prod_{i=1}^{m} a_i \Gamma(b_i + 1)}{\Gamma(1 + \sum_{i=1}^{m} b_i)} \cdot \frac{n^{b_1 + \cdots + b_m}}{(\log n)^{c_1 + \cdots + c_m}},
$$

![Image](images/B9780443218576000217/si385.png)

其中 ≲ 表示“渐近更小”，Γ 为伽马函数。详情请见[此处](https://mathoverflow.net/questions/364559/general-asymptotic-result-in-additive-combinatorics-sums-of-sets)和[此处](https://mathoverflow.net/questions/363055/goldbach-conjecture-and-other-problems-in-additive-combinatorics/)。

在本例中，`m = 2`![Image](images/B9780443218576000217/si386.png)，`a[1] = a[2] = 1`![Image](images/B9780443218576000217/si387.png)，`c[1] = c[2] = 0`![Image](images/B9780443218576000217/si388.png)，`b[1] = 1/3`![Image](images/B9780443218576000217/si389.png)，`b[2] = 1/2`![Image](images/B9780443218576000217/si390.png)。因此 `v(n) ≲ n^(5/6)`![Image](images/B9780443218576000217/si391.png)。注意此方法可能导致重复计数，例如 `225 = 6³ + 3² = 5³ + 10² = 0³ + 15²`![Image](images/B9780443218576000217/si392.png)。因此形式为 `x³ + y²`![Image](images/B9780443218576000217/si161.png) 的正整数的实际数量 `w(n)`![Image](images/B9780443218576000217/si393.png) 甚至更小，肯定小于 `n^(5/6)`![Image](images/B9780443218576000217/si169.png)。利用函数 `w(n)`![Image](images/B9780443218576000217/si393.png) 的反函数，立即可得第 `k` 个元素渐近大于 `n^(6/5)`![Image](images/B9780443218576000217/si394.png)。

## 练习 17.7：狄利克雷函数的奇特因式分解

**问题陈述：** 基于欧拉乘积，证明 `L[P](z, χ) = L[P](z/2, ψ) L[P](z/2, -ψ)`![Image](images/B9780443218576000217/si395.png)，其中 `ψ²(p) = χ(p)`![Image](images/B9780443218576000217/si396.png)，因此 `ψ(p) ∈ {1, -1, i, -i}`![Image](images/B9780443218576000217/si397.png)。特别地，如果 `χ(p) = 1`![Image](images/B9780443218576000217/si100.png)，可以选择 `ψ(p[2k+1]) = 1`![Image](images/B9780443218576000217/si398.png) 和 `ψ(p[2k]) = -1`![Image](images/B9780443218576000217/si399.png)，其中 `p[k]`![Image](images/B9780443218576000217/si112.png) 是第 `k` 个素数。在这种情况下，`L(z, χ) = ζ(z)`![Image](images/B9780443218576000217/si400.png)，且如果 `σ > 0`![Image](images/B9780443218576000217/si30.png)，`L(z/2, ψ)`![Image](images/B9780443218576000217/si401.png) 和 `L(z/2, -ψ)`![Image](images/B9780443218576000217/si402.png) 的欧拉乘积均收敛。然而，`L[P](z/2, ψ) L[P](z/2, -ψ) = ζ(z)`![Image](images/B9780443218576000217/si403.png) 仅当 `σ > 1`![Image](images/B9780443218576000217/si19.png) 时成立。这些公式如何递归推广？
