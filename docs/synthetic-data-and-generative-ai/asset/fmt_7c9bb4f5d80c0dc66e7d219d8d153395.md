
### 11.2.2 Machine Precision and BBP Formulas

However, because of machine precision (the problem discussed in Section [11.2.2](#Chp011_203-228_B9780443218576000151.xhtml#s0040)), the `x[k]`![Image](images/B9780443218576000151/si112.png)'s generated by a computer for the shift map (or any map for that matter) eventually become periodic. Thus `{d(k)}`![Image](images/B9780443218576000151/si17.png) becomes periodic, too. A workaround is the use exact arithmetic to compute `d(k)`![Image](images/B9780443218576000151/si29.png), as in my Python code in Section [11.3.3](#Chp011_203-228_B9780443218576000151.xhtml#s0070). Another solution is to use **Bailey–Borwein–Plouffe formulas** \[[Wiki](https://en.wikipedia.org/wiki/Bailey%E2%80%93Borwein%E2%80%93Plouffe_formula)\] to compute the digits. There are many BBP formulas for various good **transcendental** seeds \[[Wiki](https://en.wikipedia.org/wiki/Transcendental_number)\] such as `` `$x_0 = \frac{\pi}{4}` ``![Image](images/B9780443218576000151/si125.png), but as far as I know, none for the subset of **algebraic numbers** \[[Wiki](https://en.wikipedia.org/wiki/Algebraic_number)\] such as `` `$x_0 = \sqrt{2}/2` ``![Image](images/B9780443218576000151/si122.png).

If `L[3]^*(n) < 0.5`![Image](images/B9780443218576000151/si53.png) or `L[3]^*(n) > 1.5`![Image](images/B9780443218576000151/si54.png), the sequence `{d(k)}`![Image](images/B9780443218576000151/si17.png) (the first `n` elements) lacks true randomness; it is not **strongly pseudorandom**. [Table 11.1](#Chp011_203-228_B9780443218576000151.xhtml#t0010) summarizes these findings for a larger collection of sequences, computed at ![Image](images/B9780443218576000151/fx001.jpg). The notation `Python[200]` corresponds to the Python implementation of the Mersenne twister, using the `random.random()` function and the seed 200, that is, `random.seed(200)`. Similarly, `SQRT[90,91]` is for the binary digits of `` `$\sqrt{2205}` ``![Image](images/B9780443218576000151/si1.png), obtained using the bivariate seed `y = 90, z = 91`![Image](images/B9780443218576000151/si129.png) in the code in Section [11.3.3](#Chp011_203-228_B9780443218576000151.xhtml#s0070). Not surprisingly, the sequence `Base3[0.72]` fails, as `0.72 = 18/25`![Image](images/B9780443218576000151/si130.png) is a rational number with a small denominator. Thus `d(k) = χ(p[k])`![Image](images/B9780443218576000151/si32.png) is periodic with a rather small period. The column labeled Status in [Table 11.1](#Chp011_203-228_B9780443218576000151.xhtml#t0010) indicates if the sequence in question fails or passes the prime test.

For convenience, I also included a type of sequences called `CounterExample`. For this type of sequences, `χ(p[k])`![Image](images/B9780443218576000151/si131.png) perfectly alternates between −1 and +1. One of the two resulting sequences `{d(k)}`![Image](images/B9780443218576000151/si17.png) barely passes the test, the other fails. Now, the `Dirichlet4` sequence with seed set to 3, has perfectly alternating `d(k)`![Image](images/B9780443218576000151/si29.png)'s and is thus nonrandom. It fails the prime test, but barely. This means that passing this test is not a guarantee of randomness. Only failing the test is a guarantee of nonrandomness.

The prime test can be extended using the option All in the Python code. To do so, define the `L[4]`![Image](images/B9780443218576000151/si132.png) statistics as follows:

```
$L\_{4}(n) = \\sum\\limits\_{k = 1}^{n}\\chi(k),\\quad L\_{4}^{\\ast}(n) = \\frac{|L\_{4}(n)|}{\\sqrt{n\\log\\log n}}.$
```

![Image](images/B9780443218576000151/si133.png)(11.6)

Now with `L[4]^*`![Image](images/B9780443218576000151/si134.png) rather than `L[3]^*`![Image](images/B9780443218576000151/si109.png), the `Dirichlet4` sequence with the seed set to 3 would dramatically fail the prime test, rather than just barely failing. It would reveal that despite the appearances, there is something definitely nonrandom about this sequence. Indeed, it satisfies `χ(4*k + 1) = 1`![Image](images/B9780443218576000151/si135.png), `χ(4*k + 3) = -1`![Image](images/B9780443218576000151/si136.png), and `χ(2*k) = 0`![Image](images/B9780443218576000151/si137.png). The details of the `L[4]^*`![Image](images/B9780443218576000151/si134.png) version of the prime test still need to be worked out, thus I did not include it in this chapter.

Finally, if you swap −1/+1![Image](images/B9780443218576000151/si138.png) in the `{d(k)}`![Image](images/B9780443218576000151/si17.png) sequence, the new sequence may pass the test even if the original fails (or the other way around). This is the case for the sequence `SQRT[90,91]`. Also, the `L[3]^*`![Image](images/B9780443218576000151/si109.png) scale should be interpreted as an earthquake scale: an increase from 0.35 to 0.45, or from 1.3 to 1.8, represents a massive difference. A sequence with a low `L[3]^*`![Image](images/B9780443218576000151/si109.png) alternates too frequently compared to a random sequence, resulting in a ratio +1 versus −1 too close to 50% among the `d(k)`![Image](images/B9780443218576000151/si29.png)'s. The ratio in question corresponds to the column labeled `P[d(k) = 1]`![Image](images/B9780443218576000151/si139.png) in [Table 11.1](#Chp011_203-228_B9780443218576000151.xhtml#t0010).

### Exercise 11.1

#### Pseudorandom sequence generated by rational numbers

Let `q[k] = 2^(-{k*log[2]3})`![Image](images/B9780443218576000151/si140.png) be a rational number (`k = 1, 2`![Image](images/B9780443218576000151/si18.png), and so on), where the brackets represent the **fractional part function** \[[Wiki](https://en.wikipedia.org/wiki/Fractional_part)\]. For instance, `q[6] = 512/729`![Image](images/B9780443218576000151/si141.png). Let `M[n]`![Image](images/B9780443218576000151/si142.png) be the median of `{q[1], ..., q[n]}`![Image](images/B9780443218576000151/si143.png). Thus if `n` is odd, then `M[n]`![Image](images/B9780443218576000151/si142.png) is the middle term after rearranging the `q[k]`![Image](images/B9780443218576000151/si144.png)'s in increasing order. Prove that (1) `` `$M_n \rightarrow \sqrt{2}/2` ``![Image](images/B9780443218576000151/si145.png) as `n → ∞`![Image](images/B9780443218576000151/si146.png), (2) the binary digit expansion of `q[k]`![Image](images/B9780443218576000151/si144.png) has period `2 * 3^(k - 1)`![Image](images/B9780443218576000151/si147.png), and (3) the proportion of 0 and 1 among these digits is exactly 50/50.

#### Solution

Solution to (2) and (3) is found [here](https://math.stackexchange.com/questions/3310862/what-is-the-period-of-the-fraction-1-3k-in-base-2-for-k-1-2-dots); (3) follows from the **equidistribution modulo** 1 \[[Wiki](https://en.wikipedia.org/wiki/Equidistribution_theorem)\] of the sequence `{k*log[2]3}`![Image](images/B9780443218576000151/si148.png). This implies that the `q[k]`![Image](images/B9780443218576000151/si144.png)'s are distributed like `2^(-U)`![Image](images/B9780443218576000151/si149.png) where `U` is uniformly distributed on `[0, 1]`![Image](images/B9780443218576000151/si90.png).
