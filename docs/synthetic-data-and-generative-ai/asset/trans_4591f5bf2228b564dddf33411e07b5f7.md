
我介绍了一些鲜为人知的原始插值方法及其在真实数据集上的应用。这些简单的技术易于实现，可用于回归或预测。它们为基于模型的统计方法提供了一种替代方案。应用包括都柏林海潮插值、利用地理空间数据预测芝加哥地区气温，以及一个天文学问题，即行星排列及其发生频率。在一个示例中，5 分钟数据可用 80 分钟测量值替代，通过插值重构 5 分钟增量，且无明显损失。因此，我的算法可用于数据压缩。

第一种技术与傅里叶方法有着紧密联系。除了上述应用外，我还展示了如何利用它高效插值复杂的数学函数，如贝塞尔函数和黎曼 zeta 函数。对于熟悉 `MATLAB®` 或 `Mathematica` 的人来说，这是一个尝试 `Python` 中 `MPmath` 库并查看其在此背景下与传统工具相比如何的机会。在此过程中，我还展示了如何利用该方法生成合成数据 [[维基](https://en.wikipedia.org/wiki/Synthetic_data)]，无论是时间序列还是地理空间数据。

根据参数不同，在地理空间背景下，插值要么接近最近邻方法、克里金法 `kriging` [[维基](https://en.wikipedia.org/wiki/Kriging)]（也称为高斯过程回归），要么是加性和乘性技术真正原创的混合体。有一个选项是不对远离训练集的位置进行插值，因为无论使用何种技术，这些位置的回归或插值结果可能都没有意义。

第二种技术基于普通最小二乘法——即用于求解多项式回归的同一方法——但我并不使用导致过拟合的高度不稳定多项式，而是专注于避免这些陷阱的通用函数，利用迭代 `greedy algorithm` [[维基](https://en.wikipedia.org/wiki/Greedy_algorithm)] 寻找最优解。特别是，基于正交函数的解决方案能带来一种特别简单的实现，并具有直接解。

## 9.1 第一种方法

一般原理很简单。我们要在属于称为根集的集合 `R` 的特定点 `t = ρ[1], ρ[2], …`![Image](images/B9780443218576000138/si2.png) 处插值函数 `g(t)`![Image](images/B9780443218576000138/si1.png)。这些点是某个函数 `ψ` 的根。我们构造一个函数 `w(t, ρ)`![Image](images/B9780443218576000138/si3.png)，它仅当 `t = ρ`![Image](images/B9780443218576000138/si4.png) 且 `ρ ∈ R`![Image](images/B9780443218576000138/si5.png) 时等于零。选择函数 `ψ` 和 `w` 使得当 `t → ρ ∈ R`![Image](images/B9780443218576000138/si6.png) 时，极限 `ψ(t)/w(t, ρ)`![Image](images/B9780443218576000138/si7.png)——一个分子分母均为零的商——存在且不为零。该极限记为 `λ(ρ)`![Image](images/B9780443218576000138/si8.png)。插值函数记为 `f(t)`![Image](images/B9780443218576000138/si9.png)，由 [(9.1)](#Chp009_147-168_B9780443218576000138.xhtml#deq1) 定义，由构造可知，当 `t ∈ R`![Image](images/B9780443218576000138/si10.png) 时，它与 `g(t)`![Image](images/B9780443218576000138/si1.png) 相同。这导出了如下公式

$f(t) = \psi(t) \cdot \sum\limits_{\rho \in R}\frac{f(\rho)}{\lambda(\rho)} \cdot \frac{1}{w(t,\rho)},\quad\text{~with~}\lambda(\rho) = \lim\limits_{t\rightarrow\rho}\text{~~}\frac{\psi(t)}{w(t,\rho)}.$

![Image](images/B9780443218576000138/si11.png)(9.1)

此处 `w(t, ρ) = 0`![Image](images/B9780443218576000138/si12.png) 当且仅当 `t = ρ`![Image](images/B9780443218576000138/si4.png)。必须适当选择函数 `ψ` 和 `w`，使公式 [(9.1)](#Chp009_147-168_B9780443218576000138.xhtml#deq1) 中的极限始终存在且不为零。通常，`w(t, ρ)`![Image](images/B9780443218576000138/si3.png) 度量 `t` 和 `ρ` 之间的接近程度。如果求和是无限的且级数是 `conditionally convergent` [[维基](https://en.wikipedia.org/wiki/Conditional_convergence)]（条件收敛）——相对于 `absolutely convergent`（绝对收敛）而言——则根 `ρ` 需要适当排序。这将在第 [9.1.1](#Chp009_147-168_B9780443218576000138.xhtml#s0015) 节讨论。级数的收敛性可能还要求当 `|ρ| → ∞`![Image](images/B9780443218576000138/si14.png) 且 `t` 固定时，`w(t, ρ) → ∞`![Image](images/B9780443218576000138/si13.png) 足够快。

在一维情况下，可使用洛必达法则 [[维基](https://en.wikipedia.org/wiki/L%27H%C3%B4pital%27s_rule)] 计算该极限：

$\lambda(\rho) = \frac{\psi^{\prime}(\rho)}{w^{\prime}(\rho,\rho)},\quad\text{~with~}\psi^{\prime}(t) = \frac{\partial\psi(t)}{\partial t}\text{~and~}w^{\prime}(t,\rho) = \frac{\partial w(t,\rho)}{\partial t}.$

![Image](images/B9780443218576000138/si15.png)

对于 `roots with multiplicity` [[维基](https://en.wikipedia.org/wiki/Multiplicity_\(mathematics\))]（重根），可能需要多次应用洛必达法则。符号 ∂ 代表 `partial derivative` [[维基](https://en.wikipedia.org/wiki/Partial_derivative)]（偏导数），此处指对 `t` 的偏导数。在高维情况下，除特定情形外，极限通常不存在，参见 [[1]](#Chp009_147-168_B9780443218576000138.xhtml#br0005) 和第 [9.1.3](#Chp009_147-168_B9780443218576000138.xhtml#s0025) 节。

### 9.1.1 无限求和示例

我从一些通向有趣公式的数学推导开始。然后我利用这些公式插值时间序列，并展示一个很酷的应用。设 `ψ(t) = sin πt`![Image](images/B9780443218576000138/si16.png) 和 `R = {ρ[0], ρ[1], …} = ℕ`![Image](images/B9780443218576000138/si17.png)，使得 `ρ[k] = k`![Image](images/B9780443218576000138/si18.png)。令 `w(t, ρ) = t² − ρ²`![Image](images/B9780443218576000138/si19.png)，可得

$f(t) = \frac{\sin\pi t}{\pi} \cdot \left\lbrack \frac{f(0)}{t} + 2t\sum\limits_{k = 1}^{\infty}{( - 1)}^{k}\frac{f(k)}{t^{2} - k^{2}} \right\rbrack.$

![Image](images/B9780443218576000138/si20.png)(9.2)

公式 [(9.2)](#Chp009_147-168_B9780443218576000138.xhtml#deq3) 适用于任何可写成以下形式的偶函数 `f`：

$f(t) = \sum\limits_{k = 0}^{\infty}\alpha_{k}\cos\beta_{k}t\ \text{~with~}|\beta_{k}| < \pi,\text{~or~}f(t) = \int_{- \infty}^{\infty}\alpha(u)\cos(\beta(u)t)du\ \text{~with~}|\beta(u)| < \pi.$

![Image](images/B9780443218576000138/si21.png)(9.3)
