
在这种情况下 `q[k] = k`![Image](images/B9780443218576000217/si317.png)。注意 `k^(-z) = k^(-σ) ⋅ [cos(t log k) + i sin(t log k)]`![Image](images/B9780443218576000217/si318.png)。只需证明第 `k` 项等于 `k^(-σ) cos(t log k)`![Image](images/B9780443218576000217/si319.png) 的级数不能收敛，尽管随着 `k` 增加，`cos(t log k)`![Image](images/B9780443218576000217/si320.png) 在正负值之间无限次振荡。原因是 `log k`![Image](images/B9780443218576000217/si321.png) 增长太慢。当 `k` 非常接近（比如说）`2π` 的倍数时，太多连续项全为正，而 `k^(σ)`![Image](images/B9780443218576000217/si322.png) 增长不够快（如果 `σ < 1`![Image](images/B9780443218576000217/si9.png)），无法使部分和保持有界并收敛。相反，如果余弦函数中的 `log k`![Image](images/B9780443218576000217/si321.png) 被 `$\sqrt{k}$`![Image](images/B9780443218576000217/si323.png) 取代，且 `σ = 0.75`![Image](images/B9780443218576000217/si252.png)，则级数收敛：0 到 ∞ 之间的对应积分等于 `$\sqrt{2π/|t|}`$![Image](images/B9780443218576000217/si324.png)。

## 练习 17.4

### 截断狄利克雷函数

确定对于固定的 `σ` 值，当 `n` = 3![Image](images/B9780443218576000217/si141.png) 且 `t` 遍历公式 [(17.8)](#Chp017_329-360_B9780443218576000217.xhtml#deq11) 中所有正实数时，轨道覆盖的区域。推广到 `n` = 4![Image](images/B9780443218576000217/si325.png)。

### 解答

让我们假设在这种情况下空洞的中心是 (1, 0)![Image](images/B9780443218576000217/si142.png)。证明留给读者。那么时刻 `t` 轨道上一点与原点之间距离的平方等于

```
d^{2}(t) = \left\lbrack \beta^{\sigma}\cos(t\log 2) - \lambda_{3}^{\sigma}\cos(t\log 2) \right\rbrack^{2} + \left\lbrack \beta^{\sigma}\sin(t\log 2) - \lambda_{3}^{\sigma}\sin(t\log 2) \right\rbrack^{2} = \beta^{2\sigma} + \lambda_{3}^{2\sigma} - 2\beta^{\sigma}\lambda_{3}^{\sigma}\left\lbrack \cos(t\log 2)\cos(t\log 3) + \sin(t\log 2)\sin(t\log 3) \right\rbrack = \beta^{2\sigma} + \lambda_{3}^{2\sigma} - 2\beta^{\sigma}\lambda_{3}^{\sigma}\cos\left( t\log\frac{2}{3} \right).
```

![Image](images/B9780443218576000217/si326.png)

由于余弦取遍 −1 和 +1 之间的所有值，以周期 `2π/(log 3 - log 2)`![Image](images/B9780443218576000217/si327.png) 无限次出现，轨道的外边界是以 (1, 0)![Image](images/B9780443218576000217/si142.png) 为中心、半径为 `ρ`[1]![Image](images/B9780443218576000217/si328.png) 的圆，内边界（即空洞的形状）也是以 (1, 0)![Image](images/B9780443218576000217/si142.png) 为中心、半径为 `ρ`[2]![Image](images/B9780443218576000217/si329.png) 的圆。此处

```
\rho_{1} = \sqrt{\beta^{2\sigma} + \lambda_{3}^{2\sigma} + 2\beta^{\sigma}\lambda_{3}^{\sigma}} = |\beta^{\sigma} + \lambda_{3}^{\sigma}|,\quad\rho_{2} = \sqrt{\beta^{2\sigma} + \lambda_{3}^{2\sigma} - 2\beta^{\sigma}\lambda_{3}^{\sigma}} = |\beta^{\sigma} - \lambda_{3}^{\sigma}|.
```

![Image](images/B9780443218576000217/si330.png)

因此 `β` 越大，空洞越大。我假设 `β`、`λ`[3] ≥ 0![Image](images/B9780443218576000217/si331.png)。

`n` = 4![Image](images/B9780443218576000217/si325.png) 的情况要复杂得多。中心不再是 (1, 0)![Image](images/B9780443218576000217/si142.png)，而是通常为 (`c`, 0)![Image](images/B9780443218576000217/si110.png) 且 `c` < 1![Image](images/B9780443218576000217/si332.png)。此外，形状可能不再是圆。可能有空洞，也可能没有。然而，如果 `β` 足够大，就会有一个空洞，大到足以包含 (1, 0)![Image](images/B9780443218576000217/si142.png)。到 (1, 0)![Image](images/B9780443218576000217/si142.png) 距离的平方现在是

```
d^{2}(t) = \beta^{2\sigma} + \lambda_{3}^{2\sigma} + \lambda_{4}^{2\sigma} - 2\beta^{\sigma}\lambda_{3}^{\sigma}\cos\left( t\log\frac{2}{3} \right) - 2\beta^{\sigma}\lambda_{4}^{\sigma}\cos\left( t\log\frac{2}{4} \right) - 2\lambda_{3}^{\sigma}\lambda_{3}^{\sigma}\cos\left( t\log\frac{3}{4} \right).
```

![Image](images/B9780443218576000217/si333.png)

`d`²(`t`)![Image](images/B9780443218576000217/si334.png) 的最小可能值是 `d`[min] = `β`^(2`σ`) + `λ`[3]^(2`σ`) + `λ`[4]^(2`σ`) − 2`β`^(`σ`)`λ`[3]^(`σ`) − 2`β`^(`σ`)`λ`[4]^(`σ`) − 2`λ`[3]^(`σ`)`λ`[3]^(`σ`)![Image](images/B9780443218576000217/si335.png)。如果 `d`[min] > 0![Image](images/B9780443218576000217/si336.png)，则存在一个足以包含 (1, 0)![Image](images/B9780443218576000217/si142.png) 的空洞。
