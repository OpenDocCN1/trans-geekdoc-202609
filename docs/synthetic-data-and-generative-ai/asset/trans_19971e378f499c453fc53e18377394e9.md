
本章基础的标准对称一维**随机游走** [[Wiki](https://en.wikipedia.org/wiki/Random_walk)] 是一个序列 `{S[n]}`，其中 `n ≥ 0`，起始于 `S[0] = 0`，并由 `S[n] = X[n] + S[n−1]` 递归定义，适用于 `n > 0`。这里 `X[1]`、`X[2]` 等是独立随机变量，满足 `P[X_n = 1] = P[X_n = -1] = 1/2`。因此 `{S[n]}` 是一个离散时间随机过程，确实是最基本的一个。在第 [12.1.2](#Chp012_229-241_B9780443218576000163.xhtml#s0020) 节和第 [12.1.3](#Chp012_229-241_B9780443218576000163.xhtml#s0040) 节中，我放弃了独立性假设，从而得到修正的随机游走，如 [[6](#Chp012_229-241_B9780443218576000163.xhtml#br0030),[9]](#Chp012_229-241_B9780443218576000163.xhtml#br0045) 所述。更多一般性参考文献见 [[1](#Chp012_229-241_B9780443218576000163.xhtml#br0005),[8]](#Chp012_229-241_B9780443218576000163.xhtml#br0040)。

经过适当的重缩放，随机游走变成一个称为**布朗运动** [[Wiki](https://en.wikipedia.org/wiki/Brownian_motion)] 的连续时间随机过程 `S[t]`，其中 `t ∈ ℝ⁺`。请看 [图 12.1](#Chp012_229-241_B9780443218576000163.xhtml#f0010) 中灰色的时间序列，显示了一个特定实例：它显示了短窗口内 `S[n]` 的初始值，呈现出布朗运动的外观。相比之下，橙色、红色和灰色的每条时间序列代表一种特定类型的非布朗运动的一个实例。第 [12.1.2](#Chp012_229-241_B9780443218576000163.xhtml#s0020) 节和第 [12.1.3](#Chp012_229-241_B9780443218576000163.xhtml#s0040) 节重点讨论这三类过程，它们是准随机的，但非完全随机。

### 12.1.1 纯随机游走的三个基本性质

标准随机游走 `{S[n]}`（在 [图 12.1](#Chp012_229-241_B9780443218576000163.xhtml#f0010) 中以灰色显示）是基础或参考过程，用于构建更复杂的模型。它有太多性质，无法在本短章中一一列举。但以下性质与我们的讨论最为相关：

- **迭代对数律** [[Wiki](https://en.wikipedia.org/wiki/Law_of_the_iterated_logarithm)]。在我们的语境下，表述如下：

$$
\limsup\frac{|S_{n}|}{\sqrt{2nv\log\log n}} = 1\quad\text{as~}n\rightarrow\infty.
$$

(12.1)

这里，根据**哈特曼-温特纳定理** [[Wiki](https://encyclopediaofmath.org/wiki/Law_of_the_iterated_logarithm)]，`v = Var[X[1]] = 1`。参见 [[8]](#Chp012_229-241_B9780443218576000163.xhtml#br0040) 第 118–123 页，了解适用于布朗运动的版本。

- `S[1], …, S[n]` 中**零穿越**的期望数量，记为 `N[n]`。这里零穿越是指满足 `S[k] = 0` 的索引 `0 < k ≤ n`。对于 `n > 0`，我们有（见[此处](https://math.stackexchange.com/questions/1684576/expected-of-returns-in-a-symmetric-simple-random-walk)）

$$
E\lbrack N_{2n}\rbrack = - 1 + \frac{2n + 1}{4^{n}}\begin{pmatrix} {2n} \\ n \\ \end{pmatrix} \sim \frac{2}{\sqrt{\pi}} \cdot \sqrt{n}\quad\text{as~}n\rightarrow\infty.
$$

- 到达零的**首次命中时间**分布 [[Wiki](https://en.wikipedia.org/wiki/First-hitting-time_model)]，或 `S[0] = 0` 后的首次零穿越，也称为首次返回时间。相关随机变量记为 `T`。定义如下：`T = n`（其中 `n > 0`）当且仅当 `S[n] = 0` 且当 `0 < k < n` 时 `S[k] ≠ 0`。如果 `n` 为奇数，则 `P[T = n] = 0`，且 `E[T] = Var[T] = ∞`。然而，我们的随机游走会无限次穿越 X 轴。我们还有以下**概率生成函数** [[Wiki](https://en.wikipedia.org/wiki/Probability-generating_function)]（见[此处](https://math.stackexchange.com/questions/64919/biased-random-walk-and-pdf-of-time-of-first-return)）：

$$
\sum\limits_{n = 1}^{\infty}{(2x)}^{2n}P\lbrack T = 2n\rbrack = 1 - \sqrt{1 - 4x^{2}}\quad\text{if~}x \leqslant \frac{1}{4}.
$$

由此可得

$$
P\lbrack T = 2n\rbrack = \frac{1}{(2n - 1)4^{n}}\begin{pmatrix} {2n} \\ n \\ \end{pmatrix} \sim \frac{1}{\sqrt{4\pi}} \cdot n^{- 3/2}\quad\text{as~}n\rightarrow\infty,\quad E\lbrack T^{- 1}\rbrack = \int_{0}^{1/2}\frac{1 - \sqrt{1 - 4x^{2}}}{x}dx = 1 - \log 2.
$$

注意 `E[T^(−1)]` 是有限的，而 `E[T]` 是无限的。`E[T] = ∞` 这一事实解释了为什么序列 `S[n]` 可以在 X 轴上方或下方停留极长的时间段，如 [图 12.1](#Chp012_229-241_B9780443218576000163.xhtml#f0010) 中灰色曲线所示。

上述三个统计量 `|S_{n}|/\sqrt{2n\log\log n}`、`N[2n]` 和 `T^(−1)` 可用于为伪随机数生成器设计随机性检验。事实上，第 [11](#Chp011_203-228_B9780443218576000151.xhtml) 章中的**素数检验**依赖于迭代对数律 (LIL) 的数论版本。目的是检测极微弱的非随机偏离，即使在足以通过经典 LIL 检验的序列中，但并非完全随机。在本章中，目标是模拟准随机序列，而不是创建新的随机性检验。

我现在描述缺乏序列 `{X[n]}` 中真正独立性的特殊类型修正随机游走。特别地，我将讨论它们为何特别且极具研究价值，重点关注应用。
