

# 概述

在此，我通过随机过程的叠加生成合成数据，并将其与贝叶斯生成混合模型（高斯混合模型或 `GMM`）进行比较。我将解释其优势与差异。实际的分类和聚类算法是无模型的，并在将原始数据转换为图像后，在 `GPU` 中作为图像滤波器执行。随后我将讨论向 3D 或 4D 以及利用稀疏张量扩展到更高维度的泛化。当观测值数量大且簇间重叠显著时，该技术尤为适用。

该方法可使用少量迭代和大滤波窗口来实现，这类似于神经网络，局部窗口中的像素作为节点，它们到局部中心的距离作为权重函数。或者，你可以用大量迭代（相当于深度神经网络中的数百层）和微小窗口来实现该方法。后一种情况对应于**稀疏网络**，每个节点具有零个或一个连接。它用于实现分形分类，其中点标签在每次迭代中发生变化，发生在高度非线性的簇边界周围。这等同于在贝叶斯框架中给类别分配概率设定先验。然而，分类是在没有底层模型的情况下执行的。最后，算法的聚类（无监督）部分依赖于相同的滤波技术，并结合颜色均衡器。后者可用于执行层次聚类。

本文档中包含的 `Python` 代码也在我的 `GitHub` 仓库中。一个数据动画展示了该方法论的简洁性：视频中的每一帧代表一次迭代，即对所有数据点进行一次滤波器应用。确实，该分类器可作为一个黑箱系统使用。它遵循可解释机器学习的现代趋势，也称为可解释 AI。视频展示了算法如何收敛到最优，从而产生整个观测空间的分类。对新点进行分类则是即时的：读取其颜色。整个系统在时间效率上很高。它不需要计算所有训练集点的组内距离。然而，它是内存密集型的。大滤波器可能会很慢，尽管它们需要的迭代次数很少。我将讨论一种使它们快得多的简单技术。

## 5.1 简介

我通过 `Python` 代码和大量图解，解释如何将传统表格数据转换为图像，以使用简单的图像滤波技术执行聚类和监督分类。我还解释了如何使用张量而非图像将该方法论推广到更高维度。归根结底，图像位图是二维数组或矩阵，即二维张量。通过对整个空间（在低维情况下）进行分类，生成的分类规则非常快。我还将讨论算法的收敛性，以及如何进一步提高其速度。

本短章涵盖了许多主题，可作为合成数据生成、混合模型、边界效应、可解释 AI、分形分类、随机收敛、`GPU` 机器学习、深度神经网络和无模型贝叶斯分类的入门介绍。我使用极少的数学公式，使其通俗易懂，当然也适合非数学家。通过引入一种解决通用分类问题的原创直观方法，我用简单的英语解释了它如何与深度和极深度神经网络相关联。在此过程中，我建立了与图像分割、直方图均衡化、层次聚类、卷积滤波器和随机过程的联系。我还从速度和性能方面比较了标准神经网络与极深但稀疏的神经网络。分形分类器——极深度神经网络的一个示例——通过 `Python` 生成的视频进行了演示。它在处理大量重叠的簇和大量观测值时非常有用。超参数允许你微调合成数据中的簇重叠程度和簇的形状。

## 5.2 生成合成数据

我的示例中使用的数据是通过一种技术生成的，该技术在贝叶斯框架下与**高斯混合模型**（`GMM`）有一定相似性 [[Wiki](https://en.wikipedia.org/wiki/Mixture_model)]。我没有使用混合模型，而是使用了叠加的随机过程，也称为交织。与混合模型的差异很微妙，可以用统计检验检测到，但并不重要，肉眼也不可见。而且，我没有使用高斯分布，而是使用任意分布。其数学模型是随机扰动的格点过程，也称为泊松-二项点过程。
