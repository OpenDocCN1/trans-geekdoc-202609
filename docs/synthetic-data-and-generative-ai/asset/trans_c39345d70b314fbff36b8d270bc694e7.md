

## 1.3.3 曲线拟合问题

遗憾的是，`curve_fitting` 在大多数情况下会失败或表现非常差。[图 1.4](#Chp001_1-34_B9780443218576000059.xhtml#f0030) 展示了为数不多的它在噪声环境下表现良好的案例之一。这个 Python 函数在许多场景下仍然非常有用，但不适用于我们的示例。默认设置（`method='lm'`，应避免使用）使用了一种所谓的鲁棒版 Levenberg-Marquardt 算法，可追溯至 1977 年，详见[此处](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.xhtml)。从本质上讲，它会陷入局部极小值或无法收敛，甚至可能拒绝一个手动选择的、接近最优解的初始条件，并将其判定为“不可行”。令人惊讶的是，增加数据中的噪声量反而能带来改进。

为了解决数值不稳定问题，可以使用更现代的技术，例如 `swarm optimization`（群体优化）[[维基](https://en.wikipedia.org/wiki/Particle_swarm_optimization)]。[此处](https://pyswarms.readthedocs.io/en/latest/)有文档记录的 `PySwarms` 库是 Python 的解决方案。有关教程，请见[此处](https://machinelearningmastery.com/a-gentle-introduction-to-particle-swarm-optimization/)。一个更简单的自制解决方案利用了这样一个事实：拟合曲线 `f[θ](x)`![Image](images/B9780443218576000059/si146.png)（统计学家称之为回归函数）在 `θ[1]`![Image](images/B9780443218576000059/si161.png) 和 `θ[4]`![Image](images/B9780443218576000059/si162.png) 上都是线性的，该方案将问题拆分如下：

*   **步骤 1：** 在足以包含最优值的区域内采样 `θ[2], θ[5]`![Image](images/B9780443218576000059/si163.png)。
*   **步骤 2：** 给定 `θ[2], θ[5]`![Image](images/B9780443218576000059/si164.png)，找到使 `$E(\theta) = \sum_{k = 1}^{n}g^{2}(Y_{k},X_{k};\theta)`![Image](images/B9780443218576000059/si166.png) 最小化的 `θ[1], θ[4]`![Image](images/B9780443218576000059/si165.png)。

这里 `(Y[k], X[k])`![Image](images/B9780443218576000059/si167.png) 是训练集中的第 `k` 个观测值，而 `θ = (θ[1], θ[2], θ[4], θ[5])`![Image](images/B9780443218576000059/si168.png)。这两个步骤都很简单。重复这些步骤，直到过去几次迭代计算出的最小 `E(θ)`![Image](images/B9780443218576000059/si169.png) 几乎不再减小。步骤 2 只是一个没有截距的简单标准二维线性回归，有精确解。好处之一是，如果存在多个极小值，你一定能找到所有极小值，而不会面临收敛问题。它还将 4D 蒙特卡洛模拟简化为 2D 模拟。

## 1.3.4 三维空间中的直线拟合、无监督聚类及其他推广

在三维空间中，直线是两个平面 `A` 和 `B` 的交集，其方程分别为 `g1(w, θ[A]) = 0`![Image](images/B9780443218576000059/si174.png) 和 `g1(w, θ[B]) = 0`![Image](images/B9780443218576000059/si175.png)。例如，`g1(w, θ[A]) = θ[0]w[0] + θ[1]w[1] + θ[2]w[2] − θ[3]`![Image](images/B9780443218576000059/si176.png)。为了拟合直线，

*   设 `θ[A] = (θ[0], θ[1], θ[2], θ[3])^T`![Image](images/B9780443218576000059/si177.png) 和 `θ[B] = (θ[4], θ[5], θ[6], θ[7])^T`![Image](images/B9780443218576000059/si178.png)，
*   在公式 [(1.1)](#Chp001_1-34_B9780443218576000059.xhtml#deq1) 中使用 `θ = (θ[A], θ[B])`![Image](images/B9780443218576000059/si179.png) 和 `g(w, θ) = g1²(w, θ[A]) + g1²(w, θ[B])`![Image](images/B9780443218576000059/si180.png)，
*   使用约束条件 `θ[A]^T θ[A] + θ[B]^T θ[B] = 1`![Image](images/B9780443218576000059/si181.png)，或两个约束条件：`θ[A]^T θ[A] = 1`![Image](images/B9780443218576000059/si182.png) 和 `θ[B]^T θ[B] = 1`![Image](images/B9780443218576000059/si183.png)。

使用两个约束条件时，我们在公式 [(1.2)](#Chp001_1-34_B9780443218576000059.xhtml#deq2) 中有两个拉格朗日乘子 `λ[A]`![Image](images/B9780443218576000059/si184.png) 和 `λ[B]`![Image](images/B9780443218576000059/si185.png)。
