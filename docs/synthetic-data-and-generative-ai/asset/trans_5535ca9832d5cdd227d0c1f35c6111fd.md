
数据集 `diabetes.csv` 位于我的 GitHub 目录中，[此处](https://github.com/VincentGranville/Main/blob/main/diabetes.csv)。原始数据可在 Kaggle 找到，[此处](https://www.kaggle.com/uciml/pima-indians-diabetes-database)。值得注意的是，所有特征均被视为连续变量，即使是二元的 `Outcome`。因此，妊娠次数（整数）或由 GAN 生成的“结果”均为实数，必须映射为整数才具有实际意义。其他实现方式（如 Copula 或基于 Copula 的 GAN）没有这一限制。另一种替代方案是针对 `Outcome==0` 使用一个 GAN，针对 `Outcome==1` 使用另一个 GAN。此外，分类特征（此处除 Outcome 外不存在）可用 `dummy variables` [[维基百科](https://en.wikipedia.org/wiki/Dummy_variable_(statistics))] 替代。

### 10.4.2.1 超参数

有令人惊讶的大量超参数可供微调。这就是这些系统训练和优化耗时较长的原因之一。此外，所有 GAN 中都存在的梯度下降（及其自身参数）是瓶颈。算法自行识别良好参数——并可能随时间调整——是实现该过程至少自动化的一种方式。但这可能导致过拟合。最佳解决方案是使用在许多场景下效果良好的标准超参数，而不试图过度调整。

所有这些参数均在代码的 GAN 部分设置并使用，见第 [10.7.2](#Chp010_169-201_B978044321857600014X.xhtml#s0115) 节。唯一的例外是学习率参数。

- **轮数**。GAN 的一次迭代包含处理完整数据集：这是通过若干小样本（批次）逐个完成的。迭代次数即为 `epochs` 数量，在用于训练 GAN 的 `train()` 函数中设置为 `n_epochs=10000`（典型值）。
- **批量大小**。见轮数。此处在 `train()` 函数中设置为 `n_batch=128`。一半批量用于从真实数据采样，另一半用于生成潜在数据。
- **潜在数据**。此处 `latent variables` [[维基百科](https://en.wikipedia.org/wiki/Latent_and_observable_variables)] 为零均值、单位方差的单变量随机高斯偏差；其数量通常与特征数量匹配。其作用类似于 Copula 方法中的高斯偏差。不过，在 \[ − 1, 1\]![Image](images/B978044321857600014X/si13.png) 上使用均匀分布值得探索，因为许多 GAN 函数（例如 `ReLU`）返回 0 到 1 之间的值。第 [9.3.3](#Chp009_147-168_B9780443218576000138.xhtml) 节的傅里叶回归中也使用了此类限制。
- **激活函数**。在神经网络中，`activation function` [[维基百科](https://en.wikipedia.org/wiki/Activation_function)] 决定 `neuron` 是否应被激活。代码中使用的经典示例有 `ReLU` [[维基百科](https://en.wikipedia.org/wiki/Rectifier_(neural_networks))] 和 `sigmoid` [[维基百科](https://en.wikipedia.org/wiki/Sigmoid_function)]。
- **核初始化器**。它定义设置 Keras 层初始随机权重的方式。见文档 [此处](https://keras.io/api/layers/initializers/)。
- **层数**。神经网络（生成器和判别器均）使用 3 层。通过指令 `model.add()` 添加层，可选项包括：激活函数、核初始化器等。见代码中的 `define_generator()`、`define_discriminator()` 和 `define_gan()`（两者的组合）。有 3 层，即属于 `deep neural network`（深度神经网络）。
- **学习率**。它关联梯度下降。我尝试了 0.01 和 0.001，最终采用后者。较小值导致行为在开始时相当混乱、收敛较快，但准确度略有下降。较大值导致缓慢稳定的进展，但可能陷入糟糕的局部最优。可将其视为模拟退火算法中的降温计划。
- **梯度下降方法**。我使用 `Adam`。替代方案 `SGD`（`stochastic gradient descent` [[维基百科](https://en.wikipedia.org/wiki/Stochastic_gradient_descent)]）在此表现不佳，但在计算机视觉领域表现良好。
- **损失函数**。在梯度下降或任何优化问题中，`loss function` [[维基百科](https://en.wikipedia.org/wiki/Loss_function)] 指定到最优向量的距离类型，用于最小化。可将其视为由最小二乘法求解的回归问题——此时损失函数为二次函数。有时也称为误差函数。
- **准确率**。它计算预测等于标签的频率，用于分类上下文。在此上下文中，分类意味着将观测值分配给真实（真正真实或极佳的合成）或虚假（不接近现实的劣质合成数据）。见 Keras 文档 [此处](https://keras.io/api/metrics/accuracy_metrics/)。有多种可选指标来衡量准确率。
- **架构**。即神经网络类型。本例中设置为 `Sequential`。

### 10.4.2.2 GAN：主要步骤

本节步骤对应第 [10.7.2](#Chp010_169-201_B978044321857600014X.xhtml#s0115) 节的实际 GAN 过程。不包括预处理步骤：在交叉验证框架下检查真实训练集预测癌症的效果如何（第 [10.7.1](#Chp010_169-201_B978044321857600014X.xhtml#s0110) 节）。也不包括后处理步骤：GAN 评估以及合成训练集在相同交叉验证框架下预测癌症的效果如何。这部分代码见第 [10.7.3](#Chp010_169-201_B978044321857600014X.xhtml#s0120) 节。假设所有 GAN 模型已按第 [10.4.2.1](#Chp010_169-201_B978044321857600014X.xhtml#s0060) 节讨论的超参数创建并编译完毕。因此本节仅涵盖用于训练 GAN 的 `train()` 函数。话虽如此，这是代码中最重要的部分。

在 `train()` 函数中，以下步骤针对每个 epoch 重复执行：

- **步骤 1：更新判别器**。从真实数据获取新样本（半个批次），并将这些点分配给 `label=1`；获取新的潜在数据样本（半个批次，随机高斯向量）以生成假数据，并将这些点分配给 `label=0`。假采样函数还通过指令 `X=generator.predict(x_input)` 将潜在数据映射到真实数据空间。此处 `x_input` 代表潜在数据，`X` 为映射后的版本。`train_on_batch()` 函数（真实样本调用一次，假样本调用一次）还返回每个数据标签（假/真）的损失。注意判别器被设置为“nontrainable”（不可训练）。
- **步骤 2：更新生成器**。获取完整样本（完整批次）的潜在数据，此次分配给 `label=1` 以训练生成器。训练旨在随时间推移（平均而言）最小化损失函数 `g_loss`（由判别器返回的 `d_loss` 值的平均值），直到达到平衡：极有可能是一个局部最小值。注意 `g_loss` 随时间振荡，以免过快陷入局部最小值。最陡峭的梯度下降会导致此问题。因此我们使用 `Adam gradient descent`（自适应矩估计）来避免此问题。
- **步骤 3**。若 epoch 迭代为 200 的倍数，输出汇总统计以显示进度，特别是 `g_loss` 随时间平均下降的情况。

注意判别器的输出层由 `sigmoid` 函数激活，以区分真实和假样本。
