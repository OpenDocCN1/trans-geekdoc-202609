
为简单起见，我考虑一维泊松-二项过程。观测值由 `2n + 1` 个点 `X[k]` (`k = -n, …, n`) 组成，它们是强度为 `λ` 和缩放因子为 `s` 的一维泊松-二项过程的实现，通过模拟获得。我在模拟中选择了 logistic `F`。除非 `F` 具有异常厚或薄的尾部，否则它对点分布影响甚微。设

$$R = \frac{1}{2n + 1}\left[ \max_{|k| \leqslant n} X_k - \min_{|k| \leqslant n} X_k \right] \tag{16.15}$$

$$B_k = \left[ \frac{k}{R}, \frac{k + 1}{R} \right), \quad k = -n, \ldots, n-1 \tag{16.16}$$

和

$$p = \frac{1}{2n}\sum_{k=-n}^{n-1} \chi[ N(B_k) = 0 ], \quad q = \frac{1}{2n}\sum_{k=-n}^{n-1} \chi[ N(B_k) = 1 ] \tag{16.17}$$

其中 `χ` 是指示函数 [[Wiki](https://en.wikipedia.org/wiki/Indicator_function)]，`N(B_k)` 是 `B_k` 中的点数。如果 (`λ`, `s`) 和 (`p`, `q`) 之间存在一一映射，则可以通过将公式 [(16.17)](#Chp016_293-327_B9780443218576000205.xhtml#deq23) 应用于观测数据来轻松计算 (`p`, `q`)，然后通过逆映射恢复 (`λ`, `s`)。甚至可以为二元参数 (`λ`, `s`) 构建二维置信区域。该方法具有高度通用性（不特定于点过程），因此所有细节均见第 [18.3](#Chp018_361-386_B9780443218576000229.xhtml) 节（置信区域）和第 [18.3.5](#Chp018_361-386_B9780443218576000229.xhtml) 节（最小对比估计）。

## 16.4.2 模型可识别性、难以检测的模式

泊松-二项过程及相关点过程（如 `m-interlacings`）表现出许多难以检测的模式。有些甚至无法通过统计检验来检测。取决于模型参数，许多肉眼不可见。在某些情况下，这是由于 `可识别性`：两个表面上不同、具有不同参数集的模型，在统计上是相同的，且彼此无法区分。但大多数时候，差异是真实的，只是微妙或难以察觉。相反，有时肉眼会在不存在差异的地方感知到差异，类似于视觉错觉。难以检测的差异示例包括：

- 区分两个不同的 `F`（附着在点上的分布），例如 logistic 分布与高斯或 Cauchy 分布，除非 `s` 非常小。
- 如果 `s` 很大，该过程很难与平稳泊松过程区分。
- 点计数统计量（期望、方差等）是周期性的，但振幅极小。
- `m-interlacings` 中的簇结构可能不可见，除非应用某种变换：请参阅 [图 16.8](#Chp016_293-327_B9780443218576000205.xhtml#f0055) 左图。与点计数相比，`最近邻距离` 通常更擅长检测差异。

![Figure 16.8 Realization of a 5-interlacing with s=0.15 and λ=1: original (left), modulo 2/λ (right).](images/B9780443218576000205/gr014.jpg)

*图 16.8 `s` = 0.15 和 `λ` = 1 的 5-interlacing 实现：原始图（左），模 2/`λ`（右）。*

- 除非 `s` 非常小，否则可能无法检测底层晶格是方形还是六边形，或者我们处理的是 `m-interlacing` 还是泊松-二项过程的混合。

相反，在某些情况下，肉眼会感知到不存在的差异，例如 [图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040) 右图比左图点少，而实际上它们点数相同。事实上，泊松-二项模型是一个很好的框架，用于测试和基准测试需要极高精度的统计技术。例如，那些旨在检测系外行星、癌症早期迹象或股市细微模式的技术。

### 16.4.2.1 随机残差

`m-interlacing` 的每个单独过程都有自己的位移向量，它决定了簇的中心。通过平移，簇在每个晶格位置周围被随机复制。因此，对于统计推断，通常研究模 `2/λ` 或 `1/λ` 的过程（观测数据），在那里统计模式被放大且更易于检测。模 `2/λ` 是指：我们不研究原始点 (`X`, `Y`)，而是关注 (`X mod 2/λ`, `Y mod 2/λ`)。经过取模运算后的变换数据称为残差数据，或 `随机残差`。[图 16.8](#Chp016_293-327_B9780443218576000205.xhtml#f0055) 中存在 `m = 5` 个簇（尽管重叠巨大）这一事实，在展示残差的右图中显而易见，但在左图中则不然。通常，在无监督聚类的背景下，我们不知道 `m-interlacing` 的某个点属于哪个单独过程。

#### 备注

取模运算符定义为 `α mod β = α - β ⋅ ⌊α/β⌋`，其中括号表示向下取整函数（也称为整数函数 [[Wiki](https://en.wikipedia.org/wiki/Floor_and_ceiling_functions)]）。它与模算术 [[Wiki](https://en.wikipedia.org/wiki/Modular_arithmetic)] 中使用的相同，只是这里 `α`、`β` 通常是实数而非整数。

## 16.4.3 隐藏模型与随机排列

在一维中，附着在泊松-二项点过程任意点 `X[k]` 上的未观测索引 `k`，产生了一个有趣的随机过程，称为 `隐藏过程` 或索引过程。它可用于生成无限的、局部随机排列（此处为一维），使用以下算法：

### 算法

生成一个阶为 `m` 的局部随机排列。

**步骤 1：** 生成一个具有 `2n + 1` 个点 `X[-n], …, X[n]` 的一维泊松-二项过程实现。

- 令 `L(X[k]) = k`，其中 `-n ≤ k ≤ n`。函数 `L` 在源代码中作为 `hash table` [[Wiki](https://en.wikipedia.org/wiki/Hash_table)] 存储；哈希表的键是 `X[k]`。
- 实际上，不存在 `h ≠ k` 使得 `X[h] = X[k]` 的两个 `X[h]`、`X[k]`，因此这种冲突问题不会出现。
