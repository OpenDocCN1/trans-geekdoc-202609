
该方法假设单个残差误差是独立同分布的。我在第 [7.4.2.1](#Chp007_113-129_B9780443218576000114.xhtml#s0075) 节中讨论如何解决此问题。此外，它假设误差是加性的，而非乘性的。在后一种情况下，可能需要使用 `Y` 的变换版本，而不是 `Y` 本身。关于 Excel 实现，请参阅我的 GitHub 存储库中的 `Regression5_Static` 电子表格，[此处](https://github.com/VincentGranville/Machine-Learning/blob/main/Spreadsheets/README.md)。在 Test 选项卡中，`column AD` 对应 `ϵ' = ϵ`![Image](images/B9780443218576000114/si115.png)，而 `column AE` 对应 `ϵ''`![Image](images/B9780443218576000114/si116.png)。按 `AF`（均匀偏差）对 `columns AE:AF` 进行排序，以重新打乱残差误差。然后 `Y` 会在 `column I` 中自动被 `Y''`![Image](images/B9780443218576000114/si117.png) 替换，新的回归系数向量 `β''`![Image](images/B9780443218576000114/si118.png) 位于 Results 选项卡中的 `cells K6:P6`。

### 7.4.2.1 参数化自助法

另一种选择是对 `ϵ'`、`ϵ''`![Image](images/B9780443218576000114/si119.png) 等使用高斯偏差。它们需要具有与观测残差误差 `ϵ` 计算出的方差相同的方差。这种方法称为**参数化自助法**。

如果 `ϵ` 存在自相关，例如，如果您处理的是时间序列且特征之一是时间，则可以使用具有与 `ϵ` 相同自相关结构的自回归过程来模拟 `ϵ'`、`ϵ''`![Image](images/B9780443218576000114/si119.png) 等。同样，如果 `ϵ` 与 `Y` 相关，可以用适当的参数模型来处理。线性回归的参数化自助法见文献 [\[4\]](#Chp007_113-129_B9780443218576000114.xhtml#br0020)。回归的无分布预测推断见文献 [\[5\]](#Chp007_113-129_B9780443218576000114.xhtml#br0025)。

## 7.5 特征选择

在第 [7.5.1](#Chp007_113-129_B9780443218576000114.xhtml#s0085) 节中，我比较了每种潜在特征组合所得回归系数的性能。性能指标是 R 平方的一个显著改进版本；此外，它应用于验证集，而非训练集。然后，在第 [7.5.2](#Chp007_113-129_B9780443218576000114.xhtml#s0090) 节中，我讨论了逐步特征选择技术（前向、后向），基于第 [7.5.1](#Chp007_113-129_B9780443218576000114.xhtml#s0085) 节构建的特征表，每次添加或移除一两个特征。综合特征汇总表使您能够快速执行逐步回归（这比完全拟合的回归更具可解释性），并评估该技术是否无法捕捉到足够好的配置，至少对于此处研究的数据集而言。

### 7.5.1 组合法

这里我考察所有 `2^m - 1`![Image](images/B9780443218576000114/si120.png) 种可能的特征 `X[1]`、…、`X[m]`![Image](images/B9780443218576000114/si23.png) 配置，以评估单个特征和特征交互的重要性，这比查看特征间的交叉相关性更有洞察力。对于每种配置，我使用三种方法计算回归系数向量：15 次迭代的不动点法、100 次迭代的不动点法（两者均从 `β[0] = 0`![Image](images/B9780443218576000114/si13.png) 开始），以及第 [7.2.3](#Chp007_113-129_B9780443218576000114.xhtml#s0030) 节定义的特殊 `β[0]`![Image](images/B9780443218576000114/si7.png) 单独使用（无迭代）。除非另有说明，所有排名均基于不动点算法的 100 次迭代。

我使用第 [7.4](#Chp007_113-129_B9780443218576000114.xhtml#s0060) 节定义的评分指标 `s`（R 平方的一个有意义的单调函数）来衡量性能。如果改用 R 平方，排名仍将相同。完整模型有 `m = 6`![Image](images/B9780443218576000114/si90.png) 个特征。所有其他模型都是子模型，称为配置：它们缺少一个或多个特征。指标 `s` 在验证集上计算，而非训练集。

`Regression5_Static.xlsx` 电子表格中 Results 选项卡的汇总表；请参阅 `columns U:AS`。该电子表格可在[此处](https://github.com/VincentGranville/Machine-Learning/blob/main/Spreadsheets/README.md)获取。其结构与第 [7.2](#Chp007_113-129_B9780443218576000114.xhtml#s0015)、[7.2.4](#Chp007_113-129_B9780443218576000114.xhtml#s0035) 和 [7.3.1](#Chp007_113-129_B9780443218576000114.xhtml#s0045) 节所述电子表格相同。区别在于此处数据集是静态的，因此无法生成不同的数据集。该方法受书籍“可解释机器学习”[\[6\]](#Chp007_113-129_B9780443218576000114.xhtml#br0030)启发，特别是第 7 章关于排列特征重要性和特征交互的内容。`s` 越高，性能越好。请注意，如果性能是在训练集而非验证集上计算的，则会有 `0 ≤ s ≤ 1`![Image](images/B9780443218576000114/si81.png)。
