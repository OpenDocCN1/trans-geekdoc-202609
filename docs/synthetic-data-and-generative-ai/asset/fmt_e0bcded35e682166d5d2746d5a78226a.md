
## Exercise 16.1

- Generate a particular type of **random graph**, called **random NN graph**, as follows. Let `V[1]`, …, `V[n]`![Image](images/B9780443218576000205/si151.png) be the `n` **vertices** of the graph (their locations do not matter). For the “nearest neighbor” to vertex `V[k]`![Image](images/B9780443218576000205/si152.png) (`k = 1, …, n`![Image](images/B9780443218576000205/si153.png)), randomly pick up one of the `n` vertices except `V[k]`![Image](images/B9780443218576000205/si152.png) itself. Two points (vertices) can have the same nearest neighbor. Now study the distribution of `S` via simulations. Is it the same as for the graph generated by the nearest neighbors in a stationary Poisson point process?

- This is the most difficult part. Let `P(S = k)`![Image](images/B9780443218576000205/si154.png), `k = 2, 3, …`![Image](images/B9780443218576000205/si155.png) be the size distribution for connected components of a stationary Poisson process; `S` is a random variable. Of course, it does not depend on `λ`. Does it uniquely characterize the Poisson process, in the same way that the exponential distribution for interarrival times uniquely characterizes the Poisson process in one dimension? Do we have `P(S = 2) = 1/2`![Image](images/B9780443218576000205/si156.png), not only for Poisson processes, but also for a much larger class of point processes?

#### Hints

Beware of the **boundary effect**; to minimize the impact, use a uniform distribution for `F` (the distribution attached to the points of the Poisson–binomial process) and `n > 10^3`![Image](images/B9780443218576000205/si157.png). When the scaling factor `s` is zero, there is only one connected component of infinite size (`P[S = ∞] = 1`![Image](images/B9780443218576000205/si158.png)): this is a singularity, as illustrated on the left plot in [Fig. 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040). But as soon as `s > 0`![Image](images/B9780443218576000205/si141.png), all the connected components are of finite size and rather small. The smallest ones have two points as each point has a nearest neighbor, thus `P[S < 2] = 0`![Image](images/B9780443218576000205/si159.png). When `s = ∞`![Image](images/B9780443218576000205/si106.png), the process becomes a stationary Poisson process.

I conjecture that stationary Poisson processes and some other (if not all) Poisson–binomial processes share the exact same discrete probability distribution for the size of connected components defined by nearest neighbors, and abbreviated as **CCS distribution**. Thus, unlike the point count distribution or nearest neighbor distance distributions, the **CCS distribution** can not be used to characterize a Poisson process. For random graphs, the **CCS distribution** is different from that of a Poisson process. I used a **Kolmogorov–Smirnov test** [[Wiki](https://en.wikipedia.org/wiki/Kolmogorov-Smirnov_test)] (see also [[17]](#Chp016_293-327_B9780443218576000205.xhtml#br0085)) to compare the two empirical **CCS distributions** – the one attached to Poisson processes versus the one attached to random NN graphs – and concluded, based on my sample size (`n = 10^4`![Image](images/B9780443218576000205/si148.png) points or vertices), that they were statistically different.

To conclude, it appears that the **CCS distribution** cannot be arbitrary. Many point processes seem to have the same **CCS distribution**, called **attractor distribution**, and these processes constitute the **domain of attraction** of the attractor. The concepts of **domain of attraction** and **attractor** is used in other contexts such as **dynamical systems** [[Wiki](https://en.wikipedia.org/wiki/Attractor)] or extreme value theory [[Wiki](https://en.wikipedia.org/wiki/Generalized_extreme_value_distribution)] (also, see [[5]](#Chp016_293-327_B9780443218576000205.xhtml#br0025), page 317). The most well known analogy is the **Central Limit Theorem**, where the Gaussian distribution is the main attractor, and the Cauchy distribution is another. In Chapter 11 of “The Probabilistic Method” [[1]](#Chp016_293-327_B9780443218576000205.xhtml#br0005), dealing with the size of connected components in random graphs, the author introduces a random variable `T[c]`![Image](images/B9780443218576000205/si160.png), also counting a number of vertices (called **nodes** in the book). Its distribution has all the hallmarks of an attractor. See Theorem 11.4.2 (page 202) in the book in question.

To find the connected components, you can use the source code in `Section 16.2.4.3` (#Chp016_293-327_B9780443218576000205.xhtml#s0075). To simulate point processes, you can use the program `PB_NN.py` (https://github.com/VincentGranville/Point-Processes/blob/main/Source%20Code/PB_NN.py) available on GitHub and described in `section 6.4` in [[20]](#Chp016_293-327_B9780443218576000205.xhtml#br0100): it produces an output file `PB_NN_dist_full.txt` (https://github.com/VincentGranville/Point-Processes/blob/main/Data/PB_NN_dist_full.txt) that can be used as input, without any change, to the connected components algorithm in `section 16.2.4.3` (#Chp016_293-327_B9780443218576000205.xhtml#s0075). ## Exercise 16.2

Maximum clique problem. In **undirected graphs** [[Wiki](https://en.wikipedia.org/?title=Undirected_graph)], a **clique** is a set of vertices (also called nodes) all connected to each other. In **nearest neighbor** graphs, two points are connected if one of them is a closest neighbor to the other. How would you identify a clique of maximum size in such a graph? No need to design an algorithm from scratch; instead, search the literature. Finding the maximum clique [[Wiki](https://en.wikipedia.org/wiki/Clique_problem)] is **NP-hard** [[Wiki](https://en.wikipedia.org/wiki/NP-hardness)], and the problem is related to the “P versus NP” conjecture [[Wiki](https://en.wikipedia.org/wiki/P_versus_NP_problem)]. The maximum clique problem has many applications, in particular in social networks. Probabilistic properties of cliques in **random graphs** are discussed in “Cliques in random graphs” [[6]](#Chp016_293-327_B9780443218576000205.xhtml#br0030) and “On the evolution of random graphs” [[16]](#Chp016_293-327_B9780443218576000205.xhtml#br0080). See also the **Erdős–Rényi model** [[Wiki](https://bit.ly/3uzQzNF)]. More recent articles include [[18](#Chp016_293-327_B9780443218576000205.xhtml#br0090),[30]](#Chp016_293-327_B9780443218576000205.xhtml#br0150).
