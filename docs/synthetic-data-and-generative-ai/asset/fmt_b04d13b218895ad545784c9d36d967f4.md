
Now you can use `R²`![Image](images/B9780443218576000059/si76.png) for model comparison purposes and even for feature selection [[Wiki](https://en.wikipedia.org/wiki/Feature_selection)]. You can test the improvement obtained by using the full model over a submodel, with the metric `S(θ[*]) = R²(θ^(\*)) − R²(θ[*])`![Image](images/B9780443218576000059/si77.png). Here `θ[*]`![Image](images/B9780443218576000059/si67.png) is the optimum `θ` attached to the submodel. Obviously, `0 ≤ S(θ[*]) ≤ 1`![Image](images/B9780443218576000059/si78.png). The larger `S(θ[*])`![Image](images/B9780443218576000059/si79.png), the bigger the improvement. Conversely, the smaller, the better the performance of the submodel. Examples include fitting an ellipse (full model) versus fitting a circle (submodel) or using all the features (full model) versus using a subset (submodel). You can compare submodels and rank them according to `S(θ[*])`![Image](images/B9780443218576000059/si79.png). This allows you to identify the smallest set of features that achieve a good enough `S(θ[*])`![Image](images/B9780443218576000059/si79.png), for dimensionality reduction purposes [[Wiki](https://en.wikipedia.org/wiki/Dimensionality_reduction)].

Finally, another update consists of using positive weights `ψ_k(θ)`![Image](images/B9780443218576000059/si80.png) in formula [(1.1)](#Chp001_1-34_B9780443218576000059.xhtml#deq1). This amounts to performing **weighted regression** [[Wiki](https://en.wikipedia.org/wiki/Generalized_least_squares#Weighted_least_squares)]. For instance, data points far away from the optimum shape, that is, observations with a large `g²(W_k, θ^(\*))`![Image](images/B9780443218576000059/si81.png), may be discarded to reduce the impact of outliers. Or the weights can be used to balance the coefficients `θ_i`![Image](images/B9780443218576000059/si68.png), in an effort to achieve scale-invariance in the expression `wθ`. Then the top system in [(1.2)](#Chp001_1-34_B9780443218576000059.xhtml#deq2) becomes

```
\sum_{k = 1}^{n} \psi_k(\theta) \nabla_\theta [g^2(W_k, \theta)] + \sum_{k = 1}^{n} g^2(W_k, \theta) \nabla_\theta [\psi_k(\theta)] = \lambda \nabla_\theta [\eta(\theta)].
```

## 1.3 Case studies

In Section [1.3.1](#Chp001_1-34_B9780443218576000059.xhtml#s0040), I show how to solve the logistic regression. The first version is standard least squares, to further illustrate backward compatibility with the traditional method. The second illustrates how it could be done if you want to follow the spirit of the new methodology. Then I discuss two fundamental examples based on synthetic data.

### 1.3.1 Logistic regression, two ways

In the traditional setting, `w = (y, x)`![Image](images/B9780443218576000059/si83.png) where `y` is the response and `x` the features. For the logistic regression [[Wiki](https://en.wikipedia.org/wiki/Logistic_regression)], we have

`g(w, θ) = g(y, x) = y − F(xᵀθ)`, with `xᵀθ = θ_1 x_1 + ⋯ + θ_m x_m`.

![Image](images/B9780443218576000059/si84.png)

Here `x_1 = 1`![Image](images/B9780443218576000059/si18.png) corresponds to the intercept, thus we have `m − 1`![Image](images/B9780443218576000059/si85.png) actual features `x_2, x_3, …, x_m`![Image](images/B9780443218576000059/si86.png). There is no constraint on the parameter `θ`, thus there is no function `η(θ)`![Image](images/B9780443218576000059/si87.png). In formula [(1.2)](#Chp001_1-34_B9780443218576000059.xhtml#deq2), `η(θ) = 0`![Image](images/B9780443218576000059/si42.png) should be ignored, and `λ = 0`![Image](images/B9780443218576000059/si88.png). The function `F` is a cumulative distribution function with a symmetric density around the origin. In this case, `F(xᵀθ) = 1 / (1 + exp[−xᵀθ])`![Image](images/B9780443218576000059/si89.png) is the standard **logistic distribution** [[Wiki](https://en.wikipedia.org/wiki/Logistic_distribution)].

In the new methodology, one would proceed as follows. First, the original data is denoted as `z = (v, u)`![Image](images/B9780443218576000059/si90.png). The logistic regression applies to the original data. Here `v` is the response, and `u` the feature vector. The parameter `θ` is unchanged (not subject to a mapping), and still denoted as `θ`. This regression can be stated as

`g(z, θ) = g(v, u) = v − F(uᵀθ)`, with `uᵀθ = θ_1 u_1 + … + θ_m u_m`.

![Image](images/B9780443218576000059/si91.png)

The first step is to map `z = (v, u)`![Image](images/B9780443218576000059/si90.png) onto `w = (y, x)`![Image](images/B9780443218576000059/si83.png), with the hope of simplifying the problem, as discussed in Section [1.1.1](#Chp001_1-34_B9780443218576000059.xhtml#s0015). This is done via the link function `y = F^(−1)(v) = log[v/(1 − v)]`![Image](images/B9780443218576000059/si92.png) and `u = x`![Image](images/B9780443218576000059/si93.png). Now we are back to

`g(z, θ) = g(w, θ) = g(y, x; θ) = y − xᵀθ`, with `xᵀθ = θ_1 x_1 + … + θ_m x_m`.

![Image](images/B9780443218576000059/si94.png)

This is how standard linear regression is expressed in the new framework. But it is still the traditional linear regression, with nothing new. The final step consists in extending `θ`, adding one component `θ_0`![Image](images/B9780443218576000059/si95.png) to `θ_1, …, θ_m`![Image](images/B9780443218576000059/si96.png). With the new `θ` (still denoted as `θ`) we have `g(w, θ) = wᵀθ = θ_0 w_0 + ⋯ + θ_m w_m`![Image](images/B9780443218576000059/si97.png). You need to add one constraint on `θ`. The constraint `θ_0 = −1`![Image](images/B9780443218576000059/si17.png), that is, `η(θ) = θ_0 + 1`![Image](images/B9780443218576000059/si44.png), yields the exact same solution as traditional linear regression. But `θᵀθ = 1`![Image](images/B9780443218576000059/si59.png), that is, `η(θ) = θᵀθ − 1`![Image](images/B9780443218576000059/si43.png), makes the problem somehow symmetric, and more elegant.

However, in many applications, the response `v` in the original space is either 0 or 1, such as cancer versus noncancer, or fraud versus nonfraud. In this case, the link function is undefined. The mapping with the link function works if the response is a proportion, strictly between zero and one. Otherwise, the standard logistic regression is the best approach. A possible workaround is to use for `F` a distribution with a finite support, such as uniform on `[a, b]`![Image](images/B9780443218576000059/si98.png). After all, the observed values (the features) are always bounded anyway. Then, intuitively, given `θ`, estimates of `a` and `b` are proportional respectively to the minimum and maximum of `U_k θ`![Image](images/B9780443218576000059/si99.png), over `k = 1, …, n`![Image](images/B9780443218576000059/si49.png).

This suggests a new approach to logistic regression. First, use the model `v = F_θ(uᵀθ)`![Image](images/B9780443218576000059/si100.png) in the `(v, u)`![Image](images/B9780443218576000059/si101.png)-space, where `0 ≤ v ≤ 1`![Image](images/B9780443218576000059/si102.png) and `F_θ`![Image](images/B9780443218576000059/si103.png) is the empirical distribution [[Wiki](https://en.wikipedia.org/wiki/Empirical_distribution_function)] of `uθ` given `θ`. Then choose `θ^(\*)`![Image](images/B9780443218576000059/si10.png) that minimizes the sum of squared residuals:

```
θ^* = argmin_θ ∑_{k=1}^n g^2(V_k, U_k; θ) = argmin_θ ∑_{k=1}^n (V_k - F_θ(U_k θ))^2.
```
