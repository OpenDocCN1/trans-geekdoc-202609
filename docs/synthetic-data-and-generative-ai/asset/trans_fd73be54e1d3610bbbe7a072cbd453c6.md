
- **连通分量的大小** – 一个有趣的问题是识别与点过程相关的最近邻**无向图**中的连通分量，请参见[练习 16.1](#Chp016_293-327_B9780443218576000205.xhtml#enun0010)。这些连通分量展示在[图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040)中。它们的大小分布尤为引人关注：例如，在[图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040)的左图中，对应 `s = 0`，仅存在一个无限大小的连通分量；在右图中，存在无限多个小的连通分量（约 50% 仅包含两个点）。这仍是一个开放性问题：即该统计量能否用于区分不同类型的点过程，又或是其理论分布对于一大类点过程完全相同（即它是**吸引子分布**），因此鲜有实际价值。

### 16.3.2.3 瑞利检验

**瑞利检验**是一种通用的统计检验，用于评估由二维点组成的两个数据集是否源自同类随机点过程。它假设底层点过程模型由最近邻距离的分布唯一表征。最常见的用例是假设模型为平稳泊松过程：在这种情况下，检验统计量服从**瑞利分布**。它可推广到高维情况；此时瑞利分布变为**韦伯分布**。简而言之，该检验实际所做的是比较在两个数据集上计算出的最近邻距离经验分布（可能经过标准化），以从统计角度评估它们是否无法区分。

检验步骤如下。假设你有两个由二维点组成的数据集，通过一个窗口观测。你在处理好**边界效应**后，基于观测值计算两个数据集最近邻距离的经验分布。设 `η[1](u)` 和 `η[2](u)` 为相关的两个分布。检验统计量为

```
V = ∫[-∞]^∞ |η[1](u) - η[2](u)| du = ∫[0]^1 |ν[1](u) - ν[2](u)| du
```
(16.13)

其中 `ν` 为经验**分位数函数**，即经验分布函数的反函数。另一种检验基于 `W = sup[u] |η[1](u) - η[2](u)|`，或 `W' = sup[u] |ν[1](u) - ν[2](u)|`。基于 `W` 的检验是传统的 Kolmogorov–Smirnov 检验 [[维基百科](https://en.wikipedia.org/wiki/Kolmogorov-Smirnov_test)]，具有已知的列表值。在 Excel 中，使用经验分位数函数更方便，它可直接作为 Excel 的 `PERCENTILE` 函数使用。在实践中，公式 [(16.13)](#Chp016_293-327_B9780443218576000205.xhtml#deq18) 中的积分被替换为在 `u ∈ [0, 1]` 上 100 个等间距值计算出的求和。`W` 的优势在于它（渐近地）已知不依赖于数据源自的底层（可能未知的）点过程模型。

我在 [`PB_inference.xlsx`](https://github.com/VincentGranville/Point-Processes/tree/main/Spreadsheets) 中提供了一个演示：请查看电子表格中的“Rayleigh test”选项卡。我比较了两个数据集，一个来自参数 `s = 20` 的二维泊松-二项过程模拟，另一个来自 `s = 0.4`。在两种情况下，模拟器中的 `λ` 均设为 1.5；其在生成数据集上的估计值接近 1.5。然后我将**最近邻距离**（其经验分位数函数）与强度为 `λ²` 的二维平稳泊松过程的理论分布进行比较。理论分布为期望为 `1/(2λ)` 的瑞利分布。参数 `s = 20` 的数据集至少根据瑞利检验，无法与平稳泊松过程的一个实现区分开来。这是预料之中的：当 `s → ∞` 时，泊松-二项过程收敛于泊松过程，且收敛速度非常快。但参数 `s = 0.4` 的数据集与泊松点过程实现显著不同，这从统计量 `V` 或 `W'` 即可看出。

统计量 `V` 和 `W'` 的列表值可通过模拟获得。对于 `W`，自 1948 年以来其值已知，因为 `W` 即为 Kolmogorov–Smirnov 统计量 [[17]](#Chp016_293-327_B9780443218576000205.xhtml#br0085)。此处我直接使用了瑞利分布的列表值，因为我是在将模拟数据与平稳泊松过程的实现进行比较。经验分位数函数的**置信带** [[维基百科](https://en.wikipedia.org/wiki/Confidence_and_prediction_bands)] 可通过**重采样**方法 [[维基百科](https://en.wikipedia.org/wiki/Resampling_(statistics))] 获得，如自助法或**参数自助法**。另请参阅第 [18.3](#Chp018_361-386_B9780443218576000229.xhtml) 节。

[图 16.7](#Chp016_293-327_B9780443218576000205.xhtml#f0050) 展示了我的检验结果，使用了最近邻距离的经验分位数函数以及检验统计量 `V`。无需重采样或置信带，结论显而易见：`s = 0.4` 提供的模拟数据集与泊松点过程实现显著不同（灰色曲线偏离严重），而 `s = 20` 无法与泊松点过程区分（红色和蓝色曲线代表**最近邻距离**的经验分位数函数，几乎重合）。有趣的是，[图 16.7](#Chp016_293-327_B9780443218576000205.xhtml#f0050) 中对应 `s = 0.4` 的散点图（最右侧）看起来比 `s = 20`（中间图）更随机，但实际情况恰恰相反。`s = 0.4` 的图对应一个**排斥过程**，其中点之间的距离比纯随机所决定的更远；因此它表现出较少的大空隙和较少的聚类，错误地给人一种随机性增加的印象。
