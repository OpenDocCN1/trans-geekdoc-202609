
模拟 `radial processes` 有不同的方法；最流行的方法对子过程使用二元高斯分布。具有 `nonhomogeneous` 径向强度的泊松点过程在我的文章“通过最近邻距离估计泊松点过程的强度”[\[19\]](#Chp016_293-327_B9780443218576000205.xhtml#br0095)中进行了讨论。重点在于径向（因此是非齐次）强度函数：在这种情况下 `λ` 取决于位置，这与 `λ` 为常数的平稳泊松过程形成对比。估计此类过程的 `intensity function` 等同于一个 `density estimation` 问题，使用核密度估计器 [[Wiki](https://en.wikipedia.org/wiki/Kernel_density_estimation)]。

### 16.2.4 叠加扰动晶格：混合模型的一种替代方案

当具有相同分布 `F` 的 `m` 个独立泊松-二项过程的点捆绑在一起时，我们称这些过程为 `superimposed`。结果可能不再是泊松-二项分布，这与标准泊松过程的叠加不同（后者本身是泊松-二项过程的一种特例，其中 `s = ∞`![Image](images/B9780443218576000205/si106.png)）。确实，如果缩放因子 `s` 很小且 `m > 1`![Image](images/B9780443218576000205/si107.png) 不太小，则生成的过程会在每个晶格位置周围表现出聚类现象。此外，每个单独点过程的强度或缩放因子可能不同，且生成的过程可能不是齐次的。叠加点过程也称为 `interlaced` 过程。

我首先描述混合模型，然后再介绍交织过程。这两种模型有许多相似之处，但也存在一些差异。`m` 个点过程的 `mixture`，记为 `M`，定义如下：

-   我们有 `m` 个具有相同分布 `F` 的独立点过程 `M[1]`，…，`M[m]`![Image](images/B9780443218576000205/si108.png)。
-   与 `M[i]`![Image](images/B9780443218576000205/si109.png) 相关的强度和缩放因子分别记为 `λ[i]`![Image](images/B9780443218576000205/si110.png) 和 `s[i]`![Image](images/B9780443218576000205/si111.png)（`i = 1, …, m`![Image](images/B9780443218576000205/si112.png)）。
-   `M[i]`![Image](images/B9780443218576000205/si109.png) 的点（`i = 1, …, m`![Image](images/B9780443218576000205/si113.png)）记为 (`X[i_h]`, `Y[i_k]`)![Image](images/B9780443218576000205/si114.png)。
-   混合过程 `M` 的点 (`X[h]`, `Y[k]`)![Image](images/B9780443218576000205/si4.png) 以概率 `π[i] > 0`![Image](images/B9780443218576000205/si115.png) 等于 (`X[i_h]`, `Y[i_k]`)![Image](images/B9780443218576000205/si114.png)，`i = 1, …, m`![Image](images/B9780443218576000205/si112.png)。

`π[i]`![Image](images/B9780443218576000205/si116.png) 是混合比例，其和等于 1。虽然混合或叠加泊松-二项过程看起来像是同一种操作，这对平稳泊松过程成立，但在泊松-二项过程的情况下，它们是截然不同的操作，当缩放因子非常小时会导致显著差异。当 `s = 0`![Image](images/B9780443218576000205/si10.png) 时，差异最为明显。特别是，叠加过程比混合过程的随机性更小。这是由于底层晶格的离散性质所致。然而，随着缩放因子变大，混合过程和叠加过程的行为趋于相似。

[图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040) 表示 `m` 个叠加的平移拉伸泊松-二项过程的一个实现，称为 `m-interlacing`。对于每个单独的过程 `M[i]`![Image](images/B9780443218576000205/si109.png)，`i = 1, …, m`![Image](images/B9780443218576000205/si112.png)，附加到点 (`X[i_h]`, `X[i_k]`)![Image](images/B9780443218576000205/si117.png)（其中 `h`, `k ∈ ℤ`![Image](images/B9780443218576000205/si5.png)）的分布是

```math
P(X_{ih} < x, Y_{ik} < y) = F\left( \frac{x - \mu_{i} - h/\lambda}{s} \right) F\left( \frac{y - \mu_{i}^{\prime} - k/\lambda^{\prime}}{s} \right), \quad i = 1,\ldots,m.
```

![Image](images/B9780443218576000205/si118.png)

这推广了公式 [(16.1)](#Chp016_293-327_B9780443218576000205.xhtml#deq1)。[图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040) 所示模型使用的参数如下：

-   叠加过程的数量：`m = 4`![Image](images/B9780443218576000205/si119.png)；每个过程用不同颜色显示，
-   颜色：`M[1]`![Image](images/B9780443218576000205/si120.png) 为红色，`M[2]`![Image](images/B9780443218576000205/si121.png) 为蓝色，`M[3]`![Image](images/B9780443218576000205/si122.png) 为橙色，`M[4]`![Image](images/B9780443218576000205/si123.png) 为黑色，
-   缩放因子：`s = 0`![Image](images/B9780443218576000205/si10.png)（左图）和 `s = 5`![Image](images/B9780443218576000205/si124.png)（右图），
-   强度：`λ = 1/3`![Image](images/B9780443218576000205/si125.png)（X 轴）和 `λ' = √3/3`![Image](images/B9780443218576000205/si126.png)（Y 轴），
-   平移向量，X 坐标：`μ[1] = 0`![Image](images/B9780443218576000205/si127.png)，`μ[2] = 1/2`![Image](images/B9780443218576000205/si128.png)，`μ[3] = 2`![Image](images/B9780443218576000205/si129.png)，`μ[4] = 3/2`![Image](images/B9780443218576000205/si130.png)，
-   平移向量，Y 坐标：`μ[1]' = 0`![Image](images/B9780443218576000205/si131.png)，`μ[2]' = √3/2`![Image](images/B9780443218576000205/si132.png)，`μ[3]' = 0`![Image](images/B9780443218576000205/si133.png)，`μ[4]' = √3/2`![Image](images/B9780443218576000205/si134.png)，
-   `F` 分布：均值为零、方差为 `π²/3`![Image](images/B9780443218576000205/si135.png) 的标准中心 `logistic distribution`。

出于模拟目的，第 `i` 个过程 `M[i]`![Image](images/B9780443218576000205/si109.png) 的点 (`X[i_h]`, `Y[i_k]`)![Image](images/B9780443218576000205/si114.png)（`i = 1, …, m`![Image](images/B9780443218576000205/si112.png)）按如下方式生成：

```math
X_{ih} = \mu_{i} + \frac{h}{\lambda} + s \cdot \log\left( \frac{U_{ih}}{1 - U_{ih}} \right),
```
![Image](images/B9780443218576000205/si136.png)(16.11)

```math
Y_{ik} = \mu_{i}^{\prime} + \frac{k}{\lambda^{\prime}} + s \cdot \log\left( \frac{U_{ik}}{1 - U_{ik}} \right),
```
![Image](images/B9780443218576000205/si137.png)(16.12)

其中 `U[i_j]`![Image](images/B9780443218576000205/si138.png) 在 `[0, 1]`![Image](images/B9780443218576000205/si104.png) 上独立均匀分布，且 `−n ≤ h, k ≤ n`![Image](images/B9780443218576000205/si139.png)。我在模拟中选择了 `n = 25`![Image](images/B9780443218576000205/si140.png)——窗口比 [图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040) 大得多——以避免图中的 `boundary effects`。边界效应有时称为 `edge effect`。观测窗口外未观测到的数据点被称为 `censored data` [[Wiki](https://en.wikipedia.org/wiki/Censoring_(statistics))]。当然，在我的模拟中，它们的位置和特征（如属于哪个过程）由设计已知。但在真实数据集中，它们确实是缺失或不可观测的，统计推断必须相应调整 [\[15\]](#Chp016_293-327_B9780443218576000205.xhtml#br0075)。
