## 18.3 对偶置信区域

本教程解释了如何在尽可能少用统计理论的情况下构建置信区域（置信区间的二维版本）。我还避免了传统的术语和符号，如 `α`、`Z[1−α]`![Image](images/B9780443218576000229/si7.png)、临界值、置信水平、显著性水平等。这些对初学者和专业人士来说都可能令人困惑。

相反，我仅使用模拟和两个关键词：置信区域和置信水平。目的是利用一个对机器学习专业人士、软件工程师和非统计学家都友好的框架来解释该概念。我希望您能深入理解该技术，而不感到头疼。我还介绍了一种替代类型的置信区域，称为对偶置信区域。它在渐近意义上等同于标准定义。在我看来，它更直观。

### 18.3.1 案例研究

此示例源自第 [16.4.1](#Chp016_293-327_B9780443218576000205.xhtml) 节中讨论的实际应用。此处我提供说明方法所需的最少材料。完整问题见第 [18.3.5](#Chp018_361-386_B9780443218576000229.xhtml#s0070) 节，供好奇的读者参考。在最简单的形式中，我们处理的是独立的 `bivariate Bernoulli trials`。数据集有 `n` 个观测值。每个观测值包含两个测量值 `(u[k], v[k])`![Image](images/B9780443218576000229/si8.png)，其中 `k=1,…,n`![Image](images/B9780443218576000229/si9.png)。如果某个区间 `B[k]`![Image](images/B9780443218576000229/si11.png) 包含零个点，则 `u[k]=1`![Image](images/B9780443218576000229/si10.png)（否则 `u[k]=0`![Image](images/B9780443218576000229/si12.png)）。同样，如果同一区间包含一个点，则 `v[k]=1`![Image](images/B9780443218576000229/si13.png)（否则 `v[k]=0`![Image](images/B9780443218576000229/si14.png)）。

区间 `B[k]`![Image](images/B9780443218576000229/si11.png) 可以包含多个点，但当然不能同时包含一个点和两个点。`B[k]`![Image](images/B9780443218576000229/si11.png) 包含零个点的概率是 `p`；包含一个点的概率是 `q`，满足 `0 < p + q < 1`![Image](images/B9780443218576000229/si15.png)。目标是估计 `p` 和 `q`。估计量（基于观测值计算的比例）记为 `p[0]`![Image](images/B9780443218576000229/si16.png) 和 `q[0]`![Image](images/B9780443218576000229/si17.png)。

因为我们处理的是伯努利变量，所以标准差为 `σ_p = sqrt(p(1 - p))`![Image](images/B9780443218576000229/si18.png) 和 `σ_q = sqrt(q(1 - q))`![Image](images/B9780443218576000229/si19.png)。观测向量的两个分量 `u[k], v[k]`![Image](images/B9780443218576000229/si20.png) 之间的相关性为 `ρ_p,q = - p*q/σ[p]*σ[q]`![Image](images/B9780443218576000229/si21.png)。确实，观测到 `(0, 0)`![Image](images/B9780443218576000229/si22.png) 的概率是 `1 - p - q`![Image](images/B9780443218576000229/si23.png)，观测到 `(1, 0)`![Image](images/B9780443218576000229/si24.png) 的概率是 `p`，观测到 `(0, 1)`![Image](images/B9780443218576000229/si25.png) 的概率是 `q`，观测到 `(1, 1)`![Image](images/B9780443218576000229/si26.png) 的概率为零。

### 18.3.2 标准置信区域

水平为 `γ` 的置信区域是一个面积最小的域，它包含基于您的 `n` 个观测值的估计量 `(p[0], q[0])`![Image](images/B9780443218576000229/si27.png) 潜在值的比例 `γ`。当 `n` 很大时，`(p[0], q[0])`![Image](images/B9780443218576000229/si27.png) 近似服从 `bivariate normal distribution`（也称为高斯分布），这归功于 `central limit theorem`。该正态分布的 `covariance matrix` 由在 `p = p[0]`![Image](images/B9780443218576000229/si30.png) 和 `q = q[0]`![Image](images/B9780443218576000229/si31.png) 处测得的 `σ[p], σ[q]`![Image](images/B9780443218576000229/si28.png) 和 `ρ[p, q]`![Image](images/B9780443218576000229/si29.png) 指定。对于固定的 `γ`，最优形状——即面积最小的形状——其边界必然是相关分布的一个等高线。在我们的例子中，该分布是二元高斯分布，因此等高线是椭圆。

我们定义

```
H_n(x,y,p,q) = \frac{2n}{1 - \rho_{p,q}^{2}}\left\lbrack \left( \frac{x - p}{\sigma_{p}} \right)^{2} - 2\rho_{p,q}\left( \frac{x - p}{\sigma_{p}} \right)\left( \frac{y - q}{\sigma_{q}} \right) + \left( \frac{y - q}{\sigma_{q}} \right)^{2} \right\rbrack,
```

![Image](images/B9780443218576000229/si32.png)(18.1)

其中

```
\sigma_{p} = \sqrt{p(1 - p)},\quad\sigma_{q} = \sqrt{q(1 - q)},\quad\rho_{p,q} = - \frac{pq}{\sqrt{pq(1 - p)(1 - q)}}.
```

![Image](images/B9780443218576000229/si33.png)(18.2)
