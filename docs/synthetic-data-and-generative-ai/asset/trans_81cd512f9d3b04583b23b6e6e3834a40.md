
$$L_P(z,\chi) = L(z/2^n, -\psi_n) \prod_{k=1}^n L_P(z/2^k, \psi_k),$$

![Image](images/B9780443218576000217/si408.png)

其中 `n ≥ 1` ![Image](images/B9780443218576000217/si409.png) 且 `ψ[k+1]² = -ψ[k]` ![Image](images/B9780443218576000217/si410.png) 对于 `k = 1, 2` ![Image](images/B9780443218576000217/si411.png)，依此类推。此公式对 `σ` 的哪些取值有效？根据构造，所有相关的欧拉乘积必然收敛，这表明 `σ > 2^n` ![Image](images/B9780443218576000217/si412.png)。

# 练习 17.8

## 黎曼zeta函数的零点

如往常一样，`z = σ + i t` ![Image](images/B9780443218576000217/si2.png)。设 `S[0]` ![Image](images/B9780443218576000217/si413.png) 为任意包含恰好一个值 `t[0]` ![Image](images/B9780443218576000217/si414.png) 的开区间，使得 $\zeta(\frac{1}{2} + i t_0) = 0$ ![Image](images/B9780443218576000217/si415.png)，并设 `η(z)` ![Image](images/B9780443218576000217/si29.png) 为标准**狄利克雷eta函数**。讨论当 `t ∈ S[0]` ![Image](images/B9780443218576000217/si416.png) 且 $\frac{1}{2} < \sigma < 1$ ![Image](images/B9780443218576000217/si20.png) 时 `η(z)` ![Image](images/B9780443218576000217/si29.png) 的零点是否存在。展示当 `S[0] = ]199, 202[` ![Image](images/B9780443218576000217/si417.png) 时该如何运作。您可以在[此处](http://www.dtc.umn.edu/~odlyzko/zeta_tables/)找到 `ζ(z)` ![Image](images/B9780443218576000217/si8.png) 的前 ![Image](images/B9780443218576000217/fx006.jpg) 个非平凡零点的表格。

## 解答

假设 `σ` 固定。设 `μ(σ)` ![Image](images/B9780443218576000217/si418.png) 为当 `t ∈ S[0]` ![Image](images/B9780443218576000217/si416.png) 时 `|η(z)|` ![Image](images/B9780443218576000217/si419.png) 的最小值，并设 `τ(σ)` ![Image](images/B9780443218576000217/si420.png) 为取得最小值的值。即，

$$\mu(\sigma) = \min_{t \in S_0} |\eta(\sigma + it)|, \quad \tau(\sigma) = \underset{t\in S_0}{\arg\min} |\eta(\sigma + it)|.$$

![Image](images/B9780443218576000217/si421.png)

如果 `S[0] = ]199, 202[` ![Image](images/B9780443218576000217/si417.png) 则 `t[0] ≈ 201.26` ![Image](images/B9780443218576000217/si422.png)。设 `t[0]' = 44π/log 2 ≈ 199.42` ![Image](images/B9780443218576000217/si423.png)。我们有 `1 - 2^(1-z) = 0` ![Image](images/B9780443218576000217/si424.png) 其中 `z = 1 + i t[0]'` ![Image](images/B9780443218576000217/si425.png)，并且：

- $\mu(\frac{1}{2}) = 0$ ![Image](images/B9780443218576000217/si426.png) 和 $\tau(\frac{1}{2}) = t_0$ ![Image](images/B9780443218576000217/si427.png)，因为 $\eta(\frac{1}{2} + i t_0) = 0$ ![Image](images/B9780443218576000217/si428.png)，
- `μ(1) = 0` ![Image](images/B9780443218576000217/si429.png) 和 `τ(1) = t[0]'` ![Image](images/B9780443218576000217/si430.png)，因为 `η(1 + i t[0]') = 0` ![Image](images/B9780443218576000217/si431.png)，
- `μ(σ)` ![Image](images/B9780443218576000217/si418.png) 严格单调递增且连续，如果 $\frac{1}{2} \leqslant \sigma \leqslant \sigma_0$ ![Image](images/B9780443218576000217/si432.png) 且 `σ[0] ≈ 0.75` ![Image](images/B9780443218576000217/si433.png)，
- `μ(σ)` ![Image](images/B9780443218576000217/si418.png) 严格单调递减且连续，如果 `σ[0] ≤ σ ≤ 1` ![Image](images/B9780443218576000217/si434.png)。

换句话说，`μ(σ)` ![Image](images/B9780443218576000217/si418.png) 是凸的。这似乎意味着如果 `t ∈ S[0]` ![Image](images/B9780443218576000217/si416.png) 且 $\frac{1}{2} < \sigma < 1$ ![Image](images/B9780443218576000217/si20.png)，则不存在零点。然而，证明 `μ(σ)` ![Image](images/B9780443218576000217/si418.png) 是单调递增或递减的，且仅在某个 `σ[0]` ![Image](images/B9780443218576000217/si104.png) 处有一个变化点（取决于 `S[0]` ![Image](images/B9780443218576000217/si413.png)），可能与证明黎曼假设（RH）本身一样困难：这仅基于经验证据，且与 `ζ(z)` ![Image](images/B9780443218576000217/si8.png) 导数不存在零点（推测）有关。事实上，这只是黎曼假设的一个推论，见[此处](https://mathoverflow.net/questions/190802/zeros-of-the-derivative-of-riemanns-xi-function)。

不过，有一点特别引人注目，这可能有助于取得进展：函数 `τ(σ)` ![Image](images/B9780443218576000217/si420.png) 几乎是平坦的，在 `σ[0]` ![Image](images/B9780443218576000217/si104.png) 处只有一个间断点。确实，如果 $\frac{1}{2} \leqslant \sigma < \sigma_0$ ![Image](images/B9780443218576000217/si436.png)，则 `201.26 ≤ τ(σ) ≤ 201.29` ![Image](images/B9780443218576000217/si435.png)；如果 `σ[0] < σ ≤ 1` ![Image](images/B9780443218576000217/si438.png)，则 `199.41 ≤ τ(σ) ≤ 199.42` ![Image](images/B9780443218576000217/si437.png)。这些变化太小了，以至于让人怀疑它们是真实的，还是由数值不精度引起的（这意味着函数 `τ(σ)` ![Image](images/B9780443218576000217/si420.png) 可能是完全平坦的，仅有一个间断点，从而可能使证明 RH 变得更容易）。如果这些变化确实存在，可能会有除 `η(z)` ![Image](images/B9780443218576000217/si29.png) 之外的其他函数具有相同的零点，例如 `η(z)` ![Image](images/B9780443218576000217/si29.png) 的一个缩放版本，其缩放因子没有零点，对于该函数这些变化不存在。这样的函数可能更容易研究。

更一般地，每当 `S[0]` ![Image](images/B9780443218576000217/si413.png) 包含一个值 `t[0]'` ![Image](images/B9780443218576000217/si439.png) 使得 `z = 1 + i t[0]'` ![Image](images/B9780443218576000217/si425.png) 是 `1 - 2^(1-z)` ![Image](images/B9780443218576000217/si440.png) 的零点，从而也是 `η(z)` ![Image](images/B9780443218576000217/si29.png) 的零点时，函数 `μ(σ)` ![Image](images/B9780443218576000217/si418.png) 和 `τ(σ)` ![Image](images/B9780443218576000217/si420.png) 具有相同的行为。因为这些零点以 `2π/log 2` ![Image](images/B9780443218576000217/si441.png) 为增量均匀分布，且由于在 $\sigma = \frac{1}{2}$ ![Image](images/B9780443218576000217/si24.png) 处的零点随着 `t → ∞` ![Image](images/B9780443218576000217/si357.png) 变得越来越接近（见 [\[3](#Chp017_329-360_B9780443218576000217.xhtml#br0015),[17\]](#Chp017_329-360_B9780443218576000217.xhtml#br0085)），所以在 `S[0]` ![Image](images/B9780443218576000217/si413.png) 中要么有一个 `t[0]'` ![Image](images/B9780443218576000217/si439.png)，要么没有。不可能有多于一个。当没有时，情况甚至更简单，相当于设定 `σ[0] = ∞` ![Image](images/B9780443218576000217/si442.png)，或者至少 `σ[0] > 1` ![Image](images/B9780443218576000217/si443.png)。

最后，如果能够证明本练习中讨论的要点，那么当然 RH 就得到了证明。只需考虑所有可能的 `S[0]` ![Image](images/B9780443218576000217/si413.png) 的集合，即可表明如果 $\frac{1}{2} < \sigma < 1$ ![Image](images/B9780443218576000217/si20.png)，无论 `t` 多大，任何地方都不会有零点。
