
最后，我对某种原始的降维技术感兴趣。这不是一种真正的数据缩减技术，但它允许你将参数数量减少 2 倍：例如，通过映射 `z` ↦ `w`![Image](images/B9780443218576000059/si3.png) 从 ℝ²![Image](images/B9780443218576000059/si28.png) 到 ℂ![Image](images/B9780443218576000059/si29.png)，将 `w` 和 `θ` 视为复数而非实数，其中 `w` = `ν(z)`![Image](images/B9780443218576000059/si22.png)。一个好处是可以对 `ν` 使用 `conformal map` [[Wiki](https://en.wikipedia.org/wiki/Conformal_map)]，从而保持角度不变。一个例子是 `log-polar map` [[Wiki](https://en.wikipedia.org/wiki/Log-polar_coordinates)] `z` = exp(`w`)![Image](images/B9780443218576000059/si30.png) 及 `g(w, θ)` = `z^θ` = exp(`θ w`)![Image](images/B9780443218576000059/si31.png)，这对应于使用极坐标系，其中 `θ`、`z`、`w` ∈ ℂ![Image](images/B9780443218576000059/si32.png)：这在处理圆形数据时会让事情变得更简单。下一步是研究四元数以将参数数量减少 4 倍，但存在许多挑战。无论如何，我承诺在介绍性演示中保持简单，因此这里不会讨论复数或四元数映射。这是未来研究的主题。

有趣的是，圆拟合问题已被广泛研究，参见 [[6]](#Chp001_1-34_B9780443218576000059.xhtml#br0030)。本质上，这些方法使用 `φ` 来求解问题，且并非微不足道。基于我方法的解涉及使用 `θ`，并导出一个具有简单解的非常经典的算法。代价是 `θ` 参数不太容易解释：它们是二次型的系数。相反，直接解涉及具有明显含义的 `φ` 参数：圆的半径、圆心，以及（椭圆情况下）旋转角。然而，我的方法使得推广到椭圆甚至更复杂的形状（或超平面）变得容易得多，同时拥有的解甚至比 [[6]](#Chp001_1-34_B9780443218576000059.xhtml#br0030) 中讨论的仅适用于圆的解还要简单。当然，在这种情况下 `φ` 和 `θ` 之间存在一一映射，见[此处](https://math.stackexchange.com/questions/1810677/center-and-axis-of-quadratic-surface)。所以你总能从 `θ` 恢复 `φ`。

## 1.2 方法论、实现细节与注意事项

我建议你先阅读第 [1.1.1](#Chp001_1-34_B9780443218576000059.xhtml#s0015) 节，因为它提供了大量背景信息。本节描述了方法论的细节。为求简单，我不描述最一般的情况，而是描述一个足以涵盖所有实际应用的情况。我首先介绍数据（称为点云）、参数和形状的概念。

`数据` 集记为 `W`，包含 `m` + 1![Image](images/B9780443218576000059/si33.png) 个变量和 `n` 个观测值。因此 `W` 如常是一个 `n` × (`m` + 1)![Image](images/B9780443218576000059/si34.png) 矩阵。第 `k` 行对应第 `k` 个观测值 `W[k]` = (`W[k, 0]`, `W[k, 1]`, …, `W[k, m + 1]`)![Image](images/B9780443218576000059/si35.png)。为兼容传统模型，我用 `W[k, 0]` = `Y[k]`![Image](images/B9780443218576000059/si36.png) 表示因变量或响应变量（如果存在），用 (`X[k, 1]`, …, `X[k, m]`) = (`W[k, 1]`, …, `W[k, m + 1]`)![Image](images/B9780443218576000059/si37.png) 表示自变量或特征。对应响应的列向量记为 `Y`，表示自变量的 `n` × `m`![Image](images/B9780443218576000059/si38.png) 矩阵记为 `X`。整个数据集 `W` 称为点云。

`参数` 是一个多元列向量，记为 `θ` = (`θ[0]`, `θ[1]`, …, `θ[d]`)![Image](images/B9780443218576000059/si39.png)，包含 `d` + 1![Image](images/B9780443218576000059/si40.png) 个分量。通常，`d` = `m`![Image](images/B9780443218576000059/si41.png)，且 `θ` 满足某些约束，由函数 `η` 指定为 `η(θ)` = 0![Image](images/B9780443218576000059/si42.png)。最常见的函数有 `η(θ)` = `θ^T θ` − 1![Image](images/B9780443218576000059/si43.png)、`η(θ)` = `θ[0]` + 1![Image](images/B9780443218576000059/si44.png) 和 `η(θ)` = (`θ[0]` + ⋯ + `θ[d]`) − 1![Image](images/B9780443218576000059/si45.png)。此处 `^(T)` 表示矩阵/向量转置算子。

目的是将一个 `形状` 拟合到点云上。经过适当映射后，最典型的形状是超平面或二次型（椭球体）。前者是后者的特例。该形状属于由多元参数 `θ` 驱动的参数方程族。形状的方程为 `g(w, θ)` = 0![Image](images/B9780443218576000059/si12.png)，其中 `g` 为某函数。典型例子包括 `g(w, θ)` = `wθ`![Image](images/B9780443218576000059/si46.png) 和 `g(w, θ)` = `wθ` − 1![Image](images/B9780443218576000059/si47.png)，其中 `d` = `m`![Image](images/B9780443218576000059/si41.png)。前者通常包含截距：对所有 `k` = 1, …, `n`![Image](images/B9780443218576000059/si49.png) 有 `X[k, 1]` = 1![Image](images/B9780443218576000059/si48.png)。请记住 `w` 和 `θ` 是向量，但 `g(w, θ)`![Image](images/B9780443218576000059/si50.png) 是实数而非向量。因此 `wθ` 表示 `点积` [[Wiki](https://en.wikipedia.org/wiki/Dot_product)]。

### 1.2.1 解、R 平方与向后兼容性

最拟合数据的形状对应 `θ` = `θ^*`![Image](images/B9780443218576000059/si51.png)，通过最小化平方和获得：

```
\theta^{\ast} = \underset{\theta}{\arg\min}\sum\limits_{k = 1}^{n}g^{2}(W_{k},\theta).
```
![Image](images/B9780443218576000059/si52.png)(1.1)

解可能不唯一。唯一性和数值稳定性将在未来的文章中讨论，但基础内容已在本书中涵盖。约束 `η(θ)` = 0![Image](images/B9780443218576000059/si42.png) 保证了解需要求解一个（有时是非线性的）`d` + 2![Image](images/B9780443218576000059/si53.png) 个方程、含 `d` + 2![Image](images/B9780443218576000059/si53.png) 个未知数的方程组。在某些情况下，`d` ≤ `m`![Image](images/B9780443218576000059/si54.png) 以避免 `model identifiability`（模型可识别性）问题 [[Wiki](https://en.wikipedia.org/wiki/Identifiability)]。此外，过大的 `d` 可能导致 `overfitting`（过拟合）[[Wiki](https://en.wikipedia.org/wiki/Overfitting)]。此时需要 `n` > `d`![Image](images/B9780443218576000059/si55.png)，否则除非对 `θ` 增加更多约束，否则解可能不唯一。解 `θ^*`![Image](images/B9780443218576000059/si10.png) 通过求解以下方程组获得

```
\left\{ \begin{aligned} {\sum\limits_{k = 1}^{n}\nabla_{\theta}[ g^{2}(W_{k},\theta)]} & {= \lambda\nabla_{\theta}[\eta(\theta)],} \\ {\eta(\theta)} & {= 0,} \\ \end{aligned} \right.
```
