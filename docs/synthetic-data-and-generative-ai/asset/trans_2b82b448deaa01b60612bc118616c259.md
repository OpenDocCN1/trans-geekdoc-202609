
一个大问题是如何处理不属于任何 `usable node` 的观测值：它们无法被分类。`usable node` 是指拥有足够文章、且众数内平均 `p` 远离所有节点全局平均 `p` 的节点。解决此问题的一种方法是使用两种算法：迄今所述应用于可用或理想节点的算法（称之为算法 A）以及另一种称为算法 B 的算法，后者对所有观测值进行分类。无法用算法 A 分类或评分的观测值，将用算法 B 进行分类/评分。由此产生的混合算法称为隐决策树。

在代码中，`p`（浏览量的对数）用 `pv` 表示。节点数量是找到的键值对总数，包括那些微小不稳定的节点，无论它们被分类为好、坏还是未分类。`p` 高于任意设定的 `pv_threshold_good=7.1`（见源代码）的文章被视为好文章。这对应于流量约为平均值 1.3 倍的文章，因为我使用对数刻度，且平均 `p` 为 6.83。被分类为好的文章平均 `p` 为 8.09，即流量约为平均值的 3.3 倍。

两个重要指标是：

*   **聚合因子**：它是有用节点平均大小的指标，在本例中指分类为好的节点。高于 5 的值非常理想。
*   **错误率**：此处测量的最重要错误率是被错误分类为好的坏文章数量。目标是检测非常好的文章并找出其受欢迎的原因，以便在未来增加好文章的比例。避免坏文章是第二重要的目标，所以我也有兴趣找出导致文章变坏的原因。

还请注意，该方法正确识别了一定比例的好文章，但留下了许多未分类。我在第 [2.3.3](#Chp002_35-47_B9780443218576000060.xhtml#s0060) 节中解释如何改进这一点。最后，如果文章满足第 [2.2.3](#Chp002_35-47_B9780443218576000060.xhtml#s0030) 节中指定的某些标准，则将其标记为好文章。

现在我分享一些由这些隐决策树在本研究调查的数据集上揭示的有趣发现。首先，具有以下标题特征的文章表现良好：包含数字（如“10 great deep learning articles”）、包含当年年份、是疑问句（how to）、是博客文章或属于图书类别。

以下标题关键词是受欢迎程度的良好预测指标：everyone（如“10 regression techniques everyone should know”）、libraries、infographic、explained、algorithms、languages、amazing、must read、R Python、job interview questions、should know（如“10 regression techniques everyone should know”）、NoSQL databases、versus、decision trees、logistic regression、correlations、tutorials、code、free。

### 2.2.4 改进方法论

某些双词关键词应视为单词关键词。例如，“San Francisco”必须被视为单词关键词。这很容易自动检测：当你分析文本数据时，“San”和“Francisco”组合在一起的频率远高于纯随机概率。此外，我查看了文本中两个关键词相邻的节点。如果允许两个关键词不相邻，键值对（节点）的数量会显著增加，但预测能力不会获得太多额外提升，且存在过拟合风险。

另一个改进是倾向于包含分布在数年内的文章的节点，而不是集中在几周或几个月内的节点。后一类可能曾一度流行，但随后逐渐消退。最后，你不能只关注具有巨大潜力的文章。拥有许多不太受欢迎的文章也很重要：它们构成了长尾。没有这些不太受欢迎的文章，从长远来看，你将面临内容过度集中和读者流失的问题。

### 2.3.1 偏差校正

在在线排名中，最受欢迎的书籍、作者、文章、餐厅、产品等，通常是那些存在时间长的。我通过创建调整后的分数来解决这个问题。这使您能够在新旧项目之间进行公平比较。

对于顶级时间不敏感文章，浏览量在前三天达到峰值，但受欢迎程度在许多年里保持高位。简而言之，浏览量随时间的衰减非常低。最后，最热门的主题（关键词）会随时间变化；这种分析有助于发现趋势。使用两个不同的数据源进行浏览量测量也是个好主意，看看它们有何不同，理解原因，并检查差异是否随时间恶化。

此处评分的文章跨越三年，涵盖超过 ![Image](images/B9780443218576000060/fx005.jpg) 篇内容，三个网站总计 600 万浏览量。汇总数据在 GitHub 上，[这里](https://github.com/VincentGranville/Machine-Learning/blob/main/Source%20Code/ArticlePopularity.txt)。其中列出了根据时间调整分数排名的前 46 篇文章。每篇文章后括号中的数字是未调整（旧）分数。时间调整分数与旧分数之间的差异非常显著。

#### 2.3.1.1 时间调整分数

您测量特定文章的浏览量，时间段为 `t[0], t[1]`![Image](images/B9780443218576000060/si3.png)。典型模型使用速率为 `λ` 的**指数衰减**。调整因子为

```latex
q = \frac{1}{\lambda} \cdot \left\lbrack \exp( - \lambda t_{0}) - \exp( - \lambda t_{1}) \right\rbrack > 0.
```

![Image](images/B9780443218576000060/si4.png)

现在定义调整分数为 `p/q`![Image](images/B9780443218576000060/si5.png)，其中 `p` 是 `t[0], t[1]`![Image](images/B9780443218576000060/si3.png) 内观测到的浏览量。如果 `λ = 0`![Image](images/B9780443218576000060/si6.png)（无衰减），则 `q = t[1] - t[0]`![Image](images/B9780443218576000060/si7.png)。
