
# 训练集生成

训练集由 `n` 个观测值组成，生成过程如下。首先在椭圆（或您感兴趣的弧段）上采样 `n` 个点。然后通过添加噪声扰动这些点。您有两个选项：`noise_CDF='Uniform'` 和 `noise_CDF='Normal'`。代码中参数 `noise` 指定噪声量。对于区间 `[-a, a] × [-a, a]` 上的均匀分布，`noise` 代表 `a`。对于协方差矩阵为 `σ²I`（其中 `I` 为单位矩阵）的二元正态分布，它代表 `σ²`。在椭圆上采样点有多种方法。此处提供三种选项，由参数 `sampling` 设置。它们在第 1.3.2.3 节“椭圆弧上的采样点”段中描述。选项 `'Enhanced'` 是唯一执行随机采样（在椭圆上随机选取点）的方法，并用于图 1.2。

在图 1.2 中，训练集大小 `n = 30`，而在图 1.1 中，`n = 250`。在代码中，`n` 由变量 `npts` 表示。训练集以红色显示（印刷版为浅灰色），拟合椭圆以蓝色显示（印刷版为深灰色），如果图像中存在真实椭圆（如图 1.2），则以黑色显示。后者呈现为多边形而非椭圆，因为真实椭圆上的采样点由线段连接，且 `n` 较小。通常，真实椭圆和拟合椭圆非常接近，尽管存在系统性偏差，除非椭圆离心率很高，否则肉眼难以察觉。稍后将详细说明。

在某些情况下，解可能不唯一，或者可能是双曲线或抛物线而非椭圆。例如，如果椭圆退化为圆，旋转角的任何值实际上都是正确的，尽管估计曲线仍然唯一且被正确识别。此外，如果真实椭圆具有高离心率，生成的白噪声（无偏噪声）会迫使训练集点比预期更频繁地落在椭圆内部，而非边界外部。这是因为在椭圆内部，假设长轴为水平方向，来自北侧的噪声与来自南侧的噪声强烈重叠。结果导致 `a[p]` 和 `b[p]` 的估计值产生偏差，小于实际值。最终，拟合曲线的离心率高于真实曲线。离心率越高，这种效应越明显。如果噪声方差足够小，几乎没有偏差。

## 1.3.2.2 拟合椭圆的置信区域：陨石形状的应用

通过在 Python 代码中设置 `mode='ConfidenceRegion'` 来计算置信区域。此时程序会自动创建若干训练集（数量由参数 `nframes` 决定），针对由参数 `params` 指定的同一椭圆：中心、半轴长度和旋转角。然后估计椭圆参数，从而确定由相关参数唯一确定的真实椭圆。图 1.2 展示了表 1.1 所述示例的置信区域。

实际上我决定显示多边形而非拟合椭圆，通过选择选项 `sampling='Enhanced'`。该多边形由拟合椭圆上 `n = 30` 个训练集点的预测位置组成。这些位置的获取方式与线性回归问题中预测值在拟合线上显示的方式完全相同。毕竟，本节介绍的椭圆拟合是一般云回归技术的一个特例。然后我用线段连接这些点，每个训练集生成一个多边形。这些多边形的叠加即为置信区域。
