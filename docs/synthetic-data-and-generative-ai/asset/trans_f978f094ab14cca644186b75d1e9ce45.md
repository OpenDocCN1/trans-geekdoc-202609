
**步骤 2：** 对 `2*n + 1` 个点 `X[k]` 进行排序，其中 `-n ≤ k ≤ n`。

- 记排序后的第 `k` 个点为 `X[(k)]`。

**步骤 3：** 选择 `m` 个连续的有序点，记为 `X[(1)], …, X[(m)]`，其中 `m` 远小于 `n`。

- 获取它们的原始索引：`σ(k) = L(X[(k)])`，`k = 1, …, m`。
- 设 `τ(k) = L(X[(k + 1)])`，`k = 1, …, m`（因此 `X[τ(k)]` 是 `X[σ(k)]` 右侧最近的点）。

现在 `σ` 是 {1, …, `m`} 上的一个**随机排列** [[维基百科](https://en.wikipedia.org/wiki/Random_permutation)]。为了生成 [图 16.9](#Chp016_293-327_B9780443218576000205.xhtml#f0060) 中的图表，我使用了 `m = 10³`，`n = 3 × 10⁴`，以及一个参数为 `λ = 1`、`s = 3`、且 `F` 服从逻辑分布的泊松-二项过程。由于该理论旨在生成无限排列而非有限排列，因此可能会出现**边界效应**。为将其最小化，需同时取较大的 `m` 和 `n`。如果存在边界效应（例如当 `F` 使用厚尾分布如柯西分布时，或使用较大的 `s` 时），当 `k` 接近 1 或接近 `m` 时，`σ(k)` 上的表现最为明显。

![图 16.9 局部随机排列 σ；τ(k) 是 Xk 右侧最近邻的索引。](images/B9780443218576000205/gr015.jpg)

图 16.9 局部随机排列 `σ`；`τ(k)` 是 `X[k]` 右侧最近邻的索引。

这些排列可用于模拟长事件序列中的局部重排。影响主要是局部的，但当 `s` 较大或 `F` 具有厚尾时，平均而言影响倾向于扩散到更长的距离。例如，在 [图 16.9](#Chp016_293-327_B9780443218576000205.xhtml#f0060) 中，绝对值最大的偏移是 `σ(k) - k = 35`，发生在 `k = 108` 处（见左图的峰值）。然而，如果 `m` 足够大，任意高度的峰值（或深谷）都会出现，除非你对 `F` 使用均匀分布，或任何具有有限支撑域的分布。

[图 16.9](#Chp016_293-327_B9780443218576000205.xhtml#f0060) 右图显示了索引空间 `ℤ × ℤ` 中差异 `σ(k) - k` 和 `τ(k) - k` 的联合经验分布（基于数据而非理论）。当然，由于索引 `τ(k)` 指向 `X[σ(k)]` 右侧的最近邻，即 `X[τ(k)]`，我们有 `τ(k) ≥ 1 + σ(k)`，这解释了为什么主对角线是空白的。除此之外，该图显示了独立性、对称性和**各向异性**（散点中无方向性趋势）。这意味着：

- 给定点 `X[k]`，其右侧最近邻的索引 `τ(k)` 根据某种径向分布随机分布在 `k` 周围；
- 给定点 `X[k]`，一旦点排序完成，其顺序 `σ(k)` 根据相同的径向分布随机分布在 `k` 周围；
- 两者之间相互独立。

用于比较或描述这些排列的两个指标是平均和最大**索引差异**，分别测量为 `1 ≤ k ≤ m` 时 `|σ(k) - k|` 的平均值和最大值。随着 `s` 增加，该值变大。另一个感兴趣的指标与排列的**熵**有关 [[维基百科](https://www.aptech.com/blog/permutation-entropy/)] [[43]](#Chp016_293-327_B9780443218576000205.xhtml#br0215)，即整数 `k` 与 `σ(k) - k` 之间的相关性，在 `k = 1, …, m` 上计算得出。虽然 [图 16.9](#Chp016_293-327_B9780443218576000205.xhtml#f0060) 中的示例表现出基本为零的相关性，但此处未报告的其他一些情况表现出强相关性。另见 [[2]](#Chp016_293-327_B9780443218576000205.xhtml#br0010)。关于排列的基础介绍，请参见 [[7]](#Chp016_293-327_B9780443218576000205.xhtml#br0035)。

### 16.4.4 恢复 `F` 分布

为简化起见，假设我们处理的是一维泊松-二项过程。要恢复附加到每个点 `X[k]` 上的公共分布 `F` 是困难的，甚至是不可能的。但请参阅第 [16.4.4.2 节](#Chp016_293-327_B9780443218576000205.xhtml#s0165)。在许多情况下，两个不同的 `F` 会导致本质上相同的模型，从而引起**可识别性**问题。如果 `s` 非常小，小到足以使 `|X_k - k/λ| < 1/(2λ)` 对大多数 `k ∈ ℤ` 成立，则情况会容易得多。此时附加到点 `X` 上的索引（通常未知）等于

```
L(X) = arg min_{k∈ℤ} | X - k/λ |
```

即 `X = X[k]` 且 `k = L(X)`。关于 `arg min` 的定义见[此处](https://en.wikipedia.org/wiki/Arg_max)。这假设 `λ` 和 `s` 是已知或已估计的。在这种特定情况下，在许多点 `X` 上计算的 `s*X - s*L(X)` 的经验分布，随着观测点数趋于无穷大，收敛于 `F`。

一个更实际的情况是，给定几个 `F` 的候选分布，必须决定哪个 `F` 能为数据提供最佳拟合。在这种情况下，可以通过模拟计算理论期望 `η(r, λ, s, F) = E[T^(r)(λ, s)]` 作为 `r > 0` 的函数，针对各种 `F`，并找出哪个 `F` 能为估计的 `E[T^(r)(λ, s)]` 提供最佳拟合，后者记为 `η[0](r, λ, s, F)` 并在数据上计算得出（计算在数据上时，期望被平均值替代）。所谓最佳拟合，是指找到使以下值最小化的 `F`（例如）

```
γ(F) = ∫_0^2 |η(r, λ, s, F) - η[0](r, λ, s, F)| dr
```
