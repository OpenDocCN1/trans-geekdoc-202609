
## 性能指标

*   • R平方 `r`，其中 `0 ≤ r ≤ 1`![Image](images/B9780443218576000114/si78.png)，是 `Y` 和 `P` 之间相关系数的平方。它也等于 `[σ[Y]² − (Y − P)^(T)(Y − P)] / σ[Y]²`![Image](images/B9780443218576000114/si79.png)。

*   • 均方根误差或 RMSE [[维基百科](https://en.wikipedia.org/wiki/Root-mean-square_deviation)]，定义为 `e = sqrt((Y - P)^T (Y - P)) / n`![Image](images/B9780443218576000114/si80.png)，其中 `n` 是观测值的数量。与均方误差 (MSE) 相比，它是衡量实际误差的更好指标。特别地，如果 `Y` 以（比如说）英里为单位，则 RMSE 以英里为单位，而 MSE 以平方英里为单位。同样，如果 `Y` 以年为单位，RMSE 以年为单位，而 MSE 以平方年为单位——这是一个无意义的指标。

*   • 得分 `s`，其中 `0 ≤ s ≤ 1`![Image](images/B9780443218576000114/si81.png)，定义为 `s = 1 − e(P) / e(P[0])`![Image](images/B9780443218576000114/si82.png)。这里，`P[0]`![Image](images/B9780443218576000114/si83.png) 是基础模型，对应 `β = 0`![Image](images/B9780443218576000114/si53.png)（因此，调整后的预测值为常数，等于在训练集上计算出的 `Y` 的平均值）。特别地，`s` 使用 RMSE 比率来衡量相对于基础模型的改进，而 `r` 则使用 MSE 比率来做同样的事情。在我看来，`s` 比 `r` 更直观、更现实。它通过公式 `r = 2*s − s²`![Image](images/B9780443218576000114/si84.png) 与 `r` 相关，或者等价地，`s = 1 - sqrt(1 - r)`![Image](images/B9780443218576000114/si85.png)。我们总是有 `r ≥ s`![Image](images/B9780443218576000114/si86.png)，所以 `r` 是拟合优度的一个夸大度量。

由于模型是在测试数据集上训练的，但模型性能是在验证集上衡量的，因此上述性能指标是混合的。特别地，因此，关系 `r = 2*s − s²`![Image](images/B9780443218576000114/si84.png) 几乎成立，但不完全成立。此外，在极少数情况下（数据噪声很大时），`r` 可能略微为负。性能结果显示在“Results”选项卡中，单元格 `J13:R19`。我还包含了简单模型的性能指标，该模型使用第 [7.2.3](#Chp007_113-129_B9780443218576000114.xhtml#s0030) 节中定义的回归系数向量 `β = β[0]`![Image](images/B9780443218576000114/si87.png)。在电子表格中，该模型被称为“预测 `P[b]`![Image](images/B9780443218576000114/si88.png)”。

此外，电子表格允许您选择在不动点迭代中将哪些特征包含在模型中或不包含。特征选择标志存储在“Results”选项卡中的单元格 `B4:B9` 内。默认值为 `1`，对应包含。这对于测试使用所有特征与使用特征子集相比能获得多少模型改进特别有用。在真实数据中，一些特征通常缺失，因为模型开发者不知道它们的存在，并且它们未在数据集中捕获：换句话说，它们是未观测到的。特征选择标志允许您比较在观测数据上的性能，与包含所有相关特征的理想数据集上获得的性能。

最后，使用合成数据提供了巨大的好处：您可以一次性在数百万个截然不同的数据集上测试和基准测试算法。这假设合成数据是正确生成的。设计此类数据集既是一门艺术，也是一门科学。它通常涉及相当数量的数学知识，有时相当高深。我希望本文能帮助读者构建高质量、丰富的合成数据，涵盖广泛的潜在现实生活场景。其他合成数据集见第 [5](#Chp005_83-102_B9780443218576000096.xhtml) 章（包含合成聚类）和第 [6](#Chp006_103-111_B9780443218576000102.xhtml) 章“计算机视觉：通过可解释 AI 进行形状分类”（包含合成形状）。
