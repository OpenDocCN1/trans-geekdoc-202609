
The point counts attached to a realization `ω` of the point process, is denoted as `N[ω]`![Image](images/B9780443218576000205/si55.png). The aggregated point count over the `m` realizations is denoted as `N`, and the set of `m` realizations is denoted as `Ω`. Now, for `i` = 1, 2, 3![Image](images/B9780443218576000205/si56.png) and `j[1]`, `j[2]`, `j[3]` ∈ ℕ![Image](images/B9780443218576000205/si57.png), I can define the following quantities:

```
p_i(j) = (1/m) ∑_{ω ∈ Ω} χ[N_ω(B_i) = j],
p(j_1, j_2, j_3) = (1/m) ∑_{ω ∈ Ω} ∏_{i=1}^{3} χ[N_ω(B_i) = j_i]
```
![Image](images/B9780443218576000205/si58.png) (16.7)

```
p'(j_1, j_2, j_3) = (1/m^3) ∏_{i=1}^{3} ∑_{ω ∈ Ω} χ[N_ω(B_i) = j_i]
```
![Image](images/B9780443218576000205/si59.png) (16.8)

where `χ` is the indicator function [[Wiki](https://en.wikipedia.org/wiki/Indicator_function)]. For instance, `p[1](3) = 0.043`![Image](images/B9780443218576000205/si60.png) means that in 43 realizations out of ![Image](images/B9780443218576000205/fx001.jpg), the domain `B[1]`![Image](images/B9780443218576000205/si61.png) contained exactly 3 points. Also, `p'(j[1], j[2], j[3]) = p[1](j[1]) * p[2](j[2]) * p[3](j[3])`![Image](images/B9780443218576000205/si62.png). The three point counts `N(B[1])`![Image](images/B9780443218576000205/si63.png), `N(B[2])`![Image](images/B9780443218576000205/si64.png), `N(B[3])`![Image](images/B9780443218576000205/si65.png) are independently distributed if and only if formulas [(16.7)](#Chp016_293-327_B9780443218576000205.xhtml#deq9) and [(16.8)](#Chp016_293-327_B9780443218576000205.xhtml#deq10) represent the same quantity when `m` = ∞![Image](images/B9780443218576000205/si66.png). In other words, the three point counts are independently distributed if `p` → `p'`![Image](images/B9780443218576000205/si67.png) pointwise [[Wiki](https://en.wikipedia.org/wiki/Pointwise_convergence)], as `m` → ∞![Image](images/B9780443218576000205/si68.png).

To avoid future confusion, `p` and `p'`![Image](images/B9780443218576000205/si69.png) are denoted as `p[A]`![Image](images/B9780443218576000205/si70.png) and `p[A]'`![Image](images/B9780443218576000205/si71.png) to emphasize the fact that they are attached to the process `M[A]`![Image](images/B9780443218576000205/si48.png). To test for independence, I simulated `m` realizations of a sister point process `M[B]`![Image](images/B9780443218576000205/si72.png): one with the same marginal distributions for the three point counts, using the estimates `p[i](j)`![Image](images/B9780443218576000205/si73.png) obtained from `M[A]`![Image](images/B9780443218576000205/si48.png), but this time with guaranteed independence of the point counts, by design. Likewise, I define the functions `p[B]`![Image](images/B9780443218576000205/si74.png) and `p[B]'`![Image](images/B9780443218576000205/si75.png). Let `ρ[A]`![Image](images/B9780443218576000205/si76.png) be the correlation between `p[A]`![Image](images/B9780443218576000205/si70.png) and `p[A]'`![Image](images/B9780443218576000205/si71.png), computed across all triplets satisfying

```
min{p[A](j[1], j[2], j[3]), p[A]'(j[1], j[2], j[3])} > ϵ
```
![Image](images/B9780443218576000205/si77.png)

I chose `ϵ` = 0![Image](images/B9780443218576000205/si78.png). In my example, there were fewer than 7 × 7 × 7 = 343![Image](images/B9780443218576000205/si79.png) such triplets. Finally, the statistic of the test is `ρ[A]²`![Image](images/B9780443218576000205/si80.png).

### 16.1.3.1 Results and interpretation

In the spreadsheet [PB_independence.xlsx](https://github.com/VincentGranville/Point-Processes/tree/main/Spreadsheets), the tab Dataset_A corresponds to `M[A]`![Image](images/B9780443218576000205/si48.png), and Dataset_B corresponds to `M[B]`![Image](images/B9780443218576000205/si72.png). The same computations are done in tab Dataset_C for another point process `M[C]`![Image](images/B9780443218576000205/si81.png), identical to `M[A]`![Image](images/B9780443218576000205/si48.png) except that this time `s` = 4![Image](images/B9780443218576000205/si82.png). With such a “large” `s`, `M[C]`![Image](images/B9780443218576000205/si81.png) is not that different from a stationary Poisson point process: in particular, the point counts are almost independent (no statistical test could detect that they are not, unless using extremely large samples).

The main findings are displayed in [Fig. 16.2](#Chp016_293-327_B9780443218576000205.xhtml#f0015). Blue represents the `M[A]`![Image](images/B9780443218576000205/si48.png) process, gray represents `M[B]`![Image](images/B9780443218576000205/si72.png), and red represents `M[C]`![Image](images/B9780443218576000205/si81.png). Each blue dot corresponds to a vector (`p[A]`, `p[A]'`)![Image](images/B9780443218576000205/si83.png) attached to a particular (`j[1]`, `j[2]`, `j[3]`)![Image](images/B9780443218576000205/si84.png). In case of perfect independence, all the dots should be on the main diagonal. Blue dots are too far away from the main diagonal, and thus the point counts in `M[A]`![Image](images/B9780443218576000205/si48.png) are not independent. To the contrary, `M[B]`![Image](images/B9780443218576000205/si72.png) (supposed to exhibit independence by construction) and `M[C]`![Image](images/B9780443218576000205/si81.png) (known from theory to exhibit near-independence) are close enough to each other and to the main diagonal. If you repeat the experiment with `M[B]`![Image](images/B9780443218576000205/si72.png) a hundred times, you will get a hundred gray regression lines, generating a confidence curve for the test. Note that the `R²`![Image](images/B9780443218576000205/si85.png) displayed for the three regression lines in [Fig. 16.2](#Chp016_293-327_B9780443218576000205.xhtml#f0015), are identical to `ρ[A]²`![Image](images/B9780443218576000205/si80.png), `ρ[B]²`![Image](images/B9780443218576000205/si86.png), `ρ[C]²`![Image](images/B9780443218576000205/si87.png), confirming the somewhat poor performance of `M[A]`![Image](images/B9780443218576000205/si48.png). The slope of the regression line is also an indicator of lack of independence, if it is not close enough to one. Again, `M[B]`![Image](images/B9780443218576000205/si72.png) is the loser here, when measured against the slope. The intercept of the regression line (when different enough from zero) further confirms this.
