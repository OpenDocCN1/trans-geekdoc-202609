
请记住，`U[k]`![图片](images/B9780443218576000059/si105.png) 是一个行向量，而 `θ` 是一个列向量；点积 `U[k]θ`![图片](images/B9780443218576000059/si99.png) 是一个实数。此外，`V[k]`![图片](images/B9780443218576000059/si106.png) 是与第 `k` 个观测值相关联的二元响应，而 `U[k]`![图片](images/B9780443218576000059/si105.png) 是对应的 `m` 维特征向量，两者均位于原始的 (`v`, `u`)![图片](images/B9780443218576000059/si101.png) 空间中。经验分布 `F[θ]`![图片](images/B9780443218576000059/si103.png) 计算如下：`F[θ](t)`![图片](images/B9780443218576000059/si107.png) 是在 `U[1]`，…，`U[n]`![图片](images/B9780443218576000059/si108.png) 中满足 `U[k]θ ≤ t`![图片](images/B9780443218576000059/si109.png) 的观测特征向量的比例。这种方法可称为 `CDF regression`。您可以使用此处介绍的方法来求解，但这将非常消耗计算资源，因为 `F[θ]`![图片](images/B9780443218576000059/si103.png) 以一种不明显的方式依赖于 `θ`。在这种情况下，`V[k]`![图片](images/B9780443218576000059/si106.png) 的预测值为 `F[θ^*](U[k]θ^*)`![图片](images/B9780443218576000059/si110.png)。

### 1.3.2 椭球与超平面拟合

这是一个基础示例，超平面是椭球的一种特殊情况。我将通过一个基于合成数据的低维示例来说明该方法。思路是用二次型来表示形状。在二维情况下，方程为

`θ[0]x² + θ[1]xy + θ[2]y² + θ[3]x + θ[4]y + θ[5] = 0`。

![图片](images/B9780443218576000059/si111.png)

诀窍是引入人造变量 `w[0] = x²`![图片](images/B9780443218576000059/si112.png)、`w[1] = xy`![图片](images/B9780443218576000059/si113.png)、`w[2] = y²`![图片](images/B9780443218576000059/si114.png)、`w[3] = x`![图片](images/B9780443218576000059/si115.png)、`w[4] = y`![图片](images/B9780443218576000059/si116.png)、`w[5] = 1`![图片](images/B9780443218576000059/si117.png)，以便我们可以使用 `g(w, θ) = wθ`![图片](images/B9780443218576000059/si46.png) 这一通用框架。同样，`wθ` 是点积。为避免平凡解 `θ^* = 0`![图片](images/B9780443218576000059/si118.png)，我们添加约束 `θ^T θ = 1`![图片](images/B9780443218576000059/si59.png)，即 `η(θ) = θ^T θ - 1`![图片](images/B9780443218576000059/si43.png)。此时，`θ^*`![图片](images/B9780443218576000059/si10.png) 是以下方程组的解

$\\left\\{ \\begin{aligned} {(W^{T}W - \\lambda I)\\theta} & {= 0,} \\\\ {\\theta^{T}\\theta} & {= 1.} \\\\ \\end{aligned} \\right.$

![图片](images/B9780443218576000059/si119.png)(1.6)

上述解在任意维度下均正确。它是 [(1.2)](#Chp001_1-34_B9780443218576000059.xhtml#deq2) 的直接应用。这里 `W` 是包含 `n` 个观测值的 `n × 6`![图片](images/B9780443218576000059/si120.png) 矩阵。因此，`W[k0] = X[k]²`![图片](images/B9780443218576000059/si121.png)、`W[k1] = X[k]Y[k]`![图片](images/B9780443218576000059/si122.png)、`W[k2] = Y[k]²`![图片](images/B9780443218576000059/si123.png)、`W[k3] = X[k]`![图片](images/B9780443218576000059/si124.png)、`W[k4] = Y[k]`![图片](images/B9780443218576000059/si125.png)、`W[k5] = 1`![图片](images/B9780443218576000059/si126.png)。一个略有不同的版本（具有略微不同的 `η(θ)`![图片](images/B9780443218576000059/si87.png)）的 Python 代码和更多细节，可在[此处](https://scipython.com/blog/direct-linear-least-squares-fitting-of-an-ellipse/)找到。我在自己的代码中使用了它，可在我的 GitHub 仓库[此处](https://github.com/VincentGranville/Machine-Learning/blob/main/Source%20Code/fittingEllipse.py)获取，文件名为 `fittingEllipse.py`。它基于 Halir 关于椭圆拟合的文章 [\[2\]](#Chp001_1-34_B9780443218576000059.xhtml#br0010)。

Python 代码会检查拟合形状是否真的是椭圆。然而，依照我的方法论精神，无论它是椭圆、抛物线、双曲线，甚至是一条直线，都无关紧要。解的唯一性并不重要：事实上，如果两个截然不同的解（例如椭圆和抛物线）产生相同的最小均方误差，从而都是最优的，这反映了数据集的某些特性，这是值得了解的有趣信息。不过，使用公式 [(1.4)](#Chp001_1-34_B9780443218576000059.xhtml#deq4) 计算 `R²(θ^*)`![图片](images/B9780443218576000059/si66.png) 会很有意思，其中 `θ^*`![图片](images/B9780443218576000059/si67.png) 对应于一个圆。这将表明完整模型（椭圆）相对于圆子模型是否提供了显著改进。

椭球拟合与多元多项式回归 [\[7\]](#Chp001_1-34_B9780443218576000059.xhtml#br0035) 有一些相似之处。区别在于：

*   • 椭圆拟合是一个“完整”模型；而在多项式回归 `y = θ[1] + θ[2]x + θ[3]x²`![图片](images/B9780443218576000059/si127.png) 中，项 `y²`![图片](images/B9780443218576000059/si128.png) 和 `xy` 始终缺失。
*   • 多项式回归拟合的是无界曲线，如 `y = x²`![图片](images/B9780443218576000059/si129.png)，导致拟合效果差；相反，在椭圆拟合中（如果解真的是椭圆），解是有界的。
*   • 要使多项式回归拥有与椭圆拟合同样多的项，唯一的办法是增加多项式的次数，这会进一步增加解的不稳定性。

最后，Umbach [\[6\]](#Chp001_1-34_B9780443218576000059.xhtml#br0030) 提出了一种不同的椭圆拟合方法。该方法复杂得多，事实上，他们只研究到了圆。简而言之，他们的方法通过最小二乘法直接估计中心、半轴长度和旋转角度，而不是估计表示椭圆的二次型中的系数。关于参数曲线的更多内容，请参阅第 [6](#Chp006_103-111_B9780443218576000102.xhtml) 章“形状识别”。

#### 1.3.2.1 曲线拟合：一个视频中的 250 个示例

通过在 Python 代码中设置 `mode='CurveFitting'` 来执行椭圆拟合。程序会根据参数（中心、半轴长度和旋转角度）自动创建多个椭圆，然后为每个椭圆生成不同的训练集，并将拟合过程的结果输出为图像。然后将这些图像捆绑在一起生成视频和动画 GIF。每张图像都展示了一个特定的椭圆和训练集，以及基于该训练集拟合出的椭圆。椭圆参数由代码中的变量 `params` 设置：它是一个包含五个分量的数组。椭圆的数量由参数 `nframes` 设置，该参数也决定了输出视频的帧数。

实际上，程序的功能不止于此：它还处理椭圆弧。在这种情况下，使用训练集的质心来估计椭圆中心是行不通的。因此，即使训练集由随机分布在该椭圆一部分周围的点组成，程序也能恢复出原始的未知椭圆。相关弧由极坐标下的下界和上界角度决定，在代码中分别表示为 `tmin` 和 `tmax`，其中 `tmin=0` 和 `tmax=2π` 对应完整的椭圆。
