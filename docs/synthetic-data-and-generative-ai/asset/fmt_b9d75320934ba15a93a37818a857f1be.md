
For other Dirichlet-`L` functions with known `abscissa of convergence` [[Wiki](https://en.wikipedia.org/wiki/Dirichlet_series#Abscissa_of_convergence)] `σ < 1`![Image](images/B9780443218576000217/si9.png), see the article “Modular Elliptic Curves”, pages 14–18, in [[16]](#Chp017_329-360_B9780443218576000217.xhtml#br0080). Interestingly, (conditional) convergence is proved also for `σ > 5/6`![Image](images/B9780443218576000217/si173.png), by looking at the series rather than the product. Primes of the form `x³ + y²`![Image](images/B9780443218576000217/si161.png) are listed in the [Encyclopedia of Integer Sequences](https://oeis.org/), as entry [A066649](https://oeis.org/A066649). Related entries include [A022549](https://oeis.org/A022549), [A055393](https://oeis.org/A055393), [A173795](https://oeis.org/A173795), and [A123364](https://oeis.org/A123364).

`Note.` The theory of elliptic curves is now a hot topic in number theory. They were used in the proof of `Fermat's last theorem` [[Wiki](https://en.wikipedia.org/wiki/Fermat%27s_Last_Theorem)]. The proof was published in 1995, more than 350 years after it was first conjectured. The theorem states that `x^(n) + y^(n) = z^(n)`![Image](images/B9780443218576000217/si174.png) has no nontrivial solution in integer numbers if `n > 2`![Image](images/B9780443218576000217/si175.png).

### 17.3.2.3 Analytic continuation, convergence, and functional equation

If the `Euler product` converges only for `σ > 1`![Image](images/B9780443218576000217/si19.png), you need to find an extension to `σ > 0.5`![Image](images/B9780443218576000217/si115.png) to assess whether `L[P](z, χ)`![Image](images/B9780443218576000217/si107.png) has roots when `0.5 < σ < 1`![Image](images/B9780443218576000217/si90.png). One way to do it is to get an `analytic continuation` [[Wiki](https://en.wikipedia.org/wiki/Analytic_continuation)], at least down to `σ = 0.5`![Image](images/B9780443218576000217/si53.png). If `χ(·)`![Image](images/B9780443218576000217/si4.png) is constant and equal to 1, try using the alternating Dirichlet series `η[P](z, χ)`![Image](images/B9780443218576000217/si88.png) defined by formula [(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5), rather than the Euler product, to compute `L[P](z, χ)`![Image](images/B9780443218576000217/si107.png). It may converge over a larger domain. If the analytic continuation satisfies a standard `Dirichlet functional equation` [[Wiki](https://en.wikipedia.org/wiki/Functional_equation_\(L-function\))] and `z[0] = σ + i t`![Image](images/B9780443218576000217/si176.png) is a root with `0 < σ < 1`![Image](images/B9780443218576000217/si177.png), then `1 - z[0]`![Image](images/B9780443218576000217/si178.png) is also a root. Thus in that case, if there is no root with `0.5 < σ < 1`![Image](images/B9780443218576000217/si90.png), then any possible root with `0 < σ < 1`![Image](images/B9780443218576000217/si177.png) must have `σ = 0.5`![Image](images/B9780443218576000217/si53.png). The functional equation, when it exists, can be derived using `exponential sums` such as $\sum_{k = 1}^{\infty}\exp( - \pi k^{2}y)$![Image](images/B9780443218576000217/si179.png). See Section 4.1 (page 71) in [[4]](#Chp017_329-360_B9780443218576000217.xhtml#br0020).

If for some `σ[0]`![Image](images/B9780443218576000217/si104.png) the Dirichlet series converges, then it converges for all `z` with `ℜ(z) = σ > σ[0]`![Image](images/B9780443218576000217/si180.png). The `abscissa of conditional convergence` for the `η[P]`![Image](images/B9780443218576000217/si181.png) series defined in formula [(17.5)](#Chp017_329-360_B9780443218576000217.xhtml#deq6) is denoted as `σ[c]`![Image](images/B9780443218576000217/si182.png). It is the minimum value satisfying

```
\sum\limits_{k = 1}^{\infty}{( - 1)}^{k + 1}\chi(k)k^{- \sigma_{c}} < \infty.
```

![Image](images/B9780443218576000217/si183.png)(17.11)

The `abscissa of absolute convergence`, denoted as `σ[a]`![Image](images/B9780443218576000217/si184.png), is the minimum value satisfying

```
\sum\limits_{k = 1}^{\infty}|\chi(k)|k^{- \sigma_{a}} < \infty.
```

![Image](images/B9780443218576000217/si185.png)

Note that `χ(k) ∈ {-1, 0, +1}`![Image](images/B9780443218576000217/si186.png). It is equal to 0 only if `k` cannot be expressed as a product of elements of `P`. This happens when `P` is not the full set of primes. Similar arguments can be used to obtain the abscissa of convergence for the `L[P]`![Image](images/B9780443218576000217/si187.png) series, or to study the convergence of the product. For instance, for the product in formula [(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5), conditional convergence is equivalent to the convergence of the series `∑[p ∈ P] χ(p) p^(-σ)`![Image](images/B9780443218576000217/si188.png). In particular, for `χ = χ[4]`![Image](images/B9780443218576000217/si16.png), the `Dirichlet character modulo 4` introduced at the beginning of Section [17.2.2](#Chp017_329-360_B9780443218576000217.xhtml#s0045), the series for `L[P](z, χ)`![Image](images/B9780443218576000217/si107.png) has `σ[c] = 0`![Image](images/B9780443218576000217/si189.png) because `χ[4]`![Image](images/B9780443218576000217/si1.png) is periodic, and thus the series in formula [(17.11)](#Chp017_329-360_B9780443218576000217.xhtml#deq14) is alternating.

### 17.3.2.4 Hybrid Dirichlet–Taylor series

An interesting generalization of the `Euler product`, with `χ(p) = x^(ν(p))`![Image](images/B9780443218576000217/si190.png), is as follows:

```
L_{P}(z,x,\nu) = \prod\limits_{p \in P}\frac{1}{1 - x^{\nu(p)}p^{- z}} = \sum\limits_{k = 1}^{\infty}\varphi(k)x^{\Omega_{\nu}(k)}k^{- z},
```

![Image](images/B9780443218576000217/si191.png)

where `ν(p)`![Image](images/B9780443218576000217/si192.png) is defined on the primes `p ∈ P`![Image](images/B9780443218576000217/si165.png). If the unique factorization of `k`, using primes in `P`, is `k = p[1]^(a[1]) p[2]^(a[2]) p[3]^(a[3]) ...`![Image](images/B9780443218576000217/si193.png), then `Ω[ν](k) = a[1] ν(p[1]) + a[2] ν(p[2]) + ...`![Image](images/B9780443218576000217/si194.png), where the latter sum is actually finite. Here the `a[i]`![Image](images/B9780443218576000217/si36.png)'s are integers ⩾0. If `k` cannot be factored in `P`, for instance, if `P` does not contain all the prime integers, then `φ(k) = Ω[ν](k) = 0`![Image](images/B9780443218576000217/si195.png) otherwise `φ(k) = 1`![Image](images/B9780443218576000217/si196.png). Note that `Ω[ν](·)`![Image](images/B9780443218576000217/si197.png) is a function defined on `Q = Q[P]`![Image](images/B9780443218576000217/si198.png), the multiplicative group generated by `P`, containing all product combinations of elements of `P` (including 1). In fact, `Ω[ν](·)`![Image](images/B9780443218576000217/si197.png) generalizes the `Omega function` [[Wiki](https://en.wikipedia.org/wiki/Prime_omega_function)]. If the elements of `Q[P]`![Image](images/B9780443218576000217/si199.png) are denoted (in increasing order) as `q[1], q[2]`![Image](images/B9780443218576000217/si200.png), and so on, then the following notation is more flexible:

```
L_{P}(z,x,\nu) = \prod\limits_{p \in P}\frac{1}{1 - x^{\nu(p)}p^{- z}} = \sum\limits_{k = 1}^{\infty}x^{\Omega_{\nu}(q_{k})}q_{k}^{- z}.
```

![Image](images/B9780443218576000217/si201.png)(17.12)
