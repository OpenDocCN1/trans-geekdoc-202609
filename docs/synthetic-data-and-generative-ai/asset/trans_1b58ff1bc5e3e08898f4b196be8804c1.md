# 第 6 章：基于可解释 AI 的形状分类与合成

## 摘要

此处我使用参数极坐标方程定义了二维空间中形状和形状签名的数学概念。该签名在平移或缩放因子下唯一表征形状。在实际应用中，数据集由位于形状上的点或像素组成，而非曲线本身。如果这些点采样不当——即它们在曲线上分布不均匀——则需要重新加权以计算形状的有效质心，并进行形状比较。我将讨论权重，然后引入用于比较形状（将其视为图像中的点集或像素集）的度量。这些度量与豪斯多夫距离相关。我还引入了两个形状之间的相关距离。有了这些度量，就可以使用任意大小的训练集进行形状识别或分类。我在应用中使用了合成数据。这使你能够了解分类器的表现，区分两个非常相似的形状，或在有噪声的情况下进行区分。本文还讨论了旋转不变度量。

### 关键词

豪斯多夫距离；形状签名；形状分类；合成形状；可解释 AI

## 6.1 简介

**计算机视觉**中的一个核心问题是比较形状并评估它们的相似程度。例如，这用于文本识别。现代技术涉及神经网络。在此，我重温了一种在计算机出现之前就已开发的方法论。借助现代技术，它催生了一种高效、自动化的 AI 算法。其优势在于，该黑箱系统的决策过程易于解释，因此也易于控制。

相反，神经网络使用数百万个无法解释的权重，可能导致过拟合。为何它们在某些数据上效果极好，而在其他数据上效果不佳，仍是个谜。我的“老派”分类器经适配现代数据和计算机架构后，可实现对参数的完全控制。换言之，你预先就知道微调参数将如何影响输出。因此称为可解释 AI [[Wiki](https://en.wikipedia.org/wiki/Explainable_artificial_intelligence)]。

在理想世界中，人们希望融合这两种方法，以发挥各自的优势，并最小化各自的缺点。这种融合被称为集成方法 [[Wiki](https://en.wikipedia.org/wiki/Ensemble_learning)]。此外，既然我们处理的是位于曲线（即“形状”）上的采样点，相同的方法论也适用于声音识别。

## 6.2 数学基础

本节关注形状的数学概念。稍后，我将该方法论应用于由点集或像素集表示的形状，这些形状通过矩形窗口（即数字图像）观测。窗口中心为坐标系原点。形状可以是任何事物：可能代表一个字母、一个象形文字或符号组合。它们可能由多条不相连的曲线组成。我们仅关注定义形状的轮廓。它可能对应某个域的边界，也可能不对应；轮廓可能不闭合，且可能由不相连的线段组成。

此外，不涉及颜色或灰度。数学形状模型可视为白底黑图，无厚度。在实际应用中，矩形图像以形状为中心，且噪声已被滤除。参见 [图 6.1](#Chp006_103-111_B9780443218576000102.xhtml#f0010) 中的示例，比较两个形状。

![Figure 6.1 Comparing two shapes.](images/B9780443218576000102/gr001.jpg)

**图 6.1** 比较两个形状。

为便于说明，使用参数极坐标方程定义二维数学形状，如下所示：

`r[t] = g(t), θ[t] = h(t), with t ∈ T, r[t] ≥ 0, 0 ≤ θ[t] ≤ 2π.`

![](images/B9780443218576000102/si1.png)

此处 `g`、`h` 为实值函数，`T` 为索引域。`n = 20` 个点的示例如下：

`θ[t] = (t + η) mod 2π, r[t] = c + d sin(a t) sin(2π b − b t), t = 2π k / n with k = 0, …, n − 1.`

![](images/B9780443218576000102/si4.png) (6.1)

该示例如 [图 6.1](#Chp006_103-111_B9780443218576000102.xhtml#f0010) 所示。参数 `η` 控制形状的旋转角度或方向。根据定义，`α mod β = α − β⌊α/β⌋`，其中括号表示取整函数。

![](images/B9780443218576000102/si5.png)
