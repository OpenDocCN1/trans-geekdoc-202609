
威廉·休伯（[William Huber](https://www.analysisandinference.com/team/william-a-huber-phd)）证明了这一未发表定理，详见[此处](https://stats.stackexchange.com/questions/422354/correlations-between-two-sequences-of-irrational-numbers)；关于该主题的更多讨论见[此处](https://stats.stackexchange.com/questions/450922/cross-correlations-in-digit_distributions)。注意，⌊`b` ⋅ {`b`^(`k`)`α`}⌋![图片](images/B9780443218576000151/si208.png)是`α`在`b`进制下的第`k`位数字。括号代表取整函数。因此，如果`α[1]` = `p``α`![图片](images/B9780443218576000151/si209.png)和`α[2]` = `q``α`![图片](images/B9780443218576000151/si210.png)，则序列({`b`^(`k`)`α[1]`})![图片](images/B9780443218576000151/si211.png)和({`b`^(`k`)`α[2]`})![图片](images/B9780443218576000151/si212.png)之间的相关性为`ρ`(`p`, `q`) = (`p``q`)^( − 1)![图片](images/B9780443218576000151/si206.png)。如果`α[1]`, `α[2]`![图片](images/B9780443218576000151/si213.png)是无理数且在ℚ![图片](images/B9780443218576000151/si201.png)上线性无关，那么要表示`α[1]` = `p``α`![图片](images/B9780443218576000151/si209.png), `α[2]` = `q``α`![图片](images/B9780443218576000151/si210.png)的唯一方法是让`p`, `q`![图片](images/B9780443218576000151/si103.png)趋向无穷大，从而相关性消失。这意味着`α[1]`![图片](images/B9780443218576000151/si214.png)和`α[2]`![图片](images/B9780443218576000151/si215.png)的数字序列之间的相关性为零。

涉及更多数论内容。特别是，该方法使用第[11.3.3](#Chp011_203-228_B9780443218576000151.xhtml#s0070)节描述的新算法来计算无理数的二进制数字。它还与`square-free integers`（[平方因子](https://en.wikipedia.org/wiki/Square-free_integer)）有关，以及用有理数逼近无理数，这与连分数相关。平方因子也在第[11.2.1](#Chp011_203-228_B9780443218576000151.xhtml#s0020)节和第[17.2.2.2](#Chp017_329-360_B9780443218576000217.xhtml)节中讨论。它们占所有正整数的61%：确切比例是6/`π`²![图片](images/B9780443218576000151/si216.png)。

### 11.4.2 快速PRNG：解释

每个正整数`c`可以写成`c` = `a``b`![图片](images/B9780443218576000151/si217.png)，其中`a`是平方数，`b`是平方因子。例如，如果`c` = 3⁵ × 13⁶ × 19![图片](images/B9780443218576000151/si218.png)，则`a` = 3⁴ × 13⁶![图片](images/B9780443218576000151/si219.png)和`b` = 3 × 19![图片](images/B9780443218576000151/si220.png)。如果`c`是平方数，则`c` = `a`![图片](images/B9780443218576000151/si221.png)和`b` = 1![图片](images/B9780443218576000151/si222.png)。

此处使用的无理数由一个二元`seed`（`y[0]`, `z[0]`）![图片](images/B9780443218576000151/si223.png)表征。给定种子，连续�代生成以下数字的二进制数字：

```
x_0 = \frac{- (z_0 - 1) + \sqrt{(z_0 - 1)^2 + 8y_0}}{4}.
```

![图片](images/B9780443218576000151/si224.png)(11.7)

与平方因子的联系如下：`c` = (`z[0]` − 1)² + 8`y[0]`![图片](images/B9780443218576000151/si225.png)不能是平方数。我使用符号`c` = `a``b`![图片](images/B9780443218576000151/si217.png)，其中`a`是`c`的平方部分，`b`是平方因子部分。因此，我们必须有`b` > 1![图片](images/B9780443218576000151/si100.png)。我使用大量种子来生成大量无理数。根据第[11.4.1](#Chp011_203-228_B9780443218576000151.xhtml#s0080)节的理论，任意一对无理数的两个数字序列之间的交叉相关性必须为零。这意味着一旦某个种子产生了特定的`b`，任何具有相同`b`的未来种子都必须被拒绝。这是通过代码中的变量`accepted`以及`hash table`（Python中的字典）`squareFreeList`来实现的。该哈希表的键实际上是`b`。

每个无理数生成的数字数量由参数`size`指定。无理数的总数由`Niter`决定。并非全部使用：由于上述原因，有少数被拒绝。所有被接受的无理数的所有二进制数字都存储在哈希表`digits`中。例如，`digits[(b,k)]`是具有平方因子`b`的无理数的第`k`位数字。与此数字对应的种子(`y[0]`, `z[0]`)![图片](images/B9780443218576000151/si223.png)是`squareFreeList[b]`.

由于Python代码中种子的特定选择（其中`y[0]` = 1![图片](images/B9780443218576000151/si226.png)），许多无理数接近零。更具体地说，公式[(11.7)](#Chp011_203-228_B9780443218576000151.xhtml#deq8)给出了如下近似：`x[0]` ≈ `y[0]`/(`z[0]` − 1)![图片](images/B9780443218576000151/si227.png)。因此，前几位数字有偏差，应当跳过。这是通过参数`offset`实现的。还有其他有问题的无理数，例如`z[0]` − 1![图片](images/B9780443218576000151/si228.png)是2的幂的情况。该算法的未来版本可以拒绝这些无理数，也可以拒绝那些与哈希表中已有数字过于接近的无理数。然而，增加参数`offset`是消除这些问题的最简单方法。下一步是运行标准测试套件，如`Diehard tests`（[Diehard测试](https://en.wikipedia.org/wiki/Diehard_tests)），并检查该PRNG是否根据参数和配置通过所有测试。

我尚未测试`size`=1的算法：这是生成大量数字的最快方式（假设相应增加`Niter`），并且假设`offset`足够大，可能是最佳选择。特别是，如果你只提取每个无理数的一位数字，有一种更快的方法，见第[11.4.4](#Chp011_203-228_B9780443218576000151.xhtml#s0095)节。
