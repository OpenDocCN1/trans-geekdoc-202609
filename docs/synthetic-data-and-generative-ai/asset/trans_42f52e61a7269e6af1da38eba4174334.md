
在惩罚和拒绝不理想的单个样条或预测值时，无需过于激进。中位数能很好地过滤掉非稳健的测量值。越激进，使用的样条越少，导致统计置信度越低。在极端情况下，某些位置可能完全没有预测值：对于这些位置，Python 代码中的变量 `count` 等于零，计数器 `missing` 加一。这可能是好事，也可能不是。

## 8.3.2 预测值与预测区间

在 [8.2 节](#Chp008_131-145_B9780443218576000126.xhtml#s0015) 中，我使用了跨所有 `M = n(n-1)/2`![Image](images/B9780443218576000126/si1.png) 条样条计算的中位数预测值，作为特定位置响应 `z` 的最终预测值。此处 `n` 为训练集中的观测值数量。然后，我利用在同一位置计算出的这 `M` 个值的分位数来构建预测区间。一般情况也适用同样的原理，但现在 `M = (n choose r)`![Image](images/B9780443218576000126/si36.png) 是一个二项式系数。请注意，实际样条数量将取决于位置 `(x, y)`![Image](images/B9780443218576000126/si26.png)，如果某些样条被拒绝，则该数量小于 `M`。在 Python 代码中，每次调用函数 `F()` 都会生成一条新的随机样条。数字 `M` 是预先指定的，选择得足够大（>500），但远小于 `(n choose r)`![Image](images/B9780443218576000126/si37.png)。此外，我主要使用 `r = 2`![Image](images/B9780443218576000126/si38.png)。

中位数的一种替代方案是使用加权平均来计算预测值。对于附加在样条 `L[k]`![Image](images/B9780443218576000126/si16.png) 上的权重，请使用公式 [(8.3)](#Chp008_131-145_B9780443218576000126.xhtml#deq6)。这些权重和整个系统的设计旨在满足以下性质。设 `(x, y)`![Image](images/B9780443218576000126/si26.png) 为训练集点的位置。那么，在 `(x, y)`![Image](images/B9780443218576000126/si26.png) 处的预测值，使用相关权重且令 `s → ∞`![Image](images/B9780443218576000126/si39.png) 并精心选择 `M = n`![Image](images/B9780443218576000126/si40.png) 条样条，将与观测值完全相同。例如，如果 `k = (k[1], …, k[r])`![Image](images/B9780443218576000126/si18.png) 中的索引 `k[1]`![Image](images/B9780443218576000126/si41.png) 覆盖了 1 到 `n` 之间的所有整数值，即所有训练集点，则此性质成立。在这种情况下，总是至少存在一个索引向量 `k` 使得 `δ[k](x, y) = 0`![Image](images/B9780443218576000126/si32.png)，对应一条包含 `(x, y, z)`![Image](images/B9780443218576000126/si42.png) 的样条，其权重等于 1，远大于所有其他权重。有关正式证明，请参阅 [练习 8.1](#Chp008_131-145_B9780443218576000126.xhtml#enun0010)。

确实，当 `s` 很大时，加权方法类似于 `inverse distance weighting`（谢泼德法）[[维基百科](https://en.wikipedia.org/wiki/Inverse_distance_weighting)]，或 `nearest neighbor interpolation`[[维基百科](https://en.wikipedia.org/wiki/Nearest-neighbor_interpolation)]。加权版本已在 Python 代码中实现。在预测中纳入邻近数据的另一种方法是，仅使用由靠近目标位置 `(x, y)`![Image](images/B9780443218576000126/si26.png) 的训练集点确定的局部样条。最后，仍需开发高效的实现。该方法可轻松利用并行计算机架构实现。

然而，虚线的斜率仅为 0.4640。你可能期望它接近 1：毕竟，完美拟合意味着所有蓝点都落在主对角线上。在实践中，斜率将始终介于 0 和 1 之间。解释如下。回归技术（准确说是空间回归）充当平滑器或噪声过滤技术，抑制振幅。要消除抑制效应，需要恢复振幅。这可以通过标准化预测值来轻松实现，使其均值和方差与训练集上测得的原始信号（观测响应）`z` 的均值和方差相对应。这样做不会改变 R 平方，因为它在平移和乘法下是不变的。实际上，R 平方是 `z` 与 `z[m]`![Image](images/B9780443218576000126/si43.png) 之间相关系数的平方。

预测水平基于 20%（下界）和 80%（上界）经验分位数。因此，置信水平为 60%。无法以任何有意义的方式直接在散点图上显示预测带。取而代之的是，[图 8.2](#Chp008_131-145_B9780443218576000126.xhtml#f0015) 中的每个蓝点对应一个绿点和一个红点：即预测区间的上界和下界。对于每个蓝点，相关的红点和绿点都在同一条垂直线上（未显示），平行于垂直轴。细节并不重要；最终，[图 8.2](#Chp008_131-145_B9780443218576000126.xhtml#f0015) 仍能很好地展示该方法的性能以及预测区间的样子。

详细实现位于 [`Fuzzy4.xlsx`](https://ln5.sync.com/dl/0caeb8e10/mztnibg9-xrkdks7g-r8bsgabw-3fsizwif) 电子表格中。大部分繁重计算在 Python 中完成。电子表格提供最后步骤：预测区间和可视化。它还包含 Python 生成的输出文件 `fuzzy_big.txt`。现在，我将讨论该电子表格中的各个字段。
