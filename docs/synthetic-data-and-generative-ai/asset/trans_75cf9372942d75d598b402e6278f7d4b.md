
该技术必须正确实施，以减少惩罚少数群体的 `algorithmic bias` [[维基百科](https://en.wikipedia.org/wiki/Algorithmic_bias)]。使用 Copula 时，请参阅第 [10.2.1](#Chp010_169-201_B978044321857600014X.xhtml#s0020) 节中的问题。一个解决方案是向真实数据中添加额外特征（例如教育水平），以更好地捕捉作为一个整体持续受到惩罚的人口群体（高犯罪率地区）的细微差别，从而发现表现良好的子群体。然后你可以为高犯罪率地区受过大学教育的人群等子群体计算单独的 Copula。

最后，对于作者和出版商，合成图像可以模仿并替代受版权保护的图像，从而消除许可费和授权问题。合成艺术被称为 `AI art`。问题是：谁拥有它？你能拥有随机生成的模式或数字吗？

## 10.2 使用 Copula 生成合成数据

生成具有与真实数据集完全相同的相关结构和边缘分布的数据的一种方法是使用 `copulas` [[维基百科](https://en.wikipedia.org/wiki/Copula_(probability_theory))]。生成 *n* 个合成观测值的算法如下：

- **步骤 1：** 计算与真实数据相关的相关矩阵 `W`。
- **步骤 2：** 从均值为零、协方差矩阵为 `W` 的多元高斯分布中生成 *n* 个偏差值。每个偏差值是一个向量 `Z[i]`（*i* = 1, …, *n*），其分量与真实数据集中的特征相匹配。
- **步骤 3：** 对于每个生成的 `Z[i][j]`（第 *i* 个向量中的第 *j* 个特征），计算 `U[i][j] = Φ(Z[i][j])`，其中 `Φ` 是单变量标准正态分布的 CDF（累积分布函数）。因此 `0 ≤ U[i][j] ≤ 1`。
- **步骤 4：** 计算 `S[i][j] = Q[j](U[i][j])`，其中 `Q[j]` 是第 *j* 个特征的单变量 `empirical quantile distribution`（经验分布的逆），基于真实数据计算得出。

假设 `W` 是非奇异的，你的特征向量集合 `S[i]`（*i* = 1, …, *n*）就是你的合成数据，模仿你的真实数据集。这里我隐式地使用了 `Gaussian copula`，但也存在其他选项，例如 `Frank copula`。该方法是 `Sklar's theorem` [[维基百科](https://en.wikipedia.org/wiki/Copula_(probability_theory)#Sklar's_theorem)] 的直接应用。有多种方法可以衡量合成数据与真实数据之间的相似度或距离。在这种情况下，`Hellinger distance` [[维基百科](https://en.wikipedia.org/wiki/Hellinger_distance)] 很常用。另请参阅第 [6.4](#Chp006_103-111_B9780443218576000102.xhtml) 节关于比较两个数据集的内容。然而，这些指标会导致过拟合：最好的合成数据是真实数据的精确复制品。如 [表 10.1](#Chp010_169-201_B978044321857600014X.xhtml#t0010) 所示，拥有与真实数据匹配的统计摘要，并结合最差的 Hellinger 得分，可以得到更丰富的合成数据。最终，质量应通过将合成数据添加到训练集后，对验证集进行预测所获得的改进来衡量。

Hellinger 距离很受欢迎，因为它的取值在 0 和 1 之间，0 表示完美拟合，1 表示最坏情况。它基于 PDF（概率密度函数）而非 CDF（累积分布函数）。与两个 CDF 之间的 `Kolmogorov–Smirnov distance` [[维基百科](https://en.wikipedia.org/wiki/Kolmogorov%E2%80%93Smirnov_test)] 相比，这导致了一个更粗糙的指标，对噪声更敏感。此外，虽然 Hellinger 距离可以通过处理涉及所有特征的联合多元 PDF 来全局计算，但它基于在特征向量中大量小的多元箱体上测量的观测频率，每个箱体的观测值很少，因此不稳定。一个更好的解决方案是分别计算每个特征的距离，然后取这些距离的最大值。简而言之，将最佳合成视为使所有特征中的最大距离最小化的合成。从好的方面来看，Hellinger 距离可以很好地处理分类数据。

比较两个概率密度函数 `P` 和 `P'` 的公式如下，以具有 *n* 个水平或类别的离散分布为例进行说明。实际上，它应用于频率（在每个特征上测量的经验 PDF）：

```
H(P, P') = (1/√2) * √(Σ_{k=1}^{n} (√p_i - √p_i')^2)
```

在 Python 中，合成算法的四个步骤分别由函数 `np.corrcoef`、`np.random.multivariate_normal`、`norm.cdf` 和 `np.quantile` 执行。除了来自 `Scipy` 库的 `norm.cdf`（标准高斯分布的 CDF）外，其他函数均在 `Numpy` 中实现。要在每次运行程序时生成完全相同的合成数据，请使用相同的 `seed` 调用 `np.random.seed`。
