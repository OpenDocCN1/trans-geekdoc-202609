## 18.1 Python 中的声音处理

### 18.1.1 从数据可视化到视频再到数据音乐

我们都熟悉静态数据可视化。动态 GIF（如[这个](https://mltechniques.com/2022/04/20/computer-vision-shape-classification-via-explainable-ai/)）带来了新的维度，但它们并不新鲜。然后，以视频形式呈现的数据是相当新颖的，我的 YouTube 频道[这里](https://www.youtube.com/c/VincentGranvilleVideos)有示例。然而，我不记得有任何数据集被表示为旋律。本节很可能是首个示例。

就像数据视频一样，时间是主要组成部分。这个概念非常适合时间序列。特别是，这里我生成了两个时间序列，每个包含 `n = 300` ![Image](images/B9780443218576000229/si1.png) 个观测值，在时间上等间距分布。它代表纯粹的、不相关的噪声：第一个是高斯分布，由声音频率表示；第二个是均匀分布，由音符时长表示。每个音符对应一个观测值。我使用了最标准的音阶，并避免了`半音` [[Wiki](https://en.wikipedia.org/wiki/Semitone)]——钢琴上的黑键——以产生悦耳的旋律。要聆听它，请访问[这个 GitHub 链接](https://github.com/VincentGranville/Machine-Learning/blob/main/Images/sound.wav)，下载 WAV 文件并播放。确保您的扬声器已打开。您甚至可以在办公室播放它，毕竟这是工作相关的。

因为它代表噪声，所以旋律永不重复，也没有记忆。然而它似乎展现出模式，即随机性的模式。随机数据实际上是模式最丰富的数据，因为如果足够大，它包含所有存在的模式。如果你在正方形中绘制随机点，有些会显得聚集，有些区域会显得稀疏，有些点会显得对齐。随机音符也是如此。这将是未来一篇文章的主题，标题为“随机性的模式”。

下一步是为真实数据集创建旋律，展现自相关性和其他特性。这里使用的二元时间序列如下图所示：红曲线（印刷版为浅灰色）是与音频中音符频率相关的缩放高斯噪声；蓝曲线（印刷版为深灰色）是与音符时长相关的缩放均匀噪声。就我而言，我计划为数论中的著名函数（黎曼函数）创建旋律，并将声音与我迄今制作的无声视频融合，例如在[图 18.1](#Chp018_361-386_B9780443218576000229.xhtml#f0010)中。

### 18.1.3 Python 代码

在 WAV 文件中，声音通常以波形记录。这些波形由 `get_sine_wave()` 函数生成，每个音符一个波形。基准音符频率为 440。每个八度包含 12 个音符，包括五个半音。我跳过了那些以避免不协和音。频率从一个八度到下一个八度翻倍。我只包含了标准笔记本电脑可渲染的可听音符，因此代码中有 `range(40,65)` 这一指令。

代码的最后一行将波形值转换为整数，并将整个旋律保存为 sound.wav。现在您可以编写自己的代码来聆听您的数据！或者您可以使用该代码测试大量随机音符序列，看看某些短片段是否足够好且足够原创，可以融入您自己的音乐。您也可以尝试非正弦波。例如，混合波形以模拟和声音高（同时发出两个或更多音符）以及钢琴以外的乐器。

## 18.2 R 中的数据视频与增强可视化

长期以来，R 生成的图表看起来像素化且因质量差而易于辨认。问题在于图形库缺乏`抗锯齿`机制 [[Wiki](https://en.wikipedia.org/wiki/Spatial_anti-aliasing)]。现在有了 ggplot2 [[Wiki](https://ggplot2.tidyverse.org/)]，这个问题已得到解决。不过这个包学习曲线陡峭。但如果您仍在使用旧的 `plot()` 函数，您仍会面临该问题。然而，有一个简单的变通方法，即使用 Cairo 库。我先解释它的工作原理，然后介绍如何使用 AV 库制作视频。

### 18.2.1 使用 Cairo 库生成更好的图表

该问题如[图 18.2](#Chp018_361-386_B9780443218576000229.xhtml#f0020)所示。如果您放大查看，问题会更加明显。修复方法只需在 R 中添加两行代码。首先，您需要使用命令 `install.packages('Cairo')` 安装 Cairo 库。您的 R 脚本的前两行代码如下：

![图 18.2 使用 Cairo 前（左）和后（右）的 R 图表。](images/B9780443218576000229/gr002.jpg)

[图 18.2](#Chp018_361-386_B9780443218576000229.xhtml#cf0020) 使用 Cairo 前（左）和后（右）的 R 图表。

```
library('Cairo');
CairoWin(5,5);
```

第二行代码是在屏幕上创建一个高分辨率窗口，以替代标准的 R 图形窗口。如果想要更大的窗口，请尝试 `CairoWin(6,6)`。如果您想将图像保存为 PNG 文件，请将第二行代码替换为类似如下内容：

```
CairoPNG(filename="c:/Users/yourname/nice.png", width=600, height=600);
```

要实际生成 PNG 图像，请在脚本底部添加 `dev.off()`。详情请参阅 [CairoGraphics.org](https://www.cairographics.org/) 或维基百科条目[这里](https://en.wikipedia.org/wiki/Cairo_\(graphics\))。我的 R 脚本完整版可在我的 GitHub 仓库[这里](https://github.com/VincentGranville/Point-Processes/blob/main/Source%20Code/PP_NN_arrows.r)获取。它使用了一个输入文件，也在同一仓库[这里](https://github.com/VincentGranville/Point-Processes/blob/main/Data/PB_r.txt)提供。
