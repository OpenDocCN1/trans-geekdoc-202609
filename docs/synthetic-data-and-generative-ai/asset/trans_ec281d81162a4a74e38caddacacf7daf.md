第[16](#Chp016_293-327_B9780443218576000205.xhtml)章对该主题提供了更全面的综述，包含大量参考文献，涵盖从模拟、图属性到理论的各个方面。这些过程最近变得流行起来，应用于传感器数据、细胞网络、晶体学和化学。它们灵活且非常易于模拟。三个主要参数是尺度或扩散因子 `s`、强度 `λ`（与单位面积内的预期点数相关），以及局部分布 `F`，后者可能是高斯分布，也可能不是。在本章中，我不讨论理论。我仅介绍生成合成数据所需的基本材料。详情请参阅第[16](#Chp016_293-327_B9780443218576000205.xhtml)章。

首先，我在本文档包含的 Python 代码中使用 `λ = 1`。然后，如果 `s = 0`，所有点都位于晶格上：不再有随机性。相反，如果 `s` 很大（例如 `s > 5`），则点近似均匀分布，如泊松点过程。在这种情况下，模拟数据没有聚类结构。此处的合成数据使用 `s = 0.05`（导致簇间分离良好）或 `s = 0.15`（导致簇显著重叠）。

## 5.2 随机晶格过程

### 5.2.1 使用逻辑分布的模拟

所有模拟均在二维空间中进行。选择逻辑分布作为 `F` 没有特别原因，只是因为它最容易采样。高斯分布也可以。分布 `F` 对最终结果影响很小。确实，要通过逆向工程识别底层分布 `F` 并不容易，有时甚至不可能。关于此主题的讨论，请参见第[16](#Chp016_293-327_B9780443218576000205.xhtml)章。最后，算法如下：

#### 数据生成：算法

生成的数据是二维的，但很容易推广到任意维度。对于每个晶格顶点 `(h, k)`，其中 `h, k` 为整数（正或负），以及每个随机晶格过程 `M[i]`（`0 ≤ i < m`），按如下方式生成二元观测值 `(x[ih], y[ik])`：

```
x_ih = μ_i + h/λ_i + s · log(U_ih / (1 - U_ih))
```

(5.1)

```
y_ik = μ'_i + k/λ'_i + s · log(U_ik / (1 - U_ik))
```

(5.2)

公式[(5.1)](#Chp005_83-102_B9780443218576000096.xhtml#deq1)和[(5.2)](#Chp005_83-102_B9780443218576000096.xhtml#deq2)来自第[16.2.4](#Chp016_293-327_B9780443218576000205.xhtml)节。`U[ih], U[ik]` 是 `[0, 1]` 上的独立均匀偏差。实际上，我们在有限矩形窗口中生成点，并仅保留子窗口内的点，以避免我书中描述的边界效应。这在[5.4](#Chp005_83-102_B9780443218576000096.xhtml#s0060)节的 Python 代码中实现，其中 `−25 ≤ h, k ≤ 25`。在代码中，我使用数组 `stretchX`、`stretchY` 存储系数 `1/λ[i], 1/λ'[i]`，使用 `shiftX`、`shiftY` 存储位移向量 `(μ[i], μ'[i])`。位移向量是簇的中心。在矩形窗口中，根据设计，来自过程 `M[i]`（在混合模型中扮演混合成分角色）的观测点数在二维情况下与 `λ[i] × λ'[i]` 成正比。在我的示例中，我选择了 `λ[i] = λ'[i] = λ`，其中 `λ = 1`。

### 5.2.2 将原始观测值映射到图像位图

最终，由于所涉及的随机过程具有晶格性质（点模式在每个顶点周围表现出统计铺砌），点通过取模运算符进行变换（见 Python 代码中的 `xmod` 和 `ymod`），然后映射到图像位图（Python 代码中的二元数组 `bitmap`）。随后，使用图像处理技术执行分类或聚类。

## 5.3 分类与无监督聚类

我在此描述一种快速监督和无监督分类的方法论。数据首先被转换为一个名为 `bitmap` 的二维数组。这些点被称为像素，该数组代表存储在 `GPU`（图形处理单元）[[Wiki](https://en.wikipedia.org/wiki/General-purpose_computing_on_graphics_processing_units)] 中的图像。应用于 `bitmap` 的函数是标准图像处理技术，如高通滤波或`直方图均衡化`[[Wiki](https://en.wikipedia.org/wiki/Histogram_equalization)]。
