
这是轮廓线的一般椭圆形式。从本质上讲，当 `n` 很大时，它不依赖于 `n`、`p`、`q`![Image](images/B9780443218576000229/si34.png)。标准置信区域于是就是满足 `H[n](x, y, p[0], q[0]) ≤ G[γ]`![Image](images/B9780443218576000229/si35.png) 的所有 (`x`, `y`)![Image](images/B9780443218576000229/si2.png) 的集合。在这里，你选择 `G[γ]`![Image](images/B9780443218576000229/si36.png) 以保证**置信水平**为 `γ`。将 ⩽ 替换为 = 即可得到该区域的边界。

在这种情况下，`G[γ]`![Image](images/B9780443218576000229/si36.png) 是**霍特林分布**的一个**分位数** [[维基百科](https://en.wikipedia.org/wiki/Hotelling%27s_T-squared_distribution)]。在 [18.3.4 节](#Chp018_361-386_B9780443218576000229.xhtml#s0065) 中，我将展示如何计算 `G[γ]`![Image](images/B9780443218576000229/si36.png)。这些模拟适用于任何设置，无论 `G[γ]`![Image](images/B9780443218576000229/si36.png) 是霍特林分位数、费舍尔分位数还是任意分位数。又或者无论你的估计量 (`p[0]`, `q[0]`)![Image](images/B9780443218576000229/si27.png) 的极限分布是否为高斯分布，随着样本量 `n` 的增加。这些模拟为计算置信区域提供了一个通用框架。

### 18.3.3 对偶置信区域

**对偶置信区域**只需在 `H[n](x, y, p, q)`![Image](images/B9780443218576000229/si38.png) 中交换 (`x`, `y`)![Image](images/B9780443218576000229/si2.png) 和 (`p`, `q`)![Image](images/B9780443218576000229/si37.png) 的角色即可获得。因此，它被定义为满足 `H[n](p, q, x, y) ≤ H[γ]`![Image](images/B9780443218576000229/si39.png) 的 (`x`, `y`)![Image](images/B9780443218576000229/si2.png) 的集合。同样，你选择 `H[γ]`![Image](images/B9780443218576000229/si40.png) 以保证置信水平为 `γ`。此外，(`p`, `q`)![Image](images/B9780443218576000229/si37.png) 被替换为 (`p[0]`, `q[0]`)![Image](images/B9780443218576000229/si27.png)。这不再是椭圆的方程。在实践中，这两个置信区域非常相似。此外，`H[γ]`![Image](images/B9780443218576000229/si40.png) 几乎等同于 `G[γ]`![Image](images/B9780443218576000229/si36.png)。解释如下：点 (`x`, `y`)![Image](images/B9780443218576000229/si2.png) 属于 (`p[0]`, `q[0]`)![Image](images/B9780443218576000229/si27.png) 的对偶置信区域，当且仅当 (`p[0]`, `q[0]`)![Image](images/B9780443218576000229/si27.png) 属于 (`x`, `y`)![Image](images/B9780443218576000229/si2.png) 的标准置信区域。我对这两个区域使用相同的 `n` 和置信水平 `γ`。你可以用同样的原理来定义对偶置信区间。

对偶置信区域基于贝叶斯统计中**可信区域** [[维基百科](https://en.wikipedia.org/wiki/Credible_interval)] 的相同原理。产生非椭圆区域的其他方法见文献 [[4]](#Chp018_361-386_B9780443218576000229.xhtml#br0020)。

### 18.3.4 模拟

模拟包括生成 `N` 个数据集，每个数据集包含 `n` 个观测值。请使用 [18.3.1 节](#Chp018_361-386_B9780443218576000229.xhtml#s0050) 中描述的联合伯努利模型进行模拟。目的是创建具有与你的观测值相同统计行为的数据集：换句话说，即合成数据。具体而言，我使用一些预先指定的 `p[0]`、`q[0]`![Image](images/B9780443218576000229/si41.png) 来模拟二元伯努利模型，这些是我们想要估计的真实但未知的值。我现在描述如何进行操作。

对于每个模拟数据集，计算比例、标准差和相关性。它们分别表示为 `x`、`y`、`σ[x]`、`σ[y]`![Image](images/B9780443218576000229/si42.png) 和 `ρ[x, y]`![Image](images/B9780443218576000229/si43.png)（每个数据集一组值）。使用标准公式，但这次 `x`、`y`![Image](images/B9780443218576000229/si5.png) 是观测值，而 `p[0]`、`q[0]`![Image](images/B9780443218576000229/si41.png) 是变量。即，

```
$H\_{n}(p\_{0},q\_{0},x,y) = \frac{2n}{1 - \rho\_{x,y}^{2}}\left\lbrack \left( \frac{p\_{0} - x}{\sigma\_{x}} \right)^{2} - 2\rho\_{x,y}\left( \frac{p\_{0} - x}{\sigma\_{x}} \right)\left( \frac{q\_{0} - y}{\sigma\_{y}} \right) + \left( \frac{q\_{0} - y}{\sigma\_{y}} \right)^{2} \right\rbrack,\sigma\_{x} = \sqrt{x(1 - x)},\quad\sigma\_{y} = \sqrt{y(1 - y)},\quad\rho\_{x,y} = - \frac{xy}{\sqrt{xy(1 - x)(1 - y)}}$.
```

![Image](images/B9780443218576000229/si44.png)

还要为每个数据集计算 `G(x, y) = H[n](x, y, p[0], q[0])`![Image](images/B9780443218576000229/si45.png) 和 `H(x, y) = H[n](p[0], q[0], x, y)`![Image](images/B9780443218576000229/si46.png)。将结果放入一个包含 `N` 行 7 列的表中。按如下步骤操作。

*   **标准置信区域** – 按 `G(x, y)`![Image](images/B9780443218576000229/si47.png) 对表进行排序。
*   **对偶置信区域** – 按 `H(x, y)`![Image](images/B9780443218576000229/si48.png) 对表进行排序。

排序后表格中的前 `⌊γN⌋`![Image](images/B9780443218576000229/si49.png) 行决定了你的置信水平为 `γ` 的置信区域。这些行中的所有 (`x`, `y`)![Image](images/B9780443218576000229/si2.png) 都属于你的置信区域。这里 `⌊⋅⌋`![Image](images/B9780443218576000229/si50.png) 代表取整函数（向下取整）。在前 `⌊γN⌋`![Image](images/B9780443218576000229/si49.png) 行中，`H(x, y)`![Image](images/B9780443218576000229/si48.png) 的最后一个值——如果按 `H(x, y)`![Image](images/B9780443218576000229/si48.png) 排序——就是 `H[γ]`![Image](images/B9780443218576000229/si40.png)。同理，如果按 `G(x, y)`![Image](images/B9780443218576000229/si47.png) 排序，`G(x, y)`![Image](images/B9780443218576000229/si47.png) 的最后一个值就是 `G[γ]`![Image](images/B9780443218576000229/si36.png)。请参阅 [图 18.4](#Chp018_361-386_B9780443218576000229.xhtml#f0035) 中的示例，包含 ![Image](images/B9780443218576000229/fx004.jpg) 和 ![Image](images/B9780443218576000229/fx005.jpg)。随着 `N` 的增加，你的模拟产生的区域将越来越接近理论区域。包含这些模拟的电子表格可在我的 GitHub 仓库中获取，[点此访问](https://github.com/VincentGranville/Point-Processes/tree/main/Spreadsheets)。

### 18.3.5 最小对比估计量的原始问题
