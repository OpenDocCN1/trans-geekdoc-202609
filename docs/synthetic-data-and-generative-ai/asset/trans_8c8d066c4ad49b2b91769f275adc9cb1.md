
## 17.1 黎曼假设和广义黎曼假设

复平面是标准的二维空间：实轴是水平轴或X轴；虚轴是垂直轴或Y轴。黎曼假设（RH）指出，前面定义的黎曼zeta函数`ζ(z`)![Image](images/B9780443218576000217/si8.png)没有根（即`ζ(z) ≠ 0`![Image](images/B9780443218576000217/si12.png)），如果$\frac{1}{2} < \sigma < z$![Image](images/B9780443218576000217/si13.png)。我使用符号`σ = ℜ(z`)![Image](images/B9780443218576000217/si14.png)表示`σ`是复数`z = σ + it`![Image](images/B9780443218576000217/si2.png)的实部。在整个文中，正数是指⩾0的数。大于0的数称为严格正数。

广义黎曼假设（GRH）对一类更大的良好行为函数做出了与RH相同的断言，不仅仅是`ζ(z`)![Image](images/B9780443218576000217/si8.png)。简而言之，它适用于`χ(·`)![Image](images/B9780443218576000217/si4.png)完全乘性且周期性的Dirichlet函数；这些被称为Dirichlet-*L*函数。这里，我们将自己限制在`χ(p) ∈ {−1, +1}`![Image](images/B9780443218576000217/si15.png)。然而，我们也考虑那些非周期性的`χ(·`)![Image](images/B9780443218576000217/si4.png)。经典的非平凡周期性`χ(·`)![Image](images/B9780443218576000217/si4.png)是`χ = χ[4]`![Image](images/B9780443218576000217/si16.png)，即模4的非平凡Dirichlet特征。它导致一个欧拉乘积，据推测当$\sigma > \frac{1}{2}$![Image](images/B9780443218576000217/si17.png)时收敛。证明收敛性，哪怕仅在`σ = 0.99`![Image](images/B9780443218576000217/si18.png)这一点上，也将是证明GRH的重要里程碑。当然，如果`σ > 1`![Image](images/B9780443218576000217/si19.png)，该乘积收敛。如果允许`χ(·`)![Image](images/B9780443218576000217/si4.png)非周期性，则存在已知情况（本章讨论）满足GRH的要求。通常，这些函数不太有趣，且不满足类Dirichlet函数方程。

### 17.1.2 轨迹与空洞

本章首次引入了一个原创概念：Dirichlet函数轨迹的空洞。它在[图17.1](#Chp017_329-360_B9780443218576000217.xhtml#f0010)中得到体现，该图处理有限欧拉乘积；以及在[图17.5](#Chp017_329-360_B9780443218576000217.xhtml#f0030)中，该图展示了截断Dirichlet级数的轨迹（即无限乘积的截断展开，换句话说，部分和）。在RH和GRH的背景下，如果$\frac{1}{2} < \sigma < 1$![Image](images/B9780443218576000217/si20.png)固定且`0 < t < T`![Image](images/B9780443218576000217/si21.png)有界，则空洞存在。但随着`T → ∞`![Image](images/B9780443218576000217/si22.png)，在没有根的情况下（$\frac{1}{2} < \sigma < 1$![Image](images/B9780443218576000217/si20.png)），空洞收缩为原点的单元集；如果存在根（`σ = 1/2`![Image](images/B9780443218576000217/si24.png）），则收缩为空集。研究那些总是有空洞的修正Dirichlet函数，可能是朝着RH和GRH取得进展的关键。特别有趣的是研究它们在趋近标准Dirichlet函数时的极限行为，以及空洞缓慢蒸发的过程。这是第[17.3.1](#Chp017_329-360_B9780443218576000217.xhtml#s0065)节和第[17.3.3](#Chp017_329-360_B9780443218576000217.xhtml#s0095)节的主题。

![图17.1 三条轨迹（σ = 0.5,0.75,1.25）具有有限欧拉乘积：P = {2,3}（左）vs {2,3,5}（右）。](images/B9780443218576000217/gr001.jpg)

图17.1 三条轨迹（`σ = 0.5,0.75,1.25`）具有有限欧拉乘积：`P = {2,3}`（左）vs `{2,3,5}`（右）。

空洞是一个最大半径的圆，圆心在X轴上（由于对称性），轨迹永不穿越。空洞的中心可能不在原点（见第[17.2.2.1](#Chp017_329-360_B9780443218576000217.xhtml#s0050)节示例），即使没有根。没有根可能是由空洞引起的，或者因为轨迹从未过度靠近Y轴。对于固定的`σ`，固定域`0 < t < T`![Image](images/B9780443218576000217/si21.png)上的轨迹，定义为当`t`（称为“时间”）在`t = 0`![Image](images/B9780443218576000217/si25.png)和`t = T`![Image](images/B9780443218576000217/si26.png)之间连续变化时，相应Dirichlet函数在复平面上所有可能值的集合。这里，`t`是参数`z = σ + it`![Image](images/B9780443218576000217/si2.png)的虚部。完整轨迹对应`T = ∞`![Image](images/B9780443218576000217/si27.png)。空洞的大小，以及其存在/不存在和位置，取决于`σ`，当然也取决于`T`、`P`![Image](images/B9780443218576000217/si28.png)和`χ(·`)![Image](images/B9780443218576000217/si4.png)。

最后，在动力系统背景下，空洞被称为排斥盆地。轨迹可能是有界的，如果`σ > 1`![Image](images/B9780443218576000217/si19.png)；否则无界（在这种情况下，通常延伸至整个复平面）。

## 17.2 欧拉乘积

我从有限欧拉乘积开始，那里一切都很顺利：这里`P`是质数集合的有限子集；不存在收敛性问题，且轨迹总是有空洞。我首先引入黎曼函数`ζ(z`)![Image](images/B9780443218576000217/si8.png)的Dirichlet版本`η(z`)![Image](images/B9780443218576000217/si29.png)，因为我们需要它将收敛域从`σ > 1`![Image](images/B9780443218576000217/si19.png)扩展到`σ > 0`![Image](images/B9780443218576000217/si30.png)，以便研究当`0 < σ < 1`![Image](images/B9780443218576000217/si177.png)时的行为（空洞和/或根的存在）。对于`ζ(z`)![Image](images/B9780443218576000217/si8.png)，函数`χ(·`)![Image](images/B9780443218576000217/si4.png)是常数且等于1。然后我转向任意`χ(·`)![Image](images/B9780443218576000217/si4.png)，包括模4的Dirichlet特征，以及无限乘积。函数`χ`通过公式`χ(ab) = χ(a)χ(b)`![Image](images/B9780443218576000217/si5.png)扩展到所有整数：这种扩展导出了基本公式[(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5)、[(17.5)](#Chp017_329-360_B9780443218576000217.xhtml#deq6)和[(17.6)](#Chp017_329-360_B9780443218576000217.xhtml#deq7)，将欧拉乘积与其Dirichlet级数展开联系起来，只要两者都收敛。欧拉乘积建立了Dirichlet函数的解析性质与质数分布之间的联系。
