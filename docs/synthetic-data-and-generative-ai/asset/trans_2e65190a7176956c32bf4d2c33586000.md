
引入序列依赖的一种方法是增加[图 12.1](#Chp012_229-241_B9780443218576000163.xhtml#f0010)中灰色曲线的振荡频率（从而增加熵）。灰色曲线代表纯随机游走的一个实现。为了达到这个目标，你可能希望该序列违背迭代对数律：你想要构建一个序列，使其满足迭代对数律的修正版，其中公式 [(12.1)](#Chp012_229-241_B9780443218576000163.xhtml#deq1) 中的 `$\sqrt{2n\log\log n}$` 被替换为（比如说）`$n^{2/5}`。

为此，你需要在模拟相关序列时添加约束。然而你想要保留准随机性——即序列 `X[n]` 中不存在漂移和自相关——即使存在一些微弱的缺乏独立性。这种微弱程度确实如此，以至于大多数统计检验都无法捕捉到它，尽管它可以让肉眼高度可见：请看[图 12.1](#Chp012_229-241_B9780443218576000163.xhtml#f0010)中的红色曲线，尤其是蓝色曲线。

#### 12.1.2.1 应用

此类序列可用于生成合成数据（见第 [7](#Chp007_113-129_B9780443218576000114.xhtml) 章）或建模几乎无约束的随机过程，例如几乎完美市场中的股价波动。另见 [\[4\]](#Chp012_229-241_B9780443218576000163.xhtml#br0020)。另一个应用是在位第三方（政府或黑客）无法察觉的情况下，在某些加密系统中引入不可检测的后门，这取决于依赖性的强度。这种后门可以帮助加密公司在合法用户丢失密钥并请求解密时解密消息，即使该加密公司没有存储或检索密钥的标准机制（正是为了避免政府干预）。

这假设在特定引入序列中的弱依赖类型，与用于解密相关序列的算法（或密钥）类型之间存在映射。该映射可以设置得足够宽松，使得即使是母公司也无法完全解密，但有助于检索部分数据，例如序列的来源：在这种情况下，依赖类型充当签名的代理。只需添加一些额外的位，使序列具有所需的统计行为。

具有讽刺意味的是，你需要一个非常优秀、工业级的**伪随机数生成器**（PRNG）来生成几乎完美的随机序列。不够好的 PRNG——例如**梅森旋转算法**——可能引入不规则性，从而干扰你想引入的那些不规则性。这在第 [11](#Chp011_203-228_B9780443218576000151.xhtml) 章关于 PRNG 的内容中有详细讨论。

#### 12.1.2.2 生成准随机序列的算法

生成此类序列的一种方法如下：

```
S = 0
For n = 1, 2, …
    Generate random deviate U on [0, 1]
    M = g(n)
    If (S < -M and U < 1/2 - ε) or (S > M and U < 1/2 + ε) or (|S| ≤ M and U < 1/2)
    Then
        X[n] = -1
    Else
        X[n] = 1
    S = S + X[n]
    S[n] = S
```

这里 `$0 < \epsilon < \frac{1}{2}$` 和 `α > 0`。函数 `g(n)` 为正且增长速度慢于 `$\sqrt{n}`$。通常，`g(n) = α n^β` 其中 `$0 \leqslant \beta \leqslant \frac{1}{2}`$，或 `g(n) = α (log n)^β` 其中 `β ≥ 0`。第 [12.3.2](#Chp012_229-241_B9780443218576000163.xhtml#s0070) 节中的 Python 代码执行此模拟：选择选项 `deviations='Small'`。你可以自定义函数 `g(n`)，在代码中表示为 `G`。选项 `mode='Power'` 对应 `g(n) = α n^β`，而 `mode='Log'` 对应 `g(n) = α (log n)^β`。

结果显示在[图 12.1](#Chp012_229-241_B9780443218576000163.xhtml#f0010)中。配色方案如下：

*   灰色曲线：`ϵ = 0`，对应纯随机游走。
*   蓝色曲线：`g(n) = log n`, `ϵ = 0.05`。
*   红色曲线：`g(n) = n^β` 其中 `β = 0.35`, `ϵ = 0.05`。

黄色曲线代表一种截然不同的过程，在第 [12.1.3](#Chp012_229-241_B9780443218576000163.xhtml#s0040) 节中讨论。

#### 12.1.2.3 修正随机游走的方差

第 [12.1.2.2](#Chp012_229-241_B9780443218576000163.xhtml#s0030) 节中定义的修正随机游走 `S[n]` 的对称性质导致了几个恒等式。令 `p[n](m) = P(S[n] = m)`，其中 `-n ≤ m ≤ n`。此外，令 `S[0] = 0` 和 `p[0](0) = 1`。然后可以使用帕斯卡三角递推的某个修正版本来递归计算 `p[n](m)`：

$$
p_{n + 1}(m) = \left\lbrack \frac{1}{2} + \epsilon \cdot A_{n}(m - 1) \right\rbrack p_{n}(m - 1) + \left\lbrack \frac{1}{2} - \epsilon \cdot A_{n}(m + 1) \right\rbrack p_{n}(m + 1),
$$
(12.2)

其中 `A[n](m) = χ[m < -g(n)] - χ[m > g(n)]`。这里 `χ` 是指示函数：如果 `ω` 为真，则 `χ(ω) = 1`，否则 `χ(ω) = 0`。相关的一些恒等式包括：

$$
\sum\limits_{m = - n}^{n}m \cdot p_{n}(m) = E\lbrack S_{n}\rbrack = 0,\quad\sum\limits_{m = - n}^{n}A_{n}(m)p_{n}(m) = 0,\quad\sum\limits_{m = - n}^{n}m^{2}A_{n}(m)p_{n}(m) = 0,\sum\limits_{m = - n}^{n}m^{2}\left\lbrack A_{n - 1}(m - 1)p_{n - 1}(m - 1) + A_{n - 1}(m + 1)p_{n - 1}(m + 1) \right\rbrack = 0.
$$

从这些恒等式中，很容易建立方差的递推公式：

$$
{Var}\lbrack S_{n + 1}\rbrack = {Var}\lbrack S_{n}\rbrack + 1 - \delta_{n},\quad\text{with~}\delta_{n} = 8\epsilon \cdot \sum\limits_{m > g(n)}m \cdot p_{n}(m).
$$
(12.3)
