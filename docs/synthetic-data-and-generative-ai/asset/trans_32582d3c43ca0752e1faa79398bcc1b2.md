
# 16.1 扰动晶格：定义与性质

相关过程被称为`perturbed lattices`，此处称为`Poisson–binomial processes`，原因很快将变得显而易见。它既不同于`Poisson`过程，也不同于`binomial`过程。本章涵盖更高级的材料，特别是涉及统计学和概率论方面的内容。大多数数学推导（如定理）仅提及而不给出证明。有兴趣的读者可参考[\[20\]](#Chp016_293-327_B9780443218576000205.xhtml#br0100)了解详情。重点仍然在于数据驱动推断、经验分布、`quantile functions`（概率分布的逆函数）以及推断技术，包括一种新的独立性检验。本文讨论的主题包括二维聚类过程、`nearest neighbor`图、基于晶格的结构、统计推断，以及一种简单的替代方案，可替代通常用于`generative adversarial models` (GAN) 的`Gaussian mixture models` (GMM)。近年来，`perturbed-lattice point processes`引起了相当大的兴趣，参见[\[34\]](#Chp016_293-327_B9780443218576000205.xhtml#br0170)，[\[38\]](#Chp016_293-327_B9780443218576000205.xhtml#br0190)。

随机扰动晶格此处称为`Poisson–binomial processes`。它们基于晶格结构和概率分布的位置-尺度族。它们的特征在于任意不重叠集合中点计数的联合分布，或`nearest neighbor`点之间距离的分布。在一维情况下，后者称为`interarrival times`，而前者（点计数）具有联合`Poisson–binomial distribution`。类似地，最近邻距离具有联合`Poisson–exponential distribution`。在一维情况下，点过程是一个时间序列。

底层晶格是无限二维方格网格[[Wiki](https://en.wikipedia.org/wiki/Square_tiling)]，方格面积为`λ²`，晶格位置（即`vertices`）具有整数坐标。参数`λ > 0`称为过程的`intensity`：它决定了单位面积内的平均点数。对于晶格上的每个位置`(h, k)`，我们关联一个随机变量`(X[h], Y[k])`，它表示附着在顶点`(h, k)`上的随机点的坐标，其中`h, k ∈ ℤ`。随机变量`(X[h], Y[k])`独立分布，其分布`F[s]`取决于一个称为`scale`的参数`s`。更具体地说，我们有

```math
P[(X_h, Y_k) < (x, y)] = F_s((λx - h)/λ) F_s((λy - k)/λ) = F((x - h/λ)/s) F((y - k/λ)/s).
```
(16.1)

一个类似于`central limit theorem`的基本结果是：当`s → ∞`时，该过程收敛到强度为`λ²`的齐次`Poisson process`[[Wiki](https://en.wikipedia.org/wiki/Poisson_point_process)]。证明见[\[20\]](#Chp016_293-327_B9780443218576000205.xhtml#br0100)。即使`s ≈ 20`，近似效果也非常好。相反，如果`s = 0`，点`(X[h], Y[k])`与底层晶格的固定位置`(h, k)`重合。通常，晶格位置是未知且不易恢复的：晶格扮演着确定性`hidden process`的角色。所有这些内容，包括推广到球面晶格、六方晶格，或用随机线替换随机点，均在我的著作[\[20\]](#Chp016_293-327_B9780443218576000205.xhtml#br0100)中讨论。

通过分位数函数易于模拟的`F`的典型选择有

```math
Uniform: F(x) = 1/2 + x/2 if -1 ≤ x ≤ 1, with F(x) = 1 if x > 1 and F(x) = 0 if x < -1
Laplace: F(x) = 1/2 + 1/2 sgn(x)(1 + exp(-|x|))
Logistic: F(x) = 1/(1 + exp(-x))
Cauchy: F(x) = 1/2 + 1/π arctan(x)
```

其中`sgn(x)`是符号函数[[Wiki](https://en.wikipedia.org/wiki/Sign_function)]，满足`sgn(0) = 0`。[表 16.1](#Chp016_293-327_B9780443218576000205.xhtml#t0010) 建立了缩放因子`s`与`F[s]`方差之间的联系。

## 表 16.1：`F[s]` 的方差，作为 `s` 的函数。

| `F` | Uniform | Logistic | Laplace | Cauchy | Gaussian |
| --- | --- | --- | --- | --- | --- |
| `Var[F[s]]` | `s²/3` | `π²s²/3` | `2s²` | `∞` | `s²` |

## 16.1.1 点计数分布

设`B = [a, b] × [c, d]`定义一个矩形，其中`a < b`，`c < d`，且`p[h, k] = P[(X[h], Y[k]) ∈ B]`。我们有

```math
p_{h,k} = [F((b - h/λ)/s) - F((a - h/λ)/s)] · [F((d - k/λ)/s) - F((c - k/λ)/s)].
```
(16.2)

因此，计算集合`B`中过程点数的整值随机变量`N(B)`，称为`counting measure`[[Wiki](https://en.wikipedia.org/wiki/Counting_measure)]或点计数，具有参数为`p[h, k]`（其中`h, k ∈ ℤ`）的`Poisson–binomial distribution`[[Wiki](https://en.wikipedia.org/wiki/Poisson_binomial_distribution)]。与标准`Poisson–binomial distribution`的唯一区别在于，这里我们有无限多个参数（即`p[h, k]`）。该分布的基本性质给出

```math
E[N(B)] = Σ_{h,k=-∞}^{∞} p_{h,k},
```
(16.3)

```math
Var[N(B)] = Σ_{h,k=-∞}^{∞} p_{h,k}(1 - p_{h,k}),
```
(16.4)

```math
P[N(B) = 0] = Π_{h,k=-∞}^{∞} (1 - p_{h,k}),
```
(16.5)

```math
P[N(B) = 1] = { Π_{h,k=-∞}^{∞} (1 - p_{h,k}) } · Σ_{h,k=-∞}^{∞} p_{h,k}/(1 - p_{h,k}).
```
(16.6)
