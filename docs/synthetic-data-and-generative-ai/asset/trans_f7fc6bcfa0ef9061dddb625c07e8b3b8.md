## 15.1 简介

该项目始于尝试为天文学中的**三体问题** [[维基百科](https://en.wikipedia.org/wiki/Three-body_problem)] 生成模拟：研究三个天体在引力相互作用下的轨道。网上有许多演示，经过一番研究，我对 Philip Mocz 版本的 *N*\-体问题产生了兴趣：即涉及任意数量天体的推广。本章中这些天体被称为恒星。Philip 是劳伦斯利弗莫尔国家实验室的计算物理学家，拥有哈佛大学天体物理学博士学位。他的模拟 Python 代码可在[这里](https://github.com/pmocz/nbody-python)找到。

我的模拟基于他的代码，并进行了大幅升级。最终结果是三星系问题：每个包含数百颗恒星的小星团，因单个恒星的引力而合并。它模拟了星系合并。此外，我加入了诞生过程，不断生成新恒星。我还允许恒星碰撞，导致恒星随时间变少但变大。最后，我的模拟允许负质量恒星，以及不同于经典**逆平方定律** [[维基百科](https://en.wikipedia.org/wiki/Inverse-square_law)] 的非寻常引力定律。

这些奇异宇宙产生了壮观的数据动画（MP4 视频），但或许更重要的是，它们可能有助于解释导致宇宙膨胀的原因，包括随时间推移的不同压缩和膨胀阶段。取决于初始配置，可能出现截然不同的结果。负质量，以质量绝对值为基础的星团质心而引力基于带符号质量，可能导致不同的宇宙模型。许多已知现象，如流浪恒星以极高速度逃离星团、黑洞和双星形成、恒星丝状结构、星团随时间变得能量减弱（膨胀减缓、速度变小），在我的视频中均清晰可见。恒星碰撞引出一个有趣的图问题。

实现采用牛顿万有引力定律的离散近似。基于椭圆轨道但不符合我们宇宙定律的早期版本见第 [4.3.1](#Chp004_61-82_B9780443218576000084.xhtml) 节。其他壮观的轨道可视化，虽被比作三体问题，实则与数论中的黎曼假设相关，见第 [4.3.3](#Chp004_61-82_B9780443218576000084.xhtml) 节。关于 3D 可视化，见[这里](https://towardsdatascience.com/modelling-the-three-body-problem-in-classical-mechanics-using-python-9dc270ad7767)。本章模拟为 2D，对应于三个二维平面之一的投影。

## 15.2 模型参数与模拟结果

视频中呈现的演化恒星系统从初始配置开始，包含恒星的位置、速度和质量。这些向量存储在 Python 代码的三个 numpy 数组中，名为 `pos`、`vel` 和 `mass`，每颗恒星对应一个条目。位置和速度有三个分量，对应 X、Y 和 Z 轴。初始值随机生成。典型视频需要约十亿个伪随机数。因此使用优质的伪随机数生成器（PRNG）至关重要。如何为 Python PRNG——梅森旋转算法——选择良好的种子，在第 [11](#Chp011_203-228_B9780443218576000151.xhtml) 章讨论。
