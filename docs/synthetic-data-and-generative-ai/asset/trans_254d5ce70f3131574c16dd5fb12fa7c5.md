
其中 `∇θ`![Image](images/B9780443218576000059/si57.png) 是关于 `θ` 的梯度算子 [[维基百科](https://en.wikipedia.org/wiki/Gradient)]，而 `λ` 称为**拉格朗日乘数** [[维基百科](https://en.wikipedia.org/wiki/Lagrange_multiplier)]。这是一个经典的约束凸优化问题。公式 [(1.2)](#Chp001_1-34_B9780443218576000059.xhtml#deq2) 的上半部分由 `d + 1`![Image](images/B9780443218576000059/si40.png) 个方程组成，包含 `d + 2`![Image](images/B9780443218576000059/si53.png) 个未知数 `θ[0]`，…，`θ[d]`![Image](images/B9780443218576000059/si58.png) 和 `λ`。下半部分是一个包含 `d + 1`![Image](images/B9780443218576000059/si40.png) 个未知数 `θ[0]`，…，`θ[d]`![Image](images/B9780443218576000059/si58.png) 的单个方程。将它们结合在一起，构成了一个包含 `d + 2`![Image](images/B9780443218576000059/si53.png) 个方程和 `d + 2`![Image](images/B9780443218576000059/si53.png) 个未知数的方程组。请注意当 `η(θ) = θ^T θ − 1`![Image](images/B9780443218576000059/si43.png) 时，即 `θ^T θ = 1`![Image](images/B9780443218576000059/si59.png) 时，与**套索回归** [[维基百科](https://en.wikipedia.org/wiki/Lasso_\(statistics\))] 的类比。

相对于特定 `θ` 的**均方误差**（MSE）定义为

$$
\text{MSE}(\theta) = \frac{1}{n}\sum\limits_{k = 1}^{n}g^{2}(W_{k},\theta) \geqslant \text{MSE}(\theta^{\ast}).
$$

![Image](images/B9780443218576000059/si60.png)(1.3)

现在定义关于 `θ` 的 R 平方为

$$
R^{2}(\theta) = 1 - \frac{\text{MSE}(\theta^{\ast})}{\text{MSE}(\theta)}.
$$

![Image](images/B9780443218576000059/si61.png)(1.4)

立即可得 `0 ≤ R²(θ) ≤ 1`![Image](images/B9780443218576000059/si62.png)。完美拟合对应 `MSE(θ*) = 0`![Image](images/B9780443218576000059/si63.png)（整个点云位于形状上）。在这种情况下，如果 `θ ≠ θ*`![Image](images/B9780443218576000059/si64.png) 且最优 `θ*`![Image](images/B9780443218576000059/si10.png) 是唯一的，则 `R²(θ) = 1`![Image](images/B9780443218576000059/si65.png)。

在传统线性回归中，R 平方定义为 `R²(θ*)`![Image](images/B9780443218576000059/si66.png)，其中 `θ*`![Image](images/B9780443218576000059/si67.png) 是基础模型的最优 `θ`。基础模型对应于除截距项对应的系数外，所有连接自变量的系数 `θ[i]`![Image](images/B9780443218576000059/si68.png) 均设为零。换句话说，在基础模型中，预测的 `Y` 是常数，等于 `Y` 的经验均值。结果，`MSE(θ*) = Var[Y]`![Image](images/B9780443218576000059/si69.png)，即 `Y` 的经验方差。一个结果是 `R²(θ*)`![Image](images/B9780443218576000059/si66.png) 是观测响应 `Y` 与全模型预测响应之间相关系数的平方。

与传统线性回归的向后兼容性如下所示。标准单变量回归对应于 `g(w, θ) = wθ = θ[0]y + θ[1]x + θ[2]`![Image](images/B9780443218576000059/si70.png)，约束条件为 `θ[0] = −1`![Image](images/B9780443218576000059/si17.png)。因此 `g(w, θ) = 0`![Image](images/B9780443218576000059/si12.png) 当且仅当 `y = θ[1]x + θ[2]`![Image](images/B9780443218576000059/si71.png)。这也推广到多元回归。新方法中一种更优雅的表述是用对称约束 `θ[0]² + θ[1]² + θ[2]² = 1`![Image](images/B9780443218576000059/si72.png) 替换约束 `θ[0] = −1`![Image](images/B9780443218576000059/si17.png)。注意 `w` 是行向量，`θ` 是列向量。

### 1.2.2 模型升级

所谓模型，是指方法的一般设置：本讨论不涉及概率模型。可以通过重采样和自助法 [[维基百科](https://en.wikipedia.org/wiki/Bootstrapping_\(statistics\))] 获得每个数据点 `W[k]`![Image](images/B9780443218576000059/si74.png) 处个体误差 `g(W[k], θ*)`![Image](images/B9780443218576000059/si73.png) 的**预测区间** [[维基百科](https://en.wikipedia.org/wiki/Prediction_interval)]（或针对连接到 `Y[k]`![Image](images/B9780443218576000059/si75.png) 的估计响应，如果存在自变量），以及 `θ*`![Image](images/B9780443218576000059/si10.png) 的**置信区域** [[维基百科](https://en.wikipedia.org/wiki/Confidence_region)]。对于训练集外的点也是如此。

此外，平方项可以替换为绝对值，如**分位数回归** [[维基百科](https://en.wikipedia.org/wiki/Quantile_regression)] 所示，以最小化异常值的影响并保持尺度不变性：如果变量以年为单位测量，则平方以平方年为单位，这是一个无意义的度量。这导致了一个修正后的、更好的度量来评估拟合质量，取代 R 平方。请参阅第 [7](#Chp007_113-129_B9780443218576000114.xhtml) 章第 [7.4](#Chp007_113-129_B9780443218576000114.xhtml) 节关于“性能评估”的内容，了解 R 平方的替代方案。拟合优度（例如 R 平方）应在验证集 [[维基百科](https://en.wikipedia.org/wiki/Training,_validation,_and_test_data_sets)] 上测量，即使 `θ*`![Image](images/B9780443218576000059/si10.png) 是在训练集的一个子集上计算的：这是一种标准做法，称为交叉验证 [[维基百科](https://en.wikipedia.org/wiki/Cross-validation_\(statistics\))]，在第 [8](#Chp008_131-145_B9780443218576000126.xhtml) 章关于模糊回归的内容中通过合成数据进行了说明。

现在，让我们回到 R 平方。在标准线性回归中，R 平方通过公式 [(1.4)](#Chp001_1-34_B9780443218576000059.xhtml#deq4) 定义为 `R²(θ*)`![Image](images/B9780443218576000059/si66.png)，其中 `θ*`![Image](images/B9780443218576000059/si67.png) 是基础模型的最优 `θ`（基础模型的预测响应为常数，等于 `Y` 的均值）。在新方法中，可能不存在响应变量。尽管如此，`R²`![Image](images/B9780443218576000059/si76.png) 的定义扩展到了这种情况，并与传统版本兼容。更重要的是，它导致了许多可能的 `R²`![Image](images/B9780443218576000059/si76.png)，每个子模型对应一个（不仅仅是基础模型），这对于标准回归也同样适用。子模型对应于在参数向量 `θ` 上添加约束，或者换句话说，在参数空间的一个子集上工作。令 `θ*`![Image](images/B9780443218576000059/si67.png) 为特定子模型的最优解，而 `θ*`![Image](images/B9780443218576000059/si10.png) 为全模型的最优解。那么取决于 `θ*`![Image](images/B9780443218576000059/si67.png) 的 `R²`![Image](images/B9780443218576000059/si76.png) 定义保持不变。这再简单不过了！
