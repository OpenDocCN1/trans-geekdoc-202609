If `f` is known only for integer values or we are dealing with a data set, the integral is replaced by a sum, and `D` is the discrete set of interpolation nodes (the integers), or the set of observed features in case of a data set. It is convenient to introduce the following notations:

`β[k] = ∫[D] p[k](x) f(x) dx`, `γ[k] = ∫[D] p[k]²(x) dx`, `β[ij] = ∫[D] p[i](x) p[j](x) dx`.

Then we have `α[0] = β[0]/γ[0]`![Image](images/B9780443218576000138/si101.png) and for `n > 0`![Image](images/B9780443218576000138/si102.png),

$$
\alpha_n = \frac{1}{\gamma_n}\left\lbrack \beta_n - \sum_{k=0}^{n-1} \alpha_k \beta_{kn} \right\rbrack.
$$

### 9.2.2 Using orthogonal functions

If the coefficients `β[ij]`![Image](images/B9780443218576000138/si104.png) are all zero, the formulas considerably simplify. This is the case if (`p[k]`)![Image](images/B9780443218576000138/si105.png) is a sequence of **orthogonal functions** [[Wiki](https://en.wikipedia.org/wiki/Orthogonal_functions)]. The most well-known example is `p[2k](x) = cos(kπx/L)`![Image](images/B9780443218576000138/si106.png) combined with `p[2k+1](x) = sin(kπx/L)`![Image](images/B9780443218576000138/si107.png) for `k = 0, 1`![Image](images/B9780443218576000138/si108.png), and so on. If `D = [-L, L]`![Image](images/B9780443218576000138/si109.png), it corresponds to approximating or interpolating a periodic function `f` on `D` using its **Fourier series** [[Wiki](https://en.wikipedia.org/wiki/Fourier_series)]. In this case, `γ[k] = L`![Image](images/B9780443218576000138/si110.png) if `k > 0`![Image](images/B9780443218576000138/si111.png), with `γ[0] = 2L`![Image](images/B9780443218576000138/si112.png).

Unfortunately, the polynomials `p[x](x) = x^(k)`![Image](images/B9780443218576000138/si113.png) are not orthogonal on any interval. However, there is a process called **Gram–Schmidt orthogonalization** [[Wiki](https://en.wikipedia.org/wiki/Gram%E2%80%93Schmidt_process)] that turns any sequence of linearly independent functions into orthogonal ones. When applied to `1, x, x², x³`![Image](images/B9780443218576000138/si114.png), and so on, it leads to **Legendre polynomials** [[Wiki](https://en.wikipedia.org/wiki/Legendre_polynomials)] for the `p[k](x)`![Image](images/B9780443218576000138/si93.png)'s. They are orthogonal on `D = [-1, 1]`![Image](images/B9780443218576000138/si115.png).

As usual, rather than minimizing the distance between `f` and `f[n]`![Image](images/B9780443218576000138/si98.png) in formula [(9.9)](#Chp009_147-168_B9780443218576000138.xhtml#deq11), it is possible to use a weighted distance. All the results can be adapted. In particular, many orthogonal functions involve a weight. For instance, the **Hermite polynomials** [[Wiki](https://en.wikipedia.org/wiki/Hermite_polynomials)] involve the weight `w(x) = exp(-x²/2)`![Image](images/B9780443218576000138/si116.png), and satisfy

```
∫[-∞]^∞ p[i](x) p[j](x) w(x) dx = 0 if i ≠ j.
```

![Image](images/B9780443218576000138/si117.png)

In this case, `D` is the entire real line, infinite in both directions. Finally, it is also possible to directly work with a discrete set `D` and **discrete orthogonal functions** [[Wiki](https://en.wikipedia.org/wiki/Discrete_orthogonal_polynomials)]. The integrals become sums as usual. The general framework related to all these concepts is the **Sturm–Liouville theory** [[Wiki](https://en.wikipedia.org/wiki/Sturm%E2%80%93Liouville_theory)].

### 9.2.3 Application to regression

You can apply the Fourier series method to multivariate regression as follows. It works best with continuous features. For discrete features, I advise to look at **discrete Fourier series** [[Wiki](https://en.wikipedia.org/wiki/Discrete_Fourier_series)] instead. You want to transform each continuous feature separately so that the values are – as closely as possible – distributed uniformly on the interval `[-1, 1]`![Image](images/B9780443218576000138/si118.png) after the transformation. This is accomplished in two steps: first apply the transformation `F[k]`![Image](images/B9780443218576000138/si119.png) to the `k`th component of the feature vector. Then apply the transformation `Q`. Do this for each component `k = 1, …, n`![Image](images/B9780443218576000138/si63.png). Here

- `F[k]`![Image](images/B9780443218576000138/si119.png) is the **empirical distribution function** [[Wiki](https://en.wikipedia.org/wiki/Empirical_distribution_function)] attached to feature `k`. In Python, use the function `ECDF()` from the `statsmodel` library.
- `Q` is the **quantile function** [[Wiki](https://en.wikipedia.org/wiki/Quantile_function)] of a uniform distribution on `[-1, 1]`![Image](images/B9780443218576000138/si118.png). Thus `Q(u) = -1 + 2u`![Image](images/B9780443218576000138/si120.png).

Now use formula [(9.8)](#Chp009_147-168_B9780443218576000138.xhtml#deq10) on the transformed data, with the `p[k]`![Image](images/B9780443218576000138/si121.png) and `α[k]`![Image](images/B9780443218576000138/si122.png) from the first paragraph in Section [9.2.2](#Chp009_147-168_B9780443218576000138.xhtml#s0045), together with `L = 1`![Image](images/B9780443218576000138/si123.png). Note that there is no matrix inversion in this procedure. It is a particular type of **spline regression** [[Wiki](https://en.wikipedia.org/wiki/Multivariate_adaptive_regression_spline)]. See Python code in Section [9.3.3](#Chp009_147-168_B9780443218576000138.xhtml#s0070). For a different type of spline regression based on exact interpolation similar to the method discussed in Section [9.1.3](#Chp009_147-168_B9780443218576000138.xhtml#s0025), see Chapter [8](#Chp008_131-145_B9780443218576000126.xhtml).

For polynomial regression, use Legendre polynomials, after transforming the features so that values stay within `[-1, 1]`![Image](images/B9780443218576000138/si118.png), and uniformly distributed. Again, there is no matrix inversion and the procedure is fast and simple. For another example of regression with Legendre polynomials, see [[3]](#Chp009_147-168_B9780443218576000138.xhtml#br0015).

The methods presented here have their roots in interpolating math functions, where successive terms in the summation formula – in this case formula [(9.8)](#Chp009_147-168_B9780443218576000138.xhtml#deq10) – have on average a decreasing impact. Otherwise, the sum, usually involving an infinite number of terms, would not converge. So it makes sense to order the features by decreasing importance. The first feature with coefficient `α[1]`![Image](images/B9780443218576000138/si124.png) may be chosen as that with least residual error. The second feature with coefficient `α[2]`![Image](images/B9780443218576000138/si125.png) being the one yielding the best improvement to the residual error, and so on.

Also, for the same reason, in multivariate regression, the method is suited for data sets with a large `n` (number of features) well approximated by model [(9.8)](#Chp009_147-168_B9780443218576000138.xhtml#deq10), even with a small number of observations, see [[4]](#Chp009_147-168_B9780443218576000138.xhtml#br0020). Such data sets are sometimes referred to as **wide data**. A more general version uses **multidimensional Fourier series** [[2]](#Chp009_147-168_B9780443218576000138.xhtml#br0010).
