
for some constant `C` with 0 < `C` < ∞![Image](images/B9780443218576000217/si123.png). But the prime numbers are not perfectly random, and one would expect `$\sqrt{n\log\log n}$`![Image](images/B9780443218576000217/si284.png) to be replaced by (say) `$\sqrt{n^{1 + \epsilon}}$`![Image](images/B9780443218576000217/si285.png) for any arbitrary small `ϵ` > 0![Image](images/B9780443218576000217/si126.png). This may be the case in the deterministic example where `χ(p)` = +1![Image](images/B9780443218576000217/si286.png) if `p` ≡ 1 `mod` 4![Image](images/B9780443218576000217/si225.png) and `χ(p)` = −1![Image](images/B9780443218576000217/si287.png) if `p` ≡ 3 `mod` 4![Image](images/B9780443218576000217/si227.png). One way to make the random Euler product more realistic is to introduce weak dependencies among the `χ(p)`![Image](images/B9780443218576000217/si3.png)'s. Then one can test whether the improved stochastic model (with weak dependencies) is a better fit to the observed data – the actual `χ(p)`![Image](images/B9780443218576000217/si3.png)'s. The weak dependencies can be introduced as follows, when simulating `χ(p[n + 1])`![Image](images/B9780443218576000217/si288.png) for `n` large enough:

- If `$|L_{\chi}(n)| < \beta\sqrt{n{(\log\log\log n)}^{\nu}}$`![Image](images/B9780443218576000217/si289.png), then `$P\lbrack\chi(p_{n + 1}) = 1\rbrack = \frac{1}{2} + \mu n^{- \alpha}$`![Image](images/B9780443218576000217/si290.png), `$P\lbrack\chi(p_{n + 1}) = - 1\rbrack = \frac{1}{2} - \mu n^{- \alpha}$`![Image](images/B9780443218576000217/si291.png).
- Otherwise choose between +1 and −1 so that `|L[χ](n + 1)| < |L[χ](n)|`![Image](images/B9780443218576000217/si292.png).

You may try with various values of `α`, `β`, `ν` > 0![Image](images/B9780443218576000217/si293.png) and `μ` to see which ones provide the best fit for very large `n`, say `n` > 10^(15)![Image](images/B9780443218576000217/si294.png). You could also change the sign of `μ` every now and then. The choice of `log log log n`![Image](images/B9780443218576000217/si295.png) is inspired by Gonek's conjecture; see [[14]](#Chp017_329-360_B9780443218576000217.xhtml#br0070) page 29.

Finally, another random Euler product also investigated in [[15]](#Chp017_329-360_B9780443218576000217.xhtml#br0075) is the following:

```
\rho^{2} = \prod\limits_{p \in P}\frac{1}{1 - 2p^{- \sigma}\cos(\Theta_{p}) + p^{- 2\sigma}}.
```

![Image](images/B9780443218576000217/si296.png)(17.16)

Here the `Θ[p]`![Image](images/B9780443218576000217/si297.png)'s are independent uniform deviates on [0, 2`π`]![Image](images/B9780443218576000217/si298.png). Compare this to formula [(17.14)](#Chp017_329-360_B9780443218576000217.xhtml#deq24). Since

```
\frac{1}{2\pi}\int_{0}^{2\pi}\frac{1}{1 - 2p^{- \sigma}\cos\theta + p^{- 2\sigma}}d\theta = \frac{1}{1 - p^{- 2\sigma}},
```

![Image](images/B9780443218576000217/si299.png)

we have

```
\text{E}\lbrack\rho^{2}\rbrack = \prod\limits_{p \in P}\text{E}\left\lbrack \frac{1}{1 - 2p^{- \sigma}\cos(\Theta_{p}) + p^{- 2\sigma}} \right\rbrack = \prod\limits_{p \in P}\frac{1}{1 - p^{- 2\sigma}} = L_{P}(2\sigma,\chi_{0}),
```

![Image](images/B9780443218576000217/si300.png)

where again, `χ[0](·)`![Image](images/B9780443218576000217/si275.png) is the constant function equal to 1. If `P` is the full set of primes, `L[P](2σ, χ[0])` = `ζ(2σ)`![Image](images/B9780443218576000217/si301.png). The proof that the distribution attached to `ρ²`![Image](images/B9780443218576000217/si276.png) exists and is not singular can be found in [[15]](#Chp017_329-360_B9780443218576000217.xhtml#br0075).

## 17.4 Exercises

The following exercises require out-of-the-box thinking. They complement the theory or provide a proof to some of the theoretical results discussed in this chapter.

### Exercise 17.1: Asymptotic formula

Prove the asymptotic formula [(17.2)](#Chp017_329-360_B9780443218576000217.xhtml#deq3).

#### Solution

By definition, we have `q[k]` = `p[1]^(a[1])` `p[2]^(a[2])` ⋯ `p[d]^(a[d])`![Image](images/B9780443218576000217/si67.png) for some positive integers `a[1]`, …, `a[d]`![Image](images/B9780443218576000217/si302.png). In other words, `a[1] log p[1]` + … + `a[d] log p[d]` = `log q[k]`![Image](images/B9780443218576000217/si303.png). This is the equation of a (`d` − 1)![Image](images/B9780443218576000217/si304.png)-dimensional simplex with vertices (`log p[1]`, 0, …, 0)![Image](images/B9780443218576000217/si305.png), (0, `log p[2]`, …, 0), …, (0, 0, …, `log p[d]`)![Image](images/B9780443218576000217/si306.png). If you add the origin as a vertex, then the number of points `v[k]`![Image](images/B9780443218576000217/si307.png) with integer coordinates, inside the newly created `d`-dimensional simplex, is approximately equal to the volume `V[k]`![Image](images/B9780443218576000217/si308.png) of that `simplex` [[Wiki](https://en.wikipedia.org/wiki/Simplex#Volume)]. Also, `v[k]`![Image](images/B9780443218576000217/si307.png) is the number of positive integers less than or equal to `q[k]`![Image](images/B9780443218576000217/si43.png), since each integer has a unique factorization in (ordered) prime numbers. So, `q[k]`![Image](images/B9780443218576000217/si43.png) is the inverse of the function `v[k]`![Image](images/B9780443218576000217/si307.png), which is asymptotically equal to the inverse of `V[k]`![Image](images/B9780443218576000217/si308.png). To complete the proof, use the well known fact that

```
V_{k} = \frac{1}{d!}\left( \log q_{k} \right)^{d}\prod\limits_{p \in P}\frac{1}{\log p} = \frac{1}{d!}\prod\limits_{p \in P}\log_{p}q_{k},
```

![Image](images/B9780443218576000217/si309.png)

where `log[p]`![Image](images/B9780443218576000217/si310.png) stands for the logarithm in base `p`. The result is easy to verify if `d` = 1![Image](images/B9780443218576000217/si311.png).

### Exercise 17.2: Equivalence between series and Euler product

Prove formula [(17.1)](#Chp017_329-360_B9780443218576000217.xhtml#deq2).

#### Solution

Expanding the product in formula [(17.1)](#Chp017_329-360_B9780443218576000217.xhtml#deq2), one obtains

```
\prod\limits_{p \in P}\frac{1}{1 - p^{- z}} = \prod\limits_{p \in P}\left( 1 + p^{- z} + p^{- 2z} + \cdots \right) = \sum\limits_{a_{1},a_{2},\ldots,a_{d}}\left( p_{1}^{a_{1}}p_{2}^{a_{2}}\cdots p_{d}^{a_{d}} \right)^{- z} = \sum\limits_{k = 1}^{\infty}q_{k}^{- z}.
```

![Image](images/B9780443218576000217/si312.png)

Let us denote the rightmost series in the above equation as `ζ[P](z)`![Image](images/B9780443218576000217/si313.png). To complete the proof, use the fact that

```
\sum\limits_{k = 1}^{\infty}\delta_{k}q_{k}^{- z} = \zeta_{P}(z) - 2\sum\limits_{q_{k}\text{~even}}q_{k}^{- z} = \zeta_{P}(z) - 2\sum\limits_{k = 1}^{\infty}{(2q_{k})}^{- z} = (1 - 2^{1 - z})\zeta_{P}(z).
```

![Image](images/B9780443218576000217/si314.png)

Another interesting identity is the following:

```
(1 - 2^{1 - z})\prod\limits_{p \in P}\frac{1}{1 + p^{- z}} = (1 - 2^{1 - z})\frac{\zeta_{P}(2z)}{\zeta_{p}(z)} = \sum\limits_{k = 1}^{\infty}\delta_{k}\lambda(q_{k})q_{k}^{- z},
```

![Image](images/B9780443218576000217/si315.png)

where `λ(·)`![Image](images/B9780443218576000217/si116.png) is the `Liouville function` [[Wiki](https://en.wikipedia.org/wiki/Liouville_function)].

### Exercise 17.3: Convergence problem

If `P` is the set of all primes and `δ[k]`![Image](images/B9780443218576000217/si316.png) is replaced by +1, then the series in formula [(17.1)](#Chp017_329-360_B9780443218576000217.xhtml#deq2) will not converge if `σ` < 1![Image](images/B9780443218576000217/si9.png). Here, `z` = `σ` + `it`![Image](images/B9780443218576000217/si2.png). That is, `σ` is the real part of the complex number `z`.

#### Solution
