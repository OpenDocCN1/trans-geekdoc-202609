## 17.1 介绍

设 `z = σ + i t`![Image](images/B9780443218576000217/si2.png) 为复数：`σ` 为实部，`t` 为虚部。设 `P` 为一组数，称为素数：`P` 的元素不能分解为 `P` 中元素的乘积。在某种意义上，数之于分子，犹如素数之于原子。通常但不总是，`P` 是所有素数的标准集合，或其子集（有限或无限均可）。最后，`p` 代表 `P` 的一个元素，`χ(p)`![Image](images/B9780443218576000217/si3.png) 是任何取两个可能值的函数：根据 `p` 取 +1 或 −1。函数 `χ(·)`![Image](images/B9780443218576000217/si4.png) 利用公式 `χ(ab) = χ(a)χ(b)`![Image](images/B9780443218576000217/si5.png) 扩展到 `P` 之外，其中 `χ(1) = 1`![Image](images/B9780443218576000217/si6.png)。

本章总结了关于 `z` 的各种函数的已知性质和猜想，这些函数可以用以下乘积表示，称为欧拉乘积：

```
\prod_{p \in P} \frac{1}{1 - \chi(p) p^{-z}}.
```

![Image](images/B9780443218576000217/si7.png)

最著名的例子是函数 `χ(·)`![Image](images/B9780443218576000217/si4.png) 为常数（因此等于 1）且 `P` 为全体素数整数的集合：这对应于黎曼zeta函数 `ζ(z)`![Image](images/B9780443218576000217/si8.png)。当展开为级数时，欧拉乘积变成所谓的狄利克雷级数。级数和乘积可能不在同一域上收敛；当级数**条件收敛**但非**绝对收敛** [[Wiki](https://en.wikipedia.org/wiki/Absolute_convergence)] 时，乘积可能发散。这通常发生在 `σ < 1`![Image](images/B9780443218576000217/si9.png) 时。这是巨大困难的根源，也是广义黎曼假设（GRH）至今未被证明的原因。这也解释了为什么所有活动都发生在 `1/2 ≤ σ < 1`![Image](images/B9780443218576000217/si10.png) 时。

我不会在此详细讨论复分析。只需知道如果 `z = σ + i t`![Image](images/B9780443218576000217/si2.png)，则 `p^{-z} = exp(-z log p) = p^{-σ} cos(t log p) - i p^{-σ} sin(t log p)`![Image](images/B9780443218576000217/si11.png)。此外，欧拉乘积中的因子按 `p` 的值递增排序。如果没有这一规定，当收敛是条件而非绝对时，该乘积可能有多种不同值的解释。关于黎曼zeta函数和狄利克雷函数的介绍见 [[4]](#Chp017_329-360_B9780443218576000217.xhtml#br0020) 和 [[18]](#Chp017_329-360_B9780443218576000217.xhtml#br0090)。最后，我偶尔使用条件收敛或绝对收敛乘积这一术语。这一直观概念定义于[此处](https://encyclopediaofmath.org/wiki/Infinite_product)。
