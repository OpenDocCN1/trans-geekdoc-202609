# Exercise 17.8

## Roots of the Riemann zeta function

As usual, `z = σ + i t` ![Image](images/B9780443218576000217/si2.png). Let `S[0]` ![Image](images/B9780443218576000217/si413.png) be any open interval containing exactly one value `t[0]` ![Image](images/B9780443218576000217/si414.png) such that $\zeta(\frac{1}{2} + i t_0) = 0$ ![Image](images/B9780443218576000217/si415.png), and let `η(z)` ![Image](images/B9780443218576000217/si29.png) be the standard **Dirichlet eta function**. Discuss the existence (or not) of roots of `η(z)` ![Image](images/B9780443218576000217/si29.png) if `t ∈ S[0]` ![Image](images/B9780443218576000217/si416.png) and $\frac{1}{2} < \sigma < 1$ ![Image](images/B9780443218576000217/si20.png). Show how it works when `S[0] = ]199, 202[` ![Image](images/B9780443218576000217/si417.png). You can find a table of the first ![Image](images/B9780443218576000217/fx006.jpg) nontrivial roots of `ζ(z)` ![Image](images/B9780443218576000217/si8.png), [here](http://www.dtc.umn.edu/~odlyzko/zeta_tables/).

## Solution

Assume `σ` is fixed. Let `μ(σ)` ![Image](images/B9780443218576000217/si418.png) be the minimum of `|η(z)|` ![Image](images/B9780443218576000217/si419.png) if `t ∈ S[0]` ![Image](images/B9780443218576000217/si416.png), and let `τ(σ)` ![Image](images/B9780443218576000217/si420.png) be the value achieving the minimum. That is,

$$\mu(\sigma) = \min_{t \in S_0} |\eta(\sigma + it)|, \quad \tau(\sigma) = \underset{t\in S_0}{\arg\min} |\eta(\sigma + it)|.$$

![Image](images/B9780443218576000217/si421.png)

If `S[0] = ]199, 202[` ![Image](images/B9780443218576000217/si417.png) then `t[0] ≈ 201.26` ![Image](images/B9780443218576000217/si422.png). Let `t[0]' = 44π/log 2 ≈ 199.42` ![Image](images/B9780443218576000217/si423.png). We have `1 - 2^(1-z) = 0` ![Image](images/B9780443218576000217/si424.png) where `z = 1 + i t[0]'` ![Image](images/B9780443218576000217/si425.png), and:

- $\mu(\frac{1}{2}) = 0$ ![Image](images/B9780443218576000217/si426.png) and $\tau(\frac{1}{2}) = t_0$ ![Image](images/B9780443218576000217/si427.png) since $\eta(\frac{1}{2} + i t_0) = 0$ ![Image](images/B9780443218576000217/si428.png),
- `μ(1) = 0` ![Image](images/B9780443218576000217/si429.png) and `τ(1) = t[0]'` ![Image](images/B9780443218576000217/si430.png), since `η(1 + i t[0]') = 0` ![Image](images/B9780443218576000217/si431.png),
- `μ(σ)` ![Image](images/B9780443218576000217/si418.png) is strictly increasing and continuous if $\frac{1}{2} \leqslant \sigma \leqslant \sigma_0$ ![Image](images/B9780443218576000217/si432.png) with `σ[0] ≈ 0.75` ![Image](images/B9780443218576000217/si433.png),
- `μ(σ)` ![Image](images/B9780443218576000217/si418.png) is strictly decreasing and continuous if `σ[0] ≤ σ ≤ 1` ![Image](images/B9780443218576000217/si434.png).

In other words, `μ(σ)` ![Image](images/B9780443218576000217/si418.png) is convex. It seems to imply that there is no root if `t ∈ S[0]` ![Image](images/B9780443218576000217/si416.png) and $\frac{1}{2} < \sigma < 1$ ![Image](images/B9780443218576000217/si20.png). However, proving that `μ(σ)` ![Image](images/B9780443218576000217/si418.png) is increasing or decreasing, with only one change-point at some `σ[0]` ![Image](images/B9780443218576000217/si104.png) (depending on `S[0]` ![Image](images/B9780443218576000217/si413.png)), may be as hard as proving RH itself: it is based on empirical evidence only, and related to the (conjectured) absence of roots for the derivative of `ζ(z)` ![Image](images/B9780443218576000217/si8.png). Indeed, it is just a consequence of the Riemann Hypothesis, see [here](https://mathoverflow.net/questions/190802/zeros-of-the-derivative-of-riemanns-xi-function).

There is something particularly striking though, which could prove useful to make some progress: the function `τ(σ)` ![Image](images/B9780443218576000217/si420.png) is almost flat, with a single discontinuity at `σ[0]` ![Image](images/B9780443218576000217/si104.png). Indeed, `201.26 ≤ τ(σ) ≤ 201.29` ![Image](images/B9780443218576000217/si435.png) if $\frac{1}{2} \leqslant \sigma < \sigma_0$ ![Image](images/B9780443218576000217/si436.png), and `199.41 ≤ τ(σ) ≤ 199.42` ![Image](images/B9780443218576000217/si437.png) if `σ[0] < σ ≤ 1` ![Image](images/B9780443218576000217/si438.png). These variations are so small that you wonder if they are real, or caused by numerical imprecision (implying the function `τ(σ)` ![Image](images/B9780443218576000217/si420.png) could be perfectly flat with a single discontinuity, making it potentially easier to prove RH). If these variations really do exist, there might be a function other than `η(z)` ![Image](images/B9780443218576000217/si29.png) with the same roots, say a scaled version of `η(z)` ![Image](images/B9780443218576000217/si29.png) with a scaling factor free of roots, for which the variations are absent. Such a function may be easier to investigate.

More generally, the functions `μ(σ)` ![Image](images/B9780443218576000217/si418.png) and `τ(σ)` ![Image](images/B9780443218576000217/si420.png) have this same behavior whenever `S[0]` ![Image](images/B9780443218576000217/si413.png) contains a value `t[0]'` ![Image](images/B9780443218576000217/si439.png) such that `z = 1 + i t[0]'` ![Image](images/B9780443218576000217/si425.png) is a root of `1 - 2^(1-z)` ![Image](images/B9780443218576000217/si440.png), and therefore a root of `η(z)` ![Image](images/B9780443218576000217/si29.png). Because these roots are evenly spaced by the increment `2π/log 2` ![Image](images/B9780443218576000217/si441.png), and since the roots at $\sigma = \frac{1}{2}$ ![Image](images/B9780443218576000217/si24.png) are closer and closer to each other as `t → ∞` ![Image](images/B9780443218576000217/si357.png) (see [\[3](#Chp017_329-360_B9780443218576000217.xhtml#br0015),[17\]](#Chp017_329-360_B9780443218576000217.xhtml#br0085)), there is either one `t[0]'` ![Image](images/B9780443218576000217/si439.png) in `S[0]` ![Image](images/B9780443218576000217/si413.png), or none. There can't be more than one. When there is none, the situation is even easier and amounts to setting `σ[0] = ∞` ![Image](images/B9780443218576000217/si442.png), or at least `σ[0] > 1` ![Image](images/B9780443218576000217/si443.png).

Finally, if it was possible to prove the points discussed in this exercise, then, of course, RH would be proved. It suffices to consider the collection of all possible `S[0]` ![Image](images/B9780443218576000217/si413.png) to show that there would be no root anywhere, no matter how large `t` is, if $\frac{1}{2} < \sigma < 1$ ![Image](images/B9780443218576000217/si20.png).
