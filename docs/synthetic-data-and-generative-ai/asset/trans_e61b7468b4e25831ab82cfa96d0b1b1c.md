
$E\\lbrack\\exp( - itT^{\\ast})\\rbrack = \\frac{1}{1 + t^{2}} = E\\lbrack\\exp( - itZ\_{1})\\rbrack \\times E\\lbrack\\exp( - itZ\_{2})\\rbrack = \\left( E\\lbrack\\exp( - itZ\_{1})\\rbrack \\right)^{2}.$

![图片](images/B9780443218576000205/si333.png)

因此 `E`[`exp`( − `i` `t` `Z[1]`)] = (1 + `t`²)^( − 1/2)![图片](images/B9780443218576000205/si334.png)。对**傅里叶变换**取逆以获取 `Z[1]` 的密度![图片](images/B9780443218576000205/si335.png)，即依附于 `F` 的密度，可得

$f(x) = \\frac{1}{2\\pi}\\int\_{- \\infty}^{\\infty}\\frac{\\cos(tx)}{\\sqrt{1 + t^{2}}}dt = \\frac{1}{\\pi}K\_{0}(x),$

![图片](images/B9780443218576000205/si336.png)

其中 `K[0]`![图片](images/B9780443218576000205/si337.png) 是第二类修正**贝塞尔函数** [[Wiki](https://mathworld.wolfram.com/ModifiedBesselFunctionoftheSecondKind.xhtml)]。关于拉普拉斯分布及其推广的更多内容见 [[25]](#Chp016_293-327_B9780443218576000205.xhtml#br0125)。当 `T^*`![图片](images/B9780443218576000205/si330.png) 为高斯或柯西分布时情况较简单，因为这些分布属于**稳定分布族** [[Wiki](https://en.wikipedia.org/wiki/Stable_distribution)]：此时 `F` 分别为高斯或柯西分布。

### 16.4.5 记录观测点与其顶点之间的距离

[图 16.10](#Chp016_293-327_B9780443218576000205.xhtml#f0065) 展示了具有逻辑斯蒂 `F` 的泊松-二项过程的点 (`X[h]`, `Y[k]`)![图片](images/B9780443218576000205/si4.png)（蓝色）。它们的格点顶点 (`h/λ`, `k/λ`)![图片](images/B9780443218576000205/si96.png) 以小红叉显示。箭头连接两者。此处 `λ` = 1![图片](images/B9780443218576000205/si49.png)。这幅图显示了一个点距离其依附的**顶点**可以有多远。如果 `s` = 0![图片](images/B9780443218576000205/si10.png)，两个位置重合，但当 `s` 很大时，距离可以任意大。

![图 16.10 每个箭头将一个点（蓝色）连接到其顶点（红色）：s = 0.2（左），s = 1（右）。](images/B9780443218576000205/gr016.jpg)

图 16.10 每个箭头将一个点（蓝色）连接到其顶点（红色）：`s` = 0.2（左），`s` = 1（右）。

注意，[图 16.10](#Chp016_293-327_B9780443218576000205.xhtml#f0065) 中的两幅图（左和右）具有相同数量的点。但在右图中，点在某些区域聚集，在其他区域稀疏，给人一种点更少的错觉。显然，最近邻点之间距离的经验分布（特别是极端距离），或最大空区的平均面积，一旦 `λ` 已知或被估计，就可用于估计**缩放因子** `s`。

这引出了我的下一个讨论主题，即**极值**，或**记录值**。这是**顺序统计量** [[Wiki](https://en.wikipedia.org/wiki/Order_statistic)] 或极值理论 [[Wiki](https://en.wikipedia.org/wiki/Extreme_value_theory)] 领域的一部分。极值不同于**异常值** [[Wiki](https://en.wikipedia.org/wiki/Outlier)]：极值可以是可预测的，具有已知分布。相反，异常值通常被视为误差、故障或服从不同模型的数据点。无论如何，两者都会影响由“边界”界定的观测窗口，并有可能引入偏差。

一个问题是点离其顶点可以有多远，以及这种“极端情况”发生的频率如何。更有趣的是反向问题，关联到逆模型或**隐藏模型**：一个靠近原点、位于小观测窗口内部的点 (`X[h]`, `Y[k]`)![图片](images/B9780443218576000205/si4.png)，其顶点会不会非常远？这样的点不会由点过程模拟器生成。它将不被计入，从而引入偏差。随着 `s` 增加，这种情况发生的频率增加，需要越来越大的观测窗口。

除非 `F` 具有有限支撑域（例如 `F` 为均匀分布），否则小观测窗口中未观测到的点——尽管其期望数量有限且相当小——可以依附于任意远的顶点。在二维情况下，点与其格点位置之间的距离 `R` 大于 `r` 的概率 `P[R > r]`![图片](images/B9780443218576000205/si338.png) 为

$P(R > r) = \\int\_{- \\infty}^{\\infty}\\int\_{- \\infty}^{\\infty}\\chi(x^{2} + y^{2} > r)F\\left( \\frac{x}{s} \\right)F\\left( \\frac{y}{s} \\right)dxdy,$

![图片](images/B9780443218576000205/si339.png)

其中 `χ(A)`![图片](images/B9780443218576000205/si340.png) 是指示函数，若 `A` 为真则等于 1，否则等于 0。

距离 `R` 对应 [图 16.10](#Chp016_293-327_B9780443218576000205.xhtml#f0065) 中箭头的长度。如果 `F` 是高斯分布，则 `R` 服从**瑞利分布** [[Wiki](https://en.wikipedia.org/wiki/Rayleigh_distribution)]。在二维情况下，平稳泊松点过程中两个最近邻点之间的距离也服从瑞利分布，见第 [16.3.2.3](#Chp016_293-327_B9780443218576000205.xhtml#s0120) 节和 [习题 16.3](#Chp016_293-327_B9780443218576000205.xhtml#enun0025)。
