
同样，`η` 是决定形状方向的角度。在 [图 6.2](#Chp006_103-111_B9780443218576000102.xhtml#f0015) 左侧图表中，形状右侧的点密度肉眼可见地要高得多。在下部这一点甚至更加明显。因此，质心（橙点；印刷版为深灰色）被吸引向曲线的密集区域。一旦通过权重函数校正了这种影响，新的质心（灰点）现在看起来就很好地“居中”了。请注意，权重函数 `w[t]`![Image](images/B9780443218576000102/si21.png) 如 [图 6.3](#Chp006_103-111_B9780443218576000102.xhtml#f0020) 所示，是双峰的。它被选定为积分等于 1，因此它代表了 `T = [0, 1]`![Image](images/B9780443218576000102/si39.png) 上的一个概率分布。

## 6.4 形状比较

我从基于迄今为止建立的数学理论的相关性度量开始。然后我讨论它的优缺点，以及如何改进它。在真实数据集上的完整实现将在第 [6.5](#Chp006_103-111_B9780443218576000102.xhtml#s0050) 节中探讨。我使用符号 `ρ[t]`、`φ[t]`![Image](images/B9780443218576000102/si29.png) 表示第一个形状，用 `ρ[t]′`、`φ[t]′`![Image](images/B9780443218576000102/si40.png) 表示第二个形状。假设参数极坐标方程满足（可能经过适当变换后）`φ[t] = φ[t]′`![Image](images/B9780443218576000102/si41.png) 对于 `t ∈ T`![Image](images/B9780443218576000102/si19.png) 成立，则定义

```
γ = ∫[T](ρ[t] − ρ[t]′)² dt = ∫[T]ρ[t]² dt + ∫ρ[t]′² dt − 2∫[T]ρ[t]ρ[t]′ dt = 2 − 2λ
```

![Image](images/B9780443218576000102/si42.png)

其中

```
λ = ∫[T]ρ[t]ρ[t]′ dt
```

![Image](images/B9780443218576000102/si43.png)

根据 [(6.3)](#Chp006_103-111_B9780443218576000102.xhtml#deq10) 可知 `0 ≤ λ ≤ 1`![Image](images/B9780443218576000102/si44.png)。此外，当且仅当 `λ = 1`![Image](images/B9780443218576000102/si45.png) 时，两个形状才相同（最多相差一个缩放因子和一个平移向量）。相关性 `λ` 度量了两个形状有多接近。它依赖于 `φ[t] = φ[t]′`![Image](images/B9780443218576000102/si41.png) 这一事实。如果这一假设仅被轻微违反，分类器在简单数据集上仍可能起作用，例如识别字母表中的字母。但如果 `φ[t]`![Image](images/B9780443218576000102/si46.png) 和 `φ[t]′`![Image](images/B9780443218576000102/si47.png) 之间的差异显著，则可能会失效。

对于由多条弧组成的复杂形状，并不总能满足 `φ[t] = φ[t]′`![Image](images/B9780443218576000102/si41.png)。但对于闭合凸形状，总是可以做到的。此外，如果形状相同但经过旋转，通常 `λ ≠ 1`![Image](images/B9780443218576000102/si48.png)。系数 `λ` 取决于每个形状的方向角 `η`、`η′`![Image](images/B9780443218576000102/si49.png)，如公式 [(6.1)](#Chp006_103-111_B9780443218576000102.xhtml#deq2) 所示。因此，`λ` 也记作 `λ(η, η′)`![Image](images/B9780443218576000102/si50.png)。

为规避此问题，可以使用

```
\lambda^{*} = \min\limits_{\eta,\eta^{\prime}}\lambda(\eta,\eta^{\prime}).
```

![Image](images/B9780443218576000102/si51.png)

那么，当且仅当 `λ* = 1`![Image](images/B9780443218576000102/si52.png) 时，两个形状才相同（最多相差缩放因子、平移向量和方向）。由于对称性，可以设定 `η = 0`![Image](images/B9780443218576000102/si53.png)。在实践中，通常改用度量 `-log(1-λ)`![Image](images/B9780443218576000102/si54.png) 或 `-log(1-λ*)`![Image](images/B9780443218576000102/si55.png)。有关形状相关性的一般参考，请参见 [\[4\]](#Chp006_103-111_B9780443218576000102.xhtml#br0020)。

当然，也总是可以通过比较它们的签名来比较两个形状，参见 [\[2\]](#Chp006_103-111_B9780443218576000102.xhtml#br0010)。一种方法如下。对于第一个形状签名上的每个点 `P[t]`![Image](images/B9780443218576000102/si56.png)，在第二个形状签名上找到其最近邻 `Q[t]`![Image](images/B9780443218576000102/si57.png)，并计算这两点之间的距离 `D[t]`![Image](images/B9780443218576000102/si58.png)。然后计算

```
D = ∫[T]D[t] dt
```

![Image](images/B9780443218576000102/si59.png)

通过交换第一和第二个形状的角色重复该操作：对于第二个形状签名上的每个点 `Q[t]′`![Image](images/B9780443218576000102/si60.png)，在第一个形状签名上找到其最近邻 `P[t]′`![Image](images/B9780443218576000102/si61.png)，并计算这两点之间的距离 `D[t]′`![Image](images/B9780443218576000102/si62.png)。然后计算

```
D′ = ∫[T]D[t]′ dt
```

![Image](images/B9780443218576000102/si63.png)

如果 `D = 0`![Image](images/B9780443218576000102/si64.png)，则第一个形状是第二个形状的子集。如果 `D′ = 0`![Image](images/B9780443218576000102/si65.png)，则第二个形状是第一个形状的子集。如果 `D = D′ = 0`![Image](images/B9780443218576000102/si66.png)，则形状相同。因此 `δ = min(D, D′)`![Image](images/B9780443218576000102/si67.png) 是一个度量形状相似性的指标。它与 `Hausdorff distance` [[Wiki](https://en.wikipedia.org/wiki/Hausdorff_distance)]（豪斯多夫距离）密切相关，尽管对异常值的敏感度较低。

### 6.4.1 形状分类

既然我们有了比较两个形状的度量，就可以将其作为相似性度量来进行形状分类。如果形状 `S[1]`![Image](images/B9780443218576000102/si68.png) 和 `S[2]`![Image](images/B9780443218576000102/si69.png) 满足 `-log(1-λ) > α`![Image](images/B9780443218576000102/si70.png)，我们可以记作 `S[1] ∼ S[2]`![Image](images/B9780443218576000102/si71.png) 以表示它们等价（非常相似）。在这种情况下，`α = 8`![Image](images/B9780443218576000102/si72.png) 是一个很好的阈值。在字符识别中，如果你有一个包含数千个象形文字的训练集，可以使用此技术将任何新的象形文字分类为与训练集中的一个或多个等价，或归类为尚未分类（一个全新的，或书写太差以至于无法识别的）。
