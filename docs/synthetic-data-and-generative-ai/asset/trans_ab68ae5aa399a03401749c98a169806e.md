
*   •  附加到 `X[5]`![Image](images/B9780443218576000114/si98.png) 上的回归系数在最优配置中为正，但在除最顶端之外的其他前 8 个配置中均缺失（零）或为负。负值更合理，因为 `Y` 与 `X[5]`![Image](images/B9780443218576000114/si98.png) 之间的相关性强烈为负。

*   •  如果由于任何原因，特征 `X[6]`![Image](images/B9780443218576000114/si99.png) 不在你的数据集中，你将错失 63 个配置中的前 14 个配置。这确实是你绝不能缺少的特征。令人惊讶的是，它与 `Y` 的相关性并不高，远低于 `X[1]`、`X[3]`![Image](images/B9780443218576000114/si126.png) 或 `X[5]`![Image](images/B9780443218576000114/si98.png)。它展现威力的时刻不在于孤立存在，而在于与其他特征结合：有点像木炭看似无害，但与硫磺和硝石结合却能制成火药。

当然，确定理想配置就像挑拣樱桃（指只挑最好的）。然而，目标是最小化过拟合，并青睐简洁性和可解释性。在这方面，第四个配置是我最喜欢的，因为它在 6 个特征中仅使用了 `m = 4`![Image](images/B9780443218576000114/si125.png) 个特征，而且如果你单独使用特殊的 `β[0]`![Image](images/B9780443218576000114/si7.png) 搭配相同的特征配置，它也是赢家。我的第二选择是第 15 个配置，前提是单独使用特殊的 `β[0]`![Image](images/B9780443218576000114/si7.png)。如果单独使用 `β[0]`![Image](images/B9780443218576000114/si7.png)，它是第二好的配置，仅使用 3 个特征，其表现与使用定点算法 100 次迭代一样好（在该水平上）。它也是不含 `X[6]`![Image](images/B9780443218576000114/si99.png) 的最佳配置。

### 7.5.2 逐步回归法

根据表 [7.4](#Chp007_113-129_B9780443218576000114.xhtml#t0025) 和 [7.5](#Chp007_113-129_B9780443218576000114.xhtml#t0030)，很容易重构 **逐步回归** 的演进过程 [[维基百科](https://en.wikipedia.org/wiki/Stepwise_regression)]。该方法是一种逐步特征选择过程。这里（假设）`{2, 3}`![Image](images/B9780443218576000114/si127.png) 表示由两个特征 `X[2]`、`X[3]`![Image](images/B9780443218576000114/si128.png) 组成的配置。

*   •  前向回归，每次添加一个特征：

    `1 → {1, 3} → {1, 3, 6} → {1, 2, 3, 6} → {1, 2, 3, 4, 6} → Full.`

    ![Image](images/B9780443218576000114/si129.png)

*   分数 `s(β[100])`![Image](images/B9780443218576000114/si130.png) 分别为 `0.289, 0.408, 0.437, 0.554, 0.587, 0.589`![Image](images/B9780443218576000114/si131.png)，排名分别为 `40, 23, 15, 4, 2, 1`![Image](images/B9780443218576000114/si132.png)。

*   •  后向回归，每次移除一个特征：

    `Full → {1, 2, 3, 4, 6} → {1, 2, 3, 6} → {1, 2, 6} → {1, 2} → 1.`

    ![Image](images/B9780443218576000114/si135.png)

*   分数 `s(β[100])`![Image](images/B9780443218576000114/si130.png) 分别为 `0.589, 0.587, 0.554, 0.502, 0.318, 0.289`![Image](images/B9780443218576000114/si136.png)，排名分别为 `1, 2, 4, 8, 33, 40`![Image](images/B9780443218576000114/si137.png)。

*   •  成对前向回归，每次添加两个特征：`{1, 3} → {1, 2, 3, 6} → Full`![Image](images/B9780443218576000114/si138.png)。

*   •  成对后向回归，每次移除两个特征：`Full → {1, 2, 3, 6} → {1, 3}`![Image](images/B9780443218576000114/si139.png)。

注意，分别具有 `m = 5, 4, 3, 2, 1`![Image](images/B9780443218576000114/si140.png) 个特征的最佳配置分别为 `{1, 2, 3, 4, 6}`![Image](images/B9780443218576000114/si141.png)、`{1, 2, 3, 6}`![Image](images/B9780443218576000114/si142.png)、`{1, 2, 6}`![Image](images/B9780443218576000114/si143.png)、`{1, 3}`、`{1}`![Image](images/B9780443218576000114/si144.png)，其得分分别为 `0.587, 0.554, 0.502, 0.408, 0.289`![Image](images/B9780443218576000114/si145.png)，排名分别为 `2, 4, 8, 23, 40`![Image](images/B9780443218576000114/si146.png)。因此，逐步回归过程虽然在每次仅涉及一个配置时并非完全最优，但在此数据集上表现相当不错。如果在 4 个特征处停止，前向回归很容易解释。

## 7.6 结论

以线性回归为例，我阐释了如何将机器学习技术晦涩的输出转化为可解释的解决方案。此处描述的方法也展示了合成数据的威力，前提是合成数据生成得当。使用合成数据有一大优势：你可以一次性在数百万个截然不同的数据集上测试和基准测试算法。

我还引入了一种新的模型性能指标，在许多方面优于 R 平方，且基于交叉验证。该方法得出的近似效果非常好，在噪声数据上几乎接近精确解，只需少量迭代，得到的自然回归系数易于解释，同时避免了过拟合。事实上，给定特定数据集，许多截然不同的回归系数集合会导致几乎相同的预测结果。选择在精确性和可解释性之间提供最佳折衷的系数是合理的。

与传统方法相比，我的解决方案不需要矩阵求逆，也很简单。事实上，它可以轻松在 Excel 中实现，无需任何编码。尽管没有统计模型，我还展示了如何使用参数和非参数自助法技术计算置信区间。最后，我展示了如何生成具有特定协方差矩阵的多元数据。另一种选择是使用 **Copula（联结函数）** [[维基百科](https://en.wikipedia.org/wiki/Copula_(probability_theory))]，它是 **分位数函数** 的多维推广。Copula 方法已用于医疗数据生成模型的背景中；参见 [[3]](#Chp007_113-129_B9780443218576000114.xhtml#br0015) 第 98 页。另请参阅第 [10.2](#Chp010_169-201_B978044321857600014X.xhtml) 节。
