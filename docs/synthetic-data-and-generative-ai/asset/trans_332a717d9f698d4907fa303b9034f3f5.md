
满足 `p mod 4 = 3` 的素数似乎比其他素数更多，至少较小的素数是这样：它们占了先机。这被称为**切比雪夫偏差** [[Wiki](https://en.wikipedia.org/wiki/Chebyshev%27s_bias)]。如果这两类素数分布不均匀，轨道可能会任意接近原点。然而，得益于**狄利克雷定理** [[Wiki](https://en.wikipedia.org/wiki/Dirichlet%27s_theorem_on_arithmetic_progressions)]，我们知道分布是均匀的。因此，人们会预期公式 [(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5) 和 [(17.6)](#Chp017_329-360_B9780443218576000217.xhtml#deq7) 中的欧拉乘积平均而言会在 `χ[4](p) = +1` 和 `χ[4](p) = −1` 之间很好地交替，从而对某个小于 1 的 `σ = σ[0]` 收敛，进而对所有 `σ > σ[0]` 收敛。这与公式 [(17.1)](#Chp017_329-360_B9780443218576000217.xhtml#deq2) 中的乘积形成对比，后者对应于主特征 `χ(p) = 1`（对所有 `p` 成立），记作 `χ[4,0]`，且仅当 `σ > 1` 时收敛。

由于公式 [(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5) 中的乘积非零，若 `σ[0] < σ < 1` 则无根，由此可得出结论：如果 `σ[0] < σ < 1`，`L[P](z, χ[4])` 的轨道永不穿越 X 轴。然而，至今无人知晓 `σ[0]` 的最小可能值——称为**绝对收敛 abscissa** [[Wiki](https://en.wikipedia.org/wiki/General_Dirichlet_series)]——是否小于 1。据推测它可能低至 0.5，甚至更低。这是**广义黎曼假设** [[Wiki](https://en.wikipedia.org/wiki/Generalized_Riemann_hypothesis)] 的一部分，是数论中一个活跃的研究课题。然而，公式 [(17.5)](#Chp017_329-360_B9780443218576000217.xhtml#deq6) 中定义的相关级数 `L[P](z, χ[4])` 在 `σ > 0` 时是**条件收敛** [[Wiki](https://en.wikipedia.org/wiki/Conditional_convergence)] 的，参见 [[4]](#Chp017_329-360_B9780443218576000217.xhtml#br0020) 中的例 2.39，第 36 页。

关于在 RH 背景下关注完全乘法函数 `χ`（而不仅仅是狄利克雷特征）的参考文献，请参见 [[1]](#Chp017_329-360_B9780443218576000217.xhtml#br0005)。最后，我在第 [17.3.2.3](#Chp017_329-360_B9780443218576000217.xhtml#s0085) 节中更详细地讨论了 `χ[4]`。特别是，我展示了 `L[P](z, χ[4,1])` 与对应于 `L[P](z, χ[4,0])` 的标准黎曼 zeta 函数 `ζ(z)` 之间的巨大差异。

#### 17.2.2.1 特殊乘积

同样，我研究公式 [(17.6)](#Chp017_329-360_B9780443218576000217.xhtml#deq7) 中的无限乘积 `L[P](z, χ)`，其中 `z = σ + it`。如果对于某个 `0 < σ[0] < 1`，集合 `P` 包含无限多个素数，但间距足够大，使得

```
ρ = ∏_{p ∈ P} 1/(1 + p^{-σ₀}) > 0,
```

则对应于 `σ = σ[0]` 的 `L[P](z, χ)` 轨道将远离原点，始终保持距离 `≥ ρ`。无论函数 `χ` 如何，这都成立。特别地，这意味着如果 `σ = σ[0]`，则 `L[P](z, χ)` 无根。

现在，如果 `P` 是所有素数的集合，`χ(p) = 1` 对所有素数成立（标准情况）且 `σ = 0.5`，则公式 [(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5) 中定义的 `η[P](z, χ)` 有无限多个根。此外，如果其轨道过于接近原点，就会被吸引过去，否则会被偏转：原点似乎拥有类似黑洞的事件视界。如果靠得太近，就无法逃脱，会非常快地撞上原点。请看 [图 17.2](#Chp017_329-360_B9780443218576000217.xhtml#f0015) 中的蓝曲线，其中 X 轴代表时间 `t`，Y 轴代表复平面中到位置 `(c,0)` 的距离。对于蓝曲线，`c = 0`。注意，只要 `0.5 < σ < 1` 且 `0 < t < T` 且 `T` 有限，轨道的（有限）部分就会呈现一个洞。但随着 `T → ∞`，这个洞会非常缓慢地收缩到一个点。如果 `σ < 1`，该洞始终包含原点。但其实际中心位于 X 轴更右侧。请看图 [17.2](#Chp017_329-360_B9780443218576000217.xhtml#f0015)、[17.3](#Chp017_329-360_B9780443218576000217.xhtml#f0020) 和 [17.4](#Chp017_329-360_B9780443218576000217.xhtml#f0025)：每条曲线代表到特定位置 `(c,0)` 的距离。随着 `T` 增加，或 `σ` 减小并接近 0.5，中心向左移动，直到与原点重合。如果 `σ > 1`，该洞可能不包含原点，但轨道是有界的，且原点位于轨道外部边界之外：请看 [图 17.1](#Chp017_329-360_B9780443218576000217.xhtml#f0010) 中的黄色轨道。
