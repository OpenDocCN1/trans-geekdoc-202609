
- 列 F 到 N 对应由 Python 代码生成的 `fuzzy_big.txt` 的输出字段。它包含验证集的 200 个点，每个点最多有 `M` = 800 个条目，每个样条一个。这些用于构建预测区间。正如第 [8.3.2](#Chp008_131-145_B9780443218576000126.xhtml#s0030) 节所讨论的，一些样条被拒绝，因此每个验证点的实际行数少于 800。列 F–I 很简单。列 J 是列 I 中相关验证点的预测值，源自单个样条。该点的最终预测值是跨所有样条计算出的这些值的中位数。它存储在列 R 中。列 K 和 L 分别对应 `δ[k](x, y)` 和 `w[k](x, y)`。

- 列 P 到 U 对应验证集中每个点的汇总统计量。因此它有 200 行，每个验证点一行。基于中位数的预测值 `z[m]` 在列 R，基于权重的预测值 `z[w]` 在列 U，观测值 `z` 在列 Q，预测区间的下界和上界在列 S 和 T。

“2-D”选项卡中的单元格 X2 和 Y2 是预测区间的百分位数水平。您可以更改这些参数，它将自动更新电子表格中的[图 8.2](#Chp008_131-145_B9780443218576000126.xhtml#f0015)。预测的 `z[w]` 可以使用 Excel 的 `AverageIf` 函数计算。然而 Excel 中没有 `MedianIf` 或 `PercentileIf` 函数。有一个简单的变通方法：例如，不要使用不存在的调用 `MedianIf(F:F,P2,J:J)`，而是使用 `Median(If(F:F=P2,J:J))`。这条指令的意思是“计算列 J 的中位数，但仅针对列 F 中的元素等于单元格 P2 的行”。`Percentile` 函数同理。

## 8.4 结果

在本节中，我展示主要结果。我在第 [7](#Chp007_113-129_B9780443218576000114.xhtml) 章描述的合成数据上测试了该方法。它包含 `m` = 1000 个具有已知响应的观测值。前 800 个点用于训练“模型”，剩余的 200 个点——验证数据——用于测试和评估性能。数据集可在电子表格 [`fuzzyf2.xlsx`](https://github.com/VincentGranville/Machine-Learning/blob/main/Spreadsheets/README.md) 中获取，该表格在我的 GitHub 存储库中可用。它对应于第 [8.6](#Chp008_131-145_B9780443218576000126.xhtml#s0070) 节 Python 代码生成的小输出文件 `fuzzy_small.txt`。预测区间在第 [8.3.2](#Chp008_131-145_B9780443218576000126.xhtml#s0030) 节中讨论，并在[图 8.2](#Chp008_131-145_B9780443218576000126.xhtml#f0015) 中说明。

主要性能指标是 `R-squared`。正如第 [7](#Chp007_113-129_B9780443218576000114.xhtml) 章所讨论的，它肯定不是最好的指标，我在该章中建议了替代方案。然而，数据集足够大，且表现相对良好。因此，在这种情况下 `R-squared` 足够适用。请注意，它主要是在验证集上而非训练集上测量的，所以从技术上讲，它不是典型意义上的真正 `R-squared`。此外，这里将其定义为相关系数的平方。这在第 [8.4.3](#Chp008_131-145_B9780443218576000126.xhtml#s0060) 节中讨论。

### 8.4.1 性能评估

[表 8.1](#Chp008_131-145_B9780443218576000126.xhtml#t0010) 总结了我的主要实验。下标 `v`、`t`、`m`、`w` 分别代表验证集、训练集、中位数和加权预测值。无论每个位置使用的随机样条数量 `M` 是多少，由 `r` = 1 个点定义的样条的加权预测值效果最好。此类样条在任何地方都具有常数值。这并不奇怪，因为当 `r` = 1 时，该方法类似于克里金法或反距离插值。请注意，当 `r` = 1 时，不同样条的最大数量是 `M` = `n`。因此，如果 `n` = 800 且 `M` = 5000，某些样条会被多次使用。

中位数预测值对异常值不那么敏感，但它倾向于降低振幅，导致 `β` 值远低于 1。这不是问题，因为预测值可以轻松缩放回原尺度，而不影响 `R-squared`。对于这个特定的二维数据集，中位数法在 `r` = 2 时效果最好。此外，它在训练集内外表现同样良好。相反，加权法在训练集外性能急剧下降。较大的 `r` 值不会带来进一步改进。这令人鼓舞，因为您希望使用较小的 `r` 和 `M` 值来加快算法速度。`r` 越大，可供选择的潜在样条越多，从而产生更准确的预测区间。
