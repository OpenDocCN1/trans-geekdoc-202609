

# 摘要

此处讨论的技术可处理一大类问题。在本文中，我重点关注一个简单的问题，即线性回归。我使用迭代算法（不动点）求解该问题，该算法与梯度提升有几分相似，采用机器学习方法和可解释 AI，而非传统统计学。特别地，该算法不使用矩阵求逆。它易于在 Excel 中实现（我提供了我的电子表格），或作为黑箱系统进行自动化。此外，它具有数值稳定性，可推广至非线性问题。与导致无意义回归系数的传统统计解不同，此处的输出系数更易于理解，从而实现更好的解释。我在一组丰富的合成数据集上对其进行了测试：其表现与标准技术一样好，即使在向数据添加噪声后也是如此。然后我展示如何衡量单个特征或特征组（及特征交互）对解的影响。一个具有 `*m*` 个特征的模型有 `2^(*m*)` 个子模型。我展示了如何通过分析每个子模型的性能来获得更深入的见解。最后，我引入了一个称为 `*score*` 的新指标来衡量模型性能。基于与基准模型的比较，它比 R 平方或均方误差更有意义。

# 7.1 简介

此处，`*X*` 表示输入。它表示为一个具有 `*n*` 行和 `*m*` 列的矩阵；`*n*` 是观测值的数量，`*m*` 是特征的数量，也称为因变量。响应（也称为自变量或输出）是一个包含 `*n*` 个条目的列向量，表示为 `*Y*`。`*m*` 个回归系数（未知，待估计）存储在一个表示为 `*β*` 的列向量中。因此我们有

```
*Y* = *X**β* + *ϵ*,
```

(7.1)

其中 `*ϵ*` —— 也是一个包含 `*n*` 个条目的列向量 —— 是误差。该问题在于找到一个合适的 `*β*`，以某种方式最小化误差。如果没有误差项，方程 (7.1) 可以重写为 `*X*^(*T*)*Y* = *X*^(*T*)*X**β* + *Λ**β* − *Λ**β*`，即

```
*β* = *Λ*^(−1)*X*^(*T*)*Y* + (*I* − *Λ*^(−1)*X*^(*T*)*X*)*β*。
```

此处 `Λ` 是任意非奇异（可逆）`*m* × *m*` 矩阵，`^(*T*)` 表示矩阵或向量转置运算符 [[Wiki](https://en.wikipedia.org/wiki/Transpose)]。这引出了以下迭代算法：

```
*β*[*k* + 1] = *Λ*^(−1)*X*^(*T*)*Y* + (*I* − *Λ*^(−1)*X*^(*T*)*X*)*β*[*k*],
```

(7.2)

从参数向量（回归系数）的某个初始配置 `*β*[0]` 开始。我对 `Λ` 使用对角矩阵，因此该方法不涉及复杂的矩阵求逆。

我还使用以下符号：`*M* = *X*^(*T*)*X*` 和 `*S* = *I* − *Λ*^(−1)*M*`。该迭代算法的收敛性及其收敛速度，完全取决于 `*S*^(*k*) → 0` 随 `*k* → ∞` 发生的速度。这需要谨慎选择 `Λ`。稍后我将讨论如何在每次迭代 `*k*` 更新 `Λ`：在该算法的自适应版本中，(7.2) 中的 `Λ` 被 `*Λ*[*k*]` 替代，希望能加速收敛。这种迭代类型的通用术语（也包含牛顿优化和梯度下降）是**不动点算法** [[Wiki](https://en.wikipedia.org/wiki/Fixed-point_iteration)]。

后续讨论重点关注 `Λ` 和 `*β*[0]` 的选择，以及收敛含义和计算复杂度，并在**合成数据** [[Wiki](https://en.wikipedia.org/wiki/Synthetic_data)] 上进行了测试。我表明，仅需极少的迭代次数，通常就能获得一个非常好的预测器，尽管估计的参数向量与模拟中使用的目标向量截然不同。简而言之，基于不动点算法少量迭代的粗略近似所得出的 R 平方，与使用完整的标准统计工具获得的 R 平方非常相似。尽管采用了非统计视角且缺乏统计模型，但我解释了如何计算估计回归系数和预测值的置信区间。整个框架旨在促进解释，因此属于可解释 AI [[Wiki](https://en.wikipedia.org/wiki/Explainable_artificial_intelligence)] 范畴。

最后，我想提供该方法的一个简化版本，足够简单以便在 Excel 中轻松实现。选择 `*β*[0] = 0` 和使 `*S*` 的**弗罗贝尼乌斯范数**最小化的 `Λ` [[Wiki](https://en.wikipedia.org/wiki/Matrix_norm)]（另见 [[2]](#Chp007_113-129_B9780443218576000114.xhtml#br0010)）不仅效果良好，还能得出简单的公式，并与**特征值** [[Wiki](https://en.wikipedia.org/wiki/Eigenvalues_and_eigenvectors)] 建立有趣的联系（另见[此处](https://mathoverflow.net/questions/421309/power-of-a-matrix-largest-eigenvalue-in-absolute-value-and-convergence-acceler))。本章的最后部分重点评估每个特征的影响以及特征交互的影响。第 7.2 节讨论的合成训练集数据允许您模拟和测试大量多样的情况。最终，模型性能是在验证集上衡量的，而非训练集。
