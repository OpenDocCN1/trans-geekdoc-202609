#### 16.2.4.1 六方晶格，最近邻

生成 [图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040) 的源代码在我的 GitHub 仓库中：[`PB_NN.py`](https://github.com/VincentGranville/Point-Processes/blob/main/Source%20Code/PB_NN.py) 用于最近邻图，[`av_demo.r`](https://github.com/VincentGranville/Point-Processes/blob/main/Videos/av_demo.r) 用于可视化。

令人惊讶的是，可以使用少量（`m = 4` ![Image](images/B9780443218576000205/si119.png)）方晶格上的简单操作：叠加、拉伸和平移，来生成具有规则**六方晶格**的点过程。**拉伸晶格**是通过对 X 和/或 Y 坐标应用乘法因子，将方晶格变为矩形晶格。**平移晶格**是指网格点经过平移移动后的晶格。

该过程的每个点几乎必然（概率为 1）恰好有一个最近邻。然而，当缩放因子 `s` 为零时，这不再成立。在 [图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040) 的左图中，每个点（当 `s = 0` ![Image](images/B9780443218576000205/si10.png) 时也称为**顶点**）恰好有 3 个最近邻。这在绘制 `s = 0` ![Image](images/B9780443218576000205/si10.png) 的情况时带来了一些挑战。`s > 0` ![Image](images/B9780443218576000205/si141.png) 的情况更容易绘制，使用从任意点指向其唯一最近邻的箭头。我使用 R 语言中的 `arrow function` [[Wiki](https://stat.ethz.ch/R-manual/R-devel/library/graphics/html/arrows.xhtml)] 生成了相关箭头。点 A 和 B 之间的双向箭头意味着 B 是 A 的最近邻，且 A 是 B 的最近邻。[图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040) 左图中的所有箭头均为双向。边界效应显而易见，因为一些箭头指向窗口外的最近邻。点使用四种颜色，对应于生成基于六边形过程的 4 个平移拉伸泊松-二项过程。颜色指示某点属于这 4 个过程中的哪一个。

源代码处理具有多个最近邻的点。它生成一个包含所有点及其最近邻的列表，使用 `hash table`。一个拥有 3 个最近邻的点在该列表中有 3 个条目：每个最近邻对应一个。一组由箭头相互连接的点称为**连通分量** [[Wiki](https://en.wikipedia.org/wiki/Component_(graph_theory))]。在**图论**中，从一个连通分量的点到同一连通分量的另一个点，沿着箭头方向但忽略其方向的路径，称为**路径**。

在我的连通分量定义中，箭头方向无关紧要：底层**图**被视为**无向图** [[Wiki](https://en.wikipedia.org/wiki/Directed_graph)]。一个有趣的问题是研究大小分布，即每个连通分量的点数，特别是对于标准泊松过程。见 [练习 16.1](#Chp016_293-327_B9780443218576000205.xhtml#enun0010)。在图论中，点称为**顶点**或**节点**，箭头称为**边**。关于最近邻的更多内容见 [[20]](#Chp016_293-327_B9780443218576000205.xhtml#br0100) 中的练习 18 和 19。

最后，如果你看 [图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040)，左图似乎比右图有更多点。但它们实际上拥有大致相同数量的点。右图看起来更稀疏，因为有大面积区域没有点。但作为补偿，有些区域有多个点紧密相邻。

##### 练习 16.1

最近邻与连通分量大小分布。模拟强度为 `λ = 1` ![Image](images/B9780443218576000205/si49.png) 的平稳泊松过程的 10 个实现，每个实现包含 `n = 10³` ![Image](images/B9780443218576000205/si142.png) 个分布在正方形窗口内的点。识别**连通分量** [[Wiki](https://en.wikipedia.org/wiki/Component_(graph_theory))] 及其大小（每个连通分量中的点数）。练习目的是研究大小的分布，记为 `S`。特别是，仅包含 2 个点的连通分量的比例（`P[S=2]` ![Image](images/B9780443218576000205/si143.png)）、3 个点的比例（`P[S=3]` ![Image](images/B9780443218576000205/si144.png)）等是多少？对于连通分量，使用**无向图**，即如果 `V[i]` ![Image](images/B9780443218576000205/si146.png) 是 `V[j]` ![Image](images/B9780443218576000205/si147.png) 的最近邻，或者反之，则点 `V[i]`、`V[j]` ![Image](images/B9780443218576000205/si145.png)（也称为顶点）相连。问题如下：

- 通过模拟估计相关概率。当使用同一过程的多个实现计算比例时，我们是否在所有实现中获得 `S` 相似的经验分布？当增加 `n` 时（例如从 `n = 10³` ![Image](images/B9780443218576000205/si142.png) 到 `n = 10⁴` ![Image](images/B9780443218576000205/si148.png) 或 `n = 10⁵` ![Image](images/B9780443218576000205/si149.png)），经验分布似乎收敛吗？

- 对泊松-二项过程做相同实验，参数为 `λ = 1` ![Image](images/B9780443218576000205/si49.png) 和 `s = 0.15` ![Image](images/B9780443218576000205/si150.png)。`S` 的分布是否相同？`P[S=2]` ![Image](images/B9780443218576000205/si143.png) 呢？
