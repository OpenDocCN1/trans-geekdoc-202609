
还有其他符合 GRH 框架的“优秀函数” `` `χ(·)` `` ![Image](images/B9780443218576000151/si2.png)。例如，非整数素数，如 Beurling 素数 [\[8\]](#Chp011_203-228_B9780443218576000151.xhtml#br0040)（本章后面讨论）或 `` `Gaussian primes` `` \[[维基](https://en.wikipedia.org/wiki/Gaussian_integer)\]。有关此类函数的一般族，请参阅 `` `Dedekind zeta function` `` \[[维基](https://en.wikipedia.org/wiki/Dedekind_zeta_function)\]。有关 Riemann zeta 函数及相关主题的一般介绍，请参阅 [\[2\]](#Chp011_203-228_B9780443218576000151.xhtml#br0010) 和 [\[10\]](#Chp011_203-228_B9780443218576000151.xhtml#br0050)。

### 11.2.2 测试知名序列

此处分析的二进制序列表示为 `` `{d(k)}` `` ![Image](images/B9780443218576000151/si17.png)，其中 `` `d(k) ∈ {−1, +1}` `` ![Image](images/B9780443218576000151/si85.png) 和 `` `k = 1, 2` `` ![Image](images/B9780443218576000151/si18.png)，依此类推。测试仅限于 `` `d(k) ≤ n` `` ![Image](images/B9780443218576000151/si86.png)，基于 `` `L_3^*(n) = L_3(n)/sqrt(n log log n)` `` ![Image](images/B9780443218576000151/si87.png)，其中 `` `L[3](n)` `` ![Image](images/B9780443218576000151/si58.png) 由 [(11.5)](#Chp011_203-228_B9780443218576000151.xhtml#deq5) 定义。同样，对于素数有 `` `χ(p[k]) = d(k)` `` ![Image](images/B9780443218576000151/si48.png)，且 `` `χ(·)` `` ![Image](images/B9780443218576000151/si2.png) 通过 `` `χ(ab) = χ(a)χ(b)` `` ![Image](images/B9780443218576000151/si4.png) 扩展到非素数正整数。最后，`` `p[k]` `` ![Image](images/B9780443218576000151/si30.png) 是第 `k` 个素数，其中 `` `p[1] = 2` `` ![Image](images/B9780443218576000151/si31.png)。在我的示例中，![Image](images/B9780443218576000151/fx001.jpg)见 [表 11.1](#Chp011_203-228_B9780443218576000151.xhtml#t0010)，以及 ![Image](images/B9780443218576000151/fx002.jpg)见 [图 11.2](#Chp011_203-228_B9780443218576000151.xhtml#f0015) 和 [图 11.3](#Chp011_203-228_B9780443218576000151.xhtml#f0020)。

![图 11.2 四个序列的 L\_{3}^{\\ast}(n) 图像检验统计量：Python\[200\] 和 SQRT\[90,91\] 失败。](images/B9780443218576000151/gr002.jpg)

图 11.2 四个序列的 `` `L[3]^*(n)` `` ![Image](images/B9780443218576000151/si126.png) 检验统计量：`` `Python[200]` `` 和 `` `SQRT[90,91]` `` 失败。

![图 11.3 四个序列的 |L3(n)| 检验统计量：Python\[200\] 和 SQRT\[90,91\] 失败。](images/B9780443218576000151/gr003.jpg)

图 11.3 四个序列的 `` `|L[3](n)|` `` 检验统计量：`` `Python[200]` `` 和 `` `SQRT[90,91]` `` 失败。

序列在特定 `` `n` `` 下测试失败，并不意味着它对所有 `` `n` `` 都会失败。成功或失败也取决于种子（初始条件）。某些种子需要许多迭代——即相当大的 `` `n` ``——随机性才会显现。该测试不应用于较小的 `` `n` ``，例如 `` `n < 1000` `` ![Image](images/B9780443218576000151/si88.png)。最后，通过测试并不意味着序列足够随机。我提供了通过测试的劣质 PRNG 示例。通常，为了评估序列的随机性特征，会使用一组测试，而不仅仅是单一测试。然而，素数测试可以检测到其他测试无法发现的模式。在某种意义上，它是最后手段的测试。

此处研究的序列分为四类：

*   •  离散混沌 `` `dynamical systems` `` \[[维基](https://en.wikipedia.org/wiki/Dynamical_system)\]。在一维情况下，这些系统中许多由递归 `` `x[k+1] = g(x[k])` `` ![Image](images/B9780443218576000151/si89.png) 驱动，其中 `` `g` `` 是从 `` `[0, 1]` `` ![Image](images/B9780443218576000151/si90.png) 到 `` `[0, 1]` `` ![Image](images/B9780443218576000151/si90.png) 的连续映射。初始值 `` `x[0]` `` ![Image](images/B9780443218576000151/si91.png) 称为种子。通常，如果 `` `x[k] < 0.5` `` ![Image](images/B9780443218576000151/si93.png)，则 `` `d(k) = 1` `` ![Image](images/B9780443218576000151/si92.png)，否则 `` `d(k) = -1` `` ![Image](images/B9780443218576000151/si94.png)。`` `logistic map` `` \[[维基](https://en.wikipedia.org/wiki/Logistic_map)\]，其 `` `g(x) = 4x(1-x)` `` ![Image](images/B9780443218576000151/si95.png)，在 [表 11.1](#Chp011_203-228_B9780443218576000151.xhtml#t0010) 以及第 [11.3.2](#Chp011_203-228_B9780443218576000151.xhtml#s0065) 节的 Python 代码中标记为 Logistic。底数为 `` `b` `` 的 `` `shift map` ``，由 `` `g(x) = bx - floor(bx)` `` ![Image](images/B9780443218576000151/si96.png) 定义，其中括号表示取整函数，此处 `` `b = 3` `` ![Image](images/B9780443218576000151/si97.png)，标记为 Base3。`` `b = 2` `` ![Image](images/B9780443218576000151/si98.png) 的情况称为 `` `dyadic map` `` \[[维基](https://en.wikipedia.org/wiki/Dyadic_transformation)\]。数字 `` `floor(b x[k])` `` ![Image](images/B9780443218576000151/si99.png) 是种子 `` `x[0]` `` ![Image](images/B9780443218576000151/si91.png) 在底数 `` `b > 1` `` ![Image](images/B9780443218576000151/si100.png) 下的第 `` `k` `` 位数字。特别地，如果 `` `x[0]` `` ![Image](images/B9780443218576000151/si91.png) 是有理数，则序列 `` `{d(k)}` `` ![Image](images/B9780443218576000151/si17.png) 是周期性的，因此是非随机的。即使在最佳情况下（使用随机种子），序列 `` `{d(k)}` `` ![Image](images/B9780443218576000151/si17.png) 也是自相关的。这些动力系统在我的混沌动力系统著作 [\[4\]](#Chp011_203-228_B9780443218576000151.xhtml#br0020) 中有详细研究。

*   •  Python 函数 `` `random.random()` `` 实现的 `` `Mersenne twister` `` \[[维基](https://en.wikipedia.org/wiki/Mersenne_Twister)\]。这种同余 PRNG 也是另一种动力系统，尽管从技术上讲是“非混沌的”，因为序列 `` `{x[k]}` `` ![Image](images/B9780443218576000151/si101.png) 是周期性的。由于周期非常大，它能很好地模拟随机性。同样，具有大底数 `` `b` `` 和不良种子 `` `x[0]` `` ![Image](images/B9780443218576000151/si91.png)（导致周期性的有理数）的移位映射，如果 `` `x[0] = q/p` `` ![Image](images/B9780443218576000151/si102.png)，其中 `` `p, q` `` ![Image](images/B9780443218576000151/si103.png) 为整数且 `` `p` `` 为极大素数，也能很好地模拟随机性。在表格和图中，我均用 Python 标签表示 Mersenne twister。它对各种种子的素数测试均失败，特别是当种子设为 200 时。另见第 [11.3.1](#Chp011_203-228_B9780443218576000151.xhtml#s0060) 节。
