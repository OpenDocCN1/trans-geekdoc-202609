
# 摘要

此处讨论的创新技术远不止回归。它在信号处理中很有用，特别是空间滤波和平滑。最初是使用超平面设计的，原始版本可能会与支持向量机或支持向量回归混淆。然而，最接近的类比是模糊回归。基于样条的加权版本使其与最近邻或 `inverse distance interpolation` 有些关联，且高度非线性。最终，它是一种类克里金空间回归，具有许多潜在应用，范围从压缩到信号增强和预测。尽管没有统计模型，它仍为预测值提供置信区间。一个预测值由数百或数千个样条确定。样条在神经网络中扮演节点的角色。与神经网络不同，所有参数——到样条的距离——都具有自然的解释。

该方法在合成数据上进行了测试。性能取决于超参数和样条数量，在验证集上测量，而非训练集。尽管（按设计）对训练集点的预测近乎完美，但它对异常值鲁棒、数值稳定，且不会导致过拟合。没有回归系数、没有截距、不涉及矩阵代数、无微积分、除经验百分位数外无统计内容，甚至没有平方根。高中生也能理解。尽管表面简单，该技术远非平凡。在最简单形式下，样条类似于多元拉格朗日插值多项式。本文档包含 Python 代码。

## 关键词

多元多项式插值；模糊回归；样条；预测区间；无模型方法；非参数统计

## 8.1 简介

原始问题是将一条线拟合到一组点上——一个经典的线性回归问题。我探索了传统 `ordinary least squares` (OLS) 解 [[维基百科](https://en.wikipedia.org/wiki/Ordinary_least_squares)] 的替代方案。产生 `least absolute residuals` (LAR) [[维基百科](https://en.wikipedia.org/wiki/Least_absolute_deviations)] 的线就是一个例子。它的优点是更鲁棒。下一步是查看所有潜在的线组合。对于一组 `n` 个点，有 `M = n(n − 1)/2` ![图片](images/B9780443218576000126/si1.png) 条潜在线，因为每对点确定一条线。LAR 线只是其中之一，在某种意义上，是最好的一条。

思路是，对于实轴上的任意局部位置 `x`，可以在多条线 `z = L[k](x)` ![图片](images/B9780443218576000126/si2.png) 中选择来计算预测响应 `z`，其中 `k = 1, …, M` ![图片](images/B9780443218576000126/si3.png)。在局部层面，一些线提供的拟合比其他线更好。换句话说，每条 `M` 条线都有某种独特的、位置依赖的概率来贡献于在 `x` 处计算的预测响应。这种视角与贝叶斯方法非常相似。在文献中，这被称为 `Theil–Sen estimator` [[维基](https://mltblog.com/3LomHbJ)]。在最简单版本中，跨 `M` 条线计算的 `L[k](x)` ![图片](images/B9780443218576000126/si4.png) 的中位数是位置 `x` 处响应的最终点估计。改进版本为每条线使用不同的权重，涉及加权平均或 `weighted quantiles` [[1]](#Chp008_131-145_B9780443218576000126.xhtml#br0005)。由于每个 `x` 关联 `M` 个潜在预测值——每条线一个——你可以按如下方式定义响应的 80% 置信区间：下界（分别上界）是在 `x` 处计算的 `M` 个预测值的 10%（分别 90%） `empirical quantile` [[维基百科](https://en.wikipedia.org/wiki/Quantile)]（也称为百分位数）。

文献中使用术语 `prediction interval` [[维基百科](https://en.wikipedia.org/wiki/Prediction_interval)]，而非置信区间。注意，构建这些置信区间的方法不应与 `percentile bootstrap method` [[维基](https://stats.stackexchange.com/questions/355781/is-it-true-that-the-percentile-bootstrap-should-never-be-used)] 混淆。这里不涉及重采样。`M` 条线在训练集上计算，而模型性能在验证集上测量 [[维基百科](https://en.wikipedia.org/wiki/Training,_validation,_and_test_data_sets)]。注意，我用“模型”一词代表本章描述的实现。不涉及统计或概率模型。

## 8.2 原始版本

在转向高维的完整非线性模型之前，让我们专注于原始方法：我的模糊回归技术的第一个版本。这个版本更容易理解，更传统，并能产生简单的可视化。它将帮助你更好地理解新版本，后者要抽象和通用得多。

设 `n` 个观测点标记为 `(x[1], z[1]), …, (x[n], z[n])` ![图片](images/B9780443218576000126/si5.png)。包含 `(x[i], z[i])` ![图片](images/B9780443218576000126/si6.png) 和 `(x[j], z[j])` ![图片](images/B9780443218576000126/si7.png) 的线记为 `L[k] = L[i, j]` ![图片](images/B9780443218576000126/si8.png)。其方程为

```latex
L_{i,j}(x) = \frac{z_{i} - z_{j}}{x_{i} - x_{j}} \cdot x + \frac{x_{i}z_{j} - x_{j}z_{i}}{x_{i} - x_{j}}.
```

![图片](images/B9780443218576000126/si9.png)

立即可得

`L[i, j](x[i]) = z[i],  L[i, j](x[j]) = z[j].`
