
There are other “nice functions” `` `χ(·)` `` ![Image](images/B9780443218576000151/si2.png) that fit within the GRH framework. For instance, with primes that are not integers, such as Beurling primes [\[8\]](#Chp011_203-228_B9780443218576000151.xhtml#br0040) (discussed later in this chapter) or `` `Gaussian primes` `` \[[Wiki](https://en.wikipedia.org/wiki/Gaussian_integer)\]. For a general family of such functions, see the `` `Dedekind zeta function` `` \[[Wiki](https://en.wikipedia.org/wiki/Dedekind_zeta_function)\]. For a general introduction to the Riemann zeta function and related topics, see [\[2\]](#Chp011_203-228_B9780443218576000151.xhtml#br0010) and [\[10\]](#Chp011_203-228_B9780443218576000151.xhtml#br0050).

### 11.2.2 Testing well-known sequences

The binary sequences analyzed here are denoted as `` `{d(k)}` `` ![Image](images/B9780443218576000151/si17.png), with `` `d(k) ∈ {−1, +1}` `` ![Image](images/B9780443218576000151/si85.png) and `` `k = 1, 2` `` ![Image](images/B9780443218576000151/si18.png), and so on. The tests, restricted to `` `d(k) ≤ n` `` ![Image](images/B9780443218576000151/si86.png), are based on `` `L_3^*(n) = L_3(n)/sqrt(n log log n)` `` ![Image](images/B9780443218576000151/si87.png), with `` `L[3](n)` `` ![Image](images/B9780443218576000151/si58.png) defined by [(11.5)](#Chp011_203-228_B9780443218576000151.xhtml#deq5). Again, `` `χ(p[k]) = d(k)` `` ![Image](images/B9780443218576000151/si48.png) for prime numbers, and `` `χ(·)` `` ![Image](images/B9780443218576000151/si2.png) is extended to nonprime positive integers via `` `χ(ab) = χ(a)χ(b)` `` ![Image](images/B9780443218576000151/si4.png). Finally, `` `p[k]` `` ![Image](images/B9780443218576000151/si30.png) is the `k`th prime with `` `p[1] = 2` `` ![Image](images/B9780443218576000151/si31.png). In my examples, ![Image](images/B9780443218576000151/fx001.jpg)in [Table 11.1](#Chp011_203-228_B9780443218576000151.xhtml#t0010), and ![Image](images/B9780443218576000151/fx002.jpg)in Figs. [11.2](#Chp011_203-228_B9780443218576000151.xhtml#f0015) and [11.3](#Chp011_203-228_B9780443218576000151.xhtml#f0020).

![Figure 11.2 L\_{3}^{\\ast}(n)Image test statistic for four sequences: Python\[200\] and SQRT\[90,91\] fail.](images/B9780443218576000151/gr002.jpg)

Figure 11.2 `` `L[3]^*(n)` `` ![Image](images/B9780443218576000151/si126.png) test statistic for four sequences: `` `Python[200]` `` and `` `SQRT[90,91]` `` fail.

The fact that a sequence fails the test for a specific `` `n` `` does not mean it fails for all `` `n` ``. The success or failure also depends on the seed (the initial conditions). Some seeds require many iterations – that is, a rather large `` `n` `` – before randomness kicks in. The test should not be used for small `` `n` ``, say `` `n < 1000` `` ![Image](images/B9780443218576000151/si88.png). Finally, passing the test does not mean that the sequence is random enough. I provide examples of poor PRNGs that pass the test. Typically, to assess the randomness character of a sequence, one uses a battery of tests, not just one test. However, the prime test can detect patterns that no other one can. In some sense, it is a last resort test.

The sequences investigated here fall into four types:

*   •  Discrete chaotic `` `dynamical systems` `` \[[Wiki](https://en.wikipedia.org/wiki/Dynamical_system)\]. In one dimension, many of these systems are driven by a recursion `` `x[k+1] = g(x[k])` `` ![Image](images/B9780443218576000151/si89.png), where `` `g` `` is a continuous mapping from `` `[0, 1]` `` ![Image](images/B9780443218576000151/si90.png) onto `` `[0, 1]` `` ![Image](images/B9780443218576000151/si90.png). The initial value `` `x[0]` `` ![Image](images/B9780443218576000151/si91.png) is called the seed. Typically, `` `d(k) = 1` `` ![Image](images/B9780443218576000151/si92.png) if `` `x[k] < 0.5` `` ![Image](images/B9780443218576000151/si93.png), otherwise `` `d(k) = -1` `` ![Image](images/B9780443218576000151/si94.png). The `` `logistic map` `` \[[Wiki](https://en.wikipedia.org/wiki/Logistic_map)\], with `` `g(x) = 4x(1-x)` `` ![Image](images/B9780443218576000151/si95.png), is labeled Logistic in [Table 11.1](#Chp011_203-228_B9780443218576000151.xhtml#t0010) as well as in the Python code in Section [11.3.2](#Chp011_203-228_B9780443218576000151.xhtml#s0065). The `` `shift map` `` in base `` `b` ``, defined by `` `g(x) = bx - floor(bx)` `` ![Image](images/B9780443218576000151/si96.png) where the brackets represent the integer part function, here with `` `b = 3` `` ![Image](images/B9780443218576000151/si97.png), is labeled Base3. The case `` `b = 2` `` ![Image](images/B9780443218576000151/si98.png) is known as the `` `dyadic map` `` \[[Wiki](https://en.wikipedia.org/wiki/Dyadic_transformation)\]. The number `` `floor(b x[k])` `` ![Image](images/B9780443218576000151/si99.png) is the `` `k` ``-digit of the seed `` `x[0]` `` ![Image](images/B9780443218576000151/si91.png), in base `` `b > 1` `` ![Image](images/B9780443218576000151/si100.png). In particular, if `` `x[0]` `` ![Image](images/B9780443218576000151/si91.png) is a rational number, then the sequence `` `{d(k)}` `` ![Image](images/B9780443218576000151/si17.png) is periodic, and thus nonrandom. Even in the best-case scenario (using a random seed), the sequence `` `{d(k)}` `` ![Image](images/B9780443218576000151/si17.png) is autocorrelated. These dynamical systems are studied in detail in my book on chaotic dynamical systems [\[4\]](#Chp011_203-228_B9780443218576000151.xhtml#br0020).

*   •  `` `Mersenne twister` `` \[[Wiki](https://en.wikipedia.org/wiki/Mersenne_Twister)\] as implemented in the Python function `` `random.random()` ``. This congruential PRNG is also another type of dynamical system, though technically “nonchaotic” because the sequence `` `{x[k]}` `` ![Image](images/B9780443218576000151/si101.png) is periodic. It emulates randomness quite well as the period is very large. Likewise, the shift map with a large base `` `b` `` and a bad seed `` `x[0]` `` ![Image](images/B9780443218576000151/si91.png) (a rational number resulting in periodicity) will emulate randomness quite well if `` `x[0] = q/p` `` ![Image](images/B9780443218576000151/si102.png), where `` `p, q` `` ![Image](images/B9780443218576000151/si103.png) are integers and `` `p` `` is a very large prime. Both in the table and in the figures, I use the label Python for the Mersenne twister. It fails the prime test for various seeds, especially if the seed is set to 200. See also Section [11.3.1](#Chp011_203-228_B9780443218576000151.xhtml#s0060).
