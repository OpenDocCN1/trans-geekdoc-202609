### 11.3.1 修复 Python 中有缺陷的随机函数

Python 生成伪随机数的默认函数是 `random.random()`，位于 `random` 库中。它基于 `Mersenne twister`（梅森旋转算法）同余生成器 [[维基百科](https://en.wikipedia.org/wiki/Mersenne_Twister)]，文档见[此处](https://docs.python.org/3/library/random.xhtml)。正如第 [11.2.2](#Chp011_203-228_B9780443218576000151.xhtml#s0040) 节所讨论的，它不适用于加密及其他纯随机性至关重要的应用。事实上，文档附带了以下警告：“本模块的伪随机生成器不应用于安全目的”。

改进 `random.random()` 的一种方法是在 `random.seed()` 调用中避免使用特别糟糕的种子，例如 200 或 4。你也可以使用某些 `quadratic irrational numbers`（二次无理数）[[维基百科](https://en.wikipedia.org/wiki/Quadratic_irrational_number)] 的二进制位，利用第 [11.3.2](#Chp011_203-228_B9780443218576000151.xhtml#s0065) 节中的 Python 代码。同样，建议使用本章提出的素性测试来检查应避免哪些无理数。此外，这种方法可能较慢，因为它涉及处理非常大的整数。一种变通方法是将预计算好的大量数字表存储在安全位置。可供选择的二次无理数有无限多个。此外，你的数字序列绝不应从这些数的第一个二进制位开始，而应从随机位置开始，以增加破解难度。

例如，要生成你的序列 `d(k)`![Image](images/B9780443218576000151/si17.png)，将 `d(3*k)`![Image](images/B9780443218576000151/si150.png) 设为 `δ(g[1](k), α[1])`![Image](images/B9780443218576000151/si151.png)，将 `d(3*k + 1)`![Image](images/B9780443218576000151/si152.png) 设为 `δ(g[2](k), α[2])`![Image](images/B9780443218576000151/si153.png)，将 `d(3*k + 2)`![Image](images/B9780443218576000151/si154.png) 设为 `δ(g[3](k), α[3])`![Image](images/B9780443218576000151/si155.png)，其中

-   数 `α[1]`、`α[1]`、`α[3]`![Image](images/B9780443218576000151/si156.png) 是三个二次无理数，例如 $\sqrt{2},\sqrt{10},\sqrt{41}$![Image](images/B9780443218576000151/si157.png)，
-   数 `(δ(k, α) + 1)/2`![Image](images/B9780443218576000151/si158.png) 是二次无理数 `α` 的第 `k` 个二进制位，
-   函数 `g[1]`、`g[2]`、`g[3]`![Image](images/B9780443218576000151/si159.png) 用于扰序：例如，`g[1](k) = 5 * 10^5 + 2*k`![Image](images/B9780443218576000151/si160.png)，`g[2](k) = 3 * 10^5 + 3*k`![Image](images/B9780443218576000151/si161.png)，以及 `g[3](k) = 7 * 10^6 - k`![Image](images/B9780443218576000151/si162.png)。

另一种解决方案是对两个伪随机序列对你的序列 `d(k)`![Image](images/B9780443218576000151/si17.png) 执行 `bitwise XOR`（按位异或）[[维基百科](https://en.wikipedia.org/wiki/Bitwise_operation)]：例如 $\sqrt{2}$![Image](images/B9780443218576000151/si111.png) 和 $\sqrt{41}$![Image](images/B9780443218576000151/si163.png) 的二进制位，从任意位置开始。

还有些 Python 库提供适合加密应用的解决方案。例如，`os.urandom()` 利用操作系统创建无法播种的随机序列，因此不可复现。请参阅[此处](https://docs.python.org/3/library/os.xhtml#os.urandom)和[此处](https://docs.python.org/3/library/secrets.xhtml#module-secrets)。

### 11.3.2 用于检测 PRNG 细微缺陷的素性测试实现

此处展示的代码执行素性测试，计算 `L[3](n)`![Image](images/B9780443218576000151/si58.png)。变量 `nterms` 代表 `n`，并被设置为 ![Image](images/B9780443218576000151/fx007.jpg)。代码并非直接计算 `L[3](n)`![Image](images/B9780443218576000151/si58.png)，而是迭代计算更细粒度的统计量，即 `minL` 和 `maxL`；`L[3](n)`![Image](images/B9780443218576000151/si58.png) 是 `-minL` 和 `maxL` 之间的最大值，在最后一次迭代中获得。

种子和序列在底部的主体部分初始化。默认类别 `nonSquare` 用于 `L[3]`![Image](images/B9780443218576000151/si164.png)。其他类别 `Prime` 和 `All` 分别用于公式 [(11.5)](#Chp011_203-228_B9780443218576000151.xhtml#deq5) 中定义的 `L[1]`![Image](images/B9780443218576000151/si165.png) 和公式 [(11.6)](#Chp011_203-228_B9780443218576000151.xhtml#deq6) 中定义的 `L[4]`![Image](images/B9780443218576000151/si132.png)。如果你使用函数 `createSignHash()` 而不是默认的 `createSignHash2()`，则可以轻松计算 `L[2]`![Image](images/B9780443218576000151/si166.png)。代码之所以稍长，只是因为它涵盖了第 [11.2.2](#Chp011_203-228_B9780443218576000151.xhtml#s0040) 节中讨论的所有选项，甚至更多。它严重依赖哈希表（Python 中的字典）而非数组，因为相应的数组将相当稀疏，消耗大量内存，并拖慢计算速度。此外，得益于哈希表，代码可以轻松处理 Beurling 素数（非整数素数）。一个名为 `dirichletL.py` 的更长版本，用于计算复平面上 `L[P](z, χ)`![Image](images/B9780443218576000151/si14.png) 的轨道，其中 `z` 满足 $\sigma = \Re(z) \geqslant \frac{1}{2}$![Image](images/B9780443218576000151/si167.png) 固定，适用于任何素数集合 `P`（有限或无限），包括 Beurling 素数，可在 GitHub 上获取，[见此处](https://github.com/VincentGranville/Experimental-Math-Number-Theory/blob/main/Source-Code/dirichletL.py)。

该 Python 代码除 `primePy` 外不使用任何特殊库。要安装此库，请在 Windows 命令提示符或其 Unix 等效环境中输入命令 `pip install primePy`，就像安装任何库一样。某些较旧版本的 Python 可能需要 `BigNumber` 库。代码在 Python 3.10 下测试通过。下面展示的源代码也在 GitHub 上：查找 [randomNumbersTesting.py](https://github.com/VincentGranville/Experimental-Math-Number-Theory/blob/main/Source-Code/randomNumbersTesting.py)。
