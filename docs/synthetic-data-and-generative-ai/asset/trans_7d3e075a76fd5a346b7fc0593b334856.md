

## 18.6 肘部法则

在无监督聚类的背景下，确定聚类数量最流行的方法之一是 `elbow rule`（肘部法则）[[Wiki](https://en.wikipedia.org/wiki/Elbow_method_(clustering))]。它通常是手动执行的。在这里，我将展示如何将其自动化并应用于其他问题，例如 `outlier detection`（异常值检测）。其思路如下：聚类算法（例如 `K-means` [[Wiki](https://en.wikipedia.org/wiki/K-means_clustering)]）可以在给定数据集上识别出任意数量的聚类结构；通常，函数 `v(m)`![Image](images/B9780443218576000229/si152.png) 为由 `m` 个聚类组成的最佳聚类结构提供统计摘要，其中 `m = 1, 2, 3`![Image](images/B9780443218576000229/si153.png)，以此类推。例如，`v(m)`![Image](images/B9780443218576000229/si152.png) 是任意观测点到其分配的聚类中心距离的平方和。函数 `v(m)`![Image](images/B9780443218576000229/si152.png) 是递减的，在 `m` 的较小值时最初急剧下降，然后在 `m` 的较大值时下降得慢得多，从而在其图形中形成一个“肘部”。对应肘部位置的 `m` 值被视为最佳聚类数量。请参见 [图 18.7](#Chp018_361-386_B9780443218576000229.xhtml#f0060)。我使用标准化版本 `v'(m) = v(m)/v(1)`![Image](images/B9780443218576000229/si154.png) 代替 `v(m)`![Image](images/B9780443218576000229/si152.png)。

![图 18.7 肘部法则（右）在布朗运动（左）中发现 m = 3 个聚类。](images/B9780443218576000229/gr007.jpg)

*图 18.7 肘部法则（右）在布朗运动（左）中发现 `m` = 3 个聚类。*

我在第 [18.6.1](#Chp018_361-386_B9780443218576000229.xhtml#s0130) 节中说明如何使用肘部法则检测 `outliers`（异常值/极值）。相同的方法论适用于检测聚类数量。数据由二维 `Brownian motion`（布朗运动）的一个实现组成。我关注的是增量 `R[k]`![Image](images/B9780443218576000229/si155.png)，它测量过程中的一个点与下一个点之间的距离。出于实际目的，模拟实现可以解释为二维随机游走，而 `R[k]`![Image](images/B9780443218576000229/si155.png) 是 [图 18.7](#Chp018_361-386_B9780443218576000229.xhtml#f0060) 中连接两个连续点的线段长度。如果你放大图片，这些线段是可见的。生成此合成数据所用的模型在第 [12.2.1](#Chp012_229-241_B9780443218576000163.xhtml) 节中描述。

### 18.6.1 用于检测异常值的黑盒肘部法则

[图 18.7](#Chp018_361-386_B9780443218576000229.xhtml#f0060) 显示了一个包含 10⁴ 个点的 `Brownian motion`（布朗运动）实现，在公式 [(12.6)](#Chp012_229-241_B9780443218576000163.xhtml) 中使用了 `γ = 2`![Image](images/B9780443218576000229/si156.png) 和 `λ = Γ(1 + γ)`![Image](images/B9780443218576000229/si157.png)。目标是检测在顶部 `R[k]`![Image](images/B9780443218576000229/si155.png) 值中，有多少个值显著超出其他所有值。在这里，它们严格来说不是异常值，因为它们仍然是同一分布的离差值；相反，它们被称为极值。第一步是对这些值进行排序。按逆序排列的有序值表示为 `R[(1)]`、`R[(2)]`![Image](images/B9780443218576000229/si158.png)，以此类推，其中 `R[(1)]`![Image](images/B9780443218576000229/si159.png) 是最大的一个。我使用 `v(m) = R[(m)]`![Image](images/B9780443218576000229/si160.png) 作为肘部法则的判据，即标准化后，`v'(m) = v(m)/v(1)`![Image](images/B9780443218576000229/si154.png)。

在 [图 18.7](#Chp018_361-386_B9780443218576000229.xhtml#f0060) 的右图中，左侧的 `Y` 轴代表 `v'(m)`![Image](images/B9780443218576000229/si161.png)，`X` 轴代表 `m`，右侧的 `Y` 轴代表肘部信号的强度（红色条形的高度；稍后我将讨论其计算方法）。`v'(m)`![Image](images/B9780443218576000229/si161.png) 的前 10 个值（`m = 1, ..., 10`![Image](images/B9780443218576000229/si162.png)）为：

1.00, 0.92, 0.77, 0.76, 0.71, 0.69, 0.63, 0.61, 0.60, 0.56, 0.55, 0.55.

![Image](images/B9780443218576000229/si163.png)

显然，第三个值 0.77 是关键的，因为在序列开头初始大幅下降后，后续值停止急剧下降。因此，“肘部信号”在 `m = 3`![Image](images/B9780443218576000229/si164.png) 处最强，结论是前两个值（`2 = m - 1`![Image](images/B9780443218576000229/si165.png)）超出了所有其他值。黑盒肘部法则算法的目的是自动化决策过程：在本例中，决定最优值为 `m = 3`![Image](images/B9780443218576000229/si164.png)。

请注意，在某些情况下，肘部并不明显，甚至可能不存在。在我的例子中，肘部信号非常强，因为我在公式 [(12.6)](#Chp012_229-241_B9780443218576000163.xhtml) 中选择了一个相当大的值 `γ = 2`![Image](images/B9780443218576000229/si156.png)，导致布朗过程表现出异常强烈的聚类结构，以及顶部 `v(m)`![Image](images/B9780443218576000229/si152.png) 值之间的巨大差异。更大的 `γ` 会产生更强的差异。`γ` 的负值，例如 `γ = -0.75`![Image](images/B9780443218576000229/si166.png)，也会导致强烈的差异、分离良好的聚类以及易于检测的肘部。如果 `γ = -0.75`![Image](images/B9780443218576000229/si166.png)，由于此时 `Var[R[k]] = ∞`![Image](images/B9780443218576000229/si167.png)，生成的过程甚至不再是布朗运动。标准布朗运动对应 `γ = 0`![Image](images/B9780443218576000229/si168.png)，根据实现的不同，仍可能表现出聚类。最后，在我们的例子中，`m = 3`![Image](images/B9780443218576000229/si164.png) 也对应于 [图 18.7](#Chp018_361-386_B9780443218576000229.xhtml#f0060) 左图中的聚类数量。这是一个巧合，但这种巧合非常频繁，因为肘部左侧的顶部 `v(m)`![Image](images/B9780443218576000229/si152.png) 值对应于异常大的 `R[k]`![Image](images/B9780443218576000229/si155.png) 值。在模拟中，这些非常大的值通常每个都会导致一个新聚类的形成。

肘部法则可以递归使用，首先检测数据集中“主要”聚类的数量，然后检测每个聚类内部子聚类的数量。如果 `v'(m)`![Image](images/B9780443218576000229/si161.png) 的方差较低，信号强度（红色条形的高度）通常非常低。在这种情况下，没有一组值超出所有其他值，即不存在真正的肘部。关于该方法论在检测聚类数量方面的应用，请参阅 Chikumbo 最近的一篇文章 [[1]](#Chp018_361-386_B9780443218576000229.xhtml#br0005)。检测聚类数量的一种替代肘部法则的方法是轮廓系数法 [[Wiki](https://en.wikipedia.org/wiki/Silhouette_(clustering))]。
