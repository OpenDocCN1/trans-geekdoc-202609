
### 5.3.2 基于直方图均衡化的聚类

我对无监督聚类使用相同的滤波器。事实上，有监督和无监督聚类在源代码中并行实现，都在同一个 `loop` 内。主要区别在于附加在像素 `(x, y)` 上的颜色（或簇）`c(x, y)` 是未知的。

我使用灰度级别代替颜色，表示位图上任意位置的点密度：越暗，密度越高。我从一个位图开始，其中如果 `(x, y)` 对应位图上观测点的位置，则 `c(x, y) = 1`，否则 `c(x, y) = 0`。同样，我用相同的滤波器大小 `w = 20` 对整个位图进行 `N = 3` 次滤波。

在第 `t` 次 `loop` 中分配给像素 `(x, y)` 的新灰度级别为

$$
c^{\prime}(x,y) = \underset{j}{\arg\max}\sum_{u = - w}^{w}\sum_{v = - w}^{w}\frac{c(x - u,y - v) \cdot 10^{- t}}{\sqrt{1 + u^{2} + v^{2}}}.
$$

(5.4)

首次将此滤波器应用于整个位图时，我在公式 [(5.4)](#Chp005_83-102_B9780443218576000096.xhtml#deq4) 中使用 `t = 0`；第二次使用 `t = 1`，第三次使用 `t = 2`。目的是减弱连续滤波的效果，否则图像（[图 5.3](#Chp005_83-102_B9780443218576000096.xhtml#f0020) 中最右侧的图）在几次 `loop` 后几乎会变成全黑，从而无法直观地显示簇结构。带有阻尼因子的第二次和第三次 `loop` 比仅使用单次 `loop` 效果更好。

滤波图像后，我使用最后一步后处理来增强灰度级别：请参阅 `GD_maps` 函数源代码的第 4 部分。它包括对灰度级别的直方图进行分箱和重新缩放，使图像更清晰、更易于解释，仅使用 8 个灰度级别。这一步称为**直方图均衡化**，可以自动化。从最暗的开始，连续的灰度级别对应**层次聚类**算法 [[Wiki](https://en.wikipedia.org/wiki/Hierarchical_clustering)] 中的连续层级。为完成聚类过程，可使用**图像分割**技术 [[Wiki](https://en.wikipedia.org/wiki/Image_segmentation)] 来识别簇的边界。

我的代码中使用的均衡器适用于所有测试过的图像。不过，您可能想要使用针对特定图像的均衡器。Python Pillow 库提供了一种简便的方法，请见[此处](https://www.geeksforgeeks.org/python-pil-imageops-equalize-method/)。您也可以编写自己的 Python 代码以获得完全控制。请参阅 GitHub 上庞大的 Algorithms 仓库中的直方图均衡化代码，[此处](https://github.com/TheAlgorithms/Python/blob/master/digital_image_processing/histogram_equalization/histogram_stretch.py)。这种将表格数据转换为图像或反之亦然，或通过均衡化灰度级别来执行聚类的算法，称为**变换器** [[Wiki](https://en.wikipedia.org/wiki/Transformer_(machine_learning_model))]。

### 5.3.3 分形分类：深度神经网络类比

该滤波系统本质上是一个神经网络 [[Wiki](https://en.wikipedia.org/wiki/Neural_network)]。第一次 `loop` 之前的图像（[图 5.2](#Chp005_83-102_B9780443218576000096.xhtml#f0015) 和 [图 5.4](#Chp005_83-102_B9780443218576000096.xhtml#f0025) 左图），由训练集组成，是输入层。经过 3 次 `loop` 后得到的最终图像是输出层。中间迭代对应**隐藏层**。在每一层中，像素颜色是上一层邻近像素计算量的函数。预处理步骤是将数据集转换为图像位图。在第 [5.3.2](#Chp005_83-102_B9780443218576000096.xhtml#s0040) 节关于无监督聚类的内容中，称为“均衡器”的后处理步骤在神经网络中起着 sigmoid 函数的作用。请参阅 Luuk Spreeuwers 1992 年答辩的博士论文“用神经网络进行图像滤波” [[2]](#Chp005_83-102_B9780443218576000096.xhtml#br0010)（在线可用，[此处](https://ris.utwente.nl/ws/portalfiles/portal/255169420/Thesis_L_Spreeuwers.pdf)），了解更多关于作为神经网络的图像滤波器的信息。

在我发布的视频中[此处](https://www.youtube.com/watch?v=dNPSEh-X6uw)（YouTube）和[此处](https://github.com/VincentGranville/Point-Processes/blob/main/Videos/fractal005.gif)（GitHub 上的动态 gif），每一帧代表一个**极深神经网络**中的一层。在我的方法论中，我使用“loop”或“iteration”代替“layer”。它在 `PB_clustering_video.py` 中由 Python 变量 `loop` 表示（第 [5.4.1](#Chp005_83-102_B9780443218576000096.xhtml#s0065) 节）。像素扮演**神经元**的角色，像素与其邻居之一之间连接所附带的权重——如公式 [(5.3)](#Chp005_83-102_B9780443218576000096.xhtml#deq3) 所示——在神经网络术语中也称为“权重”或参数。

此处描述的分形分类器，在视频中展示，也在 [图 5.5](#Chp005_83-102_B9780443218576000096.xhtml#f0030) 和 [图 5.6](#Chp005_83-102_B9780443218576000096.xhtml#f0035) 中显示，在某种意义上与第 [5.3.1](#Chp005_83-102_B9780443218576000096.xhtml#s0035) 节描述的分类器相反：它不使用 `N = 3` 次 `loop`（即 3 层），而是使用数百次。但局部滤波器极小，`w ≤ 1`，而第 [5.3.1](#Chp005_83-102_B9780443218576000096.xhtml#s0035) 节中 `w = 20`。因此，每个神经元（像素）最多只连接到一个神经元。这种神经网络称为“稀疏”网络。最终，它产生的结果与使用少量 `loop` 和大局部滤波窗口的结果相似。主要区别在于簇边界不那么平滑，呈现分形状。视频（[此处](https://github.com/VincentGranville/Point-Processes/blob/main/Videos/fractal005.gif)）展示了从一次 `loop` 到下一次 `loop` 发生的连续图像变换。观看它非常容易理解该方法的工作原理，使其成为可解释 AI [[Wiki](https://en.wikipedia.org/wiki/Explainable_artificial_intelligence)] 的经典示例。
