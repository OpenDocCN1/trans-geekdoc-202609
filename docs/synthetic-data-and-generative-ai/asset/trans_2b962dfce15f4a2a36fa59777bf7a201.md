
• 对于第二个数据集，在 `θ^*(3,1)`![Image](images/B9780443218576000059/si235.png) 处评估的 `MSE(3,1)`![Image](images/B9780443218576000059/si226.png) 优于在 `θ^*(1,1)`![Image](images/B9780443218576000059/si236.png) 处评估的结果。这没有任何意义：当然，`MSE(3,1)`![Image](images/B9780443218576000059/si226.png) 在 `θ^*(3,1)`![Image](images/B9780443218576000059/si235.png) 处总是最优的，这是由设计决定的。然而，这两个 MSE 的比率，`ρ = 0.01092/0.00686 ≈ 1.59`![Image](images/B9780443218576000059/si237.png)，在这里相当高。相反，对于第一个数据集，`ρ ≈ 1.39`![Image](images/B9780443218576000059/si238.png) 要小得多。因此，模型 `(3,1)`![Image](images/B9780443218576000059/si226.png) 对于第二个数据集比对于第一个数据集更有依据。

请注意，`MSE(1,1)`![Image](images/B9780443218576000059/si231.png) 或 `MSE(3,1)`![Image](images/B9780443218576000059/si226.png) 的计算是在不知道某点被分配到哪个簇的情况下进行的。事实上，我的方法中从未讨论过点分配：你在不将点分配给特定簇的情况下找到中心。一旦计算出两个中心 `θ[A]^*`, `θ[B]^*`![Image](images/B9780443218576000059/si193.png)，每个点 `W[k]`![Image](images/B9780443218576000059/si74.png) 就会被分配给最近的簇。邻近度通过点与簇中心之间的距离来衡量。然后选择使这些距离之和最小的模型——`(1,1)`![Image](images/B9780443218576000059/si231.png) 或 `(3,1)`![Image](images/B9780443218576000059/si226.png)。

我猜测，在 `Kmeans` 过程中，用 `||W[k] - θ[A]||^(p[A])`![Image](images/B9780443218576000059/si241.png) 和 `||W[k] - θ[B]||^(p[B])`![Image](images/B9780443218576000059/si242.png) 替换 `||W[k] - θ[A]||²`![Image](images/B9780443218576000059/si239.png) 和 `||W[k] - θ[B]||²`![Image](images/B9780443218576000059/si240.png) 将产生类似于我方法的更好结果。同样，`θ[A]`, `θ[B]`![Image](images/B9780443218576000059/si188.png) 是两个簇中心，`W[k]`![Image](images/B9780443218576000059/si74.png) 是第 `k` 个观测值。即使 `p[A] = p[B] = 1`![Image](images/B9780443218576000059/si243.png) 在存在异常值的情况下（例如，来自大簇的异常值溢出到附近的较小簇）也可能使 `Kmeans` 显著改进。这种方法与**K-中位数聚类** [[Wiki](https://en.wikipedia.org/wiki/K-medians_clustering)] 有些相似。使用线性权重而非幂权重可能产生相同的效果。

### 结论

当簇严重重叠且不平衡时，我的方法检测中心的效果经常比 `Kmeans` 更好。然而，这假设你有一种机制在模型 `(1,1)`![Image](images/B9780443218576000059/si231.png)、`(2,1)`![Image](images/B9780443218576000059/si232.png) 和 `(3,1)`![Image](images/B9780443218576000059/si226.png) 之间进行选择。如果你事先知道数据高度偏态，如 [图 1.7](#Chp001_1-34_B9780443218576000059.xhtml#f0050) 所示，那么模型 `(3,1)`![Image](images/B9780443218576000059/si226.png) 是一个很好的起始候选模型。当簇分离良好且一两个分布是非对称时，模型 `(1,1)`![Image](images/B9780443218576000059/si231.png) 倾向于正确识别簇中位数，而不是标准中心（均值）。

该方法简单快捷：它不执行点分配。你可以用它在更复杂的算法中寻找初始中心配置作为首次近似，或在“无监督”逻辑回归的背景下检测两个簇（当没有自变量时）。精确解（如 [(1.12)](#Chp001_1-34_B9780443218576000059.xhtml#deq17)）适用于任意维度的两个或更多簇，例如 `(2,2)`![Image](images/B9780443218576000059/si244.png)、`(2,2,2)`![Image](images/B9780443218576000059/si245.png) 和 `(4,2)`![Image](images/B9780443218576000059/si246.png) 模型。其他原创聚类算法见第 [5](#Chp005_83-102_B9780443218576000096.xhtml) 章。

后续步骤：在不对称合成数据上进行测试，该数据建模为具有不等簇大小和方差的正态分布和伽马分布的混合，降低波动性，研究模型 `(1,1/3)`![Image](images/B9780443218576000059/si247.png)——即 `(3,1)`![Image](images/B9780443218576000059/si226.png) 的“姊妹模型”——并将该方法推广到二维或三维以及两个以上的簇。目标之一是确定我的方法何时优于 `Kmeans`，以便更多地了解 `Kmeans` 并进一步改进它。

## 1.4 与合成数据的联系：陨石、海潮

本章的示例基于模拟数据。合成数据中使用模拟的方式如下。假设你有一组陨石图像，目标是根据其形状对它们进行分类，形状由第 [1.3.2.2](#Chp001_1-34_B9780443218576000059.xhtml#s0055) 节讨论的椭圆参数总结。每种类型的陨石对应一组特定的参数值。例如，细长的陨石具有高离心率。离心率由 Python 代码中参数 `ap` 和 `bp` 的比率决定（分别为长半轴和短半轴的长度）。要生成细长陨石，在模拟中为该比率设定一个特定范围。这种生成模型技术称为**参数化自助法**（**parametric bootstrap**）。
