
- **数论序列**与素数分布或 `Beurling primes`（Beurling 素数）有关。此类序列标记为 `Dirichlet4`。主要的一个（种子设为 3）对应于：若 `p[k] ≡ 1 mod 4` 则 `χ(p[k]) = +1`，若 `p[k] ≡ 3 mod 4` 则 `χ(p[k]) = -1`。此处 `χ(2) = 0`。该函数记作 `χ[4]`，是模 4 的**非平凡狄利克雷特征** [[维基](https://en.wikipedia.org/wiki/Dirichlet_character)]。该序列勉强未通过 `L[3]^(*` 测试；定义在所有正整数上（而非仅非平方整数）的完整函数 `χ[4]` 是周期性的。其姊妹序列（种子设为 1）满足若 `p` 为素数则 `χ(p) = -χ[4](p)`。基于 Beurling 素数（素数向非整数的推广）的序列未在此包含，而是在第 [17](#Chp017_329-360_B9780443218576000217.xhtml) 章讨论。第 [11.3.2](#Chp011_203-228_B9780443218576000151.xhtml#s0065) 节的 Python 代码可轻松修改以处理它们。我 GitHub 仓库 [这里](https://github.com/VincentGranville/Experimental-Math-Number-Theory/blob/main/Source-Code/dirichletL.py) 发布的 `DirichletL.py` 代码包含了 Beurling 素数。这些数字在 Diamond [[3]](#Chp011_203-228_B9780443218576000151.xhtml#br0015) 和 Hilberdink [[8]](#Chp011_203-228_B9780443218576000151.xhtml#br0040) 的研究中被探讨。

- **二次无理数的二进制数字**。我使用一个简单、原创的递归来计算这些数字：见第 [11.3.3](#Chp011_203-228_B9780443218576000151.xhtml#s0070) 节的代码描述。Python 代码能轻松处理这些计算中涉及的超大整数。令人惊讶的是，`√2` 如预期通过了素性测试，但 `√2205` 没有。基于这些数字的序列在本文档中标记为 `SQRT`。

由于 CPU 执行计算的方式，二进制映射无法在 Python 中实现：迭代值 `{x[k]}` 在约 45 次迭代后（错误地）全等于零。这就是我选择 `b = 3` 的移位映射的原因。在这种情况下，由于有限机器精度（限于 32 位）导致的误差传播，迭代值在 45 次后也全是错的。即使使用 64 位或任何有限位数，问题依然存在。然而，当 `b = 3` 时，`x[k]` 能持续正常振荡并永远保持其统计特性（包括随机性或非随机性），这归因于系统的 `ergodicity` [[维基](https://en.wikipedia.org/wiki/Ergodicity)]。结果等同于每 45 次迭代左右使用一个新种子。

原则上，`b = 2` 的二进制映射可用于计算种子 `x_0 = √2` 的二进制数字，但由于上述问题，它行不通。相反，我使用一个特殊的递归来计算这些数字。如果你将 `b = 2` 替换为 `b = 2 - 2^(-31)`（能最接近 2 以避免完全失败），Python 代码产生的 `x[k]` 虽然在 45 次迭代后也完全错误，但从统计角度来看表现符合预期：这是避免使用 `b = 2` 的一种变通方法。其他编程语言也存在这个问题。

### 11.2.2.1 逆向工程伪随机序列

许多由递归 `x[k+1] = g(x[k])` 定义的序列（其中 `x[0]` 是种子）可以被逆向工程，因此在安全性至关重要的场合下使用它们是不安全的。这包括同余伪随机数生成器产生的序列。逆向工程是指：如果你观察到 `m` 个连续数字，就能轻松计算出所有数字，从而正确“猜出”整个序列。对于梅森旋转算法，据推测 `m = 624` 是最小可能值，尽管其周期为 `2^19937 - 1`，见 [这里](https://en.wikipedia.org/wiki/Mersenne_Twister)。对于基数 `b` 的移位映射，虽然若 `x[0]` 为随机值则 `x[k]` 渐近均匀分布于 `[0, 1]`，但向量 `(x[k], x[k+1])` 处于一种非常特定的构型：`x[k+1] - x[k]` 是一个小整数，使得序列 `{x[k]}` 绝非随机。结果，对于任意正整数 `q`，在无限序列上计算出的 `(x[1], x[2], x[3], …)` 与 `(x[q+1], x[q+2], x[q+3], …)` 之间的经验**自相关** [[维基](https://en.wikipedia.org/wiki/Autocorrelation)] 等于 `1/b^q`（若 `b` 为 `≥ 2` 的整数）。一个好的序列应对所有 `q` 具有零自相关。

有可能显著改进基础序列 `{x[k]}`，使其无法被逆向工程。对于移位映射，使用 `d(k) = ⌊b x[k]⌋` 代替 `x[k]`，若种子 `x[0]` 为随机值，则可得到零自相关和完美随机性。据推测，诸如 `x_0 = √2/2` 或 `x[0] = log 2` 之类的种子能达到此目的。解释如下：`d(k)` 是 `x[0]` 在基数 `b` 下的第 `k` 位数字。即使你观察到 `√2/2` 的 `10^100` 个连续数字，若不知道 `x_0 = √2/2`，也无法预测下一位数字会是什么。实际上，即使你拥有该信息，仍无法预测下一位数字。据推测，任意 `m` 位数字序列对于 `√2/2` 这类种子会在任意位置无限多次出现。因此，给定任意此类 `m` 位数字串（无论 `m` 多大），都无法判断它在无限数字序列中的位置，从而也就无法正确预测所有后续数字。
