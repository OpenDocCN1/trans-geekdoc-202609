
## Performance Metrics

*   • The R-squared `r`, with `0 ≤ r ≤ 1`![Image](images/B9780443218576000114/si78.png), is the square of the correlation between `Y` and `P`. It is also equal to `[σ[Y]² − (Y − P)^(T)(Y − P)] / σ[Y]²`![Image](images/B9780443218576000114/si79.png).

*   • The root mean squared error or RMSE [[Wiki](https://en.wikipedia.org/wiki/Root-mean-square_deviation)], defined as `e = sqrt((Y - P)^T (Y - P)) / n`![Image](images/B9780443218576000114/si80.png), where `n` is the number of observations. It is a much better measure of the actual error, compared to the mean squared error (MSE). In particular, if `Y` is measured in (say) miles, then RMSE is measured in miles, while MSE is measured in square miles. Likewise, if `Y` is measured in years, RMSE is measured in years while MSE is measured in square years – a meaningless metric.

*   • The score `s`, with `0 ≤ s ≤ 1`![Image](images/B9780443218576000114/si81.png), defined as `s = 1 − e(P) / e(P[0])`![Image](images/B9780443218576000114/si82.png). Here, `P[0]`![Image](images/B9780443218576000114/si83.png) is the base model, corresponding to `β = 0`![Image](images/B9780443218576000114/si53.png) (thus, the predicted value is constant after adjustment, equal to the mean value of `Y` computed on the training set). In particular, `s` measures the improvement over the base model, using RMSE ratios, while `r` does the same using MSE ratios instead. In my opinion, `s` is more intuitive and more realistic than `r`. It is related to `r` via the formula `r = 2*s − s²`![Image](images/B9780443218576000114/si84.png), or equivalently, `s = 1 - sqrt(1 - r)`![Image](images/B9780443218576000114/si85.png). We always have `r ≥ s`![Image](images/B9780443218576000114/si86.png), so `r` is an inflated measure of goodness-of-fit.

Since the model is trained on the test data set, but model performance is measured on the validation set, the above performance metrics are hybrid. In particular, as a result, the relationship `r = 2*s − s²`![Image](images/B9780443218576000114/si84.png) is almost satisfied, but not exactly. Also, on rare occasions (with very noisy data), `r` can be slightly negative. The performance results are shown in the Results tab, in cells `J13:R19`. I also included the performance metrics for the simple model consisting in using the regression coefficient vector `β = β[0]`![Image](images/B9780443218576000114/si87.png) defined in Section [7.2.3](#Chp007_113-129_B9780443218576000114.xhtml#s0030). In the spreadsheet, this model is referred to as “Predicted `P[b]`![Image](images/B9780443218576000114/si88.png)”.

In addition, the spreadsheet allows you to choose which features to include or not in the model, in the fixed point iteration. The feature selection flags are stored in cells `B4:B9` in the Results tab. The default value is `1`, corresponding to inclusion. This is particularly useful to test how much model improvement is gained by using all features, versus a subset of them. On real data, some features are usually missing because the model developer was not aware of them, and they are not captured in the data set: in other words, they are unobserved. The feature selection flags allow you to compare the performance on observed data, versus the performance obtained with a dream data set that would include all the relevant features.

Finally, the use of synthetic data offers a big benefit: you can test and benchmark algorithms on millions of very different data sets, all at once. This assumes that the synthetic data is properly generated. It is both an art and a science to design such data sets. It typically involves a decent amount of mathematics, sometimes quite advanced. It is my hope that this article will help the reader build good quality, rich synthetic data that covers a large spectrum of potential real life situations. Other synthetic data sets are found in Chapter [5](#Chp005_83-102_B9780443218576000096.xhtml) featuring synthetic clusters, and in Chapter [6](#Chp006_103-111_B9780443218576000102.xhtml) entitled “Computer Vision: Shape Classification via Explainable AI”, featuring synthetic shapes.

### 7.4.1 Results

I tested the methodology on a synthetic data set with `n = 1000`![Image](images/B9780443218576000114/si89.png) observations and `m = 6`![Image](images/B9780443218576000114/si90.png) features. The validation set also has 1000 observations. Because the data is artificially generated, the exact regression coefficients are known. They are listed in the row labeled “Exact” in [Table 7.1](#Chp007_113-129_B9780443218576000114.xhtml#t0010). The observed data `Y` is a mixture of the exact data and artificial noise. The amount of noise is controlled by the parameter Noise in the spreadsheet. The exact data is the vector `Xβ`, with `β` being the true, prespecified regression coefficients (also artificially generated). Note that `X` is also artificially generated, using the method described in Section [7.2.4](#Chp007_113-129_B9780443218576000114.xhtml#s0035).

The metric `r` in the Exact row in [Table 7.1](#Chp007_113-129_B9780443218576000114.xhtml#t0010) measures the R-squared between the observed data `Y` and the exact data. In practice, the exact data is not known. But one of the benefits of using synthetic data is that we can simulate both the unobserved, exact data, and the observed, noisy, unfiltered version, denoted as `Y`.

The metric `r` in [Table 7.1](#Chp007_113-129_B9780443218576000114.xhtml#t0010) is the R-squared, but measured on the validation set, not on the training set. By contrast, in [Fig. 7.3](#Chp007_113-129_B9780443218576000114.xhtml#f0020), the R-squared on the right plot, attached to the blue dots and blue regression line, is computed on the training set. On the left plot, it is computed on the validation set, and it matches the `r` value attached to `β[15]`![Image](images/B9780443218576000114/si91.png) in [Table 7.1](#Chp007_113-129_B9780443218576000114.xhtml#t0010). The blue dots in [Fig. 7.3](#Chp007_113-129_B9780443218576000114.xhtml#f0020) provide the scatterplot of `Y` versus the predicted values obtained with `β[15]`![Image](images/B9780443218576000114/si91.png). The orange dots form the scatterplot of `Y` versus the exact (unobserved) data.
