
点过程的一个实现 `ω` 所对应的点计数，记为 `N[ω]`![Image](images/B9780443218576000205/si55.png)。`m` 个实现的聚合点计数记为 `N`，`m` 个实现的集合记为 `Ω`。现在，对于 `i` = 1, 2, 3![Image](images/B9780443218576000205/si56.png) 和 `j[1]`、`j[2]`、`j[3]` ∈ ℕ![Image](images/B9780443218576000205/si57.png)，我可以定义以下量：

```
p_i(j) = (1/m) ∑_{ω ∈ Ω} χ[N_ω(B_i) = j],
p(j_1, j_2, j_3) = (1/m) ∑_{ω ∈ Ω} ∏_{i=1}^{3} χ[N_ω(B_i) = j_i]
```
![Image](images/B9780443218576000205/si58.png) (16.7)

```
p'(j_1, j_2, j_3) = (1/m^3) ∏_{i=1}^{3} ∑_{ω ∈ Ω} χ[N_ω(B_i) = j_i]
```
![Image](images/B9780443218576000205/si59.png) (16.8)

其中 `χ` 是指示函数 [[Wiki](https://en.wikipedia.org/wiki/Indicator_function)]。例如，`p[1](3) = 0.043`![Image](images/B9780443218576000205/si60.png) 表示在 ![Image](images/B9780443218576000205/fx001.jpg) 个实现中有 43 个实现，区域 `B[1]`![Image](images/B9780443218576000205/si61.png) 恰好包含 3 个点。此外，`p'(j[1], j[2], j[3]) = p[1](j[1]) * p[2](j[2]) * p[3](j[3])`![Image](images/B9780443218576000205/si62.png)。当且仅当公式 [(16.7)](#Chp016_293-327_B9780443218576000205.xhtml#deq9) 和 [(16.8)](#Chp016_293-327_B9780443218576000205.xhtml#deq10) 在 `m` = ∞![Image](images/B9780443218576000205/si66.png) 时表示相同的量，这三个点计数 `N(B[1])`![Image](images/B9780443218576000205/si63.png)、`N(B[2])`![Image](images/B9780443218576000205/si64.png)、`N(B[3])`![Image](images/B9780443218576000205/si65.png) 才是独立分布的。换句话说，如果 `p` → `p'`![Image](images/B9780443218576000205/si67.png) 逐点收敛 [[Wiki](https://en.wikipedia.org/wiki/Pointwise_convergence)]，当 `m` → ∞![Image](images/B9780443218576000205/si68.png) 时，这三个点计数就是独立分布的。

为避免日后混淆，`p` 和 `p'`![Image](images/B9780443218576000205/si69.png) 记为 `p[A]`![Image](images/B9780443218576000205/si70.png) 和 `p[A]'`![Image](images/B9780443218576000205/si71.png)，以强调它们属于过程 `M[A]`![Image](images/B9780443218576000205/si48.png)。为了检验独立性，我模拟了姊妹点过程 `M[B]`![Image](images/B9780443218576000205/si72.png) 的 `m` 个实现：该过程具有相同的三个点计数边缘分布，使用从 `M[A]`![Image](images/B9780443218576000205/si48.png) 获得的估计值 `p[i](j)`![Image](images/B9780443218576000205/si73.png)，但这次点计数由设计保证独立。同样，我定义函数 `p[B]`![Image](images/B9780443218576000205/si74.png) 和 `p[B]'`![Image](images/B9780443218576000205/si75.png)。设 `ρ[A]`![Image](images/B9780443218576000205/si76.png) 为 `p[A]`![Image](images/B9780443218576000205/si70.png) 和 `p[A]'`![Image](images/B9780443218576000205/si71.png) 之间的相关性，计算满足以下条件的所有三元组：

```
min{p[A](j[1], j[2], j[3]), p[A]'(j[1], j[2], j[3])} > ϵ
```
![Image](images/B9780443218576000205/si77.png)

我选择 `ϵ` = 0![Image](images/B9780443218576000205/si78.png)。在我的例子中，这样的三元组少于 7 × 7 × 7 = 343![Image](images/B9780443218576000205/si79.png) 个。最后，检验统计量是 `ρ[A]²`![Image](images/B9780443218576000205/si80.png)。

### 16.1.3.1 结果与解读

在电子表格 [PB_independence.xlsx](https://github.com/VincentGranville/Point-Processes/tree/main/Spreadsheets) 中，标签页 Dataset_A 对应 `M[A]`![Image](images/B9780443218576000205/si48.png)，Dataset_B 对应 `M[B]`![Image](images/B9780443218576000205/si72.png)。在标签页 Dataset_C 中对另一个点过程 `M[C]`![Image](images/B9780443218576000205/si81.png) 进行相同的计算，它与 `M[A]`![Image](images/B9780443218576000205/si48.png) 相同，只是这次 `s` = 4![Image](images/B9780443218576000205/si82.png)。有了这样一个“大”的 `s`，`M[C]`![Image](images/B9780443218576000205/si81.png) 与平稳泊松点过程相差无几：特别是，点计数几乎是独立的（除非使用极大样本，否则没有统计检验能检测出它们不是独立的）。

主要发现显示在 [图 16.2](#Chp016_293-327_B9780443218576000205.xhtml#f0015) 中。蓝色代表 `M[A]`![Image](images/B9780443218576000205/si48.png) 过程，灰色代表 `M[B]`![Image](images/B9780443218576000205/si72.png)，红色代表 `M[C]`![Image](images/B9780443218576000205/si81.png)。每个蓝点对应一个向量 (`p[A]`, `p[A]'`)![Image](images/B9780443218576000205/si83.png)，该向量对应特定的 (`j[1]`, `j[2]`, `j[3]`)![Image](images/B9780443218576000205/si84.png)。在完全独立的情况下，所有点都应落在主对角线上。蓝点离主对角线太远，因此 `M[A]`![Image](images/B9780443218576000205/si48.png) 中的点计数不独立。相反，`M[B]`![Image](images/B9780443218576000205/si72.png) （由设计保证表现出独立性）和 `M[C]`![Image](images/B9780443218576000205/si81.png) （理论上已知表现出近似独立性）彼此足够接近，也足够接近主对角线。如果你用 `M[B]`![Image](images/B9780443218576000205/si72.png) 重复实验一百次，你将得到一百条灰色回归线，从而生成检验的置信曲线。注意，[图 16.2](#Chp016_293-327_B9780443218576000205.xhtml#f0015) 中显示的三条回归线的 `R²`![Image](images/B9780443218576000205/si85.png) 分别等于 `ρ[A]²`![Image](images/B9780443218576000205/si80.png)、`ρ[B]²`![Image](images/B9780443218576000205/si86.png)、`ρ[C]²`![Image](images/B9780443218576000205/si87.png)，证实了 `M[A]`![Image](images/B9780443218576000205/si48.png) 表现略差。回归线的斜率也是缺乏独立性的指标，如果它不够接近 1。再次，按斜率衡量，`M[B]`![Image](images/B9780443218576000205/si72.png) 是这里的“输家”。回归线的截距（当其与零差异足够大时）进一步证实了这一点。
