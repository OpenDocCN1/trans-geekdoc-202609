

## 练习 16.1

- 按以下方式生成一种特定类型的**随机图**，称为**随机 NN 图**。设 `V[1]`，…，`V[n]`![Image](images/B9780443218576000205/si151.png) 为图的 `n` 个**顶点**（它们的位置无关紧要）。对于顶点 `V[k]`![Image](images/B9780443218576000205/si152.png) （`k = 1, …, n`![Image](images/B9780443218576000205/si153.png)）的“最近邻”，从除 `V[k]`![Image](images/B9780443218576000205/si152.png) 本身以外的 `n` 个顶点中随机选取一个。两个点（顶点）可以拥有相同的最近邻。现在通过模拟研究 `S` 的分布。它是否与由平稳泊松点过程中的最近邻生成的图的分布相同？

- 这是最困难的部分。设 `P(S = k)`![Image](images/B9780443218576000205/si154.png)，`k = 2, 3, …`![Image](images/B9780443218576000205/si155.png) 为平稳泊松过程连通分量大小的分布；`S` 是一个随机变量。当然，它不依赖于 `λ`。它是否以同样的方式唯一地刻画了泊松过程，就像指数分布对到达时间间隔的刻画唯一地刻画了一维泊松过程那样？我们是否有 `P(S = 2) = 1/2`![Image](images/B9780443218576000205/si156.png)，不仅对于泊松过程成立，而且对于一大类点过程也成立？

#### 提示

当心**边界效应**；为将其影响降至最低，请对 `F`（附加在泊松-二项过程点上的分布）使用均匀分布，并令 `n > 10^3`![Image](images/B9780443218576000205/si157.png)。当缩放因子 `s` 为零时，只有一个无限大小的连通分量（`P[S = ∞] = 1`![Image](images/B9780443218576000205/si158.png)）：这是一个奇点，如[图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040)左侧图所示。但只要 `s > 0`![Image](images/B9780443218576000205/si141.png)，所有连通分量均为有限大小且相当小。最小的分量包含两个点，因为每个点都有一个最近邻，因此 `P[S < 2] = 0`![Image](images/B9780443218576000205/si159.png)。当 `s = ∞`![Image](images/B9780443218576000205/si106.png) 时，该过程变为平稳泊松过程。

我推测平稳泊松过程和其他一些（如果不是全部）泊松-二项过程共享由最近邻定义的连通分量大小的完全相同的离散概率分布，简称为**CCS 分布**。因此，与点计数分布或最近邻距离分布不同，**CCS 分布**不能用来刻画泊松过程。对于随机图，**CCS 分布**与泊松过程的**CCS 分布**不同。我使用**柯尔莫戈罗夫-斯米尔诺夫检验** [[Wiki](https://en.wikipedia.org/wiki/Kolmogorov-Smirnov_test)]（另见 [[17]](#Chp016_293-327_B9780443218576000205.xhtml#br0085)）来比较两个经验**CCS 分布**——一个属于泊松过程，另一个属于随机 NN 图——并根据我的样本量（`n = 10^4`![Image](images/B9780443218576000205/si148.png) 个点或顶点）得出结论：它们在统计学上是不同的。

总之，**CCS 分布**似乎不能是任意的。许多点过程似乎拥有相同的**CCS 分布**，称为**吸引子分布**，这些过程构成了吸引子的**吸引域**。**吸引域**和**吸引子**的概念用于其他领域，如**动力系统** [[Wiki](https://en.wikipedia.org/wiki/Attractor)] 或极值理论 [[Wiki](https://en.wikipedia.org/wiki/Generalized_extreme_value_distribution)]（另见 [[5]](#Chp016_293-327_B9780443218576000205.xhtml#br0025)，第 317 页）。最著名的类比是**中心极限定理**，其中高斯分布是主要吸引子，柯西分布是另一个。在《概率方法》[[1]](#Chp016_293-327_B9780443218576000205.xhtml#br0005) 第 11 章中，该章处理随机图中连通分量的大小，作者引入了一个随机变量 `T[c]`![Image](images/B9780443218576000205/si160.png)，也用于计数顶点数（书中称为**节点**）。其分布具有吸引子的所有标志。请参阅该书定理 11.4.2（第 202 页）。

要查找连通分量，可以使用 `Section 16.2.4.3` (#Chp016_293-327_B9780443218576000205.xhtml#s0075) 中的源代码。要模拟点过程，可以使用 GitHub 上提供的程序 `PB_NN.py` (https://github.com/VincentGranville/Point-Processes/blob/main/Source%20Code/PB_NN.py)（在 [[20]](#Chp016_293-327_B9780443218576000205.xhtml#br0100) 的 `section 6.4` 中有描述）：它生成一个输出文件 `PB_NN_dist_full.txt` (https://github.com/VincentGranville/Point-Processes/blob/main/Data/PB_NN_dist_full.txt)，无需任何更改即可作为输入用于 `section 16.2.4.3` (#Chp016_293-327_B9780443218576000205.xhtml#s0075) 中的连通分量算法。[练习 16.2](#Chp016_293-327_B9780443218576000205.xhtml#enun0015) 涉及一个类似的问题，处理的是团而非连通分量。

## 练习 16.2

最大团问题。在**无向图** [[Wiki](https://en.wikipedia.org/?title=Undirected_graph)] 中，**团** 是一组相互连接的顶点（也称为节点）。在**最近邻**图中，如果两个点中的一个是另一个的最近邻，则它们相连。你将如何识别此类图中最大规模的团？无需从头设计算法；请查阅文献。寻找最大团 [[Wiki](https://en.wikipedia.org/wiki/Clique_problem)] 是**NP-hard** [[Wiki](https://en.wikipedia.org/wiki/NP-hardness)] 的，该问题与“P 对 NP”猜想 [[Wiki](https://en.wikipedia.org/wiki/P_versus_NP_problem)] 相关。最大团问题有许多应用，特别是在社交网络中。**随机图**中团的概率性质在“随机图中的团” [[6]](#Chp016_293-327_B9780443218576000205.xhtml#br0030) 和“随机图的演化” [[16]](#Chp016_293-327_B9780443218576000205.xhtml#br0080) 中有讨论。另请参阅**Erdős–Rényi 模型** [[Wiki](https://bit.ly/3uzQzNF)]。较新的文章包括 [[18](#Chp016_293-327_B9780443218576000205.xhtml#br0090),[30]](#Chp016_293-327_B9780443218576000205.xhtml#br0150)。
