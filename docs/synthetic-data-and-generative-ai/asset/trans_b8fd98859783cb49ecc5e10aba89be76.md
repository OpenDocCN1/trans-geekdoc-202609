
# 地形视频概览

观看发布在 YouTube 上的视频[此处](https://www.youtube.com/watch?v=RE3Lz559aM0)，快速了解本章讨论的问题。为了获得更好的视觉体验，您可以从我的 GitHub 仓库下载 MP4 文件，[此处](https://github.com/VincentGranville/Visualizations/blob/main/Source-Code/terrainx4_final3.mp4)。[图 14.1](#Chp014_259-276_B9780443218576000187.xhtml#f0010) 展示了该视频的六帧画面：第一帧（左上）、最后一帧（右下），以及中间的四帧过渡画面。每一帧由四幅图像组成，随时间演变。因此，在**动态数据可视化**中有四个子视频并行播放。现在我来描述每一帧中的四幅图像。下面列表中的细节适用于任何特定的视频帧。

## 帧构成

*   顶部的两幅图像在给定特定时间（即帧号）下，代表具有相同物理形状的同一景观。它们演示了**变形**[[Wiki](https://en.wikipedia.org/wiki/Morphing)]的概念：随着时间的推移，一种地形会变成完全不同的另一种地形。每帧左上角的图像展示了分别应用于景观和**调色板**[[Wiki](https://en.wikipedia.org/wiki/Palette_\(computing\))]的独立变形。相反，每帧右上角的图像中，只有地形发生了变形，配色方案没有变。

*   底部的两幅图像代表一个**演化过程**。与变形不同，这涉及统计建模。在这种情况下，我们知道起点，但无法预测其随机路径。幕后的随机过程是平稳的[[Wiki](https://en.wikipedia.org/wiki/Stationary_process)]。该演化过程的一个实际实现（如视频所示）类似于连续时间序列，更准确地说是**反射布朗运动**[[Wiki](https://en.wikipedia.org/wiki/Reflected_Brownian_motion)]，其中每个给定时刻的观测值是一幅图像——地形——而不是有限的数值观测向量。

*   六个视频帧中底部两幅图的左右两侧的区别如下。首先，每幅图使用不同的调色板，左侧模拟云层形成，右侧模拟地形演化。然后，左图基于**混合模型**，而右图基于混合。这两种方法将在本章后面描述。简而言之，**混合**较少受到剧烈振荡的影响，在某种意义上比混合模型方法更不混乱。相反，变形中不存在混乱：过渡总是平滑、非随机且单向的。

## 一般特征

在深入细节之前，本节将描述一些一般特征。首先，我仅关注**平稳过程**：颜色分布、图像颗粒度和任何其他模式——尽管随时间略有变化——在随机意义上是稳定的。**平衡概率分布**与演化过程相关联，这与许多其他**随机动力系统**[[Wiki](https://en.wikipedia.org/wiki/Dynamical_system)]类似。例如，碰撞的气体分子或像 *π* 这样的数字的连续二进制数字都有其自身的平衡分布：后一种情况是模拟抛均匀硬币的独立伯努利试验。描述这种情况的另一种方式是图像的**随机收敛**，或**遍历性**[[Wiki](https://en.wikipedia.org/wiki/Ergodicity)]。

## 调色板与频谱域

然后，调色板起着重要作用。在统计理论中，它被称为**频谱域**，相对应的是称为**状态空间**的物理布局。配色方案的选择决定了您是在建模景观（地形）、云层，还是如左上角图片所示的晶体结构。轮廓的粗糙度是系统的另一个重要参数。我在整个视频中保持其恒定。在 Python 代码中，它由变量 `ds` 表示。

## 地形生成与菱形-方形算法

变形是一个简单的过程，不像基于模型的演化过程模拟那样复杂。然而，生成地形远非显而易见。特别是，寻找一个好的调色板颜色本身就需要一个算法。颜色必须按特定方式排序。调色板中两个相邻颜色的差异必须很小，有一个例外：从海洋到陆地的过渡是剧烈的，因此产生了清晰的海岸线。当然，您也可以随时从现有的真实图像中提取或计算调色板。详情请参阅[[1](#Chp014_259-276_B9780443218576000187.xhtml#br0005)–[3](#Chp014_259-276_B9780443218576000187.xhtml#br0015)]。地形的物理布局是使用**菱形-方形算法**[[Wiki](https://en.wikipedia.org/wiki/Diamond-square_algorithm)]创建的，详见第 [14.2](#Chp014_259-276_B9780443218576000187.xhtml#s0015) 节。该维基百科条目介绍了其在等离子体分形中的应用。

## 调色板操作

由于**调色板** `M` 是一个取值在 0 和 1 之间的矩形数组，调色板可以进行逐元素乘法，或者您可以计算幂 `M^α`![Image](images/B9780443218576000187/si1.png) （其中 `α ≥ 0`![Image](images/B9780443218576000187/si2.png)），仍然能得到一个有效的调色板。在 Python 中使用 `numpy` 数组时，这些逐元素操作只需一行代码即可完成。这会产生有趣的结果，我在代码中使用了它。通常，`M` 的每一行是一个颜色条目，包含三个分量：红、绿、蓝。您可以添加第四个分量称为 alpha，代表**颜色透明度**或不透明度[[Wiki](https://en.wikipedia.org/wiki/Alpha_compositing)]。

## 种子与伪随机数

该算法提供无限数量的地形供您选择，作为视频的起点，或在变形情况下的终点。地形由一个唯一数字标识：构建地形时伪随机数生成器 (PRNG) 中使用的**种子**[[Wiki](https://en.wikipedia.org/wiki/Random_seed)]。这里讨论的视频有 100 帧，每帧由 4 幅图像组成，每幅图像需要 ![Image](images/B9780443218576000187/fx001.jpg) 次调用 Python 函数 `random()`。因此，您需要 3 × 10⁸![Image](images/B9780443218576000187/si3.png) 个伪随机数来生成一个视频。Python 使用**梅森旋转算法**[[Wiki](https://en.wikipedia.org/wiki/Mersenne_Twister)]作为其 PRNG，周期等于 2^(19937) − 1![Image](images/B9780443218576000187/si4.png)。然而，正如第 [11](#Chp011_203-228_B9780443218576000151.xhtml) 章所讨论的，这个 PRNG 存在缺陷：必须避免某些种子。

## 应用

最后，您可以将该方法论作为一种生成模型技术，用于自动生成并标记大量不同的景观（山脉、海洋、陆地、组合等），以创建大型合成数据训练集。该训练集与真实数据混合后，可用作景观分类的**增强数据**，或用于生成特定类别内的地形以进一步丰富分类器；请参阅第 [1.4](#Chp001_1-34_B9780443218576000059.xhtml) 节了解如何在类似背景下操作。调色板的选择使得聚类和分类变得容易。可能的应用包括在地球及其他星球上建模气候演化、天气模式或板块运动。您也可以将其用于 AI 生成艺术或视频游戏设计。虽然我主要关注 2D 模拟，但我在第 [14.4](#Chp014_259-276_B9780443218576000187.xhtml#s0060) 节中简要讨论了 3D 轮廓。
