
如果序列 `b[n]`![图片](images/B9780443218576000175/si36.png) 收敛，函数 `f` 连续且 `μ ≠ 0`![图片](images/B9780443218576000175/si37.png)，则 `b[n]`![图片](images/B9780443218576000175/si38.png) 必须收敛到某个 `b^*`![图片](images/B9780443218576000175/si39.png)，使得 `f(b^*) = 0`![图片](images/B9780443218576000175/si40.png)，因此 `b[n]`![图片](images/B9780443218576000175/si38.png) 收敛到 `f` 的一个根。你可以允许 `μ` 依赖于 `n`，在一个例子中，我成功使用了 `μ = 1/√(b_n)`![图片](images/B9780443218576000175/si41.png)。这里使用的函数 `f` 实际上是第 [13.2.1](#Chp013_243-258_B9780443218576000175.xhtml#s0025) 节中定义并在 [图 13.3](#Chp013_243-258_B9780443218576000175.xhtml#f0020) 中用蓝色显示（印刷版为深灰色）的函数 `f[3]`![图片](images/B9780443218576000175/si29.png)。该函数甚至不连续，不动点迭代也不收敛。其他函数将在第 [13.3](#Chp013_243-258_B9780443218576000175.xhtml#s0040) 节中探讨。这里的目的是解释尽管缺乏收敛性，不动点迭代如何仍能帮助找到根。

Python 代码中的许多参数在第 [13.2.1](#Chp013_243-258_B9780443218576000175.xhtml#s0025) 节中有描述，包括 offset、slope 和 logeps。参数 eps 对应第 [13.1.1](#Chp013_243-258_B9780443218576000175.xhtml#s0015) 节中的 `ϵ`。驱动不动点迭代的主要参数有：

- `mu`，对应公式 [(13.2)](#Chp013_243-258_B9780443218576000175.xhtml#deq4) 中的 `μ`。较大的值会导致不动点迭代中出现更大的跳跃，使你能更快地找到根，但当 `μ` 变得太大时，会增加错过所有根的风险。
- `window`，对应第 [13.2.1](#Chp013_243-258_B9780443218576000175.xhtml#s0025) 节中的 `w`。较大的 `w` 会增加找到根的机会。代价是精度降低。如果 `b^*`![图片](images/B9780443218576000175/si39.png) 是一个根，且不动点迭代成功定位了它，它不会找到确切的 `b^*`![图片](images/B9780443218576000175/si39.png)，而是会告诉你在区间 `[b^* - w, b^* + w]`![图片](images/B9780443218576000175/si42.png) 内可能存在一个根，而不知道实际的 `b^*`![图片](images/B9780443218576000175/si39.png) 是什么。因此，较大的 `w` 有助于获得根所在位置的粗略近似。

我在第 [13.2.3](#Chp013_243-258_B9780443218576000175.xhtml#s0035) 节通过一个实际例子展示了这些特性，以及该算法与暴力法相比有多快。对于此处讨论的这类函数，该算法不收敛：随着 `n` 增加，连续迭代值 `b[n]`![图片](images/B9780443218576000175/si38.png) 变得越来越大，或者它们可能振荡而永不收敛。当然，如果函数足够光滑且参数合适，它会收敛。但我们对那种情况不感兴趣。

既然我的例子中不存在收敛性，算法如何检测根？现在我解释它是如何工作的。首先，定义 `Δ[n] = b[n] - b[n-1]`![图片](images/B9780443218576000175/si43.png)。然后令 `ρ[n] = Δ[n] / Δ[n-1]`![图片](images/B9780443218576000175/si44.png)。数值 `ρ[n]`![图片](images/B9780443218576000175/si16.png) 称为第 `n` 次迭代的 `signal`（信号）。通常，`ρ[n] ≈ 1`![图片](images/B9780443218576000175/si45.png)。如果 `ρ[n]`![图片](images/B9780443218576000175/si16.png) 异常地低或高，我们就说信号很强。在我的例子中，值 `ρ[n] > 2`![图片](images/B9780443218576000175/si46.png) 通常意味着在 `b[n-1]`![图片](images/B9780443218576000175/si47.png) 附近有一个根。详细内容见第 [13.2.3](#Chp013_243-258_B9780443218576000175.xhtml#s0035) 节。

最后，此处研究的函数有许多接近零的值。由测试大量数值组成的暴力法甚至可能完全行不通。在大多数情况下，找到使 `f[0](b) = 0.001`![图片](images/B9780443218576000175/si48.png) 的 `b`，并不意味着在 `b` 附近存在 `b^*`![图片](images/B9780443218576000175/si39.png) 使得 `f[0](b^*) = 0`![图片](images/B9780443218576000175/si49.png)。出于同样的原因，高效但朴素的 `bisection method`（二分法）[[Wiki](https://en.wikipedia.org/wiki/Bisection_method)] 也会失败。请注意，我的方法是经验性的：强信号并不总是对应一个根，而没有强信号并不意味着没有根。使用不同的参数集进行测试会有帮助。

### 13.2.3 案例研究：分解两个大素数的乘积

这里的目标是找到函数 `f[0](b)`![图片](images/B9780443218576000175/si50.png) 的两个根中的至少一个，该函数如 [图 13.1](#Chp013_243-258_B9780443218576000175.xhtml#f0010) 所示，并由 [(13.1)](#Chp013_243-258_B9780443218576000175.xhtml#deq1) 定义。使用第 [13.2.1](#Chp013_243-258_B9780443218576000175.xhtml#s0025) 节中描述的变换，我将在不动点迭代（公式 [(13.2)](#Chp013_243-258_B9780443218576000175.xhtml#deq4)）中实际使用第三个变换 `f[3](b)`![图片](images/B9780443218576000175/si51.png)，从 `b[0] = 2000`![图片](images/B9780443218576000175/si52.png) 开始。这两个根是 `a = 7919 × 3083`![图片](images/B9780443218576000175/si53.png) 的两个素因子，即 `b^* = 3083`![图片](images/B9780443218576000175/si54.png) 和 `b^* = 7919`![图片](images/B9780443218576000175/si55.png)。因此，找到一个根就很容易找到另一个。
