
至于实际的数字计算，此处仅限于 ![Image](images/B9780443218576000151/fx007.jpg)位数字，但我将这些数字与从外部来源获得的数字进行了比较：Sagemath，见[此处](https://mltblog.com/3uMZQ4s)。正如预期的那样，结果显示两种方法产生相同的数字，特别是对于数字 `$\sqrt{2}/2$`![Image](images/B9780443218576000151/si124.png)。

用于数字计算的特殊递归如下：

```
If z[k] < 2*y[k] then  # ![Image](images/B9780443218576000151/si168.png)
    y[k+1] = 4*y[k] - 2*z[k]  # ![Image](images/B9780443218576000151/si169.png)
    z[k+1] = 2*z[k] + 3  # ![Image](images/B9780443218576000151/si170.png)
    d(k) = 1  # ![Image](images/B9780443218576000151/si92.png)
else
    y[k+1] = 4*y[k]  # ![Image](images/B9780443218576000151/si171.png)
    z[k+1] = 2*z[k] - 1  # ![Image](images/B9780443218576000151/si172.png)
    d(k) = 0  # ![Image](images/B9780443218576000151/si173.png)
```

二元种子（初始条件）由 `y[0]`![Image](images/B9780443218576000151/si174.png) 和 `z[0]`![Image](images/B9780443218576000151/si175.png) 的值决定。您需要 `z[0] > y[0]`![Image](images/B9780443218576000151/si176.png) 和 `z[0] ≠ 2*y[0]`![Image](images/B9780443218576000151/si177.png)。然后二进制数字 `d(k)`![Image](images/B9780443218576000151/si29.png) 就是该数字的数字：

$x\_{0} = \\frac{- (z\_{0} - 1) + \\sqrt{{(z\_{0} - 1)}^{2} + 8y\_{0}}}{4},$

![Image](images/B9780443218576000151/si178.png)

见[此处](https://mltblog.com/3REtOB9)。特别是，如果 `y[0] = 2, z[0] = 5`![Image](images/B9780443218576000151/si179.png)，则 `$x\_{0} = - 1 + \\sqrt{2}$`![Image](images/B9780443218576000151/si180.png)。使用变量替换 `u[k] = 2*y[k] - z[k]`![Image](images/B9780443218576000151/si181.png) 和 `v[k] = 2*z[k] + 3`![Image](images/B9780443218576000151/si182.png)，递推关系可以重写为：

```
If u[k] > 0 then  # ![Image](images/B9780443218576000151/si183.png)
    u[k+1] = 4*u[k] - v[k]  # ![Image](images/B9780443218576000151/si184.png)
    v[k+1] = 2*v[k] + 3  # ![Image](images/B9780443218576000151/si185.png)
    d(k) = 1  # ![Image](images/B9780443218576000151/si92.png)
else
    u[k+1] = 4*u[k] + v[k] - 2  # ![Image](images/B9780443218576000151/si186.png)
    v[k+1] = 2*v[k] - 5  # ![Image](images/B9780443218576000151/si187.png)
    d(k) = 0  # ![Image](images/B9780443218576000151/si173.png)
```

现在 `v[k] - 5`![Image](images/B9780443218576000151/si188.png) 可被 8 整除。令 `w[k] = (v[k] - 5)/8`![Image](images/B9780443218576000151/si189.png)。如果 `w[k+1]`![Image](images/B9780443218576000151/si190.png) 为奇数，则 `d(k) = 1`![Image](images/B9780443218576000151/si92.png)，否则 `d(k) = 0`![Image](images/B9780443218576000151/si173.png)。我们还有一个一维后向递归，允许您一直向后计算数字直到第一位数字：

```
If w[k+1] is odd then  # ![Image](images/B9780443218576000151/si190.png)
    v[k] = (v[k+1] - 3)/2  # ![Image](images/B9780443218576000151/si192.png)
    d(k) = 1  # ![Image](images/B9780443218576000151/si92.png)
else
    v[k] = (v[k+1] + 5)/2  # ![Image](images/B9780443218576000151/si193.png)
    d(k) = 0  # ![Image](images/B9780443218576000151/si173.png)
```

## 11.4 基于二次无理数的军用级 PRNG

如果您生成模拟或创建合成数据，需要数十亿或数万亿个随机数（如第 [1.3.4.1](#Chp001_1-34_B9780443218576000059.xhtml) 节所示），您需要一个伪随机数生成器（PRNG），它不仅要快，在某些情况下还要真正模拟随机性。通常您无法兼得两者。同余 PRNG 非常快，且在模拟随机性方面表现相当不错。Python 和其他语言中可用的梅森旋转算法拥有非常大的周期，足以满足任何实际需求。然而，根据种子的不同，它存在由素数分布缺乏完美随机性引起的缺陷。这些缺陷是在第 [11.2.2](#Chp011_203-228_B9780443218576000151.xhtml#s0040) 节中的**素数测试**中揭示的。相反，如果您跳过前几位数字并仔细选择数字，基于无理数的 PRNG 表现出更强的随机性。但它们往往非常慢。

在本节中，我提出了一种新方法，基于第 [11.3.3](#Chp011_203-228_B9780443218576000151.xhtml#s0070) 节的算法，从**二次无理数** [[维基百科](https://en.wikipedia.org/wiki/Quadratic_irrational_number)] 的组合（如 `$\sqrt{2}$`![Image](images/B9780443218576000151/si111.png) 或 `$\sqrt{7583}$`![Image](images/B9780443218576000151/si194.png)）中获取数十亿到数万亿位数字。目标是生成可复现的随机数。如果您想将其用于强加密，则需要使用硬件生成的种子，以确保同一种子永远不会被使用超过一次。

### 11.4.1 植根于高等解析数论的快速算法

获得快速算法的思路很简单。我不是从单个数字生成 `n` 位数字，而是从 `m` 个不同的数字生成 `r` 位数字，其中 `n = r*m`![Image](images/B9780443218576000151/si195.png)。虽然 Python 代码仅依赖基本加法和极少量操作，但单个无理数的 `n` 位二进制数字的计算涉及非常大的整数。**计算复杂度**为 `O(n²)`![Image](images/B9780443218576000151/si196.png)。如果改为从 `m` 个数字生成 `r` 位数字，计算复杂度降为 `O(r*m²)`![Image](images/B9780443218576000151/si197.png)。在最极端且非常有趣的情况下，即 `r = n`![Image](images/B9780443218576000151/si198.png) 和 `m = 1`![Image](images/B9780443218576000151/si199.png)，计算复杂度为 `O(n)`![Image](images/B9780443218576000151/si200.png)，速度与梅森旋转算法一样快。该方法基于数论中的两个深刻结论：

*   •  二次无理数的二进制数字表现为独立伯努利试验的无限实现，0 和 1 的比例相等。这个未经证实的猜想是数学中最困难的未解问题之一。涉及数万亿位数字的非常有力的实证结果支持这一假设。

*   •  来自在有理数集 `ℚ`![Image](images/B9780443218576000151/si201.png) 上线性无关的无理数的两个数字序列具有零互相关。这里的相关性定义为经验相关性。

后者是以下定理的推论：由 `k = 0, 1`![Image](images/B9780443218576000151/si205.png) 等索引的序列 (`{p b^k α}`)![Image](images/B9780443218576000151/si203.png) 和 (`{q b^k α}`)![Image](images/B9780443218576000151/si204.png) 之间的相关性 `ρ(p, q)`![Image](images/B9780443218576000151/si202.png) 等于 `ρ(p, q) = (p q)^(-1)`![Image](images/B9780443218576000151/si206.png)，其中 `p, q`![Image](images/B9780443218576000151/si103.png) 是互质的正整数，`b > 1`![Image](images/B9780443218576000151/si100.png) 是整数，`α` 是正无理数。这里 `{ ⋅ }`![Image](images/B9780443218576000151/si207.png) 表示小数部分函数。
