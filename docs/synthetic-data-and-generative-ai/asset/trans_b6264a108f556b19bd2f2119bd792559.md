
`δ[n]`![Image](images/B9780443218576000163/si72.png)的求和是有限的，因为如果`m` > `n`![Image](images/B9780443218576000163/si74.png)，则`p[n](m)` = 0![Image](images/B9780443218576000163/si73.png)。当然，`Var[S[0]]` = 0![Image](images/B9780443218576000163/si75.png)。此外，如果`ϵ` = 0![Image](images/B9780443218576000163/si57.png)，该序列是完全随机的：`δ[n]` = 0![Image](images/B9780443218576000163/si76.png)，`Var[S[n]]` = `n`![Image](images/B9780443218576000163/si77.png)，且`` `$S_n/\\sqrt{n}` ``![Image](images/B9780443218576000163/si78.png)收敛于正态分布。反过来，迭代对数律得以满足。反之，如果`ϵ` > 0![Image](images/B9780443218576000163/si79.png)，则该定律被违背。公式[(12.3)](#Chp012_229-241_B9780443218576000163.xhtml#deq7)结合`Hoeffding's inequality` [[维基](https://en.wikipedia.org/wiki/Hoeffding%27s_inequality)]，可能为`Var[S[n]]`![Image](images/B9780443218576000163/si80.png)提供一些界限。

[图 12.3](#Chp012_229-241_B9780443218576000163.xhtml#f0020)展示了四种修正随机游走的`δ[n]`![Image](images/B9780443218576000163/si72.png)，采用以下配色方案：

*   •  黄色：`g(n)` = 10![Image](images/B9780443218576000163/si81.png)，`ϵ` = 0.05![Image](images/B9780443218576000163/si59.png)
*   •  红色：`g(n)` = `n^(β)`![Image](images/B9780443218576000163/si60.png)，`β` = 0.50![Image](images/B9780443218576000163/si82.png)，`ϵ` = 0.05![Image](images/B9780443218576000163/si59.png)
*   •  蓝色：`g(n)` = `n^(β)`![Image](images/B9780443218576000163/si60.png)，`β` = 0.45![Image](images/B9780443218576000163/si83.png)，`ϵ` = 0.05![Image](images/B9780443218576000163/si59.png)
*   •  紫色：`g(n)` = `n^(β)`![Image](images/B9780443218576000163/si60.png)，`β` = 0.55![Image](images/B9780443218576000163/si84.png)，`ϵ` = 0.05![Image](images/B9780443218576000163/si59.png)

与X轴重合的曲线（`δ[n]` = 0![Image](images/B9780443218576000163/si76.png)）对应于`ϵ` = 0![Image](images/B9780443218576000163/si57.png)，即无论`g(n)`![Image](images/B9780443218576000163/si51.png)如何，均为纯随机性。该曲线在[图 12.3](#Chp012_229-241_B9780443218576000163.xhtml#f0020)中未着色。最后，第[12.3.1](#Chp012_229-241_B9780443218576000163.xhtml#s0065)节中的Python代码使用两种不同的方法精确计算`Var[S[n]]`![Image](images/B9780443218576000163/si80.png)（而非通过模拟），证明了公式[(12.3)](#Chp012_229-241_B9780443218576000163.xhtml#deq7)是正确的。

### 12.1.3 随机游走的熵小于纯随机信号

在第[12.1.2](#Chp012_229-241_B9780443218576000163.xhtml#s0020)节中，我专注于创建振荡率高于随机性所决定水平的序列，从而导致振幅降低。做相反的事情——降低振荡率——更为困难。例如，使用`g(n)` = `n^(β)`![Image](images/B9780443218576000163/si60.png)且`` `$\\beta > \\frac{1}{2}` ``![Image](images/B9780443218576000163/si85.png)将不起作用。由于迭代对数律，你无法超越`` `$\\sqrt{n}` ``![Image](images/B9780443218576000163/si52.png)：将`β`提升到阈值`` `$\\frac{1}{2}` ``![Image](images/B9780443218576000163/si86.png)之以上是无用的。

一种变通方法是使用以下算法：

```
 *S* = 0![Image](images/B9780443218576000163/si35.png)
 **For** *n* = 1, 2, …![Image](images/B9780443218576000163/si36.png)
  Generate random deviate *U* on \[0, 1\]![Image](images/B9780443218576000163/si37.png)
  *M* = *g*(*n*)![Image](images/B9780443218576000163/si38.png)
  **If** ( − *M* < *S* < 0![Image](images/B9780443218576000163/si87.png) and $U < \\frac{1}{2} + \\epsilon$![Image](images/B9780443218576000163/si42.png)) or (0 < *S* < *M*![Image](images/B9780443218576000163/si88.png) and $U < \\frac{1}{2} - \\epsilon$![Image](images/B9780443218576000163/si40.png)) or (*S* = 0![Image](images/B9780443218576000163/si35.png) and $U < \\frac{1}{2}$![Image](images/B9780443218576000163/si44.png))
  **Then**
*X*[*n*] =  − 1![Image](images/B9780443218576000163/si45.png)
  **Else**
*X*[*n*] = 1![Image](images/B9780443218576000163/si46.png)
  *S* = *S* + *X*[*n*]![Image](images/B9780443218576000163/si47.png)
  *S*[*n*] = *S*![Image](images/B9780443218576000163/si48.png)
```

第[12.3.2](#Chp012_229-241_B9780443218576000163.xhtml#s0070)节中的Python代码（选项deviations='Large'）执行此模拟。[图 12.1](#Chp012_229-241_B9780443218576000163.xhtml#f0010)中的黄色时间序列是这种修正随机游走的一个实现，此时`g(n)` = `α n^(β)`![Image](images/B9780443218576000163/si53.png)，其中`α` = 0.30![Image](images/B9780443218576000163/si89.png)，`β` = 0.54![Image](images/B9780443218576000163/si90.png)，且`ϵ` = 0.01![Image](images/B9780443218576000163/si91.png)。黄色曲线在![Image](images/B9780443218576000163/fx001.jpg)次迭代后是否会再次穿越水平轴尚不清楚，但预期会穿越。相反，其他三条曲线（灰色、红色、蓝色）保证会无限次穿越水平轴，尽管测量两次穿越间隔的随机变量`T`（在第[12.1.1](#Chp012_229-241_B9780443218576000163.xhtml#s0015)节中称为`hitting time`）具有无限期望。

对于纯随机游走（[图 12.1](#Chp012_229-241_B9780443218576000163.xhtml#f0010)中的灰色曲线），当0 < `k` ≤ 2`n`![Image](images/B9780443218576000163/si92.png)时，`S[k]` = 0![Image](images/B9780443218576000163/si16.png)的平均次数渐近等于`` `$\\sqrt{4n/\\pi}` ``![Image](images/B9780443218576000163/si93.png)，正如第[12.1.1](#Chp012_229-241_B9780443218576000163.xhtml#s0015)节所讨论的。当![Image](images/B9780443218576000163/fx004.jpg)时，预期该值约为178。对于灰色曲线，观测值为243。请记住，由于`E[T]` = ∞![Image](images/B9780443218576000163/si28.png)，同一随机游走的不同实现之间预期会存在巨大差异。事实上，在三次实现的平均值中，243降至185。此外，有缺陷的伪随机数生成器在此情况下也很容易导致结果偏差。

对于“非随机”的红色和蓝色曲线，预期会有大得多的值。基于各自单次实现，观测值分别为747和1783。同样，黄色曲线预期会有小得多的值：在[图 12.1](#Chp012_229-241_B9780443218576000163.xhtml#f0010)中，该值为105。

## 12.2 相关随机过程

存在无数种随机游走或准布朗运动，它们——有目的且经过设计——并非完全随机。人们可以就此主题写一部百科全书。一个很好的参考是Mörters和Peres的书[\[8\]](#Chp012_229-241_B9780443218576000163.xhtml#br0040)，出版于2010年。本节的目标是展示两个例子（其中一个是二维的），它们非常新颖、有趣，且与第[12.1](#Chp012_229-241_B9780443218576000163.xhtml#s0010)节讨论的材料相关。我在过去两年中构建了这些随机过程，旨在解决金融科技应用中的建模问题。

### 12.2.1 从布朗运动到聚类莱维飞行

这里我讨论使用特定概率分布生成的二维布朗运动。根据参数，这些分布可能具有或不具有无限期望或方差。当期望变为无限时（此时布朗运动不再是布朗运动），事情开始变得有趣，导致系统表现出强烈的聚类结构。
