## 9.2 第二种方法

到目前为止，我相当成功地隐藏了底层数学原理，使表述更易理解，同时不失深度。这里的数学成分明显增多。傅里叶级数再次登场。本节涵盖插值和回归，包括一元和多元，不仅针对数据集，也针对数学函数。在数学研究方面没有新意：创新在于呈现和使用该方法论的角度。这导出了非常简单、优雅且稳健的多元回归方法。

### 9.2.1 从不稳定的多项式到稳健的正交回归

逼近函数的经典方法是使用**普通最小二乘法** \[[维基](https://en.wikipedia.org/wiki/Ordinary_least_squares)\]。确实，回归技术往往以这样或那样的方式依赖这一优化技术。当响应变量记为 `f(x)`![Image](images/B9780443218576000138/si89.png)，特征向量记为 `x` 时，问题在于寻找系数 `α[1], …, α[n]`![Image](images/B9780443218576000138/si90.png) 使得

```
f_n(x) ≡ ∑_{k=0}^{n} α_k p_k(x)
```

![Image](images/B9780443218576000138/si91.png)(9.8)

是对 `f(x)`![Image](images/B9780443218576000138/si89.png) 的“最佳”逼近。正如第 [9.1.2](#Chp009_147-168_B9780443218576000138.xhtml#s0020) 节的时间序列应用中那样，函数 `f` 可以是一个数学函数，也可以代表数据集中的观测值。在后一种情况下，`f` 仅在对应数据集条目的有限个自变量 `x` 处已知。无论哪种情况，问题都归结为插值 `f`。处理真实数据时，这通常被称为回归问题，函数 `f` 允许你通过公式 [(9.8)](#Chp009_147-168_B9780443218576000138.xhtml#deq10) 预测不在训练集中的新观测值 `x` 的响应。此外，`n` 不是观测值的数量，而是与优化算法相关的迭代循环中的索引。

传统上，在多项式回归中 `p_k(x) = x^k`![Image](images/B9780443218576000138/si92.png)。在经典多元回归中，`p_k(x)`![Image](images/B9780443218576000138/si93.png) 是特征向量 `x` 的第 `k` 个分量，可能经过归一化等变换，其中 `p_0(x) = 1`![Image](images/B9780443218576000138/si94.png) 对应截距项。这里，我从另一个角度切入该问题。思路是构建一个函数序列 `(f_n)`![Image](images/B9780443218576000138/si95.png)，当 `n → ∞`![Image](images/B9780443218576000138/si96.png) 时收敛于 `f`，初始为 `f_{-1}(x) = 0`![Image](images/B9780443218576000138/si97.png)。在第 `n` 次迭代中，选择函数 `f_n`![Image](images/B9780443218576000138/si98.png) 以最小化

```
δ(α_n) ≡ ∫_D (f_n(x) - f(x))² dx = ∫_D (α_n p_n(x) + f_{n-1}(x) - f(x))² dx,
```

![Image](images/B9780443218576000138/si99.png)(9.9)
