
### 3.2.3 Square root of a matrix

Formula [(3.4)](#Chp003_49-60_B9780443218576000072.xhtml#deq8) works not only for integer values of `n`, but can be extended to fractional arguments, such as `n = 1/2`![Image](images/B9780443218576000072/si28.png). Here, I illustrate how it works on an example. Thus, I show how to compute the `square root of a matrix` [[Wiki](https://en.wikipedia.org/wiki/Square_root_of_a_matrix)], using the methodology developed so far. This problem has many applications, especially when the matrix `A` is symmetric `positive semidefinite` [[Wiki](https://en.wikipedia.org/wiki/Definite_matrix)]: then it has only one symmetric positive semidefinite square root, denoted as `A^(1/2)`![Image](images/B9780443218576000072/si29.png). See, for instance, Chapter [7](#Chp007_113-129_B9780443218576000114.xhtml) on linear regression and synthetic data, especially Section [7.2.1](#Chp007_113-129_B9780443218576000114.xhtml) entitled “correlation structure”. The square root is needed to generate synthetic data with a prespecified correlation matrix.

Now, using formula [(3.4)](#Chp003_49-60_B9780443218576000072.xhtml#deq8) with `n = 1/2`![Image](images/B9780443218576000072/si28.png), let us compute the square root of the `2×2`![Image](images/B9780443218576000072/si1.png) matrix `A` defined as

```
A = \left( \begin{array}{rr} {3\quad} & 1 \\ {1\quad} & 1 \\ \end{array} \right).
```

![Image](images/B9780443218576000072/si30.png)

Its `characteristic polynomial`, according to formula [(3.1)](#Chp003_49-60_B9780443218576000072.xhtml#deq4), is `x² - 4x + 2`![Image](images/B9780443218576000072/si31.png). The roots are `r_1 = 1 + \sqrt{2}`![Image](images/B9780443218576000072/si32.png) and `r_2 = 1 - \sqrt{2}`![Image](images/B9780443218576000072/si33.png), and are both real and positive. According to formula [(3.2)](#Chp003_49-60_B9780443218576000072.xhtml#deq6), the matrices `Q[1]`, `Q[2]`![Image](images/B9780443218576000072/si34.png) are respectively equal to

```
Q_1 = \frac{A - r_2 I}{r_1 - r_2} = \frac{1}{4} \cdot \begin{pmatrix} {2 + \sqrt{2}\quad} & \sqrt{2} \\ {\sqrt{2}\quad} & {2 - \sqrt{2}} \\ \end{pmatrix},\quad Q_2 = \frac{A - r_1 I}{r_2 - r_1} = \frac{1}{4} \cdot \begin{pmatrix} {2 - \sqrt{2}\quad} & {- \sqrt{2}} \\ {- \sqrt{2}\quad} & {2 + \sqrt{2}} \\ \end{pmatrix}.
```

![Image](images/B9780443218576000072/si35.png)

The matrix `A` has one positive definite square root, namely

```
A^{1/2} = \sqrt{r_1} \cdot Q_1 + \sqrt{r_2} \cdot Q_2 = \frac{1}{2}\begin{pmatrix} {\sqrt{10 + \sqrt{2}}\quad} & \sqrt{2 - \sqrt{2}} \\ {\sqrt{2 - \sqrt{2}}\quad} & \sqrt{2 + \sqrt{2}} \\ \end{pmatrix}.
```

![Image](images/B9780443218576000072/si36.png)

It is easy to show that `A^(1/2) ⋅ A^(1/2) = A`![Image](images/B9780443218576000072/si37.png). In higher dimensions, the Vandermonde system [(3.4)](#Chp003_49-60_B9780443218576000072.xhtml#deq8) is solved using the method described in Section [3.4.2](#Chp003_49-60_B9780443218576000072.xhtml#s0075).

## 3.3 Application to machine learning problems

I discussed principal component analysis (PCA), data compression via PCA, and pseudoinverse matrices in Section [3.2](#Chp003_49-60_B9780443218576000072.xhtml#s0015). Here I focus on applications to time series, Markov chains, and linear regression.

### 3.3.1 Markov chains

A `Markov chain` [[Wiki](https://en.wikipedia.org/wiki/Markov_chain)] is a particular type of time series or stochastic process. At iteration or time `n`, a system is in a particular state `i` with probability `P[n](i)`![Image](images/B9780443218576000072/si38.png). The probability to move from state `i` at time `n` to state `j` at time `n + 1`![Image](images/B9780443218576000072/si39.png) is called a transition probability and denoted as `p[i*j]`![Image](images/B9780443218576000072/si40.png). It does not depend on `n`, but only on `i` and `j`. The Markov chain is governed by its initial conditions `P[0](i)`, `1 ≤ i ≤ p`![Image](images/B9780443218576000072/si41.png), and the transition probability matrix denoted as `A`, containing the elements `p[i*j]`![Image](images/B9780443218576000072/si40.png). The size of the transition matrix is `p × p`![Image](images/B9780443218576000072/si14.png), where `p` is the number of potential states in the system. Thus `1 ≤ i, j ≤ p`![Image](images/B9780443218576000072/si42.png). As `n` tends to infinity, `A^(n)`![Image](images/B9780443218576000072/si13.png) and the whole system reaches an equilibrium distribution. This is because

*   The `characteristic polynomial` attached to `A` has a root equal to 1.
*   The absolute value of any root is less than or equal to 1.

### 3.3.2 Time series: autoregressive processes

Autoregressive processes (AR) [[Wiki](https://en.wikipedia.org/wiki/Autoregressive_model)] represent another basic type of time series. Unlike Markov chains, the number of potential states is infinite, and a state can be any real value, not just an integer. Yet the time is still discrete. Time-continuous AR processes such as `Gaussian processes` [[Wiki](https://en.wikipedia.org/wiki/Gaussian_process)] are not included in this discussion. An `AR(p)` process is defined as follows:

```
X[n] = a[1]X[n-1] + ⋯ + a[p]X[n-p] + e[n].
```

![Image](images/B9780443218576000072/si43.png)

Its `characteristic polynomial` is

```
x^(p) = a[1]x^(p-1) + a[2]x^(p-2) + ⋯ + a[p-1]x + a[p].
```

![Image](images/B9780443218576000072/si44.png)(3.5)

Here `{e[n]}`![Image](images/B9780443218576000072/si45.png) is a `white noise` process (typically uncorrelated Gaussian variables with same variance) [[Wiki](https://en.wikipedia.org/wiki/White_noise)]. We assume that all expectations are zero. We are dealing here with a nonhomogeneous linear (stochastic) recurrence relation. The most interesting case is when all the roots of the characteristic polynomial have absolute value less than 1. Processes satisfying this condition are called `stationary`. In that case, the `autocorrelations` are decaying exponentially fast.

The lag-`k` covariances satisfy the relation

```
\gamma_k = Cov[X_n, X_{n-k}] = \begin{cases} a_1\gamma(k-1) + \cdots + a_p\gamma(k-p) & \text{if } k \neq 0, \\ a_1\gamma(k-1) + \cdots + a_p\gamma(k-p) + \sigma^2 & \text{if } k = 0, \end{cases}
```

![Image](images/B9780443218576000072/si46.png)

with

```
\sigma^2 = Var[e[n]],\quad Var[X[n]] = \gamma(0),\quad \rho(k) = Corr[X[n], X[n-k]] = \gamma(k)/\gamma(0).
```

![Image](images/B9780443218576000072/si47.png)

Thus the autocorrelations can be explicitly computed, and are also related to the characteristic polynomial. This fact can be used for model fitting, as the autocorrelation structure uniquely characterizes the (stationary) time series. Note that if the white noise is Gaussian, then the `X[n]`![Image](images/B9780443218576000072/si48.png)'s are also Gaussian.

More about the autocorrelation structure can be found in lecture notes from Marc-Andreas Muendler [[7]](#Chp003_49-60_B9780443218576000072.xhtml#br0035), who teaches economics at UCSD. His material is very similar to what I discuss here, but more comprehensive. See also Barbara Bogacka's lecture notes on time series [[1]](#Chp003_49-60_B9780443218576000072.xhtml#br0005), especially Chapter 6. Finally, Section [3.4](#Chp003_49-60_B9780443218576000072.xhtml#s0055) in this chapter explores the mathematical aspects in more details.
