
## 18.6 Elbow Rule

In the context of unsupervised clustering, one of the most popular recipes to identify the number of clusters, is the `elbow rule` [[Wiki](https://en.wikipedia.org/wiki/Elbow_method_(clustering))]. It is usually performed manually. Here, I show how it can be automated and applied to other problems, such as `outlier detection`. The idea is a follows: a clustering algorithm (say `K-means` [[Wiki](https://en.wikipedia.org/wiki/K-means_clustering)]) can identify a cluster structure with any number of clusters on a given data set; typically, a function `v(m)`![Image](images/B9780443218576000229/si152.png) provides a statistical summary of the best cluster structure consisting of `m` clusters, for `m = 1, 2, 3`![Image](images/B9780443218576000229/si153.png), and so on. For instance, `v(m)`![Image](images/B9780443218576000229/si152.png) is the sum of the squares of the distances from any observed point to its assigned cluster center. The function `v(m)`![Image](images/B9780443218576000229/si152.png) is decreasing, sharply initially for small values of `m`, then much more slowly for larger values of `m`, creating an elbow in its graph. The value of `m` corresponding to the elbow is deemed to be the optimal number of clusters. See [Fig. 18.7](#Chp018_361-386_B9780443218576000229.xhtml#f0060). Instead of `v(m)`![Image](images/B9780443218576000229/si152.png), I use the standardized version `v'(m) = v(m)/v(1)`![Image](images/B9780443218576000229/si154.png).

![Figure 18.7 Elbow rule (right) finds m = 3 clusters in Brownian motion (left).](images/B9780443218576000229/gr007.jpg)

*Figure 18.7 Elbow rule (right) finds `m` = 3 clusters in Brownian motion (left).*

I illustrate how to use the elbow rule to detect `outliers` in Section [18.6.1](#Chp018_361-386_B9780443218576000229.xhtml#s0130). The same methodology applies to detect the number of clusters. The data consists of a realization of a 2D `Brownian motion`. I am interested in the increments `R[k]`![Image](images/B9780443218576000229/si155.png), measuring the distance between a point of the process, and the next one. For practical purposes, the simulated realization can be interpreted as a 2D random walk, and `R[k]`![Image](images/B9780443218576000229/si155.png) is the length of the segment joining two successive points in [Fig. 18.7](#Chp018_361-386_B9780443218576000229.xhtml#f0060). These segments are visible if you zoom in on the picture. The model used to produce this synthetic data is described in Section [12.2.1](#Chp012_229-241_B9780443218576000163.xhtml).

### 18.6.1 Black-box elbow rule to detect outliers

[Fig. 18.7](#Chp018_361-386_B9780443218576000229.xhtml#f0060) shows a realization of a `Brownian motion` with 10⁴ points, using `γ = 2`![Image](images/B9780443218576000229/si156.png) and `λ = Γ(1 + γ)`![Image](images/B9780443218576000229/si157.png) in formula [(12.6)](#Chp012_229-241_B9780443218576000163.xhtml). The goal is to detect the number of values, among the top `R[k]`![Image](images/B9780443218576000229/si155.png)'s, that significantly outshine all the others. Here, they are not technically outliers in the sense that they are still deviates of the same distribution; rather, they are called extremes. The first step is to rank these values. The ordered values (in reverse order) are denoted as `R[(1)]`, `R[(2)]`![Image](images/B9780443218576000229/si158.png), and so on, with `R[(1)]`![Image](images/B9780443218576000229/si159.png) being the largest one. I used `v(m) = R[(m)]`![Image](images/B9780443218576000229/si160.png) as the criterion for the elbow rule, that is, after standardization, `v'(m) = v(m)/v(1)`![Image](images/B9780443218576000229/si154.png).

On the right plot in [Fig. 18.7](#Chp018_361-386_B9780443218576000229.xhtml#f0060), the `Y` axis on the left represents `v'(m)`![Image](images/B9780443218576000229/si161.png), the `X` axis represents `m`, and the `Y` axis on the right represents the strength of the elbow signal (the height of the red bar; I discuss later how it is computed). The top 10 values of `v'(m)`![Image](images/B9780443218576000229/si161.png) (`m = 1, ..., 10`![Image](images/B9780443218576000229/si162.png)) are

1.00, 0.92, 0.77, 0.76, 0.71, 0.69, 0.63, 0.61, 0.60, 0.56, 0.55, 0.55.

![Image](images/B9780443218576000229/si163.png)

Clearly, the third value 0.77 is pivotal, as the next ones stop dropping sharply, after an initial big drop at the beginning of the sequence. So the “elbow signal” is strongest at `m = 3`![Image](images/B9780443218576000229/si164.png), and the conclusion is that the first two values (`2 = m - 1`![Image](images/B9780443218576000229/si165.png)) outshine all the others. The purpose of the black-box elbow rule algorithm is to automate the decision process: in this case deciding that the optimum is `m = 3`![Image](images/B9780443218576000229/si164.png).

Note that in some instances, it is not obvious to detect an elbow, and there may be none. In my example, the elbow signal is very strong, because I chose a rather large value `γ = 2`![Image](images/B9780443218576000229/si156.png) in formula [(12.6)](#Chp012_229-241_B9780443218576000163.xhtml), causing the Brownian process to exhibit an unusually strong cluster structure, and large disparities among the top `v(m)`![Image](images/B9780443218576000229/si152.png)'s. A larger `γ` would generate even stronger disparities. A negative value of `γ`, say `γ = -0.75`![Image](images/B9780443218576000229/si166.png), also causes strong disparities, well separated clusters, and an easy-to-detect elbow. The resulting process is not even Brownian anymore if `γ = -0.75`![Image](images/B9780443218576000229/si166.png), since in that case, `Var[R[k]] = ∞`![Image](images/B9780443218576000229/si167.png). The standard Brownian motion corresponds to `γ = 0`![Image](images/B9780443218576000229/si168.png) and can still exhibit clusters depending on the realization. Finally, in our case, `m = 3`![Image](images/B9780443218576000229/si164.png) also corresponds to the number of clusters on the left plot in [Fig. 18.7](#Chp018_361-386_B9780443218576000229.xhtml#f0060). This is a coincidence, one that happens very frequently, because the top `v(m)`![Image](images/B9780443218576000229/si152.png)'s (left to the elbow) correspond to unusually large values of `R[k]`![Image](images/B9780443218576000229/si155.png). Each of these very large values typically gives rise to the building of a new cluster, in the simulations.

The elbow rule can be used recursively, first to detect the number of “main” clusters in the data set, then to detect the number of subclusters within each cluster. The strength of the signal (the height of the red bar) is typically very low if the `v'(m)`![Image](images/B9780443218576000229/si161.png)'s have a low variance. In that case, there is no set of values outshining all the others, that is, no true elbow. For an application of this methodology to detect the number of clusters, see a recent article of Chikumbo [[1]](#Chp018_361-386_B9780443218576000229.xhtml#br0005). An alternative to the elbow rule, to detect the number of clusters, is the silhouette method [[Wiki](https://en.wikipedia.org/wiki/Silhouette_(clustering))].
