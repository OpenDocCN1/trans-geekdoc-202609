
This notation works even if the `p[k]`'s (and thus the `q[k]`'s) are not integers, as in Section [17.3.4](#Chp017_329-360_B9780443218576000217.xhtml#s0100). We can also define `η[P](z, x, ν)` using the same mechanism as in formula [(17.5)](#Chp017_329-360_B9780443218576000217.xhtml#deq6); it may provide an analytic continuation when `x → 1`.

## Examples

Assuming `P` is the set of all prime integers, interesting examples include:

- If `ν(p) = 1` and `x = 1`, then `L[P](z, x, ν) = ζ(z)`, the **Riemann zeta function** [[Wiki](https://en.wikipedia.org/wiki/Riemann_zeta_function)]. If `ν(p) = 1` and `x = -1`, then `L[P](z, x, ν) = ζ(2z)/ζ(z)`. If `ν(p) = log p` and `0 < x ≤ 1`, then `L[P](z, x, ν) = ζ(z - log x)`. If `ν(p) = p` and `-1 < x < 1`, then we have absolute convergence when `σ ≥ 0`. In addition, the series in formula [(17.12)](#Chp017_329-360_B9780443218576000217.xhtml#deq17) is a Taylor series in `x`, and a Dirichlet series in `z`. This function has no roots, but it does have **poles** [[Wiki](https://en.wikipedia.org/wiki/Zeros_and_poles)]. Furthermore, `lim[x → 1] L[P](z, x, ν) = ζ(z)`.

- Let `x = -1` and `ν(p) = 2d(π(p), α) - 1`, where `π(·)` is the **prime-counting function** [[Wiki](https://en.wikipedia.org/wiki/Prime-counting_function)] and `d(k, α)` is the `k`th binary digit of the real number `0 < α < 1`. Choose `α` so that its binary digits are random enough, behaving like an infinite fair coin-tossing game. Then, by virtue of the **Glivenko–Cantelli theorem** [[Wiki](https://en.wikipedia.org/wiki/Glivenko%E2%80%93Cantelli_theorem)], the empirical distribution [[Wiki](https://en.wikipedia.org/wiki/Empirical_distribution_function)] of the digits converge to the underlying theoretical distribution of the process described in Section [17.3.5](#Chp017_329-360_B9780443218576000217.xhtml#s0105). In particular, we have both convergence of the product and no root if `σ > 0.5`. Thus the **Generalized Riemann Hypothesis** [[Wiki](https://en.wikipedia.org/wiki/Generalized_Riemann_hypothesis)] (abbreviated as GRH) is verified in this case. You still need to find some `α` that works, for instance, some **normal number** [[Wiki](https://en.wikipedia.org/wiki/Normal_number)] that would fit the bill. Of course, `$\alpha = \sqrt{2}/2$` is a great candidate, but no one knows if it is normal or not, despite the fact that it successfully passed all the statistical tests ever designed.

- In the previous example, if `α = 2/3`, GRH is also satisfied, despite the lack of randomness: the digits alternate perfectly between 0 and 1. But `p[2k]^(-σ) - p[2k+1]^(-σ) → 0` fast enough as `k → ∞` (see [here](https://mathoverflow.net/questions/159534/does-this-alternating-euler-product-converge-for-all-res-0)), thus we have convergence of the product if `σ > 0.5` and therefore, no root. Now, let `α` be defined as follows: the first digit is zero; then `d(π(p), α) = 1` if `p ≡ 1 mod 4` and `d(π(p), α) = 0` if `p ≡ 3 mod 4`. Then `L[P](z, x, ν) = L(z, χ[4])` where `χ[4]` is the nontrivial **Dirichlet character modulo** 4. The digits have limited randomness; the proportion of zero/one is 50/50 thanks to **Dirichlet's theorem** [[Wiki](https://en.wikipedia.org/wiki/Dirichlet%27s_theorem_on_arithmetic_progressions)], and this **Dirichlet-`L` function** [[Wiki](https://en.wikipedia.org/wiki/Dirichlet_L-function)] enjoys a number of interesting properties. If its product converges when `σ > 0.5` (nobody knows), then `L(z, χ[4])` would also satisfy GRH. The nonrandomness of the digits (this in itself does not rule out GRH) is caused by the fact that `χ[4](·)` is completely multiplicative and periodic. In particular, if `p` is a prime, then `χ[4](p²) = 1` and thus `d(π(p²), α) = 1`.

- Let `ν(p) = 1/p` and `0 < x ≤ 1`. When `ν(p) = log p`, you approach `ζ` (when `x → 1`) in the exact same way as moving to the left on the real axis, from `σ > 0.5` (no root if GRH is true) to `σ = 0.5` (infinitely many roots). The case `ν(p) = 1/p` offers a different perspective. Also `x^(1/p) → 1` as `p → ∞`, regardless of `0 < x < 1`. Thus `ν(p) = 1/p` is appealing. For instance, when `x = 0.99` and `σ = 0.55`, the orbit of `η[P](z, x, ν)` has a small hole around the origin (if might shrink to a singleton if you display the full orbit for all `t > 0`, as it does if `x = 1`). The orbit regularly gets close to the origin before moving away again: this happens only when `t` is close to the imaginary part of a nontrivial root of `ζ`. For a fixed value of `σ` (say 0.5), increasing `x` from (say) 0.4 to 0.8 will move the hole to the left, closer to the origin as expected. Of course, `lim[x → 1] L[P](z, x, ν) = ζ(z)`. For instance, let `$\sigma = \frac{1}{2}$`. Then if `x = 0.4`, the orbit has a massive hole centered around `(0, 1)` on the X-axis. If `x = 0.8`, the orbit has a massive hole centered around `$(0, \frac{1}{2})$`.
