
对于某个常数 `C`，满足 0 < `C` < ∞![Image](images/B9780443218576000217/si123.png)。但素数并非完全随机，人们预期 `$\sqrt{n\log\log n}$`![Image](images/B9780443218576000217/si284.png) 会被（比如说） `$\sqrt{n^{1 + \epsilon}}$`![Image](images/B9780443218576000217/si285.png) 所取代，其中 `ϵ` > 0![Image](images/B9780443218576000217/si126.png) 为任意小的正数。在确定性示例中可能就是这种情况，即当 `p` ≡ 1 `mod` 4![Image](images/B9780443218576000217/si225.png) 时 `χ(p)` = +1![Image](images/B9780443218576000217/si286.png)，而当 `p` ≡ 3 `mod` 4![Image](images/B9780443218576000217/si227.png) 时 `χ(p)` = −1![Image](images/B9780443218576000217/si287.png)。使随机欧拉乘积更逼真的一种方法是引入 `χ(p)`![Image](images/B9780443218576000217/si3.png) 之间的弱依赖关系。然后可以检验改进的随机模型（带弱依赖）是否能更好地拟合观测数据——即实际的 `χ(p)`![Image](images/B9780443218576000217/si3.png)。弱依赖关系可以按如下方式引入，即在 `n` 足够大时模拟 `χ(p[n + 1])`![Image](images/B9780443218576000217/si288.png)：

- 如果 `$|L_{\chi}(n)| < \beta\sqrt{n{(\log\log\log n)}^{\nu}}$`![Image](images/B9780443218576000217/si289.png)，则 `$P\lbrack\chi(p_{n + 1}) = 1\rbrack = \frac{1}{2} + \mu n^{- \alpha}$`![Image](images/B9780443218576000217/si290.png)，`$P\lbrack\chi(p_{n + 1}) = - 1\rbrack = \frac{1}{2} - \mu n^{- \alpha}$`![Image](images/B9780443218576000217/si291.png)。
- 否则在 +1 和 −1 之间选择，使得 `|L[χ](n + 1)| < |L[χ](n)|`![Image](images/B9780443218576000217/si292.png)。

你可以尝试各种 `α`、`β`、`ν` > 0![Image](images/B9780443218576000217/si293.png) 和 `μ` 的值，看哪些能为非常大的 `n`（例如 `n` > 10^(15)![Image](images/B9780443218576000217/si294.png)）提供最佳拟合。你也可以偶尔改变 `μ` 的符号。选择 `log log log n`![Image](images/B9780443218576000217/si295.png) 受 Gonek 猜想启发；参见 [[14]](#Chp017_329-360_B9780443218576000217.xhtml#br0070) 第 29 页。

最后，[[15]](#Chp017_329-360_B9780443218576000217.xhtml#br0075) 中也研究了另一个随机欧拉乘积，如下所示：

```
\rho^{2} = \prod\limits_{p \in P}\frac{1}{1 - 2p^{- \sigma}\cos(\Theta_{p}) + p^{- 2\sigma}}.
```

![Image](images/B9780443218576000217/si296.png)(17.16)

这里 `Θ[p]`![Image](images/B9780443218576000217/si297.png) 是 [0, 2`π`]![Image](images/B9780443218576000217/si298.png) 上的独立均匀偏差。将其与公式 [(17.14)](#Chp017_329-360_B9780443218576000217.xhtml#deq24) 进行比较。由于

```
\frac{1}{2\pi}\int_{0}^{2\pi}\frac{1}{1 - 2p^{- \sigma}\cos\theta + p^{- 2\sigma}}d\theta = \frac{1}{1 - p^{- 2\sigma}},
```

![Image](images/B9780443218576000217/si299.png)

我们得到

```
\text{E}\lbrack\rho^{2}\rbrack = \prod\limits_{p \in P}\text{E}\left\lbrack \frac{1}{1 - 2p^{- \sigma}\cos(\Theta_{p}) + p^{- 2\sigma}} \right\rbrack = \prod\limits_{p \in P}\frac{1}{1 - p^{- 2\sigma}} = L_{P}(2\sigma,\chi_{0}),
```

![Image](images/B9780443218576000217/si300.png)

其中 `χ[0](·)`![Image](images/B9780443218576000217/si275.png) 又是等于 1 的常数函数。如果 `P` 是全体素数集合，则 `L[P](2σ, χ[0])` = `ζ(2σ)`![Image](images/B9780443218576000217/si301.png)。关于 `ρ²`![Image](images/B9780443218576000217/si276.png) 所对应的分布存在且非奇异的证明，见 [[15]](#Chp017_329-360_B9780443218576000217.xhtml#br0075)。

## 17.4 练习

### 练习 17.1：渐近公式

证明渐近公式 [(17.2)](#Chp017_329-360_B9780443218576000217.xhtml#deq3)。

#### 解答

根据定义，对于某些正整数 `a[1]`、…、`a[d]`![Image](images/B9780443218576000217/si302.png)，我们有 `q[k]` = `p[1]^(a[1])` `p[2]^(a[2])` ⋯ `p[d]^(a[d])`![Image](images/B9780443218576000217/si67.png)。换句话说，`a[1] log p[1]` + … + `a[d] log p[d]` = `log q[k]`![Image](images/B9780443218576000217/si303.png)。这是一个 (`d` − 1)![Image](images/B9780443218576000217/si304.png) 维单纯形的方程，其顶点为 (`log p[1]`, 0, …, 0)![Image](images/B9780443218576000217/si305.png)、(0, `log p[2]`, …, 0)、…、(0, 0, …, `log p[d]`)![Image](images/B9780443218576000217/si306.png)。如果加上原点作为顶点，则新形成的 `d` 维单纯形内部具有整数坐标的点 `v[k]`![Image](images/B9780443218576000217/si307.png) 的数量约等于该 `simplex` 的体积 `V[k]`![Image](images/B9780443218576000217/si308.png) [[维基百科](https://en.wikipedia.org/wiki/Simplex#Volume)]。此外，`v[k]`![Image](images/B9780443218576000217/si307.png) 是小于或等于 `q[k]`![Image](images/B9780443218576000217/si43.png) 的正整数个数，因为每个整数都有唯一的（有序）素数因式分解。因此，`q[k]`![Image](images/B9780443218576000217/si43.png) 是函数 `v[k]`![Image](images/B9780443218576000217/si307.png) 的反函数，后者渐近等于 `V[k]`![Image](images/B9780443218576000217/si308.png) 的反函数。为完成证明，利用以下众所周知的事实：

```
V_{k} = \frac{1}{d!}\left( \log q_{k} \right)^{d}\prod\limits_{p \in P}\frac{1}{\log p} = \frac{1}{d!}\prod\limits_{p \in P}\log_{p}q_{k},
```

![Image](images/B9780443218576000217/si309.png)

其中 `log[p]`![Image](images/B9780443218576000217/si310.png) 表示以 `p` 为底的对数。当 `d` = 1![Image](images/B9780443218576000217/si311.png) 时，结果易于验证。

### 练习 17.2：级数与欧拉乘积的等价性

证明公式 [(17.1)](#Chp017_329-360_B9780443218576000217.xhtml#deq2)。

#### 解答

展开公式 [(17.1)](#Chp017_329-360_B9780443218576000217.xhtml#deq2) 中的乘积，可得

```
\prod\limits_{p \in P}\frac{1}{1 - p^{- z}} = \prod\limits_{p \in P}\left( 1 + p^{- z} + p^{- 2z} + \cdots \right) = \sum\limits_{a_{1},a_{2},\ldots,a_{d}}\left( p_{1}^{a_{1}}p_{2}^{a_{2}}\cdots p_{d}^{a_{d}} \right)^{- z} = \sum\limits_{k = 1}^{\infty}q_{k}^{- z}.
```

![Image](images/B9780443218576000217/si312.png)

令上式最右边的级数记为 `ζ[P](z)`![Image](images/B9780443218576000217/si313.png)。为完成证明，利用以下事实：

```
\sum\limits_{k = 1}^{\infty}\delta_{k}q_{k}^{- z} = \zeta_{P}(z) - 2\sum\limits_{q_{k}\text{~even}}q_{k}^{- z} = \zeta_{P}(z) - 2\sum\limits_{k = 1}^{\infty}{(2q_{k})}^{- z} = (1 - 2^{1 - z})\zeta_{P}(z).
```

![Image](images/B9780443218576000217/si314.png)

另一个有趣的恒等式如下：

```
(1 - 2^{1 - z})\prod\limits_{p \in P}\frac{1}{1 + p^{- z}} = (1 - 2^{1 - z})\frac{\zeta_{P}(2z)}{\zeta_{p}(z)} = \sum\limits_{k = 1}^{\infty}\delta_{k}\lambda(q_{k})q_{k}^{- z},
```

![Image](images/B9780443218576000217/si315.png)

其中 `λ(·)`![Image](images/B9780443218576000217/si116.png) 是 `Liouville 函数` [[维基百科](https://en.wikipedia.org/wiki/Liouville_function)]。

### 练习 17.3：收敛性问题

如果 `P` 是全体素数集合，且 `δ[k]`![Image](images/B9780443218576000217/si316.png) 替换为 +1，则当 `σ` < 1![Image](images/B9780443218576000217/si9.png) 时，公式 [(17.1)](#Chp017_329-360_B9780443218576000217.xhtml#deq2) 中的级数将不收敛。这里 `z` = `σ` + `it`![Image](images/B9780443218576000217/si2.png)。即 `σ` 是复数 `z` 的实部。

#### 解答
