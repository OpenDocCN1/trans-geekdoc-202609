
因此，如果 $\sigma = \Re(z) > \frac{1}{2}$![Image](images/B9780443218576000151/si16.png)，期望是有限的。类似的论证也可用于方差。

现在让我们用伪随机数来替换随机变量 `χ(p)`![Image](images/B9780443218576000151/si12.png)，这些伪随机数以概率 $\frac{1}{2}$![Image](images/B9780443218576000151/si9.png) 取值 +1 或 −1。如果这些生成的数字“足够随机”，且不存在依赖关系，那么人们会期望它们满足拉德马赫随机乘法函数的定律。本章剩余部分将详细探讨这一想法，重点关注应用。

## 11.2 伪随机数

伪随机数没有正式定义。直观上，一组好的伪随机数是一个确定性的二进制数字序列，它满足所有随机性统计检验。当然，如果序列包含的数字很少，比如一两个，谈论随机性就没有意义。因此，伪随机数（PRN）与无限序列相关联，尽管在实践中只使用有限子序列。

PRN 序列的严格定义要求任何 `m` 位有限子序列的多元经验分布 [[Wiki](https://en.wikipedia.org/wiki/Empirical_distribution_function)] 收敛到完全随机假设下的已知理论值。设 PRN 序列记为 `{d(k)}`![Image](images/B9780443218576000151/si17.png)，其中 `k` = 1, 2![Image](images/B9780443218576000151/si18.png)，依此类推。`m` 位子序列由其索引定义，记为 `i[1]`、 `i[2]`、…、 `i[m]`![Image](images/B9780443218576000151/si19.png)。经验分布的收敛意味着无论索引 0 ≤ `i[1]` < `i[2]` < ⋯![Image](images/B9780443218576000151/si20.png) 如何，我们都有

```
\lim_{n\rightarrow\infty}\frac{1}{n}\sum_{k = 1}^{n}I\left\lbrack d(k + i_{1}) = k_{1},d(k + i_{2}) = k_{2},\ldots,d(k + i_{m}) = k_{m} \right\rbrack = 2^{- m}
```

![Image](images/B9780443218576000151/si21.png)(11.3)

对于 { − 1,  + 1}^(`m`)![Image](images/B9780443218576000151/si23.png) 中的任意 (`k[1]`、 `k[2]`、…、 `k[m]`)![Image](images/B9780443218576000151/si22.png)。这里 `I` 是指示函数：若 `A` 为真，则 `I`[`A`] = 1![Image](images/B9780443218576000151/si24.png)，否则 `I`[`A`] = 0![Image](images/B9780443218576000151/si25.png)。以下数字 `λ` 特别值得关注：

```
\lambda = \sum_{k = 1}^{\infty}d^{\prime}(k) \cdot 2^{- k},\quad\text{with~}d^{\prime}(k) = \frac{1 + d(k)}{2} \in \{ 0,1\}.
```

![Image](images/B9780443218576000151/si26.png)(11.4)

因此 `d'(k)`![Image](images/B9780443218576000151/si27.png) 是数字 `λ` 的二进制位，其中 0 ≤ `λ` ≤ 1![Image](images/B9780443218576000151/si28.png)。

公式 [(11.1)](#Chp011_203-228_B9780443218576000151.xhtml#deq1) 中的乘法函数 `χ(·)`![Image](images/B9780443218576000151/si2.png) 与 `d(k)`![Image](images/B9780443218576000151/si29.png) 之间的联系如下。将第 `k` 个素数记为 `p[k]`![Image](images/B9780443218576000151/si30.png)，其中 `p[1]` = 2![Image](images/B9780443218576000151/si31.png)。则 `d(k)` = `χ(p[k])`![Image](images/B9780443218576000151/si32.png)。PRN 的传统定义等价于要求 `λ` 是以 2 为底的**正规数** [[Wiki](https://en.wikipedia.org/wiki/Normal_number)]。我在第 [11.2.1](#Chp011_203-228_B9780443218576000151.xhtml#s0020) 节中引入了一个更强的随机性判据。

### 11.2.1 强伪随机数

由公式 [(11.3)](#Chp011_203-228_B9780443218576000151.xhtml#deq3) 定义的经验联合分布的收敛性有几个重要含义。**柯尔莫戈罗夫-斯米尔诺夫检验** [[Wiki](https://en.wikipedia.org/wiki/Kolmogorov%E2%80%93Smirnov_test)]、**贝里-埃森不等式** [[Wiki](https://en.wikipedia.org/wiki/Berry%E2%80%93Esseen_theorem)] 和**迭代对数律** [[Wiki](https://en.wikipedia.org/wiki/Law_of_the_iterated_logarithm)] 都可以应用于 PRN 序列 `{d(k)}`![Image](images/B9780443218576000151/si17.png)。这三个基本结果为有限 PRN 序列的行为提供了强有力的限制。如果序列 `{d(k)}`![Image](images/B9780443218576000151/si17.png) 或其由数字 `λ` 表示的形式不保持在这些限制内，则它不能模拟纯随机性。然而，一些具有弱依赖性的准随机 PRN 序列满足这些要求，却并非真正“随机”。例如，一个数可以是以 2 为底的正规数，但其数字却表现出某些依赖性，见[此处](https://mathoverflow.net/questions/426815/normal-numbers-and-law-of-the-iterated-logarithm)。本节旨在引入更强的要求以捕捉其中一些例外情况。这正是乘法函数 `χ(·)`![Image](images/B9780443218576000151/si2.png) 发挥作用的地方。

函数 `χ(·)`![Image](images/B9780443218576000151/si2.png) 最初定义在素数 `p` 上，通过 `χ(ab)` = `χ(a)χ(b)`![Image](images/B9780443218576000151/si4.png) 扩展到所有严格正整数。因为 `χ(p)`![Image](images/B9780443218576000151/si12.png) 在素数间是独立的（由构造决定），所以所有 `k` 上的完整序列 `{χ(k)}`![Image](images/B9780443218576000151/si33.png) 必须以某种方式表现。显然，如果 `k` 是平方整数，`χ(k)` = 1![Image](images/B9780443218576000151/si34.png)。但如果 `k` 不是平方数，我们仍有 $P[\chi(k) = 1] = P[\chi(k) = - 1] = \frac{1}{2}$![Image](images/B9780443218576000151/si35.png)。例如，`χ(4200)` = `χ(4)χ(25)χ(6)χ(7)` = `χ(6)χ(7)`![Image](images/B9780443218576000151/si36.png)。由于两个具有**拉德马赫分布** [[Wiki](https://en.wikipedia.org/wiki/Rademacher_distribution)] 的独立随机变量的乘积仍服从拉德马赫分布，因此 `χ(6)` = `χ(2)χ(3)`![Image](images/B9780443218576000151/si37.png) 服从拉德马赫分布，从而 `χ(4200)` = `χ(6)χ(7)`![Image](images/B9780443218576000151/si38.png) 也服从拉德马赫分布。因此，除非 `k` 是平方整数，否则 `χ(k)`![Image](images/B9780443218576000151/si39.png) 服从零均值的同一分布。然而，它们并非独立分布，即使去除平方整数后，甚至即使只保留**无平方因子整数** [[Wiki](https://en.wikipedia.org/wiki/Square-free_integer)] 也是如此。

我现在定义三个基本函数，它们是我新随机性检验的核心。首先，定义以下集合：

*   `S₁(n)`![Image](images/B9780443218576000151/si40.png) 包含所有不大于 `n` 的素数整数。
*   `S₂(n)`![Image](images/B9780443218576000151/si41.png) 包含所有不大于 `n` 的正无平方因子整数。
*   `S₃(n)`![Image](images/B9780443218576000151/si42.png) 包含所有不大于 `n` 的正非平方整数。

因此这些集合每个最多包含 `n` 个元素。然后，将这三个函数定义为

```
L_{1}(n) = \sum_{k \in S_{1}(n)}\chi(k),\quad L_{2}(n) = \sum_{k \in S_{2}(n)}\chi(k),\quad L_{3}(n) = \sum_{k \in S_{3}(n)}\chi(k).
```
