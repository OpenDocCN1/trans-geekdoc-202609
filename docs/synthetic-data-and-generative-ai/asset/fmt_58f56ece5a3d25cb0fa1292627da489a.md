
## 12.2 Random walks and Brownian motions

### 12.2.1 Generalized random walks in two dimensions

In some sense, it is similar to the examples studied earlier, where moving away from the law of the iterated logarithm resulted in unusual patterns: either very strong or very weak oscillations. Note that all the simulations performed here consist of discrete random walks rather than time-continuous Brownian motions. They approach Brownian motions very well, but since modern computers (at least to this date) are “digital” as opposed to “analog”, everything is broken down into bits, and is thus discrete, albeit with a huge granularity.

In one dimension, we start with `S[0] = 0`![Image](images/B9780443218576000163/si3.png) and `S[n] = S[n-1] + R[n] θ[n]`![Image](images/B9780443218576000163/si94.png), for `n = 1, 2`![Image](images/B9780443218576000163/si95.png), and so on. If the `R[n]`![Image](images/B9780443218576000163/si96.png)'s are independently and identically distributed (iid) with an exponential distribution of expectation `1/λ`![Image](images/B9780443218576000163/si97.png) and `θ[n] = 1`![Image](images/B9780443218576000163/si98.png), then the resulting process is a stationary **Poisson point process** [[Wiki](https://en.wikipedia.org/wiki/Poisson_point_process)] with intensity function `λ` on ℝ⁺![Image](images/B9780443218576000163/si99.png); the `R[n]`![Image](images/B9780443218576000163/si96.png)'s are the successive **interarrival times**. If the `θ[n]`![Image](images/B9780443218576000163/si100.png)'s are iid with `P(θ_n = 1) = P(θ_n = -1) = 1/2`![Image](images/B9780443218576000163/si101.png), and independent from the `R[n]`![Image](images/B9780443218576000163/si96.png)'s, then we get a totally different type of process, which, after proper rescaling, represents a time-continuous **Brownian motion** in one dimension. For general references, see [[2]](#Chp012_229-241_B9780443218576000163.xhtml#br0010),[[3]](#Chp012_229-241_B9780443218576000163.xhtml#br0015).

I generalize it to two dimensions, as follows. Start with `(S[0], S[0]') = (0, 0)`![Image](images/B9780443218576000163/si102.png). Then generate the points `(S[n], S[n]')`![Image](images/B9780443218576000163/si103.png), with `n = 1, 2`![Image](images/B9780443218576000163/si95.png), and so on, using the recursion

```
S[n] = S[n-1] + R[n] cos(2π θ[n])   (12.4)
```

![Image](images/B9780443218576000163/si104.png)

```
S[n]' = S[n-1]' + R[n] sin(2π θ[n])   (12.5)
```

![Image](images/B9780443218576000163/si105.png)

where `θ[n]`![Image](images/B9780443218576000163/si100.png) is uniform on `[0, 1]`![Image](images/B9780443218576000163/si37.png), and the radius `R[n]`![Image](images/B9780443218576000163/si96.png) is generated using the formula

```
R_n = (1/λ) * (-log(1 - U_n))^γ   (12.6)
```

![Image](images/B9780443218576000163/si106.png)

where `U[n]`![Image](images/B9780443218576000163/si107.png) is uniform on `[0, 1]`![Image](images/B9780443218576000163/si37.png). Also, `λ > 0`![Image](images/B9780443218576000163/si108.png), and the random variables `U[n], θ[n]`![Image](images/B9780443218576000163/si109.png) are all independently distributed. If `γ > -1`![Image](images/B9780443218576000163/si110.png), then `E[R_n] = (1/λ) Γ(1 + γ)`![Image](images/B9780443218576000163/si111.png) where `Γ` is the **gamma function** [[Wiki](https://en.wikipedia.org/wiki/Gamma_function)]. In order to standardize the process, I use `λ = Γ(1 + γ)`![Image](images/B9780443218576000163/si112.png). Thus, `E[R[n]] = 1`![Image](images/B9780443218576000163/si113.png) and if `γ > -1/2`![Image](images/B9780443218576000163/si114.png),

```
Var[R_n] = Γ(1 + 2γ) / Γ²(1 + γ) - 1
```

![Image](images/B9780443218576000163/si115.png)

We have the following cases:

*   If `γ = 1`![Image](images/B9780443218576000163/si116.png), then `R[n]`![Image](images/B9780443218576000163/si96.png) has an exponential distribution.
*   If `-1 < γ < 0`![Image](images/B9780443218576000163/si117.png), then `R[n]`![Image](images/B9780443218576000163/si96.png) has a **Fréchet distribution**. If in addition, `γ > -1/2`![Image](images/B9780443218576000163/si114.png), then its variance is finite.
*   If `γ > 0`![Image](images/B9780443218576000163/si118.png), then `R[n]`![Image](images/B9780443218576000163/si96.png) has a **Weibull distribution**, with finite variance.

Interestingly, the Fréchet and Weibull distributions are two of the three **attractor distributions** in **extreme value theory**.

The two-dimensional process consisting of the points `(S[n], S[n]')`![Image](images/B9780443218576000163/si103.png) is a particular type of random walk. The random variables `R[n]`![Image](images/B9780443218576000163/si96.png) represent the (variable) lengths of the successive increments. Under proper rescaling, assuming the variance of `R[n]`![Image](images/B9780443218576000163/si96.png) is finite, it tends to a time-continuous two-dimensional Brownian motion. However, if `Var[R[n]] = ∞`![Image](images/B9780443218576000163/si119.png), it may not converge to a Brownian motion. Instead, it is very similar to a **Lévy flight** [[Wiki](https://en.wikipedia.org/wiki/L%C3%A9vy_flight)], and produces a strong cluster structure, with well separated clusters. See [Fig. 12.4](#Chp012_229-241_B9780443218576000163.xhtml#f0025), based on `γ = -1/2`![Image](images/B9780443218576000163/si120.png), `λ = 8`![Image](images/B9780443218576000163/si121.png), and featuring the first ![Image](images/B9780443218576000163/fx005.jpg)points of the bivariate sequence `{(S[n], S[n]')}`![Image](images/B9780443218576000163/si122.png).

The Lévy flight uses a **Lévy distribution** [[Wiki](https://bit.ly/3rV7mrq)] for `R[n]`![Image](images/B9780443218576000163/si96.png), which also has infinite expectation and variance. Along with the **Cauchy distribution** (also with infinite expectation and variance), it is one of the few **stable distributions** [[Wiki](https://en.wikipedia.org/wiki/Stable_distribution)]. Such distributions are attractors for an adapted version of the **Central Limit Theorem** (CLT), just like the Gaussian distribution is the attractor for the CLT. A well-written, seminal book on the topic is “Limit Distributions for Sums of Independent Random Variables”, by Gnedenko and Kolmogorov [[5]](#Chp012_229-241_B9780443218576000163.xhtml#br0025).

For a simple introduction to Brownian and related processes, see the website [RandomServices.org](https://www.randomservices.org/) by Kyle Siegrist, especially the chapter on standard Brownian motions, [here](https://www.randomservices.org/random/brown/Standard.xhtml). The processes discussed in Section [12.2.1](#Chp012_229-241_B9780443218576000163.xhtml#s0050) are further investigated in my book “Stochastic Processes and Simulations: A Machine Learning Perspective” [[7]](#Chp012_229-241_B9780443218576000163.xhtml#br0035).

### 12.2.2 Integrated Brownian motions and special autoregressive processes

The Brownian motions pictured in [Fig. 12.5](#Chp012_229-241_B9780443218576000163.xhtml#f0030) are generated by simple time-discrete **autoregressive time series** [[Wiki](https://en.wikipedia.org/wiki/Autoregressive_model)]. Thus, the base process is autocorrelated, but the limit (after rescaling) is still a standard Brownian motion and thus perfectly random, if the autocorrelation structure is weak enough.

This autoregressive (AR) model is driven by initial conditions `S[1], ..., S[p]`![Image](images/B9780443218576000163/si123.png) and the recursion

```
S[n] = a[1] S[n-1] + ... + a[p] S[n-p] + e[n]
```
