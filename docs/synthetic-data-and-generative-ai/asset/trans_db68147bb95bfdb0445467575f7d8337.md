

## 4.2 数值稳定性与可视化

我通过在公式 [(4.1)](#Chp004_61-82_B9780443218576000084.xhtml#deq5) 中引入随机噪声，测试了计算的数值稳定性。我在我的书 [\[1\]](#Chp004_61-82_B9780443218576000084.xhtml#br0005) 第 20 页的“黎曼假设的扰动版本”一节中描述了该方法论。本文第 [4.2.3.4](#Chp004_61-82_B9780443218576000084.xhtml#s0050) 节所述的空洞对计算中的微小错误非常敏感，一旦引入极小的变化就会消失。这证实了黎曼 Zeta 函数确实具有某种独特性。关于优化高度混沌函数（计算全局最大值或最小值）的解决方案，请参阅我的书 [\[1\]](#Chp004_61-82_B9780443218576000084.xhtml#br0005) 第 17–18 页。我使用了一种发散的 `fixed-point algorithm` [[Wiki](https://en.wikipedia.org/wiki/Fixed-point_iteration)]，当接近全局最优时会发出信号。该技术将在即将发表的文章中详细描述。方法论的快速概览请见[此处](https://www.datasciencecentral.com/a-new-machine-learning-optimization-technique-part-i/)。

最后，可视化（[图 4.8](#Chp004_61-82_B9780443218576000084.xhtml#f0060) 或相应视频[此处](https://www.youtube.com/watch?v=XI5MhyNc7us)）使用了大量的 RGB 颜色。为产生视觉效果，我使用正弦函数生成颜色。更多细节请见第 [4.3.2](#Chp004_61-82_B9780443218576000084.xhtml#s0070) 节及我的书 [\[1\]](#Chp004_61-82_B9780443218576000084.xhtml#br0005) 第 85 页。调色板优化（见[此处](https://mathoverflow.net/questions/415618/lattice-like-structure-with-maximum-spacing-between-vertices)）将成为即将发表的文章的主题。

## 4.3 Python 代码

Python 代码、视频和动态 GIF 可在我的 GitHub 仓库获取，[此处](https://github.com/VincentGranville/Visualizations)。视频也在 YouTube 上，[此处](https://www.youtube.com/c/VincentGranvilleVideos)。为方便起见，Python 代码也包含在本节中。主要变量包括 `ShowOrbit`（若要显示轨道而非仅显示点，则设为 true）、`dot`（点的大小）、`r`（按时间迭代时，每 `r` 次迭代输出一帧视频）、`width` 和 `height`（图像尺寸）。最终图像最终会因用于去像素化曲线的 `antialiasing` 过程而缩小一半。这在代码的 `img.resize` 中执行，使用 `Image.LANCZOS` 参数 [[Wiki](https://en.wikipedia.org/wiki/Lanczos_resampling)]。

椭圆和线条使用 `Pillow` 库及其 `ImageDraw` 函数生成。动态 GIF 通过 `images[0].save`（生成巨大文件）或 `videoClip.write_gif` 生成，后者使用带有 `ffmpeg` 参数的 `Moviepy` 库进行压缩 [[Wiki](https://en.wikipedia.org/wiki/FFmpeg)]。处理大量颜色时，`ffmpeg` 会导致显著的质量损失，不在于形状渲染，而在于调色板。我建议使用除 `Pillow` 以外的库来生成动态 GIF，例如 `openCV`。最终，我使用在线工具 `ezgif` [ezgif](https://ezgif.com/video-to-gif) 将一些 MP4 视频转换为 GIF，该工具也基于 `ffmpeg`。

减小图像尺寸和每秒帧数（`FPS`）将优化代码并生成小得多的 GIF。就速度而言，最大的改进是将所有 `numpy` 调用（`np.log`、`np.cos` 等）替换为 `math` 调用（`math.log`、`math.cos` 等）。如果你用 `numpy` 而非 `Pillow` 生成图像，情况可能相反（我未测试）。最后，RGBA 颜色模型中的不透明度应设为 127。目前设为 80；例如见 `colp.append((0,0,255,80))` 中的第四个参数。
