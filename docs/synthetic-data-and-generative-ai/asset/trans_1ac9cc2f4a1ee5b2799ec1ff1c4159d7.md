
# 云回归：椭圆拟合与应用

## 关键词

曲线拟合；无监督回归；逻辑回归；约束优化；时间序列；聚类

## 章节概览

本章并非关于在云端执行的回归。它是关于将你的数据集视为一个点云或观测值云，其中因变量和自变量（响应变量和特征）的概念变得模糊。这是一种非常通用的回归类型，可向后兼容现有方法。将一个变量视为响应变量等同于对多元参数设置约束，并导出一个带有拉格朗日乘数的优化算法。其创新之处在于统一并将若干截然不同的方法纳入同一框架，每种方法解决一般问题的一部分，且源自不同领域。我还提出了一种新颖的逻辑回归方法，以及一种广义 `R-squared`，适用于形状拟合、模型拟合、特征选择和降维。在一个示例中，我展示了该技术如何执行无监督聚类，并通过参数自助法获得聚类中心的置信区域。

除了椭圆拟合及其在 `computer vision` 中的重要性外，一个有趣的应用是周期性时间序列的非周期性求和。虽然在机器学习界很少讨论，但此类模型能解释许多现象，例如海洋潮汐。它在时间连续的情况下特别有用，此时误差不是白噪声，而是处处光滑连续，例如颗粒温度预测。另一个有趣的应用是建模陨石形状。最后，我的方法论是无模型且数据驱动的，专注于数值稳定性。预测区间和置信区域通过自助法获得。我提供了用于复现的 Python 代码和合成数据生成器。

## 1.1 简介：圆拟合

目标是统一所有回归技术，并提出一个简单、通用的框架来解决大多数将方程拟合到数据集的问题。目前有几十种回归类型，每种都有自己的方法论和算法。这里我提出一种单一的方法论和单一的算法来解决所有这些问题。

我技术的独创性在于我的方法和方法论，而非所用数学或算法的类型。像所有通用方法一样，它相当抽象，人们会认为它更难学习和描述。相反，我认为它实际上更直观、更易掌握。首先，因变量和自变量特征是可互换的：因变量的概念在我的方法论中甚至不存在。因此我称之为“云回归”，因为数据集被视为一个点云，没有特定的轴或维度被赋予特权，除非显式要求。其次，该技术是无模型的：它使用重采样和自助法来构建预测区间，或回归系数的置信区间。

符号的审慎选择使我的方法论能向后兼容所有现有技术。`R-squared` 的概念稍作修改以提供额外可能性：衡量全模型与你所选子模型的拟合质量。在标准回归中，子模型是一个常数，称为基础模型。这里子模型可以是拟合圆（如果全模型是关于椭圆的），或是在标准线性回归中拟合平面与超平面。

所有面向初学者的回归书籍和章节都从拟合直线开始。这里最简单的例子——第一个要教的例子——是拟合一个以原点为中心的圆。想一想：直觉上，估计半径就是数据点上计算出的平均半径。确实，这是我的技术产生的解。第二个最简单的情况则是拟合一条包含斜率和截距的直线。这两个例子都是拟合二次型（椭球体）的特例。

本演示面向初学者。存在一些例子，就像在标准回归中一样，解不唯一。在我看来，非唯一性应被接纳而非规避：在现实生活中，人们会预期多个不同的形状可以拟合特定的数据集。找到其中几个能提供关于数据的更多洞见。然而，唯一性所需的条件此处不讨论：这是更高级演示的主题。

在许多情况下，得益于适当的重参数化，解可以通过简单的约束优化和拉格朗日乘数获得。这更多涉及初等微积分而非高等矩阵代数。特别地，没有显式提及 `eigenvalues` [[Wiki](https://en.wikipedia.org/wiki/Eigenvalues_and_eigenvectors)] 或 `singular value decomposition` [[Wiki](https://en.wikipedia.org/wiki/Singular_value_decomposition)]。此外，形状不需要具有导数，尽管如果有，则可以用类牛顿算法实现更快的实现。实际上，形状可能处处不可导：想想将布朗运动拟合到一组观测值上。

我提供了使用合成数据 [[Wiki](https://en.wikipedia.org/wiki/Synthetic_data)] 和 Python 代码的示例。其中一个涉及具有两个周期 `p`、`q` ![Image](images/B9780443218576000059/si1.png) 的时间序列预测，其中 `p/q` ![Image](images/B9780443218576000059/si2.png) 不是有理数。由于 `p` 和 `q` 是待估计参数之一，这是一个真正的非线性问题，无法像（例如）逻辑回归那样通过链接函数 [[Wiki](https://en.wikipedia.org/wiki/Generalized_linear_model#Link_function)] 转化为线性问题。一个用于基准测试该方法性能的实际应用是预测海洋潮汐：可用大量颗粒度地理空间数据集来测试该预测算法在此非线性背景下的表现。
