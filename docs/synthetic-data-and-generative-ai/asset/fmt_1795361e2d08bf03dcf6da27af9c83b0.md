
### 17.3.3 Riemann Hypothesis with cosines replaced by wavelets

The standard Dirichlet eta function `η(z)`![Image](images/B9780443218576000217/si29.png), with `z = σ + it`![Image](images/B9780443218576000217/si2.png), can be represented by two nonperiodic trigonometric series: one for the real part involving cosine terms, and one for the imaginary part (a phase shift of the first one) involving sine terms. If you modify even very slightly the coefficients in these series, you lose the interesting properties: **Dirichlet functional equation** [[Wiki](https://en.wikipedia.org/wiki/Functional_equation_(L-function))], infinite number of roots when $\sigma = \frac{1}{2}$![Image](images/B9780443218576000217/si24.png) (in other words, the orbit passing through the origin over and over), no root and hole in the orbit when $\frac{1}{2} < \sigma < 1$![Image](images/B9780443218576000217/si20.png).

But what about a drastic change, replacing the sine and cosine functions by other periodic functions? Depending on the replacement, this actually works (except for the functional equation and therefore the roots when $\sigma = \frac{1}{2}$![Image](images/B9780443218576000217/si24.png)), proving that there is nothing special about the sines and cosines when dealing with the Riemann Hypothesis, at least when $\frac{1}{2} < \sigma < 1$![Image](images/B9780443218576000217/si20.png). I start by introducing the following real-valued function:

$$
\varphi(z,\theta) = \sum\limits_{k = 1}^{\infty}{( - 1)}^{k + 1}\frac{W(\theta + t\log k)}{k^{\sigma}},
$$

![Image](images/B9780443218576000217/si245.png)(17.13)

where `z = σ + it`![Image](images/B9780443218576000217/si2.png), `0 ≤ θ < 2π`![Image](images/B9780443218576000217/si246.png), and `W` is a periodic function of period 2π, to be defined later. I also use the notation `φ[1](z) = φ(z, 0)`![Image](images/B9780443218576000217/si247.png) and `φ[2](z) = φ(z, π/2)`![Image](images/B9780443218576000217/si248.png). In particular, if `W(x) = cos x`![Image](images/B9780443218576000217/si249.png), then `φ[1](z)`![Image](images/B9780443218576000217/si250.png) is the real part of `η(z)`![Image](images/B9780443218576000217/si29.png), and `φ[2](z)`![Image](images/B9780443218576000217/si251.png) is the imaginary part. Also, here `P` is the full set of prime integers and `χ(·)`![Image](images/B9780443218576000217/si4.png) is the constant function equal to 1.

The top part of [Fig. 17.7](#Chp017_329-360_B9780443218576000217.xhtml#f0040) shows the orbit of the modified `η(z)`![Image](images/B9780443218576000217/si29.png) function for `σ = 0.75`![Image](images/B9780443218576000217/si252.png) and `0 < t < 200`![Image](images/B9780443218576000217/si253.png), using the three functions `W` discussed in this section. The left plot corresponds to the cosine wave (in this case `η(z)`![Image](images/B9780443218576000217/si29.png) is the standard Dirichlet function), the middle plot to the triangular wave, and the right plot to the alternating quadratic wave.

- **Triangular wave**

$$
W(x) = \begin{cases} {- 2x/\pi,} & {\text{if~}0 \leqslant x \leqslant \pi/2,} \\ {- 2 + 2x/\pi,} & {\text{if~}\pi/2 \leqslant x \leqslant 3\pi/2,} \\ {4 - 2x/\pi} & {\text{if~}3\pi/2 \leqslant x \leqslant 2\pi;} \end{cases}
$$

![Image](images/B9780443218576000217/si254.png)

- **Alternating quadratic wave**

$$
W(x) = \begin{cases} {- 4x(x - \pi)/\pi^{2},} & {\text{if~}0 \leqslant x \leqslant \pi,} \\ {4(x - \pi)(x - 2\pi)/\pi^{2}} & {\text{if~}\pi \leqslant x \leqslant 2\pi;} \end{cases}
$$

![Image](images/B9780443218576000217/si255.png)

- **Cosine wave**

`W(x) = cos x`.

![Image](images/B9780443218576000217/si256.png)

### 17.3.4 Riemann Hypothesis for Beurling primes

Beurling primes are real or complex numbers used to mimic and study distributions related to prime integers. A Beurling prime set `P = {p[1], p[2], …}`![Image](images/B9780443218576000217/si160.png) is any set of real or complex numbers with the constraint that the product of elements of `P` cannot be an element of `P`. We then define `Q = Q[P]`![Image](images/B9780443218576000217/si198.png) as the set of all product combinations `q = p[1]^(a[1]) p[2]^(a[2]) …`![Image](images/B9780443218576000217/si257.png) where `a[1], a[2], …`![Image](images/B9780443218576000217/si258.png) are integers ⩾0. It is also required that the factorization of `q ∈ Q[P]`![Image](images/B9780443218576000217/si259.png), using Beurling primes from `P`, is unique.

A counterexample is the set of **Hilbert primes** [[Wiki](https://en.wikipedia.org/wiki/Hilbert_number)]: for instance, 1617 = 21 × 77 = 33 × 49![Image](images/B9780443218576000217/si260.png) where 21, 33, 49, 77![Image](images/B9780443218576000217/si261.png) are Hilbert primes (they cannot be factored as a product of Hilbert primes). A good example is when `Q` is the set of numbers that are sums of two square integers: if `q, q' ∈ Q`![Image](images/B9780443218576000217/si262.png) then `q ⋅ q' ∈ Q`![Image](images/B9780443218576000217/si263.png). In this case, `P = {2, 5, 9, 13, …}`![Image](images/B9780443218576000217/si264.png), see [here](https://oeis.org/A055025). Note that 9, 49![Image](images/B9780443218576000217/si265.png), and 121 are primes in `Q`. Related to this set is the set of **Gaussian primes** [[Wiki](https://en.wikipedia.org/wiki/Gaussian_integer)], which are complex numbers.

The Python code in Section [17.5.1](#Chp017_329-360_B9780443218576000217.xhtml#s0120) handles Beurling primes. In the current implementation, `P` is the set of all prime integers except that 3 is replaced by 2 + log 3 ≈ 3.0986![Image](images/B9780443218576000217/si266.png). When using the Beurling option, set the Dirichlet parameter to True, to get convergence when $\frac{1}{2} \leqslant \sigma < 1$![Image](images/B9780443218576000217/si10.png). The orbit of `η[P](z, χ)`![Image](images/B9780443218576000217/si88.png), assuming `χ(·)`![Image](images/B9780443218576000217/si4.png) is constant and equal to 1, exhibits a hole that encompasses the origin if $\frac{1}{2} < \sigma < 1$![Image](images/B9780443218576000217/si20.png). The hole shrinks to a point (the origin) if the full, infinite orbit is plotted, pointing to the absence of roots, just like for the standard Dirichlet eta function `η(z)`![Image](images/B9780443218576000217/si29.png). Of course, this is part of the GRH conjecture, not a proven fact. Likewise, if $\sigma = \frac{1}{2}$![Image](images/B9780443218576000217/si24.png), there are infinitely many roots. In the context of Beurling numbers, the associated Dirichlet function `L[P](z, χ)`![Image](images/B9780443218576000217/si107.png) is called a **Dedekind zeta function** [[Wiki](https://en.wikipedia.org/wiki/Dedekind_zeta_function)], and Dedekind eta for the alternating series `η[P](z, χ)`![Image](images/B9780443218576000217/si88.png).
