
此处 `F` 为逻辑分布，我选择 `r` = 2![Image](images/B9780443218576000205/si171.png)。除 `r` = 1![Image](images/B9780443218576000205/si179.png) 外，任何 `r` > 0![Image](images/B9780443218576000205/si169.png) 均适用。若 `λ[0]` = 1.45![Image](images/B9780443218576000205/si180.png) 且 `τ[0]` = 0.77![Image](images/B9780443218576000205/si181.png)，则 `τ′` = (`λ[0]`)²`τ[0]` = 1.61![Image](images/B9780443218576000205/si182.png)。查看 `E[T²(1, s′)]`![Image](images/B9780443218576000205/si183.png) 表，为满足 `E[T²(1, s′)]` ≈ 1.61![Image](images/B9780443218576000205/si184.png)，需有 `s′` = 0.65![Image](images/B9780443218576000205/si185.png)。因此 `s[0]` = `s′`/`λ[0]` = 0.45![Image](images/B9780443218576000205/si186.png)。这些数字与模拟获得的数字相符。要查看或下载该表，请参阅 [`PB_inference.xlsx`](https://github.com/VincentGranville/Point-Processes/tree/main/Spreadsheets) 中的 `E[T²]`![Image](images/B9780443218576000205/si187.png) 选项卡。

方程 `E[T²(1, s′)]` = `τ′`![Image](images/B9780443218576000205/si188.png)，其中 `s′`![Image](images/B9780443218576000205/si176.png) 为未知数，可使用数值方法求解。最简单的方法是通过模拟强度为 `λ=1`![Image](images/B9780443218576000205/si49.png) 和缩放因子为 `s` 的泊松-二项过程，为各种 `s` 值构建一张精细的 `E[T²(1, s)]`![Image](images/B9780443218576000205/si189.png) 表。然后，通过传统方式浏览并插值该表以找到 `s′`![Image](images/B9780443218576000205/si176.png)，确定最接近满足 `E[T²(1, s)]` = `τ′`![Image](images/B9780443218576000205/si190.png) 的 `s` 值。当然，这可以自动化。执行相关模拟有两种方法：

*   •  生成每个过程的一个实现，包含大量点（即，对于 `λ=1`![Image](images/B9780443218576000205/si49.png) 和 `s` 增量等于 0.01 的每个 0 < `s` < 20![Image](images/B9780443218576000205/si191.png) 生成一个实现），

*   •  或者生成每个过程的多个实现，每个实现包含相当少量的点。

无论哪种方式，若两种情况使用相同的 `F`，由于**遍历性**，结果应几乎相同。模拟还允许你计算相关估计量的理论方差（至少是一个非常好的近似）。当有多个估计量（基于不同统计量）可用时，这很有用，可用于选择最佳估计量：方差最小的那个。模拟还允许你计算估计量的**置信区间**。

#### 16.3.1.3 替代估计方法

也可以使用点计数 `N(B)`![Image](images/B9780443218576000205/si19.png) 来估计 `s`。思路是将状态空间（一维情况下点所在的实线）划分为短区间 `B[k]` = \[`k`/`λ`, (`k` + 1)/`λ`\[![Image](images/B9780443218576000205/si192.png)，`k` = 0, ±1, ±2![Image](images/B9780443218576000205/si193.png)，以此类推，覆盖观测到的点；注意**边界效应**。这假设 `λ` 已知或已估计。设 `N[k]` = `N(B[k])`![Image](images/B9780443218576000205/si194.png) 为 `B[k]`![Image](images/B9780443218576000205/si195.png) 中观测点数的随机变量。我们有 `E[N[k]]` = 1![Image](images/B9780443218576000205/si196.png)。此外，得益于 `B[k]`![Image](images/B9780443218576000205/si195.png) 的选择，`Var[N[k]]` ≤ 1![Image](images/B9780443218576000205/si197.png) 不依赖于 `k`（参见第 [16.1.2](#Chp016_293-327_B9780443218576000205.xhtml#s0020) 节）。当 `s` = ∞![Image](images/B9780443218576000205/si106.png) 时，方差最大且等于 1。

对于任意 `s` 和 `λ` 值，均可通过模拟或公式 [(16.4)](#Chp016_293-327_B9780443218576000205.xhtml#deq5) 计算理论方差 `v(λ, s)` = `Var[N[k]]`![Image](images/B9780443218576000205/si198.png)，其中 `a=0`![Image](images/B9780443218576000205/si199.png) 和 `b=1/λ`![Image](images/B9780443218576000205/si200.png)。它略微依赖于 `F`，但依赖性极弱。现在，基于你的观测，假设 `λ` 已知或已估计，计算所有 `B[k]`![Image](images/B9780443218576000205/si195.png) 中 `N[k]`![Image](images/B9780443218576000205/si201.png) 的经验方差，即 (`N[k]` − 1)²![Image](images/B9780443218576000205/si202.png) 的平均值。该经验方差记为 `v[0](λ)`![Image](images/B9780443218576000205/si203.png)。`s` 的估计值是使经验方差与理论方差相等的那个值，即求解方程 `v(λ, s)` = `v[0](λ)`![Image](images/B9780443218576000205/si204.png) 的*唯一* `s` 值。该方法易于推广到高维，见第 [16.3.2.1](#Chp016_293-327_B9780443218576000205.xhtml#s0110) 节。`E[N[k]]` = 1![Image](images/B9780443218576000205/si196.png) 这一事实是同一本书中定理 4.1 的直接推论。

请参阅 [`PB_inference.xlsx`](https://github.com/VincentGranville/Point-Processes/tree/main/Spreadsheets) 中的 `N[k]`![Image](images/B9780443218576000205/si201.png) 选项卡，了解具有**广义逻辑** `F` 的泊松-二项过程模拟，以及在 Excel 中计算 `E[N[k]]`![Image](images/B9780443218576000205/si205.png) 和 `Var[N[k]]`![Image](images/B9780443218576000205/si206.png) 的方法。

### 16.3.2 空间统计、最近邻、聚类

此处重点关注二维点过程。第 [16.3.2.3](#Chp016_293-327_B9780443218576000205.xhtml#s0120) 节提供了一种原创检验，用于判断特定数据集中的点分布——更准确地说是最近距离——是否与泊松过程一致。简而言之，它检验你面对的是**泊松过程**的一个实现，还是更复杂的过程（如 `m-混合`：泊松-二项过程的叠加）。

#### 16.3.2.1 二维过程的推断

暂假设我们处理的是单个二维泊松-二项点过程。第 [16.3.1](#Chp016_293-327_B9780443218576000205.xhtml#s0085) 节讨论的一维情况下的部分方法可推广到高维。边长为 1/`λ`![Image](images/B9780443218576000205/si38.png) 的正方形内的点计数分布，其期望等于 1。因此，估计 `λ` 的一种方法是：针对未知 `λ` 的各种值，将观测窗口 `W` 划分为小正方形 $B_{h,k}(\lambda) = \left\lbrack \frac{h}{\lambda},\frac{h + 1}{\lambda}\left\lbrack \times \left\lbrack \frac{k}{\lambda},\frac{k + 1}{\lambda}\lbrack \right. \right. \right.$![Image](images/B9780443218576000205/si207.png)，计算每个正方形内的点数 `N[h, k](λ)`![Image](images/B9780443218576000205/si208.png)（称为**点计数**），并找到使经验方差最小化的 `λ`

$v(\lambda) = \sum\limits_{h,k}\left( N_{h,k}(\lambda) - 1 \right)^{2}$

![Image](images/B9780443218576000205/si209.png)

基于观测值计算。求和针对 `h`, `k` ∈ ℤ ∩ `W′`![Image](images/B9780443218576000205/si210.png)，其中 `W` 为观测窗口，`W′`![Image](images/B9780443218576000205/si211.png) 略小于 `W` 以缓解**边界效应**。简而言之，你对**强度** `λ` 的估计定义为 $\lambda_{0} = \underset{\lambda}{\arg\min} v(\lambda)$![Image](images/B9780443218576000205/si212.png)。
