
# Mathematical Derivations and Exercises

## Preliminary Derivation

- `χ^⋆(p[k]) = +1`![Image](images/B9780443218576000217/si354.png) if `m[k]`![Image](images/B9780443218576000217/si347.png) is even, otherwise `χ^⋆(p[k]) = -1`![Image](images/B9780443218576000217/si355.png).

Also, `p^(-z) = [cos(t log p[k]) + i sin(t log p[k])] ⋅ p^(-σ) → χ^⋆(p[k]) p^(-σ)`![Image](images/B9780443218576000217/si356.png) as `t → ∞`![Image](images/B9780443218576000217/si357.png). Thus for the Euler product, with the special `t` discussed above (a function of `m[1], …, m[d]`![Image](images/B9780443218576000217/si358.png)) and `z = σ + i t`![Image](images/B9780443218576000217/si2.png), we have

### Equation (17.17)

$$
L_P(z,\chi)\rightarrow\prod_{k=1}^{d}\frac{1}{1 - \chi^{\star}(p_k)\chi(p_k)p_k^{-\sigma}} \in \mathbb{R}\quad\text{as }t\rightarrow\infty.
$$

![Image](images/B9780443218576000217/si359.png)(17.17)

If `∑[p ∈ P] p^(-σ) = ∞`![Image](images/B9780443218576000217/si360.png), then the product in formula [(17.17)](#Chp017_329-360_B9780443218576000217.xhtml#deq39) can approximate any positive value arbitrarily closely, as `d → ∞`![Image](images/B9780443218576000217/si62.png). Indeed, `d[k] = χ^⋆(p[k])`![Image](images/B9780443218576000217/si361.png) can be seen as the `k`th binary digit of the (real) number `L[P](z, χ)`![Image](images/B9780443218576000217/si107.png) in some special numeration system. And you can compute `d[k]`![Image](images/B9780443218576000217/si362.png) using a technique similar to that used for standard binary digits in base 2, with a version of the **greedy algorithm** [[Wiki](https://en.wikipedia.org/wiki/Greedy_algorithm)]. To get arbitrarily close to zero, one way is to choose the function `χ^⋆`![Image](images/B9780443218576000217/si349.png) so that `χ^⋆ χ = -1`![Image](images/B9780443218576000217/si363.png).

## Note

In the computation of `S(χ^⋆)`![Image](images/B9780443218576000217/si364.png), I implicitly used the following facts. First, if `k` has the prime factorization `k = p[1]^(a[1])⋯p[d]^(a[d])`![Image](images/B9780443218576000217/si365.png), then `cos(t log k) = cos(a[1] t log p[1] + ⋯ + a[d] t log p[d])`![Image](images/B9780443218576000217/si366.png). Recursively using `cos(α + β) = cos α cos β - sin α sin β`![Image](images/B9780443218576000217/si367.png), with the fact that all the sines are zero and `cos(a[i] t log p[i]) → cos(a[i] m[i] π) = [χ^⋆(p[i])]^(a[i])`![Image](images/B9780443218576000217/si368.png) as `t → ∞`![Image](images/B9780443218576000217/si357.png), one obtains `cos(t log k) → [χ^⋆(p[1])]^(a[1])⋯[χ^⋆(p[d])]^(a[d]) = χ^⋆(k)`![Image](images/B9780443218576000217/si369.png).

## Exercise 17.6: Density of integers of the form x³ + y²

**Problem Statement:** Prove that the `k`th integer of the form `x³ + y²`![Image](images/B9780443218576000217/si161.png) is asymptotically larger than `k^(6/5)`![Image](images/B9780443218576000217/si170.png).

### Solution

Let `v(n)`![Image](images/B9780443218576000217/si371.png) be the number of lattice points `(x, y)`![Image](images/B9780443218576000217/si372.png), with `x, y`![Image](images/B9780443218576000217/si164.png) positive integers, satisfying `x³ + y² ≤ n`![Image](images/B9780443218576000217/si373.png). Estimating `v[n]`![Image](images/B9780443218576000217/si374.png) is a classic problem in **additive number theory** [[Wiki](https://en.wikipedia.org/wiki/Additive_number_theory)], generalizing the **Gaussian circle problem** [[Wiki](https://en.wikipedia.org/wiki/Gauss_circle_problem)]. The solution to this class of problems is as follows. Let `S[1], …, S[m]`![Image](images/B9780443218576000217/si375.png) be `m` infinite sets of positive integers, and `v[i](n)`![Image](images/B9780443218576000217/si376.png) be the number of elements less than `n` in `S[i]`![Image](images/B9780443218576000217/si377.png). Let `v(n)`![Image](images/B9780443218576000217/si371.png) be the number of lattice points `(x[1], …, x[m])`![Image](images/B9780443218576000217/si378.png), with `x[i] ∈ S[i]`![Image](images/B9780443218576000217/si379.png), satisfying `x[1] + ⋯ + x[m] ≤ v(n)`![Image](images/B9780443218576000217/si380.png). If `v[i](n) ∼ a[i] n^(b[i]) (log n)^(-c[i])`![Image](images/B9780443218576000217/si381.png) with `0 < b[i] ≤ 1`![Image](images/B9780443218576000217/si382.png), `c[i] ≥ 0`![Image](images/B9780443218576000217/si383.png) and `a[i] > 0  (i = 1, …, m)`![Image](images/B9780443218576000217/si384.png), then

$$
v(n) \lesssim \frac{\prod_{i=1}^{m} a_i \Gamma(b_i + 1)}{\Gamma(1 + \sum_{i=1}^{m} b_i)} \cdot \frac{n^{b_1 + \cdots + b_m}}{(\log n)^{c_1 + \cdots + c_m}},
$$

![Image](images/B9780443218576000217/si385.png)

where ≲ means “asymptotically smaller”, and Γ is the Gamma function. See [here](https://mathoverflow.net/questions/364559/general-asymptotic-result-in-additive-combinatorics-sums-of-sets) and [here](https://mathoverflow.net/questions/363055/goldbach-conjecture-and-other-problems-in-additive-combinatorics/) for details.

In our case, `m = 2`![Image](images/B9780443218576000217/si386.png), `a[1] = a[2] = 1`![Image](images/B9780443218576000217/si387.png), `c[1] = c[2] = 0`![Image](images/B9780443218576000217/si388.png), `b[1] = 1/3`![Image](images/B9780443218576000217/si389.png), `b[2] = 1/2`![Image](images/B9780443218576000217/si390.png). Thus `v(n) ≲ n^(5/6)`![Image](images/B9780443218576000217/si391.png). Note that this method may result in double counting, for instance, `225 = 6³ + 3² = 5³ + 10² = 0³ + 15²`![Image](images/B9780443218576000217/si392.png). Thus the actual number `w(n)`![Image](images/B9780443218576000217/si393.png) of positive integers of the form `x³ + y²`![Image](images/B9780443218576000217/si161.png) is even smaller, thus definitely smaller than `n^(5/6)`![Image](images/B9780443218576000217/si169.png). It follows immediately, using the inverse of the function `w(n)`![Image](images/B9780443218576000217/si393.png), that the `k`th element is asymptotically larger than `n^(6/5)`![Image](images/B9780443218576000217/si394.png).

## Exercise 17.7: Strange factorization of the Dirichlet functions

**Problem Statement:** Show, based on the Euler product, that `L[P](z, χ) = L[P](z/2, ψ) L[P](z/2, -ψ)`![Image](images/B9780443218576000217/si395.png) where `ψ²(p) = χ(p)`![Image](images/B9780443218576000217/si396.png), thus `ψ(p) ∈ {1, -1, i, -i}`![Image](images/B9780443218576000217/si397.png). In particular, if `χ(p) = 1`![Image](images/B9780443218576000217/si100.png), one can choose `ψ(p[2k+1]) = 1`![Image](images/B9780443218576000217/si398.png) and `ψ(p[2k]) = -1`![Image](images/B9780443218576000217/si399.png) where `p[k]`![Image](images/B9780443218576000217/si112.png) is the `k`th prime. In this case, `L(z, χ) = ζ(z)`![Image](images/B9780443218576000217/si400.png), and the Euler products of `L(z/2, ψ)`![Image](images/B9780443218576000217/si401.png) and `L(z/2, -ψ)`![Image](images/B9780443218576000217/si402.png) both converge if `σ > 0`![Image](images/B9780443218576000217/si30.png). However, `L[P](z/2, ψ) L[P](z/2, -ψ) = ζ(z)`![Image](images/B9780443218576000217/si403.png) only if `σ > 1`![Image](images/B9780443218576000217/si19.png). How can these formulas be generalized recursively?
