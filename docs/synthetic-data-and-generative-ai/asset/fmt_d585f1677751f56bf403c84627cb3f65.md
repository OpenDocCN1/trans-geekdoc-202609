## 13.3 Generalization with synthetic random functions

Perhaps the synthetic example most closely resembling `f[0](b) = a mod b`![Image](images/B9780443218576000175/si68.png) discussed in Section [13.2.2](#Chp013_243-258_B9780443218576000175.xhtml#s0030) is `f[0](b) = ⌊b U[b]⌋`![Image](images/B9780443218576000175/si69.png) where the `U[b]`![Image](images/B9780443218576000175/si70.png)'s are independent random deviates on `[0, 1]`![Image](images/B9780443218576000175/si71.png). The major difference is the independence assumption. For `a mod b`![Image](images/B9780443218576000175/si72.png), the residues somewhat behave as if they were independent (assuming the `b`'s are integers and `a` is fixed), but they are not really independent. To use `f[0](b) = ⌊b U[b]⌋`![Image](images/B9780443218576000175/si69.png), set `mode='Random'` in the Python code.

They are more and more spaced out as `b` increases. In this example, with the seed of the random generator set to `seed=105`, the first few roots are
