
最后，“云回归”涵盖了 `general linear model` [[维基百科](https://en.wikipedia.org/wiki/General_linear_model)]、`generalized linear model` [[维基百科](https://en.wikipedia.org/wiki/Generalized_linear_model)]（因此也包括逻辑回归），以及 `weighted least squares` [[维基百科](https://en.wikipedia.org/wiki/Generalized_least_squares#Weighted_least_squares)]（因此也包括贝叶斯回归）。通过第 [1.1.1](#Chp001_1-34_B9780443218576000059.xhtml#s0015) 节讨论的映射 `z ↦ w`![Image](images/B9780443218576000059/si3.png)，它可以适应样条，如 `adaptive regression splines` [[维基百科](https://en.wikipedia.org/wiki/Multivariate_adaptive_regression_spline)]。云回归和 `total least squares` 方法 [[维基百科](https://en.wikipedia.org/wiki/Total_least_squares)] 都最小化数据点与形状之间平方距离之和，尽管我的方法不赋予响应变量（统计学家称之为因变量）特殊地位：换句话说，它在没有响应变量、只有点云的标准情况下也能工作。此外，我的技术能处理真正的非线性情况，这与广义线性模型不同。因此，我称之为所有回归之母。

这并非回归技术首次不区分因变量和自变量：`partial least squares` [[维基百科](https://en.wikipedia.org/wiki/Partial_least_squares_regression)] 也允许这样做。另见 [[5]](#Chp001_1-34_B9780443218576000059.xhtml#br0025)。

## 1.1.1 我方法的早期版本

当前版本更加通用、简洁，且与首个实现截然不同。不过，提供一些历史背景可能会有帮助。最初，目标是计算一组点（观测值，或“点云”）与预先指定的形状 `Γ[θ]`![Image](images/B9780443218576000059/si4.png)（一条线、一个平面或一个圆）之间平方距离之和，该形状属于由多维参数 `θ` 驱动的参数族。

思路如下。设 `P[∞]`![Image](images/B9780443218576000059/si5.png) 为位于离形状极远处的一个固定点，`P` 为训练集中的一个点。画一条穿过 `P` 和 `P[∞]`![Image](images/B9780443218576000059/si5.png) 的线 `L[P]`![Image](images/B9780443218576000059/si6.png)，并找到形状与线之间最靠近 `P` 的交点 `Γ[θ] ∩ L[P]`![Image](images/B9780443218576000059/si7.png)。设 `Q[θ]`![Image](images/B9780443218576000059/si8.png) 为该点。该点可能不唯一，甚至可能不存在（取决于 `θ`），但距离 `Δ[θ](P) = ||P - Q[θ]||`![Image](images/B9780443218576000059/si9.png) 是存在的，假设存在交点。然后找到使所有训练集点 `P` 上的 `Δ[θ](P)`![Image](images/B9780443218576000059/si11.png) 之和最小化的 `θ^(*)`![Image](images/B9780443218576000059/si10.png)。如果唯一，该 `θ^(*)`![Image](images/B9780443218576000059/si10.png) 即确定了最拟合数据的形状。传统的基于投影的技术计算点与形状之间的精确距离，因此要求形状可微。基于 `P[∞]`![Image](images/B9780443218576000059/si5.png) 的方法适用于不可微的形状。新实现中的某些特定情况产生的结果与 `P[∞]`![Image](images/B9780443218576000059/si5.png) 方法获得的结果相似或相同。

如果相关形状是超平面，且背景是传统的多元线性回归，则该形状由 `g(w, θ) = 0`![Image](images/B9780443218576000059/si12.png) 定义，其中 `w = (y, x[1], …, x[m])`![Image](images/B9780443218576000059/si13.png) 和 `g(w, θ) = θ[0]y + (θ[1]x[1] + ⋯ + θ[m]x[m])`![Image](images/B9780443218576000059/si14.png)。这里 `y` 对应因变量，`x[1], …, x[m]`![Image](images/B9780443218576000059/si15.png) 对应特征，`θ[0], θ[1], …, θ[m]`![Image](images/B9780443218576000059/si16.png) 为回归系数，约束条件为 `θ[0] = -1`![Image](images/B9780443218576000059/si17.png)。在新方法中，约束 `θ[0] = -1`![Image](images/B9780443218576000059/si17.png) 通过拉格朗日乘数法处理，除此之外得出的结果与传统解相同。如果有截距项，则 `x[1] = 1`![Image](images/B9780443218576000059/si18.png)。最终目标是提出一种既通用又直观的技术，顺应可解释人工智能 [[维基百科](https://en.wikipedia.org/wiki/Explainable_artificial_intelligence)] 的现代潮流。

在我的方法论的第二个版本中（非当前版本），我引入了一个映射系统，本质上是与链接函数相关的坐标变换。目标是变换数据，使映射后的数据更易于求得简单解。此外，这也是为了获得尺度无关解的一种尝试：无论你的单位是英里还是公里，都不应影响解。在其最一般形式中，观测值和参数分别记为 `z` 和 `φ`。形状满足方程 `h(z, φ) = 0`![Image](images/B9780443218576000059/si19.png)。映射定义为 `g(w, θ) = ξ(h(z, φ))`![Image](images/B9780443218576000059/si20.png)，其中 `ξ: ℝ → ℝ`![Image](images/B9780443218576000059/si21.png) 为严格单调函数，`w = ν(z)`![Image](images/B9780443218576000059/si22.png) 和 `θ = ϕ(φ)`![Image](images/B9780443218576000059/si23.png)，`ν` 和 `ϕ` 为某些多元一一映射。所有计算均在 `(w, θ)`![Image](images/B9780443218576000059/si24.png)\-空间中进行，尽管计算完成后如有需要可还原回原始的 `(z, φ)`![Image](images/B9780443218576000059/si25.png) 空间。

我最终放弃了 `ξ`，并直接忽略了 `φ` 和 `ϕ`，从而得到一个抽象程度较低的模型，却涵盖了所有实际情况。因此在当前版本中，`h(z, φ) = g(w, θ)`![Image](images/B9780443218576000059/si26.png)，我们不关心 `φ`。我们不妨直接使用 `φ = θ`![Image](images/B9780443218576000059/si27.png)。映射 `ν` 在新方法中引出了样条回归。然而，当使用样条时，它们是预先指定的而非估计的，以避免过拟合。通常选择它们是为了简化计算。
