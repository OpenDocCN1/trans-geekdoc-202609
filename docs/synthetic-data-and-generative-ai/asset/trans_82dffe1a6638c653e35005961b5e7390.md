
中性选择 `β[0]` = 0![Image](images/B9780443218576000114/si13.png) 作为迭代不动点算法的回归系数起始向量，效果很好。另一种选择是选择能保持响应变量 `Y` 与各特征 `X[1]`，…，`X[m]`![Image](images/B9780443218576000114/si23.png) 之间相关性符号的回归系数。这里，`X[i]`![Image](images/B9780443218576000114/si48.png) 是矩阵 `X` 的第 `i` 列。设

$c_i = \frac{Cov[Y,X_i]}{Var[X_i]},\quad c = {(c_1,\ldots,c_m)}^{T},\quad Q = \sum_{i=1}^{m}c_i X_i = Xc,$

![Image](images/B9780443218576000114/si49.png)

其中 `ω` 为选定的实数，以使误差 `ϵ`^(*T*)*`ϵ` = (`Y` − `ω``Q`)^(*T*)(`Y` − `ω``Q`) = `Y`^(*T*)*`Y` − 2`Q`^(*T*)*`Y``ω` + `Q`^(*T*)*`Q``ω`²![Image](images/B9780443218576000114/si50.png) 最小化。我们得到

$w = \frac{Y^{T}Q}{Q^{T}Q} = \frac{Y^{T}Xc}{c^{T}X^{T}Xc}\quad\text{and}\quad{Var}[c_i X_i] = {Var}[Y] \cdot \rho^{2}[X_i,Y] = \sigma_{Y}^{2} \cdot \rho^{2}[X_i,Y],$

![Image](images/B9780443218576000114/si51.png)

其中 `ρ` 表示相关函数。现在，`β[0]` = `ω``c`![Image](images/B9780443218576000114/si52.png) 是一个合理、易于解释且优于 `β[0]` = 0![Image](images/B9780443218576000114/si13.png) 的起始点。与基础模型 `β` = 0![Image](images/B9780443218576000114/si53.png) 相比，它显著降低了残差误差。在许多情况下，它产生的残差误差几乎可与最佳预测器的误差相媲美。

举例说明，假设 `X[2]` = `X[3]`![Image](images/B9780443218576000114/si54.png)。你应该避免数据集中出现高度相关的特征，但在某些情况下，多个特征之间的相互依赖性很强但更难以检测，并导致同样的问题。在我的例子中，假设 `X[2]`![Image](images/B9780443218576000114/si55.png) 和 `X[3]`![Image](images/B9780443218576000114/si56.png) 都与响应变量 `Y` 正相关，那么将 +4 和 -2 作为分别对应 `X[2]`![Image](images/B9780443218576000114/si55.png) 和 `X[3]`![Image](images/B9780443218576000114/si56.png) 的回归系数的模型，其表现与 -2、+4 或 +1、+1 一样好。此处提出的 `β[0]`![Image](images/B9780443218576000114/si7.png) 解决了这个问题：它保证在该示例中，与 `X[2]`![Image](images/B9780443218576000114/si55.png) 和 `X[3]`![Image](images/B9780443218576000114/si56.png) 对应的回归系数均为正，且若 `X[2]` = `X[3]`![Image](images/B9780443218576000114/si54.png) 则二者相同。这使得回归系数更易于解释。此外，该技术在数值上稳定且更鲁棒。

### 7.2.4 仿真与 Excel 电子表格

第 [7.2](#Chp007_113-129_B9780443218576000114.xhtml#s0015) 节中描述的公式和计算已在我的电子表格 Regression5.xlsx 中实现，可在我的 GitHub 仓库 [此处](https://github.com/VincentGranville/Machine-Learning/blob/main/Spreadsheets/README.md) 获取。这些内容涵盖了电子表格的大部分，剩余部分将在后续章节中解释。

电子表格中的“Test”（测试）和“Results”（结果）选项卡包含以下内容：

*   •  随机偏差 `Z[1]`，…，`Z[m]`![Image](images/B9780443218576000114/si14.png) 位于 Test 选项卡的 A 到 F 列。零均值噪声位于 H 列。响应变量 `Y` 中的噪声量由 Results 选项卡中 E5 单元格的参数 Noise 控制。通常情况下，Results 选项卡中浅黄色高亮的单元格对应可供修改的参数或超参数。其上方 E4 单元格中的参数 `γ` 是用于模拟列向量 `Z[1]`，…，`Z[m]`![Image](images/B9780443218576000114/si14.png) 的广义逻辑分布的核心参数。

*   •  Results 选项卡 E7 单元格中的标志允许你选择 `β[0]` = 0![Image](images/B9780443218576000114/si13.png) 或第 [7.2.3](#Chp007_113-129_B9780443218576000114.xhtml#s0030) 节中讨论的特殊 `β[0]`![Image](images/B9780443218576000114/si7.png)。

*   •  默认情况下，回归使用传统的 `β[k]`![Image](images/B9780443218576000114/si32.png)。如果你想改用归一化的 `β[k]^(*)`![Image](images/B9780443218576000114/si45.png)，它们会在 Test 选项卡的 AX2:ES7 单元格中迭代计算。例如，BL2:BL7 单元格代表 `β[15]^(*)`![Image](images/B9780443218576000114/si57.png)，即不动点算法中的第 15 次迭代（`k` = 15![Image](images/B9780443218576000114/si58.png)），以列向量形式存储。标准 `β[k]`![Image](images/B9780443218576000114/si32.png) 在同一选项卡的 AX20:ES25 单元格中计算。

*   •  Test 选项卡的 I 列是响应变量 `Y`。特征 `X[1]`，…，`X[m]`![Image](images/B9780443218576000114/si23.png)（也称为自变量）位于同一选项卡的 J 到 O 列。它们是作为随机向量 `Z[1]`，…，`Z[m]`![Image](images/B9780443218576000114/si14.png) 的线性组合生成的。更精确地说，根据公式 [(7.3)](#Chp007_113-129_B9780443218576000114.xhtml#deq5)，`X` = `W``Z`![Image](images/B9780443218576000114/si59.png)，其中 `W` 是 `m` × `m`![Image](images/B9780443218576000114/si5.png) 权重矩阵。随机权重矩阵 `W` 存储在 Results 选项卡的 B15:G20 单元格中。实际的真实（随机）回归参数就在同一选项卡的上方，位于 B12:G12 单元格中。

*   •  中间计算结果在 Test 选项卡中。例如，`m` × `m`![Image](images/B9780443218576000114/si5.png) 矩阵 `X^T X`![Image](images/B9780443218576000114/si60.png) 存储在 AP2:AU7 单元格，向量 `X^T Y`![Image](images/B9780443218576000114/si61.png) 存储在 AN2:AN7 单元格，相关矩阵 `R[X]`![Image](images/B9780443218576000114/si39.png) 存储在 AE3:AJ8 单元格，协方差矩阵 `Ω[X]`![Image](images/B9780443218576000114/si33.png) 存储在 AE12:AJ17 单元格。

该交互式电子表格大量使用 Excel 的 SUMPRODUCT（求和乘积）和 TRANSPOSE（转置）函数，只需一个简单操作即可轻松实现行向量与列向量的相乘。它也使矩阵乘法变得更容易。

## 7.3 阻尼调度与收敛加速

公式 [(7.2)](#Chp007_113-129_B9780443218576000114.xhtml#deq3) 中的 `m` × `m`![Image](images/B9780443218576000114/si5.png) 对角矩阵 `Λ^(-1)`![Image](images/B9780443218576000114/si62.png) 称为阻尼参数，或不动点迭代的**预条件子** [[维基百科](https://en.wikipedia.org/wiki/Preconditioner)]。它控制收敛速率。如果 |`φ`| < 1![Image](images/B9780443218576000114/si63.png)，不动点算法即可收敛，其中 `φ` = `φ`(`S`)[Image](images/B9780443218576000114/si64.png) 是 `S` = `I` − `Λ^(-1)``X^T X`![Image](images/B9780443218576000114/si65.png) 的最大特征值的绝对值。|`φ`|![Image](images/B9780443218576000114/si66.png) 越小，收敛越快。收敛速度最终取决于当 `k` → ∞![Image](images/B9780443218576000114/si11.png) 时 `S^k` → 0![Image](images/B9780443218576000114/si10.png) 的速度，而这本身是 |`φ`|![Image](images/B9780443218576000114/si66.png) 的函数。因此，选择 `Λ` 使 `S` 接近零是合理的。一种方法是选择使 `S` 的 Frobenius 范数最小的 `Λ`，换句话说，即选择使 `S` 的系数平方和最小的 `Λ`。这导出

$\lambda_i^{- 1} = \frac{1}{m_{ii}}\sum_{j=1}^{m}m_{ij}^{2},\quad i = 1,\ldots,m,$

![Image](images/B9780443218576000114/si67.png)(7.4)
