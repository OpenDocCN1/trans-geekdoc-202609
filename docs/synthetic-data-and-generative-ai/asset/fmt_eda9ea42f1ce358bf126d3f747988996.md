## 18.3 Dual confidence regions

This tutorial explains how to build confidence regions (the 2D version of a confidence interval) using as little statistical theory as possible. I also avoid the traditional terminology and notation such as `α`, `Z[1−α]`![Image](images/B9780443218576000229/si7.png), critical value, confidence level, significance level, and so on. These can be confusing to beginners and professionals alike.

Instead, I use simulations and two keywords only, confidence region and confidence level. The purpose is to explain the concept using a framework that will appeal to machine learning professionals, software engineers and nonstatisticians. My hope is that you will gain a deep understanding of the technique, without headaches. I also introduce an alternative type of confidence region, called dual confidence region. It is asymptotically equivalent to the standard definition. In my opinion, it is more intuitive.

### 18.3.1 Case study

This example comes from a real-life application discussed in Section [16.4.1](#Chp016_293-327_B9780443218576000205.xhtml). Here I provide the minimum amount of material necessary to illustrate the methodology. The full problem is described Section [18.3.5](#Chp018_361-386_B9780443218576000229.xhtml#s0070), for the curious reader. In its simplest form, we are dealing with independent `bivariate Bernoulli trials`. The data set has `n` observations. Each observation consists of two measurements `(u[k], v[k])`![Image](images/B9780443218576000229/si8.png), for `k=1,…,n`![Image](images/B9780443218576000229/si9.png). Here `u[k]=1`![Image](images/B9780443218576000229/si10.png) if some interval `B[k]`![Image](images/B9780443218576000229/si11.png) contains zero point (otherwise `u[k]=0`![Image](images/B9780443218576000229/si12.png)). Likewise, `v[k]=1`![Image](images/B9780443218576000229/si13.png) if the same interval contains one point (otherwise `v[k]=0`![Image](images/B9780443218576000229/si14.png)).

The interval `B[k]`![Image](images/B9780443218576000229/si11.png) can contain more than one point, but, of course, it cannot simultaneously contain one and two points. The probability that `B[k]`![Image](images/B9780443218576000229/si11.png) contains zero point is `p`; the probability that it contains one point is `q`, with `0 < p + q < 1`![Image](images/B9780443218576000229/si15.png). The goal is to estimate `p` and `q`. The estimators (proportions computed on the observations) are denoted as `p[0]`![Image](images/B9780443218576000229/si16.png) and `q[0]`![Image](images/B9780443218576000229/si17.png).

Since we are dealing with Bernoulli variables, the standard deviations are `σ_p = sqrt(p(1 - p))`![Image](images/B9780443218576000229/si18.png) and `σ_q = sqrt(q(1 - q))`![Image](images/B9780443218576000229/si19.png). Also the correlation between the two components `u[k], v[k]`![Image](images/B9780443218576000229/si20.png) of the observation vector is `ρ_p,q = - p*q/σ[p]*σ[q]`![Image](images/B9780443218576000229/si21.png). Indeed, the probability to observe `(0, 0)`![Image](images/B9780443218576000229/si22.png) is `1 - p - q`![Image](images/B9780443218576000229/si23.png), the probability to observe `(1, 0)`![Image](images/B9780443218576000229/si24.png) is `p`, the probability to observe `(0, 1)`![Image](images/B9780443218576000229/si25.png) is `q`, and the probability to observe `(1, 1)`![Image](images/B9780443218576000229/si26.png) is zero.

### 18.3.2 Standard confidence region

A confidence region of level `γ` is a domain of minimum area that contains a proportion `γ` of the potential values of your estimator `(p[0], q[0])`![Image](images/B9780443218576000229/si27.png), based on your `n` observations. When `n` is large, `(p[0], q[0])`![Image](images/B9780443218576000229/si27.png) approximately has a `bivariate normal distribution` (also called Gaussian), thanks to the `central limit theorem`. The `covariance matrix` of this normal distribution is specified by `σ[p], σ[q]`![Image](images/B9780443218576000229/si28.png) and `ρ[p, q]`![Image](images/B9780443218576000229/si29.png) measured at `p = p[0]`![Image](images/B9780443218576000229/si30.png) and `q = q[0]`![Image](images/B9780443218576000229/si31.png). For a fixed `γ`, the optimum shape – the one with minimum area – necessarily has a boundary that is a contour level of the distribution in question. In our case, that distribution is bivariate Gaussian, and thus contour levels are ellipses.

Let us define

```
H_n(x,y,p,q) = \frac{2n}{1 - \rho_{p,q}^{2}}\left\lbrack \left( \frac{x - p}{\sigma_{p}} \right)^{2} - 2\rho_{p,q}\left( \frac{x - p}{\sigma_{p}} \right)\left( \frac{y - q}{\sigma_{q}} \right) + \left( \frac{y - q}{\sigma_{q}} \right)^{2} \right\rbrack,
```

![Image](images/B9780443218576000229/si32.png)(18.1)

with

```
\sigma_{p} = \sqrt{p(1 - p)},\quad\sigma_{q} = \sqrt{q(1 - q)},\quad\rho_{p,q} = - \frac{pq}{\sqrt{pq(1 - p)(1 - q)}}.
```
