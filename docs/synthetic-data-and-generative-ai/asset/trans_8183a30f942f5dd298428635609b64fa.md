
现在你可以使用 `R²`![Image](images/B9780443218576000059/si76.png) 进行模型比较，甚至用于特征选择 [[维基百科](https://en.wikipedia.org/wiki/Feature_selection)]。你可以使用指标 `S(θ[*]) = R²(θ^(\*)) − R²(θ[*])`![Image](images/B9780443218576000059/si77.png) 来检验使用完整模型相对于子模型所获得的改进。这里 `θ[*]`![Image](images/B9780443218576000059/si67.png) 是与子模型相关联的最优 `θ`。显然，`0 ≤ S(θ[*]) ≤ 1`![Image](images/B9780443218576000059/si78.png)。`S(θ[*])`![Image](images/B9780443218576000059/si79.png) 越大，改进幅度越大。反之，越小，则子模型的性能越好。示例包括拟合椭圆（完整模型）与拟合圆（子模型）的对比，或使用所有特征（完整模型）与使用特征子集（子模型）的对比。你可以比较子模型，并根据 `S(θ[*])`![Image](images/B9780443218576000059/si79.png) 对它们进行排序。这使你能够确定实现足够好 `S(θ[*])`![Image](images/B9780443218576000059/si79.png) 的最小特征集，用于降维目的 [[维基百科](https://en.wikipedia.org/wiki/Dimensionality_reduction)]。

最后，另一个更新是在公式 [(1.1)](#Chp001_1-34_B9780443218576000059.xhtml#deq1) 中使用正权重 `ψ_k(θ)`![Image](images/B9780443218576000059/si80.png)。这相当于执行**加权回归** [[维基百科](https://en.wikipedia.org/wiki/Generalized_least_squares#Weighted_least_squares)]。例如，远离最优形状的数据点，即具有较大 `g²(W_k, θ^(\*))`![Image](images/B9780443218576000059/si81.png) 的观测值，可能会被丢弃以减少异常值的影响。或者权重可用于平衡系数 `θ_i`![Image](images/B9780443218576000059/si68.png)，以期在表达式 `wθ` 中实现尺度不变性。然后 [(1.2)](#Chp001_1-34_B9780443218576000059.xhtml#deq2) 中的顶部系统变为

```
\sum_{k = 1}^{n} \psi_k(\theta) \nabla_\theta [g^2(W_k, \theta)] + \sum_{k = 1}^{n} g^2(W_k, \theta) \nabla_\theta [\psi_k(\theta)] = \lambda \nabla_\theta [\eta(\theta)].
```

## 1.3 案例研究

在第 [1.3.1](#Chp001_1-34_B9780443218576000059.xhtml#s0040) 节中，我将展示如何求解逻辑回归。第一种版本是标准最小二乘法，旨在进一步说明与传统方法的向后兼容性。第二种版本说明了如果你想遵循新方法论的精神，该如何操作。然后我将讨论两个基于合成数据的基本示例。

### 1.3.1 逻辑回归，两种方法

在传统设定中，`w = (y, x)`![Image](images/B9780443218576000059/si83.png)，其中 `y` 是响应变量，`x` 是特征。对于逻辑回归 [[维基百科](https://en.wikipedia.org/wiki/Logistic_regression)]，我们有

`g(w, θ) = g(y, x) = y − F(xᵀθ)`，其中 `xᵀθ = θ_1 x_1 + ⋯ + θ_m x_m`。

![Image](images/B9780443218576000059/si84.png)

这里 `x_1 = 1`![Image](images/B9780443218576000059/si18.png) 对应截距项，因此我们有 `m − 1`![Image](images/B9780443218576000059/si85.png) 个实际特征 `x_2, x_3, …, x_m`![Image](images/B9780443218576000059/si86.png)。参数 `θ` 没有约束，因此不存在函数 `η(θ)`![Image](images/B9780443218576000059/si87.png)。在公式 [(1.2)](#Chp001_1-34_B9780443218576000059.xhtml#deq2) 中，应忽略 `η(θ) = 0`![Image](images/B9780443218576000059/si42.png)，且 `λ = 0`![Image](images/B9780443218576000059/si88.png)。函数 `F` 是一个在原点附近密度对称的累积分布函数。在这种情况下，`F(xᵀθ) = 1 / (1 + exp[−xᵀθ])`![Image](images/B9780443218576000059/si89.png) 是标准**逻辑分布** [[维基百科](https://en.wikipedia.org/wiki/Logistic_distribution)]。

在新方法论中，流程如下。首先，原始数据记为 `z = (v, u)`![Image](images/B9780443218576000059/si90.png)。逻辑回归应用于原始数据。这里 `v` 是响应变量，`u` 是特征向量。参数 `θ` 保持不变（不进行映射），仍记为 `θ`。该回归可表述为

`g(z, θ) = g(v, u) = v − F(uᵀθ)`，其中 `uᵀθ = θ_1 u_1 + … + θ_m u_m`。

![Image](images/B9780443218576000059/si91.png)

第一步是将 `z = (v, u)`![Image](images/B9780443218576000059/si90.png) 映射到 `w = (y, x)`![Image](images/B9780443218576000059/si83.png)，希望简化问题，正如第 [1.1.1](#Chp001_1-34_B9780443218576000059.xhtml#s0015) 节所讨论的。这是通过链接函数 `y = F^(−1)(v) = log[v/(1 − v)]`![Image](images/B9780443218576000059/si92.png) 和 `u = x`![Image](images/B9780443218576000059/si93.png) 完成的。现在我们回到

`g(z, θ) = g(w, θ) = g(y, x; θ) = y − xᵀθ`，其中 `xᵀθ = θ_1 x_1 + … + θ_m x_m`。

![Image](images/B9780443218576000059/si94.png)

这就是标准线性回归在新框架中的表达方式。但这仍然是传统的线性回归，没有任何新意。最后一步是扩展 `θ`，向 `θ_1, …, θ_m`![Image](images/B9780443218576000059/si96.png) 添加一个分量 `θ_0`![Image](images/B9780443218576000059/si95.png)。使用新的 `θ`（仍记为 `θ`），我们有 `g(w, θ) = wᵀθ = θ_0 w_0 + ⋯ + θ_m w_m`![Image](images/B9780443218576000059/si97.png)。你需要给 `θ` 添加一个约束。约束 `θ_0 = −1`![Image](images/B9780443218576000059/si17.png)，即 `η(θ) = θ_0 + 1`![Image](images/B9780443218576000059/si44.png)，得到的解与传统线性回归完全相同。但 `θᵀθ = 1`![Image](images/B9780443218576000059/si59.png)，即 `η(θ) = θᵀθ − 1`![Image](images/B9780443218576000059/si43.png)，使问题在某种程度上变得对称，且更加优雅。

然而，在许多应用中，原始空间中的响应 `v` 要么是 0 要么是 1，例如癌症与非癌症，或欺诈与非欺诈。在这种情况下，链接函数未定义。如果响应是一个比例，严格介于 0 和 1 之间，则带有链接函数的映射有效。否则，标准逻辑回归是最佳方法。一个可能的变通方法是让 `F` 使用一个有限支撑的分布，例如 `[a, b]`![Image](images/B9780443218576000059/si98.png) 上的均匀分布。毕竟，观测值（特征）无论如何总是有界的。然后，直观上，给定 `θ`，`a` 和 `b` 的估计值分别与 `U_k θ`![Image](images/B9780443218576000059/si99.png) 在 `k = 1, …, n`![Image](images/B9780443218576000059/si49.png) 下的最小值和最大值成比例。

这提示了一种新的逻辑回归方法。首先，在 `(v, u)`![Image](images/B9780443218576000059/si101.png) 空间中使用模型 `v = F_θ(uᵀθ)`![Image](images/B9780443218576000059/si100.png)，其中 `0 ≤ v ≤ 1`![Image](images/B9780443218576000059/si102.png)，且 `F_θ`![Image](images/B9780443218576000059/si103.png) 是给定 `θ` 时 `uθ` 的经验分布 [[维基百科](https://en.wikipedia.org/wiki/Empirical_distribution_function)]。然后选择使平方残差和最小化的 `θ^(\*)`![Image](images/B9780443218576000059/si10.png)：

```
θ^* = argmin_θ ∑_{k=1}^n g^2(V_k, U_k; θ) = argmin_θ ∑_{k=1}^n (V_k - F_θ(U_k θ))^2.
```
