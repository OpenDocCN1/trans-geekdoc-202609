
收敛性以及公式[(9.2)](#Chp009_147-168_B9780443218576000138.xhtml#deq3)左边与右边的匹配，植根于傅里叶级数理论。详情请见[此处](https://mathoverflow.net/questions/438157/convergence-of-series-related-to-partial-fraction-expansion-of-cotangent-functio)。奇函数也存在类似公式。注意：*f*为偶函数当且仅当`f(−t) = f(t)`，*f*为奇函数当且仅当`f(−t) = −f(t)`。通过结合奇函数和偶函数的两个公式，可得到一个适用于所有函数（无论奇偶性）的公式。同样，关于向`f(t)`收敛也存在限制：函数*f*必须是两项之和，一项涉及余弦（如公式[(9.3)](#Chp009_147-168_B9780443218576000138.xhtml#deq4)所示），另一项涉及正弦。在我的通用解中，必须将公式[(9.3)](#Chp009_147-168_B9780443218576000138.xhtml#deq4)中的`π`替换为`π/2`——正弦项同理——才能使公式[(9.2)](#Chp009_147-168_B9780443218576000138.xhtml#deq3)的广义版本成立。

该公式假设**插值节点**为整数。但可通过变换`t' = a + b*t`使用不同网格。随后利用`f(t')`的已知值插值`f`，其中`(t' − a)/b`为整数，而非利用`f(t)`的已知值（其中`t`为整数）。通过适当选择`a`，可将插值公式推广至先前讨论的限制之外。对于不均匀间距节点，应使用非线性映射`φ(t)`代替`a + b*t`。函数`φ`应严格单调，因而可逆。

Python实现见第[9.3.1](#Chp009_147-168_B9780443218576000138.xhtml#s0060)节，并在我的GitHub仓库中提供为`interpol_fourier.py`，地址：[此处](https://github.com/VincentGranville/Statistical-Optimization/blob/main/interpol_fourier.py)。利用线性变换`a + b*t`，我使用非整数节点插值数学函数。代码包含带复数参数的高级复值数学函数（贝塞尔函数、黎曼ζ函数），供科学计算爱好者参考。同时也演示了如何在Python中使用[mpmath库](https://mpmath.org/)，这是Matlab的替代方案。

[图9.1](#Chp009_147-168_B9780443218576000138.xhtml#f0010)展示了**黎曼ζ函数**`ζ(σ + i*t)`在**临界线**上实部的插值，即`σ = 1/2`时的情况。根据著名的**黎曼假设**，所有非平凡零点均位于此处。实际上，我首次使用插值公式正是在此背景下（整数节点）。此处的近似基于更精细的网格，精度更高。详见第[17](#Chp017_329-360_B9780443218576000217.xhtml)章。

有趣的是，该函数与许多现实生活中的时间序列颇为相似：归根结底，它只是幅度各异、周期不相容的正弦和余弦项的特殊组合。因此它是时间序列合成的良好候选者，通过选择合适的`t`区间和映射，能模拟许多真实案例。海洋潮汐数据和地球与金星的距离（第[9.1.2](#Chp009_147-168_B9780443218576000138.xhtml#s0020)节）即属此类，虽涉及的项数较少（`ζ`函数项数无限）。

### 9.1.2 应用：海洋潮汐、行星排列

第[9.1.1](#Chp009_147-168_B9780443218576000138.xhtml#s0015)节引入的框架及对应Python代码，均可处理数学函数和时间序列数据集。代码中用`g`表示精确函数，插值版本记为`interpolate`。每个插值`f(t)`基于`2*n + 1`个整数节点，在这些节点上假设精确值`g(t)`已知，分布在时间水平轴上`t`的两侧（左侧和右侧）。

此处数据集（时间序列）为都柏林海洋潮汐，以5分钟为增量测量。小规模数据提取`tides_Dublin.txt`在我的GitHub仓库：[此处](https://github.com/VincentGranville/Statistical-Optimization/blob/main/tides_Dublin.txt)。完整版可在此下载：[此处](https://www.digitalocean.ie/Data/DownloadTideData)，来自DigitalOcean.ie。我用它测试方法论，因为潮汐无需统计模型即可轻松预测。结论如下：

*   仅需80分钟增量的数据即可重构5分钟时间序列。因此可将数据集压缩16倍（仅保留小部分），几乎无信息损失。
*   5分钟实测数据与5分钟插值非常接近。二者不同时，插值似乎优于实测值。插值消除了噪声。
*   此做法在文献中称为时间序列**解聚**。可用于从小时观测中恢复未观测的5分钟污染水平和降雨数据，及其他场景。
*   这也等同于生成16个偏移的80分钟插值潮汐子集，偏移量为5分钟。每个子集本身即为合成数据集。若5分钟数据未知，这将极其有用，能提供80分钟数据集的多个合成副本。尽管5分钟数据已知，我仍这样做是为了测试插值精度。所有插值（无论时刻）均基于单一的80分钟增量实测子集生成，仿佛中间值未知。

数据集存储在表`temp`中。它等价于一个数组，只是索引不再是整数，而是`1/16`的倍数。因此Python中我使用字典而非数组。插值计算使用索引为整数的观测值（16个观测值中的1个）。第[9.1.1](#Chp009_147-168_B9780443218576000138.xhtml#s0015)节数学函数插值同理。最后，每个插值基于`2*n + 1`个节点（索引为整数的精确值），`n = 8`，跨越`(8 + 8) × 80`分钟时段（约21小时）。设计上，每80分钟——即索引为整数时——插值与精确值完全一致：对应[图9.2](#Chp009_147-168_B9780443218576000138.xhtml#f0015)中的橙点。
