
[图 15.3](#Chp015_277-292_B9780443218576000199.xhtml#cf0085) 宇宙 4（左）和宇宙 7（右）的快照。

宇宙 4 有一颗质量为负的巨大中心恒星，显示为红色。此外，引力定律不是平方反比定律：我在 Python 代码中使用 `law=-0.5` 而不是标准的 `law=3`。蓝色恒星具有正质量，整个系统开始时只有一个单一的恒星星团。然而，最终形成了多个星团。右上角的星团在早期形成，以疯狂递增的速度围绕红色恒星运动，最终解体。这个脉动宇宙表现出快速增长的**熵** [[Wiki](https://en.wikipedia.org/wiki/Entropy)]，最终陷入**奇点** [[Wiki](https://en.wikipedia.org/wiki/Singularity)]：它实际上在完成 2000 个视频帧之前就导致 Python 程序崩溃。这解释了为什么相应的视频比其他视频短 25 秒。如果你放大查看，会注意到除了中心恒星外，还有几颗质量为负的小恒星：它们显示为红色。

相反，宇宙 7 是我们在现实生活中所知的经典、表现良好的版本。它开始时有三个分离的星团，但最终只剩下一个，因为星团迅速合并。随着宇宙膨胀，熵随时间减少，尽管最终膨胀速度越来越慢。绿色、蓝色和品红色表示恒星最初属于哪个星团。该快照取自视频中间，显示三个星团已经充分混合，此时形成了一个单一星团。可以看到许多双星，它们可能来自不同的星团。一旦两颗恒星碰撞，产生的恒星颜色变为橙色，这解释了为什么靠近中心处聚集着橙色恒星（通常较大）。

## 摘要

本章涵盖与现代机器学习最相关的额外主题，摘自我所著的《随机过程与模拟：机器学习视角》[[20]](#Chp016_293-327_B9780443218576000205.xhtml#br0100)。目的是向你介绍一种新型的**随机点过程** [[Wiki](https://en.wikipedia.org/wiki/Point_process)]，其应用于传感器数据、化学、物理（特别是晶体学）和蜂窝网络：例如，优化基站或**物联网**（IOT）设备的位置。

相关过程称为**扰动晶格**，在此称为泊松-二项过程，原因很快将变得显而易见。它既不同于泊松过程，也不同于二项过程。本章涵盖更高级的材料，特别是涉及统计和概率理论的内容。大多数数学推导（如定理）仅提及而不加证明。有兴趣的读者可参考 [[20]](#Chp016_293-327_B9780443218576000205.xhtml#br0100) 了解详情。重点仍然在于数据驱动推断、经验分布、**分位数函数**（概率分布的逆函数）以及包括一种新的独立性检验在内的推断技术。本章讨论的主题包括二维簇过程、最近邻图、基于晶格的结构、统计推断，以及一种简单的替代方案，可替代通常用于**生成对抗模型**（GAN）中的**高斯混合模型**（GMM）。近年来，扰动晶格点过程引起了相当大的兴趣，参见 [[34](#Chp016_293-327_B9780443218576000205.xhtml#br0170),[38]](#Chp016_293-327_B9780443218576000205.xhtml#br0190)。
