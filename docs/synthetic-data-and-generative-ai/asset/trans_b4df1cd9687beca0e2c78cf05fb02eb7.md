
在二维空间中，在一个**无向最近邻图**中，最大团的最小规模为 2（因为每个点都有一个最近邻），最大规模为 3。最大团必须是一个**连通分量**。请参阅[练习 16.1](#Chp016_293-327_B9780443218576000205.xhtml#enun0010)中连通分量的定义。如果每个点恰好有一个最近邻，则大小为 `n` > 1![Image](images/B9780443218576000205/si161.png) 的连通分量有 `n` 或 `n` − 1![Image](images/B9780443218576000205/si162.png) 条边（见[图 16.6](#Chp016_293-327_B9780443218576000205.xhtml#f0040)右侧图中的箭头），而大小为 `n` 的团恰好有 $\frac{1}{2}n(n - 1)$![Image](images/B9780443218576000205/si163.png) 条边。这就是为什么不存在规模大于 3 的最大团的原因。但在 `d` 维空间中，最大团的规模可以是 `d` + 1![Image](images/B9780443218576000205/si164.png)。最大团可以使用**MaxCliqueDyn 算法** [[维基](https://en.wikipedia.org/wiki/MaxCliqueDyn_maximum_clique_algorithm)] 来寻找。

#### 16.2.4.3 用于计算连通分量的 Python 代码

Python 代码 [`PB_NN_graph.py`](https://github.com/VincentGranville/Point-Processes/blob/main/Source%20Code/PB_NN_graph.py) 也在 GitHub 上。我还用它生成了第 [15.3](#Chp015_277-292_B9780443218576000199.xhtml) 节中描述的问题的连通分量。网上有许多可用的实现。这里介绍的算法不像大多数其他算法那样使用递归。相反，它依赖于一种称为 `stack` 的数据结构。它与任何高效的替代方案一样快，并在最近邻图上进行了测试。如果两个点中的一个是另一个的最近邻，则认为这两个点是连通的。输入文件的第一列表示点的索引 `idx`，`NNidx[idx]`（在第二列中）是以点 `idx` 为最近邻的点的索引。

算法工作如下。浏览点列表。如果点 `idx` 尚未分配给连通分量，则创建一个包含 `idx` 的新连通分量 `cliqueHash[idx]`；找到与 `idx` 连通的点，将它们添加到 `stack`（`stack`）中。找到与连通到 `idx` 的点相连通的点，以此类推，递归地进行，直到无法再添加更多点。每次将一个点添加到 `cliqueHash` 时，将 `stack` 的大小减一。找到所有连通分量大约需要 2`n` 步，其中 `n` 是点的数量。该算法不使用递归函数；它使用 `stack` 来模拟递归。

代码的第一部分创建无向图哈希，具体如下：如果索引为 `k` 的点是索引为 `idx` 的点的最近邻，则将点 `idx` 添加到 `hash[k]`，并将点 `k` 添加到 `hash[idx]`。因此 `hash[idx]` 包含所有直接连接到点 `idx` 的点（它们的索引）；这些点由波浪号符号分隔。

## 16.3 点过程的统计推断

本节涵盖以下主题：泊松-二项过程核心参数的估计（强度和尺度因子），以及莱利检验，用于评估——基于最近邻距离的分布——空间数据集是否表现出随机分布中不期望出现的模式。最小对比估计、预测相邻点之间的极端距离，以及恢复附加在泊松-二项过程上的潜在隐藏分布 `F`，将在第 [16.4](#Chp016_293-327_B9780443218576000205.xhtml#s0130) 节中讨论。点计数独立性的检验在第 [16.1.3](#Chp016_293-327_B9780443218576000205.xhtml#s0025) 节中介绍。在类似于混合模型的聚类过程中检测聚类并估计其数量，请参见第 [5](#Chp005_83-102_B9780443218576000096.xhtml) 章。

### 16.3.1 核心参数估计

假设点过程覆盖整个空间 ℝ![Image](images/B9780443218576000205/si165.png) 或 ℝ²![Image](images/B9780443218576000205/si166.png) 且包含无限多个点，并且只能通过有限的（通常是矩形的）窗口或区间观测到有限数量的点。这里我专注于一维情况。关于二维过程，请参见第 [16.3.2.1](#Chp016_293-327_B9780443218576000205.xhtml#s0110) 节。

在一维情况下，两个最基本的参数是强度 `λ` 和尺度因子 `s`。这里提出的 `λ` 的标准估计量是渐近无偏的 [[维基](https://en.wikipedia.org/wiki/Consistent_estimator)]。关于一种更通用的、无模型的方法，能同时为 `s` 和 `λ` 产生无偏估计量以及置信区域，请参见第 [18.3](#Chp018_361-386_B9780443218576000229.xhtml) 节。本节的目标是提供高效、易于计算且利用底层模型性质的估计量。

#### 16.3.1.1 强度

有多种方法可以估计强度 `λ`（更具体地说，是在 `d` 维中的 `λ`^(`d`)![Image](images/B9780443218576000205/si167.png)），使用**到达间隔时间**（一维）、最近邻距离（二维）或在某个区间 `B` 上计算的点计数分布 `N`(`B`)![Image](images/B9780443218576000205/si19.png)。假设边界效应得到缓解，一个方差较小的良好估计量是观测到的点总数除以观测窗口的面积（或一维情况下的长度）。

到达间隔时间的期望值是 1/`λ`![Image](images/B9780443218576000205/si38.png)。因此，如果你对所有观测点（在一维中称为事件）的所有到达间隔时间取平均值，你会得到 1/`λ`![Image](images/B9780443218576000205/si38.png) 的一个无偏估计量。它的乘法逆元将是 `λ` 的一个略微有偏的估计量；如果点的数量足够大（例如 >50），偏差可以忽略不计。

#### 16.3.1.2 尺度因子

一旦估计了 `λ`，就可以通过利用这样一个事实来估计尺度因子 `s`：对于任意 `r` > 0![Image](images/B9780443218576000205/si169.png)，`E`[`T`^(`r`)(`λ`, `s`)] = `E`[`T`^(`r`)(1, `λ``s`)]/`λ`^(`r`)![Image](images/B9780443218576000205/si168.png)。这里 `T`(`λ`, `s`)![Image](images/B9780443218576000205/si170.png) 是到达间隔时间（一个随机变量），换句话说，是在一维情况下 X 轴上一个点到其右侧最近邻的距离。这个结果不依赖于分布 `F`。有关证明，请参阅我的著作《随机过程与仿真：机器学习方法》中的定理 4.2。

令 `r` = 2![Image](images/B9780443218576000205/si171.png)，设

*   •  `τ[0]`![Image](images/B9780443218576000205/si172.png) 为你对 `T`²(`λ`, `s`)![Image](images/B9780443218576000205/si173.png) 的估计值（在你的数据集上计算的平均值），
*   •  `τ'` = (`λ`[0])^(`r`) ⋅ `τ[0]`![Image](images/B9780443218576000205/si174.png)，其中 `λ`[0]![Image](images/B9780443218576000205/si175.png) 是你对 `λ` 的估计值（见第 [16.3.1.1](#Chp016_293-327_B9780443218576000205.xhtml#s0090) 节），
*   •  `s'`![Image](images/B9780443218576000205/si176.png) 为 `E`[`T`^(`r`)(1, `s'`)] = `τ'`![Image](images/B9780443218576000205/si177.png) 的解。

则 `s`[0] = `s'`/`λ`[0]![Image](images/B9780443218576000205/si178.png) 是 `s` 的一个估计值。
