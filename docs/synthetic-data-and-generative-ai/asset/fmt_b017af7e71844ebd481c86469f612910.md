
This is the general elliptic form of the contour line. Essentially, it does not depend on `n`, `p`, `q`![Image](images/B9780443218576000229/si34.png) when `n` is large. The standard confidence region is then the set of all (`x`, `y`)![Image](images/B9780443218576000229/si2.png) satisfying `H[n](x, y, p[0], q[0]) ≤ G[γ]`![Image](images/B9780443218576000229/si35.png). Here you choose `G[γ]`![Image](images/B9780443218576000229/si36.png) to guarantee that the **confidence level** is `γ`. Replace ⩽ by = to get the boundary of that region.

In this case `G[γ]`![Image](images/B9780443218576000229/si36.png) is a **quantile** of the **Hotelling distribution** [[Wiki](https://en.wikipedia.org/wiki/Hotelling%27s_T-squared_distribution)]. In Section [18.3.4](#Chp018_361-386_B9780443218576000229.xhtml#s0065), I show how to compute `G[γ]`![Image](images/B9780443218576000229/si36.png). The simulations apply to any setting, whether `G[γ]`![Image](images/B9780443218576000229/si36.png) is a Hotelling, Fisher, or any quantile. Or whether the limit distribution of your estimator (`p[0]`, `q[0]`)![Image](images/B9780443218576000229/si27.png) is Gaussian or not, as `n` – the sample size – increases. These simulations provide a generic framework to compute confidence regions.

### 18.3.3 Dual confidence region

The **dual confidence region** is simply obtained by swapping the roles of (`x`, `y`)![Image](images/B9780443218576000229/si2.png) and (`p`, `q`)![Image](images/B9780443218576000229/si37.png) in `H[n](x, y, p, q)`![Image](images/B9780443218576000229/si38.png). It is thus defined as the set of (`x`, `y`)![Image](images/B9780443218576000229/si2.png) satisfying `H[n](p, q, x, y) ≤ H[γ]`![Image](images/B9780443218576000229/si39.png). Again, you choose `H[γ]`![Image](images/B9780443218576000229/si40.png) to guarantee that the confidence level is `γ`. Also, (`p`, `q`)![Image](images/B9780443218576000229/si37.png) is replaced by (`p[0]`, `q[0]`)![Image](images/B9780443218576000229/si27.png). This is no longer the equation of an ellipse. In practice, both confidence regions are very similar. Also, `H[γ]`![Image](images/B9780443218576000229/si40.png) is almost identical to `G[γ]`![Image](images/B9780443218576000229/si36.png). The interpretation is as follows. A point (`x`, `y`)![Image](images/B9780443218576000229/si2.png) is in the dual confidence region of (`p[0]`, `q[0]`)![Image](images/B9780443218576000229/si27.png) if and only if (`p[0]`, `q[0]`)![Image](images/B9780443218576000229/si27.png) is in the standard confidence region of (`x`, `y`)![Image](images/B9780443218576000229/si2.png). I use the same `n` and confidence level `γ` for both regions. You can use the same principle to define dual confidence intervals.

Dual confidence regions are based on the same principle as **credible regions** [[Wiki](https://en.wikipedia.org/wiki/Credible_interval)] in Bayesian statistics. Other methods producing nonelliptic regions are described in [[4]](#Chp018_361-386_B9780443218576000229.xhtml#br0020).

### 18.3.4 Simulations

The simulations consist of generating `N` data sets, each with `n` observations. Use the joint Bernoulli model described in Section [18.3.1](#Chp018_361-386_B9780443218576000229.xhtml#s0050), for the simulations. The purpose is to create data sets that have the same statistical behavior as your observations: in other words, synthetic data. In particular, I simulate the bivariate Bernoulli model using some prespecified `p[0]`, `q[0]`![Image](images/B9780443218576000229/si41.png), the true but unknown values that we want to estimate. I now describe how to proceed.

For each simulated data set, compute the proportions, standard deviations, and correlations. They are denoted as `x`, `y`, `σ[x]`, `σ[y]`![Image](images/B9780443218576000229/si42.png), and `ρ[x, y]`![Image](images/B9780443218576000229/si43.png) (one set of values per data set). Use the standard formulas, but this time with `x`, `y`![Image](images/B9780443218576000229/si5.png) observed, and `p[0]`, `q[0]`![Image](images/B9780443218576000229/si41.png) the variables. That is,

```
$H\_{n}(p\_{0},q\_{0},x,y) = \frac{2n}{1 - \rho\_{x,y}^{2}}\left\lbrack \left( \frac{p\_{0} - x}{\sigma\_{x}} \right)^{2} - 2\rho\_{x,y}\left( \frac{p\_{0} - x}{\sigma\_{x}} \right)\left( \frac{q\_{0} - y}{\sigma\_{y}} \right) + \left( \frac{q\_{0} - y}{\sigma\_{y}} \right)^{2} \right\rbrack,\sigma\_{x} = \sqrt{x(1 - x)},\quad\sigma\_{y} = \sqrt{y(1 - y)},\quad\rho\_{x,y} = - \frac{xy}{\sqrt{xy(1 - x)(1 - y)}}$.
```

![Image](images/B9780443218576000229/si44.png)

Also compute `G(x, y) = H[n](x, y, p[0], q[0])`![Image](images/B9780443218576000229/si45.png) and `H(x, y) = H[n](p[0], q[0], x, y)`![Image](images/B9780443218576000229/si46.png) for each data set. Put the results in a table with `N` rows and 7 columns. Proceed as follows.

*   **Standard confidence region** – sort the table by `G(x, y)`![Image](images/B9780443218576000229/si47.png).
*   **Dual confidence region** – sort the table by `H(x, y)`![Image](images/B9780443218576000229/si48.png).

The first `⌊γN⌋`![Image](images/B9780443218576000229/si49.png) rows in your sorted table determine your confidence region of level `γ`. All the (`x`, `y`)![Image](images/B9780443218576000229/si2.png) in those rows belong to your confidence region. Here `⌊⋅⌋`![Image](images/B9780443218576000229/si50.png) represents the integer part function. In the first `⌊γN⌋`![Image](images/B9780443218576000229/si49.png) rows, the last value of `H(x, y)`![Image](images/B9780443218576000229/si48.png) – if sorted by `H(x, y)`![Image](images/B9780443218576000229/si48.png) – is `H[γ]`![Image](images/B9780443218576000229/si40.png). Likewise, if sorted by `G(x, y)`![Image](images/B9780443218576000229/si47.png), the last value of `G(x, y)`![Image](images/B9780443218576000229/si47.png) is `G[γ]`![Image](images/B9780443218576000229/si36.png). See example in [Fig. 18.4](#Chp018_361-386_B9780443218576000229.xhtml#f0035), with ![Image](images/B9780443218576000229/fx004.jpg)and ![Image](images/B9780443218576000229/fx005.jpg). As `N` increases, your simulations yield regions closer and closer to the theoretical ones. The spreadsheet with these simulations is available on my GitHub repository, [here](https://github.com/VincentGranville/Point-Processes/tree/main/Spreadsheets).
