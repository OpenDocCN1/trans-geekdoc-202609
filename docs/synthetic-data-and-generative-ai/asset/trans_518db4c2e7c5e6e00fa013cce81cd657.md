
其中 `0 < ϵ < 1`、`p > 0` 和 `0 < t[0] < 2π` 为参数。参数 `ϵ` 为离心率。由于函数 `g(t)` 和 `f(t)` 是任意的、可以是不连续的，并且可能包含无限多个参数（例如泰勒级数或傅里叶级数的系数），因此它涵盖了宇宙中存在的所有可能形状。

## 6.3 形状签名

形状签名的概念并非新事物，请参阅 [\[1](#Chp006_103-111_B9780443218576000102.xhtml#br0005),[3\]](#Chp006_103-111_B9780443218576000102.xhtml#br0015)。每个形状（或点集）都由一个称为 `signature` 的归一化集合唯一描述。在我们的语境中，该集合可以是一条曲线、一个点集、多条折线曲线，或这些元素的组合。签名不依赖于形状的位置或重心。它依赖于方向，尽管很容易推广定义使其具有旋转不变性，或用于处理三维形状。第一步是将重心（质心）作为原点，然后通过标准化半径 `r[t]` 的方差来重缩放形状。

质心是位于形状上的点的加权平均值。通常，权重是常数。然而，如果点在形状上分布不均匀，则可以使用适当的权重来校正这种伪影。这在 [图 6.2](#Chp006_103-111_B9780443218576000102.xhtml#f0015) 中有所说明。现在我将深入探讨重加权过程的细节。

### 6.3.1 加权质心

设 `(x[t], y[t])` 为形状上观测点的标准坐标。换句话说，`x[t] = r[t] cos θ[t]` 和 `y[t] = r[t] sin θ[t]`。质心定义为 `(G[x], G[y])`，满足

```math
G_{x} = \frac{1}{\mu}\int_{T}w_{t}x_{t}dt,\quad G_{y} = \frac{1}{\mu}\int_{T}w_{t}y_{t}dt,\quad\text{with~}\mu = \int_{T}w_{t}dt.
```

此处 `w[t] > 0` 为权重函数，`t ∈ T`。如果 `t` 是离散的（例如，形状由观测数据点组成），则积分替换为求和。

在大多数情况下，点在曲线上分布不均匀。在真实数据集中，这表现为点密度高的位置曲线显得更暗或更粗；请见 [图 6.2](#Chp006_103-111_B9780443218576000102.xhtml#f0015)。如果这不是期望的特征，可以通过适当的重加权来消除。为了使点在曲线上均匀分布，在计算质心时按如下步骤进行。使用微积分中的符号，你希望 `Δs[t]`（包含 `(x[t], y[t])` 的无限小曲线段的长度）与 `w[t]` 成正比。由于比例因子无关紧要，我们必须有

```math
\Delta s_{t} = \sqrt{(\Delta x_{t})^{2} + (\Delta y_{t})^{2}} = w_{t}\Delta t.
```

这导出

```math
w_{t} = \sqrt{\left( \frac{dx_{t}}{dt} \right)^{2} + \left( \frac{dy_{t}}{dt} \right)^{2}}.
```

利用极坐标可重写为

```math
w_{t} = \sqrt{\left( \frac{dr_{t}}{dt} \right)^{2} + r_{t}^{2}\left( \frac{d\theta_{t}}{dt} \right)^{2}}.
```

该公式假设涉及的函数可微。在许多情况下，存在一些点（`t` 的值），函数仅左侧或右侧可微 [[Wiki](https://en.wikipedia.org/wiki/Semi-differentiability)]，而非两侧皆可微。对于这些点，使用左导数或右导数。

### 6.3.2 计算签名

我们需要一个易于计算的数学对象，能在平移向量和缩放因子的意义下唯一表征一个形状。所有极坐标 `(r[t], θ[t])` 的集合（`t ∈ T`）唯一表征该形状。但它不具备尺度不变性或平移不变性。为解决此问题，首先需要变换坐标系，使由公式 [(6.2)](#Chp006_103-111_B9780443218576000102.xhtml#deq4) 定义的质心 `(G[x], G[y])` 成为原点。你可以使用第 [6.3.1](#Chp006_103-111_B9780443218576000102.xhtml#s0025) 节讨论的权重函数 `w[t]`。然后，需要按因子 `σ` 重缩放。最终，新坐标为

```math
u[t] = \sigma^{-1} \cdot (x[t] - G[x]) = \rho[t] \cos \phi[t],\quad v[t] = \sigma^{-1} \cdot (y[t] - G[y]) = \rho[t] \sin \phi[t].
```

此处 `u[t], v[t]` 为取代 `x[t], y[t]` 的新笛卡尔坐标，`ρ[t], φ[t]` 为取代 `r[t], θ[t]` 的新极坐标。出于将在 6.4 节比较两个形状时变得显而易见的原因，缩放因子选取如下：

```math
\sigma = \sqrt{\int_{T}{(x_{t} - G_{x})}^{2} + {(y_{t} - G_{y})}^{2}dt}.
```

立即可得

```math
\rho_{t} = \sigma^{-1} \cdot \sqrt{{(x_{t} - G_{x})}^{2} + {(y_{t} - G_{y})}^{2}},\quad\text{and~}\int_{T}\rho_{t}^{2}dt = 1.
```

现在签名定义为所有 `(ρ[t], φ[t])` 的集合（`t ∈ T`）。由构造知，`0 ≤ φ[t] ≤ 2π`。绘制签名时，为使其无论形状如何均保持在 `[0, 2π] × [0, 1]` 范围内，可在垂直轴上用 `ρ[t]/(1 + ρ[t])` 代替 `ρ[t]`。签名示例见 [图 6.2](#Chp006_103-111_B9780443218576000102.xhtml#f0015)（右图）。
