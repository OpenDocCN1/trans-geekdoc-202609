
同样，应首先估计 `s` 和 `λ`。统计量 `T(λ, s)`![Image](images/B9780443218576000205/si170.png) 是 **到达间隔时间** 或一维空间中一个点与其右侧最近邻点之间的距离。然而，`λ`、`s`、`F`![Image](images/B9780443218576000205/si312.png) 的联合估计是可行的，即寻找使 `γ(F)`![Image](images/B9780443218576000205/si313.png) 最小化的参数 `λ`、`s`、`F`![Image](images/B9780443218576000205/si312.png)，现记为 `γ(λ, s, F)`![Image](images/B9780443218576000205/si314.png)。请参阅第 [16.3.1](#Chp016_293-327_B9780443218576000205.xhtml#s0085) 节以分别估计 `λ` 和 `s`：这种分步过程更简单，且不易 **过拟合** [[Wiki](https://en.wikipedia.org/wiki/Overfitting)]。

此处介绍的估计技术，特别是公式 [(16.18)](#Chp016_293-327_B9780443218576000205.xhtml#deq25)，有时被称为 **最小对比估计**。请参阅 Jesper Møller 的演示文稿“空间点过程与基于模拟的推断简介”[[31]](#Chp016_293-327_B9780443218576000205.xhtml#br0155) 中的第 114–116 页。

#### 16.4.4.1 通过模拟获得的理论值

本节重点介绍了一些使用 [`PB_main.py`](https://github.com/VincentGranville/Point-Processes/blob/main/Source%20Code/PB_main.py) 获得的模拟结果，用于计算各种 `λ`、`s`![Image](images/B9780443218576000205/si316.png) 下到达间隔时间 `T = T(λ, s)`![Image](images/B9780443218576000205/si242.png) 的矩 `E[T^r]`![Image](images/B9780443218576000205/si315.png)，以及与点计数（随机变量）`N(B)`![Image](images/B9780443218576000205/si19.png) 相关的统计量，其中 `B = [a, b]`![Image](images/B9780443218576000205/si317.png) 是一个区间。目标是：

- 表明除非 `F` 有有限支集或 `s` 非常小，否则 `F` 的选择影响很小；
- 表明随着 `s` 增加，泊松-二项过程收敛到平稳泊松过程的速度有多快；
- 表明该过程的任意点均可用于计算 `T` 的 *理论分布*，因此选择 `X[0]`![Image](images/B9780443218576000205/si318.png) 或任意 `X[k]`![Image](images/B9780443218576000205/si29.png)，或对多个点取平均，得到的理论分布相同；
- 表明你可以使用包含许多点的单次过程实现，或包含少量点的多次过程实现，来计算 `T` 的理论分布。

最后一个事实说明了 `T` 的 **遍历性**。

[表 16.2](#Chp016_293-327_B9780443218576000205.xhtml#t0015) 显示了基于 `λ = 1`![Image](images/B9780443218576000205/si49.png)、`r = 1/2`![Image](images/B9780443218576000205/si321.png) 和 `B = [a, b]`![Image](images/B9780443218576000205/si317.png)（其中 `a = -0.75`![Image](images/B9780443218576000205/si322.png) 和 `b = 0.75`![Image](images/B9780443218576000205/si323.png)）的模拟结果。测试了三种不同的 `F`：均匀分布、逻辑分布和柯西分布。符号 `μ(B)`![Image](images/B9780443218576000205/si324.png) 代表 `b - a`![Image](images/B9780443218576000205/si325.png)。在二维情况下，它代表集合 `B` 的面积（通常为正方形或圆形）。在一维情况下，当 `s = ∞`![Image](images/B9780443218576000205/si106.png) 时，`N(B)`![Image](images/B9780443218576000205/si19.png) 服从期望为 `λμ(B)`![Image](images/B9780443218576000205/si326.png) 的泊松分布，而 `T` 服从期望为 `1/λ`![Image](images/B9780443218576000205/si38.png) 的指数分布。极限过程是强度为 `λ` 的平稳泊松过程。当 `s = ∞`![Image](images/B9780443218576000205/si106.png) 时，`` `E[√T]` ``![Image](images/B9780443218576000205/si319.png) 的确切公式是通过 Mathematica 在线版本获得的：你可以在此处 [here](https://bit.ly/30t354T) 查看计算过程。一般来说，当 `s → ∞`![Image](images/B9780443218576000205/si8.png) 时，若 `F` 为均匀分布，收敛到泊松过程的速度比使用逻辑分布或柯西分布作为 `F` 时更慢、更不平稳。

#### 16.4.4.2 从到达间隔时间分布中恢复 `F`

此处假设 `F` 具有密度 `f`，且我们处理的是一维泊松-二项过程。测量 X 轴上一个点与其右侧最近邻点之间距离的随机变量 `T(λ, s)`![Image](images/B9780443218576000205/si170.png) 称为到达间隔时间。给定标准化到达间隔时间的极限分布，目的是恢复 `F` 的分布。如果你熟悉 **特征函数** [[Wiki](https://en.wikipedia.org/wiki/Characteristic_function_(probability_theory))] 的概念，这个练习很简单。如果不熟悉，你应该先熟悉这个概念。文中提到的定理源自我所著的《随机过程与模拟：一种机器学习方法》。

**标准化到达间隔时间** 定义为 `` `(1/s)[T(λ,s) - 1/λ]` ``![Image](images/B9780443218576000205/si327.png)，根据定理 4.3，其期望为零。根据定理 4.2，它可以重写为 `` `(1/(λ s))[T(1, λ s) - 1]` ``![Image](images/B9780443218576000205/si328.png)。当 `s → 0`![Image](images/B9780443218576000205/si329.png) 时，其极限记为 `T^*`![Image](images/B9780443218576000205/si330.png)。除了高斯分布和柯西分布外，最简单的情况之一是：如果 `T^*`![Image](images/B9780443218576000205/si330.png) 服从标准 **拉普拉斯分布** [[Wiki](https://en.wikipedia.org/wiki/Laplace_distribution)]（即以零为中心对称，方差为 `π²/3`![Image](images/B9780443218576000205/si135.png)），证明 `F` 是第二类 **修正贝塞尔分布** [[35]](#Chp016_293-327_B9780443218576000205.xhtml#br0175)。注意，根据洛必达法则 [[Wiki](https://bit.ly/3sQXEbL)]，`T^*`![Image](images/B9780443218576000205/si330.png) 是 `T(λ, s)`![Image](images/B9780443218576000205/si170.png) 关于 `s` 的导数，在 `s = 0`![Image](images/B9780443218576000205/si10.png) 处取值。

根据定理 4.4，我们有

`` `P(T^* < y) = ∫_{-∞}^∞ F(y - x) f(x) dx` ``
