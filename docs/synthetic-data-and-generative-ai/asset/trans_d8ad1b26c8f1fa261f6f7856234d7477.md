### 9.1.3 二维问题

在本节中，我讨论一个带有有限求和的基本示例，其中一切都很顺利。然而，这是一个基础且非常重要的情况，因为它适用于所有回归问题。此外，它很容易推广到更高维度。我使用符号 `t = (x, y)` 和 `z = f(t) = f(x, y)`。假设 `ψ(x, y)` 有 `n` 个根 `ρ[k] = (x[k], y[k])`，其中 `k = 1, …, n`。设定如下：我们有一个包含 `n` 个观测值 `(z[k], x[k], y[k])` 的数据集，其中 `k = 1, …, n`。这里 `z[k]` 是响应变量或因变量，`x[k], y[k]` 是两个特征，也称为自变量或预测变量。我使用

```
ψ(t) = ψ(x, y) = ∏_{k=1}^{n} w_k(x, y),  λ(ρ_k) = λ(x_k, y_k) = ∏_{i≠k} w_i(x, y),
```

其中 `w_k(x, y) = w(t, ρ[k]) = w(x, y; x[k], y[k])`。我在公式 [(9.7)](#Chp009_147-168_B9780443218576000138.xhtml#deq9) 中提供了一个具体示例。现在，请记住，根据构造，`w(x, y; x', y') = 0` 当且仅当 `(x, y) = (x', y')`。由此可得

```
z = f(x, y) = ∑_{k=1}^{n} γ_k f(x_k, y_k),  with  γ_k = ∏_{i≠k} w_i(x, y) / w_i(x_k, y_k) = ∏_{i≠k} w(x, y; x_i, y_i) / w(x_k, y_k; x_i, y_i).
```

(9.6)

因此，`z[k] = f(x[k], y[k])`，对于 `k = 1, …, n`。给定一个新观测 `(x, y)`，基于训练集中的 `n` 个数据点的预测响应 `z` 由公式 [(9.6)](#Chp009_147-168_B9780443218576000138.xhtml#deq8) 提供。如果 `(x, y)` 已经在训练集中，则预测的 `z` 将是精确的。

与传统的基于核的方法不同，这里“距离”或“核”函数 `w` 的选择至关重要。一些改进保留了 `z[k] = f(x[k], y[k])`（对于 `k = 1, …, n`）这一事实，同时为训练集外的观测提供了显著更好的预测和平滑度。这使该方法成为回归技术的一个合适替代方案。特别是，我实现了以下改进：

*   将 `γ[k]` 替换为 `γ[k]' = γ[k] / (1 + γ[k])`。这保证了这些系数位于 0 和 1 之间。
*   将 `γ[k]'` 替换为 `γ[k]* = γ[k]' / w_k^(κ)(x, y)`，其中 `κ ≥ 0` 是一个超参数。如果点 `(x[k], y[k])` 离 `(x, y)` 太远，这会减少其影响。
*   归一化 `γ[k]*` 使其和等于 1。这消除了训练集外的加性偏差。

这些变换使该技术在一定程度上成为混合方法：乘法、加法和最近邻方法的组合。通过在插值 `f(x, y)` 时完全忽略点 `(x[k], y[k])`（如果 `w_k(x, y) > δ`），可以获得进一步改进。这里 `δ > 0` 是一个超参数。这可能导致无法为远离所有训练集点的点 `(x, y)` 进行预测：这实际上是一个理想的特性，而不是缺陷。
