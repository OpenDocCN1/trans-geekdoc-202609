
Because of the generalized **universality property** [[Wiki](https://en.wikipedia.org/wiki/Zeta_function_universality)] discussed in [Exercise 17.5](#Chp017_329-360_B9780443218576000217.xhtml#enun0035), the inequality ⩾ `ρ` becomes an equality: the largest circle encompassing the origin, not crossed by the orbit, has radius exactly equal to `ρ`.

We already know that if `P` is the full set of primes and `σ` < 1, there is no hole. According to the Riemann Hypothesis, the hole at the origin is reduced to a singleton if 0.5 < `σ` < 1, and to an empty set if `σ` = 0.5. The **Generalized Riemann Hypothesis** [[Wiki](https://en.wikipedia.org/wiki/Generalized_Riemann_hypothesis)] claims that this is true regardless of the **Dirichlet character** `χ`(·) [[Wiki](https://en.wikipedia.org/wiki/Dirichlet_character)]. But what if we use the set of **twin primes** [[Wiki](https://en.wikipedia.org/wiki/Twin_prime)] for `P`? Then the product in formula [(17.9)](#Chp017_329-360_B9780443218576000217.xhtml#deq12) converges if `σ` = 1, thus there is a hole with `ρ` > 0 encompassing the origin, if `σ` = 1. The convergence is a direct consequence of **Brun's theorem** [[Wiki](https://en.wikipedia.org/wiki/Brun%27s_theorem)]: the fact that the sum of the inverse of twin primes converges. I did not investigate the case `σ` < 1.

I now discuss two cases that are known to satisfy [(17.9)](#Chp017_329-360_B9780443218576000217.xhtml#deq12). Both illustrate methods of **additive number theory** [[Wiki](https://en.wikipedia.org/wiki/Additive_number_theory)]. The idea is to look at two (or more) sets of integers `A` and `B`, and then check the density of integers in `A + B`. The most well-known example is **Goldbach's conjecture** [[Wiki](https://en.wikipedia.org/wiki/Goldbach%27s_conjecture)]: it states that if `A = B` is the set of all primes, then `A + B`, defined as the set of all integers `a + b` with `a ∈ A`, `b ∈ B`, covers all positive even integers greater than 2. The second most well-known example is when `A = B` is the set of square integers. The problem is referred to as **sums of squares** [[Wiki](https://en.wikipedia.org/wiki/Gauss_circle_problem)]. The resulting `A + B` is too large to be of interest here. A more general version is the sum of higher powers, known as **Waring's problem** [[Wiki](https://en.wikipedia.org/wiki/Waring%27s_problem)]. If `A = B` is the set of positive cubes, or `A` is the set of positive cubes and `B` the set of squares, then `A + B` is small enough to lead to interesting results. Let us now investigate these popular cases.

### 17.3.2.1 Sums of two cubes, or cuban primes

Let `P` be the set of primes, greater than 2, that are the sum of two cubes. They are called **cuban primes** [[Wiki](https://en.wikipedia.org/wiki/Cuban_prime)], and featured in the OEIS list of integer sequences as entries [A334520](https://oeis.org/A334520) and [A002407](https://oeis.org/A002407). These primes are of the form `3*x² + 3*x + 1` where `x` is a positive integer. Because cuban primes are less numerous than square integers, we have `∏[p ∈ P](1 + p^(-σ))^(-1) < ∞` if `σ > 0.5`. Thus, if `σ > 0.5` and regardless of `χ`, the associated `L[P](z, χ)` orbit has a hole at the origin, with radius > 0 (not a single point or an empty set). In short, `L[P](z, χ)` never gets too close to zero if `σ > 0.5`. This is in stark contrast to the standard Riemann zeta function `ζ(z)`, which has a hole of strictly positive radius only if `σ > 1`.

It is conjectured that there are infinitely many cuban primes. For primes of the form `x³ + 2*y³`, a proof was published in 2001, see [[12]](#Chp017_329-360_B9780443218576000217.xhtml#br0060).

### 17.3.2.2 Primes associated to elliptic curves

Now, let `P = {p[1], p[2], …}` be the set of primes of the form `x³ + y²`, listed in increasing order. These primes are far less numerous than primes of the form `x² + y²`, but far more numerous than primes of the form `x³ + y³` (the cuban primes). Here `x, y` are positive integers. Note that if `p ∈ P`, then `y² = x³ + p` for some integers `x ≤ 0`, `y ≥ 0`. This is the equation of an **elliptic curve** [[Wiki](https://en.wikipedia.org/wiki/Elliptic_curve)].

When `n` is large enough, the number of positive integers smaller than `n`, of the form `x³ + y²`, is less than `n^(5/6)`. We do not know how many of them are prime numbers, but we know that it must be less than that. Thus `p[k]` is asymptotically larger than `k^(6/5)`. For details, see [Exercise 17.6](#Chp017_329-360_B9780443218576000217.xhtml#enun0040), based on a general summation formula posted [here](https://mathoverflow.net/questions/364559/general-asymptotic-result-in-additive-combinatorics-sums-of-sets). Then, using formula [(17.6)](#Chp017_329-360_B9780443218576000217.xhtml#deq7), we have

```latex
\rho = |L_{P}(z,\chi)| \geqslant \prod\limits_{k = 1}^{\infty}\frac{1}{1 + p_{k}^{\sigma}} \geqslant \prod\limits_{k = 1}^{\infty}\frac{1}{1 + k^{6\sigma/5}}.
```
(17.10)

Regardless of the function `χ`(·), the rightmost product in formula [(17.10)](#Chp017_329-360_B9780443218576000217.xhtml#deq13) converges (absolutely) if `6*σ/5 > 1`, that is, if `$\sigma > \frac{5}{6}$`. So, not only `L[P](z, χ)` has no zero if `$\sigma > \frac{5}{6}$`, but there is a circle of radius `ρ > 0` centered at the origin (a hole), that the orbit never crosses.
