
## 7.3 定点迭代

其中 `λ[1]`，…，`λ[m]`![Image](images/B9780443218576000114/si68.png) 是对角矩阵 `Λ` 的对角元素，而 `m[i j]`![Image](images/B9780443218576000114/si69.png) 是矩阵 `M = X^(T)X`![Image](images/B9780443218576000114/si8.png) 第 `i` 列中的第 `j` 个元素。在实践中，采用这种 `Λ` 的选择，假设 `M` 非奇异，定点迭代总是收敛的，且 `m[i i]` > 0![Image](images/B9780443218576000114/si70.png)。请参阅关于此主题的讨论，[此处](https://mathoverflow.net/questions/421309/power-of-a-matrix-largest-eigenvalue-in-absolute-value-and-convergence-acceler)。

### 7.3.1 电子表格实现

`λ[i]`![Image](images/B9780443218576000114/si71.png) 在 Test 选项卡的 AL2:AL7 单元格中计算。此外，`|φ|`![Image](images/B9780443218576000114/si66.png) 在同一选项卡的 AY59:ES59 单元格中迭代计算。电子表格中用于计算 `|φ|`![Image](images/B9780443218576000114/si66.png) 的方法称为**幂迭代** [[Wiki](https://en.wikipedia.org/wiki/Power_iteration)]。另请参阅[此处](https://math.stackexchange.com/questions/2554808/finding-approximation-of-largest-eigenvalue)。

现在我们已具备计算回归系数的所有条件。它们位于 Results 选项卡的 K5:P5 单元格（基于 `k = 15`![Image](images/B9780443218576000114/si58.png) 次迭代的计算）和 K6:P6 单元格（基于 `k = 100`![Image](images/B9780443218576000114/si72.png) 次迭代的计算）。`|φ|`![Image](images/B9780443218576000114/si66.png) 的最终值位于 Results 选项卡的 K21 单元格。请注意，`|φ|`![Image](images/B9780443218576000114/si66.png) 的值超过 0.95 意味着系统**病态** [[Wiki](https://en.wikipedia.org/wiki/Condition_number)]。例如，某些特征几乎是其他特征的线性组合。这通常会导致性能不佳。在这种情况下，使用少量迭代（`k = 15`![Image](images/B9780443218576000114/si58.png)），结合第 [7.2.3](#Chp007_113-129_B9780443218576000114.xhtml#s0030) 节建议的初始 `β[0]`![Image](images/B9780443218576000114/si7.png)，效果最好。这也能避免过拟合问题。

`Y` 的预测值，分别在经过 `k = 15`![Image](images/B9780443218576000114/si58.png) 和 `k = 100`![Image](images/B9780443218576000114/si72.png) 次迭代后获得，位于 Test 选项卡的 P 列和 Q 列。仅使用 `β[0]`![Image](images/B9780443218576000114/si7.png) 获得的预测值（如第 [7.2.3](#Chp007_113-129_B9780443218576000114.xhtml#s0030) 节所计算）位于 S 列，而使用传统回归获得的预测值位于 U 列，由 Excel 的 Linest 函数生成。通过去除观测（合成）数据中引入的人为噪声而获得的滤波响应位于 R 列。定点回归的计算复杂度与相乘两个 `m × m`![Image](images/B9780443218576000114/si5.png) 矩阵相同，再乘以定点算法中的迭代次数。

### 7.3.2 无过拟合的可解释回归

第 [7.2.3](#Chp007_113-129_B9780443218576000114.xhtml#s0030) 节介绍的回归系数向量 `β[0]`![Image](images/B9780443218576000114/si7.png) 直观、稳健，并保留相关性符号：由设计决定，与响应 `Y` 正相关的特征会被分配正相关系数，如前所述。此外，在许多情况下，其性能接近最优回归系数。它绝对优于基准模型，除非噪声量巨大。但在这种情况下，所有模型表现都很差，无法超越基准模型。性能比较请参见第 [7.4.1](#Chp007_113-129_B9780443218576000114.xhtml#s0065) 节。如果你的问题是病态的（例如，某些特征几乎相同或是其他特征的线性组合），传统技术会导致无意义的回归系数，或完全失效。相反，相关的 `β[0]`![Image](images/B9780443218576000114/si7.png) 能很好地处理这种情况。

所有这些使得相关的 `β[0]`![Image](images/B9780443218576000114/si7.png) 成为定点迭代的良好起点，如果目标是获得稳健、易解释且不易过拟合的解。它可以通过使用定点算法的少量迭代来改进。迭代次数越多，越接近标准的“精确”解，但最终会失去可解释性。使用较少的迭代，你可能仍能获得良好的性能，同时避免上述许多问题。决定何时停止的一种方法是运行多次迭代，并比较（假设）10 次与 100 次迭代后获得的 R 平方。如果差异可忽略不计，则使用在 `k = 10`![Image](images/B9780443218576000114/si73.png) 次迭代获得的回归系数。建议使用第 [7.4](#Chp007_113-129_B9780443218576000114.xhtml#s0060) 节定义的指标 `s`，而不是使用 R 平方。

### 7.3.3 自适应阻尼

提高收敛的一种可能方法是使用依赖于 `k` 的矩阵 `Λ`，记为 `Λ[k]`![Image](images/B9780443218576000114/si12.png)。最简单的例子是当 `Λ[k] = λ(k) ⋅ I`![Image](images/B9780443218576000114/si74.png)，其中 `λ(k)`![Image](images/B9780443218576000114/si75.png) 是实数，`I` 是 `m × m`![Image](images/B9780443218576000114/si5.png) 单位矩阵。然后，选择使 `||(I − λ^(-1))β[k]||[2]`![Image](images/B9780443218576000114/si76.png) 最小化的 `λ(k)`![Image](images/B9780443218576000114/si75.png)，即

```latex
\lambda(k) = \underset{\lambda}{\arg\min} ||(I - \lambda^{-1})\beta_{k}||_{2} = \underset{\lambda}{\arg\min} [(I - \lambda^{-1}M)\beta_{k}]^{T}(I - \lambda^{-1}M)\beta_{k} = \underset{\lambda}{\arg\min} \beta_{k}^{T}\beta_{k} - 2\lambda^{-1}\beta_{k}^{T}M\beta_{k} + \lambda^{-2}(M\beta_{k})^{T}M\beta_{k} = \frac{(M\beta_{k})^{T}M\beta_{k}}{\beta_{k}^{T}M\beta_{k}}.
```

![Image](images/B9780443218576000114/si77.png)

同样，`M = X^(T)X`![Image](images/B9780443218576000114/si8.png)。初步测试显示，与使用固定 `Λ` 相比，没有显著改进。事实上，大约 20% 的时间，回归系数的连续迭代不会收敛，而是振荡。然而，这个问题很容易解决，自适应阻尼——即 `Λ` 依赖于 `k`——有潜力处理具有更大 `m`（特征数量）的数据集。在我大约 100 次测试中，最坏的情况如 [图 7.1](#Chp007_113-129_B9780443218576000114.xhtml#f0010) 所示。与仅使用预条件（固定 `Λ`）相比，其缺点是需要更多计算。关于预条件在类似背景下的近期机器学习应用，请参阅 [[1]](#Chp007_113-129_B9780443218576000114.xhtml#br0005)。
