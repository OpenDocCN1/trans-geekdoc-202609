
该应用程序（包括随附的 Python 代码和 Excel 电子表格）在第 [8](#Chp008_131-145_B9780443218576000126.xhtml) 章中使用合成数据进行了详细讨论。此处无需视频：简单的散点图即可。我之所以包含此可视化，是因为它适用于任何维度，且尽管易于解读，却极少在其他地方被提及。此外，它可以在 Excel 中完成，请参阅 [图 4.1](#Chp004_61-82_B9780443218576000084.xhtml#f0025)，以及 Excel 实现 `fuzzy4.xlsx`，可在[此处](https://ln5.sync.com/dl/0caeb8e10/mztnibg9-xrkdks7g-r8bsgabw-3fsizwif)获取。

目的是计算训练集之外数据的预测值和预测区间，通常用于回归问题（线性或非线性）。我使用验证集 [[Wiki](https://en.wikipedia.org/wiki/Training,_validation,_and_test_data_sets)] 来评估性能，将真实值与预测值进行比较。验证集是训练集的一个子集，不用于训练模型，而是用于测试模型。观测响应 `Z[obs]`![Image](images/B9780443218576000084/si18.png) —— 也称为真实值 —— 取决于 `m` 个特征 `X[1]`，…，`X[m]`![Image](images/B9780443218576000084/si19.png)。它们均为列向量，每个条目对应一个观测值。因此，维度为 `m`。`m` 维特征空间中特定位置 `x = (x[1], …, x[m])`![Image](images/B9780443218576000084/si20.png) 处的预测值记为 `Z[pred](x)`![Image](images/B9780443218576000084/si21.png)，而（例如）90% 预测区间的下界和上界分别记为 `Z[0.05](x)`![Image](images/B9780443218576000084/si22.png) 和 `Z[0.95](x)`![Image](images/B9780443218576000084/si23.png)。

如果 `m > 2`![Image](images/B9780443218576000084/si24.png)，可视化预测区间就会变得具有挑战性。一种方法是创建一个散点图，其中包含验证集中所有 `x` 对应的蓝色二元向量 (`Z[obs](x)`, `Z[pred](x)`)![Image](images/B9780443218576000084/si25.png)。因此 `Z[obs](x)`![Image](images/B9780443218576000084/si26.png) 在横轴上，`Z[pred](x)`![Image](images/B9780443218576000084/si21.png) 在纵轴上。然后，在散点图上添加红色的点 (`Z[obs](x)`, `Z[0.95](x)`)![Image](images/B9780443218576000084/si27.png) 和绿色的点 (`Z[obs](x)`, `Z[0.05](x)`)![Image](images/B9780443218576000084/si28.png)。最终结果见图 [4.1](#Chp004_61-82_B9780443218576000084.xhtml#f0025)。当然，无论维度如何，该方法均适用。

解读该可视化非常容易。如果观测值和预测值相同，则点云，即 (`Z[obs](x)`, `Z[pred](x)`)![Image](images/B9780443218576000084/si25.png)，应全部位于主对角线上。偏离主对角线的垂直轴偏差显示了各个残差误差。它提供的拟合优度 [[Wiki](https://en.wikipedia.org/wiki/Goodness_of_fit)] 图景，比任何单一指标（如 R 平方或均方根偏差 `RMSE` [[Wiki](https://en.wikipedia.org/wiki/Root-mean-square_deviation)]）都要好得多。请注意，R 平方等指标有几个缺点，替代指标将在第 [8](#Chp008_131-145_B9780443218576000126.xhtml) 章中讨论。

该可视化的另一个重要特征是穿过点云的回归线的斜率。如果拟合完美且所有点都位于主对角线上，则斜率将等于 1。实际上，它总是介于 0 和 1 之间。较低的斜率（例如 0.5）并不意味着拟合不好。这意味着回归正在平滑数据中的尖峰，并充当去噪滤波器。这实际上是一件好事。很容易重新缩放预测值，使其方差与在训练集上计算的方差相同。这将恢复原始数据中的较大变化，同时保持平滑度和 R 平方不变。事实上，R 平方定义为观测值与预测值之间相关系数的平方，在缩放和/或平移下保持不变。

### 4.2.3 无限数据集的监督分类

在该问题中，可视化显示了 9 个维度：一个用于时间（在视频中），一个用于点的大小，一个用于类别或组标签，两个用于物理位置（状态空间），四个用于 RGBA 颜色。显示原始数据的视频最后一帧如 [图 4.5](#Chp004_61-82_B9780443218576000084.xhtml#f0045) 所示。水平红线是实轴（X 轴）。红线左侧的黑点是原点 `(0, 0)`![Image](images/B9780443218576000084/si29.png)，右侧的黑点对应 `(0, 1)`![Image](images/B9780443218576000084/si30.png)。使用较大点以实际对整个状态空间执行 `fuzzy classification`（模糊分类）的版本如 [图 4.6](#Chp004_61-82_B9780443218576000084.xhtml#f0050) 所示。这是该情况下最具洞察力的可视化。相应的视频分别见[此处](https://youtu.be/HT8e3WsRLZI)和[此处](https://youtu.be/rRQbxpZAQ78)。请注意三组（红、蓝、黄）之间巨大的重叠。然而，强烈的模式浮现出来：这些点并非随机分布。

该数据集源自数论。它不是合成数据，因为它代表一种真实现象。然而，如果能够使用整个无限数据集，聚类的边界、空洞的边界以及聚类重叠的范围将被精确知晓。理论考量可以解开部分谜团。但此处研究的问题与黎曼假设 [[Wiki](https://en.wikipedia.org/wiki/Riemann_hypothesis)] 有关，后者是有史以来最著名的未解数学难题之一。因此，机器学习技术对于获取更多洞见仍然有用，且在此表现出色。在数学界，此处使用的方法被描述为 `experimental mathematics`（实验数学）[[Wiki](https://en.wikipedia.org/wiki/Experimental_mathematics)]。

#### 4.2.3.1 机器学习视角

在深入数学细节之前，我先解释该问题的机器学习层面。每个通道（红、绿、蓝）中的颜色等级由 0 到 255 之间的整数值表示。使用 `RGBA` 颜色模型有助于可视化聚类重叠。黄色点密度高且蓝色点密度低的区域呈现略微偏绿色，但颜色中黄色多于蓝色。反之，黄色点密度低且蓝色点密度高的区域也呈现略微偏绿色，但颜色中蓝色多于黄色。高点密度导致区域更亮，而低密度区域几乎透明。

事实上，监督分类仅基于该机制自动执行，点的大小是主要超参数。要找到分配给任意位置的标签（红、黄或蓝），必须获取其在 [图 4.6](#Chp004_61-82_B9780443218576000084.xhtml#f0050) 中的 RGB 颜色。例如，如果 `RGB = (155, 105, 100)`![Image](images/B9780443218576000084/si31.png)，则该点为红、蓝、黄的概率分别为 `50/255`、 `100/255`![Image](images/B9780443218576000084/si32.png) 和 `105/255`。计算详情请参阅 [练习 4.1](#Chp004_61-82_B9780443218576000084.xhtml#enun0010)。因此有时称为模糊分类，但它实际上与贝叶斯分类非常相似。
