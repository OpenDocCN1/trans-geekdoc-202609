
使用多边形而非椭圆的原因是为了一个特定应用：基于低分辨率图像估算微小、遥远天体的形状。这在创建这些天体的分类法时特别有用：形状参数被用来对它们进行分类，并了解它们的历史以及引力相互作用，还可作为机器学习算法中的特征。那么，对于一颗小陨石，人们预期将其视为多面体（多边形的 3D 版本）而非椭球体。当然，如果训练集中点的数量 `n` 很大，那么多面体就与拟合椭球体无法区分。但在实践中，由于低分辨率图像，`n` 通常相当小。

### 1.3.2.3 Python 代码

在此高层摘要中，代码中的主要参数以红色高亮显示（印刷版为浅灰色）。该程序列在本节中，也可在 GitHub [此处](https://github.com/VincentGranville/Machine-Learning/blob/main/Source%20Code/fittingEllipse.py) 获取，文件名为 `fittingEllipse.py`。

最小二乘优化使用 Halir 和 Flusser 算法 [[2]](#Chp001_1-34_B9780443218576000059.xhtml#br0010) 的一个实现来执行，该实现改编自 Christian Hill（著作《Learning Scientific Programming with Python》[[3]](#Chp001_1-34_B9780443218576000059.xhtml#br0015) 的作者）发布 [这里](https://scipython.com/blog/direct-linear-least-squares-fitting-of-an-ellipse/) 的版本。该优化——最小化观测点与拟合椭圆之间的平方误差之和——是在代表椭圆的二次方程系数上执行的。这是最简单的方法，也是我在本章其他地方采用的方法。函数 `fit_ellipse()` 完成此工作，而 `cart_to_pol()` 将这些系数转换为有意义的特征：椭圆的中心、旋转角、离心率、长半轴和短半轴 [[Wiki](https://simple.wikipedia.org/wiki/Semi-major_and_semi-minor_axes)]。

#### 椭圆弧上的采样点

Python 代码还集成了由不同作者编写的其他组件。首先，它通过代码主体部分的参数 `sampling_method` ![Image](images/B9780443218576000059/fx001.jpg) 提供了三种在椭圆或椭圆部分弧上采样点的选项：

*   **周长上均匀间隔**，通过函数 `sample_from_ellipse_even()`。代码改编自发布 [这里](https://math.stackexchange.com/questions/3710402/generate-random-points-on-perimeter-of-ellipse) 的匿名版本。它需要计算**椭圆积分** [[Wiki](https://en.wikipedia.org/wiki/Elliptic_integral)]。该技术与第 [6](#Chp006_103-111_B9780443218576000102.xhtml) 章第 [6.3.1](#Chp006_103-111_B9780443218576000102.xhtml) 节中描述的“加权质心”技术相同。

*   **在周长上随机选择**，使得椭圆上两个连续采样点之间的平均距离为常数。它涉及从多元正态分布采样、重新缩放点，然后对采样点进行排序，使其在周长上有序。这还需要根据另一个数组对数组进行排序。这在函数 `sample_from_ellipse()` 中完成。

*   **标准、最简单，但众所周知会产生偏差的采样**。它由在椭圆极坐标表示中选择等间距角度组成。对于曲线拟合，它足够好，与另外两种方法相比差别极小。

若要在部分弧而非完整椭圆上采样，请在主循环中将参数 `tmin` ![Image](images/B9780443218576000059/fx002.jpg) 和 `tmax` ![Image](images/B9780443218576000059/fx003.jpg) 设置为适当的值。这些是极坐标系中的角度，应介于 0 和 `2 * π` 之间。完整椭圆对应 `tmin` 设为零，`tmax` 设为 `2 * π`。

#### 训练集和椭圆参数

然后，为了创建训练集，通过均匀或高斯噪声扰动椭圆上的采样点。选择由代码主体部分的参数 `noise_type` ![Image](images/B9780443218576000059/fx004.jpg) 设定。参数 `noise_level` ![Image](images/B9780443218576000059/fx005.jpg) 决定噪声量，换句话说，即噪声方差。无论是椭圆上的点还是训练集中的点，都是名为 `x` 和 `y` 的数组（分别对应 X 和 Y 坐标）。训练集中的点数由参数 `npts` 决定。

椭圆的形状由 5 维参数向量 `params` ![Image](images/B9780443218576000059/fx006.jpg) 设定。其分量在整个代码中分别表示为 `x0`、`y0`、`ap`、`bp`、`phi`，分别是椭圆的中心、半轴长度和椭圆的方向（旋转角）。

#### 置信区域与曲线拟合

程序在主循环中一次创建一条椭圆，共创建 `nframes` ![Image](images/B9780443218576000059/fx007.jpg) 条椭圆。每次迭代时，创建的椭圆和训练集会被保存为 PNG 图像，以便包含在视频或动画 GIF 中（见下一段）。这就是控制主循环的变量被称为 `frame` 的原因。每次迭代时，椭圆的真实参数（你选择的那些）及其最小二乘估计值都会显示在屏幕上。

如果参数 `mode` ![Image](images/B9780443218576000059/fx008.jpg) 设为 `'ConfidenceRegion'`，则噪声量和所有椭圆参数在整个迭代过程中保持不变。拟合形状因训练集（而训练集取决于噪声）而异，从而为给定噪声量的特定椭圆创建置信区域。新的拟合椭圆不断添加到图像中而不擦除旧的，以显示正在构建的置信区域。高离心率椭圆会导致置信区域产生偏差。用于构建置信区域的方法称为**参数自助法** [[Wiki](https://en.wikipedia.org/wiki/Bootstrapping_\(statistics\)#Parametric_bootstrap)]。

相反，如果 `mode` 设为 `'FittingCurves'`，则每次迭代都会生成一条具有不同参数和不同噪声量的椭圆，在新图像中擦除前一条。在这种情况下的目的是评估拟合质量，取决于噪声量和椭圆形状（特别是离心率以及是使用完整弧还是部分弧进行训练）。

#### 创建视频和动画 GIF

在主循环的每次迭代中，程序在本地文件夹中创建并保存一张图像，图像包含红色（印刷版为浅灰色）的训练集（分布在真实椭圆弧周围的一团点）和蓝色（印刷版为深灰色）的拟合椭圆。图像名称为 `ellipsexxx.png`，其中 `xxx` 为当前帧号。在最后一次迭代（视频中的最后一帧），真实椭圆——即主循环中设置参数所对应的椭圆——会以黑色添加到图像中：这使你能够在选择选项 `mode='ConfidenceRegion'` 时评估偏差。
