In the same tab, you will find the computation of the weight function, the weighted centroid, and the computations related to the new coordinate system `ρ[t]`, `φ[t]`![Image](images/B9780443218576000102/si29.png).

My simulations rely on synthetic data [[Wiki](https://en.wikipedia.org/wiki/Synthetic_data)]. In other words, I use mathematically-generated shapes. The benefit is that you can generate a large class of shapes (actually, infinitely many), mimicking any existing shape, and compare the performance of various shape classifiers. In particular, you can assess how well a specific metric can detect different, yet very similar shapes, or how it performs when various levels of noise are introduced. Modern methods combine real observations with synthetic data to further enrich training sets. This is known as **augmented data** [[Wiki](https://en.wikipedia.org/wiki/Data_augmentation)].

Several other machine learning techniques, tested on synthetic data and accompanied by professional summary spreadsheets, are available (along with the data sets and source code), in my book “Stochastic Processes and Simulations: A Machine Learning Perspective”. Many are described in Chapter [16](#Chp016_293-327_B9780443218576000205.xhtml).

### Exercise 6.1

Find the weight function satisfying `Δ(w[t]x[t]) = Δ(w[t]y[t])`![Image](images/B9780443218576000102/si75.png). This is related to the material presented in Section [6.3.1](#Chp006_103-111_B9780443218576000102.xhtml#s0025). It uses the same notations.

#### Solution

You need to find `w[t]`![Image](images/B9780443218576000102/si21.png) satisfying `x[t]Δw[t] + w[t]Δx[t] = y[t]Δw[t] + w[t]Δy[t]`![Image](images/B9780443218576000102/si76.png). Dividing by `Δt`, and letting `Δt → 0`![Image](images/B9780443218576000102/si77.png), we get

$$
x_{t}\frac{dw_{t}}{dt} + w_{t}\frac{dx_{t}}{dt} = y_{t}\frac{dw_{t}}{dt} + w_{t}\frac{dy_{t}}{dt},
$$

![Image](images/B9780443218576000102/si78.png)

that is,

$$
(x_{t} - y_{t})\frac{dw_{t}}{dt} = \left( \frac{dy_{t}}{dt} - \frac{dx_{t}}{dt} \right)w_{t}.
$$

![Image](images/B9780443218576000102/si79.png)

This is successively equivalent to

$$
\frac{d}{dt}(\log w_{t}) = \frac{1}{w_{t}}\frac{dw_{t}}{dt} = \frac{1}{x_{t} - y_{t}}\left( \frac{dy_{t}}{dt} - \frac{dx_{t}}{dt} \right),\log w_{t} = \int\frac{1}{x_{t} - y_{t}}\left( \frac{dy_{t}}{dt} - \frac{dx_{t}}{dt} \right)dt + C,w_{t} = C^{\prime}\exp\left\lbrack - \int_{0}^{t}\frac{1}{y_{\tau} - x_{\tau}}\left( \frac{dy_{\tau}}{d\tau} - \frac{dx_{\tau}}{d\tau} \right)d\tau \right\rbrack,
$$

![Image](images/B9780443218576000102/si80.png)

where `C`, `C'`![Image](images/B9780443218576000102/si81.png) are constants, with `C' > 0`![Image](images/B9780443218576000102/si82.png). The value of `C'`![Image](images/B9780443218576000102/si83.png) is unimportant when using formula [(6.2)](#Chp006_103-111_B9780443218576000102.xhtml#deq4). However, you can choose it so that the weight function integrates to one. Or you can use `C' = 1`![Image](images/B9780443218576000102/si84.png). I assumed, without loss of generality, that the integration domain `T` is an interval containing the origin `τ = 0`![Image](images/B9780443218576000102/si85.png).

You can test this formula on a line segment, defined by `x[t] = t`![Image](images/B9780443218576000102/si86.png), `y[t] = a + bt`![Image](images/B9780443218576000102/si87.png), with `t ∈ [0, 1]`![Image](images/B9780443218576000102/si88.png). This is the most basic shape other than a finite set of points! A slightly more difficult exercise is to find the weight function satisfying `|Δ(w[t]x[t])| = |Δ(w[t]y[t])|`![Image](images/B9780443218576000102/si89.png). [Exercise 6.1](#Chp006_103-111_B9780443218576000102.xhtml#enun0010) is a starting point to solve this problem.
