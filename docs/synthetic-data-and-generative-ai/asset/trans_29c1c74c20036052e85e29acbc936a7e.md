
## 18.4 特征工程

### 特征组合与分箱

最后，您可以一次添加两三个特征，而不是只添加一个。有时，组合特征比孤立特征具有更强的预测能力。例如，如果特征 `A` 是国家，取值为 {USA, UK}![Image](images/B9780443218576000229/si82.png)，特征 `B` 是一天中的小时，取值为 {“Day - Pacific Time”, “Night - Pacific Time”}![Image](images/B9780443218576000229/si83.png)，那么这两个特征单独使用时预测能力都很弱。但当您将它们结合时，会得到一个强得多的特征：如果您的响应（即您要预测的目标）是美国的互联网流量质量，则“UK/Night”表现好，“USA/Night”表现差，“UK/Day”表现差，而“USA/Day”表现好。同时使用这两个特征还能降低假阳性和假阴性的风险。

此外，为避免特征过于细粒度，应使用特征分箱。因此，不要将国家作为特征 `A`（有 200 个潜在国家值），而应使用国家组，包含 3 个国家列表（高风险、低风险、中性）。这些组别会随时间变化。同样，不要将（例如）“IP 地址”作为特征 `B`（有数十亿个潜在值），而应使用 IP 地址类型，包含 6 或 7 种类型，其中一种例如是“IP 地址在某白名单中”。

### 18.4.1 交叉验证的工作原理

我通过两个特征的子集来说明预测能力的概念。假设您有两个二元特征 `A` 和 `B`，取值为 0 或 1。此外，在欺诈检测的背景下，通常假设 `training set`（训练集）中的每个观测值要么是 Good（无欺诈），要么是 Bad（欺诈）。欺诈状态（`G` 或 `B`）在统计学中称为响应变量或因变量。特征 `A` 和 `B` 也称为规则或自变量。

交叉验证的工作原理如下。首先，将您的 `training set`（即已知响应 `B` 或 `G` 的数据）分成两部分：`validation set`（验证集）和 `training data`（训练数据）。确保两部分都数据丰富：如果 `validation set` 很大（数百万观测值）但只包含 200 个客户中的一两个，则它是数据贫乏的，当处理 `training set` 之外的数据时，您的统计推断将受到负面影响（鲁棒性低）。使用两个不同时间段分别用于训练和验证是个好主意。您将在 `training data` 上计算 `predictive power`（预测能力，包括规则选择）。当您确定了最终的最优特征子集后，再在 `validation set` 上计算 `predictive power`。如果 `validation set` 上的 `predictive power` 显著下降（与 `training data` 相比），说明您的分析有问题：找出问题，修复它，重新开始。您可以使用多个 `validation` 和 `training sets`：这能让您了解 `predictive power` 在不同 `validation set` 间的变化情况。方差过大是一个应当解决的问题。

### 18.4.2 测量特征的预测能力

标准方法基于经典的拟合优度指标 [[Wiki](https://en.wikipedia.org/wiki/Goodness_of_fit)]，例如在 `confusion matrix`（混淆矩阵）[[Wiki](https://en.wikipedia.org/wiki/Confusion_matrix)] 上计算的各种比率。相关示例在该维基百科文章中有讨论，包括假阳性率和假阴性率。这里我描述一种计算 `predictive power` 的原创方法。使用上述具有两个取值 0、1 的二元特征 `A`、`B`![Image](images/B9780443218576000229/si84.png) 的示例，我们可以将控制数据集的观测值分成 8 个分箱。设 `n[1]`、`n[2]`、…、`n[8]`![Image](images/B9780443218576000229/si85.png) 为 [表 18.2](#Chp018_361-386_B9780443218576000229.xhtml#t0015) 中所示这 8 个分箱中每个分箱的观测值数量。

[表 18.2](#Chp018_361-386_B9780443218576000229.xhtml#cf0150)

八个分箱：2 个特征（`A`、`B`）乘以 2 种结果（Good/Bad）。

| 分箱 | 特征 `A` | 特征 `B` | 响应 |
| --- | --- | --- | --- |
| 1 | 0 | 0 | G |
| 2 | 0 | 1 | G |
| 3 | 1 | 0 | G |
| 4 | 1 | 1 | G |
| 5 | 0 | 0 | B |
| 6 | 0 | 1 | B |
| 7 | 1 | 0 | B |
| 8 | 1 | 1 | B |

![Image](images/B9780443218576000229/t0015.png)

现在让我们引入以下量：

```math
P_{00} = \frac{n_{5}}{n_{1} + n_{5}},\quad P_{01} = \frac{n_{6}}{n_{2} + n_{6}},\quad P_{10} = \frac{n_{7}}{n_{3} + n_{7}},\quad P_{11} = \frac{n_{8}}{n_{4} + n_{8}},\quad p = \frac{n_{5} + n_{6} + n_{7} + n_{8}}{n_{1} + n_{2} + \cdots + n_{8}}.
```

![Image](images/B9780443218576000229/si86.png)

假设 `p` 衡量整体欺诈比例，小于 50%（即 `p` < 0.5![Image](images/B9780443218576000229/si87.png)，否则我们可以互换欺诈和非欺诈）。对于任意 0 < `r` < 1![Image](images/B9780443218576000229/si88.png)，定义 `W` 函数（形状像 W），基于参数 0 < `a` < 1![Image](images/B9780443218576000229/si89.png)（通常 `a` = 0.5 − `p`![Image](images/B9780443218576000229/si90.png)），定义如下：

```math
W(r) = \begin{cases} 
1 - r/p, & \text{if } 0 < r < p, \\
a(r - p)/(0.5 - p), & \text{if } p < r < 0.5, \\
a(r - 1 + p)/(p - 0.5), & \text{if } 0.5 < r < 1 - p, \\
(r - 1 + p)/p, & \text{if } 1 - p < r < 1.
\end{cases}
```

![Image](images/B9780443218576000229/si91.png)

通常，`r` = `P[00]`、`P[01]`、`P[10]`![Image](images/B9780443218576000229/si92.png) 或 `P[11]`![Image](images/B9780443218576000229/si93.png)。函数 `W` 具有以下性质：

*   当 `r` = `p`![Image](images/B9780443218576000229/si94.png) 或 `r` = 1 − `p`![Image](images/B9780443218576000229/si95.png) 时，它取最小值 0，即当 `r` 不提供任何关于欺诈/非欺诈的信息时。
*   当 `r` = 1![Image](images/B9780443218576000229/si96.png) 或 `r` = 0![Image](images/B9780443218576000229/si97.png) 时，它取最大值 1，即在给定分箱中我们实现了欺诈与非欺诈的完美区分时。
*   它是对称的：如果 0 < `r` < 1![Image](images/B9780443218576000229/si88.png)，则 `W(r)` = `W(1 - r)`![Image](images/B9780443218576000229/si98.png)。因此如果您互换 Good 和 Bad（`G` 和 `B`），它仍提供相同的预测能力。

现在让我们定义 `predictive power` 为

```math
H = P[00]W(P[00]) + P[01]W(P[01]) + P[10]W(P[10]) + P[11]W(P[11]).
```

![Image](images/B9780443218576000229/si99.png)

函数 `H` 是特征子集 {`A`, `B`}![Image](images/B9780443218576000229/si100.png) 的 `predictive power`，包含四个分箱“00”、“01”、“10”、“11”，分别对应（`A` = 0, `B` = 0）![Image](images/B9780443218576000229/si101.png)、（`A` = 0, `B` = 1）![Image](images/B9780443218576000229/si102.png）、（`A` = 1, `B` = 0）![Image](images/B9780443218576000229/si103.png）、（`A` = 1, `B` = 1）![Image](images/B9780443218576000229/si104.png)。虽然 `H` 与 `entropy metric`（熵指标）有远亲关系，但它有自己的特定性质。与熵不同，`H` 不基于物理概念或模型；它实际上是一个 `synthetic metric`（综合指标）。
