
Primes satisfying `p mod 4 = 3` seem to be more numerous than the others, at least the smaller ones: they get a good head start. This is known as **Chebyshev's bias** [[Wiki](https://en.wikipedia.org/wiki/Chebyshev%27s_bias)]. If these two types of primes are not evenly distributed, the orbit could get arbitrarily close to the origin. However, thanks to **Dirichlet's theorem** [[Wiki](https://en.wikipedia.org/wiki/Dirichlet%27s_theorem_on_arithmetic_progressions)], we know that the distribution is even. Thus one would expect that the Euler product in formulas [(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5) and [(17.6)](#Chp017_329-360_B9780443218576000217.xhtml#deq7) would alternate nicely between `χ[4](p) = +1` and `χ[4](p) = −1` on average, thus converging for some `σ = σ[0]` smaller than 1, and thus for all `σ > σ[0]`. This is in contrast to the product in formula [(17.1)](#Chp017_329-360_B9780443218576000217.xhtml#deq2), corresponding to the principal character `χ(p) = 1` for all `p`, denoted as `χ[4,0]` and converging only for `σ > 1`.

Having no root if `σ[0] < σ < 1` due to the nonvanishing product in formula [(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5), one would conclude that the orbit of `L[P](z, χ[4])` never crosses the X-axis if `σ[0] < σ < 1`. However, to this day, nobody knows if the smallest possible value of `σ[0]`, called the **abscissa of absolute convergence** [[Wiki](https://en.wikipedia.org/wiki/General_Dirichlet_series)], is less than 1. It is conjectured to be as low as 0.5, or lower. This is part of the **Generalized Riemann Hypothesis** [[Wiki](https://en.wikipedia.org/wiki/Generalized_Riemann_hypothesis)], an active research topic in number theory. Yet, the associated series `L[P](z, χ[4])` defined in formula [(17.5)](#Chp017_329-360_B9780443218576000217.xhtml#deq6) is **conditionally convergent** [[Wiki](https://en.wikipedia.org/wiki/Conditional_convergence)] if `σ > 0`, see Example 2.39, page 36, in [[4]](#Chp017_329-360_B9780443218576000217.xhtml#br0020).

For a reference focusing on completely multiple functions `χ` in the RH context, not just Dirichlet characters, see [[1]](#Chp017_329-360_B9780443218576000217.xhtml#br0005). Finally, I discuss `χ[4]` in more details in Section [17.3.2.3](#Chp017_329-360_B9780443218576000217.xhtml#s0085). In particular, I show the big contrast between `L[P](z, χ[4,1])` and the standard Riemann zeta function `ζ(z)` corresponding to `L[P](z, χ[4,0])`.

#### 17.2.2.1 Special products

Again, I investigate the infinite product `L[P](z, χ)` in formula [(17.6)](#Chp017_329-360_B9780443218576000217.xhtml#deq7), with `z = σ + it`. If for some `0 < σ[0] < 1`, the set `P` contains infinitely many primes, but sufficiently spaced out so that

```
ρ = ∏_{p ∈ P} 1/(1 + p^{-σ₀}) > 0,
```

then the orbit of `L[P](z, χ)` corresponding to `σ = σ[0]` will stay away from the origin, at a distance `≥ ρ` at all times. This is true regardless of the function `χ`. In particular, it means that `L[P](z, χ)` has no root if `σ = σ[0]`.

Now, if `P` is the set of all primes, `χ(p) = 1` for all primes (the standard case) and `σ = 0.5`, then `η[P](z, χ)`, defined in formula [(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5), has infinitely many roots. In addition, if its orbit gets too close to the origin, it gets attracted to it, otherwise it gets deflected: the origin seems to have an event horizon similar to that of a black hole. If you get too close, there is no way out, you will hit the origin very fast. See the blue curve in [Fig. 17.2](#Chp017_329-360_B9780443218576000217.xhtml#f0015), where the X-axis represents the time `t`, and the Y-axis the distance to the location `(c,0)` in the complex plane. For the blue curve, `c = 0`. Note that as long as `0.5 < σ < 1` and `0 < t < T` with `T` finite, the (finite) portion of the orbit exhibits a hole. But the hole shrinks very slowly to a single point, as `T → ∞`. If `σ < 1`, the hole encompasses the origin at all times. But its actual center is located further to the right on the X-axis. See Figs. [17.2](#Chp017_329-360_B9780443218576000217.xhtml#f0015), [17.3](#Chp017_329-360_B9780443218576000217.xhtml#f0020), and [17.4](#Chp017_329-360_B9780443218576000217.xhtml#f0025): each curve represents a distance to a specific location `(c,0)`. The center moves to the left as `T` increases, or as `σ` decreases and gets closer to 0.5, until it merges with the origin. If `σ > 1`, the hole may not contain the origin, but the orbit is bounded and the origin is outside the external boundary of the orbit: see the yellow orbit in [Fig. 17.1](#Chp017_329-360_B9780443218576000217.xhtml#f0010).
