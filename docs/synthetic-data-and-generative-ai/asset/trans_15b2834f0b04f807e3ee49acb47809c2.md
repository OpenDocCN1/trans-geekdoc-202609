请注意，我的方法不涉及任何统计模型。但仍可使用自助法技术计算插值的各种置信区间或预测区间。这在我的文章、著作以及相关文献中均有详细讨论。关于用于预测海洋潮汐的参数模型，请参见第 [1.3.3](#Chp001_1-34_B9780443218576000059.xhtml) 节。

## 练习 9.1

### 行星何时排列？

我们首先创建一个包含地球与金星每日距离测量值的数据集，并对距离进行插值，以测试良好性能所需的最少数据量：能否从月度观测中重建每日数据？季度或年度观测呢？然后，目的是评估一类特定模型不仅擅长综合此类数据，同时还擅长综合其他类型数据集，如[图 9.2](#Chp009_147-168_B9780443218576000138.xhtml#f0015)中的海洋潮汐或[图 9.1](#Chp009_147-168_B9780443218576000138.xhtml#f0010)中的黎曼 ζ 函数。

NASA 发布的行星事实表包含所需的所有信息。可在[此处](https://nssdc.gsfc.nasa.gov/planetary/factsheet/)获取。我选择金星和地球，是因为它们是太阳系中轨道离心率最低的行星之一。为简化起见，假设两者轨道均为圆形。还假设在记为 `t = 0` 的时刻，太阳、金星和地球排成一线且位于同侧（金星位于地球和太阳之间）。

请注意，所有主要行星绕太阳公转方向相同。设 `θ[V]`、`θ[E]`、`R[V]`、`R[E]` 分别为金星和地球的公转周期，以及金星和地球到太阳的距离。根据 NASA 表格，这些数值分别为 224.7 天、365.2 天、`108.2 × 10⁶` 公里和 `149.6 × 10⁶` 公里。设 `d[V](t)` 为时刻 `t` 地球与金星之间的距离。首先需将公转周期转换为角速度 `ω[V] = 2π/θ[V]` 和 `ω[E] = 2π/θ[E]`（单位：每天）。然后基本三角学可得公式

```
d_V^2(t) = R_E^2 [ 1 + (R_V/R_E)^2 - 2(R_V/R_E)cos((ω_V - ω_E)t) ]
```
(9.4)

因此距离是周期性的，当 `(ω[V] − ω[E])t` 是 `2π` 的整数倍时，距离最小，等于 `R[E] − R[V]`。这大约每 584 天发生一次。

### 完成步骤

练习包含以下步骤：

*   **步骤 1**：使用公式 [(9.4)](#Chp009_147-168_B9780443218576000138.xhtml#deq5) 生成连续 10 年（从 `t = 0` 开始）的 `d[V](t)` 每日值。

*   **步骤 2**：使用第 [9.3.1](#Chp009_147-168_B9780443218576000138.xhtml#s0060) 节中的 Python 代码处理你的数据。利用每 30 个观测值中的 1 个进行每日数据插值。判断每月一次测量是否足以重建每日观测。观察需要多少节点（代码中的变量 `n`）才能获得良好的插值效果。

*   **步骤 3**：加入火星。当 `(ω[V] − ω[E])t` 和 `(ω[M] − ω[E])t` 均近似为 `2π` 的整数倍时，三颗行星（金星、地球、火星）与太阳排成一线且位于同侧，即地火距离 `d[M](t)` 和地金距离 `d[V](t)` 均达到最小值。简而言之，当 `g(t) = d[V](t) + d[M](t)` 取最小值时发生排列。假设在 `t = 0` 时发生。绘制函数 `g(t)` 的图像，时间跨度需足够长以观察到全局最小值（即对应排列）。此处 `ω[M]` 为火星角速度，其轨道近似为圆形。

*   **步骤 4**：重复步骤 1 和 2，但这次针对 `g(t)`。与 `d[V](t)` 不同，函数 `g(t)` 非周期性。或者改用木星代替金星，因为这会导致夜空中肉眼可见的排列现象：两颗行星的视位置重合。

*   **步骤 5**：此类时间序列的一个可能通用模型为

```
f(t) = Σ_{k=1}^m A_k sin(θ_k t + φ_k) + Σ_{k=1}^m A'_k cos(θ'_k t + φ'_k)
```
(9.5)

其中 `A[k]`、`A'[k]`、`θ[k]`、`θ'[k]`、`φ[k]`、`φ'[k]` 为参数，分别代表振幅、频率和相位。证明该参数配置是冗余的：可通过设定 `φ[k] = φ'[k] = 0` 并重新参数化，在保持完整建模能力的同时简化模型。提示：使用角和公式（自行搜索）。
