

即使 `p[k]`（以及因此而来的 `q[k]`）不是整数，如第 [17.3.4](#Chp017_329-360_B9780443218576000217.xhtml#s0100) 节所示，这种表示法依然有效。我们也可以使用与公式 [(17.5)](#Chp017_329-360_B9780443218576000217.xhtml#deq6) 相同的机制来定义 `η[P](z, x, ν)`；当 `x → 1` 时，它可能提供解析延拓。

## 示例

假设 `P` 是所有素数整数的集合，有趣的例子包括：

- 若 `ν(p) = 1` 且 `x = 1`，则 `L[P](z, x, ν) = ζ(z)`，即**黎曼 ζ 函数** [[Wiki](https://en.wikipedia.org/wiki/Riemann_zeta_function)]。若 `ν(p) = 1` 且 `x = -1`，则 `L[P](z, x, ν) = ζ(2z)/ζ(z)`。若 `ν(p) = log p` 且 `0 < x ≤ 1`，则 `L[P](z, x, ν) = ζ(z - log x)`。若 `ν(p) = p` 且 `-1 < x < 1`，则当 `σ ≥ 0` 时具有绝对收敛性。此外，公式 [(17.12)](#Chp017_329-360_B9780443218576000217.xhtml#deq17) 中的级数是关于 `x` 的泰勒级数，也是关于 `z` 的狄利克雷级数。该函数没有零点，但确实有**极点** [[Wiki](https://en.wikipedia.org/wiki/Zeros_and_poles)]。此外，`lim[x → 1] L[P](z, x, ν) = ζ(z)`。

- 令 `x = -1` 且 `ν(p) = 2d(π(p), α) - 1`，其中 `π(·)` 是**素数计数函数** [[Wiki](https://en.wikipedia.org/wiki/Prime-counting_function)]，`d(k, α)` 是实数 `0 < α < 1` 的第 `k` 个二进制数字。选择 `α` 使其二进制数字足够随机，表现得像无限次公平的抛硬币游戏。凭借**格利文科-坎泰利定理** [[Wiki](https://en.wikipedia.org/wiki/Glivenko%E2%80%93Cantelli_theorem)]，这些数字的**经验分布** [[Wiki](https://en.wikipedia.org/wiki/Empirical_distribution_function)] 收敛于第 [17.3.5](#Chp017_329-360_B9780443218576000217.xhtml#s0105) 节所述过程的潜在理论分布。特别地，若 `σ > 0.5`，则乘积收敛且无零点。因此，在这种情况下验证了**广义黎曼假设** [[Wiki](https://en.wikipedia.org/wiki/Generalized_Riemann_hypothesis)]（简称 GRH）。你仍需找到某个有效的 `α`，例如某个符合要求的**正规数** [[Wiki](https://en.wikipedia.org/wiki/Normal_number)]。当然，`$\alpha = \sqrt{2}/2$` 是一个极佳的候选者，但没人知道它是否为正规数，尽管它成功通过了迄今设计的所有统计检验。

- 在上一个例子中，若 `α = 2/3`，尽管缺乏随机性，GRH 依然成立：数字在 0 和 1 之间完美交替。但 `p[2k]^(-σ) - p[2k+1]^(-σ) → 0` 随 `k → ∞` 足够快（见[此处](https://mathoverflow.net/questions/159534/does-this-alternating-euler-product-converge-for-all-res-0)），因此若 `σ > 0.5` 乘积收敛，从而没有零点。现在，按如下方式定义 `α`：第一个数字为零；若 `p ≡ 1 mod 4` 则 `d(π(p), α) = 1`，若 `p ≡ 3 mod 4` 则 `d(π(p), α) = 0`。则 `L[P](z, x, ν) = L(z, χ[4])`，其中 `χ[4]` 是模 4 的非平凡**狄利克雷特征**。这些数字具有有限的随机性；得益于**狄利克雷定理** [[Wiki](https://en.wikipedia.org/wiki/Dirichlet%27s_theorem_on_arithmetic_progressions)]，零/一的比例为 50/50，且这个**狄利克雷-L 函数** [[Wiki](https://en.wikipedia.org/wiki/Dirichlet_L-function)] 享有许多有趣的性质。若其乘积在 `σ > 0.5` 时收敛（无人知晓），则 `L(z, χ[4])` 也将满足 GRH。数字的非随机性（这本身并不排除 GRH）是由 `χ[4](·)` 完全乘性且周期性引起的。特别地，若 `p` 为素数，则 `χ[4](p²) = 1`，从而 `d(π(p²), α) = 1`。

- 令 `ν(p) = 1/p` 且 `0 < x ≤ 1`。当 `ν(p) = log p` 时，当 `x → 1` 时你以完全相同的方式逼近 `ζ`，就像在实轴上从 `σ > 0.5`（若 GRH 为真则无零点）向左移动到 `σ = 0.5`（有无限多个零点）一样。`ν(p) = 1/p` 的情况提供了不同的视角。此外，无论 `0 < x < 1`，`x^(1/p) → 1` 随 `p → ∞`。因此 `ν(p) = 1/p` 很有吸引力。例如，当 `x = 0.99` 且 `σ = 0.55` 时，`η[P](z, x, ν)` 的轨道在原点周围有一个小洞（若显示所有 `t > 0` 的完整轨道，它可能会收缩为一个单例，就像 `x = 1` 时那样）。轨道定期靠近原点然后再远离：这仅当 `t` 接近 `ζ` 的非平凡零点的虚部时发生。对于固定的 `σ` 值（如 0.5），将 `x` 从（如）0.4 增加到 0.8 会将洞向左移动，更靠近原点，这符合预期。当然，`lim[x → 1] L[P](z, x, ν) = ζ(z)`。例如，令 `$\sigma = \frac{1}{2}$`。则若 `x = 0.4`，轨道在 X 轴上以 `(0, 1)` 为中心有一个巨大的洞。若 `x = 0.8`，轨道在 X 轴上以 `$(0, \frac{1}{2})$` 为中心有一个巨大的洞。
