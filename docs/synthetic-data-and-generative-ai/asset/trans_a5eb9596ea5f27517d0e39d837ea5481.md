
其中 `a[1]`，…，`a[p]`![图片](images/B9780443218576000163/si125.png) 是满足某些条件以保证**平稳性**的实系数。根据选择，序列 `{e[n]}`![图片](images/B9780443218576000163/si126.png) 是**白噪声**：`E[e[n]]` = 0![图片](images/B9780443218576000163/si127.png)，`Var[e[n]]` = `σ`²![图片](images/B9780443218576000163/si128.png) 是固定的（不依赖于 `n`），且 `e[n]`![图片](images/B9780443218576000163/si129.png) 独立同分布。

该过程的行为，因此 [图 12.5](#Chp012_229-241_B9780443218576000163.xhtml#f0030) 中所示的布朗运动的行为，由其 `p` 次**特征多项式**的根决定。

```
x^p = a[1]*x^(p-1) + a[2]*x^(p-2) + … + a[p-1]*x + a[p]
```

![图片](images/B9780443218576000163/si130.png)

这些根可以是实数或复数，单根或多根。就平稳性而言，临界情况是模最大的根的**模**等于 1。如果该模大于 1，则过程不再平稳。实数 `a` 的模是其绝对值 `|a|`![图片](images/B9780443218576000163/si131.png)，而对于复数 `a + b*i`![图片](images/B9780443218576000163/si132.png)，其定义为 $\sqrt{a^{2} + b^{2}}$![图片](images/B9780443218576000163/si133.png)。此外，如果模最大的根是重根，则会发生异常情况：由此产生的布朗运动非常平滑，不再是布朗运动。它变成了积分布朗运动；其导数是布朗运动。请参见 [图 12.5](#Chp012_229-241_B9780443218576000163.xhtml#f0030) 左上角的图。同一图中的其他图对应于特征多项式根和由此产生的行为的其他特殊情况。这在第 [3](#Chp003_49-60_B9780443218576000072.xhtml) 章（线性代数）中有详细讨论。
