
The generalized `Omega function` [[Wiki](https://en.wikipedia.org/wiki/Prime_omega_function)] is defined as follows: if the prime factorization of `q[k]`![Image](images/B9780443218576000217/si43.png) is `q[k] = p[1]^(a[1]) p[2]^(a[2]) ⋯ p[d]^(a[d])`![Image](images/B9780443218576000217/si67.png), then `Ω(q[k]) = a[1]χ(p[1]) + ⋯ + a[d]χ(p[d])`![Image](images/B9780443218576000217/si68.png). The function `(-1)^(Ω(q[k]))`![Image](images/B9780443218576000217/si69.png) is denoted as `λ(q[k])`![Image](images/B9780443218576000217/si70.png) and referred to as the generalized `Liouville function` [[Wiki](https://en.wikipedia.org/wiki/Liouville_function)]. The series in formula [(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5) is called a `Dirichlet-L function` [[Wiki](https://en.wikipedia.org/wiki/Dirichlet_L-function)]. The function `χ` can be extended to all strictly positive integers as follows: `χ(1) = 1`![Image](images/B9780443218576000217/si6.png), `χ(p) = 0`![Image](images/B9780443218576000217/si71.png) if `p ∉ P`![Image](images/B9780443218576000217/si72.png), and `χ(ab) = χ(a)χ(b)`![Image](images/B9780443218576000217/si5.png). Then `χ(q[k]) = λ(q[k])`![Image](images/B9780443218576000217/si73.png) is a `completely multiplicative function` [[Wiki](https://en.wikipedia.org/wiki/Multiplicative_function)].

From now on, all functions denoted as `χ(⋅)`![Image](images/B9780443218576000217/si4.png) are assumed to be completely multiplicative, and thus uniquely characterized by the values they take on prime arguments. Now, let `L_P(z, χ) = (1 - 2^(1 - z))^(-1) η_P(z, χ)`![Image](images/B9780443218576000217/si74.png). Then we have:

$L\_{P}(z,\\chi) = \\sum\\limits\_{k = 1}^{\\infty}\\chi(k)k^{- z},\\quad\\eta\_{P}(z,\\chi) = (1 - 2^{1 - z})L\_{P}(z,\\chi) = \\sum\\limits\_{k = 1}^{\\infty}{( - 1)}^{k + 1}\\chi(k)k^{- z},$

![Image](images/B9780443218576000217/si75.png)(17.5) 

$L\_{P}(z,\\chi) = \\prod\\limits\_{p \\in P}\\frac{1}{1 - \\chi(p)p^{- z}},\\quad|L\_{P}(z,\\chi)| = \\prod\\limits\_{p \\in P}|1 - \\chi(p)p^{- z}|^{- 1} \\geqslant \\prod\\limits\_{p \\in P}\\frac{1}{1 + p^{- \\sigma}}.$

![Image](images/B9780443218576000217/si76.png)(17.6) 

If for a fixed integer `m > 1`![Image](images/B9780443218576000217/si77.png) we have `χ(p) = χ(q)`![Image](images/B9780443218576000217/si78.png) whenever `p, q ∈ P`![Image](images/B9780443218576000217/si79.png) are two primes with `p ≡ q mod m`![Image](images/B9780443218576000217/si80.png), and if in addition `χ(p) = 0`![Image](images/B9780443218576000217/si71.png) if `p` divides `m`, then `χ(⋅)`![Image](images/B9780443218576000217/si4.png) is called a `Dirichlet character` modulo `m` [[Wiki](https://en.wikipedia.org/wiki/Dirichlet_character)]. The standard Omega and Liouville functions correspond to the case where `χ` is constant and equal to +1, and `P` is the set of all prime numbers. The standard Liouville function also satisfies

$\\sum\\limits\_{k = 1}^{n}\\lambda(k)\\left\\lfloor \\frac{n}{k} \\right\\rfloor = \\lfloor\\sqrt{n}\\rfloor,\\quad L(n) = \\sum\\limits\_{k = 1}^{n}\\lambda(k) = \\sum\\limits\_{k = 1}^{n}\\mu(k)\\left\\lfloor \\sqrt{\\frac{n}{k}} \\right\\rfloor,$

![Image](images/B9780443218576000217/si81.png)

where `μ(k)`![Image](images/B9780443218576000217/si82.png) is Liouville's sister function, called the `Möbius function` [[Wiki](https://en.wikipedia.org/wiki/M%C3%B6bius_function)]. See [here](https://mathoverflow.net/questions/393351/exact-formula-for-partial-sums-of-liouville-function-ln-oeis-sequence-a0028) for details. The brackets stand for the integer part function. The partial sums of the Liouville function are denoted as `L(n)`![Image](images/B9780443218576000217/si83.png), while the partial sums of the Möbius function are the `Mertens function` [[Wiki](https://en.wikipedia.org/wiki/Mertens_function)], and denoted as `M(n)`![Image](images/B9780443218576000217/si84.png). If `q = q[k] = p[1]^(a[1]) p[2]^(a[2]) ⋯ p[d]^(a[d])`![Image](images/B9780443218576000217/si85.png), then `μ(q[k]) = (-1)^(w(q[k]))`![Image](images/B9780443218576000217/si86.png), with `ω(q[k]) = χ(p[1]) + ⋯ + χ(p[d])`![Image](images/B9780443218576000217/si87.png). The standard Möbius function corresponds to the case where `χ` is a constant function equal to 1, and `P` is the set of all prime numbers.

Finally, formula [(17.3)](#Chp017_329-360_B9780443218576000217.xhtml#deq4), providing a lower bound for the distance between the origin and any point on the orbit of `η_P(z, χ)`![Image](images/B9780443218576000217/si88.png), is still applicable and remains unchanged. In particular, if `P` is the set of all primes (or a big enough, infinite subset), the lower bound is zero due to divergence of the product. If that lower bound is indeed reached, even if asymptotically only, then the hope to find a hole bigger than a singleton evaporates.

### 17.2.2 Infinite Euler products

If `P` is the set of all prime numbers, the products in formula [(17.1)](#Chp017_329-360_B9780443218576000217.xhtml#deq2), [(17.3)](#Chp017_329-360_B9780443218576000217.xhtml#deq4), and [(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5) become infinite. As a result, if `0.5 ≤ σ < 1`![Image](images/B9780443218576000217/si89.png), the holes in the orbit in [Fig. 17.1](#Chp017_329-360_B9780443218576000217.xhtml#f0010) may shrink to an empty set (`σ = 0.5`![Image](images/B9780443218576000217/si53.png)) or a single point – the origin – if `0.5 < σ < 1`![Image](images/B9780443218576000217/si90.png). Actually, it may well be an empty set too in the latter case; nobody knows. But the Riemann hypothesis states that it should be a single point. This is the situation if `χ` is a constant function equal to 1. This function is called `principal character` in this context. But what happens if `χ` is not a constant? In this latter case, depending on `χ`, the orbit may never get too close to the origin.

Let us consider the `completely multiplicative` function `χ` called nontrivial `Dirichlet character modulo 4`, and denoted as `χ[4]`![Image](images/B9780443218576000217/si1.png) or `χ[4, 1]`![Image](images/B9780443218576000217/si91.png). It is uniquely characterized by its values on prime numbers `p`, as follows: `χ[4](p) = +1`![Image](images/B9780443218576000217/si92.png) if `p mod 4 = 1`![Image](images/B9780443218576000217/si93.png), `χ[4](p) = -1`![Image](images/B9780443218576000217/si94.png) if `p mod 4 = 3`![Image](images/B9780443218576000217/si95.png), and `χ[4](2) = 0`![Image](images/B9780443218576000217/si96.png). It satisfies `χ[4](k + 4) = χ(k)`![Image](images/B9780443218576000217/si97.png) for all positive integers. Again, `P` is the set of all primes.
