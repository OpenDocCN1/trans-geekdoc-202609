
*   **类型 3**：当存在模等于 1 的复根时，一种高度振荡的时间序列，它填满了一个稠密区域。

在[图 3.1](#Chp003_49-60_B9780443218576000072.xhtml#f0010)中，我重新缩放了横轴和纵轴，使时间序列看起来是时间连续的。经过这种变换，`Type 2` 实际上对应于一维**布朗运动** [[Wiki](https://en.wikipedia.org/wiki/Brownian_motion)]。`Type 3` 具有一条曲线，其**分形维数** [[Wiki](https://en.wikipedia.org/wiki/Fractal_dimension)] 严格介于 1 和 2 之间。`Type 1` 看起来非常平滑。它似乎在任何地方都具有任意阶导数。因此它不可能是布朗运动。然而，如果你放大或缩小，相同的统计特性（平滑度、预期峰值数量等）会重复出现。这意味着我们正在处理一种奇怪的数学函数：一种无法用泰勒级数逼近，却同时非常平滑、混沌且具有自复制特性的函数。此外，我们需要记住它是一个**随机函数**。

![图 3.1 基于特征多项式根的类型分类的 AR 模型。](images/B9780443218576000072/gr001.jpg)

图 3.1 基于特征多项式根的类型分类的 AR 模型。

时间序列的平滑度通常使用其**赫斯特指数** [[Wiki](https://en.wikipedia.org/wiki/Hurst_exponent)] 来度量。极端、最混沌的情况是白噪声，“中间情况”是布朗运动。这里 `Type 3` 似乎比白噪声更极端，而 `Type 1` 异常平滑。除 `Type 3` 外，这些时间序列的离散版本都具有长程自相关性。

### 3.4.1.1 白噪声：弗雷歇、韦伯和指数情况

我使用最简单的分布之一进行采样，以生成白噪声 `e[n]`![Image](images/B9780443218576000072/si45.png)。利用 `[0, 1]`![Image](images/B9780443218576000072/si78.png) 上的独立均匀离散值 `U[1]`、`U[2]`、…![Image](images/B9780443218576000072/si77.png)，我首先生成离散值

`v[n] = τ(-log(1-U[n]))^(γ), n = 1, 2, …`

![Image](images/B9780443218576000072/si79.png)(3.7)

然后噪声 `e[n]`![Image](images/B9780443218576000072/si80.png) 通过以下方式生成

`e[n] = v[n] - E[v[n]], with E[v[n]] = τΓ(1 + γ) and Var[e[n]] = Var[v[n]] = τ²[Γ(1+2γ) - Γ²(1+γ)]`

![Image](images/B9780443218576000072/si81.png)

这里 `τ`、`γ`![Image](images/B9780443218576000072/si82.png) 是参数，满足 `γ > -1/2`![Image](images/B9780443218576000072/si83.png)，而 `Γ` 是**伽马函数** [[Wiki](https://en.wikipedia.org/wiki/Gamma_function)]。我们有以下情况：

*   如果 `γ = 1`![Image](images/B9780443218576000072/si84.png)，则 `v[n]`![Image](images/B9780443218576000072/si85.png) 服从指数分布。
*   如果 `-1 < γ < 0`![Image](images/B9780443218576000072/si86.png)，则 `v[n]`![Image](images/B9780443218576000072/si85.png) 服从**弗雷歇分布**。如果此外还有 `γ > -1/2`![Image](images/B9780443218576000072/si83.png)，则其方差有限。
*   如果 `γ > 0`![Image](images/B9780443218576000072/si87.png)，则 `v[n]`![Image](images/B9780443218576000072/si85.png) 服从**韦伯分布**，方差有限。

令人惊讶的是，该分布根据 `γ < 0`![Image](images/B9780443218576000072/si88.png) 还是 `γ > 0`![Image](images/B9780443218576000072/si87.png) 而有不同的名称。该分布在我的随机过程书籍中有讨论 [[5, pages 41–42]](#Chp003_49-60_B9780443218576000072.xhtml#br0025)。
