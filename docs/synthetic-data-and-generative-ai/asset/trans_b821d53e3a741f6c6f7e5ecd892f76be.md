### 13.3.2 与泊松-二项分布的联系

取决于随机偏差序列 `U[b]`![图片](images/B9780443218576000175/si91.png)，新函数 `f[0]`![图片](images/B9780443218576000175/si20.png) 在任何特定区间 `[s, t]`![图片](images/B9780443218576000175/si92.png) 内可能有零个、一个或多个整数根。预期整数根的数量是一个服从**泊松-二项分布**的随机变量 `N(s, t)`![图片](images/B9780443218576000175/si93.png) [[维基](https://en.wikipedia.org/wiki/Poisson_binomial_distribution)]。假设 `s` 和 `t` 为整数，其期望、方差和无根的概率分别为

```latex
$E\lbrack N(s,t)\rbrack = \sum\limits_{k = s}^{t}\frac{1}{k},\quad{Var}\lbrack N(s,t)\rbrack = \sum\limits_{k = s}^{t}\frac{1}{k}\left( 1 - \frac{1}{k} \right),\quad P\lbrack N(s,t) = 0\rbrack = \prod\limits_{k = s}^{t}\left( 1 - \frac{1}{k} \right).$
```

![图片](images/B9780443218576000175/si94.png)

当 `s, t`![图片](images/B9780443218576000175/si95.png) 很大且 `t/s → λ`![图片](images/B9780443218576000175/si96.png) 时，泊松-二项分布可由期望为 `log λ`![图片](images/B9780443218576000175/si97.png) 的泊松分布很好地近似。这一高级结果的证明（甚至不在研究生课程中讲授）可参见我的随机过程著作 [[1]](#Chp013_243-258_B9780443218576000175.xhtml#br0005) 第 2.3.1 节。该结果推广了在某些假设下二项分布向泊松分布收敛的著名结论。它是**勒卡姆不等式**的一个特例 [[维基](https://en.wikipedia.org/wiki/Le_Cam's_theorem)]；另见 [[2]](#Chp013_243-258_B9780443218576000175.xhtml#br0010)。

将其应用于第 [13.2.2](#Chp013_243-258_B9780443218576000175.xhtml#s0030) 节的问题，其中 `f[0](b) = a mod b`![图片](images/B9780443218576000175/si68.png)，`b ∈ [2900, 3200]`![图片](images/B9780443218576000175/si98.png)，在该区间内找到至少一个根的概率约为 `1 - exp(-log λ) = 1 - 1/λ`![图片](images/B9780443218576000175/si99.png)。由于 `λ = t/s`![图片](images/B9780443218576000175/si100.png)，`s = 2900`![图片](images/B9780443218576000175/si101.png)，`t = 3200`![图片](images/B9780443218576000175/si102.png)，相关概率约为 9.4%。注意 `$t < \sqrt{a}$`![图片](images/B9780443218576000175/si103.png)。一般来说，该结果有效需要此条件。区间 `$[2, \sqrt{a}]$`![图片](images/B9780443218576000175/si104.png) 内无根意味着 `a` 是素数。

#### 13.3.2.1 下一个根的位置：估算

设 `T[s]`![图片](images/B9780443218576000175/si105.png) 为大于 `s` 的第一个根的位置。我关心比率 `R[s] = T[s]/s > 1`![图片](images/B9780443218576000175/si106.png)。根据前面的讨论，当 `s` 很大时，连续根的分布近似遵循**非齐次泊松过程**。很容易证明 `R[s]`![图片](images/B9780443218576000175/si107.png) 的期望是无限的。然而，`log R[s]`![图片](images/B9780443218576000175/si108.png) 的期望是有限的。让我们利用泊松近似来计算它。我们有

```latex
P(log R[s] > τ) = P[T[s] > s exp(τ)] = exp(-τ).
```

![图片](images/B9780443218576000175/si109.png)

因此，

```latex
E[log R[s]] = ∫[0]^∞ exp(-τ) dτ = 1.
```
