
## 15.3 碰撞图

### 15.3.1 恒星 47 的碰撞图

[图 15.1](#Chp015_277-292_B9780443218576000199.xhtml#f0010)中的**有向图**是使用 Python 的 `NetworkX` 库生成的。代码列在[15.5.2 节](#Chp015_277-292_B9780443218576000199.xhtml#s0065)中。粉色圆圈中的数字代表恒星 ID。附在每个箭头上的权重表示碰撞发生的时间帧。恒星 47 的最后一次碰撞发生在时间 `t` = 687![Image](images/B9780443218576000199/si1.png)（即视频帧 687，整个视频共 2000 帧）。注意碰撞链 509 ↦ 441 ↦ 81 ↦ 47![Image](images/B9780443218576000199/si2.png)，始于视频帧 9。恒星 47 最终质量为 59.21，而恒星 509 在被吞噬前质量为 2.90：经过所有碰撞后，质量增长了 20 倍！

![图 15.1 视频 7 中最大恒星吞噬者（恒星 47）的碰撞图。](images/B9780443218576000199/gr001.jpg)

图 15.1 视频 7 中最大恒星吞噬者（恒星 47）的碰撞图。

所有恒星的碰撞总数为 349。在创建时刻（`t` = 0![Image](images/B9780443218576000199/si3.png)）有 1000 颗恒星。碰撞导致的质量累积在早期发生得非常快，但迅速达到最大值。在这种情况下，恒星 47 成为碰撞次数最多、质量最大的恒星，因此选择它进行说明。还有其他几颗恒星经历了许多碰撞，尽管大多数恒星经历零次或一次碰撞。

检测所有碰撞图相当于检测整个图的所有**连通分量**[[Wiki](https://en.wikipedia.org/wiki/Component_(graph_theory))]。为此，我使用了[16.2.4.3 节](#Chp016_293-327_B9780443218576000205.xhtml)中描述的 `PB_NN_graph.py` 程序。相关 Python 代码也可在 GitHub 上获取，[此处](https://github.com/VincentGranville/Point-Processes/blob/main/Source%20Code/PB_NN_graph.py)。确保输入文件是对称的：如果 A, B 是碰撞之一（恒星 A 和 B 之间），也要在输入文件中包含 B, A。[图 15.1](#Chp015_277-292_B9780443218576000199.xhtml#f0010)中与恒星 47 相关的子图代表这些连通分量之一，即最大的一个。按大小排序的所有连通分量列表可在[此处](https://github.com/VincentGranville/Visualizations/blob/main/Source-Code/nbody_graph_principalComponents_set7.txt)找到，恒星 47 的合并序列位于顶部；每个分量中的每个数字代表一颗恒星。

有几种工具（如 `GraphViz` [[Wiki](https://en.wikipedia.org/wiki/Graphviz)]）可用于可视化[图 15.1](#Chp015_277-292_B9780443218576000199.xhtml#f0010)中显示的图类型。这里我使用了 Python 的 `NetworkX` 库 [[Wiki](https://en.wikipedia.org/wiki/NetworkX)]。然而，制作美观的可视化并非易事。绘图函数提供多种不同的布局，如[此处](https://www.python-graph-gallery.com/322-network-layout-possibilities)所示：谱布局、弹簧布局、随机布局或 `Fruchterman–Reingold` [[Wiki](https://en.wikipedia.org/wiki/Force-directed_graph_drawing)]。每种布局都为节点选择一些最优位置，但没有一种能产生良好的结果。最后，我手动计算了节点的位置，尽管该过程可以自动化。请注意，相关图实际上是一棵 `tree`（树）[[Wiki](https://en.wikipedia.org/wiki/Tree_(data_structure))]，以 47 为根节点。参见[此处](https://mathoverflow.net/questions/418727/solving-functional-equation-fxy-fxy-and-diophantine-equations/418735#418735)了解可视化此类图的替代方案。

### 15.3.2 有趣的发现：宇宙是如何开始的

[图 15.2](#Chp015_277-292_B9780443218576000199.xhtml#f0015) 展示了使用[表 15.2](#Chp015_277-292_B9780443218576000199.xhtml#t0015)中第七组参数时碰撞的行为。X 轴代表时间帧，每个时间实例对应一个特定的视频帧。左上图中的时间轴被截断，因为碰撞随时间变得非常罕见。在另外两幅图中，它不是线性刻度，而是向右压缩，原因相同。

![图 15.2 整个碰撞结构的汇总统计：X 轴代表时间。](images/B9780443218576000199/gr002.jpg)

图 15.2 整个碰撞结构的汇总统计：X 轴代表时间。

这种行为是标准宇宙的典型特征。特别是，虽然碰撞随时间变得罕见，但它们以波浪形式出现，每一新波浪的强度都比前一个弱，且连续波浪之间的间隔随时间增加。右上角的图显示了由于碰撞，恒星质量在开始时增长有多快，最大质量在不到 30 个视频帧内变为初始值的 6 倍。视频有 2000 帧：每秒 20 帧，因此持续 1 分 40 秒。所以 30 帧代表视频的前 1.5 秒。

[图 15.2](#Chp015_277-292_B9780443218576000199.xhtml#f0015)底部的图片展示了该过程的复杂性。Y 轴表示碰撞位置与全局恒星团不断演化的质心之间的距离，针对该时间帧内发生的所有碰撞。开始时，根据设计我们有三个恒星团，碰撞在每个团内部局部发生。碰撞发生在距离全局质心相对较远的地方，全局质心位于三个团之外。但很快，这三个团合并，因此到质心的距离发生变化，许多碰撞最终发生在新质心附近，那里正在形成更大的恒星。结果是平均到质心的距离减小。但过了一段时间后（约 54 个时间帧，即视频中的 3 秒钟不到），距离开始再次增加，因为宇宙在膨胀，许多碰撞不再发生在质心附近。

## 15.4 动画数据可视化

本节中的图片展示了使用[表 15.2](#Chp015_277-292_B9780443218576000199.xhtml#t0015)中的参数集生成的各种合成宇宙的快照。完整视频在 GitHub 上，[此处](https://github.com/VincentGranville/Visualizations/tree/main/Source-Code)。查找文件名以 `nbody` 开头的 MP4 文件。视频也在 YouTube 上，[此处](https://www.youtube.com/c/VincentGranvilleVideos/videos)。我测试的参数集在[15.2.3 节](#Chp015_277-292_B9780443218576000199.xhtml#s0030)中描述。

标准宇宙（`law=3` 的正恒星质量）的常见主题包括：膨胀减缓和恒星速度随时间降低、仅保持结合一段时间的双星、丝状结构、从中心位置高速弹射的流浪恒星、四处移动的小局部恒星团、整个系统的漂移，以及允许碰撞时随时间形成大质量恒星。另一个值得探讨的问题是，根据初始配置，是否存在主要的旋转方向（顺时针或逆时针）。换句话说，这些系统是否是**各向异性**的 [[Wiki]](https://en.wikipedia.org/wiki/Anisotropy)？
