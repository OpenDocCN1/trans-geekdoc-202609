## 13.2 不收敛的不动点算法

在本节中，我从公式 [(13.1)](#Chp013_243-258_B9780443218576000175.xhtml#deq1) 定义的函数 `f(b)`![Image](images/B9780443218576000175/si1.png) 开始。我在第 [13.3 节](#Chp013_243-258_B9780443218576000175.xhtml#s0040) 中研究一类更广泛的函数。诀窍在于大幅放大零点，产生涟漪效应，使不动点迭代能够利用这些效应缩小解的范围。最终，你不再关注收敛性（此处不存在），而是关注迭代 `n` = 1, 2![Image](images/B9780443218576000175/si17.png) 等步骤中信号 `ρ[n]`![Image](images/B9780443218576000175/si16.png) 的强度。`ρ[n]`![Image](images/B9780443218576000175/si16.png) 的值通常接近 1，但高值（高于 2）表明发生了异常情况。通常，当跨越一个根时会产生此类高值。

### 13.2.1 通向直观解法的技巧

假设 `f` 为正值且其最小值为零。如果 `f` 取负值，则用绝对值 `|f(b)|`![Image](images/B9780443218576000175/si18.png) 或平方 `f²(b)`![Image](images/B9780443218576000175/si19.png) 替换 `f(b)`![Image](images/B9780443218576000175/si1.png)。这在求根和优化问题中均适用。在优化中，`f` 是目标函数的导数。基础函数 `f`（或其绝对值或平方）记为 `f[0]`![Image](images/B9780443218576000175/si20.png)。

目标是应用连续变换，使函数 `f[0]`![Image](images/B9780443218576000175/si20.png) 更有利于根检测。第一步变换是取对数，从而在函数图像的任何根周围制造一个垂直的无底深渊。在实践中，实现方式如下：新函数简单地是

```
f[1](b) = max[log(f[0](b)), δ]
```

![Image](images/B9780443218576000175/si21.png)

其中 `δ` 是一个负数，其绝对值足够大。在 Python 代码中，`δ` 由 `logeps` 表示，设为 −10。该参数控制深渊的深度，使其有了底部。它有助于区分非常接近零的值和恰好等于零的值。例如，若 `f[0](b) = 0.01`![Image](images/B9780443218576000175/si22.png)，则 `f[1](b) = -4.61`![Image](images/B9780443218576000175/si23.png)；而若 `f[0](b) = 0`![Image](images/B9780443218576000175/si24.png)，则 `f[1](b) = -10`![Image](images/B9780443218576000175/si25.png)。

第二步是扩大深渊。其壁将从垂直变为倾斜。深渊的宽度及其壁的坡度由 Python 代码中的参数 `window` 控制，此处称为 `w`。简而言之，这一变换是应用于 `f[1]`![Image](images/B9780443218576000175/si26.png) 的**移动平均**。所得函数为

```
f_2(b) = (1/(2w + 1)) * sum_{k=-w}^{w} f_1(b + kh)
```

![Image](images/B9780443218576000175/si27.png)

增量 `h` 设为 1，因为在我的特定问题中这很合理。我未测试其他值。

第三步是线性变换，将 `f[2]`![Image](images/B9780443218576000175/si28.png) 转换为 `f[3]`![Image](images/B9780443218576000175/si29.png)，满足 `f[3](b) = p + q*f[2](b)`![Image](images/B9780443218576000175/si30.png)。参数 `p` 和 `q` 在 Python 代码中分别称为 `offset` 和 `slope`。函数 `f[0]`、`f[1]`![Image](images/B9780443218576000175/si31.png) 和 `f[3]`![Image](images/B9780443218576000175/si29.png) 在 Python 代码中分别称为 `fmod`、`fmod2` 和 `fresidue`。[图 13.3](#Chp013_243-258_B9780443218576000175.xhtml#f0020) 中的蓝曲线（印刷版为深灰色）是与 [图 13.1](#Chp013_243-258_B9780443218576000175.xhtml#f0010) 所示 `f[0]`![Image](images/B9780443218576000175/si20.png) 函数相关的 `f[3]`![Image](images/B9780443218576000175/si29.png) 变换，参数为 `p` = -100![Image](images/B9780443218576000175/si32.png) 和 `q` = 20![Image](images/B9780443218576000175/si33.png)。第 [13.4 节](#Chp013_243-258_B9780443218576000175.xhtml#s0070) 中讨论的后续变换仅用于美化，与不动点算法无关。

![图 13.3 变换后的函数 f3，放大了位于 b = 3083 处的根。](images/B9780443218576000175/gr003.jpg)
