
Linear regression problems can be solved using the `ordinary least squares` (OLS) method [[Wiki](https://en.wikipedia.org/wiki/Ordinary_least_squares)]. The framework involves a response `y`, a data set `X` consisting of `p` features or variables and `m` observations, and `p` regression coefficients (to be determined) stored in a vector `b`. In matrix notation, the problem consists of finding `b` that minimizes the distance `||y - Xb||`![Image](images/B9780443218576000072/si49.png) between `y` and `Xb`. Here `X` is an `m × p`![Image](images/B9780443218576000072/si50.png) matrix, and `y`, `b`![Image](images/B9780443218576000072/si51.png) are column vectors. The solution is

```
b = A^(-1) X^T y, with A = X^T X.
```

![Image](images/B9780443218576000072/si52.png)

The techniques discussed in Section [3.4.2](#Chp003_49-60_B9780443218576000072.xhtml#s0075) can be used to compute the inverse of `A` using formula [(3.4)](#Chp003_49-60_B9780443218576000072.xhtml#deq8) with `n = -1`![Image](images/B9780443218576000072/si2.png), either exactly using all the roots of its `characteristic polynomial`, or approximately using the 2–3 roots with the lowest moduli. You need to use the recursion [(3.8)](#Chp003_49-60_B9780443218576000072.xhtml#deq29) backward when implementing the methodology in Section [3.4.2](#Chp003_49-60_B9780443218576000072.xhtml#s0075), that is, for `n = -1, -2`![Image](images/B9780443218576000072/si53.png), and so on, rather than for `n = 1, 2`![Image](images/B9780443218576000072/si54.png), and so on.

If `A` is not invertible, the methodology described in Section [3.2.1](#Chp003_49-60_B9780443218576000072.xhtml#s0020) can be useful: it amounts to working with a pseudoinverse of `A`. Note that `A` is a `p × p`![Image](images/B9780443218576000072/si14.png) matrix as in Section [3.2](#Chp003_49-60_B9780443218576000072.xhtml#s0015). Questions regarding confidence intervals can be addressed using model-free techniques as discussed in Chapter [8](#Chp008_131-145_B9780443218576000126.xhtml).

## 3.4 Mathematics of autoregressive time series

Here I connect the dots between the autoregressive `time series` described in Section [3.3.2](#Chp003_49-60_B9780443218576000072.xhtml#s0045), and the material in Section [3.2](#Chp003_49-60_B9780443218576000072.xhtml#deq6). For the AR(`p`) process in Section [3.3.2](#Chp003_49-60_B9780443218576000072.xhtml#s0045), we have

```
$X_{n} = g(e_{p},e_{p + 1},\ldots,e_{n}) + \sum\limits_{k = 1}^{p}r_{k}^{n}q_{k},\quad\text{with~}\begin{pmatrix} q_{1} \\ q_{2} \\ \vdots \\ q_{p} \end{pmatrix} = V^{- 1}\begin{pmatrix} X_{0} \\ X_{1} \\ \vdots \\ X_{p - 1} \end{pmatrix},$
```

![Image](images/B9780443218576000072/si55.png)

where `V` is the same matrix as in formula [(3.4)](#Chp003_49-60_B9780443218576000072.xhtml#deq8), the `r[k]`![Image](images/B9780443218576000072/si56.png)'s are the roots (assumed distinct here) of the `characteristic polynomial` defined by [(3.5)](#Chp003_49-60_B9780443218576000072.xhtml#deq17), and `g` is a linear function of `e[p]`, `e[p+1]`, …, `e[n]`![Image](images/B9780443218576000072/si57.png). For instance, if `p = 1`![Image](images/B9780443218576000072/si58.png), we have

```
$g(e_{p},e_{p + 1},\ldots,e_{n}) = \sum\limits_{k = 0}^{n - p}a_{1}^{k}e_{n - k}.$
```

![Image](images/B9780443218576000072/si59.png)

This allows you to compute `Var[X[n]]`![Image](images/B9780443218576000072/si60.png) and `Cov[X[n], X[n-k]]`![Image](images/B9780443218576000072/si61.png), conditionally to `X[0]`, …, `X[p-1]`![Image](images/B9780443218576000072/si62.png). The limit, when `n` tends to infinity, allows you to compute the unconditional variance and autocorrelations attached to the process, in the stationary case. For instance, if `p = 1`![Image](images/B9780443218576000072/si58.png), we have

```
${Var}\lbrack X_{\infty}\rbrack = \lim\limits_{n\rightarrow\infty}\sum\limits_{k = 0}^{n - p}a_{1}^{2k}{Var}\lbrack e_{n - k}\rbrack = \sigma^{2}\sum\limits_{k = 0}^{\infty}a_{1}^{2k} = \frac{\sigma^{2}}{1 - a_{1}^{2}},$
```

![Image](images/B9780443218576000072/si63.png)

where `σ²` = `Var[e[0]]`![Image](images/B9780443218576000072/si64.png) is the variance of the white noise `{e[n]}`![Image](images/B9780443218576000072/si45.png), and `|a[1]| < 1`![Image](images/B9780443218576000072/si65.png) because we assumed stationarity. For the general case (any `p`), the formula, if `n` is larger than or equal to `p`, is

```
$g(e_{p},e_{p + 1},\ldots,e_{n}) = \sum\limits_{k = 0}^{n - p}\alpha_{k}e_{n - k},\text{~~}\text{with~}\alpha_{0} = 1,\text{~~}\alpha_{k} = \sum\limits_{t = 1}^{p}a_{t}\alpha_{k - t}\text{~~}\text{if~}k > 0,\text{~~}\alpha_{k} = 0\text{~~}\text{if~}k < 0.$
```

![Image](images/B9780443218576000072/si66.png)

In this case, we have

```
${Var}\lbrack X_{\infty}\rbrack = \sigma^{2}\sum\limits_{k = 0}^{\infty}\alpha_{k}^{2}.$
```

![Image](images/B9780443218576000072/si67.png)

The initial conditions for the coefficients `α[k]`![Image](images/B9780443218576000072/si68.png) correspond to `k = 0, -1, -2, …, -(p-1)`![Image](images/B9780443218576000072/si69.png). Thus `α[0] = 1`![Image](images/B9780443218576000072/si70.png), and the remaining `α[k]`![Image](images/B9780443218576000072/si68.png)'s (`k < 0`)![Image](images/B9780443218576000072/si71.png) are zero. Thus, the recurrence relation for `α[n]`![Image](images/B9780443218576000072/si72.png) can be solved using the same roots `r[1]`, …, `r[p]`![Image](images/B9780443218576000072/si73.png) solution of Eq. [(3.5)](#Chp003_49-60_B9780443218576000072.xhtml#deq17). Assuming the roots are distinct, we have

```
$\alpha_{n} = \sum\limits_{k = 1}^{p}r_{k}^{n}q_{k}^{\prime},\quad\text{with~}\begin{pmatrix} q_{1}^{\prime} \\ q_{2}^{\prime} \\ \vdots \\ q_{p}^{\prime} \end{pmatrix} = W^{- 1}\begin{pmatrix} 1 \\ 0 \\ \vdots \\ 0 \end{pmatrix},\quad\text{and~}W = \begin{pmatrix} {1\quad} & {1\quad} & {\cdots\quad} & 1 \\ {r_{1}^{- 1}\quad} & {r_{2}^{- 1}\quad} & {\ldots\quad} & r_{p}^{- 1} \\ {\vdots \quad} & {\vdots \quad} & {\ddots \quad} & \vdots \\ {r_{1}^{- (p - 1)}\quad} & {r_{2}^{- (p - 1)}\quad} & {\ldots\quad} & r_{p}^{- (p - 1)} \end{pmatrix}.$
```

![Image](images/B9780443218576000072/si74.png)(3.6)

Again, a direct computation of `W^(-1)`![Image](images/B9780443218576000072/si75.png) is numerically unstable, except in some special cases. Typically, a few of the `r[k]`![Image](images/B9780443218576000072/si56.png)'s are dominant. The others can be ignored, leading to approximations and increased stability. Finally, if two time series models, say an ARMA and an AR models, have the same variance and covariance structure, they are actually identical.

### 3.4.1 Simulations: curious fractal time series

To simulate the `autoregressive` time series described in Section [3.3.2](#Chp003_49-60_B9780443218576000072.xhtml#s0045), I proceed backwards: first, pick up the roots `r[1]`, …, `r[p]`![Image](images/B9780443218576000072/si73.png) of the `characteristic polynomial`, then compute the coefficients `a[1]`, …, `a[p]`![Image](images/B9780443218576000072/si76.png). This leads to interesting discoveries. I want at least one of the roots to have its modulus equal to one. The other roots must have a modulus strictly smaller than one. Roots can have a multiplicity greater than one. Depending on the roots, whether they are all real, whether some are complex, or whether some have a multiplicity greater than one, the pattern is very different. It falls into three categories:

- Type 1: A very smooth time series if the root(s) with largest modulus has a multiplicity greater than one.
- Type 2: A Brownian-like appearance if all the roots are real and distinct.
