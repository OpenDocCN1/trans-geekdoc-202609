### 1.3.3 周期性时间序列的非周期性求和：海洋潮汐

在本节中，我将探讨通过最小二乘法拟合**非周期三角级数**的问题。一个著名的例子是具有无限个叠加周期的狄利克雷 η 函数。其模值如[图 1.3](#Chp001_1-34_B9780443218576000059.xhtml#f0025)所示。实际应用也非常多。一个很好的练习是下载海洋潮汐数据，并使用本节描述的方法来预测不同地点的高潮和低潮：潮汐主要受两个因素影响——月球和太阳的引力——每个因素都有其自身的周期。但两者的组合并非周期性的。拟合技术允许你量化每个隐藏分量（本例中为太阳和月球）的影响，并恢复它们各自的周期。潮汐数据可在此免费获取：[here](https://tidesandcurrents.noaa.gov/)。

![图 1.3 由周期项组成的三个非周期时间序列（见第 17.2.2.1 节）。](images/B9780443218576000059/gr010.jpg)

图 1.3 由周期项组成的三个非周期时间序列（见第 [17.2.2.1](#Chp017_329-360_B9780443218576000217.xhtml) 节）。

用我的符号表示，该问题定义为 `w = (y, x)` 和

`g(y, x; θ) = y - [θ[1]cos(θ[2]x + θ[3]) + θ[4]cos(θ[5]x + θ[6])]`.

(1.7)

`θ` 没有约束，因此 [(1.2)](#Chp001_1-34_B9780443218576000059.xhtml#deq2) 中没有 `η` 函数和 `λ`。这里 `y` 是响应变量，`x` 代表时间。因此，我也使用 `y = f[θ](x)` 这种表示法，它等价于 `g(y, x; θ) = 0`。在科学计算中，这类问题称为**曲线拟合** [[维基](https://en.wikipedia.org/wiki/Curve_fitting)]。有库可以解决它：在 Python 中，可以使用 `Scipy` 库中的 `optimize.curve_fit` 函数。更多详情请参阅 [Python 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.curve_fit.xhtml)。

最后，如果你只对给定 `x` 预测 `y` 感兴趣，而不关心估计参数向量 `θ`，那么以下插值公式有时会很有用：

$y = f(x) \approx \frac{\sin\pi x}{\pi} \cdot \left\lbrack \frac{f(0)}{x} + 2x\sum\limits_{k = 1}^{n}{( - 1)}^{k}\frac{f(k)}{x^{2} - k^{2}} \right\rbrack.$

(1.8)

我在第 [17](#Chp017_329-360_B9780443218576000217.xhtml) 章关于黎曼假设的练习 [17.9](#Chp017_329-360_B9780443218576000217.xhtml) 中使用了它，以在 `y` 已知（即观测到）于整数增量 `x = 0, 1` 等处时，获得 `y = f[θ](x)` 的良好近似，即使 `θ` 未知。我将其应用于一个与[图 1.3](#Chp001_1-34_B9780443218576000059.xhtml#f0025)所示函数密切相关的函数 `f[θ](x)`。该函数（即狄利克雷 η 函数的实部）可以表示为具有不同振幅和不同周期的余弦项的无限求和。因此，在这种情况下，未观测到的 `θ` 的维度是无限的，且 `θ` 在预测实验中仍是一个隐藏参数，对实验者隐藏（如同盲测）。其分量是各种周期和振幅系数。近似公式 [(1.8)](#Chp001_1-34_B9780443218576000059.xhtml#deq13) 在特定条件下有效：详见练习 [17.9](#Chp017_329-360_B9780443218576000217.xhtml)。

#### 1.3.3.1 数值不稳定性及其修复方法

考虑 `θ[3] = θ[6] = 0` 这一较简单的情况：我们从模型中去掉这两个系数。即便如此，该问题依然是**病态的** [[维基](https://en.wikipedia.org/wiki/Condition_number)]。特别地，如果 `θ^* = (θ[1]^*, θ[2]^*, θ[4]^*, θ[5]^*)` 是一个最优解，那么 `(θ[4]^*, θ[5]^*, θ[1]^*, θ[2]^*)` 也是。至少在不失一般性的前提下，你需要添加约束 `|θ[1]| ≥ |θ[4]|`。

在 Python 中，我使用了 `Scipy` 的 `curve_fitting` 函数。它对此问题效果不佳，即使你为系数 `θ[1], θ[2], θ[4], θ[5]` 指定了边界，并用一个接近最优解 `θ^*` 的向量 `θ` 启动算法。我的测试包括：

- 寻找最优 `θ`，若拟合函数为 `y = f[θ](x) = θ[1]cos θ[2]x + θ[4]cos θ[5]x`，
- 使用合成训练集，其中 `y = a[1]cos a[2]x + a[4]cos a[5]x + a[7]cos a[8]x`。

[图 1.4](#Chp001_1-34_B9780443218576000059.xhtml#f0030) 中的灰色曲线称为“模型”，即 `y = a[1]cos a[2]x + a[4]cos a[5]x`，而蓝色曲线是拟合曲线（不一定唯一），点代表观测值（训练集为红色，验证集为橙色）。观测点并不完全位于灰色曲线上，因为我引入了一些噪声：模型与数据之间的第三项 `a[7]cos a[8]x`。注意观测值相对于 X 轴是等间距的，但相对于 Y 轴绝对不是。可以使用不同的采样机制来解决此问题。该图由第 [1.3.3.2](#Chp001_1-34_B9780443218576000059.xhtml#s0075) 节的 Python 代码生成。`a[1], ..., a[8]` 的值是预先指定的。显然，如果 `a[7] = 0`，则一个显而易见的最优解是 `θ[i]^* = a[i]`（`i = 1, 2, 4, 5`）。它提供完美拟合。此外，系数 `a[7]` 指定了数据中的噪声量。
