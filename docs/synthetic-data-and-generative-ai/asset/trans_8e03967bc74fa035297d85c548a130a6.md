
第 [18.3.1](#Chp018_361-386_B9780443218576000229.xhtml#s0050) 节介绍的原始问题在于估计扰动格点过程的两个参数 `λ`、`s`，即强度和尺度。这些随机过程可应用于传感器定位和蜂窝网络优化。由于在这种情况下无法进行直接估计（这些参数依附于一个隐藏的格点过程），我改用代理统计量 `p`、`q`。

这种方法称为**最小对比估计**，要求原始参数空间与代理空间之间存在一一映射。最小对比估计是一种包含**最大似然估计** [[维基百科](https://en.wikipedia.org/wiki/Maximum_likelihood_estimation)] 的通用技术。Tilman Davies [[2]](#Chp018_361-386_B9780443218576000229.xhtml#br0010) 和 Jesper Møller [[5]](#Chp018_361-386_B9780443218576000229.xhtml#br0025) 在点过程背景下使用了该方法。另请参阅此处 [here](https://cimpatogo2018.sciencesconf.org/data/pages/Handout_Moller_CIMPA_Togo_2018.pdf) 或此处 [here](https://drive.google.com/file/d/1y5TZXvAL8fP9G5UkmV3npKgoVB0YWtXk/view?usp=sharing) 的第 114–116 页幻灯片。

第 [18.3.1](#Chp018_361-386_B9780443218576000229.xhtml#s0050) 节讨论的点计数统计量测量落在特定区间 `B[k]` 内的该过程点的数量。我使用了 `n` 个不重叠的区间 `B[1]`、…、`B[n]`，每个区间产生一个观测向量 `(u[k], v[k])`，其中 `k` = 1、…、`n`。观测向量在各区间间近似独立同分布。然而，向量的第一和第二分量呈负相关。这解释了为何为模型选择二元伯努利分布。

更具体地说，该情况近似相同（且渐近相同）于以下情形：我们观测到一个独立同分布的二元伯努利序列 `(U[k], V[k])`，但对于每个 `k`，`U[k]` 和 `V[k]` 呈负相关，其相关性与公式 [(18.2)](#Chp018_361-386_B9780443218576000229.xhtml#deq2) 中相同。这些随机变量具有以下联合分布：

`P(U[k]=0, V[k]=0) = 1 - p - q`，`P(U[k]=1, V[k]=0) = p`，`P(U[k]=0, V[k]=1) = q`，`P(U[k]=1, V[k]=1) = 0`。

必须满足以下条件：`0 < p, q < 1` 且 `p + q < 1`。

[图 18.5](#Chp018_361-386_B9780443218576000229.xhtml#f0040) 中的散点图展示了使用最小对比估计量的估计过程。X 轴代表 `p`，Y 轴代表 `q`。有两个主要特征：

- **观测数据。** 三个紫点对应从三组观测中得出的 `(p, q)` 估计值，每组包含 ![Image](images/B9780443218576000229/fx006.jpg)。
- **理论模型。** 基于模拟，四个重叠的簇展示了四组不同理论 `(λ, s)` 值对应的 `(p, q)` 分布。每个簇（由其颜色标识）包含 100 个点，对应 100 次模拟。同一簇内的每次模拟使用相同的手工选取的 `(λ, s)`。这些模拟的目的是通过数值近似找到逆映射 `(p, q) ↦ (λ, s)`，以便在观测到 `(p, q)` 时恢复隐藏参数 `(λ, s)`。四种颜色只是一个小小的开端。在 [表 18.1](#Chp018_361-386_B9780443218576000229.xhtml#t0010) 中，每个簇由两个统计量汇总：其在 `(p, q)` 空间中的计算中心，与手工选取的参数向量 `(λ, s)` 相关联。

**图 18.5** 使用 `(p,q)` 作为代理统计量对 `(λ,s)` 进行最小对比估计。

但让我们设想一下，如果我手工选取 `10^5` 个 `(λ, s)` 向量而不是 4 个，从而生成 `10^5` 个簇中心和一个包含 `10^5` 条目的超大 [表 18.1](#Chp018_361-386_B9780443218576000229.xhtml#t0010)。同样，`(λ, s)` 的最佳估计量仍将是通过最小化观测计算出的紫点 `(p[0], q[0])` 与 `10^5` 个簇中心之间的距离而获得的。在实践中，手工选取过程是自动化的（计算机化的），从而导致估计过程的黑箱实现。
