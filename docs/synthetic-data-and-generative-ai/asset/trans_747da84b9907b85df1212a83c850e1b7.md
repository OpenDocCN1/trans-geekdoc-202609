
设 `W[k]` 为第 `k` 个观测值（`k` = 1, …, `n`），存储为行向量；`W` 为数据集（一个具有 `n` 行的矩阵）；`θ = (θ[A], θ[B])`，其中 `θ[A], θ[B]` 为列向量，每个向量的维度与 `W[k]` 相同。然后，根据 [(1.1)](#Chp001_1-34_B9780443218576000059.xhtml#deq1)，任何最优解满足

```
(θ_A^*, θ_B^*) = argmin_θ Σ_{k=1}^n g^2(W_k, θ) = argmin_{θ_A, θ_B} Σ_{k=1}^n ||W_k^T - θ_A||^p · ||W_k^T - θ_B||^p.
```

![图片](images/B9780443218576000059/si210.png) (1.10)

照常，**均方误差**（MSE）是 [(1.10)](#Chp001_1-34_B9780443218576000059.xhtml#deq15) 中的和在 `θ^* = (θ[A]^*, θ[B]^*)` 处计算得出的值，再除以 `n`。立即可知，如果 `h` 是保距映射（旋转、对称或平移），且 `θ^*` 是数据集 `W` 的最优解，则 `h(θ^*)` 是 `h(W)` 的最优解，因为 MSE 在此类变换下保持不变。因此，在不失一般性的前提下，可以假设数据集 `W` 以原点为中心。

你可以为每个簇选择不同的 `p` —— 例如 `p[A], p[B]` —— 或者像公式 [(1.5)](#Chp001_1-34_B9780443218576000059.xhtml#deq5) 那样使用加权和。如果 `p = 2` 且只有一个簇（因此没有 `θ[B]`），则 `θ[A]^*` 是点云（即 `W[k]`）的质心。现在假设簇之间分离得很好，以至于每个观测值 `W[k]` 要么与 `A` 的中心重合，要么与 `B` 的中心重合。此时只存在唯一的最优解：`θ[A]^*` 是其中一个簇的质心，`θ[B]^*` 是另一个簇的质心，且 MSE 为零。

如果有三个簇，公式 [(1.10)](#Chp001_1-34_B9780443218576000059.xhtml#deq15) 变为

```
(θ_A^*, θ_B^*, θ_C^*) = argmin_{θ_A, θ_B, θ_C} Σ_{k=1}^n ||W_k^T - θ_A||^p · ||W_k^T - θ_B||^p · ||W_k^T - θ_C||^p.
```

![图片](images/B9780443218576000059/si217.png) (1.11)

如果 `p > 0` 是偶数整数（或 `p[A], p[B]` 均为偶数整数），则在 [(1.10)](#Chp001_1-34_B9780443218576000059.xhtml#deq15) 或 [(1.11)](#Chp001_1-34_B9780443218576000059.xhtml#deq16) 中寻找最优解归结为求解一个多元多项式方程组，其中未知数是 `θ[A]` 和 `θ[B]` 的分量。簇越多，多项式的次数越高。特别地，在一维情况下，若 `p = p[A] = p[B] = 2`，且数据集（点云 `W`）以原点为中心，则最优解 `(θ[A]^*, θ[B]^*)` 满足

```
θ_A^* θ_B^* = -σ_W^2,  θ_A^* + θ_B^* = (1/(n σ_W^2)) Σ_{k=1}^n W_k^3,  with σ_W^2 = (1/n) Σ_{k=1}^n W_k^2.
```

![图片](images/B9780443218576000059/si219.png) (1.12)

公式 [(1.12)](#Chp001_1-34_B9780443218576000059.xhtml#deq17) 可以轻松推广到任意维度。它是通过令梯度为零以求得 [(1.10)](#Chp001_1-34_B9780443218576000059.xhtml#deq15) 中的最小值而获得的。遗憾的是，`p = 1` 时不存在精确公式。然而，在一维情况下，对于 `p = 1`，我们有

```
|W_k - θ_A| · |W_k - θ_B| = 1/2 · |(W_k - θ_A)^2 + (W_k - θ_B)^2 - (θ_A - θ_B)^2|.
```

![图片](images/B9780443218576000059/si220.png)

根据目前在一维情况下进行的少量测试，总体而言 `p = 1` 效果优于 `p = 2`。如果两个簇中度不平衡，如 [图 1.5](#Chp001_1-34_B9780443218576000059.xhtml#f0040) 所示，则 `p = 1` 仍然表现良好。然而，如果它们严重不平衡，如 [图 1.7](#Chp001_1-34_B9780443218576000059.xhtml#f0050) 所示，该方法会失效。这仍然可以修复，方法是选择两个不同的 `p` 值，分别记为 `p[A]` 和 `p[B]`。此时最优解对应于将较大的 `p` 分配给较小的簇：即 [图 1.7](#Chp001_1-34_B9780443218576000059.xhtml#f0050) 中的蓝色簇（印刷版为深灰色）。在这种情况下，`p[A] = 3, p[B] = 1` 的效果与 [图 1.5](#Chp001_1-34_B9780443218576000059.xhtml#f0040) 中 `p[A] = 1, p[B] = 1` 的效果一样好。在 [图 1.7](#Chp001_1-34_B9780443218576000059.xhtml#f0050) 中，蓝色簇（印刷版为深灰色）有 1500 个点，红色簇（印刷版为中灰色）有 8500 个点。两个中心分别为 0.5 和 1.0，小簇和大簇的标准差分别为 0.1 和 0.2。

![图 1.7 具有挑战性的混合分布，需要 pA = 3, pB = 1 来识别两个簇中心。](images/B9780443218576000059/gr017.jpg)

**图 1.7** 具有挑战性的混合分布，需要 `p[A] = 3, p[B] = 1` 来识别两个簇中心。

一个好的做法是尝试 `(1, 1), (2, 1), (3, 1)` 作为 `(p[A], p[B])` 的值，以查看哪一个能提供最佳拟合，如第 [1.3.4.3](#Chp001_1-34_B9780443218576000059.xhtml#s0095) 节所示。这在黑箱系统中特别有用，即在自动处理成千上万个数据集而无人工查看任何一个数据集的情况下。因为从视觉角度来看，“最佳”解有时是局部最小值而非全局最小值，我建议列出在寻找最优解 `(θ[A]^*, θ[B]^*)` 过程中找到的所有局部极小值。

当然，这种方法和其他任何分类器或模式搜索算法一样都有其局限性：如果混合分布只有一个模态，无论使用什么方法，都无法找到两个截然不同的有意义的中心。这种情况发生在簇中心确实不同，但方差巨大，或者其中一个簇包含极少点的情况下。另一个例子是簇具有不规则、非凸形状，带有多个中心和空洞。在后一种情况下，该方法对于寻找局部模态仍然有用。
