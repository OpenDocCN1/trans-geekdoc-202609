
设 `d(1)`、`d(2)`、… 为一个整数序列，其中 `d(k) ∈ {−1, 1}`，且 `P = {p[1], p[2], …}` 为素数集合。目标是基于前 `n` 个元素 `d(1)`、…、`d(n)` 来检验序列 `{d(k)}` 的随机性程度。算法如下：

*   **步骤 1。** 设置 `χ(p[k]) = d(k)`，其中 `p[k]` 是第 `k` 个素数（`p[1] = 2`）。
*   **步骤 2。** 对于 `k ∉ P` 且素因子分解为 `k = p[1]^(a[1]) p[2]^(a[2]) ⋯` 的情况，设置 `χ(k) = χ^(a[1])(p[1]) χ^(a[2])(p[2]) ⋯`，其中 `χ(1) = 1`。
*   **步骤 3。** 使用公式 `[(11.5)]` 计算 `L_3^*(n) = |L_3(n)| / √(n log log n)`。
*   **步骤 4。** 如果 `L_3^*(n) < 0.5` 或 `L_3^*(n) > 1.5`，则序列 `{d(k)}`（前 `n` 个元素）缺乏真正的随机性。

该测试被称为“**素数测试**”。让我们用 `k = 4200` 来说明步骤 2：因为 `4200 = 2³ ⋅ 3 ⋅ 5² ⋅ 7`，所以 `χ(4200) = χ³(2) χ(3) χ²(5) χ(7) = χ(2) χ(3) χ(7)`。

某些非随机序列可能通过素数测试。因此，你永远不应单独使用此测试来决定一个序列是否足够好。此外，`L_3(n)` 的标准化（使用 `√(n log log n)` 作为分母）并不完美，但假设 `10⁴ < n < 10^(15)` 时，足以满足所有实际用途。该测试能检测出其他测试无法发现的偏离随机性的情况。我将在本章后面讨论实际例子和 Python 实现。

满足 `[(11.3)]` 并通过所有现有测试（包括素数测试）的 PRN 序列被称为**强伪随机**。由公式 `[(11.4)]` 定义的对应实数 `λ` 被称为**强正规数**。证明几乎所有数都是强正规数应该不难。因此几乎所有 PRN 序列都是强伪随机的。然而，创建一个可被证明为强伪随机的序列，难度相当于证明给定数字是正规数（更不用说强正规数了）。有趣的是，**同余随机数生成器**产生的序列没有一个是强伪随机的，原因与没有有理数是正规数的原因相同：在这两种情况下，`d(k)` 都是周期性的。

现代测试套件包括 1995 年发布的 **Diehard 测试** 和 2007 年推出的 **TestU01** 框架。

### 11.2.1.2 理论背景：迭代对数律

素数测试检查从 `{d(k)}` 导出的乘法函数 `χ(k)` 是否满足**迭代对数律**的一个特定版本。真正随机的序列 `{d(k)}` 满足该定律。由于 `{χ(k)}` 是乘法的，因此是非随机的，迭代对数律必须进行调整以处理由此产生的依赖关系。特别是，用于标准化 `L_3(n)` 的 `√(n log log n)` 权重仅提供近似值，但足以满足所有实际用途。精确权重在 `[[6]]` 和 `[[9]]` 中讨论。

许多序列 `{d(k)}` 即使不使用本章引入的素数/欧拉乘积装置，也满足基本的迭代对数律。这里研究的大多数序列都属于这种情况。然而，通过观察 `χ(k)` 而非原始的 `d(k)`，我们能够放大那些用标准手段无法检测到的缺陷。一个例子是 Python 中实现的梅森旋转算法，它通过了标准测试，但当种子设为 200 时，却未能通过素数测试。

### 11.2.1.3 与广义黎曼假设的联系

**广义黎曼假设**（GRH）是数学中最著名的未解问题之一。它断言：如果 `1/2 < σ = Re(z) < 1`，则由公式 `[(11.1)]` 定义的函数 `L(z, χ)` 没有零点。这里 `z = σ + i t` 是一个复数，`σ = ℜ(z)` 是其实部。它适用于一类特定的函数 `χ(·)`，即那些“表现良好”的函数。当然，如果对 `χ(·)` 没有任何限制，则存在已知满足 GRH 的**完全乘法函数**。例如，由 `χ(p[2k]) = −1`、`χ(p[2k+1]) = 1` 定义的函数，其中 `p[k]` 是第 `k` 个素数。相应的 `L(z, χ)` 在 `σ > 1/2` 时没有零点，因为乘积在 `σ > 0` 时收敛，而且当然乘积没有零点。序列 `{χ(p[k])}` 显然是非随机的，因为它完美地交替出现，因此我在[表 11.1](#Chp011_203-228_B9780443218576000151.xhtml#t0010)中将其标记为 CounterExample。
