
## 8.3 高维空间中的完整非线性模型

我现在讨论一般模型。为简单起见，我重点关注二维情况：一个响应变量 `z`，包含两个特征 `x`、`y`。这是一个重要的情况，在**地理统计学** [[Wiki](https://en.wikipedia.org/wiki/Geostatistics)] 中有应用。`d` 维情况并不更复杂，但符号表示很快会变得繁琐。直线 `L[k]` 现在被样条函数取代，仍记作 `L[k]`。但这一次，`k = (k[1], …, k[r])` 是一个向量，满足 `1 ≤ k[i] ≤ n` (`i = 1, …, r`)。正如一个平面由恰好 3 个点唯一确定，我们希望样条函数 `L[k]` 由恰好 `r` 个点唯一确定，在本例中为 `(x[k[1]], y[k[1]], z[k[1]]), …, (x[k[r]], y[k[r]], z[k[r]])`。也就是说，我们希望

```
z[k[i]] = L[k](x[k[i]], y[k[i]]),  i = 1, …, r.
```

存在一种非常简单的样条函数满足此性质，即

```
L_k(x,y) = ∑_{i=1}^{r} (z_{k_i}/2) [ ∏_{j≠i} (ψ(x - x_{k_j}) / ψ(x_{k_i} - x_{k_j})) + ∏_{j≠i} (ψ(y - y_{k_j}) / ψ(y_{k_i} - y_{k_j})) ],
```

(8.1)

其中 `ψ` 是满足 `ψ(0) = 0` 的任意实值函数。实际上，可以选择恒等函数作为 `ψ`。由此产生的样条函数类似于用于插值的 `r − 1` 次多元拉格朗日多项式 [[3]](#Chp008_131-145_B9780443218576000126.xhtml#br0015)。我现在讨论这种回归类型的各种特性、问题、能力和潜在实现。

### 8.3.1 几何邻近性、权重与数值稳定性

从现在开始，我假设 `ψ` 为恒等函数。一个关键概念是平面上位置 `(x, y)` 与样条函数之间的邻近性。在给定 `(x, y)` 预测 `z` 时，必须计算每个样条函数 `L[k]` 的 `L[k](x, y)`。样条函数的数量随 `r` 快速增加。对于特定位置 `(x, y)`，某些样条函数比其他样条函数更相关。以下度量衡量了到 `L[k]` 的邻近性：

```
δ_k(x,y) = ( ∏_{i=1}^{r} max(|x - x_{k_i}|, |y - y_{k_i}|) )^{1/r}.
```

(8.2)

它是 ℝ² 中 `r` 个切比雪夫距离 [[Wiki](https://en.wikipedia.org/wiki/Chebyshev_distance)] 的几何平均。特别地，如果这些距离中任意一个为零，则该值为零。算术平均无法满足这一基本性质，但几何平均可以。`L[k]` 相对于 `(x, y)` 的相关性或重要性随后被定义为权重

```
w[k](x, y) = exp[ − s ⋅ δ[k](x, y) ],
```

(8.3)

其中 `s > 0` 是**平滑参数**。当 `δ[k](x, y) = 0` 时，它取得最大值。另一方面，某些样条函数总是有问题的，甚至可能不存在。这些样条函数通过精度指标来识别

```
ε_k = ∏_{i=1}^{r} ∏_{j=i+1}^{r} |x_{k_i} - x_{k_j}| ⋅ |y_{k_i} - y_{k_j}|.
```

(8.4)

特别地，如果 `ε[k] = 0`，则样条函数 `L[k]` 未定义。拒绝或忽略 `ε[k] < 10^(−5)` 的样条函数是一种良好的做法。这能提高系统的数值稳定性。

此外，某些样条函数可能会产生异常预测值，这取决于位置 `(x, y)`。在混合 `M` 个预测值 `L[k](x, y)`（每个样条函数一个）以计算 `(x, y)` 处的最终预测值和预测区间时，应忽略此类异常预测以提升性能。该最终预测值是在剔除不良样条函数或预测后，所有样条函数在 `(x, y)` 处计算出的中位数或加权平均值。异常预测值通过 Python 代码中的**超参数** `zzdevratio` 进行检测和剔除。
