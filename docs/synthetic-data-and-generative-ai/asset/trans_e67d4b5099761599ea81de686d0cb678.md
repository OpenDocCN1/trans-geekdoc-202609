
### 11.2.2 机器精度与BBP公式

然而，由于机器精度（第[11.2.2](#Chp011_203-228_B9780443218576000151.xhtml#s0040)节讨论的问题），计算机为移位映射（或任何映射）生成的`x[k]`![Image](images/B9780443218576000151/si112.png)最终会变得周期性。因此`{d(k)}`![Image](images/B9780443218576000151/si17.png)也会变得周期性。一种变通方法是使用精确算术来计算`d(k)`![Image](images/B9780443218576000151/si29.png)，就像第[11.3.3](#Chp011_203-228_B9780443218576000151.xhtml#s0070)节中的Python代码那样。另一种解决方案是使用**Bailey–Borwein–Plouffe公式**\[[维基百科](https://en.wikipedia.org/wiki/Bailey%E2%80%93Borwein%E2%80%93Plouffe_formula)\]来计算数字。对于各种良好的**超越数**种子\[[维基百科](https://en.wikipedia.org/wiki/Transcendental_number)\]，如`` `$x_0 = \frac{\pi}{4}` ``![Image](images/B9780443218576000151/si125.png)，存在许多BBP公式，但据我所知，对于**代数数**\[[维基百科](https://en.wikipedia.org/wiki/Algebraic_number)\]子集（如`` `$x_0 = \sqrt{2}/2` ``![Image](images/B9780443218576000151/si122.png)）则没有。

#### 11.2.2.2 图示

图[11.2](#Chp011_203-228_B9780443218576000151.xhtml#f0015)和[11.3](#Chp011_203-228_B9780443218576000151.xhtml#f0020)展示了素性检验的核心统计量，由公式[(11.5)](#Chp011_203-228_B9780443218576000151.xhtml#deq5)定义：`L[3]^*(n)`![Image](images/B9780443218576000151/si126.png)和`|L[3](n)|`![Image](images/B9780443218576000151/si128.png)，针对![Image](images/B9780443218576000151/fx005.jpg)和![Image](images/B9780443218576000151/fx006.jpg)之间的`n`。如果`L[3]^*(n) < 0.5`![Image](images/B9780443218576000151/si53.png)或`L[3]^*(n) > 1.5`![Image](images/B9780443218576000151/si54.png)，序列`{d(k)}`![Image](images/B9780443218576000151/si17.png)（前`n`个元素）缺乏真正的随机性；它不是**强伪随机**的。表[11.1](#Chp011_203-228_B9780443218576000151.xhtml#t0010)总结了在![Image](images/B9780443218576000151/fx001.jpg)计算的更大一组序列的这些发现。符号`Python[200]`对应于梅森旋转算法的Python实现，使用`random.random()`函数和种子200，即`random.seed(200)`。类似地，`SQRT[90,91]`用于`` `$\sqrt{2205}` ``![Image](images/B9780443218576000151/si1.png)的二进制数字，通过第[11.3.3](#Chp011_203-228_B9780443218576000151.xhtml#s0070)节代码中的二元种子`y = 90, z = 91`![Image](images/B9780443218576000151/si129.png)获得。不出所料，序列`Base3[0.72]`失败了，因为`0.72 = 18/25`![Image](images/B9780443218576000151/si130.png)是一个分母很小的有理数。因此`d(k) = χ(p[k])`![Image](images/B9780443218576000151/si32.png)是周期性的，周期相当小。表[11.1](#Chp011_203-228_B9780443218576000151.xhtml#t0010)中标记为Status的列指示相关序列是通过还是未通过素性检验。

为方便起见，我还包含了一种称为`CounterExample`的序列类型。对于这类序列，`χ(p[k])`![Image](images/B9780443218576000151/si131.png)在−1和+1之间完美交替。由此产生的两个序列`{d(k)}`![Image](images/B9780443218576000151/si17.png)中，一个勉强通过测试，另一个失败。现在，种子设为3的`Dirichlet4`序列，具有完美交替的`d(k)`![Image](images/B9780443218576000151/si29.png)，因此是非随机的。它未通过素性检验，但只是勉强失败。这意味着通过该测试并不能保证随机性。只有未通过测试才能保证非随机性。

素性检验可以通过Python代码中的All选项进行扩展。为此，定义`L[4]`![Image](images/B9780443218576000151/si132.png)统计量如下：

```
$L\_{4}(n) = \\sum\\limits\_{k = 1}^{n}\\chi(k),\\quad L\_{4}^{\\ast}(n) = \\frac{|L\_{4}(n)|}{\\sqrt{n\\log\\log n}}.
```

![Image](images/B9780443218576000151/si133.png)(11.6)

现在使用`L[4]^*`![Image](images/B9780443218576000151/si134.png)而不是`L[3]^*`![Image](images/B9780443218576000151/si109.png)，种子设为3的`Dirichlet4`序列将在素性检验中惨败，而不仅仅是勉强失败。这将揭示尽管表面看起来随机，但该序列确实存在某种确定的非随机性。事实上，它满足`χ(4*k + 1) = 1`![Image](images/B9780443218576000151/si135.png)、`χ(4*k + 3) = -1`![Image](images/B9780443218576000151/si136.png)和`χ(2*k) = 0`![Image](images/B9780443218576000151/si137.png)。`L[4]^*`![Image](images/B9780443218576000151/si134.png)版本的素性检验细节仍需完善，因此我未将其包含在本章中。

最后，如果你在`{d(k)}`![Image](images/B9780443218576000151/si17.png)序列中交换−1/+1![Image](images/B9780443218576000151/si138.png)，新序列可能会通过测试，即使原序列失败（反之亦然）。序列`SQRT[90,91]`就是这种情况。此外，`L[3]^*`![Image](images/B9780443218576000151/si109.png)刻度应被理解为地震刻度：从0.35增加到0.45，或从1.3增加到1.8，代表巨大的差异。与随机序列相比，具有低`L[3]^*`![Image](images/B9780443218576000151/si109.png)的序列交替过于频繁，导致`d(k)`![Image](images/B9780443218576000151/si29.png)中+1与−1的比率过于接近50%。有关比率对应表[11.1](#Chp011_203-228_B9780443218576000151.xhtml#t0010)中标记为`P[d(k) = 1]`![Image](images/B9780443218576000151/si139.png)的列。

### 练习 11.1

#### 由有理数生成的伪随机序列

设`q[k] = 2^(-{k*log[2]3})`![Image](images/B9780443218576000151/si140.png)为有理数（`k = 1, 2`![Image](images/B9780443218576000151/si18.png)，以此类推），其中括号表示**小数部分函数**\[[维基百科](https://en.wikipedia.org/wiki/Fractional_part)\]。例如，`q[6] = 512/729`![Image](images/B9780443218576000151/si141.png)。设`M[n]`![Image](images/B9780443218576000151/si142.png)为`{q[1], ..., q[n]}`![Image](images/B9780443218576000151/si143.png)的中位数。因此如果`n`为奇数，则`M[n]`![Image](images/B9780443218576000151/si142.png)是在将`q[k]`![Image](images/B9780443218576000151/si144.png)按升序重新排列后的中间项。证明：（1）当`n → ∞`![Image](images/B9780443218576000151/si146.png)时，`` `$M_n \rightarrow \sqrt{2}/2` ``![Image](images/B9780443218576000151/si145.png)；（2）`q[k]`![Image](images/B9780443218576000151/si144.png)的二进制数字展开的周期为`2 * 3^(k - 1)`![Image](images/B9780443218576000151/si147.png)；（3）这些数字中0和1的比例恰好为50/50。

#### 解答

(2)和(3)的解答见[此处](https://math.stackexchange.com/questions/3310862/what-is-the-period-of-the-fraction-1-3k-in-base-2-for-k-1-2-dots)；(3)源于序列`{k*log[2]3}`![Image](images/B9780443218576000151/si148.png)的**模1等分布**\[[维基百科](https://en.wikipedia.org/wiki/Equidistribution_theorem)\]。这意味着`q[k]`![Image](images/B9780443218576000151/si144.png)的分布类似于`2^(-U)`![Image](images/B9780443218576000151/si149.png)，其中`U`在`[0, 1]`![Image](images/B9780443218576000151/si90.png)上均匀分布。
