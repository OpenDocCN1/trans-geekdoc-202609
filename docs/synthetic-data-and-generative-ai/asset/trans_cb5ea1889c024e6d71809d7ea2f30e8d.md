### 4.2.3.4 对六个挑战性问题的部分解答

在机器学习中，通常没有数学证明来表明模型是精确的。例如，统计模型显示吸烟会增加患肺癌的几率。这些论据令人信服。但对此没有正式证明。通常，建立因果关系很难。相反，在数学中，通常有正式证明可用，它们可用于测试和基准测试统计模型。人们会认为第 [4.2.3.1](#Chp004_61-82_B9780443218576000084.xhtml#s0035) 节提出的六个问题有精确的数学答案。不幸的是，这里并非如此。然而，有一些部分答案可用。首先，让我定义一下我所说的“洞”是什么意思。

#### 定义

T-洞 `Ω[T] = Ω[T](σ)`![Image](images/B9780443218576000084/si53.png) 是以实（水平）轴上某个位置 `t[T]`![Image](images/B9780443218576000084/si54.png) 为圆心的最大圆，使得如果 `0 < t ≤ T`![Image](images/B9780443218576000084/si56.png)，则 `η(σ + i t) ∉ Ω[T]`![Image](images/B9780443218576000084/si55.png)。洞 `Ω` 是 `Ω[T]`![Image](images/B9780443218576000084/si57.png) 的极限，当 `T → ∞`![Image](images/B9780443218576000084/si58.png) 时。

简而言之，给定 `σ` 时，`η` 的轨道如果 `0 < t < T`![Image](images/B9780443218576000084/si59.png) 则永远不会进入洞内。这里 `t[T] = t[T](σ)`![Image](images/B9780443218576000084/si60.png) 是 `σ` 的函数，满足 `0 ≤ t[T] < 2`![Image](images/B9780443218576000084/si61.png)。另一个重要概念（见问题 4）是实轴上从未被轨道穿过或触及的最大线段。

现在，让我们专注于回答问题 1-6。首先，公式 [(4.1)](#Chp004_61-82_B9780443218576000084.xhtml#deq5) 中的级数绝对收敛 [[维基](https://en.wikipedia.org/wiki/Absolute_convergence)]。因此黄色轨道是有界的：这是一个平凡事实。蓝色和红色轨道无界的事实很久以前就已证明。参见经典参考文献“黎曼 ζ 函数理论”[[2]](#Chp004_61-82_B9780443218576000084.xhtml#br0010)。这为问题 1 提供了完整答案。

此外，已知轨道覆盖稠密区域。当你不断添加越来越多的点（从而增加 `T`）时，洞最终会收缩为勒贝格测度为零的集合：如果 `0.5 < σ < 1`![Image](images/B9780443218576000084/si62.png)，这成立。这是黎曼 ζ 函数普适性质的结果 [[维基](https://en.wikipedia.org/wiki/Zeta_function_universality)]。这为问题 5 和 6 提供了部分答案。如果 `σ` 固定且 `t` 有界，我推测与蓝色和黄色轨道相关的洞总是存在。对于蓝色轨道，这一陈述，特别是如果应用于 `]0.5, 1[`![Image](images/B9780443218576000084/si63.png) 中的所有 `σ`，比黎曼假设 (RH) 更强，因此至今未被证明。有人认为 RH 可能不可证，但那是另一个故事。

红色轨道（`σ = 0.5`![Image](images/B9780443218576000084/si64.png)）没有洞。随着 `σ` 从 1.25 减小到 0.5，洞收缩并在实轴上向左移动，朝向原点。当 `σ = 0.5`![Image](images/B9780443218576000084/si64.png) 时，它最终收缩为空集并成为吸引子点。这一点由黎曼 ζ 函数在 `σ = 0.5`![Image](images/B9780443218576000084/si64.png) 时有无限多个非平凡零点这一事实得到确认。当 `0.5 < σ < 1`![Image](images/B9780443218576000084/si62.png) 时，狄利克雷 η 函数和黎曼 ζ 函数的根是相同的。蓝色轨道的洞似乎包含原点，这表明如果 `σ = 0.75`![Image](images/B9780443218576000084/si65.png)，黎曼 ζ 函数没有零点。至今，这一比 RH 弱得多的猜想仍未被证明。

排斥和 `吸引域` [[维基](https://en.wikipedia.org/wiki/Attractor)] 的概念在动力系统中是基础的。洞是一个排斥域，而对于红色轨道，原点是一个吸引子点。我的下一本书将详细讨论这些主题，涵盖广泛的动力系统。

### 4.2.4 具有混沌收敛性的算法

我们都熟悉展示梯度下降或其他优化算法运行过程的图片，甚至动画 GIF，它们根据初始条件收敛到最优解。在所有情况下，曲面（无论是 2D 还是 3D）都是光滑的，尽管存在许多具有多个局部极大值和极小值的例子。请看一个带有 Mathematica 代码的示例，[这里](https://commons.wikimedia.org/wiki/File:Gradient_descent.gif)。梯度下降的维基百科条目（[这里](https://en.wikipedia.org/wiki/Gradient_descent)）也有一个很棒的 3D 视频。

这里我直观地说明了函数不太光滑时的收敛机制，在一般背景下。这与优化无关，除非你将加速收敛视为一个优化问题。视频中的每一帧都显示了给定初始条件下向最终解的进展。该 2D 问题在六种不同初始条件下的收敛路径如 [图 4.8](#Chp004_61-82_B9780443218576000084.xhtml#f0060) 所示。很难分辨哪里是开始，哪里是结束。如果你看视频，[这里](https://www.youtube.com/watch?v=XI5MhyNc7us)，这很直观。

[图 4.8](#Chp004_61-82_B9780443218576000084.xhtml#f0060) 中所示算法使用公式 [(4.1)](#Chp004_61-82_B9780443218576000084.xhtml#deq5) 在复平面上计算 `η` 函数的连续值。每次迭代向求和添加一项新项，并生成一帧新画面。可以使用 `收敛加速` 技术 [[维基](https://en.wikipedia.org/wiki/Series_acceleration)] 显著提高收敛速度，例如欧拉变换 [[维基](https://mathworld.wolfram.com/EulerTransform.xhtml)]，这在我的书 [[1]](#Chp004_61-82_B9780443218576000084.xhtml#br0005) 第 65 页有描述。我在书中（同一页）解释了为什么在这种情况下收敛如此混沌。当连续迭代产生振荡值时，相同的收敛加速技术也适用于梯度下降和其他类似的迭代算法。对于 `η` 函数，Borwein 方法 [[维基](https://en.wikipedia.org/wiki/Borwein%27s_algorithm)] 可能是最佳方法。
