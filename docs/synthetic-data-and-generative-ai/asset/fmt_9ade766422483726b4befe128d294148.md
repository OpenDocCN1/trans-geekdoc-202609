
A proof (by [William Huber](https://www.analysisandinference.com/team/william-a-huber-phd)) of this unpublished theorem can be found [here](https://stats.stackexchange.com/questions/422354/correlations-between-two-sequences-of-irrational-numbers), with additional discussion on this topic, [here](https://stats.stackexchange.com/questions/450922/cross-correlations-in-digit-distributions). Note that ⌊`b` ⋅ {`b`^(`k`)`α`}⌋![Image](images/B9780443218576000151/si208.png) is the `k`th digit of `α` in base `b`. The brackets represent the integer part function. Thus, if `α[1]` = `p``α`![Image](images/B9780443218576000151/si209.png) and `α[2]` = `q``α`![Image](images/B9780443218576000151/si210.png), the correlation between the sequences ({`b`^(`k`)`α[1]`})![Image](images/B9780443218576000151/si211.png) and ({`b`^(`k`)`α[2]`})![Image](images/B9780443218576000151/si212.png) is `ρ`(`p`, `q`) = (`p``q`)^( − 1)![Image](images/B9780443218576000151/si206.png). If `α[1]`, `α[2]`![Image](images/B9780443218576000151/si213.png) are irrational and linearly independent over ℚ![Image](images/B9780443218576000151/si201.png), then the only way you can write `α[1]` = `p``α`![Image](images/B9780443218576000151/si209.png), `α[2]` = `q``α`![Image](images/B9780443218576000151/si210.png) is by letting `p`, `q`![Image](images/B9780443218576000151/si103.png) tend to infinity, thus the correlation vanishes. It implies that the correlation between the digit sequences of `α[1]`![Image](images/B9780443218576000151/si214.png) and `α[2]`![Image](images/B9780443218576000151/si215.png) is zero.

There is more number theory involved. In particular, the method uses the new algorithm described in Section [11.3.3](#Chp011_203-228_B9780443218576000151.xhtml#s0070) to compute the binary digits of quadratic irrationals. It is also connected to `square-free integers`, and approximations of irrational by rational numbers which is linked to continued fractions. Square-free integers \[[Wiki](https://en.wikipedia.org/wiki/Square-free_integer)\] are also discussed in Sections [11.2.1](#Chp011_203-228_B9780443218576000151.xhtml#s0020) and [17.2.2.2](#Chp017_329-360_B9780443218576000217.xhtml). They represent 61% of all positive integers: the exact proportion is 6/`π`²![Image](images/B9780443218576000151/si216.png).

### 11.4.2 Fast PRNG: explanations

Each positive integer `c` can be written as `c` = `a``b`![Image](images/B9780443218576000151/si217.png), where `a` is a square, and `b` is square-free. For instance, if `c` = 3⁵ × 13⁶ × 19![Image](images/B9780443218576000151/si218.png), then `a` = 3⁴ × 13⁶![Image](images/B9780443218576000151/si219.png) and `b` = 3 × 19![Image](images/B9780443218576000151/si220.png). If `c` is a square, then `c` = `a`![Image](images/B9780443218576000151/si221.png) and `b` = 1![Image](images/B9780443218576000151/si222.png).

The quadratic irrationals used here are characterized by a bivariate `seed` (`y[0]`, `z[0]`)![Image](images/B9780443218576000151/si223.png). Given a seed, the successive iterations produce the binary digits of the number

```
x_0 = \frac{- (z_0 - 1) + \sqrt{(z_0 - 1)^2 + 8y_0}}{4}.
```

![Image](images/B9780443218576000151/si224.png)(11.7)

The connection to square-free integers is as follows: `c` = (`z[0]` − 1)² + 8`y[0]`![Image](images/B9780443218576000151/si225.png) cannot be a square. I use the notation `c` = `a``b`![Image](images/B9780443218576000151/si217.png), where `a` is the square part of `c` and `b` is the square-free part. Thus, we must have `b` > 1![Image](images/B9780443218576000151/si100.png). I use a large number of seeds to generate a large number of quadratic irrationals. The cross-correlation between the two digit sequences in any pair of quadratic irrationals must be zero. Based on the theory in Section [11.4.1](#Chp011_203-228_B9780443218576000151.xhtml#s0080), it means that once a seed produces a specific `b`, any future seed with the same `b` must be rejected. This is accomplished using the variable `accepted` in the code, along with the `hash table` (dictionary in Python) `squareFreeList`. The key for this hash table is actually `b`.

The number of digits produced for each quadratic irrational is specified by the parameter `size`. The total number of quadratic irrationals is determined by `Niter`. Not all of them are used: a few are rejected for the reason just mentioned. All the binary digits of all the accepted quadratic irrationals are stored in the hash table `digits`. For instance, `digits[(b,k)]` is the `k`th digit of the quadratic irrational with square-free part `b`. The seed (`y[0]`, `z[0]`)![Image](images/B9780443218576000151/si223.png) corresponding to this number is `squareFreeList[b]`.

Due to the particular choice of seeds in the Python code (with `y[0]` = 1![Image](images/B9780443218576000151/si226.png)), many quadratic irrationals are close to zero. More specifically, formula [(11.7)](#Chp011_203-228_B9780443218576000151.xhtml#deq8) yields the following approximation: `x[0]` ≈ `y[0]`/(`z[0]` − 1)![Image](images/B9780443218576000151/si227.png). So the first few digits are biased and should be skipped. This is accomplished via the parameter `offset`. There are other problematic quadratic irrationals such as those with `z[0]` − 1![Image](images/B9780443218576000151/si228.png) being a power of 2. A future version of this algorithm can reject these quadratic irrationals, and also reject those that are too close to a number already in the hash table. However, increasing the parameter `offset` is the easiest option to eliminate these problems. The next step is to run a standard battery of tests such as the `Diehard tests`, and check whether this PRNG passes all of them depending on the parameters and configuration.

I have not tested yet the algorithm with `size`=1: this is the fastest way to generate many digits (assuming `Niter` is increased accordingly), and possibly the best choice assuming `offset` is large enough. In particular, if you extract just one digit of each quadratic irrational, there is a faster way to do it, see Section [11.4.4](#Chp011_203-228_B9780443218576000151.xhtml#s0095).
