
最后，有几个 Python 库处理连结函数，例如 [`Copulalib`](https://pypi.org/project/copulalib/) 和 [`Copulas`](https://pypi.org/project/copulas/)。另请参阅 [`SDV`](https://pypi.org/project/sdv/)（Python 版合成数据库），了解包括深度学习在内的更多选项。我 GitHub 仓库（主文件夹）上的 Python 程序 [`copula.py`](https://github.com/VincentGranville/Main/blob/main/copula.py) 展示了其工作原理。也可以避免使用连结函数，直接处理相关矩阵，如第 [7.2.1](#Chp007_113-129_B9780443218576000114.xhtml) 节所示。或者完全忽略相关性，仅向每个特征添加不相关的白噪声：这可能是生成合成数据最简单的方法。与连结函数相比，这种方法在生成超出真实数据观测范围的合成值方面显著优越。它还能保留相关结构，并且在某种意义上，生成更丰富的数据。另一种流行的方法是 `rejection sampling` [[维基百科](https://en.wikipedia.org/wiki/Rejection_sampling)]。

### 10.2.1 保险数据集：Python 代码与结果

我使用第 [10.2](#Chp010_169-201_B978044321857600014X.xhtml#s0015) 节中的算法合成了 Kaggle 上共享的保险数据集，[此处](https://www.kaggle.com/datasets/teertha/ushealthinsurancedataset)。GitHub（主文件夹）上的电子表格 [`insurance.xlsx`](https://github.com/VincentGranville/Main/blob/main/insurance.xlsx) 总结了所有发现，并包含三个数据集：真实数据、我用 [`insurance.py`](https://github.com/VincentGranville/Main/blob/main/insurance.py)（同一文件夹）生成的合成数据，以及 `Mostly.ai` 生成的合成数据。该数据集包含以下字段：`age`、`sex`、`bmi`（体重指数）、计划覆盖的子女数量、`smoker`（是或否）、`region`（东北部等）以及保险公司为相关客户产生的 `charges`。

我不知道 `Mostly.ai` 使用什么算法，但他们生成的真实数据合成副本与我的惊人地相似。两者都具有由连结函数生成的所有标志（优点和缺点）。我的版本略好，因为我为每个观测组生成了不同的连结函数（从而也是不同的相关矩阵）。我按 `sex`、`smoker` 状态和 `region` 对观测值进行分组，而 `Mostly.ai` 则对所有这些组应用相同的连结函数。自动将这些组检测为决策树中的大型同质 `nodes`，并为每个 `node` 使用单独的连结函数，将产生一种 `ensemble method`，这与第 [2](#Chp002_35-47_B9780443218576000060.xhtml) 章所述的 `boosted trees` 不无相似之处。我所说的大 `node`，是指包含许多观测值（足以计算有意义的相关矩阵和经验分位数）但深度较小以避免过拟合的 `node`。这些 `nodes` 是在真实数据上检测到的。

[表 10.1](#Chp010_169-201_B978044321857600014X.xhtml#t0010) 提供了一些高层汇总统计量：合成数据 1 由 `Mostly.ai` 生成，合成数据 2 使用此处描述的方法生成。相关结构得到了很好地重构。合成数据 2 在“最大费用”（所有观测值计算出的最大值）方面优于合成数据 1，因为它为每个组生成单独的连结函数。此外，该特征呈双峰分布。

痛点在于连结函数无法生成超出真实数据集观测范围的值：观察最大值和最小值时这显而易见。所有数据集具有相同数量的观测值。即使我将合成观测值的数量增加 100 倍，我仍然受限于最大费用小于 ![Image](images/B978044321857600014X/fx013.jpg)，尽管该上限在真实数据中并非异常值。“age” 特征也是如此，尽管这因年龄 18 和 64 是截断点而变得复杂。问题在于第 [10.2](#Chp010_169-201_B978044321857600014X.xhtml#s0015) 节中的分位数函数 `Q[j]`![Image](images/B978044321857600014X/si7.png) 为每个特征 `j` 生成真实数据中观测到的最小值和最大值之间的值。一种变通方法是在真实数据或合成数据中引入不相关的白噪声；请参阅第 [10.2.2](#Chp010_169-201_B978044321857600014X.xhtml#s0025) 节。

本节中的 Python 代码可按如下方式优化速度：预计算真实数据集中与每个特征相关的经验分位数函数，以及标准高斯分布的 `CDF`。换句话说，使用预计算值表。请注意，我的方法中的经验分位数需要为每个组单独计算。除“`bmi`”外，保险数据集中的特征高度非高斯：“`charges`”呈双峰，“number of children”服从几何（离散）分布，而“`age`”除极值外服从均匀分布。

### 10.2.2 潜在改进

第 [10.2.1](#Chp010_169-201_B978044321857600014X.xhtml#s0020) 节实现的连结函数方法存在一些局限性：它无法生成超出真实数据观测范围的合成数据。一个简单的解决方案是向每个特征添加一些参数化噪声。该参数可以是添加到特定特征的噪声量，换句话说，即附加噪声的方差。请参阅第 [7.2](#Chp007_113-129_B9780443218576000114.xhtml) 节了解该方法的应用。对于类高斯特征，使用白噪声（零均值的不相关高斯噪声）是合理的。对于某些特征，使用双参数分布生成的噪声可能更合适。噪声也可以一次为多个特征联合生成，噪声分量间的相关性复制真实数据中相关特征的相关性。这同样在 [7.2](#Chp007_113-129_B9780443218576000114.xhtml) 节中讨论。

此外，与其使用 `Step 4` 中的经验分位数（见第 [10.2](#Chp010_169-201_B978044321857600014X.xhtml#s0015) 节开头），不如使用某些已知分布的分位数：即适合相关特征的分布。相关分布的参数在真实数据上估计。因此，在为特定特征执行 `Step 4` 中的模拟时，使用该分布及其在真实数据上估计的参数。例如，在保险数据集中，`BMI` 特征（体重指数）可用高斯分布很好地近似，而子女数量可用几何分布很好地近似。“`charges`”特征（保险公司为每位投保人的成本）呈双峰：在这种情况下，两个高斯分布的混合可能是一个良好的拟合。在此背景下，这种混合被称为 `Gaussian mixture models` (`GMM`)。

最后，你可以生成大量合成数据集来模拟同一个真实数据集。这通过在 Python 代码中每次使用不同的种子来实现。然而，这相当低效，因为每个新的合成版本都不会在改善与真实数据的拟合方面取得任何进展：你需要尝试大量的种子。一个更好的解决方案是使用参数化噪声或预先指定的分布：根据特征选择高斯、几何或高斯混合，正如前面针对该特定数据集所述。因此，你引入了可以基于真实数据估计或微调的参数，而不是使用无参数的经验分位数。请记住，分位数分布是累积分布的逆函数，无论是经验的还是参数化的基于模型的。
