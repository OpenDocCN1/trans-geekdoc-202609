### 5.3.1 基于卷积滤波器的监督分类

这里合成数据集代表训练集。算法包括对整个位图进行 `N` 次滤波。每次对每个像素 (`x`, `y`)![图片](images/B9780443218576000096/si27.png) 应用一个局部滤波器。最初，附加在像素上的颜色 `c(x, y)`![图片](images/B9780443218576000096/si28.png) 代表它在训练集中所属的簇（换句话说，它在 `m`-混合中源自的单个点过程）：如果在训练集中，其值为 0 到 `m - 1`![图片](images/B9780443218576000096/si29.png) 之间的整数，否则为 255。分配给 (`x`, `y`)![图片](images/B9780443218576000096/si27.png) 的新颜色是

```
c^{\prime}(x,y) = \underset{j}{\arg\max}\sum\limits_{u = - w}^{w}\sum\limits_{v = - w}^{w}\frac{\chi\lbrack c(x - u,y - v) = j\rbrack}{\sqrt{1 + u^{2} + v^{2}}}
```

![图片](images/B9780443218576000096/si30.png)(5.3)

即使 [(5.3)](#Chp005_83-102_B9780443218576000096.xhtml#deq3) 最大化的 `j` 值。这里 `χ[A]`![图片](images/B9780443218576000096/si31.png) 是指示函数 [[Wiki](https://en.wikipedia.org/wiki/Indicator_function)]：若 `A` 为真则 `χ[A]` = 1![图片](images/B9780443218576000096/si32.png)，否则为 0。边界问题（当 `x - u`![图片](images/B9780443218576000096/si33.png) 或 `y - v`![图片](images/B9780443218576000096/si34.png) 在位图之外时）在源代码中处理。

在 Python 代码中，`N` 是参数 `nloop`，`w` 是参数 `window`。在图中也称为 `w` 和 `loops`。特别地，我使用了 `N = 3`![图片](images/B9780443218576000096/si35.png) 和 `w = 20`![图片](images/B9780443218576000096/si36.png)。公式 [(5.3)](#Chp005_83-102_B9780443218576000096.xhtml#deq3) 对应 Python 代码中的 `method = 1`。虽然较慢，但它提供了精细的簇边界。一个更快的版本，即 `method = 0`，不进行除以 `sqrt(1 + u^2 + v^2)`![图片](images/B9780443218576000096/si37.png) 的操作。它更快不仅因为避免了平方根计算，还因为可以非常高效地实现；见第 [5.3.5](#Chp005_83-102_B9780443218576000096.xhtml#s0055) 节。然而，使用快速方法时的精度损失虽然明显，但比预期的小。请参阅 [图 5.7](#Chp005_83-102_B9780443218576000096.xhtml#f0040) 进行比较。

请注意，每个簇即使重叠很小，也延伸到整个平面。所以总存在一定程度的重叠。但当扩散因子 `s`（Python 代码中的变量 `s`）很小时，重叠小得多。对比 [图 5.2](#Chp005_83-102_B9780443218576000096.xhtml#f0015) 和 [图 5.4](#Chp005_83-102_B9780443218576000096.xhtml#f0025) 即可明显看出。两个图的簇数量相同，簇中心也相同；只有 `s` 不同——因此簇重叠程度也不同。

在对整个位图进行 `N = 3`![图片](images/B9780443218576000096/si35.png) 次滤波后，得益于局部滤波窗口的大尺寸（`w = 20`![图片](images/B9780443218576000096/si36.png)），所有像素都被分配到了一个簇。这意味着任何未来点（不在训练集中）都可以轻松高效地分类：首先，在其位图上找到其位置；然后其簇就是分配给该位置的颜色。值得探讨的是，如果对位图进行多次滤波，是否会发生收敛（以及收敛到什么解）。我在我的论文“模拟退火：收敛性证明”[[1]](#Chp005_83-102_B9780443218576000096.xhtml#br0005)中研究了类似滤波器的收敛性。经验证据表明，额外的循环（将 `N` 增加到 `N = 3`![图片](images/B9780443218576000096/si35.png) 以上）几乎没有任何区别。
