
如果 `offset` 很大，你会花费时间计算数字（位于每个二次无理数二进制展开的开头），而这些数字仅用于获取后续数字。有一种更高效的方法：使用不同的种子（`y[0]'`，`z[0]'`）![Image](images/B9780443218576000151/si229.png)。新种子的好处是保持无平方因子部分 `b` 不变。要一次性获得位置 `k` 处的数字（假设第一个位置对应 `k = 0`![Image](images/B9780443218576000151/si230.png)），请使用种子 `y[0]' = 2^(2*k)*y[0]`![Image](images/B9780443218576000151/si231.png)，`z[0]' = 2^k*(z[0] - 1) + 1`![Image](images/B9780443218576000151/si232.png)。然后 `x[0]' = 2^k*x[0]`![Image](images/B9780443218576000151/si233.png)，所以你的二次无理数乘以 `2^k`![Image](images/B9780443218576000151/si234.png)。这是公式 `[(11.7)](#Chp011_203-228_B9780443218576000151.xhtml#deq8)` 的直接推论。然而，如果 `y[0]' >= z[0]'`![Image](images/B9780443218576000151/si235.png)，这将不起作用，当 `k` 足够大时，这种情况总是会发生。所以你需要使用一组不同的（`y[0]'`，`z[0]'`）![Image](images/B9780443218576000151/si229.png)，使其满足 `x[0]' = floor(2^k*x[0])`![Image](images/B9780443218576000151/si237.png)。我在关于混沌动力系统的书籍 `[[4]](#Chp011_203-228_B9780443218576000151.xhtml#br0020)` 的第 5.3.3 节中描述了如何高效地做到这一点。

最后，这里的数字是指小数点右侧开始的二进制数字。你为起始数字选择的位置 `k` 可以是随机的：它可以取决于二次无理数。这使得逆向工程你的随机数字序列变得非常困难。

### 11.4.5 安全性与其他 PRNG 的比较

电子表格 [`strongprng.xlsx`](https://github.com/VincentGranville/Experimental-Math-Number-Theory/blob/main/Source-Code/strongprng.xlsx)（在 GitHub 上）将二次无理数 PRNG 与梅森旋转算法进行了比较。测试涉及 ![Image](images/B9780443218576000151/fx008.jpg) 个二次无理数，每行一个。根据接受规则，只使用了 4971 个。对于每一个，我计算了 400 个二进制数字，并按照方法论的建议跳过了前 100 个。所以总共有 4971 个块，每个块包含 300 个数字。对应梅森旋转算法的标签页具有相同的块结构和相同数量的数字：它是使用 `Python` 代码中的选项 `PRNG='Mersenne'` 生成的。D 列括号中的数字代表块 ID：对于二次无理数 PRNG 是数字 `b`，对于梅森旋转算法则没有特定含义。

我计算了一些汇总统计量：每列和每行的数字期望和方差，以及行之间、列之间的交叉相关性。结果符合预期，且在比较这两个 PRNG 时显示出显著的相似性。你会期望任何像样的 PRNG 都能通过这些基本测试，所以这不足为奇。你需要更复杂的测试来检测难以发现的偏离随机性的情况；这就是第 `[11.2.2](#Chp011_203-228_B9780443218576000151.xhtml#s0040)` 节进行素数测试的目的。`[图 11.4](#Chp011_203-228_B9780443218576000151.xhtml#f0040)` 显示了 5000 个相关值。它们在统计上与零无差异，并且是独立的，尽管它们对应按时间顺序生成的种子。实际上，它们的联合分布与梅森旋转算法产生的分布相同（图中未显示，但包含在电子表格中）。

无论使用梅森旋转算法还是二次无理数，压缩因子——基于应用于 150 万原始数字的 `zip` 工具——大致相同，接近 8。这是可达到的最差压缩因子：代表一个数字的每个字符（8 位）变成了 1 位信息。这意味着 `zip` 工具无法检测到数字中的任何模式，从而无法实现任何程度的真正压缩。

#### 11.4.5.1 重要评论

文献中很少有严肃的文章涉及利用无理数的数字来构建 PRNG。似乎由于计算复杂性和错误地认为这违背了随机性的非确定性本质，这一想法很早就被放弃了。我希望我的二次无理数 PRNG 能揭穿所有这些迷思。注意，曾有尝试利用混沌动力系统来构建 PRNG。例如，参见 `[[11]](#Chp011_203-228_B9780443218576000151.xhtml#br0055)` 和 `[[1]](#Chp011_203-228_B9780443218576000151.xhtml#br0005)`。我即将出版的关于动力系统的书详细探讨了许多新的相关方法。

此外，我的 PRNG 通过组合数千到数十亿个二次无理数，与**组合线性同余生成器** `[[Wiki](https://en.wikipedia.org/wiki/Combined_linear_congruential_generator)]` 有一些相似之处。它们避免了这些生成器面临的缺点。在同余生成器的背景下，组合用于增加周期和随机性。在二次无理数 PRNG 的情况下，周期总是无限的，目标是增加安全性，而不是随机性，因为仅用一个数字随机性就已经达到最大。此外，使用许多每个只有少量数字的二次无理数，比使用一个具有许多数字的数运行得快得多。另外，使用许多二次无理数可以利用分布式架构实现非常高效的实现。

最后，虽然发布随机数字表听起来像原始人的想法，但它服务于一个在现代科学研究和基准测试中已被遗忘的非常重要的目的——可复现性。如果你希望你的研究可复现，你可以自由地重用我的 Excel 电子表格。当然，如果你使用带有相同种子的 `Python` 代码，你会得到相同的数字。梅森旋转算法则不然：数字可能取决于你使用的 `Python` 版本。此外，二次无理数 PRNG 的一个优势是其可移植性，以及无论你使用何种编程语言，都能得到相同的数字。时间允许的话，我将发布一个大得多的表，至少包含一万亿位数字。在此期间，如果你需要这样的表，请随时发邮件至 [`vincentg@MLTechniques.com`](mailto:vincentg@MLTechniques.com) 联系我。

### 11.4.6 好奇的应用：一种新型彩票

以下应用需要实时生成大量伪随机数，速度越快越好。这些数字必须极好地模拟随机性。它将受益于使用二次无理数 PRNG。这个想法是创建一个虚拟的、市场中性的股票市场，人们用代币买卖股票。简而言之，一个合成股票市场，你用合成货币（代币）玩。另一种描述是彩票或猜数字游戏。你每笔交易支付费用（真钱），每次猜对，你会获得特定金额，也是真钱。参与者可以选择不同的策略，从保守且仅限于小收益和低波动，到激进且有极小机会赢大钱。
