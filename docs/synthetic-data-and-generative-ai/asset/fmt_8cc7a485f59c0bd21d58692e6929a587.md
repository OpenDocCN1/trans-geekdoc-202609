
### Another case worth investigating

Finally, another case worth investigating is as follows. Let `P` be the set of all primes, and `p[k]`![Image](images/B9780443218576000217/si112.png) be the `k`th prime with `p[1]` = 2![Image](images/B9780443218576000217/si32.png). Define `χ(p[2k+1])` = +1![Image](images/B9780443218576000217/si113.png) and `χ(p[2k])` = -1![Image](images/B9780443218576000217/si114.png). Then the product in formula [(17.4)](#Chp017_329-360_B9780443218576000217.xhtml#deq5) converges if `σ` > 0.5![Image](images/B9780443218576000217/si115.png) (prove it for `t` = 0![Image](images/B9780443218576000217/si25.png), using the fact that the product is alternating; see also [here](https://mathoverflow.net/questions/159534/does-this-alternating-euler-product-converge-for-all-res-0)). Thus the infinite product (which has no root) can be used to compute `η[P](z, χ)`![Image](images/B9780443218576000217/si88.png). But the convergence is not absolute. I expect that there is no root if 0.5 < `σ` < 1![Image](images/B9780443218576000217/si90.png). But I also expect that the hole is reduced to a single point (the origin), as in the standard case.

### 17.2.2.2 Probabilistic properties and conjectures

Here `P` is the set of all primes, and `χ(p)` = 1![Image](images/B9780443218576000217/si100.png) for all `p`. The Liouville function `λ(·)`![Image](images/B9780443218576000217/si116.png) and Möbius function `μ(·)`![Image](images/B9780443218576000217/si117.png), introduced in Section [17.2.1.1](#Chp017_329-360_B9780443218576000217.xhtml#s0040), have many interesting properties and open questions. Many are equivalent to or generalizing RH. Here I present here a brief summary; more can be found [here](https://mathoverflow.net/questions/391736/normal-numbers-liouville-function-and-the-riemann-hypothesis). Again, let `L(n)` = `λ(1)` + ⋯ + `λ(n)`![Image](images/B9780443218576000217/si118.png).

- The numbers `λ(k)`![Image](images/B9780443218576000217/si119.png), for positive integers `k`, are equal to -1 or +1 in equal proportions, thus averaging to zero. But due to a good head start with negative values, it takes a long time for `L(n)`![Image](images/B9780443218576000217/si83.png) to turn positive. In fact, the **Pólya conjecture** [[Wiki](https://en.wikipedia.org/wiki/P%C3%B3lya_conjecture)] claims that `L(n)`![Image](images/B9780443218576000217/si83.png) is always negative, but it was disproved in 1958. The smallest possible `n` satisfying `L(n)` > 0![Image](images/B9780443218576000217/si120.png), namely ![Image](images/B9780443218576000217/fx001.jpg), was found in 1980. The sign changes in `λ(k)` = ±1![Image](images/B9780443218576000217/si121.png) occur somewhat randomly, as in independent Bernoulli trials. If the +1 and -1 were truly randomly distributed with zero mean, they would satisfy the **law of the iterated logarithm** [[Wiki](https://en.wikipedia.org/wiki/Law_of_the_iterated_logarithm)]:

```
\underset{n\rightarrow\infty}{\lim\sup}\frac{|L(n)|}{\sqrt{n\log\log n}} = C,
```

![Image](images/B9780443218576000217/si122.png)(17.7)

for some constant `C` with 0 < `C` < ∞![Image](images/B9780443218576000217/si123.png). It is conjectured that this is not the case. In fact, the `λ(k)`![Image](images/B9780443218576000217/si119.png)'s cannot possibly be independent, not even asymptotically, since the function is completely multiplicative. But to prove RH, all that is needed is a weaker statement, the fact `` `$L(n)/\sqrt{n^{1 + \epsilon}}\rightarrow 0` ``![Image](images/B9780443218576000217/si124.png) as `n` → ∞![Image](images/B9780443218576000217/si125.png), for any `ε` > 0![Image](images/B9780443218576000217/si126.png). This is yet unproved. A similar conjecture exists for the Möbius function: the Mertens conjecture [[Wiki](https://en.wikipedia.org/wiki/Mertens_conjecture)], also implying RH, and thus yet unproved. See [[11]](#Chp017_329-360_B9780443218576000217.xhtml#br0055) for a stochastic version, based on random multiplicative **Rademacher functions** [[Wiki](https://en.wikipedia.org/wiki/Rademacher_distribution)], used as a substitute to emulate the “randomness” of the Möbius function.

- A stronger conjecture, yet not as strong as the law of the iterated logarithm, is this: the `λ(k)`![Image](images/B9780443218576000217/si119.png)'s behave like the binary digits of a **normal number** [[Wiki](https://en.wikipedia.org/wiki/Normal_number)]. In short, the number `` `$\nu = \sum_{k = 1}^{\infty}\lambda(k)2^{- k}` ``![Image](images/B9780443218576000217/si127.png) is normal. Of course, `ν` is irrational, otherwise `λ(·)`![Image](images/B9780443218576000217/si116.png) would be a periodic function. It is not yet known if `ν` is transcendental, though some closely related numbers are [[2]](#Chp017_329-360_B9780443218576000217.xhtml#br0010). The normality (or equivalently, ergodicity) of the sequence `{λ(k)}`![Image](images/B9780443218576000217/si128.png) would imply that the **Chowla conjecture**, itself stronger than RH, is true; see [[6]](#Chp017_329-360_B9780443218576000217.xhtml#br0030). But this is yet unproved.

- The numbers `μ(k)`![Image](images/B9780443218576000217/si82.png), for positive integers `k`, are equal to -1, 0, or +1. The proportion of those equal to zero is 1 - 6/`π`²![Image](images/B9780443218576000217/si129.png). This is because `μ(k)` = 0![Image](images/B9780443218576000217/si130.png) if and only if `k` has a square factor. It is well known and easy to prove that the proportion of **square-free integers** [[Wiki](https://en.wikipedia.org/wiki/Square-free_integer)] is 6/`π`²![Image](images/B9780443218576000217/si131.png). The proportions of `μ(k)`![Image](images/B9780443218576000217/si82.png)'s equal to -1 or -1 are identical, a consequence of **Dirichlet's theorem** [[Wiki](https://en.wikipedia.org/wiki/Dirichlet%27s_theorem_on_arithmetic_progressions)].

Finally, an application of **Kronecker's theorem** [[Wiki](https://en.wikipedia.org/wiki/Kronecker%27s_theorem)] leads to the following result: over time, for any fixed `σ`, the orbit of the Dirichlet `L`-function defined by formula [(17.5)](#Chp017_329-360_B9780443218576000217.xhtml#deq6) (assuming convergence) eventually fills a dense area in the complex plane. This is true whether the orbit is bounded or not, and whether it is has a “visible” hole or not. In other words, the image domain of `η[P](z, χ)`![Image](images/B9780443218576000217/si88.png) or `L[P](z, χ)`![Image](images/B9780443218576000217/si107.png) is a **dense set** [[Wiki](https://en.wikipedia.org/wiki/Dense_set)]. I provide an elegant proof of this fact in [Exercise 17.5](#Chp017_329-360_B9780443218576000217.xhtml#enun0035), using arguments similar to those used to prove its **universality property** [[Wiki](https://en.wikipedia.org/wiki/Zeta_function_universality)]. This implies that if 0.5 < `σ` < 1![Image](images/B9780443218576000217/si90.png), assuming `P` contains sufficiently many prime numbers, the Dirichlet eta function, regardless of `χ`, gets arbitrarily close to zero, even though it may never actually hit zero. In other words, in that case, the hole eventually shrinks to a single point.
