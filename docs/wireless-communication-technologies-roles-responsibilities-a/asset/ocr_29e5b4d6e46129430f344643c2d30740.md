Random Forest executes slow, and next to random forest Decision Tree executes in 0.354 seconds[44].

# 12.5 CONCLUSION

We suggested an integrated AI-SDN-IoMT architecture in this paper to forecast COVID-19 in patients. The sensors in IoMT equipments communicate with the smart system via the SDN network. To anticipate diseases, a machine learning-based forecasting model is constructed. Different machine learning models are implemented, and XGBoost stands out in regard to performance measures like Accuracy, Precision, Recall, F1 score, and ROC-AUC score. Furthermore, it is quicker to execute than other techniques.

We will add more machine learning models in the future, and multi-criteria decision making will be used to select the best model. In addition, we will look into privacy and security concerns.
