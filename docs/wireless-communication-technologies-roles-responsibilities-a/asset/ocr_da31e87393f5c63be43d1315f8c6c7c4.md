# 13.4.3.1 Latency

Latency has been found to be improving in the honeycomb 3d toroidal interconnection network, which has been found by analyzing the readings at different inter packet arrival delays. The Figure 13.35. is a comparison of the latencies observed in two different design patterns at the given inter packet arrival delay, i.e. time interval in simpler words in tornado traffic pattern.
