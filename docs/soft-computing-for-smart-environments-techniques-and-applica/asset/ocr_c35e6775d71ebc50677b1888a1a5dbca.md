**Step 16:** Determine the standardized decision matrix as exhibited in Eq. (1.23) for the beneficial criteria by using Eq. (1.24) and for the non-beneficial criteria by applying Eq. (1.25).

$S = [s_{ij}]_{m\times n}$  (1.23)

Beneficial criteria: $egin{cases} s_{ij} = \left( \dfrac{l_{ij}}{u_j^+}, \dfrac{m_{ij}}{u_j^+}, \dfrac{u_{ij}}{u_j^+} \right) \\ u_j^+ = \max_i u_{ij} \end{cases}$  (1.24)

Non-beneficial criteria: $egin{cases} s_{ij} = \left( \dfrac{l_j^-}{l_{ij}}, \dfrac{l_j^-}{m_{ij}}, \dfrac{l_j^-}{u_{ij}} \right) \\ l_j^- = \min_i l_{ij} \end{cases}$  (1.25)

**Step 17:** Calculate the weighted standardized decision matrix ($R$) by multiplying the weights achieved ($w_{\text{final}}$) with the standardized decision matrix ($s_{ij}$) as presented in Eqs. (1.26) and (1.27).
