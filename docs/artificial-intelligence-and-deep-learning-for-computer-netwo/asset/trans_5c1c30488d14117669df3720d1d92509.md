本研究使用了三个数据集来模拟交换机产生的流量：两个 CAIDA \[[15](#ch03.xhtml#ref3_15)\] 数据集和一个大学 \[[13](#ch03.xhtml#ref3_13)\] 数据集。这些数据集概述了骨干网络和商业网络流量。流量被分解为流。流是一个四元组，包括源 IP 地址、目的 IP 地址、源端口号和目的端口号。

我们将数据按时间间隔分解，使用 *N* 个数据点构建单变量时间序列 \[[16](#ch03.xhtml#ref3_16)\]。

### [3.7.2 评估指标](#ch03.xhtml#c_sec3_007_002)

**负载均衡率：** 负载均衡率计算控制器负载在时间 *t* 时与其理想值的变化 \[[6](#ch03.xhtml#ref3_6)\]。在本报告中，我们将控制器的理想负载视为系统的平均负载。

$\\frac{\\sum\_{j = 1}^{k}\\left( \\left| {L\_{c}(t) - L^{I}(t)} \\right| \\right)}{k}$

### [3.7.3 实验结果](#ch03.xhtml#c_sec3_007_003)

应用 Q-learning 之前，五个控制器 {*c*[0]*, c*[1]*, c*[2]*, c*[3]*, c*[4]} 在不同时间步的瞬时负载如 [图 3.5](#ch03.xhtml#fig3_5) 所示。控制器负载是指与控制器连接的交换机生成的流量数量。负载按 30 秒间隔（时间步）计算。本实验旨在展示网络流量的动态特性。从图中可以看出，控制器负载存在较大变化。这一结果证实了我们关于网络流量突发性的假设。

[图 3.5 使用 Q-learning 与 *ϵ*\-greedy 方法的控制器负载。](#ch03.xhtml#Ffig3_5)

基于 Q-learning 的方法与随机方法的负载均衡率对比如 [图 3.6](#ch03.xhtml#fig3_6) 所示。随机方法的负载均衡存在较大变化。在 Q-learning 与 ϵ-greedy 方法的情况下，负载均衡率的变化范围为 100000 到 700000，而随机方法的变化范围为 200000 到 1200000。结果表明，所提 Q-learning 方法可以限制负载均衡率的变化。此外，它还提高了负载均衡率。我们的方法还改善了控制器之间的负载均衡。Q-learning 方法的平均负载均衡率比随机方法低 30%。Q-learning 的解要么随机选择，要么取决于 Q 矩阵确定的最佳动作。在学习的早期阶段，Q 矩阵不具备太多智能。因此，随机过程优于最优动作。然而，随着学习过程的推进，随机动作的选择比例降低，而来自 Q 矩阵的最优动作被选择的比例提高。因此，所提方法在利用与探索之间取得了平衡，从而得到更好的解决方案。另一方面，随机策略仅进行探索。

![图 3.6 负载均衡率对比。](images/fig3_6.jpg)

两种方法中迁移交换机数量的对比如 [图 3.7](#ch03.xhtml#fig3_7) 所示。随机方法中迁移的交换机数量大约是 *ϵ*\-greedy 方法的三倍。交换机迁移涉及不同利益相关者之间交换控制消息的成本。结果表明，Q-learning 方法降低了交换机迁移成本和控制器之间的同步成本。这也意味着迁移时间减少。在本工作中，我们考虑基于降序调度选择交换机；因此，少量交换机从过载状态卸载以平衡系统。

## [3.8 结论与未来工作](#ch03.xhtml#c_sec3_8)

本章提出了一种采用知识平面来负载均衡软件定义网络中控制器的架构。知识平面采用强化学习，自适应地改变 SDN 中控制器与交换机之间的绑定。我们首先介绍 SDN 和 RL 的基础知识。为了便于使用 RL，我们使用马尔可夫决策过程重新表述了负载均衡问题。解决方案框架利用 Q-learning，这是一种广为人知的无模型强化学习技术。我们使用真实网络流量在实验中验证了所提方案。

我们将所提工作与随机方法进行了比较，使用了两个指标，即负载均衡率和迁移交换机数量。我们观察到，所提方案将控制器负载变化范围限制在 60% 以上的因子之内。这表明我们所提策略下系统的稳定性更高。同时，迁移交换机数量（开销）大约是随机方法的三分之一。在本章中，我们展示了如何将机器学习技术应用于解决 SDN 问题。未来，我们打算使用其他学习算法，如深度学习，来捕捉网络流量行为，并解决更复杂的 SDN 问题，例如控制器放置。
