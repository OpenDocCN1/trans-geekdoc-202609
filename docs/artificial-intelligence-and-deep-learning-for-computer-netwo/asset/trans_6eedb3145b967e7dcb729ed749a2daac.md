

现有的 IDS 能够检测信标帧伪造和接入点泛洪攻击，但无法检测去认证攻击和信标泛洪，这最终可能导致合法接入点拒绝服务。因此，本文提出了一种基于机器学习的方法来检测大量信标伪造。具体而言，我们通过在网络上发起伪造、泛洪和去认证攻击，捕获网络帧，并使用监督学习和深度学习模型对其进行分析来生成数据集。结果表明，我们的方法能够以 92% 的准确率检测信标伪造、泛洪和去认证等攻击。

## [2.2 问题陈述](#ch02.xhtml#c_sec2_2)

在本文中，我们提出使用监督学习和深度学习模型（如 `SVM`、`k-NN`、`random forest`、`MLP` 和 `CNN`）来分类多种类型的信标伪造。具体而言，我们通过在运行 Kali Linux 的虚拟机上使用 Python 脚本对 Wi-Fi 网络发起伪造攻击，生成 pcap 格式的数据集 \[[10](#ch02.xhtml#ref2_10)]。生成的数据集使用 `tshark` \[[11](#ch02.xhtml#ref2_11)] 基于静态分类规则转换为 csv 文件。然后对数据集进行检查，以检测和分类各种类型的信标攻击，例如伪造、泛洪和去认证。

## [2.3 相关工作](#ch02.xhtml#c_sec2_3)

现有工作已提出 IDS 和机器学习算法来检测和预测常见的网络攻击，例如 DDoS、中间人攻击等。然而，很少有方法研究管理帧来检测信标攻击。其中一些方法详细介绍如下。

Liu 等人 \[[12](#ch02.xhtml#ref2_12)] 基于位置和集中式监控检测无线传感器网络（WSN）中的虚假信标节点。但所提出的算法显示出较高的误报率，因此模型不适用。\[[13](#ch02.xhtml#ref2_13)] 和 \[[14](#ch02.xhtml#ref2_14)] 采用了类似的方法，作者提出了一种基于序列号对管理帧进行分类的理论方法。Ping Lu 等人 \[[15](#ch02.xhtml#ref2_15)] 提出了一种基于位置指纹的自适应方法来检测虚假接入点。然而，这种方法也导致了较低的准确率。Lovinger 等人 \[[16](#ch02.xhtml#ref2_16)] 提出了一种便携式方法，使用基于签名的方法检测网络中的去认证和虚假接入点，但需要额外的固件。\[[17](#ch02.xhtml#ref2_17)] 和 \[[18](#ch02.xhtml#ref2_18)] 通过实现时钟偏移检测了虚假接入点。但这种方法需要修改协议和接入点。Di Mauro 等人 \[[19](#ch02.xhtml#ref2_19)] 利用质询-响应认证协议在无线传感器网络中检测虚假 AP。Han 等人 \[[20](#ch02.xhtml#ref2_20)] 使用用户与 DNS 服务器之间的往返时间（RTT）来检测虚假 AP，尽管该模型在低流量和高流量期间分别能够提供 100% 和 60% 的准确率。无线嗅探器也可用于查找虚假 AP。然而，这些方法在公共/大面积区域部署成本高昂 \[[21](#ch02.xhtml#ref2_21),[22](#ch02.xhtml#ref2_22)]。

与现有方法相反，我们通过发起伪造、泛洪和去认证攻击并捕获网络流量来生成数据集。使用 `tshark` 从 pcap 文件中提取相关特征，并根据理论规则进一步分类。生成的数据集使用各种监督学习和深度学习模型（如 `SVM`、`k-NN`、`MLP`、`random forest` 和 `CNN`）进行分析，以分类不同的信标攻击。

## [2.4 模型简介](#ch02.xhtml#c_sec2_4)

在本节中，我们对所模拟的数学模型进行了简要介绍。

### [2.4.1 SVM](#ch02.xhtml#c_sec2_004_001)

`SVM` 用于二进制分类，通过构建由公式 2.1 给出的边际超平面，在数据点簇之间提出最优边界。

`H : w^(T)(x) + b = 0` (2.1)

数据点被迭代分类，以最小化对新测试点分类的错误。这是通过使用内核将特征向量 `ϕ(x)` 转换为高维空间来完成的。然后使用公式 2.2 对数据点进行分类。

`y[n][w^(T)ϕ(x[n])+b] ≤ 0∀n` (2.2)

### [2.4.2 k-NN](#ch02.xhtml#c_sec2_004_002)

`k-NN` 选择 `k` 个最近邻，并使用欧几里得距离（`d`）计算查询实例与其余样本之间的距离，如公式 2.3 所示。得到的值按顺序排列，并选择前 `k` 个点来确定最近邻 \[[23](#ch02.xhtml#ref2_23)]。

```
$d(p,q) = \\sqrt{\\sum\\limits\_{i = 1}^{n}{(q\_{i} - p\_{i})}^{2}}$ (2.3)
```

其中，

1. `p[i]` = 查询实例

2. `q[i]` = 考虑的第二个样本

### [2.4.3 随机森林](#ch02.xhtml#c_sec2_004_003)

随机森林是一种集成算法，它在不同的样本簇上构建决策树，并在分类数据点时采用多数投票。用于确定每个特征重要性的权重按公式 2.4 计算。

```
$RF\_{i} = \\frac{\\sum\_{j \\in alltrees}{norm\_{ij}}}{T}$ (2.4)
```

其中，

1. `RF[i]` = 从所有决策树计算出的特征 `i` 的重要性

2. `norm[ij]` = 树 `j` 中特征 `i` 的归一化特征重要性

3. `T` = 树的总数

### [2.4.4 多层感知机 (MLP)](#ch02.xhtml#c_sec2_004_004)

MLP 属于前馈神经网络类，它在有向图中连接多个层，从而通过节点提供信号路径。每个节点由非线性激活函数 `y = f(WxT + b)` 表征。当观察到分类错误时，每个节点的权重按公式 2.5 更新。

```
weight = weight + L * (y[exp] − y[pred]) * x (2.5)
```

其中，

1. `L` = 学习率

2. `y[exp]` = 输出的期望值

3. `y[pred]` = 输出的预测值

4. `x` = 输入

### [2.4.5 CNN](#ch02.xhtml#c_sec2_004_005)

CNN 属于处理具有网格拓扑的数据的神经网络类。每个卷积层包含一系列称为内核的滤波器。内核是整数（像素）矩阵，用于将输入向量重塑为与内核相同的大小，如公式 2.6 所示。此特性称为步长。内核和重塑向量中的相应像素相乘以生成特征图。然后根据特征图值学习和分类数据。

```
$W\_{out} = \\frac{W - F + 2P}{S} + 1$ (2.6)
```

其中，

1. `W[out]` = 输出体积的大小

2. `W` = 输入的大小

3. `F` = 空间大小

4. `P` = 填充

5. `S` = 步长
