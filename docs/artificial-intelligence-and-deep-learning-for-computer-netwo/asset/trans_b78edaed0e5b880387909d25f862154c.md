

# 网络恐怖主义

在美国，关键基础设施被定义为“对美国至关重要的资产、系统和网络，无论是物理的还是虚拟的，其瘫痪或破坏将对安全、国家经济安全、公共健康或安全，或其任何组合产生严重影响” \[[4](#ch06.xhtml#ref6_4)\]。提供电力和水、控制航空交通或支持金融交易的基础设施被视为“关键生命维持基础设施”。所有这些都直接依赖于底层通信和网络基础设施 \[[5](#ch06.xhtml#ref6_5)\]。敌人（网络专家）可以通过网络空间摧毁一个国家的关键基础设施。这可以通过直接对国家电网发起网络攻击来实现，也可以通过拒绝服务攻击获取秘密信息来间接实现。此类攻击的一个例子是2007年4月/5月对爱沙尼亚的攻击。保护此类关键基础设施是网络安全的重要组成部分，并被列入国家网络安全战略中的重要国家任务。

# 数字媒体

娱乐行业是受未经授权的信息共享（未经操纵）影响最大的行业之一，例如电影、音乐和其他形式的数字媒体。虽然这种未经授权的共享不一定违反共享数字媒体的完整性、机密性或可用性，但这直接影响了受版权保护的数字媒体合法所有者的经济损失。

除此之外，如今每个人的日常生活都包含大量的数字媒体交换和共享，尤其是数字图像和视频。例如，YouTube 上每分钟上传了 `500+` 小时的视频内容 \[[6](#ch06.xhtml#ref6_6)\]，Facebook 用户每小时上传了 `14.58` 百万张图片 \[[7](#ch06.xhtml#ref6_7)\]，根据2017年收集的数据，Instagram 上每天分享了 `8.95` 百万张图片和视频 \[[8](#ch06.xhtml#ref6_8)\]。

在共享的信息中，大量信息被操纵（故意创建虚假信息），向观众提供错误信息。根据麻省理工学院（MIT）研究人员的一份报告 \[[9](#ch06.xhtml#ref6_9)\]，在2019年印度人民院选举期间，WhatsApp 群组中共享的照片大约每 `八` 张中有 `一` 张具有误导性。在2018年10月至2019年6月期间，汇编了来自25万用户的总共 `5` 百万条消息。观察发现，52% 的所有消息都是视觉类，包括35% 的图片和17% 的视频，且所有共享图片中有13% 具有误导性 \[[9](#ch06.xhtml#ref6_9)\]。在本章中，我们将详细讨论图像操纵及其检测技术。本章的动机和主要目标将在下一节中介绍。

## [6.1.1 动机与目标](#ch06.xhtml#c_sec6_001_001)

近年来，许多研究人员专注于数字多媒体内容安全和保护的各个领域，例如数字多媒体版权管理、数字多媒体身份验证以及伪造检测。为了解决这些问题，在过去几年中开发了许多先进的安全措施和技术；其中最广泛使用的是 `digital signature` 和 `digital watermarking` \[[10](#ch06.xhtml#ref6_10)\]。

数字图像和视频可以使用广泛可用的图像和视频编辑工具轻松操纵。在感知上，已经无法区分专业操纵（伪造）的图像和视频与真实的图像和视频。图像操纵的示例显示在 [图 6.1](#ch06.xhtml#fig6_1)。[图 6.1(a)](#ch06.xhtml#fig6_1) 展示了一张真实图像，其中共有四匹马，而 [图 6.1(b)](#ch06.xhtml#fig6_1) 展示了一张伪造（操纵）的图像，其中添加了两匹额外的马。使用传统的多媒体安全和保护技术，包括 `digital signature` 和 `digital watermarking`，我们可以检测多媒体的真实性。此类技术依赖于一些外部信息，例如 `digital signature` 或 `watermark`，并且外部信息是通过某种方式预处理多媒体数据计算得出的。此外，此类技术需要嵌入式硬件芯片和软件来将 `digital signature` 或 `watermark` 嵌入图像和视频中。此外，许多数码相机不支持数字水印或数字签名。

另一方面，盲法医措施领域是新兴且仍在发展的领域，它不需要任何预处理步骤，即不需要嵌入数字签名或水印。通过分析图像的内在特征 \[[12](#ch06.xhtml#ref6_12),[13](#ch06.xhtml#ref6_13)\]，这些特征是操纵操作本身留下的，它可以检测被篡改的图像和视频。因此，盲法医技术是一种完全基于后处理的操作。本章旨在通过盲数字法医措施调查图像伪造检测问题。

最常见的盲数字图像伪造检测技术包括 `copy-move forgery detection` \[[14](#ch06.xhtml#ref6_14)\]、`image splicing forgery detection` \[[15](#ch06.xhtml#ref6_15)\]、`image retouching detection` \[[16](#ch06.xhtml#ref6_16)\] 和 `joint photographic experts group (JPEG) double/multiple compression detection` \[[17](#ch06.xhtml#ref6_17)\]。

`Copy-move forgery` 也称为区域复制伪造，其中图像的区域被复制并粘贴到同一图像中的另一个目标区域，以模糊或重复图像中的一个或多个重要对象。与复制-移动伪造不同，`image splicing` \[[18](#ch06.xhtml#ref6_18)\] 包含多个图像的组合。`Image retouching` \[[16](#ch06.xhtml#ref6_16),[19](#ch06.xhtml#ref6_19)\] 无非是通过编辑某些图像像素（如红眼去除、锐度、色调调整等）来增强图像质量。此类修改通常可以通过调查图像自然统计特性的不一致性来检测 \[[19](#ch06.xhtml#ref6_19),[20](#ch06.xhtml#ref6_20),[21](#ch06.xhtml#ref6_21)\]。

`JPEG double/multiple compression detection` \[[13](#ch06.xhtml#ref6_13),[17](#ch06.xhtml#ref6_17),[22](#ch06.xhtml#ref6_22)\]（JPEG 压缩图像）在进行伪造之前必须先解压缩。进行伪造后，生成的图像可能会再次压缩以存储为 JPEG 格式。因此，当 JPEG 图像被修改/编辑时，由于将编辑后的图像连续保存回内存，会发生后续压缩。因此，可以推断双重或多重压缩的图像是伪造的。但是，不能保证双重或多重 JPEG 压缩的图像总是伪造的。然而，不同程度的 JPEG 压缩是伪造的一个良好指标。

本章的主要目标是提出一个用于基于 JPEG 双重压缩的图像操纵（伪造）检测的盲法医框架。在下一节中，我们将介绍本章的贡献。
