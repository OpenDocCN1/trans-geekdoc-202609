## 6.1 引言

近年来，网络安全受到了研究人员的广泛关注。网络安全是保护我们宝贵数字信息的框架。它为计算机、移动设备、服务器、数字电子系统和数据提供必要的防护，以抵御恶意攻击。然而，网络安全涵盖大量主题；例如，资源利用、未经授权的访问以及操纵数字数据。接下来，我们简要介绍几个场景 \[[1](#ch06.xhtml#ref6_1)\] 作为示例：

网络欺凌– 在我们的现代社会中，网络欺凌已成为主要威胁 \[[2](#ch06.xhtml#ref6_2)\]。据 \[[2](#ch06.xhtml#ref6_2)\] 报告，数字技术越来越多地被用于欺凌、“造成尴尬、引发骚扰和暴力，并造成心理伤害。”这可能导致“对受害者产生严重和负面的影响。”然而，在网络空间中被欺凌并不构成完整性、保密性或信息的丧失。相反，此类活动的目标是用户本人。

家庭自动化– 随着电子技术以及信息和通信技术（ICT）先进领域的发展，大量家庭自动化应用 \[[3](#ch06.xhtml#ref6_3)\]，如集成家庭安全系统、电视机、热水器等，正在迅速增加。其中许多应用具有基于 Web 的控制系统，允许从外部进行控制。不幸的是，这种基于 Web 的控制系统增加了未经授权访问此类系统的风险，并可能造成伤害。这种伤害的范围可以从“恶作剧”（如切换冰箱）到严重犯罪，例如关闭安全系统以入室盗窃或其他不当行为。
