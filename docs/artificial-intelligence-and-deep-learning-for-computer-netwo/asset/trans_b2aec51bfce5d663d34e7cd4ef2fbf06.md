

在我们的离散时间环境模型中，时间被划分为时隙，这些时隙具有固定或可变长度，且已知其平均值。我们假设队列的容量为 `K` 个数据包，阈值为 `L`。当数据包数量超过 `L` 的值时，超出的数据包将被丢弃。令时间由 `t` = 0, 1, 2, … 索引，我们将 [`t` − 1, `t`] 定义为时间窗口 `t` 的间隔。现在，我们定义以下符号。令 `D̂`[`t` + 1] 为 [`t`, `t` + 1] 上的目标平均延迟，`D`[`t`] 为 [`t` − 1, `t`] 上的测量平均延迟，`L`[`t`+1] 为 [`t`, `t` + 1] 上的队列阈值，`α`[`t`] 为 [`t` − 1, `t`] 上的平均数据包到达率，`β` 为队列的服务率，`W`[`t`+1] 为 [`t`, `t` + 1] 上的流量调度指标。在时隙 [`t`, `t` + 1] 中，我们为流量 `j` 定义一个指标 `W`[`t` + 1]^(`j`)，该指标基本上对待调度流量的重要性施加一个权重。`W`[`t` + 1]^(`j`) 在 [第 4.3.4 节](#ch04.xhtml#sec4_003_004) 中定义。

#### [4.3.1.1 NB-PTS 的解决方案方法](#ch04.xhtml#c_sec4_003_001_001)

基于上述排队模型，我们将 NB-PTS 的解决方案方法设计为 *三个阶段*，如下所示：

1.  **Phase-**1: 队列阈值的估计 ([第 4.3.2 节](#ch04.xhtml#sec4_003_002)) 和目标平均延迟的计算 ([第 4.3.3 节](#ch04.xhtml#sec4_003_003))

2.  **Phase-**2: 对待调度流量施加权重的指标的计算 ([第 4.3.4 节](#ch04.xhtml#sec4_003_004))

3.  **Phase-**3: 基于阶段 2 中计算的指标值进行流量调度 ([第 4.3.6 节](#ch04.xhtml#sec4_003_006))

对于队列阈值的估计，我们采用了一种在线学习机制。这是因为队列阈值高度依赖于当前信道条件和流量量，必须由发射器处理；因此，该阈值的值需要自适应和动态地选择，以便将数据包丢弃的概率最小化。在这方面，`ϵ`-贪婪 \[[23](#ch04.xhtml#ref4_23)\] 策略已被采用作为在线学习机制。

#### [4.3.1.2 目标平均延迟的推导](#ch04.xhtml#c_sec4_003_001_002)

在我们的系统中，我们使用两状态马尔可夫调制伯努利过程 (MMBP-2) 作为到达过程，以提供到达率的随机性，这是 IIoT 流量的常见特征 \[[4](#ch04.xhtml#ref4_4)\]。这可以扩展到 m 状态 MMBP。在每个状态中，到达过程占据几何长度的时间槽，即，一个过程的服务持续时间是时隙持续时间的整数倍。在我们为控制策略提出的离散时间排队模型中，队列具有 `K` 个数据包的有限等待空间，包括正在服务中的数据包。平均到达率和平均队列长度在每个时间窗口 `t` 上计算，然后利用这些信息来测量下一个时间窗口 `t` + 1 的 `L` 值，以将时间延迟绑定在所需值。通过调整阈值，进而我们控制传入流量的调度。

在排队模型的每个状态中，在一个时间槽中发生到达的概率遵循伯努利过程。它通过两状态马尔可夫过程变化，并且与到达过程独立。因此，该模型遵循 MMBP/Geo/1/K 队列。然而，时间窗口的长度应远小于到达过程停留在同一状态的平均时间。因此，在稳态下，该模型可以近似为最大时间窗口上的 Geo/Geo/1/K 队列。这意味着到达流量可以被视为遵循伯努利过程，除了到达过程发生状态变化的少数时间窗口之外。[图 4.1](#ch04.xhtml#fig4_1) 显示了 Geo/Geo/1/K 队列的状态转换模型，其中阈值位于 `L` = `K` − 1 处，`α` 通常是平均数据包到达率。队列长度过程具有有限状态空间，并遵循马尔可夫链。这个马尔可夫链是非周期的、不可约的、非零复发的，并具有一个唯一的概率分布 \[[24](#ch04.xhtml#ref4_24)\]。

令 `α` ≠ `β`，首先我们假设 `L` = `K` − 1。然后我们将 `L` 推广为 `L` = `K` − `i`，即，我们可以将阈值调整到传输队列中的任何位置。如 [图 4.1](#ch04.xhtml#fig4_1) 所示，令状态由 `q[0]`、`q[1]`、`q[2]` 等表示。从状态转换图 ([图 4.1](#ch04.xhtml#fig4_1))，具有 `L` = `K` − 1 的离散时间有限队列可以表示如下：

```
\\begin{array}{lll} q\_{0} & = & {q\_{0}(1 - \\alpha) + q\_{1}\\lbrack\\beta(1 - \\alpha)\\rbrack} \\\\ q\_{1} & = & {q\_{0}\\alpha + q\_{1}\\lbrack\\alpha\\beta + (1 - \\alpha)(1 - \\beta)\\rbrack + q\_{2}\\lbrack\\beta(1 - \\alpha)\\rbrack} \\\\ \\end{array}
```

一般来说，对于 `i` = 2, 3, …, `K` − 1，我们有

```
\\begin{array}{lll} q\_{i} & = & {q\_{i - 1}\\lbrack\\alpha(1 - \\beta)\\rbrack + q\_{i}\\lbrack\\alpha\\beta + (1 - \\alpha)(1 - \\beta)\\rbrack + q\_{i + 1}\\lbrack\\beta(1 - \\alpha)\\rbrack} \\\\ q\_{K - 2} & = & {q\_{K - 3}\\lbrack\\alpha(1 - \\beta)\\rbrack + q\_{K - 2}\\lbrack\\alpha\\beta + (1 - \\alpha)(1 - \\beta)\\rbrack + q\_{K - 1}\\beta} \\\\ q\_{K - 1} & = & {q\_{K - 2}\\lbrack\\alpha(1 - \\beta)\\rbrack + q\_{K - 1}(1 - \\beta)} \\\\ \\end{array}
```

通过递归求解这些方程并假设 $\\gamma = \\frac{\\alpha(1 - \\beta)}{\\beta(1 - \\alpha)}$，我们可以用 `q`[0] 表示平衡概率，如下所示：

```
q\_{i} = q\_{0}\\frac{\\gamma^{i}}{\\left( {1 - \\beta} \\right)},\\mspace{9mu} 1 \\leq i \\leq K - 2
```
(4.1)

对于 `i` = `K` − 1，我们有

```
q\_{K - 1} = q\_{0}\\gamma^{(K - 1)}\\frac{\\left( 1 - \\alpha \\right)}{\\left( 1 - \\beta \\right)}
```
(4.2)

通过归一化方程，我们得到 $\\sum\_{i = 0}^{K - 1}{q\_{i} = 1}$。因此，`q`[0] 可以按如下计算：

```
q\_{0} = \\frac{(1 - \\beta)(1 - \\gamma)}{1 - (1 - \\gamma)(\\beta + \\alpha\\gamma^{(K - 1)}) - \\gamma^{K}}
```
(4.3)

现在，我们求有限队列长度过程的生成函数，它由 $P(z) = \\sum\_{i = 0}^{K - 1}{q\_{i}z^{i}}$ 给出。即

```
P(z) = \\frac{q\_{0}}{(1 - \\beta)}\\left\\lbrack \\frac{1 - (1 - \\gamma z)(\\beta + \\alpha\\gamma^{K - 1}z^{K - 1}) - {(\\gamma z)}^{K}}{1 - \\gamma z} \\right\\rbrack
```
(4.4)

接下来，我们使用利特尔法则求平均队列等待时间，该法则指出系统中数据包的平均数等于数据包平均等待时间与系统中数据包平均到达率的乘积 \[[25](#ch04.xhtml#ref4_25)\]。对于 `L` = `K` − 1，我们通过对 `P` (`z`) 在 `z` = 1 处求一阶导数来计算该队列的平均队列长度 (MQL)。通过这种方式，我们可以继续使用 `L` = `K` −2, `K` −3, …，并可以找到 MQL 方程的一些规律。这意味着阈值 `L` 可以放置在有限队列的任何位置。因此，对于 `L` = `K` − 1，我们有

```
P^{(1)}\\left( 1 \\right) = \\frac{\\gamma\\left\\lbrack {1 - L\\alpha\\gamma^{L - 1} + \\left( {2L\\alpha - \\left( {L + 1} \\right)} \\right)\\gamma^{L} - \\left( {L\\alpha - L} \\right)\\gamma^{L + 1}} \\right\\rbrack}{(1 - \\gamma)\\left\\lbrack {1 - \\left( {1 - \\gamma} \\right)\\left( {\\beta + \\alpha\\gamma^{L}} \\right) - \\gamma^{L + 1}} \\right\\rbrack}
```
(4.5)
