[图 5.7](#ch05.xhtml#fig5_7) 显示了用于预处理技术的恶意数据集的物联网网络通信，以去除噪声数据和空帧。噪声是指不符合所需格式的内容，空帧是指特定帧中不存在数据。为处理噪声数据，使用词错误率（WER）和句子错误率（SER）\[[3](#ch05.xhtml#ref5_3)\]。WER 表示实际数据中的噪声水平。这些通过给定噪声数据与特定语言之间的比较来测量。这表示为词级距离。这是通过应用动态规划完成的，如方程（5.1）所示。

`WER = (Sub + Del + Ins) / N` (5.1)

其中 Sub 表示替换，Del 表示删除的数量，Ins 表示插入，N 表示给定序列中的总词数。预处理后，将数据发送到特征提取技术。

特征提取技术对于检测数据集中的恶意性非常重要。这些代表实际数据集的重要特征。这些特征对于在 \[[7](#ch05.xhtml#ref5_7)\] 和 \[[5](#ch05.xhtml#ref5_5)\] 中预测的不同类型的普通数据和恶意数据是不同的。

然后，使用深度学习技术检测线性数据集中的恶意漏洞。如今，深度学习技术几乎用于所有应用程序。这些技术使用机器学习模型用于不同的实时应用程序。在本章中，基于数据集的 LSTM 深度神经网络（DNN）模型中的漏洞检测深度学习技术。LSTM（长短期记忆）是一个强大的 DNN 模型，是 RNN（循环神经网络）的修改版本。该模型提供了避免长期依赖问题的功能。

LSTM 的基本结构如 [图 5.7](#ch05.xhtml#fig5_7) 所示。

### [5.3.3 LSTM 算法](#ch05.xhtml#c_sec5_003_003)

1. 使用 sigmoid 层和先前的隐藏层以及当前输入值来决定从单元状态输出的信息。输出在 1 或 0 之间，其中 1 表示保留全部信息，0 表示忽略信息。

2. 识别或决定存储在单元中的新信息。这分为两个阶段完成。在第一阶段，决定更新哪些值。这是通过 sigmoid 层完成的。在下一阶段，tanh 层决定要添加到单元中的新值，如 [图 5.8](#ch05.xhtml#fig5_8) 所示。

3. 使用先前状态计算的新值更新单元状态，如 [图 5.8](#ch05.xhtml#fig5_8) 所示。
