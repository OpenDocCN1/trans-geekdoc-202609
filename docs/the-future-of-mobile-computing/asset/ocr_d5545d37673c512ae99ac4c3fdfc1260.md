+   - Sentiment Analysis Component: Utilizing natural language processing, this component analyses written communication (chat messages, forum posts) for sentiment and emotional tone. It helps identify students’ emotional states and overall satisfaction (Kosheleva et al., 2018).

Before analysis and integration, the raw data collected from different monitoring techniques undergo preprocessing to ensure consistency, accuracy, and compatibility across various data sources. Key aspects of data integration include API Integration, Data Mapping, Data Synchronization, Dashboard Integration etc(Hooshyar, D, et al., 2020).
