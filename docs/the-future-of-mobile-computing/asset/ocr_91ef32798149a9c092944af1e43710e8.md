# Abstract

When we talk about mobile computing, we are referring to the collection of information technology systems, products, services, and operational strategies and processes that make it possible for end users to access computation, information. The word “mobile” may also be used to refer to access in a fixed location via the use of equipment that users are able to move about as required but that stays stationary while it is performing its function.
