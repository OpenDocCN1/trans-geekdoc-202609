- Edge Operating Systems: Edge operating systems are specifically designed for edge devices, providing lightweight, resource-efficient, and secure operating environments. These operating systems optimize power consumption, offer robust security features, and often support containerization and virtualization technologies for efficient execution of edge applications.
- Edge AI: The term “edge AI” refers to the incorporation of artificial intelligence (AI) technologies into edge devices, including machine learning (Chilukuri, Prathima et al., 2023) and deep learning. Edge AI gives edge devices the ability to process intelligent data locally, do predictive analytics, and make decisions without constantly relying on cloud connectivity.
- Edge Security: The main goals of edge security are to guard against cyberattacks, illegal access, and data breaches for edge devices, communications, and data. It includes secure protocols, encryption, access control methods, and secure boot procedures to guarantee the confidentiality and integrity of data processed at the edge.
- Fog Computing: Fog computing extends edge computing challenges by introducing fog nodes, which are sited between the edge and the cloud. Fog nodes provide additional computing and storage resources, enabling the execution of complex and resource-intensive applications at the edge.
- Edge-to-Cloud Integration: Edge computing often works in conjunction with cloud computing, necessitating protocols, APIs, and data synchronization mechanisms for seamless communication, data sharing, and workload offloading between edge devices and cloud infrastructure.

- **Enhanced Privacy and Security:** Data to be processed and analyzed locally, edge computing eliminates the need to send sensitive data to centralized cloud environments. By reducing the amount of sensitive data that is exposed to possible risks related to data transmission and cloud storage, this localized approach improves security and privacy. By limiting the data’s geographic scope, it also makes compliance with data protection laws possible.
- **Edge Intelligence and Real-time Analytics:** Devices at the edge can now process and analyse data intelligently thanks to edge computing. Edge devices have the capability to extract valuable insights from data in real-time by utilising advanced analytics algorithms, machine learning, and artificial intelligence. Applications like anomaly detection, personalised user experiences, predictive maintenance, and contextual decision-making based on local data are made possible by EI.
- **Offline Operation and Resilience:** Edge computing can operate in offline or partially connected environments. This is especially useful in situations where there is no guarantee of constant cloud connectivity, such as remote locations or areas with intermittent network coverage. Edge devices can function independently, executing critical tasks and storing data until connectivity is restored, ensuring uninterrupted operation and improved resilience.
- **Scalability and Distributed Architecture:** Edge computing allows for distributed processing and storage capabilities across multiple edge devices or nodes. This distributed architecture provides scalability and flexibility, as additional devices can be easily added or removed from the network. It also improves fault tolerance, as a failure in one edge device or node does not disrupt the entire system.
- **Edge-Cloud Collaboration and Hybrid Architectures:** Edge computing complements cloud computing by enabling efficient collaboration between edge devices and cloud infrastructure. Hybrid architectures (Chilukuri, Prathima et al., 2023) that leverage both edge and cloud resources can be designed to balance computational requirements, storage needs, and network constraints. This enables workload offloading, data synchronization, and seamless integration between the edge and the cloud for optimal resource utilization.

Edge networking introduces certain challenges, such as managing a distributed network infrastructure, maintaining security across multiple locations, and coordinating data synchronization and consistency between edge devices and centralized systems. These opportunities (Xue H et al., 2020) offered by edge computing have the potential to revolutionize various industries, including manufacturing, healthcare, transportation, energy, retail, and smart cities. By harnessing the power of edge computing, organizations can unlock new levels of efficiency, responsiveness, and innovation in their operations and services.

The technology of edge computing offers many opportunities, but it also comes with a set of difficulties and an intriguing range of potential future developments. Its capacity to process and analyze data closer to the source opens up opportunities by lowering latency, facilitating real-time decision-making, and improving overall system performance. It makes it easier for AI and machine learning to be integrated at the edge, enabling uses like driverless cars, smart cities, and customized experiences.

However, several issues require attention. Scalability, connectivity, security, and data management pose challenges that need to be addressed. Managing a large number of distributed edge devices, ensuring robust connectivity, securing sensitive data, and optimizing resource utilization are critical aspects. Standardization, interoperability, and efficient orchestration and management systems are necessary for seamless integration and collaboration within the edge ecosystem. Looking ahead, future trends in edge computing include the integration of 5G networks, enabling ultra-low latency and high-bandwidth connectivity. Edge AI and machine learning will flourish, allowing real-time processing and decision-making on edge devices. The edge-to-cloud continuum will enable dynamic workload distribution, while edge security measures will strengthen to protect against cyber threats and preserve data privacy. The concept of Edge-as-a-Service will emerge, providing on-demand access to edge computing resources and capabilities. Federated edge computing and federated learning models will enable collaboration and knowledge sharing while preserving data privacy. Industry-specific edge solutions will continue to evolve, addressing the unique needs of various sectors.

Effective edge management and orchestration frameworks will be developed to handle the scale and complexity of edge deployments. These frameworks will enable centralized control, monitoring, and automation, optimizing resource allocation and ensuring seamless integration.

## Present Issues of Edge Computing

Addressing issues in edge computing requires collaborative efforts from industry stakeholders, including standardization bodies, device manufacturers, network providers, and software developers (Akula CS et al., 2020). Some of the issues are scalability, connectivity, security, data management, standardization and interoperability, orchestration and management and energy efficiency.

Edge computing involves deploying numerous computing devices across a distributed network, which can pose challenges in terms of scalability. Managing a large number of edge devices and ensuring their seamless integration into the overall system can be complex. Connectivity: Edge computing relies on robust and reliable network connectivity between edge devices and centralized systems. In remote or rural areas with limited network infrastructure, maintaining consistent connectivity becomes a significant challenge.

Edge devices often process and store sensitive data, making them potential targets for cyberattacks. Securing edge devices against unauthorized access, data breaches, and malware attacks is crucial. Additionally, managing security updates and patches across a vast number of distributed devices can be challenging (Salman et al., 2020). Edge computing generates vast amounts of data, and managing this data efficiently poses challenges. Determining what data to process and store locally versus sending it to the cloud for analysis and storage requires careful consideration. Data governance, data privacy, and compliance with regulations add additional complexity to data management in edge computing. Resource constraints: Edge devices typically have limited processing power, memory, and storage capacities. Optimizing resource utilization and executing computationally intensive tasks within the constrained resources of edge devices can be a significant challenge.

The edge computing landscape is currently fragmented, with various vendors offering different edge solutions. Lack of standardized interfaces, protocols, and interoperability between edge devices, platforms, and cloud systems hinders seamless integration and limits the potential for collaboration and innovation. Managing a distributed edge infrastructure, monitoring device health, and ensuring smooth coordination and synchronization among edge devices require efficient orchestration and management systems. Developing robust management frameworks that can handle the scale and complexity of edge deployments is an ongoing challenge.
