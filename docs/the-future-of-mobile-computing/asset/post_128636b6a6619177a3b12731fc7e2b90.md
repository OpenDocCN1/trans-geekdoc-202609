
- **Latency:** Latency is a critical metric that measures the delay between a request and the corresponding response in edge computing systems. Low latency is essential for time-sensitive applications such as remote surgery, telemedicine and remote healthcare, finance trading, smart grid and energy management, emergency response and public safety etc.
- **Throughput:** Throughput refers to the rate at which data can be processed or transmitted in edge computing systems. It quantifies the system’s capacity to handle a large volume of data efficiently. Higher throughput ensures faster data processing and improved system performance.
- **Reliability:** Reliability assesses the system’s ability to consistently deliver services without disruptions or failures. It takes into account factors such as fault tolerance, redundancy, and failover mechanisms (Jain and Smaranika, 2019). High reliability is crucial for mission-critical applications to ensure uninterrupted operation.
- **Scalability:** Scalability measures how well a system manages more devices, users, and data without slowing down. It evaluates how well the edge infrastructure can adapt to changing workloads and resource demands.
- **Resource Utilization:** Efficient and effective utilization of available resources is critical in an edge computing system as it supports time-sensitive applications. It involves maximizing the usage of computational resources, storage capacity, network bandwidth, and other system resources to achieve optimal performance, minimize wastage, and ensure cost-effectiveness. Optimal resource utilization ensures efficient use of available resources, minimizing wastage and maximizing system performance.

## Benchmarking in Edge Computing

Benchmarking is an essential practice in performance evaluation, providing standardized procedures and datasets for comparing and evaluating the performance of edge computing systems. The distributed and heterogeneous nature of edge environment presents unique challenges to the design of benchmarks for edge computing. Researchers are developing benchmark suites that encompass various edge computing components, including edge devices, edge servers, and network connectivity, to capture the performance characteristics comprehensively (Hao et al., 2018).

Benchmarking also involves defining realistic workloads that simulate real-world scenarios and application requirements. These workloads help evaluate the system’s performance under different conditions, such as varying data volumes, arrival rates, and processing demands. Realistic workload generation techniques, such as trace-based approaches or synthetic workload generators, are employed to ensure accurate performance evaluations.

Furthermore, benchmarking frameworks consider the diversity of edge computing applications and their specific requirements. For example, benchmarks may focus on latency-sensitive applications like video streaming, latency-insensitive applications like batch processing, or a combination of both. This approach enables targeted performance evaluation based on the application domain and its associated metrics.

## Simulation and Modeling in Performance Evaluation

Simulation and modeling techniques are widely used in performance evaluation of edge computing systems. Simulations allow researchers to emulate complex edge architectures and analyze their performance under different conditions. They provide a cost-effective and controlled environment for testing various configurations, algorithms, and workload scenarios. Simulation frameworks like CloudSim, iFogSim, and EdgeCloudSim have been developed specifically for edge computing research (Sonmez et al., 2018; Gupta et al., 2017).

Modeling, on the other hand, involves creating mathematical or analytical models that capture the behavior and performance characteristics of edge computing systems. Models can be used to predict system performance, optimize resource allocation, and evaluate different design choices. Analytical models, queuing models, and stochastic models are commonly used to analyze and optimize various aspects of edge computing performance.

## Challenges in Performance Evaluation

Edge environment is inherently distributed and dynamic in nature. It presents several challenges in terms of performance evaluation. Some key challenges are discussed below.

- **Heterogeneity:** Edge computing encompasses diverse devices, networks, and software platforms, leading to heterogeneity in performance characteristics. Developing evaluation methodologies that consider this heterogeneity and provide accurate performance insights is a challenge.
- **Scalability:** Evaluating scalability of edge computing systems is challenged by dynamic nature of edge networks. Scaling the evaluation methodologies to capture large-scale edge deployments is a significant challenge.
- **Realistic Workload Generation:** Generating realistic workloads that capture the diversity of edge computing applications, data volumes, and processing demands is a complex task. Workload generation techniques should accurately represent real-world scenarios to ensure meaningful performance evaluations.
- **Dynamic Resource Allocation:** Edge computing involves dynamic resource allocation to optimize performance and energy efficiency. Developing evaluation methodologies that capture dynamic resource allocation strategies and their impact on system performance is a research challenge.

## Research Trends in Edge Computing

Due to its ability to meet the growing demands of data-intensive and time-sensitive applications, edge computing has garnered significant attention. As a result, researchers worldwide are actively investigating various aspects of edge computing, including architectural design, resource management, security, data analytics, and application development. These research endeavors aim to push the boundaries of edge computing and capitalize on its promises for enhanced performance, scalability, and efficiency.

## Convergence of Edge and Artificial Intelligence

One prominent research trend in edge computing is integration of AI at network edge. Researchers are exploring ways to enable intelligent decision-making, predictive analytics, and real-time analytics directly at the edge (Zhou et al., 2019; Harth et al., 2018). This can be achieved by deploying lightweight AI models and algorithms on edge devices.

## Edge Computing for IoT

IoT is a key domain where edge computing plays a vital role. Many customized edge computing solutions have been developed using IoT, enabling local analytics, at the edge (Chakraborty et al., 2023). Edge-enabled IoT architectures, edge-based data management, and edge analytics techniques have emerged as key research areas to support the massive-scale deployment and efficient operation of IoT systems.

Edge computing brings computational capabilities nearer to IoT devices. In smart homes, it can enable intelligent automation, energy management, and enhanced security by processing sensor data locally (Kong et al., 2022). Edge computing also enables real-time data analysis in transportation systems, enabling intelligent traffic management and autonomous vehicles.
