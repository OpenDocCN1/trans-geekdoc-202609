## Methodology

### System Architecture and Components

- Collection Layer: This is the core Layer, responsible for gathering diverse data streams that reflect students’ interactions and behaviors during online learning. This layer incorporates multiple monitoring techniques, including real-time video analysis, keystroke dynamics, mouse movement analysis, and sentiment analysis (Sun. B et al., 2021).
- Data Processing Layer: The Data Processing Layer receives and preprocesses the raw data collected from various sources. This layer involves data cleansing, formalization, and transformation to ensure consistency and accuracy. Additionally, data fusion techniques may be applied to merge the disparate data streams into a cohesive student profile.
- Analysis and Modelling Layer: In the Analysis and Modelling Layer, machine learning algorithms come into play. These algorithms analyse the pre-processed data to extract meaningful insights about student Behavior, engagement patterns, and learning.
- Dashboard and Visualization Layer: The insights generated by the analysis layer are presented to educators through a user-admin interconnection-based dashboard. This dashboard provides visualizations, metrics, and real-time reports that facilitate educators’ understanding of students’ progress, engagement, course progress, communication support and potential challenges.
