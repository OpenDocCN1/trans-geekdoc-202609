# Methodologies

Edge technologies are referred to as various tools, frameworks, protocols, and devices that are utilized in edge computing (Cao et al., 2020) environments. These technologies enable the deployment, management, and execution of computing resources at the network edge. Here are some key edge technologies:

+   - Edge Devices: Physical devices that are situated at the edge of networks are known as edged devices. Examples of these devices include edge servers, gateways, routers, switches, and Internet of Things devices (Magesh, S., et al., 2020). To gather, process, and transmit data, these devices have sensors, processors, and storage capacities.
+   - Edge Computing Platforms: Edge computing platforms provide the software infrastructure for managing and orchestrating edge computing resources. These platforms enable the deployment, configuration, and monitoring of edge devices, as well as enable communication, analytics, and data processing between cloud and edge environments.
