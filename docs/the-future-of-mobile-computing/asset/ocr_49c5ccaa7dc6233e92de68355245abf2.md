Using a decentralized infrastructure called fog computing, data sources like application users and sensors are located at the cloud’s edge, where storage and processing components are located (Pan et al., 2018). Fog computing is the process of storing data locally before sending it to the cloud. The load of the cloud is shared by fog computing through devices with minimal processing capabilities. Also, the goal is to use the cloud for data-intensive analytics. The system’s overall efficiency is increased and the amount of data transported through it is reduced through the fog computing architecture. Fog computing acts as a layer of computing between cloud and edge (Vora et al., 2017).

This paradigm will help to prioritizes in the swift analysis and also handling of data at the edge of the network, precisely in where it’s captured or created. The contextualized services of mobile edge computing are tailored based on individual needs and the utilization of network resources.
