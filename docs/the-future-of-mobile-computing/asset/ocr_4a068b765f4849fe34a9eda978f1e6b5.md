Edge applications are created specifically to run on edge servers or devices as part of an edge computing infrastructure. These applications make use of the computing resources and edge computing capabilities to process data, run analytics, and provide services closer to the source or consumer of the data. Edge application deployment at the edge has several advantages, including decreased latency, improved performance, and increased data privacy. Edge applications can span across many domains and industries. Few examples of edge applications include IoT applications, Autonomous vehicles, Augmented reality and Virtual reality, Video surveillance, Edge Analytics, Content delivery and Edge caching and Edge gaming. Edge computing is frequently used by IoT applications to process sensor data and carry out real-time analysis. Edge applications, for instance, can monitor traffic flow in smart cities, optimise energy use, and recognise environmental changes.
