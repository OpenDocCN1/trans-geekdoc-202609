Therefore, protecting edge devices is essential to guaranteeing the overall security of the edge computing infrastructure.

There are several key aspects to consider in edge cybersecurity:

+   - Device Hardening: To reduce vulnerabilities, edge devices should be hardened. In order to avoid unauthorised access, this entails turning down unused services, installing security patches and updates, setting up strong passwords, and putting in place access controls.
+   - Secure Communication: To transport data and communicate with other devices or cloud services, edge devices must first create secure communication channels. Implementing encryption methods like Transport Layer Security (TLS) and using secure communication protocols with the proper authentication and authorisation processes, such as HTTPS or MQTT, are required for this.
+   - Access Control: Mechanisms for access control should be in place to guarantee that only authorised people and devices can access and communicate with edge devices. Access control lists, role-based access control (RBAC) policies, and authentication techniques like username and password, biometric authentication, and two-factor authentication are all included in this.
+   - Data encryption: To prevent unauthorised access to sensitive information, data should be encrypted both at rest and while in transit. Advanced Encryption Standard (AES) and other encryption methods can be used to protect data being held on edge devices or sent across a network.
+   - Intrusion Detection and Prevention: Intrusion detection and prevention systems (IDPS) can be placed at the edge to monitor and analyse network traffic, detect malicious activity, and block or mitigate possible threats in real-time.
+   - Edge Firewalls: Edge firewalls can be used to filter and manage network traffic between the edge devices and external networks. These firewalls support the enforcement of security policies, the blocking of harmful traffic, and the prevention of unauthorised access.
+   - Threat intelligence: Edge cybersecurity methods should keep track on and incorporate recent updates on new threats and vulnerabilities. Organisations may actively reduce potential risks and vulnerabilities by remaining educated on the most recent attack vectors and trends.
