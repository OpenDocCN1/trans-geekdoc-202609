
## The Techniques Applied in Natural Language Processing

The major techniques employed to complete the natural language processing tasks are syntactic analysis and semantic analysis. They are described in this way how they can be used.

### Syntax

Syntax is the arrangement of words in a sentence that makes them sound grammatical. Syntactic analysis is used to determine whether or not the Natural Language fits with grammar policies within NLP. Here’s a set of syntax strategies you can use (Chowdhary K. R., 2020).

- Lemmatization
- Morphological Segmentation
- Word Segmentation
- Part-of-speech tagging
- Parsing
- Sentence breaking.

### Semantics

The meaning to be conveyed by the wording is referred to as Semantics. One of the more complex factors in natural language processing, which still needs to be further resolved, is linguistic analysis. In the semantic analysis, you’ll find some techniques:

- Named entity recognition (NER)
- Word sense disambiguation
- Natural language generation.

- **Ambiguity:** It can be tricky to tell the intended word. Advanced models, contextual embeddings, help address this challenge by considering the broader context of the sentence.
