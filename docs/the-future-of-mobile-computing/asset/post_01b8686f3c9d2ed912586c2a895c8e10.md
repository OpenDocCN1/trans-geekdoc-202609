## Introduction

Edge computing, a paradigm-shifting technology, has emerged in response to the issues caused by the increasing volume of data created by connected devices in the modern world. The internet of things (IoT) and the proliferation of smart devices have caused problems with real-time data processing, bandwidth, and latency for traditional cloud-based computing infrastructures. By moving computation and data processing closer to the source, at the network edge, edge computing seeks to get around these constraints.

In its most basic form, edge computing is a decentralised computing architecture that distributes computation and data storage among a network of edge devices, such as sensors, gateways, and routers, positioned close to the data source. These edge devices act as mini data centres that can analyse data in real time close to its source (Cao K et al., 2020). Edge computing does this by minimising the need for data to travel over vast distances to centralised cloud servers, which decreases latency, boosts reaction times, and improves system performance as a whole.

Pushing intelligence closer to the network’s edge, where data is being created and consumed, is the underlying idea behind edge computing. A variety of applications and use cases that were previously not possible or realistic utilising conventional cloud computing technologies are now possible thanks to this paradigm shift in computing.

One of the key advantages of edge computing is its capacity to handle mission-critical and real-time applications. Edge computing offers quicker decision-making and prompt responses to events or anomalies by processing data locally at the edge. Real-time capabilities can help sectors like manufacturing, energy, healthcare, transportation, and smart cities by increasing efficiency, optimising operations, strengthening monitoring and analysis, and making choices quickly. Real-time monitoring, autonomous control systems, predictive maintenance, and intelligent resource allocation are all made possible by it.

The capacity of edge computing to solve the problems associated with network connectivity and bandwidth constraints is another important advantage of the technology (Varghese B et al., 2016). Only pertinent and useful data is delivered to the cloud or data centre by processing and analysing data at the edge, reducing the amount of data that must cross the network. Edge computing is excellent for situations with sporadic or weak network access since it not only optimises bandwidth utilisation but also lessens the dependence on continual high-speed connectivity.

Additionally, edge computing enables improved data protection and privacy. Businesses can have more control over their data and lower the danger of sensitive data being compromised or exposed during transmission by processing and storing it locally at the edge. In fields like healthcare and finance, where data privacy and regulatory compliance are crucial, this is especially significant.

## Significance of Edge Computing

An important technical development with broad consequences in many fields is edge computing. Its significance comes from its ability to deal with important concerns including data processing, latency, bandwidth, privacy, and real-time decision-making (Khan WZ et al., 2019). The following salient features underline the importance of edge computing:

### Reduced Latency

By bringing computation closer to the data source, edge computing cuts down on the amount of time data must travel to and from a central cloud server. This decreased latency makes it possible to evaluate data in real-time and make decisions more quickly, which is essential for applications like autonomous vehicles, industrial automation, and remote monitoring that call for quick responses (Stankovski S et al., 2020).

### Real-Time Data Processing

Edge computing makes it possible to process and analyse data right at or close to the data source. Predictive maintenance, anomaly detection, and real-time analytics are applications that significantly benefit from this capacity. Organisations can increase overall efficiency, optimise processes, and make quicker choices by processing data at the edge.

### Optimisation of Bandwidth

With the proliferation of connected devices and the exponential rise in data generation, sending all data to a single cloud server might put a pressure on network capacity. Edge computing resolves this issue by minimising the amount of data transmitted across the network by doing local data processing, filtering, and summarization at the edge. This optimisation results in significant cost savings and improved network performance, reducing reliance on high-bandwidth connections. These upgrades help create a network architecture that is efficient and affordable.

### Enhanced Privacy and Security

Edge computing tackles privacy and security issues by keeping sensitive data localised and minimising data exposure during transmission. By processing data locally, businesses may keep control of their data and put security safeguards in place right at the edge devices. This regional strategy reduces the dangers of data breaches and assures adherence to data privacy laws.

### Decentralised Architecture

Edge computing makes it possible for a decentralised design by dispersing processing power and brainpower across the network. By reducing reliance on a single, central cloud server, this architecture improves fault tolerance, scalability, and flexibility. In the event of network outages or problems with cloud access, edge devices’ independence enables the creation of more durable and resilient systems.

## Industrial Automation

Industrial automation relies heavily on edge computing, which has transformed how factories and production lines run. Edge computing allows real-time analysis, quicker decision-making, lower latency, and increased operational efficiency by moving computation and data processing closer to the source as specified in Figure 1. Here is a thorough explanation of how edge computing is applied to industrial automation:

Massive volumes of data are produced by industrial automation systems from sensors, equipment, and manufacturing lines. PLCs or industrial gateways are examples of equipment that can process real-time data directly at the edge — thanks to edge computing (Stankovski S et al., 2020). Edge devices can react to events, spot anomalies, and take rapid action by evaluating data locally. Low latency is necessary for real-time control and decision-making in industrial automation. Edge computing eliminates the need to send data to a distant cloud server for processing, thereby lowering the latency involved with delivering data over a network. This enables quicker response times, enabling quick actions to handle process variances or key events.
