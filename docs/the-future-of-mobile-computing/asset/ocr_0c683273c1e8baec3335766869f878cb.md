Data processing and also the storage are typically centralised in data centers that will have been situated in the specific and geographic locations in the traditional cloud computing. However, there are some growing demands for faster data processing and also real-time decision-making due to the emergence of Internet of Things (IoT) devices, autonomous vehicles, and other latency-sensitive applications. This is met most by edge infrastructure, which uses the decentralizes computing things and relocates them close to the data-generating and -consuming devices. The use of the edge servers, small data centres, or even specialised hardware like the routers or the gateways with computing the capabilities which can accomplish the edge devices. These edge nodes will also be carefully positioned at various locations, including cell towers, network hubs, or close to end users or Internet of Things devices. The benefits of edge infrastructure include reduced latency, bandwidth optimization, scalability, enhanced privacy and security and offline capabilities. Smart cities, autonomous vehicles, industrial automation, augmented reality/virtual reality (AR/VR), and healthcare are few applications for edge infrastructure. Edge computing creates new opportunities for real-time data processing, quicker decision-making, and enhanced user experience for enterprises (Stankovski et al., 2020).

Edge infrastructure consists of hardware, software, and networking elements that make data processing and storage closer to the source of the data and supports the process of edge computing (Liu et al., 2019). In order to reduce latency, increase responsiveness, and improve system performance, edge infrastructure aims to process and analyse data closer to its source. The important elements of edge infrastructure specified in figure 4 include Edge data centers, Edge devices, Edge networks, Edge computing platforms, Edge analytics and AI, Privacy and security, and Monitoring and management tools. Edge data centers are smaller-scale data centers deployed at the edge. To facilitate local data processing and storage, edge data centers host computing resources, storage, and networking hardware. The characteristics of edge data centers include, Compact, energy-efficient, and able to operate in complex environments. Edge devices are actual hardware components, such as edge servers, gateways, routers, or switches, that are situated at the network’s edge. By handling data processing and management locally, these devices offload the workloads from the centralised data centers (Jain et al., 2019). They might be equipped with specialised hardware, like GPUs or FPGAs, to support particular computing needs.
