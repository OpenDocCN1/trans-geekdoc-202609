## Edge Services and Applications

Edge as a Service (EaaS) is the term used to describe the on-demand cloud-based delivery of edge computing resources, capabilities, and services to users. Without having to maintain the underlying hardware and software components, it enables companies and developers to take advantage of edge computing infrastructure. The users can access edge computing resources remotely like cloud services. To bring computation closer to the data source or end users, the edge infrastructure is typically deployed across a distributed network of edge locations or devices. The benefits of edge as a service include on-demand resource provisioning, reduced latency, simplified development and deployment, cost efficiency, scalability and agility, edge analytics and AI, and enhanced security and privacy. Edge service providers include Cloud service providers, telecommunications firms, or providers of specialised edge computing platforms. Users can focus on creating and deploying their applications while these providers take care of managing the underlying infrastructure, which includes edge devices, networks, and software platforms. Also, the adoption of a new computing paradigm that produces better digital experiences and ultimately enhances the Internet as a whole is made simpler for modern engineering teams by the introduction of edge as a service. Overall, edge computing benefits are made available to developers and companies through edge as a service, giving them flexible, scalable, and cost-effective access to edge resources and capabilities. It enables enterprises to take advantage of edge computing’s potential without having to make costly upfront investments and manage their own infrastructure.

Edge Computing has a multilayered architecture to distribute the workload among the edge devices, edge servers and enterprise servers which forms the components of edge as a service as specified in Figure 5. With the rapid development of edge computing, a single intelligent platform that offers full edge-as-a-service solution management capability is required. The tools support in rendering services such as operation management, data analytics, automation, orchestration, management and security. The popular tools used to provide edge-as-a-service include Kubernetes, Apache OpenWhisk, TensorFlow Lite, AWS Greengrass, Azure IoT Edge, Google Cloud IoT Edge, EdgeX Foundry, and Eclipse ioFog. The selection of tools depends on different factors, including the requirements for particular use cases, the infrastructure that supports them, programming languages, and the desired integration level with cloud services.

Edge applications are created specifically to run on edge servers or devices as part of an edge computing infrastructure. These applications make use of the computing resources and edge computing capabilities to process data, run analytics, and provide services closer to the source or consumer of the data. Edge application deployment at the edge has several advantages, including decreased latency, improved performance, and increased data privacy. Edge applications can span across many domains and industries. Few examples of edge applications include IoT applications, Autonomous vehicles, Augmented reality and Virtual reality, Video surveillance, Edge Analytics, Content delivery and Edge caching and Edge gaming. Edge computing is frequently used by IoT applications to process sensor data and carry out real-time analysis. Edge applications, for instance, can monitor traffic flow in smart cities, optimise energy use, and recognise environmental changes. Edge applications can improve production processes, monitor the health of the machines, and enable predictive maintenance in industrial settings. For autonomous vehicles, where timely decision-making is crucial, edge applications are essential. With the help of edge computing, sensor data can be processed onboard so that vehicles can make important decisions without relying on cloud connectivity. Algorithms for computer vision, AI-based object detection, and sensor fusion for enhanced perception are examples of edge applications for autonomous vehicles (Goundar et al., 2021).

For an immersive experience, AR and VR applications frequently need low latency and high bandwidth. Rendering, object tracking, and gesture recognition are examples of computation-intensive tasks that edge applications can offload to edge servers, reducing latency and improving user experience. This enables responsiveness and real-time interaction in AR/VR applications. Video surveillance systems perform video processing and real-time analysis using edge applications. The need to send huge amounts of video data to a centralised server can be minimised by using edge servers to run algorithms for object detection, facial recognition, and anomaly detection. This makes it possible to use network bandwidth effectively, respond more quickly, and increase security. Edge applications can analyse data locally and produce insights (Mao et al., 2017). In situations where real-time analysis is necessary, like in industrial automation, healthcare monitoring, and retail analytics, this is especially helpful. In order to save bandwidth and facilitate quicker decision-making, edge analytics applications can process data locally and transmit only the pertinent information to the central/cloud infrastructure.

Edge applications are used by content delivery networks (CDNs) to cache and distribute content closer to end users. In order to reduce latency and enhance the performance of content delivery, edge caching applications can store popular web content, videos, and software updates at edge servers. This makes it possible for quicker load times, better streaming quality, and improved user experiences. In cloud gaming services, where game rendering and processing are delegated to edge servers, edge applications are being used. This reduces the processing load on client devices and makes it possible for devices with limited computing power to provide high-quality gaming experiences. Low-latency gameplay, multiplayer communication, and real-time streaming of game content are all possible with edge gaming applications. Applications that need real-time processing, low latency, and resource efficiency can be deployed using edge computing. As the edge computing ecosystem develops there is a possibility of more innovative and industry-specific applications emerging.

## Conclusion

A taxonomy offers a structured framework for organising and understanding the complexities of edge computing systems through the analysis and classification of various edge computing-related elements, including edge devices, edge architectures and edge services. Also, a taxonomy improves understanding and management of the heterogeneous nature of devices present at the network edge by classifying edge devices based on their capabilities, characteristics, and functionalities. Making informed decisions about the choice of device, allocation of resources and distribution of tasks in edge computing environments is made easier through this categorization.

The architectural approaches used in edge computing, such as cloud-centric, fog computing, and mobile edge computing, can also be identified and distinguished using a taxonomy of edge architectures. In order to make the best architectural decisions and optimisations based on particular use cases and requirements, it is helpful to understand the trade-offs, benefits, and limitations associated with each architecture. Data analytics, real-time processing, AI inference, and IoT services are just a few of the numerous services and applications that can be deployed at the edge. The taxonomy of edge services also helps in categorising these services and applications. A taxonomy can effectively place and manage these services in edge computing systems by classifying them and providing information about their unique features, resource needs, and performance considerations.

Thus, a comprehensive taxonomy of edge computing offers a structured framework that improves our knowledge of the various elements and facets of this developing field. It supports better resource management, optimisation, and decision-making in edge computing environments, enhancing system responsiveness, scalability, and user experience. An up-to-date and flexible taxonomy will be necessary for successfully navigating the complex landscape of edge computing technologies and applications as edge computing continues to develop and become more pervasive.
