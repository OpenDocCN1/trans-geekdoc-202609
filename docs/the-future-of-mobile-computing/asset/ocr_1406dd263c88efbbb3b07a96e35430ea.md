# Introduction: Edge Computing in Context

Edge computing is a distributed computing model that extends cloud computing capabilities to the edge of the network. It takes cloud computing abilities closer to edge. Edge devices refer to the computing devices located close to the edge of a network. These devices include smartphones, sensors, IoT, gadgets, routers, gateways, and other hardware that gather, process, and transmit data. They often play a role in collecting and managing data before sending it to be centralized systems for further analysis and storage. Edge computing distributes tasks like data collection, storage, processing, and decision-making nearer to devices that create and utilize data (Shi and Dustdar, 2016). It leverages a decentralized infrastructure composed of edge nodes, which can be devices, gateways, or micro-data centers, located in proximity to data source. These edge nodes handle data processing and storage tasks. Thereby reducing the need for transmitting data to a centralized location.

Here, edge devices play a vital role in locally processing and analyzing data. They are equipped with computational capabilities, storage, networking capabilities to execute tasks such as data filtering, preprocessing, analytics, real-time decision-making etc.

Edge computing leverages the proximity of these devices to the data source to achieve low-latency processing, reduce network traffic, and enhance overall system performance. It enables data to be processed, at the location where it is generated. Localized processing not only enhances performance but also reduces network congestion and bandwidth consumption. Moreover, it allows for offline or disconnected operation, ensuring uninterrupted service availability even in scenarios where connectivity may be limited or intermittent.
