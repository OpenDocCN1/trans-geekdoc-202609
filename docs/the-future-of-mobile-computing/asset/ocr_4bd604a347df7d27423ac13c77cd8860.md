# Edge-Based Machine Learning Models

Edge models are machine learning models loaded and executed directly on edge devices, which include sensors, cameras, smartphones, and other Internet of Things (IoT) devices. It will lessen the necessity for centralized processing on cloud servers by moving machine learning’s processing capacity closer to the data center. Several edge-based machine learning models are as follows (Wang et al., 2019).

+   - Edge-based machine learning models that carry out on-device inference, or the act of generating predictions or judgments, do so directly on the device from which the data is obtained.
+   - By using model compression approaches, machine learning models can be deployed on edge devices with limited resources because of their smaller size.
+   - Reducing a model’s numerical values’ precision, usually from 32-bit floating-point integers to lower-bit representations, is known as quantization.
+   - Utilizing prior information from pre-trained models on one job to enhance performance on a related task is known as transfer learning.
