# Edge Devices

An edge device can be used as a networking device to control the flow of data efficiently at the boundary of two networks. They are frequently employed in situations requiring real-time or nearly real-time processing as well as those with bandwidth, latency, or connectivity limitations. The networks with different protocols become highly incompatible and can be managed with the help of edge device.
