# Methodology

The three main elements that make up mobile computing are as follows: (1) communication, (2) hardware, and (3) software. When it comes to wireless networks, data flow, and protocols, the communication idea is more specifically referring to these things. There are many different kinds of mobile devices that may be considered hardware. The software that is used in mobile computing is comprised of the programs that are installed in the hardware of mobile devices. These applications include specialized software for the industry, apps for data collecting, and web browsers (Laurila et al., 2012). Mobile devices, in contrast to purpose-oriented Internet of Things (IoT) devices, are equipped with sensors that may serve several purposes. A few examples of these sensors include microphones, accelerometers, gyroscopes, and global positioning system receivers.
