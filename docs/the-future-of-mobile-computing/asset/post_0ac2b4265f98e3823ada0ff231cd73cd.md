## Edge Devices

An edge device can be used as a networking device to control the flow of data efficiently at the boundary of two networks. They are frequently employed in situations requiring real-time or nearly real-time processing as well as those with bandwidth, latency, or connectivity limitations. The networks with different protocols become highly incompatible and can be managed with the help of edge device. Moreover, edge devices provide interconnectivity between two different networks to carry out operations such as data transmission, monitoring and filtering between networks. Also, edge devices for data collection from various data sources, processing the data locally and sending data to the network layer making relevant decisions. The network layer connects the edge devices with the cloud and specifies the network infrastructure. Also, organizations can make decisions more quickly, reduce the cost of data transfers, and address privacy concerns by storing sensitive data locally by processing data locally. The rising demand for real-time analytics, low latency, enhanced security, and reduced use of network bandwidth leads to the rapid increase of edge devices.

## Edge Infrastructure

In order to support edge computing and other edge-related technologies, edge infrastructure is used. It refers to the physical and virtual components that are deployed at networks edge. A distributed computing model known as edge infrastructure brings computing power and data storage closer to a location usually at the edge of a network. Data processing and also the storage are typically centralised in data centers that have been situated in specific geographic locations in the traditional cloud computing. However, there are some growing demands for faster data processing and also real-time decision-making due to the emergence of Internet of Things (IoT) devices, autonomous vehicles, and other latency-sensitive applications. This is met most by edge infrastructure, which uses decentralized computing and relocates it close to the data-generating and -consuming devices. The use of edge servers, small data centres, or even specialised hardware like routers or gateways with computing capabilities can accomplish the edge devices. These edge nodes will also be carefully positioned at various locations, including cell towers, network hubs, or close to end users or Internet of Things devices. The benefits of edge infrastructure include reduced latency, bandwidth optimization, scalability, enhanced privacy and security and offline capabilities. Smart cities, autonomous vehicles, industrial automation, augmented reality/virtual reality (AR/VR), and healthcare are few applications for edge infrastructure. Edge computing creates new opportunities for real-time data processing, quicker decision-making, and enhanced user experience for enterprises (Stankovski et al., 2020).

Edge infrastructure consists of hardware, software, and networking elements that make data processing and storage closer to the source of the data and supports the process of edge computing (Liu et al., 2019). In order to reduce latency, increase responsiveness, and improve system performance, edge infrastructure aims to process and analyse data closer to its source. The important elements of edge infrastructure specified in figure 4 include Edge data centers, Edge devices, Edge networks, Edge computing platforms, Edge analytics and AI, Privacy and security, and Monitoring and management tools. Edge data centers are smaller-scale data centers deployed at the edge. To facilitate local data processing and storage, edge data centers host computing resources, storage, and networking hardware. The characteristics of edge data centers include, Compact, energy-efficient, and able to operate in complex environments. Edge devices are actual hardware components, such as edge servers, gateways, routers, or switches, that are situated at the network’s edge. By handling data processing and management locally, these devices offload the workloads from the centralised data centers (Jain et al., 2019). They might be equipped with specialised hardware, like GPUs or FPGAs, to support particular computing needs.

Edge computing platforms include, operating systems, middleware, and software frameworks that support edge computing features. It enables the orchestration, management, and service deployment at the edge. Utilisation of resources is optimised, handling data distribution, effective processing and communication between edge devices are all made possible by edge computing software. To connect edge devices, edge data centres, and the centralised cloud or data centres, edge infrastructure depends on robust networking capabilities. This might include both wired and wireless technologies, including cellular networks, Ethernet, Wi-Fi, and specialised protocols like LoRaWAN or Zigbee. Security measures are incorporated into edge infrastructure to secure data and devices there. This includes intrusion detection systems, access controls, authentication methods, and encryption (Varghese, 2016). Moreover, management systems will be used to monitor and control edge devices, collects the telemetry data, perform the updates, and ensure the total health and performance of the edge infrastructure (Khan et al., 2017). Edge management is specified as the practices, technologies, tools used to manage edge computing infrastructure. At the network edge, edge devices and applications must be provisioned, monitored, configured and updated (Satyanarayanan, 2017). The performance, security, and efficiency of the distributed computing environment are all made possible by effective edge management. For edge infrastructure to remain reliable, secure, and performant, effective edge management will be essential for the edge. It enables businesses to take advantage of edge computing deployments, manage distributed computing environments effectively, and also guarantee smooth operation. Thus, edge computing is built on the edge infrastructure, which enables businesses to process and analyse data in real-time, closer to the point of generation. It offers reduced latency, enhanced performance, and improved data privacy and security, supporting the development of edge-related technologies and applications. Edge analytics and AI (Artificial Intelligence) are complementary technologies that enable data analysis and smart decision-making at the network edge. In comparison to sending data to a centralised cloud or data centre for processing, edge analytics refers to the practice of analysing data close to the source. When data is processed locally, either on edge devices or in edge data centres, edge analytics enables real-time insights, prompt action, and decreased latency. This strategy is especially helpful within applications like IoT deployments, autonomous vehicles, industrial automation, and smart cities where low latency, bandwidth optimisation, and real-time decision-making are essential.
