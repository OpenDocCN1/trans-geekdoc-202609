### Abstract

Edge Computing is termed as an important paradigm utilized to address the problems related to latency, bandwidth, and privacy. It is required to create a taxonomy that offers a thorough understanding of the various aspects and components of edge computing. This chapter focuses on the taxonomy of edge computing that captures its various aspects including deployment models, application domains, infrastructure, and services. The chapter also discusses the components such as edge servers, edge networks, edge analytics, and edge devices. The range of edge computing-enabled applications discussed in the chapter include such as Internet of Things, autonomous driving, augmented reality, video surveillance, and more. By providing the systematic organization of edge computing concepts, the taxonomy helps researchers, decision-makers to navigate the landscape of edge computing effectively (Varghese et al., 2016). It facilitates better understanding of different elements of edge computing and their relationship. It facilitates a better understanding of the relationships and interdependencies between different elements of edge computing, fostering knowledge sharing, collaboration, and innovation. This chapter provides a discussion on the taxonomy of edge computing, offering a structured framework for comprehending the various dimensions and elements of this evolving technique.

### Introduction

Edge computing represents a shift in distributed computing, strategically relocating data storage and computational capabilities to be closer to the sources where the data originates from the cloud. This innovation will redefine the conventional cloud model by decentralizing computing power, that will help in bringing it nearer to the edge of the network, precisely where data will be generated (Vora et al., 2017).

This evolution is a departure from the traditional centralized cloud architecture, aiming to minimize data transit between distances and enhance the efficiency of data processing and storage at the data’s point of creation. This will also improve the performance of the system and it will also reduce the usage of bandwidth (Cao et al., 2020).

Also, edge computing can be used as a method to optimize cloud computing systems. Edge can be the form of any device used for computing and can also be used as a network resource. Moreover, it is easy to expand the edge computing paradigm from individual to enterprise-wide applications. Edge computing can get around the limitations of conventional cloud computing models by processing data locally.

Applications that use real-time such as internet connectivity, traffic monitoring, and surveillance that need prompt responses, which can be hindered by latency and mobile-related issues. Edge computing relocates processing to network’s edge, and effectively addresses these application requirements. The issues due to cloud computing can be resolved using mobile-edge computing, fog computing, and edge-server model. A diverse range of technologies, components, and entities are included in edge computing. This chapter introduces the taxonomy of edge computing in terms of edge devices, infrastructure, edge services, and applications.

### Background of Edge Computing

Being edge computing close to the source of the data can result in significant business benefits such as faster insights, faster response times, and better bandwidth availability (Jain et al., 2019). Gartner predicts that by 2025, 75% of data processing will occur outside of a traditional data center or the cloud. Massive amounts of data have been generated as a result of the rapid expansion and increasing computing power of IoT devices. Furthermore, as the number of mobile devices connected to 5G networks grows, there will be an increase in the volume of data.

Transmitting all the device-generated data to a centralised data center leads to issues related to latency and bandwidth. Edge computing, which processes and analyses data closer to the point of creation, is a more efficient substitute. In the past, automation and speeding up innovation through the creation of useful data insights was the potential of cloud computing and artificial intelligence (AI). However, network and infrastructure capabilities have not kept up with connected devices’ ability to produce data at a scale and in a complexity never before seen. Edge computing makes it possible to analyse data more quickly and thoroughly, resulting in deeper insights, quicker responses, and improved customer experiences.

### Characteristics and Paradigms of Edge Computing

Edge computing in its core changes the traditional centralized computing paradigm by moving computational resources closer to the points of data generation at the edge. Its essence lies in reducing the distance that data must travel, minimizing latency, and optimizing bandwidth usage. This proximity enables fundamental shifts in how data will be processed, fostering a decentralized architecture distributed across various edge devices, servers, and network infrastructure. This distributed nature enhances scalability, fault tolerance, and resource utilization, by providing a robust foundation for a multitude of applications.

One of the main traits of edge computing is the ability to significantly reduce latency. By processing data closer to its origin at the edge, it minimizes the time taken for the data to traverse from the edge devices to the centralized data centers and back. This feature is instrumental in applications requiring real-time or near-real-time responses, such as IoT devices, autonomous vehicles, and industrial automation systems. This enables the delivery of timely responses in critical situations, enhancing user experience and enabling swift decision-making in various domains. The tasks of network administrators will be made easy without traversing the entire Wide Area Networks using mobility services. Real-time analytics and big data analytics can be executed with enhanced accuracy and scalability. Monitoring of IoT-based applications and Machine Learning pipeline becomes easier through this characteristic of edge computing. Figure 1 represents the characteristics of edge computing.

The next important characteristic is provided through the support extended for mobility in edge computing. This characteristic is rendered through the LISP (Locator ID Separator) protocol which provides direct communication with mobile devices by implementing the distributed directory system. The mobility support is extended through LISP by the process of decoupling host and location identity. This characteristic is termed a key principle in edge computing. The property location-awareness is used to access services from edge servers near the location of users. Devices can be tracked by users through technologies such as GPS or using wireless access points. This particular characteristic proves highly beneficial for applications like vehicular safety and disaster management that rely on edge-based solutions.

The proximity characteristic of edge computing improves users experience by making resources available for computation at their levels of proximity. Also, users can make service decisions comfortably since resources required for computation are available in the local vicinity. Moreover, this can help service providers to analyze behavior of mobile users by extracting device information in order to improve process of allocating resources and services to users.
