# Present Issues of Edge Computing

Addressing issues in edge computing requires collaborative efforts from industry stakeholders, including standardization bodies, device manufacturers, network providers, and software developers (Akula CS et al., 2020). Some of the issues are scalability, connectivity, security, data management, standardization and interoperability, orchestration and management and energy efficiency.

Edge computing involves deploying numerous computing devices across a distributed network, which can pose challenges in terms of scalability. Managing a large number of edge devices and ensuring their seamless integration into the overall system can be complex. Connectivity: Edge computing relies on robust and reliable network connectivity between edge devices and centralized systems. In remote or rural areas with limited network infrastructure, maintaining consistent connectivity becomes a significant challenge.

Edge devices often process and store sensitive data, making them potential targets for cyberattacks. Securing edge devices against unauthorized access, data breaches, and malware attacks is crucial. Additionally, managing security updates and patches across a vast number of distributed devices can be challenging (Salman et al., 2020). Edge computing generates vast amounts of data, and managing this data efficiently poses challenges. Determining what data to process and store locally versus sending it to the cloud for analysis and storage requires careful consideration. Data governance, data privacy, and compliance with regulations add additional complexity to data management in edge computing. Resource constraints: Edge devices typically have limited processing power, memory, and storage capacities. Optimizing resource utilization and executing computationally intensive tasks within the constrained resources of edge devices can be a significant challenge.

The edge computing landscape is currently fragmented, with various vendors offering different edge solutions. Lack of standardized interfaces, protocols, and interoperability between edge devices, platforms, and cloud systems hinders seamless integration and limits the potential for collaboration and innovation. Managing a distributed edge infrastructure, monitoring device health, and ensuring smooth coordination and synchronization among edge devices require efficient orchestration and management systems. Developing robust management frameworks that can handle the scale and complexity of edge deployments is an ongoing challenge.
