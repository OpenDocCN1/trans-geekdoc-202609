# In-Display Fingerprint Scanners and Improved Device Security

Under-display or in-screen fingerprint scanners, sometimes referred to as in-display fingerprint scanners, are a type of biometric authentication technology that is built into the display of a device, like laptops or smartphones (Yeh et al., 2023). The introduction of this technology aims to improve device security in a more seamless and practical manner in Figure 2.

+   - Biometric Authentication: Fingerprint Recognition, In-display fingerprint scanners use each user’s unique fingerprint patterns to authenticate and unlock a device. This biometric authentication solution is more convenient and often faster than typing in a password or PIN (Ni et al., 2023). Seamless Integration: Integration into the Display, unlike traditional fingerprint scanners, which are often located on a device’s front or back, in-display fingerprint scanners are embedded beneath the screen of a smartphone. This link enables more efficient and aesthetically pleasing design.
