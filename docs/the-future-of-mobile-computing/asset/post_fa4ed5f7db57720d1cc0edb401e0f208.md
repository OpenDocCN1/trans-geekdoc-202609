In industrial automation, edge devices serve as localised control units that are capable of taking independent choices. Based on real-time sensor data, they can run control algorithms, put logic into place, and carry out directives. This localised control increases system responsiveness and robustness overall by reducing reliance on a centralised control system. In industrial automation, edge computing optimises the use of network bandwidth. Only pertinent data must be communicated to the central system or the cloud when data processing and analysis are done at the edge devices. Because less data needs to be delivered, network congestion is reduced, and communication expenses are decreased.

Machine learning algorithms can now be implemented at the edge devices in industrial automation thanks to edge computing. Real-time data can be evaluated and used to inform local decisions by putting machine learning models directly on the edge devices. Predictive maintenance, anomaly detection, and production process optimisation are made easier as a result, increasing productivity and lowering downtime (Shakarami A et al., 2020; Kozik R et al., 2021). Edge computing equips edge devices with the ability to perform advanced analytics. Data can be analysed in real-time to gain insightful knowledge, spot trends, anticipate equipment problems, and enhance production procedures by running analytics algorithms locally (Wang F et al., 2020). Industrial automation systems can make intelligent decisions at the edge thanks to edge analytics, which eliminates the need for constant data transfer to a distant server.

Robotics applications in industrial automation are improved by edge computing. Real-time data processing and decision-making can happen onboard by putting edge devices nearby or directly aboard robots. This reduces the need for constant communication with a central system, improves robot autonomy, and enables faster response times, enabling more sophisticated and efficient robotic automation. Not every piece of data produced by sensors and machines is crucial in industrial automation. Data prioritisation and filtering are made possible by edge computing at the edge devices. To the central system or cloud for additional analysis and storage, only pertinent and essential data is communicated. This lessens the need for bandwidth, improves data transfer, and makes sure that the most pertinent data is used to provide insightful conclusions.

The fault tolerance and dependability of industrial automation systems are improved via edge computing. The system is less prone to single points of failure by dispersing computational power among a number of edge devices. Edge devices have the ability to continue operating autonomously in the case of network or cloud connectivity problems, ensuring ongoing production and process control. Edge computing focuses on local data processing and control, but it can also interact with cloud-based systems for more comprehensive analytics, historical data storage, and centralised management. For long-term analysis, proactive maintenance, and performance improvement, compiled data from numerous edge devices can be sent to the cloud. A strong and complete ecosystem for industrial automation is produced by this integration of edge and cloud computing.

In industrial automation, edge computing enables scalable and adaptable implementation. To adapt to changes in production lines, machinery, or industrial layouts, edge devices can be quickly added or withdrawn. Without major disruptions or infrastructure changes, its scalability and flexibility allow for the seamless extension or reconfiguration of automation systems. Edge computing improves industrial automation system security by limiting the exposure of sensitive data to external networks. Sensitive data can stay within the factory network when edge devices process data locally, reducing the possibility of unauthorised access or data breaches. Edge computing also enables localised security mechanisms, such as firewalls, access controls, and encryption, that are specifically designed to safeguard the industrial environment and the relevant edge devices.

In industrial automation, edge computing aids cost optimisation. Edge computing lowers the cost of data transmission by lowering the requirement for constant high-bandwidth network connections and minimising data transfer to the cloud. Additionally, it lessens the need for cloud infrastructure, which may lead to possible savings on the price of cloud processing and storage.

## Edge Cybersecurity

Edge cybersecurity refers to the security measures and strategies implemented at the edge of a network to protect edge devices, data, and applications from cyber threats. Edge computing creates new security concerns and needs by moving computation and data processing closer to the edge devices. The processing power, memory, and security capabilities of edge devices, such as sensors, actuators, gateways, and IoT devices, are frequently constrained by available resources. These devices are particularly susceptible to assaults because they may not have built-in security mechanisms and may not have the processing power to run complex security software (Cao K et al., 2020).

Therefore, protecting edge devices is essential to guaranteeing the overall security of the edge computing infrastructure.

There are several key aspects to consider in edge cybersecurity:

- Device Hardening: To reduce vulnerabilities, edge devices should be hardened. In order to avoid unauthorised access, this entails turning down unused services, installing security patches and updates, setting up strong passwords, and putting in place access controls.
- Secure Communication: To transport data and communicate with other devices or cloud services, edge devices must first create secure communication channels. Implementing encryption methods like Transport Layer Security (TLS) and using secure communication protocols with the proper authentication and authorisation processes, such as HTTPS or MQTT, are required for this.
- Access Control: Mechanisms for access control should be in place to guarantee that only authorised people and devices can access and communicate with edge devices. Access control lists, role-based access control (RBAC) policies, and authentication techniques like username and password, biometric authentication, and two-factor authentication are all included in this.
- Data encryption: To prevent unauthorised access to sensitive information, data should be encrypted both at rest and while in transit. Advanced Encryption Standard (AES) and other encryption methods can be used to protect data being held on edge devices or sent across a network.
- Intrusion Detection and Prevention: Intrusion detection and prevention systems (IDPS) can be placed at the edge to monitor and analyse network traffic, detect malicious activity, and block or mitigate possible threats in real-time.
- Edge Firewalls: Edge firewalls can be used to filter and manage network traffic between the edge devices and external networks. These firewalls support the enforcement of security policies, the blocking of harmful traffic, and the prevention of unauthorised access.
- Threat intelligence: Edge cybersecurity methods should keep track of and incorporate recent updates on new threats and vulnerabilities. Organisations may actively reduce potential risks and vulnerabilities by remaining educated on the most recent attack vectors and trends.
- Security analytics: Implementing security analytics tools and technologies at the edge can assist in spotting unusual behaviour, spotting security events, and giving out early warnings of possible cyber attacks. To evaluate data patterns and spot suspect activity, these analytics solutions employ machine learning and artificial intelligence algorithms.
- Enhanced efficiency: Edge computing enables real-time data analysis and decision-making at the edge devices, reducing the need for data to travel to a central server or cloud. This localized processing improves system response times and enables faster automation control, leading to enhanced operational efficiency and productivity.
- Predictive Maintenance: Industrial automation can employ predictive maintenance techniques thanks to edge computing. Machines and apparatus can be continuously checked for indications of probable faults or anomalies by doing local data analysis at the edge. This proactive strategy aids in avoiding unplanned downtime, streamlining maintenance plans, and lowering maintenance expenditures.
- Improved Quality Control: With edge computing, firms may put in place real-time quality control systems. Instantaneous analysis of data from edge sensors and devices enables the quick detection of errors or departures from desired parameters. This makes it possible to take rapid corrective action, reduce waste, and guarantee a constant level of product quality.
- Offline Operations: Edge computing enables offline operations in situations when dependable network connectivity is not guaranteed. Edge devices can store and analyse data locally, ensuring that automated processes continue even during brief network interruptions. The synchronised data can be sent to central systems for analysis and synchronisation after connectivity has been restored.
- Reduced Network Traffic: Edge computing reduces the amount of data transmitted over the network by filtering and processing data at the edge devices. Edge computing optimises network bandwidth utilisation, lowers latency, and lessens the stress on the network infrastructure by only transmitting information that is pertinent and useful to central servers or the cloud.
