# Introduction

Edge computing represents a shift in the distributed computing, also strategically relocating the data storage and also computational will have the capabilities to closer of the sources where the data will be originates from the cloud. This innovation will redefine the conventional cloud model by the decentralizing of computing power, thar will be helps in bringing it nearer to the edge of the network, precisely where data will be generated (Vora et al., 2017).

This of the evolution a departure in the form that traditional centralized cloud architecture, aiming to the minimize of the data will be transit between the distances and enhance the efficiency of data processing and storage at the data’s point of creation. This will also improve the performance of the system and it will also reduce the usage of bandwidth (Cao et al., 2020).

Also, edge computing can be used as a method to optimize cloud computing systems. Edge can be the form of any device used for computing and can also be used as a network resource. Moreover, it is easy to expand the edge computing paradigm from individual to enterprise-wide applications. Edge computing can get around the limitations of conventional cloud computing models by processing data locally.
