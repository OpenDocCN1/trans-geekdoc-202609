# Overview of Machine Learning Algorithms

Machine learning algorithms can be categorized into three types: supervised learning, unsupervised learning, and reinforcement learning (Carbonell et al., 1983). Supervised learning algorithms are trained using labeled data and can predict outcomes based on input-output mappings. Examples include linear regression, logistic regression, decision trees, and support vector machines. On the other hand, unsupervised learning algorithms are trained on raw data without labeled outputs as specified in Figure 1. They discover patterns in the data without prior knowledge of those patterns. Examples include clustering, dimensionality reduction, and association rule learning specified in Table 1. Reinforcement learning algorithms learn through interaction with an environment. They take actions to maximize rewards and minimize punishments. Examples include Q-learning and policy gradient. Chooosing the most suitable algorithm for a specific problem depends on the data and desired outcomes, this is just a glimpse of the many machine learning algorithms available.

Table 1. Types of learning and machine learning algorithm

| Type | Description | Example |
|---|---|---|
| Supervised learning | Algorithms are trained on a set of labelled data, where each data point has both an input and an output. | Linear regression, logistic regression, decision trees, support vector machines |
| Unsupervised learning | Algorithms are trained on a set of unlabeled data, where each data point only has an input. | Clustering, dimensionality reduction, association rule learning |
| Reinforcement learning | Algorithms are trained by interacting with an environment and learning to take actions that maximize reward and minimize punishment. | Q-learning, policy gradients |
