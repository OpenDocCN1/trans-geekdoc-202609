# The Techniques Applied in Natural Language Processing

The major techniques employed to complete the natural language processing tasks are synthesis analysis and semantic analysis. They are described in this way how they can be used.

# Syntax

Syntax is the arrangement of words in a sentence that makes them sound grammatical. syntactic analysis is used to determine whether or not the Natural Language fits with grammar policies within NLP. Here’s a set of syntax strategies you can use (Chowdhary K. R, 2020).

+   - Lemmatization
+   - Morphological Segmentation
+   - Word Segmentation
+   - Part-of-speech tagging
+   - Parsing
+   - Sentence breaking.

# Sematics

The meaning to be conveyed by the wording is referred to as Semantics. One of the more complex factors in natural languages processing, which still needs to be further resolved, is linguistic analysis. In the semantic analysis, you’ll find some techniques:

+   - Named entity recognition (NER)
+   - Word sense disambiguation
+   - Natural language generation.

# Speech Recognition Technologies

Speech recognition technologies are playing an increasingly important role in intelligent mobile computing. The use of voice recognition in Intelligent Mobile Technologies provides several major advantages (Chen & Deng, 2021). Speech recognition allows users to communicate with their devices handsfree, which is especially helpful in situations when they have no hand and can’t use it while on the road or working out.
