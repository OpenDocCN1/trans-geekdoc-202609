# Introduction

The exponential growth of connected devices has led to the rise in popularity of edge computing. The Internet of Things (IoT), and the growing demand for real data distribution have all contributed to the rise in popularity of edge computing. Edge computing provides various benefits by distributing data at or close to the edge. These advantages include Decreased Latency Lower potential is achieved by reducing the amount of time that data must travel from the source to the processing point through edge computing. This is crucial for applications like autonomous vehicles, engineering automation, and augmented reality that call for responsiveness in real-time or almost real-time. Bandwidth Optimisation: By reducing the amount of data that must be transmitted to centralized cloud data centers, edge computing helps to conserve bandwidth. Edge devices can optimise bandwidth usage and lessen network congestion by filtering and optimizing data locally before sending it to the cloud through processing and analysis of statistics. Figure 1 specifies the architecture of edge computing. Enhanced Reliability: Distributed processing and storage among several edge devices, or nodes, are made possible by edge computing. This distributed architecture enhances reliability and fault tolerance since even if one edge node fails, others can continue to operate independently. It also improves resiliency by ensuring that critical services can still function in situations where network connectivity to the cloud is disrupted. Edge computing makes it possible to manage and store sensitive data locally, lowering the possibility of data breaches and guaranteeing compliance with Data Privacy and Security’s data protection laws. This localized approach to data management provides an additional layer of privacy and security, as sensitive information doesn’t have to traverse the network or reside in a centralized data center.
