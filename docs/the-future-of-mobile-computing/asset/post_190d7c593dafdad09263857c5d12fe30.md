### Abstract

A distributed computing paradigm known as “edge computing” moves data storage and processing closer to the location where the data is generated or consumed. In traditional cloud computing, devices or end users are not close to the centralized data centers where data processing and storage take place. In edge computing, the data-generating devices or sensors are located at or close to the network’s edge, where processing and storage resources are located. Cutting down on latency and bandwidth needed to send data to distant data centers for processing is the main goal of edge computing. Faster response times and increased efficiency are made possible by edge computing, which processes data closer to the source and better utilization of network resources.

Edge computing technologies encompass a wide range of tools, frameworks, and protocols that enable the deployment, management, and execution of computing resources at the network edge.

**Keywords:** distributed computing, cloud computing, storage, network, analytics

## Introduction

The exponential growth of connected devices has led to the rise in popularity of edge computing. The Internet of Things (IoT), and the growing demand for real-time data distribution have all contributed to the rise in popularity of edge computing. Edge computing provides various benefits by distributing data at or close to the edge. These advantages include Decreased Latency Lower latency is achieved by reducing the amount of time that data must travel from the source to the processing point through edge computing. This is crucial for applications like autonomous vehicles, industrial automation, and augmented reality that call for responsiveness in real-time or almost real-time. Bandwidth Optimisation: By reducing the amount of data that must be transmitted to centralized cloud data centers, edge computing helps to conserve bandwidth. Edge devices can optimise bandwidth usage and lessen network congestion by filtering and optimizing data locally before sending it to the cloud through processing and analysis of statistics. Figure 1 specifies the architecture of edge computing. Enhanced Reliability: Distributed processing and storage among several edge devices, or nodes, are made possible by edge computing. This distributed architecture enhances reliability and fault tolerance since even if one edge node fails, others can continue to operate independently. It also improves resiliency by ensuring that critical services can still function in situations where network connectivity to the cloud is disrupted. Edge computing makes it possible to manage and store sensitive data locally, lowering the possibility of data breaches and guaranteeing compliance with data protection laws. This localized approach to data management provides an additional layer of privacy and security, as sensitive information doesn’t have to traverse the network or reside in a centralized data center. Scalability: Edge computing allows for scalable deployment of computing resources by distributing them across various edge devices or nodes. This scalability is particularly advantageous in scenarios where the volume of data generated is vast or when processing requirements fluctuate rapidly.
