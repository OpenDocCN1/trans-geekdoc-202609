Edge computing platforms include, operating systems, middleware, and software frameworks that support edge computing features. It enables the orchestration, management, and service deployment at the edge. Utilisation of resources is optimised, handling data distribution, effective processing and communication between edge devices are all made possible by edge computing software. To connect edge devices, edge data centres, and the centralised cloud or data centres, edge infrastructure depends on robust networking capabilities. This might include both wired and wireless technologies, including cellular networks, Ethernet, Wi-Fi, and specialised protocols like LoRaWAN or Zigbee. Security measures are incorporated into edge infrastructure to secure data and devices there. This includes intrusion detection systems, access controls, authentication methods, and encryption (Varghese, 2016). Moreover, management systems will be used to monitor and control edge devices, collects the telemetry data, perform the updates, and ensure the total health of the patients and will also performance of the edge in the infrastructure (Khan et al., 2017). Edge management is specified as the practices, technologies, tools used to manage edge computing infrastructure. At the network edge, edge devices and applications must be provisioned, monitored, configured and updated (Satyanarayanan, 2017). The performance, security, and efficiency of the distributed computing environment are all made possible by effective edge management. For edge infrastructure to remain such as reliable, secure, and performant, effective edge management will be essential for the edge. It enables the businesses to take over the advantage of the edge computing deployments, manage distributed computing environments effectively, and also it will also guarantee us the smooth operation. Thus, The Edge computing is built on the edge infrastructure, which enables us businesses to process us and analyse act on data in real-time, closer to the point of generation. It offers reduced latency, enhanced performance, and improved data privacy and security, supporting the development of edge-related technologies and applications. Edge analytics and AI (Artificial Intelligence) are complementary technologies that enable data analysis and smart decision-making at the network edge. In comparison the sending data to a centralised cloud or data centre for the processing of the edge analytics refers to the practise of analysing data or close to the source. When the data is processed through locally, either on edge devices or in edge data centres, edge analytics enables real-time insights, prompt action, and decreased latency. This strategy is especially helpful within applications like IoT deployments, autonomous vehicles, industrial automation, and smart cities where low latency, bandwidth optimisation, and real-time decision-making are essential.
