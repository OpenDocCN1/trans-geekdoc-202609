# Future Urban Computing for Smart Cities

At this point, with increased connectivity to the cloud, the network’s periphery is increasingly serving as a mobile computing system. This is as a result of the fast development of 5G networks as well as the increased integration with cloud computing. There have been a number of instances in which the phrase “mobile cloud computing” has been used in the field of mobile computing. The whole computer network will be pushed to a new decentralised computing stage, and the process of developing smart cities will be hastened as a consequence of the interaction between how mobile computing and cloud computing can be used to handle data on demand. Both of these developments will occur simultaneously.

As the number of mobile devices endures to rise, it will become more obvious that there is a need for interaction with neighbouring edge applications. When combined with enhanced dispensation, computing, and power capacities, as well as the decentralised nature of mobile computing, edge computing is anticipated to deliver meaningfully enhanced throughput, enhanced performance, and real-time responses. This is accomplished by bringing computing and data closer to the user, as well as by tailoring the dispensation requirements of each individual user. Computing at the edge and computing on mobile devices are both capable of managing localised data for the purpose of facilitating rapid response for a certain range of area sizes. Nevertheless, centralised cloud computing is also being driven by the growing amount of data generated in metropolitan areas and the geo-analysis of data across cities.

The purpose of detecting, recording, sharing, and analysing a wide range of human-related activities, a number of different devices will link to the cloud-based Internet inside the smart city. Computing on the cloud, when combined with the assistance of algorithms that are powered by artificial intelligence, will provide businesses, governments, and individual citizens with more intelligent solutions.
