+   - **Relational:** Using attributes (columns) and tuples
+   - **Hierarchical:** Combining records and fields in a logical tree structure
+   - **Distributed:** Storing information in more than one database

89. Database normalization is the means by which a DBMS organizes data in order to reduce redundancy and can include one of four normal forms: unnormalized, first normal form, second normal form, or third normal form.

# 94. Certification versus accreditation:
