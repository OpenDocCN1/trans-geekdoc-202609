# LEAP

This is a weak form of EAP. It offers client-to-server authentication only and is vulnerable to man-in-the-middle attacks and password-cracking attacks.

# PEAP

Protected EAP (PEAP), which was developed by Cisco Systems, with Microsoft, and RSA Security, is similar to EAP-TTLS. It does not require client-side certificates.

# EAP-TTLS

EAP Tunneled Transport Layer Security (EAP-TTLS) does not use a client-side certificate, allowing other authentication methods (such as passwords) for client-side authentication. EAP-TTLS is thus easier to deploy than EAP-TLS, but it is less secure when omitting the client-side certificate.

# EAP-SIM

EAP Subscriber Identity Module (EAP-SIM) is used for authentication and session key distribution for mobile phones using GSM.

# EAP-FAST

EAP Flexible Authentication via Secure Tunneling (FAST) was designed by Cisco to replace LEAP. It uses a Protected Access Credential (PAC), which acts as a pre-shared key.
