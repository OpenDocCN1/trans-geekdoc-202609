# ## Asset Security

+   1. Confidentiality, integrity, and availability (CIA) are the basic building blocks of any good security program and are commonly referred to collectively as the CIA triad.

+   2. Classification of information:

+   - **Public:** Built on a four-level model: confidential, private, sensitive, and public

+   - **Military:** Built on five-layer model: top secret, secret, confidential, sensitive but unclassified, and unclassified

+   3. Scoping and tailoring:

+   - **Scoping:** Used to determine which portions of a standard will be employed by an organization

+   - **Tailoring:** Used to customize a standard for an organization

+   4. Protection of data:

+   - **Data at rest:** Stored data that resides on a disk or in a file

+   - **Data in motion:** Data that is being transferred across a network

+   5. Data classification policy should specify:

+   - Who can access the data

+   - How the data should be secured

+   - The amount of time the data should be stored (retention)
