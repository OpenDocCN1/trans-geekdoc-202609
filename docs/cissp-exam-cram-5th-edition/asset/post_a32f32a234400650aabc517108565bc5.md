
- **Biba:** Integrity model that has two basic rules: the star property (no write up) and simple integrity (no read down). The model addressed only one goal: integrity.

- **Clark-Wilson:** Integrity model with three goals: maintaining consistency, preventing unauthorized access, and preventing improper modification. Properties include tamperproof, logged, and consistent.

- **Brewer and Nash:** Prevents conflicts of interest also known as the Chinese Wall.

- **State machine:** Basis of the Bell-LaPadula and Biba models. Concerned with state transaction and modes of operation.

- 24. Cryptography can be used for confidentiality, integrity, authentication, and/or nonrepudiation.

- 25. Internet security applications include:
  - **SET:** Developed by MasterCard and Visa
  - **SSH:** A secure replacement for Telnet
  - **TLS and SSL:** Both used to protect web communications
  - **IPsec:** The standard for VPNs and secure communication

- 26. Symmetric cryptography works by providing both parties with the same key for encryption and decryption. It provides confidentiality and is hard to break. Its weakness is that the keys are subject to exposure and must be transmitted through a different channel than the message.

- 27. Data Encryption Standard (DES) is a block encryption algorithm based on IBM’s 128-bit algorithm; 56 bits make up the key and 8 bits are used for parity. Four primary modes of DES:
  - **Electronic Code Book (ECB):** Native encryption mode used for small amounts of data. ECB is the weakest form of DES.
  - **Cipher Block Chaining (CBC):** Works by taking each bit of data from the previous block and applying it to the next.
  - **Cipher Feedback Mode (CFB):** Emulates a stream cipher and can be used when the encryption of individual characters is required.
  - **Output Feedback Mode (OFB):** Emulates a stream cipher and generates random binary bits that are combined with plaintext to create ciphertext and does not propagate errors.

- 28. Asymmetric algorithms use two different keys. The advantage is that key distribution is easier. Asymmetric algorithms are not as fast as symmetric systems.

- 29. Asymmetric algorithms include RSA, Diffie-Hellman, El Gamal, and Elliptic Curve Cryptosystem.

- 30. Hashing algorithms work well for integrity verification and include the MD series, HAVAL, Tiger, and SHA.

- 31. A public key infrastructure (PKI) allows individuals using the Internet to obtain and share cryptographic keys from a trusted authority. A PKI consists of four basic components and is governed by the X.509 standards:
  - **Certificate authority (CA):** Used to verify and issue digital certificates. The certificate includes the public key and information about it.
  - **Registration authority (RA):** Verifies authenticity for the CA. Cannot issue or sign certificates.
  - **Repository:** Accepts certificates and distributes them to authorized parties.
  - **Archive:** Responsible for the long-term storage of archived information distributed from the CA.

- 32. Cryptographic attack terms to know: known plaintext, ciphertext only, chosen plaintext, chosen ciphertext, rainbow table, and birthday attack.

- 33. Authentication protocols:
  - PAP: Plaintext
  - CHAP: Challenge response with periodic reauthentication
  - EAP: Advanced authentication techniques such as smart cards

- 34. ARP poisoning involves sending fake ARP packets to change ARP cache tables and redirect traffic.

- 35. DNS spoofing is much like ARP poisoning, except the attack attempts to poison the DNS cache. Victims can be redirected to incorrect Internet sites.

- 36. Sniffing is a passive attack that requires the attacker to gain some type of access to the network. Any plaintext information is at risk. FTP, Telnet, SMTP, and SNMP can be targets. MITM attacks can undermine cryptographic systems such as SSL and SSHv1.

- 37. Email communications must be secured. Communication between mail servers is done using SMTP, and communication between mail servers and clients is done using POP3 or IMAP. Open mail relays are a security concern as they can be used to forward spam. Security solutions for email include S/MIME, PGP, MOSS, PEM, and DKIM.

  - **2G**: GPRS, EDGE

  - **4G**: LTE
  - **5G**: SDNs

- 39. The seven layers of the Open Systems Interconnect model are application, presentation, session, transport, network, data link, and physical.

- 40. TCP/IP is the foundation of the Internet as we know it today. TCP/IP is similar to the OSI model but consists of only four layers. TCP/IP protocols include:
  - TCP: A reliable, slow, and connection-oriented protocol that ensures that packets are delivered to the destination computer
  - UDP: A fast, best-effort, non-connection-oriented protocol

- 41. Internal routing protocols can be divided into two broad categories:
  - Distance-vector protocols: RIP
  - Link-state protocols: OSPF

- 42. TCP/IP data can be addressed three ways:
  - Unicast: To one particular system
  - Multicast: To a group
  - Broadcast: To all systems

- 43. Data can be transmitted using two fundamental methods: analog and digital. Each converts the signal to a binary value.

- 44. Information can move in two ways:
  - Asynchronous communication: Two devices are not synchronized in any way.
  - Synchronous communication: Two devices are synchronized and usually controlled by a clocking mechanism.

- 45. Baseband transmission means the entire cable is used for the transmission of data so that only one thing can happen at a time.

- 46. Broadband transmission means the cable is divided into channels so that different types of data can be transmitted all at the same time.

- 47. Firewalls focus security to one point and don’t protect against insiders behind the firewall.

- 48. Common firewall terms:
  - Demilitarized zone (DMZ): A network segment that is located between the protected and unprotected networks.
  - Bastion host: A device that has been hardened and is to be deployed in the DMZ to run specific services.
  - Packet filtering: Considered a first level of defense. Access is based on rules.
  - Stateful packet filtering: Method of control that uses a state table to keep track of activity and control access.
  - Proxy: Stands between the trusted and untrusted networks.

- 49. Software-defined networking (SDN) separates the network functions from the hardware and involves three planes: infrastructure, control, and application planes. SD-WAN is an extension of SDN to the Internet.

- 50. Three solutions are used for federated identity management:
  - **SAML:** Does not provide authentication
  - **OAuth 2.0:** Provides only authorization
  - **OpenID:** Provides authentication and authorization

- 51. Important terms:
  - **Subject:** An active entity
  - **Object:** A passive entity

- 52. Granularity is the ability to which an access control system can be regulated.

- 53. Biometric system rates:
  - **FRR:** False rejection rate, or Type I error; the percentage of valid users who are falsely rejected
  - **FAR:** False acceptance rate, or Type II error; the percentage of invalid users who are falsely accepted
  - **CER:** Crossover error rate; the point at which the FRR equals the FAR

- 54. Cognitive passwords are used to verify identity based on information such as maiden name, pet name, and high school.

- 55. Centralized access control, such as RADIUS, TACACS, TACACS+, and Diameter, can be used to maintain user IDs, rights, and permissions in one central location.
