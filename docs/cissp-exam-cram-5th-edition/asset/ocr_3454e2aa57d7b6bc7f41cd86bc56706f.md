# An Example of Aggregation and Inference

Many students struggle with the concepts of aggregation and inference. The following are the two examples I use in the classroom to explain these concepts.

*Aggregation* refers to adding together available information. An aggregation attack is possible when pieces of information can be combined from different sources with different data classification levels to result in a composite view of data that exceeds the user’s access.
