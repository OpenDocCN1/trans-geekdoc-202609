# 58. Access control categories:

+   - **Technical:** Examples include encryption, authentication, network segmentation, and antivirus.
+   - **Physical:** Examples include locks, fences, guards, lights, video, and physical IDs.
+   - **Administrative:** Examples include policies, procedures, training, and pre-employment checks.
+   - **Controls:** Controls can be preventive, detective, deterrent, corrective, compensating, or recovery.

59. Access control models are established to control how subjects can access data and the user’s level of authorization. There are four primary models:

+   - **DAC:** The user controls who has access to the system; uses ACLs
+   - **MAC:** Looks to the system to determine access; typically used by organizations that handle highly sensitive data and is based on labels
+   - **RBAC:** Considered nondiscretionary; places users into groups and implicitly assigns access; used by companies with high turnover
+   - **ABAC:** More flexible; can make use of XACML; uses rights to access a resource that is passed on policies that combine attributes

60. Intrusion detection can be signature, statistical, or anomaly based and is host or network based.

# 61. Access management facility controls include:

+   - **Lighting:** Used to discourage crime and protect employees. The NIST standard states that an area should be illuminated at 2 feet wide by 8 feet high.
+   - **Fencing:** A 3- to 4-foot fence is a deterrent; a 6- to 7-foot fence is hard to climb; an 8-foot fence with three strands of barbed wire acts as a serious deterrent.

Perimeter controls include gates, guards, dogs, CCTV, turnstiles, mantraps, and alarms.
