$y^2 = x^3 + ax + b$

along with a single point O, the point at infinity.

The space of the elliptic curve has the following properties:

+   ▶ Addition is the counterpart of modular multiplication.
+   ▶ Multiplication is the counterpart of modular exponentiation.

Thus, given two points, P and R, on an elliptic curve where P = KR, finding K is known as the _elliptic curve discrete logarithm problem_. ECC is fast. According to RFC 4492, a 163-bit key used in ECC has similar cryptographic strength to a 1,024-bit key used in the RSA algorithm. It can therefore be implemented in smaller, less-powerful devices such as smartphones, tablets, smart cards, and other handheld devices.

# Merkle-Hellman Knapsack

_Merkle-Hellman Knapsack_ (Knapsack) is an asymmetric algorithm based on fixed weights. Although this system was popular for a while, it was broken in 1982.
