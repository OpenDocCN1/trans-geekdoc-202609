Job titles can be confusing because different organizations tend to use
different titles for identical positions. In addition, smaller organizations tend
to combine duties under one position or title. For example, some network
architects are called network engineers. The critical concept for a security
professional is to understand that, to avoid conflicts of interest, certain roles
should not be combined. Table 8.1 lists some examples of role combinations
and whether it’s okay to combine them.

# TABLE 8.1 Separation of Duties

| :--- | :--- | :--- |
| Systems analyst | No | Security administrator |
| Application programmer | Yes | Systems analyst |
| Help desk | No | Network administrator |
| Data entry | Yes | Quality assurance |
