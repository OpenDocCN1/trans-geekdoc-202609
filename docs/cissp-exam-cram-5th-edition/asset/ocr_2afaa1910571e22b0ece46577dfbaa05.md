41. Internal routing protocols can be divided into two broad categories:

+   - Distance-vector protocols: RIP
+   - Link-state protocols: OSPF

42. TCP/IP data can be addressed three ways:

+   - Unicast: To one particular system
+   - Multicast: To a group
+   - Broadcast: To all systems

43. Data can be transmitted using two fundamental methods: analog and digital. Each converts the signal to a binary value.

44. Information can move in two ways:

+   - Asynchronous communication: Two devices are not synchronized in any way.
+   - Synchronous communication: Two devices are synchronized and usually controlled by a clocking mechanism.

45. Baseband transmission means the entire cable is used for the transmission of data so that only one thing can happen at a time.

46. Broadband transmission means the cable is divided into channels so that different types of data can be transmitted all at the same time.

47. Firewalls focus security to one point and don’t protect against insiders behind the firewall.

48. Common firewall terms:

+   - Demilitarized zone (DMZ): A network segment that is located between the protected and unprotected networks.
+   - Bastion host: A device that has been hardened and is to be deployed in the DMZ to run specific services.
+   - Packet filtering: Considered a first level of defense. Access is based on rules.
+   - Stateful packet filtering: Method of control that uses a state table to keep track of activity and control access.
+   - Proxy: Stands between the trusted and untrusted networks.
