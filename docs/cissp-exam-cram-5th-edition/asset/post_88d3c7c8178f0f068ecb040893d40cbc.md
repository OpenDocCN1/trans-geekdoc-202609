
- **Relational:** Using attributes (columns) and tuples
- **Hierarchical:** Combining records and fields in a logical tree structure
- **Distributed:** Storing information in more than one database

89. Database normalization is the means by which a DBMS organizes data in order to reduce redundancy and can include one of four normal forms: unnormalized, first normal form, second normal form, or third normal form.

90. There are three known database interface languages: ODBC, OLE DB, and JDBC.

91. The SDLC includes the following stages: project initiation, functional design and planning, system design, functional review, software development, product installation, operation and maintenance, and disposal.

92. Software development models include waterfall, spiral, RAD, JAD, CASE, and prototyping.

93. Security weaknesses at the code level include buffer overflows, covert channels, memory reuse, and backdoors.

## 94. Certification versus accreditation:

- **Certification:** Developers certify that the software has passed all the tests and is operating as defined.
- **Accreditation:** Management authorizes the software to operate and accepts any risk.
