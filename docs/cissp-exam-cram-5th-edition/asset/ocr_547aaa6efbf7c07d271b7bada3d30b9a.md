# Centralized and Decentralized Access Control Models

Access control models can be divided into two distinct types: *centralized* and *decentralized*. Depending on an organization’s environment and requirements, one methodology typically works better than the other.

# Centralized Access Control

Centralized access control systems maintain user IDs, rights, and permissions in one central location. Remote Authentication Dial-In User Service (RADIUS), Terminal Access Controller Access-Control System (TACACS), and Diameter are all examples of centralized access control systems.
