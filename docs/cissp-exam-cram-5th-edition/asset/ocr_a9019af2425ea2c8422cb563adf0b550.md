+   - Cipher locks: Programmable
+   - Preset locks: Warded or pin and tumbler
+   - Device locks: Used to prevent the theft of equipment

# # Security Assessment and Testing

63. Assessment and audit perspectives:

+   - **Internal:** Has the advantage that insiders know the environment; can be conducted before a required third-party audit
+   - **External:** Has the advantage of no bias; can be used for compliance audits
+   - **Third-party:** Has the advantage that it helps provide an external perspective; may be required, depending on regulation

64. Penetration testing is the process of evaluating an organization’s security measures. Testing can be performed in a number of ways, including internal, external, whitebox, and blackbox testing. Penetration testing not only tests vulnerabilities but attempts to exploit them.

65. Log review is an important task and typically makes use of a SIEM.

66. Synthetic transactions are actions run against a monitored system to see how it responds.

+   - **Real-user monitoring:** Monitors actual users
+   - **Synthetic performance monitoring:** Uses scripts that mimic a typical user; also called proactive monitoring

67. Two types of fuzz testing are generation-based and mutation-based testing.

68. Sensitive information is not included in a SOC 3 report as this type of report is available to the public.

69. Disaster recovery is a subset of business continuity activities.
