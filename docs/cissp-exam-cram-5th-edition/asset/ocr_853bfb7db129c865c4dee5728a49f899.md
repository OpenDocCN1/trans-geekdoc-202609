# FIGURE 4.19 Asymmetric Encryption

Here’s how asymmetric encryption functions: Imagine that you want to send a client a message. You use your client’s public key to encrypt the message. When your client receives the message, he uses his private key to decrypt it. The important concepts here are that if the message is encrypted with the public key, only the matching private key will decrypt it.
