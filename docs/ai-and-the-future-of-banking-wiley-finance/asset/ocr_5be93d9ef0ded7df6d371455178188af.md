# **TABLE 24**  Table of Common Cybercrime Expressions

| Expression | Explanation |
|---|---|
| Authentication | In the context of computer systems, ‘authentication’ is the process by which the system confirms the individual’s identity. It is considered one of the five pillars of information assurance, or ‘IA’. (The others are integrity, availability, confidentiality and non-repudiation.)^34 | 
| Malware | Malware is any software intentionally designed to cause damage to a computer, server, client or computer network and may include viruses or worms. |
| Viruses | A type of malicious software or ‘malware’ that, when executed, replicates itself by modifying other computer programs and inserting its own code. When this replication succeeds, the affected areas are then said to be ‘infected’ with a computer virus.^35 |
| Worms | An internet worm is a program that spreads across the internet by replicating itself on computers via their network connections.^36 |
| Trojan | A malicious program that misleads users about its true intent. The term is based on the ‘Trojan Horse’ of Greek mythology. For example, a user is duped into opening an e-mail attachment disguised to appear not suspicious (e.g. a routine form to be filled in), leading to access to an individual’s personal or banking details.^37 |
| Phishing | Fooling a computer user into submitting personal information by creating a counterfeit website that looks like a real (and trusted) site.^38 |
| Click fraud | A click on an ad that is not the result of any genuine interest in what that ad is offering, and which as a result generates fraudulent revenue in a ‘pay per click’ environment.^39 |
| Botnets | A series of interconnected ‘bots’ that may be affected by a common set of malware. The term *botnet* is derived from the words *robot* and *network*. A bot in this case is a device infected by malware, which then becomes part of a network or *net* of infected devices controlled by a single attacker or attack group.^40 |
| Cryptology | Cryptology (or cryptography) is a method of protecting information and communications through the use of codes so that only those for whom the information is intended can read and process it.^41 |
| Firewalls | Software or firmware that enforces a set of rules about what data ‘packets’ will be allowed to enter or leave a network. |
| Intrusion detection systems/techniques | Systems and processes that identify intrusion, such as the analysis of traffic, detection of anomaly, or detection of malware.^42 |
| Honeypots | A form of security approach whereby data (for example) that appears to be part of a wider database is in fact isolated and monitored for the purposes of countering cybercrime. |
