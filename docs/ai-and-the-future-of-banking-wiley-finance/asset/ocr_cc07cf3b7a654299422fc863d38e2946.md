+   2. **Transparency:** In a Blockchain environment, it is possible to see what transactions have been made by an entity’s ‘public address’. This may look something like ‘2XT1bhs GHkBxxxTvpUHEkngT2TbyCt7NKLs ent1BTC’, even if it is not known to whom or to what entity that address belongs. The ability to track these payments and to audit them becomes extremely interesting for management of money within the supply chain and also with respect to collecting taxes.

+   3. **Immutability:** An immutable object in programming is an object whose state cannot be changed after it has been created, compared to a ‘mutable’ object, which can be changed. This ‘immutability’ means that once data has been entered into the Blockchain it is permanent and tamper-proof. This is done using what is known as a ‘cryptographic hash function’, which means that every transaction has a ‘hash reference’ (256 bits in length) and also ‘hash pointers’, which link one ‘hash’ to the previous one, creating the Blockchain.
