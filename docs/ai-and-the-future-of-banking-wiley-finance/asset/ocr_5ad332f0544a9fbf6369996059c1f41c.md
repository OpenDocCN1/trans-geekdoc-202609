|---|---|---|
|  | Bias-variance tradeoff | Described as one of the central problems in machine learning, it reflects the challenge of creating a mathematic model that is accurate in training data, but also responds well to unseen data. |
|  | Model and feature selection | The process of selecting relevant variables and predictors for use in the construction of mathematical models, ensuring simplification, and creating better ability for the model to generalise, for example. |
|  | Model tuning | Whilst a generic set of parameters (a special kind of variable) used in a model may provide a starting point for analysis and will generally result in a well-performing model, the model may not have the optimal configurations for a particular dataset and business problem and may need to be tuned. |
|  | Classification | Where a set of data has been divided into predefined groups and patterns are found in the data that allows them to be differentiated within those group, these identified patterns then can be used to classify other data. |
|  | Neural nets | Neural nets or neural networks are loosely modelled on the human (mammalian) brain and comprise interconnected systems or processing elements that process information by responding to external inputs. |
|  | Deep learning | Also known as ‘deep structured’ or ‘hierarchical’ learning, it is a supervised, semi-supervised or unsupervised machine learning method based on artificial neural networks. |
|  | Recurrent neural networks, including LSTM | LSTM (long short-term memory) is a subset of neural networks and introduces the concept of time, allowing the network to deal with sequences of information. Especially relevant with dynamic data such as voice and video. |
