# **TABLE 2**  Knowledge Requirements for Machine Learning

| Competency level | Generic description | Explanation |
|---|---|---|
| Base requirements | Linear algebra | A branch of mathematics involving linear equations and linear functions. Often used in engineering and science, it allows natural phenomena to be modelled and then computerised. |
|  | Probability theory (basic, not measure-theoretic) | A branch of mathematics concerned with probability. The theory treats the concept as a form of rigorous mathematical assumptions or axioms to create a set of possible outcomes. |
|  | Optimisation theory | Mathematical selection of the best element with regard to certain criteria, often used in quantitative disciplines such as computer science and engineering to operations research and economics. |
|  | Python for Data Science and Artificial Intelligence | Python is a high-level, general-purpose programming language, often used in research and data science. Popular because it is relatively easy to interpret and learn, it handles different data structures well and has some powerful statistical and visual libraries. |
| Further development | Probability and statistics | Two related but associated academic studies that are branches of mathematics concerned with the laws governing random events. This includes the collection, analysis, interpretation and display of numerical data. Statistical analysis often uses probability distributions. |
|  | Linear regression method | A statistical linear approach to finding the relationship between a dependent variable and an independent variable. It helps to understand whether a set of variables does a good job in predicting an outcome, or which variables in particular are most significant in predicting an outcome. |
|  | Dimensionality reduction | A process that allows the ability to reduce the number of variables yet still keep (or improve) the final outcome of a mathematical model. |
|  | Unsupervised machine learning | Unsupervised learning is a type of self-organised neuroscientific approach to learning that helps find previously unknown patterns in data set without preexisting insight. |
