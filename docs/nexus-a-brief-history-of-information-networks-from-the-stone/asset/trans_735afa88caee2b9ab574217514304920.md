

# 印刷媒体与猎巫运动的历史

印刷媒体与猎巫运动的历史表明，一个不受管制的信息市场并不一定会导致人们识别并纠正自己的错误，因为愤怒可能优先于真相。为了让真相胜出，有必要建立拥有权力、能够将平衡倾向于事实的策展机构。然而，正如天主教会的历史所表明的那样，此类机构可能会利用其策展权力来压制对自身的任何批评，将所有替代观点定性为错误，并阻止机构自身的错误被曝光和纠正。是否有可能建立更好的管理机构，利用其权力来促进对真理的追求，而不是为自己谋取更多权力？

# 早期现代欧洲与科学革命

早期现代欧洲见证了此类策展机构的基础，正是这些机构——而非印刷机或像《天体运行论》这样的特定书籍——构成了科学革命的基础。这些最重要的策展机构并非大学。许多科学革命的重要领导人并非大学教授。例如，尼古拉·哥白尼、罗伯特·波义耳、第谷·布拉赫和勒内·笛卡尔都不担任学术职位。斯宾诺莎、莱布尼茨、洛克、贝克莱、伏尔泰、狄德罗或卢梭也是如此。

# 策展机构在科学革命中的作用

在科学革命中发挥核心作用的策展机构连接了大学内外的学者和研究人员，从而形成了一个涵盖整个欧洲并最终遍及全球的信息网络。为了推动科学革命，科学家们必须依赖远方同事发表的信息。这种对从未见过之人工作的信任，明显体现在皇家学会（成立于1660年）和法国科学院（1666年）等科学协会中；体现在《皇家学会哲学汇刊》（1665年）和《皇家科学院史》（1699年）等科学期刊中；也体现在《百科全书》（1751–72年）的架构师等科学出版商中。这些机构基于经验证据收集信息，从而将注意力集中在哥白尼的发现，而非克拉默的幻想上。当一篇文章提交给《皇家学会哲学汇刊》时，编辑提出的主要问题不是：“有多少人愿意为阅读此文付费？”而是：“有什么证据表明这是真的？”

# 科学权威的兴起

起初，这些新机构看起来像蜘蛛网一样脆弱，缺乏重塑人类社会所需的权力。与猎巫领域的专家不同，《皇家学会哲学汇刊》的编辑无法对任何人施以酷刑并处决。与天主教会不同，科学院并不拥有广袤的领土和预算。但科学机构凭借一种极具原创性的信任主张获得了影响力。通常，教会告诉人们必须信任它，因为它拥有绝对的真理，以一本绝无谬误的圣书形式存在。而科学机构则因其拥有强大的自我纠正机制而获得权威，这些机制能够揭露并纠正机构自身的错误。正是这些自我纠正机制，而非印刷技术，构成了科学革命的动力。

# 对无知的发现

换句话说：科学革命是由对无知的发现所启动的。\[91\] 一神教宗教假设它们拥有通往绝无谬误知识源的途径。基督徒有《圣经》，穆斯林有《古兰经》，印度教徒有《吠陀》，佛教徒有《三藏》。科学文化没有类似的圣书，也不声称其英雄是绝无谬误的先知、圣徒或天才。科学项目始于摒弃绝无谬误的幻想，并继续构建一个将错误视为不可避免的信息网络。当然，人们经常谈论哥白尼、达尔文和爱因斯坦的天才，但没有一人被视为无懈可击。他们都犯过错误，甚至最受赞誉的科学论著也肯定会包含错误和漏洞。

因为即使是天才也容易受到确认偏误的影响，你不能指望他们纠正自己的错误。科学是一项团队工作，依赖于机构合作，而非依赖于个别科学家或例如一本绝无谬误的书。当然，机构也容易出错。尽管如此，科学机构与宗教机构不同，在于它们奖励怀疑和创新，而非从众。科学机构也与阴谋论不同，在于它们奖励自我怀疑。阴谋论者倾向于对现有共识持极度怀疑态度，但当涉及到他们自己的信念时，他们会失去所有怀疑精神，并陷入确认偏误。\[92\] 科学的标志不仅仅是怀疑，而是自我怀疑，在每个科学机构的核心，我们都能找到一个强大的自我纠正机制。科学机构确实会就特定理论（如量子力学或进化论）的准确性达成广泛共识——但这仅仅是因为这些理论成功地经受住了旨在反驳它们的密集尝试，这些尝试不仅由局外人发起，也由机构成员本身发起。

## 自我纠正机制

作为一种信息技术，自我纠正机制与圣书截然相反。圣书被假定为绝无谬误的。自我纠正机制拥抱易错性。自我纠正指的是一个实体用来纠正自身的机制。一位老师纠正学生的作文，这不是自我纠正机制；学生并没有纠正自己的文章。一位法官将罪犯送进监狱，这不是自我纠正机制；罪犯并没有揭露自己的罪行。当盟军击败并瓦解纳粹政权时，这不是自我纠正机制；如果任其自生自灭，德国不会对自己进行去纳粹化。但是，当一本科学期刊发表一篇纠正先前文章中错误的文章时，这就是机构自我纠正的一个例子。
