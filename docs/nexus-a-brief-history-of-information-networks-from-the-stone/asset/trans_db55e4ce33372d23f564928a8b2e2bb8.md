

# 第二原则：去中心化

保护民主免受极权监控政权崛起的第二个原则是去中心化。民主社会绝不允许将其所有信息集中在一个地方，无论该节点是政府还是私营企业。建立一个收集公民信息的国家医疗数据库，以提供更好的医疗服务、预防流行病和开发新药，可能非常有用。但是，将此数据库与警察、银行或保险公司的数据库合并将是一个非常危险的想法。这可能会使医生、银行家、保险人和警察的工作更加高效，但这种超高效率可能会为极权主义铺平道路。为了民主的生存，某种程度的低效率是特征而非缺陷。为了保护个人的隐私和自由，最好是既不让警察，也不让老板了解我们的一切。

多个数据库和信息渠道对于维持强大的自我纠正机制也是必不可少的。这些机制需要各种相互制衡的机构：政府、法院、媒体、学术界、私营公司、非政府组织。每个机构都有缺陷且会消亡，因此必须由其他机构进行监督。为了相互监督，这些机构必须拥有独立的信息获取渠道。如果所有报纸都从政府获取信息，它们就无法揭露政府的腐败。如果学术界的研究和出版依赖于单一企业巨头的数据库，科学家们还能对该公司的活动提出批评吗？单一档案使审查变得容易。

# 第三原则：互惠

第三个民主原则是互惠。如果民主国家加强对个人的监控，它们必须同时加强对政府和企业的监控。税务机关或福利机构收集更多关于我们的信息并不一定是坏事。这可能有助于使税收和社会保障系统不仅更高效，而且更公平。糟糕的是所有信息单向流动：从下往上。俄罗斯联邦安全局收集了大量关于俄罗斯公民的信息，而公民本身几乎对联邦安全局及普京政权的内部运作一无所知。亚马逊和TikTok了解我的偏好、购买和个性方面的大量信息，而我几乎对它们的商业模式、税收政策和政治偏好一无所知。它们如何赚钱？它们是否缴纳了应缴的所有税款？它们是否听从政治大佬的指令？它们是否收买了政客？

民主需要平衡。政府和企业经常开发应用程序和算法作为自上而下监控的工具。但算法同样可以成为强大的自下而上透明度和问责制工具，揭露贿赂和逃税行为。如果它们更了解我们，而我们同时更了解它们，平衡就得以保持。这不是一个新想法。在十九和二十世纪，民主国家极大地扩大了对公民的政府监控，例如，九十年代的意大利或日本政府拥有的监控能力，是专制的罗马皇帝或日本将军只能梦寐以求的。意大利和日本仍然保持民主，因为它们同时提高了政府的透明度和问责制。相互监督是维持自我纠正机制的另一个重要元素。如果公民更多地了解政客和首席执行官的活动，就更容易追究他们的责任并纠正他们的错误。

# 第四原则：变化与休息

第四个民主原则是监控系统必须始终为变化和休息留出空间。在人类历史上，压迫可以采取剥夺人们改变可能性的形式，也可以采取剥夺人们休息可能性的形式。例如，印度教种姓制度是基于神话，认为神灵将人们分为僵化的种姓，任何试图改变某人地位的行为都等同于反抗神灵和宇宙的正确秩序。现代殖民地以及巴西和美国等国家的种族主义基于类似的神话，认为上帝或自然将人们分为僵化的种族群体。据说，忽视种族或试图混合种族是对神法或自然法的罪过，可能导致社会秩序崩溃甚至人类物种的毁灭。

在光谱的另一端，现代极权政权如斯大林的苏联相信人们能够进行几乎无限的变化。通过无情的社会控制，甚至根深蒂固的生物特征，如自私和家庭纽带，都可以被连根拔起，创造出一个新的社会主义人。

国家特工、神父和邻居的监控对于强加僵化的种姓制度和极权再教育运动至关重要。新的监控技术，尤其是与社会信用系统相结合时，可能会迫使人们顺应新的种姓制度，或不断改变他们的行为、思想和个性，以符合来自上层的最新指令。

因此，使用强大监控技术的民主社会必须警惕过于僵化和过于灵活这两个极端。例如，考虑一个利用算法监测我健康的国家医疗系统。在一个极端，系统可能会采取过于僵化的方法，并要求其算法预测我可能会患哪些疾病。算法随后扫描我的基因数据、病历、社交媒体活动、饮食和日程安排，得出结论：我五十岁时有91%的几率心脏病发作。\[5\] 如果这个僵化的医疗算法被我的保险公司使用，可能会促使保险公司提高我的保费。如果被我的银行家使用，可能会导致他们拒绝向我提供贷款。如果被潜在的配偶使用，他们可能决定不与我结婚。

但是，认为僵化的算法真正发现了关于我的真相是一个错误。人体不是一块固定的物质，而是一个不断生长、衰败和适应的复杂有机系统。我们的心灵也在不断运动。思想、情感和感觉浮现，持续一段时间，然后消失。在我们的大脑中，几小时内就会形成新的突触。\[6\] 例如，仅仅阅读这一段就会稍微改变你的大脑结构，鼓励神经元形成新的连接或放弃旧的连接。你已经比开始阅读时有所不同了。即使在基因层面，情况也出奇地灵活。虽然个人的DNA在整个生命过程中保持不变，但表观遗传和环境因素可以显著改变相同基因的表达方式。
