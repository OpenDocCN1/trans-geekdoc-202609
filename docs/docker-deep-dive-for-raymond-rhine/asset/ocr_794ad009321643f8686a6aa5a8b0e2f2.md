# Multi-architecture builds

You can use the `docker build` command to build images for multiple architectures, including ones different from your local machine. For example:

+   - Docker on an AMD machine can build ARM images
- Docker on an ARM machine can build AMD images

You also have the option to perform build builds locally or in the cloud. Both work with the standard `docker build` command and only require minimal backend configuration.
