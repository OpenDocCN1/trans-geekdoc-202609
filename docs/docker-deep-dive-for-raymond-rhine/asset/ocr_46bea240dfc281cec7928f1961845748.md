It's published on port `5001`, meaning you can point your browser to the name or IP of any swarm node on `5001`. If you're using Multipass, the node IPs usually start with `192.168`, and you can find them by running a `multipass list` command from your host's terminal. Alternatively, you can run an `ip` command inside a VM and use the IP address of the `enp0s1` interface.
