In summary, hypervisors perform hardware virtualization where they divide hardware resources into virtual versions and package them as VMs. Container engines perform OS virtualization where they divide OS resources into virtual versions and package them as containers. VMs look and feel exactly like physical servers. Containers look and feel exactly like regular operating systems.
