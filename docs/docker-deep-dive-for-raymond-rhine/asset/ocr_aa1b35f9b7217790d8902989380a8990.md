machine emulating the target architecture. It works most of the
time but is slow and doesn’t have a shared cache.

Build Cloud is a new service from Docker, Inc. that performs
builds in the cloud on native hardware without requiring
emulation. It’s very fast, lets you share a common build cache
with teammates, and is seamlessly integrated into Docker
Desktop and any version of the Docker Engine using a version
ofbuildx supporting the cloud driver. It also integrates with
GitHub Actions and other CI solutions. At the time of writing,
Docker Build Cloud is a subscription service you have to pay for.

We’ll use both in future chapters, but I ran the following
command to build AMD and ARM versions of the

`nigelpoulton/tu-demo` image using Docker Build Cloud.

```
$ docker buildx build \
  --builder=cloud-nigelpoulton-ddd-cloud \
  --platform=linux/amd64,linux/arm64 \
  -t nigelpoulton/tu-demo:latest --push
```
