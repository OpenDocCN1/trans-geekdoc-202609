Let's assume you need the rollout to proceed in a staged manner by updating two replicas at a time with a 20-second delay between each. You can use the following command to accomplish this.

```
$ docker service update \\
  --image nigelpoulton/ddd-book:web0.2 \\
  --update-parallelism 2 \\
  --update-delay 20s \\

uber-svc
overall progress: 2 out of 12 tasks
1/12: running [====================================]
2/12: running [================================]
3/12: ready [====================================>
4/12: ready [====================================>
5/12:
6/12:
<Snip>
11/12:
12/12:
```

Let's review the command.

**docker service update** lets you update existing services. This example tells Docker to update all 12 replicas to the new web0.2 version of the image. The --update-parallelism flag tells Docker to update two replicas at a time, and the --update-delay flag tells Docker to insert a 20-second cool-off
