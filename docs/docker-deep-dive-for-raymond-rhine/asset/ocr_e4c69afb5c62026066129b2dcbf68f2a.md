```
command: python app.py      <-- Run this command
deploy:
  replicas: 4                             <-- Deploy 4 replicas
  update_config:\                        <-- When you perform an
    parallelism: 2                       <-- update 2 replicas at a
    delay: 10s                           <-- wait 10 seconds between
    failure_action: rollback             <-- and perform a rollback
  constraints:
    'node.role == worker'               <-- Only run replicas on worker
  restart_policy:
    condition: on-failure                <-- Only restart if
    delay: 5s                            <-- they've failed (non-zero)
    max_attempts: 3                      <-- wait five seconds between
    window: 120s                          <-- only three restarts
                                      -- and give up after
networks:
  - counter-net                          <-- Connect replicas to the
ports:
  - published: 5001                     <-- Publish the service endpoint
    target: 8080                         <-- map traffic to each replica
volumes:
  - type: volume                        <-- Mount the "counter-vol"
    source: counter-vol                 <-- "/app" in each service
    target: /app
```

The **image** key is the only mandatory key and tells Docker which image to use when creating service replicas. Swarm stacks don't support building images at deploy time, so the image must exist before you deploy the app. Docker is also **opinionated** and assumes you want to pull images from Docker Hub.
