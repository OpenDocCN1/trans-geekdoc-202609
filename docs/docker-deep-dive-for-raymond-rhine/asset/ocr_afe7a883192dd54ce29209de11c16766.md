+   - Dockerfile FROM instruction specifies the base image. It's usually the first instruction in a Dockerfile, and it is considered a good practice to build from Docker Official Images or images from Verified Publishers. FROM is also used to identify new build stages in multi-stage builds.

+   - Dockerfile RUN instruction lets you run commands during a build. It's commonly used to update packages and install dependencies. Every RUN instruction creates a new image layer.

+   - Dockerfile COPY instruction adds files to images, and you'll regularly use it to copy your application code into a new image. Every COPY instruction creates an image layer.

+   - Dockerfile EXPOSE instruction documents an application's network port.

+   - Dockerfile ENTRYPOINT and CMD instructions tell Docker how to run the app when starting a new container.

+   - Some other Dockerfile instructions include LABEL, ENV, ONBUILD, HEALTHCHECK and more.
