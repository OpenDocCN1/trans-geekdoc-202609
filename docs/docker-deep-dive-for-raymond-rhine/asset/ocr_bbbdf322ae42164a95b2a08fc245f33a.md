When you deploy the app, you'll use the `docker compose` command to send the `compose.yaml` file to Docker. Docker will create the `counter-net` network and the `counter-vol` volume and use the Dockerfile to build an OCI image for the `web-fe` service. The Dockerfile tells Docker to copy the code from the `app` folder into the image. Docker then starts the `web-fe`, mounts the `counter-vol` volume, and connects to the `counter-net` network. It also starts a container for the `redis` service and connects that to the same `counter-net` network.

Docker also uses the name of the build context directory to name the services, network, and volume so that you can easily identify them.
