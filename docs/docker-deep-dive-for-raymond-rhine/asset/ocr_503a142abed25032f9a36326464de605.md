# Build a Swarm lab

This section shows you how to build a three-node swarm lab with a single manager and two workers. You can skip to the next section if you already have a swarm.

You can build the lab in Multipass, Play with Docker, or just about any Docker Docker environment. However, I don't recommend using Docker Desktop, as you only get a single swarm node.
