Let’s create a new service and attach it to the uber-net network.

```
$ docker service create --name uber-svc \
  --network uber-net \
  -p 8080:8080 --replicas 12 \
  nigelpoulton/ddd-book:web0.0
```

Let’s step through what just happened.

On the first line, you named the service uber-svc. You then used the **--network** flag to tell Docker to attach all service replicas to the new uber-net network. Then, you mapped 8080 on every swarm node to port 8080 in all 12 replicas. Finally, you told Docker which image to base the 12 replicas on.

This mode of publishing a service on every swarm node, including nodes not even running replicas, is called **ingress mode** and is the default. The alternative is **host mode**, which only publishes a service on nodes running replicas.
