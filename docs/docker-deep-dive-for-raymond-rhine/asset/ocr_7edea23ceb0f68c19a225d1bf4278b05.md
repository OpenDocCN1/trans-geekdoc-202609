However, if --advertise-addr is a load balancer, you must use --listen-addr to specify a local IP.
I recommend specifying both flags in important production environments. However, for most lab environments, you can just run a docker swarm init without any flags.
You can also specify a different port for the advertise and listen addresses, but using the default 2377 is common.
