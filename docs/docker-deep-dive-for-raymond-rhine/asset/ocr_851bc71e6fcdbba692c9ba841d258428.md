Pulling the right image for your system is one thing, but what about building images for all these different architectures?

The docker buildx command makes it easy to create multi-architecture images. For example, you can use Docker Desktop on linux/arm to build images for linux/amd and possibly other architectures. We'll perform builds like these in future chapters, but docker buildx offers two ways to create multi-architecture images:

+   - Emulation
- Build Cloud

Emulation mode performs builds for different architectures on your local machine by running the build inside a QEMU virtual images
