borrowed from the Docker samples buildme repo on GitHub. Don’t worry if you’re not a Go programmer; you don’t need to be. You only need to know that it compiles the client and server apps into executable files that do not need the Go language or any other tools or runtimes to execute.

Here’s the Dockerfile:

```
FROM golang:1.22.1-alpine AS << Stage 0
WORKDIR /src
COPY go.mod go.sum .
RUN go mod download
COPY . .

FROM base AS-client << Stage 1
RUN go build -o /bin/client ./cmd/client

FROM base AS build-server << Stage 2
RUN go build -o /bin/server ./bin/server

FROM scratch AS prod << Stage 3
COPY --from=build-client /bin/client /bin/
COPY --from=build-server /bin/server /bin/
ENTRYPOINT [ "/bin/server" ]
```
