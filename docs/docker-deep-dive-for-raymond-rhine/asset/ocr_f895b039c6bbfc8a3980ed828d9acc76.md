Restart Docker on one of your managers to see if it automatically re-joins the cluster.

```
$ sudo systemctl restart docker
```

Try to list the nodes in the swarm.

```
$ docker node ls
Error response from daemon: Swarm is encrypted and needs to be un
```

Docker has restarted, but the manager hasn’t been allowed to re-join the swarm. You can prove this by running a **docker node ls** from one of your other managers and the restarted manager will be listed as **down** and **unreachable**.

Run the **docker swarm unlock** command to unlock the swarm for the restarted manager and provide the unlock key.

```
$ docker swarm unlock
Please enter unlock key: <enter your key>
```
