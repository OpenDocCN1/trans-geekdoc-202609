```
condition: on-failure
max_attempts: 3
delay: 5s
window: 120s
```

This app tells Docker to restart replicas if they fail, to attempt a maximum of 3 restarts, to wait 5 seconds between each restart attempt, and to wait up to 120 seconds to decide if the restart worked.

The **networks** key tells Docker to attach all replicas to the **counter-net** network.

```
web-fe:
networks:
  - counter-net
```

The **ports** block publishes the app on port 5001 on the ingress network and port 8080 on the counter-net network. This means external traffic can hit any swarm node on 5001 and get redirected to the service replicas on 8080.

```
web-fe:
ports:
  published: 5001
  target: 8080
```
