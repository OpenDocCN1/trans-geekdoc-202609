Run the following command from the node that will be your swarm manager.

```
$ docker swarm init
Swarm initialized: current node (lhma...w4nn) is now a manager.
<Snip>
```

Copy the docker swarm join command shown in the output and paste it into the two nodes you want to join as workers.

# Worker 1

```
$ docker swarm join --token SWMTKN-1-2hl6....31lgq 172.31.40.19
This node joined a swarm as a worker.
```

# Worker 2
