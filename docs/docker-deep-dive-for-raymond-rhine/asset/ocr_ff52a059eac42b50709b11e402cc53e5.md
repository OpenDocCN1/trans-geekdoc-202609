# 12: Docker and WebAssembly

WebAssembly is driving the third of cloud computing, and Docker is evolving to take advantage.

We built the first wave on virtual machines (VMs), the second on containers, and we're building the third on WebAssembly. Each wave is driving smaller, faster, and more secure workloads, and all three will work together in the future of cloud computing.

![](bbox=[0.233, 0.467, 0.672, 0.678])

In this chapter, you'll write a simple WebAssembly application and use Docker to containerize and run it in a container. The goal is to introduce you to WebAssembly and show you how easy it is to work with Docker and WebAssembly together.
