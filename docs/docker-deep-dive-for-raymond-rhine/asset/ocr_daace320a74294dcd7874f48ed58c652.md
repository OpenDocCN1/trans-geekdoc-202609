**-d** flag runs the container in the background, and the **--name** flag calls it **c1**. The **-p 5005:8080** maps port 5005 on your Docker host to port 8080 inside the container, which means you'll be able to point a browser to port 5005 and reach the app. The last line tells Docker to base the container on the **nigelpoulton/ddd-book:ch8.node** image you just built.

Docker will use the local copy of the image from the previous steps. It only pulls a copy from Docker Hub if it doesn't have a local copy.
