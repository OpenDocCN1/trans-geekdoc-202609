Type Ctrl PQ to exit the container and run another docker ps command to verify the container is still running this time.

```
root@d3c892ad0eb3:/# <Ctrl PQ>
read escape sequence

$ docker ps
CONTAINER ID IMAGE COMMAND STATUS NAMES
d3c892ad0eb3 ubuntu:24.04  "bash"  Up 27 seconds ddd-ctr
```

The container is still up.
