As mentioned, the <command> is optional; you don't need it if the image has an Entrypoint or Cmd instruction. If you specify a <command>, it will override a Cmd instruction but will be appended to an Entrypoint instruction.

The following command starts a new background container based on the Alpine image and tells it to run the sleep 20 command, causing it to run for 20 seconds and then exit. The -rm flag cleans up the exited container so you don't have to delete it manually.

```
$ docker run --rm -d alpine sleep 20
```

If you run a docker ps command before the 20-second timer expires, you'll see the container in the output. If you run it after 20 seconds, the container will be gone. The --rm argument automatically cleans up the exited container.

Most production images will specify an Entrypoint or Cmd instruction.
