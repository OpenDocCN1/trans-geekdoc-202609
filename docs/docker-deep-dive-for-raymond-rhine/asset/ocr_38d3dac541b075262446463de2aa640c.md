You start with application code and infrastructure requirements — things like networks, ports, volumes, and secrets. You containerize the application and combine all the services and infrastructure definitions into a single declarative stack file. You set the number of replicas, as well as rollout and restart policies. Then, you use the `docker stack deploy` command to deploy the application from the stack file.

You should also perform all updates declaratively by updating the stack file and redeploying the app.
