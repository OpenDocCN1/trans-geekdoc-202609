Run a docker service ls command to see a list of all the services on your swarm.

| ID | NAME | MODE | REPLICAS | IMAGE |
|---|---|---|---|--|
| z7o...uw | web-fe | replicated | 5/5 | nigelpoulton/ddd... |

The output shows a single service along with some basic config and state info. Among other things, you can see the name of the service and that all five replicas are running. Some of the replicas might not be in the running state if you run the command too soon after deploying the service. This is usually because the workers are still pulling the image and starting the replicas.

You can run a docker service ps command to see a list of service replicas and the state of each.
