
The volume still exists, including the counter data stored in it. This is because Docker knows that we store important information in volumes and might not want to delete them with other application resources. With this mind, Docker decouples the lifecycle of volumes from the rest of the application.

Docker also keeps the images built and pulled when it started the app. This makes future deployments faster.

Feel free to run a `docker images` command to verify the images still exist.
