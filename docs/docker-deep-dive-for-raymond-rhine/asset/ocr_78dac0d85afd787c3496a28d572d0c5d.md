# Deploying apps with Docker Stacks – The TLDR

Docker Stacks combine Compose and Swarm to create a platform for easy deployment and management of multi-container apps on secure, highly available infrastructure.

You build a swarm, define your apps in Compose files, and deploy and manage them with the `docker stack` command.
