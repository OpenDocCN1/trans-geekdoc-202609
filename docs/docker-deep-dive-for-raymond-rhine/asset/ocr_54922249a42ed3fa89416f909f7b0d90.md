The **command** key tells Docker how to start the app in each replica. Our example tells it to execute **python app.py** in replicas.

The **deploy.replicas** key tells Swarm to deploy and manage four service replicas (identical containers).

```
web-fe:
  deploy:
    replicas: 4
```

If you need to change the number of replicas after you've deployed the service, you should update the value of **deploy.replicas** in the stack file and then redeploy the stack. We'll see this later.

The **deploy.update_config** block tells Docker how to perform rollouts.

```
web-fe:
  deploy:
    update_config:
      parallelism: 2
      delay: 10s
      failure_action: rollback
```
