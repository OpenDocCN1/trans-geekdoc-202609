# ## Docker overlay networking – The TLDR

Real-world containers need a reliable and secure way to communicate without caring which host they’re running on or which networks those hosts are connected to. — they create flat, layer 2 networks that span multiple hosts. Containers on different hosts can connect to the same overlay network and communicate directly.
