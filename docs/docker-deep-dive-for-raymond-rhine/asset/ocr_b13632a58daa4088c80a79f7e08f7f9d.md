| Term | Definition (according to Nigel) |
| --- | --- |
| Observed state | Also known as current state or actual state. The most up-to-date view of the cluster and running applications. Docker Swarm is always working to make observed state match desired state. |
| Open Container Initiative (OCI) | Lightweight governance body responsible for creating and maintaining standards for low-level container technologies as images, runtimes, and registries. Docker creates OCI-compliant images, implements an OCI-compliant runtime, and Docker Hub is an OCI-compliant registry. |
