+   * gelf
* gcplogs
* journald (only works on Linux hosts running systemd)
* splunk
* syslog

**json-file** and **journald** are the easiest to configure, and they both work with the **docker service logs** command. However, other drivers don't always work with the native Docker commands and you may have to use the logging platform’s native tools.

The following snippet is from a **daemon.json** configuration file on a Docker host configured to use the **syslog** driver. The **daemon.json** file is usually located in **/etc/docker/daemon.json**, but sometimes it doesn’t exist unless you create it manually for custom settings.

```
{
  "log-driver": "syslog"
}
```

You can force new new services to use specific log drivers by starting them with the **--log-driver** and **--log-opts** flags. Doing this will override anything set in the **daemon.json** file.
