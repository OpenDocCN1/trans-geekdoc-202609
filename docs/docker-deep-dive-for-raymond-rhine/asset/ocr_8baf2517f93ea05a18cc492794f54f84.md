The PID numbers returned are the PID numbers as seen from the Docker host (not from within the containers).

You’re about to stop and restart the app. However, before doing this, connect your browser to the app again and refresh the page few times. Make a note of the counter value before continuing.

Run the following commands to stop the app and recheck its status.

```
$ docker compose stop
[+] Running 2/2
  - Container multi-container-redis-1 Stopped
  - Container multi-container-web-fe-1 Stopped
```

```
$ docker compose ps
NAME COMMAND SERVICE STATUS PORTS
```

The app is down, but Docker hasn't deleted any of its resources. Verify this by checking if the containers still exist.

| NAME | IMAGE | ... | SERVICE |
