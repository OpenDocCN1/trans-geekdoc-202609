Each MediaType: application/vnd.docker.distribution.manifest.v2+json line refers to a manifest for each specific architecture.

Figure 6.13 shows manifest lists and manifests are related. On the left, you can see a manifest list with entries for the different architectures supported by the image. The arrows show that each entry in the manifest list points to a manifest defining the image config and the list of layers making up the image for that architecture.
