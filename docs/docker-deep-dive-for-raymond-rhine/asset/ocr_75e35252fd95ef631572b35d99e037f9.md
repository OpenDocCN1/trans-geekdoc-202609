So far, you've seen that starting and stopping containers doesn’t lose changes. You also saw that restarting them is very fast.

Run the following command to delete the container. The -f flag forces the operation and doesn’t allow the usual 10-second period to flush buffers and gracefully quit. Be careful forcing operations like this, as Docker doesn’t ask you to confirm.

```
$ docker rm webserver -f
webserver
```
