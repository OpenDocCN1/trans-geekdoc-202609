# Deploying the app

If you plan on following this section, you'll need a copy of the book's GitHub repo and a swarm. The examples use a three-node swarm with a single manager called **mgr1** and two workers called **wrk1** and **wrk2**.

# Deploy the app

You deploy Stacks with the `docker stack deploy` command, and in its basic form it accepts two arguments:

+   - The name of the stack file (Compose file)
- The name of the stack (app)

We'll use `compose.yaml` file in the `ddd-book/swarm-app` folder, and we'll call the app `ddd`.
