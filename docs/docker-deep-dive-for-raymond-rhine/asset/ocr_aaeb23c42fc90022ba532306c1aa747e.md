The output is much longer this time, and I've trimmed the example in the book so you only see the `hello_world.wasm` binary. This is the Wasm app and will run on any system with the `spin` Wasm runtime.

You'll containerize the app in the next section, but you should test it works before proceeding.

Run a `spin up` command to start a local instance of the app. This will start the app using the local `spin` runtime you installed earlier.

```
$ spin up
Logging component stdio to ".spin/logs"

Serving http://127.0.0.1:3000
Available Routes:
  hello-world: http://127.0.0.1:3000/hello
```

Point your browser to `http://127.0.0.1:3000/hello` and make sure the app works.
