| Term | Definition (according to Nigel) |
| --- | --- |
| Orchestrator | Software that deploys and manages apps. Docker Swarm and Kubernetes are examples of orchestrators that manage microservices apps, keep them healthy, scale them up and down, and more... |
| Overlay network | A large flat layer-2 network that spans multiple swarm nodes. All containers on the same overlay network can communicate with each other even if they're on different Docker hosts that are on different networks. The built-in overlay driver creates overlay networks using advanced VXLAN technologies. They are only supported by Docker Swarm.
