
# 第五部分

## 11

当你第一次听到“网络安全”这个词时，你可能会认为只有政府、银行和大公司才需要考虑这方面的问题。当然，这些行业绝对需要拥抱网络安全——但它们并不是唯一的相关行业。网络安全考量适用于各种不同的组织和行业，包括一些你可能意想不到的。

### 名人、娱乐与流行文化

#### 泰勒·斯威夫特

你是否曾好奇像泰勒·斯威夫特这样的人是如何管理网络安全的？音乐行业的成功依赖于许多因素，其中之一就是音乐能在预定的时间、以预定的方式发布。如果歌曲或专辑在发行日期前泄露，可能会让艺人及其唱片公司损失大量金钱，并可能损害艺人的事业。据新闻报道，泰勒·斯威夫特（或确切地说是她的团队）非常清楚这一点，并采取了一系列措施来管理她最宝贵的数据：即将发布的音乐。

据报道，当伴舞演员在拍摄泰勒·斯威夫特的音乐视频时表演，他们并不是伴随着视频主题的实际音轨进行表演。为确保音乐仅被绝对需要知道的人听到，并显然是为了限制有人在官方发行日期前秘密录制并发布音乐的可能性，斯威夫特的伴舞演员伴随“点击音轨”表演，这种音轨只播放相关曲目的正确节拍，而不是曲目本身。^([1](#22_chapter11.xhtml#ch11_en1)) 这样，舞者们能跟上正确的节奏，却不会接触到音乐本身。

报道表明，这并非保护斯威夫特音乐安全的孤立案例，而是整体策略的一部分。爱德华·希兰曾评论过斯威夫特团队为保护其音乐所采取的措施，那是在他们合作她专辑《Red》中的歌曲《Everything Has Changed》时。据希兰说，当斯威夫特团队的一名成员去见他时，他只听了一遍这首歌。显然那首歌是iPad上唯一的歌曲，而iPad被存放在一个上锁的公文包里；希兰听了一遍，确认满意后，iPad就被锁起来带走了。^([2](#22_chapter11.xhtml#ch11_en2)) 这显示出一种对斯威夫特知识产权网络安全深思熟虑的做法。斯威夫特的团队对音乐保持着严格的保管链，不通过电子邮件发送（因为邮件容易遭受黑客攻击），而且据希兰透露，他们甚至可能将歌曲保存在所谓的“净设备”上，即从未用于访问互联网或存储其他数据的设备。

斯威夫特的团队不仅非常重视她的数字安全，也非常重视她的物理安全。2018年据报道，设在她演唱会场外播放泰勒·斯威夫特排练片段的自助终端机，远不止表面看起来那么简单。当观演者观看终端机上播放的斯威夫特片段时，他们的影像被采集，并进行面部识别扫描，以确定参加者中是否有斯威夫特已知的跟踪狂。^([3](#22_chapter11.xhtml#ch11_en3)) 这可能显得极端，确实引发了关于个人安全与他人隐私平衡的问题，但它展示了名人如何（并且确实）将最新数字技术作为其安全策略的一部分来采用。

#### 金·卡戴珊

物理安全当然是公众人物早就意识到的问题。然而，随着互联网和社交媒体技术带来的更强连接性，这些问题变得更加凸显，意味着知名人士比几十年前更容易被大众接触到。2016年，在金·卡戴珊在巴黎居住期间遭遇袭击后，卡戴珊家族重新评估了他们对社交媒体的使用。卡戴珊在枪指下被抢劫，罪犯偷走了价值1000万美元的珠宝。据称该犯罪团伙的头目向法国警方供认，他们利用她在社交媒体上分享的信息实施了袭击。^([4](#22_chapter11.xhtml#ch11_en4)) 卡戴珊曾在社交媒体上晒出昂贵珠宝的照片，并评论说它们不是赝品，她的帖子还透露了她在巴黎的行踪和动向。这当然不是要怪卡戴珊招致袭击：她是犯罪行为的受害者，经历了据所有报道必定极其创伤的经历。但此案确实凸显了罪犯将社交媒体作为其活动工具这一事实。这是我们所有人都应意识到的，尤其是知名人士。这意味着网络安全对名人至关重要，不仅关乎保护他们的数据安全和财务，也关乎他们的物理安全。

#### 凯特琳·詹纳

卡戴珊家族帝国还有很多这样的例子。当凯特琳·詹纳宣布跨性别时，这当然是一个巨大的新闻事件——这意味着网络安全是其核心（正如我们在[第8章](#18_chapter08.xhtml#ch08_sec_001)首次提到的）。《名利场》拥有詹纳跨性别后的独家首次公开采访和拍摄，这涉及大量安保工作以保持独家性并防止照片等细节泄露。据报道，拍摄现场聘请了额外安保，现场所有人被迫不带手机，以防他们拍照。文章和照片仅存储在一台从未联网的电脑上，每晚所有数据都被存入U盘并从电脑本身删除。稿件被人工送交印刷厂，而非冒险通过互联网传输。^([5](#22_chapter11.xhtml#ch11_en5))
