## 02

现在我们了解了什么是网络安全——那它为什么重要？互联互通的信息是许多事物的核心：在我们的个人生活、工作生活以及整个社会中。自互联网发明短短几十年来，其发展已呈现爆发式增长。它已成为我们在个人层面互动（从社交媒体到网上银行）、组织运营（从即时通讯、电子邮件和全球视频会议到外包在线薪资系统、电子商务网站等）以及关键国家基础设施管理方式的基础组成部分。
