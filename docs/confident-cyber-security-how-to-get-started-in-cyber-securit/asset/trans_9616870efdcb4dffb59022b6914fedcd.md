

## 小型企业与网络犯罪

针对社交媒体影响者的攻击表明，不仅仅是大型组织会因网络不安全和网络犯罪分子的活动而受害。英国中小企业联合会发现，网络犯罪每年给英国中小企业群体造成数十亿英镑的损失，20%的英国小型企业报告称在2017-2019年间遭受过网络攻击，每家企业单次攻击的平均直接成本为1300英镑。^([13](#22_chapter11.xhtml#ch11_en13)) 小型企业最常卷入网络钓鱼邮件诈骗、恶意软件和勒索软件感染。小型企业在成为网络攻击受害者时往往感到惊讶，这通常是因为人们假设网络犯罪是有针对性的，并且只有大型企业才会成为目标。现实情况是，网络犯罪分子往往撒下大网；利用网络钓鱼诈骗和凭证填充（见[第3章](#11_chapter03.xhtml#ch03_sec_002)和[第6章](#15_chapter06.xhtml#ch06_sec_001)）等攻击手段，这很容易做到。网络犯罪分子能够利用计算机程序一次性发送大量网络钓鱼邮件或批量收集大量密码，而小型企业通常没有大型企业那样完善的网络安全防御，因此成为极具吸引力的目标。大小组织都可能卷入网络攻击，并非因为它们是直接目标，而是因为它们是真实目标的*供应商*。美国零售商Target即是如此，其通过制冷、供暖和空调公司遭到入侵；据称该入侵导致Target的首席信息官和首席执行官在成本达到1.62亿美元后辞职。

## 教育

教育是另一个或许意想不到地成为网络犯罪目标的领域。大学通常拥有大量知识产权、研发数据，以及巨额资金和个人数据。由于去中心化的结构和众多不同的利益相关者（学者、行政人员、研究人员和学生），大学可能是难以保护的组织。传统上，许多企业存在一种“自上而下”、集中授权的文化，接受领导层制定规则、其他人遵守的现实（程度不一）。在大学里，通常有各个独立运作、与校中央职能部门相对独立的学院和系。学者和研究人员拥有的权威，在传统意义上难以“统管”：大学的首席信息安全官可能很难告诉一位权威学者，不应将敏感研究数据存储在U盘上或发送到个人邮箱，因为存在网络安全风险，因为学术界的文化不像许多其他组织那样构建为自上而下的结构。虽然保护数据符合学者个人以及整个大学的最佳利益，但CISO需要说服学者，而不能依赖机构权威。

2019年7月，兰卡斯特大学报告称遭受网络攻击，涉及网络钓鱼邮件。^([14](#22_chapter11.xhtml#ch11_en14)) 学生记录系统被访问，部分学生的学生记录和身份证明文件泄露。同时，本科申请者的姓名、地址、电话号码和电子邮件地址被盗，使网络犯罪分子能够向部分申请者发送带有虚假大学发票的网络钓鱼邮件。

这一案例凸显了一个重要问题：我们有时会低估电子邮件地址的价值，许多人倾向于广泛分享它们。电子邮件地址对网络犯罪分子和欺诈者具有价值，因为他们可以利用这些地址通过网络钓鱼邮件联系我们。如果网络犯罪分子能够获取电子邮件地址列表，特别是结合申请大学等信息，他们就可以利用这些信息快速发送令人信服的网络钓鱼邮件，只要有一个人上钩，对他们就是有利可图的。如果你申请了大学，预期要向其付款，并收到一封来自大学账户（或看起来非常像来自合法账户）的邮件，你难道不会支付发票吗？

个人数据、维持运营的需求和低IT预算也是使教育部门容易遭受网络攻击的因素。国家网络安全中心和伦敦学习网对英国430所学校进行审计，发现83%至少经历过一次网络安全事件，30%遭受过恶意软件感染，35%经历过重要信息不可用。^([15](#22_chapter11.xhtml#ch11_en15)) 全球范围内，有大量关于学校成为勒索软件攻击受害者的报道。

这些只是网络安全高度相关的职业、行业和领域的几个例子——还有很多。可以说，任何涉及资金或信息利益的行业都需要这些技能——不仅仅是大企业。凡是涉及资金或信息利益之处，我们都需要防范网络犯罪分子的活动。
