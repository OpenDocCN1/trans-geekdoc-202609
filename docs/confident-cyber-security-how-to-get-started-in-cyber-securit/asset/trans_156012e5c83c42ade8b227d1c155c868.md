
# 手机诈骗与网络安全意识

2019年8月，新闻媒体警告人们一种新型手机诈骗，该诈骗涉及面对面实施的社会工程学与数字欺诈相结合。诈骗手法如下：一个包裹被送到你家门口，上面写着你的名字，里面装着一部新智能手机。不久后，又有人敲门，另一名快递员解释说送错了货，并要求拿回手机。这种送货诈骗基于身份盗窃：犯罪分子利用你的详细信息订购了一部手机（或其他高价值物品），然后试图在送货时将其拦截。他们使用你的（被盗）详细信息进行购买，然后从你手中夺走该物品并将其出售，让你承担最初的费用。

这一诈骗凸显了意识的重要性，不仅要了解最新的诈骗手段，还要了解其背后的方法和犯罪心理。网络犯罪分子总会找到新战术来实施犯罪，但这些战术植根于相同的通用技术和策略。遵循本章涵盖的步骤将保护个人免受大多数正在发生的网络犯罪侵害：

1.  使用强且唯一的密码以及双因素认证（2FA）保护你的账户。
2.  警惕银行卡复制，不要让他人接触你的银行卡，尤其是拿到你看不见的设备上操作。
3.  通过保持设备更新以及谨慎下载应用来保护你的设备。
4.  通过避免在公共Wi-Fi上进行任何敏感操作（如网上银行）并考虑使用可信赖的VPN来保护你的数据。
5.  注意你使用的网站，特别是当你购买商品或输入个人或财务数据时。
6.  精明使用社交媒体，意识到你分享的信息以及网上的人并不总是他们看起来的样子。
7.  不仅在网络上人们并不总是他们看起来的样子；社会工程学跨越数字、物理和社会世界，被用于各种犯罪。

所有这些建议的基础都是意识。了解这些犯罪是如何实施的、犯罪分子是如何作案的以及我们可以做些什么来更好地保护自己，是第一步。保持警惕是最有价值的方法，这是一种拥抱情境意识并信任直觉的心态。如果感觉可疑，值得花点时间查明你的怀疑是否属实。

## 互联网执法

这是互联网执法如此困难的原因之一：犯罪可以在一个国家实施而针对另一个国家，即使能确定攻击者身份，采取法律行动也可能具有挑战性或不可能，因为这依赖于各国合作。为了试图缓解这一问题，已建立框架以尽可能促进和管理这种合作。

### 《塔林手册2.0》

《塔林手册2.0：适用于网络行动的国际法》（以下简称《塔林手册》），其起草工作由北约合作网络防御卓越中心主导，是对现有国际法如何适用于网络空间的全面分析。我们从《塔林手册》中可以得出的一些广泛结论包括：主权适用于网络空间，国家管辖权应适用于网络活动，国家对可归因于其且构成违反国际法的网络行为负责（包括由非国家行为体在国家有效控制下实施的行为）。^([1](#20_chapter10.xhtml#ch10_en1)) 当然，《塔林手册》包含更多关于网络活动国际法的分析，且贡献专家在许多观点上存在分歧。这是一个新兴且不断扩展的法律领域，发展迅速，正如我们将在本章的案例研究中看到的那样。

### 《瓦森纳安排》

《瓦森纳安排》（瓦森纳）成立于1996年，以荷兰海牙郊区瓦森纳命名，1995年在那里达成国际协议，启动多边合作。该安排旨在通过管控全球武器贸易来促进国际稳定。目前有42个国家自愿参与该安排，包括英国、美国、乌克兰、俄罗斯联邦、爱沙尼亚、荷兰、日本和澳大利亚。

2013年，瓦森纳安排修订纳入了“入侵软件”和“入侵软件技术”的指挥和投送平台，将两者均列为需要出口许可证的物品，就像实体武器一样。在网络安全社区，这一措辞引起了困惑和担忧，因为它将要求从事防御性安全活动的人员获得出口管制许可证。这带来了严重的意外后果风险，例如，对实时攻击的技术响应可能会因出口管制文书工作的处理而受阻。

2017年，在Katie Moussouris和Iain Mulholland的专家建议下，瓦森纳安排修订达成一致，使得跨境漏洞披露共享和安全事件响应免于瓦森纳安排涵盖的出口管制许可证。^([2](#20_chapter10.xhtml#ch10_en2))

瓦森纳安排反映了我们在国家和国际层面管理网络安全时面临的一些问题，因为在物理领域讲得通的规则和法规不一定适用于网络领域。这一例子凸显了让具备网络安全专业知识的人参与此类国际协定制定的重要性，以理解和解释理论上讲得通的法规在实践中将如何运作。

### 《国际武器贸易条例》

没有什么比法规更能表明基于网络的攻击被视为与动能武器相当。《国际武器贸易条例》（ITAR）自1976年以来被美国用于限制和控制军事技术出口，以保护美国免受外国势力利用其武器对抗美国或其盟友。它控制美国军火清单（USML）上所列资产的出口。写作时，USML分为21个类别，涵盖从火器到化学制剂和核武器的所有内容。由于为定制访问开发的软件通常属于ITAR管辖范围，显然美国等国家认识到所谓的网络武器有可能像传统武器一样具有价值和毁灭性。
