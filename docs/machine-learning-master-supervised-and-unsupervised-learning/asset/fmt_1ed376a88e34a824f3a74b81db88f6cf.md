
# Supervised versus Unsupervised Learning

Most of the statistical-based learning algorithms are categorized into two categories: supervised learning algorithms and unsupervised learning algorithms. The example discussed earlier in this chapter is a suitable example of supervised learning. It is referred to as supervised machine learning because the algorithm's learning process uses a training dataset; in other words, the process is done under the supervision of a supervisor. The algorithm learns the prediction in the training process, and corrections are made by the teacher. The learning process continues until it achieves acceptable performance.

Supervised learning is further divided into two categories: regression and classification, which we will discuss later in this chapter. Popular machine learning algorithms include classification, support vector machine, and linear regression.

Unsupervised learning algorithms are those where you have input values or input data but no corresponding output variables. The main aim of the unsupervised learning technique is to understand the structure or distribution of the data; these algorithms help learners understand more about the data. In unsupervised learning, there is no concept of teachers. Algorithms have their own choice to learn and explore the data. Suitable examples of unsupervised learning are clustering and association problems. Popular algorithms include k-means clustering, PCA, and independent component analysis.

# Regression versus Classification

Classification-related problems are used to find the function that can divide the available dataset into different categories according to its parameters. In the classification process, algorithms are trained on the training dataset and can categorize the data into different classes. On the other hand, regression is the process of finding the correlation between dependent and independent variables. Regression algorithms are used for the prediction of house prices, stock predictions, weather forecasting, and so on.

# Feature Selection

With the rapid development of big data, we have more access to high-dimensional datasets, which has also improved the performance of most machine learning algorithms. However, much data collected from different sensors is corrupted, noisy, and sometimes useless. These types of data sometimes influence the accuracy and computational speed of the model. Hence, the selection of useful data or features is always a cumbersome task for any machine learning algorithm. Useful and effective features always improve the accuracy of the model and increase model interpretability. Keeping this in mind, feature selection algorithms always play an important role in the statistical learning-based approach.

Feature selection is also referred to as variable selection, attribute selection, or subset selection. It is a process by which the data scientist automatically selects relevant or useful features for use in statistical-based learning methods. The feature selection algorithm selects the most suitable features from the pool of features, which can help reduce prediction time and improve prediction accuracy.

The feature selection approach can be explained in two steps:

1.  Combination of different search techniques that add new feature subsets.
2.  The evaluation process measures the score of different feature subsets.

This could be computationally expensive because selecting the best subset of features from the available features is always challenging. Keeping this in mind, feature selection approaches are categorized into different categories. We will now explore the different methods and techniques that make the selection process easier, simpler, faster, and more reliable.

Here are some feature selection approaches:

*   Filter
*   Wrapper
*   Embedded methods

## Filters

In this method, irrelevant attributes or redundant columns are filtered out. We can choose a single statistical measure suitable for the whole dataset. The module calculates the feature score for each column, and then the column returns its value by its feature score. Choosing the right feature may improve the accuracy and efficiency of the model. The selection of the best feature does not depend on any machine learning algorithm. Features can be selected according to their score in numerous statistical tests that suit the particular dataset. The various statistical test methods based on categorical or continuous data are:

### Pearson Correlation

The Pearson correlation method measures the quantifying linear independence between two continuous variables `x` and `y`. The value can vary from `-1` to `+1`. It is shown as:

It is calculated by taking the covariance of the two variables and then dividing it by the product of the standard deviation. If the scale of the two variables changes, it does not affect the coefficient value.

### Chi-squared

This is another statistical method used to measure how much the expected values are closer to the actual values. In this method, we assume that variables are random variables drawn from an adequate sample of independent variables.

### Linear Discriminant Analysis (LDA)

`LDA` is used to find the linear combination of features that categorizes the feature into different classes. It is suitable for categorical data.

### Analysis of Variance (ANOVA)

This method is similar to `LDA` but uses one dependent feature and one categorical independent feature. It is suitable for finding if several groups are equal or not.

## Wrappers

In the wrapper method, the feature selection method is based on machine learning algorithms. This method follows a greedy search approach in which it tries to evaluate the performance of all possible combinations of features according to various evaluation criteria. Evaluation criteria are performance metrics that always depend on the type of problem. For example, for classification, the evaluation parameters are accuracy, precision, and recall. For regression, the evaluation parameters are p-values and r-squared. Finally, wrappers select the best combination of features that yields optimal results. ## Embedded Methods

Embedded methods complete the feature selection process within the construction of machine learning algorithms. In other words, the feature selection process is done during the training of the model, which is why it is called "embedded". The advantage of an embedded method is that classification and selection of features are done at the same time; for that reason, they are less computationally expensive. The different types of embedded methods are `L1 regularization`, `L2 regularization`, and `L1/L2 regularization`. These methods will be discussed later in this chapter.
