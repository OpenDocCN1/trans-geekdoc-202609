**摘要** 信息通信技术的快速发展为先进管理和控制系统带来了优势，特别是对于电力系统。虽然已经提取了有用信息，但这些数据尚未充分利用，现有的故障检测技术通常基于监测和诊断而非预测。本文提出将深度学习算法集成到电力系统中发电组的故障预测中，并探索了运行数据在故障预测应用中的有效性和可行性。我们的方法包含两个用于降维的预处理模块，以及一个用于描述提取数据并预测发电组故障行为的深度线性回归模型。实验结果证明了我们方法的有效性。

**关键词** 故障预测、特征提取、维度关系、最小二乘、深度学习

近年来，发电组异常故障导致的非计划停机频率增加，因此全方位监控发电组状态、研究状态信息以预测故障，并改进设备管理以减少事故频率、提高发电组的可靠性和长期运行，是确保整个电厂生产安全的关键。

近期故障检测技术经历了水平化发展，主要包括故障后诊断、诊断、设备状态监测和故障前检测。除了故障前预测，故障检测技术已相对成熟。它们使用时域和频域分析来分析发动机、风扇、轴承、齿箱和接头的信号数据。从那时起，人工智能、边缘神经网络和支持向量机已应用于其中。作为局部故障检测的应用，故障检测技术已成为工业和企业部门故障诊断研究的主要领域。这些技术被用于军事设备管理，随后被应用于发电机组以及各种发电故障预测网络 [1, 3, 5, 6]。尽管使用了许多不同的方法，在今天的实际工作中，各种预测方法都有其局限性。然而，显而易见，确定参数之间的关系或提高预测速度仍然困难。换句话说，许多故障预测任务受到了限制。故障预测的实时准确性、鲁棒性以及最重要的故障指标评估部分。

# I. 引言

随着信息通信技术的快速发展，电力系统已实现自动化管理，许多分布式管理和控制系统为电力系统中单元的实时监测和运行带来了巨大收益。

作为电力系统的重要子集，发电系统负责管理和控制发电设备（如发电机）。随着快速发展，经济需求逐年增长。为了满足发电需求，增加了发电机组的数量。然而，发电机组数量越多，设备之间的协调就越复杂。因此，故障频率和组件数量将随之增加。如果发生故障，将导致严重后果，例如单元将长时间停机，人身安全将受到威胁。这些耗时的维护以及单元的维护和停机成本也影响了发电的经济效益。因此，提高发电设备的安全可靠运行至关重要。

作为主要电力设备，发电组的安全可靠运行与其密切相关。

在本文中，我们关注电力系统中发电组的故障预测，并引入了深度学习方法。我们的方法包括两个部分：第一是基于偏最小二乘（`PLS`）的预处理模块，用于降维；第二是专门用于提取数据以预测发电组故障行为的深度线性回归模型。`PLS`方法不仅能降维并解释变量，还能保留原始知识系统中的信息并消除噪声干扰。线性回归的知识在于它可以很好地拟合原始系统的分布关系，获得全局最优，并学习具有泛化性能的映射关系。降维和降低复杂性可以提高数据处理效率并缩短模型处理时间，而深度线性回归模型可以减少预测误差，结果具有良好的对齐质量。两者的结合可以满足实时性和准确性的要求，对设备诊断具有实际价值。

# V. 结论

在本文中，引入了深度学习算法来处理发电机的故障，并评估了故障预测应用中误差数据的可行性。我们的方法包含两个部分：第一部分用于降维的偏最小二乘模块，第二部分用于压缩运行数据并预测电机故障行为的深度回归模型。结果显示，我们的方法在压缩和扩展数据的同时保留了原始知识系统的信息并消除了噪声干扰。深度回归模型可以获得全局最优，并学习具有良好泛化性能的映射。通过降低维度复杂度可以提高模型的准确性。
