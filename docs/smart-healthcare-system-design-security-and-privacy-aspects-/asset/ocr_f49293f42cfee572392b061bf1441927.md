# 3.3.2 Weighted Product Model (WPM)

WPM was launched by Yoon and Hwang in the year 1995. Normalization is the primary step of any decision making method, but it is not needed in this WPM as the method is called as dimensionless method. Similar to SMART, in this method also, there are two types of parameters (benefit—higher value means improvement with lower cost assessment means improvement).

Weights become elements, positive power weight is utilized for gain criteria, and negative power weight is utilized for price criteria.

$$Utility_{i} = \prod_{j=1}^{j=m} (U_{ij})^{w_{j}} \tag{3.3}$$

We can sort the substitutes based on the output scores by following the calculation above.
