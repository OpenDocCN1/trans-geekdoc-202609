# 9.4 Need for Security in Medical IoT

IoT applications in real time gather vast quantities of personal data from Company firms in hospitals, household and financial transactions. In order to access user data, heterogeneous real time IoT presents a need for proper protection algorithms. While several security algorithms exist, they do not provide the IoT environment with higher order security. It is diffi- cult to perform complicated data encryption techniques in IoT devices due to the energy limited nature of IoT devices. There is therefore a need for lightweight security algorithms that provide IoT data with a higher degree of security with minimal transmission and overhead computation on those kind of IoT devices.
