IoT systems interact directly with the cloud in the conventional method [3]. For certain applications, the volume of data from sensors to the cloud to connect is however, prohibitive. Connected cars, for instance, can produce voluminous data even in megabytes (MB) for every second [4]. In addition, few applications need rapid reaction, such as face recognition need dedicated artificial intelligence (AI) based hardware for processing in devices like smartphones. The fog and edge layer paradigm has therefore been applied to the IoT [4] architecture. Data processing and local decisions can be performed by fog and edge systems, eliminating additional cloud communication [5]. The implementation of this modern model, however, is trailed by important side special effects that need to be properly handled, such as cost and security [6], for example.
