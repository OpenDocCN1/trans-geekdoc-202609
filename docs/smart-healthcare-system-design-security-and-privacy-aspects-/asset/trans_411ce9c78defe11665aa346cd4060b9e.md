# 智能云-IoT 系统学习分析领域的进展

**系列主编：Souvik Pal 博士和 Dac-Nhuong Le 博士**

适应机制、学习分析、计算智能和数据分析在云-IoT 系统领域中的作用正变得越来越重要且相互交织。智能系统的能力取决于 IoT 设备中各种自主决策算法。基于 IoT 的智能系统生成大量数据（大数据），这些数据无法由传统的数据处理算法和应用进行处理。因此，该丛书系列涉及在云和物联网支持的环境中，借助分析推理和语义理解，将不同的计算方法整合到系统中的研究。该丛书出版实证研究、理论和数值分析以及新颖研究发现的卷册。
