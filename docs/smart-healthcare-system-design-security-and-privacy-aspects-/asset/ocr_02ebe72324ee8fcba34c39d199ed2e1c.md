# ## 6.5 Performance Analysis

Our proposed model improves home care of the patients and remote healthcare up to 90% accuracies in detecting the common diseases. Our model is able to disrupt the exponential spread of the COVID-19 disease. In our model we have used biosensors. The accuracy levels of the biosensors are very high. We have Jelastic as a cloud service. The cloud server can analyze the patients’ data using machine learning and deep learning techniques with high accuracies. We have used LoRaWAN networking protocol that can provide security with AES encryption.
