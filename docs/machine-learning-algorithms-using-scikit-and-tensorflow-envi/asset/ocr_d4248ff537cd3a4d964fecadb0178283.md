# 5.1 Classification Accuracy

The most popular and straightforward technique of assessing accuracy is classification accuracy. The number of accurate predictions divided by all forecasts, or a ratio of accurate predictions to total predictions, is how classification accuracy is calculated.

Although it can offer you a fast indication of how your classifier is doing, it works best when there are nearly equal numbers of observations and examples in each class. You're generally better off using another statistic because this doesn't happen very frequently.
