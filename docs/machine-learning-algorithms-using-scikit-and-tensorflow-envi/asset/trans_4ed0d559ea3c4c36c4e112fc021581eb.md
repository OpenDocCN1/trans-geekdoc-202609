### 使命

计算应用程序和分布式系统的理论与实践已成为推动商业、工程和科学创新的关键研究领域之一。软件工程、系统分析和高性能计算领域为解决任何现代组织的计算问题提供了广泛的应用和解决方案。

**系统分析、软件工程和高性能计算（ASASEHPC）丛书**汇集了分布式计算、系统与软件工程、高性能计算和服务科学领域的研究。这套出版物对于寻求该领域最新实践和知识的学者、研究人员和从业者非常有用。
