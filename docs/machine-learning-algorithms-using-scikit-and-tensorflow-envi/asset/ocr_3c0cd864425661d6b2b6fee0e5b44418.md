Besides, experiments are tested by by extracting the necessary features from the and given to the convolutional neural network and with extracting the necessary features from the given coffee image that means using convolutional neural network for both feature extraction and classification. finally, the developed classier model can be able classify the diseases 98% accuracy by ResNet50.

In the future, recognising a given images and classifying based on the nutrient deficiency and other class label also future research direction.
