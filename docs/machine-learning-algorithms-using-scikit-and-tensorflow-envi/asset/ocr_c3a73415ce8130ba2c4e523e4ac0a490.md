# CNN Training

The neural network training process involves identifying kernels for convolution operations and weights in fully-connected networks in order to reduce discrepancies between output predictions with ground truth labelling on a training example. Error function with stochastic gradient optimization approaches are important in backpropagation, which is frequently employed for training neural networks. A loss method computes the effectiveness of a model with specified kernels and weights with forward propagation
