A hyper-parameter is a parameter that is set before the learning process begins. Furthermore, these parameters are tunable and can directly affect how well model trains. In a convolutional neural network, experiments can be conducted by various methods; mainly changing types of parameters as well as hyper-parameters the network enables us to switch the parameters to build different classification experiments.
