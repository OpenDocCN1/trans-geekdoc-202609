# 简介

区块链是一种分布式数字化账本技术，它通过使用点对点网络实现合法且高度安全的交易。它最早于 2008 年被提出，并于 2009 年作为比特币的底层技术投入使用。从那时起，区块链的知名度不断提高，并在各个领域日益显示出实用性。在比特币之后，区块链网络被用于运行各种加密货币。除了拥有加密应用外，区块链已被证明在治理、网络安全、工业系统、金融计量经济学和企业管理等领域非常有用。

区块链技术应用有潜力改变我们目前对健康信息技术及其相关软硬件基础设施的使用方式。其底层技术及相关加密货币凭借去中心化架构，暗示了一系列应用场景，我们认为这些应用相较于目前公共医疗领域及相关私营市场参与者所使用的传统遗留系统，能够带来成本节约和效率提升。我们建议，在美国医疗体系的公共项目中，有许多应用可以利用区块链技术来实现。

区块链的根本承诺在于其底层信息技术（IT）架构及其“不可篡改”的数据条目链，这使得安全且公开的交易成为可能。区块链的去中心化分布式数据库包含数据，允许建立一个可审计的分布式账本，让所有人都能看到每一笔交易。区块链的开源属性使该技术天然契合公共和私营部门健康信息技术中与繁杂交易系统相关的需求。

与对遗留 IT 系统进行更改相比，区块链的编程和系统级变更实施相对更容易。区块链的优势显而易见，但作为一种新技术，关于其功效和效率仍存在疑问。在本文中，我们试图回答关于该技术、互操作性问题以及与医疗领域相关的具体应用和相关成本的问题。我们还探讨了与医疗保健相关的一些隐私和数据安全顾虑，这些是任何健康 IT 系统固有的。最后，我们还审视了部署区块链技术的政策影响，并建议进一步的研究领域。

区块链是一个不断增长的记录列表，称为区块，它们通过密码学链接在一起。每个区块包含前一个区块的加密哈希值、一个时间戳和交易数据（通常表示为默克尔树）。根据设计，区块链具有抗数据修改能力。这是因为一旦记录，任何给定区块中的数据都无法在不更改所有后续区块的情况下追溯修改。

作为分布式账本使用时，区块链通常由点对点网络共同管理，该网络共同遵守节点间通信和验证新区块的协议。尽管区块链记录并非绝对不可更改，但区块链在设计上可被视为安全的，并体现了具有高拜占庭容错性的分布式计算系统。区块链被描述为“一种开放的分布式账本，可以高效、可验证且永久地记录双方之间的交易”。

区块链由一个使用化名中本聪的人（或一群人）于 2008 年发明，旨在作为加密货币比特币的公共交易账本。中本聪的真实身份至今仍不为人知。区块链为比特币的发明使其成为第一种无需可信权威或中央服务器即可解决双重支付问题的数字货币。比特币的设计启发了其他应用和可被公众读取的区块链，并被加密货币广泛使用。区块链被视为一种支付轨道。私有链已被提议用于商业用途，但《Computerworld》称，在没有适当安全模型的情况下推销此类私有化区块链是“推销假药”。然而，也有人认为，如果设计得当，许可链在实践中可能比无许可链更去中心化，因此更安全。

# 什么是区块链？

区块链看起来很复杂，它确实可能很复杂，但其核心概念其实非常简单。区块链是一种数据库类型。要理解区块链，首先了解什么是数据库会有所帮助。

数据库是存储在计算机系统上的一组电子化信息。数据库中的信息或数据通常以表格形式构建，以便于搜索和筛选特定信息。使用电子表格存储信息而不是数据库有什么区别？

电子表格是为一个人或一小群人设计的，用于存储和访问有限量的信息。相比之下，数据库旨在存储大量信息，可供任意数量的用户同时快速、轻松地访问、筛选和操作。大型数据库通过将数据存放在由高性能计算机组成的服务器上来实现这一点。这些服务器有时由成百上千台计算机构建，以获得必要的计算能力和存储容量，从而让许多用户能够同时访问数据库。虽然电子表格或数据库可能可供任意数量的人访问，但通常归企业所有，并由指定个人管理，该个人对其运作方式及其中的数据拥有完全控制权。
