

# 区块链应用场景

正如 IBM Food Trust 案例所示，供应商可以使用区块链记录他们购买材料的来源。这将使公司能够验证其产品的真实性，以及“有机”、“本地”和“公平贸易”等常见标签。据《福布斯》报道，食品行业越来越多地采用区块链来追踪食物从农场到用户整个过程中的路径和安全性。

## 投票

如前所述，区块链可用于促进现代投票系统。基于区块链的投票有可能消除选举欺诈并提高投票率，这在 2018 年 11 月西弗吉尼亚州的中期选举中得到了测试。以这种方式使用区块链将使得篡改选票几乎成为不可能。区块链协议还将保持选举过程的透明度，减少进行选举所需的人员，并为官员提供近乎即时的结果。这将消除重新计票的需要，或任何因欺诈可能威胁选举的真实担忧。

# 何时可能使用区块链？

区块链当然令人兴奋，并有潜力改变许多企业的运营方式，但这并不意味着它是每种场景的正确解决方案。以下是您可能选择区块链而非标准数据库的原因：

## 管理和保护数字关系或保持去中心化、共享的记录系统

当您想要保留资产的长期、透明记录时（例如，记录财产或土地权利），区块链可能是理想解决方案。“智能合约”特别适合促进数字关系和交易。通过智能合约，当交易各方同意其条件已满足时，可以自动释放付款。

## 中间人或守门人功能昂贵或耗时的场景

例如，大多数住宿提供商目前必须通过中心化聚合平台（如 Airbnb 或 Expedia）与客人互动（这些平台反过来会从每笔预订中抽成）。区块链可以改变这一切。例如，旅游公司 TUI 深信区块链的力量，正在开创连接酒店经营者和客户的直接方式，以便他们能通过区块链以简便、安全且一致的方式进行交易，而不是通过中心化预订平台。

## 记录安全交易，尤其是多方之间的交易

传统数据库可能适合记录双方之间的简单交易，但当情况变得更复杂时，区块链可以减少瓶颈并简化关系。例如，航运巨头马士基正与 IBM 合作开发一个私有区块链平台，以连接其在航运业中的各种合作伙伴和客户。此外，去中心化系统的额外安全性使区块链总体上成为交易的理想选择。

## 数据处于不断变化中，但您想保留过去行为的记录

区块链是记录活动和保持数据新鲜的更好、更安全的方式，同时还能维护其历史记录。数据无法被任何人破坏或意外删除，您将同时受益于数据的历史轨迹和即时更新的记录。

# 何时不应使用区块链？

有两个例子可以说明区块链或许不是首选解决方案。

首先，虽然区块链是优秀的交易平台，但它们并非在毫秒级发生的超快数字交易的理想解决方案。区块链需要巨大的算力，因此对于超快交易，中心化数据库很可能是处理和存储信息更快、更便宜的方式。

其次，区块链本质上是开放的信息链。因此，任何时候机密性都是关键考量因素时，私有数据库（至少目前）是更好的选择。

# 区块链类型

## 公有链

公有链是一种非限制性、无许可的分布式账本系统。任何拥有互联网接入权限的人都可以在区块链平台上登录，成为授权节点并成为区块链网络的一部分。作为公有链一部分的节点或用户被授权访问当前和过去的记录，验证交易或为传入区块做工作量证明，并进行挖掘。公有链最基本的用途是挖掘和交换加密货币。因此，最常见的公有链是比特币和莱特币区块链。如果用户严格遵守安全规则和方法，公有链大多是安全的。然而，只有当参与者不真诚地遵循安全协议时，它才是有风险的。

**示例**：比特币、以太坊、莱特币

## 私有链

私有链是一种限制性或有许可的区块链，仅在封闭网络中运行。私有链通常用于组织或企业内部，只有选定成员才是区块链网络的参与者。安全级别、授权、权限、可访问性掌握在控制组织手中。因此，私有链在用途上类似于公有链，但拥有较小且受限的网络。私有链网络部署用于投票、供应链管理、数字身份、资产所有权等。

**私有链示例**：Multichain 和 Hyperledger 项目（Fabric、Sawtooth）、Corda 等。

## 联盟链

联盟链是一种半去中心化类型，由多个组织管理区块链网络。这与我们在私有链中看到的由单个组织管理的情况相反。多个组织可以在此类区块链中充当节点并交换信息或进行挖掘。联盟链通常被银行、政府组织等使用。

**联盟链示例**：Energy Web Foundation、R3 等。

## 混合链

混合链是私有链和公有链的结合。它利用两种区块链类型的特性，即可以拥有基于私有许可的系统，也可以拥有无许可的公共系统。有了这种混合网络，用户可以控制谁获得对区块链中存储的哪些数据的访问权限。只允许区块链中选定部分的数据或记录公开，其余部分作为机密保留在私有网络中。区块链的混合系统很灵活，用户可以轻松地将私有链与多个公有链连接起来。混合链私有网络中的交易通常在该网络内验证。但用户也可以将其发布到公有链中进行验证。公有链增加哈希运算并涉及更多节点进行验证。这增强了区块链网络的安全性和透明度。

**混合链示例**：Dragonchain。

## 什么是公有链？

公有链网络是一种任何人想加入随时可以加入的区块链网络。基本上，参与方面没有任何限制。更重要的是，任何人都可以查看账本并参与共识过程。例如，以太坊是公有链平台示例之一。

因此，如果您想要一个完全去中心化的网络系统，那么公有链是最佳选择。然而，当您尝试将公有链网络与企业区块链流程结合时，可能会有点棘手。无论如何，公有链网络是革命中第一种区块链类型。事实上，是比特币奠定了区块链技术的基础。
