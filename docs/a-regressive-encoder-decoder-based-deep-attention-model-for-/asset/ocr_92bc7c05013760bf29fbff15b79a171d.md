Some research works have focused on fetus segmentation using the machine learning approaches on ultrasound images [7–9]. These research articles used the transformations and contours to find the fetus circumference in the abdominal images. This paper gives insight into the reliability of automatic systems by radiologists. Moreover, the work [11] presented a detailed overview of machine learning-based diagnosis system in ultrasound imaging.

Nevertheless, researchers also focused on the assessment of the fetus geometry for various organs. One of the recent works reported in [12] used machine learning tools for the segmentation of the fetus's brain from ultrasound images. This clinically verified work used first-trimester imaging to do the segmentation process. Besides 2D imaging, some works have used 3D volumes as well for the assessment of the fetus's brain from ultrasound images using the random forest method [13]. The reported work demonstrated good segmentation results, however, the dataset have low sample image count.

Also, studies are reported for automatic segmentation of the fetus's head using deep learning methods. The work reported in [14] used the multi-task deep model for the estimation of the fetus's head circumference using different trimester ultrasound images. The literature also explored the use of attention networks towards segmentation of the fetus using encoder-decoder deep network [15]. In many places, the choice of the dataset of ultrasound images was taken from some open-source websites, especially online challenges. One such study about the evaluation and comparison of the methodologies using the grand challenge dataset is presented in [16].

In past, some methods have used deep models to segment the brain from the fetus ultrasound images [17,18]. The motivation of these works is to explore the use of computer-assisted systems to do the automatic diagnosis of the fetus's brain. However, both of these studies' objective is different, The reported work of [17] gives the utilization of the UNet model for segmentation while the work of [18] introduced the classification aspect to identify the normal and abnormal fetal planes of ultrasound imaging. With almost a similar objective but different methodology, the work [19] reported the use of the deep model to differentiate the fetal planes into 3 classes using the dataset of 12,400 images gathered from 1792 patients.

Some of the researchers also designed CNN light-weighted deep model for semantic segmentation of the head circumference [20]. The objective of the study is to localize the fetal head in ultrasound 2D images. The methodology used the traditional LinkNet architecture [21] as the backbone network for the proposed light-weighted model design. Besides this, some of the authors also focused on the utilization of the deep models which were previously used for some other application areas. One such work is reported in [22] where the model named multi-feature pyramid UNet (MFP-UNet) is used for semantic segmentation. The objective of using this model was to overcome the limitation of the traditional UNet model.

The extensive literature study on fetal head segmentation gives the idea that deep learning-based models, especially encoder-decoder-based network architectures are the most widely used architectures for semantic segmentation of the fetus head from the ultrasound images. However, the claimed results use a wide range of statistical measures for performance computation that gained good segmentation results. However, there is still scope of improving the accuracy through model up gradation. With this goal in mind, this paper introduces a new framework incorporating the power of regression with attention to encoder-decoder network architecture to enhance the results of the fetus segmentation and its head circumference.

# 3. Proposed deep architecture design

In this work, a new design of the deep model is proposed using the base as an encoder-decoder with the inclusion of the attention gates for fetus head segmentation in Ultrasound images. The work is further extended to find the dimensions of the fetus's head using 2D ultrasound images. The proposed work is considered to be an automated CAD system that is incorporated the advanced machine learning algorithm using an attention-based encoder-decoder model with regression to minimize the loss in the network.

# 3.1. Framework design of the proposed network architecture

The design framework of the proposed network architecture is presented in Fig. 2. There are three modules i.e. Pre-processing, Model training, and Post-processing. The collective build-up of these three modules will result in the segmentation of the fetus's head and the direct assessment of the circumference of the fetus's head.

Initially, the input imaging dataset is pre-processed followed by data augmentation to increase the dataset size. The extended dataset is further used for model training. Here, in the proposed work, a new model of deep learning is proposed for fetus head segmentation. The proposed model is based on the encoder-decoder methodology with the inclusion of the attention and regression layers. This model training is the second module of the framework. Later, in the third module, the model is evaluated with the test input image followed by post-processing operations to discover the dimension of the segmented fetus head. The post-processing operation includes ellipse fitting, dimensional map, and region circumference assessment. The details of each of these modules are discussed in subsequent subsections.

# 3.2.1. Image normalization

In AI-based applications, image normalization is a process used for datasets before feeding into the model for training. Here, dataset samples are processed using the common statistical distribution for size and intensity values. In general, the process usually includes both spatial and intensity normalization.

Spatial normalization implies making whole dataset images with the same spatial relationship using scaling, linear transformations, or even deformations. The main objective of spatial normalization is to make the dataset homogeneous in terms of size and intensity value distribution. Whereas, in normalization, the overall pixel values in multiple images will have the same statistical distribution. As it is known that artifacts can create in-homogeneity in images which can be corrected with normalization. Thus, before processing the ultrasound images, the framework uses the pre-processing of the input dataset images.

In this work, a Min-Max normalization of the input images (gray-scale or RGB) is performed to maintain the homogeneity in intensity distribution. As the 8-bit image is represented by using the pixel intensity between 0 and 255, a linear normalization of a digital image is performed using the given Eq. (1).

```
OutputChannel = 255 * (Input Channel – min )/( max – min ) (1)
```

where the max and min are the maximum and minimum pixel value representations of the input image.
