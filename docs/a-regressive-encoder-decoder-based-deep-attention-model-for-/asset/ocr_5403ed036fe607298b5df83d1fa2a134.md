# 3.3. Designing proposed attention encoder-decoder regression architecture

The main objective of the work is to segment the fetus's head from ultrasound images. To do so a new encoder-decoder model powered by the attention and regression layer is proposed for the segmentation of the fetus's head. The proposed model is inspired by the traditional model design frameworks which were designed using deep neural architecture for various Biological segmentation problems [23]. The basic architecture of the proposed model with the regression layer is shown in Fig. 4.

The model is designed using the convolution blocks and the skip connection that connects the high-dimensional feature vector with the output features collectively at the decoder part. This helps in making

the final prediction results more reliable and accurate. A detailed description of the model design and its associated components are discussed in the following subsections.

# 3.3.1. Encoder

The first half of the model called an encoder, is a collection of the Dense convolution blocks followed by a max-pooling to down-sample the input image into feature representations at multiple levels.
