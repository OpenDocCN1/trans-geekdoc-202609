Thus each of the blocks in the encoder is a dense block having an iterative concatenation of earlier feature vectors. Each dense block has some fixed number of layers, say N layers. The total number of direct connections for this dense block is (N*(N + 1))/2.

The proposed architecture uses the 4 dense blocks in the encoding phase each of length 4 i.e. there are 4 layers in the dense block each comprises of batch normalization, 2D convolution filter, and ReLU activation with the concatenation of the skip connections as shown in Fig.6. The first layer of the network is the input layer which took an image as input using 96 filters of size 7 x 7 with a stride equal to 2. This resulted in a feature descriptor of size 112 x 112 x 96. The output is then max pooled with a filter of size 3 x 3 and stride equal to 2 to get the reduced output of size 56 x 56.

Later, the encoder used the four dense blocks. These layers were repeated several times in a dense block as indicated by the count in Table 1. It is also to be noted that for the first three dense blocks, the output is further processed with the 2D convolution, to reduce the channels of the feature map, with average pooling having dimensions as 1 x 1 for convolution, 3 x  for average pooling, and stride equal to 2. At the end of the encoding phase, the output vector of 7 x 7 is produced to generate segmented output.

# 3.3.2. Decoder

The second half of the proposed architecture is the decoder which is just the transpose of the encoder. The objective of this phase is to project the low encoded features extracted by the encoder onto the higher resolution towards semantic segmentation. It consists of up-sampling of the data in just the reciprocal manner as done in the encoding phase.
