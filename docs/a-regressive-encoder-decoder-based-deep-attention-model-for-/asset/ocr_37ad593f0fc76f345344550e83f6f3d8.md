# Algorithm 1. Working of attention gate with skip connection.

Require: vectors x and g
Ensure: vector g should be taken from the next lowest layer of the network.
Dimensions (filters x height x width): x <- 64x64x64
Dimensions (filters x height x width): g <- 32x32x32
Convolution: Vector x stride convoluted resulted into updated dimension as
x <- 64x32x32
Convolution: vector g convoluted with 1x1 filter resulted into dimension x <-
64x32x32.
Elementary Sum: The two vectors are summed element-wise as x � g. It
resulted in larger aligned weights and relatively smaller unaligned weights.
Dimension Reduction: The resultant of vector x � g processed by a ReLU
activation followed by 1x1 convolution filter to reduce the dimensions to
(x � g) <- 1x32x32.
Feature Scaling: The vector is processed with the sigmoid layer to scale the
vector in the range [0,1]. This coefficient value closer to 1 indicate more
relevant features, called attention weights.
Up-sampling: The attention weights are up-sampled using trilinear interpo-
lation with dimension x <- 64x64 .
Normalize: The attention weights are multiplied element-wise to the original
x vector and then passed along in the skip connection as normal.

# 3.3.4. Regression

The last layer of the model is the regression layer which can be used
to minimize and handle the model loss. Before the regression layer, the
model uses the encoder-decoder architecture as the backbone network
to map feature output. The traditional architecture of the CNN model in-
cludes a softmax layer which was used for the classification problems.
Replacing the last softmax layer with a fully-connected regression
layer with a linear activation function helps to minimize the loss while
training. The model is trained by using the continuous value predicted
loss function. Here, in this work, the hybrid loss function is used for
the model training. Binary weighted cross-entropy (WCE) and Mean
Squared Error (MSE) are used as training cost functions.
These loss functions are defined in Eq. (2):

```
Cross Entropy (Q, T) = \(\sum_{i=1} T_i * \log(Q_i) + (1 - T_i) * \log(1 - Q_i)\) (2)
```

where Q is the output of the last layer of the decoder, T is the ground
truth or the expected output.

The binary-weighted cross-entropy, using the constant factor of
weight factor w = 5, is given in Eq. (3):

```
WCE(Q, T) = \(\sum_{i=1} ((1 - T_i)(w - 1) + 1)(T_i * \log(Q_i) + (1 - T_i)* \log(1 - Q_i))\) (3)
```

The Mean Absolute Error is calculated on basis of the pixel and is
defined in Eq. (4):

```
Mean Absolute Error(MAE) = \(\frac{1}{N} \sum_{i=1} |Q_i - T_i|\) (4)
```

where, Qi is the probability of the pixel from the query, Ti is the
probability of the pixel from the target, and N is the total pixels in an
image.
