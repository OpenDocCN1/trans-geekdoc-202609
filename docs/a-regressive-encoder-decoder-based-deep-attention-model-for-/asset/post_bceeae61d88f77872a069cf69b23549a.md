- Dense block reduces the number of parameters and is more efficient in the usage of the parameters
- Dense block motivates feature reuse and strengthens feature propagation.

Thus each of the blocks in the encoder is a dense block having an iterative concatenation of earlier feature vectors. Each dense block has some fixed number of layers, say N layers. The total number of direct connections for this dense block is (N*(N + 1))/2.

The proposed architecture uses the 4 dense blocks in the encoding phase each of length 4 i.e. there are 4 layers in the dense block each comprises of batch normalization, 2D convolution filter, and ReLU activation with the concatenation of the skip connections as shown in Fig. 6. The architecture description of the encoding is explained in Table 1.

The first layer of the network is the input layer which took an image as input using 96 filters of size 7 x 7 with a stride equal to 2. This resulted in a feature descriptor of size 112 x 112 x 96. The output is then max pooled with a filter of size 3 x 3 and stride equal to 2 to get the reduced output of size 56 x 56.

Later, the encoder used the four dense blocks. These layers were repeated several times in a dense block as indicated by the count in Table 1. It is also to be noted that for the first three dense blocks, the output is further processed with the 2D convolution, to reduce the channels of the feature map, with average pooling having dimensions as 1 x 1 for convolution, 3 x 3 for average pooling, and stride equal to 2. At the end of the encoding phase, the output vector of 7 x 7 is produced to generate segmented output.

## 3.3.2. Decoder

The second half of the proposed architecture is the decoder which is just the transpose of the encoder. The objective of this phase is to project the low encoded features extracted by the encoder onto the higher resolution towards semantic segmentation. It consists of up-sampling of the data in just the reciprocal manner as done in the encoding phase.

The only difference in decoding is the use of the skip connections where the same hierarchical decoding output and encoding output are concatenated by using the attention gate as described in detail in subsection 3.3.3. Technically, every iterative step of the expansion path of the feature map indulges a 2 x 2 transpose convolution that reduces the number of features to half of the value. The up-sampling consists of two layers i.e. up-sampling layer and a dropout layer with the dimensional filter of size 3 x 3 (up-sampling) and dropout equal to 0.2. The model uses the concatenation of the output features of the expansion and contracting path using the attention gate. Here, a 3 x 3 convolution and ReLU are used for processing. The last layer of the model is the regression layer which helps to map the output to the desired segmented region.

## 3.3.3. Attention gate

As the name suggests Attention refers to the focus on a specific object. Here, in the proposed architecture, the attention logic is used between the layers to put emphasis only on relevant activation maps during model training. This helps to place the attention on a specific imaging part rather than on the complete image. Based on learning,

attention can be classified as Soft attention and Hard attention. The main difference between these attention types is given as Hard attention picks image patches one at a time to pay attention and requires Reinforcement learning with Monte Carlo sampling. On the other hand, in Soft attention weights can be used on multiple patches of the image to determine the relevancy and the back-propagation approach can be used for the model training. In this work, soft attention is used with the encoder-decoder model.

As shown in Fig. 5, during decoding, most of the spatial information which is to be recreated is imprecise. Thus, the model uses skip connections that concatenate the information from the down-sampling with the up-sampling. However, this can result in many redundant low-level features because at the initial layers the feature representation is quite poor. Therefore, introducing soft attention at skip connections can suppress much of the activations from outside of region-of-interest (ROI) and minimizes the number of redundant features to carry forward. The basic flow mechanism of soft attention is shown in Fig. 7.

### Algorithm 1. Working of attention gate with skip connection.

Require: vectors x and g
Ensure: vector g should be taken from the next lowest layer of the network.
Dimensions (filters x height x width): x <- 64x64x64
Dimensions (filters x height x width): g <- 32x32x32
Convolution: Vector x stride convoluted resulted into updated dimension as x <- 64x32x32
Convolution: vector g convoluted with 1x1 filter resulted into dimension x <- 64x32x32.
Elementary Sum: The two vectors are summed element-wise as x + g. It resulted in larger aligned weights and relatively smaller unaligned weights.
Dimension Reduction: The resultant of vector x + g processed by a ReLU activation followed by 1x1 convolution filter to reduce the dimensions to (x + g) <- 1x32x32.
Feature Scaling: The vector is processed with the sigmoid layer to scale the vector in the range [0,1]. This coefficient value closer to 1 indicate more relevant features, called attention weights.
Up-sampling: The attention weights are up-sampled using trilinear interpolation with dimension x <- 64x64.
Normalize: The attention weights are multiplied element-wise to the original x vector and then passed along in the skip connection as normal.

## 3.3.4. Regression

The last layer of the model is the regression layer which can be used to minimize and handle the model loss. Before the regression layer, the model uses the encoder-decoder architecture as the backbone network to map feature output. The traditional architecture of the CNN model includes a softmax layer which was used for the classification problems. Replacing the last softmax layer with a fully-connected regression layer with a linear activation function helps to minimize the loss while training. The model is trained by using the continuous value predicted loss function. Here, in this work, the hybrid loss function is used for the model training. Binary weighted cross-entropy (WCE) and Mean Squared Error (MSE) are used as training cost functions. These loss functions are defined in Eq. (2):

```
Cross Entropy (Q, T) = \(\sum_{i=1} T_i * \log(Q_i) + (1 - T_i) * \log(1 - Q_i)\) (2)
```

where Q is the output of the last layer of the decoder, T is the ground truth or the expected output.

The binary-weighted cross-entropy, using the constant factor of weight factor w = 5, is given in Eq. (3):

```
WCE(Q, T) = \(\sum_{i=1} ((1 - T_i)(w - 1) + 1)(T_i * \log(Q_i) + (1 - T_i)* \log(1 - Q_i))\) (3)
```

The Mean Absolute Error is calculated on basis of the pixel and is defined in Eq. (4):

```
Mean Absolute Error(MAE) = \(\frac{1}{N} \sum_{i=1} |Q_i - T_i|\) (4)
```

where, Qi is the probability of the pixel from the query, Ti is the probability of the pixel from the target, and N is the total pixels in an image.
