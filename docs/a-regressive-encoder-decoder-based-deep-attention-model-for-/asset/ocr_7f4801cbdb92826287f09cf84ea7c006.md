# 4.3. Metrics to evaluate performance

In the proposed work, the Dice coefficient score, Difference in Head Circumference, Hausdorff Distance, and mean absolute percent error are used as a metric for performance evaluation.

The mathematical notation of these metrics is given in Eq. 10-13:

+   1. Dice Coefficient (DC): is defined as the ratio assessment on the number of pixels using segmentation output and the ground truth and is given as:
+   
+   \(\text{Dice Coefficient (DC)} = \frac{2 * (Seg_{Area} \cap Grt_{Area})}{|Seg_{Area}| + |Grt_{Area}|}\) (10)

where \(Grt_{Area}\) is the ground truth area and \(Seg_{Area}\) is the area extracted from the segmentation part.

+   2. Difference Head Circumference (DHC): is defined as the difference in the fetus head perimeter assessment of the segmented region and the ground truth and is given as:
+   
+   Difference Head Circumference (DHC) = \(P_{Seg} - P_{Grt}\) (11)

where, \(P_i\) represent the perimeter and \(i \in\) (segmented region, ground truth)

+   3. Mean Absolute Percentage Error (MAPE): is defined as the absolute percentage error with respect to the available ground truth and is given as:
+   
+   \(MAPE = \frac{MAE}{Grt} . 100\) (12)

where MAE is the mean absolute error and is given by

\(MAE = \frac{1}{N} \sum_{i=1}^{N} (S_i - G_i)\)

here, \(S_i\) is the pixel probability in Segmented output and \(G_i\) is the actual pixel probability in the available ground truth.

+   4. Hausdorff Distance (HD): is given as the distance between two contour points and found maximum among all such combinations. It is given as:
+   
+   \(HD(Seg, Grt) = max (h(Seg, Grt), h(Grt, Seg))\) (13)

where,
\(h(Seg, Grt) = max_{s \in Seg} min_{g \in Grt} \|p - g\|\)
\(h(Grt, Seg) = max_{g \in Grt} min_{s \in Seg} \|g - p\|\)

where, Seg represents the pixels in the segmented space (\(s_1, s_2, ...., s_n\)) and Grt represents the pixels in the ground truth (\(g_1, g_2, ...., g_n\)).
