# Computational Network Science: An Algorithmic Approach

Many algorithmic improvements and optimizations are possible such as the use of dynamic programming techniques. Clique percolation method (CPM) is a strategy for discovering overlapping communities (Palla et al., 2005), even CPM is computationally intractable. A key concept is reachability among nodes where there is a path between them. There are many other community concepts as lambda sets (Cross and Parker, 2004), k-Clique is a maximal subgraph in which the largest geodesic distance between any two nodes (defined in the network) is not larger than k. k-Club, which is a subclass of k-cliques, which restricts the geodesic distance not larger than k. A subgraph $G_s(V_s, E_s)$ is a $\gamma$-dense (i.e., quasi-clique) iff $E_s / |(V_s-1)/2| \ge \gamma$. When $\gamma=1$, $\gamma$-dense is the same as clique. A commonly used similarity measure such as Jaccard (Equation 6.7) can be used to find a group of similar nodes in a community:

Jaccard(v_i, v_j) = \frac{\N_i \cap \N_j}{\N_i \cup \N_j} = \frac{\sum A_{ik} A_{jk}}{\|N_i| + |N_j| - \sum A_{ik} A_{jk}} (6.7)
