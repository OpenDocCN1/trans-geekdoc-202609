An agent may perform one of two actions of adding or deleting a link that deterministically transitions the agent from one state to another. If the agent has $\sigma$ existing links, it will have $\sigma$ available “delete” actions and $I-\sigma$ available “add” actions totaling $I=\sigma+I-\sigma$ actions. If the target agent’s add link reciprocates, dyadic links are established (i.e., actualized). Otherwise, link is directional (i.e., aspirational). If a delete link is reciprocated by the target agent, deleting the link, dyadic link will break. Otherwise, a directional (i.e., aspirational) link will remain. The actions of target agents are unknown, we can model the result of link status probabilistically.

With addition or subtraction of each link, agent's connectivity network topology changes, which creates a new state (i.e., status) for the agent. If two agents reciprocate deleted links, a dyadic link between them is created. Each agent is involved in $I+1$ states, where $I$ states are reached from $I$ actions. Possible $I+1$ states for agent $i$, denoted by $M_i$, form a Markovian state space since state change is a deterministic function of link changed by action. An agent will value states that give them better structural properties (e.g., centrality measure), $\mu_i$, is a function that assigns a utility for each state for player $i$.
