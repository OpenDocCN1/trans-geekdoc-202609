# # Network Games

Decision making requires reasoning. Whereas decision theory is about the process of an individual's reasoning when pertinent decision attributes can be independently ascertained, game theory (GT) is about the process of reasoning when pertinent decision attributes include decisions of other individuals (Fudenberg, 1991). The latter is the scenario in networks where all the decisions are interdependent. GT has been long used as a branch of mathematics (Barron, 2008) to explain economic decision making in the theories of microeconomics (Mas-Cole et al., 1995). We will briefly introduce GT in Section 3.1 before the discussion of network-relevant applications in Sections 3.2–3.6.
