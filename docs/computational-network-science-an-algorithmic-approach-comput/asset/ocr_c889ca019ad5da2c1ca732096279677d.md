In cascade models, there are designated nodes that are initially active and spread their influence to other nodes. A more in-depth discussion of influence is deferred to Chapter 7. Let us consider a weighted graph, where each edge has a weight (i.e., strength) and each node carries a threshold value. There are a few nodes that are already active. The neighbors of an active node become active when the sum of the weights on the incoming edges is greater than the threshold value of that node. Linear threshold models (LTM) were first introduced by Granovetter (Granovetter, 1978). In LTMs, each node $v$ randomly chooses a threshold $	heta$ from a uniform distribution between 0 and 1. Let $	heta_v$ denote the fraction of neighbors of $v$ to be active to activate $v$. A neighbor $w$ be able to influence $v$ with weight $b_{w,v}$. We assume that $b_{w,v} \le 1$. Each node is activated if it satisfies Equation 6.6. The process of activations proceeds in successive activation stages until no further activations are possible.

$$\sum b_{w,v} \ge \theta_v$$ (6.6)
