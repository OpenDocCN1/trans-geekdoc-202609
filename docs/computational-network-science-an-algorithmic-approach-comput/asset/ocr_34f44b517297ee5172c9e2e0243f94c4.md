# 7.2 SOCIAL LEARNING

DeGrout assumes a society of $n$ agents, where individuals possess an initial ($t=0$) opinion on a singular subject, represented by a vector of probabilities $p(0) = (p_1(0), ..., p_n(0))$, where $p(t)$ denotes the probabilistic belief of agent $i$ at time $t$. Let $T$ be a matrix of interactions among agents, where $T_{ij}$ is the amount of weight (i.e., trust) agent $i$ places on $j$'s opinion at time $t$ in forming $i$'s opinion at $t+1$. We assume that agent $i$'s influence (i.e., trust) is limited to the sum of its peers. Therefore, the model renders to be stochastic. Probabilities are updated using Equations 7.4–7.6 with the Markov chain property:

```
$p(t) = T \times p(t-1) \quad (7.4)$
```

```
$p(t) = T_i \times p(0) \quad (7.5)$
```

```
$\forall i, p_i(\infty) = lim_{t\to\infty} p_i(t) \quad (7.6)$
```

A network $N$ and a matrix $T$ reach consensus if $\forall i, j \in N, p_i(\infty) = p_j(\infty)$. Such a matrix $T$ is a steady-state Markov chain. A society is said to be wise when the most influential influence vanishes in the society
