# 3.5.2 Medium Access: Bandwidth Auction Game

Measurement of data transfer rate (i.e., communication bit rate) is bandwidth and it becomes an item of contention when multiple users (e.g., vehicles) share an access point (e.g., roadside access point). Users offer bids $s_i$, price per unit of bandwidth allocation in an auction style. If $t_i$ is the duration of connection to the access point requested by user $i$, Equation 3.12 is the amount of bandwidth allocated to user $i$, denoted by $g_i$. $N$ is the number of users and $B$ is the total amount of bandwidth available. Since players do not know each other's type by their request duration $t_i$, they play a Bayesian game with equilibrium determined by an iterative algorithm shown in Figure 3.6. $\varepsilon$ is a small parametric value.

```
$g_i = \frac{s_it_i}{\sum_{j=1}^N s_jt_j} \times B \quad (3.12)$
```
