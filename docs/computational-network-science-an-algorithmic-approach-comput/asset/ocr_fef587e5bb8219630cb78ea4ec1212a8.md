Definition (a node's resource access measure): SC for node i with respect to resource R is the sum of resource access to all resources in the network. This includes neighbors who are resource owners and remote resource owners.

An obvious observation is that a node that is well connected with many nearby resource owners has a higher SC than a node that has fewer and more distant resource owners. It is possible for nodes to be rich or poor in SC given their position in the network relative to resource owner nodes. Given the policies for sharing and hoarding, it is possible to build differential relations and make certain nodes beneficiaries of SC. It is also possible to withhold resources from certain nodes, thereby ostracizing them by lack of SC.

Next, we focus on determination of SC in a given network as stated in the following definition.

# Definition (a node's SC measure): SC for the network with respect to resource R is the sum of SC for all nodes in the network.

SC is generated in the links through dynamics of interaction inside the links. Therefore, SC for a network linearly scales by summing SC for all links in the network. Increased links are proportional to increased SC stated in Observation 2. The effects of topology are overlooked in the network perspective but are considered in the egocentric in the next definition. All bridged communities contribute to accumulation of the over-instrumental purpose of SC (Lin, 2001). In general networks and from an egocentric perspective, bridging is said to contribute to SC (Smith, 2008). We return to this when we discuss our egocentric view of SC.
