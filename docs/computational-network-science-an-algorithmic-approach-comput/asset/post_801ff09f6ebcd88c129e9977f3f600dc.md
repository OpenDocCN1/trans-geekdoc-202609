# 3.3 COOPERATION IN NETWORK SYNTHESIS GAME

Cooperation in GT suggests coalition formation. This can be applied to networks. Let $I$ be a set of players. $S$ is a set of all possible coalitions (i.e., all nonempty subsets of $I$). Whereas $B$ is the least amount of resources needed for accommodating service demands, $b$ is the amount of available resources of the $i$th member of a coalition, which is common knowledge among players. If the sum of available resources in a coalition $S$ exceeds the threshold of resources required to meet the service demands $B$, that coalition is worthwhile. Otherwise, the coalition $S$ has no value. This is shown in Equation 3.8;

> $If \sum_{i}^{|S|} b_i > B, \text{ then } \vartheta(S) = 1; \quad \text{otherwise, } \vartheta(S) = 0 \quad (3.8)$

Network synthesis game can be formulated in the form of a weighted voting game $(I, w), W/2$, where $w$ is the weight of player $i$’s vote and $W = \sum_{i}^{|I|} w_i$. Network synthesis game is isomorphic to a weighted voting game with $b_i = w$, and $B = W/2$.

# 3.4 BAYESIAN GAMES

In the real world, data is unavailable to players. In fact, possession of more information and larger strategic options have adverse effect on player utility (Aumann, 1976). This is the fundamental premise for Bayesian games, where each player $i$ is of specific type $\tau_i$, which is strictly private knowledge, known only to $i$, and not by others. $q$ is a joint probability distribution over the profiles of types. $\sigma(\tau)$ is the set of strategies of player $i$ with type $\tau_i$. Strategies depend on player types. Utility is a function computed by Equation 3.9 that produces a value for a given player-type vector and their strategy vector. Each player will evaluate ex ante (i.e., before the event) expected utility by marginalizing $q$ given its own type in Equation 3.10. If player set and their strategy sets are finite, a mixed Bayesian equilibrium exists (Menache and Ozdagar, 2011).

# 3.5 APPLICATIONS

This section outlines two key applications in wireless networking that are modeled as Bayesian games.

### 3.5.1 Packet Forwarding Game

In a wireless network, packets travel from senders to receivers. Each node is tempted to drop the packet the player should forward, as this would save some of his or her resources. However, if the other node reasons in the same way, the packet that the first player wanted to send will also be dropped. They could, however, do by mutually forwarding each other's packet. Hence, there is a dilemma.

A sender can choose between strategies to forward the packet in good faith or alter it and thereby attack the receiver. The receiver has two available strategies to vigilantly monitor possible attacks or to stay idle. Wherever all are alike, might be one of the following types: malicious or benign. Since we do not know the sender type, packet forwarding is modeled as a Bayesian game. The payoffs for packet forwarding game are shown in Figure 3.5. $C_A$ is the sender's cost of attacking. $G_A$ is the sender's utility for a successful attack. $C_F$ is the sender's cost of forwarding. $C_M$ is the receiver's cost of monitoring for attacks.
