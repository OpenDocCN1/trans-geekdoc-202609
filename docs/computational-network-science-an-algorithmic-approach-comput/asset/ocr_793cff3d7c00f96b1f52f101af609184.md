A more nuanced coordination game is found in the second price auction game. Let there be $n$ players bidding for a single item. Let $v_i$, player $i$'s valuation and all valuations are common knowledge. Valuations are ordered as shown in Equation 3.6. Players simultaneously bid $b_1,b_2,...,b_n$. The item is won by the player with the highest bid. The winner's utility is computed as $\mu_i = \vartheta_i - b_j$, where $b_j$ is the bid of the second highest bid and $\vartheta_i$ is the value/worth for agent $i$.

$(b_1, b_2,\dots,b_n) = (\vartheta_1, \vartheta_2,\dots,\vartheta_n)$ is a NE solution. $\vartheta_i$ wins and pays $\mu_i = \vartheta_i - \vartheta_2$. Otherwise, $\mu_j = 0$ for all $j 
eq i$.

$(b_1, b_2,\dots,b_n) = (\vartheta_2, 0,..., 0)$ is the second NE solution, where $v_1$ wins and pays 0.

$(b_1, b_2,\dots,b_n) = (\vartheta_3, 0,..., 0)$ is the third NE solution, where $v_1$ wins and pays 0.

This can repeat for $n$ NE solutions illustrating the need for coordination to select the desired NE.

```
$$\vartheta_1 \gg \vartheta_2 \gg \dots \gg \vartheta_n > 0 \quad (3.6)$
```
