imp = SimpleImputer(missing_values=np.nan, strategy='mean')

# 编码 categorical 数据

为了在机器学习目的中利用数据集中的 categorical 国家特征，需要将其转换为数值格式。一种有效的技术叫做 one-hot encoding（一热编码）。该方法为每个唯一的 country 值创建一个独立的二进制特征。对于数据集中的每条记录，与其 country 值对应的二进制特征设为 1，而其他二进制特征设为 0。

结果，'country' 列的类别信息被转换为一组数值特征。这些新特征准确表示每个 country 值在数据集中的存在或不存在。这种数值表示使得机器学习模型能够在训练和预测过程中有效理解和分析 'country' 特征。

通过使用 one-hot encoding，我们确保 'country' 特征的类别属性不会阻碍模型的理解。相反，它提供了结构化的方式将类别数据纳入机器学习算法，提高模型获取有意义洞察并基于数据集特征做出准确预测的能力。

# 代码说明

ct = ColumnTransformer(transformers=[('encoder', OneHotEncoder(), [1])], remainder='passthrough')

ColumnTransformer 是 scikit-learn（sklearn.compose）模块中的类，用于对数据集的不同列应用不同的转换。

在此代码中，transformers=[('encoder', OneHotEncoder(), [1])] 指定了转换步骤：

'encoder' : 给定的转换步骤名称。

OneHotEncoder() : 用于执行一热编码的转换对象。

[1] : 指示转换（一热编码）应用于输入数据（ X ）的列索引 1。

X = np.array(ct.fit_transform(X))

ct.fit_transform(X) : 该方法先拟合转换器 ct 对数据（确定一热编码的类别，例如），然后根据指定的转换对数据进行变换。

X 然后被赋值为转换后的数据，并使用 np.array() 转换为 NumPy 数组。
