# 什么是不平衡数据？

不平衡数据指的是类别在数据集中不均匀分布，即某一类（或几类）的实例数量显著多于其他类。这种不平衡会给机器学习模型带来挑战，因为模型可能会偏向多数类，导致在少数类上的表现不佳。

# 处理数据不平衡

# 为什么我们需要统计？

在数据科学和分析领域，统计学作为基础框架发挥着核心作用。它是数据专业人士深入数据的稳健工具，通过探索性数据分析（EDA）这一关键步骤，帮助他们与数据深度互动。

统计学广泛应用于数据探索、可视化和理解，赋予专业人士得出明智结论的能力。通过应用统计原则，数据专业人士可以发现复杂的模式、识别趋势，并揭示数据集内的关系。

这些能力提供了宝贵的洞察，从而塑造决策过程。通过统计学，专业人士能够熟练地处理数据的复杂性，将原始信息转化为可操作的智慧。
