

# DLT (分布式账本技术)

它是驱动区块链的底层。虽然它最早由 Stuart Haber 和 W Scott Stornetta 在 1991 年概述，但最早是在 2008 年由一个名为 Satoshi Nakamoto 的个人或小组提出的概念。它允许在去中心化的数据库中通过加密技术以安全且准确的方式存储所有信息。一旦信息存储，它就变成了一个不可篡的数据库。预计到 2027 年，全球 10% 的 GDP 将通过 DLT 处理。

# Docker

由 Solomon Hykes 于 2013 年发明。该工具旨在使用容器创建、部署和运行应用程序。容器将应用程序所需的所有部分（如库）打包在一起，并作为一个包部署。它为运行在共享环境中的应用程序带来了安全性。

# Dogecoin (狗狗币)

它是一种点对加密货币，主要用于打赏系统，社交媒体用户可以为提供有趣或值得关注的内容打赏。它由软件工程师 Billy Markus 和 Jackson Palmer 于 2013 年 12 月 6 日参考“Doge”表情包中的柴犬脸作为其 Logo 和命名创建的。它最初是对各种山寨币增长的讽刺。它具有 1 分钟的区块间隔，这意味着它比其他区块链更快。

# Double Counting (重复计算)

会计中的重复计算是一种错误，由于任何原因，某笔交易被计算了多次。

# Double Spending (双重花费)

双重花费与数字货币相关的独特问题，它允许在线价值单位被花费多次。这是因为在缺乏记录双方之间每笔交易的中央权威的情况下，精通技术的人可以相对地复制价值单位周围的数字信息。比特币作为区块链技术的首次商业应用，通过独特的加密执行过程以及在分布式账本中记录交易（在交易最终确定和批准之前需要所有各方的共识），防止了在线创建的数字价值单位的双重花费问题。因此，它被称为加密货币。比特币使用一种称为区块链的通用账本，提供了一种让所有节点能够通过受博弈论启发的过程确认每笔交易，并以区块的形式广播到所有节点的方法。

# Digital Twin (数字孪生)

数字孪生是一种虚拟表示，作为物理实体或过程的实时数字对等物。数字孪生概念被广泛用于监控企业范围内的物理资产，如涡轮、引擎和电信塔。

当所考虑的资产在其生命周期内使用分布式且不可篡的账本作为单一事实来源，与多个利益相关者共享或进行交易时，基于区块链的数字孪生具有适用性。基于物联网的产品和工业资产是使用区块链数字孪生概念的良好竞争者。

# EEA (以太坊企业联盟)

以太坊企业联盟 (EEA) 是一个由成员领导的行业组织，其目标是推动以太坊区块链技术作为开放标准来赋能企业。它于 2017 年 2 月启动。EEA 的使命是提供开放、基于标准的架构和规范，以加速企业级以太坊的采用。成员包括全球的多个机构。创始成员和轮值董事包括埃森、桑德士银行、BlockApps、梅隆银行、CME Group、ConsensSys、IC3、英特、摩根、微软和 Nuco。

# EIP (以太坊改进建议)

EIP 是以太坊改进建议（Ethereum Improvement Proposal）的缩写，就像 BIP 是比特币投资提案（Bitcoin Investment Proposal）的缩写一样。EIP 为以太坊区块链设定了技术标准（协议规范、合约标准、客户端 API 等）。Martin Becze、Vitalik Buterin 和 Gavin Wood 是 2015 年到 2016 年底最初的 EIP 编辑。

# ECC (椭圆曲线加密)

它是一种基于有限域上的椭圆曲线及其代数结构的公钥加密。它们能够提供与 RSA 加密相同的加密强度，但密钥尺寸小得多。

# ECDSA (椭圆曲线数字签名算法)

ECDSA 是一种利用 ECC 的数字签名算法，用于创建签名和验证过程的密钥对。

# Encryption (加密)

加密是通过密码学保护信息的过程。明文转换为另一种形式即密文。只有持有密钥方才能将密文转换回明文。AES、三重 DES、RSA (Rivest-Shamir-Adleman)、Blowfish 和 ECC 是一些领先的加密技术。

# Enterprise Blockchain (企业区块链)

它是通常由公司实现的区块链网络，用于管理企业流程，如财务、保险、供应链、合同、国际汇款和全球支付。企业区块链本质上是许可性的区块链，加入区块链的伙伴、同行或供应商需要获得托管公司的预先批准。托管的公司并不控制区块链，因为一旦被录取，所有方都拥有平等的权利控制权。R3、以太坊企业联盟、Linux基金会是开发企业区块链的一些知名组织。

# EOA (外部所有账户)

外部账户由私钥控制。拥有账户私钥的人能够从账户发送加密货币（以以太坊为例）和消息。它不像由代码控制的合约账户 (CA)。交易验证涉及检查时间戳和 nonce 组合以建立有效性，以及执行所需的可用费用。

# EOS 区块链

创业操作系统 (EOS) 是一种基于区块链的去中心化操作系统，旨在创建、托管和支持安全的去中心化应用程序 (dApps) 和智能合约。它是为了满足大规模去中心化应用而，由 Daniel Larimer 和 Brendan Blumer 开发。它由 Block.one 公司作为开源软件发布，发行了其原生货币 EOS。

epoch 是选定共识小组的目标时期。它还定义了预设数量区块在链上确认所需的时间。在以太坊区块链中，每 30000 个区块，就会使用一段新数据（DAG）来挖掘新区块。每组 30000 个区块被称为一个 epoch。

# ERC 20 (以太坊意见请求 - 20)

ERC 20 被定义为以太坊网络上发行标记的标准协议。根据官方来源，该协议管理着以太坊区块链上的标记。后缀“20”的唯一目的是代表唯一的提案 ID。开发者使用 ERC20 代币来开发他们的项目。这是他们将其项目代币化，同时也为他们各自的项目提供了融资方式。ERC 20 为以太坊系统内的其他代币定义了六种不同的函数，并导致了多种替代标记 (Alt Tokens) 或替代币 (Alternate Coins) 的诞生。
