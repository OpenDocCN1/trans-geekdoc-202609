

# 艾兰·图灵

被誉为现代计算机科学之父的艾兰·马西森·图灵的工作导致了图灵完备性的起源。在区块链世界，图灵完备性意味着协议只要拥有正确的指令、足够的时间处理能力，就能使用其代码库执行任何任务。从本质上说，它允许编写循环。当以太坊声称它是图灵完备的而比特币不是时，图灵完备性变得非常突出。事实上，比特币是图灵完备的。图灵完备性有助于保护数据避免可能的信息窃取，增强系统防御黑客的安全性，并提供安全的交易系统。

# 代币 / 替代代币

它们代表比特币之外的所有加密货币。有多种属性可以将代币与比特币区分开来，例如共识机制、智能合约、低价格波动或无波动。全球有 350 多家交易所交易着超过 10,000 种代币。

# 反脆弱性

反脆弱资产在存在风险和不确定性时表现更好，并从负面事件中获得力量。这一概念由著名作家纳西姆·尼古拉斯·塔勒布创立。他曾说：“事物从冲击中获益；它们在面对波动、随机性、无序和压力时会繁荣增长，并热爱冒险、风险和不确定性”。一个经典的例子是比特币（BTC），多年来随着每一次价格冲击而变得更加强大。

# API（应用程序编程接口）

应用程序接口允许任何系统从第三方系统获取数据或向其推送数据。API 的普及在各个领域开启了多种可能性。在银领域，开放 API 银行导致金融科技公司和银行创造了许多创新产品和服务，从而提高了客户参与度，增强了交易安全性并增加了便利性。

# Ashdraked（爆仓）

Ashdraking 指做空比特币导致加密投资者资本的全额损失，其目的是高价卖出比特币并在低价买回。该术语以“Ashdrake 爵”命名，这是一位罗马尼亚比特币交易者的笔名，他曾对比特币进行做空——押注其价值将下降。最初，随着比特币在 2014-2015 年下跌，他赚了巨额利润。随后，他在 300 美元时做空比特币，预计价格会下跌。相反，比特币价格在几周内飙升至 600 美元，他损失了大量资金。

# ASIC（专用集成电路）

专用集成电路是专为特定的计算用途构建的，而不是通用的。这些电路变得非常流行，并用于挖掘加密货币，因为在个人电脑上挖矿非常困难。它们比通用处理器（GPU）更高效。一旦发布了特定加密货币的 ASIC，没有 ASIC 的挖矿通常是无利的。

# 非对称密钥

非对称密钥是指使用两个不同或独立的公钥和私钥（密钥是不同的，与对称密钥不同）。公钥用于加密，只能通过私钥解密。公钥和私钥在数学上是相互连接的，它们的关系随算法而异。加密货币中的这些密钥确保交易来源的合法性，黑客无法提取资金。在比特币中，钱包地址是对应公钥的哈希版本。它证明了接收资金/代币/硬币的所有权。

# ATH（历史最高点）

加密货币或任何股票价格的历史最高点是指该资产截至目前为止的最高价格。例如，比特币在 2017 年达到了 19,783 美元的 ATH，随后在 2021 年 3 月达到了 61,712 美元的 ATH。

# ATL（历史最低点）

历史最低点是加密货币或任何股票截至此日的最低价格。这被用作衡量资产性能和价格相对变化的标准。

# 原子交换

原子交换是指两种加密货币之间可以相互交易，即在没有第三方平台或交易所干预的情况下，将一种转换为另一种。它们以完全点点对人的方式在钱包之间进行。它们之所以被称为“原子的”，是因为结果要么是交换成功且每位交易者都收到对方的资金，要么什么都没有发生且两个交易者都保留各自的资金。在 2013 年实现这一点的 Tier Nolan 被广泛认为是原子交换的发明者。第一次原子交换发生在比特币和山币之间。

# ABCI（应用区块链接口）

ABCI（应用区块链接口）的目的是在一台计算机上的任何有限确定性状态转换机与跨多个计算机的区块链复制引擎（也称为共识引擎）之间提供一个整洁的接口。

# AKS（Azure Kubernetes 服务）

AKS 是微软 Azure 公共云上的一种开源全托管容器编排服务，可用于集群环境中部署、扩展和管理 Docker 容器及基于容器的应用程序。它可以秒级内设置和管理容器化应用程序，并于 2019 年 3 月 8 日发布。

# B_money

B-money 是最早的加密货币之一，从未正式发布。B-money 致力于提供今天加密货币提供的许多相同的服务和功能（匿名、分布式现金系统）。它由陈财（Wei Dai）发明。他是密码朋人（Cypherpunks）的成员，并共同提出了 VMAC 消息身份验证算法。以太坊的最小单位以他的名字命名为 Wei。1 Wei 是一个以太坊的万亿分之一。

# BAAS（区块链即服务）

BAAS 是第三方为构建区块链应用程序的公司创建并管理云网络的服务。这些第三方服务是不断增长的区块链技术领域的一个较新进展。

IBM, AWS, Azure, Oracle, SAP, Alibaba, Stezy, Zeeve, Settlemint, Chainstack 是全球领先的一些区块链即服务提供商。

# Bakong

Bakong 是柬埔寨国家银行发行的首个央行数字货币（CBDC）。它由日本金融科技公司 SORAMITSU 共同开发并于 2020 年 10 月 28 日发布。Bakong 支持瑞尔和美元交易，并有自己的用于交易的移动应用程序。

# 熊陷阱

熊陷阱始于一组交易者卖出大量加密货币。这让其他交易者由于怀疑价格会调整而卖出。这导致价格进一步下跌。当早期的卖者以较低的价格买回加密货币时，熊陷阱就释放了。熊陷阱可能持续几小时或几天。

# 熊鲸

加密市场中一个以低于市场价格的折扣卖出巨大数量资产的人，这会将市场价格推向更低水平。这一事件发生在 2014 年的比特币中，当时一个被称为 Bearwhale 的个人对比特币失去信心，将 30,000 枚币转移到 Bitstamp，并在市场价格为 350 美元时设置了每币 300 美元的卖出单。

# Besu

Hyperledger Besu 是一种以太坊客户端，旨在为公共和私有许可区块链用例提供企业级支持。它也可以在 Rinkeby、Ropsten 和 Görli 等测试网络上运行。Hyperledger Besu 包含了多种共识算法，包括工作量证明（PoW）和权威证明（IBFT、IBFT 2.0、Etherhash 和 Clique）。其全面的许可方案专为联盟链环境设计。

# BFT（拜庭容错）

BFT 是系统能够抵抗源自拜庭将军问题的这一类故障的属性。这意味着即使区块链网络中的某些节点故障或采取恶意行为，BFT 系统也能继续运行。它被用作区块链网络中的共识机制之一，保护区块链不受恶意节点或未知入侵者的操纵。实用型拜庭容错由 Miguel Castro 和 Barbara Liskov 在 MIT 实验室引入，并用于 Hyperledger、Stellar 和 Ripple 等区块链协议。
