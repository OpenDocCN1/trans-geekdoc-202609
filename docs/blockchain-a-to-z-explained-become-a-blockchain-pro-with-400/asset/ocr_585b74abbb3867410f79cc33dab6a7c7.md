# YAML (Yet Another Markup Language)

YAML, first proposed by Clark Evans in 2001, is a Markup and Data serialization language that came into existence in 2001.
YAML is an alternative to JSON that formats data in a natural, easy to read and concise manner. Its not a programming language in the true true sense. YAML files store information anddoesn't include actions and decisions. It was released in an era that had proliferation of various mark-up languages like HTML, XML and SGML. Later, YAML was recoined as YAML Aint Markup Language.
