

# 前言

C.P. Gurnani

Tech Mahindra 董事总经理兼首席执行官

毫无疑问，区块链是全球每一位首席执行官都在关注的技术。没有其他新兴技术能像区块链在近年来引发的如此巨大且具有颠覆性的关注。这既是因为比特币（区块链技术的首个商业化应用），也是因为其在改变我们日常生活的众多业务流程和服务方面具有天生的巨大潜力。

在加密货币世界，区块链不仅催生了比特币网络，还孕育了以太坊、Ripple、莱特币（Litecoin）等其他许多正在改变世界的加密货币。区块链还触发了根本性的新应用和业务模式的出现，例如非同质化代币（NFTs），它开启了加密货币或数字收藏品的新趋势。

在企业级应用领域，区块链展示了其转型以下领域的潜力：

- 供应链：使其具有反脆弱性；
- 支付与国际汇款：通过稳定币和央行数字货币（CBDC）；
- 贸易融资：赋能网络执行自动化且不可篡改的发票折扣贴现；
- 数字身份：通过自主主权身份（Self Sovereign Identities）确保其安全；
- 媒体与娱乐业：通过配置自执行的合约与权利管理。

在政府对公民（G2C）服务中，区块链在促进福利管理、权属管理乃至选举与投票管理中急需的透明方面展现了巨大潜力。

预见到这些变革性趋势，我们在 2018 年 5 月在 Rajesh 的卓越领导下，正式在公司启动了区块链业务部门。他是公司内部所有区块链事务的“首选专家”。

我个人认为，Rajesh 拥有一种在混乱和不确定的情况下创造价值的独特特质。在区块链早期，技术的采纳尚不明朗，因为全球监管机构每个月都在支持或禁止加密货币，而且区块链当时仅涉及加密货币。尽管如此，Rajesh 和他的团队能够带来一种愿景，为我们全球的客户寻找实用且有意义的应用。2019 年，TRAI UCC 规程是 Tech Mahindra 区块部门的一个决定性时刻。在一个充满该技术怀疑者和批评者的世界里，Rajesh 不仅领导了自己的团队，还领导了印度电信生态系统中的技术和业务代表，建立了全球最大的多云区块链网络，以保护终端客户免受商业电话和短信的干扰。

我很自豪地说，我们的区块链能力因通过研究和执行大型项目所创造的投资、领导力和知识产权而获得了全球认可。我最珍视的认可是 Tech Mahindra 入选“2021 年福布斯全球50 强区块链公司”。其他认可还包括第六届年度 NASSCOM 技术奖和 Hyperledger 认证服务提供商标识。

对于 Rajesh 来说，回馈社会与创造收入同样重要。我乐于投入他关于区块链技能开发和增强的想法。事实上，在他在 TechM 任职的前 180 天内，Rajesh 就在印度多地举办了 8 多场 Hyperledger Fabric 和 Corda 课堂培训，吸引了 350 多名技术参与者。他还领导了与特伦甘纳邦政府合作的区块链区的建立与执行，用于区块链政策和初创生态系统的开发。

看到他通过这本书继续他的旅程，贡献区块链知识知识，我感到非常高兴。我相信这是一本包含 400 多个术语和区块链词汇的独特作品，而且是全球首创。

这本书不仅是 Rajesh Dhuddu 和合作者 Srinivas Mahankali 努力的结晶，来自我们区块链团队成员 Amey Rajput、Dhen Dhulla 和 Aman Malhotra 的积极投入和贡献。

我对比 Rajesh 作为区块链领导者的押注取得了良好结果，我相信他及团队书中的工作对于所有渴望进阶学习并精通区块链的人来说，将是一次充实知识的读物。
