

# 图灵完备

如果一台机器可以执行任何其他可编程计算机能够执行的计算，则被认为是图灵完备的。现代计算机在这意义上都是图灵完备的。运行在以太坊区块链上的以太坊虚拟机（EVM）也能够处理任何“可计算函数”。简而言之，它能够完成你使用任何传统计算机和编程语言可以完成的工作

# 代币化

代币化是一个将业务商品、策略或服务转换为可交易且可在区块链上记录的离散单元的过程。有助于增加底层资产的流动性并促进价值的释放。

# 代币经济学

加密货币的供需特征代表了代币经济学。它基于哈佛心理学家BF·斯金纳（BF Skinner）于1972年提出的代币经济理念。他认为通过提供某些可识别价值的单位，可以控制行为并激励积极行动。它还研究加密货币在更广泛生态系统中的运行方式，涵盖代币分配以及激励机制如何促进网络中的积极行为。

# Tendermint

一种用于构建区块链（特别是 Cosmos 生态系统）的区块链应用和领先的拜占庭容错（BFT）引擎。支持 Tendermint Core 和 Gaia。Tendermint core 为所有忽略编程语言的区块链应用提供 Web 服务器、数据库和支持库。

# Tezos

Tezos 是一个基于权益证明（Proof of Stake）的开源区块链网络，以 TEZ 作为原生货币，促进点对点交易和智能合约。Tezos 智能合约使用形式化验证，使其在数学上是验证的。

# TVL (总锁仓量)

DeFi 世界中的 TVL 指单个去中心化交易所（DEX）、去中心化应用（dApp）或整个生态系统内部持有的资金。Curve Finance、Uniswap、Sushiswap、Bancor 和 Balancer 是根据各自的 TVL 的一些领先 DEX。

# Ubuntu

Ubuntu 是由 Mark Shuttleworth 于 2004 年 10 月创建的 Linux 发行版。它基于 Debian，主要由自由开源软件组成，旨在解决 Linux 中存在的由于各种不支持的社区版导致的碎片化问题。它与以太坊的许多开发工具兼容。Ubuntu 是一个完整的 Linux 操作系统，提供社区和专业支持。事实上，它被称为世界上第一个免费软件，也是第一个按照可预测间隔和节奏定期发布的操作系统。Ubuntu Desktop 还是世界上最广泛使用的 Linux 工作站平台。Ubuntu Server 是 Openstack 项目的参考操作系统，也是 AWS、Google 和 Azure 上流行的操作系统。

# 父区块 (Uncle Blocks)

父区块与比特币的孤儿区块（Orphan blocks）类似；当两个区块在同一时间被挖掘并提交到账本时，它们会在以太坊区块链中创建。只有一个作为一个区块进入账本，另一个不能，因为它的工作证明份额相对较低。以太坊系统中父区块会有奖励，与比特币中的孤儿区块不同。UTXO 基于 Hal Finney 的可重用工作证明提案，而该提案又基于 Adam Back 的 Hashcash 提案。

# Uniswap

Uniswap 是最流行的基于以太坊的 DEX，是一种用于交换加密货币的去中心化金融协议。该协议通过智能合约和自动做市商（AMM）模型促进以太坊区块链上加密货币代币之间的自动交易。由 Hayden Adams 于 2018 年使用 Solidity 开发。

# 不可链接性

它有助于为公共区块链提供匿名性。在比特币中，当难以链接属于同一用户的多个地址和交易时，就会发生不可链接性。

# 美元币 (USD Coin)

USD Coin (USDC) 是一种挂钩美元的数字稳定币，运行在以太坊、Stellar 和 Algorand 区块链上。每个 USDC 都有一个储备美元支持。USD Coin 由一个名为 Centre 的财团管理。它由 Circle 公司创立，该公司帮助互联网企业在一个统一的平台上接受和支付付款。

# UTXO (未花费交易输出)

UTXO 定义了区块链交易中未被花费的输出，即可以作为新交易的输入。换句话说，它可以定义为执行加密货币交易后剩余的数字货币金额。它有助于简单地防止双花费，无需扫描整个区块链。比特币使用 UTXO 模型来防止双重计算和花费。UTXO 基于 Hal Finney 的重用工作证明提案，该提案又基于 Adam Back 的 Hashcash 提案。

# UBIN (项目 UBIN)

Project Ubin 是一个与行业合作的项目，旨在探索区块链和分布式账本技术（DLT）用于支付和证券清结算与结算。该项目旨在帮助新加坡管理局（MAS）和行业通过在代币化新加坡元、重新设计实时全额结算（RTGS）货币转账、交收即付（DvP）和跨境支付中的实际实验和广泛的生态协作，更好地理解 DLT 及其可能带来的收益。

# *Ursa*

Hyperledger Ursa 是一个共享加密库，防止加密工作的重复，从而提高区块链网络的整体安全性。Ursa 的两个主要组件是 Base-Crypto 库和 Z-Mix。它的库作为 Hyperledger 和非 Hyperledger 项目使用加密的仓库。

# 验证者 (Validator)

验证者是验证区块链上所有输入交易并用其私钥对这些验证过的交易进行签名的人。

# 空壳软件 (Vaporware)

它是一种早期向公众发布的产品（通常是计算机硬件或软件），但延迟延迟要么从未制造或被正式取消。在区块链领域，它指的是由于缺乏适当的用例或技术支持项目的承诺或主张而从未实现或启动的加密货币项目。Tron 和 Verge 在早期曾被认为是加密世界的空壳软件。

# VeChainThor

VeChainThor 是一个公共区块链，由 Sunny Lu 于 2015 年构思并于 2016 年发布。它旨在让企业用户大规模采用区块链技术，以增强供应链可见性、碳信用和防伪服务。它为供应链提供数字可验证的可溯性。它托管了 VeChain 生态系统，使用物理跟踪设备跟踪供应链的每个阶段。由 VeChain (VET) 代币和 VeThor 令牌 (VTHO) 驱动，VET 用于价值的存储和传输，VTHO 作为能量令牌（燃料）支付网络上的交易。

# VIPER (Viper 协议)

Viper Protocol 是基于 Harmony 区块链的跨链多产品 DeFi（去中心化金融）协议。VIPER 是原生治理和收益生成令牌，用于 Viper Exchange/DEX 以及在 Harmony 区块链上运行的所有 DeFi 产品。它还兼容币安智能链、Fantom 等。

# VMAC (v消息认证码)

VMAC 是一种基于分组密码的消息的消息认证码（MAC）算法，使用了 2007 年 4 月由 Ted Krovetz 和 Wei Dai 提出的通用哈希。该算法旨在用于 64 位系统上的高性能，并有形式化分析的支持。

# Vyper

Vyper 是一种用于编写智能合约的合约导型 Python 编程语言。它由 Vitalik Buterin 和 Gavin Wood 创建。它的功能比 Solidity 少，但使合约更安全且易于审计。它取代了最初为以太坊开发的 Serpent。
