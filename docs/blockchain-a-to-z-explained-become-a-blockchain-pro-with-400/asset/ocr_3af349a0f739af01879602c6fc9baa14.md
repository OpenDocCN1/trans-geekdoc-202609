# Serenity

Ethereum 2.0 version is referred as Serenity. It is an upgrade of existing Ethereum on the main net. New features include implementation of sharding to facilitate replacement of Proof of Work (PoW) consensus with Proof of Stake (PoS), leading to an increase in transaction speeds. Serenity will be launched in three phases with third phase implementation to be completed by mid of the year 2022. Topaz, Rinkeby, Medella, Zinken are some of the test networks of Serenity.
