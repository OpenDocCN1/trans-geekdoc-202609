

# Go 语言

Go（或 Golang）是一种开源编程语言。它是静态类型语言，并产生编译后的机器码二进制文件。由 Robert Griesemer、Rob Pike 和 Ken Thompson 于 2007 年在 Google 设计；在语法上与 C 语言相似。创建 Go 的主要目标是结合其他编程语言的优点，在实现易用性的同时，特别为可扩展的服务器和软件系统提供先进的生产力。

# Goerli

Görli 测试网是第一个权威证明（Proof-of-Authority）跨客户端测试网，它同步了 Parity Ethereum、Geth、Nethermind、Hyperledger Besu（原 Pantheon）以及 EthereumJS。该测试网是一个基于社区的项目，完全开源。

# Gossip（垃圾邮件协议）

在技术术语中，对于区块链，Gossip 是每个参与者反复向随机选择的另一个成员传递的信息，并告诉他们关于交易的所有信息。例如，节点 A 与 B 交互，获知节点 C 和节点 D的存在并与它们建立连接。它模拟了疾病传播的方式。Gossip 存在不同的协议，如传播协议和计算聚合协议。使用 Hashgraph 共识的 Hedera 区块链就是基于 Gossip 协议。

# Governance（治理）

它指的是区块链中每个用户或参与者同意遵循的结构。它规定了区块链适应不断变化的时代需求并保持相关性的机制。核心开发者、节点持有者代币持有者负责治理，包括链下治理和链上治理。

治理也可能出现在联邦区块链部署中，联盟形成的语境下。这种治理是许可性区块链网络主参与者所遵循的框架。治理框架有助于在形成共识的组织之间提供业务规则、指导和合约条件。

# Gwei

Gwei 或 gGigawei 定义为 1,000,000,000 wei，是以太坊的最小基础单位。1 gwei 等于 0.000000001 ETH，或者 10 亿 gwei等于 1 个太坊。

# Grid

Grid 是 Hyperledger 设计用于解决供应链挑战的解决方案。有趣的是，Grid 并不是一个区块链框架或应用程序。本质上，它是一个由框架、库和技术组成的生态系统，允许开发者为构建特定的业务模型选择合适的组件。它将各种 Hyperledger 栈组件封装成一个有效的业务解决方案。Cargill、Target、Intel 和 Bitwise IO 是 Grid 的主要用户。

# Greedy（贪婪合约）

贪婪合约是指持续存在并无限锁定以太的合约。它在任何情况下都不会释放以太。这通常发生在多签钱包使用 parity 合约向所有者释放以太的情况下。如果 parity 合约被销毁（killed），钱包合约将无法访问库，并陷入贪婪的困境。

# Hal Finney（哈尔·芬尼）

Harold Thomas Finney 是 PGP 公司的开发者和首位员工，一位密码朋克（cypherpunk）和比特币开发的早期贡献者。他开发了基于 Adam Back Hashcash 协议的可重用工作证明系统（RPoW）。他被认为在比特币发布后运行了首个比特币软件，并且首笔比特币交易的受益者（在该交易中他从比特币创始人 Satoshi Nakamoto 那处收了 10 BTC，记录在区块 170 中）。即使在 2009 年因肌萎侧索硬化症瘫痪后，他继续编写代码，并使用一台追踪他眼球运动的电脑为比特币编写软件。

# Halving（减半）

减半是指挖掘新加密货币区块的奖励减少一半的事件。减半确保了加密货币的供应受到限制，从而产生了稀缺性和更高的价值。比特币减半每 4 年发生一次，或者每挖掘 21 万个区块发生一次。比特币从 2008 年开始的 50 BTC 区块奖励将每 4 年或每挖掘 21 万个区块减半一次。减半将持续进行，直到比特币减小到最小值 —— 0.00000001，或者比特币挖掘达到 2100 万的供应上限（上限），这预计将在 2140 年发生。

# Hard Fork（硬分叉）

区块链技术中的硬分叉是对网络协议的激进更改，使得之前无效的区块和交易有效，反之亦然。硬分叉要求所有节点或用户升级到协议软件的最新版本。分叉可能由对现有区块链实现功能不满的开发者或加密社区成员发起。硬分叉也被用作新技术项目或加密货币发行众筹资金的渠道。比特币黄金、比特币现金和经典以太坊由于其创世区块链网络的硬分叉而产生。

# Hard Wallet（硬件钱包）

也称为硬件钱包，是一种在安全硬件设备（如硬盘或 USB 驱动）中存储用户私钥的加密货币钱包。由于未连接互联网且不在线，它们便于冷存储。只有在需要转移资金时，它们才会连接互联网或其他设备。Ledger、Ledger Nano S、Trezor 和 KeepKey 是市场上可用的一些硬件钱包。

# Hash（哈希）

它由哈希算法创建，该算法接收大量数据集和大范围的值，并将其转换为较小范围的值。

# Hash Function（哈希函数）

哈希函数是任何可将任意大小的数据转换为固定大小值的函数。哈希函数返回的值称为哈希值（hash values）、哈希码（hash codes）、摘要（digests）或简单称为哈希（hashes）。这些值通常用于索引固定大小的对象，即哈希表（hash table）。MD5、SHA-1、SHA-2 是不同哈希函数的示例。比特币使用名为双256 的哈希函数。Hyperledger Fabric 使用 SHA-2 作为默认哈希函数。

# Hash Tables（哈希表）

用于存储键或值对。它使用哈希函数将键转换为哈希值或哈希，然后将其作为表中相应键值对的索引。它们由哈希函数和持有表中键值条目的数组（Array）组成。它们有助于存储不断增加的记录而无需被篡改或修订。它们还有助于缩小数据结构的大小并提高数据处理速度。

# Hashcash（哈希现金）

Hashcash 是一种工作证明系统，基于 SHA-1 算法，由 Adam Back 于 1997 年发明。它的基础基于这样一个概念：某些数学结果很容易验证，但发现计算这些结果的值却很困难。它用于识别重复邮件、限制垃圾邮件并减少拒绝服务攻击。基于工作证明的 Hashcash 成为比特币的基础，解决了去中心化加密货币中存在的双花费问题。

# Hashing（哈希化）

哈希是指取任何长度的输入字符串、数据或信息，输出固定长度的输出。在比特币等加密货币的背景下，交易被作为输入并通过哈希算法（比特币使用 SHA-256）产生固定长度的输出。它通常是一个单向函数，无法通过输出推断输入。然而，通过使用创建输出的源数据，可以生成相同的输出。
