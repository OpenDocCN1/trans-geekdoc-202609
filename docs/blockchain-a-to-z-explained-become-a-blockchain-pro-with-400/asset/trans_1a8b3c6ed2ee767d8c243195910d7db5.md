

# Zeppelin

Zeppelin 由 Demian Brener 和 Manuel Aaroz 于 2015 年创立，是一个通过 Open Zeppelin 为以太坊虚拟机 (EVM) 构建的新型智能合约开发框架，专注于安全性、模块化和代码可重用性。

# 零确认交易 (Zero Confirmation Transaction)

零确认交易是指已经发生但尚未被矿工确认的交易。这意味着该交易尚未在区块链上被记录和验证。当一个区块记录了该数据时，首次确认就会产生。

# ZK Snark (零知识简洁非交互式知识论证)

zk-SNARK 是一种密码学证明，允许一方在不泄露某些信息的情况下，证明其拥有这些信息。它由 Bitansky 等人引入。这种证明的实现是通过在交易发生前创建的密钥完成的。“简洁”零知识证明可以在几毫秒内完成验证，即使对于非常大的程序，其证明长度也只有几百字节。Zcash 是世界上第一个使用 ZK Snark 加密交易的加密货币。截至 2021 年，已有 82 种加密货币采用了零知识证明或其他隐私技术来加密交易。

# ZK-STARK (零知识可扩展透明知识论证)

这些是由 Eli Ben Sasson 创建的，是与 ZK-SNARK 不同的量子证明。它们在计算速度和尺寸方面更具可扩展性，并且由于它们使用抗碰撞哈希函数，因此不需要初始的信任设置。

# ZKP (密码学中的零知识证明)

零知识证明或零知识协议是一种方法，一方（证明者）可以向另一方（验证者）证明他们知道一个值 x，而除了他们知道该值 x 事实之外，不传递任何信息。零知识证明的本质在于，通过简单揭示某些信息来证明拥有该信息是非常轻易的；挑战在于如何在不泄露信息本身或任何额外信息的情况下证明这种拥有。简单来说，它有助于在数据世界中维护隐私。

零知识证明必须满足三个属性：

- 备性 (Completeness)：诚实的证明者始终能够证明真实陈述的正确性。
- 可靠性 (Soundness)：欺骗者永远无法向诚实的验证者证明虚假陈述是正确的。
- 零知识 (Zero-knowledge)：如果陈述是真实的，验证者除了获知陈述为真这一事实外，学不到任何东西。例如，一个超过 18 岁并向验证者证明这一事实的公民，能够证明其年龄的真实性，而无需揭露其实出生日期或实际年龄。

ZKP 的基础通过著名的故事——《阿里巴巴山山洞与 ZKP》（The Ali Baba Cave）以及 Jean Jacques Quisquater 在其论文《如何向你的孩子解释零知识协议》中写的 ZKP 来解释。

# 51% 攻击

51% 攻击是指对工作证明 (PoW) 区块链的攻击，攻击者或一组攻击者获得了 51% 或更多的算力或哈希率控制。攻击者利用 51% 攻击来反转区块链中已经发生的交易，这被称为“双花费”。基于以太坊的 Krypton 和 Shift 区块链曾遭受过 51% 攻击。

# $Whale

$WHALE 是 2020 年 5 月作为 ERC 20 代币推出的社交货币。它由实物和稀有的 NFT 资产支持，同时通过限量发行促进稀缺性并驱动价值增长。其最大供应量为 1000 万币。其价值主张基于：1. 金库，2. 强品牌，3. 社区，4. 代币经济学，5. 领导力和6. 存储数字艺术和收藏品的金库
