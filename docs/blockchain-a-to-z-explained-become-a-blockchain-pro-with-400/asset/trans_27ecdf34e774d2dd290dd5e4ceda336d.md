

# Cosmos

Cosmos 是一个去中心化的并行区块链网络，每条区块链都由拜占庭容错（BFT）共识算法（如 Tendermint 共识）驱动，使其生态系统中的区块链能够相互扩展并协同操作。

Cosmos 有两种类型的区块链：区域（Zones）和枢纽（Hubs）。Zones 是普通的区块链，而 Hubs 是连接各个区域的区块链。Cosmos Hub 是一个公共的权益证明（PoS）区块链，其原生资产或加密货币是 Atom。目前流通量超过 2.1 亿个 Atom。

数据挖掘跨行业标准过程模型（CRISP-DM）是指数据挖掘专家在处理跨组织、系统和平台的数据时所使用的标准。区块链是一个跨企业平台，数据记录在区块链账本中。由于这些数据被认为是数据分析的高质量输入，因此严格遵守 CRISP-DM 至关重要，这是一种包含了许多开放标准流程的开放标准流程。

# 加密无政府主义（Crypto-anarchy）

加密无政府主义（Crypto-anarchy）是一种政治意识形态，它相信通过加密软件在计算机网络上发送和接收信息时实现机密性和安全性，从而获得隐私、政治自由和经济自由。1988年，提摩西·梅编写了《加密无政府主义宣言》，其中规定了基本原则，如确保完全匿名的加密交换、言论自由和交易自由。比特币的发明受到该宣言的影响，作为区块链技术的首个商业化实现，它通过消除金融交易对监管机构和中央权威的需求，被认为是加密无政府主义的象征。随着萨尔瓦多成为第一个采用比特币作为法定货币的国家，比特币在合法和政府支持的金融交易中的作用将增加，并可能实现加密无政府主义者的目标和梦想。

# 加密学（Cryptography）

加密学（或称密码学）是通过隐藏对手和恶意黑客来确保安全通信的实践和研究。它是通过使用算法将普通/明文转换为不可理解的格式的过程，使得意方可以通过应用相应的解密方法理解相同的内容。据信，加密早在公元前400年就被斯巴达人用于信信，他们使用一种名为“斯基拉”（Scytale）的加密设备进行秘密通信。加密历史可分为三个阶段：第一阶段——第一次世界大战之前，密码仅限于少数页纸或少数手动设备。第一次世界大战后，开始使用电话和电报设备实现密码的机械化，导致了第二阶段。在此阶段，随着数据加密标准（DES）和高级加密标准（AES）的出现，经历了从电电设备到电子设备的转变。第三阶段始于世纪的最后二十年，随着数字签名和哈希算法的出现。

# 加密挖矿（Cryptojacking）

加密挖矿是一种恶意的加密货币挖掘，发生在网络犯罪入侵企业和个人计算机、笔记本电脑以及移动设备并安装恶意软件时。这些软件使用计算机的力量和资源来挖掘加密货币，或偷取毫无防备被害者的加密钱包。加密挖矿恶意软件影响了全球55%的企业，占用高达65%的CPU性能。Coinhive和MassMiner是一些危险的加密挖矿恶意软件。

# 密码朋者（Cypherpunks）

密码朋者是支持提摩西·梅提出的加密无政府主义概念的人。该小组由提摩西·梅、约翰·吉尔摩和埃里克·休斯创立。密码朋者邮件列表始于1992年，涵盖了计算机科学、密码学、政治讨论等主题。密码朋者主张广泛使用强加密和隐私增强技术作为社会和政治变革的途径。

# 守护进程（Daemon）

守护进程是在后台运行的进程，等待特定的事件或条件以激活。在区块链世界中，守护进程分发区块和交易、创建新区块、验证区块和交易，并在分叉发生时解决。

# DAG（有向无环图）

它是一种使用拓扑排序的有向图数据结构。序列只能从开始到结束。DAG通常应用于与数据处理、调度、导航寻找最佳路线以及数据压缩相关的问题。DAG技术通常与区块链放在一起，但它被认为是分布式账本技术（DLT）的另一种形式。它由连接多个其他交易的单个交易网络组成。DAG中没有区块，也没有先前验证的区块链。

# Dai (or DAI)

Dai是一种稳定加密货币，旨在通过以太坊区块链上的智能合约自动系统使其价值尽可能接近美元（USD）。2017年12月18日，Dai及其相关智能合约在以太坊主网上正式推出。它由 MakerDAO 维护和监管，MakerDAO 是一个去中心化自治组织，由其治理代币 MKR 的所有者组成。用户可以抵押其Ether贷款，并按1.5:1的比例接收新生成的 DAI（即每存入1.5 Ether获得1 DAI）。因此，DAI被认为是去中心化金融（DeFi）的良好应用。一旦偿还贷款及其利息，返回的 DAI将被自动销毁，并允许提取抵押品。

# DAML 

DAML由Yuval Rooz共同创立并领导的公司Digital Asset开发。它用于构建区块链智能合约等数字资产。该技术通过为交易双方提供一种新的、可验证的方式来更新分布式账本，同时保护数据机密性，补充了Digital Asset现有的技术。这是一种受Haskell启发的新型函数式编程语言已开发多年，随着快速变化的区块链环境的最新发展，DAML已成为构建智能合约最流行的语言。它提供了DAML Connect（完整的开发和应用栈）、DAML Drivers（允许使用分布式账本、区块链或数据库部署应用）和DAML Hub（一种能够快速应用开发的云服务）。

# DAO（去中心化自治组织）

DAO是一种被设计为自动化和去中心化的组织。它作为一种风险基金的形式运作，基于开源代码，且没有典型的管理结构或董事会。为了实现完全去中心化，DAO不隶属于任何特定的国家，尽管它使用了以太坊网络。它通过众筹获得了1.5亿美元的加密货币，于2016年4月启动，并在2016年9月停止运行。DAO代码中的一个漏洞被用户利用，将DAO的资金转移到了子公司。作为结果，以太坊社区硬分叉了以太坊区块链以恢复所有资金。原始未分叉的区块链被称为Ethereum Classic，分叉后的区块链被称为Ethereum。

# DAPS（去中心化应用）

去中心化应用（dApps）是运行在区块链或P2P网络上的数字应用程序或程序，而不是单一计算机，且不受单一机构的范围和控制。Chainlink、Brave、EOS Dynasty、Maker DAO和Chainyard是一些著名的dApps。
