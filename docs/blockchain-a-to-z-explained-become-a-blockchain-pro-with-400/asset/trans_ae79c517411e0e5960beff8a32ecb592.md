

# IPFS (星际文件系统)

星际文件系统 (IPFS) 由 Juan Benet 创建，它是一种用于在分布式文件系统中进行存储和共享数据的协议和点对点网络。IPFS 使用内容寻址在连接所有计算设备的全局命名空间中唯一标识每个文件。IPFS 允许用户不仅可以接收内容，还可以像 Bit 一样托管内容。与中心化的服务器不同，IPFS 围绕去中心化的用户操作者系统构建，这些操作者持有整体数据的一部分，创建了一个具有韧性的文件存储和共享系统。Brave（浏览器解决方案）和 Filecoin（协作存储解决方案）已使用 IPFS 协议来设计它们的服务和产品。

# Iroha

Hyperledger Iroha 设计用于将区块链或分布式账本技术（DLT）整合到移动或物联网设备中。它基于 YAC 共识机制、多签名，并支持 Windows、Linux 和 MacOS 环境。它为身份管理和金融领域基于移动的用例提供了替代设计方案。

# IOTA

IOTA 由 David Sonstebo、Dominik Schiener、Sergey Ivancheglo 和 Sergei Popov 于 2015 年创建，是一种为物联网设计的开源分布式账本和加密货币。它使用有向无环图（也称为 Tangle）在其账本上存储交易，比基于区块链的分布式账本具有更高的可扩展性。它的设计旨在促进微交易，因为它不使用矿工来验证交易。取而代之的是，允许在网络上启用新交易的节点也会批准之前的交易。MegaIOTA 单位代表在不同加密货币交易所的 IOTA 交易。

# IBM Blockchain 平台

IBM Blockchain Platform 构建在 Linux Foundation 的开源、基于社区的 Hyperledger Fabric 平台。许多公司已使用 IBM Blockchain Platform 开启它们的区块链之旅和实施。IBM 提供了 Food Trust（生产者、供应商、零售商和制造商的生态系统，为所有人创建一个安全可持续的食品系统）、Blockchain Transparent Supply（抗脆弱且透明的供应链解决方案）、TradeLens（通过克服遗留数据系统、文档人工处理和可见性差带来的挑战，转型集装箱物流）。

# IaaS (基础设施即服务)

云基础设施服务，即基础设施即服务 (IaaS)，由高度扩展和自动化的计算资源组成，也称为云计算。IaaS 提供了访问和监控计算机、网络、存储和其他服务的完全自服务。IaaS 提供商维护基础设施，用户根据“按需”和“按需付费”业务模式购买云计算服务。Amazon AWS、Digital Ocean、Microsoft Azure、Google Cloud 和 Cloud Stack 是一些著名的 IaaS 服务提供商。

# Jaxx

Jaxx 是一个用于 Bitcoin、Bitcoin Cash、Ethereum、Ethereum Classic、Litecoin、Dash、Zcash 以及长期其他区块链资产和加密货币的免费数字钱包。用户可以使用 Jaxx 进行加密货币交易、消费和接收。它支持 Changelly 和 Simplex 等第三方应用。

# Jaxx Liberty

Jaxx Liberty 不仅仅是一个加密货币钱包。它在应用中拥有加密货币持有、价格、新闻和奖励等功能，作为管理加密货币财富的一站式门户。它可以在 Android、iOS、macOS、Windows、Linux 和 Chrome 浏览器上同步。

# JSON

JavaScript 对象表示 (JSON) 是一种用于在计算机之间存储和传输数据的文本格式。它是语言无关的，与创建 JavaScript 对象的代码非常相似。JSON 使 JavaScript 对象存储为文本成为。JSON 文件用于存储区块链。

# Kafka

Kafka 由 LinkedIn 于 2011 年创建并开源，是一个社区分布式事件流平台，每天能够处理数万亿次事件。Kafka 最初构想为消息队列，基于分布式提交日志的抽象。提交日志基本上是一种只允许追加的数据结构；无法进行修改或删除。后来，Kafka 演变成了一个全功能的事件流平台。在区块链实现中，它有助于可扩展性、可靠性、持久性和高性能。它专为处理高负载交易而设计。对于较低的负载，可以使用 RabbitMQ 等消息队列。

# Keyfile (密钥文件)

区块链中的 Keyfile 是私钥的加密版本。它是使用私钥和用户用于加密它的密码生成的。如果用文本编辑器打开密钥库文件，它将显示与私钥加密相关的数据。

# Keys (密钥)

区块链中有两种密钥——公钥和私钥。公钥通常反映用于区块链交易的地址。私钥提供访问加密货币或对给定地址内资金的所有权。区块链钱包会自动生成并存储私钥。私钥建立所有权并帮助签名交易以花费资金。

# Klaytn

Kakao（韩国最大的移动平台）全球公共区块链项目 Klaytn 是一个企业级以服务为中心的平台，为用户带来友好的区块链体验。它通过高效的“混合”设计结合了公链和私链的最佳特性。Klaytn 由全球众多声誉卓高的品牌参与保护，共同创建一个可靠的业务平台以及稳健的去中心化信任系统。Klay 是其原生资产，用于燃料和保护该协议。

# Kraken

Kraken 是一家位于美国的加密货币交易所和银行，成立于 2011 年，由 Payward Inc 所有。它支持 40 种加密货币与法币的转换和交易。它向彭博终端流加密货币的价格信息。截至 2020 年，Kraken 的服务已向美国 48 个州和 176 个国家的居民开放。

# Kubernetes

Kubernetes 是一个可移植、可扩展的开源平台，用于管理容器负载以及运行 Linux 容器和服务的主机集群。它由 Google 的工程师于 2014 年设计，拥有大型且快速增长的生态系统。Kubernetes 源自希腊语，意为舵手或导航员。由于 K 和 S 之间正好有八个字母，它通常被称为 K8s。

# KYC (了解您的客户)

KYC 是金融服务中的一系列活动或指南，服务提供者努力验证客户身份、适用性以及与其建立业务关系涉及的风险。KYC 文件通常包括身份证明和地址证明文件，如护照、驾照、选民证等。KYC帮助银行、金融机构和加密货币交易所执行并完成洗钱政策。eKYC 指使用互联网或数字手段完成身份验证。

# *Kimchi premium (韩国溢价)*

Kimchi premium 是韩国与世界其他地区加密货币价格的差异。溢价通常出现在比特币价格中，并在 2018 年 1 月达到 55%。缺乏其他高回报投资渠道、对技术的深度兴趣以及在线赌博导致了韩国这种溢价产生。

# Ledger (账本)

账本是包含账户的簿，将日记中的分类和汇总信息以借贷的形式记录在其中。区块链是基于点对点 (P2P) 构建的公共电子账本，公链中可以开放共享，私有链中通过许可共享。它在不同用户之间共享，创建不可变或不可更改的交易记录，每条记录都有时间戳并与前一条记录链接。
