

# Filecoin

Filecoin 是一种基于社区的数据存储和检索解决方案，允许用户基于星际文件系统（IPFS）租用设备上的闲置存储空间。它由 Protocol Labs 及其 CEO Juan Benet 发起。用户之间及用户的支付通过 Filecoin 区块链的原生货币 FLT 完成。它使用了复制证明（PoRep）和时空证明（PoST）机制。主要使用 Go 语言编写，并集成了 Rust、Javascript 和 Python。Filecoin 在启动后的前 30 分钟内筹集了 2 亿美元。

# Flow

Flow 是一种与 NFT 收藏品和加密游戏相关的区块链。开发了 NBA（国家篮球协会）Topshots ——领先的体育 NFT 的 Dapper Labs 开发了 Flow。它诞生于 2017 年左右，当时 Cryptokitties 等 NFT 正挤满了以太坊。

# FOMO

错失恐惧（Fear-Of-Missing-Out）是一种由网络效应定义的现象。当社区许多人开始对新产品、实体或流程表现出兴趣时，这种效应就会发生，此时网络中的其他“潜在用户”开始感到有必要在太晚之前加入这一行列。历史上的许多产品由于 FOMO 在定价或需求方面获得了巨大的关注，而 FOMO 纯基于情绪而非内在价值。加密货币价格的突然上涨，或对特定加密货币的突然兴趣及其价格飙升，通常是由于 FOMO。加密货币的 FOMO 曾导致比特币出现过高达 350% 的溢价。

# Fork（分叉）

当区块链网络中的底层协议发生变化或与加密货币相关的基本方面需要更改时，就会发生分叉。分叉有两种：软叉（Soft fork）和硬叉（Hard fork）。当更改向后兼容时发生软叉，用户只需要升级软件。当更改向后兼容时发生硬叉，用户必须迁移到新链，否则将面临无法挖掘任何区块的风险。硬叉通常是因为社区对拟议的更改及其实现存在分歧。比特币现金（Bitcoin Cash）、比特币黄金（Bitcoin Gold）和以太坊经典（Ethereum Classic）都是由于硬叉而出现的加密货币示例。

# Frontier

Frontier 是一个区块链平台，其目标是将多个平台的 DeFi 服务聚合到单一的链无关 DeFi 层。它是链无关的，支持在以太坊、币安链（Binance Chain）、Band Chain、Kava 和 Harmony 上运行 DeFi，并有一种名为 FUSD 的原生货币。用例包括流动性提供、质押、资产交换、协议跟踪和资产管理。

# FUD

FUD 代表恐惧、不确定性和怀疑（Fear, Uncertainty, and Doubt）；当特定加密货币或市场由于某些个人或实体传播负面信息和虚假信息的宣传策略而面临下降趋势时，就会发生。加密货币世界中的 FUD 包括：

- 无内在价值
- 犯罪用途
- 高波动性
- 市场操纵
- 丢失托管
- 产品缺陷
- 政府禁止

# Fungible（同质化）

同质性意味着特定类型的代币或资产之间可以相互交换。比特币、以太坊、莱币、Ripple 是同质代币 —— 它们可以相互交换或与法币交换。CryptoPunk、Metariff、Art Blocks 和 Hashmasks是非 NFT。

# Game Theory（博弈论）

博弈论最初由数学家约翰·冯·诺依曼（John von Neumann）和经济学家奥斯卡·摩根斯坦（Oskar Morgenstern）开发，研究管理各种决策者之间策略交互的数学模型，并帮助在涉及已知收益或可量化结果的情况下确定最可能的结果。基本上，它是对人们为什么做以及如何做决策的研究。它已应用于比特币网络中，通过激励矿工使用其计算能力来维护网络，并刻意让恶意者的挖掘变得困难且昂贵，从而促进良好行为。它通过工作量证明（Proof of Work）促进共识来帮助决策。在以太坊提的权益证明（Proof of Stake）中，博弈论不仅用于奖励良好行为，还用于惩罚恶性行为。奖惩结合加强了协议的安全性。

# Gas

Gas 指在以太坊区块链平台上成功执行交易或运行合约所需的费用或定价价值。本质上，它衡量了在以太坊网络上运行操作所需的计算量。Gas 费用用以太坊原生货币 Ether 支付，并以 Gwei 为单位。每个 Gwei 是 Ether 的十分之一。

# Gas Limit（Gas 限制）

Gas Limit 术是指用户在以太坊上发送交易或执行合约函数时愿意支付的最大价格。平均区块的 gas 限制为 150 万。

# Gas Price（Gas 价格）

对以太坊上要支付的大约交易费用的泛指。它以 Gwei 计算，并由拍卖类型机制决定，矿工按降序寻找费用最高的交易优先处理。

# Gas Price Oracle（Gas 价格预言机）

这是一种帮助用户预测 gas 价格工具，通过查看之前的区块利用率和 gas 限制在特定时间内进行确认。它可以相应调整 gas 价格。

# Genesis Block（创世区块）

Genesis Block 是挖掘出的第一个区块链区块。创世区块形成了整个区块链交易系统的基础，是区块链中所有其他区块的原型。比特币的创世区块于 2009 年 1 月创建，奖励为 50比特币。以太坊的创世区块于 2015 年 7 月诞生。

# Geth

Geth (Go Ethereum) 是一种用 Go 语言实现的、用于运行以太坊节点的命令行界面。使用 Geth，用户可以加入以太坊网络、在账户之间传输 ether、挖掘 ether 以及与智能合约交互。它创建了运行在以太坊虚拟机上的软件。

# Ghost (GHOST)

GHOST 协议最初是一种协议修改，一种链选择规则，它利用主链外的区块来获得更安全、可扩展的系统。它采用孤区块（未进入主链的有效区块）作为叔叔区块（uncle blocks），以便这些区块的工作被包含在主链中。这防止了攻击者接管主链。它在创建新区块所需很短的区块链中更具相关性和适用性。例如：以太坊区块时间为 10 到 20 秒，而比特币为 10 分钟。因此，在以太坊中孤区块或过期区块的概率很高。Ghost 协议并没有忽略这些区块，而确定最长链时考虑它们以确保网络安全。

# Github

GitHub 是用于版本控制和协作的代码托管平台。它允许用户在任何地方共同进行项目，拥有 6000 万个由5600 万开发者访问的仓库。Github 有助于轻松的项目管理、有效的团队管理、改进代码编写、代码托管以及增强代码安全。它始于 Git，这是 Linux 创始人 Linus Torvalds 启动的一个开源项目。它是最著名的 DevOps 工具之一，用于源代码管理和跟踪源代码更改，允许多个开发者同时工作并对非线性开发做出贡献。
