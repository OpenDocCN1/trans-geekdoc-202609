# Multisig (Multi-signature)

Multi-signature (Multisig) refers to using multiple keys to authorize a blockchain transaction, rather than a single signature from one key. It avoids a single-point of failure, making it substantially more difficult for the wallet to be compromised. So, a multisig wallet can be programmed in such a way that a transaction can be authorized if atleast 2 out of 3 keys are used. Electrum, Armory and BitGo are examples of Multisig wallets.
