

# 币安 (Binance)

币安是一家加密货币交易所，提供交易各种加密货币的平台。截至2018年1月，币安在交易量方面是全球最大的加密货币交易所。币安由赵长鹏（Changpeng Zhao）创立，他曾是一个开发过高频交易软件的开发者。币安还推出了两种内部开发的加密货币——市市值超过500亿美元的币安币（BNB）和币安智能链（BSC）。BNB可用于支付币安上各种交易的手续费。

# BIP (比特币改进建议)

这是一项用于提议比特币协议更改的标准。它们包括与共识相关的关键变更，如软分叉和硬分叉协议升级；比特币软件实现，如关于种子格式备份和点对点层的修改。第一个 BIP - BIP 0001 由 Amir Taaki 在2011年提出。BIP 141（也称为隔离见证或 SegWit）导致了区块增大，以解决降低比特币交易速度的区块限制问题。

# Bit (位)

Bit 是一种用于指定比特币子单位的常用单位 - 1,000,000 bits 等于 1 个比特币 (BTC)。这种单位通常对于价格提示、商品和服务的定价更加方便。它也被称为微比特币（Micro bitcoin）。然而，比特币的最小单位是聪（Satoshi），100 个聪组成 1 个 Bit。

# BITA (交通运输区块链联盟)

交通运输区块链联盟（BiTA）是一个标准和倡导性组织，旨在帮助教育、倡导并为交通行业的区块链应用建立标准。它成立于2017年8月。BITA 拥有近500名成员，来自25多个国家的第三方物流（3PL）、第四方物流（4PL）、空运、物流、海运以及与运输行业相关的其他供应商，这些成员每年创造的收入超过1万亿美元。

# 比特币 (Bitcoin)

它是世界上第一个利用区块链、分布式账本技术引入的去中心化点对点电子现金系统。它由中本聪聪（Satoshi Nakamoto）在2008年通过一篇名为《点对点电子现金系统》的白皮书首次向世界介绍。它解决了计算机发行的货币中常见的双重计数问题，而法币（由中央银行发行的货币）则不同，中央银行作为中介通过钞票上的序列号防止双重计数。比特币的发明目的是保护中小型商家免受电子商务交易中的欺诈和退款影响，并促进低处理费的点对点微额交易。它是一个真正的去中心化网络，没有单一实体拥有或控制比特币，每个人都可以做出贡献。它是区块链的首次商业化实现。

# 比特币核心 (Bitcoin Core)

它是驱动比特币运行的软件，由加文·安德森（Gavin Andresen）使用 C++ 开发。在中本聪于2010年停止通信后，他接任了首席开发者的角色。该软件包含在包含一个安全的数字钱包，可用于存储和交易比特币。Bitcoin Core 有助于保持比特币的去中心化，并识别包含有效交易的链。

# 比特币现金 (BCH)

比特币现金是比特币的分叉。它是一个衍生币或替代币，创建于2017年8月1日，旨在适应更大的区块大小，以便允许更多交易进入单个区块。它的分叉产生是因为部分比特币开发者不同意增加原始比特币网络的容量。结果是，比特币网络变得缓慢且昂贵。BCH 分叉发生在比特币区块 478558 处。与比特币一样，BCH 的供应上限为2100万个。BCH 支持高达 32 MB 的区块，提供了更快的交易、无拥堵的网络和低的手续费。

# 比特币水龙头 (Bitcoin Faucet)

这是一个由加文·安德森运行的网站，旨在让比特币流行起来。网站访问者必须完成验证码以获得 5 个比特币。此举目的是确保比特币接触能够利用它的广泛受众。直到2012年其关闭为止，该水龙头已免费发放了 19,700 个比特币。还有其他免费的比特币水龙头，如 FreeBitcoin.in、Cointiply 和 Faucethub。

# 比特币黄金 (BTG)

BTG 是比特币在2017年10月24日在区块高度 491407 处进行的硬分叉。BTG 是一种具有比特币基本原理的加密货币，在常用的图形处理器（GPU）而非专门的 ASIC 上挖矿。ASIC 倾向于将矿权垄在少数大玩家手中，但 GPU 挖矿意味着任何人都可以挖矿，从而恢复了去中心化和独立。

Bitcoin.org 是一个社区资助的项目。最初由中本聪和 Martti Malmi 注册。2011年至2013年间，它用于发布新版本的比特币软件（现在称为 Bitcoin core）。今天，它是一个拥有全球贡献者的独立开源项目。它帮助人们理解关于比特币属性、潜在用途和局限性的准确描述。它还维护了影响比特币网络事件的透明度，并提高了其在全球范围的可访问性。

# 区块 (Block)

区块是永久记录区块链交易的文件。区块就像账本或记录簿的一页。每当完成一个区块时，它就会为下一个区块让路。区块也可以根据定义的时间间隔创建，例如比特币每10分钟创建一个区块。区块是记录的永久存储，一旦写入无法更改。

块加密在特定大小的区块中加密数据，而流加密是按位加密的。最流行的块加密是数字加密标准 (DES)、3DES 和高级加密标准 (AES)。AES 使用预定义长度为 128、192 或 256 位的密钥加密 128 位的区块。

# 区块浏览器 (Block Explorer)

区块浏览器是一种区块链搜索引擎，允许任何人搜索任何区块链交易的详情。区块浏览器是一个在线工具，用于查看区块链上发生的所有交易、当前网络算力、交易增长以及区块链地址和其他有用信息。Bitcoin Explorer 和 Etherscan 分别是比特币和以太坊的区块浏览器示例。

# 区块头 (Block Header)

区块头用于识别整个区块链上的特定区块，并通过反复哈希创建工作证明。区块链由一系列区块组成，用于存储与区块链网络发生的交易相关的信息。区块头的组成部分：
- 时间戳 (4字节)
- 版本号 (4字节)
- Merkle 根 (32字节)
- 难度目标 (4字节)
- 随机数 Nonce (4字节)
- 前区块哈希 (32字节)

# 区块高度 (Block Height)

区块高度代表特定区块链网络整个历史中确认的区块数量 - 从创世区块（区块0）到最新的区块。除了创世区块，所有区块都包含指向前一个区块的引用（哈希），区块高度是该序列中每个区块的编号。创世区块的高度为 #0，第一个挖出的区块的高度为 #1。在编写此描述时，以太坊的高度为 12,657,904。

# 区块传播 (Block Propagation)

挖矿后与网络共享区块被称为区块传播。它涉及一个信息共享过程，一个矿工将区块发送给对等节点，节点再发送给更多，直到区块到达整个网络。新区块到达网络大多数节点所需的平均时间被称为区块传播时间。
