

# Swarm

Swarm 是一个分布式存储平台和内容分发服务，构建在以太坊区块链之上，拥有原生代币 BZZ。Swarm 用户向网络上传数据，这些数据会被分成小块。激励机制确保了节点操作者在发现、存储和传播数据块时获得奖励。Swarm 计账协议（SWAP）确保节点操作者在路由消息时进行协作。ZetaSeek（用户特定搜索引擎）、Upala（dApps 的唯一身份）、Waggle（无垃圾邮件去中心化电子邮件服务）和 Swarmify（去中心化音乐流媒体）都是在 Swarm 上构建的项目。

# 同步

区块链中的同步是指与主网保持一致。当启动一个新节点时，它需要从创世区块开始开始与当前区块链同步。新节点在为网络做出贡献或验证交易之前，需要追赶并达到网络速度。取决于协议和节点类型，同步可能需要大量时间。为了加速节点与区块链的同步，正在使用镜像技术。

# 合成衍生品

这些代表通过反向工程从单一证券获得现金流的证券。它们的设计目的是为了模拟衍生品，同时改变现金流和期限等重要属性。有一个名为 Synthetix 的区块链协议，可以在以太坊区块链上发行合成资产。它们通常以名为 Synths 的 ERC 20 智能合约形式存在，可以在不拥有资产的情况下提供资产回报。Synths 可以加密货币、索引或贵金属等现实资产进行交易。

# 安全代币

它们代表资产或公司的所有权，并为代币持有者提供资产收益或公司利润份额。从本质上说，它们可交易的金融资产。它们与实用代币不同；实用代币用于比特币、莱特币和以太坊等生态系统。另一方面，证券代币提供了生态系统的所有权。涉及出售证券代币以筹资金的发行称为证券代币发行（STOs）。Sapien Equity Token、Robinhood Casino 和 Solarstake 都是 STO 的示例。

# 滑点

滑点是加密交易预期价格与实际交易价格之间的差额。这是由于交易订单进入市场到实际执行之间的价格变动造成的。防止滑点的最佳方法是使用限价单而非市场市单。限价单为订单设置了最高买入限制或最低卖出限制，在满足条件之前不会执行。

# Terra

Terra 是一个区块链平台，包含许多挂钩不同法币货币的稳定币。稳定币的抵押由 Luna 币提供。它支持 Oracle 系统和智能合约，并有大规模用户采用的计划。Luna 和 Terra 在币安、火币等交易所交易。

# 测试网

除运行网络之外的第二个区块链网络，开发者用于测试新版本的客户端软件，而不会产生真实价值风险。比特币有比特币测试网（Bitcoin Testnet），以太坊有 Ropsten、Kovan、Rinkeby，而 Hyperledger 有 Umbra。

# Kovan 测试网

Kovan 指一个支持 Parity 客户端并使用权威证明（PoA）共识的以太坊测试网。它是 Ethcore 在 Ropsten 攻击后发行的第一个 PoA 测试网。

# Rinkeby 测试网

它指一个支持 Geth 客户端并使用权威证明共识的以太坊测试网。

# Ropsten 测试网

它指一个同时支持 tGeth 和 Parity 客户端并使用权威证明共识的以太坊测试网。它与主网非常相似。更多细节请参考第 R 节的 Ropsten。

# Tether

Tether 是一种具有争议的稳定币加密货币，代币由 Tether 有限 发。它曾虚假声称每个代币都有一个美元支持，但在 2019 年 3 月 14 日将支持改为包含对关联公司的贷款。

# Theta

Theta 区块链是唯一的去中心化视频流媒体和传输端到端基础设施，提供了技术和经济解决方案。它基于多 BFT 共识、签名传播方案并支持微支付。投资者包括索尼、三星等。

# Timothy_May

Timothy C. May，广为人 Tim May，是一位美国技术/政治作家、电子工程师和英特尔高级科学家。他创造了“加密无政府主义”（Cryptoanarchy）一词，政府不仅是多余的，而且是无关的。他的加密无政府主义运动导致了 David Chaum、Wei Dai 等密码朋克人的出现，他们编写了加密货币，并为比特币和区块链等去中心化加密货币的诞生奠定了基础。

# 上月（To the Moon）

“To the Moon”是一个用于加密货币价格破表时的感叹词。同样，当一个硬币的价格正在“涨月”（mooning）时，意味着价格已经达到了顶峰。相关信息：加密交易所 Bitmex 已与太空机器人公司 Astrobotic 合作，通过月球任务将比特币送上月球。

# 代币

代币是构建在现有区块链上的资产的数字表示。它们的设计旨在实现唯一性、即时可传输性、流动性、数字稀缺性和安全性。全球超过 380 个交易所交易着超过 10,000 种不同的代币。

# TPS（每秒交易数）

区块链网络中对现有区块链数据进行更改的输入或添加被称为交易。每秒可以容纳此类交易的数量为 TPS，它决定了区块链的速度。比特币的 TPS 为 7，以太坊为 25，莱特币为 56，Cardano 为 250，ICON 为 9000。

# 交易块

交易块指的是区块链上的交易集合，可以进行哈希处理并提交到区块链。它们类似于存储和记录交易的数字文件。

# 交易费用

验证交易并将其添加到区块链的工作由矿工或验证者执行。矿工使用强大的计算机来确认交易并维护区块链网络。为了做到这一点，他们将获得每笔确认并包含在区块中的交易费用奖励。这些交易费用是他们在每个区块添加到区块链网络时获得的区块奖励之外的。通常矿工优先验证手续费较高的交易。

# 三难题

指加密项目在设计底层架构和优化时必须解决的可扩展性困境。它们涉及扩展性的方面，如速度和交易量、节点分布以及防止网络完整受到破坏。

# Troll Box

这是一个为加密货币爱好者轻松交流而创建社交应用程序。存在于 BTC-E 和 Poloniex 等交易所。Troll Box 上的用户有助于提供不受审查、相关、准确和及时的新闻，帮助成员做出更好的交易决策。

# 无须（Trustless）

互联网创建了廉价且灵活的全球基础设施，并依赖于认可的权威或中介来促进信任。需要一种既具有互联网属性又能够在无信任中介的情况下提供真实声明的全球信息系统，这种系统被称为无须。区块链实现了信任计算。

# 图灵测试

由艾兰·图灵于1950 年发明，最初被称为模仿游戏，评估机器表现出人类同等智能和行为的能力。机器将与人类和评估者进行对话，如果评估者无法区分机器和人类，则认为机器通过了测试。结果基于机器提供的答案与人类答案的相似程度，而不是必然正确答案。
