
这是一个旧的攻击，但它是DDoS历史上经典的攻击之一，因此值得提及。最著名的DoS攻击之一是MyDoom攻击。虽然这个攻击已经几年历史，但它仍然是一个极佳的研究对象，因为它是病毒用于传播DDoS攻击的典型例子。该威胁是一种经典的分布式DoS攻击。病毒/蠕虫会将自身发送到某人的通讯录中的每个人，并以此方式进一步复制，然后在预定时间，所有受感染的机器发起协同攻击，针对Santa Cruz Operations（SCO）网站 `www.sco.com`（Network World, 2004）。估计受感染的机器数量在50万到100万台之间。这次攻击取得了成功，迅速将SCO网站关闭。应当注意的是，在DoS攻击实际执行的那一天之前，网络管理员和家庭用户早已清楚知道MyDoom会做什么。此外，互联网上还提供了多种免费工具，用于清除该病毒/蠕虫。然而，似乎许多用户并未采取必要的步骤来清除他们的机器上的病毒/蠕虫。

有趣的是，MyDoom在发现多年后仍在继续造成问题。截至2009年7月，攻击者仍利用MyDoom作为后门，对韩国和美国的Web服务器发起DoS攻击。

FYI: Virus or Worm?

关于病毒和蠕虫的定义，专家们一直存在广泛争论。具体到定义的不同，有人称某些东西为病毒，有人称其为蠕虫。一个被广泛接受的一般区分是：蠕虫不需要直接的人为交互作用即可传播，而病毒需要。如果你接受这个定义，那么MyDoom和Slammer都属于蠕虫。为了避免混淆，本文在此使用 *virus/worm* 这一术语。

使这起攻击特别有趣的一点是，它明显是一次国内网络恐怖主义行为（尽管MyDoom的创建者可能持不同看法）。（网络恐怖主义将在[第12章](#ch12.xhtml#ch12)，“[网络恐怖主义与信息战](#ch12.xhtml#ch12)。”）对于不熟悉此事的读者，这里简要说明：SCO提供其UNIX操作系统的版本。与大多数其他UNIX版本一样，SCO版本受版权保护。在本次攻击发生数月之前，SCO开始指控某些Linux发行版包含SCO UNIX代码片段。SCO向许多Linux用户发送信件，要求支付许可费。Linux社区中的许多人认为这是一种阻碍Linux（开源操作系统）发展的手段。SCO更进一步，起诉了多家分发Linux的大型公司。SCO的这一主张对许多法律和技术分析人员来说显得毫无依据。此外，由于SCO与微软关系密切，微软一直在竭力遏制Linux的普及，这也使得SCO的指控显得尤其可疑。

许多分析人员认为，MyDoom病毒/蠕虫是由一名个人（或一群个人）创作的，他们认为SCO的做法是不可接受的。黑客们希望给SCO造成经济损失并损害其公众形象。这种可能的动机使得此案成为典型的国内经济恐怖主义行为：一组人因意识形态差异，攻击另一组人的技术资产。在MyDoom之前，已经有许多网站被篡改以及其他小规模攻击，这些攻击都是意识形态冲突的一部分。然而，这次病毒/蠕虫攻击是首次如此广泛且成功的。这一事件开启了信息战新趋势。随着技术成本降低、手段更易获取，未来我们可以预期此类攻击将有所增加。

#### DDoS Blackmail

2015年11月，澳大利亚公司FastMail成为DDoS攻击的受害者。首先系统遭到攻击并被取 offline。在第二次攻击后，受害者收到勒索要求。攻击者要求支付20枚比特币以终止攻击。此前，Protonmail也曾遭遇类似攻击，并被要求支付赎金以停止攻击。

#### Mirai

Mirai是一种恶意软件，它将基于Linux的机器转化为僵尸网络，用于发起DDoS攻击。该恶意软件首次出现在2016年8月。Mirai针对物联网（IoT）设备，作为DDoS攻击的基础。

### 如何防御DoS攻击

没有保证能够防止所有DoS攻击的方法，也没有绝对可靠的办法来防止黑客攻击。但你可以采取一些措施来降低风险。正如前文提到的，SYN cookies和RST cookies等方法已经被讨论。本节将介绍几种可采取的措施，使你的系统更不易受到DoS攻击。

首先，你需要考虑这些攻击是如何实施的。它们可能通过发送ICMP包（用于在Internet上发送错误消息）或由`ping`和`traceroute`工具发送来实施。如果你有一个防火墙（而且你绝对应该有一个），只需将其配置为拒绝外部网络的ICMP包，这将是保护网络免受DoS攻击的重要一步。由于DoS/DDoS攻击可以通过多种协议执行，你也可以配置防火墙拒绝所有 incoming traffic，无论其协议或端口如何。这一步骤看似激进，但确实是安全的。

在实践中

**阻止ICMP包**

阻止外部网络的ICMP包有非常少的合法理由（一些人甚至认为没有良好理由）。因此，阻止此类包通常被用作防御DoS攻击的策略之一。顺便提一下，这也会使攻击者更难扫描你的网络（如我们将在[第12章](#ch12.xhtml#ch12)看到）。

此外，可以通过使用NetStat等信息工具，检测某些DoS工具（如TFN2K）的威胁。许多这些工具可以配置为查找SYN_RECEIVED状态，这可能表明SYN洪水攻击。

如果你的网络足够大，拥有内部路由器，那么可以配置这些路由器拒绝任何不源自你的网络的流量。这样，即使攻击包通过防火墙，也不会在网络内部传播。你还应考虑在所有路由器上禁用 directed IP broadcasts。此策略可防止路由器向网络内的所有机器发送广播包，从而阻止许多DoS攻击。此外，你可以在路由器上安装过滤器，验证外部包确实拥有外部IP地址，而内部包拥有内部IP地址。

由于许多分布式DoS攻击依赖于“無辜”计算机作为发起点，保护你的电脑免受病毒和木马攻击是减少此类攻击的一种方式。这将在后续章节中详细讨论，但目前请记住以下三点：

* 始终使用病毒扫描软件并保持更新。
* 始终保持操作系统和软件补丁的更新。
* 建立组织政策，规定员工除非IT部门批准，否则不能下载任何内容到其机器上。
