
-   [黑客](#glossary.xhtml#gloss43)一词在电影和新闻中常被用来形容任何破解电脑系统的人。但在黑客社区中，黑客是指对特定系统或多个系统极其熟悉、希望进一步学习该系统的人，他们认为审视系统的弱点是了解系统的最佳方式。例如，一位精通 Linux 操作系统、致力于发现其弱点和缺陷的人就是黑客。

-   这种过程常常涉及检查缺陷是否可以被利用以获取系统访问权限。利用这一过程的“利用”部分，将黑客划分为三类：

*   [白帽黑客](#glossary.xhtml#gloss92)，在发现系统中的缺陷后，会向该系统的供应商报告。例如，白帽黑客若发现 Red Hat Linux 的某个缺陷，会（可能匿名）给 Red Hat 公司写信，详细说明缺陷及其利用方法。白帽黑客经常被公司雇佣进行渗透测试，EC Council 甚至为白帽黑客提供认证——[认证伦理黑客](#glossary.xhtml#gloss10) 考试。

*   [黑帽黑客](#glossary.xhtml#gloss10) 是媒体常描绘的形象。她在获得系统访问权限后，目标是造成某种损害，例如窃取数据、删除文件或篡改网站。黑帽黑客有时被称为 *crackers*。

*   [灰帽黑客](#glossary.xhtml#gloss42) 通常是遵守法律的公民，但在某些情况下会涉足非法活动。

-   无论黑客如何自我定位，入侵任何系统都是非法的。这意味着，技术上说，所有黑客，不管其隐喻帽子的颜色如何，都在违法。不过，许多人认为白帽黑客实际上提供了一项服务：在恶意人士利用这些漏洞之前，他们会先发现漏洞并通知供应商。

##### Script Kiddies

-   黑客是系统专家。和任何职业一样，也包含欺诈者。那么，缺乏专业能力却自称黑客的人称作 *[script kiddy](#glossary.xhtml#gloss71)*。是的，这是一个较旧的资源，但该词的含义仍然相同。该名称来源于互联网上充斥大量可下载的工具和脚本，用于执行黑客任务。许多工具拥有易用的图形用户界面，让几乎没有任何技能的人也能操作。典型例子是用于发起拒绝服务攻击的 **Low Orbit Ion Cannon** 工具。下载此类工具但不真正理解目标系统的人被视为 script kiddy。你很可能遇到的自称黑客的人，实际上大多只是 script kiddy。

##### Ethical Hacking: Penetration Testers

-   什么时候以及为何要授权他人对自己的系统进行黑客攻击？最常见的答案是为了评估系统漏洞。过去这类人被称为 *[sneaker](#glossary.xhtml#gloss74)*，但如今更广泛使用的称呼是 *penetration tester*。无论称呼如何，该人士在法律允许的范围内非法进入系统，以评估安全弱点，正如 1992 年电影 *Sneakers*（主演 Robert Redford、Dan Aykroyd、Sidney Poitier）中所描绘。越来越多的公司正在寻求此类个人或公司的服务来评估其漏洞。

-   任何被聘请评估系统漏洞的人都应技术娴熟且道德规范。进行刑事背景调查，避免有问题的背景者。市面上有大量合法的安全专业人员，他们了解黑客技巧却从未犯下安全犯罪。若把“雇佣已定罪黑客即意味着雇佣有才华的人”这一论点推至逻辑结论，则可以推断这些人实际上并不如他们自以为的那么擅长黑客技术，因为他们已经被捕。

-   给予有犯罪记录的人系统访问权限，等同于雇佣多次酒驾（DWI）前科者做司机——在两种情况下，你都在招致麻烦，并可能承担重大的民事责任。

-   对其资质进行审查也很有必要。正如有些人声称极其擅长黑客却并非如此，也有那些声称是熟练渗透测试人员却缺乏真正所需技能的人。你不想不小心雇佣一个 script kiddy，误以为她是渗透测试专家。这类人可能会错误地宣称你的系统安全，实际上只是因为其技能不足未能成功突破防护。稍后在本书第 [第 11 章](#ch11.xhtml#ch11) “[网络扫描与漏洞扫描](#ch11.xhtml#ch11)” 中会讨论评估目标系统的基本方法。第 [11 章](#ch11.xhtml#ch11) 也会讨论在雇佣顾问时应关注的资质。
