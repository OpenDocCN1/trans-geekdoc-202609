# 第6.4.11节—处置过程

本文定义了从制定需求开始，开发或获取任何系统的过程。该过程常在入门系统工程课程中教授，但可能对许多网络安全从业者来说很陌生。理解系统生命周期对于开发任何系统（包括网络安全系统）至关重要。

任何网络安全系统都必须从要求工程过程开始。要求工程的一个显著特征是要求获取。这是一种工程师从利益相关者处获取需求的过程。核心思想是利益相关者可能不清楚能做什么或应该做什么。工程师的专业知识用于获取一套需求。这在网络安全领域尤为适用。利益相关者很可能不熟悉网络安全，若没有工程师的帮助，很难得出完整的需求列表。

系统工程中的另一个有价值的工具是用例图。它最初是UML的一部分，现已被纳入SysML。用例图展示了包括其他系统在内的各类用户以及它们与所关注系统的交互方式。后续章节“[SecML](#ch15.xhtml#ch15lev1sec3)”将详细阐述用例的具体内容。不过，仅仅建模用户如何与系统交互这一概念本身就能在定义系统功能时发挥重要作用，也是在要求获取过程中与利益相关者沟通的有效工具。

统一建模语言（UML）是用于建模软件的一组图表。这些图表包括展示软件使用方式的用例图。UML还包括描述软件部署方式的部署图。总计有14种不同的UML图。SysML（系统建模语言）类似于UML，但适用于任何系统，共有9种SysML图。

本节讨论的工具仅是系统工程所使用的一部分技术，这些技术可以有效应用于一般网络安全和渗透测试领域。对于任何渗透测试人员来说，参加系统工程课程可能很有价值。教育机构可考虑在现有网络安全课程中加入系统工程课程。至少，网络安全工程师应当至少熟悉INCOSE手册。

本节所展示的工具仅是系统工程中常用工具的样本。工具固然重要，但系统工程的概念更为关键。例如，系统建模与仿真在系统工程中普遍，但在网络安全领域并不常见。将网络安全工程定义为系统工程的一个子学科，要求必须包含建模与仿真。

建模与仿真为在多种场景下测试系统提供了有效的手段。例如，若开发用于防御拒绝服务（DoS）攻击的系统，则模拟DoS攻击有助于判断系统的响应方式。MATLAB已被广泛用于建模网络流量，因此使用MATLAB来建模基于网络流量的攻击是合理的。然而，这种建模在网络安全领域并不常见，这正是将建模与仿真应用于网络安全工程的一个例子。

MATLAB是系统工程以及其他工程学科中常用的工具，已被应用于包括航天工程和生物工程在内的多个工程领域。网络安全工程也应当纳入其使用范围。该建模方法的多功能性使其成为众多不同工程学科中的有效工具。

可靠性分析是系统工程的另一重要组成部分，同样适用于网络安全工程。可靠性工程与分析是确定给定系统可靠性的过程。在网络安全领域，系统往往在未明确其可靠性的前提下被实施。可靠性工程包含多种技术和用于计算可靠性的公式。

工程学所有领域的一个共同特征是可量化的数据。必须拥有客观指标，以便作出明智的决策。可靠性工程提供了若干公式，可帮助获取这些指标，而且许多公式无需高深的数学知识即可使用。

调节可控输入的设置可改变均方差（MSD）。这是可靠性工程中相对简单的公式，可用于评估任何网络安全系统的可靠性。它对于评估入侵检测系统（IDS）和防病毒软件的效能特别有用。将MSD公式与建模与仿真结合，可在系统投入运行前精确调优网络安全系统。

MSD公式自然引出MPE公式。平均百分比误差（MPE）是模型错误的平均值，即模型预测值与实际值之间的平均误差。模型的有效性评估依赖于此指标。[Figure 15.4](#ch15.xhtml#ch15fig04) 展示了MPE公式。
