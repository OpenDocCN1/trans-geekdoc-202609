
-   [所有步骤](https://www.example.org)在保持链条保全和确保调查完整性方面都至关重要。

## EU Evidence Gathering

[www.swgde.org](http://www.swgde.org)的科学数字证据工作组（Scientific Working Group on Digital Evidence，SWGDE）为数字取证制定了多项标准。根据SWGDE《计算机取证操作程序模型标准》，取证过程包括四个步骤：

1.  **视觉检查**：此检查的目的是验证证据类型、状况及相关信息，以便进行后续取证。通常在初步证据扣押时完成。例如，当电脑被扣押时，需要记录设备是否运行、其状态如何以及整体环境如何。

2.  **取证复制**：这是在取证前对存储介质进行复制的过程。始终建议使用取证副本进行操作，而不是原始介质。

3.  **介质检查**：这是实际的取证测试阶段。所谓“介质”，指硬盘、内存条、SIM卡等可存储数字数据的项目。

4.  **证据归还**：证据将返回至适当位置，通常是受锁或受保护的设施。

上述步骤是网络取证应遵循的概述。SWGDE 网站上有大量有用文档，供深入了解正确开展数字取证的细节。

## Locard’s Principle of Transference

Dr. Edmond Locard 是一位法医科学家，他提出了如今所知的 Locard 交叉转移原则（Locard’s principle of transference）。该原则最初应用于物理取证，其核心内容是：在任何环境中进行互动时，你必然会留下痕迹。例如，闯入他人住宅的人必然会留下指纹、头发、脚印等痕迹。尽管细心的犯罪分子会通过使用手套等方式遮掩部分痕迹（如避免留下指纹），但必然会留下其他痕迹。

该原则同样适用于计算机证据，也是我们偏好使用副本进行取证的原因之一。以 Windows 系统为例，每次登录、打开文件或进行任何操作时，都会修改注册表设置、留下临时文件以及其他痕迹。在取证过程中，这些痕迹至关重要，但也意味着取证人员必须小心避免在现场留下自身的痕迹。

## Tools

此前我们已讨论过使用 Linux 命令或 FTK Disk Imager 对磁盘进行成像的方法。目前可用于开展取证分析和检查的工具种类繁多。本节将简要介绍几种广泛使用的工具，虽有其他工具存在，但以下列出的工具使用广泛。

### FTK

我们此前提到过 FTK，此处也给出简要描述。FTK（Forensic Toolkit）由 AccessData 公司开发，是一款功能强大的电脑取证工具，可用于恢复已删除文件、检查注册表设置，并执行多种取证任务。该软件价格可能对部分机构构成负担，但因其在执法部门中的高人气而广受欢迎。

AccessData 还增加了诸多功能，如“已知文件过滤”功能，用于查找特定类型的文件。FTK 还能搜索并检测涉及儿童色情制品的文件。此外，AccessData 还提供手机取证工具。更多信息请访问 [http://accessdata.com](http://accessdata.com)。

### EnCase

该工具由 Guidance Software 开发，深受执法部门欢迎，是 FTK 的直接竞争对手。它支持磁盘成像、恢复已删除文件、检查注册表，以及执行其他常见取证任务。对于部分组织而言，其价格可能过高。更多信息请访问 [https://www2.guidancesoftware.com/products/Pages/encase-forensic/overview.aspx](https://www2.guidancesoftware.com/products/Pages/encase-forensic/overview.aspx)。

### OSForensics

这是一款较新的工具，但在取证社区中获得了良好评价。它价格亲民且使用简便，功能完备，可用于恢复已删除文件、检查注册表、以及搜索磁盘。更多信息及可下载完整功能试用版请访问 [www.osforensics.com](http://www.osforensics.com)。

### Sleuth Kit

这是一套开源工具组合。整个工具组合功能强大但使用相对复杂，每个工具可能需要学习一系列命令行（或 Shell）指令才能执行。更多信息请访问 [www.sleuthkit.org](http://www.sleuthkit.org)。

### Oxygen

该工具专为手机取证设计，能够非常出色地分析 iPhone，对现代 Android 设备也有相当不错的分析效果。目前它对较旧的 Android 机型或 Windows Phone 的分析效果不佳。更多信息请访问 [www.oxygen-forensic.com](http://www.oxygen-forensic.com)。

### Cellebrite

这可能是目前最受执法部门欢迎的手机取证工具之一，对多种手机型号均表现出色。其唯一缺点是价格昂贵，是目前市场上最昂贵的手机取证工具之一。更多信息请访问 [www.cellebrite.com](http://www.cellebrite.com)。

## Finding Evidence on the PC

在证据被安全保管并制作出取证副本后，便可开始查找证据。证据形式多样，前文提到的工具均可用于提取这些证据。但本节将展示这些工具实际搜索的内容，强调不要机械复述工具输出结果，而应理解工具的工作原理。

### Finding Evidence in the Browser

浏览器可作为直接证据、间接证据或辅助证据的来源。在涉及儿童色情制品的案件中，浏览器可能直接包含相关证据；在网络跟踪案件中，也可能发现直接证据。但若怀疑某人制造并传播网络病毒，则可能仅能发现间接证据，如其搜索与病毒制作/编程相关的主题。
