
# 第10章. 安全策略

## 章节目标

阅读本章并完成练习后，您将能够：

* 认识到安全策略的重要性。
* 理解各种策略及其背后的原因。
* 了解构成良好策略的要素。
* 为网络管理创建策略。
* 评估并改进现有策略。

## 引言

迄今为止，我们在本书中探讨了网络面临的各种威胁。在[第9章](#ch09.xhtml#ch09)，“[计算机安全技术](#ch09.xhtml#ch09)”中，我们考察了针对这类攻击的各种技术防御措施。然而，事实是技术本身无法解决所有网络安全问题。存在一些技术无法阻止的问题。例如：

* 防病毒软件无法阻止用户手动打开附件并释放病毒。
* 即使网络在技术上受到保护，如果前员工（可能对公司不满）仍持有有效密码，或密码被随意贴在显示器上，网络仍然极易受到攻击。
* 如果服务器所在的房间几乎所有公司员工都能进入，那么该服务器就不安全。
* 如果终端用户易受社会工程攻击，网络也不安全。

另一个技术单独不足以解决问题的原因是：技术必须被恰当地应用。策略用于指导您如何实施和管理安全，包括安全技术。本章将探讨计算机安全策略，包括创建良好安全策略的要素以及建立网络安全策略的示例。

## 什么是策略？

安全策略是一份文档，定义了组织如何处理安全的某些方面。可以有关于终端用户行为、应对事件的IT响应，或特定问题和事件的策略。

安全策略也可以用于处理合规性要求。这类策略指示组织成员如何遵守特定法规。一个良好的例子是，向医疗工作者说明在使用电子病历软件时如何遵守HIPAA法规。

策略也可以仅仅是建议性的，建议员工如何处理某些事项，但不强制要求遵守。例如，策略可能建议用户在使用智能手机通过Wi‑Fi热点发送邮件时可能不安全，但不禁止这样做。

### ISO 17999

ISO 17799是一项关于如何制定策略的标准。虽然策略通常不被视为令人兴奋的安全话题，但它们是您安全态势的核心。因此，正确制定策略至关重要。

ISO/IEC 17799:2005 在以下信息安全管理领域描述了控制目标和控制的最佳实践：

* 安全策略
* 信息安全组织
* 资产管理
* 人力资源安全
* 物理和环境安全
* 通信和运营管理
* 访问控制
* 信息系统获取、开发和维护
* 信息安全事件管理
* 业务连续性管理
* 合规性

熟悉该标准并至少考虑其建议是一个好主意。
