#### 手机攻击

有许多方式可以攻击手机；此处简要描述了较为常见的攻击手段。

*   **Bluesnarfing:** `未经授权访问蓝牙设备上的信息`。

*   **Blue jacking:** 利用在范围内的另一台蓝牙设备（取决于蓝牙版本，可能是 10 到 240 米）发送未经请求的消息给目标。

*   **Bluebugging:** 与 bluesnarfing 类似，`bluebugging 访问并使用手机的所有功能`。

*   **Pod slurping:** 使用诸如 iPod 之类的设备，直接插入存放数据的计算机，非法获取保密数据。

#### 密码破解

当可以实际获得机器的物理访问时，密码破解最为容易。这并不像听起来那么困难。许多组织（如大学）设有供客户端或访客使用的终端机，权限极低。熟练的黑客可以利用这种访问权限进一步提升权限。

##### OphCrack

`OphCrack` 是一款非常流行的 Windows 密码破解工具，可在 [`http://ophcrack.sourceforge.net`](http://ophcrack.sourceforge.net) 下载。它基于对 Windows 密码工作原理的理解。Windows 密码存储在系统目录的 SAM 文件中，通常位于 `C:\WINDOWS\system32\config\`，SAM 代表安全帐户管理器。密码以哈希形式保存。（哈希将在 [`第 8 章`](#ch08.xhtml#ch08) “[加密](#ch08.xhtml#ch08)” 中详细讨论。）Windows 会对你输入的密码进行哈希运算，并与 SAM 文件中的哈希进行比对；若匹配则登录成功。为防止他人复制 SAM 文件并离线进行暴力破解，Windows 在系统启动时会锁定 SAM 文件。`OphCrack` 的做法是启动 Linux 系统，然后获取 SAM 文件并在其拥有的大型哈希表中查找匹配的哈希值；若找到匹配，则对应的明文即为密码。可以在 [`Figure 6.8`](#ch06.xhtml#ch06fig08) 中看到 `OphCrack` 的运行情况。

![Figure 6.8 OphCrack. ¶  ¶ Ophcrack 截图显示窗口顶部的选项有 load、delete、save、tables、crack、help、exit，其中 “Save” 被选中。下方还有三个选项：Progress（已选中）、statistics、Preferences。窗口下半部分显示表格、目录、状态和进度。 ¶ ](Images/06fig08.jpg)

**Figure 6.8** `OphCrack`。 ¶ 

该工具使用极其简单。只需将 `OphCrack` CD 插入机器并重启即可。启动过程中可按 F12 打开引导菜单，选择从 CD 启动，随后 `OphCrack` 便开始工作。需要注意的是，截至本文撰写时，密码长度超过 10 个字符的情况通常无法被 `OphCrack` 破解。

假设 `OphCrack` 成功（并非总是如此），攻击者可以做什么？最理想的情况是仅获得本地管理员账户，而非域账户。这可以用于进一步获取域访问权限。一种简单的做法是编写脚本，自动创建域管理员账户。脚本内容如下：

[Click here to view code image](Images/ch06_images.xhtml#p168pro01)

```
net user /domain /add localaccountname password
net group /domain "Domain Admins" /add localaccount
```

显而易见，如果攻击者直接执行上述脚本，它不会生效——必须拥有域管理员权限。因此攻击者将该脚本保存到 **All Users** 开机文件夹。下一次域管理员登录该系统时，脚本会自动执行。但攻击者可能不想等待这么久，于是会在系统中制造一些轻微问题（修改设置、更改配置等）。在许多组织中，技术支持人员属于域管理员组。当技术支持人员登录系统以修复问题时，脚本便会成功运行。

多年来，制作病毒需要相当的编程技能。但近年来出现了大量工具，让用户只需点击几下即可生成病毒。这也是病毒日益普遍的原因之一。其中一种工具是 `TeraBIT Virus Maker`，如 [`Figure 6.9`](#ch06.xhtml#ch06fig09) 所示。

#### Windows  hacking 技术

鉴于微软 Windows 的普遍性，专门针对该操作系统的攻击层出不穷。本节将简要概述一些常见的 Windows hacking 手法。

##### Pass the Hash

我们将在 [`第 8 章`](#ch08.xhtml#ch08) 中对密码散列进行详细讨论。现阶段只需了解，许多系统将密码以散列形式存储，因为“反向散列”（即直接还原密码）是不可能实现的。

Pass the Hash 攻击的核心是利用散列无法逆转的特性：攻击者不必尝试猜出真实密码，而是直接发送已获得的密码散列值。只要攻击者能够获得合法的用户名和对应的密码散列（即仅有散列，不知道实际密码），他就可以直接使用该散列进行认证，而无需知晓密码本身。
