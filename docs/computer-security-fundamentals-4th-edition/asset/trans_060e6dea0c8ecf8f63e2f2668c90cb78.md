
### Summary

显然，欺诈和身份盗窃是非常真实且日益严重的问题。在信息瞬时获取和在线购物的现代社会，采取保护自己的措施至关重要。你必须遵循本章中列出的步骤来保护隐私。同时，执法人员也必须获得调查和解决此类网络犯罪所需的技能。

网络跟踪是一个经常对公民和执法人员都是新的领域。两个群体都必须清楚了解什么是网络跟踪，什么不是，因为不幸的是，网络跟踪案件可能升级为现实暴力。
