
# 10.1 User Policies

## 1. Introduction
User policies define acceptable and unacceptable use for all personnel, with separate policies required for administration, faculty, and students.

## 2. Acceptable Use
- Users must comply with all applicable laws and regulations.
- Access to authorized resources is permitted for legitimate business or educational purposes.
- Passwords must be strong, unique, and kept confidential.
- Users must report security incidents promptly.

## 3. Unacceptable Use
- **Malware**: Downloading, distributing, or executing infected files is prohibited.
- **Unauthorized Access**: Sharing passwords or accessing systems without permission is forbidden.
- **Data Misuse**: Storing, transmitting, or accessing confidential or sensitive data without authorization is not allowed.
- **Software Installation**: Users must not install software without IT approval.
- **Email Attachments**: Flash animations and other potentially harmful file types are prohibited as email attachments.
- **Instant Messaging**: Sending confidential information or harassing messages via instant messaging is prohibited.
- **Password Policies**: Passwords must be at least eight characters long and not shared with any employee.

## 4. Policy Enforcement
- All policies must state clear consequences for violations.
- Policies must be properly filed and maintained.
- Regular reviews by an attorney are recommended for legal compliance.

## 5. Policy Review and Maintenance
- Policies should be reviewed regularly to ensure relevance and compliance.
- Updates must be communicated to all personnel.

## 6. Conclusion
Adherence to these policies is essential for maintaining security and integrity across the campus network.
