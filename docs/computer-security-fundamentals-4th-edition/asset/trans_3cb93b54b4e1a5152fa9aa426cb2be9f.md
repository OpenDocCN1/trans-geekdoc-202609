
如果您的州有在线驾驶记录，那么每年至少检查一次。如果您发现一些您并未犯下的驾驶违规行为，这表明您的身份可能被他人冒用。在[第13章](#ch13.xhtml#ch13)的“[网络侦探](#ch13.xhtml#ch13)”中，我们将详细探讨如何在线获取这些记录，通常费用低于5美元。

总结来说，防止身份盗用的第一步是限制您公开的个人信息数量。下一步是监控您的信用和驾驶记录，以便及时发现有人试图冒用您的身份。

保护您的身份还包括保护您的隐私。这意味着防止他人获取您未明确提供给他们的信息。该预防措施包括阻止网站在您不知情的情况下收集关于您的信息。许多网站会在小文件（即`cookies`）中存储关于您及您访问其站点的信息。这些cookie文件存储在您的机器上。cookie的问题在于，任何网站都可以读取您机器上的任何cookie——即使是您当前访问的网站没有创建的cookie。例如，如果您访问一个网站并它存储您的姓名、访问的站点以及您在该站点的停留时间，那么另一个网站可能读取该cookie并知道您在互联网上的活动去向。阻止不想要的cookie的最佳方法之一是安装反间谍软件。我们将在后续章节中详细讨论此类软件。目前，让我们看看如何修改您的Internet设置以帮助降低隐私威胁。

### 防范拍卖欺诈

处理拍卖欺诈需要一套独特的预防措施；以下是四个良好建议：

* 仅使用信誉卓著的拍卖网站。最知名的网站是eBay，但任何知名且信誉良好的网站都比不知名或晦涩的网站更安全。此类拍卖网站通常会采取措施防止欺诈和滥用。

* 如果听起来太好以致不真实，则不要出价。

* 部分网站允许您查看其他买家对特定卖家的反馈。阅读反馈，仅与信誉良好的卖家交易。

* 可能时，使用一张限额较低的独立信用卡进行在线拍卖。这样，如果信用卡被盗，您的责任将受到限制。使用借记卡则只会招致麻烦。

使用在线拍卖可以是以低价获得有价值商品的很好方式。然而，在使用这些服务时必须保持一定的谨慎。

### 防范在线骚扰

以下是保护自己免受在线骚扰的指南：

* 如果您使用聊天室、讨论板等，请不要使用真实姓名。通过Yahoo!、Gmail或Hotmail等匿名服务设置一个独立的电子邮件账户，然后使用该账户和假名在线。这将使在线追踪者很难将您与真实身份联系起来。

* 如果您成为在线骚扰的受害者，请保留所有电子邮件的数字和打印版本。利用本书后文将探讨的调查技术尝试识别 perpetrator（ perpetrator）。如果成功，您可以将电子邮件及 perpetrator的信息提供给执法机构。

* 无论如何，不要忽视网络跟踪。根据Working to Halt Online Abuse网站的数据，19%的网络跟踪案件会升级为现实世界的跟踪。

本章或本书的意图并非让您因使用Internet而感到害怕。我常用Internet进行娱乐、商业和信息获取。只需在使用Internet时保持一定的谨慎即可。
