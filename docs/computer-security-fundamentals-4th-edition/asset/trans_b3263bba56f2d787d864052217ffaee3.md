
网络安全是一个复杂且不断发展的领域。实践者必须紧跟新出现的威胁和解决方案，并主动评估风险并保护他们的网络。理解网络安全的第一步是了解网络面临的实际威胁。如果没有对系统可能受到的威胁的真实认识，您将无法有效保护它们。同时，您也必须获得安全专业人士和试图破坏您安全的对手所使用的术语的基本理解。
