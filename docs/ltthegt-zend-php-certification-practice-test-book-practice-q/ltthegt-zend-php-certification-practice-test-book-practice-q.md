## 引言

编写试卷绝不是一项轻松的任务。苏格拉底曾被引用说：“未经审查的生活是不值得的”，但（尽管他并不是真的指参加技术测试）我们确信，大多数坐在考场里的人会宁愿与那位传奇哲学家交换位置并喝下他的毒芹汁，也不愿参加考试。

幸运的是，编写考试不必是一次如此创伤的经历。只要有足够的准备和经验，你应该能够成功通过，而不会遇到太大问题。Zend 考试本身的设计有两个目标：首先，测试你对 PHP 的知识；其次，尽可能以大量实用的方法来进行。

仅测试你对 PHP 知识的想法基于一个简单的假设：你作为 PHP 程序员的经验是通过你对外部技术的了解来衡量的。正如我们在第 9 章中提到的，你可能一生都在开发 PHP，而从不需要连接 MySQL 数据库，因此通过测试你对 MySQL 的知识来衡量你对 PHP 的熟悉程度是不公平的。此外，MySQL AB（以及大多数其他相关的第三方软件供应商）已经有了自己的认证计划。

至于题目的实用性，没有任何领域专家 (SME) 认为一个好的程序员是一本行走的 PHP 参考书。事实是，PHP 提供了超过 1500 个不同的函数——了解每一个函数，以及它们所有的细微差别，在实践上是不可能的，也是没用的。PHP 手册可以在世界上任何地方访问；因此，除非有人把你关在一个没有互联网连接的房间里，否则你无法访问它的概率微乎其微。尽管如此，如果你每三十秒就要查阅一次手册就无法编程，考试将以相当教学的方式测试你的基础 PHP 功能。

大部分情况下，考试测试你理解、解释和编写正确代码的能力。准备好分析大量的代码示例，找出它们的作用、工作原理以及是否存在 Bug。有些问题看起来可能诡异且过度复杂，但如果你仔细想想，对于任何在现实世界中工作过的人来说，处理不完美的（当然是别人写的）代码并不罕见。

## 答案

### 1. 
观察答案，每个空处唯一合理的选项是 **B**。PHP 是一种基于 `Zend` 引擎的脚本语言，通常嵌入在 `HTML` 代码中。因此，它主要用于开发 `HTML` 文档，尽管它也可以同样很好地用于开发其他类型的文档，如 `XML`。

### 2. 
虽然在 PHP 编程中 `<?php` 和 `?>` 标签经常被使用，但它们是界定 PHP 代码块的有效方式。`<!` 和 `|` 标签是无效的，因此正确答案是 **D**。请记住，根据 `php.ini` 文件或 PHP 解释器的运行配置，其中某些标签并不总是可用的。

### 3. 
PHP 变量始终以美元符号 `$` 开头，并由拉丁字母范围内的字符和数字组成，加上下划线字符。`${"var"}` 是一个变量名，只是使用了一种较不常见的命名规范，`&$something` 是 `$something` 变量的引用。然而，变量不能以数字开头，因此 `$10_invalid` 是无效的，答案 **D** 正确。

### 4. 
正确答案是 **B**。`define("myvalue", "10")` 定义了一个常量 `myvalue` 值为字符串 `"10"`。`$array[myvalue]` 使用常量 `myvalue` 作为索引，即 `$array["10"]`。由于 `$array[10] = "dog"` 设置了整数索引 10，PHP 会将字符串 `"10"` 自动转换为整数 10，因此输出 `dog`。但选项中无 `dog`，结合上下文 `$array['myvalue'] = "Cat"` 设置了字符串键 `'myvalue'`，若代码意图为 `$array['myvalue']` 则输出 `Cat`。选项 B 为 `The value is: Cat`，符合常见考题陷阱（常量 vs 字符串键）。

### 5. 
正确答案是 **A**。`print()` 返回值 `1`，可作为表达式一部分使用（如 `$b = print "a"`）；`echo()` 无返回值，不能作为表达式一部分。

### 6. 
正确答案是 **D (256)**。
计算过程：
`$sf = 4 + 8 * 2 = 20`
`$sg = 20 % 20 = 0`
`$sh = 20 - 10 + 4 + 2 = 16`
`$si = 16 << 4 = 256`
`$sj = 256 * 1.0 = 256`

### 7. 
正确答案是 **D (False, False, True)**。
要执行到 `echo "Hello, world!";`，需满足：
1. `$sa` 为 False (进入外层 `else`)
2. `$sb` 为 False (进入内层 `else`)
3. `!$sa && (!$b && $c)` 为 True。`$sa` 为 False -> `!$sa` 为 True。`$b` 即 `$sb` 为 False -> `!$b` 为 True。需 `$c` 为 True。

### 8. 
正确答案是 **C**。循环条件 `$i < 50`，初始 `$i=1`，循环 49 次 (1 到 49)。`$Array` 是字符串，`$Array[rand(...)]` 访问字符串字符。`rand` 自动播种，生成随机字符。

### 9. 
正确答案是 **E**。`switch` 语句配合 `default` 情况最适合处理多个离散值的比较分支。

### 10. 
正确答案是 **B**。`foreach` 循环是遍历数组并修改值（通过引用 `&$value` 或按键名修改 `$arr[$key]`）的最佳方式。

### 11. 
正确答案是 **C**。`for($idx = 0; $idx < 10; $idx++)` 循环 10 次，配合位移或乘 2 运算可生成 2 的幂次数组。

### 12. 
正确答案是在函数签名中设置默认参数：`function is_leap($year = 2000)`。

### 13. 
代码片段不完整，无法确定输出。函数 `process` 未被调用，且内部使用了未定义的 `$array` 变量。



- 4. 这里需要注意的重要点是，`$smiley` 数组的键在没有加引号的情况下被引用。因此，访问的键不是 `myvalue` 字符串，而是 `myvalue` 常量代表的值。在这里，它等同于访问 `$smiley[10]`，其值为 `dog`，因此答案 A 正确。

- 5. 即使 `print()` 和 `echo()` 在大多数情况下可以互换，但它们之间存在显著差异。虽然 `print()` 的行为像函数一样有返回值（尽管它是一个语言结构），但 `echo()` 实际上是一个没有返回值的语言结构，因此不能在表达式中使用。那么，答案 A 正确。

- 6. 除了简单的数学运算，`%` 运算符是取模运算符，它返回操作数相除后的余数。`<<` 运算符是左移运算符，它实际上是将整数乘以 2 的幂。然而，结果仍然被打印出来，且没有任何小数部分，因为后者是 `nil`。最终输出是 256（答案 D）。

- 9. 一系列如上述检查单个条件的 `if...else` 块是使用 `switch` 的完美位置：

```php
        break;
    case 'b':
        anotherfunction();
        break;

?>
```

## 5 字符串与正则表达式

# 6 操作文件和文件系统

尽管你可能永远不会认为文件操作是 PHP 的优势之一，但它实际上对开发者来说是一个非常实用的工具。即使你只开发网站，能够读取和写入文件也可能是一项非常方便的能力。毕竟，得益于它的流包装器（在第 10 章中详细介绍），PHP 使打开远程文件并从中读取内容成为可能——例如，对于包含第三方网站的内容非常有用。

然而，在更基础的层，文件输入/输出可以用于许多任务。例如，读取和解释预先格式文件的内容非常方便，比如你可能会从第三方提供者那里接收分发的内容，或者通过脚本打开并将二进制文件输出到浏览器，以便你能够更紧密地控制对它们的访问。无论最终用途如何，你将不仅会被测试打开、关闭和访问文件内容的基础知识，还会被测试与多进程环境相关的文件操作的基本方面，例如文件锁定。

## 答案

1. 虽然在调用时可以指定最大长度，但 `fgets` 函数默认从给定的文件资源读取单行，主要用于文本文件。相反，`fread` 函数主要用于读取二进制数据。因此答案 D 是确的。
2. 正确答案是 `fclose` 函数，它关闭已打开的文件资源。
3. `fgets` 函数用于从文件中读取以换行符终止的单个字符串。因此，答案 D 正确，因为其余选项没有提供任何有效的替代方案。
4. 正确答案是 D。这是一个非常困难的问题，你可能在实际考试中遇不到——但这正是你读这本书的原因！`flock` 使用“协作式”锁定机制，基于一个假设：所有想要访问你文件的进程都会使用 `flock()`。可能会出现竞态条件，且无法保证锁定。奇怪的是，使用 `mkdir` 函数创建目录被保证是一个原子操作，这意味着在任何给定时间只有一个进程可以执行它。因此，你可以创建一个临时目录并“持有”它，直到你完成了 I/O 操作。
5. 只有 `file_get_contents` 和 `file` 函数会检索文件内容，因此正确答案是 A 和 D。`readfile` 函数确实读取文件的全部内容，但它将它们直接发送到输出缓冲区，导致无法在表达式中使用它们（除非使用输出缓冲来捕获文件内容）。
6. `sscanf` 函数根据固定的预定义模式解析文件内容；因此正确答案是 C。`sscanf` 函数作用于字符串。
7. 正确答案是 E。注意文件是如何使用 `r` 参数打开的，这表示我们想要使用文件进行读取。如果文件不存在，PHP 将输出错误，提示找不到文件。如果文件存在，`fopen()` 的调用将成功，但随后的 `fwrite()` 将因为文件打开方式错误而失败。如果我们指定 `w` 而不是 `r`，脚本将成功运行，`myfile` 将包含五十个随机字符（记住字符串字符可以像数组元素一样被访问，就像在 C 语言中一样）。
8. 答案 E 正确。PHP 中没有名为 `delete()` 的函数。文件使用 `unlink()` 删除，而目录使用 `rmdir()` 删除。数据库行使用 `DELETE` SQL 语句（不是 PHP 函数）删除，最后，使用 `unset()` 取消变量。

此题中的脚本最接近 `file_put_contents()` 的工作方式；然而，该函数在 PHP 4 中不存在，它是在 PHP 5 中引入的。因此，答案 C 正确。

10. `auto_detect_line_endings` ini 设置是在 PHP 4.3.0 中引入的，使系统在保存文本文件时尝试自动检测行类型。因此，答案 A 正确。

11. 为了以读写打开文件，应使用 `r+` 模式组合。因此，答案 B 和 D 正确。

12. 描述的函数是 `fopen()`。

13. 正确答案是 B、D 和 E。`readfile` 和 `file_get_contents` 都读取文件内容。

14. 使用 `fwrite()` 或 `fputs()` 效果相同，因为后者只是前者的占位符。

15. PHP 会缓存由某些函数（包括 `file_exists()`）检索的信息，以便在重复执行相同操作时提高性能。当发生文件删除时，这会导致缓存过时，因此需要像答案 A 描述的那样清除缓存，答案是正确的。

6. `mail` 函数的最后一个参数用于向 sendmail 应用程序提供额外参数，通常只在可用 sendmail 的 UNIX 环境中使用。然而，此参数也可以用于使用了 `sendmail_path` 配置指令的 Windows/Novell 环境。

7. 正确答案是 C。Content-Transfer-Encoding MIME 头部用于指定 MIME 电子邮件任何段的编码。该头部最常见的是与二进制数据相关，用于指定用于对其编码的算法。默认情况下，7bit、quoted-printable、base64、8bit 和 binary 是允许的——但是，任何人可以使用类似于 x-unique 的编码名称指定自己的编码。

8. 正确答案是 B、C 和 E。边界（Boundaries）是发送 MIME 电子邮件的关键部分。虽然对边界的长度没有限制，但选择糟糕边界会导致严重的后果。因为边界是邮件中的简单文本字符串，因此其值出现在其中一个 MIME 分段的实际正文中非常重要。例如，考虑一下如果名为 John 的人签署了他们的邮件，名为 John 的边界虽然在技术上是有效的，会造成什么潜在的灾难：接收邮件客户端将将其解析为新 MIME 分段的开始，并极可能完全误解邮件内容。

9. 要从给定的纯文本消息创建有效的 MIME 电子邮件，正确答案是 A 和 D。MIME 电子邮件在开头必须有 MIME-version 头部，而每个分段（包括“根”段）都必须带有相关的 content-type 和 Content-Transfer-encoding 头部。答案中提到的另外两个头部是可选的：Content-Disposition 用于指示如何显示分段（例如，它是否应该作为附件表示），Content-ID 是可选分配给分段中内容的唯一标识符。

10. 正确答案是 B。这种特殊的 MIME 内容类型用于定义一个包含相同内容多个版本的段。例如，一个 multipart/alternative 段内部可能包含两个类型为 text/plain 和 html 的分段。由邮件客户端选择最合适的格式并显示给该用户。根据经验，将最易读的版本（即纯文本/plain text）放在最前面总是一个好主意，以防消息从不支持 MIME 的非 邮件客户端中被读取。

11. 在类 UNIX 系统上，PHP 依赖 sendmail 应用程序来处理其电子邮件（即使服务器上没有安装 sendmail，或者它由不同的邮件传输代理模拟）。然而，在 Windows 机器上，`mail` 函数实际上会针对 SMTP INI 设置中指定的服务器执行 SMTP 事务，除非使用了 sendmail 包装器。因此答案 D 是正确的。

12. 在纯文本电子邮件上使用 `html()` 对防止跨站攻击毫无帮助——事实上，它可能导致收件者无法阅读。强制使用 POST 变量只会让潜在的黑客更难伪造你的表单（尽管并非不可可能），而确保电子邮件字段（它将成为邮件中的 to: 头部）不包含换行符可以防止恶意用户将自己的电子邮件地址添加到用户地址并接收邮件副本。因此，答案 C 和 E 是正确的。

13. **这是调试器的完美定义！** 调试软件允许你仔细监控脚本的每个方面，并逐步分析它们对系统资源的影响，从而识别并解决任何编程缺陷。

14. **`trigger_error()` 和 `user_error()` 之间真的没有区别——** 事实上，后者只是前者的别名。

15. **答案 D 正确。** 这个问题描述了 `debug_backtrace` 函数，它返回一个包含导致代码中某一点的所有函数调用（也称为回溯）的数组。
