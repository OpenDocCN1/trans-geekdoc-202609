### 2.3 异常值检测与AD确定

在本工作中，还研究了基于深度学习的QSPR的异常值检测。四个任务的异常值是根据实验值与预测值之间残差的经验累积分布函数(ECDF)进行检测的。ECDF是一个阶梯函数，在每个数据点处增加1/n。设\((X_1, ..., X_n)\)为具有共同累积分布函数\(F(t)\)的独立同分布实随机变量，那么对于实现值\((x_1, ..., x_n)\)，ECDF可如公式(8)所示定义。

\(\widehat{F}_n(t) = \frac{\text{number of element in the sample } \le t}{n} = \frac{1}{n} \sum_{i=1}^n I_{X_i \le t}\) (8)

对于固定的\(t\)，指示变量\(I_{X_i \le t}\)是参数\(p = F(t)\)的伯努利随机变量。ECDF的值是样本值小于或等于t的样本数除以样本总数n。Frutiger et al. [14]在群贡献模型的残差分析中提出了该方法，其中残差分布不能预先假设为正态分布。Frutiger et al. [14]在未分段数据集上应用了该方法，并在排除异常值后反复回归群贡献模型。最终，由于残差离散程度的降低，模型性能得到了成功改善。

然而，在基于深度学习的QSPR建模中，原始数据集通常分别分为训练集、验证集和测试集三个子集。尽管可以在三个数据集上检测异常值，但只能排除训练集和验证集中的异常值。测试集通常用于评估训练好的深度学习模型的泛化能力，它与训练集和验证集独立，不应在模型训练中进行评估。此外，测试集中包含的一些化合物可能会漂出由训练集和验证集确定的潜在化学空间。

为了描绘MDNN学习的潜在化学空间，并检查排除异常值后化学空间的变化，我们还从结构域和属性域两个方面研究了最终模型的AD。[16] 分子特征由Tree-LSTM网络输出的高维向量表示。由于高维向量不易直观显示和分析，因此适合对涉及训练集和验证集的AD确定应用降维算法主成分分析(PCA)。[62] 我们决定共同评估结构空间和属性空间，即将数据集中所有高维向量和目标属性组合成一个矩阵。PCA可以降低维度，并使仅少数几个主成分(PCs)保留所有数据的大部分方差。这样，ADs可以在较低维空间中进行分析和可视化。另一个因素是AD的范围也应确定，应用基于凸包的策略来探索AD边界。因此，可以轻松发现测试集中的某些化合物是否存在于AD之外。同时，通过ECDF识别的异常值也可以在可视化AD中标记，以研究异常值与AD之间的关系。凸包的计算方法在ESI的第S7节中公开。†
