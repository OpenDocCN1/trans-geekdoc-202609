## 2.2 MDNN实现与训练

由于所提出的MDNN包含动态神经网络（即Tree-LSTM网络），因此在支持动态网络的开源软件平台PyTorch上实现了它。50 训练、验证和测试的所有任务均在搭载NVidia GTX1060和Intel i5 8400的硬件平台上完成。开发了基于RDKit的解析器，并用Python实现了Faulon算法，以将SMILES表达式翻译为Python中的DAG。同时，利用简单的词嵌入算法实现，在TensorFlow中训练了嵌入向量。53 在所有程序准备就绪后，使用图3所示的流程获得了四种易燃性相关属性的多任务预测模型。

在图3的工作流中，采用了一种名为Adam的回归算法作为优化器来训练所提出的MDNN。在交替训练中，为每个任务配置了八个具有不同超参数的优化器。同时，还使用了另一个优化器来对整个MDNN进行联合训练。此外，采用早停法以避免过拟合，即，一旦在指定时间内（例如，二十个epoch）验证集的损失值没有改善，则训练过程将终止。

### 2.2.1 数据分析与准备。

用于训练MDNN的涉及FPT、AIT、LFL和UFL的实验数据是从名为DIPPR801的权威数据库中提取的。55 该数据库DIPPR801为每个实验数据点提供不确定度和接受度，其中所有数据均已由数据库维护人员检查和审查。因此，它被用作许多QSPR研究的可靠数据源。从PubChem收集了一份分子结构列表，表示异构SMILES，包括DIPPR801中所有可用化合物和其他化合物。56 从所使用的数据集中排除了涉及无机气体、盐类、金属有机物和金属元素的某些化合物，因为这些未使用化合物的分子结构与大多数传统有机物有显著差异，且其易燃性属性数据通常不可用。仅包含接受值和实验值的所用数据集以（逗号分隔值）CSV格式存储。所用化合物列表在ESI的S4节中提供。†

关于四种易燃性相关属性之间不同的单位和数值水平，有必要对原始数据集进行标准化，以便更轻松地训练模型。原因是不同的数值指标可能导致各任务之间梯度出现较大差距。请注意，原始实验数据集应采用线性变换进行标准化，以保证分布形状不变。采用了如等式（1）所示的Z-score变换，它始终可以生成均值为0、标准差为1的分布。

```
\(\hat{x}_i^{\text{exp}} = \frac{x_i^{\text{exp}} - \bar{x}^{\text{exp}}}{\sigma}\)
```

其中，\(\hat{x}_i^{\text{exp}}\)表示转换后的属性值，\(x_i^{\text{exp}}\)表示原始值，\(\bar{x}^{\text{exp}}\)和\(\sigma\)分别是数据集的平均值和标准差。应注意，\(\bar{x}^{\text{exp}}\)和\(\sigma\)必须在训练集上计算，然后使用这两个参数来转换验证集和测试集。

### 2.2.2 基于深度学习的QSPR模型的训练与评估。

与单任务DNN不同，通常有两种训练多任务DNN的策略，_即_，交替训练和联合训练。57 对于属性预测的联合训练，化学潜空间中表示分子的向量分布由四种属性和四项任务之间的共同特征同时组织，这些共同特征可以被学习。联合训练对训练数据有一个要求，_即_，四种属性的实验值必须同时在一个数据行中可用。因此，在联合训练的每个epoch中，可以训练MDNN的所有参数。在进行联合训练后，采用交替训练在一个epoch中训练每个FNN以及Tree-LSTM网络。在交替训练中，无需填充所有训练数据矩阵，这可以将一些信息从丰富的数据集转移到稀疏的数据集中。在交替训练中，在每次迭代中仅针对当前任务更新相应的FNN，而其他任务特定FNN的所有参数均被冻结。在两种训练方法中采用了两种损失函数。对于联合训练，更新整个网络的所有参数以最小化组合损失函数等式（2）。58

```
\(L(W, \sigma_1, \sigma_2, \dots, \sigma_i) = \sum_l \left( \frac{1}{2\sigma_l^2} L_i(W) + \log \sigma_i \right) \quad (2)\)
```

```
\(L(W, \sigma_i) = \frac{1}{2\sigma_i^2} L_i(W) + \log \sigma_i \quad (3)\)
```

其中，\(W\)用于表示模型参数，\(\sigma_i\)是每个任务的观测噪声变量（_即_，标准差）。该损失函数使用每个任务的同方差不确定度对所有任务的损失进行加权，从而允许每个属性对应的任务同时学习。代表每个任务损失函数的\(L_i(W)\)是通过估计值与实验值之间的均方误差（MSE）计算得出的。应注意，损失函数\(L_i(W)\)用于每个FNN，加权损失函数\(L_i(W, \sigma_i)\)用于在交替训练中训练Tree-LSTM编码器。与模型训练相关的详细信息在ESI的S5节中呈现。$^\dagger$

### 2.2.3 超参数确定。

为深度学习模型确定最优超参数配置至关重要。一般来说，应确定两部分超参数：深度神经网络的结构参数（_例如_，隐藏层数量、神经元数量、激活函数类型及参数）和训练优化器的参数。不幸的是，没有一种通用配置可以对所有模型和数据集都有效。有必要分别为不同模型优化超参数。
