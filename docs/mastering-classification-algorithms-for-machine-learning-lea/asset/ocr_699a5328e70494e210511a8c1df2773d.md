This point is highlighted by the Random Forest algorithm creates 100s of subsets from the datasets in real-world applications. Each of such models is called an **estimator**.
- Each subset contains k data points where $k < n$ (n being the number of data points in the original dataset). The k data points in each subset are selected at random with replacement.
- Note that the picture of the data in the original dataset is repeated in each subset in the illustration. This is when the subsets are created in the Random Forest algorithm, the distribution of the labels in each should be as close to the distribution of the labels in the original dataset.
- On each of the subsets, a decision tree is trained **without pruning**. So, in a model created using the Random Forest algorithm, the prediction from each decision tree is collected, and the class predicted by the maximum number of decision trees is the prediction from the model built using the Random Forest algorithm.
