+   * Bayes Theorem states that if A and B are 2 events, $P(A|B) = \frac{P(B|A)\times P(A)}{P(B)}$

+   * To find $P(Y \mid (A_i,A_j\dots,A_l))$, the Naïve Bayes Theorem assumes that events $A_1,A_2\dots A_n$ are independent.

+   * Naïve Bayes Theorem states that $P(Y \mid (A_iA_j\dots,A_n)) = P(A_i \mid Y) * P(A_j \mid Y) * \dots P(A_n \mid Y) * P(Y)$.
