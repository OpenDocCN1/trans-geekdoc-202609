
# Logistic Regression

We will start our discussion with binary classification (that is, the target variable can assume two values – 0 and 1) and later extend this to multi-class classification.

When we use a linear model for predicting a categorical variable, it is called a Logistic Regression model. In other words, the algorithm to solve classification models using a linear method is called the Logistic Regression algorithm.

In the Logistic Regression algorithm, we convert the problem of predicting the target variable (which is categorical) into a problem of predicting the probability of occurrence of the target variable. Now, the probability is a value between 0 and 1, which makes the problem of predicting a categorical target variable a problem of predicting a continuous variable.

Let us understand this through an example. Suppose our problem is to predict whether an SMS is spam. We need to predict two classes: SPAM and NOT SPAM. Now, we label SPAM as 1 and NOT SPAM as 0. Our problem is to predict 1 or 0. However, we change the problem to predicting the probability of an SMS being SPAM. In other words, our target variable is $P_{y}(y=1)$. $P(y=1)$ can take a value between 0 and 1 as this is a probability. So, it is a continuous variable. On obtaining the value, we consider a threshold value. If $P_{y}(y=1)>$ threshold, we consider $y=1$ (or SPAM in this case). If $P_{y}(y=1)\le$ threshold, $y=0$ (or NOT SPAM in this case).

So, we are using a Linear Regression method to make a prediction. By obtaining the prediction, we compare the prediction against a threshold to get the predicted binary category.

# Sigmoid function

For the Logistic Regression algorithm, we need a function that will output a value between 0 and 1. The function which does this is the Sigmoid Function. Function is of the form as follows:

```
$$\sigma(t) = \frac{1}{1+e^{-t}}$$
```

Here, t can assume a value between $-\infty$ to $+\infty$.

When $t=-\infty, e^{-t}=e^{-(-\infty)}=\infty$. So, $\sigma(t)=\frac{1}{1+e^{-t}}=\frac{1}{1+\infty}=\frac{1}{\infty}=0$.

When $t=+\infty, e^{-t}=e^{(+\infty)}=0$. So, $\sigma(t)=\frac{1}{1+e^{-t}}=\frac{1}{1+0}=\frac{1}{1}=1$.

So, the Sigmoid function always takes a value between 0 and 1.

The problem we will have for classification with one or more than 1 number of features (or independent variables) and 1 target variable (or dependent variable). So, the linear form of the problem will be as follows:

$y = a_0 + a_1x_1 + a_2x_2 + \dots + a_nx_n$

Applying the Sigmoid function, we will get as follows:

$\sigma(y) = \frac{1}{1+e^{-y}} = \frac{1}{1+e^{-(a_0+a_1x_1+\dots+a_nx_n)}}$

So, for every data point, we will get a value between 0 and 1. To make prediction, we formulate as follows:

$y = \begin{cases} 1, if \sigma(y) > 0.5 \\ 0, if \sigma(y) \le 0.5 \end{cases}$

Here, we have considered our threshold as 0.5. We could set the threshold to any other value between 0 and 1 depending on our problem.

Now we have many data points, m data points, in our dataset. For each data point, we will get as follows:

$\sigma(y_i) = \frac{1}{1+e^{-y_i}} = \frac{1}{1+e^{-(a_0+a_1x_1+\dots+a_nx_i)}}$ here $i$ varies from 1 to m.

# Cost function for Logistic Regression algorithm

Unlike the Linear Regression algorithm, we cannot use a measure like the MSE as the Cost Function for the Logistic Regression algorithm. We will need to engineer a cost function such that we get a measure of whether we are making a binary classification accurately. Once we establish the cost function, we can apply the gradient descent algorithm to minimize the cost function to obtain the optimum model.

We now know that the prediction for a data point is as follows:

```
$$\sigma(y_i) = \frac{1}{1 + e^{-Y_i}} = \frac{1}{1 + e^{-(a_0 + a_1x_1 + \dots + a_nx_{n_l})}}$$
```

Let us call $\sigma(y_j)$ as $(p_j)$. So, we get as follows:

```
$$p_i = \sigma(y_i) = \frac{1}{1 + e^{-Y_i}} = \frac{1}{1 + e^{-(a_0 + a_1x_1 + \dots + a_nx_{n_l})}}$$
```

The cost function for Logistic Regression is given as follows:

$$J = -\frac{1}{m} \sum_{i=1}^{m} [y_i \log(p_i) + (1-y_i) \log(1-p_i)]$$

Let us understand this cost function. Note that probability can only take a value between 0 and 1. So, $(p)$ and $(1-p)$ are close to 0 and 1. If $y_i=1$ and $p_i$ is close to 1, $\log(p_i)$ is close to 0. If $y_i=1$ and $p_i$ is close to 0, $-\log(p_i)$ is a large number. Similarly, if $y_i=0$ and $p_i$ is close to 1, $\log(1-p_i)$ is close to 0. If $y_i=0$ and $p_i$ is close to 0, $-\log(1-p_i)$ is a large number.

To retain this characteristic of the cost function, we can write the cost function as:

$$J = -\frac{1}{m} \sum_{i=1}^{m} [y_i \log(\hat{p}_i) + (1-y_i) \log(1-\hat{p}_i)]$$

This can be expanded as:

$$J = -\frac{1}{m} \sum_{i=1}^{m} [y_i \log(\sigma(y_i)) + (1-y_i) \log(1-\sigma(y_i))]$$

You can expand it further by replacing $y_i = a_0 + a_1x_1 + a_2x_2 + \dots + a_nx_n$.

This cost function is called the Log-Loss Function. The Sigmoid Function is called the Logistic Function. Using the Sigmoid Function and the Log-Loss Function, this algorithm gets the name Logistic Regression algorithm.

We have reached a formula like the one used for the Regression algorithm. We need to minimize $J$ by altering the coefficients. We change the coefficients so that each iteration gives the coefficient as:

$a_i = a_i - \alpha \frac{\partial J}{\partial a_i}$ where $\alpha$ is the learning rate.
