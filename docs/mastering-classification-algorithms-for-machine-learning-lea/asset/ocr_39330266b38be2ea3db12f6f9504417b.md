To create the new dataset, we need to select the number of data points as in the original dataset with replacements. This way to achieve this is to generate n of random numbers between 0 and 1 (note that in our example, n = 10, being the number of data points in the dataset). Based on the generated random numbers, whose lower limit < random number < upper limit. Notice that the range for the data points where the wrong prediction was much larger than the data points where the correct prediction was made. So, the chance that the data point with the wrong predictions will be picked for the new dataset is much higher than the data points where the correct prediction was made.
