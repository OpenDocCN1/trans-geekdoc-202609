

## 记忆点

- 熵（Entropy）是衡量数据集随机性的指标。
- 熵的值介于 0 和 1 之间。
- 当数据集的熵为 0 时，该数据集是纯随机的。
- 当数据集的熵为 1 时，该数据集是完全随机的。
- 子节点的信息增益（Information Gain）是父节点熵与子节点熵之差。
- 决策树在信息增益最大的子节点处分裂。
