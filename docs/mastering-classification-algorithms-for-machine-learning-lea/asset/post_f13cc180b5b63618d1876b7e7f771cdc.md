
Now, see that P(Benign | please) > P(Spam | please). So, if a message contains the word “please”, there is more chance that the message is Benign.

We have devised a mechanism to determine whether a message is Benign or Spam based on a particular word appearing in the message. However, a message will contain more than one word, and the presence of each word and the combinations of words in the message can lead to a message being Benign or Spam. So, we need to further our model.

We have determined P(Spam | asap) in the above example. Suppose the message also contains “call” apart from “asap.” So, we need to find P(Spam | call AND asap), which is written out as P(Spam | (call, asap)).

By Bayes Theorem, we have:

```
P(Spam|(call, asap)) = P((call,asap)|Spam)*P(Spam) / P(call,asap) --- eqA
```

Here, P(call, asap) is P(call AND asap) or P(call asap). Using the multiplication rule of probability, we know that

```
P(call, asap) = P(call | asap) * P(asap)
```

We know P(asap). However, to calculate P(call | asap), we will have to scan all the messages where “asap” exists and then see if “call” also exists. This may be possible for a small number of words. Our datasets typically contain tens of thousands of words or a combination of words. So, performing these operations would be expensive on any computer. We simplify our solution by assuming the events of each word appearing in the messages are independent of the appearance of any other word. This is a rarely reality. Nevertheless, this assumption leads us to a reasonable solution called the Naïve Bayes theorem.

## Detecting Spam using Naïve Bayes theorem

Continuing with our example, we were stuck in the phase for calculating P((call | asap) and (call, asap)|Spam). Now, if we consider that the event of the word “call” appearing in the message is independent of the event of the word “asap” appearing in the message, then we know that:

```
P(call | asap) = P(call)
```

Also, by the multiplication rule of probability and from the assumption that the event of the word “call” appearing in the message is independent of the event of the word “asap” appearing in the message, get:

## Naïve Bayes Algorithm

$P((call, asap) | Spam) = \frac{P((call, asap),Spam)}{P(Spam)} = \frac{P(call,Spam)+P(asap,Spam)}{P(Spam)}$

$\frac{[P(call|Spam)*P(Spam)][P(asap|Spam)*P(Spam)]}{P(Spam)}$

$P(call|Spam) * P(asap|Spam) * P(Spam)$

Making this substitution in equation eqA, we get:

$P(Spam|(call, asap)) = \frac{P(call|Spam)*P(asap|Spam)*P(Spam)}{P(call,asap)} --- eqB$

In the Naive Bayes algorithm, remove the denominator in the equation eqB to get:

$P(Spam|(call, asap)) = P(call|Spam) * P(asap|Spam) * P(Spam) --- eqC$

Let us generalize the equation eqC. Let the event of the message be event X. The occurrences of the words in the message are the events $A_{\mu_1}, A_{\mu_2}, ..., A_{\mu_n}$ (Here, consider that we have n words in the message). So, eqC can be written as:

$P(X|(A_{\mu_1}, A_{\mu_2}, ..., A_{\mu_n})) = P(A_1|X) * ... * P(A_{\mu_n}|X) * P(X) --- eqD$

Equation eqD is the Naive Bayes theorem.

Using Naive Bayes theorem, let us calculate $P(Spam|(call, asap))$.

From Table 2.8, we get

$P(Spam|(call, asap)) = 1/5, P(asap|Spam) = 2/5$.

We know that $P(Spam) = 2/5$.

So,

$P(Spam|(call, asap)) = (1/5) * (2/5) * (2/5) = 4/25$

If we calculate $P(Benign|(call, asap))$, then we compare $P(Benign|(call, asap))$ and $P(Spam|(call, asap))$. Whichever of these would be greater, the chances of the message being in that class, given that these two words are present in the message, would be greater. Generalization of this idea to any number of events $A_{\mu_1}, A_{\mu_2}, ..., A_{\mu_n}$ for event X in the same space is Naïve Bayes.

## Variations of Bayes Bayes

Naive Bayes algorithm can be used for binary classification (that is, classifying into two classes) or multi-class type. These variations of Bayes algorithm are available in the Scikit-Learn library. Let us discuss these implementations:

- Discrete variables can assume a finite number of values. For example, if a variable can assume [0, 1], it is discrete as the number of values is finite. Discrete variables are also categorical.
- Continuous variables are variables that assume an infinite number of values. For example, if a variable can assume any natural number, it is a continuous variable. We can perform classification only if the target variable (or dependent variable) is discrete. If the target variable is continuous, we can only perform regression.

## Bernoulli Naïve Bayes

Bernoulli Naïve Bayes performs binary classification, that is, only two classes in the dependent variable. For example, in the spam detection example, if the need is only to classify a message as spam, Bernoulli Naïve Bayes could be used. However, if there is a need to classify the nature of spam-like Virus, DDoS, etc., then there are more than two classes, and thus Bernoulli Naïve Bayes cannot be used.

## Multinomial Naïve Bayes

Multinomial Naïve Bayes allows for classifying two or more classes. Multinomial Naïve Bayes works well if the independent variables are categorical or continuous. This variation works better than other variations in text data if vectorizers like TF-IDF Vectorizers and Count Vectorizers are used to create independent variables. Refer to Annex 6 for details on Vectorizers.

## Complement Naïve Bayes

Complement Naïve Bayes is a variation of the Multinomial Naïve Bayes. Complement Naïve Bayes works well when the dataset is imbalanced.

## Naïve Bayes Algorithm

Note: A dataset is considered imbalanced if the number of data points in each class varies. For example, suppose we have a dataset of spam emails containing 1000 data points in 2 classes – spam and not spam. We would consider the dataset imbalanced if we have about 50-50% or 60-40% or 40-60% between data points for spam emails and not spam emails. Otherwise, the dataset could be regarded as imbalanced.

Any fraud dataset, like spam email, spam SMS, Credit Card fraud, etc., is heavily imbalanced. Fraud could happen once in a thousand or even a million.

## Categorical Naïve Bayes

Categorical Naïve Bayes is used when all the independent variables are categorical. It can be used for classifying two or more target classes.

## Gaussian Naïve Bayes

Gaussian Naïve Bayes implementation, the likelihood function is:

```
$P(X_i|Y) = \frac{1}{\sqrt{2\pi\sigma_y^2}} e^{-\frac{(x_i-\mu_y)^2}{2\sigma_y^2}}$
```

where $\mu_y$ and $\sigma_y$ are the mean and standard deviations of the target class. Gaussian Naïve Bayes implementation is used when all the independent variables are continuous, and all independent variables are distributed normally.

Note: A distribution is said to be normal if it is evenly distributed around the mean and forms a bell-shaped curve. The distributions in Figures 2.1, 2.2, 2.3, 2.4, and 2.5 are normally distributed.
