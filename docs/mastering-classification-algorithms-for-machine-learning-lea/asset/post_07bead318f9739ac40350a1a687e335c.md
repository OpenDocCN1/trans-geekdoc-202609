
## BaggingClassifier

In sklearn, **BaggingClassifier** class is available for implementing Bagging Ensemble Models for classification. Table 6.1 lists the essential parameters for the **BaggingClassifier** class:

| Parameter | Explanation |
| --- | --- |
| estimator | The estimator is to be used by the Bagging Classifier class. By default, the estimator is DecisionTreeClassifier. This parameter needs to be provided as an instance of the estimator class. |
| n_estimators | The number of estimator instances to be created. This means that the Bagging Classifier will create a number of models equal to the value of n_estimators using the estimator class and will create n_estimators of data sets from the provided data set. In some versions of Scikit-Learn, this parameter may be available as base_estimator. |
| bootstrap | This is a Boolean parameter, that this parameter takes values of True and False. If the value of the bootstrap parameter is set to True, the samples are drawn with replacement. If the value of the bootstrap set to False, the samples are drawn without replacement. |
| max_samples | The maximum number of data points to be drawn from the original data set is to be provided for each instance of the estimators. |
| oob_score | This is a Boolean parameter, that is, this parameter takes values of True and False. This parameter is applicable only if the bootstrap parameter is set to True. When this is set to True, the out-of-bag data points are used to check for the generalization error. |

Table 6.1: Parameters for BaggingClassifier

In the following code, we see how the BaggingClassifier from Scikit-Learn package can be used:

```python
from sklearn.ensemble import BaggingClassifier
```

```python
from sklearn.tree import DecisionTreeClassifier
```

```python
baggingClf = BaggingClassifier(estimator=DecisionTreeClassifier(), n_estimators = 1000, bootstrap=True, max_samples=500, oob_score=True)
```

## StackingClassifier

in sklearn.ensemble, **StackingClassifier** class is available to implement Stacking Ensemble Models for classification. There are two essential parameters for the StackingClassifier class. The first essential parameter is **estimators**, which take a list of the different classifiers for building the base models. The second essential parameter is **final_estimator** which takes the class to construct the meta-model.

Another important parameter for **StackingClassifier** is the passthrough. It takes a Boolean value (that is, we set this parameter to True or False). When passthrough is set to False, **StackingClassifier** uses the predictions from the Base Models as the input to build the Meta Model. When passthrough is set to True, **StackingClassifier** will use the prediction from the Base Model and the original data set to construct the Meta Model as shown in the following code:

```python
from sklearn.ensemble import StackingClassifier
...
```

```python
from sklearn.naive_bayes import MultinomialNB
from sklearn.neighbors import KNeighborsClassifier
from sklearn.tree import DecisionTreeClassifier
from sklearn.linear_model import LogisticRegression
```

```python
...
nbCls = MultinomialNB()
knnCls = KNeighborsClassifier()
dtCls = DecisionTreeClassifier()
lrCls = LogisticRegression()
```

```python
...
stackingClf = StackingClassifier(estimators=[('nb', nbCls), ('knn', knnCls), ('dt', dtCls)], final_estimator=lrCls)
...
```

Both actresses spoke English as their first language, were university educated, and had musical training. Audiometric testing indicated that both actresses had thresholds within the normal range.
