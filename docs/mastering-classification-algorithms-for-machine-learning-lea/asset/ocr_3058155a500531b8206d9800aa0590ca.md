# Conclusion

The Decision Tree algorithm is a greedy algorithm. This is because the Decision Tree tries to find an optimal split at the root node and continues to find optimal splits at each subsequent node until it cannot further reduce the impurity. Because of this approach, the Decision Tree algorithm tends to over the data. When the model is overfitting, it cannot generalize well on the new data it provides for making predictions.
