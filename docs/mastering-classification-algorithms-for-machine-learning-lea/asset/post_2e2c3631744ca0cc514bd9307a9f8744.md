Let us calculate the Entropy for the data points shown in Table A8.4. We get as follows.

$P_0 = \frac{5}{7}=0.714 \text{ and } P_1 = \frac{2}{7}$

Using these values of $P_0$ and $P_1$, we can calculate the Entropy for the dataset on the right-hand side of the split at $x_2=3.5$. We will call this Entropy$_{parent}$ as this will be the parent node for the next set of data points we will try to split.

```
Entropyparent = ((0.714 * log(0.714)) + (0.286 * log2(0.286)))
= ((0.714 * (-0.3485)) + (0.286 * (-1.807)))
= (-0.347 + (-0.516)) = -0.863
```

As the Entropy of the dataset in Table Annexure 8.4 is not 0, the dataset is impure, and we need to split this dataset to find decision points or leaves. So, we must calculate the Information Gain for all the thresholds. As the range of $x_1$ and $x_2$ have changed, we must reestablish the thresholds. Using the same logic of using the minimum and maximum values of features to establish the threshold, we get the value to consider for $x_1$, as follows.

- 1.00, 1.50, 2.00, 2.50, 3.00, 3.50, 4.00, 4.50, 5.00, 5.50, 6.00

And the values to consider for $x_2$ are as follows.
- 4.00, 5.00, 5.50, 5.50, 6.00
