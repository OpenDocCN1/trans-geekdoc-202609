# Information gain

Recall in a decision tree, we will have one root node. Under the root node, we will have two or more nodes (these nodes may be all leaf nodes, all decision nodes, or a mix of leaf nodes and decision nodes). We may have a similar structure under each decision node.

Consider the decision tree in Figure A8.1. Here, node A is the Root Node. Node B is a Decision Node. And nodes C, D, and E are leaf nodes. In Figure Annex 8.1, node A is the parent of node B, and node B is the child of node A.

Figure Annex 8.1: Example Decision Tree for illustration

We calculate the Information Gain of a Child node.

The Information Gain of a node is given as follows:

$Information Gain = Entroparent - Entropychild$

Suppose that the Entropy of node A is 0.9 and the Entropy of node B is 0.3. Then, the Information Gain at node B would be $(0.9 - 0.3) = 0.6$.
