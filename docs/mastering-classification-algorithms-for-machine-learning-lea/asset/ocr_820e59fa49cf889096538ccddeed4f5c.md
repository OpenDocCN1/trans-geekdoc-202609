The Launcher on the right-hand side can open a new Notebook. Notice that Jupyter Lab can be used for creating Notebooks using Python language or R language.

> Note: A preferred way of installing and using Jupyter Lab and Jupyter Notebook is to install Anaconda. Anaconda provides many tools than just the Jupyter Lab and Jupyter Notebook. While Jupyter Lab and Jupyter Notebook are available free of cost, some of the other tools require a subscription.
