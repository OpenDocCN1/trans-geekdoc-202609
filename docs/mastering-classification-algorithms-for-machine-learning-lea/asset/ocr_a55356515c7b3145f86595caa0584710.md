Let us say that each of the classifiers in the Voting Ensemble model, as shown in

accuracy greater than the best models used in building the Voting Ensemble model.

The theory is that each of the classifiers in the Voting ensemble model is a “weak
learner” (a “weak learner” is a model whose predictions are just better than a random
gess, and there is a diverse set of “weak learners”, the Voting Ensemble model can
be “strong learner” (that is, a model with high accuracy).

For the best results, all the classifiers in the Voting Ensemble model should be
independent. How can we make the classifiers in the Voting Ensemble Model
independent using classifiers that use different algorithms. Also, the accuracy of
The Voting Ensemble models increases if the classifiers in the Voting Ensemble
model makes different errors.

# Bagging ensemble model

In Bagging ensemble models, we use the same algorithm to create multiple models.
However, we provide a different subset of the data for each model. So, none of the
models sees the complete data set. To provide different subsets of the data to each of
models, we create random subsets of the original data set. Then, we train each of
models on one of the subsets of the data set and consider the decision made by
tmaximum number of models.
