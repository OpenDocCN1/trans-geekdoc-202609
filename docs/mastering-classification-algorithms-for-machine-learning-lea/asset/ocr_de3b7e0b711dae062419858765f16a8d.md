Note: As you would have realized, we need to choose K such that we do not have a tie between the number of classes to classify. For example, if we have 2 classes to classify, then we must choose K to be an odd number.
Also, we must choose the value of K to proportionate to the total number of data points in the dataset. Otherwise, we may make the wrong classification.

# Mechanisms to measure the distance

So far, we have used the Euclidean distance to find the similarity between data points for evaluating neighbors in use KNN algorithm. Euclidean distance is also called the L2 Norm. We have calculated the Euclidean distance between 2 points in the 2-dimensional space. We could generalize this for n-dimensional space as follows. Suppose that we have 2 points as $(x_1, x_2, ..., x_n)$ and $(y_1, y_2, ..., y_n)$. Then,

```
Euclidean Distance = $\sqrt{(x_1 - y_1)^2 + (x_2 - y_2)^2 + \dots + (x_n - y_n)^2}$
= $\sqrt{\sum_{i=1}^{n}(x_i - y_i)^2}$
```

We will discuss the other measures of distance that we could use to find the distance between 2 points.

# Manhattan distance

Manhattan distance is the absolute value of the difference between 2 vectors. Let us say that the 2 points are $(x_1, x_2, ..., x_n)$ and $(y_1, y_2, ..., y_n)$. Then,

```
Manhattan Distance = $|x_1 - y_1| + |x_2 - y_2| + \dots + |x_n - y_n|
= $\sum_{i=1}^{n}|x_i - y_i|$
```

Manhattan Distance is also called the L1 Norm.

# Hamming distance

Hamming distance is used to find the distance between 2 points if the data elements are categorical. Recall that categorical variables can only assume discrete values. Let us say that the 2 points are $(x_1, x_2, ..., x_n)$ and $(y_1, y_2, ..., y_n)$. Then,

```
Hamming Distance = $\frac{1}{n}\sum_{i=1}^{n}\delta_i$
```

Where $\delta_i=1$ if $x_i=y_i$ else 0
