All the algorithms we discussed before this chapter (namely, the Naive Bayes algorithm, K-Nearest Neighbor algorithm, Logistic Regression algorithm, and Decision Tree algorithm) could be understood by manual illustration. However, in the Ensemble models (and Neural networks), it is difficult to explain why a particular data instance was classified in a specific class.
