Now that the original data has been grouped by the Customer, we can find the total Monetary Value of each Customer by summing up the invoice values of each Customer. Similarly, we can find the last Invoice Date of each Customer.

```
dfCustomerDF = \
  .join(gb.agg({'TotalAmount': 'sum'}).rename(columns={'TotalAmount': 'MonetaryValue'}))
  .join(gb.agg({'InvoiceDate': 'max'}).rename(columns={'InvoiceDate': 'MostRecentPurchase'}))\n  .reset_index()
```
