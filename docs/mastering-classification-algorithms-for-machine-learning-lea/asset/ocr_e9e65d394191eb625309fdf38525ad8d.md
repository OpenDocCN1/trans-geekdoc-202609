Note: Many Statisticians consider the formula for Standard Deviation as:

```
$$\sigma = \sqrt{\frac{\sum_{i=1}^{n}(x_i-\mu)^2}{n-1}}$
```

In Machine learning, we will deal with massive datasets with thousands, if not millions, of data points. Now, dividing by 10,000 and 9,999 does not produce much difference. Thus, we can safely use the formula for Standard Deviation with “n” as the denominator.

In Microsoft Excel, the formula STDEV() to find Standard Deviation deiders “n - 1” as the denominator. The formula STDEV.P() to find Standard Deviation in Microsoft Excel considers “n” as the denominator.
