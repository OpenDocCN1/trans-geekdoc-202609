Now, see that P(Benign | please) > P(Spam | please). So, if a message contains the
word “please”, there is more chance that the message is Benign.

We have devised a mechanism to determine whether a message is Benign or Spam
based on a particular word appearing in the message. However, a message will
contain than one word, and the presence of each word and the combinations
words in the message can lead to a message being Benign or Spam. So, we need
to further our model.

We have determined P(Spam | asap) in the above example. Suppose the message also
contains “call” apart from “asap.” So, we need to find P(Spam | call AND asap),
which is written out as P(Spam | (call, asap)).

By Bayes Theorem, we have:

```
P(Spam|(call, asap)) = P((call,asap)|Spam)*P(Spam) / P(call,asap) --- eqA
```

Here, P(call, asap) is P(call AND asap) or P(call asap). Using the multiplication rule
of probability, we know that

```
P(call, asap) = P(call | asap) * P(asap)
```

We know P(asap). However, to calculate P(call | asap), we will have to scan all
t messages where “asap” exists and then see if “call” also exists. This may benpossible for a small number of words. Our datasets typically contain tens
of thousands of words or a combination of words. So, performing these operations
would be expensive on any computer. We simplify our solution by assuming
the events of each word appearing in the messages are independent of the
appearance of any other word. This is a rarely reality. Nevertheless, this assumption
lead us to a reasonable solution called the Naïve Bayes theorem.
