Now that our function is ready, we will apply this function to our input data. We will treat only the text in the **X_train** dataset for the moment, as this is what we will use for training our model.

Before applying the function, we convert all the data to lowercase. This is so that all the similar words appear the same. For example, the word "Same" may be used in the text as "Same", "SAME", "same" or in any other way. If we do not convert the text to lower or upper case, all the different representations of the word will appear as distinct entities, adding no value to the spam detector. Suppose we consider that the word "free" is used in SMS texts. If we treat the other representations of "free" differently, our model will weaken.

```python
X_train = X_train.str.lower()
```

# Forming TF-IDF (Converting text to numbers)

Now that we have a clean data set, we need to convert this text data to numbers so the computer can use it to model it. There are several ways to convert text data to numbers. We will use two such methods.

We will now create **TF-IDF Vectors**. To make the TF-IDF Vectors, we will use the **TfidfVectorizer** from the Scikit-Learn library as follows:

```python
from sklearn.feature_extraction.text import TfidfVectorizer
```

```python
tfidf = TfidfVectorizer(min_df=0, use_idf=True, n_range=(1, 4))
tfidfText = tfidf.fit_transform(X_train)
print('Shape of original Training Data:', X_train.shape)
print('Shape of transformed Training Data:', tfidf.shape)
Shape of original Training Data: (5014,)
Shape of transformed Training Data: (5014, 87653)
```
