

## 第6章：集成模型 – 讨论了如何将多个弱模型组合起来形成一个强力模型。本章还讨论了如何构建集成模型，包括投票（Voting）、Bagging、提升（Boosting）和堆叠（Stacking）模型。本章最后以讨论如何从语音中检测情感作为结束。为了实现这一点，本章讨论了如何从音频剪中提取信息并将其格式化，以应用于机器学习模型。

## 第7章：随机森林算法 – 它是机器学习中一种强大且先进的算法。它是 Bagging 集成的一种特例。本章讨论了随机森林算法的构建，以及是什么使模型能够无偏且低方差，并在真实数据上表现良好。书中还讨论了如何使用随机森林算法检测 ELF 文件中的恶意软件。

## 第8章：Boosting 算法 – 另一种用于解决分类问题的先进算法。本章通过示例介绍了 AdaBoost 算法。AdaBoost 算法主要使用决策树算法作为核心。因此，在本章中回顾了决策树算法。本章通过 AdaBoost 算法解决了图像分类问题。由于即使是像 AdaBoost 这样强大的算法在视频分类上也无法产生令人满意的结果，本章最后介绍了神经网络。

除了这八章之外，书中还包含 8 个附录，用于补充对必要概念的讨论。

附录 1：Jupyter Notebook 是用于开发和运行书中涉及的所有代码的集成开发环境（IDE）。书中涉及的所有代码文件作为补充材料随书提供。所有代码均以 Jupyter Notebook 的形式存在。本附录讨论了 Jupyter Notebook 的基础。

附录 2：Python 是书中使用的编程语言。本附录介绍了 Python 编程的基础知识。

附录 3：单值分解是减少数据维度的方法之一。本附录讨论了单值分解（SVD）背后的数学原理，并展示了 SVD 在图像压缩中的应用。

附录 4：文本数据预处理是在数据应用于机器学习之前的关键步骤之一。本附录讨论了清理文本数据的关键预处理步骤。

**附录 5：词干（Stemming）和词还原（Lemmatization）** 是应用于文本数据预处理的机制。本附录通过示例讨论了这些技术。

**附录 6：向量化器（Vectorizers）** 用于将文本数据转换为数字以应用于机器学习模型。机器学习模型仅可以使用数值数据构建，因此需要一种将文本数据转换为数字的机制。本附录讨论了两种向量化器——计数向量化器（Count Vectorizer）和 TF-IDF 向量化器。

**附录 7：编码器（Encoders）** 用于将文本数据转换为数字以应用于机器学习模型。机器学习模型仅可以使用数值数据构建，因此需要一种将文本数据转换为数字的机制。本附录讨论了各种编码器。

**附录 8：熵（Entropy）** 用于构建决策树。第 5 章讨论了如何使用基尼指数（Gini Index）构建决策树。本附录提供了一种使用熵和信息增（Information Gain）构建决策树的替代方法。
