Let us say that data scientist decides to create a linear model of the form M = $\beta_0 + \beta_1 * m + \beta_2 * v$. The machine needs to estimate the values of $\beta_0, \beta_1$, and $\beta_2$.

The Data Scientist provides a starting value of $\beta_0$, $\beta_1$, and $\beta_2$. Let us say that these values are $\beta_0 = 5$, $\beta_1 = 5$, and $\beta_2 = 5$. Using these values, the machine calculates the values for M, as shown in Figure 1.7. We call the value calculated by the machine M.
