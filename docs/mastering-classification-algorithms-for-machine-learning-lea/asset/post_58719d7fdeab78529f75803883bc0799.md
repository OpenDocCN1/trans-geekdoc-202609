## Data types

Python is a dynamic programming language. Unlike languages like C, C++, or Java, there is no need to declare the data types. The interpreter determines the type at runtime. 

Let's look at some basic data types in Python:

### Integer
Integers are whole numbers. They can be positive, negative, or zero without decimals.

```python
x = 10
y = -5
```

### Float
Floating point numbers are numbers with a decimal point.

```python
x = 10.5
y = -2.0
```

### Boolean
Booleans represent one of two values: True or False.

```python
is_active = True
is_finished = False
```

### String
Strings are sequences of characters enclosed in either single or double quotes.

```python
name = "Alice"
message = 'Hello World'
```

### List
Lists are ordered, mutable collections of items. They can contain different data types.

```python
my_list = [1, "apple", 3.14]
```

### Tuple
Tuples are ordered, immutable collections of items. Once created, they cannot be changed.

```python
my_tuple = (1, "apple", 3.14)
```

### Dictionary
Dictionaries are unordered (as of Python 3.7+) collections of key-value pairs.

```python
my_dict = {"name": "Alice", "age": 25}
```

### Set
Sets are unordered collections of unique items. They do not allow duplicate values.

```python
my_set = {1, 2, 3, 3}  # result will be {1, 2, 3}
```
