So, we see A = A1 ∪ A2, or the union of A1 and A2 or (A1 or A2).

Now, A1 = B1 ∩ A and A2 = B2 ∩ A (There are intersections).

So, A = (B1 ∩ A) ∪ (B2 ∩ A).

Now, let

A = Probability of the event Y = P(Y),

B1 = Probability of the event X1 = P(X1),

B2 = Probability of the event X2 = P(X2).

Then, we can state that:

P(Y) = P(X1 ∩ Y) + P(X2 ∩ Y) = P(X1, Y) + P(X2, Y)

Now, from our discussion on conditional probability, we know

P(A, B) = P(B|A) * P(A)

So, we get:

P(Y) = P(X1,Y) + P(X2,Y) = P(Y|X1) * P(Y|X2) * P(X2)

Let us consider an example. Suppose that in a class, 20% of the Males are 6' (read, 6 feet) tall and 1% of the Females are 6' tall. Furthermore, we know that 40% of the students are females. We need to determine the probability that a student in the class is 6' tall.

We consider that Y is the event that a student is 6' tall. So, we need to determine.

P(6') = P(Y)

Also, consider X1 is the event that a student is male, and X2 is the event that a student is female.

P(Female) = P(X2) = 40% and P(Male) = P(X1) = 1 - P(Female) = 1 - P(X2) = 60%

P(6'Male) = P(Y|X1) = 20% and P(6'Female) = P(Y|X2) = 1%

So, we get:

P(Y) = P(Y|X1) * P(Y|X2) * P(X2) = 20% * 60% + 1% * 40% = 12% * 0.4% = 4.8%

Total Probability theorem states that if we have n disjoint events X1, X2, ..., Xn in a sample space and we have an event Y in the same sample space, then:

P(Y) = P(Y|X1) * P(X1) + P(Y|X2) * ... + P(Y|Xn) * P(Xn)
