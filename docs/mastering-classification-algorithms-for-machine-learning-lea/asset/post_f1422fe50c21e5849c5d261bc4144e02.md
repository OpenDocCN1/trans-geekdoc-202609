> Note: We can get the value of r as 0.5 or greater than 0.5 or less than 0.5.

If r = 0.5, then $\alpha = \eta \log \frac{1-0.5}{0.5}$ = $\eta \log \frac{0.5}{0.5}$ = 0. Under this circumstance, the new weights remain the same as the old weights, as $e^0=1$. So, the model will not learn further.

Also, if r > 0.5, say 0.7, then $\alpha = \eta \log \frac{1-0.7}{0.7}$ = $\eta \log \frac{0.3}{0.7}$ = $\eta \times 0.428=-0.847$.
So when r>0.5, $\alpha$ is negative; as a result, the data points with wrong predictions get less weight instead of getting boosted. So, in this circumstance, the model cannot improve any further.
Only when r<0.5 $\alpha$ will be positive, and as a result, the data points with wrong predictions will get boosted.
Remember if r is close to 0.5, the estimator (or the model) is weak, as it merely makes a guess. If r is close to 0, also, if r is close to 1, the estimator is strong, as it has a high chance of making the correct prediction. Also, a wrong prediction is very high. If an estimator is likely to make a wrong decision, we can always flip its decision as our decision.
