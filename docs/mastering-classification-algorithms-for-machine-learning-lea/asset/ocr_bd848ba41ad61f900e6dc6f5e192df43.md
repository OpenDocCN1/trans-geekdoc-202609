# Naïve Bayes Algorithm

So, by the total probability theorem,

P(Problem) = P(Problem|McAfee) * P(McAfee) + P(Problem|NoMcAfee) * P(noMcAfee) = 1 / 10 * 1/3 + 1 / 20 * 2 / 3 = 1 / 30 + 1 / 30 = 2 / 30

So, by Bayes, the probability of the McAfee software is the cause of the problem = P(McAfee|Problem) = 1/30+1/30=1/2=50%

This Bayes analysis shows that the decision to uninstall the McAfee software from all the servers may not have been the best. Instead, could have isolated that server and analyzed it.
