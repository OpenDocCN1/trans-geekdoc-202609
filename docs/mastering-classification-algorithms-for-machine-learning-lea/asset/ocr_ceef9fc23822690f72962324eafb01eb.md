# Cleaning the data

During the EXIF, I found that JPEG files containing malware can contain chr(0) in the EXIF Tags. chr(0) or ASCII character 0 is the end of the file indicator. When any program encounters chr(0), it stops reading further information. So, removing all the chr(0) from the data is required.

```

```

0].replace(chr(0), ' '')
