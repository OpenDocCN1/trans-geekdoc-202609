We will make many decision stumps when we create a model using the AdaBoost algorithm. Let us say that we create n decision stumps. Then, we will have an alpha for each decision stump. Let us call the alpha for the $k^{th}$ decision stump as $\alpha_k$. Also, let us call the prediction from the $k^{th}$ decision stump for a new data point $p_k$. Then,

$$\tilde{y} = \sum_{k=1}^{n}(\alpha_k * p_k).$$
