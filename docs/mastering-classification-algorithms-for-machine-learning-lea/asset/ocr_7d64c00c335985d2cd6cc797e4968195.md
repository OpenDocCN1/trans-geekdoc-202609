We get as follows for computing the Entropy for the dataset on the left-hand side of the split.

```
$p_0 = \frac{2}{4} = 0.5 \text{ and } p_1 = \frac{2}{4} = 0.5$
```

Using these values of $p_0$ and $p_1$, we calculate the Entropy for the dataset on the left-hand side of the split as follows.

```
$Entropyleft = - ((0.5 * log_2(0.5)) + (0.5 * log_2(0.5))) = - ((0.5 * (-1.0)) + (0.5 * (-1.0))\n= - ((-0.5) + (-0.5)) = 1$
```

Similarly, we calculate the Entropy of the dataset on the right-hand side of the split as follows.

```
$p_0 = \frac{3}{6} = 0.5 \text{ and } p_1 = \frac{3}{6} = 0.5$
```

```
$Entropyright = - ((0.5 * log_2(0.5)) + (0.5 * log_2(0.5))) = - ((0.5 * (-1.0)) + (0.5 * (-1.0))\n= - ((-0.5) + (-0.5)) = 1$
```

Having computed the Entropy at the left-hand and right-hand sides of the split, we calculate the weighted average of the Entropy at this decision node. Note that on the left-hand side of the split, we have 4 data points, and on the right-hand side of the split, we have 6 data points. So as follows:

```
$Entropy.0 = (\frac{4}{10} * 1.0) + (\frac{6}{10} * 1.0) = 0.4 + 0.6 = 1.0$
```
