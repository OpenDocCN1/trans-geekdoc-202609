ax.axline(y = 0.5, c = 'black', linestyle = "dashed")

The significant thing to notice in Figure 4.11 is that $p$ and $(1-p)$ crosses each other at $y=0.5$. This will be the case no matter what data we provide to build the model (Also, this is the case when we have more than one independent variable). If we draw a vertical line at the point where $p$ and $(1-p)$ crosses, like the red dashed line in Figure 4.10, we get the decision boundary. The decision is that for any value of $x_i>$ decision boundary, the prediction will be class 1. And for any value of $x_i \le=$ decision boundary, the prediction will be class 0.

Using the following code, we can find the precise value of $x_i$ where we have the decision boundary.

```
import numpy as np

threshold = 0.0005
nums = np.arange(40.0, 50.0, 0.1)
for x in nums:
    S = s.eval(subs = {a0:testList[-2]['a0'], a1:testList[-2]['a1'], x1:x})
    if abs(S - 0.5) < threshold:
        print("X1 =", x, " Sigmoid =", S)
```
