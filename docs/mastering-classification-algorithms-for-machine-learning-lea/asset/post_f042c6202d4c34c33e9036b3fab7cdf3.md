# Understanding Gini index

Gini index is the measure of the impurity of a dataset.

Mathematically, Gini index is stated as.

> $Gini(t) = 1 - \sum P(i|t)^2$

Where $i$ is all the unique classes in the dataset, and $t$ varies from 1 to the total number of classes in the dataset. $P(i|t)$ is the probability of class $i$ occurring given $t$.

For example, in the dataset shown in Table 5.1, the unique classes are 0 and 1. So, for calculating Gini index, i would have values 0 and 1. In this case, $i$ varies from 1 to 2.

For example, we consider the dataset as given in Table 5.1 (we will call this dataset $d1$). As there are two classes in the data, the Gini index would be calculated as

> $Gini(d1) = 1 - (P(0|d1)^2 + P(1|d1)^2)$

In dataset $d1$, we see 10 data points. 5 are for class 0, and 5 are for class 1. So:

$$P(0|d1) = 5/10 = 0.5$$

$$P(1|d1) = 5/10 = 0.5$$

So, Gini index for dataset $d1 = 1 - (0.5^2 + 0.5^2) = 1 - (0.25 + 0.25) = 1 - 0.5 = 0.5$

Notice that the term $\sum P(i|t)^2$ varies from 0 to 1. This is because probability can assume a value between 0 and 1. The term $\sum P(i|t)^2$ is a sum of probabilities of all classes in a space. So, the extreme scenario is that only one class occurs in the dataset; its probability would be 1, and all other classes have a probability of 0. In this case, $\sum P(i|t)^2$ would be 1. A Gini index of 0 implies the dataset is perfectly pure. A Gini index of 1 means the dataset is randomly distributed. A Gini index of 0.5 indicates that all classes in the dataset are equally represented.

# Forming the decision tree using CART

Let us first go through the mechanics of forming the decision tree using the CART algorithm.

1. We calculate Gini index of the dataset. If Gini index of the dataset is 0, then the dataset is pure and needs not do anything else.
2. If Gini index of the dataset in step 1 is not 0, we decide possible points from our dataset where a decision can be made. We analyze the independent variables and make a list of values from the data.
3. We calculate the loss for each of the thresholds in step 2.
4. From the loss calculated in step 3, which is the minimum, we decide the data point where we would split.
5. From step 4, we get two datasets (as CART forms binary trees). We repeat all the steps.

So, now we need to establish a loss function $(J)$ for the algorithm used in CART as follows:

$$J = \frac{m_{left}Gini(left) + m_{right}Gini(right)}{m}$$

To form a decision tree using CART, we can find points where the data can split into two branches. The dataset on the left-hand side of the split is represented in the loss function as left, and the dataset on the right-hand side of the split is defined in the loss function as right. $m_{left}$ is the number of data points on the left-hand side of the split, and $m_{right}$ is the number of data points on the right-hand side of the split. $Gini(left)$ is the dataset's Gini index on the split's left-hand side, and $Gini(right)$ is the dataset's Gini index on the split's right-hand side. $m$ is the total number of points in the complete dataset, so $m = m_{left} + m_{right}$.

The technique establishes a list of data points from the feature variables where we evaluate the split where the loss is the minimum to split the data. To make the decision tree, we need to try various points for the features $x_1$ and $x_2$ where we can split the decision. So, we compute possible values of $x_1$ and $x_2$ where there could be a split. We will understand this concept using the data we have in Table 5.1.

To compute different values of $x_1$, we consider the range from the minimum value of $x_1$ to the maximum value of $x_1$. Then, we take points at equal intervals in this range. We find that $minimum(x_1) = 1$ and $maximum(x_1) = 7$. To avoid edge conditions, we will consider the upper limit of the range as $maximum(x_1) + 1$. So, the range for $x_1$ is 1 to 8. We will consider intervals of 0.5 in our range. So, the values of $x_1$ that we will try to use for splitting the decision are as follows:

1.00, 1.50, 2.00, 2.50, 3.00, 3.50, 4.00, 4.50, 5.00, 5.50, 6.00, 6.50, 7.00, 7.50

Similarly, we consider the points of the variable $x_2$ for splitting the decision. We see that the $minimum(x_2) = 2$ and $maximum(x_2) = 7$. So, the range for $x_2$ is 2 to 8. The values of $x_2$ that we will try to use for splitting the decision are as follows:

2.00, 2.50, 3.00, 3.50, 4.00, 4.50, 5.00, 5.50, 6.00, 6.50, 7.00, 7.50

The points we will consider for splitting the decision tree are called **thresholds**.

# Decision Tree Algorithm

Let us compute the loss for the threshold $x_1 = 1.00$. So, we split the dataset for $x_1 \le 1.00$, then the dataset on the left-hand side of the split and the dataset on the right-hand side of the split would look as shown in Table 5.2:

| $x_1 \le 1.00$ | $x_2$ | $y$ | $x_1 > 1.00$ | $x_2$ | $y$ |
|---|---|---|---|---|---|
| 1 | 4 | 0 | 7 | 6 | 0 |
| 1 | 6 | 0 | 5 | 2 | 1 |
| 1 | 2 | 1 | 7 | 2 | 1 |
| 1 | 7 | 1 | 5 | 4 | 0 |
| 2 | 4 | 0 | 2 | 7 | 1 |

**Table 5.2:** The split for $x_1 \le 1.00$

From Table 5.2, we get that the number of data points on the left-hand side of the split is four, and thus, $m_{left} = 4$. Similarly, we get that $m_{right} = 6$. Also, we get that $m = 10$. We must calculate $Gini(left)$ and $Gini(right)$.

To calculate $Gini(left)$, we get the following from 5.2:

$$P(0|left) = 2/4 = 0.5$$
$$P(1|left) = 2/4 = 0.5$$

So, $Gini(left) = 1 - (0.5^2 + 0.5^2) = 1 - (0.25 + 0.25) = 1 - 0.5 = 0.5$

To calculate $Gini(right)$, we get the following from 5.2:

$$P(0|right) = 3/6 = 0.5$$
$$P(1|right) = 3/6 = 0.5$$

So, $Gini(right) = 1 - (0.5^2 + 0.5^2) = 1 - (0.25 + 0.25) = 1 - 0.5 = 0.5$

Now, we can calculate the loss at the threshold $x_1 = 1.00$.

$$J(x_1=1.00) = \frac{4*0.5+6*0.5}{10} = \frac{2+3}{10} = \frac{5}{10}=0.5$$
