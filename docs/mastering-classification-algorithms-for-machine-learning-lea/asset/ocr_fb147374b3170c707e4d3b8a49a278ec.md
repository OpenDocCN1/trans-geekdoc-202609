At the end of this step, we used the pickle library to save the variable featureList to a file. This is so we can load this object from the file instead of computing it again. You would be aware that ELF Files are stored on the disk, and disk Input/Output (I/O) always has higher latency than reading from memory. So, saving the featureList to a file, we can read just one file and get the list of all features instead of reading all input ELF files.
