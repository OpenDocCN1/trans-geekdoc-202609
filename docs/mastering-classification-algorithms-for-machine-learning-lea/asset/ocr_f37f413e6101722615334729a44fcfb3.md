# Cost function for Logistic Regression algorithm

Unlike the Linear Regression algorithm, we cannot use a measure like the MSE as the Cost Function for the Logistic Regression algorithm. We will need to engineer a cost function such that we get a measure of whether we are making a binary classification accurately. Once we establish the cost function, we can apply the gradient descent algorithm to minimize the cost function to obtain the optimum model.

We now know that the prediction for a data point is as follows:

```
$$\sigma(y_i) = \frac{1}{1 + e^{-Y_i}} = \frac{1}{1 + e^{-(a_0 + a_1x_1 + \dots + a_nx_{n_l})}}$
```

Let us call $\sigma(y_j)$ as $(p_j)$. So, we get as follows:

```
$$p_i = \sigma(y_i) = \frac{1}{1 + e^{-Y_i}} = \frac{1}{1 + e^{-(a_0 + a_1x_1 + \dots + a_nx_{n_l})}}$
```

The cost function for the Logistic Regression algorithm is given as follows:

```
$$J = -log(p_i)$, if $y_i = 1$\n-log(1 - p_i)$, if $y_i = 0$
```

Let us understand this cost function. We note that probability can only take a value between 0 and 1. So, $(p)$ and $(1-p)$ are close to 0 and 1. So, $log(x)$ is always a negative number when $0 < x < 1$. So, when $log(x)$ is a negative number, $-log(x)$ will always be between 0 and 1. It is a positive number. So, the first thing to note is that the cost function for the Logistic Regression algorithm will always output a positive number.

Next, if $i = 1$ and $p$ is close to 0, then $J = -log(p)$ is close to 0 as $log(1) = 0$. This means that if the actual class is 1 and my prediction shows a higher probability of the class being 1, we will attach a minimal cost. If $i = 1$ and $p$ is close to 0, then $J = -log(p)$ is a large number. This means if the actual class is 1 and my prediction shows a lower probability of the class being 1, we will attach a very high cost.

Similarly, if $y = 0$ and $p$ is close to 0 (or $(1-p)$ is close to 1), then $J = -log(1-p)$ is close to 0 as $log(1) = 0$. This means that if the actual class is 0 and my prediction shows a higher probability of the class 0, we will attach a minimal cost. If $y_i = 0$ and $p_i$ is close to 1 (or $(1-p)$ is a large number), then $J = -log(1-p)$ is a large number. This means that if the actual class is 0 and my prediction shows a lower probability of the class being 0, we will attach a very high cost.
