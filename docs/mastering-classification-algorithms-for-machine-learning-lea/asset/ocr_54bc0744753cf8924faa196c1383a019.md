# Number of times the term appears in the Document
Total number of Terms in the Document

For example, in Table Annexex 6.1, the first document (Document ID = 1) has 12
terms, and "Ice" appears twice in the document. So, the Term Frequency (TF) of
t term "Ice" in the first document is TF = 2/12

Inverse Document Frequency (IDF) measures the term’s importance in the corpus.
The formula for calculating IDF is as follows:

```
IDF = log(Total number of Documents in the corpus
Number of documents containing the term)
```

Let us take two examples. First, let us calculate the IDF for the term "ice". The total
number of documents in our corpus (as the dataset in Table Annexex 6.1) is 2.
The number of documents containing the term "ice" is 2. IDF=log(2)/2=log(1)
=0.

Next, let us take the term "parlor". The total number of documents is 2. The number
of documents containing the term "parlor" is 1. So, IDFparlor=log(2)/2=log(2)=0.3010.
Notice if a term appears in more documents, the IDF for that term is smaller.

The TF-IDF for a term is calculated as the product of the TF for the term and the IDF
for the term. For example, TF-IDF = TF * IDF=2/12 * 0 = 0.

The TF-IDF value for a term is always a number between 0 and 1. As a result,
tTF-IDF values do not need to be scaled.

TF-IDF vectorizer is implemented in the Scikit-Learn package in the library sklearn.feature_extraction.text. TfidfVectorizer.
