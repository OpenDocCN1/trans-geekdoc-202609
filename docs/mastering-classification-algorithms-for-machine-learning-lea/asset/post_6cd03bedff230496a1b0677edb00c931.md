## About JPEG files

JPEG is the acronym for Joint Photographic Experts, which developed this standard for storing digital photographs in 1992. JPEG stores digital images in a compressed format. We will not get into the format of the JPEG Files in this chapter as we focus on machine learning. However, it is essential to note that in 2010 JPEG included EXIF Tags which enabled adding additional information about the images. A significant thing about EXIF Tags is that most of them can be altered using suitable software. One of the ways to remove malware from JPEG Files is to convert the JPEG Files to Bitmap (also called BMP Files). BMP Files only store the image information and do not carry any EXIF Tags. In summary, we analyze EXIF Tags in JPEG Files to determine whether the File is clean or malicious.

We will write a function named JPEGFeatureExtractorToDictionary() to read a JPEG file and extract all the EXIF Tags in the JPEG File. The function returns a dictionary where the keys are the name of the EXIF Tag, and the associated values are the values of the EXIF Tags as present in the JPEG File.

```python
from PIL import Image
from PIL.ExifTags import TAGS

def JPEGFeatureExtractorToDictionary(imageFile):
    # Declare an empty Dictionary
    returnValue = {}

    # read the image data using PIL
    image = Image.open(imageFile)

    # extract EXIF data
    exifdata = image.getexif()

    # iterating over all EXIF data fields
    for tag_id in exifdata:
        # get the tag name
        tag = TAGS.get(tag_id, tag_id)
        data = exifdata.get(tag_id)
        # decode bytes
        if isinstance(data, bytes):
            data = data.decode('iso8859-1')

        returnValue[tag] = data
```
