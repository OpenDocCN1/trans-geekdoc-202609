# Entropy

The concept of Entropy has been taken from Physics. Like in Physics, Entropy is a measure of randomness in an environment. When discussing data, here Entropy refers to the amount of randomness available in the data. Entropy can take a value between 0 and 1. If the Entropy value for a dataset is 1, it implies that the dataset is entirely random. If the Entropy value for a dataset is 0, it means that the dataset is pure.

The formula used to calculate Entropy is as follows.

```
Entropy = -\sum_{i=1}^{n}(p_i \log_2(p_i))
```

Here, i refer to the number of unique classes in the datasets and varies from 1 to n, meaning that the dataset has n classes. $p_i$ is the probability of the availability of class i in the dataset.

To understand, suppose a dataset has two classes, 0 and 1. Suppose this dataset has three elements of class 0 and 7 of class 1. Then, the probability of availability of class 0 in this dataset is given as $p_0 = 3/10 = 0.3$. And the probability of availability of class 1 in this dataset is given as $p_1 = 7/10 = 0.7$. So, under this circumstance, the value of Entropy is calculated as follows:

> $Entropy = ((0.3 * \log_2(0.3)) + (0.7 * \log_2(0.7))) = ((0.3 * (-1.737)) + (0.7 * (-0.515)) = -(-0.521) + (-0.360)) = (-0.881)$

Note: Probability is always a value between 0 and 1. Now, $log_2(1) = 0$. $log_2(x)$ where $0 < x < 1$ is a negative quantity.

As the term $(p_i * \log_2(p_i))$ will always return a negative value, calculate Entropy as the negative value of all the $(p_i * \log_2(p_i))$ terms. This way we will get a positive value for Entropy between 0 and 1.

Also, note that $log_2(0)$ is infinity. So, we consider $(0 * \log_2(0)) = 0$ as by convention $(y * \log_2(y))$ tends to 0 as $y$ tends to 0.

If the dataset has an equal number of elements for all classes, like the dataset has five elements of class 0 and 5 elements of class 1, then Entropy is shown below. So, $p_0 = 5/10 = 0.5$ and $p_1 = 5/10 = 0.5$.

```
$Entropy = ((0.5 * \log_2(0.5)) + (0.5 * \log_2(0.5))) = ((0.5 * (-1.0)) + (0.5 * (-1.0)) = -(-0.5) + (-0.5)) = -1$
```
