
在本例中，我们在调用 `greet` 函数时显式指定了参数名 `name` 和 `message`。这提高了代码的可读性，特别是在函数拥有许多参数或复杂的参数顺序时。

### 2.3.3. 命名参数的优势

命名参数提供了多项优势：

*   **清晰性**：命名参数通过显式指示每个参数的用途，使函数调用更加不言自明。
*   **灵活性**：你可以按任意顺序提供参数，这在函数拥有可选参数或大量参数时特别有用。
*   **可读性**：代码变得更具可读性和可维护性，特别是对于参数众多的函数。你无需记住确切的顺序；只需查看参数名即可。
*   **避免错误**：命名参数有助于防止意外地将错误的值传递给参数，从而减少潜在的 Bug。

### 2.3.4. 组合使用命名参数和位置参数

PHP 8 允许你在函数调用中混合使用命名参数和位置参数。但是，位置参数必须位于命名参数之前。以下是一个示例：

```
function greetUser(string $name, string $message, string $greeting = "Hello") {
    echo "$greeting, $name! $message";
}

// 使用位置参数和命名参数
greetUser("Alice", "How are you?", greeting: "Hi");
```

在本例中，我们首先对 `$name` 和 `$message` 参数使用位置参数，随后对 `$greeting` 参数使用命名参数。这种灵活性使你能够根据特定需求调整函数调用。

### 2.3.5. 默认值与命名参数

使用命名参数时，你可以轻松覆盖默认参数值。如果参数有默认值，你可以使用命名参数为该参数指定不同的值。当你想对某些参数使用默认值但更改其他参数时，这特别有用。

```
function sendMessage(string $recipient, string $message, bool $urgent = false) {
    // 使用指定的紧急程度发送消息
}

// 使用命名参数发送紧急消息
sendMessage(recipient: "Bob", message: "Meeting canceled", urgent: true);

// 使用默认紧急程度发送非紧急消息
sendMessage(recipient: "Alice", message: "See you at 2 PM");
```

### 2.3.6. 最佳实践

虽然命名参数增强了代码的可读性和灵活性，但必须审慎使用：

*   将命名参数保留用于参数数量显著、具有可选参数或参数顺序复杂的函数。
*   命名参数时，请使用描述性强且有意义的名称，以阐明其用途。
*   在整个代码库中遵循一致的命名约定，以确保可读性和可维护性。

命名参数是 PHP 8 的一项宝贵补充，使你的代码更具表现力且更易于理解。它们为函数调用提供了更大的灵活性，并在处理具有许多参数或可选参数的函数时有助于防止错误。

## 2.4. PHP 8 中的属性：语法与用法

PHP 8 引入了属性，它提供了一种向类、函数、属性等添加元数据或注解的方式。在本节中，我们将探讨 PHP 8 中属性的语法和用法，在其他编程语言中也称为注解。

### 2.4.1. 什么是属性？

属性在其他语言中常被称为注解，是一种向代码元素附加额外信息的方式。它们提供了一种标准化且结构化的方式来标记代码，用于各种目的，如文档生成、验证或框架特定的功能。

属性包含在方括号 `[]` 中，并放置在它们所注解的代码元素之前。它们由一个名称组成，并可选择性地包含括号中的参数。

### 2.4.2. 创建自定义属性

你可以在 PHP 8 中通过定义一个类并使用 `#[Attribute]` 属性对其进行标记来创建自定义属性。该类可以拥有属性、构造函数和方法，以提供属性的功能。以下是一个自定义属性的示例：

```
#[Attribute]
class MyCustomAttribute {
    public function __construct(string $value) {
        $this->value = $value;
    }

    public function getValue(): string {
        return $this->value;
    }
}
```

在本例中，`MyCustomAttribute` 是一个接受单个字符串参数的自定义属性。你可以使用此属性来注解代码元素，并将它们与特定值关联。

### 2.4.3. 应用属性

属性可应用于各种代码元素，包括类、方法、属性、参数和函数声明。以下是如何将 `MyCustomAttribute` 应用于类和方法：

```
#[MyCustomAttribute("Class annotation")]
class MyClass {
    #[MyCustomAttribute("Method annotation")]
    public function myMethod() {
        // 方法逻辑
    }
}
```

在本例中，`MyCustomAttribute` 同时应用于 `MyClass` 类和 `myMethod` 方法，但具有不同的注解值。

### 2.4.4. 访问属性值

你可以使用反射来访问应用于代码元素的属性值。PHP 提供了 `ReflectionAttribute` 类来实现此目的。以下是检索和使用属性值的方法：

```
$reflectionClass = new ReflectionClass(MyClass::class);
$classAttributes = $reflectionClass->getAttributes(MyCustomAttribute::class);

foreach ($classAttributes as $attribute) {
    $attributeInstance = $attribute->newInstance();
    echo $attributeInstance->getValue(); // 输出: Class annotation
}

$reflectionMethod = new ReflectionMethod(MyClass::class, 'myMethod');
$methodAttributes = $reflectionMethod->getAttributes(MyCustomAttribute::class);

foreach ($methodAttributes as $attribute) {
    $attributeInstance = $attribute->newInstance();
    echo $attributeInstance->getValue(); // 输出: Method annotation
}
```

在这段代码中，我们使用反射来检索应用于 `MyClass` 类和 `myMethod` 方法的属性。然后我们创建属性类的实例并访问它们的值。

### 2.4.5. 内置属性

PHP 8 包含多个内置属性，为各种目的提供功能。示例包括：

*   `#[Deprecated]`：将代码标记为已弃用，提供一种指示函数或类不应再被使用的方式。
*   `#[SuppressWarnings]`：抑制 PHP 生成的特定警告或错误。
*   `#[ReturnTypeWillChange]`：指示函数的返回类型将来可能会发生变化。

这些内置属性有助于提高代码质量、可维护性和文档化程度。

### 2.4.6. 框架与库集成

属性在 PHP 框架和库中特别有用。它们提供了一种结构化的方式来定义路由、中间件、验证规则等。Symfony、Laravel 和 Doctrine ORM 等框架广泛使用属性来提高开发人员的生产力和代码可读性。

总之，PHP 8 中的属性提供了一种标准化且结构化的方式，用于使用元数据和注解来标注代码元素。你可以为特定用例创建自定义属性，或利用内置属性处理常见场景。属性是 PHP 功能集的宝贵补充，增强了代码文档、质量以及与框架和库的集成。

## 2.5. Match 表达式：一种新的控制结构

PHP 8 引入了 match 表达式，这是一种用于处理条件逻辑的多功能且强大的控制结构。在本节中，我们将探讨 match 表达式的语法和用法，并了解它们与传统 switch 语句的区别。

### 2.5.1. 什么是 Match 表达式？
