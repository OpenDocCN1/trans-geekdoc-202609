PHP 8 introduces several functions for converting strings between different formats, such as converting a string to uppercase or lowercase.

## 6.3. Using the `str_contains`, `str_starts_with`, and `str_ends_with` Functions

PHP 8 introduces three handy string functions: `str_contains()`, `str_starts_with()`, and `str_ends_with()`, which provide efficient ways to check for substring containment, prefix, and suffix in strings. These functions are valuable for simplifying code and improving performance when working with strings.

### 6.3.1. `str_contains()`

The `str_contains()` function checks if a string contains a specified substring. It returns `true` if the substring is found, and `false` if it is not present.

```php
$text = 'This is a sample text.';
$substring = 'sample';

if (str_contains($text, $substring)) {
    echo 'Substring found!';
} else {
    echo 'Substring not found.';
}
```

In this example, `str_contains()` returns `true` because the word 'sample' exists within the given string.

### 6.3.2. `str_starts_with()`

The `str_starts_with()` function verifies if a string starts with a specified prefix. It returns `true` if the string begins with the prefix, and `false` otherwise.

```php
$text = 'Hello, world!';
$prefix = 'Hello';

if (str_starts_with($text, $prefix)) {
    echo 'String starts with the prefix!';
} else {
    echo 'String does not start with the prefix.';
}
```
