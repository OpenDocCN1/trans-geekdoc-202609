

# PHP 8 历史与环境搭建

## PHP 版本演进

PHP 历史上最重要的里程碑之一是 2004 年发布的 PHP 5。PHP 5 引入了健壮的 OOP 模型、异常处理，以及对 XML 和 Web 服务的增强支持。这些特性提升了 PHP 的能力，使其成为开发复杂 Web 应用的有力竞争者。

随着 PHP 5 的成功，PHP 6 计划包含原生 Unicode 改进和国际化支持。然而，PHP 6 的开发面临挑战和延期，最终被放弃。因此，PHP 6 从未正式发布。

取而代之的是，PHP 社区将重心转移到 PHP 7，后者于 2015 年发布。PHP 7 带来了显著的性能提升，使应用运行更快且资源占用更少。它还引入了新的语言特性和类型声明，增强了代码的可靠性和可维护性。

如今，我们迎来了 PHP 8 —— PHP 的最新主要版本。PHP 8 建立在前几个版本奠定的基础之上，引入了一系列新特性、性能增强以及类型系统的改进。本书将深入探讨 PHP 8 的能力，助你在 Web 开发项目中发挥其威力。

敬请期待，我们将探索 PHP 8 的精彩世界，发掘它如何将你的 Web 开发技能和项目推向新高度。

## 1.2 PHP 8 概览：关键特性与增强

PHP 8 引入了大量令人振奋的特性和增强，强化了语言的能力、性能和可维护性。本节将深入探讨使 PHP 8 成为语言演进重要里程碑的关键特性。

### 1. JIT 编译器

或许是 PHP 8 最令人期待的特性即即时编译器。JIT 编译器通过将 PHP 字节码动态翻译为机器码，提升脚本执行性能。这使得执行时间更短，让 PHP 8 在 CPU 密集型任务上效率大幅提高。

### 2. 联合类型

PHP 8 引入对联合类型的支持，允许变量或参数接受多种数据类型的值。例如，你可以指定函数参数同时接受 `int` 和 `float`，这为函数签名提供了更大灵活性，并改进了类型安全。

```php
function calculateSum(int|float $a, int|float $b): int|float {
    return $a + $b;
}
```

### 3. 命名参数

命名参数允许你通过参数名指定实参，使函数调用更具可读性和灵活性。该特性增强了代码清晰度，尤其适用于参数众多的函数。

```php
function createPerson(string $name, int $age) {
    // Function logic
}

// 使用命名参数
createPerson(age: 30, name: "John");
```

### 4. 属性

属性（也称注解）为类、函数和属性添加元数据提供了标准化方式。这对依赖注解进行配置和行为定义的框架和库特别有用。

```php
#[Route("/dashboard", methods: ["GET"])]
class DashboardController {
    // Controller logic
}
```

### 5. `match` 表达式

PHP 8 引入 `match` 表达式，它是 `switch` 语句的更健壮替代品。它允许更具表现力且不易出错的值匹配，简化了复杂的条件逻辑。

```php
$status = getStatus();
$result = match($status) {
    'success' => 'Operation was successful',
    'error'   => 'An error occurred',
    default   => 'Unknown status',
};
```

### 6. 构造函数属性提升

PHP 8 通过构造函数属性提升简化了类定义。它允许在构造函数参数列表中直接声明并初始化类属性，减少了样板代码。

```php
class User {
    public function __construct(
        public string $name,
        public string $email,
        private int $id = 0
    ) {}
}
```

### 7. `static` 返回类型

PHP 8 引入为方法指定 `static` 返回类型的能力。这对工厂方法和返回当前类实例的方法特别有用。

```php
class Logger {
    public static function getInstance(): static {
        // 返回当前类的实例
        return new static();
    }
}
```

### 8. 空安全运算符

空安全运算符 (`?->`) 简化了在访问对象属性或调用方法时对 `null` 值的处理。它通过优雅地处理 `null` 值来防止“空引用”错误。

```php
$company = $user?->getProfile()?->getCompany()?->getName();
```

以上仅是 PHP 8 特性和增强的部分亮点。随着阅读深入，你将更详细地探索这些主题，并学习如何在 PHP 开发项目中有效利用它们。PHP 8 为开发者提供了更多工具和选择，是 PHP 社区令人振奋的升级。

## 1.3 搭建 PHP 8 环境

在开始使用 PHP 8 之前，必须搭建开发环境。本节将指导你在本地机器上启动并运行 PHP 8。

### 1.3.1 PHP 安装

使用 PHP 8 需要在系统上安装它。安装过程可能因操作系统而异。

#### Windows

1.  从 PHP 官网下载最新的 PHP 8 Windows 安装程序（<https://windows.php.net/download/>）。
2.  运行安装程序并遵循安装向导说明。
3.  安装完成后，打开命令提示符或 PowerShell，运行 `php -v` 验证 PHP 版本。

#### macOS

1.  macOS 预装了 PHP，但建议使用 Homebrew 安装 PHP 8 以便更好地管理版本。
2.  打开终端并运行以下命令：
    ```bash
    brew update
    brew install php
    ```
3.  安装后，使用 `php -v` 检查 PHP 版本。

#### Linux (Ubuntu/Debian)

1.  打开终端并运行以下命令安装 PHP 8：
    ```bash
    sudo apt update
    sudo apt install php8.0
    ```
2.  使用 `php -v` 验证安装。

### 1.3.2 开发环境

编写和测试 PHP 代码需要文本编辑器或集成开发环境 (IDE)。常用选择包括 `Visual Studio Code`、`PHPStorm` 和 `Sublime Text`。根据偏好和需求选择最适合的一款。

### 1.3.3 Web 服务器

Web 开发需要 Web 服务器来服务 PHP 文件。你有以下几种选择：

-   **Apache**：广泛使用的 Web 服务器，与 PHP 配合良好。可单独安装 Apache，或使用 `XAMPP`、`WampServer` 等预打包方案。
-   **Nginx**：以性能著称的强大 Web 服务器。可配置 Nginx 通过 `FastCGI` 与 PHP 协作。
-   **PHP 内置开发服务器**：PHP 8 包含用于开发的内置 Web 服务器。可在项目目录下通过命令行启动：`php -S localhost:8000`。

### 1.3.4 数据库服务器

如果 PHP 应用需要数据库访问，可考虑安装 `MySQL`、`PostgreSQL` 或 `SQLite` 等数据库服务器。同时需要数据库管理工具（如 `phpMyAdmin` 或 `DBeaver`）与数据库交互。

### 1.3.5 Composer（可选）

`Composer` 是 PHP 的依赖管理器，简化了包管理。强烈建议在 PHP 项目中使用它管理第三方库和框架。安装方法请参考 Composer 官网（<https://getcomposer.org/download/>）。

### 1.3.6 IDE 配置（可选）

如果使用 `Visual Studio Code` 或 `PHPStorm` 等 IDE，可通过安装 PHP 扩展和配置 PHP 8 支持设置来提升开发体验。

完成上述步骤后，你的 PHP 8 开发环境即已就绪。你可以开始编写 PHP 代码、创建 Web 应用，并探索 PHP 8 引入的新特性与改进。
