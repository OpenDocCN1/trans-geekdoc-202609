

非捕获捕获提供了一个更优雅的解决方案。你可以使用下划线（`_`）来表明你不想捕获异常对象，而不必将异常赋值给变量。这使你的代码更整洁，并消除了声明未使用变量的需要。

try {

### 8.2.1. 非捕获捕获的优势

使用非捕获捕获有以下几个优势：

1.  **提高代码清晰度**：非捕获捕获明确表明你对异常对象不感兴趣，减少了代码中不必要的杂乱。
2.  **降低认知负荷**：通过省略变量赋值，你使开发者更容易专注于实际的异常处理逻辑。
3.  **消除未使用变量**：非捕获捕获防止了未使用变量的创建，这在代码质量和可维护性方面可能是一个问题。
4.  **增强可读性**：catch 块中没有变量名使代码更简洁、更易读，提高了整体代码质量。
5.  **强制最佳实践**：使用非捕获捕获鼓励异常处理中的最佳实践，强调了在没有不必要变量干扰的情况下进行适当错误处理的重要性。

### 8.2.2. 何时使用非捕获捕获

非捕获捕获在以下场景中特别有用：

*   当你想记录异常日志，但不需要异常对象时。
*   当你有不依赖特定异常类型的通用异常处理逻辑时。
*   当你想强调异常正在被处理，但异常对象本身对当前上下文不重要时。

以下示例演示了在日志记录场景中使用非捕获捕获：

在这个例子中，我们对异常对象本身不感兴趣；我们只是想根据异常类型记录适当的消息。

总之，当你不需要在 catch 块中捕获和使用异常对象时，PHP 8 的非捕获捕获提供了一种更整洁、更简洁的异常处理方式。此功能增强了代码可读性，并鼓励异常处理中的最佳实践。考虑在你的 PHP 8 项目中采用它，以实现更优雅和可维护的错误处理。

## 8.3. 探索用于异步编程的 Fiber

异步编程是一种提高 PHP 应用程序性能和响应能力的强大技术。它允许你并发执行多个任务，而不会阻塞主执行线程。PHP 8 引入了 Fiber（纤程），这是一种用于编写异步代码的轻量级高效机制。

### 8.3.1. 理解异步编程

在深入了解 Fiber 之前，让我们简要了解一下异步编程的概念。在传统的同步编程中，任务是按顺序依次执行的。如果一个任务需要很长时间才能完成，它会阻塞整个应用程序，使其无响应。

另一方面，异步编程允许你启动任务并继续执行其他代码，而无需等待任务完成。当任务完成时，会执行回调，允许你处理结果。这种非阻塞方法对于 I/O 密集型操作特别有益，例如网络请求或数据库查询，因为等待响应是低效的。

### 8.3.2. Fiber 简介

Fiber 是一种轻量级、协作式多任务处理形式。与由操作系统管理且可能资源密集的线程或进程不同，Fiber 由 PHP 运行时管理，更加轻量。

Fiber 本质上是在单个 PHP 进程内的一个独立执行上下文。你可以把它想象成一个轻量级线程，当它在等待某些事情（例如 I/O 操作）完成时，会协作式地将控制权交还给主程序。

### 8.3.3. 创建和使用 Fiber

要在 PHP 8 中创建和使用 Fiber，你需要使用 `Fiber` 类。以下是创建 Fiber 并异步执行它的基本示例：

```
$fiber = new Fiber(function () {

echo "Fiber started\n";

Fiber::yield();

echo "Fiber resumed\n";

});

echo "Main program started\n";

$fiber->start();

echo "Main program resumed\n";
```

在这个例子中，我们用一个闭包创建了一个 Fiber，并使用 `Fiber::yield()` 将控制权交还给主程序。当 Fiber 启动时，打印“Fiber started”，当它恢复时，打印“Fiber resumed”。

### 8.3.4. 处理异步任务

Fiber 可用于处理异步任务，例如并发发起多个 HTTP 请求。像 `ext-async` 这样的库提供了用于创建异步任务并使用 Fiber 进行调度的函数和类。

以下是使用 `ext-async` 库进行异步 HTTP 请求的简化示例：

```
$urls = ["https://example.com", "https://example.org"];

$tasks = [];

foreach ($urls as $url) {

$tasks[] = Fiber::async(function () use ($url) {

$response = await file_get_contents($url);

return $response;

});

}

foreach ($tasks as $task) {

$response = $task->join();

echo strlen($response) . " bytes received\n";

}
```

在这个例子中，我们创建了多个 Fiber，每个都异步发起一个 HTTP 请求。当所有任务完成时，我们打印接收到的数据长度。

### 8.3.5. Fiber 的优势

Fiber 为 PHP 中的异步编程提供了几个优势：

1.  **降低开销**：Fiber 比线程或进程更轻量，导致更低的资源开销。
2.  **简化代码**：使用 Fiber 的异步代码通常比复杂的基于回调的方法更直接、更易于理解。
3.  **提高响应能力**：异步代码允许你的应用程序在执行耗时的 I/O 操作时保持响应。
4.  **并行性**：Fiber 使你能够并发执行多个任务，充分利用现代多核处理器。
5.  **同步**：Fiber 可以使用通道进行通信和同步，提供了一种在并发任务之间交换数据的结构化方式。

### 8.3.6. 注意事项和用例

虽然 Fiber 是 PHP 8 的一个宝贵补充，但它们可能不适用于所有场景。在决定是否使用 Fiber 时，请考虑以下因素：

*   **I/O 密集型操作**：Fiber 非常适合 I/O 密集型任务，例如异步发起网络请求或读/写文件。
*   **CPU 密集型操作**：对于 CPU 密集型任务，Fiber 可能不会提供显著优势，因为它们不利用真正的并行性。
*   **库支持**：并非所有 PHP 库和扩展都与 Fiber 兼容。确保你依赖的库支持 Fiber。
*   **复杂性**：异步代码可能比同步代码更复杂，编写和调试难度更大。仔细设计你的异步代码，以避免回调地狱和可维护性问题。

总之，PHP 8 引入的 Fiber 为该语言带来了异步编程能力，允许你编写更高效、响应更快的应用程序。Fiber 特别适用于处理 I/O 密集型任务和简化异步代码。然而，它们需要仔细考虑和设计，以确保在你的 PHP 项目中有效使用。
