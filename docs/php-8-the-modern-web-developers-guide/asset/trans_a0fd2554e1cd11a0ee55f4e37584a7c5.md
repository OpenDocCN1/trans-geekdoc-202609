
# 第 3 章：空值安全运算符

## 3.5.5. 空值安全运算符的优势

空值安全运算符在 PHP 开发中提供了多项优势：

- **代码简化**：它减少了显式空值检查和条件语句的需求，从而产生更整洁、更简洁的代码。
- **错误预防**：该运算符有助于防止“Call to a member function on null”（在 null 上调用成员函数）及类似错误，提高了代码可靠性。
- **可读性提升**：使用空值安全运算符的代码通常更具可读性且更易于理解，因为它明确传达了处理潜在空值的意图。
- **减少样板代码**：它消除了空值检查所需的样板代码，使您的代码库更高效、更易维护。

总之，PHP 8 引入的空值安全运算符（`?->`）是该语言的一项宝贵补充，它简化了对潜在空对象的处理。它简化了代码，降低了出错风险，并增强了代码可读性，使其成为各种 PHP 开发场景中的实用工具，特别是在处理 API 响应、数据库查询和对象组合时。

# 第 4 章：错误处理与异常改进

## 4.1. 理解并利用构造函数属性提升

PHP 8 引入了一项称为**构造函数属性提升**的特性，它简化了在类的构造函数中声明和初始化对象属性的过程。此特性增强了代码可读性，并减少了具有许多属性的类的冗长度。在本节中，我们将探讨构造函数属性提升的概念并演示其用法。

### 4.1.1. 属性初始化的问题

在 PHP 中，当你创建一个具有多个属性的类时，通常需要在类中声明这些属性，在构造函数中初始化它们，并逐个为它们赋值。这可能导致冗长且重复的代码，尤其是在处理拥有许多属性的类时。

请看下面不使用构造函数属性提升的示例：

```php
class User {
    private string $username;
    private string $email;
    private int $age;

    public function __construct(string $username, string $email, int $age) {
        $this->username = $username;
        $this->email = $email;
        $this->age = $age;
    }
}
```

对于拥有大量属性的类，这种方法会变得笨重。构造函数属性提升简化了这一过程。

### 4.1.2. 使用构造函数属性提升

使用构造函数属性提升，你可以直接在构造函数的参数列表中声明并初始化属性。以下是使用构造函数属性提升后的同一个 `User` 类：

```php
class User {
    public function __construct(
        private string $username,
        private string $email,
        private int $age
    ) {}
}
```

在本例中，我们直接在构造函数的参数列表中声明并初始化了属性 `$username`、`$email` 和 `$age`。这种紧凑的语法不仅减少了代码量，还使其更具可读性和可维护性。

### 4.1.3. 构造函数属性提升的优势

构造函数属性提升提供了多项优势：

- **减少样板代码**：它消除了单独声明属性并在构造函数中初始化它们的需要，减少了代码冗余。
- **提高代码可读性**：构造函数属性提升使构造函数参数与属性之间的关系变得显式且更易于理解。
- **简化对象创建**：创建具有许多属性的类的实例时，你可以直接将值传递给构造函数，使对象创建更加简洁。
- **降低出错风险**：由于属性在构造函数内初始化，忘记初始化属性或错误初始化的可能性更小。

### 4.1.4. 使用默认值

你也可以为提升的属性分配默认值：

```php
class User {
    public function __construct(
        private string $username = 'Guest',
        private string $email = '',
        private int $age = 0
    ) {}
}
```

在本例中，如果创建 `User` 对象时未提供 `$username`、`$email` 或 `$age` 的值，将使用默认值。

### 4.1.5. 类型声明与可见性

你可以像传统属性声明一样，对提升的属性应用类型声明和可见性修饰符（`public`、`private`、`protected`）。

### 4.1.6. 兼容性

构造函数属性提升在 PHP 8 及更高版本中可用。如果你需要维护与旧版本 PHP 的兼容性，则需使用传统的属性声明和初始化方法。

### 4.1.7. 何时使用构造函数属性提升

构造函数属性提升在以下情况下特别有用：

- 你拥有具有许多属性的类。
- 你希望提高代码可读性和可维护性。
- 你希望减少属性声明和初始化的冗长度。

总之，构造函数属性提升是 PHP 8 引入的一项宝贵特性，它简化了在构造函数中声明和初始化对象属性的过程。它减少了代码冗余，增强了代码可读性，并改善了整体开发体验，使其成为创建更简洁、更易维护类的便捷工具。

## 4.2. Throw 表达式：新的错误处理机制

PHP 8 引入了 **Throw 表达式**，这是一种抛出异常和处理错误的新的、更简洁的方式。此特性简化了错误处理，并允许你在单行代码中抛出异常，减少了对冗长 `try-catch` 块的需求。在本节中，我们将探讨 Throw 表达式的概念并演示其用法。

### 4.2.1. 抛出异常的传统方式

在之前的 PHP 版本中，当你需要抛出异常时，通常使用 `try-catch` 块来处理错误。例如：

```php
try {
    // 可能抛出异常的代码
    if ($someCondition) {
        throw new MyException('An error occurred.');
    }
} catch (MyException $e) {
    // 处理异常
    echo 'Caught exception: ' . $e->getMessage();
}
```

这种方法要求你编写抛出和捕获代码，这可能导致冗长且杂乱的代码，尤其是对于简单的错误处理场景。

### 4.2.2. 引入 Throw 表达式

PHP 8 引入了 Throw 表达式，它允许你直接在表达式中抛出异常，而无需单独的 `try-catch` 块。其工作原理如下：

```php
$someCondition = true;

// 使用 Throw 表达式
$result = $someCondition ? throw new MyException('An error occurred.') : 'No error occurred.';
```

在本例中，如果 `$someCondition` 为 true，则抛出 `MyException`，程序随即随异常消息终止。如果 `$someCondition` 为 false，则将字符串 'No error occurred.' 赋值给 `$result`。

### 4.2.3. Throw 表达式的优势

Throw 表达式提供了多项优势：

- **简洁性**：它允许你在单行代码中抛出异常，使错误处理更简洁、更具可读性，尤其是对于简单情况。
- **减少嵌套**：你不再需要将抛出代码包裹在 `try-catch` 块中，降低了代码的嵌套层级并提高了其清晰度。
- **更简单的错误消息**：Throw 表达式使你能在抛出异常的同一行代码中直接指定异常消息，从而更容易理解错误原因。
- **改进的流程控制**：借助 Throw 表达式，你可以通过在需要时抛出异常来更自然地控制程序流程，而无需额外的控制结构。
