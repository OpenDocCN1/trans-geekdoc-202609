

## 第 15.3 节：PHP 8 与 Docker：容器化策略

Docker 彻底改变了应用程序的打包、分发和部署方式。PHP 开发人员可以利用 Docker 创建一致且隔离的开发、测试和生产环境。在本节中，我们将探讨如何将 PHP 8 与 Docker 高效结合以实现容器化。

### 1. 理解 Docker

Docker 是一个容器化平台，允许您将应用程序及其依赖项打包到一个称为容器的单元中。容器轻量级、可移植，且能在不同环境中一致运行。Docker 使用容器镜像来创建和运行容器。

### 2. Docker 与 PHP

PHP 开发人员可以从 Docker 中以多种方式获益：

- **一致性**：Docker 确保您的 PHP 应用程序在不同的开发机器和生产服务器上一致运行，减少了“在我机器上能跑”的问题。
- **隔离性**：每个容器都是隔离的，因此您可以在同一主机上运行具有不同配置的多个 PHP 应用程序而不会发生冲突。
- **版本控制**：Docker 镜像可以版本化，允许您指定应用程序所需的确切环境和依赖项。
- **可扩展性**：Docker 容器易于水平扩展，使其适合微服务架构。

### 3. 创建 Docker 化 PHP 应用程序

要创建 Docker 化的 PHP 应用程序，请遵循以下一般步骤：

1.  **安装 Docker**：在您的开发机器以及计划部署 PHP 应用程序的任何服务器上安装 Docker。
2.  **创建 Dockerfile**：在您的 PHP 项目根目录下创建一个 `Dockerfile`。该文件定义了构建应用程序 Docker 镜像的指令。

```dockerfile
# 使用官方 PHP 镜像作为基础镜像
FROM php:8.0-fpm

# 设置容器内的工作目录
WORKDIR /var/www/html

# 将您的 PHP 应用程序代码复制到容器中
COPY . /var/www/html

# 安装 PHP 扩展和依赖项
RUN docker-php-ext-install pdo pdo_mysql

# 暴露 PHP 应用程序将运行的端口
EXPOSE 9000

# 启动 PHP-FPM
CMD ["php-fpm"]
```

3.  **构建 Docker 镜像**：在与 `Dockerfile` 相同的目录下运行以下命令以构建 Docker 镜像：

```bash
docker build -t my-php-app .
```

4.  **运行 Docker 容器**：镜像构建完成后，您可以运行 Docker 容器：

```bash
docker run -d -p 8080:9000 my-php-app
```

此命令运行一个 PHP-FPM 容器，并将容器的 `9000` 端口映射到主机的 `8080` 端口。

5.  **访问您的 PHP 应用程序**：打开 Web 浏览器并导航至 `http://localhost:8080` 以访问在 Docker 容器中运行的 PHP 应用程序。

### 4. 用于多容器应用程序的 Docker Compose

对于包含多个服务（如 PHP、数据库和 Web 服务器）的复杂应用程序，Docker Compose 是一个宝贵的工具。它允许您使用 YAML 文件定义和管理多容器应用程序。

以下是一个用于 PHP 和 MySQL 应用程序的示例 `docker-compose.yml` 文件：

```yaml
version: '3'

services:
  web:
    image: my-php-app
    ports:
      - '8080:9000'
  db:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: my-secret-password
      MYSQL_DATABASE: mydatabase
```

使用 `docker-compose up` 运行应用程序，Docker Compose 将为您管理容器、网络和卷。

### 5. Docker 化 PHP 的优势

Docker 为 PHP 开发和部署提供了多项优势：

- **一致性**：确保您的 PHP 应用程序在不同环境中一致运行。
- **依赖管理**：在容器中轻松管理 PHP 扩展、Web 服务器、数据库和其他依赖项。
- **隔离性**：隔离应用程序的不同部分，使其更易于扩展和排查故障。
- **版本控制**：为 Docker 镜像进行版本控制以跟踪变更，并在需要时回滚到之前的版本。
- **高效部署**：快速将 Docker 容器部署到生产服务器、云平台或 Kubernetes 集群。
- **协作**：与团队成员和其他开发人员共享 Docker 镜像，简化协作。

Docker 和 PHP 8 是现代应用程序开发和部署的强强联合。通过将您的 PHP 应用程序容器化，您可以实现一致性、可扩展性和依赖项的高效管理。无论您是构建一个小型 Web 应用程序还是复杂的微服务架构，Docker 都可以简化您的开发和部署流程。

## 第 15.4 节：PHP 8 与 Kubernetes：编排与可扩展性

Kubernetes，通常缩写为 K8s，是一个开源容器编排平台，可自动化容器化应用程序的部署、扩展和管理。当与 PHP 8 结合时，Kubernetes 为在生产环境中编排和扩展 PHP 应用程序提供了强大的解决方案。

### 1. Kubernetes 基础

Kubernetes 提供了几个核心概念，使其适合部署 PHP 应用程序：

- **节点**：这是运行容器的机器（虚拟或物理）。节点是集群的一部分。
- **Pod**：Kubernetes 中最小的可部署单元。每个 Pod 可以包含一个或多个容器。Pod 代表集群中的运行进程。
- **服务**：服务定义一组 Pod 以及如何访问它们。它们确保 PHP 应用程序可以被一致地访问，即使 Pod 被添加或移除。
