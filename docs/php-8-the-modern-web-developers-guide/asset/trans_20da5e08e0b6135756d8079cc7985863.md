

# 第 1 章：PHP 8 简介

## 1.1. PHP 的演变：简史

PHP 最初是“Personal Home Page”（个人主页）的首字母缩写，自 1994 年诞生以来已发生了显著演变。它最初由 Rasmus Lerdorf 创建，作为一种用于管理其个人网站的简单脚本语言。随着时间的推移，PHP 获得了广泛流行，并转变为一种用于 Web 开发的强大服务端脚本语言。

PHP 的早期版本是面向过程的，允许开发人员在无需复杂面向对象编程（OOP）概念的情况下编写代码。1997 年发布的 PHP 3 引入了对数据库连接等更高级功能的支持，这在其被采用于构建动态 Web 应用程序的过程中发挥了关键作用。

2000 年，PHP 4 发布，带来了重大改进并引入了 OOP 支持。该版本为现代 PHP 开发奠定了基础，使创建更结构化、更易维护的代码成为可能。
