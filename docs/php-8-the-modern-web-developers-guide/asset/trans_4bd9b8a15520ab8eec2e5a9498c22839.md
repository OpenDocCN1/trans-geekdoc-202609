
$stmt = $pdo->prepare("SELECT \* FROM users WHERE username = :username");

$stmt->bindParam(':username', $username, PDO::PARAM\_STR);

$username = 'john\_doe';

$stmt->execute();

### 处理事务

当多条 SQL 语句需要作为一个整体单元执行时，**事务**对于维护数据一致性至关重要。PDO 通过 `beginTransaction()`、`commit()` 和 `rollback()` 方法支持事务。以下是一个基本示例：

```
try {

$pdo->beginTransaction();

// 执行数据库操作

$pdo->commit();

} catch (PDOException $e) {

$pdo->rollBack();

echo "事务失败: " . $e->getMessage();

}
```

### PDO 错误处理

PDO 提供了不同的错误处理模式。将 `PDO::ATTR\_ERRMODE` 设置为 `PDO::ERRMODE\_EXCEPTION` 可确保 PDO 在发生数据库错误时抛出异常，从而更容易优雅地处理错误。设置方法如下：

```
$pdo->setAttribute(PDO::ATTR\_ERRMODE, PDO::ERRMODE\_EXCEPTION);
```

### 使用获取模式

PDO 支持多种用于检索查询结果的获取模式。最常用的模式包括 `PDO::FETCH\_ASSOC`、`PDO::FETCH\_OBJ` 和 `PDO::FETCH\_BOTH`。您可以在获取数据时指定获取模式：

```
$result = $stmt->fetch(PDO::FETCH\_ASSOC);
```

### 关闭数据库连接

使用完毕后关闭数据库连接以释放资源至关重要。您可以通过将 PDO 实例设置为 null 来实现：

```
$pdo = null;
```

### PDO 进阶主题

除了基础知识外，PDO 进阶主题还包括：

*   **使用命名占位符**：您可以使用像 `:name` 这样的命名占位符，而不使用 `?` 占位符，以获得更好的可读性。
*   **批量处理**：结合预处理语句和事务，高效地插入或更新多条记录。
*   **处理 BLOB 和 CLOB 数据**：在数据库中处理二进制和大文本数据。
*   **优化查询性能**：分析并优化数据库查询以获得更好的速度。

通过掌握 PDO 进阶技术和最佳实践，您可以确保在 PHP 8 应用程序中实现安全、高效且可靠的数据库交互。

## 10.5. PHP 8 中的数据库迁移策略

数据库迁移是随着时间的推移管理数据库架构演变的关键方面。它允许您在保留现有数据的同时更改数据库结构。在本节中，我们将在 PHP 8 应用程序的背景下探讨数据库迁移策略。

### 什么是数据库迁移？

数据库迁移是应用增量更改到数据库架构以适应新功能、修改现有功能或修复问题的过程。它通常涉及创建、修改或删除数据库表、列、索引和其他对象。

### 数据库迁移的优势

1.  **数据保留**：迁移有助于确保在架构更改期间现有数据不会丢失。
2.  **版本控制**：迁移通常纳入版本控制，允许您有效地跟踪更改并与他人协作。
3.  **轻松部署**：迁移可以自动化并在应用程序部署期间应用，确保数据库架构始终保持最新。
4.  **测试**：迁移便于针对不同环境（如开发、预发布和生产）测试更改。

### 使用迁移框架

许多 PHP 应用程序利用 [Phinx](https://phinx.org/) 和 Laravel Migrations 等迁移框架来高效管理数据库架构更改。这些框架提供了一种结构化的方式来定义和执行迁移。

以下是一个简化的 Phinx 迁移示例：

```
use Phinx\\Migration\\AbstractMigration;

class CreateUserTable extends AbstractMigration
{
    public function change()
    {
        $table = $this->table('users');
        $table->addColumn('username', 'string')
              ->addColumn('email', 'string')
              ->addColumn('created\_at', 'timestamp', ['default' => 'CURRENT\_TIMESTAMP'])
              ->create();
    }
}
```

### 手动数据库迁移

如果您倾向于更手动的方法，可以编写自定义 PHP 脚本来执行用于数据库更改的 SQL 语句。以下是一个手动迁移脚本示例：

```
// 创建一个新表
$sql = "CREATE TABLE IF NOT EXISTS products (
    id INT AUTO\_INCREMENT PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    price DECIMAL(10, 2) NOT NULL
)";

// 执行 SQL 语句
$pdo->exec($sql);
```

### 最佳实践

1.  **始终备份**：在应用迁移之前，备份您的数据库，以防止因错误导致数据丢失。
2.  **使用事务**：将您的迁移脚本包裹在事务中，以确保所有更改以原子方式应用。
3.  **版本控制**：将您的迁移脚本存储在 Git 等版本控制系统中以实现可追溯性。
4.  **彻底测试**：在将迁移应用于生产数据库之前，在受控环境中进行测试。
5.  **回滚计划**：为每次迁移实现回滚脚本，以便在必要时撤销更改。

数据库迁移是为您的 PHP 8 应用程序维护结构良好且不断演进的数据库架构的关键方面。无论您选择迁移框架还是手动方法，遵循最佳实践对于确保平滑可靠的迁移至关重要。
