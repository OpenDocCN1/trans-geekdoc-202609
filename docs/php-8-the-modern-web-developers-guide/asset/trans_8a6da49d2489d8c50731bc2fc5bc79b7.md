## 在 HTML 中嵌入 PHP

要在 HTML 中嵌入 PHP 代码，通常使用 PHP 标签。最常用的方式是使用 `<?php ... ?>` 标签来包裹 PHP 代码。例如：

```html
<!DOCTYPE html>
<html>
<head>
    <title>PHP 8 Web Page</title>
</head>
<body>
    <h1>Welcome to PHP 8</h1>
    <?php
    $name = "John";
    echo "<p>Hello, $name!</p>";
    ?>
</body>
</html>
```

在本例中，`<?php ... ?>` 标签内的 PHP 代码用于动态生成问候消息。当该 PHP 脚本在服务器上运行时，它将生成带有个性化问候的 HTML 内容。

## 将逻辑与表现层分离

虽然在 HTML 中嵌入 PHP 很有用，但遵循最佳实践并保持清晰的关注点分离至关重要。将逻辑与表现层分离对于代码的可维护性和可扩展性非常关键。

一种方法是使用 PHP 生成数据，然后将其传递给负责渲染 HTML 的模板引擎或前端框架。这种方法在现代 Web 开发中很常见，它有助于更好地组织代码。

## 将 CSS 与 PHP 生成的内容集成

将 CSS 样式与 PHP 生成的内容集成非常简单。你可以像往常一样在 HTML 模板中引入 CSS 文件。以下是引入外部 CSS 文件的示例：

```html
<!DOCTYPE html>
<html>
<head>
    <title>PHP 8 Web Page</title>
    <link rel="stylesheet" type="text/css" href="styles.css">
</head>
<body>
    <h1>Welcome to PHP 8</h1>
    <?php
    $name = "John";
    echo "<p class='greeting'>Hello, $name!</p>";
    ?>
</body>
</html>
```

在本例中，`styles.css` 文件通过 `<link>` 标签链接到 HTML 文档。然后 PHP 生成的内容可以使用 CSS 类来应用样式。

PHP 主要专注于服务端脚本，这意味着它在服务器上运行并生成 HTML 发送给客户端浏览器。虽然 PHP 可以通过动态内容增强用户体验，但像 JavaScript 这样的客户端技术通常用于实现更具交互性和响应性的功能。

## 9.2. PHP 8 和 JavaScript：创建交互式 Web 应用程序

在现代 Web 开发领域，创建交互式和响应式 Web 应用程序通常涉及服务端和客户端技术的结合。虽然 PHP 擅长服务端脚本，但 JavaScript 是客户端交互的主要语言。在本节中，我们将探讨 PHP 8 如何与 JavaScript 无缝协作，以创建动态且引人入胜的 Web 应用程序。

### JavaScript 在 Web 开发中的角色

JavaScript 是一种在 Web 浏览器中运行的多功能编程语言，允许开发者为网页添加交互性和动态行为。它用于表单验证、DOM 操作和创建丰富用户界面等任务。PHP 和 JavaScript 通过分别处理服务端和客户端逻辑来相互补充。

### 使用 JavaScript 库和框架

为了创建健壮的 Web 应用程序，开发者通常会利用 JavaScript 库和框架。流行的库如 jQuery、React、Angular 和 Vue.js 提供了预构建的组件和工具来简化开发。PHP 可以通过在 PHP 脚本中动态生成 JavaScript 代码来与这些库交互。

以下是 PHP 生成 JavaScript 代码以与 jQuery 库交互的示例：

```html
<!DOCTYPE html>
<html>
<head>
    <title>PHP and JavaScript</title>
    <script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
</head>
<body>
    <button id="myButton">Click me</button>
    <div id="message"></div>
    <?php
    echo "<script>
    $(document).ready(function(){
        $('#myButton').click(function(){
            $('#message').text('Button clicked!');
        });
    });
    </script>";
    ?>
</body>
</html>
```

在本例中，PHP 生成的 JavaScript 代码使用 jQuery 处理按钮点击事件。当按钮被点击时，PHP 生成的 JavaScript 代码会使用消息“Button clicked!”更新 `<div>` 元素的内容。

### PHP 与 JavaScript 之间的通信

要创建交互式 Web 应用程序，PHP 和 JavaScript 需要有效通信。有几种方法可以实现这一点：

1.  **Ajax 请求**：PHP 可以处理由 JavaScript 发起的 Ajax（异步 JavaScript 和 XML）请求。这允许在不刷新整个页面的情况下进行实时数据检索和更新。
2.  **JSON**：PHP 可以生成 JSON（JavaScript 对象表示法）数据，JavaScript 可以轻松解析和操作这些数据。这对于在服务器和客户端之间交换结构化数据非常有用。
3.  **隐藏输入框**：PHP 可以在 HTML 表单中生成隐藏输入字段，JavaScript 可以访问和修改这些字段。提交表单时，此技术常用于在 PHP 和 JavaScript 之间传递数据。

### 服务端渲染与单页应用程序 (SPA)

Web 应用程序可以遵循不同的架构。在传统的服务端渲染 (SSR) 中，PHP 在服务器上生成 HTML 页面并将其发送给客户端。相比之下，单页应用程序 (SPA) 加载单个 HTML 页面并使用 JavaScript 动态更新内容。PHP 可以根据项目需求支持这两种方法。

### 构建实时应用程序

对于聊天应用程序或实时更新等实时应用程序，PHP 可以与 WebSockets 或服务端发送事件 (SSE) 等技术协同工作，以实现服务器和客户端之间的实时双向通信。这些技术通常与 JavaScript 结合使用，以创建响应迅速且实时的 Web 应用程序。

总之，PHP 8 和 JavaScript 是创建交互式 Web 应用程序的必备工具。通过将 PHP 的服务端能力与 JavaScript 的客户端交互性相结合，开发者可以构建功能丰富且动态的 Web 解决方案。PHP 和 JavaScript 之间的有效通信，加上库和框架的使用，使开发者能够在 Web 上创建引人入胜的用户体验。

## 9.3. 使用 PHP 8 进行安全的 Web 开发

Web 安全是 Web 开发的关键方面，PHP 8 提供了各种功能和最佳实践来增强 Web 应用程序的安全性。在本节中，我们将探讨关键的安全考量和技术，以使用 PHP 8 构建安全的 Web 应用程序。

### 清理用户输入

Web 安全的基本原则之一是永远不要信任用户输入。从用户接收的所有数据（如表单提交）都应被视为潜在恶意数据。PHP 8 提供了 `htmlspecialchars` 和 `filter_input` 等函数来清理和验证用户输入。这些函数有助于防止常见的漏洞，如跨站脚本攻击 (XSS)。

```php
// 使用 htmlspecialchars 清理用户输入
$userInput = $_POST['input_field'];
$sanitizedInput = htmlspecialchars($userInput, ENT_QUOTES, 'UTF-8');
```
