
这些函数提供了一种更简洁、更易读的方式来访问数组的首尾元素，而无需使用数组索引表示法。

## 6.1.2. `array_key_first()` 和 `array_key_last()` 函数

与 `array_first()` 和 `array_last()` 类似，PHP 8 引入了 `array_key_first()` 和 `array_key_last()` 函数，用于获取数组的首尾键。

```php
$array = ['a' => 1, 'b' => 2, 'c' => 3];

$firstKey = array_key_first($array); // 返回 'a'
$lastKey = array_key_last($array);   // 返回 'c'
```

当你需要处理关联数组并想要访问首尾键时，这些函数特别有用。

## 6.1.3. `array_is_list()` 函数

`array_is_list()` 函数检查数组是否为数字索引，即其键是否为从 0 开始的连续整数。如果数组是列表则返回 `true`，否则返回 `false`。

```php
$listArray = [1, 2, 3, 4, 5];
$assocArray = ['a' => 1, 'b' => 2, 'c' => 3];

$isList = array_is_list($listArray);  // 返回 true
$isAssoc = array_is_list($assocArray); // 返回 false
```

当你需要区分数字索引数组和关联数组时，此函数非常方便。

## 6.1.4. `array_to_list()` 函数

`array_to_list()` 函数将数组转换为数字索引数组，将其元素从 0 开始重新索引。当你想要确保数组遵循连续的整数键时，这很有用。

```php
$assocArray = ['a' => 1, 'b' => 2, 'c' => 3];
$listArray = array_to_list($assocArray);

/*
$listArray 现在为：
[0 => 1, 1 => 2, 2 => 3]
*/
```

此函数有助于将关联数组转换为列表，以便进行一致的数据处理。

## 6.1.5. `array_key_exists()` 性能改进

在 PHP 8 中，`array_key_exists()` 函数已针对更好的性能进行了优化。现在在检查关联数组中键的存在性时，其执行速度更快。

```php
$assocArray = ['a' => 1, 'b' => 2, 'c' => 3];

if (array_key_exists('b', $assocArray)) {
    // 键 'b' 存在于 $assocArray 中
}
```

这些 PHP 8 中的新数组函数和增强功能简化了常见的数组操作，并提高了数组相关操作的整体性能。它们为开发者提供了在 PHP 应用程序中处理数组的更高效工具。

## 6.2. 高级字符串操作技术

在 PHP 8 中，高级字符串操作技术得到了增强，为开发者提供了更强大的工具来处理字符串。这些技术使你能够高效地对字符串执行复杂操作。在本节中，我们将探讨其中一些高级字符串操作功能。

### 6.2.1. 字符串插值

字符串插值允许你将变量直接嵌入双引号字符串中。这简化了字符串拼接，并使代码更具可读性。

```php
$name = 'John';
$greeting = "Hello, $name!";
echo $greeting; // 输出：Hello, John!
```

字符串插值消除了在将变量插入字符串时对拼接运算符 (`.`) 的需求。

### 6.2.2. 使用 Heredoc/Nowdoc 的多行字符串

PHP 8 引入了一种使用反引号 (`` ` ``) 创建多行字符串的新方式。当你需要定义跨越多行的长字符串而无需显式换行符时，此功能非常有用。

```php
$multilineString = <<<EOD
This is a
multiline string
created using backticks.
EOD;

echo $multilineString;
```

使用反引号创建的多行字符串保留空白和换行，使其适合格式化代码或生成模板。

### 6.2.3. 字符串转换函数

PHP 8 引入了几个用于在不同格式之间转换字符串的函数，例如将字符串转换为大写或小写。

```php
$string = 'Hello, World!';
$uppercase = strtoupper($string); // 转换为大写
$lowercase = strtolower($string); // 转换为小写

echo $uppercase; // 输出：HELLO, WORLD!
echo $lowercase; // 输出：hello, world!
```

这些函数简化了字符串操作任务，特别是在处理不区分大小写的比较或格式化时。

### 6.2.4. 字符串长度和修剪

`strlen()` 函数常用于确定字符串的长度。PHP 8 还提供了用于修剪字符串首尾空白字符的函数。

```php
$string = '  Trim me!  ';
$length = strlen($string); // 返回 12
$trimmed = trim($string);  // 移除首尾空格

echo $length;
echo $trimmed; // 输出："Trim me!"
```

在处理用户输入或清理字符串以便存储时，修剪函数很有帮助。

### 6.2.5. 正则表达式

PHP 的正则表达式功能在 PHP 8 中得到了增强。你可以使用 `preg_match()` 和 `preg_replace()` 等函数，基于模式对字符串执行复杂的模式匹配和替换操作。

```php
$text = 'The quick brown fox jumps over the lazy dog.';
$pattern = '/brown/i'; // 不区分大小写匹配

if (preg_match($pattern, $text)) {
    echo 'Pattern found!';
}

$replaced = preg_replace($pattern, 'red', $text);
echo $replaced; // 输出："The quick red fox jumps over the lazy dog."
```

正则表达式是基于模式验证、搜索和操作字符串的强大工具。

### 6.2.6. Unicode 支持

PHP 8 为 Unicode 字符和多字节字符串提供了改进的支持。这对于在国际化和本地化任务中处理非 ASCII 字符至关重要。

```php
$string = 'Café';
$length = mb_strlen($string); // 多字节字符串长度

echo $length; // 输出：4 (字符)
echo $substring; // 输出："Caf"
```

这些函数确保 PHP 能够处理多语言内容并保持正确的字符编码。

### 6.2.7. 字符串包含检查

虽然传统的点运算符 (`.`) 拼接仍被广泛使用，但 PHP 8 引入了 `str_contains()`、`str_starts_with()` 和 `str_ends_with()` 函数，用于高效的字符串包含检查。

```php
$string = 'Hello, World!';
$contains = str_contains($string, 'World');    // 检查子串
$startsWith = str_starts_with($string, 'Hello'); // 检查前缀

echo $startsWith;  // 输出：true

```

这些函数在处理字符串包含检查时提高了代码可读性和性能。

总之，PHP 8 提供了广泛的高级字符串操作技术和函数，使在各种场景下处理字符串变得更加容易。这些功能增强了代码可读性、性能以及有效处理复杂字符串操作的能力。

## 6.3. 使用 `str_contains`、`str_starts_with` 和 `str_ends_with` 函数

PHP 8 引入了三个方便的字符串函数：`str_contains()`、`str_starts_with()` 和 `str_ends_with()`，它们提供了高效的方法来检查字符串中的子串包含、前缀和后缀。这些函数对于简化代码和提高处理字符串时的性能非常有价值。

### 6.3.1. `str_contains()`

`str_contains()` 函数检查字符串是否包含指定的子串。如果找到子串则返回 `true`，如果不存在则返回 `false`。

```php
$text = 'This is a sample text.';
$substring = 'sample';

if (str_contains($text, $substring)) {
    echo 'Substring found!';
} else {
    echo 'Substring not found.';
}
```

在本例中，`str_contains()` 返回 `true`，因为单词 'sample' 存在于给定字符串中。

### 6.3.2. `str_starts_with()`

`str_starts_with()` 函数验证字符串是否以指定前缀开头。如果字符串以该前缀开头则返回 `true`，否则返回 `false`。

```php
$text = 'Hello, world!';
$prefix = 'Hello';

if (str_starts_with($text, $prefix)) {
    echo 'String starts with the prefix!';
} else {
    echo 'String does not start with the prefix.';
}
```
