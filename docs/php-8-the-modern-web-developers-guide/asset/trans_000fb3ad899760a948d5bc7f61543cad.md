```sql
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL,
    password_hash VARCHAR(255) NOT NULL
);

CREATE TABLE carts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    user_id INT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE cart_items (
    id INT AUTO_INCREMENT PRIMARY KEY,
    cart_id INT NOT NULL,
    product_id INT NOT NULL,
    quantity INT NOT NULL,
    FOREIGN KEY (cart_id) REFERENCES carts(id),
    FOREIGN KEY (product_id) REFERENCES products(id)
);
```

## 第 14.4 节：电子商务网站的安全考量

在开发电子商务网站时，安全性至关重要，旨在保护敏感的客户信息并维护信任。在本节中，我们将探讨使用 `PHP 8` 构建的电子商务网站的基本安全考量和最佳实践。

### 1. 数据加密

确保所有敏感数据（包括客户个人信息和支付详情）均通过 `HTTPS` 安全传输。`PHP 8` 提供了用于处理加密和解密的内置函数（如 `OpenSSL`），您可以利用它们来保护传输中的数据。

### 2. 输入验证与清理

实施严格的输入验证和清理，以防止常见的 Web 漏洞，如 `SQL` 注入和跨站脚本攻击（`XSS`）。`PHP 8` 提供了过滤函数（如 `filter_input()` 和 `filter_var()`），用于清理用户输入并在处理前验证数据。

```php
// Example of input validation and sanitization
$email = filter_var($_POST['email'], FILTER_SANITIZE_EMAIL);

if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
    // Valid email address
} else {
    // Invalid email address
}
```

### 3. 支付卡行业数据安全标准（PCI DSS）合规

如果您的电子商务网站处理信用卡信息，请确保符合 `PCI DSS` 标准。`PHP 8` 的安全功能结合安全编码实践，可助您达成并保持合规。

### 4. 认证与授权

实施强健的用户认证机制，以防止未经授权访问电子商务应用程序的敏感区域。`PHP 8` 提供了带有内置认证组件的库和框架，使保护用户账户变得更加容易。

### 5. 会话管理

使用 `PHP 8` 的会话管理功能来安全地管理用户会话。实施会话超时并重新生成会话 ID 以防止会话固定攻击。

```php
// Example of session management in PHP 8
session_start();

if (isset($_SESSION['user_id'])) {
    // User is authenticated
} else {
    // Redirect to login page
}
```

### 6. 跨站请求伪造（CSRF）防护

通过为关键操作（如处理支付或更新用户信息）生成和验证反 `CSRF` 令牌，保护您的电子商务网站免受 `CSRF` 攻击。

```php
// Example of CSRF token generation and validation
$csrfToken = bin2hex(random_bytes(32));
$_SESSION['csrf_token'] = $csrfToken;

// In the form:
<input type="hidden" name="csrf_token" value="<?= $csrfToken ?>">
```

### 7. 定期安全审计

使用 `PHP 8` 的调试和分析工具以及第三方安全扫描工具，定期审核您的电子商务应用程序的安全性。及时解决漏洞以维护安全环境。

### 8. 安全响应头

在您的 Web 服务器配置中实施安全响应头，以缓解常见的 Web 安全威胁。诸如内容安全策略（`CSP`）和 `X-Content-Type-Options` 之类的响应头有助于防范 `XSS` 和内容类型嗅探攻击。

### 9. 错误处理

自定义 `PHP 8` 中的错误处理，以防止敏感信息在错误消息中泄露。使用适当的错误日志记录机制来跟踪错误，而不向潜在攻击者透露详细信息。

```php
// Example of custom error handling in PHP 8
set_error_handler(function ($errno, $errstr, $errfile, $errline) {
    // Log errors securely and handle them appropriately
});
```

### 10. 定期更新与补丁

保持 `PHP 8`、其库及任何第三方组件通过安全补丁保持最新。漏洞不断被发现并修补，因此保持最新状态对安全至关重要。

遵循这些安全考量和最佳实践，您可以使用 `PHP 8` 创建健壮且安全的电子商务网站，保护您的客户和业务免受潜在威胁和泄露。

## 第 14.5 节：电子商务应用的性能优化

优化电子商务应用程序的性能对于为客户提供无缝且快速的购物体验至关重要。在本节中，我们将探讨各种策略和技术，以提高基于 `PHP 8` 构建的电子商务网站的性能。

### 1. 缓存

实施缓存机制可以显著降低服务器负载并提高响应时间。`PHP 8` 为多种缓存机制提供内置支持，包括通过 `OPCache` 进行的操作码缓存，以及使用 `Memcached` 或 `Redis` 等库进行的数据缓存。

```php
// Example of using Memcached for data caching in PHP 8
$memcached = new Memcached();
$memcached->addServer('localhost', 11211);

$key = 'product_123';
$data = $memcached->get($key);

if ($data === false) {
    // Fetch data from the database and store it in the cache
    $data = fetchDataFromDatabase(123);
    $memcached->set($key, $data, 3600); // Cache data for one hour
}

// Use the $data variable
```

### 2. 内容分发网络（CDN）

利用内容分发网络将静态资源（如图片、样式表和 `JavaScript` 文件）分发到更靠近用户的边缘服务器。这可以减少延迟并加速电子商务网站内容的加载。
