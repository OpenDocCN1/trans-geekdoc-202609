## 第 15.1 节：在云平台上部署 PHP 8 应用程序

在当今快速发展的技术环境中，在云平台上部署 `PHP 8` 应用程序已成为实现可扩展性、灵活性和高效资源管理的标准做法。云服务商提供了一系列服务和功能，可以简化部署流程并提升 `PHP 8` 应用程序的性能。

## 第 15.2 节：PHP 8 的无服务器架构

近年来，无服务器架构因其简化应用程序开发和扩展的能力而广受欢迎。在本节中，我们将探讨如何利用 `PHP 8` 的无服务器计算来构建高效且具成本效益的应用程序。

### 1. 理解无服务器计算

无服务器计算，通常称为函数即服务 (`FaaS`)，允许开发人员以函数的形式编写和部署代码。这些函数响应特定事件或触发器执行，例如 `HTTP` 请求、数据库变更或文件上传。包括 `AWS`、`Azure` 和 `Google Cloud` 在内的主要云服务商均提供无服务器平台。

### 2. PHP 8 与无服务器

虽然 `PHP` 不是无服务器计算中最常用的语言，但可以在无服务器环境中运行 `PHP 8` 函数。例如，`AWS Lambda` 允许您将 `PHP` 代码打包为 Lambda 函数。您可以使用 `Bref` 框架简化 `PHP` 在 `AWS Lambda` 上的部署。

### 3. 无服务器 PHP 的优势

*   **成本效益**：采用无服务器，您只需为函数的执行时间付费。这消除了预配和维护服务器的需求，从而节省成本。
*   **自动扩展**：无服务器平台自动处理函数的扩展，确保您的应用程序无需人工干预即可应对不同级别的流量。
*   **事件驱动**：无服务器非常适合事件驱动的应用程序。`PHP` 函数可以响应 `HTTP` 请求、数据库变更或其他事件，使其适用于各种用例。
