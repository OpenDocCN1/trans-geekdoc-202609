
# 大数据概述

## 核心价值

大数据分析的很大一部分在于大数据的应用。简单来说，大数据是指规模大、复杂度高的数据集，尤其是来自新数据源的数据。这些数据集通常量大到传统软件难以有效处理。但问题的关键不在于数据量大小或收集能力，而在于能从数据中学到什么。企业若能妥善利用大数据，便能找到最佳方案解决以往难以应对的业务问题。

## 三大核心特征（3V）

### 1. 容量

数据量至关重要。大数据要求处理大量非结构化、低密度数据，这些数据价值未知，例如 Twitter 数据流、移动应用或网页的点击流、传感器设备数据等。对某些企业而言，数据量可能达数十 TB；对其他企业则更多。无论规模，大数据都包含多种数据类型，助力企业获取信息、超越竞争对手。

### 2. 速度

速度指数据接收并采取行动的快慢。高速数据流通常直接写入内存而非磁盘。联网智能产品多基于实时或近实时运行，要求实时评估和行动以确保成功。

### 3. 多样性

多样性指可用数据类型繁多。传统结构化数据易存入关系型数据库，便于排序分析。但大数据兴起后，非结构化数据更普遍。半结构化和非结构化数据（视频、音频、文本）需预处理以提取含义并支持元数据。

## 扩展特征：价值与真实性

除 3V 外，还有两个关键维度：

- **价值**：数据有内在价值，但需挖掘才能转化为商业价值。
- **真实性**：数据的真实性和可靠性同等重要。在数据即资本的时代，数据质量至关重要。

全球头部科技公司的核心价值很大程度上源于其数据资产，它们持续分析数据以开发新产品、提升效率。近期技术突破大幅降低了存储和计算成本，使海量数据存储更易行、更低成本，从而支持精准决策。

挖掘大数据价值不仅是分析，更是一个完整的发现过程，需要有洞察力的分析师、业务用户和高管提出正确问题、识别模式、做出明智假设、预测行为。

## 发展历程

大数据概念虽新，但大规模数据集可追溯至 20 世纪 60 年代（数据中心雏形、关系型数据库诞生）。2005 年前后，YouTube、Facebook 等在线服务用户生成数据量激增，引发关注。同年，开源框架 `Hadoop` 诞生，用于存储和分析大数据；`NoSQL` 平台也随之流行。这些框架让大数据处理更简单、存储更廉价，推动了大数据发展。

此后，大数据量呈指数级增长。数据生成主体不再局限于人类，`IoT`（物联网）让更多设备联网，可采集客户使用模式、产品性能等数据。`机器学习`（下章详述）催生更多工具应对数据挑战。`云计算`提供弹性伸缩能力，开发者可按需启动临时集群测试数据子集，进一步拓展大数据边界。大数据效用不会在短期内消退。

## 主要优势

1.  **更完整的答案**：掌握更多信息，能对核心业务问题给出更完整的解答。
2.  **更强的信心与新思路**：完整答案增强数据可信度，为解决业务问题提供全新路径。
