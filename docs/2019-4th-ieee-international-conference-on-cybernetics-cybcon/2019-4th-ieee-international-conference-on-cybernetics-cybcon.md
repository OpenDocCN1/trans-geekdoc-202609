# 2019 第四届 IEEE 国际控制论会议 (Cybconf) (中国北京 2019.7.5-2019.7.7) 货币评估研究









**摘要：** 基于近几十年的船舶油溢油事件，本研究建立了一种针对船舶油溢油损害的快速货币化评估方法。通过分析样本数据，选取了五类指标（溢油量、溢油面积、产品比例、海岸线、海岸线类型），开发了机器学习方法，用于对油油损害补偿金额进行快速评估和估计。比较了 BP 人工神经网络和 RBF 径基函数神经网络的结果。同时，利用多元回归分析了各评价指标对补偿金额的影响程度。最后，确定了最优模型和影响因素，为未来的现实世界案例提供支持。

溢油直接关系到安全会的生存与发展。国防实力也对经济资源和海洋环境产生影响（Yang et al., 2005）。发展中国家充分意识到污染控制中的索赔与补偿。损害的索赔与补偿机制已形成一种恶性循环。然而，由于法律和落后的评估方法，这往往变得非常复杂。同时，补偿不足无法支付清理费用。溢油未能消除将导致无法区分的损失。补偿机制的实施存在困难。一方面，旨在为利益相关者计算金额提供直接计算方法；另一方面，为利益相关者提供价值估算（Yang et al.）。

*关键词：*船舶油、货币化评估、机器学习、多元回归。


海洋环境是一个包含海洋及相邻区域各种因素的系统。它是全球生态链的重要部分，通过大量资源改变着人类的生活和生产。溢油的即时影响是海洋污染的主要来源。必须采取有效的清除和预防措施来控制污染规模和范围，以最大地减少损失和损害。根据“污染者付费”原则，损害实施者和相关的国际组织（IMF）必须遵守国际公约或相关规定。溢油损害的规定、经济和环境补偿、补偿的准备程度和完整性对控油和环境修复的有效性具有重大影响。地方政府部门、海洋部门、港口运输部门、海事法院、渔业和水产管理等部门参与了油污染的消除。及时且合理的补偿是一个影响……的经济和法律问题。

溢油发生后，管辖区的监管机构将根据溢油损害模型评估事故性质及事故造成的损害。由于受影响居民人数众多、区域内生物数量、事故中考虑的因素众多以及估时间较长，开展实时补偿并考虑受损利益的实施非常困难。在许多情况下，事故发生后采取以下解决方案。通常，补偿是通过评估每个部分损害的程度和金额来计算的。对评估结果进行汇总、安排，并得出综合性、真实数据的结论。然而，由于对方法评估的要求较高，补偿的实施存在困难。在实际过程中，基于传统模型算法对多次事故进行计算和比较。根据指标对新事故进行多样化处理，以油柱的损害作为参考。此类算法在获取高准确度数据方面更加高效方便。基于任何算法获得的数据进行补偿也可以得到事故受害者的认可。在本研究中，对现有估计模型进行了中心分析和比较，并整合了事故损失指标数据之间的特定相关性。数据获取自相关的事故损失补偿方法。采用二线性回归、径基函数网络、BP人工网络和支持向量机以确保补偿的准确性。大学指导性预评估方法的估计结果与案例具有相似性，并总结了评估与案例数据之间的相关性。系统性研究为相关案例的估计提供了科学依据和信心。更重要的是，可以制定更具指导性和建设性的指南以预防事故。

在现有清理补偿方法（包括直接评估、神经网络、模糊法）的基础上，开展了关于船舶油污染补偿估算的研究。

- 1. 多元回归模型

- 1.1 全准则线性回归模型

首先，多元回归模型整合了五个自变量——海洋溢油量、重力、溢油面积、污染海岸线长度和海岸线类型，以及因变量评估补偿金额。相应的置信水平为 95%，有助于模型进行 SPSS 回归。方程表达式如下：

Y = 0.466X₁ - 0.393X₂ + 0.163X₃ + 0.231X₄ - 0.053X₅ + 0.120




其中 Y=补偿金额，X1=溢油量，X2=比重，X3=溢油面积，X4受污染海岸线，X5受污染海岸线类型。

多元线性回归显示拟合优度标准处于较为理想的状态，这意味着解释变量对估计金额具有较高的解释程度。相应的准则显示出测试结果具有良好的统计学显著性。根据 Sig 值，通过删除最后一项来确定模型的输入变量。

# 2. 四特征线性回归模型

基于之前的分析结果，选择溢油量、比重、溢油面积和海岸线作为解释变量，作为线性回归的解释变量，记为模型 2。拟合优度优五特征回归，意味着使用这些变量可以更好地估计补偿金额。在检查相关性结果的显著性后，确定了解释变量与被变量之间的线性关系。通过相关结果可以看出，解释变量包括溢油量、比重、溢油面积和海岸线。模型 2 拟合的方程系数为：

$Y = 0.4666, 0.249X1 + 0.1837, 0.2444X2 + 0.1055$

其中 Y=补偿金额，X1=溢油量，X2=比重，X3=溢油面积，X4受污染海岸线

与上述结果相比，表明在估计损害补偿时，许多变量对决策有重要影响，需要引起注意，特别是事故损害估计过程的预防和控制中。该方法的简单性用于此类事故的快速评估。

# 4. 支持机模型 (SVM)

使用归一化数据，取前41项作为训练样本，另外41项作为测试样本。使用 MATLAB 构建支持机模型。结果显示训练的平均误差为 0.0060，验证的均方误差为 0.0068。在这些样本数据的评估中，构建了模型。通过训练样本进行训练并确定最终数据的方法。最后，模型显示最终测试集的误差为0.0825。对于仿真结果，SVM模型可以有效反映船舶油污染损失的补偿金额和影响因素。除了对应结果外，其他结果与实际SVM网络基本一致，可预测和估计船舶油污染成本。
