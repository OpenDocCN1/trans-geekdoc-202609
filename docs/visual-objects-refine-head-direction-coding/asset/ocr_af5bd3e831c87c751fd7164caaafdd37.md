Animals use visual objects to guide navigation-related behaviors. However, visual-object preferences have yet to be described in the mouse brain, limiting our understanding of how visual-objects affect spatial navigation system. Using functional ultrasound, we identified brain areas that were preferentially activated by visual objects. While visual cortex did not show a preference, areas associated with spatial preference were activated by objects.
