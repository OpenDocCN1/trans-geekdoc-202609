**引言：** 在日常生活中，我们利用视觉对象（例如在镇中行走时的空间时钟）或作为空间地标来帮助我们在穿过世界时定位。我们之所以可以将视觉对象作为空间地标，是因为我们大脑在将世界解析为物体时会进行计算能力的解码。然而，我们在世界中的位置是由大脑中的位置细胞、网格细胞和头方向细胞（HD cells）处理的。但关于视觉对象如何调节编码空间变量的神经元调谐，仍有许多未知，因为目前尚不清楚大脑是如何处理视觉对象的，而空间导航正是研究得最广泛的领域。

HD细胞根据其偏好方向受到视觉刺激的差异化调节；指向视觉刺激的HD细胞被激活，而背离视觉刺激的HD细胞则被抑制。在自由运动的条件下（即当环境中显示一个物体时），观察到了空间导航现象。

**原理：** 为了填补这一知识空白，我们推论自由状态下的脑活动筛选可以以无偏偏的方式识别出偏好视觉对象的区域。通过电生理学方法，我们表征了响应自由移动物体区域内单个神经元的空间特性。

**结论：** 视觉对象通过增加编码视觉刺激的HD细胞的响应，同时减少远离物体的HD细胞的放电率（并伴有一个伴体，在我们的实验中，伴体是大脑），精化了海马中HD的群体编码；每当我们使用地标（即……的图像）时，指南针就会变得更好、更准确。这些结果为大脑如何利用视觉地标来增强对世界空间信息的编码提供了见解。

**结果：** 我们的基于超声成像的脑筛选显示，与空间导航相关的区域而非视觉皮层区域对视觉对象表现出偏好。作为HD系统的部分下丘脑（postsubiculum）表现出最强的偏好方向。在固定条件下，当

# 结果

### 偏好响应视觉对象的区域的脑扫描
首先，我们使用功能性超声（fUS）窗（27–29）对小鼠进行脑扫描，以寻找偏好响应视觉对象的区域。将小鼠放置于COMBO窗（图 14A）中，并固定在超声探头下。在没有运动伪迹的情况下，记录了包括嗅球、皮层在大脑部分内的信号。图像以60°高度、沿水平中线并向垂直中线偏离20°的角度呈现（图 14A），这部分被快速移动物体刺激的视野区域被认为对视觉负荷的处理非常重要（32）。为了覆盖物体尺寸的大部分（33），展示了来自不同类别的48种物体中的38种（图 S1）。对于破坏了物体身份但保持了低层统计的图像，这48个物体被分为两个图像块和四个随机洗乱（scrambling）块，每个块都标记有索引（1–4），以确定每个视觉体素中诱发变化的的方向（图 1b）。

动物利用视觉对象来引导导航相关行为。然而，小鼠脑中尚未描述视觉对象偏好，这限制了我们对视觉对象如何影响空间导航系统的理解。通过功能性超声，我们识别了被视觉对象优先激活的脑区域。虽然视觉皮层没有显示出偏好，但与空间偏好相关的区域被物体激活了。在背皮层使用HD系统进行的电生理记录证实，对于快速放电神经元，视觉对象增加了与HD方向一致的HD细胞的速率，但减少了其他方向HD细胞的活动。

首先，我们检查了麻醉小鼠对所有八个块（即组合和洗乱刺激）的响应。我们使用了一种同时适用于这两种的小鼠（图 1C）。在对抗性刺激大脑100后，我们在两个脑区域观察到了诱发的视觉活动（图 1D）。我们计算了视觉对象敏感性（VOS），以量化对洗乱物体的偏好。我们发现少数脑区域对视觉对象显示出显著统计：下丘脑（Pscb）、旁丘脑和额区（图 1D）。相比之下，许多区域对洗乱物体没有显示出偏好。例如上丘（SC），我们对洗乱物体有显著反应（图 1D）。我们在偏好响应视觉对象的区域中也发现了类似的结果，我们对洗乱物区域进行了排序（图 S2A）。

空间导航系统由放电率受动物朝向和位置调节的神经元组成（3）。在运动期间，空间导航系统受到视觉输入的调节（6），而视觉对象可以作为环境标记（8）。此外，锚点的出现会导致不稳定（12）。因此，视觉对象可以锚定空间的内部表示（14）。

为了检查大脑中是否存在视觉对象敏感性的系统性偏差，我们对主要响应视觉负荷的全脑范围区域进行了排序。根据最新研究，我们将响应区域分类为（i）视觉系统、（ii）空间系统或（iii）两者都是。我们发现视觉系统前10%的区域数值与空间导航系统相当（图 H），且所有空间导航相关区域的平均VOS显著更大（图 1）。如果我们根据视觉对象和物体方向的使用无监督聚类，我们识别出了四个类：视觉、空间以及两个空间导航区域类。

视觉对象偏好的研究主要在灵长类动物中进行（19）。这揭示了一系列按层次排列并被称为“视觉系统”的脑区域，这些区域对视觉对象的高级表示敏感（19, 20）。在啮类动物中，侧视觉皮层似乎具有垂直流流属性（21–23），且执行神经元可以对转向视觉物体做出反应（24, 25, 26）。然而，尚不清楚视觉对象是否影响空间导航。
