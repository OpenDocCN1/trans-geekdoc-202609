# Data analysis

All analysis was performed using MATLAB (Mathworks) or Python.

# fUS preprocessing

The fUS series was processed using the Allen Brain Institute
mouse brain atlas. For this, all sessions of a mouse were
aligned using an approach based on the MATLAB importnunction. A high-resolution power map was created by
averaging 100 fUS frames from a single session, which was
registered to the atlas using masks to create a
temporal registration. This was applied to all frames of the same mouse. The

fUS series was processed using custom MATLAB scripts on
voxel-by-voxel basis. Temporal inversion was performed to
calculate the hemodynamic response. The BOLD signal was
calculated by subtracting the baseline signal from each
point and dividing by the baseline. Slow drifts were removed
using a fifth-order Butterworth bandpass filter with a cutoff of
0.05 Hz. Movement artifacts occurring during awake
sessions were removed using templates extracted from
non-brain voxels or

To preprocess, and trial-averaged (of the same stimulus
fUS) data of visual events were clustered using a MATLAB
UMAP (implementation, Version 4.6) was created with
distance metric and the following parameters: n_neighbors=5, cluster-
n=15. Trial-averaged fUS data of visual events was clustered
using MATLAB dendrogram.m (distance metric +
linkage method = used). For clustering at the level of voxels, pre-
processed fUS data of visual events were denoised using the
silhouette method.

# Electrophysiological preprocessing

Electrophysiological records were processed with Kilwho, and
times were analyzed using the Phy software at
https://github.com/kelly/phy/). Only units that showed
responded to the stimulus and exhibited high Spike quality
responses were included in the analysis. To estimate stimulus
frames, single-unit events were binned with 100 ms bin size and
that a 2 ms zero-overlap. A Gaussian kernel with 10 ms
was used for smoothing. For except trials, the rasters were averaged.
Raster plots were plotted using the Graph toolbox.

duration was 200 ms with a gap of 200 ms. We used 0.5 as
