Next, you're going to learn how to set up a basic line plot in an XY chart, suppose you have multiple values in a single line? Will you create another XY chart using three values and six points per value. Copy the following code and run it.

```
# -*- coding: utf-8 -*-
import pygal
xy_chart = pygal.XY()
xy_chart.add('Value 1', [(-50, -30), (100, 45), (120, 56), (168,
(211, 192), (279, 211)])
xy_chart.add('Value 2', [(-2, -14), (370, 444), (391, 464), (399,
512), (412, 569), (789, 896)])
xy_chart.add('Value 3', [(2, 10), (142, 164), (184, 216), (203, 243),
(208, 335), (243, 201)])
xy_chart.render_to_file("xy_chart.svg")
```
