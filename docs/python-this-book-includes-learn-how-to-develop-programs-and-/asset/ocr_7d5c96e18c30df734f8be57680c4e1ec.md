# Simple Bar Charts

The application of simple bar charts resembles line charts. Additionally, it discloses values to information categories. Use the code below to create a simple bar chart.

```
### -*- utf-8 *-
import pygal
#create a new bar chart.
bar = pygal.8ar()
bar.title = 'Searches for term: sleep'
bar.x_labels = map(str, range(2011, 2015))
bar.add('Searches', [81, 88, 88, 100])
bar.render_to_file('bar_chart.svg')
```
