## A P-value

A p-value refers to the probability of refusing a null hypothesis when it is found to be true. The null hypothesis is a statement that states there is no difference between two measures. If the hypothesis is that individuals who study daily score more than 90 marks out of 100, the null hypothesis in this case would be that there is no connection between hours clocked and marks scored. In case the p-value is equivalent to or less the significance level (α), then the null hypothesis is irregular and requires to be rejected.

Let's understand this feature using an example where the null hypothesis is that it is common for students to get 68 marks. Let's acquire the z-score of 68 marks:

```python
>>> zscore = (68 - classscore.mean()) / classscore.std()
>>> zscore
2.283
```

Now, let's determine the value:

```python
>>> prob = 1 - stats.norm.cdf(zscore)
>>> prob
0.03283518262804063
```

![](img/43582740ac1227a817786ef73ef3772_209_png)

So, you can see that the p-value is 3.2%, which is lower than the significance level. In other words, the null hypothesis can be rejected, and it can be concluded that it's not common to attain 68 marks in mathematics.

## One-Tailed and Two-Tailed Tests

When it comes to a two-tailed test, both tails of the null hypothesis are used to determine the hypothesis.

![](img/43582740ac1227a817786ef73ef3772_210_0.png)

For a two-tailed test, when a given percentage of 5% is used, then it's distributed equally on both sides. In this case, it is 2.5% on one side, and 2.5% on the opposite side.

Here's an example to illustrate this. The average score of mathematics exam at a national level is 60 marks, and the standard deviation is 3 marks. The average marks of the class is 53. The null hypothesis refers to the mean marks of the class, similar to the national average. First, let's test the following hypothesis by first finding the z-score-score:

```python
>>> zscore = (53 - 60) / 3.0
>>> zscore
-2.3333333333333335
```

The p-value would be:

```python
>>> prob = stats.norm.cdf(zscore)
>>> prob
0.009815328628645336
```

In this case, the p-value is 0.98%. The null hypothesis is to be rejected, and the p-value should be lower than 2.5% in either direction of the bell curve.
