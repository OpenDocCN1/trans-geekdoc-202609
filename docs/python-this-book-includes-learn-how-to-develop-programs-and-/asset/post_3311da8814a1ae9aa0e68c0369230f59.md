# Variables

A variable is like a container that holds values that you can access. It is a way of pointing a memory location that a given program uses. You use variables to help the computer save or retrieve data to and from the memory location. Python differs from other languages when it comes to variables. Languages such as Java, C++, or C link a variable to a specific data type. In other words, it can only store a given data type. For reason, when a variable is of type integer, you can only save integers inside that variable when executing the program.

Python is very flexible when handling variables. As a result, Python lets de-assign variables. For example:

```python
x = 5
x = "hello"
```

You can also assign multiple variables at once. For example:

```python
a, b, c = 1, 2, 3
```

Variables are used to store data that can be changed. For example:

```python
count = 10
count = 20
```

The value of a variable can be updated using arithmetic operators. For example:

```python
x = 5
x += 3  # 3 is added to x
```

Constants:

```python
x = 10
y = 20
```

Constants are variables whose values are not not intended to be changed during the execution of the program. In Python, there is no built-in constant type, but by convention, we use uppercase letters to indicate that a variable should be considered constant.


# Scope

Variables have a scope, which defines where they can be accessed. There are two main types of scope: local and global.

Local variables: Variables defined inside a function are local and can only be accessed within that function.

```python
def my_function():
    local_var = "I am local"
    print(local_var)

my_function()
# printing local_var outside the function would raise an error
```

Global variables: Variables defined outside any function are global and can be accessed anywhere in the program.

```python
global_var = "I am global"

def my_function():
    print(global_var)

my_function()
```

To modify a global variable inside a function, use the `global` keyword:

```python
counter = 0
def increment():
    global counter
    counter += 1

increment()
print(counter)
```

# Data Types

Python has several built-in data types. The most common ones are:

- Integers (int): Whole numbers, e.g., 5, -10, 0.
- Floats (float): Decimal numbers, e.g., 3.14, -0.5, 2.0.
- Strings (str): Sequences of characters, e.g., "hello", 'Python'.
- Booleans (bool): Logical values, True or False.
- Lists (list): Ordered, mutable collections, e.g., [1, "apple", 3.5].
- Tuples (tuple): Ordered, immutable collections, e.g., (1, "apple", 3.5).
- Sets (set): Unordered collections of unique elements, e.g., {1, 2, 3}.
- Dictionaries (dict): Key-value pairs, e.g., {"name": "Alice", "age": 25}.

Check the type of a variable using the `type()` function:

```python

print(type(3.14))     # <class 'float'>
print(type("hello"))  # <class 'str'>
print(type(True))     # <class 'bool'>
```


Using `*args` and `**kwargs` for a variable number of arguments:

```python
def sum_all(*args):
    return sum(args)

def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_info(name="Alice", age=30)
```

# Classes and Objects

Classes are blueprints for creating objects.

```python
class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        return f"{self.name} says Woof!"

my_dog = Dog("Buddy", "Golden Retriever")
print(my_dog.bark())
```

Inheritance allows one class to inherit features from another:

```python
class Cat(Dog):
    def meow(self):
        return f"{self.name} says Meow!"

my_cat = Cat("Whiskers", "Persian")
print(my_cat.bark()) # Inherited method
print(my_cat.meow())  # Own method
```
