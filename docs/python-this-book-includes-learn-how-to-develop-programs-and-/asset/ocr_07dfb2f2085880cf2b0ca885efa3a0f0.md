# Testing String Using “in” and “not in”

The "in" operator represents a Boolean operator that you can apply to determine whether a substring exists within another string. For example: When you define an expression using the "in" operator the result compute to a Boolean.

```
word = "Jackson James John Chris Tom"
ifChris" in word:print("found him!")nelse:
print("can't find Chris")
```
