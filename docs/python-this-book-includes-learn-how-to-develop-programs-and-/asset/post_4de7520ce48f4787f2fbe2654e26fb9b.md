# Functional Tools

When you pass functions around, sometimes, you may want to partially apply functions to build new functions. As a simple example, say you have a function of two variables:

```python
def exp(base, power):
  return base ** power
```

And you want to use it to create a function of one variable two_to_the whose input is power and whose output is the outcome of exp(2, power)
Of course, you can achieve this using the def, but this can sometimes become unwieldy:

```python
def two_to_the(power):
  return exp(2, power)
```

A different way is to apply functools.partial:

```python
from functools import partial
two_to_the = partial(exp, 2) # is now a function of one variable
print(two_to_the(3)) # 8
```

You can still apply partially to fill in later arguments if you describe their names:

```python
square_of = partial(exp)
```
