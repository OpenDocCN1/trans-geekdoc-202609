+   - “k-nearest neighbors regression” - The output is the object's property value, which is computed as an average of the “k-nearest neighbors” values.

A helpful method for both “classification” and “regression” can be assigning weights to the neighbors’ contributions, to allow close neighbors to make more contributions in the average, compared to the neighbors located far apart. For instance, a known "weighting scheme" is to assign individual neighbor a weight of "1/d", where "d" denotes the distance from the neighbor. The neighbors are selected from a set of objects for which the “class” (for “k-NN classification”) or the feature value of the “object” (for “k-NN regression”) has already identified.

# # Clustering

We enter the category of unsupervised machine learning, with “clustering methods” because its objective is to “group or cluster observations with comparable features”. Clustering methods do not output data to train but allow the output to be defined by the algorithm. Only data visualizations can be used in clustering techniques to check the solution’s quality.
