Functions in Python are first-class. In other words, you can allocate them to variables and pass them into functions like any other argument.
It is easy to define short anonymous functions:

```
y = apply_to_one(lambda x: x * 4) # equals 5
```

You can allocate lambdas to variables, although most people prefer to use the def keyword. Parameters of a function can also be assigned using a default argument, which is only relevant when you want a value other than the default. Sometimes, it is important to specify arguments using names.

tab_string = "\t"

# Exceptions

When something is wrong, Python throws an exception. When not addressed, these exceptions will crash your program. So to prevent your program crashing, you need to use try and except:

```
try:
    print 0 / 0
except ZeroDivisionError:
    print("cannot divide by zero")
```

Exceptions don't work well in all languages, but in the case of Python, exceptions make your code cleaner. So you should make a habit of writing exceptions in Python.
