Technically the data segregation stage is not considered as an independent machine learning pipeline, however, an "API" or tool has to be provided to support this. In order to return the required datasets, the next 2 stages ("model training" and "model assessment") must be able to call this "API". As far as the organization of the code is concerned, a "strategy pattern" is required that the "caller service" can select the appropriate algorithm during execution and the capability to inject the percentage or random seed is obviously required. The "API" must also be prepared to return the information with or without labels, to train and test the model respectively. A warning can be created and passed along with the dataset to secure the "caller service" from defining parameters that could trigger the uneven distribution of the data.
