SQL-like joins can be conducted on the DataFrame using pandas. Let’s create a lookup DataFrame, this will assign levels to each of the grades using the command below:

```
>>> grade_lookup = {'GRADE LEVEL': pd.Series(['ELEMENTARY', 'MIDDLE/HIGH', 'MISC']), 'LEVEL': pd.Series([1, 2, 3])}
>>> grade_lookup = DataFrame(grade_lookup)
```

Let's consider the first five rows of the GRADE data column as an example for calculating the joins:

```
>>> df['GRADE LEVEL'][:0:5]
GRADE LEVEL DISTRICT TOTAL
0 ELEMENTARY
1 MIDDLE/HIGH
2 DISTRICT TOTAL
3 ELEMENTARY
```

# The Inner Join

The image below represents an example of an inner join:

![](bbox=[0.134, 0.602, 0.483, 0.767])

An inner join can be executed using the following command:

```
>>> d_sub = df[0:5].join(grade_lookup.set_index(['GRADE LEVEL']),
onon=['GRADE LEVEL'], how='inner')
>>> d_sub['GRADE LEVEL', 'LEVEL']
```
