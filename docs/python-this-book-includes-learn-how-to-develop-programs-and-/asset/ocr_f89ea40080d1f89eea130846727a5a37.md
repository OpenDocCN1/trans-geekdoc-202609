The python SciPy package has helpful functions to complete statistical computations. You can get it from http://www.scipy.org/. These commands allow you to plot the binomial distribution.

```
>>> from scipy.stats import binom
>>> import matplotlib.pyplot as plt
>>> fig, ax = plt.subplots(1, 1)
>>> x = [0, 1, 2, 3, 4, 5, 6]
>>> n, p = 6, 0.5
>>> rv = binom(n, p)
>>> ax.vlines(x, 0, rv.pmf(x), colors='k', linestyle='-', lw=1, label='Probability')
>>> ax.legend(loc='best', frameon=False)
>>> plt.show()
```
