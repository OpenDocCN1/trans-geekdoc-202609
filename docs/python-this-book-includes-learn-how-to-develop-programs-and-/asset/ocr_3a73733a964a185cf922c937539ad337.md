# Logistic Regression

Logistic regression is another supervised learning approach, which is a probabilistic classification model. It is normally used in predicting a binary predictor, such as whether a credit card transaction is fraudulent. Logistic regression relies on logistics. A logistic function is a useful function that can accept any value from negative infinity to positive infinity, and display values from 0 to 1. Therefore, it is interpretable as a probability. A logistic function that outputs predicted values from o to 1 depending on the x variable:

```
F(x) = \frac{1}{1+e^{-(\beta_0+\beta_1x)}}
```

In the above example, x will be the independent variable, and F(x) will be the dependent variable.
