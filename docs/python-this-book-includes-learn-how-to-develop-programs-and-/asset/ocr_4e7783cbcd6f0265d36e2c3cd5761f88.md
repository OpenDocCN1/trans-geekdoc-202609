The join occurs with the join () method. The first argument selects the DataFrame on which the lookup occurs. Remember that the grade_lookup DataFrame's index is being set using the set_index () method. This is necessary for a join because the join method will not know which column to join the DataFrame to.

The second argument accepts a column of the d DataFrame to join the data. The third argument defines the join as an inner join.
