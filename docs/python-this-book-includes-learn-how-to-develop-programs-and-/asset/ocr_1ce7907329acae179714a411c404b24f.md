# Pandas Series

It can be defined as "one-dimensional labeled array capable of holding data
of any type (integer, string, float, python objects)." Simply put, it is like a
column in an excel spreadsheet. To generate a “Pandas Series" from an array,
a“NumPy” module must be imported and used with “array ( )" function as
shown in the code below:

```
# import pandas as pd
import pandas as pd
```

```
# import numpy as np
import numpy as np
```

```
# simple array
data = np.array(['m','a','c','h','I','n','e'])
```

```
ser = pd.Series(data)
print(ser)
```
