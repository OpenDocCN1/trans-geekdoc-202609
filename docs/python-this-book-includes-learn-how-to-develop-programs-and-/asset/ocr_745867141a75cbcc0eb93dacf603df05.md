# NumPy (Base N-Dimensional Array Package)

"NumPy" is the basic package with Python to perform scientific computations. It includes among other things: "a powerful N-dimensional array object; sophisticated (broadcasting) functions; tools for integrating C/C++ and Fortran code; useful linear algebra, Fourier transform, and random number capabilities." NumPy is widely recognized as an effective multi-dimensional container of generic data in addition to its scientific uses. It is possible to define arbitrary data types. This enables NumPy to integrate with a broad variety of databases seamlessly and quickly. The primary objective of NumPy is the homogeneity of the multidimensional array. It consists of element table (generally numbers), all of which are of the same sort and are indicated by tuples of non-negative integers. The dimensions of NumPy are called "axes" and array class is called "ndarray".

# Pandas (Data Structures and Analysis)

Pandas provide highly intuitive and user-friendly high-level data structures. Pandas has achieved popularity in the machine learning algorithm developer community, with built-in techniques for data aggregation, grouping, and filtering as well as results of time series analysis. The Pandas library has two primary structures: one-dimensional "Series" and two-dimensional "Data Frames".
