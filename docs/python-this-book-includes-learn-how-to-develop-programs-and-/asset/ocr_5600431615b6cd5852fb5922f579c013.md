# THE TUPLE

The Tuple is a way in Python to group information together. It is like a list, except that we cannot modify it once we have created a tuple.

Let's go ahead and create a tuple that groups together information about an individual.

Let's create a Person Tuple that will take str, and an int as the two types of data we want to store. The first value is a string storing a name, and the second is an integer value for how many miles they ran this month.

```
Person = ('Mike',100)
>>> Person
('Mike', 100)
```

So, the tuple is just a collection of values held together. We can actually store tuples in a list if we want. Let's create some tuples with names and each person's favorite number as a value in the second field.

```
>>> Mike = ('Mike',1)
>>> Willie = ('Willie',2)
>>> Tomoki = ('Tomoki',17)
>>> Raoul = ('Raoul',14)
>>> BestFriends = ['Willie,Mike,Tomoki,Raoul]
>>> BestFriends
[('Willie', 2), ('Mike', 1), ('Tomoki', 17), ('Raoul', 14)]
```

Now when the BestFriends list is output, we see that each entry (separated by comma) is a tuple that we created. We can then access elements in our list by using their position in the list as we have previously done. Our list will return a tuple. And if we check the type of the entry, we see that it is indeed a tuple.

```
>>> BestFriends[0]
('Willie', 2)
>>> type(BestFriends[0])
<type 'tuple'>
```
