The above loop will accept the yielded values one at a time until none are left:

```
for i in lazy_range(10):
    do_something_with(i)
```

Python has a lazy_range function known as xrange, and in python 2, the range is lazy. In other words, you can even come up with an infinite sequence.
However, you should not iterate over it without using some form of break logic.
The opposite end of laziness is that you can only go over it once. If you want to iterate through something different times, you'll need to recreate the generator every time or apply a list.
Another way to build a generator is to apply the for comprehensions surrounded in parentheses.
Keep in mind that every dict contains items ( ) method which will return a list of key-value pairs. Most frequently, you'll apply the iteritems () method, which lazily generates the key-value pairs every time you go over it.

import random
four_uniform_randoms = [random.random() for _ in range(4)]
