Pay attention to how pygal highlights the o lines on the x and y coordinates. This is a freestanding supported by the pygal library to demonstrate negative values. Additionally, take note of the add () function, and the way each value is underlined as an (x. y) coordinate, classified in an array. Let's create another chart, this time using two plots. In the following case, we will create using Value 1 and Value 2. Add the following code into your Pygal script and run it.

```
# -*- coding: utf-8 -*
import pygal
xy_chart = pygal.XY()
xy_chart.add('Value 1', [[-50, -30), (100, 45]])
xy_chart.add('Value 2', [[-2, -14), (370, 444)])
xy_chart.render_to_file("xy_chart.svg")
```
