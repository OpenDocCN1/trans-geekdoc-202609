For every component, you print the Eigenvalue, the percentage of the variance represented by that component, and the cumulative percentage value of the variance described. Now, if you add the first two components, then you can describe 95.80% of the variance within the data.

The decomposition of a correlation matrix into its Eigenvectors and values is a general method that can be applied to any matrix. In the following case, you will use it in a correlation matrix to understand the principal axes of the data distribution, that is, axes through which the highest variance in the data is observed.
