# 5.3 变化检测

数据中的变化检测是一个广泛的主题，在统计学中有着悠久的传统；参见 [27]。并非所有方法都适用于流式处理，通常是因为它们需要对数据进行多次遍历。我们仅介绍几种适合流式处理的方法。

## 5.3.1 变化检测的评估

以下标准与评估变化检测方法相关。它们涉及此类算法必须面对的根本权衡 [130]，即检测真实变化与避免虚假警报之间的权衡。许多标准取决于我们想要检测的变化的最小幅度 `θ`。

*   **平均虚假警报间隔时间，MTFA：** 度量在没有变化发生时产生虚假警报的频率。虚假警报率 (FAR) 定义为 `1/MTFA`。
*   **平均检测时间，MTD(θ)：** 度量学习系统在变化发生时检测并响应变化的能力。
*   **漏报率，MDR(θ)：** 度量发生变化却未产生警报的概率。
*   **平均运行长度，ARL(θ)：** 该指标泛化了 MTFA 和 MTD，指示变化发生后需要等待多久才能检测到该变化。我们有 `MTFA = ARL(0)`，且对于 `θ > 0`，有 `MTD(θ) = ARL(θ)`。

## 5.3.2 CUSUM 检验和 Page-Hinkley 检验
