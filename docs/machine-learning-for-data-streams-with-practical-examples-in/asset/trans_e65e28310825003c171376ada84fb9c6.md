

# 6.1 分类器评估

我们首先回顾如何评估分类器、最流行的分类方法，以及它们如何应用于数据流环境。流环境下任何分类方法的两个重要特征是：在内存和时间方面存在限制（因此我们无法将所有实例存储在内存中），以及分类模型必须能够适应传入数据分布可能发生的变化。这些特征意味着精确解不太可能存在，因此我们应该期望近似解，并因此期望相关误差是有界的。误差界在某些方面是有问题的：当它们自身对生成误差的分布做出的假设很少时，它们往往是保守的（即在实践中，结果比界所预测的要好得多）。当它们确实做出假设时，它们可以与实验结果更加一致，但容易受到那些假设根本不成立的情况的影响。

第三个要求（本章未涉及）是应对特征空间变化的能力。例如，在传感器网络中，为某些特征提供值的一个或多个传感器可能会因故障或更换而时不时离线。替换的传感器可能是更新的型号，因此它们的测量方式可能与过去不同。事实上，传感器被永久移除也是合情合理的。几乎所有流分类算法都假设特征空间是固定的，无法轻松应对这种类型的变化。除了特征空间，类标签的集合也可能随时间变化。因此，算法需要能够应对新类标签的增加和现有类标签的删除。`x` 和 `y` 中的这两种变化都代表了开发新的流分类算法的沃土。

评估是所有数据挖掘过程中最基本的任务之一，因为它有助于决定哪些技术更适合特定问题，以及如何设置参数。主要挑战在于判断一种方法优于另一种方法是否仅属巧合，抑或该说法具有统计显著性。流挖掘中应用的一些方法论与非流式数据（所有数据均可存储在内存中）的情况相同。然而，挖掘数据流带来了新的挑战，必须使用修改后的评估方法论。

在继续之前，有一点值得注意：数据挖掘中几乎所有的发现，特别是分类，都假设数据是独立同分布（IID）的。因此，平稳分布以无特定顺序随机产生数据，且生成数据的底层分布不发生变化。在流式环境中，IID 假设的任何部分都不再成立。例如，在某些时间段内，实例的标签或类别往往是相关的。在入侵检测中，存在漫长的时期所有类标签均为“非入侵”，夹杂着不频繁、短暂的入侵时期。这是数据流挖掘的另一个方面，将从进一步的研究中受益。

评估框架应由以下部分组成：

*   误差估计，
*   评估性能度量，
*   统计显著性验证，以及
*   过程的代价度量。

对于演化数据流，与传统数据挖掘评估的主要区别在于如何进行误差估计。资源有限，交叉验证可能代价太高。我们首先探讨如何定义和估计准确率，然后看哪些度量最适合衡量算法性能。最后我们回顾一些用于检验显著性和衡量整个过程代价的统计技术。

## 6.1.1 误差估计

学习算法的评估程序决定哪些示例用于训练算法，哪些用于测试算法输出的模型。

在传统的批量学习中，第一种方法是将数据集拆分为不相交的训练集和测试集。如果数据有限，则首选交叉验证：我们创建多个模型，并使用训练和测试数据的不同随机排列来平均结果。

在流环境中，（实际上）无限的数据带来了不同的挑战。交叉验证通常计算代价太高，且不那么必要。另一方面，描绘随时间变化的准确率图景至关重要。主要出现以下几种方法：

*   **留出法：** 当数据极其丰富，以至于可以定期拥有测试集时，我们可以在这些留出集上衡量性能。有一个用于持续训练学习器的训练数据流，以及用于定期计算性能的小型测试数据集。在 `MOA` 中，实现这一概念要求用户指定两个参数（假设为 `j` 和 `k`）：`j` 是用于测试的第一个窗口（实例集）的大小，`k` 是测试频率——即每 `k` 个实例测试一次（使用大小为 `j` 的测试集）。

*   **交织测试后训练：** 每个单独的示例可在用于训练*之前*先用于测试模型，并据此增量更新准确率。因此，模型始终在其未见过的示例上接受测试。在 `MOA` 中，该方案使用地标窗口模型实现（考虑从流开始到现在的数据）。

*   **预测式：** 类似于交织测试后训练，但在 `MOA` 中——实现了更近期的示例更重要这一理念，使用滑动窗口或衰减因子。滑动窗口的大小和衰减因子是参数。

*   **交织数据块：** 也类似于交织测试后训练，但按顺序使用数据块。可能需要考虑不同大小的数据块（这是 `MOA` 实现中的一个参数）。

请注意，如果我们将滑动窗口的大小设置为整个数据集中的实例数量，则中间两种方案等价。

留出法评估能更准确地估计分类器在近期数据上的准确率。然而，它需要难以针对真实数据集获取的近期测试数据。还存在一个问题，即如何确保涵盖重要的变化事件：如果留出测试发生在变化不剧烈的时期，则可能会高估分类器性能。

Gama 等人 [115] 提出了一种利用预测式准确率来估计留出法准确率的遗忘机制：包含最近观测值的大小为 `w` 的滑动窗口，或使用衰减因子 `α` 对观测值加权的衰减因子法。衰减因子 `α` 的使用如下：

```
n[i] = 1
```

其中

```
L[i] = α * L[i-1] + (1 - α) * loss(i)
```

此处 `n[i]` 是用于计算损失函数 `L[i]` 的示例数量。我们令 `n[i] = 1`，因为损失 `L[i]` 是针对每个单独示例计算的。

这两种机制的输出非常相似，因为大小为 `w` 的窗口可以用衰减因子 `α ∼ 1/w` 来近似。图 6.1 展示了留出法评估、交织测试后训练评估，以及使用大小为 1,000 的滑动窗口的预测式评估的对比。观察图 6.1 中的曲线，对于该数据集而言，使用滑动窗口的预测式评估似乎是留出法评估的一个良好近似。
