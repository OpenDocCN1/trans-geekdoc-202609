
目前，SAMOA 包含以下算法：

*   **垂直霍夫丁树 [149]：** 垂直并行方法按属性对实例进行划分以实现并行处理。具有垂直并行性的决策树诱导器处理划分后的实例（由属性子集组成）以并行计算分裂标准。例如，如果我们有包含 100 个属性的实例，并将实例划分为 5 个部分，则每部分将有 20 个属性。在每个部分中，算法并行处理这 20 个属性以确定局部最佳分裂属性，并结合并行计算结果以确定全局最佳分裂属性并增长树。

*   **AMRules [241]：** SAMOA 使用垂直和水平并行性的混合体在集群上分发 AMRules。AMRules 构建的决策规则是可理解的模型，其中规则的前件是属性值条件的合取，后件是属性的线性组合。

*   **自适应装袋：** 这是一种易于并行化的方法。每个装袋副本被分配给不同的处理器。

*   **分布式聚类：** SAMOA 中的聚类分为两层：第一层对拆分后的数据执行聚类，第二层使用第一层输出的微簇执行元聚类。

### 12.2.1 任务

MOA 中的主要任务如下：

*   **WriteStreamToARFFFile** 将数据流输出到 ARFF 文件。ARFF 是 WEKA 项目 [107] 使用的一种方便的数据格式，它通过包含指定属性类型、名称和值的头部来扩展 CSV 格式。

*   **MeasureStreamSpeed** 测量数据流的速度。

*   **LearnModel** 从数据流中学习预测模型。

*   **EvaluateModel** 在数据流上评估静态预测模型。

*   **EvaluatePeriodicHeldOutTest** 通过定期在保留集上测试，在数据流上评估分类器。

*   **EvaluateInterleavedTestThenTrain** 通过按顺序对每个实例先测试后训练，在数据流上评估分类器。没有遗忘机制，因此所有实例在评估中同等重要。

*   **EvaluatePrequential** 通过按顺序对每个示例先测试后训练，在数据流上评估分类器。它可以选择使用滑动窗口或衰减因子作为遗忘机制。

*   **EvaluatePrequentialCV** 通过执行 *k* 折分布式交叉验证，在数据流上评估分类器；每次新实例到达时，随机选择一个分类器用于测试，使用其他分类器进行训练。它可以选择使用滑动窗口或衰减因子作为遗忘机制。

*   **EvaluateInterleavedChunks** 通过按顺序对数据块先测试后训练，在数据流上评估分类器。

评估方法在第 6.1 节中定义。

*   **ArffFileStream** 从 ARFF 文件读取数据流。
