## 编程最佳实践

* 尽量减小变量的作用域。
* 优先使用组合而非继承。
* 优先使用静态成员类而非非静态成员类。
* 尽量减小类和成员的访问权限。
* 通过接口引用对象。
* 使用构建器代替参数过多的构造函数。
