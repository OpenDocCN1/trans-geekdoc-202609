# 9.1 评估度量

不幸的是，评估聚类不像评估分类器那样明确无误。文献中描述了许多不同的聚类质量度量，也许太多了，它们形式化了“良好聚类”应达到的不同期望。

度量可分为两大类：结构性或内部度量，以及基于真实标签的度量，称为外部度量。第一类严格基于数据点和获得的聚类结果。关于三十种内部度量的广泛研究见文献 [178]，外部度量的其他研究包括 [57, 231, 250]。一些示例如下：

*   **凝聚度：** 数据集中某点到其分配的簇质心的平均距离。越小越好。
*   **SSQ（误差平方和）：** 数据点到其分配质心的平方距离之和。与凝聚度密切相关。越小越好。
*   **分离度：** 某点到分配给其他簇的点的平均距离。越大越好。
*   **轮廓系数：** 粗略地说，是凝聚度与点到其第二近质心的平均距离之比。它奖励那些点非常接近其分配的质心且远离任何其他质心的聚类结果，即具有良好凝聚度和良好分离度的聚类。

另一方面，外部度量需要知道数据点的“真实”聚类，或真实标签，根据定义，这在实际场景中几乎总是未知的。然而，在评估新的聚类算法时，人们通常从已知的生成器创建合成数据集，因此可以将算法获得的聚类与真实模型进行比较。在这种情况下，某些度量类似于分类或信息检索中应用的其他度量：

*   **准确率：** 分配到其“正确”簇的点的比例。
*   **召回率：** 一个簇中实际上被分配到该簇的点的比例。
*   **精确率：** 分配到一个簇且真正属于该簇的点的比例。
*   **纯度：** 在纯度最高的聚类中，簇内的所有点都属于同一个真实标签类别或簇。形式上，纯度为

# 9.2 `k`-means 算法

`k`-means（也称为 Lloyd 算法）是聚类中最常用的方法之一，因其简单性而著称。[图 9.1](#chapter_9.xhtml#fig9-1) 展示了其伪代码。

k-means 聚类算法，或 Lloyd 算法。

`k`-means 假设点集 `P` 是某维度 `d` 下 ℜ^(`d`) 的子集，以便点可以相加和求平均。算法以未指定的方式选择 `k` 个质心开始——例如，随机选择。之后，迭代两个步骤：首先，将每个实例分配给最近的质心；其次，将质心重新计算为分配给它的示例的均值或质心。该过程通常在没有点改变质心时停止，或在执行了最大迭代次数后停止。产生的 `k` 个质心决定了算法找到的 `k` 个簇。

`k`-means 隐含的贪心启发式仅保证收敛到局部最小值，且 `k`-means 找到的解的质量和收敛速度众所周知地取决于初始随机分配步骤。`k`-means++ [19] 通过使用新的初始化步骤，提高了该方法相对于纯随机方法的稳定性：

```
1        choose center c[1] to be p[1]
2        for i = 2,…,k
3              do select c[i] = p ∈ P with probability d(p,C)/cost(C,P).
```

简而言之，初始中心随机选择，但所有后续中心的选择概率与其到已选中心的距离成正比。分散 `k` 个初始簇中心有助于加快收敛速度并达到更好的局部最小值。流式聚类方法 StreamKM++ 也采用了这一策略。

将 `k`-means 转换为流式设置并不直接，因为它需要反复迭代数据集。我们将看到，大多数流式聚类方法有两个阶段，一个在线阶段和一个离线阶段。在线阶段更新数据的统计信息，生成某种形式的摘要或草图，通常表示为称为 `microclusters`（微簇）的少量点。然后离线阶段利用这些摘要高效地计算最终聚类，要么在固定的时间间隔，要么按需进行。

# 9.3 BIRCH、BICO 和 CLUSTREAM

这三种算法是增量式的，并共享一个共同的思想：用微簇来总结数据流，以便在离线阶段对它们进行聚类。

平衡迭代缩减和聚类利用层次结构 (BIRCH) 由 Zhang 等人 [258] 提出。它是第一种提出使用所谓的 `clustering feature`（聚类特征，CF）向量来表示微簇的增量聚类方法。假设数据集点是 `d` 个实数的向量，CF 是一个三元组 (`N, LS, SS`)，由以下项目组成：

*   `N`：CF 中数据点的数量
*   `LS`：`N` 个数据点的 `d` 维向量和
*   `SS`：`N` 个数据点的 `d` 维平方和。

CF 具有以下有用属性：

*   它们是可加的：`CF[1] + CF[2] = (N[1] + N[2], LS[1] + LS[2], SS[1] + SS[2])`。
*   从 CF 很容易计算点到簇的距离、平均簇间距离和平均簇内距离。

BIRCH 的另一个特点是使用 `CF trees`（CF 树），一种类似于经典 `B+` 树数据结构的高度平衡树。它由两个参数定义：分支因子 `B`，即任何给定节点可能拥有的最大子节点数，以及叶子半径阈值 `R`。算法维护这样一个属性：由叶子表示的所有点都落在该处质心半径 `R` 的球内。每个叶子节点和每个内部节点都包含一个 CF 向量。

BIRCH 算法包含多达四个阶段：

> 阶段 1：扫描所有数据并构建初始内存 CF 树
>
> 阶段 2：将 CF 树压缩成一个更小的树（可选）
>
> 阶段 3：全局聚类
>
> 阶段 4：细化簇（可选且离线，因为它需要更多遍数）。
