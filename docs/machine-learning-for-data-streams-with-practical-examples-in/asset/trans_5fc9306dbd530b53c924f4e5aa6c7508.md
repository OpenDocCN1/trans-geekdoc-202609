C 语言源代码公开可用。内置函数基于所引用论文（第 924 页），在公开的 C 语言实现中对应 `pred20` 至 `pred29` 函数。扰动函数的工作方式遵循 C 语言实现，而非论文中的描述。

*   **generators.HyperplaneGenerator** 生成预测旋转超平面类别的问题。

该问题在文献 [138] 中被用作 CVFDT 与 VFDT 对比的测试平台。*d* 维空间中的超平面是满足 ![](images/pg206-in-2.png) 的点 *x* ∈ℜ^(*d*) 的集合，其中 *x*[*i*] 是点 *x* 的第 *i* 个坐标。满足 ![](images/pg206-in-3.png) 的点示例被标记为正类，满足 ![](images/pg206-in-4.png) 的点示例被标记为负类。超平面适用于模拟时变概念，因为我们可以通过改变权重的相对值，以平滑的方式改变超平面的方向和位置。我们通过给每个权重属性添加漂移来引入变化：*w*[*i*] = *w*[*i*] + *dσ*，其中 *σ* 是变化方向反转的概率，*d* 是变化速度。

*   **generators.LEDGenerator** 生成预测七段 LED 显示器上显示数字的问题。

该数据源源自 CART 书籍 [56]。目标是预测七段 LED 显示器上显示的数字，其中每个属性有 10% 的几率被反转。其最优贝叶斯分类率（最佳可能分类器的速率）为 74%。实验中使用的特定生成器配置（led）产生 24 个二元属性，其中 17 个是无关属性。

*   **generators.LEDGeneratorDrift** 生成预测七段 LED 显示器上显示数字（带漂移）的问题。

*   **generators.RandomRBFGenerator** 生成随机径向基函数数据流。

设计该生成器是为了提供一种替代的复杂概念类型，这种类型不易用决策树近似。RBF（径向基函数）生成器的工作原理如下：生成固定数量的随机簇。每个簇有一个随机中心、一个标准差、一个类标签和一个权重。通过按权重成比例的概率选择一个簇，然后从以该簇中心为中心、以该簇在每个轴上的标准差为标准差的高斯分布中生成一个点，从而产生新示例。这实际上在每个中心周围创建了一个密度各异的正态分布超球体示例。仅生成数值属性。被选中的簇也决定了示例的类标签。

*   **generators.RandomRBFGeneratorDrift** 生成带漂移的随机径向基函数数据流。漂移通过以恒定速度移动中心来引入。

*   **generators.RandomTreeGenerator** 基于随机生成的树生成数据流。

该生成器基于文献 [88] 中的提议，产生的概念应有利于决策树学习器。它通过随机选择属性进行分裂，并为每个叶节点分配随机类标签来构建决策树。树构建完成后，数据流中的示例通过为属性分配均匀分布的随机值来生成，这些值再通过树确定类标签。该生成器具有参数以控制类别数量、属性数量、名义属性标签和树的深度。

生成示例后可引入噪声。对于离散属性和类标签，噪声概率参数决定了某个特定值被切换为非原始值的几率。对于数值属性，会向所有值添加一定程度的随机噪声，该噪声源自标准差等于原始值标准差乘以噪声概率的随机高斯分布。

*   **generators.SEAGenerator** 生成 SEA 概念函数。

该生成器在文献 [233] 中提出，用于研究对突发概念漂移的反应。数据流使用三个属性生成，只有前两个相关。所有三个属性的值均在 0 到 10 之间。数据流中的点被划分为四个具有不同概念的块。在每个块中，0/1 类由不等式 *f*[1] + *f*[2] ≤ *θ* 确定，其中 *f*[1] 和 *f*[2] 代表前两个属性，*θ* 为阈值。这四个类最常用的阈值分别为 9、8、7 和 9.5。

*   **generators.STAGGERGenerator** 生成 STAGGER 概念函数，由 Schlimmer 和 Granger 在文献 [223] 中提出。

STAGGER 概念是三个属性的布尔函数，用于编码对象：大小（小、中、大）、形状（圆、三角、矩形）和颜色（红、蓝、绿）。概念是两个属性的合取或析取，例如 *(颜色=红 且 大小=小)* 或 *(颜色=绿 或 形状=圆)*。

*   **generators.WaveformGenerator** 生成预测三种波形类型之一的问题。

它与 LED 数据集同源。该任务的目标是区分三种不同的波形类别，每种类别由两个或三个基础波组合生成。最优贝叶斯分类率已知为 86%。该问题有两个版本：wave21 拥有 21 个数值属性，均包含噪声；wave40 则额外引入了 19 个无关属性。

*   **generators.WaveformGeneratorDrift** 生成预测三种波形类型之一（带漂移）的问题。

## 12.2.4 决策树

*   **HoeffdingTree** 适用于无变化数据流的决策树诱导器，详见第 6.3.2 节。要在叶节点使用多数类学习器，请使用 `HoeffdingTree -l MC`。

*   **DecisionStump** 仅含单个内部节点的决策树，因此仅测试一个属性来预测实例。

*   **HoeffdingOptionTree** Hoeffding 选项树，详见第 7.6.1 节。可以选择放置在叶节点的分类器类型：多数类、朴素贝叶斯或自适应朴素贝叶斯。默认选择自适应朴素贝叶斯，因为它往往能给出最佳结果；它监控多数类和朴素贝叶斯预测器的错误率，并跟踪近期实例上表现较好的预测器进行切换。要在叶节点使用多数类学习器运行实验，请使用 `HoeffdingOptionTree -l MC`。

*   **HoeffdingAdaptiveTree** 适用于演变数据流的决策树诱导器，详见第 6.3.5 节。

*   **AdaHoeffdingOptionTree** 适用于流式数据的自适应 Hoeffding 选项树，叶节点使用自适应朴素贝叶斯分类器 [38]。*自适应 Hoeffding 选项树* 是一种具有以下改进的 Hoeffding 选项树：每个叶节点存储当前错误的估计值，使用 *α* = 0.2 的 EWMA 计数器进行估计。投票过程中每个节点的权重与其错误的倒数平方成正比。
