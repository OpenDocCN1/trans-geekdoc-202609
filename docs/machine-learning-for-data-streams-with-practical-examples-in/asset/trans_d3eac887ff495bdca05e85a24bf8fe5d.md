

## 第 2、3 和 4 阶段：离线部分

特别是第 3 阶段，基于 CF 树中收集的信息执行批量聚类。第 1 阶段是在线过程，也是实际作用于数据流的过程。对于每个到达的点，算法会下降树，更新遍历的内部节点 CF 的统计信息，以到达最接近该点的叶节点。然后它检查叶节点是否能在半径 `R` 内吸收该点。如果可以，则通过更新叶节点统计信息将该点“分配”给叶节点。如果不行，则为新点创建一个新叶节点。这个新叶节点可能导致父节点拥有超过 `B` 个子节点；如果是这样，它必须分裂成两个，以此类推，递归地向上直到根节点。此处未描述的另一条规则，会被应用于合并在此过程中可能变得过近的叶节点和内部节点。

## BICO

**BICO**（“BIRCH meets coresets for `k`-means clustering”，即 BIRCH 结合用于 `k` 均值聚类的核心集）由 Fichtenberger 等人 [101] 提出。它将 BIRCH 的数据结构与用于聚类的核心集理论概念相结合。核心集在 9.6 节中有详细解释。BIRCH 通过启发式方式决定如何将点分组到子簇中。BICO 的目标是找到一个不仅规模小，而且能提供近似原始点集保证的简化集合。

## CLUSTREAM

**CLUSTREAM** 由 Aggarwal 等人 [6] 提出，旨在作为 BIRCH 的一种自适应扩展，能够处理不断变化的数据流。在 CLUSTREAM 中，CF 树的节点维护形式为 `(N, LS, SS, LT, ST)` 的 CF 向量，这通过两个额外的时间特征扩展了 BIRCH CF：

*   `LT`：时间戳之和
*   `ST`：时间戳平方和

CLUSTREAM 的离线阶段只是定期对 CF 树叶节点处的微簇应用 `k` 均值算法。在线阶段类似于 BIRCH，但它考虑了簇的新近度。它在内存中保持最大数量的微簇。如果一个点需要创建一个新微簇（叶节点）但没有更多可用空间，算法要么删除最旧的微簇，要么合并两个最旧的微簇。“最旧”微簇的概念是通过考虑微簇中是否有显著的近期活动来定义的。更准确地说，统计量 `LT` 和 `ST` 被用来计算其时间戳的平均值和标准差；假设时间戳呈正态分布，算法可以利用它们来决定微簇中所需比例的点是否早于期望的新近度阈值。

由于选择删除的是最旧的簇而不是最小的簇，这赋予了 CLUSTREAM 一个有趣的特性：通过查看具有相似时间戳分布的微簇，我们可以获得所需时间范围内的聚类快照，对更近的时间范围分辨率更高，随着时间推移分辨率逐渐降低。这有时被称为*金字塔式*时间范围。

# 9.4 基于密度的方法：DBSCAN 和 Den-Stream

基于密度的聚类器基于这样一种思想：簇的形成不仅基于距离上的整体邻近性，还基于连接的密度。因此，它们生成的簇可能不是球形的，而是具有适应特定被聚类数据形状的形状。

**DBSCAN** 算法 [96] 由 Ester 等人提出，是最著名的基于密度的离线算法。它基于这样一种思想：簇应该围绕其邻域内拥有大量点的点来构建。以下定义将这一思想形式化：

*   `p` 的 `ε`-邻域是距离 `p` 在 `ε` 或以内的点的集合。
*   **核心点** 是其 `ε`-邻域具有至少 `μ` 总权重（数据集点的比例）的点。
*   **密度区域** 是核心点 `ε`-邻域的并集。
*   如果 `q` 在 `p` 的 `ε`-邻域内，则点 `q` 从 `p` **直接可达**。如果存在序列 `p[1], …, p[n]` 使得 `p[1] = p`，`p[n] = q`，且每个 `p[i+1]` 都从 `p[i]` 直接可达，则点 `q` 从 `p` **可达**。
*   核心点 `p` 与所有从它可达的（核心或非核心）点形成一个簇。
*   所有从核心点不可达的点都被视为 **异常值**。

请注意，簇由其包含的任意核心点决定，并且对于给定的 `ε` 和 `μ` 值，这些定义为任何数据集创建了唯一的聚类。

DBSCAN 算法具有参数 `ε` 和 `μ`，并利用这些属性来寻找这个唯一的聚类。它以任意顺序访问数据集中的点。对于一个先前未访问的点 `p`，它找到所有从 `p` 直接 `ε`-可达的点。如果发现 `p` 是一个 `μ` 核心点，则形成一个新簇，并将所有从 `p` 可达的点添加到该簇中并标记为已访问；否则，如果 `p` 的权重低于 `μ`，则暂时将其标记为“异常值”，并继续处理下一个未访问的点。异常值稍后可能被发现从真正的核心点可达，并被宣布为“非异常值”并添加到某个簇中。

观察可知，DBSCAN 强烈依赖非流式处理，因为每个点可能被反复访问。

**Den-Stream** 由 Cao 等人 [61] 开发，是一种基于与 DBSCAN 相似思想但使用微簇快速计算在线统计信息的基于密度的流式方法。它使用阻尼窗口模型，意味着每个数据点的权重使用衰减函数 `f(t) = 2^(-λt)` 指数级减小，其中 `λ > 0`。

微簇有两种类型：根据权重是大于还是小于 `μ`，微簇被称为 **潜在核心微簇** 或 **异常值微簇**。因此，异常值微簇是尚未（或还没有）拥有足够权重被视为核心的微簇。

**DEN-STREAM** 方法有两个阶段：在线阶段和离线阶段。它们的伪代码如 [图 9.2](#chapter_9.xhtml#fig9-2) 所示。在在线阶段，每当一个新点到达时，DEN-STREAM 首先尝试将其合并到潜在微簇之一中。如果不可能，则尝试将该点与异常值微簇合并。如果异常值微簇的权重增加到足以成为潜在微簇，则该微簇被提升。否则，DEN-STREAM 启动一个新的异常值微簇。离线阶段包括移除未达到足够权重的微簇，并执行批量 DBSCAN 聚类。

# 9.5 CLUSTREE

迄今为止介绍的流式聚类算法都需要应用离线阶段才能在请求时生成簇。相比之下，**CLUSTREE**（Kranen 等人 [150]）是一种 **随时聚类** 方法，即它可以在任何时间点提供聚类结果。它是一种无参数算法，能自动适应流的速度，并能检测流中的概念漂移、新颖性和异常值。

CLUSTREE 使用一种紧凑且自适应的索引结构来维护流摘要，具有对数插入时间。该结构是一棵平衡树，其中每个节点包含一定数量点的 CF，类似于 CLUSTREAM。这棵树包含不同粒度层级的微簇层次结构。平衡条件保证了对所有微簇的对数访问时间。
