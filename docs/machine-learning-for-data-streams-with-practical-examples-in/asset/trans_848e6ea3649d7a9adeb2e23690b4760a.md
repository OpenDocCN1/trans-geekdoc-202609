

## 5.3.4 漂移检测方法

Gama 等人 [114] 提出的漂移检测方法（DDM）适用于预测模型的场景。该方法监控在先前流数据项上学习到的模型所产生的错误数量。通常，随着使用数据的增多，模型的错误率应该会降低或保持稳定，这假设学习方法能控制过拟合，且数据和标签分布是平稳的。相反，当 DDM 观察到预测错误率增加时，它将其视为发生了变化的证据。

更准确地说，令 `p[t]` 表示时间 `t` 时预测器的错误率。由于 `t` 个样本中的错误数量服从二项分布，其在时间 `t` 的标准差由 `sqrt(p[t] * (1 - p[t]) / t)` 给出。DDM 存储截至时间 `t` 观察到的最小错误率值 `p[min]`，以及该时刻的标准差 `s[min]`。随后执行以下检查：

*   若 `p[t] + s[t] ≥ p[min] + 2·s[min]`，则发出警告。从此时起，为预期可能发生的变化声明，存储新的样本。
*   若 `p[t] + s[t] ≥ p[min] + 3·s[min]`，则宣告发生变化。由学习方法诱导的模型被丢弃，并使用自警告发生以来存储的样本构建新模型。`p[min]` 和 `s[min]` 的值也随之重置。

这种方法通用且简单易用，但其缺点是响应变化可能过于迟缓。确实，由于 `p[t]` 是基于上次变化以来的所有样本计算的，因此在变化发生后可能需要许多观测值才能使 `p[t]` 显著大于 `p[min]`。此外，对于缓慢变化，警告后内存中保留的样本数量可能变得很大。

文献 [216] 中展示并深入分析了一种使用 EWMA 来估计错误的改进方法。

## 5.3.5 ADWIN

ADWIN 算法（自适应滑动窗口，ADaptive sliding WINdow）[30, 32] 是一种基于第 4.7 节所述指数直方图的变化检测器和估计算法。它旨在解决前述变化估计和检测方法中的一些问题。所有这些问题均可归因于快速响应变化与减少误报之间的权衡。

通常，这种权衡通过要求用户输入（或猜测）一个截止参数来解决。例如，EWMA 中的参数 `α` 指示如何对近期样本与较旧样本进行加权；`α` 越大，方法对变化的反应越快，但由于统计波动，误报率也会越高。卡尔曼滤波器、CUSUM 或 Page-Hinkley 检验中的参数起着类似的作用。对于基于窗口的统计检验，我们一方面希望有长窗口，使每个窗口上的估计更稳健；另一方面又希望有短窗口，以便在变化一发生就能尽快检测到。DDM 方法没有此类参数，但其平均检测时间不仅取决于变化的幅度，还取决于之前无变化运行的长度。

直观上，ADWIN 算法通过同时在多个尺度上检查变化来解决这一权衡，就好像在 EWMA 中同时尝试多个 `α` 值，或在基于窗口的算法中同时尝试多个窗口长度一样。用户无需猜测变化发生的频率，也无需猜测多大的偏差应触发警报。指数直方图的使用使我们能比暴力法更高效地（在时间和内存上）实现这一点。在负面方面，它在计算上比 EWMA 或 CUSUM 等简单方法代价更高（在时间和内存上）：每项处理时间和内存不是常数，而是被监控的最大窗口长度的对数函数。因此，当变化的尺度未知且这一事实可能成问题时，应使用该方法。

ADWIN 以一种定义明确的方式解决了跟踪比特流或实值数字流平均值的问题。它维护一个可变长度的最近见项窗口，该窗口具有这样的性质：其长度是在统计上与假设“窗口内部平均值未发生变化”一致的最大长度。更准确地说，当且仅当有足够证据表明窗口的旧片段的平均值与窗口其余部分的平均值不同时，该旧片段才会被丢弃。这有两个后果：一是每当窗口收缩时，变化都能被可靠地检测到；二是当前窗口上的平均值可在任何时候作为流中当前平均值的可靠估计（除非存在尚未清晰可见的极小或近期变化）。下面我们更详细地描述该算法。

ADWIN 的输入是一个置信值 `δ ∈ (0, 1)` 和一个（可能无限的）实值序列 `x[1], x[2], x[3], …, x[t], …` `x[t]` 的值仅在时间 `t` 可用。

该算法由一个测试 `T(W[0], W[1], δ)` 参数化，该测试比较两个窗口 `W[0]` 和 `W[1]` 的平均值，并判断它们是否可能来自同一分布。一个好的测试应满足以下标准：

*   若 `W[0]` 和 `W[1]` 由同一分布生成（无变化），则概率至少为 `1 − δ` 时测试判定为“无变化”。
*   若 `W[0]` 和 `W[1]` 由两个不同分布生成，且其平均值相差超过某个量 `ε(W[0], W[1], δ)`，则概率至少为 `1 − δ` 时测试判定为“变化”。

ADWIN 将项目流 `x[t]` 输入指数直方图。对于每个流项目，如果直方图中当前有 `b` 个桶，它最多运行 `b − 1` 次测试 `T`，具体如下：对于 `1…b − 1` 中的 `i`，令 `W[0]` 由最旧的 `i` 个桶组成，`W[1]` 由最近的 `b − i` 个桶组成，然后执行测试 `T(W[0], W[1], δ)`。若某次测试返回“变化”，则假设某处发生了变化并丢弃最旧的桶；指数直方图中隐式存储的窗口随被丢弃桶的大小而收缩。若无测试返回“变化”，则不丢弃桶，因此指数直方图隐式窗口增加 1。

在任何时候，我们都可以查询指数直方图以获取窗口中存储元素平均值的估计。与传统指数直方图不同，滑动窗口的大小 `W` 不是固定的，而是可以随时间增长和收缩。如前所述，`W` 实际上是当前项之前最长的、在其上 `T` 无法检测到任何变化的窗口的大小。ADWIN 使用的内存为 `O(log W)`，其更新时间为 `O(log W)`。
