
# 惰性分类器

惰性分类器基于一个非常简单的想法：分类器由保留部分已见实例组成，并利用最接近待预测类标签实例的那些实例的类标签进行预测。特别地，`k`近邻或`k`-NN方法输出最接近待预测实例的`k`个实例的多数类标签。

对于该分类器，需要预先定义一种接近度或距离概念，且其性能取决于该距离相对于标签的意义程度。

## 示例 2.1

考虑以下推文数据集，我们想在此基础上构建一个模型来预测新到达推文的情感（+ 或 −）。

| **ID** | **文本** | **情感** |
| --- | --- | --- |
| T1 | glad happy glad | + |
| T2 | glad glad joyful | + |
| T3 | glad pleasant | + |
| T4 | miserable sad glad | − |

假设我们要对以下新实例进行分类：

| **ID** | **文本** | **情感** |
| --- | --- | --- |
| T5 | glad sad miserable pleasant glad | ? |

简单分类器将执行以下预测：

*   **多数类分类器：** 多数类标签为 +，因此预测为 +。
*   **无变化分类器：** 最后一个实例（T4）的类标签为 −，因此预测为 −。
*   **惰性分类器：** 如果我们用共同单词的数量来衡量相似度，最接近 T5 的推文是 T4，其标签为 −。因此，1-NN 分类器预测 T5 为 −。

# 2.2.5 朴素贝叶斯

朴素贝叶斯分类器是一种基于贝叶斯定理使用的简单分类器。基本思想是根据属性值计算每个类的概率，并选择概率最高的类。在假设所有属性相互独立的朴素假设下，可以通过将所有属性在特定取值下该特定类标签的条件概率相乘来计算类概率。独立性假设几乎总是错误的，但可以证明较弱的假设已足够，且朴素贝叶斯凭借其简洁性在各类任务中表现出惊人的优异性能。

# 2.2.6 决策树

决策树学习器从训练示例构建树结构，以预测未见示例的类标签。决策树的主要优势在于其预测易于理解。这就是为什么在不希望使用黑箱分类器的场景中（例如医疗健康相关应用），它们是最常用的分类器之一。

在流挖掘中，最先进的决策树分类器是 `Hoeffding tree`（霍夫丁树），由 Domingos 和 Hulten [88] 提出，及其变体。传统决策树会扫描整个数据集以发现形成数据初始划分的最佳属性。一旦找到，数据将按所选属性的值进行划分，并将算法递归地应用于生成的数据集，以构建子树。递归将持续直到满足某些停止准则。这种方法无法直接用于流设置，因为我们无法承担存储实例并反复扫描它们的资源成本（时间和内存）。

`Hoeffding tree` 基于这样的思想：我们不查看之前（存储的）实例来决定树中如何划分，而是等待接收足够多的实例，并在可以有信心地做出划分决策时才做决定。这种方法的主要优势是不需要存储实例。相反，保留足够统计量以做出划分决策。足够统计量使得将朴素贝叶斯模型整合到树的叶节点中变得容易。

`Hoeffding adaptive tree`（霍夫丁自适应树）[33] 是 `Hoeffding tree` 的扩展，当数据流演变且类标签分布或实例分布发生变化时，它能够创建和替换新分支。

# 2.2.7 集成学习

集成学习是分类器的集合，当它们组合在一起时，预测效果优于其中任何一个单独预测。如果我们使用相同的算法来构建集成中的所有分类器，我们将需要向算法提供不同的数据子集以使它们有所不同。`Bagging`（装袋法）是一种集成方法，它（1）使用通过对原始输入数据流有放回采样获得的子集作为分类器构建器每次运行的输入，（2）使用分类器的多数投票作为预测策略。

`ADWIN bagging` 方法 [38] 在 MOA 中实现为 `OZABAGADWIN`，是装袋法的扩展，当数据流演变且类标签分布发生变化时，它能够创建和替换新分类器。

# 2.3 回归

与分类一样，回归任务的目标是学习一个模型，用于预测标签未知实例的标签属性值。然而，这里的标签是一个实值，而不是离散值集合中的一个。精确预测标签是不现实的，因此目标是在某些度量下（如平均平方距离）尽可能接近正确值。

几种分类算法都有天然的回归对应版本，包括惰性学习和决策树。

# 2.4 聚类

当我们拥有未标记实例并希望根据它们的相似性或亲和力在其中找到同质组或簇时，聚类很有用。与分类的主要区别在于，在学习过程之前这些组是未知的，学习之后我们也不知道它们是否是“正确”的。这就是为什么它被称为*无监督*学习。聚类的用途包括市场营销中的客户细分和社交网络中的社区发现。

我们可以将聚类视为一个优化问题，即我们希望最小化一个成本函数，该函数评估将示例划分为簇的“差异程度”。一些聚类方法需要被告知要在数据中寻找的期望簇数，而另一些则会自行发现一定数量的簇。

`k`-means（k均值）聚类方法是聚类中最常用的方法之一，因其简洁性。它首先以随机方式选择 `k` 个质心。之后，重复两个步骤：首先，将每个实例分配给最近的质心；其次，通过计算分配给该质心的实例的质心（质心即中心）来重新计算簇质心。重复此过程直到满足某些停止准则，例如分配不再发生变化。它不是一种流式方法，因为它需要对同一数据进行多次遍历。

流式聚类方法通常有两个层次，一个在线层次和一个离线层次。在在线层次，从数据流中高效地计算和更新一组微簇；在离线阶段，在微簇上执行经典的批量聚类方法，如 `k`-means。在线层次仅对数据进行一次遍历；离线阶段执行多次遍历，但不是遍历所有数据，而是遍历微簇集合，这通常是一个相当小的、可控大小的集合。离线层次可以在流结束时（如果结束）调用一次，也可以随着流动定期调用以更新簇集合。

# 2.5 频繁模式挖掘

频繁模式挖掘是无监督学习中的一项重要任务。它可用于简单描述数据结构、发现关联规则，或发现可用于分类或聚类任务的判别特征。模式类别的示例包括项集、序列、树和图 [255]。
