
问题如下：给定一个包含模式的数据源（批量数据集或数据流）和一个阈值 `σ`，找出所有在数据集中以至少 `σ` 的比例作为子模式出现的模式。例如，如果我们的数据源是超市购物记录流，且 `σ` = 10%，如果至少 10% 的购物记录同时包含奶酪*和*葡萄酒（或许还有其他产品），我们就称 {奶酪,葡萄酒} 为频繁模式。对于图而言，三角形可以是一个图模式，如果我们有一个图数据库，当至少 `σ` 比例的图至少包含一个三角形时，该模式即为频繁模式。

在批量设置中，Apriori、Eclat 和 FP-growth 是在数据库中寻找频繁项集的三个最著名算法，其中每个项都是一个集合。针对序列和图等数据结构也存在类似的算法。然而，很难将它们直接迁移到流设置中，要么是因为它们需要对数据进行多次扫描，要么是因为它们存储了过多的信息。

流上频繁模式挖掘的算法通常以批量挖掘算法为基础，但需要实现其他思路；此外，它们通常是近似的而非精确的。Moment 和 IncMine 是数据流中频繁项集挖掘的算法。

### 3.2.1 漂移流生成器

MOA 流是通过生成器构建的，可以读取 ARFF 文件、连接多个流或过滤流。MOA 流生成器允许我们模拟潜在的无限数据序列。

可以构建表现出概念漂移或概念随时间变化的流。两个例子是旋转超平面和随机 RBF 生成器。这些流中的变化率由一个参数决定，其操作将在第 12 章中解释。

我们也可以通过连接多个流来引入概念漂移或变化。在 MOA 中，这是通过构建两个纯分布的加权组合来完成的，这两个纯分布表征了变化前后的目标概念。MOA 使用 Sigmoid 函数作为一种优雅且实用的解决方案，来定义流中每个新实例在漂移后属于新概念的概率。Sigmoid 函数引入了一种渐进、平滑的过渡，其持续时间由两个参数控制：`p`，即变化发生的位置，以及过渡的长度 `w`，如 [图 3.5](#chapter_3.xhtml#fig3-5) 所示。

![Figure 3.5 A sigmoid function f(t) = 1/(1 + e−4(t−p)/w).](images/Fig3-5.png)

**图 3.5**  

一个 Sigmoid 函数 `f(t) = 1/(1 + e^(-4(t-p)/w))`。
