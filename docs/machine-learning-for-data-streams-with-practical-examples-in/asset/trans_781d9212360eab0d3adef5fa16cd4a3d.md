当 |*I*| 是某个素数 *p* 时，这里有一个成对独立哈希函数族的简单构造。将 *I* 视为区间 \[0…*p* − 1\]。族中的函数 *h* 由 \[0…*p* − 1\] 中的两个值 *a* 和 *b* 定义，并计算 *h*(*x*) = (*ax* + *b*) mod *p*。注意，这样一个函数由 *a* 和 *b* 描述，因此用 2log *p* 位。这个族是成对独立的，因为给定 *x*、*y* 和值 *h*(*y*)，对于每个可能的值 *h*(*x*)，方程组 {*h*(*x*) = *ax* + *b*, *h*(*y*) = *ay* + *b*} 都有唯一解 (*a*, *b*)，所以 *h*(*x*) 的所有值等可能。然而请注意，如果我们知道 *x*、*y*、*h*(*x*) 和 *h*(*y*)，我们可以唯一地求解 *a*、*b*，从而知道对于其他每个输入 *z* 的值 *h*(*z*)。如果 |*I*| 是素数幂 *p*^(*b*)，我们可以通过在大小为 *p*^(*b*) 的有限域中运算来推广这个构造；请注意这*不*等同于模 *p*^(*b*) 运算。我们也可以选择一个略大于 |*I*| 的素数，得到仅在边缘上偏离成对独立性的函数。

成对独立函数足以用于 CM-sketch。矩估计算法需要一种称为 4-wise independence 的推广。对于其他算法，如 HyperLogLog，据我们所知，*k*\-wise independence 无法被正式证明为足够。然而，尽管不存在正式保证，著名的哈希函数如 `MD5`、`SHA1`、`SHA256` 和 `Murmur3` 在实践中似乎没有问题 [104, 134]。文献 [71] 提出了理论论据，解释为什么简单的哈希函数在草图等数据结构问题上可能表现良好。

## 4.9.2 创建 (𝜖, *δ*)-近似算法

设 *f* 为待近似的函数，*g* 为随机算法，使得对所有 *x* 有 E\[*g*(*x*)\] = *f*(*x*)，且 Var(*g*(*x*)) = *σ*²。运行 *k* 个独立的 *g* 副本，记为 *g*[1], …, *g*[*k*]，通过平均它们的输出来组合，结果记为 *h*。我们有 E\[*h*(*x*)\] = *f*(*x*)，且由方差的简单性质，Var(|*f*(*x*) − *h*(*x*)|) ≤ Var(*f*(*x*) − *h*(*x*)) = Var(*h*(*x*)) = *σ*²/*k*。然后由切比雪夫不等式，对于每个 𝜖，有 |*f*(*x*) − *h*(*x*)| > 𝜖 的概率至多为 *σ*²/(*k*𝜖²)。这意味着如果我们选择 *k* = *σ*²/(𝜖²*δ*)，则 *h* 是 *f* 的 (𝜖, *δ*)-近似。*h* 的内存和更新时间是 *g* 的 *k* 倍。

通常为了达到精度 𝜖，需要 *σ*²/𝜖² 形式的依赖关系，但 1/*δ* 形式的依赖关系可以按如下方式改进：使用上述方法达到固定置信度，例如 (𝜖, 1/6)-近似。然后运行该固定置信度算法的 *ℓ* 个副本并取结果的*中位数*。使用霍夫丁不等式可以证明，如果取 *ℓ* = *O*(ln(1/*δ*))，则新算法是 (𝜖, *δ*)-近似；见练习 4.9。因此最终算法使用的内存和运行时间是原始算法 *g* 的 *k* · *ℓ* = *O*((*σ*²/𝜖²) ln(1/*δ*)) 倍。

这种转换已经存在于 Alon 等人 [14] 关于流上矩估计的开创性论文中。

## 4.9.3 其他草图技术

本章展示的草图是因其在流挖掘和数据流学习中的潜在用途而选取的。数据流上还提出了许多其他算法问题，例如解决组合问题、几何问题和图问题。此外，我们的展示中省略了小波、低维嵌入和压缩感知等深度算法技术的流式变体。近期的综合参考文献包括 [79, 172]。

鉴于线性代数问题在机器学习中日益突出，相关算法值得特别提及。在线奇异值分解（[221] 和最近的 [159]）以及主成分分析 [49] 的进展很可能在流式处理中变得极具影响力。书籍 [248] 深入介绍了线性代数草图；它们在流挖掘和学习任务中的实际应用是一个非常有前景但很大程度上未被探索的方向。
