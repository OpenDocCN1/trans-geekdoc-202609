首先，并非严格要求在每个项目后执行测试；实际上每隔 *k* 个项目测试一次也是可以的，当然这会以延迟 *k* 个时间单位检测到突变为代价。其次，实验表明，如果处理任一项目时最多丢弃一个桶，而不是丢弃检测到的变化点之前的所有桶，误报率会略有优势；如果有必要，处理后续项目时会丢弃更多桶。第三，我们可以为指数直方图设定最大尺寸，这样如果流中没有变化，内存就不会无限增长。最后，我们需要确定一个测试 *T*；在文献 [30, 32] 和 MOA 实现中，使用了第 5.3.3 节给出的基于 Hoeffding 界的测试，以便对算法性能有严格的界限。然而，在实践中，使用那里的其他统计测试可能更好，因为在相同的虚警率下，它们对真实变化的反应更快。

## 5.4 与其他摘要及多维数据的结合

第 4 章提出的摘要（指数直方图除外）考虑了从摘要初始化那一刻起整个数据流中的信息。这意味着它们不包含遗忘机制，也不认为更新的数据更重要。将这些摘要与本章提出的估计和变化检测算法相结合是可能且自然的。

例如，Papapetrou 等人 [193] 提出了 ECM，这是 CM-Sketch 的一个变体，其中整数计数被替换为类似于指数直方图的滑动窗口结构。Muthukrishnan 等人 [184] 将 CM-Sketch 与序贯检验技术相结合，以检测多维数据中的变化。

多维数据流中的变化检测是一个具有挑战性的问题，特别是当解决方案必须随维度数量良好扩展，且必须是通用的、非针对特定场景定制时。一个快速的解决方案是通过监控数据的一个或多个一维统计量（例如执行随机投影或 PCA）将问题降维为一维。这通常会降低对变化的敏感度，特别是当变化局限于数据的一个小子空间时。直接处理多维变化的通用方法可参见文献 [82, 153, 201, 237]。

# 第 6 章 分类

分类是最广泛使用的数据挖掘技术之一。从非常一般的角度来看，给定一组群体（通常称为*类别*），分类旨在预测新实例可能属于哪个群体。分类的结果通常是识别单个群体，或给出每个群体的成员资格可能性的概率分布。它是*监督*学习最重要的情况，意味着可供学习算法使用的标签可用于指导它。垃圾邮件过滤器是一个很好的例子，我们要预测新邮件是否被视为垃圾邮件。Twitter 情感分析是另一个例子，我们要预测新传入推文的情感是正面还是负面。

更正式地说，分类问题可以表述如下：给定一组形式为 (*x, y*) 的带标签*实例*或*样本*，其中 *x* = *x*[1], ..., *x*[*k*] 是一个*特征*或*属性*值向量，*y* 是 *n*[*C*] 个不同*类别*之一，也被视为称为*类别*的离散属性的值。分类器构建算法构建一个分类器或模型 *f*，使得 *y* = *f*(*x*) 是任意无标签样本 *x* 的预测类别值。例如，*x* 可以是一条推文，*y* 是其情感极性；或者 *x* 可以是一封邮件，*y* 是关于它是否为垃圾邮件的决定。大多数经典分类方法将所有训练数据加载到主内存，然后通过对数据的多次遍历来构建 *f*。在流设置中，*f* 通常是增量构建的，数据检查限制为单次遍历，实例逐个呈现。
