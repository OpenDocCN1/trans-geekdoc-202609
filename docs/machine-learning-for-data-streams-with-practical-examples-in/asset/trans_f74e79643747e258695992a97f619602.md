# 8 回归

回归是一种学习任务，其目标是预测一个数值，而不是像分类那样预测一个分类属性。分类中使用的一些技术可用于回归，但并非全部。决策树、感知机和惰性学习经过修改后可用于回归。

## 8.1 简介

给定一个要预测的*数值*属性，称为*结果* (outcome)，回归算法构建一个模型，为每个未标记实例 *x* 预测 *x* 的结果的数值预测 *y*。

回归问题的例子包括无法简化为离散标签的数量预测，例如股市价格、产品销量、时间延迟或网站访问量。可以通过将结果的值离散化为区间，将回归问题归约为分类问题；反之，也可以将离散类别转换为数值变量，利用回归算法进行分类。当然，这些转换不一定能产生最优结果。

最简单的回归算法是返回目标属性的平均值。这相当于分类中的多数类方法，即一种不使用其他属性信息的学习器。一种在非流式回归中更有用的方法是*线性回归*。

线性回归构建一个形式为

```
f(x) = w0 + w1*x1 + ... + wp*xp
```

的线性模型 *f*，该模型最小化残差平方和：

```
RSS(w) = Σ(yi - f(xi))^2
```

其中输入是 *N* 对 (*x*[*i*]*, y*[*i*]) 的集合。然而，精确解是

```
w = (X^T X)^-1 X^T y
```

这很难增量计算，更不用说在流式设置中了。可以使用随机投影草图给出近似解（例如参见 [73, 248]），但它们在实际数据挖掘中的应用仍处于初步阶段。因此，我们寻找其他更明显具有增量性和自适应性的策略。

## 8.2 评估

为了评估回归方法，我们可以使用与分类相同的方法论，如留出法、预测式和交错测试-训练法，但错误分类率度量不适用。回归中通常考虑以下度量：

*   **均方误差 (MSE)：** 这是最常用的度量，通过实际值与预测值之差的平方的平均值给出误差：

```
MSE = (1/N) * Σ(yi - ŷi)^2
```

*   **均方根误差：** 均方误差的平方根：

```
RMSE = sqrt(MSE)
```

*   **相对平方误差：** 回归方法的 MSE 与最简单回归方法（均值回归算法）的 MSE 之比：

```
RSE = MSE(model) / MSE(mean)
```

*   **相对平方根误差：** 相对平方误差的平方根：

```
RRSE = sqrt(RSE)
```

*   **平均绝对误差：** 该度量类似于 MSE，但考虑差值的绝对值：

```
MAE = (1/N) * Σ|yi - ŷi|
```

*   **相对绝对误差：** 类似于相对平方误差，但考虑差值的绝对值：

```
RAE = MAE(model) / MAE(mean)
```

很容易看出，所有这些度量都可以通过在内存中维护固定数量的值来增量计算。

## 8.3 感知机学习

感知机 [37] 在第 6.5 节中作为一种在线分类方法被提出。然而，它也可以很自然地被视为一种回归方法。

给定一个实例对 (*x*[*i*]*, y*[*i*]) 的数据流，其中 *x*[*i*] 是一个示例，*y*[*i*] 是其数值结果值，感知机的目标是在示例上最小化 MSE。为此，策略再次是沿着下降误差梯度的方向移动权重向量 *w* 中的每个权重。

在这种情况下，更新规则变为：

```
w <- w + η * (yi - ŷi) * xi
```

与分类一样，权重可以在每个单独示例上更新，如上述权重所示，或者以小批量为单位进行单次更新步骤。这使我们能够微调更新时间和自适应性之间的权衡。

## 8.4 惰性学习

惰性学习是分类和回归中最简单、最自然的模型之一——特别是 *k* 近邻算法。给定实例间的距离函数 *d*，回归中的 *k*-NN 方法找到最接近待预测实例的 *k* 个实例，并对它们的结果取平均。与分类一样，平均值可以根据到每个邻居的距离进行加权。

该方法的性能强烈依赖于所使用的距离函数。对于具有数值属性的稠密实例，欧几里得距离可能是合适的。对于文本数据，余弦相似度度量或 Jaccard 系数可能更合适。

`IBLStreams` 是由 Shaker 和 Hüllermeier [225] 提出的用于流式回归的惰性学习实现。除了流式 *k*-NN 的基本思想外，它还包括用于从数据库中移除异常点、移除与数据库中已有实例过于接近的实例（因此不太有用），以及自适应选择数据库大小和参数 *k* 的启发式方法。
