
*   **Clusterer:** 此接口由聚类器和离群点检测器使用。聚类器继承 `AbstractClusterer` 抽象类，并实现以下方法：
    *   `resetLearningImpl()`：用于重置或初始化聚类器
    *   `trainOnInstanceImpl()`：用于使用新实例更新聚类器
    *   `getClustering()`：用于获取聚类器计算出的聚类点
*   **OutlierDetector：** 与聚类器类似，但专门设计用于离群点检测。

为了演示系统中学习算法的实现和使用，我们展示并解释了一个简单决策树桩分类器的 Java 代码。该分类器监控在每个属性上分割时的类别信息增益，并选择使该值最大化的属性。该决策会被多次重新审视，因此随着更多示例的出现，树桩有可能随时间改变。实际上，如果流分布没有变化，在充分训练后它不太可能再发生改变。

## 清单 15.1：选项处理

![](images/pg229-1.png)

要设置分类器的公共接口，必须指定可供用户使用的选项。为了让系统自动处理选项，这些选项需要作为类的公共成员，并继承 `moa.options.Option` 类型，如清单 15.1 所示。

示例分类器——决策树桩——有三个选项，每个类型不同。用于构建选项的前三个参数的含义在不同选项类型之间是一致的。第一个参数是用于标识选项的短名称。第二个是用于命令行的字符，应当唯一——命令行字符不能在不同选项间重复，否则会抛出异常。第三个标准参数是描述选项用途的字符串。选项构造函数的额外参数允许指定附加信息，如默认值或值的有效范围。

决策树桩分类器指定的第一个选项是“宽限期”。该选项用整数表示，因此类型为 `IntOption`。该参数控制从示例流学习时重新考虑最佳树桩的频率。这提高了分类器的效率——在每个单独示例后评估代价高昂，且单个示例不太可能改变当前最佳树桩的选择。默认值 1,000 意味着树桩的选择仅每 1,000 个示例重新评估一次。最后两个参数指定选项允许的值范围——负的宽限期没有意义，因此范围限制为大于或等于 0 的整数。

第二个选项是一个标志，即二元开关，由 `FlagOption` 表示。默认情况下所有标志均关闭，仅在用户请求时开启。此标志控制决策树桩是否仅允许二向分裂。默认情况下树桩允许有两个以上的分支。

第三个选项确定用于决定哪个树桩最佳的分裂准则。这是一个 `ClassOption`，需要特定的 `SplitCriterion` 类型 Java 类。如果所需类恰好是 `OptionHandler`，则这些选项将用于配置传入的对象。

## 清单 15.2：杂项字段

![](images/pg230-1.png)

清单 15.2 中使用了四个全局变量来维护分类器的状态：

*   `bestSplit` 字段维护分类器当前选择的树桩。其类型为 `AttributeSplitSuggestion`，该类用于将实例分割成不同子集。
*   `observedClassDistribution` 字段记录分类器观察到的总体类别标签分布。其类型为 `DoubleVector`，这是一个方便的类，用于维护浮点值向量而无需管理其大小。
*   `attributeObservers` 字段存储 `AttributeClassObservers` 的集合，每个属性对应一个。这是决定以哪个属性作为树桩基础所需的信息。
*   `weightSeenAtLastSplit` 字段记录上次执行评估的时间，以便分类器根据宽限期参数确定何时进行下一次评估。

`isRandomizable()` 函数需实现以指定分类器是否包含随机性。如果包含，将自动设置为接受随机种子。此分类器不包含随机性，因此返回 `false`。
