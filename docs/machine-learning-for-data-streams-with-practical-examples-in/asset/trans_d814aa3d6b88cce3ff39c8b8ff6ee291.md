
我们省略了关于*关联规则*的讨论，因为通常它们是通过首先从数据集（或流）中挖掘频繁项集，然后从挖掘出的项集中确定频繁规则来获得的；也就是说，除了挖掘频繁项集之外，没有什么本质上特定于流设置的内容。树的关联规则或概率蕴涵在文献[23]中有讨论，并被证明在若干非平凡方面与集合上的关联规则表现不同。

序列模式挖掘框架（SPMF）[106]包含许多模式挖掘算法的实现，主要用于批处理设置，且多为 Java 语言。`IncMine`、`AdaGraphMiner` 和 `Moment` 的实现可在 MOA 网站的*扩展*部分获得。

# MOA 及其生态系统简介

**M**assive **O**nline **A**nalysis（MOA）是一个开源软件框架，允许用户在不断演变的数据流上构建和运行机器学习及数据挖掘实验。它由新西兰怀卡托大学开发，并以一种名为恐鸟的大型、已灭绝、不会飞的鸟类命名，这种鸟过去只生活在新西兰。

MOA 的显著特点是它可以通过仅对数据进行一次扫描、每个数据项耗时极短，从大型数据集或流中学习和挖掘。在扫描数据时，它仅存储摘要和统计信息，而不是实例本身，因此内存使用通常也很小。

MOA 使用 Java 编写，并在 GNU 通用公共许可证条款下分发。它包含一组学习器、流生成器和评估器，可从图形用户界面（GUI）、命令行界面（CLI）和 Java API 使用。基于 Java 的优势在于可移植性以及强大且成熟的支持库。该语言使用广泛，自动垃圾回收等特性有助于减轻编程负担和错误。MOA 可在任何拥有合适 Java 虚拟机的平台上运行，如 Linux、Mac、Windows 和 Android。

MOA 的一个预期设计目标是易于使用且易于扩展。

有几个与 MOA 相关的开源软件库。其中一些，如 `ADAMS`、`MEKA` 和 `OpenML`，在其系统内部使用 MOA 执行数据流分析。`StreamDM` 包含 MOA 中一些最流行方法的 C++ 实现，而 `Apache SAMOA` 是一个新平台，利用 Hadoop 硬件在分布式环境中执行流挖掘。

在本书的这一部分中，我们将展示如何使用 GUI、CLI 和 Java API，以及如何掌握 MOA 算法、生成器和评估器。

在本章中，我们首先简要讨论 MOA 的架构以及如何安装软件。之后我们将介绍 MOA 的最新发展和可用的扩展，最后展示一些可以与 MOA 结合使用或作为其替代品的开源框架。目的不是使读者精通所有这些其他包，而是让他们了解这些工具的可能性。

# 11.1 MOA 架构

MOA 围绕*任务*的概念构建。在 MOA 中运行的所有实验都被定义为任务。有简单的任务，如将流写入文件或计算流的速度，但最重要的任务是评估任务。例如，在分类中，第 6.1 节描述了两种主要的评估方法：留出法和预测式。

MOA 包含用于分类、回归、聚类、异常检测、推荐和频繁模式挖掘的方法。任务通常由流源、学习器和评估参数组成，例如使用的实例数量、输出结果的周期性以及输出预测的文件名。此外，不同类型的任务需要不同的评估策略。

任务可以从 GUI 或 CLI 运行。

# 11.2 安装

MOA 可从 [https://moa.cms.waikato.ac.nz](https://moa.cms.waikato.ac.nz) 获取，最新版本始终可以作为压缩 zip 文件下载。发布包包含一个 `moa.jar` 文件，这是一个可执行的 Java jar 文件，可以作为 Java 应用程序运行或从命令行调用。它还包含 `sizeofag.jar` 文件，用于测量实验使用的内存。脚本 `bin\moa.bat`（Windows）和 `bin/moa.sh`（Linux 和 Mac）是启动 MOA GUI 的最简便方式。

# 11.3 MOA 的最新发展

本书未详细涵盖的 MOA 最新发展包括：

*   **多目标学习：** 一个用于多目标学习 [91, 188, 232] 的选项卡，其目标是同时预测多个相关的目标属性。多目标学习的例子包括同一建筑中温度的预测、同一路网中的轨迹预测或股票价格预测。

*   **异常检测**：一个用于基于距离的异常检测 [20, 120] 的选项卡。该选项卡使用最广泛采用的标准来确定一个元素是否为异常，该标准基于固定距离内邻居元素的数量，对比一个固定阈值。

*   **推荐系统**：MOA 有一个任务用于使用在线推荐算法。MOA 中的 `EvaluateOnlineRecommender` 任务接收一个评分预测器和一个数据集（每个训练实例为一个 [用户, 物品, 评分] 三元组），并评估模型在给定用户和物品的情况下预测评分的效果，随着处理实例越来越多。这类似于推荐系统的在线场景，其中用户对物品的新评分不断到达，系统必须对用户未评分的物品进行预测，以知道推荐哪些物品。有两种在线推荐算法可用：`BaselinePredictor` 和 `BRISMFPredictor`。第一种是一个非常简单的评分预测器，第二种实现了文献 [234] 中描述的一种分解算法。

# 11.4 MOA 扩展

以下有用的 MOA 扩展可从其网站获得：

*   **IBLStreams：** `IBLStreams` [225]，在第 8.4 节中描述，是一种用于数据流分类和回归问题的基于实例的学习算法。

*   **MOA-IncMine：** `IncMine`，由文献 [66] 提出并在第 10.3.4 节中描述，从不断演变的数据流中计算频繁闭项集。MOA 中的实现描述于文献 [202]，并使用了来自文献 [106] 的 `CHARM` 批量挖掘器实现。
