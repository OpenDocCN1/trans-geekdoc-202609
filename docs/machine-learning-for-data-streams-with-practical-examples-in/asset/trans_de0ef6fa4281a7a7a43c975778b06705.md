

# 数据流

*数据流* 是一种算法抽象，用于支持实时分析。它们是项目的序列，可能是无限的，每个项目都有一个时间戳，因此具有时间顺序。数据项逐个到达，我们希望实时构建并维护这些项目的模型，例如模式或预测器。处理流式数据时存在两个主要的算法挑战：流数据量大且速度快，我们需要实时从中提取信息。这意味着通常我们需要接受近似解，以便使用更少的时间和内存。此外，数据可能在演变，因此当数据发生变化时，我们的模型必须能够适应。

## 时间与内存

准确性、时间和内存是流挖掘过程的三个主要资源维度：我们关注的是那些能以最少的时间和较低的总内存获得最大准确性的方法。稍后我们将展示，通过将内存和时间结合在一个单一的成本度量中，可以将评估简化为一个二维任务。另请注意，由于数据以高速到达，无法被缓冲，因此处理单个项目的时间与总时间一样重要，而总时间通常是传统数据挖掘中考虑的指标。

## 应用

流式数据有许多场景。这里我们提供几个示例领域：

*   **传感器数据与物联网**：每天，工业界使用更多的传感器来监控流程并提高其质量。城市开始部署庞大的传感器网络，以监控人员流动、检查桥梁和道路的健康状况、城市交通、人们的生命体征等。
*   **电信数据**：电信公司拥有大量的通话数据。如今，移动通话和手机位置是需要处理的海量数据源，通常要求实时处理。
*   **社交媒体**：Facebook、Twitter、LinkedIn 和 Instagram 等社交网站的用户持续产生关于其互动和贡献的数据。话题与社区发现以及情感分析只是由此产生的实时分析问题中的两个例子。
*   **市场营销与电子商务**：销售企业实时收集大量交易数据，可对其进行分析以挖掘价值。检测电子交易中的欺诈行为至关重要。
*   **医疗保健**：医院在照顾病人时会收集大量时效性数据，例如监测病人的生命体征，如血压、心率和体温。远程医疗也将在病人居家时对其进行监测，可能包括通过独立传感器获取的日常活动数据。此外，系统还可能包含实验室检测结果、病理报告、X 光片和数字影像。其中一些数据可用于实时提供病人病情变化的预警。
*   **流行病与灾难**：源自互联网的数据流可用于检测流行病和自然灾害，并可与疾病控制和预防中心及灾害控制和预防中心的官方统计数据相结合 [63]。
*   **计算机安全**：计算机系统必须免受硬件、软件和信息的盗窃与损坏，以及所提供服务的中断或误导，特别是内部威胁检测 [11, 229] 和入侵检测 [194, 195]。
*   **电力需求预测**：供应商需要提前一段时间知道客户将请求多少电力。这些数字随一天中的时间、一年中的季节、地理位置、天气、经济状况、客户习惯以及许多其他因素而变化，使其成为一个在海量分布式数据上的复杂预测问题。

# 本书内容

在大数据的众多方面中，本书专注于从数据流中进行挖掘和学习，因此专注于对高速到达的序列数据执行数据分析的技术。在定义大数据的诸多“V”特征中，我们主要解决的是**速度** 问题。

这些技术通过 `MOA`（大规模在线分析）以实操方式进行演示。`MOA` 是最流行的开源数据流挖掘框架，拥有非常活跃且不断壮大的社区。它包含一系列机器学习 (ML) 算法（分类、回归、聚类、模式挖掘、异常检测、变化检测和推荐系统）以及评估工具。`MOA` 与 `WEKA` 项目相关，同样使用 Java 编写，但设计用于扩展以应对更苛刻的问题。

第一部分介绍大数据领域、主要技术概览以及 `MOA` 使用的初步实操指南。第二部分详细介绍了大量流挖掘算法，优先介绍已在 `MOA` 中实现的算法，并为有兴趣深入了解的读者提供相关文献指引。第三部分深入探讨 `MOA`。它提供了一些额外的实操练习和 `MOA` 的部分内部结构，面向希望向 `MOA` 添加算法、修改现有算法，或通过其 API 在应用程序中使用 `MOA` 的读者。

最后，我们要提到还有其他非常有用且重要的数据流挖掘技术，但本书未涵盖，例如匹配问题、主题发现、排序/学习排序、推荐系统、循环概念挖掘、地理空间数据和大规模流式图挖掘。此外，在实际项目中，缺失数据、特征提取、异常检测和形成训练实例等方面将很重要；我们在此不显式涵盖它们，因为它们往往高度依赖于具体问题。

# 大数据流挖掘

在本章中，我们将简要介绍一些从数据流中学习的基本方法。在下一章中，我们将展示一个使用 `MOA` 及本章简要介绍的一些方法的实践示例。这些及其他方法将在本书第二部分中详细介绍。

## 算法

数据流挖掘的主要算法包括分类、回归、聚类和频繁模式挖掘。

假设我们有一个项目流，也称为实例或样本，它们持续不断地到达。当我们需要根据项目的其他特征，从一组标称标签中为每个项目分配一个标签时，我们就处于分类场景中。只要稍后能获得（许多）样本的正确标签，分类器就可以被训练。分类的一个例子是将传入的电子邮件标记为垃圾邮件或非垃圾邮件。回归是一个类似于分类的预测任务，不同之处在于要预测的标签是数值而非标称值。回归的一个例子是预测明天股市中某股票的价值。

分类和回归需要一组适当标记的样本来学习模型，以便我们可以使用该模型预测未见样本的标签。它们是*监督* 学习任务的主要例子。当样本未被标记时，一个有趣的任务是将它们分组到同质簇中。聚类可用于例如获取网站的用户画像。它是*无监督* 学习任务的一个例子。

频繁模式挖掘在样本中寻找最相关的模式。例如，在超市销售数据集中，可以知道哪些商品被一起购买并获得关联规则，例如：*大多数购买奶酪的顾客也会购买葡萄酒*。

对于预测器、聚类器和频繁模式挖掘器，流挖掘算法最重要的要求是相同的：

> **要求 1**：一次处理一个实例，并（至多）检查它一次。
>
> **要求 2**：处理每个实例使用有限的时间。
