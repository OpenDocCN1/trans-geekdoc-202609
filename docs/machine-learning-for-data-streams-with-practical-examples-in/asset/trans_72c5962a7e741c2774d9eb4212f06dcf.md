
每个新实例首先由模型集合进行检查，以确定它是否位于集合的决策边界之外。如果它在决策边界内部，则使用集合中模型的多数投票进行正常分类。否则，它将被声明为 F-outlier（过滤异常值）。这些 F-outliers 是潜在的新类实例，它们被临时存储在缓冲区中，以观察它们彼此之间是否接近。这是通过使用 `q`-邻域轮廓系数（q-NSC）来完成的，这是一种衡量内聚度和分离度的统一度量，其值介于 -1 和 +1 之间。正值表示该点更接近 F-outlier 实例（内聚度更高）且远离现有类实例（分离度更高），反之亦然。如果对于集合中的所有分类器，都有足够数量的 F-outliers 具有正的 q-NSC，则声明发现了一个新类。

SAND（半监督自适应新颖性检测）方法 [133] 根据分类器置信度的变化动态确定数据块大小。因此 SAND 更高效，并避免了在无变化期间进行不必要的训练。

最后，文献 [10] 提出了一种“基于类”的集成技术，用以取代传统的“基于数据块”的方法，以检测循环类。作者声称基于类的集成方法优于基于数据块的技术。
