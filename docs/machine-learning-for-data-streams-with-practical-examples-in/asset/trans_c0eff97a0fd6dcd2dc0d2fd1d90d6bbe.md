

# 12.2.6 函数分类器

*   **MajorityClass** 始终预测在训练数据中观察到频率最高的类别。
*   **NoChange** 它预测用于训练模型的最后一个实例中观察到的类别。
*   **Perceptron**，单感知机分类器。以增量方式执行经典的多类感知机学习。
*   **SGD** 实现随机梯度下降以学习各种线性模型：二分类 SVM、二分类逻辑回归和线性回归。
*   **SPegasos** 实现 Shalev-Shwartz 等人 [226] 提出的 Pegasos（SVM 的原始估计次梯度求解器）方法的随机变体。

# 12.2.7 漂移分类器

*   **SingleClassifierDrift** 用于处理概念漂移数据流的分类器，基于使用变化检测器来监控分类器的错误。当变化检测器发出警告信号时，会创建一个新分类器；当发出变化信号时，当前分类器将被新分类器替换。这是 Gama 等人 [114] 提出的 DDM 方法中的策略，详见第 5.3.4 节。可以使用多种漂移检测方法：
    *   **CusumDM** 和 **PageHinkleyDM**，见第 5.3.2 节。
    *   **DDM**，见第 5.3.4 节。
    *   **EDDM**，基于分类错误间距离的估计分布，见文献 [22]。
    *   **ADWINChangeDetector**，见第 5.3.5 节。
    *   **EWMAChartDM**，基于使用指数加权移动平均（EWMA）控制图 [216]，见第 5.3.4 节提及。
    *   **GeometricMovingAverageDM**，基于使用几何移动平均估计。
    *   **HDDM_A_Test** 和 **HDDM_W_Test**，基于使用 Hoeffding 界，见文献 [44]。
    *   **SEEDChangeDetector**，基于检测波动率偏移，见文献 [136]。
    *   **SeqDrift1ChangeDetector** 和 **SeqDrift2ChangeDetector**，第一个基于比较滑动窗口中的数据和存储库中的数据，第二个基于比较水库中的数据和存储库中的数据，见文献 [196, 220]。
    *   **STEPD**，基于使用比例相等的统计检验，见文献 [186]。

# 12.2.8 主动学习分类器

*   **ActiveClassifier** 用于主动学习的分类器，旨在在不请求超过其预算允许的标签数量的前提下学习一个准确的模型。该分类器可以使用多种显式处理概念漂移的主动学习策略，详见第 6.8 节。

# 12.3 聚类

MOA 中的聚类选项卡包含以下主要组件：

*   面向演化流的流聚类数据生成器（包括新奇性、合并等事件），
*   一组最先进的流聚类算法，
*   用于流聚类的评估度量，以及
*   用于分析结果和比较不同设置的可视化工具。

## 12.3.1 数据馈送与数据生成器

[图 12.3](#chapter_12.xhtml#fig12-3) 显示了带有事件的 RBF 数据生成器配置对话框的截图。通常可以设置簇的维度、数量和大小，以及漂移速度、衰减视界（老化）和噪声率。事件构成了底层数据模型的变化，如簇增长、簇合并或新簇的创建。利用事件频率和各个事件的权重，可以研究不同方法在各种设置下的行为和性能。最后，数据生成器的设置可以存储和加载，这提供了共享设置的机会，从而为可重复性和比较提供基准流数据集。

## 12.3.2 流聚类算法

目前 MOA 包含多种流聚类方法，包括：

*   **StreamKM++**，见第 9.2 节。
*   **CluStream**，见第 9.3 节。
*   **ClusTree**，见第 9.5 节。
*   **Den-Stream**，见第 9.5 节。
*   **CobWeb**。一种层次聚类器，也是最早的数据增量聚类方法之一，由 Fisher [102] 提出。

## 12.3.3 可视化与分析

评估过程开始后，有多种分析输出的选项：

*   可以停止流，并将当前的（微）聚类结果作为数据集传递给 WEKA Explorer 进行进一步分析或挖掘；
*   在可配置的时间间隔评估的评估度量，可以存储为 CSV 文件，以便使用首选程序离线获取图表；
*   最后，聚类结果和相应的度量都可以在 MOA 内部在线可视化。

MOA 允许同时配置和评估两种不同的设置以进行直接比较，例如在同一流上比较两种不同算法，或在具有不同噪声水平的流上比较同一算法，等等。

可视化组件允许可视化流以及聚类结果，为多维数据选择维度，并并行比较不同设置的实验。[图 12.4](#chapter_12.xhtml#fig12-4) 显示了可视化选项卡的截图。在该截图中，在相同的流设置下比较了 **CluStream** 算法的两种不同设置，包括每 50000 个样本发生一次合并/分裂事件，并选择了四种度量进行在线评估（F1、精确率、召回率和 SSQ）。
