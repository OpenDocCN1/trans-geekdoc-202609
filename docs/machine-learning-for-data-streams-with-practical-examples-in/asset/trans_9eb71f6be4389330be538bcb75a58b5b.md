
# MOA 类与选项处理

带有参数或选项的 MOA 类必须继承 `AbstractOptionHandler` 类。这些选项可以是以下类型：

*   **Integer**：`IntOption` (name, char, purpose, default Value, min Value, max Value)
*   **Float**：`FloatOption` (name, char, purpose, default Value, min Value, max Value)
*   **Flag**：`FlagOption` (name, char, purpose)
*   **File**：`FileOption` (name, char, purpose, default File name, default File extension, Output)
*   **String**：`StringOption` (name, char, purpose, default Value)
*   **Multichoice**：`MultichoiceOption` (name, char, purpose, option labels, option descriptions, default option index)
*   **Class**：`ClassOption` (name, char, purpose, required type, default CLI string)
*   **List**：`ListOption` (name, char, purpose, expected option type, default list, separator char)

以下是一些定义为 Java 类的选项示例：

**Listing 14.1: 带有默认值的选项类定义。**

```java
public IntOption gracePeriodOption = new
IntOption(
    "gracePeriod",
    'g',
    "The number of instances a leaf should observe between split attempts.",
    200, 0, Integer.MAX_VALUE);

public ClassOption splitCriterionOption = new
ClassOption("splitCriterion",
    's', "Split criterion to use.",
    SplitCriterion.class,
    "InfoGainSplitCriterion");

public FloatOption splitConfidenceOption = new
FloatOption(
    "splitConfidence",
    'c',
    "The allowable error in split decision, values closer to 0 will take longer to decide.",
    0.0000001, 0.0, 1.0);

public FlagOption binarySplitsOption = new
FlagOption("binarySplits", 'b',
    "Only allow binary splits.");

public FileOption dumpFileOption = new
FileOption("dumpFile", 'd',
    "File to append intermediate csv results to.", null, "csv", true);

public StringOption xTitleOption = new
StringOption("xTitle", 'm',
    "Title of the plots’ x-axis.",
    "Processed instances");
```

要通过 API 从 Java 源代码更改这些选项的值，有两种可能性：

*   `setValueViaCLIString(String s)`：通过文本设置此选项的值，该文本可以包含多个嵌套参数，类似于 CLI 文本。
*   每个选项都有特定的方法来更改其值：
    *   **Integer**：`setValue(int v)`
    *   **Float**：`setValue(double v)`
    *   **Flag**：`setValue(boolean v)`
    *   **File**：`setValue(String v)`
    *   **String**：`setValue(String v)`
    *   **Multichoice**：`setChosenIndex(int index)`
    *   **Class**：`setCurrentObject(Object obj)`
    *   **List**：`setList(Option[] optList)`

获取这些选项值也有两种方式：

*   `getValueAsCLIString()`：获取描述此选项嵌套参数的文本。
*   每个选项都有特定的方法来获取其值：
    *   **Integer**：`getValue()`
    *   **Float**：`getValue()`
    *   **Flag**：`isSet()`
    *   **File**：`getFile()`
    *   **String**：`getValue()`
    *   **Multichoice**：`getChosenIndex()`
    *   **Class**：`getPreparedClassOption(ClassOption classOption)`
    *   **List**：`getList()`

# 14.3 预测评估示例

作为示例，我们将编写 Java 代码来执行预测评估。

我们首先初始化将从中读取实例的数据流。在本例中，我们将使用第 12.2.2 节中解释的 `RandomRBFGenerator`。

**Listing 14.2: 流初始化的 Java 代码。**

```java
RandomRBFGenerator stream = new
RandomRBFGenerator();
stream.prepareForUse();
```

现在我们必须构建一个空的学习器。我们创建一个霍夫丁树，并使用 `setModelContext` 告诉它实例属性的信息。

**Listing 14.3: 学习器初始化的 Java 代码。**

```java
Classifier learner = new HoeffdingTree();
learner.setModelContext(stream.getHeader());
learner.prepareForUse();
```

要执行预测评估，我们必须先测试然后在流中的每个实例上训练。同时，我们保留一些准确率统计数据以便计算最终的准确率值。

**Listing 14.4: 预测评估的 Java 代码。**

```java
int numInstances = 10000;
int numberSamplesCorrect = 0;
int numberSamples = 0;
boolean isTesting = true;

while (stream.hasMoreInstances() &&
       numberSamples < numInstances) {
    Instance inst = stream.nextInstance().getData();
    if (isTesting) {
        if (learner.correctlyClassifies(inst)) {
            numberSamplesCorrect++;
        }
    }
    numberSamples++;
    learner.trainOnInstance(inst);
}
```

最后，我们输出评估结果。在我们的例子中，我们关注准确率，因此打印该设置下霍夫丁树的最终预测准确率。

**Listing 14.5: 输出结果的 Java 代码。**

```java
double accuracy = 100.0 * (double)
    numberSamplesCorrect / (double) numberSamples;
System.out.println(numberSamples + " instances processed with " + accuracy + "% accuracy");
```

完整的评估方法 Java 代码如下：

**Listing 14.6: 完整的 Java 代码。**

```java
RandomRBFGenerator stream = new
RandomRBFGenerator();
stream.prepareForUse();

Classifier learner = new HoeffdingTree();
learner.setModelContext(stream.getHeader());
learner.prepareForUse();

int numInstances = 10000;
int numberSamplesCorrect = 0;
int numberSamples = 0;
boolean isTesting = true;

while (stream.hasMoreInstances() &&
       numberSamples < numInstances) {
    Instance inst = stream.nextInstance().getData();
    if (isTesting) {
        if (learner.correctlyClassifies(inst)) {
            numberSamplesCorrect++;
        }
    }
    numberSamples++;
    learner.trainOnInstance(inst);
}

double accuracy = 100.0 * (double)
    numberSamplesCorrect / (double) numberSamples;
System.out.println(numberSamples + " instances processed with " + accuracy + "% accuracy");
```

# 15 在 MOA 中开发新方法

在某些情况下，开发扩展 MOA 功能的新方法很有用。在本章中，我们介绍 MOA 中一些最流行对象的结构，并展示如何实现新对象。本章需要对 Java 中的数据结构有良好的理解。

## 15.1 MOA 中的主要类

MOA 中的所有对象都应实现 `MOAObject` 接口并继承 `AbstractMOAObject` 抽象类。要在 Java 中创建一个需要配置选项的新类，需要继承 `AbstractOptionHandler` 抽象类。MOA 选项非常灵活，并且由于它们可以是递归的，因此可以将具有选项的对象本身定义为选项。例如，这是一个具有不同于默认选项的霍夫丁树分类器的规范：

```
moa.classifiers.trees.HoeffdingTree
-n (VFMLNumericAttributeClassObserver -n 20)
-g 300 -s GiniSplitCriterion -t 0.04 -l MC
```

在该示例中，我们选择 `VFMLNumericAttributeClassObserver` 对象作为数值属性类观察器，它有 20 个箱。我们将数字 20 作为选项传递给该类。注意选项是递归的，并且可以包含大量 Java 类。

MOA 中的主要学习器接口有：

*   **Classifier**：该接口由分类器和回归器使用。分类器通常继承 `AbstractClassifier` 抽象类，并实现以下三个方法：
    *   `resetLearningImpl`：重置或初始化分类器
    *   `trainOnInstanceImpl`：使用新实例更新学习器
    *   `getVotesForInstance`：从学习器获得预测

    `AbstractClassifier` 抽象类包含以下两个用于 API 的方法：
    *   `prepareForUse`：调用 `resetLearningImpl` 以准备分类器
    *   `trainOnInstance`：使用 `trainOnInstanceImpl` 通过新实例训练学习器

*   **Regressor**：回归方法实现此接口并继承 `AbstractClassifier` 抽象类。分类和回归的区别在于，对于分类，`getVotesForInstance` 返回一个包含每个类估计预测值的数组，而对于回归，`getVotesForInstance` 返回一个长度为 1 的数组，包含预测结果。
