# 集成方法

集成预测器是较小模型的组合，它们的单独预测以某种方式（例如平均或投票）结合形成最终预测。在批处理和流式场景中，集成往往能提高预测准确性，优于其任何单一组成部分，代价是需要更多的时间和内存资源，并且它们通常易于并行化。但在流式处理中，分类器集成相对于单分类器方法还有额外的优势：它们易于扩展；如果挖掘分布式流，不需要将多个流集中到单个站点；并且可以通过修剪集成中表现不佳的部分并添加新分类器来使其适应变化。关于流式集成的全面且最新的讨论见文献 [124]。

我们首先讨论通过加权或投票现有分类器来创建集成的通用方法，如加权多数和堆叠。然后讨论装袋和提升，这两种流行的方法通过在将输入分布交给创建分类器的基础算法之前对其进行转换来创建集成。接下来，我们讨论一些使用霍夫丁树作为基础分类器的方法。最后，我们讨论循环概念，即过去出现的分布倾向于稍后重新出现的场景，以及如何用集成来应对它们。

# 7.1 准确率加权集成

一种简单的集成方案采用 *N* 个预测器 *C*[1], …, *C*[*N*] 并应用某个函数 *f* 来组合它们的预测：在每个待预测的实例 *x* 上，集成预测 *f*(*C*[1](*x*),…,*C*[*N*](*x*))，其中 *C*[*i*](*x*) 表示 *C*[*i*] 对 *x* 的预测。这些预测器可能从一开始就是固定的，也许是从批量数据离线训练的，或者是在同一流上在线训练的。

对于分类，*f* 可以简单地是*投票*，即在 *C*[*i*](*x*) 中产生最受欢迎的类别。在*加权投票*中，每个分类器 *C*[*i*] 都有一个权重 *w*[*i*] 附加到其投票上。如果我们有一个二分类问题，类别在 {0, 1} 中，加权投票可以表示为：

准确率加权集成（AWE）由 Wang 等人 [244] 提出，旨在使用非流式学习器挖掘演变数据流。AWE 以块为单位处理流，并为每个新块构建一个新分类器。每当添加一个分类器时，最旧的一个就会被移除，从而允许集成适应变化。AWE 在 MOA 中作为 `ACCURACYWEIGHTEDENSEMBLE` 实现。

文献 [244] 表明，如果每个分类器被赋予与 *err*[*r*] − *err*[*i*] 成比例的权重，则集成的表现优于基础分类器，其中 *err*[*i*] 是第 *i* 个分类器在测试集上的误差，*err*[*r*] 是随机分类器的误差，后者以训练集中类别 *c* 的概率预测类别 *c*。作为测试集的代理，AWE 在最近的块上计算这些误差，假设它是最相似于接下来将到达的实例的块。

该方法的优点是其简单性，以及它可以与非流式基础分类器一起使用，但在平稳和非平稳流上都能良好工作。该方法的一个缺点是块大小必须由领域专家在外部确定，并考虑基础分类器的学习曲线。

AWE 的变体已在 [148, 58] 等文献中提出。[58] 中的变体在 MOA 中作为 `ACCURACYUPDATEDENSEMBLE` 实现。

# 7.2 加权多数

加权多数算法由 Littlestone 和 Warmuth [160] 提出，结合 *N* 个现有的预测器（在此语境下称为“专家”），并学习随时间调整它们的权重。它类似于感知机算法，但其更新规则以乘法方式而非加法方式改变权重。与感知机不同，可以证明它收敛于几乎等于最佳专家的错误率，加上一个取决于 *N* 的小项。因此，当专家数量大且许多专家表现不佳时，它很有用。

该算法见[图 7.1](#chapter_7.xhtml#fig7-1)。算法的输入是一个需要预测的项目流，每个项目后跟其正确标签。接收到第 *t* 个项目 *x*[*t*] 后，算法发出对 *x*[*t*] 标签的预测 *ŷ*[*t*]。然后算法接收 *x*[*t*] 的正确标签 *y*[*t*]。在算法中，`sign` 函数对负数返回 0，对非负数返回 1。
