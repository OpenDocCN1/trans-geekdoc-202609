## 6.1.2 分布式评估

在分布式数据流设置中，我们拥有可以同时训练的分类器。这提供了一个实现类似经典 `k` 折交叉验证的机会。针对该设置下的评估，已提出多种方法以涵盖数据丰富或稀缺、以及待比较分类器数量的不同组合 [40]：

*   **`k` 折分布式分割验证：** 适用于数据丰富且有 `k` 个分类器的情况。每当一个新实例到达时，以概率 `1/k` 决定它是否用于测试。如果用于测试，则由所有分类器使用。如果不用于测试，则用于训练，并仅分配给一个分类器。因此，每个分类器看到的实例不同，但它们使用相同的数据进行测试。

*   **`5x2` 分布式交叉验证：** 适用于数据较少，且我们想仅使用（例如）十个分类器的情况。我们创建五组分类器对，对于每一组，每当一个新实例到达时，以概率 `1/2` 决定这两个分类器中的哪一个用于测试；该组的另一个分类器用于训练。所有实例均用于测试或训练，测试实例与训练实例之间没有重叠。

*   **`k` 折分布式交叉验证：** 适用于数据稀缺且我们有 `k` 个分类器的情况。每当一个新实例到达时，它被随机选定的一个分类器用于测试，并被其他分类器用于训练。这种评估等同于 `k` 折分布式交叉验证。

## 6.1.3 性能评估度量

在真实数据流中，每个类别的实例数量可能在不断演变和变化。有人可能会认为，预训练准确率度量仅适用于所有类别平衡且拥有大致相同示例数量的情况。Kappa 统计量是一种对量化流式分类器预测性能更敏感的度量。

Kappa 统计量 `κ` 由 Cohen [76] 提出，定义如下：

其中 `p[0]` 是分类器的预训练准确率，`p[c]` 是随机分类器——即以与待考察分类器相同的数量随机分配示例给每个类别的分类器——做出正确预测的概率。如果分类器总是正确的，则 `κ = 1`。如果其预测与正确结果一致的频率与随机分类器相同，则 `κ = 0`。

Kappa M 统计量 `κ[m]` [40] 是一种与多数类分类器而非随机分类器进行比较的度量：

![](images/pg90-2.png)

在预测类别的分布与实际类别的分布存在显著差异的情况下，多数类分类器的表现可能优于给定分类器，而该分类器却拥有正的 `κ` 统计量。

Kappa 统计量的一种替代方案是计算接收者操作特征曲线下面积 AUC。Brzezinski 和 Stefanowski 在文献 [59] 中提出了一种增量算法，该算法使用带有滑动窗口的排序树结构来计算带遗忘机制的 AUC。由此产生的评估度量称为预训练 AUC，也可在 `MOA` 中使用。

其中 ![](images/pg91-in-1.png) 是无变化分类器的准确率，该分类器只是简单地重复最后接收到的标签（第 6.2.2 节），当相同标签成批出现时，这是一个简单且有用的分类器。

统计量 `κ[per]` 取值范围为 0 到 1。其解释类似于 `κ`：如果分类器完全正确，则 `κ[per] = 1`。如果分类器达到的准确率与无变化分类器相同，则 `κ[per] = 0`。优于无变化分类器的分类器介于 0 和 1 之间。有时 `κ[per] < 0`，这意味着分类器的表现比无变化基线更差。

使用 `κ[per]` 代替 `κ[m]`，我们可以检测非 IID 数据的误导性分类器性能。对于高度不平衡但独立分布的数据，多数类分类器可能击败无变化分类器。`κ[per]` 和 `κ[m]` 度量可视为正交的，因为它们衡量性能的不同方面。

## 6.1.4 统计显著性

在评估分类器时，我们应关注结果的统计显著性。仅观察单个分类器的性能时，提供关于其统计显著性的一些见解是很方便的。我们可以使用参数估计的*置信区间*来指示估计的可靠性。为此，我们可以使用 Chernoff 界或 Hoeffding 界，它们比 Markov 不等式或 Chebyshev 不等式更精确，因为我们关心的度量是对单个项目评估的平均值。对于数量合理的大量数据点，通常适用正态分布近似；参见第 4.2 节。
