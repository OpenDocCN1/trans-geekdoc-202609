In contrast to other forms of cryptocurrency like Bitcoin and Ethereum, Ripple is made up of a "hash tree" rather than a blockchain. Because there are a finite number of coins – 100 billion – XRP cannot be mined. Cryptocurrency is built on blockchain technology. It's a type of database that groups information into groups or blocks. Each new piece of information is added after a newly added block is combined into a new block, which is then added to the chain. A Block chain, as the name suggests, divides data into blocks that are linked together. Ripple is similar to blockchain in that transactions are processed by multiple nodes. The payment process entails someone sending a transaction, the information is given a single value and sent to a shared public database, validating servers or nodes sharing the information, and the transaction is authorized and processed if separate servers report a match. Because it does not involve proof of work, the system is not comparable to Bitcoin. In Bitcoin, a miner on the Bitcoin blockchain is required to complete a complex equation to show the work before the acceptance of the block into the chain. The Ripple model, on the other hand, is consensus-based. The transaction is cleared once there is agreement. As a result, the Ripple network could indeed process 1,500 transactions per second, whilst Bitcoin can only handle three to six transactions per second, and Ethereum can only handle 15 transactions per second. Despite the fact that it is not identical to the blockchain system, the Ripple process is relatively efficient and quick, which is one of the main reasons banks and major payment systems are considering and experimenting with Ripple.
