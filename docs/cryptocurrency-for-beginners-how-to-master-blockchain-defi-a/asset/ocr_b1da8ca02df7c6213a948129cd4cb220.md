# 1.4 What is Cryptography?

Cryptography is a means of protecting communications in the face of third parties with malicious intent—that is, third parties that intend to steal your information or overhear your conversation—by using encryption and decryption. Among the computational algorithms that cryptography employs are SHA-256, which would be the hashing method that Bitcoin employs; a public key, which is similar to digital information of the user that is got to share with everybody; and a secret key, which is similar to electronic signatures of the user that is kept private.

# Bitcoin Transactions and Cryptography

A typical bitcoin transaction details include who you want to transfer bitcoin to and how many bitcoin you want to send. Following that, the data is processed via a hashing method. The SHA-256 algorithm is used by Bitcoin, as previously stated. The output is subsequently signed using the user's private key, which allows the user to be uniquely identified. The cryptographically signed output is subsequently sent around the network for verification by other users. The sender's public key is used to do this.

Miners are users who examine a transaction to see if it is genuine or not. The transaction, along with numerous others, is then uploaded to the network, where the data can no longer be modified.
