# How Does Dogecoin Work?

Dogecoin is a virtual currency that, like Bitcoin and Ethereum, is based on blockchain technology. Blockchain is a decentralized digital ledger that keeps all transactions conducted with a decentralized digital currency in a distributed, secure manner. The Dogecoin blockchain record, which is regularly updated with all transactions in the cryptocurrency, is carried by all holders in an identical copy. The blockchain network of Dogecoin, like those of other cryptocurrencies, employs encryption to make all transactions safe.
