# # Ethereum Features

Listed below are the salient features of Ethereum.

+   • Launched in 2015, Ethereum’s blockchain commonly recognized synonym is Blockchain 2.0

+   • Smart contracts program the transfers

+   • Its smart contracts remove the need for third parties in multiple structures, not just financial ones

+   • It offers a forum to develop smart-contract applications (known as dApps)

+   • It offers a programming language, named Solidity, to develop the dApps with

+   • Ether is the currency; it drives transfers on the Ethereum blockchain

+   • Ether is extremely liquid

+   • Ethereum’s transfers take seconds to complete
