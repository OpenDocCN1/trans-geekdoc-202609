# ## Ethereum ecosystem

The Ethereum blockchain stack comprises multiple modules. At heart, there is the Ethereum blockchain operating on the peer-to-peer Ethereum network. Furthermore, there's an Ethereum client that operates on the nodes and links to the p-to-p Ethereum network from where block chain can be downloaded and stored locally. It provides multiple functions, like mining and account management. A local copy of the blockchain is then synchronized periodically with the network. Another aspect is the web3.js library that enables contact with the geth client through the Remote Procedure Call (RPC) interface. A list of all high-level elements present in the Ethereum blockchain contains the following:

+   - Keys and addresses
+   - Accounts
+   - Transactions and messages
+   - Ether crypto currency/tokens
+   - The EVM
+   - Smart contracts
