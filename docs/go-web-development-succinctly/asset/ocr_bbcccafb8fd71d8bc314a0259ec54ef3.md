# Creating a workspace

The final step is telling Go where any code you write, as well as any third-party libraries you download with go get, will reside. Do this by setting the GOPATH environment variable using the same techniques described above.

Go will create bin, pkg, and src files in this location:

+   - bin: Contains executables
- pkg: Contains package objects
- src: Contains source code
