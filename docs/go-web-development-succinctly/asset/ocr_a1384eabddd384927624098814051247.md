# Logging

Any application that grows beyond the trivial will need good logging in order to enable its developers to locate and fix errors.

# Basic logging

Go's log package lets you write to all the standard devices, custom files, (via io.Writer interface. So far, we've only logged to stdout via fmt.Println, etc), but that's not a realistic option for production applications. Let's consider how we might log output to files and be specific about which files gets type of log message.

In the following code, we create an application that log notices to notices.log, warnings to warnings.log, and errors to errors.log.
