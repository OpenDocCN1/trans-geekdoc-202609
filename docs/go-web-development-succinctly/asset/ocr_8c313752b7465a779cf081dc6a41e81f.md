That information JSON, JavaScript Object Notation. Despite the name, it's not specific to JavaScript. In fact, it's a common way of encoding data in a very lightweight format, and it's used by applications in many different languages, including Go.

Apart being lightweight and easily parsed by client applications, JSON is also human readable. Well, just barely. You can tidy the response by viewing it in your browser's developer console or by installing an extension that prettifies a JSON response.

As you can see, JSON is a simple bunch of key/value pairs. Everything inside the braces is a JSON object, and objects themselves can contain other objects and arrays of values.

However, this isn't a JSON tutorial. You can find out JSON almost anywhere on the web, and there's not a lot to it. The takeaway here is that APIs can parse a URL and return data in the JSON format that can be consumed by a client application.
