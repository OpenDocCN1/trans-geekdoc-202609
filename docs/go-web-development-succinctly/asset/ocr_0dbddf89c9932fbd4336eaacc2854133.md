Let's consider some of the benefits of using templates. First, our code is much neater. We don't need to wade through long strings of tags in order to work out what's going on.

Second, we can change the template at any time, no recompilation needed.

Third, the template syntax is simple enough that we could hand it over to someone who knows nothing about Go, or about web development in general, but might have a better handle on design than we do.

What else can we do with Go templates? Quite a lot, it happens. Check out the official documentation for the definitive list. In the meantime, there are several features that are so useful it would be remiss of me not to least mention them—embedded methods and conditionals.

# Using embedded methods in templates

Let's say we want to do something with our populated output. Perhaps we'd like to format the Population column in the preceding example to use a comma as a thousands separator.

Sure, we could add an extra string in the City structure to display formatted output and write the formatted Population column each time we retrieve a row from the table. But, technically, that's presentation, right? And haven't been keen to get as much presentation logic out of our main code as possible?

Also, this is especially cumbersome because Go's finth package doesn't provide this functionality out of the box, which means we'll have to roll our own.
