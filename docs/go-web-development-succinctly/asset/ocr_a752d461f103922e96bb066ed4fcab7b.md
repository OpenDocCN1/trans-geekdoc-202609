# How so?

Well, consider a website that you access in a browser. You enter a URL to the site, and the program behind the site can analyze URL to understand your intention. In a static site, you're simply entering URLs that point to file resources on the web server, but in a site that employs web services, you can effectively use the API as a command line entry not only for resources, but also for specific operations that the program's API exposes.

Consider the Open Movie Database website (http://www.omdbapi.com) that provides a free REST API to access information about movies. You only need to craft the URL so that it specifies what you want it to give.

If you start at https://www.omdbapi.com/, you get the home page in Figure 19.
