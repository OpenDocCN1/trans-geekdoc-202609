Question 61. What data type would the variable $myVar have after the following code is executed: $myVar = "123abc";

+   A. Integer

+   B. String

+   C. Boolean

+   D. Float

Correct Answer: B

Explanation: The variable $myVar contains the value "123abc" which is enclosed in double quotes, making it a string data type in PHP. Integer, Boolean, and Float do not apply as they are numeric or logical values, not textual.

Question 62. In PHP, which of the following is the correct syntax for a single-line comment?

+   A. <!-- This is a comment -->

+   B. // This is a comment

+   C. # This is a comment

+   D. Both B and C

Correct Answer: D

Explanation: Both options B and C represent valid single-line comment syntaxes in PHP. Option B uses double slashes //, and option C uses a hash # Option A is an HTML comment, not a PHP comment.
