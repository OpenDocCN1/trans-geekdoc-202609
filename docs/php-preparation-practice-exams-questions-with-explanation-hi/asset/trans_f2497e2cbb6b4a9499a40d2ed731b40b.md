## 问题 78. 哪一个 PHP 函数用于停止脚本执行并立即显示消息，通常用于调试或应用程序发生严重错误时？

A. die()

B. exit()

C. stop()

D. terminate()

正确答案：A

解释：`die()` 函数是 PHP 中 `exit()` 的别名，通常用于停止脚本的执行。它可选地接受一个字符串参数，该参数可以作为消息输出。它对于调试以及由于严重错误而停止执行非常有帮助。

# 问题 79. 如果调用 PHP 函数时传递的参数多于设计接收的数量，会发生什么？例如，如果一个函数定义了两个参数，但在调用时传入了三个参数？

A. PHP 将抛出一个致命错误（fatal error）。

B. PHP 将忽略额外的参数。

C. PHP 将返回 NULL。

D. PHP 将发出警告（warning）并继续运行。

正确答案：B

解释：PHP 允许传递比函数定义接收更多的参数，它会简单地忽略额外的参数。函数将仅使用定义的参数数量执行，这使其在处理不同参数数量时具有灵活性。

## 问题 80. 开发者如何通过指定在脚本执行期间未捕获异常时调用的函数，来处理 PHP 中的未捕获异常，从而提供一种全局捕获机制？

- A. set_error_handler()
- B. try-catch 块
- C. set_exception_handler()
- D. trigger_error()

正确答案：C

解释：`set_exception_handler()` 函数允许开发者指定一个自定义函数来全局处理未捕获的异常。这对于捕获本地 try-catch 块未处理的意外异常非常有用，可以确保优雅的错误处理。

## 问题 81. 在 PHP 中，以下哪种方法是定义接收两个参数、通过相加执行计算并返回结果的正确方法？该函数应命名为 `addNumbers`，并且应该能够处理浮点数和整数。

- A. function addNumbers($a, $b) { return $a + $b; }
- B. function addNumbers(int $a, int $b) { return $a + $b; }
- C. function addNumbers(float $a, float $b) { return $a + $b; }
- D. function addNumbers($a, $b) { return (int)$a + (int)$b; }

正确答案：A

解释：在 PHP 中定义增加两个数并返回结果的函数的正确方法是选项 A。通过不为参数指定类型，它允许处理浮点数和整数，提供了灵活性。选项 B 和 C 分别将参数限制为整数和浮点数，可能无法处理所有数字类型，而选项 D 强制将值转换为整数，可能会导致精度丢失。

# 问题 82. 当 PHP 脚本遇到错误时，错误处理中的 try 块和 catch 块的作用是什么？请描述它们如何协同工作以有效管理异常。

- A. try 块捕捉错误，catch 块在未发生错误时执行代码。

- B. try 块执行代码，catch 块处理 try 内部代码抛出的异常。

- C. try 和 catch 块都必须有 return 语句，错误处理才能有效。

- D. try 和 catch 在 PHP 中可以互换，可以放在代码的任何地方。

正确答案：B

解释：`try` 块用于封装可能抛出异常的代码，而 `catch` 块则是当异常发生时处理这些异常的地方。这种结构允许开发者优雅地管理错误并保持对程序流的控制，而不是让脚本意外终止。选项 A、C 和 D 误解了 PHP 中这些结构的功能。

# 问题 83. 以下哪一个 PHP 函数最适合定义一个接收可数量参数并计算其平均值的函数，允许灵活的输入数量？

- A. function average($values) { return array_sum($values) / count($values); }

- B. function average(...$values) { return array_sum($values) / count($values); }

- C. function average($values) { return array_sum($values) / count($values); } 配合 func_num_args($args)

- D. function average() { $args = func_get_args(); return array_sum($args) / count($args); }

正确答案：B

解释：选项 B 正确利用了扩展运算符 `(...)` 来接收可数量的参数，允许函数处理任意数量的数字输入。这种灵活性对于在不需要数组的情况下计算平均值至关重要。选项 A 需要数组，而选项 C 在不修改的情况下无法直接允许变长参数。选项 D 实现了相同的功能，但效率低于扩展运算符。

## 问题 84. 在 PHP 中，执行错误处理时，`error_reporting()` 函数的作用是什么？它如何使用它来控制脚本中的错误报告级别？

- A. 它仅在发生严重错误时才向浏览器发送错误消息。
- B. 它根据常量定义的严重性级别报告哪些错误。
- C. 它无论设置如何都会自动将所有错误记录到指定文件中。
- D. 它允许开发者在执行期间忽略脚本中的所有错误。

正确答案：B

解释：`error_reporting()` 函数设置 PHP 将报告哪些类型的错误，基于定义的严重性级别。通过指定 `E_ALL`、`E_NOTICE` 或 `E_WARNING` 等级别，开发者可以控制错误报告的详细程度，它是调试的重要工具。选项 A、C 和 D 错误描述了该函数的目的和功能。

## 问题 85. 当你定义 PHP 函数时，关于函数内部变量范围，以下哪个是正确的？全局变量是如何交互的？

- A. 局部变量不需要特殊声明即可访问全局变量。
- B. 全局变量只有在声明为 global 的情况下才能在函数内部访问。
- C. PHP 函数可以访问外部的所有变量。
- D. 函数内部的局部变量可以覆盖全局变量。

正确答案：B

解释：在 PHP 中，全局变量必须通过 `global` 关键字访问。这确保了函数显式访问全局上下文，避免意外修改。选项 A 是错误的，因为局部变量无法直接访问全局变量；选项 C 误解了规则，选项 D 描述了覆盖的行为。

# 问题 86. PHP 中以下哪种错误类型可以使用 Exception 类和 `throw` 关键字进行捕获和处理，允许开发者有效管理运行时错误？

- A. PHP 生成的所有错误，包括致命错误。
- B. 自定义异常以及派自 Exception 类的标准异常。
- C. 解析 PHP 脚本期间发生的语法错误。
- D. 对脚本执行至关重要的警告和通知。

正确答案：B

解释：PHP 的 Exception 类专门设计用于管理自定义异常和标准异常，允许开发者抛出并捕获执行期间预期错误。这不涵盖致命错误、语法错误或警告，因为这些无法通过异常处理系统捕获。选项 A、C 和 D 错误包含了无法通过异常机制管理的错误。
