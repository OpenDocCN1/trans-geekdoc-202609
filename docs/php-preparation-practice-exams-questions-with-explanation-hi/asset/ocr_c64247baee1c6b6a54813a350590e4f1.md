**Question 18.** When using mysqli in PHP, what does the function mysqli_close() do, and why is it important to call this function after database operations are complete?

+   A. It resets the database to its original state.

+   B. It permanently deletes the database.

+   C. It closes the database connection and frees up resources.

+   D. It creates a new database connection.

Correct Answer: C

Explanation: The mysqli_close() function is used to close a previously opened database connection, which is important for freeing system resources that are no longer needed. Properly closing connections helps maintain performance and avoids potential memory leaks, especially in applications that handle numerous database interactions. Failing to close connections can lead to resource exhaustion over time.
