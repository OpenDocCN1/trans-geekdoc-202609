# Question 84. In PHP, which control structure is used to execute a block of code only if a specified condition is true, allowing for optional alternative blocks to be executed if the condition is false?

+   A. switch

+   B. if...else

+   C. for

+   D. while

Correct Answer: B

Explanation: The if...else control structure in PHP allows for the execution of a block of code based on whether a condition evaluates to true or false. If the condition is true, the code within the block runs; if false, the code in the else block (if provided) is executed.
