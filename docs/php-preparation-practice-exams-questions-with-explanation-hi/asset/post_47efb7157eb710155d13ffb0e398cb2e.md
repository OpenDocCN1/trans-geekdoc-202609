**Question 44.** Which of the following statements accurately describes the purpose of using prepared statements in PHP when interacting with a MySQL database? Prepared statements are often recommended for their performance and security benefits, particularly in environments where the same query needs to be executed multiple times with different parameters.

- A. They allow SQL queries to be cached for faster execution.
- B. They help in preventing SQL injection attacks by separating SQL code from data.
- C. They enable dynamic SQL queries that adjust based on user input.
- D. They automatically optimize queries for better performance.

Correct Answer: B

Explanation: The correct answer is B, as prepared statements help in preventing SQL injection attacks by separating SQL code from data. **Question 48.** What is the primary purpose of using transactions in PHP when performing multiple SQL operations? This concept is crucial for ensuring data integrity and consistency, particularly in scenarios involving multiple changes.

A. To reduce the amount of data sent to the database.
B. To allow multiple SQL statements to be executed as a single unit of work.
C. To enhance performance by optimizing execution.
D. To automatically roll back changes after a predefined timeout.

Correct Answer: B

Explanation: The correct answer is B, as transactions allow multiple SQL statements to be executed as a single unit of work. This means that if one operation fails, all changes made during the transaction can be rolled back, maintaining the integrity and consistency of the database.
