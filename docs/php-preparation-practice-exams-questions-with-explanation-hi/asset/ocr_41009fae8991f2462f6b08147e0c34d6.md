**Question 63.** In PHP, executing a SQL query using the MySQL extension, what function must be used to prepare the statement for execution to prevent SQL injection attacks effectively?

+   A. mysql_query()
B. mysql_prepare()
C. mysql_execute()
D. mysql_bind_param()
Correct Answer: B

Explanation: The mysqli_prepare() function is used to prepare a SQL statement for execution, which can be executed multiple times with different parameters while significantly reducing the risk of SQL injection. Prepared statements separate the SQL logic from the data being sent, ensuring better security practices.

**Question 64.** Which of the following methods in PDO is used to fetch a single row from the result set, returning the data as an associative array, where the column names are the keys of the array?

+   A. fetchRow()
B. fetchAssoc()
C. fetchOne()
Correct Answer: C

Explanation: The fetch() method in PDO retrieves the next row from a result set. By default, it returns the row as an associative array if the PDO::FETCH_ASSOC fetch style is set. This makes it easy to access the data by column names, enhancing readability and maintainability of the code when handling database results.
