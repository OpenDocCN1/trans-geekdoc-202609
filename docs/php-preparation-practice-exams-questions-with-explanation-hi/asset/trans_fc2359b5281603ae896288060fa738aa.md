**问题 20。** 在 PHP 应用程序中使用 ORM（对象关系映射）工具的主要目的是什么？它是如何简化数据库交互的？

- A. 它将 SQL 查询转换为原始 HTML。
- B. 它提供了一个直接执行复杂 SQL 查询的框架。
- C. 它允许开发人员使用对象而非 SQL 语句与数据库进行交互，从而提高代码的可维护性。

**问题 21。** 哪个 PHP 函数主要用于建立与 MySQL 数据库的连接？该函数成功连接到数据库所需的参数是什么？

- B. `mysqli_connect()` - 需要数据库服务器地址、用户名、密码和数据库名称作为参数。
- C. `db_connect()` - 仅使用数据库服务器地址作为参数。

## **问题 22。** 使用 PHP 数据对象 (PDO) 进行数据库交互时，以下哪个描述描述了使用预处理语句的优势？

- A. 预处理语句仅适用于 MySQL 数据库，从而增强了安全性。
- B. 预处理语句允许使用不同的参数高效执行相同的 SQL 语句。
- C. 预处理语句无助于防止 SQL 注入攻击。
- D. 预处理语句会自动处理所有类型的数据库连接，而无需配置。

正确答案：B

解释：PDO 中的预处理语句具有显著的优势，特别是在性能和安全性方面。它们允许使用不同的参数多次执行相同的 SQL 查询，而无需重新解析。这不仅提高了效率，还有助于防止注入攻击，因为参数被视为数据而非可执行代码。

**问题 25。** 如果你需要在 PHP 中安全地处理用户输入并将其包含 SQL 查询，以下哪种方法是防止 SQL 注入攻击的最佳实践？

- A. 在将用户输入包含到查询之前使用 `htmlspecialchars()` 转义特殊字符。
- B. 使用 `mysqli_real_escape_string()` 对用户输入进行清理。
- C. 使用带有绑定参数的预处理语句。
- D. 在在查询中使用用户输入之前，用正则表达式对用户输入进行验证。

正确答案：C

解释：使用带有绑定参数的预处理语句是防止 SQL 注入攻击的最佳实践。这种方法确保用户输入被视为数据而非可执行代码。虽然像 `mysqli_real_escape_string()` 这样的转义函数有所帮助，但它们提供的安全性不如预处理语句，因为后者会自动处理输入清理。

## 问题 27。在 PHP 中使用事务时，关于提交或回滚事务的过程，以下哪个描述是正确的？

- A. 事务在每次查询后都会自动提交，因此没有必要手动处理。
- B. 事务只有在已提交后才能被回滚。
- C. 为了确保数据完整性，如果事务的一个部分失败，你应该回滚整个事务到原始状态。
- D. 回滚只能对 SELECT 查询执行。

正确答案：C

解释：在数据库事务的上下文中，如果事务的某部分失败，回滚整个事务以维护数据完整性至关重要。这意味着在事务期间所做的任何更改都会撤销，将数据库恢复到事务开始之前的状态。这在执行多个相互依赖的查询场景中至关重要，确保了部分更新不会导致不一致。
