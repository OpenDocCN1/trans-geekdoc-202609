# Question 17. In PHP, which control structure can be used to execute a block of code repeatedly as long as a specified condition remains true?

A. if statement

B. foreach loop

C. while loop

D. switch statement

Correct Answer: C

Explanation: The while loop in PHP is designed to repeatedly execute a block of code as long as the specified condition evaluates to true. This is fundamental for scenarios where the number of iterations isn't known beforehand, and it provides flexibility in executing code on dynamic conditions.
