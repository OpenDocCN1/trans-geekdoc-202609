Question 44. In PHP, what does the parent:: keyword signify when used within a child class method?

+   A. It allows the child class to override the parent class methods

+   B. It is used to call a method from the child class

+   C. It refers to the parent class's namespace

+   D. It enables access to the parent class's properties and methods

Correct Answer: D

Explanation: The parent:: keyword is used in a child class to call methods or access properties from its parent class. This is particularly useful when a child class overrides a method but still wants to utilize the functionality of the method defined in the parent class, thereby facilitating code reuse and the implementation of polymorphism.

Question 45. Which of the following statements correctly describes encapsulation in PHP OOP?

+   A. Encapsulation allows data to be modified directly from outside the class.

+   B. Encapsulation restricts access to certain details of an object and protects its integrity.

+   C. Encapsulation means creating multiple objects from a single class.

+   D. Encapsulation is about inheritance in OOP.

Correct Answer: B

Explanation: Encapsulation is a fundamental concept in OOP that involves restricting access to certain components of an object and controlling how the object's data can be accessed or modified. This is typically achieved using visibility keywords such as public, private, and protected, which help maintain the integrity of the object's state and prevent unintended interference from outside the class.
