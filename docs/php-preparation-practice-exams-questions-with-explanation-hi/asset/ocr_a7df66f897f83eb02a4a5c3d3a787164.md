A. Interfaces in PHP allow classes to inherit from multiple parent classes.

B. Interfaces in PHP define a contract that classes must implement, ensuring they provide specific methods but without defining how those methods should work.

C. Interfaces in PHP allow abstract classes to inherit properties from one another.

D. PHP does not support interfaces; it only uses abstract classes for defining contracts.

Correct Answer: B

Explanation: In PHP, interfaces are used to define a set of methods that implementing classes must provide. Unlike classes, interfaces do not contain any method bodies. They enforce a contract that the implementing class must fulfill, allowing for consistent behavior across different classes, regardless of their place in the inheritance chain.

**Question 98.** How does the concept of abstraction work in PHP, particularly when dealing with abstract classes and methods, and how does it differ from a normal class in terms of object instantiation?

A. Abstract classes in PHP can be instantiated directly, but only if they do not contain abstract methods.

B. Abstract classes in PHP cannot be instantiated directly and can contain abstract methods that must be implemented by subclasses.

C. Abstract classes in PHP can be instantiated like any other class but do not require method implementation.

D. Abstract classes in PHP are only used for type hinting and cannot contain any methods.

Correct Answer: B

Explanation: In PHP, abstract classes cannot be instantiated directly. They are intended to serve as base classes for other classes to extend. Abstract methods within these classes must be implemented by any subclass, allowing for consistent design while deferring specific implementations to child classes.
