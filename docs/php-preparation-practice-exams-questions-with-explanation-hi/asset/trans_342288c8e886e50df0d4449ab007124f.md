**问题 75.** 下面代码的输出是什么：echo gettype(10.5)？

A. integer

B. float

C. double

D. string

正确答案：B
解释：PHP 中的 `gettype()` 函数返回传递给它的变量的类型。在这种情况下，`gettype(10.5)` 将返回 float，因为 10.5 是一个浮点数。注意，在某些语境下，double 是等效类型，但 `gettype()` 专门为浮点数返回 float。

**问题 77.** 下面代码输出什么？$x = 5; $y = $x++;
echo $y;

A. 5

B. 6

C. null

D. 0

正确答案：A

解释：在这段代码中，$y 在增加之前被赋值为 $x 的值。后自增运算符 (++) 在返回当前值后将 $x 的值增加 1。因此，$y 将持有 $x 的原始值（即 5），而 $x 在此此操作后将变为 6。

**问题 79.** 该代码片段的输出是什么：$a = "Hello"; $b = $a; $b = " World"; echo $a?

A. Hello World

B. Hello

C. World

D. Hello World Hello

正确答案：B

解释：在这段代码中，$b 被赋值为 $a 的值，但当使用连接运算符 (.) 修改 $b 时，它不会改变 $a。因此，当调用 echo $a; 时，它输出 "Hello"。变量 $b$ 变成了 "Hello World"，但它不会影响 $a。

**问题 90. 在 PHP 中，你可以声明哪两种主要的变量类型？它们在内存管理和灵活性方面有何区别？**

A. 静态和动态变量
B. 全局和局部变量
C. 公有和私有变量
D. 整数和浮点变量

正确答案：B
解释：全局变量在声明后可以在脚本的任何部分访问，而局部变量限于定义它们的函数或块。这种区别对于内存管理至关重要，因为局部变量在作用域结束后会被销毁，有助于防止内存泄漏并提高脚本性能。

**问题 91. 在 PHP 中使用关联数组时，下列哪项正确演示了如何定义包含至少三个键值对的关联数组？使用关联数组相比索引数组的优势是什么？**

A. $colors = array('red' => '#FF0000', 'green' => '#00FF00', 'blue' => '#0000FF');
B. $colors = array('#FF0000', '#00FF00', '#0000FF');
C. $colors[] = 'red'; $colors[] = 'green'; $colors[] = 'blue';

正确答案：A
解释：关联数组允许使用描述性键而不是数字索引，使数据更具可读性且易于管理。
