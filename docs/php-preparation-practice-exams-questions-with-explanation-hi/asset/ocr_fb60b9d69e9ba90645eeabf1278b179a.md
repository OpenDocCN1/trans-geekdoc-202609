# **Question 22.** When using PHP Data Objects (PDO) for database interactions, which of the following statements describes the advantages of using prepared statements?

+   A. Prepared statements only work with MySQL databases, enhancing security.

+   B. Prepared statements allow for executing the same SQL statement multiple times with different parameters efficiently.

+   C. Prepared statements do not help in preventing SQL injection attacks.

+   D. Prepared statements automatically handle all types of database connections without configuration.

Correct Answer: B

Explanation: Prepared statements in PDO offer significant advantages, particularly in performance and security. They enable the same SQL query to be executed multiple times with different parameters without the need for re-parsing. This not only improves efficiency but also helps prevent injection attacks, as the parameters are treated as data rather than executable code.
