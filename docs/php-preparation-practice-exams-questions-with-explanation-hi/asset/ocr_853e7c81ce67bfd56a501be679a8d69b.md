**Question 77.** What does the following code output? $x = 5; $y = $x++;
echo $y;

+   A. 5

+   B. 6

+   C. null

+   D. 0

Correct Answer: A

Explanation: In this code, $y is assigned the value of $x before it is incremented. The post-increment operator (++) increases the value of $x by 1 after the current value has been returned. Therefore, $y will hold the original value of $x, which is 5, while $x becomes 6 after this operation.
