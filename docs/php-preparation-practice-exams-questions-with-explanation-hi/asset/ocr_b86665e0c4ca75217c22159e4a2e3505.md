# **Question 89.** What is the primary difference between an abstract class and an interface in PHP, particularly in terms of how they are utilized in application design and their limitations regarding method definitions?

A. An abstract class cannot contain any concrete methods.

B. An interface can contain method definitions with implementation.

C. An abstract class can provide default behavior, while an interface cannot.

D. An interface allows for the implementation of multiple classes at once.

Correct Answer: C

Explanation: The primary difference between an abstract class and an interface in PHP is that an abstract class can provide default behavior through concrete method implementations, while an interface cannot contain any method implementations. This allows abstract classes to define some common functionality that derived classes can inherit, whereas interfaces only specify method signatures that implementing classes must define.
