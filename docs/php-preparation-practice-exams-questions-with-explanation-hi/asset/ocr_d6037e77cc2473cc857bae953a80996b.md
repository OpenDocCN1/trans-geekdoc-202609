# Question 91. In PHP, what are the two main types of variables that you can declare, and how do they differ in terms of memory management and flexibility in coding?

+   A. Static and dynamic variables
B. Global and local variables
C. Public and private variables
D. Integer and float variables

Correct Answer: B
Explanation: Global variables are accessible from any part of the script after their declaration, while local variables are confined to the function or block in which they are declared. This distinction is crucial for memory management, as local variables are destroyed once their scope ends, helping prevent memory leaks and improving the performance of the script.
