# Question 8. When using PHP Data Objects (PDO) for database interaction, which of the following methods is used to execute a prepared statement after binding the necessary parameters?

+   A. execute()

+   B. run()

+   C. prepare()

+   D. bind()

Correct Answer: A

Explanation: The execute() method is called on a PDO statement object after the statement has been prepared and parameters have been bound. This method executes the prepared statement with the bound parameters, allowing for secure and efficient database interactions, as it handles the execution process and possibly errors.
