**Question 53.** When working with database transactions in PHP, which of the following statements accurately describes the significance of the commit and rollback operations in maintaining data integrity, especially in applications that require multiple related database operations to succeed or fail as a single unit?

+   A. Commit is used to undo changes, while rollback saves changes.

+   B. Rollback is used to undo changes, while commit saves changes permanently.

+   C. Both commit and rollback are optional for data integrity.

+   D. Commit and rollback are used only for read operations.

Correct Answer: B

Explanation: In database transactions, the commit operation saves all changes made during the transaction permanently to the database, while the rollback operation undoes all changes if an error occurs, ensuring that the database remains in a consistent state. This mechanism is essential for applications that require multiple related operations to either succeed or fail without leaving partial updates.
