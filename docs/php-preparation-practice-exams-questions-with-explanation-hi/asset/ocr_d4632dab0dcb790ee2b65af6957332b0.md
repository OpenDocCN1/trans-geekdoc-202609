# **Question 49.** In a PHP application, which function is used to retrieve the ID of the last inserted row in a MySQL database after an INSERT operation has been executed? This function is particularly useful in applications that require tracking of newly created records.

+   A. mysqli_last_id()

+   B. mysqli_insert_id()

+   C. mysqli_get_last_id()

+   D. mysqli_fetch_last()

Correct Answer: B

Explanation: The correct answer is B, mysqli_insert_id(). This function retrieves the ID generated by a subsequent INSERT operation on a table with AUTO_INCREMENT column. It allows developers to reference the newly created record immediately after insertion, which is vital for managing related data effectively.
