# Question 70. Which control structure in PHP can be best utilized for scenarios requiring the evaluation of several alternative conditions that might lead to various outcomes, particularly when those conditions are mutually exclusive and evaluated based on a single variable's value?

+   A. if...else

+   B. foreach

+   C. switch

+   D. for

Correct Answer: C

Explanation: The "switch" statement is ideal for evaluating multiple conditions based on a single variable's value. Each case represents a unique condition, and only the block of code corresponding to the matching case is executed, enhancing code clarity and reducing complexity in situations where numerous conditional paths are possible.

# Question 71. When writing PHP scripts that require the execution of a block of code only when a specific condition is true, which control structure should be employed, and how does it differ from its alternative that includes an else clause?

+   A. if; it does not provide an alternative action.

+   B. switch; it handles multiple conditions.

+   C. while; it continues until the condition is false.

+   D. do...while; it checks conditions after executing the code.

Correct Answer: A

Explanation: The "if" statement is used when you want to execute a block of code solely on whether a specified condition evaluates to true. In contrast, using an "if...else" statement provides an alternative action if the condition is false, offering more control over the flow of execution based on different conditions.
