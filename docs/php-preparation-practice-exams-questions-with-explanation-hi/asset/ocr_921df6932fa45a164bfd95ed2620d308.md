# Question 78. How does the concept of encapsulation in PHP Object-Oriented Programming ensure that the internal state of an object is protected from unintended interference and misuse, particularly through the use of access modifiers?

+   A. By allowing public access to all class properties and methods.

+   B. By restricting access to class properties and methods using private and protected keywords.
C. By implementing all methods as static methods.
D. By enforcing a strict hierarchy among classes.

Correct Answer: B
Explanation: Encapsulation is the practice of restricting direct access to an object's properties and methods. In PHP, this is achieved through access modifiers like private and protected, which control visibility. This protects the internal state of an object, ensuring that it can only be modified through public methods, reducing the risk of unintended interference.

# Question 79. When using traits in PHP, how do they enhance code reuse, particularly in scenarios where a single class needs to share functionalities from multiple sources without the constraints of traditional inheritance?

+   A. They are similar to abstract classes and cannot be instantiated.
B. They allow multiple traits to be included in a single class, providing shared methods.
C. They define a set of static methods.
D. They can only be used in conjunction with interfaces.

Correct Answer: B
Explanation: Traits in PHP provide a mechanism for code reuse that allows developers to include shared methods in multiple classes. They can be combined within a single class, enabling a class to adopt behaviors from multiple traits without being limited by PHP's single inheritance model, promoting modularity and code duplication.
