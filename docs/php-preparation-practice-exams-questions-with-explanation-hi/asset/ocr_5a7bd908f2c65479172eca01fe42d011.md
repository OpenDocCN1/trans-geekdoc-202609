# Question 10. When performing database migrations in a PHP application,
of which the following practices is most advisable to ensure the integrity
and smooth execution of the migration process, especially in a production
environment?

+   A. Backing up the database before making any changes and documenting
all migration steps.

+   B. Performing migrations during peak usage times to minimize downtime.

+   C. Writing migration scripts that rely heavily on manual intervention to
adjust data.

+   D. Ignoring version control for migration scripts as they can be regenerated
if needed.

Correct Answer: A

Explanation: Backing up the database before making any changes is crucial
for data integrity and disaster recovery. Documenting migration steps
ures that the process is repeatable and traceable, which is vital for
maintaining a stable production environment.
