**Question 24.** In PHP, what is the significance of inheritance in Object-Oriented Programming, and how does it facilitate code reusability by allowing a derived class to inherit properties and methods from a base class?

+   A. It prevents classes from sharing functionalities.

+   B. It allows a derived class to inherit and override methods from a base class.

+   C. It requires every class to implement all methods explicitly.

+   D. It only applies to interfaces and not to classes.

Correct Answer: B

Explanation: Inheritance is a key feature in OOP that allows a derived class to inherit properties and methods from a base class. This facilitates code reusability because the derived class can extend or modify the behavior of the base class without duplicating code, promoting a cleaner and more organized structure.
