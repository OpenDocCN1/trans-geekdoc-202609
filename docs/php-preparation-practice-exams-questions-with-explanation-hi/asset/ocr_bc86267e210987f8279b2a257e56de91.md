# Question 74. In PHP, when a class is defined with the final keyword, what is the implication for the class and its methods, especially in the context of inheritance and overriding?

+   A. The class can be inherited, but its methods cannot be overridden.

+   B. The class cannot be inherited, and its methods cannot be overridden.

+   C. The class can be inherited, and its methods can be overridden.

+   D. The class can be instantiated only once.

Correct Answer: B

Explanation: Declaring a class as final in PHP prevents it from being extended by any other class, effectively prohibiting inheritance. Consequently, any methods within a final class cannot be overridden in subclasses, ensuring that the behavior of that class remains unchanged.
