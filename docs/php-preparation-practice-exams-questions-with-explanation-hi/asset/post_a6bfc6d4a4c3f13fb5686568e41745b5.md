- C. To ensure data integrity, if one part of a transaction fails, you should roll back the entire transaction to its original state.
- D. Rollbacks can only be performed on SELECT queries.

Correct Answer: C

Explanation: In the context of database transactions, if one part of a transaction fails, it is crucial to roll back the entire transaction to maintain data integrity. This means that any changes made during the transaction are undone, reverting the database to its state before the transaction began. This is essential in scenarios where multiple interdependent queries are executed, ensuring that partial updates do not lead to inconsistency.
