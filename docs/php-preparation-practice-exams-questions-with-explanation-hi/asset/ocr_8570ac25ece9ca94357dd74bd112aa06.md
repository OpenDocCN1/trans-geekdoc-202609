# **Question 32.** When integrating a MySQL database with PHP, which of the following functions is primarily used to execute an SQL query, and what are the consequences of using this function incorrectly in terms of error handling and data integrity?

+   A. mysql_query()
B. mysqli_execute()
C. pg_query()
D. PDO::query()

Correct Answer: A
Explanation: The mysql_query() function was used for executing SQL queries in older versions of PHP. If used incorrectly, such as not checking for errors or using user-supplied data without validation, it can lead to SQL injection vulnerabilities, data corruption, or application crashes.

# **Question 33.** In the context of PHP and database integration, what role does the mysqli_connect() function play, and what are the potential implications of failing to properly close a database connection after executing database operations?

+   A. It initializes a connection to the MySQL database using OOP principles.
B. It establishes a connection to the MySQL database server and can lead to resource exhaustion if not properly managed.
C. It retrieves data from a MySQL database without establishing a persistent connection.
D. It allows batch processing of multiple queries to enhance performance.

Correct Answer: B
Explanation: The mysqli_connect() function is crucial for establishing a connection to the MySQL database server. Failing to close the connection can lead to resource exhaustion, where the server runs out of available connections, potentially affecting performance and availability of the application.
