

A. 预留语句对于所有查询都更快。
B. 预留语句有助于防止 SQL 注入攻击。
C. 预留语句会自动对数据建立索引。
D. 预留语句不受用户输入的影响。

正确答案：B

解释：在 PHP 中使用 PDO 预留语句的主要优势是能够防止 SQL 注入。通过将 SQL 逻辑与用户输入分离，预留语句确保任何输入都被严格视为视为数据，而不是可执行代码。这显著增强了安全性，特别是在处理数据时。

问题 83. 将 PHP 应用程序与 MySQL 数据库集成时，以下哪种方法被认为是管理数据库连接并确保其高效利用的最佳实践？

- A. 为每个请求打开新的数据库连接。
- B. 使用持久连接以保持连接开启。
- C. 在每次查询后关闭数据库连接。
- D. 使用连接池来管理多个连接。

正确答案：D

解释：在 PHP 与 MySQL 集成时，利用连接池是最佳实践。这种方法通过重用现有的连接而不是重复打开新连接，实现了连接的高效利用，提高了性能。

问题 84. 在与数据库集成的 PHP 应用程序中，以下哪个陈述正确描述了事务的使用，为什么它对维护数据完整性至关重要？

- A. 事务允许将多个查询作为一个单一的工作单元执行，确保全部成功，要么都不应用。
- B. 事务仅对读操作有用。
- C. 事务会自动回滚数据库中进行的任何更改。
- D. 事务只能与 MySQL 数据库一起使用。

正确答案：A

解释：与数据库交互的 PHP 应用程序中的事务允许将多个查询作为一个单一的工作单元执行。这意味着如果一个查询失败，事务可以回滚，从而确保所有操作都成功，由此维护了数据完整性。

- A. mysql_last_id()

- C. db_get_lastID()

问题 88. 以下哪项是在 PHP 中使用 mysql_ 函数进行数据库集成的缺点，特别是对现代 Web 应用安全实践的影响？

- A. 它们同时支持 MySQL 和 PostgreSQL 数据库。
- B. 它们比 MySQLi 或 PDO 更高效。
- C. 它们不支持预留语句，导致容易受到 SQL 注入攻击。
- D. 基础操作需要大量的编码。

正确答案：C

解释：在 PHP 中使用 mysql_ 函数的一个重大缺点是它们不支持预留语句。这种缺乏支持使得应用程序容易受到 SQL 注入的攻击，因为用户输入可以直接影响 SQL 查询的结构。在对安全性至关重要的现代 Web 应用中，这是一个关键问题，因此建议使用 MySQLi 或 PDO 扩展。

问题 91. PHP 中的哪个函数用于连接 MySQL 数据库，并需要主机名、用户名、密码和数据库名作为参数来建立成功连接？

- A. mysqli_query()
- B. mysqli_connect()
- C. pg_connect()
- D. oci_connect()

正确答案：B

解释：mysqli_connect() 函数专门用于连接 PHP 中的 MySQL 数据库。它接受主机名（通常为 'localhost'）、用户名、密码和数据库名等参数来创建连接。如果连接成功，返回一个连接对象；否则返回 FALSE。
