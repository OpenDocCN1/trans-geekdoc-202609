**问题 30。** 在 PHP 应用程序中，如果你想使用面向对象的方法连接数据库，并确保兼容 MySQL 和 PostgreSQL 数据库，你会选择哪种扩展？

-   A. MySQL
-   B. PDO
-   C. SQLite

正确答案：B

解释：PDO（PHP Data Objects）扩展是使用面向对象的方法连接数据库的最佳选择，同时确保了对包括 MySQL 和 PostgreSQL 在内的多个数据库系统的兼容性。PDO 提供了一个统一的接口并允许使用预处理语句，使其成为 PHP 数据库交互中多功能且安全的选项。

**问题 31.**** 在 PHP 中连接数据库时使用 PHP Data Objects (PDO) 的主要目的是什么，特别是在处理多个数据库系统时？它是如何增强数据库交互安全性的？

-   A. 为了方便进行数据库连接，而不需要任何 SQL 知识。
-   B. 为访问不同的数据库提供一致的接口，同时通过预处理语句防止 SQL 注入攻击。
-   C. 允许直接访问数据库表而不需要 SQL 查询。
-   D. 启用数据库的自动数据备份过程。

正确答案：B

解释：PDO 为 MySQL、PostgreSQL 和 SQLite 等各种数据库系统提供了统一的接口。它对预处理语句的使用通过分离 SQL 代码和数据帮助防止 SQL 注入攻击，从而增强了数据库交互期间安全性。

## **问题 32.**** 将 MySQL 数据库与 PHP 集成时，以下哪个函数主要用于执行 SQL 查询？在错误处理和数据完整性方面，错误使用该函数会导致什么后果？

-   A. mysql_query()
-   B. mysqli_execute()
-   C. pg_query()
-   D. PDO::query()

正确答案：A
解释：`mysql_query()` 函数用于旧版本 PHP 中执行 SQL 查询。如果使用不当（例如不检查错误或在未经过验证的情况下使用用户提供的数据），可能会导致 SQL 注入漏洞、数据损坏或应用程序崩溃。

## Question 35. 在 PHP 中，哪个函数用于执行 INSERT、UPDATE 或 DELETE 语句后获取受影响的行数？在 Web 应用程序中忽略此信息可能导致什么？

-   A. mysqli_num_rows()
-   B. mysqli_affected_rows()
-   C. mysql_info()
-   D. mysqli_query_rows()

正确答案：B

解释：`mysqli_affected_rows()` 函数用于获取最后一个 INSERT、UPDATE 或 DELETE 操作影响的行数。忽略此信息可能会导致应用程序在数据未实际发生变化的情况下假设数据已更改，可能导致数据状态不一致或错误的用户反馈。
