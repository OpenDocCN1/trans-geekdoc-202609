**Question 95.** When declaring a constant in PHP using the define() function, which of the following correctly demonstrates how to declare a constant named SITE_NAME with the value "My Website", and what are the benefits of using constants in programming?

+   A. define(SITE_NAME, "My Website");
B. define("SITE_NAME", "My Website");
C. constant("SITE_NAME", "My Website");
D. const SITE_NAME = "My Website";

Correct Answer: B

Explanation: The correct syntax for declaring a constant using the define() function requires the constant name to be enclosed in quotes. Constants are beneficial as they provide a fixed value that cannot be changed throughout the script, ensuring data integrity and making the code easier to manage and understand.
