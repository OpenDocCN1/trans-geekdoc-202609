Question 13. When integrating PHP with a database, which of the following methods is typically used to retrieve data from a MySQL database after executing a SELECT query?

+   A. mysqli_fetch_array()

+   B. mysqli_query()

+   C. mysqli_connect()

+   D. mysqli_execute()

Correct Answer: A

Explanation: The mysqli_fetch_array() function is used to fetch a result row as an associative, numeric, or both types of array after executing a SELECT query with mysqli_query(). This function retrieves the data from the result set and allows for easy access to the returned records. The other options are not directly used for fetching data from a result set.

Question 14. In PHP, what is the primary advantage of using the PDO (PHP Data Objects) extension over MySQLi when connecting to databases, particularly in terms of database abstraction?

+   A. PDO supports only MySQL databases.

+   B. PDO allows for easier switching between different database types with minimal code changes.

+   C. PDO is more efficient in executing complex queries.

+   D. PDO does not support prepared statements.

Correct Answer: B

Explanation: The primary advantage of using PDO is its ability to support multiple database management systems (DBMS), allowing developers to switch between databases like MySQL, PostgreSQL, SQLite, etc., with minimal code changes. This flexibility makes PDO a preferred choice for applications that may need to connect to different databases over time. The other options misrepresent the capabilities of PDO.
