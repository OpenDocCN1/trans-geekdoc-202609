## **问题 79.** 在 PHP 中使用嵌套控制结构时，关于代码的可读性和可维护性，需要需要考虑的重要因素是什么？

- A. 为了保持简单性，应该完全避免嵌套。

- C. 嵌套层数过多会导致代码变得复杂且难以追踪。

# **问题 80.** 在 PHP 中，`break` 语句在循环中是如何运作的？在不指定数字参数的情况下使用它会有什么效果？

- A. 它终止所有嵌套循环并退出脚本。
- B. 它停止脚本的整个执行。
- C. 它跳出最近的包含它的循环或 switch 语句。

正确答案：D

解释：PHP 中的 `break` 语句用于退出最近的循环或 switch 语句。当在不带数字参数的情况下调用时，它会立即停止当前的循环迭代，并跳转到循环后的下一行代码。此特性允许对循环执行流进行灵活控制。

问题 82. 在 PHP 中何时使用 `if...else` 语句是合适的？它与 `switch` 语句有何区别？

A. 使用 `if...else` 用于单个条件检查，使用 `switch` 用于多个不相关的条件。

B. 使用 `if...else` 用于复杂的逻辑条件，使用 `switch` 用于简单的变量比较。

C. `if...else` 只能处理数值比较，而 `switch` 处理字符串。

D. 对于所有条件，`if...else` 始终比 `switch` 高效。

正确答案：B

解释：`if...else` 语句是处理复杂逻辑条件的理想选择，特别是当条件涉及多个变量或逻辑运算符时。相比之下，`switch` 语句最适用于针对单个表达式的简单、离散值的比较。这种区别有助于根据当前问题确定最有效的结构。
