# Question 68. When dealing with nested control structures in PHP, what potential issue might arise if an incorrect number of braces or keywords is used to delineate the beginning and end of the control structures, and what best practice can be applied to mitigate this risk?

+   A. Logic errors that can cause unexpected behavior; always use comments.

+   B. Infinite loops; use echo statements.

+   C. Syntax errors leading to runtime exceptions; ensure proper indentation and use of braces.

+   D. Variable scoping issues; declare variables outside the structures.

Correct Answer: C

Explanation: Improprily paired braces or keywords can lead to syntax errors, causing the PHP interpreter to throw exceptions at runtime. To mitigate these issues, adopting a consistent indentation style and grouping related statements with proper braces can enhance code readability and reduce the risk of errors.

# Question 69. In the context of PHP control structures, which of the following statements describes the primary function of the "break" statement, and how can it affect the flow of control within loops or switch statements?

+   A. It allows a loop to skip to the next iteration immediately.

+   B. It terminates the current loop or switch execution and continues with the next statement after the loop or switch.

+   C. It creates an infinite loop if used incorrectly.

+   D. It pauses execution until a condition is met.

Correct Answer: B

Explanation: The "break" statement in PHP is utilized to exit the current loop or switch statement immediately. This allows for a graceful termination of the flow of control, directing the program to resume execution at the next statement following the loop or switch, effectively preventing further iterations or case evaluations.
