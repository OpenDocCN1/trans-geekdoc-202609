**Question 93.** When integrating PHP with a MySQL database, which of the following practices should be employed to prevent SQL injection attacks, ensuring that user inputs are safely included in SQL statements?

+   A. Using the htmlspecialchars() function
B. Using prepared statements with parameterized queries
C. Relying solely on user input validation
D. Encoding special characters in a database

Correct Answer: B

Explanation: Using prepared statements with parameterized queries is a highly effective way to prevent SQL injection attacks when integrating PHP with MySQL. This approach separates SQL logic from data inputs, ensuring that user input is treated as data rather than executable code, enhancing security against injection vulnerabilities.

**Question 94.** Which PHP extension is required for using PDO (PHP Data Objects), a database access layer providing a uniform method of access to multiple databases, including MySQL, PostgreSQL, SQLite, and more?

+   A. mysqli
B. pdo_mysql
C. oci8
D. pgsql

Correct Answer: B

Explanation: The pdo_mysql extension is necessary for utilizing PDO with MySQL databases in PHP. PDO provides a consistent interface for database operations and supports prepared statements, making it a preferred choice for database interactions across various database management systems.
