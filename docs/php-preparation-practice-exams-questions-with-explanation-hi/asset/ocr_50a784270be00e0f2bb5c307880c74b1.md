# Question 81. Which PHP function is primarily used to establish a connection to a MySQL database, allowing a developer to interact with the database and perform operations as querying, inserting, or updating data?

+   A. mysqli_connect()
B. db_connect()
C. connect_to_db()
D. mysqli_connection()

Correct Answer: A

Explanation: The mysqli_connect() function is specifically designed for establishing a connection to a MySQL database in PHP. It accepts parameters such as the hostname, username, password, and database name. This function is part of the MySQLi extension, which provides a more secure and robust way to interact with MySQL databases compared to the older MySQL extension, which has been deprecated.
