# **Question 85.** In PHP, when a class implements an interface, what must be ensured regarding the methods declared in that interface, particularly concerning visibility and structure in the implementing class?

+   A. The methods in the implementing class must have the same visibility as in the interface.

+   B. The methods in the implementing class can have different names than those in the interface.

+   C. The methods in the implementing class can be declared as static only.

+   D. The methods in the implementing class are optional and do not need to be implemented.

Correct Answer: A

Explanation: When a class implements an interface in PHP, it must implement all the methods declared in the interface with the same visibility. This ensures that the implementing class adheres to the contract specified by the interface, maintaining consistent access levels for the methods across different implementations.
