**Question 93.** When integrating PHP with a MySQL database, which of the following practices should be employed to prevent SQL injection attacks, ensuring that user inputs are safely included in SQL statements?

- A. Using the htmlspecialchars() function
- B. Using prepared statements with parameterized queries
- C. Relying solely on user input validation
- D. Encoding special characters in a database

Correct Answer: B

Explanation: Using prepared statements with parameterized queries is a highly effective way to prevent SQL injection attacks when integrating PHP with MySQL. This approach separates SQL logic from data inputs, ensuring that user input is treated as data rather than executable code, enhancing security against injection vulnerabilities.

**Question 94.** Which PHP extension is required for using PDO (PHP Data Objects), a database access layer providing a uniform method of access to multiple databases, including MySQL, PostgreSQL, SQLite, and more?

- A. mysqli
- B. pdo_mysql
- C. oci8
- D. pgsql

Correct Answer: B

Explanation: The pdo_mysql extension is necessary for utilizing PDO with MySQL databases in PHP. PDO provides a consistent interface for database operations and supports prepared statements, making it a preferred choice for database interactions across various database management systems.

**Question 95.** In a scenario where a web application utilizes PHP to interact with a MySQL database, which function is best suited for retrieving a single row of data as an associative array after executing a SELECT query?

- A. mysqli_fetch_row()
- B. mysqli_fetch_assoc()
- C. mysqli_fetch_all()
- D. mysqli_fetch_object()

Correct Answer: B

Explanation: The mysqli_fetch_assoc() function retrieves the next row of the result set as an associative array, with column names as keys. This is ideal for accessing data by column name, enhancing code readability and maintainability, especially when handling data returned from a SELECT.

## Question 96. When integrating PHP with a MySQL database, what is the purpose of the mysqli_real_escape_string() function, and how does it contribute to database security?

- A. It converts special characters to HTML entities
- B. It checks if a database connection is successful
- C. It sanitizes user inputs by escaping special characters
- D. It retrieves the number of affected rows from the last query

Correct Answer: C

Explanation: The mysqli_real_escape_string() function sanitizes user inputs by escaping special characters, such as quotes and backashes, which could otherwise interfere with SQL syntax. This is crucial in preventing SQL injection attacks when incorporating user inputs into SQL queries, enhancing the overall security of the application.

## Question 97. In PHP, when connecting to a database, which of the following statements correctly represents the procedure for checking if the connection was successful and handling connection errors appropriately?

- A. $conn = mysqli_connect('localhost', 'user', 'pass'); if (!$conn) { die('Connection failed: ' . mysqli_connect_error()); }
- B. $conn = mysqli_connect('localhost', 'user', 'pass'); if ($conn) { echo 'Connected successfully'; };
- C. $conn = mysqli_connect('localhost', 'user', 'pass'); if (mysqli_connect_error()) { echo 'Connection failed'; }
- D. $conn = mysqli_connect('localhost', 'user', 'pass'); if (isset($conn)) { echo 'Connected successfully'; };

Correct Answer: A

Explanation: The first statement correctly establishes a connection to the database using mysqli_connect() and checks for a successful connection. If the connection fails, it uses mysqli_connect_error() to output a detailed error message, ensuring robust error handling in the application.

## Question 98. Which of the following SQL statements, when executed through PHP, correctly updates a user's email address in a database table named 'users', ensuring the email update is performed only for the user with specific user ID?

- A. UPDATE users SET email = 'new_email@example.com' WHERE user_id = 1;
- B. UPDATE users SET email WHERE user_id = 1 = 'new_email@example.com';
- C. UPDATE users SET email = 'new_email@example.com' WHERE user_id = 1;
- D. UPDATE users WHERE user_id = 1 SET email = 'new_email@example.com';

Correct Answer: A

Explanation: The correct SQL statement is UPDATE users SET email = 'new_email@example.com' WHERE user_id = 1. This query updates the 'email' column for the specific user identified by user_id = 1, ensuring that only the intended record is modified in the database.

## Question 99. In the context of PHP database integration, which of the following statements about using transactions is true, especially when executing multiple SQL queries that need to be treated as a single unit of work?

- A. Transactions automatically commit after each statement execution.
- B. Using transactions helps ensure data integrity by allowing rollback in case of errors.
- C. Transactions are only applicable in MySQL databases and not in others.
- D. Transactions cannot be used with prepared statements.

Correct Answer: B

Explanation: The statement that transactions help ensure data integrity by allowing rollback in case of errors is true. Transactions enable the execution of multiple SQL statements as a single unit, ensuring that all operations are successful; if any operation fails, all changes can be rolled back to maintain the database's integrity.

## Question 100. When using PHP to execute a database query that returns multiple rows, which of the following methods is appropriate to fetch all the resulting rows into an array for further processing?

- A. mysqli_fetch_array()
- B. mysqli_fetch_all()
- C. mysqli_fetch_assoc()
- D. mysqli_fetch_object()

Correct Answer: B

Explanation: The mysqli_fetch_all() function retrieves all result rows from a query as an array, which can then be easily processed or iterated over in PHP. This function is particularly useful when handling queries that return multiple rows, allowing developers to access all data in one operation efficiently.
