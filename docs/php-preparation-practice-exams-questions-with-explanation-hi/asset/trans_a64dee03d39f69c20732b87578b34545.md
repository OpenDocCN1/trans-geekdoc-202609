## 问题 62。在使用 PDO（PHP 数据对象）进行数据库集成时，与直接使用 MySQLi 扩展连接数据库相比，具有哪种优势？

- A. PDO 允许访问多种数据库类型。
- B. PDO 需要特定的 MySQL 版本。
- C. PDO 不支持预处理语句。
- D. PDO 无法处理事务。

正确答案：A
解析：PDO（PHP Data Objects）是一个访问层，提供了访问多种数据库（如 MySQL、PostgreSQL 和 SQLite）的统一方法。这种灵活性允许开发者编写与数据库无关的代码，使得在不大幅更改代码库的情况下更容易切换数据库类型。这是与仅限于 MySQL 数据库的 `mysqli` 相比的一个主要优势。

## 问题 63。在 PHP 中，使用 MySQL 扩展执行 SQL 查询时，必须使用哪个函数来准备待执行的语句，以有效防止 SQL 注入攻击？

- A. mysql_query()
- B. mysql_prepare()
- C. mysql_execute()
- D. mysql_bind_param()

正确答案：B

解析：`mysqli_prepare()` 函数用于准备待执行的 SQL 语句，该语句可以使用不同的参数执行多次，同时显著降低了 SQL 注入的风险。预处理语句将 SQL 逻辑与所发送的数据分离，确保了更好的安全实践。

- B. fetchAssoc()
- C. fetchOne()

## 问题 68。在 PHP 中，在对数据库执行多个 SQL 查询时使用事务的主要目的是什么？它如何增强数据一致性？

- A. 提高查询性能。
- B. 确保所有所有查询都作为一个工作单元执行。
- C. 自动创建数据库的备份。
- D. 简化 SQL 语法。

正确答案：B
解析：在 PHP 中执行多个 SQL 查询时使用事务的主要目的是确保所有查询都作为一个工作单元执行。这意味着如果其中一个查询失败，事务期间进行的所有其他更改都可以回滚，从而维护数据的一性和完整性。在需要多个操作共同成功或失败的场景下，事务是关重要的。
