Question 99. What is the correct way to define a static method in PHP, and how does it differ from instance methods, particularly in terms of how it is accessed and its relationship to object instantiation?

+   Static methods are defined using the static keyword and can be accessed without creating an instance of the class.

+   Static methods are defined using the public keyword and can only be accessed after an object has been instantiated.

+   Static methods in PHP cannot be defined; all methods must be accessed through an object.

+   Static methods are defined without any keyword and automatically accessible via the class name.

Correct Answer: A

Explanation: In PHP, static methods are defined using the static keyword and can be accessed directly using the class name, without the need for object instantiation. These methods are often used for utility functions or operations that do not depend on object properties.

+   The final keyword allows a class to be inherited, but its methods cannot be overridden.

+   The final keyword ensures that a method can be overridden in any child class.

+   The final keyword has no impact on inheritance or overriding in PHP.
