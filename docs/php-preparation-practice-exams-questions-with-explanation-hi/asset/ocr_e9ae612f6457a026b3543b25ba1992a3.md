# Question 90. How does the final keyword affect class inheritance and method overriding in PHP, and what implications does it have for the design of extensible applications?

+   A. It allows a class to be extended by any other class.

+   B. It prevents the class from being instantiated.

+   C. It restricts a method from being overridden in derived classes.

+   D. It makes a method available only to the class in which it is declared.

Correct Answer: C

Explanation: The final keyword in PHP is used to indicate that a class or method cannot be extended or overridden, respectively. When applied to a class, it prevents other classes from inheriting from it, while applying it to a method restricts derived classes from overriding that method. This is useful for ensuring that certain behaviors remain consistent and unaltered across subclasses, thereby promoting a more controlled and stable application design.

# Question 91. In PHP, what are traits, and how do they enhance the reusability of code in classes, particularly in situations where multiple inheritance might be needed?

+   A. Traits are classes that can be instantiated multiple times.

+   B. Traits are similar to interfaces but can contain method implementations.

+   C. Traits allow for code reuse across multiple classes without inheritance.

+   D. Traits can only be used within a single class.

Correct Answer: C

Explanation: Traits in PHP provide a mechanism for code reuse across multiple classes without the need for traditional inheritance. They allow developers to include methods and properties in several classes, overcoming the limitations of single inheritance in PHP. This enhances flexibility and promotes the DRY (Don't Repeat Yourself) principle by enabling code sharing without creating complex inheritance hierarchies.
