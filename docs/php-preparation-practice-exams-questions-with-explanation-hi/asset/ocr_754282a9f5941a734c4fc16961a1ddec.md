# Question 98. What happens when an if-else structure checks a variable for a negative number and the variable holds a positive value?

+   A. It will print a positive message.

+   B. It will execute the negative block.

+   C. It will execute the else block.

+   D. No action will be taken.

Correct Answer: C

Explanation: When the if-else structure checks a variable with a positive value against a negative condition, the condition evaluates as false. Consequently, the else block executes, which typically handles the case of the variable being non-negative.

# Question 99. In a nested if-else structure that checks for an even number and then checks if that number is greater than 10, what would happen if the number is 4?

+   A. Even and greater than ten.

+   B. Even but not greater than ten.

+   C. Not even.

+   D. No conditions met.

Correct Answer: B

Explanation: The outer condition identifies the number as even, but the inner condition fails since 4 is not greater than 10. Therefore, the outcome is that it is "Even but not greater than ten".
