# Question 96. In PHP, what will happen if you attempt to call a function that has not been defined and you are running your script in a production environment without error reporting enabled?

+   A. The script will execute normally, and a default value will be returned.

+   B. A fatal error will occur, and the script will terminate without any output.

+   C. A warning will be issued, but the script will continue executing subsequent code.

+   D. The function call will be ignored, and the script will return NULL.

Correct Answer: B

Explanation: The correct answer is B, as calling an undefined function will result in a fatal error, which stops the execution of the script. If error reporting is disabled, no error message will be displayed, making it essential to ensure that all functions are properly defined before they are invoked.
