# **Question 66.** When integrating a PHP application with a database, what role does the try...catch block serve when working with PDO for error handling, particularly during database connections?

+   A. It automatically commits SQL transactions.

+   B. It prevents SQL syntax errors.

+   C. It handles exceptions and errors gracefully.

+   D. It optimizes query performance.

Correct Answer: C

Explanation: The try...catch block in PHP is essential for handling exceptions that may occur during database operations with PDO. By wrapping database connection and query execution code within a try block, any exceptions thrown can be caught and handled in the catch block, allowing developers to manage errors gracefully, provide user-friendly error messages, and maintain application stability.
