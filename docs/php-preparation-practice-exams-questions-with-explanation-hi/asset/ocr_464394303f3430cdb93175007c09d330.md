# Question 78. When working with transactions in PHP using MySQL, which sequence of commands must be executed to ensure that a set of operations completes entirely or rolls back to maintain data integrity in case of failure?

+   A. START TRANSACTION, COMMIT, ROLLBACK
B. BEGIN, COMMIT, ROLLBACK
C. BEGIN TRANSACTION, ROLLBACK, COMMIT
D. START TRANSACTION, ROLLBACK, COMMIT

Correct Answer: D

Explanation: The correct sequence is START TRANSACTION, followed by either COMMIT to save the changes or ROLLBACK to undo them if an error occurs. This sequence ensures data integrity by allowing developers to group multiple operations that must succeed or fail as a unit, preventing partial updates that could lead to inconsistencies.

# Question 79. In PHP, when handling errors during database operations, which approach is recommended to catch exceptions that may arise during PDO operations, providing a robust way to manage potential issues without crashing the application?

+   A. Ignoring errors to maintain performance.
B. Using a try-catch block to handle PDO exceptions.
C. Logging errors without user notification.
D. Always displaying error messages directly to the user.

Correct Answer: B

Explanation: Using a try-catch block to handle PDO exceptions is the recommended approach. This method allows developers to gracefully manage errors that may occur during database operations, ensuring that the application can respond appropriately without crashing. It also enables logging of errors or displaying user-friendly messages instead of exposing sensitive error details.
