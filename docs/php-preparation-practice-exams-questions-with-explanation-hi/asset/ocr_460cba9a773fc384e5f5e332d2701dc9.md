Question 42. When using PHP to execute a SQL query that retrieves data from a database, which function is utilized to fetch the resulting data as an associative array? This is particularly useful for developers who want to work with data in a key-value pair format, allowing for easier manipulation and access to the results.

+   A. mysqli_fetch_assoc()
B. mysqli_fetch_array()
C. mysqli_fetch_row()
D. mysqli_fetch_object()

Correct Answer: A

Explanation: The correct answer is A, mysqli_fetch_assoc(). This function fetches a result row as an associative array, where the keys are the column names. This allows developers to refer to the data using meaningful names rather than numeric indices, making the code more readable and easier to maintain.

Question 43. In the context of PHP and MySQL integration, which method is considered a secure way to prevent injection attacks when handling user input before executing an SQL query? This practice is crucial for maintaining the security and integrity of a web application, especially when user input is inserted in database queries.

+   A. htmlspecialchars()
B. mysqli_real_escape_string()
C. strip_tags()
D. json_encode()

Correct Answer: B

Explanation: The correct answer is B, mysqli_real_escape_string(). This function escapes special characters in a string for use in an SQL statement, thus preventing SQL injection attacks. By sanitizing user input, developers can ensure that malicious data cannot manipulate the structure of SQL queries, enhancing the overall security of the application.
