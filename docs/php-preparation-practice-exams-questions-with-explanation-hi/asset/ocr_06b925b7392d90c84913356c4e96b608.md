# **Question 24.** Which of the following PHP statements is used to check the data type of a variable, ensuring it is a boolean before executing a specific block of code?

A. if (is_bool($var)) { ... }

B. if (gettype($var)) == "boolean" { ... }

C. if ($var is boolean) { ... }

D. if (type($var) == "bool") { ... }

Correct Answer: A

Explanation: The function is_bool($var) checks if the variable $var is of the boolean data type and returns true or false accordingly. This is the most efficient way to verify the data type in this context. Option B is also valid but less efficient, while the other options are incorrect syntactically.

# **Question 25.** What is the output of the following PHP code snippet: echo 5 + "10"?;

A. 15

B. 510

C. Error

D. 5 + 10

Correct Answer: A

Explanation: In PHP, when you add an integer and a string that can be interpreted as a number, PHP performs type juggling. The string "10" is converted to the integer 10, and the result of 5 + 10 is 15. Therefore, the output is 15, and the other options are incorrect interpretations of the code's execution.
