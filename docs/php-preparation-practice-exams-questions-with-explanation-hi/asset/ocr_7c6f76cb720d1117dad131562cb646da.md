**Question 25.** In PHP, if an error occurs during the execution of the script, which function can be used to write a custom error message to a specified log file instead of displaying the error on the screen?

+   A. log_error()

+   B. write_error_log()

+   C. error_log()

+   D. save_error_log()

Correct Answer: C

Explanation: error_log() is used to send error messages to a log file, a system log, or even to an email address. It helps to log errors without displaying them to users, enhancing security and debugging capabilities.

**Question 26.** In PHP, which function is used to get the last error that occurred in the script, and what kind of information does it return when no error has occurred?

+   A. error_get_last(); returns an empty array.

+   B. error_get_last(); returns NULL.

+   C. get_last_error(); returns FALSE.

+   D. error_last(); returns TRUE.

Correct Answer: B

Explanation: error_get_last() retrieves information about the last error that occurred during the execution of the script. If no error has occurred, it returns NULL.
