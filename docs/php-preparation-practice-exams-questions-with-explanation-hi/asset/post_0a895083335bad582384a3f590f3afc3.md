
**Question 27.** In PHP, which of the following statements correctly demonstrates the use of an if-else construct to handle a situation where a variable named $age is checked to determine whether it represents an adult or a minor, thus effectively allowing decision-making based on conditional logic?

-   A. if ($age >= 18) { echo "Adult"; } else { echo "Minor"; }
-   B. if ($age < 18) { echo "Adult"; } else { echo "Minor"; }
-   C. if ($age == 18) { echo "Minor"; } else { echo "Adult"; }

Correct Answer: A

Option B incorrectly reverses the logic, while options C and D contain syntax errors or incorrect comparisons, making A the only valid solution.
