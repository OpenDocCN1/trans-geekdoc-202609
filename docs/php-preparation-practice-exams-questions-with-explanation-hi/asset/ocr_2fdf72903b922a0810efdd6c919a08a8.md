**Question 48.** In a nested control structure scenario in PHP, which of the following statements accurately describe the behavior and evaluation order of nested if-else statements when dealing with multiple conditions?

+   A. The outer if condition must be true for the inner if condition to be evaluated

+   B. The inner if condition is evaluated first, regardless of the outer condition

+   C. The execution will always proceed to the else block if the outer if condition is false

+   D. The inner and outer if conditions are evaluated independently and simultaneously

Correct Answer: A

Explanation: In nested if-else structures in PHP, the outer condition must evaluate to true for the inner condition to be checked. This means that the inner conditions are only reached if their parent outer conditions allow for that part of the code to execute, thus maintaining a structured flow of control.
