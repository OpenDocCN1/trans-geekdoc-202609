# Question 81. In PHP, how does the use of abstract classes differ from interfaces, particularly in terms of defining method implementations and enforcing class hierarchies?

+   A. Abstract classes cannot contain any abstract methods.

+   B. Interfaces can provide method implementations, while abstract classes cannot.

+   C. Abstract classes can have method implementations, while interfaces cannot enforce any.

+   D. Both serve the same purpose and can be used interchangeably.

Correct Answer: C

Explanation: Abstract classes in PHP can define both abstract methods (which must be implemented by subclasses) and concrete methods (with implementation). This allows them to provide shared functionality. In contrast, interfaces only define method signatures without any implementation, and classes that implement an interface must provide the method definitions, enforcing a clear contract.
