# Question 12. When declaring a variable in PHP, what is the proper syntax for initializing a string variable with the text "Hello, World!" and ensuring the use of double quotes?

+   A. string $greeting = "Hello, World!";
B. $greeting = 'Hello, World!';
C. $greeting = "Hello, World!"
D. $greeting = "Hello, World"

Correct Answer: C

Explanation: To initialize a string variable in PHP, you can use either single quotes or double quotes, but for this question, the correct syntax using double quotes is $greeting = "Hello, World!". This allows for variable interpolation, which single quotes do not support.

# Question 13. What is the correct way to create a floating-point number in PHP, and how can you assign it to a variable to ensure that it is accurately recognized as a float?

+   A. $myFloat = "3.14"
B. $myFloat = 3.14;
C. $myFloat = 3.14f;
D. $myFloat = float(3.14)

Correct Answer: B

Explanation: In PHP, to create a floating-point number, you can assign it directly without quotes. Thus, the correct way is $myFloat = 3.14; which is automatically recognized as a float type. Options A and C use incorrect syntax, and D is not valid in PHP.
