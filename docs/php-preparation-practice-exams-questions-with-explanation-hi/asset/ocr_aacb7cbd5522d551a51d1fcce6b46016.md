**Question 75.** When using the switch statement in PHP, what will happen if no case matches the value being evaluated and there is no default case provided?

+   A. The program will terminate.
B. An error will occur.
C. The switch statement will not execute any code.
D. The code following the switch statement will execute without interruption.

Correct Answer: C

Explanation: If none of the case statements match the expression in a switch statement, and there is no default case to handle unmatched cases, the entire switch block will effectively be ignored, meaning no code within it will be executed. This allows for a clean exit from the switch without affecting the execution flow of subsequent code.
