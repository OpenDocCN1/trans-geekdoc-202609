# **Question 76.** In PHP's OOP paradigm, what is the significance of using the __construct() method in a class, and how does it facilitate the creation of class instances, especially in terms of initialization of properties?

+   A. It allows the creation of static methods within the class.

+   B. It serves as a destructor for cleaning up resources.

+   C. It is a special method that is automatically invoked when an object is instantiated.

+   D. It is used to clone objects from an existing instance.

Correct Answer: C

Explanation: The __construct() method in PHP is automatically called when a new instance of a class is created. Its primary purpose is to initialize object properties and perform any setup tasks necessary for the object, ensuring that the object is in a valid state upon instantiation.

# **Question 77.** Which feature of Object-Oriented Programming in PHP allows a single interface to represent different underlying data types, enabling method overloading and simplifying the code for handling diverse object types?

+   A. Inheritance

+   B. Polymorphism

+   C. Encapsulation

+   D. Abstraction

Correct Answer: B

Explanation: Polymorphism is a fundamental feature of OOP that allows methods to perform differently based on the object type invoking them. This capability enables the same method to accept different data types and behaviors, thus simplifying code and enhancing its maintainability and flexibility.
