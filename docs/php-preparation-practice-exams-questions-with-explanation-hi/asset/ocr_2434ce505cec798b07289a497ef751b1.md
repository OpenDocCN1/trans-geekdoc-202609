# Question 96. When integrating PHP with a MySQL database, what is the purpose of the mysqli_real_escape_string() function, and how does it contribute to database security?

+   A. It converts special characters to HTML entities

+   B. It checks if a database connection is successful

+   C. It sanitizes user inputs by escaping special characters

+   D. It retrieves the number of affected rows from the last query

Correct Answer: C

Explanation: The mysqli_real_escape_string() function sanitizes user inputs by escaping special characters, such as quotes and backashes, which could otherwise interfere with SQL syntax. This is crucial in preventing SQL injection attacks when incorporating user inputs into SQL queries, enhancing the overall security of the application.
