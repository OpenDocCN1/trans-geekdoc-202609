**Question 27.** In PHP, which of the following statements correctly demonstrates the use of an if-else construct to handle a situation where a variable named $age is checked to determine whether it represents an adult or a minor, thus effectively allowing decision-making based on conditional logic?

+   A. if ($age >= 18) { echo "Adult"; } else { echo "Minor"; }

+   B. if ($age < 18) { echo "Adult"; } else { echo "Minor"; }

+   C. if ($age == 18) { echo "Minor"; } else { echo "Adult"; }

+   D. if ($age = 18) { echo "Minor"; } else { echo "Adult"; }

Correct Answer: A

Explanation: The correct syntax for using an if-else statement in PHP checks if the $age variable is greater than or equal to 18 to determine if the person is an adult. If this condition is true, it outputs "Adult"; otherwise, it outputs "Minor." Option B incorrectly reverses the logic, while options C and D contain syntax errors or incorrect comparisons, making A the only valid solution.

**Question 28.** When using a nested loop structure in PHP, which of the following scenarios best illustrates a practical application of this concept, specifically demonstrating the utility of an outer loop controlling an inner loop that performs an action for each iteration of the outer loop?

+   A. Printing a single row of stars

+   B. Displaying through a multi-dimensional array

+   C. Iterating through a single-dimensional array

+   D. Summing the values of a single array

Correct Answer: B

Explanation: A nested loop structure is particularly effective for generating a multiplication table, where the outer loop iterates through one dimension (the multiplier), and the inner loop iterates through the other dimension (the multiplicand). This arrangement allows each combination of values to be calculated and displayed, showcasing the power of nested loops in managing two-dimensional data representations or operations in PHP.
