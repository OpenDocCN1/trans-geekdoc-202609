Question 46. In PHP, which function would you use to raise a user-defined
error that can trigger an error handler?

+   A. error_log()

+   B. set_exception_handler()

+   C. trigger_error()

+   D. restore_exception_handler()

Correct Answer: C

Explanation: The trigger_error() function is used to create a user-defined
error, which can invoke an error handler if one has been set. This function
allows custom error messages and error levels to be specified.

Question 47. Which PHP function is used to log errors to a specific file or
to a system log?

+   A. log_error()

+   B. error_reporting()

+   C. error_log()

+   D. set_error_handler()

Correct Answer: C

Explanation: The error_log() function sends an error message to a specified
destination, such as a file or a system log. It helps in monitoring and
debugging issues in production environments by logging errors externally.
