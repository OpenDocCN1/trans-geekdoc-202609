# Question 40. In PHP, how can polymorphism be achieved through the use of method overriding, and why is it an essential feature of Object-Oriented Programming?

+   A. By allowing a class to inherit multiple behaviors from other classes

+   B. By enabling a subclass to provide a specific implementation of a method that is already defined in its parent class

+   C. By preventing subclasses from changing the method behavior of the parent class

+   D. By allowing classes to implement multiple interfaces simultaneously

Correct Answer: B

Explanation: Polymorphism in PHP allows subclasses to provide specific implementations of methods that are already defined in their parent classes through method overriding. This essential feature promotes code flexibility and reusability, as it enables the same method to behave differently based on the object's actual class, facilitating dynamic method resolution at runtime.
