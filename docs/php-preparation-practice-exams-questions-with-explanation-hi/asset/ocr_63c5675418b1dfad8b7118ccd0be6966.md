# Question 55. When utilizing inheritance in PHP, what is the significance of the parent keyword in a derived class method when you want to access a method from the base class, and how does it facilitate better code organization?

+   A. It prevents any access to the base class's properties.

+   B. It allows you to override the base class method without any functionality.

+   C. It enables calling the base class method from within a derived class.

+   D. It automatically creates a new base class.

Correct Answer: C

Explanation: The parent keyword in PHP is used within a derived class to call methods or access properties from its base class. This is particularly useful when you want to extend or modify the behavior of a base class method while still retaining the functionality of the original method. It promotes better code organization and reusability by allowing derived classes to build on extending functionality.

# Question 56. In PHP, what is the main advantage of using interfaces in Object-Oriented Programming, and how do they differ from abstract classes in terms of design and implementation?

+   A. Interfaces can contain code implementations for methods.

+   B. Abstract classes define multiple inheritance, while interfaces do not.

+   C. Interfaces define a contract that implementing classes must follow without providing method implementations.

+   D. Abstract classes cannot define constants, while interfaces can.

Correct Answer: C

Explanation: Interfaces in PHP provide a way to define a contract for classes that implement them, specifying methods that must be defined without providing the actual implementation. This promotes a consistent design across different classes. Unlike abstract classes, which can contain both abstract methods and concrete implementations, interfaces strictly focus on method signatures, making them a powerful tool for enforcing consistent behavior across disparate class hierarchies.
