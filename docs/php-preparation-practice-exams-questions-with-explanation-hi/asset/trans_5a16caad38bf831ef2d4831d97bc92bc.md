## 问题 10. PHP 中 `clone` 关键字的目的是什么？特别是与对象克隆相关的，它如何在保留对象属性和状态的同时创建对象副本的？克隆在处理 PHP 引用方面有何影响？

- A. 它允许基于现有类创建新类。
- B. 它创建对象的副本，并允许在不影响原始对象的情况下进行更改。
- C. 它通过对原始对象创建引用来防止原始对象的更改。
- D. 它用于终止对象的执行。

正确答案：B

解析：PHP 中的 `clone` 关键字用于创建对象的副本，保留其当前状态和属性。当对象被克隆时，新实例可以独立于原始对象进行修改。然而，如果对象包含指向其他对象的引用属性，那么这些引用也会被复制，除非经过显式处理，否则这些被引用的对象将产生共享状态。

- B. 它限制了对对象某些组件的直接访问。
- C. 它促进了 PHP 中的多继承。
- D. 它主要用于函数重载。

正确答案：B

解析：封装是 OOP 的一项基本原则，它限制了对对象某些组件的直接访问，从而保护了对象数据的完整性。通过使用 public、private 和 protected 等访问修饰符，PHP 允许开发者暴露某些方法的同时隐藏其他方法。这种方法增强了数据抽象，并保护了对象的内部状态免受意外干扰。

## 问题 13. PHP 中的继承如何增强可复用性？它提供了哪些机制让子类从父类继承属性和方法，从而能够允许方法重写和多态的层次级类结构？

- C. 它只能继承基类的公共属性。
- D. 它仅限于单层级继承。

正确答案：A

解析：继承是 PHP OOP 中的一项关键特性，它通过允许类（子类）从另一个类（父类）继承属性和方法来增强代码的可复用性。这种机制能够创建层次结构结构，促进了方法重写，即子类可以为其父类中定义的方法提供特定的实现。这支持了多态，允许不同子类的对象被视为父类对象。
