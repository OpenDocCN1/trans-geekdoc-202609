# **Question 61.** In PHP, when utilizing traits, what is the primary advantage of using them over traditional class inheritance, and how do they enhance code reusability and organization?

+   - Traits allow defining properties but not methods.

+   - Traits cannot be reused across multiple classes.

+   - Traits enable code reuse without the limitations of single inheritance.

+   - Traits enforce strict method signatures in classes.

Correct Answer: C

Explanation: Traits in PHP are a mechanism for code reuse that allows developers to include shared methods across multiple classes without the constraints of single inheritance. This flexibility enables classes to incorporate functionalities from several traits, thereby enhancing code organization and reducing duplication. Traits are particularly useful in scenarios where multiple classes need to share common methods but do not share a parent-child relationship.
