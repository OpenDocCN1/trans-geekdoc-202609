# **Question 37.** When integrating a PHP application with a relational database, what is the significance of normalizing the database schema, and how does it impact data integrity and redundancy?

+   A. It increases redundancy and complexity in data retrieval processes.

+   B. It ensures that data is stored in a structured manner, reducing redundancy and improving data integrity through the use of foreign keys.

+   C. It enables faster execution of SQL queries by duplicating data across tables.

+   D. It simplifies database backups and restores processes significantly.

Correct Answer: B

Explanation: Normalizing the database schema is a critical process that organizes data into tables to minimize redundancy and dependency. By structuring data properly, it ensures data integrity through relationships and foreign keys, which helps maintain consistent and accurate data across the application.
