**Question 31.** In the context of PHP control structures, which of the following is the correct way to use the break statement within a loop, ensuring the loop terminates immediately when a certain condition is met, effectively demonstrating the control of loop execution?

+   A. for ($i = 0; $i < 10; $i++) { if ($i == 5) break; echo $i; }
B. while ($i < 10) { if ($i == 5) break; echo $i; $i++; }
C. foreach ($arr as $value) { if ($value == 0) break; echo $value; }
D. All of the above

Correct Answer: D

Explanation: All the provided options correctly demonstrate the use of break statement in different loop contexts. The break statement is used to exit a loop when a specific condition is met, which is accurately represented in the for, while, and foreach loop examples. This versatility makes the break statement an essential tool for controlling loop execution in PHP effectively.

**Question 32.** In PHP, what is the primary difference between using a for loop and a foreach loop when iterating through an array, specifically focusing on the aspects of simplicity and the handling of array elements during the iteration process?

+   A. A for loop requires manual index management; foreach automatically handles keys/values.
B. A foreach loop can only iterate through associative arrays, while for can iterate through indexed arrays.
C. A for loop executes fewer times than a foreach loop.
D. A for loop requires the array size to be known beforehand.

Correct Answer: A

Explanation: The primary difference between the for loop and foreach loop in PHP lies in their approach to iteration. The for loop necessitates manual index management and is more verbose, while the foreach loop simplifies the process by automatically handling both keys and values in an array. This makes foreach particularly convenient for traversing arrays without the risk of index errors and enhances code clarity.
