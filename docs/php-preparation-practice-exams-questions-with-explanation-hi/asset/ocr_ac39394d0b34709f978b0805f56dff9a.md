# Question 50. What is the correct way to declare a variable in PHP?

+   A. var $variable_name;

+   D. declare variable_name = value;

Correct Answer: B

# Question 51. Which of the following is NOT a valid data type in PHP?

+   A. String

+   B. Integer

+   C. Character

+   D. Array

Correct Answer: C

Explanation: PHP does not have a separate data type for characters; instead, it uses strings to represent single characters. Strings can contain one or more characters, so option C is correct as it is not a recognized data type in PHP.
