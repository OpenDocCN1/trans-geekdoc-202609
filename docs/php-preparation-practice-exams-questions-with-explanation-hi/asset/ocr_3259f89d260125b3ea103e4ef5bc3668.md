# **Question 60.** In PHP, if you want to write a custom error handler that deals with user-generated errors (e.g., using trigger_error()), which error type would you use?

+   A. E_USER_ERROR

+   B. E_WARNING

+   C. E_PARSE

+   D. E_COMPILE_ERROR

Correct Answer: A

Explanation: E_USER_ERROR is used for user-generated errors in PHP, often triggered by trigger_error(). This allows developers to manually raise errors that should be handled in the same way as system-generated fatal errors.
