# **Question 20.** Which statement best explains the difference between the === operator and the == operator in PHP, particularly in the context of type comparison?

+   A. === checks for value equality, while == checks for type equality.

+   B. === checks for both value and type equality, while == checks only for value equality.

+   C. === checks for type equality, while == checks for value equality and type conversion.

+   D. Both === and == perform the same type of comparison.

Correct Answer: B

Explanation: The === operator in PHP checks for both value and type equality, meaning that the variables must be equal in both value and type. In contrast, the == operator checks only for value equality, performing type conversion if necessary. This makes === a stricter comparison than ==.
