# 问题 10。在 PHP 应用中执行数据库迁移时，以下哪种实践最建议，以确保迁移过程的完整性和顺利执行，特别是在生产环境中？

-   A. 在进行任何更改之前备份数据库并记录所有的迁移步骤。
-   B. 在使用高峰期执行迁移以尽量地减少停机时间。
-   C. 编写严重依赖人工干预调整数据的迁移脚本。
-   D. 忽略迁移脚本的版本控制，因为如果需要，可以重新生成。

正确答案：A

解释：在进行任何更改之前备份数据库对于数据完整性和灾难恢复至关重要。记录迁移步骤确保了过程的可重复和可追溯性，这对于维护稳定的生产环境至关重要，可以防止数据丢失并在迁移过程中发生错误时允许快速恢复。

# 问题 11。以下哪个 PHP 函数用于使用 mysqli 扩展建立到 MySQL 数据库的连接，函数成功执行所需的参数是什么？

-   A. connect_to_db($host, $username, $password)
-   B. mysqli_connect($host, $username, $password, $database)
-   C. db_connect($host, $user, $pass)
-   D. mysql_connect($host, $user, $pass, $dbname)

正确答案：B

解释：使用 mysqli 扩展建立 MySQL 数据库连接的正确函数是 `mysqli_connect()`，它需要四个参数：主机、用户名、密码和数据库名。该函数在成功时返回一个连接对象，可用于进一步的数据库操作。使用 `mysql_connect()` 是过时的，因为它已经被 mysqli 和 PDO 取代。

# 问题 12。在 PHP 和数据库集成的范围内，预处理语句（prepared statements）的目的是？它们是如何增强数据库操作安全性的？

-   A.它们被用于在 PHP 中格式化 SQL 查询。
-   B.它们通过将 SQL 逻辑与数据分离来防止 SQL 注入攻击。
-   它们通过缓存结果来优化查询执行。
-   D它们允许在 MySQL 数据库中动态创建表。

正确答案：B

解释：预处理语句是一种通过分离 SQL 代码与处理的数据来增强安全的功能。这种分离有助于防止 SQL 注入攻击，恶意输入可能会操控查询。通过绑定参数，预处理语句确保输入被视为数据而非可执行代码，从而显著提高了安全性。

# 问题 13。在集成 PHP 与数据库时，在执行 SELECT 查询后，通常使用以下哪种方法从 MySQL 数据库检索数据？

-   A. mysqli_fetch_array()
-   B. mysqli_query()
-   C. mysqli_connect()
-   D. mysqli_execute()

正确答案：A

解释：`mysqli_fetch_array()` 函数用于在使用 `mysqli_query()` 执行 SELECT 查询后，将结果行作为关联数组、数字数组或两种类型的数组获取。该函数从结果集中检索数据并允许轻松访问返回的记录。其他选项没有直接用于从结果集中检索数据。

# 问题 14。在 PHP 中，连接数据库时使用 PDO（PHP Data Objects）扩展相比 MySQLi 的主要优势是什么，特别是在数据库抽象方面？

-   A.PDO 仅支持 MySQL 数据库。
-   B.PDO 允许以极少的代码更改在不同数据库类型之间切换。
-   C.PDO 在执行复杂查询方面效率更高。
-   D.PDO 不支持预处理语句。

正确答案：B

解释：PDO 的主要优势是它支持多个数据库管理系统（DBMS），允许开发者以极少的代码更改在 MySQL、PostgreSQL、SQLite 等数据库之间切换。这种灵活性使得 PDO 成为可能随时间需要连接到不同数据库的应用程序的首选。其他选项误导了 PDO 的功能。

# 问题 15。在 PHP 应用中，使用哪个函数转义字符串中的特殊字符用于 SQL 语句，帮助防止 SQL 注入漏洞？

-   A. mysqli_real_escape_string()
-   B. htmlspecialchars()
-   C. strip_tags()
-   D. addslashes()

正确答案：A

解释：`mysqli_real_escape_string()` 函数专门设计用于转义用于 SQL 语句的字符串中的特殊字符。对于防止 SQL 注入攻击至关重要，因为它确保任何潜在的有害输入在包含查询之前经过清理。虽然 `addslashes()` 也可以转义字符，但在 MySQL 语境下不如 `mysqli_real_escape_string()` 安全。

# 问题 16。事务（transactions）在 PHP 数据库集成中的作用是什么？在执行多个相关的 SQL 操作时如何有效地管理它们？

-   A.事务确保所有 SQL 操作都在单个语句中执行。
-   B.事务允许在其中一个失败时对多个 SQL 操作进行回滚。
-   C.事务自动提交更改。
-   D.PHP 不支持事务。

正确答案：B

解释：PHP 数据库集成中的事务用于将多个相关的 SQL 操作作为一个单元进行管理。如果其中一个失败，整个事务可以回滚。这对于需要原子性（全成功或全失败）的应用程序至关重要。

# 问题 17。以下哪种 SQL 语句可以使用 PHP 向数据库表插入新记录，其正确的语法是什么？

-   A.INSERT INTO table_name VALUES (value1, value2);
-   B.INSERT table_name (value1, value2);
-   C.INSERT INTO table_name (column1, column2) VALUES (value1, value2);
-   D.ADD table_name (value1, value2);

正确答案：C

解释：向数据库表插入新记录的正确 SQL 语法是 `INSERT INTO table_name (column1, column2) VALUES (value1, value2)`。该语句指定了要插入数据的表和列。选项 A 和 B 不包含所需的语法。

# 问题 18。在 PHP 中使用 mysqli 时，mysqli_close() 函数的作用？为什么在数据库操作完成后调用此函数很重要？

-   A.将数据库重置为原始状态。
-   B.永久删除数据库。
-   C.关闭数据库连接并释放资源。
-   D.创建一个新的数据库连接。

正确答案：C

解释：`mysqli_close()` 函数用于关闭之前打开的数据库连接，这对于释放不再需要的系统资源很重要。正确关闭连接有助于维护性能并避免潜在的内存泄漏，特别是在处理大量数据库交互的应用程序中。不关闭连接会导致资源长时间耗尽。
