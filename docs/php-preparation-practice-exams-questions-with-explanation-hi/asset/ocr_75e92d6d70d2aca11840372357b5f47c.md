# Question 96. Which of the following accurately describes how PHP handles overriding, when a subclass provides its own implementation of a method that already exists in the parent class, while maintaining compatibility with the OOP principle of inheritance?

+   A. PHP does not support method overriding.
B. PHP allows method overriding but requires the use of the override keyword in the child class.
C. PHP allows a child class to override a parent class method by defining a method with the same name and arguments in the child class, without any special keywords.
D. PHP allows overriding only for private methods.

Correct Answer: C

Explanation: PHP supports method overriding, allowing a child class to provide its own implementation of a parent class method simply by defining a method with the same name and parameters. No special keyword override is needed. This feature is part of how inheritance and polymorphism work in PHP.
