Question 9. When implementing a switch statement in PHP, which of the following is true regarding the case statements, especially when multiple cases should lead to the same block of code being executed?

+   A. Each case must have a unique statement.
B. Multiple cases can share the same code block if they are listed consecutively without a break.
C. Each case must be terminated with a semicolon.
D. A default case must always be included.

Correct Answer: B

Explanation: In PHP, multiple case labels can lead to the same block of code by stacking one after the other without an intervening break. This allows for handling multiple values in the same manner, improving code efficiency and readability.

Question 10. Which of the following PHP control structures is specifically designed to iterate over each element of an array or object, automatically handling the key-value pairs without requiring a separate index variable?

+   A. for
B. foreach
C. while
D. do-while

Correct Answer: B

Explanation: The foreach construct in PHP is tailor-made for iterating over arrays and objects. It simplifies accessing each element and its corresponding key without the need for additional counters or index management, making it particularly useful for array manipulation.
