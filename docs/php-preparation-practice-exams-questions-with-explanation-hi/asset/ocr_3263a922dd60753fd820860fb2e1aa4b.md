# Question 76. In a scenario where you need to insert a new record into a MySQL database using PHP, which SQL command format is recommended to ensure that the input values are secure bound and the risk of SQL injection is minimized?

+   A. INSERT INTO table (column1, column2) VALUES (value1, value2)
B. INSERT INTO table SET column1 = value1, column2 = value2
C. INSERT INTO table (column1, column2) VALUES (?, ?, ?)
D. INSERT INTO table (column1, column2) SELECT value1, value2

Correct Answer: C

Explanation: The recommended SQL command format is INSERT INTO table (column1, column2) VALUES (?, ?). This uses placeholders for the binding of values in a prepared statement, effectively mitigating SQL injection risks. It provides a secure way to handle user inputs while executing database commands.

# Question 77. Which function in PHP is used to retrieve the last inserted ID after performing an INSERT operation on a MySQL database, allowing developers to maintain a reference to the new record for subsequent operations?

+   A. mysqli_last_insert_id()
B. last_insert()
C. get_last_id()
D. mysqli_insert_id()

Correct Answer: D

Explanation: The mysqli_insert_id() function returns the ID generated by an AUTO_INCREMENT column by the last INSERT query executed on the database connection. This function is crucial for scenarios where you need to reference the newly created record, such as when inserting related records into other tables.
