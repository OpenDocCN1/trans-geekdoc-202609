Question 81. Which of the following represents a key characteristic of the continue statement in PHP when used within looping constructs?

A. It terminates the entire loop and moves to the next line of code.

B. It skips the remaining code in the current iteration and proceeds with the next iteration.

C. It is used to exit a function prematurely.

D. It is only applicable for loops.

Correct Answer: B

Explanation: The continue statement in PHP is specifically designed to skip the remainder of the current loop iteration and continue with the next iteration. This is useful when a specific condition is met, and you want to avoid executing certain parts of the loop while still processing further iterations.

Question 82. When would it be appropriate to use an if...else statement in PHP, and what distinguishes it from a switch statement?

A. Use if...else for a single condition check and switch for multiple unrelated conditions.

B. Use if...else for complex logical conditions and switch for simple variable comparisons.

C. if...else can only handle numeric comparisons, while switch handles strings.

D. if...else is always more efficient than switch for all conditions.

Correct Answer: B

Explanation: The if...else statement is ideal for handling complex logical conditions, especially when the conditions involve multiple variables or require logical operators. In contrast, the switch statement is best suited for simpler, discrete value comparisons against a single expression. This distinction helps determine the most efficient structure based on the problem at hand.
