# Question 87. Which of the following best describes polymorphism in the context of Object-Oriented Programming in PHP, and how does it enhance the flexibility of the code, particularly when dealing with different class types?

A. It restricts the use of inheritance to a single base class.

B. It allows different classes to be treated as instances of the same class through a common interface.

C. It mandates that all methods must be overridden in derived classes.

D. It enforces type safety by preventing any type of object from being assigned to a variable.

Correct Answer: B

Explanation: Polymorphism in OOP allows objects of different classes to be treated as objects of a common superclass or interface. This enhances code flexibility, as it enables the use of generic algorithms and functions that operate on different class types without needing to know their specific implementations. This makes the code more extensible and easier to maintain.
