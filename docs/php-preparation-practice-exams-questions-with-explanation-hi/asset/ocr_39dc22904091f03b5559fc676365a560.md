**Question 12.** In the context of PHP, which of the following control structures are typically preferred when the number of iterations is predetermined and is especially useful for processing a specific range of values?

B. for
C. if

Correct Answer: B

**Question 13.** What is the main purpose of using the continue statement within a loop in PHP?

+   A. To terminate the loop entirely
B. To skip the rest of the current iteration and continue with the next iteration
C. To exit the current function and return to the caller
D. To pause the execution of the loop

Correct Answer: B

Explanation: The continue statement is used to skip the remaining code in the current iteration of a loop and immediately proceed to the next iteration.
