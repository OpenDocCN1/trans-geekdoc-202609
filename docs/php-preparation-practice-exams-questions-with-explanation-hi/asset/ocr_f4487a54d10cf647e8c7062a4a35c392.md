**Question 53.** Which of the following concepts is not one of the four fundamental principles of Object-Oriented Programming (OOP) that is commonly used in PHP to improve code reusability, maintainability, and organization?

+   A. Encapsulation
B. Inheritance
C. Polymorphism
D. Compilation

Correct Answer: D

Explanation: The Compilation is not a fundamental principle of OOP. The four main principles of OOP are encapsulation, inheritance, polymorphism, and abstraction. Encapsulation refers to restricting access to certain components of an object, inheritance allows a class to inherit properties and methods from another class, and polymorphism enables methods to do different things based on the object it is acting upon.

**Question 54.** In PHP, what is the primary purpose of the `__construct()` method when defining a class, and how does it enhance the functionality of the objects instantiated from that class?

+   A. It acts as a destructor for the class instance.
B. It initializes properties of the class when an object is created.
C. It is used to define the class methods.
D. It defines constants for the class.

Correct Answer: B

Explanation: The `__construct()` method in PHP serves as a constructor, which is automatically called when an object of the class is instantiated. This method is primarily used to initialize the class properties and to set up any necessary resources for the object. By using the constructor, developers can ensure that objects are in a valid state immediately upon creation.
