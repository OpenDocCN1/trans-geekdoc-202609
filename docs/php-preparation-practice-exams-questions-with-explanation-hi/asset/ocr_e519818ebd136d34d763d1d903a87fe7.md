**Question 97.** What will be the output of the following PHP code snippet: echo (10 == "10") ? 'True' : 'False', and how does this demonstrate PHP's approach to type comparison?

+   A. True

+   B. False

+   C. 10

+   D. 10 days

Correct Answer: A

Explanation: The code uses the equality operator ==, which checks for value equality while ignoring type differences. In this case, "10" (a string) is compared with 10 (an integer), and since they hold the same value, the output will be 'True'. This behavior illustrates PHP's type juggling mechanism, where it automatically converts types during comparison.

**Question 98.** In PHP, how can you explicitly convert a string to an integer, and which of the following methods would correctly perform this conversion while avoiding potential issues with type coercion?

+   A. (int)$string;

+   B. intval($string);

+   C. $string = (integer)$string;

+   D. All of the above

Correct Answer: D

Explanation: All provided options are valid methods to explicitly convert a string to an integer in PHP. (int)$string and intval($string) directly convert the string to an integer type, while $string = (integer)$string; performs the conversion and reassigns the result back to the variable. Using these methods help prevent unexpected behavior during arithmetic operations due to automatic type coercion.
