## 问题 53。在 PHP 中处理数据库事务时，以下哪种陈述准确地描述了 commit（提交）和 rollback（回滚）操作在维护数据完整性方面的重要性，特别是在需要多个相关数据库操作作为一个单元整体成功或失败的应用中？

- A. Commit 用于撤销更改，而 rollback 保存更改。
- B. Rollback 用于撤销更改，而 commit 永久保存更改。
- C. 对于数据完整性而言，commit 和 rollback 都是可选的。
- D. Commit 和 rollback 仅用于读取操作。

正确答案：B

解析：在数据库事务中，commit 操作将事务期间的所有更改永久地保存到数据库中，而 rollback 操作在发生错误时撤销所有更改，确保数据库保持一致状态。这种机制对于需要多个相关操作要么全部成功要么全部失败而不留部分更新的应用至关重要。

## 问题 54。在 PHP 中，利用哪个函数准备用于执行的 SQL 语句，通过允许开发者在执行前向查询绑定参数，帮助缓解与 SQL 注入相关的安全风险？

- A. mysqli_query()
- B. mysqli_prepare()
- C. mysqli_bind()
- D. pdo_prepare()

正确答案：B

解析：`mysqli_prepare()` 函数为执行准备 SQL 语句，这有助于保护应用程序免受 SQL 注入攻击。通过使用此函数，开发者可以创建参数化查询，安全地绑定输入参数并安全地执行语句，使其成为在 PHP 中编写安全数据库交互至关重要的函数。

问题 55。以下哪一个扩展提供了与数据库交互的面向对象接口，提供了预语句、事务和多数据库支持等功能，从而允许开发者编写更具维护性和多功能性的数据库代码？

- A. MySQL
- B. PDO
- C. ODBC
- D. SQLite

正确答案：B

解析：PDO（PHP Data Objects）是一个提供访问不同数据库系统的统一接口的扩展。它支持预语句、事务和多种数据库类型（MySQL, PostgreSQL, SQLite 等）等功能，极具灵活性。这种灵活性允许开发者编写更具维护性的代码，并在不同的数据库之间轻松切换。

问题 56。当从 PHP 应用查询 MySQL 数据库时，使用索引的主要目的是什么，特别是在优化数据库操作（如 SELECT 语句）的性能方面，以便缩短用户的响应时间？

- A. 增加存储空间。
- B. 提高数据完整性。
- C. 加快数据检索。
- D. 简化 SQL 查询。

正确答案：C

解析：索引是特殊的数据结构，可以提高数据库表上数据检索操作的速度。通过在 WHERE 子句或 JOIN 条件中频繁使用的列上创建索引，数据库引擎可以更快速地定位并访问数据，显著缩短通过 PHP 应用查询数据的用户响应时间。

## 问题 57。在 PHP 应用中，你会使用哪条 SQL 语句来更新 MySQL 数据库表中的现有记录，确保更改仅应用于由唯一标识符指定的特定行，从而维护数据准确性并防止意外修改？

- A. INSERT INTO table_name SET column1 = value1 WHERE condition;
- B. UPDATE table_name SET column1 = value1 WHERE condition;
- C. DELETE FROM table_name WHERE condition;
- D. SELECT * FROM table_name WHERE condition;

正确答案：B

解析：UPDATE 语句用于修改表中的现有记录。通过指定表名、要更新的列以及识别特定记录的条件（通常使用唯一标识符），该语句确保了只有预期的记录被更改，从而维护了数据的准确性和完整性。

## 问题 58。在 PHP 应用中，处理数据库交互时，数据访问对象（DAO）模式的主要作用是什么，特别是在促进数据库操作的结构化方法以及增强代码的可维护性和扩展性方面？

- A. 它直接执行 SQL 查询，不进行抽象。
- B. 它充当应用程序和数据库之间的中间件，封装数据访问。
- C. 它消除了使用 SQL 查询的需要。
- D. 它允许同时进行数据库连接。

正确答案：B

解析：数据访问对象（DAO）模式充当应用程序与数据库之间的中间层，封装了所有数据访问逻辑。这促进了数据库交互的结构化方法，通过将业务逻辑与数据访问分离增强了代码的可维护性和扩展性。

## 问题 59。在集成 PHP 应用和 MySQL 数据库时，以下哪些技术对于确保敏感信息（如密码）安全存储至关重要，特别是在保护用户数据不受未经授权访问和潜在破解方面？

- A. 明文存储密码。
- B. 使用 bcrypt 等哈希算法。
- C. 使用对称加密密码。
- D. 在网络上明文发送密码。

正确答案：B

解析：安全存储密码对于保护用户数据至关重要。使用像 bcrypt 这样包含唯一盐且计算密集型的哈希算法，可以确保即使数据库被破解，实际密码也是安全的。这种方法防止了未经授权的访问并缓解了与密码破解相关的风险。
