# Question 72. In PHP, when integrating with a database, which of the following best practices should be followed to prevent SQL injection attacks, ensuring that user input is sanitized and the database remains secure from malicious queries?

+   A. Using addslashes() on user input.

+   B. Directly embedding user input in SQL queries.

+   C. Employing prepared statements with bound parameters.

+   D. Relying solely on user input validation.

Correct Answer: C

Explanation: Prepared statements with bound parameters are a secure method for handling user input in SQL queries. This technique ensures that the input is treated as data rather than executable code, significantly reducing the risk of SQL injection attacks. Unlike functions like addslashes(), which only partially protects against injections, prepared statements provide a robust security layer.
