## Question 4. What role does the break statement play within control structures in PHP, especially in switch cases or loops, and how can its usage impact the flow of execution in a script when combined with nested control structures?

A. It terminates the current loop or switch statement, preventing any further code execution in that structure.

B. It allows for the continuation of the next iteration in a loop without exiting the loop entirely.

C. It is used to define a new control structure, enhancing the readability of the code.

D. It pauses the execution of the script until a specified condition is met.

Correct Answer: A

Explanation: The break statement in PHP is used to terminate the current loop or switch case, effectively preventing any subsequent code within that structure from executing. This is particularly important in nested control structures, as it helps to manage the flow of execution and prevent unintended behaviors, ensuring that the program logic remains clear and effective.

## Question 5. How does the continue statement function within looping structures in PHP, and in what specific situations might be used to skip the current iteration while continuing with the next one, particularly when filtering data within a collection?

- A. It breaks the entire loop, preventing any further iterations from occurring.
- B. It skips the remaining code in the current iteration of the loop and proceeds to the next iteration.
- C. It reinitializes the loop's control variable, allowing for a new execution context.
- D. It terminates the script entirely, indicating a critical error in the program.

Correct Answer: B

Explanation: The continue statement in PHP is designed to skip the remaining code in the current iteration of a loop and continue with the next iteration. This is especially useful when filtering data, allowing the loop to bypass certain entries without breaking the loop entirely. For instance, if you only want to process valid entries in an array, using continue can skip over invalid entries efficiently.

## Question 6. In PHP, which of the following constructs allows you to execute a block of code multiple times, depending on a specified condition, and is often used when the number of iterations is known beforehand?

- A. while
- B. for
- C. do-while
- D. foreach

Correct Answer: B

Explanation: The for loop in PHP is specifically designed for situations where the number of iterations is known in advance. It consists of three parts: initialization, condition, and increment/decrement, which together determine how long the loop will run. This makes it an excellent choice for iterating over arrays or when you need to execute code a specific number of times.

## Question 7. In PHP, which of the following statements is used to terminate a switch statement or exit a loop early, effectively skipping the remaining code execution in the current control structure?

- A. exit
- B. break
- C. continue
- D. return

Correct Answer: B

Explanation: The break statement in PHP is used to exit a control structure, such as a switch or a loop. When break is executed, the program flow continues with the next statement following the control structure, making it useful for skipping to the end of a block when a specific condition is met.

## Question 8. Which control structure in PHP can be used to repeatedly execute a block of code as long as a specified condition evaluates to true, and it checks this condition before each iteration?

- A. for
- B. foreach
- C. while
- D. do-while

Correct Answer: C

Explanation: The while loop checks the specified condition before each iteration. If the condition is true, the code block within the loop executes. This structure is ideal for scenarios where the number of iterations isn't known beforehand, and the loop should continue until the condition becomes false.
