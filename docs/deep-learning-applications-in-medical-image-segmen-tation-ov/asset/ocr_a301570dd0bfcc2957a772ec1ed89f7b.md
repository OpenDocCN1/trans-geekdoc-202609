# Table 11.5 Explainable AI techniques for deep learning models.

| Technique | Description | Advantages | Disadvantages |
| :--- | :--- | :--- | :--- |
| Local Interpretable Model-Agnostic Explanations (LIME) | Explains individual predictions of any black-box model by learning an interpretable model locally around the prediction. | * Model-agnostic: works with any machine learning model.
* Generates explanations for individual predictions. | * Can be computationally expensive for complex models.
* Local explanations might not generalize well to other data points. |
| SHapley Additive exPlanations (SHAP) | Explains how each feature contributes to a specific prediction by distributing the prediction credit among all features. | * Provides insights into feature importance.
* Offers different explanation modes (summary, dependence plots). | * Can be computationally expensive for large datasets.
* Interpretation of SHAP values might require domain knowledge. |
| Feature importance techniques (permutation importance, feature ablation) | Ranks the features based on the drop in model performance when a feature is permuted or removed. | * Simple to implement and understand.
* Identifies the most important features of the model. | * Does not explain how features interact.
* Can be misleading for correlated features. |
| Partial dependence plots (PDP) | Visualizes the marginal effect of a single feature on the model's prediction, averaging over the other features. | * Easy to interpret visually.
* Shows how the model's prediction changes with a single feature. | * Can be cumbersome to generate for many features.
* Does not account for feature interactions. |
| Gradient-based techniques (Grad-CAM, integrated gradients) | Highlights image regions that contribute most to the model's prediction. | * Provides visual explanation for image classification models.
* Helps identify which parts of the image the model focuses on. | * Limited to image data.
* Interpretation might be subjective. |
