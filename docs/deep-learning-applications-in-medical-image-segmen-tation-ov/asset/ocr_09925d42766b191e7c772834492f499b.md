Specificity, also referred to as the true negative rate, measures the accuracy of true negatives (TN) relative to the total negative predictions (TN + FN [false negative]). A higher specificity value suggests a lower false positive rate. Recall, or sensitivity, evaluates the correctness of all relevant instances and ranges from 0 to 1, with higher values indicating fewer false negatives. It is computed by dividing true positives (TP) by the sum of false negatives (FN) and true positives (TP).
