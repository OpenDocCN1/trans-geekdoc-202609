# 1.4.5 F1 Score

This metric is necessary for evaluating the accuracy of a model. It combines precision and recall into a single measure using the harmonic mean. Instead of using a conventional average, the harmonic mean restricts extreme values. This measurement is useful for striking a balance between recall and precision. The score for these metrics ranges from 0 to 1, with 1 indicating the best performance and 0 indicating the worst. Models with an F1 score near one are regarded as ideal, as they have a low number of false positives and false negatives. This metric is applicable to both binary and multi-class classification and segmentation problems. Mathematically, the F1 score is stated as in Eq. (1.5).

```
F1_score = 2 × Recall × Precision / Recall + Precision (1.5)
```

# 1.4.6 Accuracy

Accuracy, also referred to as overall pixel accuracy, represents the percentage of image pixels that are correctly classified. While it is a fundamental performance metric, it has a restriction in representing segmentation performance when there is a class imbalance. When there is an imbalance between the segmentation classes, one class tends to dominate the others. There may be bias in the results if the accuracy of the dominant class is higher than that of the other class. Therefore, when there is no class imbalance in an image, accuracy should be used as a measure of segmentation performance. One alternative definition of accuracy is per-class accuracy, which averages the fraction of properly classified pixels across all classes. This statistic is especially helpful for images that have an imbalance in class. Both the average per-class accuracy and per-class accuracy should be taken into account in situations of class imbalance. However, the average per-class accuracy has a limitation in terms of reducing the confidence measurement of individual classes. Additionally, when there are fewer instances of a specific class, there may be a large variance that can affect the reliability of the results. Mathematically, accuracy is stated as in Eq. (1.6).

```
Accuracy = Accurately classified pixels / Total number of pixels present in the image = TP + TN / TP + TN + FP + FN (1.6)
```
