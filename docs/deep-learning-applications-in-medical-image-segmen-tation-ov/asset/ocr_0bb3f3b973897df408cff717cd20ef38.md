The corrected AIC metric is used in our work and simply denoted by AIC for convenience. In addition using equation 4.12,

```
BIC = n_d ln \frac{RSS}{n_d} + n_p ln(n_d) \tag{4.12}
```

Note that AIC and BIC have completely different frameworks with BIC housing a higher penalty term when n_d > e^2.

The optimal growth model is the one that achieves the lowest AIC and BIC metrics. For better analysis and interpretation of results, the Akaike and Bayesian weights are computed from the Akaike and Bayesian information criteria, respectively. For each model, the difference in AIC value is calculated as in equation 4.13:

```
Δ AIC_k = AIC_k - AIC_min, k = 1, 2 ... 12 \tag{4.13}
```

where AIC_min is the lowest AIC value of the twelve models. Further, the Akaike weights are represented as given in equation 4.14:

```
w_{AIC_k} = \frac{e^{-0.5 Δ AIC_k}}{\sum_{m=1}^{12} e^{-0.5 Δ AIC_m}} \tag{4.14}
```

Using these weights, the evidence ratio (ER) between models M_1 and M_2 is given by equation 4.15:

```
ER_{AIC} = \frac{w_{AIC_{M_1}}}{w_{AIC_{M_2}}} \tag{4.15}
```
