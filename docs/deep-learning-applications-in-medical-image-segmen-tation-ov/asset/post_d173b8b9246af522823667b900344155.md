### 11.3.1 Building Blocks for Medical Image Segmentation

After pre-processing of the medical images, the segmentation phase starts. All the individual images are divided into different sets of pixels by applying image segmentation algorithm. The image segmentation involves converting an image into a collection of pixels that are represented by a mask or a labeled image. By dividing an image into segments, one can process only the important segments of the image instead of processing the entire image. This chapter discusses various techniques for segmentation, such as Clustering which combines pixels that are related in some way, Region expanding expands regions until they reach a boundary, and thresholding used as an end-to-end solution for image segmentation. ### 11.3.1.1 Activation Functions

Activation functions add nonlinearity to the network, allowing it to learn complicated correlations between input and output data. Common activation functions utilized in CNNs are:

- Rectified linear unit (ReLU): This function is computationally efficient and avoids the vanishing gradient problem that can hinder training in deeper networks. The representation of the ReLU function is shown in below equation:

$f(x) = \max(0, x)$

where $f(x)$ is the computationally efficient set of functions that returns 0 if it receives any negative input otherwise it returns $x$.

- Sigmoid: The sigmoid function guarantees that the output of the neural network will always be 0 and 1. This function is applied to each layer of the neural network. A sigmoid function is a bounded, differentiable real function that defines all the real input values and has a non-negative derivative at each point. The sigmoid function is defined as the below equation:

$f(x) = \frac{1}{1 + e^{-x}}$

- Hyperbolic tangent (TanH): The TanH is a nonlinear activation function having a center at 0 and all the values range between -1 and 1. This activation function helps to de-center the hidden layers of neural networks because the mean of each TanH function is 0 or near 0.

$f(x) = \frac{\exp(x) - \exp(-x)}{\exp(x) + \exp(-x)}$

### 11.3.1.2 Loss Functions

Loss functions measure how well the predictions of the model deviate from the actual truth labels. Minimizing the loss function during training guides the network toward learning optimal parameters.

Common loss functions used in image segmentation include:

- Binary cross-entropy: Suitable for binary classification tasks (e.g. pixel-wise classification between background and foreground).

- Dice loss: Penalizes the model for both false positives (classifying background as foreground) and false negatives (classifying foreground as background).

### 11.3.2 Common Architectures

### 11.3.2.1 U-Net

U-Net is a fully convolutional network (FCN) developed exclusively for medical image segmentation. It uses an encoder-decoder architecture with skip connections.

### 11.3.2.2 Components

- Encoder: Extracts features from the input image through repeated convolutional and pooling operations.
- Decoder: Upsamples the extracted features and combines them with corresponding features from the encoder path (via skip connections) for precise localization.
- Skip connections: Connect corresponding encoder and decoder layers directly to preserve spatial information and aid in precise segmentation of small structures.

### 11.3.2.3 Convolutional Neural Networks (CNNs)

CNNs are a type of deep neural network design that work particularly well with image data. These are skilled in capturing spatial characteristics and relationships within an image. CNNs are a broad category of architectures that use convolutional layers to extract features from images. They can be utilized for a variety of segmentation tasks. A complete image processing is shown in Figure 11.2.

The key components are as follows (Gudhe et al. 2023):

- Input layer: Receives the pre-processed image data, typically a 3D tensor representing the image width, height, and color channels (e.g. RGB).

- Convolutional layer: Applies filters (kernels) that slide across the input, extracting local features like edges, shapes, and textures.

- Pooling layer: Downsampling the feature maps created by the convolutional layer reduces data size and processing expense while keeping critical information. Maximum and average pooling are two common pooling operations.

- Activation layer: This introduces non-linearity to the network, allowing it to learn complex patterns. Popular activation functions include ReLU and sigmoid.

- Fully connected layer: Flattens the output from the previous layers into a vector and performs traditional neural network operations for classification or regression tasks.

### 11.3.2.4 Fully Convolutional Network (FCN)

The FCNs are a type of CNN where all layers depend on convolutional function, which enables end-to-end segmentation. The end-to-end segmentation is a cluster of pixel-wise selection of images. The participating components of FCN are as follows:

- Encoder: Similar to a general CNN encoder, extracting features.
- Upsampling layers: Increase the feature map resolution to match the input image size.
- Output layer: Produces a probability map for each pixel belonging to a specific class.
