The enhanced medical images are fed into a deep learning model for semantic segmentation. Various models are available for analyzing medical images, one of which is the U-net model, a fully convolutional neural network. Its architecture is segmented into encoder and decoder paths. The encoder path captures contextual information (the content of the image), while the decoder portion preserves spatial features (the location of information within the image). The encoder component consists of a sequence of convolutional and max-pooling layers. A convolutional layer serves as a fundamental unit for processing image data and detecting patterns and spatial features in the input data. The convolutional operation involves sliding a small filter (kernel) over the input data, resulting in a dot product between the filter's weights and the values in the receptive field of the input domain. The inputs provided to the convolutional operation include a cell imaging sample of size (n x n x channels) and a set of filters, each with a size of (i x i x channels). The output of the convolution yields an image or feature map with a size of (n-out x n-out x k).
