Various upsampling techniques are available, such as bilinear interpolation, cubic interpolation, nearest neighbor interpolation, and transposed convolution. Most of these methods are based on interpolation, meaning the network does not learn on its own, and manual feature engineering is required. To achieve optimal upsampling, transposed convolution has been identified as the preferred method. Unlike other techniques, transposed convolution does not rely on preset conditions, and the network contains learnable parameters. Transposed convolution has been widely utilized in semantic segmentation to reconstruct the original sample size.
