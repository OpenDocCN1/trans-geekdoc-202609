Furthermore, researchers are exploring synergies between generative models and methods like transfer learning (Shorten and Khoshgoftaar 2019; Talo et al. 2019) or active learning (Ren et al. 2022; Rahimi et al. 2021) to enhance augmentation effectiveness. ## 1.4 Performance Metrics for Evaluating Segmentation Models

Performance metrics for the segmentation of medical images are used to evaluate the accuracy and quality of segmentation algorithms applied to medical imaging data. According to the system's functionality, a number of variables influence the choice of a suitable evaluation metric. In this section, we go through a few of the most popular performance indicators that may be used to assess how accurately the deep learning models segment images. Here TP, TN, FP, FN, and GT stand for true positive, true negative, false positive, false negative, and ground truth, respectively:

### 1.4.1 Dice Similarity Coefficient (DSC)

The DSC evaluates how much of the ground truth region overlaps with the segmented region. It is calculated as the ratio of twice the intersection of the segmented and ground truth regions to the sum of their sizes. A higher DSC value indicates better segmentation accuracy. The Dice coefficient can be mathematically stated as illustrated in Eq (1.1):

```
DSC = \left| \frac{2 \times S_{GT} \cap S_{Segmented}}{|S_{GT}| + |S_{Segmented}|} \right| = \frac{2 \times TP}{2TP + FP + FN} \quad (1.1)
```

When compared to overall pixel accuracy, the DSC is preferable since it accounts for false alarms and missed values within each class. It is preferable because it not only checks whether or not pixels have been correctly labeled but also checks whether or not segmentation boundaries have been correctly drawn. In addition, DSC is often used to evaluate the reliability of a network's performance through the implementation of cross-validation strategies.

### 1.4.2 Intersection over Union (IoU)

The IoU, which is also called the Jaccard Index (JI), measures how much the expected segmentation and the ground truth segmentation overlap by figuring out the ratio of the area where they overlap to the area where they join. JI shares similarities with the DSC since they exhibit a monotonic or positive correlation, as demonstrated by the following Eq. (1.2).

```
JI = \frac{S_{GT} \cap S_{Segmented}}{S_{GT} \cup S_{Segmented}} = \frac{TP}{TP + FP + FN} (1.2)
```

### 1.4.3 Precision

Precision, also known as true predictive assessment, is calculated as the ratio of true positives to the combined total of false positives and true positives. True positive refers to the correct identification of instances from the positive class, while false positive represents instances incorrectly predicted from the positive class. Precision is a valuable metric for assessing the success of predictions. It precisely states the percentage of reliable positive results. Higher precision levels suggest more accurate and exact results from the model. A higher precision number, then, is indicative of a well-trained architecture using the given data. Mathematically, precision is stated as in Eq. (1.3).

```
Precision = \frac{Accurately identified disease pixels}{total number of pixels predicted as diseased} = \frac{TP}{TP + FP} (1.3)
```

### 1.4.4 Recall

Recall, also referred to as sensitivity, is the ratio of true positives to the sum of true positives and false negatives. In this context, true positive represents the accurate identification of instances from the positive class, while false negative indicates the incorrect prediction of instances from the negative class. Essentially, recall represents the fraction of true positives that are successfully detected. Similar to precision, recall is a valuable metric for evaluating prediction success, particularly when dealing with imbalanced classes. Higher values of recall signify that the model effectively captures most of the positive outcomes and correctly labels them. Mathematically, recall is stated as in Eq. (1.4).

```
Recall = \frac{Accurately identified disease pixels}{total number of pixels in GT} = \frac{TP}{TP + FN} (1.4)
```

### 1.4.5 F1 Score

This metric is necessary for evaluating the accuracy of a model. It combines precision and recall into a single measure using the harmonic mean. Instead of using a conventional average, the harmonic mean restricts extreme values. This measurement is useful for striking a balance between recall and precision. The score for these metrics ranges from 0 to 1, with 1 indicating the best performance and 0 indicating the worst. Models with an F1 score near one are regarded as ideal, as they have a low number of false positives and false negatives. This metric is applicable to both binary and multi-class classification and segmentation problems. Mathematically, the F1 score is stated as in Eq. (1.5).

```
F1_score = 2 × Recall × Precision / (Recall + Precision) (1.5)
```

### 1.4.6 Accuracy

Accuracy, also referred to as overall pixel accuracy, represents the percentage of image pixels that are correctly classified. While it is a fundamental performance metric, it has a restriction in representing segmentation performance when there is a class imbalance. When there is an imbalance between the segmentation classes, one class tends to dominate the others. There may be bias in the results if the accuracy of the dominant class is higher than that of the other class. Therefore, when there is no class imbalance in an image, accuracy should be used as a measure of segmentation performance. One alternative definition of accuracy is per-class accuracy, which averages the fraction of properly classified pixels across all classes. This statistic is especially helpful for images that have an imbalance in class. Both the average per-class accuracy and per-class accuracy should be taken into account in situations of class imbalance. However, the average per-class accuracy has a limitation in terms of reducing the confidence measurement of individual classes. Additionally, when there are fewer instances of a specific class, there may be a large variance that can affect the reliability of the results. Mathematically, accuracy is stated as in Eq. (1.6).

```
Accuracy = Accurately classified pixels / Total number of pixels present in the image = (TP + TN) / (TP + TN + FP + FN) (1.6)
```
