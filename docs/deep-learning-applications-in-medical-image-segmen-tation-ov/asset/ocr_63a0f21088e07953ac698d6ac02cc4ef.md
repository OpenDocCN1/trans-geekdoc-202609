# ## 1.4.2 Intersection over Union (IoU)

The IoU, which is also called the Jaccard Index (JI), measures how much the expected segmentation and the ground truth segmentation overlap by figuring out the ratio of the area where they overlap to the area where they join. JI shares similarities with the DSC since they exhibit a monotonic or positive correlation, as demonstrated by the following Eq. (1.2).

```
JI = \frac{S_{GT} \cap S_{Segmented}}{S_{GT} \cup S_{Segmented}} = \frac{TP}{TP + FP + FN} (1.2)
```

# ## 1.4.3 Precision

Precision, also known as true predictive assessment, is calculated as the ratio of true positives to the combined total of false positives and true positives. True positive refers to the correct identification of instances from the positive class, while false positive represents instances incorrectly predicted from the positive class. Precision is a valuable metric for assessing the success of predictions. It precisely states the percentage of reliable positive results. Higher precision levels suggest more accurate and exact results from the model. A higher precision number, then, is indicative of a well-trained architecture using the given data. Mathematically, precision is stated as in Eq. (1.3).

```
Precision = \frac{Accurately identified disease pixels}{total number of pixels predicted as diseased} = \frac{TP}{TP + FP} (1.3)
```

# ## 1.4.4 Recall

Recall, also referred to as sensitivity, is the ratio of true positives to the sum of true positives and false negatives. In this context, true positive represents the accurate identification of instances from the positive class, while false negative indicates the incorrect prediction of instances from the negative class. Essentially, recall represents the fraction of true positives that are successfully detected. Similar to precision, recall is a valuable metric for evaluating prediction success, particularly when dealing with imbalanced classes. Higher values of recall signify that the model effectively captures most of the positive outcomes and correctly labels them. Mathematically, recall is stated as in Eq. (1.4).

```
Recall = \frac{Accurately identified disease pixels}{total number of pixels in GT} = \frac{TP}{TP + FN} (1.4)
```
