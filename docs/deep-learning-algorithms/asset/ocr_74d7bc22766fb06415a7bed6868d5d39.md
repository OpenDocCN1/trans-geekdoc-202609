\( y_j = \left\{ \begin{aligned} 1 \quad \text{if } X \in jth \, class \\ 0 \quad \text{if } X \notin jth \, class \end{aligned} \right. \)

We intend to seek the mapping function \( X \to Y^l \) using all the samples in order to determine Y when a new X comes.

# 2) **Softmax regression:-**

Softmax regression is a generalization of the logistic regression in many classification problems [51]. Logistic regression is for binary classification problems, class tag \( y^{(t)} \in \{0,1\} \). The hypothesis function is as following:

\( h_\phi(X) = \frac{1}{1 + \exp(-\phi^T X)} \)

Training model parameters vector \( \phi \in \mathbb{R}^{D+1} \), which can minimize the cost function:

\( J(\phi) = -\frac{1}{L} \left[ \sum_{i=1}^L \left[ y^{(t)} \log h_\phi \left( x^{(t)} \right) + \left( 1 - y^{(t)} \right) \log \left( 1 - h_\phi \left( x^{(t)} \right) \right) \right] \right] \)

Softmax regression is for many classification problems, class tag \( y^{(t)} \in \{1, 2, \cdots, k\} \). It is used for each given sample X, using hypothesis function to estimate the probability value \( p(Y=j|X) \) for each category j. The hypothesis function is as following:

\( h_\phi \left( X^t \right) = \left[ \begin{array}{c} p \left( Y^{(t)} = 1 | X^{(t)}; \phi \right) \\ p \left( Y^{(t)} = 2 | X^{(t)}; \phi \right) \\ \vdots \\ p \left( Y^{(t)} = k | X^{(t)}; \phi \right) \end{array} \right] = \frac{1}{\sum_{j=1}^k \mathrm{e}^{\phi_j^T X^{(t)}}} \left[ \begin{array}{c} \mathrm{e}^{\phi_1^T X^{(t)}} \\ \mathrm{e}^{\phi_2^T X^{(t)}} \\ \vdots \\ \mathrm{e}^{\phi_k^T X^{(t)}} \end{array} \right] \)

where, \( \phi_0, \phi_1, \cdots, \phi_k \in \mathbb{R}^{D+1} \) denote model parameters vector, the cost function is as following:

\( J(\phi) = -\frac{1}{L} \left[ \sum_{i=1}^L \sum_{j=1}^k \mathbf{1} \left\{ Y^{(t)} = j \right\} \log \frac{\mathrm{e}^{\phi_j^T X^{(t)}}}{\sum_{j=1}^k \mathrm{e}^{\phi_j^T X^{(t)}}} \right] \)

where, \( \mathbf{1} \{\cdot\} \) denotes:

\( \mathbf{1} \left\{ \text{The value of expression is true} \right\} = 1 \text{ or } \mathbf{1} \left\{ \text{The value of expression is false} \right\} = 0 \)
