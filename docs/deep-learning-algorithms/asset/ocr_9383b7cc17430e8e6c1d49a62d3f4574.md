Q satisfies the Bellman equation \(Q^*(s, a) = E_{s' \sim \mathcal{E}} [r + \gamma \max_{a'} Q^*(s', a') \mid s, a]\). The reinforcement learning algorithms estimate the action value function by iteratively updating the Bellman equation \(Q^*(s, a) = E_{s' \sim \mathcal{E}} [r + \gamma \max_{a'} Q^*(s', a') \mid s, a]\). When \(t \to \infty\), the algorithm makes Q-value function converge to the optimal action value function [1]. If the optimal Q- function \(Q^*\) is known, the agent can select optimal actions by selecting the action with the maximal value in a state: \(\pi^* = \text{argmax}_a Q^*(s, a)\).

# Target Deep Q Learning

RL agents update their model parameters while they observe a stream of transitions like \((s_t, a_t, r_t, s_{t+1})\). They discard the incoming data after a single update. There are two issues with this method. The first one is that there are strong correlations among the incoming data, which may break the assumption of many popular stochastic gradient-based algorithms. Secondly, the minor changes in the Q function may result in a huge change in the policy, which makes the algorithm difficult to converge [7, 9, 14, 15].

As for the deep Q-networks algorithms proposed in (Mnih et al., 2013), two aspects are improved. On the one hand, the action value function is approximated by the DNN, DQN uses the DNN with a parameter \(\theta\) to approximate the value function, \(Q(s, a; \theta) \approx Q^*(s, a; \theta)\); on the other hand, the experience replay mechanism is adopted. The algorithm learns from sampled transitions from an experience buffer, rather than learning fully online. Tis mechanism makes it possible to break the temporal correlations by mixing more and less recent experience for updating and training. Tis model free reinforcement learning algorithm solves the problem of "model disaster" and uses the generalized approximation method of the value function to solve the problem of "dimension disaster. The convergence issue was mentioned in 2015 by Schaul et al. [14]. The above Q-learning update rules can be directly implemented in a neural network. DQN uses the DNN with parameters \(\theta\) to approximate the value function\(^\circ\). The parameter \(\theta\) updates from transition \((s_t, a_t, r_{t+1}, s_{t+1})\) are given by the following [11]:

\(\theta_{t+1} \leftarrow \theta_t + \alpha (y_t^Q - Q(s_t, a_t; \theta_t)) \nabla_\theta Q(s_t, a_t; \theta_t)\)

with \(y_t^{\text{DQN}} = r_t + \gamma \max_a \widetilde{Q}(s_{t+1}, a; \theta_t^-)\)

The update targets for Sarsa can be described as follows:

\(y_t^{\text{Sarsa}} = r_t + \gamma \widetilde{Q}(s_{t+1}, a_{t+1}; \theta_t^-)\)
