# EXPERIMENTS

# Experimental Setup

So far, we have carried out our experiments on several classical control and Box2D environments on OpenAI Gym: CartPole-v0, MountainCar-v0, and LunarLander-v2 [15]. We use the same network architecture, learning algorithms, and hyperparameters for all these environments.

We trained the algorithms using 10,000 episodes and used the Adaptive Moment Estimation (Adam) algorithm to minimize the loss with learning rate \(\mu = 0.00001\) and set the batch size to 32.

The summary of the configuration is provided below. The target network updated each 300 steps. The behavior policy during training was \(\varepsilon\)-greedy with \(\varepsilon\) annealed linearly from 1 to 0.01 over the first five thousands steps and fixed at 0.01 thereafter. We used a replay memory of ten thousands most recent transitions

We independently executed each method 10 times, respectively, on every task.

For each running time, the learned policy will be tested 100 times without exploration noise or prior knowledge by every 100 training episodes to calculate the average scores. We report the mean and standard deviation of the convergence episodes and the scores of the best policy.

```
(1) Initialize action-value network Q with random weights \(\theta\)
(2) Initialize the target neural network buffer \((Q_i)_{i=1}^N\)
(3) For episode 1, M do
(4)   For t = 1, T do
(5)     With probability \(\varepsilon\) select a random action \(a_t\), otherwise
(6)     \(a_t = \text{argmax}_a Q(s_t, a; \theta)\)
(7)     Execute action \(a_t\) in environment and observe reward \(r_t\)
    and next state \(s_{t+1}\) and store transition \((s_t, a_t, r_t, s_{t+1})\) in D
(8)     Sample random minibatch of transition \((s_j, a_j, r_j, s_{j+1})\) from D
(9)     set \(y_j = \lambda^{-1} \sum_{i=1}^N \lambda^{i-1} r_j + \gamma \max_a \overline{Q}(s_{j+1}, a; \theta^-)\)
(10)    Ensemble Q-learner \(\overline{Q}(s, a; \theta) = \sum_{i=1}^N w_i Q_i(s, a; \theta_i)\)
(11)   set \(y_j^{\text{DQN}} = r_t + \gamma \max_a \overline{Q}(s_{t+1}, a_t; \theta_T)\)
(12)   set \(y_j^{\text{DDQN}} = r_t + \gamma \overline{Q}(s_{t+1}, \text{argmax}_a \overline{Q}(s_{t+1}, a_t; \theta_T); \theta_T)\)
(13)   set \(y_j = r_j + \gamma Q(s_{t+1}, \text{argmax}_a \overline{Q}(s_{t+1}, a_t; \theta_T); \theta_T)\)
(14)   Set \(y_j = r_j\), if episode terminates at step j + 1; \(\sum_{i=1}^k \beta_t y^t\), otherwise
(15) \(\theta_t = \text{argmin}_\theta \left[ (y_{s_{t+1}} - Q(s, a; \theta))^2 \right]\)
(16) Every C steps reset Q = Q
(17) End for
```
