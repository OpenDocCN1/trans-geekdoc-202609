$P(h^{k-1}|\theta)=\frac{1}{Z(\theta)}\sum_{h^k}\exp(-E(h^{k-1},h^k,\theta))$

$Z(\theta)=\sum_{h^{k-1}}\sum_{h^k}\exp(-E(h^{k-1},h^k;\theta))$

where, $Z(\theta)$ denotes the normalizing constant. The conditional distributions over $h^k$ and $h^{k-1}$are given as:

$p(h^k|h^{k-1})=\prod_j p(h_j^k|h^{k-1})$

$p(h^{k-1}|h^k)=\prod_i p(h_i^{k-1}|h^k)$

The probability of turning unit j is a logistic function of the states $h^{k-1}$and $w_{ij}^k$ :

$p(h_j^k=1|h^{k-1})=sigm(c_j^k+\sum_i w_{ij}^k h_i^{k-1})$

The probability of turning unit i is a logistic function of the states of h^k and $w_{ij}^k$ :

$p(h_i^{k-1}=1|h^k)=sigm(b_i^{k-1}+\sum_j w_{ij}^k h_j^k)$

where, the logistic function been chosen is the sigmoid function:

$sigm(x)=1/(1+e^{-x})$

The derivative of the log-likelihood with respect to the model parameter w^k can be obtained from Equation (48):

$\frac{\partial \log p(h^{k-1})}{\partial w_{ij}^k}=\langle h_i^k h_j^k \rangle_{p_0}-\langle h_i^k h_j^k \rangle_{p_{Model}}$

where, $\langle \rangle_{p_0}$ denotes an expectation with respect to the data distribution and Model $\langle \rangle_{p_{Model}}$ denotes an expectation with respect to the distribution defined by the model [55]. The expectation $\langle \rangle_{p_{Model}}$ cannot be computed analytically.
