The images of this database are originally of size 1024 * 1024 * 1 pixels; hence, they were first downsampled to 227 * 227 * 1 pixels to fit the input layer of the pretrained model: AlexNet which does not accept other input data sizes. Note that we decided to use the same input images size for the CNN created from scratch, only for networks performance comparison purposes, although any slice could be used. Moreover, the images of the database are of grayscale type, and since the AlexNet model requires 3-channels input data, images were all converted to RGB by concatenating their grayscale channel for three times to become 227 * 227 * 3.

# Training the Network Models

The two employed deep models are simulated using MATLAB environment. The networks were trained on a Windows 64-bit desktop computer with an Intel Core i7 4770 central processing unit (CPU) and 16GB random access memory. It is important to mention that there was no graphical processing unit (GPU) available in the used desktop.
