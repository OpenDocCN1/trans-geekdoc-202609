# PHP—Function preg_match_all()

# Syntax

```
int preg_match_all (string pattern, string string, array pattern_array [, int order]);
```

# Definition and Usage

The preg_match_all() function matches all occurrences of pattern in string.

It will place these matches in the array pattern_array in the order you specify using the optional input parameter order. There are two possible types of order –

+   • **PREG_PATTERN_ORDER** –REG PATTERN_ORDERRe matches in the array pattern_array in the od. PREG_PATTERN_ORDER specifies the order in the way that you might think most logical; $pattern_array[0] is an array of all complete pattern matches, $pattern_array[1] is an array of all strings matching the first parenthesized regexp, and so on.
