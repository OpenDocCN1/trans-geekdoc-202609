

### 6.3.1 多层感知机

多层感知机是用于学习 EHR 数据模式和行为的常用网络之一。它通常由多个隐藏层组成；隐藏层的数量由问题的复杂性决定。它是一种通用的前馈网络，其中每个神经元都连接到下一层的所有神经元。信息流仅单向流动，且没有反馈连接。每层中的神经元对来自前一层的输入和连接权重的乘积值求和，并应用激活函数以产生最终输出。常用的激活函数有阈值、线性和 Sigmoid 激活函数。网络通过寻找输入和输出之间的关系来学习神经元之间的连接权重。

隐藏层权重的更新如公式 (6.1) 所示，其中 `d` 表示前一层的单元数，`x_j` 是来自前一层节点 `j` 的输入，`w[ij]` 和 `b[ij]` 分别代表权重和偏置，`sigma()` 代表激活函数 [[1](#ch6.xhtml#ref6_1)]。

(6.1)

```
h_i = sigma( sum_{j=1}^{d} (x_j * w_ij + b_ij) )
```

### 6.3.2 卷积神经网络 (CNN)

CNN 是一种在图像处理（尤其是医学图像分析）、计算机视觉、数据挖掘等领域获得良好应用的工具。CNN 的显著特性是其能够识别相邻数据之间的强连接性，而不是将原始数据作为一个整体来看待。CNN 是一种学习机制，它从前序层中提取强低级特征并将其传递给包含卷积滤波器的下一高层。提取的特征在池化层中进行汇总。它是临床应用中首要且常用的工具。U-Net [[19](#ch6.xhtml#ref6_19)] 和 ResNet [[20](#ch6.xhtml#ref6_20)] 是医学图像分析中常用的架构，它们能用较少的层数表示完整图像且具有良好的收敛性。Dense CNN [[21](#ch6.xhtml#ref6_21)] 减轻了梯度问题并减少了涉及的参数。证明 CNN 在从医生笔记中预测疾病编码方面是高效的。CNN 的基本架构如 [图 6.3](#ch6.xhtml#fig6_3) 所示。

![图 6.3 卷积神经网络。](images/fig6_3_C.jpg)

[图 6.3 卷积神经网络。](#ch6.xhtml#R_fig6_3)

一维卷积 [[1](#ch6.xhtml#ref6_1)] 由下式给出

(6.2)

```
C_1d = sum_{alpha=-infty}^{infty} x(a) * w(t - a)
```

二维卷积 [[1](#ch6.xhtml#ref6_1)] 为

(6.3)

```
C_2d = sum_m sum_n x(m,n) * K(i-m, j-n)
```

其中 `x` 是输入信号，`w` 是加权函数，`X` 是二维网格，`K` 是核。

### 6.3.3 循环神经网络 (RNN)

它是一种用于深度学习的前馈神经网络。这种神经网络的强连接使其看起来像一个有向图。门控循环单元是 RNN 变体的一个版本，被称为长短期记忆 (LSTM)。研究人员已将该网络应用于疾病诊断 [[24](#ch6.xhtml#ref6_24)]、[[25](#ch6.xhtml#ref6_25)] 和其他临时医疗建议。门控 RNN 在建模长期依赖方面很高效 [[26](#ch6.xhtml#ref6_26)]。除了医学相关问题，该网络已被证明在模式识别和多种图像处理应用等其他领域也很成功 [[27](#ch6.xhtml#ref6_27)]。当数据按适当顺序排列时，RNN 比 CNN 是更好的选择。该网络旨在处理时间依赖性 [[1](#ch6.xhtml#ref6_1)]，因此常用于自然语言处理和时间序列数据。RNN 根据当前输入以及前一个隐藏状态来更新其隐藏状态。因此，显然最终状态包含了所有前序阶段的细节。RNN 也用于从临床数据中提取特征。[图 6.4](#ch6.xhtml#fig6_4) 表示 RNN 的架构。

### 6.3.4 受限玻尔兹曼机

它是一种无监督随机学习技术，能识别输入数据的概率分布。该网络应用于 X 光片 [[28](#ch6.xhtml#ref6_28)] 和 CT 图像 [[29](#ch6.xhtml#ref6_29)] 等医学图像的分类任务领域。RBM 是解释数据生成基本过程的广义模型。一般来说，玻尔兹曼机是全连接的，而在 RBM 中，隐藏层单元之间或可见单元之间不存在连接。吉布斯采样是用于训练 RBM 的过程。深度置信网络 (DBN) 是 RBM 的堆叠表示，形成一个有监督学习网络。

RBM 的能量函数 [[26](#ch6.xhtml#ref6_26)] 由下式给出

(6.4)

```
E(v, h) = -b^T v - C^T h - W v^T h
```

其中 `v` 代表可见单元，`h` 代表隐藏单元。[图 6.5](#ch6.xhtml#fig6_5) 展示了 RBM 的可见单元和隐藏单元。

### 6.3.5 自编码器

自编码器 (AE) 在训练数据较少时应用于多种有监督任务的预训练过程中，但它是典型的无监督深度学习技术。AE 将输入数据投影到低维空间，这称为编码。编码和重构机制的表示 [[1](#ch6.xhtml#ref6_1)] 由公式 (6.5) 和 (6.6) 给出。

(6.5)

```
z = sigma(W * x + b)
```

(6.6)

```
x_tilde = sigma(W' * z + b')
```

其中 `x` 是输入，`x_tilde` 是输入的近似表示，`W` 是编码权重，`W'` 是解码权重，`z` 是编码表示。网络通过训练以减小误差 `||x - x_tilde||`，从而使编码表示准确。AE 被视为一种类似于主成分分析 (PCA) 的降维技术，因为它将输入数据转换为判别性方面并将其作为输出存储。由于隐藏层激活函数中发生的非线性变换，它在解决复杂问题上比 PCA 和类似技术更具优势。基于堆叠的贪婪训练方法用于设计深层 AE 网络。[图 6.6](#ch6.xhtml#fig6_6) 展示了自编码器的架构。
