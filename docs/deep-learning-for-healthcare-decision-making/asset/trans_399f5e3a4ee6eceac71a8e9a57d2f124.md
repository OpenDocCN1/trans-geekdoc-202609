
可信系统应设计为分析此类异构数据，以学习海量临床数据并学习疾病及其相关症状之间的相关性。此外，应妥善识别疾病的病因、特定疾病通常影响的人数、通常受影响的地区、此类疾病的风险因素等，以减轻此类疾病在未来的影响。在进行此类严格分析时，应保持患者数据的机密性。多种传统机器学习方法，如主成分分析（PCA）[2](#ch6.xhtml#ref6_2)、[3](#ch6.xhtml#ref6_3)、人工神经网络（ANN）、卷积神经网络（CNN）、贝叶斯网络、概率神经网络、支持向量机（SVM）[4](#ch6.xhtml#ref6_4)、[5](#ch6.xhtml#ref6_5)、决策树[6](#ch6.xhtml#ref6_6)等，被用于分析这些临床大数据。这些方法在医院数据的几个子领域取得了成功的结果，但高度复杂和异构的 EHR 数据要求采用先进的深度学习技术，后者在其他几个当代领域已取得成功。深度学习在多个领域确保了预测和知识传播的准确性，因此，使用这些技术以获得临床分析的精确性并不令人惊讶。

## 6.2 EHR 概述

医院之间相互竞争，通过电子记录维护患者的医疗问题历史并加强健康专家之间的协作，以提供更好的患者护理。此类记录通过减少错误、在更短时间内识别既往健康问题、正在服用的药物和总体健康状况，从而提高患者护理效率，真正使患者和医院双方受益。EHR 通常分为两类：基本 EHR（缺少医生笔记）和高级综合 EHR（包含医生笔记）。其设计初衷是为了医院内部的行政便利，因此存在多种编码类别用于录入患者健康数据。有特定代码，如疾病国际统计分类（ICD）及相关健康问题、现行操作术语（CPT）和逻辑观察标识符名称和代码（LOINC）[1](#ch6.xhtml#ref6_1)。上述代码并非固定不变，而是因医院和世界不同地区而异。只有当代码在 EHR 中得到适当表示时，深度学习技术才能有效工作。由于数据量巨大且代码种类繁多，协调和分析成为一项艰巨任务，这使得引入深度学习技术进入该领域成为必要。

### 6.2.1 EHR 的特征

全球各地医院收集的 EHR 数据量巨大，据报告此类数据已超过 25 EB（艾字节）[7](#ch6.xhtml#ref6_7)、[8](#ch6.xhtml#ref6_8)。得益于物联网，开发出多种可穿戴传感器以自动监测患者健康，这导致此类数据激增。此类传感器还会生成实时数据，需要即时分析和快速响应。一方面数据量在增长，另一方面数据采集源的数量也在增长。随着数据源数量增加，分析复杂性也随之增加，因为没有通用的方式来描述疾病代码和临床笔记的格式。因此，可以明确得出结论：EHR 数据在速度、真实性、多样性和容量方面具有大数据的所有物理特征，因此大数据分析应扩展至该领域。

### 6.2.2 EHR 数据的类别

在患者健康检查或治疗过程中会收集大量数据。医院以不同格式表示和存储这些信息。医学影像、疾病编码和临床笔记是数据的基本类别。医学诊断有多种成像技术，即光学相干断层扫描（OCT）、磁共振成像（MRI）、计算机断层扫描（CT）、X 射线，以及基于信号的数据，如 EEG、ECG 等。MRI 图像通常用于识别大脑、心脏、骨骼和关节的疾病。CT 和 X 射线通常用于检测腹部和胸部的异常。然而，临床数据分析的困难在于此类数据的可获得性，与社交网站数据等其他大数据相比较少。因此，无法为训练阶段提供所需数量的数据。与此数据相关的另一个问题是将这些数据呈现给神经网络层的格式。

## 6.3 EHR 中的机器学习与深度学习

最初，研究人员使用机器学习技术进行 EHR 记录的知识发现过程。通过让机器从现有数据中学习使其变得智能的过程称为机器学习。监督学习和无监督学习是机器学习的两种常见类型。将输入与已知目标映射的过程称为监督学习，而在不提供目标的情况下对相关数据进行分组的方法称为无监督学习。回归和分类归属于机器学习，而聚类过程归属于无监督学习。需要从数据中提取重要特征，这些特征构成机器学习算法的输入。提取此类重要特征是机器学习过程中的关键问题之一，应妥善解决。在某些情况下，这些特征是手工提取的，但由于 EHR 数据量大且异构，这不可能实现。因此，这些记录的机器学习或深度学习方法需要自动特征提取。这些特征作为输入提供给用作机器学习技术的神经网络的输入层。EHR 数据机器学习和深度学习的常用架构总结如下。[图 6.1](#ch6.xhtml#fig6_1) 显示了用于机器学习的基本前馈网络。
