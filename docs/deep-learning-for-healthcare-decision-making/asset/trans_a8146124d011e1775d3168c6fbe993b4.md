

## 1.4 医疗保健中的机器学习

机器学习是人工智能的一个子集，在许多与健康相关的领域发挥着至关重要的作用，包括新医疗程序的开发、患者数据和记录的处理以及慢性病的治疗。在医疗保健领域，机器学习的应用更为广泛，它在许多方面帮助患者和医务人员。在医疗保健行业，机器学习最自然的用途是实现医疗账单自动化和临床决策支持。在医疗行业，机器学习和医疗保健方法以多种方式被使用。放射学中的深度学习通过自动检测难以识别的模式，帮助放射科医生在评估常规X光摄影、CT、MRI、PET扫描和放射学描述等影像时做出更精准的判断。

基于机器学习的自动检测和诊断技术已显示出其表现堪比专家放射科医生。用于观察乳腺癌的医疗机器学习程序达到了89%的准确率，这与放射科医生相当，甚至更优。这只是机器学习在医疗保健中众多应用方式的一小部分 [[1](#ch1.xhtml#ref1_1)]。

医疗保健中的机器学习涵盖了基于患者特征预测哪种治疗技术最适合患者。这需要监督学习，监督学习要求使用具有预定目标变量的训练数据集。

机器学习的进一步进展是神经网络。它已被用于预测患者是否会患上特定疾病。使用具有无数特征层级的深度学习或神经网络模型预测结果的最先进方法是医学界的现代趋势。最新模型中可能存在更多的隐藏元素，这些元素可通过当今图形处理单元和云架构更强大的处理能力轻松识别。深度学习在医疗保健中最常见的应用是检测恶性细胞。

结合深度学习的机器学习，能够定制具有多个特征阶段的神经网络模型以预测结果，这是至关重要的需求。深度学习常用于医疗保健中识别潜在的癌细胞。机器学习专注于制药公司的药物发现和药物开发等大型领域。

在放射照片中识别有害肿瘤是深度学习在医疗保健中的常见应用之一。放射组学中的深度学习用于捕捉医学影像中肉眼难以察觉的临床模式。在以肿瘤学为中心的图像分析中，深度学习和放射组学可被广泛应用 [[16](#ch1.xhtml#ref1_16)]。

Quotient Health、Kensi、Ciox Health 等公司在医疗保健系统中使用机器学习。

## 1.5 医疗保健中的自然语言处理（NLP）

自然语言处理（NLP）是指计算机理解人类最新语音词汇和文本的能力。在当前流行的技术中，它基本上用于垃圾邮件隐私保护、个人语音助手和语言翻译应用。

自然语言处理（NLP）系统在医疗保健中常与机器学习结合使用。大多数基于 NLP 的医疗保健深度学习应用需要医疗机器学习的实践。统计自然语言处理（NLP）建立在机器学习基础上，最近促进了识别准确率的提高。

自然语言处理是一种深刻的技术，具有搜索、分析和理解海量患者数据的能力。在医疗保健中使用机器学习，在 NLP 的支持下，可以从数据中提取有意义的见解和概念，这些数据过去被认为埋藏在使用非传统医疗算法的文本形式中。在最新的医疗创新中，NLP 能够精准地驾驭世间海量的非结构化数据，为理解质量、改进技术和改善患者预后提供极大洞见。

医疗保健中最普遍的应用是医疗文档的创建、理解和分类，以及已发布的研究。该系统可以分析无结构的患者医疗信息，生成记录患者对话的报告，并参与对话式 AI [[18](#ch1.xhtml#ref1_18)]。

医疗保健中最流行的 NLP 技术包括光学字符识别、情感分析、命名实体识别、文本分类和主题建模。

## 1.6 深度学习模型

深度学习是一个新兴领域，其应用跨越多个用例。了解和理解深度学习中各个领域使用的不同模型类型非常重要。深度学习此前已在医疗保健领域产生了影响。Google 投入大量精力研究深度学习模型如何对住院患者和结果监测进行预测。博客文章“电子健康记录的深度学习”举例说明了如何在增强患者护理洞察的同时减轻行政负担。深度学习在医疗保健中效果最好，因为它降低了行政成本，同时让医生专注于他们最擅长的事情：治疗患者 [[15](#ch1.xhtml#ref1_15)]、[[16](#ch1.xhtml#ref1_16)]。

![Figure 1.4 Road map from clinical data generation, through NLP data enrichment and ML data analysis.](images/fig1_4_C.jpg)

图 1.4 从临床数据生成，通过 NLP 数据丰富和 ML 数据分析的路线图。

深度学习联盟正在革新患者保障；它在健康计划的临床实践中发挥着关键作用。最流行的应用是计算机视觉、自然语言处理和强化学习。

*   深度学习算法可以生成精确的自动诊断建议：
*   降低护理成本
*   避免报告危急病例的延误
*   通过减少行政工作量，为医疗专业人员腾出时间，专注于更复杂的诊断或患者护理。
*   审核处方和诊断结果以减少诊断错误。
*   更快速的诊断。

随着全球疫情爆发，深度学习模型的使用变得更加必要。研究人员目前正在研究深度学习应用。

**新冠肺炎（COVID-19）的早期诊断：**

*   分析胸部 CT 图像和胸部 X 光片 (CXR)
*   可预测是否需要入住重症监护室
*   协助识别潜在的 COVID-19 患者
*   计算所需的机械通气量

用于与患者沟通的深度学习技术（如语音和文本识别）在未来将持续增长。因此，医疗保健中的深度学习应用滋生了对数据隐私和法律的担忧 [[11](#ch1.xhtml#ref1_11)]。
