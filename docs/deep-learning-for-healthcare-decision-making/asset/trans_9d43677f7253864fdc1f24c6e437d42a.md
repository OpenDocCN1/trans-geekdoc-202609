
# 4 基于卷积神经网络的胶质瘤MRI图像分割

Anupama M. Nayak^()

## 摘要

生物医学科学领域对准确且直观的诊断工具的需求，促使许多研究人员专注于整合深度学习提供的各种模型以适应治疗应用。特别是神经网络，已被广泛研究用于辅助图像分割和分类操作。该项目旨在解决癌症患者胶质瘤MRI图像自动分割的需求。利用卷积神经网络的DenseNet架构变体构建了一个高精度的3D分割工具。我们的程序还能对肿瘤进行初步分类，分为高级别肿瘤和低级别肿瘤，为医学界提供关于胶质瘤严重程度的初步见解。我们利用开源Python库函数构建了我们的架构。该架构的训练和测试是在基准MICCAI BRaTS数据集上进行的。我们的模型显示出高分割精度，准确率接近100%（经增强后约为99.94%）。灵敏度和阳性预测值（PPV）也获得了相同的数值。这种分割精度水平可被认为是实际医疗应用的理想选择。
