
## 10.2 IoT、区块链与机器学习在医疗监测中的应用

由于大流行病（COVID-19）带来的高度威胁风险，世界卫生组织（WHO）建议各国制定“大流行病计划”。大流行病计划通常根据 WHO 的大流行阶段进行规划，旨在从一开始就实现大流行病管理中明确的成果 [[10](#ch10.xhtml#ref10_10)]。针对医疗领域的任何紧急情况，已识别出不同类型的技术。每场灾难分为四个阶段：缓解、准备、响应和恢复 [[11](#ch10.xhtml#ref10_11)]。“桌面推演或基于讨论的会议”是寻找应对危机有效解决方案的重要策略；此类讨论将创建一个场景，该场景由管理、劳动者、资金等不同领域和部门之间的沟通与协作共同辅助。一项合法的研究可提供广泛的框架和心理模型，复现完美的决策环境 [[11](#ch10.xhtml#ref10_11)]。在所有关键技术中，IoT 被视为应对此类大流行病最常用的技术之一，可提供网络上所有设备间的连接 [[12](#ch10.xhtml#ref10_12)]、[[13](#ch10.xhtml#ref10_13)]。网络中每个对象间的信息交换，通过基于跨所有中心（即设备/客户端）传达的协议的周期进行授权。区块链的概念源于每个人利用加密策略持有对前一个区块的引用这一事实。区块链不像普通网络服务那样存储在集中式服务器上，而是存储在称为中心的网络设备（PC）上，每个设备都拥有整个区块链的副本 [[14](#ch10.xhtml#ref10_14)]。跨网络中心复制和存储各种区块链的多个副本，保证了更高的系统安全性和用户间的价值，用户可同时访问相同数据，从而实现区块中已批准交易的可检测性和可变性。因此，区块链是一个分布式组织，所有组织用户无需相互信任即可信任该框架。除了区块链技术，机器学习（ML）也被用于分析通过不同传感器和医疗设备收集的大量数据。不同研究人员已致力于基于 ML 的医疗监测系统，通过提供智能实时健康监测系统，为患者提供有效及时的治疗。Ani 等人 [[15](#ch10.xhtml#ref10_15)] 提出了一种基于 IoT 和 ML 的医疗监测系统，用于预测老年人的慢性疾病，如哮喘、癌症、糖尿病等。该拟议系统包含三层：(1) 硬件层（微控制器、血压及其他基于传感器的设备）；(2) 应用层（云服务器和 Web 环境）；(3) 不同的 ML 算法，如 `naïve Bayes`、`RFT` 等。几乎所有 `RFT` 均提供 93% 的准确率。Onasanya 等人 [[16](#ch10.xhtml#ref10_16)] 利用 IoT 和云服务的概念提出了一个基于癌症的系统。该模型基于体域无线传感器网络（`BWSN`）的概念，连接患者以监测其健康参数。Kumar 等人 [[17](#ch10.xhtml#ref10_17)] 建议了一种利用 IoT 和 ML 识别心脏病的医疗监测框架。拟议系统由三层组成。第 1 层收集植入患者体内传感器的数据，第 2 层利用 `HBase` 收集大量信息，第 3 层专注于称为 ML 的数据分析技术。Varadarajan 等人 [[18](#ch10.xhtml#ref10_18)] 提出了一种利用云作为安全存储空间的基于 IoT 的医疗系统。他们提出了一种基于模糊规则的疾病诊断技术。拟议系统由八个组件组成，分别命名为 `UCI repository dataset`、医疗传感器、云计算、`fuzzy temporal neural classifier` 和数据累积。该拟议系统已使用 `JAVA` 编程在 `Amazon cloud` 上实现。`K-NN`、`DT`、`SVM` 和 `NB` 被用作重要的 ML 技术，每种技术获得不同的准确率结果。Verma 等人 [[19](#ch10.xhtml#ref10_19)] 讨论了一种用于学生疾病诊断的智能系统。拟议方法分三阶段工作。第 1 阶段从不同传感器收集数据，第 2 阶段通过特定网关将数据移至云端，第 3 阶段处理数据。此外，还将连接一个预警系统，以便在发生任何紧急情况时警告患者和护理人员。Gutte 等人 [[20](#ch10.xhtml#ref10_20)] 利用不同的 IoT 设备提出了一种基于 IoT 的健康监测系统。拟议系统分为四层。第 1 层处理数据收集概念，第 2 层使用 `Raspberry Pi` 作为微控制器处理数据，第 3 层涉及数据存储概念。一旦出现任何危急情况，拟议系统会向患者或护理人员发送短信和电子邮件。

通过对不同研究人员工作的研究，我们了解到区块链和 ML 技术在以低成本为患者提供安全、智能的实时医疗监测服务方面发挥着高效作用。

## 10.3 在医疗领域建立 IoT 面临的问题与挑战

尽管 IoT 具有诸多优势，且能解决不同领域的各种并发症，但仍存在大量挑战。这些并发症可能体现在解决安全问题、隐私担忧等方面 [[21](#ch10.xhtml#ref10_21)]、[[22](#ch10.xhtml#ref10_22)]、[[23](#ch10.xhtml#ref10_23)]、[[24](#ch10.xhtml#ref10_24)]、[[25](#ch10.xhtml#ref10_25)]。本节简要描述所有可能的问题与挑战：建立 IoT 面临的主要挑战如 [表 10.1](#ch10.xhtml#tab10_1) 所示。

### 表 10.1：IoT 的主要问题与挑战

| 问题 | 挑战 | 解释 |
| --- | --- | --- |
| 安全问题 | 设计实践：速率与安全 | 近期缺乏关于基于安全的 IoT 规划人员培训资产 |
| | | IoT 分析过程中缺乏关于成本与收益的信息 |
| | 标准与指标、机密性、认证与控制、现场可升级性、设备废弃 | 缺乏关于与安全问题相关的伦理和标准度量的知识；缺乏最优性受控角色可能导致劫持和网络攻击问题；因缺乏关于 IoT 设备可维护性和可升级性的知识而产生挑战；对旧设备和不需要设备的替换推断有限 |
| 互操作性问题 | 专有生态系统与消费者意愿缺失 | 缺乏关于数据收集格式的知识可能导致互操作性问题；因此必须实施适当的安全协议 |
| | 技术风险、配置 | 对技术问题认知不足可能产生技术问题；因缺乏关于多设备使用的标准配置知识而产生问题 |
| IoT 伦理问题 | 理想努力的爆发 | 因缺乏生成标准协议的努力而产生挑战 |
| 新兴经济体问题 | 投资 | 在 IoT 及其相关活动研究领域的投资有限 |
| 发展问题 | 基础设施资源、技术与工业发展 | 全球通信和互联网基础设施负担沉重；在赋能互联网和通信基础设施方面努力较少 |
