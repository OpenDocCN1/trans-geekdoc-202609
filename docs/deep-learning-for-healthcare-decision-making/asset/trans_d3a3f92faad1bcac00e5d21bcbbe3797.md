## 3.2 医疗保健领域机器学习与人工智能文献综述

### 3.2.1 机器学习在医疗保健中的应用

机器学习技术在医疗保健领域发挥着重要作用。目前，它正被开发和实施，用于各种针对性的健康应用，如患者监测、医学诊断、卫生系统学习和临床决策支持 [[21](#ch3.xhtml#ref3_21)]。这些应用涵盖了一系列方法，包括监督学习、认知学习、无监督学习、深度学习和基于强化学习的算法等不同概念，这些方法可用于分析和解释复杂的医疗数据，而在该类情况下，经典统计算法可能无法胜任。机器学习算法在医疗保健领域充满希望的方向是开发自动化风险预测方法，以指导临床护理。预测模型的目的取决于数据的异质性、数据的深度、数据的广度、建模任务、机器学习算法的选择以及特征选择技术 [[22](#ch3.xhtml#ref3_22)]。即使机器学习算法常用于医疗保健，但更多的司法管辖区不允许这些算法成为最终的决策者；它们主要被用作检测方法或诊断辅助工具。

机器学习用于医疗服务并非新鲜事物，且已在公共和私营医疗部门均实现了不断扩展。医疗保健领域最重要的机器学习服务如图 3.2 [Figure 3.2](#ch3.xhtml#fig3_2) 所示。首先是识别与诊断，涉及识别患者疾病、监测其病情并建议必要的预防措施。还有药物发现与制造，包括自动化识别新药或先导分子，以最小化错误并提高药物开发和发现的效率。得益于深度学习和计算机视觉，医学影像也是医疗保健中一项非常重要的应用，它有助于检测微观异常；因此，医生可以提出适当的诊断。另一项应用是患者治疗与监测，涵盖基于海量数据集和电子健康记录规划和管理具体行动，以使患者恢复健康。允许患者直接共享其数据的智能健康记录是另一项应用，机器学习在此被用于节省精力、时间和成本。最后，许多机器学习模型（如人工神经网络）被用于疾病预测，这不仅有助于预测轻微疾病，还能基于从社交媒体平台、卫星、网站等获取的大量数据预测严重的传染性疾病。

目前，机器学习算法正被用于全球最严重的前所未有的公共卫生危机之一——新型冠状病毒疫情（SARS-00V-2 或 COVID-19）。它帮助科学家对 COVID-19 基因组进行分类 [[23](#ch3.xhtml#ref3_23)]、识别针对 COVID-19 的潜在药物候选者 [[24](#ch3.xhtml#ref3_24)]、预测用于疫苗配方的 COVID-19 相关蛋白质结构 [[25](#ch3.xhtml#ref3_25)]，以及用于 COVID-19 病毒的其他有用应用 [[26](#ch3.xhtml#ref3_26)]。文献 [[23](#ch3.xhtml#ref3_23)] 的作者识别出一种内在的 SARS-CoV-2 基因组特征，并将其与一种结合多种技术的机器学习算法配合使用，实现了对整个 SARS-CoV-2 病毒基因组的极高精度分类。所提出的算法允许对 SARS-CoV-2 病毒序列进行 100% 准确的分类，并在几分钟内找到 5000 多个病毒基因组之间最合适的关系。然而，该算法可以为分类学分类提供良好的实时可能性。Ge 等人 [[24](#ch3.xhtml#ref3_24)] 提出了一个框架，应用统计分析和机器学习技术来整合和利用大规模知识图谱、文献和转录组数据，以寻找针对 COVID-19 病毒的潜在药物候选者。他们利用过去的 MERS-CoV 和 SARS-CoV 数据证明，所提出的框架可以预测针对特定冠状病毒的有益药物候选者。Khan 等人 [[27](#ch3.xhtml#ref3_27)] 建议了一种名为 `CoroNet` 的深度学习模型，基于深度卷积神经网络利用 X 射线摄影图像识别 COVID-19 感染病例。所提出的模型在所用数据集上进行了测试，结果显示该模型总体准确率达到 89.6%。

### 3.2.2 人工智能在医疗保健中的应用

人工智能引入了大量可用于工业 4.0 的智能算法。其中大多数算法对医疗保健领域有重要影响。人工智能技术在医疗保健中的性能取决于其关键参数和健康数据的质量。人工智能在医疗保健中应用的典型架构极有可能在保持医疗质量的同时降低医疗成本，即将仅由专业人员提供的护理转变为具有共同责任和自我赋能的个性化患者护理（图 3.4 [Figure 3.4](#ch3.xhtml#fig3_4)）。治疗决策由人工智能直接面向患者做出，或由护理人员根据治疗建议的复杂程度做出 [[28](#ch3.xhtml#ref3_28)]。

![Figure 3.4 A typical architecture of artificial intelligence applications in healthcare.](images/fig3_4_C.jpg)

[图 3.4 人工智能在医疗保健中应用的典型架构。](#ch3.xhtml#R_fig3_4)

人工智能被证明是放射学、病理学以及最近眼科学中图像识别的潜在工具 [[29](#ch3.xhtml#ref3_29)]。它已被广泛用于监测疲劳，并已被证明有效 [[30](#ch3.xhtml#ref3_30)]。例如，人工神经网络、鼠标交互和键盘模式的数据分析以及心率数据检查已被研究用于识别有助于疲劳识别的原因和特征。针对 COVID-19 的检测，Salman 等人 [[31](#ch3.xhtml#ref3_31)] 提出了一种基于深度学习和 X 射线成像的新模型，这将极大地提高放射科医生的效率，从而有助于控制疫情。
