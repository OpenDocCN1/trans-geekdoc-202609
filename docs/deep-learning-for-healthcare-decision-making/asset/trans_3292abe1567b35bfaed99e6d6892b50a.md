
# 第1章：医疗保健中的深度学习与人工智能

## 1.1 深度学习概述

*   一种策略是使用算法从数据中提取见解，这被称为机器学习。
*   另一种做法是使用一种称为深度学习概念的专用算法。

请以同心圆结构的形式考虑这种关联。

深度学习是一种算法形式，旨在极擅长预测事件。深度学习与神经网络的原理紧密相关。

大脑皮层启发了神经网络。在其最原始的形式中，感知机是生物神经元的数学模型。类似于大脑皮层，可以有许多层相互依赖的感知机。输入值和原始数据通过这个“网络”隐藏层传递，直到到达输出层。预测层由一个或多个节点组成，具体取决于模型仅输出一个数值，还是处理多类分类问题。

我们的原始数据或输入值，通过相同的隐藏层“网络”流动，直到到达输出层。根据模型仅输出数值还是处理多类分类问题，预测层可能包含一个或多个节点。

神经网络的隐藏单元对数据进行转换，以弄清其与目标变量的关系。每个节点都有一个权重，该权重乘以其输入的值。当在多层上执行此操作时，网络能够将数据转化为某种有用的形式。

“深度学习”这一术语的提出，旨在让我们的神经网络拥有更多的隐藏单元。同样，可用的不同类型神经网络的数量也在增长。循环神经网络、卷积神经网络和长短期记忆网络只是几个流行的模型。

深度学习至关重要，原因之一是：它使我们能够在现实场景中获得实质性的、实用的精度。机器学习也已用于分类文本和图像数十年，但它最终突破了障碍——即算法必须满足特定准确度水平才能在商业场景中运行这一要求。

DL使企业应用更可行的任务的一个好范例是计算机视觉。DL在对照片进行分类和标记方面不仅优于任何其他传统方法；它也开始超越实际的人类。

## 1.2 深度学习在医疗保健中的应用

医疗保健行业现在可以以极快的速度检查数据，同时保持精确的准确性。深度学习在医疗保健领域有许多优势，包括快速、高效和精准。在发现新药物组合方面，深度学习至关重要。在疫情爆发期间，人工智能及其子集深度学习等颠覆性技术被用于支持疫苗和药物的开发。由于药物开发是一项艰巨的任务，深度学习可以帮助使其更高效、更具成本效益、更简单。深度学习算法可以预测药物特性、预测药物-靶点相互作用，并生成具有理想特性的分子。深度学习算法可以快速处理基因组、临床和人群数据，并可使用多种工具包来发现趋势。研究人员现在可以利用深度学习和机器学习进行更快的分子建模和预测分析，以确定蛋白质结构 [[1](#ch1.xhtml#ref1_1)]。

X光、MRI扫描和CT扫描等医学图像可用于训练深度学习模型。在医学图像中，算法可以检测风险并标记异常。深度学习常用于癌症检测。得益于图像识别，通过MRI成像和X光进行的癌症检测已超越人类准确度标准。其他常见的医疗相关应用包括药物发现、临床试验匹配和基因组学 [[12](#ch1.xhtml#ref1_12)]。

临床试验耗时且昂贵。利用深度学习和机器学习的预测分析可用于寻找潜在的临床试验志愿者，并允许科学家从多个数据点和来源汇总人员。深度学习还将允许在最少人工干预和错误的情况下进行持续的试验监测。

利用深度学习模型，更容易调查患者的健康数据、病史、生命体征、医学检查结果和其他信息。因此，医疗服务提供者能够更好地诊断每位患者并为其提供个性化治疗。机器学习模型可以利用深度神经网络预测未来的健康问题或风险，并利用从连接设备收集的实时统计数据提供适当的药物或治疗 [[11](#ch1.xhtml#ref1_11)]。

过去几年来，人工智能（AI）、语义计算和机器学习逐渐渗透进医疗行业。这些技术知识相互关联，为行业带来了新事物，并改变了医疗专家执行任务和提供患者护理的方式。它们有能力通过增加新层来影响医疗技术解决方案。

## 1.3 医疗保健系统中的人工智能

随着数据量的增长，人工智能（AI）在医疗保健系统中被广泛使用。这包括诊断和药物推荐、患者参与和行政事务。在许多环境中，AI可以比人类更好地执行各类职责，但实施其功能可能需要更多时间。

人工智能（AI）及相关技术在商业和社会中变得非常普遍，并成功进入医疗保健领域。这些技术有能力在患者护理以及许多其他医疗机构中产生巨大变化和影响 [[2](#ch1.xhtml#ref1_2)]。

在分析恶性癌症和咨询方面，研究人员能够检测临床试验中的早期迹象；算法此前已超越放射科医生。

例如，在放射学领域，Aidoc开发了算法以加速患者诊断和治疗。颅内出血、肺栓塞和颈椎骨折算法允许系统对需要医疗关注的个体进行优先排序。这种AI和深度学习的应用通过揭示潜在问题，协助繁忙的放射科医生，使医疗从业者能够更好地管理和引导患者。通过与工作流集成，它还扩大了对关键患者数据的访问，同时减少了文书工作。
