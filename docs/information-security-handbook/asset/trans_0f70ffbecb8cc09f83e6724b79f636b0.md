

4. **存储层级：** 它在基于闪存的存储设备上工作，并可通过缓冲区管理策略实现，勒索软件活动可通过同一位置上的读写痕迹发现。Ex: ID3, SSD。

5. **API 调用监控：** GURLS 是 API 调用监控的一个示例；它使用基于该特性的方法，即 API 调用的频率和字符串。

6. **在 Android 设备中：** 它使用混合方法，其中静态分析和动态分析用于攻击设备的勒索软件。静态分析关注操作码，动态分析关注内存；通过从执行日志中提取数据来完成。

作者 \[7\] 使用带有学习算法的勒索软件检测技术。这可以从 [图 9.6](#ch09.xhtml#fig9_6) 中理解。当使用学习算法时，第一个标准是使用不同的算法选择特征并创建最优特征集。然后，使用此最优模式进行训练和测试；学习开始，并且可以通过不同的方式完成，例如监督学习和非监督学习。监督学习算法使用勒索软件数据样本作为训练集，并识别勒索软件与正常数据的模式以区分两者。非监督学习输入未标记的数据集，并尝试发现模式并构建模型。

## 9.2 相关研究

本节详细介绍了用于防止和检测攻击的技术方法。作者说 \[[8](#ch09.xhtml#ref9_8)\] 它使用强大的加密算法和密钥结构，但这并不是这种勒索软件攻击的唯一品质。它还建议整合由影子经纪人投放的黑客技术。换句话说，WannaCry 是各种一起运行并攻击系统的模块的组合。作者通过彻底的恶意软件分析，识别恶意二进制文件，然后从该恶意数据中收集模式；然后保存数据，并通过指标了解受损情况。它还报告调查结果，以制定未来应对攻击者的策略。作者 \[[9](#ch09.xhtml#ref9_9)\] 试图使用预定义规则开发一种通用检测方法。作者使用主成分分析提取流量特征，所有恶意内容在攻击过程中都可以轻松与正常流量区分开来。在本文中，作者使用 CWDR（全面 WannaCry 检测规则）规则集经历了八个阶段来检测 WannaCry 攻击。在 [图 9.7](#ch09.xhtml#fig9_7) 中，我们了解了保护策略，通过该策略可以保护系统免受 WannaCry 攻击。

作者 \[[10](#ch09.xhtml#ref9_10)\] 引入了网络杀伤链的概念。如果攻击者想要执行攻击，对手必须走的一条路径。杀伤链中的每个环节都起着至关重要的作用，如果链条断裂，攻击就永远不会发生。通过移除其中任何一个条件，可以削弱勒索软件。这些条件由作者在论文 \[10\] 中指定，如下所示：

**条件 1：** 进入和执行是第一个条件；这意味着攻击者试图进入主机系统以开始感染系统。

**条件 2：** 此条件尝试生成唯一的随机整数，并用于生成加密密钥。

**条件 3：** 成功勒索是第三个条件，它使用解密密钥。

**条件 4：** 要开始实际加密，需要修改权限。

**条件 5：** 勒索软件必须能够拒绝受害者访问关键文件，这需要对受害者的权限。

**条件 6：** 最后一个环节是功能性支付路径，受害者与勒索软件操作者之间存在一条路径。

因此，作者提出了具有五个核心功能的 NIST 网络安全框架。WannaCry 不是唯一一种勒索软件攻击类型；还有一种称为 Petya 勒索软件攻击 \[[11](#ch09.xhtml#ref9_11)\]。Petya 攻击家族包含各种其他攻击，如 PetrWrap 和 NotPetya。这种攻击的概念是修改 Windows 系统主引导记录，这可能会导致系统崩溃。Petya 使用加密密钥，即 AES-128 与 RSA；文件可以在不重新加载系统的情况下被加密，Petya 还使用命令通过远程访问 Windows 管理指令。

到目前为止，我们了解了勒索软件攻击类型检测策略，但勒索软件攻击的起源始于网络安全和恶意软件检测概念出现之时。这些是不仅检测勒索软件，还检测其他类型攻击的领域。作者 \[[12](#ch09.xhtml#ref9_12)\] 描述了网络安全中使用的关键基础设施。NIST 提供的框架中的重要功能如下：

1. **识别：** 识别各种网络资产，以及该资产暴露的风险分析；此外，它涉及对人员和设备进行强加密身份验证。

2. **保护：** 此功能定义为用于访问控制、防御、区域划分、经过身份验证的通信等的保护机制。

3. **检测：** 检测是一种功能，要求进行恶意软件检测、入侵检测、渗透测试和漏洞评估。

4. **响应：** 当攻击发生或被激活且攻击被检测到时，此功能开始工作。然后第一项任务是控制攻击造成的当前和未来损害。这可以通过定位和遏制来完成。

5. **恢复：** 当有人想要在攻击发生后恢复数据或文件，以及通过改进响应功能的更好检测策略规划时，会调用这些功能。

在本文中，\[[13](#ch09.xhtml#ref9_13)\] 作者说恶意软件检测系统依赖于通过分析技术明显的恶意软件区别提取特征。各种分析技术在静态和动态工具上工作。提取特征后，系统必须通过恶意软件分类器进行训练。

1. **静态恶意软件分析：** 它基于特征提取的概念，不获取恶意软件样本。静态特征通过不同的分析函数提取，如哈希值、操作码、字符串和 N-grams。

作者 \[5\] 使用加密勒索软件 STATIC，它获取二进制输入然后生成库。这些文件是 DLL。存在各种静态工具：PeView、PEid、CFF Explorer、Psfile、Accesschk。通过 [图 9.8](#ch09.xhtml#fig9_8)，我们了解静态恶意软件分析的工作原理。

2. **动态恶意软件分析：** 它在运行时工作，这意味着恶意软件文件被执行，在运行时可以捕获恶意软件的活动。它基于恶意软件与计算机系统的交互。创建了一个虚拟环境，称为 VMware。恶意软件在一个环境中运行，通过创建、删除和新日志条目来检测它；基于此运行活动，该文件被视为损害系统的文件。一些未经静态分析正确检查的文件可以用于动态分析。
