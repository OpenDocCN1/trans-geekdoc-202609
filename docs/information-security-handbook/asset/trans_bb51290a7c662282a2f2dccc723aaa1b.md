

Nimisha Ghosh 等人（2017）针对无线同质传感器网络提出了一种节能路由方案，并使用了移动收集器 \[[20](#ch03.xhtml#ref3_20),[21](#ch03.xhtml#ref3_21),[22](#ch03.xhtml#ref3_22),[23](#ch03.xhtml#ref3_23),[24](#ch03.xhtml#ref3_24),[25](#ch03.xhtml#ref3_25),[26](#ch03.xhtml#ref3_26),[27](#ch03.xhtml#ref3_27),[28](#ch03.xhtml#ref3_28),[29](#ch03.xhtml#ref3_29),[30](#ch03.xhtml#ref3_30),[31](#ch03.xhtml#ref3_31),[32](#ch03.xhtml#ref3_32)\]。粒子群优化（PSO）和蚁群优化（ACO）等遗传算法被应用于结果优化。主要思路是使用模糊逻辑从网络中的簇中选择簇头。移动收集器从这些簇头收集信息并将其传输到汇聚节点。LEACH 路由协议得到了改进，不再在每一轮中选择簇头，而是按需选择。这种按需选择将减少早期做法中每轮产生的开销。此处用于模糊逻辑的语言变量包括节点度、丢包概率和节点中心性。基于这些变量，计算节点成为簇头的概率值。PSO 用于优化隶属函数，以获得更好的范围输出（概率）。

## 3.3 拟议工作

拟议技术旨在通过改进网络性能参数和分组投递率来优化网络效率，从而优化网络能耗。神经模糊逻辑用于帮助选择合适的簇头。拟议工作的算法如下：

步骤 1. 读取节点总数和初始能量。

步骤 2. 将簇和簇头初始化为 1。

步骤 3. 检查节点的能量值是否发生变化/更新。

步骤 4. 对网络中的所有节点形成簇。如果满足能量约束，则检查此条件 `c(i)<=(P/(1-P*mod(r,(1/P))))` 并增加候选簇头计数。这里 `c(i)` 是每个节点在 0 到 1 之间的随机值，`P` 和 `r` 分别是簇头概率和迭代次数。

步骤 5. 存储簇头 ID 和能量，并计算到基站的距离。

步骤 6. 使用 `1-(10*log10(distance.^error_rate))` 计算每个候选节点的分组丢失，这里 `distance` 是候选簇头与簇中其他成员之间的距离。

步骤 7. 将所有选定的候选簇头的输入能量、到汇聚点的距离和分组丢失值输入模糊模型。

步骤 8. 用训练数据检查测试数据（输入神经模糊模型的簇头参数）。如果需要输出，则通过调整能量和距离来训练参数。

步骤 9. 计算最小距离路径以执行路由。

步骤 10. 检查所需结果。
