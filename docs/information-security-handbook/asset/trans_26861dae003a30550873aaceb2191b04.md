

这是一个无处不在计算的时代，数字设备已成为企业和机构不可或缺的工具，这导致各种系统、行业和组织活动中的信息无处不在；因此，将信息作为资产进行保护是必要的。这必须针对信息被剥夺、亵渎、破坏、泄露和滥用的风险 \[[1](#ch10.xhtml#ref10_1)\]。在数字技术趋势方面，信息在无限增长，每种类型的业务都需要竞争性工具来构建安全系统，以防止信息泄露到外部世界并保护商业世界的整个社会 \[[2](#ch10.xhtml#ref10_2)\]。有必要构建一个强大的安全结构，该结构应对组织的安全系统有效。鉴于所有这些要求，设计了一个适当的系统以满足数字环境的需求，以保护数据和信息 \[[3](#ch10.xhtml#ref10_3)\]，这被称为安全管理系统（SMS）。在本节中，我们将回顾信息安全的基本概念，专门讨论信息的安全管理系统，并讨论如何利用安全管理系统技术来应对相关风险。在这方面包含的所有批评和复杂性将进一步解释。

## [10.2 企业中的信息安全应用](#ch10.xhtml#c_sec10_2)

信息安全是通过评估信息风险，对各种规模的企业（从中小企业到大型企业）的信息采取安全措施并合理保护的方式。事实上，这对许多组织来说一直是一个更大的挑战。此外，信息安全已成为一项现有的风险管理流程，涵盖所有需要保护的信息 \[[4](#ch10.xhtml#ref10_4)\]。信息安全和计算机安全术语被错误地互换使用，但它们在利用保密性、完整性和可用性等共同目标来保护信息免受外部世界影响的方面也是相互关联的。因此，它们之间存在细微差别，例如，信息安全涉及信息的保密性、完整性和可用性（CIA），无论其现有形式如何，包括印刷品和电子形式（如 [图 10.1](#ch10.xhtml#fig10_1) 中所述）。计算机安全的基础是确保计算机系统的便捷运行和访问，与当前的信息处理无关。虽然信息安全主要关乎敏感数据的干净访问和保护，此外，合法性、快速响应性、可靠性、有效性以及信息的确定性和确定性等其他特征也可以归类为保护范畴。

### [10.2.1 信息安全组件：保密性、完整性、可用性（CIA）](#ch10.xhtml#c_sec10_002_001)

研究发现，现代组织未能遵循信息安全的良好治理原则，特别是遵守信息安全和监控政策，这主要是由于资源和专业知识有限 \[5\]。为了保护敏感信息，组织需要建立潜在的先决条件，旨在指导企业内的信息安全政策。

#### [10.2.1.1 保密性](#ch10.xhtml#c_sec10_002_001_001)

在信息安全方面，术语 `confidentiality` 与一组规则相关，这些规则旨在限制信息访问 \[5\]。它确保只有授权的信息和授权人员才能访问信息，并禁止未经授权的人员持有信息。换句话说，我们将保密性视为隐私。保密性通过多种方法实现，例如用户 ID 和密码、访问控制列表以及基于策略的安全性 \[[6](#ch10.xhtml#ref10_6)\]。在网上银行中，账户号被作为保密性方法的示例。此外，在网络中，数据加密是认证保密性的标准方法。虽然用户 ID 和密码是典型程序的账户，但双因素身份验证过程在发挥酌情权方面起着作用 \[[7](#ch10.xhtml#ref10_7)\]。其他一些程序也共享一些谨慎行动，包括生物特征验证和软件令牌。

#### [10.2.1.2 完整性](#ch10.xhtml#c_sec10_002_001_002)

完整性旨在确保信息在合法检索时未被更改，并且预期用途得到真正遵守。它旨在认证信息格式未被篡改，并且被感知的方式与创建者建议用户拥有的方式一致 \[[8](#ch10.xhtml#ref10_8)\]。完整性与信息的可靠性相关，即使存储在因果系统、仓库和数据库等中。它必须由公认的过程进行改革，并通过文件权限和访问控制进行保护。组织中使用一些安全机制来执行完整性，这些机制包括数据加密和哈希。许多工具实现了“单向哈希”。例如，当数据要传输到接收方时，特定数据的哈希值也会计算并随原始消息/数据一起传输。当接收方接收到数据时，哈希消息与接收到的哈希值进行比较 \[5\]。如果两者相同，则数据处于原始格式；否则，它已失去其价值。有时，数据会因非人为事件（例如服务器崩溃）而被修改。为了避免这些更改并恢复原始性，必须已经观察到冗余系统和备份程序，以便确保数据完整性。

#### [10.2.1.3 可用性](#ch10.xhtml#c_sec10_002_001_003)

任何组织的效率都取决于其服务，这些服务应随时可供其授权人员使用。CIA 三元组中的可用性确保在需要时数据和信息能够随时顺利地提供，并在适当的时间范围内 \[5\]。这个时间范围对不同的公司/行业意味着不同的事情；有些公司无法承受一天 24 小时中哪怕一秒钟的崩溃或不可用，而有些公司如果网站偶尔中断几分钟也无所谓。可用性通过一些方法来实现，例如硬件维护、网络优化和软件补丁/升级。有时，硬件问题显然会发生；在这种情况下，RIAD \[7\]、故障转移、冗余和高可用性集群被用来缓解重大影响。分布式拒绝服务（DDOS）攻击 \[[9](#ch10.xhtml#ref10_9)\] 是旨在使相应服务瘫痪并从而推翻可用性的恶意行为 \[[10](#ch10.xhtml#ref10_10)\]；在这种情况下，硬件系统可以防止停机和数据不可访问。任何自然灾害或人为灾害都可能导致可用性受到破坏。对于上述情况，公司通常尝试设计容错系统，其中包括冗余系统和驱动器等。

组织中应提供各种工具来认证材料的保密性、完整性和可用性。因此，可以利用这些工具来观察信息安全程序。例如，身份验证、访问控制、加密、备份、防火墙和虚拟专用网络等 \[5\]。
