

# 数据聚合与无线传感器网络

特定情境下的数据组合由无线传感器网络（WSNs）中的数据聚合所涉及。聚合的主要目标是通过减少资源消耗（如电池电量或带宽）以及传输数据包来延长网络寿命。此外，数据聚合过程还会影响服务质量要求，包括数据准确性、延迟、容错性和安全性 \[[7](#ch01.xhtml#ref1_7)\]。由于 WSNs 的广泛应用，需要围绕数据聚合采用节能程序。因此，节能程序和算法的应用发挥着重要作用 \[[8](#ch01.xhtml#ref1_8),[9](#ch01.xhtml#ref1_9)\]。

数据聚合通过一种广为人知的方法实现，即在多个集群中对传感器节点进行分类，并在每个集群中选择一个簇头（CH）来聚合任务。簇头通过轮换节点来确保节点之间的负载分布。最近，聚类协议受到了多位研究者的广泛关注。一种称为聚类的高效方法提高了可扩展性和负载平衡，并延长了 WSN 的寿命 \[[10](#ch01.xhtml#ref1_10),[11](#ch01.xhtml#ref1_11)\]。此类方法假设节点将相应数据发送到基站（BS）；然而，由于长距离数据传输，这是一种能源效率低下的方法。为了解决此类问题，某些节点允许在多个跳数中依赖相应数据向基站传输 \[[12](#ch01.xhtml#ref1_12)\]。由于某些控制数据包用于路由构建并被重传，此阶段存在一定的电力浪费。

无线传感器节点是智能基础设施的重要因素，具有结构更简单、成本更低且适合广泛部署场景的特点。因此，它完成了智能电网监控的实现 \[[13](#ch01.xhtml#ref1_13),[14](#ch01.xhtml#ref1_14),[15](#ch01.xhtml#ref1_15)\]。智能电网、环境监测、监控操作、家庭和工业自动化 \[[16](#ch01.xhtml#ref1_16),[17](#ch01.xhtml#ref1_17),[18](#ch01.xhtml#ref1_18)\]，以及包括移动社交网络在内的社交网络 \[[19](#ch01.xhtml#ref1_19),[20](#ch01.xhtml#ref1_20),[21](#ch01.xhtml#ref1_21)\]，是 WSNs 的各种应用。网络中包含处理能力、数据存储和无线传输资源受限的小型传感器 \[[22](#ch01.xhtml#ref1_22),[23](#ch01.xhtml#ref1_23)\]。受限能量是 WSNs 的重大限制 \[[24](#ch01.xhtml#ref1_24),[25](#ch01.xhtml#ref1_25),[26](#ch01.xhtml#ref1_26)\]。在各种实现中，能量补充在实际和可行性上都不切实际。设计一个寿命更长的节能应用系统是复杂的 \[26,[27](#ch01.xhtml#ref1_27)\]。已对 WSNs 中的路由算法优化 \[[28](#ch01.xhtml#ref1_28)\]、数据融合 \[[29](#ch01.xhtml#ref1_29)\]、MAC 优化 \[[30](#ch01.xhtml#ref1_30)\] 以及结合多个层级的跨层优化技术进行了大量研究 \[[31](#ch01.xhtml#ref1_31)\]。MAC 优化被归类为重要方法之一。著名的 MAC 优化方法通过周期性地关闭传感器节点的工作单元 \[31,[32](#ch01.xhtml#ref1_32),[33](#ch01.xhtml#ref1_33),[34](#ch01.xhtml#ref1_34),[35](#ch01.xhtml#ref1_35)\] 来实现。在关闭（睡眠）模式下，工作单元的能耗比工作（活动）状态低一个数量级。节点必须保持在睡眠状态更长时间以节省能量。

# 提议的 SC-MCHMP 协议

提议的 SC-MCHMP 协议通过引入多个有效参数（如节点 ID、剩余能量水平、距离、延迟、RSSI（接收信号强度指示器）、RDR（剩余传输比率）和节点的 ETX（预期传输次数））来增强路由协议的转发节点选择方法，从而选择合适的转发节点。基于上述参数，协议为每个传感器节点估计并分配一个分数。分数是描述传感器节点稳定性的因素。节点的高分表示该节点具有高稳定性。剩余能量、邻居之间的距离、节点延迟和 RSSI 是可以通过交换路由协议的控制数据包直接从节点提取的主要参数。RDR 和 ETX 等参数在运行时估计，并根据节点数据传输进行评估。这些估计值随后进行交换，并最初与 1 跳邻居节点进行比较，相应地更新节点的路由表。在数据传输期间，节点交换表信息并计算用于分数计算的邻居当前值。

* 我们为 WSNs 提出了一种优化协议，以提高 QoS 并改善网络能源优化。
* 提议的协议在降低网络开销的同时实现了高数据传输率。
* 使用提议的协议，网络端到端延迟可降低高达 60%。
* 提议的协议将传感器节点的能量耗散水平保持在非常低的水平。
* 该协议通过使用多个有效参数选择合适的邻居来改进转发节点选择过程。
* 使用混合 MAC 协议可确保无碰撞的数据传输，即使在突发流量中也是如此。

## 1.2 文献综述

引入了各种聚类方法，用于在节点之间分配负载以及应对能源受限问题。该领域中一个重要的经典分布式程序是 LEACH \[[36](#ch01.xhtml#ref1_36)\]。该方法包括设置阶段和稳态阶段。在设置阶段，每个节点都尝试以一定概率成为簇头。在稳态阶段，每个簇成员将感知数据传输到相应的簇头。随后，每个簇头在数据聚合过程中将数据传输到基站。电池电量较少的节点有机会担任簇头角色，这是因为每个节点成为簇头的机会是独立地取决于概率值。因此，它不能确保簇头的合适分布。

LEACH 的应用被用作提出改进方法（如 LEACH-C \[[37](#ch01.xhtml#ref1_37)\]、集中式聚类算法以及 LEACH-E \[[38](#ch01.xhtml#ref1_38)\] 和 LEACH-B \[[39](#ch01.xhtml#ref1_39)\] 分布式聚类程序）的标准，这些方法借助节点的剩余能量和各种相关标准来专注于降低能耗。作者在 \[[40](#ch01.xhtml#ref1_40)\] 中以均匀尺寸组织了网络。每个簇包含一个簇头、下一个簇头和一组传感器节点。根据传感器节点接收到的数据选择簇头，并由基站将网络划分为簇。为创建一组剩余能量高于阈值的合格继任者，以便在下一级担任簇头的任务。此方法使传感器节点拥有额外的电源维护。
