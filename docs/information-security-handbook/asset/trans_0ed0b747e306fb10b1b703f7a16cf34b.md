

特征选择和分组方法需要考虑各种因素，例如 IDS 的类型、攻击类型、用于测试的数据准备以及训练目的。并非所有特征在攻击检测过程中都有用，因为存在冗余，且某些特征可能因未参与攻击检测而无用。特征选择有助于提高 IDS 在复杂性和成本方面的性能。在未来的工作中，将研究在应用层实施区块链，以结合基于网络的入侵检测系统来检测应用层和网络层攻击。
