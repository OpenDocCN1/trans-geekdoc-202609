## 7.1 引言

当前攻击者正在磨练其欺骗技术，利用混淆技术开发稳定的恶意软件，以避免被检测并增强其破坏能力。大多数恶意软件攻击都是通过常用文件（如照片、PDF、电子表格和其他文件）进行的，攻击者会在这些文件中引入恶意代码。入侵者需要了解某些良性文件的结构，才能将危险代码与良性文件合并。将恶意软件嵌入这些日常使用的文档中有三个关键优势。第一个优势是大多数人依赖 PDF 文件，这可能增加对人们进行社会工程攻击的机会 \[[1](#ch07.xhtml#ref7_1)\]。第二个优势是大量用户正在使用过时的技术和应用程序，使他们容易受到此类攻击 \[[2](#ch07.xhtml#ref7_2)\]。软件中的漏洞可以被利用来构建成功的恶意软件，从而防止被检测。受害者使用过时和不安全软件的程度越高，其系统的恶意软件感染生命周期就越长 \[[3](#ch07.xhtml#ref7_3)\]。许多研究人员表明，自学习策略可以用于提高检测系统的检测技能和性能。例如，可以将系统视为一个孩子，将输入系统的数据视为在学校教给孩子的章节。攻击者的主要目标是破坏系统，而在我们的示例中，则是让孩子在评估中不及格。因此，为了实现这一结果，攻击者可能会尝试向系统输入非法数据，或者提供精心设计的输入来迷惑系统。在示例中，讲师可能会尝试用不当数据教孩子，甚至在考试时给出复杂的问题来让孩子不及格。输入不当数据可以被视为投毒攻击，而在评估过程中出现棘手问题的过程可以被称为规避攻击。大多数关于自学习检测技术的研究表明，这些方法能够准确识别和分类掺杂隐藏恶意软件的文件 \[2\]。关于对这类检测系统进行规避攻击的研究表明，向这些系统输入精心制作的输入可以击败它们 \[2\]。例如，向清晰图像添加扰动，就能导致机器学习图像识别系统将其误分类。

在本文中，我们将讨论不同作者提出的各种基于机器学习的 PDF 分类器。由于便携式文档格式（PDF）文件轻便且便携性高，因此被大多数用户广泛使用。它是查看和共享数据的广泛继承格式，这使其成为黑客选择的感染载体。在这里，我们将讨论 PDF 结构以及通过创建对抗样本来逃避恶意软件 PDF 检测系统的不同方法。这些 PDF 检测器主要分为两种不同的类型：静态和动态。我们回顾了迄今为止提出的大多数 PDF 分类器，以了解这些检测器用于检测的机制。

## 7.2 PDF 文件的 X 射线

解析 PDF 的方式可能取决于用于操作或查看它的解析器类型 \[2,3,[4](#ch07.xhtml#ref7_4),[5](#ch07.xhtml#ref7_5),[6](#ch07.xhtml#ref7_6)\]。每个 PDF 文件中都有几个基本元素，对于 PDF 文件的表示至关重要 \[2\]。这些元素基本上分为两类：一般结构和文件内容 \[2\]。第一类包括关于文件中存储内容的信息 \[2\]。第二类描述了内容向访问文件的用户显示的方式 \[3\]。PDF 文件的一般结构可以被视为对象网络，其中每个对象都有不同的功能要执行 \[2\]。PDF 结构中有四个主要组件：头部、主体、交叉引用表和尾部。头部是包含一行文本代码的 PDF 部分 \[[7](#ch07.xhtml#ref7_7)\]。此内容以 % 符号开头，并指示 PDF 文档的版本。主体部分包含对对象的请求，这意味着 PDF 文档执行的操作。在这些项目中，有机会包含各种类型的混合文档类型，如图片和视频记录 \[2\]。事实上，甚至可执行的恶意代码也可以通过将它们呈现为主体部分中至少一个对象来嵌入 PDF 记录 \[2\]。在主体中声明的每个对象都是包含唯一编号的 PDF 记录片段，即其引用编号 \[2\]。引用编号在调用特定项目时可能很有用。每当需要了解一个项目时，都可以使用引用编号。在主体中声明的每个唯一对象都以捕获词标记“endobj”结束 \[3\]。通过交叉引用表，我们可以理解 PDF 的这一部分包含一个表。我们应该理解这个表的功能和作用 \[2\]。这个表通常包含关于 PDF 文档中不同对象位置的数据。它还告诉解析器从哪里开始解析过程 \[3\]。它在记录中使用“xref”标记表示，在其下方，我们可以看到不同的行，每一行都指示主体字段中引用的各个项目的引用。只有在交叉引用表中引用的对象才会在解析 PDF 记录时被解析 \[2\]。尾部字段描述了一些对记录翻译至关重要的基本组件 \[2\]。第一个项目的地址位于其中之一。它还包含与引用相关的元数据的引用 \[3\]。尾部字段的结束通过使用标记“%%EOF”来指示。这也意味着文件的结束，并向解析器发出停止其解析活动的信号 \[2\]。
