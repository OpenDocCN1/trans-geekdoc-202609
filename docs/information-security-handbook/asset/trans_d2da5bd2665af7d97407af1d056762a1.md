

# Big Data Overview

首先，人们普遍认为，大数据描述的是巨大的数据集，需要创新的分析方法才能充分利用它们并创造出新颖且创新的价值形式。大数据的广泛性并非源于绝对的规模或大小，而是关于研究和分析的适当规模。由于这是一个在学术界和工业界各个领域都被广泛使用的术语，研究人员以多种方式对其进行了定义。Sagiroglu \[[1](#ch04.xhtml#ref4_1)\] 将大数据与数据集的容量相关联，认为大数据是大规模数据集的表达，这些数据集具有庞大、更多样化以及复杂的结构，伴随着分析、存储和可视化数据以进行进一步处理和得出结果的复杂性。Van Dijck \[[2](#ch04.xhtml#ref4_2)\] 提出的另一种定义将大数据描述为社会行动向在线可测量数据的转变，这随后允许进行预测分析和实时跟踪。他们鼓励构建更可靠、更准确的预测，以解决从气候变化到恐怖主义活动等复杂而错综复杂的问题 Kitchin \[[3](#ch04.xhtml#ref4_3)\]。此外，大数据还体现了企业和国家机构在大量信息积累方面面临的行政挑战。Bekker \[[4](#ch04.xhtml#ref4_4)\] 将大数据描述为具有信息特征的数据，例如统计正确性和事件日志的性质等，并且这要求诸如并行处理、分布式存储和简单的解决方案可扩展性等技术需求。作者进一步全面描述了每个特征，认为传统数据随时可能发生变化；例如，银行账户、仓库中的产品数量等，而大数据描述的是表示某些事件的每条记录的日志，例如，网页浏览、商店中的购买活动、随时间变化的传感器值、社交媒体评论等。大数据的这种特性允许事件数据不发生变化。虽然大数据被认为在统计上是正确的，但它可能包含错误或遗漏，这就是为什么它不被认为是需要绝对准确性的任务的良好选择。作者强调的大数据的另一个属性是由于其容量而产生的技术要求；它需要并行处理，高存储容量需要特殊的存储方法。

Andrea \[[5](#ch04.xhtml#ref4_5)\] 确定了与大数据相关的核心主题，即信息、方法、技术及其影响。他们引用了关于大数据术语的各种解释，并检查它们是否包含上述主题。信息可以被视为大数据存在的根本原因之一，因为其生成和可用性为大数据提供了燃料。大数据中的信息催生了一个名为“数据化”的新术语，旨在将模拟信号组织成数字形式，以产生否则无法推断的洞察。技术经常与大数据相关联，允许其利用，例如 Hadoop \[[6](#ch04.xhtml#ref4_6),[7](#ch04.xhtml#ref4_7)\]。在相对较小的机器上高效存储大量数据的能力是技术应用于大数据的基本要素。因此，可以说技术是处理大数据的核心设备。对定量数据的广泛分析以及从个人行为中获取价值的必要性需要处理技术和方法；因此，方法将大数据转化为资产。大数据分析的利用不仅允许高效且恰当地管理数据，还帮助将此类数据纳入决策过程。对这些方法以及技术、其优势和劣势以及文化倾向的认识，传播开来以促进明智和智能的决策，正如大数据所要求的那样。它对我们社会造成的影响程度通常通过技术和实施方法的成功故事和轶事来描绘。这些故事结合新颖的原则和程序发展，对某一主题的知识创造做出了宝贵贡献。如果信息可用性和生产的普遍性导致跨越多个科学领域的大量应用，那么它也对社会产生不利影响。由于大数据的发展而产生的主要关切包括：隐私问题、信息可访问性问题等；因此，影响是大数据的一个核心主题。作者 \[5\] 然后将定义分为几组，第一组完全专注于列举大数据的特征。在这一组中，Laney \[[8](#ch04.xhtml#ref4_8)\] 提出了一个框架，表达了数据在三个维度上的容量、多样性和速度的增加；该框架后来被称为大数据的三个 V。该模型后来被扩展到价值 \[[9](#ch04.xhtml#ref4_9)\]、真实性 \[[10](#ch04.xhtml#ref4_10)\]、变异性 \[[11](#ch04.xhtml#ref4_11)\]、粘度 \[[12](#ch04.xhtml#ref4_12)\]、传播性 \[12\] 和有效性 \[[13](#ch04.xhtml#ref4_13),[14](#ch04.xhtml#ref4_14)\]，下面将详细描述。另一组从处理海量数据背后的技术要求来定义大数据。其余的定义将大数据与超过某些阈值相关联，例如当数据超过传统数据库系统的处理能力时，则可以将其称为大数据。作者 \[5\] 在以前定义的基础上提出了一个结论性定义；它指出大数据是信息资源的一种表现，其特征是高速度、容量和变化，需要特定的分析过程和技术将其转化为价值。总而言之，大数据仅仅是一种转换，其中数据被处理为信息，信息被处理为知识，知识转化为智慧和价值，如 [Figure 4.1](#ch04.xhtml#fig4_1)（大数据转换）所示。

## 4.1.1 Volume – 数据的容量

海量的容量是使数据变得“大”的主要商标。如果我们将大数据视为一个金字塔，容量无疑是基础。它指出每秒从手机、社交媒体、M-2-M 传感器、信用卡、视频、照片等产生的海量数据。当前的数据量可能非常惊人。考虑几个例子：

*   在 Thomas Reuter 于 2010 年编制的一份年度报告中，他分享了他对世界数据量的估计，超过 800 EB，并且仍在进一步增长。2012 年，硬件公司 EMC 声称世界数据量为 99 EB，并预测其增长率每年为 50%。

*   截至 2019 年 5 月的统计数据显示，每分钟有多达 500 个视频上传到 YouTube。

*   2018 年拍摄了超过一万亿张照片，并且预计该数字在当前年份将上升 7%。
