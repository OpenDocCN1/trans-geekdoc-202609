

## 5.1 引言

网络安全被认为是信息安全的主要组成部分，因为它负责在网络之间传输安全信息，并保护机密信息免受未经授权的访问。随着网络用户及其交易的迅速增加，对网络安全系统的需求也在不断增长。某些网络入侵攻击可能导致跨网络的服务不可用。此类攻击被称为拒绝服务攻击（DOS）\[[1](#ch05.xhtml#ref5_1)\]。在客户端/服务器环境中，服务提供商因服务不可用而导致合法客户端无法获得服务是主要问题。拒绝服务（DOS）攻击的一种变体是分布式拒绝服务（DDOS）攻击。在 DDOS 攻击中，入侵者从多个位置而非单一位置发起攻击，如 [图 5.1](#ch05.xhtml#fig5_1) 所示。入侵者最初会控制本地系统。此类受感染的系统被称为主控系统或处理器。主控系统随后会与更靠近目标服务器的进一步受攻破系统进行交互。多个 DDOS 代理的攻击综合效果会产生成千上万的请求，从而使服务器不堪重负。在这种情况下，服务器可能会变慢或崩溃 \[[2](#ch05.xhtml#ref5_2)\]。DOS/DDOS 攻击被认为是一种重要的网络攻击类型，可能在网络环境中造成各种挑战。以下是基于对文献和相关工作的深入审查后提出的问题陈述：

1. 重大问题是，一群人或自动化系统同时从多台计算机攻击一台服务器或计算机。这种大规模的数据流会导致服务器资源不足，从而导致服务器崩溃并停止工作 \[[3](#ch05.xhtml#ref5_3)\]。服务器计算机的资源被严重耗尽，即 CPU 利用率增加、内存过载问题以及带宽利用率增加等。

2. 带宽是计算机网络中的一种有用资源。带宽利用率 \[[4](#ch05.xhtml#ref5_4)\] 是在跨网络传输信息时的一个更重要因素。当网络中发起 DDOS 攻击时，带宽利用率增加可能会减慢网络中的流量或数据。

3. 有必要了解如何检测和预防 DOS/DDOS 攻击 \[[5](#ch05.xhtml#ref5_5)》，这些攻击会在网络中造成安全挑战。可以实施专家蜂窝网安全基础设施，以高效地在网络中检测和预防此类攻击。

本研究的主要目标如下：

* 在网络中实施专家蜂窝网安全基础设施。
* 制定模糊逻辑规则，并使用专家蜂窝网系统在网络中检测 DDOS 攻击。
* 提供更好的带宽利用率，并减少网络中 DDOS 攻击的发生。
* 通过软件仿真工具 DDOSSim 对所提安全基础设施进行性能分析。

### 5.1.1 DDOS 攻击类型

以下是客户端/服务器架构中常见的 DDOS 攻击类型。这六种可破坏网络流量的 DDOS 攻击在客户端/服务器环境中被观察到 \[[6](#ch05.xhtml#ref5_6)\]。此类攻击可能破坏网络。这些攻击如下所示 \[[7](#ch05.xhtml#ref5_7)\]。

1. 协议违规攻击
2. 分片攻击
3. 网络基础设施攻击

#### 5.1.1.1 直接洪水攻击

这些攻击是 DOS 攻击的简单版本。在这种情况下，攻击者通过从自己的系统发送数据包直接攻击受害者的网站。在这种攻击中，数据包的源地址可以被伪造。有许多工具可用于允许针对 TCP、UDP 和 ICMP 等协议进行此类攻击 \[[8](#ch05.xhtml#ref5_8),[9](#ch05.xhtml#ref5_9)\]。一些常用工具包括 hping2、synsend、synk7、synhose 和 stream2。在这种情况下，攻击者发送一个数据包，该数据包被目标计算机接收。

#### 5.1.1.2 远程控制网络攻击

在这种攻击中，攻击者将应用程序发送到目标系统，并破坏网络中的流量。计算机会监听来自中央计算机的命令。网络流量可以通过病毒自动或手动地被破坏。常用的控制通道包括直接端口通信、IRC 频道或 ICMP ping 数据包。僵尸机会以有组织的方式被动监听多个目标端口上的 TCP SYN 数据包。当来自任何特定 IP 地址的端口匹配时，会调用用户定义的函数 \[10,[11](#ch05.xhtml#ref5_11)\]。攻击者可以使用数据包头字段来获取有关 IP 地址和要运行及攻击系统的命令的信息。受攻破的计算机可以直接向目标发起攻击，或通过反射媒介发起攻击。在这种类型的攻击中，很难追踪原始控制系统。

#### 5.1.1.3 反射洪水攻击

在这种情况下，攻击者使用受害者的 IP 地址伪造源 IP 地址，并将其传输到中间主机。中间主机会向目标计算机的目标地址发送回复 \[[12](#ch05.xhtml#ref5_12),[13](#ch05.xhtml#ref5_13)\]。在反射攻击中，很难识别实际攻击者，因为数据包来自中间服务器。
