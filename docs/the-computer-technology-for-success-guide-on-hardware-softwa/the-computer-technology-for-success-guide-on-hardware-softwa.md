# 引言

计算机与信息技术是计算机信息科学系的一个辅修。对于很多人来说，信息技术（IT）基本上等同于当你遇到计算机问题时找的人。虽然这种观点并非完全错误，但它大大低估了这一关键职业领域的范围。

如果你希望更好地了解信息技术以及该领域的许多方面，那么你来对地方了。我们已经为你完成了调研，并与 IT 行业专业人士交流，了这份实用的入门指南。

信息技术（IT）是使用任何计算机、存储、网络和其他物理设备、基础设施和流程，来创建、处理、存储、保护和交换所有形式的电子数据。通常，IT 用于业务运营背景，而不是用于个人或娱乐目的的技术。IT 的商业用途涵盖了计算机技术和电信。

# 什么是信息技术？

计算机信息技术（CIT）是在组织内部使用和研究计算机、网络、计算机语言和数据库来解决实际问题。该专业为学生从事编程、网络、系统管理和互联网开发做准备。信息系统中学习的技术包括编程、网络、服务器管理、信息安全、数据库设计与开发、系统分析与设计以及 Web 开发。最基础的信息技术定义是应用技术在大规模范围内解决业务或组织问题。无论担任什么角色，IT 部门的成员都与他人合作解决各种大小不同的技术问题。

IT 部门有三个主要的责任支柱：

**IT 治理：** 这指的是政策和流程的结合，确保 IT 系统有效运行并与组织需求保持一致。

**IT 运营：** 这是 IT 部门日常工作的统称。这包括提供技术支持、网络维护、安全测试和设备管理职责。

**硬件与基础设施：** 这一关注领域指的是 IT 基础设施的所有物理组件。IT 的这一支柱包括路由器、服务器、电话系统和笔记本电脑等个人设备的安装和维护。

尽管组织的 IT 部门处理许多不同的功能，并在保持业务运行方面发挥着着性作用，但 Belitsoft 的 IT 负责人 Andrey Prokopchuk 表示，完美的 IT 部门是你甚至察觉不到的那一个。这意味着他们能够为许多日常任务实现自动化并创建流程，使业务能够顺畅运行。理想的 IT 部门还与业务目标保持一致，并在流程上保持透明，以便业务的其他部分能够理解并提供建议。

# 信息技术示例

涉及信息技术的职业路径时，示例从微型咨询公司到大型跨国公司不等，从高技术专业领域到需要强大人际技巧的管理阶梯。以下是一些你可能选择的路线示例：

- 计算机支持专家 – 这些职位需要学士学位，如果你喜欢回答有关计算机软件和硬件的问题、设置设备以及培训计算机用户，那么这些职位非常适合你。该职位的人员需要熟悉各种软件，包括数据库接口程序、环境工具开发和操作系统软件。根据美国劳工统计局（BLS），这份工作的中位年薪为 53,000 美元，该领域的增长速度快于平均水平。

- 网络和计算机系统管理员 – 这份工作通常需要计算机相关领域的学士学位，尽管某些雇主可能仅要求副科学学位或专科证书。无论如何，这些工作通常对没有该领域之前工作经验的人士开放，BLS 报告显示，2018 年的中位薪为 82,000 美元。该工作的日常任务可能包括维护计算机网络硬件和软件、备份数据和排除网络问题。要从事这项工作，你需要了解如何使用数据库管理软件以及网络监控和 Web 开发工具。

- 计算机网络架构师 – 这是网络管理员职业阶梯的提升，通常需要学士学位和 IT 领域的领域经验。该职位的人员设计并构建网络，例如内网、局域网（LAN）和广域网（WAN）。根据 BLS，2018 年此类工作的中位薪为 109,000 美元。网络架构师通常需要理解各种软件系统，包括管理工具、开发环境软件和操作系统。这项工作通常还包含人情味，因为网络架构师可能需要与客户以及销售和营销人员合作，满足客户需求并确保账户设置正确。

- 数据库管理员 – 这一快速发展的领域涉及财务信息和客户发货记录等数据的保护和安全。这些工作通常位于为其他公司服务的专业公司中，或保险等数据密集型行业。根据 BLS，2018 年这项工作的中位薪为 90,000 美元。大多数雇主期望该职位的候选人拥有信息或


计算机相关学科。理解数据库管理软件、操作系统工具、开发环境和网络平台软件以及企业资源计划工具也有帮助。

## 计算机系统分析师 – 这项工作也被称为系统架构师，要求对 IT（信息技术）和业务系统都有理解。与许多信息技术职业一样，该工作的典型背景是计算机或信息科学领域的学士学位，但也有人是在学习商业甚至文科之后后才从事这一工作。强大的计算机技能是必不可少的，通常包括编程工具、数据库管理软件和开发环境软件。同时，从事这项工作的人必须能够应用计算机系统解决工作流、库存控制和生产流程等业务管理问题。随着越来越多的企业转向云计算，该领域的工作将会增长。根据劳工统计局（BLS）的数据，2018年该工作的中位薪资为88,000美元。

## 信息安全分析师 – 这是 IT 领域增长最快的工作之一，根据 BLS 数据，预计到2028 年将增长32%。这些职位的人士负责保护公司网络和系统免受网络攻击。这些工作通常需要计算机相关专业的学士学位，并具备一些 IT 领域的经验。该领域的专业人士需要使用开发环境工具，以及网络监控、操作系统和特定的安全工具。根据 BLS 数据，2018 年该工作的中位薪资为98,000美元。

从这份列表中可以看出，IT 职位代表了高薪、快速增长的职业路径。同样明显的是，其中许多职业的第一步是获得学士学位。在高等教育的背景下，计算机科学主要侧重于编程和软件开发，而信息技术是对与业务运营相关的计算机系统和网络的研究。其中任何一种都可以成为在该领域获得卓越职业的基石。学生还可能选择专攻网络安全等特定的计算机相关领域，或者通过获得相关领域的硕士学位继续深造。无论你的具体路径如何，Leavitt 和 Whistler 在 1958 年看到的正在新兴的 IT 机会世界在今天仍在增长，且没有尽头。

## 信息技术包含什么？

“信息技术”一词已扩展到涵盖一系列技术和相关学科。IT 仍然由基于计算机的信息系统组成，包括计算硬件、操作系统（OS）、应用程序软件以及处理以产生有用信息的数据。随着时间的推移，这些 IT 组件和功能都变得越来越复杂，涵盖了不断增长的技术和方法论子集。例如，应用程序开发最初是一个相对线性的过程，系统分析师和程序员创建代码来实现业务目的。它现在已演变为一种更具合作性和有机的过程，体现了应用创建流程，例如 DevOps 和敏捷软件开发。即使是操作系统——让服务器和客户端计算机运行的基础代码——也承担了新的维度。可视化和容器化等技术已经打破（或至少改变了）操作系统与宿主机硬件之间的纽带。结果是，IT 不仅仅发生在本地；云计算环境现在补充甚至取代了传统数据中心的本地部署资源。所有这些发展都使 IT 变得更加复杂，并要求 IT 员工具备更高的专业化以及新的角色和职责。

## 为什么信息技术很重要？

简单来说，如果没有运行 IT 系统，大多数机构的工作将变得极其缓慢。你很难找到一家至少部分依赖计算机和连接它们的网络的企业。维持标准的服务水平、安全性和连接性是一项巨大的任务，但这并不是他们面临的唯一优先级或潜在挑战。越来越多的公司想要实施更直观、更复杂的解决方案。首席信息安全官兼技术博客 Edward Kiledjian 表示：“IT 可以为公司提供超越、领先于并交付优于竞争对手的产品所需的优势。”让我们来看看当前和未来的 IT 专家将处理的需求：

**数据过载：** 企业需要处理海量数据。数据需要大量的处理能力、复杂的软件和人类分析技能。

**云服务：** 大多数企业不再运营自己的“服务器场”来存储大量数据。许多企业现在与云服务第三方托管平台合作，由这些平台维护数据。

**视频托管的带宽：** 视频会议解决方案变得越来越，因此需要更多的网络带宽来充分支持它们。

## 软件

软件分为两类：系统软件和应用程序。
系统软件涵盖管理基本计算功能的计算机程序。它们包括：

- 操作系统 (OS)；
- 基本输入输出系统 (BIOS)；
- 启动程序；
- 汇编器；以及
- 设备驱动程序。

业务应用包括：

- 数据库，例如 SQL Server；
- 交易系统，例如实时订单输入；
- 电子邮件服务器，如 Microsoft Exchange
- Web 服务器，如 Apache 和微软的 Internet 信息服务 (IIS)；
- 客户关系管理 (CRM)，例如 Oracle NetSuite 和 HubSpot；以及
- 企业资源计划 (ERP) 系统，如 SAP S/4HANA。

这些应用利用程序指令来为了业务目的对数据进行操纵、整合、分散或其他其他方式的处理。

运行在智能手机、平板电脑和其他便携设备上的移动应用通常通过互联网连接云端或数据中心应用。这些应用扩展了计算范围，并创建了一类需要特殊专业知识来维护的新型软件和电信。

## 硬件

有许多不同的计算机硬件。计算机服务器运行业务应用。在客户端-服务器模型中，服务器与客户端设备交互。它们还通过计算机网络与其他服务器进行通信，这些网络通常连接到互联网。

存储是另一种类型的硬件。它是任何以数据形式承载信息的技术。存储可以是特定服务器上的本地存储，也可以在许多服务器之间共享，并可以安装在现场，也可以通过云服务访问。存储的信息可以采取许多形式，包括文件、多媒体、电话以及 Web 和传感器数据。存储硬件包括易失性随机存储器 (RAM) 以及非易失性磁带、硬盘驱动器和固态硬盘。

电信设备由网卡 (NIC)、电缆、无线通信和交换设备组成，将硬件元素连接在一起并到外部网络。

## 硬件与软件

你已经知道处理硬件和软件是 IT 部门工作的大部分内容，但什么算作硬件？什么是软件？让我们来详细区分这一重要区别。硬件包括计算机系统的所有物理部分。这包括安装在计算机内部的硬件，如主板、中央处理器和硬盘。硬件还描述可以连接到计算机外部的组件，如键盘、鼠标和打印机。但请记住，某些平板电脑和较小的笔记本电脑将键盘和鼠标等集成在设备内部。基本上，硬件是指任何与计算机及其网络相关的你可以物理触摸和操纵的部件、组件或设备。与硬件不同，软件不是你可以物理改变的东西。软件涵盖了所有电子形式存储的数据、应用程序和程序，例如操作系统或视频编辑工具。那么这种区别如何适用于 IT 职业呢？几乎每份 IT 工作都需要硬件和软件方面知识的结合。某些 IT 工作人员可能会花费更多时间在配置硬件组件上，但这些组件也受软件的控制。此外，IT 专业人员负责为用户部署和设置软件应用程序。

## IT 职业机会

现在你了解了 IT 部门的一般职责，你可能在好奇内部具体的角色是什么。以下你可以在许多 IT 部门中找到的一些职位：

计算机支持专家在前线工作，排除任何技术问题，包括软件问题、计算机崩溃和硬件故障。这些专家可能还会协助高级 IT 成员处理更大规模的网络问题。

网络系统管理员关注大局，即网络系统的整体和性能。

计算机系统分析师在幕后工作，将 IT 与业务解决方案相结合。他们通常在技术公司工作。

信息安全分析师负责组织计算机网络的安全，进行测试并开发公司范围的安全实践。

请记住，这些职位将根据公司规模而变化。在较小的公司，你的大部分日常工作将围绕打印机等平庸事务，但另一方面，你可能被要求更像一个全才。在大型公司，IT 员工拥有更多样化的关注领域，有些人可能会进入管理和战略规划职位，而另一些人可能会追求网络安全等专业领域。

# 信息技术与计算机科学

计算机科学家实际上是科学家。他们关注计算理论。这意味着他们理解计算机程序背后的“为什么”。利用算法和高级数学，计算机科学家发明了处理传输信息的新方法。计算机科学家通常关注软件、操作系统和实现。就像《矩阵》中的 Neo 一样，计算机科学家可以看到并理解代码。计算机科学的学生将学习不同编程语言的基础知识、线性和离散数学以及软件设计和开发。计算机科学家研究机器本身，并理解各种计算机过程之所以运作。简单来说，计算机科学家可以与计算机交流。该领域建立在数学（计算机的语言）的基础上。计算机科学家理解计算机如何工作，并可以创建一个实现你要求的程序或操作系统。

## 计算机科学职业

计算机科学是一个快速发展的领域，预计其就业机会将大幅增加。高薪通常与计算机科学职业相关。如果你正在攻读计算机科学学位，以下职业路径向你开放：

应用软件开发人员：作为应用程序和程序背后的创意大脑，软件开发者为计算机和技术设备设计并构建程序和应用程序。《愤怒鸟》？是软件开发者开发的。微软 Office？那是软件开发者开发的。软件开发人员的中位工资为 98,260 美元。

系统工程师：操作系统为计算机和设备运行提供基础。微软 Windows、Linux 和 iOS 是操作系统类型的示例。系统工程师为个人电脑、手机甚至汽车设计并创建这类系统。根据 PayScale 的数据，系统工程师的中位工资为 76,593 美元。

Web 开发人员：Web 开发人员不是图形设计师。图形设计师创建你在网站上看到的图像；Web 开发人员编写使网站运行的代码。Web 开发人员将图形、音频和视频集成到网站，并监控流量、性能和容量。





## 信息技术职业

从家庭作坊到跨国公司，在每一个层面上，企业都需要 IT。在未来十年中，IT 职业机会的增长预计将快于平均水平。根据您的教育程度，IT 学位可以为您提供一份丰厚的薪水。

# 信息和通信技术的缺点

## 人类可用就业机会的减少

当技术被用于企业的生产过程中时，组织会将技术视为更好的“员工”。工作不仅可以按时完成，而且某些过程可以自动化以方便操作。因此，软件工具有能力执行本属于人类员工的任务。这意味着，它们已成为人类的竞争对手，因为公司认为没有必要雇佣这么多的人来完成那些通过少数员工和智能软件就能完成的工作。

虽然这种对劳动力需求的减少对企业雇主来说可能是一个好消息，但对人类劳动者来说并不有利。当用技术取代人类时，企业经营认为雇佣他们没有意义。因此，失业率上升，社会上有更多的人在为维持生计和支付账单而挣扎。因此，公司理解如何雇佣人类劳动者而不是仅仅因为技术进步而将其解雇是非常重要的。例如，如果企业能够重新培训员工会更好，在培训后，员工应被重新分配执行其他角色并占据机器无法胜任的新职位。此外，要记住技术设备只有在由熟练的人类员工操作时才能发挥最佳作用。

## 技术进步使员工变得反社会

技术为个人之间的相互交流提供了渠道，而并不一定需要处于同一地区。这得益于 Skype 等多种通信工具。结果是，同事可以从世界不同的地方举行会议。

尽管这很美好，但问题在于人类的大部分通信已移至线上。与此同时，那些采用技术设备进行绝大多数通信的员工，正经历着社交技能的退化。个人行为发生了变化，因为他们习惯了花费大部分时间使用笔记本电脑和手机等技术设备。但企业可以做一些事情来解决这个问题。并不是所有的会议和通信都应该在线进行。企业主应该安排一年中的特定时期，让员工可以面对面会面和互动。

## 对技术设备的过度依赖

众所周知，技术设备在自动化复杂的企业流程方面非常有用。这对你的公司是极好的。然而，由于多种因素，所有机器都可能在任何时候故障。当发生这种情况时，生产操作突然停止，这会让你的业务陷入恐慌状态。

当工作自动化时，人们往往过度依赖技术设备。结果是，他们觉得没有必要理解如何手动执行这些过程。技术设备出现问题，整个业务运营就会停止。这就是为什么作为企业主，你不应该让你的运营完全依赖技术应用程序。培训你的工人，让他们知道当技术应用程序故障时该做什么。此外，你应该有一份完整的手册，规定在设备故障的意外情况下应该采取什么措施以确保公司和业务运营的正常运行。

## 实施成本与合规性

实施新解决方案需要时间和金钱。通常情况下，当业务运营的新阶段被实施时，业务服务将会中断。需要额外的员工培训，客户在实施过程中可能不得不忍受服务质量下降。组织通常聘请外部承包商来执行新硬件和软件解决方案的实施。虽然随着技术的改进，信息技术解决方案变得越来越廉价，但有广泛要求的组织必须确保遵守所有法规，否则它们将面临法律诉讼和罚款的风险。

## 越来越多的数据监管

在现代世界，信息是巨大的业务。这就是为什么数据保护及其伦理使用对监管机构和立法者具有至关重要的意义。企业主无法承担对客户数据保护涉及内容的忽视。某些行业的监管比其他行业得多，例如金融服务和医疗保健行业，因为在日常业务运营中，这些企业积累了来自患者和客户的私人敏感信息。

尽管如此，仅仅因为你拥有一家时尚店并不意味着你免受监管。你处理邮件列表的方式；确认你收集信息的个人年龄的过程；以及你管理信用卡数据的方式，都是受监管的。做好准备并采用标准协议是保护你的公司和客户的关键。





# 结论

信息技术帮助企业、政府和个人提高效率和效能。硬件和处理能力的快速提升迫使消费者购买新的相关技术。从市场层面来看，这种快速的更替创造了需求。然而，从企业的角度来看，这可能导致客户留存率降低。尽管如此，各机构继续需要创新的技术解决方案，这为新进入者留下了空间，特别是那些拥有独特理念的进入者。能够找到利基市场——或竞争较小市场——的企业将发现这个行业具有吸引力。尽管如此，进入现有市场的准入门槛仍然很高，因此大多数潜在的进入者会认为整个行业缺乏吸引力。

近年来，计算和通信技术取得了显著进展，对社会产生了深远影响。技术正在改变我们工作、娱乐以及与他人互动的方式。由于这些技术能力，新的行业、组织形式和商业模式正在不断涌现。技术进步可以创造巨大的经济和其他效益，但也可能给劳动者带来巨大变化。信息技术和自动化可以通过增强或替代特定任务中的工人，来改变工作开展的方式。
