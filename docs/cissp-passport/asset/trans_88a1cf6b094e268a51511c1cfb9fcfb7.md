

# 其他资源

除了 IEEE 道德准则示例之外，许多与网络安全专业人员密切相关或与其一致的其他专业组织也有值得提及的类似准则。另一个值得注意的例子是项目管理协会（PMI）道德与职业行为准则，可在 [`https://www.pmi.org/about/ethics/code`](https://www.pmi.org/about/ethics/code) 查看。

## 治理伦理要求

还有一些作为监管要求的一部分而施加的标准，涵盖了技术专业人员的行为方式。其中一些标准并不专门针对网络安全专业人员，但它们确实规定了有关数据保护等方面的道德行为，并适用于组织和人员。几乎所有数据保护法规，例如欧盟的《通用数据保护条例》（GDPR）、美国的《健康保险可移植性与责任法案》（HIPAA）、美国国家标准与技术研究院（NIST）出版物、2002年《萨班斯-奥克斯利法案》第406条中规定的道德准则要求，以及无数其他法律法规，都描述了拥有敏感数据特权访问权限的用户和人员必须采取的行动，以便从法律和道德角度保护这些数据，以符合安全、隐私和其他治理要求。

# 复习

## 目标 1.1：理解、遵守并推广职业道德

在此目标中，我们关注了 CISSP 考试中更重要的目标之一——一个在考试准备中经常被忽视的目标。我们讨论了旨在指导我们专业行为的道德准则要求。我们特别审查了 `(ISC)² Code of Ethics`，因为它与考试最相关。道德准则由序言和四项强制性准则组成。`(ISC)²` 还有一套全面的投诉程序，用于针对认证成员的道德投诉。投诉程序详细说明了正式指控认证成员违反四项准则中一项或多项的过程，同时确保对被指控者进行公正和公正的正当程序。

我们还审查了组织道德，并讨论了某些组织可能没有正式的道德准则文件，但其道德或专业行为期望可能包含在其政策中。这些通常出现在可接受使用、接受礼品、贿赂和其他类型的政策中。影响员工专业行为的大多数政策通常出现在员工手册中。

最后，我们讨论了职业道德的其他来源，来自专业组织和治理要求，这些来源可能定义如何保护某些敏感数据分类。在没有规定专业行为的其他核心道德文件的情况下，`(ISC)² Code of Ethics` 对 CISSP 认证持有者是强制性的，并应用于指导他们的行为。

## 1.1 问题

**[1](#ch01.xhtml#ch1ques1-1).** 你是一名为小企业工作的 CISSP。你的工作场所没有正式的职业道德准则。你的经理最近要求你篡改一组生产服务器漏洞评估的结果，以使其看起来安全态势正在改善。在没有工作场所道德准则的情况下，以下哪项应指导你对此请求的行为？

**A.** 你自己的职业良知

**B.** `(ISC)² Code of Ethics`

**C.** 工作场所可接受使用政策

**D.** 计算机伦理研究所政策

**[2](#ch01.xhtml#ch1ques1-2).** Nichole 是安全运营中心（SOC）主管，她观察到她的一名 CISSP 认证下属反复违反公司的专业行为要求和 `(ISC)² Code of Ethics`。她应该采取以下哪项行动？

**A.** 仅向公司人力资源部门报告违规行为

**B.** 向 `(ISC)²` 和人力资源部门报告违规行为

**C.** 忽略一次性违规行为并对个人进行辅导

**D.** 仅向 `(ISC)²` 报告违规行为

**[3](#ch01.xhtml#ch1ques1-3).** 以下哪项是基于特定行业、数据类型和敏感性，对个人施加的保护数据的法律、道德或专业要求？

**A.** `(ISC)² Code of Ethics`

**B.** IEEE Code of Ethics

**C.** 《萨班斯-奥克斯利法案》道德准则要求

**D.** 计算机伦理研究所的《计算机伦理十诫》

**[4](#ch01.xhtml#ch1ques1-4).** Bobby 被指控违反了 `(ISC)² Code of Ethics` 的四项准则之一。一位网络安全专业同事投诉称，Bobby 故意撰写一份网络安全审计报告，以有利于他正在申请工作的公司，以便赢得其经理的青睐。Bobby 很可能违反了以下哪项准则？

**A.** 为委托人提供勤勉和称职的服务

**B.** 光荣、诚实、公正、负责任且合法地行事

**C.** 促进和保护专业

**D.** 保护社会、公共利益、必要的公众信任和信心以及基础设施

## 1.1 答案

**[1](#ch01.xhtml#r_ch1ques1-1).** B 在没有工作场所的其他具有约束力的职业道德准则的情况下，`(ISC)² Code of Ethics` 将认证专业人员约束于更高的行为标准。虽然运用你自己的专业判断是值得赞赏的，但并非每个人的专业标准都处于同一水平。工作场所政策并不总是专门涵盖网络安全人员的专业行为。计算机伦理研究所的政策对网络安全专业人员不具约束力。

**[2](#ch01.xhtml#r_ch1ques1-2).** B 由于该员工既违反了公司的专业行为要求，也违反了 `(ISC)² Code of Ethics`，Nichole 应该将该行为同时报告给这两个机构。如果违规行为仅涉及 `(ISC)² Code of Ethics`，她可能不需要向公司报告。一次性违规可能是意外造成的，应由主管酌情处理；但是，重复违规可能需要进一步行动，具体取决于违规的性质和情况。

**[3](#ch01.xhtml#r_ch1ques1-3).** C 《萨班斯-奥克斯利法案》（SOX）道德准则要求是防止证券和金融欺诈的法规（该法案第406条）的一部分，要求组织制定道德准则以保护财务和个人数据。其他选项并不关注数据敏感性或法规，而是适用于技术和网络安全专业人员。

**[4](#ch01.xhtml#r_ch1ques1-4).** A 虽然可以认为伪造审计报告可能违反 `(ISC)² Code of Ethics` 的四项准则中的任何一项或全部，但该场景特别影响要求专业人员为委托人提供勤勉和称职服务的准则。
