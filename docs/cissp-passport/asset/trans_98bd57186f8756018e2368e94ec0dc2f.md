

# 目标 1.12：应用供应链风险管理（SCRM）概念

在本目标中，我们讨论了供应链风险管理的基础知识，包括供应链的定义、上游和下游供应商，以及与供应链三个关键部分相关的风险。我们讨论了与硬件相关的风险，包括有缺陷的、被攻破的或假冒的硬件，以及与软件相关的风险，同样包括有缺陷的、被攻破的甚至假冒的软件。我们介绍了供应链的第三部分，即可能外包给第三方提供商的服务。服务固有的风险包括缺乏安全控制、恶意内部人员以及有缺陷的安全流程。我们还讨论了第三方监控和评估，既包括提供服务的一方，也包括使用外部评估人员。最后，我们讨论了应对任何类型的服务提供商或供应链中任何其他人员施加的最低安全要求，以及服务级别协议在施加和强制执行安全要求方面的重要性。

## 1.12 问题

**[1](#ch01.xhtml#ch1ques12-1).** 您的公司决定将供应链风险纳入其整体风险管理计划。您的主管指派您启动该流程。为了开始供应链风险管理，您应该首先做以下哪项？

**A.** 对供应链进行风险分析。

**B.** 识别公司供应链的所有上游和下游组件。

**C.** 开始检查收到的任何硬件是否存在故障或被攻破。

**D.** 开始扫描购买的任何软件以查找漏洞。

**[2](#ch01.xhtml#ch1ques12-2).** 您的公司从各种海外供应商处接收硬件和软件组件。作为努力提升供应链风险可见性的一部分，您决定公司必须开始更仔细地验证硬件和软件组件。以下哪项是完成此任务的最佳方式？

**A.** 对接收到的任何硬件或软件组件进行安全测试。

**B.** 向供应商请求任何硬件或软件组件的安全文档。

**C.** 将硬件和软件安装到关键系统中，然后测试系统。

**D.** 委托第三方评估人员评估和监控您的供应商。

**[3](#ch01.xhtml#ch1ques12-3).** 您的公司从本地云服务提供商处承包基础设施服务。在最初撰写合同时，安全考虑未包含在协议中。现在合同在期满时正在重新谈判，您的主管希望您在新合同中包含几个关键要求。以下哪项应作为新合同安全要求的一部分包含在内？

**A.** NIST 或 CIS 控制标准

**B.** 事件响应团队就绪情况

**C.** 最低安全要求，包括控制措施和安全职责

**D.** 数据保密性要求

**[4](#ch01.xhtml#ch1ques12-4).** 您的公司处理敏感数据，其中一些受监管要求约束。您正在与一家新的第三方提供商签订合同，该提供商将能够访问敏感数据。虽然保护敏感数据的监管要求将自动施加给新提供商，但以下哪项您也应建立，以帮助在提供商的人员访问敏感数据时保护敏感数据？

**A.** 保密协议（NDA）

**B.** 服务级别协议（SLA）

**C.** 提供商自身的内部安全评估报告

**D.** 第三方评估人员关于提供商的报告

## 1.12 答案

**[1](#ch01.xhtml#r_ch1ques12-1).** B 在做任何其他事情之前，您都应该花时间识别公司的所有上游供应商及其提供的商品和服务，以及您的公司通过其提供商品或服务的链条中的任何下游环节。

**[2](#ch01.xhtml#r_ch1ques12-2).** A 要验证硬件和软件组件的安全状态，您应该开始对这些组件运行安全测试。请求接收到的任何硬件或软件组件的安全文档很有用，但可能不会让您对其安全态势更有信心，因为文档可能被伪造或不完整。将一些硬件和软件安装到关键系统中不是最佳选择，因为对这些系统的安全扫描可能无法识别被攻破的组件。此外，委托第三方评估人员/监控人员可能成本过高。

**[3](#ch01.xhtml#r_ch1ques12-3).** C 您应在新合同中包含最低安全要求以及安全职责。如果编写得当，这些最低安全要求将涵盖其他选项。

**[4](#ch01.xhtml#r_ch1ques12-4).** A 除了法规施加的数据保护要求外，您还应让组织及其人员签署保密协议，以确保敏感数据受到保护且不会披露给未经授权的各方。虽然数据保护要求可能包含在服务级别协议中，但这些要求可能较为笼统，且对为第三方提供商工作的个人可能不具强制力。评估报告可能会让您了解提供商的安全态势，但不能保证敏感数据受到保护。

# 建立和维护安全意识、教育和培训计划

在本目标中，我们将讨论组织的安全意识、教育和培训计划。这是组织可用的关键行政控制之一，也是保护其资产最关键的控制之一。

## 安全意识、教育和培训计划

组织的安全意识、教育和培训计划是一项关键的行政控制，针对组织中最脆弱的要素：人员。该计划向员工（学生）传达与人为要素相关的威胁、漏洞和风险。需要注意的是，这些术语——意识、教育和培训——各不相同，尽管有时会被混用。[表 1.13-1](#ch01.xhtml#ch1tab13-1) 详细说明了这三个术语的独特要素。

### 提供意识和培训的方法和技术

不同级别的意识、培训和教育通常需要不同的演示方法，并可能取决于受众知识或理解水平、学生的安全职责、主题深度等因素。频率也可能决定学生接受的演示类型；例如，初始培训和教育通常比复习意识简报或培训更全面，因此可能使用不同的演示方法。可用设备或培训空间等后勤因素有时会影响用于受众的演示方法。
