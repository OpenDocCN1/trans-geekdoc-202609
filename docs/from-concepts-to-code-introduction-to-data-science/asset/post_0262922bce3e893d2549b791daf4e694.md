# 15
Clustering with K-Means

We don't always have the luxury of labeled data for supervised learning. A more common case is that a dataset $\{x_i\}_{i=1}^n$ is not labeled, but we want to identify substructure as groupings. Clustering techniques are also helpful in finding outliers; such points may be located in isolated or small groups. We will begin this chapter by studying concepts to clustering. Then we will learn about k-means clustering and work out a small example. Lastly, we will apply k-means to a nutrition dataset of roughly 9000 foods.

# 15.1 Clustering Concepts

Let's start with a very small example to illustrate the ideas. Suppose that a teacher wishes to group her students by some measure of assessment performance. The assessments may consist of quizzes or exams, for example. After the students are grouped, they can be given more targeted instruction. What is the best way to implement this grouping? We face some questions to be answered early on, including:

- Which students should be used in the grouping calculations? We might include in the analysis all current students in a specific class, or we use both current and historical students from a course.
- Which variables should be included? We might include one assessment at a time, all assessments given in a particular course, or only the assessments given before the final exam. For example, if we use a system that identifies students needing support on recent learning, then the clustering could be based on the last exam.
- How do we measure the quality of the groups? To understand the quality of the groups, we might try to correlate the groupings with another variable. It is also important to bear in mind that there is a limit to the number of groups that can be supported by the teacher and teaching assistants.

There is no single, prescriptive answer to these questions. Instead, the right choices will depend on how the clustering information will be used. It will also take some iterating to arrive at a satisfactory answer.

Let's narrow focus to three students who have taken two exams. Their scores are as follows:

| exam1 | exam2 |
|---|---|---|
| A | 70 | 82 |
| B | 75 | 80 |
| C | 95 | 90 |

What is a reasonable way to group these students? First, we use distance. In this example, we will use Euclidean distance, which shows 15.1:

Notice where the horizontal and vertical lines cross, it forms a right angle:

- Student A scored 70 on exam 1
- Student B scored 80 on exam 2

The distance between A and B will be the hypotenuse of the formed right triangle. $\sqrt{(75-70)^2+(82-80)^2} = \sqrt{29} \approx 5.39$ according to the Pythagorean theorem (which you might recall as $c = \sqrt{a^2+b^2}$).

Euclidean distance can be stated as a formula for vectors x and y, each with length p:

```
$d(x, y) = \sqrt{\sum_{i=1}^{p} (x_i - y_i)^2}$ \quad (15.1)
```

This is an extension of our example to the p-dimensional case. The distances between the other students could be calculated in a similar fashion. Notice that one method involves doing the calculation of all pairwise distances $d(A,B), d(A,C), d(B,C)$. For a large number of datapoints, this can be a calculation. One simplification, which we will see later with the k-means algorithm, is to stop taking the square root. Instead, we calculate squared distances $d^2$, because ranking on $d^2$ will be identical to ranking based on $d$. Since the square root function is monotonically increasing function.

Another consideration is the number of groups k to be formed. A single group will illuminate similarities or differences in the students, so we would help either, as this places each student on their own. In the general case of n objects, we require that k is greater than one and less than n. There are different ways of measuring the quality of grouping, and we will study a specific metric shortly. Conceptually, points within a group should be "close together" and points in different groups should be "far apart." The closeness can be measured by sum of squared distances between points.

In the next section, we will discuss the popular k-means clustering algorithm. The algorithm can scale to massive numbers of observations and variables, and it requires only a single parameter. We have already introduced many of the important concepts used in k-means, so let's dive deeper.
