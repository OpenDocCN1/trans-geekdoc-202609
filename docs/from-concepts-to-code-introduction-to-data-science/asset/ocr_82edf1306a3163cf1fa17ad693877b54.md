Breaking a document into its words, or word tokenization, is a common and useful step in language processing. This can be useful for inferring the topic, for instance. Next, we will tokenize the first string in sent. We can use the split() function to split on spaces.

```
tokens = sent[0].split(' ')
print(tokens)
```

OUT:

```
['2021', 'California', 'wildfire', 'season', 'was', 'a', 'series', 'of', 'wildfires', 'that', 'burned', 'across', 'the', 'U']
```

Notice what this did: it produced a list of strings, where each string is a word. Python datatypes can be recognized by their punctuation; strings are enclosed in quotes, and lists are enclosed in square brackets.

Next, we would like to associate each word with its position in the sentence. This is useful if we want to incorporate text data in a model, for example. We cannot directly feed text into a model, so we need to represent numerically.

Here is what we would like to build:

```
word_index = {'2021': 0, 'California': 2, 'wildfire': 3, 'season': 4, 'was': 5, 'series': 7, 'of': 8, 'wildfires': 9, 'that': 10, 'burned': 11, 'across': 12, 'the': 13, 'U': 14}
```

This Python object called a dictionary stores key:value pairs. The keys in this case are strings, and the values are integers indicating positions, starting from zero. The code snippet below provides a solution.

```
# empty dictionary
word_index = {}
```

```
for ix, token in enumerate(tokens):
    word_index[token] = ix
```

```
print(word_index)
```
