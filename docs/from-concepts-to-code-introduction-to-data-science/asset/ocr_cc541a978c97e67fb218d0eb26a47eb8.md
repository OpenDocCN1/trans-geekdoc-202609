A squared loss function is applied to the residuals. The objective of OLS regression is to establish parameter estimates $eta_0, eta_1, \dots, eta_p$ that minimize the sum of squared residuals $SS_{res}$ defined as:

```
$SS_{res}(eta) = \sum_{i=1}^n (y_i - (eta_0 + eta_1x_{i1} + \dots + eta_px_{ip}))^2 \quad (13.1)$
```

Minimizing $SS_{res}$ with respect to $eta$ can be done with differential calculus, and this will yield a parameter estimate $\hat{eta}_i$ for each parameter $eta_i$. Next, we will review the details for the simple linear regression case.

# 13.1.1 Parameter Estimation for Linear Regression

Let us use the residual sum of squares for the simple predictor:

```
$SS_{res}(eta) = \sum_{i=1}^n (y_i - (eta_0 + eta_1x_i))^2$
```

There are two parameters in this model: $eta_0$ and $eta_1$. Our strategy is to simplify the equation and find a critical point. This is done by taking the partial derivative with respect to each parameter (i.e., computing the gradient), setting the equations to zero, and solving the system of equations.

```
$SS_{res}(eta) = \sum_{i=1}^n (y_i^2 - 2y_i(eta_0 + eta_1x_i) + (eta_0 + eta_1x_i)^2) \= = \sum_{i=1}^n (y_i^2 - 2y_ieta_0 - 2y_ieta_1x_i + 2eta_0eta_1x_i + eta_1^2x_i^2)$
```

Next, take the partial derivative with respect to $eta_0$ and set to zero:

```
$\frac{\partial SS_{res}(eta)}{\partial eta_0} = \sum_{i=1}^n (-2y_i + 2eta_0 + 2eta_1x_i) \= 0 = -\sum_{i=1}^n y_i + neta_0 + eta_1\sum_{i=1}^n x_i \quad (text{(dividing through } n) \= 0 = -ar{y} + eta_0 + eta_1ar{x} \quad (text{(dividing by } n)$
```

We used the definition of the mean in the final line: $ar{z} = \sum_{i=1}^n z_i/n$.
