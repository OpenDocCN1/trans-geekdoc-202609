Next, let's get a little fancier. We will apply some filtering to the data. Select all rows where location_captured is China:

```python
df[location_captured == 'China']
```

OUT:

| year | location_captured | females | males | cubs | unknown_sex | total |
|---|---|---|---|---|---|---|
| 2014 | China | 14 | 11 | 2 | 0 | 27 |
| 2015 | China | 10 | 12 | 0 | 0 | 22 |

Let's break this down. The expression `df.location_captured == 'China'` verifies that location_captured value is equal to 'China' for each row in the dataframe. The result is a series of Boolean values, or True/False. These data types, which are bool, are new to us.

```
0 True
1 False
2 False
3 True
4 False
5 False
```

Booleans are used to filter the rows of the dataframe. This means that only rows where the value is True will be returned, which explains why rows 0 and 3 were output. How can we determine locations less than 15 females in 2015? We can filter on multiple conditions to answer this since we are applying criteria on females and year:

```python
df[(df.females < 15) & (df.year == 2015)]
```

OUT:

| year | location_captured | females | males | cubs | unknown_sex | total |
|---|---|---|---|---|---|---|
| 2015 | China | 10 | 12 | 0 | 0 | 22 |

Notice that `&` is the AND operator (note that `|` is the OR operator). This gets correct, but it returns unnecessary columns. Let's adjust the statement to select only the location_captured column.

```python
df[(df.females < 15) & (df.year == 2015)]['location_captured']
```

OUT:
```
China
```

This gets the desired answer. The syntax we used to subset on rows and columns:

```python
dataframe[row_condition][column_condition]
```

The column condition was simple; it was the column name. If we want several columns, we can put them in a list. We subset data using dataframe methods. For more complex subsetting, it makes sense to use SQL, which is shorthand for Structured Query Language. We will dive into SQL later in the book.

## 6.2.3 Creating New Columns

Next, we would like to do a simple calculation and store the results in the dataframe: for each row, the number of females and males (these are the adults with known sex). Since the operation is simple, we can write an expression involving the necessary columns, and assign the result to a new variable with the equals operator like this:

```python
df['f_and_m'] = df['females'] + df['males']
```

Alternatively, we can use a dot notation on the right, which is shorter and often preferred:

```python
df['f_and_m'] = df.females + df.males
```

OUT:

| year | location_captured | females* | males | cubs | unknown_sex* | total | f_and_m |
|---|---|---|---|---|---|---|---|
| 2014 | China | 14 | 11 | 2 | 0 | 27 | 25 |
| 2014 | Russia | 25 | 21 | 3 | 2 | 51 | 46 |
| 2014 | China & Russia | 33 | 24 | 5 | 2 | 64 | 57 |
| 2015 | China | 10 | 12 | 0 | 0 | 22 | |
| 2015 | Russia | 24 | 20 | 8 | 3 | 55 | 44 |
| 2015 | China & Russia | 31 | 25 | 8 | 3 | 67 | 56 |

> * females and unknown_sex are abbreviated to fit. index is suppressed.

Pandas performed this operation on each row, or row-wise, which was very convenient. For more complex row-wise operations, we can define a function and use the apply() function. We will discuss this later.

We cannot use the dot notation when creating a new variable; this is not valid syntax. Watch what happens:

