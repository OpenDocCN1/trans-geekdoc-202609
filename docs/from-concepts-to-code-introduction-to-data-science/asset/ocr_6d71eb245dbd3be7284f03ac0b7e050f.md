Next, we need to compute the gradient of the negative log-likelihood. Mathematically, this provides the update direction of the parameter vector. which has

```
\sum_{i=1}^{n} (y_i - p(x_i|\theta))_{ij}
```

This can be computed compactly with the matrix operation

```
-np.dot(X.T, y - p)
```

Let's break this. Both $y$ and $p$ have the same shape, and we can compute their difference. The $y - p$ represents the prediction errors for each observation. For each parameter $j$, we need to compute the dot product between the prediction errors and the values of the $j$th predictor; this is summing over the observations. The result is a column vector of length $j$, where element $j$ is computed, we update the parameter with respect to parameter $j$.

Now that the iteration estimates taking a step of $\alpha$ in the direction of the negative gradient. This is expected to minimize the log-likelihood (or maximize the log-likelihood). Every 1000 iterations, we report the iteration number (the progress) and store the log-likelihood. If we plot the log-likelihood versus the iterations, we see it converging to a value, or limit. For an appropriate $\alpha$ and number of iterations, the parameter estimates should converge to the true values.
