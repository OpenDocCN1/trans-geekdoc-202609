## 5.8 Cloud Computing

Cloud computing is the delivery of computing services over the internet. It provides tremendous flexibility compared to computing with the machines premises. Advantages include:

- a wide variety of processors and storage, including state-of-the-art GPUs.
- Automated scaling of hardware to match demand. This can be very cost effective by buying machines to match peak demand and having them sit idle for the remainder of the year.
- Highly durable data storage that reduces the risk of data loss.
- Features for automating the deployment of services, such as model predictions.
- Advanced security features.

Cloud service offerings are commonly grouped into categories which often interact:

- IaaS, or infrastructure as a service, provides access to servers, storage, and networking. This is the back-end infrastructure required for running applications and workloads.
- PaaS, or platform as a service, is a cloud environment that includes everything to build, run, and manage applications.
- SaaS, or software as a service, is on-demand access to cloud-hosted applications.

Cloud providers own and maintain warehouses of hardware, and customers can access these resources virtually through an internet connection. Security is essential in this setup, whereby an organization's data is transmitted and placed on external servers which are shared by others. Customers pay only for what they use, which is called consumption-based pricing. Providers offer a variety of hardware and software for different use cases and patterns.

> Note that forgetting to shut down a server, an issue called "leaving the lights on," will incur billing charges.

such as compute-intensive jobs and storage-intensive. The warehouses are secure and climate controlled, and they are placed throughout the world to offer fast response times with high availability. Data can be copied to multiple locations to reduce the likelihood of data loss. This practice promotes durability of data; note that each copy of data incurs costs. Compute jobs can be set to automatically scale as the required resources increase or decrease. For example, additional servers can be added if there is a surge in customer demand.

The number of cloud-provider services has grown rapidly in the last years. Early services include compute (for processing a batch of data with Python, file storage, and database storage. Today, there are services for game development, end-to-machine learning, generative AI, chatbots, and hundreds of other applications. The services respond to customer demand, and competition works to guide prices lower.

The largest cloud providers are Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform (GCP), Alibaba Cloud, and Oracle Cloud. AWS was first to market and it is the largest cloud provider by market share. The top three are fierce competitors offering similar services. Some of the key differentiators are the number of regions/zones, the pace of innovation (e.g., better hardware, fully featured services), the level of customer service, and pricing. For example, some providers build their own GPU chips to accelerate machine learning and bring down pricing.

## 5.9 Chapter Summary

Hardware comprises the physical components of the computer, while software is the instructions to operate computers. The CPU is the brain of the computer that processes information and temporarily stores it in RAM. A GPU is a processor of specialized cores which are excellent at performing parallel computations. For machine learning, RAM, or memory, is much faster than hard disk storage, but it is more expensive. As a result, computers typically have much more storage than RAM. Solid-state drives store data in integrated circuits, making them smaller and faster. The motherboard connects all of the principal components.

The most important software on the computer is the operating system. Operating systems organize files into a directory structure. This structure is different in Windows versus non-Windows operating systems, and perhaps looks slightly different.

The file format is the structure of a data file. Some common data formats are CSV, DOCX, and TXT. There are many specialized formats such as MP4, WAV, and PNG for media and Parquet for columnar data. Saving data in appropriate formats can speed up workloads significantly.

The shell supports interfacing with a computer. It is a computer program that takes commands, interprets them for the OS, and outputs the results. Users interact with the shell through a GUI or a command-line interface. Use of the CLI is general through terminal. Users enter commands at the prompt in the terminal.

Version control is essential for tracking file changes. The most widely used system for version control is Git. GitHub is a popular internet service for software development and version control, and it is based on Git. We reviewed details of how to set up Git and GitHub, and how to execute common tasks like forking and cloning a repo. A fork of a repo will make an independent copy in the user's account. A clone of a repo will create a linked copy which will continue to sync with the original repo.
