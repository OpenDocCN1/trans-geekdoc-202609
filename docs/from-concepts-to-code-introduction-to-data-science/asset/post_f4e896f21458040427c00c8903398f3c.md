
The penalty term in Lasso regression consists of two parts: the sum of the absolute value of the parameter estimates, which penalizes magnitudes, and a scalar $\lambda$ which controls the relative importance of the penalty term versus the sum of squared residuals term. The regularization term for $p$ parameters looks like this:

```
$$\lambda \sum_{j=1}^p |\beta_j|, \quad \lambda \ge 0$$
```

The loss function for Lasso regression with $p$ predictors combines the two terms as:

```
$SS_{res}(\beta) = \sum_{i=1}^n (y_i - \beta_0 + \beta_1 x_{i1} + \dots + \beta_p x_{ip})^2 + \lambda \sum_{j=1}^n |\beta_j|, \quad \lambda \ge 0$$
```

The first term can be minimized by selecting parameter estimates which bring the predictors closer to the response values $y_i$. At the same time, the second term adds a positive quantity which increases with the sum of the magnitudes of the parameter estimates. Specifically, increasing any coefficient $|\beta_j|$ will increase the penalty. Additionally, increasing $\lambda$ will increase the value of the loss function. Ultimately, the optimal parameter estimates must strike a balance between these two terms.

Earlier, we encountered parameters, which are important quantities in the configuration of a model. Additionally, their values are not known in advance. The $\lambda$ term is an example of a hyperparameter, and a common way to estimate its value through k-fold validation. Here is an outline of possible steps:

- 1. Provide a list of possible values for $\lambda$. We can start with 10 since we are near the right of order of magnitude. This is the hyperparameter grid. Referring to this set as $\Lambda$, we might use $\Lambda = \{1 \times 10^{-4}, 1 \times 10^{-3}, \dots, 1 \times 10^3, 1 \times 10^5\}$.
- 2. Decide on the number of folds $k$.
- 3. Set aside portion of the dataset for final evaluation (a test set).
- 4. For each possible $\lambda_i \in \Lambda$, repeat these steps:
  For iterations $1, \dots, k$, train the model on $k-1$ folds and evaluate a metric such as MSE on the left-out fold. Each iteration should leave out a different fold.
  The average MSE to attain the final estimate $MSE_i$.
- 5. From the pairs $(\lambda_i, MSE)$, select the $\lambda_i$ with lowest value $MSE$. This yields the optimal value $\lambda^*$.
- 6. The final model is the version with regularization value $\lambda^*$.

For a more accurate $\lambda^*$, a finer grid can be used in the first step after the MSEs are observed from the original course grid. Modern software packages support Lasso regression, as well the popular variants Ridge regression and elastic regularization. For more details on regularization, you might consult [4].

### 18.3.1 Tree-Based Models

Tree-based models are built up from the intuitive construct of a *decision tree*. Each tree forms a hierarchy, with a root at the top and branches emanating from the root and each node in the tree. For a pair of nodes connected by a branch, there is a parent-child relationship where the parent is higher in the tree. The terminating nodes at the bottom of the tree are the leaves. These leaves represent useful predictors, while the branches represent conditions on these predictors (e.g., if *age<20*, go left). A predictor is useful if it separates the observation target values into groups which increase *purity*, where purity is defined by a metric such as *entropy*. A 50/50 separation would have highest entropy (lowest purity).

When fitting a decision tree to training data, important considerations include the predictors to use, the depth of the trees, and the cutpoints for each of the predictors (e.g., do we move left when age<20 or when age>21?). A major shortcoming of decision tree is that it can overfit the training data. A useful technique for reducing overfitting is to build multiple decision trees and then aggregate the results into a prediction. Two popular and effective models following this approach are random forests (RF) and gradient-boosted trees (GBT). A variant of the GBT XGB is very efficient and wins many data science competitions.

One distinction between RF and GBT is that the former builds a set of independent trees, while the latter builds a sequence of small trees meant to correct prediction errors. The "randomness" in random forests reflects the practice of drawing subsets of data and predictors when building each tree. After each tree is built, its predictions are equally weighted to produce an aggregated prediction. The GBT model, will, determine an optimal weighting of the small trees to produce an aggregated prediction. The technique of combining multiple trees to yield a prediction is called an ensemble method.

A major advantage of random forest models is that the construction of the independent trees can be done in parallel across multiple cores to speed up processing. Since the GBT model builds trees sequentially as error refinements, the task cannot be done in parallel by multiple cores.

From their architecture, tree-based models do not assume a linear relationship between predictors and the target. This provides flexibility not present in linear regression and logistic regression models (recall that logistic regression models assume a linear relationship between the log odds and predictors). To be sure, there are many kinds of data where the linearity assumption is violated. For example, the relationship between a predictor and a target may exhibit this piecewise-linear behavior.

Regression models require the user to determine the best set of predictors. Tree-based models automatically determine useful predictors, the most important higher in the tree. Predictors that aren't helpful for increasing explanatory power are dropped from the model. For a large set of predictors, this can save a lot of time.

Regression requires imputation of missing values. For some implementations of tree-based models, missing values are treated as a separate level for each predictor. In doing this, imputation is not necessary in the tree-based model.

A challenge introduced by tree-based models is that interpretation is less clear compared to linear and logistic regression models. This is primarily because treebased models combine output from multiple trees when making a prediction. There are specialized methods for measuring the importance of predictors in these models, but they are still more challenging to understand than the parameter estimates in a regression model.

### 18.3.2 Artificial Neural Networks

Artificial neural networks, simply called neural networks, when there is no risk of confusion with biological neural networks, were first developed in the 1950s and have seen a resurgence in the last several decades. Many of today's state-of-the-art models are based on customized neural networks. We will learn about some of their cases later and see an overview of their architecture.

The building blocks of neural networks are weights and biases. The nodes are arranged in layers, beginning with an *input layer*, followed by one or more hidden layers, and finally an *output layer*. Neural networks with more than one hidden layer are called *deep neural networks* (DNNs). The subfield of machine learning that uses DNNs is called *deep learning*.
