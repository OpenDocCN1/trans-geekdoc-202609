More formally, $e$ can be defined with a statement using a *limit*, where the limit will be defined in the next section on differential calculus.

```
$e = \lim_{n\to\infty} (1 + \frac{1}{n})^n$
```

The exponential function $y = e^x$ is very common and appears in probability that we will soon encounter. The inverse of this function is a logarithmic function; it is given special notation $ln(x)$ which denotes the *natural logarithm*. The base is generally not written, as it is understood to be $e$. For example, $ln(e^3) = 3$, as to the power of 3 is $e^3$. A second example is $ln(1) = 0$, as $e$ to the power of 0 is 1.

Figure 8.7 shows the functions $e^x$ and $ln(x)$. As $x$ increases, $e^x$ increases to $+\infty$. As $x$ decreases, $e^x$ tends to zero (it approaches an *asymptote* at zero). Its domain is therefore $(-\infty,+\infty)$, while its range is $(0,+\infty)$. The function $ln(x)$ increases as $x$ increases, but the rise is much slower than $e^x$. As $x$ decreases to zero, $ln(x)$ approaches $-\infty$. The domain is $(0,+\infty)$, while the range is $(-\infty,+\infty)$. $e^x$ and $ln(x)$ are inverses, their domains and ranges are reversed.
