# Data Transformation

```
f(x) = \begin{cases} 0 & x \le c \ 1 & x > c \end{cases}
```

Here is a code snippet to binarize data using sklearn. Binarizer() takes a threshold which is zero by default. Values less than or equal to the threshold will be set to zero, and to one otherwise.

from sklearn.preprocessing import Binarizer

```
bin = Binarizer() # set up the scaler
bin_data = bin.fit_transform(data)

print(data)
print('')
print(bin_data)
```

# 10.4.2 Discretization

Discretizing a continuous variable into buckets can sometimes yield a more powerful predictor. In particular, it can be effective when the variable has a wide range and it is used in a regression model. The cut() function from pandas can discretize data into equal-sized buckets based on ranks or quantiles.

The example below creates 1000 random values drawn from a standard normal distribution. They are multiplied, scaled, to increase their range. The data is divided into deciles, where decile 0 is the lowest 10% of data values, decile 1 is the next 10%, and so on. The original data and the deciles are plotted in Figures 10.5(a) and 10.5(b) to show the discretized effect.

```
data = 100*np.random.normal(size=1000)
data.sort()
```
