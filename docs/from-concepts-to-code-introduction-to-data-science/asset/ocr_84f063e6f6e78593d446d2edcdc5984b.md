$adjusted R^2 = 1 - (1 - R^2) \left(\frac{n-1}{n-p-1}\right)$

where

+   * $n$ is the number of observations
* $p$ is the number of model parameters, excluding the intercept

sklearn doesn't have a function to compute adjusted $R^2$, so we can define it ourselves:

```
def adj_squared(X, y, y_pred):
    r2 = r_score(y, y_pred)      # compute R-squared
    n = len(y)                    # number of observations
    p = X.shape[1]               # number of parameters
    adj_r2 = 1 - (1 - r2) * (n - 1)/(n - p - 1)
    return adj_r2
```

Next, let's compute the $R^2$ and adjusted $R^2$ for this smaller model:

```
print('R2:', r_score(y_test, y_test_predicted)
```

```
print('adj R2:', adj_squared(x_test_subset_s,
    y_test,
    y_test_predicted)
```
