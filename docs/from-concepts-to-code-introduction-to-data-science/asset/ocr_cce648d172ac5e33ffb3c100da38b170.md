$z = \frac{X_n - \mu}{s/\sqrt{n}} = \frac{-0.5 - 0}{10/sqrt{1000}} \approx -1.581$

Next, we can compute the probability of this value or lower under the standard normal distribution. This represents the left-tailed probability. We can then double this value to include the right-tailed probability. From Python, we can call the function `stats.norm.cdf(z)`, which computes the left tail cumulative distribution function of a standard normal. Doubling the probability gives a p-value of approximately 0.1138. As the p-value is greater than $\alpha = 0.05$, we cannot reject $H_0$ as the risk of making a Type I error would be too large. Thus, based on the sample data, the mean $\mu$ is not statistically different from zero.

Python code is shown below for experimenting with different values and measuring the impact on the conclusion. For example, changing the sample mean from -0.5 to -1.0 will produce a p-value of 0.00157 and lead to rejecting $H_0$.

```
from scipy import stats
n = 1000
alpha = 0.05
xbar = -0.5
mu = 0
s = 10

test_stat = (xbar - mu) / (s/np.sqrt(n))

# p-value for two-tailed test
pval = stats.norm.cdf(test_stat) * 2

print('test-stat:', round(test_stat, 4))
print('p-value (two-tailed):', round(pval, 4))
```
