a) One thousand rows of data. It is best to be definitive.
b) Five hundred rows of data for both the case of customers churning and not. This will cover each outcome.
c) You should indicate that you need cases where the customer churned and did not churn. It is hard to say how many rows are needed, but you will certainly need variables that are predictive.
d) You should refer to the project that you are predicting if a stock went up or down. The number of rows used in that project should be sufficient.
