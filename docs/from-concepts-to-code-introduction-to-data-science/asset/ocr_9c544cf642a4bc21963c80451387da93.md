Next, we need to determine the parameter estimate $eta_1$. We take the partial derivative of $S$ with respect to $eta_1$ and set equal to zero:

```
$$\frac{\partial S_{res}(eta)}{\partial \beta_1} = \sum_{i=1}^n (-2x_iy_i + 2\beta_0x_i + 2\beta_1x_i^2)$
$$0 = \sum_{i=1}^n (-x_iy_i + \beta_0x_i + \beta_1x_i^2) \quad \text{(dividing by 2)}$$
$$0 = \sum_{i=1}^n (-x_iy_i + (	ilde{y}-\hat{eta}_0)x_i + \beta_1x_i^2) \quad \text{(substituting for $\hat{eta}_0)}$$
$$0 = -\sum_{i=1}^n x_iy_i + \sum_{i=1}^n x_i\tilde{y} - \hat{eta}_0\sum_{i=1}^n x_i + \hat{eta}_1\sum_{i=1}^n x_i^2 \quad \text{(applying sums)}$$
$$0 = -\sum_{i=1}^n x_i(y_i-\tilde{y}) + \hat{eta}_1\sum_{i=1}^n x_i(x_i-\tilde{x}) \quad \text{(grouping terms)}$$
```

Solve for the parameter estimate $\hat{eta}_1$:

```
$$\hat{eta}_1 = \frac{\sum_{i=1}^n x_i(y_i-\tilde{y})}{\sum_{i=1}^n x_i(x_i-\tilde{x})}$$$
```

This is equivalent to the common equation for $eta_1$, which is left as an exercise:

```
$$\hat{eta}_1 = \frac{\sum_{i=1}^n x_i(y_i-\tilde{y})}{\sum_{i=1}^n x_i(x_i-\tilde{x})^2}$$$
```

We have now seen how to derive the simple linear regression estimates using differential calculus. This is done in software, but it is a valuable exercise nonetheless. For the more general case, we can use matrices. This will handle the simple linear regression case that we just completed, as well as the multiple linear regression case. This involves creating:

+   A design matrix $X$ which holds the predictor data. The $n$ rows represent the observations and the $p+1$ columns represent the intercept term (in the first column) and the $p$ predictors in the remaining columns. For example, element $x_{12}$ is the value of predictor 2 for observation 1.
