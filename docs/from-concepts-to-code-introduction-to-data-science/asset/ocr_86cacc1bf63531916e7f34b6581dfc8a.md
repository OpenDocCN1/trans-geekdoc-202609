# 6.3.3 Data Type Conversion

Next, let's make the blood pressure data types match. In this case, since we don't measure blood pressure to decimal precision, both systolic and diastolic can be integers. This will mean converting bp.diastolic to integer, which can be done like this:

```
df = df.astype({'bp_diastolic':np.int32})
```

We used the astype() function, passing a dictionary with the column name as key and the required data type as value. We could have passed additional key:value pairs to convert multiple columns if we wished.

Now we check the data types, and we see that bp.diastolic has the desired integer type.

```
df.dtypes

patientid    int64
date          object
bp_systolic  int64
bp_diastolic  int32
```

The data type conversion produces a new dataframe. We can see this by calling id() before the assignment and noticing that the dataframe memory addresses differ.

```
id(df)
264196136432
```

```
df = df.astype({'bp_diastolic':np.int32})
```

```
id(df)
2641537679264
```
