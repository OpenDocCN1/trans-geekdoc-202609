# 4.1 Data Types

Each piece of data will have an associated data type, which allows for a set of possible values and operations. A numerical measurement like 121.5 may be compared to another numerical measurement with the > and = operators, for example. The measurements might also be averaged. A word such as “Love” from a social media tweet could be uppercase or lowercase. It would not make sense to uppercase a numerical measurement, and it would not make sense to compute the average two words.

Each programming language will define a set of built-in data types. In Python, the float data type would be appropriate for decimal values like 121.5. The string data type would be sensible for words “Love,” as strings hold a sequence of letters and punctuation. The other two primitive data types in Python are integers and Booleans. The Boolean data type takes True and False, such whether a Twitter account has followers or not. More complex data types can be built from the primitive data types. We will actively work with and study the various Python data types throughout the book.

To summarize, are the Python data types with examples:

| Type | Examples |
|---|---|
| float | 3.14, 2.71, -1.111 |
| integer | -2, 0, 500 |
| bool | True, False |
| string | ‘success’, bag of words |

# 4.2 Statistical Data Types

Data can also be categorized into statistical data types. At the first level of the taxonomy, data can be qualitative or quantitative. Qualitative data can be further divided into categorical data and ordinal data. Categorical data can take the form of text or even numeric values. A key property is that it does not have a meaningful ordering. Examples include eye color and zip code. Note that zip codes are integers, calculations on them are not meaningful (we would not compute the mean of two zip codes). Although categorical data cannot be ordered, it is still highly useful, and it can be included in models. Ordinal data has a natural ordering system, and an example is letter grades assigned to student exams; a grade of A is preferable to a grade of B, for example.
