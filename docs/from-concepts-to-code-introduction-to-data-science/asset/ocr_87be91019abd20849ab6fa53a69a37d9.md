# An Overview of Machine Learning

+   * TP (*true positive*): the positive label is predicted, and this is the true label

+   * FP (*false positive*): the positive label is predicted, but actual label is negative

+   * TN (*true negative*): the negative label is predicted, and this is the true label

+   * FN (*false negative*): the negative label is predicted, but the actual label is positive

To summarize, there are two outcomes that are correct ($TP$ and $TN$), and two outcomes that are incorrect ($FP$ and $FN$). Which error is worse – a false positive or a false negative? This depends on the problem. In the case of a COVID-19 test, a false negative would suggest that the person isn't infected, which could lead to spreading the disease and not seeking treatment.

Let's imagine that ten individuals take a COVID-19 test, and the results are $TP=8, FP=1, TN=7$, and $FN=3$. Notice that most individuals tested positive, which could make sense if they don't feel well and this prompts the test. From this information, we can compute quantities such as:

+   * The number of positive predictions: $TP + FP = 8 + 1 = 9$

+   * The number of negative predictions: $TN + FN = 7 + 3 = 10$

+   * The number of actual positives: $TP + FN = 8 + 3 = 11$

+   * The number of actual negatives: $TN + FP = 7 + 5 = 12$

This information can be organized into a two-way table called a *confusion matrix*, which has this form:

| predicted | P | N |
|---|---|---|n| actual | TP | FN |
| N | FP | TN |

For example, the cell $FN$ represents the number of false negatives. This is where the actual label is $P$ and the predicted label is $N$. We can fill in the confusion matrix with our data:

| predicted | P | N |
|---|---|---|n| actual | 85 | 3 |
| N | 5 | 7 |
