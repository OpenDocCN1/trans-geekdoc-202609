Notice the right triangle formed in the figure. The horizontal side formed from the x-axis is called the adjacent side, the vertical side dropped from the circle to the x-axis is called the opposite side, and the side forming the radius is called the hypotenuse. The trigonometric functions sine, cosine, and tangent are defined as ratios of these triangle sides:

```
$$\sin(\theta) = opposite/hypotenuse$\n$\cos(\theta) = adjacent/hypotenuse$\n$\tan(\theta) = \sin(\theta)/\cos(\theta) = opposite/adjacent$
```

Since the hypotenuse has length 1 for the unit circle, it follows in this example that the adjacent side is equal to$\cos(\theta)$ and the opposite side is equal to$\sin(\theta)$. The exponential function with base $a$ (for any $a>0$) and rational number $x$ can be written as $y = a^x$. The inverse of the exponential function is the logarithm with base $a$, which can be written as $x = log_a(y)$. The logarithm is determined by answering the question "base to which power is $y$?" For example, solving $log_2(8)$, we ask 2 to which power is 8? The solution is 3.

A very special base is $e$, which can be understood like this:

Compute the sum $S_n = 1 + \frac{1}{1!} + \frac{1}{2!} + \dots + \frac{1}{n!}$ for some $n$.

The expression $n!$ is read "factorial" and computed as $n \times (n-1) \times \dots \times 1$. For example, $3! = 3 \times 2 \times 1 = 6$.
