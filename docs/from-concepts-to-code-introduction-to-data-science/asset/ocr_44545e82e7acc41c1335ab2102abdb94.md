The prompt displays the working directory followed by a blinking cursor. This is usually intimidating for the uninitiated, as there is not much happening. It is waiting for a command. The contents of the working directory can be listed with the **ls** command, by **Enter**.

The terms shell, terminal, and command line tend to be used interchangeably, and because this are fundamentally intertwined. The shell is the program interacting with the OS, the terminal is a specific environment for interaction, and the command line is the actual line where commands are entered. The book will use statements such as "open a terminal" or "run at the command line," and clarification will be given as needed.
