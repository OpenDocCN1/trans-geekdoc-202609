# Function Inverse

The inverse $f(x) = y$ serves to undo the function. It is itself a function, if entering $y$ into the inverse function $f^{-1}$ produces the output $x$. This can be written as $f^{-1}(f(x)) = x$. We can use function composition to show that $f(f^{-1}(y)) = y$. Not every function has an inverse, so we will discuss the necessary conditions next. A function that has an inverse is treated as *invertible*

Does our parabola from Figure 8.1 have an inverse? An inverse is itself a function, which means that each input must map to one output. Remember that the inverse works backwards, so $y$ is treated as input and $x$ is treated as output. We want to confirm if each possible $y$ value maps to only one.

Let's select the value 60 on the y-axis and check if it maps to one on the x-axis. We can draw a horizontal line at 60, where the line intersects the graph, and draw vertical lines to the x-axis at those intersections. It turns out there are two x-values $-\sqrt{60}$ and $\sqrt{60}$. In fact, due to symmetry, every horizontal line will return two values. Since we cannot uniquely identify an $x$ for $f^{-1}(y)$, the inverse does not exist. This *horizontal line test* can be a useful way to check for a function inverse.

Our quick test two criteria, so let's explore each. First, a function $f$ is one-to-one if $f(x) 
eq f(y)$ whenever $x 
eq y$. That is, if two inputs are different, their outputs must be different. The parabola violated this rule, as $f(\sqrt{60}) = f(-\sqrt{60}) = 60$. A function is onto if for every $b \in B$ there is at least one $a \in A$ with $a(a)=b$. For illustration, imagine that $A$ is a set of cats and $B$ is a set of cats, and there are more cats than cats ($|A| > |B|$). An animal shelter asks each cat to indicate their top candidate for adoption, imposing a strict rule that each cat must be adopted. This creates an onto function, whereby each element of $B$ (the cats) is matched with at least one element of $A$ (the cat lovers).

Finally, a function $f$ has an inverse $f^{-1}$ if it is one-to-one and onto.

# Monotonicity

Some functions have the increasing property that $x$ increases or decreases as $x$ increases. A function that increases or remains constant as $x$ increases is called a *monotonically increasing function*, as in a function that decreases or remains constant as $x$ increases is called a *monotonically decreasing function*.

A function is *strictly increasing* if it always increases as $x$ increases, and it is *strictly decreasing* if it always decreases as $x$ increases. Functions meeting either of these conditions are *strictly monotone*.
