As the number of ML applications grows, the number of supporting containers may grow along with it. Managing and orchestrating containers becomes an important requirement and it can present a challenge. Docker Compose is a tool for defining and sharing multi-container applications. It allows for managing a system of Docker images in a single file. Additionally, there are cloud tools for container scheduling and orchestration, such as Amazon Elastic Container Service (ECS).
