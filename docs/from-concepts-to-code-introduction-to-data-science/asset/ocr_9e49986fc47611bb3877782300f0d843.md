# Matrix Multiplication

For $m 	imes n$ matrix **E** and $n 	imes p$ matrix **F**, two products **EF** and **FE** may be formed, and are generally different. The dimensions of **E** and **F** determine if the product is valid, and if so, the dimensions of the product. A short mnemonic can be used: if $X$ is $a 	imes b$ and **Y** is $c 	imes d$, then **XY** we will be $(a 	imes b) 	imes (c 	imes d)$. The inner dimensions are $b$ and $c$, while the outer dimensions are $a$ and $d$. The inner dimensions must match for the product to be valid. The product will have the outer dimensions.

For the case of **E** and **F**, the calculation looks like $(m 	imes n) 	imes (n 	imes p)$. The inner dimensions are both $n$, and so the product is valid. The outer dimensions will be $m 	imes p$. The product will have the same number of rows as the left matrix and the same number of columns as the right matrix.

Returning to our numerical example, **C = AB** can be formed as follows: For each element of **C**, written $c_{ij}$, row $i$ from **A** and column $j$ from **B**. Next compute the *inner product* of these two vectors as follows:

```
$c_{ij} = \sum_{k=1}^{p} a_{ik}b_{kj}$
```

For this example,

```
$c_{11} = \sum_{k=1}^{p} a_{1k}b_{k1} = (a_{11} \times b_{11}) + (a_{12} \times b_{21}) + (a_{13} \times b_{31}) = (1 \times 1) + (5 \times (-1)) + (0 \times 0) = -4$
```
