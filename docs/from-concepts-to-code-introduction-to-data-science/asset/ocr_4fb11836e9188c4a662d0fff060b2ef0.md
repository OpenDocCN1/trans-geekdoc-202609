# Detecting Breast Cancer 279

The target variable is called diagnosis and it takes value 'M' for malignant and 'B' for benign. Each patient has a unique identifier in the id column, and the columns f1-f30 are cell measurements that can be used as predictors. We begin by importing modules and reading in the data:

```
import numpy as np
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split
```

```
datapath = '../datasets/wbc.csv'
df = pd.read_csv(datapath)
```

We need to code the target values as 1 for the event 'M' and 0 for the non-event 'B'. The predictors are selected, and the dataset is split into a training and test set for performance measurement.

```
# code the target
df['target'] = df['diagnosis'].apply(lambda x: 1 if x == 'M'
else 0)
```

```
# select the data for the model, saving as numpy arrays
```
