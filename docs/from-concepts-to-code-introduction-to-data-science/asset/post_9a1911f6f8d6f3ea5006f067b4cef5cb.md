## 13.1 Mathematical Framework

Returning to our labeled data $\{(x_i, y_i)\}_{i=1}^n$, we want to learn a function that can predict the target $y$ given $X$. A linear regression model specifies a linear relationship between $X$ and the target $y$. This is a simpler structure than a nonlinear model, which will make it easier to explain and fit to data. The tradeoff is that for a complex relationship between predictors and target, the linear model might not fit well. In this chapter, we will specify precisely what we mean by the fitting well. For some intuition, consider a single predictor $X$, its associated response $Y$, and a set of observations $(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)$. A linear model that best fits the data will minimize its distance from the points, in effect “passing through” a majority of them as in Figure 13.1.

For each observation $i$, the error in measuring the target in linear regression is $\epsilon_i$. A common assumption made in linear regression is that the errors follow a normal distribution with mean zero and variance $\sigma^2 > 0$. This is often written as

![](img/7f40a2246fd3d2d5353d109f489c4e33_264_0.png)

FIGURE 13.1: Scatter Plot with Line of Best Fit

$\epsilon_i \sim \mathcal{N}(0, \sigma^2)$

The normality assumption is not necessary for fitting the model, but it is a requirement in the statistical testing.

Next, let's look at the mathematical form for linear regression, which is stated for each observation $i$ and $p$ predictors:

$y_i = \beta_0 + \beta_1 x_{i1} + \dots + \beta_p x_{ip} + \epsilon_i, \quad i=1, \dots, n$

where

- $y_i$ is the target for observation $i$
- $\beta_0$ is an intercept parameter
- $\beta_1, \dots, \beta_p$ are slope parameters or $weights$
- $x_{i1}, \dots, x_{ip}$ are predictors for observation $i$
- $\epsilon_i$ is the error for observation $i$

In this setup, we assume that the target can be modeled by a linear combination of predictors. There is a linear equation for each observation, for a total of $n$ equations. There are $p+1$ unknown, represented by the weights $\beta_0, \beta_1, \dots, \beta_p$, applied to each predictor. The weighted combination of predictors is an attempt to match the target value.

As a small example, imagine we have collected three observations $(1,2), (2,3), (3,5)$. There is one predictor, and the first observation has predictor value 1 and target value 2. Given this data, we can write three linear equations with two unknowns:

```
$$2 = \beta_0 + \beta_1(1) + \epsilon_1$$
$$3 = \beta_0 + \beta_1(2) + \epsilon_2$$
$$5 = \beta_0 + \beta_1(3) + \epsilon_3$$
```

Now let's guess that $\beta_0 = 0$ and $\beta_1 = 2$. This produces:

```
$$2 = 0 + 2 + \epsilon_1$$
$$3 = 0 + 4 + \epsilon_2$$
$$5 = 0 + 6 + \epsilon_3$$
```

For the first equation, the weighted combination of predictors exactly matches the target. For the next two equations, however, there are errors. In fact, this system has more equations than unknowns, and it cannot be solved. It is called an *overdetermined system*. An overdetermined system is better than an *underdetermined system*, which results when there are more unknowns than equations. Underdetermined systems cannot be solved.

In algebra class, you might have seen systems where the number of equations matched the number of unknowns. These systems can be exactly solved, which is wonderful. In practice, it won't be possible to have a matching number of equations and unknowns; we will collect observations generally outweigh the predictors: $n > p$. To solve the overdetermined system, we will establish a metric and an objective, such as minimizing squared errors. This procedure will yield estimates $\hat{\beta}_j$ for each parameter $\beta_j$. Then the predictions can be estimated with fitting equation:

$$\hat{y}_i = \hat{\beta}_0 + \hat{\beta}_1 x_{i1} + \dots + \hat{\beta}_p x_{ip}$$

In the case of a simple predictor ($p = 1$), we can drop the subscript and write the fitting equation:

$$\hat{y}_i = \hat{\beta}_0 + \hat{\beta}_1 x_i$$

This model is *simple linear regression*. In the case of multiple predictors ($p > 1$), the model is called *multiple linear regression*. The prediction $\hat{y}_i$ is called the *fitted value*. The difference between the target and the fitted value, $y_i - \hat{y}_i$, is called the *residual*. The residual is an estimate of the true error. A common technique for fitting a linear regression is called *ordinary least squares* (OLS regression), and this is what will be used. A squared loss function is applied. The objective of OLS regression is to establish parameters $\beta_0, \beta_1, \dots, \beta_p$ that minimize the sum of squared residuals $SS_{res}$ defined as:

$$SS_{res}(\beta) = \sum_{i=1}^n (y_i - (\beta_0 + \beta_1 x_{i1} + \dots + \beta_p x_{ip}))^2$$

Minimizing $SS_{res}$ with respect to $\beta$ can be done with differential calculus, and this will yield a parameter estimate $\hat{\beta}_i$ for each parameter $\beta_i$. Next, we will review the details for the simple regression case.

### 13.1.1 Parameter Estimation for Linear Regression

Let use the residual sum of squares for the simple predictor:

$$SS_{res}(\beta) = \sum_{i=1}^n (y_i - (\beta_0 + \beta_1 x_i))^2$$

There are two parameters in this model: $\beta_0$ and $\beta_1$. Our strategy is to simplify the equation and find critical points. This is done by taking the partial derivative with respect to each parameter (i.e., computing the gradient), setting the equations to zero, and solving the system of equations.

$$SS_{res}(\beta) = \sum_{i=1}^n (y_i - (\beta_0 + \beta_1 x_i))^2 = \sum_{i=1}^n (y_i^2 - 2y_i\beta_0 - 2y_i\beta_1x_i + 2\beta_0\beta_1x_i + \beta_1^2x_i^2)$$

Next, take the partial derivative with respect to $\beta_0$ and set to zero:

$$\frac{\partial SS_{res}(\beta)}{\partial \beta_0} = \sum_{i=1}^n (-2y_i + 2\beta_0 + 2\beta_1x_i) = 0 = -\sum_{i=1}^n y_i + n\beta_0 + \beta_1\sum_{i=1}^n x_i \quad (\text{dividing through } n) = 0 = -\bar{y} + \beta_0 + \beta_1\bar{x} \quad (\text{dividing by } n)$$

We used the definition of the mean in the final line: $\bar{z} = \sum_{i=1}^n z_i/n$.

Now solve for the parameter estimate $\beta_0$:

$$\hat{\beta}_0 = \bar{y} - \hat{\beta}_1\bar{x}$$

Next, we need to determine the parameter estimate $\beta_1$. We take the partial derivative of $S$ with respect to $\beta_1$ and set equal to zero:

$$\frac{\partial S_{res}(\beta)}{\partial \beta_1} = \sum_{i=1}^n (-2x_iy_i + 2\beta_0x_i + 2\beta_1x_i^2)$$
$$0 = \sum_{i=1}^n (-x_iy_i + \beta_0x_i + \beta_1x_i^2) \quad (\text{dividing by 2})$$
$$0 = \sum_{i=1}^n (-x_iy_i + (\bar{y}-\hat{\beta}_0)x_i + \beta_1x_i^2) \quad (\text{substituting for } \hat{\beta}_0)$$
$$0 = -\sum_{i=1}^n x_iy_i + \sum_{i=1}^n x_i\bar{y} - \hat{\beta}_0\sum_{i=1}^n x_i + \hat{\beta}_1\sum_{i=1}^n x_i^2 \quad (\text{applying sums})$$
$$0 = -\sum_{i=1}^n x_i(y_i-\bar{y}) + \hat{\beta}_1\sum_{i=1}^n x_i(x_i-\bar{x}) \quad (\text{grouping terms})$$

Solve for the parameter estimate $\hat{\beta}_1$:

$$\hat{\beta}_1 = \frac{\sum_{i=1}^n x_i(y_i-\bar{y})}{\sum_{i=1}^n x_i(x_i-\bar{x})}$$

This is equivalent to the common equation for $\beta_1$, which is left as an exercise:

$$\hat{\beta}_1 = \frac{\sum_{i=1}^n x_i(y_i-\bar{y})}{\sum_{i=1}^n x_i(x_i-\bar{x})^2}$$

We have now seen how to derive the simple linear regression estimates using differential calculus. This is done in software, but it is a valuable exercise nonetheless. For the more general case, we can use matrices. This will handle the simple linear regression case that we just completed, as well as the multiple linear regression case. This involves creating:

- A design matrix $X$ which holds the predictor data. The $n$ rows represent the observations and the $p+1$ columns represent the intercept term (in the first column) and the $p$ predictors in the remaining columns. For example, element $x_{12}$ is the value of predictor 2 for observation 1.
