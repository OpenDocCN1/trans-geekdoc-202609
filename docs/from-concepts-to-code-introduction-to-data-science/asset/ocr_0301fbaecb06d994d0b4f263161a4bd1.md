
# Inverse

The inverse $M^{-1}$ of a square matrix $\mathbf{M}$ is a matrix such that $MM^{-1} = M^{-1}M = \mathbf{I}$. The inverse is unique, and it serves the same role as in arithmetic. Finding the inverse of a matrix is efficiently computed (e.g., Python has a function `numpy.linalg.inv()`), it involves solving a system of linear equations. *Gaussian elimination* is one popular method for inverting a matrix. A matrix with an inverse is called an *invertible matrix*; it is otherwise called a *non-invertible matrix*. For further details, an excellent text is [29].

# 8.6 Chapter Summary

We started this chapter with an introduction to set theory. Sets, collections of objects, are everywhere in data science, from sets of products to sets of recommendations. It is important to compare and combine sets; operations the inclusion, union, and intersection were discussed. Sets are also essential blocks of functions and probability.

A function is a mapping that assigns each element of a set and assigns an element as output. In data science, we use functions to transform input data to (hopefully) more useful output. We might also perform a sequence of transformations, which is an example of function composition. The inverse function of a function serves to undo the function. We discussed checking if a curve is a function (each input must map to only one output), and if a function has an inverse (it must be one-to-one and onto).
