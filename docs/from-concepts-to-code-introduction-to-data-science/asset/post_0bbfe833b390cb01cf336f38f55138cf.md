We have separately created univariate plots for the underlying variables and a scatterplot to see their covariances. A jointplot (Figure 11.9) combines the scatterplot with the histograms of the underlying, or marginal, variables:

```python
sns.jointplot(x='Explained by: Social support', y='Happiness score', data=df)
```

Notice that we changed from a scatter plot to a joint plot by changing the subplot to jointplot. The seaborn interface makes this very easy.

Computing correlations is straightforward with pandas. All of the pairwise correlations can be computed in a dataframe with the df.corr() command. If we would like only the correlations with the target column, we can subset the column:

```python
df.corr(['Happiness score'])
```
