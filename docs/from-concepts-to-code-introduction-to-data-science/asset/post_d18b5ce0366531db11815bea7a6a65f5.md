
Note that 0 is the zero vector. Next, we rearrange:

```
$$X^T y = X^T X \beta$$
```

This produces the *normal equations*, the last step is to solve for $\beta$. We multiply the left by the inverse of the matrix $X^T X$. This is done to each side of the equation:

```
$$$\beta = (X^T X)^{-1} X^T y$$
```

This section required knowledge of linear algebra and matrix derivatives. A helpful reference is [42]. The important part is to remember the matrix formula for the parameter estimates. This formula makes it possible to solve the linear regression problem for any number of parameters.

## 14.1 Mathematical Framework

As in the regression task, a labeled dataset $(x_i, y_i)_{i=1}^n$ is available. The goal is to learn a function that can predict the target $y$ given $x$. We regard the outcome as an event that occurs $(y=1)$ with probability $p$ and does not occur $(y=0)$ with probability $1-p$. Given this setup, we need a function that takes predictors as inputs and produces the probability of the event as output. The predictors can potentially have domain $(-\infty, \infty)$.

A first thought might be to reuse our linear regression approach, which consists of a linear combination of the predictors. The trouble with this approach is that the range can be $(-\infty, \infty)$, which is inconsistent with probabilities. Instead, we begin with the sigmoid function to model probabilities. It has form:

$p(t) = \sigma(t) = \frac{1}{1+e^{-t}}$

An example sigmoid function is shown in Figure 14.1. The function is useful because it has domain $(-\infty, \infty)$ and range $(0,1)$. Given this range, the output can be treated as the probability of the event. Notice the $S$ shape and horizontal asymptotes at zero and when the input tends to $-\infty$ and $\infty$, respectively.

![](img/7f40a2246fd3d2d5353d109f489c4e33_288_0.png)

FIGURE 14.1: Sigmoid Function

The $odds$ of an event is the ratio of the probability of the event taking place divided by the probability it does not take place, $p/(1-p)$. We first simplify $1-p$, showing the dependence on $t$:

```
$1-p(t) = 1 - \frac{1}{1+e^{-t}} = \frac{1+e^{-t}}{1+e^{-t}} - \frac{1}{1+e^{-t}} = \frac{e^{-t}}{1+e^{-t}}$
```

Then the odds form

```
$$\frac{p(t)}{1-p(t)} = \frac{1/(1+e^{-t})}{e^{-t}/(1+e^{-t})} = \frac{1}{e^{-t}} = e^t$$
```

This expresses the odds as an exponential function of $t$. We can take the logarithm of both sides to yield an expression for the $log$ odds:

```
$$ln \frac{p(t)}{1-p(t)} = t$$
```

This results from $exp()$ and $ln()$ being inverses of one another. We now assume that $t$ is a linear combination of the predictors:

```
$$t = \beta_0 + \beta_1 x_1 + \dots + \beta_k x_k$$
```

In fact, the right-hand side is the specification from the linear model. In the case of a single predictor ($k=1$), we can drop the subscript on the predictor and write it as

```
$$ln \frac{p(t)}{1-p(t)} = \beta_0 + \beta_1 x$$
```

This is the equation for logistic regression. It assumes a linear relationship between the predictors and the log odds of the probability of the event.

### 14.1.1 Parameter Estimation for Logistic Regression

Now that the form is specified, we will need parameter estimates $\hat{\beta}_i$ for each parameter $\beta_i$, where $i=0,\dots,k$. Our technique is to write the probability of observing a sequence of outcomes as a function of the parameters (this is called the likelihood function), and to apply gradient descent to maximize the likelihood.

> Note: This section is more mathematically heavy than the early sections. It will be good to attempt the section and see the application of preliminary material, such as calculus, but it is not required.

Each outcome is a Bernoulli random variable with success probability $p(t)$, which is a function of the data and parameters. Given this information, a sequence of outcomes can be treated as a sequence of independent Bernoulli trials. The likelihood of observing the outcomes, denoted $\mathcal{L}(\beta)$, has this:

```
$$\mathcal{L}(\beta) = \prod_{i=1}^n p(x_i|\beta)^{y_i} (1-p(x_i|\beta))^{1-y_i}$$
```
