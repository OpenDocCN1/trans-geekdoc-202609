# 8.2 Functions

For sets A and B, a function is a rule or mapping that takes an element of A as input and assigns an element of B as output. This is commonly written f: A -> B for a function f. The space of inputs A is called the domain, and the space of outputs B is called the range. The value of the function at a point x can be written f(x). Note that for each input value, there can only be one output value. The vertical line test is a graphical method for checking if a curve is a function. If vertical line intersects the curve in more than one place, then it is not a function. Note we might define a function using the y notation as in y = 2x or using the f(x) notation as in f(x) = 2x to clarify the functional dependence on x.
