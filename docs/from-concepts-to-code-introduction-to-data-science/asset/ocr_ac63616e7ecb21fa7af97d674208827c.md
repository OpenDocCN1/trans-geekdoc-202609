Let's code the mathematical formula for the parameter estimates. Then we can verify that the calculated results match the estimates from sklearn. As a reminder, here is the formula:

> $$\beta = (X^TX)^{-1}X^T y$$

In the code snippet, the @ symbol performs matrix multiplication:

```
import numpy as np
```

```
# design matrix, prepend column of ones for the case
# intercept term
# hstack() horizontally stacks the two arrays
X = np.hstack((np.ones((x_train.shape[0], 1)), x_train_s))
```

```
XtX = X @ X
```

```
# compute matrix inverse
XtXi = np.linalg.inv(XtX)
```

```
betas = XtXi @ (X.T @ y_train)
```
