Let's apply this definition to compute the derivative of $f(x) = x^2$:

```
$f'(x) = \lim_{h\to 0} \frac{f(x+h)-f(x)}{h}
=\lim_{h\to 0} \frac{(x+h)^2-x^2}{h}
=\lim_{h\to 0} \frac{x^2+2xh+h^2-x^2}{h}
=\lim_{h\to 0} \frac{2xh+h^2}{h}
=\lim_{h\to 0} \frac{h(2x+h)}{h}
=2x$
```

The final step in the calculation applies the limit, setting $h$ to zero. This implies that the derivative $f'(x) = 2x$ is dependent on the point $x$. For example, $f'(-10) = -20$, $f'(-5) = -10$, $f'(0) = 0$, $f'(5) = 10$, and $f'(10) = 20$. Recalling the graph of the parabola and considering tangents to it at $x=-10, x=-5, x=0$, and $x=5$, the slope is most negative at $x=-10$, it increases to the parabola vertex $x=0$ (which is a horizontal line at this point), and it is most positive at $x=10$.

The derivative of a function can help find extrema, maxima and minima. In viewing a graph from left to right, the function decreases, flattens, and then increases. The derivative for the corresponding intervals would be negative, zero, and then positive. At the value where the derivative is zero, say $x=c$, $f(c)$ would have a minimum. Conversely, for a graph that increases, flattens, and then decreases, the derivative would be positive, zero, and negative. The function would attain a maximum. This leads to a definition and a useful application of the derivative to find extrema.

+   A point $x$ is a critical point of the function $f$ exists if $f'(x)=0$ or does not exist. Function maxima and minima occur at critical points or at the endpoints of intervals. As an example, the function $f(x)=x^2$ has derivative $f'(x)=2x$ and is equal to zero when $x=0$. Hence, $x=0$ is a critical point. The derivative is negative when $x<0$ and positive when $x>0$, indicating that the function reaches a minimum at $x=0$.
