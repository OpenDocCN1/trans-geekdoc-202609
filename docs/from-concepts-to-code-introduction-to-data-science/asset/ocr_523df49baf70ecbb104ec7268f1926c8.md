Data can be copied to multiple locations to reduce the likelihood of data loss. This practice promotes durability of data; note that each copy of data incurs costs. Compute jobs can be set to automatically scale as the required resources increase or decrease.nFor example, additional servers can be added if there is a surge in customer demand.

The number of cloud-provider services has grown rapidly in the last years. Early services include compute (for processing a batch of data with Python, file storage, and database storage. Today, there are services for game development, end-to-machine learning, generative AI, chatbots, and hundreds of other applications. The services respond to customer demand, and competition works to guide prices lower.

The largest cloud providers are Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform (GCP), Alibaba Cloud, and Oracle Cloud. AWS was first to market and it is the largest cloud provider by market share. The top three are fierce competitors offering similar services. Some of the key differentiators are the number of regions/zones, the pace of innovation (e.g., better hardware, fully featured services), the level of customer service, and pricing. For example, some providers build their own GPU chips to accelerate machine learning and bring down pricing.

The table below lists services offered by the three largest cloud providers. Data and relational (SQL) databases will be discussed later; the former is used for unstructured data, while the latter is used for structured data.

| Service | AWS | Azure | GCP |
|---|---|---|---|
| Compute | Amazon EC2 | Virtual Machines | Compute Engine |
| Data | Amazon S3 | Blob Storage | BigQuery |
| SQL DB | Amazon RDS | SQL Database | Cloud SQL |
| ETL | AWS Glue | Data Factory | Cloud Data Fusion |
| ML | SageMaker | Machine Learning | Vertex AI |

Most of the 500 companies use cloud-based services. This makes cloud skills essential for data science and related roles. Here is a brief sketch of how a data scientist Carla works in the cloud: Carla arrives at the office to test a new predictor in a system that her team built. She logs into the AWS Management Console and launches SageMaker Studio. She opens a notebook and starts the EC2 compute instances. Since she will be training a large machine learning model, she selects an instance from the P3 class. The datasets are saved in an S3 bucket (object file storage), and she loads them into the notebook. She pulls the latest project code from GitHub, creates a new branch for experiment, and starts to modify code.
