# 13.5 Appendix: Parameter Estimation in Matrix Form

We return to the system of equations in compact matrix notation:

```
$y = X\beta + \epsilon$$
```

Next, we write the equation for the sum of squared residuals:

```
$SS_{res}(eta) = (y - X\beta)^T(y - X\beta)$
```

Now we take the derivative of $SS_{res}$ with respect to $\beta$. This is like taking the derivative of quadratic function $(y - X\beta)^2$. The result is 2 times the derivative of $(y - X\beta)^T$ with respect to $\beta:

```
$$\frac{dSS_{res}(\beta)}{d\beta} = -2X^T(y - X\beta)$$
$0 = -2X^T(y - X\beta)$ (set equal to zero)$
```
