# 9.2.2 Confidence Intervals

When we computed the sample mean, this was a **point estimate** of the population parameter $\mu$. The **confidence interval** (CI) is a range that supplements the point estimate with information about its uncertainty. As an example, I used to visit my mother on on Long Island, near Manhattan. She would ask what time I would arrive, so I would give a time like noon. To avoid traffic on the expressway, we noticed that I tended to arrive in a range that was $\pm 30$ minutes of the target. Eventually, we would form an interval for planning my arrival: if I said noon, we would plan for 11:30 am–12:30 pm. The interval was more likely to be correct, and we were both happier.

The confidence interval can be regarded from a frequentist point of view like this: we can imagine a large number of samples from the population. For each sample, we can construct a confidence interval with a desired level, say 95% (this is most common). The fraction of intervals containing the true parameter would approach 95% as the number of samples increases.

For a parameter $\theta$, the interval is centered at the point estimate $\hat{	heta}$, and the standard error is subtracted and added to form the lower and upper limit. The multiple is called the *critical value* (cv) and it is chosen to construct the CI with a desired confidence level. Specifically, it is the value that puts probability $1-\\alpha$ in the interval and $\alpha/2$ in each tail. For $\alpha = 0.05$, this would put 0.95 probability in the interval and 0.025 in each tail. The confidence interval would look like

```
$$\hat{	heta} \pm cv \times SE$$
```

or equivalently

```
$$\hat{	heta} - cv \times SE, \quad \hat{	heta} + cv \times SE$$
```

For the travel example, $\hat{	heta}$ is noon and $cv \times SE$ is 30 minutes. The interval is then (11:30 am, 12:30 pm).

Next, let's consider this specific case: we want to construct a 95% confidence interval for the population mean $\mu$, the population standard deviation $\sigma$ is unknown, and we have drawn a small sample of size $n = 20$. We can use $\bar{X}$ as a point estimate for $\mu$ and the sample standard deviation $s$ as a point estimate for $\sigma$. Suppose $\bar{x}=15$ and $s=2$.

Since the sample is small, the sampling distribution of $\bar{X}$ follows a t-distribution with $\nu = n-1=19$ degrees of freedom. Then the confidence interval can be expressed like this:

```
$$\bar{x} - t_{n-1,\alpha/2} \cdot \frac{s}{\sqrt{n}}, \quad \bar{x} + t_{n-1,\alpha/2} \cdot \frac{s}{\sqrt{n}}$$
```
