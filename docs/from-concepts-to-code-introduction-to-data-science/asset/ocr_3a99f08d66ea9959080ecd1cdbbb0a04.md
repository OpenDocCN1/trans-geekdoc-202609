# Power Rule

For integer $n$ and function $f(x) = x^n$,

$f'(x) = nx^{n-1}$

Example 1:

$f(x) = x^4$
$f'(x) = 4x^3$

Example 2:

$f(x) = 3x^5$

# Product Rule

For $h(x) = f(x)g(x)$, $h(x)$ is differentiable and

$h'(x) = f(x)g'(x) + g(x)f'(x)$

This rule works as first (second)' + second (first)'

Example:

$h(x) = x^2(3x + 1)$
$h'(x) = x^2(3) + (3x + 1)(2x)$
$h'(x) = 3x^2 + 6x^2 + 2x$
$h'(x) = 9x^2 + 2x$
