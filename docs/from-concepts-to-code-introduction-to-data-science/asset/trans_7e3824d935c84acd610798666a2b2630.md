## 8.2 函数

对于集合 A 和 B，函数是一种规则或映射，它接受 A 的一个元素作为输入并将 B 的一个元素作为输出。对于函数 f，通常写成 $f: A -> B$。输入空间 A 称为定义域，输出空间 B 称为值域。函数在点 x 处的值可以写为 $f(x)$。注意对于每个输入值，只能有一个输出值。垂直线判法是一种检查曲线是否为函数的图形方法。如果垂直线与曲线相交于一个一点，则它不是函数。注意，我们可能使用像 y = 2x 的 y 符号或使用像 f(x) = 2x 的 f(x) 符号来定义函数，以明确对 x 的函数依赖。

函数将两个或多个输入映射到同一个输出是完全有效的。图 8.1 显示了函数 $f(x) = x^2$ 的图像。对于所有的 $x$，$-x$ 和 $x$ 将映射到相同的值 $f(-x) = f(x)$。例如，$f(-2) = f(2) = 4$。

## 复合

**函数复合**是一种运算 $\circ$，它接受两个函数 $f$ 和 $g$ 并产生一个新的函数 $h = g \circ f$，使得 $h(x) = g(f(x))$。先应用函数 $f$，然后应用函数 $g$。对于两个以上函数复合的情况，例如 $k \circ g \circ f$，我们从右到左应用这些函数，每次处理两个函数。例如，通过应用方程 $h(x) = g(f(x))$，$k \circ g \circ f = k(g(f(x))) = k(h(x))$。这种嵌套复合的求值是由函数复合的结合律（或结合律）支持的。

考虑一个有两个函数 $f(x) = x+1$ 和 $g(x) = \sqrt{x}$ 的例子，它们都定义在集合 $x \ge 0$ 上。我们形成复合函数 $h(x) = g(f(x)) = \sqrt{x+1}$。我们可以计算 $h(3)$ 和 $h(-2)$。第一种情况是可能的，$h(3) = \sqrt{3+1} = 2$。第二种情况未定义，因为 $h(-2) = \sqrt{-2+1} = \sqrt{-1}$。因此，复合仅在 $h$ 的定义域范围内有效。在这种情况下，定义域 $x \ge -1$。

函数复合在数据科学中特别重要，因为机器学习模型对数据应用一系列函数。在计算机视觉中，图像像素可以分层排列并进行多次聚合平均，以推断是否可以找到感兴趣的对象。

## 准备知识

一个函数是单调的，如果它完全是递增的或完全是递减的。一个函数 $f$ 是严格递增的，如果对于 $x_1 < x_2$，$f(x_1) < f(x_2)$。同样，一个函数 $f$ 是严格递减的，如果对于 $x_1 < x_2，$f(x_1) > f(x_2)$。

一个函数是单调的，如果它在定义域内是单调的。严格单调函数是单射的，这意味着它有反函数。

## 准备知识

函数 $f$ 是单射，如果定义域内的每个输入都有唯一的输出。函数的定义域是所有可能的输入值。函数的值域是所有可能的输出值。

函数是连续的，如果它可以不抬笔画出。形式上，函数 $f$ 在点 $c$ 处连续，如果 $x$ 趋于 $c$ 的极限存在并等于 $f(c)$。

函数在一点是可微的，如果在该点有导数。导数 $f'(x)$ 代表图形在该点的切线斜率。

## 凸性

函数 $f$ 是凸的，如果任意两点的线段位于图形上方或其上。几何上，凸函数“向上开口”。形式上，对于定义域内的任意 $x_1, x_2$ 以及 $t \in [0, 1]$，$f(tx_1 + (1-t)x_2) \le tf(x_1) + (1-t)f(x_2)$。

函数 $f$ 是凹的，如果 $-f$ 是凸的。或者，如果任意两点的线段位于图形下方或其上。几何上，凹函数“向下开口”。形式上，对于定义域内的任意 $x_1, x_2$ 以及 $t \in [0, 1]$，$f(tx_1 + (1-t)x_2) \ge tf(x_1) + (1-t)f(x_2)$。

## 极值

函数 $f$ 在 $x$ 处有局部极值，如果对于 $x$ 邻域内的所有 $x^*$，$f(x) \le f(x^*)$。它在 $x$ 处有局部极大值，如果对于 $x$ 邻域内的所有 $x^*$，$f(x) \ge f(x^*)$。全局极小值是整个定义域内最小的局部极值。全局极大值是整个定义域内最大的局部极大值。

为了找到可微函数的极值，我们找到导数为零的点，$f'(x) = 0$。这些点被称为临界点。找到临界点后，我们可以使用二阶导数判法来确定它们是极小值还是极大值：如果 $f''(x) > 0，$x$ 是局部极小值；如果 $f''(x) < 0$ 是局部极大值。
