# 4.5.3 Web Scraping and APIs

Common methods for ingesting large quantities of data are web scraping and the use of an API. Web scraping uses computer code to collect data from web pages found on the internet. When done properly, the process collects publicly available follows respectful conventions. For example, a user should not overwhelm a maximum number of requests in a short period of time. Scraping can face several challenges, such as changes to the structure of the web page. Web scrapers work by exploiting the layout of a page, and if layout changes the scraper can fail to retrieve data. For a system running in production, a broken web scraper can be disastrous.
