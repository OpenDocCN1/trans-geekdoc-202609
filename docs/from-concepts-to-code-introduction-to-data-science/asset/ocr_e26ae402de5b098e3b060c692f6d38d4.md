A function $f(x)$ is continuous at a point $x_0$ if for every positive number $\epsilon$, there exists another positive number $\delta$ such that $|f(x) - f(x_0)| < \epsilon$ for all $x$ for which $|x - x_0| < \delta$.

We have defined continuity at a point. For a function to be continuous on an interval, it must be continuous at each point in the interval.

# Derivative

We use functions to model behavior: given input $x$, what is output $f(x)$? Another question is about sensitivity to the change: when we change $x$ by some 'small' amount, what will be the change to $f(x)$? If we press down more firmly on the accelerator, what will be the change in position over given time increment? The *derivative* measures this change in output with respect to a change in input:

We start with a discussion of the derivative of a single-variable function, and then to the case of a function of multiple variables. In the former case, the derivative at a given value is the slope of the *tangent line* to the graph of the function at point. Figure 8.9 shows an example. At the point $x=1.5$, the derivative is approximately $0.408$ (we soon discuss how to calculate this), which is equal to the slope of the tangent line to the function at this point. For the tangent (or derivative) to exist at this point, the function must be continuous at this point. If we move the point along the curve, the derivative will change in accordance with the behavior of the function.
