# A Note on numpy

The numpy module also supports work with random variables; it is an essential package for numerical computing in Python. NumPy defines a highly efficient object for NumPy array. We will work with NumPy arrays throughout the book.

from scipy import stats

```
# compute the cdf when z=0
print('(Z < 0):', stats.norm.cdf(0))

# compute as 1 - F(0)
print('(Z > 0):', 1-stats.norm.cdf(0))

# compute F(1) and subtract left tail F(-1)
print('P(-1 < Z < 1):',
round(stats.norm.cdf(1) - stats.norm.cdf(-1), 3)
```

```
print('P(-2 < Z < 2):',
round(stats.norm.cdf(2) - stats.norm.cdf(-2), 3))

print('P(-3 < Z < 3):',
round(stats.norm.cdf(3) - stats.norm.cdf(-3), 3))
```

OUTPUT:
nP(Z < 0): 0.5
nP(Z > 0): 0.5
nP(-1 < Z < 1): 0.683
nP(-2 < Z < 2): 0.954
nP(-3 < Z < 3): 0.997

The output indicates some interesting facts about the standard normal distribution. First, half of the probability is below Z=0 and half is above, by symmetry. Roughly 68% of the probability is between -1 and 1, or one standard deviation of the mean (which is zero).
