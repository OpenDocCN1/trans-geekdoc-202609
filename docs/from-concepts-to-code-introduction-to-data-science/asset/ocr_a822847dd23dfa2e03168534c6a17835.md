# 10.1.2 Limiting Extreme Values

Two popular approaches for limiting the effects of extreme values, which may be produced by noise, are winsoring and trimming. Care needs to be taken with these approaches, as outliers may also be legitimate data. For example,

In winsoring, outliers are set to given percentiles of the data. 80% winsorization leave the middle 80% of the data untouched. Values below the 10th percentile would be floored to the 10th percentile, and values above the 90th percentile would be capped at the 90th percentile. The code below winsizes containing outliers. The bottom 10% of the data is floored at 1 (the 10th percentile), while the top 10% is capped at 9 (the 90th percentile).

```
from scipy.stats import winsorize

data_win = [-1000,1,2,3,4,5,6,7,8,9,1000]
winsorize(data_win, limits=[0.1, 0.1])
```

Winsoring can be helpful in measuring a statistic that is robust to outliers. If we wanted to understand the center of the data, we might compute the mean. The mean of the non-outlier values [1,2,3,4,5,6,7,8,9] is 5. For this case, winsorizing the data and computing its mean will match this value. Had
