There is no single, prescriptive answer to these questions. Instead, the right choices will depend on how the clustering information will be used. It will also take some iterating to arrive at a satisfactory answer.

Let's narrow focus to three students who have taken two exams. Their scores are as follows:

| exam1 | exam2 |
|---|--|
| A | 70 | 82 |
| B | 75 | 80 |
| C | 95 | 90 |

What is a reasonable way to group these students based on their exam scores? First, we would probably agree that a group, cluster, should consist of students who are more similar to each other. If two students are different, they should be in different clusters. To measure similarity, we can represent each student as a point based on data distance metric. There are many possible distance metrics, and the particular problem might define the metric for us. In this example, we will use Euclidean distance, which is a straight-line distance.
