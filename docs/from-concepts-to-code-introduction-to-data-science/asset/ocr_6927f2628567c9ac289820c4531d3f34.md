```
print('B: \n',B)
print('')
print('AB: \n', A@B)
```

OUTPUT:

```
A:
[[ 1 5 0]
 [ 2 12 -1]
 [ 4 12 3]]
```

```

[[ 1 4 0]

```

```
AB:
[[ -4 4 30]
[-10 7 72]
 [-8 19 72]]
```

Let's define another matrix D with dimensions that do not support multiplication with A. Then we can see how Python handles such a case.

```
D = np.array([[1,4,0],[-1,0,6]])
```

```
print('D: \n', D)
print('')
print('A dimensions:', A.shape)
print('D dimensions:', D.shape)
print('AD: \n', A@D)
```

OUTPUT:

```
D:
[[ 1 4 0]
 [-1 0 6]]
```

A dimensions: (3, 3)
D dimensions: (2, 3)
