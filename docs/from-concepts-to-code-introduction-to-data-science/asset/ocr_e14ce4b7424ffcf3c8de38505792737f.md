# ##8.1 Set Theory

Set
A *set* is a collection of objects. Sets often arise in data science, for example
when we consider the set of unique users, the set of videos they've watched,
nor the set of Boolean predictors in a dataframe.

Additional sets include:

+   - The set of integers Z
- The set of real numbers R
- The set of positive real numbers R+ = {x ∈ R : x > 0}

Set Builder Notation
In the last case, *set builder notation* denotes each element from the real num-ers (x ∈ R) such that the element is greater than zero. This notation is useful
when it is tedious or not possible to enumerate elements in a set.

Subset
For sets A and B, we say A is a *subset of B* (written A ⊆ B) if every element
A is an element of B. This allows for the possibility that A and B
contain exactly the same elements, in which case A = B. In the case where
every element of A is an element of B and they are not equal (for example, B
contains additional elements), then A is a proper subset of B, written A ⊆ B.

Empty Set
The *empty set*, denoted {} or Ø, contains no elements and is a subset of every
set. This set plays a prominent role, for example when testing if a filter returns
elements from a dataset.
