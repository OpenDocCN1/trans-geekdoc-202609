# 13.3.3 Model Fitting

Next, we train (or fit) a linear regression model on the training data. OLS regression can be implemented with the LinearRegression() function from sklearn. We instantiate the model and fit it to training data in a single line. By default, an intercept term is included. The order of the parameters is important: the fit() function takes X followed by y as this code snippet:

```
reg = LinearRegression().fit(x_train_s, y_train)
```

Let's code the mathematical formula for the parameter estimates. Then we can verify that the calculated results match the estimates from sklearn. As a reminder, here is the formula:

> $$\beta = (X^TX)^{-1}X^T y$$

In the code snippet, the @ symbol performs matrix multiplication:

```
import numpy as np
```

```
# design matrix, prepend column of ones for the case
# intercept term
# hstack() horizontally stacks the two arrays
X = np.hstack((np.ones((x_train.shape[0], 1)), x_train_s))
```

```
XtX = X @ X
```

```
# compute matrix inverse
XtXi = np.linalg.inv(XtX)
```

```
betas = XtXi @ (X.T @ y_train)
betas
```

# 13.3.4 Interpreting the Parameter Estimates

The sklearn package allowed for fitting the model and working with the parameter estimates, but didn't tell us which estimates, if any, are statistically different from zero. The statsmodels package can fit the same linear regression model and run one-sample t-tests to answer this question. Since we have already done the work of preparing the data, the code is minimal:

```
# import statsmodels
import statsmodels.api as sm

# append column of 1 to design matrix for intercept term
X = sm.add_constant(x_train_s)

# fit the OLS model
results = sm.OLS(y_train, X).fit()

# print the model summary
print(results.summary())
```

Table 13.1 shows the parameter estimate table and confidence intervals indicate that all variables except x5 ('Population') are significant. For x5, the p-value is greater than 0.05, and zero is contained in the 95% confidence interval. The next step would be to drop this variable and refit the model.

# 13.3.5 Model Evaluation

Since we know the target values from the test set, y_test, we can compare them to our predictions to assess model performance. We will use R² as metric. As a reminder, $R^2$ measures the fraction of $Y$ explained by the predictors. The details of $R^2$ calculation are included at the end of this section. The `r2_score()` function from `sklearn` will compute $R^2$. It takes an array of actual values and an array of predicted values, in that order.

```
print(r2_score(y_test, y_test_predicted))
```
