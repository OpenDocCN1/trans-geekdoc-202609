can think about two subjects A and B with identical data except for a single predictor where the value differs by 1 unit. Suppose the data looks like:

| subject | x1 | x2 |
|---|---|---|
| A | v+1 | w |
| B | v | w |

In this case, the x1 variable differs by one unit between subjects. This can be done with any predictor to yield an analogous interpretation. We will now write a formula that compares these two subjects with their data. Recall the formula for the odds of the event, with the linear combination of predictors substituted:

```
$$\frac{p(x)}{1-p(x)} = exp(\beta_0 + \beta_1 x_{i1} + \dots + \beta_k x_{ik})$$
```

Denote subject A as $x_A$ and subject B as $x_B$. Next, we form the ratio of the odds, called the odds ratio (abbreviated OR) for the two subjects like this:

> $OR = \frac{p(x_A)/(1-p(x_A))}{p(x_B)/(1-p(x_B))}$

Now we will form an equation for the odds ratio, using the linear combination of predictors for each subject and plugging in the data:

```
$$\frac{p(x_A)/(1-p(x_A))}{p(x_B)/(1-p(x_B))} = \frac{exp(\beta_0 + \beta_1(v + 1) + \beta_2 w)}{exp(\beta_0 + \beta_1 v + \beta_2 w)}$$
```

We can use the property of exponentials:

```
$exp(a)/exp(b) = exp(a-b)$
```

This will simplify the ratio greatly, since for example

```
$exp(\beta_0)/exp(\beta_0) = exp(\beta_0 - \beta_0)
= exp(0)
= 1$
```

More generally, the same term in the numerator and denominator yields a multiplicative factor of 1.

Also recall the following property of exponentials:

$exp(a + b) = exp(a)exp(b)$

This allows for writing simple factors in the numerator and denominator, which can cancel. Returning to the odds ratio, the equation becomes

```
$p(X_A)/(1-p(X_A)) = exp(\beta_0 + \beta_1(v+1) + \beta_2w)$
$p(X_B)/(1-p(X_B)) = exp(\beta_0 + \beta_1v + \beta_2w)$
$= exp(\beta_0) \times exp(\beta_1(v+1)) \times exp(\beta_2w)$
$= exp(\beta_0) \times exp(\beta_1v) \times exp(\beta_2w)$
$= exp(\beta_1)$
```

The odds ratio has a very simple form and interpretation: increasing the value of predictor $j$ by one unit will multiply the odds of the event by factor $exp(\beta_j)$. Returning to the parameter estimate table, the coefficient on $x1$ is $1.1042$. Increasing $x1$ by one unit will multiply the odds of malignancy by a factor of $e^{1.1042} = 3.017$.

To understand the parameter estimate if the odds will increase, decrease, or remain unchanged, we can consider the case where the value is zero. In this case, $e^0 = 1$, which means that the odds are multiplied by a factor of one (it is unchanged). A positive parameter estimate will increase the odds of the odds of the event.
