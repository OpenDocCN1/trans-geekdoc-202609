# 5.5.2 GitHub

Next, we will review GitHub, which is a popular internet hosting service for software development and version control built on Git GitHub also provides tools for software feature requests, task management, continuous integration, and project widgets. For more details on GitHub, see [22].

GitHub and Git are often confused, and clarification is in order. Git can be used for version control independently of GitHub (or similar services like GitLab). However, tools like GitHub are required to collaborate on versioncontrolled software over the web with other users. Many users opt for GitHub for themselves, as it provides a nice user interface and many helpful features.

In this section, you will create a GitHub account, make an independent copy of the course repo (fork the repo), and download the repo to your computer (clone the forked copy).
