# Data Processing

After data is ingested and integrated, it needs to be processed from its raw form to make it more useful. There are many ways that processing might be done. Some tasks are done as part of a research and development function, as such interactive processing as part of a data science pipeline workflow. For example, a data scientist might load data from a file or database and run code to process the data for machine learning. Since the work is experimental and not required in real time, the speed of processing might not be critical. This kind of work is usually part of the dev environment.

On the other hand, processing is time sensitive, as the data might feed a model that provides recommendations to customers in real time. If the customer needs to wait more than a few seconds for the response, she might abandon the application. This workload is running in the production environment, or prod. Data processing in prod needs to be automated and optimized for speed. It is unwise for workers to test features in prod, as they might interrupt the product delivered to customers.

The methods and tools used to process data will depend on how the data is structured, which environment is in use, and other factors. In this chapter, we will build coding skills to process data in unstructured and structured formats. The examples will begin with smaller datasets and code samples, which will focus attention on learning the concepts and techniques.
