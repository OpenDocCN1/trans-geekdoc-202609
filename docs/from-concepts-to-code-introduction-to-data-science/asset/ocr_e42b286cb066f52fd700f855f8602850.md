# I. Download and Installation

Download SQLite from https://www.sqlite.org/download.html

Windows users will install:

```
sqlite-tools-win32-x86-[some_number].zip
```

Mac users will install:

```
sqlite-tools-osx-x86-[some_number].zip
```

where [some_number] is a version number that changes over time.

If the sqlite folder name is long, it can be shortened to sqlite, for example. It is important to make note of where the database is saved. This location is the database path.

On a Windows machine, the path might look something like:

```
C:\Users\apt4c\Documents\database\sqlite
```

On a Mac, it might look something like:

```
/user/apt4c/Documents/database/sqlite
```
