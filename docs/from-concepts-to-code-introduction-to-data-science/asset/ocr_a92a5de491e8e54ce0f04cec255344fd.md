can think about two subjects A and B with identical data except for a single predictor where the value differs by 1 unit. Suppose the data looks like:

| subject | x1 | x2 |
|---|---|---||
| A | v+1 | w |
| B | v | w |

In this case, the x1 variable differs by one unit between subjects. This can be done with any predictor to yield an analogous interpretation. We will now write a formula that compares these two subjects with their data. Recall the formula for the odds of the event, with the linear combination of predictors substituted:

```
$$\frac{p(x)}{1-p(x)} = exp(\beta_0 + \beta_1 x_{i1} + \dots + \beta_k x_{ik})$
```

Denote subject A as $x_A$ and subject B as $x_B$. Next, we form the ratio of the odds, called the odds ratio (abbreviated OR) for the two subjects like this:

> $OR = \frac{p(x_A)/(1-p(x_A))}{p(x_B)/(1-p(x_B))}$

Now we will form an equation for the odds ratio, using the linear combination of predictors for each subject and plugging in the data:

```
$$\frac{p(x_A)/(1-p(x_A))}{p(x_B)/(1-p(x_B))} = \frac{exp(\\beta_0 + \beta_1(v + 1) + \beta_2 w)}{exp(\\beta_0 + \beta_1 v + \beta_2 w)}$
```

We can use the property of exponentials:

```
$exp(a)/exp(b) = exp(a-b)$
```

This will simplify the ratio greatly, since for example

```
$exp(\beta_0)/exp(\beta_0) = exp(\\beta_0 - \\beta_0)\n= exp(0)\n= 1$
```
