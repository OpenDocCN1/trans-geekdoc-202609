# 13.3.2 Data Scaling

Next, we scale the training data and the test data using StandardScaler(). This is done after splitting the predictor standard deviations needs to be measured on the training set. The test set is treated as an independent data set, and it would not be correct to use that data in standard deviation measurements.

The code below will instantiate a StandardScaler object and scale the training data. Specifically, the mean and standard deviation will be computed for each column. Next, each column will have its mean subtracted, and the result will be divided by the column standard deviation.

```
scaler = StandardScaler()
x_train_s = scaler.fit_transform(x_train)
```
