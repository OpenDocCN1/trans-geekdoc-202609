# III. Working with SQLite from Python

Python has APIs for working with databases. Here we use the SQLite API. The API uses specific code that wraps around the SQL query for execution. To distinguish the SQL code from the wrapper, the query will be defined in each code snippet. We begin importing the module and setting the relative path to the database. This assumes that the working directory is

C:\Users\apt4c\Documents\database

```python
# import the SQLite API
import sqlite3
```

```python
# set relative path to the database
PATH_TO_DB = "./sqlite/musicians.db"
```

Next, we create a connection to the database, the cursor will allow for defining a set of rows and performing complex logic on them.

```python
# create db connection
conn = sqlite3.connect(PATH_TO_DB)
```

```python
# create cursor
cur = conn.cursor()
```

Next, we define some artist data. For this small example, we create a list of tuples containing artist name and genres. For example, Taylor Swift's music can be categorized as country and pop.

```python
artists = [
    ('Taylor Swift', ['country', 'pop']),
    ('Chris Stapleton', ['country', 'soul', 'rock', 'bluegrass']),
    ('Bono Hewson', ['rock', 'pop'])
]
```

To create the table in the database, we will need to provide a schema. For each field, the schema needs to provide:

- The field name
- The field data type
- Optional attributes, such as whether the field may contain null values

Each database transaction ends with a commit command. Let's create the table, passing the schema:

```python
query = 'CREATE TABLE artist (artist_name string, genre string);'
cur.execute(query)
conn.commit()
```

Next, insert multiple records of data with executemany(). For each record, the placeholder (?,?,?) will be populated with the two columns of data in artists. The INSERT statement is how records are written to database tables with SQL.

```python
query = 'INSERT INTO artist VALUES (?,?);'
cur.executemany(query, artists)
conn.commit()
```

Let's verify that the data was stored properly. We will use a SELECT statement to select all rows and columns. The ‘*’ token will fetch all columns.

```python
query = 'SELECT * FROM artist;'
for row in conn.execute(query):
    print(row)
```

OUT:
('Taylor Swift', ['country', 'pop'])
('Chris Stapleton', ['country', 'soul', 'rock', 'bluegrass'])
('Bono Hewson', ['rock', 'pop'])

Note that the loop for fetching rows is required by the API. If we wanted to fetch all the rows in SQLite at the command line, we would simply run the query:

```bash
sqlite select * from artist;
```

OUT:
Taylor Swift|['country', 'pop']
Chris Stapleton|['country', 'soul', 'rock', 'bluegrass']

The result set has a different syntax, but it contains the same data.

Next, let's select only the musicians who sing country music. Filtering is done with the WHERE command. The text match can be implemented with the LIKE command like this:

```python
query = "SELECT * \
FROM artist \
WHERE genre LIKE '%%country%%';"

for row in conn.execute(query):
    print(row)
```

# NOTES:
# The character ‘’ is a line break for readability
# The character ‘%’ is a wildcard for string matching
# This will match on genres containing ‘country'

OUT:
('Taylor Swift', ['country', 'pop'])
('Chris Stapleton', ['country', 'soul', 'rock', 'bluegrass'])

This gives the correct output, but we really want the artist names. We were selecting all columns with '*', but we can specify the columns that we want. Let's run the same query but SELECT only the artist_name column:

```python
query = "SELECT artist_name \
FROM artist \
WHERE genre LIKE '%country%%';"

for row in conn.execute(query):
    print(row)

OUT:
('Taylor Swift',)
('Chris Stapleton',)
```

This has the right output. If we would like the artist names in a list, we store the first element of each tuple:

```python
data = []
query = "SELECT artist_name \
FROM artist \
WHERE genre LIKE '%country%%';"

for row in conn.execute(query):
    # extract artist name and append to list
    data.append(row[0])

print(data)

OUT:
['Taylor Swift', 'Chris Stapleton']
```

Storing the result allows for downstream use. # Counting and Aggregating

It is often useful to count the number of records in a table to understand its size. This can be done as follows:

```python
query = 'SELECT count(*) FROM artist;
conn.execute(query).fetchone()[0]
```

OUT:
3

The count(*) function counts the number of records. The fetchone() function retrieves the result set.

Data aggregations are useful for partitioning a dataset and computing statistics on each piece of the partition. An example is the calculation of a town's daily rainfall by month. These calculations are commonly and efficiently performed with Split-Apply-Combine pattern. The first step in the strategy is to define one or more grouping variables (in this case, the grouping variable would be month). Next, the months are split into discrete groups. For the records in each group, a function is applied to the values. Here, we calculate the mean rainfall over the days in January, February, and so on. This yields the daily average rainfall for each month. In the final step, the results from each group (the months) are combined into a structure, such as a table.

The Split-Apply-Combine pattern is supported in SQL and many other languages including Python and R. Let's demonstrate how to aggregate data using SQL. By creating a small dataset of concert venues with their states:

```python
query = 'CREATE TABLE venues
(venue_name string, venue_state string);'

('Santa Barbara Bowl', 'CA'),

query = 'INSERT INTO venues VALUES (?,?,?)'
cur.executemany(query, venue_data)
conn.commit()

query = 'SELECT * FROM venues;

    print(row)

OUT:
```
