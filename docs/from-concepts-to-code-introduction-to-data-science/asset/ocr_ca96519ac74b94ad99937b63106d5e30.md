# Differentiation Rules

We assume the functions $f(x)$ and $g(x)$ are differentiable on the domain of interest.

# Multiplication by a Constant

For constant $c$ and function $f(x)$,

```
$\frac{d}{dx}[cf(x)] = cf'(x)$
```

In this rule, the constant comes out of the differentiation.

Example:

```
$f(x) = 3x$
f'((x) = 3\frac{d}{dx}x$
f'((x) = 3(1) = 3$
```

# Derivative of a Sum of Functions

For function $h(x) = f(x) + g(x)$, $h(x)$ is differentiable and

```
$h'(x) = f'(x) + g'(x)$
```

Example: For $f(x) = 3x$ and $g(x) = 4$,

```
$h(x) = 3x + 4$
f'(x) = 3\frac{d}{dx}(x) + \frac{d}{dx}(4)$
f'(x) = 3 + 0 = 3$
```
