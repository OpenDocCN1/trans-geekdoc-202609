# Mathematics Preliminaries

Next, we investigated the monotonicity and convexity properties of a function. A monotonic function is either entirely nonincreasing or nondecreasing. A convex function forms a cup shape. Convexity simplifies the task of searching for the global minimum value on a domain.

The final topic on functions was a survey of different function types. Polynomials include linear functions, which feature prominently in regression analysis. The elementary functions include trigonometric functions, the exponential function, and the logarithm.

Many used functions in machine learning are differentiable functions. To build conceptual understanding we briefly reviewed the important concepts of limit, continuity, and derivative from calculus. The limit is the notion of getting arbitrarily close to point $f$ by changing the input value. A function is continuous at point $\xi$ if it is possible to get arbitrarily close by moving $x$ close to some point $\xi$. A function is continuous on an interval if it is continuous at each point within it.

The derivative measures the change in function output with respect to a change in input. It is equivalent to the tangent to the function at a given point after taking a limit. A function that is differentiable at each point in its domain is called a differentiable function.

The derivative has several useful applications and it can help us understand the underlying function. Differentiability implies continuity, but the reverse is not true. The derivative can help find extrema through use of critical points; these are points where the derivative is zero or undefined. Differentiation rules are faster to apply than the definition of the derivative; we reviewed some of these rules. The partial derivative measures specific targets to a function of multiple variables.

As our data is subject to randomness, we briefly reviewed probability theory which rests on a thorough mathematical framework. The essential ingredients are the triplet of sample space, events, and probability. A random variable is a quantity subject to the sample space as a mapping to a measurable space. A random variable may be discrete (finite or countable number of outcomes) or continuous (uncountable number of outcomes).

The probability that an event will occur is the number of ways of achieving success divided by the number of possible outcomes. When information is provided, this can be included in probability calculations; the probability given is the conditional probability. When one variable does not affect the probability of another, they are independent.

We reviewed examples of discrete random variables (discrete uniform, Bernoulli) and continuous random variables (uniform, Normal, and Standard). Discrete random variables use a probability function to specify the probability at each possible value. Continuous random variables use a probability density function to specify the probability over a range of values, as the probability of any particular value is zero. The cumulative distribution function is a function that takes the possible values as input and returns the probability of realizing that value or lower as output.

# Exercises

Many variables follow a normal distribution or something approximately normal. The sum of a large number of independent, identically distributed random variables follows an approximately normal distribution by the central limit theorem. It is often useful to convert a normally distributed random variable to a standard normal using standardization. Computing probabilities of random variables can be easily accomplished through software.

A matrix is a rectangular array of numbers. The number of rows and columns of matrix, or dimensions, will be important when performing operations. We reviewed matrix addition, subtraction, and multiplication. Matrix multiplication is not commutative (AB does not always equal BA). Addition and subtraction are done element-wise, while multiplication is done with interchanging rows for columns (or vice versa). The identity of a matrix is a square matrix with 1 on the diagonal and 0 elsewhere. The inverse of a square matrix $M$ will produce the identity matrix when it is multiplied by $M$ on the left or right. When a matrix has an inverse, it is called invertible. The inverse of a matrix is best implemented with software.
