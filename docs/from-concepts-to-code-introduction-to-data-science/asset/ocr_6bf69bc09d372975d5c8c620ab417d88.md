A confidence interval can be used for conducting a two-tailed hypothesis test. If the hypothesized test $H_0$ does not fall in the confidence interval, then we can reject $H_0$ at significance level $\alpha$. Reproducing our parameter estimates in Table 9.2, the rightmost columns with headers $[0.025$ and $0.975]$, show 95% confidence interval lower limits and upper limits, respectively. For the example, the 95% confidence interval for the parameter on alcohol is $(0.291, 0.328)$. The null hypothesis assumes a parameter value of zero for each parameter test. Since zero is not contained in the confidence interval, the null can be rejected in each test.
