```
$\hat{Y} = \hat{eta}_0 + \hat{eta}_1 \times \text{alcohol} + \hat{eta}_2 \times \text{ph}$
```

The quantity $Y$ denotes a predictor. The values $\hat{eta}_0$, $\hat{eta}_1$, and $\hat{eta}_2$ are coefficient estimates (called coef) in the table. It is important to understand if these estimates are different from zero, as this would suggest their predictors are important. While the estimates may have values like 1 or 2, it is important to take their standard error into account when deciding if they are significantly different from zero.

Let's walk through the table to make sense of it. The rows alcohol and ph represent predictors to be tested. The Intercept is a constant added to the model; we can treat this as a third parameter to be tested. The hypotheses for alcohol, are $H_0: \beta_1=0$ versus $H_A: \beta_1 \neq 0$. This is a two-tailed test to determine if $\beta_1$ is significantly different from zero. The data sample is used to compute the estimate of $\hat{eta}_1=0.3093$.

As a sample difference will produce a estimate, we need to know the standard error of $\hat{eta}_1$; this is to 0.009 in the std err column. Next test statistic is then computed. It will have the form a t-statistic (hypothesized value)/standard error. In this case, the test statistic is a t-statistic that reduces to $t=$ estimate/standard error, which equals $H_0$. The test statistic reduces to $t=33.207$ when plugging in non-rounded values.

Given t, p-value of a two-tailed test is computed from the t-distribution with appropriate degrees of freedom $\nu$. In this case, $\nu$ is the number of observations minus the number of predictors. The large value $t=33.207$ produces a small p-value=0.000. This is sufficient to know that the p-value is less than $\alpha=0.05$, which leads us to reject $H_0$ at this level and conclude that $\beta_1$ is significantly different from zero. We reach the same conclusion for Intercept and ph: at $\alpha=0.05$, their coefficient estimates are significantly different from zero.
