The calories contain integers, while the other variables contain strings due to the inclusion of units such as "10.5mg" or "10.5 mg". Note that in a proper database, units would be in a separate field from values, but data in the wild has complications. Our strategy will be to loop over each variable, which are strings, retain only the numeric portions, and cast the values to floats. Then "10.5mg" or "10.5 mg" will become 10.5. The regular expression pattern, regex, that we will use in this: [\d]+. Regex can be tricky for the uninitiated, but with exposure and practice comes skill. The plus sign (+) denotes one or more, and it allows for retaining all dots (.) and slashes (/). For small tasks, simply searching for a regex should give the right form. An excellent tool for building, testing, and debugging is https://regex101.com/

We loop over each variable to prepare it for modeling:

```
# clear the column if it doesn't hold integers
 not isinstance(df[var].values[0], np.int64):

# use regex to retain numeric part of data
df = df[var].str.replace(r'([^.||\d]+)', '')

# convert strings to floats
df = df[var].values.astype(float)
```
