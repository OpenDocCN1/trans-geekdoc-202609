## 8.2 Functions

For sets A and B, a function is a rule or mapping that takes an element of A as input and assigns an element of B as output. This is commonly written f: A -> B for a function f. The space of inputs A is called the domain, and the space of outputs B is called the range. The value of the function at a point x can be written f(x). Note that for each input value, there can only be one output value. The vertical line test is a graphical method for checking if a curve is a function. If vertical line intersects the curve in more than one place, then it is not a function. Note we might define a function using the y notation as in y = 2x or using the f(x) notation as in f(x) = 2x to clarify the functional dependence on x.

It is completely valid for a function to map two or more inputs to the same output. Figure 8.1 shows the graph of the function $f(x) = x^2$. Both $-x$ and $x$ will map to the same value $f(-x) = f(x)$ for all $x$. For example, $f(-2) = f(2) = 4$.

## Function Composition

**Function composition** is an operation $\circ$ that takes two functions $f$ and $g$ and produces a new function $h = g \circ f$ such that $h(x) = g(f(x))$. The function $f$ is applied, followed by the function $g$. For cases where two functions are composed, say $k \circ g \circ f$, we apply the functions from right to left, taking them two at a time. For example, $k \circ g \circ f = k(g(f(x))) = k(h(x))$, by applying the equation $h(x) = g(f(x))$. The evaluation of this nested composition is supported by the associative property of function composition.

Consider an example with two functions $f(x) = x+1$ and $g(x) = \sqrt{x}$, each defined for the set $x \ge 0$. We form the function composition $h(x) = g(f(x)) = \sqrt{x+1}$. We can compute $h(3)$ and $h(-2)$. The first case is possible, with $h(3) = \sqrt{3+1} = 2$. The second case is undefined, since $h(-2) = \sqrt{-2+1} = \sqrt{-1}$. Hence, composition will only work where the domain of $h$ is defined. In this case, the domain $x \ge -1$.

Function composition is particularly important in data science because machine learning models apply a sequence of functions to data. In computer vision, image pixels can be arranged in layers and aggregated averaged many times to infer whether an object of interest can be found.

## Monotonicity

A function is monotonic if it is either entirely increasing or entirely decreasing. A function $f$ is strictly increasing if for $x_1 < x_2$, we have $f(x_1) < f(x_2)$. Similarly, $f$ is strictly decreasing if for $x_1 < x_2$, we have $f(x_1) > f(x_2)$.

A function is monotonic if it is monotonic on its domain. A strictly monotonic function is one-to-one, which means it has an inverse.

## Preliminaries

A function $f$ is injective if for every input in the domain, there is exactly one output in the range. The domain of a function is the set of all possible input values. The range of a function is the set of all possible output values.

A function is continuous if it can be drawn without lifting the pen. Formally, a function $f$ is continuous at a point $c$ if the limit of $f(x)$ as $x$ approaches $c$ exists and is equal to $f(c)$.

A function is differentiable at a point if it has a derivative at that point. The derivative $f'(x)$ represents the slope of the tangent line to the graph at $x$.

## Convexity

A function $f$ is convex if for any line segment connecting two points on the graph, the segment lies above or on the graph. Geometrically, a convex function "bowls upwards". Formally, $f$ is convex if for all $x_1, x_2$ in the domain and $t \in [0, 1]$, $f(tx_1 + (1-t)x_2) \le tf(x_1) + (1-t)f(x_2)$.

A function $f$ is concave if $-f$ is convex. Alternatively, if any line segment connecting two points on the graph lies below or on the graph. Geometrically, a concave function "bowls downwards". Formally, $f$ is concave if for all $x_1, x_2$ in the domain and $t \in [0, 1]$, $f(tx_1 + (1-t)x_2) \ge tf(x_1) + (1-t)f(x_2)$.

A function is linear if it is both convex and concave. A linear function has the form $f(x) = ax + b$.

A function is convex if its second derivative is non-negative, $f''(x) \ge 0$. A function is concave if its second derivative is non-positive, $f''(x) \le 0$.

## Extrema

A function $f$ has a local minimum at $x$ if $f(x) \le f(x^*)$ for all $x^*$ in some neighborhood of $x$. It has a local maximum at $x$ if $f(x) \ge f(x^*)$ for all $x^*$ in some neighborhood of $x$. A global minimum is a local minimum that is the smallest over the entire domain. A global maximum is a local maximum that is the largest over the entire domain.

To find the extrema of a differentiable function, we find points where the derivative is zero, $f'(x) = 0$. These points are called critical points. After finding critical points, we can use the second derivative test to determine if they are minima or maxima: if $f''(x) > 0$, $x$ is a local minimum; if $f''(x) < 0$, $x$ is a local maximum.
