
## Classification with Logistic Regression

The term $p(x_i|\beta)$ denotes the probability of the event $i$ given the parameter values, and the term $1-p(x_i|\beta)$ denotes the probability of a non-event for outcome $i$. The exponents $y_i$ and $1-y_i$ allow for a compact expression for a Bernoulli trial. For example, if the event occurs for outcome $i$, then $y_i = 1$ and $1-y_i = 0$. It follows that

```
$p(x_i|\beta)^{y_i}(1-p(x_i|\beta))^{1-y_i} = p(x_i|\beta)^1 (1-p(x_i|\beta))^0\n= p(x_i|\beta)$
```

represents the probability of an event for outcome $i$. Similarly, if the event did not occur for outcome $i$, then $y_i = 0$ and $1-y_i = 1$. It follows that

```
$p(x_i|\beta)^{y_i}(1-p(x_i|\beta))^{1-y_i} = p(x_i|\beta)^0 (1-p(x_i|\beta))^1\n= 1-p(x_i|\beta)$
```

This term represents the probability of a non-event for outcome $i$.

Lastly, the product notation $\prod_{i=1}^n$ expresses the likelihood of events. For the case of three trials $(n=3)$ all resulting in events, the likelihood will be

```
$\mathcal{L}(\beta) = \prod_{i=1}^n p(x_i|\beta)^{y_i}(1-p(x_i|\beta))^{1-y_i}\n= = \prod_{i=1}^3 p(x_i|\beta)\n= = p(x_1|\beta)p(x_2|\beta)p(x_3|\beta)$
```

It is easier to work with the **log-likelihood**, or the logarithm of the likelihood, as the products become sums. It is valid to apply the logarithm, as the parameters that maximize the likelihood will also maximize the log-likelihood. This is because $log(\cdot)$ is a monotonically increasing function. The log-likelihood has the form

```
$l(\beta) = \sum_{i=1}^n y_i \ln p(x_i|\beta) + (1-y_i) \ln (1-p(x_i|\beta))$
```

This uses two properties of logarithms:

```
$log(ab) = log(a) + log(b)\nlog(a)^b = b log(a)$
```

## Mathematical Framework

Filling in the steps,

```
$l(\beta) = \ln \prod_{i=1}^{n} p(x_i|\beta)^{y_i}(1 - p(x_i|\beta))^{1-y_i}$
= \sum_{i=1}^{n} \ln p(x_i|\beta)^{y_i}(1 - p(x_i|\beta))^{1-y_i}$$\n= \sum_{i=1}^{n} \ln p(x_i|\beta)^{y_i} + \ln (1 - p(x_i|\beta))^{1-y_i}$$\n= \sum_{i=1}^{n} \ln p(x_i|\beta) + (1 - y_i) \ln (1 - p(x_i|\beta))$
```

> Note: In the introductory chapter on machine learning, we defined the cross-entropy loss for binary classification as follows:
$H(\hat{p}_i, y_i) = -y_i \ln(\hat{p}_i) + (1 - y_i) \ln (1 - \hat{p}_i)$
If we sum the cross-entropy loss over $n$ observations, it will be equivalent to the negative log-likelihood.

We can apply the logarithm property $log(a/b) = log(a) - log(b)$ to yield

```
$l(\beta) = \sum_{i=1}^{n} \ln (1 - p(x_i|\beta)) + y_i \ln \frac{p(x_i|\beta)}{1 - p(x_i|\beta)}$
```

The term on the right is odd, which can be replaced by the linear term $\beta_0 + \beta_1 x_1 + \dots + \beta_k x_k$ like this:

```
$I(\beta) = \sum_{i=1}^{n} \ln (1 - p(x_i|\beta)) + \sum_{i=1}^{n} y_i (\beta_0 + \dots + \beta_k x_k)$
```

Substituting for $1 - p(x_i|\beta)$ and simplifying yields

```
$l(\beta) = \sum_{i=1}^{n} -ln (1 + exp(\beta_0 + \dots + \beta_k x_k)) + \sum_{i=1}^{n} y_i (\beta_0 + \dots + \beta_k x_k)$
```

## Gradient Descent

Now we have an expression for the log-likelihood, we want to maximize it. Unfortunately, it is not possible to follow approach (take partial derivatives, set equal to zero, and find the critical point), as there is no closed-form solution. Instead, we use a numerical approach to find an approximate solution. The convention in optimization is to solve a minimization problem, and maximizing the log-likelihood would be reframed as minimizing the negative log-likelihood. There are many algorithms to accomplish this task, and we will use gradient descent as it is an iterative method that simultaneously updates the parameters according to this equation:

```
$\beta^{(t+1)} = \beta^{(t)} - \alpha \frac{\partial l(\beta)}{\partial\beta^{(t)}}$
```

where
- $\beta^{(t)}$ is vector of parameter estimates at iteration $t$
- $\alpha$ is the learning rate or step size
- $\partial l(\beta)/\partial\beta^{(t)}$ is the gradient of the log-likelihood

A useful analogy for understanding gradient descent is a hiker finding the lowest point in the mountains. Imagine that she moves downhill in the direction of greatest descent (the gradient). For a given number of paces (the learning rate), the algorithm begins by initializing the parameter estimates as $\beta^{(0)}$. The parameter update moves in the direction of the largest change, which is determined by the gradient, bringing estimates closer to their optimal values. A larger step size can lead to faster convergence, but it might miss the minimum. When optimality is reached, the algorithm is said to converge. In practice, it may not be possible to reach optimality (due to a bad start) or take a very long time (due to a small alpha). Stopping criteria are used to prevent the algorithm from running indefinitely: (1) a maximum number of iterations is provided, and (2) a tolerance is set to determine when a change in the objective function is small enough to stop.

```

$\frac{d}{d\beta}ln(1+\beta x) = \frac{1}{1+\beta x}\frac{d}{d\beta}(1+\beta x)$

The function we differentiate also includes an exponential term. As a reminder, the differentiation rule for exponential looks like this:

```
$\frac{d}{dx}e^x = e^x$
```

We have a composite function of the exponential, so the chain rule can be used again. For example,

```
$\frac{d}{d\beta}e^{\beta x} = e^{\beta x}\frac{d}{d\beta}(\beta x)$
