# 13.3.1 Data Splitting

In practice, we would spend some additional time exploring the data to understand its properties and weaknesses. For brevity, let's assume this was done. Next, since we want to train a model and assess how its performance generalizes to unseen data, we will train the model on the training set and the test set. We will train the model on the training set and the test set, and we can evaluate its performance to be better on the former, as the model will learn patterns in this set. The hope is that the model performs similarly on the test set. For splitting the data, we will use the function train_test_split() from sklearn. It takes four parameters and returns four datasets. Let's look at the code and how it works:

```
x_train, x_test, y_train, y_test = 
train_test_split(housing.data,
housing.target,
train_size = 0.6,
random_state=314)
```

INPUTS:

+   - housing.data - the predictor data
- housing.target - the target data
