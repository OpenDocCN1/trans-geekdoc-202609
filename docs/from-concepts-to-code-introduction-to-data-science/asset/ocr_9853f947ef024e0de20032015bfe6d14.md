# Music Query: Single Table

This gives the correct output, but we really want the artist names. We
were selecting all columns with '*', but we can specify the columns that we
want. Let's run the same query but SELECT only the artist_name column:

```
query = "SELECT artist_name \
FROM artist \
WHERE genre LIKE '%country%%";
```

for row in conn.execute(query):

```
print(row)

OUT:
('Taylor Swift',
('Chris Stapleton',))
```

This has the right output. If we would like the artist names in a list, we
store the first element of each tuple like this:

```
data = []
query = "SELECT artist_name \
FROM artist \
WHERE genre LIKE '%country%%";
```

for row in conn.execute(query):

```
# extract artist_name and append to list
data.append(row[0])
```

```
print(data)

OUT:
['Taylor Swift', 'Chris Stapleton']
```

Storing the result allows for downstream use later.

# Counting and Aggregating
