Now that the dataset is numeric and scaled, it is ready for k-means. We fit k-means using a range of values for k. For each fitting, we compute the silhouette score and save it in list for subsequent visualization. To improve the chances of the algorithm converging to a global optimum, we set 100 initializations.

```
scores = []

```

   print(f'fitting k-means for {cls} clusters')

```
# fit k-means
kmeans = KMeans(n_clusters=cls,
               random_state=rand,
               n_init=100).fit(scaled_data_sub)

```
