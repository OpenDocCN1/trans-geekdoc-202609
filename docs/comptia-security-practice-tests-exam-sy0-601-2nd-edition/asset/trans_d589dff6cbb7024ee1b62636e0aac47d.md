以下是问题 193–195 的场景。

弗兰克是小型公司的首席 IT 人员，已将其公司的基础设施从本地数据中心迁移到基于云的基础设施即服务（IaaS）提供商。最近他收到了报告称其网站响应缓慢且有时无法访问。弗兰克认为攻击者可能正在对其组织进行拒绝服务攻击。

- 193. C. 弗兰克的最佳选择是审查其云托管提供商提供的抗拒绝服务和其他安全工具，并适当使用它们。主要的 IaaS 提供商拥有多种安全工具，可帮助检测和防止 DoS 攻击导致其基础设施上托管的站点宕机。联系云服务提供商的 ISP 是行不通的，因为 ISP 与云提供商合作，而不是与弗兰克合作！云服务提供商可能能够协助弗兰克，但他们最有可能指示他使用他们已提供的现有工具。
- 194. C. 由于弗兰克使用的是云服务提供商的 Web 服务，他需要审查他们捕获的日志。如果他尚未配置日志，他需要这样做，然后他需要一种服务或能力来分析他关心的流量类型。Syslog 和 Apache 日志都存在于传统的 Web 主机上，如果弗兰克在 IaaS 环境中运行自己的 Web 服务器，则它们是合适的。
- 195. B. 最有用的数据可能来自 IPS，即入侵防御系统。他将能够确定攻击是否为拒绝服务（DoS）攻击，并且 IPS 可能帮助他确定拒绝服务攻击的来源。防火墙可能提供一些有用信息，但只会显示流量是否被允许，而不会分析流量以获取攻击信息。漏洞扫描器会指出其应用程序或服务器是否存在问题，但不会识别此类攻击。反恶意软件可以帮助在系统上找到恶意软件，但对 DoS 攻击无效。
- 196. D. 合同条款、审计和安全审查都是在与执行系统集成工作的供应商合作时降低第三方风险的常见手段。如果要使用第三方供应商的数据中心或托管服务，通常会请求 SOC（服务组织控制）报告。
- 197. B. 使用受污染数据训练人工智能（AI）或机器学习（ML）系统是一个重大问题。埃利亚斯需要确保其网络上的流量典型且无恶意，以确保 AI 不会认为恶意流量对其网络是正常的。
- 198. C. 黑客行动主义者最常见的动机是发表政治声明。声誉提升通常与脚本小子相关，而经济利益最常见的是有组织犯罪或内部威胁的目标。收集高价值数据是国家行为者和有组织犯罪的典型行为。
- 199. D. 预测分析工具使用大量数据，包括有关安全趋势和威胁的信息、来自各种安全工具和其他来源的大型安全数据集以及行为模式，以预测和识别恶意和可疑行为。
- 200. C. 身份欺诈和身份盗窃通常使用社会安全号码作为身份盗窃的一部分。尾随是指跟随某人通过安全门或闸门，以便不必出示凭证或代码，而冒充是社会工程技术，即声称自己是别人。勒索是一个潜在答案，但最常见的用途是身份欺诈。
- 201. A. SOAR 工具，如安全信息和事件管理（SIEM）工具，高度专注于安全运营。它们包括威胁和漏洞管理、安全事件响应以及安全运营和自动化工具，但不提供源代码分析和测试工具。
- 202. B. Security+ 考试大纲明确将这些项目列为威胁向量。虽然还有许多其他向量，但你应熟悉直接访问、无线、电子邮件、供应链、社交媒体、可移动媒体和云作为考试的向量。
- 203. C. 虽然乍一看可能很奇怪，但 SourceForge 和 GitHub 都用于存放示例漏洞利用代码以及威胁情报分析人员可能觉得有用的其他信息。它们不是暗网的一部分，也不是自动指标共享（AIS）来源或公共信息共享中心。
- 204. B. 信任而非验证用户输入是不当输入处理的根本原因。所有输入都应被视为潜在恶意，因此被视为不可信。应执行适当的过滤、验证和测试，以确保仅接受和处理有效的数据输入。
