
**204.** B. 可信平台模块（TPM）被用作现代个人电脑硬件信任根的基石。TPM 可以提供加密密钥、PUF（物理不可克隆函数）或设备唯一序列号。CPU 和硬盘不用于此功能，而 HSM（硬件安全模块）用于公钥基础设施（PKI）和加密目的，但不用作个人电脑的硬件信任根。

**205.** C. 下一代防火墙通常内置 URL 过滤、黑名单等高级功能，以及超越简单包过滤或有状态包检测的其他应用层能力。

**206.** D. 移动应用管理（MAM）工具专为此目的设计，允许将应用分发到移动设备、从移动设备移除并在移动设备上进行管理。MOM 是 Microsoft Operations Manager，这是一种系统管理工具，微软在当前使用中已用 Operations Manager 取代了它。MLM 通常指多层次营销或金字塔骗局——而不是安全术语。MIM 也不是安全术语。

**207.** A. 云应用与本地应用有许多相同的担忧，但由本地访问导致运行应用的系统被入侵的场景要小得多。云应用供应商更可能在安全的数据中心运营，除授权人员外，对服务器的访问受限或完全不可访问，从而大大降低了此类安全问题的可能性。

**208.** D. 证书颁发机构（CA）最关键的部分是其根证书，确保根证书永不暴露对该 CA 的持续运营至关重要。因此，根 CA 通常以离线 CA 的形式维护，使攻击者更难入侵系统并获取根证书。实际上，被入侵的 CA 可能会失去全球组织的信任，无法继续开展业务。

**209.** C. 分流隧道 VPN 仅将通过 VPN 发往远程网络的流量发送，所有其他流量分流出去，使用 VPN 系统或用户的主网络连接。这减少了通过 VPN 发送的总体流量，但也意味着这些流量无法通过 VPN 进行监控和保护。Half-pipe 不是安全术语，而水平分割（split horizon）最常用于描述内部和外部 DNS 视图可能不同的 DNS。

**210.** A. 环路保护正是查找这类问题。环路保护发送包含 PDU（协议数据单元）的数据包。这些数据包会被其他网络设备检测到，并允许网络设备关闭它们接收到这些数据包的端口。其余选项是为本题杜撰的。

**211.** C. 蜂窝运营商和手机制造商都使用 OTA（空中下载）更新来提供固件更新和更新的电话配置数据。移动设备管理（MDM）工具可用于监控当前固件版本和电话设置，使 Charles 能够确定其员工使用的手机是否已更新以确保安全。网络访问控制（NAC）代理可能会捕获其中部分数据，但仅限于联网手机，这不包括场外手机、关闭 Wi-Fi 的手机或远程设备。OTA 并非专门用于更新加密密钥的方式，尽管固件或设置可能包含这些密钥。OTA 不是由手机本身发送的。

**212.** C. 开源防火墙通常不具备商业防火墙同等级的厂商支持和维护。这意味着如果出现问题，你没有厂商可以求助，你将依赖支持社区来提供补丁和更新。开源防火墙通常更便宜，其开源特性意味着任何人都可以验证代码，只要愿意检查，而且下载即可获得，速度很快。

**213.** C. WPA3 个人版用 SAE（对等实体同时认证）取代了 PSK（预共享密钥）。SAE 通过要求攻击者在每次认证尝试之前与网络进行交互，有助于防止针对密钥的暴力破解攻击。这减慢了暴力破解攻击的速度。WPA3 还包含 192 位加密模式。它不会用 128 位加密替换 64 位加密、增加每信道安全性或添加分布式拒绝服务（DDoS）监控和防护。

**214.** B. Security Enhanced Linux（SELinux）为基于 Linux 的系统提供强制访问控制，而 SEAndroid 是 SELinux 在 Android 上的实现。这意味着 Isaac 可以使用 SEAndroid 来实现他的目标。Android 确实使用注册表，但没有 MAC 模式。MACDroid 是为本题编造的，单用户模式也不会使 Android 成为基于 MAC 的系统。

**215.** B. 所描述的系统是特权访问管理（PAM）系统。PAM 系统用于安全管理并控制特权账户。MAC 是一种在操作系统级别强制访问的访问控制方案。FDE 是全盘加密，TLS 是传输层安全性。

**216.** A. 使用允许控制设备的移动设备管理（MDM）工具，可以让 Amina 锁定摄像头，防止员工使用 Android 平板电脑拍照。她仍然需要确保员工不会将自己的带摄像头设备带入设施。DLP 是数据丢失防护，OPAL 是硬盘加密标准，MMC 有多种含义，包括多媒体卡和 Windows 系统的 Microsoft Management Console 管理单元，这些都不能提供她所需的那种控制。

**217.** C. 统一端点管理（UEM）工具可以管理台式机、笔记本电脑、移动设备、打印机和其他设备。UEM 工具通常使用部署到移动设备上的应用来配置和管理它们，Olivia 在此列表中的最佳选择是 UEM 工具。CASB 是云访问安全代理，不用于管理移动设备；其他选项需要大量手动工作，且不太可能成功——或者用户只会在方便时更改设置。

**218.** C. 下一代（NG）安全 Web 网关（SWG）在云访问安全代理和下一代防火墙的功能基础上增加了额外功能。虽然功能可能有所不同，但可能包括 Web 过滤、TLS 解密以支持流量分析和高级威胁防护、云访问安全代理（CASB）功能、数据丢失防护（DLP）和其他高级能力。这类解决方案相对较新，市场变化迅速。

**219.** C. 访问策略是根据有关访问请求的信息和属性构建的。如果满足策略要求，则可以执行允许或拒绝访问、要求额外身份验证步骤等操作。地理位置和基于时间的登录侧重于单一信息组件，账户审计用于审查账户的权限，而不是执行此类验证或基于策略的控制。

220. B. 文件权限的数字表示通常在使用 chmod 时替代 rwx 表示法。数字 7 设置完全权限，第一个数字设置用户权限，这意味着这里用户将被授予对该文件的完全访问权限。

221. B. 证书固定将已知证书与主机关联，然后将该已知证书与所呈现的证书进行比较。这有助于防止中间人攻击，但如果证书已更新而固定的证书没有更新，则可能会失败。CRL（证书吊销列表）会显示证书是否已被吊销，但不会显示证书是否已更改。Patrick 无法访问远程服务器的私钥，除非他恰好是管理员。

222. C. 隐私增强邮件（PEM）是证书颁发机构签发的最常见格式。DER（可区分编码规则）格式是 ASCII 文本 PEM 格式的二进制形式。PKCS#7 或 P7B 格式是 Base64 ASCII，而 PKCS#12（即 PFX）格式是用于将服务器证书、中间证书和私钥存储在单个文件中的二进制格式。

223. C. Michelle 唯一的选择是，在每一台信任该证书的机器上，将其从受信任证书列表中移除。这可能非常耗时且容易出错，这也是许多组织在生产环境中避免使用自签名证书的原因之一。

224. D. 将与域名关联的 IP 地址更改为任意值可能会导致路由或其他问题。这意味着更改 IP 地址将不是验证域名的一种可选方法。其余选项是合法且正常的证书验证方式。

225. A. SNMPv3 增加了对用户和组进行身份验证、然后加密消息的能力，从而提供消息的完整性和保密性。它没有内置 SQL 注入防护，但它也不是通常需要考虑 SQL 注入问题的协议。

226. A. 此图显示的是反向代理。反向代理接受来自外部世界的连接，并将它们发送到内部服务器。正向代理接受内部连接并将它们发送到外部服务器。轮询和下一代代理并不是代理的类型，尽管轮询是一种负载均衡形式。
