1. **C.** 图中显示了服务和端口，但未列出协议。Ben 应询问这些服务是基于 TCP 还是 UDP，因为错误的猜测会导致服务无法正常运行，而开放不必要的协议可能会无意中造成暴露或风险。子网掩码在客户端网络中需要多个系统时显示，服务名称对于防火墙规则并非必需，API 密钥也不应存储在这样的文档中。

2. **A.** 正确答案是 Open Web Application Security Project（OWASP）。它是 Web 应用程序安全的事实标准。北美电力可靠性公司（NERC）关注发电厂安全，Trusted Foundry 是用于描述计算机 IC 安全供应链的术语，而 ISA/IEC 标准用于保护工业自动化和控制系统（IACSs）。

3. **B.** 供应商多样性带来两个安全好处。首先是如果某个供应商停止运营，不会存在单点故障。第二个好处是每个供应商都有特定的方法和算法来检测恶意软件。如果你在所有需要恶意软件检测的位置都使用同一供应商，那么该供应商方法中的任何缺陷或弱点都会在网络中持续存在。使用单一供应商意味着该供应商方法或技术中的任何弱点都可能影响整个系统或网络。供应商分叉（vendor forking）不是行业术语，而且这并非中立行为；供应商多样性可以改善安全性。

4. **B.** 在这种场景下，最适合 Scott 需求的是一个带有主 NAS 完整副本的第二个网络附加存储（NAS）设备。在故障场景中，辅助 NAS 可以直接取代主 NAS，同时替换单个磁盘甚至整个 NAS。基于磁带的备份需要更长的恢复时间，无论它们是完整备份还是增量备份，尽管在某些情况下增量备份可能花费更多时间，因为按顺序更换磁带会增加恢复过程的时间。最后，基于云的备份系统在 Scott 担心本地灾难时会有用，但会比本地相同的 NAS 更慢，因此无法满足 Scott 的主要需求。
