The second benefit is that each vendor has a specific methodology and algorithms used for detecting malware. Using a single vendor means that any weakness in that vendor’s methodology or technology could impact the entire system or network. Vendor forking is not a term in the industry, and this is not a neutral act; vendor diversity improves security.
