**64. A.** VM escape is a situation wherein an attacker is able to go through the VM to interact directly with the hypervisor and potentially the host operating system. The best way to prevent this is to limit the ability of the host and the VM to share resources. If possible, they should not share any resources. Patching might mitigate the situation, but it is not the most effective solution. Using firewalls and antimalware tools is a good security practice but would have minimal effect on mitigating VM escape.
