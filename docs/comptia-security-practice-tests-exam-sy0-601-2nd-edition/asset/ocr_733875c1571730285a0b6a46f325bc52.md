87. C. An intrusive scan attempts to actively exploit vulnerabilities, and thus could possibly cause some disruption of operations. A penetration test actually attempts to breach the network by exploiting vulnerabilities. An audit is primarily a document check. Both intrusive and nonintrusive vulnerability scans can be effective at finding vulnerabilities.
