We retrieved the whole transcriptomic dataset comprised of 47 samples and 64253 expression values (Barrett et al., 2012). ## 2.2. Computational framework

Fig. 1 demonstrates the performed steps of the presented computational framework. In the data preprocessing part, biopsy samples of LP were obtained from the patients. Then, samples were collected and prepared to be provided to a biological technology measuring the expression level of genes (Bi et al., 2020). In the machine learning part, we are given a gene expression dataset as {(x1, y1), ... (xm, ym)}, where xi designates the ith sample and yi is the corresponding sample type. In this study, we considered yi in the binary case ({Control, Lichen Planus}). We encoded all samples xi (for i = 1...m) as an m × n matrix, where m and n are the numbers of samples and genes, respectively. We also had a 1 × m column vector, encoding all sample types yi (for i = 1...m). We aimed to identify p important genes out of the n genes, where p << n and these p genes are expressed in each sample. Therefore, we presented these new sparse variants of the SVM, working as follows: in Eq. (1), we sought to find arguments (i.e., w = [w1... wn] and bias b ∈ R) minimizing the objective function subject to shown constraints. Each sample was encoded by expression values of n genes. As a result, weights in w corresponded to the gene importance among all samples. Because w is used in SVM model as sign(w.x+b) to discriminate between Control and LP examples, a higher weight |wi| in absolute value refers to the more greater importance of the ith gene. A modified version of SVM leading to sparse representation is given by

```
arg min w,b ||w||^2 / 2 + c sum_{i=1}^m xi^k
subject to yi(w . xi + b) >= 1 - xi, i = 1, 2, ..., m
xi >= 0,
||w||_1 <= lambda.
(1)
```

In the above equation, the constrained optimization problem is different from the soft margin SVM in (Turki and Taguchi, 2023) as it includes additional constraint, ||W||_1 <= lambda, shrinking weights for genes with less prediction power closer to zero. That leads to increased sparsity for weight vector w. ||W||_1 = (sum_{i=1}^n |wi|) is the L1-norm, lambda ∈ R. Eq. (2) shows a new variant of the constrained optimization problem as
arg min w,b u sum_{i=1}^m phi(||w||^2 / 2) + c sum_{i=1}^m xi^k
phi(v) = { 2r|v| - r^2, if |v| > r; v^2, otherwise }
subject to yi(w . xi + b) >= 1 - xi, i = 1, 2, ..., m
xi >= 0,
||w||_1 <= lambda.
(2)

where we included ||W||_1 <= lambda as an additional constraint. Therefore, when |v| > r, then Eq. (2) becomes
arg min w,b u sum_{i=1}^m (2r | ||w||^2 / 2 | - r^2) + c sum_{i=1}^m xi^k
subject to yi(w . xi + b) >= 1 - xi, i = 1, 2, ..., m
xi >= 0,
||w||_1 <= lambda.
(3)

Otherwise, the constrained optimization problem becomes as
arg min w,b u sum_{i=1}^m (||w||^2 / 2)^2 + c sum_{i=1}^m xi^k
subject to yi(w . xi + b) >= 1 - xi, i = 1, 2, ..., m
xi >= 0,
||w||_1 <= lambda.
(4)

For a given input dataset, we had different w and b as a result of the different optimization problems. We utilized CVXR in R to find the weight vector w and bias b, minimizing the constrained optimization problem (Fu et al., 2020). For the enrichment analysis part, we uploaded p genes associated with the highest p weights ( |w1| > |w2| > ... > |wp| ) to enrichment analysis tools, namely Enrichr and Metascape, identifying and interpreting biological-related terms such as important expressed genes, drugs, drug targets, therapeutic targets, and others to be explained in the subsequent section.
