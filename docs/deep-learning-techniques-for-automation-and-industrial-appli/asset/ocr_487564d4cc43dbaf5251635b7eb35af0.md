# 8.1 Introduction

Steganalysis is a method to detect whether a particular image is pure or contains some hidden information that can be a possible malicious act. There are several methods available to hide information known as steganographic methods [1, 2]. Though steganography can be used for good purposes like hiding consumer data in credit cards, its use has increased considerably for ill purposes. Forensic experts have to deal with millions of images daily and steganalysis helps in identifying adulterated images through steganography. These adulterated images are named as stego images while their original ones are cover images. Specific steganalysis [3] targets known steganographic methods, while universal steganalysis [4] deals with stego images created through any steganographic method.

Universal steganalysis is a form of supervised machine learning technique in which classifiers are trained on features extracted from both cover and stego images. For a long time, extracting rich features, such as spatial rich model (SRM) [5], projection SRM (PSRM) [6], and max-SRM [7], followed by an ensemble classifier (EC) [8] were the successful methods for discovering stego images. Unfortunately, these features are very high in number, e.g., 34671 for SRM, so researchers used a lot of feature selection techniques to improve the classification results and decrease the classification time [9, 10]. With the successful application of deep learning methods in computer vision, researchers moved towards applying these methods also to steganalysis, and soon they found good results. A deep learning method combines feature extraction and classification by learning the features automatically from the images in a supervised manner after using output from the classifier.

With the resemblance of filters used in convolutional neural networks (CNN) and SRM, researchers explored CNNs for steganalysis, and customized CNNs to suit steganalysis needs. The highly content-adaptive steganographic methods, such as HUGO [11], Wavelet Obtained Weights (WOW) [12], Spatial UNIversal WAvelet Relative Distortion (S-UNIWARD) [13] in the spatial domain, and JPEG UNIversal WAvelet Relative Distortion (J-UNIWARD) [13], Uniform Embedding Distortion for JPEG Compression (UED-JC) [14] in Joint Photographic Expert Group (JPEG) domain make the task of steganalysis difficult as hidden messages distort the noise part of an image. Thus, it was too challenging to apply deep learning to extract features from this noise part. Different researchers, therefore, came forward by first applying some of the fixed SRM filters to calculate noise residuals from the images before feeding them to the CNN network.
