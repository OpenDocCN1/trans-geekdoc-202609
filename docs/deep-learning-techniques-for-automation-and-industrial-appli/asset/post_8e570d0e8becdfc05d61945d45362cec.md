
Convolutions in ResNet-50 have been shown to improve its performance for steganalysis by various researchers. This work unfreezes all the layers of the network to fine-tune it. Further, average pooling is used instead of max pooling as done in XuNet. Batch normalization (BN) has also proven beneficial for steganalysis, which is present in ResNet-50 and XuNet, but not in the VGGNet-16 model used in this work. ### 8.2.2.2.3 EfficientNet-B0

EfficientNet-B0 [36] is the baseline for the family of EfficientNet CNN networks. It is made up of several MBConv [42, 43] blocks along with squeeze-and-excitation optimization [44] as shown in Figure 8.6 [36]. The model uses depth-wise and point-wise convolutions, which reduce the number of parameters of the model, allowing it to become deeper with lesser number of floating-point operations (FLOPS). The EfficientNet family is made scalable in a systematic way by increasing depth, width, and resolution in a particular ratio that depends on the computational resources available. This first-time introduction of a compound scaling method has helped to avoid a lot of manual tuning to scale the networks in a random way. The baseline EfficientNet-B0 network is also designed in the same way as in ref. [43].

Using this compound scaling, the authors have scaled the network simultaneously along width, depth, and resolution, and created EfficientNet-B1 to B7. The largest, EfficientNet-B7, outperformed all the other CNN networks and is the winner of the ImageNet challenge of image recognition till now with minimum detection error reported. Due to its increased accuracy on the ImageNet dataset, this work uses the pretrained EfficientNet-B0 model only, rather than using the other variants, to keep the computational resources manageable.

## 8.3 Experimental Results and Analysis

All experiments are done with the help of Keras and TensorFlow libraries with GPU provided by the Kaggle online platform. The experiments are carried out on 6,000 pairs of training images and 1,000 pairs of validation images. Further testing is done on 3,000 pairs of images. XuNet is not a pretrained model; thus, in this work, it is trained for a large number of epochs with a mini-batch size of 64 images. The same setting is used as described by the authors [20] for the initialization of the XuNet network. The authors in ref. [32] have discussed that in the mini-batches of training, cover and their corresponding stego images, known as pair constraint (PC), can prove to be detrimental for network training in the last stages but may work better in the initial stages for convergence of the network. In this work, 100 epochs are used with the PC and a learning rate of 0.001 for XuNet. After that, images are shuffled in subsequent epochs to create mini-batches, and a mini-batch of size 64 is picked. Five hundred epochs are used to train XuNet with an initial learning rate of 0.001. The next 500 epochs are used with a learning rate of 0.0001.

For pretrained models, 50 epochs are also used with the PC and a learning rate of 0.001. After that, 100 epochs are trained with shuffled images and a learning rate of 0.0001, and the last 100 epochs with shuffled images and a learning rate of 0.00001. These learning rate values are used by trying a few in every set of epochs. A lesser number of epochs than for XuNet is used, as these are pretrained models. Hyperparameter values are decided by trying a few values; dropout rates of 0.2, 0.3, and 0.4 are tried, and the best dropout rate of 0.3 is picked.

If more epochs were used, the training accuracy of these pretrained models would keep increasing while validation accuracy would start dropping. Further, for pretrained models with a large number of layers, the training dataset of 12,000 images is not enough.

XuNet, giving an accuracy of 90%, is trained from scratch on steganalysis with a predefined heuristic of calculating residual from the image, and then applying a trainable network. Our work also trained XuNet without the K₅ filter, but even with a large number of epochs, the model did not converge. Figure 8.8 shows the accuracy curve of XuNet for the last 500 epochs when trained with 1,000 epochs without the K₅ filter, and it is clear that the model does not converge. VGGNet gives the lowest accuracy as it does not contain a BN layer, which has proven beneficial for steganalysis by many researchers. Another benefit of using pretrained networks is that, though they are pretrained on JPEG images, they are also providing good results on grayscale images. On the contrary, if XuNet is applied to JPEG images, it needs a different set of preprocessing filters for making the network converge, whereas these pretrained models have already been trained on JPEG images, so they can be easily applied to JPEG domain steganalysis without the use of preprocessing filters.
