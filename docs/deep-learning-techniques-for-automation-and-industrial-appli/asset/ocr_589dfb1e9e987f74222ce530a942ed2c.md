The following steps are part of the training process shown in Figure 10.6:

+   1. **Data preparation:** Setting up the dataset for training is the initial step. In order to do this, a collection of labeled fruit and leaf photos must be gathered and divided into training, validation, and testing sets. The validation set is used to assess the model’s performance during training, the testing set is used to assess the model’s ultimate performance. The training set is used to train the model.
+   2. **Pre-processing:** The images in the dataset are typically pre-processed to ensure that they are of a consistent size and format. This step may involve resizing, cropping, and normalizing the images.
+   3. **Transfer learning:** To avoid changes to the pre-trained weights during training, the pre-trained model is loaded, and its weights are frozen. On top of the pre-trained model, a new output layer is built to correspond to the number of classes in the fruit leaf dataset. The new output layer is randomly initialized, and the entire model is then trained on the fruit leaf dataset.
+   4. **Fine-tuning:** After the initial training is complete, the weights of the pre-trained model can be fine-tuned by unfreezing some of the layers in the pre-trained model and training them along with the new output layer on the fruit leaf dataset. Fine-tuning can help the model learn more specific features that are relevant to the fruit leaf classification task.
