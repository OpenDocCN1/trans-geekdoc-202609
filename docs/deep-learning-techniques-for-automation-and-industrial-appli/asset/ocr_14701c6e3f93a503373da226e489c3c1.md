# 6.3.3 Color Attenuation Prior

Color attenuation prior (CAP) assumes that the difference between brightness and saturation of an image affects the haze density. Also, haze density is directly proportional to scene depth, which can be explained by [24]:

(x) ∝ d(x) ∝ v(x) − s(x) (6.5)

(x) represents haze density, d(x) represents scene depth, v(x) represents brightness of scene, s(x) represents saturation. The linear relationship among scene depth, brightness, and saturation is given by:

d(x) = θ₀ + θ₁ v(x) + θ₂ s(x) (6.6)

where θ₀, θ₁, and θ₂ are unknown linear coefficients; the basic color attenuation prior step is as shown in Figure 6.2. For improved color attenuation techniques useful for both synthetic and real scenes, quad decomposition method is applied for air light estimation. The use of a low pass filter is a common technique to remove background noise from an image. In addition to using a low pass filter, adaptive linear weighting can also be used to further remove background noise from an image [25].

Estimated air light using haze line, which assumes that in RGB space hazy pixel values can be modeled as lines, intersects at the air light [26]. Finally, constant scattering coefficient values are replaced by dynamic scattering coefficient values.
