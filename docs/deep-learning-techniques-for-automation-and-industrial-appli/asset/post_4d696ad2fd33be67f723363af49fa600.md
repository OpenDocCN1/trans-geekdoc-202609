### 7.5 Conclusion and Scope of Future Work

Individual counting with face detection, a surveillance system, is used mainly for security purposes. Experiments were performed using a Raspberry Pi with feature extraction by changing their angles in an imaging scenario.

## A Comparative Analysis of Different CNN Models for Spatial Domain Steganalysis

Ankita Gupta*, Rita Chhikara and Prabha Sharma

Department of Computer Science and Engineering, The NorthCap University, Gurugram, Haryana, India

### Abstract

Universal steganalysis detects whether an image is a cover image or a stego image with some hidden information embedded through various steganographic methods. Steganalysis started with simple machine learning techniques of feature extraction and then classification. The focus on steganalysis has now shifted towards exploring deep learning methods. The most popular and successful deep learning models for image classification are based on convolutional neural networks (CNNs). CNN networks also show a resemblance to traditional steganalysis of using filters for feature extraction. Due to the use of content-adaptive steganographic methods, the stego message is hidden more in the complex areas of the image, and thus cannot be detected with a simple statistical analysis of the image. The stego information in these steganographic methods basically affects the dependencies between the pixels introduced through various kinds of noise present in the image. Thus, the difference between the cover and stego image is identified through the noise part rather than the image content. Different researchers have used various preprocessing filters to calculate the noise residuals, passing them to the CNN network instead of images directly. This work uses a content-adaptive steganography method, highly undetectable steganography (HUGO), for creating stego images. This work provides a comparative analysis of one of the variants of CNN models specific to steganalysis and various pretrained models of computer vision applied to steganalysis. An in-depth analysis of the pros and cons of different deep learning models for steganalysis has been presented in this chapter.

### 8.1 Introduction

Steganalysis is a method to detect whether a particular image is pure or contains some hidden information that can be a possible malicious act. There are several methods available to hide information known as steganographic methods [1, 2]. Though steganography can be used for good purposes like hiding consumer data in credit cards, its use has increased considerably for ill purposes. Forensic experts have to deal with millions of images daily and steganalysis helps in identifying adulterated images through steganography. These adulterated images are named as stego images while their original ones are cover images. Specific steganalysis [3] targets known steganographic methods, while universal steganalysis [4] deals with stego images created through any steganographic method.

Universal steganalysis is a form of supervised machine learning technique in which classifiers are trained on features extracted from both cover and stego images. For a long time, extracting rich features, such as spatial rich model (SRM) [5], projection SRM (PSRM) [6], and max-SRM [7], followed by an ensemble classifier (EC) [8] were the successful methods for discovering stego images. Unfortunately, these features are very high in number, e.g., 34671 for SRM, so researchers used a lot of feature selection techniques to improve the classification results and decrease the classification time [9, 10]. With the successful application of deep learning methods in computer vision, researchers moved towards applying these methods also to steganalysis, and soon they found good results. A deep learning method combines feature extraction and classification by learning the features automatically from the images in a supervised manner after using output from the classifier.

With the resemblance of filters used in convolutional neural networks (CNN) and SRM, researchers explored CNNs for steganalysis, and customized CNNs to suit steganalysis needs. The highly content-adaptive steganographic methods, such as HUGO [11], Wavelet Obtained Weights (WOW) [12], Spatial UNIversal WAvelet Relative Distortion (S-UNIWARD) [13] in the spatial domain, and JPEG UNIversal WAvelet Relative Distortion (J-UNIWARD) [13], Uniform Embedding Distortion for JPEG Compression (UED-JC) [14] in Joint Photographic Experts Group (JPEG) domain make the task of steganalysis difficult as hidden messages distort the noise part of an image. Thus, it was too challenging to apply deep learning to extract features from this noise part. Different researchers, therefore, came forward by first applying some of the fixed SRM filters to calculate noise residuals from the images before feeding them to the CNN network.
