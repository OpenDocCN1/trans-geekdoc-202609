# 7.5 Conclusion and Scope of Future Work

Individual counting with face detection, a surveillance system, is used mainly for security purposes. Experiments were performed using a raspberry pi with feature extraction by changing their angles in an imaging scenario.

In the future, it can further proceed with high-accuracy face recognition with different datasets along with pose variations, expression changes, and facial disguises. All these properties of face recognition should be unique for each face. After capturing the face image, it should be matched with the dataset image. Considering the lighting condition in front of doors will also be good for identifying an individual's facial features. This technology will help recognize people's faces in public places, like airports, shopping malls, banks, schools, and police stations.
