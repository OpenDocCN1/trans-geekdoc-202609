# G. LSTM

Hochreiter and Schimdhuber worked hard to develop and use LSTM [30] for a variety of uses. IBM chose LSTMs for voice recognition majority of the time. The LSTM uses a cell, a piece of memory that is only long enough to store a value, and it uses that value as its input function. This enables the unit to retain the most recently created value. Three gates that control information flow in and out of the memory unit or cell make up a memory cell:

+   - The input port or gate controls the data flow into fresh memory;
+   - The second gate, which is referred to as the ‘forget panel port’ controls gate, is used to erase a chunk of old data and assist a cell in storing new data.
+   - The output gate duty once again entails keeping track of data in a cell that is used as cell output.

The weight of the cell may be used for control. It is crucial to use a training technique known as time back propagation that increases weight. The method calls for a network performance error optimization.
