# 6.3.5 Deep Learning

To remove the limitations of existing dehazing techniques such as assumption based or complex fusion method, CNN was proposed as shown in Figure 6.3 [35]. Multi-scale CNN is based on training of datasets; it consists of two networks. Coarse networks determine rough transmission value, while fine scales further refine transmission value [36]. The cascaded convolutional neural network (CNN) approach utilizes two subnetworks that work together to determine both the transmission map and the global atmospheric light. This technique removes noise and the scene artifact, as it works on training of datasets [37]. Ranking CNN can reproduce statistical and structural features simultaneously. The regression model is further trained based on learned features to predict scene depth effectively [38].

Image sensing networks measure air quality index based on haze relevant feature and three-dimensional CNN [39]. Multifature bilinear techniques determine transmittance value, which include different steps. Firstly, feature is extracted through trained dataset. Secondly, non-linear mapping is done. Lastly, haze-free images are restored without noise and abrupt edges [40]. Dual network has two components, i.e., dehazing and denoising networks. Dehazing network determines air light using AL-Net, while generating the transmission map using TM-Net. Finally, noise from textural layer is removed by denoising network [41]. CycleGAN uses unsupervised training method, which produces haze mask. The uses of haze mask and hazy version result in clean output by reformulated scattering model [42]. Atmospheric value and transmission map are determined at the same time [43]. This technique reduces the computational time but does not work well for dense haze. CNN uses a patch map selection network, which is determined based on the selected patch size for each pixel. This technique visually and qualitatively showed better results [44]. A knowledge transfer technique consists of a teacher network, which utilizes clear images for training to learn robust and strong prior [45].
