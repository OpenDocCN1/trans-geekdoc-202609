# 4.4.6 DenseNet Family

A DenseNet is a type of convolutional neural network that creates dense connections between layers by using dense blocks [21]. The DenseNet family consists of three members: DenseNet121, 169, and 201 – all of which perform almost identically on satellite data, with DenseNet169 outperforming the others.
