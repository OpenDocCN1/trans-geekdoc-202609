+   1. **Hard Parameter Sharing**
+   
+      It is often used for the MTL approach in NNs and has a long history (dating back to [22]). When several task-based output layers are desired, it is often used to partition hidden layers across tasks shown in Figure 12.1.
+   
+      Sharing hard parameters significantly reduces the likelihood of overfitting [23]. It has been shown that if shared parameters are overfitting, N, where N is the number of tasks, might be smaller than the number of tasks, or output layers. This has the obvious consequence that the more tasks we learn, the more our model learns about all tasks, and the less chance we have of successfully completing our initial assignment.

+   2. **Sharing Soft Parameters**
+   
+      Instead, for soft parameter sharing, the particular roles have their own models with unique parameters. The gap between model parameters is then controlled to promote comparable parameters. For instance, although [25] employs the norm trace requirement, [24] utilizes the regularization l2l2 model shown in Figure 12.2.
