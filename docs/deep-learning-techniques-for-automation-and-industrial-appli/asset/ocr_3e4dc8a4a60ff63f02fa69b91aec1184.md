# 12.3.5  **Multitask Learning (V)**

A typical approach is used in the ML area of multi-task learning (MTL) to carry out many tasks simultaneously. These techniques provide advantages including improved data efficiency, less overfit by employing common representations, and quick learning using auxiliary data. However, learning many tasks simultaneously poses significant design and optimization issues, and selecting which activities to learn simultaneously is a difficult decision.

# 12.3.5.1  *Learning-Related Problem*

Challenges that do not arise in one task result from learning definitions for several tasks. Conflicting demands in particular, may arise in many jobs. It is known as negative transfer or destructive interference when improving a model’s performance in one task causes damage to another with different criteria [20].
