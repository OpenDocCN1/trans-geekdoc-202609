Across the 91 papers (2010–2020) analyzed, it was observed that the researchers have used, on average, more than two models across various model families such as statistical models, AIML models, ANN, remote sensing, and GIS.

+   - Multicriteria-decision-analysis with analytic hierarchy or network process (MCDA/AHP/ANP)
+   - Logistic regression
+   - Evidential belief function (EBF)
+   - Random forest or subspace, SVM or DT
+   - Frequency-ratio
+   - Weights of evidence (WoE)
+   - Multivariate adaptive regression spline (MDRS)
