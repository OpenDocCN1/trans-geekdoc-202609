
## 6.7 Conclusions

Python and MATLAB are used to implement several methods of single-image dehazing. We have compared synthetic and a real dataset for different dehazing techniques. The main drawback for real dataset is the non-availability of ground truth or reference image. As a result, it is not feasible to implement measures such as peak signal-to-noise ratio or structural similarity index to evaluate a real scene captured in a hazy environment. Also, in many other techniques in which the output image size is reduced, certain features cannot be implemented. To overcome these entire drawbacks, we applied color difference Ciede2000 as one of the ways to assess the output quality based on visibility. It is observed that fully convolutional network (FCN) gives the best result visually, but color difference is not maintained for synthetic scenes. CAP does not maintain color difference for synthetic scenes and gives very high Ciede2000 value. Overall, the best SSIM and PSNR result has been observed in the case of deep learning methods like CNN and FCN for synthetic scenes. In the future, better quality assessment parameters are required for checking the quality of real scene output.
