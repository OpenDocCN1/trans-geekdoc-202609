# 6.3.2 Dark Channel Prior

He et al. performed an empirical experiment for haze and haze-free images. It was found that hazy scenes carry dark pixels whose values are nearly zero for any one of the color channel bands [16]. The dark channel is mathematically defined as:

$J^{dar}(x)=\frac{\min_{y\in\Omega(x)} (\min J^{c}(y))}{cs\{r,g,b\}}$ (6.4)

Here, Ω(x) represents a local patch, which is centered at x. cs (r, g, b) is the color channel band. J^c is the color intensity. All pixels in Ω(x) and the minimum value from all color bands are chosen as dark channels [17]. Tomasi et al. proposed a bilateral filter for edges, which can be used to minimize the dark channel [18]. Tang et al. proposed new techniques: Firstly, atmospheric value is estimated by a binary tree algorithm. Secondly, transmission value is estimated by two different parts: the bright and dark regions. Transmission value in the dark region is determined through DCP, and adaptive transmission is applied on the bright region. Lastly, guided filter is applied for both parts [19]. In this technique, DCP is used to compute the atmospheric value, while mean transmission value is computed using the R, G, and B color space. In YCbCr, the Y band estimates transmission value.
