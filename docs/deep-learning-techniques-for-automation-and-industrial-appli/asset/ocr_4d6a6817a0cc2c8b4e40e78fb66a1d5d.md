# 2.5 Methodology

The dataset on chili leaves was collected from a field in Andhra Pradesh. The dataset consists of two classes: healthy leaves and unhealthy leaves. The healthy leaves class includes leaves in a healthy state, whereas the unhealthy leaves class comprises leaves that are in an unhealthy state. To apply deep learning to images, the dataset was divided into three parts: training, testing, and validation, in the ratio 7:2:1. The training folder contains 58 images; the testing folder contains 20 images; and the validation folder contains 10 images.

The Figure 2.3 shows the methodologies used in this chapter.

The first model applied was the convolutional neural network (CNN). CNN is one of the deep learning models used in image recognition and the recognition of different patterns. The model was made with three convolutional layers and one flattened layer. The accuracy found using CNN was 80%;
