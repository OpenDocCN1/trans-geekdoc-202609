Originally, XuNet was trained on 512 by 512 image size, but in this work, it is trained on 256 by 256 image size to make it comparable with other pretrained models. The pretrained models used in this work are VGGNet-16 [34], ResNet-50 [35], and EfficientNet-B0 [36], all initialized with ImageNet weights. The preprocessing layer of fixed SRM filters is not used with these networks as this has to be attached as the initial layer of the pretrained networks which may decrease the performance of these networks. Further, our work wants to observe the performance of pretrained networks without using any preprocessing filter. Fully connected layers of pretrained networks are discarded to finetune the network with a new set of fully connected layers. L2 regularization is used in fully connected layers except the last one. The dropout layer is also used before fully connected layers. Image size is taken as 256 by 256 for all the networks used in this work.

# 8.2.1 Dataset

In this work, BOSSbase 1.01 dataset [17] of 10,000 grayscale images are used. These images act as cover images for steganalysis. The images are of size 512 by 512. All images are resized to 256 by 256. These 10,000 images are then converted to stego images using HUGO [11] steganography algorithm at payload 0.8 bpp. A training set constitutes of 6,000 pairs of cover and stego images is used. A validation set of 1,000 pairs and a testing set of 3,000 pairs are used in this work.
