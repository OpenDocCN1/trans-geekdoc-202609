# 4.3.3 Training Processes

The UC Merced dataset is divided into three parts: training, testing, and validation, with 80%, 10%, and 10%, respectively. Since each class has 100 images, the first 100 were given the label '0' and the next 100 were given the label '1' for all the classes. An array contains the names of all classes. Combining the array and label together forms the ground truth for the classification. Every model in the experiment has a deep learning model as its foundation, with three layers for performance enhancement. The base or foundation model is frozen first, followed by 18 epochs of training with a batch size of 24. Categorical cross-entropy was used as the loss function throughout the experiment, with RMSprop as the optimizer and pooling at maximum (Max) Pooling and Figure 4.3 shows the expanding various deep architectures.
