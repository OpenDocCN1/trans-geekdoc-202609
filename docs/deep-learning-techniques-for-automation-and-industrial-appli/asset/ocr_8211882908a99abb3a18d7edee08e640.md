# 8.2.2.2.3 EfficientNet-B0

EfficientNet-B0 [36] is the baseline for the family of EfficientNet CNN networks. It is made up of several MBConv [42, 43] blocks along with squeeze and excitation optimization [44] as shown in Figure 8.6 [36]. The model uses depth-wise and point-wise convolutions, which reduce the number of parameters of the model, allowing it to become deeper with lesser number of floating-point operations (FLOPS). The EfficientNet family is made scalable in a systematic way by increasing depth, width, and resolution in a particular ratio that depends on the computational resources available. This first-time introduction of a compound scaling method has helped to avoid a lot of manual tuning to scale the networks in a random way. The baseline EfficientNetB0 network is also designed in the same way as in ref. [43].

Using this compound scaling, the authors have scaled the network simultaneously along width, depth, and resolution, and created EfficientNet-B1 to B7.
