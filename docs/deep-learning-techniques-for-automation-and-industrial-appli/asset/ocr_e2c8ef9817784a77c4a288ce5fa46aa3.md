# 7.3.2 Algorithm of the Proposed System

The algorithm for individual counting via face detection is provided below. This algorithm was developed using a custom dataset, which consisted of a variety of images, primarily featuring people but also including ‘non-faces’ such as hands or potted plants. The objective of the algorithm is to detect and label people’s faces with rectangles while also counting the number of people within the frame at any given moment.

The new method to improve the surveillance framework and to gain more information from them were discussed and implemented below. Feature extraction techniques were used mainly for face detection.

Individual counting frameworks incorporate mechanical control frameworks, e.g., rotating entryway and infrared sensor recognition framework. In our present society, the video capturing framework is progressively connected in numerous parts of our lives shown in Figure 7.2.

Here, I defines the number of the image in the dataset and J defines the number of shift steps of the sub-window.

**Algorithm:** Individual counting via Face Detection

**Input:** Original Image
