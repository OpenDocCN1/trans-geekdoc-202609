# 2

## AI takes off

杰夫·迪恩和安德鲁·吴并非出于教他们的AI猫长什么样的目的——它是自主学习的。“它基本上发明了猫的概念，”迪恩在2012年对《纽约时报》表示。

迪恩和吴在谷歌的实验性技术实验室X取得的成就，展示了自IBM的深蓝击败加里·卡斯帕罗夫以来的十五年间，AI取得了多大的进步。那次事件帮助激发了人们对AI的重新兴趣和研究。在随后的几年里，AI开始与人类在西洋双陆棋中竞争。第一批机器人手术系统被开发出来。机器在识别语音、理解书面语言和识别手写数字方面取得了进步。

多种因素使得迪恩和吴的壮举成为可能。到新千年初期，硬件成本相比十年前已大幅下降。速度也大大提升。此外，AI研究人员受益于一个发现：最适合他们工作的计算机芯片不是传统的中央处理器（CPU），而是用于渲染电脑游戏图形的图形处理器（GPU）（由英伟达于1999年发明，每个芯片拥有大约200倍的处理器，且能以更快的速度处理数据）。最后，随着全球互联网在2005年获得首批十亿用户，以及智能手机的普及即将到来，可用于“训练”神经网络的数据量呈指数级增长。

鉴于这些进步，AI从小众计算机科学系走向硅谷并不令人意外。大型科技公司的巨头们正忙于挖掘AI研究人员，并支付巨额薪水，让他们将注意力转向新雇主拥有的海量数据集。谷歌的实验室X就是一个典型的例子。

为了让他们的AI学习识别猫，迪恩和吴的团队构建了一个由16,000个计算机处理器组成、拥有十亿个连接的巨型网络，并使用一千万个随机的YouTube视频缩略图进行训练。

2012年另一项——或许更具意义——的成就，是由多伦多大学的三位研究人员：亚历克斯·克里热夫斯基、伊利亚·苏茨克维和杰弗里·辛顿（后者是AI领域的先驱）创建的、后来被命名为AlexNet的人工神经网络取得的。这是首次使用传统的卷积神经网络配合GPU，它凭借当年ImageNet竞赛的冠军一举成名。

到2015年，速度和准确性方面又取得了进一步进步。当年ImageNet竞赛的获胜者达到了96%的准确率，首次超越了人类在图像中识别物体的能力。一年前，Facebook的人脸识别神经网络DeepFace在某些人脸上的准确率达到了97.35%，仅比人类在同一测试中的得分低四分之一百分点。Facebook的神经网络是使用来自4,030人的440万张标记的人脸照片进行训练的，这些人都在使用该社交网络。

正是在这个时候，AI竞赛中的另一大参与者开始引起头条新闻。DeepMind是一家位于伦敦的人工智能公司，谷歌据称于2014年以4亿美元收购了它，此前它一直是一家相对默默无闻的初创公司。但它宣布其深度Q网络——一种使用强化学习的深度神经网络——能够在仅获得有限信息的情况下，赢得包括《太空侵略者》和《打砖块》在内的49款经典Atari游戏，这一消息震惊了研究界。“我们试图构建一套类似人脑的通用算法，”该公司联合创始人德米斯·哈萨比斯对《WIRED》杂志表示。

2016年3月，DeepMind迈出了巨大的一步，利用其AlphaGo系统，击败了这项有着3000年历史的棋类游戏围棋的世界冠军。从某个层面上看，这听起来可能与几十年前深蓝击败卡斯帕罗夫的成就不相上下。但卡斯帕罗夫曾能与深蓝抗衡，在系列赛中打平了大部分比赛，直到最后一局才垂头丧气地认输。而且他下的是国际象棋。围棋使用黑白棋子，在19×19的棋盘上进行，其复杂程度远超国际象棋（许多AI研究人员不相信机器能在几十年内击败世界最佳人类棋手），而围棋世界排名第一的李世石，曾十八次获得该游戏的顶级头衔，与卡斯帕罗夫不同，他被彻底击溃。他以1–4落败。

AlphaGo最初是通过观察人类下棋来学习的，但随着时间的推移，它发展出了自己的决策能力。其底层包含多个神经网络，体现了多年的AI进步以及谷歌全球数据中心的算力。一个神经网络负责选择下一步棋，另一个则旨在根据目前的棋步预测比赛的胜者。结果是一个不仅重复其从观察数千步人类棋步中学到的棋风，而且能够创造出自己风格的系统。在一场特定的比赛中，机器指示摆放实体棋子的人下了一步出人意料的棋，没有人类会想到下这一步。“这不是人类的下法。我从未见过人类下过这一步，”范辉表示，他是三届欧洲围棋冠军，当时正在解说这场比赛，并且在AlphaGo击败李世石之前，曾与DeepMind合作与AlphaGo进行了数百场训练比赛。“太漂亮了。”

自那场与李世石的比赛以来，AlphaGo系统进一步提升。事实上，它已经超越了人类知识。其中一个版本，被称为AlphaGo Zero，从零开始学习如何下棋，没有使用之前的人类棋局进行训练——在此过程中，它学会了击败AlphaGo。DeepMind表示，它“在短短几天内积累了数千年的人类知识”。下一个版本AlphaZero，不仅能下围棋，还能下国际象棋和将棋，而无需针对每种不同的游戏进行调整。

2020年11月30日，DeepMind宣布其AI系统已超越游戏领域，攻克了生物学中最艰难的挑战之一。其AlphaFold系统，据透露，已经成功生成了蛋白质的准确3D模型，蛋白质是存在于所有生物体中的高度复杂物质。
