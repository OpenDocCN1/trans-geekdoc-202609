`The Open Systems Interconnection Reference Model`

在 1970 年代，随着计算机网络日益复杂，研究人员创建了 `Open Systems Interconnection (OSI) reference model`，以标准化网络。OSI 参考模型作为开发和通信协议的框架。协议是决定数据在网络中传输格式和顺序的规则和过程。例如，使用 `Transmission Control Protocol` *(TCP)* 进行通信时，接收方需要回复确认收到消息，否则 TCP 可能会重新传输该消息。

尽管 OSI 如今不如从前重要，但熟悉它仍然很重要，以便理解常见概念，如低层网络和路由，尤其是在涉及硬件时。
