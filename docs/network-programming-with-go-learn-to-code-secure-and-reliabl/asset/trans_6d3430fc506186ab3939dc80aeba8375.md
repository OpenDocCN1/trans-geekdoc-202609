***TLS over TCP***

TLS 是有状态的；客户端和服务器在初始握手期间协商会话参数，一旦达成一致，它们就交换加密的 TLS 记录，持续整个会话期间。由于 TCP 也是有状态的，它是实现 TLS 的理想传输层协议，因为你可以利用 TCP 的可靠性保证来维护 TLS 会话。
