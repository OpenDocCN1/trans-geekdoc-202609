```
    c='+';
else if (op==SUB)
    c='-';
else if (op==MUL)
    c='*';
else if (op==DIV)
    c='/';
else if (op==MOD)
    c='%';
else
    c='?';
```

-   [为了避免在执行大量 `if`/`else-if` 检查时的低效，编译器可以构建 **跳转表**（jump table）。跳转表是一种汇编数据结构，存储 `switch` 语句各分支的目标地址，使得根据 case 编号直接索引到对应代码块，实现直接跳转。]

-   [下面的代码展示了使用跳转表的汇编实现：]

```
.section data
table:
dd target_0
dd target_1
dd target_2
dd target_3
dd target_4
 
.section text
mov eax, [op]
cmp eax, 5
jge default
jmp [table+eax*4]
 
target_0:
mov byte [c], '+'
jmp done
 
target_1:
mov byte [c], '-'
jmp done
 
target_2:
mov byte [c], '*'
jmp done
 
target_3:
mov byte [c], '/'
jmp done
 
target_4:
mov byte [c], '%'
 jmp done
 
default:
mov byte [c], '?'
jmp done
 
done:
```
