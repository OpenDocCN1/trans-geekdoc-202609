
数字千年版权法案（DMCA）是1998年由国会通过的法律，使美国符合国际版权协定。它设计用于保护知识产权，能够在内容到达市场后跟踪并控制受保护内容。

计算机欺诈与滥用法案（CFAA）于1984年制定，是一项联邦反黑客法，禁止未经授权访问计算机和网络。由于法律条文表述不清，检察官一直滥用该法。近年来，为保护安全研究人员免受其起诉，相关保护措施逐步出台。据《WIRED》2014年文章所述：

> *2008年一起高调案例中，三名麻省理工学院学生因发现马萨诸塞湾交通局电子车票系统的漏洞而被禁止在DEF CON黑客会议上发言。该系统漏洞可让任何人免费乘车。MBTA申请并获得临时禁令，阻止学生发言。法官在颁布临时禁令时指出，学生计划展示的信息将为他人提供黑客系统的手段，即“谈论黑客行为等同于实际黑客行为”。该判决随后因被视为对言论的违宪事先限制而受到公开批评，且当MBTA试图将临时禁令转为永久时，另一位法官驳回，认为CFAA不适用于言论，与案件无关。*

CFAA的另一起悲剧性滥用导致了Aaron Swartz的自杀。该案件发生在一位美国检察官利用CFAA对互联网活动家Aaron Swartz展开强力起诉，指控他非法获取MIT closet中的数百万份学术论文。尽管JSTOR未提出投诉，司法部仍推进起诉。检察官Carmen Ortiz坚称“盗窃即盗窃”，并称仅仅是维护法律。Aaron Swartz因即将面临的审判和被定罪的恐惧而于2013年自杀。此事后，两名议员提出了迟长的修正案——Aaron's law，旨在防止检察官滥用该法。该修正案由Rep. Zoe Lofgren (D-Calif.) 和 Sen. Ron Wyden (D-Oregon) 引入，内容包括：排除违反服务条款和用户协议的行为；缩小“未经授权访问”的定义，明确区分严重的黑客活动与轻微的超出授权范围的行为；将“未经授权访问”定义为“绕过一种或多种技术措施，阻止未经授权的个人获取或修改受保护计算机上的信息”；并明确“绕过”不包括仅仅更改MAC地址或IP地址以获取系统访问。
