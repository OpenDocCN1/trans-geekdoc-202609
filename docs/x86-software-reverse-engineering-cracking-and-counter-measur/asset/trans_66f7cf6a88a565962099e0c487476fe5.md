-   [Cheat Engine: 查看内存

  Cheat Engine 以内存扫描为核心思想。

  主 Cheat Engine 窗口主要用于扫描内存。但现在，请专注于一些更简单的功能：内存视图。如 [Figure 11.10](#c11.xhtml#c11-fig-0010) 所示，点击 "Memory View" 查看进程的内存。

  内存视图提供了一个易于使用且强大的方式来查看、扫描和修改进程的内存。如 [Figure 11.11](#c11.xhtml#c11-fig-0011) 所示，内存视图包括屏幕顶部的反汇编、中间的指令引用以及底部的十六进制转储。

-   [Cheat Engine: 字符串引用

  [Figure 11.12](#c11.xhtml#c11-fig-0012) 显示会弹出的窗口，你可以点击字符串以查看其交叉引用。双击交叉引用地址，即可跳转到字符串在反汇编中的使用位置。

-   [Cheat Engine: 修改程序

  回想一下，"nop" 出一段代码是最安全、最简单的方式，在不影响程序其余部分的情况下将其删除。Cheat Engine 使这变得容易。要绕过一个指令（例如关键检查中的最终条件跳转），右键单击该指令并选择 "Replace With Code That Does Nothing"，如 [Figure 11.13](#c11.xhtml#c11-fig-0013) 所示。

  Cheat Engine 高度交互。你可以立即在运行的程序中尝试你的修改！如果修改无效或想要撤销，右键单击修改后的代码并选择 "Restore With Original Code"，如 [Figure 11.14](#c11.xhtml#c11-fig-0014) 所示。

  ![Figure 11.13: 在 Cheat Engine 中 noping 出指令](images/c11f013.png)

  [Figure 11.13](#c11.xhtml#R_c11-fig-0013) `nop` 出指令在 Cheat Engine 中

-   [Cheat Engine: 复制字节

  一旦你找到了一个有效的补丁，下一步是将该补丁复制到可执行文件中，而不是运行进程。如 [Figure 11.15](#c11.xhtml#c11-fig-0015) 所示，你可以右键单击补丁位置并选择 "Copy To Clipboard ➪ Bytes Only" 以复制这些字节供其他工具使用。

-   [Cheat Engine: 获取地址

  要制作一个补丁，你需要知道在文件中要修改的数据的位置。Cheat Engine 专注于运行时分析，因此它不知道数据在文件中的具体位置。

  要找到地址，使用 010 Editor 对要替换的机器代码进行搜索。该地址即为用于在 CodeFusion 或其他补丁工具中进行修改的文件偏移量。

-   [IDA 入门]

  如果你曾经在谷歌搜索逆向工程工具，IDA 肯定会出现。它是逆向工程工具的“凯迪拉克”。

  IDA，即交互式反汇编器，允许对二进制进行可视化的反汇编。它采用免费增值模式，免费版提供有限功能，而更强大的功能（或更不常见的架构）需要付费许可。

  [Figure 11.16](#c11.xhtml#c11-fig-0016) 显示了在 IDA 中加载新文件的过程。IDA 会自动识别许多常见文件格式，但如果识别错误，你可以选择 "Generic Binary File"。IDA 还提供了 "Processor Type" 下拉菜单，用于更改架构。

  IDA 的最大优势之一是其图形视图，该视图显示可执行文件的 x86 机器码和控制流的可视化表示。[Figure 11.17](#c11.xhtml#c11-fig-0017) 展示了该视图及其最有用的组件，包括可执行文件的内存映射、函数列表、逻辑块视图和图形窗口。
