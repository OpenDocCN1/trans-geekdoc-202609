
# Epochwise BPTT Algorithm for High-Order FTS Forecasting

In this study, epochwise BPTT algorithm \[[15](#bodymatter-007.xhtml#b_9783110670905-007_ref_015)\] is applied for forecasting high-order FTS. Computation is done by truncating the backward propagation of information to a predefined number of time steps. So this model is a combination of epochwise BPTT and truncated BPTT \[[Figure 7.2](#bodymatter-007.xhtml#b_9783110670905-007_fig_002)\]. Steps of the proposed BPTT-based approach are as follows.

![Figure 7.2: Epochwise BPTT (truncated).](graphic/converted/b_9783110670905-007_fig_002.png)

Figure 7.2: Epochwise BPTT (truncated).

## Step 1

Apply fuzzy c-means (FCM) algorithm \[[18](#bodymatter-007.xhtml#b_9783110670905-007_ref_018)\] to create "`k`" clusters and obtain fuzzy membership value of each datapoint in each cluster.

## Step 2

Choose number of prior time steps "`h`." Here, this is equal to the number of order of the model.

## Step 3

Apply truncated version of epochwise BPTT as described below.

Let us consider, total number of datapoints (total time period) is "`MAX`" and number of prior time steps is "`h`." Each layer of the unfolded network takes fuzzy membership values as input.

### Algorithm

3.1. Initial activation = 0; iteration = 0.

3.2. `t` = 1;

3.3. Repeat steps 3.4–3.9 until `t` ≤ `MAX`-`h`

3.4. `t`[0] = `t`; repeat steps 3.5–3.6 until `t`[0] < `t` + `h`

3.5. Calculate output values in the forward pass using [eqs. (7.1)](#bodymatter-007.xhtml#b_9783110670905-007_eq_001)–[(7.3)](#bodymatter-007.xhtml#b_9783110670905-007_eq_003).

3.6. `t`[0] = `t`[0] + 1.

3.7. Proceed in the backward direction repeating [eqs. (7.4)](#bodymatter-007.xhtml#b_9783110670905-007_eq_004) and [(7.5)](#bodymatter-007.xhtml#b_9783110670905-007_eq_005).

3.8. Update each connection weight using [eq. (7.6](#bodymatter-007.xhtml#b_9783110670905-007_eq_006)).

3.9. `t` = `t` + 1.

3.10. Iteration = Iteration + 1

3.11. If Iteration < maximum iteration, go to step 3.2, else stop.

## Step 4

Defuzzification:

Let us consider that `m` clusters are created in the dataset. If the output membership values are `µ`[1], `µ`[2], … … …, `µ[m]`. and corresponding centers of the clusters are `c`[1], `c`[2], … … …, `c[m]`. Then,

(7.7)${Output} = \\frac{\\sum\_{i = 1}^{m}c\_{i}\\mu\_{i}}{\\sum\_{i = 1}^{m}\\mu\_{i}}$

### Example

Let us consider temperature (August) data set. Fuzzy C-means algorithm is applied to create three clusters. Membership values are shown in [Table 7.1](#bodymatter-007.xhtml#b_9783110670905-007_tab_003). Number of input units and processing units are three in this case. Now for the fifth order model, number of prior time steps `h` = 5.

Now, the following sequence of membership values is fed into the system. Each layer of the unfolded network represents a time step. Each of three membership values is fed into the input layer of the network through three nodes.
