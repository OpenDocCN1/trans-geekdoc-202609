

# Arica 和 Vural 提出了一种离线字符识别系统

Arica 和 Vural 提出了一种离线字符识别系统，通过使用最少的预处理操作来限制关键信息的丢失 \[[11](#bodymatter-003.xhtml#b_9783110670905-003_ref_011)\]。他们使用了一种高效的分割算法，用于从灰度图像中检测字符边界、倾斜角度、上下基线、笔画宽度和高度。隐马尔可夫模型（`HMM`）用于估计系统参数以及某些特征空间参数。`HMM` 用于根据字符形状特征确定字符的等级。Khedher 等人描述了，选择良好的特征可以为任何字符识别系统提供更好的准确性 \[[12](#bodymatter-003.xhtml#b_9783110670905-003_ref_012)\]。他们讨论了如何为识别阿拉伯手写字符选择不同的良好特征。他们使用了手写字符的真实样本。阿拉伯数字的平均识别准确率为 88%，阿拉伯字母的平均识别准确率为 70%。Hanmandlu 和 Murthy 实现了一种模糊模型，以隶属度值的形式用于识别手写英文和印地语数字 \[[13](#bodymatter-003.xhtml#b_9783110670905-003_ref_013)\]。模糊集中的隶属函数通过熵的优化进行调整。该模型对印地语数字的准确率为 95%，对英文数字的准确率为 98.4%。Arora 等人实现了一个用于识别天城文的系统 \[[14](#bodymatter-003.xhtml#b_9783110670905-003_ref_014)\]。从阴影、直线拟合、交点和链码直方图中提取了四个特征，采用了盒法。阴影特征从图像的所有部分提取，而链码直方图、交点和直线拟合特征则通过将图像分割为子图像来提取。该系统使用了 4,900 个天城文字符进行测试，准确率为 92.8%。Kimura 实现了一个用于字符识别的系统，该系统使用基于遗传算法的特征选择 \[[15](#bodymatter-003.xhtml#b_9783110670905-003_ref_015)\]。他选择基因的方式是使训练数据的识别率不超过预定义阈值。因此，该系统被采用为选择特征数量的缩减比率。Graves 和 Schmidhuber 开发了一种多维 `RNN` 模型用于阿拉伯手写字符识别。他们参加了 2007 年的 ICDAR 单词识别竞赛，在 IFN/ENIT 数据集上的准确率为 91% \[[16](#bodymatter-003.xhtml#b_9783110670905-003_ref_016)\]。`MLP` 被 Pal 和 Singh 用于识别手写英文字符 \[[17](#bodymatter-003.xhtml#b_9783110670905-003_ref_017)\]。他们使用字符边界追踪和傅里叶描述子提取特征。该系统通过比较字符的特征和形状来分类每个字符。他们进行了调查，以通过使用优化的隐藏层数量来获得更好的字符分类准确率。他们报告了手写英文字符的 94% 识别准确率。Pradeep 等人提取了用于离线字符识别的对角特征 \[[18](#bodymatter-003.xhtml#b_9783110670905-003_ref_018)\]。该系统基于神经网络模型，他们使用了两种方法，分别使用 54 个特征和 69 个特征来实现此识别系统。他们报告称，使用 54 个特征时离线字符识别的准确率为 97.8%，使用 69 个特征时为 98.5%。Neves 等人提出了一种使用支持向量机的离线手写数字识别系统，并声明其准确率优于 `MLP` \[[19](#bodymatter-003.xhtml#b_9783110670905-003_ref_019)\]。实验在 NIST SD19 标准数据集上进行。他们报告称，`MLP` 能够区分非线性可分类，但由于陷入局部最小值而无法实现最优解。因此，`MPL` 可能无法为数字识别提供更高的准确率。Gaurav 和 Bhatia 提出了一种处理各种预处理技术的技术，这些技术包括倾斜检测和校正、对比度拉伸、转换为二值图像、噪声去除、分割和形态学操作，用于字符识别 \[[20](#bodymatter-003.xhtml#b_9783110670905-003_ref_020)\]。该技术用于包含不同强度彩色背景的手写文档。他们得出结论，单一技术不足以从不同强度的背景图像中识别字符。深度学习因其在计算机视觉和机器学习中的稳定性能，被广泛应用于各种应用领域 \[[21](#bodymatter-003.xhtml#b_9783110670905-003_ref_021)\]。Hu 等人使用 `DNN` 和 `CNN` 实现了 OCR 系统和人脸识别系统，其准确率优于其他系统。`DNNs` 和 `CNNs` 为深度学习应用的扩展提供了巨大机会。他们使用该系统来解决约旦安全问题中的人脸识别问题。他们在人脸识别方面取得了巨大成功。Ghazi 和 Ekenel 展示了 VGG-Face 模型和轻量化 CNN，并在五个基准数据集上进行了测试。他们报告称，即使面部或字符的对齐度较低，预处理也可以提高性能 \[[22](#bodymatter-003.xhtml#b_9783110670905-003_ref_022)\]。该方法在 MNIST 数据集上的准确率高达 98.46%，表现出良好的性能。使用 CNN 时，不需要图像/数据预处理和手工制作的特征提取。Younis 和 Alkhateeb 在约旦大学不同人员拍摄的人脸数据集上，使用深度 `CNN` 实现了一个人脸识别系统 \[[23](#bodymatter-003.xhtml#b_9783110670905-003_ref_023)\]。他们在 Tensorflow 和 Keras 环境中实现了该系统。经过 80 个 epoch 后，人脸分类的准确率是可以接受的，这花费的时间非常少。

# 3.4 MLP、CNN 和 RNN 概述

`MLP` 网络在模式识别领域已被使用很长时间，它使用手工制作的特征进行模式分类。为特定应用选择最佳特征需要花费大量时间。最佳特征也称为手工制作的特征。手工制作的特征完全依赖于某些应用，但可能不适用于其他应用。深度学习（`DL`）是神经网络领域的一场革命，它使用大量层来训练网络以实现更好的准确率。`DL` 包含一个输入层、一系列隐藏层和一个输出层，用于特征提取和特征分类。`DL` 试图通过多阶段特征学习过程自动提取更多特征。研究人员提出了许多神经网络，作为现有模型的修改或新模型。他们通常推荐 `MLP`、`CNN` 和 `RNN`，以在广泛的应用领域中获得稳定性能。
