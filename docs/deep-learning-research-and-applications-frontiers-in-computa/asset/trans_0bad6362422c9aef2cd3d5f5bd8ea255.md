

# 感知机是一种简单的神经网络模型

感知机是一种简单的神经网络模型。它是复杂神经网络的先驱。它试图像生物大脑一样解决难题。神经网络的力量来自于其能够从训练数据中正确建模系统，并对数据分类进行输出预测。从这个意义上说，神经网络科学地学习映射。这类网络能够学习任何映射函数。任何神经网络的预测能力都来自于网络的多层结构。MLP 的架构由一个输入层、一个输出层和多个隐藏层组成，如 [图 3.2.](#bodymatter-003.xhtml#b_9783110670905-003_fig_002) 所示。该架构在不同尺度上学习特征，并将其组合为高阶特征。例如，架构先学习线条，再从线条集合中学习形状。MLP 是一种高效的分类器。在训练期间，输入被分配了一个类别，以便网络训练系统。网络能够非常高效地从输入数据集到输出数据集学习映射，用于数据分类。

## 3.4.2 卷积神经网络

CNN 是计算机视觉中一种高效的神经网络架构。它用于自动提取特征，然后对提取的特征进行分类。该架构在图像的原始像素上使用一系列滤波器来提取高级、中级和低级特征，然后根据提取的特征对图像进行分类。CNN 使用输入数据的小方块来保持像素之间的空间关系，以提取特征。特征在整个图像上提取，以允许图像中的对象进行平移或偏移。CNN 架构由一系列不同的层组成，这些层将输入数据转换为输出数据。该架构由输入层、输出层和隐藏层组成，如 [图 3.3.](#bodymatter-003.xhtml#b_9783110670905-003_fig_003) 所示。隐藏层分为两个模块。第一个模块用于特征提取，第二个模块用于特征分类。第一个模块由重复的卷积层和池化层组成。第二个模块由多个全连接层组成。最后一个全连接层中的节点数由目标类别的数量决定。这一层称为输出层。

Figure 3.3: Basic architecture of CNN.

### 3.4.2.1 卷积层

卷积层是 CNN 的主要层。该层由一组卷积滤波器组成，用于执行一些数学运算以在输出映射中生成一个值。在前向传递中，每个滤波器在整个图像子区域上进行卷积。它只是输入图像/数据子区域的值与卷积滤波器的值之间的点积。它生成卷积滤波器的二维激活映射，以检测特定类型的特征。卷积层的输出数据大小取决于滤波器的大小、步长的值和零填充。卷积层中连接到输入数据相同子区域的神经元数量由滤波器的大小控制。这些神经元学习在输入数据中激活不同的特征。对于第一个卷积层，输入数据是输入图像的原始像素，神经元学习激活输入图像中边缘的存在。卷积操作的步骤称为步长，它控制卷积层输出数据的大小。如果步长为 n，则卷积滤波器一次移动 `n` 个像素。对于较小的步长值，滤波器会重叠感受野并产生较大的输出数据大小。零填充用于用零填充输入数据的边缘。它需要保持输出数据大小与输入数据大小相同。每个卷积层对输出映射应用修正线性单元 (ReLU)，从而在架构中引入非线性。ReLU 应用逐元素激活，而不影响卷积层的感受野。该层中最常用的非线性激活函数是 `f(x) = tanh(x)`、`f(x) = max(0,x)` 和 `f(x) =(1+e^(−x))^(−1)`。

### 3.4.2.2 池化层

池化层对前一个卷积层生成的输入数据执行非线性下采样操作。该层在两个连续的卷积层之间执行。它是一种压缩提取特征并减少训练数据过拟合的过程。最常见的是，池化层使用 2 × 2 滤波器和步长为 2 进行下采样。因此，这种技术丢弃了 75% 的激活值。虽然有几种非线性函数可用，但最大池化是池化操作中最常用的非线性函数。在此层中，输入数据被分割为若干个方形子区域，并生成每个子区域的最大值。池化背后的逻辑是，图像/数据中特征的实际位置不那么重要。该层为架构提供了另一种形式的平移不变性。

### 3.4.2.3 全连接网络 (FCN) 层

在重复的卷积层和池化层之后，一个或多个 FCN 层执行特征分类。在此，当前层的每个节点都连接到前一层的每个节点。最终 FCN 层中的节点数由目标类别的数量决定。软最大值激活函数用于为目标类的每个节点生成 0 到 1 之间的值。软最大值函数生成图像/数据属于每个目标类别的概率。所有软最大值的总和为 1。

## 3.4.3 循环神经网络

RNN 能够为其内部记忆记住输入到输出的映射。网络包含至少一个反馈连接用于记忆，如 [图 3.4.](#bodymatter-003.xhtml#b_9783110670905-003_fig_004) 所示。延迟单元用于将 RNN 的输出引入循环回到网络中以进行记忆。RNN 将最近的过去数据插入当前状态。因此，RNN 既有当前输入数据，也有最近的过去输入数据。该网络是一种为序列数据提出的特殊神经网络。该网络允许展示时间序列数据的动态行为。RNN 架构使用其记忆来处理输入数据序列。RNN 是带有架构中循环的前馈 MLP。因此，一层的每个神经元可以将其信号传递到下一层。一层的输出可能作为下一个输入数据的输入反馈到该层。RNN 中的递归连接允许对任何输入数据序列获得广泛抽象的知识。RNN 更适用于连续手写字符识别或语音识别。
