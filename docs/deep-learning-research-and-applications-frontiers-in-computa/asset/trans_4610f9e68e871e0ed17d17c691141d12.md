本文研究的是单变量模型。在每个温度数据集（[表 7.2](#bodymatter-007.xhtml#b_9783110670905-007_tab_004)–[7.5](#bodymatter-007.xhtml#b_9783110670905-007_tab_007)）中，最大值与最小值之间的差异很小，即数据范围较小。但是，对于差异较大的应用，在聚类之前需要对数据进行预处理。在这种情况下，在聚类之前需要计算连续值之间的差异。差分有助于减少聚类的数量。如果时间序列包含趋势、季节效应等模式，则需要对数据进行预处理。

使用 BPTT 的缺点是大序列的内存需求。让我们讨论两种模型的时间复杂度和空间复杂度相关问题。对于具有 `n` 个输入层节点、`h` 个隐藏层节点和 `m` 个输出层节点的 BPNN 模型，第一层和第二层分别有 `h(n + 1)` 和 `m(h + 1)` 个链接权重。对于每个时代，空间和时间复杂度均为 `O(h · (m + n))` [[20](#bodymatter-007.xhtml#b_9783110670905-007_ref_015)]。

让我们假设隐藏层节点数和输入节点数分别为 `n` 和 `m`。时代长度由 `h` 表示。对于完全连接网络，可调整权重的数量 = `n (n + m)`，单位之间非零权重的数量 = `n²`。如果考虑每个时间段的期望输出值，那么时代级 BPTT 的空间复杂度为 `O(nh)`，平均时间复杂度（每个时间步）为 `O(n²)` [[15](#bodymatter-007.xhtml#b_9783110670905-007_ref_020)]。

## 7.5 结论

拟议模型可以处理不同数量的聚类和阶数。除了温度数据外，该预测模型还适用于其他数据集。未来，该技术还可以扩展到对多个观测值进行预测。未来还可以研究使用可变/动态序列长度（先前时间步）[21] 而不是固定序列长度的应用。这种方法也适用于解决复杂和动态的现实世界问题，例如生物信息学中的序列分类，其中需要包含多个变量的大型数据库。其他信号分析应用包括地震学和语音处理领域。
