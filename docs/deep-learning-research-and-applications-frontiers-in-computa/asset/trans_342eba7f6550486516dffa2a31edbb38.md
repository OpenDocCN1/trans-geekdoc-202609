

# 2.2 卷积运算

我们知道大脑处理信息，计算大量数据，并保留短期和长期记忆。人脑通过五个感觉器官获取原始输入并处理信息。ANN（人工神经网络）的概念正是由此而来。在 ANN 中，科学界一直试图模拟人脑的工作原理。大脑有其基本构建单元，负责从五种感官（来自外部世界）获取输入，并向身体发送指令。类比于 ANN 模型中发生计算的地方，其构建单元是神经元或神经细胞。神经元负责接收输入信号，并将这些输入映射到目标响应。同样，ANN 拥有一个由互连神经元组成的密集网络，每个连接都有突触权重。输入信号通过这个密集网络传播，并映射到目标响应。[表 2.1](#bodymatter-002.xhtml#b_9783110670905-002_tab_001) 和 ([图 2.2](#bodymatter-002.xhtml#b_9783110670905-002_fig_002)) 展示了生物神经元与人工神经元之间的比较。

在普通神经网络中，我们使用诸如梯度下降等权重更新规则来更新参数 `w^([L]^)`，该规则通过反向传播误差来最小化每次迭代后的损失。

在 DL（深度学习）中，我们拥有一个由神经元层组成的密集网络，原始输入按层级顺序逐层线性和非线性处理（图 2.3）。DL 是表示学习的一个子领域。神经网络试图自动学习良好的特征或表示，而深度神经网络（DNN）或 DL 算法（基于 ANN）则试图从原始输入 `x` 学习（多级别的）表示和输出。DL 并不仅仅意味着使用神经网络，而是意味着我们拥有多层表示。卷积神经网络（CNN）（Le Cunn 1989）是一种此类 DL 架构，已知其适用于以网格方式结构化的数据（[图 2.3](#bodymatter-002.xhtml#b_9783110670905-002_fig_003)）。

![图 2.3: 人工神经网络。](graphic/converted/b_9783110670905-002_fig_003.png)

图 2.3: 人工神经网络。

`Z[L] = W[L]A[L−1] + B[L] A[L] = g(Z[L])`

现在回到我们使用 DL 算法替代人工分类星系图像的任务，我们需要知道图像识别的基础是什么。图像是一个二维函数 `f(x,y)`，其中 `x` 和 `y` 是空间坐标，`f` 在任何坐标对 `(x,y)` 处的幅度称为该点图像像素的强度。因此，通俗地说，我们可以说图像是一个 `m × n` 维矩阵，可以被视为一个二维网格。当我们谈论图像时，我们将所有原始像素视为图像的特征。对于物体/图像分类任务，研究人员长期以来依赖于物体的边缘。图像的边缘图给出了物体的大致轮廓或形状，在物体分类中非常有用。在许多计算机视觉任务中，我们首先通过将滤波器传遍图像来检测图像中的边缘。[图 2.4](#bodymatter-002.xhtml#b_9783110670905-002_fig_004) 展示了滤波器如何传遍图像。

![图 2.4: 图像上 Sobel 滤波器的应用。](graphic/converted/b_9783110670905-002_fig_004.png)

图 2.4: 图像上 Sobel 滤波器的应用。

此处使用的滤波器是 Sobel 滤波器。我们可以说，滤波器可以被视为一组权重，它将输入 `A^([L−1]^)` 映射到输出 `Z^([L]^)]`。将滤波器传遍图像的效果在 [图 2.5](#bodymatter-002.xhtml#b_9783110670905-002_fig_005) 中显示，其中使用 Sobel 滤波器检测了猫的边缘。

![图 2.5: 应用 Sobel 滤波器后的猫图像输出。](graphic/converted/b_9783110670905-002_fig_005.jpg)

图 2.5: 应用 Sobel 滤波器后的猫图像输出。

像 Sobel 滤波器一样，有许多不同类型的滤波器可以在各种场景中使用。读者脑海中应该会出现一个问题：如何选择最优滤波器。如前所述，ML 算法学习参数 `W`，将输入 `X` 映射到输出 `Y`。因此，我们可以将物体识别任务视为一个受监督的 ML 问题，并学习能给出正确特征（边缘）的最优滤波器，这些特征可进一步用于分类物体。CNN 学习正确的一组滤波器，以提取用于分类物体的正确特征。在下一节中，我们给出了 CNN 的数学概述。名称表明 CNN 使用名为卷积的数学算子。这种卷积运算与数学或信号处理教科书中定义的不同。DL 社区实际上使用互相关（逐元素乘积之和），但按惯例称为 CNN，在本章中，我们将遵循该惯例。如前所述，卷积运算可以在任何以网格格式排列的数据上执行。例如，音频数据（一维网格，随时间或文本序列测量幅度）和图像（二维网格，每个位置 `x`、`y` 代表一个像素）。因此，使用正确的滤波器（可通过受监督的 ML 学习），我们可以学习提取正确的特征。

让我们看看卷积运算是如何工作的。

## 2.2 卷积运算

在板球比赛中，我们根据球员的平均表现来评判其优劣。这只不过是球员在所有参加的比赛中得分的平均值。现在假设我们作为板球队的教练，被指派从一群球员中选出最佳球员，我们可以使用卷积运算来帮助我们。卷积运算只是球员最近 `n` 场比赛得分的加权和。

因此，我们的责任是选择那些不仅表现一直很好，而且在最近过去也表现良好的球员。因此，球员在最近过去得到的得分应比在遥远过去得到的得分赋予更高的权重。因此，我们使用加权和来计算球员的表现。
