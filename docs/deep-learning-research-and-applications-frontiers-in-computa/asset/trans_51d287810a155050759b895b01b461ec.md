

# 基于时代的 BPTT 算法用于高阶 FTS 预测

在本研究中，时代 BPTT 算法 \[[15](#bodymatter-007.xhtml#b_9783110670905-007_ref_015)\] 用于预测高阶 FTS。计算通过将反向传播的信息截断到预定义的时间步数来完成。因此，该模型是时代 BPTT 和截断 BPTT \[[Figure 7.2](#bodymatter-007.xhtml#b_9783110670905-007_fig_002)\] 的组合。所提议的基于 BPTT 的方法步骤如下。

![Figure 7.2: Epochwise BPTT (truncated).](graphic/converted/b_9783110670905-007_fig_002.png)

Figure 7.2: Epochwise BPTT (truncated).

## Step 1

应用模糊 C 均值 (FCM) 算法 \[[18](#bodymatter-007.xhtml#b_9783110670905-007_ref_018)\] 创建 "`k`" 个簇，并获取每个数据点在每个簇中的模糊隶属度值。

## Step 2

选择先前时间步数 "`h`"。在此，这等于模型的阶数。

## Step 3

应用如下所述的时代 BPTT 的截断版本。

让我们考虑，数据点总数（总时间段）为 "`MAX`"，先前时间步数为 "`h`"。展开网络的每一层将模糊隶属度值作为输入。

### Algorithm

3.1. 初始激活 = 0；迭代 = 0。

3.2. `t` = 1；

3.3. 重复步骤 3.4–3.9，直到 `t` ≤ `MAX`-`h`

3.4. `t`[0] = `t`；重复步骤 3.5–3.6，直到 `t`[0] < `t` + `h`

3.5. 使用 [eqs. (7.1)](#bodymatter-007.xhtml#b_9783110670905-007_eq_001)–[(7.3)](#bodymatter-007.xhtml#b_9783110670905-007_eq_003) 在前向传递中计算输出值。

3.6. `t`[0] = `t`[0] + 1。

3.7. 在反向方向继续，重复 [eqs. (7.4)](#bodymatter-007.xhtml#b_9783110670905-007_eq_004) 和 [(7.5)](#bodymatter-007.xhtml#b_9783110670905-007_eq_005)。

3.8. 使用 [eq. (7.6](#bodymatter-007.xhtml#b_9783110670905-007_eq_006)) 更新每个连接权重。

3.9. `t` = `t` + 1。

3.10. Iteration = Iteration + 1

3.11. 如果 Iteration < 最大迭代次数，则转到步骤 3.2，否则停止。

## Step 4

去模糊化：

让我们考虑数据集中创建了 `m` 个簇。如果输出隶属度值为 `µ`[1], `µ`[2], … … …, `µ[m]`，且相应的簇中心为 `c`[1], `c`[2], … … …, `c[m]`。则，

(7.7)${Output} = \\frac{\\sum\_{i = 1}^{m}c\_{i}\\mu\_{i}}{\\sum\_{i = 1}^{m}\\mu\_{i}}$

### Example

让我们考虑温度（八月）数据集。模糊 C 均值算法被应用于创建三个簇。隶属度值显示在 [Table 7.1](#bodymatter-007.xhtml#b_9783110670905-007_tab_003)。在此情况下，输入单元和处理单元的数量均为三。现在，对于五阶模型，先前时间步数 `h` = 5。

现在，将以下隶属度值序列输入系统。展开网络的每一层代表一个时间步。三个隶属度值中的每一个都通过三个节点输入到网络的输入层中。
