### 4.7.2 迁移学习

深度学习的成功部分归功于大型数据集和大量计算能力的可用性。VGG `[[18](#bodymatter-004.xhtml#b_9783110670905-004_ref_018)]` 等深度神经架构如果没有大型数据集进行训练，则毫无用处。然而，在数据收集困难或昂贵的领域，大型数据集通常不可用。迁移学习使得深度学习能够在小数据集上工作。其假设是，深度学习模型在训练任务时会隐式地学习提取可重用特征。当两个领域相似时，在一个领域的数据集上训练的模型可以通过微调用于另一个领域。常见的迁移学习方法首先在像 ImageNet `[[19](#bodymatter-004.xhtml#b_9783110670905-004_ref_019)]` 这样的大型数据集上训练一个模型（通常是深度 CNN）。这使得 CNN 能够学习提取许多面向图像任务共有特征的滤波器。然后，将网络的最后一个全连接层替换为另一个全连接层，其输出神经元数量等于目标数据集中的类别数量。随后，在目标数据集上重新训练网络。在重新训练阶段，被训练的层数可以不同。可以选择只训练最后一层，并将网络的其余部分用作特征提取器。整个网络也可以重新训练。在过去十年中，迁移学习取得了一些令人印象深刻的结果。

## 4.8 深度学习框架

随着许多深度学习框架的兴起，深度学习研究变得更加容易。网络设计师不需要显式指定如何计算梯度，这些框架会自动为他们完成这项任务。这里介绍的大多数框架都是开源的。此外，其中大多数依赖于 CUDA `[[20](#bodymatter-004.xhtml#b_9783110670905-004_ref_020)]` 进行 GPU 处理。所有这些框架都使用某种形式的自动微分。下面简要介绍了一些流行的深度学习框架：

1. Theano：Theano `[[21](#bodymatter-004.xhtml#b_9783110670905-004_ref_021)]` 是一个开源项目，由蒙特利尔学习算法研究所开发。它从 2008 年一直处于活跃开发状态，直到 2017 年发布最终版本 1.0.0。本质上，该库允许在 GPU 和 CPU 上定义和执行数学表达式。与这里介绍的大多数其他库一样，它是用 C++ 实现的。它提供了一个与 Python 中流行的线性代数框架 NumPy 类似的 API。

2. Tensorflow：Tensorflow `[[22](#bodymatter-004.xhtml#b_9783110670905-004_ref_022)]` 的设计考虑了机器学习模型的部署。它内置了支持将工作负载分布到多个计算节点。在 Tensorflow 中，必须先定义并编译计算图。之后，可以输入数据并执行图。

3. Keras：Keras `[[23](#bodymatter-004.xhtml#b_9783110670905-004_ref_023)]` 是为了更容易地进行深度学习模型实验而构建的。它内置了多种深度学习架构。它提供了比 Tensorflow 或 Theano 等框架更高层次的抽象。Keras 只是一个包装器，实际计算委托给底层计算库。用户可以选择 Theano 或 Tensorflow 作为后端。

4. PyTorch：PyTorch `[[24](#bodymatter-004.xhtml#b_9783110670905-004_ref_024)]` 是一个相对较新的框架，由 Facebook AI 研究开发。它与 Keras 相似，旨在易于进行实验。与 Tensorflow 不同，PyTorch 不要求用户在执行前先编译计算图。虽然 PyTorch 不是为部署到生产环境而开发的，但最近的版本添加了功能，使 PyTorch 模型更适合生产。这些新增功能以即时编译（JIT）编译器的形式出现，允许在执行前编译和优化计算图，就像 Tensorflow 一样。PyTorch 的另一个重要特性是它允许以面向对象的方式定义神经网络。

5. Others：在过去几年中，开发了许多其他深度学习框架。计算网络工具包 `[[25](#bodymatter-004.xhtml#b_9783110670905-004_ref_025)]` 由微软开发。其他一些值得注意的框架是 MXNet `[[26](#bodymatter-004.xhtml#b_9783110670905-004_ref_026) [27](#bodymatter-004.xhtml#b_9783110670905-004_ref_027)]`。
