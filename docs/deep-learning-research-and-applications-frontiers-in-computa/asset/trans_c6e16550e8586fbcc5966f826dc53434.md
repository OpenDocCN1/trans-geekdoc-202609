

# 发育性书写障碍简介

根据先前的研究，认为书写障碍在智商水平平均的儿童中很常见，并且也出现在未被诊断出任何神经系统或知觉运动障碍的儿童中。

患有神经发育障碍的儿童患发育性书写障碍的风险非常高 \[[9](#bodymatter-005.xhtml#b_9783110670905-005_ref_009)\]。在学龄儿童中，风险相对较低，百分比在 10% 到 30% 之间 \[[8](#bodymatter-005.xhtml#b_9783110670905-005_ref_008)\]。临床已证实，书写困难会对个人的整体学业表现、心理和行为产生严重影响 \[[10](#bodymatter-005.xhtml#b_9783110670905-005_ref_010)\]。因此，尽早发现发育性书写障碍非常重要，以防止成年后出现不可控制和不希望的表现 \[[11](#bodymatter-005.xhtml#b_9783110670905-005_ref_011)\]。

科学研究证实，自动化系统在识别书写过程并对其进行评估，以区分患有书写障碍儿童的书写特征方面具有实用性 \[[8](#bodymatter-005.xhtml#b_9783110670905-005_ref_008), [12](#bodymatter-005.xhtml#b_9783110670905-005_ref_012), [13](#bodymatter-005.xhtml#b_9783110670905-005_ref_013), [14](#bodymatter-005.xhtml#b_9783110670905-005_ref_014)\]。然而，正如所认为的那样，深度学习的概念将对特征方面提供更多启示，并对诊断和识别书写障碍患者的书写缺陷更为有效。

此前，基于 HPSQ 总分估计的书写障碍自动评分系统已使用机器学习概念开发，该系统实现了书写参数化技术和同书写者归一化方法。

# 变分自编码器 (VAE)

首次，在本章中，VAE（一种用于压缩数据的深度学习技术）被用于识别书写障碍患者的常见书写特征。深度学习是无监督学习的一个子集，也称为分层学习，对机器学习领域产生了巨大影响 \[[15](#bodymatter-005.xhtml#b_9783110670905-005_ref_015)\]。AE 通常由前馈神经网络的密集、完全连接层组成；它由编码器网络和解码器网络组成。编码器被比作卷积神经网络 (CNN)。输入在自编码器内部的几个隐藏层“h”中进行处理。输入被编码为更小的表示作为输出。从特定层接收到的输出包含足够合适的信息，以便在网络的下一层中处理以产生所需的输出格式。它同时同化一个推断模型来推断图像数据的隐式特征，并理解一个生成模型，用于从这些推断的隐式特征生成图像。输入图像由 VAE 编码和解码。在此之后，实现聚类，这可能导致信息丢失。数据集中包含的各种字符之间的相似性和不相似性表现为字符聚类的输出。手动识别手写体比机器识别要容易得多，因为手写体因人而异。

VAE 被认为是一种神经网络，可以将图像加密为 `z` 实数的潜在空间中的一个方向。对于从 `z` 维正态分布中收集的样本，该方向被假设为任意的。然后，解码器网络解码编码后的向量表示并获得原始图像。可以从分布中绘制随机样本并将其输入解码器网络，其中潜在空间是 `z` 维正态分布。从此可以获得新图像，这些图像不存在于我们训练过的数据集中。编码器的架构在 [Figure 5.1](#bodymatter-005.xhtml#b_9783110670905-005_fig_001) 中表示。

VAE 的关键方面在于，其潜在表示 `y` ∈ℙ^K 源自特定的高斯分布（即，`p(y) = N(y| μ, Σ)`，其中 `μ` 表示均值，`Σ` 表示协方差）。VAE 以无监督方式训练，因为输出基本上是输入的重建版本。让我们考虑给定的训练数据集为 `S = {s[n]}[n][=1]^N`，VAE 包含一个概率编码器 `qθ(y|s)`，用于为给定的输入数据集 `s` 找到潜在表示 `y`。它还包含一个概率解码器 `pϕ(s|y)`，用于为特定的潜在表示重建输入数据，其中 `θ` 表示编码器的网络参数，`ϕ` 表示解码器的网络参数。

优化编码器和解码器中参数 `θ` 和 `ϕ` 的变分下界 `L[VAE](θ, ⌀)` 发生在学习 VAE 时。

(5.1)
```
L_VAE(θ, ∅) = ∑_{n-1}^{n} - E_y ~ qθ(y|s_n)[log p∅(s_n|y) + KL(qθ(y|s_n)||p(y))]
```

这里，第一项是重建误差，通过对 `y` 的分布取期望来计算，而第二项表示正则化项，即估计分布 `qθ(y|s[n])` 与真实分布 `p(y)` 之间的库尔贝克–莱布勒 (KL) 散度。这种散度是使用 `q` 来表示 `p` 时丢失的信息量的度量。参数的估计可以使用自编码变分贝叶斯算法完成 \[[16](#bodymatter-005.xhtml#b_9783110670905-005_ref_016)\]。

![Figure 5.2: (a) The encoder is used to compress data into latent space (y). (b) The decoder is used for reconstruction of given data which is a hidden representation.](graphic/converted/b_9783110670905-005_fig_002.png)

编码器被认为是一种神经网络，其输入是数据点 `s`，输出是隐藏表示 `y`，具有权重和偏差 `θ`。具体来说，让我们考虑 `y` 是一个手写数字的 15x15 像素照片。编码器将 225 维的数据“编码”到潜在（隐藏）表示空间 `y` 中，该空间的维度远小于 225。这通常被称为“瓶颈”，因为编码器必须能够将数据高效压缩到这个低维空间中。

从 [Figure 5.2](#bodymatter-005.xhtml#b_9783110670905-005_fig_002)，我们可以考虑或假设编码器表示为 `qθ(y|s)`。我们知道，低维空间是任意的：`qθ(y|s)`（即高斯概率密度）的参数是编码器的输出。可以对该分布进行采样，以获取表示 `y` 的噪声值。
