

### 7.4.2 性能评估

本研究中采用了五阶、六阶、七阶和八阶 FTS 模型。此处，先前时间步数的数量等同于所采用的阶数，即，对于五阶模型，`h = 5`。在第一步中，模糊 C-Means 算法被应用于为每个数据集创建不同数量的聚类，并使用 BPTT 模型定义模糊逻辑关系。模糊度指数 `m = 2`；对于温度数据集，error = 0.005。每个数据集中使用的聚类数量显示在 [表 7.6](#bodymatter-007.xhtml#b_9783110670905-007_tab_008)–[7.9](#bodymatter-007.xhtml#b_9783110670905-007_tab_011)，其中包含样本内数据的 RMSE。

外部输入节点的数量等于所采用的聚类数量。外部输入节点的数量和计算单元的数量相等。每个数据集的迭代次数为 100，学习率 = 0.5。

预测值是通过采用不同的序列长度（先前时间步数）和聚类组合计算得出的。然后，通过使用均方根误差（RMSE）和 Theil’s U 统计量 [[19](#bodymatter-007.xhtml#b_9783110670905-007_ref_019)] 计算预测误差。观察发现，预测的准确性取决于所创建的聚类数量和模型的阶数（所使用的层数）。对于每个数据集，仅显示预测值（对应于最小 RMSE）([表 7.2](#bodymatter-007.xhtml#b_9783110670905-007_tab_004)–[7.5](#bodymatter-007.xhtml#b_9783110670905-007_tab_007))。

(7.8) `${RMSE} = {}\\sqrt{\\frac{\sum\_{i = 1}^{n}\left( {A - P} \right)^{2}}{n}}` (7.9) `${U = \\left( {\sqrt{\sum\limits\_{i = 1}^{n}\left( {A - P} \right)^{2}}\\,} \\right)/\\left( {\left( \\sqrt{\sum\limits\_{i = 1}^{n}A^{2}} \\right) + \\left( \\sqrt{\sum\limits\_{i = 1}^{n}P^{2}} \\right)} \\right)}`

其中，`A` 和 `P` 分别代表实际值和预测值。观测数量为 `n`。

使用 BPTT 模型对六月数据集进行的误差估计显示在 [表 7.6](#bodymatter-007.xhtml#b_9783110670905-007_tab_008)。使用四个聚类，有四个隶属度值，这些值作为四个外部输入输入到系统中。如果我们使用五阶模型，则展开网络中的层数为五（即，`h = 5`），先前五个周期的隶属度值被输入到网络的每一层中。在这种情况下，RMSE 值为 1.17。同样，其他值是通过使用不同的序列长度（先前时间步数）和聚类组合计算得出的。

六月数据集 ([表 7.6](#bodymatter-007.xhtml#b_9783110670905-007_tab_008)) 在六阶（`h = 6`）下使用四个聚类产生最小 RMSE (0.99)。使用七月数据集 ([表 7.7](#bodymatter-007.xhtml#b_9783110670905-007_tab_009))，在六阶下使用六个聚类获得最小 RMSE (1.13)。对于八月数据集 ([表 7.8](#bodymatter-007.xhtml#b_9783110670905-007_tab_010))，在五阶（`h = 5`）下使用三个聚类获得最小 RMSE (0.98)。使用九月数据集 ([表 7.9](#bodymatter-007.xhtml#b_9783110670905-007_tab_011))，在七阶下使用七个聚类和八个聚类获得最小 RMSE (1.23)。在八阶下使用八个聚类时，RMSE 也是 1.23。

实验结果表明，预测的准确性取决于所创建的聚类数量和模型的层数（即阶数）。如果 `U` 的值 ([eq. (7.9](#bodymatter-007.xhtml#b_9783110670905-007_eq_009))) 接近于零，则可获得良好的预测准确性。
