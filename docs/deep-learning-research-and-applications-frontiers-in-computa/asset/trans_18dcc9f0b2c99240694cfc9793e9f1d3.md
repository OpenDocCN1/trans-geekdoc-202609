# 3 使用卷积神经网络进行手写数字识别

Ranjan Jana RCC Institute of Information Technology, Kolkata, West Bengal, India Siddhartha Bhattacharyya CHRIST (Deemed to be University), Bangalore, Karnataka, India Swagatam Das Indian Statistical Institute, Kolkata, West Bengal, India.

### 摘要

光学字符识别（OCR）系统已被用于从扫描文档或图像中提取文本。该系统包含两个步骤：字符检测和识别。字符识别需要一种基于特征的分类算法。字符可以使用神经网络进行识别。多层感知器（`MLP`）为字符分类提供了可接受的识别精度。此外，卷积神经网络（`CNN`）和循环神经网络（`RNN`）正在提供高精度的字符识别。`MLP`、`RNN` 和 `CNN` 在训练阶段可能会面临大量计算的问题。`MLP` 能以良好的精度解决不同类型的问题，但由于其密集的网络连接，耗时巨大。`RNN` 适用于序列数据，而 `CNN` 适用于空间数据。在本章中，一个 `CNN` 被实现用于从 MNIST 数据库中识别数字，并在 `MLP`、`RNN` 和 `CNN` 之间建立了比较研究。`CNN` 为数字识别提供了更高的精度，并且相对于 `MLP` 和 `RNN`，训练系统所需的时间最少。`CNN` 给出了更好的结果，精度高达 98.92%，因为使用的 MNIST 数字数据集是空间数据。

关键词：`convolutional neural network`, `deep neural network`, `handwritten digit recognition`, `multilayer perceptron`, `optical character recognition`, `recurrent neural network`

## 3.1 引言

光学字符识别（`OCR`）将手写文本图像或印刷文本图像转换为普通文本。文本图像通常来自文本文档的图像 \[[1](#bodymatter-003.xhtml#b_9783110670905-003_ref_001)\]。`OCR` 是许多计算机视觉问题中的重要领域，例如自动车牌识别、名片信息提取，以及护照、支票和发票文档的数据录入。`OCR` 大多是一个离线过程，它将静态文档中的文本转换出来。手写的运动可用于手写字符识别 \[[2](#bodymatter-003.xhtml#b_9783110670905-003_ref_002)\]。在在线字符识别中，除了使用字符或单词的形状外，还可以使用笔的方向和压力作为额外信息，以使过程更加高效。`OCR` 是一种机制，用于分类文本图像中属于的字符或单词。文本图像中的字符识别通过字符分割、特征提取和特征分类进行处理。多层感知器（`MLP`）的引入在计算机视觉的数据分类中是一场突破 \[[3](#bodymatter-003.xhtml#b_9783110670905-003_ref_003)\]，尽管 `MLP` 的性能完全取决于用于分类的对象的适当特征 \[[4](#bodymatter-003.xhtml#b_9783110670905-003_ref_004), [5](#bodymatter-003.xhtml#b_9783110670905-003_ref_005)\]。经典的机器学习技术已被深度神经网络（`DNN`s）所革新。该网络在原始像素数据上工作，以提取用于分类的适当特征 \[[6](#bodymatter-003.xhtml#b_9783110670905-003_ref_006)\]。`DNN` 设计有大量的隐藏层和连接。因此，网络有大量的参数，并且需要大量的训练样本来防止过拟合。`DNN` 架构主要分为卷积神经网络（`CNN`）和循环神经网络（`RNN`），以解决各种计算机视觉任务的问题。对于提取位置不变特征，通常使用 `CNN`，而 `RNN` 用于对序列数据中的网络进行建模 \[[7](#bodymatter-003.xhtml#b_9783110670905-003_ref_007)\]。与完全连接的神经网络相比，`CNN` 具有较少的参数 \[[8](#bodymatter-003.xhtml#b_9783110670905-003_ref_008)\]。`CNN` 能够通过改变隐藏层的数量和每层的可训练参数数量来对数据进行建模 \[[9](#bodymatter-003.xhtml#b_9783110670905-003_ref_009)\]。`CNN` 可以利用局部感受野和时间下采样，在输入和输出之间设计多功能的非线性关系，以提供一定程度的平移、旋转和畸变不变性 \[[10](#bodymatter-003.xhtml#b_9783110670905-003_ref_010)\]。在神经网络中，`CNN` 是由输入层和输出层之间的一系列卷积层和池化层组成的。在网络的最后一层执行完全连接层，以生成输入数据的唯一表示。在本章中，对 `MLP`、`RNN` 和 `CNN` 方法在 MNIST 数据集上的性能进行了比较。`CNN` 相比于 `MLP` 和 `RNN` 提供了更好的结果。

## 3.2 手写数字识别的动机

手写字符识别技术始于 1980 年左右。使用分类器进行手写数字识别的任务在机器学习中具有重要意义。手写字符识别通常对于邮政邮件分拣的邮政编码识别、银行支票处理、手写填写表格中的数字条目提取以及任何车辆的车牌识别非常重要。手写数字在大小、对齐和粗细方面有所不同，即使对于同一位书写者也是如此。不同个体对同一数字的书写也不同，这会影响数字的外观。因此，要实现手写字符识别，需要面对许多挑战。数字识别中的常见问题是预测数字，尽管它们相似，例如 3 和 5、9 和 4、8 和 9、5 和 6，如 [图 3.1](#bodymatter-003.xhtml#b_9783110670905-003_fig_001) 所示。本章的目的是实现一种方法，用于识别大小、粗细和方向各异的手写数字。
