

# 音频信号特征概述

## 感知特征

对心理声学的深入研究以及人类听觉信号处理的初级阶段构成了感知特征的基础。内耳中的耳蜗充当交叉带通滤波器。为了在现实世界中对其进行建模，所提议的方法包括伽马托恩滤波器 \[[20](#bodymatter-006.xhtml#b_9783110670905-006_ref_020), [21](#bodymatter-006.xhtml#b_9783110670905-006_ref_021), [22](#bodymatter-006.xhtml#b_9783110670905-006_ref_022)]，以及使用离散傅里叶变换的简单实现等，由此提取的特征被称为耳蜗图。另一个这样的特征是相关图，它负责捕捉信号中的基频和高次谐波的本质 \[[23](#bodymatter-006.xhtml#b_9783110670905-006_ref_023)]，这有助于音频分割。另一方面，模块谱能够检测扩展持续时间中的方差，这有助于在语音信号中保留音素或音节结构；这是通过对时间轴沿着每个频率分量应用某种变换来完成的 \[[24](#bodymatter-006.xhtml#b_9783110670905-006_ref_024)]。上述特征模拟了外耳。为了模拟内耳的复杂性，使用多尺度表示 \[[25](#bodymatter-006.xhtml#b_9783110670905-006_ref_025), [26](#bodymatter-006.xhtml#b_9783110670905-006_ref_026)]。因此，感知特征可以被视为能够传达声音同义性显著印象的简单次要特征。响度、尖锐度以及光谱质心或光谱通量和粗糙度等光谱特征，只是众多此类特征中的几个；MFCC 是其中最重要和最广泛使用的特征之一，将在本章后面详细阐述。

## 物理特征

物理特征在本质上更具数学性，提取技术大多直接应用于原始信号，而不将其转换到其他领域或应用滤波器，这与感知特征相反。此类特征包括能量的大小、波形在每个周期内振幅的变化 \[[27](#bodymatter-006.xhtml#b_9783110670905-006_ref_027)]、此类变化的持续时间，或波形大小的均方根。这些特征也可以是基于节奏的，并使用不同的方法计算，包括查找频率带中输出包络的峰值，或查找脉冲清晰度或带周期性，仅举几例。另一组物理特征是基于频率的，包括光谱通量、线谱频率、光谱峰值和光谱质心，光谱质心定义为光谱能量的重心，导致频率值的平均值。频率特征还包括音高剖面、谐波性、抖动以及许多其他光谱特征，将在本章后面详细阐述。小波变换在表示不连续函数方面优于傅里叶变换（FT），因为它们能够精确地重构和重建有限、非周期和非平稳信号。因此，基于小波的特征，如赫斯特参数特征和基于匹配追踪的加博特征，作为声乐和音乐音频信号的适当特征集。图像处理技术用于从音频信号的时频图（以图像形式）中提取特征。这些特征被称为图像谱图。其他物理特征包括倒谱特征以及来自特征空间、相空间和声环境特征的特征。

音频信号特征的分类体系分支到非常详细的程度，每个类别下都有各种类型的特征，感兴趣的读者可以参考 \[[18](#bodymatter-006.xhtml#b_9783110670905-006_ref_018)] 以获取更多详细信息。在本章中，仅提及并详细介绍了用于音频分类和学习的最常见和最广泛使用的特征。

## 6.2.3 梅尔频率倒谱系数 (MFCCs)

MFCCs 是最广泛使用的感知特征，因为它们成功地简洁地体现了语音幅度谱。这些特征是在对音频信号应用一系列函数后获得的，如文中所述 \[[10](#bodymatter-006.xhtml#b_9783110670905-006_ref_010), [28](#bodymatter-006.xhtml#b_9783110670905-006_ref_028)]。

它始于应用一个滤波器，该滤波器放大信号中的高频部分，从而提高这些部分的能量。放大后，整个信号被分割成小帧，通常范围在 20ms 到 40ms 之间。这样做是因为音频信号在不断变化，但在短时间内统计变化不大，因此所选范围是合适的，因为更小的范围无法为良好的光谱估计提供足够的样本。接下来的过程是应用汉明窗函数，它消除了边缘效应并同化了彼此靠近的所有频率线。这样做是为了模拟人耳的耳蜗，耳蜗无法区分彼此非常接近的频率，从而保持了该技术的感知特性。汉明窗的输出在等式 (6.1) 中表示。

(6.1) `y(n) = x(n) × w(n)`

在等式 (6.2) 中，`N` 表示每个帧中的样本数，在等式 (6.1) 中，`y(n)` 是输出信号。输入信号由 `x(n)` 表示，`w(n)` 表示汉明窗操作。时间信号由其组成频率组成，对时间信号进行傅里叶变换（FT）可得到频率域中的相应复值函数。该变换由等式 (6.3) 表示。

(6.3) $F\\left( \\xi \\right) = \\!\\!\\int\\limits\_{- \\infty}^{\\infty}\\!\\! f\\left( x \\right)e^{- 2\\pi ix\\xi}dx$

在上述方程中，ξ 是任何实数，Ƒ(ξ) 表示函数 f(x) 的傅里叶变换。因此，在窗口处理后，对结果信号应用傅里叶变换，因此现在处理的对象是频率表示。应用傅里叶变换后的结果信号用等式 (6.4) 表示。结果帧的基于周期图的功率谱估计，由 `P[i](k)` 表示，由等式 (6.5) 给出。

(6.4) $S\_{i}\\left( k \\right) = \\sum\\limits\_{n = 1}^{N}s\_{i}\\left( n \\right)y\\left( n \\right)e^{- j2\\pi kn/N\\ }\\ 1 \\leq k \\leq K$

(6.5) $P\_{i}\\left( k \\right) = \\frac{1}{N}\\left| {S\_{i}\\left( k \\right)} \\right|\\ ^{2}$

在上述方程中，`i` 是帧的总数，`n` 表示每个帧中的样本，`N` 是一个帧中的样本总数，`K` 表示傅里叶变换的长度。`y(n)` 是窗口处理后获得的输出信号。让我们假设前 `C` 个系数用于进一步处理（用法将在后面展示）。耳蜗无法区分彼此非常接近的频率线的能力在高频处更加明显。梅尔尺度有助于将这种行为融入提取的特征中，使其类似于人类处理音频的方式。梅尔变换由等式 (6.6) 给出。

(6.6) $M\\left( {\\, f} \\right) = 1125 \\times {ln}\\left( {1 + \\frac{f}{700}} \\right)$

在上述方程中，`f` 是以赫兹表示的频率。为了在梅尔尺度上表示功率谱，对其应用滤波器组。[Figure 6.4](#bodymatter-006.xhtml#b_9783110670905-006_fig_004) 展示了滤波器组和窗口分段的演示。
