## 20.3.2 DEVICE TO CLOUD DATA TRANSMISSION

The amount of data that is sent to the cloud is significantly influenced by fall detection variations, such as cloud and edge-oriented systems that use mobile IoT devices. Since fall detection uses an ML-based classifier as a cloud-based Web service, cloud-oriented fall recognition relies on continuous data communication. Fall identification on the edge enables less data transfer from the device to the cloud. It can even send no data at all to the cloud when used with the local module that alerts the care in the event of danger. Regardless of whether the fall occurred or was misidentified, there should at least certain periods of continuous surveillance when it is detected, as this would prevent the monitored individual from being able to compile a history of incidents.

If shearing in the $y$-axis of the same point leads to a new coordinate $(x_3,y_3)$, then it is

```
$$\begin{bmatrix} x_3 \\ y_3 \end{bmatrix} = \begin{bmatrix} 1 & 0 \\ Sh_y & 1 \end{bmatrix} \times \begin{bmatrix} x_i \\ y_i' \end{bmatrix}$$
```

A flip (mirror effect) reverts the pixels vertically or horizontally. For example, the (x, y) coordinate pixel is located at coordinate (width−x−1, y) at the modified image for a horizontal flip.

## 20.3.4 CLASSIFICATION USING CNN

A CNN is composed of layers, each of which uses a differentiable function to convert one volume to another (Iqbal et al., 2022). The five types of layers in the proposed CNN, as shown in Figure 20.2, include the input layer, the convolution layer, the activation function layer, the pooling layer, and the fully connected layer. The input layer holds the raw input of the image with width $W$, height $H$, and depth $C$. For a convolution layer $L^{[l]}$ with filter size, $p_h^{[l]}$ = padding size, $n_f^{[l]}$ = number of filters, for input $n_h^{[l-1]} \times n_w^{[l-1]} \times n_c^{[l-1]}$ where the height, width, and the number of channels get denoted by $H, W$, and $C$, respectively. The output is represented by $n_h^{[l]} \times n_w^{[l]} \times n_c^{[l]}$ where $n_h^{[l]} = n_h^{[l-1]} + 2p - f + 1$, each filter is $f^{[l]} \times f^{[l]} \times n_c^{[l-1]}$, activations from one layer to the next layer:

```
$A^{[l]} = M \times n_h^{[l]} \times n_w^{[l]} \times n_c^{[l]}$
```

## 20.4 ANALYSIS OF EXPERIMENTAL OUTCOM

This section defines the dataset and presents the experimental outcomes. The proposed model's performance is quantified using evaluation metrics like accuracy, precision, error rate, and F1 score. Also, the confusion matrix, the receiver operating characteristic (ROC) curve, and the learning curve have been presented, where the learning curve displays the training and validation performance over time. The ROC curve represents the relationship between the false positive rate (FPR) and the true positive rate (TPR) for several thresholds. Confusion matrices are used to assess how well the model performs across several categories, fall, and not.

### 20.4.1 DATASET DESCRIPTION

The “Fall Detection Dataset” from (Wolek and Kepsi, 2014) has been used in the proposed work. The dataset includes images categorized by “Fall” and “Not Fall”, a collection of images displaying various fall-related scenarios. The training and testing data have been divided into 80:20 ratio.

### 20.4.2 DATA AUGMENTATION OUTCOMES

Since zero to 255 for the RGB coefficient of original images is too high for the considered models to consider a particular learning rate, values between zero and one scaling by 1/255 have been targeted in the first step of the data augmentation technique (Ghosh et al., 2020). The shearing transformation on the images is applied randomly with 0.2 factor. After that, the images are zoomed with asymmetry. Half of the images are randomly flipped horizontally.
