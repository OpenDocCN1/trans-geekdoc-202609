# 20.3.2 DEVICE TO CLOUD DATA TRANSMISSION

The amount of data that is sent to the cloud is significantly influenced by fall detection variations, such as cloud and edge-oriented systems that use mobile IoT devices. Since fall detection uses an ML-based classifier as a cloud-based Web service, cloud-oriented fall recognition relies on continuous data communication. Fall identification on the edge enables less data transfer from the device to the cloud. It can even send no data at all to the cloud when used with the local module that alerts the carner in the event of danger. Regardless of whether the fall occurred or was misidentified, there should at least certain periods of continuous surveillance when it is detected, as this would prevent the monitored individual from being able to compile a history of incidents.
