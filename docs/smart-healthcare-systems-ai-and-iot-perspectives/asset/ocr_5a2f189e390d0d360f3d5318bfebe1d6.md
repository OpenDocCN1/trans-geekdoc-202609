# 15.3.4 GRADIENT BOOSTING CLASSIFI (GBC)

For the prediction of heart disease, GBC, introduced by Friedman [35], is a new kind of ensemble learning method in which error correction between weak learners combines to produce accuracy. The GBC process is a mathematical series of iterative processes designed to gradually enhance the model's performance:

+   1. Initialization: For each observation, $F_0(X)$ is the initial prediction, which is often a straightforward forward learner. The residuals are calculated as $r_0 = Y - F_0(X)$, where $Y$ is the binary outcome that determines the presence or absence of cardiac disease.

+   2. Sequential Model Building: Create a new learner, $h_n(X)$, for every iteration in order to forecast the residuals, $r_{n-1}$. To update the model, add the learning rate, denoted as $v$, is a hyperparameter that governs the influence of every weak learner—$F_n(X) = F_{n-1}(X) + v 	imes h_n(X)$ is obtained.

+   3. Gradient Descent:

The pseudo-residuals are defined as $R_n = \frac{\delta K(Y, F_{n-1}(X))}{\delta F_{n-1}(X)}$, in this case,

K symbolizes the loss function that quantifies the variation between the anticipated and exact values.

—Adjust struggling to the pseudo-residuals:

```
$h_n(X) = \arg \min \sum K(Y, F_{n-1}(X_j)) + h_n(X_j)$
```

—Revise the model: $F_n(X) = F_{n-1}(X) + v \times h_n(X)$.

+   4. Iteration: The Gradient Descent and Sequential Model Building methods must be repeated for a given number of times or until the convergence condition is satisfied.

Using the GBC has many advantages in heart disease prediction. It's really good to find intricate relationships between patient data and is able to provide a pretty complete picture of the causes, with how different factors are related to the changes of heart disease. Because the algorithm has an iterative structure, it not only makes its accuracy excellent but also allows it to handle complex relationships and prevent overfitting. Using GBC's intrinsic feature significance measurement, healthcare practitioners can discern the important factors influencing prognosis for heart disease. In fact, the GBC is a powerful tool in the arsenal of predictive modeling for heart disease. The model can make more effective predictions, and the whole is better than its parts.
