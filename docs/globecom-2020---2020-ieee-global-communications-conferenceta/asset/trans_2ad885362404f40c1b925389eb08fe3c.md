
这些实例被分为两组，我们称之为追踪器集和非追踪器集（§ III-B）。

- 2) 为站点和请求提取特征（§ III-C）。

## C. 特征提取

我们通过实验提取了与站点和请求相关的以下特征。

¹数据集可于 https://github.com/fukuda-lab/cname-cloaking 获取

### 1) 发生与 CNAME 匿装相关追踪的站点：

- num_url：站点中的 HTTP 请求总数。
- num_1st：站点中的第一方请求总数。
- num_3rd：站点中的第三方请求总数。
- pct_script_call：站点中与指纹识别相关的方法调用比例。
- pct_xhr：站点中 XMLHttpRequest 的比例，这是浏览器内置对象，可用于在 JavaScript 中发出 HTTP 请求，以便在 Web 浏览器和服务器之间交换数据。
- pct_3rd_window：窗口层次结构中源自第三方 DOM 窗口的请求比例 [22]。
- ranking：根据 Alexa 排名 [23] 的站点排名。
- country：基于 Free IP Geolocation API [24] 的站点所在国家。
- category：根据 2020 年 4 月的 FortiGuard Web Filtering [25] 数据集的站点类别。

### 2) 与 CNAME 匿装相关追踪关联的请求：

- method：针对给定请求期望执行的操作。
- is_xhr：该请求使用一种 API，该 API 提供脚本化的客户端功能，用于在客户端和服务器之间传输数据。
- content_type：导致请求的 HTML 标签，例如 image、javascript 或 document，这些标签在此 IDL [22] 中定义。
- len_url：请求 URL 的长度。
- len_sub：请求的子域长度。
- len_prefix_sub：请求的子域前缀长度。
- num_prefix_sub：子域前缀的数量。
- prefix_sub_blacklist：子域前缀位于追踪过滤列表 [14] [19] 的子域前缀中。
- is_sub_dic：子域前缀是英语字典中的单词。
- entropy_url：通过从请求 URL 计算度量熵得到的请求 URL 的随机性。
- entropy_sub：通过从子域计算度量熵得到的子域的随机性。
- entropy_prefix_sub：通过从子域前缀计算度量熵得到的子域前缀的随机性。

## D. 建模与初步结果

首先，我们将 2020 年数据集（表 I）分割为测试数据和训练数据。用于测试的数据占比为 20%。它将在 § IV-A 中用于评估我们的模型。接下来，我们描述如何使用测试数据（2020 年数据集的 80%）构建分类模型以检测基于 CNAME 匿装的追踪。

### 1) 模型交叉验证：

我们将训练数据集随机分割为 10 个较小的子集（折叠），且不放回抽样，其中九个折叠用于模型训练，剩余一个折叠用于验证。通过重复此过程十次获得 10 个性能估计值后，我们取其平均值作为最终性能估计值。随后，我们比较 10 种分类算法，并使用分层交叉验证过程在训练数据（2020 年数据集的 80%）上评估其 F1 分数。我们使用 scikit-learn 模块中的 10 种有监督分类算法（random_state = 2，使用默认参数）：

- 支持向量分类 (SVC)
- 决策树
- AdaBoost
- 随机森林
- 极端随机树
- 梯度提升
- 多层感知机 (MLP)
- K 近邻 (KNN)
- 逻辑回归
- 线性判别分析 (LDA)

我们使用 F1 分数来评估分类器的性能。F1 分数越大（≈ 1.0）表示性能越好，值越小（≈ 0）表示性能越差。图 3(a) 显示了在 2020 年数据集中，使用 10 折分层交叉验证对 10 种选定算法针对发生 CNAME 匿装相关追踪的站点进行检测时的 F1 分数。所有分类算法的检测性能各不相同。最有效的分类算法是随机森林、极端随机树和梯度提升，而支持向量分类、多层感知机和 K 近邻在该数据集上表现中等。

图 3(b) 显示了检测与 CNAME 匿装相关追踪关联的请求时的 F1 分数。最有效的分类算法是随机森林和极端随机树，而 SVC 表现最差。

### 2) 最佳模型的超参数调优：

根据之前的性能评估，我们为站点分类检测的超参数调优阶段选择了 RandomForest、ExtraTrees 和 GradientBoosting 分类器。对于请求，我们选择随机森林和极端随机树分类器。

### 3) 模型组合：

现在，我们有一组性能良好的模型，用于检测与基于 CNAME 匿装的追踪相关的站点和请求。为了平衡各自的弱点，我们组合在概念上不同的机器学习分类算法，并使用预测概率之和来预测类别标签。

因此，我们使用带软投票的 VotingClassifier 来组合来自以下有监督分类算法的预测：用于检测站点的 RandomForest、ExtraTrees 和 GradientBoosting，以及用于检测请求的 RandomForest 和 ExtraTrees。各独立算法和组合模型的性能将在下一节中讨论。
