# 2.6.2 The CIE Color Diagram

In the XYZ color model, the brightness of the color, considering that the value of the black color is Y = Z = 0, increases as the value of the Y axis increases. In order to clearly represent the color in two dimensions, the CIE color model defines the factors x, y, and z as follows:

```
x = \frac{X}{X + Y + Z}

y = \frac{Y}{X + Y + Z}

z = \frac{Z}{X + Y + Z}

```
