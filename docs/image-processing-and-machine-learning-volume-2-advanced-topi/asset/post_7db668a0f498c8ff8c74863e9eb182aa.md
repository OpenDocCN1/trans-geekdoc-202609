
On the other hand, V(x, y) is the variance magnitude at position (x, y), produced by considering a window of size h×h. Therefore, the feature vector F(x, y) at the location (x, y) is represented by a three-dimensional structure defined by Equation 5.12.

$$ \mathbf{F}(x,y)=[\mathbf{I}(x,y) \quad \mathbf{V}(x,y) \quad \mathbf{NL}(x,y)] $$ (5.12)

In F(x,y), all the values of grayscale I(x,y), variance V(x,y), and non-local mean NL(x,y) are normalized within the values [0,1].
The variance V(x,y) of contiguous pixels represents one of the simplest methods to evaluate the data dispersion. A low value corresponds to a homogeneous region, while a high magnitude could represent texturized objects. The non-local means NL(x,y) feature considers the mean of similar pixels in terms of their grayscale value. Under this characteristic, the resemblance among pixels presents better robustness in the presence of noise by assuming the comparison with regions and not with only pixels. With the use of NL(x,y), it is possible to identify if a pixel belongs to a homogeneous region with a specific intensity. Since this feature reduces the possible noise content within a region, its use presents high robustness. Therefore, with the integration of these three characteristics I(x,y), NL(x,y), and V(x,y) is possible to find pixel associations that allow for segmenting complex elements such as texturized regions or poorly illuminated components, etc.

## 5.4.2 Operative Data Set

The cost of processing the M×N features from the image through MS is prohibitive in cases where there are several characteristics per pixel. To diminish the computational overload of the process, MS is executed by considering only a subset of random elements, which represent a very reduced number of data extracted from all available elements from F(x,y). The objective is to obtain a small amount of similar data results, as the MS has been operated with the complete dataset. For this purpose, the whole set of characteristics F is classified into two sets: operative elements O and inactive elements Ō. The set of operative data O includes the elements considered for the execution of MS, while the group of inactive data Ō corresponds to the remainder of the available data information. As they are defined, it is evident that Ō represents the complement group of O in F.

The size s of O (number of random elements) has determinant importance in the resulting performance of the segmentation process. Therefore, the number s of used elements needs to be reduced until the approach presents a performance degradation in terms as it has been operated with the complete dataset. In order to analyze the effect of this parameter on the performance of the MS segmentation scheme, a sensitivity test has been considered. In the experiment, different values of s are experimented with, while the rest of the MULTI-SEGM parameters are kept fixed to their common values. In the test, s represented as the percentage of the whole data is swept from 1% to 100%, while the segmentation results of the MS method are studied. The data used in O are randomly chosen from the whole dataset F. Thus, to reduce the stochastic effects, every different value of s is executed 30 times independently. The results demonstrate that for higher percentages than 5%, the CC is expanded exponentially while a small enhancement in the performance of the method is perceived. As a conclusion from this study, it can be stated that the best size s of O is obtained when the number of elements is around 5% of the complete number of available data.

Therefore, only 5% of the M×N data is used to generate the group O. Such elements are randomly sampled from F. The set O involves three-dimensional elements {o₁, ..., oₛ}, where s = int(0.05 · M · N), assuming int(·) produces as a result the integer value corresponding to its argument. On the other hand, set of elements in Ō = {ōₐ, ō_b, ..., ō_c} is composed of data according to Ō = {a, b, c ∈ F | a, b, c ∉ O}.

## 5.4.3 Operation of the MS Algorithm

### 5.4.3.1 MS Setting

Having produced the dataset O, the MS is applied to it. In the operation of the MS, two important parameters must be configured: the kernel support range h and the step length δ. As the MS method processes the information of a three-dimensional solution space [I(x,y) V(x,y) NL(x,y)], both elements correspond to vectors of three dimensions h and δ with a magnitude for every dimension h = [h₁, h₂, h₃]; δ = [δ₁, δ₂, δ₃] where each of dimensions 1, 2, and 3 corresponds to the intensity value I(x,y), the local variance V(x,y), and the non-local mean NL(x,y) feature, respectively. These factors are configured automatically by means of an analysis of the set O. The study considered to determine the correct configuration is based on Scott’s rule introduced in [43]. Under this scheme, the extent of both elements h and δ are strongly associated with the standard deviation σ of the data in O = {o₁, ..., oₛ}. Every element from o_i ∈ O is characterized as o_i = {o_{i,1}, o_{i,2}, o_{i,3}}, where o_{ij} symbolizes the j-th variable of the i-th candidate solution (j ∈ 1, ..., 3). Therefore, the standard deviation for each dimension σ_j is computed by Equation 5.13.

$$ \sigma_j = \sqrt{\frac{1}{s} \sum_{i=1}^s \left( o_{i,j} - \bar{o}^j \right)^2} $$ (5.13)

where $\bar{o}^j$ corresponds to the averaged value such that $\bar{o}^j = \left( \frac{1}{s} \right) \sum_{i=1}^s o_{i,j}$.

With these values, the factors h and δ are configured as it is indicated by Equation 5.14.

$$ h_j = 3.5 \cdot \sigma_j \cdot s^{-(\frac{1}{3})}, \quad \delta_j = \sqrt{0.5} \cdot \sigma_j, \quad (5.14) $$
where $j \in [1,...,3]$.

$$
