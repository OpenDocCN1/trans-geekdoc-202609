# 3.1.4.1 Determination of Transformation Parameters

The parameters of the projective transformation are completely determined by the definition of 4 coordinate points \(\big(\)**x**$_1, \mathbf{x}'_1\big)\), \(\big(\)**x**$_2, \mathbf{x}'_2\big)\), \(\big(\)**x**$_3, \mathbf{x}'_3\big)\) and \(\big(\)**x**$_4, \mathbf{x}'_4\big)\), **x**$_i = (x_i, y_i)$ corresponds to the points of the original image while \(\mathbf{x}'_i = (x'_i, y'_i)\) corresponds to the transformed image.
