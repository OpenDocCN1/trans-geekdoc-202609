# PROGRAM 6.2 DETERMINATION OF THE PRINCIPAL COMPONENTS

```
% Load the data into a matrix
data = A;
% Subtract the mean of each column from the data
data = bsxfun(@minus, data, mean(data));
% Compute the covariance matrix
cov_matrix = cov(data);
% Compute the eigenvectors and eigenvalues of the
covariance matrix
[eigenvectors, eigenvalues] = eig(cov_matrix);
% Sort the eigenvectors and eigenvalues in descending
order
[eigenvalues, index] = sort(diag(eigenvalues),
'ascend');
eigenvectors = eigenvectors(:, index);
% Project the data onto the principal components
projected_data = data * eigenvectors;
% Visualize the data in the PCA space
scatter(projected_data(:, 1), projected_data(:, 2));
xlabel('First Principal Component');
ylabel('Second Principal Component');
```
