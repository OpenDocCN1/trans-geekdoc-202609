# # ALGORITHM 4.2 CHAMFER ALGORITHM FOR CALCULATING DISTANCE TRANSFORMATION

Distance Transformation ($I_b(x, y)$)
Binary image $I_b(x, y)$ of dimensions $M \times N$

+   1: Step 1. It initializes.
+   for all coordinates of the image $I_b(x, y)$ do
+   if ($I_b(x, y) = 1$) then
+   D(x, y) = 0
+   else
+   D(x, y) = a big value.

+   2: Step 2. The image with the mask $M^l$ is processed from left to right
+   and from top to bottom.
+   for y <- 1, 2, ..., M do
+   for x <- 1, 2, ..., N do
+   if ($I_b(x, y) > 0$) then
+   d1 = $m_1^l + D(x-1, y)$
+   d2 = $m_2^l + D(x-1, y-1)$
+   d3 = $m_3^l + D(x, y-1)$
+   d4 = $m_4^l + D(x+1, y-1)$
+   D(x, y) = min(d1, d2, d3, d4)
+   end
+   End

+   3: Step 3. The image with the mask $M^D$ is processed from right to left
+   and from bottom to top.
+   for y <- M - 1, ..., 1 do
+   for x <- N - 1, ..., 1 do
+   if ($I_b(x, y) > 0$) then
+   d1 = $m_1^R + D(x+1, y)$
+   d2 = $m_2^R + D(x+1, y+1)$
