Different Operations That Can Be Implemented Using the MATLAB® Function bwmorph

| Operation | Description |
|---|---|
| shrink | If n=inf, the objects are reduced to points. Objects without holes are reduced to points, while objects with holes form rings. This operation maintains the Euler number |
| skel | If n=inf remove all pixels, reducing them to their lowest expression, lines. This process is called skeletonization |
| thicken | Add pixels to objects, only placing pixels that are connected |
