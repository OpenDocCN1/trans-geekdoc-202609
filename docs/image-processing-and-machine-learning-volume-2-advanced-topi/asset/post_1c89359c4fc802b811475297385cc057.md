## 3.3.2 Ideal Interpolation

Obviously, the previously seen interpolation alternatives do not produce a good approximation of the function, so it will be necessary to establish others that allow the intermediate values of a discrete signal to be expressed in a better way.

The objective of this section is to analyze the counterpart of the previous simple interpolation methods, that is, to raise the possibility of modeling the best possible way to interpolate a discrete function.

A discrete function, as seen in Chapter 13, has a limited bandwidth whose maximum value is characterized by half the sampling frequency ω_s / 2 with which it was obtained. In the same way, it was investigated in Chapter 13 how these signals, both in the space domain and in the frequency domain, present periodicity. In view of the above, if you only want to take one version of the spectrum F̅(ω), it will suffice to multiply the spectrum (which is periodic) by a rectangular function H(ω) of width ±ω_s / 2 or ±π. Figure 3.14 illustrates this process of obtaining the spectrum.

All of the above was considered from the point of view of the frequency domain; as it was seen in Chapter 13, a multiplication in the frequency domain corresponds to a convolution in the space domain. So, a multiplication in the frequency domain by a rectangular function would mean convolving by the transform of the rectangle function, which in this case would be by the function Sinc(x), which is defined by:

```
Sinc(x) = ( sin(πx) / πx ) (3.44)
```

Theoretically, the function Sinc(x) is the ideal interpolation function for the reconstruction of continuous functions. To interpolate a value of the function g(u) at any position x_0, the Sinc(x) function moves in such a way that its origin is the point x_0, then the point-to-point convolution between g(u) and

```

## 3.3.3 Cubic Interpolation

Due to the infinite size of the interpolation kernels necessary for the \(Sinc(x)\) function during the convolution, this method is not feasible in practice. For this reason, we try to reproduce the effects of the ideal interpolation by means of the _Sinc_(_x_) function. but using compact kernels that approximate their results. A widely used approach for the realization of these kernels is the so-called cubic interpolation, which uses cubic polynomials to make the approximation [8], that is:

```
w_{cubic}(x, a) = \begin{cases} (a + 2) \cdot |x|^3 - (a + 3) \cdot |x|^2 + 1 & \text{if } 0 \le |x| < 1 \\ a \cdot |x|^3 - 5a \cdot |x|^2 + 8a \cdot |x| - 4a & \text{if } 1 \le |x| < 2 \\ 0 & \text{if } |x| \ge 2 \end{cases} \quad (3.46)
```

where _a_ is a control parameter that defines how steep the cubic approximation falls. Figure 3.15 shows different kernels of the cubic interpolation using different values of the parameter _a_. For a standard value of _a_ = -1 a simplification of Equation 3.46 occurs, such that:

```
w_{cubic}(x) = \begin{cases} |x|^3 - 2 \cdot |x|^2 + 1 & \text{if } 0 \le |x| < 1 \\ -|x|^3 + 5 \cdot |x|^2 - 8 \cdot |x| + 4 & \text{if } 1 \le |x| < 2 \\ 0 & \text{if } |x| \ge 2 \end{cases} \quad (3.47)
```

From the comparison between the function Sinc(x) and the cubic kernel _w_<sub>cubic</sub>(_x_) in Figure 3.16, it is shown that the difference between both functions is negligible when |_x_| ≤ 1, while the differences become more evident when |_x_| > 1. The most critical case occurs when |_x_| > 2, which is when the cubic kernel returns only a value of zero.

```

### 3.3.3.1 Nearest Neighbor Interpolation Method

For the interpolation of a certain point $(x_0, y_0)$, the coordinates of the pixel $(u_0, v_0)$ that is closest to it are assigned; in many cases, to carry out this method, it is enough to apply a rounding to the coordinates obtained by the geometric transformation.

This is:

```
$I(x_0, y_0) = I(u_0, v_0)$
```

where

```
$u_0 = round(x_0)$
$v_0 = round(y_0)$
(3.49)
```

### 3.3.3.2 Bilinear Interpolation

What linear interpolation represents for the one-dimensional case, bilinear interpolation represents for the two-dimensional or image case. To explain the operation of this type of interpolation, the illustration shown in Figure 3.18 will be used. Where each of the neighboring pixels to $(x_0, y_0)$ are defined as:

![](img/fa2d7e8bd88af7122f764c748b0a3723_144_0.png)

**FIGURE 3.18** Bilinear interpolation. The interpolation of point G at position $(x_0, y_0)$ is produced in two steps considering the neighboring pixels defined at points A, B, C, and D. First through linear interpolation, points E and F are obtained considering the distance between the point to be interpolated and the adjoining pixel $a = (x_0 - u_0)$, then the vertical interpolation is performed, obtaining the intermediate points between E and F by means of the distance $b = (y_0 - v_0)$.

\( A = I(u_0, v_0) \qquad B = I(u_0 + 1, v_0) \)
\( C = I(u_0, v_0 + 1) \qquad D = I(u_0 + 1, v_0 + 1) \)

To obtain the value \((x_0, y_0)\), two different linear interpolations are obtained that are established on the points \(E\) and \(F\) from the distance \(a = (x_0 - u_0)\) that is established between the point and the nearest neighbor. These values, when calculated from a linear interpolation, are defined as:

\( E = A + (x_0 - u_0) \cdot (B - A) = A + a \cdot (B - A) \)
\( F = C + (x_0 - u_0) \cdot (D - C) = C + a \cdot (D - C) \)

From the previous values, the interpolation for point \(G\) is obtained considering the vertical distance \(b = (y_0 - v_0)\), such that:

\(\hat{I}(x_0, y_0) = G = E + (y_0 - v_0) \cdot (F - E) = E + b \cdot (F - E) \)
\( = (a - 1)(b - 1)A + a(b - 1)B + (1 - a)bC + abD \)

Just as the linear convolution kernel was formulated, the two-dimensional bilinear interpolation kernel \(W_{bilinear}(x, y)\) can also be defined. This will be the product of two one-dimensional kernels \(w_{bilinear}(x)\) and \(w_{bilinear}(y)\). Performing this multiplication is obtained as follows:

\( W_{bilinear}(x, y) = w_{bilinear}(x) \cdot w_{bilinear}(y) \)
\( W_{bilinear}(x, y) = \begin{cases} 1 - x - y - xy & \text{if } 0 \le |x|, |y| < 1 \\ 0 & \text{if not} \end{cases} \)
