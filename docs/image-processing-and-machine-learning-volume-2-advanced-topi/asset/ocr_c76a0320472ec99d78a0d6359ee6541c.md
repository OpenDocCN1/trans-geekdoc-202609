# 1.5.2 Dilation and Erosion for Intensity Images

The dilation for grayscale images (\(\Theta\)) is defined as the maximum of the sum produced by the values of the reference structure and the region of the image with which it corresponds. That is defined as follows:

```
\((I \oplus H)(x, y) = \max_{(i, j) \in H} \{ I(x+i, y+j) + H(i, j) \}\) (1.18)
```
