# ALGORITHM 4.3 ALGORITHM FOR CALCULATING THE CHAMFER RATIO INDEX

Chamfer ratio index ($I_b(r,s), R_b(i,j)$)

$I_b(r,s)$ binary image of dimension $an_l \times al_l$

$R_b(i,j)$ binary reference pattern of dimension $an_R \times al_R$

+   1: <u>Step 1</u>. The distance transformation $D(r,s)$ is obtained from the image $I_b(r,s)$ (see Algorithm 4.2)
+   
+   2: The number of pixels $K$ of the pattern $R_b(i,j)$ whose value is equal to one is obtained.
+   
+   3: <u>Step 2</u>. Values of the Chamfer ratio index $Q(r,s)$ are calculated.

+   4: for $r \leftarrow 1,2,\dots,al_l - al_R$ do
+       for $s \leftarrow 1,2,\dots,an_l - an_R$ do
+       The value of $Q(r,s)$ is calculated.
+       sumadis=0
+       for $i \leftarrow 1,2,\dots,al_R$ do
+           for $j \leftarrow 1,2,\dots,an_R$ do
+           if($R_b(i,j) = 1$) do
+           sumadis=sumadis+$D(r+i,s+j)$
+           end
+           end
+       end
+       $Q(r,s) = $ sumadis/K
+       end
+   end

+   5: Return the value of $Q$.
