The specific growing mechanism is controlled by the reference structure. This operation is defined in the set notation as follows:

```
\( I \oplus H = \{(x', y') = (x+i, y+j) \mid (x', y') \in P_I, (i, j) \in P_H \} \quad (1.5) \)
```

As indicated by expression 1.5, the set of points that involves the dilation of an image \( I \) and its reference structure \( H \) is defined by all the possible combinations of the pairs of coordinates of the sets of points \( P_I \) and \( P_H \). The dilation operation could also be interpreted as the result of adding a set of pixels with value 1 to the image (\( P_I \)).
