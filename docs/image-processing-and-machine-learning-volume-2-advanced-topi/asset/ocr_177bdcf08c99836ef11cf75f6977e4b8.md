This process can be interpreted as follows: A pixel (x\', y\') resulting from erosion is one whose reference structure centered on this pixel coincides in shape with the content of the image. # 1.2.5 Properties of Dilatation and Erosion

The dilation and erosion operations cannot be considered inverse in the strict sense because it is not possible to completely reconstruct an eroded image through the successive application of dilations. The same applies in the opposite direction. However, they have a close, dual relationship. Since a dilation of the pixels with a value of 1 in an image can be carried out by eroding the background and adding pixels with a value of zero, this can be expressed as follows:

```
\overline{I} \ominus H = \overline{I \oplus H}
(1.7)
```

Dilation is also commutative, so it is valid to formulate:

```
I \oplus H = H \oplus I
(1.8)
```

Therefore, as in convolution, it is possible to interchange the image and the reference structure. From this property, it follows that dilation is also an associative operation. Due to this, it is valid to express the following:

```
(I_1 \oplus I_2) \oplus I_3 = I_1 \oplus (I_2 \oplus I_3)
(1.9)
```

The sequence in which the operations are performed is not relevant. This property is useful since, in this way, the reference structure can be divided into smaller structures in such a way that the speed of the complete operation is faster, as there are a smaller number of operations. Under such conditions, the dilation operation could be expressed as follows:

```
I \oplus H = ((I \oplus H_1) \oplus H_2)
(1.10)
```

where H_1 and H_2 correspond to the reference structures in which H has been divided. Erosion, however, is not commutative, so:

```
I \ominus H \neq H \ominus I
(1.11)
```
