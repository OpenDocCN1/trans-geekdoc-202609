# 3.3.2 Ideal Interpolation

Obviously, the previously seen interpolation alternatives do not produce a good approximation of the function, so it will be necessary to establish others that allow the intermediate values of a discrete signal to be expressed in a better way.

The objective of this section is to analyze the counterpart of the previous simple interpolation methods, that is, to raise the possibility of modeling the best possible way to interpolate a discrete function.

A discrete function, as seen in Chapter 13, has a limited bandwidth whose maximum value is characterized by half the sampling frequency ω_s / 2 with which it was obtained. In the same way, it was investigated in Chapter 13 how these signals, both in the space domain and in the frequency domain, present periodicity. In view of the above, if you only want to take one version of the spectrum F̅(ω), it will suffice to multiply the spectrum (which is periodic) by a rectangular function H(ω) of width ±ω_s / 2 or ±π.
