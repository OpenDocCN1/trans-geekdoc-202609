
# 比特币的真正考验

最后，这将是比特币的真正考验。人们能否轻松地来回交易？如果做不到，就不可能真正存在比特币经济，因为零售商将无法使用它。如果零售商无法使用它，它有什么用？幸运的是，这其实不是个问题。iPhone 有点例外，但许多智能手机都有应用程序（移动钱包）可以读取二维码，并允许你将比特币发送给任何人。你也可以显示你地址的二维码，甚至在钱包里携带一张带有你二维码的卡片，让人们给你发送比特币。根据你拥有的钱包类型，你可以检查比特币是否已收到。

## 需要注意的几点

当你设置钱包时，如果你四处点击一下，会看到一个支付费用以加快交易的选项。这笔钱将可供比特币矿工在处理比特币信息时使用。矿工创建信息区块的工作使系统保持最新和安全。费用是对矿工的激励，确保将你的信息包含在下一个信息区块中，从而“验证”它。短期内，矿工主要通过挖掘新币赚钱（详见“比特币是什么”部分）。长期来看，随着寻找新币变得更难，经济增长，费用将成为矿工继续创建更多区块、维持经济运行的激励。你的钱包默认应设置为支付 0 费用，但如果你想优先处理交易，可以添加费用。你没有义务支付费用，许多处理大量小额交易的组织（如上述淘金者）产生的费用足以让矿工满意。

在钱包中点击交易页面或链接到特定交易时，你会看到关于确认的说明。当你进行交易时，该信息被发送到网络，网络会返回确认，表明该比特币没有双重支付。在离开付款人之前，最好等待几个确认。实际上，像这样面对面欺骗某人并不容易，对罪犯来说也不划算，但也是可能的。

## 关于购买实物比特币

有人问是否可以购买实物比特币。答案既是肯定的也是否定的。比特币本质上是一种数字货币，没有实物形式。然而，有几种方法可以让你实际上手持比特币：

### Casascius Coins
这些是 Mike Caldwell 的创意。他铸造实物硬币，并将比特币的私钥嵌入其中。你可以通过撕开硬币上的全息图来获取私钥，这将清楚地显示硬币已被篡改。Mike 竭力确保他值得信赖。这些是很好的投资策略，因为未来这些硬币可能成为巨大的收藏品。

### 纸钱包
纸钱包意味着你不将比特币信息存储在数字钱包中，而是打印出密钥信息和私钥，妥善保存在保险箱、抽屉或床垫里（如果你喜欢）。这是保护比特币安全的高度推荐且具有成本效益的系统。但请记住，有人可能会偷走它们，或者房子烧毁时它们也会随之消失，无法找回。实际上，这与现金没什么不同。此外，与 Casascius Coins 一样，直到你把它们放回电脑之前，它们并不适合消费。

*   有软件可以让打印纸钱包更容易。`bitcoinpaperwallet.com` 是其中最好的之一，并包含关于如何使用它们的良好教程。
*   比特币实际上不在钱包里，它们仍在网络上。事实上，钱包外部会有一个二维码，允许你随时向钱包发送硬币。
*   钱包的密封部分将包含私钥，没有它你无法访问硬币。因此，只在钱包上放入你想让其不可访问的硬币数量。你无法拿出这个东西取出几个硬币买杯咖啡。相反，把它当作存钱罐。要取钱，你必须砸碎它。虽然可以取出较小金额，但此时钱包的安全性已受损，更容易被盗。最好要么全在，要么全出。
*   使用纸钱包的人通常很注重安全，世界上有许多方法让不法分子黑客攻击你的电脑。`bitcoinpaperwallet.com` 提供了关于如何安全打印钱包的大量好建议。

# 如何不买比特币

简短的历史课：当人们首次基于比特币建立实际业务时，他们使用了商家可用的所有工具。他们通过信用卡和 PayPal 销售。这个商业模式的问题很快被发现：比特币交易除了收款人外，任何人都无法撤销。信用卡和 PayPal 有强有力的买家保护政策，使人们相对容易申请退款。因此，不法分子意识到这一点，开始购买比特币，随后申请退款。由于比特币是非实物产品，通过新的且不被充分理解的技术手段发送，卖家无法对此提出争议。因此，卖家停止接受信用卡和 PayPal。

这对货币来说是个大问题：如何在买卖双方之间转移资金？一些业务出现，如果你汇款给他们，他们会用比特币记账。这些业务通常在阿尔巴尼亚、波兰或俄罗斯提供地址。事实上，许多这样的业务确实有效，论坛上有很多人通过这种方式买到比特币的故事。但这需要大量时间，在此期间买家只能咬指甲等待，不知是否能收到比特币，还是投资打水漂。
