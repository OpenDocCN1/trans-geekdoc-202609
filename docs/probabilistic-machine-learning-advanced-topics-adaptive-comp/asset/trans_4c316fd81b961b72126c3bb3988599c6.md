

## 4.2.6 推断

在 PGM 的语境中，“推断”一词是指在给定一组可见节点 V 的观测值的情况下，计算一组查询节点 Q 的后验，同时对无关的干扰变量 R = {1, ..., NG} \ {Q, V} 进行边缘化：

```
p_\theta(Q|V) = \frac{p_\theta(Q, V)}{p_\theta(V)} = \frac{\sum_R p_\theta(Q, V, R)}{p_\theta(V)}
```

(如果变量是连续的，我们应该将求和替换为积分。) 如果 Q 是单个节点，则 $p_\theta(Q|V)$ 称为节点 Q 的后验边缘分布。

作为示例，假设 V = x 是观测到的声音波序列，Q = z 是相应的未知口语单词集合，而 R = r 是与信号相关的随机“非语义”因素，例如韵律或背景噪声。我们的目标是在给定声音的情况下计算单词的后验，同时对无关因素保持不变：

```
p_\theta(z|x) = \sum_r p_\theta(z, r|x) = \sum_r \frac{p_\theta(z, r, x)}{p_\theta(x)} = \sum_r \frac{p_\theta(z, r, x)}{\sum_{z^\prime, r^\prime} p_\theta(z', r', x)}
```

作为简化，我们可以将随机因素 R “合并”到查询集 Q 中，以定义完整的隐藏变量集 H = Q \cup R。在此情况下，任务简化为

```
p_\theta(h|x) = \frac{p_\theta(h, x)}{p_\theta(x)} = \frac{p_\theta(h, x)}{\sum_{h'} p_\theta(h', x)}
```

推断任务的计算复杂度取决于图的 CI 属性，我们将在第 9 章中讨论。一般来说它是 NP-hard（参见第 9.5.4 节），但对于某些图结构（如链、树和其他稀疏图），可以使用动态规划在多项式时间内高效求解（参见第 9 章）。对于难以处理的情况，我们可以使用近似贝叶斯推断的标准方法，我们将在第 7 章中回顾。

### 4.2.6.1 示例：学生网络中的推断

作为 PGM 中推断的示例，请参考第 4.2.2.2 节中的学生网络。假设我们观察到学生得了 C 级。后验边缘分布如图 4.8a 所示。我们看到低分可能是因为课程难（因为 p(D = Hard|G = C) = 0.63），但更可能是因为学生智力低（因为 p(I = High|G = C) = 0.08）。

然而，现在假设我们还观察到学生的 SAT 得分良好。新的后验边缘分布如图 4.8b 所示。现在学生智力高的后验概率已跳升至 p(I = High|G = C, SAT = Good) = 0.58，因为否则很难解释良好的 SAT 得分。一旦我们相信学生智力高，我们就必须假设课程难来解释 C 级，并且确实我们发现课程难的概率已增加到 p(D = Hard|G = C) = 0.76。（这种观测多种原因之间的负相互作用称为解释掉效应，将在第 4.2.4.2 节中讨论。）

这里我们专注于**参数学习**，即计算后验 \(p(\theta|\mathcal{D}, G)$。（此后我们将不再条件于 \(G$，因为我们假设图结构固定。）

我们可以通过将 \(\theta\) 视为“只是另一个隐藏变量”，然后进行推断来计算参数后验 \(p(\theta|\mathcal{D})$。然而，在机器学习社区中，更常见的是仅计算参数的点估计，例如后验众数 \(\hat{\theta} = \arg\max p(\theta|\mathcal{D})$。这种近似通常是合理的，因为参数依赖于所有数据，而不仅仅是单个数据点，因此比其他隐藏变量更不不确定。

### 4.2.7.1 从完整数据中学习

图 4.9 表示典型监督学习问题的图形模型。我们有 N **局部变量**，$\boldsymbol{x}_n$ 和 $\boldsymbol{y}_n$，以及 2 **全局变量**，对应参数，跨数据样本共享。局部变量被观测到（在训练集中），因此由实心（阴影）节点表示。全局变量未被观测，因此由空（未阴影）节点表示。（该模型表示生成式分类器，因此边是从 $y_n$ 到 $\boldsymbol{x}_n$；如果我们拟合判别式分类器，边将是从 $\boldsymbol{x}_n$ 到 $y_n$，并且不会有 $\boldsymbol{\theta}_y$ 先验节点。）

根据图 4.9 的 CI 属性，联合分布分解为每个节点的一项乘积：

```
p(\boldsymbol{\theta}, \mathcal{D}) = p(\boldsymbol{\theta}_x)p(\boldsymbol{\theta}_y) \left[ \prod_{n=1}^N p(y_n|\boldsymbol{\theta}_y)p(\boldsymbol{x}_n|y_n,\boldsymbol{\theta}_x) \right]
```

```
= \left[ p(\boldsymbol{\theta}_y) \prod_{n=1}^N p(y_n|\boldsymbol{\theta}_y) \right] \left[ p(\boldsymbol{\theta}_x) \prod_{n=1}^N p(\boldsymbol{x}_n|y_n,\boldsymbol{\theta}_x) \right]
```

```
= [p(\boldsymbol{\theta}_y)p(\mathcal{D}_y|\boldsymbol{\theta}_y)] [p(\boldsymbol{\theta}_x)p(\mathcal{D}_x|\boldsymbol{\theta}_x)]
```

where $\mathcal{D}_y = \{y_n\}_{n=1}^N$ 是足以估计 $\boldsymbol{\theta}_y$ 的数据，而 $\mathcal{D}_x = \{\boldsymbol{x}_n, y_n\}_{n=1}^N$ 是足以估计 $\boldsymbol{\theta}_x$ 的数据。

从公式 (4.40) 可以看出，先验、似然和后验均**分解**或根据图结构分解。因此，我们可以独立计算每个参数的后验。一般来说，我们有

```
p(\boldsymbol{\theta}, \mathcal{D}) = \prod_{i=1}^{N_G} p(\boldsymbol{\theta}_i)p(\mathcal{D}_i|\boldsymbol{\theta}_i)
```

因此似然和先验分解，进而后验也分解。如果我们只想计算 MLE，可以计算

```
\hat{\boldsymbol{\theta}} = \arg \max_{\boldsymbol{\theta}} \prod_{i=1}^{N_G} p(\mathcal{D}_i|\boldsymbol{\theta}_i)
```

我们可以对每个节点独立求解，如第 4.2.7.2 节所示。

### 4.2.7.2 示例：计算 CPT 的 MLE

在本节中，我们说明如何计算表格 CPD 的 MLE。似然由以下多项式乘积给出：

```
p(\mathcal{D}|\boldsymbol{\theta}) = \prod_{n=1}^N \prod_{i=1}^{N_G} p(x_{ni}|\boldsymbol{x}_{n,\text{pa}(i)}, \boldsymbol{\theta}_i)
```

```
= \prod_{n=1}^N \prod_{i=1}^{N_G} \prod_{j=1}^{J_i} \prod_{k=1}^{K_i} \theta_{ijk}^{\mathbb{I}[(x_{ni}=k, \boldsymbol{x}_{n,\text{pa}(i)}=j)]}
```

where

\(\theta_{ijk} \triangleq p(x_i = k | \mathbf{x}_{\text{pa}(i)} = j)\)
(4.45)

让我们定义节点 $i$ 的充分统计量为 $N_{ijk}$，即节点 $i$ 处于状态 $k$ 且其父节点处于联合状态 $j$ 的次数：

\(N_{ijk} \triangleq \sum_{n=1}^N \mathbb{I} (x_{n,i} = k, x_{n,\text{pa}(i)} = j)\)
(4.46)

多项式的 MLE 由归一化经验频率给出：

\(\hat{\theta}_{ijk} = \frac{N_{ijk}}{\sum_{k'} N_{ijk'}}\)
(4.47)

例如，请参考第 4.2.2.2 节中的学生网络。在表 4.2 中，我们展示了一些示例训练数据。例如，表中的最后一行编码了一个聪明的学生（$I = 1$），上了一门难的课（$D = 1$），得了 C（$G = 2$），但在 SAT 中表现良好（$S = 1$）并获得了良好的推荐信（$L = 1$）。

在表 4.3 中，我们列出了节点 $i = G$ 及其父节点 $(I, D)$ 的充分统计量 $N_{ijk}$ 和 MLE $\hat{\theta}_{ijk}$。类似过程可用于其他节点。因此，我们看到用表格 CPD 拟合 DPGM 归结为一个简单的计数问题。
