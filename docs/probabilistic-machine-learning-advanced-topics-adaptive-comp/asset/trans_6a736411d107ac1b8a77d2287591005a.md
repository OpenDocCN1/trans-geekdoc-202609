图 19.27: (a) 当输入维度 n 较大且决策边界局部呈线性时，即使随机噪声的误差率很小，也意味着存在小型对抗扰动。在此，$d(x_0, E)$ 表示从干净输入 $x_0$ 到对抗样本 (A) 的距离，而到随机样本 $N(0; \sigma^2 I) (B)$ 的距离约为 $\sigma \sqrt{n}$。当 $n \to \infty$ 时，$d(x_0, A)$ 与 $d(x_0, B)$ 的比值趋于 0。 (b) 通过三个点（干净图像（黑色）、对抗样本（红色）和随机噪声中的误差（蓝色））的 InceptionV3 决策边界的一个 2d 切片。对抗样本和噪声中的误差位于误差集的同一区域，该区域被错误分类为“miniature poodle”，与 a 中的半空间非常相似。特感谢 Justin Gilmer 允许使用。

这两个量由以下公式确定

$$d(x_0, E) = -\sigma \Phi^{-1}(\mu)$$ (19.52)

其中 $\Phi^{-1}$ 表示高斯分布的逆累积分布函数（cdf）。当输入维度较大时，此距离将显著小于到随机采样的带噪声图像 $x_0 + \delta$ 的距离（其中 $\delta \sim N(0, \sigma I)$），因为噪声项以高概率具有范数 $||\delta||_2 \approx \sigma \sqrt{d}$。举个具体示例，考虑 ImageNet 数据集，其中 $d = 224 \times 224 \times 3$，并假设我们设置 $\sigma = .2$。那么，如果噪声中的误差率仅为 $\mu = .01$，方程 19.52 将暗示 $d(x_0, E) = .5$。因此，到对抗样本的距离将比到典型带噪声图像的距离（约为 $\sigma \sqrt{d} \approx 77.6$）近 100 多倍。小体积误差集接近数据分布 $p(x)$ 中大多数点的这种现象称为 **浓度现象**，是许多高维数据分布的共同属性 [MDM19; Gil+18b]。

总结来说，虽然对抗样本的存在常被讨论为一种意外现象，但机器学习分类器中最坏情况错误的存在并无特殊之处——只要存在错误，它们就会始终存在。

## 20 生成模型：概览

### 20.1 简介

**生成模型**是一个联合概率分布 \(p(\boldsymbol{x})\)，其中 \(\boldsymbol{x} \in \mathcal{X}\)。在某些情况下，模型可以基于输入或协变量 \(\boldsymbol{c} \in \mathcal{C}\) 进行条件化，从而产生形式为 \(p(\boldsymbol{x}|\boldsymbol{c})\) 的 **条件生成模型**。

生成模型有多种类型。我们在第 20.2 节中简要总结，并在后续章节中深入探讨。另请参阅 [Tom22]，这是关于此主题的最近著作，内容更深入。

### 20.2 生成模型的类型

生成模型有多种类型，其中一些我们列在表 20.1 中。从高层次来看，我们可以区分 **深度生成模型** (DGM) —— 它使用深度神经网络从单个隐向量 \(\boldsymbol{z}\) 到观测数据 \(\boldsymbol{x}\) 学习复杂的映射 —— 与更“传统”的 **概率图形模型** (PGM) —— 它使用更简单、常为线性的映射，将一组互连的隐变量 \(\boldsymbol{z}_1, \dots, \boldsymbol{z}_L\) 映射到观测变量 \(\boldsymbol{x}_1, \dots, \boldsymbol{x}_D\)。当然，许多混合模型也是可能的。例如，PGMs 可以使用神经网络，DGMs 可以使用结构化状态空间。我们在第 4 章中概括讨论 PGMs，并在第 28 章、第 29 章、第 30 章中给出示例。在本书的这一部分中，我们主要关注 DGMs。

DGM 的主要类型包括：**变分自编码器** (VAE)、**自回归模型** (ARM)、**标准化流**、**扩散模型**、**基于能量的模型** (EBM) 和 **生成对抗网络** (GAN)。我们可以按照以下标准对这些模型进行分类（可视化总结见图 20.1）：

- 密度：模型是否支持对概率密度函数 \(p(\boldsymbol{x})\) 进行逐点求值，如果支持，是快还是慢，精确还是近似或边界等？对于 **隐式模型**，如 GANs，没有定义明确的密度 \(p(\boldsymbol{x})\)。对于其他模型，我们只能计算密度的下界（VAEs）或密度的近似值（EBMs, UGMs）。

- 采样：模型是否支持生成新样本，\(\boldsymbol{x} \sim p(\boldsymbol{x})\)，如果支持，是快还是慢，精确还是近似？有向 PGMs、VAEs 和 GANs 均支持快速采样。然而，无向 PGMs、EBMs、ARM、扩散和流在采样时较慢。

- 训练：参数估计使用什么方法？对于某些模型（如 AR、流和有向 PGMs），我们可以进行精确最大似然估计（MLE），虽然

- 隐变量：模型是否使用隐向量 z 来生成 x，如果使用，它是否与 x 大小相同，或者是一种可能的压缩表示？例如，ARMs 不使用隐变量；流和扩散使用隐变量，但它们不是压缩的。图形模型（包括 EBMs）可能使用也可能不使用隐变量。

- 架构：我们应该使用什么类型的神经网络，是否存在限制？对于流，我们受限于使用每层都具有可计算雅可比矩阵的可逆神经网络。对于 EBMs，我们可以使用任何喜欢的模型。其他模型有不同的限制。

### 20.3 生成建模的目标

我们可以使用生成模型完成多种不同类型的任务，如下面所述。

### 20.3.1 生成数据

生成模型的主要目标之一是生成（创建）新的数据样本。这有时被称为生成式 AI（有关最近的调查，参见 [GBGM23]）。例如，如果我们将模型 p(x) 拟合到人脸图像上，我们可以从中采样新的人脸，如图 25.10 所示。类似方法可用于创建文本、音频等样本。当该技术被滥用以制作虚假内容时，它们被称为深度伪造（参见 [Ngu+19]）。生成模型还可用于为训练判别模型创建合成数据（参见 [Wil+20; Jor+22]）。

为了控制生成的内容，使用形式为 p(x|c) 的条件生成模型很有用。以下是一些示例：

- c = 文本提示，x = 图像。这是一个文本到图像模型（示例见图 20.2、图 20.3 和图 22.6）。

- c = 图像，x = 文本。这是一个图像到文本模型，可用于图像字幕生成。

- c = 图像，x = 图像。这是一个图像到图像模型，可用于图像着色、修复、去裁剪、JPEG 伪影修复等。示例见图 20.4。

- c = 声音序列，x = 单词序列。这是一个语音到文本模型，可用于自动语音识别（ASR）。

- c = 英语单词序列，x = 法语单词序列。这是一个序列到序列模型，可用于机器翻译。
