```
x(t + \Delta t) = x(t) + f(x(t), t)\Delta t + g(t)\sqrt{\Delta t}\mathcal{N}(\mathbf{0}, \mathbf{I})
```

我们可以看到，t = 0 时（左侧）的数据分布如何逐渐转换为 t = 1 时（右侧）的纯噪声分布。

在 [Son+21b] 中，他们表明，在 T 趋向于无穷的极限下，DDPMs 对应的 SDE 由以下给出：

```
dx = -\frac{1}{2}\beta(t)xdt + \sqrt{\beta(t)}d\omega
```

其中 \beta(t/T) = T\beta_t。这里漂移项与 -x 成正比，这鼓励过程返回 0。因此，DDPM 对应一个 **方差保持** 过程。相比之下，SGMs 对应的 SDE 由以下给出：

```
dx = \sqrt{\frac{d|\sigma(t)|^2}{dt}}d\omega
```

其中 \sigma(t/T) = \sigma_t。这个 SDE 有零漂移，因此对应一个 **方差爆炸** 过程。

## 25.4.2 前向扩散 ODE

与其在每个步骤添加高斯噪声，不如只需采样初始状态，然后让它随时间根据以下 **普通微分方程** 或 **ODE** 确定性地演变：

```
dx = \left[ f(x, t) - \frac{1}{2}g(t)^2 \nabla_x \log p_t(x) \right] dt
```

```
x(t) = x(0) + \int_0^t h(x, \tau) d\tau
```

## 25.4.3 反向扩散 SDE

要从此模型生成样本，我们需要能够反转 SDE。在一个显著的结果中，[And82] 表明方程 (25.43) 形式的任何前向 SDE 都可以反转以获得以下 **逆时 SDE**：

```
dx = [f(x, t) - g(t)^2 \nabla_x \log q_t(x)] dt + g(t) d\overline{w}
```

其中 $\overline{w}$ 是时间向后流时的标准 Wiener 过程，dt 是一个无穷小负时间步，$\nabla_x \log q_t(x)$ 是得分函数。

在 DDPM 的情况下，反向 SDE 具有以下形式：

```
dx_t = \left[ -\frac{1}{2}\beta(t)x_t - \beta(t)\nabla_{x_t} \log q_t(x_t) \right] dt + \sqrt{\beta(t)} d\overline{w}_t
```

为了估计得分函数，我们可以使用第 25.3 节讨论过的去噪得分匹配，以得到

```
\nabla_{x_t} \log q_t(x_t) \approx s_\theta(x_t, t)
```

（在实践中，建议使用方差减小技术，例如重要性采样，如 [Son+21a] 中讨论。）SDE 变为

```
dx_t = -\frac{1}{2}\beta(t) [x_t + 2s_\theta(x_t, t)] dt + \sqrt{\beta(t)} d\overline{w}_t
```


## 25.4.4 反向扩散 ODE

基于第 25.4.2 节的结果，我们可以从方程 (25.49) 中的逆时 SDE 推导出概率流 ODE 以得到

```
\(d\boldsymbol{x}_t = \left[f(\boldsymbol{x}, t) - \frac{1}{2}g(t)^2 \boldsymbol{s}_\theta(\boldsymbol{x}_t, t)\right] dt\)
```

如果我们设置 \(f(\boldsymbol{x}, t) = -\frac{1}{2}\beta(t)\) 和 \(g(t) = \sqrt{\beta(t)}\)，如 DDPM 中所述，这将变为

```
\(d\boldsymbol{x}_t = -\frac{1}{2}\beta(t) [\boldsymbol{x}_t + \boldsymbol{s}_\theta(\boldsymbol{x}_t, t)] dt\)
```

请参见图 25.7b 以示说明。求解此 ODE 的一种简单方法是使用 **欧拉方法**：

```
\(\boldsymbol{x}_{t-1} = \boldsymbol{x}_t + \frac{1}{2}\beta(t) [\boldsymbol{x}_t + \boldsymbol{s}_\theta(\boldsymbol{x}_t, t)] \Delta t\)
```

然而，在实践中，使用更高阶的 ODE 求解器（如 **Heun 方法** [Kar+22]）可以获得更好的结果。

这个模型是 **神经 ODE** 的特例，也称为 **连续标准化流** （参见第 23.2.6 节）。因此，我们可以推导出精确的对数边缘似然。但是，与其直接最大化它（这很昂贵），不如使用得分匹配来拟合模型。

确定性 ODE 方法的另一个优势是它保证生成模型是 **可识别** 的。要看到这一点，请注意，ODE（在前向和反向两个方向上）是确定性的，并且由得分函数唯一确定。如果架构足够灵活，并且有足够的数据，那么得分匹配将恢复数据生成过程的真实得分函数。因此，训练后，给定的数据点将映射到潜在空间中的唯一点，无论模型架构或初始化如何（见图 25.8）。

## 25.4.5 SDE 和 ODE 方法的比较

在第 25.4.3 节中，我们将反向扩散过程描述为 SDE，在第 25.4.4 节中，我们将其描述为 ODE。我们可以通过将方程 (25.49) 中的 SDE 改写为以下形式，来看到这些方法之间的联系：

```
d\boldsymbol{x}_t = -\frac{1}{2}\beta(t)[\boldsymbol{x}_t + \boldsymbol{s}_\theta(\boldsymbol{x}_t, t)]dt - \frac{1}{2}\beta(t)\boldsymbol{s}_\theta(\boldsymbol{x}_t, t)dt + \sqrt{\beta(t)}d\overline{\boldsymbol{w}}_t \quad (25.57)
\underbrace{...}_{probability flow ODE} \quad \underbrace{...}_{Langevin diffusion SDE}
```

连续噪声注入可以补偿 ODE 项数值积分引入的误差。因此，生成的样本通常看起来更好。但是，ODE 方法可能更快。幸运的是，可以结合这些技术，如 [Kar+22] 所提议。基本思想在图 25.9 中有说明：我们在使用 ODE 求解器执行确定性步骤，然后向结果添加少量噪声之间交替进行。这可以重复若干步骤。（我们在第 25.5 节中讨论减少所需步骤数量的方法。）
