M modalities. We assume they are conditionally independent given the latent code, and hence the generative model has the form

$p_\theta(x_1, ..., x_M, z) = p(z) \prod_{m=1}^M p_\theta(x_m|z)$ (21.40)

where we treat $p(z)$ as a fixed prior. See Figure 21.5(a) for an illustration.

The standard ELBO is given by

$\mathbb{L}(\theta, \phi|\mathbf{X}) = \mathbb{E}_{q_\phi(z|\mathbf{X})} \left[ \sum_m \log p_\theta(x_m|z) \right] - D_{\text{KL}} (q_\phi(z|\mathbf{X}) \| p(z))$ (21.41)

where $\mathbf{X} = (x_1, ..., x_M)$ is the observed data. However, the different likelihood terms $p(x_m|z)$ may have different dynamic ranges (e.g., Gaussian pdf for pixels, and categorical pmf for text), so we introduce weight terms $\lambda_m \ge 0$ for each likelihood. In addition, let $\beta \ge 0$ control the amount of KL regularization. This gives us a weighted version of the ELBO, as follows:

$\mathbb{L}(\theta, \phi|\mathbf{X}) = \mathbb{E}_{q_\phi(z|\mathbf{X})} \left[ \sum_m \lambda_m \log p_\theta(x_m|z) \right] - \beta D_{\text{KL}} (q_\phi(z|\mathbf{X}) \| p(z))$ (21.42)

Often we don't have a lot of paired (aligned) data from all M modalities. For example, we may have a lot of images (modality 1), and a lot of text (modality 2), but very few (image, text) pairs. So it is useful to generalize the loss so it fits the marginal distributions of subsets of the features. Let $O_m = 1$ if modality $m$ is observed (i.e., $x_m$ is known), and let $O_m = 0$ if it is missing or unobserved. Let $\mathbf{X} = \{x_m : O_m = 1\}$ be the visible features. We now use the following objective:

$\mathbb{L}(\theta, \phi|\mathbf{X}) = \mathbb{E}_{q_\phi(z|\mathbf{X})} \left[ \sum_{m: O_m=1} \lambda_m \log p_\theta(x_m|z) \right] - \beta D_{\text{KL}} (q_\phi(z|\mathbf{X}) \| p(z))$ (21.43)
