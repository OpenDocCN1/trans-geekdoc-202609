## 28.6 独立成分分析（ICA）

请考虑以下情景。你身处一个拥挤的房间，许多人在说话。你的耳朵本质上充当两个麦克风，正在收听房间内不同语音信号的线性组合。你的目标是将混合信号去卷积为其组成部分。这被称为鸡尾酒会问题，或盲源分离（BSS）问题，其中“盲”意味着我们对信号源“一无所知”。除了声学信号处理的明显应用外，此问题还出现在分析 EEG 和 MEG 信号、金融数据以及任何其他（不一定是时序的）数据集中，在这些数据集中，隐源或因子以线性方式混合在一起。有关示例，请参见图 28.32。

### 28.6.1 无噪声 ICA 模型

我们可以将问题形式化如下。设 \(x_n \in \mathbb{R}^D\) 为“时刻” \(n\) 的观测响应向量，其中 \(D\) 是传感器/麦克风的数量。设 \(z_n \in \mathbb{R}^D\) 为时刻 \(n\) 的源信号隐藏向量，其维度与观测信号相同。我们假设

```
\(x_n = A z_n\) \tag{28.142}
```

其中 **A** 是一个可逆的 \(D \times D\) 矩阵，称为混合矩阵或生成权重。

先验的形式为 \(p(z_n) = \prod_{j=1}^D p_j(z_j)\)。通常我们假设这是一个稀疏先验，因此在任一时刻只有部分信号处于活跃状态（关于此模型先验的进一步讨论，请参见第 28.6.2 节）。该模型称为**独立成分分析**或 **ICA**，因为我们假设每个观测 \(\mathbf{x}_n\) 都是由源 \(\mathbf{z}_n\) 表示的独立成分的线性组合，即，

```
\( x_{nj} = \sum_i A_{ij} z_{ni} \) (28.143)
```

我们的目标是推断源信号，\(p(\mathbf{z}_n | \mathbf{x}_n, \mathbf{A})\)。由于模型是无噪声的，我们有

```
\( p(\mathbf{z}_n | \mathbf{x}_n, \mathbf{A}) = \delta(\mathbf{z}_n - \mathbf{B}\mathbf{x}_n) \) (28.144)
```

其中 \(\mathbf{B} = \mathbf{A}^{-1}\) 是**识别权重**。（我们将在 28.6.3 节中讨论如何估计这些权重。）

### 28.6.2 非高斯先验的必要性

由于 \(\mathbf{x} = \mathbf{Az}\)，我们有 \(\mathbb{E}[\mathbf{x}] = \mathbf{A}\mathbb{E}[\mathbf{z}]\) 和 \(\text{Cov}[\mathbf{x}] = \text{Cov}[\mathbf{Az}] = \mathbf{A}\text{Cov}[\mathbf{z}]\mathbf{A}^\mathsf{T}\)。不失一般性，我们可以假设 \(\mathbb{E}[\mathbf{z}] = \mathbf{0}\)，因为我们始终可以对数据进行中心化。同样，我们可以假设 \(\text{Cov}[\mathbf{z}] = \mathbf{I}\)，因为 \(\mathbf{A}\mathbf{A}^\mathsf{T}\) 可以捕捉 \(\mathbf{x}\) 中的任何相关性。因此，\(\mathbf{z}\) 是一组 \(D\) 个单位方差、不相关的变量，如同因子分析（第 28.3.1 节）中一样。

图 28.33：ICA 和 PCA 应用于 100 个服从均匀分布的 2 维源信号 iid 样本的示意图。由 ica_demo_uniform.ipynb 生成。

然而，这不足以唯一地确定 **A** 进而确定 **z**，正如我们在 28.3.1.6 节中解释的那样。因此，我们需要超越不相关先验，施加独立且非高斯的先验。为了说明这一点，假设我们有两个服从均匀分布的独立源，如图 28.33(a) 所示。现在假设我们有以下混合矩阵

**A** = 0.3 \(\begin{pmatrix} 2 & 3 \\ 2 & 1 \end{pmatrix}\) (28.145)

然后我们观察到图 28.33(b) 中显示的数据（假设无噪声）。全秩 PCA 模型（其中 _K_ = _D_）等价于 ICA，只不过它对 **z** 使用分解高斯先验。使用 PCA 的结果如图 28.33(c) 所示。这对应于数据的**白化**或**球形化**，其中 Cov [**z**] = **I**。为了唯一地恢复源，我们需要执行额外的旋转。问题是，对称高斯后验中没有信息告诉我们应旋转哪个角度。从某种意义上说，PCA 解决了问题的“一半”，因为它识别了线性子空间；ICA 所要做的就是识别合适的旋转。为此，ICA 使用独立但非高斯的先验。结果如图 28.33(d) 所示。这表明 ICA 可以恢复源变量，仅在索引置换和可能的符号变化上有所不同。

我们通常使用超高斯分布作为先验，意味着它具有重尾；这有助于可识别性。一种选择是使用 Laplace 先验。对于均值为 0 且方差为 1 的情况，其对数概率密度函数为

log _p_(_z_) = -√2|_z_| - log(√2) (28.146)

然而，由于 Laplace 先验在原点处不可导，在 ICA 中更常使用第 15.4.1 节讨论的逻辑分布。如果我们将均值设为 0，方差设为 1，则有 \(\mu = 0\) 和 \(s = \frac{\sqrt{3}}{\pi}\)，因此对数 pdf 变为以下形式（利用关系式 sech(_x_) = 1/cosh(_x_)）：

log _p_(_z_) = log sech<sup>2</sup>(_z_/2_s_) - log(4_s_) = -2 log cosh(\(\frac{\pi}{2\sqrt{3}}z\)) - log \(\frac{4\sqrt{3}}{\pi}\) (28.147)

### 28.6.3 最大似然估计

在本节中，我们讨论如何使用最大似然法估计混合矩阵 **A**。根据变量变换公式，我们有

_p<sub>x</sub>_(**_x_**) = _p<sub>z</sub>_(**_z_**) |det(**A**<sup>-1</sup>)| = _p<sub>z</sub>_(**Bx**) |det(**B**)| (28.148)

其中 **B** = **A**<sup>-1</sup>。我们可以先通过计算 \(\tilde{\mathbf{x}} = \mathbf{S}^{-\frac{1}{2}}\mathbf{U}^\mathsf{T}(\mathbf{x} - \bar{\mathbf{x}})\) 对数据进行白化来简化问题，其中 \(\unknown = \mathbf{U}\mathbf{S}\mathbf{U}^\mathsf{T}\) 是协方差矩阵的 SVD。现在我们可以用正交矩阵 **V** 替换一般矩阵 **B**。因此似然变为

\(p_x(\tilde{\mathbf{x}}) = p_z(\mathbf{V}\tilde{\mathbf{x}}) \, |\det(\mathbf{V})|\) (28.149)

由于我们将 **V** 约束为正交矩阵，| det(**V**) | 项是常数，因此可以舍弃。此外，为简洁起见，我们去掉波浪号。因此，平均负对数似然可以写为

\(\text{NLL}(\mathbf{V}) = -\frac{1}{N} \log p(\mathbf{X}|\mathbf{V}) = -\frac{1}{N} \sum_{j=1}^L \sum_{n=1}^N \log p_j(\mathbf{v}_j^\mathsf{T}\mathbf{x}_n)\) (28.150)

其中 \(\mathbf{v}_j\) 是 \(\mathbf{V}\) 的第 \(j\) 行，且先验是分解的，因此 \(p(\mathbf{z}) = \prod_j p_j(z_j)\)。我们还可以用经验分布下的期望替换对 \(n\) 的求和，以得到以下目标

```
\(\text{NLL}(\mathbf{V}) = \sum_j \mathbb{E} [G_j(z_j)]\)
```

其中 \(z_j = \mathbf{v}_j^\text{T}\mathbf{x}\) 且 \(G_j(z_j) \triangleq -\log p_j(z_j)\)。我们希望在 \(\mathbf{V}\) 是正交矩阵的约束下，最小化这个（非凸）目标。

推导一种（投影）梯度下降算法来拟合此模型是直接的。（有关 JAX 代码，请参见 https://github.com/tuananhle7/ica）。还可以推导一种遵循自然梯度的更快算法；详情请参见例如 [Mac03, ch 34]。然而，最流行的方法是使用一种称为**快速 ICA** [H000] 的近似牛顿法。这用于生成图 28.32。

### 28.6.4 MLE 的替代方法

在本节中，我们讨论多年来为 ICA 提出的各种替代估计器。我们将展示它们等价于 MLE。然而，它们为问题带来了有趣的视角。

### 28.6.4.1 最大化非高斯性

ICA 的早期方法之一是寻找一个矩阵 \(\mathbf{V}\)，使得分布 \(\mathbf{z} = \mathbf{V}\mathbf{x}\) 尽可能远离高斯分布。（统计学中有一种相关方法称为**投影追踪** [FT74]。）非高斯性的一种度量是峰度，但这可能对异常值敏感。另一种度量是**负熵**，定义为

```
\(\text{negentropy}(z) \triangleq \mathbb{H} (\mathcal{N}(\mu, \sigma^2)) - \mathbb{H} (z)\)
```

其中 \(\mu = \mathbb{E}[z]\) 且 \(\sigma^2 = \mathbb{V}[z]\)。由于高斯分布是（固定方差下）最大熵分布，该度量总是非负的，且对于高度非高斯的分布会取较大值。

我们可以将目标定义为最大化

```
\(J(\mathbf{V}) = \sum_j \text{negentropy}(z_j) = \sum_j \mathbb{H} (\mathcal{N}(\mu_j, \sigma_j^2)) - \mathbb{H} (z_j)\)
```

其中 \(\mathbf{z} = \mathbf{V}\mathbf{x}\)。由于我们假设 \(\mathbb{E}[\mathbf{z}] = \mathbf{0}\) 且 \(\text{Cov}[\mathbf{z}] = \mathbf{I}\)，第一项是常数。因此，

```
\(J(\mathbf{V}) = \sum_j - \mathbb{H} (z_j) + \text{const} = \sum_j \mathbb{E} [\log p(z_j)] + \text{const}\)
```

这（除了符号变化和无关常数外）等于公式 (28.151) 中的对数似然。
