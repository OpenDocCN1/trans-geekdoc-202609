### 18.2.1.4 周期核

创建一维周期随机函数的一种方法是将 x 映射到二维空间 u(x) = (cos(x), sin(x))，然后在 u 空间中使用 SE 核：

> $$\mathcal{K}(x, x') = \exp \left( - \frac{2 \sin^2((x - x')/2)}{\ell^2} \right)$$ (18.17)

这是因为 $(\cos(x) - \cos(x'))^2 + (\sin(x) - \sin(x'))^2 = 4 \sin^2((x - x')/2)$。我们可以通过指定周期 $p$ 来推广此方法，从而得到周期核，也称为 exp-sine-squared 核：

> $$\mathcal{K}_{per}(r; \ell, p) = \exp \left( - \frac{2}{\ell^2} \sin^2(\pi \frac{r}{p}) \right)$$ (18.18)

其中 $p$ 是周期，$\ell$ 是长度尺度。有关可视化，请参见图 18.3(d-e) 和图 18.4(d-e)。

相关的核是余弦核：

> $$\mathcal{K}(r; p) = \cos \left( 2\pi \frac{r}{p} \right)$$ (18.19)

### 18.2.1.5 理性二次核

我们定义理性二次核为

$$\mathcal{K}_{RQ}(r; \ell, \alpha) = \left(1 + \frac{r^2}{2\alpha \ell^2}\right)^{-\alpha}$$ (18.20)

我们认识到这与 Student $t$ 密度成正比。因此，它可以解释为不同特征长度的 SE 核的尺度混合。特别是，令 $\tau = 1/\ell^2$，并假设 $\tau \sim \text{Ga}(\alpha, \ell^2)$。则可以证明

$$\mathcal{K}_{RQ}(r) = \int p(\tau|\alpha, \ell^2)\mathcal{K}_{SE}(r|\tau)d\tau$$ (18.21)

当 $\alpha \to \infty$ 时，这将退化为 SE 核。
有关可视化，请参见图 18.3(g) 和图 18.4(g)。

### 18.2.1.6 来自谱密度的核

考虑满足 $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = \mathcal{K}(\boldsymbol{\delta})$ 的平稳核的情况，其中 $\boldsymbol{\delta} = \boldsymbol{x} - \boldsymbol{x}'$，$\boldsymbol{x}, \boldsymbol{x}' \in \mathbb{R}^d$。进一步假设 $\mathcal{K}(\boldsymbol{\delta})$ 是正定的。在这种情况下，Bochner 定理告诉我们，可以通过其傅里叶变换来表示 $\mathcal{K}(\boldsymbol{\delta})$：

$$\mathcal{K}(\boldsymbol{\delta}) = \int_{\mathbb{R}^d} p(\boldsymbol{\omega}) e^{j \boldsymbol{\omega}^T \boldsymbol{\delta}} d\boldsymbol{\omega}$$ (18.22)

其中 $j = \sqrt{-1}$，$e^{j\theta} = \cos(\theta) + j \sin(\theta)$，$\boldsymbol{\omega}$ 是频率，$p(\boldsymbol{\omega})$ 是谱密度（详情见 [SS19, p93, p253]）。

我们可以轻松地从谱密度推导并获得对多个核的直觉。如果对 RBF 核进行傅里叶变换，我们会得到谱密度 $p(\boldsymbol{\omega}) = \sqrt{2\pi \ell^2} \exp(-2\pi^2 \boldsymbol{\omega}^2 \ell^2)$。因此，谱密度也是高斯分布，但其带宽与长度尺度超参数 $\ell$ 成反比。也就是说，随着 $\ell$ 变大，谱密度会坍缩为一点质量。这个结果很直观：当我们增加长度尺度时，模型会将远距离的点视为相关，变得非常平滑且缓慢变化，因此属于低频。一般而言，由于高斯分布的尾部相对较轻，我们可以看到 RBF 核通常不会支持高频解。

我们可以改用 Student $t$ 谱密度，它具有重尾，将为更高频率提供更大的支持。对该谱密度进行逆傅里叶变换，我们可以恢复 Matérn 核，其中自由度 $\nu$ 对应于谱密度中的自由度。确实，$\nu$ 越小，使用 Matérn 核对数据拟合的平滑度就越低，频率就越高。

我们还可以通过将谱密度建模为高斯分布的尺度-位置混合并进行逆傅里叶变换，来推导谱混合核 [WA13]。由于高斯分布的尺度-位置混合在分布集合中是稠密的，因此可以近似任何谱密度，该核可以以任意精度近似任何平稳核。因此，谱混合核构成了一种强大的核学习方法，我们将在 18.6.5 节中进一步讨论。

## 18.2.2 非平稳核

平稳核假设两个输入之间的相似度量与其位置无关，即 $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}')$ 仅取决于 $\boldsymbol{r} = \boldsymbol{x} - \boldsymbol{x}'$。一个 **非平稳核** 放宽了这一假设。这对于多种问题很有用，例如环境建模（例如，[GSR12; Pat+22]），其中位置之间的相关性可能会根据环境中的隐性因素而变化。

### 18.2.2.1 多项式核

一种简单的非平稳核形式是阶数为 $M$ 的 **多项式核**（也称为 **点积核**），定义为

$\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = (\boldsymbol{x}^\top \boldsymbol{x}')^M$ (18.23)

这包含了所有阶数为 $M$ 的一项式。例如，如果 $M=2$，我们得到 **二次核**；在二维中，这变为

$(\boldsymbol{x}^\top \boldsymbol{x}')^2 = (x_1 x'_1 + x_2 x'_2)^2 = (x_1 x'_1)^2 + (x_2 x_2)^2 + 2(x_1 x'_1)(x_2 x'_2)$ (18.24)

我们可以通过使用 **非齐次多项式核** 将其推广到包含所有最高次数为 $M$ 的项

$\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = (\boldsymbol{x}^\top \boldsymbol{x}' + c)^M$ (18.25)

例如，如果 $M=2$ 且输入为二维，则有

$(\boldsymbol{x}^\top \boldsymbol{x}' + 1)^2 = (x_1 x'_1)^2 + (x_1 x'_1)(x_2 x'_2) + (x_1 x'_1) + (x_1 x'_1)(x_2 x'_2) + (x_2 x'_2)^2 + (x_2 x'_2) + (x_1 x'_1) + (x_2 x'_2) + 1$ (18.26)

### 18.2.2.2 Gibbs 核

考虑一个 RBF 核，其中长度尺度超参数和信号方差超参数都依赖于输入；这称为 **Gibbs 核** [Gib97]，定义为

$\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = \sigma(\boldsymbol{x})\sigma(\boldsymbol{x}')\sqrt{\frac{2\ell(\boldsymbol{x})\ell(\boldsymbol{x}')}{\ell(\boldsymbol{x})^2 + \ell(\boldsymbol{x}')^2}} \exp \left( - \frac{||\boldsymbol{x} - \boldsymbol{x}'||^2}{\ell(\boldsymbol{x})^2 + \ell(\boldsymbol{x}')^2} \right)$ (18.27)

如果 $\ell(\boldsymbol{x})$ 和 $\sigma(\boldsymbol{x})$ 是常数，则这将退化为标准 RBF 核。我们可以通过使用另一个 GP 来对这些核参数对输入的功能依赖性进行建模（例如，[Hei+16]）。

### 18.2.2.3 其他非平稳核

诱导非平稳性的其他方法包括使用神经网络核（18.7.1 节）、非平稳谱核 [RHK17] 或深度 GP（18.7.3 节）。

## 18.2.3 非向量（结构化）输入的核

当输入是结构化对象（如字符串和图）时，核特别有用，因为对变长输入进行“特征化”通常很困难。例如，我们可以定义一个 **字符串核**，它根据字符串共有的 n-gram 数量来比较字符串 [Lod+02; BC17]。

我们还可以在图上定义核 [KJM19]。例如，**随机游走核** 概念上同时在两个图上执行随机游走，然后计算由两次游走都产生的路径数量。如 [Vis+10] 所讨论，这可以高效计算。有关图核的更多详细信息，请参见 [KJM19]。

有关结构化对象核的综述，请参见例如 [Gär03]。

## 18.2.4 从旧核构建新核

给定两个有效的核 $\mathcal{K}_1(\boldsymbol{x}, \boldsymbol{x}')$ 和 $\mathcal{K}_2(\boldsymbol{x}, \boldsymbol{x}')$，我们可以使用以下任一方法创建一个新核：

- $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = c\mathcal{K}_1(\boldsymbol{x}, \boldsymbol{x}')$，其中 $c > 0$ 为任意常数 (18.28)
- $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = f(\boldsymbol{x})\mathcal{K}_1(\boldsymbol{x}, \boldsymbol{x}')f(\boldsymbol{x}')$，其中 $f$ 为任意函数 (18.29)
- $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = q(\mathcal{K}_1(\boldsymbol{x}, \boldsymbol{x}'))$，其中 $q$ 为任意具有非负系数的多项式函数 (18.30)
- $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = \exp(\mathcal{K}_1(\boldsymbol{x}, \boldsymbol{x}'))$ (18.31)
- $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = \boldsymbol{x}^{\mathsf{T}}\boldsymbol{A}\boldsymbol{x}'$，其中 **A** 为任意正半定矩阵 (18.32)

例如，假设我们从线性核 $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = \boldsymbol{x}\boldsymbol{x}'$ 开始。我们知道这是一个有效的 Mercer 核，因为相应的 Gram 矩阵只是数据的（缩放）协方差矩阵。根据上述规则，我们可以看到来自 18.2.2.1 节的多项式核 $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = (\boldsymbol{x}^{\mathsf{T}}\boldsymbol{x}')^M$ 是一个有效的 Mercer 核。

我们还可以使用上述规则来证明高斯核是一个有效的核。要看明白这一点，请注意 
\(\|\boldsymbol{x} - \boldsymbol{x}'\|^2 = \boldsymbol{x}^{\mathsf{T}}\boldsymbol{x} + (\boldsymbol{x}')^{{\mathsf{T}}}\boldsymbol{x}' - 2\boldsymbol{x}^{\mathsf{T}}\boldsymbol{x}'\) (18.33)

因此

\(\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = \exp(-\|\boldsymbol{x} - \boldsymbol{x}'\|^2 / 2\sigma^2) = \exp(-\boldsymbol{x}^{\mathsf{T}}\boldsymbol{x} / 2\sigma^2) \exp(\boldsymbol{x}^{\mathsf{T}}\boldsymbol{x}' / \sigma^2) \exp(-(\boldsymbol{x}')^{{\mathsf{T}}}\boldsymbol{x}' / 2\sigma^2)\) (18.34)
是一个有效的核。

我们还可以使用加法或乘法组合核：

- $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = \mathcal{K}_1(\boldsymbol{x}, \boldsymbol{x}') + \mathcal{K}_2(\boldsymbol{x}, \boldsymbol{x}')$ (18.35)
- $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = \mathcal{K}_1(\boldsymbol{x}, \boldsymbol{x}') \times \mathcal{K}_2(\boldsymbol{x}, \boldsymbol{x}')$ (18.36)

将两个正定核相乘总是得到另一个正定核。这是一种获得各个核个体属性的合取的方法，如图 18.5 所示。

此外，将两个正定核相加总是得到另一个正定核。这是一种获得各个核个体属性的析取的方法，如图 18.6 所示。

有关使用核组合来预测时间序列数据的示例，请参见 18.8.1 节。
