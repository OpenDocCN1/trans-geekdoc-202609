
其中步骤 (i) 和 (ii) 由梯度的链式法则得出，而 (iii) 和 (iv) 源自方程 (24.1) 和 (24.2) 中的定义。因此，我们可以通过以下方式获得对数似然梯度的无偏蒙特卡洛估计：

```
\(\nabla_{\boldsymbol{\theta}} \log Z_{\boldsymbol{\theta}} \simeq -\frac{1}{S} \sum_{s=1}^S \nabla_{\boldsymbol{\theta}} \mathcal{E}_{\boldsymbol{\theta}}(\tilde{\mathbf{x}}_s),\)
```

其中 \(\tilde{\mathbf{x}}_s \sim p_{\boldsymbol{\theta}}(\mathbf{x})\)，即来自 EBM 给定的 \(\mathbf{x}\) 分布的随机样本。因此，只要我们能够从模型中抽取随机样本，就能获得对数似然梯度的无偏蒙特卡洛估计，从而允许我们使用随机梯度上升来优化参数。

大量文献主要关注从 EBM 中进行高效 MCMC 采样的方法。下面我们将讨论其中的一些方法。

### 24.2.1 基于梯度的 MCMC 方法

一些高效的 MCMC 方法，例如 **Langevin MCMC**（第 12.5.6 节）或哈密顿蒙特卡洛（第 12.5 节），利用了以下事实：对 \(\mathbf{x}\) 的对数概率梯度（称为 **得分函数**）等于能量的（负）梯度，因此易于计算：

```
\(\nabla_{\mathbf{x}} \log p_{\boldsymbol{\theta}}(\mathbf{x}) = -\nabla_{\mathbf{x}} \mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x}) - \underbrace{\nabla_{\mathbf{x}} \log Z_{\boldsymbol{\theta}}}_{=0} = -\nabla_{\mathbf{x}} \mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x}).\)
```

例如，当使用 Langevin MCMC 从 \(p_{\boldsymbol{\theta}}(\mathbf{x})\) 采样时，我们先从简单的先验分布中抽取初始样本 \(\mathbf{x}^0\)，然后使用步长 \(\epsilon > 0\) 模拟超阻尼 Langevin 扩散过程 \(K\) 步：

```
\(\mathbf{x}^{k+1} \leftarrow \mathbf{x}^k + \frac{\epsilon^2}{2} \underbrace{\nabla_{\mathbf{x}} \log p_{\boldsymbol{\theta}}(\mathbf{x}^k)}_{=-\nabla_{\mathbf{x}} \mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x})} + \epsilon \mathbf{z}^k, \quad k=0, 1, \cdots, K-1.\)
```

其中 \(\mathbf{z}^k \sim \mathcal{N}(\mathbf{0}, \mathbf{I})\) 是高斯噪声项。我们在图 25.5d 中展示了此过程的示例。当 \(\epsilon \rightarrow 0\) 且 \(K \rightarrow \infty\) 时，\(\mathbf{x}^K\) 在某些正则性条件下保证分布为 \(p_{\boldsymbol{\theta}}(\mathbf{x})\)。在实践中，我们必须使用一个小的有限 \(\epsilon\)，但离散化误差通常可以忽略不计，或者可以通过 Metropolis-Hastings 步骤（第 12.2 节）进行修正，从而得到 Metropolis 调整 Langevin 算法（第 12.5.6 节）。

### 24.2.2 对比差异

运行 MCMC 直到收敛以获取样本 \(\mathbf{x} \sim p_{\boldsymbol{\theta}}(\mathbf{x})\) 计算成本高昂。因此，我们通常需要近似方法，以使基于 MCMC 的 EBM 学习实用。实现此目的的一种流行方法是 **对比差异**（CD）[Hin02]。在 CD 中，我们从数据点 \(\mathbf{x}\) 初始化 MCMC 链，然后执行固定步数的 MCMC。可以证明，CD 的 \(T\) 步骤最小化了以下目标：

```
\(\text{CD}_T = D_{\text{KL}}(p_0 \parallel p_\infty) - D_{\text{KL}}(p_T \parallel p_\infty)\)
```

其中 \(p_T\) 是 \(T\) 次 MCMC 更新后 \(\mathbf{x}\) 上的分布，而 \(p_0\) 是数据分布。通常，使用较小的 \(T\) 值即可获得良好结果，有时只需 \(T = 1\)。我们在下面给出详细信息。

### 24.2.2.1 使用 CD 拟合 RBM

CD 最初开发用于拟合一种称为受限玻尔兹曼机（第 4.3.3.2 节）的特殊隐变量 EBM。该模型专门设计用于支持快速块 Gibbs 采样，这是 CD 所必需的（也可以被标准基于 MCMC 的学习方法 [AHS85] 利用）。

为简单起见，我们将假设隐藏节点和可见节点是二进制的，并使用一步对比差异。如补充部分 4.3.1 中所讨论，二进制 RBM 具有以下能量函数：

$$\mathcal{E}(\mathbf{x}, \mathbf{z}; \boldsymbol{\theta}) = \sum_{d=1}^D \sum_{k=1}^K x_d z_k W_{dk} + \sum_{d=1}^D x_d b_d + \sum_{k=1}^K z_k c_k$$

（今后我们将丢弃一元（偏置）项，这些项可以通过钳位 $z_k = 1$ 或 $x_d = 1$ 来模拟。）这是一个 loglinear 模型，每条边具有一个二进制特征。因此，根据方程 (4.135)，对数似然梯度由钳位期望减去未钳位期望给出：

$$\frac{\partial \ell}{\partial w_{dk}} = \frac{1}{N} \sum_{n=1}^N \mathbb{E}[x_d z_k | \mathbf{x}_n, \boldsymbol{\theta}] - \mathbb{E}[x_d z_k | \boldsymbol{\theta}]$$

我们可以将上述梯度重写为矩阵-向量形式如下：

$$\nabla_{\mathbf{w}} \ell = \mathbb{E}_{p_D(\mathbf{x}) p(\mathbf{z}|\mathbf{x}, \boldsymbol{\theta})} [\mathbf{x} \mathbf{z}^T] - \mathbb{E}_{p(\mathbf{z}, \mathbf{x}|\boldsymbol{\theta})} [\mathbf{x} \mathbf{z}^T]$$

（我们可以通过设置 $x_d = 1$ 或 $z_k = 1$ 来推导偏置项梯度的类似表达式。）方程 (24.21) 梯度表达式中的第一项，当 \(\mathbf{x}\) 固定为数据案例时，有时称为 **钳位阶段**，第二项，当 \(\mathbf{x}\) 自由时，有时称为 **未钳位阶段**。当模型期望与经验期望相匹配时，两项相互抵消，梯度变为零，学习停止。

我们还可以将其与神经科学中的 **赫布学习** 原理联系起来。特别是，赫布规则指出，两个同时活跃的神经元之间的连接强度应增加。（该理论通常概括为“同放同线”。）$^1$ 因此，方程 (24.21) 中的第一项被视为赫布项，第二项为反赫布项，这是由于符号变化。

我们可以利用双部图的马尔可夫结构来近似期望，如下所示：

$$z_n \sim p(\mathbf{z}|\mathbf{x}_n, \boldsymbol{\theta})$$

$$\mathbf{x}'_n \sim p(\mathbf{x}|\mathbf{z}_n, \boldsymbol{\theta})$$

$$\mathbf{z}'_n \sim p(\mathbf{z}|\mathbf{x}'_n, \boldsymbol{\theta})$$

1. 参见 https://en.wikipedia.org/wiki/Hebbian_theory。

图 24.2：RBM 对比差异采样示意图。可见节点从数据集中抽取的示例初始化。然后我们采样一个隐藏向量，再采样另一个可见向量，以此类推。最终（在“无穷”处），我们将从联合分布 \(p(\boldsymbol{x}, \boldsymbol{z} | \boldsymbol{\theta})\) 中生成样本。

我们可以将 \(\boldsymbol{x}'_n\) 视为模型在被编码然后由模型解码后，对 \(\boldsymbol{x}_n\) 进行重构的最佳尝试。此类样本有时称为 **幻想数据**。有关示意图，请参见图 24.2。给定这些样本，我们进行如下近似：

\(\mathbb{E}_{p(\cdot|\boldsymbol{\theta})} [\boldsymbol{x}\boldsymbol{z}^{\mathsf{T}}] \approx \boldsymbol{x}_n (\boldsymbol{z}'_n)^{\mathsf{T}}\) (24.26)

在实践中，通常在上述表达式中使用 \(\mathbb{E} [\boldsymbol{z}|\boldsymbol{x}'_n]\) 而不是采样值 \(\boldsymbol{z}'_n，因为这可以减少方差。但是，在方程 (24.23) 中用 \(\mathbb{E} [\boldsymbol{z}|\boldsymbol{x}_n]\) 代替采样 \(\boldsymbol{z}_n \sim p(\boldsymbol{z}|\boldsymbol{x}_n)\) 是不合理的，因为这样每个隐藏单元将能够传递超过 1 比特的信息，因此它就不会充当多大的瓶颈。

整个过程在算法 24.1 中总结。有关更多详细信息，请参见 [Hin10; Swe+10]。

```
Algorithm 24.1: CD-1 training for an RBM with binary hidden and visible units
1 Initialize weights \(\boldsymbol{W} \in \mathbb{R}^{D \times K}\) randomly
2 for \(t = 1, 2, \dots\) do
3   for each minibatch of size \(B\) do
4     Set minibatch gradient to zero, \(\boldsymbol{g} := \boldsymbol{0}\)
5     for each case \(\boldsymbol{x}_n\) in the minibatch do
6       Compute \(\boldsymbol{\mu}_n = \mathbb{E} [\boldsymbol{z}|\boldsymbol{x}_n, \boldsymbol{W}]\)
7       Sample \(\boldsymbol{z}_n \sim p(\boldsymbol{z}|\boldsymbol{x}_n, \boldsymbol{W})\)
8       Sample \(\boldsymbol{x}'_n \sim p(\boldsymbol{x}|\boldsymbol{z}_n, \boldsymbol{W})\)
9       Compute \(\boldsymbol{\mu}'_n = \mathbb{E} [\boldsymbol{z}|\boldsymbol{x}'_n, \boldsymbol{W}]\)
10      Compute gradient \(\nabla_{\boldsymbol{W}} = (\boldsymbol{x}_n)(\boldsymbol{\mu}_n)^{\mathsf{T}} - (\boldsymbol{x}'_n)(\boldsymbol{\mu}'_n)^{\mathsf{T}}\)
11      Accumulate \(\boldsymbol{g} := \boldsymbol{g} + \nabla_{\boldsymbol{W}}\)
12    Update parameters \(\boldsymbol{W} := \boldsymbol{W} + \eta_t \frac{1}{B}\boldsymbol{g}\)
```
