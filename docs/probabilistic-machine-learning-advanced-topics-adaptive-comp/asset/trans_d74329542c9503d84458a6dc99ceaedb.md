

NGD 使用逆 FIM 作为预处理矩阵，即，我们执行以下形式的更新：

$$\theta_{t+1} = \theta_t - \eta_t \mathbf{F}(\theta_t)^{-1} \mathbf{g}_t$$ (6.85)

该项

$$\mathbf{F}^{-1} \mathbf{g}_t = \mathbf{F}^{-1} \nabla \mathcal{L}(\boldsymbol{\theta}_t) \triangleq \tilde{\nabla} \mathcal{L}(\boldsymbol{\theta}_t)$$ (6.86)

被称为 **自然梯度**。

## 6.4.2 NGD 的解释

### 6.4.2.1 NGD 作为信任区域方法

在补充章节 6.1.3.1 中，我们表明可以将标准梯度下降解释为在参数变化的 $\ell_2$ 范数受到惩罚的前提下，对目标的线性近似进行优化，即，如果 $\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t + \boldsymbol{\delta}$，则我们优化

$$M_t(\boldsymbol{\delta}) = \mathcal{L}(\boldsymbol{\theta}_t) + \mathbf{g}_t^\mathsf{T} \boldsymbol{\delta} + \eta \|\boldsymbol{\delta}\|_2^2$$ (6.87)

现在让我们用基于 FIM 的平方距离替换平方距离，$\|\boldsymbol{\delta}\|_F^2 = \boldsymbol{\delta}^\mathsf{T} \mathbf{F} \boldsymbol{\delta}$。这等价于在**白化坐标系** $\boldsymbol{\phi} = \mathbf{F}^{\frac{1}{2}} \boldsymbol{\theta}$ 中的平方欧氏距离，因为

$$\|\boldsymbol{\phi}_{t+1} - \boldsymbol{\phi}_t\|_2^2 = \|\mathbf{F}^{\frac{1}{2}}(\boldsymbol{\theta}_t + \boldsymbol{\delta}) - \mathbf{F}^{\frac{1}{2}} \boldsymbol{\theta}_t\|_2^2 = \|\mathbf{F}^{\frac{1}{2}} \boldsymbol{\delta}\|_2^2 = \|\boldsymbol{\delta}\|_F^2$$ (6.88)

新的目标变为

$$M_t(\boldsymbol{\delta}) = \mathcal{L}(\boldsymbol{\theta}_t) + \mathbf{g}_t^\mathsf{T} \boldsymbol{\delta} + \eta \boldsymbol{\delta}^\mathsf{T} \mathbf{F} \boldsymbol{\delta}$$ (6.89)

求解 $\nabla_{\boldsymbol{\delta}} M_t(\boldsymbol{\delta}) = \mathbf{0}$ 给出更新

$$\boldsymbol{\delta}_t = -\eta \mathbf{F}^{-1} \mathbf{g}_t$$ (6.90)

这与自然梯度方向相同。因此，我们可以将 NGD 视为一种信任区域方法，其中我们使用目标的一阶近似，并在约束中使用 FIM 距离。在上述推导中，我们假设 $\mathbf{F}$ 是一个常数矩阵。在大多数问题中，它会在空间中的每个点发生变化，因为我们正在优化一个称为**黎曼流形**的弯曲空间。对于某些模型，我们可以高效地计算 FIM，从而使我们能够捕捉曲率信息，尽管我们对目标使用了一阶近似。

### 6.4.2.2 NGD 作为高斯-牛顿方法

如果 \( p(\mathbf{y}|\mathbf{x}, \boldsymbol{\theta}) \) 是一个由自然参数 \( \boldsymbol{\eta} = f(\mathbf{x}, \boldsymbol{\theta}) \) 计算的指数族分布，则可以证明 [Hes00; PB14] NGD 与广义高斯-牛顿（GGN）方法（第 17.3.2 节）相同。此外，在在线环境中，这些方法等价于使用扩展卡尔曼滤波器进行序列贝叶斯推理，如 [Oli18] 所示。

## 6.4.3 NGD 的优点

使用 FIM 作为预处理矩阵，而非海森矩阵，有两个优点。首先，**F** 总是正定的，而 **H** 在鞍点处可能有负特征值，鞍点在高维空间中很普遍。其次，可以很容易地从小批量中在线近似 **F**，因为它是（关于经验分布的）梯度向量外积的期望。这与基于海森的方法 [Byr+16; Liu+18a] 形成对比，后者对小批量近似引入的噪声敏感得多。

此外，与信任区域优化的联系清楚地说明，NGD 以对预测最重要的方式更新参数，这使该方法能够在参数空间的无信息区域采取更大的步长，从而有助于避免陷入平坦区域。这也可以帮助解决参数高度相关时出现的问题。

例如，考虑 [SD12] 提出的一种带有异常高度耦合参数化的 2D 高斯分布：

\(p(x;\theta) = \frac{1}{2\pi} \exp \left[ - \frac{1}{2} \left( x_1 - \left[ 3\theta_1 + \frac{1}{3}\theta_2 \right] \right)^2 - \frac{1}{2} \left( x_2 - \left[ \frac{1}{3}\theta_1 \right] \right)^2 \right]\) (6.91)

目标是交叉熵损失：

\(\mathcal{L}(\theta) = -\mathbb{E}_{p^*(x)} [\log p(x;\theta)]\) (6.92)

该目标的梯度由以下给出

\(\nabla_\theta \mathcal{L}(\theta) = \begin{pmatrix} \mathbb{E}_{p^*(x)} \left[ 3(x_1 - [3\theta_1 + \frac{1}{3}\theta_2]) + \frac{1}{3}(x_2 - [\frac{1}{3}\theta_1]) \right] \\ \mathbb{E}_{p^*(x)} \left[ \frac{1}{3}(x_1 - [3\theta_1 + \frac{1}{3}\theta_2]) \right] \end{pmatrix}\) (6.93)

假设 \(p^*(x) = p(x; [0, 0])\)。那么 Fisher 矩阵是一个常数矩阵，由以下给出

\(\mathbf{F} = \begin{pmatrix} 3^2 + \frac{1}{3^2} & 1 \\ 1 & \frac{1}{3^2} \end{pmatrix}\) (6.94)

图 6.6 将 \(\theta\) 空间中的最陡下降与自然梯度方法进行了比较，后者等价于在 \(\phi\) 空间中的最陡下降。两种方法都从 \(\theta = (1, -1)\) 开始。全局最优解位于 \(\theta = (0, 0)\)。我们看到，NG 方法（蓝色点）收敛到该最优解的速度快得多，并且走的是最短路径，而最陡下降则采取了一条非常迂回的路线。我们还看到，在白化参数空间中，梯度场更“球形”，这使得下降简单得多且更快。

最后，请注意，由于 NGD 对分布的参数化方式不变，即使对高斯分布使用标准参数化，我们也会得到相同的结果。如果我们的概率模型更复杂（例如 DNN），这尤其有用（参见，例如，[SSE18]）。

NGD 的主要缺点是计算（逆）Fisher 信息矩阵（FIM）的计算成本。为了加速，多种方法对 **F** 的形式做出假设，以便可以高效地对其求逆。例如，[LeC+98] 对神经网络训练使用对角近似；

[RMB08] 使用低秩加分块对角近似；而 [GS15] 假设梯度的协方差可以由低树宽的有向高斯图形模型建模（即，\(\mathbf{F}\) 的 Cholesky 分解是稀疏的）。

[MG15] 提出了 **KFAC** 方法，即“克罗内克分解近似曲率”；该方法将 DNN 的 FIM 近似为分块对角矩阵，每个块是两个小矩阵的克罗内克积。该方法在神经网络的有监督学习 [GM16; BGM17; Geo+18; Osa+19b] 以及神经策略网络的强化学习 [Wu+17] 中均取得了良好效果。KFAC 近似可以使用 [AKO18] 的平均场分析来证明。此外，[ZMG19] 证明，如果 DNN 是过参数化的（即，表现得像插值器），KFAC 将收敛到 DNN 的全局最优解。

一种更简单的方法是通过用经验分布替换模型的分布来近似 FIM。特别是，定义 \(p_D(\boldsymbol{x}, \boldsymbol{y}) = \frac{1}{N} \sum_{n=1}^N \delta_{\boldsymbol{x}_n}(\boldsymbol{x})\delta_{\boldsymbol{y}_n}(\boldsymbol{y})\)，\(p_D(\boldsymbol{x}) = \frac{1}{N} \sum_{n=1}^N \delta_{\boldsymbol{x}_n}(\boldsymbol{x})\)

以及 \(p_\theta(x, y) = p_\mathcal{D}(x)p(y|x, \theta)\)。然后我们可以按以下方式计算 **经验 Fisher** [Mar16]：

\(\mathbf{F} = \mathbb{E}_{p_\theta(x, y)} [\nabla \log p(y|x, \theta)\nabla \log p(y|x, \theta)^\top]\) (6.95)

\(\approx \mathbb{E}_{p_\mathcal{D}(x, y)} [\nabla \log p(y|x, \theta)\nabla \log p(y|x, \theta)^\top]\) (6.96)

\(= \frac{1}{|\mathcal{D}|} \sum_{(x,y) \in \mathcal{D}} \nabla \log p(y|x, \theta)\nabla \log p(y|x, \theta)^\top\) (6.97)

由于该近似简单易计算，因此被广泛使用。特别是，我们可以使用平方梯度向量来计算对角近似。（这与 ADAGRAD 类似，但仅使用当前梯度而非梯度的移动平均；后者在进行随机优化时是更好的方法。）

不幸的是，经验 Fisher 的效果不如真正的 Fisher [KBH19; Tho+19]。要了解原因，请注意，当我们到达梯度向量趋于零的参数空间平坦部分时，经验 Fisher 将变得奇异，因此算法会卡在这个高原上。然而，真正的 Fisher 对输出取期望，即，它将 **y** 边缘化掉。这使得如果改变参数，它能够检测到输出的微小变化。这就是为什么自然梯度方法比标准梯度方法更能“逃离”高原。

另一种策略是使用 **F** 的精确计算，但使用截断共轭梯度（CG）方法近似求解 \(\mathbf{F}^{-1}\mathbf{g}\)，其中每个 CG 步骤使用高效的海森-向量积方法 [Pea94]。这被称为 **海森自由优化** [Mar10a]。然而，这种方法可能很慢，因为计算单个参数更新可能需要许多 CG 迭代。

## 6.4.5 指数族的自然梯度

在本节中，我们假设 \(\mathcal{L}\) 为以下形式的期望损失：

\(\mathcal{L}(\boldsymbol{\mu}) = \mathbb{E}_{q_\mu(\mathbf{z})} \left[ \tilde{\mathcal{L}}(\mathbf{z}) \right]\) (6.98)

其中 \(q_\mu(\mathbf{z})\) 是具有矩参数 \(\mu\) 的指数族分布。这是变分优化（在补充章节 6.4.3 中讨论）和自然进化策略（在第 6.7.6 节中讨论）的基础。

结果表明，对矩参数的梯度与对自然参数 \(\lambda\) 的自然梯度相同。这遵循链式法则：

\(\frac{d}{d\boldsymbol{\lambda}} \mathcal{L}(\boldsymbol{\lambda}) = \frac{d\boldsymbol{\mu}}{d\boldsymbol{\lambda}} \frac{d}{d\boldsymbol{\mu}} \mathcal{L}(\boldsymbol{\mu}) = \mathbf{F}(\boldsymbol{\lambda})\nabla_\boldsymbol{\mu} \mathcal{L}(\boldsymbol{\mu})\) (6.99)

其中 \(\mathcal{L}(\boldsymbol{\mu}) = \mathcal{L}(\boldsymbol{\lambda}(\boldsymbol{\mu}))\)，并且我们使用公式 (2.232) 写出

\(\mathbf{F}(\boldsymbol{\lambda}) = \nabla_\boldsymbol{\lambda} \boldsymbol{\mu}(\boldsymbol{\lambda}) = \nabla_\boldsymbol{\lambda}^2 \Lambda(\boldsymbol{\lambda})\) (6.100)

因此

\(\tilde{\nabla}_\boldsymbol{\lambda} \mathcal{L}(\boldsymbol{\lambda}) = \mathbf{F}(\boldsymbol{\lambda})^{-1}\nabla_\boldsymbol{\lambda} \mathcal{L}(\boldsymbol{\lambda}) = \nabla_\boldsymbol{\mu} \mathcal{L}(\boldsymbol{\mu})\) (6.101)

剩下的就是计算对矩参数的（普通）梯度。如何做到这一点的细节将取决于 *q* 的形式和 \(\mathcal{L}(\lambda)\) 的形式。我们将在下面讨论这个问题的一些方法。
