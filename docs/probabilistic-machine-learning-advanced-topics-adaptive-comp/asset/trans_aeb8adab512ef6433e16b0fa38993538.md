## 25.3 基于分数的生成模型（SGMs）

*本节由 Yang Song 和 Durk Kingma 撰写。*

在第 24.3 节中，我们讨论了如何使用分数匹配来拟合基于能量的模型（EBMs）。这会调整 EBM 的参数，使模型的分数函数 \(\nabla_{\mathbf{x}} \log p_{\boldsymbol{\theta}}(\mathbf{x})\) 与数据的分数函数 \(\nabla_{\mathbf{x}} \log p_D(\mathbf{x})\) 相匹配。拟合标量能量函数并计算其分数的替代方法是直接学习分数函数。这被称为**基于分数的生成模型**或**SGM** [SE19; SE20b; Son+21b]。我们可以使用基本分数匹配（第 24.3.1 节）、切片分数匹配（第 24.3.3 节）或去噪分数匹配（第 24.3.2 节）来优化分数函数 \(\mathbf{s}_{\boldsymbol{\theta}}(\mathbf{x})\)。我们将在下面更详细地讨论这一类模型。（与 EBM 的比较，请参见 [SH21]。）

### 25.3.1 示例

在图 25.5a 中，我们展示了**瑞士卷**数据集。我们通过使用基本分数匹配拟合具有 2 个隐藏层（每个隐藏层有 128 个隐藏单元）的 MLP 来估计分数函数。在图 25.5b 中，我们展示了网络在进行 10,000 步 SGD 训练后的输出。我们可以看到没有主要的假阴性（因为无论数据密度最高的地方，梯度场都是零），但存在一些假正例（因为一些零梯度区域不对应于数据区域）。预测输出与经验数据密度的比较在图 25.5c 中显示得更清楚。在图 25.5d 中，我们展示了从学习模型中生成的一些样本，使用 Langevin 采样生成。

### 25.3.2 多尺度噪声添加

一般来说，当存在低数据密度区域时，分数匹配可能会遇到困难。为了了解这一点，假设 \(p_D(\mathbf{x}) = \pi p_0(\mathbf{x}) + (1-\pi)p_1(\mathbf{x})\)。令 \(\mathcal{S}_0 := \{\mathbf{x} \mid p_0(\mathbf{x}) > 0\}\) 和 \(\mathcal{S}_1 := \{\mathbf{x} \mid p_1(\mathbf{x}) > 0\}\) 分别为 \(p_0(\mathbf{x})\) 和 \(p_1(\mathbf{x})\) 的支撑集。当它们互不相交时，\(p_D(\mathbf{x})\) 的分数由

\(\nabla_{\mathbf{x}} \log p_D(\mathbf{x}) = \begin{cases} \nabla_{\mathbf{x}} \log p_0(\mathbf{x}), & \mathbf{x} \in \mathcal{S}_0 \\ \nabla_{\mathbf{x}} \log p_1(\mathbf{x}), & \mathbf{x} \in \mathcal{S}_1, \end{cases}\) (25.30)

给出，这不依赖于权重 \(\pi\)。因此，分数匹配无法正确恢复真实分布。此外，Langevin 采样在模式之间穿梭时会有困难。（在实践中，即使不同模式的支撑集仅近似不相交，这种情况也会发生。）

Song 和 Ermon [SE19; SE20b] 以及 Song 等人 [Son+21b] 通过用不同尺度的噪声扰动训练数据来克服这一困难。具体来说，他们使用

$q_\sigma(\tilde{\boldsymbol{x}}|\boldsymbol{x}) = \mathcal{N}(\tilde{\boldsymbol{x}}|\boldsymbol{x}, \sigma^2 \mathbf{I})$

$q_\sigma(\tilde{\boldsymbol{x}}) = \int p_D(\boldsymbol{x}) q_\sigma(\tilde{\boldsymbol{x}}|\boldsymbol{x}) d\boldsymbol{x}$

对于较大的噪声扰动，不同模式由于添加的噪声而连接，因此它们之间的估计权重是准确的。对于较小的噪声扰动，不同模式更加不连通，但受噪声扰动的分布更接近原始未扰动的数据分布。使用诸如退火 Langevin 动力学 [SE19; SE20b; Son+21b] 或扩散采样 [SD+15a; HJA20; Son+21b] 等采样方法，我们可以先从受噪声扰动最严重的分布进行采样，然后平滑地降低噪声尺度的幅度直到达到最小值。此过程有助于结合来自所有噪声尺度的信息，并在从较小尺度采样时保持来自较高噪声扰动的权重的正确估计。

在实践中，所有分数模型共享权重，并通过一个条件化于噪声尺度的单个神经网络实现；这被称为**噪声条件分数网络**，形式为 \(\boldsymbol{s}_\theta(\boldsymbol{x}, \sigma)\)。不同尺度的分数是通过训练一组分数匹配目标（每个噪声尺度一个）来估计的。如果我们使用方程 (24.33) 中的去噪分数匹配目标，我们得到

$\mathcal{L}(\boldsymbol{\theta}; \sigma) = \mathbb{E}_{q(\boldsymbol{x}, \tilde{\boldsymbol{x}})} \left[ \frac{1}{2} \| \nabla_{\boldsymbol{x}} \log p_\theta(\tilde{\boldsymbol{x}}, \sigma) - \nabla_{\boldsymbol{x}} \log q_\sigma(\tilde{\boldsymbol{x}}|\boldsymbol{x}) \|_2^2 \right]$
$= \frac{1}{2} \mathbb{E}_{p_D(\boldsymbol{x})} \mathbb{E}_{\tilde{\boldsymbol{x}} \sim \mathcal{N}(\boldsymbol{x}, \sigma^2 \mathbf{I})} \left\{ \left\| \boldsymbol{s}_\theta(\tilde{\boldsymbol{x}}, \sigma) + \frac{(\tilde{\boldsymbol{x}} - \boldsymbol{x})}{\sigma^2} \right\|_2^2 \right\}$

这里我们使用了这样一个事实：对于高斯分布，分数由

$\nabla_{\boldsymbol{x}} \log \mathcal{N}(\tilde{\boldsymbol{x}}|\boldsymbol{x}, \sigma^2 \mathbf{I}) = -\nabla_{\boldsymbol{x}} \frac{1}{2\sigma^2} (\boldsymbol{x} - \tilde{\boldsymbol{x}})^\top (\boldsymbol{x} - \tilde{\boldsymbol{x}}) = \frac{\boldsymbol{x} - \tilde{\boldsymbol{x}}}{\sigma^2}$

给出。

如果我们有 $T$ 个不同的噪声尺度，我们可以使用

$\mathcal{L}(\boldsymbol{\theta}; \sigma_{1:T}) = \sum_{t=1}^T \lambda_t \mathcal{L}(\boldsymbol{\theta}; \sigma_t)$

以加权方式组合损失，其中我们选择 \(\sigma_1 > \sigma_2 > \cdots > \sigma_T\)，且加权项满足 \(\lambda_t > 0\)。

### 25.3.3 与 DDPM 的等价性

我们现在展示上述基于分数的生成模型训练目标与 DDPM 损失等价。为了理解这一点，首先让我们用 $q_0(\boldsymbol{x}_0)$ 替换 $p_D(\boldsymbol{x})$，用 \(\boldsymbol{x}_t$ 替换 \(\tilde{\boldsymbol{x}}\)，并用 \(\boldsymbol{s}_\theta(\boldsymbol{x}_t, t)\) 替换 \(\boldsymbol{s}_\theta(\tilde{\boldsymbol{x}}, \sigma)\)。我们还将通过均匀随机采样时间步来计算方程 (25.36) 的随机近似。然后方程 (25.36) 变为

$\mathcal{L} = \mathbb{E}_{\boldsymbol{x}_0 \sim q_0(\boldsymbol{x}_0), \boldsymbol{x}_t \sim q(\boldsymbol{x}_t|\boldsymbol{x}_0), t \sim \text{Unif}(1,T)} \left[ \lambda_t \left\| \boldsymbol{s}_\theta(\boldsymbol{x}_t, t) + \frac{(\boldsymbol{x}_t - \boldsymbol{x}_0)}{\sigma_t^2} \right\|_2^2 \right]$

如果我们使用 \(\boldsymbol{x}_t = \boldsymbol{x}_0 + \sigma_t \boldsymbol{\epsilon}$，并定义 \(\boldsymbol{s}_{\boldsymbol{\theta}}(\boldsymbol{x}_t, t) = -\frac{\boldsymbol{\epsilon}_{\boldsymbol{\theta}}(\boldsymbol{x}_t, t)}{\sigma_t}$，我们可以将其改写为
\[
\mathcal{L} = \mathbb{E}_{\boldsymbol{x}_0 \sim q_0(\boldsymbol{x}_0), \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I}), t \sim \text{Unif}(1, T)} \left[ \frac{\lambda_t}{\sigma_t^2} \| \boldsymbol{\epsilon} - \boldsymbol{\epsilon}_{\boldsymbol{\theta}}(\boldsymbol{x}_t, t) \|_2^2 \right]
\]
(25.38)

如果我们设置 \(\lambda_t = \sigma_t^2$，我们就恢复了方程 (25.24) 中的 \(L_{\text{simple}}\) 损失。

## 25.4 使用微分方程的连续时间模型

在本节中，我们考虑隐藏层数量趋于无限时的 DDPM 模型，或者等价地，噪声级别趋于无限时的 SGM。这需要从离散时间切换到连续时间，这使数学变得复杂。优势是我们可以利用关于常微分方程和随机微分方程求解器的大量现有文献，以实现更快的生成，正如我们将看到的。

### 25.4.1 前向扩散 SDE

让我们首先考虑一个扩散过程，其中噪声级别 \(\beta_t$ 被改写为 \(\beta(t)\Delta t$，其中 \(\Delta t$ 是步长：

\(\boldsymbol{x}_t = \sqrt{1 - \beta_t}\boldsymbol{x}_{t-1} + \sqrt{\beta_t}\mathcal{N}(\mathbf{0}, \mathbf{I}) = \sqrt{1 - \beta(t)\Delta t}\boldsymbol{x}_{t-1} + \sqrt{\beta(t)\Delta t}\mathcal{N}(\mathbf{0}, \mathbf{I})\tag{25.39}$

如果 \(\Delta t$ 很小，我们可以使用一阶泰勒级数展开来近似第一项，得到

\(\boldsymbol{x}_t \approx \boldsymbol{x}_{t-1} - \frac{\beta(t)\Delta t}{2}\boldsymbol{x}_{t-1} + \sqrt{\beta(t)\Delta t}\mathcal{N}(\mathbf{0}, \mathbf{I})\tag{25.40}$

因此，对于小 \(\Delta t\)，我们有

\(\frac{\boldsymbol{x}_t - \boldsymbol{x}_{t-1}}{\Delta t} \approx -\frac{\beta(t)}{2}\boldsymbol{x}_{t-1} + \frac{\sqrt{\beta(t)}}{\sqrt{\Delta t}}\mathcal{N}(\mathbf{0}, \mathbf{I})\tag{25.41}$

现在我们可以切换到连续时间极限，并将其写为以下随机微分方程或 SDE：

\(\frac{d\boldsymbol{x}(t)}{dt} = -\frac{1}{2}\beta(t)\boldsymbol{x}(t) + \sqrt{\beta(t)}\frac{d\boldsymbol{w}(t)}{dt}\tag{25.42}$

其中 \(\boldsymbol{w}(t)$ 表示标准 Wiener 过程，也称为布朗噪声。更一般地，我们可以按如下形式写出这样的 SDE，其中我们使用 Itô 微积分符号（参见例如 [SS19]）：

\(d\boldsymbol{x} = \underbrace{\boldsymbol{f}(\boldsymbol{x}, t)}_{\text{drift}} dt + \underbrace{g(t)}_{\text{diffusion}} d\boldsymbol{w}\tag{25.43}$

上述 SDE 的第一项称为漂移系数，第二项称为扩散系数。
