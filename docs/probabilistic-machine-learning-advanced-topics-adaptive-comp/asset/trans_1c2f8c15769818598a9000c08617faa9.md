

由于目标函数是随机的，且可重参数化，我们可以使用 SGD 来优化它。但是，[Ing20] 提出了 **确定性 ADVI**，其中样本 \(\epsilon_s \sim \mathcal{N}(\mathbf{0}, \mathbf{I})\) 在优化过程中保持固定。这称为常用随机数技巧（第 11.6.1 节），并使目标函数成为确定性函数；这允许使用更强大的二阶优化方法，例如 BFGS。（当然，如果数据集很大，我们可能需要使用小批量子采样，这会重新引入随机性。）

### 10.2.2.2 示例：用于 beta-二项式模型的 ADVI

为了说明 ADVI，我们考虑第 7.4.4 节中的一维 beta-二项式模型。我们希望使用先验 \(p(\theta) = \text{Beta}(\theta|a, b)\) 和似然 \(p(\mathcal{D}|\theta) = \prod_i \text{Ber}(y_i|\theta)\) 来近似 \(p(\theta|\mathcal{D})\)，其中充分统计量为 \(N_1 = 10, N_0 = 1\)，且先验是非信息性的，\(a = b = 1\)。我们使用变换 \(\theta = T^{-1}(z) = \sigma(z)\)，并使用 SGD 优化 ELBO。该方法的结果如图 7.4 所示，表明高斯拟合是一个良好的近似，尽管后验具有偏态特性。

### 10.2.2.3 示例：用于 GMM 的 ADVI

在本节中，我们使用 ADVI 来近似高斯混合模型参数的后验。与第 10.3.6 节的 VBEM 算法的区别在于，我们将 ADVI 与高斯变分后验相结合，而不是使用由共轭分布乘积定义的平均场近似。

要应用 ADVI，我们解析地边缘化掉离散局部隐变量 \(m_n \in \{1, \dots, K\}\)，因此似然的形式为

```
\(p(\mathcal{D}|\boldsymbol{\theta}) = \prod_{n=1}^N \left[ \sum_{k=1}^K \pi_k \mathcal{N}(\mathbf{y}_n | \boldsymbol{\mu}_k, \text{diag}(\boldsymbol{\Sigma}_k)) \right]\) (10.64)
```

我们为 \(\boldsymbol{\mu}_k\) 使用非信息性高斯先验，为 \(\mathbf{L}_k\) 使用均匀 LKJ 先验，为 \(\boldsymbol{\sigma}_k\) 使用对数正态先验，并为混合权重 \(\boldsymbol{\pi}\) 使用均匀 Dirichlet 先验。（有关 STAN 语法中模型的定义，请参见 [Kuc+16, Fig 21]。）未约束参数的后验近似是块对角高斯分布。\(q(\mathbf{u}) = \mathcal{N}(\mathbf{u}|\boldsymbol{\psi}_\mu, \boldsymbol{\psi}_\Sigma)\)，其中未约束参数是使用合适的双射计算的（有关详细信息，请参见代码）。

我们将此方法应用于图 10.12 中的 Old Faithful 数据集，使用 \(K=10\) 个混合成分。结果如图 10.7 所示。在左上角，我们展示了一种特殊情况，即通过设置 \(\boldsymbol{\psi}_\Sigma = \mathbf{0}\) 将后验约束为 MAP 估计。我们发现后验中没有稀疏性，因为边缘化掉参数时没有贝叶斯“奥卡姆剃刀”。在面板 c-d 中，我们展示了后验的 3 个样本。我们发现贝叶斯方法强烈偏好只有 2 个混合成分，尽管对其他一些高斯成分有少量支持（由淡椭圆显示）。

## 10.2.3 黑盒变分推理

在本节中，我们假设可以逐点计算 \(\tilde{\mathcal{L}}(\boldsymbol{\psi}, \boldsymbol{z}) = \log p(\boldsymbol{z}, \boldsymbol{x}) - \log q_{\boldsymbol{\psi}}(\boldsymbol{z})\)，但不假设可以对该函数求梯度。（例如，\(\boldsymbol{z}\) 可能包含离散变量。）因此，我们将模型视为“黑盒”。因此，这种方法称为 **黑盒变分推理** 或 **BBVI** [RGB14; ASD20]。

### 10.2.3.1 使用 REINFORCE 估计梯度

为了估计 ELBO 的梯度，我们将使用 **评分函数估计器**，也称为 **REINFORCE** 估计器（第 6.3.4 节）。特别是，假设我们将 ELBO 写为

\(\mathfrak{L}(\boldsymbol{\psi}) = \mathbb{E}_{q(\boldsymbol{z}|\boldsymbol{\psi})} \left[ \tilde{\mathcal{L}}(\boldsymbol{\psi}, \boldsymbol{z}) \right] = \mathbb{E}_{q(\boldsymbol{z}|\boldsymbol{\psi})} [\log p(\boldsymbol{x}, \boldsymbol{z}) - \log q(\boldsymbol{z}|\boldsymbol{\psi})]\) (10.65)

然后根据公式 (6.58) 我们有

\(\nabla_{\boldsymbol{\psi}} \mathfrak{L}(\boldsymbol{\psi}) = \mathbb{E}_{q(\boldsymbol{z}|\boldsymbol{\psi})} \left[ \tilde{\mathcal{L}}(\boldsymbol{\psi}, \boldsymbol{z}) \nabla_{\boldsymbol{\psi}} \log q(\boldsymbol{z}|\boldsymbol{\psi}) \right]\) (10.66)

然后我们可以计算这一点的蒙特卡洛近似：

$$\widehat{\nabla_\psi \mathbb{L}(\psi_t)} = \frac{1}{S} \sum_{s=1}^S \tilde{\mathcal{L}}(\psi, z_s) \nabla_\psi \log q_\psi(z_s)|_{\psi=\psi_t}$$

我们可以将其传递给任何类型的梯度优化器，例如 SGD 或 Adam。

### 10.2.3.2 使用控制变量减少方差

在实践中，该估计器的方差相当大，因此使用控制变量或 CV 等方法很重要（第 6.3.4.1 节）。为了了解其工作原理，请考虑公式 (10.67) 中的朴素梯度估计器，对于第 $i$ 个分量，我们可以将其写为

$$\nabla_{\psi_i} \widehat{\mathbb{L}(\psi_t)}^{\text{naive}} = \frac{1}{S} \sum_{s=1}^S \tilde{g}_i(z_s)$$

$$\tilde{g}_i(z_s) = g_i(z_s) \times \tilde{\mathcal{L}}(\psi, z_s) \qquad g_i(z_s) = \nabla_{\psi_i} \log q_\psi(z_s)$$

该控制变量版本可以通过用以下内容替换 \(\tilde{g}_i(z_s)\) 来获得：

$$\tilde{g}_i^{cv}(z) = \tilde{g}_i(z) + c_i(\mathbb{E}[b_i(z)] - b_i(z))$$

其中 \(b_i(z)\) 是基线函数，\(c_i\) 是某个常数，将在下面指定。一个方便的基线是评分函数，\(b_i(z) = \nabla_{\psi_i} \log q_\psi(z) = g_i(z)\)，因为它与 \(\tilde{g}_i(z)\) 相关，并且具有 \(\mathbb{E}[b_i(z)] = \mathbf{0}\) 的性质，因为评分函数的期望值为零，如我们在公式 (3.44) 中所示。因此

$$\tilde{g}_i^{cv}(z) = \tilde{g}_i(z) - c_i g_i(z) = g_i(z)(\tilde{\mathcal{L}}(\psi, z) - c_i)$$

所以 CV 估计器由以下公式给出

$$\nabla_{\psi_i} \widehat{\mathbb{L}(\psi_t)}^{cv} = \frac{1}{S} \sum_{s=1}^S g_i(z_s) \times (\tilde{\mathcal{L}}(\psi, z_s) - c_i)$$

可以证明，最小化 CV 估计器方差的最优 \(c_i\) 为

$$c_i = \frac{\text{Cov}[g_i(z) \tilde{\mathcal{L}}(\psi, z), g_i(z)]}{\mathbb{V}[g_i(z)]}$$

有关更多详细信息，请参见例如 [TND21]。

## 10.3 坐标上升变分推理

变分推理中的一种常见近似是假设所有隐变量都是独立的，即，

$$q_\psi(z) = \prod_{j=1}^J q_j(z_j)$$

其中 \( J \) 是隐变量的数量，\( q_j(z_j) \) 是 \( q_{\psi_j}(z_j) \) 的简写，其中 \(\psi_j\) 是第 \( j \) 个分布的变分参数。这称为 **平均场** 近似。

根据公式 (10.11)，ELBO 变为

\(\mathrm{L}(\psi) = \int q_\psi(\mathbf{z}) \log p_\theta(\mathbf{x}, \mathbf{z}) d\mathbf{z} + \sum_{j=1}^J \mathbb{H}(q_j)\)

因为乘积分布的熵是乘积中每个组件的熵之和。
第一项也通常根据图形模型的马尔可夫特性进行分解。
这使我们可以使用坐标上升优化方案来估计每个 \(\psi_j\)，如第 10.3.1 节所述。这称为 **坐标上升变分推理** 或 **CAVI**，是基于梯度的变分推理的一种替代方法。

### 10.3.1 CAVI 算法推导

在本节中，我们推导坐标上升变分推理（CAVI）过程。
为了推导更新方程，我们最初假设只有 3 个离散隐变量，以简化符号。在这种情况下，ELBO 由以下公式给出

\(\mathrm{L}(q_1, q_2, q_3) = \sum_{z_1} \sum_{z_2} \sum_{z_3} q_1(z_1)q_2(z_2)q_3(z_3) \log \tilde{p}(z_1, z_2, z_3) + \sum_{j=1}^3 \mathbb{H}(q_j)\)

为了简洁，我们定义 \(\tilde{p}(\mathbf{z}) = p_\theta(\mathbf{z}, \mathbf{x})\)。我们将逐一优化每个 \(q_i\)，同时保持其他项固定。

让我们来看 \(q_3\) 的目标函数：

\(\mathrm{L}_3(q_3) = \sum_{z_3} q_3(z_3) \left[ \sum_{z_1} \sum_{z_2} q_1(z_1)q_2(z_2) \log \tilde{p}(z_1, z_2, z_3) \right] + \mathbb{H}(q_3) + const\)
\(= \sum_{z_3} q_3(z_3) [g_3(z_3) - \log q_3(z_3)] + const\)

其中

\(g_3(z_3) \triangleq \sum_{z_1} \sum_{z_2} q_1(z_1)q_2(z_2) \log \tilde{p}(z_1, z_2, z_3) = \mathbb{E}_{\mathbf{z}_{-3}} [\log \tilde{p}(z_1, z_2, z_3)]\)

其中 \(\mathbf{z}_{-3} = (z_1, z_2)\) 是除了 \(z_3\) 之外的所有变量。这里 \(g_3(z_3)\) 可以解释为期望负能量（对数概率）。我们可以通过定义将其转换为未归一化概率分布

\(\tilde{f}_3(z_3) = \exp(g_3(z_3))\)

我们可以将其归一化得到

\(f_3(z_3) = \frac{\tilde{f}_3(z_3)}{\sum_{z'_3} \tilde{f}_3(z'_3)} \propto \exp(g_3(z_3))\)
