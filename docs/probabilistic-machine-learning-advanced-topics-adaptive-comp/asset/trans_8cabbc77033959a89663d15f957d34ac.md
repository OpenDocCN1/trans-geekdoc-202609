

### 4.3.2.1 Ising 模型

考虑图 4.15(b) 中的二维格点。我们可以将联合分布表示为以下公式：

$p(\boldsymbol{x}|\boldsymbol{\theta}) = \frac{1}{Z(\boldsymbol{\theta})} \prod_{i \sim j} \psi_{ij}(x_i, x_j; \boldsymbol{\theta})$

其中 $i \sim j$ 表示 $i$ 和 $j$ 是图中的邻居。这被称为 **二维格点模型**。

**Ising 模型**是上述公式的一种特例，其中变量 $x_i$ 是二进制的。此类模型常用于表示磁性材料。特别是，每个节点代表一个原子，该原子可以具有磁偶极，即 **自旋**，其处于 +1 和 -1 两种状态之一。在某些磁系统中，相邻自旋倾向于相似；在其他系统中，它们倾向于不相似。我们可以通过定义团势如下来捕捉这种相互作用：

$\psi_{ij}(x_i, x_j; \boldsymbol{\theta}) = \begin{cases} e^{J_{ij}} & \text{if } x_i = x_j \\ e^{-J_{ij}} & \text{if } x_i \neq x_j \end{cases}$

其中 $J_{ij}$ 是节点 $i$ 和 $j$ 之间的耦合强度。这被称为 **Ising 模型**。如果图中两个节点未连接，则设置 $J_{ij} = 0$。我们假设权重矩阵是对称的，因此 $J_{ij} = J_{ji}$。通常我们还假设所有边的强度相同，因此每条 $(i, j)$ 边的 $J_{ij} = J$。因此

$\psi_{ij}(x_i, x_j; J) = \begin{cases} e^J & \text{if } x_i = x_j \\ e^{-J} & \text{if } x_i \neq x_j \end{cases}$

更常见的是将 Ising 模型定义为基于能量的模型，如下所示：

$p(\boldsymbol{x}|\boldsymbol{\theta}) = \frac{1}{Z(J)} \exp(-\mathcal{E}(\boldsymbol{x}; J))$

$\mathcal{E}(\boldsymbol{x}; J) = -J \sum_{i \sim j} x_i x_j$

其中 $\mathcal{E}(\boldsymbol{x}; J)$ 是能量，我们利用了以下事实：如果 $x_i \neq x_j$，则 $x_i x_j = -1$；如果 $x_i = x_j$，则 $x_i x_j = +1$。$J$ 的大小控制了相邻位点之间的耦合强度程度，这取决于系统的（逆）温度（越冷 = 耦合越紧密 = $J$ 的绝对值越大）。

如果所有边权均为正，$J > 0$，则相邻自旋可能处于相同状态，因为如果 $x_i = x_j$，能量项会贡献 $-J < 0$，而较低能量对应更高概率。在机器学习文献中，这被称为 **关联马尔可夫网络**。在物理学文献中，这被称为 **铁磁模型**。如果权重足够强，相应的概率分布将有两个模式，对应于图 4.16a 中的两个棋盘图案。这些被称为系统的基态。

如果所有权重均为负，$J < 0$，则自旋希望与邻居不同（参见图 4.16b）。这被称为 **反铁磁** 系统，并导致一个 **受挫系统**，因为在二维格点中不可能所有邻居彼此都不同。因此相应的概率分布将有多个模式，对应于问题的不同“解”。

图 4.17 显示了不同 J > 0 的 Ising 模型的一些样本。（样本使用第 12.3.3 节讨论的吉布斯采样方法创建。）随着温度降低，分布变得不那么熵，样本的“团聚性”增加。可以证明，当格点尺寸趋于无穷时，存在一个 **临界温度** $J_c$，其下会出现许多大簇，其上会出现许多小簇。在各向同性平方格点模型的情况下，可以证明 [Geo88]：

```
$J_c = \frac{1}{2} \log(1 + \sqrt{2}) \approx 0.44$ (4.79)
```

当我们改变系统的一个参数时，全局行为的这种快速变化称为 **相变**。这可以用来解释自然系统（如水）如何在温度略有变化时突然从固体变为液体，或从液体变为气体。有关 Ising 模型统计力学的更多细节，请参见例如 [Mac03, ch 31]。

除了成对项外，通常还添加一元项 $\psi_i(x_i)$。在统计物理学中，这被称为 **外场**。得到的模型如下所示：

```
$p(\boldsymbol{x}|\boldsymbol{\theta}) = \frac{1}{Z(\boldsymbol{\theta})} \prod_i \psi_i(x_i; \boldsymbol{\theta}) \prod_{i \sim j} \psi_{ij}(x_i, x_j; \boldsymbol{\theta})$ (4.80)
```

\(\psi_i\) 项可以被视为与相邻节点的贡献无关的局部偏置项。对于二进制节点，我们可以将其定义如下：

```
\(\psi_i(x_i) = \left\{ \begin{array}{ll} e^\alpha & \text{if } x_i = +1 \\ e^{-\alpha} & \text{if } x_i = -1 \end{array} \right.\)
```

如果将其写为基于能量的模型，则有

```
\(\mathcal{E}(\mathbf{x}|\boldsymbol{\theta}) = -\alpha \sum_i x_i - J \sum_{i \sim j} x_i x_j\)
```

### 4.3.2.2 Potts 模型

在第 4.3.2.1 节中，我们讨论了 Ising 模型，它是用于定义二进制变量分布的简单二维 MRF。很容易将 Ising 模型推广到多个离散状态，\(x_i \in \{1, 2, \dots, K\}\)。如果我们对每条边使用相同的势函数，可以写成

```
\(\psi_{ij}(x_i = k, x_j = k') = e^{J_{ij}(k, k')}\)
```

其中 \(J_{ij}(k, k')\) 是一个节点具有状态 \(k\) 且其邻居具有状态 \(k'\) 时的能量。一种常见的特例是

```
\(\psi_{ij}(x_i = k, x_j = k') = \left\{ \begin{array}{ll} e^J & \text{if } k = k' \\ e^0 & \text{if } k \neq k' \end{array} \right.\)
```

这被称为 **Potts 模型**。如果定义 \(J_{\text{potts}} = 2J_{\text{ising}}\)，则 Potts 模型退化为 Ising 模型。如果 \(J > 0\)，则鼓励相邻节点具有相同标签；这是关联马尔可夫模型的一个示例。该模型的一些样本如图 4.18 所示。二维 Potts 模型的相变发生在以下值（参见 [MS96]）：

```
\(J_c = \log(1 + \sqrt{K})\)
```

我们可以扩展此模型，为每个节点添加局部证据。如果将其写为基于能量的模型，则有

```
$$\mathcal{E}(\boldsymbol{x}|\boldsymbol{\theta}) = - \sum_i \sum_{k=1}^K \alpha_k \mathbb{I}(x_i = k) - J \sum_{i \sim j} \mathbb{I}(x_i = x_j) \quad (4.86)$$
```

### 4.3.2.3 用于蛋白质结构预测的 Potts 模型

Potts 模型的一个有趣应用出现在 **蛋白质结构预测** 领域。目标是从氨基酸的一维序列预测蛋白质的三维形状。一种常见方法称为 **直接耦合分析（DCA）**。下面我们简要介绍；详情请参见 [Mor+11]。

首先，从同一蛋白质家族的一组相关氨基酸序列中计算 **多序列比对（MSA）**，这可以使用 HMM 完成，如第 29.3.2 节所述。MSA 可以表示为一个 \(N \times T\) 矩阵 \(\mathbf{X}\)，其中 \(N\) 是序列数量，\(T\) 是每个序列的长度，\(X_{ni} \in \{1, \dots, V\}\) 是序列 \(n\) 中位置 \(i\) 处的字母标识。对于蛋白质序列，\(V=21\)，表示 20 种氨基酸加上间隙字符。

一旦获得 MSA 矩阵 \(\mathbf{X}\)，我们就使用极大似然估计或某种近似（如伪似然 [Eke+13]）来拟合 Potts 模型；详情请参见第 4.3.9 节。5 拟合模型后，我们选择具有最高 \(J_{ij}\) 系数的边，其中 \(i, j \in \{1, \dots, T\}\) 是蛋白质中的位置或 **残基**。由于这些位置高度耦合，它们很可能处于物理接触状态，因为相互作用的残基必须协同进化以避免破坏蛋白质的功能（有关综述，请参见例如 [LHF17]）。这个图称为 **接触图**。一旦建立接触图，它可以作为输入用于三维结构预测算法，例如 [Xu18] 或 **AlphaFold** 系统 [Eva+18]，后者赢得了 2018 年 CASP 竞赛。此类方法使用神经网络来学习形式为 \(p(d(i,j)|\{c(i,j)\})\) 的函数，其中 \(d(i,j)\) 是残基 \(i\) 和 \(j\) 之间的三维距离，\(c(i,j)\) 是接触图。

### 4.3.2.4 Hopfield 网络

**Hopfield 网络** [Hop82] 是一个完全连接的 Ising 模型（第 4.3.2.1 节），具有对称权重矩阵 \(\mathbf{W} = \mathbf{W}^\mathsf{T}\)。相应的能量函数形式为

```
$$\mathcal{E}(\boldsymbol{x}) = - \frac{1}{2} \boldsymbol{x}^\mathsf{T} \mathbf{W} \boldsymbol{x} \quad (4.87)$$
```

其中 \(x_i \in \{-1, +1\}\)。

Hopfield 网络的主要应用是作为 **联想记忆** 或 **内容可寻址内存**。其想法是：假设我们使用一组完全观测的位向量进行训练，这些向量对应我们希望记忆的模式。（我们将在下面讨论如何做到这一点。）然后，在测试时，我们将部分模式呈现给网络。我们希望估计缺失变量；这称为 **模式补全**。也就是说，我们希望计算

```
$$\boldsymbol{x}^* = \operatorname{argmin}_\boldsymbol{x} \mathcal{E}(\boldsymbol{x}) \quad (4.88)$$
```
