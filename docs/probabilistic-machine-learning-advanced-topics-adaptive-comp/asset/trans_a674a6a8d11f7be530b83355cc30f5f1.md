### 4.2.2.3 Sigmoid 信念网

在本节中，我们考虑图 4.3a 所示形式的深度生成模型。这对应于以下联合分布：

```
\(p(\boldsymbol{x}, \boldsymbol{z}) = p(\boldsymbol{z}_2)p(\boldsymbol{z}_1|\boldsymbol{z}_2)p(\boldsymbol{x}|\boldsymbol{z}_1) = \prod_{k=1}^{K_2} p(z_{2,k}) \prod_{k=1}^{K_1} p(z_{1,k}|\boldsymbol{z}_2) \prod_{d=1}^D p(x_d|\boldsymbol{z}_1)\)
```

其中 \(\boldsymbol{x}\) 表示可见叶节点，\(\boldsymbol{z}_\ell\) 表示隐藏内部节点。（我们假设在第 \(\ell\) 级有 \(K_\ell\) 个隐藏节点，以及 \(D\) 个可见叶节点。）

现在考虑特殊情况，其中所有隐性变量都是二进制的，所有隐性 CPD 都是逻辑回归模型。即，

```
\(p(\boldsymbol{z}_\ell|\boldsymbol{z}_{\ell+1}, \boldsymbol{\theta}) = \prod_{k=1}^{K_\ell} \text{Ber}(z_{\ell,k}|\sigma(\boldsymbol{w}_{\ell,k}^\mathsf{T}\boldsymbol{z}_{\ell+1}))\)
```

其中 \(\sigma(u) = 1/(1 + e^{-u})\) 是 Sigmoid（逻辑）函数。结果称为 **Sigmoid 信念网** [Nea92]。

在底层，\(p(\boldsymbol{x}|\boldsymbol{z}_1, \boldsymbol{\theta})\)，我们使用适合我们所处理的数据类型的任何观察模型。例如，对于实值数据，我们可以使用

```
\(p(\boldsymbol{x}|\boldsymbol{z}_1, \boldsymbol{\theta}) = \prod_{d=1}^D \mathcal{N}(x_d|\boldsymbol{w}_{1,d,\mu}^\mathsf{T}\boldsymbol{z}_1, \exp(\boldsymbol{w}_{1,d,\sigma}^\mathsf{T}\boldsymbol{z}_1))\)
```

其中 \(\boldsymbol{w}_{1,d,\mu}\) 是控制第 \(d\) 个输出均值的权重，\(\boldsymbol{w}_{1,d,\sigma}\) 是控制第 \(d\) 个输出方差的权重。

我们还可以在层内隐藏变量之间添加有向连接，如图 4.3b 所示。这称为 **深度自回归网络** 或 **DARN** 模型 [Gre+14]，它结合了隐性变量建模和自回归建模的思想。

我们在第 21 章讨论其他形式的层次生成模型。

## 4.2.3 高斯贝叶斯网

考虑一个 DPGM，其中所有变量都是实值的，所有 CPD 都具有以下形式，称为线性高斯 CPD：

```
p(x_i|\mathbf{x}_{\text{pa}(i)}) = \mathcal{N}(x_i|\mu_i + \mathbf{w}_i^\mathsf{T}\mathbf{x}_{\text{pa}(i)}, \sigma_i^2) \quad (4.11)
```

如下文所示，将所有这些 CPD 相乘会得到形式为 $p(\mathbf{x}) = \mathcal{N}(\mathbf{x}|\boldsymbol{\mu}, \boldsymbol{\Sigma})$ 的大型联合高斯分布，其中 $\mathbf{x} \in \mathbb{R}^{N_G}$。这称为 **有向高斯图形模型** 或 **高斯贝叶斯网**。

我们现在解释如何推导 $\boldsymbol{\mu}$ 和 $\boldsymbol{\Sigma}$，遵循 [SK89, App. B]。为方便起见，我们将 CPD 重写为以下形式：

```
$x_i = \mu_i + \sum_{j \in \text{pa}(i)} w_{i,j}(x_j - \mu_j) + \sigma_i z_i \quad (4.12)$
```

其中 $z_i \sim \mathcal{N}(0, 1)$，$\sigma_i$ 是给定父节点时 $x_i$ 的条件标准差，$w_{i,j}$ 是 $j \to i$ 边的强度，$\mu_i$ 是局部均值。$^1$

很容易看出，全局均值只是局部均值的拼接，$\boldsymbol{\mu} = (\mu_1, \dots, \mu_{N_G})$。我们现在推导全局协方差，$\boldsymbol{\Sigma}$。令 $\mathbf{S} \triangleq \text{diag}(\boldsymbol{\sigma})$ 为包含标准差的对角矩阵。我们可以将等式 (4.12) 重写为矩阵-向量形式如下：

```
$(\mathbf{x} - \boldsymbol{\mu}) = \mathbf{W}(\mathbf{x} - \boldsymbol{\mu}) + \mathbf{S}\mathbf{z} \quad (4.13)$
```

其中 $\mathbf{W}$ 是回归权重矩阵。现在令 $\mathbf{e}$ 为噪声项向量：$\mathbf{e} \triangleq \mathbf{S}\mathbf{z}$。我们可以重排以得到 $\mathbf{e} = (\mathbf{I} - \mathbf{W})(\mathbf{x} - \boldsymbol{\mu})$。由于 $\mathbf{W}$ 是下三角矩阵（因为在拓扑排序中若 $j < i$ 则 $w_{j,i} = 0$），我们有 $\mathbf{I} - \mathbf{W}$ 是对角线为 1 的下三角矩阵。因此

```
\(\begin{pmatrix} e_1 \\ e_2 \\ \vdots \\ e_{N_G} \end{pmatrix} = \begin{pmatrix} 1 \\ -w_{2,1} & 1 \\ -w_{3,2} & -w_{3,1} & 1 \\ \vdots \\ -w_{N_G,1} & -w_{N_G,2} & \dots & -w_{N_G, N_G-1} & 1 \end{pmatrix} \begin{pmatrix} x_1 - \mu_1 \\ x_2 - \mu_2 \\ \vdots \\ x_{N_G} - \mu_{N_G} \end{pmatrix} \quad (4.14)\)
```

由于 $\mathbf{I} - \mathbf{W}$ 总是可逆的，我们可以写成

```
$\mathbf{x} - \boldsymbol{\mu} = (\mathbf{I} - \mathbf{W})^{-1}\mathbf{e} \triangleq \mathbf{U}\mathbf{e} = \mathbf{U}\mathbf{S}\mathbf{z} \quad (4.15)$
```

其中我们定义了 $\mathbf{U} = (\mathbf{I} - \mathbf{W})^{-1}$。因此协方差由以下给出

```
$\boldsymbol{\Sigma} = \text{Cov}[\mathbf{x}] = \text{Cov}[\mathbf{x} - \boldsymbol{\mu}] = \text{Cov}[\mathbf{U}\mathbf{S}\mathbf{z}] = \mathbf{U}\mathbf{S} \text{Cov}[\mathbf{z}] \mathbf{S}\mathbf{U}^\mathsf{T} = \mathbf{U}\mathbf{S}^2\mathbf{U}^\mathsf{T} \quad (4.16)$
```

因为 $\text{Cov}[\mathbf{z}] = \mathbf{I}$。

1. 如果不减去父节点的均值（即，如果使用 $x_i = \mu_i + \sum_{j \in \text{pa}(i)} w_{i,j} x_j + \sigma_i z_i$），则 $\boldsymbol{\Sigma}$ 的推导会复杂得多，如 [Bis06, p370] 所示。

## 4.2.4 条件独立性性质

我们写 $\mathbf{x}_A \perp_G \mathbf{x}_B | \mathbf{x}_C$ 如果在图 $G$ 中 $A$ 在给定 $C$ 的情况下与 $B$ 条件独立。（我们将在下面的章节中讨论如何确定给定图是否隐含这样的 CI 性质。）令 $I(G)$ 为图编码的所有此类 CI 语句的集合，令 $I(p)$ 为在某个分布 $p$ 中成立的所有此类 CI 语句的集合。我们说 $G$ 是 $p$ 的 **独立性图（I-map）**，或者说 $p$ 相对于 $G$ 是 **马尔可夫** 的，当且仅当 $I(G) \subseteq I(p)$。换句话说，如果图不做出任何与分布不符的 CI 断言，则该图是独立性图。这使得我们在推理 $p$ 的 CI 性质时可以将图作为 $p$ 的安全代用。这对于设计适用于大类分布的算法非常有帮助，无论其特定的数值参数如何。请注意，完全连接图是所有分布的独立性图，因为它根本不做任何 CI 断言，如下文所示。因此，如果 $G$ 是 $p$ 的独立性图，且不存在 $G' \subseteq G$ 是 $p$ 的独立性图，则我们说 $G$ 是 $p$ 的 **最小独立性图（minimal I-map）**。

我们现在转向如何推导 $I(G)$ 的问题，即 DAG 蕴含哪些 CI 性质。

### 4.2.4.1 全局马尔可夫性质（d-分离）

我们说一条 *无向路径* $P$ 被一组节点 $C$（包含证据）**d-分离**，当且仅当以下至少一条条件成立：

- 1. P 包含链或管道，$s \to m \to t$ 或 $s \leftarrow m \leftarrow t$，其中 $m \in C$
- 2. P 包含帐篷或分叉，$s \swarrow m \searrow t$，其中 $m \in C$
- 3. P 包含 **碰撞器** 或 **v-结构**，$s \to m \leftarrow t$，其中 $m$ 不在 $C$ 中且 $m$ 的任何后代也不在 $C$ 中。

接下来，我们说一组 *节点集* $A$ 在给定第三个观察集 $C$ 的情况下与另一组节点 $B$ d-分离，当且仅当从每个节点 $a \in A$ 到每个节点 $b \in B$ 的每条无向路径都被 $C$ d-分离。最后，我们定义 DAG 的 CI 性质如下：

```
$\mathbf{X}_A \perp_G \mathbf{X}_B | \mathbf{X}_C \iff \text{A is d-separated from B given C}$ (4.17)
```

这称为（有向）**全局马尔可夫性质**。

**Bayes 球算法** [Sha98] 是一种基于上述定义来判断 $A$ 是否在给定 $C$ 的情况下与 $B$ d-分离的简单方法。其思想如下。我们对 $C$ 中的所有节点进行“着色”，表示它们已被观察。然后在 $A$ 中的每个节点放置“球”，根据某些规则让它们“弹跳”，然后询问是否有任何球到达 $B$ 中的任何节点。图 4.4 显示了三条主要规则。请注意，球可以沿与边方向相反的方向移动。我们看到球可以穿过链，但如果中间节点着色则不能。同样，球可以穿过分叉，但如果中间节点着色则不能。然而，球不能穿过 v-结构，除非中间节点着色。

我们可以如下证明 Bayes 球的 3 条规则。首先考虑链结构 $X \to Y \to Z$，它编码了

```
$p(x, y, z) = p(x)p(y|x)p(z|y)$ (4.18)
```
