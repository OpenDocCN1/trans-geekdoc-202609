where $\tilde{x} = x - \mu$, and $\mathbf{C} = \mathbf{W}\mathbf{W}^T + \mathbf{\Psi}$. Using Equation (28.47), the Mahalanobis distance can be computed using

$\tilde{x}^T \mathbf{C}^{-1} \tilde{x} = \tilde{x}^T [\mathbf{\Psi}^{-1} \tilde{x} - \mathbf{\Psi}^{-1} \mathbf{W} \mathbf{L}^{-1} (\mathbf{W}^T \mathbf{\Psi}^{-1} \tilde{x})]$ (28.49)

which takes $O(L^3 + LD)$ to compute. From the matrix determinant lemma, the log determinant is given by

$\log \det(\mathbf{C}) = \log \det(\mathbf{L}) + \log \det(\mathbf{\Psi})$ (28.50)

which takes $O(L^3 + D)$ to compute. (See also Section 28.2.5, where we discuss fitting low-rank GMM classifiers discriminatively, which requires similar computations.)

# 28.3.1.4 Model fitting using EM

We can compute the MLE for the FA model either by performing gradient ascent on the log likelihood in Equation (28.48), or by using the EM algorithm [RT82; GH96b]. The latter can converge faster, and automatically satisfies positivity constraints on $\mathbf{\Psi}$. We give the details below, assuming that the observed data is standardized, so $\mu = 0$ for notational simplicity.

In the E step, we compute the following expected sufficient statistics:

$\mathbf{E}_{x,z} = \sum_{n=1}^N x_n \mathbb{E}[\mathbf{z} | x_n]^T$ (28.51)

$\mathbf{E}_{z,z} = \sum_{n=1}^N \mathbb{E}[\mathbf{z}\mathbf{z}^T | x_n]$ (28.52)

$\mathbf{E}_{x,x} = \sum_{n=1}^N x_n x_n^T$ (28.53)

where

$\mathbb{E}[\mathbf{z} | \mathbf{x}] = \mathbf{Bx}$ (28.54)

$\mathbb{E}[\mathbf{z}\mathbf{z}^T | \mathbf{x}] = \text{Cov}[\mathbf{z} | \mathbf{x}] + \mathbb{E}[\mathbf{z} | \mathbf{x}] \mathbb{E}[\mathbf{z} | \mathbf{x}]^T = \mathbf{I} - \mathbf{BW} + \mathbf{B}\mathbf{x}\mathbf{x}^T \mathbf{B}^T$ (28.55)

$\mathbf{B} \triangleq \mathbf{W}^T (\mathbf{\Psi} + \mathbf{W}\mathbf{W}^T)^{-1} = \mathbf{W}^T \mathbf{C}^{-1}$ (28.56)

In the M step, we have

$\mathbf{W}^{\text{new}} = \mathbf{E}_{x,z} \mathbf{E}_{z,z}^{-1}$ (28.57)

$\mathbf{\Psi}^{\text{new}} = \frac{1}{N} \text{diag}(\mathbf{E}_{x,x} - \mathbf{W}^{\text{new}} \mathbf{E}_{x,z}^T)$ (28.58)
