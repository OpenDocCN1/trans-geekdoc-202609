## 29.12.6.2 方法运行所需的假设

该方法的有效性基于 3 个假设：（1）可预测性：我们假设，给定现有数据，我们的模型可以对结果进行充分预测。（我们可以通过回溯预测来检查这一点，即对部分历史数据进行预测。）（2）不受影响性：我们假设干预不会改变未来协变量 \(\boldsymbol{x}_{n+1:m}\)。（我们可以通过将每个协变量作为结果变量来运行该方法，从而潜在地检查这一点。）（3）稳定性：我们假设，如果干预未发生，那么治疗前时期的结果模型会延续到治疗后时期。（我们可以通过查看如果将治疗时间提前是否仍会预测到效果来检查这一点。）

## 29.12.6.3 示例

作为一个具体示例，让我们假设我们有一个局部水平模型，并使用线性回归来建模对协变量的依赖关系，如第 29.12.2.3 节所示。即，

```
\( y_t = \mu_t + \beta^\mathsf{T} x_t + \mathcal{N}(0, \sigma_y^2) \) (29.159)
\( \mu_t = \mu_{t-1} + \delta_{t-1} + \mathcal{N}(0, \sigma_\mu^2) \) (29.160)
\( \delta_t = \delta_{t-1} + \mathcal{N}(0, \sigma_\delta^2) \) (29.161)
```

请参见图 29.40 中的图形模型。该模型的静态参数为 \(\boldsymbol{\theta}=(\beta,\sigma_y^2,\sigma_\mu^2,\sigma_\delta^2)\)，其他项为状态变量或观测变量。（请注意，我们可以自由使用任何类型的 STS 模型；局部水平模型只是一个简单的默认值。）

为简单起见，让我们假设我们有一个单个标量输入 \(x_t\)，以及标量输出 \(y_t\)。我们在 \(x_t\) 上使用自回归过程生成一些合成数据，然后设置 \(y_t = 1.2x_t + \epsilon_t\)。然后我们在时间步 \(t=70\) 手动干预，将 \(y_t\) 值增加 10。在图 29.41 中，我们展示了将因果影响过程应用于此数据集时的输出。在第一行中，我们看到预测输出 \(\tilde{y}_t\)（蓝色线）在 \(t \ge 70\) 时遵循模型在干预前时期学习到的一般 AR 趋势，而实际观测值 \(y_t\)（黑色线）则截然不同。因此，点对点因果影响 \(\tau_t = y_t - \tilde{y}_t\) 的后验分布在 \(t \ge 70\) 时的值约为 10。

## 29.12.6.4 与合成控制的比较

使用其他“供体”时间序列的线性组合 \(\boldsymbol{\beta}^\mathsf{T} x_t\) 与“合成控制” [Aba; Shi+21] 的概念在精神上相似。但是，我们不局限于供体的凸组合。事实上，当我们有许多协变量时，可以使用尖峰-平板先验（第 15.2.5 节）或马蹄先验（第 15.2.7 节）来选择相关的协变量。此外，即使我们只观测结果序列 \(y_t\)，而没有任何其他平行时间序列，STS 方法也可以应用。

## 29.12.7 Prophet

Prophet [TL18a] 是 Facebook 的一个流行时间序列预测库。它拟合形式为

```
$y(t) = g(t) + s(t) + h(t) + w^T x(t) + \epsilon_t$
```

的广义加法模型，其中 g(t) 是趋势函数，s(t) 是季节性波动（使用应用于正弦基集的线性回归建模），h(t) 是可选的稀疏“假日效应”集合，x(t) 是可选的（可能滞后的）协变量集合，w 是回归系数，\(\epsilon_t\) 是残差噪声项，假设为独立同分布高斯。

Prophet 是回归模型，而不是自回归模型，因为它在给定时间戳 t 和协变量 x_{1:T} 时预测时间序列 y_{1:T}，但不条件于 y 的过去观测值。为了建模对时间的依赖，趋势函数被假设为带有 S 个均匀分布在时间的变点的分段线性趋势。（有关变点检测的讨论见第 29.5.6 节。）即，模型形式为

```
$g(t) = (k + a(t)^T \delta)t + (m + a(t)^T \gamma)$
```

其中 k 是增长率，m 是偏移量，a_j(t) = I(t >= s_j)，其中 s_j 是第 j 个变点的时间，delta_t ~ Laplace(tau) 是变化幅度，gamma_j = -s_j delta_j 用于使函数连续。delta 上的拉普拉斯先验确保 MAP 参数估计是稀疏的，因此变点边界之间的差异通常为 0。

有关 Prophet 工作原理的交互式可视化，请参见 https://github.com/MBtimeseries。

## 29.12.8 神经预测方法

当数据较少时（例如，短序列或少量协变量），经典时间序列方法效果很好。但是，在某些情况下，我们有大量数据。例如，我们可能有一个非常长的单序列，例如来自实时传感器的异常检测 [Ahm+17]。或者，我们可能有多个相关序列，例如相关产品的销售 [Sal+19b]。在这两种情况下，更大的数据意味着我们可以负担得起拟合更复杂的参数模型。神经网络是一种自然选择，因为它们具有灵活性。直到最近，它们在预测任务中的表现还不如经典方法具有竞争力，但最近这种情况开始改变，如 [Ben+22; LZ20] 所述。

单变量时间序列预测文献中的一个常见基准是 M4 预测竞赛 [MSA18]，它要求参赛者对多种不同类型的（单变量）时间序列（无协变量）进行预测。这项竞赛最近由一种神经方法 [Smy20] 获胜。更准确地说，2019 年 M4 竞赛的获胜者是一种名为 ES-RNN [Smy20] 的混合 RNN-经典方法。指数平滑（ES）部分允许对当前时间序列的观测过去进行数据高效的适应；循环神经网络（RNN）部分允许从多个相关时间序列中学习非线性分量。（这被称为局部+全局模型，因为 ES 部分仅在局部时间序列上“训练”，而 RNN 则在相关时间序列的全局数据集上训练。）

在 [Ran+18] 中，他们采用了一种混合 RNN 和经典方法的不同方法，称为 DeepSSM。具体来说，他们训练一个单一的 RNN 来预测状态空间模型（见主章节 29.1）的参数。更详细地说，设 x_{1:T}^n 表示第 n 个时间序列，theta_t^n 表示线性趋势 SSM 模型（见第 29.12.1 节）的非平稳参数。我们训练一个 RNN 来计算 $\theta_t^n = f(c_{1:T}^n; \phi)$，其中 $\phi$ 是跨所有序列共享的 RNN 参数。我们可以使用预测参数通过卡尔曼滤波器计算序列的对数似然，$L_n = \log p(x_{1:T}^n | c_{1:T}^n, \theta_{1:T}^n)$。这两个模块可以结合起来，允许对 $\phi$ 进行端到端训练以最大化 $\sum_{n=1}^N L_n$。

在 [Wan+19c] 中，他们提出了一种称为 **深度因子** 的不同混合模型。其思想是将每个时间序列（或其隐函数，用于非高斯数据）表示为来自神经模型的全局时间序列与随机局部模型（例如 SSM 或 GP）的加权和。[SYD19] 的 **深度全局-局部** （全局-局部）方法提出了一种相关的混合方法，其中全局模型使用矩阵分解来学习共享因子。然后将其与时间卷积网络相结合。

也可以训练纯粹的神经模型，而不诉诸经典方法。例如，[Ore+20] 的 **N-BEATS** 模型训练一个残差网络来预测一组基函数的权重，对应于多项式趋势和周期信号。基函数的权重使用神经网络对每个输入窗口进行预测。另一种方法是 [Sal+19b] 的 **DeepAR** 模型，它将单个 RNN 拟合到大量时间序列。原始论文使用了整数（计数）时间序列，采用负二项似然函数进行建模。这是一个单峰分布，可能不适合所有任务。还提出了更灵活的形式，例如高斯混合 [Muk+18]。

一种流行的替代方法是使用 **分位回归** [Koe05]，其中模型被训练以预测分布的分位数，这可以通过优化 pinball loss 来实现（见第 14.3.2.1 节）。例如，[Gas+19] 提出了 **SQF-RNN**，它使用样条来表示分位数函数。他们使用 **CRPS** 或 **连续排名概率分数** 作为损失函数，该函数训练模型预测所有分位数。特别是，对于分位数预测器 $F^{-1}(\alpha)$，CRPS 损失定义为

$$\text{CRPS}(F^{-1}, y) = \int_0^1 2\ell_\alpha(y, F^{-1}(\alpha)) d\alpha$$

其中内层损失函数是方程 (14.53) 定义的 pinball loss。CRPS 是一个适当得分规则，但对异常值不那么敏感，并且比日志损失更具“距离感知”。对于确定性预测，CRPS 退化为绝对误差。

上述方法都预测单个输出（每个时间步）。如果存在多个同时观测，最好尝试建模它们之间的相互依赖。在 [Sal+19a] 中，他们为此使用（低秩）**高斯协方函数**，在 [Tou+19] 中，他们使用**非参数协方函数**。

在 [Wen+17] 中，他们使用扩张因果卷积（或 RNN）同时预测多步先行的分位数。他们将其方法称为 **MQ-CNN**。在 [WT19] 中，他们将其扩展为预测完整的分位数函数，以所需的分位数水平 $\alpha$ 作为输入，而不是预先指定固定的水平集合。他们还使用 copula 来学习多个单变量边缘分布之间的依赖关系。
