

如前所述，$p(\boldsymbol{u})$ 通常易于求值。因此，如果可以使用灵活的可逆变换 $\boldsymbol{f}$，其雅可比行列式 $\text{det} \mathbf{J}(\boldsymbol{f})(\boldsymbol{u})$ 可以高效计算，那么就可以构建复杂的密度 $p(\boldsymbol{x})$，这些密度允许精确采样和高效的精确似然计算。这与需要使用变分推断等方法对似然进行下界估计的潜在变量模型形成对比。

人们可能会想知道，从简单的 $p(\boldsymbol{u})$ 中采样的随机变量经变换得到的密度 $p(\boldsymbol{x})$ 有多么灵活。事实证明，我们可以使用此方法来逼近任何平滑分布。要看清这一点，请考虑基分布 $p(\boldsymbol{u})$ 为一维均匀分布的场景。回顾一下，逆变换采样（第 11.3.1 节）从均匀分布中采样随机变量，并使用累积分布函数（cdf）的逆函数对其进行变换，以从所需密度生成样本。只要变换 $\boldsymbol{f}$ 足够强大以对逆 cdf 进行建模，我们就可以使用此方法从任何一维密度中采样（对于行为良好且其 cdf 可逆且可微的密度来说，这是一个合理的假设）。我们可以先利用概率链式法则将密度 $p(\boldsymbol{x})$ 表示为一维条件分布的乘积，然后对每个一维条件分布应用逆变换采样，从而将此论证进一步扩展到多维。其结果是一个归一化流，它将均匀分布的乘积转换为所需的任意分布 $p(\boldsymbol{x})$。更详细的证明请参见 [Pap+19]。

我们如何定义雅可比行列式易于计算的灵活可逆映射？我们将在第 23.2 节中详细讨论此主题，但简而言之，主要有两种方法。第一种方法是定义一组在设计上即可逆且其雅可比行列式易于计算的简单变换；例如，如果雅可比矩阵是三角矩阵，则其行列式可以高效计算。第二种方法是利用可逆函数的复合也是可逆的，且整体雅可比行列式只是各个雅可比行列式的乘积这一事实。更准确地说，如果 $\boldsymbol{f} = \boldsymbol{f}_N \circ \cdots \circ \boldsymbol{f}_1$，其中每个 $\boldsymbol{f}_i$ 都是可逆的，那么 $\boldsymbol{f}$ 也是可逆的，其逆为 $\boldsymbol{g} = \boldsymbol{g}_1 \circ \cdots \circ \boldsymbol{g}_N$，对数雅可比行列式由以下公式给出：

```
$$\log |\text{det} \mathbf{J}(\boldsymbol{g})(\boldsymbol{x})| = \sum_{i=1}^N \log |\text{det} \mathbf{J}(\boldsymbol{g}_i)(\boldsymbol{u}_i)|$$
```

其中 $\boldsymbol{u}_i = \boldsymbol{f}_i \circ \cdots \circ \boldsymbol{f}_1(\boldsymbol{u})$ 是流的第 $i$ 个中间输出。这使我们能够从简单组件中创建复杂流，就像图形模型使我们能够从更简单的条件分布中创建复杂联合分布一样。

最后，关于术语的说明。可逆变换也称为 **双射**。可微且具有可微逆函数的双射称为 **微分同胚**。流模型的变换 $\boldsymbol{f}$ 是一个微分同胚，尽管在本章剩余部分中，为了简单起见，我们将称其为“双射”，并将可微性隐含。流模型的密度 $p_x(\boldsymbol{x})$ 也称为通过变换 $\boldsymbol{f}$ 对基分布 $p_u(\boldsymbol{u})$ 的 **前推**，有时表示为 $p_\boldsymbol{x} = \boldsymbol{f}_* p_u$。最后，在数学中，“流”一词指的是由实数 $t$ 索引的任何微分同胚族 $\boldsymbol{f}_t$，其中 $t=0$ 索引恒等函数，$t_1+t_2$ 索引 $\boldsymbol{f}_{t_2} \circ \boldsymbol{f}_{t_1}$（在物理学中，$t$ 通常表示时间）。在机器学习中，我们将“流”一词用于上述含义的类比，以强调我们可以通过复合更简单的变换来创建灵活的可逆变换；在此意义上，索引 $t$ 类似于 $\boldsymbol{f}_i \circ \cdots \circ \boldsymbol{f}_1$ 中的变换数量 $i$。

## 23.1.2 如何训练流模型

归一化流有两种常见的应用。第一种是观测数据的密度估计，通过将 \(p_\theta(\boldsymbol{x})\) 拟合到数据上，并将其作为数据密度的估计，随后可能从 \(p_\theta(\boldsymbol{x})\) 生成新数据。第二种是变分推断，涉及采样和评估由流模型参数化的变分后验 \(q_\theta(\boldsymbol{z}|\boldsymbol{x})\)。如下文所示，这些应用优化不同的目标，并对流模型施加不同的计算约束。

### 23.1.2.1 密度估计

密度估计需要最大化公式 (23.2) 中的似然函数。这要求我们能够对任何给定的 \(\boldsymbol{x}\) 高效求值逆流 \(\boldsymbol{u} = \boldsymbol{f}^{-1}(\boldsymbol{x})\) 及其雅可比行列式 \(\det \mathbf{J}(\boldsymbol{f}^{-1})(\boldsymbol{x})\)。优化模型后，可以选择使用它来生成新数据。要采样新点，我们需要前向映射 \(\boldsymbol{f}\) 可处理。

### 23.1.2.2 变分推断

归一化流通常用于变分推断，以参数化潜在变量模型中的近似后验分布，如第 10.4.3 节所述。考虑具有连续潜在变量 \(\boldsymbol{z}\) 和可观测变量 \(\boldsymbol{x}$ 的潜在变量模型。为简单起见，我们将模型参数视为固定，因为我们有兴趣用归一化流 \(q_\theta(\boldsymbol{z}|\boldsymbol{x})^1\) 来近似真实后验 \(p^*(\boldsymbol{z}|\boldsymbol{x})$。如第 10.1.1.2 节所述，变分参数通过最大化证据下界（ELBO）进行训练，给出如下

```
\(L(\boldsymbol{\theta}) = \mathbb{E}_{q_\theta(\boldsymbol{z}|\boldsymbol{x})} [\log p(\boldsymbol{x}|\boldsymbol{z}) + \log p(\boldsymbol{z}) - \log q_\theta(\boldsymbol{z}|\boldsymbol{x})]\)
```

将 ELBO 视为 \(\boldsymbol{\theta}$ 的函数时，它可以简化如下（为简单起见，我们丢弃了对 \(\boldsymbol{x}$ 的依赖）：

```
\(L(\boldsymbol{\theta}) = \mathbb{E}_{q_\theta(\boldsymbol{z})} [\ell_\theta(\boldsymbol{z})] .\)
```

设 \(q_\theta(\boldsymbol{z})$ 表示具有基分布 \(q(\boldsymbol{u})$ 和变换 \(\boldsymbol{z} = f_\theta(\boldsymbol{u})$ 的归一化流。然后，重参数化技巧（第 6.3.5 节）允许我们使用随机梯度优化参数。为此，我们首先将基分布上的期望写为：

```
\(L(\boldsymbol{\theta}) = \mathbb{E}_{q_\theta(\boldsymbol{z})} [\ell_\theta(\boldsymbol{z})] = \mathbb{E}_{q(\boldsymbol{u})} [\ell_\theta(f_\theta(\boldsymbol{u}))] .\)
```

然后，由于基分布不依赖于 \(\boldsymbol{\theta}$，我们可以按如下方式获得随机梯度：

```
\(\nabla_\theta L(\boldsymbol{\theta}) = \mathbb{E}_{q(\boldsymbol{u})} [\nabla_\theta \ell_\theta(f_\theta(\boldsymbol{u}))] \approx \frac{1}{N} \sum_{n=1}^N \nabla_\theta \ell_\theta(f_\theta(\boldsymbol{u}_n)) ,\)
```

其中 \(\{\boldsymbol{u}_n\}_{n=1}^N$ 是来自 \(q(\boldsymbol{u})$ 的样本。

1. 此处我们用 \(\boldsymbol{\theta}$ 表示变分后验的参数，这不应与其他地方通常也用 \(\boldsymbol{\theta}$ 表示的模型参数混淆。
