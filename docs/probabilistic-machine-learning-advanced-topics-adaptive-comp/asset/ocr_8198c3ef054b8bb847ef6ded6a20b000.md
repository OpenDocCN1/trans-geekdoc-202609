# 15.2.6 Laplace prior (Bayesian lasso)

A computationally cheap way to achieve sparsity is to perform MAP estimation with a Laplace prior by minimizing the penalized negative log likelihood:

```
PNLL(w) = -log p(D|w) - log p(w|\lambda) = ||Xw - y||_2^2 + \lambda ||w||_1 (15.89)
```

where ||w||_1 \\triangleq \\sum_{d=1}^D |w_d| is the \\ell_1 norm of w. This method is called lasso, which stands for “least absolute shrinkage and selection operator” [Tib96]. See Section 11.4 of the prequel to this book, [Mur22], for details.

In this section, we discuss posterior inference with this prior; this is known as the Bayesian lasso [PC08]. In particular, we assume the following prior:

```
p(w|\sigma^2) = \prod_j \frac{\lambda}{2\sqrt{\sigma^2}} e^{-\lambda|w_j|/\sqrt{\sigma^2}} (15.90)
```

(Note that conditioning the prior on \sigma^2 is important to ensure that the full posterior is unimodal.)
