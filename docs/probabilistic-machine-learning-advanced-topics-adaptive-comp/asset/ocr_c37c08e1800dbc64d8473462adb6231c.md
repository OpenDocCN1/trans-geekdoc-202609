# Algorithm 8.1: Functions for a linear Gaussian system.

```
1 def GaussMoments(\(\tilde{\mu}, \tilde{\Sigma}, \mathbf{A}, \mathbf{b}, \mathbf{\Omega}\)) :
2   \(\bar{\mu} = \mathbf{A} \tilde{\mu} + \mathbf{b}\)
3   \(\mathbf{S} = \mathbf{\Omega} + \mathbf{A} \tilde{\Sigma} \mathbf{A}^T\)
4   \(\mathbf{C} = \tilde{\Sigma} \mathbf{A}^T\)
5   Return (\(\bar{\mu}, \mathbf{S}, \mathbf{C}\))
6 def GaussCondition(\(\tilde{\mu}, \tilde{\Sigma}, \bar{\mu}, \mathbf{S}, \mathbf{C}, \mathbf{y}\)) :
7   \(\mathbf{K} = \mathbf{C} \mathbf{S}^{-1}\)
8   \(\tilde{\mu} = \tilde{\mu} + \mathbf{K}(\mathbf{y} - \bar{\mu})\)
9   \(\tilde{\Sigma} = \tilde{\Sigma} - \mathbf{K} \mathbf{S} \mathbf{K}^T\)
10 \(\ell = \log \mathcal{N}(\mathbf{y} | \bar{\mu}, \mathbf{S})\)
11 Return (\(\tilde{\mu}, \tilde{\Sigma}, \ell\))
```

from which we get the marginal distribution

\(p(\mathbf{z}_t | \mathbf{y}_{1:t-1}) = \mathcal{N}(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1})\)

In the update step, we compute the joint distribution

\(p(\mathbf{z}_t, \mathbf{y}_t | \mathbf{y}_{1:t-1}) = \mathcal{N} \left( \begin{pmatrix} \boldsymbol{\mu}_{t|t-1} \\ \bar{\boldsymbol{\mu}}_t \end{pmatrix}, \begin{pmatrix} \boldsymbol{\Sigma}_{t|t-1} & \mathbf{C}_t \\ \mathbf{C}_t^T & \mathbf{S}_t \end{pmatrix} \right)\)

\((\hat{\mathbf{y}}_t, \mathbf{S}_t, \mathbf{C}_t) = \mathbf{GaussMoments}(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \mathbf{H}_t, \mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t, \mathbf{R}_t)\)

We then condition this on the observations to get the posterior distribution

\(p(\mathbf{z}_t | \mathbf{y}_t, \mathbf{y}_{1:t-1}) = p(\mathbf{z}_t | \mathbf{y}_{1:t}) = \mathcal{N}(\boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t})\)

\((\boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t}, \ell_t) = \mathbf{GaussCondition}(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \hat{\mathbf{y}}_t, \mathbf{S}_t, \mathbf{C}_t, \mathbf{y}_t)\)

The overall KF algorithm is shown in Algorithm 8.2.

# Algorithm 8.2: Kalman filter.

```
1 def KF(\(\mathbf{F}_{1:T}, \mathbf{B}_{1:T}, \mathbf{b}_{1:T}, \mathbf{Q}_{1:T}, \mathbf{H}_{1:T}, \mathbf{D}_{1:T}, \mathbf{d}_{1:T}, \mathbf{R}_{1:T}, \mathbf{u}_{1:T}, \mathbf{y}_{1:T}, \boldsymbol{\mu}_{0|0}, \boldsymbol{\Sigma}_{0|0}\)) :
2   foreach t = 1 : T do
3     // Predict:
4     (\(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \text{--}\)) = GaussMoments(\(\boldsymbol{\mu}_{t-1|t-1}, \boldsymbol{\Sigma}_{t-1|t-1}, \mathbf{F}_t, \mathbf{B}_t \mathbf{u}_t + \mathbf{b}_t, \mathbf{Q}_t\))
5     // Update:
6     (\(\bar{\boldsymbol{\mu}}, \mathbf{S}, \mathbf{C}\)) = GaussMoments(\(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \mathbf{H}_t, \mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t, \mathbf{R}_t\))
7     (\(\boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t}, \ell_t\)) = GaussCondition(\(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \bar{\boldsymbol{\mu}}, \mathbf{S}, \mathbf{C}, \mathbf{y}\))
8   Return (\(\boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t}\))_{t=1}^T, \(\sum_{t=1}^T \ell_t\)
```
