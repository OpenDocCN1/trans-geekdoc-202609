域泛化（DG）与多任务学习类似，但在我们想要预测的内容上有所不同。具体来说，在 DG 中，我们只关心目标分布上的预测精度，而不关心 J 个训练分布。此外，我们假设没有来自目标分布的任何标记数据。因此，我们必须对 p^t(x, y) 与 j = 1 : J 的 p^j(x, y) 之间的关系做出一些假设。

正式化这一点的一种方法是创建一个分层贝叶斯模型，如 [Bax00] 所提议并在图 19.13 中所示。这编码了这样的假设：p^t(x, y) = p(x|phi^t)p(y|x, w^t)，其中 w^t 源自所有分布共享的常见“总体水平”模型 w^0，phi^t 亦然。（但是请注意，在判别模型中，我们不需要建模 p(x|phi^t)。）有关分层贝叶斯 GLM 的讨论，请参见第 15.5 节；有关分层贝叶斯 MLP 的讨论，请参见第 17.6 节。

已为 DG 提出了许多其他技术。但是，请注意，[GLP21] 发现这些方法中没有一种始终优于在所有提供的数据集上进行经验风险最小化的基线方法。有关更多信息，请参见例如 [GLP21; She+21; Wan+21; Chr+21]。

## 19.6.3 不变风险最小化

域泛化中备受关注的一种方法称为**不变风险最小化**或 **IRM** [Arj+19]。目标是学习一个在所有环境中都表现良好，但不太依赖于第 19.2.1 节讨论的那种“虚假特征”的预测器。

IRM 是早期一种称为**不变因果预测**（ICP）[PBM16b]方法的扩展。这使用假设检验方法来找出在每个环境中直接导致结果的预测器（特征）集合，而不是间接原因特征或仅与结果相关的特征。有关示意图，请参见图 19.14。

在 [Arj+19] 中，他们提出了 ICP 的扩展以处理高维输入的情况，其中各个变量没有任何因果含义（例如，它们对应于像素）。他们的方法需要找到一个在所有环境中平均表现良好，同时对每个单独环境也是最优的预测器。也就是说，我们想要找到

\(f^* = \operatorname{argmin}_{f \in \mathcal{F}} \sum_{j=1}^J \frac{1}{N_j} \sum_{n=1}^{N_j} \ell(\boldsymbol{y}_n^j, f(\boldsymbol{x}_n^j))\) (19.26)

\(\text{such that } f \in \operatorname{argmin}_{g \in \mathcal{F}} \frac{1}{N_j} \sum_{n=1}^{N_j} \ell(\boldsymbol{y}_n^j, g(\boldsymbol{x}_n^j)) \text{ for all } j \in \mathcal{E}\) (19.27)

其中 E 是环境集合，F 是预测函数集合。其背后的直觉如下：在任何给定环境中，可能有许多函数能够实现较低的经验损失，因为问题可能是欠指定的，但如果我们选择在所有环境中也能良好工作的那个函数，它更有可能依赖于因果特征而非虚假特征。

不幸的是，最近的研究表明，IRM 原理对于协变偏移通常效果不佳，无论在理论 [RRR21] 还是实践 [GLP21] 中都是如此，尽管它在某些反因果（生成）模型 [Ahu+21] 中可以工作良好。

## 19.6.4 元学习

元学习的目标是“学习学习算法”[TP97]。一种常见的做法是向元学习者提供来自不同分布的一组数据集。这与域泛化（第 19.6.2 节）非常相似，区别在于我们将每个训练分布划分为训练集和测试集，以便我们可以“练习”从训练集学习泛化到测试集。有关元学习的一般综述可见 [Hos+20a]。这里我们基于 [Gor+19] 提出的分层贝叶斯框架，给出一个统一的总结。

### 19.6.4.1 将元学习作为预测的概率推断

我们假设有 \(J\) 个任务（分布），每个任务都有一个训练集 \(\mathcal{D}_{train}^j = \{(\boldsymbol{x}_n^j, \boldsymbol{y}_n^j) : n=1:N^j\}\) 和一个测试集 \(\mathcal{D}_{test}^j = \{(\tilde{\boldsymbol{x}}_m^j, \tilde{\boldsymbol{y}}_m^j) : m=1:M^j\}\)。此外，\(\boldsymbol{w}^j\) 是特定于任务的参数，\(\boldsymbol{w}^0\) 是共享参数，如图 19.15 所示。这与图 19.13 中的域泛化模型非常相似，除了两个不同之处：首先，由于使用盘式表示法存在微不足道的区别；其次，在元学习中，我们对所有分布都有训练和测试分区，而在 DG 中，我们只有目标分布的测试集。

我们将对全局参数 \(\boldsymbol{w}^0\) 学习一个点估计，因为它在所有数据集中共享，因此不确定性很小。但是，我们将为 \(\boldsymbol{w}^j\) 计算一个近似后验，因为每个任务通常数据很少。我们用 \(p(\boldsymbol{w}^j|\mathcal{D}_{train}^j, \boldsymbol{w}^0)\) 表示这个后验。从此，我们可以计算每个任务的后验预测分布：

\(p(\tilde{\boldsymbol{y}}^j|\tilde{\boldsymbol{x}}^j, \mathcal{D}_{train}^j, \boldsymbol{w}^0) = \int p(\tilde{\boldsymbol{y}}^j|\tilde{\boldsymbol{x}}^j, \boldsymbol{w}^j)p(\boldsymbol{w}^j|\mathcal{D}_{train}^j, \boldsymbol{w}^0)d\boldsymbol{w}^j\) (19.28)

![](img/ca72c1626f4850f058a9edc138c1ac73_779_0.png)

图 19.15：用于元学习的分层贝叶斯模型。有 $J$ 个任务，每个任务都有一个训练集 $\mathcal{D}^j = \{(\boldsymbol{x}_n^j, \boldsymbol{y}_n^j) : n = 1 : N^j\}$ 和一个测试集 $\mathcal{D}_{\text{test}}^j = \{(\tilde{\boldsymbol{x}}_m^j, \tilde{\boldsymbol{y}}_m^j) : m = 1 : M^j\}$。$\boldsymbol{w}^j$ 是特定于任务的参数，$\boldsymbol{\theta}$ 是共享参数。改编自 [Gor+19] 的图 1。

由于计算后验通常是不可处理的，我们将学习预测分布的摊销近似（参见第 10.1.5 节），记为 $q_\phi(\tilde{\boldsymbol{y}}|\tilde{\boldsymbol{x}}, \mathcal{D}_{\text{train}}^j, \boldsymbol{w}^0)$。我们选择先验 $\boldsymbol{w}^0$ 和推理网络 $\boldsymbol{\phi}$ 的参数，以使这个预测后验对任何给定的输入数据集尽可能准确：
\(\boldsymbol{\phi}^* = \text{argmin}_{\boldsymbol{\phi}} \mathbb{E}_{p(\mathcal{D}_{\text{train}}, \tilde{\boldsymbol{x}})} \left[ D_{\text{KL}} \left( p(\tilde{\boldsymbol{y}}|\tilde{\boldsymbol{x}}, \mathcal{D}_{\text{train}}, \boldsymbol{w}^0) \| q_\phi(\tilde{\boldsymbol{y}}|\tilde{\boldsymbol{x}}, \mathcal{D}_{\text{train}}, \boldsymbol{w}^0) \right) \right]\) (19.29)
\(= \text{argmin}_{\boldsymbol{\phi}} \mathbb{E}_{p(\mathcal{D}_{\text{train}}, \tilde{\boldsymbol{x}})} \left[ \mathbb{E}_{p(\tilde{\boldsymbol{y}}|\tilde{\boldsymbol{x}}, \mathcal{D}_{\text{train}}, \boldsymbol{w}^0)} \left[ \log q_\phi(\tilde{\boldsymbol{y}}|\tilde{\boldsymbol{x}}, \mathcal{D}_{\text{train}}, \boldsymbol{w}^0) \right] \right]\) (19.30)
\(= \text{argmin}_{\boldsymbol{\phi}} \mathbb{E}_{p(\mathcal{D}_{\text{train}}, \tilde{\boldsymbol{x}}, \tilde{\boldsymbol{y}})} \left[ \log \int p(\tilde{\boldsymbol{y}}|\tilde{\boldsymbol{x}}, \boldsymbol{w}) q_\phi(\boldsymbol{w} | \mathcal{D}_{\text{train}}, \boldsymbol{w}^0) d\boldsymbol{w} \right]\) (19.31)

此处我们做了近似 \(p(\tilde{\boldsymbol{y}}|\tilde{\boldsymbol{x}}, \mathcal{D}_{\text{train}}, \boldsymbol{w}^0) \approx p(\tilde{\boldsymbol{y}}|\tilde{\boldsymbol{x}}, \mathcal{D}_{\text{train}})\)。然后，我们可以通过从 $p(\mathcal{D})$ 中采样 $J$ 个任务（分布），每个任务都被划分为训练集和测试集，\(\{(\mathcal{D}_{\text{train}}^j, \mathcal{D}_{\text{test}}^j) \sim p(\mathcal{D}) : j = 1 : J\}\)，其中 \(\mathcal{D}_{\text{test}}^j = \{(\tilde{\boldsymbol{x}}_m, \tilde{\boldsymbol{y}}_m)\}\)，来对外部期望进行蒙特卡洛近似。我们可以通过从特定于任务的参数后验 \(\boldsymbol{w}_s^j \sim q_\phi(\boldsymbol{w}^j | \mathcal{D}^j, \boldsymbol{w}^0)$ 中抽取 $S$ 个样本，来对内部期望（积分）进行 MC 近似。生成的目标函数如下形式（为简化记号，我们假设每个测试集有 $M$ 个样本）：

\(\mathcal{L}_{\text{meta}}(\boldsymbol{w}^0, \boldsymbol{\phi}) = \frac{1}{MJ} \sum_{m=1}^M \sum_{j=1}^J \log \left( \frac{1}{S} \sum_{s=1}^S p(\tilde{\boldsymbol{y}}_m^j | \tilde{\boldsymbol{x}}_m^j, \boldsymbol{w}_s^j) \right)\) (19.32)

请注意，这与标准的（摊销的）变分推断不同，后者侧近似给定任务所有数据的参数后验的预期准确性，\(\mathcal{D}_{\text{all}}^j = \mathcal{D}_{\text{train}}^j \cup \mathcal{D}_{\text{test}}^j$，而不是侧于给定训练集的测试集预测准确性。
