The parameters of the joint filtering predictive distribution, $p(z_t, z_{t+1}|y_{1:t})$, take precisely the same form as those in the filtering derivation described in Section 8.2.4.2:

$\eta_{t,t+1|t} = \begin{pmatrix} \eta_{t|t} \\ 0 \end{pmatrix}, \quad \Lambda_{t,t+1|t} = \begin{pmatrix} \Lambda_{t|t} + F_{t+1}^T Q_{t+1}^{-1} F_{t+1} & -F_{t+1}^T Q_{t+1}^{-1} \\ -Q_{t+1}^{-1} F_{t+1} & Q_{t+1}^{-1} \end{pmatrix}, \quad (8.120)$

We can now update this potential function by subtracting out the filtered information and adding in the smoothing information, using the rules for manipulating Gaussian potentials described in Section 2.3.3:

$\eta_{t,t+1|T} = \eta_{t,t+1|t} + \begin{pmatrix} 0 \\ \eta_{t+1|T} \end{pmatrix} - \begin{pmatrix} 0 \\ \eta_{t+1|t} \end{pmatrix} = \begin{pmatrix} \eta_{t|t} \\ \eta_{t+1|T} - \eta_{t+1|t} \end{pmatrix}, \quad (8.121)$

and

$\Lambda_{t,t+1|T} = \Lambda_{t,t+1|t} + \begin{pmatrix} 0 & 0 \\ 0 & \Lambda_{t+1|T} \end{pmatrix} - \begin{pmatrix} 0 & 0 \\ 0 & \Lambda_{t+1|t} \end{pmatrix} \quad (8.122)$

$= \begin{pmatrix} \Lambda_{t|t} + F_{t+1}^T Q_{t+1}^{-1} F_{t+1} & -F_{t+1}^T Q_{t+1}^{-1} \\ -Q_{t+1}^{-1} F_{t+1} & Q_{t+1}^{-1} + \Lambda_{t+1|T} - \Lambda_{t+1|t} \end{pmatrix} \quad (8.123)$

Applying the information form marginalization formula Equation (2.85) leads to Equation (8.115) and Equation (8.113).

# 8.3 Inference based on local linearization

In this section, we extend the Kalman filter and smoother to the case where the system dynamics and/or the observation model are nonlinear. (We continue to assume that the noise is additive Gaussian, as in Equation (8.15).) The basic idea is to linearize the dynamics and observation models about the previous state estimate using a first order Taylor series expansion, and then to apply the standard Kalman filter equations from Section 8.2.2. Intuitively we can think of this as approximating a stationary non-linear dynamical system with a non-stationary linear dynamical system. This approach is called the **extended Kalman filter** or **EKF**.

# 8.3.1 Taylor series expansion

Suppose $x \sim \mathcal{N}(\mu, \Sigma)$ and $y = g(x)$, where $g : \mathbb{R}^n \to \mathbb{R}^m$ is a differentiable and invertible function. The pdf for $y$ is given by

$p(y) = |\det \text{Jac}(g^{-1})(y)| \mathcal{N}(g^{-1}(y)|\mu, \Sigma) \quad (8.124)$

In general this is intractable to compute, so we seek an approximation.

Suppose $x = \mu + \delta$, where $\delta \sim \mathcal{N}(0, \Sigma)$. Then we can form a first order Taylor series expansion of the function $g$ as follows:

$g(x) = g(\mu + \delta) \approx g(\mu) + G(\mu)\delta \quad (8.125)$

where $G(\mu) = \text{Jac}(g)(\mu)$ is the Jacobian of $g$ at $\mu$:

$[G(\mu)]_{jj'} = \frac{\partial g_j(x)}{\partial x_{j'}}|_{x=\mu} \quad (8.126)$
