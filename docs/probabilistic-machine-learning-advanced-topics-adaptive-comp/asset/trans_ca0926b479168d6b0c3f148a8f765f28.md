乍一看，计算每个索引似乎需要 $O(N)$ 时间，总时间为 $O(N^2)$，但如果将 $U^i$ 从小到大排序，我们可以在 $O(N)$ 时间内实现它。我们将此函数表示为 \(\mathbf{A}_{1:N} = \text{icdf}(\mathbf{W}^{1:N}, \mathbf{U}^{1:N})\)。有关 JAX 代码的示例，请参见清单 13.1。$^1$

## 清单 13.1：从有序逆累积分布函数中采样

```
def icdf(weights, u):
  n = weights.shape[0]
  cumsum = jnp.cumsum(weights)
  idx = jnp.searchsorted(cumsum, u)
  return jnp.clip(idx, 0, n - 1)
```

## 13.2.4.2 多项式重采样

在多项式重采样中，我们将 \(\mathbf{U}^{1:N}\) 设置为从均匀分布中抽取的 $N$ 个有序样本集。然后我们使用 \(\mathbf{A}_{1:N} = \text{icdf}(\mathbf{W}^{1:N}, \mathbf{U}^{1:N})$ 计算祖先索引。

尽管这是一种简单的方法，但它可能会给分布的表示引入大量方差。例如，假设所有权重都相等，$W^n = 1/N$。令 \(\mathcal{W}^n = \sum_{m=1}^N \mathbb{I}(A^m = n)$ 为粒子 $n$ 的“后代”数量（即，该粒子在重采样步骤中被选中的次数）。我们有 \(\mathcal{W}^n \sim \text{Bin}(N, 1/N)$，因此 \(P(\mathcal{W}^n = 0) = (1 - 1/N)^N \approx e^{-1} \approx 0.37$。因此，任何给定的粒子有 37% 的概率消失，尽管它们都有相同的初始权重。在下面的章节中，我们将讨论一些 **低方差重采样** 方法。

## 13.2.4.3 分层重采样

改进多项式重采样的一种简单方法是使用 **分层重采样**，其中我们将单位间隔划分为 $N_s$ 个分层，$(0, 1/N_s)$、$(1/N_s, 2/N_s)$，一直到 $(1 - 1/N_s, 1)$。然后我们生成

\(U^i \sim \text{Unif}((i-1)/N_s, i/N_s)\) \(\text{(13.34)}\)

并计算 \(\mathbf{A}_{1:N} = \text{icdf}(\mathbf{W}^{1:N}, \mathbf{U}^{1:N})$。\(^2\)

1. 修改自 https://github.com/blackjax-devs/blackjax/blob/main/blackjax/smc/resampling.py.
2. 要计算 \(\mathbf{U}^{1:N}$，我们可以使用 `v = jr.uniform(rngkey, (n,))` 和 `u = (jnp.arange(n) + v) / n`。

## 13.2.4.4 系统重采样

我们可以通过强制所有样本从共享随机源 $u \sim \text{Unif}(0, 1)$ 的确定性生成来进一步减少方差，方法是计算

```
$U^i = \frac{i - 1}{N_s} + \frac{u}{N_s}$ (13.35)
```

然后我们计算 $\mathbf{A}_{1:N} = \text{icdf}(\mathbf{W}^{1:N}, \mathbf{U}^{1:N})$。\(^3\)

3. 要计算 $\mathbf{U}^{1:N}$，我们可以使用 `v = jr.uniform(rngkey, ())` 和 `u = (jnp.arange(n) + v) / n`。

## 13.2.4.5 比较

可以证明上述所有方法都是无偏的。从经验上看，系统重采样的方差似乎比其他方法低 [HSG06]，尽管分层重采样以及 [GCW19] 中更复杂的方法具有更好的理论特性。不推荐多项式重采样，因为它被证明比其他方法具有更高的方差。

## 13.2.5 自适应重采样

重采样步骤可能导致多样性丢失，因为每个祖先可能生成多个子代，而有些可能不生成任何子代，因为祖先索引 $A_t^n$ 是独立采样的；这就是上文提到的路径退化问题。另一方面，如果我们从不重采样，最终会得到 SIS，它会遭受权重退化（权重可忽略的粒子）的问题。一种折中方法是使用 **自适应重采样**，即每当 **有效样本量** 或 **ESS** 降低到某个最小值（例如 $N/2$）以下时进行重采样。定义 ESS 的常用方法如下：\(^4\)

```
$\text{ESS}(W^{1:N}) = \frac{1}{\sum_{n=1}^N (W^n)^2}$ (13.36)
```

或者，我们可以使用未归一化权重来计算 ESS：

```
$\text{ESS}(\tilde{w}^{1:N}) = \frac{\left(\sum_{n=1}^N \tilde{w}^n\right)^2}{\sum_{n=1}^N (\tilde{w}^n)^2}$ (13.37)
```

请注意，如果我们有 $k$ 个权重为 $\tilde{w}^n = 1$ 和 $N - k$ 个权重为 $\tilde{w}^n = 0$，那么 ESS 为 $k$；因此 ESS 在 1 到 $N$ 之间。

带自适应重采样的 SISR 的伪代码见算法 13.3。（我们采用 [Law+22, App. B] 的表示法，即先采样序列的新扩展，然后在每个步骤结束时可选择重采样序列。）

## 算法 13.3：带自适应重采样的 SISR（通用 SMC）

```
1 Initialization: \(\tilde{w}_0^{1:N_s} = 1, \hat{Z}_0 = 1\)
2 for \(t=1:T\) do
3   for \(i=1:N_s\) do
4     Sample particle \(\mathbf{z}_t^i \sim q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1}^i)\)
5     Compute incremental weight \(\alpha_t^i = \frac{\tilde{\gamma}_t(\mathbf{z}_{1:t}^i)}{\tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1}^i)q_t(\mathbf{z}_t^i|\mathbf{z}_{1:t-1}^i)}\)
6     Compute unnormalized weight \(\tilde{w}_t^i = \tilde{w}_{t-1}^i \alpha_t^i\)
7 Estimate normalization constant: \(\widehat{Z_t/Z_{t-1}} = \frac{\sum_{i=1}^{N_s} \tilde{w}_t^i}{\sum_{i=1}^{N_s} \tilde{w}_{t-1}^i}, \hat{Z}_t = \hat{Z}_{t-1}(\widehat{Z_t/Z_{t-1}})\)
8 if \(ESS(\tilde{w}_{t-1}^{1:N}) < ESS_{\min}\) then
9   Compute ancestors \(\mathbf{a}_t^{1:N_s} = \text{resample}(\tilde{w}_t^{1:N_s})\)
10   Select \(\mathbf{z}_t^{1:N_s} = \text{permute}(\mathbf{a}_t^{1:N_s}, \mathbf{z}_t^{1:N_s})\)
11   Reset unnormalized weights \(\tilde{w}_t^{1:N_s} = 1/N_s\)
12 Compute normalized weights \(W_t^i = \frac{\tilde{w}_t^i}{\sum_j \tilde{w}_t^j}\) for \(i=1:N_s\)
13 Compute MC posterior \(\hat{\pi}_t(\mathbf{z}_{1:t}) = \sum_{i=1}^{N_s} W_t^i \delta(\mathbf{z}_{1:t} - \mathbf{z}_{1:t}^i)\)
```

### 13.3.1 局部最优提议

我们定义（一步）**局部最优提议分布** \(q_t^*(\mathbf{z}_t|\mathbf{z}_{1:t-1})$ 为最小化以下内容的分布：

```
\(D_\text{KL} \left( \pi_{t-1}(\mathbf{z}_{1:t-1}) q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1}) \| \pi_t(\mathbf{z}_{1:t}) \right)\) (13.38)
\(= \mathbb{E}_{\pi_{t-1} q_t} [\log \{ \pi_{t-1}(\mathbf{z}_{1:t-1}) q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1}) \} - \log \pi_t(\mathbf{z}_{1:t})]\) (13.39)
\(= \mathbb{E}_{\pi_{t-1} q_t} [\log q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1}) - \log \pi_t(\mathbf{z}_t|\mathbf{z}_{1:t-1})] + \text{const}\) (13.40)
\(= \mathbb{E}_{\pi_{t-1} q_t} [D_\text{KL} \left( q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1}) \| \pi_t(\mathbf{z}_t|\mathbf{z}_{1:t-1}) \right)] + \text{const}\) (13.41)
```

KL 通过选择以下内容来最小化：

```
\(q_t^*(\mathbf{z}_t|\mathbf{z}_{1:t-1}) = \pi_t(\mathbf{z}_t|\mathbf{z}_{1:t-1}) = \frac{\tilde{\gamma}_t(\mathbf{z}_{1:t})}{\tilde{\gamma}_t(\mathbf{z}_{1:t-1})}\) (13.42)
```

其中 \(\tilde{\gamma}_t(\mathbf{z}_{1:t-1}) = \int \tilde{\gamma}_t(\mathbf{z}_{1:t}) d\mathbf{z}_t$ 是当前目标分布下过去序列的概率。

请注意，下标 \(t$ 指定第 $t$ 个分布，因此在 SSM 的上下文中，我们有 \(\pi_t(\mathbf{z}_t|\mathbf{z}_{1:t-1}) = p(\mathbf{z}_t|\mathbf{z}_{1:t-1}, \mathbf{y}_{1:t})$。因此，当提议 \(\mathbf{z}_t$ 时，我们应该对所有数据进行条件设定，包括最近的观测 \(\mathbf{y}_t$；这称为 **引导粒子滤波器**，并将优于从先验分布中提议的 **自举滤波器**。

一般来说，计算局部最优提议是不可行的，因此我们将在下面考虑各种近似方法。

### 13.3.2 基于扩展和无迹卡尔曼滤波器的提议

近似局部最优提议分布的一种方法是基于扩展卡尔曼滤波器（第 8.3.2 节）或无迹卡尔曼滤波器（第 13.3.2 节），这分别产生扩展粒子滤波器 [DGA00] 和无迹粒子滤波器 [Mer+00]。为解释这些方法，我们遵循 [NLS19, p36] 的表述。像往常一样，我们假设动态系统可以写成 \(\mathbf{z}_t = \mathbf{f}(\mathbf{z}_{t-1}) + \mathbf{q}_t$ 和 \(\mathbf{y}_t = \mathbf{h}(\mathbf{z}_t) + \mathbf{r}_t$，其中 \(\mathbf{q}_t$ 是系统噪声，\(\mathbf{r}_t$ 是观测噪声。EKF 和 UKF 近似假设，给定第 \(i\) 个历史时，相邻时间步的联合分布为高斯分布：

\(p(\mathbf{z}_t, \mathbf{y}_t | \mathbf{z}_{1:t-1}^i) \approx \mathcal{N} \left( \begin{pmatrix} \mathbf{z}_t \\ \mathbf{y}_t \end{pmatrix} ; \hat{\boldsymbol{\mu}}^i, \hat{\boldsymbol{\Sigma}}^i \right)\) (13.43)

其中

\(\hat{\boldsymbol{\mu}}^i = \begin{pmatrix} \hat{\boldsymbol{\mu}}_z^i \\ \hat{\boldsymbol{\mu}}_y^i \end{pmatrix}, \hat{\boldsymbol{\Sigma}}^i = \begin{pmatrix} \hat{\boldsymbol{\Sigma}}_{zz}^i & \hat{\boldsymbol{\Sigma}}_{zy}^i \\ \hat{\boldsymbol{\Sigma}}_{yz}^i & \hat{\boldsymbol{\Sigma}}_{yy}^i \end{pmatrix}\) (13.44)

（详情见第 8.5.1 节。）

EKF 和 UKF 以不同方式计算 \(\hat{\boldsymbol{\mu}}^i$ 和 \(\hat{\boldsymbol{\Sigma}}^i$。在 EKF 中，我们对 \(\mathbf{f}$ 和 \(\mathbf{h}$ 进行线性化，并假设噪声项为高斯分布。然后我们对这个线性化模型精确计算 \(p(\mathbf{z}_t, \mathbf{y}_t | \mathbf{z}_{1:t-1}^i)$（参见第 8.3.1 节）。在 UKF 中，我们将 sigma 点传播通过 \(\mathbf{f}$ 和 \(\mathbf{h}$，并使用无迹变换近似得到的均值和协方差，这可能更准确（参见第 8.4 节）。一旦我们计算了 \(\hat{\boldsymbol{\mu}}^i$ 和 \(\hat{\boldsymbol{\Sigma}}^i$，就可以使用高斯条件分布的标准规则来计算近似提议，如下所示：

\(q(\mathbf{z}_t | \mathbf{z}_{1:t-1}^i, \mathbf{y}_t) \approx \mathcal{N}(\mathbf{z}_t | \boldsymbol{\mu}_t^i, \boldsymbol{\Sigma}_t^i)\) (13.45)
\(\boldsymbol{\mu}_t^i = \hat{\boldsymbol{\mu}}_z^i + \hat{\boldsymbol{\Sigma}}_{zy}^i (\hat{\boldsymbol{\Sigma}}_{yy}^i)^{-1} (\mathbf{y}_t - \hat{\boldsymbol{\mu}}_y^i)\) (13.46)
\(\boldsymbol{\Sigma}_t^i = \hat{\boldsymbol{\Sigma}}_{zz}^i - \hat{\boldsymbol{\Sigma}}_{zy}^i (\hat{\boldsymbol{\Sigma}}_{yy}^i)^{-1} \hat{\boldsymbol{\Sigma}}_{yz}^i\) (13.47)

请注意，线性化（或 sigma 点）近似需要分别对每个粒子进行。

### 13.3.3 基于拉普拉斯近似的提议

为了处理 SSM 中的非高斯似然，我们可以使用拉普拉斯近似（第 7.4.3 节），如 [DGA00] 所建议。具体来说，考虑一个具有线性高斯潜在动态和 GLM 似然的 SSM。在每个步骤中，我们计算步骤 \(t$ 的最大值 \(\mathbf{z}_t^* = \text{argmax} \log p(\mathbf{y}_t | \mathbf{z}_t)$（例如，使用 Newton-Raphson 方法），然后使用以下公式近似似然：

\(p(\mathbf{y}_t | \mathbf{z}_t) \approx \mathcal{N}(\mathbf{z}_t | \mathbf{z}_t^*, -\mathbf{H}_t^*)\) (13.48)

其中 \(\mathbf{H}_t^*$ 是众数处的对数似然的黑塞矩阵。我们现在使用卡尔曼滤波器的更新步骤计算 \(p(\mathbf{z}_t | \mathbf{z}_{t-1}^i, \mathbf{y}_t)$，使用与第 13.3.2 节相同的方程。这种组合称为拉普拉斯高斯滤波器 [Koy+10]。我们将在第 13.3.3.1 节中给出一个示例。
