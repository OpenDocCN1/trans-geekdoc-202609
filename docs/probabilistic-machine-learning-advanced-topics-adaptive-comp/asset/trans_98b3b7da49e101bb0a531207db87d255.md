## 18.6 学习核函数

在 [Mac98] 中，David MacKay 问道：“高斯过程如何取代神经网络？我们是不是把孩子和脏水一起倒掉了？” 这一评论是在 20 世纪 90 年代末提出的，正值第二波神经网络浪潮的终结。研究人员和从业者对与神经网络相关的设计决策——例如激活函数、优化程序、架构设计——以及缺乏一套原则性框架来做出这些决策感到厌倦。相比之下，高斯过程被视为灵活且原则性的概率模型，这自然源于 Radford Neal 关于无限神经网络的研究 [Nea96]，我们将在第 18.7 节中更深入地讨论这一点。然而，MacKay [Mac98] 指出，神经网络可以通过自适应隐基函数发现数据的丰富表示，而带有标准核函数（例如 RBF 核）的高斯过程本质上只是平滑工具。确实，高斯过程的泛化性能取决于核函数的适用性。学习核函数是我们使用高斯过程进行表征学习的方式，在许多情况下将对良好的性能至关重要——尤其是当我们希望进行外推，即对远离数据的位置进行预测时 [WA13; Wil+14]。如我们将看到，学习核函数在许多方面与训练神经网络类似。此外，神经网络和高斯过程可以通过深度核学习（参见第 18.6.6 节）和 NN-GP（第 18.7.2 节）等方法协同结合。

### 18.6.1 核函数参数的经验贝叶斯方法

假设，如第 18.3.2 节所示，我们使用带有 RBF 核的 GP 进行 1d 回归。由于数据包含观测噪声，核具有以下形式：

```
K_y(x_p, x_q) = \sigma_f^2 \exp(-\frac{1}{2\ell^2}(x_p - x_q)^2) + \sigma_y^2 \delta_{pq} \quad (18.161)
```

这里 \ell 是函数变化的水平尺度，\sigma_f^2 控制函数的垂直尺度，\sigma_y^2 是噪声方差。图 18.15 说明了更改这些参数的影响。我们使用 (\ell, \sigma_f, \sigma_y) = (1, 1, 0.1) 从 SE 核中采样了 20 个带噪声的数据点，然后在给定数据的条件下使用各种参数进行了预测。在图 18.15(a) 中，我们使用 (\ell, \sigma_f, \sigma_y) = (1, 1, 0.1)，结果是一个良好的拟合。在图 18.15(b) 中，我们将长度尺度增加到 \ell = 3；现在函数看起来更平滑，但我们可以说是欠拟合。

要估计核函数参数 \theta（有时称为超参数），我们可以使用离散网格值上的穷举搜索，并以验证损失为目标，但这可能非常缓慢。（这是非概率方法，例如 SVM，用于调整核函数的方法。）这里我们考虑经验贝叶斯方法，这将允许我们使用连续优化方法，速度快得多。特别是，我们将最大化边缘似然

```
$$ p(\mathbf{y}|\mathbf{X}, \boldsymbol{\theta}) = \int p(\mathbf{y}|\mathbf{f}, \mathbf{X}) p(\mathbf{f}|\mathbf{X}, \boldsymbol{\theta}) d\mathbf{f} $$
```

（之所以称其为边缘似然，而不是仅仅似然，是因为我们已经边缘化了隐含高斯向量 $\mathbf{f}$。）由于 $p(\mathbf{f}|\mathbf{X}) = \mathcal{N}(\mathbf{f}|\mathbf{0}, \mathbf{K})$，且 $p(\mathbf{y}|\mathbf{f}) = \prod_{n=1}^N \mathcal{N}(y_n|f_n, \sigma_y^2)$，边缘似然由以下给出

```
$$ \log p(\mathbf{y}|\mathbf{X}, \boldsymbol{\theta}) = \log \mathcal{N}(\mathbf{y}|\mathbf{0}, \mathbf{K}_\sigma) = -\frac{1}{2} \mathbf{y} \mathbf{K}_\sigma^{-1} \mathbf{y} - \frac{1}{2} \log |\mathbf{K}_\sigma| - \frac{N}{2} \log(2\pi) $$
```

其中 $\mathbf{K}_\sigma$ 对 $\boldsymbol{\theta}$ 的依赖是隐式的。第一项是数据拟合项，第二项是模型复杂度项，第三项只是一个常数。为了理解前两项之间的权衡，请考虑一个 1d SE 核，在改变长度尺度 $\ell$ 的同时保持 $\sigma_y^2$ 不变。设 $J(\ell) = -\log p(\mathbf{y}|\mathbf{X}, \ell)$。对于短长度尺度，拟合效果会很好，因此 $\mathbf{y}^\mathsf{T} \mathbf{K}_\sigma^{-1} \mathbf{y}$ 会很小。然而，模型复杂度会很高：$\mathbf{K}$ 将近似为对角矩阵，因为大多数点不会被认为与任何其他点“靠近”，因此 $\log |\mathbf{K}_\sigma|$ 会很大。对于长长度尺度，拟合效果会很差，但模型复杂度会很低：$\mathbf{K}$ 将近似全为 1，因此 $\log |\mathbf{K}_\sigma|$ 会很小。

我们现在讨论如何最大化边缘似然。可以证明

```
$$ \frac{\partial}{\partial \theta_j} \log p(\mathbf{y}|\mathbf{X}, \boldsymbol{\theta}) = \frac{1}{2} \mathbf{y}^\mathsf{T} \mathbf{K}_\sigma^{-1} \frac{\partial \mathbf{K}_\sigma}{\partial \theta_j} \mathbf{K}_\sigma^{-1} \mathbf{y} - \frac{1}{2} \text{tr}(\mathbf{K}_\sigma^{-1} \frac{\partial \mathbf{K}_\sigma}{\partial \theta_j}) $$ $$ = \frac{1}{2} \text{tr} \left( (\boldsymbol{\alpha} \boldsymbol{\alpha}^\mathsf{T} - \mathbf{K}_\sigma^{-1}) \frac{\partial \mathbf{K}_\sigma}{\partial \theta_j} \right) $$
```

其中 $\boldsymbol{\alpha} = \mathbf{K}_\sigma^{-1} \mathbf{y}$。计算 $\mathbf{K}_\sigma^{-1}$ 需要 $O(N^3)$ 时间，然后每个超参数需要 $O(N^2)$ 时间来计算梯度。

图 18.16: 边缘似然曲面局部极小值的示意图。(a) 我们绘制了 $\sigma_y^2$ 与 $\ell$ 相对的对数边缘似然，其中 $\sigma_f^2 = 1$ 固定，使用面板 b 和 c 中显示的 7 个数据点。(b) 对应左下角局部极小值的函数，$(\ell, \sigma_n^2) \approx (1, 0.2)$。这相当“曲折”且噪声较低。(c) 对应右上角局部极小值的函数，$(\ell, \sigma_n^2) \approx (10, 0.8)$。这相当平滑且噪声较高。数据是使用 $(\ell, \sigma_n^2) = (1, 0.1)$ 生成的。改编自 [RW06] 的图 5.5。由 gpr_demo_marglik.ipynb 生成。

$\frac{\partial \mathbf{K}_\sigma}{\partial \theta_j}$ 的形式取决于核函数的形式，以及我们正在对哪个参数求导数。通常，我们对超参数有约束，例如 $\sigma_y^2 \ge 0$。在这种情况下，我们可以定义 $\theta = \log(\sigma_y^2)$，然后使用链式法则。给定对数边缘似然及其导数的表达式，我们可以使用任何标准的基于梯度的优化器来估计核函数参数。但是，由于目标函数不是凸的，局部极小值可能是一个问题，如下面所示，因此我们可能需要使用多次重启。

#### 18.6.1.1 示例

考虑图 18.16。我们使用 $\sigma_f^2 = 1$ 的 SE 核（方程 18.161），并绘制 $\log p(\mathbf{y}|\mathbf{X}, \ell, \sigma_y^2)$（其中 $\mathbf{X}$ 和 $\mathbf{y}$ 是面板 b 和 c 中显示的 7 个数据点），在改变 $\ell$ 和 $\sigma_y^2$ 时。两个局部最优解在面板 a 中用 + 标记。左下角的最优解对应于低噪声、短长度尺度解（面板 b 中显示）。右上角的最优解对应于高噪声、长长度尺度解（面板 c 中显示）。仅有 7 个数据点时，没有足够证据有把握地决定哪个更合理，尽管更复杂的模型（面板 b）的边缘似然比更简单的模型（面板 c）高出约 60%。有更多数据时，更复杂的模型会变得更受青睐。

图 18.16 说明了一些其他有趣（且典型）的特征。$\sigma_y^2 \approx 1$ 的区域（面板 a 的顶部）对应于噪声非常高的情况；在这种情况下，边缘似然对长度尺度不敏感（由水平等高线指示），因为所有数据都被解释为噪声。$\ell \approx 0.5$ 的区域（面板 a 的左侧）对应于长度尺度非常短的情况；在这种情况下，边缘似然对噪声水平不敏感（由垂直等高线指示），因为数据被完美插值。好的优化器不会选择这两个区域中的任何一个。
