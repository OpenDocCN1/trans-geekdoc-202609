### 32.2.1.3 解缠

给定关于数据集如何生成的知识，例如存在位置、形状和颜色等生成数据的某些变化因素，我们通常希望估计在学习表示中能多大程度地恢复这些因素。这需要使用解缠表示学习方法（参见第 21.3.1.1 节）。虽然有多种解缠度量指标，但大多数衡量的是隐性因素与学习表示维度之间存在一对一对应关系的程度。

## 32.2.2 表示相似性

与其衡量表示与下游任务之间的兼容性，我们不妨直接考察两个固定表示之间的关系，而无需参照某个任务。在本节中，我们假设拥有两组对应于相同 n 个样本的固定表示。这些表示可以从同一网络的不同层或不同神经网络的层中提取，且不必具有相同的维度。为了记号方便，我们假设每组表示都按行堆叠形成矩阵 \(\mathbf{X} \in \mathbb{R}^{n \times p_1}\) 和 \(\mathbf{Y} \in \mathbb{R}^{n \times p_2}\)，使得 \(\mathbf{X}_{i,:}\) 和 \(\mathbf{Y}_{i,:}\) 是同一样本的两个不同表示。

### 32.2.2.1 表示相似性分析与中心内核对齐

表示相似性分析（RSA）是神经科学中衡量表示相似性的主导技术 [KMB08]，但也已应用于机器学习。RSA 将衡量表示矩阵之间相似性的问题简化为衡量单个样本表示之间相似性的问题。RSA 首先从每个表示中形成表示相似性矩阵（RSM）。给定用于测量单个样本表示对 \(\mathbf{x}, \mathbf{x}' \in \mathcal{X}\) 和 \(\mathbf{y}, \mathbf{y}' \in \mathcal{Y}\) 之间相似性的函数 \(k : \mathcal{X} \times \mathcal{X} \mapsto \mathbb{R}\) 及 \(k' : \mathcal{Y} \times \mathcal{Y} \mapsto \mathbb{R}\)，相应的表示相似性矩阵 \(\mathbf{K}, \mathbf{K}' \in \mathbb{R}^{n \times n}\) 包含所有样本对表示之间的相似性，即 \(\mathbf{K}_{ij} = k(\mathbf{X}_{i,:}, \mathbf{X}_{j,:})\) 和 \(\mathbf{K}'_{ij} = k'(\mathbf{Y}_{i,:}, \mathbf{Y}_{j,:})\)。这些表示相似性矩阵通过应用矩阵相似性函数 \(s(\mathbf{K}, \mathbf{K}')\) 转换为标量相似性值。RSA 框架可以通过选择相似性函数 \(k(\cdot, \cdot)\)、\(k'(\cdot, \cdot)\) 和 \(s(\cdot, \cdot)\) 来涵盖多种不同形式的相似性。如何选择这些函数是一个有争议的话题 [BS+20; Kri19]。在实践中，通常选择 \(k(\mathbf{x}, \mathbf{x}') = k'(\mathbf{x}, \mathbf{x}') = \text{corr}[\mathbf{x}, \mathbf{x}']\)，即样本之间的皮尔逊相关系数。\(s(\cdot, \cdot)\) 通常被选为表示相似性矩阵之间的斯皮尔曼秩相关系数，其计算方法是将 \(\mathbf{K}\) 和 \(\mathbf{K}'\) 重塑为向量，计算其元素的排名，并测量这些排名之间的皮尔逊相关系数。

**中心内核对齐（CKA）**是一种最初在机器学习文献中提出的技术 [Cri+02; CMR12]，但可以解释为 RSA 的一种形式。在中心内核对齐中，每个样本的相似性函数 $k$ 和 $k'$ 被选为正半定义内核，使得 $K$ 和 $K'$ 成为内核矩阵。矩阵相似性函数 $s$ 是中心内核矩阵之间的余弦相似度

s(K, K') = \frac{\langle HKH, HK'H \rangle_F}{\|HKH\|_F \|HK'H\|_F}, \tag{32.1}

where $\langle A, B \rangle_F = \text{vec}(A)^\top \text{vec}(B) = \text{tr}(A^\top B)$ is the Frobenius product, and $H = I - \frac{1}{n} 11^\top$ is the centering matrix. As it is applied above, the centering matrix subtracts the means from the rows and columns of the similarity index.

其中 $\langle A, B \rangle_F = \text{vec}(A)^\top \text{vec}(B) = \text{tr}(A^\top B)$ 是 Frobenius 乘积，$H = I - \frac{1}{n} 11^\top$ 是中心矩阵。如上文所述，中心矩阵从相似性指数的行和列中减去均值。

当 $k$ 和 $k'$ 被选为线性内核 $k(x, x') = k'(x, x') = x^\top x'$ 时，会出现中心内核对齐的一种特殊情况。在这种情况下，$K = XX^\top$ 和 $K' = YY^\top$，从而允许用特征对之间而非样本对之间的相似性来表达 CKA 的另一种形式。表示本身首先必须通过从其列中减去均值进行中心化，得到 $\tilde{X} = HX$ 和 $\tilde{Y} = HY$。然后，所谓的线性中心内核对齐由以下公式给出

s(K, K') = \frac{\langle \tilde{X}\tilde{X}^\top, \tilde{Y}\tilde{Y}^\top \rangle_F}{\|\tilde{X}\tilde{X}^\top\|_F \|\tilde{Y}\tilde{Y}^\top\|_F} = \frac{\|\tilde{X}^\top \tilde{Y}\|_F^2}{\|\tilde{X}^\top \tilde{X}\|_F \|\tilde{Y}^\top \tilde{Y}\|_F}. \tag{32.2}

线性中心内核对齐等价于中心特征之间的 RV 系数 [RE76]，如 [Kor+19] 所示。

### 32.2.2.2 典型相关分析及相关方法

给定两个数据集（在此情况下为表示矩阵 $X$ 和 $Y$），典型相关分析或 CCA（第 28.3.4.3 节）试图将两个数据集映射到共享潜空间，使它们在此空间中达到最大相关性。第 $i$ 对典型权重 $(w_i, w'_i)$ 最大化相应典型向量之间的相关性 $\rho_i = \text{corr}[Xw_i, Yw'_i]$，约束条件是新典型向量与之前的典型向量正交，

maximize corr[$Xw_i, Yw'_i$]
subject to $\forall_{j<i} Xw_i \perp Xw_j$
       $\forall_{j<i} Yw'_i \perp Yw'_j$
       $\|Xw_i\| = \|Yw'_i\| = 1.$ \tag{32.3}

非零典型相关系数的最大数量为秩的最小值，$p = \min(\text{rk}(X), \text{rk}(Y))$。

计算典型权重和相关系数的标准算法 [BG73] 首先将各个表示分解为正交矩阵与第二个矩阵的乘积，$\tilde{X} = QR : Q^\top Q = I$ 和 $\tilde{Y} = Q'R' : Q'^\top Q' = I$。这些分解可以通过 QR 分解或奇异值分解得到。对 $Q^\top Q' = U \Sigma V^\top$ 进行第二次奇异值分解，可提供确定典型权重和相关系数所需的量。

具体而言，典型相关系数是奇异值 \(\boldsymbol{\rho} = \text{diag}(\boldsymbol{\Sigma})\)；典型向量是 \(\boldsymbol{X}\boldsymbol{W} = \boldsymbol{Q}\boldsymbol{U}\) 和 \(\boldsymbol{Y}\boldsymbol{W}' = \boldsymbol{Q}'\boldsymbol{V}\) 的列；典型权重是 \(\boldsymbol{W} = \boldsymbol{R}^{-1}\boldsymbol{U}\) 和 \(\boldsymbol{W}' = \boldsymbol{R}'^{-1}\boldsymbol{V}\)。

将得到的典型相关系数向量转换为标量的两种常见策略是取**平均平方典型相关系数**，\(R^2_{\text{CCA}}(\boldsymbol{X}, \boldsymbol{Y}) = \|\boldsymbol{\rho}\|_2^2/p = \|\boldsymbol{Q}^\top \boldsymbol{Q}'\|_\text{F}^2/p,\) 或**平均典型相关系数**，\(\bar{\rho} = \sum_{i=1}^p \boldsymbol{\rho}_i/p = \|\boldsymbol{Q}^\top \boldsymbol{Q}'\|_*/p,\) where \(\|\cdot\|_*\) denotes the nuclear norm. The mean squared canonical correlation has several alternative names, including Yanai's GCD [Yan74; RBS84], Pillai's trace, or the eigenspace overlap score [May+19].

其中 \(\|\cdot\|_*\) 表示核范数。平均平方典型相关系数还有几个替代名称，包括 Yanai's GCD [Yan74; RBS84]、Pillai's trace 或 eigenspace overlap score [May+19]。

虽然 CCA 是一种强大的工具，但它受到维度灾难的影响。如果至少一个表示的神经元数量多于样本数量，且每个神经元与其他神经元线性无关，则所有典型相关系数均为 1。在实践中，由于神经网络表示是高维的，我们可能会处于数据不足以准确估计典型相关系数的情境。此外，即使可以准确估计典型相关系数，相似性度量可能也希望减少对低方差方向相似性的强调。

**奇异向量 CCA（SVCCA）**通过在执行 CCA 时仅保留 \(\tilde{\boldsymbol{X}}\) 和 \(\tilde{\boldsymbol{Y}}\) 的最大主成分来缓解这些问题。给定表示的奇异值分解 \(\tilde{\boldsymbol{X}} = \boldsymbol{U}\boldsymbol{\Sigma}\boldsymbol{V}^\top\) 和 \(\tilde{\boldsymbol{Y}} = \boldsymbol{U}'\boldsymbol{\Sigma}'\boldsymbol{V}'^\top$，SVCCA 仅保留 \(\boldsymbol{U}\) 的前 \(k\) 列，对应 \(\boldsymbol{\sigma} = \text{diag}(\boldsymbol{\Sigma})\) 的最大 \(k\) 个奇异值（即 \(k\) 个最大主成分），以及 \(\boldsymbol{U}'\) 的前 \(k'\) 列，对应最大 \(k'\) 个奇异值 \(\boldsymbol{\sigma}' = \text{diag}(\boldsymbol{\Sigma}')\)。利用这些奇异值分解，随后可通过上文描述的 Björck 和 Golub [BG73] 算法计算典型相关系数、向量和权重，方法是设定

\(\boldsymbol{Q} = \boldsymbol{U}_{:,1:k}, \quad \boldsymbol{R} = \boldsymbol{\Sigma}_{1:k,1:k}\boldsymbol{V}_{:,1:k}^\top, \quad \boldsymbol{Q}' = \boldsymbol{U}'_{:,1:k}, \quad \boldsymbol{R}' = \boldsymbol{\Sigma}'_{1:k,1:k}\boldsymbol{V}'_{:,1:k}^\top.\)

Raghu 等人 [Rag+17] 建议保留足够的成分以解释 99% 的方差，即将 \(k\) 设置为满足 \(\|\boldsymbol{\sigma}_{1:k}\|^2/\|\boldsymbol{\sigma}\|^2 = 0.99\) 的最小值，并将 \(k'\) 设置为满足 \(\|\boldsymbol{\sigma}'_{1:k'}\|^2/\|\boldsymbol{\sigma}'\|^2 = 0.99\) 的最小值。但是，对于固定的 \(\min(k, k')\) 值，基于 CCA 的相似度量会随 \(\max(k, k')\) 的值而增加。因此，那些需要更多成分来解释表示 99% 方差的表示，可能会比奇异值谱衰减更快的表示看起来对所有其他表示都“更相似”。在实践中，通常将 \(k\) 和 \(k'\) 设置为相同的固定值更好。

**投影加权 CCA（PWCCA）** [MRB18] 则是通过它们解释的原始表示变异度量来对相关性进行加权。得到的相似性度量为

\(\text{PWCCA}(\boldsymbol{X}, \boldsymbol{Y}) = \frac{\sum_{i=1}^p \alpha_i \rho_i}{\sum_{i=1}^p \alpha_i}, \quad \alpha_i = \|(\boldsymbol{Y}\boldsymbol{w}'_i)^\top \boldsymbol{Y}\|_1.\)
