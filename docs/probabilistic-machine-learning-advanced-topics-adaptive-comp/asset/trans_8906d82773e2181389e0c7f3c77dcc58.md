

where \(\mathbf{U}_L\) 是一个 \(D \times L\) 矩阵，其列由 \(\mathbf{S}\) 的 \(L\) 个最大特征值对应的特征向量给出，\(\Lambda_L\) 是相应特征值的 \(L \times L\) 对角矩阵，\(\mathbf{R}\) 是一个任意的 \(L \times L\) 正交矩阵，（WLOG）我们可以取 \(\mathbf{R} = \mathbf{I}\)。

若将 \(\mathbf{W}\) 的极大似然估计代入，我们得到预测分布的协方差为

\(\mathbf{C} = \mathbf{W}\mathbf{W}^T + \sigma^2 \mathbf{I} = \mathbf{U}_L (\Lambda_L - \sigma^2 \mathbf{I}) \mathbf{U}_L^T + \sigma^2 \mathbf{I}\) \tag{28.68}

观测方差的极大似然估计为

\(\sigma^2 = \frac{1}{D-L} \sum_{i=L+1}^D \lambda_i\) \tag{28.69}

这相当于被丢弃维度所关联的平均失真。如果 \(L = D\)，则估计噪声为 0，因为模型退化为 \(\mathbf{z} = \mathbf{x}\)。

### 28.3.2.2 在无噪声极限下恢复 PCA

在无噪声极限下，即 \(\sigma^2 = 0\) 时，我们看到（当 \(\mathbf{R} = \mathbf{I}\) 时）极大似然估计为

\(\hat{\mathbf{W}} = \mathbf{U}_L \Lambda_L^{\frac{1}{2}}\) \tag{28.70}

因此

\(\hat{\mathbf{C}} = \hat{\mathbf{W}}\hat{\mathbf{W}}^T = \mathbf{U}_L \Lambda_L^{\frac{1}{2}} \Lambda_L^{\frac{1}{2}} \mathbf{U}_L^T = \mathbf{S}_L\) \tag{28.71}

其中 \(\mathbf{S}_L\) 是 \(\mathbf{S}\) 的秩 \(L\) 近似。这与标准 PCA 相同。

### 28.3.2.3 计算后验

要将 PPCA 用作 PCA 的替代方案，我们需要计算后验均值 \(\mathbb{E}[\mathbf{z}|\mathbf{x}]\)，它相当于 PCA 编码器模型。利用第 28.3.1.2 节的因子分析结果，我们有

\(p(\mathbf{z}|\mathbf{x}) = \mathcal{N}(\mathbf{z}|\sigma^{-2} \Sigma \mathbf{W}^T (\mathbf{x} - \boldsymbol{\mu}), \Sigma)\) \tag{28.72}

其中

\(\Sigma^{-1} = \mathbf{I} + \sigma^{-2} \mathbf{W}^T \mathbf{W} = \frac{1}{\sigma^2} \underbrace{(\sigma^2 \mathbf{I} + \mathbf{W}^T \mathbf{W})}_{\mathbf{M}}\) \tag{28.73}

因此

\(p(\mathbf{z}|\mathbf{x}) = \mathcal{N}(\mathbf{z}|\mathbf{M}^{-1} \mathbf{W}^T (\mathbf{x} - \boldsymbol{\mu}), \sigma^2 \mathbf{M}^{-1})\) \tag{28.74}

在 \(\sigma^2 = 0\) 极限下，我们有 \(\mathbf{M} = \mathbf{W}^T \mathbf{W}\)，因此

\(\mathbb{E}[\mathbf{z}|\mathbf{x}] = (\mathbf{W}^T \mathbf{W})^{-1} \mathbf{W}^T (\mathbf{x} - \bar{\mathbf{x}})\) \tag{28.75}

这是数据在潜在空间中的正交投影，与标准 PCA 中的情况相同。

### 28.3.2.4 使用 EM 进行模型拟合

在第 28.3.2.2 节中，我们展示了如何使用特征向量方法拟合 PCA 模型。我们也可以使用 EM，通过利用 PPCA 在零噪声极限（\(\sigma^2 = 0\)）下的概率公式，如 [Row97] 所示。

特别是，令 \(\tilde{\mathbf{Z}} = \mathbf{Z}^{\mathsf{T}}\) 为一个 \(L \times N\) 矩阵，其列存储后验均值（低维表示）。同样，令 \(\tilde{\mathbf{x}}_n = \mathbf{x}_n - \hat{\boldsymbol{\mu}}\) 为沿 \(\tilde{\mathbf{X}}\) 列存储的中心化样本。根据方程 (28.75)，当 \(\sigma^2 = 0\) 时，我们有

\(\tilde{\mathbf{Z}} = (\mathbf{W}^{\mathsf{T}}\mathbf{W})^{-1}\mathbf{W}^{\mathsf{T}}\tilde{\mathbf{X}}\) (28.76)

这构成了 E 步。请注意，这只是对数据的正交投影。

根据方程 (28.87)，M 步由下式给出

\(\hat{\mathbf{W}} = \left[ \sum_n \tilde{\mathbf{x}}_n \mathbb{E}[\mathbf{z}_n | \tilde{\mathbf{x}}_n]^{\mathsf{T}} \right] \left[ \sum_n \mathbb{E}[\mathbf{z}_n | \tilde{\mathbf{x}}_n] \mathbb{E}[\mathbf{z}_n | \tilde{\mathbf{x}}_n]^{\mathsf{T}} \right]^{-1}\) (28.77)

这里我们利用了 \(\sigma^2 = 0\) 时 \(\boldsymbol{\Sigma} = \text{Cov}[\mathbf{z} | \tilde{\mathbf{x}}] = 0\mathbf{I}\) 的事实。

总之，完整的算法如下：

\(\tilde{\mathbf{Z}} = (\mathbf{W}^{\mathsf{T}}\mathbf{W})^{-1}\mathbf{W}^{\mathsf{T}}\tilde{\mathbf{X}}\) (E step) (28.78)
\(\mathbf{W} = \tilde{\mathbf{X}} \tilde{\mathbf{Z}}^{\mathsf{T}} (\tilde{\mathbf{Z}} \tilde{\mathbf{Z}}^{\mathsf{T}})^{-1}\) (M step) (28.79)

将此表达式与多输出线性回归的极大似然估计进行比较是有价值的，其形式为 \(\mathbf{W} = (\sum_n \mathbf{y}_n \mathbf{x}_n^{\mathsf{T}})(\sum_n \mathbf{x}_n \mathbf{x}_n^{\mathsf{T}})^{-1}\)。由此可见，M 步类似于线性回归，只是将观测输入替换为潜在变量的期望值。

[TB99] 表明，EM 算法的唯一稳定不动点是全局最优解。也就是说，EM 算法收敛到这样一个解，其中 **W** 所跨越的线性子空间与 **S** 的前 \(L\) 个特征向量所定义的子空间相同。但是，如果我们希望 **W** 是正交的，并且按特征值降序包含特征向量，则需要对结果矩阵进行正交化（这可以非常廉价地完成）。或者，我们可以修改 EM 以直接给出主基 [A003]。

## 28.3.3 因子分析器混合模型

因子分析模型（第 28.3.1 节）假设观测数据可以建模为从低维高斯因子集进行线性映射而生成。放宽这一假设的一种方法是假设模型仅在局部是线性的，因此整体模型成为 FA 模型的（加权）组合；这被称为**因子分析器混合模型**或 MFA [GH96b]。数据的整体模型是线性流形的混合，可用于近似整体弯曲流形。另一种思考该模型的方式是高斯混合模型，其中每个混合分量都有一个对角加低秩的协方差矩阵。

### 28.3.3.1 模型定义

生成过程如下。首先，我们从离散分布 \(\text{Cat}(\cdot | \boldsymbol{\pi})\) 中采样一个离散潜在指示器 \(m_n \in \{1, \dots, K\}\)，以指定应使用哪个子空间（聚类）来生成数据。

![](img/ca72c1626f4850f058a9edc138c1ac73_968_0.png)

如果 \(m_n = k\)，我们从高斯先验中采样 \(\boldsymbol{z}_n\)，并将其传递通过 \(\mathbf{W}_k\) 矩阵，其中 \(\mathbf{W}_k\) 将 \(L\) 维子空间映射到 \(D\) 维可见空间。\(^2\) 最后，我们添加从 \(\mathcal{N}(\boldsymbol{\mu}_k, \boldsymbol{\Psi})\) 中采样的高斯观测噪声。因此，模型如下：

\(p(\boldsymbol{x}_n|\boldsymbol{z}_n, m_n=k, \boldsymbol{\theta}) = \mathcal{N}(\boldsymbol{x}_n|\boldsymbol{\mu}_k + \mathbf{W}_k\boldsymbol{z}_n, \boldsymbol{\Psi})\) \tag{28.80}
\(p(\boldsymbol{z}_n|\boldsymbol{\theta}) = \mathcal{N}(\boldsymbol{z}_n|\mathbf{0}, \mathbf{I})\) \tag{28.81}
\(p(m_n|\boldsymbol{\theta}) = \text{Cat}(m_n|\boldsymbol{\pi})\) \tag{28.82}

可见空间中的相应分布由下式给出

\(p(\boldsymbol{x}|\boldsymbol{\theta}) = \sum_k p(m=k) \int p(\boldsymbol{z}) p(\boldsymbol{x}|\boldsymbol{z}, m) \, dz\) \tag{28.83}
\(= \sum_k \pi_k \int \mathcal{N}(\boldsymbol{z}|\mathbf{0}, \mathbf{I}) \mathcal{N}(\boldsymbol{x}|\mathbf{W}_k\boldsymbol{z} + \boldsymbol{\mu}_k, \boldsymbol{\Psi}) \, dz\) \tag{28.84}
\(= \sum_k \pi_k \mathcal{N}(\boldsymbol{x}|\boldsymbol{\mu}_k, \boldsymbol{\Psi} + \mathbf{W}_k \mathbf{W}_k^\intercal)\) \tag{28.85}

在特殊情况下 \(\boldsymbol{\Psi} = \sigma^2 \mathbf{I}\)，我们得到 PPCA 模型的混合。参见图 28.8，了解该方法在某些 2D 数据上的应用示例。

我们可以将其视为高斯混合模型的低秩版本。特别是，该模型需要 \(O(KLD)\) 个参数，而全协方差高斯混合模型需要 \(O(KD^2)\) 个参数。这可以减少过拟合。

### 28.3.3.2 使用 EM 进行模型拟合

我们可以使用 EM 拟合此模型，扩展第 28.3.1.4 节的结果（推导过程见 [GH96b]，更快的 ECM 版本见 [ZY08]）。在 E 步中，我们使用以下公式计算数据点 \(i\) 对于聚类 \(j\) 的后验责任

\(r_{ij} \triangleq p(m_i=j|\boldsymbol{x}_i, \boldsymbol{\theta}) \propto \pi_j \mathcal{N}(\boldsymbol{x}_i|\boldsymbol{\mu}_j, \mathbf{W}_j \mathbf{W}_j^\intercal + \boldsymbol{\Psi})\) \tag{28.86}

2. 如果我们允许 \(\boldsymbol{z}_n\) 依赖于 \(m_n\)，则可以让每个子空间具有不同的维度，如 [KS15] 所建议。
