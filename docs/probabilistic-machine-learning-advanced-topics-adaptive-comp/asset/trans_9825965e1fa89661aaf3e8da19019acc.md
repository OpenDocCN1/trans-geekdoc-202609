图 8.9: 动态逻辑回归模型。\(\boldsymbol{w}_t\) 是时间 \(t\) 的回归权重，\(\eta_t = \boldsymbol{w}_t^T \boldsymbol{x}_t\)。与图 29.24a 相比。

where \(\mu^j_{t-1|t-1}\) 和 \(\tau^j_{t-1|t-1}\) 是给定过去数据的参数 \(j\) 的后验均值和方差。现在我们讨论如何更新这个先验。首先，我们使用标准线性高斯更新计算一步前瞻预测密度 \(p_{t|t-1}(\boldsymbol{w}_t)\)，即，\(\boldsymbol{\mu}_{t|t-1} = \boldsymbol{\mu}_{t-1|t-1}\) 和 \(\boldsymbol{\tau}_{t|t-1} = \boldsymbol{\tau}_{t-1|t-1} + \mathbf{Q}\)，如果没有漂移，我们可以设置 \(\mathbf{Q} = 0\mathbf{I}\)。

现在我们专注于测量更新步骤。定义标量和（如果我们使用二分类，则对应 logits）为 \(\eta_t = \boldsymbol{w}_t^T \boldsymbol{x}_t\)。如果 \(p_{t|t-1}(\boldsymbol{w}_t) = \prod_j \mathcal{N}(w_t^j | \mu_{t|t-1}^j, \tau_{t|t-1}^j)\)，那么我们可以按如下方式计算 \(\eta_t\) 的 1d 先验预测分布：

```
\(p(\eta_t|\mathcal{D}_{1:t-1}, \boldsymbol{x}_t) \approx p_{t|t-1}(\eta_t) = \mathcal{N}(\eta_t|m_{t|t-1}, v_{t|t-1})\) (8.212)

\(m_{t|t-1} = \sum_j x_{t,j} \mu_{t|t-1}^j\) (8.213)

\(v_{t|t-1} = \sum_j x_{t,j}^2 \tau_{t|t-1}^j\) (8.214)
```

1d \(\eta_t\) 的后验如下给出：

```
\(p(\eta_t|\mathcal{D}_{1:t}) \approx p_t(\eta_t) = \mathcal{N}(\eta_t|m_t, v_t)\) (8.215)

\(m_t = \int \eta_t \frac{1}{Z_t} p(y_t|\eta_t) p_{t|t-1}(\eta_t) d\eta_t\) (8.216)

\(v_t = \int \eta_t^2 \frac{1}{Z_t} p(y_t|\eta_t) p_{t|t-1}(\eta_t) d\eta_t - m_t^2\) (8.217)

\(Z_t = \int p(y_t|\eta_t) p_{t|t-1}(\eta_t) d\eta_t\) (8.218)
```

where \(p(y_t|\eta_t) = \text{Ber}(y_t|\eta_t)\)。这些积分是一维的，因此可以使用高斯求积高效计算，如 [Zoe07; KB00] 所述。

在推断出 \(p_t(\eta_t)\) 后，我们需要计算 \(p_t(\boldsymbol{w}|\eta_t)\)。可以按如下方式完成。定义 \(\delta_m\) 为均值的变化，\(\delta_v\) 为方差的变化：

\(\begin{aligned} m_t &= m_{t|t-1} + \delta_m, \quad v_t = v_{t|t-1} + \delta_v \tag{8.219} \\ p_t(w_t^i) &= \mathcal{N}(w_t^i|\mu_{t|t}^i, \tau_{t|t}^i) \tag{8.220} \\ \mu_{t|t}^i &= \mu_{t|t-1}^i + a_i \delta_m \tag{8.221} \\ \tau_{t|t}^i &= \tau_{t|t-1}^i + a_i^2 \delta_v \tag{8.222} \\ a_i \triangleq \frac{x_t^i \tau_{t|t-1}^i}{\sum_j (x_t^j)^2 + \tau_{t|t-1}^j} \tag{8.223} \end{aligned}\)

因此我们可以看到，输入 \(i\) 幅值较大（大 \(|x_t^i|\)）或不确定性较大（大 \(\tau_{t|t-1}^i\)）的参数会被更新最多，因为 \(a_i\) 因子较大，这符合直觉。

例如，我们考虑一个 2d 二分类问题。我们使用 ADF 顺序计算后验，并与使用 Laplace 近似计算的离线估计进行比较。在图 8.10 中，我们绘制了 3 个参数作为“时间”（即，每次对一个训练样本进行条件化后）的函数的后验边际分布。我们看到我们收敛到离线 MAP 估计。在图 8.11 中，我们展示了以不同顺序对数据进行序列贝叶斯更新的结果。我们仍然收敛到近似相同的答案。在图 8.12 中，我们看到来自 Laplace 估计和 ADF 估计（训练结束时）的后验预测分布是相似的。

请注意，整个算法每步只需 \(O(D)\) 时间和空间，与 SGD 相同。但是，与 SGD 不同，没有步长参数，因为对角协变矩阵隐式地指定了每个维度的更新大小。此外，我们得到的是后验近似，而不仅仅是点估计。

### 8.7.1 基于网格的近似

在 SSM 中进行近似推断的一个非常简单的方法是离散化状态空间，然后应用 HMM 滤波器和平滑器（参见第 9.2.3 节），如 [RG17] 所提议。这被称为 **基于网格的近似**。不幸的是，由于维度灾难，这种方法无法扩展到高维问题。特别是，我们知道如果有 \(K\) 个状态，HMM 滤波器每步需要 \(O(K^2)\) 次操作。如果我们有 \(N_z\) 个维度，每个离散为 \(B\) 个 bin，那么 \(K = B^{N_z}\)，因此该方法很快就变得不可处理。

然而，这种方法在 1d 或 2d 中可能很有用。作为示例，考虑一个简单的 1d SSM，具有被加性 Student 噪声损坏的线性动力学：

\(z_t = z_{t-1} + \mathcal{T}_2(0, 1)\) (8.224)

观测值也是线性的，并且也被加性 Student 噪声损坏：

\(y_t = z_t + \mathcal{T}_2(0, 1)\) (8.225)

这种稳健观测模型在观测数据中存在潜在异常值时很有用，例如图 8.13a 中的 \(t = 20\) 时。（另请参见第 8.5.5 节，讨论稳健卡尔曼滤波器。）

不幸的是，使用非高斯似然意味着结果的后验可能变得多峰。幸运的是，这对基于网格的方法不是问题。我们在图 8.14a 和图 8.14b 中展示了滤波和平滑的结果。我们看到在 \(t = 20\) 时，滤波分布 \(p(z_t|\mathbf{y}_{1:20})\) 是双峰的，其均值距离真实状态相当远（有关详细图表，请参见图 8.13b）。这种多峰分布可以通过适当精细的离散化来近似。

### 8.7.3 变分推断

EP 可以被视为对每个时间步 \(t\) 局部最小化包容性 KL，\(D_{\text{KL}}(p(\mathbf{z}_t|\mathbf{y}_{1:T}) \parallel q(\mathbf{z}_t|\mathbf{y}_{1:T}))\)。另一种方法是在全局范围内最小化排他性 KL，\(D_{\text{KL}}(q(\mathbf{z}_{1:T}|\mathbf{y}_{1:T}) \parallel p(\mathbf{z}_{1:T}|\mathbf{y}_{1:T}))\)；这称为变分推断，并在第 10 章中解释。这两个目标之间的差异在第 5.1.4.1 节中有更详细的讨论，但从实践角度来看，VI 的主要优势是我们可以推导出目标的可处理较低界，然后可以使用随机优化对其进行优化。与 EP 不同，该方法保证收敛。有关 VI 应用于 SSM（包括状态估计和参数估计）的更多详细信息，参见 [CWS21; Cou+20; Cou+21; BFY20; FLMM21; Cam+21]。

### 8.7.4 MCMC

在第 12 章中，我们讨论了马尔可夫链 Monte Carlo（MCMC）方法，可用于从不可处理的后验中抽取样本。在 SSM 的情况下，这既包括状态上的分布 \(p(\mathbf{z}_{1:T}|\mathbf{y}_{1:T})\)，也包括参数上的分布 \(p(\boldsymbol{\theta}|\mathbf{y}_{1:T})\)。在某些情况下，例如使用 HMM 或线性高斯 SSM 时，我们可以执行阻塞 Gibbs 采样，即我们使用前向滤波后向采样从 \(p(\mathbf{z}_{1:T}|\mathbf{y}_{1:T}, \boldsymbol{\theta})\) 中采样整个序列，然后采样参数 \(p(\boldsymbol{\theta}|\mathbf{z}_{1:T}, \mathbf{y}_{1:T})\)（有关详细信息，参见 [KK96; Sco02; CMR05]）。或者，我们可以边缘化隐藏状态并只计算参数后验 \(p(\boldsymbol{\theta}|\mathbf{y}_{1:T})\)。当状态推断不可处理时，我们可以使用基于梯度的 HMC 方法（假设状态是连续的），尽管这在长序列上扩展性不佳。
