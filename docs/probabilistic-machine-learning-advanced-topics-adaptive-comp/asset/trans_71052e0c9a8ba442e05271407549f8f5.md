与之密切相关的一种技术依赖于**重建误差**。其思想是将自编码器或 VAE（第 21.2 节）拟合到 ID 样本上，然后测量输入的重建误差：OOD 样本很可能会产生较大误差（例如，参见 [Pol+19]）。然而，这与密度估计方法存在相同的问题。

与其尝试估计似然或重建输出，不如使用经过训练以区分“真实”和“假”数据的 GAN（第 26 章）。这已扩展到 [KR21b] 的 OpenGAN 方法中的开放集识别场景。

## 19.3.3 选择性预测

假设系统对输入为 OOD 的置信度为 $p$（计算此类置信度得分的方法讨论见第 19.3.4 节）。如果 $p$ 低于某个阈值，系统可以选择**弃权**，不将其分类为特定标签。通过改变阈值，我们可以控制准确率与弃权率之间的权衡。这称为**选择性预测**（例如，参见 [EW10; GEY19; Ziy+19; JKG18]），在错误比寻求人类专家帮助代价更高的应用中很有用（例如，医学图像分类）。

### 19.3.3.1 示例：MLP 中的 SGLD 与 SGD

提高 OOD 检测性能的一种方法是对模型参数“采用贝叶斯观点”，使其值的不确定性反映在后验预测分布中。这可以提高选择性预测任务的性能。

在本节中，我们给出了一个简单示例：将浅层 MLP 拟合到 MNIST 数据集上，使用标准 SGD（具体为 RMSprop）或随机梯度朗格文动力学（第 12.7.1 节，一种 MCMC 推理形式）。我们使用 6,000 个训练步骤，每个步骤使用大小为 1,000 的小批量。在将模型拟合到训练集后，我们在测试集上评估其预测。为了评估模型校准的程度，我们选择置信度高于阈值 $t$ 的预测子集。（置信度只是分配给 MAP 类别的概率。）当我们将阈值 $t$ 从 0 增加到 1 时，我们会对更少的示例进行预测，但准确率应该提高。如图 19.8 所示：绿色曲线表示我们进行预测的测试集比例，蓝色曲线表示准确率。左侧显示 SGD，右侧显示 SGLD。在此情况下，性能非常相似，尽管 SGD 略高一点。然而，当存在分布转移时，情况会有些改变。

为了研究分布转移下的效果，我们将两个模型应用于 FashionMNIST 数据。结果如图 19.9 所示。两个模型的准确率都非常低（低于 10% 的随机水平），但 SGD 在其许多预测中仍然非常有信心，而 SGLD 则更保守。要看清这一点，考虑置信度阈值为 0.5 的情况：SGD 方法对大约 97% 的示例进行预测（回想一下，绿色曲线对应右侧纵轴），而 SGLD 仅对大约 70% 的示例进行预测。

关于分布转移下贝叶斯神经网络行为的更多细节，请参见第 17.4.6.2 节。

## 19.3.4 开放集和开放世界识别

在第 19.3.3 节中，我们讨论了当系统对其预测输出不够自信时“拒绝分类”的方法。如果系统检测到这种缺乏自信是因为输入来自新类别，而不仅仅是现有类别的新实例，我们称此问题为开放集识别（综述见例如 [GHC20]）。与其将新类别“标记”为 OOD，我们不如允许类别集随时间增长；这称为开放世界分类 [BB15a]。请注意，开放世界分类最自然地在持续学习系统的背景下解决，我们将在第 19.7.3 节中讨论。

## 19.4 对分布转移的鲁棒性

在本节中，我们讨论提高模型对分布转移鲁棒性的技术。特别是，给定来自 $p(\boldsymbol{x}, \boldsymbol{y})$ 的带标签数据，我们旨在创建近似 $q(\boldsymbol{y}|\boldsymbol{x})$ 的模型。

## 19.4.1 数据增强

提高预测模型对分布转移鲁棒性的一种简单方法是通过修改源数据来模拟目标分布的样本。这称为**数据增强**，并在深度学习社区中广泛使用。例如，通常会对图像施加小扰动（例如平移或旋转），同时保持标签不变（假设标签对此类变化应保持不变）；详情见例如 [SK19; Hen+20]。同样，在 NLP（自然语言处理）中，通常会更改不应影响标签的单词（例如，在情感分析系统中将 "he" 替换为 "she"），或者使用**回译**（从源语言翻译成目标语言再翻译回来）来生成改写句；此类技术的综述见例如 [Fen+21]。关于数据增强的因果视角，见例如 [Kau+21]。

## 19.4.2 分布鲁棒优化

我们可以通过求解以下**分布鲁棒优化**（DRO）问题来构建对（某些形式的）协变转移鲁棒的判别模型：

$$\min_{f \in \mathcal{F}} \max_{w \in \mathcal{W}} \frac{1}{N} \sum_{n=1}^N w_n \ell(f(\boldsymbol{x}_n), \boldsymbol{y}_n)$$

其中样本来自源分布，\((\boldsymbol{x}_n, \boldsymbol{y}_n) \sim p\)。这是**最小-最大优化问题**的一个示例，我们希望最小化最坏情况风险。鲁棒性集 \(\mathcal{W}\) 的指定是决定该方法工作效果和优化问题难度的关键因素。通常它以输入周围的 \(\ell_2\) 球来指定，但也可以在特征（嵌入空间）中定义。也可以根据结构因果模型的局部变化来定义鲁棒性集 [Mei18a]。关于 DRO 的更多详细信息，见例如 [CP20a; LFG21; Sag+20; RM22]。

## 19.5 适应分布转移

在本节中，我们讨论将模型**适应**目标分布的技术。如果我们有来自目标分布的一些带标签数据，可以使用迁移学习，如第 19.5.1 节所讨论。然而，获取目标分布的带标签数据通常不是一种选择。因此，在其他部分中，我们讨论仅依赖于目标分布的**无标签**数据的技术。

### 19.5.1 使用迁移学习的有监督适应

假设我们来自源分布的带标签训练数据为 \(\mathcal{D}^s = \{(\boldsymbol{x}_n, \boldsymbol{y}_n) \sim p : n = 1 : N_s\}\)，以及来自目标分布的一些带标签数据 \(\mathcal{D}^t = \{(\boldsymbol{x}_n, \boldsymbol{y}_n) \sim q : n = 1 : N_t\}\)。我们的目标是在目标分布 \(q\) 上最小化风险，这可以通过以下公式计算：

$$R(f, q) = \mathbb{E}_{q(\boldsymbol{x}, \boldsymbol{y})} [\ell(\boldsymbol{y}, f(\boldsymbol{x}))]$$

我们可以使用以下公式对风险进行经验近似：

$$\hat{R}(f, \mathcal{D}^t) = \frac{1}{|\mathcal{D}^t|} \sum_{(\boldsymbol{x}_n, \boldsymbol{y}_n) \in \mathcal{D}^t} \ell(\boldsymbol{y}_n, f(\boldsymbol{x}_n))$$
