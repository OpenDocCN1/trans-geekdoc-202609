## 17.3.8 基于 SGD 轨迹的方法

在 [MH B17; SL18; CS18] 中，研究表明，在某些假设下，随机梯度下降（SGD）在固定学习率下运行时产生的迭代，对应于以局部模式为中心的后验高斯近似的样本，\(p(\theta|\mathcal{D}) \approx \mathcal{N}(\theta|\hat{\theta}, \mathbf{\Sigma})\)。因此，我们可以使用 SGD 生成近似后验样本。这与 SG-MCMC 方法类似，只是我们不添加显式梯度噪声，并且学习率保持不变。

在 [Izm+18] 中，他们指出，这些 SGD 解（固定学习率）环绕着良好泛化点的外围，如图 17.5 所示。这部分是因为 SGD 除非将学习率退火到 0，否则不会收敛到局部最优。因此，他们提出计算多个 SGD 样本的平均值，每个样本在特定间隔（例如，一个训练周期）后收集，以得到 \(\bar{\theta} = \frac{1}{S} \sum_{s=1}^S \theta_s\)。他们称这为随机权重平均（SWA）。他们表明，得到的点倾向于对应于比 SGD 解更广的局部最小值（见图 17.10），从而获得更好的泛化性能。

SWA 方法与 Polyak-Ruppert 平均相关，后者常用于凸优化。区别在于 Polyak-Ruppert 通常假设学习率衰减到零，并对迭代使用指数移动平均（EMA），而非等权平均；Polyak-Ruppert 平均主要用于减少 SGD 估计的方差，而不是作为寻找更好泛化点的方法。

在 [Mad+19] 中，他们提出将 SGD 在局部模式附近产生的一组样本拟合为高斯分布。他们使用 SWA 解作为高斯分布的均值。对于协方差矩阵，他们使用低积加对角近似形式 \(p(\theta|\mathcal{D}) = \mathcal{N}(\theta|\bar{\theta}, \mathbf{\Sigma})\)，其中 \(\mathbf{\Sigma} = (\mathbf{\Sigma}_{\text{diag}} + \mathbf{\Sigma}_{\text{lr}})/2\)，\(\mathbf{\Sigma}_{\text{diag}} = \text{diag}(\overline{\theta^2} - (\bar{\theta})^2)\)，\(\overline{\theta} = \frac{1}{S} \sum_{s=1}^S \theta_s\)，\(\overline{\theta^2} = \frac{1}{S} \sum_{s=1}^S \theta_s^2\)，以及 \(\mathbf{\Sigma}_{\text{lr}} = \frac{1}{S} \Delta \Delta^T\) 是 \(\Delta_i = (\theta_i - \bar{\theta}_i)\) 的最后 \(K\) 个样本的样本协方差矩阵，其中 \(\bar{\theta}_i\) 是前 \(i\) 个样本的参数运行平均值。他们称此方法为 **SWAG**，代表“带高斯后验的随机权重平均”。这可用于在预测时生成任意数量的后验样本。他们表明，SWAG 可扩展到拥有数百万参数的大型残差网络以及 ImageNet 等大型数据集，与传统的 SGD 训练相比，精度和校准得到改善，且无需额外的训练开销。

## 17.3.9 深度集成

许多常规近似推断方法专注于在后验众数附近的局部邻域内近似后验 \(p(\theta|\mathcal{D})\)。虽然这在经典机器学习中通常不是主要限制，但现代深度神经网络具有高度多峰的后验，不同模式中的参数会产生非常不同的函数。另一方面，单个模式邻域内的函数可能做出相当相似的预测。因此，使用这种局部近似来计算后验预测会低估不确定性并导致泛化性能更差。

一种简单的替代方法是训练多个模型，然后使用等权重的 Dirac delta 函数混合物来近似后验，

\(p(\theta|\mathcal{D}) \approx \frac{1}{M} \sum_{m=1}^M \delta(\theta - \hat{\theta}_m)\) (17.18)

其中 \(M\) 是模型数量，\(\hat{\theta}_m\) 是模型 \(m\) 的 MAP 估计。参见图 17.6 的示意图。

![](img/ca72c1626f4850f058a9edc138c1ac73_681_0.png)

Figure 17.6: 负对数似然在参数空间中变化的卡通示意图。子空间方法（红色）模拟局部模式周围的局部邻域，而集成方法（蓝色）使用一组不同的众数来近似后验。来自 [FHL19] 的图 1。经 Balaji Lakshminarayanan 允许使用。

这种方法称为 **深度集成** [LPB17; FHL19]。

这些模型可以在用于初始化的随机种子 [LPB17]、超参数 [Wen+20c]、架构 [Zai+20] 或上述所有方面有所不同。此外，[DF21; TB22] 讨论了如何添加显式排斥项，以确保集成成员之间的功能多样性。这样，每个成员对应一个不同的预测函数。结合这些比结合同一吸引盆地中的多个样本更有效，尤其是在存在数据分布偏移 [Ova+19] 的情况下。

### 17.3.9.1 多-SWAG

我们可以进一步改进这种方法，使用第 17.3.8 节的 SWAG 方法将高斯分布拟合到每个局部模式，以获得高斯混合模型近似：

```
$p(\theta|\mathcal{D}) \approx \frac{1}{M} \sum_{m=1}^M \mathcal{N}(\theta|\hat{\theta}_m, \Sigma_m)$
```

这种方法称为 **MultiSWAG** [WI20]。MultiSWAG 像深度集成一样，对多个吸引盆地进行贝叶斯模型平均，同时也对每个盆地内部进行平均，并提供了一种随时生成任意数量后验样本（\( S > M \)）的简便方法。

### 17.3.9.2 带随机先验的深度集成

拟合深度集成中每个成员的标准方法是为每个成员初始化一组不同的随机参数，但然后在相同的数据上对它们全部进行训练。不幸的是，这可能导致每个集成成员的预测相当相似，从而降低了该方法的效益。提高多样性的一种方法是在不同的数据子集上训练每个成员；这称为 **自助采样**。另一种方法是将第 \( i \) 个集成成员 \( g_i(\boldsymbol{x}) \) 定义为可训练模型 \( t_i(\boldsymbol{x}) \) 和固定但随机的 **先验网络** \( p_i(\boldsymbol{x}) \) 的加和，以得到

```
$g_i(\boldsymbol{x}; \boldsymbol{\theta}_t) = t_i(\boldsymbol{x}; \boldsymbol{\theta}_i) + \beta p_i(\boldsymbol{x})$
```

### 17.3.9.3 深度集成作为近似贝叶斯推断

贝叶斯神经网络的后验预测分布无法用解析形式表示。因此，深度学习中的所有贝叶斯推断方法都是近似的。在此背景下，所有近似推断程序都处于一个光谱上，表示它们多么接近近似真实的后验预测分布。深度集成可以提供比单个盆地边缘化方法更好的贝叶斯模型平均近似，因为来自不同吸引盆地的点质量比标准贝叶斯方法（后者在单个盆地内采样）代表了更大的功能多样性。
