### 28.3.1.2 计算后验

我们可以使用高斯的贝叶斯规则来计算潜在编码的后验 \(p(\mathbf{z}|\mathbf{x})\)。特别是，根据公式 (2.121)，我们有

```
p(\mathbf{z}|\mathbf{x}) = \mathcal{N}(\mathbf{z}|\mu_{z|x}, \Sigma_{z|x})
\Sigma_{z|x} = (\mathbf{I} + \mathbf{W}^T \Psi^{-1} \mathbf{W})^{-1} = \mathbf{I} - \mathbf{W}^T (\mathbf{W}\mathbf{W}^T + \Psi)^{-1} \mathbf{W}
\mu_{z|x} = \Sigma_{z|x} [\mathbf{W}^T \Psi^{-1} (\mathbf{x} - \mu)] = \mathbf{W}^T (\mathbf{W}\mathbf{W}^T + \Psi)^{-1} (\mathbf{x} - \mu)
```

我们可以通过使用矩阵反演引理来避免对 \(D \times D\) 矩阵 \(\mathbf{C} = \mathbf{W}\mathbf{W}^T + \Psi\) 求逆：

```
\mathbf{C}^{-1} = (\mathbf{W}\mathbf{W}^T + \Psi)^{-1}
= \Psi^{-1} - \Psi^{-1} \mathbf{W} (\mathbf{I} + \mathbf{W}^T \Psi^{-1} \mathbf{W})^{-1} \mathbf{W}^T \Psi^{-1}
```

其中 \(\mathbf{L} = \mathbf{I} + \mathbf{W}^T \Psi^{-1} \mathbf{W}\) 为 \(L \times L\) 矩阵。

### 28.3.1.3 计算似然

在本节中，我们讨论如何高效地计算日志（边缘）似然，其由以下公式给出：

```
\log p(\mathbf{x}|\mu, \mathbf{C}) = -\frac{1}{2} [D \log(2\pi) + \log \det(\mathbf{C}) + \hat{\mathbf{x}}^T \mathbf{C}^{-1} \hat{\mathbf{x}}]
```

其中 \(\tilde{x} = x - \mu\)，且 \(\mathbf{C} = \mathbf{W}\mathbf{W}^T + \mathbf{\Psi}\)。使用公式 (28.47)，马氏距离可通过以下方式计算

$\tilde{x}^T \mathbf{C}^{-1} \tilde{x} = \tilde{x}^T [\mathbf{\Psi}^{-1} \tilde{x} - \mathbf{\Psi}^{-1} \mathbf{W} \mathbf{L}^{-1} (\mathbf{W}^T \mathbf{\Psi}^{-1} \tilde{x})]$ (28.49)

计算复杂度为 $O(L^3 + LD)$。根据矩阵行列式引理，日志行列式由以下公式给出

$\log \det(\mathbf{C}) = \log \det(\mathbf{L}) + \log \det(\mathbf{\Psi})$ (28.50)

计算复杂度为 $O(L^3 + D)$。（另参见第 28.2.5 节，其中我们讨论了歧视性拟合低秩 GMM 分类器，这需要类似的计算。）

### 28.3.1.4 使用 EM 进行模型拟合

我们可以通过对公式 (28.48) 中的日志似然执行梯度上升，或者使用 EM 算法 [RT82; GH96b] 来计算 FA 模型的极大似然估计。后者收敛速度更快，并自动满足对 \(\mathbf{\Psi}\) 的正性约束。下面给出详细内容，假设观测数据已标准化，因此为了记号简洁，\(\mu = 0\)。

在 E 步中，我们计算以下期望充分统计量：

$\mathbf{E}_{x,z} = \sum_{n=1}^N x_n \mathbb{E}[\mathbf{z} | x_n]^T$ (28.51)

$\mathbf{E}_{z,z} = \sum_{n=1}^N \mathbb{E}[\mathbf{z}\mathbf{z}^T | x_n]$ (28.52)

$\mathbf{E}_{x,x} = \sum_{n=1}^N x_n x_n^T$ (28.53)

其中

$\mathbb{E}[\mathbf{z} | \mathbf{x}] = \mathbf{Bx}$ (28.54)

$\mathbb{E}[\mathbf{z}\mathbf{z}^T | \mathbf{x}] = \text{Cov}[\mathbf{z} | \mathbf{x}] + \mathbb{E}[\mathbf{z} | \mathbf{x}] \mathbb{E}[\mathbf{z} | \mathbf{x}]^T = \mathbf{I} - \mathbf{BW} + \mathbf{B}\mathbf{x}\mathbf{x}^T \mathbf{B}^T$ (28.55)

$\mathbf{B} \triangleq \mathbf{W}^T (\mathbf{\Psi} + \mathbf{W}\mathbf{W}^T)^{-1} = \mathbf{W}^T \mathbf{C}^{-1}$ (28.56)

在 M 步中，我们有

$\mathbf{W}^{\text{new}} = \mathbf{E}_{x,z} \mathbf{E}_{z,z}^{-1}$ (28.57)

$\mathbf{\Psi}^{\text{new}} = \frac{1}{N} \text{diag}(\mathbf{E}_{x,x} - \mathbf{W}^{\text{new}} \mathbf{E}_{x,z}^T)$ (28.58)

### 28.3.1.5 处理缺失数据

我们也可以在存在缺失数据的情况下进行后验推断（如果我们做缺失随机假设——讨论见第 3.11 节）。具体来说，令 \(\mathbf{x} = (\mathbf{x}_1, \mathbf{x}_2)\)，\(\mathbf{W} = [\mathbf{W}_1, \mathbf{W}_2]\)，\(\boldsymbol{\mu} = [\boldsymbol{\mu}_1, \boldsymbol{\mu}_2]\)，并假设 \(\mathbf{x}_2\) 缺失（未知）。根据补充部分 2.1.1，我们有

p(z|x_1) = \mathcal{N}(z|\mu_{z|1}, \Sigma_{z|1}) (28.59)

\Sigma_{z|1}^{-1} = I + W_1^T \Sigma_{11}^{-1} W_1 (28.60)

\mu_{z|1} = \Sigma_{z|1}[W_1^T \Sigma_{11}^{-1} (x_1 - \mu_1)] (28.61)

其中 \(\Sigma_{11}\) 是 \(\Psi\) 的左上角块。

### 28.3.1.6 参数不可识别性

FA 模型的参数是不可识别的。为了看清这一点，考虑一个具有权重 \(\mathbf{W}\) 和观测协方差 \(\Psi\) 的模型。我们有

Cov[x] = W E[z z^T] W^T + E[\epsilon \epsilon^T] = W W^T + \Psi (28.62)

其中 \(\epsilon \sim \mathcal{N}(0, \Psi)\) 是观测噪声。

现在考虑另一个具有权重 \(\tilde{\mathbf{W}} = \mathbf{W} \mathbf{R}\) 的模型，其中 \(\mathbf{R}\) 是任意正交旋转矩阵，满足 \(\mathbf{R} \mathbf{R}^T = \mathbf{I}\)。它具有相同的似然，因为

Cov[x] = \tilde{W} E[z z^T] \tilde{W}^T + E[\epsilon \epsilon^T] = W R R^T W^T + \Psi = W W^T + \Psi (28.63)

几何上，将 \(\mathbf{W}\) 乘以正交矩阵相当于在生成 \(\mathbf{x}\) 之前旋转 \(\mathbf{z}\)；但由于 \(\mathbf{z}\) 来自各向同性高斯分布，这不会影响似然。因此，我们无法唯一地识别 \(\mathbf{W}\)，也就无法唯一地识别潜在因子。这被称为“因子旋转问题”（参见，例如，[Dar80]）。

为了打破这种对称性，可以使用下面讨论的几种解决方案。

- 强制 \(\mathbf{W}\) 具有正交列。在（P）PCA 中，我们强制 \(\mathbf{W}\) 具有正交列，并按递减特征值（\(\mathbf{W}\mathbf{W}^T\) 的特征值）的顺序对维度进行排序。然而，这仍然不能确保可识别性，因为我们可以始终用另一个正交矩阵乘以 \(\mathbf{W}\) 而不改变似然。

- 强制 \(\mathbf{W}\) 为下三角矩阵。解决排列不可识别性的一种方法（在贝叶斯社区中很流行，例如 [LW04]）是确保第一个可见特征仅由第一个潜在因子生成，第二个可见特征仅由前两个潜在因子生成，以此类推。例如，如果 L = 3 且 D = 4，相应的因子载荷矩阵由以下公式给出

W = \begin{pmatrix} w_{11} & 0 & 0 \\ w_{21} & w_{22} & 0 \\ w_{31} & w_{32} & w_{33} \\ w_{41} & w_{42} & w_{43} \end{pmatrix} (28.64)

我们还要求 \(w_{kk} > 0\) 对 \(k = 1:L\) 成立。这个受约束矩阵中的参数总数为 \(D + DL - L(L-1)/2\)，这等于 FA 中可唯一识别的参数数量（不包括均值）。¹ 这种方法的缺点是，前 L 个可见变量（称为**创始变量**）会影响潜在因子的解释，因此必须谨慎选择。

- **对权重的稀疏性促进先验。** 与预先指定 **W** 中哪些项为零不同，我们可以使用 ℓ₁ 正则化 [ZHT06]、ARD [Bis99; AB08] 或 spike-and-slab 先验 [Rat+09] 来鼓励项为零。这称为稀疏因子分析。这不一定能确保唯一的 MAP 估计，但它确实鼓励可解释的解。

- **选择信息性旋转矩阵。** 有多种启发式方法试图寻找可用于修改 **W**（进而修改潜在因子）的旋转矩阵 **R**，以试图提高可解释性，通常通过鼓励它们（近似）稀疏来实现。一种流行的方法称为 varimax [Kai58]。

- **对潜在因子使用非高斯先验。** 如果我们将潜在变量的先验 \(p(\mathbf{z})\) 替换为非高斯分布，则有时可以唯一地识别 **W** 以及潜在因子。详情见，例如，[KKH20]。

### 28.3.2 概率主成分分析

在本节中，我们考虑因子分析模型的一个特例，其中 **W** 具有正交列且 \(\Psi = \sigma^2 \mathbf{I}\)，因此 \(p(\mathbf{x}) = \mathcal{N}(\mathbf{x}|\boldsymbol{\mu}, \mathbf{C})\)，其中 \(\mathbf{C} = \mathbf{W}\mathbf{W}^\top + \sigma^2 \mathbf{I}\)。该模型称为**概率主成分分析**（PPCA）[TB99] 或 **合理的 PCA**（sensible PCA）[Row97]。

与因子分析相比，PPCA 的优势在于 MLE 具有解析解，如第 28.3.2.2 节所示。与非概率 PCA 相比，PPCA 的优势在于该模型定义了一个合适的似然函数，这使得以各种方式扩展变得更容易，例如，通过创建 PPCA 模型的混合（参见第 28.3.3 节）。

### 28.3.2.1 MLE 推导

PPCA 的日志似然由以下公式给出：

```
log p(X|μ, W, σ²) = -ND/2 log(2π) - N/2 log|C| - 1/2 Σⁿ₌₁ (**xₙ** - **μ**)ᵀ **C⁻¹** (**xₙ** - **μ**) (28.65)
```

\(\boldsymbol{\mu}\) 的 MLE 是 \(\bar{\mathbf{x}}\)。代入得到：

```
log p(X|μ, W, σ²) = -N/2 [D log(2π) + log|C| + tr(**C⁻¹ S**)] (28.66)
```

其中 \(S = \frac{1}{N} \sum_{n=1}^N (\mathbf{x}_n - \bar{\mathbf{x}})(\mathbf{x}_n - \bar{\mathbf{x}})^\top\) 是经验协方差矩阵。在 [TB99; Row97] 中，他们表明该目标的最大值必须满足：

```
Ŵ = **U_L** (Λ_L - σ²**I**)¹ᐟ² **R** (28.67)
```

1. 我们为 \(\Psi\) 得到 D 个参数，为 **W** 得到 DL 个参数，但需要去掉来自 **R** 的 L(L - 1)/2 个自由度，因为这是 L × L 正交矩阵空间的维度。要看清这一点，请注意：**R** 的第一列中有 L - 1 个自由参数（因为列向量必须归一化为单位长度），第二列中有 L - 2 个自由参数（必须与第一列正交），以此类推。
