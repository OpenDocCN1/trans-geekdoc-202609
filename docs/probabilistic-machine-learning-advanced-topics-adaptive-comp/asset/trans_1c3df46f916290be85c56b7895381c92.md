### 9.4.4.3 使用自适应调度提高收敛速度

实现 LBP 的标准方法是执行**同步更新**，即所有节点并行吸收消息，然后并行发送消息。也就是说，第 \(k+1\) 次迭代的新消息是并行使用以下公式计算的：

```
m_{1:E}^{k+1} = (f_1(m^k), \dots, f_E(m^k))
```

其中 \(E\) 为边的数量，\(f_i(m)\) 是根据所有旧消息计算边 \(i\) 消息的函数。这类似于求解线性方程组的 Jacobi 方法。

众所周知 [Ber97b]，Gauss-Seidel 方法以固定的循环方式执行**异步更新**，在求解线性方程组时收敛更快。我们可以将同样的想法应用于 LBP，使用如下形式的更新：

```
m_i^{k+1} = f_i(\{m_j^{k+1}: j < i\}, \{m_j^k: j > i\})
```

其中，边 \(i\) 的消息是根据排序中更早的边的新消息（第 \(k+1\) 次迭代）和更晚的边的旧消息（第 \(k\) 次迭代）计算的。

这就提出了以什么顺序更新消息的问题。一个简单的想法是使用固定顺序或随机顺序。图 9.13 展示了此方法的优势，可见（阻尼）异步更新比同步更新更频繁地实现收敛。

然而，通过使用自适应顺序，我们可以做得更好。直觉是，我们应将计算精力集中在最不确定的变量上。[EMK06] 提出了一种称为 **残差信念传播** 的技术，其中消息的发送根据其与前一次值的差异的范数进行调度。也就是说，我们定义第 \(k\) 次迭代中新消息 \(m_{s \to t}\) 的残差为：

```
r(s, t, k) = || \log m_{s \to t} - \log m_{s \to t}^k ||_\infty = \max_j |\log \frac{m_{s \to t}(j)}{m_{s \to t}^k(j)}|
```

我们可以将消息存储在优先队列中，并始终发送残差最高的消息。当一条消息从 \(s\) 发送到 \(t\) 时，所有依赖于 \(m_{s \to t}\) 的其他消息（即 \(m_{t \to u}\) 形式的消息，其中 \(u \in \text{nbr}(t) \setminus s\)）都需要重新计算；重新计算它们的残差，并将它们重新加入队列。在 [EMK06] 中，他们（通过实验）表明，这种方法比同步更新或使用固定顺序的异步更新收敛得更频繁，速度也快得多。

[SM07] 提出了残差 BP 的一种改进。在该论文中，他们使用消息残差的上界而非实际残差。这意味着只有即将发送的消息才会被计算；它们不会仅仅为了评估残差而被计算。观察到，这种方法比残差 BP 快约五倍，尽管最终结果的质量相似。

### 9.4.6 广义信念传播

我们可以通过将形成紧密环的节点聚类在一起来提高环形 BP 的准确性。这被称为簇变分法，或广义信念传播 [YFW00]。

聚类的结果是一个超图，即顶点集合之间而非单个顶点之间存在超边的图。请注意，连接树（第 9.6 节）是一种超图。我们可以使用偏序集（poset）图来表示超图，其中每个节点代表一个超边，如果 e2 是 e1 的子集，则存在箭头 e1 -> e2。参见图 9.14 了解示例。

如果允许超图中最大超边的大小达到图的树宽，则我们可以将超图表示为树，该方法将是精确的，就像 LBP 在普通树（树宽为 1）上是精确的一样。这样一来，我们可以定义从 LBP 一直到精确推断的近似连续谱。更多信息请参见补充部分 10.4.3.3。

### 9.4.7 凸信念传播

在补充部分 10.4.3 中，我们从变分角度分析 LBP，并表明，无论是标准 BP 还是广义 BP，其产生的优化问题都是非凸的。然而，如补充部分 10.4.4 所述，可以创建凸 BP 的一个版本，其优势在于它总会收敛。

### 9.4.8 应用：纠错码

LBP 最初由 Judea Pearl 在其 1988 年的书中提出 [Pea88]。他认识到将 BP 应用于环形图可能无法工作，但将其作为一种启发式方法予以推荐。

![](img/ca72c1626f4850f058a9edc138c1ac73_450_0.png)

图 9.15：（a）(2,3) 低密度奇偶校验码的简单因子图表示。每个消息位（空心圆圈）连接到两个奇偶因子（实心黑色方形），每个奇偶因子连接到三个位。每个奇偶因子的形式为 \(\psi_{stu}(x_s, x_t, x_u) = \mathbb{I}(x_s \otimes x_t \otimes x_u = 1)\)，其中 \(\otimes\) 是异或运算符。每个隐藏节点的局部证据因子未显示。（b）随机 LDPC 码的较大示例。我们可以看到，这个图是“局部树状”的，即没有短环；相反，每个环的长度为 \(\sim \log m\)，其中 \(m\) 是节点数量。这提示了为什么环形 BP 在此类图上效果如此好。（但是请注意，某些纠错码图有短环，因此这并非完全解释。）来自 [WJ08] 的图 2.9。经 Martin Wainwright 允许使用。

然而，LBP 受到关注的主要动力在于 McEliece、MacKay 和 Cheng [MMC98] 表明，一种称为 turbo 码 [BGT93] 的流行纠错算法可以被视为在某类图上应用 LBP 的一个实例。

我们在第 5.5 节介绍了纠错码。请回顾，基本思想是通过带噪声信道发送源消息 \(\boldsymbol{x} \in \{0, 1\}^m\)，并让接收者根据带噪声测量值 \(\boldsymbol{y} \in \{0, 1\}^m\) 或 \(\boldsymbol{y} \in \mathbb{R}^m\) 尝试推断它。也就是说，接收者需要计算 \(\boldsymbol{x}^* = \text{argmax}_{\boldsymbol{x}} p(\boldsymbol{x}|\boldsymbol{y}) = \text{argmax}_{\boldsymbol{x}} \tilde{p}(\boldsymbol{x})\)。

通常将 \(\tilde{p}(\boldsymbol{x})\) 表示为因子图（第 4.6.1 节），它可以轻松表示位之间的任何确定性关系（奇偶性约束）。因子图是一种二分图，一侧是 \(x_i\) 节点，另一侧是因子。每个节点连接到 \(n\) 个因子，且每个因子连接到 \(k\) 个节点的图称为 \((n, k)\) 码。图 9.15(a) 展示了一个 (2,3) 码的简单示例，其中每个位（空心圆圈）连接到两个奇偶因子（实心黑色方形），每个奇偶因子连接到三个位。每个奇偶因子的形式为

\[\psi_{stu}(x_s, x_t, x_u) \triangleq \left\{ \begin{array}{ll} 1 & \text{如果 } x_s \otimes x_t \otimes x_u = 1 \\ 0 & \text{否则} \end{array} \right.\tag{9.81}\]

如果随着分组长度 \(m\) 增加，奇偶校验和变量节点的度数保持有界，则这称为 **低密度奇偶校验码**，或 **LDPC 码**。（turbo 码的构建方式类似。）

图 9.15(b) 展示了一个随机构造的 LDPC 码示例。这个图是“局部树状”的，即没有短环；相反，每个环的长度为 \(\sim \log m\)。这一事实对 LBP 的成功很重要，LBP 仅保证在树形结构图上工作。使用
