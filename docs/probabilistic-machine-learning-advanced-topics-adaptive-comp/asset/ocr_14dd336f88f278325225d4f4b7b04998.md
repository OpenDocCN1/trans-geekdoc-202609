where we impose the following sum-to-zero constraints

```
\sum_j \alpha_j = \sum_k \beta_k = \sum_j \gamma_{jk} = \sum_k \gamma_{jk} = 0
```

We are interested in testing whether \(\gamma = 0\), meaning there is no interaction effect. This is traditionally done using a **two-way ANOVA test**. However, we can also use a Bayesian approach and just compute \(p(\theta|D)\).

# 3.10.3.6 Count predicted variable with nominal predictors (\(\chi^2\) test)

Consider a situation in which we observed two nominal values for each item measured. For example, the gender of a person (male or female) and whether they are left handed or right handed (LH or RH). If we count the number of outcomes of each type, we can represent the data as a \(R \times C\) **contingency table**. See Table 3.3 for an example. We may be interested in testing the null hypothesis that there is no interaction effect between the two groups and the outcome (i.e., the two variables are independent). In frequentist statistics, this is often tackled using a \(\chi^2\)-**test**, which uses the sampling distribution of the \(\chi^2\) test statistic, defined as

```
\chi^2 = \sum_{r=1}^R \sum_{c=1}^C \frac{(O_{r,c} - E_{r,c})^2}{E_{r,c}}
```

where \(r\) indexes the rows, and \(c\) the columns, \(O_{r,c}\) is the observed count in cell \((r, c)\), and \(E_{rc} = N p_r . p_c\) is the expected count, where \(p_r. = O_c. / N\) and \(p_{.c} = O_{.r} / N\) are the empirical marginal frequencies.

In the Bayesian approach, we can just modify the two-way ANOVA of Section 3.10.3.5, and replace the Gaussian distribution with a Poisson distribution. We also need to pass the predicted natural parameter through an exponential link, since a Poisson distribution requires that the rate parameter is non-negative. Thus the model becomes

```
p(y|x = (r, c), \theta) = \text{Poi}(y | \lambda_{r,c})
\lambda_{rc} = \exp(\beta_0 + \beta_r + \beta_c + \beta_{r,c})
```

We can now perform posterior inference in the usual way.
