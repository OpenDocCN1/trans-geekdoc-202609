where we assume E and H are invertible. One can show (see e.g., [Mur22, Sec 7.3.2] for the proof) that

```
\mathbf{M}^{-1} = \begin{pmatrix} (\mathbf{M}/\mathbf{H})^{-1} & -(\mathbf{M}/\mathbf{H})^{-1}\mathbf{F}\mathbf{H}^{-1} \\ -\mathbf{H}^{-1}\mathbf{G}(\mathbf{M}/\mathbf{H})^{-1} & \mathbf{H}^{-1} + \mathbf{H}^{-1}\mathbf{G}(\mathbf{M}/\mathbf{H})^{-1}\mathbf{F}\mathbf{H}^{-1} \end{pmatrix}
```

```
= \begin{pmatrix} \mathbf{E}^{-1} + \mathbf{E}^{-1}\mathbf{F}(\mathbf{M}/\mathbf{E})^{-1}\mathbf{G}\mathbf{E}^{-1} & -\mathbf{E}^{-1}\mathbf{F}(\mathbf{M}/\mathbf{E})^{-1} \\ -(\mathbf{M}/\mathbf{E})^{-1}\mathbf{G}\mathbf{E}^{-1} & (\mathbf{M}/\mathbf{E})^{-1} \end{pmatrix}
```

where

```
\mathbf{M}/\mathbf{H} \triangleq \mathbf{E} - \mathbf{F}\mathbf{H}^{-1}\mathbf{G}
```

```
\mathbf{M}/\mathbf{E} \triangleq \mathbf{H} - \mathbf{G}\mathbf{E}^{-1}\mathbf{F}
```

We say that M/H is the Schur complement of M wrt H, and M/E is the Schur complement of M wrt E.

From the above, we also have the following important result, known as the matrix inversion lemma or the Sherman-Morrison-Woodbury formula:

```
(\mathbf{M}/\mathbf{H})^{-1} = (\mathbf{E} - \mathbf{F}\mathbf{H}^{-1}\mathbf{G})^{-1} = \mathbf{E}^{-1} + \mathbf{E}^{-1}\mathbf{F}(\mathbf{H} - \mathbf{G}\mathbf{E}^{-1}\mathbf{F})^{-1}\mathbf{G}\mathbf{E}^{-1}
```

Now we return to the derivation of the MVN conditioning equation. Let us factor the joint p(x_1, x_2) as p(x_2)p(x_1|x_2) as follows:

```
p(x_1, x_2) \propto \exp \left\{ -\frac{1}{2} \begin{pmatrix} x_1 - \mu_1 \\ x_2 - \mu_2 \end{pmatrix}^\mathsf{T} \begin{pmatrix} \Sigma_{11} & \Sigma_{12} \\ \Sigma_{21} & \Sigma_{22} \end{pmatrix}^{-1} \begin{pmatrix} x_1 - \mu_1 \\ x_2 - \mu_2 \end{pmatrix} \right\}
```

Using the equation for the inverse of a block structured matrix, the above exponent becomes

```
p(x_1, x_2) \propto \exp \left\{ -\frac{1}{2} \begin{pmatrix} x_1 - \mu_1 \\ x_2 - \mu_2 \end{pmatrix}^\mathsf{T} \begin{pmatrix} \mathbf{I} & \mathbf{0} \\ -\Sigma_{22}^{-1}\Sigma_{21} & \mathbf{I} \end{pmatrix} \begin{pmatrix} (\Sigma/\Sigma_{22})^{-1} & \mathbf{0} \\ \mathbf{0} & \Sigma_{22}^{-1} \end{pmatrix} \right\}
```

```
\times \left( \begin{pmatrix} \mathbf{I} & -\Sigma_{12}\Sigma_{22}^{-1} \\ \mathbf{0} & \mathbf{I} \end{pmatrix} \begin{pmatrix} x_1 - \mu_1 \\ x_2 - \mu_2 \end{pmatrix} \right\}
```

```
= \exp \left\{ -\frac{1}{2}(x_1 - \mu_1 - \Sigma_{12}\Sigma_{22}^{-1}(x_2 - \mu_2))^\mathsf{T}(\Sigma/\Sigma_{22})^{-1} \right\}
```

```
(x_1 - \mu_1 - \Sigma_{12}\Sigma_{22}^{-1}(x_2 - \mu_2))) \times \exp \left\{ -\frac{1}{2}(x_2 - \mu_2)^\mathsf{T}\Sigma_{22}^{-1}(x_2 - \mu_2) \right\}
```

This is of the form

```
\exp(\text{quadratic form in } x_1, x_2) \times \exp(\text{quadratic form in } x_2)
```

Hence we have successfully factorized the joint as

```
p(x_1, x_2) = p(x_1|x_2)p(x_2)
```

```
= \mathcal{N}(x_1|\mu_{1|2}, \Sigma_{1|2})\mathcal{N}(x_2|\mu_2, \Sigma_{22})
```
