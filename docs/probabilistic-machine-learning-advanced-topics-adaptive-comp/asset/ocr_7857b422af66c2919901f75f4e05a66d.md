The square root of this is called the standard error of the mean:
se($\mu$) \(\triangleq \sqrt{\mathbb{V}[\mu|\mathcal{D}]} \approx \frac{s}{\sqrt{N}}\)

Thus we can approximate the 95% credible interval for $\mu$ using
\(I_{.95}(\mu|\mathcal{D}) = \bar{y} \pm 2 \frac{s}{\sqrt{N}}\)

# ## 3.4.4 The multivariate Gaussian model

In this section, we derive the posterior \(p(\mu, \Sigma|\mathcal{D})\) for a multivariate Gaussian. For simplicity, we consider this in three steps: inferring just $\mu$, inferring just $\Sigma$, and then inferring both.

# ### 3.4.4.1 Posterior of $\mu$ given $\Sigma$

The likelihood has the form

```
\(p(\mathcal{D}|\mu) = \mathcal{N}(\bar{y}|\mu, \frac{1}{N}\Sigma)\)
```

For simplicity, we will use a conjugate prior, which in this case is a Gaussian. In particular, if \(p(\mu) = \mathcal{N}(\mu|\tilde{m}, \tilde{V})\) then we can derive a Gaussian posterior for $\mu$ based on the results in Section 2.3.2.2 We get

```
\(p(\mu|\mathcal{D}, \Sigma) = \mathcal{N}(\mu|\hat{m}, \hat{V})\)
\(\hat{V}^{-1}=\tilde{V}^{-1}+N\Sigma^{-1}\)
\(\hat{m}=\hat{V}(\Sigma^{-1}(N\bar{y})+\tilde{V}^{-1}\tilde{m})\)
```

Figure 3.8 gives a 2d example of these results.

# ### 3.4.4.2 Posterior of $\Sigma$ given $\mu$

We now discuss how to compute \(p(\Sigma|\mathcal{D}, \mu)\).

# ### Likelihood

We can rewrite the likelihood as follows:

```
\(p(\mathcal{D}|\mu, \Sigma) \propto |\Sigma|^{-\frac{N}{2}} \exp \left( -\frac{1}{2} \text{tr}(\mathbf{S}_\mu \Sigma^{-1}) \right)\)
```

where

```
\(\mathbf{S}_\mu \triangleq \sum_{n=1}^N (\mathbf{y}_n - \mu)(\mathbf{y}_n - \mu)^\top\)
```

is the scatter matrix around $\mu$.
