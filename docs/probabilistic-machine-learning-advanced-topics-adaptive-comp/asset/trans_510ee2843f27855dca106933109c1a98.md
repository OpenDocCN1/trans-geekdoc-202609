除了推断隐藏状态，我们可能还想预测未来的观测值。我们可以如下计算未来 h 步的观测预测分布：

```
p(\mathbf{y}_{t+h}|\mathbf{y}_{1:t}) = \sum_{\mathbf{z}_{t+h}} p(\mathbf{y}_{t+h}|\mathbf{z}_{t+h})p(\mathbf{z}_{t+h}|\mathbf{y}_{1:t}) \qquad (8.2)
```

其中，隐藏状态预测分布是通过将当前信念状态传递给动态模型得到的：

```
p(\mathbf{z}_{t+h}|\mathbf{y}_{1:t}) = \sum_{\mathbf{z}_{t:t+h-1}} p(\mathbf{z}_t|\mathbf{y}_{1:t})p(\mathbf{z}_{t+1}|\mathbf{z}_t)p(\mathbf{z}_{t+2}|\mathbf{z}_{t+1})\cdots p(\mathbf{z}_{t+h}|\mathbf{z}_{t+h-1}) \qquad (8.3)
```

> （当状态为连续时，我们需要将求和替换为积分。）

## 8.1.2 贝叶斯滤波方程

贝叶斯滤波是一种算法，用于递归地计算信念状态 \(p(\mathbf{z}_t|\mathbf{y}_{1:t})\)，已知前一步的先验信念 \(p(\mathbf{z}_{t-1}|\mathbf{y}_{1:t-1})\)、新观测值 \(\mathbf{y}_t\) 和模型。可以使用顺序贝叶斯更新来完成，并且每个时间步所需的计算量恒定（与 t 无关）。对于动态模型，这简化为下面描述的预测-更新循环。

预测步骤就是查普曼-科尔莫戈罗夫方程：

```
p(\mathbf{z}_t|\mathbf{y}_{1:t-1}) = \int p(\mathbf{z}_t|\mathbf{z}_{t-1})p(\mathbf{z}_{t-1}|\mathbf{y}_{1:t-1})d\mathbf{z}_{t-1} \qquad (8.4)
```

预测步骤计算隐藏状态的单步前瞻预测分布，将前一时间步的后验更新为当前步骤的先验。2

更新步骤就是贝叶斯法则：

p(\mathbf{z}_t|\mathbf{y}_{1:t}) = \frac{1}{Z_t} p(\mathbf{y}_t|\mathbf{z}_t) p(\mathbf{z}_t|\mathbf{y}_{1:t-1}) (8.5)

其中归一化常数是

Z_t = \int p(\mathbf{y}_t|\mathbf{z}_t) p(\mathbf{z}_t|\mathbf{y}_{1:t-1}) d\mathbf{z}_t = p(\mathbf{y}_t|\mathbf{y}_{1:t-1}) (8.6)

我们可以使用归一化常数来按如下方式计算序列的对数似然：

\log p(\mathbf{y}_{1:T}) = \sum_{t=1}^T \log p(\mathbf{y}_t|\mathbf{y}_{1:t-1}) = \sum_{t=1}^T \log Z_t (8.7)

其中我们定义 \(p(\mathbf{y}_1|\mathbf{y}_0) = p(\mathbf{y}_1)\)。此量对于计算参数的 MLE 很有用。

## 8.1.3 贝叶斯平滑方程

在离线设置中，我们想要计算 \(p(\mathbf{z}_t|\mathbf{y}_{1:T})\)，即在给定所有数据（包括过去和未来）时对时刻 t 的隐藏状态的信念。这称为（固定区间）平滑。我们首先执行前向或滤波通道，然后通过从右（时间 t = T）到左（t = 1）逆向计算来得到平滑的信念状态，如下文所述。因此，这种方法也称为前向滤波后向平滑或 FFBS。

假设通过归纳，我们已经计算出了 \(p(\mathbf{z}_{t+1}|\mathbf{y}_{1:T})\)。我们可以使用以下公式将其转换为两个连续时间步上的联合平滑分布：

p(\mathbf{z}_t, \mathbf{z}_{t+1}|\mathbf{y}_{1:T}) = p(\mathbf{z}_t|\mathbf{z}_{t+1}, \mathbf{y}_{1:T}) p(\mathbf{z}_{t+1}|\mathbf{y}_{1:T}) (8.8)

为了推导第一项，请注意，根据模型的马尔可夫性质和贝叶斯法则，我们有

p(\mathbf{z}_t|\mathbf{z}_{t+1}, \mathbf{y}_{1:T}) = p(\mathbf{z}_t|\mathbf{z}_{t+1}, \mathbf{y}_{1:t}, \mathbf{y}_{t+1:T}) (8.9)

= \frac{p(\mathbf{z}_t, \mathbf{z}_{t+1}|\mathbf{y}_{1:t})}{p(\mathbf{z}_{t+1}|\mathbf{y}_{1:t})} (8.10)

= \frac{p(\mathbf{z}_{t+1}|\mathbf{z}_t) p(\mathbf{z}_t|\mathbf{y}_{1:t})}{p(\mathbf{z}_{t+1}|\mathbf{y}_{1:t})} (8.11)

因此，两个连续时间步上的联合分布由以下公式给出：

p(\mathbf{z}_t, \mathbf{z}_{t+1}|\mathbf{y}_{1:T}) = p(\mathbf{z}_t|\mathbf{z}_{t+1}, \mathbf{y}_{1:T}) p(\mathbf{z}_{t+1}|\mathbf{y}_{1:T}) = \frac{p(\mathbf{z}_{t+1}|\mathbf{z}_t) p(\mathbf{z}_t|\mathbf{y}_{1:t}) p(\mathbf{z}_{t+1}|\mathbf{y}_{1:T})}{p(\mathbf{z}_{t+1}|\mathbf{y}_{1:t})} (8.12)

2. 如果将 \(p(\mathbf{z}_1)\) 作为输入提供给模型，则在 t = 1 时不需要预测步骤。但是，如果我们只提供 \(p(\mathbf{z}_0)\)，则需要应用预测步骤来计算 \(p(\mathbf{z}_1|\mathbf{y}_{1:0}) = p(\mathbf{z}_1)\)。

由此我们得到新的平滑边缘分布：

\(p(\mathbf{z}_t|\mathbf{y}_{1:T}) = p(\mathbf{z}_t|\mathbf{y}_{1:t}) \int \left[ \frac{p(\mathbf{z}_{t+1}|\mathbf{z}_t)p(\mathbf{z}_{t+1}|\mathbf{y}_{1:T})}{p(\mathbf{z}_{t+1}|\mathbf{y}_{1:t})} \right] d\mathbf{z}_{t+1}\)

\(= \int p(\mathbf{z}_t, \mathbf{z}_{t+1}|\mathbf{y}_{1:t}) \frac{p(\mathbf{z}_{t+1}|\mathbf{y}_{1:T})}{p(\mathbf{z}_{t+1}|\mathbf{y}_{1:t})} d\mathbf{z}_{t+1}\)

直观地，我们可以这样解释：我们从两片滤波分布 \(p(\mathbf{z}_t, \mathbf{z}_{t+1}|\mathbf{y}_{1:t})\) 开始，然后除去旧的 \(p(\mathbf{z}_{t+1}|\mathbf{y}_{1:t})\) 并乘上新的 \(p(\mathbf{z}_{t+1}|\mathbf{y}_{1:T})\)，最后对 \(\mathbf{z}_{t+1}\) 进行边缘化。

## 8.1.4 高斯假设

一般来说，计算实现贝叶斯滤波和平滑所需的积分是不可处理的。但是，有两个显著例外：如果状态空间是离散的，如 HMM 中的情况，我们可以将信念状态表示为离散分布（直方图），并可以使用前向-后向算法进行更新，如第 9.2 节所讨论；如果 SSM 是线性高斯模型，那么我们可以用高斯分布表示信念状态，并可以使用卡尔曼滤波和平滑进行更新，我们将在第 8.2.2 节和第 8.2.3 节中讨论。在非线性和/或非高斯设置中，我们仍然可以用高斯分布表示近似信念状态，如第 8.3 节、第 8.4 节、第 8.5 节和第 8.6 节所讨论。我们将在第 8.7 节中讨论一些非高斯近似。

在本章的大部分内容中，我们假设 SSM 可以写成受加性高斯噪声影响的非线性模型：

\(\mathbf{z}_t = \mathbf{f}(\mathbf{z}_{t-1}, \mathbf{u}_t) + \mathcal{N}(\mathbf{0}, \mathbf{Q}_t)\)
\(\mathbf{y}_t = \mathbf{h}(\mathbf{z}_t, \mathbf{u}_t) + \mathcal{N}(\mathbf{0}, \mathbf{R}_t)\)

其中 \(\mathbf{f}\) 是转移或动态函数，\(\mathbf{h}\) 是观测函数。在某些情况下，我们将进一步假设这些函数是线性的。

## 8.2 线性高斯 SSM 的推断

在本节中，我们讨论所有分布均为线性高斯的 SSM 中的推断。这称为**线性高斯状态空间模型（LG-SSM）**或**线性动态系统（LDS）**。我们将在第 29.6 节详细讨论此类模型，但简言之，它们具有以下形式：

\(p(\mathbf{z}_t|\mathbf{z}_{t-1}, \mathbf{u}_t) = \mathcal{N}(\mathbf{z}_t|\mathbf{F}_t\mathbf{z}_{t-1} + \mathbf{B}_t\mathbf{u}_t + \mathbf{b}_t, \mathbf{Q}_t)\)
\(p(\mathbf{y}_t|\mathbf{z}_t, \mathbf{u}_t) = \mathcal{N}(\mathbf{y}_t|\mathbf{H}_t\mathbf{z}_t + \mathbf{D}_t\mathbf{u}_t + \mathbf{d}_t, \mathbf{R}_t)\)

其中 \(\mathbf{z}_t \in \mathbb{R}^{N_z}\) 是隐藏状态，\(\mathbf{y}_t \in \mathbb{R}^{N_y}\) 是观测值，\(\mathbf{u}_t \in \mathbb{R}^{N_u}\) 是输入。（我们已允许参数随时间变化，以便考虑以后的扩展。）我们通常假设过程噪声和观测噪声的均值（即偏置或偏移项）为零，因此 \(\mathbf{b}_t = \mathbf{0}\) 且 \(\mathbf{d}_t = \mathbf{0}\)。此外，我们通常没有输入，因此 \(\mathbf{B}_t = \mathbf{D}_t = \mathbf{0}\)。在这种情况下，模型
