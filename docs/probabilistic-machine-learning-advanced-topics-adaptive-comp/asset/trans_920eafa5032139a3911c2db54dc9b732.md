由 STS 模型给出。在 [SSF16; See+17] 中，他们考虑了形式为 \(y_t \sim \text{Poi}(y_t|g(d_t^y))\) 的似然，其中 \(d_t = z_t + \mathbf{u}_t^T \mathbf{w}\) 是瞬时潜在需求，\(\mathbf{u}_t\) 是编码季节性指标（例如，距离节假日的时间距离）的协变量，而 \(g(d) = e^d\) 或 \(\log(1+e^d)\) 是传递函数。动态模型是一个局部随机游走项，且 \(z_t = z_{t-1} + \alpha \mathcal{N}(0,1)\)，以捕捉数据中的序列相关性。

然而，有时我们观察到零计数，\(y_t = 0\)，并非因为没有需求，而是因为没有供应（即，我们缺货）。如果我们不对此进行适当建模，可能会错误地推断 \(z_t = 0\)，从而低估需求，这可能导致未来订购的库存不足，进一步加剧错误。

一种解决方案是为似然使用 **零膨胀泊松 (ZIP)** 模型 [Lam92]。这是一种形式为 \(p(y_t|d_t) = p_0 \mathbb{I}(y_t=0) + (1-p_0) \text{Poi}(y_t|e^{d_t})\) 的混合模型，其中 \(p_0\) 是第一个混合分量的概率。也常使用（可能是零膨胀的）负二项式模型（第 2.2.1.4 节）作为似然。这在 [Cha14; Sal+19b] 中用于需求预测问题。这些似然的缺点是对于 \(d_t=0\) 它们不是对数凹的，这使得后验推断变得复杂。特别是，拉普拉斯近似是不好的选择，因为它可能找到鞍点。在 [SSF16] 中，他们通过使用对数凹 **多阶似然** 来解决这个问题，其中 \(y_t=0\) 以概率 \(\sigma(d_0^2)\) 发出；否则 \(y_t=1\) 以概率 \(\sigma(d_1^2)\) 发出；否则 \(y_t\) 以概率 \(\text{Poi}(d_t^2)\) 发出。这推广了 [SOB12] 中的方案。

### 29.12.5.4 示例：选举面板数据的分层 SSM

假设我们为美国总统选举进行一项调查。设 \(N_t^j\) 为时间 t 在州 j 投票的人数，设 \(y_t^j\) 为其中投民主党票的人数。（我们假设 \(N_t^j - y_t^j\) 投共和党。）自然希望对这些数据在时间上（纵向）和空间上的依赖关系进行建模（这是 **面板数据** 的一个示例）。

我们可以使用分层 SSM 来做到这一点，如图 29.38 所示。最高级别的马尔可夫链 \(z_t^0\) 建模国家级趋势，而州特定的链 \(z_t^j\) 建模局部“随机效应”。在实践中，我们通常还会在国家级 \(\mathbf{u}_t^0\) 和州级 \(\mathbf{u}_t^j\) 中包含协变量。

## 29.12.6 时间序列干预的因果影响

在本节中，我们讨论如何在给定一些 **准实验** 时间序列数据的情况下估计干预的因果效应。（术语“准实验”意味着数据是在干预下收集的，但没有使用随机分配。）例如，假设 \(y_t\) 是时间 t 某公司网页的点击率（CTR）。该公司在时间 n 启动广告活动，并观察干预前的结果 \(\mathbf{y}_{1:n}\) 和干预后的结果 \(\mathbf{y}_{n+1:m}\)。（这是一个 **中断时间序列** 的示例，因为“自然”过程在某个时间点受到了干扰。）一个自然的问题是：如果该公司没有运行广告活动，CTR 会是多少？这是一个 **反事实** 问题。（我们在第 4.7.4 节讨论反事实。）如果我们能预测这个反事实时间序列 \(\tilde{\mathbf{y}}_{n+1:m}\)，那么我们将实际的 \(y_t\) 与预测的 \(\tilde{y}_t\) 进行比较，并用此来估计干预的 **因果影响**。

为了预测反事实结果，我们将使用结构时间序列 (STS) 模型（参见第 29.12 节），遵循 [Bro+15]。STS 模型是一种线性高斯状态空间模型，其中箭头具有关于 **时间箭头** 的自然因果解释；因此 STS 是一种结构方程模型，进而也是结构因果模型（参见第 4.7 节）。使用 SCM 使我们能够在给定观测数据的情况下推断噪声变量的潜在状态；然后我们可以“回滚时间”到干预点，在那里通过在模型的新版本中“向前滚动时间”来探索我们实际上所走的那条路之外的另一条“分叉路口”，使用 **双网络** 方法进行反事实推断（参见第 4.7.4 节）。

### 29.12.6.1 计算反事实预测

为了更详细地解释该方法，请考虑图 29.39 中的双网络。干预发生在时间 n = 2 之后，总共有 m = 4 个观测值。我们在干预前观察到 2 个数据点 y₁:₂，之后观察到 2 个数据点 y₃:₄。我们假设观测值由潜在状态 z₁:₄ 生成，这些状态随时间演变。状态受到外生噪声项的影响，这些噪声项可以表示任何未建模因素，例如经济状况。此外，我们还有外生协变量 x₁:ₘ。

为了预测如果我们没有执行干预（用 ã = 0 表示的事件）会发生什么，我们复制干预后发生的模型部分，并用其进行预测。目标是计算反事实分布 p(ỹₙ₊₁:ₘ|y₁:ₙ, x₁:ₘ)，其中 ỹₜ 表示如果动作为 ã = 0 的反事实结果。我们可以按如下方式计算这个反事实分布：

$$
p(\tilde{y}_{n+1:m}|y_{1:n}, x_{1:m}) = \int p(\tilde{y}_{n+1:m}|\tilde{z}_{n+1:m}, x_{n+1:m}, \theta)p(\tilde{z}_{n+1:m}|z_n, \theta) \times p(z_n, \theta|x_{1:n}, y_{1:n}) d\theta dz_n d\tilde{z}_{n+1:m}
$$

其中

$$
p(z_n, \theta|x_{1:n}, y_{1:n}) = p(z_n|x_{1:n}, y_{1:n}, \theta)p(\theta|x_{1:n}, y_{1:n})
$$

对于线性高斯 SSM，项 \(p(z_n|x_{1:n}, y_{1:n}, \theta)\) 可以使用卡尔曼滤波（第 8.2.2 节）计算，项 \(p(\theta|y_{1:n}, x_{1:n})\) 可以使用 MCMC 或变分推断计算。
