

我们定义随机变量可能取值的集合为其 **状态空间**，记作 \(X(\Omega) = \mathcal{X}\)。我们使用以下公式定义任意给定状态的概率：

\(p_X(a) = \mathbb{P}[X = a] = \mathbb{P}[X^{-1}(a)]\) (2.1)

其中 \(X^{-1}(a) = \{\omega \in \Omega | X(\omega) = a\}\) 是 \(a\) 的原像。这里 \(p_X\) 称为随机变量 \(X\) 的 **概率质量函数** 或 **pmf**。在掷两次公平硬币的示例中，pmf 为 \(p_X(0) = \mathbb{P}[\{(T, T)\}] = \frac{1}{4}\)、\(p_X(1) = \mathbb{P}[\{(T, H), (H, T)\}] = \frac{2}{4}\) 和 \(p_X(2) = \mathbb{P}[\{(H, H)\}] = \frac{1}{4}\)。pmf 可以用直方图或某个参数函数表示（参见第 2.2.1 节）。我们称 \(p_X\) 为随机变量 \(X\) 的 **概率分布**。当上下文清楚时，我们常会从 \(p_X\) 中省略下标 \(X\)。

## 2.1.3 连续随机变量

我们也可以考虑具有连续结果的实验。在此情况下，我们假设样本空间是实数的一个子集，\(\Omega \subseteq \mathbb{R}\)，并将每个连续随机变量定义为恒等函数，\(X(\omega) = \omega\)。例如，考虑测量某个事件的持续时间（秒）。我们定义样本空间为 \(\Omega = \{t : 0 \le t \le T_{\max}\}\)。由于这是一个不可数集，我们无法像离散情况那样通过枚举来定义所有可能的子集。相反，我们需要使用 **博雷尔 σ-场**（也称为 **博雷尔 σ-代数**）来定义事件空间。我们说 \(\mathcal{F}\) 是一个 σ-场，如果 (1) \(\emptyset \in \mathcal{F}\) 且 \(\Omega \in \mathcal{F}\)；(2) \(\mathcal{F}\) 对补集封闭，即如果 \(E \in \mathcal{F}\)，则 \(E^c \in \mathcal{F}\)；以及 (3) \(\mathcal{F}\) 对可数并和交封闭，即 \(\bigcup_{i=1}^\infty E_i \in \mathcal{F}\) 且 \(\cap_{i=1}^\infty E_i \in \mathcal{F}\)，前提是 \(E_1, E_2, \dots \in \mathcal{F}\)。最后，我们说 \(\mathcal{B}\) 是一个博雷尔 σ-场，如果它是由形式为 \((-\infty, b] = \{x : -\infty < x \le b\}\) 的半闭区间生成的 σ-场。通过对这些区间取并、交和补，我们可以看到 \(\mathcal{B}\) 包含以下集合：

\((a, b], [a, b], (a, b], [a, b], \{b\}, -\infty \le a \le b \le \infty\) (2.2)

在持续时间示例中，我们可以进一步将事件空间限制为仅包含下界为 0 且上界 \(\le T_{\max}\) 的区间。

为了定义概率度量，我们为每个 \(x \in \Omega\) 分配一个权函数 \(p_X(x) \ge 0\)，称为 **概率密度函数** 或 **pdf**。常见 pdf 列表请参见第 2.2.2 节。然后，我们可以使用以下公式推导事件 \(E = [a, b]\) 的概率：

\(\mathbb{P}[(a, b)] = \int_E d\mathbb{P} = \int_a^b p(x)dx\) (2.3)

我们还可以定义随机变量 \(X\) 的 **累积分布函数** 或 **cdf** 如下：

\(P_X(x) \triangleq \mathbb{P}[X \le x] = \int_{-\infty}^x p_X(x') dx'\) (2.4)

从此，我们可以使用以下公式计算区间的概率：

\(\mathbb{P}[(a, b)] = p(a \le X \le b) = P_X(b) - P_X(a)\) (2.5)

术语“概率分布”可能指 pdf \(p_X\)、cdf \(P_X\)，甚至概率度量 \(\mathbb{P}\)。

我们可以将上述定义推广到多维空间 \(\Omega \subseteq \mathbb{R}^n\)，以及更复杂的样本空间，例如函数空间。

## 2.1.4 概率公理

与事件空间相关的概率定律必须遵循 **概率公理**（也称为 **柯尔莫戈罗夫公理**），如下所示：

- 非负性：对于任何 \(E \subseteq \Omega\)，\(\mathbb{P}[E] \ge 0\)。
- 归一化：\(\mathbb{P}[\Omega] = 1\)。
- 可加性：对于任意两两不相交的可数集序列 \(\{E_1, E_2, \dots\}\)，有

\[
\mathbb{P}[\cup_{i=1}^\infty E_i] = \sum_{i=1}^\infty \mathbb{P}[E_i]
\] (2.6)

在有限情况下，若仅有两个不相交集 \(E_1\) 和 \(E_2\)，则变为

\[
\mathbb{P}[E_1 \cup E_2] = \mathbb{P}[E_1] + \mathbb{P}[E_2]
\] (2.7)

这对应于事件 \(E_1\) 或 \(E_2\) 的概率，前提是它们互斥（不相交集）。

从这些公理中，我们可以推导出 **补集法则**：

\[
\mathbb{P}[E^c] = 1 - \mathbb{P}[E]
\] (2.8)

其中 \(E^c = \Omega \setminus E\) 是 \(E\) 的补集。（这是因为 \(\mathbb{P}[\Omega] = 1 = \mathbb{P}[E \cup E^c] = \mathbb{P}[E] + \mathbb{P}[E^c]\)。）

我们还可以证明 \(\mathbb{P}[E] \le 1\)（反证法），以及 \(\mathbb{P}[\emptyset] = 0\)（这由第一推论在 \(E = \Omega\) 时得出）。

我们还可以展示以下结果，称为 **加法法则**：

\[
\mathbb{P}[E_1 \cup E_2] = \mathbb{P}[E_1] + \mathbb{P}[E_2] - \mathbb{P}[E_1 \cap E_2]
\] (2.9)

这对任意一对事件均成立，即使它们不相交。

## 2.1.5 条件概率

考虑两个事件 \(E_1\) 和 \(E_2\)。如果 \(\mathbb{P}[E_2] \neq 0\)，我们定义在给定 \(E_2\) 下 \(E_1\) 的 **条件概率** 为

\[
\mathbb{P}[E_1|E_2] \triangleq \frac{\mathbb{P}[E_1 \cap E_2]}{\mathbb{P}[E_2]}
\] (2.10)

由此，我们可以得到 **乘法法则**：

\[
\mathbb{P}[E_1 \cap E_2] = \mathbb{P}[E_1|E_2]\mathbb{P}[E_2] = \mathbb{P}[E_2|E_1]\mathbb{P}[E_1]
\] (2.11)

- 这些定律可证明源于关于在不确定性下推理的一组更基本假设，该结果称为 **Cox 定理** [Cox46; Cox61]。

条件概率衡量在事件 \(E_2\) 已发生的情况下，事件 \(E_1\) 发生的可能性。然而，如果事件无关，概率不会改变。形式上，我们说 \(E_1\) 和 \(E_2\) 是 **独立事件**，如果

\[
\mathbb{P}[E_1 \cap E_2] = \mathbb{P}[E_1]\mathbb{P}[E_2]
\] (2.12)

如果 \(\mathbb{P}[E_1] > 0\) 且 \(\mathbb{P}[E_2] > 0\) 均成立，这等价于要求 \(\mathbb{P}[E_1|E_2] = \mathbb{P}[E_1]\) 或等价地，\(\mathbb{P}[E_2|E_1] = \mathbb{P}[E_2]\)。类似地，我们说 \(E_1\) 和 \(E_2\) 在给定 \(E_3\) 下条件独立，如果

\[
\mathbb{P}[E_1 \cap E_2|E_3] = \mathbb{P}[E_1|E_3]\mathbb{P}[E_2|E_3]
\] (2.13)

从条件概率的定义出发，我们可以推导出 **全概率公式**，其内容如下：如果 \(\{A_1, \dots, A_n\}\) 是样本空间 \(\Omega\) 的一个划分，则对于任意事件 \(B \subseteq \Omega\)，有

\[
\mathbb{P}[B] = \sum_{i=1}^n \mathbb{P}[B|A_i]\mathbb{P}[A_i]
\] (2.14)

## 2.1.6 贝叶斯法则

从条件概率的定义出发，我们可以推导出 **贝叶斯法则**（也称为 **贝叶斯定理**），即对于任意两个事件 \(E_1\) 和 \(E_2\)，若 \(\mathbb{P}[E_1] > 0\) 且 \(\mathbb{P}[E_2] > 0\)，则有

\[
\mathbb{P}[E_1|E_2] = \frac{\mathbb{P}[E_2|E_1]\mathbb{P}[E_1]}{\mathbb{P}[E_2]}
\] (2.15)

对于具有 \(K\) 个可能状态的离散随机变量 \(X\)，我们可以使用全概率公式将贝叶斯法则写为：

\[
p(X=k|E) = \frac{p(E|X=k)p(X=k)}{p(E)} = \frac{p(E|X=k)p(X=k)}{\sum_{k'=1}^K p(E|X=k')p(X=k')}
\] (2.16)

这里 \(p(X=k)\) 是 **先验概率**，\(p(E|X=k)\) 是 **似然**，\(p(X=k|E)\) 是 **后验概率**，而 \(p(E)\) 是一个归一化常数，称为 **边际似然**。

类似地，对于连续随机变量 \(X\)，我们可以将贝叶斯法则写为：

\[
p(X=x|E) = \frac{p(E|X=x)p(X=x)}{p(E)} = \frac{p(E|X=x)p(X=x)}{\int p(E|X=x')p(X=x')dx'}
\] (2.17)

## 2.2 常见概率分布

有多种多样的概率分布用于各种模型。我们在下面的章节中总结了一些更常用的分布。更多信息请参见补充章节 2，以及 https://ben18785.shinyapps.io/distribution-zoo/ 以获取交互式可视化。

### 2.2.1 离散分布

在本节中，我们讨论一些定义在（非负）整数子集上的离散分布。

### 2.2.1.1 伯努利分布和二项分布

令 \(x \in \{0, 1, \dots, N\}\)。二项分布定义为

\[
\text{Bin}(x|N, \mu) \triangleq \binom{N}{x} \mu^x (1 - \mu)^{N-x}
\]

其中 \(\binom{N}{k} \triangleq \frac{N!}{(N-k)!k!}\) 是从 \(N\) 个中选 \(k\) 个的方法数（这称为二项式系数，读作 “N 选 k”）。

如果 \(N=1\)，即 \(x \in \{0, 1\}\)，二项分布退化为伯努利分布：

\[
\text{Ber}(x|\mu) = \begin{cases} 1 - \mu & \text{若 } x = 0 \\ \mu & \text{若 } x = 1 \end{cases}
\]

其中 \(\mu = \mathbb{E}[x] = p(x=1)\) 是均值。

### 2.2.1.2 类别分布和多项分布

如果变量是离散值的，\(x \in \{1, \dots, K\}\)，我们可以使用类别分布：

\[
\text{Cat}(x|\theta) \triangleq \prod_{k=1}^K \theta_k^{\mathbb{I}(x=k)}
\]

或者，我们可以用 one-hot 向量 \(\boldsymbol{x}\) 表示 \(K\) 值变量 \(x\)，从而写成

\[
\text{Cat}(\boldsymbol{x}|\theta) \triangleq \prod_{k=1}^K \theta_k^{x_k}
\]

如果 \(\boldsymbol{x}\) 的第 \(k\) 个元素计数了在 \(N = \sum_{k=1}^K x_k\) 次试验中值 \(k\) 出现的次数，则得到多项分布：

\[
\mathcal{M}(\boldsymbol{x}|N, \boldsymbol{\theta}) \triangleq \binom{N}{x_1 \dots x_K} \prod_{k=1}^K \theta_k^{x_k}
\]

其中多项式系数定义为

\[
\binom{N}{k_1 \dots k_m} \triangleq \frac{N!}{k_1! \dots k_m!}
\]
