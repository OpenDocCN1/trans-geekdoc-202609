# 2.3.2.2 Posterior distribution (Bayes' rule for Gaussians)

Now we consider computing the posterior \( p(z|y) \) from a linear Gaussian system. Using Equation (2.78) for conditioning a joint Gaussian, we find that the posterior is given by

```
\( p(z|y) = \mathcal{N}(z | \hat{\mu}, \hat{\Sigma}) \)
\( \hat{\mu} = \tilde{\mu} + \tilde{\Sigma} \mathbf{W}^T (\Omega + \mathbf{W} \tilde{\Sigma} \mathbf{W}^T)^{-1} (y - (\mathbf{W} \tilde{\mu} + b)) \)
\( \hat{\Sigma} = \tilde{\Sigma} - \tilde{\Sigma} \mathbf{W}^T (\Omega + \mathbf{W} \tilde{\Sigma} \mathbf{W}^T)^{-1} \mathbf{W} \tilde{\Sigma} \)
```

This is known as Bayes' rule for Gaussians. We see that if the prior \( p(z) \) is Gaussian, and the likelihood \( p(y|z) \) is Gaussian, then the posterior \( p(z|y) \) is also Gaussian. We therefore say that the Gaussian prior is a conjugate prior for the Gaussian likelihood, since the posterior distribution has the same type as the prior. (In other words, Gaussians are closed under Bayesian updating.)

We can simplify these equations by defining \( \mathbf{S} = \mathbf{W} \tilde{\Sigma} \mathbf{W}^T + \Omega \), \( \mathbf{C} = \tilde{\Sigma} \mathbf{W}^T \), and \( \mathbf{m} = \mathbf{W} \tilde{\mu} + b \), as in Equation (2.120). We also define the Kalman gain matrix:\(^8\)

```
\( \mathbf{K} = \mathbf{C} \mathbf{S}^{-1} \)
```

From this, we get the posterior

```
\( \hat{\mu} = \tilde{\mu} + \mathbf{K} (y - \mathbf{m}) \)
\( \hat{\Sigma} = \tilde{\Sigma} - \mathbf{K} \mathbf{C}^T \)
```

Note that

```
\( \mathbf{K} \mathbf{S} \mathbf{K}^T = \mathbf{C} \mathbf{S}^{-1} \mathbf{S} \mathbf{S}^{-T} \mathbf{C}^T = \mathbf{C} \mathbf{S}^{-1} \mathbf{C}^T = \mathbf{K} \mathbf{C}^T \)
```

and hence we can also write the posterior covariance as

```
\( \hat{\Sigma} = \tilde{\Sigma} - \mathbf{K} \mathbf{S} \mathbf{K}^T \)
```

Using the matrix inversion lemma from Equation (2.93), we can also rewrite the posterior in the following form [Bis06, p93], which takes \( O(L^3) \) time instead of \( O(D^3) \) time:

```
\( \hat{\Sigma} = (\tilde{\Sigma}^{-1} + \mathbf{W}^T \Omega^{-1} \mathbf{W})^{-1} \)
\( \hat{\mu} = \hat{\Sigma} [\mathbf{W}^T \Omega^{-1} (y - \mathbf{b}) + \tilde{\Sigma}^{-1} \tilde{\mu}] \)
```

Finally, note that the corresponding normalization constant for the posterior is just the marginal on \( y \) evaluated at the observed value:

```
\( p(y) = \int \mathcal{N}(z | \tilde{\mu}, \tilde{\Sigma}) \mathcal{N}(y | \mathbf{W} z + b, \Omega) dz \)
\( = \mathcal{N}(y | \mathbf{W} \tilde{\mu} + b, \Omega + \mathbf{W} \tilde{\Sigma} \mathbf{W}^T) = \mathcal{N}(y | \mathbf{m}, \mathbf{S}) \)
```

From this, we can easily compute the log marginal likelihood. We summarize all these equations in Algorithm 8.1.
