## 26.3 生成对抗网络

我们研究了不同的学习原则，这些原则不需要使用显式似然，因此可以用于训练隐式模型。这些学习原则指定了训练准则，但不告诉我们如何训练隐式模型或对模型进行参数化。为了回答这些问题，我们现在研究训练隐式模型的算法，其中模型（判别器和生成器）都是深度神经网络；这引导我们进入生成对抗网络（GANs）。我们将介绍如何将学习原则转化为训练GAN的损失函数（第26.3.1节）；如何使用梯度下降训练模型（第26.3.2节）；如何改进GAN优化（第26.3.4节）以及如何评估GAN收敛性（第26.3.5节）。

### 26.3.1 从学习原则到损失函数

在第26.2节中，我们讨论了隐式生成模型的学习原则：类概率估计、f-散度界、积分概率度量和矩匹配。这些原则可用于制定损失函数，以训练模型参数\(\theta\)和评价器参数\(\phi\)。这些目标中的许多通过最小-最大表述使用零和损失：生成器的目标是最小化判别器正在最大化的同一函数。我们可以将其形式化为：

```
min max \( V(\phi, \theta) \) (26.41)
```

作为示例，当

```
\( V(\phi, \theta) = \frac{1}{2}\mathbb{E}_{p^*(x)}[\log D_\phi(x)] + \frac{1}{2}\mathbb{E}_{q_\theta(x)}[\log(1 - D_\phi(x))]. \) (26.42)
```

时，我们可以使用伯努利对数损失（方程（26.19））恢复原始GAN。

我们所讨论的大多数学习原则导致零和损失的原因在于其底层结构：评价器最大化一个量以近似偏差或距离——例如f-散度或积分概率度量——而模型最小化这种对偏差或距离的近似。然而，情况未必如此。直觉上，判别器训练准则需要确保判别器能够区分数据和模型样本，而生成器损失函数需要确保模型样本根据判别器与数据不可区分。

要构建一个非零和GAN，请考虑由伯努利评分规则诱导的原始GAN中的零和准则（方程26.42）。判别器通过将数据分类为真实（标签1）和样本分类为假（标签0）来尝试区分数据和模型样本，而生成器的目标是最小化判别器将其样本分类为假的概率：\(\min_{\theta} \mathbb{E}_{q_\theta(x)} \log(1 - D_\phi(x))\)。生成器一个同样直观的目标是最大化判别器将其样本分类为真实的概率。虽然差异可能看起来很微妙，但这种损失，称为“非饱和损失” [Goo+14]，定义为\(\mathbb{E}_{q_\theta(x)} - \log D_\phi(x)\)，在训练早期享有更好的梯度特性，如图26.5所示：当生成器表现不佳且判别器能轻易将其样本与数据区分开来（即\(D(G(z))\)较低）时，非饱和损失提供更强的学习信号（通过梯度）；关于饱和和非饱和损失的梯度特性的更多内容可见 [AB17; Fed+18]。

存在许多其他非零和GAN损失，包括LS-GAN [Mao+17]、使用铰链损失训练的GAN [LY17]和相对论GAN [JM18]的表述。因此，我们可以通常将GAN表述写成如下：

```
\(\min_{\phi} L_D(\phi, \theta); \quad \min_{\theta} L_G(\phi, \theta). \quad (26.43)\)
```

如果\(-L_D(\phi, \theta) = L_G(\phi, \theta) = V(\phi, \theta)\)，则可恢复零和表述。尽管偏离了零和结构，但一般表述中的优化嵌套形式仍然存在，我们将在第26.3.2节中讨论这一点。

判别器和生成器的损失函数，分别为\(L_D\)和\(L_G\)，遵循方程26.5中的一般形式，这使得它们能够用于高效训练隐式生成模型。因此，此处考虑的大多数损失函数可以写成如下形式：

```
\(L_D(\phi, \theta) = \mathbb{E}_{p^*(x)} g(D_\phi(x)) + \mathbb{E}_{q_\theta(x)} h(D_\phi(x)) = \mathbb{E}_{p^*(x)} g(D_\phi(x)) + \mathbb{E}_{q(z)} h(D_\phi(G_\theta(z))) \quad (26.44)\)
\(L_G(\phi, \theta) = \mathbb{E}_{q_\theta(x)} l(D_\phi(x)) = \mathbb{E}_{q(z)} l(D_\phi(G_\theta(z))) \quad (26.45)\)
```

其中\(g, h, l : \mathbb{R} \rightarrow \mathbb{R}\)。当\(g(t) = -\log t, h(t) = -\log(1 - t)\)且\(l(t) = \log(1 - t)\)时，我们恢复原始GAN；当\(g(t) = -\log t, h(t) = -\log(1 - t)\)且\(l(t) = -\log(t)\)时，为非饱和损失；当\(g(t) = t, h(t) = -t\)且\(l(t) = t\)时，为Wasserstein距离表述；对于f-散度，\(g(t) = t, h(t) = -f'(t)\)且\(l(t) = f^*(t)\)。

### 26.3.2 梯度下降

GANs在判别器和生成器的参数上采用上述学习原则，结合基于梯度的学习。我们假设一个带有判别器损失函数\(L_D(\phi, \theta)\)和生成器损失函数\(L_G(\phi, \theta)\)的一般表述。由于判别器通常被引入以近似距离或偏差\(D(p^*, q_\theta)\)（第26.2节），为了使生成器最小化该偏差的良好近似，应在每次生成器更新时完全求解判别器优化。这意味着对于每次生成器更新，首先要找到最优判别器参数\(\phi^* = \arg\min_\phi L_D(\phi, \theta)\)，以便执行由\(\nabla_\theta L_G(\phi^*, \theta)\)给出的梯度更新。完全求解内层优化问题\(\phi^* = \arg\min_\phi L_D(\phi, \theta)\)

对生成器的每次优化步骤来说，这样做在计算上开销过大，这促使使用交替更新：执行几个梯度步骤来更新判别器参数，然后进行生成器更新。请注意，更新判别器时，我们保持生成器参数固定；更新生成器时，我们保持判别器参数固定。我们在算法26.1中展示了这些交替更新的一般算法。

```
Algorithm 26.1: General GAN training algorithm with alternating updates
1 Initialize \phi, \theta
2 for each training iteration do
3   for K steps do
4     Update the discriminator parameters \phi using the gradient \nabla_\phi L_D(\phi, \theta);
5     Update the generator parameters \theta using the gradient \nabla_\theta L_G(\phi, \theta)
6 Return \phi, \theta
```

因此，我们有兴趣计算\(\nabla_\phi L_D(\phi, \theta)\)和\(\nabla_\theta L_G(\phi, \theta)\)。鉴于判别器和生成器的损失函数选择遵循方程26.44和26.45中的一般形式，我们可以计算可用于训练的梯度。要计算判别器梯度，我们写：

```
\nabla_\phi L_D(\phi, \theta) = \nabla_\phi [ \mathbb{E}_{p^*(x)} g(D_\phi(x)) + \mathbb{E}_{q_\theta(x)} h(D_\phi(x)) ] (26.46)
= \mathbb{E}_{p^*(x)} \nabla_\phi g(D_\phi(x)) + \mathbb{E}_{q_\theta(x)} \nabla_\phi h(D_\phi(x)) (26.47)
```

其中\(\nabla_\phi g(D_\phi(x))\)和\(\nabla_\phi h(D_\phi(x))\)可以通过反向传播计算，每个期望都可以使用蒙特卡洛估计进行估计。对于生成器，我们希望计算梯度：

```
L_G(\phi, \theta) = \nabla_\theta \mathbb{E}_{q_\theta(x)} l(D_\phi(x)) (26.48)
```
