

## 35.3.2 REINFORCE

应用策略梯度定理来优化策略的一种方法是使用随机梯度上升。假设 $\tau = (s_0, a_0, r_0, s_1, \dots, s_T)$ 是一条轨迹，其中 $s_0 \sim p_0$ 且策略为 $\pi_\theta$。那么，

$$
\nabla_\theta J(\pi_\theta) = \frac{1}{1-\gamma} \mathbb{E}_{p_{\pi_\theta}^\infty(s) \pi_\theta(a|s)} [\nabla_\theta \log \pi_\theta(a|s) Q_{\pi_\theta}(s, a)]
$$

$$
\approx \sum_{t=0}^{T-1} \gamma^t G_t \nabla_\theta \log \pi_\theta(a_t|s_t)
$$

其中回报 $G_t$ 如方程 (34.76) 所定义，因子 $\gamma^t$ 归因于 $p_{\pi_\theta}^\infty$ 的定义，其中时刻 $t$ 的状态被折扣。

我们可以在梯度估计中使用一个基线，以获得以下更新规则：

$$
\theta \leftarrow \theta + \eta \sum_{t=0}^{T-1} \gamma^t (G_t - b(s_t)) \nabla_\theta \log \pi_\theta(a_t|s_t)
$$

这称为 **REINFORCE** 算法 [Wil92]。$^3$ 更新方程可解释如下：我们计算由轨迹诱导的折扣未来奖励之和，与基线相比，如果为正，则增加 $\theta$ 以使该轨迹更可能发生，否则减少 $\theta$。因此，我们强化良好行为，并减少产生不良行为的机会。

我们可以使用常数（与状态无关）基线，或者使用与状态相关的基线 $b(s_t)$ 以进一步降低方差。一种自然选择是使用估计值函数 $V_w(s)$，它可以例如通过 MC 学习。算法 35.2 给出了伪代码，其中使用带有单独学习率的随机梯度更新。

```
**Algorithm 35.2:** REINFORCE with value function baseline
1 Initialize policy parameters $\theta$, baseline parameters $w$
2 repeat
3   Sample an episode $\tau = (s_0, a_0, r_0, s_1, \dots, s_T)$ using $\pi_\theta$
4   Compute $G_t$ for all $t \in \{0, 1, \dots, T-1\}$ using Equation (34.76)
5   for $t = 0, 1, \dots, T-1$ do
6     $\delta = G_t - V_w(s_t)$ // scalar error
7     $w \leftarrow w + \eta_w \delta \nabla_w V_w(s_t)$
8     $\theta \leftarrow \theta + \eta_\theta \gamma^t \delta \nabla_\theta \log \pi_\theta(a_t|s_t)$
9 until converged
```

3. 术语 “REINFORCE” 是 “REward Increment = nonnegative Factor x Offset Reinforcement x Characteristic Eligibility” 的首字母缩写。短语 “characteristic eligibility” 指的是 $\nabla \log \pi_\theta(a_t|s_t)$ 项；短语 “offset reinforcement” 指的是 $G_t - b(s_t)$ 项；而短语 “nonnegative factor” 指的是 SGD 的学习率 $\eta$。

## 35.3.3 演员-批判方法

演员-批判方法 [BSA83] 使用策略梯度方法，但期望回报是通过值函数的时序差分学习来估计，而不是通过 MC 轨迹采样。术语 “actor” 指的是策略，术语 “critic” 指的是值函数。TD 更新中使用自助法相比 MC 可以更高效地学习值函数。此外，它使我们能够开发一个完全在线的、增量的算法，无需等到轨迹结束才更新参数（如算法 35.2 中所示）。

具体来说，考虑在情景任务中使用一步 TD(0) 方法来估计回报，即，我们用 $G_{t:t+1} = r_t + \gamma V_w(s_{t+1})$ 替换 $G_t$。如果使用 $V_w(s_t)$ 作为基线，则方程 (35.25) 中的 REINFORCE 更新变为

$$
\theta \leftarrow \theta + \eta \sum_{t=0}^{T-1} \gamma^t (G_{t:t+1} - V_w(s_t)) \nabla_\theta \log \pi_\theta(a_t|s_t)
$$

$$
= \theta + \eta \sum_{t=0}^{T-1} \gamma^t (r_t + \gamma V_w(s_{t+1}) - V_w(s_t)) \nabla_\theta \log \pi_\theta(a_t|s_t)
$$

### 35.3.3.1 A2C 和 A3C

请注意，$r_{t+1} + \gamma V_w(s_{t+1}) - V_w(s_t)$ 是优势函数 $A(s_t, a_t) = Q(s_t, a_t) - V(s_t)$ 的单样本近似。因此，此方法被称为 **优势演员-批判** 或 **A2C**（算法 35.3）。如果我们并行运行演员并异步更新它们的共享参数，则该方法称为 **异步优势演员-批判** 或 **A3C** [Mni+16]。

```
Algorithm 35.3: Advantage actor critic (A2C) algorithm
1 Initialize actor parameters $\theta$, critic parameters $w$
2 repeat
3   Sample starting state $s_0$ of a new episode
4   for $t = 0, 1, 2, \dots$ do
5     Sample action $a_t \sim \pi_\theta(\cdot|s_t)$
6     Observe next state $s_{t+1}$ and reward $r_t$
7     $\delta = r_t + \gamma V_w(s_{t+1}) - V_w(s_t)$
8     $w \leftarrow w + \eta_w \delta \nabla_w V_w(s_t)$
9     $\theta \leftarrow \theta + \eta_\theta \gamma^t \delta \nabla_\theta \log \pi_\theta(a_t|s_t)$
10 until converged
```

### 35.3.3.2 资格痕迹

在 A2C 中，我们使用单步展开，然后使用值函数来近似轨迹的期望回报。更一般地，我们可以使用 n 步估计

$$
G_{t:t+n} = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \dots + \gamma^{n-1} r_{t+n-1} + \gamma^n V_w(s_{t+n})
$$

并按如下方式获得 n 步优势估计：

$$
A_{\pi_\theta}^{(n)}(s_t, a_t) = G_{t:t+n} - V_w(s_t)
$$

n 步实际奖励是无偏样本，但方差较高。相比之下，$V_w(s_{t+n+1})$ 方差较低，但有偏差。通过改变 $n$，我们可以控制偏差-方差权衡。而不是使用单个 $n$ 值，我们可以采取加权平均，权重与 $\lambda^n$ 成正比，用于 $A_{\pi_\theta}^{(n)}(s_t, a_t)$，如同 TD($\lambda$) 中一样。可以证明该平均值等价于

$$
A_{\pi_\theta}^{(\lambda)}(s_t, a_t) \triangleq \sum_{\ell=0}^{\infty} (\gamma \lambda)^\ell \delta_{t+\ell} \tag{35.30}
$$

其中 $\delta_t = r_t + \gamma V_w(s_{t+1}) - V_w(s_t)$ 是时刻 $t$ 的 TD 误差。这里，$\lambda \in [0, 1]$ 是一个控制偏差-方差权衡的参数：较大的值会降低偏差但增加方差，如同 TD($\lambda$) 中一样。我们可以使用资格痕迹高效实现方程 (35.30)，如算法 35.4 所示，这是 **广义优势估计（GAE）** [Sch+16b] 的示例。更多细节请参见 [SB18, Ch.12]。

```
**Algorithm 35.4: Actor critic with eligibility traces**

1 Initialize actor parameters $\theta$, critic parameters $w$
2 repeat
3   Initialize eligibility trace vectors: $z_\theta \leftarrow \mathbf{0}, z_w \leftarrow \mathbf{0}$
4   Sample starting state $s_0$ of a new episode
5   for $t = 0, 1, 2, ...$ do
6     Sample action $a_t \sim \pi_\theta(\cdot|s_t)$
7     Observe state $s_{t+1}$ and reward $r_t$
8     Compute the TD error: $\delta = r_t + \gamma V_w(s_{t+1}) - V_w(s_t)$
9     $z_w \leftarrow \gamma \lambda z_w + \nabla_w V_w(s_t)$
10    $z_\theta \leftarrow \gamma \lambda z_\theta + \gamma^t \nabla_\theta \log \pi_\theta(a_t|s_t)$
11    $w \leftarrow w + \eta_w \delta z_w$
12    $\theta \leftarrow \theta + \eta_\theta \delta z_\theta$
13 until converged
```

## 35.3.4 边界优化方法

在策略梯度方法中，目标 $J(\theta)$ 不一定单调增加，反而可能会崩溃，尤其是在学习率不够小的情况下。我们现在描述能够保证单调改进的方法，类似于边界优化算法（第 6.5 节）。我们从一个有用的事实开始，该事实关联两个任意策略的策略值 [KL02]：

$$
J(\pi') - J(\pi) = \frac{1}{1-\gamma} \mathbb{E}_{p_\pi^\infty(s)} [\mathbb{E}_{\pi^\prime(a|s)} [A_\pi(s, a)]] \tag{35.31}
$$

其中 $\pi$ 可解释为策略优化过程中的当前策略，而 $\pi'$ 是一个候选新策略（例如相对于 $Q_\pi$ 的贪婪策略）。如同策略改进定理（第 34.6.2 节）中所述，如果对所有 $s$ 都有 $\mathbb{E}_{\pi^\prime(a|s)} [A_\pi(s, a)] \ge 0$，则 $J(\pi') \ge J(\pi)$。然而，当使用函数近似时，我们无法确保此条件成立，因为这样一致改进的策略 $\pi'$ 可能无法由我们的参数族 $\{\pi_\theta\}_{\theta \in \Theta}$ 表示。因此，当我们没有直接从 $p_\pi^\infty$ 采样状态的方法时，方程 (35.31) 的非负性不容易确保。

确保 $J$ 单调改进的一种方法是保守地改进策略。对于 $\theta \in [0, 1]$，定义 $\pi_\theta = \theta \pi' + (1 - \theta)\pi$。根据策略梯度定理（方程 (35.21)，其中 $\Theta = [\theta]$），$J(\pi_\theta) - J(\pi) = \theta L(\pi') + O(\theta^2)$，其中

$$
\begin{aligned}
L(\pi') \triangleq \frac{1}{1 - \gamma} \mathbb{E}_{p_\pi^\infty(s)} \left[ \mathbb{E}_{\pi'(a|s)} \left[ A_\pi(s, a) \right] \right] = \frac{1}{1 - \gamma} \mathbb{E}_{p_\pi^\infty(s)\pi(a|s)} \left[ \frac{\pi'(a|s)}{\pi(a|s)} A_\pi(s, a) \right]
\end{aligned} \tag{35.32}
$$

在上述内容中，我们已将状态分布从方程 (35.31) 中的 $p_\pi^\infty$ 切换到 $p_\pi^\infty$，同时引入了高阶残差项 $O(\theta^2)$。线性项 $\theta L(\pi')$ 可以根据由 $\pi$ 采样的情节进行估计和优化。高阶项可以以多种方式界定，从而得到 $J(\pi_\theta) - J(\pi)$ 的不同下界。然后我们可以优化 $\theta$ 以确保此下界为正，这将意味着 $J(\pi_\theta) - J(\pi) > 0$。在 **保守策略迭代** [KL02] 中，使用了以下（略微简化）的下界

$$
\begin{aligned}
J^{CPI}(\pi_\theta) \triangleq J(\pi) + \theta L(\pi') - \frac{2\varepsilon\gamma}{(1 - \gamma)^2} \theta^2
\end{aligned} \tag{35.33}
$$

其中 $\varepsilon = \max_s |\mathbb{E}_{\pi'(a|s)} [A_\pi(s, a)]|$。

此思路可以推广到形式超出 $\pi_\theta$ 的策略，其中足够小的 $\theta$ 条件被 $\pi'$ 与 $\pi$ 之间足够小的偏差所取代。在 **安全策略迭代** [Pir+13] 中，偏差是最大总变异，而在 **信任区域策略优化（TRPO）** [Sch+15b] 中，偏差是最大 KL-散度。在后一种情况下，$\pi'$ 可以通过优化以下下界来找到

$$
\begin{aligned}
J^{TRPO}(\pi') \triangleq J(\pi) + L(\pi') - \frac{\varepsilon \gamma}{(1 - \gamma)^2} \max_s D_{KL}(\pi(s) \parallel \pi'(s))
\end{aligned} \tag{35.34}
$$

其中 $\varepsilon = \max_{s,a} |A_\pi(s, a)|$。

在实践中，上述更新规则可能过于保守，并且使用了近似。[Sch+15b] 提出了一种实现两种想法的版本：一种是将点向最大 KL-散度替换为某些平均 KL-散度（通常在 $p_{\pi_\theta}^\infty$ 上平均）；第二种是在方程 (35.34) 中最大化前两项，其中 $\pi'$ 位于以 $\pi$ 为中心的 KL-球内。也就是说，我们求解

$$
\begin{aligned}
\underset{\pi'}{\text{argmax}} \, L(\pi') \, \text{s.t.} \, \mathbb{E}_{p_\pi^\infty(s)} [D_{KL}(\pi(s) \parallel \pi'(s))] \le \delta
\end{aligned} \tag{35.35}
$$

对于某个阈值 $\delta > 0$。

在第 6.4.2.1 节中，我们表明，每一步使用 KL 惩罚的信任区域方法等价于自然梯度下降（参见例如 [Kak02; PS08b]）。这一点很重要，因为参数空间中步长为 $\eta$ 的一步不一定对应于策略空间中步长为 $\eta$ 的一步：

$$
d_\theta(\theta_1, \theta_2) = d_\theta(\theta_2, \theta_3) \neq d_\pi(\pi_{\theta_1}, \pi_{\theta_2}) = d_\pi(\pi_{\theta_2}, \pi_{\theta_3}) \tag{35.36}
$$

其中 \(d_\theta(\theta_1, \theta_2) = \|\theta_1 - \theta_2\|\) 是欧氏距离，而 \(d_\pi(\pi_1, \pi_2) = D_{KL}(\pi_1 \parallel \pi_2)\) 是 KL 距离。换句话说，参数的任何给定变化对策略的影响取决于我们在参数空间中的位置。这一点由自然梯度方法考虑到，
