at t:

p(\mathbf{z}_t, \mathbf{y}_t | \mathbf{y}_{1:t-1}, \mathbf{u}_{1:t}) = p(\mathbf{y}_t | \mathbf{z}_t, \mathbf{u}_t) p(\mathbf{z}_t | \mathbf{y}_{1:t-1}, \mathbf{u}_{1:t-1}) (8.105)
= \mathcal{N}_c(\mathbf{y}_t | \mathbf{R}_t^{-1} (\mathbf{H}_t \mathbf{z}_t + \mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t), \mathbf{R}_t^{-1}) \mathcal{N}_c(\mathbf{z}_t | \boldsymbol{\eta}_{t|t-1}, \boldsymbol{\Lambda}_{t|t-1}) (8.106)
= \mathcal{N}_c(\mathbf{z}_t, \mathbf{y}_t | \boldsymbol{\eta}_{\mathbf{z},\mathbf{y}|t}, \boldsymbol{\Lambda}_{\mathbf{z},\mathbf{y}|t}) (8.107)

where

\boldsymbol{\eta}_{\mathbf{z},\mathbf{y}|t} = \left( \begin{array}{ c } \boldsymbol{\eta}_{t|t-1} - \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} (\mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t) \\ \mathbf{R}_t^{-1} (\mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t) \end{array} \right) (8.108)
\boldsymbol{\Lambda}_{\mathbf{z},\mathbf{y}|t} = \left( \begin{array}{ c c } \boldsymbol{\Lambda}_{t|t-1} + \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} \mathbf{H}_t & - \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} \\ - \mathbf{R}_t^{-1} \mathbf{H}_t & \mathbf{R}_t^{-1} \end{array} \right) (8.109)

The information form filtered parameters \(\boldsymbol{\eta}_{t|t}, \boldsymbol{\Lambda}_{t|t}\) are then derived using the conditional formulae in 2.3.1.4.

# ## 8.2.4.3 Smoothing: algorithm

The smoothing equations are as follows:

p(\mathbf{z}_t | \mathbf{y}_{1:T}) = \mathcal{N}_c(\mathbf{z}_t | \boldsymbol{\eta}_{t|T}, \boldsymbol{\Lambda}_{t|T}) (8.110)
\mathbf{U}_t = \mathbf{Q}_t^{-1} + \boldsymbol{\Lambda}_{t+1|T} - \boldsymbol{\Lambda}_{t+1|t} (8.111)
\mathbf{L}_t = \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \mathbf{U}_t^{-1} (8.112)
\boldsymbol{\Lambda}_{t|T} = \boldsymbol{\Lambda}_{t|t} + \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \mathbf{F}_t - \mathbf{L}_t \mathbf{Q}_t^{-1} \mathbf{F} (8.113)
= \boldsymbol{\Lambda}_{t|t} + \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \mathbf{F}_t - \mathbf{L}_t \mathbf{U}_t \mathbf{L}_t^\mathsf{T} (8.114)
\boldsymbol{\eta}_{t|T} = \boldsymbol{\eta}_{t|t} + \mathbf{L}_t (\boldsymbol{\eta}_{t+1|T} - \boldsymbol{\eta}_{t+1|t}). (8.115)

The parameters \(\boldsymbol{\eta}_{t|t}\) and \(\boldsymbol{\Lambda}_{t|t}\) are the filtered values from Equations (8.98) and (8.97) respectively. Similarly, \(\boldsymbol{\eta}_{t+1|t}\) and \(\boldsymbol{\Lambda}_{t+1|t}\) are the predicted parameters from Equations (8.95) and (8.92). The matrix \(\mathbf{L}_t\) is the information form analog to the backwards Kalman gain matrix in Equation (8.67).

# ## 8.2.4.4 Smoothing: derivation

From the generic forwards-filtering backwards-smoothing equation, Equation (8.14), we have

p(\mathbf{z}_t | \mathbf{y}_{1:T}) = p(\mathbf{z}_t | \mathbf{y}_{1:t}) \int \left[ \frac{p(\mathbf{z}_{t+1} | \mathbf{z}_t) p(\mathbf{z}_{t+1} | \mathbf{y}_{1:T})}{p(\mathbf{z}_{t+1} | \mathbf{y}_{1:t})} \right] d\mathbf{z}_{t+1} (8.116)
= \int p(\mathbf{z}_t, \mathbf{z}_{t+1} | \mathbf{y}_{1:t}) \frac{p(\mathbf{z}_{t+1} | \mathbf{y}_{1:T})}{p(\mathbf{z}_{t+1} | \mathbf{y}_{1:t})} d\mathbf{z}_{t+1} (8.117)
= \int \mathcal{N}_c(\mathbf{z}_t, \mathbf{z}_{t+1} | \boldsymbol{\eta}_{t,t+1|t}, \boldsymbol{\Lambda}_{t,t+1|t}) \frac{\mathcal{N}_c(\mathbf{z}_{t+1} | \boldsymbol{\eta}_{t+1|T}, \boldsymbol{\Lambda}_{t+1|T})}{\mathcal{N}_c(\mathbf{z}_{t+1} | \boldsymbol{\eta}_{t+1|t}, \boldsymbol{\Lambda}_{t+1|t})} d\mathbf{z}_{t+1} (8.118)
= \int \mathcal{N}_c(\mathbf{z}_t, \mathbf{z}_{t+1} | \boldsymbol{\eta}_{t,t+1|T}, \boldsymbol{\Lambda}_{t,t+1|T}) d\mathbf{z}_{t+1}. (8.119)
