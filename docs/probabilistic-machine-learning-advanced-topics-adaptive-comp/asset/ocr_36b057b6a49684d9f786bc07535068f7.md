# ## 8.5 Other variants of the Kalman filter

In this section, we briefly mention some other variants of Kalman filtering. For a more extensive review, see [SS23; Li+17e].

# ### 8.5.1 General Gaussian filtering

*This section is co-authored with Peter Chang.*

Let $p(\mathbf{z}) = \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \boldsymbol{\Sigma})$ and $p(\mathbf{y}|\mathbf{z}) = \mathcal{N}(\mathbf{y}|\mathbf{h}_{\boldsymbol{\mu}}(\mathbf{z}), \mathbf{\Omega})$ for some function $\mathbf{h}_{\boldsymbol{\mu}}$. Let $p(\mathbf{z}, \mathbf{y}) = p(\mathbf{z})p(\mathbf{y}|\mathbf{z})$ be the exact joint distribution. The best Gaussian approximation to the joint can be computed by solving

$q(\mathbf{z}, \mathbf{y}) = \underset{q \in \mathcal{N}}{\text{argmin}} D_{\text{KL}} (p(\mathbf{z}, \mathbf{y}) \| q(\mathbf{z}, \mathbf{y})) \tag{8.155}$

As we explain in Section 5.1.4.2, this can be obtained by **moment matching**, i.e.,

$q(\mathbf{z}, \mathbf{y}) = \mathcal{N}\left( \begin{pmatrix} \mathbf{z} \\ \mathbf{y} \end{pmatrix} \middle| \begin{pmatrix} \boldsymbol{\mu} \\ \hat{\mathbf{y}} \end{pmatrix}, \begin{pmatrix} \boldsymbol{\Sigma} & \mathbf{C} \\ \mathbf{C}^{\top} & \mathbf{S} \end{pmatrix} \right) \tag{8.156}$

where

$\hat{\mathbf{y}} = \mathbb{E}[\mathbf{y}] = \int \mathbf{h}_{\boldsymbol{\mu}}(\mathbf{z}) \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \boldsymbol{\Sigma}) d\mathbf{z} \tag{8.157}$

$\mathbf{S} = \mathbb{V}[\mathbf{y}] = \mathbf{\Omega} + \int (\mathbf{h}_{\boldsymbol{\mu}}(\mathbf{z}) - \hat{\mathbf{y}})(\mathbf{h}_{\boldsymbol{\mu}}(\mathbf{z}) - \hat{\mathbf{y}})^{\top} \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \boldsymbol{\Sigma}) d\mathbf{z} \tag{8.158}$

$\mathbf{C} = \text{Cov}[\mathbf{z}, \mathbf{y}] = \int (\mathbf{z} - \boldsymbol{\mu})(\mathbf{h}_{\boldsymbol{\mu}}(\mathbf{z}) - \hat{\mathbf{y}})^{\top} \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \boldsymbol{\Sigma}) d\mathbf{z} \tag{8.159}$

We can use the above Gaussian approximation either for the time update (i.e., going from $p(\mathbf{z}_{t-1}|\mathbf{y}_{1:t-1})$ to $p(\mathbf{z}_t|\mathbf{y}_{1:t-1})$ via $p(\mathbf{z}_{t-1}, \mathbf{z}_t|\mathbf{y}_{1:t-1})$), or for the measurement update, (i.e., going from $p(\mathbf{z}_t|\mathbf{y}_{1:t-1})$ to $p(\mathbf{z}_t|\mathbf{y}_{1:t})$ via $p(\mathbf{z}_t, \mathbf{y}_t|\mathbf{y}_{1:t-1})$). For example, if the prior from the time update is $p(\mathbf{z}_t) = \mathcal{N}(\mathbf{z}_t|\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1})$, then the measurement update becomes

$$ \begin{aligned} \mathbf{K}_t &= \mathbf{C}_t \mathbf{S}_t^{-1} \tag{8.160} \\ \boldsymbol{\mu}_{t|t} &= \boldsymbol{\mu}_{t|t-1} + \mathbf{K}_t (\mathbf{y}_t - \hat{\mathbf{y}}_t) \tag{8.161} \\ \boldsymbol{\Sigma}_{t|t} &= \boldsymbol{\Sigma}_{t|t-1} - \mathbf{K}_t \mathbf{S}_t \mathbf{K}_t^{\top} \tag{8.162} \end{aligned} $$

The resulting method is called **general Gaussian filtering** or **GGF** [IX00; Wu+06].

# #### 8.5.1.1 Statistical linear regression

An alternative perspective on the above method is that we are approximating the likelihood by $q(\mathbf{y}|\mathbf{z}) = \mathcal{N}(\mathbf{y}|\mathbf{Az} + \mathbf{b}, \mathbf{\Omega})$, where we define

$$ \begin{aligned} \mathbf{A} &= \mathbf{C}^{\top} \mathbf{\Sigma}^{-1} \\ \mathbf{b} &= \hat{\mathbf{y}} - \mathbf{A} \boldsymbol{\mu} \\ \mathbf{\Omega} &= \mathbf{S} - \mathbf{A} \mathbf{\Sigma} \mathbf{A}^{\top} \end{aligned} \tag{8.163} $$
