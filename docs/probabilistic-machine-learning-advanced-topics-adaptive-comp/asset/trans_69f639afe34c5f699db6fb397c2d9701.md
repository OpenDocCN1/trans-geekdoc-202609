
其中 $\mathbf{N}_j = (N_{j1}, \dots, N_{jK})$ 是离开状态 $j$ 的计数，$B(\boldsymbol{\alpha})$ 是广义beta函数。

我们可以使用[Min00c]中讨论的方法来拟合此模型。不过，我们也可以使用以下近似[MP95, p12]：

```
$m_k \propto |\{j : N_{jk} > 0\}|$
```

这表明单词 $k$ 的先验概率由其出现的不同上下文的数量给出，而不是由其出现的次数给出。为了证明此结果的合理性，MacKay 和 Peto [MP95] 给出了以下示例。

> 想象，你看，语言，你看，有，你看，一个经常出现的词组 'you see'，你看，其中词组的第二个词，see，以非常高的概率跟随第一个词，you，你看。然后边缘统计，你看，将由单词 you 和 see 极大地主导，你看，频率相等，你看。

如果我们使用标准平滑公式，即方程 (3.270)，那么对于之前未见过的某个新上下文单词，P(you|novel) 和 P(see|novel) 将是相同的，因为“you”和“see”的边缘频率相同（各11次）。然而，这似乎不合理。“you”出现在许多上下文中，因此 P(you|novel) 应该较高，但“see”只跟随“you”，因此 P(see|novel) 应该较低。如果我们使用贝叶斯公式方程 (3.273)，我们将免费获得此效果，因为我们回退到 $m_k$ 而不是 $f_k$，并且根据方程 (3.276)，$m_k$ 对于“you”会很大，对于“see”会很小。

虽然优雅，但这个贝叶斯模型并不比最先进的语言模型（称为插值Kneser-Ney [KN95; CG98]）更好。通过使用非参数贝叶斯的思想，可以创建一个优于此类启发式方法的语言模型，如[Teh06; Woo+09]中所讨论。然而，使用循环神经网络（第16.3.4节）可以获得更好的结果；它们成功的关键在于它们不对每个符号进行“原子”处理，而是学习一个分布式嵌入表示，该表示编码了某些符号比其他符号更相似的假设。

## 3.8 模型选择

> 所有模型都是错的，但有些是有用的。——乔治·博克斯 [BD87, p424]。

在本节中，我们假设有一组不同的模型 $\mathcal{M}$，每个模型可能以不同程度拟合数据，并且每个模型可能做出不同的假设。我们讨论如何从这组模型中选择最佳模型，或对所有模型进行平均。

我们假设“真”模型在集合 $\mathcal{M}$ 中；这被称为 $\mathcal{M}$-**完整**假设 [BS94]。当然，在现实中，没有任何模型可能是充分的；这被称为 $\mathcal{M}$-**开放**场景 [BS94; CI13]。

### 3.8.1 贝叶斯模型选择

选择最佳模型的自然方法是根据贝叶斯规则选择最可能的模型：

```
\(\hat{m} = \underset{m \in \mathcal{M}}{\text{argmax}} p(m|\mathcal{D})\) (3.277)
```

其中

```
\(p(m|\mathcal{D}) = \frac{p(\mathcal{D}|m)p(m)}{\sum_{m \in \mathcal{M}} p(\mathcal{D}|m)p(m)}\) (3.278)
```

是模型上的后验。这被称为**贝叶斯模型选择**。如果模型上的先验是均匀的，\(p(m) = 1/|\mathcal{M}|$，那么MAP模型由以下给出：

```
\(\hat{m} = \underset{m \in \mathcal{M}}{\text{argmax}} p(\mathcal{D}|m)\) (3.279)
```

数量 \(p(\mathcal{D}|m)\) 由以下给出：

```
\(p(\mathcal{D}|m) = \int p(\mathcal{D}|\theta, m)p(\theta|m)d\theta\) (3.280)
```

这被称为**边缘似然**，或模型 *m* 的**证据**。（有关如何计算此数量的详细信息，请参见第3.8.3节。）如果模型对观测数据分配了较高的先验预测密度，则我们认为它是一个好的模型。但是，如果模型过于灵活，则一些先验设置将与数据不匹配；这种概率质量将被“浪费”，从而降低预期似然。这种隐式正则化效应称为**贝叶斯奥卡姆剃刀**。有关示例，请参见图3.22。

### 3.8.2 贝叶斯模型平均

如果我们的目标是进行预测，那么对所有模型进行平均优于仅使用单一模型进行预测。也就是说，我们应该使用以下方法计算**后验预测分布**：

```
$p(y|\mathcal{D}) = \sum_{m \in \mathcal{M}} p(y|m)p(m|\mathcal{D})$
```

这被称为贝叶斯模型平均 [Hoe+99]。这与机器学习技术**集成**类似，在该技术中，我们对预测器进行加权组合。但是，它不相同，如[Min00b]所指出的，因为集成中的权重不需要总和为1。特别是，在BMA中，如果存在单一最佳模型，称其为 \( m^*\)，那么在大样本极限下，\( p(m|\mathcal{D}) \) 将变成一个退化分布，其所有权重都在 \( m^*\) 上，而 \( \mathcal{M} \) 的其他成员将被忽略。集成中不会发生这种情况。

### 3.8.3 估计边缘似然

要执行贝叶斯模型选择或平均，我们需要能够计算方程(3.280)中的边缘似然，也称为证据。下面我们简要总结了一些合适的方法。有关更多详细信息，请参见例如[FW12]。

#### 3.8.3.1 共轭模型的解析解

如果我们使用共轭先验，可以解析地计算边缘似然，如第3.4.5.4节所讨论。我们在第3.8.1.1节中给出了一个示例。

#### 3.8.3.2 谐波均值估计器

一种特别简单的估计器，称为**谐波均值估计器**，在[NR94]中提出。它定义如下：

```
$p(\mathcal{D}) \approx \left( \frac{1}{S} \sum_{s=1}^S \frac{1}{p(\mathcal{D}|\theta_s)} \right)^{-1}$
```

其中 \( \theta_s \sim p(\theta) \) 是来自先验的样本。这源于以下恒等式：

```
$\mathbb{E} \left[ \frac{1}{p(\mathcal{D}|\theta)} \right] = \int \frac{1}{p(\mathcal{D}|\theta)} p(\theta|\mathcal{D}) d\theta$
$= \int \frac{1}{p(\mathcal{D}|\theta)} \frac{p(\mathcal{D}|\theta)p(\theta)}{p(\mathcal{D})} d\theta$
$= \frac{1}{p(\mathcal{D})} \int p(\theta) d\theta = \frac{1}{p(\mathcal{D})}$
```

（我们假设先验是适当的，因此积分为1。）
