## 29.2 隐马尔可夫模型 (HMMs)

在本节中，我们讨论隐马尔可夫模型（HMM），它是一种隐藏状态为离散的状态空间模型（SSM），因此 \(\boldsymbol{z}_t \in \{1, \dots, K\}\)。观测可以是离散的，\(\boldsymbol{y}_t \in \{1, \dots, N_y\}\)，也可以是连续的，\(\boldsymbol{y}_t \in \mathbb{R}^{N_y}\)，或者是两者的某种组合，如下所示。有关 HMM 的更多细节可以在补充第 29 章以及其他参考文献中找到，例如 [Rab89; Fra08; CMR05]。如需交互式介绍，请参见 https://nipunbatra.github.io/hmm/。

### 29.2.1 条件独立性属性

HMM 图形模型如图 29.1(b) 所示。这编码了隐藏状态是马尔可夫的，且观测在隐藏状态条件下独立同分布的假设。剩下的就是指定每个节点的条件概率分布的形式。

### 29.2.2 状态转移模型

初始状态分布表示为

```
\(p(z_1 = j) = \pi_j\) (29.8)
```

其中 \(\boldsymbol{\pi}\) 是 \(K\) 个状态上的离散分布。

![](img/ca72c1626f4850f058a9edc138c1ac73_1002_0.png)

图 29.2：来自具有 10 个伯努利观测的 HMM 的一些样本。由 bernoulli_hmm_example.ipynb 生成。

转移模型表示为

```
p(z_t = j|z_{t-1} = i) = A_{ij}
```

这里 A 的第 i 行对应从状态 i 出发的分布。这是一个行随机矩阵，即每一行之和为一。我们可以通过创建状态转移图来可视化转移矩阵中的非零项，如图 2.15 所示。

### 29.2.3 离散似然

观测模型 p(y_t|z_t = j) 可以根据数据类型采用多种形式。对于离散观测，我们可以使用

```
p(y_t = k|z_t = j) = y_{jk}
```

例如，请参见第 9.2.1.1 节中的赌场 HMM 示例。

如果每个时间步有 D 个离散观测，我们可以使用如下形式的因子模型

```
p(y_t|z_t = j) = \prod_{d=1}^D Cat(y_{td}|y_{d,j,:})
```

在二进制观测的特殊情况下，这变为

```
p(y_t|z_t = j) = \prod_{d=1}^D Ber(y_{td}|y_{d,j})
```

在图 29.2 中，我们给出了一个具有 5 个隐藏状态和 10 个伯努利观测的 HMM 示例。

### 29.2.4 高斯似然

如果 \(\mathbf{y}_t\) 是连续的，通常使用高斯观测模型：

```
\(p(\mathbf{y}_t | z_t = j) = \mathcal{N}(\mathbf{y}_t | \boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)\) (29.13)
```

作为一个简单的例子，假设我们有一个具有 3 个隐藏状态的 HMM，每个状态生成一个 2d 高斯分布。我们可以将这些高斯分布表示为 2d 椭圆，如图 29.3(a) 所示。我们称这些为“睡莲叶”，因为它们的形状。我们可以想象一只青蛙从一片睡莲叶跳到另一片。（这个类比归功于已故的 Sam Roweis。）它会在一片叶子上待一段时间（对应于保持在同一离散状态 \(z_t\)），然后跳到一片新叶子上（对应于转移到新状态）。请参见图 29.3(b)。我们看到的数据只是来自青蛙当前所在叶子附近的 2d 点（例如，水滴）。因此，这个模型类似于高斯混合模型（第 28.2.1 节），因为它生成观测的簇，只是现在数据点之间存在时间相关性。

我们也可以使用更灵活的观测模型。例如，如果我们使用一个 \(M\) 分量的 GMM，那么我们有

```
\(p(\mathbf{y}_t | z_t = j) = \sum_{k=1}^M w_{jk} \mathcal{N}(\mathbf{y}_t | \boldsymbol{\mu}_{jk}, \boldsymbol{\Sigma}_{jk})\) (29.14)
```

这被称为 GMM-HMM。

### 29.2.5 自回归似然

标准 HMM 假设观测在隐藏状态条件下条件独立。在实践中，这种情况往往并不成立。但是，可以直接从 \(\mathbf{y}_{t-1}\) 到 \(\mathbf{y}_t\) 以及从 \(z_t\) 到 \(\mathbf{y}_t\) 添加直接弧，如图 29.1(a) 所示。这被称为 **自回归 HMM**。

对于连续数据，我们可以使用如下形式的观测模型

```
\(p(\mathbf{y}_t | \mathbf{y}_{t-1}, z_t = j, \boldsymbol{\theta}) = \mathcal{N}(\mathbf{y}_t | \mathbf{E}_j \mathbf{y}_{t-1} + \boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)\) (29.15)
```

![](img/ca72c1626f4850f058a9edc138c1ac73_1004_0.png)

图 29.4：每个 5 个隐藏状态的观测动态说明。吸引子点对应于相应自回归过程的稳态解。由 hmm_ar.ipynb 生成。

这是一个线性回归模型，其中参数根据当前隐藏状态选择。（我们也可以使用非线性模型，例如神经网络。）此类模型在计量经济学中被广泛使用，在那里它们被称为 **体系切换马尔可夫模型** [Ham90]。类似的模型可以定义用于离散观测（例如，参见 [SJJ99]）。

我们还可以考虑更高阶扩展，即条件依赖于最后 \(L\) 个观测：

```
$p(\boldsymbol{y}_t | \boldsymbol{y}_{t-L:t-1}, z_t=j, \boldsymbol{\theta}) = \mathcal{N}(\boldsymbol{y}_t | \sum_{\ell=1}^L \mathbf{W}_{j,\ell} \boldsymbol{y}_{t-\ell} + \boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j)$ (29.16)
```

AR-HMM 本质上结合了两个马尔可夫链，一个作用于隐藏变量以捕捉长程依赖，另一个作用于观测变量以捕捉短程依赖 [Ber99]。由于所有可见节点都是观测到的，在它们之间添加连接仅仅改变似然，而不会使后验推断任务复杂化（参见第 9.2.3 节）。

现在让我们考虑 Scott Linderman 的一个 2d 示例。我们使用具有 5 个状态的从左到右转移矩阵。此外，最终状态返回到第一个状态，因此我们只是循环遍历各个状态。设 \(\boldsymbol{y}_t \in \mathbb{R}^2\)，并假设我们将 \(\mathbf{E}_j\) 设置为旋转角度为 7 度的旋转矩阵，并将每个 \(\boldsymbol{\mu}_j\) 设置为围绕原点相隔 72 度的圆上的点，因此每个状态在圆上旋转 1/5。如果模型长时间保持在同一状态 \(j\)，观测动态将收敛到稳态 \(\boldsymbol{y}_{*,j}\)，它满足 \(\boldsymbol{y}_t = \mathbf{E}_j \boldsymbol{y}_{*,j} + \boldsymbol{\mu}_j\)；我们可以使用 \(\boldsymbol{y}_{*,j} = (\mathbf{I} - \mathbf{E}_j)^{-1} \boldsymbol{\mu}_j\) 求解稳态向量。我们可以可视化每个 5 个状态所诱导的 2d 流，如图 29.4 所示。

在图 29.5(a) 中，我们展示了从该模型中采样的一条轨迹。我们看到，观测向量的两个组件根据底层隐藏状态经历不同的动态。在图 29.5(b) 中，我们以 2d 散点图展示了相同的数据。第一个观测是状态 2 的黄色点，位于 $(-0.8, 0.5)$。动态收敛到稳态值 $\boldsymbol{y}_{*,2} = (-2.0, 3.8)$。然后系统跳转到绿色状态（状态 3），因此它在最后一个观测上添加偏移量 $\boldsymbol{\mu}_3$，然后收敛到稳态值 $\boldsymbol{y}_{*,3} = (-4.3, -0.8)$。以此类推。
