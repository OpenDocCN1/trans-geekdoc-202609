图 36.6：双重差分设定下假设的因果图。这里，我们关心的结果是治疗前后时期的差异，Y1 − Y0。该差异受治疗、未观测因素 U 和观测协变量 X 的影响。U 和 A 之间的虚线箭头表明变量之间存在统计依赖关系，但我们对精确的因果机制保持不可知态度。例如，在最低工资示例中，U 可能是餐厅所在街区的平均收入，它取决于州，因此也取决于治疗。

下一步是给出目标因果效应的定义，该定义不依赖于参数模型，并给出与之配套的非参数识别假设。换句话说，因果估计量将是接受治疗的单元上的平均处理效应。为了在数学上理解这一点，我们将引入一种新的记号：

```
P^{A=1}(Y|do(A=a)) \triangleq \int P(Y|A=a, \text{parents of } Y) dP(\text{parents of } Y|A=1) \quad (36.89)
```

```
E^{A=1}[Y|do(A=a)] \triangleq E_{P^{A=1}(Y|do(A=a))}[Y]. \quad (36.90)
```

请回顾，普通 do 算子的工作原理是将 P(parents|A=a) 替换为边际分布 P(parents)，从而打破后门关联。现在，我们将分布 P(parents|A=a) 替换为 P(parents|A=1)，而不考虑实际的治疗值。这仍然打破了所有后门关联，但更符合我们仅在接受治疗的单元中估计治疗效果的目标。

为了使用 do-演算形式化因果估计量，我们需要假设某种部分因果结构。我们将使用图 36.6 中的图。有了这个，我们的因果估计量就是接受治疗的单元上的平均处理效应，即：

```
ATT^{\text{DID}} = E^{A=1}[Y_1 - Y_0|do(A=1)] - E^{A=1}[Y_1 - Y_0|do(A=0)] \quad (36.91)
```

在最低工资示例中，这是最低工资上涨对受影响餐厅就业的平均效果（即新泽西州的餐厅）。

最后，我们正式化识别假设，即在 X 条件下，处理组和未处理组的趋势相同。**条件平行趋势**假设是：

```
E^{A=1}[Y_1 - Y_0|X, do(A=0)] = E[Y_1 - Y_0|X, A=0]. \quad (36.92)
```

换句话说，这意味着对于具有协变量 \( X \) 的处理单元，如果不分配治疗我们本会看到的趋势，与具有协变量 \( X \) 的未处理单元实际看到的趋势相同。也就是说，如果新泽西州没有提高最低工资，那么新泽西州的麦当劳的就业预期变化将与宾夕法尼亚州麦当劳的就业预期变化相同。

有了这个，我们可以给出主要的识别结果：

## **定理 5**（双重差分识别）。我们观察到 \( A, Y_0, Y_1, X \sim P \)。假设

- 1. _(因果结构)_ 数据遵循图 36.6 中的因果图。
- 2. _(条件平行趋势)_ \(\mathbb{E}^{A=1}[Y_1 - Y_0|X, \text{do}(A=0)] = \mathbb{E}[Y_1 - Y_0|X, A=0]\).
- 3. _(重叠)_ P\((A=1) > 0\) 且 P\((A=1|X=x) < 1\) 对样本空间中所有 \( x \) 的值都成立。也就是说，不存在仅存在于处理组中的协变量值。

那么，对处理组的平均处理效应被识别为 \(\text{ATT}^\text{DID} = \tau^\text{DID}\)，其中

```
\(\tau^\text{DID} = \mathbb{E}[\mathbb{E}[Y_1 - Y_0|A=1, X] - \mathbb{E}[Y_1 - Y_0|A=0, X]|A=1].\) (36.93)
```

_证明._ 首先，通过展开定义，我们有
\(\mathbb{E}^{A=1}[Y_1 - Y_0|\text{do}(A=1), X] = \mathbb{E}[Y_1 - Y_0|A=1, X].\) (36.94)

其解释是近乎同义反复的说法：在治疗下的处理组中的平均效应等于处理组中实际观察到的平均效应。接下来，

```
\(\mathbb{E}^{A=1}[Y_1 - Y_0|\text{do}(A=0), X] = \mathbb{E}[Y_1 - Y_0|A=0, X].\) (36.95)
```

这正是条件平行趋势假设。结果立即得出。（重叠假设是为了确保所有条件期望都有定义）。

### 36.6.1 估计

有了识别结果，下一项任务是估计观测估计量方程 (36.93)。为此，我们定义 \(\tilde{Y} \triangleq Y_1 - Y_0\)。然后，我们假设 \(\tilde{Y}, X, A \overset{\text{iid}}{\sim} P\) 服从某个未知分布 \( P \)，我们的目标估计量是 \(\mathbb{E}[\mathbb{E}[\tilde{Y}|A=1, X] - \mathbb{E}[\tilde{Y}|A=0, X]|A=1]\)。我们可以立即认识到这是通过调整估计平均处理效应时出现的观测估计量，如第 36.4.5.3 节所述。也就是说，尽管调整设定与双重差分设定之间的因果情况和识别论证不同，但我们最终面临的统计估计任务是相同的。因此，我们可以使用为调整开发的所有估计工具。也就是说，那里的所有技术——预期结果建模、倾向得分方法、双重机器学习等——纯粹是关于 _统计_ 任务，这在两个场景中是相同的。因此，我们得到了与第 36.4.6 节中看到的相同的一般估计配方。即，

- 1. 拟合统计或机器学习模型 \(\hat{Q}(a, x)\) 作为 \(\tilde{Y} = Y_1 - Y_0\) 的预测器，和/或 \(\hat{g}(x)\) 作为 \( A \) 的预测器。
- 2. 为每个数据点计算预测值 $\hat{Q}(0, x_i), \hat{Q}(1, x_i), \hat{g}(x_i)$。
- 3. 将这些预测组合成对处理组平均处理效应的估计。

第三步中的估计器可以是预期结果模型估计器、倾向权重估计器、双重机器学习估计器，或调整设定中有效的任何其他策略。

## 36.7 可信性检查

一旦我们选择了识别策略、拟合了模型并产生了估计值，我们就会面临一个基本问题：我们应该相信它吗？报告的估计值是否成功捕捉了真实的因果效应，取决于因果识别所需的假设是否成立、机器学习模型的质量，以及由于仅能获取有限数据样本而导致的估计值变异性。后两个问题在机器学习和统计实践中已经很熟悉。例如，我们应该通过在留出数据上检查性能、检查特征重要性等方式来评估我们的模型。同样，我们应该报告由于有限样本而导致的不确定性的度量（例如，以置信区间的形式）。由于这些程序已经是熟悉的做法，我们将不再赘述。然而，模型评估和不确定性量化是任何可信的因果分析的关键部分。

评估识别假设的有效性更为棘手。首先，有些假设实际上可以从数据中检查出来。例如，在使用后门调整或双重差分的分析中，应检查重叠性；在工具变量设定中，应检查相关性。再次强调，检查这些条件对于可信的因果分析绝对必要。但是，再次强调，这仅涉及熟悉的数据分析，因此我们将不再进一步讨论。接下来，有些因果假设无法从数据中验证；例如，后门调整中没有未观测混杂、IV 中的排他限制以及 DiD 中的条件平行趋势。最终，必须使用对所考虑特定问题的实质性因果知识来评估这些假设的有效性。但是，可以进行一些补充分析，使所需的判断更容易。我们现在讨论其中两种技术。

### 36.7.1 安慰剂检验

在许多情况下，我们可能能够找到一个可被解释为“处理”的变量，已知它对结果没有影响，但我们预计它与结果之间的混杂方式与感兴趣的真实处理非常相似。例如，如果我们试图估计 COVID 疫苗在预防症状性 COVID 方面的疗效，我们可以将安慰剂处理定为 HPV 疫苗接种。我们不期望这里存在任何因果效应。然而，似乎合理的是，导致个人寻求（或避免）HPV 疫苗接种和 COVID 疫苗接种的潜在因素是相似的；例如，健康意识、对针头的恐惧等等。那么，如果我们的识别策略对 COVID 疫苗有效，我们也会期望它对 HPV 疫苗接种有效。因此，我们用于估计 COVID 效应的估计程序，当应用于 HPV 时，应产生 $\hat{\tau} \approx 0$。或者，更准确地说，置信区间应包含 0。如果没有发生这种情况，我们可能会怀疑仍然存在一些未被识别程序充分处理的潜在混杂因素。
