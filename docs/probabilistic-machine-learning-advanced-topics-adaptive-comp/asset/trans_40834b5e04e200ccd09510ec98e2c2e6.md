令 $f(\mathbf{x})_c = p(y = c|\mathbf{x}), \hat{y}_n = \text{argmax}_{c \in \{1, \dots, C\}} f(\mathbf{x}_n)_c$，且 $\hat{p}_n = \max_{c \in \{1, \dots, C\}} f(\mathbf{x}_n)_c$。分箱 $b$ 内的准确率定义为

$$
\text{acc}(\mathcal{B}_b) = \frac{1}{|\mathcal{B}_b|} \sum_{n \in \mathcal{B}_b} \mathbb{I}(\hat{y}_n = y_n)
$$

该分箱内的平均置信度定义为

$$
\text{conf}(\mathcal{B}_b) = \frac{1}{|\mathcal{B}_b|} \sum_{n \in \mathcal{B}_b} \hat{p}_n
$$

如果绘制准确率与置信度图，我们将得到一个**可靠性图**，如图 14.1 所示。准确率与置信度之间的差距以红色条形表示。我们可以使用**预期校准误差 (ECE)** [NCH15] 来衡量此项：

$$
\text{ECE}(f) = \sum_{b=1}^B \frac{|\mathcal{B}_b|}{B} |\text{acc}(\mathcal{B}_b) - \text{conf}(\mathcal{B}_b)|
$$

在多类情况下，ECE 仅关注 MAP（最高标签）预测的误差。我们可以使用**边际校准误差**扩展该指标以查看所有类别，该方法在 [KLM19] 中提出：

$$
\text{MCE} = \sum_{c=1}^C w_c \mathbb{E} \left[ (p(Y = c | x) - f(\mathbf{x})_c)^2 \right]
$$

$$
= \sum_{c=1}^C w_c \sum_{b=1}^B \frac{|\mathcal{B}_{b,c}|}{B} (\text{acc}(\mathcal{B}_{b,c}) - \text{conf}(\mathcal{B}_{b,c}))^2
$$

其中 $\mathcal{B}_{b,c}$ 是类别 $c$ 的第 $b$ 个分箱，$w_c \in [0, 1]$ 表示类别 $c$ 的重要性。（如果所有类别同样重要，我们可以设置 $w_c = 1/C$。）在 [Nix+19] 中，他们将此指标称为**静态校准误差**；他们表明，某些 ECE 良好的方法可能具有较差的 MCE。其他多类校准指标在 [WLZ19] 中讨论。

## 14.2.2.2 改进校准

原则上，训练分类器以优化适当评分规则（如 NLL）应自动得到一个校准良好的分类器。然而在实践中，不平衡的数据集可能导致校准不佳的预测。下面我们将按照 [Guo+17] 讨论各种改进概率分类器校准的方法。

## 14.2.2.3 Platt 缩放

令 $z$ 为 log-odds（即 logit），$p = \sigma(z)$，由概率二分类器生成。我们希望将其转换为更校准的值 $q$。最简单的方法称为 **Platt 缩放**，该方法在 [Pla00] 中提出。其思想是计算 $q = \sigma(az+b)$，其中 $a$ 和 $b$ 在验证集上通过极大似然估计估计。

在多类情况下，我们可以通过矩阵缩放扩展 Platt 缩放：$\mathbf{q} = \text{softmax}(\mathbf{W}z + \mathbf{b})$，其中 $\mathbf{W}$ 和 $\mathbf{b}$ 在验证集上通过极大似然估计。由于 $\mathbf{W}$ 具有 $K \times K$ 个参数（$K$ 为类别数量），该方法容易过拟合，因此在实际中我们将 $\mathbf{W}$ 限制为对角矩阵。

## 14.2.2.4 非参数（直方图）方法

Platt 缩放对校准曲线的形状做出了强假设。一种更灵活的非参数方法是将预测概率划分为分箱 $p_m$，并为每个分箱估计一个经验概率 $q_m$；然后我们用 $q_m$ 替换 $p_m$；这称为 **直方图分箱** [ZE01a]。我们可以通过要求 $q = f(p)$ 为分段常数且单调非递减的函数来对该方法进行正则化；这称为 **等回归** [ZE01a]。另一种方法，称为 **缩放-分箱校准器**，是先应用一种缩放方法（如 Platt 缩放），然后对其应用直方图分箱。这样做的优势在于使用每个分箱中缩放概率的平均值，而不是观察到的二进制标签的平均值（见图 14.2）。在 [KLM19] 中，他们证明这会带来更好的校准，因为估计器的方差更低。

在多类情况下，$\mathbf{z}$ 是 logit 向量，$\mathbf{p} = \text{softmax}(\mathbf{z})$ 是概率向量。我们希望将其转换为更校准的版本 $\mathbf{q}$。[ZE01b] 提出将直方图分箱和等回归扩展到这种情况，通过对每个 $K$ 个一对其余问题应用上述二进制方法，其中 $K$ 为类别数量。然而，这需要 $K$ 个单独的校准模型，并导致一个未归一化的概率分布。

## 14.2.2.5 温度缩放

在 [Guo+17] 中，他们在经验上注意到，将 Platt 缩放的对角版本应用于各种 DNN 时，通常最终学习到的向量形式为 $\mathbf{w} = (c, c, \dots, c)$，其中 $c$ 为某个常数。这表明了一种更简单的缩放形式，他们称之为 **温度缩放**：$\mathbf{q} = \text{softmax}(\mathbf{z}/T)$，

## 14.2.2.6 标签平滑

训练分类器时，我们通常将真实目标标签表示为 one-hot 向量，例如 y = (0, 1, 0) 表示 3 个类别中的第 2 个。如果我们将一些概率质量“分散”到所有分箱中，可以改善结果。例如，我们可以使用 y = (0.1, 0.8, 0.1)。这称为标签平滑，并且

通常会产生校准更好的模型 [MKH19]。

## 14.2.2.7 贝叶斯方法

拟合分类器的贝叶斯方法通常会产生更校准的预测，因为它们表示参数中的不确定性。示例见第 17.3.8 节。然而，[Ova+19] 表明，即使校准良好的模型（包括贝叶斯模型）在应用于来自不同分布的输入时，也常常会出现校准错误（详情见第 19.2 节）。

## 14.2.3 超越边际概率评估

校准（第 14.2.2 节）专注于评估边际预测分布 \(p(y|\boldsymbol{x})\) 的属性。但这有时不足以区分好模型和坏模型，尤其是在在线学习和序列决策的背景下，如 [Lu+22; Osb+21; WSG21; KKG22] 所指出。例如，考虑两个观察一系列硬币抛掷的学习代理。设时刻 \(t\) 的结果为 \(Y_t \sim \text{Ber}(\theta)\)，其中 \(\theta\) 是未知参数。代理 1 认为 \(\theta = 2/3\)，而代理 2 认为 \(\theta = 0\) 或 \(\theta = 1\)，但不确定是哪个，并分别以 \(1/3\) 和 \(2/3\) 的概率对这些事件赋予概率。因此，两个代理尽管模型不同，但对下一个结果的预测相同：对于代理 \(i=1,2\)，\(p(Y_1^i = 0) = 1/3\)。然而，两个代理对未来 \(\tau\) 个结果*序列*的预测截然不同：特别是，代理 1 预测每个单独的硬币抛掷都是随机的伯努利事件，其概率源于不可约噪声或**数据不确定性**：

\(p(Y_1^1 = 0, \dots, Y_\tau^1 = 0) = \frac{1}{3^\tau}\)

相比之下，代理 2 预测序列要么全为正面，要么全为反面，其概率由对真实参数的**认知不确定性**引起：

\(p(Y_1^2 = y_1, \dots, Y_\tau^2 = y_\tau) = \begin{cases} 1/3 & \text{if } y_1 = \cdots = y_\tau = 0 \\ 2/3 & \text{if } y_1 = \cdots = y_\tau = 1 \\ 0 & \text{otherwise} \end{cases}\)

这两个代理之间信念的差异将影响其行为。例如，在赌场中，代理 1 在长期反复下注正面的风险很小，但对于代理 2，这是一个非常不明智的策略，进行一些初始信息收集（探索）是有价值的。

基于以上，我们看到在评估预测模型时，评估*联合*预测分布是有用的。在 [Lu+22; Osb+21] 中，他们提出给定一组 \(\tau\) 个输入 \(\boldsymbol{x} = X_{T:T+\tau-1}\) 和过去 \(T\) 个数据样本 \(\mathcal{D}_T = \{(X_t, Y_{t+1}) : t = 0, 1, \dots, T-1\}\)，来评估 \(\tau\) 个结果 \(\boldsymbol{y} = Y_{T+1:T+\tau}\) 的后验预测分布。贝叶斯最优预测分布是

\(P_T^B = p(\boldsymbol{y}|\boldsymbol{x}, \mathcal{D}_T)\)

这通常难以计算。相反，代理将使用一个近似分布，称为**信念状态**，我们用以下符号表示：

\(Q_T = p(\boldsymbol{y}|\boldsymbol{x}, \mathcal{D}_T)\)
