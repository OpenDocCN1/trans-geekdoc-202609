The natural performance metric is the KL between these distributions. Since this depend on the inputs $x$ and $\mathcal{D}_T = (X_{0:T-1}, Y_{1:T})$, we will averaged the KL over these values, which are drawn iid from the true data generating distribution, which we denote by

$P(X, Y, \mathcal{E}) = P(X|\mathcal{E})P(Y|X, \mathcal{E})P(\mathcal{E})$

where $\mathcal{E}$ is the true but unknown environment. Thus we define our metric as

$d_{B,Q}^{KL} = \mathbb{E}_{P(x, \mathcal{D}_T)} [D_{KL}(P^B(y|x, \mathcal{D}_T) || Q(y|x, \mathcal{D}_T))]$

where

$P(x, \mathcal{D}_T, \mathcal{E}) = P(\mathcal{E}) \left[ \prod_{t=0}^{T-1} P(X_t|\mathcal{E})P(Y_{t+1}|X_t, \mathcal{E}) \right] \left[ \prod_{t=T}^{T+\tau-1} P(x_t|\mathcal{E}) \right]$

and $P(x, \mathcal{D}_T)$ marginalizes this over environments.

Unfortunately, it is usually intractable to compute the exact Bayes posterior, $P_T^B$, so we cannot evaluate $d_{B,Q}^{KL}$. However, in Section 14.2.3.1, we show that

$d_{B,Q}^{KL} = d_{\mathcal{E},Q}^{KL} - \mathbb{I}(\mathcal{E}; y|\mathcal{D}_T, x)$

where the second term is a constant wrt the agent, and the first term is given by

$d_{\mathcal{E}, Q}^{KL} = \mathbb{E}_{P(x, \mathcal{D}_T, \mathcal{E})} [D_{KL}(P(y|x, \mathcal{E}) || Q(y|x, \mathcal{D}_T))]$

$= \mathbb{E}_{P(y|x, \mathcal{E})P(x, \mathcal{D}_T, \mathcal{E})} [\log \frac{P(y|x, \mathcal{E})}{Q(y|x, \mathcal{D}_T)}]$

Hence if we rank agents in terms of $d_{\mathcal{E}, Q}^{KL}$, it will give the same results as ranking them by $d_{B, Q}^{KL}$.

To compute $d_{\mathcal{E}, Q}^{KL}$ in practice, we can use a Monte Carlo approximation: we just have to sample $J$ environments, $\mathcal{E}^j \sim P(\mathcal{E})$, sample a training set $\mathcal{D}_T$ from each environment, $\mathcal{D}_T^j \sim P(\mathcal{D}_T|\mathcal{E}^j)$, and then sample $N$ data vectors of length $\tau$, $(x_n^j, y_n^j) \sim P(X_{T:T+\tau-1}, Y_{T+1:T+\tau}|\mathcal{E}^j)$. We can then compute

$\hat{d}_{\mathcal{E}, Q}^{KL} = \frac{1}{JN} \sum_{j=1}^J \sum_{n=1}^N [\log P(y_n^j|x_n^j, \mathcal{E}^j) - \log Q(y_n^j|x_n^j, \mathcal{D}_T^j)]$

where

$p_{jn} = P(y_n^j|x_n^j, \mathcal{E}^j) = \prod_{t=T}^{T+\tau-1} P(Y_{n, t+1}^j|X_{n,t}^j, \mathcal{E}^j)$

$q_{jn} = Q(y_n^j|x_n^j, \mathcal{D}_T^j) = \int Q(y_n^j|x_n^j, \theta) Q(\theta|\mathcal{D}_T^j) d\theta$

$\approx \frac{1}{M} \sum_{m=1}^M \prod_{t=T}^{T+\tau-1} Q(Y_{n, t+1}^j | X_{n,t}^j, \theta_m^j)$
