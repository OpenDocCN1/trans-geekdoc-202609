## 21.4 避免后验坍缩

如果解码器 \(p_\theta(x|z)\) 足够强大（例如，像素 CNN 或用于文本的 RNN），则 VAE 无需使用潜在代码 \(z\) 来做任何事情。这被称为 **后验坍缩** 或 **变分过度剪枝**（例如，见 [Che+17b; Ale+18; Hus17a; Phu+18; TT17; Yeu+17; Luc+19; DWW19; WBC21]）。要了解为什么会发生这种情况，请考虑方程 (21.21)。如果存在生成器的参数设置 \(\theta^*\)，使得对于每个 \(z\) 都有 $p_{\theta^*}(x|z) = p_D(x)$，那么我们可以使 $D_{KL} (p_D(x) \| p_\theta(x)) = 0$。由于生成器与潜在代码无关，我们有 $p_\theta(z|x) = p_\theta(z)$。先验 $p_\theta(z)$ 通常是一个简单的分布，例如高斯分布，因此我们可以找到推断参数的设置，使得 $q_{\phi^*}(z|x) = p_\theta(z)$，从而确保 $D_{KL}(q_\phi(z|x) \| p_\theta(z|x)) = 0$。因此，我们已成功最大化 ELBO，但没有学习到数据的任何有用潜在表示，而这是潜在变量建模的目标之一。$^5$ 我们将在下面讨论后验坍缩的一些解决方案。

### 21.4.1 KL 退火

一种常见的解决此问题的方法，在 [Bow+16a] 中提出，即使用 **KL 退火**，其中 ELBO 中的 KL 惩罚项由 \(\beta\) 缩放，\(\beta\) 从 0.0（对应于自动编码器）增加到 1.0（对应于标准 MLE 训练）。（请注意，相比之下，第 21.3.1 节中的 \(\beta\)-VAE 模型使用 \(\beta > 1\)。）

KL 退火可以工作得很好，但需要调整 \(\beta\) 的时序。一种标准做法 [Fu+19] 是使用 **循环退火**，即多次重复增加 \(\beta\) 的过程。这通过利用前一个周期中学习到的良好表示来热启动优化，从而确保逐步学习更有意义的潜在代码。

### 21.4.2 对速率进行下界

另一种方法是坚持使用原始未修改的 ELBO 目标，但通过限制 \(q\) 的灵活性来防止速率（即 $D_{\mathbb{KL}}(q \| p)$ 项）坍缩到 0。例如，[XD18; Dav+18] 使用 von Mises-Fisher（第 2.2.5.3 节）先验和后验，而不是高斯分布，并且他们将后验约束为具有固定浓度，\(q(\boldsymbol{z}|\boldsymbol{x}) = \text{vMF}(\boldsymbol{z}|\boldsymbol{\mu}(\boldsymbol{x}), \kappa)\)。这里参数 \(\kappa\) 控制代码的速率。\(\delta\)-VAE 方法 [Oor+19] 使用高斯自回归先验和对角高斯后验。我们可以通过调整 AR 先验的回归参数来确保速率至少为 \(\delta\)。

### 21.4.3 自由比特

在本节中，我们讨论 **自由比特** [Kin+16] 方法，这是另一种对速率进行下界的方法。为解释这一点，考虑一个完全因式分解的后验，其中 KL 惩罚的形式为

$$\mathcal{L}_R = \sum_i D_{\mathbb{KL}}(q_\phi(z_i|\boldsymbol{x}) \| p_\theta(z_i))$$

其中 $z_i$ 是 \(\boldsymbol{z}\) 的第 \(i\) 个维度。我们可以将其替换为铰链损失，对于已经低于目标压缩率 \(\lambda\) 的维度，该损失将放弃降低 KL：

$$\mathcal{L}'_R = \sum_i \max(\lambda, D_{\mathbb{KL}}(q_\phi(z_i|\boldsymbol{x}) \| p_\theta(z_i)))$$

因此，KL 足够小的比特“是免费的”，因为模型不需要“支付”根据先验对它们进行编码。

### 21.4.4 添加跳跃连接

潜在变量坍缩的一个原因是，潜在变量 \(\boldsymbol{z}\) 与观测数据 \(\boldsymbol{x}\) 的“连接”不足够。一种简单的解决方案是通过添加 **跳跃连接**（类似于残差网络（第 16.2.4 节））来修改生成模型的架构，如图 21.10 所示。这称为 **跳跃 VAE** [Die+19a]。

### 21.4.5 改进的变分推断

后验坍缩问题部分是由于对后验的近似不佳引起的。在 [He+19] 中，他们提议在保持模型和 VAE 目标不变的同时，在每次生成模型拟合步骤之前更积极地更新推理网络。这使推理网络能够更忠实地捕捉当前的真实后验，从而在有用时鼓励生成器使用潜在代码。

但是，这仅解决了由于摊销差距 [CLD18] 而引起的后验坍缩部分，而不是更根本的变分剪枝问题，即 KL 项在后验偏离先验太远时惩罚模型，而先验通常过于简单，无法匹配聚合后验。

缓解变分剪枝的另一种方法是使用比标准 ELBO（第 10.5.1 节）更紧的下界，或更准确的后验近似（第 10.4 节），或更准确的（分层）生成模型（第 21.5 节）。

### 21.4.6 替代目标

上述方法的替代方案是将 ELBO 目标替换为其他目标，例如在第 21.3.2 节中讨论的 InfoVAE 目标，其中包括对抗自动编码器和 MMD 自动编码器作为特例。InfoVAE 目标包含一个显式强制 x 和 z 之间非零互信息的项，这有效地解决了后验坍缩问题。

## 21.5 具有层次结构的 VAE

我们定义具有 L 个随机层的分层 VAE 或 HVAE，为以下生成模型：

$$
p_\theta(x, z_{1:L}) = p_\theta(z_L) \left[ \prod_{l=L-1}^{1} p_\theta(z_l | z_{l+1}) \right] p_\theta(x | z_1)
$$

我们可以通过使上述模型成为非马尔可夫模型来对其进行改进，即让每个 z_l 依赖于所有更高级别的随机变量 z_{l+1:L}，而不仅仅是前一级，即，

$$
p_\theta(x, z) = p_\theta(z_L) \left[ \prod_{l=L-1}^{1} p_\theta(z_l | z_{l+1:L}) \right] p_\theta(x | z_{1:L})
$$

注意，似然现在是 p_\theta(x | z_{1:L}) 而不是仅仅 p_\theta(x | z_1)。这类似于从所有前驱变量到所有其子节点添加跳跃连接。通过使用残差连接的确定性“骨干”，它累积所有随机决策并将它们沿链传播下来，很容易实现这一点，如图 21.11（左）所示。我们将在下面讨论如何在该模型中执行推断和学习。

6. 文献中关于是否将顶层标记为 z_L 或 z_1 存在分歧。我们采用前一种约定，因为我们将编号较低的层（例如 z_1）视为“更接近数据”，而将编号较高的层（例如 z_L）视为“更抽象”。
