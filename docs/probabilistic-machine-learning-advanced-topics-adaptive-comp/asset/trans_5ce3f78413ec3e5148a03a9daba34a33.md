
## 6.6.1 基于序列模型的优化

BayesOpt 是一种称为序列模型优化 (SMBO) [HHLB11] 的策略的示例。在此方法中，我们在在某点查询函数和根据新数据更新代理估计之间交替进行。更准确地说，在每次迭代 n 时，我们有一个标记的数据集 Dn = {(xi, yi) : i = 1 : n}，记录了我们已查询的点 xi 及其对应的函数值 yi = f(xi) + εi，其中 εi 是可选的噪声项。我们使用此数据集来估计真函数 f 上的概率分布；我们将其表示为 p(f|Dn)。然后，我们使用采集函数 α(x; Dn) 选择下一个要查询的点 xn+1，该函数计算查询 x 的预期效用。（我们将在 6.6.3 节讨论采集函数。）在观察到 yn+1 = f(xn+1) + ϵn+1 后，我们更新对函数的信念，并重复此过程。有关伪代码，请参见算法 6.5。

```
Algorithm 6.5: Bayesian optimization
1 Collect initial dataset D0 = {(xi, yi)} from random queries xi or a space-filling design
2 Initialize model by computing p(f|D0)
3 for n = 1, 2, ... until convergence do
4   Choose next query point xn+1 = argmaxx∈X α(x; Dn)
5   Measure function value, yn+1 = f(xn+1) + ϵn
6   Augment dataset, Dn+1 = {Dn, (xn+1, yn+1)}
7   Update model by computing p(f|Dn+1)
```

该方法在图 6.10 中进行了说明。目标是找到实心黑色曲线的全局最优值。在第一行中，我们显示了两个先前查询的点 x1 和 x2，以及它们对应的函数值。y1 = f(x1) 和 y2 = f(x2)。我们对这些位置处 f 值的不确定性为 0（如果假设没有观测噪声），这由后验可信区间（着色蓝色区域）变得“收缩”来示例。因此，采集函数（底部显示为绿色）在那些先前查询的点上的值也为 0。红色三角形表示采集函数的最大值，这成为我们的下一个查询点 x3。在第二行中，我们显示观察 y3 = f(x3) 的结果；这进一步减少了我们对函数形状的不确定性。在第三行中，我们显示观察 y4 = f(x4) 的结果。此过程重复进行，直到时间耗尽，或者我们确信没有更好的未探索点可供查询。

我们需要为 BayesOpt 算法提供的两个主要“成分”是（1）表示和更新后验代理 p(f|Dn) 的方法，以及（2）定义和优化采集函数 α(x; Dn) 的方法。我们将在下文讨论这两个主题。

## 6.6.2 代理函数

在本节中，我们讨论表示和更新函数后验 p(f|Dn) 的方法。

### 6.6.2.1 高斯过程

在 BayesOpt 中，使用高斯过程（GP）作为我们的代理非常常见。高斯过程在第 18 章中有详细说明，但基本思想是它们将 p(f(x)|Dn) 表示为高斯分布，

![](img/ca72c1626f4850f058a9edc138c1ac73_324_0.png)

图 6.10：三次迭代序列贝叶斯优化示意图。各行对应训练集大小 t = 2、3、4。虚线黑色曲线是真实但未知的函数 f(x)。实线黑色曲线是后验均值 μ(x)。着色蓝色区间是从 μ(x) 和 σ(x) 得出的 95% 可信区间。实心黑点对应函数值已计算的点，即 f(xn) 已知的 xn。底部的绿色曲线是采集函数。红点是建议的下一个查询点，即采集函数的最大值。来源：[Sha+16] 图 1。经 Nando de Freitas 友好许可使用。

p(f(x)|Dn) = N(f|μn(x), σn^2(x))，其中 μn(x) 和 σn(x) 是可通过训练数据 Dn = {(xi, yi) : i = 1 : n} 使用简单闭式方程导出的函数。GP 需要指定核函数 Kθ(x, x')，它度量输入点 x 和 x' 之间的相似性。其直觉是，如果两个输入相似，因此 Kθ(x, x') 较大，则相应的函数值也可能相似，因此 f(x) 和 f(x') 应为正相关。这使我们能够在标记训练点之间插值函数；在某些情况下，它还允许超出这些点进行外推。

当训练数据较少时，GP 工作良好，并且支持闭式贝叶斯更新。然而，精确更新对 N 个样本需要 O(N^3) 时间，如果执行许多函数求值，这将变得太慢。有多种方法（第 18.5.3 节）可将此降低为 O(NM^2) 时间，其中 M 是我们选择的参数，但这会牺牲一些精度。

此外，GP 的性能在很大程度上取决于是否有一个良好的核函数。我们可以通过最大化边缘似然来估计核参数 θ，如第 18.6.1 节所述。然而，由于样本量较小（按假设），我们通常可以通过使用近似贝叶斯推断方法将 θ 边缘化来获得更好的性能，如第 18.6.2 节所述。有关详细信息，请参见 [WF16] 等。

### 6.6.2.2 贝叶斯神经网络

GP 的一种自然替代方案是使用参数模型。如果使用线性回归，我们可以高效地执行精确贝叶斯推断，如第 15.2 节所示。如果使用非线性模型，例如 DNN，则需要使用近似推断方法。我们在第 17 章中详细讨论了贝叶斯神经网络。关于它们在 BayesOpt 中的应用，请参见 [Spr+16; PPR22; Kim+22] 等。

### 6.6.2.3 其他模型

我们可以自由使用其他形式的回归模型。[HHLB11] 使用随机森林集成；此类模型可以轻松处理条件参数空间，如第 6.6.4.2 节所述，尽管 bootstrapping（用于获取不确定性估计所必需）可能较慢。

### 6.6.3 采集函数

在 BayesOpt 中，我们使用一个 **采集函数**（也称为 **优良函数**）来评估我们可能查询的每个点的预期效用：\(\alpha(\boldsymbol{x}|\mathcal{D}_n) = \mathbb{E}_{p(y|\boldsymbol{x},\mathcal{D}_n)}[U(\boldsymbol{x},y; \mathcal{D}_n)]\)，其中 \(y = f(\boldsymbol{x})\) 是点 \(\boldsymbol{x}\) 处函数的未知值，\(U()\) 是效用函数。不同的效用函数会产生不同的采集函数，如下文所述。我们通常选择使已查询点的效用较小（在无噪声观测情况下为 0）的函数，以鼓励探索。

### 6.6.3.1 改进概率

让我们定义 \(M_n = \max_{i=1}^n y_i\) 为迄今观察到的最佳值（称为 **现行最佳**）。（如果观测有噪声，使用最高均值 \(\max_i \mathbb{E}_{p(f|\mathcal{D}_n)}[f(\boldsymbol{x}_i)]\) 是一个合理的替代方案 [WF16]。）然后，我们使用 \(U(\boldsymbol{x}, y; \mathcal{D}_n) = \mathbb{I}(y > M_n)\) 定义某个新点 \(\boldsymbol{x}\) 的效用。只有当新值优于现行最佳值时，这才会给予奖励。相应的采集函数则由预期效用给出，\(\alpha_{PI}(\boldsymbol{x}; \mathcal{D}_n) = p(f(\boldsymbol{x}) > M_n | \mathcal{D}_n)\)。这称为 **改进概率** [Kus64]。如果 \(p(f|\mathcal{D}_n)\) 是 GP，则该量可按以下闭式形式计算：

\(\alpha_{PI}(\boldsymbol{x}; \mathcal{D}_n) = p(f(\boldsymbol{x}) > M_n | \mathcal{D}_n) = \Phi(\gamma_n(\boldsymbol{x}, M_n)) \quad (6.174)\)

其中 \(\Phi\) 是 \(\mathcal{N}(0, 1)\) 分布的累积分布函数，且

\(\gamma_n(\boldsymbol{x}, \tau) = \frac{\mu_n(\boldsymbol{x}) - \tau}{\sigma_n(\boldsymbol{x})} \quad (6.175)\)

### 6.6.3.2 预期改进

PI 的问题在于所有改进都被视为同样良好，因此该方法倾向于相当激进地开发 [Jon01]。一种常见的替代方案是通过定义 \(U(\boldsymbol{x}, y; \mathcal{D}_n) = (y - M_n)\mathbb{I}(y > M_n)\) 来考虑改进的幅度，并

\(\alpha_{EI}(\boldsymbol{x}; \mathcal{D}_n) = \mathbb{E}_{\mathcal{D}_n}[U(\boldsymbol{x}, y)] = \mathbb{E}_{\mathcal{D}_n}[(f(\boldsymbol{x}) - M_n)\mathbb{I}(f(\boldsymbol{x}) > M_n)] \quad (6.176)\)

该采集函数称为 **预期改进**（**EI**）准则 [Moc+96]。在 GP 代理的情况下，它具有以下闭式表达式：

\(\alpha_{EI}(\boldsymbol{x}; \mathcal{D}_n) = (\mu_n(\boldsymbol{x}) - M_n)\Phi(\gamma) + \sigma_n(\boldsymbol{x})\phi(\gamma) = \sigma_n(\boldsymbol{x})[\gamma_n\Phi(\gamma) + \phi(\gamma)] \quad (6.177)\)
