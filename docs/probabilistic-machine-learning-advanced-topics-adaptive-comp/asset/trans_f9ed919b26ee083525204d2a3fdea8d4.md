图 4.29: 用于序列标注的一维条件随机场（CRF）。

具体来说，它对应于以下形式的模型：

```
p(\boldsymbol{y}|\boldsymbol{x}, \boldsymbol{\theta}) = \frac{1}{Z(\boldsymbol{x}, \boldsymbol{\theta})} \prod_c \psi_c(\boldsymbol{y}_c; \boldsymbol{x}, \boldsymbol{\theta})
```

（请注意，分区函数现在不仅取决于参数 \boldsymbol{\theta}，还取决于输入 \boldsymbol{x}。）现在假设势函数是对数线性的，形式如下：

```
\psi_c(\boldsymbol{y}_c; \boldsymbol{x}, \boldsymbol{\theta}) = \exp(\boldsymbol{\theta}_c^T \boldsymbol{\phi}_c(\boldsymbol{x}, \boldsymbol{y}_c))
```

这是我们在第 4.3.4 节中讨论的最大熵模型的条件版本。当然，我们也可以使用非线性势函数，例如 DNN。

CRFs 很有用，因为它们能捕捉输出标签之间的依赖关系。因此，它们可用于 **结构化预测**，其中在给定输入 \(\boldsymbol{x}\) 时我们想要预测的输出 \(\boldsymbol{y} \in \mathcal{Y}\) 位于某些结构化空间中，例如标签序列或与图上节点关联的标签。在这些问题中，输出 \(\boldsymbol{y}\) 的有效值集通常存在约束。例如，如果我们想进行句子分析，输出应满足语法规则（例如，名词短语必须在动词短语之前）。有关 CRF 在 NLP 中应用的详细信息，请参见第 4.4.1 节。在某些情况下，“约束”是“软”的，而不是“硬”的。例如，如果我们想为图像中的每个像素关联一个标签（一项称为语义分割的任务），我们可能希望一个位置的标签与其邻居相同，除非视觉输入强烈暗示该位置的语义内容发生变化（例如，在物体边缘）。有关 CRF 在计算机视觉任务中应用的详细信息，请参见第 4.4.2 节。

## 4.4.1 一维 CRFs

在本节中，我们专注于定义在链式结构图形模型上的一维 CRFs。图形模型如图 4.29 所示。给定一组输入 \(\boldsymbol{x}_{1:T}\)，这定义了序列 \(\boldsymbol{y}_{1:T}\) 上的联合分布，如下所示：

```
p(\boldsymbol{y}_{1:T}|\boldsymbol{x}, \boldsymbol{\theta}) = \frac{1}{Z(\boldsymbol{x}, \boldsymbol{\theta})} \prod_{t=1}^T \psi(\boldsymbol{y}_t, \boldsymbol{x}_t; \boldsymbol{\theta}) \prod_{t=2}^T \psi(\boldsymbol{y}_{t-1}, \boldsymbol{y}_t; \boldsymbol{\theta})
```

![](img/ca72c1626f4850f058a9edc138c1ac73_218_0.png)

图 4.30: 用于联合词性标注和名词短语分割的 CRF。来自 [KF09a] 中的图 4.E.1。得到 Daphne Koller 的友好授权。

其中 \(\psi(y_t, x_t; \theta)\) 是节点势，\(\psi(y_t, y_{t+1}; \theta)\) 是边缘势。（我们假设边缘势与输入 \(x\) 无关，但此假设并非必需。）

请注意，也可以考虑使用判别式有向马尔可夫链来定义这种条件分布的另一种方式：

```
\(p(y_{1:T}|x, \theta) = p(y_1|x_1; \theta) \prod_{t=2}^T p(y_t|y_{t-1}, x_t; \theta)\) (4.139)
```

这称为最大熵隐马尔可夫模型 [MFP00]。然而，与 CRF 相比，它存在一个微妙的缺陷。具体来说，在有向模型中，每个条件 \(p(y_t|y_{t-1}, x_t; \theta)\) 都是 **局部归一化** 的，而在 CRF 中，由于 \(Z(x, \theta)\) 项，模型是 **全局归一化** 的。后者允许信息在整个序列中传播，我们将在第 4.5.3 节中更详细地讨论这一点。

CRF 在 1980 年代至 2010 年代期间广泛应用于自然语言处理（NLP）社区（参见例如 [Smi11]），尽管最近它们大多已被 RNN 和 Transformer 取代（参见例如 [Gol17]）。幸运的是，通过将 CRF 与 DNN 结合，我们可以兼得二者之长，从而将数据驱动技术与关于标签空间约束的先验知识相结合。下面我们给出一些示例。

### 4.4.1.1 名词短语分块

NLP 中一项常见的任务是 **信息抽取**，我们试图将句子解析为 **名词短语**（NP），例如人名或企业名称及地址，以及 **动词短语**，用于描述谁在对谁做什么（例如，“British Airways rose”）。为了处理这项任务，我们可以为每个词分配一个 **词性** 标签，标签对应名词、动词、形容词等。此外，为了提取每个名词短语的跨度，我们可以将词标注为位于名词短语开头（B）、内部（I）或外部（O）。示例见图 4.30。

基于此模型，我们可以计算标签的 MAP 序列，从而提取标记为名词短语的跨度。这称为 **名词短语分块**。

### 4.4.1.2 命名实体识别

在本节中，我们考虑命名实体提取任务，其中不仅要对名词短语进行标记，还要将其分类为不同类型。一种简单的方法是将 BIO 表示法扩展到 {B-Per, I-Per, B-Loc, I-Loc, B-Org, I-Org, Other}。然而，有时一个词是人名、地点还是其他东西可能不明确。专有名词尤其难以处理，因为它们属于 **开放类**，即可能存在无限多个名称，而名词和动词的集合虽然很大但基本固定。例如，“British Airways”是一个组织，而“British Virgin Islands”是一个地点。

通过考虑词之间的长程相关性，可以获得更好的性能。例如，我们可以在同一词的所有出现之间添加链接，并强制该词在每次出现时都具有相同的标签。（同样的技术也有助于解决代词指代问题。）这称为跳链 CRF。图 4.31 进行了说明，其中我们展示了单词 “Green” 在同一句话中的两次出现都被解释为人名。

我们发现图结构本身会随输入而变化，这是 CRF 相对于生成模型的另一个优势。不幸的是，由于树宽更大，该模型中的推理通常比具有局部连接的简单链更昂贵（参见第 9.5.2 节）。

### 4.4.1.3 自然语言分析

对链式结构语言模型的一种推广是使用概率文法。特别是，乔姆斯基范式中的概率上下文无关文法或 PCFG 是一组形式为 \(\sigma \rightarrow \sigma' \sigma''\) 或 \(\sigma \rightarrow x\) 的重写或产生式规则，其中 \(\sigma, \sigma', \sigma'' \in \Sigma\) 是非终结符（类似于词性），\(x \in \mathcal{X}\) 是终结符，即单词。每条此类规则都有关联的概率。结果模型定义了单词序列上的概率分布。我们可以通过对生成该序列的所有树求和来计算观察到特定序列 \(x = x_1 \dots x_T\) 的概率。这可以使用里-外算法在 \(O(T^3)\) 时间内完成；详情请参见例如 [JM08; MS99; Eis16]。

PCFG 是生成模型。可以通过使用形式为 \(p(y|x) \propto \exp(w^T \Psi(x, y))\) 的 CRF 来制作判别式版本，以编码给定单词序列 \(x\) 时标记树 \(y\) 的概率。例如，我们可以定义 \(\Psi(x, y)\) 来计算每个产生式规则使用的次数（这类似于链式结构模型中的状态转移次数），如图 4.32 所示。我们也可以使用深度神经网络来定义特征，如 [DK15b] 的神经 CRF 分析器方法所示。
