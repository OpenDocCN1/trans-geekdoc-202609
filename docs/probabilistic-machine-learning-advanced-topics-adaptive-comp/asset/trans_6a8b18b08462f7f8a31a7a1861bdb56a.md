
where typically \( f_n(\theta) = p(x_n|\theta) \)。这利用了后验仅关心近似似然的乘积，而不是分别近似每个似然这一事实。因此，\( \tilde{f}(\theta) \) 只需近似平均似然即可。

我们可以按如下方式修改 EP 以适应此设置。首先，在计算空洞分布时，我们使用

\( q_{-n}(\theta) \propto q(\theta)/\tilde{f}(\theta) \)

然后我们计算倾斜分布

\( q_{\backslash n}(\theta) \propto f_n(\theta)q_{-n}(\theta) \)

接下来，我们使用矩匹配为该数据点推导新的局部因子：

\( \tilde{f}_n(\theta) = \text{proj}(q_{\backslash n}(\theta))/q_{-n}(\theta) \)

最后，我们使用这个新的局部因子对平均似然 \( \tilde{f}(\theta) \) 进行阻尼更新：

\( \tilde{f}_{\text{new}}(\theta) = \tilde{f}_{\text{old}}(\theta)^{1-1/N}\tilde{f}_n(\theta)^{1/N} \)

ADF 算法与 SEP 类似，即我们计算倾斜分布 \( q_{\backslash t} \propto f_t q_{t-1} \)，然后对其进行投影，而无需保留 \( f_t \) 因子。区别在于，它不使用空洞分布 \( q_{-t}(\theta) \) 作为先验，而是使用前一时间步的后验 \( q_{t-1} \)。这避免了计算和存储 \( \tilde{f} \) 的需要，但在批处理设置下会导致过度自信。

## 11 蒙特卡洛方法

### 11.1 简介

在本章中，我们讨论 **蒙特卡洛方法**，这是一种解决数值积分问题的随机方法。该名称来源于摩纳哥的“蒙特卡洛”赌场；冯·诺伊曼和乌拉姆在二战期间研发原子弹时曾将其用作代号。从那以后，该技术已广泛应用于物理学、统计学、机器学习以及科学和工程的许多领域。

在本章中，我们简要介绍一些关键概念。在第 12 章中，我们讨论 MCMC，它是高维问题中最广泛使用的 MC 方法。在第 13 章中，我们讨论 SMC，它广泛用于状态空间模型中的 MC 推断，但也可以更一般地应用。有关 MC 方法的更多细节，请参见，例如，[Liu01; RC04; KTB11; BZ20]。

### 11.2 蒙特卡洛积分

我们通常希望计算随机变量的某个函数的期望值，\(\mathbb{E}[f(\mathbf{X})]\)。这需要计算以下积分：

```
\(\mathbb{E}[f(\mathbf{x})] = \int f(\mathbf{x})p(\mathbf{x})d\mathbf{x}\) (11.1)
```

其中 \(\mathbf{x} \in \mathbb{R}^n\)，\(f : \mathbb{R}^n \to \mathbb{R}^m\)，且 \(p(\mathbf{x})\) 是 \(\mathbf{X}\) 的目标分布。<sup>1</sup> 在低维（例如，最高 3 维）情况下，我们可以使用 **数值积分** 高效计算上述积分，它（自适应地）计算一个网格，然后在网格上的每个点处评估函数。<sup>2</sup> 但这不能扩展到更高维度。

另一种方法是绘制多个随机样本，\(\mathbf{x}_n \sim p(\mathbf{x})\)，然后计算

```
\(\mathbb{E}[f(\mathbf{x})] \approx \frac{1}{N_s} \sum_{n=1}^{N_s} f(\mathbf{x}_n)\) (11.2)
```

这称为 **蒙特卡洛积分**。它相对于数值积分的优势在于，函数仅在概率非可忽略的位置进行评估，因此它不需要

- 在许多情况下，目标分布可能是后验 \(p(\mathbf{x}|\mathbf{y})\)，这可能难以计算；在此类问题中，我们通常使用未归一化分布 \(\tilde{p}(\mathbf{x}) = p(\mathbf{x}, \mathbf{y})\) 代替，然后使用 \(Z = \int p(\mathbf{x}, \mathbf{y})d\mathbf{x} = p(\mathbf{y})\) 对结果进行归一化。
- 在一维中，数值积分称为 **正则积分**；在更高维度中，它称为 **多重正则积分** [Sar13]。

### 11.2.1 示例：通过蒙特卡洛积分估计 $\pi$

蒙特卡洛积分可用于许多应用，而不仅限于机器学习和统计学。例如，假设我们想要估计 $\pi$。已知半径为 $r$ 的圆的面积是 $\pi r^2$，但它也等于以下定积分：

$I = \int_{-r}^r \int_{-r}^r \mathbb{I} (x^2 + y^2 \le r^2) \, dx dy \qquad (11.3)$

因此 $\pi = I/(r^2)$。让我们通过蒙特卡洛积分来近似它。令 $f(x, y) = \mathbb{I} (x^2 + y^2 \le r^2)$ 成为一个指示函数，圆内点为 1，圆外点为 0，并令 $p(x)$ 和 $p(y)$ 为 $[-r, r]$ 上的均匀分布，因此 $p(x) = p(y) = 1/(2r)$。则

$I = (2r)(2r) \iint f(x, y) p(x) p(y) \, dx dy \qquad (11.4)$
$= 4r^2 \iint f(x, y) p(x) p(y) \, dx dy \qquad (11.5)$
$\approx 4r^2 \frac{1}{N_s} \sum_{n=1}^{N_s} f(x_n, y_n) \qquad (11.6)$

使用 5000 个样本，我们得到 $\hat{\pi} = 3.10$，标准误差为 0.09，而真实值为 $\pi = 3.14$。我们可以像图 11.1 那样绘制接受或拒绝的点。

若用 $\mu = \mathbb{E}[f(X)]$ 表示精确均值，用 $\hat{\mu}$ 表示 MC 近似值，则可证明，在独立样本下，

```
(\hat{\mu} - \mu) \to \mathcal{N}(0, \frac{\sigma^2}{N_s})
```

其中

```
\sigma^2 = \mathbb{V}[f(X)] = \mathbb{E}[f(X)^2] - \mathbb{E}[f(X)]^2
```

这是中心极限定理的结果。当然，上述表达式中 $\sigma^2$ 是未知的，但可以通过 MC 估计：

```
\hat{\sigma}^2 = \frac{1}{N_s} \sum_{n=1}^{N_s} (f(x_n) - \hat{\mu})^2
```

因此，对于足够大的 $N_s$，我们有

```
P \left\{ \hat{\mu} - 1.96 \frac{\hat{\sigma}}{\sqrt{N_s}} \le \mu \le \hat{\mu} + 1.96 \frac{\hat{\sigma}}{\sqrt{N_s}} \right\} \approx 0.95
```

术语 $\sqrt{\frac{\hat{\sigma}^2}{N_s}}$ 称为（数值或经验）**标准误差**，是我们对 $\mu$ 估计不确定性的估计。

如果我们希望以至少 95% 的概率报告一个误差在 $\pm \epsilon$ 以内的答案，则需要使用满足 $1.96 \sqrt{\hat{\sigma}^2/N_s} \le \epsilon$ 的样本数量 $N_s$。我们可以将 1.96 因子近似为 2，得到 $N_s \ge \frac{4\hat{\sigma}^2}{\epsilon^2}$。

上述结果值得注意的是，估计中的误差 $\sigma^2/N_s$ 在理论上与积分的维度无关。问题是，从高维分布中采样可能很困难。我们接下来转到该话题。

### 11.3 从简单分布生成随机样本

我们在第 11.2 节中了解到，如何使用蒙特卡洛积分评估随机变量 $X$ 的不同函数 $f$ 的 \(\mathbb{E} [f(X)]\)。主要的计算挑战是高效地从概率分布 \(p^*(x)\)（可能是后验，\(p^*(x) \propto p(x|\mathcal{D})\)）中生成样本。在本节中，我们讨论适用于参数单变量分布的采样方法。这些方法可作为从更复杂的多变量分布中采样的构建块。

### 11.3.1 使用逆累积分布函数进行采样

从单变量分布中采样的最简单方法基于 **逆概率变换**。令 \(F\) 为我们要采样的某个分布的累积分布函数，并令 \(F^{-1}\) 为其逆函数。则我们有以下结果。

定理 11.3.1. 如果 \(U \sim U(0, 1)\) 是均匀随机变量，则 \(F^{-1}(U) \sim F\)。

**证明。**

```
Pr(F^{-1}(U) \le x) = Pr(U \le F(x)) \quad (\text{applying } F \text{ to both sides}) (11.11)
= F(x) \quad (\text{because } Pr(U \le y) = y) (11.12)
```

其中第一行成立因为 \(F\) 是单调函数，第二行成立因为 \(U\) 在单位区间上是均匀分布的。

因此，对于任何我们可以评估其逆累积分布函数的单变量分布，我们可以按如下方式采样：使用 **伪随机数生成器** 生成一个随机数 \(u \sim U(0, 1)\)（详情见，例如，[Pre+88]）。令 \(u\) 表示 \(y\) 轴上的高度。然后沿 \(x\) 轴“滑动”直到与 \(F\) 曲线相交，然后“向下”并返回相应的 \(x\) 值。这相当于计算 \(x = F^{-1}(u)\)。参见图 11.3 了解示意图。

例如，考虑指数分布

```
$$ \text{Expon}(x|\lambda) \triangleq \lambda e^{-\lambda x} \mathbb{I}(x \ge 0) \tag{11.13} $$
```

其累积分布函数为

```
$$ F(x) = 1 - e^{-\lambda x} \mathbb{I}(x \ge 0) \tag{11.14} $$
```
