# 10 Variational inference

# 10.1 Introduction

In this chapter, we discuss **variational inference**, which reduces posterior inference to optimization.
Note that VI is a large topic; this chapter just gives a high level overview. For more details, see e.g.,
[Jor+98; JJ00; Jaa01; WJ08; SQ05; TLG08; Zha+19b; Bro18].

# 10.1.1 The variational objective

Consider a model with unknown (latent) variables \(\boldsymbol{z}\), known variables \(\boldsymbol{x}\), and fixed parameters \(\boldsymbol{\theta}\). (If
the parameters are unknown, they can be added to \(\boldsymbol{z}\), as we discuss later.) We assume the prior is
\(p_\theta(\boldsymbol{z})\) and the likelihood is \(p_\theta(\boldsymbol{x}|\boldsymbol{z})\), so the unnormalized joint is \(p_\theta(\boldsymbol{x}, \boldsymbol{z}) = p_\theta(\boldsymbol{x}|\boldsymbol{z})p_\theta(\boldsymbol{z})\), and the
posterior is \(p_\theta(\boldsymbol{z}|\boldsymbol{x}) = p_\theta(\boldsymbol{x}, \boldsymbol{z})/p_\theta(\boldsymbol{x})\). We assume that it is intractable to compute the normalization
constant, \(p_\theta(\boldsymbol{x}) = \int p_\theta(\boldsymbol{x}, \boldsymbol{z})d\boldsymbol{z}\), and hence intractable to compute the normalized posterior. We
therefore seek an approximation to the posterior, which we denote by \(q(\boldsymbol{z})\), such that we minimize
the following loss:

```
\(q = \underset{q \in \mathcal{Q}}{\text{argmin}} D_{KL}(q(\boldsymbol{z}) \| p_\theta(\boldsymbol{z}|\boldsymbol{x}))\)
```

Since we are minimizing over functions (namely distributions \(q\)), this is called a **variational method**.
In practice we pick a parametric family \(\mathcal{Q}\), where we use \(\boldsymbol{\psi}\), known as the **variational parameters**,
to specify which member of the family we are using. We can compute the best variational parameters
(for given \(\boldsymbol{x}\)) as follows:

```
\(\begin{aligned}
\boldsymbol{\psi}^* &= \underset{\boldsymbol{\psi}}{\text{argmin}} D_{KL}(q_\psi(\boldsymbol{z}) \| p_\theta(\boldsymbol{z}|\boldsymbol{x})) \\
&= \underset{\boldsymbol{\psi}}{\text{argmin}} \mathbb{E}_{q_\psi(\boldsymbol{z})} \left[ \log q_\psi(\boldsymbol{z}) - \log \left( \frac{p_\theta(\boldsymbol{x}|\boldsymbol{z})p_\theta(\boldsymbol{z})}{p_\theta(\boldsymbol{x})} \right) \right] \\
&= \underset{\boldsymbol{\psi}}{\text{argmin}} \underbrace{\mathbb{E}_{q_\psi(\boldsymbol{z})}[\log q_\psi(\boldsymbol{z}) - \log p_\theta(\boldsymbol{x}|\boldsymbol{z}) - \log p_\theta(\boldsymbol{z})]}_{\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\boldsymbol{x})} + \log p_\theta(\boldsymbol{x})
\end{aligned}\)
```

The final term \(\log p_\theta(\boldsymbol{x}) = \log(\int p_\theta(\boldsymbol{x}, \boldsymbol{z})d\boldsymbol{z})\) is generally intractable to compute. Fortunately, it is
independent of \(\boldsymbol{\psi}\), so we can drop it. This leaves us with the first term, which we write as follows:

```
\(\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\boldsymbol{x}) = \mathbb{E}_{q_\psi(\boldsymbol{z})} [-\log p_\theta(\boldsymbol{x}, \boldsymbol{z}) + \log q_\psi(\boldsymbol{z})]\)
```
