where \(\mu^j_{t-1|t-1}\) and \(\tau^j_{t-1|t-1}\) are the posterior mean and variance for parameter \(j\) given past data. Now we discuss how to update this prior. First we compute the one-step-ahead predictive density \(p_{t|t-1}(\boldsymbol{w}_t)\) using the standard linear-Gaussian update, i.e., \(\boldsymbol{\mu}_{t|t-1} = \boldsymbol{\mu}_{t-1|t-1}\) and \(\boldsymbol{\tau}_{t|t-1} = \boldsymbol{\tau}_{t-1|t-1} + \mathbf{Q}\), where we can set \(\mathbf{Q} = 0\mathbf{I}\) if there is no drift.

Now we concentrate on the measurement update step. Define the scalar sum (corresponding to the logits, if we are using binary classification) as \(\eta_t = \boldsymbol{w}_t^T \boldsymbol{x}_t\). If \(p_{t|t-1}(\boldsymbol{w}_t) = \prod_j \mathcal{N}(w_t^j | \mu_{t|t-1}^j, \tau_{t|t-1}^j)\), then we can compute the 1d prior predictive distribution for \(\eta_t\) as follows:

```
\(p(\eta_t|\mathcal{D}_{1:t-1}, \boldsymbol{x}_t) \approx p_{t|t-1}(\eta_t) = \mathcal{N}(\eta_t|m_{t|t-1}, v_{t|t-1})\) (8.212)

\(m_{t|t-1} = \sum_j x_{t,j} \mu_{t|t-1}^j\) (8.213)

\(v_{t|t-1} = \sum_j x_{t,j}^2 \tau_{t|t-1}^j\) (8.214)
```

The posterior for the 1d \(\eta_t\) is given by

```
\(p(\eta_t|\mathcal{D}_{1:t}) \approx p_t(\eta_t) = \mathcal{N}(\eta_t|m_t, v_t)\) (8.215)

\(m_t = \int \eta_t \frac{1}{Z_t} p(y_t|\eta_t) p_{t|t-1}(\eta_t) d\eta_t\) (8.216)

\(v_t = \int \eta_t^2 \frac{1}{Z_t} p(y_t|\eta_t) p_{t|t-1}(\eta_t) d\eta_t - m_t^2\) (8.217)

\(Z_t = \int p(y_t|\eta_t) p_{t|t-1}(\eta_t) d\eta_t\) (8.218)
```

where \(p(y_t|\eta_t) = \text{Ber}(y_t|\eta_t)\). These integrals are one dimensional, and so can be efficiently computed using Gaussian quadrature, as explained in [Zoe07; KB00].
