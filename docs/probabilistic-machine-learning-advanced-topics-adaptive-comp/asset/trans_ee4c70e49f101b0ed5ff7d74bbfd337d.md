### 28.4.2.2 狄里克莱先验相对于高斯先验的优势

与使用高斯先验相比，使用狄里克莱先验的主要优势是隐因更具可解释性。要理解这一点，请注意，第 \( d \) 个输出分布的均值参数形式为 \( \boldsymbol{\mu}_{nd} = \mathbf{W}^d \mathbf{z}_n \)，因此

```
p(x_{nd} = v | \mathbf{z}_n) = \sum_k z_{nk} w_{vk}^d \tag{28.130}
```

因此，隐性变量可以相加组合以计算均值参数，从而有助于可解释性。相比之下，第 28.3.5.2 节中的 CatPCA 模型使用高斯先验，因此 \( \mathbf{W}^d \mathbf{z}_n \)

可以为负；因此必须将此向量通过 softmax，将自然参数转换为均值参数；这使得 \(\mathbf{z}_n\) 更难解释。

### 28.4.2.3 与混合模型的联系

如果 \(\mathbf{z}_n\) 是一个 one-hot 向量，而不是概率单纯形上的任意点，那么 mPCA 模型将等同于从 \(\mathbf{W}_d\) 中选择与离散隐藏状态对应的单列。这等同于一组分类分布的有限混合（参见第 28.2.2 节），并对应于假设 \(\mathbf{x}\) 由单个簇生成。然而，mPCA 模型不要求 \(\mathbf{z}_n\) 为 one-hot，而是允许 \(\mathbf{x}_n\) 部分属于多个簇。出于此原因，该模型也称为 **混合成分** 混合模型或 **混合成员资格** 模型 [EFL04]。

## 28.5 主题模型

在本节中，我们展示如何修改第 28.4.2 节的多项式 PCA 模型，以创建用于离散标记序列（如文档中的单词或 DNA 序列中的基因）的隐性变量模型。基本思想是假设给定隐性 **主题向量** \(\mathbf{z}\) 时，单词是条件独立的。\(\mathbf{z}\) 不是单个离散簇标签，而是簇上的概率分布，每个单词都从其自身的“局部”簇中采样。在 NLP 社区中，这种模型称为 **主题模型**（参见例如 [BGHM17]）。

### 28.5.1 狄里克莱分配（LDA）

在本节中，我们讨论最常见的主题模型，即隐性 **狄里克莱分配** 或 **LDA** [BNJ03a; Ble12]。（术语“LDA”的此用法不应与线性判别分析混淆。）在遗传学社区中，该模型称为 **混合模型** [PSD00]。

### 28.5.1.1 模型定义

我们可以按如下方式定义 LDA 模型。让 \(x_{nl} \in \{1, \dots, V\}\) 成为文档 \(n\) 中第 \(l\) 个单词的标识，其中 \(l\) 现在可以从 1 到 \(L_n\)（文档长度），\(V\) 是词汇表的大小。位置 \(l\) 处单词 \(v\) 的概率由

\(p(x_{nl} = v|\mathbf{z}_n) = \sum_k z_{nk} w_{kv}\) (28.131)

给出，其中 \(0 \le z_{nk} \le 1\) 是文档 \(n\) 中“主题” \(k\) 的比例，且 \(\mathbf{z}_n \sim \text{Dir}(\boldsymbol{\alpha})\)。

我们可以通过为每个文档中的每个单词关联一个离散隐性变量 \(m_{nl} \in \{1, \dots, N_z\}\) 来重写此模型，其分布为 \(p(m_{nl}|\mathbf{z}_n) = \text{Cat}(m_{nl}|\mathbf{z}_n)\)。因此 \(m_{nl}\) 指定文档 \(n\) 中第 \(l\) 个单词使用的主题。完整的联合模型变为

\(p(\mathbf{x}_n, \mathbf{z}_n, \mathbf{m}_n) = \text{Dir}(\mathbf{z}_n|\boldsymbol{\alpha}) \prod_{l=1}^{L_n} \text{Cat}(m_{nl}|\mathbf{z}_n)\text{Cat}(x_{nl}|\mathbf{W}[m_{nl},:])\) (28.132)

其中 \(\mathbf{W}[k,:] = \mathbf{w}_k\) 是第 \(k\) 个主题上的单词分布。请参见图 28.23 了解相应的 DPGM。

图 28.23: 隐性狄里克莱分配（LDA）作为 DPGM。（a）展开形式。（b）盘子形式。

我们通常在主题参数上使用狄里克莱先验，\(p(\boldsymbol{w}_k) = \text{Dir}(\boldsymbol{w}_k | \boldsymbol{1}_V \boldsymbol{v})\)；通过设置足够小的 \(\beta\)，我们可以鼓励这些主题稀疏，使每个主题仅预测单词的一个子集。此外，我们在隐性因子上使用狄里克莱先验，\(p(\boldsymbol{z}_n) = \text{Dir}(\boldsymbol{z}_n | \boldsymbol{\alpha} \mathbf{1}_{N_z})\)。如果设置足够小的 \(\alpha\)，我们可以鼓励每个文档的主题分布稀疏，使每个文档仅包含一部分主题。请参见图 28.24 了解示例。
请注意，LDA 的早期版本称为 **概率 LSA**，在 [Hof99] 中提出。（LSA 代表“隐性语义分析”，指将 PCA 应用于文本数据；详情请参见 [Mur22, Sec 20.5.1.2]。）似然函数 \(p(\boldsymbol{x}|\boldsymbol{z})\) 与 LDA 相同，但 pLSA 为 \(\boldsymbol{z}\) 指定了一个先验，因为它旨在用于固定语料库的后验分析（类似于 LSA），而不是作为真正的生成模型。

### 28.5.1.2 一词多义

每个主题是共现且因此语义相关的单词分布。例如，图 28.25 显示了从拟合到 **TASA corpus**\(^3\) 的 LDA 模型中学习到的 3 个主题。这些似乎对应于单词“play”的 3 种不同含义：演奏乐器、戏剧表演和进行体育比赛。

我们可以使用推断的文档级主题分布来克服 **一词多义**，即消除特定单词的歧义。图 28.26 说明了这一点，其中一部分单词被标注为其分配的主题（即，我们显示 \(\arg\max_k p(m_{nl}=k|\boldsymbol{x}_n)\)）。在第一篇文档中，单词“music”清楚地表明音乐主题（编号 77）存在于文档中，这反过来使得 \(m_{nl}=77\) 更可能，其中 \(l\) 是对应单词“play”的索引。

3. TASA corpus 是包含 37,651 篇文档和 12,190,931 个单词标记的未标记教育材料集合。出现在少于 5 篇文档中的单词已被星号替换，但标点符号已保留。合并的词汇表大小为 37,202 个唯一单词。
