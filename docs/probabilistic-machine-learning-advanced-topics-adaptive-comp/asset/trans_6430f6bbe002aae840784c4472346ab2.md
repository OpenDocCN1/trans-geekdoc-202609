

剩下的就是计算未知参数 \(\mu_j\) 的后验分布。应用高斯分布的贝叶斯法则（公式（2.121）），我们发现相应的后验分布由

\(p(\mu_j|\mathbf{y}_j, n_j) = \mathcal{N}(\mu_j| \widehat{m}_j, \widehat{\tau}_j^2)\) (34.32)

\(1 / \widehat{\tau}_j = n_j/\sigma_j^2 + 1/\tau_j^2\) (34.33)

\(\widehat{m}_j / \widehat{\tau}_j = n_j\overline{y}_j/\sigma_j^2 + m_j/\tau_j^2\) (34.34)

我们可以看到，后验精度（逆方差）是先验精度加上 \(n_j\) 个单位测量精度的加权和。我们还可以看到，后验精度加权均值是先验精度加权均值与测量精度加权均值之和。

给定后验后，我们可以将 \(\widehat{m}_j\) 代入公式（34.31）。在完全对称的情况下，其中 \(n_1 = n_0\)、\(m_1 = m_0 = m\)、\(\tau_1 = \tau_0 = \tau\) 且 \(\sigma_1 = \sigma_0 = \sigma\)，我们发现最优策略是简单地"选择胜者"，即经验表现更好的臂：

\(\pi^*(\mathbf{y}_1, \mathbf{y}_0) = \mathbb{I}\left( \frac{m}{\tau^2} + \frac{\overline{y}_1}{\sigma^2} > \frac{m}{\tau^2} + \frac{\overline{y}_0}{\sigma^2} \right) = \mathbb{I}(\overline{y}_1 > \overline{y}_0)\) (34.35)

然而，当问题具有非对称性时，我们需要考虑不同的样本量和/或不同的先验信念。

## 34.3.1.2 最优样本量

我们现在讨论如何计算实验中每个臂的最优样本量，即 \(n_0\) 和 \(n_1\) 的值。我们假设总人口规模为 \(N\)，且不能重复使用测试阶段的人员。

测试阶段的先验预期奖励由

\(\mathbb{E}[R_{\text{test}}] = n_0 m_0 + n_1 m_1\) (34.36)

部署阶段的预期奖励取决于我们使用的决策规则 \(\pi(\mathbf{y}_1, \mathbf{y}_0)\)：

\(\mathbb{E}_{\pi}[R_{\text{roll}}] = \int_{\mu_1} \int_{\mu_0} \int_{\mathbf{y}_1} \int_{\mathbf{y}_0} (N - n_1 - n_0) (\pi(\mathbf{y}_1, \mathbf{y}_0)\mu_1 + (1 - \pi(\mathbf{y}_1, \mathbf{y}_0))\mu_0)\) (34.37)

\(\times p(\mathbf{y}_0|\mu_0)p(\mathbf{y}_1|\mu_1)p(\mu_0)p(\mu_1)d\mathbf{y}_0d\mathbf{y}_1d\mu_0d\mu_1\) (34.38)

对于 \(\pi = \pi^*\)，可以证明这等于

\(\mathbb{E}[R_{\text{roll}}] \triangleq \mathbb{E}_{\pi^*}[R_{\text{roll}}] = (N - n_1 - n_0) \left( m_1 + e\Phi(\frac{e}{v}) + v\phi(\frac{e}{v}) \right)\) (34.39)

其中 \(\phi\) 是高斯概率密度函数（pdf），\(\Phi\) 是高斯累积分布函数（cdf），\(e = m_0 - m_1\) 且

\(v = \sqrt{ \frac{\tau_1^4}{\tau_1^2 + \sigma_1^2/n_1} + \frac{\tau_0^4}{\tau_0^2 + \sigma_0^2/n_0} }\) (34.40)

在完全对称的情况下，公式（34.39）简化为

\(\mathbb{E}[R_{\text{roll}}] = \underbrace{(N - 2n)m}_{R_a} + \underbrace{(N - 2n) \frac{\sqrt{2}\tau^2}{\sqrt{\pi}\sqrt{2\tau^2 + \frac{2}{n}\sigma^2}}}_{R_b}\) (34.41)

这具有直观的解释。第一项 \(R_a\) 是我们在了解任何关于臂的信息之前预期获得的先验奖励。第二项 \(R_b\) 是我们因选择最佳动作进行部署而预期看到的奖励。令 \(R_b = (N - 2n)R_i\)，其中 \(R_i\) 是增量收益。我们可以看到，增量收益随 \(n\) 增加而增加，因为使用更大的样本量我们更有可能选择正确的动作；然而，正如 \(N - 2n\) 前因子所示，这种收益只能在更少的人群中累积。（这是探索-利用权衡的结果。）

总预期奖励由公式（34.36）和公式（34.41）相加得到：

\(\mathbb{E}[R] = \mathbb{E}[R_{\text{test}}] + \mathbb{E}[R_{\text{roll}}] = Nm + (N - 2n) \left( \frac{\sqrt{2}\tau^2}{\sqrt{\pi}\sqrt{2\tau^2 + \frac{2}{n}\sigma^2}} \right)\) (34.42)

（非对称情况下的公式见 [FB19]。）

我们可以最大化公式（34.42）中的预期奖励，以找到测试阶段的最优样本量，由对称性可知其满足 \(n_1^* = n_0^* = n^*\)，并且由 \(\frac{d}{dn^*}\mathbb{E}[R] = 0\) 可得

\(n^* = \sqrt{\frac{N}{4}u^2 + \left(\frac{3}{4}u^2\right)^2} - \frac{3}{4}u^2 \le \sqrt{N}\frac{\sigma}{2\tau}\) (34.43)

其中 \(u^2 = \frac{\sigma^2}{\tau^2}\)。因此我们可以看到，随着观测噪声 \(\sigma\) 的增加，最优样本量 \(n^*\) 会增加，因为我们需要收集更多数据才能对正确决策有信心。然而，最优样本量随 \(\tau\) 的增加而减少，因为相信效应大小 \(\delta = \mu_1 - \mu_0\) 会较大意味着我们预期需要更少的数据即可得出确定的结论。

## 34.3.1.3 遗憾

给定一个策略，自然会想知道它有多好。我们定义策略的**遗憾**为基于**完美信息**（PI）关于真实最佳动作的预期奖励与由于我们的策略而获得的预期奖励之差。最小化遗憾等同于使我们策略的预期奖励等于最佳可能奖励（这可能较高或较低，取决于具体问题）。

一个知道哪个 \(\mu_j\) 更大的神谕会选择得分最高的动作，因此获得预期奖励 \(N\mathbb{E}[\max(\mu_1, \mu_2)]\)。由于我们假设 \(\mu_j \sim \mathcal{N}(m, \tau^2)\)，我们有

\(\mathbb{E}[R|PI] = N \left( m + \frac{\tau}{\sqrt{\pi}} \right)\) (34.44)

因此，最优策略的遗憾由

\(\mathbb{E}[R|PI] - (\mathbb{E}[R_{\text{test}}|\pi^*] + \mathbb{E}[R_{\text{roll}}|\pi^*]) = N \frac{\tau}{\sqrt{\pi}} \left( 1 - \frac{\tau}{\sqrt{\tau^2 + \frac{\sigma^2}{n^*}}} \right) + \frac{2n^*\tau^2}{\sqrt{\pi}\sqrt{\tau^2 + \frac{\sigma^2}{n^*}}}\) (34.45)

可以证明，遗憾为 \(O(\sqrt{N})\)，当使用时间范围（人口规模）\(N\) 时，这对该问题是最优的 [AG13]。

## 34.3.1.4 预期误差率

有时，目标被表述为**最佳臂识别**，即识别 \(\mu_1 > \mu_0\) 是否成立。也就是说，如果我们定义 \(\delta = \mu_1 - \mu_0\)，我们想知道 \(\delta > 0\) 还是 \(\delta < 0\)。这自然地表述为一个**假设检验**。然而，这可以说是错误的目标，因为如果 \(\delta\) 的幅度很小，通常不值得花钱收集大量样本量来有把握地确定 \(\delta > 0$（例如）。相反，优化总预期奖励更有意义，使用第 34.3.1.1 节的方法。尽管如此，如果我们使用第 34.3.1.1 节的策略，我们可能想知道选择错误臂的概率。在对称情况下，这由以下给出：

\( Pr(\pi(\mathbf{y}_1, \mathbf{y}_0) = 1 | \mu_1 < \mu_0) = Pr(Y_1 - Y_0 > 0 | \mu_1 < \mu_0) = 1 - \Phi \left( \frac{\mu_1 - \mu_0}{\sigma \sqrt{\frac{1}{n_1} + \frac{1}{n_0}}} \right) \tag{34.46} \)

上述表达式假设 \(\mu_j\) 是已知的。由于它们未知，我们可以使用 \(\mathbb{E} [Pr(\pi(\mathbf{y}_1, \mathbf{y}_0) = 1 | \mu_1 < \mu_0)]\) 来计算预期误差率。由对称性可知，量 \(\mathbb{E} [Pr(\pi(\mathbf{y}_1, \mathbf{y}_0) = 0 | \mu_1 > \mu_0)]\) 相同。可以证明，这两个量均由

\(\text{Prob. error} = \frac{1}{4} - \frac{1}{2\pi} \arctan \left( \frac{\sqrt{2}\tau}{\sigma} \sqrt{\frac{n_1 n_0}{n_1 + n_0}} \right) \tag{34.47} \)

如预期，误差率随样本量 \(n_1\) 和 \(n_0\) 的增加而降低，随观测噪声 \(\sigma\) 的增加而升高，并随效应大小的方差 \(\tau\) 的增加而降低。因此，最小化分类误差的策略也将最大化预期奖励，但它可能会选择过大的样本量，因为它没有考虑 \(\delta\) 的幅度。

## 34.3.2 示例

在本节中，我们给出了上述框架的一个简单示例。假设我们的目标是进行**网站测试**，我们有两个不同版本的网页，想要在**点击率**方面进行比较。观测数据现在是二进制的，\(y_{ij} \sim \text{Ber}(\mu_j)\)，因此使用 beta 先验 \(\mu_j \sim \text{Beta}(\alpha, \beta)\) 是自然的（参见第 3.4.1 节）。然而，在这种情况下，最优样本量和决策规则更难计算（详情见 [FB19; Sta+17]）。作为一个简单的近似，我们可以假设 \(\bar{y}_{ij} \sim \mathcal{N}(\mu_j, \sigma^2)\)，其中 \(\mu_j \sim \mathcal{N}(m, \tau^2)\)、\(m = \frac{\alpha}{\alpha + \beta}\)、\(\tau^2 = \frac{\alpha \beta}{(\alpha + \beta)^2 (\alpha + \beta + 1)}\) 且 \(\sigma^2 = m(1 - m)\)。为了设定高斯先验，[FB19] 使用了约 2000 次先前 A/B 测试的实证数据。对于每次测试，他们观察了每个变体页面被投放的次数，以及用户点击每个版本的总次数。基于这些数据，他们使用了一个分层贝叶斯模型来推断 \(\mu_j \sim \mathcal{N}(m = 0.68, \tau = 0.03)\)。这个先验意味着预期效应大小相当小，\(\mathbb{E} [|\mu_1 - \mu_0|] = 0.023$。（这与 [Aze+20] 的结果一致，后者发现对 Microsoft Bing EXP 平台所做的大多数更改影响可忽略，尽管偶尔会有一些“大获全胜”。）使用此先验，并假设人口规模为 \(N = 100,000$，公式（34.43）指出最优运行试验次数为 \(n_1^* = n_0^* = 2284$。测试阶段的预期奖励（点击次数或**转化数**）为 \(\mathbb{E} [R_{test}] = 3106$，部署阶段为 \(\mathbb{E} [R_{roll}] = 66,430$，总奖励为 69,536。预期误差率为 10%。
