This works as follows. Given previous sample $x^i$, we sample $v^{i+1}$ from

```
$p(v|x^i) = U_{[0,\tilde{p}(x^i)]}(v)$ \qquad (12.60)
```

This amounts to uniformly picking a point on the vertical line between 0 and $\tilde{p}(x^i)$. We use this to construct a “slice” of the density at or above this height, by computing $A^{i+1} = \{x : \tilde{p}(x) \ge v^{i+1}\}$. We then sample $x^{i+1}$ uniformly from this set. See Figure 12.7(a) for an illustration.

To compute the level set $A$, we can use an iterative search procedure called stepping out, in which we start with an interval $x_{min} \le x \le x_{max}$ around the current point $x^i$ of some width, and then we keep extending it until the endpoints fall outside the slice. We can then use rejection sampling to sample from the interval. For the details, see [Nea03].
