

然后，对于折 $j$ 中的每个数据点 $i$，我们取 $\hat{Q}(a_i, x_i) = \hat{Q}^{-j}(a_i, x_i)$ 和 $\hat{g}(x_i) = \hat{g}^{-j}(x_i)$。也就是说，每个数据点的估计条件结果和倾向得分均来自未在该数据点上训练的模型的预测。然后，我们通过将 $\{\hat{Q}(a_i, x_i), \hat{g}(x_i)\}_i$ 代入公式 (36.30) 来估计 $\tau$。可以证明，这种交叉拟合程序具有与上述相同的渐近保证——以 $\sqrt{n}$ 速率的中心极限定理。

## 36.4.3 不确定性量化

除了平均处理效应的点估计 $\hat{\tau}$ 之外，我们还希望报告一个衡量估计不确定性的指标。例如，以置信区间的形式。$\sqrt{n}\hat{\tau}$ 的渐近正态性（公式 (36.39））为此量化提供了一种方法。具体来说，我们可以将置信区间等基于极限方差 $\mathbb{E}[\phi(\mathbf{X}_i; Q, g, \tau)^2]$。当然，我们实际上不知道 $Q$、$g$ 或 $\tau$ 中的任何一个。然而，结果表明，使用 $\frac{1}{n} \sum_i \phi(\mathbf{X}_i; \hat{Q}, \hat{g}, \hat{\tau})^2$ 估计渐近方差就足够了 [Che+17e]。也就是说，我们可以通过简单地将我们的拟合干扰模型和 $\tau$ 的点估计代入以下公式来估计不确定性：

```
$\hat{\mathbb{V}}[\hat{\tau}] = 1/n \sum_i \phi(\mathbf{X}_i; \hat{Q}, \hat{g}, \hat{\tau})^2.$
```

然后可以使用此估计方差以常规方式计算置信区间。例如，我们将 $\tau$ 的 95% 置信区间报告为 $\hat{\tau} \pm 1.96\sqrt{\hat{\mathbb{V}}[\hat{\tau}]/n}$。

或者，我们也可以通过自助法来量化不确定性。不过请注意，这需要为每个自助模型重新拟合干扰函数。取决于模型和数据，这可能在计算上过于昂贵。

## 36.4.4 匹配

调整式因果估计中一种特别流行的方法是**匹配**。直观上，其思想是将每个处理组单元与具有相同（或至少相似）混杂变量值的未处理组单元进行匹配，然后比较处理组单元及其匹配对照组的观察结果。如果我们对所有共同原因进行匹配，那么结果的差异直观上是该处理组单元所受处理效应的一个含噪估计。我们现在将更仔细地构建这一思想。在此过程中，我们将看到匹配本质上可以理解为一种特定的结果模型调整。

为简单起见，考虑 $X$ 为离散随机变量的情况。定义 $\mathcal{A}_x$ 为协变量值为 $x$ 的处理组单元集合，$\mathcal{C}_x$ 为协变量值为 $x$ 的未处理组单元集合。在这种情况下，匹配估计量为：

```
$\hat{\tau}^{\text{matching}} = \sum_x \hat{\text{P}}(x) \big( \frac{1}{|\mathcal{A}_x|} \sum_{i \in \mathcal{A}_x} Y_i - \frac{1}{|\mathcal{C}_x|} \sum_{j \in \mathcal{C}_x} Y_j \big),$
```

其中 $\hat{\text{P}}(x)$ 是 $\text{P}(X = x)$ 的一个估计量——例如，$X = x$ 的单元比例。现在，我们可以将 $Y_i = Q(A_i, X_i) + \xi_i$ 重写，其中 $\xi_i$ 是由该方程定义的单元特定噪声项。特别是，我们有 $\mathbb{E}[\xi_i | A_i, X_i] = 0$。代入此式，我们得到：

```
$\hat{\tau}^{\text{matching}} = \sum_x \hat{\text{P}}(x) (Q(1, x) - Q(0, x)) + \sum_x \frac{1}{|\mathcal{A}_x|} \sum_{i \in \mathcal{A}_x} \xi_i - \frac{1}{|\mathcal{C}_x|} \sum_{j \in \mathcal{C}_x} \xi_j.$
```

我们可以将第一项识别为通常目标参数 $\tau$ 的估计量（如果 $\hat{P}(x) = P(x)$，则它将等于 $\tau$）。第二项是期望为 0 的随机变量平均值的差，因此只要 $|\mathcal{A}_x|$ 和 $|\mathcal{C}_x|$ 随数据增多都趋于无穷大，每一项都将趋于 0。因此，我们看到匹配估计量是估计参数 $\tau$ 的一种特定方式。该程序可以通过引入 $X$ 值接近的某种概念，然后对接近的处理组和对照组变量进行匹配，扩展到连续协变量。

此处我们应强调两点。首先，请注意，这里的论证与因果识别无关。匹配是估计观测参数 $\tau$ 的一种特定技术。$\tau$ 是否可以解释为平均处理效应由定理 2 的条件决定——特定的估计策略对此没有任何说明。其次，请注意，本质上匹配相当于对 $\hat{Q}$ 做出特定的模型选择。具体来说，$\hat{Q}(1, x) = \frac{1}{|\mathcal{A}_x|} \sum_{i \in \mathcal{A}_x} Y_i$，$\hat{Q}(0, x)$ 同理。也就是说，我们将具有相同协变量值的单元的条件预期结果估计为样本均值。这是否是一个好主意取决于我们对 $Q$ 的模型质量。在可能有更好模型的情况下（例如，机器学习模型能够很好地拟合数据），我们可能期望通过直接使用条件预期结果预测器来获得更准确的估计。

顺便提及另一个重要案例。一般来说，在使用基于调整的识别时，只需对任何满足 $A \perp \! \! \! \perp X | \phi(X)$ 的 $X$ 的函数 $\phi(X)$ 进行调整即可。要理解只对 $\phi(X)$ 进行调整就足够了，首先注意 $g(X) = P(A=1|X) = P(A=1|\phi(X))$ 仅取决于 $\phi(X)$，然后回顾目标参数可以写成 $\tau = \mathbb{E}[\frac{YA}{g(X)} - \frac{Y(1-A)}{1-g(X)}]$，因此 $\tau$ 仅通过 $g(X)$ 依赖于 $X$。也就是说：将 $X$ 替换为减小版本 $\phi(X)$，使得 $g(X) = P(A=1|\phi(X))$，不会对 $\tau$ 产生任何影响。确实，$\phi(X)$ 最流行的选择就是倾向得分本身，$\phi(X) = g(X)$。这导致了**倾向得分匹配**，这是一个两步程序：首先拟合倾向得分模型，然后基于每个单元的估计倾向得分值进行匹配。再次强调，这只是估计观测参数 $\tau$ 的一种特定程序，并不能说明将 $\tau$ 解释为因果效应是否有效。

## 36.4.5 实际考虑与程序

在进行因果分析时，实际中可能会出现许多问题，下面我们将讨论其中一些问题。

### 36.4.5.1 调整哪些变量

在使用协变量调整估计因果效应时，选择调整哪些变量是一个关键细节。当拥有完整的因果图，说明 $A$、$Y$ 及所有协变量 $X$ 之间的关系时，标准是明确的。具体来说，调整所有实际上是 $A$ 和 $Y$ 的因果父节点的变量。事实上，在拥有完整图的情况下，此标准可以进一步推广——见第 36.8 节。在实践中，我们通常并不实际知道所有变量之间的完整因果图。因此，通常会应用简单的启发式方法来确定调整哪些变量。不幸的是，这些启发式方法存在严重局限性。不过，探索这些局限性是有启发意义的。

定理 2 的一个关键条件是，我们调整的协变量 $X$ 必须包含所有共同原因。在没有完整因果图的情况下，很诱人对尽可能多的观测变量进行条件化，以试图确保此条件成立。然而，这可能会带来问题。例如，假设 $M$ 是 $A$ 对 $Y$ 的效应的中介变量——即，$M$ 位于从 $A$ 到 $Y$ 的某条有向路径上。

A 和 Y 之间的路径。然后，对 M 进行条件化会阻断此路径，移除部分因果效应。请注意，这并不总是导致衰减或幅度较小的效应估计。通过特定中介的效应可能与来自处理的其他因果路径方向相反；因此，对中介进行条件化可能会放大甚至改变处理效应的符号。或者，如果 C 是 A 和 Y 之间的碰撞变量——即由两者引起的一个变量——那么对 C 进行条件化会在 A 和 Y 之间引入额外的统计依赖关系。

上面讨论的“对所有变量进行条件化”启发式的两个陷阱都涉及对处理 A 下游的变量进行条件化。对此的一种自然反应是将条件化限制在所有预处理变量上，或者那些在因果上位于处理上游的变量。重要的是，如果在观测协变量 X 中存在有效的调整集，那么在预处理协变量中也会存在一个有效的调整集。这是因为 A 和 Y 之间的任何打开的回门路径都必须包含 A 的一个父节点，而预处理协变量集包括这些父节点。然而，对预处理变量的完整集合进行条件化仍有可能通过碰撞变量在 A 和 Y 之间诱导新的回门路径。特别是，如果存在一个协变量 D，它分别与处理 A 和结果 Y 混杂，那么 D 是一个碰撞变量，对 D 进行条件化会打开一条新的回门路径。由于图形的形状，这种现象被称为 m-偏倚 [Pea09c]，见图 36.4。

VanderWeele 和 Shpitser [VS11] 给出了预处理变量启发式的一个实用改进。他们的启发式建议对所有作为处理、结果或两者原因的预处理变量进行条件化。该启发式的基本限定条件是，变量在因果上位于处理和/或结果的上游。这消除了对仅与处理和结果混杂的协变量进行条件化的可能性，从而避免 m-偏倚。值得注意的是，该启发式比上述启发式需要更多的因果知识，但不需要详细了解不同协变量之间如何在因果上相互关联。

VanderWeele 和 Shpitser [VS11] 标准是一个有用的经验法则，但实际中还常出现其他考量。例如，如果一个人对协变量之间的因果结构有更多了解，则可以优化调整集以最小化所得估计量的方差 [RS20]。通过修剪调整集来减少方差的一个重要示例是排除那些已知仅是处理的父节点而非结果的父节点的变量（即所谓的工具变量，如第 36.5 节所述）。
