概率编程语言与标准语言之间的区别在 [Gor+14] 中被描述如下：“概率程序是通常的函数式或命令式程序，附加了两个构造：（1）能够从分布中随机抽取值的能力，以及（2）通过观察对程序中变量值进行条件化的能力。”前者是定义 \(p(\boldsymbol{z}, \boldsymbol{y})\) 的一种方式，后者与标准贝叶斯条件化 \(p(\boldsymbol{z}|\boldsymbol{y})\) 相同。

PPL 的一些最近示例包括 **Gen** [CT+19]、**Pyro** [Bin+19] 和 **Turing** [GXG18]。此类模型中的推断通常基于 SMC，我们将在第 13 章中讨论。有关 PPL 的更多详细信息，请参见例如 [Mee+18]。

## 4.7 结构因果模型

> 而概率编码了我们对静态世界的信念，因果性则告诉我们当世界改变时（无论是通过干预还是通过想象行为）概率是否以及如何改变。—— Judea Pearl [PM18b]。

在本节中，我们讨论如何使用有向图形模型表示法来表示**因果模型**。我们将在第 36 章中更详细地讨论因果性，但我们在此介绍一些基本概念和表示法，因为这是我们在书中其他部分所需的基础材料。

因果模型背后的核心思想是创建世界的机制模型，以便我们可以推理局部变化的影响。典型示例是电子电路：我们可以通过局部修改电路，然后从相同的初始条件“重新运行”它，来预测任何动作的影响，例如“敲除”特定晶体管或更改电线的电阻水平。

我们可以推广此想法来创建**结构因果模型**或**SCM** [PGJ16]，也称为**功能因果模型** [Sch19]。SCM 是一个三元组 \(\mathcal{M} = (\mathcal{U}, \mathcal{V}, \mathcal{F})\)，其中 \(\mathcal{U} = \{U_i : i = 1 : N\}\) 是一组未解释或**外源**“噪声”变量，这些变量作为输入传递给模型，\(\mathcal{V} = \{V_i : i = 1 : N\}\) 是模型本身的一组**内生**变量，而 \(\mathcal{F} = \{f_i : i = 1 : N\}\) 是形式为 \(V_i = f_i(\mathrm{V}_{\mathrm{pa}_i}, U_i)\) 的确定性函数集，其中 \(\mathrm{pa}_i\) 是变量 \(i\) 的父节点，且 \(U_i \in \mathcal{U}\) 是外部输入。我们假设方程可以以**递归**方式结构化，因此给定父节点时节点的依赖图是一个 DAG。最后，我们假设我们的模型是**因果充分**的，这意味着 \(\mathcal{V}\) 和 \(\mathcal{U}\) 是所有与因果相关的因素（尽管它们可能并非全部被观察到）。这被称为“**因果马尔可夫假设**”。

当然，模型通常无法表示所有可能影响观察或决策的变量。毕竟，模型是现实的_抽象_。我们选择不以功能方式显式建模的变量可以被归入未建模的外源项中。为了表示我们对这些术语的无知，我们可以使用它们值上的分布 \(p(U)\)。通过将此外部噪声“推入”模型的确定性部分，我们在内生变量上诱导出一个分布 \(p(\mathcal{V})\)，如同在概率图形模型中一样。然而，SCM 对 PGM 做出了更强的假设。

我们通常假设 \(p(U)\) 是因式分解的（即，\(U_i\) 是独立的）；这被称为**马尔可夫 SCM**。如果外源噪声项不是独立的，这将打破以下假设：

### 4.7.1 示例：教育对财富的因果影响

我们现在基于 [PM18b, p276] 给出一个 SCM 的简单示例。假设我们对教育对财富的因果效应感兴趣。设 $X$ 表示一个人的教育水平（在某个数值尺度上，例如 0 = 高中，1 = 大学，2 = 研究生院），$Y$ 表示其财富（在某个时间点）。在某些情况下，我们可能期望增加 $X$ 会增加 $Y$（当然这取决于学位性质、工作性质等）。因此，我们从 $X$ 向 $Y$ 添加一条边。然而，获得更多教育可能花费大量资金（在某些国家），这是财富的一个潜在混淆因素。设 $Z$ 为个人基于其教育所产生的债务。我们从 $X$ 向 $Z$ 添加一条边以反映较大的 $X$ 通常意味着较大的 $Z$，并从 $Z$ 向 $Y$ 添加一条边以反映较大的 $Z$ 通常意味着较低的 $Y$。

我们可以如图 4.53b(a) 所示以图形方式表示我们的结构假设。相应的 SCM 形式为：

\(X = f_X(U_x)\) (4.183)

\(Z = f_Z(X, U_z)\) (4.184)

\(Y = f_Y(X, Z, U_y)\) (4.185)

对于某组函数 $f_x, f_y, f_z$ 和某个先验分布 $p(U_x, U_y, U_z)$。我们还可以如图 4.53b(b) 所示显式表示外源噪声项；这明确了我们假设噪声项先验独立。（我们稍后再回到这一点。）

### 4.7.2 结构方程模型

**结构方程模型** [Bol89; BP13]，也称为**路径图**，是结构因果模型的一个特例，其中所有功能关系都是线性的，且噪声项上的先验是高斯的。SEM 在经济学和社会科学中广泛使用，因为它们具有因果解释，同时在计算上可处理。

例如，让我们制作我们教育示例的 SEM 版本。我们有

\(X = U_x\) (4.186)

\(Z = c_z + w_{xz}X + U_z\) (4.187)

\(Y = c_y + w_{xy}X + w_{zy}Z + U_y\) (4.188)

如果我们假设 \(p(U_x) = \mathcal{N}(U_x|0, \sigma_x^2)\)、\(p(U_z) = \mathcal{N}(U_z|0, \sigma_z^2)\) 和 \(p(U_y) = \mathcal{N}(U_y|0, \sigma_y^2)\)，则该模型可以转换为以下高斯 DGM：

\(p(X) = \mathcal{N}(X|\mu_x, \sigma_x^2)\) (4.189)

\(p(Z|X) = \mathcal{N}(Z|c_z + w_{xz}X, \sigma_z^2)\) (4.190)

\(p(Y|X, Z) = \mathcal{N}(Y|c_y + w_{xy}X + w_{zy}Z, \sigma_y^2)\) (4.191)

我们可以放松线性假设，以允许任意灵活的函数，并放松高斯假设，以允许任何噪声分布。由此产生的“非参数 SEM”等价于结构因果模型。（有关 SEM 和 SCM 之间更详细的比较，请参见 [Pea12; BP13; Shi00b]。）

### 4.7.3 Do 算子和增强 DAG

SCM 的主要优点之一是它们让我们能够预测**干预**的效果，干预是改变一个或多个局部机制的动作。一种简单的干预是强制变量取某个给定值，例如，我们可以强制基因为“开启”或“关闭”。这称为**完美干预**，并写为 do($X_i = x_i$)，其中我们引入了新的**“do”算子**表示法（如同动词“执行”）。该表示法意味着我们主动将变量 $X_i$ 固定到值 $x_i$（而不仅仅是观察到它具有该值）。由于 $X_i$ 的值现在与其通常的父节点独立，我们应该在图中“切断”指向节点 $X_i$ 的入边。这称为**“图手术”**操作。

在图 4.54a 中，我们针对我们的教育 SCM 说明了这一点，其中我们强制 $Z$ 取某个给定值。例如，我们可以通过偿还所有人的学生债务来设置 \(Z = 0\)。请注意，\(p(X|\text{do}(Z = z)) \neq p(X|Z = z)\)，因为干预改变了模型。例如，如果我们看到某人债务为 0，我们可能会推断他们可能没有接受过高等教育，即 $p(X \ge 1|Z = 0)$ 很小；但如果我们偿还所有人的大学贷款，那么在这个修改后的世界中观察到某人没有债务不应改变我们对他们是否接受高等教育的信念，即 $p(X \ge 1|\text{do}(Z = 0)) = p(X \ge 1)\)。

在更现实的场景中，我们可能无法将变量设置为特定值，但我们可能能够以某种方式将其从当前值更改。例如，我们可能能够将所有人的债务减少某个固定金额，例如 \(\Delta = -10,000\)。因此，我们用 \(Z = f'_Z(X, U_z)\) 替换 \(Z = f_Z(X, U_z)\)，其中 \(f'_Z(X, U_z) = f_Z(X, U_z) + \Delta\)。这称为**加性干预**。

为了建模此类场景，我们可以创建一个**增强 DAG**，其中每个变量都增加了一个额外的父节点，表示变量的机制是否以某种方式发生变化 [Daw02; Daw15; CPD17]。这些额外变量由方形节点表示，对应于决策变量或动作，如影响图形式主义（第 34.2 节）中所述。同样的形式主义也用于强化学习中的 MDP（参见第 34.5 节）。

我们在图 4.54b 中给出了一个示例，其中我们添加了 \(A_z \in \{0, 1\}\) 节点以指定是否使用债务减少政策。\(Z\) 的修改机制变为

\(Z = f'_Z(X, U_z, A_z) = \begin{cases} f_Z(X, U_z) & \text{if } A_z = 0 \\ f_Z(X, U_z) + \Delta & \text{if } A_z = 1 \end{cases}\) (4.192)

有了这个新定义，对动作效果的条件化可以使用标准概率推断来执行。即，\(Q[\text{do}(A_z = a), E = e] = p(Q|A_z = a, E = e)\)，其中 \(Q\) 是查询（例如，事件 \(X \ge 1\)），\(E\) 是（可能为空的）证据变量。这是因为 \(A_z\) 节点没有父节点，因此当我们将其固定时，没有入边可切断。

尽管增强 DAG 允许我们使用标准表示法（没有显式 do 算子）和推断机制，但使用“外科式”干预（即删除指向被设置为某值的节点的入边）会产生一个更简单的图，这可以简化许多计算，特别是在非参数环境中（有关讨论，请参见 [Pea09b, p361]）。因此，它是一个有用的抽象，即使它不如增强 DAG 方法那么通用。
