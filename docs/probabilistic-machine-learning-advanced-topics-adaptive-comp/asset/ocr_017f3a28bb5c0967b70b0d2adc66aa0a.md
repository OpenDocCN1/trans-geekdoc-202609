Unfortunately, computing this integral is usually intractable, since it corresponds to the normalization constant of the exact posterior. Fortunately, the ELBO is a lower bound on this:

```
$$ \mathbb{L}(\theta, \psi_n | x_n) \le \log p(x_n | \theta) $$ (10.21)
```

We can thus optimize the model parameters by maximizing

```
$$ \mathbb{L}(\theta, \psi_{1:N} | \mathcal{D}) \triangleq \sum_{n=1}^N \mathbb{L}(\theta, \psi_n | x_n) \le \log p(\mathcal{D} | \theta) $$ (10.22)
```

This is the basis of the **variational EM** algorithm. We discuss this in more detail in Section 6.5.6.1, but the basic idea is to alternate between maximizing the ELBO wrt the variational parameters $\{\psi_n\}$ in the E step, to give us $q_{\psi_n}(z_n)$, and then maximizing the ELBO (using the new $\psi_n$) wrt the model parameters $\theta$ in the M step. (We can also use SGD and amortized inference to speed this up, as we explain in Sections 10.1.4 to 10.1.5.)

# ## 10.1.3.2 Empirical Bayes for fully observed models

Suppose we have a fully observed model (with no local latent variables) of the form

```
$$ p(\mathcal{D}, \theta | \xi) = p(\theta | \xi) \prod_{n=1}^N p(x_n | \theta) $$ (10.23)
```

as shown in Figure 10.3b. In the context of Bayesian parameter inference, our goal is to compute the parameter posterior:

```
$$ p(\theta | \mathcal{D}, \xi) = \frac{p(\mathcal{D} | \theta) p(\theta | \xi)}{p(\mathcal{D} | \xi)} $$ (10.24)
```
