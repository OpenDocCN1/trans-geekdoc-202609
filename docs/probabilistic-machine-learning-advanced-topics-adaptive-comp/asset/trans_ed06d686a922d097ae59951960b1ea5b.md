## 2.2.3.1 伽马分布

**伽马分布** 是针对正实值随机变量（rv’s，x > 0）的一种灵活分布。它由两个参数定义，称为形状 \(a > 0\) 和速率 \(b > 0\)：

```
\(\mathrm{Ga}(x|\text{shape} = a, \text{rate} = b) \triangleq \frac{b^a}{\Gamma(a)} x^{a-1} e^{-xb}\) (2.38)
```

有时，分布是用速率 \(a\) 和 **尺度** \(s = 1/b\) 来参数化的：

```
\(\mathrm{Ga}(x|\text{shape} = a, \text{scale} = s) \triangleq \frac{1}{s^a \Gamma(a)} x^{a-1} e^{-x/s}\) (2.39)
```

请参见图 2.3a 以示说明。

## 2.2.3.2 指数分布

**指数分布** 是伽马分布的一个特例，定义为

```
\(\mathrm{Exp}(x|\lambda) \triangleq \mathrm{Ga}(x|\text{shape} = 1, \text{rate} = \lambda)\) (2.40)
```

该分布描述了泊松过程中事件之间的时间，即事件以恒定平均速率 \(\lambda\) 连续且独立发生的过程。

## 2.2.3.3 卡方分布

**卡方分布** 是伽马分布的一个特例，定义为

```
\(\chi^2_\nu(x) \triangleq \mathrm{Ga}(x|\text{shape} = \frac{\nu}{2}, \text{rate} = \frac{1}{2})\) (2.41)
```

其中 \(\nu\) 称为自由度。这是平方高斯随机变量之和的分布。更准确地说，如果 \(Z_i \sim \mathcal{N}(0,1)\)，且 \(S = \sum_{i=1}^\nu Z_i^2\)，则 \(S \sim \chi^2_\nu\)。因此，如果 \(X \sim \mathcal{N}(0, \sigma^2)\)，则 \(X^2 \sim \sigma^2 \chi^2_1\)。由于 \(\mathbb{E}[\chi_1^2] = 1\) 且 \(\mathbb{V}[\chi_1^2] = 2\)，我们有
\(\mathbb{E}[X^2] = \sigma^2, \mathbb{V}[X^2] = 2\sigma^4\)

## 2.2.3.4 逆伽马分布

逆伽马分布，记作 \(Y \sim \text{IG}(a, b)\)，是 \(Y = 1/X\) 的分布，假设 \(X \sim \text{Ga}(a, b)\)。该概率密度函数定义为

\(\text{IG}(x|\text{shape} = a, \text{scale} = b) \triangleq \frac{b^a}{\Gamma(a)} x^{-(a+1)} e^{-b/x}\)

均值仅在 \(a > 1\) 时存在。方差仅在 \(a > 2\) 时存在。

缩放逆卡方分布是逆伽马分布的一种重参数化：

\(\chi^{-2}(x|\nu, \sigma^2) = \text{IG}(x|\text{shape} = \frac{\nu}{2}, \text{scale} = \frac{\nu \sigma^2}{2})\)

\(= \frac{1}{\Gamma(\nu/2)} \left( \frac{\nu \sigma^2}{2} \right)^{\nu/2} x^{-\frac{\nu}{2}-1} \exp \left( - \frac{\nu \sigma^2}{2x} \right)\)

正则逆卡方分布，记为 \(\chi^2_\nu(x)\)，是 \(\nu \sigma^2 = 1\)（即 \(\sigma^2 = 1/\nu\)）的特例。这对应于 \(\text{IG}(x|\text{shape} = \nu/2, \text{scale} = \frac{1}{2})\)。

## 2.2.3.5 帕累托分布

帕累托分布具有以下 pdf：

\(\text{Pareto}(x|m, \kappa) = \kappa m^\kappa \frac{1}{x^{(\kappa+1)}} \mathbb{I}(x \ge m)\)

请参见图 2.4(a) 查看一些图表。我们可以看到 \(x\) 必须大于最小值 \(m\)，但之后 pdf 会迅速衰减。如果在对数-对数尺度上绘制该分布，它会形成直线 \(\log p(x) = -a \log x + \log(c)\)，其中 \(a = (\kappa + 1)\) 且 \(c = \kappa m^\kappa\)：请参见图 2.4(b) 以示说明。

当 \(m = 0\) 时，分布形式为 \(p(x) = \kappa x^{-a}\)。这被称为幂律。如果 \(a = 1\)，分布形式为 \(p(x) \propto 1/x\)；如果将 \(x\) 解释为频率，则这称为 1/f 函数。

帕累托分布适用于建模表现出重尾或长尾的量的分布，其中大多数值较小，但存在少数非常大的值。许多形式的数据都表现出这一特性。([ACL16] 认为这是因为许多数据集由各种潜在因素生成，当混合在一起时，自然会导致重尾分布。) 我们在下面给出一些示例。

### 财富分布建模

帕累托分布以意大利经济学家和社会学家维尔弗雷多·帕累托的名字命名。他创建它是为了建模不同国家之间的财富分布。确实，在经济学中，参数 $\kappa$ 称为 **帕累托指数**。如果我们设置 $\kappa = 1.16$，我们就得到了 **80-20 法则**，该法则指出社会中 80% 的财富由 20% 的人口持有。$^2$

### 齐夫定律

**齐夫定律** 认为，语言中出现频率最高的单词（如“the”）出现的频率大约是第二高频单词（“of”）的两倍，而后者又是第四高频单词的两倍，以此类推。这对应于以下形式的帕累托分布：

```
$p(x = r) \propto \kappa r^{-a}$ (2.47)
```

其中 r 是按频率排序时单词 x 的排名，\(\kappa\) 和 \(a\) 是常数。如果我们设置 \(a = 1\)，我们就得到了齐夫定律。\(^3\) 因此，齐夫定律预测，如果我们绘制单词对数频率与其对数排名的图，将得到斜率为 -1 的直线。事实上，如图 2.5 所示，这是正确的。\(^4\) 请参见 [Ada00] 了解齐夫定律的进一步讨论，并参见第 2.6.2 节了解语言模型的讨论。

2. 实际上，财富分布比这更加偏斜。例如，截至 2014 年，80 名亿万富翁拥有的财富与 35 亿人一样多！（来源：http://www.pbs.org/newshour/making-sense/wealthiest-getting-wealthier-lobbying-lot。）这种极端的收入不平等存在于许多寡头国家，包括美国（参见例如 [HP10]）。

3. 例如，\(p(x=2) = \kappa 2^{-1} = 2\kappa 4^{-1} = 2p(x=4)\)。

## 2.2.4 [0, 1] 上的连续分布

在本节中，我们讨论一些定义在 [0, 1] 区间上的单变量分布。

### 2.2.4.1 贝塔分布

贝塔分布在区间 [0, 1] 上有支持，定义如下：

```
Beta(x|a, b) = \frac{1}{B(a, b)} x^{a-1} (1-x)^{b-1}
```

其中 \(B(a, b)\) 是贝塔函数。我们要求 \(a, b > 0\) 以确保分布可积（即确保 \(B(a, b)\) 存在）。如果 \(a = b = 1\)，我们得到均匀分布。如果 \(a\) 和 \(b\) 都小于 1，我们得到一个在 0 和 1 处带有“尖峰”的双峰分布；如果 \(a\) 和 \(b\) 都大于 1，分布是单峰的。请参见图 2.3b。

## 2.2.5 多变量连续分布

在本节中，我们总结一些其他广泛使用的多变量连续分布。

### 2.2.5.1 多变量正态分布（高斯分布）

多变量正态分布（MVN），也称为多变量高斯分布，是目前最广泛使用的多变量分布。因此，第 2.3 节全部内容都专门讨论它。

### 2.2.5.2 多变量 Student 分布

高斯分布的一个问题是它们对异常值敏感。幸运的是，我们可以轻松地将在主章节 2.2.2.3 中讨论的 Student 分布扩展到 \(D\) 维。特别是，多变量 Student 分布的 pdf 由以下给出：

```
\mathcal{T}_\nu(x|\mu, \Sigma) = \frac{1}{Z} \left[ 1 + \frac{1}{\nu} (x-\mu)^T \Sigma^{-1} (x-\mu) \right]^{-\left(\frac{\nu+D}{2}\right)}
```

```
Z = \frac{\Gamma(\nu/2)}{\Gamma(\nu/2 + D/2)} \frac{\nu^{D/2}\pi^{D/2}}{|\Sigma|^{-1/2}}
```

其中 \(\Sigma\) 称为尺度矩阵。
