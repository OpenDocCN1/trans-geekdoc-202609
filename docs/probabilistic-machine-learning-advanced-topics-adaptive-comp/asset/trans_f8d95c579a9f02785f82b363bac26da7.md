

其中 \(\Delta\) 是相邻离散测量时间之间的步长，\(\boldsymbol{q}_t \sim \mathcal{N}(\mathbf{0}, \mathbf{Q})\) 是过程噪声，噪声协方差矩阵 \(\mathbf{Q}\) 由

```
\(\mathbf{Q} = \begin{pmatrix} \frac{q_1 \Delta^3}{3} & 0 & \frac{q_1 \Delta^2}{2} & 0 \\ 0 & \frac{q_2 \Delta^3}{3} & 0 & \frac{q_2 \Delta^2}{2} \\ \frac{q_1 \Delta^2}{2} & 0 & q_1 \Delta & 0 \\ 0 & \frac{q_2 \Delta^2}{2} & 0 & q_2 \Delta \end{pmatrix}\)
```

给出，其中 \(q_i\) 是维度 \(i\) 上白噪声过程的扩散系数（详情见 [SS19, p44]）。

现在假设在每个离散时间点，我们都会观测到受高斯噪声损坏的位置。因此观测模型变为

```
\(\underbrace{\begin{pmatrix} y_{1,t} \\ y_{2,t} \end{pmatrix}}_{\boldsymbol{y}_t} = \underbrace{\begin{pmatrix} 1 & 0 & 0 & 0 \\ 0 & 0 & 1 & 0 \end{pmatrix}}_{\mathbf{H}} \underbrace{\begin{pmatrix} u_t \\ \dot{u}_t \\ v_t \\ \dot{v}_t \end{pmatrix}}_{\boldsymbol{z}_t} + \boldsymbol{r}_t \tag{29.82}\)
```

其中 \(\boldsymbol{r}_t \sim \mathcal{N}(\mathbf{0}, \mathbf{R})\) 是 **观测噪声**。我们可以看到，观测矩阵 \(\mathbf{H}\) 只是“提取”状态向量的相关部分。假设我们从此模型中采样一条带噪声的观测轨迹，\(\boldsymbol{z}_{1:T}, \boldsymbol{y}_{1:T} \sim p(\boldsymbol{z}, \boldsymbol{y} | \boldsymbol{\theta})\)。（我们使用对角观测噪声，\(\mathbf{R} = \text{diag}(\sigma_1^2, \sigma_2^2)\)。）结果如图 29.23(a) 所示。我们可以使用卡尔曼滤波器（第 8.2.2 节）为每个 \(t\) 计算 \(p(\boldsymbol{z}_t | \boldsymbol{y}_{1:t}, \boldsymbol{\theta})\)。（我们用模糊先验初始化滤波器，即 \(p(\boldsymbol{z}_0) = \mathcal{N}(\boldsymbol{z}_0 | \mathbf{0}, 10^5 \mathbf{I})\)。）结果如图 29.23(b) 所示。我们看到后验均值（红线）接近真值，但存在相当大的不确定性（由置信椭圆表示）。为了改进结果，我们可以使用卡尔曼平滑器（第 8.2.3 节）计算 \(p(\boldsymbol{z}_t | \boldsymbol{y}_{1:T}, \boldsymbol{\theta})\)，其中我们对过去和未来的所有数据进行条件化。结果如图 29.23(c) 所示。现在我们看到得到的估计更加平滑，不确定性降低。（边缘处的不确定性较大，因为用于条件化的邻居信息较少。）

## 29.7.2 在线贝叶斯线性回归（递归最小二乘）

在第 15.2.2 节中，我们讨论如何以批量模式为线性回归模型计算 \(p(\boldsymbol{w} | \sigma^2, \mathcal{D})\)，使用形式为 \(p(\boldsymbol{w}) = \mathcal{N}(\boldsymbol{w} | \boldsymbol{\mu}, \boldsymbol{\Sigma})\) 的高斯先验。在本节中，我们讨论如何通过重复执行以下更新在线计算此后验：
\(p(\boldsymbol{w} | \mathcal{D}_{1:t}) \propto p(\mathcal{D}_t | \boldsymbol{w}) p(\boldsymbol{w} | \mathcal{D}_{1:t-1}) \tag{29.83}\)
\(\propto p(\mathcal{D}_t | \boldsymbol{w}) p(\mathcal{D}_{t-1} | \boldsymbol{w}) \dots p(\mathcal{D}_1 | \boldsymbol{w}) p(\boldsymbol{w}) \tag{29.84}\)

其中 \(\mathcal{D}_t = (\boldsymbol{u}_t, y_t)\) 是第 \(t\) 个带标签的样本，\(\mathcal{D}_{1:t-1}\) 是前 \(t-1\) 个样本。（为了简洁，我们省略了对 \(\sigma^2\) 的条件化。）我们看到，先前的后验 \(p(\boldsymbol{w} | \mathcal{D}_{1:t-1})\) 成为当前先验，并被 \(\mathcal{D}_t\) 更新为新的后验 \(p(\boldsymbol{w} | \mathcal{D}_{1:t})\)。这是序列贝叶斯更新或在线贝叶斯推断的一个例子。在线性回归的情况下，此过程称为 **递归最小二乘** 或 **RLS** 算法。

我们可以通过使用线性高斯状态空间模型（第 29.6 节）来实现此方法。基本思想是让隐藏状态表示回归参数，并让（时间变化的）观测模型 \(\mathbf{H}_t\) 表示当前特征向量 \(\mathbf{x}_t\)。也就是说，观测模型的形式为

```
\(p(y_t|\mathbf{w}_t) = \mathcal{N}(y_t|\mathbf{H}_t\mathbf{z}_t, \mathbf{R}_t) = \mathcal{N}(y_t|\mathbf{x}_t^\mathsf{T}\mathbf{w}_t, \sigma^2)\) (29.85)
```

如果假设回归参数不变，则动态模型变为

```
\(p(\mathbf{w}_t|\mathbf{w}_{t-1}) = \mathcal{N}(\mathbf{w}_t|\mathbf{w}_{t-1}, 0) = \delta(\mathbf{w}_t - \mathbf{w}_{t-1})\) (29.86)
```

（如果我们确实让参数随时间变化，则会得到所谓的 **动态线性模型** [Har90; WH97; PPC09]。）有关模型，请参见图 29.24a；有关将卡尔曼滤波器方程应用于此特殊情况时的简化，请参见补充部分 8.1.2。

我们在图 29.24b 中展示了一个 1d 示例。我们看到，在线推断在单次遍历数据后即收敛到精确的批量（离线）后验。

如果我们将卡尔曼增益矩阵近似为 \(\mathbf{K}_t \approx \eta_t\mathbf{1}\)，则会得到 **最小均方** 或 **LMS** 算法，其中 \(\eta_t\) 是学习率。在 LMS 中，我们需要调整学习率以确保收敛到 MLE。此外，该算法可能需要多次遍历数据才能收敛到该全局最优解。相比之下，RLS 算法会自动进行步长调整，并在单次遍历数据后收敛到最优后验。

在第 8.6.3 节中，我们将此方法扩展以执行逻辑回归的在线参数估计，并在第 17.5.2 节中将此方法扩展以执行 MLP 的在线参数估计。

## 29.7.3 自适应滤波

考虑一个 \(D\) 阶自回归模型：

```
\(y_t = w_1 y_{t-1} + \cdots + w_D y_{t-D} + \epsilon_t\) (29.87)
```

其中 \(\epsilon_t \sim \mathcal{N}(0, 1)\)。**自适应滤波**的问题是在给定观测 \(\mathbf{y}_{1:t}\) 的情况下估计参数 \(\mathbf{w}_{1:D}\)。

我们可以将其表述为 LG-SSM 中的推断，通过定义观测矩阵为 \(\mathbf{H}_t = (y_{t-1} \dots y_{t-D})\) 并将状态定义为 \(\mathbf{z}_t = \mathbf{w}\)。我们也可以允许参数随时间演变，类似于第 29.7.2 节。

## 29.7.4 时间序列预测

在第 29.12 节中，我们讨论如何使用 LDS 模型进行时间序列预测。

很诱人地认为我们只需将输入 \(\mathbf{u}_t\) 设置为协变量 \(\mathbf{x}_t\)。不幸的是，这行不通，因为输入的效果是以与隐藏状态（参数）无关的方式给输出添加一个偏置项。也就是说，由于我们有 \(\mathbf{y}_t = \mathbf{H}_t\mathbf{z}_t + \mathbf{D}_t\mathbf{u}_t + \mathbf{d} + \mathbf{r}_t\)，如果我们设置 \(\mathbf{u}_t = \mathbf{x}_t\)，则特征将由常数 LDS 参数 \(\mathbf{D}_t\) 相乘，而不是由包含回归权重的隐藏状态 \(\mathbf{z}_t\) 相乘。
