
### 18.5.4.3 小批量 SVI

计算第 18.5.4.1 节中的最优变分解需要求解批量优化问题，耗时 $O(M^3 + NM^2)$。如果 $N$ 很大，除非 $M$ 很小（这会牺牲精度），否则这可能仍然太慢。

另一种方法是对 VFE 目标进行随机优化，而不是批量优化。这被称为随机变分推断（参见第 10.1.4 节）。关键观察是，方程 (18.147) 中的对数似然是 $N$ 项之和，我们可以通过小批量采样来近似，以计算梯度的噪声估计，如 [HFL13] 所提。

更具体地说，目标变为

\[\mathcal{L}(q) = \left[ \frac{N}{B} \sum_{b=1}^B \frac{1}{|\mathcal{B}_b|} \sum_{n \in \mathcal{B}_b} \mathbb{E}_{q(f_n)} [\log p(y_n | f_n)] \right] - D_{\text{KL}} (q(\mathbf{f}_Z) \| p(\mathbf{f}_Z))\]

其中 $\mathcal{B}_b$ 是第 $b$ 个批次，$B$ 是批次数量。由于 GP 模型（带高斯似然）属于指数族，我们可以高效计算方程 (18.159) 关于 $q(\mathbf{f}_Z)$ 标准参数的自然梯度（参见第 6.4 节）；与遵循标准梯度相比，这收敛快得多。详情请参见 [HFL13]。

## 18.5.5 利用核矩阵乘法挖掘并行性和结构

计算 $\mathbf{K}_{X,X}$ 的 Cholesky 分解需要 $O(N^3)$ 时间，这对于求解线性系统 $\mathbf{K}_\sigma \boldsymbol{\alpha} = \mathbf{y}$ 以及计算 $|\mathbf{K}_{X,X}|$ 是必需的。Cholesky 分解的替代方法是使用线性代数方法，这些方法通常仅基于 **矩阵向量乘法** 或 **MVM**，常被称为 **克雷洛夫子空间方法**。这些方法通常快得多。

简而言之，如果核矩阵 $\mathbf{K}_{X,X}$ 具有特殊的代数结构（这通常取决于所选的核或输入的结构），那么利用该结构进行快速矩阵乘法通常更容易。此外，即使核矩阵 **不** 具有特殊结构，矩阵乘法也很容易并行化，因此可以由 GPU 大幅加速，而基于 Cholesky 的方法则主要是串行的。基于矩阵乘法的算法与现代硬件进步相协调，后者能够实现显著的并行化。

### 18.5.5.1 使用共轭梯度和 Lanczos 方法

我们可以使用共轭梯度（CG）来求解线性系统 $\mathbf{K}_\sigma \boldsymbol{\alpha} = \mathbf{y}$。CG 中的关键计算步骤是执行 MVM 的能力。设 $\tau(\mathbf{K}_\sigma)$ 为与 $\mathbf{K}_\sigma$ 进行一次 MVM 的时间复杂度。对于稠密的 $n \times n$ 矩阵，有 $\tau(\mathbf{K}_\sigma) = n^2$；然而，如果 $\mathbf{K}_\sigma$ 是稀疏或结构化的，我们可以加速此过程，如下文所述。

即使 $\mathbf{K}_\sigma$ 是稠密的，我们仍然可以通过近似求解线性系统来节省时间。具体来说，如果执行 $C$ 次迭代，CG 将耗时 $O(C\tau(\mathbf{K}_\sigma))$。如果运行 $C=n$ 次，且 $\tau(\mathbf{K}_\sigma) = n^2$，则在 $O(n^3)$ 时间内得到精确解。然而，通常我们可以使用较少的迭代次数并仍然获得良好的精度，这取决于 $\mathbf{K}_\sigma$ 的条件数。

我们可以使用 MVM 原语和一种称为 **随机 Lanczos 四分法** 的类似迭代方法来计算矩阵的对数行列式 [UCS17; Don+17a]。对于 $L$ 次迭代，这将耗时 $O(L\tau(\mathbf{K}_\sigma))$。

### 18.5.5.2 具有紧支持的核

假设我们使用具有 **紧支持** 的核，其中如果 ∥**x**−**x**<sup>′</sup>∥ > ϵ（对于某个阈值 ϵ，参见 [MR09] 等），则 K(**x**, **x**<sup>′</sup>) = 0，那么 K<sub>σ</sub> 将是稀疏的，因此 τ(K<sub>σ</sub>) 将为 O(N)。我们还可以通过其他方式诱导稀疏性和结构，如第 18.5.5.3 节所述。

### 18.5.5.3 KISS

确保 MVM 快速的一种方法是强制核矩阵具有结构。[WN15] 的 **结构化核插值 (SKI)** 方法如下执行此操作。首先假设我们有一组诱导点，带有 Gram 矩阵 **K**<sub>Z,Z</sub>。然后它使用这些值来插值并预测完整核矩阵的条目：

\[\mathbf{K}_{X,X} \approx \mathbf{W}_{\mathbf{X}}\mathbf{K}_{Z,Z}\mathbf{W}_{\mathbf{X}}^{\top}\]

其中 $\mathbf{W}_{\mathbf{X}}$ 是包含插值权重的稀疏矩阵。如果使用三次插值，每行只有 4 个非零元素。因此，对于任何向量 $\mathbf{v}$，我们可以在 $O(N + M^2)$ 时间内计算 $(\mathbf{W}_{\mathbf{X}}\mathbf{K}_{Z,Z}\mathbf{W}_{\mathbf{X}}^{\mathsf{T}})\mathbf{v}$。请注意，**SKI** 方法概括了所有诱导点方法。例如，通过将插值权重设置为 $\mathbf{W} = \mathbf{K}_{X,Z}\mathbf{K}_{Z,Z}^{-1}$，我们可以恢复回归子集 (SOR) 方法。我们可以将此过程识别为在用户指定的核上执行全局高斯过程插值策略。有关更多详细信息，请参见 [WN15] 和 [WDN15]。

在一维中，我们可以通过选择规则网格上的诱导点来进一步减少运行时间，从而使 $\mathbf{K}_{Z,Z}$ 成为 Toeplitz 矩阵。在高维中，我们需要使用多维点网格，导致 $\mathbf{K}_{Z,Z}$ 成为 Toeplitz 矩阵的 Kronecker 积。这使得矩阵向量乘法在 $O(N + M \log M)$ 时间和 $O(N + M)$ 空间内完成。所得方法称为 **KISS-GP** [WN15]，代表“可扩展结构化 GP 的核插值”。

遗憾的是，在利用 $\mathbf{K}_{Z,Z}$ 中的 Kronecker 结构时，KISS 方法在输入维度 $D$ 上可能需要指数时间，因为需要创建完全连接的多维格点。在 [Gar+18b] 中，他们提出了一种称为 **SKIP** 的方法，代表 "SKI for products"。其思路是利用许多核（包括 ARD）可以写成一维核的乘积这一事实：$\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = \prod_{d=1}^D \mathcal{K}^d(\boldsymbol{x}, \boldsymbol{x}')$。这可以与一维 SKI 方法相结合，以实现快速 MVM。使用 $C$ 次 CG 迭代和秩为 $L$ 的 Lanczos 分解来计算对数边际似然（这是核学习的瓶颈）的总运行时间变为 $O(DL(N + M \log M) + L^3 N \log D + C L^2 N)$。典型值为 $L \sim 10^4$ 和 $C \sim 10^2$。

### 18.5.5.4 张量列车方法

考虑第 18.5.4 节中的高斯 VFE 方法。我们需要估计协方差 $\mathbf{S}$ 和均值 $\mathbf{m}$。我们可以使用 Kronecker 结构高效地表示 $\mathbf{S}$，就像 KISS 所做的那样。此外，我们可以使用 **张量列车分解** [Ose11] 结合 **SKI** [WN15] 来高效地表示 $\mathbf{m}$。所得的 **TT-GP** 方法可以有效地扩展到数十亿个诱导点，如 [INK18] 所述。

## 18.5.6 将 GP 转换为 SSM

考虑定义在一维标量输入（如时间索引）上的函数。对于许多平稳的一维核，相应的 GP 可以使用线性时不变（LTI）随机微分方程（SDE）[^3] 进行建模；该 SDE 随后可以转换为线性-高斯状态空间模型（第 29.1 节），这最早由 [HS10] 提出。例如，考虑方程 (18.14) 中的指数核，$\mathcal{K}(t, t') = \frac{q}{2\lambda} \exp(-\lambda|t - t'|)$，它对应于 $\nu = 1/2$ 的 Matérn 核。相应的 SDE 是 Ornstein-Uhlenbeck 过程，形式为 $\frac{dx(t)}{dt} = -\lambda x(t) + w(t)$，其中 $w(t)$ 是谱密度为 $q$ 的白噪声过程 [SS19, p258]。[^4]
