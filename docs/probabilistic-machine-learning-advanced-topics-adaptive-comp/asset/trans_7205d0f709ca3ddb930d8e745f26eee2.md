### 17.5.1 适用于 DNN 的序列拉普拉斯方法

在 [RBB18b] 中，他们将第 17.3.2 节的拉普拉斯方法扩展到序列设置中。具体来说，设 \(p(\theta|\mathcal{D}_{1:t-1}) \approx \mathcal{N}(\theta|\mu_{t-1}, \Lambda_{t-1}^{-1})\) 为前一步的近似后验；我们假设精度矩阵是克罗内克分解的。我们现在通过求解 MAP 问题来计算新的均值

```
\(\mu_t = \text{argmax} \log p(\mathcal{D}_t|\theta) + \log p(\theta|\mathcal{D}_{t-1})\) (17.38)
```

```
\(= \text{argmax} \log p(\mathcal{D}_t|\theta) - \frac{1}{2}(\theta - \mu_{t-1})\Lambda_{t-1}^{-1}(\theta - \mu_{t-1})\) (17.39)
```

一旦我们计算了 \(\mu_t\)，我们就在该点计算近似海森矩阵，并得到新的后验精度

```
\(\Lambda_t = \lambda \mathbf{H}(\mu_t) + \Lambda_{t-1}\) (17.40)
```

其中 \(\lambda \ge 0\) 是一个权重因子，用于权衡模型对新数据与旧数据的关注程度。

现在假设我们对后验精度矩阵使用对角近似。从公式 (17.39) 我们可以看到，这相当于在每个新的 MAP 估计中添加一个二次惩罚，以鼓励其保持接近以前任务的参数。这种方法称为 **弹性权重巩固 (EWC)** [Kir+17]。

### 17.5.2 适用于 DNN 的扩展卡尔曼滤波

在第 29.7.2 节中，我们展示了如何使用卡尔曼滤波来增量计算已知方差的线性回归模型权重的精确后验，即，我们计算 \(p(\boldsymbol{\theta}|\mathcal{D}_{1:t}, \sigma^2)\)，其中 \(\mathcal{D}_{1:t} = \{(\boldsymbol{u}_i, y_i) : i = 1 : t\}\) 是迄今看到的数据，且

```
\(p(y_t|\boldsymbol{u}_t, \boldsymbol{\theta}, \sigma^2) = \mathcal{N}(y_t|\boldsymbol{\theta}^\mathsf{T}\boldsymbol{u}_t, \sigma^2)\) (17.41)
```

是线性回归似然。

现在考虑非线性回归的情况：

```
\(p(y_t|\boldsymbol{u}_t, \boldsymbol{\theta}, \sigma^2) = \mathcal{N}(y_t|f(\boldsymbol{\theta}, \boldsymbol{u}_t), \sigma^2)\) (17.42)
```

其中 \(f(\boldsymbol{\theta}, \boldsymbol{u}_t)\) 是某个非线性函数，例如 MLP。我们可以使用扩展卡尔曼滤波器（第 8.3.2 节）来近似计算 \(p(\boldsymbol{\theta}_t|\mathcal{D}_{1:t}, \sigma^2)\)，其中 \(\boldsymbol{\theta}_t\) 是隐藏状态（例如，参见 [SW89; PF03]）。为此，请注意，我们可以将动态模型设置为恒等函数，\(f(\boldsymbol{\theta}_t) = \boldsymbol{\theta}_t\)，因此参数保持不变地传播，并将观测模型设置为输入相关函数 \(f(\boldsymbol{\theta}_t) = f(\boldsymbol{\theta}_t, \boldsymbol{u}_t)\)。我们将观测噪声设置为 \(\mathbf{R}_t = \sigma^2\)，并将动态噪声设置为 \(\mathbf{Q}_t = q\mathbf{I}\)，其中 \(q\) 是一个小常数，以允许参数根据人工 **过程噪声** 缓慢漂移。（在实践中，将 \(q\) 从较大的初始值退火到接近 0 的值可能很有用。）

### 17.5.2.1 示例

我们现在给出此过程的实际示例。我们从真实函数中采样一个合成数据集：

```
\(h^*(u) = x - 10 \cos(u) \sin(u) + u^3\) (17.43)
```

并添加 \(\sigma = 3\) 的高斯噪声。然后我们使用具有一个隐藏层（含 \(H\) 个隐藏单元）的 MLP 来拟合此数据，因此模型形式为

```
\(f(\boldsymbol{\theta}, \boldsymbol{u}) = \mathbf{W}_2 \tanh(\mathbf{W}_1 \boldsymbol{u} + \boldsymbol{b}_1) + \boldsymbol{b}_2\) (17.44)
```

其中 \(\mathbf{W}_1 \in \mathbb{R}^{H \times 1}, \boldsymbol{b}_1 \in \mathbb{R}^H, \mathbf{W}_2 \in \mathbb{R}^{1 \times H}, \boldsymbol{b}_2 \in \mathbb{R}\)。我们设置 \(H = 6\)，因此总共有 \(D = 19\) 个参数。

给定数据后，我们按顺序计算后验，从模糊的高斯先验开始，\(p(\boldsymbol{\theta}) = \mathcal{N}(\boldsymbol{\theta}|\mathbf{0}, \unknown_0)\)，其中 \(\unknown_0 = 100\mathbf{I}\)。（在实践中，我们不能从先验均值开始，即 \(\boldsymbol{\theta}_0 = \mathbf{0}\)，因为围绕该点线性化模型会导致零梯度，因此我们为 \(\boldsymbol{\theta}_0\) 使用一个初始随机样本。）结果如图 17.16 所示。我们可以看到，模型适应数据，而无需指定任何学习率。此外，我们看到预测变得越来越自信，因为后验集中在 MLE 上。

### 17.5.2.2 设置方差项

在上述示例中，我们手动设置方差项。一般来说，我们需要估计噪声方差 \(\sigma\)，它决定 \(\mathbf{R}_t\) 从而决定学习率，以及先验 \(\unknown_0\) 的强度，它控制正则化的程度。[FNG00] 中讨论了对此的一些方法。

### 17.5.2.3 降低计算复杂度

上述朴素 EKF 方法耗时 \(O(N_z^3)\)，对于大型神经网络而言禁止性高。一种名为 **解耦 EKF** 的简单近似方法在 [PF91; SPD92] 中被提出（综述见 [PF03]）。该方法将权重划分为 \(G\) 个组或块，并独立估计每个组 \(g\) 的相关矩阵。若 \(G=1\)，则退化为标准全局 EKF。若将每个权重放入其自身的组，则得到完全对角近似。在实践中，这并不比 SGD 更好，因为它忽略了参数之间的相关性。一个有用的折中方法是将每个神经元对应的所有权重放入其自身的组；这称为 **节点解耦 EKF**，已用于 [Sim02] 训练 RBF 网络和 [GUK21] 训练指数族矩阵分解模型（广泛用于推荐系统）。关于 DEKF 的更多细节，请参见补充部分 17.1。

提高计算效率的另一种方法是利用这样一个事实：DNN 的有效维度通常相当低（参见第 17.4.3 节）。实际上，我们可以通过使用低维系数向量来近似模型参数，该向量指定对应于权重空间的线性流形中的点；定义此线性流形的基集可以随机选择 [Li+18b; GARD18; Lar+22]，也可以通过对 SGD 迭代应用 PCA 来估计 [Izm+19]。我们可以利用这一观察结果在此低维子空间中执行 EKF，从而显著加快推断速度，如 [DMKM22] 中所讨论。

### 17.5.3 适用于 DNN 的假设密度滤波

在第 8.6.3 节中，我们讨论了如何使用假设密度滤波（ADF）来执行在线（二元）逻辑回归。在本节中，我们将其推广到非线性预测模型，例如 DNN。关键是对模型每一层的隐藏激活进行高斯矩匹配。这为第 17.5.2 节中的 EKF 方法提供了一种替代方案，后者基于网络的线性化。

我们将假设以下似然：

p(\boldsymbol{y}_t | \boldsymbol{u}_t, \boldsymbol{w}_t) = \text{Expfam}(\boldsymbol{y}_t | \ell^{-1}(f(\boldsymbol{u}_t; \boldsymbol{w}_t)))

其中 \( f(\boldsymbol{x}; \boldsymbol{w}) \) 是 DNN，\( \ell^{-1} \) 是逆链接函数，且 Expfam() 是某个指数族分布。例如，如果 \( f \) 是线性的且我们正在求解二元分类问题，我们可以写成

p(y_t | \boldsymbol{u}_t, \boldsymbol{w}_t) = \text{Ber}(y_t | \sigma(\boldsymbol{u}_t^T \boldsymbol{w}_t))

我们在第 8.6.3 节中讨论了使用 ADF 拟合此模型。

在 [HLA15b] 中，他们提出了 **概率反向传播 (PBP)**，这是应用于 MLP 的 ADF 的一个实例。基本思想是使用完全分解分布来近似每一层权重上的后验

p(\boldsymbol{w}_t | \mathcal{D}_{1:t}) \approx p_t(\boldsymbol{w}_t) = \prod_{l=1}^L \prod_{i=1}^{D_l} \prod_{j=1}^{D_{l-1}+1} \mathcal{N}(w_{ijl} | \mu_{ijl}^t, \tau_{ijl}^t)

其中 \( L \) 是层数，\( D_l \) 是第 \( l \) 层的神经元数量。（[SHM14] 的 **期望反向传播** 算法是此的特例，其中方差固定为 \( \tau = 1 \）。）
