# 20.3.4 Structure discovery

Some kinds of generative models have latent variables z, which are assumed to be the “causes” that generated the observed data x. We can use Bayes’ rule to invert the model to compute p(z|x) ∝ p(z)p(x|z). This can be useful for discovering latent, low-dimensional patterns in the data. For example, suppose we perturb various proteins in a cell and measure the resulting phosphorylation state using a technique known as flow cytometry, as in [Sac+05].
