

我们假设 $\mathbf{K} = \mathbf{K}_x + \mathbf{K}_{y|x}$ 是可逆的（尽管先验或似然单独可能是奇异的）。
$\mathbf{G} = [\mathbf{g}_1^\mathsf{T}; \dots ; \mathbf{g}_K^\mathsf{T}]$ 的 $K$ 行和 $\mathbf{H} = [\mathbf{h}_1^\mathsf{T}; \dots ; \mathbf{h}_M^\mathsf{T}]$ 的 $M$ 行可以组合成 $\mathbf{F} = [\mathbf{f}_1^\mathsf{T}; \dots ; \mathbf{f}_L^\mathsf{T}]$ 的 $L$ 行，这些行定义了系统的线性约束。
如果假设 $\mathbf{\Sigma}_p$ 和 $\mathbf{\Sigma}_n$ 是对角阵，则图形模型的结构由 $\mathbf{F}$ 的稀疏性唯一确定。
所得后验分解为 $L$ 个高斯“专家”的乘积：

```
$p(\mathbf{x}|\mathbf{y}) \propto \prod_{l=1}^L \exp(-\frac{1}{2}\mathbf{x}^\mathsf{T}\mathbf{K}_l\mathbf{x} + \mathbf{h}_l^\mathsf{T}\mathbf{x}) \propto \prod_{l=1}^L \mathcal{N}(\mathbf{f}_l^\mathsf{T}\mathbf{x}; \boldsymbol{\mu}_l, \boldsymbol{\Sigma}_l)$ (9.101)
```

其中 $\boldsymbol{\Sigma}_l$ 在 $l = 1 : K$ 时等于 $\mathbf{\Sigma}_{p,t,l}$，在 $l = K + 1 : L$ 时等于 $\mathbf{\Sigma}_{n,v,l'}$（此时 $l' = l - K$）。类似地，$\boldsymbol{\mu}_l$ 在 $l = 1 : K$ 时等于 $\boldsymbol{\mu}_{p,t}$，在 $l = K + 1 : L$ 时等于 $(y_{l'} - c_{l'})$。

要应用扰动和 MAP，我们按如下步骤进行。首先通过采样 $\tilde{\boldsymbol{\mu}}_p \sim \mathcal{N}(\boldsymbol{\mu}_p, \mathbf{\Sigma}_p)$ 扰动先验均值，并通过采样 $\tilde{\mathbf{y}} \sim \mathcal{N}(\mathbf{y}, \mathbf{\Sigma}_n)$ 扰动测量值。（注意，这等价于先扰动每个信息形式势中的线性项，使用 $\tilde{\mathbf{h}}_l = \mathbf{h}_l + \mathbf{f}_l \mathbf{\Sigma}_l^{-\frac{1}{2}} \boldsymbol{\epsilon}_l$，其中 $\boldsymbol{\epsilon}_l \sim \mathcal{N}(0,1)$。）然后使用扰动后的参数计算 $\mathbf{x}$ 的 MAP 估计：

```
$\tilde{\mathbf{x}} = \mathbf{K}^{-1}\mathbf{G}^\mathsf{T}\mathbf{\Sigma}_p^{-1} \tilde{\boldsymbol{\mu}}_p + \mathbf{K}^{-1}\mathbf{H}^\mathsf{T}\mathbf{\Sigma}_n^{-1}(\tilde{\mathbf{y}} - \mathbf{c})$ (9.102)
$= \mathbf{K}^{-1}\mathbf{G}^\mathsf{T}\mathbf{\Sigma}_p^{-1}(\boldsymbol{\mu}_p + \boldsymbol{\epsilon}_{\mu}) + \mathbf{K}^{-1}\mathbf{H}^\mathsf{T}\mathbf{\Sigma}_n^{-1}(\mathbf{y} + \boldsymbol{\epsilon}_y - \mathbf{c})$ (9.103)
$= \boldsymbol{\mu} + \mathbf{A}\boldsymbol{\epsilon}_{\mu} + \mathbf{B}\boldsymbol{\epsilon}_y$ (9.104)
```

可以看出 $\mathbb{E}[\tilde{\mathbf{x}}] = \boldsymbol{\mu}$ 且 $\mathbb{E}[(\tilde{\mathbf{x}} - \boldsymbol{\mu})(\tilde{\mathbf{x}} - \boldsymbol{\mu})^\mathsf{T}] = \mathbf{K}^{-1} = \mathbf{\Sigma}$，因此该方法生成精确样本。

该方法非常可扩展，因为稀疏 GMRF（即后验均值）的 MAP 估计可以使用共轭梯度求解器高效计算。或者，我们可以使用环形信念传播（第 9.4 节），它通常可以计算精确的后验均值（参见，例如，[WF01a; JMW06; Bic09; Du+18]）。

### 9.7.2.2 离散情况

在 [PY11; PY14] 中，他们将扰动-MAP 扩展到离散图形模型的情况。此设置更复杂，且需要使用 Gumbel 噪声，可通过 $\epsilon = -\log(-\log(u))$ 进行采样，其中 $u \sim \text{Unif}(0,1)$。这种噪声应添加到模型中的所有势函数，但作为简单的近似，它可以仅添加到一元项，即局部证据势。给定输入 $\mathbf{c}$ 时，配置 $\mathbf{x}$ 的得分（或未归一化对数概率）为

```
$S(\mathbf{x}; \mathbf{c}) = \log p(\mathbf{x}|\mathbf{c}) + \text{const} = \sum_i \log \phi_i(x_i) + \sum_{ij} \log \psi_{ij}(x_{i,j})$ (9.105)
```

这里为了记号简洁，假设为成对 CRF。如果通过向每个条目添加 $\epsilon_{ik}$ 来扰动局部证据势 $\phi_i(k)$，其中 $k$ 索引离散隐态，则得到 $\tilde{S}(\mathbf{x}; \mathbf{c})$。然后通过求解 $\tilde{\mathbf{x}} = \text{argmax } \tilde{S}(\mathbf{x}; \mathbf{c})$ 计算样本 $\tilde{\mathbf{x}}$。这种方法的优点在于可以利用离散模型的高效 MAP 求解器，如补充部分第 9.3 节中讨论的那些。这反过来可用于参数学习和配分函数估计 [HJ12; Erm+13]。

## 10 变分推断

### 10.1 引言

在本章中，我们讨论 **变分推断**，它将后验推断归结为优化问题。
需要注意的是，VI 是一个大主题；本章仅给出高层概述。有关更多细节，参见，例如，[Jor+98; JJ00; Jaa01; WJ08; SQ05; TLG08; Zha+19b; Bro18]。

### 10.1.1 变分目标

考虑一个带有未知（隐含）变量 \(\boldsymbol{z}\)、已知变量 \(\boldsymbol{x}\) 和固定参数 \(\boldsymbol{\theta}\) 的模型。（如果参数未知，它们可以被加入到 \(\boldsymbol{z}\) 中，稍后我们会讨论。）我们假设先验是 \(p_\theta(\boldsymbol{z})\)，似然是 \(p_\theta(\mathbf{x}|\boldsymbol{z})\)，因此未归一化联合分布是 \(p_\theta(\mathbf{x}, \boldsymbol{z}) = p_\theta(\mathbf{x}|\boldsymbol{z})p_\theta(\boldsymbol{z})\)，后验是 \(p_\theta(\boldsymbol{z}|\mathbf{x}) = p_\theta(\mathbf{x}, \boldsymbol{z})/p_\theta(\mathbf{x})\)。我们假设计算归一化常数 \(p_\theta(\mathbf{x}) = \int p_\theta(\mathbf{x}, \boldsymbol{z})d\boldsymbol{z}\) 是不可处理的，因此计算归一化后验也是不可处理的。因此，我们寻求后验的一个近似，记为 \(q(\boldsymbol{z})\)，以最小化以下损失：

```
\(q = \underset{q \in \mathcal{Q}}{\text{argmin}} D_{KL}(q(\boldsymbol{z}) \| p_\theta(\boldsymbol{z}|\boldsymbol{x}))\)
```

由于我们是在对函数（即分布 \(q\)）进行最小化，这被称为 **变分方法**。
在实践中，我们选择一个参数族 \(\mathcal{Q}\)，其中使用 \(\boldsymbol{\psi}\)，即 **变分参数**，来指定我们使用的是家族中的哪个成员。我们可以按如下方式计算最佳变分参数（给定 \(\mathbf{x}\) 时）：

```
\(\begin{aligned}
\boldsymbol{\psi}^* &= \underset{\boldsymbol{\psi}}{\text{argmin}} D_{KL}(q_\psi(\boldsymbol{z}) \| p_\theta(\boldsymbol{z}|\boldsymbol{x})) \\
&= \underset{\boldsymbol{\psi}}{\text{argmin}} \mathbb{E}_{q_\psi(\boldsymbol{z})} \left[ \log q_\psi(\boldsymbol{z}) - \log \left( \frac{p_\theta(\mathbf{x}|\boldsymbol{z})p_\theta(\mathbf{z})}{p_\theta(\mathbf{x})} \right) \right] \\
&= \underset{\boldsymbol{\psi}}{\text{argmin}} \underbrace{\mathbb{E}_{q_\psi(\boldsymbol{z})}[\log q_\psi(\boldsymbol{z}) - \log p_\theta(\mathbf{x}|\boldsymbol{z}) - \log p_\theta(\boldsymbol{z})]}_{\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\boldsymbol{x})} + \log p_\theta(\mathbf{x})
\end{aligned}\)
```

最后一项 \(\log p_\theta(\mathbf{x}) = \log(\int p_\theta(\mathbf{x}, \boldsymbol{z})d\boldsymbol{z})\) 通常不可处理。幸运的是，它与 \(\boldsymbol{\psi}\) 无关，因此可以丢弃。这样就只剩下第一项，我们将其写作如下：

```
\(\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) = \mathbb{E}_{q_\psi(\mathbf{z})} [-\log p_\theta(\mathbf{x}, \mathbf{z}) + \log q_\psi(\mathbf{z})]\)
```

图 10.1：变分推断示意图。大椭圆表示变分分布集 $\mathcal{Q} = \{q_\psi(\mathbf{z}) : \psi \in \mathcal{O}\}$，其中 $\mathcal{O}$ 是可能的变分参数集。真实分布是点 $p(\mathbf{z}|\mathbf{x})$，我们假设它位于集合之外。我们的目标是在变分家族中找到对 $p$ 的最佳近似，即 KL 散度中最接近的点 $\psi^*$。我们通过从随机初始点 $\psi^{\text{init}}$ 开始优化程序来找到该点。改编自 David Blei 的图表。

最小化该目标将最小化 KL 散度，使我们的近似逼近真实后验。请参见图 10.1 了解示意图。在下面的章节中，我们给出了该目标函数的两种不同解释。

### 10.1.1.1 物理学视角：最小化变分自由能

如果定义 $\mathcal{E}_\theta(\mathbf{z}) = -\log p_\theta(\mathbf{z}, \mathbf{x})$ 为能量，那么我们可以将公式 (10.5) 中的损失重写为

```
$\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) = \mathbb{E}_{q_\psi(\mathbf{z})}[\mathcal{E}_\theta(\mathbf{z})] - \mathbb{H}(q_\psi) = \text{expected energy - entropy}$ (10.6)
```

在物理学中，这被称为 **变分自由能**（VFE）。它是 **自由能**（FE）$-\log p_\theta(\mathbf{x})$ 的一个上界，这源于以下事实

```
$D_{\text{KL}}(q_\psi(\mathbf{z}) || p_\theta(\mathbf{z}|\mathbf{x})) = \mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) + \log p_\theta(\mathbf{x}) \ge 0$ (10.7)
```

```
$\underbrace{\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x})}_{\text{VFE}} \ge \underbrace{-\log p_\theta(\mathbf{x})}_{\text{FE}}$ (10.8)
```

变分推断等价于最小化 VFE。如果达到 $-\log p_\theta(\mathbf{x})$ 的最小值，则 KL 散度项将为 0，因此我们的近似后验将是精确的。

### 10.1.1.2 统计学视角：最大化证据下界 (ELBO)

VFE 的负值称为 **证据下界** 或 **ELBO** 函数 [BKM16]：

```
$\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) \triangleq \mathbb{E}_{q_\psi(\mathbf{z})}[\log p_\theta(\mathbf{x}, \mathbf{z}) - \log q_\psi(\mathbf{z})] = \text{ELBO}$ (10.9)
```

名称“ELBO”之所以产生，是因为

```
$\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) \le \log p_\theta(\mathbf{x})$ (10.10)
```

其中 $\log p_\theta(\mathbf{x})$ 称为“证据”。不等式源于公式 (10.8)。因此，关于 $\psi$ 最大化 ELBO 将最小化原始 KL，因为 $\log p_\theta(\mathbf{x})$ 关于 $\psi$ 是常数。
