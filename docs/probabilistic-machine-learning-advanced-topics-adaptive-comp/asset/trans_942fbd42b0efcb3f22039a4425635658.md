### 6.6.4.3 多保真度代理模型

在某些情况下，我们可以构建不同精度级别的代理函数，每个函数可能需要不同的计算时间。特别是，设 \( f(\boldsymbol{x}, s) \) 为在 \( \boldsymbol{x} \ 处保真度为 \( s \) 的真函数近似。目标是通过观察一系列 \( (\boldsymbol{x}_i, s_i) \) 值处的 \( f(\boldsymbol{x}, s) \) 来求解 \( \max_{\boldsymbol{x}} f(\boldsymbol{x}, 0) \)，使得总成本 \( \sum_{i=1}^n c(s_i) \) 低于某个预算。例如，在超参数选择的背景下，\( s \) 可能控制我们运行参数优化器的时间长短，或者验证集的大小。

除了为实验选择使用何种保真度外，如果更便宜的代理结果表明不值得运行至完成，我们也可以选择提前终止昂贵的试验（查询）（参见，例如，[Str19; Li+17c; FKH17]）。或者，我们可以选择恢复早先中止的运行，以收集更多关于它的数据，如 **冻结-解冻算法** [SSA14] 所示。

### 6.6.4.4 约束

如果我们希望在已知约束条件下最大化一个函数，可以简单地将约束构建到采集函数中。但如果约束未知，除了估计函数外，还需要估计可行集的支撑集。在 [GSA14] 中，他们提出了加权 EI 准则，给出为 \( \alpha_{wEI}(\boldsymbol{x}; \mathcal{D}_n) = \alpha_{EI}(\boldsymbol{x}; \mathcal{D}_n) h(\boldsymbol{x}; \mathcal{D}_n) \)，其中 \( h(\boldsymbol{x}; \mathcal{D}_n) \) 是一个带有伯努利观测模型的高斯过程，用于指定 \( \boldsymbol{x} \) 是否可行。当然，其他方法也是可能的。例如，[HL+16b] 提出了一种基于预测熵搜索的方法。

## 6.7 无导数优化

**无导数优化** 或 **DFO** 是指一类不使用导数来优化函数的技术。这对于黑箱函数优化以及离散优化都很有用。如果函数求值代价高昂，我们可以使用贝叶斯优化（第 6.6 节）。如果函数求值代价低廉，我们可以使用随机局部搜索方法或进化搜索方法，如下文所述。

### 6.7.1 局部搜索

在本节中，我们讨论启发式优化算法，这些算法试图在离散、无结构的搜索空间中找到全局最大值。这些算法将局部梯度基更新（形式为 \( \boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t + \eta_t \boldsymbol{d}_t \)）替换为以下离散类似式：

```
\(\boldsymbol{x}_{t+1} = \underset{\boldsymbol{x} \in \text{nbr}(\boldsymbol{x}_t)}{\text{argmax}} \mathcal{L}(\boldsymbol{x})\)
```

其中 nbr($\boldsymbol{x}_t$) \(\subseteq \mathcal{X}\) 是 \(\boldsymbol{x}_t\) 的 **邻居** 集合。这称为 **爬山法**、**最陡上升法** 或 **贪心搜索**。
如果一点的“邻域”包含整个空间，方程 (6.187) 将在一步内返回全局最优解，但通常这样的全局邻域太大，无法穷举搜索。因此，我们通常定义局部邻域。例如，考虑 **八皇后问题**。这里的目标是在 \(8 \times 8\) 棋盘上放置皇后，使它们互不攻击（参见图 6.14）。状态空间的形式为 \(\mathcal{X} = 64^8\)，因为我们需要指定棋盘上每个皇后的位置。但是，由于约束条件，只有 \(8^8 \approx 17\)M 个可行状态。我们将一个状态的邻居定义为将单个皇后移动到同一列的另一格子所生成的所有可能状态，因此每个节点有 \(8 \times 7 = 56\) 个邻居。根据 [RN10, p.123]，如果从随机生成的八皇后状态开始，最陡上升法有 86% 的时间会陷入局部最大值，因此只能解决 14% 的问题实例。但是，它很快，成功时平均需要 4 步，陷入困境时平均需要 3 步。

在下面的章节中，我们讨论稍微聪明一些、不太容易陷入局部最大值的算法。

### 6.7.1.1 随机局部搜索

爬山法是贪心的，因为它通过精确求解方程 (6.187) 来选择其局部邻域中最好的点。减少在每一步陷入局部最大值机会的一种方法是近似最大化此目标。例如，我们可以定义一个上坡邻居上的概率分布，与它们改进的程度成正比，然后随机采样一个。这称为 **随机爬山法**。如果我们逐渐降低这个概率分布的熵（因此随着时间的推移变得更加贪心），我们会得到一种称为模拟退火的方法，我们将在第 12.9.1 节中讨论。

另一种简单的技术是使用贪心爬山法，但每当达到局部最大值时，就从另一个随机起始点重新开始。这称为 **随机重启爬山法**。要看到这种方法的好处，请再次考虑八皇后问题。如果每次爬山搜索成功的概率为 \(p \approx 0.14\)，那么我们预计需要 \(R = 1/p \approx 7\) 次重启才能找到有效解。平均总步数可以按如下计算。设 \(N_1 = 4\) 为成功试验的平均步数，\(N_0 = 3\) 为失败试验的平均步数。那么平均总步数为 \(N_1 + (R - 1)N_0 = 4 + 6 \times 3 = 22\)。由于每一步都很快，整体方法非常快。例如，它可以在一分钟内求解 \(n = 1\)M 的 \(n\) 皇后问题。

当然，求解 \(n\) 皇后问题并不是实践中最有用的任务。然而，它是几个现实世界 **布尔可满足性问题** 的典型例子，这些问题出现在从 AI 规划到模型检查的各种问题中（参见，例如，[SLM92]）。在这些问题中，我们讨论过的简单 **随机局部搜索（SLS）** 算法效果出奇地好（参见，例如，[HS05]）。

### 6.7.1.2 禁忌搜索

爬山法一旦达到局部最大值或平坦区就会停止。显然可以执行随机重启，但这将忽略到目前为止获得的所有信息。一种更智能的替代方法称为 **禁忌搜索** [GL97]。这类似于爬山法，但它允许移动到降低（或至少不增加）评分函数的状态，前提是移动到之前未见过的新状态。我们可以通过维护一个禁忌列表来强制执行此操作，该列表跟踪最近访问的 \(\tau\) 个状态。这迫使算法探索新状态，并增加从局部最大值中逃脱的机会。我们继续这样做最多 \(c_{max}\) 步（称为“禁忌任期”）。伪代码可见算法 6.6。（如果设置 \(c_{max} = 1\)，则得到贪心爬山法。）

```
Algorithm 6.6: Tabu search.
t := 0 // counts iterations
c := 0 // counts number of steps with no progress
Initialize x0
x* := x0 // current best incumbent
while c < cmax do
    x_{t+1} = argmax_{x \in nbr(x_t) \\ {x_{t-r},...,x_{t-1}}} f(x)
    if f(x_{t+1}) > f(x*) then
        x* := x_{t+1}
        c := 0
    else
        c := c + 1
    t := t + 1
return x*
```

例如，考虑禁忌搜索到达山顶 \(x_t\) 时会发生什么。下一步，它将移动到峰值的一个邻居 \(x_{t+1} \in \text{nbr}(x_t)\)，该邻居得分较低。下一步，它将移动到前一步的邻居 \(x_{t+2} \in \text{nbr}(x_{t+1})\)；禁忌列表阻止它循环返回 \(x_t\)（峰值），因此它将被迫选择同等高度或更低的邻近点。它以这种方式继续，“绕圈”峰值，可能被迫下山到较低水平集（逆盆地淹没操作），直到找到通向新峰值的山脊，或者直到超过最大非改进移动次数。

根据 [RN10, p.123]，禁忌搜索将可解决的八皇后问题百分比从 14% 提高到 94%，尽管此变体每个成功实例平均需要 21 步，每个失败实例平均需要 64 步。
