

此仿射变换的雅可比矩阵为 \(\frac{\partial z}{\partial \epsilon} = \mathbf{L}\)。由于 \(\mathbf{L}\) 是三角矩阵，其行列式等于主对角线元素的乘积，因此

\(\log \left| \det \frac{\partial z}{\partial \epsilon} \right| = \sum_{k=1}^K \log |L_{kk}|\) (10.53)

我们可以使用下式计算 \(\mathbf{L}\)：

\(\mathbf{L} = \mathbf{M} \odot \mathbf{L}' + \text{diag}(\boldsymbol{\sigma})\) (10.54)

其中 \(\mathbf{M}\) 是一个掩码矩阵，对角线及其上方为 0，对角线下方为 1，而 \((\boldsymbol{\mu}, \log \boldsymbol{\sigma}, \mathbf{L}')\) 由推理网络预测。通过此构造，\(\mathbf{L}\) 的对角线元素由 \(\boldsymbol{\sigma}\) 给出，因此

\(\log \left| \det \frac{\partial z}{\partial \epsilon} \right| = \sum_{k=1}^K \log |L_{kk}| = \sum_{k=1}^K \log \sigma_k\) (10.55)

### 10.2.1.3 低积加对角协方差的高斯分布

在高维情况下，使用 Cholesky 分解的一种高效替代方案是因子分解

\(\boldsymbol{\Sigma} = \mathbf{B}\mathbf{B}^\top + \mathbf{C}^2\) (10.56)

其中 \(\mathbf{B}\) 是大小为 \(d \times f\) 的因子载荷矩阵，\(f \ll d\) 是因子的数量，\(d\) 是 \(\mathbf{z}\) 的维度，且 \(\mathbf{C} = \text{diag}(c_1, \dots, c_d)\)。这使得变分参数的总数从 \(d + d(d+1)/2\) 减少到 \((f+2)d\)。在 [ONS18] 中，他们称这种方法为 **VAFC**（带因子协方差的变分近似的缩写）。

在 \(f=1\) 的特殊情况下，协方差矩阵变为

\(\boldsymbol{\Sigma} = \mathbf{b}\mathbf{b}^\top + \text{diag}(\mathbf{c}^2)\) (10.57)

在这种情况下，可以在 \(O(d)\) 时间内以闭式计算 ELBO 的自然梯度（第 6.4 节），如 [Tra+20b; TND21] 所示，他们称这种方法为 **NAGVAC-1**（自然梯度高斯变分近似）。这相比于遵循普通梯度，可以实现更快的收敛。

在第 10.1.2 节中，我们表明这种低积近似远优于对角近似。更多示例请参见补充材料第 10.1 节。

### 10.2.1.5 示例：贝叶斯参数推断

在本节中，我们使用可重参数化 SVI 来推断高斯混合模型（GMM）参数的后验。我们将离散潜变量边缘化掉，因此只需要近似全局潜变量 \(p(\boldsymbol{\theta}|\mathcal{D})\) 的后验。由于我们已将所有局部潜变量边缘化掉，这有时被称为“坍缩”模型。也就是说，我们将图 10.5b 中的模型转换为图 10.5a 中的模型。我们选择一个与似然共轭的分解（均匀场）变分后验，且该后验也是可重参数化的。这使我们能够使用 SGD 拟合后验。

为简单起见，我们假设每个高斯混合分量都有对角协方差矩阵。因此，一个数据点 \(\boldsymbol{x} \in \mathbb{R}^D\) 的似然为

```
\(p(\boldsymbol{x}|\boldsymbol{\theta}) = \sum_{k=1}^K \pi_k \mathcal{N}(\boldsymbol{x}|\boldsymbol{\mu}_k, \text{diag}(\boldsymbol{\lambda}_k)^{-1})\)
```

其中 \(\boldsymbol{\mu}_k = (\mu_{k1}, \dots, \mu_{kD})\) 是均值，\(\boldsymbol{\lambda}_k = (\lambda_{k1}, \dots, \lambda_{kD})\) 是精度，\(\boldsymbol{\pi} = (\pi_1, \dots, \pi_K)\) 是混合权重。我们为这些参数使用以下先验：

```
\(p_{\boldsymbol{\xi}}(\boldsymbol{\theta}) = \left[ \prod_{k=1}^K \prod_{d=1}^D \mathcal{N}(\mu_{kd}|0,1)\text{Ga}(\lambda_{kd}|5,5) \right] \text{Dir}(\boldsymbol{\pi}|\mathbf{1})\)
```

其中 \(\boldsymbol{\xi}\) 是超参数。我们假设以下均匀场后验：

```
\(q_{\boldsymbol{\psi}}(\boldsymbol{\theta}) = \left[ \prod_{k=1}^K \prod_{d=1}^D \mathcal{N}(\mu_{kd}|m_{kd}, s_{kd})\text{Ga}(\lambda_{kd}|\alpha_{kd}, \beta_{kd}) \right] \text{Dir}(\boldsymbol{\pi}|\boldsymbol{c})\)
```

其中 \(\boldsymbol{\psi} = (\boldsymbol{m}_{1:K,1:D}, \boldsymbol{s}_{1:K,1:D}, \boldsymbol{\alpha}_{1:K,1:D}, \boldsymbol{\beta}_{1:K,1:D}, \boldsymbol{c})\) 是 \(\boldsymbol{\theta}\) 的变分参数。

我们可以使用以下公式计算 ELBO：

```
\(\text{L}(\boldsymbol{\xi}, \boldsymbol{\psi}|\mathcal{D}) = \mathbb{E}_{q_{\boldsymbol{\psi}}(\boldsymbol{\theta})} [\log p(\mathcal{D}|\boldsymbol{\theta}) + \log p_{\boldsymbol{\xi}}(\boldsymbol{\theta}) - \log q_{\boldsymbol{\psi}}(\boldsymbol{\theta})]\)
```

由于分布是可重参数化的，我们可以将梯度推入此表达式内部。我们可以通过绘制单个后验样本来近似期望，并可以使用小批量近似对数似然。然后，我们可以使用算法 10.2 中的伪代码更新变分参数，（以及可选的先验超参数，如我们在第 10.1.3.2 节中讨论的那样）。

```
Algorithm 10.2: Reparameterized SVI for Bayesian parameter inference
1 Initialize \(\boldsymbol{\psi}, \boldsymbol{\xi}\)
2 repeat
3   Sample minibatch \(\mathcal{B} = \{\boldsymbol{x}_b \sim \mathcal{D} : b = 1 : B\}\)
4   Sample \(\boldsymbol{\epsilon} \sim q_0\)
5   Compute \(\tilde{\boldsymbol{\theta}} = g(\boldsymbol{\psi}, \boldsymbol{\epsilon})\)
6   Compute \(\mathcal{L}(\boldsymbol{\psi}|\mathcal{D}, \tilde{\boldsymbol{\theta}}) = -\frac{N}{B} \sum_{\boldsymbol{x}_n \in \mathcal{B}} \log p(\boldsymbol{x}_n|\tilde{\boldsymbol{\theta}}) - \log p_{\boldsymbol{\xi}}(\tilde{\boldsymbol{\theta}}) + \log q_{\boldsymbol{\psi}}(\tilde{\boldsymbol{\theta}})\)
7   Update \(\boldsymbol{\xi} := \boldsymbol{\xi} - \eta \nabla_{\boldsymbol{\xi}} \mathcal{L}(\boldsymbol{\xi}, \boldsymbol{\psi}|\mathcal{D}, \tilde{\boldsymbol{\theta}})\)
8   Update \(\boldsymbol{\psi} := \boldsymbol{\psi} - \eta \nabla_{\boldsymbol{\psi}} \mathcal{L}(\boldsymbol{\xi}, \boldsymbol{\psi}|\mathcal{D}, \tilde{\boldsymbol{\theta}})\)
9 until converged
```

图 10.6 给出了此方法的实际示例。我们从 2D 中的 3 个高斯分布混合物生成数据集，使用 \(\boldsymbol{\mu}_1^* = [2, 0]\)、\(\boldsymbol{\mu}_2^* = [-2, -4]\)、\(\boldsymbol{\mu}_3^* = [-2, 4]\)，精度 \(\lambda_{dk}^* = 1\)，以及均匀混合权重 \(\boldsymbol{\pi}^* = [1/3, 1/3, 1/3]\)。图 10.6a 显示了包含 3000 个点的训练集。我们使用 SVI 进行拟合，批大小为 500，迭代 1000 个时代，使用 Adam 优化器。图 10.6b 显示拟合模型的预测。更准确地说，它显示 \(p(\boldsymbol{x}|\overline{\boldsymbol{\theta}})\)，其中 \(\overline{\boldsymbol{\theta}} = \mathbb{E}_{q(\boldsymbol{\theta}|\boldsymbol{\psi})}[\boldsymbol{\theta}]\)。图 10.6c 显示基于 \(q(\boldsymbol{\mu}_1|\boldsymbol{\psi})\) 中 10,000 个样本的核密度估计。我们看到后验均值为 \(\mathbb{E}[\boldsymbol{\mu}_1] \approx [-2, -4]\)。由于标签切换不可辨识性，我们发现这与 \(\boldsymbol{\mu}_2^*\) 而非 \(\boldsymbol{\mu}_1^*\) 匹配。

### 10.2.1.6 示例：LVMs 的 MLE

在本节中，我们考虑使用可重参数化 SVI 来计算具有连续潜变量的潜变量模型（LVM）的 MLE，例如变分自编码器（第 21.2 节）。与第 10.2.1.5 节不同，我们无法解析地边缘化掉局部潜变量。相反，我们将使用分摊推断，如第 10.1.5 节所示，这意味着我们学习一个推理网络（参数为 \(\phi\)），根据输入 \(x_n\) 预测局部变分参数 \(\psi_n\)。如果在每次迭代中从数据集中采样单个样本 \(x_n\)，并从变分后验中采样单个潜变量 \(z_n\)，则得到算法 10.3 中的伪代码。

```
Algorithm 10.3: Reparameterized amortized SVI for MLE of an LVM
1 Initialize \(\theta, \phi\)
2 repeat
3   Sample \(x_n \sim p_\mathcal{D}\)
4   Sample \(\epsilon_n \sim q_0\)
5   Compute \(z_n = g(\phi, x_n, \epsilon_n)\)
6   Compute \(\mathcal{L}(\theta, \phi | x_n, z_n) = - \log p_\theta(x_n, z_n) + \log q_\phi(z_n | x_n)\)
7   Update \(\theta := \theta - \eta \nabla_\theta \mathcal{L}(\phi, \theta | x_n, z_n)\)
8   Update \(\phi := \phi - \eta \nabla_\phi \mathcal{L}(\phi, \theta | x_n, z_n)\)
9 until converged
```

## 10.2.2 自动微分变分推断

要应用高斯 VI，我们需要将受约束参数（如方差项）转换为无约束形式，使它们位于 \(\mathbb{R}^D\)。这种技术可用于任何可以定义到 \(\mathbb{R}^D\) 双射的分布。这种方法称为 **自动微分变分推断** 或 **ADVI** [Kuc+16]。下面给出详细信息。

### 10.2.2.1 基本思想

我们的目标是近似后验 \(p(\theta|\mathcal{D}) \propto p(\theta)p(\mathcal{D}|\theta)\)，其中 \(\theta \in \Theta\) 位于某个 \(D\) 维受约束参数空间。设 \(T : \Theta \to \mathbb{R}^D\) 是将受约束空间 \(\Theta\) 映射到无约束空间 \(\mathbb{R}^D\) 的双射映射，其逆映射为 \(T^{-1} : \mathbb{R}^D \to \Theta\)。设 \(u = T(\theta)\) 为无约束潜变量。我们将对 \(u\) 的后验使用高斯变分近似，即 \(q_\psi(u) = \mathcal{N}(u|\mu, \Sigma)\)，其中 \(\psi = (\mu, \Sigma)\)。

根据变量变换公式（公式 2.257），我们有

```
\(p(u) = p(T^{-1}(u)) |\det(\mathbf{J}_{T^{-1}}(u))|\) \\
(10.62)
```

其中 \(\mathbf{J}_{T^{-1}}\) 是逆映射 \(u \to \theta\) 的雅可比矩阵。因此 ELBO 变为

```
\(\mathbf{L}(\psi) = E_{u \sim q_\psi(u)} [ \log p(\mathcal{D}|T^{-1}(u)) + \log p(T^{-1}(u)) + \log | \det( \mathbf{J}_{T^{-1}}(u) ) | ] + \mathbb{H}(\psi)\) \\
(10.63)
```

这是一个可处理的目标，假设雅可比矩阵可处理，因为最终的熵项有闭式解，并且我们可以对 \(u\) 的期望使用蒙特卡洛近似。
