## 19.3.1 使用双样本检验检测偏移

假设我们从源分布和目标分布中收集一组样本。然后我们可以使用双样本检验的标准技术来估计原假设 p(x,y) = q(x,y) 是否成立。（如果我们有无标签样本，我们只需检验 p(x) = q(x)。）例如，我们可以使用 MMD（第 2.7.3 节）来测量输入样本集之间的距离（参见 [Liu+20a]）。或者我们可以测量在源分布上训练的分类器的嵌入空间中的（欧氏）距离（参见 [KM22]）。

在某些情况下，可能只需检验标签分布 p(y) 是否发生变化，这比检验输入分布 p(x) 的变化更容易。特别是，如果标签偏移假设（第 19.2.3.3 节）成立（即 q(x|y) = p(x|y)），再加上其他一些假设，那么我们可以使用第 19.5.4 节中的黑盒偏移估计技术来估计 q(y)。如果发现 q(y) = p(y)，则可以得出 q(x,y) = p(x,y) 的结论。在 [RGL19] 中，他们通过实验表明，即使标签偏移假设不成立，该方法在检测分布偏移方面也效果良好。

也可以使用合形预测（第 14.3 节）来开发“分布无关”的方法来检测协变偏移，前提是只能访问校准集和某些一致性评分函数 [HL20]。

## 19.3.2 检测单个分布外（OOD）输入

现在假设我们只有一个来自目标分布的无标签样本 x ~ q，我们想知道 x 是分布内（ID）还是分布外（OOD）。我们将此问题称为分布外检测，尽管它也被称为异常检测和新奇检测。

OOD 检测问题需要对测试样本是 ID 还是 OOD 做出二元决策。如果是 ID，我们可以可选地要求返回其类标签，如图 19.6 所示。在下面的章节中，我们简要概述了为解决此问题提出的技术，但有关更多详细信息，请参见 [Pan+21; Ruf+21; Bul+20; Yan+21; Sal+21; Hen+19b]。

### 19.3.2.1 有监督 ID/OOD 方法（异常值暴露）

OOD 检测最简单的方法假设我们在训练时可以访问带标签的 ID 和 OOD 样本。然后我们只需拟合一个二元分类器来区分 OOD 或背景类（称为“已知未知”）与 ID 类（称为“已知已知”）。这种技术称为异常值暴露（参见 [HMD19; Thu+21; Bit+21]）且效果不错。然而，在大多数情况下，我们不会有足够多的 OOD 分布示例，因为 OOD 集基本上是除了我们感兴趣的输入之外的所有可能输入的集合。

2. 异常值检测任务与异常或 OOD 检测有些不同，尽管名称相似。在异常值检测文献中，假设只有一个无标签数据集，目标是识别与大多数样本相比“非典型”的样本。这常用于数据清洗。（请注意，这是一种转导式学习任务，模型在相同的数据上进行训练和评估。我们专注于归纳式任务，即在一个数据集上训练模型，然后在另一个数据集上测试。）

### 19.3.2.2 分类置信度方法

与其试图解决二元 ID/OOD 分类问题，我们可以直接尝试预测输入的类。设 C 个标签上的概率为 \(p_c = p(y=c|\boldsymbol{x})\)，logits 为 \(\ell_c = \log p_c\)。我们可以从这些量中以多种方式推导出 **置信度得分** 或 **不确定性度量**，例如，最大概率 \(s = \max_c p_c\)、边际 \(s = \max_c \ell_c - \max_c^2 \ell_c\)（其中 \(\max^2\) 表示第二大元素）、熵 \(s = \mathbb{H}(\boldsymbol{p}_{1:C})\)、**"能量得分"** \(s = \sum_c \ell_c\) [Liu+21b] 等。在 [Mil+21; Vaz+22] 中，他们表明简单的最大概率基线在实践中表现非常好。

### 19.3.2.3 合形预测

可以使用合形预测（第 14.3 节）来创建具有可证明界定风险的 OOD 检测和 ID 分类方法。详情见 [Ang+21]，但我们在此概述基本思路。

我们希望解决图 19.6 中所示的两阶段决策问题。我们定义预测集如下：

```
\(\mathcal{T}_\lambda(\boldsymbol{x}) = \begin{cases} \emptyset & \text{if OOD}(\boldsymbol{x}) > \lambda_1 \\ \text{APS}(\boldsymbol{x}) & \text{otherwise} \end{cases}\) (19.3)
```

其中 OOD(\(\boldsymbol{x}\)) 是某种启发式 OOD 分数（例如最大类概率），而 APS(\(\boldsymbol{x}\)) 是第 14.3.1 节的自适应预测集方法，它返回顶 K 类标签的集合，使其概率之和超过阈值 \(\lambda_2\)。（正式地，APS(\(\boldsymbol{x}\)) = \(\{\pi_1, \dots, \pi_K\}\)，其中 \(\pi\) 将 \(f(\boldsymbol{x})_{1:C}\) 按降序排序，且 \(K = \min\{K' : \sum_{c=1}^{K'} f(\boldsymbol{x})_c > \lambda_2\}\)。）

3. [Kir+21] 反对使用熵，因为它混淆了关于使用哪个 C 个标签的不确定性与关于任何标签是否合适的不确定性，与“无上述选项”相比。

方法（见 [Ang+21]）。得到的阈值将共同最小化以下风险：

```
R_1(\boldsymbol{\lambda}) = p(\mathcal{T}_{\boldsymbol{\lambda}}(\boldsymbol{x}) = \emptyset)
R_2(\boldsymbol{\lambda}) = p(\boldsymbol{y} \notin \mathcal{T}_{\boldsymbol{\lambda}}(\boldsymbol{x}) | \mathcal{T}_{\boldsymbol{\lambda}}(\boldsymbol{x}) \neq \emptyset)
```

其中 \(p(\boldsymbol{x}, y)\) 是真实但未知的源分布（仅 ID 样本，无需 OOD 样本），\(R_1\) 是 ID 样本被错误拒绝为 OOD 的概率（I 类错误），\(R_2\) 是（在决定分类的条件下）真实标签不在预测集中的概率。目标是将 \(\lambda_1\) 设置得尽可能大（以便在出现 OOD 示例时能够检测到它们），同时控制 I 类错误（例如，我们可能希望确保将不超过 10% 的分布内样本错误地标记为 OOD）。然后我们按照第 14.3.1 节中 APS 方法的常规方式设置 \(\lambda_2\)。

### 19.3.2.4 无监督方法

如果没有带标签的示例，OOD 检测的一种自然方法是将无条件密度模型（如 VAE）拟合到 ID 样本上，然后评估似然 \(p(\boldsymbol{x})\) 并将其与某个阈值进行比较。不幸的是，对于许多类型的深度模型和数据集，我们有时会发现源分布的样本的 \(p(\boldsymbol{x})\) 比新奇目标分布的样本更低。例如，如果我们在 Fashion-MNIST 上训练像素-CNN 模型（第 22.3.2 节）或归一化流模型（第 23 章）并在 MNIST 上进行评估，我们会发现它对 MNIST 样本赋予更高的似然 [Nal+19a; Ren+19; KIW20; ZGR21]。这种现象也出现在其他几种模型和数据集中（参见图 19.7）。

解决此问题的一个方法是使用相对于基准密度模型的 **对数似然比**，\(R(\boldsymbol{x}) = \log p(\boldsymbol{x})/q(\boldsymbol{x})\)，而不是原始对数似然 \(L(\boldsymbol{x}) = \log p(\boldsymbol{x})\)。（这种技术在 [Ren+19] 等其他论文中进行了探讨。）一个重要的优点是该比率对数据的变换具有不变性。要看到这一点，令 \(\boldsymbol{x}' = \boldsymbol{\phi}(\boldsymbol{x})\) 为某些可逆但可能是非线性的变换。根据变量变换法，我们有 \(p(\boldsymbol{x}') = p(\boldsymbol{x}) | \det \text{Jac}(\boldsymbol{\phi}^{-1})(\boldsymbol{x}) |\)。因此 \(L(\boldsymbol{x}')\) 将以取决于变换的方式与 \(L(\boldsymbol{x})\) 不同。相比之下，无论 \(\boldsymbol{\phi}\) 如何，我们都有 \(R(\boldsymbol{x}) = R(\boldsymbol{x}')\)，因为

```
R(\boldsymbol{x}') = \log p(\boldsymbol{x}') - \log q(\boldsymbol{x}') = \log p(\boldsymbol{x}) + \log | \det \text{Jac}(\boldsymbol{\phi}^{-1})(\boldsymbol{x}) | - \log q(\boldsymbol{x}) - \log | \det \text{Jac}(\boldsymbol{\phi}^{-1})(\boldsymbol{x}) |
```
