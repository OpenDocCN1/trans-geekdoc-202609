## 18.8 用于时间序列预测的高斯过程

可以使用高斯过程进行时间序列预测（例如，参见 [Rob+13]）。基本思想是将未知输出建模为时间的函数 f(t)，并将关于 f 形式的先验表示为 GP；然后我们根据观测证据更新该先验，并预测未来。朴素地，这需要 `O(T^3)` 时间。然而，对于某些平稳核，可以将问题重新表述为线性高斯状态空间模型，然后使用卡尔曼平滑器在 `O(T)` 时间内进行推断，如 [SSH13; SS19; Ada+20] 所述。对于 Matérn 核，这种转换可以精确完成；对于高斯 (RBF) 核，则可以近似完成（参见 [SS19, Ch. 12]）。在 [SGF21] 中，他们描述了如何使用并行前缀扫描算子将对 T 的线性依赖降低到 `log(T)` 时间，该算子可以在 GPU 上高效运行（参见第 8.2.3.4 节）。

### 18.8.1 示例：毛纳洛亚

在本节中，我们使用第 29.12.5.1 节中的毛纳洛亚 CO2 数据集。我们在图 18.29(a) 中展示了原始数据。我们可以看到，在长期趋势上叠加了一个年周期（或准周期）信号。按照 [RW06, Sec 5.4.3]，我们将使用核的组合来对其进行建模：

$$\mathcal{K}(r) = \mathcal{K}_1(r) + \mathcal{K}_2(r) + \mathcal{K}_3(r) + \mathcal{K}_4(r)$$ (18.189)

其中，对于第 $i$ 个核，$\mathcal{K}_i(t, t') = \mathcal{K}_i(t - t')$。

为了捕捉长期平滑上升趋势，我们令 $\mathcal{K}_1$ 为平方指数 (SE) 核，其中 $\theta_0$ 是振幅，$\theta_1$ 是长度尺度：

$$\mathcal{K}_1(r) = \theta_0^2 \exp \left( - \frac{r^2}{2 \theta_1^2} \right)$$ (18.190)

为了建模周期性，可以使用来自公式 (18.18) 的周期或 exp-sine-squared 核，周期为 1 年。然而，由于季节趋势是否严格周期性尚不明确，我们将此周期核与另一个 SE 核相乘，以允许远离周期性时的衰减；结果是 $\mathcal{K}_2$，其中 $\theta_2$ 是幅值，$\theta_3$ 是周期分量的衰减时间，$\theta_4 = 1$ 是周期，$\theta_5$ 是周期分量的平滑度。

$$\mathcal{K}_2(r) = \theta_2^2 \exp \left( - \frac{r^2}{2 \theta_3^2} - \theta_5 \sin^2 \left( \frac{\pi r}{\theta_4} \right) \right)$$ (18.191)

为了建模（小的）中期不规则性，我们使用有理二次核（公式 (18.20)）：

$$\mathcal{K}_3(r) = \theta_6^2 \left[ 1 + \frac{r^2}{2 \theta_7^2 \theta_8} \right]^{-\theta_8}$$ (18.192)

其中 $\theta_6$ 是幅值，$\theta_7$ 是典型长度尺度，$\theta_8$ 是形状参数。

独立噪声的幅值可以纳入似然函数的观测噪声中。对于相关噪声，我们使用另一个 SE 核：

$$\mathcal{K}_4(r) = \theta_9^2 \exp \left( - \frac{r^2}{2 \theta_{10}^2} \right)$$ (18.193)

其中 $\theta_9$ 是相关噪声的幅值，$\theta_{10}$ 是长度尺度。（注意，$\mathcal{K}_1$ 和 $\mathcal{K}_4$ 的组合是不可识别的，但这不影响预测。）

我们可以通过优化边缘似然（关于 $\theta$）来拟合此模型（参见第 18.6.1 节）。得到的预测如图 18.29(b) 所示。

## 19 超越 iid 假设

### 19.1 介绍

监督机器学习的标准方法假设训练集和测试集都包含来自同一分布的独立同分布（iid）样本。然而，在许多情况下，测试分布可能与训练分布不同；这称为 **分布漂移**，如第 19.2 节所述。

在某些情况下，我们可能有来自多个相关分布的数据，而不仅仅是训练和测试，如第 19.6 节所述。我们还可能遇到流式数据中的情况，其中数据分布可能在不断变化，或以分段常数的方式变化，如第 19.7 节所述。最后，在第 19.8 节中，我们讨论了测试分布由对手选择以最小化预测系统性能的情况。

### 19.2 分布漂移

假设我们有一个来自 **源分布** p(**x**, y) 的标记训练集，我们用它来拟合预测模型 p(y|**x**)。在测试时，我们会遇到来自 **目标分布** q(**x**, y) 的数据。如果 p != q，我们说发生了 **分布漂移** 或 **数据集偏移** [QC+08; BD+10]。这会对预测模型的性能产生不利影响，如第 19.2.1 节所示。

在第 19.2.2 节中，我们使用因果图模型的语言给出了几种分布漂移的分类法。然后我们讨论了可以采用的各种策略，以缓解分布漂移造成的危害。特别是，在第 19.3 节中，我们讨论了检测漂移的技术，以便在模型不自信时可以放弃给出错误预测。在第 19.4 节中，我们讨论了提高对漂移鲁棒性的技术；特别是，给定来自 p(**x**, y) 的标记数据，我们旨在创建一个逼近 q(y|**x**) 的模型。在第 19.5 节中，我们讨论了在给定来自目标分布的一些标记或未标记数据的情况下，调整模型以适应目标分布的技术。
