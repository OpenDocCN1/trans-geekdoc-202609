

(注意：我们使用符号 \(\mathfrak{L}\) 表示 ELBO，而非 \(\mathcal{L}\)，因为我们想要最大化 \(\mathfrak{L}\) 但最小化 \(\mathcal{L}\)。)

我们可以将 ELBO 重写如下：

\(\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) = \mathbb{E}_{q_\psi(\mathbf{z})} [\log p_\theta(\mathbf{x}, \mathbf{z})] + \mathbb{H}(q_\psi(\mathbf{z}))\quad (10.11)\)

我们可以这样理解：

ELBO = 期望联合对数概率 + 熵 \(\quad (10.12)\)

第二项鼓励后验达到最大熵，而第一项鼓励其成为联合 MAP 配置。

我们还可以将 ELBO 重写为

\(\mathbf{L}(\psi|\boldsymbol{\theta}, \mathbf{x}) = \mathbb{E}_{q_\psi(\mathbf{z})} [\log p_\theta(\mathbf{x}|\mathbf{z}) + \log p_\theta(\mathbf{z}) - \log q_\psi(\mathbf{z})]\quad (10.13)\)
\(= \mathbb{E}_{q_\psi(\mathbf{z})} [\log p_\theta(\mathbf{x}|\mathbf{z})] - D_{KL} (q_\psi(\mathbf{z}) \| p_\theta(\mathbf{z}))\quad (10.14)\)

我们可以这样理解：

ELBO = 期望对数似然 - 从后验到先验的 KL 散度 \(\quad (10.15)\)

KL 项充当正则化器，防止后验偏离先验过多。

## 10.1.2 变分后验的形式

选择变分后验形式有两种主要方法，即 \(q_\psi(\mathbf{z}|\mathbf{x})\)。在第一种方法中，我们选择一个方便的函数形式，例如多元高斯分布，然后使用基于梯度的方法优化 ELBO。这称为**固定形式变分推断**，并在第 10.2 节中讨论。另一种方法是做**均匀场**假设，即后验分解为：

\(q_\psi(\mathbf{z}) = \prod_{j=1}^J q_j(\mathbf{z}_j)\quad (10.16)\)

其中 \(q_j(\mathbf{z}_j) = q_{\psi_j}(\mathbf{z}_j)\) 是第 \(j\) 组变量的后验。我们不需要为每个 \(q_j\) 指定函数形式。相反，最优分布形式可以通过一次针对每一组变分参数最大化 ELBO（以坐标上升的方式）来推导。因此，这称为**自由形式变分推断**，并在第 10.3 节中讨论。

我们现在给出一个将变分推断应用于 2d 隐性向量 \(\mathbf{z}\)（表示高斯分布的均值）的简单示例。先验为 \(\mathcal{N}(\mathbf{z}|\tilde{\mathbf{m}}, \tilde{\mathbf{V}})\)，似然为

\(p(\mathcal{D}|\mathbf{z}) = \prod_{n=1}^N \mathcal{N}(\mathbf{x}_n|\mathbf{z}, \boldsymbol{\Sigma}) \propto \mathcal{N}(\overline{\mathbf{x}}|\mathbf{z}, \frac{1}{N}\boldsymbol{\Sigma})\quad (10.17)\)

精确后验 \(p(\mathbf{z}|\mathcal{D}) = \mathcal{N}(\mathbf{z}|\widehat{\mathbf{m}}, \widehat{\mathbf{V}})\) 可以解析计算，如第 3.4.4.1 节所述。在图 10.2 中，我们比较了后验的三个高斯变分近似。如果 \(q\) 使用完整协方差矩阵，则它与精确后验匹配；然而，在高维下这是不可处理的。

![](img/ca72c1626f4850f058a9edc138c1ac73_467_0.png)

图 10.2: 高斯先验下 2d 高斯似然均值的精确（高斯）后验的变分近似。我们展示了后验的三个高斯近似，分别使用完整协方差（蓝色）、对角协方差（绿色）和对角加秩一协方差（红色）。由 gaussian_2d_vi.ipynb 生成。

维度。如果 \(q\) 使用对角协方差矩阵（对应均匀场近似），我们会发现近似过度自信，这是变分推断的一个众所周知的缺陷，源于最小化 D_KL(q || p) 的寻模态特性（详情见第 5.1.4.3 节）。最后，如果 \(q\) 使用秩一加对角近似，我们将得到更好的近似；此外，这可以相当高效地计算，如第 10.2.1.3 节所述。

## 10.1.3 使用变分 EM 进行参数估计

到目前为止，我们假设模型参数 \(\theta\) 是已知的。然而，我们可以尝试通过最大化数据集的边缘似然对数来估计它们，\(\mathcal{D} = \{x_n : n = 1 : N\}\)，

```
\(\log p(\mathcal{D}|\theta) = \sum_{n=1}^N \log p(x_n|\theta)\) (10.18)
```

通常，这很难计算，但我们下面将讨论近似方法。

### 10.1.3.1 隐性变量模型的 MLE

假设我们有一个如下形式的隐性变量模型

```
\(p(\mathcal{D}, z_{1:N}|\theta) = \prod_{n=1}^N p(z_n|\theta)p(x_n|z_n, \theta)\) (10.19)
```

如图 10.3a 所示。此外，假设我们想要给定数据集 \(\mathcal{D} = \{x_n : n = 1 : N\}\) 时计算 \(\theta\) 的 MLE。由于局部隐性变量 \(z_n\) 是隐藏的，我们必须将其边缘化以得到局部（每个样本）的边缘似然对数：

```
\(\log p(x_n|\theta) = \log \left[ \int p(x_n|z_n, \theta)p(z_n|\theta)dz_n \right]\) (10.20)
```

![](img/ca72c1626f4850f058a9edc138c1ac73_468_0.png)

图 10.3: 图形模型包含：(a) 局部随机隐性变量 \(z_n\) 和全局确定性隐性参数 \(\theta\)。 (b) 全局随机隐性参数 \(\theta\) 和全局确定性隐性超参数 \(\xi\)。观测变量 \(x_n\) 用阴影圆表示。

不幸的是，计算这个积分通常是不可处理的，因为它对应于精确后验的归一化常数。幸运的是，ELBO 是其下界：

```
$$ \mathbb{L}(\theta, \psi_n | x_n) \le \log p(x_n | \theta) $$ (10.21)
```

我们可以通过最大化来优化模型参数

```
$$ \mathbb{L}(\theta, \psi_{1:N} | \mathcal{D}) \triangleq \sum_{n=1}^N \mathbb{L}(\theta, \psi_n | x_n) \le \log p(\mathcal{D} | \theta) $$ (10.22)
```

这是**变分 EM** 算法的基础。我们将在 6.5.6.1 节中更详细地讨论这一点，但基本思想是在 E 步中交替最大化 ELBO 相对于变分参数 \(\{\psi_n\}\)，以给出 \(q_{\psi_n}(z_n)\)，然后在 M 步中使用新的 \(\psi_n\) 最大化 ELBO 相对于模型参数 \(\theta\)。（我们也可以使用 SGD 和摊销推断来加速此过程，如第 10.1.4 至 10.1.5 节所述。）

### 10.1.3.2 完全观测模型的经验贝叶斯

假设我们有一个完全观测模型（没有局部隐性变量），形式如下

```
$$ p(\mathcal{D}, \theta | \xi) = p(\theta | \xi) \prod_{n=1}^N p(x_n | \theta) $$ (10.23)
```

如图 10.3b 所示。在贝叶斯参数推断的背景下，我们的目标是计算参数后验：

```
$$ p(\theta | \mathcal{D}, \xi) = \frac{p(\mathcal{D} | \theta) p(\theta | \xi)}{p(\mathcal{D} | \xi)} $$ (10.24)
```

其中 \(\theta\) 是全局未知模型参数（隐性变量），\(\xi\) 是先验的超参数。如果超参数未知，我们可以使用经验贝叶斯（见第 3.7 节）通过计算来估计它们

\(\hat{\boldsymbol{\xi}} = \operatorname{argmax}_{\boldsymbol{\xi}} \log p(\mathcal{D}|\boldsymbol{\xi})\)

我们可以使用变分 EM 来计算这一点，类似于第 10.1.3.1 节，只不过现在要估计的参数是 \(\boldsymbol{\xi}\)，隐性变量是共享的全局参数 \(\boldsymbol{\theta}\)，观测值是整个数据集 \(\mathcal{D}\)。我们然后得到下界

\(\log p(\mathcal{D}|\boldsymbol{\xi}) \ge \mathsf{L}(\boldsymbol{\xi}, \boldsymbol{\psi}|\mathcal{D}) = \mathbb{E}_{q_\psi(\boldsymbol{\theta})}\left[\sum_{n=1}^N \log p(\mathbf{x}_n|\boldsymbol{\theta})\right] - D_{\mathrm{KL}}\left(q_\psi(\boldsymbol{\theta}) \| p(\boldsymbol{\theta}|\boldsymbol{\xi})\right)\)

我们相对于变分后验的参数 \(\boldsymbol{\psi}\) 和先验超参数 \(\boldsymbol{\xi}\) 来优化此目标。

如果先验 \(\boldsymbol{\xi}\) 是固定的，我们只需要优化变分参数 \(\boldsymbol{\psi}\) 来计算后验 \(q_\psi(\boldsymbol{\theta}|\mathcal{D})\)。这称为**变分贝叶斯**。更多详情见第 10.3.3 节。

## 10.1.4 随机变分推断

在第 10.1.3 节中，我们看到参数估计需要优化整个数据集的 ELBO，它被定义为每个 \(N\) 个数据样本 \(\mathbf{x}_n\) 的 ELBO 之和。如果 \(N\) 很大，计算这个目标可能会很慢。幸运的是，我们可以用随机近似替换这个目标，它计算更快，并提供无偏估计。具体来说，在每一步中，我们可以从数据集中抽取一个大小为 \(B = |\mathcal{B}|\) 的随机小批量，然后做如下近似

\(\mathsf{L}(\boldsymbol{\theta}, \boldsymbol{\psi}_{1:N}|\mathcal{D}) = \sum_{n=1}^N \mathsf{L}(\boldsymbol{\theta}, \boldsymbol{\psi}_n|\mathbf{x}_n) \approx \frac{N}{B} \sum_{\mathbf{x}_n \in \mathcal{B}} \left[ \mathbb{E}_{q_{\psi_n}(\mathbf{z}_n)} \left[ \log p_\theta(\mathbf{x}_n|\mathbf{z}_n) + \log p_\theta(\mathbf{z}_n) - \log q_{\psi_n}(\mathbf{z}_n) \right] \right]\)

这可以用于随机优化算法，例如 SGD。这称为**随机变分推断**或 **SVI** [Hof+13]，使得 VI 可以扩展到大数据集。

## 10.1.5 摊销变分推断

在第 10.1.4 节中，我们看到在 SVI 的每次迭代中，我们需要为小批量中的每个样本 \(n\) 优化局部变分参数 \(\boldsymbol{\psi}_n\)。这种嵌套优化可能相当缓慢。

一种替代方法是训练一个模型，称为**推理网络**或**识别网络**，以从观测数据 \(\mathbf{x}_n\) 预测 \(\boldsymbol{\psi}_n\)，使用 \(\boldsymbol{\psi}_n = f_\phi^{\text{inf}}(\mathbf{x}_n)\)。这种技术称为**摊销变分推断** [GG14] 或 **推理编译** [LBW17]，因为我们通过训练一个跨所有示例共享的模型来减少每示例时间推断的成本。（另请参见 [Amo22] 关于摊销优化的一般讨论。）为了简洁起见，我们将摊销后验写为

\(q(\mathbf{z}_n|\boldsymbol{\psi}_n) = q(\mathbf{z}_n|f_\phi^{\text{inf}}(\mathbf{x}_n)) = q_\phi(\mathbf{z}_n|\mathbf{x}_n)\)
