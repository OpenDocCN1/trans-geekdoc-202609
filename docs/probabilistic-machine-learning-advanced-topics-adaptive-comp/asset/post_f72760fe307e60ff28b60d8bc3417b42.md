
The corresponding ELBO becomes

\(\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathcal{D}) = \sum_{n=1}^N [\mathbb{E}_{q_\phi(\mathbf{z}_n|\mathbf{x}_n)} [\log p_\theta(\mathbf{x}_n, \mathbf{z}_n) - \log q_\phi(\mathbf{z}|\mathbf{x}_n)]]\)

If we combine this with SVI we get an amortized version of Equation (10.27). For example, if we use a minibatch of size 1, we get

\(\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathbf{x}_n) \approx N [\mathbb{E}_{q_\phi(\mathbf{z}_n|\mathbf{x}_n)} [\log p_\theta(\mathbf{x}_n, \mathbf{z}_n) - \log q_\phi(\mathbf{z}|\mathbf{x}_n)]]\)

We can optimize this as shown in Algorithm 10.1. Note that the (partial) maximization wrt \(\boldsymbol{\theta}\) in the M step is usually done with a gradient update, but the maximization wrt \(\boldsymbol{\phi}\) in the E step is trickier, since the loss uses \(\boldsymbol{\phi}\) to define an expectation operator, so we can't necessarily push the gradient operator inside; we discuss ways to optimize the variational parameters in Section 10.2 and Section 10.3.

| Algorithm 10.1: Amortized stochastic variational EM |
|---|
| 1 Initialize \(\boldsymbol{\theta}, \boldsymbol{\phi}\) |
| 2 repeat |
| 3 Sample \(\mathbf{x}_n \sim p_\mathcal{D}\) |
| 4 E step: \(\boldsymbol{\phi} = \text{argmax}_\boldsymbol{\phi} \mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathbf{x}_n)\) |
| 5 M step: \(\boldsymbol{\theta} = \text{argmax}_\boldsymbol{\theta} \mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathbf{x}_n)\) |
| 6 until converged |

## 10.1.6 Semi-amortized inference

Amortized SVI is widely used for fitting LVMs, e.g., for VAEs (see Section 21.2), for topic models [SS17a], for probabilistic programming [RHG16], for CRFs [TG18], etc. However, the use of an inference network can result in a suboptimal setting of the local variational parameters \(\boldsymbol{\psi}_n\). This is called the **amortization gap** [CLD18]. We can close this gap by using the inference network to warm-start an optimizer for \(\boldsymbol{\psi}_n\); this is known as **semi-amortized VI** [Kim+18c]. (See also [MYM18], who propose a closely related method called **iterative amortized inference**.) An alternative approach is to use the inference network as a proposal distribution. If we combine this with importance sampling, we get the IWAE bound of Section 10.5.1. If we use this with Metropolis-Hastings, we get a VI-MCMC hybrid (see Section 10.4.5).

## 10.2 Gradient-based VI

In this section, we will choose some convenient form for \(q_\psi(\mathbf{z})\), such as a Gaussian for continuous \(\mathbf{z}\), or a product of categoricals for discrete \(\mathbf{z}\), and then optimize the ELBO using gradient based methods.

On the left, we show the standard form of the computation graph. The gradient wrt the generative parameters \(\theta\) is easy to compute, since we can push gradients inside the expectation, and use a single Monte Carlo sample:

```
\(\nabla_\theta \mathbf{L}(\theta, \phi | x) = \nabla_\theta \mathbb{E}_{q_\phi(z|x)} [\log p_\theta(x, z) - \log q_\phi(z|x)]\)
\(= \mathbb{E}_{q_\phi(z|x)} [\nabla_\theta \{ \log p_\theta(x, z) - \log q_\phi(z|x) \}]\)
\(\approx \nabla_\theta \log p_\theta(x, z^s)\)
```

where \(z^s \sim q_\phi(z|x)\). This is an unbiased estimate of the gradient, so can be used with SGD.

The gradient wrt the inference parameters \(\phi\) is harder to compute since

```
\(\nabla_\phi \mathbf{L}(\theta, \phi | x) = \nabla_\phi \mathbb{E}_{q_\phi(z|x)} [\log p_\theta(x, z) - \log q_\phi(z|x)]\)
\(\neq \mathbb{E}_{q_\phi(z|x)} [\nabla_\phi \{ \log p_\theta(x, z) - \log q_\phi(z|x) \}]\)
```

However, we can often use the reparameterization trick, which we discuss in Section 10.2.1. If not, we can use blackbox VI, which we discuss in Section 10.2.3.

### 10.2.1 Reparameterized VI

In this section, we discuss the **reparameterization trick** for taking gradients wrt distributions over continuous latent variables \(z \sim q_\phi(z|x)\). We explain this in detail in Section 6.3.5, but we summarize the basic idea here.

The key trick is to rewrite the random variable \( z \sim q_\phi(z|x) \) as some differentiable (and invertible) transformation \( g \) of another random variable \( \epsilon \sim p(\epsilon) \), which does not depend on \( \phi \), i.e., we assume we can write

\( z = g(\phi, x, \epsilon) \quad (10.36) \)

For example,

\( z \sim \mathcal{N}(\mu, \text{diag}(\sigma)) \Longleftrightarrow z = \mu + \epsilon \odot \sigma, \quad \epsilon \sim \mathcal{N}(\mathbf{0}, \mathbf{I}) \quad (10.37) \)

Using this, we have

\( \mathbb{E}_{q_\phi(z|x)} [f(z)] = \mathbb{E}_{p(\epsilon)} [f(z)] \quad \text{s.t.} \quad z = g(\phi, x, \epsilon) \quad (10.38) \)

where we define

\( f_{\theta, \phi}(z) = \log p_\theta(x, z) - \log q_\phi(z|x) \quad (10.39) \)

Hence

\( \nabla_\phi \mathbb{E}_{q_\phi(z|x)} [f(z)] = \nabla_\phi \mathbb{E}_{p(\epsilon)} [f(z)] = \mathbb{E}_{p(\epsilon)} [\nabla_\phi f(z)] \quad (10.40) \)

which we can approximate with a single Monte Carlo sample. This lets us propagate gradients back through the \( f \) function. See Figure 10.4 for an illustration. This is called **reparameterized VI** or **RVI**.

Since we are now working with the random variable \( \epsilon \), we need to use the change of variables formula to compute

\( \log q_\phi(z|x) = \log p(\epsilon) - \log \left| \det \left( \frac{\partial z}{\partial \epsilon} \right) \right| \quad (10.41) \)

where \( \frac{\partial z}{\partial \epsilon} \) is the Jacobian:

\( \frac{\partial z}{\partial \epsilon} = \begin{pmatrix} \frac{\partial z_1}{\partial \epsilon_1} & \cdots & \frac{\partial z_1}{\partial \epsilon_k} \\ \vdots & \ddots & \vdots \\ \frac{\partial z_k}{\partial \epsilon_1} & \cdots & \frac{\partial z_k}{\partial \epsilon_k} \end{pmatrix} \quad (10.42) \)

We design the transformation \( z = g(\epsilon) \) such that this Jacobian is tractable to compute. We give some examples below.

### 10.2.1.1 Gaussian with diagonal covariance (mean field)

Suppose we use a fully factorized Gaussian posterior. Then the reparameterization process becomes

\( \epsilon \sim \mathcal{N}(\mathbf{0}, \mathbf{I}) \quad (10.43) \)

\( z = \mu + \sigma \odot \epsilon \quad (10.44) \)

where the inference network generates the parameters of the transformation:

\((\boldsymbol{\mu}, \log \boldsymbol{\sigma}) = f_\phi^{\text{inf}}(\boldsymbol{x})\)

Thus to sample from the posterior \(q_\phi(\boldsymbol{z}|\boldsymbol{x})\), we sample \(\boldsymbol{\epsilon} \sim \mathcal{N}(\boldsymbol{0}, \mathbf{I})\), and then compute \(\boldsymbol{z}\).

Given the sample, we need to evaluate the ELBO:

\(f(\boldsymbol{z}) = \log p_\theta(\boldsymbol{x}|\boldsymbol{z}) + \log p_\theta(\boldsymbol{z}) - \log q_\phi(\boldsymbol{z}|\boldsymbol{x})\)

To evaluate the \(p_\theta(\boldsymbol{x}|\boldsymbol{z})\) term, we can just plug \(\boldsymbol{z}\) into the likelihood. To evaluate the \(\log q_\phi(\boldsymbol{z}|\boldsymbol{x})\) term, we need to use the change of variables formula from Equation (10.41). The Jacobian is given by \(\frac{\partial \boldsymbol{z}}{\partial \boldsymbol{\epsilon}} = \text{diag}(\boldsymbol{\sigma})\). Hence

\(\log q_\phi(\boldsymbol{z}|\boldsymbol{x}) = \sum_{k=1}^K [\log \mathcal{N}(\epsilon_k|0, 1) - \log \sigma_k] = - \sum_{k=1}^K \left[ \frac{1}{2} \log(2\pi) + \frac{1}{2} \epsilon_k^2 + \log \sigma_k \right]\)

Finally, to evaluate the \(p(\boldsymbol{z})\) term, we can use the transformation \(\boldsymbol{z} = \mathbf{0} + \mathbf{1} \odot \boldsymbol{\epsilon}\), so the Jacobian is the identity and we get

\(\log p(\boldsymbol{z}) = \sum_{k=1}^K \left[ \frac{1}{2} \epsilon_k^2 + \frac{1}{2} \log(2\pi) \right]\)

An alternative is to use the objective

\(f'(\boldsymbol{z}) = \log p_\theta(\boldsymbol{x}|\boldsymbol{z}) + D_{\text{KL}}(q_\phi(\mathbf{Z}|\boldsymbol{x}) \parallel p_\theta(\mathbf{Z}))\)

In some cases, we evaluate the second term analytically, without needing Monte Carlo. For example, if we assume a diagonal Gaussian prior, \(p(\boldsymbol{z}) = \mathcal{N}(\boldsymbol{z}|\mathbf{0}, \mathbf{I})\), and diagonal gaussian posterior, \(q(\boldsymbol{z}|\boldsymbol{x}) = \mathcal{N}(\boldsymbol{z}|\boldsymbol{\mu}, \text{diag}(\boldsymbol{\sigma}))\), we can use Equation (5.78) to compute the KL in closed form:

\(D_{\text{KL}}(q \| p) = -\frac{1}{2} \sum_{k=1}^K [\log \sigma_k^2 - \sigma_k^2 - \mu_k^2 + 1]\)

The objective \(f'(\boldsymbol{z})\) is often lower variance than \(f(\boldsymbol{z})\), since it computes the KL analytically. However, it is harder to generalize this objective to settings where the prior and/or posterior are not Gaussian.

### 10.2.1.2 Gaussian with full covariance

Now consider using a full covariance Gaussian posterior. We will compute a Cholesky decomposition of the covariance, \(\boldsymbol{\Sigma} = \mathbf{L}\mathbf{L}^\mathsf{T}\), where \(\mathbf{L}\) is a lower triangular matrix with non-zero entries on the diagonal. Hence the reparameterization becomes

\(\boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})\)

\(\boldsymbol{z} = \boldsymbol{\mu} + \mathbf{L}\boldsymbol{\epsilon}\)
