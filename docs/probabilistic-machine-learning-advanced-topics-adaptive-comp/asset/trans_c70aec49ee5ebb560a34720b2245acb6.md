## 29.13.1 深度马尔可夫模型

假设我们创建一个SSM，其中为动态模型和/或观测模型使用深度神经网络；结果称为 **深度马尔可夫模型** [KSS17] 或 **随机RNN** [BO14; Fra+16]。（这与变分RNN不完全相同，我们将在 29.13.4 节中解释。）

我们可以使用SVI（10.1.4 节）来拟合DMM。关键是推断潜在变量的后验分布。

从一阶马尔可夫性质出发，精确后验分布由下式给出：

$p(z_{1:T}|x_{1:T}) = \prod_{t=1}^T p(z_t|z_{t-1}, x_{1:T}) = \prod_{t=1}^T p(z_t|z_{t-1}, x_{t:T})$ (29.164)

其中我们定义$p(z_1|z_0, x_{1:T}) = p(z_1|x_{1:T})$，且由于$z_t \perp x_{1:t-1}|z_{t-1}$，消去成立，如[KSS17]所指出。

通常，计算$p(z_{1:T}|x_{1:T})$是不可行的，因此我们使用推理网络对其进行近似。$q$有多种选择。一种简单的是完全分解模型，$q(z_{1:T}) = \prod_t q(z_t|x_{1:t})$。如图 29.42a 所示。由于$z_t$仅依赖于过去数据$x_{1:t}$（该数据累积在RNN隐藏状态$h_t$中），我们可以在运行时使用此推理网络进行在线推断。但是，对于离线训练模型，我们可以使用更准确的后验分布，即使用

$q(z_{1:T}|x_{1:T}) = \prod_{t=1}^T q(z_t|z_{t-1}, x_{1:T}) = \prod_{t=1}^T q(z_t|z_{t-1}, x_{t:T})$ (29.165)

请注意，对过去观测值$x_{1:t-1}$的依赖已经由$z_{t-1}$捕获，如公式 (29.164) 所示。对未来观测值$x_{t:T}$的依赖可以由反向RNN总结，如图 29.42b 所示。因此

$q(z_{1:T}, h_{1:T}|x_{1:T}) = \prod_{t=T}^1 \mathbb{I}(h_t = f(h_{t+1}, x_t)) \prod_{t=1}^T q(z_t|z_{t-1}, h_t)$ (29.166)

![](img/ca72c1626f4850f058a9edc138c1ac73_1059_0.png)

给定完全分解的\(q(\mathbf{z}_{1:T})\)，我们可以按如下方式计算ELBO。

```
\log p(\mathbf{x}_{1:T}) = \log \left[ \sum_{\mathbf{z}_{1:T}} p(\mathbf{x}_{1:T}|\mathbf{z}_{1:T})p(\mathbf{z}_{1:T}) \right]
= \log \mathbb{E}_{q(\mathbf{z}_{1:T})} \left[ p(\mathbf{x}_{1:T}|\mathbf{z}_{1:T}) \frac{p(\mathbf{z}_{1:T})}{q(\mathbf{z}_{1:T})} \right]
= \log \mathbb{E}_{q(\mathbf{z}_{1:T})} \left[ \prod_{t=1}^T \frac{p(\mathbf{x}_t|\mathbf{z}_t)p(\mathbf{z}_t|\mathbf{z}_{t-1})}{q(\mathbf{z}_t)} \right]
\ge \mathbb{E}_{q(\mathbf{z}_{1:T})} \left[ \sum_{t=1}^T \log p(\mathbf{x}_t|\mathbf{z}_t) + \log p(\mathbf{z}_t|\mathbf{z}_{t-1}) - \log q(\mathbf{z}_t) \right]
= \sum_{t=1}^T \mathbb{E}_{q(\mathbf{z}_t)} [\log p(\mathbf{x}_t|\mathbf{z}_t)] - \mathbb{E}_{q(\mathbf{z}_{t-1})} [D_{\text{KL}} (q(\mathbf{z}_t) \| p(\mathbf{z}_t|\mathbf{z}_{t-1}))]
```

如果我们假设变分后验是联合高斯分布，我们可以使用重参数化技巧来使用后验样本计算ELBO的随机梯度。此外，由于我们假设了高斯先验，KL项可以解析计算。

## 29.13.2 循环状态空间模型

在DMM中，观测模型\(p(\mathbf{x}_t|\mathbf{z}_t)\)是一阶马尔可夫的，动态模型\(p(\mathbf{z}_t|\mathbf{z}_{t-1})\)也是如此。我们可以通过添加确定性隐藏状态来修改模型，以捕获长程依赖。我们可以使用\(p(\mathbf{x}_t|\mathbf{h}_t)\)使观测模型依赖于\(\mathbf{z}_{1:t}\)而不仅仅是\(\mathbf{z}_t\)，其中\(\mathbf{h}_t = f(\mathbf{h}_{t-1}, \mathbf{z}_t)\)，因此\(\mathbf{h}_t\)记录了所有随机选择。如图 29.43a 所示。我们还可以通过将\(p(\mathbf{z}_t|\mathbf{z}_{t-1})\)替换为\(p(\mathbf{z}_t|\mathbf{h}_{t-1})\)使动态先验依赖于\(\mathbf{z}_{1:t-1}\)，如图 29.43b 所示。这被称为 **循环状态空间模型**。

我们可以为RSSM推导一个推理网络，类似于我们用于DMM的网络，只不过现在我们使用标准前向RNN来计算\(q(\mathbf{z}_t|\mathbf{x}_{1:t-1}, \mathbf{x}_{1:t})\)。

![](img/ca72c1626f4850f058a9edc138c1ac73_1060_0.png)

图 29.43：循环状态空间模型。(a) 先验是一阶马尔可夫的，p(z_t|z_{t-1})，但观测模型不是马尔可夫的，p(x_t|h_t) = p(x_t|z_{1:t})，其中 h_t 总结了 z_{1:t}。(b) 先验模型也不再是一阶马尔可夫的，p(z_t|h_{t-1}) = p(z_t|z_{1:t-1})。菱形是确定性节点，圆形是随机节点。

## 29.13.3 改进多步预测

在图 29.44(a) 中，我们展示了 ELBO 中涉及的损失项。特别是，波形边 z_{t|t} → z_{t|t−1} 对应于 E_{q(z_{t−1})} [D_{KL}(q(z_t) || p(z_t|z_{t−1}))]，而实线边 z_{t|t} → x_t 对应于 E_{q(z_t)} [log p(x_t|z_t)]。我们看到，动态模型 p(z_t|z_{t−1}) 仅根据其与一步先验后验 q(z_t) 的差异进行惩罚，这可能会损害模型进行长期预测的能力。

解决此问题的一个方法是使用动态模型进行多步前向预测，并使用这些预测来重建未来观测值，并将这些误差作为额外损失项添加。这称为观测超步 [Amo+18]，如图 29.44(b) 所示。

[Haf+19] 提出的一种更快速的方法是应用类似的想法，但在潜在空间中。更准确地说，让我们通过反复应用转换模型并对中间状态进行边缘化来计算多步预测模型，以得到 p(z_t|z_{t−d})。然后我们可以按如下方式计算 ELBO：

![](img/ca72c1626f4850f058a9edc138c1ac73_1061_0.png)

图 29.45：变分 RNN。(a) 生成模型。(b) 推理模型。菱形节点是确定性的。

如下所示：

```
\(\log p_d(x_{1:T}) \triangleq \log \int \prod_{t=1}^T p(z_t | z_{t-d}) p(x_t | z_t) dz_{1:T}\)
```

```
\(\ge \sum_{t=1}^T \mathbb{E}_{q(z_t)} [\log p(x_t | z_t)] - \mathbb{E}_{p(z_{t-1} | z_{t-d}) q(z_{t-d})} [D_{KL} (q(z_t) \| p(z_t | z_{t-1}))]\)
```

为了训练模型使其擅长在不同未来时标深度 d 上进行预测，我们可以对上述所有 \(1 \le d \le D\) 进行平均。但是，出于计算原因，我们可以只对 KL 项进行平均，使用权重 \(\beta_d\)。这称为潜在超步 [Haf+19]，如图 29.44(c) 所示。新的目标变为

```
\(\frac{1}{D} \sum_{d=1}^D \log p_d(x_{1:T}) \ge \sum_{t=1}^T \mathbb{E}_{q(z_t)} [\log p(x_t | z_t)]\)
```

```
\(- \frac{1}{D} \sum_{d=1}^D \beta_d \mathbb{E}_{p(z_{t-1} | z_{t-d}) q(z_{t-d})} [D_{KL} (q(z_t) \| p(z_t | z_{t-1}))]\)
```

## 29.13.4 变分 RNN

变分 RNN (VRNN) [Chu+15] 与循环状态空间模型类似，但隐藏状态是基于所有过去隐藏状态 _和_ 所有过去观测值生成的，而不仅仅是基于过去隐藏状态。这是一个更具表达性的模型，但用于预测时速度较慢，因为向未来展开需要生成观测值 _x_<sub>_t_+1</sub>、_x_<sub>_t_+2</sub> 等以“输入”隐藏状态（隐藏状态控制动态）。这使得该模型对预测和基于模型的强化学习（见 35.4.5.2 节）的用处较小。

更准确地说，生成模型如下：

```
\(p(x_{1:T}, z_{1:T}, h_{1:T}) = \prod_{t=1}^T p(z_t | h_{t-1}, x_{t-1}) \mathbb{I}(h_t = f(h_{t-1}, x_{t-1}, z_t)) p(x_t | h_t)\)
```
