

由不同的策略 \(\pi'\) 生成，简单地对数据中的奖励求平均得到 \(J(\pi')\)，而不是 \(J(\pi)\)。我们必须以某种方式修正这个差距，即“偏差”。另一个挑战是，非策略数据也可能导致算法不稳定和发散，我们将在第 35.5.3 节中讨论。

消除分布不匹配并非非策略学习所独有，在监督学习中也需要用来处理协变量偏移（第 19.2.3.1 节），在因果效应估计（第 36 章）等领域也是如此。非策略学习还与 **离线强化学习**（也称为 **批式强化学习**）密切相关：前者强调数据与智能体策略之间的分布不匹配，后者强调数据是静态的，且不允许进一步与环境进行在线交互 [LP03; EGW05; Lev+20]。显然，在固定数据的离线场景中，非策略学习通常是关键的技术组成部分。最近，已经准备了若干数据集，以便于离线 RL 方法的实证比较（例如，参见 [Gul+20; Fu+20]）。

最后，虽然本节主要关注 MDPs，但大多数方法都可以简化并适应上下文盗贼（第 34.4 节）的特殊情况。事实上，非策略方法已在众多工业盗贼应用中得到成功应用（例如，参见 [Li+10; Bot+13; SJ15; HLR16]）。

## 35.5.1 基本技术

我们从四种基本技术入手，并在后续章节中考虑更复杂的方法。非策略数据被假设为轨迹的集合：\(\mathcal{D} = \{\boldsymbol{\tau}^{(i)}\}_{1 \le i \le n}\)，其中每个轨迹和以前一样是一个序列：\(\boldsymbol{\tau}^{(i)} = (s_0^{(i)}, a_0^{(i)}, r_0^{(i)}, s_1^{(i)} \dots)\)。在这里，奖励和下一状态根据奖励和转移模型采样；动作由 **行为策略** 选择，记为 \(\pi_b\)，它与智能体正在评估或改进的 **目标策略** \(\pi_e\) 不同。当 \(\pi_b\) 未知时，我们处于 **行为-无关非策略** 设置中。

### 35.5.1.1 直接法

非策略学习的一种自然方法是首先从非策略数据中估计 MDP 未知的奖励和转移模型。这可以分别使用回归和密度估计方法对奖励和转移模型进行处理，以获得 \(\hat{R}\) 和 \(\hat{P}\)；进一步讨论见第 35.4 节。这些估计模型随后为我们提供了一种廉价的（近似）模拟原始 MDP 的方法，我们可以在模拟数据上应用在策略方法。该方法直接建模在状态中采取动作的结果，因此得名 **直接法**，有时也被称为 **回归估计器** 和 **插件估计器**。

虽然直接法很自然且有时有效，但它有几个局限性。首先，模拟器中的微小估计误差在长时域问题中会产生累积效应（或者等价地，当折扣因子 \(\gamma\) 接近 1 时）。因此，针对 MDP 模拟器优化的智能体可能会对估计误差过拟合。不幸的是，学习 MDP 模型（尤其是转移模型）通常很困难，这使得该方法仅局限于 \(\hat{R}\) 和 \(\hat{P}\) 可以高保真学习的领域。相关讨论见第 35.4.6 节。

### 35.5.1.3 双重稳健法

可以结合之前讨论的直接法和重要性采样法。为了建立直觉，考虑在上下文盗贼（第 34.4 节）中估计 \(J(\pi_e)\) 的问题，即当 \(\mathcal{D}\) 中 \(T=1\) 时。**双重稳健**（DR）估计器由以下公式给出

\[
\hat{J}_{\text{DR}}(\pi_e) \triangleq \frac{1}{n} \sum_{i=1}^n \left( \frac{\pi_e(a_0^{(i)}|s_0^{(i)})}{\hat{\pi}_b(a_0^{(i)}|s_0^{(i)})} \left( r_0^{(i)} - \hat{Q}(s_0^{(i)}, a_0^{(i)}) \right) + \hat{V}(s_0^{(i)}) \right) \tag{35.51}
\]

其中 \(\hat{Q}\) 是 \(Q_{\pi_e}\) 的估计，可以使用第 35.2 节讨论的方法获得，且 \(\hat{V}(s) = \mathbb{E}_{\pi_e(a|s)} \left[ \hat{Q}(s, a) \right]\)。如果 \(\hat{\pi}_b = \pi_b\)，则项 \(\hat{Q}\) 在平均上被 \(\hat{V}\) 抵消，我们得到无偏的 IS 估计；如果 \(\hat{Q} = Q_{\pi_e}\)，则项 \(\hat{Q}\) 在平均上被奖励抵消，我们得到与直接法相同的也是无偏的估计器。换句话说，估计器方程 (35.51) 是无偏的，只要估计 \(\hat{\pi}_b\) 和 \(\hat{Q}\) 中有一个是正确的。这一观察证明了双重稳健这一名称的合理性，该名称起源于因果推断（例如，参见 [BR05]）。

上述 DR 估计器可以递归地扩展到 MDPs。给定一个长度为 \(T\) 的轨迹 \(\tau\)，定义 \(\hat{J}_{\text{DR}}[T] \triangleq 0$，且对于 \(t < T\)，有

\[
\hat{J}_{\text{DR}}[t] \triangleq \hat{V}(s_t) + \hat{\rho}_t(\tau) \left( r_t + \gamma \hat{J}_{\text{DR}}[t+1] - \hat{Q}(s_t, a_t) \right)
\]

其中 \(\hat{Q}(s_t, a_t)\) 是剩余 \(T-t\) 步的累积奖励估计。\(J(\pi_e)\) 的 DR 估计器，记为 \(\hat{J}_{\text{DR}}(\pi_e)\)，是 \(\mathcal{D}\) 中所有 \(n\) 条轨迹上的 \(\hat{J}_{\text{DR}}[0]\) 的平均值 [JL16]。可以验证（作为练习），递归定义等价于

\[
\hat{J}_{\text{DR}}[0] = \hat{V}(s_0) + \sum_{t=0}^{T-1} \left( \prod_{t^\prime=0}^t \hat{\rho}_{t^\prime}(\tau) \right) \gamma^t \left( r_t + \gamma \hat{V}(s_{t+1}) - \hat{Q}(s_t, a_t) \right)
\]

这种形式可以通过令 \(T \rightarrow \infty\) [TB16] 很容易地推广到无穷时域设置。除了双重稳健性之外，该估计器还被证明在某些条件下能实现最小方差
