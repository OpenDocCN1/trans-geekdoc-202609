
The natural performance metric is the KL between these distributions. Since this depends on the inputs $x$ and $\mathcal{D}_T = (X_{0:T-1}, Y_{1:T})$, we will average the KL over these values, which are drawn iid from the true data generating distribution, which we denote by

$$P(X, Y, \mathcal{E}) = P(X|\mathcal{E})P(Y|X, \mathcal{E})P(\mathcal{E})$$

where $\mathcal{E}$ is the true but unknown environment. Thus we define our metric as

$$d_{B,Q}^{KL} = \mathbb{E}_{P(x, \mathcal{D}_T)} [D_{KL}(P^B(y|x, \mathcal{D}_T) || Q(y|x, \mathcal{D}_T))]$$

where

$$P(x, \mathcal{D}_T, \mathcal{E}) = P(\mathcal{E}) \left[ \prod_{t=0}^{T-1} P(X_t|\mathcal{E})P(Y_{t+1}|X_t, \mathcal{E}) \right] \left[ \prod_{t=T}^{T+\tau-1} P(x_t|\mathcal{E}) \right]$$

and $P(x, \mathcal{D}_T)$ marginalizes this over environments.

Unfortunately, it is usually intractable to compute the exact Bayes posterior, $P_T^B$, so we cannot evaluate $d_{B,Q}^{KL}$. However, in Section 14.2.3.1, we show that

$$d_{B,Q}^{KL} = d_{\mathcal{E},Q}^{KL} - \mathbb{I}(\mathcal{E}; y|\mathcal{D}_T, x)$$

where the second term is a constant wrt the agent, and the first term is given by

$$d_{\mathcal{E}, Q}^{KL} = \mathbb{E}_{P(x, \mathcal{D}_T, \mathcal{E})} [D_{KL}(P(y|x, \mathcal{E}) || Q(y|x, \mathcal{D}_T))]$$

$$= \mathbb{E}_{P(y|x, \mathcal{E})P(x, \mathcal{D}_T, \mathcal{E})} [\log \frac{P(y|x, \mathcal{E})}{Q(y|x, \mathcal{D}_T)}]$$

Hence if we rank agents in terms of $d_{\mathcal{E}, Q}^{KL}$, it will give the same results as ranking them by $d_{B, Q}^{KL}$.

To compute $d_{\mathcal{E}, Q}^{KL}$ in practice, we can use a Monte Carlo approximation: we just have to sample $J$ environments, $\mathcal{E}^j \sim P(\mathcal{E})$, sample a training set $\mathcal{D}_T$ from each environment, $\mathcal{D}_T^j \sim P(\mathcal{D}_T|\mathcal{E}^j)$, and then sample $N$ data vectors of length $\tau$, $(x_n^j, y_n^j) \sim P(X_{T:T+\tau-1}, Y_{T+1:T+\tau}|\mathcal{E}^j)$. We can then compute

$$\hat{d}_{\mathcal{E}, Q}^{KL} = \frac{1}{JN} \sum_{j=1}^J \sum_{n=1}^N [\log P(y_n^j|x_n^j, \mathcal{E}^j) - \log Q(y_n^j|x_n^j, \mathcal{D}_T^j)]$$

where

$$p_{jn} = P(y_n^j|x_n^j, \mathcal{E}^j) = \prod_{t=T}^{T+\tau-1} P(Y_{n, t+1}^j|X_{n,t}^j, \mathcal{E}^j)$$

$$q_{jn} = Q(y_n^j|x_n^j, \mathcal{D}_T^j) = \int Q(y_n^j|x_n^j, \theta) Q(\theta|\mathcal{D}_T^j) d\theta$$

$$\approx \frac{1}{M} \sum_{m=1}^M \prod_{t=T}^{T+\tau-1} Q(Y_{n, t+1}^j | X_{n,t}^j, \theta_m^j)$$

where \(\theta_m^j \sim Q(\theta | D_T^j)\) is a sample from the agent's posterior over the environment.

The above assumes that \(P(Y|X)\) is known; this will be the case if we use a synthetic data generator, as in the "neural testbed" in [Osb+21]. If we just have \(J\) empirical distributions for \(P^j(X, Y)\), we can replace the KL with the cross entropy, which only differs by an additive constant:

$$d_{\mathcal{E}, Q}^{KL} = \mathbb{E}_{P(x, D_T, \mathcal{E})} [D_{KL}(P(y|x, \mathcal{E}) \| Q(y|x, D_T))]$$

$$= \underbrace{\mathbb{E}_{P(x, y|\mathcal{E})}[\log P(y|x, \mathcal{E})]}_{\text{const}} - \underbrace{\mathbb{E}_{P(x, y|D_T) P(\mathcal{E})}[\log Q(y|x, D_T)]}_{d_{\mathcal{E}, Q}^{CE}}$$

where the latter term is just the empirical negative log likelihood (NLL) of the agent on samples from the environment. Hence if we rank agents in terms of their NLL or cross entropy $d_{\mathcal{E}, Q}^{CE}$ we will get the same results as ranking them by $d_{\mathcal{E}, Q}^{KL}$, which will in turn give the same results as ranking them by $d_{B,Q}^{KL}$.

In practice we can approximate the cross entropy as follows:

$$\hat{d}_{\mathcal{E}, Q}^{CE} = -\frac{1}{JN} \sum_{j=1}^J \sum_{n=1}^N \log Q(y_n^j | x_n^j, D_T^j)$$

where \(D_T^j \sim P^j\), and \((x_n^j, y_n^j) \sim P^j\).

An alternative to estimating the KL or NLL is to evaluate the joint predictive accuracy by using it in a downstream task. In [Osb+21], they show that good predictive accuracy (for \(\tau > 1\)) correlates with good performance on a bandit problem (see Section 34.4). In [WSG21] they show that good predictive accuracy (for \(\tau > 1\)) results in good performance on a transductive active learning task.

### 14.2.3.1 Proof of claim

We now prove Equation (14.29), based on [Lu+21a]. First note that

$$d_{\mathcal{E}, Q}^{KL} = \mathbb{E}_{P(x, D_T, \mathcal{E}) P(y|x, \mathcal{E})} \left[ \log \frac{P(y|x, \mathcal{E})}{Q(y|x, D_T)} \right]$$

$$= \mathbb{E} \left[ \log \frac{P(y|x, D_T)}{Q(y|x, D_T)} \right] + \mathbb{E} \left[ \log \frac{P(y|x, \mathcal{E})}{P(y|x, D_T)} \right]$$

For the first term in Equation (14.40) we have

$$\mathbb{E} \left[ \log \frac{P(y|x, D_T)}{Q(y|x, D_T)} \right] = \sum P(x, y, D_T) \log \frac{P(y|x, D_T)}{Q(y|x, D_T)}$$

$$= \sum P(x, D_T) \sum P(y|x, D_T) \log \frac{P(y|x, D_T)}{Q(y|x, D_T)}$$

$$= \mathbb{E}_{P(x, D_T)} [D_{KL}(P(y|x, D_T) \| Q(y|x, D_T))] = d_{B,Q}^{KL}$$

We now show that the second term in Equation (14.40) reduces to the mutual information. We exploit the fact that

$$P(y|x, \mathcal{E}) = P(y|D_T, x, \mathcal{E}) = \frac{P(\mathcal{E}, y|D_T, x)}{P(\mathcal{E}|D_T, x)}$$

since $\mathcal{D}_T$ has no new information in beyond $\mathcal{E}$. From this we get

```
\(\mathbb{E} \left[ \log \frac{P(\boldsymbol{y}|\mathbf{x}, \mathcal{E})}{P(\boldsymbol{y}|\mathbf{x}, \mathcal{D}_T)} \right] = \mathbb{E} \left[ \log \frac{P(\mathcal{E}, \boldsymbol{y}|\mathcal{D}_T, \mathbf{x}) / P(\mathcal{E}|\mathcal{D}_T, \mathbf{x})}{P(\boldsymbol{y}|\mathbf{x}, \mathcal{D}_T)} \right]\)
\(= \sum P(\mathcal{D}_T, \mathbf{x}) \sum P(\mathcal{E}, \boldsymbol{y}|\mathcal{D}_T, \mathbf{x}) \log \frac{P(\mathcal{E}, \boldsymbol{y}|\mathcal{D}_T, \mathbf{x})}{P(\boldsymbol{y}|\mathcal{D}_T, \mathbf{x}) P(\mathcal{E}|\mathcal{D}_T, \mathbf{x})}\)
\(= \mathbb{I}(\mathcal{E}; \boldsymbol{y}|\mathcal{D}_T, \mathbf{x})\)
```

Hence

```
\(d_{\mathcal{E}, Q}^{KL} = d_{B, Q}^{KL} + \mathbb{I}(\mathcal{E}; \boldsymbol{y}|\mathcal{D}_T, \mathbf{x})\)
```

as claimed.

## 14.3 Conformal prediction

In this section, we briefly discuss **conformal prediction** [VGS05; SV08; ZFV20; AB21; KSB21; Man22b]. This is a simple but effective way to create prediction intervals or sets with guaranteed frequentist coverage probability from any predictive method \(p(\boldsymbol{y}|\mathbf{x})\). This can be seen as a form of **distribution free uncertainty quantification**, since it works without making assumptions (beyond exchangeability of the data) about the true data generating process or the form of the model.$^1$ Our presentation is based on the excellent tutorial of [AB21].$^2$

1. The exchangeability assumption rules out time series data, which is serially correlated. However, extensions to conformal prediction have been developed for the time series case, see e.g., [Zaf+22]. The exchangeability assumption also rules out distribution shift, although this has also been partially addressed.
2. See also the easy-to-use **MAPIE** Python library at https://mapie.readthedocs.io/en/latest/index.html, and the list of papers at [Man22a].

In conformal prediction, we start with some heuristic notion of uncertainty — such as the softmax score for a classification problem, or the variance for a regression problem — and we use it to define a **conformal score** \(s(\mathbf{x}, y) \in \mathbb{R}\), which measures how badly the output \(y\) “conforms” to \(\mathbf{x}\). (Large values of the score are less likely, so it is better to think of it as a non-conformity score.) Next we apply this score to a **calibration set** of $n$ labeled examples, that was not used to train $f$, to get $\mathcal{S} = \{s_i = s(\mathbf{x}_i, y_i) : i = 1 : n\}$. The user specifies a desired confidence threshold $\alpha$, say 0.1, and we then compute the $(1-\alpha)$ quantile $\hat{q}$ of $\mathcal{S}$. (In fact, we should replace $1-\alpha$ with $\frac{\lceil(n+1)(1-\alpha)\rceil}{n}$, to account for the finite size of $\mathcal{S}$.) Finally, given a new test input, $\mathbf{x}_{n+1}$, we compute the prediction set to be

```
$$\mathcal{T}(\mathbf{x}_{n+1}) = \{y : s(\mathbf{x}_{n+1}, y) \le \hat{q}\}$$ (14.49)
```

Intuitively, we include all the outputs $y$ that are plausible given the input. See Figure 14.4 for an illustration.

Remarkably, one can show the following general result

```
$$1 - \alpha \le P^*(y^{n+1} \in \mathcal{T}(\mathbf{x}_{n+1})) \le 1 - \alpha + \frac{1}{n+1}$$ (14.50)
```

where the probability is wrt the true distribution $P^*(\mathbf{x}_{n+1}, y_{n+1})$. We say that the prediction set has a **coverage** level of $1 - \alpha$. This holds for any value of $n \ge 1$ and $\alpha \in [0, 1]$. The only assumption is that the values $(\mathbf{x}_i, y_i)$ are exchangeable, and hence the calibration scores $s_i$ are also exchangeable. To see why this is true, let us sort the scores so $s_1 < \cdots < s_n$, so $\hat{q} = s_i$, where $i = \frac{\lceil(n+1)(1-\alpha)\rceil}{n}$. (We assume the scores are distinct, for simplicity.) The score $s_{n+1}$ is equally likely to fall in anywhere between the calibration points $s_1, \dots, s_n$, since the points are exchangeable. Hence

```
$$P^*(s_{n+1} \le s_k) = \frac{k}{n+1}$$ (14.51)
```

for any $k \in \{1, \dots, n+1\}$. The event $\{y_{n+1} \in \mathcal{T}(\mathbf{x}_{n+1})\}$ is equivalent to $\{s_{n+1} \le \hat{q}\}$. Hence

```
$$P^*(y_{n+1} \in \mathcal{T}(\mathbf{x}_{n+1})) = P^*(s_{n+1} \le \hat{q}) = \frac{\lceil(n+1)(1-\alpha)\rceil}{n+1} \ge 1 - \alpha$$ (14.52)
```

For the proof of the upper bound, see [Lei+18]. Although this result may seem like a “free lunch”, it is worth noting that we can always achieve a desired coverage level by defining the prediction set to be all possible labels. In this case, the prediction set will be independent of the input, but it will cover the true label $1 - \alpha$ of the time. To rule out some degenerate cases, we seek prediction sets that are as small as possible (although we allow for the set to be larger for harder examples), while meeting the coverage requirement. Achieving this goal requires that we define suitable conformal scores. Below we give some examples of how to compute conformal scores $s(\mathbf{x}, y)$ for different kinds of problem. It is also important to note that the coverage guarantees are frequentist in nature, and refer to average behavior, rather than representing per-instance uncertainty, as in the Bayesian approach.

3. Using a calibration set is called **split conformal prediction**. If we don’t have enough data to adopt this splitting approach, we can use **full conformal prediction** [VGS05], which requires fitting the model $n$ times using a leave-one-out type procedure.
4. It is also possible to learn conformal scores in an end-to-end way, jointly with the predictive model, as discussed in [Stu+22].
