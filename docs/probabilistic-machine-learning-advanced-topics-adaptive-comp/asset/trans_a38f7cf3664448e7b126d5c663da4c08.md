

## 28.2.5.1 混合生成/判别训练

不幸的是，形式为 \(p(\boldsymbol{x}, y)\) 的生成模型的分类准确率可能远低于形式为 \(p(y|\boldsymbol{x})\) 的判别（条件）模型，因为后者直接针对给定特征预测标签进行了优化，不会在建模输入的无关细节上“浪费”容量。（关于生成式与判别式分类器的更深入讨论，见例如 [Mur22, 第 9.4 节]。）

幸运的是，可以以判别方式训练生成模型，这可以缩小与条件模型之间的性能差距，同时保持生成模型的优势。特别是，我们可以优化以下混合目标，该目标在 [BT04; Rot+18] 中提出：

```
\(\mathcal{L}(\boldsymbol{\theta}) = -\lambda \sum_{n=1}^N \log p(\boldsymbol{x}_n, y_n|\boldsymbol{\theta}) - (1 - \lambda) \sum_{n=1}^N \log p(y_n|\boldsymbol{x}_n, \boldsymbol{\theta})\underbrace{}_{\mathcal{L}_{gen}(\boldsymbol{\theta})} \quad \underbrace{}_{\mathcal{L}_{dis}(\boldsymbol{\theta})}\) (28.25)
```

其中 \(0 \le \lambda \le 1\) 控制生成建模与判别建模之间的权衡。

如果我们有未标记数据，可以如下修改生成损失：

```
\(\mathcal{L}_{gen}(\boldsymbol{\theta}) = \kappa \sum_{n=1}^{N^l} \log p(\boldsymbol{x}_n^l, y_n^l|\boldsymbol{\theta}) + (1 - \kappa) \sum_{n=1}^{N^u} \log p(\boldsymbol{x}_n^u|\boldsymbol{\theta})\) (28.26)
```

这里我们引入了额外的权衡参数 \(0 \le \kappa \le 1\)，以防止未标记数据淹没标记数据（如果 \(N_u \gg N_l\)），如 [Nig+00] 所提议。

改变目标函数的替代方法是改变模型本身，使用 \(p(\boldsymbol{x}, y) = p(y|\boldsymbol{x}, \boldsymbol{\theta})p(\boldsymbol{x}|\tilde{\boldsymbol{\theta}})\) 参数化联合分布，然后定义不同类型的联合先验 \(p(\boldsymbol{\theta}, \tilde{\boldsymbol{\theta}})\)；详情见 [LBM06; BL07a]。

## 28.2.5.2 优化问题

为了优化损失，我们需要将模型重新参数化为无约束形式。对于类先验，可以使用 \(\pi_{1:C} = \text{softmax}(\tilde{\pi}_{1:C})\)，并针对 logits \(\tilde{\pi}_{1:C}\) 进行优化。混合权重 \(\alpha_{c,1:K}\) 亦然。均值 \(\boldsymbol{\mu}_{ck}\) 已经是无约束的。对于协方差矩阵，我们将使用对角加低秩表示，以减少参数数量：

```
\(\boldsymbol{\Sigma}_{c,k} = \text{diag}(\boldsymbol{d}_{c,k}) + \mathbf{S}_{c,k}\mathbf{S}_{c,k}^\mathsf{T}\) (28.27)
```

其中 \(\mathbf{S}_{c,k}\) 是一个无约束的 \(D \times R\) 矩阵，\(R \ll D\) 是近似的秩。（为了数值稳定性，我们通常在上述表达式中添加 \(\epsilon \mathbf{I}\)，以确保 \(\boldsymbol{\Sigma}_{c,k}\) 对所有参数设置都是正定的。）为了确保对角项的正性，可以使用 softplus 变换 \(d_{c,k} = \log(1 + \exp(d_{c,k}))\)，并针对 \(\tilde{d}_{c,k}\) 项进行优化。

## 28.2.5.3 数值问题

为了计算类条件对数似然 \(\ell_c = \log p(\boldsymbol{x}|y=c)\)，可以使用 log-sum-exp 技巧以避免数值下溢。定义 \(\hat{\alpha}_{ck} = \log \alpha_{ck}\) 和 \(\ell_{ck} = \log \mathcal{N}(\boldsymbol{x}|\boldsymbol{\mu}_{ck}, \boldsymbol{\Sigma}_{ck})\)。则有

```
\(\ell_c = \log p(x|y=c) = \log \sum_k e^{\tilde{\alpha}_{ck}+\ell_{ck}}\tag{28.28}\)
\(= e^M \log \sum_k e^{\tilde{\alpha}_{ck}+\ell_{ck}-M} \stackrel{\Delta}{=} \text{logsumexp}(\{\tilde{\alpha}_{ck} + \ell_{ck}\}_k)\tag{28.29}\)
```

其中 \(M = \max_k \tilde{\alpha}_{ck} + \ell_{ck}\)。
我们可以使用类似的方法来计算类的后验。我们有

```
\(p(y=c|x) = \frac{\pi_c e^{l_c}}{Z} = \frac{\pi_c e^{l_c-L}}{e^{-L} Z} = \frac{\pi_c e^{\tilde{l}_c}}{\tilde{Z}}\tag{28.30}\)
```

其中 \(L = \max_c l_c\)，\(\tilde{l}_c = l_c - L\)，\(\tilde{Z} = \sum_c \pi_c e^{\tilde{l}_c}\)。这样我们就可以将类先验概率 \(\pi_c\) 与缩放的类条件对数似然 \(\tilde{l}_c\) 结合起来，以稳定的方式得到类后验。（我们也可以计算对数归一化常数 \(\log p(x) = \log Z = \log(\tilde{Z}) + L\)。）

为了计算单个高斯对数密度 \(\ell_{ck} = \log \mathcal{N}(x|\mu_{ck}, \Sigma_{ck})\)，需要计算 \(\log \det(\Sigma_{ck})\) 和 \(\Sigma_{ck}^{-1}\)。为了提高效率，可以使用矩阵行列式引理来计算

```
\(\det(\mathbf{A} + \mathbf{S}\mathbf{S}^T) = \det(\mathbf{I} + \mathbf{S}^T \mathbf{A}^{-1} \mathbf{S}) \det(\mathbf{A})\tag{28.31}\)
```

其中 \(\mathbf{A} = \text{diag}(d) + \epsilon \mathbf{I}\)，并使用矩阵反演引理来计算

```
\((\mathbf{A} + \mathbf{S}\mathbf{S}^T)^{-1} = \mathbf{A}^{-1} - \mathbf{A}^{-1}\mathbf{S}(\mathbf{I} + \mathbf{S}^T \mathbf{A}^{-1} \mathbf{S})^{-1} \mathbf{S}^T \mathbf{A}^{-1}\tag{28.32}\)
```

（另见第 28.3.3 节中关于因子分析器混合模型的讨论。）

## 28.3 因子分析

在本节中，我们讨论一个简单的潜在因子模型，其中先验 \(p(z)\) 是高斯的，似然 \(p(x|z)\) 也是高斯的，并使用线性解码器作为均值。这个家族包括许多重要的特例，如下文所述的 PCA。我们还将简要讨论一些简单的扩展。

### 28.3.1 因子分析：基础

因子分析对应于以下线性高斯潜在变量生成模型：

```
\(p(z) = \mathcal{N}(z|\mu_0, \Sigma_0)\tag{28.33}\)
\(p(x|z, \theta) = \mathcal{N}(x|\mathbf{W}z + \mu, \Psi)\tag{28.34}\)
```

其中 \(\mathbf{W}\) 是一个 \(D \times L\) 矩阵，称为**因子载荷矩阵**，\(\Psi\) 是一个对角 \(D \times D\) 协方差矩阵。

### 28.3.1.1 作为低秩加对角协方差高斯分布的 FA

FA 可以被视为高斯分布的低秩版本。要看到这一点，请注意，诱导的边缘分布 \(p(\mathbf{x}|\boldsymbol{\theta})\) 是高斯分布（推导见方程 (2.129)）：

\(p(\mathbf{x}|\boldsymbol{\theta}) = \int \mathcal{N}(\mathbf{x}|\mathbf{W}\mathbf{z} + \boldsymbol{\mu}, \boldsymbol{\Psi})\mathcal{N}(\mathbf{z}|\boldsymbol{\mu}_0, \boldsymbol{\Sigma}_0)d\mathbf{z}\)
\(= \mathcal{N}(\mathbf{x}|\mathbf{W}\boldsymbol{\mu}_0 + \boldsymbol{\mu}, \boldsymbol{\Psi} + \mathbf{W}\boldsymbol{\Sigma}_0\mathbf{W}^T)\)

一阶和二阶矩可推导如下：

\(\mathbb{E}[\mathbf{x}] = \mathbf{W}\boldsymbol{\mu}_0 + \boldsymbol{\mu}\)
\(\text{Cov}[\mathbf{x}] = \mathbf{W}\text{Cov}[\mathbf{z}]\mathbf{W}^T + \boldsymbol{\Psi} = \mathbf{W}\boldsymbol{\Sigma}_0\mathbf{W}^T + \boldsymbol{\Psi}\)

由此可知，我们可以不失一般性地设置 \(\boldsymbol{\mu}_0 = \mathbf{0}\)，因为我们可以始终将 \(\mathbf{W}\boldsymbol{\mu}_0\) 吸收到 \(\boldsymbol{\mu}\) 中。同样，我们可以不失一般性地设置 \(\boldsymbol{\Sigma}_0 = \mathbf{I}\)，因为我们可以始终通过使用新的权重矩阵 \(\tilde{\mathbf{W}} = \mathbf{W}\boldsymbol{\Sigma}_0^{-\frac{1}{2}}\) 来吸收相关先验，因为此时

\(\text{Cov}[\mathbf{x}] = \mathbf{W}\boldsymbol{\Sigma}_0\mathbf{W}^T + \boldsymbol{\Psi} = \tilde{\mathbf{W}}\tilde{\mathbf{W}}^T + \boldsymbol{\Psi}\)

最后，我们发现应将 \(\boldsymbol{\Psi}\) 限制为对角矩阵，否则我们可以设置 \(\tilde{\mathbf{W}} = \mathbf{0}，从而忽略潜在因子，但仍能建模任何协方差。经过这些简化后，我们得到最终模型：

\(p(\mathbf{z}) = \mathcal{N}(\mathbf{z}|\mathbf{0}, \mathbf{I})\)
\(p(\mathbf{x}|\mathbf{z}) = \mathcal{N}(\mathbf{x}|\mathbf{W}\mathbf{z} + \boldsymbol{\mu}, \boldsymbol{\Psi})\)

由此可得

\(p(\mathbf{x}) = \mathcal{N}(\mathbf{x}|\boldsymbol{\mu}, \mathbf{W}\mathbf{W}^T + \boldsymbol{\Psi})\)

例如，假设 \(L=1, D=2\) 且 \(\boldsymbol{\Psi} = \sigma^2\mathbf{I}\)。我们在图 28.6 中说明了此情况下的生成过程。我们可以将此视为取一个各向同性高斯“喷雾罐”，表示似然 \(p(\mathbf{x}|\mathbf{z})\)，并随着我们变化一维潜在先验 \(z\)，将其“沿”一维直线 \(\mathbf{w}z + \boldsymbol{\mu}\)“滑动”。这在 2d 中诱导出一个拉长（因此相关）的高斯分布。也就是说，诱导分布的形式为 \(p(\mathbf{x}) = \mathcal{N}(\mathbf{x}|\boldsymbol{\mu}, \mathbf{w}\mathbf{w}^T + \sigma^2\mathbf{I})\)。

一般来说，FA 使用低秩分解来近似可见向量的协方差矩阵：

\(\mathbf{C} = \text{Cov}[\mathbf{x}] = \mathbf{W}\mathbf{W}^T + \boldsymbol{\Psi}\)

这只使用 \(O(LD)\) 个参数，从而在具有 \(O(D^2)\) 个参数的完整协方差高斯分布和具有 \(O(D)\) 个参数的对角协方差之间实现了灵活的折中。
