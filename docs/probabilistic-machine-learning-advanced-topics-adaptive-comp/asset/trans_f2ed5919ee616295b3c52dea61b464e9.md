我们可以将HHMM表示为有向图模型，如图29.18所示。\(Q_t^\ell\) 表示时间 \(t\) 和层级 \(\ell\) 的状态。只有当下一层级的链“结束”时，层级 \(\ell\) 的状态转换才被“允许”，这由 \(F_t^{\ell-1}\) 节点决定。（下一层级的链在选择进入其终止状态时结束。）这种机制确保高层级链的演化速度比低层级链更慢，即低层级嵌套在高层级之中。

可变持续时间HMM可以被视为HHMM的一种特例，其中顶层是一个确定性计数器，底层是一个常规HMM，只有在计数器“超时”后才能改变状态。更多细节请参见 [MP01]。

## 29.5.3 因子HMM

HMM使用单个离散随机变量 \(z_t \in \{1, \dots, K\}\) 来表示隐藏状态。表示10比特信息需要 \(K = 2^{10} = 1024\) 个状态。相比之下，考虑隐藏状态的**分布式表示**，其中每个 \(z_{t,m} \in \{0, 1\}\) 表示第 \(t\) 个隐藏状态的第 \(m\) 比特。现在我们可以仅使用10个二进制变量来表示10比特。该模型称为因子HMM [GJ97]。

更精确地说，模型定义如下：

\(p(\mathbf{z}, \mathbf{y}) = \prod_t \left[ \prod_m p(z_{tm} | z_{t-1, m}) \right] p(\mathbf{y}_t | \mathbf{z}_t)\)  (29.58)

其中 \(p(z_{tm} = k | z_{t-1, m} = j) = A_{mjk}\) 是链 \(m\) 转移矩阵中的一个元素，\(p(z_{1m} = k | z_{0m}) = p(z_{1m} = k) = \pi_{mk}\) 是链 \(m\) 的初始状态分布，且

\(p(\mathbf{y}_t | \mathbf{z}_t) = \mathcal{N} \left( \mathbf{y}_t | \sum_{m=1}^M \mathbf{W}_m \mathbf{z}_{tm}, \boldsymbol{\Sigma} \right)\)  (29.59)

是观测模型，其中 \(\mathbf{z}_{tm}\) 是 \(z_{tm}\) 的1-of-\(K\) 编码，\(\mathbf{W}_m\) 是一个 \(D \times K\) 矩阵（假设 \(\mathbf{y}_t \in \mathbb{R}^D\)）。图29.19a说明了 \(M = 3\) 时的模型。

FHMM的一个有趣应用是**能量解聚**问题 [KJ12]。在此问题中，我们观察房屋在每个时刻的总能耗，即观测模型形式为

\(p(y_t | \mathbf{z}_t) = \mathcal{N} (y_t | \sum_{m=1}^M w_m z_{tm}, \sigma^2)\)  (29.60)

其中 \(w_m\) 是设备 \(m\) 使用的能量量，若设备 \(m\) 在时间 \(t\) 被使用则 \(z_{tm} = 1\)，否则 \(z_{tm} = 0\)。转移模型假设为

\(p(z_{t,m} = 1 | z_{t-1, m}) = \begin{cases} A_{01} & \text{if } z_{t-1, m} = 0 \\ A_{11} & \text{if } z_{t-1, m} = 1 \end{cases}\)  (29.61)

我们不知道每个时间步哪些设备被打开（即，\(z_{tm}\) 是隐藏的），但通过对FHMM随时间进行推断，我们可以将总能量分解为各部分，从而确定哪些设备耗电最多。

## 29.5.4 耦合HMM

如果我们有多个相关数据流，可以使用**耦合HMM** [Bra96]。这是一系列HMM，其中状态转换取决于邻近链的状态。也就是说，我们将每个时间片的条件分布表示为

\(p(\boldsymbol{z}_t, \boldsymbol{y}_t | \boldsymbol{z}_{t-1}) = \prod_m p(\boldsymbol{y}_{tm} | z_{tm}) p(z_{tm} | \boldsymbol{z}_{t-1, m-1:m+1})\) (29.62)

边界条件以明显的方式定义。关于 \(M=3\) 链的示例，请参见第29.5.4节。

耦合HMM已用于各种任务，例如**音频-视觉语音识别** [Nef+02]、高速公路交通流建模 [KM00]以及人与人之间对话互动建模 [Bas+01]。

然而，该模型有两个缺点。首先，精确推断需要 \(O(T(K^M)^2)\)，与因子HMM相同；然而，在实践中这通常不是问题，因为 \(M\) 通常很小。其次，如果有 \(M\) 条链且每条链有 \(K\) 个状态，则该模型需要 \(O(MK^4)\) 个参数来指定，因为每个状态不仅取决于其自身的历史，还取决于其两个邻居的历史。有一种密切相关的模型，称为**影响模型** [Asa00]，它通过计算成对转移矩阵的凸组合来使用更少的参数。

## 29.5.6 变点检测

本节讨论变点检测，即检测时间序列中观测值分布何时发生“突变”的任务。我们关注在线情况。（关于此问题的离线方法综述，见例如 [AC17; TOV18]。（另见 [BW20]，对各种方法进行了最近的实证评估，重点关注一维时间序列情况。）我们讨论的方法原则上可用于高维时间序列分割。我们的起点是第29.5.1节讨论的隐含半马尔可夫模型（HSMM）。这类似于HMM，但我们显式建模每个状态中花费的持续时间。通过将隐状态 \(z_t\) 与持续时间变量 \(d_t\) 增广来实现，\(d_t \) 根据持续时间分布初始化，\(d_t \sim D_{z_t}(\cdot)\)，然后倒计数至1。另一种方法是添加一个变量 \(r_t \in \{0, 1, \dots\}\)，它对当前状态进行运行长度编码；每当创建新段时，它从0开始，然后每步加一。转移动态指定为

$$
p(r_t|r_{t-1}) = \begin{cases} H(r_{t-1} + 1) & \text{if } r_t = 0 \\ 1 - H(r_{t-1} + 1) & \text{if } r_t = r_{t-1} + 1 \\ 0 & \text{otherwise} \end{cases} \quad (29.63)
$$

图29.21: 贝叶斯在线变点检测（BOCPD）示意图。(a) 一维时间序列基于均值的变点分成三个段（长度分别为 \(g_1 = 4\)、\(g_2 = 6\)、\(g_3\) 长度未定，因为第三段尚未结束）的假设分割。来自 [AM07] 的图1。感谢Ryan Adams允许使用。

其中 \(H(\tau)\) 是危险函数：

\(H(\tau) = \frac{p_g(\tau)}{\sum_{t=\tau}^{\infty} p_g(t)}\) (29.64)

其中 \(p_g(t)\) 是长度为 \(t\) 的段的概率。参见图29.21以示说明。如果将 \(p_g \) 设置为参数为 \(\lambda\) 的几何分布，则危险函数为常数 \(H(\tau) = 1/\lambda\)。

运行长度表示的优势在于，我们可以以因果方式（仅依赖过去数据）定义段的观测模型：

\(p(\mathbf{y}_t | \mathbf{y}_{1:t-1}, r_t = r, z_t = k) = p(\mathbf{y}_t | \mathbf{y}_{t-r:t-1}, z_t = k) = \int p(\mathbf{y}_t | \boldsymbol{\eta}) p(\boldsymbol{\eta} | \mathbf{y}_{t-r:t-1}, z_t = k) d\boldsymbol{\eta}\) (29.65)

其中 \(\boldsymbol{\eta}\) 是该段“局部”的参数。这被称为段的**基础预测模型**或**UPM**。UPM参数的后验由以下给出

\(p(\boldsymbol{\eta} | \mathbf{y}_{t-r:t-1}, z_t = k) \propto p(\boldsymbol{\eta} | z_t = k) \prod_{i=t-r}^{t-1} p(\mathbf{y}_i | \boldsymbol{\eta})\) (29.66)

其中我们使用由状态 \(k \) 选择的超参数来初始化 \(\boldsymbol{\eta} \) 的先验。如果模型是共轭指数型，我们可以以封闭形式计算此边缘似然，并得到

\(\pi_t^{r,k} = p(\mathbf{y}_t | \mathbf{y}_{t-r:t-1}, z_t = k) = p(\mathbf{y}_t | \psi_t^{r,k})\) (29.67)

其中 \(\psi_t^{r,k}\) 是基于最后 \(r \) 个观测值（并使用来自状态 \(k \) 的先验）在时间 \(t \) 的后验预测分布的参数。

在特殊情况下，如果我们有 \(K = 1 \) 个隐状态，则每个段独立建模，我们得到一个**乘积分区模型** [BH92]：

\(p(\mathbf{y} | \mathbf{r}) = p(\mathbf{y}_{s_1:e_1}) \dots p(\mathbf{y}_{s_N:e_N})\) (29.68)

其中 \(s_i \) 和 \(e_i \) 分别是段 \(i \) 的开始和结束，可以从运行长度 \(\mathbf{r} \) 计算得出。（我们初始化为 \(r_0 = 0\)。）因此，段之间没有信息共享。这可以是
