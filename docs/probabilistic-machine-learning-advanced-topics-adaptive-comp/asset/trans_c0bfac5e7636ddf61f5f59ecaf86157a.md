
满足 $\mathbf{Q}_t$ 的任何稀疏约束。此外，我们可以一次执行 $k$ 步的推理，通过预测

\(p_\theta(\boldsymbol{x}_{t-k}|\boldsymbol{x}_t) \propto \sum_{\tilde{\boldsymbol{x}}_0} q(\boldsymbol{x}_{t-k}|\boldsymbol{x}_t, \tilde{\boldsymbol{x}}_0)\tilde{p}_\theta(\tilde{\boldsymbol{x}}_0|\boldsymbol{x}_t)\) (25.77)

注意，在多步高斯情况下，我们需要更复杂的模型来处理多峰性（参见第 25.5.2 节）。相比之下，离散分布已经内置了这种灵活性。

### 25.7.4 噪声调度

在本节中，我们讨论如何为 \(\beta_t$ 选择噪声调度。对于离散化高斯扩散，[Aus+21] 提议在离散化步骤前线性增加高斯噪声的方差。对于均匀扩散，我们可以使用形式为 \(\alpha_t = \cos(\frac{t/T+s}{1+s}\frac{\pi}{2})\) 的余弦调度，其中 \(s = 0.08$，如 [ND21] 所提议。（回顾 \(\beta_t = 1 - \alpha_t$，因此噪声随时间增加。）对于掩码扩散，我们可以使用形式为 \(\beta_t = 1/(T - t + 1)$ 的调度，如 [SD+15b] 所提议。

### 25.7.5 与离散序列其他概率模型的联系

D3PM 与其他概率文本模型之间存在有趣的联系。例如，假设我们将转换矩阵定义为均匀转换矩阵和吸收 MASK 状态的组合，即，\(\mathbf{Q} = \alpha \mathbf{1}\mathbf{e}_m^\top + \beta \mathbf{1}\mathbf{1}^\top/K + (1 - \alpha - \beta)\mathbf{I}\)。对于一个一步扩散过程，其中 \(q(\boldsymbol{x}_1|\boldsymbol{x}_0)$ 将 \(\alpha = 10\%\) 的标记替换为 MASK，并且 \(\beta = 5\%\) 均匀随机，我们恢复了用于训练 **BERT** 语言模型的相同目标，即

\(L_0(\boldsymbol{x}_0) = -\mathbb{E}_{q(\boldsymbol{x}_1|\boldsymbol{x}_0)} \log p_\theta(\boldsymbol{x}_0|\boldsymbol{x}_1)\) (25.78)

（这是因为 \(L_T = 0$，并且方程 (25.27) 的变分界中没有使用其他时间步。）

现在考虑一个确定性逐个掩码标记的扩散过程。对于长度为 \(N = T$ 的序列，如果 \(i < N - t$（直通），则 \(q([\boldsymbol{x}_t]_i|\boldsymbol{x}_0) = [\boldsymbol{x}_0]_i$，否则 \([\boldsymbol{x}_t]_i$ 设置为 MASK。由于这是一个确定性过程，后验 \(q(\boldsymbol{x}_{t-1}|\boldsymbol{x}_t, \boldsymbol{x}_0)$ 是在 \(\boldsymbol{x}_t$ 上的一个狄拉克 δ 函数，其中掩码标记少一个。接着可以证明 KL 项变为 \(D_\text{KL}(q([\boldsymbol{x}_t]_i|\boldsymbol{x}_t, \boldsymbol{x}_0) \parallel p_\theta([\boldsymbol{x}_{t-1}]_i|\boldsymbol{x}_t)) = -\log p_\theta([\boldsymbol{x}_0]_i|\boldsymbol{x}_t)$，这是自回归模型的标准交叉熵损失。

最后可以证明，生成式 **掩码语言模型**（如 [WC19; Gha+19]）也对应于离散扩散过程：序列从所有位置被掩码开始，每一步，给定前一序列生成一组标记。[Cha+22] 的 **MaskGIT** 方法在应用向量量化到图像补丁后，在图像领域使用类似程序。这些并行迭代解码器比顺序自回归解码器快得多。请参见图 25.17 以示例说明。

## 26 生成对抗网络

*本章由 Mihaela Rosca、Shakir Mohamed 和 Balaji Lakshminarayanan 撰写。*

### 26.1 简介

在本章中，我们关注 **隐式生成模型**，这是一种没有显式似然函数的概率模型 [ML16]。这包括 **生成对抗网络** 或 **GANs** [Goo16] 家族。在本章中，我们对该主题进行了介绍，重点从概率角度阐述。

为了为 GAN 发展概率公式，首先区分两种概率模型很有用：**“规定概率模型”** 和 **“隐式概率模型”** [DG84]。我们将称之为 **显式概率模型** 的规定概率模型，对观测随机变量 $x$ 的分布提供显式参数化规范，并指定带有参数 $\theta$ 的对数似然函数 $\log q_\theta(x)$。本书迄今遇到的大多数模型都是这种形式，无论是最先进的分类器、大词汇量序列模型还是精细时空模型。或者，我们可以指定一个 **隐式概率模型**，它定义了直接生成数据的随机过程。此类模型是气候与天气、种群遗传学和生态学问题的自然方法，因为对这类系统的机制理解可以直接用于描述生成模型。我们在图 26.1 中说明了隐式模型和显式模型之间的区别。

本章关注的隐式生成模型形式可以表示为概率隐变量模型，类似于 VAEs（第 21 章）。隐式生成模型使用隐变量 $z$，并使用参数 $\theta$ 将其通过确定性函数 $G_\theta$ 变换，该函数从 $\mathbb{R}^m \rightarrow \mathbb{R}^d$ 映射。隐式生成模型不包括似然函数或观测模型。相反，生成过程在输出空间上定义了一个有效密度，从而构成有效似然函数：

```
$x = G_\theta(z'); \quad z' \sim q(z)$ (26.1)

\(q_\theta(x) = \frac{\partial}{\partial x_1} \cdots \frac{\partial}{\partial x_d} \int_{\{G_\theta(z) \le x\}} q(z)dz,\) (26.2)
```

其中 $q(z)$ 是隐变量的分布，提供外部随机源。方程 (26.2) 是转换密度 $q_\theta(x)$ 的定义，定义为累积分布函数的导数，因此对由集合 $\{G_\theta(z) \le x\}$ 定义的所有事件积分分布 $q(z)$。当隐变量和数据维度相等（$m = d$）且函数 $G_\theta(z)$ 可逆或具有易于表征的根时，我们恢复了概率分布变换的规则。这种变量变换属性也用于归一化流（第 23 章）。在扩散模型（第 25 章）中，我们也将噪声转换为数据及其反向，但变换不是严格可逆的。

图 26.1：可视化规定生成模型与隐式生成模型之间的区别。规定模型直接访问学习到的密度（有时是未归一化的）。隐式模型只能访问模拟器，该模拟器可用于从隐含密度生成样本。由 genmo_types_implicit_explicit.ipynb 生成

我们可以开发更通用、更灵活的隐式生成模型，其中函数 $G$ 是一个 $d > m$ 的非线性函数，例如由深度网络指定。此类模型有时被称为生成器网络或生成神经采样器；它们也可以被视为可微模拟器。不幸的是，在这类模型中积分 (26.2) 是不可处理的，我们甚至可能无法确定集合 $\{G_\theta(z) \le x\}$。当然，不可处理性也是 VAEs（第 21 章）等显式隐变量模型的挑战，但在 GAN 的情况下，缺乏似然项使学习问题更加困难。因此，此问题称为无似然推断或基于仿真的推断。

无似然推断也构成了称为近似贝叶斯计算（ABC）的领域的基础，我们将在第 13.6.5 节简要讨论。ABC 和 GAN 为我们提供了两种不同的算法框架，用于隐式生成模型的学习。两种方法都依赖于基于比较真实数据和模拟数据的学习原则。这种比较学习体现了无似然推断的核心原则，而扩展这一想法是下一节的重点。随后的章节将专门关注 GAN，以发展更详细的基础和实际注意事项。（另见 https://poloclub.github.io/ganlab/ 以获取交互式教程。）
