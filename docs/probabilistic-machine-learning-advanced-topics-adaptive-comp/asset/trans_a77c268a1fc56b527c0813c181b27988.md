取决于输入，即 Z = phi(XW(X))，其中 W(X) 是下文定义的函数。这种乘积交互称为注意力。

通过将注意力与非参数核心预测方法（如高斯过程（第 18 章））进行比较，我们可以更好地理解注意力。在此方法中，我们使用核将输入查询 x ∈ R^d 与每个训练样本 X = (x_1, ..., x_n) 进行比较，得到相似度得分向量 alpha = [K(x, x_i)]_{i=1}^n。然后，我们使用此向量来检索相应的 m 个目标值 y_i ∈ R^d_v 的加权组合，以计算预测输出，如下所示：

```
\hat{y} = \sum_{i=1}^n \alpha_i y_i
```

详情见第 18.3.7 节。

我们可以按如下方式构建该方法的可微分参数化版本（详情见 [Tsa+19]）。首先，我们将存储的示例矩阵 X 替换为学习嵌入，以创建一组存储的键 K = X W_k ∈ R^{n × d_k}。同样，我们将存储的输出矩阵 Y 替换为学习嵌入，以创建一组存储的值 V = Y W_v ∈ R^{n × d_v}。最后，我们将输入嵌入以创建查询 q = W_q x ∈ R^{d_k}。需要学习的参数是三个嵌入矩阵。

接下来，我们使用软注意力层替换固定核函数。更准确地说，我们为查询 q 定义加权输出如下：

```
Attn(q, (k_1, v_1), ..., (k_n, v_n)) = Attn(q, (k_{1:n}, v_{1:n})) = \sum_{i=1}^n \alpha_i(q, k_{1:n}) v_i
```

其中 alpha_i(q, k_{1:n}) 为第 i 个注意力权重；这些权重对每个 i 满足 0 <= alpha_i(q, k_{1:n}) <= 1，且 sum_i alpha_i(q, k_{1:n}) = 1。

注意力权重可以通过注意力得分函数 a(q, k_i) ∈ R 计算得出，该函数计算查询 q 与键 k_i 的相似度。例如，我们可以使用（缩放）点积注意力，其形式为

```
a(q, k) = q^T k / sqrt{d_k}
```

（对 \(\sqrt{d_k}\) 进行缩放是为了减小输出对向量维度的依赖。）

给定得分后，我们可以使用 softmax 函数计算注意力权重：

\(\alpha_i(\boldsymbol{q}, \boldsymbol{k}_{1:n}) = \text{softmax}_i([a(\boldsymbol{q}, \boldsymbol{k}_1), \dots, a(\boldsymbol{q}, \boldsymbol{k}_n)]) = \frac{\exp(a(\boldsymbol{q}, \boldsymbol{k}_i))}{\sum_{j=1}^n \exp(a(\boldsymbol{q}, \boldsymbol{k}_j))}\) (16.10)

示意图见图 16.6。

在某些情况下，我们希望将注意力限制在词典的子集中，对应有效条目。例如，我们可能希望将序列填充到固定长度（以便高效小批处理），在这种情况下，我们应该对填充位置进行“掩码”。这称为**掩码注意力**。我们可以通过将掩码条目的注意力得分设置为很大的负数（例如 \(-10^6\)）来高效实现这一点，从而使相应的 softmax 权重为 0。

为了提高效率，我们通常并行计算所有 \(n\) 个向量。设查询、键和值的相应矩阵分别表示为 \(\mathbf{Q} \in \mathbb{R}^{n \times d_k}\)、\(\mathbf{K} \in \mathbb{R}^{n \times d_k}\)、\(\mathbf{V} \in \mathbb{R}^{n \times d_v}\)。令

\(\boldsymbol{z}_j = \sum_{i=1}^n \alpha_i(\boldsymbol{q}_j, \mathbf{K}) \boldsymbol{v}_i\) (16.11)

为与第 j 个查询对应的第 j 个输出。我们可以并行使用以下公式计算所有输出 \(\mathbf{Z} \in \mathbb{R}^{n \times d_v}\)：

\(\mathbf{Z} = \text{Attn}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}})\mathbf{V}\) (16.12)

其中 softmax 函数按行应用。示意图见图 16.7（左）。

为了提高模型的灵活性，我们通常使用**多头注意力**层，如图 16.7（右）所示。令第 i 个头为

\(\boldsymbol{h}_i = \text{Attn}(\mathbf{Q}\mathbf{W}_i^Q, \mathbf{K}\mathbf{W}_i^K, \mathbf{V}\mathbf{W}_i^V)\) (16.13)

其中 \(\mathbf{W}_i^Q \in \mathbb{R}^{d \times d_k}\)、\(\mathbf{W}_i^K \in \mathbb{R}^{d \times d_k}\) 和 \(\mathbf{W}_i^V \in \mathbb{R}^{d \times d_v}\) 是线性投影矩阵。我们定义 MHA 层的输出为

\(\mathbf{Z} = \text{MHA}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{Concat}(\boldsymbol{h}_1, \dots, \boldsymbol{h}_h)\mathbf{W}^O\) (16.14)

其中 \(h\) 为头数，且 \(\mathbf{W}^O \in \mathbb{R}^{hd_v \times d}\)。使用多头可以提高层的性能，尤其是在某些权重矩阵初始化不佳的情况下；训练后，我们通常可以移除除一个头以外的所有头 [MLN19]。

当一个注意力层的输出用作另一个层的输入时，该方法称为**自注意力**。这是 Transformer 模型的基础，我们将在第 16.3.5 节中讨论。

### 16.2.8 循环层

我们可以通过将输入 \(\boldsymbol{x}\) 与当前状态 \(\boldsymbol{s}_t\) 相结合，然后使用某种函数计算输出和新状态，使模型具有**状态性**：

\((\boldsymbol{y}, \boldsymbol{s}_{t+1}) = f(\boldsymbol{x}, \boldsymbol{s}_t)\) (16.15)

这称为**循环层**，如图 16.8 所示。这是**循环神经网络**的基础，将在第 16.3.4 节中讨论。在标准 RNN 中，函数 \(f\) 是一个简单的 MLP，但也可能使用注意力（第 16.2.7 节）。

### 16.2.9 乘积层

在本节中，我们讨论**乘积层**，它们对组合不同信息源很有用。我们的介绍遵循 [Jay+20]。

假设我们有输入 \(\boldsymbol{x} \in \mathbb{R}^n\) 和 \(\boldsymbol{z} \in \mathbb{R}^m\)。在线性层中（以及推广到卷积层中），通常将输入拼接得到 \(f(\boldsymbol{x}, \boldsymbol{z}) = \mathbf{W}[\boldsymbol{x}; \boldsymbol{z}] + \boldsymbol{b}\)，其中 \(\mathbf{W} \in \mathbb{R}^{k \times (m+n)}\) 且 \(\boldsymbol{b} \in \mathbb{R}^k\)。我们可以通过使用**乘积交互**（如以下**双线性形式**）来增强模型的表达能力：

\(f(\boldsymbol{x}, \boldsymbol{z}) = \boldsymbol{z}^{\mathsf{T}} \mathbb{W} \boldsymbol{x} + \mathbf{U} \boldsymbol{z} + \mathbf{V} \boldsymbol{x} + \boldsymbol{b}\) (16.16)

其中 \(\mathbb{W} \in \mathbb{R}^{m \times n \times k}\) 是一个权重张量，定义方式使得

\((\boldsymbol{z}^{\mathsf{T}} \mathbb{W} \boldsymbol{x})_k = \sum_{ij} z_i \mathbb{W}_{ijk} x_j\) (16.17)

也就是说，输出的第 k 个条目是 \(\boldsymbol{z}\) 和 \(\boldsymbol{x}\) 的加权内积，其中权重矩阵是 \(\mathbb{W}\) 的第 k 个“切片”。其他参数的大小为 \(\mathbf{U} \in \mathbb{R}^{k \times m}\)、\(\mathbf{V} \in \mathbb{R}^{k \times n}\) 和 \(\boldsymbol{b} \in \mathbb{R}^k\)。

该表述包含许多有趣的特例。特别是，**超网络** [HDL17] 可以以这种方式看待。超网络是一个为另一个神经网络生成参数的神经网络。特别是，我们将 \(f(\boldsymbol{x}; \boldsymbol{\theta})\) 替换为 \(f(\boldsymbol{x}; g(\boldsymbol{z}; \boldsymbol{\phi}))\)。如果 \(f\) 和 \(g\) 是仿射的，则这等价于一个乘积层。要理解这一点，令 \(\mathbf{W}' = \boldsymbol{z}^{\mathsf{T}} \mathbb{W} + \mathbf{V}\) 和 \(\boldsymbol{b}' = \mathbf{U} \boldsymbol{z} + \boldsymbol{b}\)。如果我们定义 \(g(\boldsymbol{z}; \boldsymbol{\Phi}) = [\mathbf{W}', \boldsymbol{b}']\) 和 \(f(\boldsymbol{x}; \boldsymbol{\theta}) = \mathbf{W}' \boldsymbol{x} + \boldsymbol{b}'\)，则恢复方程 (16.16)。

我们还可以将 RNN 中使用的门控层（第 16.3.4 节）视为一种乘积交互。特别是，如果超网络计算对角矩阵 \(\mathbf{W}' = \sigma(\boldsymbol{z}^{\mathsf{T}} \mathbb{W} + \mathbf{V}) = \text{diag}(a_1, \dots, a_n)\)，则我们可以定义 \(f(\boldsymbol{x}, \boldsymbol{z}; \boldsymbol{\theta}) = \boldsymbol{a}(\boldsymbol{z}) \odot \boldsymbol{x}\)，这是标准门控机制。

注意力机制（第 16.2.7 节）也是一种乘积交互，尽管它们涉及查询、键和值之间的三向交互。

另一种变体出现在超网络仅为卷积层的每个通道计算一个标量权重加上一个偏置项的情况：

\(f(\boldsymbol{x}, \boldsymbol{z}) = \boldsymbol{a}(\boldsymbol{z}) \odot \boldsymbol{x} + \boldsymbol{b}(\boldsymbol{z})\) (16.18)
