## 9.2.3 前向-后向算法

在本节中，我们介绍了 HMM 平滑中最常见的方法，即前向-后向或 FB 算法 [Rab89]。在前向传递中，我们像以前一样计算 \(\alpha_t(j) = p(\boldsymbol{z}_t = j | \boldsymbol{y}_{1:t})\)。在后向传递中，我们计算条件似然

```
\beta_t(j) \triangleq p(\boldsymbol{y}_{t+1:T} | \boldsymbol{z}_t = j)
```

然后我们使用以下方法组合它们

```
\gamma_t(j) = p(z_t = j | y_{t+1:T}, y_{1:t}) \propto p(z_t = j, y_{t+1:T} | y_{1:t}) = p(z_t = j | y_{1:t}) p(y_{t+1:T} | z_t = j, y_{1:t}) = \alpha_t(j) \beta_t(j)
```

在矩阵记法中，这变为

```
\gamma_t = \text{normalize}(\alpha_t \odot \beta_t)
```

请注意，前向和后向传递可以独立计算，但两者都需要访问局部证据 $p(y_t | z_t)$。结果仅在最后组合。因此这被称为 **双滤波平滑** [Kit04]。

### 9.2.3.1 后向递归

我们可以按从右到左的方式递归计算 $\beta$ 值，如下所示

```
\beta_{t-1}(i) = p(y_{t:T} | z_{t-1} = i)
= \sum_j p(z_t = j, y_t, y_{t+1:T} | z_{t-1} = i)
= \sum_j p(y_{t+1:T} | z_t = j, y_t, z_{t-1} = i) p(z_t = j, y_t | z_{t-1} = i)
= \sum_j p(y_{t+1:T} | z_t = j) p(y_t | z_t = j, z_{t-1} = i) p(z_t = j | z_{t-1} = i)
= \sum_j \beta_t(j) \lambda_t(j) A_{i,j}
```

我们可以将结果方程写成矩阵-向量形式

```
\beta_{t-1} = \mathbf{A}(\lambda_t \odot \beta_t)
```

基本情况是

```
\beta_T(i) = p(y_{T+1:T} | z_T = i) = p(\emptyset | z_T = i) = 1
```

这是非事件的概率。

请注意，$\beta_t$ 不是状态上的概率分布，因为它不需要满足 $\sum_j \beta_t(j) = 1$。但是，我们通常对其进行归一化以避免数值下溢（见第 9.2.3.4 节）。

### 9.2.3.3 双切片平滑边缘分布

我们可以使用前向-后向算法的输出计算双切片边缘分布，如下所示

```
p(z_t, z_{t+1}|y_{1:T}) = p(z_t, z_{t+1}|y_{1:t}, y_{t+1:T})
\propto p(y_{t+1:T}|z_t, z_{t+1}, y_{1:t})p(z_t, z_{t+1}|y_{1:t})
= p(y_{t+1:T}|z_{t+1})p(z_t, z_{t+1}|y_{1:t})
= p(y_{t+1:T}|z_{t+1})p(z_t|y_{1:t})p(z_{t+1}|z_t)
= p(y_{t+1}, y_{t+2:T}|z_{t+1})p(z_t|y_{1:t})p(z_{t+1}|z_t)
= p(y_{t+1}|z_{t+1})p(y_{t+2:T}|z_{t+1}, y_{t+1})p(z_t|y_{1:t})p(z_{t+1}|z_t)
= p(y_{t+1}|z_{t+1})p(y_{t+2:T}|z_{t+1})p(z_t|y_{1:t})p(z_{t+1}|z_t)
```

我们可以用已计算的量来重写此式，如下所示

```
\xi_{t,t+1}(i, j) \propto \lambda_{t+1}(j)\beta_{t+1}(j)\alpha_t(i)A_{i,j}
```

或者用矩阵-向量形式

```
\xi_{t,t+1} \propto \mathbf{A} \circ [\alpha_t(\lambda_{t+1} \odot \beta_{t+1})^T]
```

由于 \alpha_t \propto \lambda_t \circ \alpha_{t|t-1}，我们也可以将上述方程写成如下形式

```
\xi_{t,t+1} \propto \mathbf{A} \circ [(\lambda_t \odot \alpha_{t|t-1}) \circ (\lambda_{t+1} \odot \beta_{t+1})^T]
```

这可以解释为入站消息与局部因子的乘积，如图 9.4 所示。具体而言，我们组合因子 \alpha_{t|t-1} = p(z_t|y_{1:t-1})、\mathbf{A} = p(z_{t+1}|z_t)、\lambda_t \propto p(y_t|z_t)、\lambda_{t+1} \propto p(y_{t+1}|z_{t+1}) 和 \beta_{t+1} \propto p(y_{t+2:T}|z_{t+1}) 来得到 p(z_t, z_{t+1}, y_t, y_{t+1}, y_{t+2:T}|y_{1:t-1})，然后我们可以对其进行归一化。

### 9.2.3.4 数值稳定的实现

在大多数关于 HMM 的出版物中，例如 [Rab89]，前向消息被定义为以下未归一化的 *联合* 概率

```
\alpha'_t(j) = p(z_t = j, y_{1:t}) = \lambda_t(j) \left[ \sum_i \alpha'_{t-1}(i) A_{i,j} \right] \tag{9.30}
```

我们定义前向消息为归一化的 *条件* 概率

```
\alpha_t(j) = p(z_t = j | y_{1:t}) = \frac{1}{Z_t} \lambda_t(j) \left[ \sum_i \alpha_{t-1}(i) A_{i,j} \right] \tag{9.31}
```

未归一化（联合）形式存在多个问题。首先，由于联合事件 \((z_t = j, y_{1:t})\) 的概率极小，它很快会遭受数值下溢。1 其次，它不太容易解释，因为它不是状态上的分布。第三，它阻止了使用试图近似后验分布的近似推断方法（我们稍后将看到这些方法）。因此，我们始终使用归一化（条件）形式。

当然，两个定义仅相差一个乘法常数，因为 \(p(z_t = j | y_{1:t}) = p(z_t = j, y_{1:t}) / p(y_{1:t})\) [Dev85]。因此，*算法差异* 仅仅是一行代码（即是否调用 `normalize` 函数）。尽管如此，我们认为呈现归一化版本更好，因为这将鼓励读者正确实现该方法（即每一步后都进行归一化以避免下溢）。

在实践中，计算证据的对数概率 \(\ell_t(j) = \log p(y_t | z_t = j)\) 比计算概率 \(\lambda_t(j) = p(y_t | z_t = j)\) 更具数值稳定性。我们可以使用 log-sum-exp 技巧将状态条件对数似然 \(\lambda_t(j)\) 与状态先验 \(p(z_t = j | y_{1:t-1})\) 结合起来，如方程 (28.30) 所示。

## 9.2.4 前向过滤后向平滑

执行离线平滑的另一种方法是使用前向过滤/后向平滑，如第 8.1.3 节所讨论。在这种方法中，我们首先执行前向或过滤传递，然后通过从右（时间 \(t = T\)）向左（\(t = 1\)）反向计算来得到平滑信念状态。这种方法广泛用于具有连续隐藏状态的 SSM，因为第 9.2.3 节中使用的后向似然 \(\beta_t(i)\) 在状态空间不是离散时并不总是定义明确。

我们通过归纳假设已经计算了

```
\gamma_{t+1}(j) \triangleq p(z_{t+1} = j | y_{1:T}) \tag{9.32}
```

1. 例如，如果观测与状态独立，则有 \(p(z_t = j, y_{1:t}) = p(z_t = j) \prod_{i=1}^t p(y_i)\)，随着 \(t\) 增大会呈指数级变小。
