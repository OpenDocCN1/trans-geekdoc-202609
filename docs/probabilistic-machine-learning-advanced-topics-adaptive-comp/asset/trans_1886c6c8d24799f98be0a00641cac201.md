### 6.6.3.3 上置信边界（UCB）

另一种方法是，在某个置信水平 \(\beta_n\) 下计算函数的 **上置信边界** 或 **UCB**，然后定义采集函数如下：\(\alpha_{UCB}(\boldsymbol{x}; \mathcal{D}_n) = \mu_n(\boldsymbol{x}) + \beta_n \sigma_n(\boldsymbol{x})\)。这与 34.4.5 节讨论的上下文盗贼设置相同，只不过我们是在 \(\boldsymbol{x} \in \mathcal{X}\) 上进行优化，而不是在有限的拉臂集合 \(a \in \{1, \dots, A\}\) 上优化。如果我们使用 GP 作为代理模型，该方法称为 **GP-UCB** [Sri+10]。

### 6.6.3.4 汤普森采样

我们在 34.4.6 节中在多臂盗贼的背景下讨论了 **汤普森采样**，其中状态空间是有限的，\(\mathcal{X} = \{1, \dots, A\}\)，采集函数 \(\alpha(a; \mathcal{D}_n)\) 对应于拉臂 \(a\) 是最佳拉臂的概率。我们可以使用以下公式将其推广到实值输入空间 \(\mathcal{X}\)：

```
$$\alpha(\boldsymbol{x}; \mathcal{D}_n) = \mathbb{E}_{p(\boldsymbol{\theta}|\mathcal{D}_n)} \left[ \mathbb{I} \left( \boldsymbol{x} = \underset{\boldsymbol{x}'}{\text{argmax}} f_{\boldsymbol{\theta}}(\boldsymbol{x}') \right) \right]$$ (6.179)
```

我们可以通过采样 \(\tilde{\boldsymbol{\theta}} \sim p(\boldsymbol{\theta}|\mathcal{D}_n)\) 来计算该积分的单样本近似。然后可以按如下方式选择最优动作：

```
$$\boldsymbol{x}_{n+1} = \underset{\boldsymbol{x}}{\text{argmax}} \alpha(\boldsymbol{x}; \mathcal{D}_n) = \underset{\boldsymbol{x}}{\text{argmax}} \mathbb{I} \left( \boldsymbol{x} = \underset{\boldsymbol{x}'}{\text{argmax}} f_{\tilde{\boldsymbol{\theta}}}(\boldsymbol{x}') \right) = \underset{\boldsymbol{x}}{\text{argmax}} f_{\tilde{\boldsymbol{\theta}}}(\boldsymbol{x})$$ (6.180)
```

换句话说，我们贪婪地最大化采样的代理模型。

对于连续空间，汤普森采样比在盗贼情况下更难应用，因为我们无法直接从采样函数中计算出最佳“拉臂” \(\boldsymbol{x}_{n+1}\)。此外，使用 GP 时，采样函数（而非参数代理模型的参数）存在一些微妙的技术难点（讨论见 [HLHG14]）。

### 6.6.3.5 熵搜索

由于 BayesOpt 的目标是找到 \(\boldsymbol{x}^* = \text{argmax}_{\boldsymbol{x}} f(\boldsymbol{x})\)，因此试图直接最小化我们对 \(\boldsymbol{x}^*\) 位置的不确定性是有道理的，我们将其表示为 \(p_*(\boldsymbol{x}|\mathcal{D}_n)\)。因此我们将效用定义如下：

```
$$U(\boldsymbol{x}, y; \mathcal{D}_n) = \mathbb{H}(\boldsymbol{x}^*|\mathcal{D}_n) - \mathbb{H}(\boldsymbol{x}^*|\mathcal{D}_n \cup \{(\boldsymbol{x}, y)\})$$ (6.181)
```

其中 \(\mathbb{H}(\boldsymbol{x}^*|\mathcal{D}_n = \mathbb{H}(p_*(\boldsymbol{x}|\mathcal{D}_n))\) 是关于最优值位置的后验分布的熵。这被称为信息增益准则；它与主动学习中使用的目标不同之处在于，这里我们希望获取关于 \(\boldsymbol{x}^*\) 的信息，而不是关于所有 \(\boldsymbol{x}\) 的 \(f\) 信息。相应的采集函数如下：

```
$$\alpha_{ES}(\boldsymbol{x}; \mathcal{D}_n) = \mathbb{E}_{p(y|\boldsymbol{x},\mathcal{D}_n)} [U(\boldsymbol{x}, y; \mathcal{D}_n)] = \mathbb{H}(\boldsymbol{x}^*|\mathcal{D}_n) - \mathbb{E}_{p(y|\boldsymbol{x},\mathcal{D}_n)} [\mathbb{H}(\boldsymbol{x}^*|\mathcal{D}_n \cup \{(\boldsymbol{x}, y)\})]$$ (6.182)
```

这被称为 **熵搜索** [HS12]。

不幸的是，计算 \(\mathbb{H}(\boldsymbol{x}^*|\mathcal{D}_n)\) 是困难的，因为它需要对输入空间建立概率模型。幸运的是，我们可以利用互信息的对称性，将方程 (6.182) 中的采集函数改写如下：

```
$$\alpha_{PES}(\boldsymbol{x}; \mathcal{D}_n) = \mathbb{H}(y|\mathcal{D}_n, \boldsymbol{x}) - \mathbb{E}_{\boldsymbol{x}^*|\mathcal{D}_n} [\mathbb{H}(y|\mathcal{D}_n, \boldsymbol{x}, \boldsymbol{x}^*)]$$ (6.183)
```

其中，我们可以使用汤普森采样从 \(p(\boldsymbol{x}^*|\mathcal{D}_n)\) 近似期望。现在我们只需对输出空间 \(y\) 的不确定性建模即可。这被称为 **预测熵搜索** [HLHG14]。

### 6.6.3.6 知识梯度

迄今我们考虑的采集函数都是贪婪的，因为它们只着眼于下一步。[FPD09] 提出的 **知识梯度** 采集函数会向前看两步，考虑如果我们查询 \(\boldsymbol{x}\)、更新后验，然后根据新的信念最大化所获得的知识，可能带来的改进。更准确地说，让我们定义如果查询一个额外点，可以找到的最佳值：

```
\( V_{n+1}(\boldsymbol{x}, y) = \max_{\boldsymbol{x}'} \mathbb{E}_{p(f|\boldsymbol{x}, y, \mathcal{D}_n)} [f(\boldsymbol{x}')] \qquad (6.184) \)
\( V_{n+1}(\boldsymbol{x}) = \mathbb{E}_{p(y|\boldsymbol{x}, \mathcal{D}_n)} [V_{n+1}(\boldsymbol{x}, y)] \qquad (6.185) \)
```

我们定义 KG 采集函数如下：

```
\( \alpha_{KG}(\boldsymbol{x}; \mathcal{D}_n) = \mathbb{E}_{\mathcal{D}_n} [(V_{n+1}(\boldsymbol{x}) - M_n) \mathbb{I}(V_{n+1}(\boldsymbol{x}) > M_n)] \qquad (6.186) \)
```

与方程 (6.176) 中的 EI 函数比较。）因此，我们选择点 \(\boldsymbol{x}_{n+1}\)，使得观察 \(f(\boldsymbol{x}_{n+1})\) 会为我们提供可以随后利用的知识，而不是直接试图找到 \(f\) 值更好的更好点。

### 6.6.3.7 优化采集函数

采集函数 \(\alpha(\boldsymbol{x})\) 通常是多模态的（例如，见图 6.11），因为在所有先前查询过的点上它都为 0（假设无噪声观测）。因此，最大化该函数本身可能是一个难解的子问题 [WHD18; Rub+20]。

在连续设置中，通常使用多重启动 BFGS 或网格搜索。我们也可以使用交叉熵方法（第 6.7.5 节），将高斯混合模型 [BK10] 或 VAE [Fau+18] 用作 \(\boldsymbol{x}\) 上的生成模型。在离散组合设置中（例如，在优化生物序列时），[Bel+19] 使用正则化进化（第 6.7.3 节），[Ang+20] 使用近端策略优化（第 35.3.4 节）。还有许多其他组合是可能的。

## 6.6.4 其他问题

在使用贝叶斯优化时，还有许多其他问题需要解决，下面简要提及其中几个。

### 6.6.4.1 并行（批量）查询

在某些情况下，我们希望在多个点上并行查询目标函数，这称为 **批量贝叶斯优化**。现在我们需要对一组可能的查询进行优化，这在计算上比常规情况更加困难。关于该主题的近期论文，请参见 [WHD18; DBB20]。
