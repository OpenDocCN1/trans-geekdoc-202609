## 29.5 HMMs: generalizations

在本节中，我们讨论了在第 29.2 节中介绍的 vanilla HMM 的各种扩展。

### 29.5.1 隐半马尔可夫模型 (HSMM)

在标准 HMM (第 29.2 节) 中，我们在状态 i 中恰好停留 d 步的概率为

```
p(d_i = d) = (1 - A_ii) A_ii^d ∝ exp(d log A_ii)   (29.50)
```

其中 A_ii 是自环概率。这被称为 **几何分布**。然而，这种关于 d 的指数衰减函数有时是不现实的。

建模非几何等待时间的一种简单方法是将每个状态替换为 n 个新状态，每个新状态都与原始状态具有相同的发射概率。例如，考虑图 29.15(a) 中的模型。显然，该模型能生成的最短序列长度为 n = 4。模型中任意长度为 d 的路径的概率为 p^(d-n)(1-p)^n；乘以可能路径的数量，我们得到长度为 d 的路径的总概率为

```
p(d) = \binom{d-1}{n-1} p^{d-n} (1-p)^n   (29.51)
```

这等价于负二项分布。通过调整 n 和每个状态的自环概率 p，我们可以模拟广泛范围的等待时间：参见图 29.15(b)。

一种更通用的解决方案是使用 **半马尔可夫模型**，其中下一个状态不仅取决于前一个状态，还取决于我们在该状态中停留了多长时间。当状态空间是

![](img/ca72c1626f4850f058a9edc138c1ac73_1019_0.png)

图 29.16：将隐半马尔可夫模型编码为 DPGM。(a) \( d_t \) 是一个确定性递减计数器（持续时间变量）。每个观测是独立生成的。(b) 与 (a) 类似，但现在我们将每个段内的观测作为一个块生成。在此图中，我们使用无向边表示每个段内观测之间的非马尔可夫依赖。我们通过断开 \( \boldsymbol{y}_{1:3} \) 与 \( \boldsymbol{y}_{4:5} \) 之间的连接，表示不同段间观测的条件独立；这可以通过在 \( d_t = 1 \)（表示段结束）时“断开链接”来强制执行。

如果不直接观察，结果称为隐半马尔可夫模型 (HSMM)、变时长 HMM 或显式时长 HMM [Yu10]。

表示 HSMM 的一种方法是使用图 29.16(a) 所示的图形模型。节点 \( d_t \in \{1, \dots, D\} \) 是状态持续时间计数器，其中 \( D \) 是任何状态的最大持续时间。当我们首次进入状态 \( j \) 时，我们从该状态的持续时间分布中采样 \( d_t \)，即 \( d_t \sim p_j(\cdot) \)。此后，\( d_t \) 确定性地递减直到 \( d_t = 1 \)。更准确地说，我们定义以下 CPD：

```
p(d_t = d' | d_{t-1} = d, z_t = j) = \begin{cases} D_j(d') & \text{if } d=1 \\ 1 & \text{if } d'=d-1 \text{ and } d>1 \\ 0 & \text{otherwise} \end{cases}
```

注意，\( D_j(d) \) 可以表示为表（非参数方法）或某种参数分布，例如伽马分布。如果 \( D_j(d) 是（截断的）几何分布，这模拟了标准 HMM。

当 \( d_t > 1 \) 时，状态 \( z_t \) 不允许改变。当 \( d_t = 1 \) 时，我们随机转移到一个新状态。（我们假设 \( A_{jj} = 0 \)。）更准确地说，我们定义状态 CPD 如下：

```
p(z_t = k | z_{t-1} = j, d_{t-1} = d) = \begin{cases} 1 & \text{if } d>0 \text{ and } j=k \\ A_{jk} & \text{if } d=1 \\ 0 & \text{otherwise} \end{cases}
```

这确保模型在段的整个持续时间内保持在同一状态。在该段内的每个步骤中，生成一个观测。

HSMM 之所以有用，不仅因为它们可以显式建模每个状态的持续时间，还因为它们可以一次性建模整个观测子序列的分布，而不是假设所有观测在每个时间步都是独立生成的。也就是说，它们可以使用形式为 \( p(\boldsymbol{y}_{t:t+l-1} | z_t = k, d_t = l) \) 的似然模型，如果

状态 \( k \) 的持续时间为 \( l \) 个时间步，则生成 \( l \) 个相关观测。这种方法被称为 **分段 HMM**，用于建模分段线性数据或表现出其他局部趋势的数据 [ODK96]。我们也可以使用 RNN 来建模每个段，从而得到 **RNN-HSMM** 模型 [Dai+17]。

更准确地说，我们可以定义分段 HMM 如下：

$p(\boldsymbol{y}, \boldsymbol{z}, \boldsymbol{d}) = \left[ p(z_1)p(d_1|z_1) \prod_{t=2}^T p(z_t|z_{t-1}, d_{t-1})p(d_t|z_t, d_{t-1}) \right] p(\boldsymbol{y}|\boldsymbol{z}, \boldsymbol{d})$

在标准 HSMM 中，我们假设

$p(\boldsymbol{y}|\boldsymbol{z}, \boldsymbol{d}) = \prod_{t=1}^T p(y_t|z_t)$

因此持续时间变量仅确定隐藏状态动态。为了定义分段 HMM 的 $p(\boldsymbol{y}|\boldsymbol{z}, \boldsymbol{d})$，让我们使用 $s_i$ 和 $e_i$ 表示段 $i$ 的开始和结束时间。这个序列可以从 $\boldsymbol{d}$ 确定性地计算得出，使用 $s_1=1, s_i = s_{i-1} + d_{s_{i-1}}$，和 $e_i = s_i + d_{s_i} - 1$。我们现在定义观测模型如下：

$p(\boldsymbol{y}|\boldsymbol{z}, \boldsymbol{d}) = \prod_{i=1}^{|\boldsymbol{s}|} p(\boldsymbol{y}_{s_i:e_i}|z_{s_i}, d_{s_i})$

有关 DPGM，请参见图 29.16(b)。

如果我们为每个段使用 RNN，则有

$p(\boldsymbol{y}_{s_i:e_i}|z_{s_i}, d_{s_i}) = \prod_{t=s_i}^{e_i} p(y_t|\boldsymbol{y}_{s_i:t-1}, z_{s_i}) = \prod_{t=s_i}^{e_i} p(y_t|h_t, z_{s_i})$

其中 $h_t$ 是给定此序列中先前观测的确定性更新的隐藏状态。

如 [Chi14] 所示，可以在 $O(TK^2 + TKD)$ 时间内计算 $p(z_t, d_t|\boldsymbol{y}_{1:T})$，其中 \( T \) 是序列长度，\( K \) 是状态数，\( D \) 是任何段的最大持续时间。在 [Dai+17] 中，他们展示了如何基于均匀场近似 $q(\boldsymbol{z}, \boldsymbol{d}|\boldsymbol{y}) = \prod_t q(z_t|\boldsymbol{y})q(d_t|\boldsymbol{y})$ 训练近似推断算法，以在 $O(TK + TD)$ 时间内计算后验。

### 29.5.2 层次 HMM

**层次 HMM** (HHMM) [FST98] 是 HMM 的扩展，旨在建模具有层次结构的领域。图 29.17 给出了用于自动语音识别的 HHMM 示例，其中单词由电话组成，电话由子电话组成。我们始终可以将 HHMM“展平”为常规 HMM，但因式化表示通常更易于解释，并允许更高效的推断和模型拟合。

HHMM 已在许多应用领域中使用，例如语音识别 [Bil01]、基因查找 [Hu+00]、计划识别 [BVW02]、监控交通模式 [Lia+07]、室内机器人定位 [TMK04] 等。HHMM 的表达能力不如随机上下文无关文法 (SCFG)，因为它们只允许有界深度的层次结构，但它们支持更高效的推断。在
