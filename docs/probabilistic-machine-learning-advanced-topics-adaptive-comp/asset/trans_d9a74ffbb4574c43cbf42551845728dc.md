

这些结果可以如下解释：均值是来自 GP 的通常均值，加上线性模型的全局偏移，使用 $\overline{\beta}$；协方差是来自 GP 的通常协方差，加上由于 $\beta$ 的不确定性而产生的额外正项。

In the limit of an uninformative prior for the regression parameters, as \(\mathbf{B} \rightarrow \infty \mathbf{I}\), this simplifies to

```
\(\mathbb{E}[g(\mathbf{X}_*)|\mathcal{D}] = \mathbb{E}[f(\mathbf{X}_*)|\mathcal{D}] + \mathbf{R}^\mathsf{T}(\mathbf{H}_\mathsf{X} \mathbf{K}_\sigma^{-1} \mathbf{H}_\mathsf{X}^\mathsf{T})^{-1} \mathbf{H}_\mathsf{X} \mathbf{K}_\sigma^{-1} \mathbf{y}\) \tag{18.70}
\(\text{Cov}[g(\mathbf{X}_*)|\mathcal{D}] = \text{Cov}[f(\mathbf{X}_*)|\mathcal{D}] + \mathbf{R}^\mathsf{T}(\mathbf{H}_\mathsf{X} \mathbf{K}_\sigma^{-1} \mathbf{H}_\mathsf{X}^\mathsf{T})^{-1} \mathbf{R}\) \tag{18.71}
```

## 18.3.5 边缘似然

大多数核函数都有一些自由参数。例如，RBF-ARD 核函数（第 18.2.1.2 节）的形式为

```
\(\mathcal{K}(\mathbf{x}, \mathbf{x}') = \exp\left(-\frac{1}{2} \sum_{d=1}^D \frac{1}{\ell_d^2}(x_d - x'_d)^2\right) = \prod_{d=1}^D \mathcal{K}_{\ell_d}(x_d, x'_d)\) \tag{18.72}
```

其中每个 $\ell_d$ 是特征维度 $d$ 的长度尺度。将这些（以及观测噪声方差 $\sigma_y^2$，如果存在）表示为 $\theta$。我们可以如下计算这些参数的似然：

```
\(p(\mathbf{y}|\mathbf{X}, \theta) = p(\mathcal{D}|\theta) = \int p(\mathbf{y}|f_\mathsf{X}, \theta) p(f_\mathsf{X}|\mathbf{X}, \theta) df_\mathsf{X}\) \tag{18.73}
```

由于我们对函数 $f$ 进行了积分消去，我们通常将 $\theta$ 称为超参数，并将 \(p(\mathcal{D}|\theta)\) 称为边缘似然。

由于 $f$ 是一个 GP，我们可以使用对应高斯分布的边缘似然来计算上述积分。这给出了

```
\(\log p(\mathcal{D}|\theta) = -\frac{1}{2}(\mathbf{y} - \mu_\mathsf{X})^\mathsf{T} \mathbf{K}_\sigma^{-1}(\mathbf{y} - \mu_\mathsf{X}) - \frac{1}{2} \log |\mathbf{K}_\sigma| - \frac{N}{2} \log(2\pi)\) \tag{18.74}
```

第一项是观测值与预测值之间马氏距离的平方：拟合越好，距离越小。第二项是协方差矩阵的对数行列式；它衡量模型复杂度：更平滑的函数行列式越小，因此对于更简单的函数，$-\log |\mathbf{K}_\sigma|$ 会更大（更不负）。边缘似然衡量拟合度与复杂度之间的权衡。

在第 18.6.1 节中，我们讨论如何通过最大化关于 $\theta$ 的边缘似然，从数据中学习核函数参数。

## 18.3.6 计算与数值问题

在本节中，我们讨论实现上述方程时出现的计算与数值问题。为了记号简洁，我们假设先验均值为零，\(m(\mathbf{x}) = 0\)。后验预测均值由 \(\mu_* = \mathbf{k}_*^\mathsf{T} \mathbf{K}_\sigma^{-1} \mathbf{y}\) 给出。出于数值稳定性的考虑，直接求逆 \(\mathbf{K}_\sigma\) 是不明智的。一个更稳健的替代方法是计算分解，\(\mathbf{K}_\sigma = \mathbf{L} \mathbf{L}^\mathsf{T}\)，耗时 \(O(N^3)\)。在此基础上，我们可以计算

```
\(\mu_* = \mathbf{k}_*^\mathsf{T} \mathbf{K}_\sigma^{-1} \mathbf{y} = \mathbf{k}_*^\mathsf{T} \mathbf{L}^{-\mathsf{T}} (\mathbf{L}^{-1} \mathbf{y}) = \mathbf{k}_*^\mathsf{T} \mathbf{\alpha}\) \tag{18.75}
```

这里 $\boldsymbol{\alpha} = \mathbf{L}^{\top} \backslash (\mathbf{L} \backslash \mathbf{y})$，我们使用反斜杠运算符来表示回代。对于每个测试用例，我们可以在 $O(N^2)$ 时间内计算方差，使用 $\sigma_*^2 = k_{**} - \mathbf{k}_*^{\top} \mathbf{L}^{-T} \mathbf{L}^{-1} \mathbf{k}_* = k_{**} - \mathbf{v}^{\top} \mathbf{v}$，其中 $\mathbf{v} = \mathbf{L} \backslash \mathbf{k}_*$。

最后，对数边缘似然（用于核函数学习，第 18.6 节）可以使用 $\log p(\mathbf{y}|\mathbf{X}) = -\frac{1}{2}\mathbf{y}^{\top}\boldsymbol{\alpha} - \sum_{n=1}^N \log L_{nn} - \frac{N}{2}\log(2\pi)$ 进行计算。

我们看到总成本由 $O(N^3)$ 主导。我们将在第 18.5 节讨论更快但近似的方法。

## 18.3.7 核脊回归

脊回归一词指的是对回归权重施加 $\ell_2$ 惩罚的线性回归：$\mathbf{w}^* = \underset{\mathbf{w}}{\text{argmin}} \sum_{n=1}^N (y_n - f(\mathbf{x}_n; \mathbf{w}))^2 + \lambda \|\mathbf{w}\|_2^2$

其中 $f(\mathbf{x}; \mathbf{w}) = \mathbf{w}^{\top} \mathbf{x}$。其解为 $\mathbf{w}^* = (\mathbf{X}^{\top}\mathbf{X} + \lambda \mathbf{I})^{-1}\mathbf{X}^{\top}\mathbf{y} = (\sum_{n=1}^N \mathbf{x}_n \mathbf{x}_n^{\top} + \lambda \mathbf{I})^{-1} (\sum_{n=1}^N \mathbf{x}_n y_n)$

在本节中，我们考虑其函数空间版本：$f^* = \underset{f \in \mathcal{F}}{\text{argmin}} \sum_{n=1}^N (y_n - f(\mathbf{x}_n))^2 + \lambda \|f\|^2$

为了使此有意义，我们需要定义函数空间 $\mathcal{F}$ 和范数 $\|f\|$。如果我们使用由正定核函数 $\mathcal{K}$ 派生的函数空间，则得到的方法称为 **核脊回归**（KRR）。我们将看到，得到的估计 $f^*(\mathbf{x}_*)$ 等价于 GP 的后验均值。下面给出详细信息。

### 18.3.7.1 再生核希尔伯特空间

在本节中，我们简要介绍解释 KRR 所需的相关数学“机制”。令 $\mathcal{F} = \{f : \mathcal{X} \to \mathbb{R}\}$ 为实值函数空间。该空间的元素（即函数）可以像向量一样相加和数乘。也就是说，若 $f \in \mathcal{F}$ 且 $g \in \mathcal{F}$，则对于 $\alpha, \beta \in \mathbb{R}$，有 $\alpha f + \beta g \in \mathcal{F}$。我们也可以为 $\mathcal{F}$ 定义一个 **内积**，它是一个映射 $\langle f, g \rangle \in \mathbb{R}$

它满足以下条件：

```
\langle \alpha f_1 + \beta f_2, g \rangle = \alpha \langle f_1, g \rangle + \beta \langle f_2, g \rangle
\langle f, g \rangle = \langle g, f \rangle
\langle f, f \rangle \ge 0
\langle f, f \rangle = 0 \text{ iff } f(x) = 0 \text{ for all } x \in \mathcal{X}
```

我们使用以下公式定义函数的范数：

```
||f|| \triangleq \sqrt{\langle f, f \rangle}
```

带有内积算子的函数空间 H 称为希尔伯特空间。（我们还要求函数空间是完备的，这意味着 H 中每个柯西函数序列 f_i 都有一个也在 H 中的极限。）

最常见的希尔伯特空间是称为 L^2 的空间。要定义它，我们需要在输入空间 X 上指定一个测度 \mu；这是一个将 X 的任何（合适的）子集 A 分配给一个正数（例如其体积）的函数。这可以通过密度函数 w : X -> R 来定义，如下：

```
\mu(A) = \int_A w(x) dx
```

因此我们有 \mu(dx) = w(x)dx。我们现在可以定义 L^2(X, \mu) 为满足条件的函数 f : X -> R 的空间

```
\int_X f(x)^2 w(x) dx < \infty
```

这被称为平方可积函数集。该空间具有由以下公式定义的内积：

```
\langle f, g \rangle = \int_X f(x)g(x)w(x)dx
```

我们定义再生核希尔伯特空间（RKHS）如下。令 H 为函数 f : X -> R 的希尔伯特空间。如果存在一个（对称）核函数 K : X x X -> R 并具有以下属性，则我们称 H 为带有内积 \langle \cdot, \cdot \rangle_H 的 RKHS：

- 对于每个 x \in X，有 K(x, \cdot) \in H。
- K 满足再生性质：

```
\langle f(\cdot), K(\cdot, x') \rangle = f(x')
```

"'再生性质'这一术语的原因如下。令 f(\cdot) = K(x, \cdot)。那么我们有"

```
\langle K(x, \cdot), K(\cdot, x') \rangle = K(x, x')
```

### 18.3.7.2 RKHS 中函数的复杂性

从机器学习的角度来看，RKHS 的主要用途是它允许我们通过其范数来定义函数的“平滑度”或“复杂性”的概念，正如我们现在讨论的。

假设我们有一个正定核函数 $\mathcal{K}$。根据默瑟定理，我们有 $\mathcal{K}(\boldsymbol{x}, \boldsymbol{x}') = \sum_{i=1}^{\infty} \lambda_i \phi_i(\boldsymbol{x}) \phi_i(\boldsymbol{x}')$。现在考虑由形式为 $f(\boldsymbol{x}) = \sum_{i=1}^{\infty} f_i \phi_i(\boldsymbol{x})$ 的函数定义的希尔伯特空间 $\mathcal{H}$，且满足 $\sum_{i=1}^{\infty} f_i^2 / \lambda_i < \infty$。该空间中两个函数的内积为

$$\langle f, g \rangle_{\mathcal{H}} = \sum_{i=1}^{\infty} \frac{f_i g_i}{\lambda_i}$$

因此，（平方）范数由以下公式给出：

$$\|f\|_{\mathcal{H}}^2 = \langle f, f \rangle_{\mathcal{H}} = \sum_{i=1}^{\infty} \frac{f_i^2}{\lambda_i}$$

这类似于某些 GP 目标中出现的二次型 $f^T \mathbf{K}^{-1} f$（见方程 (18.101)）。因此，函数的平滑度由相应核函数的性质控制。

### 18.3.7.3 表示定理

在本节中，我们考虑函数空间中的（正则化）经验风险最小化问题。具体来说，考虑以下问题：

$$f^* = \operatorname{argmin}_{f \in \mathcal{H}_{\mathcal{K}}} \sum_{n=1}^N \ell(y_n, f(\boldsymbol{x}_n)) + \frac{\lambda}{2} \|f\|_{\mathcal{H}}^2$$

其中 $\mathcal{H}_{\mathcal{K}}$ 是带有核 $\mathcal{K}$ 的 RKHS，$\ell(y, \hat{y}) \in \mathbb{R}$ 是损失函数。可以证明 [KW70; SHS01] 以下结果：

$$f^*(x) = \sum_{n=1}^N \alpha_n \mathcal{K}(x, x_n)$$

其中 $\alpha_n \in \mathbb{R}$ 是依赖于训练数据的一些系数。这被称为 **表示定理**。

现在考虑损失函数为平方损失且 $\lambda = \sigma_y^2$ 的特殊情况。我们要最小化

$$\mathcal{L}(f) = \frac{1}{2\sigma_y^2} \sum_{n=1}^N (y_n - f(\boldsymbol{x}_n))^2 + \frac{1}{2} \|f\|_{\mathcal{H}}^2$$

代入方程 (18.94)，并利用 $\langle \mathcal{K}(\cdot, \boldsymbol{x}_i), \mathcal{K}(\cdot, \boldsymbol{x}_j) \rangle = \mathcal{K}(\boldsymbol{x}_i, \boldsymbol{x}_j)$ 这一事实，我们得到

$$\mathcal{L}(f) = \frac{1}{2} \boldsymbol{\alpha}^T \mathbf{K} \boldsymbol{\alpha} + \frac{1}{2\sigma_y^2} \| \boldsymbol{y} - \mathbf{K} \boldsymbol{\alpha} \|^2$$

$$= \frac{1}{2} \boldsymbol{\alpha}^T (\mathbf{K} + \frac{1}{\sigma_y^2} \mathbf{K}^2) \boldsymbol{\alpha} - \frac{1}{\sigma_y^2} \boldsymbol{y}^T \mathbf{K} \boldsymbol{\alpha} + \frac{1}{2\sigma_y^2} \boldsymbol{y}^T \boldsymbol{y}$$
