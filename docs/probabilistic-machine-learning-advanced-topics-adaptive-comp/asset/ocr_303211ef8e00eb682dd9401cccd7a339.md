where

$$\boldsymbol{\mu}'' = \begin{pmatrix} \boldsymbol{\mu}_{t|t-1} \\ \mathbf{H}_t \boldsymbol{\mu}_{t|t-1} \end{pmatrix}, \quad \boldsymbol{\Sigma}'' = \begin{pmatrix} \boldsymbol{\Sigma}_{t|t-1} & \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} \\ \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} & \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1}^{-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t \end{pmatrix}$$ (8.45)

Finally, we convert this joint into a conditional using Equation (2.78) as follows:

$$p(\mathbf{z}_t | \mathbf{y}_t, \mathbf{y}_{1:t-1}) = \mathcal{N}(\mathbf{z}_t | \boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t})$$ (8.46)

$$\boldsymbol{\mu}_{t|t} = \boldsymbol{\mu}_{t|t-1} + \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} (\mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t)^{-1} [\mathbf{y}_t - \mathbf{H}_t \boldsymbol{\mu}_{t|t-1}]$$ (8.47)

$$= \boldsymbol{\mu}_{t|t-1} + \mathbf{K}_t [\mathbf{y}_t - \mathbf{H}_t \boldsymbol{\mu}_{t|t-1}]$$ (8.48)

$$\boldsymbol{\Sigma}_{t|t} = \boldsymbol{\Sigma}_{t|t-1} - \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} (\mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t)^{-1} \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1}$$ (8.49)

$$= \boldsymbol{\Sigma}_{t|t-1} - \mathbf{K}_t \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1}$$ (8.50)

where

$$\mathbf{S}_t = \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t$$ (8.51)

$$\mathbf{K}_t = \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} \mathbf{S}_t^{-1}$$ (8.52)

# 8.2.2.5 Abstract formulation

We can represent the Kalman filter equations much more compactly by defining various functions that create and manipulate jointly Gaussian systems, as in Section 2.3.2. In particular, suppose we have the following linear Gaussian system:

$$p(\mathbf{z}) = \mathcal{N}(\tilde{\boldsymbol{\mu}}, \tilde{\mathbf{\Sigma}})$$ (8.53)

$$p(\mathbf{y} | \mathbf{z}) = \mathcal{N}(\mathbf{Az} + \mathbf{b}, \mathbf{\Omega})$$ (8.54)

Then the joint is given by

$$p(\mathbf{z}, \mathbf{y}) = \mathcal{N} \left( \begin{pmatrix} \tilde{\boldsymbol{\mu}} \\ \tilde{\boldsymbol{\mu}} \\ \mathbf{C}^\mathsf{T} \end{pmatrix}, \begin{pmatrix} \tilde{\mathbf{\Sigma}} & \mathbf{C} \\ \mathbf{S} \end{pmatrix} \right) = \mathcal{N} \left( \begin{pmatrix} \tilde{\boldsymbol{\mu}} \\ \mathbf{A} \tilde{\boldsymbol{\mu}} + \mathbf{b} \end{pmatrix}, \begin{pmatrix} \tilde{\mathbf{\Sigma}} & \tilde{\mathbf{\Sigma}} \mathbf{A}^\mathsf{T} \\ \mathbf{A} \tilde{\mathbf{\Sigma}} \mathbf{A}^\mathsf{T} + \mathbf{\Omega} \end{pmatrix} \right)$$ (8.55)

and the posterior is given by

$$p(\mathbf{z} | \mathbf{y}) = \mathcal{N}(\mathbf{z} | \widehat{\boldsymbol{\mu}}, \widehat{\mathbf{\Sigma}}) = \mathcal{N} \left( \mathbf{z} \big| \tilde{\boldsymbol{\mu}} + \mathbf{K}(\mathbf{y} - \overline{\mathbf{\mu}}), \tilde{\mathbf{\Sigma}} - \mathbf{K} \mathbf{S} \mathbf{K}^\mathsf{T} \right)$$ (8.56)

where **K** = **CS**<sup>-1</sup>. See Algorithm 8.1 for the pseudocode.

We can now apply these functions to derive Kalman filtering as follows. In the prediction step, we compute

$$p(\mathbf{z}_{t-1}, \mathbf{z}_t | \mathbf{y}_{1:t-1}) = \mathcal{N} \left( \begin{pmatrix} \boldsymbol{\mu}_{t-1|t-1} \\ \boldsymbol{\mu}_{t|t-1} \end{pmatrix}, \begin{pmatrix} \boldsymbol{\Sigma}_{t-1|t-1} & \boldsymbol{\Sigma}_{t-1,t|t-1} \\ \boldsymbol{\Sigma}_{t,t-1|t-1} & \boldsymbol{\Sigma}_{t|t-1} \end{pmatrix} \right)$$ (8.57)

$$(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \boldsymbol{\Sigma}_{t-1,t|t}) = \text{GaussMoments}(\boldsymbol{\mu}_{t-1|t-1}, \boldsymbol{\Sigma}_{t-1|t-1}, \mathbf{F}_t, \mathbf{B}_t \mathbf{u}_t + \mathbf{b}_t, \mathbf{Q}_t)$$ (8.58)
