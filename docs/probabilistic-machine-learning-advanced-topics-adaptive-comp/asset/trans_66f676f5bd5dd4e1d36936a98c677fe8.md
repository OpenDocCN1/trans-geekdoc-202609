```
\(\nabla \log w_s = \frac{1}{w_s} \nabla w_s\) \tag{10.176}
```

因此

```
\(\nabla \ell(\boldsymbol{\theta}|\boldsymbol{\phi}, \boldsymbol{x}) = \frac{1}{\frac{1}{S} \sum_{s=1}^S w_s} \left( \frac{1}{S} \sum_{s=1}^S \nabla w_s \right)\) \tag{10.177}
```

```
\(= \frac{1}{\sum_{s=1}^S w_s} \left( \sum_{s=1}^S w_s \nabla \log w_s \right)\) \tag{10.178}
```

```
\(= \sum_{s=1}^S \overline{w}_s \nabla \log w_s\) \tag{10.179}
```

其中 \(\overline{w}_s = w_s / (\sum_{s'=1}^S w_{s'})\)。

在对 \(\boldsymbol{\theta}\) 求导的情况下，我们有

```
\(\nabla_{\boldsymbol{\theta}} \log w_s = \frac{1}{w_s} \nabla_{\boldsymbol{\theta}} w_s = \frac{q_{\boldsymbol{\phi}}(\boldsymbol{z}_s|\boldsymbol{x})}{p_{\boldsymbol{\theta}}(\boldsymbol{x}, \boldsymbol{z}_s)} \nabla_{\boldsymbol{\theta}} \frac{p_{\boldsymbol{\theta}}(\boldsymbol{x}, \boldsymbol{z}_s)}{q_{\boldsymbol{\phi}}(\boldsymbol{z}_s|\boldsymbol{x})} = \frac{1}{p_{\boldsymbol{\theta}}(\boldsymbol{x}, \boldsymbol{z}_s)} \nabla_{\boldsymbol{\theta}} p_{\boldsymbol{\theta}}(\boldsymbol{x}, \boldsymbol{z}_s) = \nabla_{\boldsymbol{\theta}} \log p_{\boldsymbol{\theta}}(\boldsymbol{x}, \boldsymbol{z}_s)\) \tag{10.180}
```

因此我们得到

```
\(\nabla_{\boldsymbol{\theta}} \ell(\boldsymbol{\theta}|\boldsymbol{\phi}, \boldsymbol{x}) = \sum_{s=1}^S \overline{w}_s \nabla \log p_{\boldsymbol{\theta}}(\boldsymbol{x}, \boldsymbol{z}_s)\) \tag{10.181}
```

### 10.6.2 睡眠阶段

在睡眠阶段，我们试图最小化真后验（在当前模型下）与推理网络对该后验的近似之间的 KL 散度：

```
\(\mathcal{L}(\boldsymbol{\phi}) = \mathbb{E}_{p_{\boldsymbol{\theta}}(\boldsymbol{x})} [D_{\text{KL}}(p_{\boldsymbol{\theta}}(\boldsymbol{z}|\boldsymbol{x}) \| q_{\boldsymbol{\phi}}(\boldsymbol{z}|\boldsymbol{x}))] = \mathbb{E}_{p_{\boldsymbol{\theta}}(\boldsymbol{z}, \boldsymbol{x})} [-\log q_{\boldsymbol{\phi}}(\boldsymbol{z}|\boldsymbol{x})] + \text{const}\) \tag{10.182}
```

等价地，我们可以最大化以下对数似然目标：

```
\(\ell(\boldsymbol{\phi}|\boldsymbol{\theta}) = \mathbb{E}_{(\boldsymbol{z}, \boldsymbol{x}) \sim p_{\boldsymbol{\theta}}(\boldsymbol{z}, \boldsymbol{x})} [\log q_{\boldsymbol{\phi}}(\boldsymbol{z}|\boldsymbol{x})]\) \tag{10.183}
```

其中 \(p_{\boldsymbol{\theta}}(\boldsymbol{z}, \boldsymbol{x}) = p_{\boldsymbol{\theta}}(\boldsymbol{z}) p_{\boldsymbol{\theta}}(\boldsymbol{x}|\boldsymbol{z})\)。我们可以看出，睡眠阶段相当于基于生成模型样本对推理网络进行极大似然训练。这些“幻想样本”，在网络“做梦”时创建，可以使用祖先采样（第 4.2.5 节）轻松生成。如果我们使用 \(S\) 个这样的样本，目标变为

```
\(\ell(\boldsymbol{\phi}|\boldsymbol{\theta}) = \frac{1}{S} \sum_{s=1}^S \log q_{\boldsymbol{\phi}}(\boldsymbol{z}'_s | \boldsymbol{x}'_s)\) \tag{10.184}
```

其中 \((z'_s, x'_s) \sim p_\theta(z, x)\)。其梯度由以下给出

\(\nabla_\phi \ell(\phi|\theta) = \frac{1}{S} \sum_{s=1}^S \nabla_\phi \log q_\phi(z'_s|x'_s)\)

我们不要求 \(q_\phi(z'|x)\) 可重参数化，因为样本是从与 \(\phi\) 无关的分布中绘制的。这意味着将此方法应用于具有离散潜在变量的模型很容易。

### 10.6.3 白日梦阶段

睡眠阶段的缺点是推理网络 \(q_\phi(z|x)\) 试图跟踪一个移动目标 \(p_\theta(z|x)\)。此外，它仅在模型的合成数据上进行训练，而非真实数据。[BB15b] 的重权觉醒-睡眠算法提出，除了幻想数据外，还使用经验分布中的真实数据来学习推理网络。他们称使用真实数据的情况为“觉醒阶段 \(q\) 更新”，但我们将其称为“白日梦阶段”，因为与睡眠不同，系统使用真实数据 \(x\) 来更新推理模型，而不是幻想。$^1$ [Le+19] 进一步提出，仅使用觉醒阶段和白日梦阶段，并完全跳过睡眠阶段。

更详细地，我们要最小化的新目标变为

\(\mathcal{L}(\phi|\theta) = \mathbb{E}_{p_D(x)} [D_{KL}(p_\theta(z|x) \parallel q_\phi(z|x))]\)

我们可以按如下方式计算上述表达式负值的单个样本近似：

\(\ell(\phi|\theta, x) = \mathbb{E}_{p_\theta(z|x)} [\log q_\phi(z|x)]\)

其中 \(x \sim p_D\)。我们可以使用重要性采样近似此期望，以 \(q_\phi\) 为提议分布。这得出了每个数据点的梯度的以下估计器：

\(\nabla_\phi \ell(\phi|\theta, x) = \int p_\theta(z|x) \nabla_\phi \log q_\phi(z|x) dz \approx \sum_{s=1}^S \overline{w}_s \nabla_\phi \log q_\phi(z_s|x)\)

其中 \(z_s \sim q_\phi(z_s|x)\) 且 \(\overline{w}_s\) 为归一化权重。

我们可以看到方程 (10.188) 与方程 (10.185) 非常相似。关键区别在于，在白日梦阶段，我们从 \((x, z_s) \sim p_D(x) q_\phi(z|x)\) 采样，其中 \(x\) 是真实数据点，而在睡眠阶段，我们从 \((x'_s, z'_s) \sim p_\theta(z, x)\) 采样，其中 \(x'_s\) 是生成的数据点。

## 10.7 期望传播（EP）

下界最大化（即标准 VI）的一个问题在于，我们正在最小化 D_KL(q || p)，这会诱导零强制行为，正如我们在第 5.1.4.1 节中讨论的那样。这意味着 q(z|x) 倾向于过于紧凑（过度自信），以避免 q(z|x) > 0 但 p(x|z) = 0 的情况，这将导致无穷 KL 惩罚。

虽然零强制行为对于某些多模态后验（例如混合模型）可能是可取的，但对于许多单模态后验（例如贝叶斯逻辑回归或具有对数凹似然的高斯过程（GPs））来说并不那么合理。避免此问题的一种方法是最小化 D_KL(p || q)，它是零避免的，正如我们在第 5.1.4.1 节中讨论的那样。这倾向于产生宽泛的后验，从而避免过度自信。在本节中，我们讨论期望传播或 EP [Min01b]，它可以被视为 D_KL(p || q) 的局部近似。
