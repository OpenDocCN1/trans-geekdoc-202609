

对数似然的导数由以下[IKB21]给出：

\(\nabla_\theta \log p(y|f(x,\theta)) = \mathbf{J}_\theta(x)^\top r(y; f)\) (17.14)

\(\nabla_\theta^2 \log p(y|f(x,\theta)) = \mathbf{H}_\theta(x)^\top r(y; f) - \mathbf{J}_\theta(x)^\top \Lambda(y; f) \mathbf{J}_\theta(\theta)\) (17.15)

由于网络海森矩阵**H**通常难以计算，因此通常将其舍弃，只保留雅可比项。这称为**广义高斯-牛顿**（**GGN**）近似[Sch02; Mar20]。GGN近似保证是正定的。相比之下，原始海森矩阵在方程(17.15)中不一定成立，因为目标不是凸的。此外，计算雅可比项比计算海森矩阵更便宜。

综合起来，对于高斯先验，\(p(\theta) = \mathcal{N}(\theta|m_0, S_0)\)，拉普拉斯近似变为 \(p(\theta|\mathcal{D}) \approx \mathcal{N}(\theta|\theta^*, \Sigma_\text{GGN})\)，其中

\(\Sigma_\text{GGN}^{-1} = \sum_{n=1}^N \mathbf{J}_{\theta^*}(x_n)^\top \Lambda(y_n; f_n) \mathbf{J}_{\theta^*}(x_n) + S_0^{-1}\) (17.16)

不幸的是，求逆这个矩阵需要\(O(P^3)\)时间，因此对于参数众多的模型，通常会使用进一步的近似。最简单的方法是使用对角近似，其时间和空间复杂度为\(O(P)\)。更复杂的方法在[RBB18a]中介绍，该方法利用了[MG15]的**KFAC**（Kronecker factored curvature，克罗内克因子化曲率）近似。这使用克罗内克积来近似每一层的协方差。

拉普拉斯近似的一个局限是，后验协方差源自在MAP参数处计算的海森矩阵。这意味着拉普拉斯形成一个高度*局部*近似：即使非高斯后验可以用高斯分布很好地描述，使用拉普拉斯*形成*的高斯分布只捕获MAP参数处的后验局部特征——因此可能严重受制于局部最优，提供过于紧凑或分散的表示。此外，曲率信息仅在模型估计后使用，而不在模型优化过程中使用。相比之下，变分推断（第17.3.3节）可以以可比的成本提供更准确的近似。

## 17.3.3 变分推断

在固定形式变分推断（第10.2节）中，我们为后验近似\(q_\psi(\theta)\)选择一个分布，并最小化\(D_\text{KL}(q \| p)\)，关于\(\psi\)。我们通常选择一个高斯近似后验，\(q_\psi(\theta) = \mathcal{N}(\theta|\mu, \Sigma)\)，这使我们能够使用重参数化技巧来创建ELBO梯度的低方差估计器（见第10.2.1节）。尽管使用了高斯分布，但最小化KL目标的参数通常与我们使用拉普拉斯近似（第17.3.2节）所找到的不同。

神经网络的变分方法至少可以追溯到Hinton和Camp [HC93]。在深度学习中，[Gra11]重新探讨了变分方法，使用具有对角协方差矩阵的高斯近似。这将模型中每个参数的分布近似为一元高斯分布，其中均值为点估计，方差捕获不确定性，如图17.3所示。[Blu+15]进一步改进了该方法，他们使用重参数化技巧来计算较低方差的ELBO估计；他们将他们的方法称为**通过反向传播的贝叶斯**（**BBB**）。这本质上与算法10.2中的SVI算法相同，只是似然变为来自DNN的\(p(y_n|x_n, \theta)\)，而先验\(p_\xi(\theta)\)和变分后验\(q_\psi(\theta)\)是高斯分布。

已提出许多BBB的扩展。在[KSW15]中，他们提出了**局部重参数化技巧**，在每一层采样激活值**a**=**Wz**，而不是权重**W**，从而得到较低方差的ELBO梯度估计。在[Osa+19a]中，他们使用了[Kha+18]的**变分在线高斯-牛顿（VOGN）**方法，以提高可扩展性。VOGN是自然梯度下降的噪声版本，其中额外的噪声模拟了变分推断的效果。在[Mis+18]中，他们用低秩加对角近似替换了对角近似，并使用VOGN进行拟合。在[Tra+20b]中，他们使用一种称为**NAGVAC**的秩一加对角近似（见第10.2.1.3节）。在这种情况下，参数数量仅为计算点估计的3倍（用于变分均值、方差和秩一向量），使该方法非常可扩展。此外，在这种情况下，可以解析地计算自然梯度，从而加快模型拟合（见第6.4节）。还提出了许多其他变分方法（见例如，[LW16; Zha+18; Wu+19a; HHK19]）。另见第17.5.4节，讨论DNN的在线VI。

## 17.3.4 期望传播

期望传播（EP）与变分推断类似，只是它在本地优化\(D_{\text{KL}}(p \| q)\)而不是\(D_{\text{KL}}(q \| p)\)，其中\(p\)是精确后验，\(q\)是近似后验。详情见第10.7节。

EP的一个特例是第8.6节的假设密度滤波（ADF）算法，它等同于ADF的第一遍。在第8.6.3节中，我们展示了如何将ADF应用于在线逻辑回归。在[HLA15a]中，他们将ADF扩展到BNN的情况；他们将他们的方法称为概率反向传播或**PBP**。他们将模型中每个参数近似为高斯因子，如图17.3所示。详情见第17.5.3节。

## 17.3.5 最后一层方法

对后验的一个非常简单的近似是只对最后一层的权重“进行贝叶斯推断”，并对所有其他参数使用MAP估计。这称为**神经-线性近似**[RTS18]。更详细地说，设\(\mathbf{z} = f(\mathbf{x}, \boldsymbol{\theta})\)为模型在任何可选最终非线性之前的预测输出（例如，logits）。我们假设其形式为\(\mathbf{z} = \mathbf{w}_L^\top \phi(\mathbf{x}; \boldsymbol{\theta})\)，其中\(\phi(x)\)是前\(L-1\)层提取的特征。这给我们提供了一个贝叶斯GLM。给定\(\phi()\)，我们可以使用标准技术，例如拉普拉斯近似（第15.3.5节），来计算\(p(w_L|\mathcal{D}) = \mathcal{N}(\mu_L, \Sigma_L)\)。为了估计特征提取器的参数，我们可以以通常的方式优化对数似然。给定最后一层权重的后验，我们可以使用以下公式计算logits的后验预测分布：

\(p(z|x, \mathcal{D}) = \mathcal{N}(z|\mu_L\boldsymbol{\phi}(x), \boldsymbol{\phi}(x)^\top \Sigma_L \boldsymbol{\phi}(x))\) (17.17)

这可以通过最终的softmax层来计算\(p(y|x, \mathcal{D})\)，如第15.3.6节所述。[KHH20]表明，这可以减少对远离训练数据的输入的预测过度自信。然而，这种方法忽略了之前特征提取层引入的不确定性，大部分参数都位于这些层中。我们在第17.3.6节讨论了解决方案。

## 17.3.6 SNGP

可以通过将DNN作为特征提取器，然后将其输入到最后一层的核中，将DNN与高斯过程（GP）模型（第18章）相结合。这被称为“深度核学习”（见第18.6.6节）。这种方法的一个问题是，特征提取器可能会丢失分类精度不需要，但在分布外输入上获得强健性能所需的信息（见第17.4.6.2节）。基本问题是，在分类问题中，如果远离的点被投影得靠得很近，只要它们位于决策边界的正确一侧，训练精度（对数似然）就不会下降。因此，特征提取层可以抹除两个输入之间的距离，使得OOD输入在最终层看来接近训练集。

解决这一问题的一个方法是使用[Liu+20d; Liu+22a]的**SNGP**（谱归一化高斯过程）方法。这将特征提取层约束为“距离保持”，即使用权重的谱归一化来界定特征提取器的Lipschitz常数，从而使输入空间中相距很远的两个输入在经过多层特征提取后仍然相距很远。整体方法确保了与计算预测置信度相关但可能与计算预测标签无关的信息不会丢失。这有助于提高诸如分布外检测（第17.4.6.2节）等任务的性能。
