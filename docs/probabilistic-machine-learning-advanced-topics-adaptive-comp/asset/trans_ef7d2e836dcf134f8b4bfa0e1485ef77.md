## 4.2.8.2 示例：朴素贝叶斯分类器

在某些模型中，我们有双索引变量。例如，考虑朴素贝叶斯分类器。这是一个简单的生成式分类器，定义如下：

```
p(\boldsymbol{x}, y | \boldsymbol{\theta}) = p(y | \boldsymbol{\pi}) \prod_{d=1}^D p(x_d | y, \boldsymbol{\theta}_d) \quad (4.68)
```

特征 x_{1:D} 在给定类标签 y 的情况下被视为条件独立，这正是“朴素”一词的由来。尽管如此，该模型往往效果出奇地好，并且极易拟合。

我们可以像图 4.13a 所示表示条件独立性假设。我们可以用盘形表示维度 d 上的重复。当我们转向推断参数 \(\boldsymbol{\theta} = (\boldsymbol{\pi}, \boldsymbol{\theta}_{1:D,1:C})\) 时，还需要表示数据案例 n 上的重复。这在图 4.13b 中所示。请注意，参数 \(\boldsymbol{\theta}_{dc}\) 取决于 d 和 c，而特征 x_{nd} 取决于 n 和 d。这是使用嵌套盘形来表示共享 d 索引。

## 4.2.8.3 示例：放宽朴素贝叶斯假设

从图 4.13a 可以看出，观测特征在给定类标签的情况下是条件独立的。我们当然可以允许特征之间存在依赖关系，如图 4.14 所示。（为简单起见，我们省略了参数节点。）如果强制特征之间的边形成一棵树，则该模型称为树增强朴素贝叶斯分类器 [FGG97]，或 TAN 模型。（树是一种受限的图形模型，具有我们稍后讨论的各种计算优势。）请注意，树的拓扑结构可能随类节点 y 的值而变化；在这种情况下，该模型称为贝叶斯多网络，可以看作是树的受监督混合。

## 4.3 无向图形模型（马尔可夫随机场）

有向图形模型（第 4.2 节）非常有用。然而，对于某些领域，像 DAG 要求的那样被迫为边选择方向，这相当尴尬。例如，考虑建模图像。假设相邻像素的强度值相关是合理的。我们可以使用具有 2D 格网拓扑的 DAG 来建模，如图 4.15(a) 所示。这称为 **马尔可夫网格** [AHK65]。然而，其条件独立性特性相当不自然。

另一种选择是使用无向概率图形模型（**UPGM**），也称为 **马尔可夫随机场**（**MRF**）或 **马尔可夫网络**。这些模型不需要我们指定边的方向，对于图像分析和空间统计等某些问题来说，它们要自然得多。例如，图 4.15(b) 显示了一个无向 2D 格网；现在每个节点的马尔可夫毯仅仅是其最近邻，如第 4.3.6 节所示。

总的来说，UPGM 相对于 DPGM 的主要优点是：(1) 它们是对称的，因此对于空间或关系数据等特定领域来说更“自然”；以及 (2) 判别式 UPGM（也称为条件随机场，或 CRF），定义形式为 \(p(\boldsymbol{y}|\boldsymbol{x})\) 的条件密度，其效果优于判别式 DPGM，原因如第 4.5.3 节所述。UPGM 相对于 DPGM 的主要缺点是：(1) 参数的可解释性较差且模块化程度较低，原因如第 4.3.1 节所述；以及 (2) 估计参数在计算上更昂贵，原因如第 4.3.9.1 节所述。

### 4.3.1 表示联合分布

由于无向图没有关联的拓扑顺序，我们无法使用链式法则来表示 \(p(\boldsymbol{x}_{1:N_G})\)。因此，我们不再为每个节点关联条件概率分布（CPD），而是为图中的每个 **极大团** 关联 **势函数** 或 **因子**。^3 我们将团 \(c\) 的势函数表示为 \(\psi_c(\boldsymbol{x}_c; \boldsymbol{\theta}_c)\)，其中 \(\boldsymbol{\theta}_c\) 是其参数。势函数可以是其参数的任何非负函数（下面给出一些示例）。我们可以使用这些函数来定义联合分布，如第 4.3.1.1 节所述。

3. 团是一组彼此都是邻居的节点。**极大团** 是一个不能再增大而不失去团性质的团。

### 4.3.1.1 Hammersley-Clifford 定理

假设联合分布 \(p\) 满足无向图 \(G\) 隐含的条件独立性性质。（我们讨论如何在 4.3.6 节中推导这些性质。）那么 **Hammersley-Clifford 定理** 告诉我们，\(p\) 可以写成如下形式：

\(p(\boldsymbol{x}|\boldsymbol{\theta}) = \frac{1}{Z(\boldsymbol{\theta})} \prod_{c \in \mathcal{C}} \psi_c(\boldsymbol{x}_c; \boldsymbol{\theta}_c)\) (4.69)

其中 \(\mathcal{C}\) 是图 \(G\) 的所有（极大）团的集合，而 \(Z(\boldsymbol{\theta})\) 是 **配分函数**，由以下公式给出：

\(Z(\boldsymbol{\theta}) \triangleq \sum_{\boldsymbol{x}} \prod_{c \in \mathcal{C}} \psi_c(\boldsymbol{x}_c; \boldsymbol{\theta}_c)\) (4.70)

请注意，配分函数确保整体分布总和为 1。Hammersley-Clifford 定理从未发表过，但证明可见 [KF09a]。（请注意，该定理仅适用于正分布，即对于所有配置 \(\boldsymbol{x}\) 均有 \(p(\boldsymbol{x}|\boldsymbol{\theta}) \ge 0\) 的分布，这排除了某些具有硬约束的模型。）

### 4.3.1.2 Gibbs 分布

方程 (4.69) 中的分布可以重写为：

\(p(\boldsymbol{x}|\boldsymbol{\theta}) = \frac{1}{Z(\boldsymbol{\theta})} \exp(-\mathcal{E}(\boldsymbol{x}; \boldsymbol{\theta}))\) (4.71)

其中 \(\mathcal{E}(\boldsymbol{x}) > 0\) 是状态 \(\boldsymbol{x}\) 的 **能量**，定义为

\(\mathcal{E}(\boldsymbol{x}; \boldsymbol{\theta}) = \sum_c \mathcal{E}(\boldsymbol{x}_c; \boldsymbol{\theta}_c)\) (4.72)

其中 \(\boldsymbol{x}_c\) 是团 \(c\) 中的变量。我们可以通过定义团势来看出等价性

\(\psi_c(\boldsymbol{x}_c; \boldsymbol{\theta}_c) = \exp(-\mathcal{E}(\boldsymbol{x}_c; \boldsymbol{\theta}_c))\) (4.73)

我们看到，低能量与高概率状态相关联。方程 (4.71) 称为 **Gibbs 分布**。这种概率模型也称为 **基于能量的模型**。它们常用于物理学和生物化学。它们也用于 ML 中定义生成模型，如第 24 章所述。（另见第 4.4 节，我们在其中讨论条件随机场（CRF），即形式为 \(p(\boldsymbol{y}|\boldsymbol{x}, \boldsymbol{\theta})\) 的模型，其中势函数依赖于输入特征 \(\boldsymbol{x}\)。）

### 4.3.2 完全可见的 MRF（Ising、Potts、Hopfield 等）
