### 3.6.1.1 后验推断

我们可以使用多种方法在此模型中执行近似后验推断。在第 3.7.1 节中我们讨论一种基于优化的方法，但在此我们讨论贝叶斯统计中最流行的方法之一，称为 HMC 或哈密顿蒙特卡洛。这在 12.5 节中有所描述，但简而言之，它是一种 MCMC（马尔可夫链蒙特卡洛）形式，它利用对数联合分布梯度的信息来指导采样过程。该算法在无约束参数空间中生成样本，因此我们需要定义所有参数上的对数联合分布 \(\boldsymbol{\omega} = (\tilde{\boldsymbol{\theta}}, \tilde{\boldsymbol{\xi}}) \in \mathbb{R}^D\) 如下：

\[
\log p(\mathcal{D}, \boldsymbol{\omega}) = \log p(\mathcal{D}|\boldsymbol{\theta}) + \log p(\boldsymbol{\theta}|\boldsymbol{\xi}) + \log p(\boldsymbol{\xi}) \tag{3.250}
\]

\[
+ \sum_{j=1}^J \log |\text{Jac}(\sigma)(\hat{\theta}_j)| + \sum_{i=1}^2 \log |\text{Jac}(\sigma_+)(\tilde{\xi}_i)| \tag{3.251}
\]

其中 \(\theta_j = \sigma(\tilde{\theta}_j)\) 是 sigmoid 变换，\(\xi_i = \sigma_+(\tilde{\xi}_i)\) 是 softplus 变换。（我们需要添加雅可比项来解释这些确定性变换。）然后我们可以使用自动微分来计算 \(\nabla_\boldsymbol{\omega} \log p(\mathcal{D}, \boldsymbol{\omega})\)，并将其传递给 HMC 算法。该算法从后验中返回一组（相关）样本 \((\tilde{\boldsymbol{\theta}}^s, \tilde{\boldsymbol{\xi}}^s) \sim p(\boldsymbol{\omega}|\mathcal{D})\)，我们可以将其反向变换为 \((\boldsymbol{\xi}^s, \boldsymbol{\theta}^s)\)。然后我们可以通过对合适的 \(f\) 使用 \(p(f(\boldsymbol{\theta})|\mathcal{D})\) 的蒙特卡洛近似来估计感兴趣量的后验（例如，为了计算组 \(j\) 的后验平均比率，我们设置 \(f(\boldsymbol{\theta}) = \theta_j\))。

### 3.6.1.2 示例：老鼠数据集

在此节中，我们应用此模型来分析在特定临床试验中患某种肿瘤的老鼠数量（详情见 [Gel+14a, p102]）。我们在图 3.15a 的第 1–2 行中显示原始数据。在第 3 行，我们显示每个组的 MLE \(\hat{\theta}_j\)。我们看到一些组的 \(\hat{\theta}_j = 0\)，这远小于合并 MLE \(\hat{\theta}_\text{pooled}\)（红线）。在第 4 行，我们显示从所有数据估计的后验均值 \(\mathbb{E}[\theta_j|\mathcal{D}]\)，以及红线所示的总体均值 \(\mathbb{E}[\theta|\mathcal{D}] = \mathbb{E}[a/(a+b)|\mathcal{D}]\)。我们看到计数较低的组的估计值向总体均值增加，计数较大的组的估计值向总体均值减少。换句话说，各组相互正则化；这种现象称为收缩。收缩量由 \((a, b)\) 上的先验控制，该先验从数据中推断出来。

在图 3.15b 中，我们显示每个参数的 95% 可信区间，以及总体均值。（这被称为森林图。）我们可以使用它来决定任何组是否与任何指定目标值（例如，总体平均值）有显著差异。

### 3.6.2 分层高斯模型

在此节中，我们考虑第 3.6.1 节模型的一个变体，这次我们有实值数据而不是二进制计数数据。更具体地，我们假设 \(y_{ij} \sim \mathcal{N}(\theta_j, \sigma^2)\)，其中 \(\theta_j\) 是组 \(j\) 的未知均值，\(\sigma^2\) 是观测方差（为简单起见，假设在各组间共享且固定）。请注意，有 \(N_j\) 个各自方差为 \(\sigma^2\) 的观测 \(y_{ij}\) 相当于拥有一个测量值 \(\bar{y}_j := \frac{1}{N_j} \sum_{i=1}^{N_j} y_{ij}\)，其方差为 \(\sigma_j^2 := \sigma^2/N_j\)。这使我们能够简化记号

并且每组使用一个观测，似然为 \(y_j \sim \mathcal{N}(\theta_j, \sigma_j^2)\)，其中我们假设 \(\sigma_j\) 已知。

我们通过假设每个组的参数来自一个共同分布来使用分层模型，\(\theta_j \sim \mathcal{N}(\mu, \tau^2)\)。模型变为

\[
p(\mu, \tau^2, \boldsymbol{\theta}_{1:J}|\mathcal{D}) \propto p(\mu)p(\tau^2) \prod_{j=1}^J \mathcal{N}(\theta_j|\mu, \tau^2)\mathcal{N}(y_j|\theta_j, \sigma_j^2) \tag{3.252}
\]

其中 \(p(\mu)p(\tau^2)\) 是超参数上的某种先验。有关图形模型，请参见图 3.19a。

### 3.6.2.1 示例：八所学校数据集

现在让我们将此模型应用于一些数据。我们将考虑来自 [Gel+14a, Sec 5.5] 的 **八所学校** 数据集。目标是估计新辅导项目对 SAT 分数的影响。设 \(y_{nj}\) 为学校 \(j\) 中学生 \(n\) 相对于基准线的观测得分提高。由于每个学校有多名学生，我们使用经验均值 \(\bar{y}_{\cdot j} = \frac{1}{N_j}\sum_{n=1}^{N_j} y_{nj}\) 和标准差 \(\sigma_j\) 来总结其数据。有关数据的说明，请参见图 3.16a。我们还显示 \(\theta\) 的合并 MLE，它是数据的精度加权平均值：

\[
\bar{y}_{..} = \frac{\sum_{j=1}^J \frac{1}{\sigma_j^2}\bar{y}_{\cdot j}}{\sum_{j=1}^J \frac{1}{\sigma_j^2}} \tag{3.253}
\]

我们看到与总体均值相比，学校 0 有异常大的提高（28 分），这表明仅根据 \(\mathcal{D}_0\) 来估计 \(\theta_0\) 可能不可靠。然而，我们可以轻松应用我们的分层模型。我们将使用 HMC 进行近似推断。（有关更快的近似方法，请参见第 3.7.2 节。）

计算（近似）后验后，我们可以为每个学校计算边缘后验 \(p(\theta_j|\mathcal{D})\)。这些分布在图 3.16b 中显示。再次，我们看到向全局均值 \(\overline{\mu} = \mathbb{E}[\mu|\mathcal{D}]\) 的收缩，它接近合并估计 \(\bar{y}_{..}\)。事实上，如果我们将超参数固定为其后验均值，并使用近似

\[
p(\mu, \tau^2|\mathcal{D}) = \delta(\mu - \overline{\mu})\delta(\tau^2 - \overline{\tau}^2) \tag{3.254}
\]

那么我们可以使用第 3.4.3.1 节的结果来计算边缘后验

\[
p(\theta_j|\mathcal{D}) \approx p(\theta_j|\mathcal{D}_j, \overline{\mu}, \overline{\tau}^2) \tag{3.255}
\]

特别是，我们可以证明后验均值 \(\mathbb{E}[\theta_j|\mathcal{D}]\) 介于 MLE \(\hat{\theta}_j = y_j\) 和全局均值 \(\overline{\mu} = \mathbb{E}[\mu|\mathcal{D}]\) 之间：

\[
\mathbb{E}[\theta_j|\mathcal{D}, \overline{\mu}, \overline{\tau}^2] = w_j\overline{\mu} + (1 - w_j)\hat{\theta}_j \tag{3.256}
\]

其中向全局均值的收缩量由以下给出

\[
w_j = \frac{\sigma_j^2}{\sigma_j^2 + \tau^2} \tag{3.257}
\]

因此我们看到，测量精度较低的组（例如，由于样本量较小）会有更多的收缩，这符合直觉。如果 \(\tau^2\) 较小，也会有更多的收缩；当然，\(\tau^2\) 是未知的，但我们可以为其计算后验，如图 3.17 所示。

### 3.6.2.2 非中心化参数化

事实证明，由于方差超参数 \(\tau^2\) 与组均值 \(\theta_j\) 之间存在紧密依赖，此模型的后验推断对许多算法来说都很困难，如图 3.18 中的 **漏斗形状** 所示。特别是，考虑在参数空间中进行局部移动。算法只有在所有 \(\theta_j\) 都接近先验均值 \(\mu\) 时，才能“访问” \(\tau^2\) 较小的地方（对应于对先验的强收缩）。除非所有组 *同时* 将其 \(\theta_j\) 估计值移近 \(\mu\)，否则可能难以进入 \(\tau^2\) 较小的区域。

解决此问题的标准方法是使用以下 **非中心化参数化** 重写模型：

\[
\theta_j = \mu + \tau\eta_j \tag{3.258}
\]

\[
\eta_j \sim \mathcal{N}(0, 1) \tag{3.259}
\]
