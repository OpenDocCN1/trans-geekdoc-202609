## 13.6.3 数据退火

如果我们有一组 iid 观测值，可以将第 \(t\) 个目标定义为

\(\tilde{\gamma}_t(\boldsymbol{\theta}) = p(\boldsymbol{\theta})p(\mathbf{y}_{1:t}|\boldsymbol{\theta})\) (13.80)

现在可以将 SMC 应用于此模型。根据公式 (13.74)，增量权重变为

\(\alpha_t(\boldsymbol{\theta}) = \frac{\tilde{\gamma}_t(\mathbf{z}_{t-1})}{\tilde{\gamma}_{t-1}(\mathbf{z}_{t-1})} = \frac{p(\boldsymbol{\theta})p(\mathbf{y}_{1:t}|\boldsymbol{\theta})}{p(\boldsymbol{\theta})p(\mathbf{y}_{1:t-1}|\boldsymbol{\theta})} = p(\mathbf{y}_t|\mathbf{y}_{1:t-1}, \boldsymbol{\theta})\) (13.81)

这可以插入到 Algorithm 13.3 的通用 SMC 算法中。不幸的是，从 MCMC 内核中采样通常需要 \(O(t)\) 时间，因为 MH 接受/拒绝步骤需要为任何拟议的 \(\boldsymbol{\theta}'\) 计算 \(p(\boldsymbol{\theta}') \prod_{i=1}^t p(\mathbf{y}_{1:t}|\boldsymbol{\theta}')\)。因此，如果有 \(T\) 个观测值，总成本为 \(O(T^2)\)。为了降低这一点，我们可以仅在 ESS 低于某个水平时在时间 \(t\) 采样参数；在剩余步骤中，我们通过重复先前采样的值来确定性地扩展序列。该技术在 [Cho02] 中被提出，他们称其为 **迭代批次重要性采样** 或 **IBIS** 算法。

### 13.6.3.1 示例：1d 高斯的 IBIS

## 13.6.4 采样罕见事件和极值

假设我们希望从 \(\pi_0(\boldsymbol{\theta})\) 中采样值，条件是事件 \(S(\boldsymbol{\theta}) > \lambda^*\) 发生，其中 \(S\) 是某个得分或"适应度"函数。如果 \(\lambda^*\) 位于得分分布的尾部，这对应于采样罕见事件，这可能很困难。

一种方法是使用 SMC 从阈值逐渐增加的一系列分布中采样：

\(\pi_t(\boldsymbol{\theta}) = \frac{1}{Z_t} \mathbb{I}(S(\boldsymbol{\theta}) \ge \lambda_t) \pi_0(\boldsymbol{\theta})\) (13.82)

其中 \(\lambda_0 < \cdots < \lambda_T = \lambda^*\)。然后我们可以使用似然退火，其中"似然"是函数

\(G_t(\boldsymbol{\theta}_t) = \mathbb{I}(S(\boldsymbol{\theta}_t) \ge \lambda_t)\) (13.83)

我们可以使用 SMC 从最终分布 \(\pi_T\) 生成样本。我们可能还希望估计

\(Z_T = p(S(\boldsymbol{\theta}) \ge \lambda_T)\) (13.84)

其中概率是相对于 \(\pi_0(\boldsymbol{\theta})\) 取的。

我们可以自适应地设置阈值 \(\lambda_t\)，方法如下：在每个步骤中，按分数对样本进行排序，并将 \(\lambda_t\) 设置为 \(\alpha\)-th 最高分位数。例如，如果设置 \(\alpha = 0.5\)，我们保留前 50% 的适应度最高的粒子。这确保了每个步骤的 ESS 等于最小阈值。详情见 [Cér+12]。请注意，此方法与 **交叉熵方法**（第 6.7.5 节）非常相似。区别在于，CEM 在每个步骤将参数分布（例如，高斯分布）拟合到粒子上并从中采样，而不是使用马可维亚内核。

## 13.6.5 SMC-ABC 和无似然推断

术语 **无似然推断** 指的是估计黑箱的参数 \(\boldsymbol{\theta}\)，我们可以从中采样数据 \(\boldsymbol{y} \sim p(\cdot|\boldsymbol{\theta})\)，但无法逐点评估 \(p(\boldsymbol{y}|\boldsymbol{\theta})\)。此类模型称为模拟器，因此这种推断方法也称为 **基于仿真的推断**（见例如 [Nea+08; CBL20; Gou+96]）。这些模型也称为 **隐式模型**（见第 26.1 节）。

如果我们想要近似没有已知似然的模型的后验，可以使用 **近似贝叶斯计算** 或 **ABC**（见例如 [Bea19; SFB18; Gut+14; Pes+21]）。在此设置中，我们同时采样参数 \(\boldsymbol{\theta}\) 和合成数据 \(\boldsymbol{y}\)，使得合成数据（从 \(\boldsymbol{\theta}\) 生成）与观测数据 \(\boldsymbol{y}^*\) 足够接近，由某些距离得分判断，\(d(\boldsymbol{y}, \boldsymbol{y}^*) < \epsilon\)。（对于高维问题，我们通常要求 \(d(\boldsymbol{s}(\boldsymbol{y}), \boldsymbol{s}(\boldsymbol{y}^*)) < \epsilon\)，其中 \(\boldsymbol{s}(\boldsymbol{y})\) 是数据的低维汇总统计量。）

在 SMC-ABC 中，我们逐渐减少差异 \(\epsilon\) 以得到一系列分布，如下所示：

\(\pi_t(\boldsymbol{\theta}, \boldsymbol{y}) = \frac{1}{Z_t} \pi_0(\boldsymbol{\theta}) p(\boldsymbol{y}|\boldsymbol{\theta}) \mathbb{I}(d(\boldsymbol{y}, \boldsymbol{y}^*) < \epsilon_t)\) (13.85)

其中 \(\epsilon_0 > \epsilon_1 > \cdots\)。这与第 13.6.4 节中的罕见事件 SMC 采样器类似，区别在于我们不能直接评估候选者 \(\boldsymbol{\theta}\) 的质量。相反，我们必须先将其转换为数据空间，然后在那里进行比较。详情见 [DMDJ12]。

尽管 SMC-ABC 在遗传学和流行病学等某些领域很流行，但这种方法相当慢，无法扩展到高维问题。在这种情况下，更有效的方法是训练生成模型来 **模拟** 模拟器；如果该模型是参数化的且具有可处理的似然（例如，流模型），我们可以使用其参数的常规后验推断方法（包括基于梯度的方法，如 HMC）。详情见例如 [Bre+20a]。

## 13.6.6 SMC²

我们已经看到 SMC 可以作为 MCMC 的有用替代方案。然而，它要求我们能够高效地评估似然比项 \(\frac{\gamma_t(\boldsymbol{\theta}_t)}{\gamma_{t-1}(\boldsymbol{\theta}_t)}\)。在无法做到这一点的情况下（例如，对于隐变量模型），我们可以使用 SMC（具体来说是公式 (13.10) 中的估计 \(\hat{Z}_t\)）作为子例程来近似这些似然。这称为 **SMC²**。详情见 [CP20b, 第 18 章]。
