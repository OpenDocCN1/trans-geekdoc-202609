We can then compute a Monte Carlo approximation to this:

$$\widehat{\nabla_\psi \mathbb{L}(\psi_t)} = \frac{1}{S} \sum_{s=1}^S \tilde{\mathcal{L}}(\psi, z_s) \nabla_\psi \log q_\psi(z_s)|_{\psi=\psi_t}$$

We can pass this to any kind of gradient optimizer, such as SGD or Adam.

# 10.2.3.2 Reducing the variance using control variates

In practice, the variance of this estimator is quite large, so it is important to use methods such as control variates or CV (Section 6.3.4.1). To see how this works, consider the naive gradient estimator in Equation (10.67), which for the $i$'th component we can write as

$$\nabla_{\psi_i} \widehat{\mathbb{L}(\psi_t)}^{\text{naive}} = \frac{1}{S} \sum_{s=1}^S \tilde{g}_i(z_s)$$

$$\tilde{g}_i(z_s) = g_i(z_s) \times \tilde{\mathcal{L}}(\psi, z_s) \qquad g_i(z_s) = \nabla_{\psi_i} \log q_\psi(z_s)$$

The control variate version of this can be obtained by replacing $\tilde{g}_i(z_s)$ with

$$\tilde{g}_i^{cv}(z) = \tilde{g}_i(z) + c_i(\mathbb{E}[b_i(z)] - b_i(z))$$

where $b_i(z)$ is a baseline function, $c_i$ is some constant, to be specified below. A convenient baseline is the score function, $b_i(z) = \nabla_{\psi_i} \log q_\psi(z) = g_i(z)$, since this is correlated with $\tilde{g}_i(z)$, and has the property that $\mathbb{E}[b_i(z)] = \mathbf{0}$, since the expected value of the score function is zero, as we showed in Equation (3.44). Hence

$$\tilde{g}_i^{cv}(z) = \tilde{g}_i(z) - c_i g_i(z) = g_i(z)(\tilde{\mathcal{L}}(\psi, z) - c_i)$$

so the CV estimator is given by

$$\nabla_{\psi_i} \widehat{\mathbb{L}(\psi_t)}^{cv} = \frac{1}{S} \sum_{s=1}^S g_i(z_s) \times (\tilde{\mathcal{L}}(\psi, z_s) - c_i)$$

One can show that the optimal $c_i$ that minimizes the variance of the CV estimator is

$$c_i = \frac{\text{Cov}[g_i(z) \tilde{\mathcal{L}}(\psi, z), g_i(z)]}{\mathbb{V}[g_i(z)]}$$

For more details, see e.g., [TND21].
