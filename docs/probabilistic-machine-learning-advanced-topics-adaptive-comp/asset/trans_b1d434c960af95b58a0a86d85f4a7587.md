\(\text{mean} = \boldsymbol{\mu}, \text{ mode } = \boldsymbol{\mu}, \text{ cov } = \frac{\nu}{\nu - 2} \boldsymbol{\Sigma} \quad (2.51)\)

均值仅在 \(\nu > 1\) 时有定义（有限）。同样，协方差仅在 \(\nu > 2\) 时有定义。

## 2.2.5.3 圆形正态（von Mises Fisher）分布

有时数据位于单位球面上，而不是欧几里得空间中的任意点。例如，任何 \(\ell_2\) 归一化的 \(D\) 维向量都位于嵌入于 \(\mathbb{R}^D\) 中的单位 \((D-1)\) 球面上。有一种适用于此类角数据的高斯分布扩展，称为 von Mises-Fisher 分布，或圆形正态分布。它有如下概率密度函数：

\(\text{vMF}(\boldsymbol{x} | \boldsymbol{\mu}, \kappa) \triangleq \frac{1}{Z} \exp(\kappa \boldsymbol{\mu}^\mathsf{T} \boldsymbol{x}) \quad (2.52)\)

\(Z = \frac{(2\pi)^{D/2} I_{D/2 - 1}(\kappa)}{\kappa^{D/2 - 1}} \quad (2.53)\)

其中 \(\boldsymbol{\mu}\) 是均值（满足 \(||\boldsymbol{\mu}||=1\)），\(\kappa \ge 0\) 是浓度或精度参数（类似于标准高斯分布中的 \(1/\sigma\)），\(Z\) 是归一化常数，且 \(I_r(\cdot)\) 为第一类第 \(r\) 阶修正贝塞尔函数。vMF 类似于球形多元高斯分布，但由**余弦距离**而非欧几里得距离参数化。

vMF 分布可用于混合模型中对 \(\ell_2\) 归一化向量进行聚类，作为使用高斯混合模型 [Ban+05] 的替代方案。若 \(\kappa \rightarrow 0\)，则退化为球形 K-means 算法。它还可用于混合模型（第 28.4.2 节），这被称为球形主题模型 [Rei+10]。

若 \(D=2\)，另一种选择是在单位圆上使用 von Mises 分布，其形式为

\(\text{vMF}(x | \mu, \kappa) = \frac{1}{Z} \exp(\kappa \cos(x - \mu)) \quad (2.54)\)

\(Z = 2\pi I_0(\kappa) \quad (2.55)\)

## 2.2.5.4 矩阵正态分布（MN）

矩阵正态分布由定义在矩阵 \(\mathbf{X} \in \mathbb{R}^{n \times p}\) 上的以下概率密度函数给出：

\(\mathcal{MN}(\mathbf{X} | \mathbf{M}, \mathbf{U}, \mathbf{V}) \triangleq \frac{|\mathbf{V}|^{n/2}}{2\pi^{np/2} |\mathbf{U}|^{p/2}} \exp \left\{ -\frac{1}{2} \text{tr} \left[ (\mathbf{X} - \mathbf{M})^\mathsf{T} \mathbf{U}^{-1} (\mathbf{X} - \mathbf{M}) \mathbf{V} \right] \right\} \quad (2.56)\)

其中 \(\mathbf{M} \in \mathbb{R}^{n \times p}\) 是 \(\mathbf{X}\) 的均值，\(\mathbf{U} \in \mathcal{S}_{++}^{n \times n}\) 是行间的协方差，\(\mathbf{V} \in \mathcal{S}_{++}^{p \times p}\) 是列间的精度。可以看到

\(\text{vec}(\mathbf{X}) \sim \mathcal{N}(\text{vec}(\mathbf{M}), \mathbf{V}^{-1} \otimes \mathbf{U}). \quad (2.57)\)

需要注意的是，矩阵正态分布的定义有另一个版本，它使用列协方差矩阵 \(\tilde{\mathbf{V}} = \mathbf{V}^{-1}\) 而不是 \(\mathbf{V}\)，从而导致如下密度

\(\frac{1}{2\pi^{np/2} |\mathbf{U}|^{p/2} |\tilde{\mathbf{V}}|^{n/2}} \exp \left\{ -\frac{1}{2} \text{tr} \left[ (\mathbf{X} - \mathbf{M})^\mathsf{T} \mathbf{U}^{-1} (\mathbf{X} - \mathbf{M}) \tilde{\mathbf{V}}^{-1} \right] \right\}.\)

这两个定义版本显然是等价的，但我们将看到，我们在公式 (2.56) 中采用的定义将导致后验分布的整洁更新（就像在使用共轭先验分析多元正态分布的后验时，精度矩阵比协方差矩阵更方便使用一样）。

## 2.2.5.5 Wishart 分布

Wishart 分布是伽马分布到正定矩阵的推广。Press [Pre05, p107] 曾说，“Wishart 分布在多元统计学中的重要性和实用性方面，仅次于正态分布”。我们将主要使用它来建模估计协方差矩阵时的不确定性（参见第 3.4.4 节）。

Wishart 的概率密度函数定义如下：

\(Wi(\mathbf{S}|\mathbf{\Sigma}, \nu) \triangleq \frac{1}{Z} |\mathbf{\Sigma}|^{(\nu-D-1)/2} \exp \left( -\frac{1}{2} \text{tr}(\mathbf{\Sigma}\mathbf{S}^{-1}) \right)\)

\(Z \triangleq |\mathbf{S}|^{-\nu/2} 2^{\nu D/2} \Gamma_D(\nu/2)\)

这里 \(\nu\) 称为“自由度”，\(\mathbf{S}\) 称为“尺度矩阵”。（我们稍后将对这些参数有更多直觉。）归一化常数仅在 \(\nu > D - 1\) 时存在（因此概率密度函数仅在此时有定义）。

该分布具有以下性质：

\(\text{mean} = \nu\mathbf{S}, \quad \text{mode} = (\nu - D - 1)\mathbf{S}\)

注意，众数仅在 \(\nu > D + 1\) 时存在。

若 \(D=1\)，Wishart 退化为伽马分布：

\(Wi(\lambda | s^{-1}, \nu) = \text{Ga}(\lambda | \text{shape} = \frac{\nu}{2}, \text{rate} = \frac{1}{2s})\)

若 \(s=2\)，则退化为卡方分布。

Wishart 分布与高斯分布之间存在有趣的联系。特别是，设 \(\mathbf{x}_n \sim \mathcal{N}(0, \mathbf{\Sigma})\)。可以证明，散射矩阵 \(\mathbf{S} = \sum_{n=1}^N \mathbf{x}_n \mathbf{x}_n^\mathsf{T}\) 服从 Wishart 分布：\(\mathbf{S} \sim Wi(\mathbf{\Sigma}, N)\)。

## 2.2.5.6 逆 Wishart 分布

若 \(\lambda \sim \text{Ga}(a, b)\)，则 \(\frac{1}{\lambda} \sim \text{IG}(a, b)\)。类似地，若 \(\mathbf{\Sigma}^{-1} \sim Wi(\mathbf{S}^{-1}, \nu)\)，则 \(\mathbf{\Sigma} \sim IW(\mathbf{S}, \nu)\)，其中 IW 是逆 Wishart 分布，即逆伽马分布的多维推广。对于 \(\nu > D - 1\) 和 \(\mathbf{S} \succ 0\)，其定义如下：

\(IW(\mathbf{\Sigma}|\mathbf{S}, \nu) = \frac{1}{Z} |\mathbf{\Sigma}|^{-(\nu+D+1)/2} \exp \left( -\frac{1}{2} \text{tr}(\mathbf{S}\mathbf{\Sigma}^{-1}) \right)\)

\(Z_{IW} = |\mathbf{S}|^{-\nu/2} 2^{\nu D/2} \Gamma_D(\nu/2)\)

可以证明，该分布具有以下性质：

\(\text{mean} = \frac{\mathbf{S}}{\nu - D - 1}, \quad \text{mode} = \frac{\mathbf{S}}{\nu + D + 1}\) (2.65)

若 \(D = 1\)，则其退化为逆伽马分布：

\(\text{IW}(\sigma^2 | s^{-1}, \nu) = \text{IG}(\sigma^2 | \nu/2, s/2)\) (2.66)

若 \(s = 1\)，则其退化为逆卡方分布。

## 2.2.5.7 Dirichlet 分布

beta 分布的多元推广是 **狄利克雷** 分布，其支撑集定义在 **概率单纯形** 上，即

\(S_K = \{ \mathbf{x} : 0 \le x_k \le 1, \sum_{k=1}^K x_k = 1 \}\) (2.67)

概率密度函数定义如下：

\(\text{Dir}(\mathbf{x} | \boldsymbol{\alpha}) \triangleq \frac{1}{B(\boldsymbol{\alpha})} \prod_{k=1}^K x_k^{\alpha_k - 1} \mathbb{I}(\mathbf{x} \in S_K)\) (2.68)

其中 \(B(\boldsymbol{\alpha})\) 是多元 beta 函数，

\(B(\boldsymbol{\alpha}) \triangleq \frac{\prod_{k=1}^K \Gamma(\alpha_k)}{\Gamma(\sum_{k=1}^K \alpha_k)}\) (2.69)

图 2.6 展示了 \(K=3\) 时狄利克雷分布的一些图示。我们可以看到，\(\alpha_0 = \sum_k \alpha_k\) 控制分布的强度（即峰值有多尖锐），而 \(\alpha_k\) 控制峰值出现的位置。例如，Dir\((1,1,1)\) 是均匀分布，Dir\((2,2,2)\) 是以 \((1/3,1/3,1/3)\) 为中心的宽分布，而 Dir\((20,20,20)\) 是以 \((1/3,1/3,1/3)\) 为中心的窄分布。Dir\((3,3,20)\) 是一个非对称分布，将更多密度集中在单纯形的一个角上。如果所有 \(k\) 都有 \(\alpha_k < 1\)，则在单纯形的角上会出现“尖峰”。当 \(\alpha_k < 1\) 时从该分布采样得到的样本是稀疏的，如图 2.7 所示。

供今后参考，以下是狄利克雷分布的一些有用性质：

\(\mathbb{E}[x_k] = \frac{\alpha_k}{\alpha_0}, \quad \text{mode } [x_k] = \frac{\alpha_k - 1}{\alpha_0 - K}, \quad \mathbb{V}[x_k] = \frac{\alpha_k(\alpha_0 - \alpha_k)}{\alpha_0^2(\alpha_0 + 1)}\) (2.70)

其中 \(\alpha_0 = \sum_k \alpha_k\)。

我们通常使用形式为 \(\alpha_k = \alpha/K\) 的对称 Dirichlet 先验。在此情况下，\(\mathbb{E}[x_k] = 1/K\)，且 \(\mathbb{V}[x_k] = \frac{K-1}{K^2(\alpha+1)}\)。由此可见，增大 \(\alpha\) 会提高分布的精度（即减小方差）。
