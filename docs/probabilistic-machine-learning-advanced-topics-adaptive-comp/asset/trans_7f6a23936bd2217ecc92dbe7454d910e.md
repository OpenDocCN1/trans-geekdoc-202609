在线学习对决策和控制问题非常有用，例如多臂老虎机（第 34.4 节）和强化学习（见第 35 章），其中代理“永生”，且没有固定的训练阶段随后是测试阶段。（例如，第 17.5 节讨论了神经网络的在线贝叶斯推断。）

之前的持续学习场景可视为在线学习的特例：我们在每个时间步使用不同的分布（任务），并提供一组示例作为输入，而不是单个示例。在奇数时间步，我们使用当前分布的数据进行训练，损失为 0；在偶数时间步，我们在测试分布上进行评估，该分布可能由所有先前见过的任务的并集组成，并返回经验损失。（因此在旧分布上表现良好很重要，因为我们假设此类分布会反复出现。）通常在 CL 中，每个任务的数据量很大，而在线学习更关注使用少量数据快速适应缓慢（或分段连续）变化的分布。

## 19.8 对抗样本

*本节由 Justin Gilmer 合著。*

在第 19.2 节中，我们讨论了当输入分布因某种原因发生偏移时，预测模型会发生什么。在本节中，我们考虑对手故意选择输入以最小化预测模型性能的情况。也就是说，假设输入 \(\mathbf{x}\) 被分类为属于类 \(c\)。然后我们选择一个新的输入 \(\mathbf{x}_{adv}\)，使该标签的概率最小化，前提是 \(\mathbf{x}_{adv}\) 与原始输入 \(\mathbf{x}\) 在“感知上相似”。这产生了以下目标：

```
\(\mathbf{x}_{adv} = \underset{\mathbf{x}' \in \Delta(\mathbf{x})}{\text{argmin}} \log p(y=c|\mathbf{x}') \qquad (19.46)\)
```

其中 \(\Delta(\mathbf{x})\) 是与 \(\mathbf{x}\) “相似”的图像集合（下面我们将讨论不同的相似性概念）。

方程 (19.46) 是 **对抗攻击** 的一个示例。我们在图 19.23 中对此进行了说明。输入图像 \(\mathbf{x}\) 在左侧，被预测为熊猫，概率为 57%。通过向输入添加少量精心选择的噪声（中间所示），我们生成右侧的 **对抗图像** \(\mathbf{x}_{adv}\)：它“看起来像”输入，但现在被分类为长臂猿，概率为 99%。

创建对抗图像的能力最初在 [Sze+14] 中被注意到。创建此类示例出乎意料地容易，这似乎很矛盾，因为现代分类器在正常输入上似乎效果很好，而对人类来说，扰动后的图像“看起来”是一样的。我们在第 19.8.5 节解释了这个悖论。

对抗图像的存在也引发了安全问题。例如，[Sha+16] 表明，只需让人 A 戴上带有特殊图案的太阳镜，就可以迫使人脸识别系统将人 A 误分类为人 B；[Eyk+18] 表明，可以将小的“对抗贴纸”贴在交通标志上，将停车标志分类为限速标志。

下面我们简要讨论如何创建对抗攻击、它们为何发生，以及我们如何尝试防御。我们主要关注图像深度神经网络的情况，但需要注意的是，许多其他类型的模型（包括逻辑回归和生成模型）也可能遭受对抗攻击。此外，这并不局限于图像领域，还出现在许多类型的高维输入中。例如，[Li+19] 包含音频攻击，[Dal+04; Jia+19] 包含文本攻击。关于对抗样本的更多细节可参见例如 [Wiy+19; Yua+19]。

### 19.8.1 白盒（基于梯度）攻击

要创建对抗样本，我们必须找到一个“小”扰动 \(\boldsymbol{\delta}\) 添加到输入 \(\boldsymbol{x}\) 以创建 \(\boldsymbol{x}_{\text{adv}} = \boldsymbol{x} + \boldsymbol{\delta}\)，使得 \(f(\boldsymbol{x}_{\text{adv}}) = y'\)，其中 \(f()\) 是分类器，\(y'\) 是我们希望系统输出的标签。这称为 **目标攻击**。或者，我们可能只想找到一个扰动，使当前预测标签从当前值变为任何其他值，使得 \(f(\boldsymbol{x} + \boldsymbol{\delta}) \neq f(\boldsymbol{x})\)，这称为 **非目标攻击**。

通常，我们将对手的目标定义为 *最大化* 以下损失：

```
\boldsymbol{x}_{\text{adv}} = \argmax_{\boldsymbol{x}' \in \Delta(\boldsymbol{x})} \mathcal{L}(\boldsymbol{x}', y; \boldsymbol{\theta})
```

其中 \(y\) 是真实标签。对于非目标情况，我们可以定义 \(\mathcal{L}(\boldsymbol{x}', y; \boldsymbol{\theta}) = -\log p(y|\boldsymbol{x}')\)，从而最小化真实标签的概率；对于目标情况，我们可以定义 \(\mathcal{L}(\boldsymbol{x}', y; \boldsymbol{\theta}) = \log p(y'|\boldsymbol{x}')\)，从而最大化所需标签 \(y' \neq y\) 的概率。

为了定义我们所说的“小”扰动，我们施加约束 \(\boldsymbol{x}_{\text{adv}} \in \Delta(\boldsymbol{x})\)，这是输入 \(\boldsymbol{x}\) 的“感知相似”图像集合。大部分文献关注一种简化设置，即对手被限制对干净输入 \(\boldsymbol{x}\) 进行有界 \(l_p\) 扰动，即

```
\Delta(\boldsymbol{x}) = \{ \boldsymbol{x}' : ||\boldsymbol{x}' - \boldsymbol{x}||_p < \epsilon \}
```

通常人们假设 p = 1 或 p = 0。我们将在第 19.8.3 节讨论更现实的威胁模型。

在本节中，我们假设攻击者知道模型参数 \(\boldsymbol{\theta}\)；这称为 **白盒攻击**，并允许我们使用基于梯度的优化方法。我们将在第 19.8.2 节放宽这一假设。

为了求解方程 (19.47) 中的优化问题，我们可以使用任何类型的约束优化方法。在 [Sze+14] 中，他们使用了有界约束 BFGS。[GSS15] 提出了更高效的 **快速梯度符号（FGS）** 方法，该方法执行如下形式的迭代更新：

```
\boldsymbol{x}_{t+1} = \boldsymbol{x}_t + \boldsymbol{\delta}_t
\boldsymbol{\delta}_t = \epsilon \text{sign}(\nabla_{\boldsymbol{x}} \log p(y'|\boldsymbol{x}, \boldsymbol{\theta})|_{\boldsymbol{x}_t})
```
