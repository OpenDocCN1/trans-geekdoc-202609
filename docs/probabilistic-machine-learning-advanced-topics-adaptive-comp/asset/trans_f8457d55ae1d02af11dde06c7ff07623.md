## 34.7.3 获取策略

在本节中，我们讨论一些常用的 AL 启发式方法，用于选择查询哪些点。

### 34.7.3.1 不确定性采样

选择下一个标注样本的一个直观启发式方法是选择模型目前最不确定的那个样本。这称为 **不确定性采样**。我们已在回归的图 34.16 中对此进行了说明，其中用后方方差表示不确定性。对于分类问题，我们可以用多种方式衡量不确定性。设 \boldsymbol{p}_n = [p(y=c|\boldsymbol{x}_n)]_{c=1}^C 为每个未标记输入 \boldsymbol{x}_n 的类概率向量。设 U_n = \alpha(\boldsymbol{p}_n) 为样本 n 的不确定性，其中 \alpha 是获取函数。\alpha 的一些常见选择有：**熵采样** [SW87a]，使用 \alpha(\boldsymbol{p}) = - \sum_{c=1}^C p_c \log p_c；**边际采样**，使用 \alpha(\boldsymbol{p}) = p_2 - p_1，其中 p_1 是最可能类的概率，p_2 是第二可能类的概率；以及 **最不自信采样**，使用 \alpha(\boldsymbol{p}) = 1 - p_{c^*}，其中 c^* = \text{argmax}_c p_c。这些策略之间的差异如图 34.17 所示。在实践中，通常发现边际采样效果最好 [Chu+19]。

### 34.7.3.2 委员会查询

在本节中，我们讨论如何将不确定性采样应用于仅返回点预测而非概率分布的模型，例如支持向量机（SVM）。基本方法是创建一组多样化的模型，并将模型预测之间的分歧作为一种不确定性。（即使对于概率模型，如 DNN，这也可能很有用，因为模型不确定性通常可能大于参数不确定性，如我们在深度集成第 17.3.9 节中讨论的。）

更详细地说，假设我们有 K 个集成成员，设 c_n^k 为成员 k 在输入 x_n 上的预测类。设 v_nc = sum_{k=1}^K I(c_n^k = c) 为投给类 c 的票数，q_nc = v_nc / C 为诱导分布。（类似方法可用于回归模型，其中我们使用成员间预测的标准差。）然后我们可以使用分布 q_n 进行边际采样或熵采样。这种方法称为委员会查询（QBC）[SOS92]，通常可以优于单一模型的标准不确定性采样，如图 34.18 所示。

### 34.7.3.3 信息论方法

一种自然的获取策略是选择其标签将最大限度地减少我们对模型参数 w 不确定性的点。这称为 **信息增益** 准则，最初在 [Lin56] 中提出。定义如下：

\(\alpha(\boldsymbol{x}) \triangleq \mathbb{H} \left(p(\boldsymbol{w}|\mathcal{D})\right) - \mathbb{E}_{p(y|\boldsymbol{x},\mathcal{D})} [\mathbb{H} \left(p(\boldsymbol{w}|\mathcal{D}, \boldsymbol{x}, y)\right)]\)

（注意第一项关于 x 是常数，但我们包含它以便后续使用。）这等价于参数后验的预期变化，如下所示：

\(\alpha'(\boldsymbol{x}) \triangleq \mathbb{E}_{p(y|\boldsymbol{x},\mathcal{D})} [D_{\text{KL}} (p(\boldsymbol{w}|\mathcal{D}, \boldsymbol{x}, y) \| p(\boldsymbol{w}|\mathcal{D}))]\)

利用互信息的对称性，我们可以将方程 (34.95) 改写为如下形式：

\(\begin{align*}\alpha(\boldsymbol{x}) &= \mathbb{H} (\boldsymbol{w}|\mathcal{D}) - \mathbb{E}_{p(y|\boldsymbol{x},\mathcal{D})} [\mathbb{H} (\boldsymbol{w}|\mathcal{D}, \boldsymbol{x}, y)] \\ &= \mathbb{I}(\boldsymbol{w}, y|\mathcal{D}, \boldsymbol{x}) \\ &= \mathbb{H} (\boldsymbol{y}|\boldsymbol{x}, \mathcal{D}) - \mathbb{E}_{p(\boldsymbol{w}|\mathcal{D})} [\mathbb{H} (\boldsymbol{y}|\boldsymbol{x}, \boldsymbol{w}, \mathcal{D})]\end{align*}\)

这种方法的优点是，我们现在只需考虑输出 y 的预测分布的不确定性，而不必考虑参数 w 的不确定性。这种方法称为基于分歧的贝叶斯主动学习或 BALD [Hou+12]。

方程 (34.99) 有一个有趣的解释。第一项偏好那些预测标签存在不确定性的样本 x。仅使用这一点作为选择准则相当于不确定性采样，如上文所讨论。然而，这可能对固有歧义或标注错误的样本产生问题。通过添加第二项，我们对这种行为进行惩罚，因为即使我们知道参数，对于预测分布是熵的点，我们也会添加大的负权重。因此，我们忽略 aleatoric（内在）不确定性并专注于 epistemic 不确定性。

## 34.7.4 批量主动学习

在许多应用中，我们需要一次性选择一批未标记样本，因为在单个样本上训练模型太慢。这称为批量主动学习。关键挑战在于，我们需要确保所请求的不同查询是多样的，从而最大化信息增益。已为该问题提出了各种方法；在此，我们关注 [KAG19] 的 **BatchBALD** 方法，它扩展了第 34.7.3.3 节的 BALD 方法。

### 34.7.4.1 BatchBALD

将 BALD 得分扩展到一组 b 个候选查询点的简单方法是定义

\(\alpha_{\text{BALD}}(\{\boldsymbol{x}_1, \dots, \boldsymbol{x}_B\}, p(\boldsymbol{w}|\mathcal{D})) = \alpha_{\text{BALD}}(\boldsymbol{x}_{1:B}, p(\boldsymbol{w}|\mathcal{D})) = \sum_{i=1}^B \mathbb{I}(y_i; \boldsymbol{w}|\boldsymbol{x}_i, \mathcal{D})\) (34.100)

然而，这可能会选择在信息内容上非常相似的点。在 BatchBALD 中，我们使用标签集合与参数之间的联合条件互信息：

\(\alpha_{\text{BBALD}}(\boldsymbol{x}_{1:B}, p(\boldsymbol{w}|\mathcal{D})) = \mathbb{I}(\boldsymbol{y}_{1:B}; \boldsymbol{w}|\boldsymbol{x}_{1:B}, \mathcal{D}) = \mathbb{H}(\boldsymbol{y}_{1:B}|\boldsymbol{x}_{1:B}, \mathcal{D}) - \mathbb{E}_{p(\boldsymbol{w}|\mathcal{D})}[\mathbb{H}(\boldsymbol{y}_{1:B}|\boldsymbol{x}_{1:B}, \boldsymbol{w}, \mathcal{D})]\) (34.101)

为了理解这与 BALD 的区别，我们将使用信息图来表示互信息，形式如文氏图，如第 5.3.2 节所述。特别是，[Yeu91a] 表明，对于离散随机变量 x 和 y，我们可以定义一个有符号测度 \(\mu^*\)，使得 \(\mathbb{I}(x; y) = \mu^*(x \cap y)\)、\(\mathbb{H}(x, y) = \mu^*(x \cup y)\)、\(\mathbb{E}_{p(y)}[\mathbb{H}(x|y)] = \mu^*(x \backslash y)\) 等。利用这一点，我们可以将标准 BALD 解释为单个交集之和 \(\sum_i \mu^*(y_i \cap \boldsymbol{w})\)，这会对 y_i 之间的重叠进行重复计算，如图 34.19(a) 所示。相比之下，BatchBALD 通过计算以下内容来考虑重叠：

\(\mathbb{I}(\boldsymbol{y}_{1:B}; \boldsymbol{w}|\boldsymbol{x}_{1:B}, \mathcal{D}) = \mu^*(\cup_i y_i \cap \boldsymbol{w}) = \mu^*(\cup_i y_i) - \mu^*(\cup_i y_i \backslash \boldsymbol{w})\) (34.102)

这在图 34.19(b) 中得到说明。由此可以看出，\(\alpha_{\text{BBALD}} \le \alpha_{\text{BALD}}\)。实际上，可以证明^6

\(\mathbb{I}(\boldsymbol{y}_{1:B}; \boldsymbol{w}|\boldsymbol{x}_{1:B}, \mathcal{D}) = \sum_{i=1}^B \mathbb{I}(y_i, \boldsymbol{w}|\boldsymbol{x}_{1:B}, \mathcal{D}) - \mathbb{TC}(\boldsymbol{y}_{1:B}|\boldsymbol{x}_{1:B}, \mathcal{D})\) (34.103)

其中 TC 是总相关性（参见第 5.3.5.1 节）。

6. See `http://blog.blackhc.net/2022/07/kbald/`

### 34.7.4.2 优化 BatchBALD

为了避免因共同对点子集进行评分而导致的组合爆炸，我们可以使用贪心近似一次计算一个点的 BatchBALD。特别是，假设在第 n-1 步时，我们已经有一个部分批次 \(\mathcal{A}_{n-1}\)。下一个点使用以下方法选择：

\(\boldsymbol{x}_n = \underset{\boldsymbol{x} \in \mathcal{D}_{\text{pool}} \backslash \mathcal{A}_{n-1}}{\text{argmax}} \alpha_{\text{BBALD}}(\mathcal{A}_{n-1} \cup \{\boldsymbol{x}\}, p(\boldsymbol{w}|\mathcal{D}))\) (34.104)

然后我们将 \(\boldsymbol{x}_n\) 添加到 \(\mathcal{A}_{n-1}\) 中以得到 \(\mathcal{A}_n\)。幸运的是，BatchBALD 获取函数是次模的，如 [KAG19] 所示。因此，该贪心算法在最优值的 \(1 - 1/e \approx 0.63\) 范围内（参见第 6.9.4.1 节）。
