

### 3.8.7.1 最小描述长度 (MDL)

我们可以用信息论（第 5 章）的术语来思考为不同模型打分的问题。目标是发送者将数据传达给接收者。首先，发送者需要指定使用哪个模型 m；这需要 C(m) = -log p(m) 比特（参见第 5.2 节）。然后，接收者可以通过计算 \(\hat{\theta}_m\) 来拟合模型，从而近似地重建数据。为了完美重建数据，发送者需要发送模型无法解释的残差误差；这需要

```
-L(m) = - \log p(\mathcal{D}|\hat{\theta}, m) = - \sum_n \log p(y_n | x_n, \hat{\theta}, m)
```

比特。（我们忽略发送输入特征 \(\boldsymbol{x}_n\) 的成本，如果存在的话。）总成本是

```
\mathcal{L}_{\text{MDL}}(m) = - \log p(\mathcal{D}|\hat{\theta}, m) + C(m)
```

选择使该成本最小的模型称为最小描述长度或 MDL 原则。有关详细信息，请参见例如 [HY01]。

### 3.8.7.2 贝叶斯信息准则 (BIC)

贝叶斯信息准则或 BIC [Sch78] 与 MDL 类似，形式为

```
\mathcal{L}_{\text{BIC}}(m) = -2 \log p(\mathcal{D}|\hat{\theta}, m) + D_m \log N
```

其中 D_m 是模型 m 的自由度。

我们可以将 BIC 得分作为对数边缘似然的简单近似来推导。特别是，假设我们对后验进行高斯近似，如第 7.4.3 节所讨论。那么我们从方程 (7.28) 得到如下结果：

```
\log p(\mathcal{D}|m) \approx \log p(\mathcal{D}|\hat{\theta}_{\text{map}}) + \log p(\hat{\theta}_{\text{map}}) - \frac{1}{2} \log |\mathbf{H}|
```

其中 H 是在 MAP 估计 \(\hat{\theta}_{\text{map}}\) 处计算的负对数联合分布 log p(\(\mathcal{D}, \theta\)) 的黑森矩阵。我们可以看到方程 (3.309) 是对数似然加上一些罚项。如果我们有一个统一先验，\(p(\theta) \propto 1\)，我们可以丢弃先验项，并用 MLE \(\hat{\theta}\) 替换 MAP 估计，得到

```
\log p(\mathcal{D}|m) \approx \log p(\mathcal{D}|\hat{\theta}) - \frac{1}{2} \log |\mathbf{H}|
```

我们现在专注于近似 log \(|\mathbf{H}|\) 项，有时称为奥卡姆因子，因为它是模型复杂度（后验分布的体积）的度量。我们有 \(\mathbf{H} = \sum_{i=1}^N \mathbf{H}_i\)，其中 \(\mathbf{H}_i = \nabla \nabla \log p(\mathcal{D}_i | \theta)\)。让我们用固定矩阵 \(\hat{\mathbf{H}}\) 近似每个 \(\mathbf{H}_i\)。那么我们有

```
\log |\mathbf{H}| = \log |N \hat{\mathbf{H}}| = \log (N^D |\hat{\mathbf{H}}|) = D \log N + \log |\hat{\mathbf{H}}|
```

其中 D = \(\dim(\theta)\)，并且我们假设 H 是满秩的。我们可以丢弃 log \(|\hat{\mathbf{H}}|\) 项，因为它与 N 无关，因此会被似然淹没。将所有部分结合起来，我们得到希望最大化的 BIC 得分：

```
J_{\text{BIC}}(m) = \log p(\mathcal{D}|\hat{\theta}, m) - \frac{D_m}{2} \log N
```

我们还可以通过乘以 $-2$ 定义希望最小化的 **BIC 损失**：

```
$\mathcal{L}_{\text{BIC}}(m) = -2 \log p(\mathcal{D}|\hat{\theta}, m) + D_m \log N$
```

### 3.8.7.3 赤池信息准则

**赤池信息准则** [Aka74] 与 BIC 密切相关。其形式为

```
$\mathcal{L}_{\text{AIC}}(m) = -2 \log p(\mathcal{D}|\hat{\theta}, m) + 2 D_m$
```

与 BIC 相比，这对复杂模型的惩罚较轻，因为正则化项与 $N$ 无关。该估计量可以从频率派视角推导出来。

### 3.8.7.4 广泛适用信息准则 (WAIC)

MDL、BIC 和 AIC 的主要问题是，计算模型的自由度可能比较困难，而自由度是定义复杂度项所需的，因为大多数参数高度相关，且无法从似然中唯一识别。特别是，如果参数到似然的映射不是一对一的，那么该模型被称为**奇异统计模型**，因为相应的 Fisher 信息矩阵（第 3.3.4 节）以及上述的黑森矩阵 **H** 可能是奇异的（行列式为 0）。即使在奇异情况下也适用的一种替代准则称为**广泛适用信息准则**（WAIC），也称为**渡边–赤池信息准则** [Wat10; Wat13]。

WAIC 与其他信息准则类似，只是它更具贝叶斯特性。首先，它用 LPPD 替换了使用参数点估计的对数似然 $L(m)$，LPPD 将参数边缘化掉。（参见方程 (3.295)）。对于复杂度项，WAIC 使用预测分布的方差：

```
$C(m) = \sum_{n=1}^N \mathbb{V}_{\theta|\mathcal{D},m}[\log p(y_n|x_n, \theta, m)] \approx \sum_{n=1}^N \mathbb{V}\{\log p(y_n|x_n, \theta_s, m) : s = 1 : S\}$
```

其直觉如下：对于给定数据点 $n$，如果不同的后验样本 $\theta_s$ 作出非常不同的预测，那么模型是不确定的，并且可能过于灵活。复杂度项基本上计算这种情况发生的频率。最终的 WAIC 损失为

```
$\mathcal{L}_{\text{WAIC}}(m) = -2 \text{LPPD}(m) + 2 C(m)$
```

有趣的是，可以证明第 3.8.6 节中的 PSIS LOO 估计量与 WAIC 渐近等价 [VGG17]。

## 3.9 模型检查

贝叶斯推断和决策是最优的，但前提是建模假设正确。在本节中，我们将讨论评估模型是否合理的几种方法。从贝叶斯角度看，这似乎有点奇怪，因为如果我们知道有更好的模型，为什么不直接使用它呢？这里我们假设我们没有特定的替代模型（因此我们不进行模型选择，与第 3.8.1 节不同）。相反，我们只是想看看观察到的数据是否“典型”，即如果我们的模型正确，我们可能会期望看到的数据。这称为**模型检查**。

### 3.9.1 后验预测检验

假设我们正在尝试估计硬币正面朝上的概率，\(\theta \in [0, 1]\)。我们有两个候选模型或假设，\(M_1\) 对应 \(\theta = 0.99\)，\(M_2\) 对应 \(\theta = 0.01\)。假设我们抛硬币 40 次，出现 30 次正面。显然我们有 \(p(M = M_1 | \mathcal{D}) \gg p(M = M_2 | \mathcal{D})\)。然而模型 \(M_1\) 对于数据来说仍然是一个非常糟糕的模型。（此示例来自 [Kru15, p331]。）

为了评估候选模型 \(M\) 在观察到一些数据 \(\mathcal{D}\) 后的优劣，我们可以想象使用该模型生成合成的未来数据集，通过从后验预测分布中抽样：

```
\(\tilde{\mathcal{D}}^s \sim p(\tilde{\mathcal{D}} | M, \mathcal{D}) = \{y_{1:N}^s \sim p(\cdot | M, \theta^s), \theta^s \sim p(\theta | \mathcal{D}, M)\}\)
```

这些代表模型的“合理幻觉”。为了评估模型的质量，我们可以计算观察到的数据 \(\mathcal{D}\) 与模型的幻觉相比是多么“典型”。为了进行此比较，我们创建一个或多个标量**检验统计量**，\(\text{test}(\tilde{\mathcal{D}}^s)，并将其与实际数据上的检验统计量 \(\text{test}(\mathcal{D})\) 进行比较。这些统计量应衡量感兴趣的特征（因为一般来说，不可能用给定模型捕捉数据的每个方面）。如果 \(\text{test}(\tilde{\mathcal{D}}^s)\) 在不同 \(s\) 之间的分布与 \(\text{test}(\mathcal{D})\) 的值之间存在较大差异，则表明模型不佳。这种方法称为**后验预测检验** [Rub84]。

### 3.9.1.1 示例：一维高斯分布

为了更清楚地说明，让我们考虑 [Gel+04] 中的一个示例。1882 年，Newcomb 使用某种方法测量光速，并获得了 \(N = 66\) 个测量值，如图 3.25(a) 所示。左侧尾部明显有两个异常值，表明分布不是高斯分布。尽管如此，我们还是来拟合一个高斯分布。为了简单起见，我们将只计算 MLE，并使用后验预测密度的插件近似：

```
\(p(\tilde{y} | \mathcal{D}) \approx \mathcal{N}(\tilde{y} | \hat{\mu}, \hat{\sigma}^2), \quad \hat{\mu} = \frac{1}{N} \sum_{n=1}^N y_n, \quad \hat{\sigma}^2 = \frac{1}{N} \sum_{n=1}^N (y_n - \hat{\mu})^2\)
```

设 \(\tilde{\mathcal{D}}^s\) 为从该分布中采样的 \(s\) 个大小为 \(N = 66\) 的数据集，其中 \(s = 1 : 1000\)。这些样本中某些数据集的 \(\tilde{\mathcal{D}}^s\) 直方图如图 3.25(b) 所示。很明显，没有一个样本包含真实数据中出现的大负值。这表明该模型无法捕捉数据中存在的长尾。（我们假设这些极端值在科学上很有趣，并且是我们希望模型捕捉的内容。）

一种更正式的拟合检验方法是定义一个检验统计量。由于我们关心小值，让我们使用

```
\(\text{test}(\mathcal{D}) = \min\{y : y \in \mathcal{D}\}\)
```

图 3.25(c) 显示了 \(s = 1 : 1000\) 时 \(\text{test}(\tilde{\mathcal{D}}^s)\) 的经验分布。对于真实数据，\(\text{test}(\mathcal{D}) = -44\)，但生成数据的检验统计量 \(\text{test}(\tilde{\mathcal{D}})\) 要大得多。事实上，我们看到 \(-44\) 位于预测分布 \(p(\text{test}(\tilde{\mathcal{D}}) | \mathcal{D})\) 的左侧尾部。
