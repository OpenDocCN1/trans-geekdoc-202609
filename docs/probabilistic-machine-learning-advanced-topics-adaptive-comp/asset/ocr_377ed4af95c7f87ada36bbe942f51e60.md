need to ensure the different queries that we request are diverse, so we maximize the information gain. Various methods for this problem have been devised; here we focus on the **BatchBALD** method of [KAG19], which extends the BALD method of Section 34.7.3.3.

# 34.7.4.1 BatchBALD

The naive way to extend the BALD score to a batch of $b$ candidate query points is to define

\(\alpha_{\text{BALD}}(\{\boldsymbol{x}_1, \dots, \boldsymbol{x}_B\}, p(\boldsymbol{w}|\mathcal{D})) = \alpha_{\text{BALD}}(\boldsymbol{x}_{1:B}, p(\boldsymbol{w}|\mathcal{D})) = \sum_{i=1}^B \mathbb{I}(y_i; \boldsymbol{w}|\boldsymbol{x}_i, \mathcal{D})\) (34.100)

However this may pick points that are quite similar in terms of their information content. In BatchBALD, we use joint conditional mutual information between the set of labels and the parameters:

\(\alpha_{\text{BBALD}}(\boldsymbol{x}_{1:B}, p(\boldsymbol{w}|\mathcal{D})) = \mathbb{I}(\boldsymbol{y}_{1:B}; \boldsymbol{w}|\boldsymbol{x}_{1:B}, \mathcal{D}) = \mathbb{H}(\boldsymbol{y}_{1:B}|\boldsymbol{x}_{1:B}, \mathcal{D}) - \mathbb{E}_{p(\boldsymbol{w}|\mathcal{D})}[\mathbb{H}(\boldsymbol{y}_{1:B}|\boldsymbol{x}_{1:B}, \boldsymbol{w}, \mathcal{D})]\) (34.101)

To understand how this differs from BALD, we will use information diagrams for representing MI in terms of Venn diagrams, as explained in Section 5.3.2. In particular, [Yeu91a] showed we can define a signed measure, \(\mu^*\), for discrete random variables \(x\) and \(y\) such that \(\mathbb{I}(x; y) = \mu^*(x \cap y)\), \(\mathbb{H}(x, y) = \mu^*(x \cup y)\), \(\mathbb{E}_{p(y)}[\mathbb{H}(x|y)] = \mu^*(x \backslash y)\), etc. Using this, we can interpret standard BALD as the sum of the individual intersections, \(\sum_i \mu^*(y_i \cap \boldsymbol{w})\), which double counts overlaps between the \(y_i\), as shown in Figure 34.19(a). By contrast, BatchBALD takes overlap into account by computing

\(\mathbb{I}(\boldsymbol{y}_{1:B}; \boldsymbol{w}|\boldsymbol{x}_{1:B}, \mathcal{D}) = \mu^*(\cup_i y_i \cap \boldsymbol{w}) = \mu^*(\cup_i y_i) - \mu^*(\cup_i y_i \backslash \boldsymbol{w})\) (34.102)

This is illustrated in Figure 34.19(b). From this, we can see that \(\alpha_{\text{BBALD}} \le \alpha_{\text{BALD}}\). Indeed, one can show$^6$

\(\mathbb{I}(\boldsymbol{y}_{1:B}; \boldsymbol{w}|\boldsymbol{x}_{1:B}, \mathcal{D}) = \sum_{i=1}^B \mathbb{I}(y_i, \boldsymbol{w}|\boldsymbol{x}_{1:B}, \mathcal{D}) - \mathbb{TC}(\boldsymbol{y}_{1:B}|\boldsymbol{x}_{1:B}, \mathcal{D})\) (34.103)

where TC is the total correlation (see Section 5.3.5.1).

# 34.7.4.2 Optimizing BatchBALD

To avoid the combinatorial explosion that arises from jointly scoring subsets of points, we can use a greedy approximation for computing BatchBALD one point at a time. In particular, suppose at step \(n-1\) we already have a partial batch \(\mathcal{A}_{n-1}\). The next point is chosen using

\(\boldsymbol{x}_n = \underset{\boldsymbol{x} \in \mathcal{D}_{\text{pool}} \backslash \mathcal{A}_{n-1}}{\text{argmax}} \alpha_{\text{BBALD}}(\mathcal{A}_{n-1} \cup \{\boldsymbol{x}\}, p(\boldsymbol{w}|\mathcal{D}))\) (34.104)

We then add \(\boldsymbol{x}_n\) to \(\mathcal{A}_{n-1}\) to get \(\mathcal{A}_n\). Fortunately the BatchBALD acquisition function is submodular, as shown in [KAG19]. Hence this greedy algorithm is within \(1 - 1/e \approx 0.63\) of optimal (see Section 6.9.4.1).
