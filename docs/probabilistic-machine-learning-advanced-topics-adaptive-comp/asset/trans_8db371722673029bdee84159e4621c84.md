## 29.3.3.2 HMM model

基线模型效果良好，但仍有改进空间。特别是，如果没有上下文，许多错误将难以纠正。例如，假设用户输入了“advice”：他们是指“advice”还是“advise”？这取决于他们打算使用名词还是动词，如果不查看单词序列，这很难判断。为此，我们将模型“升级”为 HMM。我们只需将独立先验 p(z1:T) = ∏t p(zt) 替换为单词上的标准一阶语言模型 p(z1:T) = ∏t p(zt |zt−1)。该模型的参数可以通过在大量“干净”文本语料库中统计二元语法来估计（参见第 2.6.3.1 节）。观测模型 p(yt |zt) 可以保持不变。

## 29.3.3.3 Extended HMM model

我们可以扩展 HMM 模型来处理更高级别的错误，而不仅仅是单个单词的拼写错误。特别是，[LDZ11; LDZ12] 提出建模以下几种错误：

- 两个单词合并为一个，例如，“home page” → “homepage”。
- 一个单词拆分为两个，例如，“illinoisstate” → “illinois state”。
- 单词内部错误，如字母的替换、转置、插入和删除，如第 29.3.3.2 节所述。

我们可以使用 HMM 来建模这一点，其中我们用一个不发出任何符号的静默状态来扩展状态空间。图 29.11 说明了该模型如何将观测到的查询“government home page of illinoisstate”“去噪”为格式正确的查询“government homepage of illinois state”。使用 HMM 的替代方案是使用监督学习来拟合序列到序列翻译模型，使用 RNN 或 Transformer。这可以工作得很好，但通常需要更多的训练数据，这对低资源语言来说可能是个问题 [ECM18]。

## 29.4 HMMs: parameter learning

在本节中，我们将讨论如何给定一组部分观测到的序列，计算 HMM 模型参数的点估计或完整后验分布。

### 29.4.1 The Baum-Welch (EM) algorithm

在本节中，我们将讨论如何使用 EM 算法计算 HMM 参数的近似最大似然估计，EM 算法是一种迭代界优化算法（详情见第 6.5.3 节）。当应用于 HMM 时，所得方法称为 Baum-Welch 算法 [Bau+70]。

### 29.4.1.1 Log likelihood

单个序列的联合概率由下式给出：

```
p(\mathbf{y}_{1:T}, \mathbf{z}_{1:T} | \boldsymbol{\theta}) = [p(z_1 | \boldsymbol{\pi})] \left[ \prod_{t=2}^T p(z_t | z_{t-1}, \mathbf{A}) \right] \left[ \prod_{t=1}^T p(\mathbf{y}_t | \mathbf{z}_t, \mathbf{B}) \right] \tag{29.23}
```

```
= \left[ \prod_{k=1}^K \pi_k^{\mathbb{I}(z_1=k)} \right] \left[ \prod_{t=2}^T \prod_{j=1}^K \prod_{k=1}^K A_{jk}^{\mathbb{I}(z_{t-1}=j, z_t=k)} \right] \left[ \prod_{t=1}^T \prod_{k=1}^K p(\mathbf{y}_t | \mathbf{B}_k)^{\mathbb{I}(z_t=k)} \right] \tag{29.24}
```

其中 \(\boldsymbol{\theta} = (\boldsymbol{\pi}, \mathbf{A}, \mathbf{B})\)。当然，我们无法计算这个目标，因为 \(\mathbf{z}_{1:T}\) 是隐藏的。因此，我们将优化期望完全数据对数似然，其中期望是使用算法上一次迭代的参数来计算的：

```
Q(\boldsymbol{\theta}, \boldsymbol{\theta}^{old}) = \mathbb{E}_{p(\mathbf{z}_{1:T} | \mathbf{y}_{1:T}, \boldsymbol{\theta}^{old})} [\log p(\mathbf{y}_{1:T}, \mathbf{z}_{1:T} | \boldsymbol{\theta})] \tag{29.25}
```

这可以轻松地对 \(N\) 个序列求和。图形模型见图 29.12。上述目标是观测数据对数似然 \(\log p(\mathbf{y}_{1:T} | \boldsymbol{\theta})\) 的下界，因此整个过程是一种界优化方法，保证收敛到局部最优。（事实上，如果初始化合适，该方法可以证明会收敛到（接近）全局最优之一 [YBW15]。）

### 29.4.1.2 E step

设 \(A_{jk} = p(z_t = k | z_{t-1} = j)\) 为 \(K \times K\) 转移矩阵。对于第一个时间片，设 \(\pi_k = p(z_1 = k)\) 为初始状态分布。设 \(\boldsymbol{\theta}_k\) 表示状态 \(k\) 的观测模型参数。

![](img/ca72c1626f4850f058a9edc138c1ac73_1012_0.png)

图 29.12：带盘式标记的 HMM。\(A\) 是状态转移矩阵 \(p(z_t|z_{t-1})\) 的参数，\(B\) 是离散观测模型 \(p(x_t|z_t)\) 的参数。\(T_n\) 是第 \(n\) 个序列的长度。

为了计算期望充分统计量，我们首先对每个序列运行前向-后向算法（参见第 9.2.3 节）。这将返回以下节点和边缘边缘分布：

$$ \gamma_{n,t}(j) \triangleq p(z_t = j|y_{n,1:T_n}, \theta^{old}) \tag{29.26} $$  
$$ \xi_{n,t}(j, k) \triangleq p(z_{t-1} = j, z_t = k|y_{n,1:T_n}, \theta^{old}) \tag{29.27} $$

其中 \(T_n\) 是序列 \(n\) 的长度。然后我们可以按如下方式推导期望计数（注意，我们跨时间和跨序列聚合充分统计量，因为参数是共享的）：

$$ \mathbb{E}[N_k^1] = \sum_{n=1}^N \gamma_{n,1}(k), \mathbb{E}[N_k] = \sum_{n=1}^N \sum_{t=2}^{T_n} \gamma_{n,t}(k), \mathbb{E}[N_{jk}] = \sum_{n=1}^N \sum_{t=2}^{T_n} \xi_{n,t}(j, k) \tag{29.28} $$

给出上述量之后，我们可以按如下方式计算期望完全数据对数似然：

$$ Q(\theta, \theta^{old}) = \sum_{k=1}^K \mathbb{E}[N_k^1] \log \pi_k + \sum_{j=1}^K \sum_{k=1}^K \mathbb{E}[N_{jk}] \log A_{jk} + \sum_{n=1}^N \sum_{t=1}^{T_n} \sum_{k=1}^K p(z_t = k|y_{n,1:T_n}, \theta^{old}) \log p(y_{n,t}|\theta_k) \tag{29.29} $$

### 29.4.1.3 M step

我们可以通过在和为一的约束下最大化目标来估计转移矩阵和初始状态概率。结果只是期望计数的归一化版本：

$$ \hat{A}_{jk} = \frac{\mathbb{E}[N_{jk}]}{\sum_{k'} \mathbb{E}[N_{jk'}]}, \hat{\pi}_k = \frac{\mathbb{E}[N_k^1]}{N} \tag{29.30} $$

这个结果非常直观：我们只需将从 \(j\) 到 \(k\) 的预期转移次数相加，然后除以从 \(j\) 转移到任何其他状态的预期次数。

对于类别观测模型，期望充分统计量为
\[\mathbb{E} [M_{kv}] = \sum_{n=1}^N \sum_{t=1}^{T_n} \gamma_{n,t}(k) \mathbb{I}(y_{n,t} = v) = \sum_{n=1}^N \sum_{t:y_{n,t}=v} \gamma_{n,t}(k) \tag{29.31}\]

M 步的形式为

\[\hat{B}_{kv} = \frac{\mathbb{E} [M_{kv}]}{\mathbb{E} [N_k]} \tag{29.32}\]

这个结果非常直观：我们只需将处于状态 \(k\) 且观测到符号 \(v\) 的预期次数相加，然后除以处于状态 \(k\) 的预期次数。伪代码见算法 11。

对于高斯观测模型，期望充分统计量由以下给出

\[\overline{y}_k = \sum_{n=1}^N \sum_{t=1}^{T_n} \gamma_{n,t}(k) y_{n,t}, \quad \overline{yy^\top}_k = \sum_{n=1}^N \sum_{t=1}^{T_n} \gamma_{n,t}(k) y_{n,t} y_{n,t}^\top \tag{29.33}\]

M 步变为

\[\hat{\mu}_k = \frac{\overline{y}_k}{\mathbb{E} [N_k]} \tag{29.34}\]

\[\hat{\Sigma}_k = \frac{\overline{y y^\top}_k - \mathbb{E} [N_k] \hat{\mu}_k \hat{\mu}_k^\top}{\mathbb{E} [N_k]} \tag{29.35}\]

在实践中，我们通常需要向这些估计添加一个对数先验，以确保得到的 \(\hat{\Sigma}_k\) 估计值条件良好。详情见 [Mur22, Sec 4.5.2]。

```
**Algorithm 29.1:** Baum-Welch algorithm for (discrete observation) HMMs

1 Initialize parameters \(\theta\)
2 for each iteration do
  3 // E step
  4 Initialize expected counts: \(\mathbb{E} [N_k] = 0\), \(\mathbb{E} [N_{jk}] = 0\), \(\mathbb{E} [M_{kv}] = 0\)
  5 for each datacase n do
    6 Use forwards-backwards algorithm on \(\boldsymbol{y}_n\) to compute \(\gamma_{n,t}\) and \(\xi_{n,t}\)
       (Equations 29.26-29.27)
    7 \(\mathbb{E} [N_k] := \mathbb{E} [N_k] + \sum_{t=2}^{T_n} \gamma_{n,t}(k)\)
    8 \(\mathbb{E} [N_{jk}] := \mathbb{E} [N_{jk}] + \sum_{t=2}^{T_n} \xi_{n,t}(j, k)\)
    9 \(\mathbb{E} [M_{kv}] := \mathbb{E} [M_{kv}] + \sum_{t:x_{n,t}=v} \gamma_{n,t}(k)\)
  10 // M step
  11 Compute new parameters \(\theta = (\mathbf{A}, \mathbf{B}, \boldsymbol{\pi})\) using Equations 29.30
```
