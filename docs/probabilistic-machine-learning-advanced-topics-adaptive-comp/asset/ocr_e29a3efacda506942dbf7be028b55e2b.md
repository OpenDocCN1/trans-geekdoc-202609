The \(\psi_i\) terms can be thought of as a local bias term that is independent of the contributions of the neighboring nodes. For binary nodes, we can define this as follows:

```
\(\psi_i(x_i) = \left\{ \begin{array}{ll} e^\alpha & \text{if } x_i = +1 \\ e^{-\alpha} & \text{if } x_i = -1 \end{array} \right.\)
```

If we write this as an energy-based model, we have

```
\(\mathcal{E}(\mathbf{x}|\boldsymbol{\theta}) = -\alpha \sum_i x_i - J \sum_{i \sim j} x_i x_j\)
```

# 4.3.2.2 Potts models

In Section 4.3.2.1, we discussed the Ising model, which is a simple 2d MRF for defining distributions over binary variables. It is easy to generalize the Ising model to multiple discrete states, \(x_i \in \{1, 2, \dots, K\}\). If we use the same potential function for every edge, we can write

```
\(\psi_{ij}(x_i = k, x_j = k') = e^{J_{ij}(k, k')}\)
```

where \(J_{ij}(k, k')\) is the energy if one node has state \(k\) and its neighbor has state \(k'\). A common special case is

```
\(\psi_{ij}(x_i = k, x_j = k') = \left\{ \begin{array}{ll} e^J & \text{if } k = k' \\ e^0 & \text{if } k \neq k' \end{array} \right.\)
```

This is called the **Potts model**. The Potts model reduces to the Ising model if we define \(J_{\text{potts}} = 2J_{\text{ising}}\). If \(J > 0\), then neighboring nodes are encouraged to have the same label; this is an example of an associative Markov model. Some samples from this model are shown in Figure 4.18. The phase transition for a 2d Potts model occurs at the following value (see [MS96]):

```
\(J_c = \log(1 + \sqrt{K})\)
```
