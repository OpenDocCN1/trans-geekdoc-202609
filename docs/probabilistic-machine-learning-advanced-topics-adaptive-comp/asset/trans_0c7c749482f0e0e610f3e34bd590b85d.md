## 9.6 结树算法（JTA）

结树算法（JTA）是变量消元的一种推广，它让我们能够使用动态规划高效地计算所有后验边缘，而无需重复冗余工作，从而避免了第 9.5.5 节中提到的问题。基本思路是将图转换成一种特殊的树，称为结树（也称连接树或团树），然后在此树上运行信念传播（消息传递）。我们可以通过“符号化”地运行变量消元（如第 9.5.2 节所述）并将生成的填充边添加到图中来创建连接树。得到的弦图随后可以转换为一棵树，如补充部分第 9.2.1 节所述。得到树后，我们可以使用第 9.3.2 节方法的变体在其上执行消息传递。详情请参见补充部分第 9.2.2 节。

## 9.7 将推断作为优化问题

在本节中，我们将讨论如何通过求解优化问题来执行后验推断，这在计算上通常更简单。另请参见补充部分第 9.3 节。

### 9.7.1 将推断作为反向传播

在本节中，我们将讨论如何使用自动微分在图形模型中计算后验边缘。为了符号简单，我们关注无向图形模型，其中联合分布可以表示为指数族（第 2.4 节），如下所示：

\( p(\mathbf{x}) = \frac{1}{Z} \prod_c \psi_c(\mathbf{x}_c) = \exp(\sum_c \boldsymbol{\eta}_c^\mathsf{T} \mathcal{T}(\mathbf{x}_c) - \log A(\boldsymbol{\eta})) = \exp(\boldsymbol{\eta}^\mathsf{T} \mathcal{T}(\mathbf{x}) - \log A(\boldsymbol{\eta})) \quad \text{(9.93)} \)

其中，\(\psi_c\) 是团 \(c\) 的势函数，\(\boldsymbol{\eta}_c\) 是团 \(c\) 的自然参数，\(\mathcal{T}(\mathbf{x}_c)\) 是相应的充分统计量，而 \(A = \log Z\) 是对数配分函数。

我们将考虑成对模型（带有节点势和边缘势）以及离散变量。自然参数是节点和边缘对数势，\(\boldsymbol{\eta} = (\{\eta_{s;j}\}, \{\eta_{st;j,k}\})\)，充分统计量是节点和边缘指示函数，\(\mathcal{T}(\mathbf{x}) = (\{\mathbb{I}(x_s=j)\}, \{\mathbb{I}(x_s=j, x_t=k)\})\)。（注：我们使用 \(s,t \in \mathcal{V}\) 索引节点，使用 \(j,k \in \mathcal{X}\) 索引状态。）

充分统计量的均值由下式给出：

\( \boldsymbol{\mu} = \mathbb{E}[\mathcal{T}(\mathbf{x})] = (\{p(x_s=j)\}_s, \{p(x_s=j, x_t=k)\}_{s \neq t}) = (\{\mu_{s;j}\}_s, \{\mu_{st;jk}\}_{s \neq t}) \quad \text{(9.94)} \)

关键结果（来自公式 2.236）是 \(\boldsymbol{\mu} = \nabla_{\boldsymbol{\eta}} A(\boldsymbol{\eta})\)。因此，只要我们有一个计算 \(A(\boldsymbol{\eta}) = \log Z(\boldsymbol{\eta})\) 的函数，就可以使用自动微分（第 6.2 节）来计算梯度，然后从梯度向量中提取相应的节点边缘。如果对某些变量有证据（已知值），我们只需在节点势中将相应条目“钳位”为 0 或 1。

利用自动微分可以执行概率推断的观察已被多个研究小组独立发现（例如，[Dar03; PD03; Eis16; ASM17]）。这也有利于开发可微的推断近似方法（参见，例如，[MB18]）。

#### 9.7.1.1 示例：小型模型中的推断

作为具体示例，考虑一个小型链式结构模型 \(x_1 - x_2 - x_3\)，其中每个节点有 \(K\) 个状态。我们可以将节点势表示为 \(K \times 1\) 张量（数字表），将边缘势表示为 \(K \times K\) 张量。配分函数由下式给出：

\( Z(\boldsymbol{\psi}) = \sum_{x_1, x_2, x_3} \psi_1(x_1)\psi_2(x_2)\psi_3(x_3)\psi_{12}(x_1, x_2)\psi_{23}(x_2, x_3) \quad \text{(9.95)} \)

令 \(\boldsymbol{\eta} = \log(\boldsymbol{\psi})\) 为对数势，\(A(\boldsymbol{\eta}) = \log Z(\boldsymbol{\eta})\) 为对数配分函数。我们可以使用 \(\boldsymbol{\mu}_s = \nabla_{\eta_s} A(\boldsymbol{\eta})\) 计算单节点边缘 \(\boldsymbol{\mu}_s = p(x_s=1:K)\)，并使用 \(\boldsymbol{\mu}_{s,t} = \nabla_{\eta_{s,t}} A(\boldsymbol{\eta})\) 计算成对边缘 \(\boldsymbol{\mu}_{s,t}(j,k) = p(x_s=j, x_t=k)\)。

我们可以高效地使用 numpy 的 einsum 函数来计算配分函数 \(Z\)，该函数使用爱因斯坦求和公约实现张量收缩。我们将张量的每个维度标记为 A、B 和 C，以便 einsum 知道如何匹配它们。然后我们使用自动微分库计算梯度。5 其结果是，推断可以在两行 Python 代码中完成，如清单 9.1 所示：

### 清单 9.1：从对数配分函数的导数计算边缘

```
import jax.numpy as jnp
from jax import grad
logz_fun = lambda logpots: np.log(jnp.einsum("A,B,C,AB,BC",
*jnp.exp(lp) for lp in logpots]))
probs = grad(logz_fun)(logpots)
```

要执行条件推断，例如 \(p(x_s = k|x_t = e)\)，我们将单热指示向量相乘以将 \(x_t\) 钳位为值 e，从而使未归一化联合分布仅对有效的状态组合分配非零概率。然后我们对所有未钳位变量的值求和，得到受限配分函数 \(Z_e\)。梯度将给出基于证据的条件边缘 [Dar03]。

## 9.7.2 扰动与 MAP

在本节中，我们将讨论如何通过将优化作为子例程来从图形模型中绘制后验样本。基本思路是制作 S 份模型副本，每份副本的参数都有略微扰动的版本，\(\boldsymbol{\theta}_s = \boldsymbol{\theta}_s + \boldsymbol{\epsilon}_s\)，然后计算 MAP 估计值，\(\boldsymbol{x}_s = \operatorname{argmax} p(\boldsymbol{y}; \theta_s)\)。对于合适选择的 \(\epsilon_s\) 噪声分布，这种技术——称为 **扰动-MAP**——可以证明能给出精确的后验样本 [PY10; PY11; PY14]。

### 9.7.2.1 高斯情况

我们首先考虑高斯 MRF 的情况。令 \(\boldsymbol{x} \in \mathbb{R}^N\) 为隐藏状态向量，其先验为

> \(p(\boldsymbol{x}) \propto \mathcal{N}(\mathbf{G}\boldsymbol{x}|\boldsymbol{\mu}_p, \boldsymbol{\Sigma}_p) \propto \exp(-\frac{1}{2}\boldsymbol{x}^\top \mathbf{K}_x \boldsymbol{x} + \boldsymbol{h}_x^\top \boldsymbol{x})\) (9.96)

其中，\(\mathbf{G} \in \mathbb{R}^{K \times N}\) 是表示先验依赖关系（例如，成对相关性）的矩阵，\(\mathbf{K}_x = \mathbf{G}^\top \boldsymbol{\Sigma}_p^{-1} \mathbf{G}\)，\(\boldsymbol{h}_x = \mathbf{G}^\top \boldsymbol{\Sigma}_p^{-1} \boldsymbol{\mu}_p\)。令 \(\boldsymbol{y} \in \mathbb{R}^M\) 为带有似然的测量值

> \(p(\boldsymbol{y}|\boldsymbol{x}) = \mathcal{N}(\boldsymbol{y}|\mathbf{H}\boldsymbol{x} + \boldsymbol{c}, \boldsymbol{\Sigma}_n) \propto \exp(-\frac{1}{2}\boldsymbol{x}^\top \mathbf{K}_{y|x} \boldsymbol{x} + \boldsymbol{h}_{y|x}^\top \boldsymbol{x} - \frac{1}{2}\boldsymbol{y}^\top \boldsymbol{\Sigma}_n^{-1} \boldsymbol{y})\) (9.97)

其中，\(\mathbf{H} \in \mathbb{R}^{M \times N}\) 表示隐藏变量和可见变量之间的依赖关系，\(\mathbf{K}_{y|x} = \mathbf{H}^\top \boldsymbol{\Sigma}_n^{-1} \mathbf{H}\)，\(\boldsymbol{h}_{y|x} = \mathbf{H}^\top \boldsymbol{\Sigma}_n^{-1} (\boldsymbol{y} - \boldsymbol{c})\)。后验由以下公式给出（参见第 8.2.4 节中信息滤波器的一步）

> \(p(\boldsymbol{x}|\boldsymbol{y}) = \mathcal{N}(\boldsymbol{x}|\boldsymbol{\mu}, \boldsymbol{\Sigma})\) (9.98)
> \(\boldsymbol{\Sigma}^{-1} = \mathbf{K} = \mathbf{G}^\top \boldsymbol{\Sigma}_p^{-1} \mathbf{G} + \mathbf{H}^\top \boldsymbol{\Sigma}_n^{-1} \mathbf{H}\) (9.99)
> \(\boldsymbol{\mu} = \mathbf{K}(\mathbf{G}^\top \boldsymbol{\Sigma}_p^{-1} \boldsymbol{\mu}_p + \mathbf{H}^\top \boldsymbol{\Sigma}_n^{-1} (\boldsymbol{y} - \boldsymbol{c}))\) (9.100)
