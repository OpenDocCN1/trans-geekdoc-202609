## 15.2.5 峰值-平板先验

在进行预测时，能够选择输入特征的一个子集通常很有用，无论是为了减少过拟合，还是为了提高模型的可解释性。如果我们确保权重向量 \(\boldsymbol{w}\) 是**稀疏**的（即，具有许多零元素），则可以实现这一点，因为如果 \(w_d = 0\)，则 \(x_d\) 在内积 \(\boldsymbol{w}^\top \boldsymbol{x}\) 中不起任何作用。

使用贝叶斯推断实现稀疏性的标准方法是使用**峰值-平板（SS）先验** [MB88]，它是一个 2 分量混合模型的形式，一个分量是 0 处的“尖峰”，另一个分量是 \(-a\) 到 \(a\) 之间的均匀“平板”：

\(p(\boldsymbol{w}) = \prod_{d=1}^D (1 - \pi)\delta(w_d) + \pi \text{Unif}(w_d \mid -a, a) \quad \text{(15.86)}\)

其中 \(\pi\) 是每个系数非零的先验概率。因此，系数的相应对数先验为

\(\log p(\boldsymbol{w}) = ||\boldsymbol{w}||_0 \log(1 - \pi) + (D - ||\boldsymbol{w}||_0) \log \pi = -\lambda ||\boldsymbol{w}||_0 + \text{const} \quad \text{(15.87)}\)

其中 \(\lambda = \log \frac{\pi}{1 - \pi}\) 控制模型的稀疏性，而 \(||\boldsymbol{w}||_0 = \sum_{d=1}^D \mathbb{I}(w_d \neq 0)\) 是权重的 \(\ell_0\) **范数**。因此，使用峰值-平板先验的 MAP 估计相当于 \(\ell_0\) **正则化**；它对非零系数的数量进行惩罚。有趣的是，后验样本也将是稀疏的。相比之下，考虑使用拉普拉斯先验。**lasso** 估计器使用 MAP 估计，这会导致稀疏估计。然而，后验样本不是稀疏的。有趣的是，[EY09] 从理论上表明（并且 [SPZ09] 从实验上证实）使用带有峰值-平板先验的后验均值也会比使用带有拉普拉斯先验的后验众数获得更好的预测精度。

在实践中，我们通常用广义高斯分布来近似均匀平板，

\(p(\boldsymbol{w}) = \prod_d (1 - \pi)\delta(w_d) + \pi \mathcal{N}(w_d \mid 0, \sigma_w^2) \quad \text{(15.88)}\)

当 \(\sigma_w^2 \rightarrow \infty\) 时，第二项趋近于 \([-\infty, +\infty]\) 上的均匀分布。我们可以通过为每个系数关联一个二元随机变量 \(s_d \sim \text{Ber}(\pi)\) 来实现混合模型，以指示系数是“开”还是“关”。

不幸的是，使用这种离散混合先验的 MAP 估计（更不用说完全贝叶斯推断）在计算上是困难的。已经提出了各种近似推断方法，包括贪婪搜索（见，例如，[SPZ09]）或 MCMC（见，例如，[HS09]）。

## 15.2.6 拉普拉斯先验（贝叶斯套索）

一种计算成本较低的实现稀疏性的方法是使用拉普拉斯先验进行 MAP 估计，通过最小化惩罚负对数似然：

```
PNLL(w) = -log p(D|w) - log p(w|\lambda) = ||Xw - y||_2^2 + \lambda ||w||_1 (15.89)
```

其中 \(||w||_1 \triangleq \sum_{d=1}^D |w_d|\) 是 \(\boldsymbol{w}\) 的 \(\ell_1\) 范数。这种方法称为 lasso，代表“最小绝对收缩和选择算子” [Tib96]。有关详细信息，请参见本书前身 [Mur22] 的第 11.4 节。

在本节中，我们讨论了使用此先验的后验推断；这被称为贝叶斯套索 [PC08]。特别是，我们假设以下先验：

```
p(w|\sigma^2) = \prod_j \frac{\lambda}{2\sqrt{\sigma^2}} e^{-\lambda|w_j|/\sqrt{\sigma^2}} (15.90)
```

（请注意，将先验条件化于 \(\sigma^2\) 很重要，以确保完整的后验是单峰的。）

为了简化推断，我们将把拉普拉斯先验表示为高斯尺度混合，我们在 28.2.3.2 节中讨论过这一点。特别是，可以证明拉普拉斯分布是高斯分布的无限加权和，其中精度来自伽马分布：

```
Laplace(w|0, \lambda) = \int \mathcal{N}(w|0, \tau^2)Ga(\tau^2|1, \frac{\lambda^2}{2})d\tau^2
```

因此，我们可以将贝叶斯套索模型表示为分层隐变量模型，如图 15.3a 所示。相应的联合分布形式如下：

```
p(y, w, \tau, \sigma^2 | X) = \mathcal{N}(y | Xw, \sigma^2 I_N) \left[ \prod_j \mathcal{N}(w_j | 0, \sigma^2 \tau_j^2) Ga(\tau_j^2 | 1, \lambda^2 / 2) \right] p(\sigma^2)
```

我们还可以创建一个 GSM 以匹配**组 lasso** 先验，它同时将多个系数设置为零：

```
w_g | \sigma^2, \tau_g^2 \sim \mathcal{N}(0, \sigma^2 \tau_g^2 I_{d_g})
```

```
\tau_g^2 ~ Ga(\frac{d_g + 1}{2}, \frac{\lambda^2}{2})
```

其中 \(d_g\) 是组 \(g\) 的大小。因此，我们可以看到每个组有一个方差项，每个方差项都来自伽马先验，其形状参数取决于组大小，而其速率参数由 \(\lambda\) 控制。

图 15.3b 给出了一个示例，其中我们有 2 个组，一个大小为 2，另一个大小为 3。这张图更清楚地说明了为什么应该存在分组效应。例如，假设 \(w_{1,1}\) 很小；那么 \(\tau_1^2\) 将被估计为很小，这会由于收缩（参见第 3.6 节）而迫使 \(w_{1,2}\) 也很小。反之，假设 \(w_{1,1}\) 很大；那么 \(\tau_1^2\) 将被估计为很大，这将允许 \(w_{1,2}\) 也变得很大。

鉴于这些分层模型，我们可以轻松推导出吉布斯采样算法（第 12.3 节）来从后验中采样（见，例如，[PC08]）。不幸的是，这些后验样本不是稀疏的，即使 MAP 估计是稀疏的。这是因为先验对每个系数为零的事件赋予了无穷小概率。

## 15.2.7 马蹄先验

拉普拉斯先验不适合稀疏贝叶斯模型，因为后验样本不是稀疏的。峰值-平板先验不存在这个问题，但使用起来通常太慢了（虽然见 [BRG20]）。幸运的是，可以设计连续先验（没有离散隐变量），既稀疏又计算效率高。这种类型的一个流行先验是**马蹄先验** [CPS10]，因其密度函数的形状而得名。

在马蹄先验中，我们不对每个权重使用拉普拉斯先验，而是使用以下高斯尺度混合：

```
w_j \sim \mathcal{N}(0, \lambda_j^2 \tau^2)
\lambda_j \sim \mathcal{C}_+(0, 1)
\tau^2 \sim \mathcal{C}_+(0, 1)
```

其中 \(\mathcal{C}_+(0, 1)\) 是半柯西分布（第 2.2.2.4 节），\(\lambda_j\) 是局部收缩因子，\(\tau^2\) 是全局收缩因子。柯西分布具有非常厚的尾部，因此 \(\lambda_j\) 很可能要么是 0，要么远离 0，这以连续的方式模拟了峰值-平板先验。有关更多详细信息，请参见，例如，[Bha+19]。

## 15.2.8 自动相关性确定

使用促进稀疏性的先验进行后验推断的替代方法是使用高斯先验 \(w_j \sim \mathcal{N}(0, 1/\alpha_j)\) 进行后验推断，但我们使用经验贝叶斯来优化精度 \(\alpha_j\)。也就是说，我们首先计算 \(\hat{\boldsymbol{\alpha}} = \text{argmax}_{\boldsymbol{\alpha}} p(\mathbf{y}|\mathbf{X}, \boldsymbol{\alpha})\)，然后计算 \(\hat{\mathbf{w}} = \text{argmax}_{\mathbf{w}} \mathcal{N}(\mathbf{w}|\mathbf{0}, \hat{\boldsymbol{\alpha}}^{-1})\)。也许出人意料的是，我们将看到这会导致稀疏估计，我们将在第 15.2.8.2 节中解释原因。这种技术被称为稀疏贝叶斯学习 [Tip01] 或自动相关性确定（ARD）[Mac95; Neal96]。它也被称为 NUV 估计，代表“未知方差的正态先验” [Loe+16]。它最初为神经网络开发（其中稀疏性应用于第一层权重），但在此我们将其应用于线性模型。

### 15.2.8.1 线性模型的 ARD

在本节中，我们通过将其应用于线性回归，更详细地解释了 ARD。似然是 \(p(y|\mathbf{x}, \mathbf{w}, \beta) = \mathcal{N}(y|\mathbf{w}^\mathsf{T}\mathbf{x}, 1/\beta)\)，其中 \(\beta = 1/\sigma^2\)。先验是 \(p(\mathbf{w}) = \mathcal{N}(\mathbf{w}|\mathbf{0}, \mathbf{A}^{-1})\)，其中 \(\mathbf{A} = \text{diag}(\boldsymbol{\alpha})\)。边缘似然可以解析计算（使用公式 (2.129)），如下所示：

```
\(p(\mathbf{y}|\mathbf{X}, \boldsymbol{\alpha}, \beta) = \int \mathcal{N}(\mathbf{y}|\mathbf{X}\mathbf{w}, (1/\beta)\mathbf{I}_N)\mathcal{N}(\mathbf{w}|\mathbf{0}, \mathbf{A}^{-1})d\mathbf{w} \tag{15.98}\)
\(= \mathcal{N}(\mathbf{y}|\mathbf{0}, \beta^{-1}\mathbf{I}_N + \mathbf{X}\mathbf{A}^{-1}\mathbf{X}^\mathsf{T}) \tag{15.99}\)
\(= \mathcal{N}(\mathbf{y}|\mathbf{0}, \mathbf{C}_{\boldsymbol{\alpha}}) \tag{15.100}\)
```

其中 \(\mathbf{C}_{\boldsymbol{\alpha}} \triangleq \beta^{-1}\mathbf{I}_N + \mathbf{X}\mathbf{A}^{-1}\mathbf{X}^\mathsf{T}\)。这与峰值-平板先验（第 15.2.5 节）下的边缘似然非常相似，后者由

```
\(p(\mathbf{y}|\mathbf{X}, s, \sigma_w^2, \sigma_y^2) = \int \mathcal{N}(\mathbf{y}|\mathbf{X}_s\mathbf{w}_s, \sigma_y^2\mathbf{I})\mathcal{N}(\mathbf{w}_s|\mathbf{0}_s, \sigma_w^2\mathbf{I})d\mathbf{w}_s = \mathcal{N}(\mathbf{y}|\mathbf{0}, \mathbf{C}_s) \tag{15.101}\)
```

给出，其中 \(\mathbf{C}_s = \sigma_y^2\mathbf{I}_N + \sigma_w^2\mathbf{X}_s\mathbf{X}_s^\mathsf{T}\)。（这里 \(\mathbf{X}_s\) 指的是设计矩阵，我们仅选择 \(\mathbf{X}\) 中 \(s_d = 1\) 的列。）区别在于，我们将二元变量 \(s_j \in \{0, 1\}\) 替换为连续变量 \(\alpha_j \in \mathbb{R}^+\)，这使得优化问题更容易求解。

目标是对数边缘似然，由

```
\(\ell(\boldsymbol{\alpha}, \beta) = -2 \log p(\mathbf{y}|\mathbf{X}, \boldsymbol{\alpha}, \beta) = \log |\mathbf{C}_{\boldsymbol{\alpha}}| + \mathbf{y}^\mathsf{T} \mathbf{C}_{\boldsymbol{\alpha}}^{-1} \mathbf{y} \tag{15.102}\)
```

有各种算法用于优化 \(\ell(\boldsymbol{\alpha}, \beta)\)，我们将在 15.2.8.3 节中讨论其中一些。ARD 可以作为 \(\ell_1\) 正则化的替代方法。虽然 ARD 目标不是凸的，但它往往能给出更稀疏的结果 [WW12]。此外，可以证明 [WRN10] ARD 目标的局部最优解比 \(\ell_0\)-正则化目标少得多，因此更容易优化。
