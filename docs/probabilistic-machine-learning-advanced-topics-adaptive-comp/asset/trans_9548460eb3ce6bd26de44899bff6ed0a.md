

潜在结果的主要优势在于，反事实陈述通常能更直接地映射到我们对世界的机制性理解中。这可以使阐述因果期望和因果假设变得更加容易。另一方面，潜在结果表示法并不能自动区分干预性查询与反事实查询。此外，因果图通常提供了一种直观且简便的方式来阐述涉及许多变量的结构因果模型的假设——潜在结果很快就会变得难以处理。简而言之：这两种形式化各有不同的优势，而这些优势仅仅关乎将我们对世界的因果理解转化为清晰数学假设有多容易。

## 36.3 随机对照试验

我们现在转向从数据中估计因果效应的问题。我们首先从**随机对照试验**开始，这是一种旨在使因果关切尽可能简单的实验。因果估计最简单的情况是 _A_ 和 _Y_ 没有共同原因。世界很少如此配合以使这种情况发生。然而，有时我们可以设计一个实验来强制执行无共同原因结构。在随机对照试验中，我们将每个参与者随机分配到治疗组或对照组。由于随机分配不依赖于研究中单位的任何属性，因此没有治疗分配的原因，进而也没有 _Y_ 和 _A_ 的共同原因。

通常使用 RCT 来研究平均处理效应，

```
\(\text{ATE} = E[Y|\text{do}(A = 1)] - \mathbb{E}[Y|\text{do}(A = 0)].\)
```

这是对人群中随机选定的成员，分配治疗与不分配治疗之间的预期差异。在 RCT 中，很容易看出这种因果量被识别为观测分布的一个参数 \(\tau^{RCT}\)：

```
\(\tau^{RCT} = \mathbb{E}[Y|A = 1] - \mathbb{E}[Y|A = 0].\)
```

那么，一个自然的估计量是：

```
\(\hat{\tau}^{RCT} \triangleq \frac{1}{n_A} \sum_{i:A_i=1} Y_i - \frac{1}{n - n_A} \sum_{i:A_i=0} Y_i,\)
```

其中 _n<sub>A</sub>_ 是接受治疗的单位数量。也就是说，我们将平均处理效应估计为治疗组的平均结果与未处理（对照）组的平均结果之差。

随机对照试验是估计因果效应的金标准。这是因为根据设计，我们知道没有混杂因素可以产生对数据的替代性因果解释。特别是，三角 DAG 的假设——没有未观测混杂因素——是通过设计强制执行的。然而，也有局限性。最明显的是，随机对照试验有时难以实施。这可能是由于费用、监管限制或更根本的困难（例如，在发展经济学中，感兴趣的反应有时是在治疗数十年后收集的）。此外，可能很难确保 RCT 的参与者代表治疗将部署的人群。例如，药物试验中的参与者可能比最终服用该药物的患者群体更年轻、更贫穷。

- 关于在 RCT 中高效估计因果效应的文献可以追溯到 Fisher [Fis25]，这些文献采用了更复杂的估计量。另请参见 Lin [Lin13a] 和 Bloniarz 等人 [Blo+16] 以了解更现代的处理方法。

## 36.4 混杂因素调整

我们现在转向使用观测数据（即非实验数据）估计因果效应的问题。因果推断最常见的应用是估计干预的平均处理效应（ATE）。ATE 通常也被称为**平均因果效应**，或 ACE。在这里，我们关注一个重要的特例，即治疗 A 是二元的，并且我们观察到结果 Y 以及一组影响 A 和 Y 的共同原因 X。

### 36.4.1 因果待估量、统计待估量与识别

考虑这样一个问题：我们观察到治疗 A、结果 Y 和协变量 X，它们从某个未知分布 P 中独立同分布地抽取。我们希望了解平均处理效应：即对人群中随机选定的成员，分配治疗与不分配治疗之间的预期差异。根据引言中的讨论，学习这一量有三个步骤：在数学上形式化因果待估量，给出因果待估量作为统计待估量被识别的条件，最后，从数据中估计这一统计待估量。我们现在转向前两个步骤。

平均处理效应定义为：如果我们进行干预并将 A 设为 0 时的平均结果，与如果我们进行干预并将 A 设为 1 时的平均结果之差。使用 do 符号，我们可以正式地写成

```
ATE = \mathbb{E}[Y|\text{do}(A = 1)] - \mathbb{E}[Y|\text{do}(A = 0)].
```

下一步是阐述 ATE 作为统计待估量（分布 \(P\) 的一个参数）被识别的充分条件。关键问题是可能存在**混杂因素**。混杂因素是影响治疗和结果的“共同原因”变量。当观测数据中存在混杂变量时，被观察到接受某一水平治疗 \(A\) 的子人群会以与其观察到的 \(Y\) 相关的方式与剩余人群不同。例如，童年骑马（治疗）与成年后健康（结果）之间存在强烈的正相关性 [RB16]。然而，这两个量都受财富 \(X\) 的影响。童年骑过马的人群（\(A=1\)）比没有骑过马的人群更富有。因此，即使骑马对成人健康没有实际因果益处，骑马人群的健康结果也会更好。

我们将以因果 DAG 的形式表达因果识别所需的假设。具体来说，我们考虑图 36.3 中的简单三角 DAG，其中治疗和结果都受到*观测到的*混杂因素 \(X\) 的影响。事实证明，该 DAG 编码的假设足以实现识别。要理解为什么如此，请回顾，目标因果效应是根据如果移除 \(X\) 到 \(A\) 的边时所见到的分布来定义的（这就是 do 的含义）。关键洞察在于，由于干预仅修改 \(X\) 与 \(A\) 之间的关系，因此给定 \(X\) 和 \(A\) 生成结果 \(Y\) 的结构方程（在图 36.3 中表现为 \(A \rightarrow Y \leftarrow X\)），即使在移除 \(X \rightarrow Y\) 边后仍然相同。例如，我们可能会认为，吸烟状态 \(A\) 和混杂因素 \(X\) 产生肺癌 \(Y\) 的生理过程保持不变，无论吸烟或不吸烟的决定是如何做出的。其次，由于干预不改变人群的构成，我们也期望观测过程与干预过程之间背景特征 \(X\) 的分布相同。

基于这些关于观测数据与干预数据之间不变性的洞察，我们可以如下推导 ATE 的统计待估量。

### 定理 2（无未观测混杂因素的调整）

我们观察到 \(A, Y, X \sim P\)。假设

- *(混杂因素已观测)* 数据服从图 36.3 中的因果结构。特别是，\(X\) 包含 \(A\) 和 \(Y\) 的所有共同原因，且 \(X\) 中没有变量是由 \(A\) 或 \(Y\) 引起的。
- *(重叠)* 对所有 \(x\) 的取值，\(0 < \mathsf{P}(A=1|X=x) < 1\)。也就是说，不存在治疗总是或从不被分配的个体。

那么，平均处理效应被识别为 \(\text{ATE}=\tau\)，其中

\(\tau = \mathbb{E}[\mathbb{E}[Y|A=1, X]] - \mathbb{E}[\mathbb{E}[Y|A=0, X]].\)

证明。首先，我们使用期望的塔属性，对 \(X\) 进行条件化来展开 ATE。然后，我们应用上面讨论的不变性：

\(\begin{aligned} \text{ATE} &= \mathbb{E}[Y|\text{do}(A=1)] - \mathbb{E}[Y|\text{do}(A=0)] \\ &= \mathbb{E}[\mathbb{E}[Y|\text{do}(A=1), X]] - \mathbb{E}[\mathbb{E}[Y|\text{do}(A=0), X]] \\ &= \mathbb{E}[\mathbb{E}[Y|A=1, X]] - \mathbb{E}[\mathbb{E}[Y|A=0, X]] \end{aligned}\)
