This is called the **probability flow ODE** [Son+21b, Sec D.3]. We can compute the state at any moment in time using any ODE solver:

```
x(t) = x(0) + \int_0^t h(x, \tau) d\tau
```

See Figure 25.7b for a visualization of a sample trajectory. If we start the solver from different random states x(0), then the induced distribution over paths will have the same marginals as the SDE model. See the heatmap in Figure 25.6 for an illustration.

# 25.4.3 Reverse diffusion SDE

To generate samples from this model, we need to be able to reverse the SDE. In a remarkable result, [And82] showed that any forwards SDE of the form in Equation (25.43) can be reversed to get the following **reverse-time SDE**:

```
dx = [f(x, t) - g(t)^2 \nabla_x \log q_t(x)] dt + g(t) d\overline{w}
```

where $\overline{w}$ is the standard Wiener process when time flows backwards, dt is an infinitesimal negative time step, and $\nabla_x \log q_t(x)$ is the score function.

In the case of the DDPM, the reverse SDE has the following form:

```
dx_t = \left[ -\frac{1}{2}\beta(t)x_t - \beta(t)\nabla_{x_t} \log q_t(x_t) \right] dt + \sqrt{\beta(t)} d\overline{w}_t
```

To estimate the score function, we can use denoising score matching as we discussed in Section 25.3, to get

```
\nabla_{x_t} \log q_t(x_t) \approx s_\theta(x_t, t)
```

(In practice, it is advisable to use variance reduction techniques, such as importance sampling, as discussed in [Son+21a].) The SDE becomes

```
dx_t = -\frac{1}{2}\beta(t) [x_t + 2s_\theta(x_t, t)] dt + \sqrt{\beta(t)} d\overline{w}_t
```
