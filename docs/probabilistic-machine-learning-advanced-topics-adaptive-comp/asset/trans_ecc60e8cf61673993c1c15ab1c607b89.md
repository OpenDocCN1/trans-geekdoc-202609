## 3.5 非信息性先验

当我们几乎没有或没有特定领域知识时，最好使用非信息性、无信息性或客观先验，以“让数据自己说话”。不幸的是，定义此类先验没有唯一方法，它们都编码了某种知识。因此，使用扩散先验、最小信息先验或默认先验一词更好。

在下面的章节中，我们简要提及一些创建默认先验的常见方法。有关更多细节，请参见例如 [KW96] 和 Stan 网站。$^7$

### 3.5.1 最大熵先验

定义无信息先验的一种自然方法是使用具有最大熵的先验，因为它对状态空间中的任何特定值所做的承诺最少（关于熵的讨论见第 5.2 节）。这是拉普拉斯“充分理由不足原则”的形式化，他认为如果没有理由偏好某个先验而非另一个，我们应该选择一个“平坦”的先验。

例如，在成功率 $\theta \in [0, 1]$ 的伯努利分布中，最大熵先验是均匀分布，$p(\theta) = \text{Beta}(\theta | 1, 1)$，这符合直觉。

然而，在某些情况下，我们对随机变量 $\theta$ 有一些了解，并且希望我们的先验与这些约束相匹配，但除此之外具有最大熵。更精确地说，假设我们想要找到一个分布 $p(\theta)$ 使其熵最大，并受到某些特征或函数 $f_k(\theta)$ 的期望值与已知量 $F_k$ 匹配的约束。这被称为最大熵先验。在第 2.4.7 节中，我们表明这样的分布必须属于指数族（第 2.4 节）。

例如，假设 $\theta \in \{1, 2, \dots, 10\}$，并让 $p_c = p(\theta = c)$ 为相应的先验。假设我们知道先验均值为 1.5。我们可以使用以下约束对其进行编码

```
$$
\mathbb{E}[f_1(\theta)] = \mathbb{E}[\theta] = \sum_c c p_c = 1.5 \quad (3.218)$$
```

$\min_{\mathbf{p}} \mathbb{H}(\mathbf{p}) \quad \text{s.t.} \quad \sum_c c \, p_c = 1.5, \quad \sum_c p_c = 1.0 \quad (3.219)$

这给出了图 3.12 中的衰减指数曲线。现在假设我们知道 $\theta$ 以 0.8 的概率为 3 或 4。我们可以使用

$\mathbb{E}[f_1(\theta)] = \mathbb{E}[\mathbb{I}(\theta \in \{3, 4\})] = \text{Pr}(\theta \in \{3, 4\}) = 0.8 \quad (3.220)$

这给出了图 3.12 中的倒 U 型曲线。我们注意到，这个分布在尽可能多的地方是平坦的。

### 3.5.2 Jeffreys 先验

设 $\theta$ 为具有先验 $p_\theta(\theta)$ 的随机变量，并设 $\phi = f(\theta)$ 为 $\theta$ 的某个可逆变换。我们希望选择一个对该函数 $f$ **不变**的先验，以便后验不依赖于我们如何参数化模型。

例如，考虑参数为 $\theta$ 的伯努利分布。假设 Alice 使用带数据 $\mathcal{D}$ 的二项似然，并计算 $p(\theta|\mathcal{D})$。现在假设 Bob 使用相同的似然和数据，但以赔率参数 $\phi = \frac{\theta}{1-\theta}$ 对模型进行参数化。他使用变量代换公式将 Alice 的先验转换为 $p(\phi)$，然后计算 $p(\phi|\mathcal{D})$。如果他随后转换回 $\theta$ 参数化，他应该得到与 Alice 相同的结果。

只要我们使用 **Jeffreys 先验**，以 Harold Jeffreys 命名，就可以实现这一目标。$^8$ 在一维中，Jeffreys 先验由 $p(\theta) \propto \sqrt{F(\theta)}$ 给出，其中 $F$ 是 Fisher 信息（第 3.3.4 节）。

8. Harold Jeffreys，1891–1989，是一位英国数学家、统计学家、地球物理学家和天文学家。他不应与理查德·杰弗里（Richard Jeffrey）混淆，后者是一位倡导概率主观诠释的哲学家 [Jef04]。

在多维中，Jeffreys 先验的形式为 \(p(\boldsymbol{\theta}) \propto \sqrt{\det \mathbf{F}(\boldsymbol{\theta})}\)，其中 \(\mathbf{F}\) 是 Fisher 信息矩阵（第 3.3.4 节）。

要了解为什么 Jeffreys 先验对参数化不变，请考虑一维情况。假设 \(p_\theta(\theta) \propto \sqrt{F(\theta)}\)。使用变量代换，我们可以按如下方式推导出 $\phi$ 的相应先验：

```
\(\begin{aligned} p_\phi(\phi) &= p_\theta(\theta) \left| \frac{d\theta}{d\phi} \right| \tag{3.221} \\ &\propto \sqrt{F(\theta)} \left( \frac{d\theta}{d\phi} \right)^2 = \sqrt{\mathbb{E} \left[ \left( \frac{d \log p(x|\theta)}{d\theta} \right)^2 \right] \left( \frac{d\theta}{d\phi} \right)^2} \tag{3.222} \\ &= \sqrt{\mathbb{E} \left[ \left( \frac{d \log p(x|\theta) \frac{d\theta}{d\phi}}{d\theta} \right)^2 \right]} = \sqrt{\mathbb{E} \left[ \left( \frac{d \log p(x|\phi)}{d\phi} \right)^2 \right]} \tag{3.223} \\ &= \sqrt{F(\phi)} \tag{3.224} \end{aligned}\)
```

因此，无论我们使用 $\theta$ 参数化还是 $\phi$ 参数化，先验分布都是相同的。

我们下面给出一些 Jeffreys 先验的示例。

#### 3.5.2.1 二项分布的 Jeffreys 先验

让我们使用速率参数化 $\theta$ 推导二项分布的 Jeffreys 先验。根据公式 (3.57)，我们有

```
\(p(\theta) \propto \theta^{-\frac{1}{2}} (1-\theta)^{-\frac{1}{2}} = \frac{1}{\sqrt{\theta(1-\theta)}} \propto \text{Beta}(\theta | \frac{1}{2}, \frac{1}{2}) \tag{3.225}\)
```

现在考虑赔率参数化，$\phi = \theta / (1-\theta)$，所以 $\theta = \frac{\phi}{\phi+1}$。似然变为

```
\(p(x|\phi) \propto \left( \frac{\phi}{\phi+1} \right)^x \left( 1 - \frac{\phi}{\phi+1} \right)^{n-x} = \phi^x (\phi+1)^{-x} (\phi+1)^{-n+x} = \phi^x (\phi+1)^{-n} \tag{3.226}\)
```

因此对数似然为

```
\(\ell = x \log \phi - n \log(\phi+1) \tag{3.227}\)
```

一阶和二阶导数为

```
\(\frac{d\ell}{d\phi} = \frac{x}{\phi} - \frac{n}{\phi+1} \tag{3.228}\)
```

```
\(\frac{d^2\ell}{d\phi^2} = -\frac{x}{\phi^2} + \frac{n}{(\phi+1)^2} \tag{3.229}\)
```

由于 \(\mathbb{E}[x] = n\theta = n\frac{\phi}{\phi+1}\)，Fisher 信息矩阵由以下给出

```
\(F(\phi) = -\mathbb{E} \left[ \frac{d^2\ell}{d\phi^2} \right] \tag{3.230}\)
```

```
\(= \frac{n(\phi+1) - n\phi}{\phi(\phi+1)^2} = \frac{n}{\phi(\phi+1)^2} \tag{3.231}\)
```

#### 3.5.2.2 多项分布的 Jeffreys 先验

对于具有 $K$ 个状态的分类随机变量，可以证明 Jeffreys 先验由以下给出

```
\(p(\boldsymbol{\theta}) \propto \text{Dir}(\boldsymbol{\theta} | \frac{1}{2}, \cdots, \frac{1}{2})\)
```

请注意，这与更明显的选择 \(\text{Dir}(\frac{1}{K}, \dots, \frac{1}{K})\) 或 \(\text{Dir}(1, \dots, 1)\) 不同。

#### 3.5.2.3 一元高斯分布均值和方差的 Jeffreys 先验

考虑一个一维高斯 $x \sim \mathcal{N}(\mu, \sigma^2)$，两个参数均未知，因此 $\boldsymbol{\theta} = (\mu, \sigma)$。根据公式 (3.62)，Fisher 信息矩阵为

```
\(\mathbf{F}(\boldsymbol{\theta}) = \begin{pmatrix} 1/\sigma^2 & 0 \\ 0 & 2/\sigma^2 \end{pmatrix}\)
```

因此 \(\sqrt{\det(\mathbf{F}(\boldsymbol{\theta}))} = \sqrt{\frac{2}{\sigma^4}}\)。然而，高斯的标准 Jeffreys 无信息先验定义为独立无信息先验的乘积（参见 [KW96]），即，

```
\(p(\mu, \sigma^2) \propto p(\mu)p(\sigma^2) \propto 1/\sigma^2\)
```

结果表明，我们可以使用共轭 NIX 先验来模拟此先验：

```
\(p(\mu, \sigma^2) = NI\chi^2(\mu, \sigma^2 | \mu_0 = 0, \bar{\kappa} = 0, \bar{\nu} = -1, \bar{\sigma}^2 = 0)\)
```

这使我们能够轻松重用第 3.4.3.3 节中高斯分布共轭分析的结果，如我们在第 3.4.3.4 节中所示。
