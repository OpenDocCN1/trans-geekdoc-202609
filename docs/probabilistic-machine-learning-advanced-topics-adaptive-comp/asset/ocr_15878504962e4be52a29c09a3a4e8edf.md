# 8.2.2.2 Update step

The update step (also called the **measurement update step**) can be computed using Bayes’ rule, as follows:

```
p(\mathbf{z}_t|\mathbf{y}_{1:t}, \mathbf{u}_{1:t}) = \mathcal{N}(\mathbf{z}_t|\boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t}) \tag{8.25}

\hat{\mathbf{y}}_t = \mathbf{H}_t \boldsymbol{\mu}_{t|t-1} + \mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t \tag{8.26}

\mathbf{S}_t = \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t \tag{8.27}

\mathbf{K}_t = \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} \mathbf{S}_t^{-1} \tag{8.28}

\boldsymbol{\mu}_{t|t} = \boldsymbol{\mu}_{t|t-1} + \mathbf{K}_t (\mathbf{y}_t - \hat{\mathbf{y}}_t) \tag{8.29}

\boldsymbol{\Sigma}_{t|t} = \boldsymbol{\Sigma}_{t|t-1} - \mathbf{K}_t \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \tag{8.30}

= \boldsymbol{\Sigma}_{t|t-1} - \mathbf{K}_t \mathbf{S}_t \mathbf{K}_t^\mathsf{T} \tag{8.31}
```

where **K**<sub>_t_</sub> is the **Kalman gain matrix**. Note that \(\hat{\mathbf{y}}_t\) is the expected observation, so \(\mathbf{e}_t = \mathbf{y}_t - \hat{\mathbf{y}}_t\) is the **residual error**, also called the **innovation term**. The covariance of the observation is denoted by **S**<sub>_t_</sub>, and the cross covariance bwtween the observation and state is denoted by \(\mathbf{C}_t = \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T}\). In practice, to compute the Kalman gain, we do not use **K**<sub>_t_</sub> = **C**<sub>_t_</sub>**S**<sub>_t_</sub><sup>-1</sup>, but instead we solve the linear system **K**<sub>_t_</sub>**S**<sub>_t_</sub> = **C**<sub>_t_</sub>.<sup>6</sup>

To understand the update step intuitively, note that the update for the latent mean, \(\boldsymbol{\mu}_{t|t} = \boldsymbol{\mu}_{t|t-1} + \mathbf{K}_t \mathbf{e}_t\), is the predicted new latent mean plus a correction factor, which is **K**<sub>_t_</sub> times the error signal **e**<sub>_t_</sub>. If **H**<sub>_t_</sub> = **I**, then **K**<sub>_t_</sub> = \(\boldsymbol{\Sigma}_{t|t-1} \mathbf{S}_t^{-1}\); in the scalar case, this becomes \(k_t = \Sigma_{t|t-1} / S_t\), which is the ratio between the variance of the prior (from the dynamics model) and the variance of the measurement, which we can interpret as an inverse signal to noise ratio. If we have a strong prior and/or very noisy sensors, |**K**<sub>_t_</sub>| will be small, and we will place little weight on the correction term. Conversely, if we have a weak prior and/or high precision sensors, then |**K**<sub>_t_</sub>| will be large, and we will place a lot of weight on the correction term. Similarly, the new covariance is the old covariance minus a positive definite matrix, which depends on how informative the measurement is.

Note that, by using the matrix inversion lemma, the Kalman gain matrix can also be written as

```
\(\mathbf{K}_t = \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} (\mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t)^{-1} = (\boldsymbol{\Sigma}_{t|t-1}^{-1} + \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} \mathbf{H}_t)^{-1} \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} \tag{8.32}\)
```

This is useful if \(\mathbf{R}_t^{-1}\) is precomputed (e.g., if it is constant over time) and \(N_y \gg N_z\). In addition, in Equation (8.97), we give the information form of the filter, which shows that the posterior precision has the form \(\boldsymbol{\Sigma}_t^{-1} = \boldsymbol{\Sigma}_{t|t-1}^{-1} + \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} \mathbf{H}_t\), so we can also write the gain matrix as \(\mathbf{K}_t = \boldsymbol{\Sigma}_t \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1}\).
