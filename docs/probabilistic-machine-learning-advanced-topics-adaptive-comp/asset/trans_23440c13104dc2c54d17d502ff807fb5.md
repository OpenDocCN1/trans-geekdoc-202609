### 3.10.2.3 参数估计方法

第 3.10.2.1 节的贝叶斯假设检验方法存在多个缺点，例如计算边缘似然的计算困难（参见第 3.8.3 节）以及对先验的敏感性（参见第 3.10.2.2 节）。另一种方法是以通常方式估计模型的参数，然后查看分配给对应于原假设的参数值的后验概率有多大。例如，要“检验”一枚硬币是否公平，我们可以先计算后验 \(p(\theta|\mathcal{D})\)，然后通过计算 \(p(0.5-\epsilon < \theta < 0.5+\epsilon|\mathcal{D})\) 来评估原假设的合理性，其中 \((0.5-\epsilon, 0.5+\epsilon)\) 称为 **实际等价区域** 或 **ROPE** [Kru15; KL17c]。这不仅计算更简单，而且允许我们量化效应大小（即，\(\theta\) 相对于 0.5 的原假设值的预期偏差），而不仅仅是接受或拒绝一个假设。因此，此方法称为 **贝叶斯估计**。我们将在下面给出一些示例，遵循 https://www.sumsar.net/blog/2014/01/bayesian-first-aid/。(另见第 3.10.3 节，了解使用 GLM 执行更一般检验的方法。)

### 3.10.2.4 比例单样本检验（二项检验）

假设我们进行 \(N\) 次抛硬币实验并观察到 \(y\) 次正面，其中正面出现的频率为 \(\theta\)。我们希望检验原假设 \(\theta = 0.5\)。在频率派统计中，我们可以使用 **二项检验**。我们现在提出一种贝叶斯替代方案。首先计算后验，\(p(\theta|\mathcal{D}) \propto p(\theta)\text{Bin}(x|\theta,N)\)。为此，我们需要指定一个先验。我们将使用非信息先验。遵循第 3.5.2.1 节，Jeffreys 先验是 \(p(\theta) \propto \text{Beta}(\theta|\frac{1}{2},\frac{1}{2})\)，但 [Lee04] 认为，当已知正面和反面都有可能出现时，均匀先验或平坦先验 \(p(\theta) \propto \text{Beta}(\theta|1,1)\) 是最不具信息量的。然后后验变为 \(p(\theta|\mathcal{D}) = \text{Beta}(\theta|y+1, N-y+1)\)。由此，我们可以使用 \(\ell = P^{-1}(\alpha/2)\) 和 \(u = P^{-1}(1-\alpha/2)\) 计算可信区间 \(\mathcal{I} = (\ell, u)\)，其中 \(P\) 是后验的累积分布函数。我们也可以轻松计算频率超过原假设值的概率，使用

```
\(p(\theta > 0.5|\mathcal{D}) = \int_{0.5}^1 p(\theta|\mathcal{D})d\theta\) (3.328)
```

我们可以使用数值积分或解析方法计算此量 [Coo05]。

### 3.10.2.5 相对比例双样本检验（卡方检验）

现在考虑我们有 \(J\) 组的情况，在每组 \(j\) 中，我们在 \(N_j\) 次试验中观察到 \(y_j\) 次成功。我们用 \(\theta_j\) 表示成功率，并有兴趣检验所有组的 \(\theta_j\) 是否相同的假设。在频率派统计中，我们可以使用 \(\chi^2\) **检验**。我们在此提出一种贝叶斯替代方案。我们将使用第 3.10.2.4 节的扩展，即 \( y_j \sim \text{Bin}(\theta_j, N_j) \)，其中 \( \theta_j \sim \text{Beta}(1, 1) \)，对于 \( j = 1 : J \)。为简化记号，假设 J = 2 组。后验由以下给出

\( p(\theta_1, \theta_2 | \mathcal{D}) = \text{Beta}(\theta_1 | y_1 + 1, N_1 - y_1 + 1)\text{Beta}(\theta_2 | y_2 + 1, N_2 - y_2 + 1) \) (3.329)

然后我们可以使用以下方法计算组差异 \( \delta = \theta_1 - \theta_2 \) 的后验

\( p(\delta | \mathcal{D}) = \int_0^1 \int_0^1 \mathbb{I}(\delta = \theta_1 - \theta_2) p(\theta_1 | \mathcal{D}_1) p(\theta_2 | \mathcal{D}_2) \) (3.330)

\( = \int_0^1 \text{Beta}(\theta_1 | y_1 + 1, N_1 - y_1 + 1)\text{Beta}(\theta_1 - \delta | y_2 + 1, N_2 - y_2 + 1) d\theta_1 \) (3.331)

然后我们可以使用 \( p(\delta > 0 | \mathcal{D}) \) 来决定两组之间的相对比例是否存在显著差异。

### 3.10.2.6 均值单样本检验（t 检验）

考虑一个数据集，其中我们有 \(N\) 个实数值观测 \(y_n\)，我们假设它们来自高斯分布 \(y_n \sim \mathcal{N}(\mu, \sigma^2)\)。我们希望检验 \(\mu = 0\) 的假设。在频率派统计中，标准方法是使用 **t 检验**，它基于标准化估计均值的抽样分布。在此，我们开发一种贝叶斯替代方案。

如果我们使用非信息先验（它是共轭高斯-伽马先验的极限情况），那么在边缘化掉 \(\sigma^2\) 后，\(p(\mu | \mathcal{D})\) 的后验与 MLE \(\hat{\mu}\) 的抽样分布相同，如我们在第 15.2.3.2 节所示。特别是，两者都具有 Student \(t\) 分布。因此，在此简单设置中，贝叶斯可信区间将与频率派置信区间相同。

然而，对于 \(p(\mu) \propto 1\) 和 \(p(\sigma) \propto 1\) 的平坦或非信息先验可能会产生较差的结果，因为我们通常不期望任意大的值。根据 [GHV20a]，通常最好使用 **弱信息先验**，其超参数可以从数据的统计量中推导出来。例如，对于均值，我们可以使用 \(\mu = \mathcal{N}(\mu = 0, \sigma = 2.5 \text{sd}(Y))\)（假设数据已中心化），对于标准差，我们可以使用 \(p(\sigma) = \text{Half-Student-t}(\mu = 0, \sigma = \text{sd}(y), \nu = 4)\)。这些先验不再是共轭的，但我们可以使用 MCMC 或第二部分讨论的其他算法轻松进行近似后验推断。我们称此方法为 **BTT**，即“贝叶斯 t 检验”。

[Kru13] 提议使用 Student 似然 \(y_n \sim \mathcal{T}(\mu, \sigma, \nu)\) 而不是高斯似然，因为它对异常值更稳健。他将该方法称为 **BEST** 方法（“贝叶斯估计取代 t 检验”），但我们称其为 **稳健 BTT**。除了不同的似然之外，稳健 BTT 使用不同的弱信息先验，即 \(\mu \sim \mathcal{N}(\mu = M_\mu, \sigma = S_\mu)\)，\(\sigma \in \text{Unif}(\sigma_{\text{low}}, \sigma_{\text{high}})\)，以及 \(\nu - 1 \sim \text{Expon}(1/29)\)。

11. 此默认先验被 Python **bambi** 库 [Cap+22] 以及 R **rstanarm** 库使用（参见 https://mc-stan.org/rstanarm/articles/priors.html）。

12. \(\nu\) 的先验是均值为 29 并向右平移 1 的指数分布，这使 \(\nu\) 远离零。根据 [Kru13]，“选择此先验是因为它平衡了近似正态分布（\(\nu > 30\)）与重尾分布（\(\nu < 30\)）。为避免异常值的污染，\(\mu\) 的先验使用 \(M_\mu = M\)，其中 \(M\) 是截断均值，\(S_\mu = 10^3 D\)，其中 \(D\) 是平均绝对偏差。\(\sigma\) 的先验使用 \(\sigma_{\text{low}} = D/1000\) 和 \(\sigma_{\text{high}} = D \times 1000\)。

### 3.10.2.7 配对样本相对均值检验（配对 t 检验）

现在假设我们有来自两组的配对数据，\(\mathcal{D} = \{(y_{1n}, y_{2n}) : n = 1 : N\}\)，我们假设 \(y_{jn} \sim \mathcal{N}(\mu_j, \sigma^2)\)。我们有兴趣检验是否 \(\mu_1 = \mu_2\)。一个更简单的替代方法是定义 \(y_n = y_{2n} - y_{1n}\)，我们使用 \(y_n \sim \mathcal{N}(\mu, \sigma^2)\) 对其进行建模。然后我们可以使用 t 检验来检验是否 \(\mu = 0\)；这称为配对样本 t 检验。在贝叶斯设置中，我们可以直接将 \(\{y_n = y_{2n} - y_{1n}\}\) 传递给第 3.10.2.6 节的 BTT 过程。

### 3.10.2.8 双样本相对均值检验（双样本 t 检验）

在本节中，我们考虑有两个数据集的情况，\(\mathcal{D}_1 = \{y_{1n} \sim \mathcal{N}(\mu_1, \sigma_1^2) : n = 1 : N_1\}\) 和 \(\mathcal{D}_2 = \{y_{2n} \sim \mathcal{N}(\mu_2, \sigma_2^2) : n = 1 : N_2\}\)，我们希望检验原假设 \(\mu_1 = \mu_2\)。如果假设 \(\sigma_1^2 = \sigma_2^2\)，则可以使用双样本 t 检验，也称为独立 t 检验或非配对 t 检验。如果允许观测值的方差随组别变化，则可以使用 Welch's t 检验。

在贝叶斯设置中，我们可以通过将第 3.10.2.6 节的 BTT 模型推广到两组来解决此问题，即为 j = 1, 2 定义 \(y_{jn} \sim \mathcal{N}(\mu_j, \sigma_j^2)\)。（我们也可以使用稳健似然。）一旦指定了模型，我们就可以以通常方式进行后验推断，并计算诸如 \(p(\mu_1 - \mu_2 > 0 | \mathcal{D})\) 之类的量。参见图 3.27 以获得示例。
