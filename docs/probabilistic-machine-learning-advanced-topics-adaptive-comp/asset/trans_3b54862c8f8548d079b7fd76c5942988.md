
要了解为什么这个双射被称为“逆自回归”，请比较公式 (23.26) 与公式 (23.20)。两个公式仅在记号上有所不同：我们可以通过交换 u 与 x 以及 h 与 h^-1 从一个得到另一个。换句话说，逆自回归双射对自回归双射的逆进行了直接参数化。由于逆自回归双射交换了其自回归对应物的前向和逆向方向，因此它们也交换了计算属性。这意味着逆自回归流的前向方向 f 本质上是并行的，因此速度快，而其逆向方向 f^-1 本质上是顺序的，因此速度慢。

逆自回归流的一个例子是 [Kin+16] 中的同名 IAF 模型。IAF 使用仿射标量双射、掩码条件器和排列层，因此它正是第 23.2.4.2 节中描述的 MAF 模型的逆。使用 IAF，我们可以从基分布（例如对角高斯分布）中并行生成 u，然后并行采样 x 的每个元素。但是，对任意数据点 x 评估 p(x) 很慢，因为我们必须顺序评估 u 的每个元素。幸运的是，评估 IAF 生成的样本（与外部提供的样本相反）的似然性不产生额外成本，因为在这种情况下 u_i 项已经被计算。

尽管 IAF 并不十分适合密度估计或最大似然训练，但它非常适合在变分推断中参数化变分后验。这是因为为了估计变分下界（ELBO），我们只需要来自变分后验的样本及其关联的概率密度，这两者都可以高效地获取。详情请参见第 23.1.2.2 节。

IAF 的另一个有用应用是训练它们来模仿那些概率密度评估速度快但采样速度慢的模型。一个显著的例子是 [Oor+18] 中的并行 WaveNet 模型。该模型是一个 IAF p_s，通过最小化 KL 散度 D_KL(p_s || p_t) 来模仿预训练的 WaveNet 模型 p_t。这个 KL 可以通过先从 p_s 采样，然后在这些样本上评估 log p_s 和 log p_t 来轻松估计，这些操作对这些模型来说都是高效的。训练后，我们得到一个 IAF，它可以生成与原始 WaveNet 质量相似的音频，但速度快得多。

### 23.2.4.4 与自回归模型的联系

自回归流可以被视为对连续随机变量的自回归模型的推广，这些模型在第 22.1 节中讨论过。具体来说，任何连续自回归模型都可以重新参数化为一个单层自回归流，如下文所述。

考虑连续随机变量 x = (x1, ..., xD) ∈ R^D 上的一般自回归模型，写为

$p(\boldsymbol{x}) = \prod_{i=1}^D p_i(x_i | \boldsymbol{\theta}_i) \quad \text{where} \quad \boldsymbol{\theta}_i = \Theta_i(\boldsymbol{x}_{1:i-1}). \quad (23.27)$

在上述表达式中，p_i(x_i | θ_i) 是自回归模型的第 i 个条件分布，其参数 θ_i 是前序变量 x_{1:i-1} 的任意函数。例如，p_i(x_i | θ_i) 可以是一维高斯分布的混合，其中 θ_i 代表其均值、方差和混合系数的集合。

现在考虑从自回归模型中采样向量 x，可以通过一次采样一个元素来完成，如下所示：

$x_i \sim p_i(x_i|\Theta_i(x_{1:i-1})) \quad \text{for } i=1,\dots,D.$

每个条件分布可以使用逆变换采样（第 11.3.1 节）进行采样。令 U(0,1) 为区间 [0,1] 上的均匀分布，令 CDF_i(x_i|θ_i) 为第 i 个条件分布的累积分布函数。采样可以写为：

$x_i = \text{CDF}_i^{-1}(u_i|\Theta_i(x_{1:i-1})) \quad \text{where } u_i \sim U(0,1).$

将上述表达式与公式 (23.19) 中自回归双射的定义进行比较，我们发现自回归模型已被表达为一个单层自回归流，其基分布在 [0,1]^D 上均匀分布，其标量双射对应于逆条件累积分布函数。以这种方式将自回归模型视为流具有一个重要优势，即允许我们通过在流中组合多个自回归模型实例来提高自回归模型的灵活性，而不会牺牲整体的可处理性。

## 23.2.5 残差流

残差网络是 **残差连接** 的组合，残差连接是形式为 f(u) = u + F(u) 的函数。函数 F: R^D → R^D 被称为 **残差块**，它计算输出和输入之间的差值，f(u) - u。

在 F 满足某些条件下，残差连接 f 变得可逆。我们将由可逆残差连接组成的流称为 **残差流**。在以下内容中，我们将描述限制残差块 F 的两种方法，以使残差连接 f 可逆。

### 23.2.5.1 收缩残差块

确保残差连接可逆的一种方法是选择残差块为收缩映射。收缩映射是 Lipschitz 常数小于 1 的函数 F；也就是说，存在 0 ≤ L < 1，使得对于所有 u1 和 u2 我们有：

||F(u1) - F(u2)|| ≤ L||u1 - u2||.

f(u) = u + F(u) 的可逆性可以如下证明。考虑映射 g(u) = x - F(u)。因为 F 是收缩映射，所以 g 也是收缩映射。因此，根据 Banach 定点定理，g 有一个唯一的固定点 u*。因此我们有

u* = x - F(u*)
⇒ u* + F(u*) = x
⇒ f(u*) = x.

因为 u* 是唯一的，所以 u* = f^{-1}(x)。

具有收缩残差块的残差流的一个例子是 [Beh+19] 中的 **iResNet** 模型。iResNet 的残差块是卷积神经网络，即由卷积层和非线性激活函数组成的组合。由于组合的 Lipschitz 常数小于或等于各个函数的 Lipschitz 常数之积，因此只需确保卷积是收缩的，并使用斜率小于或等于 1 的递增激活函数即可。iResNet 模型通过对其权重应用谱归一化 [Miy+18a] 来确保卷积是收缩的。

一般来说，逆 f^{-1} 没有解析表达式。但是，我们可以使用以下迭代过程来近似 f^{-1}(x)：

u_n = g(u_{n-1}) = x - F(u_{n-1}). (23.34)

Banach 定点定理保证序列 u_0, u_1, u_2, … 对于任何 u_0 的选择都将收敛到 u* = f^{-1}(x)，且收敛速率为 O(L^n)，其中 L 是 g（与 F 相同）的 Lipschitz 常数。在实践中，选择 u_0 = x 很方便。

此外，雅各比行列式没有解析表达式，其精确计算成本为 O(D^3)。但是，存在一个计算高效的随机估计器来估计对数雅各比行列式。其思路是将对数雅各比行列式表示为幂级数。利用 f(x) = x + F(x) 这一事实，我们有

log | det J(f) | = log | det(I + J(F)) | = Σ_{k=1}^∞ (-1)^{k+1}/k tr[J(F)^k]. (23.35)

当 J(F) 的矩阵范数小于 1 时，该幂级数收敛，这里由于 F 是收缩映射，这完全得到保证。J(F)^k 的迹可以通过 Hutchinson 迹估计器 [Ski89; Hut89; Mey+21] 利用雅各比-向量积高效近似：

tr[J(F)^k] ≈ v^T J(F)^k v, (23.36)

其中 v 是来自均值为零且协方差为单位的分布（如 N(0, I)）的样本。最后，无穷级数可以通过截断 [Beh+19] 近似为有限级数，但这不幸会产生有偏估计器，或者通过使用俄罗斯轮盘估计器 [Che+19] 来近似，该估计器是无偏的。

### 23.2.5.2 具有低阶雅各比的残差块

有一种计算高效的方法来计算身份矩阵低阶扰动矩阵的行列式。假设 A 和 B 是矩阵，其中 A 是 D×M，B 是 M×D。以下公式被称为 Weinstein-Aronszajn 恒等式^2，是更一般的矩阵行列式引理的特例：

det(I_D + AB) = det(I_M + BA). (23.37)

我们分别用 I_D 和 I_M 表示 D×D 和 M×M 的单位矩阵。该公式的意义在于将计算成本为 O(D^3) 的 D×D 行列式转换为计算成本为 O(M^3) 的 M×M 行列式。如果 M 小于 D，这将节省计算量。
