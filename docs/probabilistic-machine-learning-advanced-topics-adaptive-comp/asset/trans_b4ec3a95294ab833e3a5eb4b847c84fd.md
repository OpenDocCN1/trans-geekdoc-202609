### 20.3.2 密度估计

**密度估计** 的任务是评估观测数据向量的概率，即计算 _p_(_x_)。这对于异常值检测（第 19.3.2 节）、数据压缩（第 5.4 节）、生成式分类器、模型比较等可能很有用。

解决这个问题的一个简单方法（在低维下有效）是使用**核密度**

图 20.5：基于 6 个数据点（用 x 表示）在 1d 中估计的非参数（Parzen）密度估计器。第一行：均匀核。第二行：高斯核。左列：带宽参数 h = 1。右列：带宽参数 h = 2。改编自 http://en.wikipedia.org/wiki/Kernel_density_estimation。由 parzen_window_demo.ipynb 生成。

估计或 KDE，其形式为

```
$$ p(\boldsymbol{x}|\mathcal{D}) = \frac{1}{N} \sum_{n=1}^N \mathcal{K}_h(\boldsymbol{x} - \boldsymbol{x}_n) $$
```

这里 $\mathcal{D} = \{\boldsymbol{x}_1, ..., \boldsymbol{x}_N\}$ 是数据，$\mathcal{K}_h$ 是带有**带宽** $h$ 的密度核，它是一个函数 $\mathcal{K} : \mathbb{R} \rightarrow \mathbb{R}_+$，满足 $\int \mathcal{K}(x) dx = 1$ 和 $\int x \mathcal{K}(x) dx = 0$。我们在图 20.5 中给出了一个 1d 示例：第一行使用均匀（方框）核，第二行使用高斯核。

在高维中，KDE 受到**维度灾难**（见例：[AHK01]）的影响，我们需要使用某种参数密度模型 $p_{\boldsymbol{\theta}}(\boldsymbol{x})$。

### 20.3.3 填补缺失值

**填补缺失值** 的任务是“填充”数据向量或数据矩阵中的缺失值。例如，假设 $\mathbf{X}$ 是一个 $N \times D$ 的数据矩阵（可以把它想象成电子表格），其中一些条目（称为 $\mathbf{X}_m$）可能缺失，而其余条目（$\mathbf{X}_o$）已被观测。填补缺失数据的一种简单方法是使用每个特征的均值 $\mathbb{E} [x_d]$；这称为**均值填补**，并

### 20.3.4 结构发现

某些生成模型具有隐性变量 z，这些变量被假设是生成观测数据 x 的“原因”。我们可以使用贝叶斯规则反转模型以计算 p(z|x) ∝ p(z)p(x|z)。这对于发现数据中的隐性低维模式可能很有用。例如，假设我们干扰细胞中的各种蛋白质，并使用称为流式细胞术的技术测量结果的磷酸化状态，如 [Sac+05] 所示。此类数据集的示例见图 20.7(a)。每一行代表一个数据样本 xn ~ p(·|an, z)，其中 x ∈ R^11 是输出向量（磷酸化），a ∈ {0, 1}^6 是输入动作向量（干扰），z 是未知的细胞信号网络结构。我们可以使用图形模型结构学习技术推断图结构 p(z|D)（参见第 30.3 节）。特别是，我们可以使用 [EM07] 中描述的动态规划方法，得到如图 20.7(b) 所示的结果。在这里，我们绘制中位图，其中包括所有满足 p(zij = 1|D) > 0.5 的边。（有关此问题的更近期方法，见例：[Bro+20b]。）
