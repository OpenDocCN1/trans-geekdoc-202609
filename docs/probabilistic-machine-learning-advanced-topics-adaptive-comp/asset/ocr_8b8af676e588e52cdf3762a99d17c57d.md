At test time, we usually turn the dropout noise off, so the model acts deterministically. To ensure the weights have the same expectation at test time as they did during training (so the input activation to the neurons is the same, on average), at test time we should use \(\mathbb{E}[\theta_{lij}] = w_{lij} \mathbb{E}[\epsilon_i]\). For Bernoulli noise, we have \(\mathbb{E}[\epsilon] = 1 - p\), so we should multiply the weights by the keep probability, \(1 - p\), before making predictions. We can, however, use dropout at test time if we wish. This is called **Monte Carlo dropout** (see Section 17.3.1).
