## 23.2 构建流

在本节中，我们将讨论如何计算各种设计为可逆且具有高效可计算雅可比行列式的流。

### 23.2.1 仿射流

一个简单的选择是使用仿射变换 $x = f(u) = A u + b$。当且仅当 $A$ 是可逆方阵时，这才是一个双射。$f$ 的雅可比行列式是 det $A$，其逆为 $u = f^{-1}(x) = A^{-1}(x - b)$。由仿射双射组成的流称为**仿射流**，或者如果忽略 $b$，则称为**线性流**。

单独来看，仿射流的表达能力有限。例如，假设基分布是高斯分布，$p(u) = N(u|\mu, \Sigma)$。那么经过仿射双射后的映射分布仍然是高斯分布，$p(x) = N(x|A\mu + b, A\Sigma A^\top)$。然而，当仿射双射与我们稍后讨论的非仿射双射组合时，它们是有用的构建块，因为它们鼓励通过流进行维度的"混合"。

出于实际原因，我们需要确保流的雅可比行列式和逆能够快速计算。一般来说，显式计算 det $A$ 和 $A^{-1}$ 需要 $O(D^3)$ 时间。为降低成本，我们可以对 $A$ 加入结构。如果 $A$ 是对角矩阵，成本变为 $O(D)$。如果 $A$ 是三角矩阵，雅可比行列式为对角元素的乘积，因此耗时 $O(D)$；对流求逆需要求解三角方程组 $A u = x - b$，这可以通过回代在 $O(D^2)$ 时间内完成。

三角变换的结果取决于维度的顺序。为降低对此的敏感性，并鼓励维度间的"混合"，我们可以将 $A$ 与一个置换矩阵相乘，其行列式的绝对值为 1。我们通常使用在每层反转索引或随机打乱索引的置换。然而，通常每层的置换是固定的，而不是学习得到的。

对于具有空间结构的数据（例如图像），我们可以将 $A$ 定义为卷积矩阵。例如，GLOW [KD18b] 使用 $1 \times 1$ 卷积；这相当于跨特征维度的逐点线性变换，但跨空间维度是常规卷积。[HBW19] 中介绍了两种更通用的建模 $d \times d$ 卷积的方法，一种基于堆叠自回归卷积，另一种基于在傅里叶域中进行卷积。

### 23.2.2 逐元素流

令 $h : \mathbb{R} \to \mathbb{R}$ 为一个标量值双射。我们可以通过逐元素应用 $h$ 来创建一个向量值双射 $f : \mathbb{R}^D \to \mathbb{R}^D$，即 $f(u) = (h(u_1), \dots, h(u_D))$。函数 $f$ 是可逆的，其雅可比行列式由 $\prod_{i=1}^D \frac{dh}{du_i}$ 给出。由这样的双射组成的流称为**逐元素流**。

单独来看，逐元素流是有限的，因为它们不建模元素之间的依赖关系。然而，它们是构建更复杂流（如耦合流（第 23.2.3 节）和自回归流（第 23.2.4 节））的有用构建块，正如我们稍后将看到的。在本节中，我们将讨论用于在逐元素流中构建标量值双射 \( h : \mathbb{R} \rightarrow \mathbb{R} \) 的技术。

### 23.2.2.1 仿射标量双射

仿射标量双射的形式为 \( h(u; \boldsymbol{\theta}) = au + b \)，其中 \( \boldsymbol{\theta} = (a, b) \in \mathbb{R}^2 \)。（这是仿射流的标量版本。）其导数 \( \frac{dh}{du} \) 等于 \( a \)。当且仅当 \( a \neq 0 \) 时，它才可逆。在实践中，我们通常将 \( a \) 参数化为正值，例如将其设为无约束参数的指数或 softplus。当 \( a = 1 \) 时，\( h(u; \boldsymbol{\theta}) = u + b \) 通常称为**加法标量双射**。

### 23.2.2.2 高阶扰动

仿射标量双射使用简单，但受限。在保持可逆性的前提下，我们可以通过添加高阶扰动使其更灵活。例如，Ziegler 和 Rush [ZR19b] 提出了以下方法，他们称之为**非线性平方流**：

\( h(u; \boldsymbol{\theta}) = au + b + \frac{c}{1 + (du + e)^2}, \) (23.9)

其中 \( \boldsymbol{\theta} = (a, b, c, d, e) \in \mathbb{R}^5 \)。当 \( c = 0 \) 时，这退化为仿射情况。当 \( c \neq 0 \) 时，它添加一个逆二次扰动，如图 23.1 所示，这可以诱导多峰性。在约束 \( a > \frac{9}{8\sqrt{3}}cd \) 和 \( d > 0 \) 下，该函数变为可逆，其逆可通过求解二次多项式解析计算。

### 23.2.2.3 严格单调标量函数的组合

严格单调标量函数是指始终递增（处处导数为正）或始终递减（处处导数为负）的函数。这类函数是可逆的。许多激活函数，如逻辑 sigmoid $\sigma(u) = 1/(1 + \exp(-u))$，都是严格单调的。

以这样的激活函数为起点，我们可以通过**锥形组合**（正系数线性组合）和函数复合来构建更灵活的单调函数。假设 \(h_1, \dots, h_K\) 是严格递增的；则以下也是严格递增的：

- \(a_1 h_1 + \dots + a_K h_K + b\) 且 \(a_k > 0\)（带偏置的锥形组合），
- \(h_1 \circ \dots \circ h_K\)（函数复合）。

通过重复上述两种构造，我们可以构建任意复杂的递增函数。例如，逻辑 sigmoid 的锥形组合的复合只是一个所有权重均为正的 MLP [Hua+18b]。

这样的标量双射的导数可以通过反复应用链式法则来计算，在实践中可以通过自动微分完成。然而，其逆通常无法以封闭形式计算。在实践中，我们可以使用二分法来数值计算逆，因为该函数是单调的。

### 23.2.2.4 来自积分的标量双射

确保标量函数严格单调的一个简单方法是将其导数约束为正值。令 \(h' = \frac{dh}{du}\) 为该导数。Wehenkel 和 Louppe [WL19] 直接用神经网络参数化 \(h'\)，其输出通过上移 1 的 ELU 激活函数变为正值。然后他们对导数进行数值积分以得到双射：

\(h(u) = \int_0^u h'(t)dt + b,\) (23.10)

其中 \(b\) 是偏置。他们称这种方法为**无约束单调神经网络**。

上述积分通常无法以封闭形式计算。然而，如果对 \(h'\) 加以适当约束，则可以计算。例如，Jaini、Selby 和 Yu [JSY19] 取 \(h'\) 为 \(K\) 个次数为 \(L\) 的平方多项式之和：

\(h'(u) = \sum_{k=1}^K \left( \sum_{\ell=0}^L a_{k\ell} u^\ell \right)^2 .\) (23.11)

这使 \(h'\) 成为次数为 \(2L\) 的非负多项式。积分在解析上可处理，并使 \(h\) 成为次数为 \(2L + 1\) 的递增多项式。对于 \(L = 0\)，\(h'\) 为常数，因此 \(h\) 退化为仿射标量双射。在这些方法中，双射的导数可以直接读出。然而，其逆通常无法以解析形式计算。在实践中，我们可以使用二分法来数值计算逆。

### 23.2.2.5 样条

构建单调标量函数的另一种方法是使用**样条**。这些是分段多项式或分段有理函数，用样条经过的 \(K + 1\) 个**节点** \((u_k, x_k)\) 参数化。即，我们设置 \(h(u_k) = x_k\)，并在区间 \((u_{k-1}, u_k)\) 上通过插值定义 \(h\)。
