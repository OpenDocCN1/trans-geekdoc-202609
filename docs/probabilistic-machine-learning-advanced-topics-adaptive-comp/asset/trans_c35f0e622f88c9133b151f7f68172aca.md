

[Nae+18] 指出，这些分布之间的 KL 散度可以如下界定：

$$0 \le D_{KL}(\mathbb{E}[\hat{\pi}_T(z_{1:T})] \parallel \pi_T(z_{1:T})) \le -\mathbb{E} \left[ \log \frac{\hat{Z}_T}{Z_T} \right]$$ (13.86)

其中

$$Z_T(\theta) = p_\theta(y_{1:T}) = \int p_\theta(z_{1:T}, y_{1:T}) dz_{1:T}$$ (13.87)

因此

$$\mathbb{E} \left[ \log \hat{Z}_T(\theta, \phi) \right] \le \mathbb{E} [\log Z_T(\theta)] = \log Z_T(\theta)$$ (13.88)

因此，我们可以使用 SMC 采样来计算 $\mathbb{E} \left[ \log \hat{Z}_T(\theta, \phi) \right]$ 的无偏近似，它是证据（边缘似然对数）的下界。

我们现在可以使用 SGD 关于 $\theta$ 和 $\phi$ 最大化这个下界，作为一种学习提议分布和模型的方法。不幸的是，计算下界的梯度比较棘手，因为重采样步骤是不可微的。然而，在实际中，可以忽略重采样算子对参数的依赖，或者使用可微近似（例如，见 [Ros+22]）。这种总体方法在几篇论文中被独立提出：**FIVO**（滤波变分目标）论文 [Mad+17]、**变分 SMC** 论文 [Nae+18] 和 **自编码 SMC** 论文 [Le+18]。

### 13.6.8 变分平滑 SMC

第 13.6.7 节中的方法使用 SMC，其中目标分布被定义为滤波分布，$\pi_t(z_{1:t}) = p_\theta(z_{1:t}|y_{1:t})$；这被称为 **滤波 SMC**。不幸的是，在将模型拟合到离线序列数据时，这可能效果不佳，因为在时间 $t$，无论提议多么好，目标函数都会忽略所有未来观测。这可能会导致当前采样轨迹集下未来观测不太可能的情况，从而导致粒子贫乏和下界估计的高方差。

最近，[Law+22] 提出了一种称为 **SIXO**（带有扭曲目标的平滑推断）的新方法，它使用平滑分布作为目标，$\pi_t(z_{1:t}) = p_\theta(z_{1:t}|y_{1:T})$，以创建方差更低的变分下界。当然，不可能直接计算这个后验，但我们可以使用 **扭曲粒子滤波器** [WL14a; AL+16] 来近似它。在这种方法中，我们使用以下公式近似（未归一化的）后验：

$$p_\theta(z_{1:t}, y_{1:T}) = p_\theta(z_{1:t}, y_{1:t}) p_\theta(y_{t+1:T} | z_{1:t}, y_{1:t})$$ (13.89)

$$= p_\theta(z_{1:t}, y_{1:t}) p_\theta(y_{t+1:T} | z_t)$$ (13.90)

$$\approx p_\theta(z_{1:t}, y_{1:t}) r_\phi(y_{t+1:T}, z_t)$$ (13.91)

其中 $r_\phi(y_{t+1:T}, z_t) \approx p_\theta(y_{t+1:T} | z_t)$ 是 **扭曲函数**，它充当“前瞻函数”。

近似扭曲函数的一种方法是注意到

$$p_\theta(y_{t+1:T} | z_t) = \frac{p_\theta(z_t | y_{t+1:T}) p_\theta(y_{t+1:T})}{p_\theta(z_t)} \propto \frac{p_\theta(z_t | y_{t+1:T})}{p_\theta(z_t)}$$ (13.92)

其中我们丢弃了与 $z_t$ 无关的项，因为在归一化采样权重时这些项会相互抵消。我们可以使用第 2.7.5 节的二元分类器方法来近似密度比。为此，我们定义一个分布为 $p_1 = p_\theta(z_t, y_{t+1:T})$，另一个分布为 $p_2 = p_\theta(z_t)p_\theta(y_{t+1:T})$，使得 $p_1/p_2 = \frac{p_\theta(z_t|y_{t+1:T})}{p_\theta(z_t)}$。我们可以轻松地使用祖先采样绘制样本 $(z_{1:T}, y_{1:T}) \sim p_\theta$，从中我们可以通过边缘化计算 $(z_t, y_{t+1:T}) \sim p_1$。我们也可以从 $(\tilde{z}_{1:T}, \tilde{y}_{1:T}) \sim p_\theta$ 采样一个新的序列，从中我们可以通过边缘化计算 $(\tilde{z}_t, \tilde{y}_{t+1:T}) \sim p_2$。然后，在训练二元分类器 $r_\psi(y_{t+1:T}, z_t)$ 时，我们使用 $(z_t, y_{t+1:T})$ 作为正例，使用 $(\tilde{z}_t, \tilde{y}_{t+1:T})$ 作为负例。

一旦我们更新了扭曲参数 $\psi$，就可以重新运行 SMC 以获得对数边缘似然的更紧下界，然后我们可以关于模型参数 $\theta$ 和提议参数 $\phi$ 对其进行优化。因此，整体方法是一种随机变分 EM 类方法，用于优化下界

$\mathcal{L}_{\text{SIXO}}(\theta, \phi, \psi, y_{1:T}) \triangleq \mathbb{E} \left[ \log \hat{Z}_{\text{SIXO}}(\theta, \phi, \psi, y_{1:T}) \right]$ (13.93)

$\le \log \mathbb{E} \left[ \hat{Z}_{\text{SIXO}}(\theta, \phi, \psi, y_{1:T}) \right] = \log p_\theta(y_{1:T})$ (13.94)

在 [Law+22] 中，他们证明如下：假设真模型 $p^*$ 是一个 SSM，其中模型的最优提议函数满足 $p^*(z_t|z_{1:t-1}, y_{1:T}) \in \mathcal{Q}$，模型的最优前瞻函数满足 $p^*(y_{t+1:T}|z_t) \in \mathcal{R}$。此外，假设 SIXO 目标有一个唯一的最大化器。那么，在最优情况下，学习到的提议 $q_{\phi^*}(z_t|z_{1:t-1}, y_{1:T}) \in \mathcal{Q}$ 等于最优提议，学习到的扭曲函数 $r_{\psi^*}(y_{t+1:T}, z_t) \in \mathcal{R}$ 等于最优前瞻，并且下界是紧的（即，$\mathcal{L}_{\text{SIXO}}(\theta^*, \phi^*, \psi^*) = p^*(y_{1:T})$），对于任何样本数量 $N_s \ge 1$ 和任何类型的 SSM $p^*$ 都成立。（这与 FIVO 下界形成对比，FIVO 下界通常不会变紧。）

## 14 预测模型：概览

### 14.1 简介

机器学习的绝大部分都关注于解决一个单一问题，即学习使用从标记训练集 D = {(**x**_n_, **y**_n_) : _n_ = 1 : _N_} 估计的某个函数 _f_，从输入 **x** 预测输出 **y**，其中 \(\mathbf{x}_n \in \mathcal{X} \subseteq \mathbb{R}^D\) 和 \(\mathbf{y}_n \in \mathcal{Y} \subseteq \mathbb{R}^C\)。我们可以使用条件概率模型 _p_(**y**|_f_(**x**)) 来模拟对给定输入的正确输出的不确定性。当 Y 是离散标签集合时，这在机器学习文献中被称为 **判别模型**，因为它让我们能够区分 **y** 的不同可能值。如果输出是实数值，Y = R，这被称为 **回归模型**。（在统计学文献中，“回归模型”一词在两种情况下都使用，即使 Y 是离散集合。）我们将使用更通用的术语 **“预测模型”** 来指代此类模型。

预测模型可以被视为条件生成模型（在第 20 章讨论）的特例。在预测模型中，输出通常是低维的，并且有一个我们想要预测的单一最佳答案。然而，在大多数生成模型中，输出通常是高维的，例如图像或句子，并且对于任何给定的输入可能有多个正确输出。我们将在第 14.1.1 节讨论各种类型的预测模型，但将详细内容推迟到后续章节。本章剩余部分讨论与所有类型的预测模型相关的问题，无论其具体形式如何，例如评估。

### 14.1.1 模型类型

存在许多不同类型的预测模型 _p_(**y**|**x**）。最大的区别在于 **参数模型**（具有与训练集大小无关的固定参数数量）和 **非参数模型**（具有随训练集大小增长的可变参数数量）之间。非参数模型通常更灵活，但用于预测时可能较慢。参数模型通常不够灵活，但用于预测时更快。

大多数非参数模型基于将测试输入 **x** 与存储的训练示例 {**x**_n_, _n_ = 1 : _N_} 中的某些或全部进行比较，使用某种形式的相似性，_s<sub>n</sub>_ = K(**x**, **x**_n_) ≥ 0，然后使用训练标签的某种加权组合来预测输出，例如 \(\hat{\mathbf{y}} = \sum_{n=1}^N s_n\mathbf{y}_n\)。典型示例是高斯过程，我们将在第 18 章讨论。其他示例，例如 _K_-近邻模型，在本书的前作 [Mur22] 中讨论。
