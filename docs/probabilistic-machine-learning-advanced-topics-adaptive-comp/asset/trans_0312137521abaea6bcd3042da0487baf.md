表 28.1: 一些流行的“浅层”隐性因子模型。缩写：FA = 因子分析，PCA = 主成分分析，GMM = 高斯混合模型，NMF = 非负矩阵分解，mPCA = 多项式 PCA，LDA = 隐性狄里克莱分配，ICA = 独立成分分析。k = 1 : L 跨越潜在维度，d = 1 : D 跨越观测维度。（对于 ICA，我们有约束 L = D。）

此潜在变量的先验为 p(z = k) = πk，条件分布为 p(x|z = k) = pk(x) = p(x|θk)。也就是说，我们定义以下联合模型：

```
p(z|θ) = Cat(z|π) (28.4)
p(x|z = k, θ) = p(x|θk) (28.5)
```

数据的“生成性故事”是：我们首先采样特定分量 z，然后根据 z 的取值选择参数来生成观测 x。通过对 z 边缘化，我们恢复方程 (28.3)：

```
p(x|θ) = Σk=1^K p(z = k|θ)p(x|z = k, θ) = Σk=1^K πk p(x|θk) (28.6)
```

通过改变基础分布 pk，我们可以创建不同种类的混合模型，如下文所示。

## 28.2.1 高斯混合模型 (GMMs)

高斯混合模型（或 GMM），也称为高斯混合（MoG），定义如下：

```
p(x) = Σk=1^K πk N(x|μk, Σk) (28.7)
```

在图 28.1 中，我们展示了由 2d 中 3 个高斯分布的混合定义的密度。每个混合分量由一组不同的椭圆等高线表示。如果允许混合分量数量足够大，GMM 可以逼近 RD 上的任何平滑分布。

GMM 常用于对实值数据样本 xn ∈ RD 进行无监督聚类。这分为两个阶段。首先，我们通常通过计算 MLE θ̂ = argmax log p(D|θ) 来拟合模型，

其中 $\mathcal{D} = \{ \mathbf{x}_n : n = 1 : N \}$（例如，使用 EM 或 SGD）。然后，我们将每个数据点 $\mathbf{x}_n$ 与一个离散潜在或隐藏变量 $z_n \in \{ 1, \dots, K \}$ 关联，该变量指定用于生成 $\mathbf{x}_n$ 的混合分量或聚类的身份。这些潜在身份是未知的，但我们可以使用贝叶斯规则计算它们的后验分布：

$r_{nk} \triangleq p(z_n = k | \mathbf{x}_n, \boldsymbol{\theta}) = \frac{p(z_n = k | \boldsymbol{\theta}) p(\mathbf{x}_n | z_n = k, \boldsymbol{\theta})}{\sum_{k'=1}^K p(z_n = k' | \boldsymbol{\theta}) p(\mathbf{x}_n | z_n = k', \boldsymbol{\theta})}$ (28.8)

量 $r_{nk}$ 被称为数据点 $n$ 对于聚类 $k$ 的**责任度**。给定责任度，我们可以按如下方式计算最可能的聚类分配：

$\hat{z}_n = \arg \max_k r_{nk} = \arg \max_k [ \log p(\mathbf{x}_n | z_n = k, \boldsymbol{\theta}) + \log p(z_n = k | \boldsymbol{\theta}) ]$ (28.9)

这称为**硬聚类**。（如果我们使用责任度将每个数据点按比例分配给不同的聚类，则称为**软聚类**。）参见图 28.2 了解示例。

![](img/ca72c1626f4850f058a9edc138c1ac73_953_0.png)

图 28.3：我们将 20 个伯努利分布的混合模型拟合到二值化 MNIST 数字数据上。我们可视化了估计的聚类均值 \(\hat{\mu}_k\)。每张图像上方的数字表示估计的混合权重 \(\hat{\pi}_k\)。训练模型时未使用任何标签。由 `mix_bernoulli_em_mnist.ipynb` 生成。

如果对 \(z_n\) 采用统一先验，并且使用协方差为 \(\Sigma_k = \mathbf{I}\) 的球形高斯分布，则硬聚类问题简化为

```
\(z_n = \text{argmin}_k ||x_n - \hat{\mu}_k||_2^2\) (28.10)
```

换句话说，我们按欧氏距离将每个数据点分配给其最近的质心。这是 K-means 聚类算法的基础（参见本书前作）。

## 28.2.2 伯努利混合模型

如果数据是二值的，我们可以使用**伯努利混合模型**（BMM），也称为**伯努利混合**，其中每个混合分量具有以下形式：

```
\(p(\mathbf{x}|z=k, \boldsymbol{\theta}) = \prod_{d=1}^D \text{Ber}(y_d | \mu_{dk}) = \prod_{d=1}^D \mu_{dk}^{y_d} (1 - \mu_{dk})^{1-y_d}\) (28.11)
```

这里 \(\mu_{dk}\) 是簇 \(k\) 中位 \(d\) 变为 1 的概率。

例如，考虑使用 \(K=20\) 个分量将伯努利混合模型拟合到 MNIST 数据集。每个混合分量的结果参数（即 \(\boldsymbol{\mu}_k\) 和 \(\pi_k\)）如图 28.3 所示。我们看到，该模型“发现”了每种数字的表示。（有些数字被多次表示，因为模型不知道“真实”的类别数量。有关如何选择混合分量数量 \(K\) 的信息，请参见第 3.8.1 节。）

## 28.2.3 高斯尺度混合模型 (GSMs)

高斯尺度混合模型（GSM）[AM74; Wes87] 就像一个“无限”的高斯分布混合，每个分量具有不同的尺度（方差）。更准确地说，设 \(x = \epsilon z\)，其中 \(z \sim \mathcal{N}(0, \sigma_0^2)\) 和 \(\epsilon \sim p(\epsilon)\)。我们可以将其视为对高斯随机变量 $z$ 应用**乘法噪声**。我们有 $x|\epsilon \sim \mathcal{N}(0, \epsilon^2\sigma_0^2)$。对尺度 $\epsilon$ 边缘化得到

$p(x) = \int \mathcal{N}(x|0, \sigma_0^2 \epsilon^2) p(\epsilon) d\epsilon$

通过改变先验 $p(\epsilon)$，我们可以创建各种有趣的分布。下面给出一些示例。

这种方法的主要优点是，使用**扩展参数化**通常在计算上更方便，其中我们显式包含尺度项 $\epsilon$，因为在此条件下，分布是高斯分布。我们在第 6.5.5 节中使用这种表述，讨论鲁棒回归。

### 28.2.3.1 作为 GSM 的 Student-t 分布

我们可以将 Student 分布表示为如下 GSM：

$\mathcal{T}(x|0, \sigma^2, \nu) = \int_0^\infty \mathcal{N}(x|0, z\sigma^2) \text{IG}(z|\frac{\nu}{2}, \frac{\nu}{2}) dz = \int_0^\infty \mathcal{N}(x|0, z\sigma^2) \chi^{-2}(z|\nu, 1) dz$

其中 IG 是逆伽马分布（第 2.2.3.4 节）。因此，我们可以将 Student 视为不同宽度高斯分布的无限叠加；对其边缘化会产生比同方差高斯分布具有更宽尾部的分布。这一结果还解释了为什么当自由度变大时，Student 分布趋近于高斯分布，因为当 $\nu = \infty$ 时，逆伽马分布变成一个狄拉克 δ 函数。

### 28.2.3.2 作为 GSM 的拉普拉斯分布

同样，可以证明拉普拉斯分布是高斯分布的无限加权和，其中精度来自伽马分布：

$\text{Laplace}(x|0, \lambda) = \int \mathcal{N}(x|0, \tau^2) \text{Ga}(\tau^2|1, \frac{\lambda^2}{2}) d\tau^2$

### 28.2.3.3 峰值与平台分布

假设 $\epsilon \sim \text{Ber}(\pi)$。（注意 $\epsilon^2 = \epsilon$，因为 $\epsilon \in \{0, 1\}$。）在此情况下，我们有

$p(x) = \sum_{\epsilon \in \{0, 1\}} \mathcal{N}(x|0, \sigma_0^2 \epsilon) p(\epsilon) = \pi \mathcal{N}(x|0, \sigma_0^2) + (1 - \pi) \delta_0(x)$

这称为峰值与平台分布，因为 $\delta_0(x)$ 是 0 处的“峰值”，而 $\mathcal{N}(x|0, \sigma_0^2)$ 对于足够大的 $\sigma_0$ 表现得像统一的“平台”。该分布在稀疏建模中很有用。
