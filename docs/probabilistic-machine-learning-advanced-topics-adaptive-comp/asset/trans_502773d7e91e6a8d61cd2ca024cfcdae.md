## 36.5.2 工具单调性和局部平均处理效应

我们现在考虑一种可加未观测混杂的替代假设，该假设适用于工具变量和处理变量均为二元的情况。将工具变量概念化为分配至处理会比较方便。然后，人口分为四个子群：

- 顺从者，若被分配至处理则接受处理，否则不接受处理。
- 始终接受者，无论其分配如何都接受处理。
- 从不接受者，无论其分配如何都拒绝处理。
- 逆向者，若被分配至处理则拒绝处理，若未被分配则接受处理。

在此设定中，我们的目标是识别顺从者中的平均处理效应。局部平均处理效应（或称依从者平均处理效应）定义为^8

8. 我们遵循计量经济学文献的惯例，使用 "LATE"，因为 "CATE" 已经常用于表示条件平均处理效应。

LATE = E[Y|do(A = 1), 顺从者] - E[Y|do(A = 0), 顺从者]. (36.56)

LATE 的识别需要一个额外的假设。即，工具单调性：被分配（未被分配）处理只会增加（减少）每个单位接受处理的概率。等价地，P(逆向者) = 0。我们可以写出识别结果。

**定理 4.** 鉴于工具变量假设和工具单调性，局部平均处理效应被识别为观测分布的一个参数 \(\tau^{LATE}\)；即，LATE = \(\tau^{LATE}\)。具体为，

\(\tau^{LATE} = \frac{E[E[Y|X, Z = 1] - E[Y|X, Z = 0]]}{E[P(A = 1|X, Z = 1) - P(A = 1|X, Z = 0)]}\). (36.57)

**证明.** 我们现在表明，在 IV 假设和单调性条件下，LATE = \(\tau^{LATE}\)。首先，注意到

\(\tau^{LATE} = \frac{E[Y|do(Z = 1)] - E[Y|do(Z = 0)]}{P(A = 1|do(Z = 1)) - P(A = 1|do(Z = 0))}\). (36.58)

这源自对分子和分母分别应用后门调整（Theorem 2）。我们的策略是将 E[Y|do(Z = z)] 分解为顺从者、忽略工具的单位（总是/从不接受者）以及逆向者的贡献。为此，请注意 P(顺从者|do(Z = z)) = P(顺从者)，总是/从不接受者和逆向者亦然——对工具的干预不会改变人口的构成。然后，

\(\mathbb{E}[Y|do(Z=1)] - \mathbb{E}[Y|do(Z=0)]\) (36.59)
= (\mathbb{E}[Y|\text{顺从者}, do(Z=1)] - \mathbb{E}[Y|\text{顺从者}, do(Z=0)])P(\text{顺从者}) (36.60)
+ (\mathbb{E}[Y|\text{总是/从不}, do(Z=1)] - \mathbb{E}[Y|\text{总是/从不}, do(Z=0)])P(\text{总是/从不}) (36.61)
+ (\mathbb{E}[Y|\text{逆向者}, do(Z=1)] - \mathbb{E}[Y|\text{逆向者}, do(Z=0)])P(\text{逆向者}). (36.62)

关键在于顺从者子群的效应，即 Equation (36.60)。首先，根据顺从者群体的定义，我们有：

\(\mathbb{E}[Y|\text{顺从者}, do(Z=z)] = \mathbb{E}[Y|\text{顺从者}, do(A=z)]\). (36.63)

也就是说，在此子群中，处理的因果效应与工具的因果效应相同——这是工具变量方法能够识别局部平均处理效应的核心原因。这意味着

\text{LATE} = \mathbb{E}[Y|\text{顺从者}, do(Z=1)] - \mathbb{E}[Y|\text{顺从者}, do(Z=0)]. (36.64)

此外，我们有 P(顺从者) = P(A = 1|do(Z = 1)) − P(A = 1|do(Z = 0))。原因很简单，根据子群的定义，

P(A = 1|do(Z = 1)) = P(\text{顺从者}) + P(\text{总是接受者}) (36.65)
P(A = 1|do(Z = 0)) = P(\text{总是接受者}). (36.66)

现在，将 P(顺从者) 的表达式和 Equation (36.64) 代入 Equation (36.60)，我们得到：

(\mathbb{E}[Y|\text{顺从者}, do(Z=1)] - \mathbb{E}[Y|\text{顺从者}, do(Z=0)])P(\text{顺从者}) (36.67)
= LATE \times (P(A = 1|do(Z=1)) - P(A = 1|do(Z=0))) (36.68)

这为我们给出了局部平均处理效应的表达式，用工具对顺从者的效应以及单位被分配/未分配时接受处理的概率来表示。

下一步是表明剩余的工具效应分解项，即 Equations (36.61) 和 (36.62)，均为 0。Equation (36.61) 是工具对总是/从不接受者的因果效应。它等于 0，因为根据该子群的定义，工具在此子群中没有因果效应——它们忽略了工具！在数学上，这仅仅是 \mathbb{E}[Y|\text{总是/从不}, do(Z=1)] = \mathbb{E}[Y|\text{总是/从不}, do(Z=0)]。最后，Equation (36.62) 根据工具单调性假设为 0：我们假设 P(逆向者) = 0。

总而言之，我们现在有 Equations (36.60) 至 (36.62) 归约为：

\(\mathbb{E}[Y|do(Z=1)] - \mathbb{E}[Y|do(Z=0)]\) (36.69)
= LATE \times (P(A = 1|do(Z=1)) - P(A = 1|do(Z=0))) + 0 + 0 (36.70)

对 LATE 进行变形并代入 Equation (36.58) 即可得到所声称的识别结果。

### 36.5.2.1 估计

在单调工具假设下，估计局部平均处理效应存在一种适用于通用监督学习方法的双重机器学习方法。这里，我们想要一个针对参数的估计量 \(\hat{\tau}^{\text{LATE}}\) for the parameter

\(\tau^{\text{LATE}} = \frac{\mathbb{E}[\mathbb{E}[Y|X, Z=1] - \mathbb{E}[Y|X, Z=0]]}{\mathbb{E}[P(A=1|X, Z=1) - P(A=1|X, Z=0)]}.\)

为了定义估计量，引入一些额外的记法会比较方便。首先，我们定义烦扰函数：

\(\mu(z, x) = \mathbb{E}[Y|z, x]\)
\(m(z, x) = P(A=1|x, z)\)
\(p(x) = P(Z=1|x).\)

我们还按以下方式定义得分 \(\phi\) 由：

\(\phi_{Z \to Y}(\mathbf{X}; \mu, p) \triangleq \mu(1, X) - \mu(0, X) + \frac{Z(Y - \mu(1, X))}{p(X)} - \frac{(1-Z)(Y - \mu(0, X))}{1 - p(X)}\)
\(\phi_{Z \to A}(\mathbf{X}; m, p) \triangleq m(1, X) - m(0, X) + \frac{Z(A - m(1, X))}{p(X)} - \frac{(1-Z)(A - m(0, X))}{1 - p(X)}\)
\(\phi(\mathbf{X}; \mu, m, p, \tau) \triangleq \phi_{Z \to Y}(\mathbf{X}; \mu, p) - \phi_{Z \to A}(\mathbf{X}; m, p) \times \tau\)

然后，估计量通过两阶段程序定义：

- 为 \(\mu, m, p\) 中的每一个拟合模型 \(\hat{\mu}, \hat{m}, \hat{p}\)（使用监督机器学习）。
- 将 \(\hat{\tau}^{\text{LATE}}\) 定义为 \(\frac{1}{n} \sum_i \phi(\mathbf{X}_i; \hat{\mu}, \hat{m}, \hat{p}, \hat{\tau}^{\text{LATE}}) = 0\) 的解。即，

\(\hat{\tau}^{\text{LATE}} = \frac{\frac{1}{n} \sum_i \phi_{Z \to Y}(\mathbf{X}_i; \hat{\mu}, \hat{p})}{\frac{1}{n} \sum_i \phi_{Z \to A}(\mathbf{X}_i; \hat{m}, \hat{p})}\)

有助于直观理解的是，LATE 的双重机器学习估计量实际上是 \(Z\) 对 \(Y\) 的平均处理效应的双重机器学习估计量除以 \(Z\) 对 \(A\) 的平均处理效应的双重机器学习估计量。

与第 36.4 节类似，烦扰函数可以通过以下方式估计：

- 拟合一个模型 \(\hat{\mu}\)，通过最小化均方误差来从 \(Z, X\) 预测 \(Y\)。
- 拟合一个模型 \(\hat{m}\)，通过最小化平均交叉熵来从 \(Z, X\) 预测 \(A\)。
- 拟合一个模型 \(\hat{p}\)，通过最小化平均交叉熵来从 \(X\) 预测 \(Z\)。
