反事实推理比干预推理需要更严格的假设（例如，参见 [DM22]）。的确，朱迪亚·珠儿提出了他所谓的 **因果层次结构** [Pea09b; PGJ16; PM18b]，它包含三个分析层次，每一层比上一层更强大，但也做出了更强的假设。摘要见表 4.6。

在反事实推理中，我们希望回答如下类型的问题：$p(Y^{a'}|\text{do}(a), y)$，其读作：“结果 $Y$ 的概率分布是什么，*如果我本应执行* $a'$，给定我已经执行了 $a$ 并观察到结果 $y$”。（我们还可以基于任何其他观察到的证据进行条件设定，例如协变量 \(\boldsymbol{x}\)。）该量 $Y^{a'}$ 通常称为 **潜在结果** [Rub74]，因为它是在假设世界中你执行了 $a'$ 而非 $a$ 时会出现的结果。（注意，$p(Y^{a'} = y)$ 等价于 $p(Y = y|\text{do}(a'))$，属于干预预测，而非反事实预测。）

潜在结果框架背后的假设可以使用结构因果模型清晰地表达。我们在图 4.55 中以只有两个可能动作的简单情况为例进行了说明。我们看到有一组“**单元**”（如单个患者），由下标索引。每个单元都与一个隐藏的外源随机噪声源 $U_i$ 关联，它捕获了该单元的所有独特之处。该噪声被确定性地映射到两个潜在结果，\(Y_i^0\) 和 \(Y_i^1\)，具体取决于采取哪个动作。对于任何给定单元，我们只能观察其中一个结果，即对应于实际所选动作的那个结果。在图 4.55 中，单元 1 选择动作 \(A_1 = 0\)，因此我们可以看到 \(Y_1^0 = y_1\)，而单元 2 选择动作 \(A_2 = 1\)，因此我们可以看到 \(Y_2^1 = y_2\)。对于同一单元无法同时观察到两个结果的事实称为“因果推断的基本问题” [Hol86]。

我们将假设噪声源相互独立，这称为“稳定单元处理价值假设”或 **SUTVA**。（如果对人 \(j\) 的治疗可能以某种方式影响人 \(i\) 的结果，例如由于 \(i\) 和 \(j\) 之间疾病或信息的传播，则这不成立。）我们还假设将噪声映射到结果的确定性机制在所有单元中均相同（由图 4.55 中的共享参数向量 \(\theta\) 表示）。我们还需要做最后一个假设，即外源噪声不受我们行为的影响。（这是对“其他条件不变”假设（或法律术语中的“ceteris paribus”）的形式化。）

基于上述假设，我们可以预测在选择另一个动作的替代宇宙中，**单个单元**的结果会是什么。步骤如下。首先，我们使用 SCM \(G\) 进行**归溯**，以推断 \(p(U_i|A_i = a, Y_i = y_i)\)，即在实际世界中给定观察证据的情况下，单元 \(i\) 的隐性因素的后验分布。其次，我们执行**干预**，即通过将 \(A_i = a\) 替换为 \(A_i = a'\) 来修改 \(G\) 的因果机制，从而得到 \(G_{a'}\)。第三，我们执行**预测**，即将隐性因素的分布 \(p(U_i|A_i = a, Y_i = y_i)\) 通过修改后的 SCM \(G_{a'}\) 传播，以得到 \(p(Y_i^{a'}|A_i = a, Y_i = y_i)\)。

在图 4.55 中，我们看到每个可能结果变量都有两个副本，以表示所有可能世界的集合。当然，我们只能根据实际采取的动作看到其中一个世界。更一般地，如果我们“克隆”所有确定性变量，并且对于同一单元，图中两个分支之间的噪声保持不变，则该模型称为 **孪生网络** [Pea09b]。我们将在 29.12.6 节中看到一个更实际的示例，该节讨论评估时间序列中干预的反事实因果影响。（另参见 [RR11; RR13]，它们提出了一种相关形式主义，称为 **单世界干预图** 或 **SWIG**。）

从上述内容可以看出，潜在结果框架在数学上与结构因果模型等价，但不使用图形模型表示法。这导致两个学派创始人之间进行了激烈的辩论$^{16}$。SCM 方法在计算机科学中更流行（例如，参见 [PJS17; Sch19; Sch+21b]），而 PO 方法在经济学中更流行（例如，参见 [AP09; Imb19]）。现代因果教材通常同时使用这两种形式主义（例如，参见 [HR20a; Nea20]）。

16. 潜在结果框架基于唐纳德·鲁宾等人的工作，因此有时也称为 **Rubin 因果模型**（例如，参见 https://en.wikipedia.org/wiki/Rubin_causal_model）。结构因果模型框架基于朱迪亚·珠儿等人的工作。另参见 http://causality.cs.ucla.edu/blog/index.php/2012/12/03/judea-pearl-on-potential-outcomes/ 以了解两者的讨论。

## 5 信息论

机器学习本质上是关于 **信息处理** 的。但什么是信息，我们如何衡量它？归根结底，我们需要一种方法来量化从一组信念到另一组信念的更新幅度。事实证明，在一份相对简短的期望属性列表中，有一个唯一的答案：Kullback-Leibler (KL) 散度（参见 5.1 节）。我们将研究 KL 散度的性质及两个特例：熵（5.2 节）和互信息（5.3 节），它们足够有用，值得独立研究。接着，我们将简要讨论信息论的两个主要应用。第一个应用是 **数据压缩** 或 **源编码**，即从数据中去除冗余，使其能以更紧凑的形式表示，无论是无损方式（例如 ZIP 文件）还是有损方式（例如 MP3 文件）。详情见 5.4 节。第二个应用是 **纠错** 或 **信道编码**，即以一种方式对数据进行编码，使其在通过嘈杂信道（如电话线或卫星链路）发送时能容错。详情见 5.5 节。

事实证明，数据压缩和纠错方法都依赖于对数据拥有一个准确的概率模型。对于压缩，发送方需要概率模型，以便为出现频率最高的数据向量分配更短的 **码字**，从而节省空间。对于纠错，接收方需要概率模型，以便将接收到的带噪声消息与可能消息的先验相结合，从而推断出最可能的源消息。

显然，概率机器学习对信息论有用。然而，信息论对机器学习也有用。的确，我们已经看到，贝叶斯机器学习关乎表示和减少我们的不确定性，因此本质上关乎信息。在 5.6.2 节中，我们将更详细地探讨这一方向，讨论信息瓶颈。

有关信息论的更多信息，参见例如 [Mac03; CT06]。

### 5.1 KL 散度

*本节由 Alex Alemi 撰写。*

要讨论信息论，我们需要一种方法来测量或量化信息本身。假设我们从描述关于随机变量信念程度的某个分布开始，记为 \(q(x)\)。我们随后希望将信念程度更新为某个新分布 \(p(x)\)，也许是因为我们进行了一些新测量，或者仅仅是多思考了一会儿问题。我们所寻求的是一种数学方法，用于量化此次更新的幅度，我们将其记为 \(I[p\|q]\)。对于这样的度量，什么样的标准是合理的？我们将在下面讨论这个问题，然后定义一个满足这些标准的量。
