
估计器:

\(\hat{\tau}^{\text{IPTW}} \triangleq \frac{1}{n} \sum_i \frac{Y_i A_i}{\hat{g}(X_i)} - \frac{Y_i(1-A_i)}{1-\hat{g}(X_i)}.\) (36.28)

这里，\(\hat{g}\) 是倾向得分函数的估计。回顾第 14.2.1 节，如果模型设定正确且损失函数是适当评分规则，则风险最小化器 \(g^* = \text{argmin}_g \mathbb{E}[L(A, g(X))]\) 将为 \(g^*(X) = \text{P}(A=1|X)\)。也就是说，我们可以通过拟合从 \(X\) 预测 \(A\) 的模型来估计倾向得分。交叉熵和平方损失都是适当评分规则，因此我们可以使用标准的监督学习方法。

总的来说，步骤是估计倾向得分函数（使用机器学习），然后将估计的倾向得分 \(\hat{g}(x_i)\) 代入公式 (36.28)。IPTW 估计器计算处理组和未处理组之间加权平均值的差异。其效果是提高那些不太可能接受治疗但却实际上偶然接受了治疗的单位的结局权重（未处理组的情况亦然）。直觉上，此类单位对于未处理人群来说是典型的。因此，它们在接受治疗下的结局对于了解如果典型的未处理单位接受了治疗会发生什么具有参考价值。

有必要发出一句警告。虽然 IPTW 在渐近意义上有效且在实践中很流行，但对于有限样本可能非常不稳定。如果对于某些 \(x\) 值，估计的倾向得分是极端的（即非常接近 0 或 1），那么相应的 IPTW 权重可能非常大，导致高方差估计器。在某些情况下，可以通过使用 Hajek 版本的估计器来缓解这种不稳定性。

\(\hat{\tau}^{\text{h-IPTW}} \triangleq \sum_i Y_i A_i \frac{1/\hat{g}(X_i)}{\sum_i A_i /\hat{g}(X_i)} - \sum_i Y_i(1-A_i) \frac{1/(1-\hat{g}(X_i))}{\sum_i (1-A_i)/(1-\hat{g}(X_i))}.\) (36.29)

但是，即使在自归一化后，极端权重仍可能持续存在，要么是因为 \(X\) 的某些层中治疗分配高度不平衡，要么是因为倾向得分估计方法过拟合。在这种情况下，通常会应用诸如权重裁剪之类的启发式方法。关于反倾向得分类估计器的更长讨论（包括一些实际改进），请参见 Khan and Ugander [KU21]。

## 36.4.2.3 双机器学习

我们已经看到，如何通过协变量与结局之间的关系，或者协变量与治疗之间的关系来估计平均处理效应。在每种情况下，我们都遵循两步估计程序。首先，我们拟合预期结局或倾向得分的模型。其次，我们将这些拟合模型代入效应的下游估计器。毫不奇怪，\(\tau\) 估计值的质量取决于 \(\hat{Q}\) 或 \(\hat{g}\) 估计值的质量。这有问题，因为 \(Q\) 和 \(g\) 可能是需要大量样本才能估计的复杂函数。尽管我们只对一维参数 \(\tau\) 感兴趣，但迄今描述的天真估计器可能具有非常慢的收敛速度。这会导致不可靠的推断或非常大的置信区间。值得庆幸的是，存在将 \(Q\) 和 \(g\) 结合在估计器中的策略，从原则上讲，这些策略比单独使用 \(Q\) 或 \(g\) 表现更好。增强反概率加权治疗估计器（AIPTW）就是这样的一种估计器。它定义为

\(\hat{\tau}^{\text{AIPTW}} \triangleq \frac{1}{n} \sum_i \hat{Q}(1, X_i) - \hat{Q}(0, X_i) + A_i \frac{Y_i - \hat{Q}(1, X_i)}{\hat{g}(x_i)} - (1 - A_i) \frac{Y_i - \hat{Q}(0, X_i)}{1 - \hat{g}(X_i)}.\) (36.30)

也就是说，\(\hat{\tau}^{\text{AIPTW}}\) 是结果调整估计器加上一个依赖于倾向得分的稳定项。这个估计器是更广泛的一类估计器的特例，这一类估计器被称为 **semi-parametrically efficient** 或 **double machine-learning** 估计器 [Che+17e; Che+17d]。我们在此使用后一种术语。

我们现在转向理解双机器学习估计器在哪种意义上对 **nuisance functions** \(Q\) 和 \(g\) 的误估计具有鲁棒性。为此，我们定义 \(\tau\) 的 **influence curve** 为由\(^6\) 定义的函数 \(\phi\)

\(\phi(X_i, A_i, Y_i; Q, g, \tau) \triangleq Q(1, X_i) - Q(0, X_i) + A_i \frac{Y_i - Q(1, X_i)}{g(x_i)} - (1 - A_i) \frac{Y_i - Q(0, X_i)}{1 - g(X_i)} - \tau.\) (36.31)

根据设计，\(\hat{\tau}^{\text{AIPTW}} - \tau = \frac{1}{n} \sum_i \phi(\mathbf{X}_i; \hat{Q}, \hat{g}, \tau)\)。我们首先考虑如果我们直接知道 \(Q\) 和 \(g\)，而不必估计它们会发生什么。在这种情况下，估计器将是 \(\hat{\tau}^{\text{ideal}} = \frac{1}{n} \sum_i \phi(\mathbf{X}_i; Q, g, \tau)\)，并且根据中心极限定理，我们将有：

\(\sqrt{n}(\hat{\tau}^{\text{ideal}} - \tau) \xrightarrow{d} \text{Normal}(0, \mathbb{E}[\phi(\mathbf{X}_i; Q, g, \tau)^2]).\) (36.32)

此结果刻画了最佳可能情况下的估计不确定性。如果我们知道 \(Q\) 和 \(g\)，我们可以依赖此结果，例如，为我们的估计值找到置信区间。

问题是：当 \(Q\) 和 \(g\) 需要被估计时会发生什么？对于一般的估计器和烦扰函数模型，我们不期望公式 (36.32) 的 \(\sqrt{n}\) 速率成立。例如，\(\sqrt{n}(\hat{\tau}^Q - \tau)\) 只有在 \(\sqrt{n}\mathbb{E}[(\hat{Q} - Q)^2]^{\frac{1}{2}} \to 0\) 时才收敛。也就是说，对于天真估计器，只有当我们也能以 \(\sqrt{n}\) 速率估计 \(Q\) 时，我们才能获得估计 \(\tau\) 的 \(\sqrt{n}\) 速率——这是一个更难的任务！这就是双机器学习估计器帮助解决的问题。

为了理解如何做到这一点，我们将估计 \(\tau\) 的误差分解如下：

\(\sqrt{n}(\hat{\tau}^{\text{AIPTW}} - \tau)\) (36.33)
\(= \frac{1}{\sqrt{n}} \sum_i \phi(\mathbf{X}_i; Q, g, \tau)\) (36.34)
\(+ \frac{1}{\sqrt{n}} \sum_i \phi(\mathbf{X}_i; \hat{Q}, \hat{g}, \tau) - \phi(\mathbf{X}_i; Q, g, \tau) - \mathbb{E}[\phi(\mathbf{X}_i; \hat{Q}, \hat{g}, \tau) - \phi(\mathbf{X}_i; Q, g, \tau)]\) (36.35)
\(+ \sqrt{n}\mathbb{E}[\phi(\mathbf{X}_i; \hat{Q}, \hat{g}, \tau) - \phi(\mathbf{X}_i; Q, g, \tau)]\) (36.36)

我们将第一项，即公式 (36.34)，识别为 \(\sqrt{n}(\hat{\tau}^{\text{ideal}} - \tau)\)，即在知道 \(Q\) 和 \(g\) 的最佳情况下的估计误差。理想情况下，我们希望 \(\hat{\tau}^{\text{AIPTW}}\) 的误差与这种理想情况渐近相等——如果其他两项趋于 0，就会发生这种情况。

6. 影响曲线是后续内容的基础，也是将分析推广到平均处理效应（ATE）之外的关键。遗憾的是，深入一般数学将需要大幅离题，因此我们省略了。然而，请参见章节末尾的参考文献，以获取相关文献的指引。

第二项，即公式 (36.35)，是我们为使用相同数据来估计 \( Q, g \) 并计算 \(\tau\) 所支付的罚项。对于许多模型类，可以证明此类“经验过程”项趋于 0。通过为拟合烦扰函数和计算估计器使用不同数据，也可以一般性地保证这一点（参见下一节）。第三项，即公式 (36.36)，刻画了我们为烦扰函数误估计所支付的罚项。AIPTW 的特殊形式是关键所在。经过一些代数运算，我们可以证明

\(\mathbb{E}[\phi(\mathbf{X}; \hat{Q}, \hat{g}) - \phi(\mathbf{X}; Q, g)] = \mathbb{E}[\frac{1}{g(X)}(\hat{g}(X) - g(X))(\hat{Q}(1, X) - Q(1, X))\) (36.37)
\(+ \frac{1}{1 - g(X)}(\hat{g}(X) - g(X))(\hat{Q}(0, X) - Q(0, X))].\) (36.38)

重要的是，\(Q\) 和 \(g\) 的估计误差是相乘的。利用柯西-施瓦茨不等式，我们发现只要 \(\sqrt{n} \max_a \mathbb{E}[(\hat{Q}(a, X) - Q(a, X))^2]^{\frac{1}{2}} \mathbb{E}[(\hat{g}(X) - g(X))^2]^{\frac{1}{2}} \to 0\)，则 \(\sqrt{n}\mathbb{E}[\phi(\mathbf{X}; \hat{Q}, \hat{g}) - \phi(\mathbf{X}; Q, g)] \to 0\)。也就是说，只要误估计误差的 *product* 是 \( o(\sqrt{n})\)，误估计罚项就会消失。例如，这意味着即使 \(Q\) 和 \(g\) 各自的估计误差仅以 \( o(n^{-1/4}) \) 递减，\(\tau\) 也可以以（最优的）\(\sqrt{n}\) 速率进行估计。这里的要点是，双机器学习估计器具有特殊性质，即弱条件 \(\sqrt{n}\mathbb{E}(\hat{Q}(T, X) - Q(T, X))^2\mathbb{E}(\hat{g}(X) - g(X))^2 \to 0\) 足以暗示

\(\sqrt{n}(\hat{\tau}^{\text{AIPTW}} - \tau) \xrightarrow{d} \text{Normal}(0, \mathbb{E}[\phi(\mathbf{X}_i; Q, g, \tau)^2])\) (36.39)

（尽管严格来说，这还需要一些我们未讨论的额外技术条件）。这对我们之前讨论的早期估计器 *not* 成立，那些估计器要求烦扰函数估计具有更快的收敛速度。

AIPTW 估计器还有两个值得提及的良好特性。首先，它是 **non-parametrically efficient**。这意味着该估计器的方差是不做参数假设的任何估计器中最小的，即 \(\mathbb{E}[\phi(\mathbf{X}_i; Q, g, \tau)^2]\)。例如，这意味着该估计器产生任何不依赖参数假设的方法中最小的置信区间。其次，它是 **doubly robust**：只要 \(\hat{Q}\) 或 \(\hat{g}\) 至少有一个是一致的，该估计器就是一致的（随着 \( n \to \infty \) 收敛到真实的 \( \tau \)）。

## 36.4.2.4 交叉拟合

上述误差分解中的公式 (36.35) 项是为重复使用相同数据以同时拟合 \( Q, g \) 并计算估计器所支付的罚项。对于 \( Q, g \) 的许多模型选择，当 \( n \) 变大时，该项会迅速趋于 0，我们可以实现（最佳情况）\(\sqrt{n}\) 误差速率。但是，这一性质并不总是成立。

作为替代方案，我们总是可以随机分割可用数据，用一部分进行模型拟合，另一部分来计算估计器。实际上，这意味着烦扰函数估计和估计器计算是使用独立样本完成的。然后可以证明，重用罚项会消失。但是，这以减少每个烦扰函数估计和估计器计算可用数据量为代价。

该策略可以通过 **cross fitting** 方法加以改进。我们将数据分为 \( K \) 份。对于每个折 \( j \)，我们使用其余 \( K - 1 \) 份来拟合烦扰函数模型 \(\hat{Q}^{-j}, \hat{g}^{-j}\)。
