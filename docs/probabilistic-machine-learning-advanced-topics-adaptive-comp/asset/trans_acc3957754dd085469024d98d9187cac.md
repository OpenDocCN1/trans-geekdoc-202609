

我们访问空间中每个点的时间与后验概率成正比。关键在于，要决定是移动到新提出的点 \(\theta'\) 还是停留在当前点 \(\theta\)，我们只需评估未归一化的密度比

\(\frac{p(\theta|\mathcal{D})}{p(\theta'|\mathcal{D})} = \frac{p(\mathcal{D}|\theta)p(\theta)/p(\mathcal{D})}{p(\mathcal{D}|\theta')p(\theta')/p(\mathcal{D})} = \frac{p(\mathcal{D}, \theta)}{p(\mathcal{D}, \theta')}\) (7.35)

这样就避免了计算归一化常数 \(p(\mathcal{D})\) 的需要。(在实践中，我们通常使用 log 概率，而不是联合概率，以避免数值问题。)

我们可以看到，该算法的输入只是一个计算 log 联合密度 \(\log p(\theta, \mathcal{D})\) 的函数，以及一个用于决定下一步访问哪些状态的提议分布 \(q(\theta'|\theta)\)。通常使用高斯分布作为提议分布，\(q(\theta'|\theta) = \mathcal{N}(\theta'|\theta, \sigma \mathbf{I})\)；这称为随机游走 Metropolis 算法。然而，这可能非常低效，因为它在空间中盲目游走，希望能找到高概率区域。

在具有条件独立性结构的模型中，通常可以很容易地逐个变量计算完全条件分布 \(p(\theta_d|\theta_{-d}, \mathcal{D})\)，然后从中采样。这类似于坐标上升的随机模拟，称为 Gibbs 采样（详情见第 12.3 节）。

对于所有未知变量均为连续变量的模型，我们通常可以计算 log 联合分布的梯度 \(\nabla_\theta \log p(\theta, \mathcal{D})\)。我们可以利用这些梯度信息来引导提议进入高概率的空间区域。这种方法称为哈密顿蒙特卡洛（HMC），由于其速度快，是最广泛使用的 MCMC 算法之一。详情见第 12.5 节。

我们在图 7.5 中将 HMC 应用于我们的 beta-Bernoulli 模型。（我们对参数使用 logit 变换。）在面板 b 中，我们展示了算法从 4 条并行马尔可夫链生成的样本。我们可以看到，它们按预期在真实后验周围振荡。在面板 a 中，我们从每条链的后验样本计算核密度估计；我们可以看到，结果与图 7.3 中的真实后验非常吻合。

### 7.4.6 序列蒙特卡洛

MCMC 类似于随机局部搜索算法，因为它在后验分布的状态空间中移动，将当前值与提议的邻近值进行比较。另一种方法是使用一系列不同的分布（从简单到复杂）进行推断，最终分布等于目标后验。这称为序列蒙特卡洛（SMC）。这种方法更类似于树搜索而非局部搜索，相对于 MCMC 具有多种优势，我们将在第 13 章讨论。

SMC 的一个常见应用是序列贝叶斯推断，即我们递归地（也就是以在线方式）计算后验 \(p(\theta_t|\mathcal{D}_{1:t})\)，其中 \(\mathcal{D}_{1:t} = \{(x_n, y_n) : n = 1 : t\}\) 是迄今为止看到的所有数据。这一分布序列会在看到所有数据后收敛到完整的批量后验 \(p(\theta|\mathcal{D})\)。然而，当数据以持续不断的流形式到达时（如状态空间模型中，见第 29 章），该方法也可应用。将 SMC 应用于此类动态模型称为粒子滤波。详情见第 13.2 节。

## 7.5 评估近似推断算法

存在许多不同的近似推断算法，每种算法在速度、准确性、通用性、简单性等方面做出不同的权衡。这使得很难在同等条件下进行比较。

一种方法是通过与使用“精确”方法离线计算的“真实”后验 \(p(\theta|\mathcal{D})\) 进行比较，来评估近似 \(q(\theta)\) 的准确性。我们通常关注准确性与速度的权衡，可以通过评估 \(D_\text{KL}(p(\theta|\mathcal{D}) \| q_t(\theta))\) 来计算，其中 \(q_t(\theta)\) 是 \(t\) 单位计算时间后的近似后验。当然，我们也可以使用其他分布相似性度量，例如 Wasserstein 距离。

不幸的是，通常无法计算真实后验 \(p(\theta|\mathcal{D})\)。一个简单的替代方法是根据其在未见观测数据上的预测能力来评估质量，类似于交叉验证。更一般地，我们可以比较不同后验的预期损失或贝叶斯风险（第 34.1.3 节），如 [KPS98; KPS99] 所提：

\(R = \mathbb{E}_{p^*(x,y)} [\ell(y, q(y|x, \mathcal{D}))] \text{ where } q(y|x, \mathcal{D}) = \int p(y|x, \theta)q(\theta|\mathcal{D})d\theta\) (7.36)

其中 \(\ell(y, q(y))\) 是某种损失函数，例如 log-损失。或者，我们可以衡量后验在某些下游任务（如持续学习或主动学习）中的性能，如 [Far22] 所提。

有关评估变分推断的专门方法，请参见 [Yao+18b; Hug+20]，有关 Monte Carlo 方法，请参见 [CGR06; CTM17; GAR16]。

## 8 高斯滤波与平滑

### 8.1 简介

在本章中，我们考虑 **状态空间模型**（SSM）中的后验推断任务。我们将在第 29 章更详细地讨论 SSM，但可以将它们视为链式结构图形模型（图 8.1）所示条件独立性的隐变量序列模型。相应的联合分布形式为

\(p(y_{1:T}, z_{1:T}|u_{1:T}) = \left[ p(z_1|u_1) \prod_{t=2}^T p(z_t|z_{t-1}, u_t) \right] \left[ \prod_{t=1}^T p(y_t|z_t, u_t) \right]\) (8.1)

其中 \(z_t\) 是时刻 \(t\) 的隐变量，\(y_t\) 是观测值（输出），\(u_t\) 是可选输入。项 \(p(z_t|z_{t-1}, u_t)\) 称为 **动态模型** 或 **转换模型**，\(p(y_t|z_t, u_t)\) 称为 **观测模型** 或 **测量模型**，\(p(z_1|u_1)\) 是先验或初始状态分布。1

#### 8.1.1 推断目标

给定观测序列和已知模型，SSM 的主要任务之一是对隐藏状态进行后验推断；这也称为 **状态估计**。

例如，考虑一架在天空中飞行的飞机。（为简化起见，我们假设世界是 2d 而非 3d。）我们希望根据其位置的噪声传感器测量值 \(y_t \in \mathbb{R}^2\) 来估计其位置和速度 \(z_t \in \mathbb{R}^4\)，如图 8.2(a) 所示。（为简化起见，我们忽略输入 \(u_t\)。）
