

## 10.3.6.1 变分后验

我们将使用后验的标准平均场近似：$q(\theta, z_{1:N}) = q(\theta) \prod_n q_n(z_n)$。在此阶段，我们尚未指定 $q$ 函数的形式；这些形式将由似然函数和先验的形式确定。下面我们将展示最优形式如下：

$q_n(z_n) = \text{Cat}(z_n|r_n)$

$q(\theta) = \text{Dir}(\pi | \widehat{\alpha}) \prod_k \mathcal{N}(\mu_k | \widehat{m}_k, (\widehat{\kappa}_k \Lambda_k)^{-1})\text{W}(\Lambda_k | \widehat{L}_k, \widehat{\nu}_k)$

其中 $r_n$ 是后验责任度，带有帽子的参数是先验中用数据更新后的超参数。

## 10.3.6.2 $q(\theta)$ 的推导（变分 M 步）

使用算法 10.4 中的平均场方法，我们写下联合对数，并对除 $\theta$ 以外的所有变量取期望，因此我们对 $z_n$ 关于 $q(z_n) = \text{Cat}(z_n|r_n)$ 进行平均：

\(\log q(\theta) = \log p(\pi) + \sum_n \mathbb{E}_{q(z_n)} [\log p(z_n|\pi)]\)

\(+ \sum_k \left[ \log p(\mu_k, \Lambda_k) \sum_n \mathbb{E}_{q(z_n)} [z_{nk} \log \mathcal{N}(x_n|\mu_k, \Lambda_k^{-1})] \right] + \text{const}\)

由于期望联合对数分解为涉及 $\pi$ 的项和涉及 $(\mu_k, \Lambda_k)$ 的项，我们看到变分后验也分解为形式

$q(\theta) = q(\pi) \prod_k q(\mu_k, \Lambda_k)$

对于 $\pi$ 项，我们有

\(\log q(\pi) = (\alpha_0 - 1) \sum_k \log \pi_k + \sum_k \sum_n r_{nk} \log \pi_k + \text{const}\)

指数化后，我们识别出这是一个狄利克雷分布：

$q(\pi) = \text{Dir}(\pi | \widehat{\alpha})$

\(\widehat{\alpha}_k = \alpha_0 + N_k\)

\(N_k = \sum_n r_{nk}\)

对于 \(\boldsymbol{\mu}_k\) 和 \(\mathbf{\Lambda}_k\) 项，我们有

\(q(\boldsymbol{\mu}_k, \mathbf{\Lambda}_k) = \mathcal{N}(\boldsymbol{\mu}_k \mid \tilde{\mathbf{m}}_k, (\tilde{\kappa}_k \mathbf{\Lambda}_k)^{-1}) \text{Wishart}(\mathbf{\Lambda}_k \mid \widehat{\mathbf{L}}_k, \hat{\nu}_k)\)

\(\tilde{\kappa}_k = \tilde{\kappa} + N_k\)

\(\tilde{\mathbf{m}}_k = (\tilde{\kappa} \tilde{\mathbf{m}} + N_k \overline{\mathbf{x}}_k) / \tilde{\kappa}_k\)

\(\widehat{\mathbf{L}}_k^{-1} = \hat{\mathbf{L}}^{-1} + N_k \mathbf{S}_k + \frac{\tilde{\kappa} N_k}{\tilde{\kappa} + N_k} (\overline{\mathbf{x}}_k - \tilde{\mathbf{m}}) (\overline{\mathbf{x}}_k - \tilde{\mathbf{m}})^\top\)

\(\hat{\nu}_k = \hat{\nu} + N_k\)

\(\overline{\mathbf{x}}_k = \frac{1}{N_k} \sum_n r_{nk} \mathbf{x}_n\)

\(\mathbf{S}_k = \frac{1}{N_k} \sum_n r_{nk} (\mathbf{x}_n - \overline{\mathbf{x}}_k) (\mathbf{x}_n - \overline{\mathbf{x}}_k)^\top\)

这与 GMM MAP 估计的 M 步非常相似，只不过这里我们计算的是 \(\boldsymbol{\theta}\) 的后验参数，而不是点估计 \(\hat{\boldsymbol{\theta}}\)。

## 10.3.6.3 \(q(\mathbf{z})\) 的推导（变分 E 步）

变分 E 步更有趣，因为它与常规 EM 中的 E 步有很大不同，因为我们需要对参数进行平均，而不是条件于它们。特别是，我们有

\(\log q(\mathbf{z}) = \sum_n \sum_k z_{nk} \left( \mathbb{E}_{q(\boldsymbol{\pi})} [\log \pi_k] + \frac{1}{2} \mathbb{E}_{q(\mathbf{\Lambda}_k)} [\log |\mathbf{\Lambda}_k|] - \frac{D}{2} \log(2\pi) \right.\)

\(\left. - \frac{1}{2} \mathbb{E}_{q(\boldsymbol{\theta})} [(\mathbf{x}_n - \boldsymbol{\mu}_k)^\top \mathbf{\Lambda}_k (\mathbf{x}_n - \boldsymbol{\mu}_k)] \right) + \text{const}\)

利用 \(q(\boldsymbol{\pi}) = \text{Dir}(\boldsymbol{\pi} \mid \widehat{\boldsymbol{\alpha}})\) 的事实，可以证明

\(\exp(\mathbb{E}_{q(\boldsymbol{\pi})} [\log \pi_k]) = \frac{\exp(\psi(\hat{\alpha}_k))}{\exp(\psi(\sum_{k'} \hat{\alpha}_{k'}))} \triangleq \tilde{\pi}_k\)

其中 \(\psi\) 是双伽玛函数：

\(\psi(x) = \frac{d}{dx} \log \Gamma(x)\)

这处理了第一项。对于第二项，可以证明

\(\mathbb{E}_{q(\mathbf{\Lambda}_k)} [\log |\mathbf{\Lambda}_k|] = \sum_{j=1}^D \psi \left( \frac{\hat{\nu}_k + 1 - j}{2} \right) + D \log 2 + \log |\widehat{\mathbf{L}}_k|\)

最后，对于二次型的期望值，可以证明

\(\mathbb{E}_{q(\boldsymbol{\mu}_k, \mathbf{\Lambda}_k)} [(\mathbf{x}_n - \boldsymbol{\mu}_k)^\top \mathbf{\Lambda}_k (\mathbf{x}_n - \boldsymbol{\mu}_k)] = D \hat{\kappa}_k^{-1} + \hat{\nu}_k (\mathbf{x}_n - \widehat{\mathbf{m}}_k)^\top \widehat{\mathbf{L}}_k (\mathbf{x}_n - \widehat{\mathbf{m}}_k) \triangleq \tilde{\Lambda}_k\)

![](img/ca72c1626f4850f058a9edc138c1ac73_492_0.png)

图 10.11：(a) 我们绘制 exp(ψ(x)) 与 x 的关系。我们看到该函数执行一种收缩形式，因此小值会被设为零。(b) 我们对 4 个不同状态（z 值）绘制 Nk 随时间变化的图，起始于随机初始值。我们执行一系列 VBEM 更新，忽略似然项。我们看到最初计数较高的状态会得到加强，而人口稀少的状态会被淘汰。来自 [LK07]。经 Percy Liang 友好许可使用。

因此，我们得到数据点 n 属于簇 k 的后验责任度为

```
r_{nk} \propto \tilde{\pi}_k \tilde{\Lambda}_k^{\frac{1}{2}} \exp \left( - \frac{D}{2 \tilde{\kappa}_k} - \frac{\hat{\nu}_k}{2} (x_n - \tilde{m}_k)^\top \tilde{\Lambda}_k (x_n - \tilde{m}_k) \right) (10.151)
```

将其与常规 EM 中使用的表达式进行比较：

```
r_{nk}^{EM} \propto \hat{\pi}_k |\hat{\Lambda}_k|^{\frac{1}{2}} \exp \left( - \frac{1}{2} (x_n - \hat{\mu}_k)^\top \hat{\Lambda}_k (x_n - \hat{\mu}_k) \right) (10.152)
```

其中 \(\tilde{\pi}_k\) 是 \(\pi_k\) 的 MAP 估计。这一差异的意义在第 10.3.6.4 节中讨论。

## 10.3.6.4 VBEM 自动稀疏诱导效应

在常规 EM 中，E 步的形式如方程 (10.152) 所示，而在 VBEM 中，E 步的形式如方程 (10.151) 所示。虽然它们看起来相似，但存在一个重要的差异。为了理解这一点，让我们忽略似然项，只关注先验。由方程 (10.147) 可得

```
r_{nk}^{VB} = \tilde{\pi}_k = \frac{\exp(\psi(\tilde{\alpha}_k))}{\exp(\psi(\sum_{k'} \tilde{\alpha}_{k'}))} (10.153)
```

并且，根据 GMM 混合权重的常规 EM MAP 估计方程（例如，参见 [Mur22, Sec 8.7.3.4]），我们有

```
r_{nk}^{EM} = \hat{\pi}_k = \frac{\tilde{\alpha}_k - 1}{\sum_{k'} (\tilde{\alpha}_{k'} - 1)} (10.154)
```

其中 \(\tilde{\alpha}_k = \alpha_0 + N_k\)，且 \(N_k = \sum_n r_{nk}\) 是分配给簇 k 的预期数据点数。

我们从图 2.6 中知道，使用 $\alpha_0 \ll 1$ 会导致 $\boldsymbol{\pi}$ 稀疏，这将鼓励 $\boldsymbol{r}_n$ 稀疏，并“淘汰”不必要的混合分量（即 $N_k \ll N$ 的分量，意味着很少数据点被分配给簇 k）。为了鼓励这种稀疏诱导效应，让我们设置 $\alpha_0 = 0$。在这种情况下，混合权重的更新参数由以下给出：

```
$$\tilde{\pi}_k = \frac{\exp(\psi(N_k))}{\exp(\psi(\sum_{k'} N_{k'}))}$$ (10.155)
```

```
$$\hat{\pi}_k = \frac{N_k - 1}{\sum_{k'}(N_{k'} - 1)}$$ (10.156)
```

现在考虑一个没有分配数据的簇，因此 $N_k = 0$。在常规 EM 中，$\hat{\pi}_k$ 可能最终为负值，如 [FJ02] 所指出。（如果我们使用最大似然训练，这不会发生，这对应于 $\alpha_0 = 1$，但这也不会诱导任何稀疏。）此问题在 VBEM 中不会出现，因为我们使用双伽玛函数，它总是为正，如图 10.11(a) 所示。

更有趣的是，让我们考虑这些更新对具有不相等但非零分配数量的簇的影响。假设我们从 4 个簇随机分配计数开始，为了简化，忽略来自似然的贡献而迭代 VBEM 算法。图 10.11(b) 显示计数 $N_k$ 随时间如何演变。我们注意到最初计数较小的簇最终计数为零，而最初计数较大的簇最终计数更大。换句话说，最初受欢迎的簇会获得越来越多的成员。这被称为 **富者更富** 现象；当我们讨论狄利克雷过程混合模型时，我们将在第 31.2 补充节中再次遇到它。

这种效应的原因如图 10.11(a) 所示：我们看到 $\exp(\psi(N_k)) < N_k$，并且如果 $N_k$ 足够小，则为零，类似于 $\ell_1$-正则化诱导的软阈值行为（参见第 15.2.6 节）。重要的是，减少 $N_k$ 的效应对计数较小的簇影响更大。

我们现在在一个真实例子中演示这种自动剪枝方法。我们对 Old Faithful 数据集拟合一个 6 个高斯分布的混合模型，使用 $\alpha_0 = 0.001$。由于数据实际上只“需要” 2 个簇，其余 4 个被“淘汰”，如图 10.12 所示。在图 10.13 中，我们绘制了 $\alpha_k$ 的初始值和最终值；我们看到除了两个分量 k 之外，所有分量的 $\bar{\alpha}_k = 0$。

因此，我们看到带有稀疏狄利克雷先验的 GMM VBEM 提供了一种有效的方法来选择簇的数量。类似技术可用于选择 HMM 和其他隐变量模型中的状态数量。然而，这种 **变分剪枝效应**（也称为 **后验坍缩**）并不总是可取的，因为如果似然函数 $p(\boldsymbol{x}|\boldsymbol{z})$ 足够强大，它可能导致模型“忽略”隐变量 $\boldsymbol{z}$。我们将在第 21.4 节中更详细地讨论这一点。

## 10.3.6.5 边缘似然的下界

VBEM 算法正在最大化以下下界

```
$$\mathcal{L} = \sum_{\boldsymbol{z}} \int d\boldsymbol{\theta} q(\boldsymbol{z}, \boldsymbol{\theta}) \log \frac{p(\boldsymbol{x}, \boldsymbol{z}, \boldsymbol{\theta})}{q(\boldsymbol{z}, \boldsymbol{\theta})} \le \log p(\boldsymbol{x})$$ (10.157)
```

该量在每次迭代中单调增加，如图 10.14 所示。
