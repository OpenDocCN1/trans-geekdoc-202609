### 28.5.1.3 后验推断

许多算法已被提出以在 LDA 模型中执行近似后验推断。在原始 LDA 论文 [BNJ03a] 中，他们使用变分均匀场推断（参见第 10.3 节）。在 [HBB10] 中，他们使用随机 VI（参见补充部分 28.1.2）。在 [GS04] 中，他们使用坍塌吉布斯采样，它将离散潜在变量边缘化（参见补充部分 28.1.1）。在 [MB16; SS17b] 中，他们讨论如何学习摊销推理网络以对坍塌模型执行 VI。

最近，对用于拟合类 LDA 模型的光谱方法表现出了相当大的兴趣，这些方法速度快，并对其获得的解的质量提供了可证明的保证（与 MCMC 和变分方法不同，后者的解只是未知质量的近似）。这些方法在基本模型之外做出某些（合理的）假设，例如存在某些锚定词，它们唯一地确定文档的主题。详情见 [Aro+13]。

### 28.5.1.4 确定主题数量

选择 \(N_z\)，即主题数量，是一个标准的模型选择问题。已采用的一些方法如下：

- 使用退火重要性采样（第 11.5.4 节）来近似证据 [Wal+09]。
- 交叉验证，使用测试集上的对数似然。
- 使用变分下界作为 \(\log p(\mathcal{D}|N_z)\) 的代理。
- 使用非参数贝叶斯方法 [Teh+06]。

## 28.5.2 相关主题模型

LDA 的一个弱点是它无法捕捉主题之间的相关性。例如，如果一个文档有“商业”主题，那么合理地预期“金融”主题会共同出现。问题的根源在于为 \(\mathbf{z}_n\) 使用了狄利克雷先验。狄利克雷分布的问题在于它仅由一个均值向量 \(\boldsymbol{\alpha}\) 表征，但其协方差是固定的 (\(\Sigma_{ij} = -\alpha_i \alpha_j\))，而不是自由参数。

绕过这一点的一种方法是将狄利克雷先验替换为 **逻辑正态** 分布，定义如下：

```
$p(\mathbf{z}) = \int \text{Cat}(\mathbf{z}|\text{softmax}(\boldsymbol{\epsilon}))\mathcal{N}(\boldsymbol{\epsilon}|\boldsymbol{\mu},\boldsymbol{\Sigma})d\boldsymbol{\epsilon}$ (28.133)
```

这被称为 **相关主题模型** [BL07b]；

与第 28.3.5.2 节讨论的分类 PCA 的区别在于，CTM 使用逻辑正态分布来模拟均值参数，因此 \(\mathbf{z}_n\) 是稀疏且非负的，而 CatPCA 使用正态分布来模拟自然参数，因此 \(\mathbf{z}_n\) 是稠密的且可以是负的。

更准确地说，CTM 定义 \(x_{nl} \sim \text{Cat}(\mathbf{W}\text{softmax}(\boldsymbol{\epsilon}_n))\)，而 CatPCA 定义 \(x_{nd} \sim \text{Cat}(\text{softmax}(\mathbf{W}_d \mathbf{z}_n))\)。

拟合 CTM 模型很棘手，因为 \(\boldsymbol{\epsilon}_n\) 的先验不再与 \(m_{nl}\) 的多项式似然共轭。然而，我们可以推导出变分均匀场近似，如 [BL07b] 所述。

拟合模型后，可以通过修剪低强度边缘将 \(\hat{\mathbf{\Sigma}}\) 转换为稀疏精度矩阵 \(\hat{\mathbf{\Sigma}}^{-1}\)，从而得到稀疏高斯图形模型。这使您可以可视化主题之间的相关性。图 28.27 显示了将此过程应用于 1990–1999 年 *科学* 杂志文章的结果。

## 28.5.3 动态主题模型

在 LDA 中，主题（词上的分布）被假设是静态的。在某些情况下，允许这些分布随时间平滑演变是有意义的。例如，一篇文章可能使用*神经科学*主题，但如果它写于 1900 年代，则更可能使用*神经*等词汇，而如果它写于 2000 年代，则更可能使用*钙受体*等词汇（这反映了神经科学向分子生物学发展的一般趋势）。

建模这一点的一种方法是假设主题分布按照高斯随机游走演变，如同在状态空间模型中一样（参见第 29.1 节）。我们可以通过 softmax 函数将这些高斯向量映射到概率，从而得到以下模型：

```
$\mathbf{w}_k^t|\mathbf{w}_k^{t-1} \sim \mathcal{N}(\mathbf{w}_{t-1,k}, \sigma^2 \mathbf{1}_{N_w})$ (28.134)

$\mathbf{z}_n^t \sim \text{Dir}(\alpha \mathbf{1}_{N_z})$ (28.135)

$m_{nl}^t|\mathbf{z}_n^t \sim \text{Cat}(\mathbf{z}_n^t)$ (28.136)

$x_{nl}^t|m_{nl}^t=k, \mathbf{W}^t \sim \text{Cat}(\text{softmax}(\mathbf{w}_k^t))$ (28.137)
```

这被称为 **动态主题模型** [BL06]。有关 DPGM，请参见图 28.28。

可以使用结构化均匀场方法（第 10.4.1 节）对该模型执行近似推断，该方法利用卡尔曼平滑算法（第 8.2.2 节）对 \(\mathbf{w}_k^t\) 节点之间的线性高斯链执行精确推断（详情见 [BL06]）。图 28.29 说明了将该系统应用于 *科学* 杂志 100 年文章时的典型输出。
