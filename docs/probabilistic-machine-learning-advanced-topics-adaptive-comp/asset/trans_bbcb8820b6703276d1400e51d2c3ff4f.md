## 5.3.7 相关性网络

如果我们有一组相关变量，可以计算相关性网络，在其中，如果成对互信息 I(Xi; Xj) 高于某个阈值，则添加一条 i-j 边。在高斯情况下，I(Xi; Xj) = -1/2 log(1 - rho_ij^2)，其中 rho_ij 是相关系数，生成的图称为协方差图（第 4.5.5.1 节）。然而，我们也可以将其应用于离散随机变量。相关性网络在系统生物学 [Mar+06] 中非常流行，用于可视化基因之间的相互作用。但也可以将其应用于其他类型的数据集。例如，图 5.9 可视化了图 5.8 中显示的 20-newsgroup 数据集中单词之间的 MI。结果看起来直觉上是合理的。

然而，相关性网络存在一个主要问题：图通常非常稠密，因为大多数变量依赖于大多数其他变量，即使对 MI 进行了阈值处理。例如，假设 \(X_1\) 直接影响 \(X_2\)，而 \(X_2\) 直接影响 \(X_3\)（例如，这些构成信号级联的组件，\(X_1 - X_2 - X_3\)）。那么 \(X_1\) 与 \(X_3\) 具有非零 MI（反之亦然），因此除了 \(1-2\) 和 \(2-3\) 边外，还会有一条 \(1-3\) 边；因此，图可能是完全连接的，具体取决于阈值。

解决此问题的方法是学习一个概率图形模型，它表示条件 *独立性*，而不是 *依赖性*。在链示例中，不会有 \(1-3\) 边，因为 \(X_1 \perp X_3 | X_2\)。因此，图形模型通常比相关性网络稀疏得多。详情请参见第 30 章。

## 5.4 数据压缩（源编码）

数据压缩，也称为源编码，是信息理论的核心。它也与概率机器学习相关。原因如下：如果我们可以模拟不同类型数据样本的概率，那么我们可以为出现频率最高的样本分配短代码字，为出现频率较低的样本保留较长的编码。这与自然语言中的情况相似，常见单词（如 "a"、"the"、"and"）通常比罕见单词短得多。因此，压缩数据的能力需要发现数据中潜在模式及其相对频率的能力。这促使 Marcus Hutter 提出，将压缩作为衡量通用人工智能性能的客观方式。更确切地说，他向任何能够将英文维基百科前 100 MB 压缩得比某个基准更好的人提供 50,000 欧元。这被称为 Hutter 奖。在本节中，我们简要总结了数据压缩中的一些关键思想。详情见，例如，[Mac03; CT06; YMT22]。

### 5.4.1 无损压缩

离散数据，例如自然语言，始终可以以一种方式压缩，使我们能够唯一地恢复原始数据。这称为无损压缩。

Claude Shannon 证明了，无损编码来自分布 \(p\) 的某些数据所需的比特数期望至少为 \(\mathbb{H}(p)\)。这被称为源编码定理。要实现这个下界，需要提出良好的概率模型，以及基于这些模型设计代码的好方法。由于 KL 散度的非负性，\(\mathbb{H}_{ce}(p, q) \ge \mathbb{H}(p)\)，因此如果我们使用除真实模型 \(p\) 之外的任何模型 \(q\) 来压缩数据，将需要一些额外比特。额外比特的数量正好是 \(D_{KL}(p \| q)\)。

实现无损编码的常用技术包括 Huffman 编码、算术编码和非对称数制系统 [Dud13]。这些算法的输入是字符串上的概率分布（这就是 ML 发挥作用的地方）。这种分布通常使用隐变量模型来表示（例如，见 [TBB19; KAH19]）。

### 5.4.2 有损压缩和速率-失真权衡

要将实值信号（如图像和声音）编码为数字信号，我们首先必须将信号量化为一系列符号。做到这一点的一个简单方法是使用向量量化。然后我们可以使用无损编码方法压缩这一离散符号序列。但是，解压缩时我们会丢失一些信息。因此，这种方法称为 **有损压缩**。

在本节中，我们量化了表示大小（我们使用的符号数量）与产生的误差之间的这种权衡。我们将使用第 5.6.2 节讨论的变分信息瓶颈的术语（但此处我们处于无监督环境中）。具体而言，我们假设有一个随机编码器 p(z|x)、一个随机解码器 d(x|z) 和一个先验边缘分布 m(z)。

我们定义编码器-解码器对（如第 5.6.2 节中）的 **失真** 如下：

D = - \int d\mathbf{x} \, p(\mathbf{x}) \int d\mathbf{z} \, e(\mathbf{z}|\mathbf{x}) \log d(\mathbf{x}|\mathbf{z})

如果解码器是确定性模型加上高斯噪声，d(x|z) = N(x|f_d(z), \sigma^2)，且编码器是确定性的，e(z|x) = \delta(z - f_e(x))，则这变为

D = \frac{1}{\sigma^2} \mathbb{E}_{p(\mathbf{x})} [ || f_d(f_e(\mathbf{x})) - \mathbf{x} ||^2 ]

这只是使用 f_e 和 f_d 确定性地编码然后解码数据时发生的预期 **重建误差**。

我们定义模型的 **速率** 如下：

R = \int d\mathbf{x} \, p(\mathbf{x}) \int d\mathbf{z} \, e(\mathbf{z}|\mathbf{x}) \log \frac{e(\mathbf{z}|\mathbf{x})}{m(\mathbf{z})}
= \mathbb{E}_{p(\mathbf{x})} [ D_{KL} ( e(\mathbf{z}|\mathbf{x}) \| m(\mathbf{z}) ) ]
= \int d\mathbf{x} \int d\mathbf{z} \, p(\mathbf{x}, \mathbf{z}) \log \frac{p(\mathbf{x}, \mathbf{z})}{p(\mathbf{x})m(\mathbf{z})} \ge \mathbb{I}(\mathbf{x}, \mathbf{z})

这只是我们编码分布与边缘分布之间的平均 KL。如果我们使用 m(z) 来设计最优码，那么速率就是我们需要支付的使用 m(z) 而非真实 **聚合后验** p(z) = \int d\mathbf{x} \, p(\mathbf{x}) e(\mathbf{z}|\mathbf{x}) 来编码数据的 **额外比特数**。

速率和失真之间存在根本权衡。要了解原因，请注意，一个平凡的编码方案将设置 e(z|x) = \delta(z - x)，这只是使用 x 作为其自身的最佳表示。这将导致 0 失真（从而最大化似然），但会产生高速率，因为每个 e(z|x) 分布都将是唯一的，并且远离 m(z)。换句话说，将没有压缩。相反，如果 e(z|x) = \delta(z - 0)，编码器将忽略输入。在这种情况下，速率将为 0，但失真将很高。

我们可以使用第 5.3.6 节中关于互信息的变分下界和上界，来更精确地描述这种权衡。从该节我们知道：

H - D \le \mathbb{I}(\mathbf{x}; \mathbf{z}) \le R

其中 H 是（微分）熵

H = - \int d\mathbf{x} \, p(\mathbf{x}) \log p(\mathbf{x})
