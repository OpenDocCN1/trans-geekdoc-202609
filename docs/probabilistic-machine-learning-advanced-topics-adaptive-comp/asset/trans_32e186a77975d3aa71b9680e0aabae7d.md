\(bel_s(z_s) \propto \psi_s(z_s) \prod_{t \in ch_s} m_{t \to s}(z_s)\) (9.58)

要计算 s 应发送给其父节点 t 的传出消息，我们将局部信念通过连接 s 和 t 的成对势传递，然后对 s 进行边缘化以得到

\(m_{s \to t}(z_t) = \sum_{z_s} \psi_{st}(z_s, z_t) bel_s(z_s)\) (9.59)

在树的根节点处，bel_t(z_t) = p(z_t | y) 将已看到所有证据。然后它可以将消息发回给叶子节点。s 发送给其子节点 t 的消息应为 s 从所有其他子节点 u 接收到的所有消息的乘积，经过成对势传递，然后进行边缘化：

\(m_{s \to t}(z_t) = \sum_{z_s} \left( \psi_s(z_s) \psi_{st}(z_s, z_t) \prod_{u \in ch_s \setminus t} m_{u \to s}(z_s) \right)\) (9.60)

参见图 9.9。与其将 s 接收到的所有消息中除一个外的其余消息相乘，不如将所有消息相乘，然后除以来自子节点 t 的 t → s 消息。这样做的优点是，所有消息的乘积已在公式 (9.58) 中计算过，因此无需重新计算该项。于是我们得到

\(m_{s \to t}(z_t) = \sum_{z_s} \psi_{st}(z_s, z_t) \frac{bel_s(z_s)}{m_{t \to s}(z_s)}\) (9.61)

我们可以将 bel_s(z_s) 视为给定所有证据后的新更新后验 p(z_s | y)，并将 m_{t → s}(z_s) 视为预测先验 p(z_s | y_t^-)，其中 y_t^- 是根在 t 的子树中的所有证据。因此，该比率包含 t 从其自身子树中尚未知晓的新证据。我们使用此来更新节点 t 的信念状态以得到：

\(bel_t(z_t) \propto bel_t(z_t) m_{s \to t}(z_t)\) (9.62)

（注意，公式 (9.58) 是此情形的一个特例，其中我们不除以 m_{s → t}，因为在向上传递过程中，没有来自父节点的传入消息。）这与公式 (9.37) 中的后向平滑方程类似，其中 \alpha_t(i) 被 bel_t(z_t = i) 替换，A(i,j) 被 \psi_{st}(z_s = i, z_t = j) 替换，\gamma_{t+1}(j) 被 bel_s(z_s = j) 替换，而 \alpha_{t+1|t}(j) 被 m_{t \to s}(z_s = j) 替换。

## 9.3.3 Max-product 算法

在 9.3.2 节中，我们描述了和-积算法，用于计算后验边缘分布：

\(bel_i(k) = \gamma_i(k) = p(z_i = k | y) = \sum_{z_{-i}} p(z_i = k, z_{-i} | y)\) (9.63)

我们可以将求和操作替换为最大值操作，从而得到 **最大乘积信念传播**。该计算的结果是每个节点的一组 **最大边缘**：

```
\zeta_i(k) = \max_{\mathbf{z}_{\neg i}} p(z_i = k, \mathbf{z}_{\neg i} | \mathbf{y}) \quad (9.64)
```

### 9.3.3.1 Connection between MMM and MAP

在 [YW04] 中，他们表明，如果最大边缘是唯一且精确计算的（例如，如果图是树），则 \(\tilde{\mathbf{z}} = \mathbf{z}^*\)。这意味着我们可以通过运行最大乘积 BP 并将每个节点设置为其局部最大值（即使用 MMM 估计）来恢复全局 MAP 估计。但是，如果最大边缘存在平局（对应于存在多个全局最优解的情况），这种“局部拼接”过程可能导致全局不一致。如果我们有一个树结构模型，可以使用 **回溯** 过程，类似于维特比算法（第 9.2.6 节），在从根节点向后工作的同时将节点钳位到其最优值。有关详细信息，见例如 [KF09a, p569]。遗憾的是，回溯不适用于一般图。[YW04] 提出的一种替代迭代方法如下。首先运行最大乘积 BP，并将具有唯一最大边缘的所有节点钳位到其最优值；然后我们将单个模糊节点钳位到一个最优值，并将所有这些钳位值作为额外证据进行条件设定，执行更多轮消息传递，直到所有平局被打破。这可能需要多轮推理，尽管每一轮中未钳位（隐藏）变量的数量都会减少。

### 9.3.3.2 Connection between MPM and MAP

在本节中，我们讨论 MPM 估计 \(\hat{\mathbf{z}}\)，它计算后验边缘分布的最大值。通常，这不与 MAP 估计对应，即使后验边缘分布是精确的。要了解原因，请注意，MPM 仅查看给定所有可见证据时每个节点的信念状态，但忽略先验中可能存在的任何依赖关系或约束。为说明这可能成为一个问题，请考虑第 5.5 节中的纠错码示例，其中我们定义了 \(p(\mathbf{z}, \mathbf{y}) = p(z_1)p(z_2)p(z_3|z_1, z_2) \prod_{i=1}^3 p(y_i|z_i)\)，所有变量均为二进制。先验 \(p(z_1)\) 和 \(p(z_2)\) 是均匀的。条件项 \(p(z_3|z_1, z_2)\) 是确定性的，并计算 \((z_1, z_2)\) 的奇偶性。特别是，我们有 \(p(z_3 = 1|z_1, z_2) = \mathbb{I}(\text{odd}(z_1, z_2))\)，因此块 \(\mathbf{z}_{1:3}\) 中 1 的总数为偶数。似然项 \(p(y_i|z_i)\) 表示比特翻转噪声信道模型，噪声水平为 \(\alpha = 0.2\)。假设我们观察到 \(\mathbf{y} = (1, 0, 0)\)。在这种情况下，精确的后验边缘分布如下:$^2 \gamma_1 = [0.3469, 0.6531], \gamma_2 = [0.6531, 0.3469], \gamma_3 = [0.6531, 0.3469]$. 精确的最大边缘全部相同，

那么，哪种方法更好？这取决于我们的损失函数，如第 34.1 节所述。如果我们想要最小化每个 \(z_i\) 的预测误差，也称为比特误差，则应计算 MPM。如果我们想要最小化整个序列 \(\boldsymbol{z}\) 的预测误差，也称为字误差，则应使用 MAP，因为我们可以考虑全局约束。

例如，假设我们正在进行语音识别，有人说 "recognize speech"。MPM 解码可能返回 "wreck a nice beach"，因为从本地来看，"beach" 可能是 "speech" 在孤立情况下最可能的解释（参见图 34.3）。然而，MAP 解码将推断 "recognize speech" 是更可能的整体解释，通过考虑语言模型先验 \(p(\boldsymbol{z})\)。

另一方面，如果我们没有强约束，MPM 估计可能更稳健 [MMP87; SM12]，因为它将其他节点边缘化，而不是对它们取最大值。例如，在图 9.3 的赌场 HMM 示例中，我们看到 MPM 方法产生 49 个比特错误（总共可能的 \(T = 300\) 中），而 MAP 路径产生 60 个错误。

### 9.3.3.3 Connection between MPE and MAP

在图形模型文献中，计算所有隐性变量的联合最可能设置 \(\boldsymbol{z}^* = \arg \max_{\boldsymbol{z}} p(\boldsymbol{z}|\boldsymbol{y})\)，被称为最可能解释或 MPE [Pea88]。在那篇文献中，术语 "MAP" 用于指代最大化某些隐性变量并边缘化（求和其余部分）的情况。例如，如果我们最大化单个节点 \(z_i\)，但对所有其他节点 \(\boldsymbol{z}_{-i}\) 求和，则得到 MPM \(\hat{z}_i = \arg \max_{z_i} \sum_{\boldsymbol{z}_{-i}} p(\boldsymbol{z}|\boldsymbol{y})\)。

我们可以将 MPM 估计推广为计算一组查询变量 \(Q\) 的最佳猜测，给定一组可见变量 \(V\) 上的证据，并将剩余变量 \(R\) 边缘化，以得到

```
\(\boldsymbol{z}_Q^* = \arg \max_{\boldsymbol{z}_Q} \sum_{\boldsymbol{z}_R} p(\boldsymbol{z}_Q, \boldsymbol{z}_R | \boldsymbol{z}_V)\) (9.65)
```

（此处 \(\boldsymbol{z}_R\) 称为扰动变量，因为它们不感兴趣且未被观察。）在 [Pea88] 中，这被称为 MAP 估计，但我们将称其为 MPM 估计，以避免与 "MAP" 术语的 ML 用法混淆（其中我们联合最大化一切）。
