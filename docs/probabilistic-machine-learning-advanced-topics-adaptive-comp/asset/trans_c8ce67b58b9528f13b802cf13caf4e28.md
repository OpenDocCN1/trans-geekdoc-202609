## 12.6.1 马尔可夫链的混合速率

马尔可夫链收敛到平稳分布并忘记其初始状态所需的时间，称为 **混合时间**。更正式地说，我们说从状态 \(x_0\) 的混合时间是使得对于任何常数 \(\epsilon > 0\) 都满足的最小时间，即

```
\(\tau_\epsilon(x_0) \triangleq \min\{t : ||\delta_{x_0}(x)T^t - p^*||_1 \le \epsilon\}\)
```

其中 \(\delta_{x_0}(x)\) 是所有概率质量都位于状态 \(x_0\) 的分布，\(T\) 是链的转移矩阵（取决于目标 \(p^*\) 和提议 \(q\)），而 \(\delta_{x_0}(x)T^t\) 是 \(t\) 步后的分布。

链的混合时间定义为

```
\(\tau_\epsilon \triangleq \max_{x_0} \tau_\epsilon(x_0)\)
```

这是链的分布从任何起始状态变得 \(\epsilon\) 接近 \(p^*\) 所需的最长时间。

混合时间由特征间隙 \(\gamma = \lambda_1 - \lambda_2\) 决定，这是转移矩阵第一个和第二个特征值之差。对于有限状态链，可以证明 \(\tau_\epsilon = O(\frac{1}{\gamma} \log \frac{n}{\epsilon})\)，其中 \(n\) 是状态数。

我们还可以通过研究状态空间的几何来研究该问题。例如，考虑图 12.12 中的链。我们看到状态空间由两个“岛屿”组成，每个岛屿通过一个狭窄的“瓶颈”相连。（如果它们完全断开连接，链将不具备 ergodic 性，并且将不再有唯一的平稳分布，如第 2.6.4.3 节所讨论。）我们定义链的 **导通率** \(\phi\) 为在所有状态子集 \(S\) 上，从该集合转移到其补集的最小概率：

```
\(\phi \triangleq \min_{S: 0 < p^*(S) \le 0.5} \frac{\sum_{x \in S, x' \in S^c} T(x \rightarrow x')}{p^*(S)}\)
```

![](img/ca72c1626f4850f058a9edc138c1ac73_551_0.png)

图 12.12: 具有低导通率的马尔可夫链。点状弧表示概率非常低的转移。改编自 [KF09a] 的图 12.6。经 Daphne Koller 友好许可使用。

可以证明 \(\tau_\epsilon \le O\left( \frac{1}{\phi^2} \log \frac{n}{\epsilon} \right)\)。因此，导通率低的链具有高混合时间。例如，模式分离良好的分布通常具有高混合时间。在这些情况下，简单的 MCMC 方法（如 MH 和 Gibbs）通常效果不佳，需要更先进的算法（如平行退火）（例如，参见 [ED05; Kat+06; BZ20]）。

## 12.6.2 实际收敛诊断

计算链的混合时间通常相当困难，因为转移矩阵通常很难计算。此外，诊断收敛性在计算上通常是不可行的 [BBM10]。尽管如此，已经提出了各种启发式方法——例如，参见 [Gey92; CC96; BR98; Veh+19]。我们下面讨论一些当前推荐的方法，遵循 [Veh+19]。

### 12.6.2.1 迹线图

评估方法是否收敛的最简单方法之一是从非常不同的过度分散起始点运行多个链（通常为 3 或 4 条），并绘制某些感兴趣量的样本，例如状态向量某个分量的值，或某个事件（如值取极值）的样本。这称为迹线图。如果链已经混合，它应该“忘记”起始位置，因此迹线图应收敛到相同分布，并彼此重叠。

为了说明这一点，我们将考虑 [McE20, Sec 9.5] 中的一个非常简单但具有启发性的示例。该模型是一元高斯分布，\(y_i \sim \mathcal{N}(\alpha, \sigma)\)，只有 2 个观测值，\(y_1 = -1\) 和 \(y_2 = +1\)。我们首先考虑非常扩散的先验，\(\alpha \sim \mathcal{N}(0, 1000)\) 和 \(\sigma \sim \text{Expon}(0.0001)\)，两者都允许 \(\alpha\) 和 \(\sigma\) 取非常大的值。我们使用 3 条链和 500 个样本通过 HMC 拟合该模型。结果如图 12.13 所示。右侧，我们展示了 3 条不同链的 \(\alpha\) 和 \(\sigma\) 的迹线图。我们看到它们彼此重叠不多。此外，图底部众多黑色垂直线表明 HMC 存在许多发散。

问题是由过于扩散的先验引起的，因为我们只有 2 个数据点，似然无法淹没先验。因此后验也是扩散的。我们可以通过使用略强一些的先验来修复这个问题，使参数保持在更合理的值附近。例如，假设我们使用 \(\alpha \sim \mathcal{N}(1, 10)\) 和 \(\sigma \sim \text{Expon}(1)\)。现在我们得到图 12.14 中的结果。右侧我们看到

### 12.6.2.2 估计潜在尺度缩减 (EPSR)

在本节中，我们讨论一种更定量地评估收敛性的方法。基本思想是这样的：如果一条或多条链没有充分混合，那么所有链合并在一起的方差将高于各个链的方差。因此，我们将比较在链之间和链内计算的感兴趣量的方差。

更准确地说，假设我们有 _M_ 条链，并从每条链中抽取 _N_ 个样本。设 _x<sub>nm</sub>_ 表示从第 _m_ 条链的第 _n_ 个样本得到的感兴趣量。我们按如下方式计算链间和链内方差：

```
\( B = \frac{N}{M-1} \sum_{m=1}^M (\bar{x}_{\cdot m} - \bar{x}_{\cdot \cdot})^2, \text{ where } \bar{x}_{\cdot m} = \frac{1}{N} \sum_{n=1}^N x_{nm}, \bar{x}_{\cdot \cdot} = \frac{1}{M} \sum_{m=1}^M \bar{x}_{\cdot m} \quad (12.97) \)
```

```
\( W = \frac{1}{M} \sum_{m=1}^M s_m^2, \text{ where } s_m^2 = \frac{1}{N-1} \sum_{n=1}^N (x_{nm} - \bar{x}_{\cdot m})^2 \quad (12.98) \)
```

\(s_m^2\) 的公式是来自 _N_ 个样本集的通常无偏方差估计；_W_ 只是其平均值。_B_ 的公式类似，但按 _N_ 缩放，因为它基于 \(\bar{x}_{\cdot m}\) 的方差，后者是对 _N_ 个值求平均得到的。
