\mathbb{E}[Y|do(Z=1)] - \mathbb{E}[Y|do(Z=1)] (36.59)
= (\mathbb{E}[Y|\text{compiler}, do(Z=1)] - \mathbb{E}[Y|\text{compiler}, do(Z=0)])P(\text{compiler}) (36.60)
+ (\mathbb{E}[Y|\text{always/never}, do(Z=1)] - \mathbb{E}[Y|\text{always/never}, do(Z=0)])P(\text{always/never}) (36.61)
+ (\mathbb{E}[Y|\text{defier}, do(Z=1)] - \mathbb{E}[Y|\text{defier}, do(Z=0)])P(\text{defier}). (36.62)

The key is the effect on the compiler subpopulation, Equation (36.60). First, by definition of the compiler population, we have that:

\mathbb{E}[Y|\text{compiler}, do(Z=z)] = \mathbb{E}[Y|\text{compiler}, do(A=z)]. (36.63)

That is, the causal effect of the treatment is the same as the causal effect of the instrument in this subpopulation — this is the core reason why access to an instrument allows identification of the local average treatment effect. This means that

\text{LATE} = \mathbb{E}[Y|\text{compiler}, do(Z=1)] - \mathbb{E}[Y|\text{compiler}, do(Z=0)]. (36.64)

Further, we have that P(compiler) = P(A = 1|do(Z = 1)) − P(A = 1|do(Z = 0)). The reason is simply that, by definition of the subpopulations,

P(A = 1|do(Z = 1)) = P(\text{compiler}) + P(\text{always taker}) (36.65)
P(A = 1|do(Z = 0)) = P(\text{always taker}). (36.66)

Now, plugging the expression for P(compiler) and Equation (36.64) into Equation (36.60) we have that:

(\mathbb{E}[Y|\text{compiler}, do(Z=1)] - \mathbb{E}[Y|\text{compiler}, do(Z=0)])P(\text{compiler}) (36.67)
= \text{LATE} \times (P(A = 1|do(Z=1)) - P(A = 1|do(Z=0))) (36.68)

This gives us an expression for the local average treatment effect in terms of the effect of the instrument on the compliers and the probability that a unit takes the treatment when assigned/not-assigned.

The next step is to show that the remaining instrument effect decomposition terms, Equations (36.61) and (36.62), are both 0. Equation (36.61) is the causal effect of the instrument on the always/never takers. It’s equal to 0 because, by definition of this subpopulation, the instrument has no causal effect in the subpopulation — they ignore the instrument! Mathematically, this is just \mathbb{E}[Y|\text{always/never}, do(Z=1)] = \mathbb{E}[Y|\text{always/never}, do(Z=0)]. Finally, Equation (36.62) is 0 by the instrument monotonicity assumption: we assumed that P(defier) = 0.

In totality, we now have that Equations (36.60) to (36.62) reduces to:

\mathbb{E}[Y|do(Z=1)] - \mathbb{E}[Y|do(Z=1)] (36.69)
= \text{LATE} \times (P(A = 1|do(Z=1)) - P(A = 1|do(Z=0))) + 0 + 0 (36.70)

Rearranging for LATE and plugging in to Equation (36.58) gives the claimed identification result.
