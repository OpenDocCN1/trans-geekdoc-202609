此处 \(\tau\) 是一个为促进快速混合而选择的缩放因子。[RR01b] 证明，如果后验是高斯分布，则渐近最优值为 \(\tau^2 = 2.38^2/D\)，其中 \(D\) 是 \(\boldsymbol{x}\) 的维度；这会得到 0.234 的接受率，（在此例中）这是在足够广泛地探索以覆盖分布、同时又不至于被拒绝过多之间的最佳权衡。（有关随机游走 Metropolis 方法最优接受率的更近期论述，参见 [Béd08]。）

图 12.1 展示了一个示例，其中我们使用 RWM 从两个一维高斯分布的混合中采样。这是一个有些棘手的目标分布，因为它由两个有些分离的众数组成。正确设置建议分布的方差 \(\tau^2\) 非常重要：如果方差过低，链只会探索其中一个众数，如图 12.1(a) 所示；但如果方差过大，大部分移动都会被拒绝，链会非常 **粘滞**，即它会长时间停留在同一状态。这从图 12.1(b) 中重复值的长段可以明显看出。如果我们将建议分布的方差设得恰到好处，就会得到图 12.1(c) 中的轨迹，其中样本明显探索了目标分布的支撑集。

### 12.2.3.3 构建建议分布

如果存在几个可能有用的建议，可以使用 **混合建议** 将它们组合起来，混合建议是基础建议的凸组合：

```
\(q(\boldsymbol{x}'|\boldsymbol{x}) = \sum_{k=1}^K w_k q_k(\boldsymbol{x}'|\boldsymbol{x})\) (12.16)
```

其中 \(w_k\) 是和为 1 的混合权重。只要每个 \(q_k\) 是单独有效的建议，且每个 \(w_k > 0\)，则整体混合建议也将有效。特别是，如果每个建议都是可逆的，即满足详细平衡（第 2.6.4.4 节），那么混合建议也满足。

也可以通过将单个建议串联起来来组合它们，以得到

$q(\mathbf{x}'|\mathbf{x}) = \sum_{\mathbf{x}_1} \cdots \sum_{\mathbf{x}_{K-1}} q_1(\mathbf{x}_1|\mathbf{x})q_2(\mathbf{x}_2|\mathbf{x}_1) \cdots q_K(\mathbf{x}|\mathbf{x}_{K-1})$ (12.17)

一个常见的例子是，每个基础建议仅更新变量的一个子集（例如，参见第 12.3 节）。

### 12.2.3.4 数据驱动的 MCMC

在目标分布为后验 \(p^*(\mathbf{x}) = p(\mathbf{x}|\mathcal{D})\) 的情况下，将建议不仅条件于前一隐藏状态，还条件于可见数据（即使用 \(q(\mathbf{x}'|\mathbf{x}, \mathcal{D})\)）会很有帮助。这称为 **数据驱动的 MCMC**（例如，参见 [TZ02; Jih+12]）。

创建此类建议的一种方法是训练一个识别网络，使用 \(q(\mathbf{x}'|\mathbf{x}, \mathcal{D}) = f(\mathbf{x})\) 来建议状态。如果状态空间是高维的，预测所有隐藏组件可能会比较困难，因此我们可以改为训练单个“专家”来预测隐藏状态的特定部分。例如，在从图像中估计人体 3D 姿态的背景下，我们可以结合人脸检测器和肢体检测器。然后可以使用如下形式的混合建议：

\(q(\mathbf{x}'|\mathbf{x}, \mathcal{D}) = \pi_0 q_0(\mathbf{x}'|\mathbf{x}) + \sum_k \pi_k q_k(\mathbf{x}'_k|f_k(\mathcal{D}))\) (12.18)

其中 \(q_0\) 是标准的与数据无关的建议（例如，随机游走），而 \(q_k\) 更新状态空间的第 \(k\) 个分量。

整个程序是一种 **生成并测试** 形式：鉴别性建议 \(q(\mathbf{x}'|\mathbf{x}, \mathcal{D})\) 生成新假设，然后通过计算后验比 \(\frac{p(\mathbf{x}'|\mathcal{D})}{p(\mathbf{x}|\mathcal{D})}\) 来“测试”这些假设，以查看新假设是更好还是更糟。（另请参见第 13.3 节，我们在其中讨论粒子滤波器的建议分布学习。）

### 12.2.3.5 自适应 MCMC

可以在算法运行时更改建议的参数以提高效率。这称为 **自适应 MCMC**。这允许从较宽的协方差（例如）开始，允许在空间中进行大步移动直到找到一个众数，然后缩小协方差以确保对众数周围区域的仔细探索。

但是，必须小心不要违反马尔可夫性质；因此，建议的参数不应依赖于链的整个历史。事实证明，确保这一点的充分条件是随时间的推移逐渐“淡化”适应。详情请参见 [AT08]。

### 12.2.4 初始化

有必要从具有非零概率的初始状态启动 MCMC。一种自然的方法是首先使用优化器找到一个局部众数。但是，在这样的点上，日志联合的梯度为零，这可能会对某些基于梯度的 MCMC 方法（例如 HMC（第 12.5 节））造成问题，因此最好从 MAP 估计“附近”启动（例如，参见 [HFM17, Sec 7.]）。

## 12.3 Gibbs 采样

MH 的主要问题是需要选择建议分布，以及接受率可能较低。在本节中，我们描述了一种 MH 方法，它利用图形模型的条件独立性特性来自动创建良好的建议，接受概率为 1。这种方法称为 **Gibbs 采样**。²（在物理学中，这种方法称为 **Glauber 动力学** 或 **热浴法**。）这是 MCMC 中的坐标下降类比。³

### 12.3.1 基本思想

Gibbs 采样的基本思想是：依次对每个变量进行采样，条件是分布中所有其他变量的值。例如，如果有 D = 3 个变量，我们使用

- x_1^{s+1} ~ p(x_1|x_2^s, x_3^s)
- x_2^{s+1} ~ p(x_2|x_1^{s+1}, x_3^s)
- x_3^{s+1} ~ p(x_3|x_1^{s+1}, x_2^{s+1})

这很容易推广到 D 个变量。（注意，如果 x_i 是已知变量，则不对其进行采样，但它可以作为另一个条件分布的输入。）

表达式 p(x_i|x_{-i}) 称为变量 i 的 **全条件分布**。一般来说，x_i 可能只依赖于其他一些变量。如果将 p(x) 表示为图形模型，可以通过查看 i 的马尔可夫毯（即图中 i 的邻居，参见第 4.2.4.3 节）来推断依赖关系，因此可以写成

```
x_i^{s+1} ~ p(x_i|x^s_{-i}) = p(x_i|x^s_{mb(i)}) (12.19)
```

（与方程 (10.87) 中均场变分推断的方程进行比较。）

我们可以并行采样某些节点，而不会影响正确性。特别是，假设我们可以对（道德化的）无向图进行 **着色**，使得没有两个相邻节点具有相同的颜色。（一般来说，计算最优着色是 NP 完全的，但我们可以使用有效的启发式方法，例如 [Kub04] 中的方法。）然后可以并行采样所有相同颜色的节点，并依次遍历颜色 [Gon+11]。

### 12.3.2 Gibbs 采样是 MH 的特例

事实证明，Gibbs 采样是 MH 的一个特例，其中我们使用如下形式的一系列建议：

```
q_i(x'|x) = p(x'_i|x_{-i}) I(x'_{-i} = x_{-i}) (12.20)
```

也就是说，我们移动到一个新状态，其中 x_i 从其全条件分布中采样，但 x_{-i} 保持不变。
