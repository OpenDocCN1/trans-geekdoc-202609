influence someone's response. Let us model these hidden factors by Gaussian noise, \(\epsilon_n \sim \mathcal{N}(0, 1)\). Let the combined preference for positive outcomes be represented by the latent variable \(z_n = \mathbf{w}^{\mathsf{T}}\mathbf{x}_n + \epsilon_n\). We assume that the person will pick the positive label iff this latent factor is positive rather than negative, i.e.,

\(y_n = \mathbb{I}(z_n \ge 0)\) (15.164)

When we marginalize out \(z_n\), we recover the probit model:

\(p(y_n = 1 | \mathbf{x}_n, \mathbf{w}) = \int \mathbb{I}(z_n \ge 0) \mathcal{N}(z_n | \mathbf{w}^{\mathsf{T}}\mathbf{x}_n, 1) dz_n\) (15.165)
\(= p(\mathbf{w}^{\mathsf{T}}\mathbf{x}_n + \epsilon_n \ge 0) = p(\epsilon_n \ge -\mathbf{w}^{\mathsf{T}}\mathbf{x}_n)\) (15.166)
\(= 1 - \Phi(-\mathbf{w}^{\mathsf{T}}\mathbf{x}_n) = \Phi(\mathbf{w}^{\mathsf{T}}\mathbf{x}_n)\) (15.167)

Thus we can think of probit regression as a threshold function applied to noisy input.

We can interpret logistic regression in the same way. However, in that case the noise term \(\epsilon_n\) comes from a logistic distribution, defined as follows:

\(f(y|\mu, s) \triangleq \frac{e^{-\frac{y-\mu}{s}}}{s(1+e^{-\frac{y-\mu}{s}})^2} = \frac{1}{4s} \text{sech}^2(\frac{y-\mu}{s^2})\) (15.168)

where the mean is \(\mu\) and the variance is \(\frac{s^2 \pi^2}{3}\). The cdf of this distribution is given by

\(F(y|\mu, s) = \frac{1}{1 + e^{-\frac{y-\mu}{s}}}\) (15.169)

It is clear that if we use logistic noise with \(\mu = 0\) and \(s = 1\) we recover logistic regression. However, it is computationally easier to deal with Gaussian noise, as we show below.

# 15.4.2 Maximum likelihood estimation

In this section, we discuss some methods for fitting probit regression using MLE.

# 15.4.2.1 MLE using SGD

We can find the MLE for probit regression using standard gradient methods. Let \(\mu_n = \mathbf{w}^{\mathsf{T}}\mathbf{x}_n\), and let \(\tilde{y}_n \in \{-1, +1\}\). Then the gradient of the log-likelihood for a single example \(n\) is given by

\(\mathbf{g}_n \triangleq \frac{d}{d\mathbf{w}} \log p(\tilde{y}_n | \mathbf{w}^{\mathsf{T}}\mathbf{x}_n) = \frac{d\mu_n}{d\mathbf{w}} \frac{d}{d\mu_n} \log p(\tilde{y}_n | \mathbf{w}^{\mathsf{T}}\mathbf{x}_n) = \mathbf{x}_n \frac{\tilde{y}_n \phi(\mu_n)}{\Phi(\tilde{y}_n \mu_n)}\) (15.170)

where \(\phi\) is the standard normal pdf, and \(\Phi\) is its cdf. Similarly, the Hessian for a single case is given by

\(\mathbf{H}_n = \frac{d}{d\mathbf{w}^2} \log p(\tilde{y}_n | \mathbf{w}^{\mathsf{T}}\mathbf{x}_n) = -\mathbf{x}_n \left( \frac{\phi(\mu_n)^2}{\Phi(\tilde{y}_n \mu_n)^2} + \frac{\tilde{y}_n \mu_n \phi(\mu_n)}{\Phi(\tilde{y}_n \mu_n)} \right) \mathbf{x}_n^{\mathsf{T}}\) (15.171)

This can be passed to any gradient-based optimizer.
