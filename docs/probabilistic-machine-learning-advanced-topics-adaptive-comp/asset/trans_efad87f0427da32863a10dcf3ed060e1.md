**基线。** 仅仅是存在一个解释可能会改变人们与机器学习系统的交互方式。因此，通常需要考虑一个人在没有机器学习系统的情况下、有机器学习系统但没有解释的情况下、有机器学习系统和安慰剂解释（提供无信息的解释）的情况下，以及有机器学习系统和手工制作的解释（由据推测是优秀沟通者的人手动生成）的情况下的表现。

**实验设计和假设检验。** 自变量和因变量、假设以及纳入和排除标准必须在研究开始前明确定义。例如，假设某人假设特定的解释将帮助开发者调试图像分类器。在此情况下，自变量将是一种协助形式：特定的解释、竞争的解释方法以及上述基线。因变量将是开发者是否能够识别错误。纳入和排除标准可能包括要求开发者拥有足够的训练图像分类器的经验（由初始调查或预测试决定）、表现出参与度（由练习轮次的基本表现水平衡量），并且没有特定解释类型的先前经验（由初始调查决定）。其他排除标准可能包括删除异常值。例如，可以预先决定排除任何执行任务时间异常长或异常短的参与者的数据，作为参与度的替代指标。

如第 33.2 节所述，任何可解释的机器学习方法都涉及许多决策，且每个环境都有其细微差别。"解释 $X$（通过某些流水线 $Y$ 计算）是否比解释 $X'$ 更有助于用户在情境 $Z$ 中？" 等形式的研究可能无法提供太多关于*为什么*该特定解释更好或更差的洞察——这不仅使得对特定解释进行迭代变得更加困难，也使得对其他解释或情境进行推广变得更加困难。结果中存在许多潜在的变化因素，范围从解释及其呈现的属性到任务的难度。

为了减少这种方差，并获得更有用且可推广的洞察，我们可以直接操纵一些变化因素。例如，假设研究问题是在特定情境下完整解释是否优于不完整解释。有人可能会写出手工制作的解释，这些解释在所牵涉的特征方面是完整的，缺少一个重要特征的解释，以及缺少几个重要特征的解释。这样做可以确保对感兴趣的不同实验条件进行均匀覆盖，而如果解释只是直接从流水线输出，则可能不会出现这种情况。另一个例子是，有人可能会故意创建一个带有已知错误的图像分类器，或者只是假装有一个做出某些预测的图像分类器（如 [Ade+20b] 中所做）。这类研究被称为 *巫师-of-Oz* 研究，它们可以帮助我们更精确地揭示解释有用的科学原因（例如，如 [Jac+21] 中所做）。

一旦确定了自变量和因变量、假设以及参与者标准（包括如何操纵自变量和因变量），下一步就是设置研究设计本身。广义来说，*随机化* 边际化了潜在的混杂因素。例如，将受试者分配给任务时的随机化边际化了受试者的先前知识；任务顺序的随机化边际化了学习效应。匹配和重复测量可以减少方差。匹配的一个例子是要求同一受试者使用两种不同的解释执行相同的最终任务。重复测量的一个例子是要求受试者针对多个不同的输入执行最终任务。设计用户研究的其他技术包括分组随机设计/拉丁方设计，它们随机化解释类型的顺序，同时保持与每种解释类型关联的任务聚在一起。这可以用于在不进行太多上下文切换的情况下边际化学习和疲劳的影响。应仔细考虑在受试者内部和受试者之间比较什么。受试者内部的任务绩效比较将具有较低的方差，但可能来自第一个任务到第二个任务的学习效应的偏差。受试者之间的比较将具有更高的方差，以及在实验招募期间人口转移的潜在偏差。最后，这些研究设计中的每一个，以及自变量和因变量的选择，都将暗示一个适当的显著性检验。选择正确的检验和多重假设校正以避免夸大的显著性值同时保留效力至关重要。

## 定性研究。

迄今为止，我们已经描述了定量用户研究设计的标准方法——一种因变量以数值方式测量（例如，正确识别错误所需时间、检测到的错误百分比）的研究。虽然定量研究通过证明许多用户之间存在一致且可量化的效果而提供价值，但它们通常无法告诉我们某个解释为什么有效。相比之下，定性研究通常以“思考 aloud”或其他基于讨论的协议进行，用户在执行实验时暴露其思维过程，这有助于识别特定形式的解释似乎有用或无用的原因。实验者可以通过听取用户如何使用信息来获得洞察，并且根据协议，可以要求澄清。

例如，假设有人对人们如何使用基于示例的解释来理解视频游戏代理的策略感兴趣。其想法是展示视频游戏中自动代理的几个视频片段，然后询问用户代理在新情况中可能会做什么。在思考 aloud 研究中，用户将执行此任务，同时讲述他们如何将所看到的视频与新情况联系起来。通过听取这些想法，研究人员不仅可以更深入地了解用户如何建立这些联系——例如，用户可能会看到代理在一个视频中收集硬币，并推断代理将始终追逐硬币——还可能识别出令人惊讶的错误：例如，用户可能会看到代理掉入一个坑中，并将其归因于一次性的手指不灵活，而没有意识到自动代理可能每次都会犯那个错误。

虽然思考 aloud 研究中的参与者通常比其他情况下更投入研究（因为他们正在描述自己的思考），但了解他们的想法可以提供关于解释提供的信息与人类用户采取的行动之间因果过程的洞察，最终有助于推进人们如何与机器提供的信息交互的科学。

## 初步研究：

上述描述只是对必须为高质量评估正确设计的众多因素的非常高层次的概述。在实践中，通常第一次就无法全部做好。小规模的初步研究对于检查诸如参与者是否以意外的方式关注所提供的信息，或者说明是否清晰且设计良好等因素至关重要。在迭代的小规模初步研究后修改实验可以节省大量。
