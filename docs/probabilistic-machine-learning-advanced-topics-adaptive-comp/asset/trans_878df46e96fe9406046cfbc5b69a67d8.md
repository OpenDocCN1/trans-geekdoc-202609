因此，因果推断的重要部分之一是用关于所考虑过程的潜在因果结构的知识来丰富观测数据。通常，这些假设可以充分缩小 SCM 的空间，以至于只有一个与观测数据兼容的因果 estimand 值。我们说，在给定的一组假设下，如果这些假设足以提供唯一答案，则因果 estimand 是 **可识别** 或 **可辨识** 的。有许多不同的充分条件集可以产生可识别的因果效应；我们称每个充分条件集为 **识别策略**。

针对关于潜在 SCM 的一组假设，表明因果 estimand 已识别的最常见方法是通过构造。具体来说，如果因果 estimand 可以完全用可观测概率分布来表示，那么它就是已识别的。我们称这种观测分布的函数为 **统计 estimand**。一旦恢复了这样的统计 estimand，我们就可以使用标准统计工具来构建和分析该数量的 estimator。作为统计 estimand 的一个示例，在上面的 SCM 中，可以证明如 Equation (36.9) 定义的 ATE 等于以下统计 estimand

ATE \stackrel{(*)}{=} \tau^{\text{ATE}} \triangleq \mathbb{E}[\mathbb{E}[Y|H, A=1] - \mathbb{E}[Y|H, A=0]], (36.12)

其中等式 (*) 仅成立是由于 SCM 的某些特定属性。请注意，上述右侧仅涉及观测变量之间的条件期望（没有 do 算子），因此 \tau^{\text{ATE}} 只是可观测概率分布的函数。

关于我们可能对支配所考虑过程的 SCM 所做的假设有多种类型。例如，以下是我们可能对运行示例中的系统所做的断言：

- 1. 患癌概率在 A、G 和 H 上在 logit 尺度上是可加的（即，逻辑回归是一个设定良好的模型）。
- 2. 对于每个个体，吸烟绝不会降低患癌概率。
- 3. 一个人是否吸烟受其健康意识 H 影响，而不受其癌症遗传易感性 G 的影响。

这些假设从完全指定 SCM 方程形式的强参数假设，到仅指定每个方程输入而将形式完全留空的非参数假设不等。通常，完全指定参数形式的假设非常强，并且需要比我们实际拥有的更详细的关于所考虑系统的知识。识别论证的目标是找到一组假设，这些假设足够弱，以至于对于所考虑的系统可能是合理的，但又足够强，以允许识别因果效应。

如果我们不愿对 SCM 的函数形式做任何假设，那么我们的假设只是关于哪些变量影响（以及不影响）其他变量。从这个意义上说，这些哪影响哪的假设是最小的。这些假设正是通过写下一个（可能不完整的）因果 DAG 所捕获的假设，展示哪些变量是每个其他变量的父节点。图可能不完整，因为我们可能不知道每条可能的边是否存在于物理系统中。例如，我们可能不确定基因 G 是否确实对健康意识 H 有因果效应。自然会问，仅基于部分指定的因果 DAG，我们能多大程度上识别因果效应。事实证明，基于这样的非参数假设可以取得很大进展；我们将在 36.8 节中详细讨论这一点。

我们还将讨论某些无法在因果图中编码，但仍比假设已知完整函数形式更弱的假设。例如，我们可以假设结果受治疗和任何混杂因素的加性影响，且它们之间没有交互项。这些较弱的假设即使在仅假设因果图不足以实现时，也能实现因果识别。

值得强调的是，每个因果识别策略都依赖于在观测数据中无法验证的、具有一定内容的假设。这直接源于因果问题的不适定性：如果用于识别因果量的假设可以被验证，那将意味着因果 estimand 仅从观测数据即可识别。然而，由于我们知道有许多与观测数据兼容的因果 estimand 值，因此可以推断，我们识别策略中的假设必须具有不可观测的含义。

## 36.2.4 反事实与因果层次

结构因果模型让我们能够形式化并研究关于所考虑系统的不同种类查询的层次。最常见的是观测查询：纯粹关于统计关联的问题（例如，“吸烟和肺癌在该样本抽取的总体中是否关联？”）。接下来是干预查询：关于人口层面因果关系的问题（例如，“吸烟在给定人群中增加多少患癌概率？”）。本章余下部分专注于干预查询的定义、识别和估计。最后，还有反事实查询：关于如果某事有所不同，特定个体层面的因果关系的问题（例如，“如果爱丽丝不吸烟，她会患癌吗？”）。这个因果层次由 [Pea09a, Ch. 1] 推广开来。

干预查询关注干预对结果的前瞻性效应；例如，如果我们进行干预并阻止一个随机抽样的个体吸烟，他们患肺癌的概率是多少？最终，这里的概率陈述是关于我们对 SCM 中“噪声”变量 \(\xi\) 的不确定性。这些是特定于随机选定个体的未测量因素。分布由该个体抽取的总体决定。因此，干预查询是关于人群的陈述。干预查询可以使用 do-表示法以条件分布的形式书写，例如，\(P(Y|do(A = 0))\)。在我们的示例中，这代表了一个随机选定并被阻止吸烟的个体的肺癌结果分布。

反事实查询关注如果在过去应用了干预，观测到的结果可能会有何不同。反事实查询通常以将给定结果归因于特定原因的方式来表述。例如，如果爱丽丝不吸烟，她会患癌吗？大多数患肺癌的吸烟者是因为吸烟而患癌吗？反事实查询之所以如此命名，是因为它们需要在个体内部比较反事实结果。在 SCM 的形式主义中，个体 \(i\) 的反事实结果是通过将相同的 \(\xi_i\) 值传递到不同干预下的 SCM 中来生成的。反事实结果通常以潜在结果表示法书写。在我们的吸烟运行示例中，这将如下所示：

```
\(Y_i(a) \triangleq f_Y(G_i, H_i, a, \xi_{3,i}).\)
```

也就是说，$Y_i(a)$ 是当 $A$ 被设置为 $a$ 而所有 $G_i, H_i, \xi_{3,i}$ 都保持不变时我们本会看到的结果。

了解区分干预查询和根本反事实查询的要点非常重要。仅仅因为一个查询可以用潜在结果表示法书写，并不使其成为反事实查询。例如，平均处理效应，即典型的干预查询，很容易用潜在结果表示法书写：

ATE = \(\mathbb{E}[Y_i(1) - Y_i(0)].\) (36.14)

相反，反事实查询和干预查询之间的关键分界线在于：查询是需要知道个体内部潜在结果的联合分布，还是跨个体的潜在结果边缘分布就足够了。反事实查询的一个重要标志是条件化于一个潜在结果的值。例如，“患癌吸烟者若不吸烟的肺癌发病率”是一个反事实查询，可以写成：

\(\mathbb{E}[Y_i(0) \mid Y_i(1) = 1, A_i = 1]\) (36.15)

回答这个查询需要知道个体层面癌症结果（通过 \(\xi_{3,i}\)）在每个个体吸烟和不吸烟的世界之间是如何相关的。值得注意的是，这个查询无法用 do-表示法重写，因为它需要区分 \(Y(0)\) 和 \(Y(1)\)，而 ATE 可以：\(\mathbb{E}[Y \mid do(A=1)] - \mathbb{E}[Y \mid do(A=0)]\)。

反事实查询比干预查询需要类别上更多的假设来进行识别。对于识别干预查询，知道 SCM 的 DAG 结构通常就足够了，而对于反事实查询，则需要一些关于 SCM 中函数形式的假设。这是因为每个个体只观察到一个潜在结果，因此个体内部潜在结果之间的依赖性不可观测。例如，我们的运行示例中的数据不提供关于个体层面吸烟和非吸烟患癌风险如何相关的信息。因此，回答诸如“患癌吸烟者的非吸烟患癌风险是否低于未患癌吸烟者？”这样的问题，需要关于 \(\xi_i\) 中编码的特征如何转化为癌症结果的额外假设。如果没有这样的假设，要回答这个问题，我们需要观察在替代世界中不吸烟但患癌的吸烟者。因为反事实查询比较了个体在不同生成过程下本会如何发展，因此反事实查询通常被称为“跨世界”量。另一方面，干预查询只需要理解跨个体的潜在结果 \(Y_i(0)\) 和 \(Y_i(1)\) 的边缘分布；因此，个体层面不需要跨世界信息。

我们通过指出总结本节：反事实结果和潜在结果表示法在概念上通常很有用，即使它们不用于明确回答反事实查询。许多因果查询用潜在结果来形式化更直观。例如，“如果我更注重健康，我会吸烟吗？”可能比“同一总体中随机抽样的个体若接受使其更注重健康的干预，会吸烟吗？”更直观。事实上，一些因果推断学派使用潜在结果，而非 DAG，作为其主要概念构建块 [See IR15]。因果图和潜在结果都提供了表述干预查询和因果假设的方式。最终，这些在数学上是等价的。然而，在实践中，它们有不同的优势。The
