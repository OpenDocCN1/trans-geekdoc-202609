In Figure 17.1(c), we increase \(\beta_1\); this allows the first layer biases to get bigger, which allows the center of the sigmoid to shift left and right more, away from the origin. In Figure 17.1(d), we increase \(\alpha_2\); this allows the second layer linear weights to get bigger, making the functions more “wiggly” (greater sensitivity to change in the input, and hence larger dynamic range).

The above results are specific to the case of sigmoidal activation functions. ReLU units can behave differently. For example, [WI20, App. E] show that for MLPs with ReLU units, if we set \(\beta_\ell = 0\), so the bias terms are all zero, the effect of changing \(\alpha_\ell\) is just to rescale the output. To see this, note that Equation (17.9) simplifies to

```
\(f(\boldsymbol{x}; \boldsymbol{\alpha}, \boldsymbol{\beta} = \mathbf{0}) = \alpha_L \boldsymbol{\eta}_L (\cdots \varphi(\alpha_1 \boldsymbol{\eta}_1 \boldsymbol{x})) = \alpha_L \cdots \alpha_1 \boldsymbol{\eta}_L (\cdots \varphi(\boldsymbol{\eta}_1 \boldsymbol{x})) \quad (17.10)\)
\(= \alpha_L \cdots \alpha_1 f(\boldsymbol{x}; (\boldsymbol{\alpha} = \mathbf{1}, \boldsymbol{\beta} = \mathbf{0})) \quad (17.11)\)
```

where we used the fact that for ReLU, \(\varphi(\alpha z) = \alpha \varphi(z)\) for any positive \(\alpha\), and \(\varphi(\alpha z) = 0\) for any negative \(\alpha\) (since the preactivation \(z \ge 0\)). In general, it is the ratio of \(\alpha\) and \(\beta\) that matters for determining what happens to input signals as they propagate forwards and backwards through a randomly initialized model; for details, see e.g., [Bah+20].
