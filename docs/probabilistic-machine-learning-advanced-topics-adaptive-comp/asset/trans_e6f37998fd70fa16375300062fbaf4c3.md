

法则给出 \(\mathbf{J}(\mathbf{F}) = \mathbf{J}(\mathbf{F}_2)\mathbf{J}(\mathbf{F}_1)\)，其中 \(\mathbf{J}(\mathbf{F}_2)\) 是 \(D \times M\) 且 \(\mathbf{J}(\mathbf{F}_1)\) 是 \(M \times D\)。现在我们可以按如下方式应用行列式公式：
\(\det \mathbf{J}(\mathbf{f}) = \det(\mathbf{I}_D + \mathbf{J}(\mathbf{F})) = \det(\mathbf{I}_D + \mathbf{J}(\mathbf{F}_2)\mathbf{J}(\mathbf{F}_1)) = \det(\mathbf{I}_M + \mathbf{J}(\mathbf{F}_1)\mathbf{J}(\mathbf{F}_2)).\) (23.38)

由于最终行列式的代价为 \(O(M^3)\)，我们可以通过减少 \(M\) 来使雅各比行列式计算高效，也就是说，通过收窄瓶颈。

上述内容的一个例子是 [RM15] 的平面流。在此模型中，每个残差块是一个具有一个隐藏层和一个隐藏单元的 MLP。也就是说，
\(\mathbf{f}(\mathbf{u}) = \mathbf{u} + \mathbf{v}(\sigma(\mathbf{w}^\top \mathbf{u} + b)),\) (23.39)

其中 \(\mathbf{v} \in \mathbb{R}^D\)、\(\mathbf{w} \in \mathbb{R}^D\) 和 \(b \in \mathbb{R}\) 是参数，\(\sigma\) 是激活函数。残差块是 \(\mathbf{F}_1(\mathbf{u}) = \mathbf{w}^\top \mathbf{u} + b\) 和 \(\mathbf{F}_2(z) = \mathbf{v}\sigma(z)\) 的复合，因此 \(M = 1\)。它们的雅各比矩阵为 \(\mathbf{J}(\mathbf{F}_1)(\mathbf{u}) = \mathbf{w}^\top\) 和 \(\mathbf{J}(\mathbf{F}_2)(z) = \mathbf{v}\sigma'(z)\)。将这些代入雅各比行列式公式，我们得到：

\(\det \mathbf{J}(\mathbf{f})(\mathbf{u}) = 1 + \mathbf{w}^\top \mathbf{v} \sigma'(\mathbf{w}^\top \mathbf{u} + b),\) (23.40)

它可以在 \(O(D)\) 中高效计算。其他示例包括 [RM15] 的圆形流和 [Ber+18] 的 Sylvester 流。

这种技术为具有瓶颈的残差连接的行列式计算提供了一种高效方法，但一般来说无法保证此类函数是可逆的。这意味着可逆性必须逐个案例满足。例如，当 \(\sigma\) 是双曲正切且 \(\mathbf{w}^\top \mathbf{v} > -1\) 时，平面流是可逆的，但否则可能不是。

### 23.2.6 连续时间流

迄今，我们讨论的流是由一系列双射 \(\mathbf{f}_1, \dots, \mathbf{f}_N\) 组成的。从某个输入 \(\mathbf{x}_0 = \mathbf{u}\) 开始，这会创建一系列输出 \(\mathbf{x}_1, \dots, \mathbf{x}_N\)，其中 \(\mathbf{x}_n = \mathbf{f}_n(\mathbf{x}_{n-1})\)。但是，我们也可以有这样一种流：输入以连续的方式转换为最终输出。也就是说，我们从 \(\mathbf{x}_0 = \mathbf{x}(0)\) 开始，为 \(t \in [0, T]\) 和某个固定的 \(T\) 创建一个连续索引的序列 \(\mathbf{x}(t)\)，并将 \(\mathbf{x}(T)\) 视为最终输出。将 \(t\) 视为类似时间，我们称这些为连续时间流。

序列 \(\mathbf{x}(t)\) 定义为如下形式的一阶常微分方程（ODE）的解：
\(\frac{d\mathbf{x}}{dt}(t) = \mathbf{F}(\mathbf{x}(t), t).\) (23.41)

函数 \(\mathbf{F} : \mathbb{R}^D \times [0, T] \to \mathbb{R}^D\) 是一个时间相关的向量场，用于参数化 ODE。如果我们将 \(\mathbf{x}(t)\) 视为 \(D\) 维空间中粒子的位置，则向量 \(\mathbf{F}(\mathbf{x}(t), t)\) 决定了粒子在时间 \(t\) 时的速度。

（时间 \(T\) 的）流是一个函数 \(\mathbf{f} : \mathbb{R}^D \to \mathbb{R}^D\)，它接受输入 \(\mathbf{x}_0\)，求解初始条件为 \(\mathbf{x}(0) = \mathbf{x}_0\) 的 ODE，并返回 \(\mathbf{x}(T)\)。如果 ODE 的解在所有 \(t \in [0, T]\) 上都存在且唯一，则函数 \(\mathbf{f}\) 是一个定义明确的双射。这些条件对于任意 \(\mathbf{F}\) 通常不满足，但如果 \(\mathbf{F}(\cdot, t)\) 是 Lipschitz 连续且其 Lipschitz 常数不依赖于 \(t\)，则这些条件满足。也就是说，如果存在一个常数 \(L\)，使得对所有 \(\mathbf{x}_1, \mathbf{x}_2\) 和 \(t \in [0, T]\) 都有：

\(\|\mathbf{F}(\mathbf{x}_1, t) - \mathbf{F}(\mathbf{x}_2, t)\| \le L\|\mathbf{x}_1 - \mathbf{x}_2\|.\) (23.42)

这一结果是 ODE 的 **皮卡-林德勒夫定理** 的推论。$^3$ 在实践中，我们可以使用任何模型选择来参数化 \(\mathbf{F}\)，只要满足 Lipschitz 条件。

通常，ODE 无法解析求解，但我们可以通过离散化来近似求解。一个简单的例子是 **欧拉方法**，它对应于对某个小步长 \(\epsilon > 0\) 的以下离散化：

\(\mathbf{x}(t + \epsilon) = \mathbf{x}(t) + \epsilon \mathbf{F}(\mathbf{x}(t), t).\) (23.43)

这等效于具有残差块 \(\epsilon \mathbf{F}(\cdot, t)\) 的残差连接，因此 ODE 求解器可以被视为具有 \(O(T/\epsilon)\) 层的深度残差网络。较小的步长会导致更准确的解，但也会带来更多计算。还有几种其他求解方法，精度和复杂程度各异，例如更广泛的 Runge-Kutta 系列中的方法，其中一些使用自适应步长。

\(\mathbf{f}\) 的逆可以通过逆向求解 ODE 来轻松计算。也就是说，要计算 \(\mathbf{f}^{-1}(\mathbf{x}_T)\)，我们求解初始条件为 \(\mathbf{x}(T) = \mathbf{x}_T\) 的 ODE，并返回 \(\mathbf{x}(0)\)。与某些其他流（例如自回归流）不同，后者在一个方向上的计算比另一个方向更昂贵，连续时间流在两个方向上所需的计算量相同。

一般来说，\(\mathbf{f}\) 的雅各比行列式没有解析表达式。然而，我们可以将其表示为单独一个 ODE 的解，然后可以数值求解。首先，我们定义 \(\mathbf{f}_t : \mathbb{R}^D \to \mathbb{R}^D\) 为时间 \(t\) 的流，也就是说，它接受 \(\mathbf{x}_0\)，求解初始条件为 \(\mathbf{x}(0) = \mathbf{x}_0\) 的 ODE 并返回 \(\mathbf{x}(t)\)。显然，\(\mathbf{f}_0\) 是恒等函数，\(\mathbf{f}_T = \mathbf{f}\)。让我们定义 \(L(t) = \log |\det \mathbf{J}(\mathbf{f}_t)(\mathbf{x}_0)|\)。由于 \(\mathbf{f}_0\) 是恒等函数，\(L(0) = 0\)，并且由于 \(\mathbf{f}_T = \mathbf{f}\)，\(L(T)\) 给出了我们感兴趣的 \(\mathbf{f}\) 的雅各比行列式。可以证明 \(L\) 满足以下 ODE：

\(\frac{dL}{dt}(t) = \text{tr}[\mathbf{J}(\mathbf{F}(\cdot, t))(\mathbf{x}(t))].\) (23.44)

也就是说，\(L\) 在时间 \(t\) 时的变化率等于在 \(\mathbf{x}(t)\) 处评估的 \(\mathbf{F}(\cdot, t)\) 的雅各比痕迹。因此，我们可以通过求解初始条件为 \(L(0) = 0\) 的上述 ODE 来计算 \(L(T)\)。此外，我们可以将两个 ODE 合并为在扩展空间 \((\mathbf{x}, L)\) 上运行的单个 ODE，从而同时计算 \(\mathbf{x}(T)\) 和 \(L(T)\)。

连续时间流的一个例子是 [Che+18c] 的 **神经 ODE** 模型，它使用神经网络来参数化 \(\mathbf{F}\)。为了避免通过 ODE 求解器反向传播梯度（这在计算上可能要求很高），他们使用 **伴随灵敏度方法** 来将相对于 \(\mathbf{x}(t)\) 的梯度的时间演化表示为单独的 ODE。求解此 ODE 给出所需的梯度，并可以被视为反向传播的连续时间类比。

另一个例子是 [Gra+19] 的 **FFJORD** 模型。这与神经 ODE 模型类似，但它使用 Hutchinson 痕迹估计器来近似 \(\mathbf{F}(\cdot, t)\) 的雅各比痕迹。Hutchinson 痕迹估计器的这种用法与收缩残差流（第 23.2.5.1 节）中的用法类似，它以随机（但无偏）估计为代价加快了计算。

另请参见第 25.4.4 节，其中讨论了连续时间扩散模型。

## 23.3 应用

在本节中，我们将介绍流在经典概率机器学习任务中的一些应用。

### 23.3.1 密度估计

流模型允许精确的密度计算，并可用于将多模态密度拟合到观测数据。（有关示例，请参见图 23.3）。一个早期的例子是 Gaussianization [CG00]，它将这一想法应用于拟合低维密度。Tabak 和 Vanden-Eijnden [TVE10] 以及 Tabak 和 Turner [TT13] 引入了流的现代概念（包括“归一化流”这一术语），将流描述为更简单映射的复合。Deep density models [RA13] 是最早使用神经网络进行流来参数化高维密度的模型之一。此后出现了丰富的后续工作，包括 **NICE** [DKB15] 和 **Real NVP** [DSDB17]。（NVP 代表“非体积保持”，指的是变换的雅各比矩阵不为单位矩阵。）掩码自回归流（第 23.2.4.2 节）进一步提高了无条件和条件密度估计任务的性能。

流可用于 *混合模型*，该模型对输入和目标的联合密度 \(p(\boldsymbol{x}, y)\) 进行建模，而歧视性分类模型仅对条件密度 \(p(y|\boldsymbol{x})\) 进行建模，密度模型仅对边缘密度 \(p(\boldsymbol{x})\) 进行建模。Nalisnick 等人 [Nal+19b] 提出了一种基于流的混合模型，使用可逆映射进行表示学习，并表明联合密度 \(p(\boldsymbol{x}, y)\) 可以高效计算，这对于异常检测、半监督学习和选择性分类等下游任务非常有用。基于流的混合模型是内存高效的，因为大部分参数都在可逆表示中，该表示在歧视性模型和生成模型之间共享；此外，密度 \(p(\boldsymbol{x}, y)\) 可以在单次前向传递中计算，从而节省计算。Residual flows [Che+19] 使用可逆残差映射 [Beh+19] 进行混合建模，进一步提高了性能。流也被用于将密度拟合到嵌入式 [Zha+20b; CZG20] 以用于异常检测任务。

### 23.3.2 生成建模

另一项任务是生成，涉及从拟合模型 \(p^*(\boldsymbol{x})\) 生成新样本。生成是归一化流的流行下游任务，已应用于包括图像、视频、音频、文本以及图和点云等结构化对象在内的不同数据模态。图像可以说是深度生成模型中最受欢迎的模态：GLOW [KD18b] 是最早生成引人注目的高维图像的基于流的模型之一，并已扩展到视频以生成 RGB 帧 [Kum+19b]；Residual flows [Che+19] 也已被证明可以生成清晰的图像。

Oord 等人 [Oor+18] 使用流进行音频合成，通过将 WaveNet 蒸馏为 IAF（第 23.2.4.3 节），从而实现比 WaveNet 更快的采样。其他用于音频的流模型包括 WaveFLOW [PVC19] 和 FlowWaveNet [Kim+19]，它们直接使用耦合层加速 WaveNet。
