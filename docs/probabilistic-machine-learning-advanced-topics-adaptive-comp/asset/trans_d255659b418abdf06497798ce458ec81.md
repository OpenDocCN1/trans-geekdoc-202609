对于 3 个变量，MMI 由以下公式给出

\(\mathbb{I}(X; Y; Z) = \mathbb{I}(X; Y) - \mathbb{I}(X; Y|Z)\) (5.124)
\(= \mathbb{I}(X; Z) - \mathbb{I}(X; Z|Y)\) (5.125)
\(= \mathbb{I}(Y; Z) - \mathbb{I}(Y; Z|X)\) (5.126)

这可以解释为在条件设定为第三个变量时，两对变量之间互信息的变化。注意，该量关于其参数是对称的。

根据条件互信息的定义，我们有

\(\mathbb{I}(X; Z|Y) = \mathbb{I}(Z; X, Y) - \mathbb{I}(Y; Z)\) (5.127)

因此我们可以将方程 (5.125) 改写如下：

\(\mathbb{I}(X; Y; Z) = \mathbb{I}(X; Z) + \mathbb{I}(Y; Z) - \mathbb{I}(X, Y; Z)\) (5.128)

这告诉我们，MMI 是分别给定 X 和 Y 时关于 Z 所学到的内容与共同给定时的差异（另见 5.3.5.3 节）。

三路 MMI 在图 5.7 的信息图中得到说明。当我们有多个变量时，解释此类图示的方法如下：包含圆 A、B、C、... 且排除圆 F、G、H、... 的阴影区域的面积表示 \(\mathbb{I}(A; B; C; \dots | F, G, H, \dots)\)；如果 \(B = C = \emptyset\)，则这只是 \(\mathbb{I}(A|F, G, H, \dots)\)；如果 \(F = G = H = \emptyset\)，则这只是 \(\mathbb{I}(A; B; C, \dots)\)。

## 5.3.5.3 协同与冗余

MMI 为 \(\mathbb{I}(X; Y; Z) = \mathbb{I}(X; Z) + \mathbb{I}(Y; Z) - \mathbb{I}(X, Y; Z)\)。我们看到这可以是正数、零或负数。如果 X 关于 Z 提供的某些信息也由 Y 提供，那么 X 和 Y 之间存在一些 **冗余**（关于 Z）。在这种情况下，\(\mathbb{I}(X; Z) + \mathbb{I}(Y; Z) > \mathbb{I}(X; Y; Z)\)，因此（根据方程 (5.128)）我们看到 MMI 将为正数。相比之下，如果我们在共同观察 X 和 Y 时了解更多关于 Z 的信息，我们说它们之间存在一些 **协同**。在这种情况下，\(\mathbb{I}(X; Z) + \mathbb{I}(Y; Z) < \mathbb{I}(X; Y; Z)\)，因此 MMI 将为负数。

## 5.3.5.4 MMI 与因果性

MMI 的符号可用于区分不同类型的有向图模型，这些模型有时可以进行因果解释（关于因果性的一般讨论见第 36 章）。例如，考虑形式为 \(X \leftarrow Z \rightarrow Y\) 的模型，其中 Z 是 X 和 Y 的一个 "原因"。例如，假设 X 表示下雨事件，Y 表示天空变黑事件，Z 表示天空多云事件。对共同原因 Z 进行条件设定使得子变量 X 和 Y 独立，因为如果我知道天空多云，注意到天空变黑并不会改变我对是否会下雨的信念。因此 \(\mathbb{I}(X;Y|Z) \le \mathbb{I}(X;Y)\)，所以 \(\mathbb{I}(X;Y;Z) \ge 0\)。

现在考虑 Z 是共同效应的情况，\(X \rightarrow Z \leftarrow Y\)。在这种情况下，对 Z 进行条件设定会使 X 和 Y 相关，这是由于“解释消失”现象（参见 4.2.4.2 节）。例如，如果 X 和 Y 是独立随机比特，而 Z 是 X 和 Y 的异或，那么观察到 Z = 1 意味着 \(p(X \neq Y|Z = 1) = 1\)，因此 X 和 Y 现在相关（从信息论角度，而非因果角度），尽管它们先验上是独立的。因此 \(\mathbb{I}(X;Y|Z) \ge \mathbb{I}(X;Y)\)，所以 \(\mathbb{I}(X;Y;Z) \le 0\)。

最后，考虑马尔可夫链 \(X \rightarrow Y \rightarrow Z\)。我们有 \(\mathbb{I}(X;Z|Y) \le \mathbb{I}(X;Z)\)，因此 MMI 必须为正。

## 5.3.5.5 MMI 与熵

我们也可以用熵来表示 MMI。具体来说，我们知道

```
\(\mathbb{I}(X;Y) = \mathbb{H}(X) + \mathbb{H}(Y) - \mathbb{H}(X,Y)\) (5.129)
```

和

```
\(\mathbb{I}(X;Y|Z) = \mathbb{H}(X,Z) + \mathbb{H}(Y,Z) - \mathbb{H}(Z) - \mathbb{H}(X,Y,Z)\) (5.130)
```

因此我们可以将方程 (5.124) 改写如下：

```
\(\mathbb{I}(X;Y;Z) = [\mathbb{H}(X) + \mathbb{H}(Y) + \mathbb{H}(Z)] - [\mathbb{H}(X,Y) + \mathbb{H}(X,Z) + \mathbb{H}(Y,Z)] + \mathbb{H}(X,Y,Z)\) (5.131)
```

这与方程 (5.121) 形成对比。

更一般地，我们有

```
\(\mathbb{I}(X_1,\dots,X_D) = - \sum_{\mathcal{T} \subseteq \{1,\dots,D\}} (-1)^{|\mathcal{T}|} \mathbb{H}(\mathcal{T})\) (5.132)
```

对于大小为 1、2 和 3 的集合，这将展开为：

```
\(I_1 = H_1\) (5.133)

\(I_{12} = H_1 + H_2 - H_{12}\) (5.134)

\(I_{123} = H_1 + H_2 + H_3 - H_{12} - H_{13} - H_{23} + H_{123}\) (5.135)
```

我们可以使用 **莫比乌斯反演公式** 来推导以下对偶关系：

```
\(\mathbb{H}(\mathcal{S}) = - \sum_{\mathcal{T} \subseteq \mathcal{S}} (-1)^{|\mathcal{T}|} \mathbb{I}(\mathcal{T})\) (5.136)
```
针对变量集合 $\mathcal{S}$。

利用熵的链式法则，我们还可以推导出 3 路 MMI 的以下表达式：

\(\mathbb{I}(X; Y; Z) = \mathbb{H}(Z) - \mathbb{H}(Z|X) - \mathbb{H}(Z|Y) + \mathbb{H}(Z|X, Y)\) (5.137)

## 5.3.6 互信息的变分边界

在本节中，我们讨论计算 MI 上界和下界的方法，这些方法使用对不可处理分布的变分近似。这对于表示学习（第 32 章）可能很有用。该方法最初在 [BA03] 中提出。有关互信息变分边界的更详细概述，请参见 Poole et al. [Poo+19b]。

### 5.3.6.1 上界

假设联合分布 \(p(x, y)\) 不可处理，但我们可以从 \(p(x)\) 采样并计算条件分布 \(p(y|x)\)。此外，假设我们用 \(q(y)\) 近似 \(p(y)\)。那么我们可以按如下方式计算 MI 的上界：

```
\(\mathbb{I}(x; y) = \mathbb{E}_{p(x, y)} \left[ \log \frac{p(y|x)q(y)}{p(y)q(y)} \right]\) (5.138)

\(= \mathbb{E}_{p(x, y)} \left[ \log \frac{p(y|x)}{q(y)} \right] - D_{\text{KL}}(p(y) \parallel q(y))\) (5.139)

\(\le \mathbb{E}_{p(x)} \left[ \mathbb{E}_{p(y|x)} \left[ \log \frac{p(y|x)}{q(y)} \right] \right]\) (5.140)

\(= \mathbb{E}_{p(x)} [D_{\text{KL}}(p(y|x) \parallel q(y))]\) (5.141)
```

如果 \(q(y) = p(y)\)，则该边界是紧的。

这里发生的情况是 \(\mathbb{I}(Y; X) = \mathbb{H}(Y) - \mathbb{H}(Y|X)\)，并且我们假设知道 \(p(y|x)\)，因此可以很好地估计 \(\mathbb{H}(Y|X)\)。虽然我们不知道 \(\mathbb{H}(Y)\)，但可以使用某个模型 \(q(y)\) 对其进行上界估计。我们的模型永远无法比 \(p(y)\) 本身做得更好（KL 的非负性），因此我们的熵估计偏大，从而我们的 MI 估计将是一个上界。

### 5.3.6.2 BA 下界

假设联合分布 \(p(x, y)\) 不可处理，但我们可以计算 \(p(x)\)。此外，假设我们用 \(q(x|y)\) 近似 \(p(x|y)\)。那么我们可以推导出互信息的以下变分下界：

```
\(\mathbb{I}(x; y) = \mathbb{E}_{p(x, y)} \left[ \log \frac{p(x|y)}{p(x)} \right]\) (5.142)

\(= \mathbb{E}_{p(x, y)} \left[ \log \frac{q(x|y)}{p(x)} \right] + \mathbb{E}_{p(y)} [D_{\text{KL}}(p(x|y) \parallel q(x|y))]\) (5.143)

\(\ge \mathbb{E}_{p(x, y)} \left[ \log \frac{q(x|y)}{p(x)} \right] = \mathbb{E}_{p(x, y)} [\log q(x|y)] + h(x)\) (5.144)
```

其中 \(h(x)\) 是 \(x\) 的微分熵。这被称为 **BA 下界**，以作者 Barber 和 Agakov [BA03] 命名。

### 5.3.6.3 NWJ 下界

BA 下界需要一个可处理的归一化分布 $q(\boldsymbol{x}|\boldsymbol{y})$，我们可以对其进行逐点计算。如果我们以巧妙的方式重参数化此分布，就可以生成一个不需要归一化分布的下界。让我们写：

$q(\boldsymbol{x}|\boldsymbol{y}) = \frac{p(\boldsymbol{x})e^{f(\boldsymbol{x}, \boldsymbol{y})}}{Z(\boldsymbol{y})}$ (5.145)

其中 $Z(\boldsymbol{y}) = \mathbb{E}_{p(\boldsymbol{x})}[e^{f(\boldsymbol{x}, \boldsymbol{y})}]$ 是归一化常数或配分函数。将其代入上述 BA 下界，我们得到：

$\mathbb{E}_{p(\boldsymbol{x}, \boldsymbol{y})} \left[ \log \frac{p(\boldsymbol{x})e^{f(\boldsymbol{x}, \boldsymbol{y})}}{p(\boldsymbol{x})Z(\boldsymbol{y})} \right] = \mathbb{E}_{p(\boldsymbol{x}, \boldsymbol{y})} [f(\boldsymbol{x}, \boldsymbol{y})] - \mathbb{E}_{p(\boldsymbol{y})} [\log Z(\boldsymbol{y})]$ (5.146)
$= \mathbb{E}_{p(\boldsymbol{x}, \boldsymbol{y})} [f(\boldsymbol{x}, \boldsymbol{y})] - \mathbb{E}_{p(\boldsymbol{y})} \left[ \log \mathbb{E}_{p(\boldsymbol{x})} [e^{f(\boldsymbol{x}, \boldsymbol{y})}] \right]\) (5.147)
$\triangleq I_{DV}(X; Y).$ (5.148)

这是 **Donsker-Varadhan** 下界 [DV75]。

我们可以利用对数函数可以用直线上界来构建一个更可处理的版本：

$\log x \le \frac{x}{a} + \log a - 1$ (5.149)

如果设置 $a = e$，则得到

$\mathbb{I}(X; Y) \ge \mathbb{E}_{p(\boldsymbol{x}, \boldsymbol{y})}[f(\boldsymbol{x}, \boldsymbol{y})] - e^{-1} \mathbb{E}_{p(\boldsymbol{y})} Z(\boldsymbol{y}) \triangleq I_{NWJ}(X; Y)$ (5.150)

这被称为 **NWJ 下界**（以作者 Nguyen、Wainwright 和 Jordan [NWJ10a] 命名），或 f-GAN KL [NCT16a]，或 MINE-f 分数 [Bel+18]。

### 5.3.6.4 InfoNCE 下界

如果我们对上述 DV 边界进行多样本扩展，则可以生成以下下界（推导过程见 [Poo+19b]）：

$\mathbb{I}_{\text{NCE}} = \mathbb{E} \left[ \frac{1}{K} \sum_{i=1}^K \log \frac{e^{f(\boldsymbol{x}_i, \boldsymbol{y}_i)}}{\frac{1}{K} \sum_{j=1}^K e^{f(\boldsymbol{x}_j, \boldsymbol{y}_i)}} \right]$ (5.151)
$= \log K - \mathbb{E} \left[ \frac{1}{K} \sum_{i=1}^K \log \left( 1 + \sum_{j \neq i} e^{f(\boldsymbol{x}_j, \boldsymbol{y}_i) - f(\boldsymbol{x}_i, \boldsymbol{y}_i)} \right) \right]$ (5.152)

其中期望是关于来自联合分布 $p(X, Y)$ 的配对样本取的。方程 (5.152) 中的量称为 **InfoNCE** 估计值，并已在 [OLV18a; Hen+19a] 中提出。（NCE 代表“噪声对比估计”，在 24.4 节中讨论。）

这里的直觉是，互信息是联合分布 $p(\boldsymbol{x}, \boldsymbol{y})$ 与边缘分布乘积 $p(\boldsymbol{x})p(\boldsymbol{y})$ 之间的散度。换句话说，互信息是测量两者之间有多少
