

## 24.2.2.2 持续性对比差异

有时表现更好的 CD 变体是 **持续性对比差异**（PCD）[Tie08; TH09; You99]。在这种方法中，采用带有持续状态的单个 MCMC 链来从 EBM 中采样。在 PCD 中，我们在对新数据点进行训练时不会重新启动 MCMC 链；相反，我们会继承上一条 MCMC 链的状态，并用它来初始化下一步训练的新 MCMC 链。请参见第 12 行的伪代码。因此，有两个在不同时间尺度上运行的动态过程：状态 \(\mathbf{x}\) 变化很快，而参数 \(\boldsymbol{\theta}\) 变化缓慢。

```
Algorithm 24.2: Persistent MCMC-SGD for fitting an EBM
1 Initialize parameters \(\boldsymbol{\theta}\) randomly
2 Initialize chains \(\tilde{\mathbf{x}}_{1:S}\) randomly
3 Initialize learning rate \(\eta\)
4 for \(t = 1, 2, \dots\) do
5   for \(\mathbf{x}_b\) in minibatch of size \(B\) do
6     \(\mathbf{g}_b = \nabla_{\boldsymbol{\theta}}\mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x}_b)\)
7   for sample \(s = 1 : S\) do
8     Sample \(\tilde{\mathbf{x}}_s \sim\) MCMC(target \(= p(\cdot|\boldsymbol{\theta})\), init \(= \tilde{\mathbf{x}}_s\), nsteps \(= N\))
9     \(\tilde{\mathbf{g}}_s = \nabla_{\boldsymbol{\theta}}\mathcal{E}_{\boldsymbol{\theta}}(\tilde{\mathbf{x}}_s)\)
10  \(\mathbf{g}_t = -(\frac{1}{B}\sum_{b=1}^B \mathbf{g}_b) - (\frac{1}{S}\sum_{s=1}^S \tilde{\mathbf{g}}_s)\)
11  \(\boldsymbol{\theta} := \boldsymbol{\theta} + \eta\mathbf{g}_t\)
12  Decrease step size \(\eta\)
```

[You89] 为此提供了理论依据，表明我们可以从 MCMC 链的前一个值开始，只需进行几步，因为 \(p(\mathbf{x}|\boldsymbol{\theta}_t)\) 很可能接近 \(p(\mathbf{x}|\boldsymbol{\theta}_{t-1})\)，因为在中间的 SGD 步骤中我们只对参数进行了微小更改。

## 24.2.2.3 其他方法

PCD 可以通过在重放缓冲区中保留 MCMC 链的多个历史状态，并通过从中随机采样来初始化新的 MCMC 链而进一步改进 [DM19b]。CD 的其他变体包括均匀场 CD [WH02] 和多网格 CD [Gao+18]。

用 CD 训练的 EBM 可能无法忠实捕捉数据分布，因为截断 MCMC 可能导致有偏梯度更新，从而损害学习动力学 [SMB10; FI10; Nij+19]。有几种方法专注于消除这种偏差，以改进 MCMC 训练。例如，一类工作提出通过耦合 MCMC 对梯度进行无偏估计 [JOA17; QZW19]；Du 等人 [Du+20] 提出通过对 MCMC 采样算法求导并估计熵修正项来减少偏差。

## 24.3 分数匹配（SM）

如果两个连续可微的实值函数 \(f(\mathbf{x})\) 和 \(g(\mathbf{x})\) 在所有地方的第一阶导数相等，则 \(f(\mathbf{x}) \equiv g(\mathbf{x}) + \text{常数}\)。当 \(f(\mathbf{x})\) 和 \(g(\mathbf{x})\) 为具有相同第一阶导数的对数概率密度函数（pdf）时，归一化要求（公式 (24.1)）意味着 \(\int \exp(f(\mathbf{x})) d\mathbf{x} = \int \exp(g(\mathbf{x})) d\mathbf{x} = 1\)，因此 \(f(\mathbf{x}) \equiv g(\mathbf{x})\)。结果是，可以通过（近似）匹配其 log-pdf 的第一阶导数与数据分布的 log pdf 的第一阶导数来学习 EBM。如果它们匹配，则 EBM 精确捕获数据分布。对数 pdf 关于其输入的第一阶梯度函数 \(\nabla_x \log p_\theta(\mathbf{x})\) 被称为（Stein）**得分**函数。（这与 Fisher 得分 \(\nabla_\theta \log p_\theta(\mathbf{x})\) 不同。）对于训练 EBM，将分布的等价性转换为得分的等价性很有用，因为 EBM 的得分可以按以下方式轻松获得：

\(s_\theta(\mathbf{x}) \triangleq \nabla_\mathbf{x} \log p_\theta(\mathbf{x}) = -\nabla_\mathbf{x} \mathcal{E}_\theta(\mathbf{x})\) (24.27)

可以看出，这不涉及通常难以处理的归一化常数 \(Z_\theta\)。令 \(p_D(\mathbf{x})\) 为底层数据分布，我们从中拥有有限数量的 iid 样本但不知道其 pdf。**分数匹配** 目标 [Hyv05] 最小化两个分布之间称为 **Fisher 偏差** 的差异：

\(D_F(p_D(\mathbf{x}) \| p_\theta(\mathbf{x})) = \mathbb{E}_{p_D(\mathbf{x})} \left[ \frac{1}{2} \| \nabla_\mathbf{x} \log p_D(\mathbf{x}) - \nabla_\mathbf{x} \log p_\theta(\mathbf{x}) \|^2 \right].\) (24.28)

关于 \(p_D(\mathbf{x})\) 的期望，在此目标及其下方的变体中，可以使用样本 \(\mathbf{x} \sim p_D(\mathbf{x})\) 的经验均值得到一个平凡的无偏蒙特卡洛估计量。然而，公式 (24.28) 的第二项 \(\nabla_\mathbf{x} \log p_D(\mathbf{x})\) 通常不切实际，因为它需要知道 \(p_D(\mathbf{x})\) 的 pdf。我们将在下面讨论一个解决方案。

### 24.3.1 基础分数匹配

Hyvärinen [Hyv05] 表明，在某些正则性条件下，Fisher 偏差可以通过分部积分重新编写，用 \(\mathcal{E}_\theta(\mathbf{x})\) 的二阶导数替换 \(p_D(\mathbf{x})\) 未知的一阶导数：

\(D_F(p_D(\mathbf{x}) \| p_\theta(\mathbf{x})) = \mathbb{E}_{p_D(\mathbf{x})} \left[ \frac{1}{2} \sum_{i=1}^d \left( \frac{\partial \mathcal{E}_\theta(\mathbf{x})}{\partial x_i} \right)^2 - \frac{\partial^2 \mathcal{E}_\theta(\mathbf{x})}{\partial x_i^2} \right] + \text{constant}\) (24.29)
\(= \mathbb{E}_{p_D(\mathbf{x})} \left[ \frac{1}{2} \| s_\theta(\mathbf{x}) \|^2 + \text{tr}(\mathbf{J}_\mathbf{x} s_\theta(\mathbf{x})) \right] + \text{constant}\) (24.30)

其中 \(d\) 是 \(\mathbf{x}\) 的维度，\(\mathbf{J}_\mathbf{x} s_\theta(\mathbf{x})\) 是得分函数的雅可比矩阵。常数不影响优化，因此在训练时可以舍弃。[Hyv05] 表明，基于分数匹配的估计量在某些正则性条件下是一致的，这意味着通过最小化公式 (24.28) 得到的参数估计量在无限数据极限下会收敛到真实参数。示例请参见图 25.5。

目标公式 (24.30) 的一个重要缺点是计算雅可比矩阵的迹需要 \(O(d^2)\) 的时间。因此，公式 (24.30) 的隐式 SM 表述仅应用于相对简单的能量函数，其中二阶导数的计算是可处理的。

分数匹配假设在空间上具有正密度的连续数据分布，但它可以推广到离散或有界 pdf 数据分布 [Hyv07b; Lyu12]。还可以考虑超出一阶导数的对数 pdf 的高阶梯度 [PDL+12]。

### 24.3.2 去噪分数匹配（DSM）

公式 (24.30) 中的分数匹配目标对 log p_D(x) 要求多个正则性条件，例如，它应该在各处连续可微且有限。然而，这些条件在实践中可能并不总是成立。例如，数字图像的分布通常是离散且有界的，因为像素值限制在范围 {0, 1, ..., 255} 中。因此，在这种情况下 log p_D(x) 是不连续的，并且在范围外为负无穷，因此 SM 不直接适用。

为缓解此问题，可以向每个数据点添加少量噪声：x̃ = x + ϵ。只要噪声分布 p(ϵ) 是平滑的，所产生的带噪数据分布 q(x̃) = ∫ q(x̃ | x)p_D(x)dx 也是平滑的，因此 Fisher 偏差 D_F(q(x̃) || p_θ(x̃)) 是一个合适的目标。[KL10] 表明，带噪数据的目标可以由公式 (24.30) 中的无噪分数匹配目标加上一个正则化项来近似；这种正则化使分数匹配适用于更广泛的数据分布，但仍需要昂贵的二阶导数。

[Vin11] 通过证明以下内容，为上述难题提出了一种优雅且可扩展的解决方案：

```
D_F(q(\tilde{\mathbf{x}}) \parallel p_{\boldsymbol{\theta}}(\tilde{\mathbf{x}})) = \mathbb{E}_{q(\tilde{\mathbf{x}})} \left[ \frac{1}{2} \| \nabla_{\mathbf{x}} \log p_{\boldsymbol{\theta}}(\tilde{\mathbf{x}}) - \nabla_{\mathbf{x}} \log q(\tilde{\mathbf{x}}) \|_2^2 \right]
```

```
= \mathbb{E}_{q(\mathbf{x}, \tilde{\mathbf{x}})} \left[ \frac{1}{2} \| \nabla_{\mathbf{x}} \log p_{\boldsymbol{\theta}}(\tilde{\mathbf{x}}) - \nabla_{\mathbf{x}} \log q(\tilde{\mathbf{x}}|\mathbf{x}) \|_2^2 \right] + \text{constant}
```

```
= \frac{1}{2} \mathbb{E}_{q(\mathbf{x}, \tilde{\mathbf{x}})} \left[ \left\| \mathbf{s}_{\boldsymbol{\theta}}(\tilde{\mathbf{x}}) + \frac{(\tilde{\mathbf{x}} - \mathbf{x})}{\sigma^2} \right\|_2^2 \right]
```

其中 \(\mathbf{s}_{\boldsymbol{\theta}}(\tilde{\mathbf{x}}) = \nabla_{\mathbf{x}} \log p_{\boldsymbol{\theta}}(\tilde{\mathbf{x}})\) 是估计的得分函数，且

```
\nabla_{\mathbf{x}} \log q(\tilde{\mathbf{x}}|\mathbf{x}) = \nabla_{\mathbf{x}} \log \mathcal{N}(\tilde{\mathbf{x}}|\mathbf{x}, \sigma^2 \mathbf{I}) = \frac{(\tilde{\mathbf{x}} - \mathbf{x})}{\sigma^2}
```

期望可以通过从 p_D(x) 采样然后采样噪声项 x̃ 来近似。（常数项不影响优化，可以忽略而不改变最优解。）

[Vin11] 将这种估计方法称为去噪分数匹配（DSM）。Raphan 和 Simoncelli [RS07; RS11] 也探索了类似的表述，并可以追溯到 Tweedie 公式（补充部分 3.3）和 Stein 的无偏风险估计 [Ste81]。
