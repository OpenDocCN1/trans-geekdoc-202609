

它具有封闭形式更新

```
$$\boldsymbol{e}_i = \frac{1}{n_i} \sum_{j=1}^{n_i} \boldsymbol{z}_{i,j} \tag{21.80}$$
```

这类似于在拟合高斯混合模型（GMM）的均值向量时 EM 算法的 M 步。在小批量设置中，我们将上述操作替换为指数移动平均，如下所示：

```
$$N_i^t = \gamma N_i^{t-1} + (1 - \gamma)n_i^t \tag{21.81}$$ 
$$\boldsymbol{m}_i^t = \gamma \boldsymbol{m}_i^{t-1} + (1 - \gamma) \sum_j \boldsymbol{z}_{i,j}^t \tag{21.82}$$ 
$$\boldsymbol{e}_i^t = \frac{\boldsymbol{m}_i^t}{N_i^t} \tag{21.83}$$
```

作者发现 $\gamma = 0.9$ 效果良好。

上述过程将学习更新码本向量，使其与编码器输出匹配。同样重要的是，要确保编码器不会过于频繁地“改变主意”决定使用哪个码本值。为防止这种情况，作者建议在损失中添加第三项，称为 **承诺损失**，以鼓励编码器输出接近码本值。因此，我们得到最终损失：

```
$$\mathcal{L} = -\log p(\boldsymbol{x}|\boldsymbol{z}_q(\boldsymbol{x})) + ||\text{sg}(\boldsymbol{z}_e(\boldsymbol{x})) - \boldsymbol{e}||_2^2 + \beta ||\boldsymbol{z}_e(\boldsymbol{x}) - \text{sg}(\boldsymbol{e})||_2^2 \tag{21.84}$$
```

作者发现 $\beta = 0.25$ 效果良好，当然，该值取决于重建损失（NLL）项的规模。（该损失的概率解释可以在 [Hen+18] 中找到。）总体而言，解码器仅优化第一项，编码器优化第一项和最后一项，嵌入向量优化中间项。

### 21.6.3 学习先验

训练 VQ-VAE 模型后，可以学习一个更好的先验，以匹配聚合后验。为此，我们只需将编码器应用于一组数据 \(\{\boldsymbol{x}_n\}\)，从而将它们转换为离散序列 \(\{\boldsymbol{z}_n\}\)。然后，我们可以使用任何类型的序列模型来学习联合分布 \(p(\boldsymbol{z})\)。在原始 VQ-VAE 论文 [OVK17] 中，他们使用了因果卷积 PixelCNN 模型（第 22.3.2 节）。更近期的工作使用了 Transformer 解码器（第 22.4 节）。然后可以使用 VQ-VAE 模型的解码器部分对来自此先验的样本进行解码。我们将在下面的章节中给出一些示例。

### 21.6.4 分层扩展（VQ-VAE-2）

在 [ROV19] 中，他们通过使用分层潜在代码扩展了原始 VQ-VAE 模型。该模型如图 21.17 所示。他们将此应用于大小为 $256 \times 256 \times 3$ 的图像。第一个潜在层将其映射为大小为 $64 \times 64$ 的量化表示，第二个潜在层将其映射为大小为 $32 \times 32$ 的量化表示。这种分层方案允许顶层专注于图像的高层语义，将纹理等精细视觉细节留给底层。（有关分层 VAE 的更多讨论，请参见第 21.5 节。）

### 21.6.5 离散 VAE

在 VQ-VAE 中，我们对潜在变量使用 one-hot 编码，即 \(q(z = k|\mathbf{x}) = 1\) 当且仅当 \(k = \text{argmin}_k ||\mathbf{z}_e(\mathbf{x}) - \mathbf{e}_k||_2\)，然后设置 \(\mathbf{z}_q = \mathbf{e}_k\)。这不会捕捉潜在代码中的任何不确定性，并且训练需要使用直通估计器。

人们已经研究了各种其他拟合具有离散潜在代码的 VAE 的方法。在 DALL-E 论文（第 22.4.2 节）中，他们使用了一种相当简单的方法，基于对离散变量使用 Gumbel-softmax 松弛（参见第 6.3.6 节）。简而言之，让 \(q(z = k|\mathbf{x})\) 成为将输入 \(\mathbf{x}\) 分配给码本条目 \(k\) 的概率。我们可以通过计算 \(w_k = \text{argmax}_k g_k + \log q(z = k|\mathbf{x})\) 从此准确地采样 \(w_k \sim q(z = k|\mathbf{x})\)，其中每个 \(g_k\) 服从 Gumbel 分布。我们现在可以通过使用带有温度 \(\tau > 0\) 的 softmax 并计算来“松弛”这一点：

```
\(w_k = \frac{\exp\left(\frac{g_k + \log q(z=k|\mathbf{x})}{\tau}\right)}{\sum_{j=1}^K \exp\left(\frac{g_j + \log q(z=j|\mathbf{x})}{\tau}\right)}\) (21.85)
```

我们现在将潜在代码设置为码本向量的加权和：

```
\(\mathbf{z}_q = \sum_{k=1}^K w_k \mathbf{e}_k\) (21.86)
```

当 \(\tau \to 0\) 时，权重 \(\mathbf{w}\) 的分布收敛为 one-hot 分布，在这种情况下，\(\mathbf{z}\) 将等于码本条目之一。但对于有限 \(\tau\)，我们在向量之间“填充”空间。

![](img/ca72c1626f4850f058a9edc138c1ac73_840_0.png)

图 21.18：VQ-GAN 示意图。改编自 [ERO21] 的图 2。经 Patrick Esser 友好授权使用。

这使我们能够以通常的可微方式表示 ELBO：

```
$$\mathcal{L} = -\mathbb{E}_{q(\mathbf{z}|\mathbf{x})} [\log p(\mathbf{x}|\mathbf{z})] + \beta D_{\text{KL}} (q(\mathbf{z}|\mathbf{x}) \| p(\mathbf{z}))$$ (21.87)
```

其中 $\beta > 0$ 控制正则化的量。（与 VQ-VAE 不同，KL 项不是常数，因为编码器是随机的。）此外，由于 Gumbel 噪声变量是从与编码器参数独立的分布中采样的，我们可以使用重参数化技巧（第 6.3.5 节）来优化这一点。

### 21.6.6 VQ-GAN

VQ-VAE 的一个缺点是，它在重建损失中使用均方误差，这可能导致样本模糊。在 VQ-GAN 论文 [ERO21] 中，他们用（分块）GAN 损失（参见第 26 章）替换了这一点，并结合感知损失；这导致了更高的视觉保真度。此外，他们使用 Transformer（参见第 16.3.5 节）来对潜在代码的先验进行建模。有关整体模型的可视化，请参见图 21.18。在 [Yu+21] 中，他们用 Transformer 替换了 VQ-GAN 模型的 CNN 编码器和解码器，从而取得了改进的结果；他们称之为 VIM（矢量量化图像建模）。

## 22 自回归模型

### 22.1 引言

根据概率链式法则，我们可以将 $T$ 个变量上的任何联合分布写成如下形式：

$p(x_{1:T}) = p(x_1)p(x_2|x_1)p(x_3|x_2, x_1)p(x_4|x_3, x_2, x_1) \dots = \prod_{t=1}^T p(x_t|x_{1:t-1})$ (22.1)

其中 $x_t \in \mathcal{X}$ 是第 $t$ 个观测值，我们定义 $p(x_1|x_{1:0}) = p(x_1)$ 为初始状态分布。这称为 **自回归模型** 或 **ARM**。这对应于一个完全连接的 DAG，其中每个节点依赖于顺序中的所有前驱节点，如图 22.1 所示。模型还可以条件化于任意输入或上下文 $\mathbf{c}$，以定义 $p(x|c)$，但为了记号简洁，我们省略了这一点。

我们当然也可以按时间“逆向”分解联合分布，使用

$p(x_{1:T}) = \prod_{t=T}^1 p(x_t|x_{t+1:T})$ (22.2)

然而，这种“反因果”方向通常更难学习（例如，参见 [PJS17]）。

尽管方程 (22.1) 中的分解是通用的，但此表达式中的每一项（即，每个条件分布 $p(x_t|x_{1:t-1})$）都会变得越来越复杂，因为它依赖于越来越多的参数，这使得计算这些项变得缓慢，并使得估计它们的参数更加渴求数据（参见第 2.6.3.2 节）。

解决这种不可计算性的一种方法是做出（一阶）**马尔可夫假设**，这产生了一个 **马尔可夫模型** $p(x_t|x_{1:t-1}) = p(x_t|x_{t-1})$，我们将在第 2.6 节讨论。（这也称为一阶自回归模型。）不幸的是，马尔可夫假设非常局限。放松它的一种方法，并使 $x_t$ 依赖于所有过去的 $x_{1:t-1}$ 而无需显式回归它们，是假设过去可以被压缩为一个 **隐藏状态** $z_t$。如果 $z_t$ 是过去观测值 $x_{1:t-1}$ 的确定性函数，则生成的模型称为 **循环神经网络**，在第 16.3.4 节讨论。如果 $z_t$ 是过去隐藏状态 $z_{t-1}$ 的随机函数，则生成的模型称为 **隐马尔可夫模型**，我们将在第 29.2 节讨论。

另一种方法是坚持使用方程 (22.1) 中的通用 AR 模型，但对条件分布 $p(x_t|x_{1:t-1})$ 使用受限函数形式，例如某种神经网络。因此，与其做出条件独立性假设，或将过去显式压缩为充分统计量，
