## 4.5.2 在有向模型和无向模型之间转换

尽管 DPGMs 和 UPGMs 通常不等价，但如果我们愿意允许图编码的 CI 属性少于实际成立的属性，则可以安全地将一种转换为另一种，如下文所述。

### 4.5.2.1 将 DPGM 转换为 UPGM

我们可以按如下方式轻松将 DPGM 转换为 UPGM。首先，任何共享子节点的“未婚”父母必须通过在它们之间添加边来“结婚”；此过程称为 **道德化**。然后我们可以删除箭头，得到一个无向图。之所以需要这样做，是为了确保 UGM 的 CI 属性与 DGM 匹配，如第 4.3.6.2 节所述。它还确保存在一个团，可以“存储”每个家族的 CPD。

让我们考虑 [KF09a] 中的一个示例。我们将使用图 4.38(a) 中所示学生网络的完整版本。相应的联合分布形式如下：

```
P(C, D, I, G, S, L, J, H) (4.149)
```

```
= P(C)P(D|C)P(I)P(G|I, D)P(S|I)P(L|G)P(J|L, S)P(H|G, J) (4.150)
```

接下来，我们为每个 CPD 定义一个势或因子，得到

```
p(C, D, I, G, S, L, J, H) = \psi_C(C)\psi_D(D, C)\psi_I(I)\psi_G(G, I, D) (4.151)
```

```
\psi_S(S, I)\psi_L(L, G)\psi_J(J, L, S)\psi_H(H, G, J) (4.152)
```

所有势都是 **局部归一化** 的，因为它们是 CPD，因此不需要全局归一化常数，所以 Z = 1。相应的无向图显示于图 4.38(b)。我们可以看到，我们添加了 D-I、G-J 和 L-S 的道德化边。11

### 4.5.2.2 将 UPGM 转换为 DPGM

要将 UPGM 转换为 DPGM，我们按如下方式进行。对于每个势函数 ψ_c(x_c; θ_c)，我们创建一个“虚拟节点”，称为 Y_c，它被“钳位”到一个特殊的观察状态，称为 y_c^*。然后我们定义 p(Y_c = y_c^* | x_c) = ψ_c(x_c; θ_c)。这个“局部证据”CPD 编码了与 DGM 中相同的因子。总联合分布的形式为 p_undir(x) ∝ p_dir(x, y^*)。

举个例子，考虑图 4.39(a) 中的 UPGM，它定义了联合分布 p(A, B, C, D) = ψ(A, B, C, D)/Z。我们可以通过添加一个虚拟 E 节点（作为所有其他节点的子节点）将其表示为 DPGM。我们设置 E = 1 并定义 CPD p(E = 1|A, B, C, D) ∝ ψ(A, B, C, D)。通过对这个观察子节点进行条件化，所有父节点都变得依赖，如同在 UGM 中一样。

### 4.5.3 有向条件模型与无向条件模型以及标签偏置问题

有向模型和无向模型在条件（判别）设置下的行为略有不同。为此，让我们比较图 4.40a 中的一维无向 CRF 与图 4.40b 中的有向马尔可夫链。（后一种模型称为最大熵马尔可夫模型 (MEMM)，这是对第 4.3.4 节讨论的最大熵模型之间联系的引用。）与 CRF 相比，MEMM 存在一个微妙的问题，该问题（相当晦涩地）被称为标签偏置问题 [LMP01]。问题在于，时间 $t$ 处的局部特征不影响时间 $t$ 之前的状态。也就是说，$y_{t-1} \perp x_t | y_t$，从而阻止了时间上的逆向信息流。要了解这在实践中意味着什么，请考虑我们在第 4.4.1.1 节中讨论的词性标注任务。假设我们看到单词 "banks"；它可能是动词（如 "he banks at Chase"），也可能是名词（如 "the river banks were overflowing"）。在本地，该单词的词性标签是模糊的。但是，假设句子稍后我们看到单词 "fishing"；这为我们提供了足够的上下文来推断 "banks" 的含义是 "river banks" 而不是 "financial banks"。然而，在 MEMM 中，"fishing" 的证据不会逆向传递，因此我们无法推断 "banks" 的正确标签。CRF 没有这个问题。MEMM 中的标签偏置问题之所以发生，是因为有向模型是局部归一化的，这意味着每个 CPD 之和为 1。相比之下，MRFs 和 CRFs 是全局归一化的，这意味着局部因子不需要之和为 1，因为划分函数 $Z$（对所有联合配置求和）将确保模型定义一个有效的分布。然而，这个解决方案是有代价的：在 CRF 中，在看到整个句子之前，我们无法得到 $y_{1:T}$ 上的有效概率分布，因为只有那时才能对所有配置进行归一化。因此，CRF 对于在线或实时推断不如有向概率图形模型 (DPGMs) 有用。此外，$Z$ 是所有参数的函数这一事实使得 CRF 不如 DPGMs 模块化，训练速度也慢得多，如第 4.4.3 节所讨论。

## 4.5.4 组合有向图和无向图

我们还可以定义包含有向边和无向边的图形模型。下面我们将讨论几个示例。

![](img/ca72c1626f4850f058a9edc138c1ac73_229_0.png)

图 4.42：一个部分有向无环图 (PDAG)。链分量为 {A}、{B}、{C, D, E}、{F, G}、{H} 和 {I}。改编自 [KF09a] 的图 4.15。

### 4.5.4.1 链图

链图是一种 PGM，可以同时包含有向边和无向边，但没有任何有向环。图 4.41 显示了一个简单示例，它定义了以下联合模型：

```
p(\boldsymbol{x}_{1:D}, \boldsymbol{y}_{1:D}) = p(\boldsymbol{x}_{1:D})p(\boldsymbol{y}_{1:D}|\boldsymbol{x}_{1:D}) = \left[ \frac{1}{Z} \prod_{i \sim j} \psi_{ij}(x_i, x_j) \right] \left[ \prod_{i=1}^D p(y_i|x_i) \right]
```

在此示例中，先验 p(x) 由 UPGM 指定，似然 p(y|x) 指定为完全因式分解的 DPGM。

更一般地，链图可以用部分有向无环图 (PDAG) 来定义。这是一种可以分解为链分量的有向图的图，其中每个链分量内的节点仅通过无向边相互连接。示例请参见图 4.42。

我们可以使用 PDAG 来使用 \(\prod_i p(C_i|\text{pa}(C_i))\) 定义联合分布，其中每个 C_i 是一个链分量，每个 CPD 是一个条件随机场。例如，参考图 4.42，我们有

```
p(A, B, ..., I) = p(A)p(B)p(C, D, E|A, B)p(F, G|C, D)p(H)p(I|C, E, H)
p(C, D, E|A, B) = \frac{1}{Z(A, B)}\phi(A, C)\phi(B, E)\phi(C, D)\phi(D, E)
p(F, G|C, D) = \frac{1}{Z(C, D)}\phi(F, C)\phi(G, D)\phi(F, G)
```

更多详情，请参见例如 [KF09a, Sec 4.6.2]。
