首先将高斯分布投影到此约束曲面上，得到

```
$$ p(\mathbf{z}|\mathbf{x}, \mathcal{D}) = \mathcal{N} \left( \mathbf{z}|\mathbf{m} - \frac{\mathbf{V}\mathbf{1}\mathbf{1}^\top \mathbf{m}}{\mathbf{1}^\top \mathbf{V} \mathbf{1}}, \mathbf{V} - \frac{\mathbf{V}\mathbf{1}\mathbf{1}^\top \mathbf{V}}{\mathbf{1}^\top \mathbf{V} \mathbf{1}} \right) = \mathcal{N}(\mathbf{z}|\mathbf{m}', \mathbf{V}') $$
```

where 1 是大小为 C 的全一向量。为避免 \(\alpha\) 稀疏可能带来的潜在问题，[HKH22] 提议在零和约束之后，还通过使用 \(\mathbf{m}'' = \mathbf{m}' / \sqrt{c}\) 和 \(\mathbf{V}'' = \mathbf{V}' / c\) 对后验进行缩放，其中 \(c = (\sum_{ii} V''_{ii}) / \sqrt{C} / 2\)。

与 probit 近似相比，Laplace 桥近似的一个有用特性是，我们可以轻松计算每个标签存在的概率的边缘分布。这是因为 Dirichlet 分布的边缘分布是 beta 分布。我们可以利用此自适应地计算 top-k 预测集；这在精神上与符合预测（第 14.3.1 节）相似，但它是贝叶斯的，因为它表示每个实例的不确定性。该方法的工作流程如下。首先，我们按预期概率降序排列类标签，得到 \(\hat{\alpha}\)；然后，我们计算最上方标签概率的边缘分布，

```
$$ p(\pi_1|\mathbf{x}, \mathcal{D}) = \text{Beta}(\hat{\alpha}_1, \alpha_0 - \hat{\alpha}_1) $$
```

where \(\alpha_0 = \sum_c \alpha_c\)。然后，我们以类似的方式计算其他标签的边缘分布，并返回所有与最上方标签有显著重叠的标签。从图 17.9 中的示例可以看出，这种方法可以返回大小可变的输出，以自然的方式反映不确定性。

### 17.3.10.3 蒸馏

对后验预测的 MC 近似比标准的确定性插件近似慢 S 倍。加速这种方法的一个途径是使用 **蒸馏** 来用参数“学生”模型 \(p_s\) 近似半参数“教师”模型 \(p_t\)（来自公式 (17.25)），通过最小化 \(\mathbb{E} [D_{\text{KL}}(p_t(\boldsymbol{y}|\boldsymbol{x}) \| p_s(\boldsymbol{y}|\boldsymbol{x}))]\) 关于 \(p_s\) 来实现。这种方法最初在 [HVD14] 中提出，他们将该技术称为“**黑暗知识**”，因为教师在其预测概率（logits）中拥有“隐藏”的信息，而这些信息在原始独热标签中并不明显。

在 [Kor+15] 中，这一思想被用于蒸馏一位教师的预测，该教师的参数后验是使用 HMC 计算的；这被称为“**贝叶斯黑暗知识**”。[BPK16; GBP18] 中也使用了类似的想法，他们蒸馏了由 MC dropout（第 17.3.1 节）推导出的预测分布。

由于参数学生通常比半参数教师灵活性较差，可能会过度自信，且其预测缺乏多样性。为避免这种过度自信，让学生成为混合分布 [SG05; Tra+20a] 更为安全。

### 17.3.11 调温和冷后验

在处理分类问题的 BNN 时，似然通常取为

\(p(y|\boldsymbol{x}, \boldsymbol{\theta}) = \text{Cat}(y|\text{softmax}(f(\boldsymbol{x}; \boldsymbol{\theta})))\) (17.32)

其中 \(f(\boldsymbol{x}; \boldsymbol{\theta}) \in \mathbb{R}^C\) 返回 \(C\) 个类标签的 logits。这与多项式逻辑回归（第 15.3.2 节）相同；唯一的区别是 \(f\) 是 \(\boldsymbol{\theta}\) 的非线性函数。

然而，在实践中，通常发现（见例如 [Zha+18; Wen+20b; LST21; Noc+21]）如果将似然函数按某个幂 \(\alpha\) 进行缩放，BNN 能获得更好的预测准确性。也就是说，这些方法不是针对后验 \(p(\boldsymbol{\theta}|\mathcal{D}) \propto p(\boldsymbol{y}|\boldsymbol{x}, \boldsymbol{\theta})p(\boldsymbol{\theta})\)，而是针对 **调温后验**，\(p_{\text{tempered}}(\boldsymbol{\theta}|\mathcal{D}) \propto p(\boldsymbol{y}|\mathbf{X}, \boldsymbol{\theta})^\alpha p(\boldsymbol{\theta})\)。在对数空间中，我们有

\(\log p_{\text{tempered}}(\boldsymbol{\theta}|\mathcal{D}) = \alpha \log p(\boldsymbol{y}|\mathbf{X}, \boldsymbol{\theta}) + \log p(\boldsymbol{\theta}) + \text{const}\) (17.33)

这也称为 \(\alpha\)-后验或 **幂后验** [Med+21]。

另一种常见的方法是针对 **冷后验**，\(p_{\text{cold}}(\boldsymbol{\theta}|\mathcal{D}) \propto p(\boldsymbol{\theta}|\mathbf{X}, \boldsymbol{y})^{1/T}\)，或者，在对数空间中，

\(\log p_{\text{cold}}(\boldsymbol{\theta}|\mathcal{D}) = \frac{1}{T} \log p(\boldsymbol{y}|\mathbf{X}, \boldsymbol{\theta}) + \frac{1}{T} \log p(\boldsymbol{\theta}) + \text{const}\) (17.34)

如果 \(T < 1\)，我们说后验是“冷”的。注意，在高斯先验的情况下，使用冷后验等同于使用具有不同超参数的调温后验，因为

\(\frac{1}{T} \log \mathcal{N}(\boldsymbol{\theta}|0, \sigma^2_{\text{cold}} \mathbf{I}) = - \frac{1}{2T\sigma^2_{\text{cold}}} \sum_i \theta_i^2 + \text{const} = \mathcal{N}(\boldsymbol{\theta}|0, \sigma^2_{\text{tempered}} \mathbf{I}) + \text{const}\) (17.35)

其中 \(\sigma^2_{\text{tempered}} = T \sigma^2_{\text{cold}}\)。因此，这两种方法在本质上是相同的，只是重新加权了似然。

贝叶斯神经网络分类器中的冷后验是 aleatoric（标签）不确定性表示不足的结果，如 [Kap+22] 所示。在 CIFAR-100 等基准上，我们基本上不应该对训练图像的标签有任何不确定性，然而具有 softmax 似然的贝叶斯分类器对这些点的不确定性却非常高。此外，[Izm+21b] 表明，在 [Wen+20b] 的所有示例中，当移除数据增强时会出现冷后验效应。[Kap+22] 表明，使用 [Wen+20b] 中的 SGLD 推理时，数据增强的作用是将似然提高到大小为 K 的小批量的 1/K 次幂。冷后验正好抵消了这种效应，通过锐化似然，更诚实地代表我们对 aleatoric 不确定性的信念。然而，调温不是必需的，[Kap+22] 表明，通过使用 Dirichlet 观测模型来显式表示（缺乏）标签噪声，即使有数据增强，也不会出现冷后验效应。[Ait21] 的策展假设可以被视为上述解释的一种特殊情况，其中策展的作用是增加我们对训练标签的信心。

在第 14.1.3 节中，我们讨论了广义变分推断，它为理解似然或先验是否以及如何从调温中受益提供了一个一般框架。当模型误设定时（通常是这种情况），调温尤其有用 [KJD21]。
