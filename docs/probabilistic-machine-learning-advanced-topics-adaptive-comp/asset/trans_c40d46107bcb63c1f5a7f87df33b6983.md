
根据链式法则，我们有

$$\frac{\partial \log p(x)}{\partial \alpha} = \frac{\partial \log p(x)}{\partial \beta} \frac{\partial \beta}{\partial \alpha}$$

因此

$$\mathbf{F}_\alpha = \frac{\partial \boldsymbol{\beta}^\mathsf{T}}{\partial \boldsymbol{\alpha}} \mathbf{F}_\beta \frac{\partial \boldsymbol{\beta}}{\partial \boldsymbol{\alpha}}$$

使用对数技巧

$$\nabla \mathbb{E}_{p(x)} [f(x)] = \mathbb{E}_{p(x)} [f(x) \nabla \log p(x)]$$

利用公式 (3.68) 我们有

$$\frac{\partial m_i}{\partial \eta_j} = \frac{\partial \mathbb{E}[\mathcal{T}(x)_i]}{\partial \eta_j} = \mathbb{E} \left[ \mathcal{T}(x)_i \frac{\partial \log p(x|\eta)}{\partial \eta_j} \right] = \mathbb{E}[\mathcal{T}(x)_i (\mathcal{T}(x)_j - m_j)]$$

$$= \mathbb{E}[\mathcal{T}(x)_i \mathcal{T}(x)_j] - \mathbb{E}[\mathcal{T}(x)_i] m_j = \text{Cov}[\mathcal{T}(x)_i \mathcal{T}(x)_j] = (\mathbf{F}_\eta)_{ij}$$

因此

$$\frac{\partial \eta}{\partial m} = \mathbf{F}_\eta^{-1}$$

所以

$$\mathbf{F}_m = \frac{\partial \eta}{\partial m}^\mathsf{T} \mathbf{F}_\eta \frac{\partial \eta}{\partial m} = \mathbf{F}_\eta^{-1} \mathbf{F}_\eta \mathbf{F}_\eta^{-1} = \mathbf{F}_\eta^{-1} = \text{Cov}[\mathcal{T}(x)]^{-1}$$

## 3.3.5 频率学派统计学的反直觉特性

尽管统计学的频率学派方法被广泛教授，但它存在某些病理特性，导致其常被误解和/或滥用，这一点已在多篇文章中指出（见例：[Bol02; Bri12; Cla21; Gel16; Hoe+14; Jay03; Kru10; Lav00; Lyu+20; Min99; Mac03; WG17]）。我们在下面给出一些例子。

### 3.3.5.1 置信区间

在频率学派统计中，我们利用抽样分布引起的变异性来估计参数估计量的不确定性。具体来说，我们定义 $100(1-\alpha)\%$ **置信区间** 为从假设数据集 $\tilde{\mathcal{D}}$ 推导出的任何区间 $I(\tilde{\mathcal{D}}) = (\ell(\tilde{\mathcal{D}}), u(\tilde{\mathcal{D}}))$，使得

$$\Pr(\theta \in I(\tilde{\mathcal{D}})|\tilde{\mathcal{D}} \sim \theta) = 1 - \alpha$$

通常设置 $\alpha = 0.05$，从而得到 95% 置信区间（CI）。这意味着，如果我们反复抽样数据，并对每个这样的数据集计算 $I(\tilde{\mathcal{D}})$，则约 95% 的此类区间将包含真实参数 $\theta$。我们说该置信区间具有 95% **覆盖率**。

然而，请注意，公式 (3.81) _并不_ 意味着对于任何特定数据集，$\theta \in I(\mathcal{D})$ 以 95% 的概率成立，这正是贝叶斯可信区间计算的内容（第 3.2.1.7 节），也是大多数人通常关心的内容。因此我们看到，频率学派置信区间和贝叶斯置信区间的概念相当不同：在频率学派方法中，\(\theta\) 被视为未知的固定常数，而数据被视为随机的。在贝叶斯方法中，我们将数据视为固定的（因为它是已知的），并将参数视为随机的（因为它是未知的）。

置信区间的这种反直觉定义可能导致奇怪的结果。考虑来自 [Ber85a, p11] 的以下示例。假设我们从以下分布中抽取两个整数 \(\mathcal{D} = (y_1, y_2)\)：

\(p(y|\theta) = \begin{cases} 0.5 & \text{if } y = \theta \\ 0.5 & \text{if } y = \theta + 1 \\ 0 & \text{otherwise} \end{cases}\) (3.82)

如果 \(\theta = 39\)，我们期望以下结果各出现概率为 0.25：

\((39, 39), (39, 40), (40, 39), (40, 40)\) (3.83)

令 \(m = \min(y_1, y_2)\) 并定义以下区间：

\([\ell(\mathcal{D}), u(\mathcal{D})] = [m, m]\) (3.84)

对于上述样本，这将产生

\([39, 39], [39, 39], [39, 39], [40, 40]\) (3.85)

因此，公式 (3.84) 显然是一个 75% 的置信区间，因为 39 包含在这些区间的 3/4 中。然而，如果我们观察到 \(\mathcal{D} = (39, 40)\)，则 \(p(\theta = 39|\mathcal{D}) = 1.0\)，所以我们知道 \(\theta\) 必须是 39，但我们对此事实只有 75% 的“置信度”。我们可以看到，如果从不同随机抽样的数据集中计算多个置信区间，则置信区间将有 75% 的时间“覆盖”真实参数，但如果我们只有一个观察到的数据集，因此只有一个置信区间，那么频率学派的“覆盖率”概率可能非常具有误导性。更多有趣的示例（附有 Python 代码）可在 [Van14] 中找到。另请参见 [Hoe+14; Mor+16; Lyu+20; Cha+19b]，他们表明许多人（包括专业统计学家）在实践中误解和滥用频率学派置信区间，而贝叶斯可信区间则不存在这些问题。

### 3.3.5.2 p值

假设检验的频率学派方法，即零假设显著性检验（NHST），是定义一个决策程序，根据某个观测到的检验统计量 \(t(\mathcal{D})\) 在零模型的抽样分布下是否可能，来决定是否接受或拒绝零假设 \(H_0\)。我们将在 3.10.1 节更详细地描述此程序。

与其接受或拒绝零假设，不如计算一个与零假设为真的可能性相关的量。具体来说，我们可以计算一个称为 p值 的量，它定义为

\(\text{pval}(t(\mathcal{D})) \triangleq \text{Pr}(t(\tilde{\mathcal{D}}) \ge t(\mathcal{D})|\tilde{\mathcal{D}} \sim H_0)\) (3.86)

其中 \(\tilde{\mathcal{D}} \sim H_0\) 是假设的未来数据。也就是说，p值 只是在抽样分布下观测到值 \(t(\mathcal{D})\) 的尾概率。（请注意，p值 不显式依赖于数据模型，但最常见的检验统计量隐式定义了一个模型，如我们在 3.10.3 节中讨论的。）

p值 通常被解释为数据在零假设下的可能性，因此较小的值被解释为意味着 $H_0$ 不太可能，因此 $H_1$ 可能性较大。推理大致如下：

如果 $H_0$ 为真，那么此检验统计量可能不会发生。该统计量确实发生了。因此 $H_0$ 可能为假。

然而，这是无效的推理。要看原因，请考虑以下示例（来自 [Coh94]）：如果一个人是美国人，那么他可能不是国会议员。此人是国会议员。因此他可能不是美国人。

这显然是谬误的推理。相比之下，以下逻辑论证是有效的推理：

> 如果一个人是火星人，那么他不是国会议员。此人是国会议员。因此他不是火星人。

这两种情况的区别在于，火星人示例使用的是 **演绎推理**，即从逻辑定义向后推导到其后果。更准确地说，此示例使用逻辑中称为 **否定后件律** 的规则，我们从形式为 $P \Rightarrow Q$ 的定义开始；当我们观察到 $\neg Q$ 时，可以得出 $\neg P$。相比之下，美国示例涉及的是 **归纳推理**，即根据观察到的证据，利用统计规律而非逻辑定义，逆向推理出可能的（但不一定是真的）原因。

要进行归纳推理，我们需要使用概率推理（如 [Jay03] 中详细说明）。特别是，为了计算零假设的概率，我们应该使用贝叶斯规则，如下所示：

```
$p(H_0|\mathcal{D}) = \frac{p(\mathcal{D}|H_0)p(H_0)}{p(\mathcal{D}|H_0)p(H_0) + p(\mathcal{D}|H_1)p(H_1)}$ (3.87)
```

如果先验是均匀的，即 $p(H_0) = p(H_1) = 0.5$，则可以用 **似然比** $LR = p(\mathcal{D}|H_0)/p(\mathcal{D}|H_1)$ 重写如下：

```
$p(H_0|\mathcal{D}) = \frac{LR}{LR + 1}$ (3.88)
```

在美国国会示例中，\(\mathcal{D}\) 是此人是国会议员的观察结果。零假设 $H_0$ 是此人是美国人，而备择假设 $H_1$ 是此人不是美国人。我们假设 $p(\mathcal{D}|H_0)$ 较低，因为大多数美国人不是国会议员。然而，$p(\mathcal{D}|H_1)$ 也较低——事实上，在此示例中，它是 0，因为只有美国人才能成为国会议员。因此 $LR = \infty$，所以 $p(H_0|\mathcal{D}) = 1.0$，这与直觉一致。

然而，请注意，NHST 忽略了 $p(\mathcal{D}|H_1)$ 以及先验 $p(H_0)$，因此它会给出错误的结果，不仅在这个问题上，而且在许多问题上。事实上，即使大多数科学家也误解 p值。期刊 *美国统计学家* 出版了一整期特刊，警告使用 p值 和 NHST [WSL19]，多个期刊甚至已禁止使用 p值 [TM15; AGM19]。
