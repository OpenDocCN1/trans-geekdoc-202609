一个二元特征，表示房屋是否有地下室。我们使用一个包含明尼苏达州 $J = 85$ 个县的数据集；每个县有 2 到 80 次测量。

我们假设以下似然：

```
$p(y_n|x_n, g_n = j, \boldsymbol{\theta}) = \mathcal{N}(y_n|\alpha_j + \beta_j x_n, \sigma_y^2)$ (15.190)
```

其中 $g_n \in \{1, \dots, J\}$ 是房屋 $n$ 所在的县，而 $x_n \in \{0, 1\}$ 指示楼层是否位于 0 层（即地下室）或 1 层（即地面以上）。直觉上，我们预期没有地下室的房屋氡含量较低，因为它们更与地面隔绝，而地面是氡的来源。由于一些县的数据点很少，我们使用层次先验，假设 $\alpha_j \sim \mathcal{N}(\mu_\alpha, \sigma_\alpha^2)$，且 $\beta_j \sim \mathcal{N}(\mu_\beta, \sigma_\beta^2)$。我们为参数使用弱先验：$\mu_\alpha \sim \mathcal{N}(0, 1)$、$\mu_\beta \sim \mathcal{N}(0, 1)$、$\sigma_\alpha \sim \mathcal{C}_+(1)$、$\sigma_\beta \sim \mathcal{C}_+(1)$、$\sigma_y \sim \mathcal{C}_+(1)$。图形模型请参见图 15.14。

#### 15.5.2.1 后验推断

图 15.15 显示了 $\mu_\alpha, \mu_\beta, \alpha_j$ 和 $\beta_j$ 的后验边缘分布。我们看到 $\mu_\beta$ 与高概率下接近 $-0.6$，这证实了我们的怀疑，即 $x=1$（即没有地下室）会降低房屋中的氡含量。我们还看到 $\alpha_j$ 参数的分布变化很大，这是由于各县的基准比率不同。

## 16 深度神经网络

### 16.1 简介

术语“深度神经网络”或 **DNN**，在其现代用法中，指的是可以表示为 **计算图** 的任何类型可微分函数，其中节点是原语操作（例如矩阵乘法），边表示以向量、矩阵或张量形式的数值数据。在其最简单的形式中，此图可以构造为节点或“层”的线性序列。“深度”一词是指具有许多此类层的模型。

在第 16.2 节中，我们讨论该领域使用的一些基本构建块（节点类型）。在第 16.3 节中，我们给出了由这些构建块组成的常见架构示例。在第 6.2 节中，我们展示了如何有效计算定义在上述图上的函数的梯度。如果该函数在给定训练集的情况下计算模型预测的标量损失，我们可以将此梯度传递给优化例程（例如第 6 章中讨论的那些），以拟合模型。将此类模型拟合到数据称为“**深度学习**”。

我们可以用两种不同的方式将 DNN 与概率模型相结合。第一种是使用它们来定义用于条件分布内部的非线性函数。例如，我们可以使用 \(p(y|x,\theta) = \text{Cat}(y|\text{softmax}(f(x;\theta)))\) 构建一个分类器，其中 \(f(x;\theta)\) 是一个将输入 \(x\) 和参数 \(\theta\) 映射到输出 logits 的神经网络。或者，我们可以使用有向图模型（第 4 章）来构建多变量上的联合概率分布，其中每个 CPD \(p(x_i|\text{pa}(x_i))\) 都是一个 DNN。这使我们能够构建富有表达力的概率模型。

我们结合 DNN 和概率模型的另一种方式是使用 DNN 来近似后验分布，即，我们学习一个函数 \(f\) 来计算 \(q(z|f(\mathcal{D};\phi))\)，其中 \(z\) 是隐藏变量（潜在变量和/或参数），\(\mathcal{D}\) 是观测变量（数据），\(f\) 是一个 **推理网络**，\(\phi\) 是其参数；详情请参见第 10.1.5 节。请注意，在后一种设置中，联合模型 \(p(z, \mathcal{D})\) 可能是一个不含任何“神经”组件的“传统”模型。例如，它可能是一个复杂的模拟器。因此，DNN 只是为了计算目的而使用，而不是为了统计/建模目的。

有关 DNN 的更多细节可以在 [Zha+20a; Cho21; Gér19; GBC16; Raf22] 等书籍以及大量在线课程中找到。有关更理论性的处理，请参见例如 [Ber+21; Cal20; Aro+21; RY21]。

![](img/ca72c1626f4850f058a9edc138c1ac73_655_0.png)

图 16.1: 人工“神经元”，DNN 最基本的构建块。(a) 输出 y 是输入 x 的加权组合，其中权重向量表示为 w。(b) 神经元行为的替代描述。偏置项 b 可以通过定义 w_N = b 和 X_N = 1 来模拟。

#### 16.2.1 线性层

DNN 最基本的构建块是一个单一的“神经元”，它对应于一个实值信号 y，该信号通过将向量值输入信号 x 乘以权重向量 w，然后加上偏置项 b 来计算。即，

y = f(x; θ) = w^T x + b  (16.1)

其中 θ = (w, b) 是函数 f 的参数。如图 16.1 所示。（为了清晰起见，偏置项被省略。）

将一组神经元分组为一个层是常见的做法。然后，我们可以将具有 D 个单位的层的激活表示为向量 z ∈ R^D。我们可以通过乘以权重矩阵 W 并加上偏移向量或偏置项 b，将输入激活向量 x 转换为输出向量 y，得到

y = f(x; θ) = Wx + b  (16.2)

其中 θ = (W, b) 是函数 f 的参数。这被称为线性层，或全连接层。

通常将偏置向量前置到权重矩阵的第一列，并将 1 附加到向量 x，以便我们可以更简洁地写成 y = W^T x~，其中 W~ = [W, b] 且 x~ = [x, 1]。这样如果需要，我们可以在符号中忽略偏置项。

#### 16.2.2 非线性

线性层的堆叠等效于将所有权重矩阵相乘的单个线性层。为了获得更强的表达能力，我们可以通过将每个层逐元素（逐点）传递给一个称为激活函数的非线性函数来对其进行变换。这表示为

y = φ(x) = [φ(x_1), ..., φ(x_D)]  (16.3)
