## 1 引言

> “智能不仅仅是模式识别和函数逼近。它关乎对世界的建模。” —— Josh Tenenbaum, NeurIPS 2021。

当前大部分机器学习工作都集中在将输入映射到输出的任务上（即，近似形式为 \( f : \mathcal{X} \rightarrow \mathcal{Y} \) 的函数），通常使用“**深度学习**”（参见例如 [LBH15; Sch14; Sej20; BLH21]）。著名 AI 研究人员 Judea Pearl 将其称为“美化的曲线拟合”（引用自 [Har18]）。这有点不公平，因为当 \(\mathcal{X}\) 和/或 \(\mathcal{Y}\) 是高维空间——例如图像、句子、图或决策/动作序列——时，“曲线拟合”这个术语颇具误导性，因为一维直觉在高维场景中往往不适用（参见例如 [BPL21a]）。尽管如此，这句话道出了许多人认为当前试图利用机器学习技术“解决 AI”所欠缺的东西，即它们过于关注可观测模式的预测，而不足以关注这些模式背后的底层 *潜在结构* 的“理解”。

获得对观测数据背后结构的“深度理解”对于推进科学以及某些应用（例如医疗保健，参见 [DD22]）都是必要的，在医疗保健中，识别各种疾病背后的*根本原因*或机制是开发治愈方法的关键。此外，这种深度理解对于开发*稳健*和*高效*的系统也是必要的。这里所说的“稳健”是指即使数据分布出现意外变化，方法也能在系统应用于该分布时表现良好，这是许多领域（例如机器人学，参见 [Roy+21]）的重要关切。这里所说的“高效”通常是指数据或统计上的高效，即能够从少量数据中快速学习的方法（参见 [Lu+21b]）。这一点很重要，因为在某些领域（例如医疗保健和机器人学）数据可能有限，而在其他领域（例如语言和视觉）数据却很丰富，因为可以抓取互联网。我们也关注计算上高效的方法，尽管这是一个次要关切，因为计算能力在不断增长。（我们还注意到，这一趋势对 AI 最近的许多进步起到了关键作用，如 [Sut19] 所述。）

为了开发稳健和高效的系统，本书采用基于模型的方法，即在给定一个或多个数据集的样本的情况下，试图学习底层“**数据生成过程**” (**DGP**) 的 *简洁表示*（参见 [Lak+17; Win+19; Sch20; Ben+21a; Cun22; MTS22]）。这实际上与科学方法类似，我们试图通过发展理论或模型来解释观测结果（的特征）。形式化这一过程的一种方法是将其表述为应用于概率模型的 **贝叶斯推断**，如 [Jay03; Box80; GS13] 所主张。我们将在本书第二部分详细讨论推理算法。1 但在到达那之前，在第一部分中我们将介绍一些需要的相关背景材料。（已经熟悉这些基础知识的读者可以跳过此部分。）

一旦我们将一组推理方法放入工具箱中（其中一些可能只是使用优化方法计算最大似然估计，例如随机梯度下降），我们就可以将重点转向讨论不同种类的模型。模型的选择取决于我们的任务、我们拥有的数据的种类和数量，以及我们的成功度量标准。我们将广泛考虑四种主要任务：预测（例如分类和回归）、生成（例如图像或文本）、发现（数据中的“有意义结构”）和控制（最优决策）。我们将在下面给出更多细节。

在第三部分中，我们讨论用于预测的模型。这些模型是形式为 p(y|x) 的条件分布，其中 \(x \in \mathcal{X}\) 是某个输入（通常是高维的），\(y \in \mathcal{Y}\) 是所需输出（通常是低维的）。在这部分中，我们假设有一个我们想要预测的正确答案，尽管我们对它可能不确定。

在第四部分中，我们讨论用于生成的模型。这些模型是形式为 p(x) 或 p(x|c) 的分布，其中 c 是可选的条件输入，且可能存在多个有效输出。例如，给定一个文本提示 c，我们可能希望生成一组与标题“匹配”的多样化图像 x。与预测设置相比，评估此类模型更困难，因为不太清楚所需的输出应该是什么。

在第五部分中，我们讨论隐变量模型，它们是形式为 p(z, x) = p(z)p(x|z) 的联合模型，其中 z 是隐藏状态，x 是假设从 z 生成的观测值。目标是计算 p(z|x)，以便揭示观测数据中的某些（希望是有意义/有用的）底层状态或模式。我们还考虑试图发现预测模型形式为 p(y|x) 隐式学习的模式的方法，而不依赖于数据的显式生成模型。

最后，在第六部分中，我们讨论可用于在不确定性下做出决策的模型和算法。这自然引出了非常重要的因果性话题，本书也以此收尾。

鑒于本书范围广泛，我们无法对每个主题都进行详细阐述。但是，我们已尝试涵盖所有基础知识。在某些情况下，我们还对研究前沿（截至 2022 年）进行了“深入探讨”。我们希望通过将所有这些主题汇集在一起，您会发现更容易在这些看似截然不同的领域之间建立联系，从而加深对机器学习领域的理解。

1. 请注意，在深度学习社区中，“推理”一词是指将函数应用于某些输入以计算输出。这与贝叶斯推断无关，后者关注的是更难的任务：反转函数，并从观测输出逆向推导可能的隐藏输入（原因）。后者与深度学习社区所称的“训练”更为相关。

## 2 概率

### 2.1 引言

本节我们按照 [Cha21, Ch. 2] 的介绍，正式定义概率的含义。关于此主题的其他优秀介绍可参见 [GS97; BT08; Bet18; DFO20]。

#### 2.1.1 概率空间

我们定义 **概率空间** 为三元组 \((\Omega, \mathcal{F}, \mathbb{P})\)，其中 \(\Omega\) 是 **样本空间**，即实验可能结果的集合；\(\mathcal{F}\) 是 **事件空间**，即 \(\Omega\) 的所有可能子集的集合；\(\mathbb{P}\) 是 **概率测度**，即将事件 \(E \subseteq \Omega\) 映射到 \([0, 1]\) 中的一个数（即 \(\mathbb{P} : \mathcal{F} \to [0, 1]\)）的映射，该映射满足某些一致性要求，我们将在 2.1.4 节中讨论。

#### 2.1.2 离散随机变量

最简单的场景是实验结果构成一个可数集合。例如，考虑掷一个 3 面骰子，面上标有 "A"、"B" 和 "C"。（为了简洁，我们选择 3 个面而不是 6 个。）样本空间是 \(\Omega = \{A, B, C\}\)，代表了“实验”可能的所有结果。事件空间是样本空间所有可能子集的集合，因此 \(\mathcal{F} = \{\emptyset, \{A\}, \{B\}, \{C\}, \{A, B\}, \{A, C\}, \{B, C\}, \{A, B, C\}\}\)。事件是事件空间的一个元素。例如，事件 \(E_1 = \{A, B\}\) 表示骰子显示面 A 或 B 的结果，事件 \(E_2 = \{C\}\) 表示骰子显示面 C 的结果。

定义事件空间后，我们需要指定概率测度，它提供了一种计算事件空间中每个集合的“大小”或“权重”的方法。在 3 面骰子示例中，假设我们定义每个结果（原子事件）的概率为 \(\mathbb{P}[\{A\}] = \frac{2}{6}\)、\(\mathbb{P}[\{B\}] = \frac{1}{6}\) 和 \(\mathbb{P}[\{C\}] = \frac{3}{6}\)。我们可以通过对每个结果的测度求和来推导其他事件的概率，例如，\(\mathbb{P}[\{A, B\}] = \frac{2}{6} + \frac{1}{6} = \frac{1}{2}\)。我们将在 2.1.4 节中形式化这一点。

为了简化记号，我们将为事件空间中的每个可能结果分配一个数字。这可以通过定义 **随机变量** 或 **rv** 来完成，它是一个函数 \(X : \Omega \to \mathbb{R}\)，将结果 \(\omega \in \Omega\) 映射到实数轴上的数字 \(X(\omega)\)。例如，我们可以为我们的 3 面骰子定义随机变量 \(X\)，使用 \(X(A) = 1\)、\(X(B) = 2\)、\(X(C) = 3\)。另一个例子是，考虑掷两次公平硬币的实验。样本空间是 \(\Omega = \{\omega_1 = (H, H), \omega_2 = (H, T), \omega_3 = (T, H), \omega_4 = (T, T)\}\)，其中 H 代表正面，T 代表反面。令 \(X\) 为表示正面次数的随机变量。那么我们有 \(X(\omega_1) = 2\)、\(X(\omega_2) = 1\)、\(X(\omega_3) = 1\) 和 \(X(\omega_4) = 0\)。
