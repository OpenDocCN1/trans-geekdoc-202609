

Hernán 和 Robins [HR20b]，源自流行病学，Imbens 和 Rubin [IR15]，源自统计学，以及 Morgan 和 Winship [MW15]，从社会科学角度出发。Shalizi [Sha22, §7] 中关于因果性的介绍也值得推荐，特别是关于匹配的论述。双机器学习在本章中占据了突出地位。这是非参数估计的一个特定实例。这一主题在现代因果推断中具有重要的理论和实践意义。双机器学习工作包括针对许多常见场景的估计器 [Che+17e; Che+17d]。关于如何以及为什么非参数估计有效的清晰解释的良好参考文献包括 [Ken16; Ken17; FK21]。通常，非参数估计器的关键保证是渐近性的。一般来说，有许多估计器共享最优渐近保证（例如，方程 (36.30) 中给出的 AIPTW 估计器）。尽管这些在渐近意义上是等价的，但在有限样本中它们的行为可能非常不同。有一些估计器保留渐近保证，但旨在提高在实际有限样本体系中的性能 [e.g., vR11]。

对异质治疗效果的估计也存在相当大的兴趣。这里的问题是：当这种治疗应用于具有这样那样特定特征的个体时，会产生什么效果？例如，这种药物对 50 岁以上女性的效果是什么？这里使用的因果识别论证与估计平均效果的论证或多或少相同。然而，估计问题可能要复杂得多。一些参考资料包括 [Kün+19; NW20; Ken20; Yad+21]。除了本章所涵盖的内容之外，还有几种常用的因果识别和估计策略。**回归不连续设计**依赖于治疗分配中存在某种尖锐的、任意的非线性。例如，某些援助计划的资格是根据个人收入是低于还是高于固定金额来确定的。可以通过比较该阈值下方和上方紧邻的个体来研究治疗效果。**合成控制**是一类方法，通过构建该个体的合成版本作为控制来尝试研究治疗对给定个体的影响。例如，为了研究加利福尼亚州室内禁烟立法的影响，我们可以构建一个作为其他州加权平均的合成加利福尼亚州，权重选择用于平衡人口统计特征。然后，我们可以将加利福尼亚州的观察结果与合成控制的结果进行比较，合成控制是捐助州结果的加权平均。请参阅 Angrist 和 Pischke [AP08] 以了解这两种策略的教科书处理。与之密切相关的是使用时间序列建模来创建合成结果的方法。例如，为了研究从时间 T 开始的广告活动对产品销售 Yt 的影响，我们可以使用 t < T 期间的数据为 Yt 构建时间序列模型，然后使用该模型来预测如果没有开展该活动本应看到的 (Yt̃)>T 的值。我们可以通过将事实实现的 Yt 与预测的反事实 Yt̃ 进行比较来估计因果效果。请参阅 Brodersen 等人 [Bro+15] 以了解这一思想的具体实例。

在本章中，我们的重点是使用机器学习工具来估计因果效果。也有越来越多的兴趣利用因果性的思想来改进机器学习工具。这主要旨在构建在部署到新领域时鲁棒的预测器 [SS18b; SCS19; Arj+20; Mei18b; PBM16a; RC+18; Zha+13a; Sch+12b; Vej+21]，或者不依赖于训练数据中特定的“虚假”相关性的预测器 [RPH21; Wu+21; Gar+19; Mit+20; WZ19; KCC20; KHL20; TAH20; Vej+21]。
