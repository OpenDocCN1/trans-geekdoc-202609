
(未知) 确定性函数。例如，P^obs 的一个合理 SCM 可能是

G <- f_G(\xi_0) (36.5)
H <- f_H(\xi_1) (36.6)
A <- f_A(H, \xi_2) (36.7)
Y <- f_Y(G, H, A, \xi_3) (36.8)

其中，(未知) 函数 f 是固定的，变量 \xi 是未测量的原因，建模为独立的随机“噪声”变量。从概念上讲，函数 f_G、f_H、f_A、f_Y 描述现实世界中的确定性物理关系，而变量 \xi 是足以区分总体中每个单位 i 的隐藏原因。因为我们假设每个观察单位 i 是从总体中随机抽取的，所以我们将 \xi 建模为随机噪声。

SCMs 意味着概率模型，但反之不然。例如，我们的示例 SCM 基于分解 P^obs(G, H, A, Y) = P^obs(G)P^obs(H)P^obs(A | H)P^obs(Y | A, H) 隐含了观察数据的概率模型。因此，我们可以像从概率模型采样一样从 SCM 中采样：绘制一组噪声变量 \xi 并按顺序评估 SCM 中的每个赋值操作。

除了概率模型之外，SCM 还编码了关于干预效应的附加假设。这可以使用 do-演算（如动词“to do”）形式化，我们将在第 36.8 节中描述；简而言之，干预是通过替换赋值语句来表示的。例如，如果我们对在吸烟被消除的假设情景下 Y 的分布感兴趣，我们可以将 SCM 的第二行设置为 A <- 0。我们将用 P(Y|do(A = 0), H) 表示这一点。因为 SCM 中的 f 函数被假设为不变的机制关系，SCM 编码了这样一个假设：这个被编辑的 SCM 生成的数据，就是如果我们在现实中真正应用该干预时会看到的数据。因此，SCM 中语句的顺序是承重的：它们关于世界如何响应干预而变化，隐含了实质性假设。这与更标准的概率模型形成对比，在标准模型中，变量可以通过应用贝叶斯法则重新排列，而不会改变模型的实质性含义。（另见第 4.7.3 节。）

实际上，就像 SCMs 意味着概率模型一样，因果 DAGs 意味着 PGM。从功能上讲，因果图的行为像概率图形模型（第 4 章）。它们以相同的方式暗示观察数据中变量之间的条件独立关系。它们遵守马尔可夫性质：如果 X ← Y → Z，则 X ⊥⊥ Z|Y；回顾 d-separation（第 4.2.4.1 节）。此外，如果 X → Y ← Z，那么通常 X \(\not\perp\perp\) Z|Y（即使 X 和 Z 边际独立）。在这种情况下，Y 被称为 X 和 Z 的 collider。

从概念上讲，因果 DAGs 和 PGMs 之间的区别在于，概率图形模型编码了我们关于统计关系的假设，而因果图编码了我们（更强的）关于因果关系的假设。这些因果关系可用于推导统计关系在干预下将如何变化。

因果图还使我们能够在不指定完整 SCM 的情况下，推理观察数据中统计依赖的因果和非因果起源。在因果图中，两个变量——例如，A 和 D——可以以不同的方式在统计上关联。首先，可以从（祖先）A 到（后代）D 存在一条有向路径。在这种情况下，A 是 D 的因果祖先，对 A 的干预会通过传播来改变 D；P(D|do(A = a)) ≠ P(D|do(A = a’))。例如，在我们的示例中，吸烟是癌症的因果祖先。或者，A 和 D 可能共享一个共同原因——存在一些变量 C，使得从 C 到 A 和从 C 到 D 存在有向路径。如果 A 和 D 仅通过这样的路径关联，那么对 A 的干预不会改变 D 的分布。然而，P(D|A = a) ≠ P(D|A = a’) 仍然成立——观察 A 的不同值会改变我们对 D 值的猜测。原因是 A 承载关于 C 的信息，而 C 承载关于 D 的信息。例如，假设我们生活在一个吸烟对患癌症没有影响的世界（例如，所有人都使用电子烟），由于路径 A ← H → Y，吸烟与癌症之间仍然会存在关联。这样的“后门路径”的存在是统计关联和因果关联不相同的一个核心原因。当然，这些关联的更复杂变体也是可能的——例如，C 本身仅通过后门路径与 A 关联——但这已经抓住了因果路径和非因果路径之间的关键区别。

回顾我们引入 SCMs 和因果图的目的是使我们能够形式化我们对世界的因果知识，并精确地界定我们想要估计的干预量。写下因果图提供了一种简单的正式方式来编码我们对问题因果结构的知识。有用的是，这种因果结构足以直接推理干预的含义，而无需完全指定底层 SCM。关键观察是，如果对变量 $A$ 进行干预，那么干预后，其他任何变量都不是 $A$ 的原因。也就是说，当我们用直接给变量赋予特定值的语句替换 SCM 中的一行时，我们切断了该变量与其因果父节点之间的所有依赖。因此，在因果图中，被干预的变量没有父节点。这引导我们产生 **图手术** 的干预概念：将 $A$ 设置为 $a$ 的干预是删除图中所有指向 $A$ 的传入边，然后在结果概率分布（由术后手术图的条件独立结构定义）中对 $A=a$ 进行条件化的操作。我们将使用 Pearl 的 do 记法来表示此操作。$P(\mathbf{X}|\text{do}(A=a))$ 是在删除所有指向 $A$ 的边后得到的截断图中，给定 $A=a$ 时 $\mathbf{X}$ 的分布。同样，$\mathbb{E}[\mathbf{X}|\text{do}(A=a)] \triangleq \mathbb{E}_{\text{P}(\mathbf{X}|\text{do}(A=a))}[\mathbf{X}]$。因此，我们可以形式化诸如“接受药物 $A$ 的平均效应”之类的语句，如

ATE = $E[Y|\text{do}(A=1)] - \mathbb{E}[Y|\text{do}(A=0)], \quad (36.9)$

其中 ATE 代表平均处理效应。为具体起见，考虑我们的运行示例。我们对比基于对 $A$ 进行条件化得到的分布与基于对 $A$ 进行干预得到的分布：

$P(Y, H, G | A = a) = P(Y | H, G, A = a)P(G)P(H|A = a) \quad (36.10)$
$P(Y, H, G|\text{do}(A = a)) = P(Y | H, G, A = a)P(G)P(H) \quad (36.11)$

这两个分布之间的关键区别在于，标准条件分布描述的是一个总体，其中健康意识 $H$ 具有我们在吸烟状态 $A = a$ 的个体中观察到的分布，而干预分布描述的是一个总体，其中健康意识 $H$ 遵循所有个体中的边际分布。例如，我们预期 $P(H | A = \text{smoker})$ 将比边际健康意识分布（即边际分布 $P(H)$，后者也包括非吸烟者）在 $H$ 的较低值上分配更多概率质量。干预分布因此包含了一个关于吸烟将如何影响观察数据中那些倾向于过于关注健康而不吸烟的亚群体的假设。

## 36.2.3 Identification

因果推理的一个核心挑战是，许多不同的 SCM 可以产生相同的观察数据分布。这意味着，仅基于观察数据，我们无法唯一地识别生成它的 SCM。无论我们可用的数据样本有多大，这都是成立的。例如，考虑这样一种情况：存在一种治疗 $A$，它可能对结局 $Y$ 有影响，也可能没有影响，且治疗和结果都已知会受到某些 *未观察到的* 共同二进制原因 $U$ 的影响。现在，我们可能对因果 estimand $E[Y|\text{do}(A=1)]$ 感兴趣。一般来说，我们无法从观察数据中学习这个量。问题在于，我们无法区分治疗有强效的情况和治疗无效但 $U = 1$ 既导致人们倾向于接受治疗又增加积极结果概率的情况。同样的观察表明，我们无法学习（更复杂的）
