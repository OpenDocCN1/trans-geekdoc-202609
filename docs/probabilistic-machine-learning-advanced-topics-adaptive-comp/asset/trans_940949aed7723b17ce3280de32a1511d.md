

## 2.2.1.3 泊松分布

假设 \( X \in \{0, 1, 2, \dots\} \)。我们说，若随机变量的 pmf（概率质量函数）为

```
\(\text{Poi}(x|\lambda) = e^{-\lambda} \frac{\lambda^x}{x!}\) \tag{2.24}
```

则该随机变量服从参数为 \( \lambda > 0 \) 的 **泊松** 分布，记作 \( X \sim \text{Poi}(\lambda) \)。

其中 \( \lambda \) 为 \( x \) 的均值（也是方差）。

## 2.2.1.4 负二项分布

假设有一个装有 \( N \) 个球的"罐子"，其中 \( R \) 个为红色，\( B \) 个为蓝色。假设我们进行 **有放回抽样**，直至抽得 \( n \ge 1 \) 个球。令 \( X \) 为其中蓝色球的数量。可以证明 \( X \sim \text{Bin}(n, p) \)，其中 \( p = B/N \) 为蓝色球所占比例；因此 \( X \) 服从二项分布（讨论于第 2.2.1.1 节）。

现在假设我们将抽到蓝色球定义为"成功"，将抽到非蓝色球定义为"失败"。假设我们不断抽球，直至观察到 \( r \) 次失败。令 \( X \) 为最终的成功次数（蓝色球数量）；可以证明 \( X \sim \text{NegBinom}(r, p) \)，即由下式定义的 **负二项分布**：

```
\(\text{NegBinom}(x|r, p) \triangleq \binom{x+r-1}{x} (1-p)^r p^x\) \tag{2.25}
```

对 \( x \in \{0, 1, 2, \dots\} \) 成立。（若 \( r \) 为实数，则用 \(\frac{\Gamma(x+r)}{x! \Gamma(r)}\) 替换 \(\binom{x+r-1}{x}\)，利用 \( (x-1)! = \Gamma(x) \) 这一事实。）

该分布具有如下矩：

```
\(\mathbb{E}[x] = \frac{pr}{1-p}, \quad \mathbb{V}[x] = \frac{pr}{(1-p)^2}\) \tag{2.26}
```

与泊松分布相比，这个两参数家族具有更多的建模灵活性，因为它可以分别表示均值和方差。例如，这对于建模"传染性"事件很有用，此类事件的发生呈正相关，导致的方差大于独立发生时的方差。事实上，泊松分布是负二项分布的一个特例，因为可以证明 \(\text{Poi}(\lambda) = \lim_{r \to \infty} \text{NegBinom}(r, \frac{\lambda}{1+\lambda})\)。另一个特例是 \( r=1 \) 时，这称为 **几何分布**。

## 2.2.2 实数域上的连续分布

本节讨论一些定义在实数域上的单变量分布，即 \( x \in \mathbb{R} \) 时的 \( p(x) \)。

### 2.2.2.1 高斯（正态）分布

最广泛使用的单变量分布是 **高斯分布**，也称为 **正态分布**。（关于这些名称的讨论，见 [Mur22, 第 2.6.4 节]。）高斯分布的 pdf（概率密度函数）由下式给出：

```
\(\mathcal{N}(x|\mu, \sigma^2) \triangleq \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{1}{2\sigma^2}(x-\mu)^2}\) \tag{2.27}
```

![](img/ca72c1626f4850f058a9edc138c1ac73_42_0.png)

图 2.1：（a）N(0,1)、T_1(0,1) 和 Laplace(0, 1/\sqrt{2}) 的 pdf。高斯分布和拉普拉斯分布的均值均为 0，方差均为 1。当 \nu = 1 时，Student 分布的均值和方差未定义。（b）这些 pdf 的对数。需要注意的是，Student 分布对任意参数值均不是对数凹的，而拉普拉斯分布则是。尽管如此，两者均为单峰。由 student_laplace_pdf_plot.ipynb 生成。

其中 \(\sqrt{2\pi\sigma^2}\) 是确保概率密度积分为 1 所需的归一化常数。参数 \(\mu\) 表示分布的均值，其也等于众数。参数 \(\sigma^2\) 表示方差。有时我们会讨论高斯分布的 **精度**，即逆方差：\(\lambda = 1/\sigma^2\)。高精度意味着以 \(\mu\) 为中心的窄分布（低方差）。

高斯分布的累积分布函数（cdf）定义为

```
\(\Phi(x; \mu, \sigma^2) \triangleq \int_{-\infty}^x \mathcal{N}(z|\mu, \sigma^2) dz\)
```

若 \(\mu = 0\) 且 \(\sigma = 1\)（即 **标准正态** 分布），则简写为 \(\Phi(x)\)。

### 2.2.2.2 半正态分布

对于某些问题，我们需要定义在非负实数上的分布。构建此类分布的一种方法是定义 \( Y = |X| \)，其中 \( X \sim N(0, \sigma^2) \)。\( Y \) 的诱导分布称为 **半正态分布**，其 pdf 为

```
\(\mathcal{N}_+(y|\sigma) \triangleq 2\mathcal{N}(y|0, \sigma^2) = \frac{\sqrt{2}}{\sigma\sqrt{\pi}} \exp \left( -\frac{y^2}{2\sigma^2} \right) y \ge 0\)
```

可将其视为将 \( N(0, \sigma^2) \) 分布“向自身对折”所得。

### 2.2.2.3 Student t 分布

高斯分布的一个问题是对异常值敏感，因为概率随与中心的（平方）距离呈指数级快速衰减。一个更鲁棒的分布是 **Student t 分布**，我们将简称为 **Student 分布**。其 pdf 如下：

```
\(\mathcal{T}_\nu(x|\mu, \sigma^2) = \frac{1}{Z} \left[ 1 + \frac{1}{\nu} \left( \frac{x - \mu}{\sigma} \right)^2 \right]^{-(\frac{\nu+1}{2})}\)
(2.30)
```

```
\( Z = \frac{\sqrt{\nu \pi} \sigma \Gamma(\frac{\nu}{2})}{\Gamma(\frac{\nu+1}{2})} = \sqrt{\nu} \sigma B(\frac{1}{2}, \frac{\nu}{2})\)
(2.31)
```

其中 \(\mu\) 是均值，\(\sigma > 0\) 是尺度参数（非标准差），\(\nu > 0\) 称为 **自由度**（尽管更好的术语可能是 **正态度** [Kru13]，因为 \(\nu\) 较大时分布表现得像高斯分布）。这里 \(\Gamma(a)\) 是由下式定义的 **伽玛函数**：

```
\(\Gamma(a) \triangleq \int_0^\infty x^{a-1} e^{-x} dx\)
(2.32)
```

而 \(B(a, b)\) 是由下式定义的 **贝塔函数**：

```
\(B(a, b) \triangleq \frac{\Gamma(a)\Gamma(b)}{\Gamma(a + b)}\)
(2.33)
```

### 2.2.2.4 柯西分布

若 \(\nu=1\)，Student 分布称为 **柯西** 或 **洛伦兹** 分布。其 pdf 由下式定义：

```
\(\mathcal{C}(x|\mu, \gamma) = \frac{1}{Z} \left[ 1 + \left( \frac{x - \mu}{\gamma} \right)^2 \right]^{-1}\)
(2.34)
```

其中 \(Z = \gamma B(\frac{1}{2}, \frac{1}{2}) = \gamma \pi\)。该分布的显著特征在于其尾部非常重，以致定义均值的积分不收敛。

**半柯西** 分布是柯西分布（均值为 0）的一个版本，将其“向自身对折”，因此所有概率密度均位于正实数上。故其形式为

```
\(\mathcal{C}_+(x|\gamma) \triangleq \frac{2}{\pi \gamma} \left[ 1 + \left( \frac{x}{\gamma} \right)^2 \right]^{-1}\)
(2.35)
```

### 2.2.2.5 拉普拉斯分布

另一种尾部较重的分布是 **拉普拉斯分布**，又称 **双侧指数分布**。其 pdf 如下：

```
\(\text{Laplace}(x|\mu, b) \triangleq \frac{1}{2b} \exp \left( - \frac{|x - \mu|}{b} \right)\)
(2.36)
```

这里 \(\mu\) 是位置参数，\(b > 0\) 是尺度参数。参见图 2.1 的图示。

### 2.2.2.6 次高斯分布与超高斯分布

高斯分布主要有两种变体，分别称为 **超高斯** 或 **尖峰厚尾** （"Lepto" 源自希腊语，意为"窄"）和 **次高斯** 或 **平峰** （"Platy" 源自希腊语，意为"宽"）。这些分布在 **峰度** 上有所不同，峰度衡量其尾部的重轻程度（即，远离均值处密度趋于零的速度）。更准确地说，峰度定义为

\(\text{kurt}(z) \triangleq \frac{\mu_4}{\sigma^4} = \frac{\mathbb{E} [(Z - \mu)^4]}{(\mathbb{E} [(Z - \mu)^2])^2}\)

其中 \(\sigma\) 为标准差，\(\mu_4\) 为 4 阶中心矩。（因此 \(\mu_1 = \mu\) 是均值，\(\mu_2 = \sigma^2\) 是方差。）对于标准高斯分布，峰度为 3，因此有些作者将 **超额峰度** 定义为峰度减 3。

超高斯分布（例如拉普拉斯分布）具有正超额峰度，因而比高斯分布具有更重的尾部。次高斯分布（例如均匀分布）具有负超额峰度，因而比高斯分布具有更轻的尾部。参见图 2.2 的示意图。
