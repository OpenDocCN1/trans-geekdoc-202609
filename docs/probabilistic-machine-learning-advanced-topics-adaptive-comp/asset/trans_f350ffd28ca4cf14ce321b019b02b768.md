## 23.2.4.1 仿射自回归流

举个具体的例子，我们可以将 $h$ 取作一种由对数尺度 $\alpha$ 和偏置 $\mu$ 参数化的仿射标量双射（第 23.2.2.1 节）。这种自回归流被称为 **仿射自回归流**。第 $i$ 个分量的参数 $\alpha_i$ 和 $\mu_i$ 是 $\boldsymbol{x}_{1:i-1}$ 的函数，因此 $\boldsymbol{f}$ 采用以下形式：

$x_i = u_i \exp(\alpha_i(\boldsymbol{x}_{1:i-1})) + \mu_i(\boldsymbol{x}_{1:i-1})$.
(23.22)

如图 23.4(a) 所示。我们可以通过以下方式求其逆：

$u_i = (x_i - \mu_i(\boldsymbol{x}_{1:i-1})) \exp(-\alpha_i(\boldsymbol{x}_{1:i-1}))$.
(23.23)

如图 23.4(b) 所示。最后，我们可以通过以下方式计算对数雅各比行列式绝对值：

\(\log |\det \mathbf{J}(\boldsymbol{f})| = \log \left| \prod_{i=1}^D \exp(\alpha_i(\boldsymbol{x}_{1:i-1})) \right| = \sum_{i=1}^D \alpha_i(\boldsymbol{x}_{1:i-1}).\)
(23.24)

让我们来看一个仿射自回归流在二维密度估计问题上的示例。考虑一个仿射自回归流 $\boldsymbol{x} = (x_1, x_2) = \boldsymbol{f}(\boldsymbol{u})$，其中 $\boldsymbol{u} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$ 且 $\boldsymbol{f}$ 是一个单自回归双射。由于 $x_1$ 是 $u_1 \sim \mathcal{N}(0, 1)$ 的仿射变换，它是均值为 $\mu_1$、标准差为 $\sigma_1 = \exp \alpha_1$ 的高斯分布。同样，如果我们将 $x_1$ 视为固定值，$x_2$ 是 \(u_2 \sim \mathcal{N}(0, 1)\) 的一个仿射变换，所以它是 *条件*高斯分布，均值为 \(\mu_2(x_1)\)，标准差为 \(\sigma_2(x_1) = \exp(\alpha_2(x_1))\)。因此，一个单仿射自回归双射总是产生具有高斯条件分布的分布，即以下形式的分布：

```
\(p(x_1, x_2) = p(x_1) p(x_2|x_1) = \mathcal{N}(x_1|\mu_1, \sigma_1^2) \mathcal{N}(x_2|\mu_2(x_1), \sigma_2(x_1)^2)\) (23.25)
```

此结果可推广到任意维度 \(D\)。

无论函数 \(\alpha_2(x_1)\) 和 \(\mu_2(x_1)\) 多么灵活，单个仿射双射的表达能力都不强。例如，假设我们想用这样的流来拟合图 23.5(a) 所示的十字形密度。得到的最大似然拟合如图 23.5(b) 所示。红色等值线显示预测分布 \(\hat{p}(\mathbf{x})\)，它显然无法捕捉真实分布。绿色点显示数据样本的变换版本 \(p(\mathbf{u})\)；我们可以看出，这与高斯基础分布相去甚远。

幸运的是，我们可以通过组合多个自回归双射（层），并在每个层之后反转变量顺序来获得更好的拟合。例如，图 23.5(c) 显示了将具有 5 层的仿射自回归流应用于同一问题的结果。红色等值线表明我们已匹配经验分布，绿色点表明我们已匹配高斯基础分布。

请注意，获得更好拟合的另一种方法是将仿射双射 \(h\) 替换为更灵活的双射，例如单调 MLP（第 23.2.2.3 节）或单调样条（第 23.2.2.5 节）。

## 23.2.4.2 掩码自回归流

如我们所见，条件网络 $\Theta_i$ 可以是任意非线性函数。对它们进行参数化最直接的方法是为每个 $i$ 分别参数化，例如使用 $D$ 个独立的神经网络。然而，对于大 $D$ 来说，这种方法可能参数效率低下。

在实践中，我们通常通过将条件网络组合成一个单一模型 $\Theta$ 来在它们之间共享参数，该模型接收 $\mathbf{x}$ 并输出 $(\boldsymbol{\theta}_1, \dots, \boldsymbol{\theta}_D)$。为了使双射保持自回归性，我们必须约束 $\Theta$，使得 $\boldsymbol{\theta}_i$ 仅取决于 $\mathbf{x}_{1:i-1}$ 而不取决于 $\mathbf{x}_{i:D}$。实现这一点的一种方法是从任意神经网络（MLP、CNN、ResNet 等）开始，并丢弃连接（例如，通过将权重置零），直到 $\boldsymbol{\theta}_i$ 仅是 $\mathbf{x}_{1:i-1}$ 的函数。

图 23.6: 使用仿射标量双射的逆自回归流。在本图中，$u$ 是流的输入（从基础分布中采样），$x$ 是其输出（从变换分布中采样）。来自 [Jan18]。感谢 Eric Jang 允许使用。

这种方法的一个例子是 [PPM17] 的 **掩码自回归流** (**MAF**) 模型。该模型是仿射自回归流与置换层的组合，正如我们在第 23.2.4.1 节中所述。MAF 实现组合条件网络 $\Theta$ 的方式如下：它从一个 MLP 开始，然后将每一层的权重矩阵与相同大小的二进制掩码进行逐元素相乘（不同层使用不同的掩码）。掩码使用 [Ger+15] 的方法构建。这确保了每当 $j \ge i$ 时，从 $x_j$ 到 $\theta_i$ 的所有计算路径都被置零，从而使 $\theta_i$ 仅成为 $x_{1:i-1}$ 的函数。尽管如此，求解掩码条件网络 $\Theta$ 的计算成本与求解原始（未掩码）MLP 相同。MAF（及相关模型）的关键优势在于，给定 $x$ 时，所有参数 $(\theta_1, \dots, \theta_D)$ 可以通过一次神经网络求解高效计算，因此逆 $f^{-1}$ 的计算速度很快。因此，我们可以对任意数据点高效求解流模型的概率密度。然而，为了计算 $f$，条件网络 $\Theta$ 必须被调用总共 $D$ 次，因为并非所有 $x$ 的条目在开始时都可用。因此，从流中生成新样本的开销是求解其概率密度函数的 $D$ 倍。这使得 MAF 适合于密度估计，但不太适合于数据生成。

## 23.2.4.3 逆自回归流

如我们所见，产生第 $i$ 个输出 $x_i$ 的参数 $\theta_i$ 是先前输出 $x_{1:i-1}$ 的函数。这确保了雅各比矩阵 $\mathbf{J}(\mathbf{f})$ 是三角形的，因此其行列式可以高效计算。然而，还有另一种可能性：我们可以使 $\theta_i$ 成为先前 *输入* 的函数，即 $u_{1:i-1}$ 的函数。这导致了以下双射，称为 **逆自回归**：

```
$x_i = h(u_i; \Theta_i(u_{1:i-1})), \quad i = 1, \dots, D.$ (23.26)
```

与其自回归对应物类似，这个双射具有三角形的雅各比矩阵，其行列式也由 $\det \mathbf{J}(\mathbf{f}) = \prod_{i=1}^D \frac{dh}{du}$ 给出。图 23.6 说明了一个逆自回归流，适用于 $h$ 为仿射的情况。
