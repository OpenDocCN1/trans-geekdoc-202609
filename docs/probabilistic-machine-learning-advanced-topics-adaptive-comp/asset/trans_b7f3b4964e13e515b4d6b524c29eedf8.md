

## 12.5.5 黎曼流形 HMC

如果我们允许协方差矩阵随位置变化，使得 $\Sigma$ 成为 $\theta$ 的函数，该方法称为 **黎曼流形 HMC** 或 **RM-HMC** [GC11; Bet13]，因为移动遵循弯曲流形，而非由常数 $\Sigma$ 诱导的平坦流形。

协方差矩阵的一个自然选择是使用当前位置的海森矩阵，以捕捉局部几何：

$\Sigma(\theta) = \nabla^2 \mathcal{E}(\theta)$ (12.78)

由于这并不总是正定的，对于某些问题，可使用的替代方案是使用 Fisher 信息矩阵（第 3.3.4 节），其由以下公式给出：

$\Sigma(\theta) = -\mathbb{E}_{p(x|\theta)} [\nabla^2 \log p(x|\theta)]$ (12.79)

一旦计算出 $\Sigma(\theta)$，就可以按如下方式计算动能：

$\mathcal{K}(\theta, v) = \frac{1}{2} \log((2\pi)^D |\Sigma(\theta)|) + \frac{1}{2} v^\top \Sigma(\theta) v$ (12.80)

不幸的是，$\theta$ 和 $v$ 的哈密顿更新不再可分离，这使得 RM-HMC 算法更难实现，因此并未广泛使用。

## 12.5.6 Langevin Monte Carlo (MALA)

当我们进行 $L=1$ 步蛙跳时，HMC 的一个特例出现。这被称为 **朗之万蒙特卡洛（LMC）**，或 **调整朗之万算法（MALA）** [RT96]。这导致了算法 12.4 中所示的简化算法。

```
Algorithm 12.4: Langevin Monte Carlo
1 for t = 1 : T do
2   Generate random momentum $v_{t-1} \sim \mathcal{N}(0, \Sigma)$
3   $\theta^* = \theta_{t-1} - \frac{\eta^2}{2} \Sigma^{-1} \nabla \mathcal{E}(\theta_{t-1}) + \eta \Sigma^{-1} v_{t-1}$
4   $v^* = v_{t-1} - \frac{\eta}{2} \nabla \mathcal{E}(\theta_{t-1}) - \frac{\eta}{2} \nabla \mathcal{E}(\theta^*)$
5   Compute $\alpha = \min(1, \exp[-\mathcal{H}(\theta^*, v^*)] / \exp[-\mathcal{H}(\theta_{t-1}, v_{t-1})])$
6   Set $\theta_t = \theta^*$ with probability $\alpha$, otherwise $\theta_t = \theta_{t-1}$.
```

进一步的简化是消除 MH 接受步骤。在此情况下，更新变为

$\theta_t = \theta_{t-1} - \frac{\eta^2}{2} \Sigma^{-1} \nabla \mathcal{E}(\theta_{t-1}) + \eta \Sigma^{-1} v_{t-1}$ (12.81)

$= \theta_{t-1} - \frac{\eta^2}{2} \Sigma^{-1} \nabla \mathcal{E}(\theta_{t-1}) + \eta \sqrt{\Sigma^{-1}} \epsilon_{t-1}$ (12.82)

其中 $v_{t-1} \sim \mathcal{N}(0, \Sigma)$ 且 $\epsilon_{t-1} \sim \mathcal{N}(0, \mathbf{I})$。这就像带有噪声的梯度下降。如果我们将 $\Sigma$ 设置为 Fisher 信息矩阵，则这将变成带有噪声的自然梯度下降（第 6.4 节）。

现在假设 \(\boldsymbol{\Sigma} = \mathbf{I}\)，并且我们设置 \(\eta = \sqrt{2}\)。在连续时间中，我们得到以下随机微分方程（SDE），称为 **朗之万扩散**：

\(d\boldsymbol{\theta}_t = -\nabla \mathcal{E}(\boldsymbol{\theta}_t)dt + \sqrt{2}d\mathbf{B}_t\) (12.83)

其中 \(\mathbf{B}_t$ 表示 \(D$ 维布朗运动。如果我们使用此方法生成样本，该方法称为 **未调整朗之万算法** 或 **ULA** [Par81; RT96]。

## 12.5.7 SGD 与朗之万采样之间的连接

在本节中，我们将讨论随机梯度下降（SGD）与朗之万采样之间的深层联系，遵循 [BZ20, Sec 10.2.3] 的表述。

考虑加性损失的最小化

\(\mathcal{L}(\boldsymbol{\theta}) = \sum_{n=1}^N \mathcal{L}_n(\boldsymbol{\theta})\) (12.84)

例如，我们可以定义 \(\mathcal{L}_n(\boldsymbol{\theta}) = -\log p(y_n|\mathbf{x}_n, \boldsymbol{\theta})$。我们将使用小批量梯度近似：

\(\nabla_B \mathcal{L}(\boldsymbol{\theta}) = \frac{1}{B} \sum_{n \in S} \nabla \mathcal{L}_n(\boldsymbol{\theta})\) (12.85)

其中 \(\mathcal{S} = \{i_1, \dots, i_B\}$ 是大小为 \(B$ 的随机选择的索引集。为了分析简便，我们假设索引是从 \(\{1, \dots, N\}$ 中有放回地选择的。

让我们定义由小批量引起的（缩放的）估计梯度误差为

\(\boldsymbol{v}_t \triangleq \sqrt{\eta} (\nabla \mathcal{L}(\boldsymbol{\theta}_t) - \nabla_B \mathcal{L}(\boldsymbol{\theta}_t))\) (12.86)

这被称为 **扩散项**。然后我们可以将 SGD 更新改写为

\(\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta \nabla_B \mathcal{L}(\boldsymbol{\theta}_t) = \boldsymbol{\theta}_t - \eta \nabla \mathcal{L}(\boldsymbol{\theta}_t) + \sqrt{\eta} \boldsymbol{v}_t\) (12.87)

扩散项 \(\boldsymbol{v}_t$ 的均值为 0，因为

\(\mathbb{E}[\nabla_B \mathcal{L}(\boldsymbol{\theta})] = \frac{1}{B} \sum_{j=1}^B \mathbb{E}[\nabla \mathcal{L}_{i_j}(\boldsymbol{\theta})] = \frac{1}{B} \sum_{j=1}^B \nabla \mathcal{L}(\boldsymbol{\theta}) = \nabla \mathcal{L}(\boldsymbol{\theta})\) (12.88)

为了计算扩散项的方差，请注意

\(\mathbb{V}[\nabla_B \mathcal{L}(\boldsymbol{\theta})] = \frac{1}{B^2} \sum_{j=1}^B \mathbb{V}[\nabla \mathcal{L}_{i_j}(\boldsymbol{\theta})]\) (12.89)

$$
\mathbb{V} [\nabla \mathcal{L}_{i_j}(\boldsymbol{\theta})] = \mathbb{E} [ \nabla \mathcal{L}_{i_j}(\boldsymbol{\theta}) \nabla \mathcal{L}_{i_j}(\boldsymbol{\theta})^\mathsf{T} ] - \mathbb{E} [ \nabla \mathcal{L}_{i_j}(\boldsymbol{\theta}) ] \mathbb{E} [ \nabla \mathcal{L}_{i_j}(\boldsymbol{\theta})^\mathsf{T} ] \quad (12.90)
$$
$$
= \left( \frac{1}{N} \sum_{n=1}^N \nabla \mathcal{L}_n(\boldsymbol{\theta}) \nabla \mathcal{L}_n(\boldsymbol{\theta})^\mathsf{T} \right) - \nabla \mathcal{L}(\boldsymbol{\theta}) \nabla \mathcal{L}(\boldsymbol{\theta})^\mathsf{T} \triangleq \mathbf{D}(\boldsymbol{\theta}) \quad (12.91)
$$

其中 \(\mathbf{D}(\boldsymbol{\theta})$ 称为 **扩散矩阵**。因此 \(\mathbb{V}[\mathbf{v}_t] = \frac{\eta}{B}\mathbf{D}(\boldsymbol{\theta}_t)$。

[LTW15] 证明以下连续时间随机微分方程是小批量 SGD 的一阶近似（假设损失函数是 Lipschitz 连续的）：

$$
d\boldsymbol{\theta}(t) = -\nabla \mathcal{L}(\boldsymbol{\theta}(t))dt + \sqrt{\frac{\eta}{B}\mathbf{D}(\boldsymbol{\theta}_t)}d\mathbf{B}(t) \quad (12.92)
$$

其中 \(\mathbf{B}(t)$ 是布朗运动。因此，小批量引起的噪声使 SGD 表现得像一个朗之万采样器。（有关更多信息，请参见 [Hu+17]。）

噪声的缩放因子 \(\tau = \frac{\eta}{B}$ 扮演 **温度** 的角色。因此我们看到，使用较小的批量大小就像使用较高的温度；添加的噪声确保 SGD 避免进入狭窄峡谷，而将大部分时间花在具有更好泛化性能的平坦极小值中 [Kes+17]。有关此点的更多讨论，请参见第 17.4.1 节。

## 12.5.8 将 HMC 应用于受约束参数

要应用 HMC，我们要求所有隐含量都是连续的（实值）且具有无约束支撑，即 \(\boldsymbol{\theta} \in \mathbb{R}^D$，因此需要将离散隐含变量边缘化掉（尽管一些最近的工作，如 [NDL20; Zho20]，放宽了此要求）。

## 12.5.9 加速 HMC

虽然 HMC 使用梯度信息来勘探典型集，但有时典型集的几何结构可能难以采样。有关估计质量矩阵的方法，请参见第 12.5.4.3 节，这有助于处理此类困难情况。

另一个问题是评估目标分布的成本，$\mathcal{E}(\boldsymbol{\theta}) = -\log \tilde{p}(\boldsymbol{\theta})$。对于许多 ML 应用程序，其形式为 $\log \tilde{p}(\boldsymbol{\theta}) = \log p_0(\boldsymbol{\theta}) + \sum_{n=1}^N \log p(\boldsymbol{\theta}_n|\boldsymbol{\theta})$。计算这需要 $O(N)$ 时间。我们可以通过使用随机梯度方法来加速此过程；详情请参见第 12.7 节。

## 12.6 MCMC 收敛

我们从任意初始状态启动 MCMC。如第 2.6.4 节所述，只有当马尔可夫链“忘记”了其起始位置时，样本才会来自链的平稳分布。进入平稳分布所需的时间称为混合时间（详情请参见第 12.6.1 节）。在链达到其平稳分布之前收集的样本不来自 $p^*$，通常会被丢弃。这个初始期间（其样本将被忽略）称为烧-in 阶段。

例如，考虑整数 $\{0, 1, \dots, 20\}$ 上的均匀分布。假设我们使用对称随机游走从中采样。在图 12.11 中，我们展示了算法的两次运行。左侧从状态 10 开始；右侧从状态 17 开始。即使在这个小问题中，也需要超过 200 步，链才会“忘记”其起始位置。能够进行更大变化的提议分布可以更快收敛。例如，[BD92; Man] 证明，大约需要 7 次洗牌才能充分混合一副 52 张的牌（即，确保分布是均匀的）。

在第 12.6.1 节中，我们将讨论如何理论上计算混合时间。在实践中，这可能非常困难 [BBM10]（这是 MCMC 的根本弱点之一），因此在第 12.6.2 节中，我们将讨论实用启发式方法。
