## 19.5.4 标签偏移的无监督技术

在本节中，我们描述了一种称为 **黑盒偏移估计** 的方法，源自 [LWS18]，可用以无监督方式解决 **标签偏移** 问题。我们假设目标分布中唯一变化的是标签先验，即，如果源分布表示为 $p(\boldsymbol{x}, \boldsymbol{y})$，目标分布表示为 $q(\boldsymbol{x}, \boldsymbol{y})$，则我们假设 $q(\boldsymbol{x}, \boldsymbol{y}) = p(\boldsymbol{x}|\boldsymbol{y})q(\boldsymbol{y})$。

首先注意，对于任何确定性函数 $f : \mathcal{X} \rightarrow \mathcal{Y}$，我们有

```
$p(\boldsymbol{x}|y) = q(\boldsymbol{x}|y) \implies p(f(\boldsymbol{x})|y) = q(f(\boldsymbol{x})|y) \implies p(\hat{y}|y) = q(\hat{y}|y)$
```

其中 $\hat{y} = f(\boldsymbol{x})$ 是预测标签。令 $\mu_i = q(\hat{y} = i)$ 为模型在测试集上预测类别 $i$ 的经验比例，令 $q(y = i)$ 为测试集上真实但未知的标签分布，令 $C_{ij} = p(\hat{y} = i|y = j)$ 为在训练集上估计的类别混淆矩阵。

则我们有

```
$\mu_i = \sum_y q(\hat{y}|y)q(y) = \sum_y p(\hat{y}|y)q(y) = \sum_y p(\hat{y}, y)\frac{q(y)}{p(y)}$
```

我们可以将其写成矩阵-向量形式如下：

```
$\mu_i = \sum_j C_{ij}q_j, \implies \boldsymbol{\mu} = \mathbf{C}\boldsymbol{q}$
```

因此我们可以求解 $\boldsymbol{q} = \mathbf{C}^{-1}\boldsymbol{\mu}$，前提是 $\mathbf{C}$ 非奇异（如果 $\mathbf{C}$ 是强对角的，即模型正确预测类别 $y_i$ 的频率高于任何其他类别 $y_j$，则会出现这种情况）。我们还要求对于每个 $q(y) > 0$ 都有 $p(y) > 0$，这意味着我们在训练时见过每个标签。

一旦我们知道新的标签分布 $q(\boldsymbol{y})$，我们就可以调整判别式分类器，将新的标签先验考虑在内，如下所示：

```
$q(y|\boldsymbol{x}) = \frac{q(\boldsymbol{x}|y)q(y)}{q(\boldsymbol{x})} = \frac{p(\boldsymbol{x}|y)q(y)}{q(\boldsymbol{x})} = \frac{p(y|\boldsymbol{x})p(\boldsymbol{x})}{p(y)}\frac{q(y)}{q(\boldsymbol{x})} = p(y|\boldsymbol{x})\frac{q(y)}{p(y)}\frac{p(\boldsymbol{x})}{q(\boldsymbol{x})}$
```

我们可以安全地忽略 $\frac{p(\boldsymbol{x})}{q(\boldsymbol{x})}$ 项，因为它关于 $y$ 是常数，并且可以代入我们对标签分布的估计来计算 $\frac{q(y)}{p(y)}$。

总结，此方法有三个要求：(1) 混淆矩阵可逆；(2) 测试时没有新标签；(3) 唯一变化的是标签先验。如果这三个条件成立，上述方法是一个有效的估计器。有关更多详情，请参见 [LWS18]，以及基于最大似然（而非矩匹配）来估计新的边际标签分布的替代方法 [Gar+20]。

## 19.5.5 测试时自适应

在某些设置中，可以持续更新模型参数。这使模型能够适应输入分布的变化。这被称为 **测试时自适应** 或 **TTA**。它与第 19.5.3 节的无监督域自适应方法的区别在于，在在线设置中，我们只有在源上训练的模型，而没有源分布。在 [Sun+20] 中，他们提出了一种称为 TTT（“测试时训练”）的方法来自适应判别式模型。在此方法中，使用自监督代理任务来创建代理标签，然后可用于在运行时自适应模型。更具体地说，假设我们创建一个 Y 形结构网络，首先执行特征提取 \( x \rightarrow h \)，然后使用 $h$ 来预测输出 $y$ 和某些代理输出 $r$，例如输入图像的旋转角度。如果我们使用数据增强，则旋转角度是已知的。因此，我们可以在测试时应用此技术，即使 $y$ 未知，也可以更新网络的 $x \rightarrow h \rightarrow r$ 部分，该部分通过共享瓶颈（特征层）$h$ 影响 $y$ 的预测。

当然，如果代理输出（例如旋转角度）未知，我们就无法使用 TTT 之类的代理监督学习方法。在 [Wan+20a] 中，他们提出了一种受半监督学习方法启发的方法，他们称之为 TENT，代表“基于熵最小化的测试时自适应”。其思想是更新分类器参数，以最小化一批测试样本上预测分布的熵。在 [Goy+22] 中，他们从元学习角度为这一启发式提供了理由。在 [ZL21] 中，他们提出了 TENT 的贝叶斯版本，称为 BACS，代表“协变偏移下的贝叶斯自适应”。在 [ZLF21] 中，他们提出了一种称为 MEMO（“单测试点边际熵最小化”）的方法，可用于任何架构。其想法再次是在测试时对输入 $x$ 应用数据增强，以创建一组输入 $ \tilde{x}_1, \dots, \tilde{x}_B $。现在我们更新参数，以最小化由平均分布产生的预测熵

```
\(\bar{p}(y|x, w) = \frac{1}{B} \sum_{b=1}^B p(y|\tilde{x}_b, w)\)
```

这确保了模型对每个输入扰动给出相同的预测，并且预测是自信的（低熵）。

基于熵方法的替代方案是使用伪标签（由源模型在无标签目标上生成的预测输出），然后在其上进行自训练（例如，参见 [KML20; LHF20; Che+22]），通常带有额外的正则化器以防止过拟合。

## 19.6 从多个分布中学习

在第 19.2 节中，我们讨论了模型在单一源分布上训练，然后在不同的目标分布上评估的设置。在本节中，我们将其推广到模型在 \( J \ge 2 \) 个源分布的数据上训练，然后在目标分布的数据上进行测试的设置。这取决于 \( J \) 的值，包含了多种不同的问题设置，如图 19.11 所总结。

### 19.6.1 多任务学习

在多任务学习（MTL）[Car97] 中，我们有来自 \( J \) 个不同分布的标记数据 \( \mathcal{D}^j = \{(\mathbf{x}_n^j, y_n^j) : n = 1 : N_j \} \)，目标是学习一个同时在所有 \( J \) 个分布上都能很好预测的模型，其中 \( f(\mathbf{x}, j) : \mathcal{X} \rightarrow \mathcal{Y}_j \) 是第 \( j \) 个任务的输出。例如，我们可能希望将大小为 \( H \times W \times 3 \) 的彩色图像映射为每个像素的一组语义标签 \( \mathcal{Y}^1 = \{1, \dots, C\}^{HW} \)，如

以及每个像素的一组预测深度值 $\mathcal{Y}^2 = \mathbb{R}^{HW}$。我们可以使用 ERM 来实现这一点，其中每个任务都有多个样本：

```
$$f^* = \operatorname{argmin}_f \sum_{j=1}^J \sum_{n=1}^{N_j} \ell_j(\mathbf{y}_n^j, f(\mathbf{x}_n^j, j))$$ (19.25)
```

其中 $\ell_j$ 是任务 $j$ 的损失函数（经过适当缩放）。

解决 MTL 有许多方法。最简单的是拟合一个带有多个“输出头”的单一模型，如图 19.12 所示。这被称为“共享主干网络”。不幸的是，这通常会导致比训练 $J$ 个单任务网络更差的性能。在 [Mis+16] 中，他们提出对每个单任务网络的激活进行加权组合，他们称这种方法为“交叉缝合网络”。有关神经方法的更详细综述，请参见 [ZY21]，以及有关此问题的理论分析，请参见 [BLS11]。

请注意，多任务学习并不总是有助于每个任务的性能，因为有时可能会出现“任务干扰”或“负迁移”（例如，参见 [MAP17; Sta+20; WZR20]）。在这种情况下，我们应该使用单独的网络，而不是使用一个带有多个输出头的模型。
