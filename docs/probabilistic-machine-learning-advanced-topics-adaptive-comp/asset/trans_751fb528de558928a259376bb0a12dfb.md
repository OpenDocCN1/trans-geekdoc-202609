### 8.2.1.1 跟踪与状态估计

LG-SSM 的一个常见应用是从带噪声的测量（例如雷达或摄像头）中跟踪物体，例如飞机或动物。例如，假设我们想要跟踪在 2D 中移动的物体。（我们将在 29.7.1 节中更详细地讨论此示例。）隐藏状态 \(\mathbf{z}_t\) 对移动物体的位置 \((x_{t1}, x_{t2})\) 和速度 \((\dot{x}_{t1}, \dot{x}_{t2})\) 进行编码。（速度未被观测，但可以从位置的变化中推断出来。）我们假设以采样周期 \(\Delta\) 获得测量值。新位置等于旧位置加上 \(\Delta\) 倍的速度，再加上所有项中添加的噪声：

$$
\mathbf{z}_t = \underbrace{\begin{pmatrix} 1 & 0 & \Delta & 0 \\ 0 & 1 & 0 & \Delta \\ 0 & 0 & 1 & 0 \\ 0 & 0 & 0 & 1 
\end{pmatrix}}_{\mathbf{F}} \mathbf{z}_{t-1} + \mathbf{q}_t \tag{8.20}
$$

其中 \(\mathbf{q}_t \sim \mathcal{N}(\mathbf{0}, \mathbf{Q}_t)\)。观测提取位置并添加噪声：

$$
\mathbf{y}_t = \underbrace{\begin{pmatrix} 1 & 0 & 0 & 0 \\ 0 & 1 & 0 & 0 
\end{pmatrix}}_{\mathbf{H}} \mathbf{z}_t + \mathbf{r}_t \tag{8.21}
$$

其中 \(\mathbf{r}_t \sim \mathcal{N}(\mathbf{0}, \mathbf{R}_t)\)。

## 8.2.2 卡尔曼滤波器

卡尔曼滤波器（KF）是用于线性高斯状态空间模型的精确贝叶斯滤波算法。得到的算法是第 9.2.2 节中 HMM 滤波器的高斯类比。时刻 \(t\) 的信念状态现在由 \(p(z_t|y_{1:t}) = \mathcal{N}(z_t|\mu_{t|t}, \Sigma_{t|t})\) 给出，其中我们使用记号 \(\mu_{t|t'}\) 和 \(\Sigma_{t|t'}\) 来表示给定 \(y_{1:t'}\) 时的后验均值和协方差。由于所有内容都是高斯的，我们可以以封闭形式执行预测和更新步骤，如下文所述（推导过程见第 8.2.2.4 节）。

### 8.2.2.1 预测步骤

隐藏状态的一步先验预测，也称为时间更新步骤，由以下给出：

```
\(p(z_t|y_{1:t-1}, u_{1:t}) = \mathcal{N}(z_t|\mu_{t|t-1}, \Sigma_{t|t-1})\) (8.22)
\(\mu_{t|t-1} = \mathbf{F}_t \mu_{t-1|t-1} + \mathbf{B}_t u_t + b_t\) (8.23)
\(\Sigma_{t|t-1} = \mathbf{F}_t \Sigma_{t-1|t-1} \mathbf{F}_t^\top + \mathbf{Q}_t\) (8.24)
```

5. 我们用 \(\mu_{t|t}\) 和 \(\Sigma_{t|t}\) 表示滤波信念状态的均值和协方差，但一些作者使用 \(m_t\) 和 \(\mathbf{P}_t\) 代替。我们用 \(\mu_{t|T}\) 和 \(\Sigma_{t|T}\) 表示平滑信念状态的均值和协方差，但一些作者使用 \(\mathbf{m}_t^s\) 和 \(\mathbf{P}_t^s\) 代替。最后，我们用 \(\mu_{t|t-1}\) 和 \(\Sigma_{t|t-1}\) 表示一步先验后验预测分布 \(p(z_t|y_{1:t-1})\) 的均值和协方差，而一些作者使用 \(\mathbf{m}_t^-\) 和 \(\mathbf{P}_t^-\) 代替。

### 8.2.2.2 更新步骤

更新步骤（也称为 **测量更新步骤**）可以使用贝叶斯规则计算，如下所示：

```
p(\mathbf{z}_t|\mathbf{y}_{1:t}, \mathbf{u}_{1:t}) = \mathcal{N}(\mathbf{z}_t|\boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t}) \tag{8.25}

\hat{\mathbf{y}}_t = \mathbf{H}_t \boldsymbol{\mu}_{t|t-1} + \mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t \tag{8.26}

\mathbf{S}_t = \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t \tag{8.27}

\mathbf{K}_t = \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} \mathbf{S}_t^{-1} \tag{8.28}

\boldsymbol{\mu}_{t|t} = \boldsymbol{\mu}_{t|t-1} + \mathbf{K}_t (\mathbf{y}_t - \hat{\mathbf{y}}_t) \tag{8.29}

\boldsymbol{\Sigma}_{t|t} = \boldsymbol{\Sigma}_{t|t-1} - \mathbf{K}_t \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \tag{8.30}

= \boldsymbol{\Sigma}_{t|t-1} - \mathbf{K}_t \mathbf{S}_t \mathbf{K}_t^\mathsf{T} \tag{8.31}
```

其中 $\mathbf{K}_t$ 是 **卡尔曼增益矩阵**。请注意，\(\hat{\mathbf{y}}_t\) 是预期观测值，因此 \(\mathbf{e}_t = \mathbf{y}_t - \hat{\mathbf{y}}_t\) 是 **残差误差**，也称为 **创新项**。观测的协方差表示为 $\mathbf{S}_t$，观测与状态之间的交叉协方差表示为 \(\mathbf{C}_t = \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T}\)。在实践中，为了计算卡尔曼增益，我们不使用 $\mathbf{K}_t = \mathbf{C}_t \mathbf{S}_t^{-1}$，而是求解线性系统 $\mathbf{K}_t \mathbf{S}_t = \mathbf{C}_t$。<sup>6</sup>

为了直观理解更新步骤，请注意，隐藏均值的更新 \(\boldsymbol{\mu}_{t|t} = \boldsymbol{\mu}_{t|t-1} + \mathbf{K}_t \mathbf{e}_t\) 是预测的新隐藏均值加上一个校正因子，该因子是 $\mathbf{K}_t$ 乘以误差信号 $\mathbf{e}_t$。如果 $\mathbf{H}_t = \mathbf{I}$，则 $\mathbf{K}_t = \boldsymbol{\Sigma}_{t|t-1} \mathbf{S}_t^{-1}$；在标量情况下，这变为 \(k_t = \Sigma_{t|t-1} / S_t\)，即先验（来自动态模型）方差与测量方差的比率，我们可以将其解释为逆信噪比。如果我们有强先验和/或非常嘈杂的传感器，|$\mathbf{K}_t$| 将很小，我们将对校正项赋予很少的权重。相反，如果我们有弱先验和/或高精度传感器，|$\mathbf{K}_t$| 将很大，我们将对校正项赋予很大的权重。同样，新协方差是旧协方差减去一个正定矩阵，这取决于测量值的信息性有多强。

请注意，通过使用矩阵反演引理，卡尔曼增益矩阵也可以写成：

```
\(\mathbf{K}_t = \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} (\mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t)^{-1} = (\boldsymbol{\Sigma}_{t|t-1}^{-1} + \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} \mathbf{H}_t)^{-1} \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} \tag{8.32}\)
```

如果 \(\mathbf{R}_t^{-1}\) 是预先计算的（例如，如果它随时间保持不变）且 \(N_y \gg N_z\)，则这很有用。此外，在公式 (8.97) 中，我们给出了滤波器的信息形式，该形式表明后验精度的形式为 \(\boldsymbol{\Sigma}_t^{-1} = \boldsymbol{\Sigma}_{t|t-1}^{-1} + \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} \mathbf{H}_t\)，因此我们也可以将增益矩阵写为 \(\mathbf{K}_t = \boldsymbol{\Sigma}_t \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1}\)。

### 8.2.2.3 后验预测

观测的一步先验后验预测密度可以按以下方式计算。（为简化记号，我们忽略输入和偏置项。）首先，我们计算隐藏状态的一步先验预测密度：

```
\(p(\mathbf{z}_t|\mathbf{y}_{1:t-1}) = \int p(\mathbf{z}_t|\mathbf{z}_{t-1}) p(\mathbf{z}_{t-1}|\mathbf{y}_{1:t-1}) d\mathbf{z}_{t-1} = \mathcal{N}(\mathbf{z}_t|\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}) \tag{8.33}

= \mathcal{N}(\mathbf{z}_t|\mathbf{F}_t \boldsymbol{\mu}_{t-1|t-1}, \mathbf{F}_t \boldsymbol{\Sigma}_{t-1|t-1} \mathbf{F}_t^\mathsf{T} + \mathbf{Q}_t) = \mathcal{N}(\mathbf{z}_t|\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}) \tag{8.34}\)
```
