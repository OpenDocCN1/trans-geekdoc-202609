

尽管如此，此注释允许将候选函数集缩小到已经经过此类变换的函数。此推理得出所谓的 c-凹函数集，\(\mathcal{F}_c \triangleq \{f \mid \exists g : \mathcal{X} \to \mathbb{R}, f = \overline{g}\}\)，可以证明等价地，这是函数 \(f\) 的集合，使得 \(f = \overline{\tilde{f}}\)。因此，可以将注意力集中于 c-凹函数，以使用所谓的半对偶公式求解 (6.199),

\(\sup_{f \in \mathcal{F}_c} \int_{\mathcal{X}} f \, d\mu + \int_{\mathcal{X}} \overline{f} \, d\nu.\)

从 (6.199) 到 (6.203)，我们移除了对偶变量 \(g\) 并将可行集缩小到 \(\mathcal{F}_c\)，代价是引入了高度非线性变换 \(\overline{f}\)。然而，这种重新公式非常有用，因为它允许我们将注意力限制在 c-凹函数上，特别是针对两类重要的成本函数 \(c\)：距离和平方欧几里得范数。

## 6.8.3.2 康托维奇-鲁宾斯坦对偶与 Lipschitz 势

当 \(c\) 为度量 \(d\) 时，即 (6.197) 中 \(p=1\) 时，会给出一个说明 c-凹性意义的显著结果。在此情况下，可以证明（ notably 利用 \(d\) 的三角不等式），一个 \(d\)-凹函数 \(f\) 是 1-Lipschitz（对于任意 \(\mathbf{x}, \mathbf{y}\) 都有 \(|f(\mathbf{x}) - f(\mathbf{y})| \le d(\mathbf{x}, \mathbf{y})\)），并且满足 \(\overline{f} = -f\)。因此，此结果可表述为以下恒等式：

\(W_1(\mu, \nu) = \sup_{f \in 1\text{-Lipschitz}} \int_{\mathcal{X}} f \, (d\mu - d\nu).\)

此结果具有众多实际应用。对 1-Lipschitz 函数的上确界可以在低维中利用密度的小波系数高效近似 [SJ08]，或者在更一般情况下通过训练参数化为 1-Lipschitz 的神经网络（使用 ReLU 激活函数，并对权重矩阵的元素施加界限）来启发式逼近 [ACB17]。

## 6.8.3.3 作为凸函数梯度的 Monge 映射：Brenier 定理

c-凹性的另一个应用在于情形 \(c(\mathbf{x}, \mathbf{y}) = \frac{1}{2} \|\mathbf{x} - \mathbf{y}\|^2\)，这与欧几里得空间中密度之间使用的平方 \(W_2\) 距离相符，差异仅在于系数 \(\frac{1}{2}\)。[Bre91] 首先展示的显著结果是：对于该代价的两个测度之间求解 (6.194) 的 Monge 映射存在（默认 \(\mu\) 足够正规，此处假设其相对于勒贝格测度具有密度），并且必然是一个凸函数的梯度。粗略地说，可以证明

\(T^\star = \arg \min_{T: T_\sharp \mu = \nu} \int_{\mathcal{X}} \frac{1}{2} \|\mathbf{x} - T(\mathbf{x})\|_2^2 \, \mu(d\mathbf{x}).\)

存在，并且是凸函数 \(u : \mathbb{R}^d \to \mathbb{R}\) 的梯度，即 \(T^\star = \nabla u\)。反之，对于任何凸函数 \(u\)，\(\mu\) 与位移 \(\nabla u_\sharp \mu\) 之间的最优传输映射必然等于 \(\nabla u\)。

我们提供证明草图：对于任何合理的代价函数 \(c\)（例如，下有界且下半连续），可以始终利用原-对偶关系：考虑 (6.196) 的最优耦合 \(P^\star\)，以及 (6.203) 的最优 c-凹对偶函数 \(f^\star\)。这特别意味着 \((f^*, g^* = \overline{f^*})\) 是 (6.199) 的最优解。这一对线性规划的互补松弛条件表明，若 \(\mathbf{x}_0, \mathbf{y}_0\) 在 \(P^*\) 的支撑集中，则必然（且充分地）\(f^*(\mathbf{x}_0) + \overline{f^*}(\mathbf{y}_0) = c(\mathbf{x}_0, \mathbf{y}_0)\)。因此，假设 \(\mathbf{x}_0, \mathbf{y}_0\) 确实在 \(P^*\) 的支撑集中。由等式 \(f^*(\mathbf{x}_0) + \overline{f^*}(\mathbf{y}_0) = c(\mathbf{x}_0, \mathbf{y}_0)\) 可以轻易得到 \(\overline{f^*}(\mathbf{y}_0) = c(\mathbf{x}_0, \mathbf{y}_0) - f^*(\mathbf{x}_0)\)。然而，还需回顾，根据定义，\(\overline{f^*}(\mathbf{y}_0) = \inf_c c(\mathbf{x}, \mathbf{y}_0) - f^*(\mathbf{x})\)。因此，\(\mathbf{x}_0\) 具有特殊性质，即它最小化 \(\mathbf{x} \rightarrow c(\mathbf{x}, \mathbf{y}_0) - f^*(\mathbf{x})\)。若此时回顾本节假设 \(c\) 为 \(c(\mathbf{x}, \mathbf{y}) = \frac{1}{2}\|\mathbf{x} - \mathbf{y}\|^2\)，则可得 \(\mathbf{x}_0\) 满足

\(\mathbf{x}_0 \in \operatorname{argmin}_{\mathbf{x}} \frac{1}{2}\|\mathbf{x} - \mathbf{y}_0\|^2 - f^*(\mathbf{x}).\)

假设 \(f^*\) 可微（可由 c-凹性证明），则得到恒等式

\(\mathbf{y}_0 - \mathbf{x}_0 - \nabla f^*(\mathbf{x}_0) = 0 \Rightarrow \mathbf{y}_0 = \mathbf{x}_0 - \nabla f^*(\mathbf{x}_0) = \nabla \left( \frac{1}{2}\|\cdot\|^2 - f^* \right)(\mathbf{x}_0).\)

因此，若 \((\mathbf{x}_0, \mathbf{y}_0)\) 在 \(P^*\) 的支撑集中，则 \(\mathbf{y}_0\) 唯一确定，这证明 \(P^*\) 实际上是伪装成耦合的 Monge 映射，即

\(P^* = (\text{Id}, \nabla(\frac{1}{2}\|\cdot\|^2 - f^*))_\sharp \mu.\)

证明的其余部分可按如下方式完成：对于任意函数 \(h : \mathcal{X} \rightarrow \mathbf{R}\)，利用 \(c\)-变换与 Legendre 变换的定义，可以证明 \(\frac{1}{2}\|\cdot\|^2 - h\) 是凸函数，当且仅当 \(h\) 是 c-凹函数。该证明的一个中间步骤依赖于证明 \(\frac{1}{2}\|\cdot\|^2 - \overline{h}\) 等于 \(\frac{1}{2}\|\cdot\|^2 - h\) 的 Legendre 变换。因此，上述函数 \(\frac{1}{2}\|\cdot\|^2 - f^*\) 是凸函数，依据是 \(f^*\) 的 c-凹性，且最优传输映射本身即为凸函数的梯度。

明确平方欧氏代价下的最优传输映射必然为凸函数的梯度，对于求解 (6.203) 可能非常有用。确实，可利用此知识将估计限制于相关函数族，即输入凸神经网络的梯度 [AXK17]，如 [Mak+20] 或 [Kor+20] 所提，以及具有所需光滑性和强凸常数的任意凸函数 [PdC20]。

## 6.8.3.4 一维和高斯分布的闭式表达式

概率分布之间的许多度量在简单情况下具有闭式表达式。Wasserstein 距离也不例外，在两个重要场景下可以以闭式计算。当分布为一维且代价 \(c(\mathbf{x}, \mathbf{y})\) 要么是差值 \(\mathbf{x} - \mathbf{y}\) 的凸函数，要么几乎处处满足 \(\partial c/\partial \mathbf{x} \partial \mathbf{y} < 0\) 时，Wasserstein 距离本质上是 \(\mu\) 和 \(\nu\) 分位数函数之间的比较。回顾，对于测度 \(\rho\)，其分位数函数 \(Q_\rho\) 是一个取值在 \([0, 1]\) 且值在 \(\rho\) 支撑集上的函数，对应于 \(\rho\) 累积分布函数（cdf）\(F_\rho\) 的（广义）逆映射。采用这些符号，有

\(\text{OT}_c(\mu, \nu) = \int_{[0,1]} c(Q_\mu(u), Q_\nu(u)) \, \mathrm{d}u\)

特别是，当 \(c\) 为 \(\mathbf{x}, \mathbf{y} \mapsto |\mathbf{x} - \mathbf{y}|\) 时，\(\text{OT}_c(\mu, \nu)\) 对应于 Kolmogorov-Smirnov 统计量，即 \(\mu\) 的 cdf 与 \(\nu\) 的 cdf 之间的面积。若 \(c\) 为 \(\mathbf{x}, \mathbf{y} \mapsto (\mathbf{x} - \mathbf{y})^2\)，则仅恢复 \(\mu\) 和 \(\nu\) 分位数函数之间的平方欧几里得范数。最后请注意，Monge 映射也有闭式表达式，且等于 \(Q_\nu \circ F_\mu\)。

第二个闭式适用于所谓的椭圆轮廓分布，其中主要是高斯多元分布 [Gel90]。对于两个高斯分布 \(\mathcal{N}(\mathbf{m}_1, \Sigma_1)\) 和 \(\mathcal{N}(\mathbf{m}_2, \Sigma_2)\)，它们的 2-Wasserstein 距离分解为

$$
W_2^2(\mathcal{N}(\mathbf{m}_1, \Sigma_1), \mathcal{N}(\mathbf{m}_2, \Sigma_2)) = \|\mathbf{m}_1 - \mathbf{m}_2\|^2 + \mathcal{B}^2(\Sigma_1, \Sigma_2)
$$

其中 Bures 度量 \(\mathcal{B}\) 读为：

$$
\mathcal{B}^2(\Sigma_1, \Sigma_2) = \text{tr} \left( \Sigma_1 + \Sigma_2 - 2 \left( \Sigma_1^{\frac{1}{2}} \Sigma_2 \Sigma_1^{\frac{1}{2}} \right)^{\frac{1}{2}} \right).
$$

请特别注意，即使协方差矩阵不可逆，这些量也定义良好，并且当两个协方差都趋为 0 时，它们会退化为均值之间的距离。

当第一个协方差矩阵可逆时，最优 Monge 映射由以下给出：

\(T \triangleq \mathbf{x} \mapsto A(\mathbf{x} - \mathbf{m}_1) + \mathbf{m}_2, \text{ where } A \triangleq \Sigma_1^{-\frac{1}{2}} \left( \Sigma_1^{\frac{1}{2}} \Sigma_2 \Sigma_1^{\frac{1}{2}} \right)^{\frac{1}{2}} \Sigma_1^{-\frac{1}{2}}\)

很容易证明 \(T^*\) 确实是最优的：\(T_\sharp \mathcal{N}(\mathbf{m}_1, \Sigma_1) = \mathcal{N}(\mathbf{m}_2, \Sigma_2)$ 这一事实源于高斯分布的仿射前推仍是高斯分布。这里 \(T\) 设计用于精确地将第一个高斯分布推向第二个（且 \(A\) 设计用于从方差为 \(\Sigma_1\) 的随机变量恢复方差为 \(\Sigma_2\) 的随机变量）。\(T\) 的最优性可以通过简单地注意到它是凸二次形式的梯度（因为 \(A\) 是正定的），并利用上述 Brenier 定理完成证明来恢复。

## 6.8.3.5 使用线性规划求解器的精确求解

利用对偶性和 c-凹性，我们已暗示，基于在 1-Lipschitz 或凸神经网络上进行随机优化的方法可用于在 \(c\) 为欧氏距离或其平方时估计 Wasserstein 距离。然而，这些方法是非凸的，只能达到局部最优。除这两种情况及上述闭式外，计算 Wasserstein 距离的唯一可靠方法出现在 \(\mu\) 和 \(\nu\) 均为离散测度的情况下：在这种情况下，可以实例化并求解离散 (6.192) 问题，或其对偶 (6.198) 公式。原问题是网络流问题的典型示例，可用网络单纯形法以 \(O(nm(n+m)\log(n+m))\) 复杂度求解 [AMO88]，或者，也可使用可比拍卖算法 [BC89]。这些方法存在计算局限性：其立方代价在大规模场景中不可行；其组合性质使得难以并行求解具有共同代价矩阵 \(C\) 的多个最优传输问题。

统计学角度出现的另一个完全不同的问题，应进一步劝阻用户使用这些 LP 公式，尤其是在高维环境下。确实，从业者在使用 (6.192) 时最可能遇到的瓶颈是，在大多数场景中，其目标将是仅使用包含在实证中的 i.i.d 样本来近似两个连续测度 \(\mu, \nu\) 之间的距离。
