## 6.8.3.6 使用熵正则化获得平滑性

一种加速求解 (6.192) 的计算方法在 [Cut13] 中提出，建立在早期贡献 [Wil69; KY94] 以及与特殊情形 \(c=d^2\) 下薛定谔桥问题的渊源之上 [Léo14]。该想法在于通过耦合与 \(\mu, \nu\) 的乘积测度之间的库尔贝克-莱布勒散度来正则化运输成本，

\(W_{c,\gamma}(\mu, \nu) \triangleq \inf_{\pi \in \Pi(\mu, \nu)} \int_{\mathcal{X}^2} d(\mathbf{x}, \mathbf{y})^p d\pi(\mathbf{x}, \mathbf{y}) + \gamma D_{\mathbb{KL}}(\pi \| \mu \otimes \nu).\) (6.213)

当在离散测度上实例化时，该问题等价于运输矩阵集合上的以下 \(\gamma\)-强凸问题（应与 (6.192) 进行比较）

\(\text{OT}_{C, \gamma}(\mathbf{a}, \mathbf{b}) = \min_{P \in \mathbb{R}_+^{n \times m}, P \mathbf{1}_m = \mathbf{a}, P^T \mathbf{1}_n = \mathbf{b}} \langle P, C \rangle \triangleq \sum_{i,j} P_{ij} C_{ij} - \gamma \mathbb{H}(P) + \gamma (\mathbb{H}(\mathbf{a}) + \mathbb{H}(\mathbf{b})) ,\) (6.214)

这本身又等价于以下对偶问题（应与 (6.198) 进行比较）

\(\text{OT}_{C, \gamma}(\mathbf{a}, \mathbf{b}) = \max_{\mathbf{f} \in \mathbb{R}^n, \mathbf{g} \in \mathbb{R}^m} \mathbf{f}^T \mathbf{a} + \mathbf{g}^T \mathbf{b} - \gamma (e^{\mathbf{f}/\gamma})^T K e^{\mathbf{g}/\gamma} + \gamma (1 + \mathbb{H}(\mathbf{a}) + \mathbb{H}(\mathbf{b}))\) (6.215)

其中 \(K \triangleq e^{-C/\gamma}\) 是 \(-C/\gamma\) 的逐元素指数。这种正则化有几个好处。原偶对关系显示出（唯一）解 \(P^*_\gamma\) 与一对最优对偶变量 \((\mathbf{f}^*, \mathbf{g}^*)\) 之间的显式联系，如下

\(P^*_\gamma = \text{diag}(e^{\mathbf{f}/\gamma}) K \text{diag}(e^{\mathbf{g}/\gamma})\) (6.216)

问题 (6.215) 可以使用一种相当简单的策略求解，该策略在实践中证明非常稳健：简单的块坐标上升（交替优化关于 \(\mathbf{f}\) 然后关于 \(\mathbf{g}\) 的目标），从而得到著名的 Sinkhorn 算法 [Sin67]，这里使用 log-sum-exp 更新表示，从 \(\mathbf{g}\) 的任意初始化开始，依次执行这两个更新，直到收敛：

\(\mathbf{f} \leftarrow \gamma \log \mathbf{a} - \gamma \log K e^{\mathbf{g}/\gamma} \qquad \mathbf{g} \leftarrow \gamma \log \mathbf{b} - \gamma \log K^T e^{\mathbf{f}/\gamma}\) (6.217)

该算法的收敛性已得到充分研究（参见 [CK21] 及其中的参考文献）。随着 \(\gamma\) 减小，收敛自然变慢，反映了逼近 LP 解的难度，如 [AWR17] 所研究。这种正则化也有统计上的好处，因为正如 [Gen+19] 所论证，正则化 Wasserstein 距离的样本复杂度改善到 \(O(1/\sqrt{n})\) 模式，但常数项为 \(1/\gamma^{q/2}\)，随维度增长而恶化。

## 6.9 子模块化优化

*本节由 Jeff Bilmes 撰写。*

本节简要介绍了机器学习中的子模块性。\(^6\) 子模块性有一个极其简单的定义。然而，“最简单的事情往往最难完全理解” [Sam74]，尽管子模块性多年来被广泛研究，但它继续产生新的和令人惊讶的洞察与性质，其中一些对数据科学、机器学习和人工智能极为相关。子模函数作用于某个有限 _基集_ _V_ 的子集。找到 _V_ 的一个保证良好的子集通常需要与 _V_ 的大小成指数的计算量。然而，子模函数具有某些属性，使得优化要么可处理，要么可近似，而否则两者都不可能。然而，这些属性相当自然，因此子模函数既灵活又广泛适用于实际问题。子模块性涉及一种直观自然的递减收益属性，即向较小的集合添加元素比向较大的集合添加元素更有帮助。像凸性一样，子模块性允许高效找到可证明最优或近似最优的解。然而，与凸性形成对比的是，关于最大化几乎没有任何保证，子模函数既可以最小化也可以（近似）最大化。然而，子模最大化和最小化需要非常不同的算法解决方案，并有相当不同的应用。有时有人说子模函数是凸性的一种离散形式。这不完全正确，因为子模函数既像凸函数也像凹函数，但也同时具有同时类似于凸函数和凹函数的属性，但子模块性的一些属性既不像凸性也不像凹性。例如，凸性和凹性甚至可以作为一元函数来表达。这对于子模块性是不可能的，因为子模函数仅基于函数对多维离散空间中不同变量变化的响应来定义。

### 6.9.1 直觉、示例与背景

让我们定义一个 _集函数_ \(f : 2^V \rightarrow \mathbb{R}\)，它为 _V_ 的每个子集分配一个值。符号 \(2^V\) 是 _V_ 的幂集，大小为 \(2^{|V|}\)，这意味着 _f_ 生活在空间 \(\mathbb{R}^{2^n}\) 中——即，由于 _V_ 有 \(2^n\) 个可能的子集，_f_ 可以返回 \(2^n\) 个不同的值。我们使用符号 _X_ + _v_ 作为 \(X \cup \{v\}\) 的简写。此外，给定上下文中元素的值是一个如此广泛使用的概念，我们有一个特殊的符号来表示它——_v_ 在 _X_ 的上下文中的增量值 _增益_ 定义为 \(f(v|X) = f(X + v) - f(X)\)。因此，虽然 _f_(_v_) 是元素 _v_ 的值，但 \(f(v|X)\) 是如果你已经拥有 _X_ 时元素 _v_ 的值。我们还定义集合 _X_ 在 _Y_ 的上下文中的增益为 \(f(X|Y) = f(X \cup Y) - f(Y)\)。
