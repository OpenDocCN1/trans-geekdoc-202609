
where we have assumed $\mathbf{K} = \mathbf{K}_x + \mathbf{K}_{y|x}$ is invertible (although the prior or likelihood on their own may be singular).
The $K$ rows of $\mathbf{G} = [\mathbf{g}_1^\mathsf{T}; \dots ; \mathbf{g}_K^\mathsf{T}]$ and the $M$ rows of $\mathbf{H} = [\mathbf{h}_1^\mathsf{T}; \dots ; \mathbf{h}_M^\mathsf{T}]$ can be combined into the $L$ rows of $\mathbf{F} = [\mathbf{f}_1^\mathsf{T}; \dots ; \mathbf{f}_L^\mathsf{T}]$, which define the linear constraints of the system. If we assume that $\mathbf{\Sigma}_p$ and $\mathbf{\Sigma}_n$ are diagonal, then the structure of the graphical model is uniquely determined by the sparsity of $\mathbf{F}$. The resulting posterior factorizes as a product of $L$ Gaussian "experts":

```
$p(\mathbf{x}|\mathbf{y}) \propto \prod_{l=1}^L \exp(-\frac{1}{2}\mathbf{x}^\mathsf{T}\mathbf{K}_l\mathbf{x} + \mathbf{h}_l^\mathsf{T}\mathbf{x}) \propto \prod_{l=1}^L \mathcal{N}(\mathbf{f}_l^\mathsf{T}\mathbf{x}; \boldsymbol{\mu}_l, \boldsymbol{\Sigma}_l)$ (9.101)
```

where $\boldsymbol{\Sigma}_l$ equals $\mathbf{\Sigma}_{p,t,l}$ for $l = 1 : K$ and equals $\mathbf{\Sigma}_{n,v,l'}$ for $l = K + 1 : L$ where $l' = l - K$. Similarly $\boldsymbol{\mu}_l = \boldsymbol{\mu}_{p,t}$ for $l = 1 : K$ and $\boldsymbol{\mu}_l = (y_{l'} - c_{l'})$ for $l = K + 1 : L$.

To apply perturb and MAP, we proceed as follows. First perturb the prior mean by sampling $\tilde{\boldsymbol{\mu}}_p \sim \mathcal{N}(\boldsymbol{\mu}_p, \mathbf{\Sigma}_p)$, and perturb the measurements by sampling $\tilde{\mathbf{y}} \sim \mathcal{N}(\mathbf{y}, \mathbf{\Sigma}_n)$. (Note that this is equivalent to first perturbing the linear term in each information form potential, using $\tilde{\mathbf{h}}_l = \mathbf{h}_l + \mathbf{f}_l \mathbf{\Sigma}_l^{-\frac{1}{2}} \boldsymbol{\epsilon}_l$, where $\boldsymbol{\epsilon}_l \sim \mathcal{N}(0,1)$.) Then compute the MAP estimate for $\mathbf{x}$ using the perturbed parameters:

```
$\tilde{\mathbf{x}} = \mathbf{K}^{-1}\mathbf{G}^\mathsf{T}\mathbf{\Sigma}_p^{-1} \tilde{\boldsymbol{\mu}}_p + \mathbf{K}^{-1}\mathbf{H}^\mathsf{T}\mathbf{\Sigma}_n^{-1}(\tilde{\mathbf{y}} - \mathbf{c})$ (9.102)
$= \mathbf{K}^{-1}\mathbf{G}^\mathsf{T}\mathbf{\Sigma}_p^{-1}(\boldsymbol{\mu}_p + \boldsymbol{\epsilon}_{\mu}) + \mathbf{K}^{-1}\mathbf{H}^\mathsf{T}\mathbf{\Sigma}_n^{-1}(\mathbf{y} + \boldsymbol{\epsilon}_y - \mathbf{c})$ (9.103)
$= \boldsymbol{\mu} + \mathbf{A}\boldsymbol{\epsilon}_{\mu} + \mathbf{B}\boldsymbol{\epsilon}_y$ (9.104)
```

We see that $\mathbb{E}[\tilde{\mathbf{x}}] = \boldsymbol{\mu}$ and $\mathbb{E}[(\tilde{\mathbf{x}} - \boldsymbol{\mu})(\tilde{\mathbf{x}} - \boldsymbol{\mu})^\mathsf{T}] = \mathbf{K}^{-1} = \mathbf{\Sigma}$, so the method produces exact samples.

This approach is very scalable, since we compute the MAP estimate of sparse GMRFs (i.e., posterior mean) can be done efficiently using conjugate gradient solvers. Alternatively we can use loopy belief propagation (Section 9.4), which can often compute the exact posterior mean (see e.g., [WF01a; JMW06; Bic09; Du+18]).

### 9.7.2.2 Discrete case

In [PY11; PY14] they extend perturb-and-MAP to the case of discrete graphical models. This setup is more complicated, and requires the use of Gumbel noise, which can be sampled using $\epsilon = -\log(-\log(u))$, where $u \sim \text{Unif}(0,1)$. This noise should be added to all the potentials in the model, but as a simple approximation, it can just be added to the unary terms, i.e., the local evidence potentials. Let the score, or unnormalized log probability, of configuration $\mathbf{x}$ given inputs $\mathbf{c}$ be

```
$S(\mathbf{x}; \mathbf{c}) = \log p(\mathbf{x}|\mathbf{c}) + \text{const} = \sum_i \log \phi_i(x_i) + \sum_{ij} \log \psi_{ij}(x_{i,j})$ (9.105)
```

where we have assumed a pairwise CRF for notational simplicity. If we perturb the local evidence potentials $\phi_i(k)$ by adding $\epsilon_{ik}$ to each entry, where $k$ indexes the discrete latent states, we get $\tilde{S}(\mathbf{x}; \mathbf{c})$. We then compute a sample $\tilde{\mathbf{x}}$ by solving $\tilde{\mathbf{x}} = \text{argmax } \tilde{S}(\mathbf{x}; \mathbf{c})$. The advantage of this approach is that it can leverage efficient MAP solvers for discrete models, such as those discussed in Supplementary Section 9.3. This can in turn be used for parameter learning, and estimating the partition function [HJ12; Erm+13].

## 10 Variational inference

### 10.1 Introduction

In this chapter, we discuss **variational inference**, which reduces posterior inference to optimization.
Note that VI is a large topic; this chapter just gives a high level overview. For more details, see e.g.,
[Jor+98; JJ00; Jaa01; WJ08; SQ05; TLG08; Zha+19b; Bro18].

### 10.1.1 The variational objective

Consider a model with unknown (latent) variables \(\boldsymbol{z}\), known variables \(\boldsymbol{x}\), and fixed parameters \(\boldsymbol{\theta}\). (If
the parameters are unknown, they can be added to \(\boldsymbol{z}\), as we discuss later.) We assume the prior is
\(p_\theta(\boldsymbol{z})\) and the likelihood is \(p_\theta(\mathbf{x}|\boldsymbol{z})\), so the unnormalized joint is \(p_\theta(\mathbf{x}, \boldsymbol{z}) = p_\theta(\mathbf{x}|\boldsymbol{z})p_\theta(\boldsymbol{z})\), and the
posterior is \(p_\theta(\boldsymbol{z}|\mathbf{x}) = p_\theta(\mathbf{x}, \boldsymbol{z})/p_\theta(\mathbf{x})\). We assume that it is intractable to compute the normalization
constant, \(p_\theta(\mathbf{x}) = \int p_\theta(\mathbf{x}, \boldsymbol{z})d\boldsymbol{z}\), and hence intractable to compute the normalized posterior. We
therefore seek an approximation to the posterior, which we denote by \(q(\boldsymbol{z})\), such that we minimize
the following loss:

```
\(q = \underset{q \in \mathcal{Q}}{\text{argmin}} D_{KL}(q(\boldsymbol{z}) \| p_\theta(\boldsymbol{z}|\boldsymbol{x}))\)
```

Since we are minimizing over functions (namely distributions \(q\)), this is called a **variational method**.
In practice we pick a parametric family \(\mathcal{Q}\), where we use \(\boldsymbol{\psi}\), known as the **variational parameters**,
to specify which member of the family we are using. We can compute the best variational parameters
(for given \(\mathbf{x}\)) as follows:

```
\(\begin{aligned}
\boldsymbol{\psi}^* &= \underset{\boldsymbol{\psi}}{\text{argmin}} D_{KL}(q_\psi(\boldsymbol{z}) \| p_\theta(\boldsymbol{z}|\boldsymbol{x})) \\
&= \underset{\boldsymbol{\psi}}{\text{argmin}} \mathbb{E}_{q_\psi(\boldsymbol{z})} \left[ \log q_\psi(\boldsymbol{z}) - \log \left( \frac{p_\theta(\mathbf{x}|\boldsymbol{z})p_\theta(\mathbf{z})}{p_\theta(\mathbf{x})} \right) \right] \\
&= \underset{\boldsymbol{\psi}}{\text{argmin}} \underbrace{\mathbb{E}_{q_\psi(\boldsymbol{z})}[\log q_\psi(\boldsymbol{z}) - \log p_\theta(\mathbf{x}|\boldsymbol{z}) - \log p_\theta(\boldsymbol{z})]}_{\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\boldsymbol{x})} + \log p_\theta(\mathbf{x})
\end{aligned}\)
```

The final term \(\log p_\theta(\mathbf{x}) = \log(\int p_\theta(\mathbf{x}, \boldsymbol{z})d\boldsymbol{z})\) is generally intractable to compute. Fortunately, it is
independent of \(\boldsymbol{\psi}\), so we can drop it. This leaves us with the first term, which we write as follows:

```
\(\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) = \mathbb{E}_{q_\psi(\mathbf{z})} [-\log p_\theta(\mathbf{x}, \mathbf{z}) + \log q_\psi(\mathbf{z})]\)
```

Figure 10.1: Illustration of variational inference. The large oval represents the set of variational distributions $\mathcal{Q} = \{q_\psi(\mathbf{z}) : \psi \in \mathcal{O}\}$, where $\mathcal{O}$ is the set of possible variational parameters. The true distribution is the point $p(\mathbf{z}|\mathbf{x})$, which we assume lies outside of the set. Our goal is to find the best approximation to $p$ within our variational family; this is the point $\psi^*$ which is closest in KL divergence. We find this point by starting an optimization procedure from the random initial point $\psi^{\text{init}}$. Adapted from a figure by David Blei.

Minimizing this objective will minimize the KL divergence, causing our approximation to approach the true posterior. See Figure 10.1 for an illustration. In the sections below, we give two different interpretations of this objective function.

### 10.1.1.1 The view from physics: minimize the variational free energy

If we define $\mathcal{E}_\theta(\mathbf{z}) = -\log p_\theta(\mathbf{z}, \mathbf{x})$ as the energy, then we can rewrite the loss in Equation (10.5)

```
$\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) = \mathbb{E}_{q_\psi(\mathbf{z})}[\mathcal{E}_\theta(\mathbf{z})] - \mathbb{H}(q_\psi) = \text{expected energy - entropy}$ (10.6)
```

In physics, this is known as the **variational free energy** (VFE). This is an upper bound on the **free energy** (FE), $-\log p_\theta(\mathbf{x})$, which follows from the fact that

```
$D_{\text{KL}}(q_\psi(\mathbf{z}) || p_\theta(\mathbf{z}|\mathbf{x})) = \mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) + \log p_\theta(\mathbf{x}) \ge 0$ (10.7)
```

```
$\underbrace{\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x})}_{\text{VFE}} \ge \underbrace{-\log p_\theta(\mathbf{x})}_{\text{FE}}$ (10.8)
```

Variational inference is equivalent to minimizing the VFE. If we reach the minimum value of $-\log p_\theta(\mathbf{x})$, then the KL divergence term will be 0, so our approximate posterior will be exact.

### 10.1.1.2 The view from statistics: maximize the evidence lower bound (ELBO)

The negative of the VFE is known as the **evidence lower bound** or **ELBO** function [BKM16]:

```
$\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) \triangleq \mathbb{E}_{q_\psi(\mathbf{z})}[\log p_\theta(\mathbf{x}, \mathbf{z}) - \log q_\psi(\mathbf{z})] = \text{ELBO}$ (10.9)
```

The name "ELBO" arises because

```
$\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) \le \log p_\theta(\mathbf{x})$ (10.10)
```

where $\log p_\theta(\mathbf{x})$ is called the "evidence". The inequality follows from Equation (10.8). Therefore maximizing the ELBO wrt $\psi$ will minimize the original KL, since $\log p_\theta(\mathbf{x})$ is a constant wrt $\psi$.
