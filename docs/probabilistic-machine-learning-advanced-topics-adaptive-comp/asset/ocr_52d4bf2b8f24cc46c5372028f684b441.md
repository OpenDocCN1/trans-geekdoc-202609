# 5.1.5 Properties of KL

Below are some other useful properties of the KL divergence.

# 5.1.5.1 Compression lemma

An important general purpose result for the KL divergence is the **compression lemma**:

**Theorem 5.1.2.** _For any distributions P and Q with a well-defined KL divergence, and for any scalar function_ $\phi$ _defined on the domain of the distributions we have that:_

```
\(\mathbb{E}_P[\phi] \le \log \mathbb{E}_Q \left[ e^\phi \right] + D_{\text{KL}} \left( P \| Q \right).\) (5.41)
```

_Proof._ We know that the KL divergence between any two distributions is non-negative. Consider a distribution of the form:

```
\(g(x) = \frac{q(x)}{\mathcal{Z}} e^{\phi(x)}.\) (5.42)
```

where the _partition function_ is given by:

```
\(\mathcal{Z} = \int dx \, q(x) e^{\phi(x)}.\) (5.43)
```

Taking the KL divergence between \(p(x)\) and \(g(x)\) and rearranging gives the bound:

```
\(D_{\text{KL}} \left( P \| G \right) = D_{\text{KL}} \left( P \| Q \right) - \mathbb{E}_P[\phi(x)] + \log(\mathcal{Z}) \ge 0.\) (5.44)
```

One way to view the compression lemma is that it provides what is termed the Donsker-Varadhan variational representation of the KL divergence:

```
\(D_{\text{KL}} \left( P \| Q \right) = \sup_\phi \mathbb{E}_P[\phi(x)] - \log \mathbb{E}_Q \left[ e^{\phi(x)} \right].\) (5.45)
```

In the space of all possible functions \(\phi\) defined on the same domain as the distributions, assuming all of the values above are finite, the KL divergence is the supremum achieved. For any fixed function \(\phi(x)\), the right hand side provides a lower bound on the true KL divergence.

Another use of the compression lemma is that it provides a way to estimate the expectation of some function with respect to an unknown distribution _P_. In this spirit, the compression lemma can be used to power a set of what are known as PAC-Bayes bounds of losses with respect to the true distribution in terms of measured losses with respect to a finite training set. See for example Section 17.4.5 or Banerjee [Ban06].
