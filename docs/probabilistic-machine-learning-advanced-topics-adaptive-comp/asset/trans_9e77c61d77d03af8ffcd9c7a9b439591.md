

然后我们通过边缘化 \(\mathbf{z}_t\) 将其转换为关于观测值的预测：
\(p(\mathbf{y}_t|\mathbf{y}_{1:t-1}) = \int p(\mathbf{y}_t, \mathbf{z}_t|\mathbf{y}_{1:t-1})d\mathbf{z}_t = \int p(\mathbf{y}_t|\mathbf{z}_t)p(\mathbf{z}_t|\mathbf{y}_{1:t-1})d\mathbf{z}_t = \mathcal{N}(\mathbf{y}_t|\hat{\mathbf{y}}_t, \mathbf{S}_t)\) (8.35)

这也可用于计算观测值的对数似然：新后验的归一化常数可按以下方式计算：
\(\log p(\mathbf{y}_{1:T}) = \sum_{t=1}^T \log p(\mathbf{y}_t|\mathbf{y}_{1:t-1}) = \sum_{t=1}^T \log Z_t\) (8.36)

其中我们定义 \(p(\mathbf{y}_1|\mathbf{y}_0) = p(\mathbf{y}_1)\)。这只是单步先验测量预测的对数概率之和，是衡量模型在每一步有多“惊讶”的指标。

我们可以将预测步骤推广为先在潜空间中预测 \(K\) 步，然后将最终状态“接地”为预测观测值，从而预测未来 \(K\) 步的观测值。（这与 RNN（第 16.3.4 节）形成对比，后者需要在每一步生成观测值，以便更新未来隐藏状态。）

## 8.2.2.4 推导

在本节中，我们按照 [SS23, 第 6.3 节] 推导卡尔曼滤波器方程。结果是对线性高斯系统操作规则的直接应用，该规则在第 2.3.2 节中讨论过。

首先，我们推导预测步骤。根据方程 (2.120)，状态的联合预测分布由下式给出
\(p(\mathbf{z}_{t-1}, \mathbf{z}_t|\mathbf{y}_{1:t-1}) = p(\mathbf{z}_t|\mathbf{z}_{t-1})p(\mathbf{z}_{t-1}|\mathbf{y}_{1:t-1})\) (8.37)

\(= \mathcal{N}(\mathbf{z}_t|\mathbf{F}_t\mathbf{z}_{t-1}, \mathbf{Q}_t)\mathcal{N}(\mathbf{z}_{t-1}|\boldsymbol{\mu}_{t-1|t-1}, \boldsymbol{\Sigma}_{t-1|t-1})\) (8.38)
\(= \mathcal{N}\left( \begin{pmatrix} \mathbf{z}_{t-1} \\ \mathbf{z}_t \end{pmatrix} \middle| \boldsymbol{\mu}', \boldsymbol{\Sigma}' \right)\) (8.39)

其中
\(\boldsymbol{\mu}' = \begin{pmatrix} \boldsymbol{\mu}_{t-1|t-1} \\ \mathbf{F}_t\boldsymbol{\mu}_{t-1|t-1} \end{pmatrix}, \boldsymbol{\Sigma}' = \begin{pmatrix} \boldsymbol{\Sigma}_{t-1|t-1} & \boldsymbol{\Sigma}_{t-1|t-1}\mathbf{F}_t^\mathsf{T} \\ \mathbf{F}_t\boldsymbol{\mu}_{t-1|t-1} & \mathbf{F}_t\boldsymbol{\Sigma}_{t-1|t-1}\mathbf{F}_t^\mathsf{T} + \mathbf{Q}_t \end{pmatrix}\) (8.40)

因此，状态的边缘预测分布由下式给出
\(p(\mathbf{z}_t|\mathbf{y}_{1:t-1}) = \mathcal{N}(\mathbf{z}_t|\mathbf{F}_t\boldsymbol{\mu}_{t-1|t-1}, \mathbf{F}_t\boldsymbol{\Sigma}_{t-1|t-1}\mathbf{F}_t^\mathsf{T} + \mathbf{Q}_t) = \mathcal{N}(\mathbf{z}_t|\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1})\) (8.41)

现在，我们推导测量更新步骤。状态和观测值的联合分布由下式给出
\(p(\mathbf{z}_t, \mathbf{y}_t|\mathbf{y}_{1:t-1}) = p(\mathbf{y}_t|\mathbf{z}_t)p(\mathbf{z}_t|\mathbf{y}_{1:t-1})\) (8.42)

\(= \mathcal{N}(\mathbf{y}_t|\mathbf{H}_t\mathbf{z}_t, \mathbf{R}_t)\mathcal{N}(\mathbf{z}_t|\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1})\) (8.43)
\(= \mathcal{N}\left( \begin{pmatrix} \mathbf{z}_t \\ \mathbf{y}_t \end{pmatrix} \middle| \boldsymbol{\mu}'', \boldsymbol{\Sigma}'' \right)\) (8.44)

其中

$$\boldsymbol{\mu}'' = \begin{pmatrix} \boldsymbol{\mu}_{t|t-1} \\ \mathbf{H}_t \boldsymbol{\mu}_{t|t-1} \end{pmatrix}, \quad \boldsymbol{\Sigma}'' = \begin{pmatrix} \boldsymbol{\Sigma}_{t|t-1} & \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} \\ \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} & \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t \end{pmatrix}$$ (8.45)

最后，我们使用方程 (2.78) 将此联合分布转换为条件分布，如下所示：

$$p(\mathbf{z}_t | \mathbf{y}_t, \mathbf{y}_{1:t-1}) = \mathcal{N}(\mathbf{z}_t | \boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t})$$ (8.46)

$$\boldsymbol{\mu}_{t|t} = \boldsymbol{\mu}_{t|t-1} + \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} (\mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t)^{-1} [\mathbf{y}_t - \mathbf{H}_t \boldsymbol{\mu}_{t|t-1}]$$ (8.47)

$$= \boldsymbol{\mu}_{t|t-1} + \mathbf{K}_t [\mathbf{y}_t - \mathbf{H}_t \boldsymbol{\mu}_{t|t-1}]$$ (8.48)

$$\boldsymbol{\Sigma}_{t|t} = \boldsymbol{\Sigma}_{t|t-1} - \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} (\mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t)^{-1} \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1}$$ (8.49)

$$= \boldsymbol{\Sigma}_{t|t-1} - \mathbf{K}_t \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1}$$ (8.50)

其中

$$\mathbf{S}_t = \mathbf{H}_t \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} + \mathbf{R}_t$$ (8.51)

$$\mathbf{K}_t = \boldsymbol{\Sigma}_{t|t-1} \mathbf{H}_t^\mathsf{T} \mathbf{S}_t^{-1}$$ (8.52)

## 8.2.2.5 抽象表述

我们可以通过定义各种创建和操作联合高斯系统的函数，以更紧凑的方式表示卡尔曼滤波器方程，如第 2.3.2 节所示。特别是，假设我们有以下线性高斯系统：

$$p(\mathbf{z}) = \mathcal{N}(\tilde{\boldsymbol{\mu}}, \tilde{\mathbf{\Sigma}})$$ (8.53)

$$p(\mathbf{y} | \mathbf{z}) = \mathcal{N}(\mathbf{Az} + \mathbf{b}, \mathbf{\Omega})$$ (8.54)

那么联合分布由下式给出

$$p(\mathbf{z}, \mathbf{y}) = \mathcal{N} \left( \begin{pmatrix} \tilde{\boldsymbol{\mu}} \\ \mathbf{A} \tilde{\boldsymbol{\mu}} + \mathbf{b} \end{pmatrix}, \begin{pmatrix} \tilde{\mathbf{\Sigma}} & \tilde{\mathbf{\Sigma}} \mathbf{A}^\mathsf{T} \\ \mathbf{A} \tilde{\mathbf{\Sigma}} \mathbf{A}^\mathsf{T} + \mathbf{\Omega} \end{pmatrix} \right)$$ (8.55)

后验分布由下式给出

$$p(\mathbf{z} | \mathbf{y}) = \mathcal{N}(\mathbf{z} | \widehat{\boldsymbol{\mu}}, \widehat{\mathbf{\Sigma}}) = \mathcal{N} \left( \mathbf{z} \big| \tilde{\boldsymbol{\mu}} + \mathbf{K}(\mathbf{y} - \overline{\boldsymbol{\mu}}), \tilde{\mathbf{\Sigma}} - \mathbf{K} \mathbf{S} \mathbf{K}^\mathsf{T} \right)$$ (8.56)

其中 \(\mathbf{K} = \mathbf{C}\mathbf{S}^{-1}\)。伪代码见算法 8.1。

现在我们可以应用这些函数来推导卡尔曼滤波，如下所示。在预测步骤中，我们计算

$$p(\mathbf{z}_{t-1}, \mathbf{z}_t | \mathbf{y}_{1:t-1}) = \mathcal{N} \left( \begin{pmatrix} \boldsymbol{\mu}_{t-1|t-1} \\ \boldsymbol{\mu}_{t|t-1} \end{pmatrix}, \begin{pmatrix} \boldsymbol{\Sigma}_{t-1|t-1} & \boldsymbol{\Sigma}_{t-1,t|t-1} \\ \boldsymbol{\Sigma}_{t,t-1|t-1} & \boldsymbol{\Sigma}_{t|t-1} \end{pmatrix} \right)$$ (8.57)

$$(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \boldsymbol{\Sigma}_{t-1,t|t}) = \text{GaussMoments}(\boldsymbol{\mu}_{t-1|t-1}, \boldsymbol{\Sigma}_{t-1|t-1}, \mathbf{F}_t, \mathbf{B}_t \mathbf{u}_t + \mathbf{b}_t, \mathbf{Q}_t)$$ (8.58)

### 算法 8.1：线性高斯系统的函数。

```
def GaussMoments(\tilde{\mu}, \tilde{\Sigma}, \mathbf{A}, \mathbf{b}, \mathbf{\Omega}):
  \bar{\mu} = \mathbf{A} \tilde{\mu} + \mathbf{b}
  \mathbf{S} = \mathbf{\Omega} + \mathbf{A} \tilde{\Sigma} \mathbf{A}^T
  \mathbf{C} = \tilde{\Sigma} \mathbf{A}^T
  Return (\bar{\mu}, \mathbf{S}, \mathbf{C})
def GaussCondition(\tilde{\mu}, \tilde{\Sigma}, \bar{\mu}, \mathbf{S}, \mathbf{C}, \mathbf{y}):
  \mathbf{K} = \mathbf{C} \mathbf{S}^{-1}
  \tilde{\mu} = \tilde{\mu} + \mathbf{K}(\mathbf{y} - \bar{\mu})
  \tilde{\Sigma} = \tilde{\Sigma} - \mathbf{K} \mathbf{S} \mathbf{K}^T
  \ell = \log \mathcal{N}(\mathbf{y} | \bar{\mu}, \mathbf{S})
  Return (\tilde{\mu}, \tilde{\Sigma}, \ell)
```

由此我们得到边缘分布

\(p(\mathbf{z}_t | \mathbf{y}_{1:t-1}) = \mathcal{N}(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1})\)

在更新步骤中，我们计算联合分布

\(p(\mathbf{z}_t, \mathbf{y}_t | \mathbf{y}_{1:t-1}) = \mathcal{N} \left( \begin{pmatrix} \boldsymbol{\mu}_{t|t-1} \\ \bar{\boldsymbol{\mu}}_t \end{pmatrix}, \begin{pmatrix} \boldsymbol{\Sigma}_{t|t-1} & \mathbf{C}_t \\ \mathbf{C}_t^T & \mathbf{S}_t \end{pmatrix} \right)\)

\((\hat{\mathbf{y}}_t, \mathbf{S}_t, \mathbf{C}_t) = \text{GaussMoments}(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \mathbf{H}_t, \mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t, \mathbf{R}_t)\)

然后我们基于观测值对其进行条件化，以得到后验分布

\(p(\mathbf{z}_t | \mathbf{y}_t, \mathbf{y}_{1:t-1}) = p(\mathbf{z}_t | \mathbf{y}_{1:t}) = \mathcal{N}(\boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t})\)

\((\boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t}, \ell_t) = \text{GaussCondition}(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \hat{\mathbf{y}}_t, \mathbf{S}_t, \mathbf{C}_t, \mathbf{y}_t)\)

卡尔曼滤波器的整体算法如算法 8.2 所示。

### 算法 8.2：卡尔曼滤波器。

```
def KF(\mathbf{F}_{1:T}, \mathbf{B}_{1:T}, \mathbf{b}_{1:T}, \mathbf{Q}_{1:T}, \mathbf{H}_{1:T}, \mathbf{D}_{1:T}, \mathbf{d}_{1:T}, \mathbf{R}_{1:T}, \mathbf{u}_{1:T}, \mathbf{y}_{1:T}, \boldsymbol{\mu}_{0|0}, \boldsymbol{\Sigma}_{0|0}):
  foreach t = 1 : T do
    // Predict:
    (\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, --) = GaussMoments(\boldsymbol{\mu}_{t-1|t-1}, \boldsymbol{\Sigma}_{t-1|t-1}, \mathbf{F}_t, \mathbf{B}_t \mathbf{u}_t + \mathbf{b}_t, \mathbf{Q}_t)
    // Update:
    (\bar{\boldsymbol{\mu}}, \mathbf{S}, \mathbf{C}) = GaussMoments(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \mathbf{H}_t, \mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t, \mathbf{R}_t)
    (\boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t}, \ell_t) = GaussCondition(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \bar{\boldsymbol{\mu}}, \mathbf{S}, \mathbf{C}, \mathbf{y}_t)
  Return (\boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t})_{t=1}^T, \sum_{t=1}^T \ell_t
```
