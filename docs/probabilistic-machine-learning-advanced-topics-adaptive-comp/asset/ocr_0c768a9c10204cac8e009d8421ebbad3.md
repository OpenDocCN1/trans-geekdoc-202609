We can modify EP to this setting as follows. First, when computing the cavity distribution, we use

\( q_{-1}(\theta) \propto q(\theta)/\tilde{f}(\theta) \)

We then compute the tilted distribution

\( q_{\backslash n}(\theta) \propto f_n(\theta)q_{-1}(\theta) \)

Next we derive the new local factor for this datapoint using moment matching:

\( \tilde{f}_n(\theta) = \text{proj}(q_{\backslash n}(\theta))/q_{-1}(\theta) \)

Finally, we perform a damped update of the average likelihood \( \tilde{f}(\theta) \) using this new local factor:

\( \tilde{f}_{\text{new}}(\theta) = \tilde{f}_{\text{old}}(\theta)^{1-1/N}\tilde{f}_n(\theta)^{1/N} \)

The ADF algorithm is similar to SEP, in that we compute the tilted distribution \( q_{\backslash t} \propto f_t q_{t-1} \) and then project it, without needing to keep the \( f_t \) factors. The difference is that instead of using the cavity distribution \( q_{-1}(\theta) \) as a prior, it uses the posterior from the previous time step, \( q_{t-1} \). This avoids the need to compute and store \( \tilde{f} \), but results in overconfidence in the batch setting.
