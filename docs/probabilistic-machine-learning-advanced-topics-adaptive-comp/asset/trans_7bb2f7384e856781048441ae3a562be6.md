
### 26.7.6 域自适应

机器学习中一项重要的任务是纠正数据分布随时间的推移而发生的偏移，尽量减少某些域偏移度量，如第 19.5.3 节所讨论。与其他应用一样，GANs 因其避免选择距离或偏移程度的方式而广受欢迎。我们之前回顾的用于图像生成的有监督和无监督方法都研究了像素级域自适应模型，这些模型在原始像素空间中执行分布对齐，将源数据转换为目标域的风格，如 pix2pix 和 CycleGAN 所示。这些方法针对一般域自适应问题的扩展，旨在不仅在观测数据空间（例如，像素中）这样做，还要在特征层面这样做。一种通用方法是神经网络的域对抗训练 [Gan+16b] 或对抗判别域自适应 (ADDA) [Tze+17]。[Hof+18] 的 CyCADA 方法通过在适应过程中使用循环一致性损失和基于特定视觉识别任务的语义损失来强制执行结构和语义一致性，从而扩展了 CycleGAN。还有包括类条件信息 [Tsa+18; Lon+18] 的扩展，或者当要匹配的模式在源域和目标域中具有不同频率时的适应 [BHC19]。

### 26.7.7 设计、艺术与创造力

生成模型，特别是图像生成模型，丰富了算法艺术这一更通用领域的方法。带有迁移的图像和音频生成的应用也可被视为艺术图像生成的一个方面。在这些情况下，训练的目标不是泛化，而是创建跨越不同类型视觉审美的吸引人的图像 [Sar18]。一个示例是使用风格迁移 GAN 创建视觉体验，其中放置在视频下的对象会实时使用其他视觉风格重新渲染 [AFG19]。生成能力已被用于探索时尚领域的替代设计和面料 [Kat+19]，并现已成为主要绘图软件的一部分，为设计师提供新工具 [Ado]。除图像之外，使用 GANs 进行创造性和艺术表达还包括音乐、声音、舞蹈和排版等领域 [AI 19]。

## 27 发现方法：概述

### 27.1 引言

我们在第三部分中看到，如何使用监督学习方法（条件似然极大化）来创建能够根据输入对输出进行预测的概率模型。我们在第四部分中看到，如何使用无监督学习方法（无条件似然极大化）来创建能够无条件生成输出的概率模型。然而，在某些情况下，我们的目标是尝试 *理解* 给定的数据集。也就是说，我们希望 *发现* 一些“有趣”，并可能“可操作”的东西。预测和生成是发现的有用子例程，但单靠它们是不够的。特别是，尽管神经网络通常会从数据中隐式学习有用特征，但它们往往难以解释，且结果可能不稳定，并对训练协议的任意细节（例如，SGD 学习率或随机种子）敏感。

在本书的这一部分，我们专注于创建高维数据可解释表示的学习模型。一种常见的方法是使用 **隐变量模型**，其中我们假设观测到的数据 **_x_** 是由某些底层（通常是低维的）**隐因** **_z_** 引起或生成的，后者代表了世界的“真实”状态。关键的是，这些隐性变量被假定对模型的最终用户有意义。（因此，评估此类模型通常需要领域专业知识。）

例如，假设我们希望根据底层 3D 场景 **_z_** 来解释图像 **_x_** ，其中 **_z_** 由对象和表面表示。从 **_z_** 到 **_x_** 的 **前向映射** 通常是多对一的，即不同的隐性值，比如 **_z_** 和 \(z'\) ，可能由于传感器的限制而产生相同的观测值 **_x_** 。（这被称为 **感知混淆**。）因此，从 **_x_** 到 **_z_** 的逆向映射是不适定的。在这种情况下，我们需要施加一个先验 \(p(z)\)，以使我们的估计具有明确定义。在简单的设置中，我们可以使用点估计，例如 MAP 估计

```
\(\hat{z}(x) = \arg\max_z p(z|x) = \arg\max_z \log p(z) + \log p(x|z)\) (27.1)
```

在计算机视觉的背景下，这种方法被称为 **视觉作为逆向图形** 或 **综合分析** [KMY04; YK06; Doy+07; MC19]。有关说明，请参见图 27.1。

这种逆向建模方法在科学和工程中被广泛使用，其中 **_z_** 代表我们希望估计的世界底层状态，而 **_x_** 仅仅是这种真实状态的噪声或部分表现。在某些情况下，我们既知道先验 \(p(z|\theta)\) 也知道似然 \(p(x|z,\theta)\)，只需解决 **_z_** 的推断问题即可。但更常见的是，模型参数 \(\theta\) 也（部分）未知，需要从可观测样本 \(\mathcal{D} = \{x_n : n = 1 : N\}\) 中推断。在某些情况下，模型本身的结构是未知的，需要学习。

### 27.2 第五部分概览

在第 28 章中，我们讨论简单的隐变量模型，其中观测数据通常是固定维向量，例如 \(\boldsymbol{x} \in \mathbb{R}^D\)。在第 29 章中，我们将这些模型扩展到用于相关向量序列 \(\boldsymbol{x} = \boldsymbol{x}_{1:T}\)，例如语音、视频、基因组数据等。如前所述，将这些模型的部分变为非线性（“深度”）是简单直接的。这些模型也可以扩展到时空环境中。在第 30 章中，我们将这些模型扩展到用于一般图。

## 28 隐因模型

### 28.1 引言

隐变量模型（LVM）是任何其中一些变量始终是隐性的或隐藏的概率模型。一个简单的例子是混合模型（第 28.2 节），其形式为 \(p(\boldsymbol{x}) = \sum_k p(\boldsymbol{x}|z = k)p(z = k)\)，其中 \(z\) 是一个指示变量，用于指定用于生成 \(\boldsymbol{x}\) 的混合成分。但是，我们也可以使用连续隐变量，或离散和连续的混合。我们也可以有多个隐变量，它们以复杂的方式相互连接。

在本章中，我们讨论一种非常简单的 LVM，其形式如下：

```
\(\boldsymbol{z} \sim p(\boldsymbol{z})\) (28.1)
\(\boldsymbol{x}|\boldsymbol{z} \sim \text{Expfam}(\boldsymbol{x}|f(\boldsymbol{z}))\) (28.2)
```

其中 \(f(\boldsymbol{z})\) 称为 **解码器**，\(p(\boldsymbol{z})\) 是某种先验。我们假设 \(\boldsymbol{z}\) 是隐藏随机变量的单个“层”，对应一组“隐因”。我们称这些为 **隐因模型**。在本章中，我们假设解码器 \(f\) 是一个简单的线性模型；我们在第 21 章中考虑非线性扩展。因此，整体模型类似于广义线性模型（GLM）（第 15.1 节），只不过模型的输入是隐藏的。

我们可以通过改变先验 \(p(\boldsymbol{z})\) 和/或似然 \(p(\boldsymbol{x}|\boldsymbol{z})\) 的形式，创建大量不同的“经典”模型，如表 28.1 所示。我们将在以下各节中给出详细信息。（注意，尽管我们在讨论生成模型，但我们的重点是对有意义的隐性变量进行后验推断（发现），而不是生成逼真的数据样本。）

### 28.2 混合模型

创建更复杂概率模型的一种方法是采用简单分布的凸组合。这称为 **混合模型**。其形式为

```
\(p(\boldsymbol{x}|\boldsymbol{\theta}) = \sum_{k=1}^K \pi_k p_k(\boldsymbol{x})\) (28.3)
```
