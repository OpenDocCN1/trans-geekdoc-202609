
## 3 统计学

### 3.1 引言

概率论（我们在第 2 章中讨论过）关注的是在已知参数 θ 的情况下，通过计算 p(D|θ) 来对观测数据结果 D 的分布进行建模。相比之下，统计学关注的是逆问题，即在给定观测的情况下推断未知参数 θ，也就是说，我们想要计算 p(θ|D)。事实上，统计学最初被称为逆概率论。如今，统计学主要有两种方法：频率学派统计和贝叶斯统计，如下文所述。（另见第 3.4.1 节，我们在其中比较了频率学派和贝叶斯方法在决策理论中的应用。）不过请注意，本章（乃至全书）大部分内容都侧重于贝叶斯方法，原因将在后文变得清晰。

### 3.2 贝叶斯统计

在贝叶斯统计方法中，我们将参数 θ 视为未知，将数据 D 视为固定和已知。（这与频率学派方法相反，我们将在第 3.3 节中讨论。）我们通过使用贝叶斯规则计算后验分布，来表示在看到数据后（即后验阶段）对参数不确定性的表示：

p(θ|D) = \frac{p(θ)p(D|θ)}{p(D)} = \frac{p(θ)p(D|θ)}{\int p(θ')p(D|θ')dθ'}

这里 p(θ) 称为先验，表示在看到数据之前我们对参数的看法；p(D|θ) 称为似然，表示我们对在每个参数设置下期望看到的数据的看法；p(θ|D) 称为后验，表示在看到数据后我们对参数的看法；而 p(D) 称为边缘似然或证据，是我们稍后将使用的归一化常数。

计算这个后验的任务称为贝叶斯推断、后验推断，或简称为推断。我们将在本章后续章节中给出许多示例，并在第 II 部分讨论算法问题。有关贝叶斯统计的更多详情，例如，请参阅 [Ber97a; Hof09; Lam18; Kru15; McE20] 以了解入门级材料，[Gel+14a; MKL21; GHV20a] 以了解中级材料，以及 [BS94; Ber85b; Rob07] 以了解更高级的理论。

### 3.2.1 投掷硬币

通常通过考虑投掷硬币实验来解释贝叶斯推断背后的关键思想。我们将遵循这一传统（另请参阅补充部分 3.1，以了解使用贝叶斯概念学习示例的贝叶斯替代温和入门。）

设 \(\theta \in [0, 1]\) 为某枚硬币出现正面的概率，该事件用 \(Y = 1\) 表示。假设我们投掷一枚硬币 \(N\) 次，并将结果记录为 \(\mathcal{D} = \{y_n \in \{0, 1\} : n = 1 : N\}\)。我们想要计算 \(p(\theta|\mathcal{D})\)，它表示收集数据后我们对参数的看法。要计算后验，我们可以使用贝叶斯规则，如方程 (3.1) 所示。详情如下。

#### 3.2.1.1 似然

我们假设数据是 iid，即独立且同分布。因此似然具有如下形式

\(p(\mathcal{D}|\theta) = \prod_{n=1}^N \theta^{y_n}(1-\theta)^{1-y_n} = \theta^{N_1}(1-\theta)^{N_0}\)

其中我们定义了 \(N_1 = \sum_{n=1}^N \mathbb{I}(y_n = 1)\) 和 \(N_0 = \sum_{n=1}^N \mathbb{I}(y_n = 0)\)，分别表示正面和反面的次数。这些计数被称为数据的充分统计量，因为这是我们推断 \(\theta\) 所需了解的关于 \(\mathcal{D}\) 的全部信息。总计数 \(N = N_0 + N_1\) 称为样本量。

请注意，我们也可以考虑二项似然模型，即进行 \(N\) 次试验并观察正面次数 \(y\)，而不是观察一系列硬币投掷结果。现在似然具有如下形式：

\(p(\mathcal{D}|\theta) = \text{Bin}(y|N, \theta) = \binom{N}{y} \theta^y (1-\theta)^{N-y}\)

缩放因子 \(\binom{N}{y}\) 与 \(\theta\) 无关，因此我们可以忽略它。因此，这个似然与方程 (3.2) 中的伯努利似然成正比，所以两种模型关于 \(\theta\) 的推断结果相同。

#### 3.2.1.2 先验

我们还需要指定一个先验。让我们假设除了参数位于区间 \([0, 1]\) 之外，我们对它一无所知。我们可以使用均匀分布来表示这个非信息性先验，

\(p(\theta) = \text{Unif}(\theta|0, 1)\)

更一般地，我们将使用 beta 分布（第 2.2.4.1 节）来写先验，原因将在稍后变得清晰。也就是说，我们假设

\(p(\theta) = \text{Beta}(\theta | \tilde{\alpha}, \tilde{\beta}) \propto \theta^{\tilde{\alpha}-1}(1-\theta)^{\tilde{\beta}-1}\)

这里 \(\tilde{\alpha}\) 和 \(\tilde{\beta}\) 被称为超参数，因为它们是先验的参数，决定了我们对“主”参数 \(\theta\) 的看法。如果设置 \(\tilde{\alpha}=\tilde{\beta}=1\)，我们将恢复均匀先验作为特例。

![](img/ca72c1626f4850f058a9edc138c1ac73_96_0.png)

图 3.1：使用充分统计量 \(N_1 = 4, N_0 = 1\) 的伯努利似然更新 Beta 先验。（a）均匀 Beta(1,1) 先验。（b）Beta(2,2) 先验。由 beta_binom_post_plot.ipynb 生成。

我们可以将这些超参数视为**伪计数**，它们与从真实数据中得出的经验计数 \(N_1\) 和 \(N_0\) 起着类似的作用。先验的强度由 \(\tilde{N}=\tilde{\alpha} + \tilde{\beta}\) 控制；这被称为**等效样本量**，因为它与观测样本量 \(N = N_1 + N_0\) 起着类似的作用。

#### 3.2.1.3 后验

我们可以通过将似然与先验相乘来计算后验：

\(p(\theta|\mathcal{D}) \propto \theta^{N_1} (1-\theta)^{N_0} \theta^{\tilde{\alpha}-1}(1-\theta)^{\tilde{\beta}-1} \propto \text{Beta}(\theta | \tilde{\alpha}+N_1, \tilde{\beta}+N_0) = \text{Beta}(\theta | \tilde{\alpha}, \tilde{\beta})\) (3.6)

其中 \(\hat{\alpha} \triangleq \tilde{\alpha}+N_1\) 和 \(\hat{\beta} \triangleq \tilde{\beta}+N_0\) 是后验的参数。由于后验与先验具有相同的函数形式，我们称其为**共轭先验**（有关更多详情，请参见第 3.4 节）。

例如，假设我们观察到 \(N_1 = 4\) 次正面和 \(N_0 = 1\) 次反面。如果使用均匀先验，我们将得到图 3.1a 中所示的后验。毫不奇怪的是，这与似然具有完全相同的形状（但在范围 [0, 1] 上缩放以积分为 1）。

现在假设我们使用一个略偏好 \(\theta\) 接近 0.5 值的先验，这反映了我们之前相信硬币更可能是公平的。我们将通过设置 \(\tilde{\alpha}=\tilde{\beta}= 2\) 来创建这个弱先验。使用这个先验的效果在图 3.1b 中得到说明。我们看到后验（蓝色线）是先验（红色线）和似然（黑色线）之间的“折中”。

#### 3.2.1.4 后验众数（MAP 估计）

参数最可能的值由 MAP 估计给出

\(\hat{\theta}_{\text{map}} = \arg \max_{\theta} p(\theta|\mathcal{D}) = \arg \max_{\theta} \log p(\theta|\mathcal{D}) = \arg \max_{\theta} \log p(\theta) + \log p(\mathcal{D}|\theta)\) (3.7)

使用微积分，可以证明这由以下给出

\(\hat{\theta}_{\text{map}} = \frac{\tilde{\alpha} + N_1 - 1}{\tilde{\alpha} + N_1 - 1 + \tilde{\beta} + N_0 - 1}\) (3.8)

如果使用均匀先验，\( p(\theta) \propto 1 \)，那么 MAP 估计变为 MLE，因为 \( \log p(\theta) = 0 \)：
\(\hat{\theta}_{mle} = \arg \max_{\theta} \log p(\mathcal{D}|\theta) = \frac{N_1}{N_1 + N_0} = \frac{N_1}{N}\) (3.9)

这直观且易于计算。但是，MLE 在小样本设置下可能会非常具有误导性。例如，假设我们投掷硬币 \( N \) 次，但从未看到任何正面，所以 \( N_1 = 0 \)。在这种情况下，我们将估计 \( \hat{\theta} = 0 \)，这意味着我们也不会预测未来的任何观测为正面。这是一个非常极端的估计，很可能是由于数据不足造成的。我们可以通过使用更强先验的 MAP 估计来解决这个问题。例如，如果我们使用 Beta(\(\theta|2,2\)) 先验，我们将得到估计
\(\hat{\theta}_{map} = \frac{N_1 + 1}{N_1 + 1 + N_0 + 1} = \frac{N_1 + 1}{N + 2}\) (3.10)

这称为加一平滑。

#### 3.2.1.5 后验均值

后验众数可能是后验的不良摘要，因为它相当于从整个分布中选择一个单点。后验均值是一个更稳健的估计，因为它是通过对分布进行积分得出的摘要统计量，\(\overline{\theta} = \int \theta p(\theta|\mathcal{D})d\theta\)。在 beta 后验的情况下，\( p(\theta|\mathcal{D}) = \text{Beta}(\theta|\tilde{\alpha}, \tilde{\beta}) \)，后验均值由以下给出

\(\overline{\theta} \triangleq \mathbb{E}[\theta|\mathcal{D}] = \frac{\tilde{\alpha}}{\tilde{\beta} + \tilde{\alpha}} = \frac{\tilde{\alpha}}{\tilde{N}}\) (3.11)

其中 \(\tilde{N}=\tilde{\beta}+\tilde{\alpha}\) 是后验的强度（等效样本量）。

我们将现在证明后验均值是先验均值 \(m=\tilde{\alpha} / \tilde{N}\) 和 MLE \(\hat{\theta}_{mle} = \frac{N_1}{N}\) 的凸组合：

\(\mathbb{E}[\theta|\mathcal{D}] = \frac{\tilde{\alpha} + N_1}{\tilde{\alpha} + N_1 + \tilde{\beta} + N_0} = \frac{\tilde{N} m + N_1}{N + \tilde{N}}\) (3.12)

\(= \frac{\tilde{N}}{N + \tilde{N}} m + \frac{N}{N + \tilde{N}} \frac{N_1}{N} = \lambda m + (1 - \lambda)\hat{\theta}_{mle}\) (3.13)

其中 \(\lambda = \frac{\tilde{N}}{N}\) 是先验与后验等效样本量之比。我们看到先验越弱，\(\lambda\) 越小，因此后验均值越接近 MLE。

#### 3.2.1.6 后验方差

为了捕捉估计中的一些不确定性概念，一种常用方法是计算估计的标准误，这正是后验标准差：

\(\text{se}(\theta) = \sqrt{\mathbb{V}[\theta|\mathcal{D}]}\) (3.14)
