# ### 6.3.4.2 Rao-Blackwellization

Suppose $q_\theta(z)$ is a discrete distribution. In this case, our objective becomes $\mathcal{L}(\theta) = \sum_z \tilde{\mathcal{L}}(\theta, z) q_\theta(z)$. We can now easily compute gradients using $\nabla_\theta \mathcal{L}(\theta) = \sum_z \tilde{\mathcal{L}}(\theta, z) \nabla_\theta q_\theta(z)$. Of course, if $z$ can take on exponentially many values (e.g., we are optimizing over the space of strings), this expression is intractable. However, suppose we can partition this sum into two sets, a small set $S_1$ of high probability values and a large set $S_2$ of all other values. Then we can enumerate over $S_1$ and use the score function estimator for $S_2$:

\[ \nabla_\theta \mathcal{L}(\theta) = \sum_{z \in S_1} \tilde{\mathcal{L}}(\theta, z) \nabla_\theta q_\theta(z) + \mathbb{E}_{q_\theta(z | z \in S_2)} \left[ \tilde{\mathcal{L}}(\theta, z) \nabla_\theta \log q_\theta(z) \right] \]

To compute the second expectation, we can use rejection sampling applied to samples from $q_\theta(z)$. This procedure is a form of Rao-Blackwellization as shown in [Liu+19b], and reduces the variance compared to standard SFE (see Section 11.6.2 for details on Rao-Blackwellization).

# ### 6.3.5 Reparameterization trick

The score function estimator can have high variance, even when using a control variate. In this section, we derive a lower variance estimator, which can be applied if $\tilde{\mathcal{L}}(\theta, z)$ is differentiable wrt $z$. We additionally require that we can compute a sample from $q_\theta(z)$ by first sampling $\epsilon$ from some noise distribution $q_0$ which is independent of $\theta$, and then transforming to $z$ using a deterministic and differentiable function $z = g(\theta, \epsilon)$. For example, instead of sampling $z \sim \mathcal{N}(\mu, \sigma^2)$, we can sample $\epsilon \sim \mathcal{N}(0, 1)$ and compute

\[ z = g(\theta, \epsilon) = \mu + \sigma \epsilon \]

where $\theta = (\mu, \sigma)$. This allows us to rewrite our stochastic objective as follows:

\[ \mathcal{L}(\theta) = \mathbb{E}_{q_\theta(z)} \left[ \tilde{\mathcal{L}}(\theta, z) \right] = \mathbb{E}_{q_0(\epsilon)} \left[ \tilde{\mathcal{L}}(\theta, g(\theta, \epsilon)) \right] \]

Since $q_0(\epsilon)$ is independent of $\theta$, we can push the gradient operator inside the expectation, which we can approximate with Monte Carlo:

\[ \nabla_\theta \mathcal{L}(\theta) = \mathbb{E}_{q_0(\epsilon)} \left[ \nabla_\theta \tilde{\mathcal{L}}(\theta, g(\theta, \epsilon)) \right] \approx \frac{1}{S} \sum_{s=1}^S \nabla_\theta \tilde{\mathcal{L}}(\theta, g(\theta, \epsilon_s)) \]

where $\epsilon_s \sim q_0$. This is called the **reparameterization gradient** or the **pathwise derivative** [Gla03; Fu15; KW14; RMW14a; TGLG14; JO18; FMM18], and is widely used in variational inference (Section 10.2.1). For a review of such methods, see [Moh+20].

Note that the tensorflow probability library (which also has a JAX interface) supports reparameterizable distributions. Therefore you can just write code in a straightforward way, as shown in **??** 6.1.
