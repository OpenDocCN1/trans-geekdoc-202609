## 9.4.1 针对无向双子图的含环信念传播

在本节中，我们假设（为简化记号）我们的模型是一个无向双子 PGM，如方程（9.50）所示。但是，与第 9.3.2 节不同，我们不假设图是树。我们可以应用与之前相同的消息传递方程。但是，由于没有自然的节点顺序，我们将以并行异步的方式执行。基本思想是：所有节点并行接收来自邻居的消息，然后更新其信念状态，最后将新消息发送回其邻居。此消息传递过程重复直到收敛。这种计算架构被称为收缩阵列，因为它类似于跳动的心脏。

更精确地说，我们将所有消息初始化为全 1 向量。然后，并行地，每个节点使用以下公式吸收来自所有邻居的消息：

```
bel_s(z_s) \propto \psi_s(z_s) \prod_{t \in nbr_s} m_{t \to s}(z_s) \qquad (9.66)
```

然后，并行地，每个节点向其每个邻居发送消息：

```
m_{s \to t}(z_t) = \sum_{z_s} \left( \psi_s(z_s)\psi_{st}(z_s, z_t) \prod_{u \in nbr_s \backslash t} m_{u \to s}(z_s) \right) \qquad (9.67)
```

消息 \(m_{s \to t}\) 通过将所有入站消息相乘（除了接收者发送的消息），然后传递通过 \(\psi_{st}\) 势函数来计算。我们继续此过程直到收敛。如果图是树，该方法保证在 \(D(G)\) 次迭代后收敛，其中 \(D(G)\) 是图的直径，即任意两个节点之间的最大距离。

## 9.4.2 针对因子图的含环信念传播

要实现一般图（包括具有高阶团势的图，超出双子范围）的含环 BP，使用第 4.6.1 节描述的因子图表示会很有用。在本节中，我们总结了因子图双部版本的 BP 方程，这些方程如 [KFL01] 导出。对于适用于 Forney 因子图的版本，请参阅 [Loe+07]。

- 对于离散因子图这些方程的高效 JAX 实现，请参阅 https://github.com/vicariousinc/PGMax。对于高斯情况，请参阅 https://github.com/probml/pgml-jax。

![](img/ca72c1626f4850f058a9edc138c1ac73_444_0.png)

图 9.10：双部因子图上的消息传递。方形节点代表因子，圆形节点代表变量。$y_i$ 节点对应于 $f$ 除 $x$ 之外的邻居 $x'_i$。来自 [KFL01] 的图 6。由 Brendan Frey 友好授权使用。

在双部因子图的情况下，我们有两种消息：变量到因子

```
$$m_{x \to f}(x) = \prod_{h \in nbr(x) \setminus \{f\}} m_{h \to x}(x)$$
```

和因子到变量

```
$$m_{f \to x}(x) = \sum_{x'} f(x, x') \prod_{x' \in nbr(f) \setminus \{x\}} m_{x' \to f}(x')$$
```

这里 nbr(x) 是与变量 x 连接的所有因子，nbr(f) 是与因子 f 连接的所有变量。这些消息在图 9.10 中有图示。收敛时，我们可以将最终信念计算为入站消息的乘积：

```
$$bel(x) \propto \prod_{f \in nbr(x)} m_{f \to x}(x)$$
```

消息发送的顺序可以使用多种启发式方法确定，例如计算生成树并选择任意节点作为根节点。或者，可以使用剩余信念传播 [EMK06] 自适应地选择更新顺序。或者，可以使用完全并行异步的实现。

## 9.4.3 高斯信念传播

可以通过使用第 2.3.3 节中的“线性高斯模型微积分”来计算消息和信念，从而将（含环）信念传播推广到高斯情况。请注意，在线性高斯系统中计算后验均值等同于求解线性系统，因此这些方法对线性代数也有用。有关详细信息，请参见 [PL03; Bic09; Du+18] 等。

![](img/ca72c1626f4850f058a9edc138c1ac73_445_0.png)

图 9.11：使用应用于一维 MRF 的高斯信念传播插值噪声数据。由 gauss-bp-1d-line.ipynb 生成。

作为高斯 BP 的示例，考虑在 1d 中插值噪声数据的问题，如 [OED21] 讨论的那样。特别是，设 \( f : \mathbb{R} \rightarrow \mathbb{R} \) 为未知函数，我们在位置 \( x_i \) 处获得 \( N \) 个噪声测量值 \( y_i \)。我们想要在 \( G \) 个网格位置 \( g_i \) 处估计 \( z_i = f(g_i) \)。设 \( x_i \) 是 \( g_i \) 最近的位置。然后我们假设测量因子如下：

```
\(\psi_i(z_{i-1}, z_i) = \frac{1}{\sigma^2}(\hat{y}_i - y_i)^2 \tag{9.71}\)

\(\hat{y}_i = (1 - \gamma_i)z_{i-1} + \gamma_i z_i \tag{9.72}\)

\(\gamma_i = \frac{x_i - g_i}{g_i - g_{i-1}} \tag{9.73}\)
```

这里 \(\hat{y}_i\) 是预测测量值。势函数使未知函数值 \( z_{i-1} \) 和 \( z_i \) 根据这些网格点距离测量点有多远而更接近观测值。此外，我们添加一个双平滑势，它编码了先验：\( z_i \) 应接近 \( z_{i-1} \) 和 \( z_{i+1} \)：

```
\(\phi_i(z_{i-1}, z_i) = \frac{1}{\tau^2}\delta_i^2 \tag{9.74}\)

\(\delta_i = z_i - z_{i-1} \tag{9.75}\)
```

总体模型为

```
\( p(\mathbf{z}|\mathbf{x}, \mathbf{y}, \mathbf{g}, \sigma^2, \tau^2) \propto \prod_{i=1}^G \psi_i(z_{i-1}, z_i)\phi_i(z_{i-1}, z_i) \tag{9.76} \)
```

假设真实的底层函数是正弦波。我们在图 9.11(a) 中展示了一些示例数据。然后我们应用高斯 BP。由于该模型是链，且模型是线性高斯，得到的后验边缘分布（如图 9.11(b) 所示）是精确的。我们看到，该方法仅基于平滑先验就推断出了底层正弦形状。

![](img/ca72c1626f4850f058a9edc138c1ac73_446_0.png)

图 9.12：（a）一个简单的含环图。（b）4 轮消息传递后，以节点 1 为根的计算树。节点 2 和 3 在树中出现频率更高，因为它们的度数高于节点 1 和 2。来自 [WJ08] 的图 8.2。由 Martin Wainwright 友好授权使用。

要在具有非线性（但高斯）势的模型中执行消息传递，我们可以将第 8.3.2 节的扩展卡尔曼滤波技术以及第 8.5.1 节和第 8.5.1.1 节的时刻匹配技术（基于四边形/西格玛点）从链推广到一般因子图（参见 [MHH14; PHR18; HPR19] 等）。要扩展到非高斯情况，我们可以使用非参数 BP 或粒子 BP（参见 [Sud+03; Isa03; Sud+10; Pac+14] 等），它借鉴了粒子滤波（第 13.2 节）的思想。

## 9.4.4 收敛

含环 BP 可能不会收敛，或者可能只会缓慢收敛。在本节中，我们讨论了一些增加收敛机会和加快收敛速度的技术。

### 9.4.4.1 LBP 何时收敛？

关于 LBP 何时收敛的分析细节超出了本章的范围，但我们简要勾勒了基本思想。关键分析工具是计算树，它可视化了算法进行时传递的消息。图 9.12 给出了一个简单示例。第一次迭代中，节点 1 接收来自节点 2 和 3 的消息。第二次迭代中，它接收来自节点 3（通过节点 2）的一条消息，来自节点 2（通过节点 3）的一条消息，以及来自节点 4（通过节点 2 和 3）的两条消息。依此类推。

关键洞察是，LBP 的 T 次迭代等价于高度为 T + 1 的计算树中的精确计算。如果边上的连接强度足够弱，那么叶子节点对根节点的影响会随时间减弱，收敛将发生。有关更多信息，请参见 [MK05; WJ08] 及其中的参考文献。
