### 29.9.3.1 热身

在最简单的设置中，我们知道有 N 个物体需要跟踪，每个物体生成各自唯一标识的观测。如果假设物体相互独立，我们可以并行应用卡尔曼滤波和平滑，如图 29.26 所示。（在此示例中，每个物体遵循具有不同初始随机速度的线性动力学模型，如第 29.7.1 节所示。）

### 29.9.3.2 数据关联

更一般地，在每个步骤中，我们可能观察到 M 个测量值，例如雷达屏幕上的“杂波点”。由于遮挡或漏检，可能出现 M < N 的情况；由于杂波或误报，可能出现 M > N 的情况；或者可能出现 M = N。无论哪种情况，我们都需要找出 M 次检测 x_t^m 与 N 个物体 z_t^i 之间的对应关系。这称为数据关联问题，在许多应用领域中都会出现。

我们可以通过向状态空间中增加表示观测 $\mathbf{y}_{t,1:M}$ 与源 $\mathbf{z}_{t,1:N}$ 之间关联矩阵的离散变量 $m_t$ 来建模此问题。如图 29.27 所示，我们有 $N = 2$ 个物体，但每个时间步的观测数量 $M_t$ 是可变的。如我们在第 29.9.2 节中提到的，这类混合（离散-连续）模型中的推断是不可处理的，因为后验模式的数量是指数级的。在下文中，我们简要提及几种近似推断方法。

### 29.9.3.3 使用匈牙利算法的最近邻近似

在该模型中执行近似推断的常见方法是计算一个 $N \times M$ 权重矩阵，其中 $W_{im}$ 衡量物体 $i$ 与测量 $m$ 之间的“兼容性”，通常基于 $m$ 与模型认为 $i$ 所在位置的接近程度（即所谓的最近邻数据关联启发式）。

我们可以通过添加虚拟背景物体（可解释所有误报）和添加虚拟观测（可解释所有漏检），将其转化为方阵。然后可以使用匈牙利算法计算最大权二分图匹配，其时间复杂度为 $O(\max(N, M)^3)$（例如，参见 [BDM09]）。在已知测量值与轨迹之间分配关系的条件下，我们可以执行常规的贝叶斯状态更新过程（例如，基于卡尔曼滤波）。请注意，分配给虚拟观测的物体不会执行测量更新，因此它们的状态估计仅基于动力学模型的前向预测。

### 29.9.3.4 其他近似推断方案

匈牙利算法可能较慢（因为其复杂度随测量数量的立方增长），并且由于依赖硬分配，可能会产生较差的结果。使用环形信念传播（第 9.4 节）可以获得更好的性能。其基本思想是近似边缘化未知分配变量，而不是执行 MAP 估计。这称为 SPADA 方法（用于数据关联的和积算法）[WL14b; Mey+18]。

该迭代过程每次迭代的代价为 $O(NM)$。此外，[WL14b] 证明其总是在有限步内收敛，[Von13] 表明相应的解实际上是全局最优解。SPADA 方法比早期的启发式方法（例如 JPDA（联合概率数据关联）[BSWT11; Vo+15]）更高效、更准确。

也可以使用序列蒙特卡罗方法来解决数据关联和跟踪问题。有关 SMC 的一般讨论，请参见第 13.2 节；有关此模型族特定技术的综述，请参见 [RAG04; Wan+17b]。

## 29.10 非线性 SSMs

在本节中，我们考虑具有非线性转换和/或观测函数且加有高斯噪声的 SSM。也就是说，我们假设模型具有以下形式

```
z_t = f(z_{t-1}, u_t) + q_t \tag{29.121}
q_t \sim \mathcal{N}(0, Q_t) \tag{29.122}
y_t = h(z_t, u_t) + r_t \tag{29.123}
r_t \sim \mathcal{N}(0, R_t) \tag{29.124}
```

这称为非线性动力系统（NLDS），或非线性高斯 SSM（NLG-SSM）。

### 29.10.1 示例：物体跟踪和状态估计

在第 8.3.2.3 节中，我们给出了一个二维跟踪问题的示例，其中运动模型是非线性的，但观测模型是线性的。

在此，我们考虑一个运动模型是线性的，但观测模型是非线性的示例。

特别是，假设我们使用与第 29.7.1 节相同的二维线性动力学，其中状态空间包含物体的位置和速度，\(z_t = (u_t \ v_t \ \dot{u}_t \ \dot{v}_t)\)。（我们使用 \(u\) 和 \(v\) 表示两个坐标，以避免与状态和观测变量混淆。）我们不直接观测位置，而是假设存在一个**仅轴承跟踪问题**，即我们只观测目标的角度：

```
y_t = \tan^{-1} \left( \frac{v_t - s_y}{u_t - s_x} \right) + r_t \tag{29.125}
```

其中 \((s_x, s_y)\) 是测量传感器的位置。如图 29.29 所示。这种非线性观测模型阻止了使用卡尔曼滤波器，但我们仍然可以应用近似推断方法，如下文所述。

## 29.11 非高斯 SSMs

在本节中，我们考虑转换和观测噪声为非高斯的 SSM。转换和观测函数可以是线性的或非线性的。我们可以将其表示为如下概率模型：

```
p(\mathbf{z}_t | \mathbf{z}_{t-1}, \mathbf{u}_t) = p(\mathbf{z}_t | \mathbf{f}(\mathbf{z}_{t-1}, \mathbf{u}_t)) \tag{29.126}
p(\mathbf{y}_t | \mathbf{z}_t, \mathbf{u}_t) = p(\mathbf{y}_t | \mathbf{h}(\mathbf{z}_t, \mathbf{u}_t)) \tag{29.127}
```

这称为非高斯 SSM（NSSM）。
