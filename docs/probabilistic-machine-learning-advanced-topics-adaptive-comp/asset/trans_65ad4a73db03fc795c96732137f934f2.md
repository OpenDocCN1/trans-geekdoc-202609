

如果 $\mathcal{D}^t$ 足够大，我们可以直接使用标准经验风险最小化（ERM）来优化这个问题。但是，如果 $\mathcal{D}^t$ 很小，我们可能希望以某种方式使用 $\mathcal{D}^s$ 作为正则化器。这被称为 **迁移学习**，因为我们希望从 $p$ 向 $q$ “转移知识”。迁移学习有许多方法（例如，参见 [Zhu+21] 的综述）。我们下面简要提及其中几种。

## 19.5.1.1 预训练与微调

迁移学习中最简单、最广泛使用的方法是 **预训练与微调** 方法。我们首先通过计算 $f^s = \text{argmin}_f \hat{R}(f, \mathcal{D}^s)$ 将模型拟合到源分布。（注意，源数据可能未标记，在这种情况下，我们可以使用自监督学习方法。）然后我们通过计算

\(f^t = \text{argmin}_f \hat{R}(f, \mathcal{D}^t) + \lambda ||f - f^s||\) (19.10)

来调整模型以在目标分布上工作。其中 $||f - f^s||$ 是函数之间的某种距离，$\lambda \ge 0$ 控制正则化的程度。由于我们假设来自目标分布的样本很少，我们通常会“冻结”源模型的大部分参数。（这隐含地假设对源分布有用的特征对目标分布也同样有效。）然后我们可以通过从 $f^s$ “切掉头部”并用新的线性层替换它来求解方程 (19.10)，以将特征映射到目标分布的新标签集，然后在目标分布上计算参数的新 MAP 估计。（我们也可以计算源模型参数的先验，并使用它来计算目标模型参数的后验，如第 17.2.3 节所讨论。）

该方法在实践中被广泛使用，因为它简单有效。特别是，通常会选取一个在大量数据（例如整个网络）上训练过的大型预训练模型，如 Transformer（通常使用自监督学习，见第 32.3.3 节），然后将该模型用作特征提取器（例如，参见 [Kol+20]）。特征被输入到下游模型中，下游模型可以是线性分类器或浅层 MLP，并在目标分布上训练。

## 19.5.1.2 提示调制（上下文学习）

最近又发展出了一种迁移学习方法，该方法利用大型模型，例如 Transformer（第 22.4 节），这些模型通常以无监督方式在大规模 Web 数据集上训练，然后适应小型的、特定于任务的目标分布。这种方法有趣的地方在于，原始模型的参数没有改变；相反，模型只是简单地“条件化”于新的训练数据，通常以文本 **提示** $\boldsymbol{z}$ 的形式。也就是说，我们计算

\(f^t(x) = f^s(x \cup z)\) (19.11)

其中我们（手动或自动）优化 $\boldsymbol{z}$，同时保持 $f^s$ 冻结。这种方法称为 **提示调制** 或 **上下文学习**（例如，参见 [Liu+21a]），它是 **少样本学习** 的一个实例（示例见图 22.4）。

这里 $\boldsymbol{z}$ 就像一个小型训练数据集，$f^s$ 使用注意力机制（第 16.2.7 节）来“查看”其所有输入，将 $\boldsymbol{x}$ 与 $\boldsymbol{z}$ 中的示例进行比较，并利用此进行预测。之所以有效，是因为文本训练数据通常具有相似的层次结构（贝叶斯解释见 [Xie+22]）。

## 19.5.2 协变偏移下的加权 ERM

在本节中，我们重新考虑方程 (19.8) 中的风险最小化目标，但利用来自目标分布的未标记数据来估计它。如果我们做出协变偏移假设（即，$q(\boldsymbol{x}, \boldsymbol{y}) = q(\boldsymbol{x})p(\boldsymbol{y}|\boldsymbol{x})$），则有

$R(f, q) = \int q(\boldsymbol{x})q(\boldsymbol{y}|\boldsymbol{x})\ell(\boldsymbol{y}, f(\boldsymbol{x}))dxdy$
$= \int q(\boldsymbol{x})p(\boldsymbol{y}|\boldsymbol{x})\ell(\boldsymbol{y}, f(\boldsymbol{x}))dxdy$
$= \int \frac{q(\boldsymbol{x})}{p(\boldsymbol{x})}p(\boldsymbol{x})p(\boldsymbol{y}|\boldsymbol{x})\ell(\boldsymbol{y}, f(\boldsymbol{x}))dxdy$
$\approx \frac{1}{N} \sum_{(\boldsymbol{x}_n, \boldsymbol{y}_n) \in \mathcal{D}_L^t} w_n \ell(\boldsymbol{y}_n, f(\boldsymbol{x}_n))$

其中权重由比率给出

$w_n = w(\boldsymbol{x}_n) = \frac{q(\boldsymbol{x}_n)}{p(\boldsymbol{x}_n)}$

因此，我们可以通过使用 **加权 ERM** [Shi00a; SKM07] 来解决协变偏移问题。

然而，这引发了两个问题。首先，为什么我们需要使用这种技术，因为判别模型 $p(\boldsymbol{y}|\boldsymbol{x})$ 应该对任何输入 $\boldsymbol{x}$ 都有效，无论它来自哪个分布？其次，既然我们确实需要使用这种方法，在实践中应该如何估计权重 $w_n = w(\boldsymbol{x}_n) = \frac{q(\boldsymbol{x}_n)}{p(\boldsymbol{x}_n)}$？我们将在下面讨论这些问题。

### 19.5.2.1 协变偏移为何对判别模型构成问题？

对于形式为 $p(\boldsymbol{y}|\boldsymbol{x})$ 的判别模型，人们可能会认为 $p(\boldsymbol{x})$ 的这种变化不会影响预测。如果预测器 $p(\boldsymbol{y}|\boldsymbol{x})$ 是输入空间 $\boldsymbol{x}$ 所有部分的正确模型，那么这个结论是合理的。然而，大多数模型仅在输入空间的某些部分是准确的。图 19.10b 说明了这一点，其中我们显示，针对源分布拟合的线性模型在目标分布上的表现可能远不如在训练期间更加重视目标点的模型。

### 19.5.2.2 应如何估计 ERM 权重？

估计 ERM 权重 $w_n = w(\boldsymbol{x}_n) = \frac{q(\boldsymbol{x}_n)}{p(\boldsymbol{x}_n)}$ 的一种方法是为源分布和目标分布学习密度模型。然而，对于高维特征，密度估计是困难的。另一种方法是尝试近似密度比率，即通过拟合二元分类器来区分两个分布，如第 2.7.5 节所讨论。特别是，假设我们从 $p(\boldsymbol{x})$ 和 $q(\boldsymbol{x})$ 中拥有相同数量的样本。让我们将第一组标记为 $c = -1$，第二组标记为 $c = 1$。那么我们有

$p(c = 1|\boldsymbol{x}) = \frac{q(\boldsymbol{x})}{q(\boldsymbol{x}) + p(\boldsymbol{x})}$

and hence \(\frac{p(c=1|\boldsymbol{x})}{p(c=-1|\boldsymbol{x})} = \frac{q(\boldsymbol{x})}{p(\boldsymbol{x})}$. 如果分类器的形式为 \(f(\boldsymbol{x}) = p(c=1|\boldsymbol{x}) = \sigma(h(\boldsymbol{x})) = \frac{1}{1+\exp(-h(\boldsymbol{x}))}\)，其中 \(h(\boldsymbol{x})\) 是返回 logits 的预测函数，那么重要性权重由以下公式给出

\(w_n = \frac{1/(1+\exp(-h(\boldsymbol{x}_n)))}{\exp(-h(\boldsymbol{x}_n))/(1+\exp(-h(\boldsymbol{x}_n)))} = \exp(h(\boldsymbol{x}_n))$

Of course 这种方法要求测试分布中可能出现的 $\boldsymbol{x}$ 值在训练分布中也应是可能的，即 $q(\boldsymbol{x}) > 0 \Longrightarrow p(\boldsymbol{x}) > 0$。因此，无法保证该方法能够对超出训练分布的数据进行插值。

## 19.5.3 协变偏移下的无监督域自适应

我们现在转向只需访问来自目标分布的未标记示例的方法。**无监督域自适应**或 **UDA** 技术假设可以访问来自源分布的标记数据集 \(\mathcal{D}_1 = \mathcal{D}_L^s \sim p(\boldsymbol{x}, \boldsymbol{y})\) 和来自目标分布的未标记数据集 \(\mathcal{D}_2 = \mathcal{D}_L^t \sim q(\boldsymbol{x})$。然后它使用未标记的目标数据来提高预测器的鲁棒性或不变性，而不是使用加权 ERM 方法。

UDA 有多种形式（综述见例如 [KL21; CB20]）。在这里，我们只关注一种方法，称为 **域对抗学习** [Gan+16a]。设 \(f_\boldsymbol{\alpha}: \mathcal{X}_1 \cup \mathcal{X}_2 \rightarrow \mathcal{H}$ 为定义在两个输入域上的特征提取器，设 \(c_\boldsymbol{\beta}: \mathcal{H} \rightarrow \{1, 2\}$ 为从特征空间映射到输入所来自域（域 1 或域 2，即源域或目标域）的分类器，并设 \(g_\boldsymbol{\gamma}: \mathcal{H} \rightarrow \mathcal{Y}$ 为从特征空间映射到标签空间的分类器。我们希望训练特征提取器，使其无法区分输入是来自源分布还是目标分布；在这种情况下，它只能使用两个域共有的特征。因此，我们优化

\(\min_\boldsymbol{\gamma} \max_{\boldsymbol{\alpha}, \boldsymbol{\beta}} \frac{1}{N_1 + N_2} \sum_{\boldsymbol{x}_n \in \mathcal{D}_1, \mathcal{D}_2} \ell(d_n, c_\boldsymbol{\beta}(f_\boldsymbol{\alpha}(\boldsymbol{x}_n))) + \frac{1}{N_1} \sum_{(\boldsymbol{x}_n, \boldsymbol{y}_n) \in \mathcal{D}_1} \ell(\boldsymbol{y}_n, g_\boldsymbol{\gamma}(f_\boldsymbol{\alpha}(\boldsymbol{x}_n)))$
