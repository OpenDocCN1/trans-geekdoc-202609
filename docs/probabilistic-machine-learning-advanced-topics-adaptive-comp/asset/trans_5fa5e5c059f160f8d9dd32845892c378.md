## 8.6 假设密度滤波

在本节中，我们讨论 **假设密度滤波** 或 **ADF** [May79]。在此方法中，我们 **假设** 后验具有特定形式（例如，高斯分布）。在每一步中，我们用新的似然更新先前的后验；结果通常不会具有所需形式（例如，不再是高斯分布），因此我们将其投影到所需类型的最接近的近似分布上。

更详细地说，我们假设（通过归纳）我们的先验 $q_{t-1}(\boldsymbol{z}_{t-1}) \approx p(\boldsymbol{z}_{t-1}|\boldsymbol{y}_{1:t-1})$ 满足 $q_{t-1} \in \mathcal{Q}$，其中 $\mathcal{Q}$ 是可处理分布的一个家族。我们可以用新的测量更新先验，以如下方式得到近似后验。首先我们计算 **一步先验预测分布**

$p_{t|t-1}(\boldsymbol{z}_t|\boldsymbol{y}_{1:t-1}) = \int p(\boldsymbol{z}_t|\boldsymbol{z}_{t-1})q_{t-1}(\boldsymbol{z}_{t-1})d\boldsymbol{z}_{t-1}$ (8.195)

然后我们用步骤 $t$ 的似然更新这个先验，以得到后验

$p_t(\boldsymbol{z}_t|\boldsymbol{y}_{1:t}) = \frac{1}{Z_t}p(\boldsymbol{y}_t|\boldsymbol{z}_t)p_{t|t-1}(\boldsymbol{z}_t)$ (8.196)

其中

$Z_t = \int p(\boldsymbol{y}_t|\boldsymbol{z}_t)p_{t|t-1}(\boldsymbol{z}_t)d\boldsymbol{z}_t$ (8.197)

是归一化常数。不幸的是，我们经常发现得到的后验不再属于我们的可处理家族，$p(\boldsymbol{z}_t) \notin \mathcal{Q}$。因此在贝叶斯更新后，我们通过计算以下方式寻找最佳可处理近似

$q_t(\boldsymbol{z}_t|\boldsymbol{y}_{1:t}) = \underset{q \in \mathcal{Q}}{\text{argmin}} D_{\text{KL}}(p_t(\boldsymbol{z}_t|\boldsymbol{y}_{1:t}) \| q(\boldsymbol{z}_t))$ (8.198)

这最小化了从近似 $q(\boldsymbol{z}_t)$ 到“精确”后验 $p_t(\boldsymbol{z}_t)$ 的库尔贝克-莱布尔散度，可以被视为 **投影** $p$ 到可处理分布的空间。因此，整体算法由三个步骤组成——预测、更新和投影——如图 8.6 所示。

计算 \(\min_q D_{\text{KL}}(p \| q)\) 称为 **矩投影**，因为最优 \(q\) 应与 \(p\) 具有相同的矩（见第 5.1.4.2 节）。因此，在高斯情况下，我们只需设置 $q_t$ 的均值和协方差，使其与 $p_t$ 的均值和协方差相同。我们将在下面给出一些示例。相比之下，计算 \(\min_q D_{\text{KL}}(q \| p)$，如变分推断（第 10.1 节）中所示，称为 **信息投影**，并会导致模式搜索行为（见第 5.1.4.1 节），而不是试图捕获整体矩。

### 8.6.1 与高斯滤波的连接

当 \(\mathcal{Q}$ 是高斯分布集合时，ADF 与高斯滤波之间存在紧密的连接，我们在第 8.5.1 节中讨论过。GF 对应于求解以下优化问题

\(q_{t|t-1}(\boldsymbol{z}_t, \tilde{\boldsymbol{y}}_t) = \underset{q \in \mathcal{Q}}{\text{argmin}} D_{\text{KL}}(p(\boldsymbol{z}_t, \tilde{\boldsymbol{y}}_t | \boldsymbol{y}_{1:t-1}) \| q(\boldsymbol{z}_t, \tilde{\boldsymbol{y}}_t | \boldsymbol{y}_{1:t-1})) \tag{8.199}\)

这可以通过矩匹配求解（见第 8.5.1 节）。然后我们将这个联合分布条件化于事件 \(\tilde{\boldsymbol{y}}_t = \boldsymbol{y}_t$，其中 \(\tilde{\boldsymbol{y}}_t$ 是未知随机变量，\(\boldsymbol{y}_t$ 是其观测值。这给出了 \(p_t(\boldsymbol{z}_t | \boldsymbol{y}_{1:t})$，由于高斯假设，它易于计算。相比之下，在高斯 ADF 中，我们首先计算（局部）精确后验 \(p_t(\boldsymbol{z}_t | \boldsymbol{y}_{1:t})$，然后通过投影到 \(\mathcal{Q}$，用 \(q_t(\boldsymbol{z}_t | \boldsymbol{y}_{1:t})$ 近似它。因此，ADF 近似条件分布 \(p_t(\boldsymbol{z}_t | \boldsymbol{y}_{1:t})$，而 GF 近似联合分布 \(p_{t|t-1}(\boldsymbol{z}_t, \tilde{\boldsymbol{y}}_t | \boldsymbol{y}_{1:t-1})$，我们从中通过条件化推导出 \(p_t(\boldsymbol{z}_t | \boldsymbol{y}_{1:t})$。

### 8.6.2 SLDS 的 ADF（高斯和滤波）

在本节中，我们将 ADF 应用于切换线性动态系统（SLDS，第 29.9 节）的推断，SLDS 是 HMM 和 LDS 模型的组合。由此得到的方法称为 **高斯和滤波**（例如，见 [Cro+11; Wil+17]）。

高斯和滤波在每一步用 $K$ 个高斯分布的混合近似信念状态。这可以通过并行运行 $K$ 个卡尔曼滤波器实现。这特别适用于切换 SSM。我们现在描述该算法的一个版本，称为“二阶广义伪贝叶斯滤波器”（GPB2）[BSF88]。我们假设先前的信念状态 $b_{t-1}$ 是每个离散状态一个高斯分布的 $K$ 个高斯分布的混合：

```
$b_{t-1}^i \triangleq p(\mathbf{z}_{t-1}, m_{t-1} = i | \mathbf{y}_{1:t-1}) = \pi_{t-1|t-1}^i \mathcal{N}(\mathbf{z}_{t-1} | \boldsymbol{\mu}_{t-1|t-1}^i, \boldsymbol{\Sigma}_{t-1|t-1}^i)$ (8.200)
```

其中 $i \in \{1, \dots, K\}$。然后我们将其通过 $K$ 个不同的线性模型，得到

```
$b_t^{ij} \triangleq p(\mathbf{z}_t, m_{t-1} = i, m_t = j | \mathbf{y}_{1:t}) = \pi_{t|t}^{ij} \mathcal{N}(\mathbf{z}_t | \boldsymbol{\mu}_{t|t}^{ij}, \boldsymbol{\Sigma}_{t|t}^{ij})$ (8.201)
```

其中 $\pi_{t|t}^{ij} = \pi_{t-1|t-1}^i A_{ij}$，且 $A_{ij} = p(m_t = j | m_{t-1} = i)$。最后，对于每个 $j$ 的值，我们将 $K$ 个高斯混合坍缩为单个混合，以给出

```
$b_t^j \triangleq p(\mathbf{z}_t, m_t = j | \mathbf{y}_{1:t}) = \pi_{t|t}^j \mathcal{N}(\mathbf{z}_t | \boldsymbol{\mu}_{t|t}^j, \boldsymbol{\Sigma}_{t|t}^j)$ (8.202)
```

草图见图 8.8a。

用单个高斯分布近似高斯混合的最优方式由 $q = \arg \min_q D_{\text{KL}}(q \| p)$ 给出，其中 $p(\mathbf{z}) = \sum_k \pi^k \mathcal{N}(\mathbf{z} | \boldsymbol{\mu}^k, \boldsymbol{\Sigma}^k)$ 和 $q(\mathbf{z}) = \mathcal{N}(\mathbf{z} | \boldsymbol{\mu}, \boldsymbol{\Sigma})$。这可以通过矩匹配求解，即，

```
\boldsymbol{\mu} = \mathbb{E}[\boldsymbol{z}] = \sum_k \pi^k \boldsymbol{\mu}^k (8.203)
```

```
\boldsymbol{\Sigma} = \text{Cov}[\boldsymbol{z}] = \sum_k \pi^k \left( \boldsymbol{\Sigma}^k + (\boldsymbol{\mu}^k - \boldsymbol{\mu})(\boldsymbol{\mu}^k - \boldsymbol{\mu})^\mathsf{T} \right) (8.204)
```

在图形模型文献中，这被称为弱边缘化 [Lau92]，因为它保留了前两个矩。将这些方程应用于我们的模型，我们可以从 \( b_t^{ij}$ 到 \( b_t^j$ 如下（为简洁起见，我们省略了 \(t$ 下标）：

```
\pi^j = \sum_i \pi^{ij} (8.205)
```

```
\pi^{j|i} = \frac{\pi^{ij}}{\sum_{j'} \pi^{ij'}} (8.206)
```

```
\boldsymbol{\mu}^j = \sum_i \pi^{j|i} \boldsymbol{\mu}^{ij} (8.207)
```

```
\boldsymbol{\Sigma}^j = \sum_i \pi^{j|i} \left( \boldsymbol{\Sigma}^{ij} + (\boldsymbol{\mu}^{ij} - \boldsymbol{\mu}^j)(\boldsymbol{\mu}^{ij} - \boldsymbol{\mu}^j)^\mathsf{T} \right) (8.208)
```

该算法在每一步需要运行 $K^2$ 个滤波器。一种更便宜的替代方法，称为交互多模型或 IMM [BSF88]，可以通过先将先验坍缩为单个高斯分布（通过矩匹配），然后使用 $K$ 个不同的卡尔曼滤波器（每个 $m_t$ 的值一个）对其进行更新来获得。草图见图 8.8b。

### 8.6.3 在线逻辑回归的 ADF

在本节中，我们讨论 ADF 在二元逻辑回归模型的在线贝叶斯参数推断中的应用，基于 [Zoe07]。总体方法与在线线性回归情况（在第 29.7.2 节中讨论）相似，但在每个更新步骤后近似后验，这是必要的，因为似然与先验不是共轭的。

我们假设我们的模型具有以下形式：

```
p(y_t|\boldsymbol{x}_t, \boldsymbol{w}_t) = \text{Ber}(y_t|\sigma(\boldsymbol{x}_t^\mathsf{T} \boldsymbol{w}_t)) (8.209)
```

```
p(\boldsymbol{w}_t|\boldsymbol{w}_{t-1}) = \mathcal{N}(\boldsymbol{w}_t|\boldsymbol{w}_{t-1}, \mathbf{Q}) (8.210)
```

其中 \(\mathbf{Q}$ 是过程噪声的协方差，允许参数随时间缓慢变化。我们将假设 \(\mathbf{Q} = \epsilon \mathbf{I}$；如果我们相信参数不会变化，也可以设置 \(\epsilon = 0$，如递归最小二乘方法（第 29.7.2 节）中所示。模型示意图见图 8.9。

作为我们的近似家族，我们将出于计算效率考虑使用对角高斯分布。因此，先验是前一时间步的后验，并具有以下形式

```
p(\boldsymbol{w}_{t-1}|\mathcal{D}_{1:t-1}) \approx p_{t-1}(\boldsymbol{w}_{t-1}) = \prod_j \mathcal{N}(w_{t-1}^j|\mu_{t-1|t-1}^j, \tau_{t-1|t-1}^j) (8.211)
```
