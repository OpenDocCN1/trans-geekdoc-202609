对于离散数据，所有概率都上界为 1，因此 $H \ge 0$ 且 $D \ge 0$。此外，速率始终非负，$R \ge 0$，因为它是 KL 散度的平均值。（这对于离散或连续编码 \(\mathbf{z}\) 均成立。）因此，我们可以绘制 $R$ 和 $D$ 的可实现值集合，如图 5.10 所示。这被称为 **速率失真曲线**。

底部水平线对应于零失真设置，$D = 0$，在此设置下我们可以完美地对数据进行编码和解码。这可以通过使用平凡编码器来实现，其中 $e(\mathbf{z}|\mathbf{x}) = \delta(\mathbf{z} - \mathbf{x})$。香农源编码定理告诉我们，在这种情况下对数据进行编码所需的最小比特数是数据的熵，因此当 $D = 0$ 时，$R \ge H$。如果我们使用次优边缘分布 \(m(\mathbf{z})\) 进行编码，将会在不影响失真的情况下增加速率。

左侧垂直线对应于零速率设置，$R = 0$，此时隐码与 \(\mathbf{z}\) 独立。在这种情况下，解码器 \(d(\mathbf{x}|\mathbf{z})\) 与 \(\mathbf{z}\) 独立。然而，我们仍然可以学习一个不使用隐变量的联合概率模型 \(p(\mathbf{x})\)，例如，这可以是一个自回归模型。这样的模型所能达到的最小失真再次是数据的熵，\(D \ge H\)。

黑色对角线说明了满足 \(D = H - R\) 的解，其中上界和下界都很紧。在实践中，我们无法实现对角线上的点，因为这要求界限紧，并且因此假设我们的模型 \(e(\mathbf{z}|\mathbf{x})\) 和 \(d(\mathbf{x}|\mathbf{z})\) 是完美的。这被称为“非参数极限”。在有限数据设置中，我们总会产生额外误差，因此 RD 图将追踪一条上移的曲线，如图 5.10 所示。

我们可以通过最小化以下目标函数来生成沿此曲线的不同解：

```
$J = D + \beta R = \int d\mathbf{x} \ p(\mathbf{x}) \int d\mathbf{z} \ e(\mathbf{z}|\mathbf{x}) \left[ - \log d(\mathbf{x}|\mathbf{z}) + \beta \log \frac{e(\mathbf{z}|\mathbf{x})}{m(\mathbf{z})} \right]$ (5.160)
```

如果我们设置 \(\beta = 1\)，并定义 \(q(\mathbf{z}|\mathbf{x}) = e(\mathbf{z}|\mathbf{x})\)、\(p(\mathbf{x}|\mathbf{z}) = d(\mathbf{x}|\mathbf{z})\) 和 \(p(\mathbf{z}) = m(\mathbf{z})\)，这与第 21.2 节中的 VAE 目标完全匹配。要看明白这一点，请注意，第 10.1.1.2 节的 ELBO 可以写为

```
$\mathbb{L} = -(D + R) = \mathbb{E}_{p(\mathbf{x})} \left[ \mathbb{E}_{e(\mathbf{z}|\mathbf{x})} [\log d(\mathbf{x}|\mathbf{z})] - \mathbb{E}_{e(\mathbf{z}|\mathbf{x})} \left[ \log \frac{e(\mathbf{z}|\mathbf{x})}{m(\mathbf{z})} \right] \right]$ (5.161)
```

我们将其识别为预期重建误差减去 KL 项 $D_{\text{KL}}(e(z|x) \parallel m(z))$。如果我们允许 $\beta \neq 1$，我们将恢复第 21.3.1 节讨论的 $\beta$-VAE 目标。然而请注意，$\beta$-VAE 模型无法区分对角线上的不同解，所有这些解都有 $\beta = 1$。这是因为所有此类模型都有相同的边缘似然（因此也有相同的 ELBO），尽管它们在学习有趣的隐性表征方面存在根本差异。因此，似然不足以作为比较无监督表征学习方法质量的度量，如第 21.3.1 节所讨论。

关于速率、失真和感知之间固有冲突的进一步讨论，请参见 [BM19]。关于评估模型速率失真曲线的技术，请参见 [HCG20]。

### 5.4.3 比特返还编码

在前一节中，我们使用平均 KL 散度 $\mathbb{E}_{p(x)}[R(x)]$ 来惩罚我们的代码速率，其中
$$R(x) \triangleq \int dz \, p(z|x) \log \frac{p(z|x)}{m(z)} = \mathbb{H}_{ce}(p(z|x), m(z)) - \mathbb{H}(p(z|x)). \tag{5.162}$$

第一个项是交叉熵，即我们需要对 x 进行编码所需的预期比特数；第二个项是熵，即最小比特数。因此，我们正在惩罚将代码传递给接收者所需的额外比特数。为什么我们不需要“支付”我们实际使用的（总）比特数，即交叉熵呢？

原因是，我们原则上可以将最优代码所需的比特数拿回来；这称为比特返还编码 [HC93; FH97]。论证过程如下。假设 Alice 试图（无损地）向 Bob 传递一些数据，例如图像 x。在他们分道扬镳之前，Alice 和 Bob 决定共享他们的编码器 p(z|x)、边缘分布 m(z) 和解码器分布 d(x|z)。要传输图像，Alice 将使用两部分代码。首先，她将从她的编码器中采样一个代码 z ~ p(z|x)，并通过一个设计用于有效编码来自边缘分布 m(z) 的样本的信道将其传递给 Bob；这需要 -log2 m(z) 个比特。接下来，Alice 将使用她的解码器 d(x|z) 计算残差误差，并以 -log2 d(x|z) 个比特的代价无损地将其发送给 Bob。这里所需的预期总比特数正是我们天真地期望的：
$$
\mathbb{E}_{p(z|x)}[-\log_2 d(x|z) - \log_2 m(z)] = D + \mathbb{H}_{ce}(p(z|x), m(z)). \tag{5.163}
$$

我们可以看到，这是失真加上交叉熵，而不是失真加上速率。那么，我们如何拿回比特，将交叉熵转换为速率项呢？

技巧在于 Bob 实际接收到的信息比我们想象的更多。Bob 可以使用代码 z 和残差误差来完美重建 x。然而，Bob 也知道 Alice 发送的具体代码 z 以及她使用的编码器 p(z|x)。当 Alice 采样代码 z ~ p(z|x) 时，她必须使用某种熵源来生成随机样本。假设她是通过从压缩版的《白鲸》中依次选取单词来生成一串随机比特的。在 Bob 那一端，他可以反向工程所有采样比特，从而恢复压缩版的《白鲸》！因此 Alice 可以利用 z 选择中的额外随机性来共享更多信息。

虽然在原始表述中，比特返还论证在很大程度上是理论上的，它提供了一个思想实验，说明为什么我们应该用 KL 散度而不是交叉熵来惩罚我们的模型，但最近已经开发出几种实际的现实世界算法，它们确实实现了比特返回目标。这些包括 [HPHL19; AT20; TBB19; YBM20; HLA19; FHHJL20]。

## 5.5 纠错码（信道编码）

**纠错码**背后的想法是在信号 \(\boldsymbol{x}\)（即原始数据编码的结果）中添加冗余，这样当它通过嘈杂的传输线（例如手机连接）发送到接收器时，接收器可以从可能发生的任何信号损坏中恢复。这称为 **信道编码**。

更详细地说，设 \(\boldsymbol{x} \in \{0, 1\}^m\) 为源消息，其中 \(m\) 称为 **分组长度**。设 \(\boldsymbol{y}\) 为通过 **噪声信道** 发送 \(\boldsymbol{x}\) 的结果。这是消息的损坏版本。例如，每个消息比特可能以概率 \(\alpha\) 独立翻转，在这种情况下 \(p(\boldsymbol{y}|\boldsymbol{x}) = \prod_{i=1}^m p(y_i|x_i)\)，其中 \(p(y_i|x_i=0) = [1-\alpha, \alpha]\) 和 \(p(y_i|x_i=1) = [\alpha, 1-\alpha]\)。或者，我们可以添加高斯噪声，因此 \(p(y_i|x_i=b) = \mathcal{N}(y_i|\mu_b, \sigma^2)\)。接收器的目标是从噪声观测中推断真实消息，即计算 \(\text{argmax}_\boldsymbol{x} p(\boldsymbol{x}|\boldsymbol{y})\)。

增加能够恢复原始信号机会的常见方法是在发送前向其中添加 **奇偶校验位**。这些是原始信号的确定性函数，用于指定输入比特之和是奇数还是偶数。这提供了一种 **冗余** 形式，这样如果一个比特损坏，我们仍然可以推断其值，假设其他比特没有翻转。（这是合理的，因为我们假设比特是独立随机损坏的，因此多个比特翻转的可能性比仅一个比特翻转要小。）

例如，假设我们有两个原始消息比特，并且添加一个奇偶位。这可以使用有向图形模型进行建模，如图 5.11(a) 所示。该图编码了以下联合概率分布：

```
\(p(\boldsymbol{x}, \boldsymbol{y}) = p(x_1)p(x_2)p(x_3|x_1, x_2) \prod_{i=1}^3 p(y_i|x_i)\) (5.164)
```

先验 \(p(x_1)\) 和 \(p(x_2)\) 是均匀的。条件项 \(p(x_3|x_1, x_2)\) 是确定性的，并计算 \((x_1, x_2)\) 的奇偶性。具体而言，如果块 \(x_{1:2}\) 中 1 的总数为奇数，则 \(p(x_3=1|x_1, x_2) = 1\)。似然项 \(p(y_i|x_i)\) 表示一个比特翻转噪声信道模型，噪声级别 \(\alpha = 0.2\)。
