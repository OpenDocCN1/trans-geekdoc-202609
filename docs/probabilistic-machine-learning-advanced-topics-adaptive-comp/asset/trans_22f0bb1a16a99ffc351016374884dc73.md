#### 3.9.1.2 示例：线性回归

拟合条件模型 \(p(\boldsymbol{y}|\boldsymbol{x})\) 时，对于每个输入 \(\boldsymbol{x}\) 都会得到不同的预测。我们可以将预测分布 \(p(\boldsymbol{y}|\boldsymbol{x}_n)\) 与观测值 \(\boldsymbol{y}_n\) 进行比较，以检测模型表现不佳的地方。

举例来说，我们考虑来自 [McE20, Sec 5.1] 的“华夫饼离婚”数据集。该数据集包含 50 个不同美国州的离婚率 \(D_n\)、结婚率 \(M_n\) 以及初婚年龄 \(A_n\)。我们使用线性回归模型来预测离婚率，\(p(y = d|\boldsymbol{x} = (a, m)) = \mathcal{N}(d|\alpha + \beta_a a + \beta_m m, \sigma^2)\)，对参数使用模糊先验。（在本示例中，我们对后验使用拉普拉斯近似，讨论见第 7.4.3 节。）随后我们计算后验预测分布 \(p(y|\boldsymbol{x}_n, \mathcal{D})\)，它是一个一维高斯分布，并将其与每个观测结果 \(y_n\) 对比绘制。

结果如图 3.26 所示。我们看到几个离群点，其中一些已被标注。特别是，我们看到爱达荷州（ID）和犹他州（UT）的离婚率均远低于预测值。这是因为这两个州的摩门教徒比例异常高。

当然，我们预期预测模型会有误差。但理想情况下，对于模型出错的输入，其预测误差棒应当更大，而不是模型自信地犯错。在此例中，这种过度自信源于我们错误地使用了线性模型。

### 3.9.2 贝叶斯 p 值

如果观测数据的某个检验统计量 test(D) 出现在预测分布的左尾或右尾，那么在模型下它发生的可能性很小。我们可以使用 **贝叶斯 p 值**（也称为 **后验预测 p 值**）来量化这一点：

$p_B = \text{Pr}(\text{test}(\tilde{\mathcal{D}}) \ge \text{test}(\mathcal{D})|M, \mathcal{D})$ (3.320)

其中 M 表示我们使用的模型，\(\tilde{\mathcal{D}}\) 是一个假设的未来数据集。相比之下，经典或频率学派 **p 值**定义为

$p_C = \text{Pr}(\text{test}(\tilde{\mathcal{D}}) \ge \text{test}(\mathcal{D})|M)$ (3.321)

其中 M 表示原假设。关键区别在于，贝叶斯方法将观测结果与对数据条件化后模型的预期进行比较，而频率学派方法将观测结果与原假设的抽样分布进行比较，后者与数据无关。

我们可以使用蒙特卡洛积分来近似贝叶斯 p 值，方法如下：

$p_B = \int \mathbb{I}\big(\text{test}(\tilde{\mathcal{D}}) > \text{test}(\mathcal{D})\big) p(\tilde{\mathcal{D}}|\theta)p(\theta|\mathcal{D})d\theta \approx \frac{1}{S} \sum_{s=1}^S \mathbb{I}\big(\text{test}(\tilde{\mathcal{D}}^s) > \text{test}(\mathcal{D})\big)$ (3.322)

$p_B$ 的任何极端值（即接近 0 或 1 的值）都意味着观测数据在模型下不太可能，这是通过检验统计量 test 评估的。然而，如果 test(D) 是模型的充分统计量，那么它很可能被良好估计，p 值将接近 0.5。例如，在光速示例中，如果我们将检验统计量定义为数据的方差，\(\text{test}(\mathcal{D}) = \mathbb{V}\{y : y \in \mathcal{D}\}\)，则得到的 p 值为 0.48。（参见图 3.25(d)。）这表明高斯模型能够表示数据中的方差，尽管它无法表示数据的支持（范围）。

上述示例说明了一个非常重要的观点：我们不应试图评估数据是否来自给定模型（答案几乎总是否定的），而应尝试评估模型是否捕捉了我们关心的特征。有关此主题的更详细讨论，请参见 [Gel+04, ch.6]。

## 3.10 假设检验

假设我们收集了一些投币数据，想知道硬币是否公平。或者，更有趣的情况是，我们收集了一些临床试验数据，想知道治疗对结果是否存在非零影响（例如，治疗组和对照组的生存率不同）。这类问题可以使用 **假设检验** 来解决。在下面的小节中，我们将总结几种常见的假设检验方法。

### 3.10.1 频率学派方法

本节总结了经典或频率学派统计中使用的假设检验方法，称为 **原假设显著性检验** 或 **NHST**。其基本思想是定义一个形式为 \(\delta(\mathcal{D}) = \mathbb{I}(t(\mathcal{D}) \ge t^*)\) 的二元决策规则，其中 \(t(\mathcal{D})\) 是从数据导出的某个标量 **检验统计量**，\(t^*\) 是某个 **临界值**。如果检验统计量超过临界值，我们 **拒绝原假设**。可供使用的检验统计量种类繁多（例如，[Ken93] 列出了超过 100 种不同的检验），但一个简单的例子是 **t 统计量**，定义为

$$t(\mathcal{D}) = \frac{\overline{x} - \mu}{\hat{\sigma}/\sqrt{N}}$$

其中 \(\overline{x}\) 是 \(\mathcal{D}\) 的经验均值，\(\hat{\sigma}\) 是经验标准差，\(N\) 是样本量，\(\mu\) 是 **总体均值**，对应于原假设的均值（通常为 0）。

为了计算临界值 \(t^*\)，我们选择一个 **显著性水平** \(\alpha\)，通常为 0.05，它控制决策程序的 **I 类错误率**（即在原假设为真时意外拒绝它的概率）。然后我们找到一个值 \(t^*\)，使得在给定原假设下检验统计量的抽样分布下其尾概率与显著性水平相等：

$$p(t(\tilde{\mathcal{D}}) \ge t^* | H_0) = \alpha$$

这种构造保证了 \(p(\delta(\tilde{\mathcal{D}}) = 1 | H_0) = \alpha\)。

与将 \(t(\mathcal{D})\) 与 \(t^*\) 进行比较相比，更常见（但等价）的方法是计算 \(t(\mathcal{D})\) 的 **p 值**，其定义见方程 (3.86)。然后我们可以在 \(p < \alpha\) 时拒绝原假设。不幸的是，尽管 p 值和 NHST 被广泛使用，但它们存在许多问题，其中一些将在 3.3.5.2 节中讨论。因此，我们将在本书中避免使用此方法。

### 3.10.2 贝叶斯方法

本节讨论了假设检验的贝叶斯方法。实际上有两种方法：一种基于使用贝叶斯因子进行模型比较（第 3.10.2.1 节），另一种基于参数估计（第 3.10.2.3 节）。

| :--- | :--- |
| $BF < \frac{1}{100}$ | 支持 $M_0$ 的决定性证据 |
| $BF < \frac{1}{10}$ | 支持 $M_0$ 的强证据 |
| $\frac{1}{10} < BF < \frac{1}{3}$ | 支持 $M_0$ 的中等证据 |
| $\frac{1}{3} < BF < 1$ | 支持 $M_0$ 的弱证据 |
| $1 < BF < 3$ | 支持 $M_1$ 的弱证据 |
| $3 < BF < 10$ | 支持 $M_1$ 的中等证据 |
| $BF > 10$ | 支持 $M_1$ 的强证据 |
| $BF > 100$ | 支持 $M_1$ 的决定性证据 |

#### 3.10.2.1 模型比较方法

当只有两个模型（通常称为 **原假设** $M_0$ 和 **备选假设** $M_1$）时，贝叶斯假设检验是贝叶斯模型选择（第 3.8.1 节中讨论）的一个特例。让我们将 **贝叶斯因子** 定义为边缘似然比：

$$B_{1,0} \triangleq \frac{p(\mathcal{D}|M_1)}{p(\mathcal{D}|M_0)} = \frac{p(M_1|\mathcal{D})}{p(M_0|\mathcal{D})} / \frac{p(M_1)}{p(M_0)}$$ (3.325)

（这类似于 **似然比**，只是我们对参数进行了积分消去，从而可以比较复杂性不同的模型。）如果 $B_{1,0} > 1$，则我们偏好模型 1，否则偏好模型 0（见表 3.1）。

我们在 3.8.1.1 节中给出了计算二项检验贝叶斯因子的示例。更复杂检验的贝叶斯因子计算示例，请参见 [Etz+18; Ly+20] 等。

#### 3.10.2.2 不当先验会导致贝叶斯因子出现问题

在使用不当先验（即不积分为 1 的先验）进行贝叶斯模型选择时可能会出现问题，尽管此类先验对于其他目的（如参数推断）可能是可接受的。例如，考虑检验假设 $M_0 : \theta \in \Theta_0$ 与 $M_1 : \theta \in \Theta_1$。$M_0$ 的后验概率由以下给出

$$p(M_0|\mathcal{D}) = \frac{p(M_0)L_0}{p(M_0)L_0 + p(M_1)L_1}$$ (3.326)

其中 $L_i = p(\mathcal{D}|M_i) = \int_{\Theta_i} p(\mathcal{D}|\theta)p(\theta|M_i)d\theta$ 是模型 $i$ 的边缘似然。

为简化起见，假设 $p(M_0) = p(M_1) = 0.5$，并且我们对模型参数使用均匀但不当的先验，$p(\theta|M_0) \propto c_0$ 和 $p(\theta|M_1) \propto c_1$。定义 $\ell_i = \int_{\Theta_i} p(\mathcal{D}|\theta)d\theta$，因此 $L_i = c_i\ell_i$。则

$$p(M_0|\mathcal{D}) = \frac{c_0\ell_0}{c_0\ell_0 + c_1\ell_1} = \frac{\ell_0}{\ell_0 + (c_1/c_0)\ell_1}$$ (3.327)

因此后验（进而贝叶斯因子）取决于任意常数 $c_0$ 和 $c_1$。这被称为 **边缘化悖论**。因此，我们应避免使用不当先验
