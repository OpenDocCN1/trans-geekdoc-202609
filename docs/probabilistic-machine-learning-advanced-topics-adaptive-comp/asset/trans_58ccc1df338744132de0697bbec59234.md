

## 24.5.1 最小化 KL 散度的差分/导数

从数据学习概率模型的总体策略是最小化数据与模型分布之间的 KL 散度。然而，由于 EBM 的归一化常数通常难以处理，当模型为 EBM 时，直接评估 KL 散度很困难（参见第 24.2.1 节的讨论）。一种经常绕过这一困难的通用方法是考虑 KL 散度的差分/导数。事实证明，在对两个密切相关的 KL 散度求差或计算导数后，EBM 未知的配分函数通常会被抵消。

该策略的典型示例包括最小速度学习 [Mov08; Wan+20d]、最小概率流 [SBDB11] 和最小 KL 收缩 [Lyu11]，仅举几例。在最小速度学习和最小概率流中，设计了一个马尔可夫链，使其从数据分布 p_D(x) 开始并收敛到 EBM 分布 p_θ(x) = e^{-E_θ(x)} / Z_θ。具体来说，该马尔可夫链满足 p_0(x) ≡ p_D(x) 和 p_∞(x) ≡ p_θ(x)，其中我们用 p_t(x) 表示时间 t >= 0 时的状态分布。

除非 p_D(x) ≡ p_θ(x)，否则该马尔可夫链将朝着 p_θ(x) 演化。因此，我们可以通过最小化该演化“速度”的模长来将 EBM 分布 p_θ(x) 拟合到 p_D(x)，其定义为

```
\frac{d}{dt} D_{KL}(p_t(\mathbf{x}) \| p_\theta(\mathbf{x})) \Big|_{t=0} \quad \text{or} \quad \frac{d}{dt} D_{KL}(p_D(\mathbf{x}) \| p_t(\mathbf{x})) \Big|_{t=0}
```

分别在最小速度学习和最小概率流中。这些目标通常不需要计算归一化常数 Z_θ。

在最小 KL 收缩 [Lyu11] 中，选择一个分布变换 Φ，使得

```
D_{KL}(p(\mathbf{x}) \| q(\mathbf{x})) \ge D_{KL}(\Phi\{p(\mathbf{x})\} \| \Phi\{q(\mathbf{x})\})
```

当且仅当 p(x) = q(x) 时取等号。我们可以利用这个 Φ 来训练 EBM，通过最小化

```
D_{KL}(p_D(\mathbf{x}) \| p_\theta(\mathbf{x})) - D_{KL}(\Phi\{p_D(\mathbf{x})\} \| \Phi\{p_\theta(\mathbf{x})\})
```

当 Φ 为线性时，该目标不需要计算配分函数 Z_θ。

最小速度学习、最小概率流和最小 KL 收缩都可以被视为对分数匹配和噪声对比估计的推广 [Mov08; SBDB11; Lyu11]。

## 24.5.2 最小化 Stein 差异

我们可以通过最小化 Stein 差异来训练 EBM，其定义为

```
D_{Stein}(p_D(\mathbf{x}) \| p_\theta(\mathbf{x})) := \sup_{\mathbf{f} \in \mathcal{F}} \mathbb{E}_{p_D(\mathbf{x})} [\nabla_\mathbf{x} \log p_\theta(\mathbf{x})^\mathsf{T} \mathbf{f}(\mathbf{x}) + \text{trace}(\nabla_\mathbf{x} \mathbf{f}(\mathbf{x}))]
```

其中 F 是向量值函数族，∇_x f(x) 表示 f(x) 的雅可比矩阵。在某些正则性条件下 [GM15; LLJ16]，我们有 D_S(p_D(x) || p_θ(x)) >= 0，当且仅当 p_D(x) ≡ p_θ(x) 时取等号。类似于分数匹配（公式 (24.30)），目标公式 (24.62) 仅涉及 p_θ(x) 的分数函数，且不需要计算 EBM 的配分函数。不过，公式 (24.62) 中的迹项可能需要昂贵的计算，且不太适合高维数据。

有两种常见方法可以绕过这一困难。Gorham 和 Mackey [GM15] 以及 Liu、Lee 和 Jordan [LLJ16] 发现，当 F 是具有固定核的再生核希尔伯特空间（RKHS）中的单位球时，Stein 差异变为核化 Stein 差异，其中迹项为常数且不影响优化。否则，trace(∇_x f(x)) 可以使用 Skilling-Hutchinson 迹估计器 [Ski89; Hut89; Gra+20c] 进行近似。

## 24.5.3 对抗训练

回顾第 24.2.1 节，使用最大似然估计（MLE）训练 EBM 时，每次训练迭代都需要从 EBM 中采样。然而，使用多个 MCMC 步骤进行采样代价高昂，并且需要对马尔可夫链进行仔细调谐。避免这一困难的一种方法是使用无需采样的非 MLE 方法，例如分数匹配和噪声对比估计。在这里，我们介绍另一类通过对抗训练学习辅助模型从而绕过昂贵 MCMC 采样的方法，这允许快速采样。

利用 EBM 的定义，我们可以通过引入由 φ 参数化的变分分布 q_φ(x) 来重写最大似然目标：

```
\(\mathbb{E}_{p_D(\mathbf{x})}[\log p_\theta(\mathbf{x})] = \mathbb{E}_{p_D(\mathbf{x})}[-\mathcal{E}_\theta(\mathbf{x})] - \log Z_\theta\)
\(= \mathbb{E}_{p_D(\mathbf{x})}[-\mathcal{E}_\theta(\mathbf{x})] - \log \int e^{-\mathcal{E}_\theta(\mathbf{x})} \mathrm{d}\mathbf{x}\)
\(= \mathbb{E}_{p_D(\mathbf{x})}[-\mathcal{E}_\theta(\mathbf{x})] - \log \int q_\phi(\mathbf{x}) \frac{e^{-\mathcal{E}_\theta(\mathbf{x})}}{q_\phi(\mathbf{x})} \mathrm{d}\mathbf{x}\)
\(\overset{(i)}{\le} \mathbb{E}_{p_D(\mathbf{x})}[-\mathcal{E}_\theta(\mathbf{x})] - \int q_\phi(\mathbf{x}) \log \frac{e^{-\mathcal{E}_\theta(\mathbf{x})}}{q_\phi(\mathbf{x})} \mathrm{d}\mathbf{x}\)
\(= \mathbb{E}_{p_D(\mathbf{x})}[-\mathcal{E}_\theta(\mathbf{x})] - \mathbb{E}_{q_\phi(\mathbf{x})}[-\mathcal{E}_\theta(\mathbf{x})] - H(q_\phi(\mathbf{x})),\) (24.63)
```

其中 H(q_φ(x)) 表示 q_φ(x) 的熵。步骤 (i) 是由于 Jensen 不等式。公式 (24.63) 提供了对期望对数似然的上界。对于 EBM 训练，我们可以先关于 q_φ(x) 最小化上界公式 (24.63)，使其更接近似然目标，然后关于 E_θ(x) 最大化公式 (24.63) 作为最大化似然的代理。

这等同于使用以下极小极大目标

```
\(\max_\theta \min_\phi \mathbb{E}_{q_\phi(\mathbf{x})}[\mathcal{E}_\theta(\mathbf{x})] - \mathbb{E}_{p_D(\mathbf{x})}[\mathcal{E}_\theta(\mathbf{x})] - H(q_\phi(\mathbf{x})).\) (24.64)
```

优化上述目标类似于训练 GANs（第 26 章），可以通过对抗训练实现。变分分布 q_φ(x) 应该同时允许快速采样和高效的熵评估，以使公式 (24.64) 可处理。这限制了 q_φ(x) 的模型族，并且通常将我们的选择限制在可逆概率模型，例如逆自回归流（第 23.2.4.3 节）。有关设计 q_φ(x) 并使用公式 (24.64) 训练 EBM 的示例，请参见 Dai 等人 [Dai+19b]。

Kim 和 Bengio [KB16] 以及 Zhai 等人 [Zha+16] 提出使用神经采样器（如 GAN 的生成器）来表示 q_φ(x)。神经采样器是一个确定性映射 g_φ，它将随机高斯噪声 z ~ N(0, I) 直接映射到样本 x = g_φ(z)。当使用神经采样器作为 q_φ(x) 时，通过确定性映射绘制样本很高效，但 H(q_φ(x)) 难以处理，因为 q_φ(x) 的密度未知。Kim 和 Bengio [KB16] 以及 Zhai 等人 [Zha+16] 提出了几种启发式方法来近似这个熵函数。Kumar 等人 [Kum+19c] 提出通过其与互信息的连接来估计熵：H(q_φ(z)) = I(g_φ(z), z)，可以使用变分下界 [NWJ10b; NCT16b] 从样本中估计。Dai 等人 [Dai+19a] 注意到，当定义 p_θ(x) = p_0(x)e^{-ε_θ(x)/Z_θ} 时，其中 p_0(x) 是固定基分布，公式 (24.64) 中的熵项 -H(q_φ(x)) 可以替换为 D_KL(q_φ(x) || p_0(x))，这也可以使用 q_φ(x) 和 p_0(x) 的样本通过变分下界来近似，而不需要 q_φ(x) 的密度。

Grathwohl 等人 [Gra+20a] 将 q_φ(x) 表示为带噪声的神经采样器，样本通过 g_φ(z) + σε 获得，假设 z, ε ~ N(0, I)。使用带噪声的神经采样器时，∇_φ H(q_φ(x)) 变得特别容易估计，这允许对公式 (24.63) 中的极小极大目标进行基于梯度的优化。Xie 等人 [Xie+18] 提出了一种相关方法，作者使用从 MCMC 获得的样本训练带噪声的神经采样器，并用神经采样器生成的样本初始化新的 MCMC 链。这种合作采样方案提高了 MCMC 的收敛性，但样本生成可能仍然需要多个 MCMC 步骤。它不优化公式 (24.63) 中的目标。

在同时使用对抗训练和 MCMC 采样时，Yu 等人 [Yu+20] 注意到 EBM 可以使用任意 f-差异进行训练，包括 KL、反向 KL、总变差、Hellinger 等。Yu 等人 [Yu+20] 提出的方法允许我们探索不同统计差异的权衡和归纳偏差，以实现更灵活的 EBM 训练。
