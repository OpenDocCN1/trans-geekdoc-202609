### 10.3.6.6 使用 VBEM 的模型选择

第 10.3.6.4 节讨论了一种在模型拟合过程中自动选择 K 的方法，即通过“剔除”不需要的簇。另一种方法是拟合多个模型，然后使用对数边缘似然的变分下界 \mathcal{L}(K) \le \log p(D|K) 来近似 p(K|D)。特别是，如果我们有均匀先验，则得到后验

```
p(K|D) = \frac{p(D|K)}{\sum_{K^\prime} p(D|K')} \approx \frac{e^{\mathcal{L}(K)}}{\sum_{K^\prime} e^{\mathcal{L}(K')}}
```

[BG06] 表明，边缘似然的 VB 近似比 BIC [BG06] 更准确。然而，下界需要做一些修改，以考虑参数不可识别性的问题。特别是，尽管 VB 会近似参数后验所占据的体积，但它只会在局部模态的一个附近这样做。有 K 个分量时，存在 K! 个等效模态，它们仅通过标签置换而不同。因此，对对数边缘似然更准确的近似是使用 \log p(D|K) \approx \mathcal{L}(K) + \log(K!)。

### 10.3.7 变分消息传递 (VMP)

在本节中，我们描述了针对通用模型的 CAVI 算法，其中每个完全条件分布 p(zj|z−j, x) 都属于指数族，即，

```
p(zj|z−j, x) = h(zj) exp[\eta_j(z−j, x)^\mathsf{T} \mathcal{T}(zj) − A_j(\eta_j(z−j, x))]
```

其中 T(zj) 是充分统计量向量，\eta_j 是自然参数，A_j 是对数配分函数，h(zj) 是基分布。如果先验 p(zj) 与似然 p(z−j, x|zj) 共轭，则此假设成立。

如果公式 (10.159) 成立，则节点 j 的均匀场更新变为

```
q_j(z_j) \propto \exp [\mathbb{E} [\log p(z_j|z_{-j}, x)]]
= \exp \left[ \log h(z_j) + \mathbb{E} [\eta_j(z_{-j}, x)]^\mathsf{T} \mathcal{T}(z_j) - \mathbb{E} \left[ A_j(\eta_j(z_{-j}, x)) \right] \right]
\propto h(z_j) \exp \left[ \mathbb{E} [\eta_j(z_{-j}, x)]^\mathsf{T} \mathcal{T}(z_j) \right]
```

因此，我们使用其他节点的期望值来更新局部自然参数。这些将成为新的变分参数：

```
\psi_j = \mathbb{E} \left[ \eta_j(z_{-j}, x) \right]
```

我们可以将上述方法推广到适用于任何每个完全条件分布都共轭的模型。所得算法称为变分消息传递或 VMP [WB05]，适用于任何有向图形模型。VMP 与信念传播（第 9.3 节）类似：在每次迭代中，每个节点收集来自其父节点的所有消息，以及来自其子节点的所有消息（这可能要求子节点从其共父节点获取消息），并将它们组合起来计算节点充分统计量的期望值。发送的消息是节点的期望充分统计量，而不是仅仅是离散或高斯分布（如 BP 中那样）。几个软件库已实现此框架（参见例如，[Win; Min+18; Lut16; Wan17]）。

VMP 可以扩展到每个完全条件分布都是条件共轭的情况，使用辅助部分 10.3.1 中的 CVI 框架。另请参见 [ABV21]，其中他们在消息传递框架内对不可处理的因子使用局部拉普拉斯近似。

### 10.3.8 自动共轭

VMP 方法要求用户手动指定图形模型；然后对每个节点使用查找表计算相应的节点更新方程，针对每种可能的节点类型组合。可以使用一种称为 autoconj [HJT18] 的技术，自动推导任何条件共轭有向图形模型的这些更新方程。这类似于使用自动微分（autodiff）来为任何可微函数推导梯度。（注意，autoconj 在内部使用 autodiff。）所得的完全条件分布可用于 CAVI，也可用于吉布斯采样（第 12.3 节）。

## 10.4 更准确的变分后验

一般来说，如果我们使用更灵活的后验族，可以提高 ELBO 下界的紧度，从而降低后验近似的 KL 散度（尽管在更灵活的族内优化可能更慢，并且如果样本量较小可能会产生统计误差 [Bha+21]）。在本节中，我们给出了几个更准确的变分后验示例，超越了完全分解的均匀场近似或简单的单模态高斯近似。

### 10.4.1 结构化均匀场

均匀场假设非常强，有时会导致效果不佳。幸运的是，有时我们可以利用问题中的 **可处理子结构**，从而能够以分析方式有效处理后验中变量之间的某些依赖关系，而不是假设它们都相互独立。这被称为 **结构化均匀场** 方法 [SJ95]。

一个常见的例子是将变分推断（VI）应用于时间序列模型（如 HMM）时，其中每个序列内的隐变量通常随时间高度相关。我们不再假设完全分解的后验，而是可以将每个序列 **z**<sub>_n,_1:_T_</sub> 视为一个块，并仅假设块与参数之间独立：$q(\mathbf{z}_{1:N,1:T},\boldsymbol{\theta}) = q(\boldsymbol{\theta}) \prod_{n=1}^N q(\mathbf{z}_{n,1:T})$，其中 $q(\mathbf{z}_{n,1:T}) = \prod_t q(\mathbf{z}_{n,t}|\mathbf{z}_{n,t-1})$。我们可以使用前向-后向算法计算联合分布 $q(\mathbf{z}_{n,1:T})$，同时考虑时间步之间的依赖关系。详情请参见 [JW14; Fot+14]。类似的方法已应用于分解 HMM 模型，如辅助部分 10.3.2 中所述。

[AHG20] 讨论了一种自动方法，用于推导由概率编程语言指定的概率模型的结构化变分近似。

### 10.4.2 分层（辅助变量）后验

假设 $q_\boldsymbol{\phi}(\mathbf{z}|\mathbf{x}) = \prod_k q_\boldsymbol{\phi}(z_k|\mathbf{x})$ 是一个分解分布，例如对角高斯分布。这无法捕捉隐变量（**z** 的各分量）之间的依赖关系。我们当然可以使用完整的协方差矩阵，但这可能代价过高。

另一种方法是使用分层模型，在其中添加 **辅助隐变量** $\mathbf{a}$，以提高变分后验的灵活性。具体来说，我们仍然可以假设 $q_\phi(\mathbf{z}|\mathbf{x}, \mathbf{a})$ 是条件分解的，但在对 $\mathbf{a}$ 边缘化后，我们会在 **z** 的元素之间诱导依赖关系，即，

$q_\phi(\mathbf{z}|\mathbf{x}) = \int q_\phi(\mathbf{z}|\mathbf{x}, \mathbf{a}) q_\phi(\mathbf{a}|\mathbf{x}) d\mathbf{a} \neq \prod_k q_\phi(z_k|\mathbf{x})$ (10.164)

这被称为 **分层变分模型** [Ran16] 或 **辅助变量深度生成模型** [Maa+16]。

在 [TRB16] 中，他们将 $q_\phi(\mathbf{z}|\mathbf{x}, \mathbf{a})$ 建模为高斯过程，这是一种灵活的非参数分布（见第 18 章），其中 $\mathbf{a}$ 为诱导点。这种组合称为 **变分 GP**。

### 10.4.3 标准化流后验

标准化流是一类概率模型，其工作原理是将简单的源分布（例如对角高斯分布）通过一系列非线性但可逆的映射 $f$ 传递，以创建更复杂的分布。这可以用于获得比标准高斯变分推断更准确的后验近似，如第 23.1.2.2 节所述。

### 10.4.4 隐式后验

在第 26 章中，我们讨论了隐式概率分布，即我们可以从中采样但无法逐点评估其密度的模型。例如，考虑将高斯噪声项 $\mathbf{z}_0 \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$ 通过非线性、*不可逆* 映射 $f$ 传递以创建 $\mathbf{z} = f(\mathbf{z}_0)$；从 $q(\mathbf{z})$ 采样很容易，但计算密度 $q(\mathbf{z})$ 是不可处理的（与流不同）。这使得很难计算对数密度比 $\log p_\theta(\mathbf{z})/q_\phi(\mathbf{z}|\mathbf{x})$，而这是计算 ELBO 所需的。然而，我们可以使用与生成对抗网络（GAN，第 26 章）中使用的相同方法，即训练一个分类器，通过评估 $T(\mathbf{x}, \mathbf{z}) = \log q_\psi(\mathbf{z}|\mathbf{x}) - \log p_\theta(\mathbf{z})$ 来区分先验样本和变分后验样本。详情请参见例如 [TR19]。

### 10.4.5 将变分推断与 MCMC 推断相结合

有多种方法可以将变分推断与 MCMC 相结合，以获得改进的近似后验。在 [SKW15] 中，他们提出了 **哈密顿变分推断**，其中他们训练一个推断网络来初始化 HMC 采样器（第 12.5 节）。HMC 所需的对数后验（关于隐变量）的梯度由

$\nabla_{\mathbf{z}} \log p_\theta(\mathbf{z}|\mathbf{x}) = \nabla_{\mathbf{z}} \log p_\theta(\mathbf{x}, \mathbf{z}) - \nabla_{\mathbf{z}} \log p_\theta(\mathbf{x}) = \nabla_{\mathbf{z}} \log p_\theta(\mathbf{x}, \mathbf{z})$ (10.165)

给出。这很容易计算。他们使用最终样本来近似后验 $q_\phi(\mathbf{z}|\mathbf{x})$。为了计算该分布的熵，他们还训练一个辅助逆推断网络来反转 HMC 马尔可夫链。
