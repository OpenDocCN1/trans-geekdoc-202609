# 10.1.3 Parameter estimation using variational EM

So far, we have assumed the model parameters \(\theta\) are known. However, we can try to estimate them by maximising the log marginal likelihood of the dataset, \(\mathcal{D} = \{x_n : n = 1 : N\}\),

```
\(\log p(\mathcal{D}|\theta) = \sum_{n=1}^N \log p(x_n|\theta)\) (10.18)
```

In general, this is intractable to compute, but we discuss approximations below.

# 10.1.3.1 MLE for latent variable models

Suppose we have a latent variable model of the form

```
\(p(\mathcal{D}, z_{1:N}|\theta) = \prod_{n=1}^N p(z_n|\theta)p(x_n|z_n, \theta)\) (10.19)
```

as shown in Figure 10.3a. Furthermore, suppose we want to compute the MLE for \(\theta\) given the dataset \(\mathcal{D} = \{x_n : n = 1 : N\}\). Since the local latent variables \(z_n\) are hidden, we must marginalize them out to get the local (per example) log marginal likelihood:

```
\(\log p(x_n|\theta) = \log \left[ \int p(x_n|z_n, \theta)p(z_n|\theta)dz_n \right]\) (10.20)
```
