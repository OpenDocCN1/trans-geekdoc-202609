# 23.2.4.1 Affine autoregressive flows

For a concrete example, we can take $h$ to be an affine scalar bijection (Section 23.2.2.1) parameterized by a log scale $\alpha$ and a bias $\mu$. Such autoregressive flows are known as **affine autoregressive flows**. The parameters of the $i$'th component, $\alpha_i$ and $\mu_i$, are functions of $\boldsymbol{x}_{1:i-1}$, so $\boldsymbol{f}$ takes the following form:

$x_i = u_i \exp(\alpha_i(\boldsymbol{x}_{1:i-1})) + \mu_i(\boldsymbol{x}_{1:i-1})$.
(23.22)

This is illustrated in Figure 23.4(a). We can invert this by

$u_i = (x_i - \mu_i(\boldsymbol{x}_{1:i-1})) \exp(-\alpha_i(\boldsymbol{x}_{1:i-1}))$.
(23.23)

This is illustrated in Figure 23.4(b). Finally, we can calculate the log absolute Jacobian determinant by

\(\log |\det \mathbf{J}(\boldsymbol{f})| = \log \left| \prod_{i=1}^D \exp(\alpha_i(\boldsymbol{x}_{1:i-1})) \right| = \sum_{i=1}^D \alpha_i(\boldsymbol{x}_{1:i-1}).\)
(23.24)

Since $x_1$ is an affine transformation of $u_1 \sim \mathcal{N}(0, 1)$, it is Gaussian with mean $\mu_1$ and standard deviation $\sigma_1 = \exp \alpha_1$.
