这些担忧凸显了一个重要的开放领域：我们需要改进赋予解释“半透明性”属性的方法，即能够传达关于模型的“可说”与“不可说”内容的解释。半透明性很重要，因为被误解的解释如果正好迎合了用户的观点，就会为信任创造虚假基础。

### 固有可解释模型与性能之间的权衡往往并不存在；当存在权衡时，部分视图可以提供帮助。

虽然有人声称使用固有可解释模型与性能（定义为模型在某些测试数据上的性能）之间存在固有的权衡，但实际上这种权衡并不总是存在，原因有几点 [Rud19]。首先，在许多情况下，数据可以由相当简单的模型（例如，由于高噪声）或可分解为可解释部分的模型出人意料地拟合良好。通常可以找到架构、正则化器和优化器的组合，从而产生性能与黑盒方法相当，有时甚至更好的固有可解释模型 [Wan+17a; LCG12; Car+15; Let+15b; UR16; FHDV20; KRS14]。事实上，可解释性和性能可以产生协同效应：用于编码对更简单模型偏好的方法（例如，用于稀疏性属性的 L1 正则化器）最初是为提高性能和避免过拟合而开发的，而且可解释模型通常更加稳健 [RDV18]。

第二，狭隘地关注使用固有可解释模型与预定义性能指标之间的权衡（通常在验证集上测量），忽略了一个更广泛的问题：即该预定义性能指标可能无法讲述关于模型质量的全部故事。例如，使用固有可解释模型可能使人意识到预测是基于混杂因素而非因果关系——或者部署时可能失败的其他方式。这样一来，即使黑盒在验证中看起来性能数值更好，在实际中使用固有可解释模型也可能获得更好的性能。固有可解释模型还可以通过允许人类用户在适当时介入并覆盖系统，从而实现更好的人机协作。

### 人为因素至关重要。

所有机器学习系统最终都会连接到更广泛的社会技术环境。然而，在许多情况下，模型构建和优化的许多方面可以在纯计算环境中进行：有检查适当模型容量的技术，有调整梯度下降或凸优化的技术。相比之下，可解释机器学习必须考虑人为因素 *从一开始*：如果优化解释以具有各种属性仍然无法改善用户在最终任务上的表现，那么这样做就没有意义。

人机团队中的过度信任问题。最近的研究发现，即使是数据科学家也会以非预期的方式过度信任解释 [Kau+20]；他们对工具的兴奋导致他们接受表面信息而非深入挖掘。[LM20] 报告了类似的发现，指出不准确但引人注目的呈现可能产生一种理解的错觉。

可以通过采取明确措施来对抗过度依赖，迫使用户从分析和怀疑的角度参与解释中的信息。例如，可以先要求用户提交其决定，然后才显示建议和伴随解释，以激发他们对其选择与建议为何可能不一致的兴趣（并提示他们是否想更改选择）。另一种选择是在提交决定前询问用户关于解释的一些基本问题，以迫使他们仔细查看解释。还有另一种选择是只提供相关信息（解释）而不提供建议，迫使用户自行综合额外信息。然而，在所有这些情况下，存在着微妙的平衡：用户通常愿意投入额外的认知努力，如果他们看到这能取得更好的结果，但如果他们觉得努力太大，他们可能会完全开始忽略这些信息。

### 潜在的滥用风险。

过度依赖的恶意版本是利用解释来操纵用户，而不是促进用户完成最终任务。此外，用户可能会报告说他们喜欢简单、认知负担小的解释等，即使这些解释并不能帮助他们完成最终任务。作为可解释机器学习方法的创建者，必须保持警惕，确保解释能帮助用户实现他们的目标（理想情况下以他们也喜欢的方式）。

### 缺乏对机器学习的理解所导致的误解。

即使正确参与，不同情境下的用户对机器学习的了解程度也会有所不同。例如，并非所有人都能理解诸如加性因素或 Shapley 值 [Sha16] 等概念。用户也可能将模型实际拥有的理解能力归结为更多。例如，如果他们看到喙周围有一组像素被高亮显示，或者关于疾病的一组主题模型术语，他们可能会错误地相信机器学习模型具有一种与他们自己的概念相匹配的概念观念，而事实可能截然不同。

### 相关：图像解释中的感知问题。

我们的视觉处理系统的本质，在解释和误解解释时增添了另一层微妙之处。在图 33.6 中，两个解释（以鸟图像中重要像素的形式）似乎传达着类似的信息；对大多数人来说，两个解释都似乎表明鸟的腹部和脸颊是该预测的重要部分。然而，其中一个是由训练有素的网络生成的（左），但另一个来自返回随机预测的网络（右）。虽然这两个显著性图对机器来说并不完全相同，但它们看起来相似，因为人类并非将图像解析为像素值，而是将其视为一个整体，在两张图片中都看到了一只鸟。

基于像素的解释的另一个常见问题是，解释创建者通常将原始图像与重要性“掩码”（黑色和透明的显著性掩码，其中黑色像素表示无重要性，透明像素表示最大重要性）相乘，引入了黑色对象永远不会显得重要的任意工件 [Smi+17]。此外，这个二进制掩码是通过按一定百分位数裁剪重要像素生成的（例如，仅取第 99 个百分位数），这也可能引入另一个工件 [Sun+19c]。为了便于理解而进行的可视化所引入的工件与忠实地表示解释之间的平衡，仍然是一个挑战。

总而言之，所有这些关于人为因素的观点都强调了我们从一开始就所说的话：我们无法将可解释机器学习的研究与实践与其预定的社会技术环境分离开来。
