

其中 $\mu_P$ 称为分布 $P$ 的**核平均嵌入** [Mua+17]。因此

```
\text{MMD}(P, Q; \mathcal{F}) = \sup_{\|f\| \le 1} \langle f, \mu_P - \mu_Q \rangle_{\mathcal{F}} = \|\mu_P - \mu_Q\|_{\mathcal{F}}
```

由于最大化内积的单位向量 $\boldsymbol{f}$ 与特征均值之差平行，因此。要获得一些直觉，假设 $\phi(x) = [x, x^2]$。在这种情况下，MMD 计算两个分布的前两个矩的差值。这可能不足以区分所有可能的分布。然而，使用高斯核相当于比较两个无限大的特征向量，如第 18.2.6 节所示，因此我们实际上是在比较两个分布的所有矩。确实，可以证明当且仅当 $P=Q$ 时 MMD = 0，前提是我们使用非退化核。

### 2.7.3.2 使用核技巧计算 MMD

在本节中，我们描述了在给定两组样本 $\mathcal{X} = \{\boldsymbol{x}_n\}_{n=1}^N$ 和 $\mathcal{X}' = \{\boldsymbol{x}'_m\}_{m=1}^M$（其中 $\boldsymbol{x}_n \sim P$ 且 $\boldsymbol{x}'_m \sim Q$）的情况下，如何在实践中计算公式 (2.301)。令 $\boldsymbol{\mu}_P = \frac{1}{N} \sum_{n=1}^N \phi(\boldsymbol{x}_n)$ 和 $\boldsymbol{\mu}_Q = \frac{1}{M} \sum_{m=1}^M \phi(\boldsymbol{x}'_m)$ 为两个分布核平均嵌入的经验估计。那么平方 MMD 由以下给出

```
\text{MMD}^2(\mathcal{X}, \mathcal{X}') \triangleq \| \frac{1}{N} \sum_{n=1}^N \phi(\boldsymbol{x}_n) - \frac{1}{M} \sum_{m=1}^M \phi(\boldsymbol{x}'_m) \|^2
```

```
= \frac{1}{N^2} \sum_{n=1}^N \sum_{n'=1}^N \phi(\boldsymbol{x}_n)^\top \phi(\boldsymbol{x}_{n'}) - \frac{2}{NM} \sum_{n=1}^N \sum_{m=1}^M \phi(\boldsymbol{x}_n)^\top \phi(\boldsymbol{x}'_m) + \frac{1}{M^2} \sum_{m=1}^M \sum_{m'=1}^M \phi(\boldsymbol{x}'_m)^\top \phi(\boldsymbol{x}'_m)
```

由于公式 (2.303) 仅涉及特征向量的内积，我们可以使用核技巧（第 18.2.5 节）将上述内容改写如下：

```
\text{MMD}^2(\mathcal{X}, \mathcal{X}') = \frac{1}{N^2} \sum_{n=1}^N \sum_{n'=1}^N \mathcal{K}(\boldsymbol{x}_n, \boldsymbol{x}_{n'}) - \frac{2}{NM} \sum_{n=1}^N \sum_{m=1}^M \mathcal{K}(\boldsymbol{x}_n, \boldsymbol{x}'_m) + \frac{1}{M^2} \sum_{m=1}^M \sum_{m'=1}^M \mathcal{K}(\boldsymbol{x}'_m, \boldsymbol{x}'_{m'})
```

### 2.7.3.3 线性时间计算

计算 MMD 需要 $O(N^2)$ 时间，其中 $N$ 是每个分布的样本数量。在 [Chw+15] 中，他们提出了一种称为**未归一化平均嵌入**或 **UME** 的不同检验统计量，该统计量可在 $O(N)$ 时间内计算。关键思想是注意到，计算

```
\text{witness}^2(\boldsymbol{v}) = (\boldsymbol{\mu}_Q(\boldsymbol{v}) - \boldsymbol{\mu}_P(\boldsymbol{v}))^2
```

在一组测试位置 $v_1, \dots, v_J$ 上进行评估足以检测 $P$ 和 $Q$ 之间的差异。因此，我们定义（平方）UME 如下：

UME$^2(P, Q) = \frac{1}{J} \sum_{j=1}^J [\mu_P(v_j) - \mu_Q(v_j)]^2$ (2.306)

其中 $\mu_P(v) = \mathbb{E}_{p(x)}[\mathcal{K}(x, v)]$ 可在 $O(N)$ 时间内经验估计，$\mu_Q(v)$ 亦然。UME 的一个归一化版本称为 NME，在 [Jit+16] 中介绍。通过最大化相对于位置 $v_j$ 的 NME，我们可以最大化检验的统计效力，并找到 $P$ 和 $Q$ 差异最大的位置。这为高维数据提供了一个可解释的两样本检验。

### 2.7.3.4 选择合适的核

MMD（及 UME）的有效性显然至关重要的是取决于核的合适选择。即使是区分 1d 样本，核的选择也可能非常重要。例如，考虑高斯核 $\mathcal{K}_\sigma(x, x') = \exp(-\frac{1}{2\sigma^2}\|x - x'\|^2)$。改变 $\sigma$ 对区分两个不同 1d 样本集的能力的影响见图 2.22。幸运的是，MMD 对核参数可微，因此我们可以选择最优的 $\sigma^2$ 以最大化检验的效力 [Sut+17]。（另请参见 [Fla+16] 中的贝叶斯方法，该方法最大化核平均嵌入 GP 表示的边缘似然。）

对于图像等高维数据，使用预训练的 CNN 模型来计算低维特征可能很有用。例如，我们可以定义 $\mathcal{K}(x, x') = \mathcal{K}_\sigma(h(x), h(x'))$，其中 $h$ 是 CNN 的某个隐藏层，例如 [Sze+15a] 的 "inception" 模型。由此得到的 MMD 指标称为**核 inception 距离** [Bin+18]。这与**弗雷切 inception 距离** [Heu+17a] 类似，但具有更好的统计特性，并且与人类感知判断的相关性更好 [Zho+19a]。

## 2.7.4 全变差距离

两个概率分布之间的全变差距离定义如下：

$D_{\text{TV}}(p, q) \triangleq \frac{1}{2} ||\mathbf{p} - \mathbf{q}||_1 = \frac{1}{2} \int |p(\mathbf{x}) - q(\mathbf{x})| d\mathbf{x}$

这等于一个 f-偏差，其中 $f(r) = |r-1|/2$，因为

$\frac{1}{2} \int q(\mathbf{x}) |\frac{p(\mathbf{x})}{q(\mathbf{x})} - 1| d\mathbf{x} = \frac{1}{2} \int q(\mathbf{x}) |\frac{p(\mathbf{x}) - q(\mathbf{x})}{q(\mathbf{x})}| d\mathbf{x} = \frac{1}{2} \int |p(\mathbf{x}) - q(\mathbf{x})| d\mathbf{x}$

还可以证明 TV 距离是积分概率度量。事实上，它是既是 IPM 又是 f-偏差的唯一偏差 [Sri+09]。有关直观总结，请参见图 2.23。

## 2.7.5 使用二进制分类器进行密度比估计

在本节中，我们讨论了一种比较两个分布的简单方法，结果发现它等价于 IPM 和 f-偏差。

考虑一个二进制分类问题，其中来自 $P$ 的点标签为 $y=1$，来自 $Q$ 的点标签为 $y=0$，即 $P(\mathbf{x}) = p(\mathbf{x}|y=1)$ 和 $Q(\mathbf{x}) = p(\mathbf{x}|y=0)$。令 $p(y=1) = \pi$ 为类先验。根据贝叶斯法则，密度比 $r(\mathbf{x}) = P(\mathbf{x})/Q(\mathbf{x})$ 由以下给出

$\frac{P(\mathbf{x})}{Q(\mathbf{x})} = \frac{p(\mathbf{x}|y=1)}{p(\mathbf{x}|y=0)} = \frac{p(y=1|\mathbf{x})p(\mathbf{x})}{p(y=1)} / \frac{p(y=0|\mathbf{x})p(\mathbf{x})}{p(y=0)}$

$= \frac{p(y=1|\mathbf{x})}{p(y=0|\mathbf{x})} \frac{1-\pi}{\pi}$

如果我们假设 $\pi=0.5$，则可以通过拟合二进制分类器或鉴别器 $h(\mathbf{x}) = p(y=1|\mathbf{x})$ 然后计算 $r = h/(1-h)$ 来估计比值 $r(\mathbf{x})$。这被称为**密度比估计**或 **DRE** 技巧。

我们可以通过最小化风险（期望损失）来优化分类器 $h$。例如，如果我们使用对数损失，则有

\( R(h) = \mathbb{E}_{p(x|y)p(y)} \left[ -y \log h(x) - (1-y) \log(1-h(x)) \right] \) (2.311)
\( = \pi \mathbb{E}_{P(x)} \left[ -\log h(x) \right] + (1 - \pi) \mathbb{E}_{Q(x)} \left[ -\log(1-h(x)) \right] \) (2.312)

我们也可以使用其他损失函数 \(\ell(y, h(x))$（参见第 26.2.2 节）。

令 \( R_h^\ell = \inf_{h \in \mathcal{F}} R(h) \) 为损失函数 \(\ell$ 可实现的最小风险，其中我们对某个函数类 \(\mathcal{F}$ 进行最小化。\(^\text{11}$ 在 [NWJ09] 中，他们表明对于每个 \(f\)-偏差，存在一个损失函数 \(\ell$ 使得 $-D_f(P, Q) = R_h^\ell$。例如（使用 \(\tilde{y} \in \{-1, 1\}$ 的记法代替 \(y \in \{0, 1\}\)），全变差距离对应铰链损失，\(\ell(\tilde{y}, h) = \max(0, 1 - \tilde{y}h)$；Hellinger 距离对应指数损失，\(\ell(\tilde{y}, h) = \exp(-\tilde{y}h)$；\(\chi^2$ 偏差对应逻辑损失，\(\ell(\tilde{y}, h) = \log(1 + \exp(-\tilde{y}h))$。

我们还可以在二进制分类器和 IPM 之间建立联系 [Sri+09]。特别是，令 \(\ell(\tilde{y}, h) = -2\tilde{y}h$，且 \(p(\tilde{y} = 1) = p(\tilde{y} = -1) = 0.5$。那么我们有

\( R_{h^*} = \inf_h \int \ell(\tilde{y}, h(x)) p(x|\tilde{y}) p(\tilde{y}) dx d\tilde{y} \) (2.313)
\( = \inf_h 0.5 \int \ell(1, h(x)) p(x|\tilde{y} = 1) dx + 0.5 \int \ell(-1, h(x)) p(x|\tilde{y} = -1) dx \) (2.314)
\( = \inf_h \int h(x) Q(x) dx - \int h(x) P(x) dx \) (2.315)
\( = \sup_h - \int h(x) Q(x) dx + \int h(x) P(x) dx \) (2.316)

这与公式 (2.295) 匹配。因此，分类器起着与证人函数相同的作用。

11. 如果 P 是固定分布，我们对 h 最小化上述目标，同时对模型 Q(x) 最大化它，那么我们就得到了一种称为生成对抗网络的技术，用于将隐式模型拟合到样本分布 P（详情见第 26 章）。但是，在本节中，我们假设 Q 是已知的。
