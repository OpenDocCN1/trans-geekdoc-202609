## 行动

## 34 在不确定性下的决策

### 34.1 统计决策理论

贝叶斯推断提供了在给定观测数据 \(\mathbf{X} = \mathbf{x}\) 的情况下，通过计算后验 \(p(H|\mathbf{x})\) 来更新我们对隐藏量 \(H\) 信念的最优方式。然而，归根结底，我们需要将信念转化为可以在现实世界中执行的行动。我们如何决定哪个行动最佳？决策理论正是为此而生。在本节中，我们将简要介绍。更多细节，请参见例如 [DeG70; Ber85b; KWW22]。

### 34.1.1 基础

在统计决策理论中，我们有一个代理或决策者，其希望在给定某些观测或数据 \(\mathbf{x}\) 时，从一组可能动作 \(a \in \mathcal{A}\) 中选择一个动作。我们假设数据来自代理外部的某个环境；我们用隐藏或未知变量 \(h \in \mathcal{H}\) 来刻画该环境的状态，称为自然状态。最后，我们假设已知一个损失函数 \(\ell(h, a)\)，它指定了当自然状态为 \(h\) 时采取动作 \(a\) 所产生的损失。目标是定义一个策略（也称为估计量或决策程序），它指定针对每个可能观测应采取哪个动作 \(a = \delta(\mathbf{x})\)，以最小化期望损失，也称为风险：

\[
\delta^*(\cdot) = \underset{\delta}{\text{argmin}} \ R(\delta) \tag{34.1}
\]

风险由以下给出

\[
R(\delta) = \mathbb{E}[\ell(h, \delta(\mathbf{X}))] \tag{34.2}
\]

关键问题是如何定义上述期望。我们可以使用频率学派或贝叶斯方法，如下文所述。

### 34.1.2 频率学派决策理论

在频率学派决策理论中，我们将自然状态 \(h\) 视为固定但未知的量，并将数据 \(\mathbf{X}\) 视为随机的。因此，我们对数据取期望，从而得到频率学派风险：

\[
r(\delta|h) = \mathbb{E}_{p(\mathbf{x}|h)}[\ell(h, \delta(\mathbf{x}))] = \int p(\mathbf{x}|h)\ell(h, \delta(\mathbf{x}))d\mathbf{x} \tag{34.3}
\]

其思想是，一个好的估计量在许多不同的数据集上都会具有低风险。

不幸的是，自然状态未知，因此上述量无法计算。对此有几种可能的解决方案。一种想法是在 $h$ 上放置一个先验分布，然后计算**贝叶斯风险**，也称为**积分风险**：

\[
\begin{aligned} R_B(\delta) \triangleq \mathbb{E}_{p(h)} [r(\delta|h)] = \int p(h)p(x|h)\ell(h, \delta(x)) \ dh \ dx \end{aligned}
\]

最小化贝叶斯风险的决策规则称为**贝叶斯估计量**。

当然，在频率学派统计的背景下，使用先验分布可能看起来不合适。因此，我们可以使用**最大风险**来代替。其定义如下：

\[
R_{max}(\delta) = \max_h r(\delta|h)
\]

最小化最大风险得出**极小极大估计量**：

\[
\delta^* = \min_\delta \max_h r_h(\delta)
\]

极小极大估计量具有一定的吸引力。然而，计算它们可能很困难。而且，它们非常悲观。事实上，可以证明，所有极小极大估计量都等价于在**最不利先验**下的贝叶斯估计量。在大多数统计情境中（博弈论情境除外），假设自然是敌对的并不是一个合理的假设。关于这一点的进一步讨论，请参见 [BS94, p449]。

### 34.1.3 贝叶斯决策理论

在**贝叶斯决策理论**中，我们将数据视为观测到的常数 \(\mathbf{x}\)，将自然状态视为未知随机变量。选择动作 \(a\) 的**后验期望损失**定义如下：

\[
\rho(a|\mathbf{x}) \triangleq \mathbb{E}_{p(h|\mathbf{x})} [\ell(h, a)] = \int \ell(h, a)p(h|\mathbf{x})dh
\]

我们可以使用以下公式定义估计量的后验期望损失，即**贝叶斯风险**：

\[
\rho(\delta|\mathbf{x}) = \rho(\delta(\mathbf{x})|\mathbf{x})
\]

**最优策略**指定了为最小化期望损失应采取什么动作。其给出如下：

\[
\delta^*(\mathbf{x}) = \underset{a \in \mathcal{A}}{\text{argmin}} \ \mathbb{E}_{p(h|\mathbf{x})} [\ell(h, a)]
\]

表述这一结果的一种替代但等价的方式如下。让我们定义一个**效用**函数 \(U(h, a)\)，表示在每种可能状态下每种可能动作的可取性。如果设置 \(U(h, a) = -\ell(h, a)\)，则最优策略如下：

\[
\delta^*(\mathbf{x}) = \underset{a \in \mathcal{A}}{\text{argmax}} \ \mathbb{E}_h [U(h, a)]
\]

这被称为**最大期望效用原理**。

### 34.1.4 贝叶斯方法的频率学派最优性

我们看到，贝叶斯方法（由方程 (34.9) 给出）为每个单独观测 $x$ 选择最佳动作，也将优化方程 (34.4) 中的贝叶斯风险，后者为所有可能观测选择最佳策略。这源自 Fubini 定理，该定理允许我们交换双重积分的积分顺序：

\[
R_B(\delta) = \mathbb{E}_{p(x)} [\rho(\delta|x)] = \mathbb{E}_{p(h|x)p(x)} [\ell(h, \delta(x))] \quad (34.11)
\]
\[
= \mathbb{E}_{p(h)} [r(\delta|h)] = \mathbb{E}_{p(h)p(x|h)} [\ell(h, \delta(x))] \quad (34.12)
\]

参见图 34.1 以作说明。上述结果告诉我们，贝叶斯方法具有最优的频率学派性质。

更一般地，可以证明任何**可容纳策略**$^1$ 都相对于某个（可能是不正规的）先验分布是贝叶斯策略，这一结果称为**瓦尔德定理** [Wal47]。（关于这一结果的更一般版本，请参见 [DR21]。）因此，我们可以说，通过将自己“限制”在贝叶斯方法中，我们并没有损失什么（尽管我们需要检查我们的建模假设是否充分，这是我们在第 3.9 节中讨论的主题）。关于这一点的进一步讨论，请参见 [BS94, p448]。

贝叶斯方法的另一个优势是它具有构造性，也就是说，它指定了给定特定数据集时如何创建最优策略（估计量）。相比之下，频率学派方法允许你使用任何你喜欢的估计量；它只是推导了该估计量在多个数据集上的性质，但不告诉你如何创建该估计量。

### 34.1.5 一次性决策问题示例

在下面的章节中，我们将给出机器学习应用中出现的一些**一次性**决策问题的常见示例（即，做出单个决策，而不是一系列决策）。

- 如果一个估计量没有被任何其他估计量严格主导，则称其为**可容纳**的。我们说 $\delta^1$ **主导** $\delta^2$，如果对所有 $\theta$ 都有 $R(\theta, \delta^1) \le R(\theta, \delta^2)$。如果对某些 $\theta^*$ 不等式成立为严格不等式，则该主导被称为严格主导。

#### 34.1.5.1 分类

假设自然状态对应于类别标签，因此 $\mathcal{H} = \mathcal{Y} = \{1, \dots, C\}$。此外，假设动作也对应于类别标签，因此 $\mathcal{A} = \mathcal{Y}$。在这种情况下，一种非常常用的损失函数是**零一损失** \(\ell_{01}(y^*, \hat{y})\)，定义如下：

| | $\hat{y} = 0$ | $\hat{y} = 1$ |
|---|---|---|
| $y^* = 0$ | 0 | 1 |
| $y^* = 1$ | 1 | 0 |

我们可以更简洁地写成如下：

\[
\ell_{01}(y^*, \hat{y}) = \mathbb{I}(y^* \neq \hat{y})
\]

在这种情况下，后验期望损失为：

\[
\rho(\hat{y}|\boldsymbol{x}) = p(\hat{y} \neq y^*|\boldsymbol{x}) = 1 - p(y^* = \hat{y}|\boldsymbol{x})
\]

因此，最小化期望损失的动作是选择最可能的标签：

\[
\delta(\boldsymbol{x}) = \underset{y \in \mathcal{Y}}{\text{argmax}} \, p(y|\boldsymbol{x})
\]

这对应于后验分布的**众数**，也称为**最大后验估计**或 **MAP 估计**。

我们可以将损失函数推广为为假阳性和假阴性关联不同的成本。我们还可以允许一个“拒绝动作”，即当决策者不够自信时放弃分类。这被称为**选择性预测**；详情请参见第 19.3.3 节。

#### 34.1.5.2 回归

现在假设隐藏的自然状态是一个标量 \(h \in \mathbb{R}\)，相应的动作也是一个标量 \(y \in \mathbb{R}\)。对于连续状态和动作，最常见的损失是 $\ell_2$ **损失**，也称为**平方误差**或**二次损失**，定义如下：

\[
\ell_2(h, y) = (h - y)^2
\]

在这种情况下，风险由以下给出：

\[
\rho(y|\boldsymbol{x}) = \mathbb{E} \left[ (h - y)^2 | \boldsymbol{x} \right] = \mathbb{E} \left[ h^2 | \boldsymbol{x} \right] - 2y \mathbb{E} [h | \boldsymbol{x}] + y^2
\]

最优动作必须满足风险在该点的导数为零的条件（如第 6 章所述）。因此，最优动作是选择后验均值：

\[
\frac{\partial}{\partial y} \rho(y|\boldsymbol{x}) = -2 \mathbb{E} [h | \boldsymbol{x}] + 2y = 0 \Rightarrow \delta(\boldsymbol{x}) = \mathbb{E} [h | \boldsymbol{x}] = \int h \, p(h|\boldsymbol{x}) dh
\]

这通常被称为**最小平均平方误差**估计或 **MMSE 估计**。
