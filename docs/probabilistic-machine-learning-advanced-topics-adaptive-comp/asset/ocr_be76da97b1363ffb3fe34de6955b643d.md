\mathbb{I}(x; z | y) = \mathbb{I}(x; z) - \mathbb{I}(y; z)
= \mathbb{H}(z) - \mathbb{H}(z|x) - [\mathbb{H}(z) - \mathbb{H}(z|y)]
= - \mathbb{H}(z|x) + \mathbb{H}(z|y)
= \int dz dx p(x, z) \log p(z|x) - \int dz dy p(z, y) \log p(z|y)
\le \int dz dx p(x, z) \log e(z|x) - \int dz dy p(z, y) \log b(z|y)
= \langle \log e(z|x) \rangle - \langle \log b(z|y) \rangle

Putting it altogether, we get the final CEB objective:

min \beta (\langle \log e(z|x) \rangle - \langle \log b(z|y) \rangle - \langle \log d(y|z) \rangle)

Note that it is generally easier to learn the conditional backwards encoder b(z|y) than the unconditional marginal m(z). Also, we know that the tightest upper bound occurs when I(x; z|y) = I(x; z) - I(y; z) = 0. The corresponding value of beta corresponds to an optimal representation. By contrast, it is not clear how to measure distance from optimality when using IB.
