

利用 model 来获取一步先验状态预测，\(\mathbf{z}_{t|t-1}^s = \mathbf{f}(\mathbf{z}_{t-1|t-1}^s, \mathbf{q}_t^s)\)，由此我们得到 \(\mathbf{Z}_{t|t-1} = \{\mathbf{z}_{t|t-1}^s\}\)，其大小为 \(N_z \times N_s\)。接下来我们绘制 \(N_s\) 个观测噪声变量 \(\mathbf{r}_t^s \sim \mathcal{N}(\mathbf{0}, \mathbf{R}_t)\)，并使用它们来计算一步先验观测预测，\(\mathbf{y}_{t|t-1}^s = \mathbf{h}(\mathbf{z}_{t|t-1}^s, \mathbf{r}_t^s)\) 和 \(\mathbf{Y}_{t|t-1} = \{\mathbf{y}_{t|t-1}^s\}\)，其大小为 \(N_y \times N_s\)。最后我们使用以下公式计算量测更新：

```
\(\mathbf{Z}_{t|t} = \mathbf{Z}_{t|t-1} + \tilde{\mathbf{K}}_t (\mathbf{y}_t \mathbf{1}^\mathsf{T} - \bar{\mathbf{Y}}_{t|t-1})\) (8.191)
```

这与公式 (8.29) 类似。

我们现在讨论如何计算 \(\bar{\mathbf{K}}_t\)，它是公式 (8.28) 中卡尔曼增益矩阵的类比。首先注意，我们可以将精确的卡尔曼增益矩阵（在线性高斯情况下）写为 \(\mathbf{K}_t = \unknown_{t|t-1} \mathbf{H}^\mathsf{T} \mathbf{S}_t^{-1} = \mathbf{C}_t \mathbf{S}_t^{-1}\)，其中 \(\mathbf{S}_t\) 是测量的协方差，\(\mathbf{C}_t\) 是状态与输出预测之间的交叉协方差。在 EnKF 中，我们经验地近似 \(\mathbf{S}_t\) 和 \(\mathbf{C}_t\)，如下所示。首先我们计算异常

```
\(\tilde{\mathbf{Z}}_{t|t-1} = \mathbf{Z}_{t|t-1} - \bar{\mathbf{z}}_{t|t-1} \mathbf{1}^\mathsf{T}, \quad \tilde{\mathbf{Y}}_{t|t-1} = \mathbf{Y}_{t|t-1} - \bar{\mathbf{y}}_{t|t-1} \mathbf{1}^\mathsf{T}\) (8.192)
```

然后我们计算样本协方差矩阵

```
\(\tilde{\mathbf{C}}_t = \frac{1}{N_s - 1} \tilde{\mathbf{Z}}_{t|t-1} \tilde{\mathbf{Y}}_{t|t-1}^\mathsf{T}, \quad \tilde{\mathbf{S}}_t = \frac{1}{N_s - 1} \tilde{\mathbf{Y}}_{t|t-1} \tilde{\mathbf{Y}}_{t|t-1}^\mathsf{T}\) (8.193)
```

最后我们计算

```
\(\bar{\mathbf{K}}_t = \tilde{\mathbf{C}}_t \tilde{\mathbf{S}}_t^{-1}\) (8.194)
```

它与多元最小二乘问题具有相同的形式。对于具有加性噪声的模型，我们可以通过消除预测观测的采样来减少此过程的方差。因此，我们用其确定性版本替换 \(\bar{\mathbf{Y}}_{t|t-1}\)，\(\bar{\mathbf{Y}}_{t|t-1} = \mathbf{H} \mathbf{Z}_{t|t-1}\)（为记号简单起见，假设线性观测模型）。然后我们使用 \(\tilde{\mathbf{C}}_t = \frac{1}{N_s - 1} \tilde{\mathbf{Z}}_{t|t-1} \tilde{\mathbf{O}}_{t|t-1}^\mathsf{T}\)，以及 \(\tilde{\mathbf{S}}_t = \frac{1}{N_s - 1} \tilde{\mathbf{O}}_{t|t-1} \tilde{\mathbf{O}}_{t|t-1}^\mathsf{T} + \mathbf{R}_t\)。（也可以通过使用 **集合平方根滤波器** [Tip+03] 来消除潜在状态的采样，尽管这可能不够稳健。）

我们现在将计算复杂度与 KF 算法进行比较。回顾 \(N_z\) 是潜在维度的数量，\(N_y\) 是观测维度的数量，\(N_s\) 是样本的数量。我们将假设 \(N_z > N_s > N_y$，如大多数地理空间问题中所见。EnKF 时间更新需要 \(O(N_z^2 N_s)$ 时间来将样本通过模型传播（为简单起见，假设线性模型），而 KF 需要 \(O(N_z^3)$ 时间来计算 \(\mathbf{F}_t \unknown_{t-1} \mathbf{F}_t + \mathbf{Q}_t$。EnKF 量测更新需要 \(O(N_z N_y N_s)$ 时间来计算 \(\tilde{\mathbf{C}}_t$，\(O(N_y^2 N_s)$ 时间来计算 \(\tilde{\mathbf{S}}_t$，\(O(N_y^3)$ 时间来计算 \(\tilde{\mathbf{S}}_t^{-1}\)，\(O(N_z N_y^2)\) 来计算 \(\bar{\mathbf{K}}_t\)，以及 \(O(N_z N_y N_s)$ 时间来计算 \(\mathbf{Z}_{t|t}\)。相比之下，在 KF 中，量测更新需要 \(O(N_z^2 N_y)$ 来计算 \(\mathbf{C}_t$，\(O(N_z^2 N_y)$ 来计算 \(\mathbf{S}_t$，\(O(N_y^3)$ 来计算 \(\mathbf{S}_t^{-1}\)，\(O(N_z N_y^2)$ 来计算 \(\mathbf{K}_t\)，以及 \(O(N_z N_y)$ 来计算 \(\boldsymbol{\mu}_{t|t}\)。总之，EnKF 是 \(O(N_z N_s)$，但 EKF 是 \(O(N_z^2)$，如果我们为简单起见忽略对 \(N_y$ 的依赖。

不幸的是，如果 \(N_s$ 太小，EnKF 可能会变得过度自信，且滤波器可能会发散。一种常见的启发式方法来减少这种情况，称为 **协方差膨胀**，即我们用 \(\bar{\mathbf{Z}}_{t|t-1} = \frac{1}{c} (\mathbf{Z}_{t|t-1} - \tilde{\mathbf{z}}_{t|t-1} \mathbf{1}^\mathsf{T})\) 替换 \(\tilde{\mathbf{Z}}_{t|t-1}\)，其中 \(c < 1\) 是某个调整因子。

与粒子滤波器不同，EnKF 并不保证收敛到正确的后验。然而，已经开发出了混合 PF/EnKF 方法（例如，[LGMT11; FK13b; Rei13]），具有更好的理论基础。

### 8.5.5 鲁棒卡尔曼滤波器

在实践中，我们经常遇到非高斯噪声。一个常见例子是当观测模型中存在杂波或离群值，或者过程模型发生突然变化时。在这种情况下，我们可以使用拉普拉斯分布 [Ara+09] 或学生 t 分布 [Ara10; RÖG13; Ara+17] 作为噪声模型。

[Hua+17b] 提出了一种变分贝叶斯（第 10.3.3 节）方法，允许动态先验和观测模型均为（线性）学生分布，但每一步的后验都使用高斯分布进行近似，条件是噪声尺度矩阵，该矩阵使用逆 Wishart 分布建模。这方面的扩展，用于处理混合分布，可见 [Hua+19]。

### 8.5.6 双 EKF

在本节中，我们简要讨论了一种估计 SSM 参数的方法。在离线设置中，我们可以使用 EM、SGD 或贝叶斯推断来计算 \(p(\boldsymbol{\theta} | \mathbf{y}_{1:T})$ 的近似值（参见第 29.8 节）。在在线设置中，我们想要计算 \(p(\boldsymbol{\theta}_t | \mathbf{y}_{1:t})$。我们可以通过将参数添加到状态空间中（可能带有人工动态，\(p(\boldsymbol{\theta}_t | \boldsymbol{\theta}_{t-1}) = \mathcal{N}(\boldsymbol{\theta}_t | \boldsymbol{\theta}_{t-1}, \epsilon \mathbf{I})\)），然后对状态和参数进行联合推断来实现这一点。每一步的潜在变量现在包含潜在状态 \(\mathbf{z}_t\) 和潜在参数 \(\boldsymbol{\theta}_t\)。在该模型中执行近似推断的一种方法是使用双 EKF，其中一个 EKF 执行状态估计，另一个 EKF 执行参数估计 [WN01]。

### 8.5.7 归一化流卡尔曼滤波器

归一化流，如第 23 章所讨论，是一种具有可处理精确似然的深度生成模型。这些模型可用于“升级”线性高斯 SSM 的观测模型，同时仍保留可处理的精确高斯推断，如 [Béz+20] 所示。特别是，我们不再观测 \(\mathbf{y}_t = \mathbf{H}_t \mathbf{z}_t + \mathbf{r}_t\)，其中 \(\mathbf{r}_t \sim \mathcal{N}(\mathbf{0}, \mathbf{R}_t)\)，而是观测 \(\mathbf{y}_t = f_t(\mathbf{h}_t)\)，其中 \(\mathbf{h}_t = \mathbf{H}_t \mathbf{z}_t + \mathbf{r}_t\)，且 \(f_t : \mathbb{R}^{N_y} \rightarrow \mathbb{R}^{N_y}\) 是一个具有可处理雅可比矩阵的可逆函数。在这种情况下，精确后验 \(p(\mathbf{z}_t | \mathbf{y}_{1:t})\) 由常规卡尔曼滤波器方程应用于 \(\mathbf{h}_t = f_t^{-1}(\mathbf{y}_t)\) 而非 \(\mathbf{y}_t\) 给出，我们将其表示为 \(p_{\text{LGSSM}}(\mathbf{z}_t | \mathbf{h}_{1:t})\)。

此结果可通过归纳法证明。首先注意，根据变量变换公式，\(p(\mathbf{y}_t | \mathbf{z}_t) = p(\mathbf{h}_t | \mathbf{z}_t) D f_t^{-1}(\mathbf{y}_t)\)，其中 \(D g(\mathbf{a}) \triangleq |\det \text{Jac}(g)(\mathbf{a})|\)。根据归纳法，我们有 \(p(\mathbf{z}_{t-1} | \mathbf{y}_{1:t-1}) = p_{\text{LGSSM}}(\mathbf{z}_{t-1} | \mathbf{h}_{1:t-1})\)，因此根据动态模型的线性高斯假设，\(p(\mathbf{z}_t | \mathbf{y}_{1:t-1}) = p_{\text{LGSSM}}(\mathbf{z}_t | \mathbf{h}_{1:t-1})\)。因此，滤波后验由以下公式给出：

```
\(p(\mathbf{z}_t | \mathbf{y}_{1:t}) = \frac{p(\mathbf{y}_t | \mathbf{z}_t) p(\mathbf{z}_t | \mathbf{y}_{1:t-1})}{\int p(\mathbf{y}_t | \mathbf{z}'_t) p(\mathbf{z}'_t | \mathbf{y}_{1:t-1}) d\mathbf{z}'_t} = \frac{D f_t^{-1}(\mathbf{y}_t) p(\mathbf{h}_t | \mathbf{z}_t) p(\mathbf{z}_t | \mathbf{y}_{1:t-1})}{\int D f_t^{-1}(\mathbf{y}_t) p(\mathbf{h}_t | \mathbf{z}'_t) p(\mathbf{z}'_t | \mathbf{y}_{1:t-1})}\)
\(= \frac{p(\mathbf{h}_t | \mathbf{z}_t) p_{\text{LGSSM}}(\mathbf{z}_t | \mathbf{h}_{1:t-1})}{\int p(\mathbf{h}_t | \mathbf{z}'_t) p_{\text{LGSSM}}(\mathbf{z}'_t | \mathbf{h}_{1:t-1})} = p_{\text{LGSSM}}(\mathbf{z}_t | \mathbf{h}_{1:t})\)
```

类似的推理适用于平滑分布。
