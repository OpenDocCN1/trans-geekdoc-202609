\(\tilde{\gamma}_t(\mathbf{z}_{1:t}) = p(\mathbf{z}_1)p(\mathbf{y}_1|\mathbf{z}_1) \prod_{s=1}^t p(\mathbf{z}_s|\mathbf{z}_{1:s-1})p(\mathbf{y}_s|\mathbf{z}_{1:s}) \qquad (13.5)\)

例如，考虑一个一维高斯序列模型，其中动态是一阶马尔可夫的，但观测依赖于整个过去序列（这是 [NLS19] 中的示例 1.2.1）：

\(p(z_t|\mathbf{z}_{1:t-1}) = \mathcal{N}(z_t|\phi z_{t-1}, q)\)
\(p(y_t|\mathbf{z}_{1:t}) = \mathcal{N}(y_t| \sum_{s=1}^t \beta^{t-s} z_s, r) \qquad (13.6)\)

如果设置 \(\beta = 0\)，则得到 \(p(y_t|\mathbf{z}_{1:t}) = \mathcal{N}(y_t|z_t, r)\)（此处定义 \(0^0 = 1\)），因此模型变为线性高斯 SSM。随着 \(\beta\) 增大，对过去的依赖增加，使得推断问题变得更难。（我们将在下文重新讨论此示例。）

### 13.1.3 用于静态参数估计的 SMC 采样器

现在考虑从固定数据集 \(\mathcal{D} = \{ \mathbf{y}_n : n = 1 : N \}\) 进行参数估计的问题。我们假设观测是条件独立同分布的，因此后验形式为 \(p(\mathbf{z}|\mathcal{D}) \propto p(\mathbf{z}) \prod_{n=1}^N p(\mathbf{y}_n|\mathbf{z})\)，其中 \(\mathbf{z}\) 是未知参数。使用 SMC 近似 \(p(\mathbf{z}|\mathcal{D})\) 并不立刻显而易见，因为我们只有一个分布。不过，我们可以通过几种不同的方式将其转换为序列推断问题。一种方法，称为 **数据退火**，将步骤 \( t \) 的（边缘）目标分布定义为 \(\tilde{\gamma}_t(\mathbf{z}_t) = p(\mathbf{z}_t)p(\mathbf{y}_{1:t}|\mathbf{z}_t)\)。在这种情况下，时间步数 \( T\) 等于数据样本数 \( N\)。另一种方法，称为 **似然退火**，将步骤 \( t \) 的（边缘）目标分布定义为 \(\tilde{\gamma}_t(\mathbf{z}_t) = p(\mathbf{z}_t)p(\mathcal{D}|\mathbf{z}_t)^{\tau_t}\)，其中 \( 0 = \tau_t < \cdots < \tau_T = 1 \) 是温度参数。在这种情况下，步数 \( T\) 取决于我们将分布从初始先验 \( p(\mathbf{z}_1)\) 退火到最终目标 \( p(\mathcal{Z}_T)p(\mathcal{D}|\mathbf{z}_T)\) 的速度。一旦我们定义了边缘目标分布 \(\tilde{\gamma}_t(\mathbf{z}_t)\)，就需要一种方法将其扩展到变量 *序列* 上的联合目标分布 \(\tilde{\gamma}_t(\mathbf{z}_{1:t})\)，以便这些分布相互连接。我们将在第 13.6 节中说明如何做到这一点。然后我们可以将模型视为 SSM 并应用粒子滤波。最后，我们提取最终联合目标分布 \(\tilde{\gamma}_T(\mathbf{z}_{1:T}) = p(\mathbf{z}_{1:T})p(\mathcal{D}|\mathbf{z}_T)\)，从中可以计算边缘目标分布 \(\tilde{\gamma}_T(\mathbf{z}_T) = p(\mathbf{z}_T, \mathcal{D})\)，再通过归一化得到后验 \(p(\mathbf{z}|\mathcal{D})\)。详细内容在第 13.6 节中给出。

## 13.2 粒子滤波

在本节中，我们将介绍状态空间模型的 SMC 基础，最终介绍一种称为 **粒子滤波** 的方法。

### 13.2.1 重要性采样

我们首先回顾自归一化重要性采样方法（**SNIS**），它是粒子滤波的基础。（另参见第 11.5 节。）

假设我们有兴趣估计某个函数 \(\varphi_t\) 关于目标分布 \(\pi_t\) 的期望，记作

\(\pi_t(\varphi) \triangleq \mathbb{E}_{\pi_t}[\varphi_t(z_{1:t})] = \int \frac{\tilde{\gamma}_t(z_{1:t})}{Z_t} \varphi_t(z_{1:t}) dz_{1:t}\)

其中 \(Z_t = \int \tilde{\gamma}_t(z_{1:t}) dz_{1:t}\)。假设我们使用提议分布 \(q_t(z_{1:t})\) 的 SNIS，则得到以下近似：

\(\pi_t(\varphi) \approx \frac{1}{\hat{Z}_t} \frac{1}{N_s} \sum_{i=1}^{N_s} \tilde{w}_t^i(z_{1:t}^i) \varphi_t(z_{1:t}^i)\)

其中 \(z_{1:t}^i \stackrel{\text{iid}}{\sim} q_t\) 是来自提议分布的独立样本，\(\tilde{w}_t^i\) 是由以下公式定义的 **未归一化权重**：

\(\tilde{w}_t^i = \frac{\tilde{\gamma}_t(z_{1:t}^i)}{q_t(z_{1:t}^i)}\)

而 \(\hat{Z}_t\) 是由以下公式定义的近似归一化常数：

\(\hat{Z}_t \triangleq \frac{1}{N_s} \sum_{i=1}^{N_s} \tilde{w}_t^i\)

为了简化记号，让我们定义 **归一化权重** 为

\(W_t^i = \frac{\tilde{w}_t^i}{\sum_j \tilde{w}_t^j}\)

那么我们可以写成

\(\mathbb{E}_{\pi_t}[\varphi_t(z_{1:t})] \approx \sum_{i=1}^{N_s} W_t^i \varphi_t(z_{1:t}^i)\)

或者，与其计算特定目标函数的期望，不如使用加权样本之和直接近似目标分布本身：

\(\pi_t(z_{1:t}) \approx \sum_{i=1}^{N_s} W_t^i \delta(z_{1:t} - z_{1:t}^i) \triangleq \hat{\pi}_t(z_{1:t})\)

重要性采样应用于序列模型时的问题是，状态空间的维度非常大，并且随 \(t\) 增加。这使得很难定义一个能够覆盖高概率区域的好的提议分布，导致大多数样本获得可忽略的权重。在下文中，我们将讨论解决此问题的方法。

### 13.2.2 序列重要性采样

在本节中，我们讨论序列重要性采样或 **SIS**，其中提议分布具有以下自回归结构：

$q_t(\mathbf{z}_{1:t}) = q_{t-1}(\mathbf{z}_{1:t-1})q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1})$

我们可以通过重复使用 \(\mathbf{z}_{1:t-1}^i\) 样本来从 \(q_{t-1}(\mathbf{z}_{1:t-1})\) 获得样本，然后通过从条件分布 \(q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1}^i)\) 采样将其扩展一步。我们可以将此视为“增长”链（状态序列）。未归一化权重可以递归地计算如下：

\begin{aligned}
\tilde{w}_t(\mathbf{z}_{1:t}) &= \frac{\tilde{\gamma}_t(\mathbf{z}_{1:t})}{q_t(\mathbf{z}_{1:t})} = \frac{\tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1})}{\tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1})q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1})q_{t-1}(\mathbf{z}_{1:t-1})} \\
&= \frac{\tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1})}{q_{t-1}(\mathbf{z}_{1:t-1})} \frac{\tilde{\gamma}_t(\mathbf{z}_{1:t})}{\tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1})q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1})} \\
&= \tilde{w}_{t-1}(\mathbf{z}_{1:t-1}) \frac{\tilde{\gamma}_t(\mathbf{z}_{1:t})}{\tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1})q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1})}
\end{aligned}

比率因子有时被称为 **增量重要性权重**：

$\alpha_t(\mathbf{z}_{1:t}) = \frac{\tilde{\gamma}_t(\mathbf{z}_{1:t})}{\tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1})q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1})}$

请参阅算法 13.1 以获取由此产生的 SIS 算法的伪代码。（在实践中，我们在对数空间中计算权重，并使用 log-sum-exp 技巧转换回来。）

需要注意的是，在状态空间模型的特殊情况下，权重计算可以进一步简化。具体来说，假设我们有

\begin{aligned}
\tilde{\gamma}_t(\mathbf{z}_{1:t}) &= p(\mathbf{z}_{1:t}, \mathbf{y}_{1:t}) = p(\mathbf{y}_t|\mathbf{z}_{1:t})p(\mathbf{z}_t|\mathbf{z}_{1:t-1})p(\mathbf{z}_{1:t-1}, \mathbf{y}_{1:t-1}) \\
&= p(\mathbf{y}_t|\mathbf{z}_{1:t})p(\mathbf{z}_t|\mathbf{z}_{1:t-1})\tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1})
\end{aligned}

那么增量权重由以下公式给出：

$\alpha_t(\mathbf{z}_{1:t}) = \frac{p(\mathbf{y}_t|\mathbf{z}_{1:t})p(\mathbf{z}_t|\mathbf{z}_{1:t-1})\tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1})}{\tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1})q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1})} = \frac{p(\mathbf{y}_t|\mathbf{z}_{1:t})p(\mathbf{z}_t|\mathbf{z}_{1:t-1})}{q_t(\mathbf{z}_t|\mathbf{z}_{1:t-1})}$

不幸的是，SIS 存在一种称为 **权重退化** 或 **粒子贫乏** 的问题，其中大多数权重变得非常小（接近零），因此后验最终被近似为单个粒子。图 13.2a 对此进行了说明，其中我们将 SIS 应用于方程 (13.6) 中的非马尔可夫示例，使用 \(N_s = 5\) 个粒子。退化的原因在于每个粒子都必须“解释”（生成）整个观测序列。由于似然项的乘积，每个猜测状态序列随时间变得越来越不可能，每个假设的权重之间的差异将呈指数级增长。当然，在候选集中必然存在一个最佳序列，因此在归一化权重时，最佳序列将获得权重 1，其余序列将获得权重 0。但这浪费了大多数粒子。我们将在第 13.2.3 节中讨论此问题的解决方案。
