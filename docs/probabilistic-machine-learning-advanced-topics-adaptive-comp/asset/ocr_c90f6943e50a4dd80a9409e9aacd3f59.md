# 34.7.4.3 Computing BatchBALD

Computing the joint (conditional) mutual information is intractable, so in this section, we discuss how to approximate it. For brevity we drop the conditioning on $\boldsymbol{x}$ and $\mathcal{D}$. With this new notation, the objective becomes

```
$\alpha_{\text{BALD}}(\boldsymbol{x}_{1:B}, p(\boldsymbol{w}|\mathcal{D})) = \mathbb{H}(y_1, \dots, y_B) - \mathbb{E}_{p(\boldsymbol{w})}[\mathbb{H}(y_1, \dots, y_B|\boldsymbol{w})]$ (34.105)
```

Note that the $y_i$ are conditionally independent given $\boldsymbol{w}$, so $\mathbb{H}(y_1, \dots, y_B|\boldsymbol{w}) = \sum_{i=1}^B \mathbb{H}(y_i|\boldsymbol{w})$. Hence we can approximate the second term with Monte Carlo:

```
$\mathbb{E}_{p(\boldsymbol{w})}[\mathbb{H}(y_1, \dots, y_B|\boldsymbol{w})] \approx \frac{1}{S} \sum_{i=1}^n \sum_s \mathbb{H}(y_i|\hat{\boldsymbol{w}}_s)$ (34.106)
```

where $\hat{\boldsymbol{w}}_s \sim p(\boldsymbol{w}|\mathcal{D})$.

The first term, $\mathbb{H}(y_1, \dots, y_B)$, is a joint entropy, so is harder to compute. [KAG19] propose the following approximation, summing over all possible label sequences in the batch, and leveraging the fact that $p(\boldsymbol{y}) = \mathbb{E}_{p(\boldsymbol{w})}[p(\boldsymbol{y}|\boldsymbol{w})]$:

```
$\mathbb{H}(\boldsymbol{y}_{1:B}) = \mathbb{E}_{p(\boldsymbol{w})p(\boldsymbol{y}_{1:B}|w)} [-\log p(\boldsymbol{y}_{1:B}|\boldsymbol{w})]$ (34.107)

$\approx \sum_{\hat{\boldsymbol{y}}_{1:B}} \left( \frac{1}{S} \sum_{s=1}^S p(\hat{\boldsymbol{y}}_{1:B}|\hat{\boldsymbol{w}}_s) \right) \log \left( \frac{1}{S} \sum_{s=1}^S p(\hat{\boldsymbol{y}}_{1:B}|\hat{\boldsymbol{w}}_s) \right)$ (34.108)
```

The sum over all possible labels sequences can be made more efficient by noting that $p(\boldsymbol{y}_{1:n}|\boldsymbol{w}) = p(y_n|\boldsymbol{w})p(\boldsymbol{y}_{1:n-1}|\boldsymbol{w})$, so when we implement the greedy algorithm, we can incrementally update the probabilities, reusing previous computations. See [KAG19] for the details.
