## 4.3.3 带有潜变量的 MRF（玻尔兹曼机等）

在本节中，我们讨论包含潜变量的 MRF，作为在离散空间中表示高维联合分布的一种方式。

### 4.3.3.1 标准玻尔兹曼机

所有变量都可见的 MRF 在表达能力方面是有限的，因为建模变量之间相关性的唯一方法是直接添加边。一种替代方法是引入潜变量。玻尔兹曼机 [AHS85] 类似于带有潜变量的 Ising 模型（第 4.3.2.1 节）。此外，图结构可以是任意的（不仅仅是格子），二进制状态是 \( x_i \in \{0, 1\} \)，而不是 \( x_i \in \{-1, +1\} \)。我们通常将节点划分为隐藏节点 \( \mathbf{z} \) 和可见节点 \( \mathbf{x} \)，如图 4.20(a) 所示。

### 4.3.3.2 受限玻尔兹曼机（RBMs）

不幸的是，玻尔兹曼机中的精确推断（因此也是学习）是不可解决的，即使是近似推断（例如，吉布斯采样，第 12.3 节）也可能很慢。然而，假设我们限制架构，使节点排列在两层中，并且同一层中的节点之间没有连接（参见图 4.20(b)）。这种模型被称为 **受限玻尔兹曼机（RBM）** [HT01; HS06a]，或 **谐振器** [Smo86]。RBM 支持高效的近似推断，因为给定可见节点时隐藏节点是条件独立的，即，\( p(\mathbf{z}|\mathbf{x}) = \prod_{k=1}^K p(z_k|\mathbf{x}) \)。请注意，这与定向两层模型形成对比，在定向两层模型中，解释远离效应会导致潜变量在后验中变得“纠缠”，即使它们在先验中是独立的。

通常，RBM 中的隐藏节点和可见节点是二进制的，因此能量项的形式为 \(w_{dk}x_d z_k\)。如果 \(z_k = 1\)，则第 \(k\) 个隐藏单元向能量添加形式为 \(\boldsymbol{w}_k^{\mathsf{T}}\boldsymbol{x}\) 的一项；这可以被视为“软约束”。如果 \(z_k = 0\)，则隐藏单元不活跃，并且对此数据示例没有意见。通过开启不同的约束组合，我们可以在可见数据上创建复杂的分布。这是 **专家乘积**（第 24.1.1 节）的一个示例，因为 \(p(\boldsymbol{x}|\boldsymbol{z}) = \prod_{k: z_k=1} \exp(\boldsymbol{w}_k^{\mathsf{T}}\boldsymbol{x})\)。

这可以被视为一种具有指数数量隐藏组件的混合模型，对应于 \(\boldsymbol{z}\) 的 \(2^H\) 种设置。也就是说，\(\boldsymbol{z}\) 是 **分布式表示**，而标准混合模型使用 **本地表示**，其中 \(z \in \{1, K\}\)，并且 \(z\) 的每个设置对应于一个完整的原型或示例 \(\boldsymbol{w}_k\)，\(\boldsymbol{x}\) 与其进行比较，从而产生形式为 \(p(\boldsymbol{x}|z=k) \propto \exp(\boldsymbol{w}_k^{\mathsf{T}}\boldsymbol{x})\) 的模型。

已经定义了许多不同类型的 RBM，它们使用不同的成对势函数。请参见表 4.4 以获取摘要。（图 4.21 给出了从针对二值化 MNIST 数据集训练的 RBM 生成的一些图像的示例。）所有这些都是 **指数族谐振器** [WRZH04] 的特例。有关更多详细信息，请参见补充部分 4.3。

### 4.3.3.3 深度玻尔兹曼机

我们可以通过堆叠多个层来制作 RBM 的“深度”版本；这称为 **深度玻尔兹曼机** [SH09]。例如，图 4.22(a) 中的两层模型形式如下

```
p(\boldsymbol{x}, \boldsymbol{z}_1, \boldsymbol{z}_2 | \boldsymbol{\theta}) = \frac{1}{Z(\mathbf{W}_1, \mathbf{W}_2)} \exp \left( \boldsymbol{x}^{\mathsf{T}} \mathbf{W}_1 \boldsymbol{z}_1 + \boldsymbol{z}_1^{\mathsf{T}} \mathbf{W}_2 \boldsymbol{z}_2 \right)
```

其中 \(\boldsymbol{x}\) 是底部的可见节点，为了简洁，我们省略了偏置项。

### 4.3.3.4 深度信念网络（DBNs）

我们可以使用 RBM 作为潜在分布式代码的先验，然后使用 DPGM“解码器”将其转换为观测数据，如图 4.22(b) 所示。相应的联合分布形式如下

```
p(\boldsymbol{x}, \boldsymbol{z}_1, \boldsymbol{z}_2 | \boldsymbol{\theta}) = p(\boldsymbol{x} | \boldsymbol{z}_1, \mathbf{W}_1) \frac{1}{Z(\mathbf{W}_2)} \exp \left( \boldsymbol{z}_1^{\mathsf{T}} \mathbf{W}_2 \boldsymbol{z}_2 \right)
```

换句话说，它是 DPGM 上的 RBM。这种组合被称为 **深度信念网络（DBN）** [HOT06a]。然而，这个名称令人困惑，因为它实际上不是一种信念网。因此，我们将称其为 **深度玻尔兹曼网络**（方便地具有相同的 DBN 缩写）。

DBN 可以以简单的贪婪方式进行训练，并支持快速自底向上推断（详情请参见 [HOT06a]）。DBN 在深度学习历史上发挥了重要作用，因为它们是最早可以成功训练的深度模型之一。然而，它们不再被广泛使用，因为出现了更好的训练完全监督深度神经网络的方法（例如使用 ReLU 单元和 Adam 优化器），以及训练深度 DPGM 的高效方法，例如 VAE（第 21.2 节）。
