

因此优化更快、更稳健。自然策略梯度可以使用 KFAC 方法（第 6.4.4 节）来近似，如 [Wu+17] 所做。

除了 TRPO 之外，另一种受公式 (35.34) 启发的方法是使用 KL 散度作为惩罚项，用调节参数替换因子 $2\epsilon\gamma/(1-\gamma)^2$。然而，使用以下剪切目标通常效果更好且更简单，这导致了 **近端策略优化** 或 PPO 方法 [Sch+17]：

```
$J^{\text{PPO}}(\pi') \triangleq \frac{1}{1-\gamma} \mathbb{E}_{p_{\pi(a|s)}^\infty(s)\pi(a|s)} \left[ \kappa_\epsilon \left( \frac{\pi'(a|s)}{\pi(a|s)} \right) A_\pi(s,a) \right]$
```

其中 $\kappa_\epsilon(x) \triangleq \text{clip}(x, 1-\epsilon, 1+\epsilon)$ 确保 $|\kappa(x)-1| \le \epsilon$。该方法可以如 [WHT19] 中讨论的那样修改，以确保单调改进，从而使其成为真正的界优化方法。

## 35.3.5 确定性策略梯度方法

在本节中，我们考虑确定性策略的情况，即为每个状态预测一个唯一动作，因此 $a_t = \mu_\theta(s_t)$，而不是 $a_t \sim \pi_\theta(s_t)$。我们假设状态和动作是连续的，并定义目标为

```
$J(\mu_\theta) \triangleq \frac{1}{1-\gamma} \mathbb{E}_{p_{\mu_\theta}^\infty(s)} [R(s, \mu_\theta(s))]$
```

确定性策略梯度定理 [Sil+14] 提供了一种计算梯度的方法：

```
$\nabla_\theta J(\mu_\theta) = \frac{1}{1-\gamma} \mathbb{E}_{p_{\mu_\theta}^\infty(s)} [\nabla_\theta Q_{\mu_\theta}(s, \mu_\theta(s))]$
```

```
$= \frac{1}{1-\gamma} \mathbb{E}_{p_{\mu_\theta}^\infty(s)} [\nabla_\theta \mu_\theta(s) \nabla_a Q_{\mu_\theta}(s, a)|_{a=\mu_\theta(s)}]$
```

其中 $\nabla_\theta \mu_\theta(s)$ 是 $M \times N$ 雅可比矩阵，$M$ 和 $N$ 分别是 $\mathcal{A}$ 和 $\theta$ 的维度。对于形式为 $\pi_\theta(a|s) = \mu_\theta(s) + \text{noise}$ 的随机策略，当噪声水平趋于零时，标准策略梯度定理将简化为上述形式。

请注意，公式 (35.40) 中的梯度估计对状态进行积分，但不对动作进行积分，这有助于减少从采样轨迹中梯度估计的方差。然而，由于确定性策略不进行任何探索，我们需要使用非策略方法，即从随机行为策略 $\beta$ 中收集数据，其平稳状态分布为 $p_\beta^\infty$。原始目标 $J(\mu_\theta)$ 由以下近似：

```
$J_b(\mu_\theta) \triangleq \mathbb{E}_{p_\beta^\infty(s)} [V_{\mu_\theta}(s)] = \mathbb{E}_{p_\beta^\infty(s)} [Q_{\mu_\theta}(s, \mu_\theta(s))]$
```

非策略确定性策略梯度近似为（另请参见第 35.5.1.2 节）

```
$\nabla_\theta J_b(\mu_\theta) \approx \mathbb{E}_{p_\beta^\infty(s)} [\nabla_\theta [Q_{\mu_\theta}(s, \mu_\theta(s))]] = \mathbb{E}_{p_\beta^\infty(s)} [\nabla_\theta \mu_\theta(s) \nabla_a Q_{\mu_\theta}(s, a)|_{a=\mu_\theta(s)} ds]$
```

我们省略了一项取决于 $\nabla_\theta Q_{\mu_\theta}(s, a)$ 且难以估计的术语 [Sil+14]。

要应用公式 (35.42)，我们可以使用 TD 学习 $Q_w \approx Q_{\mu_\theta}$，从而得到以下更新：

```
$\delta = r_t + \gamma Q_w(s_{t+1}, \mu_\theta(s_{t+1})) - Q_w(s_t, a_t)$
```

```
$\mathbf{w}_{t+1} \leftarrow \mathbf{w}_t + \eta_w \delta \nabla_w Q_w(s_t, a_t)$
```

```
$\boldsymbol{\theta}_{t+1} \leftarrow \boldsymbol{\theta}_t + \eta_\theta \nabla_\theta \boldsymbol{\mu}_\theta(s_t) \nabla_a Q_w(s_t, a)|_{a=\boldsymbol{\mu}_\theta(s_t)}$
```

由于确定性策略梯度，这避免了策略更新中的重要性采样，并且由于使用了 Q-learning，避免了评论家更新中的重要性采样。

如果 $Q_w$ 关于 $w$ 是线性的，并使用形式为 $\phi(s, a) = a^\top \nabla_\theta \mu_\theta(s)$ 的特征，其中 $a$ 是 $a$ 的向量表示，则我们说评论家的函数近似器与策略 **兼容**；在这种情况下，可以证明上述近似不会使总体梯度产生偏差。

该方法已以多种方式扩展。[Lil+16] 的 **DDPG** 算法（代表“深度确定性策略梯度”）使用 DQN 方法（第 35.2.6 节）来更新由深度神经网络表示的 $Q$。**TD3** 算法 [FHM18]（代表“双延迟 DDPG”）通过使用双 DQN（第 35.2.5.2 节）和其他启发式方法扩展 DDPG 以进一步提高性能。最后，**D4PG** 算法 [BM+18]（代表“分布式分布 DDPG”）扩展 DDPG 以处理分布式训练，并处理 **分布强化学习**（即，使用奖励分布而非期望奖励）[BDM17]。

## 35.3.6 无梯度方法

策略梯度估计器计算“零阶”梯度，基本上是通过随机采样轨迹来评估函数。有时，使用无导数优化器（第 6.7 节）可能更高效，它甚至不尝试估计梯度。例如，[MGR18] 通过随机搜索训练线性策略取得了良好效果，[Sal+17b] 展示了如何使用进化策略来优化机器人控制器的策略。

## 35.4 基于模型的强化学习

无模型强化学习方法通常需要与环境进行大量交互才能获得良好性能。例如，Atari 基准测试中的最先进方法（如 rainbow（第 35.2.6 节））使用数百万帧，相当于以标准帧率玩多天。相比之下，人类可以在几分钟内达到相同性能 [Tsi+17]。同样，OpenAI 的机器人手控制器 [And+20] 使用 100 年的模拟数据学习操作立方体。

提高样本效率的一个有前途的方法是 **基于模型的强化学习（MBRL）**。在这种方法中，我们首先学习转移模型和奖励函数 $p_T(s'|s, a)$ 和 $R(s, a)$，然后使用它们来计算近似最优策略。这种方法可以显著减少智能体需要收集的现实世界数据量，因为它可以在其想象中（即模型中）“试试看”，而不是必须经验性地尝试。

我们可以使用模型的方式有几种，可以创建许多不同类型的模型。前面提到的一些算法，例如用于可证明高效探索的 MBIE 和 UCLR2（第 35.1.5.3 节），是基于模型的方法的示例。MBRL 还为强化学习与规划（第 34.6 节）[Sut90] 提供了自然联系。我们在下面的章节中讨论一些示例，并参考 [MBJ20; PKP21; MH20] 以获取更详细的综述。

### 35.4.1 模型预测控制（MPC）

在本章迄今为止，我们一直专注于试图学习最优策略 $\pi_*(s)$，然后在运行时可以使用它快速为任何给定状态 $s$ 选择最佳动作。然而，我们也可以避免预先完成所有这些工作，等到我们知道自己处于什么状态（称其为 $s_t$），然后使用模型来预测每个可能的动作序列之后可能出现的未来状态和奖励。

图 35.6：启发式搜索示意图。在此图中，子树按深度优先搜索过程排序。来自 [SB18] 的图 8.9。经 Richard Sutton 友好许可使用。

我们然后采取看起来最有希望的动作，并在下一步重复该过程。更准确地说，我们计算

```
$$\mathbf{a}^*_{t:t+H-1} = \text{argmax}_{\mathbf{a}_{t:t+H-1}} \mathbb{E} \left[ \sum_{h=0}^{H-1} R(s_{t+h}, a_{t+h}) + \hat{V}(s_{t+H}) \right]$$ (35.46)
```

其中期望是关于从状态 $s_t$ 执行 $\mathbf{a}_{t:t+H-1}$ 可能导致的状态序列。这里，$H$ 称为 **规划水平**，$\hat{V}(s_{t+H})$ 是此 $H$ 步前瞻过程结束时的到达奖励估计。这被称为 **滚动水平控制** 或 **模型预测控制（MPC）** [MM90; CA13]。我们将在下面讨论其中的一些特例。

### 35.4.1.1 启发式搜索

如果状态空间和动作空间是有限的，我们可以精确求解公式 (35.46)，尽管时间复杂度通常会随 $H$ 指数增长。然而，在许多情况下，我们可以剪掉不有希望的轨迹，从而使该方法在大规模问题中可行。具体来说，考虑一个离散的确定性 MDP，其中奖励最大化对应于找到到目标状态的最短路径。我们可以根据所有可能的动作扩展当前状态的后继状态，试图找到目标状态。由于搜索树随深度指数增长，我们可以使用 **启发式函数** 来确定扩展哪些节点的优先级；这被称为 **最佳优先搜索**，如图 35.6 所示。

如果启发式函数是到目标真实距离的乐观下界，则称为 **可接受**；如果我们的目标是最大化总奖励，则可接受意味着启发式函数是真实值函数的上界。可接受性确保我们永远不会错误地剪掉搜索空间的部分。在这种情况下，得到的算法称为 \(A^*\) **搜索**，并且是最优的。有关经典 AI **启发式搜索** 方法的更多细节，请参见 [Pea84; RN19]。
