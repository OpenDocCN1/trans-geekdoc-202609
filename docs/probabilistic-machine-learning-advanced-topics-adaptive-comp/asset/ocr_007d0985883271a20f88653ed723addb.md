The large oval represents the set of variational distributions $\mathcal{Q} = \{q_\psi(\mathbf{z}) : \psi \in \mathcal{O}\}$, where $\mathcal{O}$ is the set of possible variational parameters. Minimizing this objective will minimize the KL divergence, causing our approximation to approach the true posterior. See Figure 10.1 for an illustration. In the sections below, we give two different interpretations of this objective function.

# 10.1.1.1 The view from physics: minimize the variational free energy

If we define $\mathcal{E}_\theta(\mathbf{z}) = -\log p_\theta(\mathbf{z}, \mathbf{x})$ as the energy, then we can rewrite the loss in Equation (10.5)

```
$\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) = \mathbb{E}_{q_\psi(\mathbf{z})}[\mathcal{E}_\theta(\mathbf{z})] - \mathbb{H}(q_\psi) = \text{expected energy - entropy}$ (10.6)
```

In physics, this is known as the **variational free energy** (VFE). This is an upper bound on the **free energy** (FE), $-\log p_\theta(\mathbf{x})$, which follows from the fact that

```
$D_{\text{KL}}(q_\psi(\mathbf{z}) || p_\theta(\mathbf{z}|\mathbf{x})) = \mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) + \log p_\theta(\mathbf{x}) \ge 0$ (10.7)
```

```
$\underbrace{\mathcal{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x})}_{\text{VFE}} \ge \underbrace{-\log p_\theta(\mathbf{x})}_{\text{FE}}$ (10.8)
```

Variational inference is equivalent to minimizing the VFE. If we reach the minimum value of $-\log p_\theta(\mathbf{x})$, then the KL divergence term will be 0, so our approximate posterior will be exact.

# 10.1.1.2 The view from statistics: maximize the evidence lower bound (ELBO)

The negative of the VFE is known as the **evidence lower bound** or **ELBO** function [BKM16]:

```
$\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) \triangleq \mathbb{E}_{q_\psi(\mathbf{z})}[\log p_\theta(\mathbf{x}, \mathbf{z}) - \log q_\psi(\mathbf{z})] = \text{ELBO}$ (10.9)
```

The name "ELBO" arises because

```
$\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\psi}|\mathbf{x}) \le \log p_\theta(\mathbf{x})$ (10.10)
```

where $\log p_\theta(\mathbf{x})$ is called the "evidence". The inequality follows from Equation (10.8). Therefore maximizing the ELBO wrt $\psi$ will minimize the original KL, since $\log p_\theta(\mathbf{x})$ is a constant wrt $\psi$.
