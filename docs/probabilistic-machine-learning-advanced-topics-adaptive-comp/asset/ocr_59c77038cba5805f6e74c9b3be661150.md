We can better understand attention by comparing it to non-parametric kernel based prediction methods, such as Gaussian processes (Chapter 18). In this approach we compare the input query x in R^d to each of the training examples X = (x_1, ..., x_n) using a kernel to get a vector of similarity scores, alpha = [K(x, x_i)]_{i=1}^n. We then use this to retrieve a weighted combination of the corresponding m target values y_i in R^d_v to compute the predicted output, as follows:

```
\hat{y} = \sum_{i=1}^n \alpha_i y_i
```

See Section 18.3.7 for details.

We can make a differentiable and parametric version of this as follows (see [Tsa+19] for details). First we replace the stored examples matrix X with a learned embedding, to create a set of stored keys, K = X W_k in R^{n x d_k}. Similarly we replace the stored output matrix Y with a learned embedding, to create a set of stored values, V = Y W_v in R^{n x d_v}. Finally we embed the input to create a query, q = W_q x in R^{d_k}. The parameters to be learned are the three embedding matrices.

Next, we replace fixed kernel function with a soft attention layer. More precisely, we define the weighted output for query q to be

```
Attn(q, (k_1, v_1), ..., (k_n, v_n)) = Attn(q, (k_{1:n}, v_{1:n})) = \sum_{i=1}^n \alpha_i(q, k_{1:n}) v_i
```

where alpha_i(q, k_{1:n}) is the i'th attention weight; these weights satisfy 0 <= alpha_i(q, k_{1:n}) <= 1 for each i and sum_i alpha_i(q, k_{1:n}) = 1.

The attention weights can be computed from an attention score function a(q, k_i) in R, that computes the similarity of query q to key k_i. For example, we can use (scaled) dot product attention, which has the form

```
a(q, k) = q^T k / sqrt{d_k}
```
