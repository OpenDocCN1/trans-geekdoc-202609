In cases where a covariate has no useful predictive role, we would like to be able to induce sparsity, so we need to overcome this problem. A simple solution to this is to use a **non-centered parameterization** [PR03]. That is, we replace β_j ~ N(μ_β, σ_β^2) with β_j = μ_β + β̃_j σ_β, where β̃_j ~ N(0, 1) represents the offset from the global mean, μ_β. The correlation between β̃_j and σ_β is much less, as shown in Figure 15.17b. See Section 12.6.5 for more details.
