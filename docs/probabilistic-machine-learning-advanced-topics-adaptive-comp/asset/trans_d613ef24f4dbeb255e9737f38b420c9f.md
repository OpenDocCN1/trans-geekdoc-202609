

假设我们观察到 \(\boldsymbol{y} = (1, 0, 0)\)。我们知道这不可能是发送者发送的内容，因为这违反了奇偶校验约束（如果 \(x_1 = 1\) 则我们知道 \(x_3 = 1\)）。相反，\(\boldsymbol{x}\) 的 3 个后验众数为 000（第一位被翻转）、110（第二位被翻转）和 101（第三位被翻转）。后验中非零支撑的唯一其他配置是 011，这对应于三位被翻转的可能性较小的假设（参见图 5.11(b)）。其他所有假设（001、010 和 100）都与用于创建码字的确定性方法不一致。（有关此点的进一步讨论，请参见第 9.3.3.2 节。）

在实践中，我们使用更复杂的编码方案，其效率更高，即向消息添加的冗余位更少，但仍能保证可以纠正错误。详情请参见第 9.4.8 节。

## 5.6 信息瓶颈

在本节中，我们讨论判别模型 \(p(\boldsymbol{y}|\boldsymbol{x})\)，它在输入 \(\boldsymbol{x}\) 和输出 \(\boldsymbol{y}\) 之间使用一个 *随机瓶颈* 以防止过拟合，并提高鲁棒性和校准性。

### 5.6.1 标准信息瓶颈

我们说 \(\boldsymbol{z}\) 是 \(\boldsymbol{x}\) 的一个 *表示*，如果 \(\boldsymbol{z}\) 是 \(\boldsymbol{x}\) 的一个（可能是随机的）函数，因此可以由条件分布 \(p(\boldsymbol{z}|\boldsymbol{x})\) 描述。我们说 \(\boldsymbol{x}\) 的表示 \(\boldsymbol{z}\) 对于任务 \(\boldsymbol{y}\) 是 *充分* 的，如果 \(\boldsymbol{y} \perp \boldsymbol{x}|\boldsymbol{z}\)，或者等价地，如果 \(\mathbb{I}(\boldsymbol{z};\boldsymbol{y}) = \mathbb{I}(\boldsymbol{x};\boldsymbol{y})\)，即 \(\mathbb{H}(\boldsymbol{y}|\boldsymbol{z}) = \mathbb{H}(\boldsymbol{y}|\boldsymbol{x})\)。我们说一个表示是 **最小充分统计量**，如果 \(\boldsymbol{z}\) 是充分的且不存在其他具有更小 \(\mathbb{I}(\boldsymbol{z};\boldsymbol{x})\) 值的 \(\boldsymbol{z}\)。因此，我们希望找到一个表示 \(\boldsymbol{z}\)，它在最大化 \(\mathbb{I}(\boldsymbol{z};\boldsymbol{y})\) 的同时最小化 \(\mathbb{I}(\boldsymbol{z};\boldsymbol{x})\)。也就是说，我们希望优化以下目标：

```
min \, \beta \, \mathbb{I}(\boldsymbol{z}; \boldsymbol{x}) - \mathbb{I}(\boldsymbol{z}; \boldsymbol{y}) \qquad (5.165)
```

其中 \(\beta \ge 0\)，我们针对分布 \(p(\boldsymbol{z}|\boldsymbol{x})\) 和 \(p(\boldsymbol{y}|\boldsymbol{z})\) 进行优化。这被称为 **信息瓶颈原则** [TPB99]。这将最小充分统计量的概念推广为考虑充分性与最小性之间的权衡，该权衡由拉格朗日乘数 \(\beta > 0\) 捕获。

该原则在图 5.12 中得到说明。我们假设 \(Z\) 是 \(X\) 的函数，但与 \(Y\) 独立，即，我们假设图形模型 \(Z \leftarrow X \leftrightarrow Y\)。这对应于以下联合分布：

```
p(\boldsymbol{x}, \boldsymbol{y}, \boldsymbol{z}) = p(\boldsymbol{z}|\boldsymbol{x})p(\boldsymbol{y}|\boldsymbol{x})p(\boldsymbol{x}) \qquad (5.166)
```

因此，\(Z\) 可以捕获关于 \(X\) 的任何数量的信息，但不能包含关于 \(Y\) 独有的信息，如图 5.12a 所示。最优表示仅捕获对 \(Y\) 有用的关于 \(X\) 的信息；为了防止我们“浪费容量”并拟合输入中不相关的细节，\(Z\) 还应最小化关于 \(X\) 的信息，如图 5.12b 所示。

如果所有随机变量都是离散的，并且 \(\boldsymbol{z} = e(\boldsymbol{x})\) 是 \(\boldsymbol{x}\) 的一个确定性函数，则可以使用 [TPB99] 的算法来最小化第 5.6 节中的 IB 目标。如果所有变量都是联合高斯分布，该目标也可以解析求解 [Che+05]（所得方法可视为一种受监督的 PCA）。但是，一般来说，精确求解此问题在计算上是不可行的。我们在第 5.6.2 节中讨论了一种可处理的近似方法。（更多细节可参见，例如，[SZ22]。）

### 5.6.2 变分信息瓶颈

在本节中，我们利用第 5.3.6 节的思想，对公式 (5.165) 推导了一个变分上界。这被称为变分信息瓶颈或 VIB 方法 [Ale+16]。关键技巧是利用 KL 散度的非负性来写出

```
\int dx p(\boldsymbol{x}) \log p(\boldsymbol{x}) \ge \int dx p(\boldsymbol{x}) \log q(\boldsymbol{x}) \qquad (5.167)
```

对于任意分布 q。（注意 p 和 q 可能都受其他变量条件约束。）

为了更详细地解释该方法，让我们定义以下符号。令 $e(\boldsymbol{z}|\boldsymbol{x}) = p(\boldsymbol{z}|\boldsymbol{x})$ 表示编码器，$b(\boldsymbol{z}|\boldsymbol{y}) \approx p(\boldsymbol{z}|\boldsymbol{y})$ 表示反向编码器，$d(\boldsymbol{y}|\boldsymbol{z}) \approx p(\boldsymbol{y}|\boldsymbol{z})$ 表示分类器（解码器），而 $m(\boldsymbol{z}) \approx p(\boldsymbol{z})$ 表示边缘分布。（注意我们可以选择 $p(\boldsymbol{z}|\boldsymbol{x})$，但其他分布是通过对精确联合分布 $p(\boldsymbol{x}, \boldsymbol{y}, \boldsymbol{z})$ 的相应边缘分布和条件分布进行近似得出的。）此外，令 $\langle \cdot \rangle$ 表示对联合分布 $p(\boldsymbol{x}, \boldsymbol{y}, \boldsymbol{z})$ 中相关项的期望。

使用此符号，我们可以推导 $\mathbb{I}(\boldsymbol{z}; \boldsymbol{y})$ 的下界，如下所示：

```
\mathbb{I}(\boldsymbol{z}; \boldsymbol{y}) = \int dy dz p(\boldsymbol{y}, \boldsymbol{z}) \log \frac{p(\boldsymbol{y}, \boldsymbol{z})}{p(\boldsymbol{y}) p(\boldsymbol{z})} \qquad (5.168)
= \int dy dz p(\boldsymbol{y}, \boldsymbol{z}) \log p(\boldsymbol{y}|\boldsymbol{z}) - \int dy dz p(\boldsymbol{y}, \boldsymbol{z}) \log p(\boldsymbol{y}) \qquad (5.169)
= \int dy dz p(\boldsymbol{z}) p(\boldsymbol{y}|\boldsymbol{z}) \log p(\boldsymbol{y}|\boldsymbol{z}) - \text{const} \qquad (5.170)
\ge \int dy dz p(\boldsymbol{y}, \boldsymbol{z}) \log d(\boldsymbol{y}|\boldsymbol{z}) \qquad (5.171)
= \langle \log d(\boldsymbol{y}|\boldsymbol{z}) \rangle \qquad (5.172)
```

这里我们利用了 $\mathbb{H}(p(\boldsymbol{y}))$ 是一个与我们的表示无关的常数这一事实。

请注意，我们可以通过从以下分布采样来近似期望：

$$p(\mathbf{y}, \mathbf{z}) = \int d\mathbf{x} \, p(\mathbf{x})p(\mathbf{y}|\mathbf{x})p(\mathbf{z}|\mathbf{x}) = \int d\mathbf{x} \, p(\mathbf{x}, \mathbf{y})e(\mathbf{z}|\mathbf{x})$$

这只是通过编码器“推送”的经验分布。

同样，我们可以推导 $\mathbb{I}(\mathbf{z}; \mathbf{x})$ 的上界，如下所示：

$$\mathbb{I}(\mathbf{z}; \mathbf{x}) = \int d\mathbf{z} d\mathbf{x} \, p(\mathbf{x}, \mathbf{z}) \log \frac{p(\mathbf{z}, \mathbf{x})}{p(\mathbf{x})p(\mathbf{z})}$$ (5.174)

$$= \int d\mathbf{z} d\mathbf{x} \, p(\mathbf{x}, \mathbf{z}) \log p(\mathbf{z}|\mathbf{x}) - \int d\mathbf{z} \, p(\mathbf{z}) \log p(\mathbf{z})$$ (5.175)

$$\le \int d\mathbf{z} d\mathbf{x} \, p(\mathbf{x}, \mathbf{z}) \log p(\mathbf{z}|\mathbf{x}) - \int d\mathbf{z} \, p(\mathbf{z}) \log m(\mathbf{z})$$ (5.176)

$$= \int d\mathbf{z} d\mathbf{x} \, p(\mathbf{x}, \mathbf{z}) \log \frac{e(\mathbf{z}|\mathbf{x})}{m(\mathbf{z})}$$ (5.177)

$$= \langle \log e(\mathbf{z}|\mathbf{x}) \rangle - \langle \log m(\mathbf{z}) \rangle$$ (5.178)

请注意，我们可以通过从 $p(\mathbf{x}, \mathbf{z}) = p(\mathbf{x})p(\mathbf{z}|\mathbf{x})$ 采样来近似期望。综合起来，我们得到了 IB 目标的以下上界：

$$\beta \mathbb{I}(\mathbf{x}; \mathbf{z}) - \mathbb{I}(\mathbf{z}; \mathbf{y}) \le \beta (\langle \log e(\mathbf{z}|\mathbf{x}) \rangle - \langle \log m(\mathbf{z}) \rangle) - \langle \log d(\mathbf{y}|\mathbf{z}) \rangle$$ (5.179)

因此 VIB 目标为

$$\mathcal{L}_{\text{VIB}} = \beta (\mathbb{E}_{p_D(\mathbf{x})e(\mathbf{z}|\mathbf{x})} [\log e(\mathbf{z}|\mathbf{x}) - \log m(\mathbf{z})]) - \mathbb{E}_{p_D(\mathbf{x})e(\mathbf{z}|\mathbf{x})d(\mathbf{y}|\mathbf{z})} [\log d(\mathbf{y}|\mathbf{z})]$$ (5.180)

$$= -\mathbb{E}_{p_D(\mathbf{x})e(\mathbf{z}|\mathbf{x})d(\mathbf{y}|\mathbf{z})} [\log d(\mathbf{y}|\mathbf{z})] + \beta \mathbb{E}_{p_D(\mathbf{x})} [D_{\text{KL}}(e(\mathbf{z}|\mathbf{x}) \| m(\mathbf{z}))]$$ (5.181)

现在我们可以对这个目标进行随机梯度下降并最小化它（针对编码器、解码器和边缘分布的参数使用 SGD）。（我们假设分布是可重参数化的，如第 6.3.5 节中讨论的。）对于编码器 $e(\mathbf{z}|\mathbf{x})$，我们通常使用条件高斯分布，对于解码器 $d(\mathbf{y}|\mathbf{z})$，我们通常使用 softmax 分类器。对于边缘分布 $m(\mathbf{z})$，我们应该使用灵活的模型，例如高斯混合模型，因为它需要近似 **聚合后验** $p(\mathbf{z}) = \int d\mathbf{z} p(\mathbf{x}) e(\mathbf{z}|\mathbf{x})$，这是 $N$ 个高斯分布的混合（假设 $p(\mathbf{x})$ 是带有 $N$ 个样本的经验分布，且 $e(\mathbf{z}|\mathbf{x})$ 是高斯分布）。

我们在图 5.13 中对此进行了说明，我们在 MNIST 上拟合了一个 MLP 模型。在传递给 softmax 之前，我们使用了一个 2D 瓶颈层。在面板 a 中，我们展示了由确定性编码器学习到的嵌入。我们看到每个图像都被映射到一个点，类别之间或实例之间几乎没有重叠。在面板 b-c 中，我们展示了由随机编码器学习到的嵌入。每个图像都被映射到一个高斯分布，我们分别显示均值和协方差。类别仍然很好地分开，但类中的单个实例不再可区分，因为此类信息对于预测目的来说并不相关。

### 5.6.3 条件熵瓶颈

IB 试图在最大化 $\mathbb{I}(Z; Y)$ 的同时最小化 $\mathbb{I}(Z; X)$。我们可以将这个目标写成

$$\min \mathbb{I}(\mathbf{x}; \mathbf{z}) - \lambda \mathbb{I}(\mathbf{y}; \mathbf{z})$$ (5.182)
