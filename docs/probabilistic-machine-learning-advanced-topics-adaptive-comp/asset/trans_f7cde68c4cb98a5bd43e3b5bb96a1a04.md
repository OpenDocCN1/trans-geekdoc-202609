本节讨论一种更高效的技术，称为**时序差分**或**TD**学习 [Sut88]。基本思想是基于转移而非长轨迹，对采样的状态或状态-动作对增量式地减少 Bellman 误差。更具体地说，假设我们要为固定策略 \(\pi\) 学习值函数 \(V_\pi\)。给定一个状态转移 \((s, a, r, s')\)，其中 \(a \sim \pi(s)\)，我们修改估计值 \(V(s)\)，使其朝向自举目标（第 35.1.2 节）

```
\(V(s_t) \leftarrow V(s_t) + \eta [r_t + \gamma V(s_{t+1}) - V(s_t)]\) (35.6)
```

其中 \(\eta\) 为学习率。上述乘以 \(\eta\) 的项被称为**TD 误差**。参数化值函数表示的 TD 更新的更一般形式是

```
\(\boldsymbol{w} \leftarrow \boldsymbol{w} + \eta [r_t + \gamma V_{\boldsymbol{w}}(s_{t+1}) - V_{\boldsymbol{w}}(s_t)] \nabla_{\boldsymbol{w}} V_{\boldsymbol{w}}(s_t)\) (35.7)
```

其中公式 (35.6) 是特例。学习 \(Q_\pi\) 的 TD 更新规则类似。可以证明，在表格情况下，TD 学习（公式 35.6）在适当条件下会收敛到正确的值函数 [Ber19]。然而，当使用近似时（公式 35.7），它可能会发散，我们将在第 35.5.3 节进一步讨论此问题。

TD 的潜在发散也与以下事实一致：尽管形式非常相似，但公式 (35.7) 并非任何目标函数的 SGD（第 6.3.1 节）。相反，它是**自举**的一个示例，其中估计值 \(V_{\boldsymbol{w}}(s_t)\) 被更新以接近目标 \(r_t + \gamma V_{\boldsymbol{w}}(s_{t+1})\)，该目标由值函数估计值本身定义。这一思想也为 DP 方法（如值迭代）所共享，尽管它们依赖完整的 MDP 模型来计算精确的 Bellman 备份。相比之下，TD 学习可以被视为使用采样转移来近似此类备份。非自举方法的一个示例是前一节中的蒙特卡洛估计。它采样完整轨迹而非单个转移来执行更新，因此通常效率低得多。图 35.2 说明了 MC、TD 和 DP 之间的区别。

```
V(s_t) \leftarrow V(s_t) + \eta [G_{t:t+n} - V(s_t)] (35.9)
```

## 35.2.4 SARSA：在策略 TD 控制

TD 学习用于策略评估，因为它为固定策略估计值函数。为了找到最优策略，我们可以将该算法作为广义策略迭代（第 34.6.2 节）中的构建块。在此情况下，使用动作值函数 Q 以及相对于 Q 贪婪的策略 \(\pi\) 更方便。智能体在每个步骤都遵循 \(\pi\) 来选择动作，在发生转移 \((s, a, r, s')\) 时，TD 更新规则为

```
Q(s, a) \leftarrow Q(s, a) + \eta [r + \gamma Q(s', a') - Q(s, a)] \quad (35.11)
```

其中 \(a' \sim \pi(s')\) 是智能体在状态 \(s'\) 下将采取的动作。Q 更新后（用于策略评估），\(\pi\) 也会相应改变，因为它是相对于 Q 贪婪的（用于策略改进）。该算法最初由 [RN94] 提出，随后由 [Sut96] 进一步研究并重命名为 **SARSA**；名称来源于其更新规则，该规则涉及扩展的转移 \((s, a, r, s', a')\)。

为了使 SARSA 收敛到 \(Q_*\)，至少在表格情况下，每个状态-动作对都必须被无限次访问，因为该算法仅更新它访问过的 (s, a) 的 Q(s, a)。确保此条件的一种方法是使用“无限探索下的极限贪婪”（**GLIE**）策略。一个示例是 \(\epsilon\)-贪婪策略，其中 \(\epsilon\) 逐渐趋于 0。可以证明，带有 GLIE 策略的 SARSA 将收敛到 \(Q_*\) 和 \(\pi_*\) [Sin+00]。

## 35.2.5 Q-learning：非策略 TD 控制

SARSA 是一个**在策略**算法，这意味着它为当前使用的策略学习 Q-函数，这通常不是最优策略（除非在 GLIE 策略的极限情况下）。然而，通过简单修改，我们可以将其转换为一个**非策略**算法，即使使用次优策略来选择动作，它也能学习 \(Q_*\)。

想法是将公式 (35.11) 中的采样下一个动作 \(a' \sim \pi(s')\) 替换为 \(s'\) 中的贪婪动作：\(a' = \text{argmax}_b Q(s', b)\)。当发生转移 \((s, a, r, s')\) 时，这会导致以下更新

```
Q(s, a) \leftarrow Q(s, a) + \eta \left[ r + \gamma \max_b Q(s', b) - Q(s, a) \right] \quad (35.12)
```

这是表格情况下 **Q-learning** 的更新规则 [WD92]。可以以类似于公式 (35.7) 的方式进行扩展，以支持函数近似。由于它是非策略的，该方法可以使用来自任何数据源的 \((s, a, r, s')\) 三元组，例如策略的旧版本或现有（非 RL）系统的日志数据。如果每个状态-动作对都被无限次访问，则该算法在表格情况下（在学习率适当衰减的情况下）可证明收敛到 \(Q_*\) [Ber19]。算法 35.1 给出了带 \(\epsilon\)-贪婪探索的 Q-learning 的标准实现。
