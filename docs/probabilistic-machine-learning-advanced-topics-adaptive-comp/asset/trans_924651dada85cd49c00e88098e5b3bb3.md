依赖这些捷径可能会产生严重的现实后果。例如，[Zec+18a] 发现，一个用于识别肺炎的 CNN 依赖于胸部 X 光扫描中特定于医院的金属标记，而不是关注肺部本身，因此该模型无法推广到新医院。

## 19.2.2 分布转移的因果观

在以下各节中，我们将简要总结一些典型的分布转移类型。我们采用因果视角来看待这个问题，遵循 [Sch+12a; Zha+13b; BP16; Mei18a; CWG20; Bud+21; SCS22]。1（有关因果 DAG 的简要讨论，请参见第 4.7 节；有关更多详细信息，请参见第 36 章。）

我们假设模型的输入（协变量）为 $X$，需要预测的输出（标签）为 $Y$。如果我们认为 $X$ 导致 $Y$，记作 $X \rightarrow Y$，则称其为**因果预测**或**判别预测**。如果我们认为 $Y$ 导致 $X$，记作 $Y \rightarrow X$，则称其为**反因果预测**或**生成预测**。[Sch+12a]。

- 在因果性文献中，模型能否推广到新分布的问题被称为**外部效度**问题。如果模型具有外部效度，我们说它在分布之间是**可传输**的 [BP16]。

图 19.4：二维二分类问题中 4 种主要分布转移类型的示意图。改编自 [al21] 图 1。

选择使用哪个模型取决于我们对底层数据生成过程的假设。例如，假设 X 是医学图像，Y 是由人类专家或算法创建的图像分割。如果我们更改图像，则会更改标注，因此 X -> Y。现在假设 X 是医学图像，Y 是通过其他方式（例如实验室检测）估计的患者地面实测疾病状态。在这种情况下，我们有 Y -> X，因为更改疾病状态会改变图像的外观。另一个例子，假设 X 是电影文本评论，Y 是衡量评论有多有信息量的指标。显然我们有 X -> Y。现在假设 Y 是电影的星级评分，代表用户喜欢的程度；这将影响他们写的词语，因此 Y -> X。

根据上述讨论，我们可以用两种可能的方式对联合分布进行因式分解。一种方法是定义判别模型：

```
$p_{\boldsymbol{\theta}}(\boldsymbol{x}, \boldsymbol{y}) = p_{\boldsymbol{\psi}}(\boldsymbol{x}) p_{\boldsymbol{w}}(\boldsymbol{y} | \boldsymbol{x})$ (19.1)
```

参见图 19.3a。或者我们可以定义生成模型：

```
$p_{\boldsymbol{\theta}}(\boldsymbol{x}, \boldsymbol{y}) = p_{\boldsymbol{\pi}}(\boldsymbol{y}) p_{\boldsymbol{\phi}}(\boldsymbol{x} | \boldsymbol{y})$ (19.2)
```

参见图 19.3b。对于这两种模型类型中的每一种，分布的不同部分可能会从源变为目标。这就产生了 4 种典型的转移类型，我们将在 19.2.3 节中讨论。

## 19.2.3 四种主要分布转移类型

四种主要分布转移类型在 19.2 节中总结，并在图 19.4 中说明。我们将在下面给出更多详细信息（另见 [LP20]）。

### 19.2.3.1 协变转移

在因果（判别）模型中，如果 $p_{\psi}(\boldsymbol{x})$ 发生变化（即 $\boldsymbol{\psi}^s \neq \boldsymbol{\psi}^t$），我们称之为**协变转移**，也称为**域转移**。例如，训练分布可能是干净的咖啡壶图像，而

| 名称 | 源 | 目标 | 联合 |
|---|---|---|---|
| 协变/域转移 | $p(X)p(Y|X)$ | $q(X)p(Y|X)$ | 判别 |
| 概念转移 | $p(X)p(Y|X)$ | $p(X)q(Y|X)$ | 判别 |
| 标签（先验）转移 | $p(Y)p(X|Y)$ | $q(Y)p(X|Y)$ | 生成 |
| 表现转移 | $p(Y)p(X|Y)$ | $p(Y)q(X|Y)$ | 生成 |

*表 19.1：4 种主要的分布转移类型。*

测试分布可能是带有高斯噪声的咖啡壶图像，如图 19.1 所示；或者训练分布可能是目录中物体的照片，背景是整洁的白色，而测试分布可能是“在野外”收集的同类物体的照片；或者训练数据可能是合成生成的图像，而测试分布可能是真实图像。类似的转移也可能发生在文本领域；例如，训练分布可能是用英语写的电影评论，而测试分布可能是这些评论的西班牙语翻译。对抗协变转移的一些标准策略包括重要性加权（第 19.5.2 节）和域自适应（第 19.5.3 节）。

### 19.2.3.2 概念转移

在因果（判别）模型中，如果 $p_w(y|x)$ 发生变化（即 $\boldsymbol{w}^s \neq \boldsymbol{w}^t$），我们称之为**概念转移**，也称为**标注转移**。例如，考虑医学成像场景：训练分布和测试分布之间的图像标注惯例可能不同。概念转移的另一个例子是，当目标分布中出现了源分布中不存在的新标签时。这与开放世界识别有关，将在第 19.3.4 节中讨论。由于概念转移是对标签含义的改变，如果不查看目标分布中的标记示例（目标分布通过示例定义每个标签），就不可能修复这个问题。

### 19.2.3.3 标签/先验转移

在生成模型中，如果 $p_\pi(y)$ 发生变化（即 $\pi^s \neq \pi^t$），我们称之为**标签转移**，也称为**先验转移**或**患病率转移**。例如，考虑医学成像场景，如果患者患有某种疾病，则 $Y=1$，否则 $Y=0$。如果训练分布是城市医院，而测试分布是农村医院，那么疾病的患病率（由 $p(Y=1)$ 表示）可能会非常不同。

对抗标签转移的一些标准策略是使用新标签分布的估计来重新加权判别分类器的输出，我们将在 19.5.4 节中讨论这一点。

### 19.2.3.4 表现转移

在生成模型中，如果 $p_\phi(x|y)$ 发生变化（即 $\phi^s \neq \phi^t$），我们称之为**表现转移** [CWG20]，或**条件转移** [Zha+13b]。从某种意义上说，这是概念转移的逆过程。例如，考虑医学成像场景：相同疾病 $Y$ 在肿瘤形状 $X$ 中表现出来的方式可能不同。这通常是由于源和目标之间存在隐藏的混杂因素发生了变化（例如，患者年龄不同）。

## 19.2.4 选择偏差

在某些情况下，我们可能仅由于数据收集方式而引起分布的转移，而底层分布没有任何变化。具体来说，如果总体中的样本被包含在训练集中，则令 S = 1，否则 S = 0。因此，源分布为 p(X, Y) = p(X, Y|S = 1)，而目标分布为 q(X, Y) = p(X, Y|S ∈ {0, 1}) = p(X, Y)，因此不存在选择。

在图 19.5 中，我们可视化了四种选择方式。例如，假设我们根据 X 满足某些标准进行选择，例如某些质量的图像，或呈现某种模式；这可能会引起域转移或协变转移。现在假设我们根据 Y 满足某些标准进行选择，例如，我们更可能选择 Y = 1 的罕见示例，以平衡数据集（出于计算效率的原因）；这可能会引起标签转移。最后，假设我们根据 X 和 Y 两者进行选择；这可能会在 X 和 Y 之间引起非因果依赖，这种现象称为选择偏差（有关详细信息，请参见第 4.2.4.2 节）。

## 19.3 检测分布转移

一般来说，不可能使模型对测试时分布可能发生的所有转移方式都具有鲁棒性，而且在训练时我们也不一定能始终访问测试样本。作为替代方案，模型能够检测到转移发生并做出适当响应可能就足够了。有几种检测分布转移的方法，我们将在下面总结其中一些。（另见第 29.5.6 节，我们在其中讨论时间序列数据中的变点检测。）方法之间的主要区别在于我们是否拥有来自目标的一组样本
