## 34.4 上下文盗贼问题

*本节由 Lihong Li 合著。*

在第 34.3 节中，我们讨论了 A/B 测试，其中决策者尝试两个不同的动作 \(a_0\) 和 \(a_1\) 各固定次数 \(n_1\) 和 \(n_0\)，测量得到的奖励序列 \(y_1\) 和 \(y_0\)，然后选择最佳动作用于剩余时间（或剩余人群），以最大化预期奖励。

我们显然可以将其推广到两个动作以上。更重要的是，我们可以将其推广到单阶段决策问题之外。特别是，假设我们允许决策者尝试一个动作 \(a_t\)，观察奖励 \(r_t\)，然后决定在时间步 \(t+1\) 采取什么行动，而不是等到 \(n_1 + n_0\) 次实验都完成。这种即时反馈允许 **自适应策略**，这可以带来更高的预期奖励（更低的遗憾）。我们已将单阶段决策问题转化为 **序贯决策问题**。序贯决策问题有多种类型，但在本节中，我们考虑最简单的一种，称为 **盗贼问题**（参见 [LS19; Sli19]）。

### 34.4.1 盗贼问题的类型

在多臂盗贼问题（MAB）中，有一个代理（决策者），在每一步可以从某个策略 \(a_t \sim \pi_t\) 中选择一个动作，之后从环境中采样获得一个奖励 \(r_t \sim p_R(a_t)\)，其期望值为 \(R(s, a) = \mathbb{E}[R|a]\)。

我们可以将其想象成赌场中的一个代理面对多台老虎机，每台老虎机的奖励支付率不同。老虎机有时被称为单臂盗贼，因此 \(K\) 台这样的机器被称为多臂盗贼；每个不同的动作对应拉动不同老虎机的拉杆，\(a_t \in \{1, \dots, K\}\)。目标是快速找出哪台机器赔付最多，然后一直玩那台机器，直到你变得尽可能富有。

我们可以通过定义上下文盗贼问题来扩展此模型，其中每一步策略的输入是一个随机选择的状态或上下文 \(s_t \in \mathcal{S}\)。状态随时间根据某个任意过程演变，\(s_t \sim p(s_t|s_{1:t-1})\)，与代理的动作无关。策略现在形式为 \(a_t \sim \pi_t(a_t|s_t)\)，奖励函数现在形式为 \(r_t \sim p_R(r_t|s_t, a_t)\)，其期望值为 \(R(s, a) = \mathbb{E}[R|s, a]\)。在每一步，代理可以使用观察到的数据 \(\mathcal{D}_{1:t}\)（其中 \(\mathcal{D}_t = (s_t, a_t, r_t)\)）来更新其策略，以最大化预期奖励。

在（上下文）盗贼问题的有限 horizon 表述中，目标是最大化预期累积奖励：

```
J \triangleq \sum_{t=1}^T \mathbb{E}_{p_R(r_t|s_t, a_t) \pi_t(a_t|s_t) p(s_t|s_{1:t-1})} [r_t] = \sum_{t=1}^T \mathbb{E}[r_t]
```

（请注意，即使在代理更新策略时，奖励也在每一步累积；这有时被称为 "边干边学"。）在无限 horizon 表述中，当 \(T = \infty\) 时，累积奖励可能是无限的。为了防止 \(J\) 无界，我们引入一个折扣因子 \(0 < \gamma < 1\)，因此

```
J \triangleq \sum_{t=1}^\infty \gamma^{t-1} \mathbb{E}[r_t]
```

\(\gamma\) 可以解释为代理在任何时刻终止的概率（在这种情况下，它将停止累积奖励）。

另一种写法如下：

```
J = \sum_{t=1}^\infty \gamma^{t-1} \mathbb{E}[r_t] = \sum_{t=1}^\infty \gamma^{t-1} \mathbb{E}\left[ \sum_{a=1}^K R_a(s_t, a_t) \right]
```

其中我们定义

```
R_a(s_t, a_t) = \begin{cases} R(s_t, a) & \text{if } a_t = a \\ 0 & \text{otherwise} \end{cases}
```

3. 这称为随机盗贼问题。也可以允许奖励（以及可能的状态）以对抗方式选择，其中自然试图最小化代理的奖励。这称为对抗性盗贼问题。

因此，我们概念上评估所有拉臂的奖励，但只有实际选择的那一个（即 \(a_t\)）会给代理带来非零值，即 \(r_t\)。

基本盗贼问题有许多扩展。一个自然的扩展是允许代理执行 **多拉臂**，一次选择 \(M \le K\) 个不同的拉臂。让 \(\mathbf{a}_t\) 是相应的动作向量，指定所选拉臂的身份。然后我们定义奖励为

\(r_t = \sum_{a=1}^K R_a(s_t, \mathbf{a}_t)\)

where
\(R_a(s_t, \mathbf{a}_t) = \begin{cases} R(s_t, a) & \text{if } a \in \mathbf{a}_t \\ 0 & \text{otherwise} \end{cases}\)

这对于建模 **资源分配** 问题很有用。

另一种变体称为 **不安分盗贼问题** [Whi88]。这与多拉臂表述相同，此外我们还假设每个拉臂都有其关联的状态向量 \(s_t^a\)，它根据某个随机过程演变，无论是否选择了拉臂 \(a\)。然后我们定义

\(r_t = \sum_{a=1}^K R_a(s_t^a, \mathbf{a}_t)\)

where \(s_t^a \sim p(s_t^a|s_{1:t-1}^a)\) is some arbitrary distribution, often assumed to be Markovian. (The fact that the states associated with each arm evolve even if the arm is not picked is what gives rise to the term "restless".) This can be used to model serial dependence between the rewards given by each arm.

### 34.4.2 应用

上下文盗贼问题有许多应用。例如，考虑一个 **在线广告系统**。在这种情况下，状态 \(s_t\) 表示用户当前正在查看的网页的特征，动作 \(a_t\) 表示系统选择展示的广告的身份。由于广告的相关性取决于网页，奖励函数形式为 \(R(s_t, a_t)\)，因此问题是上下文相关的。目标是最大化预期奖励，这相当于人们点击广告的预期次数；这称为 **点击率** 或 **CTR**。（有关此应用的更多信息，参见 [Gra+10; Li+10; McM+13; Aga+14; Du+21; YZ22]。）

上下文盗贼问题的另一个应用出现在 **临床试验** [VBW15] 中。在这种情况下，状态 \(s_t\) 是我们正在治疗的当前患者的特征，动作 \(a_t\) 是医生选择给他们的治疗方案（例如，一种新药或 **安慰剂**）。我们的目标是最大化预期奖励，即被治愈人数的预期值。（另一个目标是尽快确定哪种治疗方案最好，而不是最大化预期奖励；这种变体称为 **最佳拉臂识别** [ABM10]。）
