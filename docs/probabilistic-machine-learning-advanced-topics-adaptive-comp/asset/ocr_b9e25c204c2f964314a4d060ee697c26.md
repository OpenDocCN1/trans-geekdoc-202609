The corresponding ELBO becomes

\(\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathcal{D}) = \sum_{n=1}^N [\mathbb{E}_{q_\phi(\mathbf{z}_n|\mathbf{x}_n)} [\log p_\theta(\mathbf{x}_n, \mathbf{z}_n) - \log q_\phi(\mathbf{z}|\mathbf{x}_n)]]\)

If we combine this with SVI we get an amortized version of Equation (10.27). For example, if we use a minibatch of size 1, we get

\(\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathbf{x}_n) \approx N [\mathbb{E}_{q_\phi(\mathbf{z}_n|\mathbf{x}_n)} [\log p_\theta(\mathbf{x}_n, \mathbf{z}_n) - \log q_\phi(\mathbf{z}|\mathbf{x}_n)]]\)

We can optimize this as shown in Algorithm 10.1. Note that the (partial) maximization wrt \(\boldsymbol{\theta}\) in the M step is usually done with a gradient update, but the maximization wrt \(\boldsymbol{\phi}\) in the E step is trickier, since the loss uses \(\boldsymbol{\phi}\) to define an expectation operator, so we can't necessarily push the gradient operator inside; we discuss ways to optimize the variational parameters in Section 10.2 and Section 10.3.

| Algorithm 10.1: Amortized stochastic variational EM |
|---|
| 1 Initialize \(\boldsymbol{\theta}, \boldsymbol{\phi}\) |
| 2 repeat |
| 3 Sample \(\mathbf{x}_n \sim p_\mathcal{D}\) |
| 4 E step: \(\boldsymbol{\phi} = \text{argmax}_\boldsymbol{\phi} \mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathbf{x}_n)\) |
| 5 M step: \(\boldsymbol{\theta} = \text{argmax}_\boldsymbol{\theta} \mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathbf{x}_n)\) |
| 6 until converged |

# 10.1.6 Semi-amortized inference

Amortized SVI is widely used for fitting LVMs, e.g., for VAEs (see Section 21.2), for topic models [SS17a], for probabilistic programming [RHG16], for CRFs [TG18], etc. However, the use of an inference network can result in a suboptimal setting of the local variational parameters \(\boldsymbol{\psi}_n\). This is called the **amortization gap** [CLD18]. We can close this gap by using the inference network to warm-start an optimizer for \(\boldsymbol{\psi}_n\); this is known as **semi-amortized VI** [Kim+18c]. (See also [MYM18], who propose a closely related method called **iterative amortized inference**.) An alternative approach is to use the inference network as a proposal distribution. If we combine this with importance sampling, we get the IWAE bound of Section 10.5.1. If we use this with Metropolis-Hastings, we get a VI-MCMC hybrid (see Section 10.4.5).
