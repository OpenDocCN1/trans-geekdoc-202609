## 6.7.2 模拟退火

模拟退火 [KJV83; LA87] 是一种随机局部搜索算法（第 6.7.1.1 节），试图寻找黑盒函数 \( \mathcal{E}(\boldsymbol{x}) \) 的全局最小值，其中 \( \mathcal{E}() \) 称为能量函数。该方法通过定义 \( p(\boldsymbol{x}) = \exp(-\mathcal{E}(\boldsymbol{x})) \) 将能量转换为状态上的（未归一化的）概率分布，然后使用 Metropolis-Hastings 算法的变体从一组概率分布中采样，其设计目的是在最终步骤中，该方法从分布的一个模态中采样，即找到最可能的状态之一或最低能量状态之一。此方法既可用于离散优化也可用于连续优化。更多详情见第 12.9.1 节。

## 6.7.3 进化算法

随机局部搜索（SLS）在每个步骤维护单个“最佳猜测”\(\boldsymbol{x}_t\)。如果运行 \(T\) 个步骤并重启 \(K\) 次，总成本为 \(TK\)。一种自然的替代方案是维护 \(K\) 个好候选者的集合或种群 \(\mathcal{S}_t\)，并在每个步骤尝试改进它们。这称为进化算法（EA）。如果运行 \(T\) 个步骤，它也耗时 \(TK\)；然而，它通常比多次重启的 SLS 获得更好的结果，因为搜索过程并行探索了更多的空间，并且种群中不同成员的信息可以共享。EA 有多种版本，如下面所述。

## 6.7.4 分布估计（EDA）算法

EA 方法维护一组好的候选解，可以看作是高适应度状态上的隐式（非参数）密度模型。[BC95] 提出“从遗传算法中移除遗传成分”，通过显式学习配置空间上的概率模型，将其质量集中在高分解上。也就是说，种群成为生成模型的参数集合，\(\unknown_t\)。

学习此类模型的一种方法如下。我们首先从当前模型 \(\mathcal{S}_t = \{x_k \sim p(x|\unknown_t)\}\) 中创建 \(K' > K\) 个候选解的样本。然后使用适应度函数对样本进行排序，并使用选择算子挑选出规模为 \(K\) 的最有希望的子集 \(\mathcal{S}_t^*\)（这称为 **截断选择**）。最后，使用最大似然估计将新的概率模型 \(p(x|\unknown_{t+1})\) 拟合到 \(\mathcal{S}_t^*\)。这称为 **分布估计** 或 **EDA** 算法（参见例如 [LL02; PSC06; Hau+11; PHL12; Hu+12; San17; Bal17]）。

请注意，EDA 等同于最小化由 \(\mathcal{S}_t^*\) 定义的经验分布与模型分布 \(p(x|\unknown_{t+1})\) 之间的交叉熵。因此，EDA 与 **交叉熵法** 相关，如第 6.7.5 节所述，尽管 CEM 通常假设特例 \(p(x|\unknown) = \mathcal{N}(x|\boldsymbol{\mu}, \boldsymbol{\Sigma})\)。EDA 也与 EM 算法密切相关，如在 [Bro+20a] 中讨论。

作为一个简单示例，假设配置空间是长度为 \(D\) 的位串，且适应度函数为 \(f(x) = \sum_{d=1}^D x_d\)，其中 \(x_d \in \{0, 1\}\)（这在 EA 文献中称为 **one-max** 函数）。一个简单的概率模型是完全分解模型 \(p(x|\unknown) = \prod_{d=1}^D \text{Ber}(x_d|\theta_d)\)。在 DBO 中使用此模型会产生一种称为一元边缘分布算法或 **UMDA** 的方法。

我们可以通过将 \(\theta_d\) 设置为 \(\mathcal{S}_t^*\) 中第 \(d\) 位为 1 的样本比例来估计伯努利模型的参数。或者，我们可以增量地调整参数。基于种群的增量学习（**PBIL**）算法 [BC95] 将此想法应用于分解伯努利模型，从而产生以下更新：

```
\(\hat{\theta}_{d,t+1} = (1 - \eta_t)\hat{\theta}_{d,t} + \eta_t \bar{\theta}_{d,t}\) (6.188)
```

其中 \(\bar{\theta}_{d,t} = \frac{1}{N_t} \sum_{k=1}^K \mathbb{I}(x_{k,d}=1)\) 是从当前迭代生成的 \(K = |\mathcal{S}_t^*|\) 个样本中估计的最大似然估计（MLE），\(\eta_t\) 是学习率。
