### 29.4.1.4 初始化

与 EM 一样，我们必须小心确保仔细初始化参数，以最大限度地降低陷入劣质局部最优的机会。有几种方法可以做到这一点，例如：

- 使用一些完全标记的数据来初始化参数。
- 初始时忽略马尔可夫依赖，使用标准混合模型估计方法（如 K-means 或 EM）估计观测参数。
- 随机初始化参数，使用多次重启，并选择最佳解。

诸如确定性退火等技术 [UN98; RR01a] 可以帮助减轻局部最小值的影响。同样，正如 K-means 常用于为 GMM 初始化 EM 一样，使用 Viterbi 训练为 HMM 初始化 EM 也是常见的。维特比算法在第 9.2.6 节中有说明，但基本上它是一种用于计算单条最可能路径的算法。作为 E 步的近似，我们可以用单条路径计算的统计量替代对路径的求和。有时这可以产生更好的结果 [AG11]。

## 29.4.2 使用 SGD 进行参数估计

虽然 EM 算法是拟合 HMM 的“传统”方法，但它本质上是一种批量算法，因此不适合扩展到大型数据集（包含许多序列）。虽然可以将界优化扩展到在线情况（例如，参见 [Mai15]），但这可能会占用大量内存。

一个简单的替代方法是使用 SGD 优化 log p(y_{1:T}|θ)。我们可以使用前向算法计算此目标，如方程 (8.7) 所示：

```
log p(y_{1:T}|θ) = \sum_{t=1}^T \log p(y_t|y_{1:t-1}, θ) = \sum_{t=1}^T \log Z_t \tag{29.36}
```

其中每个时间步的归一化常数由以下给出：

```
Z_t \triangleq p(y_t|y_{1:t-1}) = \sum_{j=1}^K p(z_t=j|y_{1:t-1})p(y_t|z_t=j) \tag{29.37}
```

当然，我们需要确保转移矩阵保持为有效的行随机矩阵，即 0 \le A_{ij} \le 1 且 \sum_j A_{ij} = 1。同样，如果我们有分类观测，我们需要确保 B_{jk} 是有效的行随机矩阵，如果我们有高斯观测，我们需要确保 \Sigma_k 是有效的半正定矩阵。这些约束在 EM 中会自动处理。使用 SGD 时，我们可以重新参数化为无约束形式，如 [BC94] 所提议。

## 29.4.3 使用谱方法进行参数估计

使用最大似然拟合 HMM 很困难，因为对数似然不是凸函数。因此存在许多局部最优，EM 和 SGD 可能会给出不佳结果。一种替代方法是边缘化隐藏变量，而是使用可见空间中的预测分布。对于离散观测 HMM，带有观测矩阵 B_{jk} = p(y_t = k|z_t = j)，这种分布的形式为

```
[y_t]_k \triangleq p(y_t=k|y_{1:t-1}) \tag{29.38}
```

这称为**预测状态表示** [SJR04]。

假设存在 *m* 个可能的隐藏状态和 *n* 个可能的可见符号，其中 \(n \ge m\)。可以证明 [HKZ12; Joh12]，PSR 向量位于 \(\mathbb{R}^n\) 的一个子空间中，维度为 \(m \le n\)。直观上，这是因为定义隐藏状态更新的线性算子 **A**（如方程 (9.8) 中所述）结合通过 **B** 映射到可观测量，在输出空间中诱导了低秩结构。此外，我们可以通过对共现计数的可观测矩阵应用 SVD 来估计该低秩子空间的基：

```
\([ \mathbf{P}_2 ]_{ij} = p(y_t = i, y_{t-1} = j)\)
```

我们还需要估计三阶统计量：

```
\([ \mathbf{P}_3 ]_{ijk} = p(y_t = i, y_{t-1} = j, y_{t-2} = k)\)
```

使用这些量，我们可以在完全在可见空间中工作的同时，对我们的预测进行递归更新。这被称为**谱估计**或**张量分解** [HKZ12; AHK12; Rod14; Ana+14; RSG17]。

我们可以使用谱方法获得隐变量模型参数的良好初始估计，然后可以使用 EM 进行改进（例如，参见 [Smi+00]）。或者，我们可以“原样”使用它们，根本不需要 EM。参见 [Mat14] 了解这些方法的比较。另请参见第 29.8.2 节，我们在其中讨论用于拟合线性动态系统的谱方法。

## 29.4.4 贝叶斯 HMM

MLE 方法容易过拟合，并且可能会遭受数值问题，尤其是在样本量较小时。在本节中，我们简要讨论了一些推断参数后验 \(p(\boldsymbol{\theta} | \mathcal{D})\) 的方法。通过采用贝叶斯方法，我们还可以使用层次狄利克雷过程（补充部分 31.1）允许状态数量无界，从而得到 **HDP-HMM** [Fox+08]。

我们可以使用各种算法进行后验推断，例如变分贝叶斯 EM [Bea03] 或阻塞吉布斯采样（参见第 29.4.4.1 节），它在使用前向滤波后向采样算法（第 9.2.7 节）对隐藏序列 \(\boldsymbol{z}^s_{1:T,1:N}\) 进行采样与从其全条件分布 \(p(\boldsymbol{\theta} | \boldsymbol{y}_{1:T}, \boldsymbol{z}^s_{1:T,1:N})\) 对参数进行采样之间交替进行。不幸的是，\(\boldsymbol{z}\) 和 \(\boldsymbol{\theta}\) 之间的高相关性使这种坐标式方法相当慢。

更快的方法是边缘化离散隐性变量（使用前向算法），然后使用 MCMC [Fot+14] 或 SVI [Obe+19] 从以下对数后验中采样：

```
\(\log p(\boldsymbol{\theta}, \mathcal{D}) = \log p(\boldsymbol{\theta}) + \sum_{n=1}^N \log p(\boldsymbol{y}_{1:T:n} | \boldsymbol{\theta})\)
```

这是一种“折叠”推断形式。

### 29.4.4.1 HMM 的阻塞吉布斯采样

_本节由 Xinglong Li 编写。_

在本节中，我们讨论使用阻塞吉布斯采样 [Sco02] 对 HMM 进行贝叶斯推断。对于观测模型，我们考虑第 29.2.5 节中的一阶自回归 HMM 模型，因此 \( p(\mathbf{y}_t|\mathbf{y}_{t-1}, z_t=j, \boldsymbol{\theta}) = \mathcal{N}(\mathbf{y}_t|\mathbf{E}_j\mathbf{y}_{t-1} + \boldsymbol{\mu}_j, \boldsymbol{\Sigma}_j) \)。对于具有 \( K \) 个隐藏状态的模型，未知参数是 \( \boldsymbol{\theta} = \{\boldsymbol{\pi}, \mathbf{A}, \mathbf{E}_1, \dots, \mathbf{E}_K, \boldsymbol{\Sigma}_1, \dots, \boldsymbol{\Sigma}_K\} \)，其中我们假设（为了记号简洁）每个自回归模型的 \( \boldsymbol{\mu}_j \) 是已知的，并且我们将观测值条件化于 \( \mathbf{y}_1 \)。

我们在使用前向滤波后向采样算法（第 9.2.7 节）对 \( p(\mathbf{z}_{1:T}|\mathbf{y}_{1:T}, \boldsymbol{\theta}) \) 进行采样与对 \( p(\boldsymbol{\theta}|\mathbf{z}_{1:T}, \mathbf{y}_{1:T}) \) 进行采样之间交替。如果我们使用共轭先验，从 \( p(\boldsymbol{\theta}|\mathbf{z}_{1:T}, \mathbf{y}_{1:T}) \) 进行采样很容易。这里我们对 \( \boldsymbol{\pi} \) 和转移矩阵的每一行 \( \mathbf{A}_{j\cdot} \) 使用狄利克雷先验，并选择矩阵正态逆 Wishart 分布作为每个自回归模型的 \( \{\mathbf{E}_j, \boldsymbol{\Sigma}_j\} \) 的先验，类似于贝叶斯多元线性回归第 15.2.9 节。特别是，\( \boldsymbol{\theta} \) 的先验分布为：

\(\boldsymbol{\pi} \sim \text{Dir}(\tilde{\boldsymbol{\alpha}}_\pi) \qquad \mathbf{A}_{j\cdot} \sim \text{Dir}(\tilde{\boldsymbol{\alpha}}_A) \qquad \text{(29.42)}\)
\(\boldsymbol{\Sigma}_j \sim \text{IW}(\tilde{\nu}_j, \tilde{\boldsymbol{\Psi}}_j) \qquad \mathbf{E}_j|\boldsymbol{\Sigma}_j \sim \mathcal{MN}(\tilde{\mathbf{M}}_j, \boldsymbol{\Sigma}_j, \tilde{\mathbf{V}}_j) \qquad \text{(29.43)}\)

其中 \(\tilde{\alpha}_{\pi,k} = \tilde{\alpha}_\pi / K\) 和 \(\tilde{\alpha}_{A,k} = \tilde{\alpha}_A / K\)。对数先验概率为

\(\log p(\boldsymbol{\theta}) = c + \sum_{k=1}^K \frac{\tilde{\alpha}_\pi}{K} \log \pi_k + \sum_{j=1}^K \sum_{k=1}^K \frac{\tilde{\alpha}_A}{K} \log A_{jk} - \sum_{j=1}^K \left( \frac{\tilde{\nu}_j + N_y + 1}{2} \log |\boldsymbol{\Sigma}_j| + \frac{1}{2} \text{tr} \left( \tilde{\boldsymbol{\Psi}}_j \boldsymbol{\Sigma}_j^{-1} \right) \right)\)
\(- \sum_{j=1}^K \left( \frac{1}{2} \log |\boldsymbol{\Sigma}_j| + \frac{1}{2} \text{tr}((\mathbf{E}_j - \tilde{\mathbf{M}}_j)^\mathsf{T} \boldsymbol{\Sigma}_j^{-1} (\mathbf{E}_j - \tilde{\mathbf{M}}_j) \tilde{\mathbf{V}}_j) \right) \qquad \text{(29.44)}\)

给定 \( \mathbf{y}_{1:T} \) 和 \( \mathbf{z}_{1:T} \)，我们记 \( N_j = \sum_{t=2}^T \mathbb{I}(z_t = j) \) 和 \( N_{jk} = \sum_{t=1}^{T-1} \mathbb{I}(z_t = j, z_{t+1} = k) \)。联合似然为

\(\log p(\mathbf{y}_{1:T}, \mathbf{z}_{1:T} | \boldsymbol{\theta}) = c + \sum_{k=1}^K \mathbb{I}(z_1 = k) \log \pi_k + \sum_{j=1}^K \sum_{k=1}^K N_{jk} \log A_{jk}\)
\(- \sum_{j=1}^K \sum_{z_t=j} \left( \frac{1}{2} \log |\boldsymbol{\Sigma}_j| + \frac{1}{2} (\mathbf{y}_t - \mathbf{E}_j \mathbf{y}_{t-1} - \boldsymbol{\mu}_j)^\mathsf{T} \boldsymbol{\Sigma}_j^{-1} (\mathbf{y}_t - \mathbf{E}_j \mathbf{y}_{t-1} - \boldsymbol{\mu}_j) \right) \qquad \text{(29.45)}\)
\(= c + \sum_{k=1}^K \mathbb{I}(z_1 = k) \log \pi_k + \sum_{j=1}^K \sum_{k=1}^K N_{jk} \log A_{jk}\)
\(- \sum_{j=1}^K \left( \frac{N_j}{2} \log |\boldsymbol{\Sigma}_j| + \frac{1}{2} (\hat{\mathbf{Y}}_j - \mathbf{E}_j \tilde{\mathbf{Y}}_j)^\mathsf{T} \boldsymbol{\Sigma}_j^{-1} (\hat{\mathbf{Y}}_j - \mathbf{E}_j \tilde{\mathbf{Y}}_j) \right) \qquad \text{(29.46)}\)

其中 \(\hat{\mathbf{Y}}_j = [\mathbf{y}_t - \boldsymbol{\mu}_j]_{z_t=j}\) 和 \(\tilde{\mathbf{Y}}_j = [\mathbf{y}_{t-1}]_{z_t=j}\)，并且可以看出 \(\hat{\mathbf{Y}}_j \sim \mathcal{MN}(\hat{\mathbf{Y}}_j | \mathbf{E}_j \tilde{\mathbf{Y}}_j, \boldsymbol{\Sigma}_j, \mathbf{I}_{N_j})\)。

显然，从 \(\log p(\boldsymbol{\theta}) + \log p(\mathbf{y}_{1:T}, \mathbf{z}_{1:T} | \boldsymbol{\theta})\) 可以看出，\( \boldsymbol{\pi} \) 和 \( \mathbf{A}_{j\cdot} \) 的后验分布仍然是狄利克雷分布。还可以证明，\( \{\mathbf{E}_j, \boldsymbol{\Sigma}_j\} \) 的后验分布仍然是矩阵正态逆 Wishart 分布，其超参数可以通过分别将方程 (15.105) 中的 \( \mathbf{Y}, \mathbf{A}, \mathbf{X} \) 替换为 \( \hat{\mathbf{Y}}_j, \mathbf{E}_j \) 和 \( \tilde{\mathbf{Y}}_j \) 直接得到。总结而言，后验
