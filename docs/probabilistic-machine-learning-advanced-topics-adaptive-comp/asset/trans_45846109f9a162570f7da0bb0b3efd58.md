
"方差"。要推导非参数检验，我们可以先对 y 应用秩变换。这与克鲁斯卡尔-瓦利斯检验类似。

方差分析假设数据服从正态分布，具有共同（共享）方差，以便可以推导 F 统计量的抽样分布。我们可以将相应的模型写成线性回归模型，使用 xn 的哑编码，其中 xn[j] = 1(xn = j)。为了避免过参数化（这可能导致后验不可识别），我们舍弃第一个水平（这称为降秩编码）。然后我们可以将模型写为

```
p(y_n|x_n; \theta) \sim \mathcal{N}(f_{\text{aov}}(\boldsymbol{x}_n, \boldsymbol{\beta}), \sigma^2)
```

其中我们使用 ANOVA 公式定义预测均值：

```
f_{\text{aov}}(\boldsymbol{x}, \boldsymbol{\beta}) = \beta_0 + \beta_2 x_{[2]} + \cdots + \beta_J x_{[J]}
```

我们可以看到 $\beta_0$ 是总体均值，也对应于因子第 1 水平将使用的值（即，如果 $x_n = 1$）。其他 $\beta_j$ 项表示相对于第 1 水平的偏差。虚无假设对应于假设所有 $j = 2 : J$ 的 $\beta_j = 0$。

该模型的更对称表述是写成

```
f_{\text{aov}}(\boldsymbol{x}; \boldsymbol{\beta}) = \beta_0 + \beta_1 x_{[1]} + \beta_2 x_{[2]} + \cdots + \beta_J x_{[J]}
```

其中 $\beta_0$ 是 **大均数**，并且我们施加约束 $\sum_{j=1}^J \beta_j = 0$。在这种情况下，我们可以将每个 $\beta_j$ 解释为组 $j$ 相对于共享基线 $\beta_0$ 的偏差量。为了满足此约束，我们可以将预测均值写为

```
f_{\text{aov}}(\boldsymbol{x}, \tilde{\boldsymbol{\beta}}) = \tilde{\beta}_0 + \sum_{j=1}^J \tilde{\beta}_j x_{[j]} = (\tilde{\beta}_0 + \overline{\beta}) + \sum_{j=1}^J (\tilde{\beta}_j - \overline{\beta}) x_{[j]}
```

其中 $\tilde{\beta}_j$ 是无约束参数，$\overline{\beta} = \frac{1}{J} \sum_{j=1}^J \tilde{\beta}_j$。此构造满足约束，因为

```
\sum_{j=1}^J \beta_j = \sum_{j=1}^J \tilde{\beta}_j - \sum_{j=1}^J \overline{\beta} = J \overline{\beta} - J \overline{\beta} = 0
```

在传统方差分析中，我们假设数据服从正态分布，具有共同（共享）方差。在贝叶斯环境中，我们可以自由放宽这些假设。例如，我们可以使用不同的似然（例如，Student）并允许每个组有自己的方差 $\sigma_j^2$，这可以使用分层贝叶斯模型可靠地估计（参见第 3.6 节）。

## 3.10.3.6 带名义预测变量的计数预测变量（卡方检验）

考虑一种情况，我们为每个测量项目观察到两个名义值。例如，人的性别（男性或女性）以及他们是左撇子还是右撇子（LH 或 RH）。如果我们统计每种类型结果的数量，可以将数据表示为一个 \(R \times C\) **列联表**。参见表 3.3 以获取示例。我们可能有兴趣检验虚无假设，即两个组与结果之间不存在交互作用效应（即，两个变量独立）。在频率派统计学中，这通常使用 \(\chi^2\)-**检验** 来解决，它使用 \(\chi^2\) 检验统计量的抽样分布，定义为

```
\chi^2 = \sum_{r=1}^R \sum_{c=1}^C \frac{(O_{r,c} - E_{r,c})^2}{E_{r,c}}
```

其中 \(r\) 索引行，\(c\) 索引列，\(O_{r,c}\) 是单元格 \((r, c)\) 中的观测计数，\(E_{rc} = N p_r . p_c\) 是期望计数，其中 \(p_r. = O_c. / N\) 和 \(p_{.c} = O_{.r} / N\) 是经验边际频数。

在贝叶斯方法中，我们可以只修改第 3.10.3.5 节的双向方差分析，并将高斯分布替换为泊松分布。我们还需要将预测的自然参数通过指数链接传递，因为泊松分布要求速率参数非负。因此模型变为

```
p(y|x = (r, c), \theta) = \text{Poi}(y | \lambda_{r,c})
\lambda_{rc} = \exp(\beta_0 + \beta_r + \beta_c + \beta_{r,c})
```

我们现在可以以通常的方式执行后验推断。

## 3.11 缺失数据

有时我们可能有 **缺失数据**，其中数据向量 $\mathbf{X}_n \in \mathbb{R}^D$ 的部分可能未知。（如果我们有监督问题，我们将标签附加到特征向量上。）我们让 $\mathbf{X}_{n,\text{mis}}$ 表示缺失部分，$\mathbf{X}_{n,\text{obs}}$ 表示观察部分。由于数据缺失的原因可能具有信息性（例如，拒绝回答调查问题如“你是否患有 X 疾病？”可能表明受试者实际上确实患有它），我们需要建模 **缺失数据机制**。为此，我们引入随机变量 $\mathbf{R}_n$，表示 $\mathbf{X}_n$ 的哪些部分被“揭示”（观察）或未被揭示。具体来说，对于观察到 $\mathbf{X}_n$ 的那些索引（分量），我们设置 $\mathbf{R}_{n,o} = 1$，对于其他索引，设置 $\mathbf{R}_{n,\text{mis}} = 0$。

关于缺失数据机制，我们可以做出不同类型的假设，如 [Rub76; LR87] 所讨论。最强的假设是假设数据是 **完全随机缺失** 或 **MCAR**。这意味着 $p(\mathbf{R}_n | \mathbf{X}_n) = p(\mathbf{R}_n)$，因此缺失性不依赖于隐藏或观察到的特征。一种更现实的假设称为 **随机缺失** 或 **MAR**。这意味着 $p(\mathbf{R}_n | \mathbf{X}_n) = p(\mathbf{R}_n | \mathbf{X}_{n,\text{obs}})$，因此缺失性不依赖于隐藏特征，但可能依赖于可见特征。如果这两个假设都不成立，我们说数据是 **非随机缺失** 或 **MNAR**。

现在考虑条件或判别模型的情况，其中我们使用形式 $p(y_n | \mathbf{x}_n, \theta)$ 的模型对给定观察输入 $\mathbf{x}_n$ 的结果 $y_n$ 进行建模。由于我们对 $\mathbf{x}_n$ 进行条件化，我们假设它总是被观察。然而，输出标签可能被观察也可能不被观察，这取决于 $r_n$ 的值。例如，在 **半监督学习** 中，我们有标注数据 $\mathcal{D}^L = \{(\mathbf{x}_n, y_n)\}$ 和未标注数据 $\mathcal{D}^U = \{(\mathbf{x}_n)\}$ [CSZ06]。

判别设置中的 3 种缺失数据场景如图 3.30 所示，使用图形模型表示法（详情见 [MPT13]）。在 MCAR 和 MAR 情况下，我们看到可以忽略具有缺失输出的未标注数据，因为未知模型参数 $\theta$ 不受 $y_n$ 影响，如果它是隐藏叶节点。然而，在 MNAR 情况下，我们看到 $\theta$ 依赖于 $y_n$，即使它是隐藏的，因为 $y_n$ 的值被假设会影响 $r_n$ 的概率，而 $r_n$ 始终被观察。在这种情况下，为了拟合模型，我们需要 **插补** 缺失值，使用 EM 等方法（参见第 6.5.3 节）。
