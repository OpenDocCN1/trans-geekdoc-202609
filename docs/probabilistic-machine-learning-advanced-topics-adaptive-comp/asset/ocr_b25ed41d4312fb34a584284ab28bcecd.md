When we condition on y, are x and z independent? We have

```
p(x, z|y) = \frac{p(x, y, _)}{p(y)} = \frac{p(x)p(y|x)p(z|y)}{p(y)} = \frac{p(x,y)p(z|y)}{p(y)} = p(x|y)p(z|y) \quad (4.19)
```

and therefore X ⊥ Z | Y. So observing the middle node of chain breaks it in two (as in a Markov chain).

Now consider the tent structure X <- Y -> Z. The joint is

```
p(x, y, z) = p(y)p(x|y)p(z|y) \quad (4.20)
```

When we condition on y, are x and z independent? We have

```
p(x, z|y) = \frac{p(x, y, z)}{p(y)} = \frac{p(y)p(x|y)p(z|y)}{p(y)} = p(x|y)p(z|y) \quad (4.21)
```

and therefore X ⊥ Z | Y. So observing a root node separates its children (as in a naive Bayes classifier: see Section 4.2.8.2).
