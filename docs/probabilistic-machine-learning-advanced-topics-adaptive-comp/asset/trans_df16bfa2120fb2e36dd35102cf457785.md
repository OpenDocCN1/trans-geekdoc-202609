从理论角度来看，次模函数的可学习性和可识别性已经得到了大量研究。从最严格的学习设置开始，问题看来非常棘手。例如，[SF08; Goe+09] 表明，如果将查询次数限制为多项式数量（即形式为 \((S, f(S))\) 的训练对）对单调次模函数进行查询，则无法以比 \(\tilde{\Omega}(\sqrt{n})\) 更好的乘法近似因子来近似 \(f\)。在 [BH11] 中，优劣以乘法判断，意味着对于集合 \(A \subseteq V\)，我们希望存在某个函数 \(g(n)\) 使得 \(\tilde{f}(A) \le f(A) \le g(n)f(A)\)，这通常是一个概率性条件（即，由分布度量，或 \(\tilde{f}(A) \le f(A) \le g(n)f(A)\) 应在至少 \(1 - \beta\) 的点比例上发生）。或者，优劣也可以通过加法近似误差来度量，例如通过范数。也就是说，定义 \(\text{err}_p(f, \tilde{f}) = \|f - \tilde{f}\|_p = (\mathbb{E}_{A \sim \mathbf{Pr}}[|f(A) - \tilde{f}(A)|^p])^{1/p}\)，我们可能希望对于 \(p = 1\) 或 \(p = 2\) 有 \(\text{err}_p(f, \tilde{f}) < \epsilon\)。在 PAC（可能近似正确）模型中，我们以 \(\delta > 0\) 的概率、\(\epsilon > 0\) 或 \(g(n) > 1\) 的近似程度、\(\beta = 0\) 的学习精度进行学习，其样本或算法复杂度取决于 \(\delta\) 和 \(g(n)\)。在 PMAC（可能主要近似正确）模型 [BH11] 中，我们也“主要”（\(\beta > 0\)）地学习。在某些情况下，我们希望学习非次模函数的最佳次模近似。在其他情况下，只要误差足够小，我们就可以偏离次模性。学习特殊情况包括覆盖函数 [FK14; FK13a]、低次多项式 [FV15]、曲率受限函数 [IJB13]、具有有限“目标”的函数 [DHK14; Bac+18]、Fourier 稀疏函数 [Wen+20a]、属于称为“juntas”的家族的函数 [FV16]、或来自次模以外家族的函数 [DFF21]，还有其他 [BRS17; FKV14; FKV17; FKV20; FKV13; YZ19]。其他结果包括，不能通过先从样本中学习次模函数来最小化次模函数 [BS17]。

学习的基本策略是尝试从一个底层次模函数 \(f\) 构造次模函数近似 \(\hat{f}\)，且仅查询后者少量次数。这些结果的总体要旨是，要在所有地方都准确地学习是困难的。在机器学习社区中，学习在实践中可以进行得极其高效，尽管没有上述那种保证。例如，给定形式为 \(f(A) = \sum_i \alpha_i f_i(A)\) 的次模组件混合物，如果每个 \(f_i\) 被视为固定，则学习仅发生在混合系数 \(\alpha_i\) 上。这可以求解为一个线性回归问题，其中最优系数可以在线性回归设置中计算出来。或者，此类函数可以在最大边界设置中学习，其主要目标是调整 \(\alpha_i\) 以确保 \(f(A)\) 在某些子集上取较大值 [SSJ12; LB12; Tsc+14]。即便如此，仍存在实际挑战，因为在实践中通常很难获得训练对集合 \(\{(S_i, F(S_i))\}_i\)。或者，也可以在强化学习设置 [CKK17] 中通过优化从环境查询得到的增益向量来直接优化隐式函数，从而“学习”一个次模函数。通常，此类实用学习算法已被用于图像摘要 [Tsc+14]、文档摘要 [LB12] 和视频摘要 [GGG15; Vas+17a; Gon+14; SGS16; SLG17]。尽管这些学习方法中没有一种声称要近似某个真实的底层次模函数，但在实践中，它们确实比上述手动构建次模函数的方法表现更好。

所谓基于次模性的核心集，是指直接优化次模函数能为某些特定问题提供理论保证的核心集。这与上述情况不同，上述情况中次模函数被用作代理启发式目标函数，即使学习了次模函数，对其优化也只是原问题的启发式方法。在某些有限情况下，可以证明我们希望近似的函数本身已经是次模函数，例如，某些朴素贝叶斯和 k-NN 分类器 [WIB15] 的情况，其中训练准确率作为训练数据子集的函数可以被证明是次模函数。因此，最大化此函数在训练准确率上提供的保证与其在次模函数上提供的保证相同。不幸的是，许多模型的准确率不是次模函数，尽管它们确实具有次模差分解 [NB05; IB12]。

在其他情况下，可以证明某些理想的核心集目标本质上是次模函数。例如，在 [MBL20] 中，表明总体梯度（对训练数据中所有样本求和）与近似梯度（仅对摘要中的样本求和）之间的范数差可以用一个超模函数上界，该超模函数在转换为次模设施选址函数并最大化后，将选择一组减少此差异的样本，并在凸情况下导致到近似最优解的相似收敛速率。在 DPP 上下文中，[TBA19] 展示了类似的示例。在其他情况下，训练数据子集和训练是使用连续-离散优化框架同时进行的，其目标是通过次模目标来最小化在多样且具有挑战性的样本上的损失 [ZB18]。在其他情况下，可以形成与次模性相关但不保证是次模的双层目标，其中从训练集中选择一组样本，其明确目的是在验证集上表现良好 [Kil+20; BMK20]。

上述方法专注于减少训练数据集中的样本数量。然而，考虑设计矩阵的转置，上述所有方法也可用于减少机器学习过程中的特征。具体而言，提取式摘要、子集选择或核心集方法中的任何一种都可以视为特征选择，而抽象式摘要、草图或蒸馏方法中的任何一种都可以视为维度
