## 13.2.3 带重采样的序列重要性采样

在本节中，我们描述带重采样的序列重要性采样（SISR）。基本思想是这样的：我们不再“将所有旧粒子序列各增长一步”，而是先通过从旧后验中采样选择 \(N_s\) 个“最适”粒子，然后让这些幸存者各增长一步。更详细地说，在步骤 \(t\) 时，我们从

```
\( q_t^{\text{SISR}}(\mathbf{z}_{1:t}) = \hat{\pi}_{t-1}(\mathbf{z}_{1:t-1}) q_t(\mathbf{z}_t | \mathbf{z}_{1:t-1}) \) (13.22)
```

其中 \(\hat{\pi}_{t-1}(\mathbf{z}_{1:t-1})\) 是前一个加权后验近似。相比之下，在 SIS 中，我们从

```
\( q_t^{\text{SIS}}(\mathbf{z}_{1:t}) = q_{t-1}^{\text{SIS}}(\mathbf{z}_{1:t-1}) q_t(\mathbf{z}_t | \mathbf{z}_{1:t-1}) \) (13.23)
```

```
**Algorithm 13.2:** Sequential importance sampling with resampling (SISR)
1 Initialization: \( z_1^i \sim q_1(z_1), \tilde{w}_1^i = \frac{\tilde{\gamma}_1(z_1^i)}{q_1(z_1^i)}, W_1^i = \frac{\tilde{w}_1^i}{\sum_j \tilde{w}_1^j}, \hat{\pi}_1(z_1) = \sum_{i=1}^{N_s} W_1^i \delta(z_1 - z_1^i) \)
2 for \( t=2:T \) do
3 Compute ancestors \( \mathbf{a}_{t-1}^{1:N_s} = \text{resample}(\tilde{w}_{t-1}^{1:N_s}) \)
4 Select \( \mathbf{z}_{t-1}^{1:N_s} = \text{permute}(\mathbf{a}_{t-1}^{1:N_s}, \mathbf{z}_{t-1}^{1:N_s}) \)
5 Reset unnormalized weights \( \tilde{w}_{t-1}^{1:N_s} = 1/N_s \)
6 for \( i=1:N_s \) do
7 Sample \( z_t^i \sim q_t(z_t | \mathbf{z}_{1:t-1}^i) \)
8 Compute unnormalized weight \( \tilde{w}_t^i = \alpha_t^i = \frac{\tilde{\gamma}_t(z_{1:t}^i)}{\tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1}^i) q_t(z_t^i | \mathbf{z}_{1:t-1}^i)} \)
9 Compute normalized weights \( W_t^i = \frac{\tilde{w}_t^i}{\sum_j \tilde{w}_t^j} \) for \( i=1:N_s \)
10 Compute MC posterior \( \hat{\pi}_t(z_{1:t}) = \sum_{i=1}^{N_s} W_t^i \delta(z_{1:t} - \mathbf{z}_{1:t}^i) \)
```

我们可以分两步从方程 (13.22) 采样。首先，我们从 \( \hat{\pi}_{t-1}(\mathbf{z}_{1:t-1}) \) 重采样 \( N_s \) 个样本，得到一组新样本 \( \mathbf{z}_{1:t-1}^i \)，这些样本是 _等权重_ 的。（有关如何执行此操作的详细信息，请参见第 13.2.4 节。）然后，我们使用 \( z_t^i \sim q_t(z_t | \mathbf{z}_{1:t-1}^i) \) 扩展每个样本，并将 \( \mathbf{z}_t^i \) 连接到 \( \mathbf{z}_{1:t-1}^i \)。

做出提议后，我们计算未归一化权重。我们使用标准 SNIS 方法，但“装作”提议是由 \( \tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1}^i) q_t(\mathbf{z}_t^i | \mathbf{z}_{1:t-1}^i) \) 给出的，尽管我们实际上使用的是 \( \hat{\pi}_{t-1}(\mathbf{z}_{1:t-1}^i) q_t(\mathbf{z}_t^i | \mathbf{z}_{1:t-1}^i) \)。这样做有效的直观原因是，先前的加权近似 \( \hat{\pi}_{t-1}(\mathbf{z}_{1:t-1}^i) \) 是先前目标分布 \( \tilde{\gamma}_{t-1}(\mathbf{z}_{1:t-1}) \) 的无偏估计。（有关更多理论细节，请参见例如 [CP20b]。）然后我们计算未归一化权重，它们与增量权重相同，因为重采样步骤将 \( \tilde{w}_{t-1}^i \) 设为 1。然后我们对这些权重进行归一化，并计算目标后验 \( \hat{\pi}_t(\mathbf{z}_{1:t}) \) 的新近似。伪代码请参见算法 13.2。

### 13.2.3.1 自助滤波器

我们现在考虑 SISR 的一个特例，其中模型是 SSM，且提议分布等于动态先验：

```
\( q_t(\mathbf{z}_t | \mathbf{z}_{1:t-1}) = p(\mathbf{z}_t | \mathbf{z}_{1:t-1}) \) (13.24)
```

在这种情况下，方程 (13.21) 中的相应增量权重简化为

```
\( \alpha_t(\mathbf{z}_{1:t}) = \frac{p(\mathbf{y}_t | \mathbf{z}_{1:t}) p(\mathbf{z}_t | \mathbf{z}_{1:t-1})}{q(\mathbf{z}_t | \mathbf{z}_{1:t-1})} = \frac{p(\mathbf{y}_t | \mathbf{z}_t) p(\mathbf{z}_t | \mathbf{z}_{1:t-1})}{p(\mathbf{z}_t | \mathbf{z}_{1:t-1})} = p(\mathbf{y}_t | \mathbf{z}_{1:t}) \) (13.25)
```

这种特例称为 **自助滤波器** [Gor93] 或 **最适者生存** 算法 [KKR95]。（在计算机视觉文献中，这被称为 **凝聚** 算法，代表 "条件密度传播" [IB98]。）有关该算法工作原理的示意图，请参见图 13.2b，以及图 13.1b 中的真实数据样本结果。

自助滤波器对于我们可以从动态中采样但无法逐点评估转换模型的模型很有用。这种情况出现在某些隐式动态模型中，例如使用微分方程定义的模型（请参见例如 [IBK06]）；此类模型常用于流行病学。但是，一般来说，使用考虑当前证据 \(\mathbf{y}_t\) 的提议要高效得多。我们将在 13.3 节讨论近似此类“局部最优”提议的方法。

### 13.2.3.2 路径退化问题

在图 13.3a 中，我们展示了粒子滤波如何在应用于方程 (13.6) 的非马尔可夫示例时，产生一组多样性更高、权重更均衡的活跃粒子。虽然粒子滤波不会遭受权重退化，但它确实会遭受另一个称为 **路径退化** 的问题。这指的是，在许多步骤中“存活”（具有非可忽略权重）的粒子数量可能会随时间迅速下降，导致当我们尝试表示过去分布时出现多样性丢失。我们在图 13.3b 中对此进行了说明，其中仅包含直到最后一步每一步都经历重采样的样本的箭头。我们可以看到，在最终存活的序列集中，我们有 \(N_s = 5\) 个 \(\mathbf{z}_1^i\) 的相同副本。（当所有路径在回溯时间时汇聚于共同祖先的时间点，称为 **汇聚** 时间。）我们将在 13.2.4 节和 13.2.5 节讨论缓解此问题的一些方法。

### 13.2.3.3 估计归一化常数

我们可以使用粒子滤波来近似归一化常数 \(Z_T = p(\mathbf{y}_{1:T}) = \prod_{t=1}^T p(\mathbf{y}_t|\mathbf{y}_{1:t-1})\)，方法如下：

```
\(\hat{Z}_T = \prod_{t=1}^T \hat{Z}_t\)
```

其中，根据方程 (13.10)，我们有

```
\(\hat{Z}_t = \frac{1}{N_s} \sum_{i=1}^{N_s} \tilde{w}_t^i = \hat{Z}_{t-1} \left( \widehat{Z_t / Z_{t-1}} \right)\)
```

其中

```
\(\widehat{Z_t / Z_{t-1}} = \frac{\sum_{i=1}^{N_s} \tilde{w}_t^i}{\sum_{i=1}^{N_s} \tilde{w}_{t-1}^i}\)
```

这种边缘似然估计对于参数估计等任务非常有用。

## 13.2.4 重采样方法

重要性采样给出了一组加权粒子，\(\{(W_t^i, z_t^i) : i = 1 : N\}\)，我们可以使用以下公式近似后验期望：

```
\(\mathbb{E}[f(z_t)|y_{1:t}] \approx \sum_{i=1}^N W_t^i f(z_t^i)\)
```

假设我们按概率 \((W_t^1, \dots, W_t^N)\) 采样单个索引 \(A \in \{1, \dots, N\}\)。那么在此索引处的期望值为

```
\(\mathbb{E}[f(z_t^A)|y_{1:t}] = \sum_{i=1}^N p(A=i)f(z_t^i) = \sum_{i=1}^N W_t^i f(z_t^i)\)
```

如果我们独立采样 \(N\) 个索引并计算它们的平均值，则得到

```
\(\mathbb{E}[f(z_t)|y_{1:t}, A_{1:N}] \approx \frac{1}{N} \sum_{i=1}^N f(z_t^{A_i})\)
```

这是一种标准的无权重蒙特卡罗估计，权重为 \(W_t^i = 1/N\)。对索引求平均得到

```
\(\mathbb{E}_{A_{1:N}} \left[ \frac{1}{N} \sum_{i=1}^N f(z_t^{A_i}) \right] = \sum_{i=1}^N W_t^i f(z_t^i)\)
```

因此，使用重采样程序的输出——该程序丢弃低权重粒子并复制高权重粒子——在期望上会给出与原始加权估计相同的结果。然而，为了降低方法的方差，我们需要仔细选择重采样方法，如下面所述。

### 13.2.4.1 逆 CDF

大多数常见的重采样方法的工作原理如下。首先，我们从权重 \(W^{1:N}\) 构建累积分布，如图 13.4 的阶梯所示。（为简洁起见，我们省略了 \(t\) 索引。）然后，给定一组 \(N\) 个均匀随机变量，\(U^i \sim \text{Unif}(0, 1)\)，我们检查 \(U^i\) 落在哪个箱（区间）中；如果它落在箱 \(a\) 中，则返回索引 \(a\)，即，如果

```
\(\sum_{j=1}^{a-1} W^j \le U^i < \sum_{j=1}^a W^j\)
```
