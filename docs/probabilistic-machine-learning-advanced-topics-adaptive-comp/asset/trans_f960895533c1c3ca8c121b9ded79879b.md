### 28.3.5.2 示例：分类 PCA

我们可以通过使用以下似然函数，将第 28.3.5.1 节中的模型推广到处理分类数据：

```
$p(x | z) = \prod_d \text{Cat}(x_d | \text{softmax}(\mathbf{W}_{d:} z))$ (28.120)
```

我们称之为 **分类 PCA**（**CatPCA**）。用于拟合此模型的变分 EM 算法在 [Kha+10] 中有描述。

## 28.3.6 带有 DNN 似然的因子分析（VAEs）

FA 模型假设观测数据可以建模为来自低维高斯因子集的线性映射。放宽这一假设的一种方法是，让从 \(\boldsymbol{z}\) 到 \(\boldsymbol{x}\) 的映射成为非线性模型，例如神经网络。也就是说，似然变为

```
\(p(\boldsymbol{x}|\boldsymbol{z}) = \mathcal{N}(\boldsymbol{x}|f(\boldsymbol{z};\boldsymbol{\theta}), \sigma^2 \mathbf{I})\)
```

我们称之为“非线性因子分析”。（当然，我们可以将高斯似然替换为其他分布，例如分类分布，那样我们就得到非线性指数族因子分析。）不幸的是，我们不再能精确计算后验或极大似然估计，因此需要使用近似方法。在第 21 章中，我们讨论了变分自编码器，它使用摊销变分推断来拟合这种非线性 FA 模型。然而，也可以使用其他推断方法（例如 MCMC）来拟合相同的模型（见例：[Hof17]）。

## 28.3.7 带有 GP 似然的因子分析（GP-LVM）

在本节中，我们讨论因子分析的非线性版本，其中我们将似然 \(p(\boldsymbol{y}|\boldsymbol{z}) = \mathcal{N}(\boldsymbol{y}|f(\boldsymbol{z}), \sigma^2 \boldsymbol{I})\) 中使用的线性解码器 \(f(\boldsymbol{z}) = \mathbf{W}\boldsymbol{z}\) 替换为由高斯过程（第 18 章）表示的非线性函数，每个输出维度一个。这被称为 GP-LVM，代表“高斯过程隐变量模型” [Law05]。（注意，我们与标准 FA 相比略有更改了符号，并将观测输出变量定义为 \(\boldsymbol{y}\)，以与标准受监督 GP 符号保持一致；GP 的输入将是隐变量 \(\boldsymbol{z}\)。）

```
\(p(\boldsymbol{z}_i) = \mathcal{N}(\boldsymbol{z}_i|\mathbf{0}, \mathbf{I})\)
```

```
\(p(\boldsymbol{y}_i|\boldsymbol{z}_i, \boldsymbol{\theta}) = \mathcal{N}(\boldsymbol{y}_i|\mathbf{W}\boldsymbol{z}_i, \sigma^2 \mathbf{I})\)
```

我们可以通过最大似然法拟合此模型，通过积分消去 \(\boldsymbol{z}_i$ 并关于 \(\mathbf{W}$（和 \(\sigma^2$）最大化。目标函数由以下给出

```
\(p(\mathbf{Y}|\mathbf{W}, \sigma^2) = (2\pi)^{-DN/2}|\mathbf{C}|^{-N/2} \exp \left( -\frac{1}{2} \text{tr}(\mathbf{C}^{-1} \mathbf{Y}^\top \mathbf{Y}) \right)\)
```

其中 \(\mathbf{C} = \mathbf{W}\mathbf{W}^\top + \sigma^2 \mathbf{I}$。如我们在第 28.3.2 节中所示，\(\mathbf{W}$ 的极大似然估计可以用 \(\mathbf{Y}^\top \mathbf{Y}$ 的特征向量来计算。

现在我们考虑对偶问题，即关于 \(\mathbf{Z}$ 最大化并积分消去 \(\mathbf{W}$。我们将使用形式为 \(p(\mathbf{W}) = \prod_j \mathcal{N}(\boldsymbol{w}_j|\mathbf{0}, \mathbf{I})$ 的先验。相应的似然变为

```
\(p(\mathbf{Y}|\mathbf{Z}, \sigma^2) = \prod_{d=1}^D \mathcal{N}(\mathbf{Y}_{\cdot,d}|\mathbf{0}, \mathbf{Z}\mathbf{Z}^\top + \sigma^2 \mathbf{I})\)
```

```
\(= (2\pi)^{-DN/2}|\mathbf{K}_z|^{-D/2} \exp \left( -\frac{1}{2} \text{tr}(\mathbf{K}_\sigma^{-1} \mathbf{Y} \mathbf{Y}^\top) \right)\)
```

其中 \(\mathbf{K}_\sigma = \mathbf{K} + \sigma^2 \mathbf{I}$，且 \(\mathbf{K} = \mathbf{Z}\mathbf{Z}^\top$。\(\mathbf{Z}$ 的极大似然估计可以用 \(\mathbf{K}_\sigma$ 的特征向量来计算，并给出与 PPCA 相同的结果（详情见 [Law05]）。

图 28.19: 使用 GP-LVM 对人体运动捕捉数据进行 2D 嵌入的示意图。我们展示了两个姿态及其对应的嵌入。由 `gplvm_mocap.ipynb` 生成。经 Aditya Ravuri 友好授权使用。

为了理解此过程的作用，考虑使用带有线性核的高斯过程对 \( f : \mathcal{Z} \rightarrow \mathcal{Y} \) 的先验进行建模：

\(\mathcal{K}(\mathbf{z}_i, \mathbf{z}_j) = \mathbf{z}_i^\top \mathbf{z}_j + \sigma^2 \delta_{ij}\) (28.127)

相应的协方差矩阵形式为 \(\mathbf{K} = \mathbf{Z}\mathbf{Z}^\top + \sigma^2\mathbf{I}$。因此，方程 (28.126) 等价于一组独立高斯过程似然的乘积。正如因子分析类似于带有未知输入的线性回归，GP-LVM 也类似于带有未知输入的高斯过程回归。其目标是计算这些未知输入的点估计，即 \(\hat{\mathbf{Z}}$。（我们也可以使用贝叶斯推断。）

对偶表述的优势在于，我们可以为 \(\mathbf{K}$ 使用比线性核更通用的核。也就是说，对于任何 Mercer 核，我们可以设置 \(K_{ij} = \mathcal{K}(\mathbf{z}_i, \mathbf{z}_j)$。\(\mathbf{Z}$ 的极大似然估计不再可通过特征值方法获得，但可以使用基于梯度的优化来计算。

在图 28.19 中，我们说明该模型（带有 ARD 核）应用于一些 **动作捕捉** 数据，数据来自 CMU mocap 数据库 http://mocap.cs.cmu.edu/。每个人都有 41 个标记，其 3D 运动使用 12 台红外摄像机进行跟踪。每个数据点对应不同的身体姿态。当投影到 2D 时，我们看到相似的姿态聚集在附近。

在数据也稀疏且非负时特别有用，例如词频计数。在这种情况下，使用泊松似然是有意义的：\(p(\boldsymbol{x}|\boldsymbol{z}) = \prod_{d=1}^D \text{Poi}(x_d|\boldsymbol{w}_d^\mathsf{T}\boldsymbol{z})$。整体模型形式为

\(p(\boldsymbol{z}, \boldsymbol{x}) = p(\boldsymbol{z})p(\boldsymbol{x}|\boldsymbol{z}) = \left[ \prod_k \text{Ga}(z_k|\alpha_k, \beta_k) \right] \left[ \prod_{d=1}^D \text{Poi}(x_d|\boldsymbol{w}_d^\mathsf{T}\boldsymbol{z}) \right]\) (28.128)

得到的模型称为 **GaP**（伽马-泊松）模型 [Can04]。图形模型请参见图 28.20a。

参数 \(\alpha_k$ 和 \(\beta_k$ 控制隐表示 \(\boldsymbol{z}_n$ 的稀疏性。如果我们设置 \(\alpha_k = \beta_k = 0$，并计算 \(\mathbf{W}$ 的极大似然估计，我们就恢复了 **非负矩阵分解**（**NMF**）[PT94; LS99; LS01]，如 [BJ06] 所示。

图 28.21 说明了将 NMF 应用于面部图像块数据集的结果，其中数据对应非负像素强度。我们看到学习到的基函数是面部的小局部部分。此外，系数向量 \(\boldsymbol{z}$ 是稀疏且为正的。对于 PCA，系数向量具有负值，得到的基函数是全局而非局部的。对于向量量化（即 GMM 模型），\(\boldsymbol{z}$ 是一个 one-hot 向量，只有一个混合分量被激活；得到的权重向量对应整个图像原型。在每种情况下，重建质量相似，但学习到的隐表示的性质相当不同。
