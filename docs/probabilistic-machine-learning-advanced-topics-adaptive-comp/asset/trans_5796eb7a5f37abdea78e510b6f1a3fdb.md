

偏好在茶中加牛奶而非柠檬的人。同样，一旦你获得了柠檬，牛奶的价值就会降低，因为有些人喜欢在茶中加柠檬而非牛奶。因此，一旦你有了茶，柠檬和牛奶就是可替代的，你绝不会同时使用两者，因为柠檬只会让牛奶凝结。这些都是次模关系，f(l|m, t) < f(l|t) 和 f(m|l, t) < f(m|t)，每一个都意味着 f(l, t) + f(m, t) > f(l, m, t) + f(t)。柠檬（分别牛奶）与茶的价值，在拥有牛奶（分别柠檬）与茶的更大语境下会下降，这是次模关系的典型特征。

并非所有物品都处于次模关系，因为有时某项物品的存在会提升另一项物品的价值。例如，一旦你有了牛奶，那么当你同时获得柠檬时，茶会变得更加有价值，因为茶可以选择柠檬或牛奶，比只有牛奶这一选择的茶更有价值。同样，一旦你有了牛奶，当你获得茶时，柠檬会变得更有价值，因为只有牛奶的柠檬远不如有茶时的柠檬有价值，即使牛奶触手可及。这意味着 f(t|l, m) > f(t|m) 和 f(l|t, m) > f(l|m)，从而蕴含 f(l, m) + f(m, t) < f(l, m, t) + f(m)。这些被称为超模关系，即随着上下文的扩大，价值增加。

我们针对四个项目 V = {c, l, m, t} 的各种子集之间的一组关系提出了要求。是否存在一个函数，能为每个 X ⊆ V 提供一个值，并满足上述所有关系？图 6.19 实际上展示了这样一个函数。左侧，我们看到一个二维正方形，其顶点表示 {c, t} 子集上的值，我们可以快速验证：西北角（对应 f({c})）的蓝色方框之和与东南角（对应 f({t})）之和，大于东北角与西南角之和，从而表达了所需的次模关系。右侧是一个三维立方体，加入了柠檬的关系。现在我们有六个正方形，并看到每个顶点的值都满足上述要求——我们通过考虑立方体六个面上每个面四个角的估值来验证这一点。由于 |V| = 4，我们需要一个四维超立方体来显示所有值，并且可以用两种方式展示。首先将其显示为超方体（tesseract），即四维超立方体的一个众所周知的三维投影。在图中，所有顶点都同时标记了 V 的子集以及函数值 f(X)（作为方框中的蓝色数字）。右侧的图展示了四维超立方体的格点版本，其中相应的三维立方体以绿色和红色显示。

因此，我们看到一个集合函数定义在基集的所有子集上，并且它们对应于超立方体所有顶点上的估值。对于咖啡、柠檬、牛奶和茶的子集估值上的特定函数，我们在一个函数中看到了次模、超模和模关系。因此，图 6.19 中定义的整体函数 f 既不是次模的，也不是超模的，更不是模的。在组合拍卖中，通常希望拥有多种此类关系方式 [LLN06]——这些关系的表示可以通过次模函数的差分 [NB05; IB12] 或次模函数与超模函数的和 [BB18] 来处理（下文将进一步描述）。然而，在机器学习中，大多数时候我们关心的是到处都是次模（或模、或超模）的函数。

### 6.9.2 次模基本定义

要使一个函数为次模函数，它必须对所有子集满足次模关系。我们得到以下定义。

定义 6.9.1（次模函数）。给定的集合函数 f : 2^V -> R 是次模的，如果对于所有 X, Y ⊆ V，都有以下不等式：

$$f(X) + f(Y) \ge f(X \cup Y) + f(X \cap Y)$$ (6.218)

次模性还有许多其他等价定义 [Bil22]，其中一些更直观、更易于理解。例如，有些集合函数是满足边际收益递减性质的集合函数。如果我们将函数 f(X) 视为衡量集合 X（它是更大数据项集 X ⊆ V 的一个子集）的价值，那么次模性属性意味着：向集合 X 添加数据项 v 的增量“价值”会随着 X 的规模增大而减少。这给出了次模性的第二个经典定义。

**定义 6.9.2**（通过边际收益递减的次模函数）。给定的集合函数 f : 2^V -> R 是次模的，如果对于所有 X, Y ⊆ V（其中 X ⊆ Y）以及所有 v ∉ Y，都有以下不等式：

$$f(X + v) - f(X) \ge f(Y + v) - f(Y)$$ (6.219)

茶中柠檬的增量价值小于牛奶已在茶中时柠檬的增量价值，这一属性当我们设置 X = {m, t} 和 Y = {l, t} 时，等价于方程 6.218（即 f(m, t) + f(l, t) > f(l, m, t) + f(t)）。同样，当我们设置 X = {t}、Y = {m, t} 且 v = l 时，它也自然等价于方程 6.219（即 f(l|m, t) < f(l|t)）。

有许多函数是次模的，一个著名的例子是将香农熵视为随机变量子集上的函数。我们首先指出，存在非负（即 f(A) ≥ 0，∀A）、单调非递减（即只要 A ⊆ B 就有 f(A) ≤ f(B)）的非熵型次模函数 [Yeu91b; ZY97; ZY98]，因此次模性并非对熵函数类的平凡重述。当一个函数是单调非递减、次模，并归一化使得 f(∅) = 0 时，它通常被称为 **多聚体函数**。因此，虽然熵函数是多聚体函数，但它并不涵盖所有多聚体函数，尽管所有多聚体函数都满足克劳德·香农提到的作为“信息”函数自然应具有的属性（参见第 6.9.7 节）。

一个函数 f 是超模的，当且仅当 -f 是次模的。如果一个函数既是次模的又是超模的，它被称为 **模函数**。模函数 m : 2^V -> R 始终可以采用向量-标量对的形式。也就是说，对于任意 A ⊆ V，都有 m(A) = c + ∑_{v ∈ A} m_v，其中 c 是标量，{m_v}_{v ∈ V} 可以看作是以 V 的元素为索引的向量的元素。如果模函数归一化，使得 m(∅) = 0，那么 c = 0，模函数可以简单地看作一个向量 m ∈ R^V。因此，我们有时会说模函数 x ∈ R^V 为集合 A 提供一个值，即部分和 x(A) = ∑_{v ∈ A} x(v)。许多组合问题将模函数作为目标函数。例如，图割问题在边上定义了一个模函数，将图中的一个割判定为对构成该割的边应用模函数。

从上述内容以及考虑图 6.19 可以看出，次模函数，事实上任何集合函数 f : 2^V -> R，都可以看作是仅定义在 n 维单位超立方体 [0, 1]^n 顶点上的函数。给定任意集合 X ⊆ V，我们定义 \mathbf{1}_X ∈ {0, 1}^V 为集合 X 的特征向量，定义为：如果 v ∈ X，则 \mathbf{1}_X(v) = 1；否则 \mathbf{1}_X(v) = 0。这为我们提供了一种从任意集合 X ⊆ V 到二进制向量 \mathbf{1}_X 的映射方式。我们还看到，\mathbf{1}_X 本身也是一个模函数，因为 \mathbf{1}_X ∈ {0, 1}^V ⊂ \mathbb{R}^V。

次模函数与凸函数和凹函数 [Lov83] 共有许多性质，包括广泛的适用性、普遍性、多种表示形式，以及在若干常见算子下的封闭性（包括混合、截断、补集和某些卷积）。这里陈述的一个重要的次模封闭性质是：如果我们对次模函数取非负加权（或锥形）组合，则保留次模性。换句话说，如果我们有一组 $k$ 个次模函数，$f_i : 2^V \rightarrow \mathbb{R}$，$i \in [k]$，并且形成 $f(X) = \sum_{i=1}^k \omega_i f_i(X)$，其中所有 $i$ 的 $\omega_i \ge 0$，那么定义 6.9.1 立即表明 $f$ 也是次模的。当我们考虑定义 6.9.1 时，我们看到次模函数位于 $2^n$ 维空间中的一个锥体内，该锥体由指数数个半空间的交集定义，每个半空间均由形式为 $f(X) + f(Y) \ge f(X \cup Y) + f(X \cap Y)$ 的不等式之一定义。因此，每个次模函数都是该锥体中的一个点。因此，对这些点取锥形组合仍保持在这个锥体内，这并不令人惊讶。

### 6.9.3 次模函数示例

如上所述，除了熵之外，还有许多函数是次模的。或许最简单的这类函数是 $f(A) = \sqrt{|A|}$，它是平方根函数（凹函数）与集合 $A$ 的基数 $|A|$ 的复合。若 $|A| = k$，则增益函数为 $f(A+v) - f(A) = \sqrt{k+1} - \sqrt{k}$，我们知道它在 $k$ 上是递减的，从而确立了 $f$ 的次模性。事实上，如果 $\phi : \mathbb{R} \rightarrow \mathbb{R}$ 是任意凹函数，则出于相同原因，$f(A) = \phi(|A|)$ 将是次模的。$^8$ 再进一步推广，定义为 $f(A) = \phi(\sum_{a \in A} m(a))$ 的函数也是次模的，只要所有 $a \in V$ 的 $m(a) \ge 0$。由于 $\sum_{a \in A} m(a) = m(A)$，这产生了一个凹函数与模函数 $f(m) = \phi(m(A))$ 的复合。我们可以对这类函数求和，并添加一个最终的模函数而不损失次模性，从而得到 $f(A) = \sum_{u \in U} \phi_u(\sum_{a \in A} m_u(a)) + \sum_{a \in A} m_\pm(a)$，其中 $\phi_u$ 可以是每个 $u$ 的不同凹函数，$m_u(a)$ 是所有 $u$ 和 $a$ 的非负实数值，$m_\pm(a)$ 是任意实数。因此，$f(A) = \sum_{u \in U} \phi_u(m_u(A)) + m_\pm(A)$，其中 $m_u$ 是 $u$ 特定的非负模函数，$m_\pm$ 是任意模函数。这类函数有时被称为 **基于特征的** 次模函数 [BB17]，因为 $U$ 可以是非负特征集合（在机器学习的“词袋”意义上），并且该函数测量由特征集合 $U$ 决定的 $A$ 上的一种分散形式。例如 $f(A) = \sum_{u \in U} \phi_u(m_u(A))$ 这样的函数倾向于给由不同特征集合 $U$ 高度估值的集合 $A$ 以高多样性得分。原因在于，由于 $\phi_u$ 的凹函数特性，向参数 $m_u(A)$ 的任何添加（例如向 $A$ 添加 $v$）都会随着 $A$ 变大而减少。为了产生一个比 $A$ 更大且具有更高估值的集合，必须使用一个尚未减少那么多的不同特征 $u' \neq u$。

设施选址是另一个众所周知的次模函数——一个恰当的绰号可能是“次模函数的 k-means”，因为它的适用性、实用性、易用性（只需要一个亲和矩阵）以及与 k-medoids 问题的相似性。设施选址函数使用亲和矩阵定义如下：$f(A) = \sum_{v \in V} \max_{a \in A} \text{sim}(a, v)$，其中 $\text{sim}(a, v)$ 是元素 $a$ 和 $v$ 之间亲和力（或相似性）的非负度量。在这里，每个元素 $v \in V$ 必须在集合 $A$ 内有一个代表，并且每个 $v \in V$ 的代表被选为集合 $A$ 中最相似于 $v$ 的元素 $a$。这个函数也是一种分散形式，因为为了最大化它，每个元素 $v \in V$ 必须有某个与其相似的元素
