更详细地说，在每一步中，我们根据某个建议分布采样新状态 x' ~ q(.|x_t)。对于实值参数，这通常只是以当前迭代为中心的随机游走建议，x' = x_t + \epsilon_{t+1}，其中 \epsilon_{t+1} ~ N(0, \Sigma)。（矩阵 \Sigma 通常是对角矩阵，并可随时间使用 [Cor+87] 中的方法进行更新。）在提出新状态后，我们计算接受概率

```
\alpha_{t+1} = \exp(-(\mathcal{E}(\boldsymbol{x}') - \mathcal{E}(\boldsymbol{x}_t))/T_t)
```

其中 T_t 是系统温度。然后我们以 min(1, \alpha_{t+1}) 的概率接受新状态（即，设置 x_{t+1} = x'），否则保持当前状态（即，设置 x_{t+1} = x_t）。这意味着，如果新状态的能量较低（即更可能），我们一定会接受它；但如果新状态的能量较高（即不太可能），我们仍可能接受，具体取决于当前温度。因此，该算法允许在概率空间中进行“下坡”移动（在能量空间中为“上坡”），但随着温度降低，这种情况发生的频率会降低。

### 12.9.2 并行退火

将 MCMC 和退火相结合的另一种方法是在不同温度下并行运行多个链，并允许一个链从相邻温度的另一个链中采样。这样，高温链可以在状态空间中进行长距离移动，并影响低温链。这被称为并行退火。详情见例如 [ED05; Kat+06]。

## 13 序列蒙特卡洛

### 13.1 简介

在本章中，我们讨论 **序列蒙特卡洛** 或 **SMC** 算法，可用于从一系列相关概率分布中采样。SMC 最常用于解决状态空间模型（SSM，第 29 章）中的滤波问题，但也可以应用于其他问题，例如从静态（但可能是多模态）分布中采样，或从某个过程中的罕见事件中采样。

我们的介绍基于优秀教程 [NLS19]，与 [Aru+02] 等传统介绍不同，我们强调的是在对一系列相关变量进行采样，而不仅仅是计算 SSM 的滤波分布。这种更通用的视角将使我们能够处理静态估计问题，如我们将看到。另一个 SMC 的良好介绍，请参见 [DJ11]。关于使用 **Feynman-Kac** 形式主义对 SMC 进行更正式（测度论）的处理，请参见 [CP20b]。

### 13.1.1 问题陈述

在 SMC 中，目标是从形式为下列相关分布序列中采样：

\(\pi_t(z_{1:t}) = \frac{1}{Z_t}\tilde{\gamma}_t(z_{1:t})\)

对于 \(t=1:T\)，其中 \(\tilde{\gamma}_t\) 是未归一化的 **目标分布**，\(\pi_t\) 是归一化版本，\(z_{1:t}\) 是感兴趣的随机变量。在某些应用中（例如，SSM 中的滤波），我们关心每个中间边缘分布 \(\pi_t(z_t)\)，\(t=1:T\)；这称为 **粒子滤波**。（“粒子”一词仅表示“样本”。）在其他应用中，我们只关心最终分布 \(\pi_T(z_T)\)，中间步骤仅出于计算原因引入；这称为 **SMC 采样器**。我们将在下面简要回顾这两者，并在后续章节中详细介绍。

### 13.1.2 状态空间模型的粒子滤波

SMC 的一个重要应用是 SSM 中的序列（在线）推理（状态估计）。举个例子，考虑具有以下联合分布的马尔可夫状态空间模型：

\(\pi_T(z_{1:T}) \propto p(z_{1:T}, y_{1:T}) = p(z_1)p(y_1|z_1) \prod_{t=1}^T p(z_t|z_{t-1})p(y_t|z_t)\)

一个常见的选择是在步骤 t 处定义未归一化的目标分布为

```
\tilde{\gamma}_t(z_{1:t}) = p(z_{1:t}, y_{1:t}) = p(z_1)p(y_1|z_1) \prod_{s=1}^t p(z_s|z_{s-1})p(y_s|z_s)
```

注意，这是对（不断增长的）一系列隐性变量的分布。然而，我们通常只关心该分布的最近边缘，在这种情况下，我们只需计算 \tilde{\gamma}_t(z_t)，从而避免存储完整历史记录。

例如，考虑以下 2D 非线性跟踪问题（与第 8.3.2.3 节中的相同）：

```
p(z_t|z_{t-1}) = \mathcal{N}(z_t|f(z_{t-1}), q\mathbf{I})
p(y_t|z_t) = \mathcal{N}(y_t|z_t, r\mathbf{I})
f(z) = (z_1 + \Delta \sin(z_2), z_2 + \Delta \cos(z_1))
```

其中 \Delta 是底层连续系统的步长，q 是系统噪声的方差，r 是观测噪声的方差。（我们将 \Delta、q 和 r 视为固定常数；有关联合状态和参数估计的讨论，请参见补充部分 13.1.3。）真实底层状态轨迹及相应的带噪声测量值如图 13.1a 所示。使用 2000 个样本的简单 SMC 形式（称为引导滤波器，第 13.2.3.1 节）计算的状态后验均值估计如图 13.1b 所示。
