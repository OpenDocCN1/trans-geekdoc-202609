## 10.5 更紧的界限

改善后验近似质量的另一种方法是优化 q，使其相对于比标准 ELBO 更紧的 log 边缘似然近似界限。我们在下面给出一些示例。

### 10.5.1 多样本 ELBO (IWAE 界限)

在本节中，我们讨论一种称为**重要性加权自编码器**或**IWAE** [BGS16]的方法，它是一种通过使用自归一化重要性采样（第 11.5.2 节）来收紧变分下界的方法。（它也可以被解释为扩展模型中的标准 ELBO 最大化，其中我们添加额外的辅助变量 [CMD17; DS18; Tuc+19]。）将推理网络 q_\phi(z|x) 视为目标后验 p_\theta(z|x) 的提议分布。定义 w_s^* = \frac{p_\theta(x, z_s)}{q_\phi(z_s|x)} 为样本的非归一化重要性权重，以及 w_s = w_s^*/(\sum_{s'=1}^S w_s'^*) 为归一化重要性权重。从公式 (11.43) 我们可以使用以下公式计算边缘似然 p(x) 的估计：

```
\hat{p}_S(x|z_{1:S}) \triangleq \frac{1}{S} \sum_{s=1}^S \frac{p_\theta(x, z_s)}{q_\phi(z_s|x)} = \frac{1}{S} \sum_{s=1}^S w_s (10.166)
```

这是无偏的，即 E_{q_\phi(z_{1:S}|x)} [\hat{p}_S(x|z_{1:S})] = p(x)，其中 q_\phi(z_{1:S}|x) = \prod_{s=1}^S q_\phi(z_s|x)。此外，由于估计器始终为正，我们可以取对数，从而获得 log 似然的随机下界：

```
L_S(\phi, \theta|x) \triangleq \mathbb{E}_{q_\phi(z_{1:S}|x)} \left[ \log \left( \frac{1}{S} \sum_{s=1}^S w_s \right) \right] = \mathbb{E}_{q_\phi(z_{1:S}|x)} \left[ \log \hat{p}_S(z_{1:S}) \right] (10.167)
\le \log \mathbb{E}_{q_\phi(z_{1:S}|x)} \left[ \hat{p}_S(z_{1:S}) \right] = \log p(x) (10.168)
```

其中我们在倒数第二行使用了 Jensen 不等式，在最后一行使用了无偏性性质。这被称为**多样本 ELBO**或**IWAE 界限** [BGS16]。该表达式对 \theta 和 \phi 的梯度在公式 (10.179) 中给出。如果 S = 1，L_S 退化为标准 ELBO：

```
L_1(\phi, \theta|x) = \mathbb{E}_{q(z|x)} [\log w] = \int q_\phi(z|x) \log \frac{p_\theta(z, x)}{q_\phi(z|x)} dz (10.169)
```

可以证明 [BGS16]，增加样本数 S 保证会使界限更紧，从而使其成为 log 似然的更好的代理。直观地说，对 log 内部的 S 个样本求平均消除了每个样本 z_s 都需要解释数据 x 的必要性。这鼓励提议分布 q 比单样本变分后验更不集中。

### 10.5.1.1 优化 IWAE 界限的病理问题

不幸的是，在 IWAE 界限中增加样本数量可能会降低信噪比，导致学习到更差的模型 [Rai+18a]。直观地说，发生这种情况的原因是增加 S 降低了界限对推理网络质量的依赖，这使得 ELBO 对 \(\phi\) 的梯度信息量减少（方差更高）。

解决这个问题的一个方法是使用**双重参数化梯度估计器** [TL18b]。另一种方法是使用避免 ELBO 最大化的替代估计方法，例如使用热力学变分目标（参见第 10.5.2 节）或重新加权的 wake-sleep 算法（参见第 10.6 节）。

### 10.5.2 热力学变分目标 (TVO)

在 [MLW19; Bre+20b] 中，他们提出了**热力学变分目标**或**TVO**。这是 IWAE 的替代方法，用于创建更紧的变分界限，具有某些优势，特别是对于不可重参数化的后验（例如，离散隐变量）。该框架还与第 10.6 节的重新加权 wake-sleep 算法有密切联系，如我们将在 10.5.3 节中看到。

TVO 技术使用**热力学积分**，也称为**路径采样**，这是物理学和系统发育学中用于近似高维分布不可处理的归一化常数的一种技术（例如，参见 [GM98; LP06; FP08]）。这基于这样一个认识：计算两个未知常数的比值比计算常数本身更容易。这与退火重要性采样（第 11.5.4 节）背后的想法类似，但 TI 是确定性的。详情请参见 [MLW19; Bre+20b]。

### 10.5.3 最小化证据上界

回顾，证据下界或 ELBO 由以下给出：

```
\(\mathbf{L}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathbf{x}) = \log p_{\boldsymbol{\theta}}(\mathbf{x}) - D_{\text{KL}}(q_{\boldsymbol{\phi}}(\mathbf{z}|\mathbf{x}) \parallel p_{\boldsymbol{\theta}}(\mathbf{z}|\mathbf{x})) \le \log p_{\boldsymbol{\theta}}(\mathbf{x})\quad (10.170)\)
```

类似地，我们可以定义证据上界或**EUBO**如下：

```
\(\text{EUBO}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathbf{x}) = \log p_{\boldsymbol{\theta}}(\mathbf{x}) + D_{\text{KL}}(p_{\boldsymbol{\theta}}(\mathbf{z}|\mathbf{x}) \parallel q_{\boldsymbol{\phi}}(\mathbf{z}|\mathbf{x})) \ge \log p_{\boldsymbol{\theta}}(\mathbf{x})\quad (10.171)\)
```

将其相对于变分参数 \(\boldsymbol{\phi}\) 最小化，作为最大化 ELBO 的替代方法，在 [MLW19] 中提出，他们表明它有时可以更快地收敛到真正的 \(\log p_{\boldsymbol{\theta}}(\mathbf{x})\)。

上述界限是针对特定输入 \(\mathbf{x}\) 的。如果我们从生成模型中采样 \(\mathbf{x}\)，并将 \(\mathbb{E}_{p_{\boldsymbol{\theta}}(\mathbf{x})}[\text{EUBO}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathbf{x})]\) 相对于 \(\boldsymbol{\phi}\) 最小化，我们就恢复了 wake-sleep 算法的睡眠阶段（参见第 10.6.2 节）。

现在假设我们从经验分布中采样 \(\mathbf{x}\)，并将 \(\mathbb{E}_{p_D(\mathbf{x})}[\text{EUBO}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathbf{x})]\) 相对于 \(\boldsymbol{\phi}\) 最小化。为了近似期望，我们可以使用自归一化重要性采样，如公式 (10.188) 中所示，以得到

```
\(\nabla_{\boldsymbol{\phi}} \text{EUBO}(\boldsymbol{\theta}, \boldsymbol{\phi}|\mathbf{x}) = \sum_{s=1}^S \overline{w}_s \nabla_{\boldsymbol{\phi}} \log q_{\boldsymbol{\phi}}(\mathbf{z}^s|\mathbf{x})\quad (10.172)\)
```

其中 \(\bar{w}_s = w^{(s)} / (\sum_{s'} w^{(s')})\)，以及 \(w^{(s)} = \frac{p(\boldsymbol{x}, \boldsymbol{z}^{(s)})}{q(\boldsymbol{z}^{(s)} | \phi_t)}\)。这等同于 wake-sleep 算法中的“做梦”更新（也称为“醒着阶段 \(\phi\) 更新”）（参见第 10.6.3 节）。

## 10.6 Wake-sleep 算法

在本章中，迄今为止我们一直专注于通过最大化 ELBO 来拟合隐变量模型。这有两个主要缺点。首先，当我们有离散隐变量时，它效果不好，因为在这种情况下我们无法使用重参数化技巧；因此我们必须使用高方差估计器，例如 REINFORCE（参见第 10.2.3 节）。其次，即使在可以使用重参数化技巧的情况下，下界也可能不够紧。我们可以通过使用 IWAE 多样本界限（第 10.5.1 节）来改善紧度，但这可能反而不会导致学习到更好的模型，原因如第 10.5.1.1 节所讨论。在本节中，我们讨论一种联合训练生成模型和推理模型的不同方法，它避免了 ELBO 最大化的一些问题。该方法称为**wake-sleep 算法** [Hin+95; BB15b; Le+19; FTT19]，因为它在两个步骤之间交替：在醒着阶段，我们优化生成模型参数 \(\theta\) 以最大化观测数据的边缘似然（我们通过从推理网络绘制重要性样本来近似 \(\log p_\theta(\boldsymbol{x})\)），而在睡眠阶段，我们优化推理模型参数 \(\phi\) 以通过在标记的 \((\boldsymbol{x}, \boldsymbol{z})\) 对上训练推理网络来学习反转生成模型，其中 \(\boldsymbol{x}\) 是当前模型参数生成的样本。这可以被视为一种**自适应重要性采样**，它迭代改进其提议，同时优化模型。我们将在下面给出更多细节。

### 10.6.1 醒着阶段

在**醒着阶段**，我们最小化从经验分布到模型分布的 KL 散度：

```
\(\mathcal{L}(\boldsymbol{\theta}) = D_{\text{KL}}(p_D(\boldsymbol{x}) \| p_\theta(\boldsymbol{x})) = \mathbb{E}_{p_D(\boldsymbol{x})} \left[ -\log p_\theta(\boldsymbol{x}) \right] + \text{const}\)
```

其中 \(p_\theta(\boldsymbol{x}) = \int p_\theta(\boldsymbol{z}) p_\theta(\boldsymbol{x} | \boldsymbol{z}) d\boldsymbol{z}\)。这等同于最大化观测数据的似然：

```
\(\ell(\boldsymbol{\theta}) = \mathbb{E}_{p_D(\boldsymbol{x})}[\log p_\theta(\boldsymbol{x})]\)
```

由于 log 边缘似然 \(\log p_\theta(\boldsymbol{x})\) 无法精确计算，我们将对其进行近似。在原始 wake-sleep 论文中，他们提出使用 ELBO 下界。在 [BB15b; Le+19] 的**重新加权 wake-sleep** (RWS) 算法中，他们提出使用第 10.5.1 节的 IWAE 界限。具体来说，如果我们从推理网络中绘制 \(S\) 个样本，\(\boldsymbol{z}_s \sim q_\phi(\boldsymbol{z} | \boldsymbol{x})\)，我们得到以下估计器：

```
\(\ell(\boldsymbol{\theta} | \boldsymbol{\phi}, \boldsymbol{x}) = \log \left( \frac{1}{S} \sum_{s=1}^S w_s \right)\)
```

其中 \(w_s = \frac{p_\theta(\boldsymbol{x}, \boldsymbol{z}_s)}{q_\phi(\boldsymbol{z}_s | \boldsymbol{x})}\)。请注意，这与公式 (10.168) 中的 IWAE 界限相同。
