### 16.2.10 隐式层

到目前为止，我们主要关注显式层，它们使用 y = f(x) 指定如何将输入转换为输出。我们也可以定义隐式层，它们通过约束函数间接指定输出：

```
y \in \underset{y}{\text{argmin}} f(x, y) \text{ such that } g(x, y) = 0 (16.19)
```

寻找此受限优化问题的解的详细方法可能因问题而异。例如，我们可能需要运行内部优化例程，或调用微分方程求解器。这种方法的主要优点是内部计算不需要显式存储，从而节省大量内存。此外，一旦找到解，我们就可以通过整个层传播梯度。利用隐函数定理，这使我们可以在端到端框架内使用高级原语。更多详情，请参见 [GHC21] 和 http://implicit-layers-tutorial.org/。

## 16.3 神经网络的典型示例

在本节中，我们给出了几种用于不同任务的广泛使用的神经网络架构的“典型”示例。

### 16.3.1 多层感知机 (MLP)

多层感知机 (MLP)，也称为前馈神经网络 (FFNN)，是最简单的神经网络类型之一。它由一系列 L 个线性层组成，并与逐元素非线性函数相结合：

```
f(x; \theta) = \mathbf{W}_L \varphi_L (\mathbf{W}_{L-1} \varphi_{L-1} (\cdots \varphi_1 (\mathbf{W}_1 x) \cdots)) (16.20)
```

![](img/ca72c1626f4850f058a9edc138c1ac73_664_0.png)

图 16.10：具有 D 个输入、第 1 层 K1 个隐藏单元、第 2 层 K2 个隐藏单元和 C 个输出的前馈神经网络。\( w_{jk}^{(l)} \) 是从第 l-1 层的节点 j 到第 l 层的节点 k 的连接权重。

例如，图 16.10 显示了一个 MLP，包含 1 个 D 单元的输入层、2 个分别具有 \( K_1 \) 和 \( K_2 \) 单元的隐藏层，以及 1 个具有 C 单元的输出层。第 l 层的第 k 个隐藏单元由
\( h_k^{(l)} = \varphi_l \left( b_k^{(l)} + \sum_{j=1}^{K_{l-1}} w_{jk}^{(l)} h_j^{(l-1)} \right) \) (16.21)

其中 \( \varphi_l \) 是第 l 层的非线性激活函数。

对于分类问题，最终的非线性通常是 softmax 函数。但是，最终层也常见线性激活，这种情况下输出被解释为 logits；训练期间使用的损失函数然后在内部转换为（对数）概率。

我们也可以使用 MLP 进行回归。图 16.11 展示了如何构建 **异方差** 非线性回归模型。（“异方差”术语仅表示预测输出方差是输入相关的，而不是常数。）该函数有两个输出，分别计算 \( f_\mu(x) = \mathbb{E}[y|x,\theta] \) 和 \( f_\sigma(x) = \sqrt{\mathbb{V}[y|x,\theta]} \)。我们可以通过使用共用的“**backbone**”和两个输出“**heads**”来在这两个函数之间共享大部分层（因此也共享参数），如图 16.11 所示。对于 \( \mu \) head，我们使用线性激活，\( \varphi(a) = a \)。对于 \( \sigma \) head，我们使用 softplus 激活，\( \varphi(a) = \sigma_+(a) = \log(1 + e^a) \)。如果使用线性 heads 和非线性 backbone，则整体模型由
\( p(y|x,\theta) = \mathcal{N} \left( y | w_\mu^T f(x; w_{\text{shared}}), \sigma_+(w_\sigma^T f(x; w_{\text{shared}})) \right) \) (16.22)

### 16.3.3 自动编码器

自动编码器是一种神经网络，它使用编码器将输入 x 映射到低维潜在空间，z = fe(x)，然后尝试使用解码器重建输入，x̂ = fd(z)。该模型被训练以最小化

$\mathcal{L}(\boldsymbol{\theta}) = ||r(\boldsymbol{x}) - \boldsymbol{x}||_2^2$ (16.23)

其中 r(x) = fd(fe(x))。（我们也可以用更一般的条件对数似然替换平方误差。）3 层 AE 的示意图请参见图 16.13。

### 16.3.4 循环神经网络 (RNN)

循环神经网络 (RNN) 是具有循环层的网络，如公式 (16.15) 所示。图 16.15 对此进行了说明。形式上，这定义了序列上的以下概率分布：

```
$p(\boldsymbol{y}_{1:T}) = \sum_{\boldsymbol{h}_{1:T}} p(\boldsymbol{y}_{1:T}, \boldsymbol{h}_{1:T}) = \sum_{\boldsymbol{h}_{1:T}} \mathbb{I}(\boldsymbol{h}_1 = \boldsymbol{h}^*_1) p(\boldsymbol{y}_1 | \boldsymbol{h}_1) \prod_{t=2}^T p(\boldsymbol{y}_t | \boldsymbol{h}_t) \mathbb{I}(\boldsymbol{h}_t = f(\boldsymbol{h}_{t-1}, \boldsymbol{y}_{t-1}))$ (16.24)
```

其中 \(\boldsymbol{h}_t\) 是确定性隐藏状态，使用 \(f(\boldsymbol{h}_{t-1}, \boldsymbol{y}_{t-1})\) 从上一个隐藏状态和上一个输出计算得出。（在训练时，\(\boldsymbol{y}_{t-1}\) 是观测到的，但在预测时，它是生成的。）

在标准 RNN 中，函数 \(f\) 是一个简单的 MLP。但是，我们也可以使用注意力，根据输入与先前状态之间的相似性，有选择地更新状态向量的部分，如 **GRU**（门控循环单元）模型和 **LSTM**（长短期记忆）模型。我们还可以通过向 \(f\) 函数输入额外输入，将模型转换为条件序列模型。更多关于 RNN 的详情，请参见例如 [Mur22, Ch. 15]。

### 16.3.5 Transformer

考虑对句子中的每个单词进行分类的问题，例如使用其词性标记（名词、动词等）。也就是说，我们想要学习一个映射 \(f : \mathcal{X} \to \mathcal{Y}\)，其中 \(\mathcal{X} = \mathcal{V}^T\) 是定义在（单词）词汇表 \(\mathcal{V}\) 上的输入序列集合，\(T\) 是句子长度，而 \(\mathcal{Y} = \mathcal{T}^T\) 是定义在（标记）词汇表 \(\mathcal{T}\) 上的输出序列集合。为了在这项任务上表现良好，我们需要学习每个单词的上下文嵌入。RNN 每次处理一个 token，因此位置 \(t\) 处单词的嵌入 \(\boldsymbol{z}_t\) 取决于网络的隐藏状态 \(\boldsymbol{s}_t\)，这可能是对所有先前看到的单词的有损摘要。我们可以创建双向 RNN，以便未来单词也可以影响 \(\boldsymbol{z}_t\) 的嵌入，但这种依赖性仍然通过隐藏状态中介。另一种方法是将 \(\boldsymbol{z}_t\) 计算为句子中所有其他单词的直接函数，通过使用第 16.2.7 节讨论的注意力算子而不是使用隐藏状态。这被称为（仅编码器）**Transformer**，并被 BERT [Dev+19] 等模型使用。此想法在图 16.16 中概述。
