请注意，方程 (36.19) 仅是出现在观测数据分布中的条件期望和分布的函数（特别是，它不包含任何“do”算子）。因此，如果我们能够完全刻画观测数据分布 \(P\)，就可以将该分布映射到唯一的 ATE。

值得注意的是，\(\tau\) 与天真估计量 \(\mathbb{E}[Y|A=1] - \mathbb{E}[Y|A=0]\) 的区别，后者仅报告处理-结果关联而不调整混杂。当我们将 \(\tau\) 中的外部期望显式地写成对 \(X\) 的积分时，比较尤其清晰：

\(\tau = \int \mathbb{E}[Y \mid A=1, X]P(X)dX - \int \mathbb{E}[Y \mid A=0, X]P(X)dX\) (36.23)

我们可以通过应用期望的塔性质，以类似形式写出天真估计量：

\(\mathbb{E}[Y \mid A=1]-\mathbb{E}[Y \mid A=0] = \int \mathbb{E}[Y \mid A=1, X]P(X \mid A=1)dX - \int \mathbb{E}[Y \mid A=0, X]P(X \mid A=0)dX\) (36.24)

关键区别在于积分所使用的 \(X\) 上的概率分布。观测均值差异对混杂变量 \(X\) 的不同条件分布进行积分，这些分布取决于 \(A\) 的值。另一方面，在 ATE 估计量 \(\tau\) 中，我们对两种处理水平都使用相同的分布 \(P(X)\) 进行积分。

**重叠** 除了对因果结构的假设外，识别还要求处理分配存在足够的随机变化。

**定义 1。** 分布 \(P\) 在 \(A, X\) 上满足 **重叠**，如果对于所有 \(x\) 都有 \(0 < P(A=1|x) < 1\)。它满足 **严格重叠**，如果对于所有 \(x\) 和某些 \(\epsilon > 0\) 都有 \(\epsilon < P(A=1|x) < 1 - \epsilon\)。

重叠的要求是任何单位都可能接受处理或不接受处理。为了看出重叠的必要性，考虑在一项研究中估计药物的有效性，其中患者性别是混杂变量，但该药物仅开给男性患者。那么，给定患者为女性时，我们就会知道该患者被分配到对照组。在没有进一步假设的情况下，不可能知道药物对女性患者人群的影响，因为没有数据来告知接受处理的女性患者的预期结果，即 \(\mathbb{E}[Y \mid A=1, X=\text{female}]\)。在这种情况下，统计估计量方程 36.19 将无法识别。同样，严格重叠确保了 \(X\) 的每个层级上的条件分布可以在有限样本中估计。

在调整大量协变量（为了满足无未观测混杂）的场景中，重叠可能特别受限。那么，某些特征组合可能对处理分配具有非常高的预测能力，即使单个特征不具有。例如，年龄超过70岁且BMI大于25的男性患者很少被分配该药物。如果这些群体代表了目标人群的显著比例，或者有显著不同的处理效果，那么这个问题可能很棘手。在这种情况下，严格重叠假设对观测研究施加了非常强的限制：为了使观测研究满足重叠，混杂变量 X 的大多数维度需要紧密模拟我们在 RCT 中预期的平衡 [D'A+21]。

## 36.4.2 具有观测混杂变量的 ATE 估计

我们现在回到使用观测数据——即非实验数据——来估计 ATE。我们已经表明，在观测到处理和结果的所有共同原因的情况下，ATE 通过统计估计量 \(\tau\) 在因果上被识别。我们现在考虑使用有限数据样本估计该量的几种策略。广义上，这些技术称为后门调整。\(^2\) 回顾一下，混杂变量的定义特征是它同时影响处理和结果。因此，调整策略可能旨在解释混杂变量对观测结果的影响、对处理的影响或两者兼而有之。我们依次讨论这些策略。

2. 如我们在第 36.8 节中讨论的，这种后门调整引用了 do-calculus 返回的估计量，以消除来自后门路径的混杂。这也将这里讨论的方法推广到某些我们不观测所有共同原因的情况。

### 36.4.2.1 结果模型调整

我们从一种依赖于建模给定处理 \(A\) 和混杂变量 \(X\) 时结果 \(Y\) 的条件期望的协变量调整方法入手。这种策略通常被称为 g-computation 或结果调整。\(^3\) 首先，我们定义

**定义 2。** 条件预期结果是函数 \(Q\)，由以下给出

\(Q(a, x) = \mathbb{E}[Y|A=a, X=x].\) (36.25)

将此定义代入我们估计量 \(\tau\) 的定义，即方程 (36.19)，我们得到 \(\tau = \mathbb{E}[Q(1, x) - Q(0, x)]\)。这表明了一种估计 \(\tau\) 的程序：为 \(Q\) 拟合模型 \(\hat{Q}\)，然后报告

\(\hat{\tau}^Q \triangleq \frac{1}{n} \sum_i \hat{Q}(1, x_i) - \hat{Q}(0, x_i).\) (36.26)

为了拟合 \(\hat{Q}\)，请回顾 \(E[Y|a, x] = \text{argmin}_Q \mathbb{E}[(Y - Q(A, X)^2]\)。也就是说，（所有函数中）平方损失风险的最小化器是条件预期结果。\(^4\) 因此，为了近似 \(Q\)，我们简单地使用均方误差来拟合一个从 \(A\) 和 \(X\) 预测 \(Y\) 的预测器。

估计程序包括几个步骤。我们首先拟合模型 \(\hat{Q}\) 来预测 \(Y\)。然后，对于每个单位 \(i\)，我们预测该单位接受处理时的结果 \(\hat{Q}(1, x_i)\)，并预测其未接受处理时的结果 \(\hat{Q}(0, x_i)\)。\(^5\) 如果该单位实际上接受了处理（\(a_i = 1\)）

then \(\hat{Q}(0, x_i)\) 是我们对其未接受处理的反事实情况会发生什么的猜测。该个体处理的预期收益估计为 \(\hat{Q}(1, x_i) - \hat{Q}(0, x_i)\) —— 即接受处理与不接受处理之间预期结果的差异。最后，我们使用经验分布 \(\hat{\text{P}}(X) = 1/n \sum_i \delta_{x_i}\) 来估计关于 P(X)（混杂变量的真实总体分布）的外部期望。实际上，这意味着我们用观测数据上的平均值来替代期望（关于未知分布）。

**线性回归** 值得多说几句的是，Q 同时作为处理和所有协变量的线性函数建模的特例。也就是说，我们假设定理 2 的识别条件，并进一步假设管辖 Y 的真实因果定律（SCM）产生：\(Q(A, X) = \mathbb{E}[Y|A, X] = \mathbb{E}[f_Y(A, X, \xi)|A, X] = \beta_0 + \beta_A A + \beta_X X\)。代入可知，\(Q(1, X) - Q(0, X) = \beta_A\)（因此也有 \(\tau = \beta_A\)）。于是，平均处理效应的估计量简化为回归系数 \(\beta_A\) 的估计量。这种“拟合线性回归并报告回归系数”的方法在实践中仍然是估计两个变量之间关联的常用方式。这里的预期结果调整程序可以被视为该程序的推广，它去除了线性参数假设。

### 36.4.2.2 倾向得分调整

结果模型调整依赖于建模混杂变量与结果之间的关系。一种流行的替代方法是建模混杂变量与处理之间的关系。这种策略通过直接解决处理组和对照组中的抽样偏差来调整混杂。这种偏差源于混杂变量与处理之间的关系。直觉上，混杂的影响可以被视为由于 P(X|A = 1) 和 P(X|A = 0) 之间的差异——例如，童年时骑过马的人群比没有骑过马的人群更富裕。当我们观测到所有混杂变量 X 时，这种过度或不足代表的程度可以通过重新加权样本来消除，使得混杂变量 X 在处理组和对照组中具有相同的分布。当两组之间的混杂变量平衡时，它们之间的任何差异都必须归因于处理。平衡处理组和对照组的关键量是 **倾向得分**，它概括了混杂变量和处理之间的关系。

**定义 3。** *倾向得分是函数 g，由以下给出* \(g(x) = \text{P}(A = 1|X = x)\)。

为了在调整中使用倾向得分，我们首先以一种暗示性的形式重写估计量 \(\tau\)，利用 \(A \in \{0, 1\}\) 这一事实：

\(\tau = \mathbb{E}[\frac{YA}{g(X)} - \frac{Y(1-A)}{1-g(X)}]. \quad (36.27)\)

这个恒等式可以通过注意到 \(\mathbb{E}[YA|X] = \mathbb{E}[Y|A=1, X]\text{P}(A=1|X) + 0\)，整理得到 \(\mathbb{E}[Y|A=1, X]\)，对 \(\mathbb{E}[Y|A=0, X]\) 做同样的处理，并代入方程 (36.19) 来验证。请注意，这个恒等式只是关于统计估计量的一个数学事实——它不依赖任何因果假设，并且无论 \(\tau\) 是否可以解释为因果效应都成立。这个表达式暗示了 **反概率处理加权估计量**，即 IPTW
