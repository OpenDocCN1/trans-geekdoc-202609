# ## 10.2.3 Blackbox variational inference

In this section, we assume that we can evaluate \(\tilde{\mathcal{L}}(\boldsymbol{\psi}, \boldsymbol{z}) = \log p(\boldsymbol{z}, \boldsymbol{x}) - \log q_{\boldsymbol{\psi}}(\boldsymbol{z})\) pointwise, but we do not assume we can take gradients of this function. (For example, \(\boldsymbol{z}\) may contain discrete variables.) We are thus treating the model as a “blackbox”. Hence this approach is called **blackbox variational inference** or **BBVI** [RGB14; ASD20].

# ### 10.2.3.1 Estimating the gradient using REINFORCE

To estimate the gradient of the ELBO, we will use the **score function estimator**, also called the **REINFORCE** estimator (Section 6.3.4). In particular, suppose we write the ELBO as

\(\mathfrak{L}(\boldsymbol{\psi}) = \mathbb{E}_{q(\boldsymbol{z}|\boldsymbol{\psi})} \left[ \tilde{\mathcal{L}}(\boldsymbol{\psi}, \boldsymbol{z}) \right] = \mathbb{E}_{q(\boldsymbol{z}|\boldsymbol{\psi})} [\log p(\boldsymbol{x}, \boldsymbol{z}) - \log q(\boldsymbol{z}|\boldsymbol{\psi})]\) (10.65)

Then from Equation (6.58) we have

\(\nabla_{\boldsymbol{\psi}} \mathfrak{L}(\boldsymbol{\psi}) = \mathbb{E}_{q(\boldsymbol{z}|\boldsymbol{\psi})} \left[ \tilde{\mathcal{L}}(\boldsymbol{\psi}, \boldsymbol{z}) \nabla_{\boldsymbol{\psi}} \log q(\boldsymbol{z}|\boldsymbol{\psi}) \right]\) (10.66)
