## 15.3.7 MCMC 推断

马尔可夫链蒙特卡洛，或 MCMC，常被视为近似推断的“金标准”，因为它对后验的形式不做任何显式假设。它在第 12 章中有深入介绍，但其输出是来自后验的一组（相关）样本，从而给出了以下非参数近似：

```
$$q(\theta|\mathcal{D}) \approx \frac{1}{S} \sum_{s=1}^S \delta(\theta - \theta^s)$$ (15.151)
```

其中 $\theta^s \sim p(\theta|\mathcal{D})$。一旦我们有了样本，就可以将它们代入公式 (15.147) 来近似后验预测分布。

一种常见的 MCMC 方法称为哈密顿蒙特卡洛（第 12.5 节）；这可以利用我们计算 log joint 梯度 $\nabla_\theta \log p(\mathcal{D}, \theta)$ 的能力，以提高效率。让我们将 HMC 应用于鸢尾花分类问题的二维、二类版本，其中我们仅使用两个输入特征（花萼长度和花萼宽度）和两个类别（Virginica 和 非 Virginica）。决策边界是点 $(x_1^*, x_2^*)$ 的集合，满足 $\sigma(b + w_1 x_1^* + w_2 x_2^*) = 0.5$。这样的点必须位于以下直线上：

```
$$x_2^* = -\frac{b}{w_2} + \left( -\frac{w_1}{w_2} x_1^* \right)$$ (15.152)
```

因此，我们可以通过从后验中采样参数 $(w_1, w_2, b) \sim p(\theta|\mathcal{D})$，并将它们代入上述方程，来计算决策边界后验的 MC 近似，

## 15.3.8 其他近似推断方法

如第二部分所述，我们可以使用许多其他近似推断方法。一种常见的方法是变分推断（第 10.1 节），它将近似推断转化为一个优化问题。它通过选择近似分布 \(q(\boldsymbol{w}; \boldsymbol{\psi})\) 并优化变分参数 \(\boldsymbol{\psi}\) 来最大化证据下界（ELBO）来实现这一点。其效果是使 \(q(\boldsymbol{w}; \boldsymbol{\psi}) \approx p(\boldsymbol{w}|\mathcal{D})\)，即 KL 散度很小。解决此问题有几种方法：使用 ELBO 的随机估计（见第 10.2.1 节），使用补充部分 10.3.1.2 中的条件共轭 VI 方法，或使用创建逻辑函数二次下界的“局部” VI 方法（见补充部分 15.1）。

在在线设置中，我们可以使用假设密度滤波（ADF）来递归计算高斯近似后验 \(p(\boldsymbol{w}|\mathcal{D}_{1:t})，如第 8.6.3 节所述。

## 15.3.9 案例研究：Berkeley 录取是否对女性存在偏见？

在本节中，我们考虑来自 [McE20, 第 11.1.4 节] 的一个简单但有趣的逻辑回归示例。感兴趣的问题是 UC Berkeley 研究生院录取是否对女性存在偏见。该数据集来自一篇著名论文 [BHO75]，该论文收集了 6 个部门男性和女性的统计数据。数据表仅有 12 行，如表 15.1 所示，尽管总样本量（观察数）为 4526。我们进行回归分析，试图确定性别是否“导致”了录取率不平衡。

试图回答上述问题的一个明显方法是拟合一个二项逻辑回归模型，其中结果是录取率，输入是表示每个样本性别（男性或女性）的二元变量。编写此模型的一种方法如下：

```
$$A_i \sim \text{Bin}(N_i, \mu_i) \quad (15.153)$$
$$
\text{logit}(\mu_i) = \alpha + \beta_{\text{MALE}[i]} \quad (15.154)$$
$$
\alpha \sim \mathcal{N}(0, 10) \quad (15.155)$$
$$
\beta \sim \mathcal{N}(0, 1.5) \quad (15.156)$$
```

这里 \(A_i\) 是样本 \(i\) 的录取人数，\(N_i\) 是申请人数，且 \(\text{MALE}[i] = 1\) 当且仅当样本为男性。因此，女性病例的 log odds 为 \(\alpha\)，男性候选人的 log odds 为 \(\alpha + \beta\)。（这些参数的先验选择在第 15.3.4 节中讨论。）

上述公式在性别上是不对称的。特别是，男性的 log odds 与两个随机变量相关联，因此先验上更不确定。通常，以以下对称方式重写模型会更好：

```
$$A_i \sim \text{Bin}(N_i, \mu_i) \quad (15.157)$$
$$
\text{logit}(\mu_i) = \alpha_{\text{GENDER}[i]} \quad (15.158)$$
$$
\alpha_j \sim \mathcal{N}(0, 1.5), j \in \{1, 2\} \quad (15.159)$$
```

这里 \(\text{GENDER}[i]\) 是性别（1 表示男性，2 表示女性），因此男性的 log odds 为 \(\alpha_1\)，女性的 log odds 为 \(\alpha_2\)。

我们可以使用多种方法进行后验推断（见第 7 章）。在这里，我们使用 HMC（第 12.5 节）。我们发现 \(\alpha_1\) 的 89% 可信区间为 \([-0.29, 0.16]\)，\(\alpha_2\) 的 89% 可信区间为 \([-0.91, 0.75]\)。^2 对应的概率差分布 \(\sigma(\alpha_1) - \sigma(\alpha_2)\) 为 \([0.12, 0.16]\)，均值为 0.14。因此，似乎 Berkeley 对男性有偏爱。

然而，在下结论之前，我们应该检查模型是否有效。在图 15.9a 中，我们绘制了后验预测分布以及原始数据。我们可以看到模型对数据的拟合非常差（蓝色数据点通常在黑色预测区间之外）。特别是，我们可以看到，除 C 和 E 部门外，女性的经验录取率实际上更高，但模型称女性的录取机会应低 14%。

问题是，男性和女性申请各个部门的数量并不相等。女性倾向于不申请录取率较高的部门（如 A 和 B），而是更多地申请录取率较低的部门（如 F）。因此，尽管总体上被录取的女性较少，但在每个部门内部，女性的录取率大致相同。

2. McElreath 使用 89% 区间而非 95%，以强调这些值的任意性。差异不显著。
