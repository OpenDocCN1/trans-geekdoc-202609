

### 8.2.4.1 滤波：算法

预测步与矩形式中的更新步具有相似的结构。我们从先验 \(p(\mathbf{z}_{t-1}|\mathbf{y}_{1:t-1}, \mathbf{u}_{1:t-1}) = \mathcal{N}_c(\mathbf{z}_{t-1}|\boldsymbol{\eta}_{t-1|t-1}, \boldsymbol{\Lambda}_{t-1|t-1})\) 开始，然后计算

```
p(\mathbf{z}_t|\mathbf{y}_{1:t-1}, \mathbf{u}_{1:t}) = \mathcal{N}_c(\mathbf{z}_t|\boldsymbol{\eta}_{t|t-1}, \boldsymbol{\Lambda}_{t|t-1}) \quad (8.89)
\mathbf{M}_t = \boldsymbol{\Lambda}_{t-1|t-1} + \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \mathbf{F}_t \quad (8.90)
\mathbf{J}_t = \mathbf{Q}_t^{-1} \mathbf{F}_t \mathbf{M}_t^{-1} \quad (8.91)
\boldsymbol{\Lambda}_{t|t-1} = \mathbf{Q}_t^{-1} - \mathbf{Q}_t^{-1} \mathbf{F}_t (\boldsymbol{\Lambda}_{t-1|t-1} + \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \mathbf{F}_t)^{-1} \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \quad (8.92)
= \mathbf{Q}_t^{-1} - \mathbf{J}_t \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \quad (8.93)
= \mathbf{Q}_t^{-1} - \mathbf{J}_t \mathbf{M}_t \mathbf{J}_t^\mathsf{T} \quad (8.94)
\boldsymbol{\eta}_{t|t-1} = \mathbf{J}_t \boldsymbol{\eta}_{t-1|t-1} + \boldsymbol{\Lambda}_{t|t-1} (\mathbf{B}_t \mathbf{u}_t + \mathbf{b}_t), \quad (8.95)
```

其中 \(\mathbf{J}_t\) 类似于矩形式 Equation (8.28) 中的卡尔曼增益矩阵。根据矩阵反演引理 Equation (2.93)，我们可以看到 Equation (8.92) 是 Equation (8.24) 中给出的预测协方差 \(\boldsymbol{\Sigma}_{t|t-1}\) 的逆。

信息形式中的更新步如下：

```
p(\mathbf{z}_t|\mathbf{y}_{1:t}, \mathbf{u}_{1:t}) = \mathcal{N}_c(\mathbf{z}_t|\boldsymbol{\eta}_{t|t}, \boldsymbol{\Lambda}_{t|t}) \quad (8.96)
\boldsymbol{\Lambda}_{t|t} = \boldsymbol{\Lambda}_{t|t-1} + \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} \mathbf{H}_t \quad (8.97)
\boldsymbol{\eta}_{t|t} = \boldsymbol{\eta}_{t|t-1} + \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} (\mathbf{y}_t - \mathbf{D}_t \mathbf{u}_t - \mathbf{d}_t). \quad (8.98)
```

### 8.2.4.2 滤波：推导

对于预测步，我们首先推导 \(t, t-1\) 时隐状态的联合分布：

```
p(\mathbf{z}_{t-1}, \mathbf{z}_t|\mathbf{y}_{1:t-1}, \mathbf{u}_{1:t}) = p(\mathbf{z}_t|\mathbf{z}_{t-1}, \mathbf{u}_t) p(\mathbf{z}_{t-1}|\mathbf{y}_{1:t-1}, \mathbf{u}_{1:t-1}) \quad (8.99)
= \mathcal{N}_c(\mathbf{z}_t | \mathbf{Q}_t^{-1} (\mathbf{F}_t \mathbf{z}_{t-1} + \mathbf{B}_t \mathbf{u}_t + \mathbf{b}_t), \mathbf{Q}_t^{-1}) \quad (8.100)
\times \mathcal{N}_c(\mathbf{z}_{t-1} | \boldsymbol{\eta}_{t-1|t-1}, \boldsymbol{\Lambda}_{t-1|t-1}) \quad (8.101)
= \mathcal{N}_c(\mathbf{z}_{t-1}, \mathbf{z}_t | \boldsymbol{\eta}_{t-1,t|t}, \boldsymbol{\Lambda}_{t-1,t|t}) \quad (8.102)
```

where

```
\(\boldsymbol{\eta}_{t-1,t|t-1} = \left( \begin{array}{ c }
\boldsymbol{\eta}_{t-1|t-1} - \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} (\mathbf{B}_t \mathbf{u}_t + \mathbf{b}_t) \\
\mathbf{Q}_t^{-1} (\mathbf{B}_t \mathbf{u}_t + \mathbf{b}_t) 
\end{array} \right) \quad (8.103)\)

\(\boldsymbol{\Lambda}_{t-1,t|t-1} = \left( \begin{array}{ c c }
\boldsymbol{\Lambda}_{t-1|t-1} + \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \mathbf{F}_t & - \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \\
- \mathbf{Q}_t^{-1} \mathbf{F}_t & \mathbf{Q}_t^{-1} 
\end{array} \right) \quad (8.104)\)
```

然后可以使用第 2.3.1.4 节中的边缘化公式推导信息形式的预测参数 \(\boldsymbol{\eta}_{t|t-1}, \boldsymbol{\Lambda}_{t|t-1}\)。

对于更新步，我们从 t 时隐状态与观测的联合分布出发：

```
p(\mathbf{z}_t, \mathbf{y}_t | \mathbf{y}_{1:t-1}, \mathbf{u}_{1:t}) = p(\mathbf{y}_t | \mathbf{z}_t, \mathbf{u}_t) p(\mathbf{z}_t | \mathbf{y}_{1:t-1}, \mathbf{u}_{1:t-1}) \quad (8.105)
= \mathcal{N}_c(\mathbf{y}_t | \mathbf{R}_t^{-1} (\mathbf{H}_t \mathbf{z}_t + \mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t), \mathbf{R}_t^{-1}) \mathcal{N}_c(\mathbf{z}_t | \boldsymbol{\eta}_{t|t-1}, \boldsymbol{\Lambda}_{t|t-1}) \quad (8.106)
= \mathcal{N}_c(\mathbf{z}_t, \mathbf{y}_t | \boldsymbol{\eta}_{\mathbf{z},\mathbf{y}|t}, \boldsymbol{\Lambda}_{\mathbf{z},\mathbf{y}|t}) \quad (8.107)
```

where

```
\(\boldsymbol{\eta}_{\mathbf{z},\mathbf{y}|t} = \left( \begin{array}{ c } \boldsymbol{\eta}_{t|t-1} - \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} (\mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t) \\ \mathbf{R}_t^{-1} (\mathbf{D}_t \mathbf{u}_t + \mathbf{d}_t) \end{array} \right) \quad (8.108)\)
\(\boldsymbol{\Lambda}_{\mathbf{z},\mathbf{y}|t} = \left( \begin{array}{ c c } \boldsymbol{\Lambda}_{t|t-1} + \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} \mathbf{H}_t & - \mathbf{H}_t^\mathsf{T} \mathbf{R}_t^{-1} \\ - \mathbf{R}_t^{-1} \mathbf{H}_t & \mathbf{R}_t^{-1} \end{array} \right) \quad (8.109)\)
```

然后使用第 2.3.1.4 节中的条件公式推导信息形式的滤波参数 \(\boldsymbol{\eta}_{t|t}, \boldsymbol{\Lambda}_{t|t}\)。

### 8.2.4.3 平滑：算法

平滑方程如下：

```
p(\mathbf{z}_t | \mathbf{y}_{1:T}) = \mathcal{N}_c(\mathbf{z}_t | \boldsymbol{\eta}_{t|T}, \boldsymbol{\Lambda}_{t|T}) \quad (8.110)
\mathbf{U}_t = \mathbf{Q}_t^{-1} + \boldsymbol{\Lambda}_{t+1|T} - \boldsymbol{\Lambda}_{t+1|t} \quad (8.111)
\mathbf{L}_t = \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \mathbf{U}_t^{-1} \quad (8.112)
\boldsymbol{\Lambda}_{t|T} = \boldsymbol{\Lambda}_{t|t} + \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \mathbf{F}_t - \mathbf{L}_t \mathbf{Q}_t^{-1} \mathbf{F}_t \quad (8.113)
= \boldsymbol{\Lambda}_{t|t} + \mathbf{F}_t^\mathsf{T} \mathbf{Q}_t^{-1} \mathbf{F}_t - \mathbf{L}_t \mathbf{U}_t \mathbf{L}_t^\mathsf{T} \quad (8.114)
\boldsymbol{\eta}_{t|T} = \boldsymbol{\eta}_{t|t} + \mathbf{L}_t (\boldsymbol{\eta}_{t+1|T} - \boldsymbol{\eta}_{t+1|t}). \quad (8.115)
```

参数 \(\boldsymbol{\eta}_{t|t}\) 和 \(\boldsymbol{\Lambda}_{t|t}\) 分别是 Equation (8.98) 和 Equation (8.97) 中的滤波值。同样，\(\boldsymbol{\eta}_{t+1|t}\) 和 \(\boldsymbol{\Lambda}_{t+1|t}\) 是 Equation (8.95) 和 Equation (8.92) 中的预测参数。矩阵 \(\mathbf{L}_t\) 是 Equation (8.67) 中后向卡尔曼增益矩阵的信息形式类比。

### 8.2.4.4 平滑：推导

根据通用前向滤波后向平滑方程 Equation (8.14)，我们有

```
p(\mathbf{z}_t | \mathbf{y}_{1:T}) = p(\mathbf{z}_t | \mathbf{y}_{1:t}) \int \left[ \frac{p(\mathbf{z}_{t+1} | \mathbf{z}_t) p(\mathbf{z}_{t+1} | \mathbf{y}_{1:T})}{p(\mathbf{z}_{t+1} | \mathbf{y}_{1:t})} \right] d\mathbf{z}_{t+1} \quad (8.116)
= \int p(\mathbf{z}_t, \mathbf{z}_{t+1} | \mathbf{y}_{1:t}) \frac{p(\mathbf{z}_{t+1} | \mathbf{y}_{1:T})}{p(\mathbf{z}_{t+1} | \mathbf{y}_{1:t})} d\mathbf{z}_{t+1} \quad (8.117)
= \int \mathcal{N}_c(\mathbf{z}_t, \mathbf{z}_{t+1} | \boldsymbol{\eta}_{t,t+1|t}, \boldsymbol{\Lambda}_{t,t+1|t}) \frac{\mathcal{N}_c(\mathbf{z}_{t+1} | \boldsymbol{\eta}_{t+1|T}, \boldsymbol{\Lambda}_{t+1|T})}{\mathcal{N}_c(\mathbf{z}_{t+1} | \boldsymbol{\eta}_{t+1|t}, \boldsymbol{\Lambda}_{t+1|t})} d\mathbf{z}_{t+1} \quad (8.118)
= \int \mathcal{N}_c(\mathbf{z}_t, \mathbf{z}_{t+1} | \boldsymbol{\eta}_{t,t+1|T}, \boldsymbol{\Lambda}_{t,t+1|T}) d\mathbf{z}_{t+1}. \quad (8.119)
```

联合滤波预测分布 \(p(\mathbf{z}_t, \mathbf{z}_{t+1}|\mathbf{y}_{1:t})\) 的参数与第 8.2.4.2 节中描述的滤波推导中的参数形式完全相同：

```
\boldsymbol{\eta}_{t,t+1|t} = \begin{pmatrix} \boldsymbol{\eta}_{t|t} \\ \mathbf{0} \end{pmatrix}, \quad \boldsymbol{\Lambda}_{t,t+1|t} = \begin{pmatrix} \boldsymbol{\Lambda}_{t|t} + \mathbf{F}_{t+1}^\mathsf{T} \mathbf{Q}_{t+1}^{-1} \mathbf{F}_{t+1} & -\mathbf{F}_{t+1}^\mathsf{T} \mathbf{Q}_{t+1}^{-1} \\ -\mathbf{Q}_{t+1}^{-1} \mathbf{F}_{t+1} & \mathbf{Q}_{t+1}^{-1} \end{pmatrix}, \quad (8.120)
```

我们现在可以通过减去滤波信息并添加平滑信息来更新这个势函数，使用第 2.3.3 节中描述的操作高斯势的规则：

```
\boldsymbol{\eta}_{t,t+1|T} = \boldsymbol{\eta}_{t,t+1|t} + \begin{pmatrix} \mathbf{0} \\ \boldsymbol{\eta}_{t+1|T} \end{pmatrix} - \begin{pmatrix} \mathbf{0} \\ \boldsymbol{\eta}_{t+1|t} \end{pmatrix} = \begin{pmatrix} \boldsymbol{\eta}_{t|t} \\ \boldsymbol{\eta}_{t+1|T} - \boldsymbol{\eta}_{t+1|t} \end{pmatrix}, \quad (8.121)
```

and

```
\boldsymbol{\Lambda}_{t,t+1|T} = \boldsymbol{\Lambda}_{t,t+1|t} + \begin{pmatrix} \mathbf{0} & \mathbf{0} \\ \mathbf{0} & \boldsymbol{\Lambda}_{t+1|T} \end{pmatrix} - \begin{pmatrix} \mathbf{0} & \mathbf{0} \\ \mathbf{0} & \boldsymbol{\Lambda}_{t+1|t} \end{pmatrix} \quad (8.122)
```

```
= \begin{pmatrix} \boldsymbol{\Lambda}_{t|t} + \mathbf{F}_{t+1}^\mathsf{T} \mathbf{Q}_{t+1}^{-1} \mathbf{F}_{t+1} & -\mathbf{F}_{t+1}^\mathsf{T} \mathbf{Q}_{t+1}^{-1} \\ -\mathbf{Q}_{t+1}^{-1} \mathbf{F}_{t+1} & \mathbf{Q}_{t+1}^{-1} + \boldsymbol{\Lambda}_{t+1|T} - \boldsymbol{\Lambda}_{t+1|t} \end{pmatrix} \quad (8.123)
```

应用信息形式边缘化公式 Equation (2.85) 得到 Equation (8.115) 和 Equation (8.113)。

## 8.3 基于局部线性化的推断

在本节中，我们将卡尔曼滤波器和平滑器扩展到系统动力学和/或观测模型为非线性的情况。（我们继续假设噪声是加性高斯噪声，如 Equation (8.15) 中所示。）

基本思路是利用一阶泰勒级数展开，以之前的状态估计为基点对动力学和观测模型进行线性化，然后应用第 8.2.2 节中的标准卡尔曼滤波方程。直觉上，我们可以将此视为用非平稳线性动力系统来近似平稳非线性动力系统。这种方法称为**扩展卡尔曼滤波器**或**EKF**。

### 8.3.1 泰勒级数展开

假设 \(x \sim \mathcal{N}(\mu, \Sigma)\) 且 \(y = g(x)\)，其中 \(g : \mathbb{R}^n \to \mathbb{R}^m\) 是一个可微且可逆的函数。\(y\) 的概率密度函数由

\(p(y) = |\det \text{Jac}(g^{-1})(y)| \mathcal{N}(g^{-1}(y)|\mu, \Sigma) \quad (8.124)\)

一般来说，这难以直接计算，因此我们寻求一种近似。

假设 \(x = \mu + \delta\)，其中 \(\delta \sim \mathcal{N}(0, \Sigma)\)。那么我们可以对函数 \(g\) 进行如下的一阶泰勒级数展开：

\(g(x) = g(\mu + \delta) \approx g(\mu) + G(\mu)\delta \quad (8.125)\)

其中 \(G(\mu) = \text{Jac}(g)(\mu)\) 是 \(g\) 在 \(\mu\) 处的雅可比矩阵：

\([G(\mu)]_{jj'} = \frac{\partial g_j(x)}{\partial x_{j'}}|_{x=\mu} \quad (8.126)\)
