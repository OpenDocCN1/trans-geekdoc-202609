## 34.2.1 示例：石油野猫井

作为示例（来自 [Rai68]），考虑为石油“野猫井”钻探者面临的决策问题创建模型，野猫井钻探者是指钻探野猫井的人，野猫井是在未知为油田的地区钻探的勘探井。

假设你必须在给定地点决定是否钻探油井。你有两个可能的动作：d = 1 表示钻探，d = 0 表示不钻探。你假设有 3 种自然状态：o = 0 表示井是干井，o = 1 表示它是湿井（有一些石油），o = 2 表示它是饱和井（有大量石油）。我们可以将其表示为决策图，如图 34.4(a) 所示。

假设你的先验信念是 p(o) = [0.5, 0.3, 0.2]，你的效用函数 U(d, o) 由以下表格指定：

| | o = 0 | o = 1 | o = 2 |
|---|---|---|---|
| d = 0 | 0 | 0 | 0 |
| d = 1 | -70 | 50 | 200 |

我们可以看出，如果不钻探，不会产生成本，但也不会赚钱。如果钻探干井，损失 $70；如果钻探湿井，获得 $50；如果钻探饱和井，获得 $200。

如果除了先验知识之外没有其他信息，你应该采取什么行动？采取行动 d 的先验期望效用为

\(\text{EU}(d) = \sum_{o=0}^2 p(o)U(d, o)\) (34.25)

我们发现 EU(d = 0) = 0 且 EU(d = 1) = 20，因此最大期望效用为

\(\text{MEU} = \max\{\text{EU}(d=0), \text{EU}(d=1)\} = \max\{0, 20\} = 20\) (34.26)

因此最优动作是钻探，d* = 1。

## 34.2.2 信息弧

现在让我们考虑模型的一个小扩展，即你可以获得一种测量（称为“sounding”），它是关于油井状态的一个带噪声的指示器。因此我们在模型中添加一条 O -> S 弧。此外，我们假设 sounding 测试的结果将在我们决定是否钻探之前可用；因此我们从 S 向 D 添加一条信息弧。这在图 34.4(b) 中说明。请注意，效用取决于动作和世界的真实状态，但不取决于测量。

我们假设 sounding 变量可以处于 3 种状态之一：s = 0 是漫反射模式，暗示没有石油；s = 1 是开放反射模式，暗示有一些石油；s = 2 是封闭反射模式，暗示有大量石油。由于 S 是由 O 引起的，我们在模型中添加一条 O -> S 弧。让我们使用以下条件分布 p(S|O) 来建模传感器的可靠性：

| | s = 0 | s = 1 | s = 2 |
|---|---|---|---|
| o = 0 | 0.6 | 0.3 | 0.1 |
| o = 1 | 0.3 | 0.4 | 0.3 |
| o = 2 | 0.1 | 0.4 | 0.5 |

假设 sounding 观测值为 s。执行动作 d 的后验期望效用为

EU(d|s) = \sum_{o=0}^2 p(o|s)U(o, d) (34.27)

我们需要对每个可能的观测 s ∈ {0, 1, 2} 和每个可能的动作 d ∈ {0, 1} 计算此值。如果 s = 0，我们发现石油状态的后验分布为 p(o|s = 0) = [0.732, 0.219, 0.049]，因此 EU(d = 0|s = 0) = 0 且 EU(d = 1|s = 0) = -30.5。如果 s = 1，我们同样发现 EU(d = 0|s = 1) = 0 且 EU(d = 1|s = 1) = 32.9。如果 s = 2，我们发现 EU(d = 0|s = 2) = 0 且 EU(d = 1|s = 2) = 87.5。因此最优策略 d*(s) 如下：如果 s = 0，选择 d = 0 并获得 $0；如果 s = 1，选择 d = 1 并获得 $32.9；如果 s = 2，选择 d = 1 并获得 $87.5。

野猫井钻探者在看到实验性 sounding 之前的最大期望效用可以使用以下公式计算：

MEU = \sum_s p(s)EU(d^*(s)|s) (34.28)

其中测试结果的先验边缘分布为 p(s) = \sum_o p(o)p(s|o) = [0.41, 0.35, 0.24]。因此 MEU 为

MEU = 0.41 \times 0 + 0.35 \times 32.9 + 0.24 \times 87.5 = 32.2 (34.29)

这些数字可以总结在图 34.5 所示的决策树中。

## 34.2.3 信息的价值

现在假设你可以选择是否进行测试。这可以建模为图 34.4(c) 所示，其中我们添加一个新的测试节点 T。如果 T = 1，我们进行测试，S 可以进入状态 {0, 1, 2}，由 O 决定，完全如上所述。如果 T = 0，我们不进行测试，S 进入一个特殊的未知状态。进行测试还存在一些相关成本。

![](img/ca72c1626f4850f058a9edc138c1ac73_1135_0.png)

图 34.5：石油野猫井问题的决策树。黑色圆圈是机会变量，黑色方形是决策节点，菱形是结果效用。绿色叶节点的效用高于红色叶节点。

是否值得进行测试？这取决于如果我们知道测试结果（即 S 的状态），我们的 MEU 会变化多少。如果不进行测试，根据方程 (34.26)，我们的 MEU = 20。如果进行测试，根据方程 (34.29)，MEU = 32.2。因此，如果进行测试（并根据其结果采取最优行动），效用的提高为 $12.2。这被称为 **完美信息的价值**（VPI）。因此，只要测试成本低于 $12.2，我们就应该进行测试。在图形模型方面，变量 S 的 VPI 可以通过计算图 34.4(b) 中基础影响图 G 的 MEU，然后计算同一影响图的 MEU（其中我们从 S 向动作节点添加信息弧），然后计算差值来确定。换句话说，

VPI = MEU(G + S -> D) - MEU(G)

其中 D 是决策节点，S 是我们要测量的变量。这将告诉我们是否值得获取测量 S。

## 34.2.4 计算最优策略

一般来说，给定一个影响图，我们可以通过修改变量消去算法（第 9.5 节）来自动计算最优策略，如 [LN01; KM08] 中所述。基本思路是从最终动作开始向后推导，在每一步计算最优决策，假设所有后续动作都被最优选择。当影响图具有简单的链式结构时，如马尔可夫决策过程（第 34.5 节），结果等同于贝尔曼方程（第 34.5.5 节）。

## 34.3 A/B 测试

假设你正在尝试决定哪个版本的产品更可能销售更多，或哪个版本的药物更可能效果更好。让我们称你正在选择的版本为 A 和 B；有时版本 A 称为 **控制组**，版本 B 称为 **处理组**。（有时不同的动作被称为“臂”。）

解决这类问题的一种非常常见的方法是使用 **A/B 测试**，即随机为不同的人群子集分配不同的动作，尝试两种动作一段时间，然后测量每种动作产生的累积 **奖励**，并选择胜出者。（这有时被称为“测试并推广”方法，因为你测试哪种方法最好，然后将其推广给其余人群。）

A/B 测试中的一个关键问题是在测试阶段获得可能带有噪声的结果后，制定一个决策规则或策略来决定哪种动作最好。另一个问题是选择分配多少人给处理组 $n_1$，多少人给控制组 $n_0$。基本的权衡在于，使用更大的 $n_1$ 和 $n_0$ 值将帮助你收集更多数据，从而在选择最佳动作时更有信心，但这会产生 **机会成本**，因为测试阶段涉及执行可能无法产生最高奖励的动作。（这是探索-利用权衡的一个示例，我们将在 34.4.3 节中进一步讨论。）在本节中，我们按照 [FB19] 的介绍，对该问题给出了一个简单的贝叶斯决策理论分析。$^2$ 有关 A/B 测试的更多细节可以在 [KTX20] 中找到。

### 34.3.1 贝叶斯方法

我们假设动作 $j$ 的第 $i$ 个奖励由 $Y_{ij} \sim \mathcal{N}(\mu_j, \sigma_j^2)$ 给出，其中 $i=1:n_j$ 且 $j=0:1$，其中 $j=0$ 对应控制组（动作 A），$j=1$ 对应处理组（动作 B），$n_j$ 是从组 $j$ 收集的样本数量。参数 $\mu_j$ 是动作 $j$ 的预期奖励；我们的目标是估计这些参数。（为简单起见，我们假设 $\sigma_j^2$ 是已知的。）

我们将采用贝叶斯方法，它非常适合序列决策问题。为简单起见，我们将对未知参数使用高斯先验，$\mu_j \sim \mathcal{N}(m_j, \tau_j^2)$，其中 $m_j$ 是动作 $j$ 的先验平均奖励，$\tau_j$ 是我们对该先验的信心。我们假设先验参数是已知的。（在实践中，我们可以使用经验贝叶斯方法，如 34.3.2 节中所讨论。）

#### 34.3.1.1 最优策略

最初，我们假设实验的样本量（即处理组的 $n_1$ 和控制组的 $n_0$ 的值）是已知的。我们的目标是计算最优策略或决策规则 $\pi(\boldsymbol{y}_1, \boldsymbol{y}_0)$，它指定应部署哪种动作，其中 $\boldsymbol{y}_j = (y_{1j}, \dots, y_{n_jj})$ 是动作 $j$ 的数据。

最优策略很简单：选择后验期望奖励更大的动作：

\(\pi^*(\boldsymbol{y}_1, \boldsymbol{y}_0) = \begin{cases} 1 & \text{if } \mathbb{E}[\mu_1|\boldsymbol{y}_1] \ge \mathbb{E}[\mu_0|\boldsymbol{y}_0] \\ 0 & \text{if } \mathbb{E}[\mu_1|\boldsymbol{y}_1] < \mathbb{E}[\mu_0|\boldsymbol{y}_0] \end{cases}\)

(34.31)
