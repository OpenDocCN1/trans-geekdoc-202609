# 17.5.1 Sequential Laplace for DNNs

In [RBB18b], they extended the Laplace method of Section 17.3.2 to the sequential setting. Specifically, let \(p(\theta|\mathcal{D}_{1:t-1}) \approx \mathcal{N}(\theta|\mu_{t-1}, \Lambda_{t-1}^{-1})\) be the approximate posterior from the previous step; we assume the precision matrix is Kronecker factored. We now compute the new mean by solving the MAP problem

```
\(\mu_t = \text{argmax} \log p(\mathcal{D}_t|\theta) + \log p(\theta|\mathcal{D}_{t-1})\) (17.38)
```

```
\(= \text{argmax} \log p(\mathcal{D}_t|\theta) - \frac{1}{2}(\theta - \mu_{t-1})\Lambda_{t-1}^{-1}(\theta - \mu_{t-1})\) (17.39)
```

Once we have computed \(\mu_t\), we compute the approximate Hessian at this point, and get the new posterior precision

```
\(\Lambda_t = \lambda \mathbf{H}(\mu_t) + \Lambda_{t-1}\) (17.40)
```
