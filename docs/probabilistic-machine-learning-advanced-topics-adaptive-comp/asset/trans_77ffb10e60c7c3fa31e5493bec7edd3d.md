## 28.2.4 将 GMM 作为逆成像问题的先验

在本节中，我们考虑将 GMM 用作黑盒密度模型，以正则化多对一映射的反演。具体来说，我们考虑从损坏版本 y 推断“干净”图像 x 的问题。我们使用形式的线性高斯前向模型

```
p(y|x) = N(y|Wx, σ²I) (28.16)
```

其中 \(\sigma^2\) 是测量噪声的方差。矩阵 \(\mathbf{W}\) 的形式取决于损坏的性质，为简化起见，我们假设其已知。以下是我们方法中可以建模的几种常见损坏示例：

- 如果损坏是由于加性噪声引起的（如图 28.4a 所示），我们可以设置 \(\mathbf{W} = \mathbf{I}\)。由此得到的 MAP 估计可用于**图像去噪**，如图 28.4b 所示。
- 如果损坏是由于模糊引起的（如图 28.4c 所示），我们可以将 \(\mathbf{W}\) 设置为固定卷积核 [KF09b]。由此得到的 MAP 估计可用于**图像去模糊**，如图 28.4d 所示。
- 如果损坏是由于遮挡引起的（如图 28.4e 所示），我们可以将 \(\mathbf{W}\) 设置为对角矩阵，在遮挡物对应的位置为 0。由此得到的 MAP 估计可用于**图像修复**，如图 28.4f 所示。
- 如果损坏是由于下采样引起的，我们可以将 \(\mathbf{W}\) 设置为卷积核。由此得到的 MAP 估计可用于**图像超分辨率**。

由此可见，线性高斯似然模型出奇地灵活。给定模型，我们的目标是通过计算 MAP 估计 \(\hat{\mathbf{x}} = \arg\max p(\mathbf{x}|\mathbf{y})\) 来反演它。然而，反演此模型的问题是不适定的，因为存在许多可能的隐式图像 \(\mathbf{x}\) 映射到同一观测图像 \(\mathbf{y}\)。因此，我们需要使用先验来正则化反演过程。

在 [ZW11] 中，他们提出将图像分块，并为每个块 \(i\) 使用形式为 \(p(\mathbf{x}_i) = \sum_k p(c_i=k)\mathcal{N}(\mathbf{x}_i|\boldsymbol{\mu}_k, \boldsymbol{\Sigma}_k)\) 的 GMM 先验。他们使用 \(K=200\) 个混合分量，并在 2M 个干净图像块的数据集上拟合 GMM。

要计算 MAP 混合分量 \(c_i^*\)，我们可以边际化掉 \(\mathbf{x}_i\) 并使用公式 (2.129) 计算边际似然

```
\(c_i^* = \arg\max_c p(c)p(\mathbf{y}_i|c) = \arg\max_c p(c)\mathcal{N}(\mathbf{y}_i|\mathbf{W}\boldsymbol{\mu}_c, \sigma^2\mathbf{I} + \mathbf{W}\mathbf{\Sigma}_c\mathbf{W}^T)\) (28.17)
```

然后我们可以通过使用近似来近似隐式块 \(\mathbf{x}_i\) 的 MAP

```
\(p(\mathbf{x}_i|\mathbf{y}_i) \approx p(\mathbf{x}_i|\mathbf{y}_i, c_i^*) \propto \mathcal{N}(\mathbf{x}_i|\boldsymbol{\mu}_{c_i^*}, \mathbf{\Sigma}_{c_i^*})\mathcal{N}(\mathbf{y}_i|\mathbf{W}\mathbf{x}_i, \sigma^2\mathbf{I})\) (28.18)
```

如果我们知道 \(c_i^*\)，我们可以使用公式 (2.121) 中高斯的贝叶斯法则来计算上述内容。

为了将此方法应用于全图像，[ZW11] 优化以下目标函数

```
\(E(\mathbf{x}|\mathbf{y}) = \frac{1}{2\sigma^2}||\mathbf{Wx} - \mathbf{y}||^2 - \text{EPLL}(\mathbf{x})\) (28.19)
```

其中 EPLL 是“预期块对数似然”，由以下给出

```
\(\text{EPLL}(\mathbf{x}) = \sum_i \log p(\mathbf{P}_i\mathbf{x})\) (28.20)
```

其中 \(\mathbf{x}_i = \mathbf{P}_i\mathbf{x}\) 是由投影矩阵 \(\mathbf{P}_i\) 计算的第 \(i\) 个块。由于这些块重叠，这不是一个有效的似然，因为它重复计算了像素。尽管如此，优化此目标函数（使用一种称为“半二次分割”的方法）在实证上效果良好。参见图 28.4，了解此过程的示例。

### 28.2.4.1 该方法为何有效？

要理解如此简单的图像块模型为何效果如此好，请注意，使用混合分量 $k$ 的单个隐式图像块 $x_i$ 的对数先验可以写成如下形式：

```
log p(x_i|c_i = k) = log N(x_i|0, \Sigma_k) = -x_i^\top \Sigma_k^{-1} x_i + a_k (28.21)
```

其中 $a_k$ 是只依赖于 $k$ 但与 $x_i$ 无关的常数。令 $\Sigma_k = V_k \Lambda_k V_k^\top$ 成为 $\Sigma_k$ 的特征分解，其中 $\lambda_{k,d}$ 是 $\Sigma_k$ 的第 $d$ 个特征值，$v_{k,d}$ 是第 $d$ 个特征向量。然后我们可以将上述内容重写如下：

```
log p(x_i|c_i = k) = - \sum_{d=1}^D \frac{1}{\lambda_{k,d}} (v_{k,d}^\top x_i)^2 + a_k (28.22)
```

由此可见，特征向量充当模板。每个混合分量都有一组不同的模板，每个模板都有自己的权重（特征值），如图 28.5 所示。通过将这些混合在一起，我们得到一个对自然图像块统计特性的强大模型。（有关该简单模型为何效果如此好的更多分析，请参见 [ZW12]，该分析基于图像形成的“枯叶”模型。）

### 28.2.4.2 使用判别模型加速推断

虽说简单有效，但如果图像很大，为每个图像块计算 \( f(\mathbf{y}) = \text{argmax}_x p(x|\mathbf{y}) \) 可能会很慢。但是，每次解决此问题时，我们都可以存储结果，并积累一个 \( (\mathbf{y}, f(\mathbf{y})) \) 对的数据集。然后我们可以训练一个摊销推断网络（第 10.1.5 节）来学习此 \( \mathbf{y} \rightarrow f(\mathbf{y}) \) 映射，以加快未来的推断，如 [RW15] 所提。（另见 [Par+19] 以获取进一步的加速技巧。）

另一种方法是放弃生成模型，并在形式为 \( (\mathbf{y}, \mathbf{x}) \) 的人工创建数据集上进行训练，其中 \( \mathbf{x} \) 是干净自然图像，\( \mathbf{y} = C(\mathbf{x}) \) 是其人工损坏版本。然后我们可以直接从 \( (\mathbf{y}, \mathbf{x}) \) 对训练判别模型 \( \hat{f}(\mathbf{y}) \)。该技术效果很好（例如，参见 [Luc+18]），但受其训练所基于的损坏形式 \( C\) 的限制。这意味着我们需要为每个线性算子 \( \mathbf{W} \)（有时甚至为每个不同的噪声水平 \( \sigma^2 \)）训练不同的网络。

### 28.2.4.3 盲反演问题

在上述讨论中，我们假设前向模型的形式为 \( p(\mathbf{y}|\mathbf{x}, \theta) = \mathcal{N}(\mathbf{y}|\mathbf{Wx}, \sigma^2\mathbf{I}) \)，其中 \( \mathbf{W} \) 已知。如果 \( \mathbf{W} \) 未知，则计算 \( p(\mathbf{x}|\mathbf{y}) \) 被称为**盲反演问题**。

此类问题更难求解。一种方法是使用类似 EM 的方法，从来自同一似然函数的一组图像中估计前向模型的参数 \( \mathbf{W} \) 和隐式图像 \( \mathbf{x} \)。也就是说，我们在 E 步中交替估计 \( \hat{\mathbf{x}} = \text{argmax}_x p(\mathbf{x}|\mathbf{y}, \hat{\mathbf{W}}) \)，在 M 步中估计 \( \hat{\mathbf{W}} = \text{argmax}_\mathbf{W} p(\mathbf{y}|\hat{\mathbf{x}}, \mathbf{W}) \)。[Ani+18] 显示了该方法的一些令人鼓舞的结果。（他们对 \( p(\mathbf{x}) \) 使用 GAN 先验，而不是 GMM。）

在我们从同一基础图像 \( \mathbf{x} \) 生成两个独立噪声样本 \( \mathbf{y}_1 \) 和 \( \mathbf{y}_2 \) 的情况下，我们可以避免显式学习图像先验 \( p(\mathbf{x}) \)，而是直接利用一种循环一致性形式学习后验众数的估计器 \( f(\mathbf{y}) = \text{argmax}_x p(\mathbf{x}|\mathbf{y}) \)，而无需访问隐式图像 \( \mathbf{x} \)；详情请参见 [XC19]。

## 28.2.5 将混合模型用于分类问题

可以使用混合模型在生成式分类器中定义类条件密度 \( p(\mathbf{x}|y=c) \)。然后我们可以使用贝叶斯法则推导类后验：

\( p(y=c|\mathbf{x}) = \frac{p(y=c)p(\mathbf{x}|y=c)}{\sum_{c'} p(y=c)p(\mathbf{x}|y=c)} = \frac{p(y=c)p(\mathbf{x}|y=c)}{Z} \tag{28.23} \)

其中 \( p(y=c) = \pi_c \) 是类标签 \( c \) 的先验，\( Z \) 是归一化常数，而 \( p(\mathbf{x}|y=c) \) 的形式取决于我们拥有的数据类型。对于实值特征，通常使用 GMM：

\( p(\mathbf{x}|y=c) = \sum_{k=1}^{K_c} \alpha_{c,k} \mathcal{N}(\mathbf{x}|\mu_{c,k}, \Sigma_{c,k}) \tag{28.24} \)

使用生成模型进行分类在处理缺失数据时很有用，因为我们可以计算 \( p(\mathbf{x}^v|y=c) = \sum_{\mathbf{x}^m} p(\mathbf{x}^m, \mathbf{x}^v|y=c) \) 来计算可见特征 \( \mathbf{x}^v \) 的边际似然。它对半监督学习也很有用，因为我们可以优化模型以拟合标记数据上的 \( \sum_n \log p(\mathbf{x}_n^l, y_n^l) \) 和未标记数据上的 \( \sum_n \log p(\mathbf{x}_n^u) \)。
