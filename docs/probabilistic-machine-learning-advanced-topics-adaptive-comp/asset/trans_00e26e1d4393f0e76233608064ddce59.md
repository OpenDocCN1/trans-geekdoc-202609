## 29.11.2 示例：随机波动率模型

在金融领域，建模**对数收益率** \(y_t = \log(p_t/p_{t-1})\) 很常见，其中 \(p_t\) 是时间 \(t\) 时某资产的价格。对该问题的常见模型，称为**随机波动率模型**（见，例如，[KSC98]），形式如下：

```
\(y_t = \boldsymbol{u}_t^\top \boldsymbol{\beta} + \exp(z_t/2)r_t\)
\(z_t = \mu + \rho(z_{t-1} - \mu) + \sigma q_t\)
\(r_t \sim \mathcal{N}(0, 1)\)
\(q_t \sim \mathcal{N}(0, 1)\)
```

我们可以看到动态模型是一个一阶自回归过程。我们通常要求 \(|\rho| < 1\)，以确保系统是平稳的。观测模型是高斯分布，但可以替换为重尾分布，如学生t分布。

我们可以通过使用更高阶自回归过程来捕获更长的时间相关性。为此，我们只需将状态空间扩展以包含过去 \(K\) 个值。例如，如果 \(K=2\)，则有

\(\begin{pmatrix} z_t - \mu \\ z_{t-1} - \mu \end{pmatrix} = \begin{pmatrix} \rho_1 & \rho_2 \\ 1 & 0 \end{pmatrix} \begin{pmatrix} z_{t-1} - \mu \\ z_{t-2} - \mu \end{pmatrix} + \begin{pmatrix} q_t \\ 0 \end{pmatrix} \tag{29.133}\)

其中 \(q_t \sim \mathcal{N}(0, \sigma_z^2)\)。因此我们有

\(z_t = \mu + \rho_1(z_{t-1} - \mu) + \rho_2(z_{t-2} - \mu) + q_t \tag{29.134}\)

## 29.12 结构时间系列模型

在本节中，我们讨论**时间序列预测**，即给定直到当前为止的数据，计算未来观测上的预测分布的问题，即计算 \(p(\mathbf{y}_{t+h} | \mathbf{y}_{1:t})\)。（模型可以选择性地条件于已知的未来输入，以获得 \(p(\mathbf{y}_{t+h} | \mathbf{y}_{1:t}, \mathbf{u}_{1:t+h})\)。）对于此问题有许多方法（见，例如，[HA21]），但在本节中，我们专注于**结构时间系列（STS）**模型，这些模型定义为线性-高斯 SSM。

许多经典时间序列方法，例如**ARMA**（自回归移动平均）方法，可以表示为 STS 模型（见，例如，[Har90; CK07; DK12; PFW21]）。然而，STS 方法具有更大的灵活性。例如，我们可以创建非线性、非高斯甚至层次扩展，如下文所述。

### 29.12.1 引言

STS 模型的基本思想是将观测的标量时间序列表示为 \(C\) 个单独分量的和：

\(f(t) = f_1(t) + f_2(t) + \cdots + f_C(t) + \epsilon_t \tag{29.135}\)

其中 \(\epsilon_t \sim \mathcal{N}(0, \sigma^2)\)。例如，我们可能有一个季节性分量，导致观测值上下波动，以及一个增长分量，导致观测值随时间增大。每个隐性过程 \(f_c(t)\) 由线性高斯状态空间模型建模，（在此语境下）也称为**动态线性模型（DLM）**。由于这些都是线性的，我们可以将它们全部合并为一个单一的 LG-SSM。特别是，在标量观测的情况下，模型形式为

\(p(\mathbf{z}_t | \mathbf{z}_{t-1}, \boldsymbol{\theta}) = \mathcal{N}(\mathbf{z}_t | \mathbf{F}\mathbf{z}_{t-1}, \mathbf{Q}) \tag{29.136}\)
\(p(y_t | \mathbf{z}_t, \boldsymbol{\theta}) = \mathcal{N}(y_t | \mathbf{H}\mathbf{z}_t + \boldsymbol{\beta}^\top \mathbf{u}_t, \sigma_y^2) \tag{29.137}\)

其中 \(\mathbf{F}\) 和 \(\mathbf{Q}\) 是分块结构矩阵，每个分量对应一个块。向量 \(\mathbf{H}\) 然后将每个分量的所有相关部分相加以生成总体均值。请注意，矩阵 **F** 和 **H** 是固定的稀疏矩阵，可从模型相应分量的形式推导，如下文所述。因此，唯一的模型参数是方差项 **Q** 和 \(\sigma_y^2\)，以及可选的回归系数 \(\boldsymbol{\beta}\)。我们可以将其推广到向量值观测，如下所示：

```
p(\boldsymbol{z}_t | \boldsymbol{z}_{t-1}, \boldsymbol{\theta}) = \mathcal{N}(\boldsymbol{z}_t | \mathbf{F} \boldsymbol{z}_{t-1}, \mathbf{Q})   (29.138)
p(\boldsymbol{y}_t | \boldsymbol{z}_t, \boldsymbol{\theta}) = \mathcal{N}(\boldsymbol{y}_t | \mathbf{H} \boldsymbol{z}_t + \mathbf{D} \boldsymbol{u}_t, \mathbf{R})   (29.139)
```

### 29.12.2 结构构建块

在本节中，我们讨论常见 STS 模型的构建块。

### 29.12.2.1 局部水平模型

最简单的隐性动态过程称为**局部水平模型**。它假设观测 \(y_t \in \mathbb{R}\) 由具有（隐性）均值 \(\mu_t\) 的高斯分布生成，该均值随时间根据随机游走演变：

\(y_t = \mu_t + \epsilon_{y,t}, \quad \epsilon_{y,t} \sim \mathcal{N}(0, \sigma_y^2)   (29.140)\)
\(\mu_t = \mu_{t-1} + \epsilon_{\mu,t}, \quad \epsilon_{\mu,t} \sim \mathcal{N}(0, \sigma_\mu^2)   (29.141)\)

我们还假设 \(\mu_1 \sim \mathcal{N}(0, \sigma_\mu^2)\)。因此，任何未来步骤的隐性均值分布为 \(\mu_t \sim \mathcal{N}(0, t \sigma_\mu^2)\)，方差随时间增长。我们也可以使用自回归（AR）过程，\(\mu_t = \rho \mu_{t-1} + \epsilon_{\mu,t}\)，其中 \(|\rho| < 1\)。这具有平稳分布 \(\mu_\infty \sim \mathcal{N}(0, \frac{\sigma_\mu^2}{1-\rho^2})\)，因此不确定性增长到有限渐近线，而不是无限增长。

### 29.12.2.2 局部线性模型

许多时间序列表现出向上或向下的线性趋势，至少在局部上是如此。我们可以通过让水平 \(\mu_t\) 在每个步骤中变化 \(\delta_{t-1}\)（表示在间隔 \(\Delta t = 1\) 上的直线斜率）来建模此过程

\(\mu_t = \mu_{t-1} + \delta_{t-1} + \epsilon_{\mu,t}   (29.142)\)

斜率本身也遵循随机游走，

\(\delta_t = \delta_{t-1} + \epsilon_{\delta,t}   (29.143)\)

且 \(\epsilon_{\delta,t} \sim \mathcal{N}(0, \sigma_\delta^2)\)。这称为**局部线性趋势模型**。

我们可以通过定义以下动态模型来结合这两个过程：

\(\begin{pmatrix} \mu_t \\ \delta_t \end{pmatrix} = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix} \begin{pmatrix} \mu_{t-1} \\ \delta_{t-1} \end{pmatrix} + \begin{pmatrix} \epsilon_{\mu,t} \\ \epsilon_{\delta,t} \end{pmatrix}   (29.144)\)
\(\underbrace{}_{z_t} \quad \underbrace{}_{F} \quad \underbrace{}_{z_{t-1}} \quad \underbrace{}_{\epsilon_t}\)

- 4. 在统计学界，符号通常遵循 [DK12]，他们将动态写为 \(\boldsymbol{\alpha}_t = \mathbf{T}_t \boldsymbol{\alpha}_{t-1} + \mathbf{c}_t \mathbf{R}_t \boldsymbol{\eta}_t\)，将观测写为 \(y_t = \mathbf{Z}_t \boldsymbol{\alpha}_t + \boldsymbol{\beta}^T \mathbf{x}_t + H_t \epsilon_t\)，其中 \(\boldsymbol{\eta}_t \sim \mathcal{N}(\mathbf{0}, \mathbf{I})\) 且 \(\epsilon_t \sim \mathcal{N}(0, 1)\)。
