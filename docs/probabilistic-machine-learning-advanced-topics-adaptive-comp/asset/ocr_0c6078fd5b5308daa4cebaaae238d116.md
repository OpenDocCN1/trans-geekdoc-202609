where \(\bar{w}_s = w^{(s)} / (\sum_{s'} w^{(s')})\), and \(w^{(s)} = \frac{p(\boldsymbol{x}, \boldsymbol{z}^{(s)})}{q(\boldsymbol{z}^{(s)} | \phi_t)}\). This is equivalent to the “daydream” update (aka “wake-phase \(\phi\) update”) of the wake-sleep algorithm (see Section 10.6.3).

# 10.6 Wake-sleep algorithm

So far in this chapter we have focused on fitting latent variable models by maximizing the ELBO. This has two main drawbacks. First, it does not work well when we have discrete latent variables, because in such cases we cannot use the reparameterization trick; thus we have to use higher variance estimators, such as REINFORCE (see Section 10.2.3). Second, even in the case where we can use the reparameterization trick, the lower bound may not be very tight. We can improve the tightness by using the IWAE multi-sample bound (Section 10.5.1), but paradoxically this may not result in learning a better model, for reasons discussed in Section 10.5.1.1. In this section, we discuss a different way to jointly train generative and inference models, which avoids some of the problems with ELBO maximization. The method is known as the **wake-sleep algorithm** [Hin+95; BB15b; Le+19; FTT19]. because it alternates between two steps: in the wake phase, we optimize the generative model parameters \(\theta\) to maximize the marginal likelihood of the observed data (we approximate \(\log p_\theta(\boldsymbol{x})\) by drawing importance samples from the inference network), and in the sleep phase, we optimize the inference model parameters \(\phi\) to learn to invert the generative model by training the inference network on labeled \((\boldsymbol{x}, \boldsymbol{z})\) pairs, where \(\boldsymbol{x}\) are samples generated by the current model parameters. This can be viewed as a form of **adaptive importance sampling**, which iteratively improves its proposal, while simultaneously optimizing the model. We give further details below.

# 10.6.1 Wake phase

In the **wake phase**, we minimize the KL divergence from the empirical distribution to the model’s distribution:

```
\(\mathcal{L}(\boldsymbol{\theta}) = D_{\text{KL}}(p_D(\boldsymbol{x}) \| p_\theta(\boldsymbol{x})) = \mathbb{E}_{p_D(\boldsymbol{x})} \left[ -\log p_\theta(\boldsymbol{x}) \right] + \text{const}\)
```

where \(p_\theta(\boldsymbol{x}) = \int p_\theta(\boldsymbol{z}) p_\theta(\boldsymbol{x} | \boldsymbol{z}) d\boldsymbol{z}\). This is equivalent to maximizing the likelihood of the observed data:

```
\(\ell(\boldsymbol{\theta}) = \mathbb{E}_{p_D(\boldsymbol{x})}[\log p_\theta(\boldsymbol{x})]\)
```

Since the log marginal likelihood \(\log p_\theta(\boldsymbol{x})\) cannot be computed exactly, we will approximate it. In the original wake-sleep paper, they proposed to use the ELBO lower bound. In the **reweighted wake-sleep** (RWS) algorithm of [BB15b; Le+19], they propose to use the IWAE bound from Section 10.5.1 instead. In particular, if we draw \(S\) samples from the inference network, \(\boldsymbol{z}_s \sim q_\phi(\boldsymbol{z} | \boldsymbol{x})\), we get the following estimator:

```
\(\ell(\boldsymbol{\theta} | \boldsymbol{\phi}, \boldsymbol{x}) = \log \left( \frac{1}{S} \sum_{s=1}^S w_s \right)\)
```

where \(w_s = \frac{p_\theta(\boldsymbol{x}, \boldsymbol{z}_s)}{q_\phi(\boldsymbol{z}_s | \boldsymbol{x})}\). Note that this is the same as the IWAE bound in Equation (10.168).
