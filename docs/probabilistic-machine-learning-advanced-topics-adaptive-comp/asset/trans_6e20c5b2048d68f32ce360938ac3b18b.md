## 18.5 将 GP 推断扩展到大数据集

在第 18.3.6 节中，我们了解到执行 GP 推断和训练的最佳方法是对 N × N 格拉姆矩阵进行 Cholesky 分解。不幸的是，这需要 O(N^3) 时间。在本节中，我们讨论将 GP 扩展到处理大 N 的方法。有关摘要，请参见表 18.3，更多详情请参见 [Liu+20c]。

1. 我们专注于高效计算边缘似然和后验预测分布的方法。关于从后验中采样函数的高效方法，请参见 [Wil+20a]。

### 18.5.1 数据子集

加速 GP 推断的最简单方法是丢弃部分数据。假设我们保留 M 个样本的子集。在这种情况下，精确推断需要 O(M^3) 时间。这称为数据子集方法。

关键问题是：我们应如何选择子集？最简单的方法是随机选择样本（该方法最近在 [HIY19] 中进行了分析）。然而，从直觉上讲，更合理的做法是尝试选择某种意义上“覆盖”原始数据的子集，使其在不包含冗余的情况下，大约保留相同的信息（在一定容差范围内）。聚类算法是一种启发式方法，但我们也可以使用核心集方法，这很可能能找到这样一个信息保留的子集（例如，请参见 [Hug+19] 以了解将此想法应用于 GP 的示例）。

#### 18.5.1.1 信息向量机

聚类和核心集方法是无监督的，因为它们只查看特征 \(\boldsymbol{x}_i\) 而不查看标签 \(y_i\)，这可能不是最优的。信息向量机 [HLS03] 使用贪心策略，迭代添加标记样本 \((\boldsymbol{x}_j, y_j)\)，以最大程度地降低函数后验的熵，\(\Delta_j = \mathbb{H}(p(f_j)) - \mathbb{H}(p^\text{new}(f_j))\)，其中 \(p^\text{new}(f_j)\) 是在条件于 \(y_j\) 后，\(f\) 在 \(\boldsymbol{x}_j\) 处的后验。（这与主动学习非常相似。）要计算 \(\Delta_j\)，设 \(p(f_j) = \mathcal{N}(\mu_j, v_j)\)，且 \(p(f_j|y_j) \propto p(f_j)\mathcal{N}(y_j|f_j, \sigma^2) = \mathcal{N}(f_j|\mu_j^\text{new}, v_j^\text{new})\)，其中 \((v_j^\text{new})^{-1} = v_j^{-1}+\sigma^{-2}\)。由于 \(\mathbb{H}(\mathcal{N}(\mu, v)) = \log(2\pi ev)/2\)，我们得到 \(\Delta_j = 0.5 \log(1+v_j/\sigma^2)\)。由于这是 \(v_j\) 的单调函数，我们可以通过选择方差最大的点来最大化它。（实际上，熵是次模函数，因此我们可以使用次模优化算法来改进 IVM，如 [Kra+08] 所示。）

#### 18.5.1.2 讨论

数据子集方法的主要问题是它忽略了一些数据，这可能会降低预测准确性并增加对真实函数的不确定性。幸运的是，还有其他可扩展方法可以避免这个问题，基本上是通过近似表示（或压缩）训练数据来实现，如下文所述。

### 18.5.2 Nyström 近似

假设我们对 \(N \times N\) 格拉姆矩阵有以下形式的秩 \(M\) 近似：

```
\(\mathbf{K}_{X,X} \approx \mathbf{U}\Lambda\mathbf{U}^\top\) (18.106)
```

其中 \(\Lambda\) 是由 \(M\) 个最大特征值组成的对角矩阵，\(\mathbf{U}\) 是由相应的 \(M\) 个特征向量组成的矩阵，每个大小为 \(N\)。在这种情况下，我们可以使用矩阵反演引理来写出

```
\(\mathbf{K}_\sigma^{-1} = (\mathbf{K}_{X,X} + \sigma^2\mathbf{I}_N)^{-1} \approx \sigma^{-2}\mathbf{I}_N + \sigma^{-2}\mathbf{U}(\sigma^2\Lambda^{-1} + \mathbf{U}^\top\mathbf{U})^{-1}\mathbf{U}^\top\) (18.107)
```

这需要 \(O(NM^2)\) 时间。同样，可以证明（利用西尔维斯特行列式引理）得出

```
\(|\mathbf{K}_\sigma| \approx |\Lambda||\sigma^2\Lambda^{-1} + \mathbf{U}^\top\mathbf{U}|\) (18.108)
```

这也需要 \(O(NM^2)\) 时间。不幸的是，直接计算这样的特征值分解需要 \(O(N^3)\) 时间，这并没有帮助。但是，假设我们选择一个 \(M < N\) 点的子集 \(Z\)。我们可以按如下方式划分格拉姆矩阵（我们假设所选点首先出现，然后是其余点）：

where \(\tilde{X} = X - Z\). We now compute an eigendecomposition of \(\mathbf{K}_{Z,Z}\) to get the eigenvalues \(\{\lambda_i\}_{i=1}^M\) and eigenvectors \(\{u_i\}_{i=1}^M\). We now use these to approximate the full matrix as shown below, where the scaling constants are chosen so that \(\|\tilde{u}_i\| \approx 1\):

```
\mathbf{K}_{X,X} = \begin{pmatrix} \mathbf{K}_{Z,Z} & \mathbf{K}_{Z,X-Z} \\ \mathbf{K}_{X-Z,Z} & \mathbf{K}_{X-Z,X-Z} \end{pmatrix} \triangleq \begin{pmatrix} \mathbf{K}_{Z,Z} & \mathbf{K}_{Z,\tilde{X}} \\ \mathbf{K}_{\tilde{X},Z} & \mathbf{K}_{\tilde{X},\tilde{X}} \end{pmatrix} (18.109)

\tilde{\lambda}_i \triangleq \frac{N}{M} \lambda_i (18.110)

\tilde{u} \triangleq \sqrt{\frac{M}{N}} \frac{1}{\lambda_i} \mathbf{K}_{\tilde{X},Z} u_i (18.111)

\mathbf{K}_{X,X} \approx \sum_{i=1}^M \tilde{\lambda}_i \tilde{u}_i \tilde{u}_i^\mathsf{T} (18.112)

= \sum_{i=1}^M \frac{N}{M} \lambda_i \sqrt{\frac{M}{N}} \frac{1}{\lambda_i} \mathbf{K}_{\tilde{X},Z} u_i \sqrt{\frac{M}{N}} \frac{1}{\lambda_i} u_i^\mathsf{T} \mathbf{K}_{\tilde{X},Z}^\mathsf{T} (18.113)

= \mathbf{K}_{\tilde{X},Z} \left( \sum_{i=1}^M \frac{1}{\lambda_i} u_i u_i^\mathsf{T} \right) \mathbf{K}_{\tilde{X},Z} (18.114)

= \mathbf{K}_{\tilde{X},Z} \mathbf{K}_{Z,Z}^{-1} \mathbf{K}_{\tilde{X},Z}^\mathsf{T} (18.115)
```

这被称为 Nyström 近似 [WS01]。如果我们定义

```
\mathbf{Q}_{A,B} \triangleq \mathbf{K}_{A,Z} \mathbf{K}_{Z,Z}^{-1} \mathbf{K}_{Z,B} (18.116)
```

那么我们可以将近似格拉姆矩阵写为 \(\mathbf{Q}_{X,X}\)。我们可以用 \(\hat{\mathbf{Q}}_{X,X} = \mathbf{Q}_{X,X} + \sigma^2 \mathbf{I}_N\) 替换 \(\mathbf{K}_\sigma\)。计算特征值分解需要 \(O(M^3)\) 时间，计算 \(\hat{\mathbf{Q}}_{X,X}^{-1}\) 需要 \(O(NM^2)\) 时间。因此，复杂度现在对 \(N\) 是线性的，而不是立方的。

如果我们在 Equation (18.52) 中的 \(\mu_{*|X}\) 和 Equation (18.53) 中的 \(\Sigma_{*|X}\) 中仅近似 *only* \(\hat{\mathbf{K}}_{X,X}\)，那么这与这些公式中其他未近似的核函数求值不一致，并可能导致预测方差为负。解决这一问题的一个方法是对所有项使用相同的 \(\mathbf{Q}\) 近似。

### 18.5.3 诱导点方法

在本节中，我们讨论一种基于诱导点（也称为伪输入）的近似方法，诱导点类似于训练数据的学习摘要，我们可以对其进行条件化，而不是对所有数据进行条件化。

设 \(\mathbf{X}\) 为观测输入，\(\mathbf{f}_X = f(\mathbf{X})\) 为未知函数值向量（我们有其带噪声的观测 \(\mathbf{y}\)）。设 \(\mathbf{f}_*\) 为一个或多个测试点 \(\mathbf{X}_*\) 处的未知函数值。最后，假设我们有 \(M\) 个额外输入 \(\mathbf{Z}\)，其未知函数值为 \(\mathbf{f}_Z\)（通常表示为 \(\mathbf{u}\)）。精确联合先验形式为

```
p(\mathbf{f}_X, \mathbf{f}_*) = \int p(\mathbf{f}_*, \mathbf{f}_X, \mathbf{f}_Z) d\mathbf{f}_Z = \int p(\mathbf{f}_*, \mathbf{f}_X | \mathbf{f}_Z) p(\mathbf{f}_Z) d\mathbf{f}_Z = \mathcal{N} \left( \mathbf{0}, \begin{pmatrix} \mathbf{K}_{X,X} & \mathbf{K}_{X,*} \\ \mathbf{K}_{*,X} & \mathbf{K}_{*,*} \end{pmatrix} \right) (18.117)
```
