## 19.8.2 黑盒攻击（无梯度攻击）

在本节中，我们不再假设对手知道预测模型 \(f\) 的参数 \(\boldsymbol{\theta}\)。这被称为 **黑盒攻击**。在这种情况下，我们必须使用无导数优化（DFO）方法（参见第 6.7 节）。

进化算法（EA）是一类 DFO 求解器。这些算法在 [NYC15] 中被用来创建黑盒攻击。图 19.24 显示了将 EA 应用于随机噪声图像生成的一些图像。这些被称为 **愚弄图像**，与对抗图像相对，因为它们在视觉上不现实。图 19.25 显示了将 EA 应用于组成模式产生网络（CPPN）[Sta07] 参数生成的一些愚弄图像。$^6$ 通过适当扰动 CPPN 参数，可以生成具有高适应度（分类器得分）但看起来不像自然图像的结构化图像 [Aue12]。

6. CPPN 是一组基本函数（如线性、正弦、Sigmoid 和高斯），可以组合起来以指定从每个坐标到所需颜色值的映射。CPPN 最初被开发为一种编码对称性和重复性等抽象属性的方法，这些属性在生物发育中经常出现。

## 19.8.3 现实世界对抗性攻击

通常，可能的对抗性输入空间 \(\Delta\) 可能非常大，并且难以精确地在数学上定义，因为它将取决于基于攻击者目标的输入语义 [BR18]。（我们希望模型保持不变的变化集 \(\Delta\) 被称为威胁模型。）

例如，考虑 [Gil+18a] 中讨论的内容受限威胁模型。这种威胁模型的一个实例涉及图像垃圾邮件，攻击者希望上传一个电子邮件中的图像附件，该图像不会被检测模型分类为垃圾邮件。在这种情况下，\(\Delta\) 非常大，因为它包含所有包含攻击者希望上传的某些语义概念（在此例中为广告）的可能图像。为了探索 \(\Delta\)，垃圾邮件发送者可以使用不同的字体、单词方向或在背景中添加随机对象，如图 19.26 中的对抗性示例所示（有关更多示例，请参见 [Big+11]）。当然，基于优化的方法仍可在此用于探索 \(\Delta\) 的部分区域。然而，在实践中，手动设计对抗性输入可能更可取，因为这在仅对底层分类器进行有限查询黑盒访问的情况下执行起来可能容易得多。

## 19.8.4 基于鲁棒优化的防御

如第 19.8.3 节所讨论的，在更通用的威胁模型中保护系统免受对抗性输入的影响似乎极其困难，因为可能的对抗性输入空间 \(\Delta$ 非常大。然而，有一条研究路线专注于生成对小约束集 \(\Delta(x)\) 内的扰动保持不变的模型，重点是 \(l_p$-鲁棒性，其中 \(\Delta(x) = \{x' : \|x - x'\|_p < \epsilon\}$。尽管解决这个玩具威胁模型对安全场景几乎没有应用，但在某些情况下，强制执行平滑先验已提高了对随机图像损坏的鲁棒性 [SHS]，导致了迁移性更好的模型 [Sal+20]，并使模型偏向于数据中的不同特征 [Yin+19a]。

也许改善 \(l_p$-鲁棒性最直接的方法是通过 **鲁棒优化** [BTEGN09] 直接对其进行优化，也称为 **对抗性训练** [GSS15]。我们定义 **对抗性风险** 为

```
\(\min_\theta \mathbb{E}_{(x,y)\sim p(x,y)} \left[ \max_{x' \in \Delta(x)} L(x', y; \theta) \right] (19.51)\)
```

方程 19.51 中的 min-max 表述从优化角度提出了独特的挑战——它要求同时求解非凹内最大化和非凸外最小化问题。更糟的是，内最大化问题在一般情况下是 NP-hard 的 [Kat+17]。然而，在实践中，在内部问题的近似最大点 \(x_{\text{adv}} \approx \text{argmax}_{x'} L(x', y; \theta)\) [Mad+18] 处计算外部目标 \(\nabla_\theta L(x_{\text{adv}}, y; \theta)$ 的梯度可能就足够了。目前，最佳实践是使用几步 PGD 来近似内部问题。

其他方法旨在 **认证** 模型在给定区域 \(\Delta(x)$ 内是鲁棒的。一种认证方法使用随机平滑 [CRK19] —— 一种将对随机噪声鲁棒的模型转换为在 \(l_2$-度量下对有界最坏情况扰动可证明鲁棒的模型的技术。另一类方法专门应用于具有 ReLU 激活的网络，利用模型在局部是线性的特性，并且在由线性约束定义的区域内进行认证归于求解一系列线性规划，可以应用标准求解器 [WK18]。

## 19.8.5 为什么模型会有对抗性示例

对抗性输入的存在具有悖论性，因为现代分类器在正常输入上似乎表现很好。然而，对抗性示例的存在是第 19.2 节讨论的对分布转移普遍缺乏鲁棒性的自然结果。要看到这一点，假设模型在与训练分布 \(p_{\text{tr}}(x)$ 不同的某些偏移输入分布 \(p_{\text{te}}(x)$ 上准确率下降；在这种情况下，模型必然容易受到对抗性攻击：如果存在错误，必定存在最近的此类错误。此外，如果输入分布是高维的，那么我们应该期望最近的错误比从某些外部分布 \(p_{\text{te}}(x)$ 随机采样的错误要近得多。
