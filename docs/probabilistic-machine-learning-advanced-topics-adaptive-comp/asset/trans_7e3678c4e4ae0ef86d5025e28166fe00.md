### 3.4.6.1 共轭先验的混合

在本节中，我们将展示如何创建**共轭先验的混合**以提高建模灵活性。幸运的是，得到的混合先验仍然是共轭的。

以预测赌场硬币抛掷结果为例，我们认为硬币可能是公平的，但也可能偏向正面。这个先验不能由 Beta 分布表示。幸运的是，它可以表示为 Beta 分布的混合。例如，我们可以使用

$p(\theta) = 0.5 \, \text{Beta}(\theta|20, 20) + 0.5 \, \text{Beta}(\theta|30, 10)$ (3.207)

如果 $\theta$ 来自第一个分布，则硬币是公平的；如果来自第二个分布，则它偏向正面。

我们可以通过引入隐性指示变量 $h$ 来表示混合，其中 $h=k$ 表示 $\theta$ 来自混合分量 $k$。先验的形式为

$p(\theta) = \sum_k p(h=k)p(\theta|h=k)$ (3.208)

其中每个 $p(\theta|h=k)$ 都是共轭的，$p(h=k)$ 称为（先验）混合权重。可以证明，后验也可以表示为共轭分布的混合，如下所示：

$p(\theta|\mathcal{D}) = \sum_k p(h=k|\mathcal{D})p(\theta|\mathcal{D}, h=k)$ (3.209)

其中 $p(h=k|\mathcal{D})$ 是后验混合权重，由以下给出：

$p(h=k|\mathcal{D}) = \frac{p(h=k)p(\mathcal{D}|h=k)}{\sum_{k'} p(h=k')p(\mathcal{D}|h=k')}$ (3.210)

这里，$p(\mathcal{D}|h=k)$ 是混合分量 $k$ 的边缘似然（见第 3.2.1.9 节）。

回到上面的示例，如果我们有方程 (3.207) 中的先验，并且观察到 $N_1 = 20$ 次正面和 $N_0 = 10$ 次反面，那么使用方程 (3.31)，后验变为

$p(\theta|\mathcal{D}) = 0.346 \, \text{Beta}(\theta|40, 30) + 0.654 \, \text{Beta}(\theta|50, 20)$ (3.211)

参见图 3.10 以示说明。

我们可以计算硬币偏向正面的后验概率，如下所示：

$\text{Pr}(\theta > 0.5 | \mathcal{D}) = \sum_k \text{Pr}(\theta > 0.5 | \mathcal{D}, h = k) p(h = k | \mathcal{D}) = 0.9604$

如果我们只使用单个 Beta(20,20) 先验，则会得到略小的值 Pr(θ > 0.5 | D) = 0.8858。因此，如果我们最初对赌场可能使用偏硬币“怀有怀疑”，那么与从开放心态开始相比，我们的担忧会更快得到证实。

### 3.4.6.2 鲁棒（重尾）先验

先验对后验影响的评估称为**敏感性分析**或**鲁棒性分析**。创建**鲁棒先验**有很多方法（参见，例如，[IR00]）。这里我们考虑一种简单的方法，即使用重尾分布。

为了说明这一点，让我们考虑 [Ber85a, p7] 中的一个例子。假设 x ~ N(θ, 1)。我们观察到 x = 5 并希望估计 θ。最大似然估计（MLE）当然是 θ̂ = 5，这似乎是合理的。在均匀先验下的后验均值也是 θ̄ = 5。但现在假设我们知道先验中位数为 0，且 θ 落在区间 (-∞, -1)、(-1, 0)、(0, 1)、(1, ∞) 中任何一个的概率为 25%。我们还假设先验是平滑且单峰的。

可以证明，形式为 N(θ | 0, 2.19^2) 的高斯先验满足这些先验约束。但在这种情况下，后验均值为 3.43，这似乎不太理想。一种能够捕捉相同先验信息的替代分布是柯西先验 T1(θ | 0, 1)。使用该先验，我们发现（使用数值积分方法：代码见 robust_prior_demo.ipynb）后验均值约为 4.6，这似乎更合理。通常，重尾先验倾向于给出对数据更敏感的结果，这通常是我们希望的。

重尾先验通常不是共轭的。但是，我们通常可以通过使用（可能是无限的）共轭先验混合来近似重尾先验。例如，在第 28.2.3 节中，我们展示了 Student 分布（柯西分布是其特例）可以表示为高斯分布的无限混合，其中混合权重来自伽马分布。这是层次先验的一个示例；详情见第 3.6 节。

### 3.4.6.3 标量方差的先验

在本节中，我们讨论一些常用的方差参数先验。这类先验在确定模型展示多少正则化方面起着重要作用。例如，考虑线性回归模型 p(y | x, w, σ^2) = N(y | w^T x, σ^2)。假设我们对权重使用高斯先验 p(w) = N(w | 0, τ^2 I)。τ^2（相对于 σ^2）的值在岭回归中起着类似于 l2-正则化项强度的作用。在贝叶斯环境中，我们需要确保为方差参数 τ^2 和 σ^2 使用合理的先验。当我们在第 3.6 节讨论层次模型时，这变得更加重要。

我们首先考虑从已知均值的高斯似然中推断方差参数 σ^2 的简单问题，如第 3.4.3.2 节。非信息先验为 p(σ^2) = IG(σ^2 | 0, 0)，这是不适当的，意味着它不积分为 1。只要后验是适当的，这没问题。如果先验是 N ≥ 2 个可观测变量噪声方差上的先验，则会出现这种情况。不幸的是，如果我们在回归模型中对（不可观测）权重的方差使用此先验 [Gel06; PS12]，即使 \( N \to \infty \) 后验也不适当，正如我们在第 3.6 节中讨论的那样。

解决此问题的一个方法是使用**弱信息性**适当先验，例如 IG(\(\epsilon, \epsilon\))。但是，事实证明这效果不太好，原因在 [Gel06; PS12] 中有说明。相反，建议使用其他先验，例如均匀、指数、半正态、半 Student-t 或半柯西；这些都下界为 0，并且只需要 1 或 2 个超参数。（术语“半”指的是分布在实轴正侧“对折”到自身。）

### 3.4.6.4 协方差矩阵的先验

协方差矩阵的共轭先验是逆 Wishart 分布（第 2.2.5.6 节）。但是，以非信息方式设置其参数可能很困难。[HW13] 中讨论的一种方法是使用逆 Wishart 的尺度混合，其中缩放参数服从逆伽马分布。可以选择形状和尺度参数，以确保所有相关参数具有均匀 (\( -1, 1 \)) 边缘分布，并且所有标准差都具有半 Student 分布。

不幸的是，Wishart 分布具有重尾，这在采样算法中使用时可能导致性能不佳。6 更常见的方法是，遵循方程 (3.213)，将 \( D \times D\) 协方差矩阵 \( \mathbf{\Sigma} \) 表示为边际标准差 \( \boldsymbol{\sigma} = (\sigma_1, \dots, \sigma_D) \) 和 \( D \times D\) 相关矩阵 \( \mathbf{R} \) 的乘积，如下所示：

```
\mathbf{\Sigma} = \text{diag}(\boldsymbol{\sigma}) \mathbf{R} \text{diag}(\boldsymbol{\sigma})
```

例如，如果 \( D=2 \)，则有

```
\mathbf{\Sigma} = \begin{pmatrix} \sigma_1 & 0 \\ 0 & \sigma_2 \end{pmatrix} \begin{pmatrix} 1 & \rho \\ \rho & 1 \end{pmatrix} \begin{pmatrix} \sigma_1 & 0 \\ 0 & \sigma_2 \end{pmatrix} = \begin{pmatrix} \sigma_1^2 & \rho\sigma_1\sigma_2 \\ \rho\sigma_1\sigma_2 & \sigma_2^2 \end{pmatrix}
```

我们可以按照第 3.4.6.3 节的建议，在标准差上设置分解先验。例如，

```
p(\boldsymbol{\sigma}) = \prod_{d=1}^D \text{Expon}(\sigma_d|1)
```

对于相关矩阵，通常使用以 [LKJ09] 作者命名的**LKJ 分布**作为先验。其形式为

```
\text{LKJ}(\mathbf{R}|\eta) \propto |\mathbf{R}|^{\eta-1}
```

因此它只有一个自由参数。当 \( \eta=1 \) 时，它是均匀先验；当 \( \eta=2 \) 时，它是“弱正则化”先验，鼓励较小的相关性（接近 0）。参见图 3.11 了解图示。

在实践中，更常见的是通过其 Cholesky 分解 \( \mathbf{R} = \mathbf{L}\mathbf{L}^\top \) 来定义 \( \mathbf{R} \)，其中 \( \mathbf{L} \) 是一个无约束的下三角矩阵。然后我们使用以下方法表示先验：

```
\text{LKJchol}(\mathbf{L}|\eta) \propto |\mathbf{L}|^{-\eta-1}
```

6. 参见 Michael Betancourt 的评论 https://github.com/pymc-devs/pymc/issues/538。
