## 35.1.5 探索-利用权衡

在未知转移模型和奖励模型的RL中，一个基本问题是决定是选择智能体已知能产生高奖励的动作，还是选择奖励不确定但可能提供有用信息的动作，从而帮助智能体到达状态-动作空间中奖励更高的部分。这称为**探索-利用权衡**，已在更简单的上下文盗匪设置中在第34.4节讨论过。关于高效探索的文献非常丰富。在本节中，我们简要描述几种代表性技术。

### 35.1.5.1 \(\epsilon\)-greedy

一种常见的启发式方法是使用参数为 \(\epsilon \in [0, 1]\) 的 \(\epsilon\)-greedy 策略 \(\pi_\epsilon\)。在这种情况下，我们以概率 \(1 - \epsilon\) 选择相对于当前模型的贪婪动作 \(a_t = \text{argmax}_a \hat{R}_t(s_t, a)\)，以概率 \(\epsilon\) 选择随机动作。该规则确保智能体持续探索所有状态-动作组合。不幸的是，可以证明这种启发式方法是次优的，因为它以至少恒定概率 \(\epsilon / |\mathcal{A}|\) 探索每个动作。

### 35.1.5.2 Boltzmann exploration

\(\epsilon\)-greedy 规则的一个低效来源是探索在所有动作上均匀发生。**Boltzmann 策略**可以更高效，通过为更有希望的动作分配更高的探索概率：

```
\(\pi_\tau(a|s) = \frac{\exp(\hat{R}_t(s_t, a)/\tau)}{\sum_{a'} \exp(\hat{R}_t(s_t, a')/\tau)}\) (35.1)
```

其中 \(\tau > 0\) 是一个温度参数，控制分布的熵值。当 \(\tau\) 接近 0 时，\(\pi_\tau\) 将接近贪婪策略。另一方面，较高的 \(\tau\) 值会使 \(\pi(a|s)\) 更加均匀，并鼓励更多探索。其动作选择概率相对于奖励估计的变化可以比 \(\epsilon\)-greedy 更“平滑”，如表 35.2 所示。

### 35.1.5.4 使用贝叶斯自适应MDP的最优解

探索-利用权衡的贝叶斯最优解可以通过将问题表述为一种称为 **贝叶斯自适应MDP** 或 **BAMDP** [Duf02] 的特殊POMDP来计算。这将第34.4.4节中的Gittins索引方法扩展到MDP设置。具体来说，BAMDP 具有一个 **信念状态** 空间 \(\mathcal{B}\)，表示对奖励模型 \(p_R(r|s, a, s')\) 和转移模型 \(p_T(s'|s, a)\) 的不确定性。这个增强MDP上的转移模型可以写成如下形式：

```
\(T^+(s_{t+1}, b_{t+1}|s_t, b_t, a_t, r_t) = T^+(s_{t+1}|s_t, a_t, b_t)T^+(b_{t+1}|s_t, a_t, r_t, s_{t+1})\) (35.3)
\(= \mathbb{E}_{b_t} [T(s_{t+1}|s_t, a_t)] \times \mathbb{I}(b_{t+1} = p(R, T|\mathbf{h}_{t+1}))\) (35.4)
```

其中 \(\mathbb{E}_{b_t} [T(s_{t+1}|s_t, a_t)]\) 是下一状态上的后验预测分布，\(p(R, T|\mathbf{h}_{t+1})\) 是给定 \(\mathbf{h}_{t+1} = (s_{1:t+1}, a_{1:t+1}, r_{1:t+1})\) 的新信念状态，可以使用贝叶斯规则计算。

同样，增强MDP的奖励函数由

$$R^+(r|s_t, b_t, a_t, s_{t+1}, b_{t+1}) = \mathbb{E}_{b_{t+1}} [R(s_t, a_t, s_{t+1})]$$ (35.5)

给出。对于小问题，我们可以最优地求解得到的增强MDP。但是，一般来说，这在计算上是不可行的。[Gha+15] 综述了许多更高效求解它的方法。例如，[KN09] 开发了一种与贝叶斯最优策略表现类似的算法，只是在可证明的少数步骤内除外；[GSD13] 提出了一种基于蒙特卡洛rollout的近似方法。更近期，[Zin+20] 提出了一种基于元学习（第19.6.4节）的近似方法，他们为多个相关任务训练了一个（无模型）策略。每个任务由一个任务嵌入向量 m 表示，该向量使用 VAE（第21.2节）从 $h_t$ 推断得出。后验 $p(m|h_t)$ 被用作信念状态 $b_t$ 的代理，策略在给定 $s_t$ 和 $b_t$ 的情况下被训练以表现良好。在测试时，策略应用于增量计算的信念状态；这使该方法能够推断这是哪种任务，然后使用预训练策略快速解决它。

## 35.2 基于值的RL

在本节中，我们假设智能体通过与环境交互来获取来自 $p_T$ 和 $p_R$ 的样本。我们将展示如何使用这些样本来学习最优的 $Q$-函数，从中可以推导出最优策略。

### 35.2.1 蒙特卡洛RL

回顾，对于任何 \(t\)，都有 $Q_\pi(s, a) = \mathbb{E} [G_t | s_t = s, a_t = a]$。估计这一点的简单方法是采取动作 \(a\)，然后根据 \(\pi\) 采样轨迹的其余部分，然后计算折扣奖励的平均总和。如果任务是情景任务，轨迹在达到终止状态时结束；或者当折扣因子 \(\gamma^t\) 变得微小到可以忽略时结束，以先发生者为准。这是值函数的蒙特卡洛估计。

我们可以将这种技术与策略迭代（第34.6.2节）结合使用，以学习最优策略。具体来说，在第 \(k\) 次迭代时，我们使用 \(\pi_{k+1}(s) = \text{argmax}_a Q_k(s, a)\) 计算一个新的、改进的策略，其中 \(Q_k\) 使用MC估计近似。此更新可以应用于采样轨迹上访问的所有状态。这种整体技术称为蒙特卡洛控制。

为确保该方法收敛到最优策略，我们需要为每个（状态，动作）对收集数据，至少在表格情况下，因为不同 \(Q(s, a)\) 值之间没有泛化。实现这一点的一种方法是使用 \(\epsilon\)-greedy 策略。由于这是一种 on-policy 算法，得到的方法将收敛到最优 \(\epsilon\)-软策略，而不是最优策略。可以使用重要性采样来估计最优策略的值函数，即使动作是根据 \(\epsilon\)-greedy 策略选择的。但是，简单地逐渐减少 \(\epsilon\) 更简单。
