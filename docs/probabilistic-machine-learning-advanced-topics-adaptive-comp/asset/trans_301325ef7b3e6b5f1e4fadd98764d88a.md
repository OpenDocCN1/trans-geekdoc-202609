

PWCCA 在表征相似性文献中享有一定的广泛应用，但它具有潜在的不良特性。首先，它是非对称的；其值取决于用于加权的两个表征中的哪一个。其次，不清楚为什么应该使用 $L^1$ 范数来确定权重，而该范数对表征的旋转不具备不变性。更直观的做法或许是直接由典范成分解释的表征方差量来加权相关性，这对应于将 $L^1$ 范数替换为平方 $L^2$ 范数。得到的相似度量为

```
$R^2_{\text{LR}}(\mathbf{X}, \mathbf{Y}) = \frac{\sum_{i=1}^p \alpha'_i \rho_i^2}{\sum_{i=1}^p \alpha'_i}, \qquad \alpha'_i = \sum_{j=1}^{p_2} \|(\mathbf{Y} \mathbf{w}'_i)^\top \mathbf{Y}\|_2^2. \quad (32.8)$
```

如 Kornblith et al. [Kor+19] 所示，当 $p_2 \ge p_1$ 时，这种替代相似度量等同于利用表征 $\tilde{\mathbf{X}}$ 对 $\tilde{\mathbf{Y}}$ 中每个神经元进行线性回归拟合所解释的总方差，

```
$R^2_{\text{LR}}(\mathbf{X}, \mathbf{Y}) = 1 - \sum_{i=1}^{p_2} \min_\beta \|\tilde{\mathbf{Y}}_{:,i} - \tilde{\mathbf{X}} \beta\|^2 / \|\tilde{\mathbf{Y}}\|_\text{F}^2. \quad (32.9)$
```

最后，CCA 与线性 CKA 之间也存在密切关系。通过直接用奇异值分解 $\tilde{\mathbf{X}} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^\top$ 和 $\tilde{\mathbf{Y}} = \mathbf{U}' \mathbf{\Sigma}' \mathbf{V}'^\top$ 来表述相似性指标，可以澄清这种关系。左奇异向量 $\mathbf{u}_i = \mathbf{U}_{:,i}$ 对应于 $\mathbf{X}$ 的主成分（已归一化为单位长度），平方奇异值 $\lambda_i = \Sigma_{ii}^2$ 是这些主成分解释的方差量（至 $1/n$ 的一个因子）。给定这些奇异值分解，$R^2_{\text{CCA}}$、$R^2_{\text{LR}}$ 和线性 CKA 变为：

```
$R^2_{\text{CCA}}(\mathbf{X}, \mathbf{Y}) = \sum_{i=1}^{p_1} \sum_{j=1}^{p_2} (\mathbf{u}_i^\top \mathbf{u}'_j)^2 / p_1 \quad (32.10)$
```

```
$R^2_{\text{LR}}(\mathbf{X}, \mathbf{Y}) = \sum_{i=1}^{p_2} \sum_{j=1}^{p_2} \lambda'_j (\mathbf{u}_i^\top \mathbf{u}'_j)^2 \big/ \sum_{j=1}^{p_2} \lambda'_j \quad (32.11)$
```

```
$\text{CKA}_\text{linear}(\mathbf{X}, \mathbf{Y}) = \frac{\sum_{i=1}^{p_1} \sum_{j=1}^{p_2} \lambda_i \lambda'_j (\mathbf{u}_i^\top \mathbf{u}'_j)^2}{\sqrt{\sum_{i=1}^{p_1} \lambda_i^2} \sqrt{\sum_{j=1}^{p_2} \lambda'_j^2}}. \quad (32.12)$
```

因此，这些相似性指标都涉及 $\mathbf{X}$ 和 $\mathbf{Y}$ 中所有主成分对之间的相似性，但根据这些主成分解释的方差比例对这些相似性赋予不同的权重。

### 32.2.2.3 比较表征相似性度量

表征相似性度量应具备哪些特性是一个开放问题，且此问题可能没有唯一答案。与下游准确性的评估近似神经网络表征的实际应用场景不同，表征相似性的目标则相反：发展对表征如何跨越神经网络演变，或在不同架构或训练设置的神经网络之间如何差异的理解。

对不同相似性度量进行分类的一种方式，是通过它们对表征所进行变换的不变性。最小的不变性形式是对表征的组成神经元进行置换的不变性，这是必需的，因为神经网络中的神经元通常没有标准顺序：对于常用的初始化策略，给定初始化的任何置换都是等概率的，并且几乎所有架构和优化器都产生在置换下等变的训练轨迹。另一方面，由互信息提供的对任意可逆变换的不变性显然是不希望的，因为许多现实的神经网络是输入的单射函数 [Gol+19]，因此任何一对表征之间总是存在可逆变换。在实践中，大多数常用的相似性度量对表征的旋转（正交变换）不变性，这意味着对置换的不变性。仅基于 CCA 相关性的相似性度量，例如 \( R^2_{CCA} \) 和 \( \bar{\rho} \)，对表征的所有可逆线性变换不变性。然而，SVCCA 和 PWCCA 不是。

区分相似性度量的另一种方式是调查已知表征之间关系的情况，并经验性地评估其恢复这些关系的能力。Kornblith et al. [Kor+19] 提出一个简单的“合理性检查”：给出两个架构相同、从不同随机初始化训练的网络 A 和 B，网络 A 中的任何层都应比与网络 B 中的任何其他层更相似于与网络 B 在架构上对应的层。他们表明，在考虑 CNN 的展平表征时，基于中心核对齐的相似性度量满足此合理性检查，而其他相似性度量则不然。相比之下，在考虑 Transformer 中单个标记的表征时，所有相似性度量都表现得相当不错。然而，Maheswaranathan et al. [Mah+19] 表明，CCA 和线性 CKA 对看似无害的 RNN 设计选择（例如激活函数）高度敏感，尽管对不同网络动力学的不动点分析表明它们都以类似方式运行。

## 32.3 学习表征的方法

表征学习的目标是学习输入的转换，使解决未来任务变得更容易。通常，在学习表征时，我们希望表征有用的任务尚不为人知，因此无法直接训练以提高任务性能。学习这种通用表征需要收集大规模未标记或弱标记数据集，并识别可以在不直接访问下游任务的情况下解决的表征任务或先验。大多数方法专注于学习参数映射 \( z = f_\theta(x) \)，该映射接收输入 \( x \) 并使用具有参数 \( \theta \) 的神经网络将其转换为表征 \( z \)。

表征学习的主要挑战是提出一个需要学习良好表征才能解决的任务。如果任务太简单，则可以在不学习输入的有趣转换的情况下解决，或通过学习 _快捷方式_ 来解决。如果任务与表征将被评估的下游任务差异太大，则该表征也可能无用。例如，如果下游任务是对象检测，则表征需要对图像中的对象身份和位置进行编码。然而，如果只关心分类，则表征可以丢弃有关位置的信息。这导致学习表征的方法通常不具备通用性：不同的训练任务可能对不同的下游任务表现更好。

### 32.3.1 监督表征学习与迁移

使用深度学习进行视觉表征学习的首次重大成功来自在大规模标记数据集上训练的网络。在发现监督深度神经网络可胜过自然图像分类中的经典计算机视觉模型 [KSH12b; CMS12] 之后，清楚这些网络学习的表征可胜过广泛用于各种任务的手工特征 [Don+14; SR+14; Oqu+14; Gir+14]。尽管无监督视觉表征学习最近在许多领域取得了有竞争力的结果，监督表征学习仍然是主导方法。

在较大的数据集上训练的较大网络通常在预训练和下游任务中均能取得更好的性能。当其他设计选择保持固定时，在自然图像数据集（如 ImageNet）上预训练期间取得更高准确性的架构，也会为下游自然图像任务学习更好的表征，该表征通过线性评估和微调准确度来衡量 [KSL19; TL19; Zha+19a; Zha+21; Abn+21]。然而，当预训练任务到下游任务的域偏移变得较大时（例如，从 ImageNet 到医学影像），预训练与下游准确性之间的相关性可能要低得多 [Rag+19;
