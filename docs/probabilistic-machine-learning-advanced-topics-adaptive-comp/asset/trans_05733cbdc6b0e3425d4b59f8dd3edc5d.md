这被称为探索，以便收集足够的数据，从而能可靠地学习奖励函数 R(s, a)；然后它可以通过为每个状态选择预测的最佳动作来利用其知识。如果代理人过早地开始利用一个不正确的模型，它将收集次优数据，并陷入负反馈循环，如图 34.7 所示。这与监督学习不同，监督学习中的数据是从固定分布中独立同分布地抽取的（详情见例如 [Jeu+19]）。我们将在下文讨论探索-利用问题的一些解决方案。

## 34.4.4 最优解

在本节中，我们讨论探索-利用权衡的最优解。让我们用 b_t = p(θ|h_t) 表示奖励函数参数的后验，其中 h_t = {s_{1:t-1}, a_{1:t-1}, r_{1:t-1}} 是观察历史；这被称为信念状态或信息状态。它是历史 h_t 的有限充分统计量。信念状态可以使用贝叶斯规则确定性地更新：

```
$b_t = \text{BayesRule}(b_{t-1}, a_t, r_t)$
```

例如，考虑一个无上下文 **Bernoulli 盗匪问题**，其中 \( p_R(r|a) = \text{Ber}(r|\mu_a) \)，且 \( \mu_a = p_R(r=1|a) = R(a) \) 是采取动作 \( a \) 的预期奖励。假设我们使用一个分解的 beta 前验 \( p_0(\theta) = \prod_a \text{Beta}(\mu_a | \alpha_0^a, \beta_0^a) \)（34.56）

其中 \( \theta = (\mu_1, ..., \mu_K) \)。我们可以以封闭形式计算后验，如第 3.4.1 节所述。特别是，我们发现

\( p(\theta|\mathcal{D}_t) = \prod_a \text{Beta}(\mu_a | \underbrace{\alpha_0^a + N_t^0(a)}_{\alpha_t^a}, \underbrace{\beta_0^a + N_t^1(a)}_{\beta_t^a}) \) (34.57)

其中

\( N_t^r(a) = \sum_{s=1}^{t-1} \mathbb{I}(a_s = a, r_s = r) \) (34.58)

这在图 34.8 中针对两臂 Bernoulli 盗匪问题进行了说明。

我们可以对 **Gaussian 盗匪问题** 使用类似的方法，其中 \( p_R(r|a) = \mathcal{N}(r|\mu_a, \sigma_a^2) \)，并使用第 3.4.3 节的结果。在上下文盗匪问题的情况下，问题会变得更加复杂。如果我们假设一个 **线性回归盗匪问题**，\( p_R(r|s, a; \theta) = \mathcal{N}(r|\phi(s, a)^\mathsf{T}\theta, \sigma^2) \)，我们可以使用贝叶斯线性回归以封闭形式计算 \( p(\theta|\mathcal{D}_t) \)，如第 15.2 节所述。如果我们假设一个 **逻辑回归盗匪问题**，\( p_R(r|s, a; \theta) = \text{Ber}(r|\sigma(\phi(s, a)^\mathsf{T}\theta)) \)，我们可以使用贝叶斯逻辑回归计算 \( p(\theta|\mathcal{D}_t) \)，如第 15.3.5 节所述。如果我们有一个形式为 \( p_R(r|s, a; \theta) = \text{GLM}(r|f(s, a; \theta)) \) 的 **神经盗匪问题**，其中 \( f \) 是某个非线性函数，那么后验推理会变得更加具有挑战性，如第 17 章所述。但是，可以应用标准技术，例如扩展卡尔曼滤波器（第 17.5.2 节）。（有关将此方法扩展到大型 DNN 的方式，请参阅 [DMKM22] 的“子空间神经盗匪问题”方法。）

无论算法细节如何，我们可以将信念状态更新表示如下：

\( p(\mathbf{b}_t|\mathbf{b}_{t-1}, a_t, r_t) = \mathbb{I}(\mathbf{b}_t = \text{BayesRule}(\mathbf{b}_{t-1}, a_t, r_t)) \) (34.59)

然后在每个步骤预测观察到的奖励为

\( p(r_t|\mathbf{b}_t) = \int p_R(r_t|s_t, a_t; \theta)p(\theta|\mathbf{b}_t)d\theta \) (34.60)

我们可以看到，这是一种特殊的（受控）马尔可夫决策过程（第 34.5 节），称为 **信念状态 MDP**。

在具有有限数量臂的无上下文盗匪问题这一特殊情况下，可以使用动态规划计算此信念状态 MDP 的最优策略（参见第 34.6 节）；结果可以表示为每个步骤的动作概率表 \( \pi_t(a_1, ..., a_K) \)，这被称为 **Gittins 指数** [Git89]。然而，计算一般上下文盗匪问题的最优策略是不可行的 [PT87]，因此我们必须求助于近似方法，如下文所述。

## 34.4.5 置信上界（UCB）

探索-利用问题的最优解是不可行的。然而，一种直觉上合理的方法基于“面对不确定性时的乐观”原则。该原则贪婪地选择动作，但基于其奖励的乐观估计。遵循此原则的最重要策略类统称为置信上界或 UCB 方法。

```
$a_t = \underset{a}{\text{argmax}} \, \tilde{R}_t(s_t, a)$ (34.61)
```

UCB 可以被视为一种探索奖励，乐观估计鼓励探索。通常，乐观程度 \(\tilde{R}_t - R\) 随时间减少，使代理人逐渐减少探索。通过构建得当的乐观奖励估计，UCB 策略已被证明在许多盗匪问题变体中能实现近似最优遗憾 [LS19]。（我们将在第 34.4.7 节讨论遗憾。）乐观函数 \(\tilde{R}\) 可以通过不同方式获得，有时以封闭形式，如下文所述。

### 34.4.5.1 频率学派方法

一种方法是使用浓度不等式 [BLM16] 来推导估计误差的高概率上界：\(|\hat{R}_t(s, a) - R_t(s, a)| \le \delta_t(s, a)\)，其中 \(\hat{R}_t\) 是 \(R\) 的常规估计（通常是 MLE），\(\delta_t\) 是一个适当选择的函数。然后通过设置 \(\tilde{R}_t(s, a) = \hat{R}_t(s, a) + \delta_t(s, a)\) 来获得乐观奖励。例如，再次考虑无上下文 Bernoulli 盗匪问题，\(R(a) \sim \text{Ber}(\mu(a))\)。MLE \(\hat{R}_t(a) = \hat{\mu}_t(a)\) 由每次采取动作 \(a\) 时观察到的奖励的经验平均值给出：

```
\(\hat{\mu}_t(a) = \frac{N_t^1(a)}{N_t(a)} = \frac{N_t^1(a)}{N_t^0(a) + N_t^1(a)}\) (34.62)
```

其中 \(N_t^r(a)\) 是（直到步骤 \(t-1\)）动作 \(a\) 被尝试且观察到的奖励为 \(r\) 的次数，\(N_t(a)\) 是动作 \(a\) 被尝试的总次数：

```
\(N_t(a) = \sum_{s=1}^{t-1} \mathbb{I}(a_s = a)\) (34.63)
```

然后，Chernoff-Hoeffding 不等式 [BLM16] 得出 \(\delta_t(a) = c / \sqrt{N_t(a)}\)，其中 \(c\) 为某个适当常数，因此，

```
\(\tilde{R}_t(a) = \hat{\mu}_t(a) + \frac{c}{\sqrt{N_t(a)}}\) (34.64)
```

### 34.4.5.2 贝叶斯方法

我们也可以从贝叶斯推导中推导 \(\tilde{R}\)。如果我们使用 beta 前验，可以如公式 (34.57) 所示以封闭形式计算后验。后验均值为 \(\hat{\mu}_t(a) = \mathbb{E}[\mu(a)|\mathbf{h}_t] = \frac{\alpha_t^a}{\alpha_t^a + \beta_t^a}\)。根据公式 (3.17)，后验标准差近似为

```
\(\hat{\sigma}_t(a) = \sqrt{\mathbb{V}[\mu(a)|\mathbf{h}_t]} \approx \sqrt{\frac{\hat{\mu}_t(a)(1 - \hat{\mu}_t(a))}{N_t(a)}}\) (34.65)
```

我们可以对 Gaussian 盗匪问题使用类似技术，其中 $p_R(R|a, \theta) = \mathcal{N}(R|\mu_a, \sigma_a^2)$，$\mu_a$ 是预期奖励，$\sigma_a^2$ 是方差。如果我们使用共轭前验，可以以封闭形式计算 $p(\mu_a, \sigma_a|\mathcal{D}_t)$（参见第 3.4.3 节）。使用非信息性的共轭前验版本，我们发现 $\mathbb{E}[\mu_a|\boldsymbol{h}_t] = \hat{\mu}_t(a)$，这只是动作 $a$ 的奖励经验平均值。此估计中的不确定性是均值的标准误，由公式 (3.133) 给出，即 $\sqrt{\mathbb{V}[\mu_a|\boldsymbol{h}_t]} = \hat{\sigma}_t(a)/\sqrt{N_t(a)}$，其中 $\hat{\sigma}_t(a)$ 是动作 $a$ 的奖励经验标准差。

此方法也可以扩展到上下文盗匪问题，前提是克服计算信念状态的困难。

一旦我们计算了均值和后验标准差，我们就将乐观奖励估计定义为

```
\(\tilde{R}_t(a) = \hat{\mu}_t(a) + c\hat{\sigma}_t(a)\) (34.66)
```

其中 $c$ 是控制策略贪婪程度的某个常数。我们可以看到，这类似于基于浓度不等式的频率学派方法，但更加通用。

### 34.4.4.6 Thompson 采样

UCB 的一个常见替代方法是使用 **Thompson 采样** [Tho33]，也称为 **概率匹配** [Sco10]。在此方法中，我们将步骤 $t$ 的策略定义为 $\pi_t(a|s_t, \boldsymbol{h}_t) = p_a$，其中 $p_a$ 是 $a$ 为最优动作的概率。这可以通过以下方式计算：

```
\(p_a = \text{Pr}(a = a_*|s_t, \boldsymbol{h}_t) = \iint \mathbb{I}\left(a = \underset{a'}{\text{argmax}} R(s_t, a'; \boldsymbol{\theta})\right) p(\boldsymbol{\theta}|\boldsymbol{h}_t) d\boldsymbol{\theta}\) (34.67)
```

如果后验不确定，代理人将采样许多不同的动作，从而自动导致探索。随着不确定性降低，它将开始利用其知识。
