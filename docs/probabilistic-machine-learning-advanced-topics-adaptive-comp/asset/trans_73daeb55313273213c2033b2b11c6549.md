

## 21.3.4 半监督 VAEs

在本节中，我们讨论如何将 VAEs 扩展到 **半监督学习** 设置，其中我们既有标记数据 $\mathcal{D}_L = \{(\mathbf{x}_n, y_n)\}$，也有未标记数据 $\mathcal{D}_U = \{(\mathbf{x}_n)\}$。我们关注在 [Kin+14a] 中提出的 **M2** 模型。

生成模型具有以下形式：

$p_\theta(\mathbf{x}, y) = p_\theta(y)p_\theta(\mathbf{x}|y) = p_\theta(y) \int p_\theta(\mathbf{x}|y, \mathbf{z})p_\theta(\mathbf{z})d\mathbf{z}$ (21.49)

其中 $\mathbf{z}$ 是一个潜在变量，$p_\theta(\mathbf{z}) = \mathcal{N}(\mathbf{z}|\mathbf{0}, \mathbf{I})$ 是潜在先验，$p_\theta(y) = \text{Cat}(y|\boldsymbol{\pi})$ 是标签先验，$p_\theta(\mathbf{x}|y, \mathbf{z}) = p(\mathbf{x}|f_\theta(y, \mathbf{z}))$ 是似然，例如高斯分布，其参数由 $f$（一个深度神经网络）计算。该方法的主要创新在于假设数据是根据潜在类别变量 $y$ 和连续潜在变量 $\mathbf{z}$ 共同生成的。对于标记数据，类别变量 $y$ 是观测到的；对于未标记数据，则未观测到。

为了计算 *标记数据* 的似然 $p_\theta(\mathbf{x}, y)$，我们需要对 $\mathbf{z}$ 进行边缘化，可以通过使用以下形式的推断网络来实现：

$q_\phi(\mathbf{z}|y, \mathbf{x}) = \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}_\phi(y, \mathbf{x}), \text{diag}(\boldsymbol{\sigma}_\phi(y, \mathbf{x})))$ (21.50)

然后我们使用以下变分下界

$\log p_\theta(\mathbf{x}, y) \ge \mathbb{E}_{q_\phi(\mathbf{z}|x, y)} [\log p_\theta(\mathbf{x}|y, \mathbf{z}) + \log p_\theta(y) + \log p_\theta(\mathbf{z}) - \log q_\phi(\mathbf{z}|\mathbf{x}, y)] = -\mathcal{L}(\mathbf{x}, y)$ (21.51)

这与 VAEs 的标准做法一致（参见第 21.2 节）。唯一的区别是，我们观察到两种数据：$\mathbf{x}$ 和 $y$。

为了计算 *未标记数据* 的似然 $p_\theta(\mathbf{x})$，我们需要对 $\mathbf{z}$ *和* $y$ 进行边缘化，可以通过使用以下形式的推断网络来实现：

$q_\phi(\mathbf{z}, y|\mathbf{x}) = q_\phi(\mathbf{z}|\mathbf{x})q_\phi(y|\mathbf{x})$ (21.52)
$q_\phi(\mathbf{z}|\mathbf{x}) = \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}_\phi(\mathbf{x}), \text{diag}(\boldsymbol{\sigma}_\phi(\mathbf{x})))$ (21.53)
$q_\phi(y|\mathbf{x}) = \text{Cat}(y|\boldsymbol{\pi}_\phi(\mathbf{x}))$ (21.54)

注意，$q_\phi(y|\mathbf{x})$ 表现得像一个判别式分类器，用于推断缺失的标签。然后我们使用以下变分下界：

$\log p_\theta(\mathbf{x}) \ge \mathbb{E}_{q_\phi(\mathbf{z}, y|\mathbf{x})} [\log p_\theta(\mathbf{x}|\mathbf{y}, \mathbf{z}) + \log p_\theta(y) + \log p_\theta(\mathbf{z}) - \log q_\phi(\mathbf{z}, y|\mathbf{x})]$ (21.55)
$= - \sum_y q_\phi(y|\mathbf{x})\mathcal{L}(\mathbf{x}, y) + \mathbb{H}(q_\phi(y|\mathbf{x})) = -\mathcal{U}(\mathbf{x})$ (21.56)

注意，判别式分类器 $q_\phi(y|\mathbf{x})$ 仅用于计算未标记数据的对数似然，这并不理想。因此，我们可以在监督数据上添加额外的分类损失，从而得到以下总体目标函数：

$\mathcal{L}(\boldsymbol{\theta}) = \mathbb{E}_{(\mathbf{x}, y) \sim \mathcal{D}_L} [\mathcal{L}(\mathbf{x}, y)] + \mathbb{E}_{\mathbf{x} \sim \mathcal{D}_U} [\mathcal{U}(\mathbf{x})] + \alpha \mathbb{E}_{(\mathbf{x}, y) \sim \mathcal{D}_L} [-\log q_\phi(y|\mathbf{x})]$ (21.57)

其中 $\mathcal{D}_L$ 是标记数据，$\mathcal{D}_U$ 是未标记数据，$\alpha$ 是一个超参数，用于控制生成式学习和判别式学习的相对权重。

## 21.3.5 带有顺序编码器/解码器的 VAE

在本节中，我们讨论用于序列数据的 VAE，例如文本和生物序列，其中数据 \(\mathbf{x}\) 是一个可变长度序列，但我们有一个固定大小的潜在变量 \(\mathbf{z} \in \mathbb{R}^K$。（我们将在 29.13 节中讨论更一般的情况，其中 \(\mathbf{z}\) 是一个可变长度的潜在变量序列，即 **顺序 VAE** 或 **动态 VAE**。）我们只需修改解码器 \(p(\mathbf{x}|\mathbf{z})\) 和编码器 \(q(\mathbf{z}|\mathbf{x})$ 以适用于序列。

### 21.3.5.1 模型

如果为 VAE 的编码器和解码器使用 RNN，则得到的模型称为 **VAE-RNN**，如 [Bow+16a] 中提出。更详细地说，生成模型是 \(p(\mathbf{z}, \mathbf{x}_{1:T}) = p(\mathbf{z})\text{RNN}(\mathbf{x}_{1:T}|\mathbf{z})$，其中 \(\mathbf{z}$ 可以作为 RNN 的初始状态注入，或作为每个时间步的输入。推断模型是 \(q(\mathbf{z}|\mathbf{x}_{1:T}) = \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}(\mathbf{h}), \boldsymbol{\Sigma}(\mathbf{h}))$，其中 \(\mathbf{h} = [\mathbf{h}_T^\rightarrow, \mathbf{h}_1^\leftarrow]$ 是应用于 \(\mathbf{x}_{1:T}$ 的双向 RNN 的输出。请参见图 21.6 以获取示意图。

最近，人们尝试将变换器与 VAE 结合。例如，在 [Li+20] 的 **Optimus** 模型中，他们为编码器使用 BERT 模型。更详细地说，编码器 \(q(\mathbf{z}|\mathbf{x})$ 源自与追加到输入序列 \(\mathbf{x}$ 的“类别标签”对应的哑 token 相关联的嵌入向量。解码器是一个标准的自回归模型（类似于 GPT），额外有一个输入，即潜在向量 \(\mathbf{z}$。他们考虑两种注入潜在向量的方法。最简单的方法是在解码步骤中将 \(\mathbf{z}$ 添加到每个 token 的嵌入层，定义 \(\mathbf{h}'_i = \mathbf{h}_i + \mathbf{W}\mathbf{z}$，其中 \(\mathbf{h}_i \in \mathbb{R}^H$ 是第 \(i\) 个 token 的原始嵌入，\(\mathbf{W} \in \mathbb{R}^{H \times K}$ 是解码矩阵，\(K$ 是潜在向量的大小。然而，他们在实验中通过让解码器的所有层关注潜在代码 \(\mathbf{z}$ 获得了更好的结果。实现此目的的简单方法是定义内存向量 \(\mathbf{h}_m = \mathbf{W}\mathbf{z}$，其中 \(\mathbf{W} \in \mathbb{R}^{L H \times K}$，\(L$ 是解码器中的层数，然后将 \(\mathbf{h}_m \in \mathbb{R}^{L \times H}$ 在每个层附加到所有其他嵌入中。

另一种称为 **transformer VAE** 的方法在 [Gre20] 中提出。该模型使用 **funnel transformer** [Dai+20b] 作为编码器，并使用 **T5** [Raf+20a] 条件变换器作为

### 21.3.5.2 应用

在本节中，我们讨论 VAEs 对序列数据的一些应用。

### 文本

在 [Bow+16b] 中，他们将 VAE-RNN 模型应用于自然语言句子。（另请参见 [MB16; SSB17] 了解相关工作。）尽管这并未提高标准困惑度指标（根据前几个词预测下一个词）方面的性能，但它确实提供了一种推断句子语义表示的方法。然后可以使用此方法进行潜在空间插值，如第 20.3.5 节所述。使用 VAE-RNN 进行此操作的结果如图 21.7a 所示。（使用 VAE-transformer 的类似结果在 [Li+20] 中显示。）相比之下，如果我们使用具有相同 RNN 编码器和解码器网络的标准确定性自动编码器，我们会学习到一个意义小得多的空间，如图 21.7b 所示。原因是确定性自动编码器的潜在空间中存在“空洞”，这些空洞会被解码为毫无意义的输出。

但是，由于 RNN（和变换器）是强大的解码器，我们需要解决后验坍塌问题，我们将在第 21.4 节中讨论。避免此问题的一种常见方法是使用 KL 退火，但更有效的方法是使用第 21.3.2 节的 InfoVAE 方法，其中包括对抗自动编码器（与 RNN 解码器一起在 [She+20] 中使用）和 MMD 自动编码器（与变换器解码器一起在 [Gre20] 中使用）。

### 草图

在 [HE18] 中，他们将 VAE-RNN 模型应用于生成各种动物和手写字符的草图（线条画）。他们将他们的模型称为 sketch-rnn。训练数据记录了 (x, y) 笔位的序列，以及笔是否接触纸张。发射模型对实数值位置偏移使用了 GMM，对离散状态使用了分类 softmax 分布。
