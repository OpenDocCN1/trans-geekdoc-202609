### 9.2.6.4 时间和空间复杂度

维特比算法的时间复杂度显然是 $O(K^2T)$，空间复杂度是 $O(KT)$，这与前向-后向算法相同。如果转移矩阵的形式为 $A_{i,j} \propto \rho(\mathbf{z}_j - \mathbf{z}_i)$，其中 $\mathbf{z}_i$ 是由状态 $i$ 表示的连续向量，$\rho(u)$ 是某个标量代价函数，例如欧氏距离，我们可以通过使用广义距离变换来实现方程 (9.44)，从而在 $O(TK)$ 时间内实现维特比算法。详情见 [FHK03; FH12]。

### 9.2.6.5 N-best 列表

通常有多条路径具有相同的似然性。维特比算法返回其中一条，但可以扩展以返回前 $N$ 条路径 [SC90; NG01]。这被称为 **N-best 列表**。计算此类列表可以对后验不确定性提供更好的总结。

此外，我们可以根据从 $(\mathbf{y}_{1:T}, \mathbf{z}_{1:T})$ 导出的全局特征，对 $\mathcal{L}_N$ 中的所有序列进行 **判别性重排序** [CK05]。该技术在语音识别中广泛使用。例如，考虑句子 “recognize speech”。系统对该声学信号的最可能解释可能是 “wreck a nice speech”，或者也许是 “wreck a nice beach”（参见图 34.3）。也许正确的解释在列表中排得更靠后。然而，通过使用重排序系统，我们可能能够基于更全局的上下文提高正确解释的得分。N-best 列表的一个问题是，通常前 N 条路径彼此非常相似，而不是对数据表示质的不同的解释。相反，我们可能希望生成一组更多样化的路径，以更准确地表示后验不确定性。一种方法是从后验中采样路径，如我们在 9.2.7 节中讨论的。另一种方法是使用决定点过程（补充部分 31.8.5），它鼓励点多样化 [Bat+12; ZA12]。

## 9.2.7 前向滤波后向采样

与计算单一最可能路径相比，从后验中采样多条路径通常很有用：$z_{1:T}^s \sim p(z_{1:T}|y_{1:T})$。我们可以通过修改 9.2.4 节中的前向滤波后向平滑算法来实现这一点，即在后向传递上绘制样本，而不是计算边缘分布。这称为 **前向滤波后向采样**（有时也不幸地缩写为 FFBS）。特别是，请注意我们可以从右到左使用

$p(z_{1:T}|y_{1:T}) = p(z_T|y_{1:T})p(z_{T-1}|z_T, y_{1:T})p(z_{T-2}|z_{T-1}, z_T, y_{1:T}) \cdots p(z_1|z_2, z_{3:T}, y_{1:T})$ (9.48)

$= p(z_T|y_{1:T}) \prod_{t=T-1}^1 p(z_t|z_{t+1}, y_{1:T})$ (9.49)

来写出联合分布。因此，在第 $t$ 步，我们从方程 (9.49) 给出的 $p(z_t|z_{t+1}^s, y_{1:T})$ 中采样 $z_t^s$。

## 9.3 树上的信念传播

9.2.3 节讨论的 HMM 前向-后向算法（以及我们将在 8.2.3 节讨论的 LDS 卡尔曼平滑算法）可以解释为应用于链式结构图形模型的消息传递算法。在本节中，我们将这些算法推广到可用于树的情况。

### 9.3.1 有向 vs 无向树

考虑一对偶无向图形模型，可以写成如下形式：

$p^*(z) \triangleq p(z|y) \propto \prod_{s \in \mathcal{V}} \psi_s(z_s|y_s) \prod_{(s,t) \in \mathcal{E}} \psi_{s,t}(z_s, z_t)$ (9.50)

其中 $\psi_{s,t}(z_s, z_t)$ 是一对偶团势，每条边一个，$\psi_s(z_s|y_s)$ 是局部证据势，每个节点一个，$\mathcal{V}$ 是节点集，$\mathcal{E}$ 是边集。（我们今后将为简洁起见省略对观测值 $y$ 的条件。）

现在假设相应的图形结构是一棵树，如图 9.7a 所示。我们总是可以通过选择任意节点作为根，然后“抓住根”并将所有边朝向远离根的方向，将其转换为有向树。例如，如果我们选择节点 1 作为根，我们得到图 9.7b。这对应于以下有向图形模型：

```
p^*(\mathbf{z}) \propto p^*(z_1)p^*(z_2|z_1)p^*(z_3|z_2)p^*(z_4|z_2)
```

然而，如果我们选择节点 2 作为根，我们得到图 9.7c。这对应于以下有向图形模型：

```
p^*(\mathbf{z}) \propto p^*(z_2)p^*(z_1|z_2)p^*(z_3|z_2)p^*(z_4|z_2)
```

由于这些图表表达相同的条件独立性属性，它们代表相同的概率分布家族，因此我们可以自由使用其中任何一种参数化。

为了使模型更加对称，最好使用无向树。如果我们将势定义为（可能未归一化的）边缘分布（即，\(\psi_s(z_s) \propto p^*(z_s)\) 和 \(\psi_{s,t}(z_s, z_t) = p^*(z_s, z_t)\)），那么我们可以写成

```
p^*(\mathbf{z}) \propto \prod_{s \in \mathcal{V}} p^*(z_s) \prod_{(s,t) \in \mathcal{E}} \frac{p^*(z_s, z_t)}{p^*(z_s)p^*(z_t)}
```

例如，对于图 9.7a，我们有

```
p^*(z_1, z_2, z_3, z_4) \propto p^*(z_1)p^*(z_2)p^*(z_3)p^*(z_4) \frac{p^*(z_1, z_2)p^*(z_2, z_3)p^*(z_2, z_4)}{p^*(z_1)p^*(z_2)p^*(z_2)p^*(z_3)p^*(z_2)p^*(z_4)}
```

为了看出与有向表示的等价性，我们可以约去项以得到

```
p^*(z_1, z_2, z_3, z_4) \propto p^*(z_1, z_2) \frac{p^*(z_2, z_3)}{p^*(z_2)} \frac{p^*(z_2, z_4)}{p^*(z_2)}
```

```
= p^*(z_1)p^*(z_2|z_1)p^*(z_3|z_2)p^*(z_4|z_2)
```

```
= p^*(z_2)p^*(z_1|z_2)p^*(z_3|z_2)p^*(z_4|z_2)
```

其中 \(p^*(z_t|z_s) = p^*(z_s, z_t)/p^*(z_s)\)。

因此，一棵树可以表示为无向图或有向图。两种表示都有用，正如我们将看到的。

```
// Collect to root
for each node s in post-order
    bel_s(z_s) \propto \psi_s(z_s) \prod_{t \in ch_s} m_{t \to s}(z_s)
    t = parent(s)
    m_{s \to t}(z_t) = \sum_{z_s} \psi_{st}(z_s, z_t) bel_s(z_s)
// Distribute from root
for each node t in pre-order
    s = parent(t)
    m_{s \to t}(z_t) = \sum_{z_s} \psi_{st}(z_s, z_t) \frac{bel_s(z_s)}{m_{t \to s}(z_s)}
    bel_t(z_t) \propto bel_t(z_t) m_{s \to t}(z_t)
```
