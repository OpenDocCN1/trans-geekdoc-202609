# 9.2.3.3 Two-slice smoothed marginals

We can compute the two-slice marginals using the output of the forwards-backwards algorithm as follows:

```
p(z_t, z_{t+1}|y_{1:T}) = p(z_t, z_{t+1}|y_{1:t}, y_{t+1:T})
\propto p(y_{t+1:T}|z_t, z_{t+1}, y_{1:t})p(z_t, z_{t+1}|y_{1:t})
= p(y_{t+1:T}|z_{t+1})p(z_t, z_{t+1}|y_{1:t})
= p(y_{t+1:T}|z_{t+1})p(z_t|y_{1:t})p(z_{t+1}|z_t)
= p(y_{t+1:T}|z_{t+1})p(z_t|y_{1:t})p(z_{t+1}|z_t)
= p(y_{t+1}, y_{t+2:T}|z_{t+1})p(z_t|y_{1:t})p(z_{t+1}|z_t)
= p(y_{t+1}|z_{t+1})p(y_{t+2:T}|z_{t+1}, y_{t+1})p(z_t|y_{1:t})p(z_{t+1}|z_t)
= p(y_{t+1}|z_{t+1})p(y_{t+2:T}|z_{t+1})p(z_t|y_{1:t})p(z_{t+1}|z_t)
= p(y_{t+1}|z_{t+1})p(y_{t+2:T}|z_{t+1})p(z_t|y_{1:t})p(z_{t+1}|z_t)
```

We can rewrite this in terms of the already computed quantities as follows:

```
\xi_{t,t+1}(i, j) \propto \lambda_{t+1}(j)\beta_{t+1}(j)\alpha_t(i)A_{i,j}
```

Or in matrix-vector form:

```
\xi_{t,t+1} \propto \mathbf{A} \circ [\alpha_t(\lambda_{t+1} \odot \beta_{t+1})^T]
```

Since \alpha_t \propto \lambda_t \circ \alpha_{t|t-1}, we can also write the above equation as follows:

```
\xi_{t,t+1} \propto \mathbf{A} \circ [(\lambda_t \odot \alpha_{t|t-1}) \circ (\lambda_{t+1} \odot \beta_{t+1})^T]
```

This can be interpreted as a product of incoming messages and local factors, as shown in Figure 9.4. In particular, we combine the factors \alpha_{t|t-1} = p(z_t|y_{1:t-1}), \mathbf{A} = p(z_{t+1}|z_t), \lambda_t \propto p(y_t|z_t), \lambda_{t+1} \propto p(y_{t+1}|z_{t+1}), and \beta_{t+1} \propto p(y_{t+2:T}|z_{t+1}) to get p(z_t, z_{t+1}, y_t, y_{t+1}, y_{t+2:T}|y_{1:t-1}), which we can then normalize.
