where we drop terms that are independent of $z_t$ since such terms will cancel out when we normalize the sampling weights. We can approximate the density ratio using the binary classifier method of Section 2.7.5. To do this, we define one distribution to be $p_1 = p_\theta(z_t, y_{t+1:T})$ and the other to be $p_2 = p_\theta(z_t)p_\theta(y_{t+1:T})$, so that $p_1/p_2 = \frac{p_\theta(z_t|y_{t+1:T})}{p_\theta(z_t)}$. We can easily draw a sample $(z_{1:T}, y_{1:T}) \sim p_\theta$ using ancestral sampling, from which we can compute $(z_t, y_{t+1:T}) \sim p_1$ by marginalization. We can also sample a fresh sequence from $(\tilde{z}_{1:T}, \tilde{y}_{1:T}) \sim p_\theta$ from which we can compute $(\tilde{z}_t, \tilde{y}_{t+1:T}) \sim p_2$ by marginalization. We then use $(z_t, y_{t+1:T})$ as a positive example and $(\tilde{z}_t, \tilde{y}_{t+1:T})$ as a negative example when training the binary classifier, $r_\psi(y_{t+1:T}, z_t)$.\

Once we have updated the twisting parameters $\psi$, we can rerun SMC to get a tighter lower bound on the log marginal likelihood, which we can then optimize wrt the model parameters $\theta$ and proposal parameters $\phi$. Thus the overall method is a stochastic variational EM-like method for optimimziing the bound\

$\mathcal{L}_{\text{SIXO}}(\theta, \phi, \psi, y_{1:T}) \triangleq \mathbb{E} \left[ \log \hat{Z}_{\text{SIXO}}(\theta, \phi, \psi, y_{1:T}) \right]$ (13.93)\\

$\le \log \mathbb{E} \left[ \hat{Z}_{\text{SIXO}}(\theta, \phi, \psi, y_{1:T}) \right] = \log p_\theta(y_{1:T})$ (13.94)\\

In [Law+22] they prove the following: suppose the true model $p^*$ is an SSM in which the optimal proposal function for the model satisfies $p^*(z_t|z_{1:t-1}, y_{1:T}) \in \mathcal{Q}$, and the optimal lookahead function for the model satisfies $p^*(y_{t+1:T}|z_t) \in \mathcal{R}$. Furthermore, assume the SIXO objective has a unique maximizer. Then, at the optimum, we have that the learned proposal $q_{\phi^*}(z_t|z_{1:t-1}, y_{1:T}) \in \mathcal{Q}$ is equal to the optimal proposal, the learned twisting function $r_{\psi^*}(y_{t+1:T}, z_t) \in \mathcal{R}$ is equal to the optimal lookahead, and the lower bound is tight (i.e., $\mathcal{L}_{\text{SIXO}}(\theta^*, \phi^*, \psi^*) = p^*(y_{1:T})$) for any number of samples $N_s \ge 1$ and for any kind of SSM $p^*$.
