

遵循此类最优策略可确保代理从任何状态出发均能获得最大预期回报。求解 \(V_*\)、\(Q_*\) 或 \(\pi_*\) 的问题称为**策略优化**。相比之下，对给定策略 \(\pi\) 求解 \(V_\pi\) 或 \(Q_\pi\) 称为**策略评估**，这将在后续章节中讨论，是 RL 问题的一个重要子类。对于策略评估，我们有类似的 Bellman 方程，只需将公式 (34.82) 和 (34.83) 中的 \(\max_a\{\cdot\}\) 替换为 \(\mathbb{E}_{\pi(a|s)}[\cdot]\) 即可。在公式 (34.84) 和 (34.85) 中，与 Bellman 最优性方程类似，我们需要对 \(\mathcal{A}\) 中的所有动作取最大值，使目标函数最大化的动作称为相对于价值函数 \(Q_*\) 或 \(V_*\) 的**贪心动作**。若 \(\mathcal{A}\) 是一个小的有限集，求解贪心动作在计算上很容易。对于高维连续空间，我们可以将 \(a\) 视为动作序列，每次优化一个维度 [Met+17]，或使用无梯度优化器，例如交叉熵方法（第 6.7.5 节），如 **QT-Opt** 方法 [Kal+18a] 所用。最近，**CAQL**（连续动作 Q-学习，[Ryu+20]）提出使用混合整数规划来求解 argmax 问题，利用 \(Q\)-网络的 ReLU 结构。我们还可以在学习最优 \(Q\)-函数后通过训练策略 \(a_* = \pi_*(s)\) 来分摊此优化的开销。

### 34.5.5.1 示例

在本节中，我们展示一个简单示例，使价值函数等概念更加具体。考虑图 34.13(a) 中所示的一维**网格世界**。共有 5 个可能状态，其中 \(S_{T1}\) 和 \(S_{T2}\) 是吸收态，因为代理一旦进入它们，交互即结束。共有 2 个动作，\(\uparrow\) 和 \(\downarrow\)。奖励函数处处为 0，除了目标状态 \(S_{T2}\)，进入该状态会获得 1 的奖励。因此，每个状态的最优动作都是向下移动。图 34.13(b) 显示了 \(\gamma = 0\) 时的 \(Q_*\) 函数。注意，我们仅展示非吸收态的函数，因为根据定义，吸收态的最优 \(Q\)-值为 0。我们看到 \(Q_*(s_3,\downarrow) = 1.0\)，因为如果代理从 \(s_3\) 向下移动，下一步将获得 1.0 的奖励；然而，对于所有其他状态-动作对，\(Q_*(s,a) = 0\)，因为它们不提供非零即时奖励。这个最优 \(Q\)-函数反映了使用 \(\gamma = 0\) 是完全近视的，并忽略了未来。图 34.13(c) 显示了 \(\gamma = 1\) 时的 \(Q_*\)。在这种情况下，我们同等关心所有未来奖励。因此，对于所有状态-动作对，\(Q_*(s,a) = 1\)，因为代理最终总能到达目标。这是无限远见的。然而，它并未给代理任何关于如何行为的短期指导。例如，在 \(s_2\) 中，不清楚应该向上还是向下移动，因为两个动作最终都能达到具有相同 \(Q_*\) 值的目标。图 34.13(d) 显示了 \(\gamma = 0.9\) 时的 \(Q_*\)。这反映了对近期奖励的偏好，同时也考虑了未来奖励。这鼓励代理寻找通往目标的最短路径，这通常是我们期望的。\(\gamma\) 的适当选择取决于代理设计者，就像奖励函数的设计一样，必须反映代理的期望行为。

## 34.6 MDP 中的规划

在本节中，我们讨论当 MDP 模型已知时如何计算最优策略。此问题称为**规划**，与模型未知的学习问题（后者通过强化学习在第 35 章中处理）相对。我们讨论的规划算法基于**动态规划**（DP）和**线性规划**（LP）。为简化起见，在本节中，我们假设状态和动作集为离散且 \(\gamma < 1\)。然而，最优策略的精确计算通常依赖于 \(\mathcal{S}\) 和 \(\mathcal{A}\) 大小的多项式，在某些情况下（例如，状态空间是若干有限集的笛卡尔积时）难以处理。这一挑战称为**维度灾难**。因此，通常需要近似，例如使用参数或非参数表示价值函数或策略，既为了计算可行性，也为了将方法扩展到处理具有一般状态和动作集的 MDP。在这种情况下，我们拥有**近似动态规划**（ADP）和**近似线性规划**（ALP）算法（见例如 [Ber19]）。

### 34.6.1 值迭代

求解 MDP 的一种流行且有效的 DP 方法是**值迭代**（VI）。从初始价值函数估计 \(V_0\) 开始，算法通过迭代更新估计值：

```
\( V_{k+1}(s) = \max_a \left[ R(s, a) + \gamma \sum_{s'} p(s'|s, a) V_k(s') \right] \) (34.86)
```

注意，更新规则有时称为**Bellman 备份**，它恰好是 Bellman 最优性方程公式 (34.82) 的右侧，其中未知 \(V_*\) 被当前估计 \(V_k\) 替换。公式 (34.86) 的一个基本性质是更新是一个**收缩**：可以验证

```
\(\max_s |V_{k+1}(s) - V_*(s)| \le \gamma \max_s |V_k(s) - V_*(s)|\) (34.87)
```

换句话说，每次迭代都会将最大价值函数误差降低一个常数因子。因此，\(V_k\) 将收敛到 \(V_*\)，之后可以使用公式 (34.85) 提取最优策略。在实践中，当 \(V_k\) 足够接近 \(V_*\) 时，我们通常可以终止 VI，因为相对于 \(V_k\) 的贪心策略将接近最优。值迭代可以调整为学习最优动作-价值函数 \(Q_*\)。

在值迭代中，我们为所有可能状态 \(s\) 计算 \(V_*(s)\) 和 \(\pi_*(s)\)，并在每次迭代中对所有可能的下一状态 \(s'\) 取平均，如图 34.14（右）所示。然而，对于某些问题，我们可能只关心某些特定起始状态的值（和策略）。例如，在图上的**最短路径问题**中，我们试图从当前状态找到到达目标状态的最短路径。这可以通过定义转移矩阵 \(p_T(s'|s,a)\) 来建模为情节 MDP，其中从节点 \(s\) 取边 \(a\) 会以概率 1 导致邻接节点 \(s'\)。奖励函数定义为所有状态 \(s\) 的 \(R(s,a) = -1\)，除了目标状态（建模为吸收态）。

对于此类问题，我们可以使用一种称为**实时动态规划（RTDP）** [BBS95] 的方法，以高效计算**最优部分策略**，该策略仅指定可达状态的行为。RTDP 维护一个价值函数估计 \(V\)。在每一步，它对当前状态 \(s\) 执行 Bellman 备份，即 \(V(s) \leftarrow \max_a \mathbb{E}_{p_T(s'|s,a)}[R(s,a) + \gamma V(s')]\)。它选择一个动作 \(a\)（通常带有一些探索），到达下一状态 \(s'\)，并重复此过程。这可以被视为更一般的**异步值迭代**的一种形式，它将计算精力集中在从当前状态更可能到达的状态空间部分，而不是在每次迭代中同步更新所有状态。

### 34.6.2 策略迭代

计算 \(\pi_*\) 的另一种有效 DP 方法是**策略迭代**。它是一种迭代算法，在确定性策略空间中搜索，直到收敛到最优策略。每次迭代包含两个步骤：**策略评估**和**策略改进**。

如前所述，策略评估步骤计算当前策略的价值函数。令 \(\pi\) 表示当前策略，\(v(s) = V_\pi(s)\) 表示以状态索引的向量形式的价值函数，\(r(s) = \sum_a \pi(a|s)R(s,a)\) 表示奖励向量，\(\mathbf{T}(s'|s) = \sum_a \pi(a|s)p(s'|s,a)\) 表示状态转移矩阵。策略评估的 Bellman 方程可以写成矩阵-向量形式：

\(\mathbf{v} = \mathbf{r} + \gamma \mathbf{T} \mathbf{v}\)

这是一个含有 \(|\mathcal{S}|\) 个未知数的线性方程组。我们可以使用矩阵求逆来求解：\(\mathbf{v} = (\mathbf{I} - \gamma \mathbf{T})^{-1}\mathbf{r}\)。或者，我们可以使用值迭代，通过计算 \(\mathbf{v}_{t+1} = \mathbf{r} + \gamma \mathbf{T} \mathbf{v}_t\) 直到近似收敛，或者使用计算效率更高的某些异步变体。

一旦我们为当前策略 \(\pi\) 评估了 \(V_\pi\)，就可以利用它推导出更好的策略 \(\pi'，因而得名策略改进。为此，我们只需计算一个确定性策略 \(\pi'，使其在每个状态下都相对于 \(V_\pi\) 贪心行动；即，\(\pi'(s) = \text{argmax}_a \{ R(s,a) + \gamma \mathbb{E}[V_\pi(s')] \}\)。我们可以保证 \(V_{\pi'} \ge V_\pi\)。要理解这一点，定义 \(\mathbf{r}'\)、\(\mathbf{T}'\) 和 \(\mathbf{v}'\)，如同之前一样，但针对新策略 \(\pi'\)。\(\pi'\) 的定义意味着 \(\mathbf{r}' + \gamma \mathbf{T}' \mathbf{v} \ge \mathbf{r} + \gamma \mathbf{T} \mathbf{v} = \mathbf{v}\)，其中等式源于 Bellman 方程。重复相同的等式，我们有

\(\mathbf{v} \le \mathbf{r}' + \gamma \mathbf{T}' \mathbf{v} \le \mathbf{r}' + \gamma \mathbf{T}' (\mathbf{r}' + \gamma \mathbf{T}' \mathbf{v}) \le \mathbf{r}' + \gamma \mathbf{T}' (\mathbf{r}' + \gamma \mathbf{T}' (\mathbf{r}' + \gamma \mathbf{T}' \mathbf{v})) \le \cdots\)

\(= (\mathbf{I} + \gamma \mathbf{T}' + \gamma^2 \mathbf{T}'^2 + \cdots) \mathbf{r}' = (\mathbf{I} - \gamma \mathbf{T}')^{-1} \mathbf{r}' = \mathbf{v}'\)
