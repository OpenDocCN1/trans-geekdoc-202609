where pa(i) are the parents of node i, and pred(i) are the predecessors of node i in the ordering. Consequently, we can represent the joint distribution as follows (assuming we use node ordering 1 : N<sub>G</sub>):

$p(x_{1:N_G}) = p(x_1)p(x_2|x_1)p(x_3|x_1, x_2) \dots p(x_{N_G}|x_1, \dots, x_{N_G-1}) = \prod_{i=1}^{N_G} p(x_i | x_{\text{pa}(i)})$ (4.2)

where p(x<sub>i</sub>|x<sub>pa(i)</sub>) is the conditional probability distribution or CPD for node i. (The parameters of this distribution are omitted from the notation for brevity.)

The key advantage of the representation used in Equation (4.2) is that the number of parameters used to specify the joint distribution is substantially less, by virtue of the conditional independence assumptions that we have encoded in the graph, than an unstructured joint distribution. To see this, suppose all the variables are discrete and have K states each. Then an unstructured joint distribution needs O(K<sup>N<sub>G</sub></sup>) parameters to specify the probability of every configuration. By contrast, with a DAG in which each node has at most N<sub>P</sub> parents, we only need O(N<sub>G</sub>K<sup>N<sub>P</sub>+1</sup>) parameters, which can be exponentially fewer if the DAG is sparse.

We give some examples of DPGM's in Section 4.2.2, and in Section 4.2.4, we discuss how to read off other conditional independence properties from the graph.

# 4.2.2 Examples

In this section, we give several examples of models that can be usefully represented as DPGM's.

# 4.2.2.1 Markov chains

We can represent the conditional independence assumptions of a first-order Markov model using the chain-structured DPGM shown in Figure 4.1(a). Consider a variable at a single time step t, which we call the "present." From the diagram, we see that information cannot flow from the past, x<sub>1:t-1</sub>, to the future, x<sub>t+1:T</sub>, except via the present, x<sub>t</sub>. (We formalize this in Section 4.2.4.) This means that the x<sub>t</sub> is a sufficient statistic for the past, so the model is first-order Markov. This implies that the corresponding joint distribution can be written as follows:

$p(x_{1:T}) = p(x_1)p(x_2|x_1)p(x_3|x_2) \cdots p(x_T|x_{T-1}) = p(x_1) \prod_{t=2}^T p(x_t | x_{1:t-1})$ (4.3)
