

## 13.4.1.1 改进

基于我们对离散状态空间进行采样的事实，可以开发该算法的改进版本。在每一步中，我们将每个 $N$ 个旧粒子传播通过所有 $K$ 个可能的转移模型。然后我们为所有 $NK$ 个新粒子计算权重，并从中采样以获得最终的 $N$ 个粒子集合。后一步可以使用 [FC03] 的**最优重采样**方法来完成，该方法将随机选择具有最大权重的粒子，同时也确保结果是无偏近似。此外，这种方法确保我们没有重复粒子，在状态空间离散时，重复粒子是浪费且不必要的。

## 13.4.2 示例：跟踪机动目标

在本节中，我们给出了来自 [DGK01] 的 SLDS 的 RBPF 示例。我们的目标是跟踪具有以下运动模型的对象：

```
$p(\boldsymbol{z}_t | \boldsymbol{z}_{t-1}, m_t = k) = \mathcal{N}(\boldsymbol{z}_t | \mathbf{F}\boldsymbol{z}_{t-1} + \boldsymbol{b}_k, \mathbf{Q})$
```

其中 $\boldsymbol{z}_t = (x_{1t}, \dot{x}_{1t}, x_{2t}, \dot{x}_{2t})$ 包含 2D 位置和速度。我们定义观测矩阵为 $\mathbf{H} = \mathbf{I}$，观测协方差为 $\mathbf{R} = 10 \text{ diag}(2, 1, 2, 1)$。我们定义动力学矩阵为

```
\(\mathbf{F} = \begin{pmatrix} 1 & \Delta & 0 & 0 \\ 0 & 1 & 0 & 0 \\ 0 & 0 & 1 & \Delta \\ 0 & 0 & 0 & 1 \end{pmatrix}\)
```

其中 \(\Delta = 0.1\)。我们将噪声协方差设置为 \(\mathbf{Q} = 0.2\mathbf{I}\)，并为每个状态设置输入偏置向量 \(\boldsymbol{b}_1 = (0, 0, 0, 0)\)、\(\boldsymbol{b}_2 = (-1.225, -0.35, 1.225, 0.35)\) 和 \(\boldsymbol{b}_3 = (1.225, 0.35, -1.225, -0.35)\)。因此，系统将根据离散状态在不同方向转弯。离散状态转移矩阵由

```
\(\mathbf{A} = \begin{pmatrix} 0.8 & 0.1 & 0.1 \\ 0.1 & 0.8 & 0.1 \\ 0.1 & 0.1 & 0.8 \end{pmatrix}\)
```

## 13.4.3 示例：FastSLAM

考虑一个在环境中移动的机器人，例如迷宫或室内办公环境。它需要学习环境的地图，并跟踪其在地图中的位置（姿态）。这个问题被称为**同时定位与建图**，简称**SLAM**。SLAM 在移动机器人领域被广泛使用（详情见 [SC86; CN01; TBF06] 等）。它在增强现实中也很有用，其中任务是递归估计手持相机相对于一组 2D 视觉地标的 3D 姿态（这被称为**视觉 SLAM**，[TUI17; SMT18; Cza+20; DH22]）。

让我们假设可以将地图表示为一组 K 个地标的 2D 位置，将它们表示为 l^1, ..., l^K（每个都是 R^2 中的向量）。（我们可以使用数据关联来找出哪个地标生成了每个观测值，如第 29.9.3.2 节中所讨论。）让 r_t 表示时间 t 时机器人未知的位置。让 z_t = (r_t, l_t^{1:K}) 成为联合状态空间。然后我们可以执行在线推断，以便机器人可以更新对其自身位置和地标位置的估计。

$p(\mathbf{z}_t | \mathbf{z}_{t-1}, \mathbf{u}_t) = p(\mathbf{r}_t | \mathbf{r}_{t-1}, \mathbf{l}_{t-1}^{1:K}, \mathbf{u}_t) \prod_{k=1}^K p(\mathbf{l}_t^k | \mathbf{l}_{t-1}^k)$ (13.68)

其中 p(r_t | r_{t-1}, l_{t-1}^{1:K}, u_t) 指定了机器人在控制信号 u_t 和障碍物位置 l_{t-1}^{1:K} 下如何移动。（注意，在本节中，我们假设人类正在操纵机器人穿过环境，因此 u_{1:t} 作为输入给出，即，我们不涉及选择移动到何处的决策理论问题。）

如果障碍物（地标）是静态的，我们可以定义 p(l_t^k | l_{t-1}^k) = \delta(l_t^k - l_{t-1}^k)，这相当于将地图视为跨越所有时间步全局共享的未知参数。更一般地，我们可以让地标位置随时间演变 [Mur00]。

观测 y_t 测量 r_t 到最近地标集合的距离。图 13.8 显示了 K = 2 时的相应图形模型，并且在第一步它看到地标 1 和 2，然后只看到地标 2，然后只看到地标 1，等等。

如果所有 CPD 都是线性高斯的，那么我们可以使用卡尔曼滤波器来维护关于机器人位置和地标位置的信念状态 p(zt|y1:t, u1:t)。在更一般的非线性模型情况下，我们可以使用 EKF（第 8.3.2 节）或 UKF（第 8.4.2 节）。随着时间的推移，由于车轮打滑等原因，机器人位置的不确定性会增加，但当机器人返回熟悉位置时，其不确定性会再次降低。这被称为闭合回路，并在图 13.9(a) 中得到说明，其中我们看到代表 Cov[zt|y1:t, u1:t] 的不确定性椭圆先增大后减小。
