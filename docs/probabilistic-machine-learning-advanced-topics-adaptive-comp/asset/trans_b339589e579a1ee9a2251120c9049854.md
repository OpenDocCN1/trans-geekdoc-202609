
$D_F(p_D(\boldsymbol{x}) \parallel p_{\boldsymbol{\theta}}(\boldsymbol{x}))$，且 DSM 不是一个一致的目标，因为最优 EBM 匹配的是带噪声分布 $q(\tilde{\boldsymbol{x}})$，而非 $p_D(\boldsymbol{x})$。当 $q(\tilde{\boldsymbol{x}})$ 与 $p_D(\boldsymbol{x})$ 显著不同时，这种不一致性变得不可忽略。

缓解 DSM 不一致性的一种方法是选择 \( q \approx p_D \)，即使用较小的噪声扰动。然而，这通常会显著增加目标值的方差并阻碍优化。举例来说，假设 \( q(\tilde{\boldsymbol{x}} \mid \boldsymbol{x}) = \mathcal{N}(\tilde{\boldsymbol{x}} \mid \boldsymbol{x}, \sigma^2 \boldsymbol{I}) \) 且 \( \sigma \approx 0 \)。对应的 DSM 目标为

```
\(\begin{aligned} D_F(q(\tilde{\boldsymbol{x}}) \parallel p_{\boldsymbol{\theta}}(\tilde{\boldsymbol{x}})) &= \mathbb{E}_{\boldsymbol{x} p_D(\boldsymbol{x})} \mathbb{E}_{\boldsymbol{z} \sim \mathcal{N}(0, \boldsymbol{I})} \left[ \frac{1}{2} \left\| \frac{\boldsymbol{z}}{\sigma} + \nabla_{\boldsymbol{x}} \log p_{\boldsymbol{\theta}}(\boldsymbol{x} + \sigma \boldsymbol{z}) \right\|_2^2 \right] \\ \\ \simeq \frac{1}{2N} \sum_{i=1}^N \left\| \frac{\boldsymbol{z}^{(i)}}{\sigma} + \nabla_{\boldsymbol{x}} \log p_{\boldsymbol{\theta}}(\boldsymbol{x}^{(i)} + \sigma \boldsymbol{z}^{(i)}) \right\|_2^2 , \end{aligned}\)
```

其中 \(\{\boldsymbol{x}^{(i)}\}_{i=1}^N \stackrel{\text{i.i.d.}}{\sim} p_D(\boldsymbol{x})\)，且 \(\{\boldsymbol{z}^{(i)}\}_{i=1}^N \stackrel{\text{i.i.d.}}{\sim} \mathcal{N}(\boldsymbol{0}, \boldsymbol{I})\)。当 \(\sigma \to 0\) 时，我们可以利用泰勒级数展开将公式 (24.35) 中的蒙特卡洛估计器改写为

```
\(\frac{1}{2N} \sum_{i=1}^N \left[ \frac{2}{\sigma} (\boldsymbol{z}^{(i)})^\mathsf{T} \nabla_{\boldsymbol{x}} \log p_{\boldsymbol{\theta}}(\boldsymbol{x}^{(i)}) + \frac{\|\boldsymbol{z}^{(i)}\|_2^2}{\sigma^2} \right] + \text{constant}.\)
```

在使用样本估计上述期望时，\( (\boldsymbol{z}^{(i)})^\mathsf{T} \nabla_{\boldsymbol{x}} \log p_{\boldsymbol{\theta}}(\boldsymbol{x}^{(i)})/\sigma \) 和 \( \|\boldsymbol{z}^{(i)}\|_2^2 / \sigma^2 \) 的方差都会随着 \(\sigma \to 0\) 由于除以 \(\sigma\) 和 \(\sigma^2\) 而无界增长。这增大了 DSM 的方差，使优化变得具有挑战性。已有多种方法被提出来降低这种方差（例如，[Wan+20d]）。

## 24.3.3 切片得分匹配（SSM）

通过向数据添加噪声，DSM 避免了昂贵的二阶导数计算。然而，如前所述，最小化 DSM 目标的最优 EBM 对应的是带噪声扰动数据的分布 \( q(\tilde{\boldsymbol{x}}) \)，而非原始无噪声数据分布 \( p_D(\boldsymbol{x}) \)。换句话说，DSM 不能给出数据分布的一致性估计器，即使拥有无限数据，也无法直接获得一个与数据分布完全匹配的 EBM。

切片得分匹配（SSM）[Son+19] 是去噪得分匹配的一种替代方案，既一致又计算高效。SSM 不再最小化两个向量值得分之间的 Fisher 散度，而是随机采样一个投影向量 \( \boldsymbol{v} \)，计算 \( \boldsymbol{v} \) 与两个得分之间的内积，然后比较得到的两个标量。更具体地说，切片得分匹配最小化以下称为 **切片 Fisher 散度** 的散度：

```
\(D_{SF}(p_D(\boldsymbol{x}) \parallel p_{\boldsymbol{\theta}}(\boldsymbol{x})) = \mathbb{E}_{p_D(\boldsymbol{x})} \mathbb{E}_{p(\boldsymbol{v})} \left[ \frac{1}{2} (\boldsymbol{v}^\mathsf{T} \nabla_{\boldsymbol{x}} \log p_D(\boldsymbol{x}) - \boldsymbol{v}^\mathsf{T} \nabla_{\boldsymbol{x}} \log p_{\boldsymbol{\theta}}(\boldsymbol{x}))^2 \right],\)
```

其中 \( p(\boldsymbol{v}) \) 表示一种投影分布，使得 \( \mathbb{E}_{p(\boldsymbol{v})}[\boldsymbol{v} \boldsymbol{v}^\mathsf{T}] \) 为正定。与 Fisher 散度类似，切片 Fisher 散度具有一种隐式形式，不涉及未知的 \( \nabla_{\boldsymbol{x}} \log p_D(\boldsymbol{x}) \)，其形式为

```
\(\begin{aligned} D_{SF}(p_D(\boldsymbol{x}) \parallel p_{\boldsymbol{\theta}}(\boldsymbol{x})) = \mathbb{E}_{p_D(\boldsymbol{x})} \mathbb{E}_{p(\boldsymbol{v})} \Bigg[ & \frac{1}{2} \sum_{i=1}^d \left( \frac{\partial \mathcal{E}_{\boldsymbol{\theta}}(\boldsymbol{x})}{\partial x_i} v_i \right)^2 + \sum_{i=1}^d \sum_{j=1}^d \frac{\partial^2 \mathcal{E}_{\boldsymbol{\theta}}(\boldsymbol{x})}{\partial x_i \partial x_j} v_i v_j \Bigg] + C. \end{aligned}\)
```

上述目标中的所有期望均可用经验均值估计，同样，常数项 C 可以移除而不影响训练。第二项涉及 \(\mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x})\) 的二阶导数，但与 SM 不同，它可以以与维度 d 成线性的代价高效计算。这是因为

\(\sum_{i=1}^d \sum_{j=1}^d \frac{\partial^2 \mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x})}{\partial x_i \partial x_j} v_i v_j = \sum_{i=1}^d \frac{\partial}{\partial x_i} \left( \sum_{j=1}^d \frac{\partial \mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x})}{\partial x_j} v_j \right) v_i, \tag{24.39}\)

其中 \(f(\mathbf{x})\) 对不同的 \(i\) 值是相同的。因此，我们只需计算一次，代价为 \(O(d)\)，*再加上* 用于外层求和以计算公式 (24.39) 的另一项 \(O(d)\) 计算，而原始 SM 目标需要 \(O(d^2)\) 计算。

对于许多 \(p(\mathbf{v})\) 的选择，SSM 目标（公式 (24.38)）的一部分可以以封闭形式求值，从而可能降低方差。例如，当 \(p(\mathbf{v}) = \mathcal{N}(\mathbf{0}, \mathbf{I})\) 时，我们有

\(\mathbb{E}_{p_D(\mathbf{x})} \mathbb{E}_{p(\mathbf{v})} \left[ \frac{1}{2} \sum_{i=1}^d \left( \frac{\partial \mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x})}{\partial x_i} v_i \right)^2 \right] = \mathbb{E}_{p_D(\mathbf{x})} \left[ \frac{1}{2} \sum_{i=1}^d \left( \frac{\partial \mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x})}{\partial x_i} \right)^2 \right] \tag{24.40}\)

因此，

\(D_{SF}(p_D(\mathbf{x}) \parallel p_{\boldsymbol{\theta}}(\mathbf{x})) = \mathbb{E}_{p_D(\mathbf{x})} \mathbb{E}_{\mathbf{v} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})} \left[ \frac{1}{2} \sum_{i=1}^d \left( \frac{\partial \mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x})}{\partial x_i} \right)^2 + \sum_{i=1}^d \sum_{j=1}^d \frac{\partial^2 \mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x})}{\partial x_i \partial x_j} v_i v_j \right] + C \tag{24.41}\)

\(= \mathbb{E}_{p_D(\mathbf{x})} \mathbb{E}_{\mathbf{v} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})} \left[ \frac{1}{2} (\mathbf{v}^T \mathbf{s}_{\boldsymbol{\theta}}(\mathbf{x}))^2 + \mathbf{v}^T [\mathbf{J} \mathbf{v}] \right] \tag{24.42}\)

其中 \(\mathbf{J} = \mathbf{J}_{\mathbf{x}} \mathbf{s}_{\boldsymbol{\theta}}(\mathbf{x})\)。（注意，\(\mathbf{Jv}\) 可通过雅可比向量积运算计算。）

上述目标公式 (24.41) 也可以通过用 Hutchinson 迹估计器 [Ski89; Hut89; Mey+21] 近似标准 SM 目标（公式 (24.30)）中的二阶梯度之和来得到。它通常（但不总是）比公式 (24.38) 具有更低的方差，并且在某些应用中表现更好 [Son+19]。

## 24.3.4 与对比散度的联系

尽管得分匹配与对比散度（第 24.2.2 节）看起来是非常不同的方法，但它们之间有着紧密的联系。事实上，得分匹配可以被视为特定 MCMC 采样器极限情况下的对比散度的一个特例。此外，得分匹配所优化的 Fisher 散度与 KL 散度的导数相关 [Cov99]，而 KL 散度是对比散度的基础目标。

对比散度需要从 EBM \(\mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x})\) 中进行采样，流行的方法之一是 Langevin MCMC。回顾第 24.2.1 节，给定任何初始数据点 \(\mathbf{x}^0\)，Langevin MCMC 方法执行以下操作

\(\mathbf{x}^{k+1} \leftarrow \mathbf{x}^k - \frac{\epsilon}{2} \nabla_{\mathbf{x}} \mathcal{E}_{\boldsymbol{\theta}}(\mathbf{x}^k) + \sqrt{\epsilon} \, \mathbf{z}^k, \tag{24.43}\)
