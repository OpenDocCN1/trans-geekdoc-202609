

自然的性能度量是这些分布之间的 KL。由于这取决于输入 $x$ 和 $\mathcal{D}_T = (X_{0:T-1}, Y_{1:T})$，我们将在这些值上对 KL 进行平均，这些值从真实数据生成分布中独立同分布（iid）抽取，我们将其表示为

$$P(X, Y, \mathcal{E}) = P(X|\mathcal{E})P(Y|X, \mathcal{E})P(\mathcal{E})$$

其中 $\mathcal{E}$ 是真实但未知的环境。因此我们定义度量为

$$d_{B,Q}^{KL} = \mathbb{E}_{P(x, \mathcal{D}_T)} [D_{KL}(P^B(y|x, \mathcal{D}_T) || Q(y|x, \mathcal{D}_T))]$$

其中

$$P(x, \mathcal{D}_T, \mathcal{E}) = P(\mathcal{E}) \left[ \prod_{t=0}^{T-1} P(X_t|\mathcal{E})P(Y_{t+1}|X_t, \mathcal{E}) \right] \left[ \prod_{t=T}^{T+\tau-1} P(x_t|\mathcal{E}) \right]$$

而 $P(x, \mathcal{D}_T)$ 将其关于环境进行边缘化。

不幸的是，计算精确的贝叶斯后验 $P_T^B$ 通常是不可处理的，因此我们无法评估 $d_{B,Q}^{KL}$。然而，在第 14.2.3.1 节中，我们表明

$$d_{B,Q}^{KL} = d_{\mathcal{E},Q}^{KL} - \mathbb{I}(\mathcal{E}; y|\mathcal{D}_T, x)$$

其中第二项关于代理是常数，第一项由

$$d_{\mathcal{E}, Q}^{KL} = \mathbb{E}_{P(x, \mathcal{D}_T, \mathcal{E})} [D_{KL}(P(y|x, \mathcal{E}) || Q(y|x, \mathcal{D}_T))]$$

$$= \mathbb{E}_{P(y|x, \mathcal{E})P(x, \mathcal{D}_T, \mathcal{E})} [\log \frac{P(y|x, \mathcal{E})}{Q(y|x, \mathcal{D}_T)}]$$

因此，如果我们根据 $d_{\mathcal{E}, Q}^{KL}$ 对代理进行排名，这将与根据 $d_{B, Q}^{KL}$ 对它们进行排名给出相同的结果。

在实践中，为了计算 $d_{\mathcal{E}, Q}^{KL}$，我们可以使用蒙特卡罗近似：我们只需采样 $J$ 个环境，$\mathcal{E}^j \sim P(\mathcal{E})$，从每个环境中采样一个训练集 $\mathcal{D}_T$，$\mathcal{D}_T^j \sim P(\mathcal{D}_T|\mathcal{E}^j)$，然后采样 $N$ 个长度为 $\tau$ 的数据向量，$(x_n^j, y_n^j) \sim P(X_{T:T+\tau-1}, Y_{T+1:T+\tau}|\mathcal{E}^j)$。然后我们可以计算

$$\hat{d}_{\mathcal{E}, Q}^{KL} = \frac{1}{JN} \sum_{j=1}^J \sum_{n=1}^N [\log P(y_n^j|x_n^j, \mathcal{E}^j) - \log Q(y_n^j|x_n^j, \mathcal{D}_T^j)]$$

其中

$$p_{jn} = P(y_n^j|x_n^j, \mathcal{E}^j) = \prod_{t=T}^{T+\tau-1} P(Y_{n, t+1}^j|X_{n,t}^j, \mathcal{E}^j)$$

$$q_{jn} = Q(y_n^j|x_n^j, \mathcal{D}_T^j) = \int Q(y_n^j|x_n^j, \theta) Q(\theta|\mathcal{D}_T^j) d\theta$$

$$\approx \frac{1}{M} \sum_{m=1}^M \prod_{t=T}^{T+\tau-1} Q(Y_{n, t+1}^j | X_{n,t}^j, \theta_m^j)$$

其中 \(\theta_m^j \sim Q(\theta | D_T^j)\) 是代理对环境后验的一个样本。

上述假设 $P(Y|X)$ 是已知的；如果我们使用合成数据生成器，如 [Osb+21] 中的“神经测试平台”，则情况如此。如果我们只有 $J$ 个关于 $P^j(X, Y)$ 的经验分布，我们可以用交叉熵代替 KL，两者仅相差一个加法常数：

$$d_{\mathcal{E}, Q}^{KL} = \mathbb{E}_{P(x, D_T, \mathcal{E})} [D_{KL}(P(y|x, \mathcal{E}) \| Q(y|x, D_T))]$$

$$= \underbrace{\mathbb{E}_{P(x, y|\mathcal{E})}[\log P(y|x, \mathcal{E})]}_{\text{const}} - \underbrace{\mathbb{E}_{P(x, y|D_T) P(\mathcal{E})}[\log Q(y|x, D_T)]}_{d_{\mathcal{E}, Q}^{CE}}$$

其中后一项只是代理在环境样本上的经验负对数似然（NLL）。因此，如果我们根据代理的 NLL 或交叉熵 $d_{\mathcal{E}, Q}^{CE}$ 对代理进行排名，我们将得到与根据 $d_{\mathcal{E}, Q}^{KL}$ 对它们进行排名相同的结果，而这又将与根据 $d_{B,Q}^{KL}$ 对它们进行排名给出相同的结果。

在实践中，我们可以按如下近似交叉熵：

$$\hat{d}_{\mathcal{E}, Q}^{CE} = -\frac{1}{JN} \sum_{j=1}^J \sum_{n=1}^N \log Q(y_n^j | x_n^j, D_T^j)$$

其中 \(D_T^j \sim P^j\)，且 \((x_n^j, y_n^j) \sim P^j$。

估计 KL 或 NLL 的替代方法是通过在下游任务中使用联合预测准确性来评估它。在 [Osb+21] 中，他们表明良好的预测准确性（对于 $\tau > 1$）与在多武装盗匪问题（见第 34.4 节）上的良好性能相关。在 [WSG21] 中，他们表明良好的预测准确性（对于 $\tau > 1$）导致在传导式主动学习任务上的良好性能。

### 14.2.3.1 声明的证明

我们现在基于 [Lu+21a] 证明方程 (14.29)。首先注意

$$d_{\mathcal{E}, Q}^{KL} = \mathbb{E}_{P(x, D_T, \mathcal{E}) P(y|x, \mathcal{E})} \left[ \log \frac{P(y|x, \mathcal{E})}{Q(y|x, D_T)} \right]$$

$$= \mathbb{E} \left[ \log \frac{P(y|x, D_T)}{Q(y|x, D_T)} \right] + \mathbb{E} \left[ \log \frac{P(y|x, \mathcal{E})}{P(y|x, D_T)} \right]$$

对于方程 (14.40) 中的第一项，我们有

$$\mathbb{E} \left[ \log \frac{P(y|x, D_T)}{Q(y|x, D_T)} \right] = \sum P(x, y, D_T) \log \frac{P(y|x, D_T)}{Q(y|x, D_T)}$$

$$= \sum P(x, D_T) \sum P(y|x, D_T) \log \frac{P(y|x, D_T)}{Q(y|x, D_T)}$$

$$= \mathbb{E}_{P(x, D_T)} [D_{KL}(P(y|x, D_T) \| Q(y|x, D_T))] = d_{B,Q}^{KL}$$

我们现在表明方程 (14.40) 中的第二项归约为互信息。我们利用以下事实

$$P(y|x, \mathcal{E}) = P(y|D_T, x, \mathcal{E}) = \frac{P(\mathcal{E}, y|D_T, x)}{P(\mathcal{E}|D_T, x)}$$

因为 $\mathcal{D}_T$ 在 $\mathcal{E}$ 之外没有新信息。由此我们得

```
\(\mathbb{E} \left[ \log \frac{P(\boldsymbol{y}|\mathbf{x}, \mathcal{E})}{P(\boldsymbol{y}|\mathbf{x}, \mathcal{D}_T)} \right] = \mathbb{E} \left[ \log \frac{P(\mathcal{E}, \boldsymbol{y}|\mathcal{D}_T, \mathbf{x}) / P(\mathcal{E}|\mathcal{D}_T, \mathbf{x})}{P(\boldsymbol{y}|\mathbf{x}, \mathcal{D}_T)} \right]\)
\(= \sum P(\mathcal{D}_T, \mathbf{x}) \sum P(\mathcal{E}, \boldsymbol{y}|\mathcal{D}_T, \mathbf{x}) \log \frac{P(\mathcal{E}, \boldsymbol{y}|\mathcal{D}_T, \mathbf{x})}{P(\boldsymbol{y}|\mathcal{D}_T, \mathbf{x}) P(\mathcal{E}|\mathcal{D}_T, \mathbf{x})}\)
\(= \mathbb{I}(\mathcal{E}; \boldsymbol{y}|\mathcal{D}_T, \mathbf{x})\)
```

因此

```
\(d_{\mathcal{E}, Q}^{KL} = d_{B, Q}^{KL} + \mathbb{I}(\mathcal{E}; \boldsymbol{y}|\mathcal{D}_T, \mathbf{x})\)
```

正如所声称。

## 14.3 一致性预测

在本节中，我们简要讨论 **一致性预测** [VGS05; SV08; ZFV20; AB21; KSB21; Man22b]。这是一种简单而有效的方法，用于从任何预测方法 \(p(\boldsymbol{y}|\mathbf{x})\) 创建具有保证频率论覆盖概率的预测区间或集合。这可以被视为一种 **无分布不确定性量化**，因为它在不对真实数据生成过程或模型形式做出假设（数据可交换性除外）的情况下工作。我们的演示基于 [AB21] 的优秀教程。$^1$ $^2$

1. 可交换性假设排除了时间序列数据，后者是序列相关的。然而，针对时间序列情况已开发出一致性预测的扩展，见例如 [Zaf+22]。可交换性假设也排除了分布偏移，尽管这也已得到部分解决。
2. 另请参见易于使用的 **MAPIE** Python 库，网址为 https://mapie.readthedocs.io/en/latest/index.html，以及论文列表 [Man22a]。

在一致性预测中，我们从某种启发式不确定性概念开始——例如分类问题的 softmax 分数，或回归问题的方差——并用它定义一个 **一致性得分** \(s(\mathbf{x}, y) \in \mathbb{R}$，该得分衡量输出 $y$ “符合” $\mathbf{x}$ 的程度。（分数越大的值越不可能，因此最好将其视为不一致性得分。）接下来，我们将该得分应用于未用于训练 $f$ 的 $n$ 个带标签示例的 **校准集**，以获得 $\mathcal{S} = \{s_i = s(\mathbf{x}_i, y_i) : i = 1 : n\}$。用户指定所需的置信阈值 $\alpha$，例如 0.1，然后我们计算 $\mathcal{S}$ 的 $(1-\alpha)$ 分位数 $\hat{q}$。（实际上，我们应该将 $1-\alpha$ 替换为 $\frac{\lceil(n+1)(1-\alpha)\rceil}{n}$，以考虑 $\mathcal{S}$ 的有限大小。）最后，给定新的测试输入 $\mathbf{x}_{n+1}$，我们将预测集计算为

```
$$\mathcal{T}(\mathbf{x}_{n+1}) = \{y : s(\mathbf{x}_{n+1}, y) \le \hat{q}\}$$ (14.49)
```

直觉上，我们包括所有给定输入时合理的输出 $y$。参见图 14.4 以示说明。

值得注意的是，可以证明以下一般结果

```
$$1 - \alpha \le P^*(y^{n+1} \in \mathcal{T}(\mathbf{x}_{n+1})) \le 1 - \alpha + \frac{1}{n+1}$$ (14.50)
```

其中概率是相对于真实分布 $P^*(\mathbf{x}_{n+1}, y_{n+1})$。我们说预测集具有 $1-\alpha$ 的 **覆盖** 水平。这对于任何 $n \ge 1$ 和 $\alpha \in [0, 1]$ 的值都成立。唯一的假设是值 $(\mathbf{x}_i, y_i)$ 是可交换的，因此校准得分 $s_i$ 也是可交换的。为了看到为什么这是真的，让我们对得分进行排序，使 $s_1 < \cdots < s_n$，因此 $\hat{q} = s_i$，其中 $i = \frac{\lceil(n+1)(1-\alpha)\rceil}{n}$。（为了简单起见，我们假设得分互不相同。）得分 $s_{n+1}$ 同样可能落在校准点 $s_1, \dots, s_n$ 之间的任何位置，因为这些点是可交换的。因此

```
$$P^*(s_{n+1} \le s_k) = \frac{k}{n+1}$$ (14.51)
```

对于任何 $k \in \{1, \dots, n+1\}$。事件 $\{y_{n+1} \in \mathcal{T}(\mathbf{x}_{n+1})\}$ 等价于 $\{s_{n+1} \le \hat{q}\}$。因此

```
$$P^*(y_{n+1} \in \mathcal{T}(\mathbf{x}_{n+1})) = P^*(s_{n+1} \le \hat{q}) = \frac{\lceil(n+1)(1-\alpha)\rceil}{n+1} \ge 1 - \alpha$$ (14.52)
```

对于上界的证明，参见 [Lei+18]。虽然这个结果可能看起来像是“免费的午餐”，但值得注意的是，我们可以通过将预测集定义为所有可能的标签来始终实现所需的覆盖水平。在这种情况下，预测集将独立于输入，但它将 $1-\alpha$ 的时间覆盖真实标签。为了排除一些退化情况，我们寻求尽可能小的预测集（尽管我们允许对于更难的示例集合更大），同时满足覆盖要求。实现这一目标要求我们定义合适的符合性得分。下面我们给出了一些如何为不同类型的问题计算符合性得分 $s(\mathbf{x}, y)$ 的示例。同样值得注意的是，覆盖保证是频率论性质的，指的是平均行为，而不是像贝叶斯方法那样表示每个实例的不确定性。

3. 使用校准集称为 **分割符合性预测**。如果我们没有足够的数据来采用这种分割方法，我们可以使用 **完全符合性预测** [VGS05]，它需要使用留一法类似程序对模型进行 $n$ 次拟合。
4. 还可以端到端地学习符合性得分，与预测模型联合进行，如 [Stu+22] 中所讨论。
