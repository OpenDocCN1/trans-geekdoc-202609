## 35.5.1.4 行为正则化方法

之前讨论的三种方法都不对目标策略 \(\pi_e\) 施加任何约束。通常，\(\pi_e\) 与 \(\pi_b\) 越不同，我们的非策略估计就越不准确。因此，在离线 RL 中优化策略时，一个自然的策略是偏好与行为策略“接近”的目标策略。类似的想法在保守策略梯度（第 35.3.4 节）的语境中有所讨论。

一种方法是对两种策略之间的接近程度施加硬约束。例如，我们可以修改 DQN（方程 (35.14)）的损失函数如下

```
\(\mathcal{L}_1^{\text{DQN}}(\boldsymbol{w}) \stackrel{\triangle}{=} \mathbb{E}_{(s,a,r,s')\sim \mathcal{D}} \left[ \left( r + \gamma \max_{\pi: D(\pi, \pi_b) \le \varepsilon} \mathbb{E}_{\pi(a'|s')} [Q_{\boldsymbol{w}-}(s', a')] - Q_{\boldsymbol{w}}(s, a) \right)^2 \right]\) (35.54)
```

在上述内容中，我们用一个期望替换了 \(\max_{a'}\) 操作，该期望基于一个与行为策略足够接近的策略，并由某个距离函数 \(D\) 衡量。有关各种实例化和更多详细信息，请参见，例如，[FMP19; Kum+19a]。

我们也可以通过惩罚差异过大的目标策略，对接近程度施加软约束。DQN 损失函数可以相应地调整为：

```
\(\mathcal{L}_2^{\text{DQN}}(\boldsymbol{w}) \stackrel{\triangle}{=} \mathbb{E}_{(s,a,r,s')\sim \mathcal{D}} \left[ \left( r + \gamma \max_{\pi} \mathbb{E}_{\pi(a'|s')} [Q_{\boldsymbol{w}-}(s', a')] - \alpha \gamma D(\pi(s'), \pi_b(s')) - Q_{\boldsymbol{w}}(s, a) \right)^2 \right]\) (35.55)
```

该想法已用于上下文盗匪 [SJ15]，并由 [WTN19] 在马尔可夫决策过程中进行了实证研究。函数 \(D\) 有多种选择，例如 KL 散度，适用于硬约束和软约束。更详细的讨论和示例可参见 [Lev+20]。

最后，行为正则化与先前的像 IS 这样的方法可以结合，其中前者确保后者具有较低方差和更强的泛化能力（例如，[SJ15]）。此外，大多数提出的行为正则化方法考虑 \(D\) 中的一步差异，在给定 \(s\) 的条件下比较 \(\pi(s)\) 和 \(\pi_b(s)\)。在许多情况下，希望考虑长期分布 \(p_\beta^\infty\) 和 \(p^\infty\) 之间的差异，我们将在下一节讨论。

## 35.5.2 时间诅咒

前一节介绍的 IS 和 DR 方法都依赖重要性比率来纠正分布不匹配。该比率取决于整个轨迹，其方差随轨迹长度 \(T\) 指数增长。相应地，策略值或策略梯度的非策略估计可能遭受指数级大的方差（因此准确性非常低），这一挑战被称为 **时间诅咒** [Liu+18b]。通过 Q-learning 和非策略 Actor-Critic 等近似算法找到的策略，常常由于分布不匹配而存在难以控制的误差。

本节讨论了解决这一挑战的一种方法，即在状态-动作分布中而非轨迹分布中考虑修正。这一变化至关重要：[Liu+18b] 描述了一个例子，在行为策略和目标策略下的状态-动作分布相同，但轨迹的重要性比率却呈指数级增长。现在更方便假设非策略数据由一组转换组成：\(\mathcal{D} = \{(s_i, a_i, r_i, s'_i)\}_{1 \le i \le m}\)，其中 \((s_i, a_i) \sim p_\mathcal{D}\)（某个固定但未知的采样分布，如 \(p_\beta^\infty\)），且 \(r_i\) 和 \(s'_i\) 从 MDP 的奖励和转换模型中采样。给定策略 \(\pi\)，我们的目标是估计修正比率 \(\zeta_\pi(s, a) = p_\pi^\infty(s, a) / p_\mathcal{D}(s, a)\)，因为它允许我们将策略值（方程 (35.15)）重写为

\(J(\pi) = \frac{1}{1-\gamma} \mathbb{E}_{p_\pi^\infty(s,a)} [R(s,a)] = \frac{1}{1-\gamma} \mathbb{E}_{p_\beta^\infty(s,a)} [\zeta_\pi(s,a) R(s,a)]\) (35.56)

为简单起见，我们假设初始状态分布 \(p_0\) 是已知的，或者可以轻松从中采样。该假设在实践中通常容易满足。

出发点是对任意给定 \(\pi\) 的以下线性规划公式：

\(\max_{d \ge 0} -D_f(d \| p_\mathcal{D}) \quad \text{s.t.} \quad d(s,a) = (1-\gamma)\mu_0(s)\pi(a|s) + \gamma \sum_{\bar{s}, \bar{a}} p(s|\bar{s}, \bar{a}) d(\bar{s}, \bar{a}) \pi(a|s) \quad \forall(s,a)\) (35.57)

其中 \(D_f\) 是 \(f\)-散度（第 2.7.1 节）。该约束是方程 (34.93) 的一个变体，在策略 \(\pi\) 下的 \(\mathcal{S} \times \mathcal{A}\) 空间中给出类似的流条件。在温和条件下，\(p_\pi^\infty\) 是满足流约束的唯一解，因此目标不影响解，但有助于下面的推导。我们现在可以获取带有乘数 \(\{\nu(s,a)\}\) 的拉格朗日，并利用变量代换 \(\zeta(s,a) = d(s,a) / p_\mathcal{D}(s,a)\) 得到以下优化问题：

\(\max_{\zeta \ge 0} \min_\nu \mathcal{L}(\zeta, \nu) = \mathbb{E}_{p_\mathcal{D}(s,a)} [-f(\zeta(s,a)) + (1-\gamma) \mathbb{E}_{p_0(s)\pi(a|s)} [\nu(s,a)] + \mathbb{E}_{\pi(a'|s') p(s'|s,a) p_\mathcal{D}(s,a)} [\zeta(s,a) (\gamma \nu(s', a') - \nu(s,a))]\) (35.58)

可以证明，方程 (35.58) 的鞍点必须与所需的修正比率 \(\zeta_*\) 重合。在实践中，我们可以对 \(\zeta\) 和 \(\nu\) 进行参数化，并在非策略数据 \(\mathcal{D}\) 上应用两时间尺度随机梯度下降/上升来求解近似鞍点。这就是 **DualDICE** 方法 [Nac+19a]，其扩展为 **GenDICE** [Zha+20c]。与 IS 或 DR 方法相比，方程 (35.58) 不计算轨迹的重要性比率，因此通常具有较低方差。此外，它对行为策略无感知，无需估计行为策略，甚至无需假设数据由一系列轨迹组成。最后，该方法可以扩展为双重鲁棒（例如，[UHJ20]），并可以针对真实策略值 \(J(\pi)\) 优化策略 [Nac+19b]（与像方程 (35.50) 这样的近似相反）。有关此类方法的更多示例，请参见 [ND20] 及其参考文献。

## 35.5.3 致命三元组

除引入偏差外，非策略数据还可能使基于值的 RL 方法不稳定甚至发散。考虑图 35.10a 中描绘的简单 MDP，源自 [Bai95]。它有 7 个状态和 2 个动作。选择虚线动作会使环境等概率地转移到 6 个上部状态，而选择实线动作则会将其转移到底部状态。所有转换的奖励均为 0，且 \(\gamma = 0.99\)。值函数 \(V_w\) 使用线性参数化，由状态内显示的表达式指示，其中 \(w \in \mathbb{R}^8\)。目标策略 \(\pi\) 在每个状态中始终选择实线动作。显然，真实值函数 \(V_\pi(s) = 0\) 可以通过设置 \(w = \mathbf{0}\) 精确表示。

![](img/ca72c1626f4850f058a9edc138c1ac73_1197_0.png)

图 35.10：(a) 一个简单的 MDP。(b) 策略参数随时间发散。源自 [SB18] 的图 11.1 和 11.2。经 Richard Sutton 授权友好使用。

假设我们使用行为策略 $b$ 生成一条轨迹，在每个状态中，它分别以 $6/7$ 和 $1/7$ 的概率选择虚线动作和实线动作。如果在这条轨迹上应用 TD(0)，参数会发散到 \(\infty\)（图 35.10b），尽管问题看起来很简单！相比之下，使用在策略数据（即 $b$ 与 \(\pi\) 相同时），带有线性近似的 TD(0) 可以保证收敛到一个良好的值函数近似 [TR97]。

这种发散行为在许多基于值的自助方法中得到展示，包括 TD、Q-learning 以及相关的近似动态规划算法，其中值函数可以是线性表示（如上面的例子）或非线性表示 [Gor95; Ber19]。这些发散现象的根本原因是，当 $V$ 被 $V_w$ 近似时，表格情况下的收缩性质（方程 (34.87））可能不再成立。当 RL 算法具有以下三个组件时，可能会变得不稳定：非策略学习、自助（与 MC 相比，为了更快的学习）、函数近似（用于大规模 MDP 中的泛化）。这种组合被称为 **致命三元组** [SB18]。它突出了非策略学习引入的另一个重要挑战，也是正在进行研究的课题（例如，[van+18; Kum+19a]）。

在非策略学习中确保收敛的一种通用方法是构建一个目标函数，其最小化会得到一个良好的值函数近似；有关更多背景，请参见 [SB18, 第 11 章]。一个自然的候选者是 Bellman 最优方程 (34.82) 左右两边之间的差异，其唯一解为 $V_*$。但是，“max”算子不利于优化。相反，我们可以引入一个熵项来平滑贪婪策略，从而在 **路径一致性学习 (PCL)** [Nac+17] 中得到一个微分平方损失：

```
\min_{V, \pi} \mathcal{L}^{\text{PCL}}(V, \pi) \triangleq \mathbb{E} \left[ \frac{1}{2} \left( r + \gamma V(s') - \lambda \log \pi(a|s) - V(s) \right)^2 \right]
```

其中最小化是针对从某些非策略分布（例如，对 \(\mathcal{D}\) 均匀分布）中抽取的 $(s, a, r, s')$ 元组进行的。然而，最小化此损失通常不会得到最优值函数和策略，这是由于一个被称为“双重采样”的问题 [SB18, 第 11.5 节]。
