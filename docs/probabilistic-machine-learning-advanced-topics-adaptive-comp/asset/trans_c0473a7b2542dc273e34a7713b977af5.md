

最后，调整集合选择标准基于这样一个假设：在观察到的协变量中确实存在一个有效的调整集。当 X 中不存在一组能够阻断所有后门路径的观察到的协变量时，任何调整后的估计都会有偏差。重要的是，在这种情况下，偏差并不一定随着条件变量的增加而减少。例如，对工具变量进行条件设定通常会导致估计具有更高的偏差，此外还有上面讨论过的更高方差。这种现象被称为偏差放大或 z-偏差；参见第 36.7.2 节。一个经验法则是，那些对处理的变异解释远多于对结果的变异的变量可能会放大偏差，并应谨慎对待。

### 36.4.5.2 Overlap

请回顾，除了无未观察混杂因素外，平均处理效应的识别还需要重叠：即对于总体分布 P，条件 0 < P(A = 1|x) < 1 必须成立。在数据无限的情况下，任何程度的重叠都足以估计因果效应。在实际设置中，即使是重叠接近失效的情况也可能带来问题。公式 (36.39) 给出了我们估计的（渐近）方差的表达式：E[φ(X; Q̂, ĝ, τ̂)²]/n。注意，φ(X; Q̂, ĝ, τ̂)² 包含与 1/g(X) 和 1/(1 - g(X)) 成正比的项。因此，如果存在使得 g(x) ≈ 0 或 g(x) ≈ 1 的单位，我们估计器的方差将会急剧膨胀（除非这些单位足够罕见，以至于对期望的贡献不大）。

在实践中，处理潜在重叠违反的一种简单方法是为处理分配概率拟合一个模型 ĝ（这本身我们也需要做），并检查 ĝ(x) 的值是否不过分极端。如果某些值过于极端，最简单的解决办法是“作弊”。我们可以简单地排除所有 ĝ(x) 取极端值的数据。这等同于仅考虑满足重叠条件的子群体上的平均处理效应。这改变了估计量的解释。受限子群体的 ATE 可能会或不会对当前现实问题提供令人满意的答案，这需要基于对现实问题的了解来证明其合理性。

### 36.4.5.3 Choice of estimand and average treatment effect on the treated

通常，我们估计因果效应的目标是定性的。我们想知道效应的符号是什么，以及它是大还是小。ATE 的用途在于它提供了一个具体的查询，我们可以用它来定性地把握这个问题。然而，它并非神圣不可侵犯；有时我们最好选择一个替代性的因果估计量，它仍然回答定性问题，但在统计上更容易估计。处理组上的平均处理效应或 ATT，

ATT \triangleq \mathbb{E}_{X|A=1}[\mathbb{E}[Y|X, do(A=1)] - E[Y|X, do(A=0)]], \quad (36.43)

就是一个经常有用的此类估计量。

当人口中许多成员不太可能接受处理，但处理单位有相当高的概率接受对照时，ATT 很有用。例如，如果我们从总体中抽取对照单位，但处理单位全部从一个较小的子群体中自我选择进入处理，就会发生这种情况。在这种情况下，无法（非参数地）确定没有相似单位接受处理的对照单位的处理效应。ATT 通过简单地从平均值中排除此类单位来解决这个障碍。

如果我们有因果结构图 36.3，并且对于所有 X = x，重叠条件 P(A = 1|X = x) < 1 成立，则 ATT 在因果上被识别为

\(\tau^{\text{ATT}} = \mathbb{E}_{X|A=1}[\mathbb{E}[Y|A=1, X] - E[Y|A=0, X]].\)

注意，这里所需的重叠条件比识别 ATE 的条件更弱。（证明与定理 2 相同。）

ATE 的估计策略可以直接转化为 ATT 的估计策略。也就是说，以相同的方式估计扰动函数，然后仅将所有数据点上的平均值替换为仅处理数据点上的平均值。原则上，也可以利用未处理的数据点来稍微改进这一点。一个相应的双重机器学习估计器是

\(\hat{\tau}^{\text{ATT-AIPTW}} \triangleq \frac{1}{n} \sum_i \frac{A_i}{P(A=1)}(Y - \hat{Q}(0, X_i)) - \frac{(1-A_i)g(X)}{P(A=1)(1-g(X))}(Y - \hat{Q}(0, X_i))\)

该估计器的方差可以通过以下方式估计

\(\phi^{\text{ATT}}(\mathbf{X}_i; Q, g, \tau) \triangleq \frac{1}{n} \sum_i \left[ \frac{A_i}{P(A=1)}(Y - \hat{Q}(0, X_i)) - \frac{(1-A_i)g(X)}{P(A=1)(1-g(X))}(Y - \hat{Q}(0, X_i)) - \frac{A\tau}{P(A=1)} \right]\)

\(\hat{\mathbb{V}}[\hat{\tau}^{\text{ATT-AIPTW}}] \triangleq \frac{1}{n} \sum_i \phi^{\text{ATT}}(\mathbf{X}_i; \hat{Q}, \hat{g}, \hat{\tau}^{\text{ATT-AIPTW}}).\)

注意，ATT 的估计器不需要估计 Q(1, X)。当处理单位稀少时，这可能是一个相当大的优势。详情请参见 Chernozhukov et al. [Che+17e]。

### 36.4.6 Summary and practical advice

我们已经看到许多遵循一般程序的估计器：

- 1. 拟合统计或机器学习模型 \(\hat{Q}(a, x)\) 作为 Y 的预测器，和/或 \(\hat{g}(x)\) 作为 A 的预测器
- 2. 为每个数据点计算预测值 \(\hat{Q}(0, x_i), \hat{Q}(1, x_i), \hat{g}(x_i)，并
- 3. 将这些预测值组合成平均处理效应的估计。

重要的是，没有单一的估计方法是万能药。例如，双重机器学习估计器具有吸引人的理论性质，例如渐近效率保证以及无需对模型拟合进行自助法即可估计不确定性的方法。然而，就点估计的质量而言，双重 ML 估计器有时可能不如其更朴素的对应物 [KS07]。事实上，存在这样的情况：结果回归、倾向得分加权或双重稳健方法中的每一种都会胜过其他方法。

在实践中选择估计器的一个困难在于，因果推断中的保障措施比标准预测建模少。在预测建模中，我们构建训练-测试划分，并使用留出数据集中的真实标签或结果来验证预测模型。然而，对于因果问题，因果估计量是与我们实际观察到的数据生成过程不同的数据生成过程的函数。因此，使用标准技术无法实证验证因果估计的许多方面。

给定方法的有效性通常取决于我们对倾向得分或结果回归模型 $\hat{g}(x)$ 和 $\hat{Q}(a, x)$ 的规范的信任程度，以及数据集中处理组和对照组的重叠程度。为扰动函数 $g$ 和 $Q$ 使用灵活模型可以缓解一些关于模型误规范的担忧，但我们使用此类模型的自由度通常受数据集大小的限制。当我们有大量数据时，可以使用灵活模型；另一方面，当数据集相对较小时，我们可能需要使用较小的参数家族或严格的正则化来获得 $Q$ 和 $g$ 的稳定估计。同样，如果协变量空间中的某些区域重叠较差，那么 $Q$ 的灵活模型可能具有高度的变异性，且反倾向得分权重可能很大。在这些情况下，IPTW 或 AIPTW 估计可能会随着大权重而剧烈波动。同时，结果回归估计将对 $Q$ 模型及其正则化的规范敏感，并且如果规范或正则化与真实结果过程不匹配，可能会产生难以衡量的偏差。

我们可以采取许多实际步骤来对因果估计进行合理性检查。最简单的检查是使用 $Q$ 和 $g$ 的几个同样复杂的估计器，计算许多不同的 ATE 估计器（例如，结果回归、IPTW、双重稳健）。然后我们可以检查它们是否至少在定性上达成一致。如果它们达成一致，这可以带来一些安心（尽管这并不是准确性的保证）。如果它们不一致，则需要谨慎，特别是在选择 $Q$ 和 $g$ 模型的规范时。

检查重叠失效也很重要。通常，替代估计器之间的不一致等问题可以追溯到重叠不佳。特别是对于高维数据，一种常见的方法是检查估计的（理想情况下是交叉拟合的）倾向得分 $\hat{g}(x_i)$。即使打算只使用包含估计结果回归函数 $\hat{Q}(a, x_i)$ 的结果回归方法，这也是一种有用的诊断。如果重叠问题相关，那么最好估计处理组上的平均处理效应，或者通过丢弃极端倾向性单位来给出的“裁剪”估计量。

不确定性量化也是大多数因果分析的重要组成部分。这通常表现为估计器方差的估计或置信区间。这对下游决策可能很重要，也可以作为一种有用的诊断。我们可以通过自助法对整个程序（包括在每个自助重复中重新拟合模型）来计算方差，或者从 AIPTW 估计器计算解析方差估计。通常，较大的方差估计可能表明分析存在问题。例如，重叠不佳通常（尽管不总是）会在这两种方法中表现为极大的方差。较小的方差估计应谨慎对待，除非其他检查（例如重叠检查或不同 $Q$ 和 $g$ 模型之间的稳定性）也通过。

上述建议仅解决了从数据样本估计 $\tau$ 的统计问题。它并未涉及 $\tau$ 是否可以合理地解释为平均处理效应。应该花费相当大的精力来考虑没有未观察混杂因素的假设是否合理。有几种方法可以评估 ATE 估计对该假设违反的敏感性。参见第 36.7 节。由于未观察混杂因素导致的偏差在实践中可能非常大——通常会压倒估计误差导致的偏差——因此进行此类分析是明智的。
