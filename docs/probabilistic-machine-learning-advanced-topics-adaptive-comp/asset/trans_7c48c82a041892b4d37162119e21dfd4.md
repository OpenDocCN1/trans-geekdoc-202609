其中 \(\Delta\) 是离散步长（有关连续时间版本，请参见 [SS19, p221]）。为简单起见，我们假设状态向量完全可见（忽略观测噪声），因此 \( h(z) = z \)。

### 8.3.3 扩展卡尔曼平滑器（EKS）

我们可以将 EKF 扩展到离线平滑情况，从而得到扩展卡尔曼平滑器，也称为扩展 RTS 平滑器。在计算 \(\mathbf{F}_t\) 时，我们只需对滤波均值附近的动态进行线性化，然后即可应用标准卡尔曼平滑器更新。更多细节请参见 [SS23, Sec 13.1]。

为提高精度，可以使用迭代 EKS，它会在先前的 MAP 估计处重新线性化模型。在 [Bel94] 中，他们表明 IEKS 等同于一种用于计算平滑后验 MAP 估计的高斯-牛顿方法。遗憾的是，IEKS 在某些情况下可能会发散。一种稳健的 IEKS 方法，使用线搜索和 Levenberg-Marquardt 来更新参数，已在 [SS20a] 中提出。

## 8.4 基于无迹变换的推断

在本节中，我们用一种不同的近似方法取代模型的局部线性化。关键思想如下：不再计算动态和测量函数的线性近似，然后将高斯分布传递通过线性化后的函数，而是将联合分布 \( p(\mathbf{z}_{t-1}, \mathbf{z}_t | \mathbf{y}_{1:t-1}) \) 和 \( p(\mathbf{z}_t, \mathbf{y}_t | \mathbf{y}_{1:t-1}) \) 近似为高斯分布，其中矩通过数值积分计算；然后我们可以计算这些分布的边缘分布和条件分布，以执行时间更新和测量更新。

计算高斯矩的方法有多种，如第 8.5.1 节所述。这里我们使用一种基于无迹变换的方法（参见第 8.4.1 节）。对转移模型和观测模型使用无迹变换，得到的整体方法称为无迹卡尔曼滤波器（UKF），[JU97; JUDW00]，也称为系数点滤波器 [VDMW03]。

与 EKF 相比，UKF 的主要优势是其精度可能更高，且更稳定。（确实，[JU97; JUDW00] 声称“无迹”一词的提出是因为该方法“不会发臭”。）此外，UKF 不需要计算观测和动态模型的雅可比矩阵，因此可以应用于不可微模型或具有硬约束的模型。不过，UKF 可能会更慢，因为它需要对动态和观测模型进行 \( N_z \) 次求值。此外，它有 3 个需要设置的超参数。

```
Algorithm 8.5: Computing sigma points using unscented transform.
def SigmaPoints($\mu, \Sigma; \alpha, \beta, \kappa$):
  n = dimensionality of $\mu$
  $\lambda = \alpha^2(n + \kappa) - n$
  Compute a set of $2n + 1$ sigma points:
  $\mathcal{X}_0 = \mu, \mathcal{X}_i = \mu + \sqrt{n + \lambda} [\sqrt{\Sigma}]_{:i}, \mathcal{X}_{i+n} = \mu - \sqrt{n + \lambda} [\sqrt{\Sigma}]_{:i}$
  Compute a set of $2n + 1$ weights for the mean and covariance:
  $w_0^m = \frac{\lambda}{n+\lambda}, w_0^c = \frac{\lambda}{n+\lambda} + (1 - \alpha^2 + \beta), w_i^m = w_i^c = \frac{1}{2(n+\lambda)}$
  Return ($\mathcal{X}_{0:2n}, w_{0:2n}^m, w_{0:2n}^c$)
```

```
Algorithm 8.6: Unscented approximation to a joint Gaussian distribution.
def UnscentedMoments($\mu, \Sigma, g, \Omega; \alpha, \beta, \kappa$):
  ($\mathcal{X}_{0:2n}, w_{0:2n}^m, w_{0:2n}^c$) = SigmaPoints($\mu, \Sigma; \alpha, \beta, \kappa$)
  $\mathcal{Y}_i = g(\mathcal{X}_i), i=0:2n$
  $\hat{y} = \sum_{i=0}^{2n} w_i^m \mathcal{Y}_i$
  $\mathbf{S} = \sum_{i=0}^{2n} w_i^c (\mathcal{Y}_i - \hat{\mathbf{y}})(\mathcal{Y}_i - \hat{\mathbf{y}})^\top + \Omega$
  $\mathbf{C} = \sum_{i=0}^{2n} w_i^c (\mathcal{X}_i - \mu)(\mathcal{Y}_i - \hat{\mathbf{y}})^\top$
  Return ($\mathcal{X}_{0:2n}, w_{0:2n}^m, w_{0:2n}^c$)
```

### 8.4.1 无迹变换

假设我们有两个随机变量 $\mathbf{x} \sim \mathcal{N}(\mu, \Sigma)$ 和 $\mathbf{y} = g(\mathbf{x})$，其中 $g : \mathbb{R}^n \to \mathbb{R}^m$。无迹变换使用以下过程对 $p(\mathbf{y})$ 形成高斯近似。首先，我们使用算法 8.5 计算一组 $2n+1$ 个系数点 $\mathcal{X}_i$ 及其对应的权重 $w_i^m$ 和 $w_i^c$，其中 $i = 0 : 2n$。（符号 $\mathbf{M}_{:i}$ 表示矩阵 $\mathbf{M}$ 的第 $i$ 列，$\sqrt{\Sigma}$ 是矩阵平方根，因此 $\sqrt{\Sigma}\sqrt{\Sigma}^\top = \Sigma$。）接下来，我们将系数点通过非线性函数传播，得到以下 $2n + 1$ 个输出：

\[ \mathcal{Y}_i = g(\mathcal{X}_i), i = 0 : 2n \quad (8.148) \]

最后，我们估计所得点集的均值和协方差：

\[ \mathbb{E}[\mathbf{g}(\mathbf{x})] \approx \hat{\mathbf{y}} = \sum_{i=0}^{2n} w_i^m \mathcal{Y}_i \quad (8.149) \]

\[ \text{Cov}[\mathbf{g}(\mathbf{x})] \approx \mathbf{S}' = \sum_{i=0}^{2n} w_i^c (\mathcal{Y}_i - \hat{\mathbf{y}})(\mathcal{Y}_i - \hat{\mathbf{y}})^\top \quad (8.150) \]

现在假设我们想要近似联合分布 $p(\mathbf{x}, \mathbf{y})$，其中 $\mathbf{y} = g(\mathbf{x}) + \mathbf{e}$，且 $\mathbf{e} \sim \mathcal{N}(\mathbf{0}, \mathbf{\Omega})$。通过定义增广函数 $\tilde{\mathbf{g}}(\mathbf{x}) = (\mathbf{x}, \mathbf{g}(\mathbf{x}))$，并应用上述过程（并添加额外噪声），我们得到

\[ \begin{pmatrix} \boldsymbol{x} \\ \boldsymbol{y} \end{pmatrix} \sim \mathcal{N}\left( \begin{pmatrix} \boldsymbol{\mu} \\ \hat{\mathbf{y}} \end{pmatrix}, \begin{pmatrix} \boldsymbol{\Sigma} & \mathbf{C} \\ \mathbf{C}^{\top} & \mathbf{S} \end{pmatrix} \right) \quad (8.151) \]

其中参数使用算法 8.6 计算。

系数点及其权重取决于三个超参数，\(\alpha\)、\(\beta\) 和 \(\kappa\)，它们决定系数点围绕均值的分布范围。这些参数的典型推荐设置是 \(\alpha=10^{-3}\)、\(\kappa=1\)、\(\beta=2\) [Bit16]。

在图 8.5(a-b) 中，我们展示了在第 8.3.1 节中讨论的线性化泰勒变换应用于非线性函数的情况。在图 8.5(c-d) 中，我们展示了相应的无迹变换，可以看出其更精确。事实上，无迹变换（使用 \(2n+1\) 个系数点）是一种三阶方法，因为 \(\boldsymbol{y}\) 的均值对于最高 3 阶多项式是精确的。然而，协方差仅对于线性函数（一阶多项式）是精确的，因为二阶多项式的平方已经是四阶。不过，UT 的思想可以使用 \(2n^2+1\) 个系数点扩展到五阶 [MS67]；这可以对二次函数精确捕获协方差项。我们在第 8.5.1.4 节中讨论了基于数值积分方法的更精确近似。

### 8.4.2 无迹卡尔曼滤波器（UKF）

UKF 两次应用无迹变换，一次用于近似通过系统模型 \(\mathbf{f}\)，一次用于近似通过测量模型 \(\mathbf{h}\)。参照第 8.2.2.5 节，我们可以推导出 UKF 算法如下：

\[ (\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, -) = \text{UnscentedMoments}(\boldsymbol{\mu}_{t-1|t-1}, \boldsymbol{\Sigma}_{t-1|t-1}, \mathbf{f}(\cdot, \mathbf{u}_t), \mathbf{Q}_t) \quad (8.152) \]

\[ (\hat{\mathbf{y}}_t, \mathbf{S}_t, \mathbf{C}_t) = \text{UnscentedMoments}(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \mathbf{h}(\cdot, \mathbf{u}_t), \mathbf{R}_t) \quad (8.153) \]

\[ (\boldsymbol{\mu}_{t|t}, \boldsymbol{\Sigma}_{t|t}, \ell_t) = \text{GaussCondition}(\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1}, \hat{\mathbf{y}}_t, \mathbf{S}_t, \mathbf{C}_t, \boldsymbol{\gamma}_t) \quad (8.154) \]

更多细节请参见 [SS23, Sec 8.8]。

### 8.4.3 无迹卡尔曼平滑器（UKS）

无迹卡尔曼平滑器，也称为无迹 RTS 平滑器 [Sar08]，是对常规卡尔曼平滑方法的一种简单修改，其中非线性通过无迹变换进行近似。关键洞察在于注意到方程 (8.80) 中的逆向卡尔曼增益矩阵 \(\mathbf{G}_t\) 可以用预测协方差和交叉协方差来定义，这两者都可以使用 UT 来估计。一旦计算出这些值，我们就可以以通常的方式使用 RTS 方程式。更多细节请参见 [SS23, Sec 14.4]。

无迹卡尔曼平滑的一个有趣应用是英国政府将其作为其 COVID-19 接触者追踪应用的一部分所使用的 [Lov+20; BCH20]。该应用使用 UKS 根据移动电话之间的蓝牙信号强度来估计（匿名）人员之间的距离；然后将距离与其他信号（如接触持续时间和索引病例的传染性水平）相结合，以估计传播风险。（另请参见 [MKS21]，了解学习风险评分的方法。）
