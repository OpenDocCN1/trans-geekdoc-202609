

我们可以如下计算交叉熵的经验近似。假设我们用基于从 \(p\) 中采样的数据构建的经验分布来近似真实分布：

\(p_{\mathcal{D}}(x|\mathcal{D}) = \frac{1}{N} \sum_{n=1}^N \mathbb{I}(x = x_n)\) (5.105)

在这种情况下，交叉熵由以下公式给出

\(H = -\frac{1}{N} \sum_{n=1}^N \log p(x_n) = -\frac{1}{N} \log \prod_{n=1}^N p(x_n)\) (5.106)

对应的困惑度由以下公式给出

\(\text{perplexity}(p_{\mathcal{D}}, p) = 2^{-\frac{1}{N} \log (\prod_{n=1}^N p(x_n))} = 2^{\log (\prod_{n=1}^N p(x_n))^{-\frac{1}{N}}}\) (5.107)

\(= (\prod_{n=1}^N p(x_n))^{-1/N} = \sqrt[N]{\prod_{n=1}^N \frac{1}{p(x_n)}}\) (5.108)

在语言模型的情况下，我们在预测下一个词时通常会条件化于前面的词。例如，在二元语法模型中，我们使用形式为 \(p(x_n|x_{n-1})\) 的二阶马尔可夫模型。我们将语言模型的**分支因子**定义为任何给定词后面可能出现的词的数量。例如，假设模型预测每个词出现的概率相同，与上下文无关，因此 \(p(x_n|x_{n-1}) = 1/K\)，其中 \(K\) 是词汇表中的词数。那么困惑度为 \(((1/K)^N)^{-1/N} = K\)。如果某些符号比其他符号更可能出现，并且模型正确地反映了这一点，则其困惑度将低于 \(K\)。然而，我们有 \(\mathbb{H}(p^*) \le \mathbb{H}_{ce}(p^*, p)\)，因此我们永远无法将困惑度降低到 \(2^{-\mathbb{H}(p^*)}\) 以下。

## 5.3 互信息

KL 散度为我们提供了一种衡量两个分布相似程度的方法。我们应如何衡量两个随机变量之间的依赖程度呢？我们可以做的一件事是，将衡量两个随机变量依赖程度的问题转化为衡量它们分布相似程度的问题。这引出了两个随机变量之间**互信息**（MI）的概念，我们将在下面对其进行定义。

### 5.3.1 定义

随机变量 \(X\) 和 \(Y\) 之间的互信息定义如下：

\(\mathbb{I}(X;Y) \triangleq D_{KL}(p(x,y) \parallel p(x)p(y)) = \sum_{y \in Y} \sum_{x \in X} p(x,y) \log \frac{p(x,y)}{p(x)p(y)}\) (5.109)

（我们写 \(\mathbb{I}(X;Y)\) 而不是 \(\mathbb{I}(X, Y)\)，以防 \(X\) 和/或 \(Y\) 表示变量集；例如，我们可以写 \(\mathbb{I}(X; Y, Z)\) 来表示 \(X\) 与 \((Y, Z)\) 之间的互信息。）对于连续随机变量，我们只需将求和替换为积分即可。

很容易看出，互信息总是非负的，即使对于连续随机变量也是如此，因为

\(\mathbb{I}(X;Y) = D_{\text{KL}}(p(x,y) \| p(x)p(y)) \ge 0\)

当且仅当 \(p(x,y) = p(x)p(y)\) 时，我们才能达到 0 的下界。

### 5.3.2 解释

了解互信息是联合分布与乘积边缘分布之间的 KL 散度，这告诉我们，互信息衡量的是当我们从将两个变量视为独立的模型 \(p(x)p(y)\) 更新为模拟它们真实联合密度 \(p(x, y)\) 的模型时所获得的信息增益。

为了进一步了解互信息的含义，将其用联合熵和条件熵重新表达是有帮助的，如下所示：

\(\mathbb{I}(X;Y) = \mathbb{H}(X) - \mathbb{H}(X|Y) = \mathbb{H}(Y) - \mathbb{H}(Y|X)\)

因此，我们可以将 \(X\) 和 \(Y\) 之间的互信息解释为在观察到 \(Y\) 后关于 \(X\) 的不确定性的降低，或者，由于对称性，是在观察到 \(X\) 后关于 \(Y\) 的不确定性的降低。顺便提一下，这个结果给出了平均而言条件化会降低熵的另一种证明。特别是，我们有 \(0 \le \mathbb{I}(X;Y) = \mathbb{H}(X) - \mathbb{H}(X|Y)\)，因此 \(\mathbb{H}(X|Y) \le \mathbb{H}(X)\)。

我们还可以得到另一种解释。可以证明

\(\mathbb{I}(X;Y) = \mathbb{H}(X,Y) - \mathbb{H}(X|Y) - \mathbb{H}(Y|X)\)

最后，可以证明

\(\mathbb{I}(X;Y) = \mathbb{H}(X) + \mathbb{H}(Y) - \mathbb{H}(X,Y)\)

参见图 5.6，了解这些方程在**信息图**方面的总结。（正式地，这是一个将集合表达式映射到其信息论对应项的有符号测度 [Yeu91a]。）

### 5.3.3 数据处理不等式

假设我们有一个未知变量 \(X\)，并且我们观察到它的一个带噪声的函数，称其为 \(Y\)。如果我们以某种方式处理带噪声的观测结果以创建一个新变量 \(Z\)，那么直观上很明显，我们无法增加关于未知量 \(X\) 的信息量。这被称为**数据处理不等式**。我们现在更正式地陈述它，然后进行证明。

**定理 5.3.1.** 假设 \(X \rightarrow Y \rightarrow Z\) 构成一个马尔可夫链，即 \(X \perp Z|Y\)。那么 \(\mathbb{I}(X;Y) \ge \mathbb{I}(X;Z)\)。

**证明.** 根据互信息的链式法则，我们可以以两种不同的方式展开互信息：

\(\mathbb{I}(X;Y,Z) = \mathbb{I}(X;Z) + \mathbb{I}(X;Y|Z)\)
\(= \mathbb{I}(X;Y) + \mathbb{I}(X;Z|Y)\)

由于 \(X \perp Z|Y\)，我们有 \(\mathbb{I}(X;Z|Y) = 0\)，因此

\(\mathbb{I}(X;Z) + \mathbb{I}(X;Y|Z) = \mathbb{I}(X;Y)\)

由于 \(\mathbb{I}(X;Y|Z) \ge 0\)，我们有 \(\mathbb{I}(X;Y) \ge \mathbb{I}(X;Z)\)。同样，可以证明 \(\mathbb{I}(Y;Z) \ge \mathbb{I}(X;Z)\)。

### 5.3.4 充分统计量

DPI 的一个重要结果如下。假设我们有链 \(\theta \to X \to s(X)\)。那么

\(I(\theta; s(X)) \le I(\theta; X)\)

如果这成立且取等号，则我们说 \(s(X)\) 是为了推断 \(\theta\) 而对数据 \(X\) 的**充分统计量**。在这种情况下，我们可以等价地写成 \(\theta \to s(X) \to X\)，因为从知道 \(s(X)\) 中重构数据的准确性与从知道 \(\theta\) 中一样。

充分统计量的一个例子是数据本身，\(s(X) = X\)，但这并不十分有用，因为它根本没有对数据进行总结。因此，我们定义**极小充分统计量** \(s(X)\) 为既充分且不包含关于 \(\theta\) 的额外信息的统计量；因此，\(s(X)\) 在不丢失与预测 \(\theta\) 相关的信息的前提下，对数据 \(X\) 进行最大程度的压缩。更正式地说，如果对于某个函数 \(f\) 和所有充分统计量 \(s'(X)\)，都有 \(s(X) = f(s'(X))\)，则我们说 \(s\) 是 \(X\) 的极小充分统计量。我们可以总结如下：

\(\theta \to s(X) \to s'(X) \to X\)

这里 \(s'(X)\) 获取 \(s(X)\) 并向其中添加冗余信息，从而创建一对多的映射。

例如，一组 \(N\) 个伯努利试验的极小充分统计量仅仅是 \(N\) 和 \(N_1 = \sum_n \mathbb{I}(X_n = 1)\)，即成功次数。换句话说，我们不需要跟踪完整的正反面序列及其顺序，只需跟踪正面和反面的总数。同样，在已知方差的情况下推断高斯分布的均值时，我们只需要知道经验均值和样本数量。

如前面在第 5.1.8 节中所述，我们将指数分布族动机设定为那些在意义上是最小的分布，即它们除了对数据某些统计量的约束外不包含其他信息。那么，用于生成指数分布族分布的统计量是充分的，这也是合理的。它还暗示了 Pitman-Koopman-Darmois 定理的更显著事实，即对于任何定域固定的分布，只有指数分布族允许随着样本数量增加而具有有限维度的充分统计量 [Dia88b]。

### 5.3.5 多元互信息

有几种方法可以将互信息的概念推广到一组随机变量，我们将在下面讨论。

### 5.3.5.1 总相关性

定义多元互信息的最简单方法是使用总相关性 [Wat60] 或多元信息 [SV98]，定义如下

\(\mathbb{TC}(\{X_1, \dots, X_D\}) \triangleq D_{KL} \left( p(x) \| \prod_d p(x_d) \right)\)

\(= \sum_x p(x) \log \frac{p(x)}{\prod_{d=1}^D p(x_d)} = \sum_d \mathbb{H}(x_d) - \mathbb{H}(x)\)

例如，对于 3 个变量，这变为

\(\mathbb{TC}(X, Y, Z) = \mathbb{H}(X) + \mathbb{H}(Y) + \mathbb{H}(Z) - \mathbb{H}(X, Y, Z)\)

其中 H(X, Y, Z) 是联合熵

\(\mathbb{H}(X, Y, Z) = - \sum_x \sum_y \sum_z p(x, y, z) \log p(x, y, z)\)

可以证明多元信息总是非负的，并且当且仅当 \(p(x) = \prod_d p(x_d)\) 时才为零。然而，这意味着即使只有两个变量之间存在交互作用，该量也非零。例如，如果 \(p(X, Y, Z) = p(X, Y)p(Z)\)，则总相关性将非零，尽管没有三方交互作用。这激发了 5.3.5.2 节中的另一种定义。

### 5.3.5.2 交互信息（共同信息）

条件互信息可以用来对多元互信息（MMI）进行归纳定义，如下所示：

\(\mathbb{I}(X_1; \cdots ; X_D) = \mathbb{I}(X_1; \cdots ; X_{D-1}) - \mathbb{I}(X_1; \cdots ; X_{D-1} | X_D)\)

这被称为多元互信息 [Yeu91b] 或共同信息 [Bel03]。该定义与交互信息 [McG54; Han80; JB03; Bro09] 等价，仅相差一个符号变化。
