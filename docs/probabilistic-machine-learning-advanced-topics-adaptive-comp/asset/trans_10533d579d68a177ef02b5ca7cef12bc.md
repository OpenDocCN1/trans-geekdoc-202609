

我们说，一个马尔可夫链 **A** 是时序可逆的，如果存在一个分布 $\pi$，使得 $\pi_i A_{ij} = \pi_j A_{ji}$ (2.285)。这些被称为**详细平衡方程**。这意味着从 $i$ 到 $j$ 的流必须等于从 $j$ 到 $i$ 的流，按适当的源概率加权。我们有以下重要结果。

### **定理 2.6.3.**

如果一个具有转移矩阵 **A** 的马尔可夫链是正则的，并且相对于分布 $\pi$ 满足详细平衡方程，那么 $\pi$ 是该链的平稳分布。

**证明.** 要看到这一点，注意 $\sum_i \pi_i A_{ij} = \sum_i \pi_j A_{ji} = \pi_j \sum_i A_{ji} = \pi_j$ (2.286)。

因此 $\pi = \mathbf{A}\pi$。

注意，这个条件是充分但不是必要的（有关不满足详细平衡的平稳分布链的示例，请参见图 2.18(a)）。

## 2.7 概率分布之间的差异度量

在本节中，我们讨论比较两个在同一空间上定义的概率分布 $P$ 和 $Q$ 的各种方法。例如，假设分布是根据样本定义的，$\mathcal{X} = \{x_1, ..., x_N\} \sim P$ 和 $\mathcal{X}' = \{\tilde{x}_1, ..., \tilde{x}_M\} \sim Q$。确定样本是否来自同一分布被称为**双样本检验**（有关说明，请参见图 2.19）。这可以通过定义某个合适的**差异度量** $D(P, Q)$ 并将其与阈值进行比较来计算。（我们使用“差异”一词而不是距离，因为我们不要求 $D$ 是对称的。）或者，假设 $P$ 是数据的经验分布，$Q$ 是模型诱导的分布。我们可以通过比较 $D(P, Q)$ 与阈值来检查模型对数据的拟合程度；这称为**拟合优度**检验。

计算一对分布之间差异的两种主要方式是：基于它们的差，$P - Q$（例如，参见 [Sug+13]），或基于它们的比，$P/Q$（例如，参见 [SSK12]）。我们下面简要讨论这两种方式。（我们的介绍部分基于 [GSJ19]。）

### 2.7.1 f-差异

在本节中，我们根据密度比 $r(x) = p(x)/q(x)$ 比较分布。特别是，考虑**f-差异** [Mor63; AS66; Csi67; LV06; CS04]，其定义如下：

$$D_f(p||q) = \int q(x) f \left( \frac{p(x)}{q(x)} \right) dx$$ (2.287)

其中 $f : \mathbb{R}_+ \to \mathbb{R}$ 是满足 $f(1) = 0$ 的凸函数。根据詹森不等式（第 5.1.2.2 节），可得 $D_f(p||q) \ge 0$，并且显然 $D_f(p||p) = 0$，因此 $D_f$ 是一个有效的差异。下面我们讨论 f-差异的一些重要特例。（注意，f-差异也称为 $\phi$-差异。）

#### 2.7.1.1 KL 差异

假设我们使用 f(r) = r log(r) 计算 f-差异。在这种情况下，我们得到一个称为 Kullback-Leibler 差异的量，定义如下：

$$D_{\text{KL}}(p \| q) = \int p(x) \log \frac{p(x)}{q(x)} dx$$ (2.288)

有关更多详细信息，请参见第 5.1 节。

#### 2.7.1.2 Alpha 差异

如果 $f(x) = \frac{4}{1-\alpha^2}(1 - x^{\frac{1+\alpha}{2}})$，则 f-差异变为 alpha 差异 [Ama09]，如下所示：

$$D_\alpha^A(p||q) \triangleq \frac{4}{1-\alpha^2} \left( 1 - \int p(x)^{(1+\alpha)/2} q(x)^{(1-\alpha)/2} dx \right)$$ (2.289)

其中我们假设 $\alpha \neq \pm 1$。另一种常见的参数化方式，也是 Minka 在 [Min05] 中使用的方式，如下所示：

$$D_\alpha^M(p||q) = \frac{1}{\alpha(1-\alpha)} \left( 1 - \int p(x)^\alpha q(x)^{1-\alpha} dx \right)$$ (2.290)

这可以使用 $D_{\alpha'}^A = D_\alpha^M$ 将其转换为 Amari 的记法，其中 $\alpha' = 2\alpha - 1$。（我们将使用 Minka 约定。）我们从图 2.20 可以看出，当 \(\alpha \to -\infty\) 时，$q$ 倾向于匹配 $p$ 的一个模式，而当 \(\alpha \to \infty\) 时，$q$ 倾向于覆盖 $p$ 的所有部分。更准确地说，可以证明当 \(\alpha \to 0\) 时，alpha 差异趋向于 \(D_{\text{KL}} (q \| p)\)，而当 \(\alpha \to 1\) 时，alpha 差异趋向于 \(D_{\text{KL}} (p \| q)\)。另外，当 \(\alpha = 0.5\) 时，alpha 差异等于 Hellinger 距离（第 2.7.1.3 节）。

#### 2.7.1.3 Hellinger 距离

（平方）Hellinger 距离定义如下：

\(D_H^2(p||q) \triangleq \frac{1}{2} \int \left( p(x)^{\frac{1}{2}} - q(x)^{\frac{1}{2}} \right)^2 dx = 1 - \int \sqrt{p(x)q(x)}dx\) (2.291)

这是一个有效的距离度量，因为它是对称的、非负的，并且满足三角不等式。我们可以看到，这等于（以常数因子为准）具有 \(f(r) = (\sqrt{r} - 1)^2\) 的 \(f\)-差异，因为

\(\int dx \, q(x) \left( \frac{p^{\frac{1}{2}}(x)}{q^{\frac{1}{2}}(x)} - 1 \right)^2 = \int dx \, q(x) \left( \frac{p^{\frac{1}{2}}(x) - q^{\frac{1}{2}}(x)}{q^{\frac{1}{2}}(x)} \right)^2 = \int dx \left( p^{\frac{1}{2}}(x) - q^{\frac{1}{2}}(x) \right)^2\) (2.292)

#### 2.7.1.4 Chi-squared 距离

Chi-squared 距离 \(\chi^2\) 定义为

\(\chi^2(p, q) \triangleq \frac{1}{2} \int \frac{(q(x) - p(x))^2}{q(x)} dx\) (2.293)

这等于（以常数因子为准）具有 \(f(r) = (r - 1)^2\) 的 \(f\)-差异，因为

\(\int dx \, q(x) \left( \frac{p(x)}{q(x)} - 1 \right)^2 = \int dx \, q(x) \left( \frac{p(x) - q(x)}{q(x)} \right)^2 = \int dx \, \frac{1}{q(x)} (p(x) - q(x))^2\) (2.294)

### 2.7.2 积分概率度量

在本节中，我们使用积分概率度量（或 IPM）[Sri+09] 计算两个分布在 \(P - Q\) 意义上的差异。其定义如下：

\(D_{\mathcal{F}}(P, Q) \triangleq \sup_{f \in \mathcal{F}} | \mathbb{E}_{p(x)} [f(\boldsymbol{x})] - \mathbb{E}_{q(x')} [f(\boldsymbol{x}')] |\) (2.295)

其中 \(\mathcal{F}\) 是某些“平滑”函数的类。使这两个期望之间的差异最大化的函数 \(f\) 称为证人函数。有关说明，请参见图 2.21。

定义函数类 \(\mathcal{F}\) 有几种方法。一种方法是使用 RKHS，其定义基于正定核函数；这产生了称为最大均值差异或 MMD 的方法。有关详细信息，请参见第 2.7.3 节。另一种方法是定义 \(\mathcal{F}\) 为具有有限 Lipschitz 常数的函数集，即 \(\mathcal{F} = \{ \|f\|_L \le 1 \}\)，其中

\(\|f\|_L = \sup_{\boldsymbol{x} \neq \boldsymbol{x}'} \frac{|f(\boldsymbol{x}) - f(\boldsymbol{x}')|}{\|\boldsymbol{x} - \boldsymbol{x}'\|}\) (2.296)

![](img/ca72c1626f4850f058a9edc138c1ac73_89_0.png)

Figure 2.21: 用于比较两个分布（(a) 不同和 (b) 相似）的平滑证人函数。来自 [GSJ19] 的图片。经 Arthur Gretton 许可使用。

在这种情况下，IPM 等于 **Wasserstein-1 距离**

```
$$W_1(P, Q) \triangleq \sup_{\|f\|_L \le 1} | \mathbb{E}_{p(x)} [f(x)] - \mathbb{E}_{q(x')} [f(x')] |$$
```

有关更多详细信息，请参见第 6.8.2.4 节。

## 2.7.3 最大均值差异（MMD）

在本节中，我们描述 [Gre+12] 的 **最大均值差异** 或 **MMD** 方法，该方法使用两个分布的样本来定义差异度量 \(D(P, Q)\)。样本使用正定核（第 18.2 节）进行比较，可处理高维输入。此方法可用于定义双样本检验，并训练隐式生成模型（第 26.2.4 节）。

### 2.7.3.1 作为 IPM 的 MMD

MMD 是一个积分概率度量（第 2.7.2 节），形式如下：

```
$$\text{MMD}(P, Q; \mathcal{F}) = \sup_{f \in \mathcal{F}: \|f\| \le 1} [\mathbb{E}_{p(x)} [f(x)] - \mathbb{E}_{q(x')} [f(x')]]$$
```

其中 \(\mathcal{F}\) 是由正定核函数 \(\mathcal{K}\) 定义的 RKHS（第 18.3.7.1 节）。我们可以将此集中的函数表示为基函数的无限和

```
$$f(x) = \langle f, \phi(x) \rangle_{\mathcal{F}} = \sum_{l=1}^{\infty} f_l \phi_l(x)$$
```

我们将证人函数 \(f\) 的集合限制为位于此 RKHS 单位球中的函数，因此 \(\|f\|_{\mathcal{F}}^2 = \sum_{l=1}^{\infty} f_l^2 \le 1\)。根据期望的线性性质，我们有

```
$$\mathbb{E}_{p(x)} [f(x)] = \langle f, \mathbb{E}_{p(x)} [\phi(x)] \rangle_{\mathcal{F}} = \langle f, \mu_P \rangle_{\mathcal{F}}$$
```
