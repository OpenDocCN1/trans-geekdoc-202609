### 20.3.6 隐空间算术

在某些情况下，我们可以超越插值，并执行 **隐空间算术**，其中我们可以增加或减少所需的“语义变异因子”的量。这最初在 **word2vec** 模型 [Mik+13] 中展示，但在其他隐变量模型中也是可能的。例如，考虑我们拟合到 CelebA 数据集的 VAE 模型，该数据集包含名人面部及一些相应属性。设 $\mathbf{X}_i^+$ 为具有属性 $i$ 的图像集合，$\mathbf{X}_i^-$ 为不具有该属性的图像集合。设 $\mathbf{Z}_i^+$ 和 $\mathbf{Z}_i^-$ 为相应的嵌入，$\bar{\mathbf{z}}_i^+$ 和 $\bar{\mathbf{z}}_i^-$ 为这些嵌入的平均值。我们定义偏移向量为 $\Delta_i = \bar{\mathbf{z}}_i^+ - \bar{\mathbf{z}}_i^-$。如果将 $\Delta_i$ 的某个正倍数加到新点 $\boldsymbol{z}$，我们就增加了属性 $i$ 的量；如果减去 $\Delta_i$ 的某个倍数，我们就减少了属性 $i$ 的量 [Whi16]。

我们在图 20.10 中给出了此示例。我们考虑戴太阳镜的属性。第 $j$ 个重建通过 $\hat{\mathbf{x}}_j = d(\boldsymbol{z} + s_j \boldsymbol{\Delta})$ 计算，其中 $\boldsymbol{z} = e(\boldsymbol{x})$ 是原始图像的编码，$s_j$ 是缩放因子。当 $s_j > 0$ 时，我们在面部添加太阳镜。当 $s_j < 0$ 时，我们移除太阳镜；但这也会产生副作用，使面部看起来更年轻、更女性化，可能是数据集偏差的结果。

### 20.3.8 基于模型的强化学习

我们在第 35 章讨论强化学习（RL）。迄今为止，RL 的主要成功案例在于计算机游戏，其中存在模拟器且数据充足。然而，在机器人技术等其他领域，数据获取成本高昂。在这种情况下，学习一个生成式“世界模型”可能很有用，以便代理可以“在脑海中”进行规划和学习。更多详情请参见第 35.4 节。

### 20.3.9 表示学习

表示学习是指学习生成观测数据 x 的（可能不可解释的）隐因子 z。主要目标是这些特征可用于“下游”监督任务。这在第 32 章中讨论。

### 20.3.10 数据压缩

能够对经常出现的数据向量（例如，图像、句子）分配高概率，对稀有向量分配低概率的模型可用于数据压缩，因为我们可以为更常见的项目分配更短的代码。确实，来自某些随机源 p(x) 的向量 x 的最优编码长度为 l(x) = − log p(x)，如 Shannon 所证明。详情请参见第 5.4 节。

## 20.4 评估生成模型

> 本节由 Mihaela Rosca、Shakir Mohamed 和 Balaji Lakshminarayanan 编写。

评估生成模型需要能够捕捉以下方面的指标：

- 样本质量 — 模型生成的样本是否属于数据分布？

- 样本多样性 — 模型分布的样本是否捕捉了数据分布的所有模式？

- 泛化 — 模型是否超越了训练数据进行泛化？

没有已知的指标能同时满足所有这些要求，但已提出了各种指标来捕捉学习分布的不同方面，下面我们将讨论其中一些。

### 20.4.1 基于似然的评估

衡量模型 q 与真实分布 p 接近程度的一种标准方法是使用 KL 散度（第 5.1 节）：

$$D_{\text{KL}}(p \| q) = \int p(\boldsymbol{x}) \log \frac{p(\boldsymbol{x})}{q(\boldsymbol{x})} = - \mathbb{H}(p) + \mathbb{H}_{\text{ce}}(p, q)$$

其中 $\mathbb{H}(p)$ 是一个常数，$\mathbb{H}_{ce}(p, q)$ 是交叉熵。如果我们用经验分布来近似 $p(\boldsymbol{x})$，则可以在数据集上用经验 **负对数似然** 来评估交叉熵：

$$\text{NLL} = -\frac{1}{N} \sum_{n=1}^N \log q(\boldsymbol{x}_n)$$

通常我们关心留出测试集上的负对数似然。

### 20.4.1.1 计算对数似然

对于离散数据模型（如语言模型），计算（负）对数似然很容易。然而，通常使用一种称为 **困惑度** 的量来衡量性能，它定义为 $2^H$，其中 $H = \text{NLL}$ 是交叉熵或负对数似然。

对于图像和音频模型，一个复杂之处在于模型通常是连续分布 $p(\boldsymbol{x}) \ge 0$，但数据通常是离散的（例如，如果我们每像素使用一个字节，则 $\boldsymbol{x} \in \{0, \dots, 255\}^D$）。因此，平均对数似然可以任意大，因为概率密度函数可以大于 1。为避免这种情况，标准做法是使用 **均匀去量化** [TOB16]，即向离散数据添加均匀随机噪声，然后将其视为连续值数据。这给出了离散模型在原始数据上的平均对数似然的下界。

要理解这一点，设 $\boldsymbol{z}$ 为连续隐变量，$\boldsymbol{x}$ 为通过四舍五入计算得到的二元观测向量，因此 $p(\boldsymbol{x}|\boldsymbol{z}) = \delta(\boldsymbol{x} - \text{round}(\boldsymbol{z}))$，逐元素计算。我们有 $p(\boldsymbol{x}) = \int p(\boldsymbol{x}|\boldsymbol{z})p(\boldsymbol{z})d\boldsymbol{z}$。设 $q(\boldsymbol{z}|\boldsymbol{x})$ 为 $\boldsymbol{x}$ 的概率逆，即它仅在 $p(\boldsymbol{x}|\boldsymbol{z})=1$ 的值上有支撑。在此情况下，根据 Jensen 不等式，

$$\log p(\boldsymbol{x}) \ge \mathbb{E}_{q(\boldsymbol{z}|\boldsymbol{x})} [\log p(\boldsymbol{x}|\boldsymbol{z}) + \log p(\boldsymbol{z}) - \log q(\boldsymbol{z}|\boldsymbol{x})]$$

$$= \mathbb{E}_{q(\boldsymbol{z}|\boldsymbol{x})} [\log p(\boldsymbol{z}) - \log q(\boldsymbol{z}|\boldsymbol{x})]$$

因此，如果我们对 $z \sim q(\boldsymbol{z}|\boldsymbol{x})$ 的密度建模，它是 $\boldsymbol{x}$ 的去量化版本，我们将得到 $p(\boldsymbol{x})$ 的下界。
