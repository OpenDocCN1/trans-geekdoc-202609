## 12.8 可逆跳跃（跨维）MCMC

假设我们有一组参数数量不同的模型，例如，混合模型中混合成分的数量未知。令模型表示为 m，令其未知数（例如，参数）表示为 \(x_m \in X_m\)（例如，\(X_m = R^n_m\)，其中 \(n_m\) 是模型 m 的维数）。在不同维数的空间中进行采样称为跨维 MCMC。我们可以采样模型指示器 \(m \in \{1, ..., M\}\)，并从乘积空间 \(\prod^M_{m=1} X_m\) 中采样所有参数，但这非常低效，且仅在 M 为有限时有效。在并集空间 \(X = \cup^M_{m=1}\{m\} \times X_m\) 中采样更为精简，其中我们只关心当前活跃模型的参数。

这种方法的困难在于在不同维数的模型之间移动时出现。问题在于，当我们计算 MH 接受率时，我们正在比较定义在不同维数空间上的密度，这没有明确定义。例如，比较球面上两个点的密度是有意义的，但将球面上的密度与圆上的密度进行比较则没有意义，因为这两个概念之间存在维数不匹配。[Gre98] 提出的解决方案，称为可逆跳跃 MCMC 或 RJMCMC，是用额外的随机变量扩展低维空间，使两个空间具有共同的度量。图 12.19 对此进行了说明。

### 12.8.1 基本思想

为了更详细地说明该方法，我们遵循 [And+03] 的表述。为了确保共同的度量，我们需要定义一种方法，将每对子空间 \(\mathcal{X}_m\) 和 \(\mathcal{X}_n\) 扩展到 \(\mathcal{X}_{m,n} = \mathcal{X}_m \times \mathcal{U}_{m,n}\) 和 \(\mathcal{X}_{n,m} = \mathcal{X}_n \times \mathcal{U}_{n,m}\)。我们还需要定义一个确定的、可微的和可逆的映射

\[
(x_m, u_{m,n}) = f_{n \to m}(x_n, u_{n,m}) = (f_{n \to m}^x(x_n, u_{n,m}), f_{n \to m}^u(x_n, u_{n,m})) \quad (12.134)
\]

可逆性意味着

\[
f_{m \to n}(f_{n \to m}(x_n, u_{n,m})) = (x_n, u_{n,m}) \quad (12.135)
\]

最后，我们需要定义提议 \(q_{n \to m}(u_{m,n}|n, x_n)\) 和 \(q_{m \to n}(u_{m,n}|m, x_m)\)。假设我们处于状态 \((n, x_n)\)。我们通过生成 \(u_{n,m} \sim q_{n \to m}(\cdot|n, x_n)\) 移动到 \((m, x_m)\)，然后计算 \((x_m, u_{m,n}) = f_{n \to m}(x_n, u_{n,m})\)。然后我们以如下概率接受该移动：

\[
A_{n \to m} = \min \left\{ 1, \frac{p(m, x_m^*)}{p(n, x_n)} \times \frac{q(n|m)}{q(m|n)} \times \frac{q_{m \to n}(u_{m,n}|m, x_m^*)}{q_{n \to m}(u_{m,n}|n, x_n)} \times |\det J_{f_{m \to n}}| \right\} \quad (12.136)
\]

其中 \(x_m^* = f_{n \to m}^x(x_n, u_{n,m})\)，\(J_{f_{m \to n}}\) 是变换的雅可比矩阵

\[
J_{f_{m \to n}} = \frac{\partial f_{n \to m}(x_m, u_{m,n})}{\partial(x_m, u_{m,n})} \quad (12.137)
\]

而 \(|\det \mathbf{J}|\) 是雅可比行列式的绝对值。

### 12.8.2 示例

让我们考虑 [AFD01] 的一个例子。他们考虑一种用于非线性回归的 RBF 网络，形式为

\[
f(x) = \sum_{j=1}^k a_j \mathcal{K}(||x - \mu_j||) + \beta^T x + \beta_0 + \epsilon \quad (12.138)
\]

其中 \(\mathcal{K}()\) 是某种核函数（例如，高斯函数），\(k\) 是此类基函数的数量，\(\epsilon\) 是一个高斯噪声项。如果 \(k=0\)，则该模型对应于线性回归。

他们将此模型拟合到图 12.20(a) 的数据中。测试集上的预测显示在图 12.20(b) 中。基函数数量 \(p(k|D)\)（及其分布）的估计显示在图 12.20(c) 中，作为迭代次数的函数；最终迭代的后验显示在图 12.20(d) 中。显然，\(k=2\) 具有最强的后验支持，考虑到数据中有两个“凸起”，这是合理的。

为了生成这些结果，他们考虑了几种提议。其中之一是使用以下方法将当前基函数 \(\mu\) 分割为两个新基函数：

\[
\mu_1 = \mu - u_{n,n+1}\alpha, \mu_2 = \mu + u_{n,n+1}\alpha \quad (12.139)
\]

其中 \(\alpha\) 是提议的一个参数，\(u_{n,m}\) 从某些分布（例如，均匀分布）中采样。为了确保可逆性，他们定义了相应的合并移动

\[
\mu = \frac{\mu_1 + \mu_2}{2} \quad (12.140)
\]

![](img/ca72c1626f4850f058a9edc138c1ac73_563_0.png)

图 12.20: 使用 RJMCMC 拟合一些一维数据的 RBF 网络。(a) 训练集上的预测。(b) 测试集上的预测。(c) p(k|D) 与迭代次数的图。(d) 最终后验 p(k|D)。改编自 [AFD01] 的图 4。由 rjmcmc_rbf 生成，由 Nando de Freitas 编写。

其中 \(\mu_1\) 随机选择，\(\mu_2\) 是其最近邻。为了确保这些移动是可逆的，我们要求 \(||\mu_1 - \mu_2|| < 2\beta\)。

分割移动的接受率由以下给出：

\[
A_{split} = \min \left\{ 1, \frac{p(k+1, \mu_{k+1})}{p(k, \mu_{k+1})} \times \frac{1/(k+1)}{1/k} \times \frac{1}{p(u_n, m)} \times |\text{det} \mathbf{J}_{split}| \right\} \quad (12.141)
\]

其中 \(1/k\) 是从 \(k\) 个基中随机均匀选择一个的概率。雅可比矩阵为

\[
\mathbf{J}_{split} = \frac{\partial(\mu_1, \mu_2)}{\partial(\mu, u_{n,m})} = \text{det} \begin{pmatrix} 1 & 1 \\ -\beta & \beta \end{pmatrix} \quad (12.142)
\]

所以 \(|\text{det} \mathbf{J}_{split}| = 2\beta\)。合并移动的接受率由以下给出：

\[
A_{merge} = \min \left\{ 1, \frac{p(k-1, \mu_{k-1})}{p(k, \mu_k)} \times \frac{1/(k-1)}{1/k} \times |\text{det} \mathbf{J}_{merge}| \right\} \quad (12.143)
\]

其中 \(|\text{det} \mathbf{J}_{merge}| = 1/(2\beta)\)。

假设当前模型的索引为 \(k\)，该算法的总体伪代码如下，如算法 12.6 所示。这里 \(b_k\) 是出生移动的概率，\(d_k\) 是死亡移动的概率，\(s_k\)

```
Algorithm 12.6: Generic reversible jump MCMC (single step)
1 Sample u ~ U(0, 1)
2 If u <= b_k
3 then birth move
4 else if u <= (b_k + d_k) then death move
5 else if u <= (b_k + d_k + s_k) then split move
6 else if u <= (b_k + d_k + s_k + m_k) then merge move
7 else update parameters
```

是分割移动的概率，\(m_k\) 是合并移动的概率。如果我们不进行维度改变的移动，则只需使用随机游走 MH 更新当前模型的参数。

### 12.8.3 讨论

RJMCMC 算法的实现可能相当棘手。然而，如果可以对连续参数进行积分消去（从而得到一种称为折叠 RJMCMC 的方法），那么大部分困难就消失了，因为我们只剩下一个离散状态空间，无需担心度量的变化。例如，如果我们固定方程 (12.138) 中的中心 \(\mu_j\)（例如，使用数据中的样本或使用 K-means 聚类），我们就得到了一个线性模型，可以对参数进行积分消去。剩下要做的就是采样要在模型中包含哪些固定基函数，这是一个离散变量选择问题。详情见 [Den+02]。

在第 31 章中，我们讨论贝叶斯非参数模型，这些模型允许无限数量的不同模型。出人意料的是，从计算上讲，这类模型通常比使用有限数量的不同模型更容易处理（而且从统计学角度来看也更现实）。

## 12.9 退火方法

许多分布是多模态的，因此难以采样。然而，通过类比金属被加热然后缓慢冷却以使分子排列的方式，我们可以想象使用计算温度参数来“平滑”分布，逐渐冷却它以恢复原来的“凹凸不平”分布。我们首先在 MAP 估计算法的上下文中更详细地解释这一想法。然后我们讨论采样情况的扩展。

### 12.9.1 模拟退火

在本节中，我们讨论模拟退火算法 [KJV83; LA87]，它是 Metropolis-Hastings 算法的一种变体，旨在寻找黑盒函数的全局最优解。（黑盒优化的其他方法将在 6.7 节中讨论。）

退火是一种物理过程，即将固体加热直到热应力释放，然后非常缓慢地冷却它，直到晶体完美排列，达到最低能量状态。取决于温度冷却的快慢，结果的质量会好或坏。我们可以将这种方法应用于概率分布，以控制模式数量（低能量状态）
