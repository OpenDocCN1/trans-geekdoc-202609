
## 8.5 Other variants of the Kalman filter

In this section, we briefly mention some other variants of Kalman filtering. For a more extensive review, see [SS23; Li+17e].

### 8.5.1 General Gaussian filtering

*This section is co-authored with Peter Chang.*

Let $p(\mathbf{z}) = \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \boldsymbol{\Sigma})$ and $p(\mathbf{y}|\mathbf{z}) = \mathcal{N}(\mathbf{y}|\mathbf{h}_{\boldsymbol{\mu}}(\mathbf{z}), \mathbf{\Omega})$ for some function $\mathbf{h}_{\boldsymbol{\mu}}$. Let $p(\mathbf{z}, \mathbf{y}) = p(\mathbf{z})p(\mathbf{y}|\mathbf{z})$ be the exact joint distribution. The best Gaussian approximation to the joint can be computed by solving

$$q(\mathbf{z}, \mathbf{y}) = \underset{q \in \mathcal{N}}{\text{argmin}} D_{\text{KL}} (p(\mathbf{z}, \mathbf{y}) \| q(\mathbf{z}, \mathbf{y})) \tag{8.155}$$

As we explain in Section 5.1.4.2, this can be obtained by **moment matching**, i.e.,

$$q(\mathbf{z}, \mathbf{y}) = \mathcal{N}\left( \begin{pmatrix} \mathbf{z} \\ \mathbf{y} \end{pmatrix} \middle| \begin{pmatrix} \boldsymbol{\mu} \\ \hat{\mathbf{y}} \end{pmatrix}, \begin{pmatrix} \boldsymbol{\Sigma} & \mathbf{C} \\ \mathbf{C}^{\top} & \mathbf{S} \end{pmatrix} \right) \tag{8.156}$$

where

$$\hat{\mathbf{y}} = \mathbb{E}[\mathbf{y}] = \int \mathbf{h}_{\boldsymbol{\mu}}(\mathbf{z}) \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \boldsymbol{\Sigma}) d\mathbf{z} \tag{8.157}$$

$$\mathbf{S} = \mathbb{V}[\mathbf{y}] = \mathbf{\Omega} + \int (\mathbf{h}_{\boldsymbol{\mu}}(\mathbf{z}) - \hat{\mathbf{y}})(\mathbf{h}_{\boldsymbol{\mu}}(\mathbf{z}) - \hat{\mathbf{y}})^{\top} \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \boldsymbol{\Sigma}) d\mathbf{z} \tag{8.158}$$

$$\mathbf{C} = \text{Cov}[\mathbf{z}, \mathbf{y}] = \int (\mathbf{z} - \boldsymbol{\mu})(\mathbf{h}_{\boldsymbol{\mu}}(\mathbf{z}) - \hat{\mathbf{y}})^{\top} \mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \boldsymbol{\Sigma}) d\mathbf{z} \tag{8.159}$$

We can use the above Gaussian approximation either for the time update (i.e., going from $p(\mathbf{z}_{t-1}|\mathbf{y}_{1:t-1})$ to $p(\mathbf{z}_t|\mathbf{y}_{1:t-1})$ via $p(\mathbf{z}_{t-1}, \mathbf{z}_t|\mathbf{y}_{1:t-1})$), or for the measurement update, (i.e., going from $p(\mathbf{z}_t|\mathbf{y}_{1:t-1})$ to $p(\mathbf{z}_t|\mathbf{y}_{1:t})$ via $p(\mathbf{z}_t, \mathbf{y}_t|\mathbf{y}_{1:t-1})$). For example, if the prior from the time update is $p(\mathbf{z}_t) = \mathcal{N}(\mathbf{z}_t|\boldsymbol{\mu}_{t|t-1}, \boldsymbol{\Sigma}_{t|t-1})$, then the measurement update becomes

$$ \begin{aligned} \mathbf{K}_t &= \mathbf{C}_t \mathbf{S}_t^{-1} \tag{8.160} \\ \boldsymbol{\mu}_{t|t} &= \boldsymbol{\mu}_{t|t-1} + \mathbf{K}_t (\mathbf{y}_t - \hat{\mathbf{y}}_t) \tag{8.161} \\ \boldsymbol{\Sigma}_{t|t} &= \boldsymbol{\Sigma}_{t|t-1} - \mathbf{K}_t \mathbf{S}_t \mathbf{K}_t^{\top} \tag{8.162} \end{aligned} $$

The resulting method is called **general Gaussian filtering** or **GGF** [IX00; Wu+06].

#### 8.5.1.1 Statistical linear regression

An alternative perspective on the above method is that we are approximating the likelihood by $q(\mathbf{y}|\mathbf{z}) = \mathcal{N}(\mathbf{y}|\mathbf{Az} + \mathbf{b}, \mathbf{\Omega})$, where we define

$$ \begin{aligned} \mathbf{A} &= \mathbf{C}^{\top} \mathbf{\Sigma}^{-1} \\ \mathbf{b} &= \hat{\mathbf{y}} - \mathbf{A} \boldsymbol{\mu} \\ \mathbf{\Omega} &= \mathbf{S} - \mathbf{A} \mathbf{\Sigma} \mathbf{A}^{\top} \end{aligned} \tag{8.163} $$

This is called **statistical linear regression** or **SLR** [LBS01; AHE07], and ensures that we minimize

$$\mathcal{L}(\mathbf{A}, \mathbf{b}, \mathbf{\Omega}) = \mathbb{E}_{\mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \mathbf{\Sigma})} [D_{\text{KL}} (p(\mathbf{y}|\mathbf{z}) \parallel q(\mathbf{y}|\mathbf{z}; \mathbf{A}, \mathbf{b}, \mathbf{\Omega}))]$$

For the proof, see [GF+15; Kam+22]. Equivalently, one can show that the above parameters minimize the following mean squared error

$$\mathcal{L}(\mathbf{A}, \mathbf{b}) = \mathbb{E} [(\mathbf{y} - \mathbf{A}\mathbf{x} - \mathbf{b})^\mathsf{T}(\mathbf{y} - \mathbf{A}\mathbf{x} - \mathbf{b})]$$

with $\mathbf{\Omega}$ given by the residual noise

$$\mathbf{\Omega} = \mathbb{E} [(\mathbf{y} - \mathbf{A}\mathbf{x} - \mathbf{b})(\mathbf{y} - \mathbf{A}\mathbf{x} - \mathbf{b})^\mathsf{T}]$$

See [SS23, Sec 9.4] for the proof.

Note that although SLR results in a linear model, it is different than the Taylor series approximation of Section 8.3.1, since the linearization is chosen to be optimal wrt a distribution of points (averaged over $\mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \mathbf{\Sigma})$), instead of just being optimal at a single point $\boldsymbol{\mu}$.

#### 8.5.1.2 Approximating the moments

To implement GGF, we need a way to compute $\hat{\mathbf{y}}$, $\mathbf{S}$ and $\mathbf{C}$. To help with this, we define two functions to compute Gaussian first and second moments:

$$g_e(\mathbf{f}, \boldsymbol{\mu}, \mathbf{\Sigma}) \triangleq \int \mathbf{f}(\mathbf{z})\mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \mathbf{\Sigma})d\mathbf{z}$$

$$g_e(\mathbf{f}, \mathbf{g}, \boldsymbol{\mu}, \mathbf{\Sigma}) \triangleq \int (\mathbf{f}(\mathbf{z}) - \overline{\mathbf{f}})(\mathbf{g}(\mathbf{z}) - \overline{\mathbf{g}})^\mathsf{T}\mathcal{N}(\mathbf{z}|\boldsymbol{\mu}, \mathbf{\Sigma})d\mathbf{z}$$

where $\overline{f} = g_e(\mathbf{f}, \boldsymbol{\mu}, \mathbf{\Sigma})$ and $\overline{\mathbf{g}} = g_e(\mathbf{g}, \boldsymbol{\mu}, \mathbf{\Sigma})$. There are several ways to compute these integrals, as we discuss below.

#### 8.5.1.3 Approximation based on linearization

The simplest approach to approximating the moments is to linearize the functions $\mathbf{f}$ and $\mathbf{g}$ around $\boldsymbol{\mu}$, which yields the following (see Section 8.3.1):

$$\hat{\mathbf{f}}(\mathbf{z}) = \boldsymbol{\mu} + \mathbf{F}(\mathbf{z} - \boldsymbol{\mu})$$

$$\hat{\mathbf{g}}(\mathbf{z}) = \boldsymbol{\mu} + \mathbf{G}(\mathbf{z} - \boldsymbol{\mu})$$

where **F** and **G** are the Jacobians of $f$ and $g$. Thus we get the following implementation of the moment functions:

$$g_e(\hat{f}, \mu, \Sigma) = \mathbb{E} \left[ \mu + \mathbf{F}(z - \mu) \right] = \mu$$

$$g_c(\hat{f}, \hat{g}, \mu, \Sigma) = \mathbb{E} \left[ (\hat{f}(z) - \overline{f})(\hat{g}(z) - \overline{g})^\top \right]$$

$$= \mathbb{E} \left[ \hat{f}(z)\hat{g}(z)^\top + \overline{f}\overline{g}^\top - \hat{f}(z)\overline{g}^\top - \overline{f}\hat{g}(z)^\top \right]$$

$$= \mathbb{E} \left[ (\mu + \mathbf{F}(z - \mu))(\mu + \mathbf{G}(z - \mu))^\top + \mu\mu^\top - \mu\mu^\top - \mu\mu^\top \right]$$

$$= \mathbb{E} \left[ \mu\mu^\top + \mathbf{F}(z - \mu)(z - \mu)^\top \mathbf{G}^\top + \mathbf{F}(z - \mu)\mu^\top + \mu(z - \mu)^\top \mathbf{G}^\top - \mu\mu^\top \right]$$

$$= \mathbf{F} \mathbb{E} \left[ (z - \mu)(z - \mu)^\top \right] \mathbf{G}^\top = \mathbf{F} \Sigma \mathbf{G}^\top$$

Using this inside the GGF is equivalent to the EKF in Section 8.3.2. However, this approach can lead to large errors and sometimes divergence of the filter [IX00; VDMW03].

#### 8.5.1.4 Approximation based on Gaussian quadrature

Since we are computing integrals wrt a Gaussian measure, we can use **Gaussian quadrature** methods of the following form:

$$\int h(z) \mathcal{N}(z | \mu, \Sigma) dz \approx \sum_{k=1}^K w^k h(z^k)$$

for a suitable set of evaluation points $z^k$ (sometimes called **sigma points**) and weights $w^k$. (Note that one-dimensional integrals are called **quadratures**, and multi-dimensional integrals are called **cubatures**.)

One way to compute the sigma points is to use the unscented transform described in Section 8.4.1. Using this inside the GGF is equivalent to the UKF in Section 8.4.2.

Alternatively, we can use **spherical cubature integration**, which gives rise to the **cubature Kalman filter** or **CKF** [AH09]. This turns out (see [SS23, Sec 8.7]) to be a special case of the UKF, with $2n_z + 1$ sigma points, and hyperparameter values of $\alpha = 1$ and $\beta = 0$ (with $\kappa$ left free). A more accurate approximation uses **Gauss-Hermite integration**, which allows the user to select more sigma points. In particular, an order $p$ approximation will be exact for polynomials of order up to $2p - 1$. See [SS23, Sec 8.3] for details, and Figure 8.5(e-f) for an illustration. However, this comes at a price: the number of sigma points is now $p^n$. Using Gauss-Hermite integration for GGF gives rise to the **Gauss-Hermite Kalman filter** or **GHKF** [IX00], also known as the **quadrature Kalman filter** or **QKF** [AHE07].

#### 8.5.1.5 Approximation based on Monte Carlo integration

We can also approximate the integrals with Monte Carlo (see Section 11.2). Note, however, that this is not the same as particle filtering (Section 13.2), which approximates the conditional $p(z_t | y_{1:t})$ rather than the joint $p(z_t, y_t | y_{1:t-1})$ (see Section 8.6.1 for discussion of this difference).
