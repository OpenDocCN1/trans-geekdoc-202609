## 17 贝叶斯神经网络

*本章由 Andrew Wilson 合著。*

### 17.1 引言

深度神经网络（DNNs）通常使用（惩罚）最大似然目标进行训练，以找到参数的单一设置。但是，像神经网络这样的大型灵活模型可以表示许多函数，这些函数对应于不同的参数设置，能够很好地拟合训练数据，但泛化方式不同。（这种现象称为 **欠指定**（underspecification，例如见 [D’A+20]；参见图 17.11 的示例。）将所有这些不同模型一起考虑可以提高准确性和不确定性表示。这可以通过使用贝叶斯模型平均计算后验预测分布来实现：

$p(y|x, \mathcal{D}) = \int p(y|x, \theta)p(\theta|\mathcal{D})d\theta$ (17.1)

其中 \(p(\theta|\mathcal{D}) \propto p(\theta)p(\mathcal{D}|\theta)\)。

将贝叶斯推断应用于 DNNs 的主要挑战是指定合适的先验，并有效地计算后验，由于参数数量多且数据集大，这具有挑战性。将贝叶斯推断应用于 DNNs 有时称为 **贝叶斯深学习** 或 **BDL**。相比之下，**深度贝叶斯学习** 或 **DBL** 指的是使用深度模型来帮助加速“经典”模型的贝叶斯推断，通常是通过训练摊销推断网络，这些网络可用作变分推断或重要性采样算法的一部分，如第 10.1.5 节所述。有关 BDL 主题的更多详情，请参见例如 [PS17; Wil20; WI20; Jos+22; Kha20; MI23]。

### 17.2 BNNs 的先验

要对 DNN 的参数执行贝叶斯推断，我们需要指定一个先验 \(p(\theta)\)。[Nal18; WI20; For22] 详细讨论了先验选择的问题。这里我们只是简要总结常见方法。

#### 17.2.1 高斯先验

考虑具有一个隐藏层（激活函数为 \(\varphi\)）和线性输出的 MLP：

\(f(\boldsymbol{x}; \boldsymbol{\theta}) = \mathbf{W}_2 \varphi(\mathbf{W}_1 \boldsymbol{x} + \boldsymbol{b}_1) + \boldsymbol{b}_2\) (17.2)

（如果输出是非线性的，例如 softmax 变换，我们可以在训练期间将其折叠到损失函数中。）如果有两个隐藏层，则变为

\(f(\boldsymbol{x}; \boldsymbol{\theta}) = \mathbf{W}_3 ( \varphi ( \mathbf{W}_2 \varphi ( \mathbf{W}_1 \boldsymbol{x} + \boldsymbol{b}_1 ) + \boldsymbol{b}_2 ) ) + \boldsymbol{b}_3\) (17.3)

一般来说，具有 \(L - 1\) 个隐藏层和线性输出时，我们有

\(f(\boldsymbol{x}; \boldsymbol{\theta}) = \mathbf{W}_L ( \cdots \varphi ( \mathbf{W}_1 \boldsymbol{x} + \boldsymbol{b}_1 ) ) + \boldsymbol{b}_L\) (17.4)

我们需要为 \(l = 1 : L\) 指定 \(\mathbf{W}_l\) 和 \(\boldsymbol{b}_l\) 的先验。最常见的选择是使用分解高斯先验：

\(\mathbf{W}_\ell \sim \mathcal{N}(\mathbf{0}, \alpha_\ell^2 \mathbf{I}), \quad \boldsymbol{b}_\ell \sim \mathcal{N}(\mathbf{0}, \beta_\ell^2 \mathbf{I})\) (17.5)

Xavier 初始化或 Glorot 初始化（以 [GB10] 的第一作者命名）是设置

\(\alpha_\ell^2 = \frac{2}{n_{\text{in}} + n_{\text{out}}}\) (17.6)

其中 \(n_{\text{in}}\) 是第 \(\ell\) 级节点的扇入（进入神经元的权重数量），\(n_{\text{out}}\) 是扇出（离开神经元的权重数量）。LeCun 初始化（以 Yann LeCun 命名）对应于使用

\(\alpha_\ell^2 = \frac{1}{n_{\text{in}}}\) (17.7)

我们可以通过考虑这些先验对其定义的相应函数分布的影响，更好地理解这些先验。为了帮助理解这种对应关系，让我们将模型重新参数化如下：

\(\mathbf{W}_\ell = \alpha_\ell \boldsymbol{\eta}_\ell, \quad \boldsymbol{\eta}_\ell \sim \mathcal{N}(\mathbf{0}, \mathbf{I}), \quad \boldsymbol{b}_\ell = \beta_\ell \boldsymbol{\epsilon}_\ell, \quad \boldsymbol{\epsilon}_\ell \sim \mathcal{N}(\mathbf{0}, \mathbf{I})\) (17.8)

因此，先验超参数的每个设置都指定了以下随机函数：

\(f(\boldsymbol{x}; \boldsymbol{\alpha}, \boldsymbol{\beta}) = \alpha_L \eta_L ( \cdots \varphi ( \alpha_1 \eta_1 \boldsymbol{x} + \beta_1 \boldsymbol{\epsilon}_1 ) ) + \beta_L \boldsymbol{\epsilon}_L\) (17.9)

为了感受这些超参数的效果，我们可以从此前验中采样 MLP 参数并绘制生成的随机函数。我们使用 sigmoid 非线性，因此 \(\varphi(a) = \sigma(a)\)。我们考虑 \(L = 2\) 层，因此 \(\mathbf{W}_1\) 是输入到隐藏层的权重，\(\mathbf{W}_2\) 是隐藏层到输出层的权重。我们假设输入和输出是标量，因此我们生成随机非线性 1d 映射 \(f : \mathbb{R} \rightarrow \mathbb{R}\)。

上述结果特定于 sigmoid 激活函数的情况。ReLU 单元的行为可能不同。例如，[WI20, App. E] 显示，对于具有 ReLU 单元的 MLP，如果我们设置 \(\beta_\ell = 0\)，因此偏差项全部为零，改变 \(\alpha_\ell\) 的效果只是重新缩放输出。要看到这一点，请注意，方程 (17.9) 简化为

\(f(\boldsymbol{x}; \boldsymbol{\alpha}, \boldsymbol{\beta} = \mathbf{0}) = \alpha_L \boldsymbol{\eta}_L (\cdots \varphi(\alpha_1 \boldsymbol{\eta}_1 \boldsymbol{x})) = \alpha_L \cdots \alpha_1 \boldsymbol{\eta}_L (\cdots \varphi(\boldsymbol{\eta}_1 \boldsymbol{x})) \quad (17.10)\)
\(= \alpha_L \cdots \alpha_1 f(\boldsymbol{x}; (\boldsymbol{\alpha} = \mathbf{1}, \boldsymbol{\beta} = \mathbf{0})) \quad (17.11)\)

其中我们使用了 ReLU 的事实：对于任何正 \(\alpha\)，\(\varphi(\alpha z) = \alpha \varphi(z)\)；对于任何负 \(\alpha\)，\(\varphi(\alpha z) = 0\)（因为预激活 \(z \ge 0\)）。一般来说，决定输入信号在随机初始化模型中前向和后向传播时发生什么的，是 \(\alpha\) 和 \(\beta\) 的比率；有关详情，请参见例如 [Bah+20]。
