We say that \(\mathcal{K}\) is a Mercer kernel iff the Gram matrix is positive definite for any set of (distinct) inputs \(\{x_i\}_{i=1}^N\).

We discuss several popular Mercer kernels below. More details can be found at [Wil14] and https://www.cs.toronto.edu/~duvenaud/cookbook/. See also Section 18.6 where we discuss how to learn kernels from data.

# 18.2.1 Stationary kernels

For real-valued inputs, \(\mathcal{X} = \mathbb{R}^D\), it is common to use **stationary kernels** (also called **shift-invariant kernels**), which are functions of the form \(\mathcal{K}(x, x') = \mathcal{K}(r)\), where \(r = x - x'\); thus the output only depends on the relative difference between the inputs. (See Section 18.2.2 for a discussion of non-stationary kernels.) Furthermore, in many cases, all that matters is the magnitude of the difference:

\(r = ||r||_2 = ||x - x'||\)

We give some examples below. (See also Figure 18.3 and Figure 18.4 for some visualizations of these kernels.)

# 18.2.1.1 Squared exponential (RBF) kernel

The **squared exponential** (SE) kernel, also sometimes called the **exponentiated quadratic kernel** or the **radial basis function** (**RBF**) kernel, is defined as

\(\mathcal{K}(r; \ell) = \exp \left( - \frac{r^2}{2\ell^2} \right)\)

Here \(\ell\) corresponds to the **length-scale** of the kernel, i.e., the distance over which we expect differences to matter.

From Equation (18.7) we can rewrite this kernel as

\(\mathcal{K}(x, x'; \ell) = \exp \left( - \frac{||x - x'||^2}{2\ell^2} \right)\)

This is the RBF kernel we encountered earlier. It is also sometimes called the **Gaussian kernel**. See Figure 18.3(f) and Figure 18.4(f) for a visualization in 1D.

# 18.2.1.2 ARD kernel

We can generalize the RBF kernel by replacing Euclidean distance with Mahalanobis distance, as follows:

\(\mathcal{K}(r; \Sigma, \sigma^2) = \sigma^2 \exp \left( - \frac{1}{2} r^\mathsf{T} \Sigma^{-1} r \right)\)

where \(r = x - x'\). If \(\Sigma\) is diagonal, this can be written as

\(\mathcal{K}(r; \ell, \sigma^2) = \sigma^2 \exp \left( - \frac{1}{2} \sum_{d=1}^D \frac{1}{\ell_d^2} r_d^2 \right) = \prod_{d=1}^D \mathcal{K}(r_d; \ell_d, \sigma^{2/d})\)
