本章的观点在很大程度上与 PAC-Bayes 文献互补，且在某些方面正交。我们的研究重点一直是贝叶斯边缘化，特别是多模态边缘化，以及模型构建的规范性方法。相比之下，PAC-Bayes 界是关于单个样本的经验风险界定，而非边缘化，目前也不具备规范性：我们为改进界所做的事情，例如减少模型参数数量或使用高度紧凑的先验，通常不会改进泛化能力。此外，尽管我们看到在多模态后验上的贝叶斯模型平均对泛化有显著影响，但它对 PAC-Bayes 界只有微小的对数效应。总体而言，由于这些界较为松散（尽管在某些情况下并非空泛），通常存在为了改进 PAC-Bayes 界而做出建模选择却不改进泛化能力的空间，这使得从界中推导出模型构建的规范性方法变得困难。

### 17.4.6.1 BMA 在默认先验下可能效果不佳

许多近似推断方法，尤其是深度集成，在某些类型的协变量偏移下显著不那么过度自信（校准更好）[Ova+19]。然而，在 [Izm+21b] 中指出，HMC（可以说对后验提供最准确的近似）在分布偏移下通常效果不佳。

这并非 HMC 的特性，Izmailov et al. [Izm+21a] 表明，这种缺乏稳健性是协变量偏移下贝叶斯模型平均的基础性问题，由训练数据的退化和不良的先验选择引起。作为一个说明性特例，MNIST 数字的所有角落像素都是黑色的。神经网络第一层中连接到这些像素的权重会被乘以零，因此可以取任意值而不影响网络输出。因此，带有高斯先验的经典 MAP 训练或 MAP 解的深度集成会将这些参数驱向零，因为它们对数据拟合没有帮助，而得到的网络对这些像素的损坏具有稳健性。另一方面，这些参数的后验将与先验相同，因此贝叶斯模型平均会将损坏乘以从先验中采样的随机数，导致预测性能下降。

图 17.14(b, c) 可视化了此示例，显示了 MNIST 上 MAP 解和 BNN 后验样本的全连接网络第一层权重。对应于边界附近零强度像素的 MAP 权重接近零，而 BNN 权重看起来有噪声，是从高斯先验中采样的。

Izmailov et al. [Izm+21a] 证明，这是一个更一般问题的特例，只要训练数据的输入特征存在线性相关性，无论对于全连接网络还是卷积网络都是如此。在这种情况下，数据位于一个超平面上。如果协变量或域偏移沿该超平面的正交方向移动，那么后验在偏移方向上将与先验相同。因此，后验模型平均对不影响问题底层语义结构（如损坏）的偏移高度脆弱，而 MAP 解对这种偏移则完全稳健。

通过引入与训练输入主成分对齐的参数先验，我们可以显著提高贝叶斯神经网络在分布外场景下的泛化准确性。Izmailov et al. [Izm+21a] 提出以下 *EmpCov* 先验：\(p(w^1) = \mathcal{N}(0, \alpha\Sigma + \epsilon I)\)，其中 \(w^1\) 是第一层权重，\(\Sigma = \frac{1}{n-1} \sum_{i=1}^n x_i x_i^T\) 是训练输入特征 \(x_i\) 的经验协方差，\(\alpha > 0\) 决定先验的尺度，\(\epsilon\) 是一个小的正常数，用于确保协方差矩阵正定。借助这一改进的先验，他们能够获得一种对分布偏移更为稳健的方法。

### 17.4.6.2 BNN 在 OOD 输入上可能过度自信

实践中一个重要问题是，当预测模型收到“分布外”或 OOD 输入时会如何表现。理想情况下，我们希望模型表达出对其预测不自信，以便系统可以拒绝预测（参见第 19.3.3 节）。在 BNNs 上使用“精确”推断方法，例如 MCMC，在某些情况下可以产生这种行为。例如，在第 19.3.3.1 节中，我们展示了使用 SGLD 拟合到 MNIST 的 MLP 在面对 fashion MNIST 的输入时，比点估计（使用 SGD 计算）更不那么过度自信。然而，这种行为并不总是可靠地发生。

为了说明问题，请考虑图 17.15 所示的 2D 非线性二分类数据集。除了两个训练类别之外，我们还用绿色突出显示了一组远离训练集支持集的 OOD 输入。直觉上，我们期望模型对远离训练集的此类输入预测 0.5 的概率（对应于“我不知道”）。然而，我们看到只有高斯过程（GP）分类器（参见第 18.4 节）和 SNGP 模型（第 17.3.6 节）会这样做，后者在特征提取器之上包含一个 GP 层。

从这个简单的示例中我们学到的教训是，“贝叶斯”只有在使用良好假设类时才有帮助。如果我们只考虑一个带有权重标准高斯先验的单一 MLP 分类器，那么学习图 17.15g 所示那种紧凑决策边界的可能性极小，因为该函数在我们的先验下几乎没有支持（参见第 17.4.4 节）。相反，我们应该拥抱贝叶斯的力量以避免过拟合，并尽可能使用复杂的模型类。
