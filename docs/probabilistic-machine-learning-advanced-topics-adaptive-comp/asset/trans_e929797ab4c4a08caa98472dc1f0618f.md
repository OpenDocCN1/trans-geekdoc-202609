### 4.2.7.3 示例：计算 CPT 的后验

在 4.2.7.2 节中，我们讨论了如何计算离散贝叶斯网中 CPT 的 MLE。我们还观察到，这可能会受到零计数问题的影响。在本节中，我们展示了贝叶斯方法如何解决此问题。

让我们在每个 CPT 的每一行上放置一个独立的狄里克莱先验，即 \theta_{ij} ~ Dir(\alpha_{ij})。然后我们可以通过简单地将伪计数添加到经验计数来计算后验，得到 \theta_{ij} | D ~ Dir(N_{ij} + \alpha_{ij})，其中 N_{ij} = {N_{ijk} : k = 1 : K_i}，且 N_{ijk} 是节点 i 处于状态 k 而其父节点处于状态 j 的次数。因此后验均值估计由以下公式给出：

```
\bar{\theta}_{ijk} = \frac{N_{ijk} + \alpha_{ijk}}{\sum_{k'}(N_{ijk'} + \alpha_{ijk'})} (4.48)
```

MAP 估计具有相同的形式，只是我们使用 \alpha_{ijk} - 1 代替 \alpha_{ijk}。

在表 4.3 中，我们说明了此方法在学生网络 G 节点上的应用，其中我们使用均匀狄里克莱先验，\alpha_{ijk} = 1。

### 4.2.7.4 从不完整数据中学习

在 4.2.7.1 节中，我们解释了当我们有完整数据时，似然（及后验）在 CPD 上分解，因此我们可以独立地估计每个 CPD。不幸的是，当我们有不完整或缺失数据时，情况不再如此。要了解这一点，请考虑图 4.10。观测数据的似然可以写成如下形式：

```
p(\mathcal{D}|\theta) = \sum_{z_{1:N}} [\prod_{n=1}^N p(z_n|\theta_z)p(x_n|z_n, \theta_x)] (4.49)
```

```
= \prod_{n=1}^N \sum_{z_n} p(z_n|\theta_z)p(x_n|z_n, \theta_x) (4.50)
```

因此对数似然由以下公式给出：

```
\ell(\boldsymbol{\theta}) = \sum_{n} \log \sum_{\boldsymbol{z}_n} p(\boldsymbol{z}_n | \boldsymbol{\theta}_z) p(\boldsymbol{x}_n | \boldsymbol{z}_n, \boldsymbol{\theta}_x)
```

对数函数不对 \sum_{\boldsymbol{z}_n} 操作进行分配，因此目标在节点上不分解。^2 因此，我们不再能通过为每个节点分别求解问题来计算 MLE 或后验。

为了解决这个问题，我们将求助于优化方法。（我们专注于 MLE 情况，并将潜变量模型的贝叶斯推断讨论留给第二部分。）在下面的章节中，我们讨论如何使用 EM 和 SGD 来寻找（非凸）对数似然目标的局部最优解。

### 4.2.7.5 在不完整数据情况下使用 EM 拟合 CPT

在存在缺失数据的情况下，估计 DPGM 参数的一种流行方法是使用期望最大化（EM）算法，该算法在 [Lau95] 中提出。我们将在 6.5.3 节详细介绍 EM，但基本思路是在推断隐性变量 \boldsymbol{z}_n（E 步或期望步骤）和根据此完成的数据集估计参数（M 步或最大化步骤）之间交替进行。在 E 步中，我们不返回完整的后验 p(\boldsymbol{z}_n | \boldsymbol{x}_n, \boldsymbol{\theta}^{(t)})，而是返回期望充分统计量（ESS），这占用的空间要小得多。在 M 步中，我们使用这些 ESS 最大化完全观测数据的对数似然的期望值。

作为示例，假设所有 CPD 都是表格形式的，如 4.2.7.2 节中的示例。完整数据的对数似然由以下公式给出：

```
\log p(\mathcal{D} | \boldsymbol{\theta}) = \sum_{i=1}^{N_G} \sum_{j=1}^{J_i} \sum_{k=1}^{K_i} N_{ijk} \log \theta_{ijk}
```

因此期望完整数据对数似然具有以下形式：

```
\mathbb{E} [\log p(\mathcal{D} | \boldsymbol{\theta})] = \sum_{i} \sum_{j} \sum_{k} \overline{N}_{ijk} \log \theta_{ijk}
```

其中

```
\overline{N}_{ijk} = \sum_{n=1}^{N} \mathbb{E} [\mathbb{I} [ (x_{ni} = k, \boldsymbol{x}_{n, \text{pa}(i)} = j) ] ] = \sum_{n=1}^{N} p(x_{ni} = k, \boldsymbol{x}_{n, \text{pa}(i)} = j | \mathcal{D}_n, \boldsymbol{\theta}^{old})
```

其中 \mathcal{D}_n 是情况 n 中所有可见变量，\boldsymbol{\theta}^{old} 是前一次迭代的参数。量 p(x_{ni}, \boldsymbol{x}_{n, \text{pa}(i)} | \mathcal{D}_n, \boldsymbol{\theta}^{old}) 称为家族边缘，可以使用任何 GM 推断算法计算。\overline{N}_{ijk} 是期望充分统计量（ESS），构成 E 步的输出。

2. 我们也可以从图形模型中看出这一点：\boldsymbol{\theta}_x 不再独立于 \boldsymbol{\theta}_z，因为存在一条通过隐藏节点 \boldsymbol{z}_n 连接它们的路径。（参见 4.2.4 节，了解如何从 DPGM 中“读取”此类 CI 属性的说明。）

给定这些 ESS，M 步具有简单形式

$$\hat{\theta}_{ijk} = \frac{N_{ijk}}{\sum_{k'} N_{ijk'}}$$ (4.55)

我们可以通过简单地将伪计数添加到期望计数来修改此公式，以使用狄里克莱先验进行 MAP 估计。

著名的 Baum-Welch 算法是上述公式的特例，当 DPGM 为 HMM 时会出现此情况（详情见 29.4.1 节）。

### 4.2.7.6 在不完整数据情况下使用 SGD 拟合 CPT

EM 算法是一种批量算法。要扩展到大型数据集，更常用随机梯度下降或 SGD（例如，见 [BC94; Bin+97]）。要应用此方法，我们需要为每个示例计算观测数据的边缘似然：

$$p(\boldsymbol{x}_n|\boldsymbol{\theta}) = \sum_{\boldsymbol{z}_n} p(\boldsymbol{z}_n|\boldsymbol{\theta}_z)p(\boldsymbol{x}_n|\boldsymbol{z}_n, \boldsymbol{\theta}_x)$$ (4.56)

其中 $\boldsymbol{\theta} = (\boldsymbol{\theta}_z, \boldsymbol{\theta}_x).$（我们称通过边缘化 $\boldsymbol{z}_n$ “折叠”了模型。）然后我们可以使用以下公式计算对数似然：

$$\ell(\boldsymbol{\theta}) = \log p(\mathcal{D}|\boldsymbol{\theta}) = \log \prod_{n=1}^N p(\boldsymbol{x}_n|\boldsymbol{\theta}) = \sum_{n=1}^N \log p(\boldsymbol{x}_n|\boldsymbol{\theta})$$ (4.57)

此目标的梯度可以按如下方式计算：

$$\nabla_\theta \ell(\theta) = \sum_n \nabla_\theta \log p(\boldsymbol{x}_n|\boldsymbol{\theta})$$ (4.58)
$$= \sum_n \frac{1}{p(\boldsymbol{x}_n|\boldsymbol{\theta})} \nabla_\theta p(\boldsymbol{x}_n|\boldsymbol{\theta})$$ (4.59)
$$= \sum_n \frac{1}{p(\boldsymbol{x}_n|\boldsymbol{\theta})} \nabla_\theta \mathbb{E}_\theta \left[ \sum_{\boldsymbol{z}_n} p(\boldsymbol{z}_n, \boldsymbol{x}_n|\boldsymbol{\theta}) \right]$$ (4.60)
$$= \sum_n \sum_{\boldsymbol{z}_n} \frac{p(\boldsymbol{z}_n, \boldsymbol{x}_n|\boldsymbol{\theta})}{p(\boldsymbol{x}_n|\boldsymbol{\theta})} \nabla_\theta \log p(\boldsymbol{z}_n, \boldsymbol{x}_n|\boldsymbol{\theta})$$ (4.61)
$$= \sum_n \sum_{\boldsymbol{z}_n} p(\boldsymbol{z}_n|\boldsymbol{x}_n, \boldsymbol{\theta}) \nabla_\theta \log p(\boldsymbol{z}_n, \boldsymbol{x}_n|\boldsymbol{\theta})$$ (4.62)

我们现在可以以常规方式对此应用小批量近似。

## 4.2.8 盘记法

为了使 PGM 的参数显式化，我们可以将它们作为节点添加到图中，并将其视为待推断的隐性变量。图 4.11(a) 显示了一个简单示例，其中我们有 N 个独立同分布

![](img/ca72c1626f4850f058a9edc138c1ac73_193_0.png)

图 4.11：左：给定 $\theta$ 时，数据点 $\mathbf{x}_n$ 条件独立。右：相同模型，使用盘记法。这表示与左侧相同的模型，只是重复的 $\mathbf{x}_n$ 节点位于一个称为盘的框内；右下角的数字 $N$ 指定了 $\mathbf{x}_n$ 节点的重复次数。

随机变量，$\mathbf{x}_n$，全部来自具有共同参数 $\theta$ 的同一分布。我们用以下公式表示：

```
$$
\mathbf{x}_n \sim p(\mathbf{x}|\theta)
$$
```

参数和数据 $\mathcal{D} = \{\mathbf{x}_1, \dots, \mathbf{x}_N\}$ 之间的相应联合分布形式如下：

```
$$
p(\mathcal{D}, \theta) = p(\theta)p(\mathcal{D}|\theta)
$$
```

其中 $p(\theta)$ 是参数的先验分布，$p(\mathcal{D}|\theta)$ 是似然。得益于 iid 假设，似然可以重写为如下形式：

```
$$
p(\mathcal{D}|\theta) = \prod_{n=1}^N p(\mathbf{x}_n|\theta)
$$
```

请注意，数据向量的顺序对于定义此模型不重要，即，我们可以交换 DPGM 的叶节点。当此属性成立时，我们说数据是**可交换**的。

在图 4.11(a) 中，我们看到 $\mathbf{x}$ 节点重复 $N$ 次。（**阴影**节点表示观测值，而未阴影（空心）节点表示隐性变量或参数。）为了避免视觉混乱，通常使用一种称为**盘**的语法糖。这是一种记号约定，即在重复变量周围画一个小框，理解为模型**展开**时框内的节点将被重复。我们通常在框的右下角写下副本数或重复次数。图 4.11(b) 说明了这一点。
