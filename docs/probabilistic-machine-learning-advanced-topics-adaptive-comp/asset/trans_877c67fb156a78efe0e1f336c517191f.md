## 32.3.4 多视图表示学习

多视图表示学习领域旨在学习一种表示，其中“相似”的输入或输入的视图在表示空间中被映射到附近，而“不相似”的输入被映射得更远。该表示空间通常是高维的，并依赖于收集数据或设计任务，以便可以生成相似的“正”样本对和不相似的“负”样本对。多视图表示学习有许多动机和目标，但所有方法都依赖于构建正样本对集合，以及防止所有表示坍塌到同一点的机制。在这里，我们使用多视图表示学习这一术语来涵盖对比学习（结合正负样本对）、度量学习以及“非对比”学习（消除了对负样本对的需求）。

与用于表示学习的生成方法不同，多视图表示学习使得将关于哪些输入在嵌入空间中应更接近的先验知识纳入变得容易。此外，这些输入不必来自同一模态，因此多视图表示学习可以应用于丰富的多模态数据集。将先验知识通过数据纳入模型的这种简单性，使得多视图表示学习成为学习表示最强大且性能最好的方法之一。

尽管存在多种多视图表示学习方法，但它们都涉及一个排斥分量，用于将正样本对在嵌入空间中拉得更近，以及一种防止表示在嵌入空间中坍塌到单一点的机制。我们首先描述多视图表示学习的损失函数，以及它们如何结合吸引和排斥项来塑造表示，然后讨论视图生成的作用，最后讨论部署多视图表示学习的实际注意事项。

### 32.3.4.1 视图选择

多视图表示学习依赖于一个数据点或“锚点” _x_、一个正样本 _x_+（_x_ 将被吸引到该样本），以及零个或多个负样本 _x_−（_x_ 将被排斥自该样本）。我们假设可以访问正样本对的数据生成过程：_p_+(_x_, _x_+)，以及给定数据点 _x_ 生成负样本的过程：_p_−(_x_−|_x_)。通常，_p_+(_x_, _x_+) 生成的 (_x_, _x_+) 是数据集中底层图像的不同增强，而 _x_− 表示来自数据集中不同随机图像的增强视图。然后 _x_− 的生成过程与 _x_ 独立，即，_p_−(_x_−|_x_) = _p_−(_x_−)。

用于生成正负样本对的视图选择对表示学习的成功至关重要。图 32.5 展示了我们下面将讨论的几种方法的正样本对 (_x_, _x_+) 和负样本 _x_−：SimCLR、CMC、SupCon 和 CLIP。

**SimCLR** [Che+20c] 通过对初始图像 _x_<sub>0</sub> 两次应用两个由变换 _t_ 和 _t_′ 定义的不同数据增强来创建正样本对：_x_ = _t_(_x_<sub>0</sub>), _x_+ = _t_(_x_<sub>0</sub>)。所使用的数据增强包括随机裁剪（带水平翻转和调整大小）、颜色扭曲和高斯模糊。这些增强的强度（例如，模糊的程度）会影响性能，通常被视为超参数。

如果我们可以获取额外信息（例如类别标签），可以使用此信息来选择具有相同标签的正样本对和具有不同标签的负样本对。当与对比损耗一起使用时，得到的目标称为 **SupCon** [Kho+20]，类似于邻域分量分析 [Gol+04]。研究表明，与标准监督学习相比，它能提高鲁棒性。

**对比多视图编码**（CMC）[TKI20] 通过将初始图像分割为正交维度（例如亮度和色度维度）来生成视图。这些视图现在不再处于同一空间（或相同维度），因此我们必须为不同的输入学习不同的编码器。然而，这些编码器的输出都位于相同维度的嵌入空间中，可以用于对比损耗。在测试时，我们可以通过平均或拼接来组合这些不同视图的嵌入。视图不必来自同一模态。CLIP [Rad+21] 在图像-文本对上使用对比学习，其中 $x$ 是图像，$x^+$ 和 $x^-$ 是文本描述。当应用于从互联网抓取的大规模图像-文本对数据集时，CLIP 能够学习强健的表示，而无需 SimCLR 或其他仅图像对比方法所需的额外数据增强。在大多数对比方法中，负样本是通过从小批量中的其他元素中随机选择 $x^+$ 来选取的。然而，如果批量大小较小，可能没有负样本在嵌入空间中与正样本接近，因此学习可能很慢。与随机选择负样本不同，可以通过硬负例挖掘更智能地选择负样本，该方法选择在嵌入空间中与正样本接近的负样本 [Fag+18]。这通常需要在训练过程中维护和更新负样本数据库；这会带来足够的计算开销，以至于该技术不常被使用。然而，在小批量内重新加权样本也可以提高性能 [Rob+21]。正负视图的选择直接影响学习到的特征和鼓励的不变性。Tian 等人 [Tia+20] 讨论了视图选择对学习表示的作用，展示了基于共享属性（如 SupCon 中）选择正样本如何可能导致学习这些属性或忽略它们。他们还提出了一种学习视图的方法（而所有先前方法都固定视图），该方法基于在视图之间的互信息水平中瞄准一个“甜蜜点”，既不太高也不太低。然而，了解哪些视图适合哪些下游任务仍然是一个开放的研究领域。

### 32.3.4.2 对比损耗

给定 $p^+$ 和 $p^-$，我们寻求学习嵌入 $f_\theta(x)$ 的损耗函数，使得 $x$ 和 $x^+$ 在嵌入空间中接近，而 $x$ 和 $x^-$ 远离。这称为度量学习。

Chopra、Hadsell、LeCun 等人 [CHL+05] 提出了一组目标函数，通过强制负样本对之间的距离始终至少比正样本对之间的距离大 $\epsilon$ 来实现这一直觉。[HCL06] 中实例化的对比损耗为：

$$\mathcal{L}_\text{contrastive} = \mathbb{E}_{x,x^+,x^-} [\|f_\theta(x) - f_\theta(x^+)\|^2 + \max(0, \epsilon - \|f_\theta(x) - f_\theta(x^-)\|^2)]. \quad (32.14)$$

该损耗通过使正样本对之间的平方 $\ell_2$ 距离变小来将正样本对拉近，并试图确保负样本对之间至少相距 $\epsilon$。在实践中使用对比损耗的一个挑战是调节超参数 $\epsilon$。

同样，三元损耗 [SKP15] 试图确保正样本对 $(x, x^+)$ 始终比负样本对 $(x, x^-)$ 彼此至少近 $\epsilon$ 的距离：

$$\mathcal{L}_\text{triplet} = \mathbb{E}_{x,x^+,x^-} [\max(0, \|f_\theta(x) - f_\theta(x^+)\|^2 - \|f_\theta(x) - f_\theta(x^-)\|^2 + \epsilon)]. \quad (32.15)$$

三元损耗方法的一个缺点是，必须小心选择硬负例：如果负样本对已经足够远，则目标函数为零，不会发生学习。

一种替代的对比损耗，因其无超参数且经验上有效而广受欢迎，称为 InfoNCE 损耗 [OLV18b] 或多类 N 对损耗
