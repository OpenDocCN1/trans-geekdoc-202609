使用更具表达性的概率模型来捕捉参数之间的依赖关系是很简单的（这些在 EA 文献中被称为 **构建块**）。例如，对于实值参数，我们可以使用多元高斯分布，$p(\boldsymbol{x}) = \mathcal{N}(\boldsymbol{x}|\boldsymbol{\mu}, \boldsymbol{\Sigma})$。由此产生的方法称为 **多元正态估计算法** 或 **EMNA**，[LL02]。（另见 Section 6.7.5。）

对于离散随机变量，使用概率图模型（第 4 章）来捕捉变量之间的依赖关系是很自然的。[BD97] 使用 Chow-Liu 算法（Supplementary Section 30.2.1）学习树结构图模型；[BJV97] 是此的特例，其中图为树。我们也可以学习更一般的图模型结构（参见例如 [LL02]）。我们通常使用贝叶斯网（Section 4.2），因为我们可以使用祖先采样（Section 4.2.5）轻松生成样本；因此产生的方法称为 **贝叶斯优化算法 (BOA)** [PGCP00]。层次化 BOA (hBOA) 算法 [Pel05] 通过使用决策树和决策图来表示贝叶斯网中的局部 CPT（如 [CHM97] 中），而不是使用表格。一般来说，学习用于 EDA 的概率模型结构被称为 **连锁学习**，这类似于如果基因可以作为构建块共同遗传，那么它们可以被连锁在一起。

我们也可以使用深度生成模型来表示好候选者的分布。例如，[CSF16] 使用去噪自编码器和 NADE 模型（Section 22.2），[Bal17] 使用 DNN 回归器，然后通过对输入进行梯度下降将其反转，[PRG17] 使用 RBMs（Section 4.3.3.2），[GSM18] 使用 VAEs（Section 21.2），等等。这类模型可能需要更多数据来拟合（因此需要更多函数调用），但可以更忠实地建模概率景观。（然而，这是否转化为更好的优化性能尚不清楚。）

## 6.7.5 交叉熵方法

交叉熵方法 [Rub97; RK04; Boe+05] 是 EDA (Section 6.7.4) 的特例，其中种群由多元高斯分布表示。具体而言，我们将 \(\boldsymbol{\mu}_{t+1}\) 和 \(\boldsymbol{\Sigma}_{t+1}\) 设为 \(\mathcal{S}_{t+1}^*$ 的经验均值和协方差，其中 \(\mathcal{S}_{t+1}^*$ 是顶部 \(K$ 个样本。这与在第 13.6.4 节讨论的用于采样罕见事件的 SMC 算法密切相关。

CEM 有时用于基于模型的强化学习 (Section 35.4)，因为它简单并且可以找到多模态目标的相当好的最优解。它也有时用于贝叶斯优化 (Section 6.6) 内部，以优化多模态获取函数（参见 [BK10]）。

### 6.7.5.1 可微分 CEM

[AY19] 的可微分 CEM 方法将顶部 \(K$ 算子替换为软的、可微分的近似，这使得优化器可以用作端到端可微分流水线的一部分。例如，我们可以使用它来创建可微分模型预测控制 (MPC) 算法（Section 35.4.1），如在第 35.4.5.2 节中所述。

基本思路如下。设 \(\mathcal{S}_t = \{ \boldsymbol{x}_{t,i} \sim p(\boldsymbol{x}|\boldsymbol{\theta}_t) : i = 1 : K' \}$ 表示当前种群，适应度值为 \(v_{t,i} = f(\boldsymbol{x}_{t,i})\)。设 \(v_{t,K}^*$ 为第 \(K$ 小的值。在 CEM 中，我们计算顶部 \(K$ 样本的集合 \(\mathcal{S}_t^* = \{i : v_{t,i} \ge v_{t,K}^* \}$，然后基于这些样本更新模型：\(\boldsymbol{\theta}_{t+1} = \text{argmax}_{\boldsymbol{\theta}} \sum_{i \in \mathcal{S}_t} p_t(i) \log p(\boldsymbol{x}_{t,i}|\boldsymbol{\theta})\)，其中 \(p_t(i) = \mathbb{I}(i \in \mathcal{S}_t^*) / |\mathcal{S}_t^*|$。在可微分版本中，我们将稀疏分布 \(\boldsymbol{p}_t$ 替换为“软”稠密分布 \(\boldsymbol{q}_t = \Pi(\boldsymbol{p}_t; \tau, K)$，其中

\(\Pi(\boldsymbol{p}; \tau, K) = \text{argmin}_{\boldsymbol{0} \le \boldsymbol{q} \le \boldsymbol{1}} -\boldsymbol{p}^\top \boldsymbol{q} - \tau \mathbb{H}(\boldsymbol{q}) \text{ s.t. } \mathbf{1}^\top \boldsymbol{q} = K\) (6.189)

将分布 \(\boldsymbol{p}$ 投影到总和为 \(K$ 的分布多胞形上。（这里 \(\mathbb{H}(\boldsymbol{q}) = -\sum_i q_i \log(q_i) + (1-q_i) \log(1-q_i)$ 是熵，\(\tau > 0$ 是温度参数。）这个投影算子（因此整个 DCEM 算法）可以通过隐式微分 [AKZK19] 进行反向传播。

## 6.7.6 进化策略

进化策略 [Wie+14] 是一种基于分布的优化形式，其中种群上的分布由高斯分布 \(p(\boldsymbol{x}|\boldsymbol{\theta}_t)$ 表示（参见例如 [Sal+17b]）。与 CEM 不同，参数是通过对目标期望值应用梯度上升来更新的，而不是在一组精英样本上使用 MLE。更精确地说，考虑平滑目标 \(\mathcal{L}(\boldsymbol{\theta}) = \mathbb{E}_{p(\boldsymbol{x}|\boldsymbol{\theta})} [f(\boldsymbol{x})]$。我们可以使用 REINFORCE 估计器（Section 6.3.4）来按以下方式计算该目标的梯度：

\(\nabla_\theta \mathcal{L}(\boldsymbol{\theta}) = \mathbb{E}_{p(\boldsymbol{x}|\boldsymbol{\theta})} [f(\boldsymbol{x}) \nabla_\theta \log p(\boldsymbol{x}|\boldsymbol{\theta})]\) (6.190)

这可以通过绘制蒙特卡洛样本来近似。我们将在下面讨论如何计算此梯度。

### 6.7.6.1 自然进化策略

如果概率模型在指数族中，我们可以计算自然梯度（Section 6.4），而不是“标准”梯度，这可能导致更快的收敛。这类方法称为自然进化策略 [Wie+14]。

### 6.7.6.2 CMA-ES

[Han16] 的 CMA-ES 方法，代表 “协方差矩阵自适应进化策略”，是一种 NES。它与 CEM 非常相似，只是以一种特殊的方式更新参数。具体而言，不是使用未加权 MLE 在精英集上计算新的均值和协方差，而是根据排名为精英样本附加权重。然后我们将新的均值设为精英集的加权 MLE。

用于更新协方差的方程更为复杂。具体而言，“进化路径”也用于在连续代中累积搜索方向，并用于更新协方差。可以证明，得到的更新近似了 L(θ) 的自然梯度，而无需显式建模 Fisher 信息矩阵 [Oll+17]。

## 6.8 最优传输

*本节由 Marco Cuturi 撰写。*

在本节中，我们关注最优传输理论，这是一套自 [Mon81] 工作起被提出的用于比较两个概率分布的工具。我们从仅涉及匹配的简单示例开始，并从那里朝着各种扩展方向发展。

### 6.8.1 热身：最优匹配两组点集

考虑两组点集 \((\mathbf{x}_1, \dots, \mathbf{x}_n)$ 和 \((\mathbf{y}_1, \dots, \mathbf{y}_n)$，每组包含从集合 \(\mathcal{X}$ 中取出的 \(n > 1$ 个不同点。这两组点集之间的 *匹配* 是一个双射映射，为每个点 \(\mathbf{x}_i$ 分配另一个点 \(\mathbf{y}_j$。这样的分配可以通过配对索引 \((i, j) \in \{1, \dots, n\}^2$ 来编码，使其定义对称群 \(\mathcal{S}_n$ 中的一个 *排列* \(\sigma$。按照此约定，给定排列 \(\sigma$，\(\mathbf{x}_i$ 将被分配给 \(\mathbf{y}_{\sigma_i}$，即第二组中的第 \(\sigma_i$ 个元素。

**匹配成本。** 在将一组与另一组进行匹配时，自然要考虑将任何点 \(\mathbf{x}_i$ 与另一个点 \(\mathbf{y}_j$ 配对时产生的成本，适用于所有可能的配对 \((i, j) \in \{1, \dots, n\}^2$。例如，\(\mathbf{x}_i$ 可能包含出租车司机 \(i$ 的当前位置信息，而 \(\mathbf{y}_j$ 包含刚刚叫车的用户 \(j$ 的位置信息；在这种情况下，\(C_{ij} \in \mathbb{R}$ 可以量化出租车司机 \(i$ 到达用户 \(j$ 所需的成本（以时间、燃料或距离计）。或者，\(\mathbf{x}_i$ 可能表示求职者 \(i$ 持有的技能向量，而 \(\mathbf{y}_j$ 表示与招聘启事 \(j$ 相关的理想技能向量；在这种情况下，\(C_{ij}$ 可以量化工人 \(i$ 完成工作 \(j$ 所需的小时数。我们将不失 generality 地假设，值 \(C_{ij}$ 是通过对点对 \((\mathbf{x}_i, \mathbf{y}_j)$ 求值 *成本函数* \(c : \mathcal{X} \times \mathcal{X} \rightarrow \mathbb{R}$ 得到的，即 \(C_{ij} = c(\mathbf{x}_i, \mathbf{y}_j)$。在许多最优传输应用中，此类成本函数具有几何解释，通常是 \(\mathcal{X}$ 上的距离函数，如图 6.18 所示，其中 \(\mathcal{X} = \mathbb{R}^2$，或如将在 Section 6.8.2.4 中稍后讨论的那样。

**最小成本匹配。** 配备成本函数 \(c\)，*最优匹配*（或分配）问题是寻找达到最小总成本的排列，由函数定义为

\[\min_\sigma E(\sigma) = \sum_{i=1}^n c(\mathbf{x}_i, \mathbf{y}_{\sigma_i}).\]
(6.191)

最优匹配问题可以说是最简单的组合优化问题之一，早在 19 世纪就已被处理 [JB65]。虽然对所有排列进行天真枚举将需要评估目标 \(E$ 总共 \(n!$ 次，但匈牙利算法 [Kuh55] 被证明可以在多项式时间内提供最优解 [Mun57]，后来被改进为在最坏情况下需要 \(O(n^3)$ 次操作。

### 6.8.2 从最优匹配到康托罗维奇和蒙日表述

最优匹配问题与许多应用相关，但它存在一些局限性。有人可能会认为，大部分最优传输文献源于克服这些局限性并将 (6.191) 扩展到更一般设置的必要性。当两组中可用点的数量不同时，会出现一个明显的问题。第二个局限性出现在考虑连续设置时，即当试图匹配（或变形）两个概率密度，而不是原子家族（离散测度）时。
