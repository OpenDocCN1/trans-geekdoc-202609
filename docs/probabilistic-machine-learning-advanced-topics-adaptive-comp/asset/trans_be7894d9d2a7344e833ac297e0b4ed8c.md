
### 6.3.5.3 “稳妥落地”估计器

在本节中，我们考虑变分推断（第 10.2 节）中出现的特例。ELBO 目标（针对单个隐性样本 \(\mathbf{z}\)）形式如下

```
\(\tilde{\mathcal{L}}(\boldsymbol{\theta}, \mathbf{z}) = \log p(\mathbf{z}, \mathbf{x}) - \log q(\mathbf{z}|\boldsymbol{\theta})\)
```

其中 \(\boldsymbol{\theta}\) 是变分后验的参数。梯度变为

```
\(\nabla_\theta \tilde{\mathcal{L}}(\boldsymbol{\theta}, \mathbf{z}) = \nabla_\theta [\log p(\mathbf{z}, \mathbf{x}) - \log q(\mathbf{z}|\boldsymbol{\theta})]\)
\(= \underbrace{\nabla_\mathbf{z} [\log p(\mathbf{z}, \mathbf{x}) - \log q(\mathbf{z}|\boldsymbol{\theta})]}_{\text{path derivative}} \mathbf{J} - \underbrace{\nabla_\theta \log q(\mathbf{z}|\boldsymbol{\theta})}_{\text{score function}}\)
```

第一项是通过生成的样本 \(\mathbf{z}\) 对 \(\boldsymbol{\theta}\) 对目标的间接影响。第二项是 \(\boldsymbol{\theta}\) 对目标的直接影响。第二项在期望下为零，因为它是得分函数（参见公式 (3.44)），但对于有限数量的样本可能非零，即使 \(q(\mathbf{z}|\boldsymbol{\theta}) = p(\mathbf{z}|\mathbf{x})\) 是真实后验。在 [RWD17] 中，他们提出丢弃第二项以创建低方差估计器。这可以通过使用 \(\log q(\mathbf{z}|\boldsymbol{\theta}')\) 实现，其中 \(\boldsymbol{\theta}'\) 是 \(\boldsymbol{\theta}\) 的一个“分离的”副本，不影响梯度。

在伪代码中，这如下所示：

```
\(\boldsymbol{\epsilon} \sim q_0(\boldsymbol{\epsilon})\)
\(\mathbf{z} = g(\boldsymbol{\epsilon}, \boldsymbol{\theta})\)
\(\boldsymbol{\theta}' = \text{stop-gradient}(\boldsymbol{\theta})\)
\(\mathbf{g} = \nabla_\theta [\log p(\mathbf{z}, \mathbf{x}) - \log q(\mathbf{z}|\boldsymbol{\theta}')]\)
```

他们称这为稳妥落地或 STL 估计器。注意，STL 估计器并不总是优于没有停止梯度项的“标准”估计器。在 [GD20] 中，他们提出使用加权估计器组合，其中权重经过优化，以在固定计算量下降低方差。

### 6.3.6 Gumbel softmax 技巧

使用离散变量时，我们无法使用重参数化技巧。但是，我们通常可以将离散变量松弛为连续变量，以一种允许使用该技巧的方式，如下面所述。

考虑一个具有 \(K\) 位的 one-hot 向量 \(\mathbf{d}\)，所以 \(d_k \in \{0, 1\}\) 且 \(\sum_{k=1}^K d_k = 1\)。这可以用来表示一个 \(K\) 类分类变量 \(d\)。令 \(P(d) = \text{Cat}(d|\boldsymbol{\pi})\)，其中 \(\pi_k = P(d_k = 1)\)，所以 \(0 \le \pi_k \le 1\)。或者，我们可以用 \((\alpha_1, \dots, \alpha_K)\) 参数化分布，其中 \(\pi_k = \alpha_k / (\sum_{k'=1}^K \alpha_{k'})\)。我们将用 \(d \sim \text{Cat}(d|\boldsymbol{\alpha})\) 表示此分布。
我们可以通过计算从该分布中采样一个 one-hot 向量 \(\mathbf{d}\)

```
\(\mathbf{d} = \text{onehot}(\arg\max_k[\epsilon_k + \log \alpha_k])\)
```

- 4. 表达“to stick a landing”是指在完成体操动作后稳稳落地。在当前语境中，类比如下：如果变分后验是最优的，那么我们希望目标为 0，并且不希望随着蒙特卡洛噪声而“波动”。

![](img/ca72c1626f4850f058a9edc138c1ac73_303_0.png)

图 6.3: 在不同温度 \(\tau\) 下，具有 \(K=7\) 状态的 Gumbel-softmax（具体）分布示意图。第一行显示 \(\mathbb{E}[\boldsymbol{z}]\)，第二行显示样本 \(\boldsymbol{z} \sim \text{GumbelSoftmax}(\boldsymbol{\alpha}, \tau)\)。左列显示离散（分类）分布，总是产生 one-hot 样本。来自 [JGP17] 的图 1。经 Ben Poole 友好许可使用。

其中 \(\epsilon_k \sim \text{Gumbel}(0, 1)\) 是从 **Gumbel 分布** [Gum54] 中采样的。我们可以先采样 \(u_k \sim \text{Unif}(0, 1)\)，然后计算 \(\epsilon_k = -\log(-\log(u_k))\) 来绘制此类样本。这称为 **Gumbel-max 技巧** [MTM14]，为分类分布提供了可重参数化的表示。

不幸的是，argmax 的导数在除了从一个标签过渡到另一个标签的边界之外处处为 0，在边界处导数未定义。但是，假设我们将 argmax 替换为 softmax，并将离散 one-hot 向量 \(\boldsymbol{d}\) 替换为连续松弛 \(\boldsymbol{x} \in \Delta^{K-1}\)，其中 \(\Delta^{K-1} = \{ \boldsymbol{x} \in \mathbb{R}^K : x_k \in [0, 1], \sum_{k=1}^K x_k = 1 \}\) 是 \(K\) 维单纯形。那么我们可以写成

```
\(x_k = \frac{\exp((\log \alpha_k + \epsilon_k)/\tau)}{\sum_{k'=1}^K \exp((\log \alpha_{k'} + \epsilon_{k'})/\tau)}\) (6.79)
```

其中 \(\tau > 0\) 是温度参数。这称为 **Gumbel-softmax 分布** [JGP17] 或 **具体分布** [MMT17]。随着 \(\tau \to 0\)，它平滑地趋近于离散分布，如图 6.3 所示。
我们现在可以用 \(f(\boldsymbol{x})\) 替换 \(f(\boldsymbol{d})\)，这允许我们对 \(\boldsymbol{x}\) 求取重参数化梯度。

### 6.3.8 直通估计器

在本节中，我们讨论如何近似信号量化版本的梯度。例如，假设我们有以下阈值函数，它将输出二值化：

```
f(x) = \begin{cases} 1 & \text{if } x > 0 \\ 0 & \text{if } x \le 0 \end{cases}
```

这没有定义明确的梯度。但是，我们可以使用 [Ben13] 提出的 **直通估计器** 作为近似。基本思想是在计算反向传播时，用 \(g(x) = x\) 替换 \(g(x) = f'(x)\)，其中 \(f'(x)\) 是 \(f\) 对输入的导数。请参见图 6.4 以进行可视化，并参见 [Yin+19b] 以了解为什么这是一个有效近似的分析。

在实践中，我们有时用 **hard tanh 函数** 替换 \(g(x) = x\)，定义如下

```
HardTanh(x) = \begin{cases} x & \text{if } -1 \le x \le 1 \\ 1 & \text{if } x > 1 \\ -1 & \text{if } x < -1 \end{cases}
```

这确保反向传播的梯度不会太大。请参见第 21.6 节，了解将此方法应用于离散自编码器的示例。

## 6.4 自然梯度下降

在本节中，我们讨论 **自然梯度下降 (NGD)** [Ama98]，这是一种用于优化（条件）概率分布 \(p_\theta(y|x)\) 参数的二阶方法。关键思想是通过测量诱导分布之间的距离来计算参数更新，而不是直接比较参数值。

![](img/ca72c1626f4850f058a9edc138c1ac73_305_0.png)

图 6.5: 将高斯分布的均值固定量更改（从实线到虚线曲线），当（共享）方差较小时（如 a 所示）可能比方差较大时（如 b 所示）影响更大。因此，对 \(\mu\) 的更改的影响（就预测准确性而言）取决于优化器在 \((\mu, \sigma)\) 空间中的位置。来自 [Hon+10] 的图 3，转载自 [Val00]。经 Antti Honkela 友好许可使用。

例如，考虑比较两个高斯分布，\(p_\theta = p(y|\mu, \sigma)\) 和 \(p_{\theta'} = p(y|\mu', \sigma')\)。参数向量之间的（平方）欧几里得距离分解为 \(\|\theta - \theta'\|^2 = (\mu - \mu')^2 + (\sigma - \sigma')^2\)。但是，预测分布的形式为 \(\exp(-\frac{1}{2\sigma^2} (y - \mu)^2)\)，因此 \(\mu\) 的变化需要相对于 \(\sigma\) 来衡量。这在图 6.5(a-b) 中得到说明，该图显示两个单变量高斯分布（虚线和实线），其均值相差 \(\delta\)。在图 6.5(a) 中，它们共享相同的小方差 \(\sigma^2\)，而在图 6.5(b) 中，它们共享相同的大方差。很明显，当方差小时，\(\delta\) 的值（就对分布的影响而言）重要得多。因此我们看到，两个参数相互作用，而欧几里得距离无法捕捉这一点。当我们考虑更复杂的模型（如深度神经网络）时，这个问题会严重得多。通过建模这些相关性，NGD 可以比其他梯度方法收敛快得多。

### 6.4.1 定义自然梯度

NGD 的关键是用 KL 散度来衡量两个概率分布之间的距离概念。如第 5.1.9 节所示，这可以用 Fisher 信息矩阵 (FIM) 来近似。特别是，对于任何给定的输入 \(x\)，我们有

```
$D_{KL}(p_\theta(y|x) \| p_{\theta+\delta}(y|x)) \approx \frac{1}{2} \delta^T F_x \delta$
```

其中 $F_x$ 是 FIM

```
$F_x(\theta) = -E_{p_\theta(y|x)}[\nabla^2 \log p_\theta(y|x)] = E_{p_\theta(y|x)}[(\nabla \log p_\theta(y|x))(\nabla \log p_\theta(y|x))^T]$
```

我们可以使用 \(\frac{1}{2} \delta^T F \delta\) 计算当前分布和更新分布之间的平均 KL 散度，其中 \(F\) 是平均 FIM：

```
$F(\theta) = E_{p_D(x)}[F_x(\theta)]$
```
