

## 8.5.2 条件时刻高斯滤波

我们可以通过将实际似然近似为线性高斯模型，来超越高斯似然假设，该方法在 [TGFS18] 中提出。唯一的要求是我们可以计算似然的第一和第二阶条件时刻：

```
\( h_\mu(z) = \mathbb{E}[y|z] = \int y p(y|z) dy \)
```

```
\( h_\Sigma(z) = \text{Cov}[y|z] = \int (y - h_\mu(z))(y - h_\mu(z))^\mathsf{T} p(y|z) dy \)
```

注意，这些积分可能是关于非高斯测度 \( p(y|z) \) 的。另外，\( y \) 可能是离散的，在这种情况下，这些积分变为求和。

接下来我们计算无条件时刻。根据全期望定律，我们有

```
\( \hat{y} = \mathbb{E}[y] = \mathbb{E}[\mathbb{E}[y|z]] = \int h_\mu(z) \mathcal{N}(z|\mu, \Sigma) dz = g_e(h_\mu(z), \mu, \Sigma) \)
```

同样地

```
\( \mathbf{C} = \text{Cov}[z, y] = \mathbb{E}[\mathbb{E}[(z - \mu)(y - \hat{y})|z]] = \mathbb{E}[(z - \mu)(h_\mu(z) - \hat{y})] \)
```

```
\( = \int (z - \mu)(h_\mu(z) - \hat{y})^\mathsf{T} \mathcal{N}(z|\mu, \Sigma) dz = g_c(z, h_\mu(z), \mu, \Sigma) \)
```

最后

```
\( \mathbf{S} = \mathbb{V}[y] = \mathbb{E}[\mathbb{V}[y|z]] + \mathbb{V}[\mathbb{E}[y|z]] \)
```

```
\( = \int h_\Sigma(z) \mathcal{N}(z|\mu, \Sigma) dz + \int (h_\mu(z) - \hat{y})(h_\mu(z) - \hat{y})^\mathsf{T} \mathcal{N}(z|\mu, \Sigma) dz \)
```

```
\( = g_e(h_\Sigma(z), \mu, \Sigma) + g_c(h_\mu(z), h_\mu(z), \mu, \Sigma) \)
```

注意，\( \hat{y} \) 的方程在方程 (8.157) 和方程 (8.180) 中是相同的，\( \mathbf{C} \) 的方程在方程 (8.159) 和方程 (8.182) 中是相同的。此外，如果 \( h_\Sigma(z) = \mathbf{\Omega} \)，则 \( \mathbf{S} \) 的方程在方程 (8.158) 和方程 (8.185) 中是相同的。

我们可以使用线性化或数值积分来近似无条件时刻。

然后我们可以将它们代入 GGF 算法。我们称之为 **条件时刻高斯滤波** 或 **CMGF**。

我们可以使用 CMGF 在具有泊松似然的 SSM 中进行近似推断。例如，如果 \( p(y|z) = \text{Poisson}(y|ce^z) \)，则有

```
\( h_\mu(z) = h_\Sigma(z) = ce^z \)
```

该方法可以用于对更一般的指数族似然执行（扩展）卡尔曼滤波，如在 [TGFS18; OlI18] 中所述。例如，假设我们有一个分类似然：

```
\( p(y_t|z_t) = \text{Cat}(y_t|p_t) = \text{Cat}(y_t|\text{softmax}(\eta_t)) = \text{Cat}(y_t|\text{softmax}(h(z_t)) \)
```

其中 \(\eta_t = h(z_t)\) 是预测 logits。则条件均值和协方差由

\(h_\mu(z_t) = p_t = \text{softmax}(h(z_t)), h_\Sigma(z_t) = \text{diag}(p_t) - p_t p_t^\top\)

（我们可以从向量 \(p_t\) 中丢弃一个类别，以确保协方差是满秩的。）这种方法可以用于神经网络分类器 [CMJ22] 的在线推断，以及高斯过程分类器 [GFTS19] 和推荐系统 [GU16; GUK21]。我们还可以将此方法用作粒子滤波算法（第 13.2 节）中的提议分布，如在 [Hos+20b] 中讨论。

## 8.5.3 迭代滤波器和平滑器

第 8.5.1 节中的 GGF 方法和第 8.5.2 节中的 CMGF 方法，都需要在执行测量更新之前计算关于预测分布 \(\mathcal{N}(z_t|\mu_{t|t-1}, \Sigma_{t|t-1})\) 的时刻。可以执行一步 GGF 以给定新观测计算后验 \(\mathcal{N}(z_t|\mu_{t|t}, \Sigma_{t|t})\)，然后使用此修正后的后验以迭代方式计算新时刻。这被称为 **迭代后验线性化滤波器** 或 **IPLF** [GF+15]。（这与我们在第 8.3.2.2 节中讨论的迭代 EKF 类似。）请参见算法 8.7 获取伪代码，以及 [SS23, Sec 10.4] 获取更多详细信息。

### 算法 8.7：迭代条件时刻高斯滤波器。

```
def Iterated-CMGF(f, Q, h_mu, h_Sigma, y_1:T, mu_0|0, Sigma_0|0, J, g_e, g_c):
    foreach t = 1 : T do
        Predict step:
            (mu_{t|t-1}, Sigma_{t|t-1}) = CondMoments(mu_{t-1|t-1}, Sigma_{t-1|t-1}, f, Q, g_e, g_c)
        Update step:
            mu_{t|t} = mu_{t|t-1}, Sigma_{t|t} = Sigma_{t|t-1}
            foreach j = 1 : J do
                (y_hat, S_t, C_t) = CondMoments(mu_{t|t}, Sigma_{t|t}, h_mu, h_Sigma, g_e, g_c)
                (mu_{t|t}, Sigma_{t|t}, l_t) = GaussCondition(mu_{t|t-1}, Sigma_{t|t-1}, y_hat, S_t, C_t, y_t)
    Return (mu_{t|t}, Sigma_{t|t})_{t=1}^T

def CondMoments(mu, Sigma, h_mu, h_Sigma, g_e, g_c) :
    y_hat = g_e(h_mu(z), mu, Sigma)
    S = g_e(h_Sigma(z), mu, Sigma) + g_c(h_mu(z), h_mu(z), mu, Sigma)
    C = g_c(z, h_mu(z), mu, Sigma)
    Return (y_hat, S, C)
```

以类似的方式，我们可以推导 **迭代后验线性化平滑器** 或 **IPLS** [GFSS17]。这与我们在第 8.3.3 节中讨论的迭代 EKS 类似。

不幸的是，IPLF 和 IPLS 可能会发散。一种更稳健的 IPLF 版本，使用线搜索执行阻尼（部分）更新，在 [Rai+18b] 中提出。同样，一种更稳健的 IPLS 版本，使用线搜索和 Levenberg-Marquardt 更新参数，在 [Lin+21c] 中提出。

已提出上述方法的各种扩展。例如，在 [HPR19] 中，他们将 IPLS 扩展到 Forney 因子图（第 4.6.1.2 节）中的信念传播，这使得该方法可以应用于超越 SSM 的大类图形模型。特别是，他们为非线性近似高斯 BP（第 9.4.3 节）给出了一个一般线性化公式（包括显式消息更新规则），其中线性化可以是基于 Jacobian 的（“EKF 风格”）、基于统计的（时刻匹配），或其他任何方式。他们还表明，任何此类线性化方法都可以从迭代中受益。

在 [Kam+22] 中，他们提出了一种基于近似期望传播（第 10.7 节）的方法，它与 IPLS 非常相似，只是用于计算 SLR 项（计算高斯消息所需）的分布不同。特别是，它不使用上一次迭代的平滑后验，而是使用“空腔”分布，即当前后验减去上一次迭代发送的传入消息，类似于第 8.2.4.4 节。其优点是传出消息不会重复计算证据。缺点是这可能在数值上不稳定。

在 [WSS21] 中，他们提出了各种“Bayes-Newton”方法，用于对具有非线性和/或非高斯似然的概率模型进行近似高斯后验计算。这推广了上述所有方法，并可以应用于 SSM 和 GP。

## 8.5.4 集合卡尔曼滤波器

集合卡尔曼滤波器（EnKF）是地球科学（气象学）社区开发的一种技术，用于在大型非线性系统中执行近似在线推断。特别是，它主要用于隐藏状态表示空间网格上每个点的未知物理量（例如温度或压力），且测量稀疏且空间定位的问题。将这些信息在空间和时间上结合起来称为数据同化。

标准参考文献是 [Eve09]，但一个更易于理解的教程（使用本章采用的相同的贝叶斯信号处理方法）在 [Rot+17] 中。

关键思想是用有限数量的样本 \(\mathbf{Z}_{t|t} = \{z_{t|t}^s : s = 1 : N_s\}\) 表示信念状态 \(p(z_t | y_{1:t})\)，其中每个 \(z_{t|t}^s \in \mathbb{R}^{N_z}\)。与粒子滤波（第 13.2 节）不同，样本以非常接近卡尔曼滤波器的方式更新，因此没有重要性采样或重采样步骤。缺点是后验不会收敛到真实的贝叶斯后验，即使 \(N_s \to \infty\) [LGMT11]，除非是线性高斯情况。但是，有时 EnKF 在样本数量较少时性能可能更好（当然，这取决于 PF 提议分布）。

后验均值和协方差可以从样本集合中如下推导：

```
\(\tilde{\mathbf{z}}_{t|t} = \frac{1}{N_s} \sum_{s=1}^{N_s} z_{t|t}^s = \frac{1}{N_s} \mathbf{Z}_{t|t} \mathbf{1} \qquad (8.189)\)
```

```
\(\tilde{\Sigma}_{t|t} = \frac{1}{N_s - 1} \sum_{s=1}^{N_s} (z_t^s - \tilde{z}_{t|t})(z_t^s - \tilde{z}_{t|t})^\top = \frac{1}{N_s - 1} \tilde{\mathbf{Z}}_{t|t} \tilde{\mathbf{Z}}_{t|t}^\top \qquad (8.190)\)
```

其中 \(\tilde{\mathbf{Z}}_{t|t} = \mathbf{Z}_{t|t} - \tilde{\mathbf{z}}_{t|t} \mathbf{1}^\top = \mathbf{Z}_{t|t} (\mathbf{I}_{N_s} - \frac{1}{N_s} \mathbf{11}^\top)\)。
