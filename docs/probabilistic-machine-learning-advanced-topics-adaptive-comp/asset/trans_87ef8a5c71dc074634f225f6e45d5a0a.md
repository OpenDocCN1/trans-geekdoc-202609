
确实，标准目标函数的形式为

```
$\mathcal{L}_{\text{VI}}(\boldsymbol{w}^0, \boldsymbol{\phi}) = \frac{1}{J} \sum_{j=1}^J \left( \sum_{(\boldsymbol{x}, \boldsymbol{y}) \in \mathcal{D}_{all}^j} \left[ \frac{1}{S} \sum_{s=1}^S \log p(\tilde{\boldsymbol{y}}^j | \tilde{\boldsymbol{x}}^j, \boldsymbol{w}_s^j) - D_{KL} \left( q_\phi(\boldsymbol{w}^j | \mathcal{D}_{all}^j, \boldsymbol{w}^0) \| p(\boldsymbol{w}^j | \boldsymbol{w}^0) \right) \right] \right)$
(19.33)
```

其中 \(\boldsymbol{w}_s^j \sim q_\phi(\boldsymbol{w}^j | \mathcal{D}_{all}^j)\)。我们可以看到，标准表述是对 log 求平均，而元学习表述是对平均求 log。后者可以提供可证明更好的预测准确性，如 [MAD20] 所指出。另一个区别是，元学习表述优化的是正向 KL，而非反向 KL。最后，在元学习表述中，参数后验上没有 KL 惩罚项。
下面我们展示该框架如何包含几种常见的元学习方法。

### 19.6.4.2 神经过程

在任务特定推理网络计算点估计的特殊情况下，\(q(\boldsymbol{w}^j | \mathcal{D}^j, \boldsymbol{w}^0) = \delta(\boldsymbol{w}^j - \mathcal{A}_\phi(\mathcal{D}^j, \boldsymbol{w}^0))\)，后验预测分布变为

```
$q(\tilde{\boldsymbol{y}}^j | \tilde{\boldsymbol{x}}^j, \mathcal{D}^j, \boldsymbol{w}^0) = \int p(\tilde{\boldsymbol{y}}^j | \tilde{\boldsymbol{x}}^j, \boldsymbol{w}^j) q(\boldsymbol{w}^j | \mathcal{D}^j, \boldsymbol{w}^0) d\boldsymbol{w}^j = p(\tilde{\boldsymbol{y}}^j | \tilde{\boldsymbol{x}}^j, \mathcal{A}_\phi(\mathcal{D}^j, \boldsymbol{w}^0), \boldsymbol{w}^0)$
(19.34)
```

其中 \(\mathcal{A}_\phi(\mathcal{D}^j, \boldsymbol{w}^0)\) 是一个接收集合并返回某些参数的函数。我们可以实证评估此预测分布，并使用标准监督最大似然方法直接对其进行优化（关于 \(\boldsymbol{\phi}\) 和 \(\boldsymbol{w}^0\)）。这种方法称为 **神经过程** [Gar+18e; Gar+18d; Dub20; Jha+22]。

### 19.6.4.3 基于梯度的元学习（MAML）

在基于梯度的元学习中，我们将任务特定的推理过程定义如下：

```
$\hat{\boldsymbol{w}}^j = \mathcal{A}(\mathcal{D}^j, \boldsymbol{w}^0) = \boldsymbol{w}^0 + \eta \nabla_\boldsymbol{w} \log \sum_{n=1}^{N^j} p(\boldsymbol{y}_n^j | \boldsymbol{x}_n^j, \boldsymbol{w})|_{_\boldsymbol{w}^0}$
(19.35)
```

即，我们将任务特定参数设置为共享参数 \(\boldsymbol{w}^0\)，沿 log 条件似然的梯度方向修改一步。这种方法称为 **与模型无关的元学习** 或 **MAML** [FAL17]。也可以通过将梯度输入 RNN 来执行多个梯度步骤 [RL17]。

### 19.6.4.4 基于度量的少样本学习（原型网络）

现在假设 \(\boldsymbol{w}^0\) 对应于共享神经特征提取器 \(h_{\boldsymbol{w}^0}(\boldsymbol{x})\) 的参数，而任务特定参数是分类器最后线性层的权重和偏置，\(\boldsymbol{w}^j = \{\boldsymbol{w}_c^j, b_c^j\}_{c=1}^C\)。让我们计算每个任务训练集中每个类的特征向量平均值：

```
$\boldsymbol{\mu}_c^j = \frac{1}{|\mathcal{D}_c^j|} \sum_{\boldsymbol{x}_n^i \in \mathcal{D}_c^j} h_{\boldsymbol{w}^0}(\boldsymbol{x}_n^c)$
(19.36)
```

现在定义任务特定的推理过程如下。我们首先计算包含每个类质心和范数的向量：

\(\hat{\mathbf{w}}^j = \mathcal{A}(\mathcal{D}^j, \mathbf{w}^0) = [\boldsymbol{\mu}_c^j, -\frac{1}{2}||\boldsymbol{\mu}_c^j||^2]_{c=1}^C\)

预测分布变为

\(q(\tilde{y}^j = c | \tilde{\mathbf{x}}^j, \mathcal{D}^j, \mathbf{w}^0) \propto \exp\left(-d(h_{\mathbf{w}^0}(\tilde{\mathbf{x}}), \boldsymbol{\mu}_c^j)\right) = \exp\left( h_{\mathbf{w}^0}(\tilde{\mathbf{x}})^\mathsf{T} \boldsymbol{\mu}_c^j - \frac{1}{2}||\boldsymbol{\mu}_c^j||^2 \right)\)

其中 \(d(\boldsymbol{\unknown}, \mathbf{v})\) 是欧氏距离。这相当于称为 **原型网络** [SSZ17] 的技术。

## 19.7 持续学习

在本节中，我们讨论 **持续学习**（例如，参见 [Had+20; Del+21; Qu+21; LCR21; Mai+22; Wan+23]），也称为 **终身学习**（例如，参见 [Thr98; CL18]），即系统从一系列不同的分布 \(p_1, p_2, \dots\) 中学习。特别是，在每个时间步 \(t\)，模型接收一批标注数据，

\(\mathcal{D}_t = \{(\mathbf{x}_n, \mathbf{y}_n) \sim p_t(\mathbf{x}, \mathbf{y}) : n = 1 : N_t\}\)

其中 \(p_t(\mathbf{x}, \mathbf{y})\) 是未知的数据分布，我们将其表示为 \(p_t(\mathbf{x}, \mathbf{y}) = p_t(\mathbf{x})p(\mathbf{y}|f_t(\mathbf{x}))\)，其中 \(f_t : \mathcal{X}_t \rightarrow \mathcal{Y}_t\) 是未知的预测函数。每个分布定义一个不同的 **任务**。然后，学习者被期望更新其对底层分布的信念状态，并使用其信念对独立测试集进行预测，

\(\mathcal{D}_t^{\text{test}} = \{(\mathbf{x}_n, \mathbf{y}_n) \sim p_t^{\text{test}}(\mathbf{x}, \mathbf{y}) : n = 1 : N_t^{\text{test}}\}\)

取决于我们如何假设 \(p_t(\boldsymbol{x}, \boldsymbol{y})\) 随时间演变，以及如何定义测试集，我们可以创建各种不同的 CL 场景。特别是，如果时间 \(t\) 的测试分布包含来自直到（并包括）时间 \(t\) 的所有任务的样本，那么我们要求模型不“遗忘”过去的数据，这对许多方法来说可能很棘手，如第 19.7.4 节所述。相比之下，如果时间 \(t\) 的测试分布与当前分布相同，如在在线学习（第 19.7.5 节）中，那么我们只要求学习者适应变化，但无需记住过去。（注意，我们专注于监督问题，但非平稳性也出现在强化学习中；特别是，由于代理不断变化的策略，输入分布发生变化，并且由于该策略的值函数被更新，所需的预测函数也会发生变化。）

### 19.7.1 域漂移

**域漂移**问题指的是 \(p_t(\boldsymbol{x})\) 随时间变化（即协变量漂移），但功能映射 \(f_t : \mathcal{X} \rightarrow \mathcal{Y}\) 保持不变的设置。例如，自动驾驶汽车的视觉系统可能需要在不断变化的光照条件下对汽车与行人进行分类（例如，参见 [Sun+22]）。

要评估此类模型，我们假设 \(f_t^{\text{test}} = f_t\) 并将 \(p_t^{\text{test}}(\boldsymbol{x})\) 定义为当前输入分布 \(p_t\)（例如，如果当前是夜间，我们希望探测器在暗图像上表现良好）。
