# Complexity Families

The fastest family of all algorithms comprises the algorithms that run in no more than constant time, no matter what their input. We denote this complexity with O(1); for example, an algorithm that checks if the last digit of a number is odd or even will not be affected by the size of the number and will run in constant time. The 1 in O(1) follows from the fact that O(1) means that the algorithm needs no more than a multiple of one steps to run—that is, a constant number of steps.

Before we meet the next complexity family, we need to take a brief excursion into a particular ways things can grow or shrink. If you add something many times, you multiply it. If you multiply something many times, you raise it to a power or exponentiate it. We just saw how big numbers with exponents like 10¹ get. What is perhaps not immediately obvious is how quickly exponentiation leads to dizzying escalation—a phenomenon called exponential growth.
