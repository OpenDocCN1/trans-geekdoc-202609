The World Wide Web is an example of a (huge) directed
graph. We can represent the web with nodes standing in
for web pages and edges standing in for the hyperlinks be-	ween each pair of pages. This graph is a directed graph,
because a page may link to another page, but that other
page does not necessarily link back to the first page.
