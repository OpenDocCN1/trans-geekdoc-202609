We have drawn the landmasses as circles, and the bridges as lines connecting the circles. The problem then can be restated as follows: If you have a pencil, is it possible to start from any of the circles, put the pencil down, and follow the lines without lifting the pencil from the paper so that you can pass through every line exactly once? Euler’s solution went as follows. Whenever you enter a landmass, you must leave it, except if this is the start or end of your walk.
