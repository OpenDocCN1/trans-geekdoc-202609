We can take care of the situation, however, by adopting a less extreme strategy. Instead of moving each item we find bang to the front, we can move just one position forward. This is called the transposition method:

+   1. Search for the item using a sequential search.
2. If the item is found, report that it is found, exchange it with the previous one (if it is not the first one), and stop.
3. Otherwise, report that the item was not found and stop.

In this way, items that are popular will gradually make their way to the front, and less popular items will move to the back, without sudden upheavals.
