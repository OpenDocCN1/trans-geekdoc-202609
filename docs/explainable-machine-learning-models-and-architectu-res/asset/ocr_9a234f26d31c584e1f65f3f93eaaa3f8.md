# 4.5 Implementation of a Microphone on FPGA

For sending a real-time raw audio signal, an onboard microphone is used. Ethernet is used to access the microphone and CIC (Cascaded Integrator Comb) compiler IP is used, which reduces the filter implementation time while providing the ability to make trade-offs between differing hardware implementations of their CIC Filter specification.
