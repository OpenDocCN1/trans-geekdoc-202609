# ## 3.1.5 FPGA Architecture

A core FPGA architecture shown in Figure 3.1 is a composition of several customizable logic blocks [CLBs], which are linked to one another by a fabric, a network of programmable interconnects (round cited in section 3.1.3). "Input/output (I/O) blocks" connect the core FPGA with external devices.

The logic operation delegated to the module is carried out by CLB. I/O blocks and CLBs are connected using Programmable Multiplexers, horizontal and vertical routing channels.
