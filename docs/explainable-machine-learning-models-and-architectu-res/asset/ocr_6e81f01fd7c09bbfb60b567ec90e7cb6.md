# 3.2.2 Hybrid FPGA Architecture

The hybrid FPGA architecture shown in Figure 3.2 is comprised of different technologies in terms of its dependency level. In the figure, different memory units are combined together to sustain parallel processing. This analysis served as the foundation for the methodology that was used to develop the new architecture, which is referred to as the Hybrid FPGA. This analysis was performed on a large collection of memory circuits to determine which types of logic resources will best match the requirements of the circuits, in terms of chip space.
