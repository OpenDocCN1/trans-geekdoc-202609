# 11.2.3 Weibull Method [12]

The computation of PDF and CDF wind distribution parameters (k-shape and c-scale) using Weibull (WB) method is carried out using the following Equations:

```
$$f(v) = \left(\frac{k}{c}\right)\left(\frac{v}{c}\right)^{k-1} \exp\left(-\left(\frac{v}{c}\right)^k\right)$$
```

```
$$F(v) = 1 - \exp\left(-\left(\frac{v}{c}\right)^k\right)$$
```

For other wind distributions PDF and CDF carried out with respective equations.
