

# 数据隐私与再识别风险

通过大数据和机器学习技术实现的数据隐私保护和个人再识别问题依然存在。虽然在数据收集时会向个人保证信息的保密性，但一旦他们的数据成为更大数据集的一部分，并能与其他数据集进行三角验证，就可能很容易识别出该个人。将为某一目的收集并获得同意的数据，重新用于另一目的，违反了最初提供的同意。然而，如果数据能够去标识化，它将具有实用价值，并能避免浪费稀缺的进一步数据收集资源。

# 高级数据分析的能力差距

在使用高级数据分析技术方面，仍然存在巨大的能力差距。十年前，这种能力差距存在于移动数据收集领域，但现在已基本弥合。随着数据分析变得更加自动化，以及我们所描述的技术使用更加普及，这一差距应当会缩小。如今，使用这些技术需要大量的数据准备、清洗和编码工作，这超出了许多评估者的技能范围。仍然需要人工解读和支持来训练模型，评估者的专业知识对于支持高质量、透明的分析至关重要。

# 评估者的培训机会

虽然网上有大量关于机器学习、情感分析和其他相关领域的培训资源，但专门面向评估者的培训机会却寥寥无几。现有的培训仅由极少数评估者提供。随着移动数据收集和计算机辅助定性数据分析课程已进入专业及通才评估培训课程的主流，数据科学和机器学习基础课程也该登场了。这些课程将使评估者——无论是委托方还是实践者——更加了解在评估合同约束条件下什么是可能的，什么是不可能的。

# 合同驱动因素与政策发展

由于大多数评估基于合同，除非客户开始要求在评估中使用这些技术，否则评估者和评估公司缺乏开发这些技能的动力。美国政府通过《2018年循证决策法案》（[US Congress, 2018](#c2.xhtml#re_TNFUK_02_AREV_C002-CIT000051)）可能开始朝这个方向迈进，但在美国联邦政府内部确保全面的监测和评估之前，还有大量工作要做，才能涉足更高级的主题。令人欣慰的是，白宫发布的《行政命令13960》（[US White House](#c2.xhtml#re_TNFUK_02_AREV_C002-CIT000052), 2022）要求所有联邦机构清点其 AI 用例，并与其他政府机构和公众共享清单。这项命令至少可能推动美国政府的委托方采用更先进的技术。无论政策层面如何发展，实践者和委托方都需要更好地掌握新兴技术技术背后的原理，以便准确评估这些技术可能带来的风险、偏见和优势。

# 弥合技能差距

评估所需技能与运用本章所述许多技术所需技能之间仍存在差距。评估者有必要了解技术在项目实施中的广泛应用，以便评估其相关性、有效性、效率、可持续性、协调性和影响。但越来越需要将这些新兴技术、自然语言处理、大数据和机器学习的培训纳入评估课程，以便下一代实践者知道如何利用这些技术，并与技术同事合作，利用证据做出决策。在这些领域的培训是一个共同合作的机会，通过在新兴技术开发中应用评估方法和技能，来规避陷阱、增强潜力（[Gandhi, 2023](#c2.xhtml#re_TNFUK_02_AREV_C002-CIT000022)）。
