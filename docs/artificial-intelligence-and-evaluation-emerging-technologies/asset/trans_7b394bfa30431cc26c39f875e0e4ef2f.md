

# 理解复杂动态：社交媒体分析方法论

为了理解这些复杂的动态，我们观察了关于冲突的信息流，以更好地了解社交媒体在塑造观点和传播信息中的作用（首先，搜索话题标签 `#RussiaUkraineWar`）。为此，我们进行了社交网络分析（SNA）（[图 9.1](#c9.xhtml#f9.1)），这使我们能够识别关键国家、追踪信息传播并考察连接公众的结构。SNA 是一种通过网络和图论分析社会结构的方法。在社交媒体背景下，SNA 可用于分析用户、群组和内容之间的连接，从而深入了解信息如何传播以及观点如何形成（[Xu & Li, 2013](#c9.xhtml#re_TNFUK_09_AREV_C009-CIT000057)；Kapoor et al., [2018](#c9.xhtml#re_TNFUK_09_AREV_C009-CIT000026)）。SNA 还可以识别社交媒体平台上的不同群组和社区（[Giuffrida](#c9.xhtml#re_TNFUK_09_AREV_C009-CIT000018) et al., 2018, [2019](#c9.xhtml#re_TNFUK_09_AREV_C009-CIT000019)；Freire et al., [2023](#c9.xhtml#re_TNFUK_09_AREV_C009-CIT000014)）。

**[图 9.1](#c9.xhtml#re_f9.1) SNA 中的中心性。**

根据本研究进行的 SNA 分析，德国、丹麦和英国是参与 Twitter 讨论最多的国家。值得注意的是，这些国家均为大西洋联盟（NATO）成员。然而，尽管不是北约成员，芬兰和奥地利也发挥了显著作用。

它们积极参与这些动态，凸显了国际协作以及在不同政治和地理实体之间建立桥梁的重要性。因此，SNA 提供了关于社会互动和信息网络复杂性的详细图景。结果表明，北约成员国和该联盟外的一些参与者都在为可能的持续冲突解决奠定坚实基础方面发挥着作用。

这些群组可能基于共同的兴趣、信仰或地理位置。通过分析这些群组之间的连接，研究人员可以深入了解信息如何在不同社区内部及之间传播，识别社交媒体上信息传播的模式。这可能包括识别最常分享的内容类型、发帖的时间和频率，以及话题标签和其他元数据的使用。通过分析这些模式，可以更好地理解信息如何共享以及观点如何形成。

一旦映射了数字语境中的所有关系，我们就使用 Google Trends 选择与话题标签 `#RussiaUkraineWar` 相关的关键词。Google Trends 是一个分析随时间变化的搜索行为的强大工具，可以提供特定关键词和短语流行度的见解。将 Google Trends 与话题标签结合使用的额外价值在于，它允许跟踪话题标签随时间的流行度、分析地理趋势并识别相关搜索查询。

从搜索词“Russia-Ukraine war”出发，我们查看了搜索量最高的词汇（“trend”）。随后选定了“Sanctions”（制裁）和“Nuclear Threat”（核威胁）。之后，我们使用这些话题标签/关键词收集相关推文。最后，使用 Power BI 构建动态仪表板以从数据中寻找洞察。下一节将描述进行研究所使用的工具。

## Google Trends

Google Trends 允许用户查看搜索词随时间的相对流行度，从而深入了解公众对特定话题的兴趣。当与话题标签结合时（[Miracula & Celardi, 2023](#c9.xhtml#re_TNFUK_09_AREV_C009-CIT000033)），Google Trends 可提供任何特定话题标签随时间推移和跨不同地区的流行度和关注度的定量分析，以及这种流行度如何与事件和趋势相关联。研究人员可以通过搜索关键词或话题标签快速识别最相关的推文，并了解人们如何讨论特定问题。这可以提供公众对冲突兴趣及其演变的见解。此外，通过查看搜索的地理位置，可以了解冲突在不同地区的感知方式。

Google 搜索量用于多个研究领域，在这些领域中，掌握个人关切、兴趣和观点的信息至关重要。例如在医学领域，检查与流感症状相关的搜索词已被证明可以预测流感活动（Ginsberg et al., [2009](#c9.xhtml#re_TNFUK_09_AREV_C009-CIT000017)）。搜索量可以预测经济指标（[Da et al., 2011](#c9.xhtml#re_TNFUK_09_AREV_C009-CIT000011)；[Choi & Varian, 2012](#c9.xhtml#re_TNFUK_09_AREV_C009-CIT000007)）。最后，在 COVID-19 大流行期间，多项研究利用搜索量分析了大流行（Pan et al., [2020](#c9.xhtml#re_TNFUK_09_AREV_C009-CIT000039)；Walker et al., [2020](#c9.xhtml#re_TNFUK_09_AREV_C009-CIT000056)）。

Google Trends 提供用户输入 Google 的查询量的时间序列指数。给定时期内最大查询份额被标准化为 100。诸如“Nuclear Threat”之类的查询会被计入“Nuclear”的查询指数计算中。请注意，Google Trends 数据是使用抽样方法计算的，因此结果每天会有几个百分点的变化。因此，正如在多个研究领域所示，搜索量分析可以揭示个人信息搜索的见解。然而，其使用伴随着几个重要的考量因素。研究人员在使用 Google Trends 数据时应谨慎，因为它存在局限性和潜在偏差。

## Twitter 和 Power BI

基于在 Google Trends 中的观察，我们试图了解有关特定事件的信息如何跨社交网络传播。我们决定从特定社交网络 Twitter 收集文本数据。这一选择的原因很简单。Twitter 是一个可以快速获取数据的社交网络，因为它提供常规 API，即一种设计用于通过互联网交换数据的应用程序编程接口（API）。

我们使用了 `Tweepy`，一个可以通过 Python 代码获取推文的库。它是一个开源库，因其易用性和多功能性而在 Python 开发者中广受欢迎。`Tweepy` 为访问 Twitter API 提供了易用的接口。该库使开发者能够编写 Python 脚本以多种方式与 Twitter 交互，例如搜索推文、发布推文和流式传输实时推文。
