# 比较政策评估

主编 Ray C. Rist

“比较政策评估”丛书是一套跨学科且具有国际视野的书籍系列，其核心高度聚焦于治理议题的比较分析——素材来源遍及所有大陆和许多不同的民族国家。审视和回顾这些政策举措的透镜是评估。这些评估分析主要基于社会学、人类学、经济学、政策科学、审计学、法学和人权等视角。本书还为所分析的政策议题演变提供了强有力的纵向视角。
