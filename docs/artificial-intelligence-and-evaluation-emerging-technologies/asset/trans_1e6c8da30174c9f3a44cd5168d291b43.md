

# 利用文本分析进行评估：近期 IEG 评估的实例

## 文本摘要

*文本摘要* 是一种有监督技术，涉及生成给定文档的较短版本，同时保留其最重要的信息和含义。例如，该技术已被用于以清晰易懂的方式总结包含在 120,000 多份非标准化资助报告中的结果案例（Ahlsén 等，[2019](#c5.xhtml#re_TNFUK_05_AREV_C005-CIT000003)）。

## 情感分析

*情感分析* 利用有监督或无监督学习，自动识别并提取文本中的情感或主观基调。情感分析的目标是确定给定文本对特定主题表达的是积极、消极还是中性的情感。例如，情感分析有助于识别受益人对特定政策干预的看法和态度。例如，该技术已被用于利用推文分析对叙利亚冲突的情感（Lucić 等，[2020](#c5.xhtml#re_TNFUK_05_AREV_C005-CIT000028)），对 2019 年阿尔巴尼亚地震的后果进行紧急响应和早期恢复评估（Contreras 等，[2022](#c5.xhtml#re_TNFUK_05_AREV_C005-CIT000013)），以及了解关于 COVID-19 疫苗的情感极性（Christensen 等，[2021](#c5.xhtml#re_TNFUK_05_AREV_C005-CIT000011)）。

## 机器翻译

*机器翻译* 是一种利用计算机自动将文本从一种自然语言翻译成另一种自然语言的技术。该技术可采用有监督或无监督方法实施。在发展政策干预的背景下，机器翻译有助于克服语言障碍，确保政策制定者和实践者能够获取所有受益人的观点和经验。例如，它已被用于为资源匮乏的语言开发快速且经济实惠的翻译系统^()

在 IEG 评估工作的背景下，文本分析的实际应用主要集中在三个领域：评价对象识别、投资组合分析和评估综合。尽管不同的文本分析方法能为评估实践提供多种效率提升，但可以说最相关的一个是利用有监督和/或无监督方法对大量文本进行分类。这也是本章所呈现示例的重点。传统的文本分类严重依赖文献审查和人工编码，需要领域专家投入大量精力和时间。这通常耗时费力，且难以规模化。相比之下，自动文本分类提供了一种可规模化的解决方案（Bravo 等，[2023](#c5.xhtml#re_TNFUK_05_AREV_C005-CIT000007)）。

## 示例 1：利用文本挖掘和有监督机器学习识别复杂的评价对象

### 使用背景

IEG 最近的主题性^()

世界银行（WB）客户国的发展成果受“营商环境”（DB）影响，一个关键渠道是其在告知和影响世行贷款项目方面的作用（世界银行，[2022](#c5.xhtml#re_TNFUK_05_AREV_C005-CIT000047)，第 6 页）。因此，要理解 DB 在世行客户国项目中的落地情况的相关性和有效性，首先有必要识别属于该投资组合的所有世行项目。此类项目通常在项目目标、组成部分或结果框架中提及 DB 指标（世界银行，[2022](#c5.xhtml#re_TNFUK_05_AREV_C005-CIT000047)，第 85 页）。

这并非一项简单的工作，因为在评估期间世行批准了 5,710 个贷款项目，对所有这些项目进行人工编码对 IEG 来说成本高得难以承受。在此情况下，人工编码主要指评估人员阅读每个项目的各种可用文档，并判断其是否为“DB 知情”项目的活动。

世行贷款项目的主要设计文档类型是项目评估文件（PAD），评估团队需要审阅每个项目的 PAD 以了解其基本原理、目标和结果框架。此类文档平均长达 92 页，意味着评估团队需审阅超过 50 万页的文本。按五人评估团队计算，每人约需阅读 10 万页文本。

除了阅读文档这一耗时任务外，评估人员还必须花费时间在识别、下载和整理相关文档等各个步骤上。除了人力资源成本，还存在人工编码偏差的问题。挑战不仅在于人工审阅文本数量，更在于在资源限制下确保质量。由 DB 项目广泛范围驱动的庞大评估主题，放大了纯人工编码过程的时间和错误风险，要求严格的编码者间信度测试。

### 该应用如何助力回答评估问题/完成任务

IEG 决定利用文本挖掘和 NLP 高效、准确地开展投资组合识别工作。这一流程使评估团队能够专注于他们的强项——运用判断力对少量项目进行分类——而算法则专注于其强项——处理大量文档并准确预测项目分类。

### 实施方式

IEG 采用了分步法，一方面结合关键词搜索和有监督 NLP，另一方面结合人工审阅（针对文档总体的子集）。该过程具有高度迭代性。**[图 5.1](#c5.xhtml#f5.1)** 示意性地描述了这一过程。

#### 使用搜索分类法进行初步投资组合识别

首先开展了一项投资组合识别工作，涉及开发一种搜索分类法，用于搜索所有项目标题、发展目标、组成部分标题和结果框架指标标题的文本（世界银行，[2022](#c5.xhtml#re_TNFUK_05_AREV_C005-CIT000047)，第 87 页）。该搜索分类法围绕 DB 的十二个监管领域或主题构建（世界银行，[2020](#c5.xhtml#re_TNFUK_05_AREV_C005-CIT000045)，第 78 页）。这一初步识别得出一份包含 372 个项目的长名单，随后通过人工筛选确定了 131 个被编码为“DB 知情”的项目。该方法识别出了最终 DB 知情投资组合（共 269 个项目）的一半。

这一初步工作凸显了仅使用搜索分类法捕捉相关项目的挑战，鉴于评价对象的复杂性。为了说明这一点，仅以 DB 涵盖的十二个监管领域之一（世界银行，[2020](#c5.xhtml#re_TNFUK_05_AREV_C005-CIT000046)，第 3 页）“获得信贷”为例。世行项目可以通过多种途径寻求影响政府监管变革，以改善私营部门获得信贷的条件。对于每条途径，用文字描述的方式可能有好几种。因此，首先识别所有与“获得信贷”相关的不同途径，然后识别所有这些途径的不同措辞方式和实际措辞方式，这项任务既繁琐又无法提供全面的结果。此外，在许多情况下，“获得信贷”（或类似词汇）在文档中被使用，但这与 DB 监管领域的背景无关。
