

# 表 2.1 国际发展评估中的关键新兴技术：前景与陷阱

| 新兴技术 | 前景 | 陷阱 |
| --- | --- | --- |
| **数据收集与获取** | | |
| 移动数据、行政登记/地理数据 | 从收集到使用的周期快，能够绘制成果图谱，能够提高数据收集质量 | 数据隐私（特别是位置信息），行政数据可能缺乏背景信息 |
| 社交媒体数据和在线数据 | 信息可用性增加，更直接地获取社区意见（潜在地无政府干预），收集成本低 | 隐私问题，无意中包含假新闻或被操纵的数据，审查制度，代表性方面潜在的公平性缺失，需要大量数据清洗 |
| 卫星、无人机、物联网 | 对项目影响和成果有完整准确的了解，客观，可实现实时监测，数据收集可能具有成本效益 | 缺乏背景信息，对安全、隐私、知情同意、安全性、数据质量和可靠性的担忧。实施可能需要技能 |
| 聊天机器人、虚拟代理 | 在低带宽环境下自动化数据收集过程，潜在降低成本，易于更新或更改收集的数据，随时可用 | 对回应不敏感且可能惹恼受访者，部署需要技能，仍处于起步阶段 |
| 虚拟现实 | 能够协助形成性评估并支持项目设计，可能减少出差需求，模拟真实生活场景 | 建立成本高昂，实施能力要求高，且可能不适用于所有情况 |
| **数据分析** | | |
| 数据分析（使用大数据） | 分析速度加快，可使用跨度广泛的数据并可重复使用数据 | 可能排除那些贡献数据较少的人，数据准备和分析需要高水平技能 |
| 自然语言处理和生成式 AI（例如：`ChatGPT`） | 自动化、速度以及在分析中纳入更多信息并揭示隐藏洞察的能力，可与其协作以支持写作和编码 | 可能存在算法偏见，特定语料库需要大量数据清洗，需要在语料库上训练模型，其得出结论的过程是黑箱，存在作者身份确认问题 |
| 机器学习 | 文档优化，发现隐藏洞察的潜力，可基于词频分配标签/分组，偏见较小，随着新数据到来可自动更新，使用难度降低 | 算法偏见可能纳入或排除关键群体，因数据准备不善可能纳入无关数据，难以准备数据并拥有足够数据训练模型 |

## 数据收集与获取

在国际发展领域，利用技术进行数据收集与获取的采用率最高。先进数据收集技术的应用在过去十年中取得了快速进展。2010 年移动数据收集和在线调查还相对较新，而如今已司空见惯。下文将详细讨论五种主要技术。

### 移动数据收集与 GPS 位置数据

国际发展界广泛采用移动和在线技术进行数据收集，通常带有全球定位系统（`GPS`）位置数据功能（Blumenstock, Cadamuro, & On, [2015](#c2.xhtml#re_TNFUK_02_AREV_C002-CIT000007)）。许多移动数据收集平台是为国际发展界设计的，范围从免费或“免费增值”^()

#### 移动与 GPS 数据收集的前景

移动数据收集有助于标准化所收集的数据，使用跳转逻辑、检查、范围，以及必答和非必答题。`GPS` 位置数据功能可实现按地理位置改进制图和数据分解。如果在互联网连接良好的地方收集数据，可能可以实时记录和转录参与者的发言。来自移动应用程序（如社区卫生工作者、农业推广工作者或教师使用的应用程序）的数据收集，可以成为关于项目如何（或未能）触达其目标产出的丰富监测数据来源。先进的移动数据收集系统可以访问现有数据库，允许数据收集员访问同一受访者的过往记录，从而简化队列调查的数据收集。当这些数据库系统与生物识别技术（Benston et al., [2020](#c2.xhtml#re_TNFUK_02_AREV_C002-CIT000006)）、嵌入式射频识别（`RFID`）标签或条形码扫描器配对时，识别受访者或特定数据收集点的准确性会提高。

#### 移动与 GPS 数据收集的陷阱

高质量、标准化且严谨的数据收集仍然需要受过培训的调查员，虽然移动数据收集加快了数据获取过程，但并未显著降低人力成本。在线数据收集虽然高效，但仍面临低回复率和不确定的抽样框架问题，这损害了数据的质量和可能的准确性。`GPS` 数据可能过于精确，潜在地泄露受访者过多信息，需要更高水平的分析技能来掩盖数据（尽管最好的平台现在允许在收集点进行掩盖）。对于所有收集的数据，如果数据未妥善存储，且去识别化和数据再利用的协议未明确界定，隐私和识别个人身份都可能构成风险。与所有数据收集一样，这种数据主要的定量性质可能意味着数据背后的背景和含义丢失或难以解释。

### 社交媒体数据和在线数据

社交媒体是提供用户创建内容（创建、讨论、交换）空间的交互式在线工具。Facebook、YouTube、WhatsApp、Instagram、TikTok、Messenger、WeChat、LinkedIn 和 Telegram 拥有最多用户（Wikipedia ([n.d.](#c2.xhtml#re_TNFUK_02_AREV_C002-CIT000055))）。除了社交媒体，互联网网站构成了一个巨大的数据和信息库，可能对评估者有用。

社交媒体分析（`SMA`）（Zachlod, Samuel, Ochsner & Werthmüller, [2022](#c2.xhtml#re_TNFUK_02_AREV_C002-CIT000058）)是评估者一个有趣的方法论工具。传统上由市场营销和销售公司使用，它们开发了几种商业可用的分析工具，如 `Tweettracker`（Kumar, Barbier, Abbasi & Liu, [2021](#c2.xhtml#re_TNFUK_02_AREV_C002-CIT000033)）、`Hootsuite`、`Planable` 和 `Loomly`（[Marvin & Sevilla, 2019](#c2.xhtml#re_TNFUK_02_AREV_C002-CIT000036)）。
