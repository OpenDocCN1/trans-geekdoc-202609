Hence, all solutions of system (1) are confined in the region as Equation 7.10.

$$\Omega = \left\{ (S,E,I,Q,R) \in R_{+}^{5} : N \le \frac{A}{d_{1}} \right\}$$ (7.10)

which completes the proof.

# 7.4.2 CALCULATION OF BASIC REPRODUCTION NUMBER

In this section, we define the basic reproduction number as the accepted number of secondary individuals produced in a completely susceptible population by an infected individual during the entire COVID-19 period. This number is useful as a measure of the strength of the control measures required to break the epidemic.

The basic reproduction number is the spectral radius of the next generation matrix. Consider the SEIQR model expressed in Equation 7.11. The system is linearized to form a Jacobian matrix. The Jacobian matrix is decomposed into the F−V matrix, where F is the production of a new infection, and V is the nonsingular matrix that changes from compartment to compartment:

$$F = \begin{pmatrix} \beta SI \\ 0 \\ 0 \\ 0 \\ 0 \end{pmatrix} \text{ and } V = \begin{pmatrix} \beta SI - A + d_{1}S \\ (d_{1}+\mu)E \\ (d_{1}+d_{2}+\alpha)I - \mu E \\ (d_{1}+d_{2}+\delta)Q - \alpha I \\ d_{1}R - \delta Q \end{pmatrix}$$ (7.11)

Taking the partial derivative with respect to infection class E and I, we get Equation 7.12:

$$F = \begin{pmatrix} 0 & \beta SI \\ 0 & 0 \end{pmatrix} \text{ and } V = \begin{pmatrix} (d_{1}+\mu) & 0 \\ -\mu & (d_{1}+d_{2}+\alpha) \end{pmatrix}$$ (7.12)

The basic reproduction number is the spectral radius of the next generation matrix $FV^{-1}$ and is given by Equation 7.13:

$$FV^{-1} = \frac{\beta S_{0} \mu}{(d_{1}+d_{2}+\alpha)(d_{1}+\mu)}$$ (7.13)

and Equation 7.14

$$R_{0} = \frac{\beta \mu}{(d_{1}+d_{2}+\alpha)(d_{1}+\mu)}$$ (7.14)

This acts as the threshold for the formation or failure of an epidemic.
