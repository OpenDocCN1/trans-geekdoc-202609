We highlight that the proposed approach using image classification models has limitations. In our computation setup, the VGG16 and VGG16+CBAM models achieved 51 ms and 52 ms of inference time on average per image, respectively. Therefore, a system may not be able to run real-time inferences. This approach

and the addition of the described techniques increased the model complexity, which demands a high computational cost.

For example, BRAMON has a large amount of data that the monitoring stations have not analyzed. Then, manual analysis cannot process the data with the same velocity as collected. Hence, our approach can be used as a filtering stage, assisting experts to quickly review the model's suggestions and reduce the time spent in human analysis.
