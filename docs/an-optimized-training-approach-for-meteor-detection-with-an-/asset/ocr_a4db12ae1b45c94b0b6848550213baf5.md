recommend using the nearest-neighbor interpolation method for the image scaling algorithm to achieve the same results.

# 5. Conclusion

In this study, we attempt to improve the robustness in the scenario of limited labeled data in the application of meteor detection. Based on the assumption that the attention mechanism may be significant for this. We investigated a generalization improvement using the CBAM attention mechanism combined with an optimized training approach from a VGG16 architecture. Using this approach, one can expect a significant data reduction of 91% based on our experiments. Therefore, we can employ an automated reduction process using the generated models by filtering a list of suspect meteors from the previous nights, as Al-Owais et al. (2022) propose. This approach will save the time spent on human analysis and the required storage.

Our optimized training approach reached state-of-the-art results close to those of previous studies. Provided that the VGG16 network correctly predicted 46 out of 50 meteor images while making 11 out of 50 mistakes in forecasting the non-meteor class. This model was more unstable in its predictions, suffering overfitting by learning the noise from the meteor class of images. Although the VGG16+CBAM model was worsening in evaluation metrics, the CBAM improved the representation power from the VGG16 network. This method focused on more critical and suppressed unnecessary features, as seen in the visual explanations.

Although further investigation is needed to verify the proposed approach in a more extensive set of new real-world images, our findings offer a promising direction for dealing with limited available labeled data in the meteor detection domain. In the same way, other work can use different batch sizes and learning rates to verify improvements. Finally, our implementation is easy to integrate with other types of attention mechanisms for testing. The dataset and the main source code used in this study are available on Zenodo (Shirasuna and Gradvohl, 2023). Future research can use the presented 7000 balanced meteor dataset for other findings in the meteor detection application.
