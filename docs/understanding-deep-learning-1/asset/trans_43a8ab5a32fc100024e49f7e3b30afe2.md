
网络运行后，会使用启发式过程移除置信度低的矩形框，并抑制对应同一物体的预测边界框，仅保留置信度最高的一个。

### 10.5.3 语义分割

语义分割的目标是根据像素所属的物体为每个像素分配一个标签，如果该像素不对应训练数据库中的任何内容，则不分配标签。图 [10.19](#c010.xhtml#c10-fig-0019) 展示了一个早期的语义分割网络。输入为 `224×224` 的 RGB 图像，输出为 `224×224×21` 的数组，包含每个位置属于 21 个可能类别中每一类的概率。

![Figure 10.19 Semantic segmentation network of Noh et al. (2015). The input is a 224×224 image, which is passed through a version of the VGG network and eventually transformed into a representation of size 4096 using a fully connected layer. This contains information about the entire image. This is then reformed into a representation of size 7×7 using another fully connected layer, and the image is upsampled and deconvolved (transposed convolutions without upsampling) in a mirror image of the VGG network. The output is a 224×224×21 representation that gives the output probabilities for the 21 classes at each position.](images/c10-fig-0019.jpg)

[图 10.19](#c010.xhtml#c10-fig-0019a) Noh 等人 (2015) 的语义分割网络。输入为 `224×224` 图像，经过一个版本的 `VGG` 网络，最终通过全连接层转换为大小为 `4096` 的表示。这包含了关于整幅图像的信息。然后通过另一个全连接层将其重塑为大小为 `7×7` 的表示，并在 `VGG` 网络的镜像结构中对图像进行上采样和反卷积（不带上采样的转置卷积）。输出为 `224×224×21` 的表示，给出了每个位置 21 个类别的输出概率。

网络的第一部分是 `VGG` 的一个较小版本（[图 10.17](#c010.xhtml#c10-fig-0017)），包含十三个而非十五个卷积层，将表示下采样至 `14×14`。随后进行一次最大池化操作，接着是两个全连接层，映射到两个大小为 `4096` 的 1D 表示。这些层不表示空间位置，而是整合来自整幅图像的信息。

在此，架构偏离了 `VGG`。另一个全连接层将表示重组为 `7×7` 空间位置和 `512` 通道。随后是一系列最大取消池化层（见 [图 10.12b](#c010.xhtml#c10-fig-0012)）和 `反卷积` 层。这些是转置卷积（见 [图 10.13](#c010.xhtml#c10-fig-0013)），但是在 2D 情况下且不带上采样。最后，有一个 `1×1` 卷积创建代表可能类别的 `21` 个通道，并在每个空间位置进行 softmax 操作，将激活值映射为类别概率。网络的下采样侧有时被称为 `编码器`，上采样侧被称为 `解码器`，因此这类网络有时被称为 `编码器-解码器网络` 或 `沙漏网络`，因其形状而得名。

最终分割结果通过一种启发式方法生成，该方法贪婪地搜索表示最多的类别并推断其区域，同时考虑概率并鼓励连通性。然后在剩余未标记像素中占主导地位的位置添加下一个表示最多的类别。此过程持续进行，直到没有足够证据添加更多类别为止（[图 10.20](#c010.xhtml#c10-fig-0020)）。

![Figure 10.20 Semantic segmentation results. The final result is created from the 21 probability maps by greedily selecting the best class and using a heuristic method to find a sensible binary map based on the probabilities and their spatial proximity. If there is enough evidence, subsequent classes are added, and their segmentation maps are combined. Adapted from Noh et al. (2015).](images/c10-fig-0020.jpg)

[图 10.20](#c010.xhtml#c10-fig-0020a) 语义分割结果。最终结果由 21 个概率图创建，通过贪婪地选择最佳类别，并使用启发式方法基于概率及其空间邻近性找到合理的二值图。如果有足够证据，则添加后续类别，并组合它们的分割图。改编自 Noh 等人 (2015)。

## 10.6 总结

在卷积层中，每个隐藏单元通过计算附近输入的加权和、加上偏置并应用激活函数来得出。权重和偏置在每个空间位置都相同，因此参数远少于全连接网络，且参数量不随输入图像大小增加。为确保信息不丢失，该操作会使用不同的权重和偏置重复进行，以在每个空间位置创建多个通道。

典型的卷积网络由卷积层和以 2 为因子下采样的层交替组成。随着网络加深，空间维度通常按 2 的因子减小，通道数按 2 的因子增加。网络末端通常有一个或多个全连接层，整合来自整个输入的信息并创建所需输出。如果输出是图像，镜像 `解码器` 会上采样回原始尺寸。

卷积层的平移等变性施加了有用的归纳偏置，使其在基于图像的任务上相对于全连接网络性能更优。我们介绍了图像分类、目标检测和语义分割网络。实验表明，随着网络加深，图像分类性能提高。然而，后续实验表明，无限增加网络深度并不能持续带来帮助；超过一定深度后，系统变得难以训练。这正是 `残差连接` 的动机，将在下一章讨论。
