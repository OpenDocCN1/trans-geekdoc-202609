
到目前为止，我们暗示加性函数 `f[x]` 可以是任何有效的网络层（例如全连接层或卷积层）。从技术上讲这是正确的，但这些函数中的运算顺序很重要。它们必须包含像 ReLU 这样的非线性激活函数，否则整个网络将是线性的。然而，在典型的网络层中（[图 11.5a](#c011.xhtml#c11-fig-0005)），ReLU 函数位于末尾，因此输出是非负的。如果我们采用这一惯例，那么每个残差块只能增加输入值。

However, we must add a linear transformation at the start of the network in case the input is all negative. c) In practice, it's common for a residual block to contain several network layers.](images/c11-fig-0005.jpg)

因此，通常会更改运算顺序，使激活函数首先被应用，随后是线性变换（[图 11.5b](#c011.xhtml#c11-fig-0005)）。有时残差块内部可能包含多个处理层（[图 11.5c](#c011.xhtml#c11-fig-0005)），但这些层通常以线性变换结束。最后我们注意到，当我们用 ReLU 操作开始这些块时，如果初始网络输入为负，它们将不执行任何操作，因为 ReLU 会将整个信号裁剪为零。因此，通常以线性变换而不是残差块开始网络，如 [图 11.5b](#c011.xhtml#c11-fig-0005) 所示。

### 11.2.2 具有残差连接的更深层网络

添加残差连接大致使网络在性能下降前可实际训练的深度翻倍。然而，我们希望进一步增加深度。为了理解为什么残差连接不允许我们任意增加深度，我们必须考虑前向传播过程中激活值方差如何变化，以及反向传播过程中梯度幅度如何变化。

## 11.3 残差网络中的梯度爆炸

在第 7.5 节中，我们看到初始化网络参数至关重要。如果没有仔细的初始化，反向传播前向传递过程中中间值的幅度可能会呈指数级增加或减少。同样，当我们向后穿过网络时，反向传递过程中的梯度可能会爆炸或消失。

因此，我们初始化网络参数，使得激活值（在前向传递中）和梯度（在反向传递中）的期望方差在层之间保持不变。He 初始化（第 7.5 节）通过将偏置 `β` 初始化为零，并选择均值为零、方差为 `2/D[h]` 的正态分布权重 `Ω`（其中 `D[h]` 是前一层隐藏单元的数量），为 ReLU 激活实现了这一点。

现在考虑一个残差网络。由于存在一条路径，使得每一层都直接对网络输出做出贡献（公式 11.5 和 [图 11.4b](#c011.xhtml#c11-fig-0004)），我们不必担心中间值或梯度会随网络深度而消失。然而，即使我们在残差块内使用 He 初始化，前向传递中的值也会随网络深度呈指数级增加。

为了理解原因，请考虑我们将残差块中处理的结果加回到输入上。每个分支都有一些（不相关的）变异性。因此，当我们重新组合它们时，总方差会增加。使用 ReLU 激活和 He 初始化时，每个块中的处理不会改变期望方差。因此，当我们与输入重新组合时，方差翻倍（[图 11.6a](#c011.xhtml#c11-fig-0006)），并随残差块的数量呈指数级增长。这限制了在前向传递中超过浮点精度之前可能的网络深度。类似的论证也适用于反向传播算法反向传递中的梯度。
