

## 1.1 具有结构化输出的监督学习

[图 1.4a](#c001.xhtml#c1-fig-0004) 描绘了一个用于语义分割的多元二分类模型。在这里，输入图像的每个像素都被分配一个二进制标签，指示其属于奶牛还是背景。[图 1.4b](#c001.xhtml#c1-fig-0004) 展示了一个多元回归模型，其中输入是街景图像，输出是每个像素处的深度。在这两种情况下，输出均为高维且结构化的。然而，这种结构与输入紧密相关，且可被利用；如果一个像素被标记为“奶牛”，则具有相似 RGB 值的邻域像素很可能具有相同的标签。

![Figure 1.4 Supervised learning tasks with structured outputs. a) This semantic segmentation model maps an RGB image to a binary image indicating whether each pixel belongs to the background or a cow (adapted from Noh et al., 2015). b) This monocular depth estimation model maps an RGB image to an output image where each pixel represents the depth (adapted from Cordts et al., 2016). c) This audio transcription model maps an audio sample to a transcription of the spoken words in the audio. d) This translation model maps an English text string to its French translation. e) This image synthesis model maps a caption to an image (example from https://openai.com/dall-e-2/). In each case, the output has a complex internal structure or grammar. In some cases, many outputs are compatible with the input.](images/c1-fig-0004.jpg)

[图 1.4](#c001.xhtml#c1-fig-0004a) 具有结构化输出的监督学习任务。a) 该语义分割模型将 RGB 图像映射为二值图像，指示每个像素属于背景还是奶牛（改编自 Noh 等人，2015）。b) 该单目深度估计模型将 RGB 图像映射为输出图像，其中每个像素代表深度（改编自 Cordts 等人，2016）。c) 该音频转录模型将音频样本映射为音频中口语单词的转录文本。d) 该翻译模型将英文文本字符串映射为其法语翻译。e) 该图像合成模型将标题映射为图像（示例来自 [https://openai.com/dall-e-2/](https://openai.com/dall-e-2/)）。在每种情况下，输出都具有复杂的内部结构或语法。在某些情况下，许多输出均与输入兼容。

[图 1.4c–e](#c001.xhtml#c1-fig-0004) 描绘了三个模型，在这些模型中，输出具有复杂的结构，但与输入的联系不那么紧密。[图 1.4c](#c001.xhtml#c1-fig-0004) 展示了一个模型，其输入为音频文件，输出为该文件的转录单词。[图 1.4d](#c001.xhtml#c1-fig-0004) 是一个翻译模型，其中输入为一段英文文本，输出包含其法语翻译。[图 1.4e](#c001.xhtml#c1-fig-0004) 描绘了一项极具挑战性的任务，其中输入为描述性文本，模型必须生成与该描述相匹配的图像。

原则上，后三项任务可在标准监督学习框架内解决，但它们更难，主要有两个原因。首先，输出可能真正存在歧义；从一个英文句子到法语句子存在多个有效翻译，且与任何标题兼容的图像也有多张。其次，输出包含大量结构；并非所有单词串都构成有效的英文或法语句子，也并非所有 RGB 值的集合都构成合理的图像。除了学习映射关系外，我们还必须遵守输出的“语法”。

幸运的是，这种“语法”可以在无需输出标签的情况下学习。例如，我们可以通过学习大量文本语料库的统计规律来学习如何构成有效的英文句子。这为本书的下一节提供了联系，下一节将讨论*无监督学习模型*。

## 1.2 无监督学习

在没有相应输出标签的情况下，仅从输入数据构建模型被称为*无监督学习*；输出标签的缺失意味着不存在“监督”。其目标不是学习从输入到输出的映射，而是描述或理解数据的结构。正如监督学习的情况一样，数据可能具有截然不同的特征；它可能是离散或连续的、低维或高维的、定长或变长的。

### 1.2.1 生成模型

本书重点关注*生成式无监督模型*，这类模型学习合成新的数据样本，使其在统计上与训练数据无法区分。一些生成模型显式地描述了输入域上的概率分布，新样本通过从该分布中采样生成。另一些则仅学习一种生成新样本的机制。

最先进的生成模型能够合成极其逼真但与训练样本不同的样本。它们在生成图像（[图 1.5](#c001.xhtml#c1-fig-0005)）和文本（[图 1.6](#c001.xhtml#c1-fig-0006)）方面取得了特别的成功。它们还可以在部分输出被预先确定的约束下合成数据（称为*条件生成*）。示例包括图像修复（[图 1.7](#c001.xhtml#c1-fig-0007)）和文本补全（[图 1.8](#c001.xhtml#c1-fig-0008)）。事实上，现代文本生成模型非常强大，以至于它们看起来似乎具有智能。给定一段文本和一个问题，模型通常可以通过生成文档最可能的补全来“填补”缺失的答案。然而，实际上，模型仅了解语言的统计规律，并不理解其答案的意义。
