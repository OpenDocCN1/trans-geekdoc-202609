
# 8.3.2 减少偏差

偏差项源于模型无法描述真实的底层函数。这表明我们可以通过使模型更灵活来减少此错误。这通常通过增加模型 `capacity` 来完成。对于神经网络，这意味着添加更多隐藏单元和/或隐藏层。

在简化模型中，增加容量对应于添加更多隐藏单元，以便将区间 `[0, 1]` 划分为更多线性区域。[图 8.7a–c](#c008.xhtml#c8-fig-0007) 显示（毫不奇怪）这确实减少了偏差；随着我们将线性区域的数量增加到十个，模型变得足够灵活，能够紧密拟合真实函数。

![Figure 8.7 Bias and variance as a function of model capacity. a–c) As we increase the number of hidden units of the toy model, the number of linear regions increases, and the model becomes able to fit the true function closely; the bias (gray region) decreases. d–f) Unfortunately, increasing the model capacity has the side-effect of increasing the variance term (gray region). This is known as the bias-variance trade-off.](images/c8-fig-0007.jpg)

[图 8.7](#c008.xhtml#c8-fig-0007a) 模型容量函数下的偏差和方差。a–c) 随着我们增加玩具模型的隐藏单元数量，线性区域的数量增加，模型变得能够紧密拟合真实函数；偏差（灰色区域）减小。d–f) 不幸的是，增加模型容量有一个副作用，即增加方差项（灰色区域）。这被称为偏差-方差权衡。

### 8.3.3 偏差-方差权衡

然而，[图 8.7d–f](#c008.xhtml#c8-fig-0007) 显示了增加模型容量的一个意外副作用。对于固定大小的训练数据集，方差项随着模型容量的增加而增加。因此，增加模型容量并不一定会减少测试误差。这被称为 `bias-variance trade-off`。

[图 8.8](#c008.xhtml#c8-fig-0008) 探讨了这一现象。在面板 a–c) 中，我们将简化的三区域模型拟合到三个各包含十五个点的不同数据集。尽管数据集不同，但最终模型大致相同；数据集中的噪声在每个线性区域大致平均掉了。在面板 d–f) 中，我们将具有十个区域的模型拟合到相同的三个数据集。该模型具有更大的灵活性，但这却是不利的；模型确实更好地拟合了数据，训练误差会更低，但大部分额外的描述能力都用于建模噪声。这种现象称为 `overfitting`。

![Figure 8.8 Overfitting. a–c) A model with three regions is fit to three different datasets of fifteen points each. The result is similar in all three cases (i.e., the variance is low). d–f) A model with ten regions is fit to the same datasets. The additional flexibility does not necessarily produce better predictions. While these three models each describe the training data better, they are not necessarily closer to the true underlying function (black curve). Instead, they overfit the data and describe the noise, and the variance (difference between fitted curves) is larger.](images/c8-fig-0008.jpg)

[图 8.8](#c008.xhtml#c8-fig-0008a) 过拟合。a–c) 一个三区域模型分别拟合到三个各包含十五个点的不同数据集。在所有三种情况下结果都相似（即方差较低）。d–f) 一个十区域模型拟合到相同的数据集。额外的灵活性不一定产生更好的预测。虽然这三个模型都能更好地描述训练数据，但它们不一定更接近真实的底层函数（黑色曲线）。相反，它们过拟合数据并描述噪声，且方差（拟合曲线之间的差异）更大。

我们已经看到，随着我们给模型增加容量，偏差会减小，但对于固定大小的训练数据集，方差会增加。这表明存在一个最优容量，使得偏差不会太大而方差仍然相对较小。[图 8.9](#c008.xhtml#c8-fig-0009) 展示了随着我们增加容量，玩具模型中这些项如何随数值变化，使用的是来自[图 8.8](#c008.xhtml#c8-fig-0008) 的数据。对于回归模型，总期望误差是偏差和方差之和，当模型容量为四时（即具有四个隐藏单元和四个线性区域），该和最小化。
