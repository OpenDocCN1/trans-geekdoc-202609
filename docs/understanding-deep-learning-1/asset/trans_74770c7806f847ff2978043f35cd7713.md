

### 10.2.6 卷积网络与感受野

第 4 章介绍了深度网络，其由一系列全连接层组成。同样，卷积网络由一系列卷积层组成。网络中某隐藏单元的*感受野*是指馈送给它的原始输入区域。考虑一个卷积网络，其中每个卷积层的核大小为三。第一层中的隐藏单元对三个最近的输入进行加权求和，因此感受野大小为三。第二层中的单元对第一层中三个最近位置进行加权求和，而这些位置本身又是三个输入的加权求和。因此，第二层中的隐藏单元具有大小为五的感受野。以此类推，后续层中单元的感受野逐渐增大，来自整个输入的信息被逐步整合（[图 10.6](#c010.xhtml#c10-fig-0006)）。

Hence, hidden units in H2 have a receptive field size of five. c) The hidden units in the third layer (kernel size three, stride two) increases the receptive field size to seven. d) By the time we add a fourth layer, the receptive field of the hidden units at position three have a receptive field that covers the entire input.](images/c10-fig-0006.jpg)

[图 10.6](#c010.xhtml#c10-fig-0006a) 核宽度为三的网络的感受野。a) 一个十一维的输入馈送到一个具有三个通道且卷积核大小为三的隐藏层。第一隐藏层 `H[1]` 中三个高亮显示的隐藏单元的预激活值是最近三个输入的不同加权求和，因此 `H[1]` 中的感受野大小为三。b) 第二层 `H[2]` 中四个高亮显示的隐藏单元的预激活值分别对第一层 `H[1]` 中三个通道在三个最近位置上的值进行加权求和。第一层 `H[1]` 中的每个隐藏单元对最近的三个输入位置进行加权。因此，`H[2]` 中的隐藏单元具有大小为五的感受野。c) 第三层中的隐藏单元（核大小三，步幅二）将感受野大小增加到七。d) 当我们添加第四层时，位置三处隐藏单元的感受野覆盖了整个输入。

### 10.2.7 示例：MNIST-1D

我们现在将卷积网络应用于 MNIST-1D 数据（见图 8.1）。输入 `x` 是一个 40 维向量，输出 `f` 是一个 10 维向量，通过 softmax 层产生类别概率。我们使用一个具有三个隐藏层的网络（[图 10.7](#c010.xhtml#c10-fig-0007)）。第一隐藏层 `H[1]` 的十五个通道分别使用核大小为三、步幅为二且采用“valid”填充的方式计算，得到十九个空间位置。第二隐藏层 `H[2]` 同样使用核大小为三、步幅为二和“valid”填充进行计算。第三隐藏层的计算方式类似。此时，表示具有四个空间位置和十五个通道。这些值被重塑为大小为六十的向量，并通过一个全连接层映射到十个输出激活值。

![Figure 10.7 Convolutional network for classifying MNIST-1D data (see figure 8.1). The MNIST-1D input has dimension Di = 40. The first convolutional layer has fifteen channels, kernel size three, stride two, and only retains "valid" positions to make a representation with nineteen positions and fifteen channels. The following two convolutional layers have the same settings, gradually reducing the representation size. Finally, a fully connected layer takes all sixty hidden units from the third hidden layer. It outputs ten activations that are subsequently passed through a softmax layer to produce the ten class probabilities.](images/c10-fig-0007.jpg)

[图 10.7](#c010.xhtml#c10-fig-0007a) 用于对 MNIST-1D 数据进行分类的卷积网络（见图 8.1）。MNIST-1D 输入的维度 `D[i]` = 40。第一个卷积层有十五个通道，核大小三，步幅二，仅保留“valid”位置，从而形成一个具有十九个位置和十五个通道的表示。接下来的两个卷积层具有相同的设置，逐渐减小表示的大小。最后，一个全连接层接收来自第三隐藏层的所有六十个隐藏单元。它输出十个激活值，随后通过 softmax 层产生十个类别概率。

该网络使用 SGD（无动量）、学习率 0.01、批量大小 100，在包含 4,000 个样本的数据集上训练了 100,000 步。我们将其与一个具有相同层数和隐藏单元数量的全连接网络进行比较（即三个隐藏层，分别具有 285、135 和 60 个隐藏单元）。卷积网络有 2,050 个参数，而全连接网络有 150,185 个参数。根据[图 10.4](#c010.xhtml#c10-fig-0004)的逻辑，卷积网络是全连接网络的一个特例。后者具有足够的灵活性来精确复制前者。[图 10.8](#c010.xhtml#c10-fig-0008) 显示两个模型都完美拟合了训练数据。然而，卷积网络的测试误差远小于全连接网络。
