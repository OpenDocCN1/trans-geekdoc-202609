

## 第二，我们设置机器学习模型

***

### 笔记本 5.2：二元交叉熵损失

***

变换后的模型输出 `sig[f[x, ϕ]]` 预测伯努利分布的参数 `λ`。这代表 `y = 1` 的概率，由此可知 `1 − λ` 代表 `y = 0` 的概率。当我们进行推理时，可能需要 `y` 的点估计，因此如果 `λ > 0.5` 则设 `y = 1`，否则设 `y = 0`。

## 5.5 示例 3：多类分类

*Multiclass classification*（多类分类）的目标是将输入数据样本 `x` 分配给 `K > 2` 个类别中的一个，即 `y ∈ {1, 2, …, K}`。现实世界的例子包括：(i) 预测手写数字图像 `x` 中出现的是 `K = 10` 个数字 `y` 中的哪一个；(ii) 预测在不完整句子 `x` 之后跟随的是 `K` 个可能单词 `y` 中的哪一个。

我们再次遵循第 5.2 节中的配方。我们首先选择预测空间 `y` 上的分布。在这种情况下，`y ∈ {1, 2, …, K}`，所以我们选择 *categorical distribution*（[图 5.9](#c005.xhtml#c5-fig-0009)），它定义在该域上。它有 `K` 个参数 `λ[1], λ[2], …, λ[K]`，它们决定每个类别的概率：

![c5-fig-5022.jpg](images/c5-fig-5022.jpg)

 (5.21)

![Figure 5.9 Categorical distribution. The categorical distribution assigns probabilities to K > 2 categories, with associated probabilities λ1, λ2, …, λK. Here, there are five categories, so K = 5. To ensure that this is a valid probability distribution, each parameter λk must lie in the range [0, 1], and all K parameters must sum to one.](images/c5-fig-0009.jpg)

[图 5.9](#c005.xhtml#c5-fig-0009a) Categorical 分布。Categorical 分布为 `K > 2` 个类别分配概率，相关概率为 `λ[1], λ[2], …, λ[K]`。此处有五个类别，所以 `K = 5`。为确保这是一个有效的概率分布，每个参数 `λ[k]` 必须位于范围 `[0, 1]` 内，且所有 `K` 个参数之和必须为 1。

这些参数被约束在 0 和 1 之间取值，并且它们的总和必须为 1，以确保是一个有效的概率分布。

然后我们使用一个具有 `K` 个输出的网络 `f[x, ϕ]` 从输入 `x` 计算这 `K` 个参数。不幸的是，网络输出不一定满足上述约束。因此，我们将网络的 `K` 个输出通过一个函数，以确保满足这些约束。一个合适的选择是 *softmax* 函数（[图 5.10](#c005.xhtml#c5-fig-0010)）。它接收一个长度为 `K` 的任意向量，并返回一个长度相同的向量，但其中的元素现在位于范围 `[0, 1]` 内且和为 1。softmax 函数的第 `k` 个输出为：

![c5-fig-5023.jpg](images/c5-fig-5023.jpg)

 (5.22)

![Figure 5.10 Multiclass classification for K = 3 classes. a) The network has three piecewise linear outputs, which can take arbitrary values. b) After the softmax function, these outputs are constrained to be non-negative and sum to one. Hence, for a given input x, we compute valid parameters for the categorical distribution: any vertical slice of this plot produces three values sum to one and would form the heights of the bars in a categorical distribution similar to figure 5.9.](images/c5-fig-0010.jpg)

[图 5.10](#c005.xhtml#c5-fig-0010a) `K = 3` 个类别的多类分类。a) 网络有三个分段线性输出，可以取任意值。b) 经过 softmax 函数后，这些输出被约束为非负且和为 1。因此，对于给定的输入 `x`，我们计算 categorical 分布的有效参数：该图的任意垂直切片产生的三个值和为 1，将形成类似于[图 5.9](#c005.xhtml#c5-fig-0009) 中 categorical 分布柱状图的高度。

其中指数函数确保非负性，分母中的求和确保这 `K` 个数字之和为 1。
