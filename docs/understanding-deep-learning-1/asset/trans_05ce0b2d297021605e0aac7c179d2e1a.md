# 第 11 章

残差网络

上一章描述了随着卷积网络深度从八层（AlexNet）扩展到十八层（VGG），图像分类性能是如何提升的。这促使人们尝试构建更深的网络。然而，当增加更多层时，性能反而下降了。

本章介绍*残差块*。在此结构中，每个网络层计算当前表示的一个加性变化，而不是直接对其进行变换。这使得更深的网络得以训练，但在初始化时会导致激活值幅度呈指数级增长。残差块采用*批量归一化*来补偿这一问题，它在每一层对激活值进行重新中心化和重新缩放。

带有批量归一化的残差块允许训练深得多的网络，并且这些网络在各种任务上都提升了性能。本章描述了结合残差块以解决图像分类、医学图像分割和人体姿态估计的架构。

## 11.1 顺序处理

我们迄今为止见到的每个网络都按顺序处理数据；每一层接收前一层的输出并将结果传递给下一层（[图 11.1](#c011.xhtml#c11-fig-0001)）。例如，一个三层网络定义为：

```
h[1] = f[1][x, ϕ[1]]
h[2] = f[2][h[1], ϕ[2]]
h[3] = f[3][h[2], ϕ[3]]
y = h[3]
```
 (11.1)

其中 `h[1]`、`h[2]` 和 `h[3]` 表示中间隐藏层，`x` 是网络输入，`y` 是输出，函数 `f[k][•, ϕ[k]]` 执行处理过程。

![Figure 11.1 Sequential processing. Standard neural networks pass the output of each layer directly into the next layer.](images/c11-fig-0001.jpg)

[图 11.1](#c011.xhtml#c11-fig-0001a) 顺序处理。标准神经网络将每一层的输出直接传递给下一层。

在标准神经网络中，每一层由一个线性变换和一个激活函数组成，参数 `ϕ[k]` 包含线性变换的权重和偏置。在卷积网络中，每一层由一组卷积和一个激活函数组成，参数包含卷积核和偏置。

由于处理是顺序的，我们可以等价地将该网络视为一系列嵌套函数：

```
y = f[3][f[2][f[1][x, ϕ[1]], ϕ[2]], ϕ[3]]
```
 (11.2)

### 11.1.1 顺序处理的局限性

原则上，我们可以添加任意数量的层，在上一章中我们看到，向卷积网络添加更多层确实能提升性能；拥有十八层的 VGG 网络（图 10.17）优于八层的 AlexNet（图 10.16）。然而，随着层数进一步增加，图像分类性能再次下降（[图 11.2](#c011.xhtml#c11-fig-0002)）。这令人惊讶，因为模型通常随着容量增加而表现更好（图 8.10）。事实上，这种下降同时出现在训练集和测试集上，这意味着问题在于训练更深的网络，而非更深网络无法泛化。

![Figure 11.2 Decrease in performance when adding more convolutional layers. a) A 20-layer convolutional network outperforms a 56-layer neural network for image classification on the test set of the CIFAR-10 dataset (Krizhevsky & Hinton, 2009). b) This is also true for the training set, which suggests that the problem relates to training the original network rather than a failure to generalize to new data. Adapted from He et al. (2016a).](images/c11-fig-0002.jpg)

[图 11.2](#c011.xhtml#c11-fig-0002a) 增加卷积层导致性能下降。a) 在 CIFAR-10 数据集（Krizhevsky & Hinton, 2009）测试集上，20 层卷积网络的图像分类性能优于 56 层神经网络。b) 训练集上也是如此，这表明问题与训练原始网络有关，而非无法泛化到新数据。改编自 He et al. (2016a)。

这种现象尚未被完全理解。一种推测是，在初始化时，当我们修改早期网络层的参数时，损失梯度会不可预测地变化。通过适当的权重初始化（见第 7.5 节），损失相对于这些参数的梯度将是合理的（即没有梯度爆炸或消失）。然而，导数假设参数发生无限小的变化，而优化算法使用有限的步长。任何合理的步长选择都可能移动到一个具有完全不同且无关梯度的位置；损失地形看起来像是一大片细小的山峰，而不是一个易于下降的单一平滑结构。因此，算法无法像损失函数梯度变化较缓慢时那样取得进展。
