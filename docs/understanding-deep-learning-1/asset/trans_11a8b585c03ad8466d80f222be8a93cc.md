
# 状态值与动作值

我们可以通过考虑在给定策略 `π` 下的期望回报 `v[s[t]|π]` 来描述一个状态有多“好”。这是从该状态开始的序列平均会收到的回报，称为*状态值*或*状态价值函数*（[图 19.7a](#c019.xhtml#c19-fig-0007)）：

[图 19.7](#c019.xhtml#c19-fig-0007a) 状态值与动作值。a) 状态 `s[t]` 的值 `v[s[t]|π]`（每个位置的数字）是给定策略 `π` 下该状态的期望回报（灰色箭头）。它是从该状态开始的许多轨迹中收到的折扣奖励平均和。此处，离鱼更近的状态更有价值。b) 状态 `st` 中动作 `a[t]` 的值 `q[s[t], a[t], π]`（每个位置/状态处对应四个动作的四个数字）是在该状态采取该特定动作时的期望回报。在这种情况下，随着我们靠近鱼，值变大，且朝向鱼的方向的动作值更大。c) 如果我们知道某状态的动作值，则可以修改策略，使其选择这些值中的最大值（面板 b 中的红色数字）。

非正式地说，状态值告诉我们，如果从该状态开始并随后遵循指定策略，平均可以期望获得多少*长期*奖励。对于那些后续转移很可能很快带来大量奖励的状态（假设折扣因子 `γ` 小于 1），其值最高。

类似地，*动作值*或*状态-动作价值函数* `q[s[t], a[t]|π]` 是在状态 `s[t]` 执行动作 `a[t]` 的期望回报（[图 19.7b](#c019.xhtml#c19-fig-0007)）：

![c19-fig-5003.jpg](images/c19-fig-5003.jpg)

 (19.3)

动作值告诉我们，如果从该状态开始，采取该动作，并随后遵循指定策略，平均可以期望获得多少长期奖励。通过这个量，强化学习算法将未来的奖励与当前的动作联系起来（即解决了时序信用分配问题）。

我们想要一个能最大化期望回报的策略。对于 MDP（但不适用于 POMDP），总是存在一个确定性的、平稳的策略，能最大化每个状态的价值。如果我们知道这个最优策略，就能得到最优状态价值函数 `v*[s[t]]`：

## 19.2.3 贝尔曼方程

我们可能不知道任何策略的状态值 `v[s[t]]` 或动作值 `q[s[t], a[t]]`。[²](#c019.xhtml#c19-fn-0002) 然而，我们知道它们之间必须是一致的，并且很容易写出这些量之间的关系。状态值 `v[s[t]]` 可以通过对动作值 `q[s[t], a[t]]` 进行加权求和来求得，其中权重取决于策略 `π[a[t]|s[t]]` 下采取该动作的概率（[图 19.8](#c019.xhtml#c19-fig-0008)）：

![c19-fig-5007.jpg](images/c19-fig-5007.jpg)

 (19.7)

![Figure 19.8 Relationship between state values and action values. The value of state six v[st = 6] is a weighted sum of the action values q[st = 6, at] at state six, where the weights are the policy probabilities π[at|st = 6] of taking that action.](images/c19-fig-0008.jpg)

[图 19.8](#c019.xhtml#c19-fig-0008a) 状态值与动作值的关系。状态六的值 `v[s[t] = 6]` 是状态六处动作值 `q[s[t] = 6, a[t]]` 的加权和，权重为采取该动作的策略概率 `π[a[t]|s[t] = 6]`。

 (19.8)

The value q[st = 6, at = 2] of taking action two in state six is the reward r[st = 6, at = 2] from taking that action plus a weighted sum of the discounted values v[st+1] of being in successor states, where the weights are the transition probabilities Pr(st+1|st = 6, at = 2). 后两个关系称为*贝尔曼方程*，是许多 RL 方法的基石。简而言之，它们表明状态（动作）值必须自洽。因此，当我们更新一个状态（动作）值的估计时，这会产生涟漪效应，导致所有其他值被修改。

# 19.3 表格型强化学习

*表格型 RL 算法*（即不依赖函数近似的算法）分为*基于模型*和*无模型*方法。*基于模型方法*显式地使用 MDP 结构，并从转移矩阵 `Pr(s[t+1]|s[t], a[t])` 和奖励结构 `r[s, a]` 中找到最佳策略。如果这些是已知的，这是一个简单的优化问题，可以用*动态规划*来解决。如果未知，则必须首先从观察到的 MDP 轨迹中估计它们。[⁴](#c019.xhtml#c19-fn-0004)
