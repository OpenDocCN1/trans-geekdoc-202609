
# CycleGAN 损失函数

CycleGAN 损失函数是三个损失的加权和（[图 15.18](#c015.xhtml#c15-fig-0019)）。内容损失鼓励前后图像相似，并基于 `ℓ1` 范数。对抗损失使用判别器鼓励输出与目标域的真实样本无法区分。最后，*循环一致性* 损失鼓励映射是可逆的。这里，两个模型被联合训练。一个将第一个域映射到第二个域，另一个则反向映射。如果翻译后的图像能成功被翻译回原始域的图像，循环一致性损失将会很低。该模型结合这三个损失来训练网络，实现将图像从一种风格翻译到另一种风格，并再翻译回来。

![图 15.18 CycleGAN。两个模型同时训练。第一个 `c′ = g[cj, θ]` 将第一种风格（马）的图像 `c` 翻译为第二种风格（斑马）的图像 `c′`。第二个模型 `c = g′[c′, θ]` 学习相反的映射。如果两个模型无法成功将图像转换到另一个域并再转换回原始图像，循环一致性损失会惩罚这两个模型。此外，两个对抗损失鼓励翻译后的图像看起来像目标域的真实样本（此处仅展示斑马）。两个内容损失鼓励每次映射前后图像的细节和布局相似（即斑马处于马所在的相同位置和姿势，且背景相同，反之亦然）。改编自 Zhu 等人 (2017)。](images/c15-fig-0018.jpg)

[图 15.18](#c015.xhtml#c15-fig-0019a) CycleGAN。两个模型同时训练。第一个 `c′ = g[cj, θ]` 将第一种风格（马）的图像 `c` 翻译为第二种风格（斑马）的图像 `c′`。第二个模型 `c = g′[c′, θ]` 学习相反的映射。如果两个模型无法成功将图像转换到另一个域并再转换回原始图像，循环一致性损失会惩罚这两个模型。此外，两个对抗损失鼓励翻译后的图像看起来像目标域的真实样本（此处仅展示斑马）。两个内容损失鼓励每次映射前后图像的细节和布局相似（即斑马处于马所在的相同位置和姿势，且背景相同，反之亦然）。改编自 Zhu 等人 (2017)。

# 15.6 StyleGAN

StyleGAN 是一种更现代的 GAN，它将数据集中的变化划分为有意义的组件，每个组件由一部分潜在变量控制。具体而言，StyleGAN 在不同尺度控制输出图像，并将风格与噪声分离。对于人脸图像，大尺度变化包括脸型和头部姿态，中尺度变化包括面部特征的形状和细节，细尺度变化包括发色和肤色。风格组件代表人类感知显著的图像方面，而噪声方面代表不重要的变化，如头发、胡茬、雀斑或毛孔的确切位置。

我们迄今为止见到的 GAN 都从一个从标准基础分布中抽取的潜在变量 `z` 开始。该变量通过一系列卷积层生成输出图像。然而，生成器的潜在变量输入可以 (i) 在架构的各个点引入，并 (ii) 以不同方式修改这些点的当前表示。StyleGAN 审慎地做出这些选择，以控制尺度并将风格与噪声分离（[图 15.19](#c015.xhtml#c15-fig-0020)）。

![图 15.19 StyleGAN。主管道（中间行）从一个学习到的常数表示（灰色框）开始。这通过一系列卷积层并逐渐上采样以创建输出。噪声（顶行）通过周期性地添加具有逐通道缩放 `ψ•` 的高斯变量 `z•` 在不同尺度添加。高斯风格变量 `z` 通过一个全连接网络创建中间变量 `w`（底行）。这用于在管道的各个点设置每个通道在空间位置上的均值和方差。](images/c15-fig-0019.jpg)

[图 15.19](#c015.xhtml#c15-fig-0020a) StyleGAN。主管道（中间行）从一个学习到的常数表示（灰色框）开始。这通过一系列卷积层并逐渐上采样以创建输出。噪声（顶行）通过周期性地添加具有逐通道缩放 `ψ•` 的高斯变量 `z•` 在不同尺度添加。高斯风格变量 `z` 通过一个全连接网络创建中间变量 `w`（底行）。这用于在管道的各个点设置每个通道在空间位置上的均值和方差。

StyleGAN 的主生成分支从一个具有 512 个通道的学习到的常数 4×4 表示开始。这通过一系列逐渐上采样表示的卷积层，以生成最终分辨率的图像。代表风格和噪声的两组随机潜在变量在每个尺度被引入；它们越接近输出，代表的细节尺度就越精细。

代表噪声的潜在变量是独立采样的高斯向量 `z[1]`、`z[2]` …，并在主生成管道中每次卷积操作后以加法方式注入。它们在被添加的位置与主表示具有相同的空间尺寸，但会乘以学习到的逐通道缩放因子 `ψ[1]`、`ψ[2]` …，因此以不同量级贡献给每个通道。随着网络分辨率的增加，这种噪声在更精细的尺度上发挥作用。

代表风格的潜在变量始于一个 1×1×512 的噪声张量，该张量通过一个七层全连接网络创建中间变量 `w`。这使得网络能够解耦风格的各个方面，以便 `w` 的每个维度可以代表一个独立的现实因素，如头部姿态或发色。该变量 `w` 被线性变换为一个 2×1×512 的张量 `y`，用于在噪声添加后，设置主分支中表示在空间位置上的逐通道均值和方差。这被称为 *自适应实例归一化*（图 11.14e）。一系列向量 `y[1]`、`y[2]` … 以这种方式在主分支的几个不同点注入，因此相同的风格在不同尺度上发挥作用。[图 15.20](#c015.xhtml#c15-fig-0021) 展示了在不同尺度操纵风格和噪声向量的示例。

![图 15.20 StyleGAN 结果。前四列展示了在各种尺度上风格的系统性变化。第五列展示了增加噪声幅度的效果。最后两列展示了两个不同尺度下的不同噪声向量。](images/c15-fig-0020.jpg)

# 15.7 总结

GAN 学习一个生成器网络，将随机噪声转换为与训练集无法区分的数据。为此，生成器使用一个判别器网络进行训练，该判别器试图区分真实样本和生成样本。然后更新生成器，使其创建的数据被判别器识别为更“真实”。这种想法的原始公式有一个缺陷：当很容易判断样本是真实还是生成时，训练信号很弱。这导致了 Wasserstein GAN 的出现，它提供了更一致的训练信号。
