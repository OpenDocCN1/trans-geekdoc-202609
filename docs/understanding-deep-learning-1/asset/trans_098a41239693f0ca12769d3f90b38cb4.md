

## 3.4 浅层神经网络：一般情况

我们已经描述了几个浅层网络示例，以帮助建立关于其工作原理的直觉。我们现在为浅层神经网络 `y = f[x, ϕ]` 定义一个通用方程，该方程利用 `h ∈ ℝ^D` 个隐藏单元将多维输入 `x ∈ ℝ^D_x` 映射为多维输出 `y ∈ ℝ^D_y`。每个隐藏单元的计算方式为：

```
h_i = a[θ_i^T x + ϕ_i]
```
 (3.11)

这些隐藏单元通过线性组合来生成输出：

```
y = Θ h + b
```
 (3.12)

其中 `a[•]` 是非线性激活函数。模型参数为 `ϕ = {θ[••], ϕ[••]}`。[图 3.11](#c003.xhtml#c3-fig-0011) 展示了一个包含三个输入、三个隐藏单元和两个输出的示例。

## 3.5 术语

我们通过介绍一些术语来结束本章。遗憾的是，神经网络伴随着大量专业术语。它们通常用*层*来描述。[图 3.12](#c003.xhtml#c3-fig-0012) 左侧是*输入层*，中间是*隐藏层*，右侧是*输出层*。我们会说 [图 3.12](#c003.xhtml#c3-fig-0012) 中的网络有一个包含四个隐藏单元的隐藏层。隐藏单元本身有时被称为*神经元*。当我们将数据传递通过网络时，隐藏层的输入值（即应用 ReLU 函数之前）称为*预激活值*。隐藏层的值（即应用 ReLU 函数之后）称为*激活值*。

![图 3.12 术语。浅层网络由输入层、隐藏层和输出层组成。每一层通过前向连接（箭头）连接到下一层。因此，这些模型被称为前馈网络。当一层中的每个变量都连接到下一层中的每个变量时，我们称之为全连接网络。每个连接代表底层方程中的一个斜率参数，这些参数称为权重。隐藏层中的变量称为神经元或隐藏单元。输入隐藏单元的值称为预激活值，隐藏单元处的值（即应用 ReLU 函数后）称为激活值。](images/c3-fig-0012.jpg)

[图 3.12](#c003.xhtml#c3-fig-0012a) 术语。浅层网络由输入层、隐藏层和输出层组成。每一层通过前向连接（箭头）连接到下一层。因此，这些模型被称为前馈网络。当一层中的每个变量都连接到下一层中的每个变量时，我们称之为全连接网络。每个连接代表底层方程中的一个斜率参数，这些参数称为权重。隐藏层中的变量称为神经元或隐藏单元。输入隐藏单元的值称为预激活值，隐藏单元处的值（即应用 ReLU 函数后）称为激活值。

由于历史原因，任何至少包含一个隐藏层的神经网络也被称为*多层感知机*，简称*MLP*。具有一个隐藏层的网络（如本章所述）有时被称为*浅层神经网络*。具有多个隐藏层的网络（如下一章所述）被称为*深层神经网络*。连接形成有向无环图的神经网络（即无环图，如本章所有示例所示）被称为*前馈网络*。如果一层中的每个元素都连接到下一层中的每个元素（如本章所有示例所示），则该网络是*全连接的*。这些连接代表底层方程中的斜率参数，称为*网络权重*。偏移参数（[图 3.12](#c003.xhtml#c3-fig-0012) 中未显示）称为*偏置*。

## 3.6 总结

浅层神经网络有一个隐藏层。它们 (i) 计算输入的若干线性函数，(ii) 将每个结果通过激活函数，然后 (iii) 对这些激活值进行线性组合以形成输出。浅层神经网络通过将输入空间划分为连续的分段线性区域曲面，基于输入 `x` 进行预测 `y`。只要有足够的隐藏单元（神经元），浅层神经网络可以以任意精度逼近任何连续函数。

第 4 章讨论深层神经网络，它通过增加更多隐藏层来扩展本章的模型。第 5-7 章描述如何训练这些模型。

## 注释

**“神经”网络：** 如果本章中的模型只是函数，为什么它们被称为“神经网络”？这种联系不幸的是很牵强。像 [图 3.12](#c003.xhtml#c3-fig-0012) 这样的可视化图包含相互密集连接的节点（输入、隐藏单元和输出）。这与哺乳动物大脑中的神经元表面上相似，后者也具有密集连接。然而，几乎没有证据表明大脑计算的工作方式与神经网络相同，在未来的思考中引入生物学视角是无益的。
