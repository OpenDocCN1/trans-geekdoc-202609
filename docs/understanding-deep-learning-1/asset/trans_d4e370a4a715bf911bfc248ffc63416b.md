

## 10.2.3 步幅、核大小和膨胀率

在上面的示例中，每个输出都是最近三个输入的总和。然而，这只是卷积操作大家族中的一种，该家族的成员由其 `stride`（步幅）、`kernel size`（核大小）和 `dilation rate`（膨胀率）来区分。当我们在每个位置都计算输出时，我们称之为步幅为一。不过，也可以将核按大于一的步幅进行移动。如果步幅为二，我们创建的输出数量大约减半（[图 10.3a–b](#c010.xhtml#c10-fig-0003)）。

![Figure 10.3 Stride, kernel size, and dilation. a) With a stride of two, we evaluate the kernel at every other position, so the first output z1 is computed from a weighted sum centered at x1, and b) the second output z2 is computed from a weighted sum centered at x3 and so on. c) The kernel size can also be changed. With a kernel size of five, we take a weighted sum of the nearest five inputs. d) In dilated or atrous convolution, we intersperse zeros in the weight vector to allow us to combine information over a large area using fewer weights.](images/c10-fig-0003.jpg)

[图 10.3](#c010.xhtml#c10-fig-0003a) 步幅、核大小和膨胀。a) 步幅为二时，我们在每隔一个位置计算核，因此第一个输出 `z[1]` 是通过以 `x[1]` 为中心的加权和计算得出的，b) 第二个输出 `z[2]` 是通过以 `x[3]` 为中心的加权和计算得出的，以此类推。c) `kernel size`（核大小）也可以改变。核大小为五时，我们取最近五个输入的加权和。d) 在膨胀或空洞卷积中，我们在权重向量中插入零，以便使用更少的权重来组合更大区域的信息。

`kernel size`（核大小）可以增加以在更大的区域上进行积分（[图 10.3c](#c010.xhtml#c10-fig-0003)）。然而，它通常保持为奇数，以便能够以当前位置为中心。增加核大小的缺点是需要更多的权重。这引出了 `dilated`（膨胀）或 `atrous`（空洞）卷积的概念，其中核值与零交错插入。例如，我们可以通过将第二个和第四个元素设为零，将大小为五的核变为大小为三的膨胀核。我们仍然从更大的输入区域整合信息，但只需要三个权重即可（[图 10.3d](#c010.xhtml#c10-fig-0003)）。我们在权重之间插入的零的数量称为 `dilation rate`（膨胀率）。

### 10.2.5 通道

如果我们只应用单个卷积，信息不可避免地会丢失；我们正在对附近的输入进行平均，而 ReLU 激活函数会截断小于零的结果。因此，通常会并行计算多个卷积。每个卷积产生一组新的隐藏变量，称为 `feature map`（特征图）或 `channel`（通道）。

[图 10.5a–b](#c010.xhtml#c10-fig-0005) 通过两个大小为三且带有零填充的卷积核对此进行了说明。第一个核计算最近三个像素的加权和，加上一个偏置，并将结果通过激活函数以产生隐藏单元 `h[1]` 到 `h[6]`。这些构成了第一个通道。第二个核计算最近三个像素的不同加权和，加上不同的偏置，并将结果通过激活函数以创建隐藏单元 `h[7]` 到 `h[12]`。这些构成了第二个通道。

![Figure 10.5 Channels. Typically, multiple convolutions are applied to the input x and stored in channels. a) A convolution is applied to create hidden units h1 to h6, which form the first channel. b) A second convolution operation is applied to create hidden units h7 to h12, which form the second channel. The channels are stored in a 2D array H1 that contains all the hidden units in the first hidden layer. c) If we add a further convolutional layer, there are now two channels at each input position. Here, the 1D convolution defines a weighted sum over both input channels at the three closest positions to create each new output channel.](images/c10-fig-0005.jpg)

[图 10.5](#c010.xhtml#c10-fig-0005a) 通道。通常，多个卷积被应用于输入 `x` 并存储在通道中。a) 应用一个卷积以创建隐藏单元 `h[1]` 到 `h[6]`，它们构成第一个通道。b) 应用第二个卷积操作以创建隐藏单元 `h[7]` 到 `h[12]`，它们构成第二个通道。通道存储在二维数组 `H[1]` 中，该数组包含第一隐藏层中的所有隐藏单元。c) 如果我们添加另一个卷积层，现在每个输入位置有两个通道。在这里，一维卷积定义了在三个最近位置上跨两个输入通道的加权和，以创建每个新的输出通道。
