
This conjecture is supported by empirical observations of gradients in networks with a single input and output. For a shallow network, the gradient of the output with respect to the input changes slowly as we change the input ([figure 11.3a](#c011.xhtml#c11-fig-0003)). However, for a deep network, a tiny change in the input results in a completely different gradient ([figure 11.3b](#c011.xhtml#c11-fig-0003)). This is captured by the autocorrelation function of the gradient ([figure 11.3c](#c011.xhtml#c11-fig-0003)). Nearby gradients are correlated for shallow networks, but this correlation quickly drops to zero for deep networks. This is termed the `shattered gradients` phenomenon.
