
反之，在*离线策略*方法中，最优策略`π`（*目标策略*）是基于由不同的*行为策略`π`′*生成的回合来学习的。通常，目标策略是确定性的，而行为策略是随机的（例如，ε-贪婪策略）。因此，行为策略可以探索环境，但学到的目标策略仍然保持高效。一些离线策略方法显式地使用重要性采样（第17.8.1节），利用来自`π`′的样本来估计策略`π`下的动作价值。另一些方法，如Q学习（下一节描述），则基于贪婪动作来估计价值，即使这不一定是实际选择的动作。

## 19.4 拟合Q学习

上述表格型蒙特卡洛和TD算法反复遍历整个MDP并更新动作价值。然而，这仅在状态-动作空间较小时才切合实际。不幸的是，这种情况很少见；即使是在国际象棋棋盘这种受限环境中，可能的合法状态也超过`10^(40)`个。

### 19.4.1 用于玩ATARI游戏的深度Q网络

深度网络非常适合从高维状态空间进行预测，因此它们是拟合Q学习中模型的自然选择。原则上，它们可以同时接收状态和动作作为输入并预测价值，但在实践中，网络仅接收状态，并同时预测每个动作的价值。

**深度Q网络**是一种突破性的强化学习架构，它利用深度网络学习玩ATARI 2600游戏。观测数据包含每个像素有128种可能颜色的`220×160`图像（[图19.13](#c019.xhtml#c19-fig-0013)）。这被重塑为`84×84`的大小，并仅保留亮度值。不幸的是，单帧无法完全观测完整状态。例如，游戏物体的速度未知。为帮助解决此问题，网络在每个时间步摄取最后四帧以形成`s[t]`。它将这些帧通过三个卷积层和一个全连接层映射，以预测该状态下每个动作的价值（[图19.14](#c019.xhtml#c19-fig-0014)）。

![Figure 19.13 Atari Benchmark. Consequently, it is usual to use several adjacent frames (here, four) to represent the state. e) The action simulates the user input via a joystick. f) There are eighteen actions corresponding to eight directions of movement or no movement, and for each of these nine cases, the button being pressed or not.](images/c19-fig-0013.jpg)
