## 12.5 用于自然语言处理的 Transformers

上一节描述了 transformer。本节描述它如何用于自然语言处理（NLP）任务。典型的 NLP 流程始于一个 `tokenizer`，它将文本分割成单词或词片段。然后将这些 token 映射到学习到的嵌入中。这些嵌入被传递通过一系列 transformer。我们现在依次考虑这些阶段中的每一个。

### 12.5.1 分词

文本处理流程始于一个 `tokenizer`。它将文本分割成来自可能 token `vocabulary`（词表）的较小组成单元（token）。在上述讨论中，我们暗示这些 token 代表单词，但存在几个困难。

*   不可避免地，一些单词（例如名字）将不在词表中。
*   如何处理标点符号尚不清楚，但这很重要。如果一个句子以问号结尾，我们必须编码此信息。
*   词表将需要针对具有不同后缀的同一单词版本使用不同的 token（例如 walk, walks, walked, walking），并且无法阐明这些变体是相关的。

一种方法是使用字母和标点符号作为词表，但这意味着将文本分割成非常小的部分，并要求后续网络重新学习它们之间的关系。

在实践中，使用字母和完整单词之间的折衷方案，最终词表包含常用单词和词片段，较大且不常用的单词可以由这些片段组成。词表是使用 `sub-word tokenizer`（子词分词器）计算的，例如 `byte pair encoding`（字节对编码，[图 12.8](#c012.xhtml#c12-fig-0008)），它根据频率贪婪地合并常见的子字符串。

### 12.5.2 嵌入

词表 `𝒱` 中的每个 token 都被映射到一个唯一的 `word embedding`（词嵌入），整个词表的嵌入存储在矩阵 `Ω[e] ∈ ℝ^(D×|𝒱|)` 中。为此，`N` 个输入 token 首先被编码在矩阵 `T ∈ ℝ^(|𝒱|×N)` 中，其中第 `n^(th)` 列对应第 `n^(th)` 个 token，是一个 `|𝒱| × 1` 的 `one-hot vector`（独热向量，即除对应 token 的条目设为 1 外，所有条目均为 0 的向量）。输入嵌入计算为 `X = Ω[e]T`，`Ω[e]` 像其他网络参数一样被学习（[图 12.9](#c012.xhtml#c12-fig-0009)）。典型的嵌入大小 `D` 为 1024，典型的总词表大小 `|𝒱|` 为 30,000，因此即使在主网络之前，`Ω[e]` 中也有许多参数需要学习。
