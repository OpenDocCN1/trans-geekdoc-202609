函数 `f[•, ϕ]` 可以是固定的可逆非线性函数，如 Leaky ReLU（图 3.13），这种情况下没有参数；也可以是任意参数化的可逆一对一映射。一个简单的例子是具有 `K` 个区域的分段线性函数（[图 16.5](#c016.xhtml#c16-fig-0005)），它将 `[0, 1]` 映射到 `[0, 1]`，如下所示：

 (16.12)

其中参数 `ϕ[1], ϕ[2], …, ϕ[K]` 为正且和为 `K`，`b = ⌊K[h]⌋` 是包含 `h` 的箱子的索引。第一项是所有前面箱子的和，第二项表示 `h` 穿过当前箱子的比例。该函数易于求逆，且其梯度几乎处处可计算。存在许多创建平滑函数的类似方案，通常使用样条，其参数确保函数单调，因此可逆。

[图 16.5](#c016.xhtml#c16-fig-0005a) 分段线性映射。通过将输入域 `h ∈ [0, 1]` 划分为 `K` 个等大小的区域（此处 `K = 5`），可以创建一个可逆的分段线性映射 `h′ = f[h, ϕ]`。每个区域有一个带参数 `ϕ[k]` 的斜率。a) 如果这些参数为正且和为 1，则 b) 该函数将是可逆的，并映射到输出域 `h′ ∈ [0, 1]`。

逐元素流是非线性的，但不混合输入维度，因此无法在变量间创建相关性。当与线性流（混合维度）交替使用时，可以建模更复杂的变换。然而在实践中，逐元素流被用作更复杂层（如*耦合流*）的组件。

[图 16.6](#c016.xhtml#c16-fig-0006a) 耦合流。a) 输入（橙色向量）被分为 `h[1]` 和 `h[2]`。输出（青色向量）的第一部分 `h'[1] = h[1]` 是 `h[1]` 的副本。输出 `h'[2]` 是通过将可逆变换 `g[, ϕ]` 应用于 `h[2]` 来创建的，其中参数 `ϕ` 本身是 `h[1]` 的（不一定可逆的）函数。b) 在逆映射中，`h[1] = h'[1]`。这使我们能够计算参数 `ϕ[h[1]]`，然后应用逆变换 `g⁻¹[h'[2], ϕ]` 来恢复 `h[2]`。

如果函数 `g[•, ϕ]` 是逐元素流，雅可比矩阵将是对角矩阵，其左上象限为单位矩阵，右下象限为逐元素变换的导数。其行列式是这些对角值的乘积。

逆变换和雅可比矩阵可以高效计算，但这种方法仅以依赖于前半部分的方式变换后半部分参数。为了实现更通用的变换，使用排列矩阵在层之间随机打乱 `h` 的元素，使每个变量最终都由其他每个变量变换。在实践中，这些排列矩阵难以学习。因此，它们被随机初始化后冻结。对于图像等结构化数据，通道被分成两半 `h[1]` 和 `h[2]`，并使用 1×1 卷积在层之间进行置换。
