# 第 16 章

归一化流

第 15 章介绍了生成对抗网络（GAN）。这些是生成模型，它们将潜在变量通过深度网络传递以创建新样本。GAN 的训练基于这样一个原则：生成的样本应与真实数据无法区分。然而，它们并未定义数据样本的分布。因此，评估新样本属于同一数据集的概率并不直观。

在本章中，我们将描述*归一化流*。这些模型通过使用深度网络将简单分布转换为更复杂的分布来学习概率模型。归一化流既可以从该分布中采样，也可以评估新样本的概率。然而，它们需要专门的架构：每一层都必须是*可逆的*。换句话说，它必须能够双向转换数据。

## 16.1 一维示例

归一化流是概率生成模型：它们将概率分布拟合到训练数据（图 14.2b）。考虑建模一维分布 `Pr(x)`。归一化流从潜在变量 `z` 上一个简单易处理的*基础*分布 `Pr(z)` 开始，并应用函数 `x = f[z, ϕ]`，其中参数 `ϕ` 的选择使得 `Pr(x)` 具有期望的分布（[图 16.1](#c016.xhtml#c16-fig-0001)）。生成新样本 `x*` 很容易；我们从基础密度中抽取 `z*`，并将其通过该函数，使得 `x* = f[z*, ϕ]`。

![Figure 16.1 Transforming probability distributions. a) The base density is a standard normal defined on a latent variable z. b) This variable is transformed by a function x = f[z, ϕ] to a new variable x, which c) has a new distribution. To sample from this model, we draw values z from the base density (green and brown arrows in panel (a) show two examples). We pass these through the function f[z, ϕ] as shown by dotted arrows in panel (b) to generate the values of x, which are indicated as arrows in panel (c).](images/c16-fig-0001.jpg)

[图 16.1](#c016.xhtml#c16-fig-0001a) 概率分布的转换。a) 基础密度是定义在潜在变量 `z` 上的标准正态分布。b) 该变量通过函数 `x = f[z, ϕ]` 转换为新变量 `x`，c) 后者具有新的分布。为了从该模型采样，我们从基础密度中抽取 `z` 值（面板 a 中的绿色和棕色箭头显示了两个示例）。我们将这些值通过函数 `f[z, ϕ]` 传递，如面板 b 中的虚线箭头所示，以生成 `x` 的值，这些值在面板 c 中用箭头表示。

### 16.1.1 概率测度

测量数据点 `x` 的概率更具挑战性。考虑将函数 `f[z, ϕ]` 应用于具有已知密度 `Pr(z)` 的随机变量 `z`。在函数拉伸的区域，概率密度会降低；在函数压缩的区域，概率密度会增加，以使新分布下的面积保持为 1。函数 `f[z, ϕ]` 拉伸或压缩其输入的程度取决于其梯度的大小。如果输入的微小变化导致输出的较大变化，则函数被拉伸。如果输入的微小变化导致输出的较小变化，则函数被压缩（[图 16.2](#c016.xhtml#c16-fig-0002)）。

![Figure 16.2 Transforming distributions. The base density (cyan, bottom) passes through a function (blue curve, top right) to create the model density (orange, left). Consider dividing the base density into equal intervals (gray vertical lines). The probability mass between adjacent lines must remain the same after transformation. The cyan-shaded region passes through a part of the function where the gradient is larger than one, so this region is stretched. Consequently, the height of the orange-shaded region must be lower so that it retains the same area as the cyan-shaded region. In other places (e.g., z = −2), the gradient is less than one, and the model density increases relative to the base density.](images/c16-fig-0002.jpg)

[图 16.2](#c016.xhtml#c16-fig-0002a) 分布转换。基础密度（青色，底部）通过函数（蓝色曲线，右上）生成模型密度（橙色，左侧）。考虑将基础密度划分为等距间隔（灰色垂直线）。相邻线之间的概率质量在转换后必须保持不变。青色阴影区域通过梯度大于 1 的函数部分，因此该区域被拉伸。因此，橙色阴影区域的高度必须降低，以保持与青色阴影区域相同的面积。在其他地方（例如 `z = −2`），梯度小于 1，模型密度相对于基础密度增加。

### 16.1.2 正向与逆向映射

为了从分布中抽取样本，我们需要正向映射 `x = f[z, ϕ]`，但为了计算似然，我们需要计算逆映射 `z = f⁻¹[x, ϕ]`。因此，我们需要审慎地选择 `f[z, ϕ]`，使其具有*可逆性*。

正向映射有时称为*生成方向*。基础密度通常选择为标准正态分布。因此，逆映射称为*归一化方向*，因为它将 `x` 上的复杂分布转换为 `z` 上的正态分布（[图 16.3](#c016.xhtml#c16-fig-0003)）。
