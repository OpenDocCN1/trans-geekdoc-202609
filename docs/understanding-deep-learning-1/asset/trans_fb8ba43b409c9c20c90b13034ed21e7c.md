

# 1.2.2 潜变量

部分（但并非所有）生成模型利用了这样一个观察结果：数据的维度可能比原始观测变量的数量所暗示的要低。例如，有效且有意义的英语句子数量远少于随机抽取单词所能组成的字符串数量。同理，现实世界的图像只是对每个像素随机抽取 RGB 值所能生成的图像中的一小部分。这是因为图像是由物理过程生成的（参见[图 1.9](#c001.xhtml#c1-fig-0009)）。

![Figure 1.9 Variation of the human face. The human face contains roughly 42 muscles, so it's possible to describe most of the variation in images of the same person in the same lighting with just 42 numbers. In general, datasets of images, music, and text can be described by a relatively small number of underlying variables although it is typically more difficult to tie these to particular physical mechanisms. Images from Dynamic FACES database (Holland et al., 2019).](images/c1-fig-0009.jpg)

[图 1.9](#c001.xhtml#c1-fig-0009a) 人脸的变化。人脸大约包含 42 块肌肉，因此只需 42 个数字就能描述同一人在相同光照条件下图像的大部分变化。一般来说，图像、音乐和文本数据集均可用相对较少的底层变量来描述，尽管通常很难将这些变量与特定的物理机制联系起来。图片源自 Dynamic FACES 数据库 (Holland et al., 2019)。

由此引出了这样一个概念：我们可以用较少数量的底层 `latent variables`（潜变量）来描述每个数据样本。在这里，深度学习的作用是描述这些潜变量与数据之间的映射关系。潜变量通常在设计上具有简单的概率分布。通过从该分布中采样并将结果传入深度学习模型，我们便能创建新样本（[图 1.10](#c001.xhtml#c1-fig-0010)）。

![Figure 1.10 Latent variables. Many generative models use a deep learning model to describe the relationship between a low-dimensional “latent” variable and the observed high-dimensional data. The latent variables have a simple probability distribution by design. Hence, new examples can be generated by sampling from the simple distribution over the latent variables and then using the deep learning model to map the sample to the observed data space.](images/c1-fig-0010.jpg)

[图 1.10](#c001.xhtml#c1-fig-0010a) 潜变量。许多生成模型利用深度学习模型来描述低维“潜”变量与观测到的高维数据之间的关系。潜变量在设计上具有简单的概率分布。因此，可以通过从潜变量的简单分布中采样，再利用深度学习模型将样本映射到观测数据空间，从而生成新样本。

这些模型催生了操控真实数据的新方法。例如，考虑寻找支撑两个真实样本的潜变量。我们可以通过在它们的潜在表示之间插值，并将中间位置映射回数据空间，从而在两个样本之间进行插值（[图 1.11](#c001.xhtml#c1-fig-0011)）。

![Figure 1.11 Image interpolation. In each row the left and right images are real and the three images in between represent a sequence of interpolations created by a generative model. The generative models that underpin these interpolations have learned that all images can be created by a set of underlying latent variables. By finding these variables for the two real images, interpolating their values, and then using these intermediate variables to create new images, we can generate intermediate results that are both visually plausible and mix the characteristics of the two original images. Top row adapted from Sauer et al. (2022). Bottom row adapted from Ramesh et al. (2022).](images/c1-fig-0011.jpg)

[图 1.11](#c001.xhtml#c1-fig-0011a) 图像插值。在每一行中，最左和最右的图像为真实图像，中间的三幅图像代表由生成模型创建的一系列插值结果。支撑这些插值的生成模型已经学会所有图像均可由一组底层潜变量创建。通过找到这两幅真实图像对应的潜变量，对其值进行插值，再利用这些中间变量生成新图像，我们便能得到既视觉合理又融合了原始两幅图像特征的中间结果。顶行改编自 Sauer 等人 (2022) 的成果。底行改编自 Ramesh 等人 (2022) 的成果。

### 1.2.3 连接监督学习与无监督学习

带有潜变量的生成模型还能造福输出具有结构的监督学习模型（[图 1.4](#c001.xhtml#c1-fig-0004)）。例如，考虑学习预测与标题对应的图像。我们不直接将文本输入映射到图像，而是学习解释文本的潜变量与解释图像的潜变量之间的关系。

这有三大优势。首先，由于输入和输出均变为低维，我们可能需要更少的文本/图像对来学习该映射。其次，我们更有可能生成一幅貌似合理的图像；潜变量的任何合理取值都应能生成看起来像合理样本的内容。第三，如果我们在两组潜变量之间的映射或从潜变量到图像的映射中引入随机性，便能生成多幅均能被该标题很好地描述的图像（[图 1.12](#c001.xhtml#c1-fig-0012)）。

![Figure 1.12 Multiple images generated from the caption “A teddy bear on a skateboard in Times Square.” Generated by DALL·E-2 (Ramesh et al., 2022).](images/c1-fig-0012.jpg)

# 1.3 强化学习

机器学习的最后一个领域是强化学习。该范式引入了**智能体**的概念，它生存于一个环境中，并可在每个时间步执行特定动作。动作会改变系统的状态，但不一定以确定性方式改变。执行动作还可能产生奖励，强化学习的目标是让智能体学会选择能带来平均高奖励的动作。

一个复杂因素是奖励可能在动作执行一段时间后才出现，因此将奖励与动作关联并非易事。这被称为 `temporal credit assignment problem`（时间信用分配问题）。随着智能体学习，它必须在 `exploration`（探索）和 `exploitation`（利用）已知知识之间权衡；也许智能体已学会如何获得微薄奖励；它是坚持此策略（利用已知），还是尝试不同动作以求改进（探索其他机会）？

### 1.3.1 两个例子

考虑教一个人形机器人移动。机器人在给定时刻只能执行有限数量的动作（移动各个关节），这些动作会改变世界的状态（它的姿态）。我们可能会在机器人到达障碍赛道的检查点时给予奖励。要到达每个检查点，它必须执行许多动作，而在收到奖励时，不清楚哪些动作促成了奖励，哪些无关紧要。这是时间信用分配问题的一个例子。
