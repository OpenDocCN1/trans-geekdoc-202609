### 10.4.2 缩放表示大小（上采样）

将网络层缩放至双倍分辨率的最简单方法是在每个空间位置将所有通道复制四次（[图 10.12a](#c010.xhtml#c10-fig-0012)）。第二种方法是最大反池化；这用于我们之前使用最大池化操作进行下采样的场景，它将数值分配回它们来源的位置（[图 10.12b](#c010.xhtml#c10-fig-0012)）。第三种方法使用双线性插值来填充我们有采样点之间的缺失值（[图 10.12c](#c010.xhtml#c10-fig-0012)）。

![Figure 10.12 Methods for scaling up representation size (upsampling). a) The simplest way to double the size of a 2D layer is to duplicate each input four times. b) In networks where we have previously used a max pooling operation (figure 10.11b), we can redistribute the values to the same positions they originally came from (i.e., where the maxima were). This is known as max unpooling. c) A third option is bilinear interpolation between the input values.](images/c10-fig-0012.jpg)

[图 10.12](#c010.xhtml#c10-fig-0012a) 缩放表示大小的方法（上采样）。a) 将 2D 层大小加倍的最简单方法是将每个输入复制四次。b) 在我们之前使用过最大池化操作的网络中（[图 10.11b](#c010.xhtml#c10-fig-0011)），我们可以将数值重新分配到它们最初所在的位置（即最大值所在位置）。这称为最大反池化。c) 第三种选择是输入值之间的双线性插值。

第四种方法大致类似于使用步长为二的下采样。在该方法中，输出数量是输入的一半，对于核大小为三的情况，每个输出是三个最近输入的加权和（[图 10.13a](#c010.xhtml#c10-fig-0013)）。在*转置卷积*中，这一过程被反转（[图 10.13c](#c010.xhtml#c10-fig-0013)）。输出数量是输入的两倍，每个输入贡献给三个输出。当我们考虑此上采样机制相关的权重矩阵（[图 10.13d](#c010.xhtml#c10-fig-0013)）时，会发现它是下采样机制权重矩阵的转置（[图 10.13b](#c010.xhtml#c10-fig-0013)）。

### 10.4.3 改变通道数

有时我们想在不进行进一步空间池化的情况下，改变一个隐藏层与下一个隐藏层之间的通道数。这通常是为了将表示与另一个并行计算相结合（见第 11 章）。为此，我们应用核大小为一的卷积。输出层的每个元素通过在同一位置对所有通道进行加权和来计算（[图 10.14](#c010.xhtml#c10-fig-0014)）。我们可以使用不同的权重重复此操作多次，以生成所需数量的输出通道。相关的卷积权重大小为 `1 × 1 × C[i] × C[∘]`。因此，这被称为*`1×1`卷积*。结合偏置和激活函数，它等同于在每个位置的通道上运行相同的全连接网络。

![Figure 10.14 1×1 convolution. To change the number of channels without spatial pooling, we apply a 1×1 kernel. Each output channel is computed by taking a weighted sum of all of the channels at the same position, adding a bias, and passing through an activation function. Multiple output channels are created by repeating this operation with different weights and biases.](images/c10-fig-0014.jpg)

[图 10.14](#c010.xhtml#c10-fig-0014a) `1×1`卷积。为了在不进行空间池化的情况下改变通道数，我们应用 `1×1` 核。每个输出通道通过在同一位置对所有通道进行加权和、加上偏置并通过激活函数来计算。通过使用不同的权重和偏置重复此操作来创建多个输出通道。

## 10.5 应用

我们通过描述三个计算机视觉应用来结束本章。我们描述用于图像分类的卷积网络，其目标是将图像分配到一组预定类别之一。然后我们考虑目标检测，其目标是识别图像中的多个对象并找到每个对象周围的边界框。最后，我们描述一个早期的语义分割系统，其目标是根据存在哪个对象，为每个像素分配一个标签。

### 10.5.1 图像分类

计算机视觉深度学习的大量开创性工作集中在使用 ImageNet 数据集进行图像分类（[图 10.15](#c010.xhtml#c10-fig-0015)）。该数据集包含 1,281,167 张训练图像、50,000 张验证图像和 100,000 张测试图像，每张图像都被标记为属于 1000 个可能类别之一。

![Figure 10.15 Example ImageNet classification images. The model aims to assign an input image to one of 1000 classes. This task is challenging because the images vary widely along different attributes (columns). These include rigidity (monkey < canoe), number of instances in image (lizard < strawberry), clutter (compass < steel drum), size (candle < spiderweb), texture (screwdriver < leopard), distinctiveness of color (mug < red wine), and distinctiveness of shape (headland < bell). Adapted from Russakovsky et al. (2015).](images/c10-fig-0015.jpg)

[图 10.15](#c010.xhtml#c10-fig-0015a) ImageNet 分类图像示例。模型旨在将输入图像分配到 1000 个类别之一。这项任务具有挑战性，因为图像在不同属性（列）上变化很大。这些属性包括刚性（猴子 `<` 独木舟）、图像中的实例数量（蜥蜴 `<` 草莓）、杂乱度（指南针 `<` 钢鼓）、大小（蜡烛 `<` 蜘蛛网）、纹理（螺丝刀 `<` 豹子）、颜色独特性（马克杯 `<` 红酒）和形状独特性（海角 `<` 钟）。改编自 Russakovsky 等人 (2015)。

大多数方法将输入图像重塑为标准尺寸；在典型系统中，网络的输入 **x** 是一个 `224×224` 的 RGB 图像，输出是 1000 个类别上的概率分布。该任务具有挑战性；类别数量大，且表现出相当大的变化（[图 10.15](#c010.xhtml#c10-fig-0015)）。2011 年，在深度网络被应用之前，最先进的方法在测试图像上的分类错误率约为 25%（正确类别在前五个建议中）。五年后，最好的深度学习模型超越了人类表现。
