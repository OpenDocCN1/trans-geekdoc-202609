

损失函数的导数告诉我们，当我们对参数进行微小改动时，损失会如何变化。优化算法利用这些信息来操控参数，使损失变小。`backpropagation algorithm`（反向传播算法）用于计算这些导数。数学细节稍显复杂，因此我们首先提出两个观察结果，以提供一些直观理解。

**观察 1：** 每个权重（`Ω[k]` 的元素）将源隐藏单元的激活值相乘，并将结果加到下一层的目标隐藏单元上。由此可见，对权重进行的任何微小改动，其效应都会被源隐藏单元的激活值放大或衰减。因此，我们针对批次中的每个数据样本运行网络，并存储所有隐藏单元的激活值。这被称为 `forward pass`（前向传播）（[图 7.1](#c007.xhtml#c7-fig-0001)）。存储的激活值随后将用于计算梯度。

**观察 2：** 偏置或权重的微小改动会导致后续网络中产生连锁反应式的变化。该改动会修改其目标隐藏单元的值。这进而会改变后续层中隐藏单元的值，进而改变再下一层隐藏单元的值，以此类推，直到模型输出发生变化，最终导致损失发生变化。

因此，要了解改变参数如何修改损失，我们还需要知道后续每个隐藏层的变化如何反过来修改其后继层。在考虑同一层或更早层中的其他参数时，也需要这些相同的量。由此可见，我们可以计算一次并重复使用它们。例如，考虑计算分别馈入隐藏层 `h[3]`、`h[2]` 和 `h[1]` 的权重发生微小变化时的效应：

*   要计算馈入隐藏层 `h[3]` 的权重或偏置发生微小变化如何修改损失，我们需要知道（i）`h[3]` 层的变化如何改变模型输出 `f`，以及（ii）该输出的变化如何改变损失 `ℓ`（[图 7.2a](#c007.xhtml#c7-fig-0002)）。
*   要计算馈入隐藏层 `h[2]` 的权重或偏置发生微小变化如何修改损失，我们需要知道（i）`h[2]` 层的变化如何影响 `h[3]`，（ii）`h[3]` 如何改变模型输出，以及（iii）该输出如何改变损失（[图 7.2b](#c007.xhtml#c7-fig-0002)）。
*   要计算馈入隐藏层 `h[1]` 的权重或偏置发生微小变化如何修改损失，我们需要知道（i）`h[1]` 层的变化如何影响 `h[2]` 层，（ii）`h[2]` 层的变化如何影响 `h[3]` 层，（iii）`h[3]` 层如何改变模型输出，以及（iv）模型输出如何改变损失（[图 7.2c](#c007.xhtml#c7-fig-0002)）。

![Figure 7.2 Backpropagation backward pass. a) To compute how a change to a weight feeding into layer h3 (blue arrow) changes the loss, we need to know how the hidden unit in h3 changes the model output f and how f changes the loss (orange arrows). b) To compute how a small change to a weight feeding into h2 (blue arrow) changes the loss, we need to know (i) how the hidden unit in h2 changes h3, (ii) how h3 changes f, and (iii) how f changes the loss (orange arrows). c) Similarly, to compute how a small change to a weight feeding into h1 (blue arrow) changes the loss, we need to know how h1 changes h2 and how these changes propagate through to the loss (orange arrows). [图 7.2](#c007.xhtml#c7-fig-0002a) 反向传播的后向传递。a) 要计算馈入 `h[3]` 层的权重变化（蓝色箭头）如何改变损失，我们需要知道 `h[3]` 中的隐藏单元如何改变模型输出 `f`，以及 `f` 如何改变损失（橙色箭头）。b) 要计算馈入 `h[2]` 的权重发生微小变化（蓝色箭头）如何改变损失，我们需要知道（i）`h[2]` 中的隐藏单元如何改变 `h[3]`，（ii）`h[3]` 如何改变 `f`，以及（iii）`f` 如何改变损失（橙色箭头）。c) 类似地，要计算馈入 `h[1]` 的权重发生微小变化（蓝色箭头）如何改变损失，我们需要知道 `h[1]` 如何改变 `h[2]`，以及这些变化如何传播至损失（橙色箭头）。后向传递首先计算网络末端的导数，然后向后工作，以利用这些计算中固有的冗余性。

随着我们在网络中向后移动，我们发现所需的大多数项已经在上一步中计算过了，因此无需重新计算。以这种方式向后遍历网络以计算导数的过程被称为 `backward pass`（后向传递）。

反向传播背后的思想相对容易理解。然而，推导过程需要矩阵微积分，因为偏置和权重项分别是向量和矩阵。为了帮助掌握底层机制，下一节将推导一个具有标量参数的更简单的玩具模型的反向传播。然后我们将在第 7.4 节中将相同的方法应用于深度神经网络。
