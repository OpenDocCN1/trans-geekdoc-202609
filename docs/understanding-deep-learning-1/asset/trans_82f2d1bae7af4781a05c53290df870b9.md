

## AlexNet (2012)

2012年，`AlexNet`成为第一个在此任务上表现良好的卷积网络。它由八个隐藏层组成，使用`ReLU`激活函数，其中前五层为卷积层，其余为全连接层（**图 10.16**）。网络首先使用步长为4的`11×11`卷积核对输入进行下采样，创建96个通道。随后通过最大池化层再次下采样，然后应用`5×5`卷积核创建256个通道。还有三个卷积核大小为`3×3`的卷积层，最终形成一个具有256个通道的`13×13`表示。该表示被重塑为长度为43,264的单个向量，然后通过三个全连接层，分别包含4096、4096和1000个隐藏单元。最后一层通过`softmax`函数输出1000个类别的概率分布。完整网络包含约6000万个参数。其中大部分位于网络末端的全连接层中。

***

### 图 10.16：AlexNet架构

![Figure 10.16 AlexNet (Krizhevsky et al., 2012). The network maps a 224×224 color image to a 1000-dimensional vector representing class probabilities. The network first convolves with 11×11 kernels and stride 4 to create 96 channels. It decreases the resolution again using a max pool operation and applies a 5×5 convolutional layer. Another max pooling layer follows, and three 3×3 convolutional layers are applied. After a final max pooling operation, the result is vectorized and passed through three fully connected (FC) layers and finally the softmax layer.](images/c10-fig-0016.jpg)

**图 10.16** AlexNet (Krizhevsky et al., 2012)。网络将`224×224`彩色图像映射为代表类别概率的1000维向量。网络首先使用步长为4的`11×11`卷积核进行卷积以创建96个通道。它再次使用最大池化操作降低分辨率，并应用`5×5`卷积层。随后是另一个最大池化层，并应用三个`3×3`卷积层。经过最后一个最大池化操作后，结果被向量化并通过三个全连接（FC）层，最后通过softmax层。

数据集大小通过(i)空间变换和(ii)输入强度修改扩充了2048倍。测试时，图像的五个不同裁剪和镜像版本被送入网络，并对它们的预测进行平均。系统使用动量系数为0.9、批量大小为128的`SGD`进行训练。`Dropout`应用于全连接层，并使用了`L2`（权重衰减）正则化项。该系统实现了16.4%的top-5错误率和38.1%的top-1错误率。当时，这在被认为远超当代方法能力的任务上实现了巨大的性能飞跃。这一结果揭示了深度学习的潜力，并开启了现代AI研究的新纪元。

## VGG网络

`VGG网络`同样针对ImageNet分类任务，实现了相当更好的性能：6.8%的top-5错误率和23.7%的top-1错误率。该网络同样由一系列交织的卷积层和最大池化层组成，表示的空间尺寸逐渐减小，但通道数增加。随后是三个全连接层（**图 10.17**）。VGG网络同样使用数据增强、权重衰减和dropout进行训练。

***

### 图 10.17：VGG网络架构

![Figure 10.17 VGG network (Simonyan & Zisserman, 2014) depicted at the same scale as AlexNet (see Figure 10.16). This network consists of a series of convolutional layers and max pooling operations, in which the spatial scale of the representation gradually decreases, but the number of channels gradually increases. The hidden layer after the last convolutional operation is resized to a 1D vector and three fully connected layers follow. The network outputs 1000 activations corresponding to the class labels that are passed through a softmax function to create class probabilities.](images/c10-fig-0017.jpg)

**图 10.17** VGG网络 (Simonyan & Zisserman, 2014) 与AlexNet按相同比例绘制（见**图 10.16**）。该网络由一系列卷积层和最大池化操作组成，表示的空间尺度逐渐减小，但通道数逐渐增加。最后一个卷积操作后的隐藏层被重塑为1D向量，随后是三个全连接层。网络输出1000个激活值，对应通过`softmax`函数生成类别概率的类别标签。

尽管训练制度存在各种细微差别，但AlexNet和VGG之间最重要的变化是网络深度。后者使用了19个隐藏层和1.44亿个参数。**图 10.16和图 10.17**按相同比例绘制以供比较。在数年间，随着网络深度增加，该任务性能普遍呈改善趋势，这证明了深度在神经网络中的重要性。

## 10.5.2 目标检测

在`目标检测`中，目标是识别并定位图像中的多个物体。基于卷积网络的早期方法是`You Only Look Once`，简称`YOLO`。YOLO网络的输入是一个`448×448`的RGB图像。它通过24个卷积层，利用最大池化操作逐渐减小表示尺寸，同时增加通道数，这与VGG网络类似。最后一个卷积层大小为`7×7`，拥有1024个通道。这被重塑为向量，一个全连接层将其映射为4096个值。另一个全连接层将此表示映射到输出。

输出值编码了`7×7`网格中每个位置存在的类别（**图 10.18a–b**）。对于每个位置，输出值还编码固定数量的边界框。五个参数定义每个框：中心点的x和y坐标、框的高度和宽度以及预测的置信度（**图 10.18c**）。置信度估计预测边界框与真实边界框的重叠程度。系统使用动量、权重衰减、dropout和数据增强进行训练。采用了迁移学习；网络最初在ImageNet分类任务上训练，然后针对目标检测进行微调。

***
