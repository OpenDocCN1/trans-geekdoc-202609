

## 6.1.1 线性回归示例

给定一个包含 `I` 个输入/输出对的数据集 {`x[i]`, `y[i]`}，我们选择最小二乘损失函数：

```
L[ϕ] = (1/I) Σ[i=1 to I] ℓ[i]
```
 (6.5)

其中项 `ℓ[i] = (ϕ[0] + ϕ[1]x[i] − y[i])²` 是第 `i^(th)` 个训练样本对损失的单独贡献。

损失函数关于参数的导数可以分解为各个贡献导数的和：

```
∂L[ϕ]/∂ϕ = (1/I) Σ[i=1 to I] ∂ℓ[i]/∂ϕ
```
 (6.6)

其中这些导数由下式给出：

```
∂ℓ[i]/∂ϕ[0] = 2(ϕ[0] + ϕ[1]x[i] − y[i])
∂ℓ[i]/∂ϕ[1] = 2(ϕ[0] + ϕ[1]x[i] − y[i])x[i]
```
 (6.7)

## 6.1.2 Gabor 模型示例

线性回归问题的损失函数（[图 6.1c](#c006.xhtml#c6-fig-0001)）总是有一个定义明确的单一全局最小值。更正式地说，它们是*凸*的，这意味着没有任何弦（曲面上两点之间的线段）与函数相交。凸性意味着无论我们在哪里初始化参数，只要我们持续向下走，就注定会到达最小值；训练过程不会失败。

---

**问题 6.2**

---

不幸的是，大多数非线性模型的损失函数（包括浅层和深层网络）都是*非凸*的。由于参数数量众多，可视化神经网络损失函数具有挑战性。因此，我们首先探索一个具有两个参数的更简单的非线性模型，以深入了解非凸损失函数的特性：

```
y = exp(−ϕ[1](x − ϕ[0])²) sin(x)
```
 (6.8)

这个* Gabor 模型*将标量输入 `x` 映射到标量输出 `y`，由一个正弦分量（产生振荡函数）乘以一个负指数分量（导致振幅随远离中心而减小）组成。它有两个参数 `ϕ = [ϕ[0], ϕ[1]]^T`，其中 `ϕ[0] ∈ ℝ` 决定函数的平均位置，`ϕ[1] ∈ ℝ^+` 沿 `x` 轴拉伸或挤压函数（[图 6.2](#c006.xhtml#c6-fig-0002)）。
