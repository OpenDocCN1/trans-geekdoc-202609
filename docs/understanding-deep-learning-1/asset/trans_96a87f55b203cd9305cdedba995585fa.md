# 第 7 章

梯度与初始化

第 6 章介绍了迭代优化算法。这些是寻找函数最小值的通用方法。在神经网络的背景下，它们寻找使损失最小化的参数，以便模型能准确地从输入预测训练输出。基本方法是随机选择初始参数，然后进行一系列平均减小损失的小幅更改。每次更改都基于当前位置处损失关于参数的梯度。

本章讨论两个神经网络特有的问题。首先，我们考虑如何高效计算梯度。这是一个严峻的挑战，因为在撰写本文时，最大的模型拥有 ~10^12 个参数，并且需要在训练算法的每次迭代中为每个参数计算梯度。其次，我们考虑如何初始化参数。如果不小心处理，初始损失及其梯度可能会变得极大或极小。无论哪种情况，都会阻碍训练过程。
