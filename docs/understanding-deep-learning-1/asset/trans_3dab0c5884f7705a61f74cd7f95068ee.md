

# SGD 特性

SGD 具有多个吸引人的特性。首先，尽管它给轨迹增加了噪声，但它仍然在每次迭代中提高了对数据子集的拟合程度。因此，即使更新不是最优的，它们也往往是合理的。其次，因为它不放回地抽取训练样本并遍历数据集，所有训练样本仍然做出同等贡献。第三，仅从训练数据的一个子集计算梯度的计算开销更小。第四，它（原则上）可以逃离局部极小值。第五，它降低了陷入鞍点附近的可能性；在损失函数的任意一点，至少某些可能的批次很可能具有显著梯度。最后，有一些证据表明，SGD 在实践中找到的神经网络参数使其能很好地泛化到新数据（见第 9.2 节）。

## 收敛与学习率调度

SGD 不一定按传统意义上“收敛”。然而，我们期望当接近全局极小值时，所有数据点都能被模型很好地描述。因此，无论选择哪个批次，梯度都会很小，参数也就不再发生太大变化。在实践中，SGD 通常配合*学习率调度*使用。学习率 `α` 从一个较高值开始，每 `N` 个周期按一个常数因子衰减。其逻辑是：在训练早期，我们希望算法探索参数空间，在山谷间跳跃以找到一个合理的区域。在后期，我们大致处于正确位置，更关注微调参数，因此减小 `α` 以进行更小幅度的改动。

动量计算的递归公式意味着梯度步长是所有先前梯度的无限加权和，权重随时间倒退而变小。如果这些梯度在多次迭代中方向一致，有效学习率会增加；如果梯度方向反复变化，求和项相互抵消，有效学习率则会降低。整体效果是轨迹更平滑，并在山谷中减少了振荡行为（[图 6.7](#c006.xhtml#c6-fig-0007)）。

## 6.4 Adam

固定步长的梯度下降具有以下不良特性：它对关联大梯度的参数做大幅调整（此时或许应更谨慎），对关联小梯度的参数做小幅调整（此时或许应探索更远）。当损失曲面在某个方向上比另一个方向陡峭得多时，很难选择一个学习率既能（i）在两个方向上都取得良好进展，又能（ii）保持稳定（[图 6.9a–b](#c006.xhtml#c6-fig-0009)）。

![Figure 6.9 Adaptive moment estimation (Adam). a) This loss function changes quickly in the vertical direction but slowly in the horizontal direction. If we run full-batch gradient descent with a learning rate that makes good progress in the vertical direction, then the algorithm takes a long time to reach the final horizontal position. b) If the learning rate is chosen so that the algorithm makes good progress in the horizontal direction, it overshoots in the vertical direction and becomes unstable. c) A straightforward approach is to move a fixed distance along each axis at each step so that we move downhill in both directions. This is accomplished by normalizing the gradient magnitude and retaining only the sign. However, this does not usually converge to the exact minimum but instead oscillates back and forth around it (here between the last two points). d) The Adam algorithm uses momentum in both the estimated gradient and the normalization term, which creates a smoother path.](images/c6-fig-0009.jpg)

[图 6.9](#c006.xhtml#c6-fig-0009a) 自适应矩估计。a) 该损失函数在垂直方向变化快，在水平方向变化慢。若用在垂直方向取得良好进展的学习率运行全批次梯度下降，算法需很长时间才能到达最终水平位置。b) 若学习率选为在水平方向取得良好进展，则在垂直方向会超调并变得不稳定。c) 一种直接的方法是每步沿每个轴移动固定距离，使两个方向都向下移动。这通过归一化梯度幅度并仅保留符号来实现。然而，这通常不收敛于精确极小值，而是在其周围来回振荡（此处在最后两点之间）。d) Adam 算法在估计梯度和归一化项中均使用动量，从而产生更平滑的路径。
