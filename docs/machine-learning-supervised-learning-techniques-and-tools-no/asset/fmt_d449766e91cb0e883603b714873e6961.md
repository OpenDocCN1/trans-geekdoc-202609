## 6.11.1 neuralnet library
![image](d2d_images/chapter_title_below.png)

The `neuralnet` command of the `neuralnet` library has the following simplified syntax:

```
neuralnet(formula, data=dataset, hidden = c(m,n),...)
```

The vector `c(m,n)` specifies the number of hidden neurons in each layer.

As an example, we are going to calculate the probabilities that applicants for bank loans have of successfully repaying the loan. To do this, we use a file named `credits.sav` that contains a dichotomous variable `credit_v` that collects the success or failure in the repayment of a credit in the history of clients (1=successful repayment, 0=failure to repay or non-repayment). This variable will be the dependent variable of the network model. As independent variables, the customer's professional category, monthly salary, age and whether or not the customer has an American Express card will be used.

We start by loading the file, separating its variables and obtaining basic statistics on them.
