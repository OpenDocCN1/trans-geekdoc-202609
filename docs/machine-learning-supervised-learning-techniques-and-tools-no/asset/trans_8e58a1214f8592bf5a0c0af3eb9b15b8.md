我们将首先对1975年753名已婚女性的数据（文件 `married.wf1`）拟合一个线性概率模型，其中428人在当年某个时间参与了劳动力市场（`inlf`=1），325人未参与（`inlf`=0）。

参与劳动力市场（`inlf`）的概率被认为取决于其他收入来源（`nwifeinc`）、受教育年限（`educ`）、工作经验年限（`exper` 和 `exper²`）、年龄、6岁以下子女数量（`kidslt6`）以及6至18岁子女数量（`kidsg6`）。

使用线性概率模型，我们将分析女性劳动力市场参与概率对上述解释变量的依赖关系。

### 线性概率模型

我们将考虑以下线性概率模型（LPM）：

![image](d2d_images/image158.png)

我们将首先使用OLS估计MLP。为此，选择 `Quick→ Estimate Equation`，在Specification选项卡的Equation Specification字段中写入拟合模型的方程，在Method字段中选择 `LS-Least Squares (NLS and ARMA)` 以进行普通最小二乘拟合（图4-1），然后单击OK。图4-2的结果显示估计参数具有良好的个体和联合显著性（也许除了 `kidsge6`）。`R²` 和Durbin Watson统计量不是很好，但我们必须考虑到我们正在估计一个线性概率模型。

除 `kidsge6` 外，所有变量在统计上均显著且符号符合预期。联合显著性也很强。对系数的解释表明，如果教育增加一年（其他变量保持不变），女性参与劳动力市场的概率将增加0.038。其他收入来源（`nwifeinc`）的影响显著，但非常小，因为如果其他收入增加一个单位，在其他因素保持不变的情况下，女性参与劳动力市场的概率将下降0.0034。

在其他因素固定的情况下，工作经验变化一年时，女性劳动力市场参与概率的估计变化为 `0.039-2(0.0006)exper`。经验不影响参与概率的点（斜率改变符号的点）为 `0.039/0.0012=32.5`（只有13名女性的 `exper>32`）。随着年龄增加一年（其他条件不变），女性参与劳动力市场的概率下降0.016。在其他变量水平给定的情况下，多一个6岁以下的孩子会使女性参与劳动力市场的概率降低0.262。在其他变量水平固定的情况下，有一个6至18岁的孩子会使女性劳动力市场参与概率增加0.013。

### Probit模型

我们首先考虑Probit模型：

![image](d2d_images/image001.png)

其中 `Ф` 是正态（0,1）的分布函数。

我们将首先使用Probit模型进行估计。为此，选择 `Quick→ Estimate Equation`，在Specification选项卡的Equation Specification字段中输入拟合模型的方程，在Method字段中选择 `BINARY-Binary choice (logit, probit, extreme value)`，在Binary estimation method字段中选择 `Probit` 以拟合Probit模型（图4-11），然后单击OK。

图4-12的结果显示估计参数具有良好的个体显著性（常数和 `kidsge6` 除外）。联合显著性非常高，因为似然比统计量的p值非常小。McFadden的伪 `R²` 不太接近1（0.22）。信息准则（Akaike、Schwarz和Hannan-Quinn）的值是合适的，因为它们很低且非常接近。

![image](d2d_images/image624.png)![image](d2d_images/image223.png)
