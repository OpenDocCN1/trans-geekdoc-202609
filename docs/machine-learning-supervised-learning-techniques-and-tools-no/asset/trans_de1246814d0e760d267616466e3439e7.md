![image](d2d_images/chapter_title_below.png)

要使用神经网络，可以使用 `nnet` 库中的 `nnet` 函数。其简化语法如下：

```
nnet(formula, data, weights, size=n ...,)
```

参数 `size=n` 表示隐藏层中节点的数量。
