
## Unsupervised Learning Neural Networks

Unsupervised learning neural networks are those that train without the need for an external supervisor or trainer to provide the network with the desired output, as they are able to organise their parameters internally by adapting to the environment in the best possible way. The network, once presented with the inputs, is able to determine, on its own, the characteristics, correlations, regularities or categories of the inputs, providing a coded output. Therefore, we can say that these networks have self-organising properties.

This type of learning should only be used when there is some degree of redundancy in the input patterns presented to the network. Otherwise, the network is unable to detect the behavioural patterns and characteristics of the data offered to it.

The structure of the network must be appropriate for the type of input data presented to it, because depending on the architecture of the unsupervised learning neural network, it will be able to detect one type of pattern or another.

Neural systems with unsupervised learning are characterised by simple architectures, since the learning laws already complicate their operation quite a lot. Secondly, most of them are feed-forward networks, or feed-forward networks with a single intermediate or hidden layer.

The most typical models that train by unsupervised learning are the networks of `Kohonen` (1977,1984) and `Grossberg` (1976).

Unsupervised networks are often used for classification. In particular, `Cohonen` networks are often used when one of the objectives of the analysis is the simple and intuitive visualisation of clusters, when the shape of the clusters is unknown, or when there are outliers or errors in the data.

## Supervised Learning Neural Networks

Neural networks with supervised learning, which are usually associated with the multilayer perceptron (`Multilayer Perceptron MLP`) and the radial basis function `RBF`, have an output pattern or dependent variable that allows them to contrast and correct the data.

Neural networks with an output pattern are a technique used for classification and prediction, which can be used to segment markets, position products, make demand forecasts, evaluate credit files or analyse the value of shares on the stock exchange, and a host of other applications.

The multilayer perceptron neural network model is based on back-propagation learning and typically uses the `back-propagation algorithm`, the `conjugate gradient descent algorithm` and the `Levenberg-Marquardt algorithm`.

Just as in the multilayer percetron all layers have the same (linear) structure, in the radial basis function (`RBF`), the intermediate layer has precisely a radial structure.

The radial basis function is a supervised function with output pattern that performs classifications (and or forecasts) from ellipses and hyperellipses that split the input data space.

The radial basis function has certain advantages over multi-layer neural networks including the fact that it can be modelled using only one intermediate layer instead of several and that its algorithm is faster and never settles on a local solution.

It should be noted that, sometimes, although supervised learning can be applied, unsupervised learning methods can be very useful and even provide better results.

For example, the `Back-Propagation Algorithm` in multi-layer networks is very slow, because the value that each weight adopts depends on the values it takes in the other layers. To avoid this problem, either an unsupervised learning method or a hybrid system could be used, which allows some layers to self-organise before their outputs are passed to the supervised network.

On the other hand, it should be noted that it may be advisable to perform some kind of unsupervised training to networks previously trained by supervised learning mechanisms. The purpose of this approach is to allow the network to gradually adapt to possible changes in the environment.

## Reinforced or Hybrid Learning

Reinforced or hybrid learning is intermediate between supervised and unsupervised learning. In this type of learning, as in supervised learning, there is an external teacher or supervisor. However, they differ in that the "trainer" does not provide the network with the desired outputs, as its behaviour is evaluated globally, i.e. it is only possible to decide and indicate to the network whether its response is good or bad and to what degree it behaves well.

The rationale of reinforcement learning is that actions that lead to an improvement in the behaviour and response of the neural network should be reinforced.

Analogous to supervised learning, the neural network responds by generating a set of outputs, corresponding to the input patterns presented to it. However, since no desired outputs are provided to the system, it is impossible to compute the fraction of error made by each of the output units. Only an indicator of the success or failure of the network is available, similar to a utility function, which evaluates the network as a whole. This requires the use of much more complex learning algorithms than in supervised learning, as well as higher demands on sample size.

Formally, the learning process consists of solving a non-linear least squares problem. To do this, numerical optimisation methods such as `back-propagation`, which is based on the stochastic approximation algorithm of `Robbins and Monro` (1951) applied to non-linear least squares, must be used. It is currently the most widely used algorithm.

Once learning has been completed, the network must be tested. The test phase consists of introducing new input patterns and checking the efficiency of the generated system. If it is not acceptable, the training phase is repeated using new example-patterns, and it may even be necessary to modify the structure of the network.

### 6.4 FUNCTIONING OF A NEURAL NETWORK

For the creation and application of a neural network to a specific problem, we have to distinguish the following steps:

**Conceptualisation of the model for the study of the specific problem.** In this Model we must point out the inputs, the outputs and the information available.

**Adaptation of the available information to the structure of the network to be created.** In other words, the learning patterns, part of the information that will be used for training or learning the network, and the validation patterns, part of the information that will be used to validate the network, will be created.

**Learning phase.** The network is presented with suitable patterns and the network provides an output, this process is repeated in a number of stages, these outputs are compared with the expected outputs and the various learning algorithms attempt to minimise the error between the output provided by the network and the expected output.

**Validation phase.** The trained network is presented with the set of validation patterns, and the error made by the network on this set is seen, this error is a measure of the goodness of the network.

**Generalisation phase.** If we have obtained a suitable network, we proceed to use the network as a predictor model, providing it with a new input, the network will process it and give an output.

As an illustrative example, we consider a bank that wants to build a model for granting personal loans for the purchase of a car. The information set is made up of a file of 5,000 previous clients in which the following variables are recorded for each client: `sex`, `marital status`, `salary`, `assets`, `current account`, etc., and whether or not the client has made regular payments.

The model would therefore have an input layer with as many nodes as there are variables in the file, one or several intermediate layers and an output layer with one node, in which there is an expected output of zero or one depending on whether or not the customer has paid regularly.
