

这个问题通常通过决定使用“扩展”面板而不是更常见的纯面板的想法来缓解。做出这一决定的原因是，后者由于受到随时间推移的流入和流出流动的影响，不能构成其来源总体的忠实横截面代表，在个人所得税面板或任何其他税的情况下，这种流动将分别表现为新纳税人以及每年不再成为纳税人的那些人。从统计上讲，这意味着此类纯面板每年都不会构成当年纳税人的随机样本。这将在至少两个方面产生有害影响。一方面，横截面面板研究需要每年开发不同的统计估计量，基于样本重新缩放技术，即为面板中的每个个体分配特定的年度权重（提升因子）。显然，这些估计量的复杂程度自然会随着纯面板与所考虑年份的总受访者数量之间的相似程度降低而增加。因此，一年与另一年的估计量之间的差异将取决于前面提到的相似程度（面板/纳税人总体）。

另一方面，税收的纯面板将不允许分析每年新纳税人或不再成为纳税人的特定特殊性，因为根据其本质，它们根本不可能包含任何这些人。从这个意义上说，这种限制会使面板的实用性降低，尤其是如果我们考虑到近年来，任何税的新纳税人在每一年往往占总数的相当可观的百分比，而且，逻辑上讲，新纳税人与老纳税人之间应该存在显著差异。

“扩展”面板作为一种试图消除上述有害影响的方法而出现。它允许进行与纯面板相关的所有研究，因为它包含其中一个作为子面板。其本质在于，由重叠的纳税人代表性样本组成，并且可以在第一次样本被选定后，通过每年纳入（或扩展）相对于前几年而言的新纳税人的额外子样本而反复提取，其分配或规模与已存在样本相对于老纳税人总数的情况相当。显然，加入面板的新纳税人将继续从加入时间起被观察。退出者事实上将作为此类观察的结果而出现，即当他们不在当年申报者中时，他们会自然出现在面板上。这样，我们将为每年提供代表性样本，我们将在其中识别新申报者、老申报者以及在某一年离开的申报者，这些样本的共同部分是上述包含在其中的纯面板子样本。IEF 的扩展面板提供了适当的提升因子，以便每年进行横截面估计并具有有界误差。

# 5.3 年度样本、横截面组合（合并数据）与面板的比较

![image](d2d_images/chapter_title_below.png)

每当不存在选择困难时，如行政登记的情况，年度样本通常被使用。孤立的年度（或横截面）样本为特定时间点提供了非常丰富的信息。然而，它缺乏时间维度，这大大限制了其有用性。然而，当有在不同年份独立获得的多个样本（称为独立横截面组合或数据池）时，可应用分析的丰富程度呈指数级增长。

像面板一样，独立横截面组合（数据池）具有时间维度，因为它由在不同时间点，通常是年份，对大量不同个体进行的观察构成。然而，数据池的显著特征是，观察结果并非来自不同时间点的同一批个体，而是每个数据池年份的样本忠实地代表了该年的总体。

然而，许多关于个人、家庭、企业等的调查会定期重复，通常每年一次。如果在每个时期抽取一个随机样本，将其结果组合起来就得到一个数据池。通过组合在不同时间点从同一总体抽取的随机样本，我们可以获得更精确的估计量和更强大的检验统计量，主要是由于涉及的样本量更大。然而，必须记住，应用模型中因变量与某些自变量之间的关系必须在时间上保持不变。从统计上讲，数据池可能出现的问题是总体在不同时期的分布可能不同，这通常通过引入虚拟变量来解决。也可能出现随时间变化的非恒定变异性或异方差性问题（许多个体和多个时期几乎不可能保持经济建模中通常要求的恒定变异性），但这些问题在统计上也是可解决的（异方差性问题的计量经济学处理）。

横截面组合对于评估某些事件或政策的影响也非常有用。它们通常在有两个或多个在事件发生前后收集的横截面数据集可用以确定该事件的经济结果影响时使用。例如，为了评估烟草税变化对烟草消费的影响，可以在不同时间点抽取两个随机样本，以便在一个时间点税改未发生，在另一个时间点发生。这些情况下使用的变化估计和有时连续的估计大多可以合理地从数据池中获得。

然而，就税收改革的模拟而言，面板格式远优于年度样本池。有两个有力的论据可以证明这一断言：

1. 面板允许从动态角度评估税收改革。具体而言，它允许分析任何税收变化对同一个体（或家庭或纳税单位）随时间的影响。换句话说，它允许对改革进行结构性分析。这是评估税收改革的一个根本问题，因为个人会根据税收变化调整其行为。并且其中许多变化并非在改革后瞬间发生，而是在一个或多个时期之后发生，因此引入动态的面板时间维度至关重要。

2. 当我们比较同质单位（个人或家庭或纳税单位）时，改革的影响可以更可靠地衡量。例如，当我们分析改革对最贫困个人（第一收入十分位）净收入的影响时，我们比较的是同一组个人。因此，处理不同时间点的同一批个体的观察结果至关重要。
