## 6.11.1 neuralnet 库
![image](d2d_images/chapter_title_below.png)

`neuralnet` 库的 `neuralnet` 命令具有以下简化语法：

```
neuralnet(formula, data=dataset, hidden = c(m,n),...)
```

向量 `c(m,n)` 指定各层中的隐藏神经元数量。

作为示例，我们将计算银行贷款申请人成功偿还贷款的概率。为此，我们使用一个名为 `credits.sav` 的文件，其中包含一个二分变量 `credit_v`，该变量收集客户历史中信贷偿还的成功或失败（1=成功偿还，0=未偿还或未还款）。该变量将是网络模型的因变量。作为自变量，将使用客户的职业类别、月薪、年龄以及客户是否拥有美国运通卡。

我们首先加载文件，分离其变量并获取它们的基本统计信息。
