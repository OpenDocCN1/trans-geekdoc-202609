为解决此问题提出了许多算法，例如 Moqueen 于 1967 年提出的 K-means 算法。然而，这些算法导致部分解，即局部最小值，未必是全局最小值（最优解）。因此，该问题的困难在于目标函数有许多局部最小值，它们不一定是全局最小值（最优解）。

为了进行这种类型的分组，我们将使用具有无监督学习的竞争神经网络，它允许我们将输入数据形成组或类别。每个输入将被分配给被激活的输出单元指定的类。在这种类型的学习中，神经元相互竞争以查看哪个被激活；只有一个被激活，因此通常称为胜者通吃学习。在这里，网络自行（无监督）将数据分组为类别，并为我们提供每个类别的原型。

这种新的学习范式由 Rumelhart 和 Zipser 于 1985 年提出，名称为竞争学习。网络由 `m` 个神经元或处理单元的一层组成，它们连接到输入信号或模式，这些连接具有相关的突触权重，将代表原型模式。每个神经元只有两种可能的输出值：0（未激活）或 1（激活），并且对于每个输入模式只有一个神经元被激活，即接收到更高突触电位的那个（获胜神经元）。
