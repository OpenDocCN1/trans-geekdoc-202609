

感知器和高斯最大似然分类器都是线性分类器。感知器在两类线性可分的前提假设下工作，而高斯分类器则不做此假设。感知器是一种非参数方法，因为它不对每个类别的分布形状做出任何假设。在此意义上它是一种更稳健的方法。高斯分类器的正态性假设限制了其应用范围。感知器算法具有自适应性且实现简单；存储需求仅限于突触权重和阈值。另一方面，高斯分类器的设计是固定的，虽然可以使其自适应，但这需要显著增加存储量，且计算更为复杂。高斯分类器最小化了平均误分类概率。感知器相对于哪种准则或期望度量是最优的？Shynk（1990）已从以下准则推导出感知器算法：最小化误差与突触电位和阈值之差的乘积的期望值，即 ![image](d2d_images/image676.png)其中 `d(k)` 是第 `kth` 次迭代时的期望输出。

# 6.7 使用神经网络进行时间序列分析

![image](d2d_images/chapter_title_below.png)

时间序列由多个变量的值序列组成，这些值随时间演变（变化）。目标是基于历史数据集合，预测产生这些值的现象或动态系统的未来行为。例如，预测电力消耗或预测某一地区将需求的流感疫苗数量。解决这些问题的最佳方法是找到产生这些过程的潜在规律。该规律可以通过解析方法获得，例如一组微分方程。然而，我们对过程的了解通常是部分或不完整的，因此，预测无法通过已知的解析模型进行。我们将尝试在时间序列观测中发现一些强经验规律。在许多现实世界问题中，一些规律，如周期性，被噪声掩盖，甚至一些动态过程由混沌时间序列描述，其中数据看起来随机，没有明显的周期性。

尽管混沌阻止了任何长期预测，然而，使用人工神经网络进行短期预测取得了令人鼓舞的结果，人工神经网络由非线性多元函数描述：

大多数可用技术假设变量之间或时间滞后的变量之间存在线性关系。但这些技术通常不足以分析现实世界的时序数据，因为它们无法解释振幅大且时间间隔不规则的突然变化。合理非线性模型的构建是一项非常困难的任务。因此，由于目标是做出良好的预测，神经网络是计算预测的良好替代方案。Lapides 和 Fraber（1987）是应用神经网络对简单（无噪声）系统建模及其预测的先驱。至少目前为止，主要问题是难以为每种情况找到合适的网络；没有固定规则可以确定每种研究案例的适当神经网络架构。La Fuente 和 Pino（1995）的工作对 Box-Jenkins 方法论与神经网络之间的预测计算进行了比较分析，并提出将 Box-Jenkins 方法论用作神经网络结构设计的前置步骤。
