

## 分布

- **逆高斯分布**。该分布适用于正尺度值且偏向较大正值的变量。如果数据值小于或等于 0 或为缺失值，则对应的案例不得用于分析。

- **负二项分布**。该分布考虑实现 k 次成功所需的尝试次数，适用于具有非负整数值的变量。如果数据值不是整数、小于 0 或为缺失值，则对应的案例不得用于分析。负二项分布的辅助参数值可以是大于或等于 0 的任意数；可以将其设为固定值或留给过程进行估计；当辅助参数设为 0 时，使用该分布等同于使用泊松分布。

- **正态分布**。适用于取值围绕中心值（均值）呈对称钟形分布的尺度变量。因变量必须是数值型。

- **泊松分布**。该分布考虑固定时间段内感兴趣事件的发生次数，适用于具有非负整数值的变量。如果数据值不是整数、小于 0 或为缺失值，则对应的案例不得用于分析。

- **Tweedie 分布**。该分布适用于可由伽马分布的泊松混合表示的变量；该分布在“混合”意义上结合了连续（取非负实数值）和离散（在单个值 0 处具有正概率质量）分布的特性。因变量必须是数值型，且数据值必须大于或等于零。如果数据值小于 0 或为缺失值，则对应的案例不得用于分析。Tweedie 分布参数的固定值可以是大于 1 且小于 2 的任意数。

- **多项分布**。该分布适用于表示有序响应的变量。因变量可以是数值型或字符串型，且必须具有至少两个不同的有效数据值。

# 2.5.2 联系函数

![image](d2d_images/chapter_title_below.png)

联系函数 `g` 是对因变量的一种变换，可实现模型的估计。常用的函数如下：

- **恒等**。`g(x)=x`。因变量不进行变换。此联系函数可与任何分布一起使用。

- **互补对数-对数**。`g(x)=log(-log(1-x))`。仅适用于二项分布。

- **累积柯西**。`g(x) = tan(π (x - 0.5))`，应用于响应每个类别的累积概率。仅适用于多项分布。

- **累积互补对数-对数**。![image](d2d_images/image111.png)，应用于响应每个类别的累积概率。仅适用于多项分布。

- **累积对数几率**。`g(x)=ln(x / (1-x))`，应用于响应每个类别的累积概率。仅适用于多项分布。

- **累积负对数-对数**。![image](d2d_images/image214.png)。应用于每个响应类别的累积概率。仅适用于多项分布。

- **累积 Probit**。![image](d2d_images/image302.png) 应用于响应每个类别的累积概率，其中 ![image](d2d_images/image286.png) 为逆标准正态累积分布函数。仅适用于多项分布。

- **对数**。![image](d2d_images/image449.png) 此联系函数可与任何分布一起使用。

- **对数补**。![image](d2d_images/image127.png) 仅适用于二项分布。

- **对数几率**。![image](d2d_images/image349.png) 仅适用于二项分布。

- **负二项**。![image](d2d_images/image470.png) 其中 `k` 为负二项分布的辅助参数。仅适用于负二项分布。

- **负对数-对数**。![image](d2d_images/image064.png) 仅适用于二项分布。

- **概率幂**。![image](d2d_images/image613.png) `α` 为所需数字规范，必须为实数。仅适用于二项分布。

- **Probit**。![image](d2d_images/image406.png)，其中 `Φ^(-1)` 为逆标准正态累积分布函数。仅适用于二项分布。

- **幂**。![image](d2d_images/image332.png) 若 `α=0`。`α` 为所需数字规范，必须为实数。此联系函数可与任何分布一起使用。

作为示例，我们考虑包含 53 名前列腺癌患者样本数据的 `logitb.sav` 文件，测量年龄、衡量肿瘤程度的酸水平、肿瘤的侵袭性、肿瘤的分期、X 光检查结果以及手术时癌症是否已扩散到淋巴结。从这些数据出发，目标是拟合一个模型，可以在无需手术的情况下预测癌症是否（或是否不）扩散到淋巴结。
