# 3.9 样本选择校正：两阶段 Heckman 或 Heckman 两步估计

![image](d2d_images/chapter_title_below.png)

截断回归是非随机样本选择这一更一般问题的特例，当用于估计的样本不是随机样本时就会出现这种情况。

Heckman 提出了一种两阶段程序，用于在存在附带截断的情况下估计模型，从而克服选择偏差问题：
阶段 1. 使用 n 个观测值，我们估计 s 关于 Z 的 Probit 模型，由此得到 ![image](d2d_images/image104.png)。根据这些估计值，我们计算每个 i 的 ![image](d2d_images/image651.png)。
阶段 2. 使用选定样本 (s=1) 我们通过 OLS 估计 Y 对 X 和 ![image](d2d_images/image246.png) 的回归。

该程序产生一致且渐近正态的估计量。

样本选择偏差存在的检验包括在第二阶段检验 `ρ = 0` 的假设，使用 ![image](d2d_images/image619.png) 的 t 统计量。当 `ρ ≠ 0` 时，第二阶段的标准误差不再有效，必须进行校正。

我们假设 X 是 Z 的子集，因为如果我们不当排除 X 的任何元素，我们可能会得到不一致的估计量。Z 至少包含一个不属于 X 的元素是很重要的。这对于 `β` 的识别并非必不可少，因为 ![image](d2d_images/image619.png) 的非线性足以达到此目的。

但如果我们有额外的元素，![image](d2d_images/image619.png) 与 X 的相关性会降低，我们将获得 `β` 的更精确估计。此外，如果在第一阶段我们不包含额外项目，则在第二阶段 ![image](d2d_images/image619.png) 的显著性可能是由于样本选择或设定错误。

除了使用 2 阶段程序外，此类模型也可以通过 MV 估计，尽管更复杂，因为我们需要 Y 和 s 的联合分布。
