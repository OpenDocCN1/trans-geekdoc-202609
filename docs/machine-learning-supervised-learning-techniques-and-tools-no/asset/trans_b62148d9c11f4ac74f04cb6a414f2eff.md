

时间序列数据倾向于更多地用于宏观经济分析，而截面数据则主要用于宏观经济分析。时间序列通常比截面数据更难分析，因为我们几乎永远不能假设经济观测在时间上是独立的。

大多数时间序列，无论是经济的还是非经济的，都与其近期历史相关（通常是强相关）。例如，我们对上季度国民生产总值的了解可以告诉我们很多关于本季度我们可以期望的 GDP 水平，因为 GDP 倾向于从一个季度到下一个季度保持稳定。时间序列数据的另一个重要特征是其收集的周期性（每周、每月、每季度等），并且许多每周、每月或每季度的序列显示出明显的季节性特征，这可能是时间序列分析方法中的一个重要因素。

对于个人所得税样本的情况，我们可以考虑衡量 1999-2008 年期间每个税项变量演变的时序。

# 5.1.3 数据结构。截面组合

![image](d2d_images/chapter_title_below.png)

截面或合并数据的组合是一种具有截面数据和时间序列数据两者特征的数据结构。数据池是不同时间点在同一总体中收集的多个截面数据的汇编（但不是针对同一个人）。例如，假设在一个国家进行两次截面家庭调查，一次在 1985 年，一次在 1990 年。1985 年，进行一次随机抽样调查以获得收入水平、储蓄、家庭规模等变量。在 1990 年，对家庭进行新的随机抽样，并使用与 1985 年相同的问卷进行调查。为了增加样本量，我们可以通过合并两年数据来形成合并的截面数据集。合并不同年份的截面数据通常对于分析新政府政策的影响很有用。其思想是在关键政策变化之前和之后收集数据。

总体而言，合并截面数据以与常规截面数据大致相同的方式进行分析，只是我们通常需要考虑变量随时间的变化。事实上，除了增加样本量之外，合并截面数据的目标通常也是观察关键关系如何随时间变化。然而，通过在不同时间点从同一总体中通过随机抽样获得的截面组合，我们将得到独立但不完全相同的分布的观测样本。

在个人所得税的情况下，可以通过汇集所有每年选定的样本来形成数据池。显然，每年随机选择的个人所得税样本不会对应于同一批个人。

# 5.1.4 数据结构。面板或纵向数据

![image](d2d_images/chapter_title_below.png)

面板数据集，或纵向数据，由截面（或截面数据集）的每个单位的时间序列组成。面板数据是在不同时间点（或不同地理单位或不同企业等）在同一总体中针对同一个人收集的多个截面数据的汇编。

举例来说，假设我们有一组个人在十年期间的薪资、教育和就业历史记录。我们也可以收集同一组企业在五年期间的财务或投资数据（因此个人不一定是人）。面板数据也可以在地理单位上收集。例如，我们可以收集同一组欧盟国家在 1990 年、1995 年和 2000 年的移民流动、税收水平、工资、政府支出等数据。面板数据的关键特征，使其与合并截面数据不同，是信息是在不同时间点从同一截面单位（个人、企业、国家等）收集的这一事实。

由于面板数据收集需要随时间重复相同的调查单位，因此面板数据比合并截面数据更难获得，尤其是在处理个人、家庭或企业数据时。然而，面板数据的优势在于它们通常使我们能够研究行为滞后或决策滞后（动态面板）的重要性。鉴于许多经济措施在实施后一段时间才可能产生影响，这一信息可能非常显著。在个人所得税的情况下，面板是通过随时间跟踪同一个人的申报表形成的。然而，这一概念，即纯面板，可以通过扩展面板技术来完善，这些技术已被用于形成 IEF 的个人所得税面板，我们将在后面深入讨论。

但我们不应忘记，面板的基本特征是其时间维度，因为它由在不同时间点，通常是年份，收集的各种个体的观测值组成。然而，面板的显著特征是观测值通常来自不同时间点的同一批个人。此外，当为面板提供信息的来源是行政记录时，几乎没有无应答，这使得可以形成紧凑的面板，非常适合进行免于缺失值和异常值的分析，而无需对缺失信息应用插补方法。探索性数据分析阶段，即在任何面板数据应用之前且对结果至关重要的阶段，因此得到了极大的促进。

包含个人所得税面板信息的数据库的发展，其数据在收集单位数量及其特征方面日益丰富，再加上用于处理它们的计算机资源能力的提高，最近导致了微观模拟模型的使用激增，目的是估计公共政策的影响。

# 5.2 纯面板和扩展面板

![image](d2d_images/chapter_title_below.png)

纯面板在整个时间段内跟踪同一批个人。随着时间的推移，这会导致样本代表性丧失的问题，因为可能有个人因不同原因退出样本。这样，面板会随时间磨损（流失），并可能变得无效。
