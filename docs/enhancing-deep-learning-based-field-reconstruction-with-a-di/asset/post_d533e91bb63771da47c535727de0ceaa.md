# Discussion

Reconstruction of a global field from sparse sensors has a major challenge in engineering and science. Models with sparse input are crucial for real-world applications. We could include flow reconstruction in ocean experiments, health monitoring with satellite data usage, and environmental sensing in robot control.

One advantage of DSPO is that reconstruction is performed within a differentiable learning framework, which dynamically learns sensor placement and reconstruction simultaneously. The bilevel framework is different from traditional placement methods because it optimizes the model end-to-end.

This process not only optimizes the architecture but also the parameters. By using different numbers of training data sizes and noise levels,

we perform comprehensive comparisons on baseline models using DSPO and static placement optimization. These experimental results demonstrate that DSPO can achieve remarkable accuracy, generalizability and robustness against given models for sparse/noisy data. Especially, DSPO enhances other baselines to approach or even reach the SOTA accuracy and performance-

This highlights that DSPO dynamically exploits the model's capacity and expressivity, alleviating the accuracy limitations imposed by network architectures.
