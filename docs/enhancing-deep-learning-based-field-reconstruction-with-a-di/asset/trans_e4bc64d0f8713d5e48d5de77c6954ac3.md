反向过程交替执行，直到目标函数不再进一步提高。以公式表示，该过程给出：

$\theta^* = \arg \min_{\theta} \mathcal{L}_0(\theta, \mathcal{Q}(\mathbf{s}', \mathbf{x}))$$

$\mathbf{x}_{t+1} = D(\nabla_{\mathbf{x}} \mathcal{L}_0).$

其中

$\nabla_{\mathbf{x}} \mathcal{L}_0 = \nabla_{\mathbf{s}'} \mathcal{L}_0 \cdot \nabla_{\mathbf{x}} \mathbf{s}'.$

$\nabla_{\mathbf{s}'} \mathcal{L}_0 = \nabla S(\mathbf{V}, \mathbf{x}_i, s'_i) = \nabla S(\mathbf{V}, \mathbf{x}_i, s).$

其中 $\mathbf{u}'_i$ 表示 RFD-BF 导数 $[\mathbf{x}_i]$ 表示 RFD-BF 传感器。生成器 $\mathcal{g}$ 计算 $l=0$ 对应的 RFD-BF 导数，对应于位置 $\mathbf{x}_i$ 传感器值的比较。该策略的核心思想是选择 $\mathbf{u}'_i$。生成器首先利用径向基函数 $\phi$ 和多项式 $\theta$ 的组合来估计传感器值：$s_i = \sum_{j} \eta_j \phi(\mathbf{x}_i - \mathbf{x}_j) + \mu_j \mathbf{x}_j$ (图. 1b)。

$\mathbf{v}_i = \sum_{j=1}^M \mathbf{u}'_j s'_j$

$\mathcal{L}_0$ 和 $\mathcal{L}_1$ 表示验证重构误差。值得注意的是，当模型只有观测值时，导数 $\nabla_{\mathbf{x}} \mathcal{L}_0$ 必须通过 $\mathbf{AD}$ 和 $\mathbf{B}$ 计算。当模型包含其输入的一部分部分时，可以使用 $\mathbf{AD}$ 计算导数。

# 结果

我们将通用 DSO 框架应用于在宽时空范围内具有强非线性动力学的六个基准测试。相对均方误差 $||q - \hat{q}||/q$ 用于评估重构性能，其中 $q$ 和 $\hat{q}$ 表示重构场。基准：使用六个重构模型验证 DSO、MLP、傅里叶神经算子 (FNO)。此外，将 DSO 与插值方法比较，即基于条件的采样（DSO）、增强聚类的采样（EES）和基于采样（CCS）。这些静态方法在插值之前优化双线性场。DWI 也被基准，它在放置期间同时优化积分场。ISH 被比较并作为基准。微分器（US）和随机采样（RS）也被视为基准。
