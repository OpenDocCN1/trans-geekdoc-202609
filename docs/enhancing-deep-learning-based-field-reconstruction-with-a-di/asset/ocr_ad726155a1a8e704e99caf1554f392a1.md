To address these issues, we propose a general bilevel framework that integrates reconstruction models with sensor placement (SPO) for global field reconstruction. The operator is introduced into the bilevel framework without introducing any additional parameters. Gradient-based bilevel optimization is used to train and test models. Our framework has three major contributions: (1) We introduce an SPO-based framework for joint reconstruction and sensor placement. (2) By alternately optimizing different variables (blocks and placement), the alternating optimization strategy is designed to effectively resolve the trade-off between reconstruction quality and sensor numbers. (3) A differential operator is introduced to handle the non-differentiability of the global field with respect to placement. This enables a end-to-end bilevel framework to dynamically optimize sensor placement with global observations and their derivatives, which effectively handles both regular and irregular field densities. This framework can serve as a general paradigm, offering high generality and flexibility for various applications. This work is the first and systematic study on using NN-based models across various scenarios, including periodic and cyclic fields, regular and irregular grids. Throughout this article, we demonstrate the effectiveness of the proposed framework by applying it to various scenarios.

The goal of sensor placement optimization (SPO) is to place sensors in a way that maximizes information for reconstruction (objective function), which is one of the biggest difficulties in reconstruction models. Most SPO strategies have various criteria based on reduced number of sensors or optimality⁵. Others use an approach that limits sensor number with QB to determine sensor placement for the MLP-based model. Others⁷ optimize sensor placement using an enhanced clustering algorithm and reconstruct models with a linear operator. Each criterion is related to reconstruction quality and error difference by sensor placement model training, which helps to guarantee an improvement in accuracy for NN-based models. Detection of reconstruction error is also one of the main challenges in evaluating reconstruction efficiency. Training models with inner-level optimization require substantial computation. Expensive iterations in inner-level optimization can cause the model to converge slowly. Fast methods converge relatively with few iterations. However, NN-based models are not differentiable with respect to sensor placement due to two limitations. One limitation is the discrete nature of sensor placement, selecting a candidate element from an an index, which fails to smooth observations with respect to the placement. This Marcato et al.¹¹⁰ proposed a bilevel walk strategy on the discrete search space, enabling differentiable sensor placement through bilinear interpolation.
