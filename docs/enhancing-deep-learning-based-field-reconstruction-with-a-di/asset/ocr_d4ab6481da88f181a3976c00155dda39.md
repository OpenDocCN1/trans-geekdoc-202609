Since the MLP is employed, we used the MLP-based encoder to transform the input features into the global field representation. The high-dimensional representation can be acquired through the MLP and $l+1$ convolutional layers, which are then converted to convolutional layers. The multiple convolutional layers are further stacked to enhance the model capacity and expressivity. The convolution layer extracts features of input data through filtering operations,

```
$X^{(l)}_i = \sigma \left( \sum_{j \ \in \mathcal{N}(i)} \frac{1}{\sqrt{d_id_j}} W^{(l)} X^{(l-1)}_j + b^{(l)} \right)$
```

where $X^{(l)}$ and $Y^{(l)}$ are input and output data at layer $l$; $W$ denotes a filter with size $H \times d$; $h$ denotes the number of filters and $b$ the bias; and $\sigma$ denotes a non-linear activation function and the operation. With the training dataset $\mathcal{D} = \{\mathbf{s}_i\}_{i=1}^N$, we utilize the CNN to learn the mapping $\mathcal{S} \mapsto \ \mathbf{u}$ for global field reconstruction.

FNO operates as one of the most successful deep learning architectures, which can efficiently learn mesh-independent architectures over infinite-dimensional spaces. Leveraging Fourier transform, we let $\mathcal{I} \mapsto \mathcal{O}$ be FNO to learn the mapping between field domains. Due to the efficiency of the fast Fourier transform, FNO is capable of generating data on complex domains. With an MLP-based encoder, 20 utilized the multiple attention layers to learn the mapping from global features to local fields.

The conceptual flow of GCNN is shown in Supplementary Fig. I-5. The F-SCNN adopts an encoder-decoder architecture. The spatial encoder $E_s$ first maps the locations $x$, to the features, and an attention-based encoder maps the features to a latent space $Z$. Then, an attention-based decoder reconstructs the field from the query locations $x$. This process may be formulated as

```
$Z = E_s(\mathbf{s}), \\n \mathbf{u} = D_s(Z, x)$
```

The encoder consists of a MLP and multiple attention blocks, whereas the decoder is composed of MLP and multiple crossed attention layers. Each block is a multi-head attention layer with a query, key, and value to learn the mapping $\mathcal{S} \mapsto \ \mathbf{u}$. The Senser is used to reconstruct the complex field from a few observations. Further details are provided in Ref. 22.

The kernel operator encoder processes the input with the Fourier transform and inverse Fourier transform. Here $R$ is the parameter of the Fourier convolution. The decoder processes the field using the inverse Fourier transform. With the training data, we utilize the CNN to learn the mapping $\mathcal{S} \mapsto \ \mathbf{u}$.
