# Methods

### Differentiable learning framework

NN-based reconstruction methods according to different tasks can be divided into two categories, which methods are either end-to-end like MLP and FCN or decoder-based. In the latter, the decoder, represented as $\mathcal{G}_{\theta}(s_i, x_i)$, is differentiable with respect to $\theta, s_i$ and $x_i$. Here, $x_i$ represents the query locations, which correspond to all global coordinates in our global framework.

# Validation of framework

The proposed framework is validated on six NN-based models, including MLP, PODN, FCN, GAN and SiN. We summarize the conceptual flow of our methods, and the detailed descriptions are as follows:

**MLP.** A representative work is to use a MLP for fluid reconstruction, demonstrating superior performance characteristics without having reprocessing the raw data. Following the related work, we use the MLP-based model to validate the proposed framework for global fluid reconstruction (Supplementary Fig. 1-C). The MLP extracts key features of observations through several fully connected layers

```
$u^{(L)}(s) = \sigma(W^{(L)}\sigma(W^{(L-1)}(\dots + W^{(1)}s + b^{(1)})\dots) + b^{(L)}); \quad (1)$
```

where $\sigma$ denotes the activation function, and the decoder contains the weights $W^{(l)}$ and biases $b^{(l)}$. The training dataset $\mathcal{D} = \{s_i, u_i\}_i$ consists of pairs of observations and reconstructions. **PODN.** Reduced-order model using PODN is a well-established and widely used class of reduced-order model techniques for fluid reconstruction—it is used to perform online prediction to reduce the computational cost of high-dimensional simulations. Furthermore, proper orthogonal decomposition (POD) models are derived from a set of snapshots (snapshots) and NN is used to learn the mapping between observations and POD coefficients.

```
$\theta^* \in \arg\min_{\theta} \sum_i ||a_i - a(s_i)||^2; \quad (2)$
```

The forward pass reconstructs global fluid fields based on limited observations, providing the best model parameters for the current placement. By default, uniform placement is used as the initial sensors for the first model. Then, through iterations, random adaptive placement strategies are used to update the locations.

The reverse process minimizes sensors locations and provides deployment for the forward process. Given the best model parameters $\theta^*$ is used to calculate the gradient information, derivative of objective function with respect to placement $s$. Consequently, automatic update of placement is performed for each iteration $\gamma_t$. In this process, the gathering operator calculates the derivative of $s$ with respect to $x_i$, which is $\frac{\partial \mathcal{L}}{\partial x_i} = \frac{\partial \mathcal{L}}{\partial s} \frac{\partial s}{\partial x_i}$.

PODN is utilized to validate the proposed framework (Supplementary Fig. 1-2). We first collect snapshots such that $u_i = \sum_j a_{ij} \phi_j$, where $u_i$ are the POD models, $\phi_j$ are the singular modes and $a_{ij}$ are the coefficients. The decomposition is obtained with sufficient dataset. Then the training dataset $\mathcal{D} = \{s_i, a_i\}_i$ is constructed. With the training data, we aim to learn a mapping from observations to coefficients: $s \rightarrow a$. The learning process is mathematically formulated as

CNN has emerged as a powerful alternative to reconstruct high-dimensional data from sparse observation in an efficient manner. The aforementioned methods suffer from limitations on regular grid. Thus, CNN has also been proposed on the Voronoi embedding to address unstructured data. Subsequently, another methods combine the MLP with CNN. Since the MLP is employed, we used the MLP-based encoder to transform the input features into the global field representation. The high-dimensional representation can be acquired through the MLP and $l+1$ convolutional layers, which are then converted to convolutional layers. The convolution layer extracts features of input data through filtering operations,

```
$H^{(l+1)} = \sigma(W^{(l)}A^{(l)}H^{(l)})$
```

where $A$ is the adjacency matrix, $I$ the identity matrix, $D$ the degree matrix of $A$. The layer captures the features of updating and aggregating neighbor features, leading both direct and indirect connections in the network.

```
$X^{(l)}_i = \sigma \left( \sum_{j \in \mathcal{N}(i)} \frac{1}{\sqrt{d_i d_j}} W^{(l)} X^{(l-1)}_j + b^{(l)} \right)$
```

where $X^{(l)}$ and $Y^{(l)}$ are input and output data at layer $l$; $W$ denotes a filter with size $H \times d$; $h$ denotes the number of filters and $b$ the bias; and $\sigma$ denotes a nonlinear activation function.

FNO operates as one of the most successful deep learning architectures, which can learn mesh-independent architectures over infinite-dimensional spaces. Leveraging Fourier transform, we let $\mathcal{I} \mapsto \mathcal{O}$ be FNO to learn the mapping between field domains. Due to the efficiency of the fast Fourier transform, FNO is capable of generating data on complex domains.

F-SCNN adopts an encoder-decoder architecture. The spatial encoder $E_s$ first maps the locations $x$, to the features, and an attention-based encoder maps the features to a latent space $Z$. Then, an attention-based decoder reconstructs the field from the query locations $x$. This process may be formulated as

```
$Z = E_s(\mathbf{s}), \\ \mathbf{u} = D_s(Z, x)$
```

The encoder consists of a MLP and multiple attention blocks, whereas the decoder is composed of MLP and multiple crossed attention layers. Each block is a multi-head attention layer with a query, key, and value to learn the mapping $\mathcal{S} \mapsto \mathbf{u}$. The Senser is used to reconstruct the complex field from a few observations. Further details are provided in Ref. 22.

The kernel operator encoder processes the input with the Fourier transform and inverse Fourier transform. Here $R$ is the parameter of the Fourier convolution. The decoder processes the field using the inverse Fourier transform. With the training data, we utilize the CNN to learn the mapping $\mathcal{S} \mapsto \mathbf{u}$.
