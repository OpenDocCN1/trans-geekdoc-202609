

# 缓存控制平面信息

![Image](graphics/bull.jpg)

对网络中流量进行有意修改或塑形并不是网络工程师必须处理的唯一一种策略。信息隐藏虽然不常被视为一种策略形式，但与构建可扩展、可重复网络的更大目标或策略相关。这些策略对流量流有影响，尽管这些影响通常是无意的而非有意的——这意味着它们经常被忽略。本章和下一章，[第20章](#ch20.xhtml#ch20)，“[信息隐藏示例](#ch20.xhtml#ch20)”，专门用于探讨这一问题、解决方案空间以及一些广泛使用的解决方案实现。本章的第一部分将考察问题空间，第二部分将介绍可用于抵消该问题的各种解决方案，第三部分将从网络复杂性的角度考虑信息隐藏。

## 问题空间

控制平面旨在尽可能多地学习关于网络拓扑和可达性的信息。为什么网络工程师在花费处理和内存学习这些信息后，还想限制其范围？有几个原因，包括

• 为了减少参与控制平面的设备中的资源利用率，通常只是为了节省成本

• 为了防止网络某一部分的故障影响网络的另一部分；换句话说，将网络划分为故障域

• 为了防止向攻击者泄露有关网络拓扑以及连接到网络的目的地的可达性信息；换句话说，减少网络的攻击面

• 为了防止可能导致整个网络故障的正反馈循环

前述列表中的问题可以分为两类：减少控制平面信息的范围以及减少允许控制平面信息变化的速度。这将在接下来的两个部分中讨论。

### 定义控制平面状态范围

[图19-1](#ch19.xhtml#ch19fig01)说明了控制平面状态的范围。

![Image](graphics/19fig01.jpg)

**图19-1** *控制平面状态的范围*

控制平面携带两种状态：拓扑和可达性。这两种控制平面状态在网络中可能具有不同的范围。例如：

• 如果 `D` 知道 `2001:db8:3e8:100::/64`，那么此可达性信息的范围是 `A`、`B`、`C` 和 `D`——整个网络。

• 如果 `C` 知道 `2001:db8:3e8:100::/64`，而 `D` 不知道，那么此可达性信息的范围是 `A`、`B` 和 `C`。

• 如果 `D` 知道连接 `A` 和 `B` 的链路，或 `A` 和 `B` 相邻，则此拓扑信息的范围是 `A`、`B`、`C` 和 `D`——整个网络。

• 如果 `D` 不知道连接 `A` 和 `B` 的链路，或 `A` 和 `B` 相邻，则此拓扑信息的范围是 `A`、`B` 和 `C`。

另一种看待方式是问：如果到特定目的地的链路或可达性发生故障，哪些设备必须参与收敛？任何不参与收敛的设备，也许通过发送更新、重新计算网络中无环路径集，或切换到备用路径，都不属于故障域。任何需要发送更新、重新计算无环路径集或切换到备用路径的设备都属于故障域。因此，故障的范围决定了故障域的范围。在 [图19-1](#ch19.xhtml#ch19fig01) 中：

• 如果 `D` 知道 `2001:db8:3e8:100::/64`，那么当 `100::/64` 与 `A` 断开时，`D` 必须重新计算其可达目的地集；因此 `D` 是该目的地的故障域的一部分。

• 如果 `D` 不知道 `2001:db8:3e8:100:/64`，那么当 `100::/64` 与 `A` 断开时，`D` 不会更改其本地转发表；因此 `D` 不是该目的地的故障域的一部分。

• 如果 `D` 知道 `A` 和 `B` 之间的链路，那么当链路故障时（连同通过该链路传递的任何可达性信息），`D` 需要重新计算网络中无环路径集；因此 `D` 是该特定链路的故障域的一部分。

• 如果 `D` 不知道 `A` 和 `B` 之间的链路，那么当链路故障时，`D` 无需重新计算任何内容；因此 `D` 不属于故障域。

此定义意味着必须为每条可达性和拓扑信息确定故障域。虽然协议和网络设计会在网络中的常见点阻止可达性和/或拓扑，但在某些情况下

• 拓扑信息被阻止，但可达性信息未被阻止。

• 部分可达性信息被阻止，但并非全部。

• 部分可达性或拓扑信息泄漏，导致抽象泄漏。

网络中控制平面信息的范围很重要，因为它对控制平面收敛的速度有很大影响。每次拓扑或可达性变化导致额外设备需要重新计算，都代表网络将保持未收敛的一段时间，因此某些目的地将不必要地不可达，或者数据包将在网络中的某些链路中循环，因为某些路由器对网络拓扑的视图与其他路由器不同。循环尤其是一个问题，因为循环往往有成为正反馈循环的潜力，这可能导致控制平面永久无法收敛。

### 正反馈循环

正反馈循环比控制平面信息的范围更难想象；[图19-2](#ch19.xhtml#ch19fig02)说明了这一点。

![Image](graphics/19fig02.jpg)

**图19-2** *说明正反馈循环的示例电路*

在 [图19-2](#ch19.xhtml#ch19fig02) 中，有四个设备：

• 设备 `A`，它将从信号输入接收到的内容与从 `B` 接收到的内容相加

• 设备 `B`，它可以增加或减少从 `C` 接收到的信号的大小或频率

• 设备 `C`，它将信号不变地传递给 `D`，并对信号进行采样，将样本发送给 `B`

• 设备 `D`，它测量信号

为了创建一个简单的反馈循环，假设 `C` 对通过它的信号采样一部分，将此样本传递给 `B`。设备 `B` 反过来放大样本的某个倍数，并将此放大后的信号传回 `A`。[图19-3](#ch19.xhtml#ch19fig03) 显示了结果。

![Image](graphics/19fig03.jpg)

**图19-3** *正反馈循环的结果*

[图19-3](#ch19.xhtml#ch19fig03) 中显示的情况是正反馈循环；`C` 放大它接收到的样本，使信号略微变大。结果在 `D` 处是幅度不断增加的信号。什么时候这个反馈循环会停止？当遇到某种限制因素时。例如，`A` 可能达到无法继续添加两个信号的极限，或者 `C` 达到输入信号极限并失效，释放其魔烟（所有电子设备在输入功率过大时会这样做）。也可以设置负反馈循环，其中 `C` 每次循环减少一点功率；在正弦波的情况下（如图所示），这需要 `C` 反转从 `A` 接收到的样本。最后，可以配置电路中的每个组件，使其既不增加也不减少 `D` 处的最终输出。在这种情况下，`C` 以某种方式调谐以补偿布线或 `A` 或 `C` 操作中的任何效率低下，通过向 `A` 注入足够的反馈来保持 `D` 处的信号功率不变。

[图19-4](#ch19.xhtml#ch19fig04) 将输出信号的幅度更改为事件的频率以说明原因。
