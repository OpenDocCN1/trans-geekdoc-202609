# 12.1.3 Balancing Transformations

Now we are ready to derive the balancing coordinate transformation T that makes the controllability and observability Gramians equal and diagonal:

W_hat_c = W_hat_o = Sigma. (12.14)

First, consider the product of the Gramians from (12.10) and (12.11):

W_hat_c W_hat_o = T^{-1} W_c W_o T. (12.15)

Plugging in the desired W_hat_c = W_hat_o = Sigma yields

T^{-1} W_c W_o T = Sigma^2  ==>  W_c W_o T = T Sigma^2. (12.16)

The latter expression in (12.16) is the equation for the eigendecomposition of W_c W_o, the product of the Gramians in the original coordinates. Thus, the balancing transformation T is related to the eigendecomposition of W_c W_o. Equation 12.16 is valid for any scaling of the eigenvectors, and the correct rescaling must be chosen to exactly balance the Gramians. In other words, there are many such transformations T that make the product W_hat_c W_hat_o = Sigma^2, but where the individual Gramians are not equal (for example diagonal Gramians W_hat_c = Sigma_c and W_hat_o = Sigma_o will satisfy (12.16) if Sigma_c Sigma_o = Sigma^2).

Below, we will introduce the matrix S = T^{-1} to simplify notation.

# Scaling Eigenvectors for the Balancing Transformation

To find the correct scaling of eigenvectors to make W_hat_c = W_hat_o = Sigma, first consider the simplified case of balancing the first diagonal element of Sigma. Let xi_u denote the unscaled first column of T, and let eta_u denote the unscaled first row of S = T^{-1}. Then

eta_u W_c eta_u* = sigma_c. (12.17a)

xi_u* W_o xi_u = sigma_o. (12.17b)

The first element of the diagonalized controllability Gramian is thus sigma_c, while the first element of the diagonalized observability Gramian is sigma_o. If we scale the eigenvector xi_u by sigma_s, then the inverse eigenvector eta_u is scaled by sigma_s^{-1}. Transforming via the new scaled eigenvectors xi_s = sigma_s xi_u and eta_s = sigma_s^{-1} eta_u, yields

eta_s W_c eta_s* = sigma_s^{-2} sigma_c. (12.18a)

xi_s* W_o xi_s = sigma_s^2 sigma_o. (12.18b)

Thus, for the two Gramians to be equal,

sigma_s^{-2} sigma_c = sigma_s^2 sigma_o  ==>  sigma_s = (sigma_c / sigma_o)^{1/4}. (12.19)
