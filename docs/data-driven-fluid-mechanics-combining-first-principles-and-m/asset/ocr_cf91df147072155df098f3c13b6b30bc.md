# 17.5.4 My MLC Problem

The definition of an MLC problem and its parameters is done by two files: `MyProblem_problem.m` and `MyProblem_parameters.m`, respectively. An example is provided in the *Plant\MyProblem* folder. The problem parameters and control law parameters should be modified only by creating an appropriate `MyProblem_parameters.m` file. Those parameters include the penalization parameter $\gamma$ (gamma), the actuation limitation, the number of constants, the operators (+, −, ×, ÷, ...), the register initialization, and so on. The user is free to do any modification in the *MyProblem* files.
