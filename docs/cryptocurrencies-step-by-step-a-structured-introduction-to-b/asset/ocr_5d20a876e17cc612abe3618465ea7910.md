# How Blockchain Works

Blockchain technology operates as a decentralized and distributed ledger system. At its simplest, a blockchain is a chain of blocks containing data. These blocks are linked in chronological order and secured using cryptographic techniques. Unlike traditional systems where a central authority manages the ledger, blockchain distributes control across a network of participants, known as **nodes**. Each step in the process—adding data, verifying transactions, and maintaining the chain—relies on a combination of cryptographic algorithms and consensus mechanisms to ensure integrity and security.

Each block in the chain has a structure. It contains three essential components: **data**, a **hash**, and the **previous block's hash**. The data depends on the blockchain's purpose. For Bitcoin, the data includes transaction details: the sender's address, the recipient's address, and the amount. The hash is a unique identifier generated from this data using a cryptographic algorithm. It acts like a fingerprint, ensuring that any change in the block's content produces a completely new hash. The previous block's hash links the blocks together, forming a chain. This linkage makes it easy to detect tampering—altering one block would invalidate all subsequent blocks, as their hashes would no longer match.

When a new transaction occurs, it is broadcast to the network. Nodes, which are computers running the blockchain software, receive the transaction and verify its validity. Verification involves checking that the sender has sufficient funds and that the transaction follows the network's rules. Once verified, the transaction is grouped with others into a block. But before the block can be added to the blockchain, it must go through a consensus process to ensure the network agrees that the block is valid.

Consensus mechanisms are the protocols blockchain networks use to achieve agreement. The most common is proof-of-work (PoW), used by Bitcoin. In PoW, nodes called **miners** compete to solve a complex mathematical puzzle. This puzzle involves finding a specific number, called a **nonce**, that, when combined with the block's data and hashed, produces a hash value that meets the network's difficulty requirements. Miners repeatedly hash the block's data with different nonces until one finds a valid solution. This process, though energy-intensive, ensures that adding a block requires significant computational effort, making it prohibitively expensive to manipulate the blockchain.
