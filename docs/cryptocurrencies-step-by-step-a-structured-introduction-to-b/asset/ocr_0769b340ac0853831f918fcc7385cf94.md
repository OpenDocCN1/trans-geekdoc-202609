# Mining Basics

Cryptocurrency mining is the process of validating transactions and adding them to a blockchain. At its core, mining secures the network, ensures data integrity, and introduces new coins into circulation. Unlike traditional financial systems where banks validate transactions, mining relies on a decentralized network of computers, known as nodes, to perform this task. These nodes solve complex mathematical puzzles as part of a consensus mechanism, most commonly **proof of work**.

When a transaction is initiated, it's broadcast to the network and grouped with other transactions into a **block**. This block is like a page in a digital ledger, and it must be validated before being added to the blockchain. Miners compete to solve a computational problem based on cryptographic hashing. The problem isn't about mathematical skill but brute force—trying different inputs repeatedly until the solution matches a target value. This target value is determined by the network's **difficulty level**, which adjusts dynamically based on how quickly blocks are being mined.

The cryptographic puzzle involves generating a hash—a fixed-length string of numbers and letters—from the block's data using a hashing algorithm. As mentioned, in Bitcoin the algorithm used is **SHA-256**. A hash is unique to the input data, and even a minor change in the data completely alters the hash. The goal for miners is to find a hash that starts with a specific number of zeros, which is determined by the difficulty level. Achieving this requires appending a random value, called a **nonce**, to the block's data and hashing it repeatedly until the desired result is found.

The miner who successfully solves the puzzle first earns the right to add the block to the blockchain. As a reward, they receive **newly minted cryptocurrency** (the block reward) and transaction fees from the transactions included in the block. For Bitcoin, this reward started at 50 BTC per block but decreases over time due to **halving events** every 210,000 blocks, or roughly every four years.

Mining requires specialized hardware to remain competitive. In Bitcoin's early days, enthusiasts could mine using their personal computers' **CPUs**. However, as the network grew, so did the difficulty of mining. Miners shifted to **GPUs** (graphics processing units), which were faster and more efficient at hashing. Today, **ASICs** (**application-specific integrated circuits**) dominate Bitcoin mining. These are devices built solely for mining and are far more powerful than GPUs or CPUs. While ASICs are efficient, they are expensive and consume significant electricity. We cover more on mining in the next section.
