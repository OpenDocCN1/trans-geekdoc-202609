
与数据收集期间记录的其他数据点相比存在显著差异。我们需要牢记，与缺失值一样，异常值也传达着重要信息。异常数据点并不意味着值总是错误，它仅仅意味着与邻近数据不同。

异常值的例子是，在记录某人的年龄时，有人误记录了负值。还可能出现这种情况：一台机器记录某地的日温度，最低为10摄氏度，最高为40摄氏度，平均温度约为25摄氏度。然而，一些记录显示日记录温度约为60摄氏度，这是不可能的，而且高于例如45摄氏度的温度也很难让人相信。这些数据点通常被称为异常值数据点。

与缺失值和字符串类别值不同，包含异常值的数据会成功运行而不会抛出任何错误。然而，这会在模型学习和预测上带来巨大问题。这会增加模型的方差，可能带来不稳定并降低泛化性能，也就是说，模型会变得不够稳健。异常值还会影响数据可视化，因为特征尺度会发生变化。

## 问题 7：描述处理数据集中异常值的策略。

回答：异常值可以通过多种方式处理，但最常用的三种方法是四分位距（IQR）技术、分位数技术和 z-score 技术。它们都非常相似，但功能略有不同。

对于 z-score 方法，通常我们会剔除 z-score 大于 +3/小于 -3 的数据点，可将其视为异常值。

在分位数方法中，我们将高于第99百分位数的任何值作为截断阈值，而低于第1百分位数的任何值被视为剔除并被认为是异常值。

IQR 是一种技术，涉及识别 Q3（第三四分位数）与 Q1（第一四分位数）之间的差异，并剔除低于 Q1 - 1.5 * IQR 或高于 Q3 + 1.5 * IQR 的数据点。

其他方法包括使用稳健模型，或不同模型的组合，甚至尝试修改异常值而不是丢弃它们。

## 问题 8：监督学习中的维度灾难是什么？

回答：维度灾难很有趣。随着特征集大小的增加，模型的性能和传统算法的计算性能趋于平均，没有进一步改善，有时性能还会下降。随之而来的是数据稀疏性、数据量增加、高维距离度量变得毫无意义等问题。计算复杂度和数据可视化变得具有挑战性，高维数据的可解释性也很困难。

像 one hot encoder 这样的技术极易导致维度爆炸，从而引发维度灾难。

## 问题 9：什么是数据缩放，为什么对某些机器学习算法是必要的？

回答：数据缩放与数据标准化密切相关，指将数据置于特定值范围内的过程，同时确保它们遵循特定格式。

假设我们有一个价格特征列，其范围从 1 到 10 百万单位。模型处理如此大的范围变得极其复杂，因此数据缩放的概念被用来将范围从大异质尺度（1 到 10 百万）降至 1 到 100 甚至 0 到 1。这有助于机器学习模型更快、更高效地处理数据，并避免大值特征主导模型学习过程。

L1 和 L2 是正则化的其他例子，它们会减少或惩罚大的系数值。因此，为了使特征具有同等重要性，进行特征缩放是必要的。

## 问题 10：什么是独热编码，以及何时对分类数据使用它？

回答：独热编码是将分类变量转换为模型友好格式的技术，使模型能够理解其表示为特定类别。

举例说明：有一个特征 gender，有 3 个唯一类别，分别是 Female、Male 和 Others。使用独热编码，gender 列将被扩展为三个新列 gender_male、gender_female 和 gender_others。不是单个列包含多个类别，而是多个列包含二进制值。假设某行是 others，则只有 gender_others 为 1，其余为 0。

## 问题 11：在什么情况下会选择标签编码而不是独热编码？

回答：独热编码倾向于在存在许多分类特征且每个特征具有大量唯一类别时导致特征爆炸。出于多种原因，性能之间总是有权衡。标签编码默认会在特征之间引入序关系，而独热编码不会带来任何额外关系；相反，会出现特征爆炸。

## 问题 12：什么是类别不平衡，为什么在监督学习中会成问题？

回答：类别不平衡是一种问题，其中某个标签的量相对于其他标签非常高或非常低。标签数量高的类别通常称为多数类，标签数量低的类别通常称为少数类。

假设我们有一个二分类问题，包含两个类别 Class A 和 Class B。不平衡的情况是 Class A 或 Class B 拥有超过 80% 或 90% 的记录。像 1:100 这样的比例高度不平衡，2:3 则是轻微不平衡。如果比例接近 1:1，则称其为平衡数据集。找到完全平衡的数据集极其困难且罕见，但通常我们会找到接近 1:1 比例的数据。

不平衡的比例会使模型以这样的方式进行调优，即它只期望高量标签，预测结果会产生偏差。因此，始终更倾向于为模型提供平衡数据。

## 问题 14：解释机器学习模型中偏差的概念。

回答：通常，机器学习模型包含两种形式的偏差。第一种偏差在数据收集和数据预处理阶段被识别出来，然后还有另一种更技术性的偏差，这实际上是大多数人在使用偏差一词时所指的意思。在机器学习中，偏差被定义为模型预测中固有的误差。当数据中存在模型不知道或不允许的关系时，模型施加约束就会发生这种情况。
