# **Support vector regressor**

A support vector regressor is a kind of ML algorithm employed in regression which among other things tries to predict a real value. **Support vector regression** (SVR) is far more flexible than linear models by searching for a hyperplane that comes as close as possible to the objects in the data space, within a certain level of generalization or error margin, in its attempt to properly span the input features and output values space. The strengths of SVR are its insensitivity to outliers, its capacity to handle non-linearity in the data utilizing kernel functions, and its suitability for large feature space. It is significant in understanding SVR in the context of ML because it plays a significant role in the current-day trending regression analysis when the traditional linear models do not work effectively.
