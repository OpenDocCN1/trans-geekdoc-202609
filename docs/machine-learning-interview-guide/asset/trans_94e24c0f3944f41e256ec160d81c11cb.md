混淆矩阵在分类评估中有多种用途：

- 准确率是 TP 与 TN 之和除以测试集中的总样本数。它大致估计了模型整体的有效性。
- 测试准确率的计算方式为 TP / (TP + FP)，衡量所考虑的模型对正类的准确程度。在误报成本较高的情况下，该指标很有用。
- 召回率（灵敏度）的计算方式为 TP / (TP + FN)，它表示模型识别所有正类样本的准确程度。当漏报正例（即假阴性）会带来惩罚时，这一点尤为重要。
- F1 分数可以计算为两倍重叠量除以结果集大小与精确率集合和召回率集合交集大小之和的比值。它以单个值提供了精确率与召回率之间经过深思熟虑的权衡。
- 准确率的计算方式为 TN / (TN + FP)，表示对所有负类样本的正确拒绝。
- **ROC 分析**：混淆矩阵用于绘制 ROC 曲线。改变阈值会导致 TPR 和 FPR 取不同值，从而展示模型结果。

### 阈值选择

在对实例进行分类的标准至关重要时，混淆矩阵有助于理解应针对各项度量选择何种阈值。

在分类问题中，混淆矩阵及其组成部分提供了关于模型性能的更多细节，以便评估其优点和缺点。因此，应使用这两个指标中的哪一个，取决于问题领域的具体背景以及与假阳性和假阴性样本相关的成本。

## 问题 9：讨论准确率作为不平衡分类任务评估指标的局限性。

**答案：** 准确率是分类问题中另一个流行的评估指标，但它不适用于不平衡数据集。

因此，不平衡数据集中的高准确率可能具有误导性；模型只需对大多数样本预测多数类，就能获得非常高的准确率。例如，当 95% 的样本属于负类时，一个对所有样本都预测为负类的分类器将获得 95% 的准确率，但它提供的信息却完全没有用处。这导致少数类得不到很好的处理，因为准确率的概念主要侧重于预测多数类的能力；因此，少数类可能被完全忽略。在异常检测任务中，异常属于负类，即少数类。

## 问题 10：描述自举法以及它如何用于交叉验证中的重采样。

**答案：** 这是一种重采样技术，常用于统计学和机器学习中，通过从原始数据集有放回地抽样来形成称为自举样本的伪数据集。需要注意的是，自举可以对行或列进行。这种方法效果良好，自举的概念可应用于从模型评估到交叉验证中重采样等广泛领域。以下是自举法及其如何在交叉验证中使用的说明：

- **自举法**：
  - **技术**：自举技术涉及从原始数据集中有放回地随机抽取 *n* 个数据点。这意味着原始数据集中的每个值都有可能被多次选中，而其他值则可能完全未被选中。这会生成一组新的随机数据。
  - **自举样本的生成**：结果是得到一个自举样本，其中部分记录重复出现，部分记录缺失。重复多次即可生成其他自举样本。
  - **变异与估计**：在估计统计量的抽样分布（无论是变异、均值还是其他参数）时，这是一种有价值的工具。它有助于确定原始值分布未知或复杂时统计量的变异程度。

自举可以通过以下几种方式纳入交叉验证过程：

- **自举交叉验证（自举 K 折）**：与 K 折交叉验证中为模型评估使用预定且不变的 *K* 不同，自举允许随机创建 *K* 折。这一过程使得每一折中可以有多个观测值，从而更准确地反映模型的性能。
- **自举聚合（Bagging）**：在集成学习中，自举常用于 bagging。Bagging 是一种使用自举样本训练多个模型，并利用平均的优势来减少过拟合的技术。
- **另一种利用取自自举样本之外的其他样本进行的验证称为 OOB（袋外）验证。这类 OOB 样本可用于验证，从而估计模型在未见数据上的性能。**

以下是自举在交叉验证中的一些优点：它稳健，偏差减小；从现有数据中得出多个验证样本，并且有一个总体预测估计。

自举的缺点是计算成本较高，并且在某些情况下预计会出现过拟合。

## 问题 11：学习曲线的目的是什么？在监督学习中如何解释它们？

**答案：** 学习曲线是监督机器学习过程中使用的图形表示，它描述了随着模型在逐渐增多的训练数据上进行训练，其性能如何变化。它们用于若干重要功能，有助于测试模型的行为和泛化能力。学习曲线显示了模型在训练集和验证集上的效率如何随训练样本量的增加而变化。它们展示了模型的训练和验证性能如何演变，这大大有助于向非技术成员和业务领域专家进行解释。

它也可以作为检测过拟合和欠拟合的工具。因此，同一条曲线将有助于比较进行超参数调优的不同模型的性能。
