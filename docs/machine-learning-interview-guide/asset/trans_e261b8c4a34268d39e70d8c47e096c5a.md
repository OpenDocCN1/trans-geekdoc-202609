## 关于作者

Rehan Guha 是一个多才多艺的人，身兼研究员、学者讲师、作家和社会分析/评论员等角色。Rehan 最初是一名编码员和开发人员，现在热衷于机器学习和算法。他的主要关注领域包括基础科学、技术、哲学和社会经济学。他毕业于加尔各答工程与管理学院，并获得了印度理工学院卡拉格普尔分校（IIT-K，AICTE 认证课程）的深度学习研究生证书。

Rehan 的研究兴趣包括优化问题、可解释人工智能、深度学习架构、机器学习和算法思维。他在学术和开放来源撰写并发表了多篇文章，并拥有多项专利，其中一项专门献给印度陆军。在八年的信息技术经验中，他接触过不同的业务部门，包括银行、医药、法律、保险、货运物流和电信，尤其为一项解决争议银行和信用风险的方案获得了专利。

目前，Rehan 撰写了一本名为《Machine Learning Cookbook with Python》的书，由 BPB Publications 出版。他发表了多篇论文，申请了多项专利，并在 NSF 资助和 NASA 赞助下对 SoilScope 等活动进行了竞争性贡献。他是一位教育者，曾在不同大学举办工作坊和研讨会，发表过自己的知识，并参与了开源软件贡献，例如 Google TensorFlow Addons。

除了工作之外，Rehan 是开放/免费知识的坚定信仰者，并直接参与联合国世界粮食计划署（WFP）和教育平等事业。他是一位积极的教育者，也是为有需要的人提供帮助的个人发展教练。Rehan 也是一位摄影爱好者，喜欢通过摄影这一媒介拍摄并重塑自己，偶尔也会享受他最初的爱好——用铅笔和墨水绘画。他在“世界河流”计划下完成的木刻素描被保存在伦敦英国文化协会博物馆，并作为展品在欧洲和亚洲巡回展出。在个人生活中，Rehan 不工作时会打非职业乒乓球和足球，并喜欢旅行，在旅行中他得以接触不同的文化和美食。
