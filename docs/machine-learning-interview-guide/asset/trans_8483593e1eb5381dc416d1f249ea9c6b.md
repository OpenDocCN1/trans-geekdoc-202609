## 逻辑回归
逻辑回归是机器学习中应用的最简单的统计方法之一，它围绕超平面绘制边界，以便在二分类问题中将两个类别分开。与预测连续输出的线性回归模型不同，逻辑回归应用 sigmoid 函数，因此适合估计特定事件发生的几率，这在邮件过滤（垃圾邮件检测）、医疗诊断和客户流失等场景中非常有用。由于逻辑回归简单、易于解释，并且在数据线性可分时表现良好，因此它是理解并在概念上构建更复杂机器学习技术的基础。其直接了当的方法为掌握更高级的模型奠定了坚实的基础。

### 问题 1：解释逻辑回归中的优势比和对数优势这两个术语。
答案：在逻辑回归中：
- 1. **优势比（Odds ratio）**：优势比是一个关键概念，有助于解释预测变量（自变量）与结果（因变量）之间的关系。它表示事件发生的概率与事件不发生的概率之比。以下是更详细的分解：它衡量预测变量每变化一个单位时优势的变化。优势比为 1 表示没有变化，>1 表示优势增加，<1 表示优势减少。计算公式为 ，其中 是预测变量的系数。
- 2. **对数优势（Logit）**：它是优势的自然对数，将预测变量与结果之间的关系线性化。在数学上，
$Log-odds = ln\left(\frac{P(Event)}{1-P(Event)}\right)$
对数优势可以取任意实数值，因此适合在逻辑回归中进行线性建模。

### 问题 2：逻辑回归是如何训练的？目标函数（损失函数）是什么？
答案：在逻辑回归中，训练过程涉及对预测变量对应的系数或权重进行估计确定，从而使结果能够最佳地拟合数据。这通常可以通过称为**最大似然估计（MLE）**的方法来实现。目标函数也称为损失函数，其目的是量化模型预测与预期结果之间的偏差。训练过程如下：
- **初始化：** 初始化权重或系数（通常为较小的值或较小的随机值，如 0 或接近 0）。
- **预测：** 用逻辑函数表示预测概率的结果。
- **损失计算：** 这一步通过损失函数来衡量预测值与实际结果之间的差距。
- **优化：** 优化变量的系数，使损失达到最小。常用的优化技术包括梯度下降等。
- **收敛：** 算法迭代更新参数，直到损失函数收敛到最小值（或达到指定的迭代次数）。

目标函数（损失函数）如下：

逻辑回归主要使用逻辑损失，也称为**对数损失**或**交叉熵损失**，作为其损失函数。

对于单个观测值，其表达式为
$$-(y \cdot \log(p) + (1 - y) \cdot \log(1 - p))$$，其中 \(y\) 是实际结果（0 或 1），\(p\) 是预测概率。

所有观测值的总损失是上述各自损失的均值。在训练中，目标是使该损失最小化，这本质上是在优化模型预测概率的能力。

总而言之，逻辑回归通过反复计算系数来降低对数损失的程度，从而希望在二分类问题中提升模型的性能。

### 问题 3：逻辑回归中的 MLE 方法是什么？
答案：在逻辑回归中，MLE 是一种估计模型参数（系数）的技术。

简要说明：
- 似然函数：对于一组给定的参数，似然函数估计观察到当前一组结果（即二元响应）的概率。在逻辑回归中，它是在假设潜在分布为逻辑分布的情况下，观察到实际结果值的似然函数的乘积。
- 对数似然函数：为了简化表达式，通常使用对数似然函数。它是似然函数的自然对数。对似然函数的优化与对对数似然函数的优化是等价的，因为它们描述的是同一件事。
- 优化：首先，其思想是估计使对数似然函数达到最大似然的参数 θ。这有时可以通过计算上高效的方式完成，例如采用梯度下降等更精细的方法。
- 系数估计：估计值称为 MLE。它们是观测结果的预测值，尤其是在对模型进行逻辑回归分析时。

简而言之，逻辑回归中的 MLE 通过利用对数似然函数来估计观测结果的似然性，并利用优化方法对该函数进行优化。

### 问题 4：逻辑回归阈值的作用是什么？如何确定阈值？
答案：逻辑回归阈值用于将预测概率转换为特定的离散类别集合。二分类任务借助模型的概率估计，将观测结果分类为正类（1）或负类（0）。

逻辑回归的作用如下：
- 逻辑回归的输出是介于 0 和 1 之间的概率。
- 阈值充当决策边界；这意味着如果预测概率大于阈值，则该观测被视为正类，否则为负类。

我们可以通过以下方式确定阈值：
- 通常，接受的阈值设为 0.5，即如果预测概率大于或等于 0.5，则该观测被视为正类。
- 阈值的选择取决于具体应用和误分类的成本（假正例和假负例）。例如，在医疗诊断中，尽量减少假负例（漏诊疾病）可能更为关键，这可能需要对阈值设得更低，以捕获更多正例。
- 阈值水平会影响模型的性能，以及精确率、召回率和 F1 分数。
