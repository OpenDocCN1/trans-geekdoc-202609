-   **目标：** 识别一个超平面，使其能够对大多数数据点提供正确的分类，同时只误分类其中有限数量的点。

### 在噪声或重叠数据中的应用：

-   **灵活性：** 软间隔 SVM 用于因噪声或重叠导致某一类中单个实例被误分类到另一类的概率非常高的情况。
-   **鲁棒性：** 由于算法允许一定程度的误分类，它们使算法对异常值以及数据集中的噪声具有鲁棒性和可靠性。
-   **参数（C）：** 调节两个类别之间间隔与错误率之间的权衡；较小的 C 值会产生更宽的容错间隔。

## 问题 12：与其它分类算法相比，SVM 的优势是什么，在什么场景下特别适用？

Answer: SVM 的优势是：

-   在高维空间中有效。
-   对过拟合具有鲁棒性。
-   由于使用支持向量，内存效率得到改善。
-   在核函数的选择上具有灵活性。
-   优化全局解，不会陷入局部最小值。

## 问题 14：讨论使用 SVM 进行分类任务相关的潜在挑战或局限性。

Answer: 使用 SVM 的一些局限性是：

-   **对缩放的敏感性：** SVM 对输入特征的尺度差异高度敏感。
-   **核函数的选择：** 许多因素会影响性能，必须选择核函数，并且设置调参可能很困难。
-   **计算复杂度：** 训练 SVM 的复杂性有时会导致训练时间效率低下，因此不适合大数据或近实时处理。
-   **内存使用：** SVM 可能占用大量内存，尤其是在高维空间中运行时。
-   **处理噪声数据的困难：** SVM 也会受到数据中的噪声和异常值以及样本错误标记的影响。
-   **二元分类：** 虽然按设计是二元分类，但 SVM 可以应用于多类问题；实现它们的方法可能并不那么明显。
-   **不平衡数据：** 不平衡的数据集也会使预测变得敏感，尤其是在被拉向尺度的错误一侧时。
-   **可解释性：** SVM 可能难以解释特征对所做分类决策的贡献。

## 问题 15：在什么情况下 SVM 可能比其他分类算法更不适用或效率更低？

Answer: SVM 可能比其他分类算法更不适用或效率更低的情况是：

-   Large datasets: SVMs are slower when there is a large number of samples; other algorithms can take less time in training.
-   High-dimensional data: Tree-based methods may be superior in high-dimensional spaces, while SVMs might have some issues here if the wrong kernel is used. SVMs often perform well in high-dimensional spaces, especially when using appropriate kernels.
-   Noise and outliers: SVMs are not tolerant to noise; perhaps, such models as random forests can handle noise differently.
-   Interpretability requirements: If, to interpret model results is especially important, more straightforward solutions as a decision tree may better serve.
-   Imbalanced datasets: SVMs are not good with decision-making for imbalanced data; possibly better to use classification models like ensemble with better class weights.
-   Non-linear decision boundaries with limited resources: When it comes to limited resources, linear models could perhaps be regarded as more suitable for working with non-linear boundaries.
-   Probabilistic output: When working with probabilistic outputs, SVMs are not useful in directly providing it, useful in this area are logistic regression or Naïve Bayes.
-   **特征数量多而样本有限**：SVM 可以处理特征数量多的情况，但特征选择可能仍然是必要的。
-   **易用性和灵活性**：如果想要在原型开发方面快速解决方案或更好的可用性，那么逻辑回归或决策树模型会更好。
-   **在线学习**：SVM 不能通过整合新数据来持续更新模型；对于在线学习，我们有随机梯度下降等。

## 模型评估

分类模型的模型评估是通常使用的统计度量，用于确定分类模型做出的正确分类数量。它使用准确率、精确率、召回率、F1 分数和 AUC 等有效性评估指标在未见数据上执行。模型评估至关重要，因为它能够确定模型的整体性能，而不仅仅是在训练集上运行时的性能。这些知识对于 ML 中做出模型选择和调优的明智选择至关重要，以及决定是否部署新模型、修改模型或现有模型以避免不可靠或预测能力弱的系统。

## 问题 1：监督学习中的过拟合是什么，如何防止？

**Answer:** 过拟合是指给定模型在训练数据上表现良好而在测试数据上表现不佳的情况。这表明模型不再是通用模型，而是受训练数据具体影响，在预测时试图模仿结果。

在使用交叉验证和一些专门的模型（如随机森林）时，很有可能防止这种情况。除了模型选择之外，还有多种防止过拟合的策略，例如交叉验证、正则化、简化模型、提前停止、剪枝（在决策树中）以及数据增强。

## 问题 2：定义欠拟合并描述其后果。

欠拟合是指模型即使在训练数据和测试数据上也表现很差的情况。从中我们可以得出模型欠拟合且性能不好的结论。

对于欠拟合，我们应用与处理模型性能相同或相似的方法，甚至通常涉及增加模型复杂度。此外，如果没有任何方法奏效，我们可以得出算法类型不适合数据集以及所设定的目标。

## 问题 3：为什么在监督学习中，尤其是在高风险应用中，模型可解释性很重要？

我们看到可解释性是有用的，并在现实生活中具有实际应用，特别是在高风险用途中。对于终端用户来说，从模型生成预测相对非常简单，但模型几乎像一个黑盒子。这些是使用 ML 模型的某些负面影响，因为相关专业人员不知道模型是如何得出特定结果的，或者为什么某个记录会输出特定值。现在，为了更好地理解“为什么”部分，可解释性的重要性就显现出来了。

对于高风险应用，输出会执行许多验证，并且有一些标准机构监督 ML 的可解释部分。

为了简单起见，让我们考虑银行领域的例子，更确切地说，是信贷风险部门。目前，贷款部门使用一个 ML 模型来确定给定客户是否适合成为贷款候选人。贷款不是那么快，客户质疑银行，询问为什么贷款未通过，然后，模型的这种可解释性就发挥作用，帮助贷款官和最终消费者理解贷款被拒绝的原因。
