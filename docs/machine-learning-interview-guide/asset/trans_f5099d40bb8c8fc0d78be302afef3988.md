## 问题5：讨论特征工程在时间序列分析中的使用。哪些特征可能与建模相关？

**答案**：特征工程是时间序列分析中的关键步骤之一，意味着基于原始时间序列数据生成新特征。因此，工程师设计良好的特征以提升时间序列模型的性能至关重要。

以下是时间序列分析中特征工程的一些方面及相关特征的示例：

- **滞后观测值**：目标变量或相关特征在当前和/或过去某个时间点的值。示例：所讨论的时间序列的历史值或其他变量在前些步骤中的值。换句话说，将目标变量或其他相关变量的过去值纳入模型，例如使用前一天、一周或一个月的值作为预测未来值的预测变量。
- **滚动统计量**：在特定时间段内进行平均和移动，并计算统计数值以揭示趋势或系列事件。示例：在预定的时间段/窗口内的移动平均、移动标准差或任何其他点统计量。
- **基于时间的特征**：从给定数据中提取的时间元素，包括星期几、月份、季节或年份。示例：星期几、月份、季节或年份的指示变量，有助于捕捉季节性或周期性。
- **移动平均**：在固定时间段内，在特定聚合水平上取值的算术平均值，目的是抵消短期波动。示例：移动平均如**简单移动平均**（**SMA**）或指数移动平均，用于拟合模式和平滑数据。
- **距上次事件的时间**：自某个日期/时间点以来经过的时间，即某个事件发生与现在之间的时间。示例：对于时间序列，自上次峰值、谷值或其他重要事件以来观测值的数量。
- **自相关**：时间序列与其过去值的相关性估计，显示随时间变化的依赖性。示例：不同滞后的自相关，以衡量依赖性的强度和周期性。
- **季节性分解成分**：将时间序列分解为趋势、季节性和残差所得到的子产品。示例：分解的第一步是提取趋势、季节性和残差成分以供进一步检查。
- **时间平移特征**：特征在时间上移动至另一个时间条件，以增加更多时间上下文。示例：使用时间滞后来分析不同时间点的关系，因为特征在时间上向前或向后移动。
- **波动性度量**：总结给定时间序列的波动或变化的度量。示例：标准差或变异系数等指标，用于确定变异程度。
- **互相关**：时间序列与其他需要分析的相关变量之间的横截面回归。示例：与其他变量的关系，是否存在其他影响，或者序列是否依赖或相关。
- **循环特征**：包括在时间序列中表现出循环行为的变量。示例：对时间相关特征的时间差取对数，并使用正弦和余弦函数进行变换，因为存在周期性。
- **历史百分位排名**：以百分位数表示，观测值与历史值的差异程度。示例：为了获得普通值和稀有值，我们使用了后三个十分位数（第10、25、75百分位）和最后两个百分位数（第90和第50）排名。
- **指数衰减**：对数据进行平均时优先使用指数权重，以便为最近的数据分配更高的权重。示例：SMA、**加权移动平均**（**WMA**）、**指数移动平均**（**EMA**），使用基于业务决策节奏计算的不同系数。
- **交互项**：当特征的功能表现预示其组合效应与各个效应之积成比例，或者特征的功能表现预示所有特征的总贡献相对量是各特征单独贡献的加总时。在产品或总和法中，将两个相关变量组合以估计联合影响或交互作用。

因此，特征工程涉及对时间序列数据及其属性以及分析目标的诸多考虑。所选特征取决于问题背景以及研究人员或从业者从时间序列中感兴趣的信息。这些特征对于提升时间序列模型的性能至关重要，其中实验和领域知识是选择和设计与模型相关的属性时的关键组成部分。

## 问题6：将时间序列数据集拆分为训练集和测试集时，关键考虑因素是什么？

答案：在将时间序列数据集细分为训练集和测试集时，需要考虑某些关键特征，尤其是在模型的开发和评估过程中。

以下是关键考虑因素：

- 时间顺序：时间序列数据应按时间先后排列。训练集的观测值应该较早，而测试集的观测值应该较晚。这是因为时间序列数据的固有特征与现实生活情况一致。示例：对于2010年1月至2020年12月的月度销售数据，使用2010年1月至2018年12月的数据进行训练，使用2019年1月至2020年12月的数据进行测试。
- 时间间隔：确保训练集和测试集之间存在明显的时间差。这有助于降低模型仅在训练数据上表现良好的可能性；换言之，模型的实际预测能力是在未见过的数据上测试的。
- 使用验证集：如果需要调整模型，除了训练集和测试集之外，使用单独的验证集是有用的。这有助于通过迭代调整模型，但测试数据集不受此过程影响。
- **处理多重拆分**：如果需要更准确的模型且数据量不足以同时用作训练和测试数据，可以使用多重拆分。这涉及构建不同的训练集和测试集，其中一个包含不同的时间分布，以分析所创建模型的稳定性。
- **考虑季节性**：如果过去的时间序列存在某些季节性问题，则每个拆分都应包含所有季节。这有助于模型学习并扩展其对不同季节性趋势的适用性。
- **处理随时间变化的变化**：当我们遇到数据的分布随时间发生变化时，应小心处理。业务人员和分析师可能需要在某个时候更改模型，因此训练集应包含这些时期的数据。
- 数据变换：可能需要对数据进行变换或预处理；如果如此，这些步骤应以统一的方式应用于训练和测试数据。例如，应根据所使用的训练集的性质应用归一化或差分技术，并且对测试集采用相同的处理。
- 避免数据泄漏：为此，在数据预处理阶段避免来自未来的信息泄漏。建议不要使用需要未来信息的特征或变换，因为它们会增加模型拟合度量。
