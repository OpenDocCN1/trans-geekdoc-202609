# Question 6: What is the role of weak learners in the context of GBTs?

Answer: In the context of GBT, weak learner is defined as a model, that generally is a shallow decision ree, with weak learning ability, meaning that it can learn slightly better than a pure random model. GBT is trained sequentially, and every weak learner corrects the errors of the previously generated GBT ensemble of weak learners. It comprises an error minimization technique using gradient descent optimization, incorporation of the model augmented with the one from the new weak learner, and integration of the new learner into the weighted ensemble. In the final step, predictions of all weak learners are averaged and a learning rate regulates the input of every weak learner. This growing process of ensemble is repeated many times to make an outstanding and accurate model for prediction.
