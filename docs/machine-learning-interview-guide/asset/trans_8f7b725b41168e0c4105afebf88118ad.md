
- **均方根误差（RMSE）**：均值标准误（SEM），是 MSE 的平方根，以与数据相同的计量单位给出误差度量。
- **平均绝对百分比误差（MAPE）**：计算绝对比例误差的平均值，衡量预测值与实际值之间的差异。
- **AIC 或 BIC**：模型的信息准则用于说明模型拟合度与复杂度之间的平衡，准则值越小，模型拟合度越高。
- **残差诊断**：检查残差，确保其遵循的模式是正常的，并且彼此独立。
- **预测精度**：在留出期之后，将预测值与实际值进行交叉验证，以检验所用模型或技术的准确性。

在这些工具中，你可以借助诊断图，用这些度量工具来衡量 SARIMA 和 SARIMAX 模型在捕捉时间序列数据模式方面的充分性和拟合度。

## 多元时间序列

多元时间序列分析是一种对多个变量随时间变化进行分析的场景，目的是发现其中某些变量之间的相关性。单变量时间序列数据分析只考虑一个变量，而多元时间序列分析则同时分析多个数据流。它可以更好地逼近因素相互作用的多元系统；可应用于金融、气象或处理传感器收集的数据。多时间戳向量的分析在机器学习中很重要，因为它有助于获得更高的预测率，增进对变量关系的理解，并提高系统及后续决策的效率。

### 问题 1：与单变量数据相比，分析多元时间序列数据面临哪些挑战？

答案：与单变量数据相比，分析多元时间序列数据存在若干挑战。具体如下：

- **复杂性增加**：多元数据中包含具有不同时间序列特征的各个变量，这使得分析更加复杂。
- **维度**：多元数据具有较高的维度，这使得显示、理解和分析这些数据变得困难。
- **依赖结构**：识别和估计变量之间的相互依赖关系是分析方法的关键，但当变量超过两个时，这一过程更加复杂。
- **数据预处理**：由于数据存在相互依赖关系，多元数据中处理缺失值、异常值和缩放的方法与单变量数据相比有所不同。
- **建模选择**：一般来说，为多元分析选择合适的模型需要考虑许多因素，因此模型选择过程以及对所选模型的验证变得更加复杂。
- **解释**：由于涉及的变量和交互作用更多，解释多元分析得出的结果更加困难。
- **计算复杂度**：在多元模型中估计模型参数和进行预测的过程比单变量模型的计算量更大，耗时更多，尤其是在处理大型数据文件时。

为了克服这些挑战，在多元时间序列分析中，应全面考虑数据性质、备选适当模型的特征以及合适的验证方法，以获得可靠且可解释的结果。

### 问题 2：预测多元时间序列数据有哪些不同的方法？

答案：预测多元时间序列数据的不同方法包括：

- **VAR（向量自回归）**：根据每个变量自身的过去值以及其他变量的过去值对各变量进行滞后处理，并能同时提供每个变量的预测。
- **机器学习模型**：例如随机森林、梯度提升、支持向量机或神经网络等一些方法，可以识别变量之间的多种依赖关系，尤其是非线性关系。
- **状态空间模型**：旨在表示系统状态和观测方程，可以提供一种更通用的方式来处理依赖性和模糊性。
- **动态因子模型**：使用主成分分析，通过将数据分解为公共因子和特定效应，提取变量的聚合信号进行预测。
- **VECM（向量误差修正模型）**：通过引入协整向量来扩展 VAR，该向量可以识别短期波动和长期关系。
- **分层预测**：在考虑层次结构互联的同时，必须准确预测不同聚合层级上的指定单个序列。
- **集成方法**：通过使用更多样化模型的原则，避免过度依赖单一模型的偏差和不确定性，进行模型组合以实现更好的预测。

所有这些方法各有优缺点，应用选择取决于数据性质、预测的时间尺度和具体需求。因此，通过将所介绍的各种预测模型变体结合使用，分析师可以为多元时间序列数据创建更有效的模型。

### 问题 3：格兰杰因果关系检验如何帮助识别多元时间序列数据中的因果关系？

答案：在分析变量间关系时，格兰杰因果关系是一种用于识别一个时间序列变量是否有助于预测另一个变量的技术，从而显示潜在的因果关系。

**其工作原理如下：**

- **时间滞后分析**：格兰杰因果分析用于判断一个变量的过去值是否能够预测另一个变量的未来值，从而暗示因果关系。
- **统计检验**：为此，它对序列的自回归模型进行统计检验，分别比较包含和不包含潜在因果变量滞后值的情况。
- **解释**：若使用滞后值能显著提高预测能力，则表明存在格兰杰因果关系，意味着该被测量变量具有先导性且可预测，但并不一定意味着它就是原因。
- **方向性**：根据格兰杰因果关系检验的结果，可以确定因果关系的性质，因为一个变量的加入可以增强另一个变量的可预测性，但反之则不然。

总之，在多元时间序列（MVTS）数据的背景下，建议使用格兰杰因果关系检验来识别多个变量之间的因果关系；但在解读检验结果时需谨慎，最好寻找更多证据来确凿证明因果关系。

### 问题 4：能否解释一下多元时间序列分析中 VAR 模型的概念？

答案：VAR 模型是一类多元时间序列模型，用于在时间序列框架内对不同变量之间的动态交互进行建模。总体而言，在 VAR 模型中，每个变量都基于其自身的过去值以及其他变量的过去值进行回归。这意味着每个被识别的变量都必须是其自身过去值以及系统中其他变量过去值的函数。

带有 $p$ 阶滞后的 VAR($p$) 模型的一般形式为：

```
Y_t = A_1 Y_{t-1} + A_2 Y_{t-2} + ... + A_p Y_{t-p} + \epsilon_t
```

其中：

- $Y_t$ 是时间 $t$ 的 $k \times 1$ 变量向量。
- $A_1, A_2, ..., A_p$ 是滞后值的系数矩阵。
- $\epsilon_t$ 是时间 $t$ 的 $k \times 1$ 误差项向量。

VAR 模型因其内生性，能够分析系统中变量之间的反馈和交互作用。它们广泛应用于经济学、金融学及其他相关学科，用于研究两个或多个变量随时间变化的相互关联模式、预测、政策评估等。再次强调，VAR 模型中的 $p$ 指的是模型中包含的滞后阶数。选择合适的阶数对于 VAR 建模同样至关重要，可以通过信息准则、序贯检验或任何其他被认为相关的信息来确定。总的来说，VAR 模型为分析多元时间序列数据和描述系统中所有变量之间的交互作用提供了一种相当灵活的方法。

### 问题 5：VAR 模型的关键假设有哪些？

答案：VAR 模型的关键假设包括：

- **线性**：变量之间的相互依赖关系是直接的或正向的。
- **平稳性**：时间序列变量是平稳的，这意味着所考虑的任何统计特征都不随时间变化。然而，事实上，最流行的模型（如 VAR）可以包含一些本质上非平稳的变量，只要它们与其他变量存在协整关系。
