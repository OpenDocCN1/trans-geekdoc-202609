

## 问题7：解释在执行降维时数据缩放和归一化的重要性。

**答案**：数据缩放和归一化在降维中至关重要，原因如下：

- **贡献均等**：这保证了所有特征都处于平衡状态，没有任何一个特征会主导整个尺度空间。
- **降低敏感性**：降低降维算法对其特征幅度的敏感性，从而强调特征维度之间的关系。
- **改善收敛性**：改进应用于降维部分的优化算法的集成过程。
- **单位一致**：解决不同测量单位带来的问题，使特征对降维过程产生标准化的影响。
- **保持距离**：因此，它保留了各点之间的相对位置以及点之间的特定距离。
- **数值稳定性**：解决因特征尺度变化而导致的数值稳定性问题。
- **可解释性**：它产生的表示具有相似的特征范围，与之前相比更容易解释。
- **与度量兼容**：确保距离具有实际意义：当降维后需要进行聚类或其他基于距离的分析时，这一点尤为重要。
- **提升泛化能力**：降低模型对特征尺度的敏感性，进而有助于提高模型对未见数据的泛化能力。
- **与正则化兼容**：在特征被缩放的情况下（通常是需要缩放特征时的情形），有助于高效地应用正则化。

总而言之，缩放和归一化增强了降维方法的有效性、准确性和可用性，使其更加高效和通用。

## 问题8：数据的稀疏性在降维算法中扮演什么角色？

**答案**：在降维算法中，数据的稀疏性所扮演的角色如下：

- **计算效率**：数据密度越低，计算越容易，因此像稀疏主成分分析（Sparse PCA）这样利用数据中稀疏模式的算法具有优势。
- **内存效率**：稀疏表示不需要存储大量的零值，从而可以在有限的内存空间内处理高维数据集。
- **特征选择**：它可用于特征选择，只利用重要的特征，例如在许多算法（如稀疏PCA）中就是如此。
- **可解释性**：这使稀疏表示更具可解释性，因为它强调了有助于理解数据组织的关键特征。
- **降噪**：由于稀疏属性的存在，可以清理数据并去除不相关的特征。
- **正则化**：这通过使用诸如L1范数之类的技术实现，该技术确保特征数量保持较少，即保持稀疏性。
- **特征压缩**：稀疏表示消除了矩阵中的零元素，这在数据的存储和传输方面非常有用。
- **改进的泛化能力**：在处理稀疏表示时，通常对未见数据有更好的校准效果，这对所有的降维模型都非常重要。
- **应对维度灾难**：因此，稀疏性缓解了维度灾难问题，使表示对高维性的敏感度降低。

稀疏的程度受到数据特征以及所应用的特定算法的影响；利用稀疏性可以产生更有效、更易理解且更易传输的降维结果。

## 问题9：距离度量的选择如何影响降维技术的结果？

**答案**：所选的距离度量对处理高维数据的不同方法的结果有着深远的影响。以下是其影响的简要说明：

- **邻域保持**：这意味着距离度量会影响数据点间邻域关系的形成。诸如t分布随机邻域嵌入（t-SNE）和等距映射（Isomap）等许多方法都依赖于邻域关系的保持，而距离的选择会影响“接近”的定义。
- **聚类分离**：距离度量在主要基于聚类的降维技术中非常核心。诸如欧氏距离等标准距离度量依赖于前者的选择，因为它定义了聚类在降维空间中的分离程度。
- **度量压力**：多维缩放（MDS）旨在最小化压力，即原始空间与降维空间之间成对距离差异的度量。距离的选择直接影响压力，反之亦然，这决定了嵌入的质量。
- **保持全局结构**：距离度量有助于维护数据中的全局结构。例如，马氏距离涉及协方差结构，这在某些情况下可能很重要。
- **对噪声的鲁棒性**：距离度量影响降维对噪声点或异常值的敏感性。同样需要注意的是，在进行比较时，某些距离度量可能比其他度量对异常值更敏感。
- **维度灾难**：已经证明，在高维空间中，距离度量会影响降维过程。某些度量可能更适合测量高维数据中的重要距离。
- **流形学习**：大多数算法，如局部线性嵌入（LLE）或Isomap，都致力于保持这些几何结构。距离度量的选择会影响这些局部几何结构的量化方式，从而影响距离的保持方式。
- **对特征尺度的敏感性**：某些距离度量依赖于特征尺度的差异。如果需要，数据标准化可能是确保所选度量正确区分相似性级别的另一步骤。
- **稀疏数据处理**：当样本较少时，考虑距离度量也应考虑稀疏程度这一事实可能至关重要。例如，观察到马氏距离比欧氏距离更能有效地处理稀疏数据。
- **特定领域考量**：需要确定最适合特定领域和数据特征的距离度量。例如，文本数据最常用的度量是余弦相似度。

## 问题10：讨论线性和非线性降维方法之间的权衡。在什么情况下你会选择其中一种而不是另一种？

**答案**：线性和非线性降维之间的权衡见表1.1：

|  | 线性 | 非线性 |
| --- | --- | --- |
| 可解释性 | 线性方法提供了清晰的解释，因为它们产生原始特征的线性变换。每个维度对应于原始特征的线性组合。 | 非线性方法，如t-SNE或统一流形逼近与投影（UMAP），由于它们捕获的复杂关系，通常会导致嵌入的可解释性较差。 |
| 计算复杂度 | 线性方法计算效率高，并且通常有封闭形式的解。它们可以很好地扩展到大型数据集和高维度。 | 非线性方法，尤其是那些基于优化的方法，计算成本可能很高，使其不太适用于大型数据集。 |
| 全局结构与局部结构的保持 | 线性方法能很好地保持全局结构，使其适用于全局关系重要的任务。 | 非线性方法擅长保持局部结构，并捕捉数据中复杂的模式和聚类。 |
| 对噪声和异常值的鲁棒性 | 线性方法对噪声和异常值的鲁棒性可能较差，而 | 非线性方法对噪声和异常值提供了更好的弹性。 |
