- 线性假设：PCA 的另一个缺点是它预设变量之间存在线性关系，因此当实际关系为非线性时（这往往是常见情况），它可能不太有用。
- 方差的保留：另一方面，PCA 保留了大部分方差，但并未涵盖那些对聚类可能至关重要却具有低方差的特征。
- 对异常值的敏感性：在异常值敏感性方面，PCA 在存在异常值时可能很脆弱，这会影响主成分的估计，并进而影响聚类结果。
- 分类数据的处理：PCA 存在一些局限性，因为它主要面向数值数据，不能直接处理分类变量，可能需要特定的转换步骤，而这些转换可能会导致信息丢失或数据失真。

了解这些局限性有助于你在聚类任务中正确应用 PCA，并在适用的情况下考虑其他方法。

## 问题12：你能解释一下 PCA 与解释方差之间的关系吗？

### 回答：关于 PCA 与解释方差之间关系的简明解释如下：

- 主成分捕获的方差：PCA 的每个主成分都保留原始数据集中的一定方差。第一个主成分解释的方差最大，第二、第三……第 k 个主成分解释的方差依次减少。
- 累积解释方差：数据中的总方差是数据集的整体变异量。累积解释方差是前 k 个主成分的总变异量，通过将截至目前每个成分所贡献的方差相加得到。
- 主成分的选择：在决定提取多少个因子时，分析人员倾向于使用累积解释方差等标准。他们希望保留足够多的主成分，以包含数据总变异的一定比例（例如 70%-95%）。
- 解释：两个数据子集中的方差比例体现了每个主成分在展示数据变异和组织结构方面的重要性。因此，解释方差较高的主成分被认为在理解数据中的重要趋势和依赖关系方面更具意义。

总之，PCA 和解释方差是相互关联的两个过程，因为 PCA 侧重于识别包含最大方差的主成分，而分析人员则利用累积解释方差来决定在分析中需要保留的因子数量。

## 问题14：应用 PCA 后，如何评估聚类结果的质量？

回答：要在应用 PCA 后评估聚类结果的质量，可以执行以下操作：

- 轮廓系数：衡量一个对象与其所属聚类的紧密程度以及与其他聚类的差异程度；取值范围为 0 到 1，越接近 1 表示聚类越紧密。
- 惯性：专门用于 k-means。它计算聚类的紧凑性，即每个样本相对于其质心的距离平方和。
- 可视化检查：在降维后的空间（如前两个主成分）中可视化聚类数据点，以便检查聚类的分离程度和离散程度。
- 领域知识：为了检查聚类在特定数据场景中的适用性和可解释性，可以运用常识理解或使用收集到的真实标签。
- 聚类稳定性：通过测试某些特征的影响来评估聚类解的稳定性，例如参数设置的小幅变化或随机起始点，可使用自举法和重采样等程序。
- 外部验证：如果已有真实标签，推荐使用三个指标，如调整兰德指数（ARI）、归一化互信息（NMI）和 Fowlkes-Mallows 指数（FMI），来衡量真实标签与聚类结果之间的相似性。

这些方法有助于理解在应用 PCA 技术降低风格计量文本数据维度后，所得到的聚类结果的质量、一致性和可靠性。

## t-分布随机邻域嵌入

t-SNE 是机器学习中的一种高级数据可视化工具，有助于在二维或三维空间中分析高维数据集。它旨在尽可能融入数据的局部结构，同时揭示数据的全局结构。因此，它非常适合大型数据集的聚类和其他探索。通过使高维空间中相近的点在低维空间中彼此靠近、相距较远的点彼此远离，t-SNE 有助于揭示数据的底层结构，从而轻松识别高维数据点中的聚类或模式。这种直观地可视化和评估聚类的独特能力，在模型解释、特征选择以及评估数据分布效果方面具有重要价值。

## 问题1：什么是 t-SNE，它如何用于聚类？

回答：t-SNE 是一种重要的算法，用于将高维数据转换为低维（通常是二维或三维）以便可视化。由于在高维数据的低维表示中，相似的数据点会彼此靠近，因此它能在局部和全局上保留数据的邻域关系。t-SNE 在聚类中并不常用，而更多用于数据探索阶段，帮助你在将数据输入聚类模型之前熟悉数据及其模式。它改进了探索性数据分析和聚类结果，有助于定义聚类及其相互关系。

## 问题2：你能解释一下 t-SNE 在聚类中的主要目标吗？

回答：就聚类而言，t-SNE 的目标是将高维数据有效投影到低维空间，同时大大保留数据结构。作为一种高维数据可视化技术，t-SNE 的目标是将具有相似高维坐标的相似数据点映射到 t-SNE 嵌入的低维空间中的邻近点，从而揭示数据的结构。在聚类情境下，t-SNE 有助于发现所需的聚类及聚类之间的关系，并有助于可视化数据、理解数据中的模式。总之，t-SNE 在聚类的数据预处理中发挥着重要作用，能够分析聚类结构并促进更好的聚类结果。

## 问题3：t-SNE 背后的数学原理是什么？

回答：t-SNE 背后的数学原理如下：

- **相似度计算**：t-SNE 基于高斯相似度函数度量高维空间中数据点对之间的距离。
- **降维**：它将这些高维相似度转换到低维空间，同时保留局部和全局空间中的关系，此外还使用 t 分布。
