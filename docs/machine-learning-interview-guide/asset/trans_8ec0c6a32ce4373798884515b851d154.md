
- **超参数调优**：对于MOSVR，某些参数、正则化参数（C）和核参数需要通过交叉验证设置为优化值。
- **评估指标**：用于评估MOSVR模型性能的标准与单输出变量回归分析中使用的标准类似；但是，它们针对多个目标变量进行了调整：**平均绝对误差（MAE）**、**平均绝对百分比误差（MAPE）**、**均方误差（MSE）**和**R平方（R-squared）**。

总而言之，通过使用改进的公式同时估计多个目标，SVR可以应用于多输出回归问题。这意味着需要修改损失函数以处理向量化目标，并需要为多输出情况寻找超参数。

## 模型评估

回归模型评估是通过检查预测结果与实际结果的准确度来检验预测模型能力的过程。所使用的评估指标包括MAE、MSE和R平方，它们用于评估模型拟合数据的好坏程度以及预测其他数据点的能力。在机器学习中，模型评估非常重要，因为它有助于改进模型，并帮助隔离过拟合和欠拟合等问题。更好的评估可以改进用于决策的模型，从而提高模型的实用性和有效性。

### 问题1：正则化如何帮助防止监督学习模型中的过拟合？

答案：这使得正则化成为监督学习中避免过拟合的有力工具。正则化通过添加一个惩罚参数来实现这一点，使模型更难让某些特征拥有较大的权重。

正则化有两种常见类型：L1正则化（也称为Lasso）和L2正则化（也称为Ridge）。

L1正则化在损失函数中加入一项额外项，该项按参数估计值的绝对值计算。

$$Total Loss = Standard Loss + \lambda \sum |w|$$

其中λ是用于定义要纳入模型系数w的正则化量的项。

L1正则化还通过强制许多特征的权重为零来使模型力求简单。因此，它结合了寻找最重要特征并将其余特征置零的操作。在处理高维数据（其中大部分是噪声或不相关特征）时，它也更有用。它使模型能够排除不相关的特征，从而提高其泛化能力。

L2正则化（Ridge）以权重的二次方（即权重平方和）增加损失函数。

$$Total Loss = Standard Loss + \lambda \sum w^2$$

其中λ是正则化强度，w指模型的参数。L2正则化使特征的大权重不受欢迎，但不会让它们变为零。相反，这类算法通常为所有特征分配相对相等的权重值，这使得模型受特定值的影响较小。它有助于避免过拟合，因为模型的灵活度略有降低。这使权重值分布更分散，同时也降低了高权重值；这使得模型在拟合训练集中的噪声时不那么敏感。

此外，还有另一种标准的正则化器，称为弹性网络正则化器，它是L1和L2的组合。

### 问题2：通常使用哪些指标来评估回归模型？

答案：回归模型的性能通常通过几个关键方面来衡量。当决定使用某个特定系数时，这取决于问题的性质、数据分布以及线性回归分析的目标。以下是一些最常用的回归评估指标：

- MAE计算估计值与实际值之间绝对差异的总体平均值。它对所有误差（包括小误差和大误差）赋予相同的重要性。
  - 公式：$MAE = \frac{1}{n} \sum |y - \hat{y}|$

- MSE关注预测值与实际值之差的平方的平均值。它赋予较大误差更高的重要性或量级。
  - 公式：$MSE = \frac{1}{n} \sum (y - \hat{y})^2$

- RMSE是对均方误差取平方根得到的。它给出了与预测变量相同量纲的可评估误差度量。
  - 公式：$RMSE = \sqrt{MSE}$

- R平方是衡量借助一个或多个自变量对因变量的解释程度。它在0和1之间变化，其中1表示完美拟合。
  - 公式：$R\text{-squared} = 1 - \left(\frac{SSR}{SST}\right)$，其中$SSR$表示残差平方和，$SST$表示总平方和。

- MAPE提供相对度量；即误差以实际值的形式表示。
  - 公式：$MAPE = \left(\frac{1}{n}\right) * \sum \left(\left|\frac{(y - \hat{y})}{y}\right|\right) * 100$

- 决定系数（调整后的R平方）确实会考虑模型中自变量的数量，并减少方程中不必要变量的影响。
  - 公式：$Adjusted\ R\text{-squared} = 1 - \left[\frac{(1 - R^2)(n - 1)}{(n - k - 1)}\right]$，其中n是数据点数量，k是使用的预测变量数量。

这些评估指标从不同角度提供了回归模型性能的信息，指标的选择应根据问题的具体目标和特征来决定。例如，MAE和RMSE通常用于一般误差度量，而R平方有助于了解模型的整体拟合优度。除了上述列表之外，还有其他使用的指标：中位数绝对误差、最大误差、解释方差得分和MPE。

### 问题3：解释MSE在回归评估中的作用。

答案：MSE可能是回归中常见的评估指标。它在检验基于回归的模型性能方面有重要作用，通常用于估计模型输出与真实值的吻合程度。

MSE被广泛使用的要点如下：

- MSE计算回归模型预测的均方误差平均值，以呈现预测的准确度水平。它是一种通过计算单一值来确定模型预测整体质量的度量。
- MSE更关注大误差，因为平方差随误差值的增大而增大。这使其对预期/推断值与真实值之间的偏差或大差异较为敏感；换句话说，那些犯严重错误的模型将受到惩罚。

MSE算法的另一种形式是RMSE。RMSE是MSE的平方根，因此它是差异平方的平均值。RMSE用于通过以与目标变量相同的度量单位呈现来提供累积误差的概念。

在实际应用中，MSE（或RMSE）的值越小，表明回归模型越容易最小化预测误差，因此模型能够更紧密地拟合数据。然而，与大多数用于计算性能的离散度度量一样，需要注意的是，MSE受离群值影响较大，因此，少量大值或显著值的存在比计算平均值时更为关键。

### 问题5：在回归问题的模型评估中，如何处理目标变量中存在离群值的情况？

答案：当回归问题的模型评估期间目标变量中存在离群值时，可以采用以下策略来有效处理它们：

- **稳健评估指标**：如果预测有受到许多离群值影响的趋势，请使用平均类指标，如MAE或中位数绝对误差。
- **残差分析**：对残差进行检验，能够将其分层或确定其对所获整体结果的影响。
- **数据变换**：执行数据变换（例如对数变换）来处理目标变量中的极值。
- **截尾或缩尾（Trimming or Winsorizing）**：应对离群值进行截尾或缩尾处理，即用不那么极端的值替换极端值。
- **稳健模型**：最后，考虑使用更稳健的统计方法（如稳健线性回归和Huber回归）进行固定效应回归，以应对离群值。
- **集成方法**：我们经常使用组合模型，例如随机森林或梯度提升，来减少离群值的影响，因为它们会聚合预测结果。
