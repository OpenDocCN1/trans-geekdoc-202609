
基于不同的性能指标进行学习和泛化，具有各种季节性趋势。

- 处理时间依赖性变化：始终考虑随时间发生的在数据分布中的此类变化。训练集必须包含此类时期，因为结构上的突然变化或转变会影响模型的性能。
- 数据转换：任何数据转换或预处理步骤都应在训练集和测试集上产生相同的效果。例如，归一化或差分必须根据训练数据的特征进行，同样，测试数据也必须采用相同的做法。
- 避免数据泄漏：确保在预处理阶段不会使用来自未来的信息，或更准确地说，来自算法处理后期阶段的信息。最好避免使用此类特征或转换，这些特征或转换在某种程度上可能会使用未来信息，即未来信息，因为它们只会使模型的表面结果看起来更好。
- 预测时域的考虑：如果目标是向前进行给定时间范围的预测，则应按照提到的预测设计安排划分。然而，需要注意的是，在形成测试集时，它应包含与预测时域相对应的时期。
- 统计显著性：确保训练集和测试数据集尽可能相同，以便它们能很好地代表已计算的指标。同样重要的是避免采用过小或有偏的样本量，这在模型评估中使用时会产生误导性结果。

这样，实践者可以妥善管理所强调的各种问题；以帮助建立时间序列技术适当的训练集和测试集，这有助于持续改进准确的预测模型。

## 问题 11：讨论趋势成分对时间序列预测模型的影响。如何识别和建模趋势？

答案：趋势成分对时间序列预测模型的影响如下：

- **模式识别**：趋势是相对于时间序列数据在一段时间内长期系统性的波动。趋势的识别和再现对预测的形成起着重要作用。它们允许考虑值的总体运动。
- **预测准确性**：某些趋势本身存在偏差；因此，忽略它们可能导致产生有偏的预测。也有说法称，未考虑影响时间序列的其他参数的模型，可能看不到整个时间序列的全貌，因此给出较差的估计。
- **分解**：将数据分解为趋势-周期、季节指数和剩余部分有助于理解每个组成部分。这种分解对于建模和预测很有用。
- **模型选择**：这意味着趋势的存在会影响预测过程中使用的模型类型。例如，指数平滑或 ARIMA 模型用于趋势成分的分析。
- **长期规划**：趋势在未来战略规划中很有用，因为它们提供了可纳入规划过程的有用信息。时间序列是上升、下降还是稳定，为管理层的行动策略提供了信息。

识别和建模趋势的一些要点是：

- **目视检查**：绘制前述时间序列数据，然后尝试轻松指出任何向上或向下的趋势。趋势可以是直线型，也可以是曲线型。
- **移动平均**：例如，应使用简单移动平均或 EMA 来过滤短期噪声并显示趋势。
- **线性回归**：使用线性回归来估计线性趋势。这意味着首先尝试在数据上画一条直线，以概述总体趋势。
- **多项式回归**：在非线性趋势的情况下，可以使用一定程度的多项式回归来捕捉时间与因变量关系方面的进一步特征。
- **指数平滑**：移动平均技术，即 Holt-Winters 指数平滑，可用于计算基于过去值指数递减权重的趋势。
- **时间序列分解**：这涉及使用诸如加法和乘法分解等技术将时间序列划分为趋势、季节性和残差等组成部分。随后进行步骤以明确描述趋势。
- **统计检验**：为了检验趋势，必须进行趋势统计检验，例如 Mann-Kendall 检验或增广 Dickey-Fuller 检验。这些检验有助于确定所获得的结果是否在指标中识别出的趋势方面具有统计显著性。
- **ML 模型**：使用 ML 模型，特别是适用于时间序列数据的技术，以捕捉数据上的更详细模式。

时间序列数据的趋势分解和预测过程是图形分析、统计程序和建模策略的结合。因此，必须选择与趋势的性质（线性或非线性）相对应的方法。随着数据性质的变化，定期评估和重新建模也很重要。

## 问题 12：ARIMA 能否用于多元时间序列预测？

**答案**：ARIMA 主要设计用于单变量时间序列预测，其中仅观察并随时间预测一个变量。然而，在处理多元时间序列预测时，可以应用 ARIMA 模型的先进变体。尽管如此，ARIMA 模型的先进变体包括用于多元时间序列预测的 **向量自回归积分移动平均（VARIMA）** 和 **带外生变量的向量自回归移动平均（VARMAX）**。

VARIMA 模型概括了 ARIMA，并涉及使用模型中所有变量的滞后值，扩展到其他相关时间序列变量。这使得一个人能够

- MAPE：实际回报与预测回报之间平均偏差的相对平均测量。当想知道误差相对于真实值的大小时很有信息量。
- **残差分析**：查看残差值，考虑它们是否具有零均值并且在模型中均匀分布。
- **AIC 和 BIC**：为选择模型的信息获取方法设定的标准。它们代表 ARIMA 模型与最佳拟合模型之间的差异；较低的值有助于比较不同的 ARIMA 模型。

通过使用所描述的任何方法或它们的组合，你将能够判断 ARIMA 模型捕捉特征并对未揭示的数据序列做出正确预测的能力。

时间序列数据基本 ARIMA 模型的扩展形式包括 SARIMA 和 **带外生变量的 ARIMA（ARIMAX）** 模型。它们通过提高对各种类型时间序列的建模能力以及季节因素和外部协变量的实现来改进模型，从而产生准确且有价值的预测。对于 ML 从业者来说，了解这些变体的实际应用很重要，因为这些模式的见解可以帮助从业者以更高的准确性改善其时间序列数据的结果，并就数据策略做出更好的决策。
