
- 探索性数据分析、特征修剪减少以及在你的数据集中创建审查偏差。列举一些处理不成比例的矩阵和分布的方法，可以重新采样数据，对其进行过采样、欠采样，或生成合成样本。Booking it 是必要的，以避免将此类属性用作模型中的特征，因为它们可能包含一些敏感信息。应避免或至少限制使用可能引入或加强偏差的方面。
- 我们需要使用去偏策略或方法来帮助减轻模型输出中的偏差。对于深度学习有一些明确的参考类别的去偏技术。这些是：重加权、重排序和对抗训练。

对于监督学习模型，处理偏差可能是一项终身任务，费力但关键，通常是技术性和伦理性的混合。因此，在模型开发过程中考虑和减轻偏差至关重要，以便创建准确且没有社会上不期望的偏见的模型。一些可以纳入以减少偏差的选项是：遇到的报告偏差、伦理和法律审查与审计、创建更可解释的模型、包含符合公平首要标准的公平约束，其中最受欢迎的库之一是 IBM AI Fairness 360。

## 问题 5：解释模型性能背景下的偏差-方差权衡。

**回答：** 偏差和方差这两个术语构成了经典的 ML 理论的一部分，因为它们涉及模型性能及其泛化能力。它指的是模型可能产生的两种类型错误之间的平衡：偏差误差和方差误差。因此，必须在这两者之间进行权衡，以便提出对未见数据泛化良好的模型。

偏差误差也称为欠拟合，存在于模型缺乏足够复杂性以捕捉数据的真实模式和特征的情况中。高偏差模型无法拟合训练数据，并且通常在训练数据和测试数据上性能都很低。

**例如**：使用复杂、非线性数据进行线性回归建模。

另一种模型评估类型是方差误差，通常称为过拟合；这种情况是指模型非常复杂并考虑了训练数据集的每一个细节，甚至包括噪声。这使得它们对训练集数据高度敏感，并且通常缺乏对其他未知数据集的良好泛化能力。高方差模型可能非常好地拟合训练数据，但以高概率对测试数据拟合很差。

**例如**：当在小训练集上使用具有多层深度的深度神经网络时就是一个例子。

偏差和方差的权衡可以用 U 形曲线最好地描绘出来，其中模型的偏差与其方差呈反比关系。模型的唯一影响是当模型复杂度增加时其方差减少而偏差升高，反之亦然。目标是找到使总体误差最小的模型，误差是偏差误差和方差误差的总和，从而提供最佳拟合模型，对未用于建模的数据进行良好的预测。

调整偏差和方差是选择、训练和评估 ML 中模型的关键。它是在简单和复杂模型之间进行选择以及设置或调整模型参数以实现特定问题的最大利益的过程。

## 问题 6：为什么在监督学习中需要评估指标？

回答：评估指标在监督学习中至关重要，原因如下：

- 性能评估工具能够在运行中对各种监督学习模型的能力进行数值量化。它们帮助用户理解给定模型与另一个模型相比预测得有多好。它还使就选择模型、超参数和包含特征做出合理决策变得更容易。
- 评估指标有助于在部署后监控模型的健康状况，因为性能会随时间被监控。关于第一个用途，如果模型性能下降，那么个人可以得出结论，是时候重新训练或更新模型了。
- 测量标准还有助于识别你的模型相对于市场上其他模型的性能水平，从而提供衡量你的模型相对于其他模型的可行性和效率的指标。

此外，使用评估指标还有助于提供对模型行为的理解，尝试获得和评估业务相关性、访问、报告、解决伦理和公平问题等。

- **阈值**：这里的许多模型使用决策标准水平来帮助控制实例是否应被分类为正类或负类。通过改变上述阈值在值范围内，ROC 曲线得以生成。

## 二元分类中 ROC 曲线的用途：

- ROC 曲线在此展示了模型在给定类别的各种分类阈值下的性能。它能够比较不同模型的性能，这在选择适合问题需求的最佳阈值时很有帮助，无论我们是想优先考虑灵敏度还是特异性。
- 使用 AUC 值意味着有一个标量值来衡量模型的性能，衡量其对类别进行分类的能力。构建模型的 AUC 通常更有价值，因为它代表了判别能力；AUC 越大，模型越好。
- 当假阳性和假阴性涉及的成本不同时，ROC 曲线很有用。研究曲线可以确定与问题比率相对应的某个水平。
- ROC 分析广泛用于医学诊断、欺诈检测以及任何分类模型性能将取决于问题性质和要求的情况。

总之，我们可以说 ROC 曲线对于评估和比较二元分类器的性能非常有用，因为它允许我们在不同阈值指标的情况下分析敏感性和特异性的关系。它有助于为特定应用选择合适的阈值，并提供关于模型判别能力的全面信息。

## 问题 8：解释分类评估中的混淆矩阵及其组成部分（或）讨论分类指标如准确率、精确率、召回率和 F1 分数。

回答：混淆矩阵是分类评估中的一个原始表格。它通过从实际类别值的角度计算预测来提供模型的概率度量。混淆矩阵由四个组成部分构成：分类过程中使用的基本术语包括 TP、TN、FP 和 FN。这些组成部分用于计算和推导其他分类测量结果，包括准确率、精确率、召回率和 F1 分数。下面是对每个组成部分的描述：

- TP 表示模型正确分类为正类的实例数量——换句话说，正确分类为属于正类的实例。这些是模型通过提供正实例的正确结果而做对的情况。
- TN 是所有正确分类为负类或不属于正类的记录。这些是模型对负实例分类做对的情况。
- 假阳性是指模型预测为阳性结果，而实际上为负性的情况。换句话说，这些是模型持乐观态度但结果为负的实例。
