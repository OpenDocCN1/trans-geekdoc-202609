
- **差分：** 计算连续观测值之间的差异。这可以执行一次（一阶差分）或多次，直到序列达到平稳。
- **对数变换：** 通过对值取对数来缩放数据，因为它可以减少方差，尤其是当给定分布的数据具有指数增长性质时。
- **季节性差分（SD）：** 如果数据中存在季节性，则在季节性频率处进行差分，以捕捉并移除周期性成分。
- **去趋势：** 通过将实际值对时间回归或使用移动平均技术来预测时间序列数据的趋势，然后将其从数据中移除，以保留周期性成分。
- **分解：** 将给定的时间序列分解为趋势、季节性和残差。必要时，需要评估并剥离序列的这些方面。
- **Box-Cox变换：** 通过应用Box-Cox幂变换对数据取对数以实现正态性。
- **整合：** 数据分析和处理的第一步是整合差分，通常称为整合，以使时间序列数据平稳。这通常表示为I(d)，其中d是差分的阶数。
- **加权移动平均（WMA）：** 对原始数据使用加权移动平均，有助于消除波动数据并突出趋势数据。
- **指数平滑：** 使用指数平滑技术识别趋势和季节性，然后将其消除。

一般来说，应根据所讨论的时间序列数据的特征来使用特定的变换。从统计学角度，你需要检查数据是否平稳。有多种技术，其中最简单的一种是绘制时间序列图并检查趋势，另一种方法是使用增强Dickey-Fuller检验。可能需要重复使用这些技术，直到获得平稳序列，这将简化各种时间序列分析技术的应用。

## 问题11：在什么场景下，你会选择概率时间序列预测方法而不是确定性方法？

每当需要衡量并包含预测的不确定性时，概率时间序列预测比确定性方法更具优势。这在风险评估、金融、运营与生产计划、能源价格、天气预报、物流甚至医学等行业中尤为重要，因为在这些行业，管理不确定性与处理确定性同样重要。概率模型包含多种可能的结果表达方式，能够对未来事件和计划给出准确的估计。

## 问题17：WMA与SMA有何不同？

**答案**：加权移动平均（WMA）与简单移动平均（SMA）的主要区别在于移动平均窗口内数据的加权方式：

- **加权方案**：SMA基于给定集合中的所有数据点计算，每个数据点被赋予相等的权重，而WMA则根据预定的权重因子计算。
- **不同的影响力**：WMA赋予当前数据比过去数据更高的权重；因此，以前的数值可能影响很小或根本没有影响。
- **可定制性**：使用WMA的一个主要优点是权重可以更改，以反映数据本身的特征以及用户的需求。
- **复杂性**：SMA易于计算和理解，而WMA则需要定义和实现权重。然而，现有来源为数据流提供了精细的视角。

总之，可以说WMA和SMA的主要区别在于，前者对移动平均窗口内的数据赋予权重，这种方式使得WMA远比SMA更灵活和通用。

## 问题18：你能解释中心移动平均的概念吗？

**答案**：中心移动平均是移动平均的一种子类型，其平均值由当前值之前和之后的所有值共同确定，所考虑的值位于中心。中心移动平均的一些关键要点如下：

- **对称平均**：基本类型的移动平均包括中心移动平均，它计算当前点前后数据点的平均值，因此在当前数据点的每一侧都提供相同数量的数据点。
- **平衡平滑**：它们提供相等的平滑，因为与SMA一样，它取当前点左侧和右侧相同数量的数据点，但滞后更小。
- **示例**：例如，如果窗口大小为3，则中心移动平均将使用当前值、前一个值和后一个值来计算移动平均。
- **应用**：中心移动平均用于时间序列、信号处理和数据平滑，在这些领域中，平滑程度与对变化的响应性之间的平衡非常重要。

总的来说，中心移动平均对数据平滑同样有帮助，因为它们涉及特定点前后相等数量的数据点，因此对于平衡平滑和响应性至关重要的应用非常有用。
