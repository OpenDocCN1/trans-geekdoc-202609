# Question 3: What is the significance of the gradient in gradient-boosting?

Arguably, it is the name gradient in gradient-boosting, which refers to optimization of a loss function by backpropagation that passes through the gradient of the loss with respect to the model’s predictions. It enables the algorithm to get a series of better solutions by continuously adjusting the predictions in the direction that would minimize the given error; thus, it is useful as an optimization prerogative in ensemble learning.
