### 线性回归

我们首先要回顾的技术是线性回归。它是一种流行的统计方法，用于根据连续自变量预测连续因变量。使用关于变量的线性方程，可以清晰地联系目标变量与预测变量，从而便于确定趋势。线性回归在机器学习中很重要，因为它易于理解、易于解释且训练速度快，并且足以构成高级方法的基础。线性回归是监督学习的一个例子，能使人们理解两个变量之间的关系，并将更复杂的方法与其进行比较。

### 问题 1：描述线性回归中找到最佳拟合线的过程。

**答案：** 在线性回归中找到最佳拟合线的过程包括：

- **定义线性模型**：因变量与自变量/特征之间应存在一种简单的关系。
- **选择代价函数**：通常，将**均方误差（MSE）**作为模型预测错误的度量。
- **初始化系数**：为了估计模型的系数，必须设置初始值（例如，斜率和截距）。
- **最小化代价函数**：你需要使用**普通最小二乘法（OLS）**等方法，要么手动求解系数，要么使用梯度下降法来帮助最小化代价函数。
- **评估模型拟合**：基于 R 方、MSE 等指标评估模型的性能。
- **进行预测**：根据最佳拟合线的方程，使用新数据拟合一条线来估计值。
- **解释系数**：认识到系数所反映的自变量对因变量的影响。
- **优化模型**：如有必要，进一步改进现有模型，以解决过拟合、异常值或如何将特征正确纳入模型等问题。

### 问题 2：线性回归中的代价函数（损失函数）通常如何定义？

**答案：** 在线性回归中，常见的代价函数（或损失函数）也称为 MSE。MSE 提供实际数据或观测数据与线性回归模型预测值之间差异的均方值。其定义如下：

```
MSE = (1/n) × Σi (yi − ŷi)²
```

- n 是数据点的数量，即样本量。
- yi 是在研究或样本的第 i 个数据点观测到的因变量值。
- ŷi 是线性回归模型在第 i 个观测处对因变量的估计值。

使用 MSE 作为代价函数的原因是它表示模型预测值与实际值之间的差异，并且由于对误差进行了平方，较大的误差会受到更高的惩罚。因此，线性回归的目标是估计模型参数（即斜率和截距）的值，使 MSE 的期望值降到最低，从而使模型达到最佳拟合。MSE 的最低值意味着找到了最佳拟合线，以及预测中的最小误差。

### 问题 3：什么是决定系数（R 方），它度量什么？

**答案：** R 方，也称为决定系数，是一个统计值，表示线性回归模型所解释的因变量方差的占比，也就是自变量对因变量的解释程度。R 方在 0 到 1 之间变化，1 是最大值。R 方的值越高，表示模型对数据的拟合越好。它是衡量模型拟合优度和回归分析中诊断检查的有用指标，但不能说明模型的预测有效性或其假设。

### 问题 4：如何解释线性回归模型中的系数（斜率和截距）？

**答案：** 线性回归模型中使用的系数和截距在解释变量之间的关系方面极其有价值。以下是如何解释它们：

- **截距（β₀）**：截距是当所有自变量都等于零时因变量的预期值。它是在数据收集开始时确定的因变量的初始度量。其解释取决于手头的问题；例如，在房价变化模型中，截距可能意味着房屋价格至少包含一个分数特征，这在现实生活中可能没有任何意义。讨论因变量作为自变量的函数的变化更有意义。

- **斜率（β₁、β₂、...、βₙ）**：每个系数估计的是，在其他条件不变的情况下，该自变量每变化一个单位对因变量的影响。例如，在估算房屋面积的 β₁ 时，假设其为 0.05，这意味着房屋面积每增加一个单位，因变量的预测值增加 0.05 个单位，因此在所有条件不变的情况下，我们估算的总单位数达到 85 个单位。
