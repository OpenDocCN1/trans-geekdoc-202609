
所采取的措施可能取决于应用领域要素和/或数据集的结构。

### 问题 9：如何解释文档中词项的 TF-IDF 分数？

回答：词项的 TF-IDF 分数是在文档约束范围内定义的，范围从 0 到 1，它表示该词项在给定文档中的重要性或相关性，相对于其他文档。以下是解释：

首先，TF-IDF 分数是 TF 和 IDF 的组合，两者以相乘的方式工作。它在特定文档内部本地进行，也在整个文档语料库上全局进行。特定词项的分数越高，源于其在给定文档内的频率越高，同时也源于该词项在整个语料库或文档集合中的频率越低。

在解释中：

- TF-IDF 值越高，该词项被认为对给定文档越重要或越相关，可能包含重要的主题或主题领域。
- 另一方面，较低的 TF-IDF 分数意味着该词项在文档中频繁使用，或通常在语料库中频繁使用，因此可能无法有效区分文档。

总体而言，如果我们回想起 TF-IDF 分数的目标是指定与给定集合中大量文档相比更与单个文档相关的词项。

## 词袋模型

### 问题 1：BoW 模型如何表示文本数据？

BoW 模型是一种将文档转换为数值向量以描述文本数据的方法。每个向量都是一个文档，向量中维度的程度是词汇表中单词的出现次数。每个维度放置的值表示特定单词在文档中的相对频率或总出现次数。与句法模型相比，该模型不考虑句子中单词的顺序或语法，而只考虑单词的存在及其频率。因此，它提供了一种相当高效的方法来对文本文档的构建块——单词进行分类和聚类。

### 问题 2：创建 BoW 表示涉及哪些步骤？

创建 BoW 表示涉及以下步骤：

- **分词**：分词将文本划分为单词或词元的细粒度。
- **小写化**：将同一单词的变体视为相等，并使用小写将给定数据中的所有单词转换为小写。
- **构建词汇表**：应从定期分词的文本中提取不同单词的列表。
- **统计词频**：统计文本中词汇表中每个单词出现的次数。
- **向量化**：基于 BoW 模型，将文本表示为数值向量，每个向量表示词汇表中每个单词的计数。
- **归一化（可选）**：预处理向量应根据文档长度差异或单词相对重要性进行缩放，通常除以总词数或使用 TF-IDF。

这些步骤导致所谓的 BoW 模型，其中每个文档被建模为词频或频率的稀疏向量，忽略了单词的语法结构和位置，但考虑了某些单词是否出现在文档中。

### 问题 3：分词在 BoW 模型中的重要性是什么？

**回答**：分词在 BoW 模型中至关重要，原因如下：

- **词分离**：像任何其他语言模型一样，分词将原始文本分解为单个单词或词元以供进一步分析。

这些计数或频率随后应分配到向量中的相关位置。

- **向量化：**
  - 文档现在处于固定维度的空间中，其中每个维度是已知词汇表中的特定单词。
  - 向量中的值表示特定单词在文档中的出现次数，或根据所用函数表示其重要性。
- **归一化（可选）：**
  - 如果向量大小不同，则根据文档数量对其进行标准化。
- **最终化：**
  - 它可用于机器学习算法的输入数据，用于分类或聚类等所有任务。

它将原始文本数据转换为可放入方程的形式，并且更容易被机器学习算法对基于文本的数据进行建模。

### 问题 5：BoW 模型中表示单词频率的常见技术有哪些？

回答：在 BoW 模型中，表示单词频率的常见技术包括以下内容：

- **原始频率**：表示单词在文档中出现的频率，指的是文档的清单。
- **二元**：以二元形式表示，单词要么在文档中（标记为 1），要么不在文档中（标记为 0）。
- **TF**：计算文档中单词的 TF 为该单词在该文档中出现的次数除以该文档中的总词数。
- **TF-IDF**：承认单词在文档中的重要性与其在语料库所有文档中的分布有关；是 TF 和逆文档频率的结果。

这些技术帮助 BoW 模型从以下任何方面解释单词的频率，为文档以及整个语料库提供不同的维度。

### 问题 6：BoW 模型如何处理文本中单词的顺序？

BoW 模型不将其组件之一纳入文本中单词的位置。它将每个文档读作无序单词的词汇表，然后根据每个单词的频率生成数字。这意味着 BoW 模型未能捕捉到文档中单词的顺序，而实际上它应该捕捉到。因此，它产生的单词之间的关系类型无法理解由于单词在文本中的位置而存在的可能的句法和语义关系。相反，它关注文档中的特定术语，以及它们是否以及如何经常出现。

### 问题 7：BoW 模型的局限性是什么？

BoW 模型具有以下局限性：

- **词序丢失**：使用简单的单词级向量，BoW 丢弃文档内单词的顺序，因此文档内文本的重要顺序丢失。

- **结构：**
  - **行**：将语料库中的文档作为突出个体捕获。
  - **列**：在此类型中，术语作为文档整个词汇表中的单词或词元出现。
- **条目：**
  - **原始频率**：表示文档中术语的词频分布。
  - **二元**：二元形式；1 表示该术语存在于该文档中，而 0 表示该术语不存在于该文档中。
  - **加权**：组织还可能根据术语在文档中的相关性缩放频率，例如使用 TF-IDF。

词-文档矩阵对于执行所有形式的文本分析至关重要，因为它将文本数据转换为大多数机器学习算法输入所需的格式。

### 问题 9：BoW 模型如何处理 OOV 单词？

**回答**：BoW 模型以以下方式处理 OOV 单词：

- **忽略 OOV 单词**：其中一些是基于预先给定的上下文词汇在文本处理中省略的单词。
- **使用特殊标记**：引入 <UNK> 等特殊标记以统一处理 OOV 单词，并用该标记替换 OOV 单词，该标记也在词汇表中。
