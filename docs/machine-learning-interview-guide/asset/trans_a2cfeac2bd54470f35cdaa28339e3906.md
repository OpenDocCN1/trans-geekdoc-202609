## N 元语法和规范化

N 元语法是一组相邻的 n 个项目，通常是单词或字符，在 NLP 上下文中出现，用于分析语言模式。最重要的预处理技术之一是规范化，即将文本数据转换为统一格式的操作。其中包括将单词规范化为全小写、消除特殊字符以及词干提取。结合在一起，N 元语法和规范化与机器学习模型配合良好，并为文本分类器、语言建模以及许多其他 NLP 任务提供具有词序列上下文及其频率的结构化特征。

这些是需要掌握的重要概念，以便改进我们内部处理语言的算法。

### 问题 1：什么是 N 元语法，以及它们如何在语言建模和特征提取中使用？

回答：N 元语法是从给定文本或语音中提取的 n 个项目（单词、字符或符号）的连续序列。

例如：

- **一元语法 (1-gram)**: I, love, AI.
- **二元语法 (2-gram)**: I love, love AI.
- **三元语法 (3-gram)**: I love AI.
- 它可以扩展到更高阶的 N 元语法，如 4-grams 和 5-grams。

在概率语言模型中，N 元语法有助于估计在给定之前 n-1 个词的情况下某个词出现的概率。这有助于预测序列的下一个词。示例：在 bigram 模型中，love 在 I 之后的概率将使用 bigram I love 的频率推导出来。N 元语法用于序列生成或语音识别，其中可以使用 N 元语法来模拟音素或声学特征序列的概率以进行转录。

我们还可以从 N 元语法的表示中提取特征向量。这些特征与给定文档中特定数量的 N 元语法的出现直接相关。N 元语法用于索引和检索文档，因为它们索引了可能对文档检索至关重要的常见短语或术语。**命名实体识别 (NER)** 用于识别构成命名实体的词模式。这有助于识别特征，例如名称、地名甚至组织等。就其用途而言，N 元语法可用于语音标注，这涉及识别词序列以确定特定句子中每个词的语法类别。总结来说，N 元语法是语言建模的重要组成部分，因为它们反映了上下文值之间的依赖关系以及特征提取，其中文本的结构和内容被表示为多种 NLP 应用，包括语言建模、文本分类、信息检索等。

### 问题 2：在 N 元语法的上下文中，可以解释标记化的概念吗？

关于 N 元语法的用法，标记化是指将文本分割为标记单元，包括单词或字符，以便创建 N 元语法。

例如，在词级标记化中，文本 "The cat sat on the mat" 将被标记为单个词：

```
['The', 'cat', 'sat', 'on', 'the', 'mat']
```

同样，在字符级标记化中，同一文本将被标记为单个字符：

```
["T", "h", "e", " ", "c", "a", "t", " ", "s", "a", "t", " ", "o", "n", " ", "t", "h", "e", " ", "m", "a", "t"]
```

之后，这些单独的标记用于形成 N 元语法，定义为文本中 n 个连续标记的序列。创建 N 元语法时标记化非常重要，因为标记化决定了文本数据表示的单元级别。

### 问题 3：使用 N 元语法在 NLP 任务中的优势是什么？

以下是使用 N 元语法在 NLP 任务中的优势的简明解释：

- **捕获局部上下文**: N 元语法可以描述为短程上下文和依赖，能够表达一个数据单元，即单词或字符对相邻文本数据单元的依赖。
- **紧凑表示**: 它们通过将标记序列映射到固定维度空间来保留文本数据的密度，这使得文本数据更易于使用和处理。
- **特征提取**: N 元语法作为 NLP 过程中的机器学习模型的特征，使得执行文本分类、文本情感分析以及信息检索等任务变得更容易。
- **灵活性**: 它在可使用的词数方面具有灵活性（unigram、bigram、trigram 等），取决于手头的任务和所需的上下文级别。
- **语言无关性**: 它们可用于任何语言的文本数据，这使得它们适用于 NLP 的多语言上下文，因此在多语言研究中很有用。

总之，N 元语法展示了一种相对简单且通用的建模技术，可用于任何文本集合，并且提取适当的 N 元语法集合是大多数 NLP 任务成功的关键因素。

### 问题 4：N 元语法如何帮助在文本中捕获局部上下文和句法信息？

**回答**: N 元语法中的词由于是 n 个连续的词或字符，因此擅长捕获局部上下文和句法信息。方法如下：

**局部上下文:** N 元语法被描述为 *n* 个词或字符的序列，以建立标记与其由窗口大小限制的直接邻居之间的直接依赖关系。

**句法信息:** 基于词共现的统计，N 元语法帮助模型识别频繁使用的句法结构，并提供有关词之间依赖关系的重要线索，这对于构建准确的句法表示和在 NLP 任务中做出合适的预测至关重要。

总之，可以认为 N 元语法是文本输入中局部上下文和句法信息的有用表示，因此有助于 NLP 模型将重要模式和依赖关系纳入模型。

### 问题 5：在 NLP 中处理 N 元语法的常见技术有哪些？

**回答:** 在 NLP 中处理 N 元语法的一些常见技术是：

- **N 元语法生成:** 将文本拆分为 *n* 个标记的块，以保留局部上下文和标记之间的依赖关系。
- **平滑:** 修改 N 元语法的概率，以确保未来出现的任何 N 元语法都有非零概率，从而增强模型的稳定性。
- **剪枝:** 如果 N 元语法出现频率很低，有时应将其过滤掉，以减少模型大小并使其在计算上更快。
- **回退与插值:** 从低阶 N 元语法预测尚未出现的 N 元语法的概率，或在各种阶数之间混合概率，以提高预测能力。
- **处理词表外 (OOV) 词**: OOV 词可以通过使用新颖的标记 **<UNK>** 基于字符的模型或利用词嵌入来处理。
- **长上下文的平滑**: 用于捕获较长上下文中复杂依赖关系的其他平滑方法包括 Kneser-Ney。

这些技术在 NLP 的不同功能中正确应用 N 元语法至关重要，包括语言建模、机器翻译以及信息检索。

### 问题 6：如何在 N 元语法模型中处理 OOV 词？

**回答**: 在 N 元语法模型中处理 OOV 词主要取决于在训练数据中未见过的情况下最小化 OOV 词影响的技术。

以下是常见方法的列表：

- **UNK 标记**: 这是为了在训练和推理期间以统一的方式处理 OOV 词；OOV 词被替换为特殊的 **<UNK>** 标记。
- **平滑技术**: 有像 Laplace 平滑这样的技术，其中概率被修改并为 OOV 词分配一定量的概率质量。
- **回退与插值**: 通常，您可以从当前低阶 N 元语法估计未见 N 元语法的概率，或从多阶 N 元语法的概率中插值未见 N 元语法的概率。
