
因此，系数相对于测量单位的相对性质在解释它们时需要加以考虑。例如，斜率为0意味着存在因变量与自变量无关的情况。对于数值字段，例如平方英尺（sqft）的系数0.05，在房价预测中可能意味着每平方英尺价格上涨5美元。

因此，截距给出基线值，而斜率系数表示自变量的变化如何影响因变量。对这些值的解释取决于具体问题的背景以及所使用的单位。

## 问题5：线性回归中的p值是什么？它如何用于特征选择？

答案：线性回归的p值是一种初步的分析统计量，用于在个体层面评估系数的重要性，这里的系数指斜率和截距。

它用于特征选择的方式如下：

- **假设检验**：p值表示原假设为真或假的概率；换句话说，它让人了解自变量是否对因变量具有统计影响。较小的p值（通常低于所选的显著性水平，比如0.05）表明显著；因此，该变量应包含在模型中。
- **特征选择**：保留那些p值较低的变量，以便它们可以被声明为统计显著，并被认为对因变量的影响更显著。p值低于0.05被认为是统计显著的；因此，自变量的p值具有预测性，可用于预测因变量。

- **变量移除**：删除高度相关的衍生度量之一——保留从理论或实用角度来看更合理的一个。
- **合并变量**：通过将相关变量相加而不是每个变量都有自己的索引来完成，这样可以提供更好的结果。
- **特征选择**：尝试主要选择更接近目标的变量，并通过使用Lasso回归或逐步回归排除更接近均值的变量。
- **主成分分析（PCA）**：使用PCA通过用线性不相关的主成分替换相关特征来降低数据维度。
- **正则化**：岭回归有能力减小多重共线性变量的系数，从而减轻多重共线性问题。
- **方差膨胀因子（VIF）**：如果VIF较高，建议移除该变量。
- **领域知识**：这引出了第八种方法，即决定采用学科专业知识来处理相关变量。

选择与你的数据和问题匹配良好的方法，同时牢记它对模型可解释性和质量的影响。

## 问题9：线性回归中正态性检验（例如Shapiro-Wilk）的目的是什么？

答案：在线性回归中使用的Shapiro-Wilk检验旨在检查所选回归模型中的残差是否呈正态分布。这一点很重要，因为若干统计检验和程序（如假设检验和置信区间）要求残差呈正态分布。

然而，正态性通常只是线性回归模型中的一个关键假设，因为它们通常可以温和地处理对该假设的某些违背，尤其是在处理大样本量时。因此，对非正态性进行分析的需求可以通过中心极限定理得到解决或减少。但是，如果偏差相当极端，则可能会建议使用其他模型，例如广义线性模型。

## 问题10：描述线性回归中梯度下降的步骤。

答案：梯度下降是一个在后续重复步骤中用于确定线性回归模型适当系数（参数）的过程。以下是线性回归中梯度下降的步骤：

- **初始化系数**：从启发式选择的线性回归模型系数值开始。这些初始系数可以设置为零或接近零的小随机值。
- **计算代价函数**：计算代价函数，在线性回归模型中通常简称为MSE。代价函数将模型预测的值与实际数据的值进行比较。
- **计算梯度**：推导代价函数关于每个系数的一阶偏导数。梯度是指向代价函数增加更快方向的向量。
- **更新系数**：（简单来说，需要从当前值中减去梯度的一部分来修正系数。）缩放距离的比例称为**学习率**或**步长**，用符号α表示。这一步沿所需方向调整系数，从而使代价函数减小。
- **重复**：执行步骤二到步骤四，直到达到预定义的循环次数或结果收敛。收敛标准可以是相对于代价函数的epsilon常数，也可以是预定义的迭代次数。
- **收敛**：该过程持续进行，直到代价函数达到最小值，并调整系数以给出最佳直线回归模型。

此过程的结果是获得最小化的系数，使线性回归在给定自变量的情况下能够有效预测因变量。选择学习率以及如何终止学习过程在梯度下降中至关重要。

## 问题11：梯度下降中的学习率是什么？它如何影响收敛？

答案：梯度下降是多元线性模型中参数逻辑回归系数估计的方法。

以下是线性回归中梯度下降的步骤：

- **初始化系数**：从对线性回归模型参数的一些假设开始。这些初始系数可以设置为零，或者分配一些小的随机值。
- **计算代价函数**：计算代价函数，在线性回归场景中通常就是MSE。代价函数定义为模型预测与观测实际值之间的差异。
- **计算梯度**：计算代价函数关于每个系数的一阶偏导数。本质上，梯度是一个指向代价函数增加最快方向的向量。
- **更新系数**：将系数除以 (1 + rate * grad) 以通过梯度的一部分来缩放变化。梯度被缩放的值构成学习率（α），通常 0 < α ≤ 1。此步骤在使代价函数增加最少的方向上调整估计系数。
- **重复**：循环执行步骤二至四，直到达到固定的迭代次数或满足一定的收敛标准。收敛标准可以是代价函数值的微小变化，也可以是预定的迭代次数。
