
# 信息时代的另一种视角是信息的泛滥

几十年前，新闻指的是每日报纸，或者也许是一段30分钟的晚间新闻广播。如今，新闻全天候在多个有线电视台和各类互联网站上发布。在我的童年时期，研究意味着去当地图书馆，查阅有限数量的书籍，希望这些书籍不超过十年旧闻。如今，只需点击鼠标按钮，即可获得学术期刊、研究网站、年鉴、词典、百科全书——信息的洪流。因此，我们可以把信息时代视为大多数人能够轻松获取广泛信息的时代。

那些成长于互联网和手机环境、沉浸在海量即时信息中的年轻读者，可能不完全理解信息爆炸的规模。一旦你领悟到信息爆炸的巨大程度，便更能体会**信息理论**的必要性。为了让你对当代文明中正在传输和消费多少信息有一个直观的认识，请参考以下事实：早在2003年，专家估计人类在整个历史进程中累计产生了**12艾字节**（exabytes）的数据。21世纪的前两年，磁性存储、印刷和胶片等现代媒介仅产生了**5艾字节**的数据。2009年，研究人员声称在**单一年份**，美国人消费了**超过3兆字节**（zettabytes）的信息。^([1](#part0011.xhtml#ch03note1a)) 截至2013年，世界万维网据说存储着**4兆字节**（4,000艾字节）的数据。

## 测量数据

如此巨大的数字对大多数人而言难以理解。大多数读者熟悉千字节、兆字节和吉字节，但你可能不太熟悉更大的单位。下面是数据的各种大小：

`Kilobyte` = 1000 bytes  
`Megabyte` = 1,000,000 bytes  
`Gigabyte` = 1,000,000,000 bytes  
`Terabyte` = 1,000,000,000,000 bytes  
`Petabyte` = 1,000,000,000,000,000 bytes  
`Exabyte` = 1,000,000,000,000,000,000 bytes  
`Zettabyte` = 1,000,000,000,000,000,000,000 bytes  

这些惊人的数据规模虽然难以把握，但足以说明**信息理论**为何如此重要。它也直观地展示了，无论是按我们获取的信息量度，还是把信息本身视为商品来衡量，我们确实处于信息时代。

### Claude Shannon

在深入探讨信息理论时，不可或缺的是**克劳德·香农**（Claude Shannon），他常被誉为**信息理论之父**。他是一位数学家和工程师，生于1916年4月30日，逝世于2001年2月24日。香农在数学的电气应用以及密码学方面做了大量工作。他的研究兴趣包括运用**布尔代数**（我们将在[第5章](#part0013.xhtml#ch05)详细讨论各种代数）和**二进制数学**（本章稍后将介绍）与电磁继电器结合使用。电气开关与二进制数字、布尔代数的配合构成了数字计算机的基础。

**Note**

二战期间，香农在贝尔实验室（Bell Labs）为国防项目工作。其工作的一部分涉及密码学和密码分析。这并不奇怪，因为他最著名的成果——信息理论——已被应用于现代密码技术的发展。1943年，香农认识了**艾伦·图灵**（Alan Turing），图灵在我们的[第2章](#part0010.xhtml#ch02)中被提及。图灵在美国工作，为美国海军的密码分析努力提供了英国已有的方法。

信息理论于1948年由香农在其文章《A Mathematical Theory of Communication》中提出。他关注信息，特别是与信号处理操作相关的信息。信息理论如今涵盖了量化、存储、传输和保护信息的整个领域。香农的里程碑论文被扩展为一本名为*《信息的数学理论》*的著作，由他与**沃伦·韦弗**（Warren Weaver）合著。

在原始论文中，香农提出了一些看似极其基础的概念，对拥有工程或数学背景的读者来说显得很直观，但在当时，还没有人尝试量化信息或信息传递过程。下面列出的概念配以简要说明，阐释其在密码学中的意义：

`![image](Images/image00484.jpeg) **信息源**（information source）产生消息。这是香农最基础的概念之一。一定有某个源产生给定的消息。在密码学语境下，该源将明文应用某种密码算法生成密文。`

`![image](Images/image00484.jpeg) **发射器**（transmitter）对消息进行处理，生成可通过**信道**（channel）传输的信号。香农大部分工作都集中在发射器和信道上，即将（加密的）消息发送到目的地的机制。`

`![image](Images/image00484.jpeg) **信道**是信号传输的介质，承载携带信息的信号。现代加密通信往往通过互联网进行，但加密的无线电和语音传输也常被使用。在第2章[^1]中，你已经了解了**识别友��（IFF）系统**。`

`![image](Images/image00484.jpeg) **接收器**（receiver）将信号转换回原始消息以便传递。为了我们的目的，接收器还会解密消息，将密文转换为明文。`

`![image](Images/image00484.jpeg) **目的地**（destination）可以是人或机器，为其准备消息。这很直观。你可能会猜到，有时接收器和目的地是同一实体。`

`![image](Images/image00484.jpeg) **信息熵**（information entropy）是香农论文中引入的全新概念，后续章节会专门展开讨论。`

除了上述概念，香农还提出了一系列重要定理，对信息通信具有重要意义，虽然这些定理主要针对电子通信，但也与密码学有关。

#### Theorem 1: Shannon’s Source Coding Theorem

*如果压缩后的代码率低于源信息的香农熵，几乎必然会导致信息丢失。*

在信息理论中，熵是随机变量不确定性的度量，后文将详细阐述。该定理指出，若压缩方式使得编码速率低于源信息内容，则极大概率会丢失部分信息。压缩常与加密一起使用，以减少传输时间和带宽。香农的编码定理在数据压缩时尤为重要。

#### Theorem 2: Noisy Channel Theorem

*对于任何给定的信道噪声程度，都可以通过信道以可计算的最大速率，将离散数据（数字信息）几乎无误地传输。*
