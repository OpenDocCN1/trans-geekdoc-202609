
# [8](#part0017.xhtml#ch08qu8a). A `\_\_\_\_\_\_\_\_\_\_\_` provides the source of nonlinearity for a given cryptographic algorithm.

# [9](#part0017.xhtml#ch08qu9a). An S-box that transposes bits is called a `\_\_\_\_\_\_\_\_\_\_\_`.

# [10](#part0017.xhtml#ch08qu10a). What are the two concerns with using a compression S-box?

## Answers

# [1](#part0017.xhtml#ch08qu1). `multiplicative inverse`

# [2](#part0017.xhtml#ch08qu2). `*x*⁸ + *x*⁴ + *x*³ + *x* + 1`

# [3](#part0017.xhtml#ch08qu3). The S-box must produce at least 50 percent avalanche.

# [4](#part0017.xhtml#ch08qu4). The resulting bits must be independent of each other.

# [5](#part0017.xhtml#ch08qu5). Decimal 99, hex x63, or binary 1100011

# [6](#part0017.xhtml#ch08qu6). `30`

# [7](#part0017.xhtml#ch08qu7). Resistance to differential cryptanalysis

# [8](#part0017.xhtml#ch08qu8). `substitution box`

# [9](#part0017.xhtml#ch08qu9). `permutation box`

# [10](#part0017.xhtml#ch08qu10). Loss of data and an inability to decrypt enciphered messages
