
一种有用的思考方式是将可能的结果排列成所谓的*混淆矩阵*（confusion matrix）或*列联表*（contingency table）（`http://en.wikipedia.org/wiki/Confusion_matrix`）。[图 3.9](#c03.xhtml#c03-fig-0016) 展示了一个列联矩阵的示例。列联表中的数字代表基于上一段讨论的阈值选择的性能。[图 3.9](#c03.xhtml#c03-fig-0016) 中的列联矩阵总结了针对 135 个测试样本进行预测的结果，该预测采用了特定的阈值概率选择。该矩阵有两列，代表可能的预测结果。它还有两行，代表每个样本的真实情况（标签）。因此，测试集中的每个样本都可以被分配到表格中的四个单元格之一。[图 3.9](#c03.xhtml#c03-fig-0016) 中描绘的两种分类是“点击”和“不点击”，适用于广告选择。根据所解决的具体问题，这些也可能对应“欺诈”和“非欺诈”，或其他配对。

左上角的单元格包含预测为点击且与标签（真实情况）匹配的样本。这些被称为*真阳性*（true positive），通常缩写为 TP。左下角框中的条目对应预测为阳性（点击）但真实情况为阴性（不点击）的样本。这些被称为*假阳性*（false positive），缩写为 FP。矩阵的右列包含预测为不点击的样本。右上角的样本在真实情况下是点击，被称为*假阴性*（false negative），缩写为 FN。右下角的样本预测为不点击且与真实结果一致。它们被称为*真阴性*（true negative），缩写为 TN。

当概率阈值改变时会发生什么？考虑极端值。如果概率阈值设置为 0.0，无论模型预测什么概率，都会被指定为点击。所有样本都落在左列。右列全为 0。TP 的数量会上升到 17。FP 的数量会上升到 118。如果 FP 没有成本且真阴性（TN）没有奖励，那可能是一个不错的选择，但不需要预测算法就能假设每个输入样本都是点击。同样，如果 FN 没有成本且 TP 没有收益，阈值可以设置为 1.0，使所有样本都被分类为不点击。这些极端情况有助于理解，但在部署系统中并无用处。以下示例展示了如何为岩石与地雷数据集构建分类器的过程。
