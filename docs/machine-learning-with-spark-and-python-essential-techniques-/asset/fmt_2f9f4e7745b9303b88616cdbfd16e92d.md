
正如[第4章](#c04.xhtml)所述，分类的替代方法是使用惩罚逻辑回归，而非惩罚回归。[清单5-5](#c05.xhtml#c05-fea-0006)展示了惩罚逻辑回归的实现代码，用于构建岩石与地雷数据的分类器。该清单及其相关结果突出了这两种方法的异同。算法差异体现在迭代结构上。逻辑回归方法涉及使用属性的线性函数来计算每个训练样本为岩石或地雷的概率和似然。（更多关于逻辑回归的背景及相关方程的详细推导，请参见`http://en.wikipedia.org/wiki/Logistic_regression`。）非惩罚逻辑回归的算法称为*迭代重加权最小二乘法*（IRLS）。名称源于算法的性质（参见`http://en.wikipedia.org/wiki/Iteratively_reweighted_least_squares`）。它根据训练集中每个样本的概率估计推导权重。给定权重后，问题转化为加权最小二乘回归问题。该过程必须迭代进行，直到概率（及相应权重）不再变化。基本上，逻辑回归的IRLS在[第4章](#c04.xhtml)中你看到的（非逻辑）惩罚回归算法基础上增加了另一层迭代。

读取变量并归一化后，程序初始化逻辑回归及其惩罚版本核心的权重和概率。每次惩罚参数递减时，这些概率和权重都必须与系数（β）一起估计。你会在代码中看到一些变量名添加了`IRLS`字母，以表示它们与IRLS迭代层相关。估计概率的迭代位于λ递减的循环内部，并包裹着对β进行坐标下降迭代的循环。

更新细节比普通（非逻辑）惩罚回归算法稍复杂。一是IRLS带来的权重。权重和概率是逐个输入样本计算的。代码中用`p`和`w`表示。权重对*属性乘以残差*和*属性平方*等乘积求和的影响也需收集。这些用类似`sumWxx`的变量表示，它是一个列表，包含权重乘以各属性平方的和。另一复杂点是残差现在是标签、概率，以及（更熟悉的）属性及其系数（β）的函数。

代码运行后生成变量排序和系数曲线，以便与非逻辑惩罚回归生成的结果比较。逻辑变换导致非线性尺度变化，使系数直接对比变得困难。普通和逻辑回归（无论是否惩罚）都生成系数向量，再将（相同的）属性乘以它们并与阈值比较。阈值次要，因可在训练后确定（如前所示）。因此，β的整体尺度不如其分量间的相对大小重要。判断相对大小的一种方法是观察两种方法引入新变量的顺序。通过对比[清单5-5](#c05.xhtml#c05-fea-0006)和[清单5-4](#c05.xhtml#c05-fea-0005)的打印输出可见，两方法在前八个属性的排序上完全一致。接下来的八个变量中，有七个为两列表共有，只是顺序略有不同。再下八个大致相同。两方法的排序总体吻合度良好。
