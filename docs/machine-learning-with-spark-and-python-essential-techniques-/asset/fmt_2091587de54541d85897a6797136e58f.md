
随着数据集变大，分裂点计算的数量与数据集大小成正比。被检查的分裂点也可能变得极其接近。为超大数据集设计的算法允许分裂点检查比数据的原始粒度粗得多。论文“PLANET: Massively Parallel Learning of Tree Ensembles with MapReduce”中阐述了一种方法，概述了 Google 工程师在大数据集上构建决策树算法所采取的方法。正如论文中提到的，他们想要决策树算法以便实现梯度提升（本章后面将学习的集成算法之一）。

#### 递归分裂以增加树深度

[Listing 6-2](#c06.xhtml#c06-fea-0002) 展示了随着树深度从 1 增加到 2，预测曲线发生的变化。生成的预测曲线如 [Figure 6.6](#c06.xhtml#c06-fig-0006) 所示，树的框图如 [Figure 6.7](#c06.xhtml#c06-fig-0007) 所示。预测曲线不再是单个阶跃，而是有三个阶跃。第二组分裂点的确定方式与第一组相同。树中的每个节点处理由其上方分裂确定的点子集。每个节点的分裂点旨在最小化其下方两个节点中的平方误差之和。[Figure 6.6](#c06.xhtml#c06-fig-0006) 中的曲线用更精细的阶跃函数逼近实际曲线。更大的树深度会产生更精细的阶跃，并对训练数据有更高的保真度。这种情况会无限持续下去吗？

随着分裂的继续，最深节点中的样本数量减少。这可能导致分裂在达到指定深度之前终止。如果一个节点中只有一个样本，分裂当然无法继续。树训练算法通常有一个参数，用于控制要分裂的最小样本量。节点中的小样本量可能导致预测结果的高方差。

### 二叉树的过拟合

上一节展示了如何训练任意深度的二叉决策树。二叉树会过拟合吗？本节讨论如何测量和调节二叉树的过拟合。二叉树过拟合的机制与你在 [Chapter 4](#c04.xhtml) “惩罚线性回归” 和 [Chapter 5](#c05.xhtml) 中看到的不同，但你会在症状和过拟合测量方法上看到一些相似之处。你将看到二叉树具有参数（例如树深度和最小叶节点大小），可用于调节模型复杂度，这与你在 [Chapter 4](#c04.xhtml) 和 [Chapter 5](#c05.xhtml) 中看到的过程类似。

#### 用二叉树测量过拟合

[Figure 6.8](#c06.xhtml#c06-fig-0008) 展示了将树深度增加到 6 时会发生什么。在 [Figure 6.8](#c06.xhtml#c06-fig-0008) 中，很难分辨真实值与预测值的区别。预测几乎跟随每一个锯齿变化。这开始暗示模型正在过拟合数据。数据生成方式表明，最佳预测应为预测值等于属性值。添加到属性中的噪声是不可预测的，但预测却跟随了标签因噪声偏离属性值的情况。合成数据提供了知道正确答案的便利。

用二叉树查看过拟合的另一种方式是考虑树中终端节点的数量与可用数据量的对比。生成 [Figure 6.8](#c06.xhtml#c06-fig-0008) 所示预测的树深度为 6。这意味着它有 64 个终端节点 (2⁶)。数据集中有 100 个点。这意味着许多点是终端节点的唯一占有者，因此它们的预测值精确匹配其观测值。难怪预测图会匹配由噪声引起的摆动。

#### 平衡二叉树复杂度以获得最佳性能

在实际问题中，可以执行交叉验证来控制过拟合。[Listing 6-3](#c06.xhtml#c06-fea-0003) 展示了在不同深度的树上针对该简单问题运行的 10 折交叉验证。代码清单显示了两个循环。外层循环为内层交叉验证循环定义树深度。内层循环划分数据并进行 10 次迭代以计算样本外误差。每个深度的均方误差 (MSE) 结果绘制在 [Figure 6.9](#c06.xhtml#c06-fig-0009) 中。

![Figure 6.9: Out-of-sample error versus tree depth for simple problem](images/c06f009.png)

**Figure 6.9** ([#c06.xhtml#R_c06-fig-0009](#c06.xhtml#R_c06-fig-0009)): Out-of-sample error versus tree depth for simple problem

#### Listing 6-3 ([#c06.xhtml#R_c06-fea-0003](#c06.xhtml#R_c06-fea-0003)): Cross-Validation at a Range of Tree Depths—simpleTreeCV.py

```
__author__ = 'mike-bowles'

import numpy as np
import matplotlib.pyplot as plt
from sklearn import tree
from sklearn.tree import DecisionTreeRegressor


#Build a simple data set with y = x + random
nPoints = 1000

#x values for plotting
x = np.linspace(-0.5, 0.5, nPoints)
x_feat = x.reshape([-1,1])

#y (labels) has random noise added to x-value
#set seed
np.random.seed(1)
y = x + np.random.randn(nPoints) * 0.1

#perform 10-fold x-val to see what tree depth works best.
nrow = nPoints
depthList = [1, 2, 3, 4, 5, 6, 7]
xvalMSE = []
nxval = 10

for iDepth in depthList:

    #build x-val loop to fit tree and evaluate on out of sample data
    oosMSE = 0.0
    for ixval in range(nxval):

        #Define test and training index sets
        idxTest = [a for a in range(nrow) if a%nxval == ixval%nxval]
        idxTrain = [a for a in range(nrow) if a%nxval != ixval%nxval]

        #Define test and training attribute and label sets
        xTrain = x_feat[idxTrain]
        xTest = x_feat[idxTest]
        yTrain = y[idxTrain]
        yTest = y[idxTest]

        #train trees of various depths and accumulate test errors
        treeModel = DecisionTreeRegressor(max_depth=iDepth)
        treeModel.fit(xTrain, yTrain)
   
        treePrediction = treeModel.predict(xTest)
        error = yTest - treePrediction

        oosMSE += np.average(error * error) / nxval

    #average the squared errors and accumulate by tree depth

    xvalMSE.append(oosMSE)

plt.plot(depthList, xvalMSE)
plt.axis('tight')
plt.xlabel('Tree Depth' )
plt.ylabel('Mean Squared Error')
plt.title('MSE versus Tree Depth - '+ str(nPoints) + ' pts')
plt.savefig('CV_Perf_vs_Tree_depth-' + str(nPoints) +  '.png', dpi=500)
plt.show() 
```

树深度是调节二叉树模型复杂度的一种方式。它的效果类似于 [Chapter 4](#c04.xhtml) 和 [Chapter 5](#c05.xhtml) 中惩罚回归模型中的系数惩罚。更大的树深度使模型能够以增加复杂度为代价从数据中提取更复杂的行为。[Figure 6.8](#c06.xhtml#c06-fig-0008) 显示，对于 [Listing 6-2](#c06.xhtml#c06-fea-0002) 中的合成问题，深度 3 给出了最佳的 MSE 性能。该深度在复现潜在关系和过拟合问题之间做出了最佳权衡。
