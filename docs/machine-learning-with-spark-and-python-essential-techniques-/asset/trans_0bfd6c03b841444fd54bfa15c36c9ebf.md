
# 为什么这两种算法如此有用？

有几个因素使得惩罚线性回归和集成方法成为一个有用的组合。简单来说，它们将在实践中遇到的绝大多数预测分析（函数逼近）问题上提供最优或近似最优的性能，包括大数据集、小数据集、宽数据集、高瘦数据集、复杂问题和简单问题。这一断言的证据可以在 Rich Caruana 及其同事的两篇论文中找到：

*   “An Empirical Comparison of Supervised Learning Algorithms”，作者 Rich Caruana 和 Alexandru Niculescu-Mizil[¹](#c01.xhtml#c01-bib-0001)
*   “An Empirical Evaluation of Supervised Learning in High Dimensions”，作者 Rich Caruana、Nikos Karampatziakis 和 Ainur Yessenalina[²](#c01.xhtml#c01-bib-0002)

在这两篇论文中，作者选择了多种分类问题，并应用多种不同的算法来构建预测模型。这些模型在未包含在训练中的测试数据上运行，然后根据算法在问题上的表现对研究中包含的算法进行排名。第一项研究比较了 9 种不同的基础算法在 11 个不同机器学习（二元分类）问题上的表现。研究中使用的问题来自各个领域，包括人口统计数据、文本处理、模式识别、物理学和生物学。**[表 1.1](#c01.xhtml#c01-tbl-0001)** 列出了研究中使用的数据集，名称与研究作者给出的相同。表格显示了每个数据集可用于预测结果的属性数量，以及正例所占的百分比。

分类问题中的*正例*是指结果为正的实验（输入数据集中的一行数据）。例如，如果分类器旨在确定雷达回波信号是否表明飞机的存在，那么正例就是雷达视野中确实有飞机的那些回波。*正例*一词源于这种结果代表存在或不存在这类示例。其他例子包括医学检测中疾病的存在或不存在，或纳税申报中作弊的存在或不存在。

并非所有分类问题都涉及存在或不存在。例如，通过机器阅读文本或分析手写样本来确定作者的性别有两个类别——男性和女性——但不存在一方是另一方不存在的情况。在这些情况下，“正例”和“负例”标签的分配有一定的随意性。正负标签的分配可以是任意的，但一旦选定就必须始终如一地使用。

第一项研究中的一些问题，某一类别的示例比另一类别多得多。这些被称为*不平衡*问题。例如，`Letter.p1` 和 `Letter.p2` 这两个数据集提出了密切相关的问题，即在各种字体中正确分类打印的大写字母。`Letter.p1` 的任务是在标准字母混合中正确分类字母 *O*。`Letter.p2` 的任务是正确分类 *A–M* 与 *N–Z*。**[表 1.1](#c01.xhtml#c01-tbl-0001)** 中显示的正例百分比反映了这一差异。

**[表 1.1](#c01.xhtml#c01-tbl-0001)** 还显示了每个数据集中的“属性”数量。属性是你可用来进行预测的变量。例如，为了预测飞机是否准时到达目的地，你可能会纳入航空公司名称、飞机型号和年份、目的地机场降水量、航路沿线风速和风向等属性。拥有大量可用于预测的属性既是福也是祸。与预测结果直接相关的属性是福；与结果无关的属性则是祸。区分福祸属性需要数据。**[第 3 章](#c03.xhtml)** “预测模型构建：平衡性能、复杂性和大数据”将更详细地讨论这一点。
