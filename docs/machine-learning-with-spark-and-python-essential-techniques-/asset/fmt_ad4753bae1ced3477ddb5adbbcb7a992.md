正如你将在[第 3 章](#c03.xhtml)以及[第 5 章](#c05.xhtml)“使用惩罚线性方法构建预测模型”和[第 7 章](#c07.xhtml)“使用 Python 构建集成模型”中的示例所见，当属性众多而样本或训练时间不足以训练更复杂的集成模型时，惩罚回归方法相对于其他算法表现最佳。

Caruana 等人在 2008 年进行了一项新研究，探讨属性数量增加时这些算法的对比情况，即它们在大数据上的表现如何。许多领域的属性数量远超第一项研究中的数据集。例如，基因组学问题拥有数万个属性（每个基因一个属性），文本挖掘问题可拥有数百万个属性（每个不同单词或单词对一个属性）。[表 1.3](#c01.xhtml#c01-tbl-0003) 展示了线性回归和集成方法随属性增长的表现。[表 1.3](#c01.xhtml#c01-tbl-0003) 显示了第二项研究中各算法的排名。表格展示了各算法在每个问题上的单独表现，最右列显示了各算法在所有问题上的平均得分排名。研究中的算法分为两组：上组算法将在本书中介绍，下组则不涉及。

[表 1.3](#c01.xhtml#c01-tbl-0003) 中的问题按属性数量排序，范围从 761 到 685,569。线性（逻辑）回归在研究使用的 11 个测试用例中有 5 个位居前三。这些优异成绩集中在较大的数据集上。注意，提升决策树（[表 1.3](#c01.xhtml#c01-tbl-0003) 中用 `BSTDT` 表示）和随机森林（用 `RF` 表示）算法仍表现靠前，它们在这些问题上的总分分别排名第一和第二。

本书涵盖的算法除原始预测性能外还有其他优势。本书介绍的惩罚线性回归模型的一大优势是训练速度快。在大规模问题上，训练速度可能成为瓶颈。某些问题的模型训练可能耗时数天或数周，这在开发早期需要迭代寻找最佳方案时尤为难以接受。除了训练极快，部署后的线性模型还能极快地生成预测——足以胜任高频交易或互联网广告插入。研究表明，惩罚线性回归在许多情况下能提供最佳答案，即使不是最佳也能接近顶尖水平。

此外，这些算法使用起来相对容易。它们没有太多可调参数，具有定义良好、结构清晰的输入类型，能解决回归和分类中的多种问题。在开始新问题后一两小时内，通常就能整理好输入数据并生成首个训练模型及性能预测。

它们最重要的特性之一是能指示哪些输入变量对预测最重要。这被证明是机器学习算法中极其宝贵的特性。预测模型开发中最耗时的步骤之一是所谓的“特征选择”或“特征工程”，即数据科学家选择用于预测结果的变量。通过按重要性对特征排序，本书涵盖的算法减少了开发过程中的猜测，使流程更加确定。

## 什么是惩罚回归方法？

惩罚线性回归是“普通最小二乘”（`OLS`）回归的衍生形式——这是高斯和勒让德约 200 年前开发的方法。惩罚线性回归方法旨在克服 `OLS` 回归的一些基本局限。`OLS` 的基本问题是有时会过拟合。可将 `OLS` 视为拟合一条穿过一组点的线，如[图 1.1](#c01.xhtml#c01-fig-0001)所示。这是一个简单的预测问题：给定单个属性 `x`，预测目标值 `y`。例如，仅用身高预测男性薪资。身高对男性薪资略有预测力（但对女性无效）。

![图 1.1：普通最小二乘拟合](images/c01f001.png)

**[图 1.1](#c01.xhtml#R_c01-fig-0001)：普通最小二乘拟合**

[图 1.1](#c01.xhtml#c01-fig-0001) 中的点代表男性薪资与身高的关系。图中的线代表该预测问题的 `OLS` 解。在某种意义上，这条线是基于身高预测男性薪资的最佳模型。数据集包含六个点。假设数据集只有两个点。想象存在一个类似[图 1.1](#c01.xhtml#c01-fig-0001)的点群体，但你无法看到所有点。也许生成它们成本太高，如前所述的基因数据。有足够的人类可用于分离罪魁祸首基因，问题在于因成本原因你没有许多人的基因序列。
