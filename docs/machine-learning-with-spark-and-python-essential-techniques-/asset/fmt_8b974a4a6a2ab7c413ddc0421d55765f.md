
稀疏系数向量是算法告诉你可以完全忽略某些变量的方式。当 $\lambda$ 变得足够小时，$\beta_2$ 和 $\beta_1$ 的最佳值将脱离 $\beta_2$ 轴，且两者均为非零。较小的惩罚即可使 $\beta_1$ 变为非零这一事实，给 $\beta_2$ 和 $\beta_1$ 确立了顺序。在某种意义上，$\beta_2$ 比 $\beta_1$ 更重要，因为它在更大的 $\lambda$ 值下获得非零系数。请记住，这些系数乘以属性。如果对应某属性的系数为零，算法即在告诉你该属性不如获得非零系数的属性重要。通过从大到小扫描 $\lambda$，你可以按重要性对所有属性排序。下一节将通过具体问题演示这一点，并展示 Python 代码，在求解 [Equation 4.8](#c04.xhtml#c04-fig-0008) 的过程中明确属性间的重要性比较。

### ElasticNet 惩罚融合了 Lasso 和 Ridge

在了解如何计算这些系数之前，你还需要知道惩罚回归问题的另一种广义表述。这称为 ElasticNet 表述。ElasticNet 表述的惩罚回归问题，是使用 Ridge 惩罚和 Lasso 惩罚的可调混合。ElasticNet 引入了另一个参数 $\alpha$，用于参数化总惩罚中 Ridge 惩罚所占的比例和 Lasso 惩罚所占的比例。端点 $\alpha=1$ 对应全 Lasso 惩罚、无 Ridge 惩罚。端点 $\alpha=0$ 对应全 Ridge 惩罚。

在 ElasticNet 表述中，必须同时指定 $\lambda$ 和 $\alpha$ 才能求解线性模型的系数。通常的做法是选定一个 $\alpha$ 值，然后求解一系列 $\lambda$ 的值。稍后你将看到这样做的计算原因。在许多情况下，$\alpha=1$ 与 $\alpha=0$ 或某个中间 $\alpha$ 值之间没有巨大的性能差异。有时差异会很大，因此你最好检查几个不同的 $\alpha$ 值，以确保不会无谓地牺牲性能。

## 求解惩罚线性回归问题

在前一节中，你了解到确定惩罚线性回归模型等同于求解一个优化问题。许多通用数值优化算法可求解 [Equations 4.6](#c04.xhtml#c04-fig-0006)、[4.8](#c04.xhtml#c04-fig-0008) 和 ElasticNet 中的优化问题，但惩罚线性回归问题的重要性促使研究人员开发了专用算法，能极快地生成解。本节介绍这些算法的基础并运行代码，以便你理解每种算法的机制。本节讲解两种算法的机制：*最小角回归*（LARS）和 `glmnet`。选择这两种是因为它们可以相互关联，也能关联到你已见过的一些方法，如 Ridge 回归和前向逐步回归。此外，它们训练速度极快，且作为 Python 包的一部分可用。[第 5 章](#c05.xhtml)“使用惩罚线性方法构建预测模型”将使用包含这些算法的 Python 包来探索示例问题。

### 理解最小角回归及其与前向逐步回归的关系

一种非常快、非常巧妙的算法是由 Bradley Efron、Trevor Hastie、Iain Johnstone 和 Robert Tibshirani 开发的最小角回归（LARS）算法（`http://en.wikipedia.org/wiki/Least-angle_regression`）。LARS 算法可理解为对你在 [第 3 章](#c03.xhtml) 中看到的前向逐步算法的一种改进。前向逐步算法总结如下：

**前向逐步回归算法**

*   将所有 $\beta$ 初始化为零。

**每一步**

*   计算使用已选变量后的残差（误差）。
*   确定哪个未用变量最能解释残差，并将其加入模型。

LARS 算法非常相似。主要区别在于 LARS 不会无保留地纳入每个新属性，而只是部分纳入。LARS 算法总结如下：

**最小角回归算法**

*   将所有 $\beta$ 初始化为零。

**每一步**

*   确定哪个属性与残差的相关性最大。
*   若相关性为正，则以微小量增加该变量的系数；若为负，则以微小量减少。
