[图 5.9](#c05.xhtml#c05-fig-0009) 展示了使用惩罚逻辑回归对岩石与地雷数据的系数曲线。如前所述，由于两种方法中逻辑函数的差异，系数的尺度与普通惩罚回归不同。普通回归试图拟合一条直线来逼近值为 0.0 和 1.0 的目标。逻辑回归则通过拟合一条直线来逼近“log odds ratio（对数几率比）”，从而预测类别成员的概率。假设 `p` 是某样本对应地雷类别的预测概率。那么几率比就是比率 `p / (1 - p)`。对数几率比是几率比的自然对数。当 `p` 的范围是 0 到 1 时，`p` 的对数几率比范围是从负无穷到正无穷。对数几率非常大且为正的情况，对应于模型非常确信该样本属于地雷类别的情况。而非常大的负数则对应岩石类别。
