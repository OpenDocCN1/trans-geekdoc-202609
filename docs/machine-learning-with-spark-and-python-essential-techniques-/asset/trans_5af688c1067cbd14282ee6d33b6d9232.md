## [清单 2-3](#c02.xhtml#R_c02-fea-0004)：数值与分类属性的汇总统计 — rVMSummaryStats.py

```
__author__ = 'mike_bowles'
import numpy as np

#read data from uci data repository
xList = list_read_rvm()
 
nrow = len(xList)
ncol = len(xList[1])

type = [0]*3

#generate summary statistics for column 3 (e.g.)
col = 3
colData = []
for row in xList:
    colData.append(float(row[col]))

colArray = np.array(colData)
colMean = np.mean(colArray)
colsd = np.std(colArray)
print("Mean = " + '\t' + str(colMean) + '\t\t' +
            "Standard Deviation = " + '\t ' + str(colsd))


#calculate quantile boundaries
ntiles = 4

percentBdry = []

for i in range(ntiles+1):
    percentBdry.append(np.percentile(colArray, i*(100)/ntiles))

print("\nBoundaries for 4 Equal Percentiles")
print(percentBdry)
print(" \n")
```

代码的第一部分选取一列数值数据，然后为其生成一些统计信息。第一步是计算所选属性的**均值**和**标准差**。了解这些将为你在开发模型时建立直觉提供基础。

代码的下一部分用于寻找**离群值**。其工作原理如下。假设你试图判断以下数字列表中是否存在离群值：`[0.1, 0.15, 0.2, 0.25, 0.3, 0.35, 0.4, 4]`。此示例特意构造了一个离群值。最后一个数字（`4`）与其他数字相比显然超出了量级。

揭示此类不匹配的一种方法是将一组数字划分为百分位数。例如，第 25 百分位包含最小的 25% 的数据。第 50 百分位包含最小的 50% 的数据。可视化这些分组形成过程的最简单方法是想象数据已按数值顺序排序。前面列表中的数字已按数值顺序排列。这使得很容易看出百分位边界的位置。一些常用的百分位数有特殊的名称。将集合划分为相等的四分之一、五分之一和十分之一所定义的百分位数分别称为`四分位数`、`五分位数`和`十分位数`。

对于前面的列表，因为列表已排序且包含八个元素，所以很容易定义四分位数。第一四分位数包含 `0.1` 和 `0.15`，以此类推。请注意这些四分位数的宽度。第一四分位数的范围是 `0.5`（`0.15–0.1`）。第二四分位数大致相同。然而，最后一个四分位数的范围是 `4.6`，这是其他四分位数范围的 100 倍。

你可以在[清单 2-3](#c02.xhtml#c02-fea-0004) 中计算出的四分位边界中看到类似的行为。首先程序计算四分位数。这显示出上四分位数比其他四分位数宽得多。为了更确定，还计算了十分位边界，同样表明上十分位异常宽。由于分布在尾部通常会变稀疏，因此一定程度的变宽是正常的。

## 使用分位数-分位数图可视化离群值

更详细地研究离群值的一种方法是，将相关数据的分布与某些合理的分布进行绘图对比，以查看相对数值是否匹配。[清单 2-4](#c02.xhtml#c02-fea-0005) 展示了如何使用 Python 函数 `probplot` 来帮助确定数据集是否存在离群值。生成的图表显示了数据中经验百分位数相关的边界与高斯分布相同百分位数的边界之间的比较。如果被分析的数据来自高斯分布，绘制的点将落在一条直线上。[图 2.1](#c02.xhtml#c02-fig-0001) 显示，岩石与地雷数据第 4 列的几个点距离该直线非常远。这意味着岩石与地雷数据的尾部包含的样本比高斯密度的尾部更多。
