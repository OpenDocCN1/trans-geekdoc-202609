
在本表中，结果（2013年的花费）为实数值——这使其成为一个回归问题。性别属性（特征1）为双值，使其成为一个分类（或因子）属性。其他两个属性为数值型。函数逼近问题的目标是（1）建立一个将属性与结果相关联的函数，以及（2）在某种意义上最小化误差。[第3章](#c03.xhtml)讨论了可用于量化总体误差的一些替代误差表征。

如[表4.1](#c04.xhtml#c04-tbl-0001)所示类型的数据集，通常由一个包含结果的列向量（[表4.1](#c04.xhtml#c04-tbl-0001)中的第一列）和包含属性的其他列（第一列之后的三个特征列）来表示。属性是用于预测结果的可用信息。数据科学家通常将[表4.1](#c04.xhtml#c04-tbl-0001)中的这种数据结构称为`dataframe`。在`dataframe`中，一列中的数据类型均相同：实数、整数、字符串变量，有时也包括布尔值。你可以在Python pandas和PySpark中（以及R编程语言中）找到`dataframe`。`dataframe`的形状与矩阵相同，但矩阵包含的元素均为相同的数值类型：实数、整数或布尔值。矩阵不能混合实数和分类变量。

这里有一个重要的观点。线性方法仅适用于数值数据。[表4.1](#c04.xhtml#c04-tbl-0001)中的数据包含非数值数据，因此线性方法无法直接用于所示数据。幸运的是，将[表4.1](#c04.xhtml#c04-tbl-0001)中的数据转换（或编码）为数值数据相对简单。在存在两个不同类别的情况下（如[表4.1](#c04.xhtml#c04-tbl-0001)中，可能性为M或F），你可以用`0.0`替代M，用`1.0`替代F，然后进行线性回归。你将在“将非数值属性纳入线性方法”一节中学习一种将分类属性编码为数值属性的更通用技术。
