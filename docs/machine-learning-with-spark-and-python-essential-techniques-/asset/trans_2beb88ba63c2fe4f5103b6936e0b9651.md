
目标 $y_i$ 对应于 $x_i$——即 X 的第 *i* 行中的预测变量。参考[表 3.1](#c03.xhtml#c03-tbl-0001)中的数据，$y_1$ 为 Yes，$y_2$ 为 No。

目标可以有几种不同的形式。例如，它们可以是实数，就像目标是预测客户将花费多少钱时那样。当目标为实数时，该问题称为*回归问题*。线性回归意味着使用线性方法来解决回归问题。（本书涵盖了线性和非线性回归方法。）

如果目标是双值的，如[表 3.1](#c03.xhtml#c03-tbl-0001)所示，该问题称为*二分类问题*。预测客户是否会点击广告就是一个二分类问题。如果目标包含若干个离散值，则该问题为*多分类问题*。预测客户会点击几个广告中的哪一个将是一个多分类问题。

### 简单问题与复杂问题的对比

本章前一节描述了量化性能的几种方法，并强调了新数据性能的重要性。设计预测模型的目标是在新样本（如您网站的新访客）上做出准确预测。作为一名实践数据科学家，您会希望获得算法性能的估计，以便设定客户预期并比较不同算法。预测建模的最佳实践要求您从训练集中保留一些数据。这些保留的样本具有相关标签，可以与在剩余数据上训练的模型产生的预测进行比较。统计学家将此技术称为*样本外误差*，因为它是未用于训练的数据上的误差。（本章后面的“[测量预测模型的性能](#c03.xhtml#c03-sec-0010)”一节将更详细地介绍此过程的机制。）重要的是，唯一算数的性能是模型在针对新样本运行时的性能。
