
你可能想问数据的另一个问题是各个属性之间是如何相互关联的。快速了解成对关系的一种方法是将带标签的属性进行交叉绘图。[清单 2-7](#c02.xhtml#c02-fea-0008) 展示了为几对代表性属性生成交叉图所需的内容。这些交叉图（也称为散点图）能让你看出成对变量之间的关联程度。

#### [清单 2-7](#c02.xhtml#R_c02-fea-0008)：属性成对交叉绘图 — corrPlot.py

[图 2.4](#c02.xhtml#c02-fig-0004) 和 [2.5](#c02.xhtml#c02-fig-0005) 展示了来自岩石与地雷数据集的两对属性的散点图。岩石与地雷的属性是声纳回波的样本。声纳信号被称为*调频*波形，因为它是一个从低频开始并在脉冲持续时间内频率升高的脉冲。岩石与地雷数据集中的属性是反射自岩石或地雷的声波的时间样本。这些返回的声学信号在时间和频率之间具有与发射信号相同的关系。岩石与地雷数据中的 60 个属性是在 60 个不同时间（因此也是 60 个不同频率）下采集的回波样本。你会预期相邻属性比在时间上分离的属性更具相关性，因为相邻时间样本之间的频率差别不大。

#### [清单 2-8](#c02.xhtml#R_c02-fea-0009)：分类目标与实值属性之间的相关性 — targetCorr.py

```
__author__ = 'mike_bowles'
from random import uniform

#将岩石与地雷数据读入 pandas 数据框
rocksVMines = pd_read_rvm() 
   
#将目标转换为数值
target = []
for i in range(208):
    #根据 "M" 或 "R" 标签分配 0 或 1 目标值
    if rocksVMines.iat[i,60] == "M":
        target.append(1.0)
    else:
        target.append(0.0)

    #将数据行绘制为序列数据
dataRow = rocksVMines.iloc[0:208,35]
plt.scatter(dataRow, target)

plt.xlabel("属性值")
plt.ylabel("目标值")
plt.show()

#
#为了改善可视化效果，此版本对点进行轻微抖动
# 并使其具有一定透明度
target = []
for i in range(208):
    #根据 "M" 或 "R" 标签分配 0 或 1 目标值
    # 并添加一些抖动
    if rocksVMines.iat[i,60] == "M":
        target.append(1.0 + uniform(-0.1, 0.1))
    else:
        target.append(0.0 + uniform(-0.1, 0.1))

    #将数据行绘制为序列数据
dataRow = rocksVMines.iloc[0:208,35]
plt.scatter(dataRow, target, alpha=0.5, s=120)

plt.xlabel("属性值")
plt.ylabel("目标值")
plt.show() 
```

这些图展示了如果你创建一个与 R 或 M 目标列表对应的列表，但将 M 替换为 1，R 替换为 0，会发生什么。然后你可以绘制如[图 2.6](#c02.xhtml#c02-fig-0006) 所示的散点图。[图 2.6](#c02.xhtml#c02-fig-0006) 凸显了交叉图的一个常见问题。当被绘制的变量之一只取少量离散值时，点会重叠在一起。如果数量很多，你只会得到一条粗粗的深色线，无法感知点沿线的分布情况。

![图 2.7：带点抖动和部分不透明度的目标-属性交叉图](images/c02f007.png)

[**图 2.7**](#c02.xhtml#R_c02-fig-0007)：带点抖动和部分不透明度的目标-属性交叉图

[清单 2-8](#c02.xhtml#c02-fea-0009) 中的代码通过两个小改动生成了第二个图，以克服这个问题。向每个点添加一个小随机数，这些点原本只取少量离散值（本例中为目标值）。目标值由构造决定只能是 0 或 1。在代码中，你会看到添加的随机数在 -0.1 和 0.1 之间均匀分布。这将点分开，但不会分得太远以至于混淆两条线。其次，点以 `alpha=0.5` 绘制，使其仅部分不透明。这样，任何重叠绘制都会在散点图中显示为加深的区域。你可能需要微调这些数字，以使图表展示你所需的信息。

[图 2.7](#c02.xhtml#c02-fig-0007) 展示了这两项改动的效果。注意上带点的左端属性 35 的浓度略高，而下带点从右到左分布更均匀。上带点对应地雷，下带点对应岩石。你可以通过测试属性 35 是大于还是小于 0.5 来为该问题构建一个分类器。如果大于 0.5 则判为岩石，如果小于 0.5 则判为地雷。属性 35 小于 0.5 的示例包含更高浓度的地雷而非岩石，而属性 35 大于 0.5 的示例包含较低密度的地雷，因此你的表现会比随机猜测好得多。
