## 关于技术编辑

**James York-Winegar** 是 Accenture Enkitec Group 的基础设施首席顾问。James 通过帮助从初创公司到大型企业的各种规模公司弥合系统管理与数据科学之间的鸿沟，协助它们管理数据生命周期。他以物理学起家，曾在超级计算机上进行大规模量子化学模拟，随后投身技术领域。他拥有伯克利大学的数据科学硕士学位。
