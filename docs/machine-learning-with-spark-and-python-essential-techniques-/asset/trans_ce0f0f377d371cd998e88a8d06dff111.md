
在 `glmnet` 中，残差之间的相关性被用来计算每个系数的大小应改变多少。但在导致 ![images](images/c04-i0067.png)<math display="inline" overflow="scroll" xmlns="http://www.w3.org/1998/Math/MathML" xmlns:xlink="http://www.w3.org/1999/xlink"><mrow><msubsup><mrow><mi>&#946;</mi></mrow><mrow><mi>j</mi></mrow><mrow><mo>~</mo></mrow></msubsup></mrow></math> 发生变化之前，结果会先通过函数 `S()`。函数 `S()` 是 Lasso 系数收缩函数。它绘制在 [图 4.5](#c04.xhtml#c04-fig-0013) 中。正如你在 [图 4.5](#c04.xhtml#c04-fig-0013) 中所见，如果第一个输入小于第二个，输出为零。如果第一个输入大于第二个，输出为第一个输入减去第二个输入后的值。这被称为软限幅器。

[清单 4.3](#c04.xhtml#c04-fea-0004) 展示了 `glmnet` 算法的代码。你可以在代码中看到如何使用 [公式 4.9](#c04.xhtml#c04-fig-0014)（用于更新 *β *'*s*）来生成 ElasticNet 系数曲线。[清单 4.3](#c04.xhtml#c04-fea-0004) 中的代码标注了 Friedman 论文中的公式编号。该论文非常通俗易懂，如果你感兴趣，可以参考它以获取更多数学细节。

### 初始化和迭代 Glmnet 算法

迭代从一个较大的 λ 值开始。它从一个足以使所有 β 's 为零的 λ 值开始。你可以通过参考 [公式 4.9](#c04.xhtml#c04-fig-0014) 来了解如何计算 λ 的起始值。[公式 4.9](#c04.xhtml#c04-fig-0014) 中的函数 `S()` 如果其第一个输入（![images](images/c04-i0070.png)<math display="inline" overflow="scroll" xmlns="http://www.w3.org/1998/Math/MathML" xmlns:xlink="http://www.w3.org/1999/xlink"><msub><mi>x</mi><mrow><mi>i</mi><mi>j</mi></mrow></msub><msub><mi>r</mi><mi>i</mi></msub></math> 的相关性）小于第二个输入——λα，则输出为零。迭代开始时所有 *β *'*s* 都等于零，因此残差等于原始标签。用于确定起始 lambda 的代码计算每个属性与标签之间的相关性，找到幅度最大的一个，然后求解使最大相关性恰好等于 λα 的 λ 值。这是导致所有 β 为零的最大 λ 值。

然后迭代通过减小 λ 开始。这是通过将 λ 乘以一个略小于 1 的数来实现的。Friedman 建议选择乘数使得 ![images](images/c04-i0075.png)<math display="inline" overflow="scroll" xmlns="http://www.w3.org/1998/Math/MathML" xmlns:xlink="http://www.w3.org/1999/xlink"><mrow><msup><mrow><mi>&#955;</mi></mrow><mrow><mn>100</mn></mrow></msup><mo>=</mo><mn>0.001</mn></mrow></math>。这给出的值大约为 0.93。如果算法运行很长时间仍未收敛，则需要使 λ 的乘数更接近 1。在 Friedman 的代码中，实现这一机制的方法是将步数从 100 增加到（例如）200，这样将起始 λ 减少到其起始值的 0.001 需要 200 步。在 [清单 4.3](#c04.xhtml#c04-fea-0004) 中，你可以直接控制乘数。系数曲线如 [图 4.6](#c04.xhtml#c04-fig-0015) 所示。

#### 清单 4.3：Glmnet 算法——glmnetWine2.py

```
__author__ = 'mike_bowles'

from Read_Fcns import list_read_wine
import numpy as np
from sklearn import datasets, linear_model
from math import sqrt
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler

def S(z, gamma):
    if gamma >= abs(z):
        return 0.0
    return (z / abs(z)) * (abs(z) - gamma)

# 将葡萄酒数据读入属性行列表和标签列表
names, xList, labels = list_read_wine()
nrows = len(xList)
ncols = len(xList[0])

# 归一化 x 
xScaler = StandardScaler()
xNormalized = xScaler.fit_transform(xList)

# 归一化标签
yScaler = StandardScaler()
labelNormalized = yScaler.fit_transform(np.array(labels).reshape(
                   [-1, 1]))

# 选择 alpha 参数的值
alpha = 1.0

# 定义迭代参数
nSteps = 100
lamMult = 0.93 # 100 步使 lambda 减少 1000 倍

# 遍历数据一次以确定恰好抑制所有系数为零的 lambda 值
xy = np.mean(xNormalized * labelNormalized, axis=0)
maxXY = np.amax(np.abs(xy))
lam = maxXY / alpha  # 起始 lambda 值

# 初始化系数向量 beta
beta = np.zeros([ncols, 1])

# 初始化每一步的 beta 矩阵
betaMat = beta.copy()

# 开始迭代
nzList = [] # 按进入顺序排列的 betas

for iStep in range(nSteps):
    # 减小 lambda 使某个系数变为非零
    lam = lam * lamMult

    deltaBeta = 100.0
    eps = 0.01
    iterStep = 0
    betaInner = beta.copy()
    while deltaBeta > eps:
        iterStep += 1
        if iterStep > 100: break

        # 循环遍历属性并一次更新一个
        # 记录起始值用于比较
        betaStart = betaInner.copy()
        for iCol in range(ncols):
            residual = labelNormalized - np.dot(xNormalized, betaInner)
            xjr = np.mean(xNormalized[:, iCol].reshape([-1, 1]) * \
                    residual)
            uncBeta = xjr + betaInner[iCol] 
            betaInner[iCol] = S(uncBeta[0], lam * alpha) / (1 + \
                                            lam * (1 - alpha))

        sumDiff = np.sum(np.abs(betaInner - betaStart))
        sumBeta = np.sum(np.abs(betaInner))
        deltaBeta = sumDiff / sumBeta
  
    print('\r', 'Step', iStep, 'Iteration', iterStep, end='')
    beta = np.array(betaInner.copy()).reshape([-1, 1])

    # 将新确定的 beta 添加到列表
    betaMat = np.concatenate((betaMat, beta.copy()), axis=1)

    # 跟踪 betas 变为非零的顺序
    nzBeta = [index for index in range(ncols) if beta[index] != 0.0]
    for q in nzBeta:

        if (q in nzList) == False:
            nzList.append(q)

# 打印出有序的 beta 列表
nameList = [names[nzList[i]] for i in range(len(nzList))]
print('\n\n', nameList)

nPts = betaMat.shape[1]

for i in range(ncols):
    # 绘制每个属性的 beta 值范围
    coefCurve = betaMat[i,:].reshape([-1,])
    xaxis = range(nSteps + 1)
    plt.plot(xaxis, coefCurve)
plt.xlabel("Steps Taken")
plt.ylabel(("Coefficient Values"))
# plt.savefig('glmnetWine2.png', dpi=500)
plt.show()

打印输出：
Step 99 Iteration 1

alcohol, volatile acidity, sulphates, total sulfur dioxide, chlorides, 
fixed acidity, pH, free sulfur dioxide, residual sugar, citric acid,
density 
```
