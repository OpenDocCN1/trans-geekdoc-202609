
代码的第一部分从加州大学欧文分校（UCI）数据存储库读取输入数据，然后将其格式化为用于标签的列表和用于属性的列表的列表。下一步是将数据（标签和属性）分成两个子集：包含三分之一数据的测试集，和包含另外三分之二数据的训练集。标记为 `test` 的数据不会用于训练分类器，而是会在分类器训练完成后保留用于评估性能。这一步模拟了分类器在部署后对新数据示例的行为。稍后，本章将讨论各种不同的留出数据方法以及对新数据性能进行估计的方法。

通过将原始数据集中的标签 M（代表 mine，地雷）和 R（代表 rock，岩石）转换为数值——1.0 对应地雷，0.0 对应岩石——然后使用普通最小二乘回归拟合线性模型来训练分类器。这是一种相当简单易懂且易于实现的方法，通常能产生与稍后讨论的更复杂算法非常相似的性能。[Listing 3.2](#c03.xhtml#c03-fea-0002) 中的程序使用 `scikit-learn` 中的线性回归类来训练普通最小二乘模型。然后使用训练好的模型在训练集和测试集上生成预测。

代码打印出预测值的一些代表性数值。线性回归模型生成的数字大多在 0.0 到 1.0 的区间内，但并非完全如此。这些预测值并不完全是概率。它们仍可通过与阈值比较来生成预测分类。函数 `confusionMatrix()` 生成混淆矩阵的数值，类似于 [Figure 3.9](#c03.xhtml#c03-fig-0016)。它接受预测值、相应的实际值（标签）和一个阈值作为输入。它将预测值与阈值比较，以确定将每个示例分配到混淆矩阵的“预测为正”还是“预测为负”列。它使用实际值将示例分配到混淆矩阵的相应行。

可以从混淆矩阵中读出每个阈值对应的错误率。总错误数是 FP（假正例）和 FN（假反例）之和。示例代码生成了样本内数据和样本外数据的混淆矩阵，并将两者都打印出来。样本内数据的误分类错误率约为 8%，样本外数据约为 26%。通常，样本外性能会比样本内性能差。它也能更具代表性地反映新示例的预期误差。

当阈值改变时，误分类错误率也会随之变化。[Table 3.2](#c03.xhtml#c03-tbl-0002) 展示了误分类错误率如何随着决策阈值的变化而变化。表中的数字基于样本外结果。这通常适用于本书中表征性能的数字。任何样本内错误都会附带警告标签：“警告：这些是样本内错误。”如果目标是最小化误分类错误，最佳阈值为 0.25。

**表 3.2**：误分类错误对决策阈值的依赖关系

| 决策阈值 | 误分类错误率 |
| --- | --- |
| 0.0 | 28.6% |
| 0.25 | 24.3% |
| 0.5 | 25.7% |
| 0.75 | 30.0% |
| 1.0 | 38.6% |

最佳阈值可能是使误分类错误最小化的那个。然而，有时一种错误类型的代价比另一种高。例如，假设在岩石与地雷的问题中，派遣潜水员进行目视检查的成本是 100 美元，而如果未清除地雷，未爆地雷造成的预期伤亡和财产损失成本为 1,000 美元。FP 成本 100 美元，FN 成本 1,000 美元。基于这些假设，[Table 3.3](#c03.xhtml#c03-tbl-0003) 总结了不同阈值下错误的美元成本。将地雷误判为岩石（并将其留在原地威胁健康安全）的较高成本将决策阈值推低至零。这意味着会有更多 FN，但它们的代价不那么高昂。更彻底的分析可以包括与 TP（真正例）和 TN（真反例）相关的成本。例如，TP 可能包含清除地雷的成本，以及因清除地雷而带来的 +1,000 美元收益。如果这些数字在你的问题中可用（或可合理估算），你最好利用它们来得出更好的阈值。

**表 3.3**：不同决策阈值下的错误成本

| 决策阈值 | 假反例成本 | 假正例成本 | 总成本 |
| --- | --- | --- | --- |
| 0.0 | 1,000 | 1,900 | 2,900 |
| 0.25 | 3,000 | 1,400 | 4,400 |
| 0.5 | 9,000 | 900 | 9,900 |
| 0.75 | 18,000 | 300 | 18,300 |
| 1.00 | 26,000 | 100 | 26,100 |

请注意，总 FP 与 FN 的相对成本取决于数据集中正例和反例的比例。岩石与地雷数据集拥有相同数量的正例和反例（地雷和岩石）。这大概是由实验方案决定的。实际部署中遇到的正例和反例比例可能不同。如果部署时的数字可能不同，你需要做一些调整以适应实际使用中的比例。

数据科学家可能没有可用的成本数据，但可能仍希望用一种方法来表征分类器的整体性能，而不是使用特定决策阈值下的误分类错误率。一种常用的技术称为*受试者工作特征曲线*（ROC 曲线）（`http://en.wikipedia.org/wiki/Receiver_operating_characteristic`）。

作为一个简单的思想实验，考虑使用一个极低的决策阈值。对于极低的值，每个示例都被预测为正例。这使得 TPR 为 1.0。因为所有东西都被分类为正例，所以没有 FN（FN 为 0.0）。这也使得 FPR 为 1.0，因为没有东西被分类为负例（TN 为 0.0）。然而，当决策阈值设得非常高时，TP 等于零，因此 TPR 也是零，FP 也是零，因为没有东西被分类为正例。因此，FPR 也是零。以下两个图是使用 `pylab` 的 `roc_curve()` 和 `auc()` 函数绘制的。[Figure 3.10](#c03.xhtml#c03-fig-0019) 显示了基于样本内数据的 ROC 曲线性能。[Figure 3.11](#c03.xhtml#c03-fig-0020) 显示了基于样本外数据的 ROC 曲线。
