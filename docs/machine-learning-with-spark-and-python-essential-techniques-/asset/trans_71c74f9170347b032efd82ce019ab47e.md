## 多类分类问题：那是什么类型的玻璃？

多类分类与二元分类类似，区别在于有多个可能的离散结果，而不仅仅是两个。回想一下，探测未爆炸地雷的问题涉及两种可能的结果：声纳照射的物体是岩石还是地雷。根据化学成分测量值确定葡萄酒口感的问题有几种可能的结果（口感评分从 3 到 8）。但对于葡萄酒问题，评分之间存在顺序关系。评分为 5 的葡萄酒比评分为 3 的好，但比评分为 8 的差。对于多类问题，结果之间不存在顺序感。本节描述的玻璃问题提供了一个多类问题的示例。

在本节中，玻璃问题展示了各种类型玻璃的化学成分。该问题的目标是确定玻璃的用途。可能的玻璃类型包括建筑窗户玻璃、车辆窗户玻璃、玻璃容器等。确定玻璃类型的动机是法医鉴定。在事故或犯罪现场，会有玻璃碎片，确定其来源有助于判断谁有过错或谁实施了犯罪。[清单 2-16](#c02.xhtml#c02-fea-0017) 显示了生成玻璃数据集摘要的代码。[图 2.20](#c02.xhtml#c02-fig-0020) 显示了归一化数据的箱线图。箱线图显示有相当数量的极端值。

glass = pd_read_glass()

    mean = summary2.iloc[1, i]
    sd = summary2.iloc[2, i]

        (glassNormalized.iloc[:,i:(i + 1)] - mean) / sd

array = glassNormalized.values
plt.boxplot(array)
plt.xlabel("Attribute Index")
plt.ylabel(("Quartile Ranges - Normalized "))
plt.show()

玻璃数据属性的箱线图显示了大量的异常值——至少与其他一些示例问题相比是显著的。玻璃数据有几个因素可能驱动这种异常值行为。一个是这是一个分类问题。属性值与类别成员资格之间不一定存在连续关系——没有理由预期跨类别的属性值会接近。玻璃数据的另一个独特特征是它有些不平衡。每个类别的示例数量从最多类别的 76 个到最少类别的 9 个不等。平均统计量可能被数量最多的类别的值主导，也没有理由预期其他类别的成员会有相似的属性值。这种剧烈的行为有利于区分不同类别，但也意味着用于预测的方法必须能够在不同类别之间勾勒出相当复杂的边界。您将在[第 3 章](#c03.xhtml)中了解到，如果给予足够的数据，集成方法产生的决策边界比惩罚线性回归更复杂，并且您将在[第 5 章](#c05.xhtml)和[第 7 章](#c07.xhtml)中看到哪一类方法在该数据集上表现更好。

平行坐标图可能会更多地揭示这些数据的行为。[图 2.21](#c02.xhtml#c02-fig-0021) 显示了平行坐标图。数据使用离散颜色绘制，对应每种可能的输出分类。图中的某些变量显示出相当明显的颜色路径。例如，深蓝色线条聚集得相当好，并且在许多属性上与其他类别明显分开。深蓝色线条在几个属性上处于数据的边缘——换句话说，在这些属性上是异常值。浅蓝色线条比深蓝色线条少，并且在一些与深蓝色相同的属性上处于边缘，但并非所有相同的属性。中间的棕色线条也聚集在一起，但处于中等数值范围内。[清单 2-17](#c02.xhtml#c02-fea-0018) 显示了生成玻璃数据平行坐标图的代码。对于岩石与地雷问题，平行坐标图中的线条使用两种颜色，以适应两种不同的标签值。在回归问题（葡萄酒口感和鲍鱼年龄）中，标签可以取任何实数值，图中的线条以一系列不同的颜色绘制。在这个多类问题中，每个类别获得自己的颜色。有六种离散颜色。标签从 1 到 7；没有 4。颜色的计算类似于回归问题中进行的计算——将数字标签除以其最大值。图中的线条呈现六种离散颜色。
