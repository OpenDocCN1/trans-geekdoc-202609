## 自由度与数据量的关系

用两个点拟合一条直线的问题在于，数据量不足以支撑该模型的自由度。一条直线有两个自由度。拥有两个自由度意味着有两个独立参数唯一确定一条直线。你可以想象抓住平面上的一条直线，在平面上上下滑动它，或扭转它以改变其斜率。因此，垂直位置和斜率是相互独立的。它们可以单独改变，而它们共同完全指定了一条直线。直线的自由度可以用几种等价的方式表示（例如它在 y 轴上的截距及其斜率、直线上的两个点等）。所有这些直线的表示都需要两个参数来指定。

当自由度的数量等于点的数量时，预测效果不佳。这些直线会穿过用于绘制它们的点，但用不同点对绘制的直线之间存在很大差异。你不能对自由度数量与数据集中点数量相等的预测抱有太大信心。[图 1.1](#c01.xhtml#c01-fig-0001)中的图表有六个点，并拟合了一条直线（两个自由度）穿过它们。即六个点对应两个自由度。确定导致遗传性状况的基因这一思维实验说明了：可供选择的基因越多，就需要更多的数据，才能从 20,000 个左右可能的人类基因中分离出病因。这 20,000 个不同的基因代表了 20,000 个自由度。即使来自 20,000 个不同人的数据也不足以得到可靠的答案，在许多情况下，合理研究范围内所能负担的只是来自 500 人左右的样本。这就是惩罚线性回归可能成为最佳算法选择的地方。

惩罚线性回归提供了一种系统的方法，将自由度减少至与可用数据量和底层现象的复杂性相匹配。这些方法已成为自由度极高问题的热门选择。它们是遗传学问题的首选算法，因为那里的自由度（即基因数量）可能高达数万；也适用于文本分类等问题，那里的自由度可能超过一百万。[第 4 章](#c04.xhtml)“惩罚线性回归”将详细介绍这些方法的工作原理、演示算法机制的示例代码，以及使用可用 Python 包实现机器学习系统的流程示例。

## 什么是集成方法？

本书涵盖的另一类算法是集成方法。集成方法的基本思想是构建一大群不同的预测模型，然后组合它们的输出——通过对输出求平均或采用多数表决（投票）。单个模型称为*基学习器*。计算学习理论的一些结果表明，如果基学习器仅比随机猜测略好，只要有足够数量的独立模型，集成的性能就可以非常好。

推动集成方法发展的问题之一是观察到某些特定的机器学习算法表现出不稳定性。例如，向数据集添加新数据可能导致生成的模型或其性能发生剧烈变化。二叉决策树和传统神经网络就表现出这种不稳定性。这种不稳定性导致模型性能的高方差，而对许多模型进行平均可以被视为降低方差的一种方法。关键在于如何生成大量独立模型，特别是当它们都使用相同的基学习器时。[第 6 章](#c06.xhtml)“集成方法”将详细介绍如何做到这一点。这些技术非常巧妙，且其基本操作原理相对容易理解。以下是即将介绍内容的预览。

应用最广泛的集成方法采用二叉决策树作为其基学习器。二叉决策树通常如[图 1.3](#c01.xhtml#c01-fig-0003)所示。

![Figure 1.4: Input-output graph for the binary decision tree example](images/c01f004.png)

**[图 1.4](#c01.xhtml#R_c01-fig-0004)**：二叉决策树示例的输入-输出图

这一描述引出了一个问题：比较值（例如 `x < 5`？）和输出值（树底部圆圈中的值）从何而来？这些值来自于在输入数据上训练二叉树。该训练算法不难理解，将在[第 6 章](#c06.xhtml)中介绍。此时需要注意的重要一点是，给定数据后，训练好的二叉决策树中的值是固定的。生成树的过程是确定性的。获得不同模型的一种方法是对训练数据进行随机抽样，并在这些随机子集上进行训练。该技术称为*装袋法*（*Bagging*，*bootstrap aggregating* 的简称）。它提供了一种生成大量略有不同的二叉决策树的方法。然后对这些树求平均（或针对分类器进行投票）以得出最终结果。[第 6 章](#c06.xhtml)将更详细地描述这一技术和其他更强大的技术。
