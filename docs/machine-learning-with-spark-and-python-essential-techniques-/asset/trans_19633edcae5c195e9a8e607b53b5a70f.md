

现代机器学习算法总体而言，特别是惩罚线性回归，生成的是一族解，而非单一解。请回顾 [公式 4.6](#c04.xhtml#c04-fig-0006) 和 [4.8](#c04.xhtml#c04-fig-0008)。这些公式左侧是 `β`，右侧全是由问题可用数据固定的数值，只有一个例外。在 [公式 4.6](#c04.xhtml#c04-fig-0006) 和 [4.8](#c04.xhtml#c04-fig-0008) 中，有一个参数 `λ` 需要通过其他方式确定。正如在讨论这些公式时指出的，当 `λ = 0` 时，问题退化为普通最小二乘回归；当 `λ → ∞` 时，`β* → 0`。因此，[公式 4.6](#c04.xhtml#c04-fig-0006) 和 [4.8](#c04.xhtml#c04-fig-0008) 所述问题中的 `β` 取决于参数 `λ`。

LARS 算法不显式处理 `λ` 值，但效果相同。LARS 算法从 `β` 等于零开始，然后将一个小增量加到能使误差减少最多的那个 `β` 上。所加的小增量会使 `β` 绝对值之和增加该增量的大小。如果增量很小，且用在最好的属性上，该过程的效果等同于求解 [公式 4.8](#c04.xhtml#c04-fig-0008) 中的最小化问题。你可以在 [清单 4.1](#c04.xhtml#c04-fea-0001) 中追踪这一过程的演变。

基本迭代仅仅是 `nSteps` 循环开头的几行代码。迭代的起点是 `β` 的一个值。第一次遍历时，它们全设为零。后续遍历时，它们来自上一次遍历的结果。迭代分两步。首先，用 `β` 计算残差。*残差* 指观测结果与预测结果之差。本例中，预测方法是将每个属性乘以 `β` 中对应的元素，然后求和。第二步是求每个属性与残差的相关性，以确定哪个属性对减小残差（误差）贡献最大。两个变量的相关性是它们偏离各自均值的乘积，再除以各自标准差进行归一化。

互为缩放版本的变量，其相关性为 +1 或 -1，取决于它们之间的缩放是正还是负。如果两个变量相互独立变化，其相关性为零。维基百科相关性页面 `http://en.wikipedia.org/wiki/Correlation_and_dependence` 给出了变量间具有其他程度相关性的很好示例。名为 `corr` 的列表包含每个属性的计算结果。你可能会注意到，严格来说，代码省略了均值、残差和归一化属性的标准差计算。之所以可行，是因为属性已归一化为标准差均为 1，且结果值将用于寻找最大相关性，所有值乘以一个常数不会改变其顺序。

计算出相关性后，确定哪个属性与残差的相关性最大（绝对值最大）就很简单了。`β` 列表中对应的元素增加一小量。若相关性为正则增量为正，否则为负。然后用 `β` 的新值重新运行迭代。

LARS 算法的净结果是 [图 4.3](#c04.xhtml#c04-fig-0011) 所示的系数曲线。查看这些曲线的方法是：想象图中“步数”轴上的一个点。此时，一条垂直线将穿过所有系数曲线。垂直线与系数曲线的交点处的值，即为 LARS 算法演变该步骤下的系数。若用 350 步生成曲线，则有 350 组系数。每一组都针对某个 `λ` 值优化了 [公式 4.8](#c04.xhtml#c04-fig-0008)。这就引出了该用哪一组的问题。稍后将解决该问题。

注意，前 25 步左右，只有一个系数非零。这是 Lasso 回归固有的稀疏性。最先离开零的系数是酒精含量；有一段时间，它是 LARS 回归唯一使用的变量。随后第二个变量加入。这一过程持续到所有变量都被用于解中。系数离开零的顺序可作为变量重要性排序的指示。如果必须丢弃一个变量，你会想丢弃最后加入的，而不是最先加入的。

### 从 LARS 生成的数百个模型中选择最佳模型

现在你有了 350 个可能的解，用于根据葡萄酒的化学性质预测其口感评分。如何选择最佳模型？要决定使用哪条曲线，需确定这 350 个选择各自的表现。正如 [第 3 章](#c03.xhtml) 所述，*性能* 指在样本外数据上的表现。[第 3 章](#c03.xhtml) 概述了几种从训练过程中保留数据以评估性能的方法。[清单 4.2](#c04.xhtml#c04-fea-0003) 展示了执行 10 折交叉验证以确定最佳部署系数集的代码。

十折交叉验证是将输入数据分成 10 个大致相等的组，移除其中一组，用其余数据训练，然后在被移除的组上测试。通过循环遍历所有 10 组并逐个移除它们进行测试，可以得到误差及其变异性的良好估计。
