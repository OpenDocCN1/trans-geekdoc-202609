### 训练线性模型：最小化误差及其他

手动寻找 `β` 的值通常不是最佳途径，尽管如果你能做到，这始终是一个很好的合理性检验。在许多问题中，问题的规模或变量之间的相互关系使得猜测 `β` 成为不可能。因此，采取的方法是通过求解一个最小化问题来寻找属性上的乘数（即 `β`）。该最小化问题旨在找到使平均平方误差最小（但非零）的 `β` 值。

使[公式 4.4](#c04.xhtml#c04-fig-0004)两边完全相等通常意味着模型过拟合。[公式 4.4](#c04.xhtml#c04-fig-0004)的右侧是你将要训练的预测模型。基本上，它表明要进行预测，你需要获取每个属性，乘以其对应的 beta，对这些乘积求和，再加上一个常数。*训练模型*意味着找到组成向量 `β` 和常数 `β₀` 的数值。*误差*定义为 `yᵢ` 的实际值与[公式 4.4](#c04.xhtml#c04-fig-0004)给出的预测值 `ŷᵢ` 之间的差值。使用平均平方误差将个别误差归约为一个待最小化的单一数值。选择误差的平方是因为无论误差是正还是负，其平方均为正，且平方函数便于某些数学运算。普通最小二乘回归问题的表述则变为寻找满足[公式 4.6](#c04.xhtml#c04-fig-0006)的 `β₀*, β*`（上标 * 表示这些是 `β` 的最佳值）。

符号 `argmin` 意为“使以下表达式最小化的自变量”。求和针对各行进行，其中一行包含属性值和对应的标签。`(...)`² 内的表达式是 `yᵢ` 与用于近似它的线性函数之间的误差。对于 2013 年图书支出的预测值，求和内的表达式将是 Outcome 列中的值减去根据[公式 4.4](#c04.xhtml#c04-fig-0004)计算出的预测值。

[公式 4.6](#c04.xhtml#c04-fig-0006) 中的 OLS 问题是选择 `β` 以最小化平方误差之和。惩罚回归问题将[公式 4.7](#c04.xhtml#c04-fig-0007)中的系数惩罚添加到[公式 4.6](#c04.xhtml#c04-fig-0006)的右侧。随后，最小化过程被迫在最小化平方预测误差和最小化系数平方值这两个相互冲突的目标之间取得平衡。单独最小化平方系数之和很容易，只需令所有系数为零即可。但这会导致巨大的预测误差。同样，OLS 解单独最小化预测误差，但可能导致巨大的系数惩罚，具体取决于 `λ` 有多大。
