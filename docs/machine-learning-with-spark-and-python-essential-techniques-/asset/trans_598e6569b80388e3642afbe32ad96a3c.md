

数据可通过 UC Irvine 数据存储库获取。该数据集的 URL 为 `http://archive.ics.uci.edu/ml/machine-learning-databases/abalone/abalone.data`。数据集为不带列标题的逗号分隔文件，列名在单独文件中。[Listing 2-11](#c02.xhtml#c02-fea-0012) 将鲍鱼数据集读入 pandas 数据框，并运行了与“分类问题：利用声呐探测未爆地雷”中相同的部分分析。对于岩石与地雷数据集，因数据性质列名较为通用；而鲍鱼数据集各列含义明确，对建立直观理解至关重要。因此代码中将列名直接复制粘贴并附加到数据集，帮助理解后续机器学习算法如何进行预测。可用于构建预测模型的列包括：Sex、Length、Diameter、Height、Whole Weight、Shucked Weight、Viscera Weight、Shell Weight 和 Rings。最后一列 Rings 需通过锯开外壳并在显微镜下计数获得，这是监督学习问题的典型安排：拥有已知答案的特殊数据集，以构建在答案未知时能生成预测的模型。

除了展示生成摘要的代码，[Listing 2-11](#c02.xhtml#c02-fea-0012) 还显示了摘要的打印输出。第一部分打印数据集的头部和尾部，输出中仅显示头部以节省空间（运行代码时两者均可见）。数据框大部分为浮点数。第一列包含动物性别，取值为 M（雄性）、F（雌性）、I（不确定）。鲍鱼性别非出生时确定，而是成熟后才定，因此幼年鲍鱼性别不确定。性别为三值分类变量，需特殊处理。某些算法仅处理实值属性（如支持向量机、K 近邻、惩罚线性回归，见[第 4 章](#c04.xhtml)）。[第 4 章](#c04.xhtml) 讨论了将分类变量转换为实值变量的技术以适用这些算法。[Listing 2-11](#c02.xhtml#c02-fea-0012) 还展示了实值属性的逐列统计摘要。

#### Listing 2-11：读取并汇总鲍鱼数据集 — abaloneSummary.py

```
__author__ = 'mike_bowles'

from Read_Fcns import pd_read_abalone
#read abalone data
abalone = pd_read_abalone()

print(abalone.head())
print(abalone.tail())

#print summary of data frame
summary = abalone.describe()
print(summary)

#box plot the real-valued attributes
#convert to array for plot routine
array = abalone.iloc[:,1:9].values
plt.boxplot(array) 
plt.xlabel("Attribute Index")
plt.ylabel(("Quartile Ranges"))
plt.show()

#the last column (rings) is out of scale with the rest
# - remove and replot
array2 = abalone.iloc[:,1:8].values
plt.boxplot(array2)
plt.xlabel("Attribute Index")
plt.ylabel(("Quartile Ranges"))
plt.show()

#removing is okay but renormalizing the variables generalizes better.
#renormalize columns to zero mean and unit standard deviation
#this is a common normalization and desirable for other operations
# (like k-means clustering or k-nearest neighbors
abaloneNormalized = abalone.iloc[:,1:9]


for i in range(8):
    mean = summary.iloc[1, i]
    sd = summary.iloc[2, i]
    abaloneNormalized.iloc[:,i:(i + 1)] = (
                    abaloneNormalized.iloc[:,i:(i + 1)] - mean) / sd

array3 = abaloneNormalized.values
plt.boxplot(array3)
plt.xlabel("Attribute Index")
plt.ylabel(("Quartile Ranges - Normalized "))
plt.show()
```
