

## 预测模型性能度量

本节涵盖与预测模型性能度量相关的两大领域。第一个领域是针对不同类型问题可使用的不同度量指标（例如，回归问题使用 `MSE`，分类问题使用误分类错误率）。在文献中（以及机器学习竞赛中），你还会看到诸如受试者工作特征曲线（`ROC` 曲线）和曲线下面积（`AUC`）之类的度量。此外，这些概念对于优化性能也很有用。

第二大领域由用于收集样本外误差估计的技术组成。回想一下，样本外误差旨在模拟新数据上的误差。在设计实践中，使用这些技术来比较不同算法，并为给定的问题复杂度和数据集大小选择最佳模型复杂度，这是一个重要环节。该过程将在本章后面详细讨论，并在本书其余部分的示例中加以应用。

### 不同类型问题的性能度量

回归问题的性能度量相对简单直接。在回归问题中，目标值和预测值都是实数。误差自然定义为目标值与预测值之间的差值。生成误差的统计摘要以便进行比较和诊断非常有用。最常用的摘要是均方误差（`MSE`）和平均绝对误差（`MAE`）。[清单 3.1](#c03.xhtml#c03-fea-0001) 对比了 `MSE`、`MAE` 和均方根误差（`RMSE`，即 `MSE` 的平方根）的计算。

#### 清单 3.1：MSE、MAE 和 RMSE 的对比——regressionErrorMeasures.py

```
__author__ = 'mike_bowles'
from math import sqrt

#here are some made-up numbers to start with
target = [1.5, 2.1, 3.3, -4.7, -2.3, 0.75]
prediction = [0.5, 1.5, 2.1, -2.2, 0.1, -0.5]

error = []
for i in range(len(target)):
    error.append(target[i] - prediction[i])

#print the errors
print("Errors ",)
print(error, '\n')

#calculate the squared errors and absolute value of errors
squaredError = []
absError = []
for val in error:
    squaredError.append(val*val)
    absError.append(abs(val))


#print squared errors and absolute value of errors
print("Squared Error")
print(squaredError, '\n')

print("Absolute Value of Error")
print(absError, '\n')

#calculate and print mean squared error MSE
print("MSE = ", sum(squaredError)/len(squaredError))

#calculate and print square root of MSE (RMSE)
print("RMSE = ", sqrt(sum(squaredError)/len(squaredError)))

#calculate and print mean absolute error MAE
print("MAE = ", sum(absError)/len(absError))

#compare MSE to target variance
targetDeviation = []
targetMean = sum(target)/len(target)
for val in target:
    targetDeviation.append((val - targetMean)*(val - targetMean))

#print the target variance
print("Target Variance = ", sum(targetDeviation)/len(targetDeviation))

#print the target standard deviation (square root of variance) 
print("Target Standard Deviation = ", sqrt(sum(targetDeviation)/
                      len(targetDeviation)))
```

该示例首先为目标值和预测值设定了一些编造的数字。首先，它通过简单的减法计算误差；然后展示 `MSE`、`MAE` 和 `RMSE` 的计算过程。请注意，`MSE` 的数量级与 `MAE` 和 `RMSE` 显著不同。这是因为 `MSE` 的单位是平方单位。因此，`RMSE` 通常是一个更实用的计算数值。清单底部计算了目标值的方差（均方差）和标准差（方差的平方根）。这些量分别可用于与预测误差的 `MSE` 和 `RMSE` 进行比较。例如，如果预测误差的 `MSE` 大致等于目标方差（或 `RMSE` 大致等于目标标准差），则预测算法表现不佳。你可以用目标均值的简单计算来替代预测算法，效果也差不多。[清单 3.1](#c03.xhtml#c03-fea-0001) 中的误差其 `RMSE` 约为目标标准差的一半。这是相当不错的性能。

除了计算误差的汇总统计量外，有时为了分析误差的来源和大小，查看误差直方图或尾部行为（分位数或十分位数边界）、正态度等也很有用。有时这些调查能提供关于误差来源和潜在性能改进的见解。

分类问题需要不同的处理方法。分类问题的方法通常围绕误分类错误率展开——即被错误分类的样本所占比例。例如，假设分类问题在于预测网站访客面前待展示链接的点击与否。通常，分类算法可以以概率形式呈现预测结果，而非硬性的“点击”与“不点击”决策。本书涉及的算法均输出概率。

这之所以有用，原因如下。如果点击与否的预测以概率给出——例如 80% 的点击概率（相应地 20% 的不点击概率）——数据科学家可以选择用 50% 作为阈值来决定展示或不展示该链接。然而在某些情况下，较高或较低的阈值会产生更好的最终结果。

例如，假设问题是欺诈检测（针对信用卡、自动清算所[支票]、保险理赔等）。基于欺诈与否的决策采取的行动是：让呼叫中心代表介入交易，或是放行交易。任一决策都涉及成本。如果介入，会产生呼叫中心成本和客户反应成本。如果不介入，则面临潜在欺诈的成本。如果采取行动的成本相对于不采取行动的成本非常低，则总成本最小化对应的阈值相对较低。更多交易会被标记为需介入。

但你在哪里为打断客户结账、要求客户致电持卡人服务才能继续划定界限呢？当你的预测算法指示交易有 20%、50% 还是 80% 的概率是欺诈时，你会进行干预吗？如果将干预阈值设为 20%，你会更频繁地介入——防范更多欺诈交易——但也会激怒更多客户，让许多呼叫中心代表忙个不停。也许将阈值设高一些（如 80%）并接受更多欺诈会更好。
