

## ROC 曲线与 AUC

通过随机判定岩石或矿石运行的分类器的 ROC 曲线，在图表上形成一条从左下角到右上角的对角线。该线通常被绘制在 ROC 曲线上作为参考基准。对于完美的分类器，ROC 曲线从 (0, 0) 直线上升到 (0, 1)，然后水平延伸至 (1, 1)。毫不奇怪，[图 3.10](#c03.xhtml#c03-fig-0019)（基于样本内数据）比 [图 3.11](#c03.xhtml#c03-fig-0020)（基于样本外数据）更接近完美。分类器的 ROC 曲线越接近左上角，其性能越好。如果 ROC 明显低于对角线，通常意味着数据科学家在某处搞反了符号，应仔细检查代码。

[图 3.10](#c03.xhtml#c03-fig-0019) 和 [3.11](#c03.xhtml#c03-fig-0020) 还展示了曲线下面积（AUC）数值。顾名思义，AUC 即 ROC 曲线下的面积。完美分类器的 AUC 为 1.0，随机猜测的 AUC 为 0.5。[图 3.10](#c03.xhtml#c03-fig-0019) 和 [3.11](#c03.xhtml#c03-fig-0020) 的 AUC 值再次证明：基于训练集误差（样本内数据）的性能估计会高估实际性能。样本内数据的 AUC 为 0.98，样本外数据的 AUC 为 0.85。

用于衡量二分类器性能的某些方法同样适用于多分类器。误分类错误率依然适用，混淆矩阵也同样有效。ROC 曲线和 AUC 也存在多分类的推广形式。[¹](#c03.xhtml#c03-bib-0001)

### 模拟已部署模型的性能

前一节的示例演示了：为了获得模型部署后预期性能的有用估计，必须在未包含于训练集的数据上测试性能。示例将可用的标记数据分成了两个子集。其中一个子集称为*训练集*，包含约三分之二的可用数据，用于拟合普通最小二乘模型。第二个子集包含剩余的三分之一数据，称为*测试集*，仅用于确定性能（模型训练期间不使用）。这是机器学习中的标准程序。

测试集大小通常占数据的 25% 到 35%，尽管没有关于大小的硬性规定。需牢记一点：随着训练数据集规模缩小，训练模型的性能会下降。从训练集中分出过多数据可能会损害最终性能。

另一种保留数据的方法称为 *n 折交叉验证*。[图 3.12](#c03.xhtml#c03-fig-0021) 示意性地展示了如何使用 n 折交叉验证将数据集划分为训练集和测试集。数据集被分成 *n* 个大小大致相等的不相交集合。图中 *n* 为 5。需对数据进行多轮训练和测试。第一轮中，第一块数据被保留用于测试，其余 `n-1` 块用于训练。第二轮中，第二块数据被保留用于测试，其他 `n-1` 块用于训练。此过程持续进行，直到所有数据都被保留过一次（如 [图 3.12](#c03.xhtml#c03-fig-0021) 所示的五折示例，共五次）。

![Figure 3.12: N-fold cross-validation](images/c03f012.png)

[**图 3.12**](#c03.xhtml#R_c03-fig-0021)：N 折交叉验证

n 折交叉验证过程可产生预测误差的估计值，并拥有多个误差样本，从而能估计误差的误差界。它能在训练集中保留更多数据，通常能带来更低的泛化误差和更好的最终性能。例如，若选择 10 折交叉验证，则每轮训练仅保留 10% 的数据用于测试。n 折交叉验证的这些优势是以更长的训练时间为代价的。采用固定保留集的方法具有训练更快的优势，因为它只需对训练数据进行一次遍历。当 n 折交叉验证的训练时间难以忍受，且可用训练数据量大到保留集中的额外数据不会对性能产生不利影响时，采用固定保留集可能是更好的选择。

另一点需注意：样本应具有整个数据集的代表性。前一节示例中使用的抽样方案并非随机抽样，而是每隔三个数据点取一个样本。在数据中均匀分布样本通常效果良好。但必须避免以引入训练集和测试集偏差的方式进行抽样。例如，若给定的数据是按采样日期排序的每日一次采样数据，则应避免编码七折交叉验证并每隔七个点采样一次。

若研究现象具有异常统计特性，抽样可能需要严格控制。可能需要小心保留测试样本中的统计特性。例如预测欺诈或广告点击等罕见事件。建模目标事件极其罕见，随机抽样可能导致测试集中过度或不足地代表这些事件，从而导致性能估计出错。分层抽样（`http://en.wikipedia.org/wiki/Stratified_sampling`）将数据划分为单独抽样后再重新组合的独立子集。当标签为罕见事件时，可能需要分别对欺诈样本和正常样本进行抽样，然后将它们合并作为测试集，以匹配训练集，更重要的是匹配模型将要应用的新数据。

模型训练和测试完成后，最佳实践是将训练集和测试集重新合并为单一数据集，并在更大的数据集上重新训练模型。样本外测试过程已给出预期预测误差的良好估计。保留部分数据正是为此目的。在更多数据上训练，模型性能和泛化能力会更好。部署的模型应在所有数据上进行训练。

本节为您提供了量化预测模型性能的工具。下一节将向您展示如何用数值比较取代您在“[驱动算法选择和性能的因素——复杂性与数据](#c03.xhtml#c03-sec-0005)”一节中看到的模型与问题复杂性的直观图形比较。这种替换使得部分选择过程实现机械化成为可能。
