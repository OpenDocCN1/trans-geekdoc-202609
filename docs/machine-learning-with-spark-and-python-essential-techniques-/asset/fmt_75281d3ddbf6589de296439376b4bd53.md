
# 本章目标

本章旨在为您奠定基础，使您能够自信地理解和使用实现此处所述算法的 Python 包。本章将输入数据集的性质描述为：一个待预测结果的列向量，以及一个用于预测的属性表。[第 3 章](#c03.xhtml)演示了预测模型需要调整其复杂度，以针对给定的问题复杂度和数据集大小获得最佳性能。[第 3 章](#c03.xhtml)还展示了一些向线性回归引入调优参数的方法。本章在该背景基础上，介绍了几个最小化问题，在这些问题中，向最小二乘回归的误差惩罚中添加了一个可调的系数惩罚。正如所演示的，这种对线性系数大小的可调惩罚会在更大或更小程度上抑制系数，从而增加复杂度调整。您看到了如何通过使用样本外数据上的误差来调整生成模型的复杂度，以实现最优性能。

本章描述了两种用于求解惩罚回归最小化问题的现代算法的操作原理，以及实现这些算法主要特性的 Python 代码，以便您拥有算法核心的具体实例，从而使操作原理更加清晰。普通回归问题（数值特征和数值目标）作为算法深入覆盖的范例。本章展示了几种扩展，以拓宽用例，涵盖二分类问题、多分类问题、属性与结果之间存在非线性关系的问题，以及包含非数值特征的问题。

[第 5 章](#c05.xhtml)将使用实现这些算法的 Python 包运行一系列示例，这些示例的选择旨在演练各种不同的问题特征，以巩固这些概念。基于您在本章所学，Python 包中的各种参数和方法将变得易于理解。

# 第 5 章 使用惩罚线性方法构建预测模型

[第 2 章](#c02.xhtml)着眼于许多不同的数据集，旨在理解数据集、各属性与标签之间的关系，以及所面临问题的性质。本章再次选取那些数据集，通过案例研究演示使用您在[第 4 章](#c04.xhtml)“惩罚线性回归”中看到的惩罚线性方法构建预测模型的过程。通常，模型构建将分为两个或更多部分。

您可能还记得[第 4 章](#c04.xhtml)所述，使用惩罚线性回归构建模型包含两个步骤。第一步是运行交叉验证，以确定最佳可达的样本外性能，并识别实现该性能的模型。确定可达性能包含了艰难的设计工作，在本章的许多示例中，只展示这一步。第二步是在整个数据集上训练以描绘系数曲线。在整个数据集上训练的目的是获得模型系数的最佳估计。但这不会改变您对误差的估计，误差是性能的衡量标准。

本章演练多种不同类型的问题：回归问题、分类问题、带分类属性的问题、以及标签对属性具有非线性依赖关系的问题。它考察基扩展，以查看其是否能提高预测性能。在每种情况下，目标都是完成您为获得可部署线性模型所需采取的步骤，并考虑一些替代路径，以确保您榨取了所有潜在性能。

## 用于惩罚线性回归的 Python 包

[第 4 章](#c04.xhtml)中的示例使用了所涉及训练算法的 Python 版本：`LARS` 和带 `ElasticNet` 惩罚的坐标下降法。在[第 4 章](#c04.xhtml)中使用 Python 代码的目的是展示算法的工作原理，以加深您对它们的理解。幸运的是，您不必每次想使用它们时都重新编写这些算法。

`scikit-learn` 拥有实现 `Lasso`、`LARS` 和 `ElasticNet` 回归的包。使用这些包有几个优势。一是减少了您需要编写和调试的代码行数。另一个巨大优势是它们比[第 4 章](#c04.xhtml)中的代码快得多。`scikit-learn` 包利用了不计算未使用属性的相关性等做法，以减少计算量。运行这些包时您会发现它们执行速度非常快。

您可以在 `sklearn.linear_model` 中找到本章使用的包。链接 `http://scikit-learn.org/stable/modules/classes.html#module-sklearn.linear_model` 列出了此处使用的模型。请注意，有几个模型有两种形式。例如，既有 `linear_model.ElasticNet`，也有 `linear_model.ElasticNetCV`。这两种模型对应本章开头讨论的两项任务。Python 包 `linear_model.ElasticNet` 用于在整个数据集上计算系数曲线，而 `linear_model.ElasticNetCV` 执行交叉验证运行以生成样本外性能估计。拥有这两种形式非常方便。

这两个版本基本使用相同的输入对象（两个 NumPy 数组——一个属性数组，一个标签数组）。在某些情况下，您无法使用交叉验证版本，因为您需要对每一折的训练集和测试集内容进行非常具体的控制：

*   如果您的问题有一个分类属性，其某个值出现频率极低，您可能需要控制采样，使该属性在各折中均匀分布。
*   如果您想要一个不同于 CV 包提供的*均方误差*（`MSE`）的误差度量，您可能还需要访问单独的折数据来编译针对您问题的误差统计。您可能更倾向于*平均绝对误差*（`MAE`），因为它更符合您在实际问题中因错误将付出的惩罚。
*   另一个需要逐折访问误差统计的例子是使用线性回归解决分类问题时。正如[第 3 章](#c03.xhtml)“预测模型构建：平衡性能、复杂度与大数据”所述，分类问题的标准误差度量包括误分类错误率或*ROC 曲线下面积*（`AUC`）。您将在本章的“岩石与地雷”和“玻璃分类”案例研究中专门看到这种情况。
