
[Figures 4.1](#c04.xhtml#c04-fig-0009) 和 [4.2](#c04.xhtml#c04-fig-0010) 中的其他曲线组分别代表 [Equations 4.7](#c04.xhtml#c04-fig-0007) 和 [4.8](#c04.xhtml#c04-fig-0008) 中的系数惩罚——即岭回归惩罚和 Lasso 惩罚。

在 [Figure 4.1](#c04.xhtml#c04-fig-0009) 中，代表系数惩罚的曲线是以原点为中心的圆。当 $\beta_1$ 和 $\beta_2$ 的平方和为常数时，这些点的集合构成一个圆。恒定惩罚曲线的形状取决于所用距离度量的性质——平方和惩罚函数对应圆（在高维空间中称为超球面或 $L_2$ 球），绝对值之和惩罚对应菱形（或 $L_1$ 球）。较小的圆（或菱形）对应距离函数的较小值。形状由惩罚函数的性质决定，但与每条曲线关联的值由非负参数 $\lambda$ 决定。

假设 [Figure 4.1](#c04.xhtml#c04-fig-0009) 中的两条曲线分别对应内圆和外圆的 $\beta_1^2 + \beta_2^2$ 等于 1.0 和 2.0。那么如果 $\lambda = 1$，这两个圆关联的惩罚分别为 1 和 2。如果 $\lambda = 10$，关联的惩罚分别为 10 和 20。[Figure 4.2](#c04.xhtml#c04-fig-0010) 中的菱形同理。增大 $\lambda$ 会增加 [Figure 4.2](#c04.xhtml#c04-fig-0010) 中同心菱形关联的惩罚。

对应预测误差平方和的椭圆环，随着环远离图中用 *x* 标记的无约束最小值而变大。如 [Equation 4.7](#c04.xhtml#c04-fig-0007) 所示，最小化这两个函数之和需要在预测误差的最小值和系数惩罚的最小值之间做出妥协。较大的 $\lambda$ 值会将妥协点拉向惩罚的最小值（所有系数为零）。较小的 $\lambda$ 值会将最小值拉向无约束的最小预测误差（[Figures 4.1](#c04.xhtml#c04-fig-0009) 和 [4.2](#c04.xhtml#c04-fig-0010) 中的 *x*）。

平方系数惩罚之和与绝对值系数惩罚之和的区别在此变得重要。[Equations 4.7](#c04.xhtml#c04-fig-0007) 或 [4.8](#c04.xhtml#c04-fig-0008) 的总体最小值将始终位于恒定惩罚曲线与平方预测误差曲线相切的点上。[Figures 4.1](#c04.xhtml#c04-fig-0009) 和 [4.2](#c04.xhtml#c04-fig-0010) 展示了说明这种相切性的两个示例。这里的关键点在于：在 [Figure 4.1](#c04.xhtml#c04-fig-0009) 中，随着 $\lambda$ 变化并移动最小值点，平方和惩罚（圆）的相切点通常不在任一坐标轴上。$\beta_1$ 和 $\beta_2$ 均不为零。相比之下，在 [Figure 4.2](#c04.xhtml#c04-fig-0010) 中，绝对值惩罚的相切点在一系列解中始终“卡”在 $\beta_2$ 轴上。沿 $\beta_2$ 轴，$\beta_1 = 0$。
