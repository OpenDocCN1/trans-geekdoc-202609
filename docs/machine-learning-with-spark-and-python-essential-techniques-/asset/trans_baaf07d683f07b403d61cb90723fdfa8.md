### 分类和分类特征的修改

为了让你完整了解决策树是如何训练的，我们还需要讨论几个细节。其中之一是：这如何用于分类问题？之前用于判断分裂的标准——MSE——仅适用于回归问题。正如你在本书其他地方所见，分类问题有不同于回归问题的优劣指标。有几种优劣指标可用于分类问题，以替代MSE来判断分裂。你已经熟悉的一种是误分类误差。另外两种常用的度量是基尼不纯度度量和信息增益。更多信息请参见`http://en.wikipedia.org/wiki/Decision_tree_learning#Gini_impurity`。这另外两种度量与误分类误差具有略微不同的属性，但在概念上并无不同。

最后一个细节是如何基于分类属性而非数值属性训练树。树中的（非终端）节点提出一个是/否问题。对于数值变量，问题的形式是给定属性是否小于某个参数。将分类变量分成两个子集，包含尝试将类别划分为两组的每一种可能分法。如果类别为A、B和C，可能的分裂有：A在第一组而B和C在第二组，B在第一组而A和C在第二组，以此类推。在某些情况下，一些数学结果可以简化这一过程。

本节提供了二元决策树的一些背景知识。二元决策树本身就是一个合法的预测工具，值得研究，但在此概述它们的主要目的是作为集成方法的背景，后者包含大量二元决策树。你将看到，使用单个树时出现的一些问题（需要调整的多个参数、结构不稳定性、大树过拟合）在成百上千棵树组合时会退居次要地位。这正是开发集成方法的初衷，它们具有显著的鲁棒性、易于训练且准确。接下来的章节将逐一讨论三种主要的集成方法。

## Bootstrap聚合：“Bagging”

Bootstrap聚合由Leo Breiman开发。该方法始于选择一个基学习器。这里将使用二元决策树作为基学习器来实现该方法。随着方法的推进，你会看到其他机器学习算法也可用作基学习器。二元决策树是合乎逻辑的选择，因为它们自然地建模具有复杂决策边界的问题，但二元决策树可能表现出过大的性能方差。通过组合大量基于树的模型可以克服方差。

### Bagging算法如何工作？

Bootstrap聚合算法使用所谓的*bootstrap*样本。Bootstrap样本常用于从适度大小的数据集生成样本统计量。一个（非参数）bootstrap样本是从数据集中有放回地随机选择若干元素（即bootstrap样本可以包含原始数据中某一行的多个副本）。Bootstrap聚合从训练数据集中获取若干个bootstrap样本，然后在每个样本上训练一个基学习器。对于回归问题，将生成的模型进行平均。对于分类问题，模型可以进行平均，也可以基于不同类别的百分比生成概率。[清单6-4](#c06.xhtml#c06-fea-0004)展示了将bagging算法应用于本章开头介绍的合成问题的代码。

该代码保留30%的数据用于测量样本外性能，而不是使用交叉验证。参数`numTreesMax`决定集成中包含的最大树数量。代码构建从第1棵树、前2棵树、前3棵树，以此类推，直到`numTreesMax`棵树的模型，以观察准确率如何随集成中包含的树的数量而变化。代码将训练好的模型存储在列表中，并将保留用于样本外误差测试的数据的预测结果存储起来。
