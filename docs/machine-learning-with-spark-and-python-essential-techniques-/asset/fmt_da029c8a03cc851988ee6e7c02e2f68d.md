
在[表 2.1](#c02.xhtml#c02-tbl-0001)中，一行代表一个单独的客户，该行中的数据都与该个体相关。第一列称为`UserID`，包含每行（案例）唯一的标识符。唯一标识符可能存在于你的问题中，也可能不存在。例如，网站通常用用户 ID 标记站点访问者，该 ID 在其访问期间与其关联。如果用户未在网站注册，则同一用户每次访问都会获得不同的 ID。该 ID 通常分配给每个观察值，这将是你要构建的预测主体。第 2、3、4 列称为`Attributes`，而不是给出更具体的名称，如`Height`或`Gender`。关键在于突出它们在预测过程中的作用。`Attributes`是关于案例的可用数据，将用于进行预测。

`Labels`是你想要预测的事物。在本例中，`UserID`是一个简单的数字，`Attribute 1`是身高，`Attribute 2`是性别，`Attribute 3`是该人去年阅读的书籍数量。`Labels`列下包含该个体去年在网上购书花费的金额。这些不同类别的数据将扮演什么角色？机器学习算法如何利用用户 ID、属性和标签？简短的回答是：你忽略用户 ID。你使用属性来预测标签。

唯一 ID 用于记账目的，允许你回溯到特定案例可用的其他数据。通常，唯一 ID 不会直接用于机器学习算法。`Attributes`是你选择用于进行预测的事物。`Labels`是机器学习算法将用来构建预测模型的观察结果。

`User ID`通常不用于进行预测，因为它太具体了。它仅与单个示例相关。机器学习的诀窍在于构建一个能泛化到新案例的模型（而不仅仅是记忆过去的案例）。为了实现这一点，算法的推导必须强制其关注不止一行数据。排除用户 ID 的一个可能例外是：当用户 ID 为数字且按用户注册顺序分配时。基本上，在这种情况下它指示注册日期，可能很有用，因为 ID 相近的用户在相似时间注册，可以以此为依据视为一组。

构建预测模型的过程称为*训练*。该过程的进行方式取决于算法，后续章节将介绍细节，但通常是迭代的。算法假设属性和标签之间存在预测关系，观察其犯下的错误，进行一些修正，然后对该过程进行迭代，直到获得一个可靠的模型。许多技术细节将在后面解决，但这就是基本思想。

## 不同类型的属性和标签驱动建模选择

[表 2.1](#c02.xhtml#c02-tbl-0001)中显示的属性有两种不同类型：数值变量和分类（或因子）变量。`Attribute 1`（身高）是数值变量，也是最常见的属性类型。`Attribute 2`是性别，由`Male`或`Female`条目表示。这种类型的属性称为*分类*或*因子*变量。分类变量的特性是其各个值之间没有顺序关系。`Male < Female`没有意义（尽管争论了几个世纪）。分类变量可以是双值的，如`Male`、`Female`，也可以是多值的，如州（`AL`、`AK`、`AR` … `WY`）。关于属性可以划分其他区别（例如整数与浮点数），但它们对机器学习算法的影响不一样。原因在于许多机器学习算法仅接受数值属性；它们无法处理分类或因子变量。惩罚回归算法仅处理数值属性。支持向量机、核方法和 k-近邻算法也是如此。[第 4 章](#c04.xhtml)将介绍将分类变量转换为数值变量的方法。变量的性质将决定你的算法选择以及开发预测模型的方向，因此这是面对新问题时需要关注的事项之一。

标签也存在类似的二分法。[表 2.1](#c02.xhtml#c02-tbl-0001)中显示的标签是数值型的：个体去年在网上购书花费的金额。但在其他问题中，标签也可能是分类的。例如，如果[表 2.1](#c02.xhtml#c02-tbl-0001)的任务是预测哪些个体明年将花费超过 200 美元，问题就会改变，解决问题的方法也会改变。预测哪些客户将花费超过 200 美元的新问题将有新的标签。新标签将取两个值之一。[表 2.2](#c02.xhtml#c02-tbl-0002)显示了[表 2.1](#c02.xhtml#c02-tbl-0001)中给出的标签与基于逻辑命题`Spending > $200`的新标签之间的关系。[表 2.2](#c02.xhtml#c02-tbl-0002)中显示的新标签取两个值之一——`True`或`False`。

**表 2.2**（[#c02.xhtml#R_c02-tbl-0002](#c02.xhtml#R_c02-tbl-0002)）：数值目标与分类目标

| TABLE 1 LABELS | >$200? |
| --- | --- |
| $120 | False |
| $270 | True |
| $75 | False |
| $600 | True |

当标签为数值型时，该问题称为*回归问题*。当标签为分类型时，该问题称为*分类问题*。如果分类目标仅取两个值，该问题称为*二元分类问题*。如果取两个以上的值，则称为*多类分类问题*。

在许多情况下，问题类型的选择取决于设计者。你刚才看到，通过简单转换标签，本示例问题可以从回归问题转换为二元分类问题。这些是你在解决问题时可能做出的权衡。例如，分类目标可能更好地支持在两个行动方案之间做出决策。

分类问题也可能比回归问题更简单。考虑例如仅有一条等高线（如 100 英尺等高线）的地形图与每 10 英尺就有一条等高线的地形图之间的复杂性差异。单条等高线将地图分为高于 100 英尺和低于 100 英尺的区域，包含的信息比更详细的等高线地图少得多。分类器试图计算单条分割等高线，而不考虑远离决策边界的行为，而回归则试图绘制整张地图。

## 关于新数据集需要注意的事项

作为初步检查数据的一部分，你需要确定数据集的许多其他特征。以下是一个清单，以及一系列了解数据集的步骤，旨在让你熟悉数据并规划预测模型开发的步骤。这些都是简单的检查，但直接影响你的后续步骤。此外，该过程能让你开始探索数据并了解其属性。

**以下是需要检查的项目**

*   行数和列数
*   分类变量的数量及每个变量的唯一值数量
*   缺失值
*   属性和标签的汇总统计量
