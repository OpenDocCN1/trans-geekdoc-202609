

## 为什么这讲得通？

为了帮助建立一些直观理解，说明为什么这讲得通，请考虑一下你在[第 3 章](#c03.xhtml)中看到的子集选择过程。使用子集选择通过丢弃某些属性（或者等价地将它们的系数设为零）来消除过拟合。惩罚回归做的是同样的事情，但它不是像子集选择那样将少数属性的系数一直降到零，而是减小*所有*系数的大小，从而减弱*所有*属性的影响。一些极限情况也将有助于形象化理解这种方法。

参数 `λ` 的取值范围可以是 0 到正无穷大之间的任何值。如果 `λ = 0`，惩罚项消失，问题退化为普通最小二乘问题。如果 `λ → ∞`，对 `β` 的惩罚变得极其严厉，以至于迫使它们全部变为零。（但请注意，`β₀` 不包含在惩罚项中，因此预测值变成一个与 `x` 无关的常数。）

正如你在[第 3 章](#c03.xhtml)的示例中所见，岭惩罚的效果类似于排除某些属性。该过程是为[公式 4.6](#c04.xhtml#c04-fig-0006)所示的惩罚版最小化问题生成一整族解。这意味着针对各种不同的 `λ` 值求解惩罚最小化问题。然后在样本外数据上测试这些解，并使用使样本外误差最小化的解来进行现实世界的预测。[第 3 章](#c03.xhtml)使用岭回归演示了这一系列步骤。

### 其他有用的系数惩罚——曼哈顿距离和弹性网

岭惩罚并非可用于惩罚回归的唯一有用惩罚。任何向量长度的度量都可以。你可以用多种方式衡量向量的长度。使用不同的长度度量会改变解的重要特性。岭回归采用了欧几里得几何度量（即*平方 β*之和）。另一种称为 Lasso 回归的有用算法采用*绝对 β*之和或 L1 度量。这种度量也称为出租车度量或*曼哈顿距离*，因为它是出租车受限于曼哈顿方格街道网格所行驶的距离。Lasso 回归具有一些有用的特性。

岭回归和 Lasso 回归的区别在于它们用于惩罚 `β`（线性系数向量）的长度度量不同。岭回归使用平方欧几里得距离——即 `β` 各分量平方之和。Lasso 使用 `β` 各分量绝对值之和。Lasso 惩罚由[公式 4.8](#c04.xhtml#c04-fig-0008)给出。

![Equation 4.8: Equation for Lasso coefficient penalty](images/c04-disp-0009.png)

[**公式 4.8**](#c04.xhtml#R_c04-fig-0008)：**Lasso 系数惩罚公式**

双竖线称为范数符号。它们用于表示向量和算子等事物的大小。范数符号右侧的下标 1 表示 `L₁` 范数，即绝对值之和。你也会看到它写作小写的 `l₁`。带下标 2 的范数符号表示平方值之和的平方根——欧几里得距离。这些不同的系数惩罚函数会导致解中出现一些重要且有用的变化。主要区别之一是 Lasso 系数向量 `β*` 是稀疏的，意味着对于中等到较大的 `λ` 值，许多系数为零。相比之下，岭回归的 `β*` 是完全填充的（即所有系数均非零）。
