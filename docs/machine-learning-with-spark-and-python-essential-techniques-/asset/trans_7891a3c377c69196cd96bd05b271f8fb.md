你需要注意该输出的几个方面。首先，让我们重述一下这个过程。该过程是训练一族模型（在本例中，是在 X 的列子集上训练的普通线性回归）。这系列模型是参数化的（在本例中，由线性模型中使用的属性数量参数化）。选择用于部署的模型是为了最小化样本外误差。纳入解决方案的属性数量可以称为 `complexity parameter`（复杂度参数）。具有较大复杂度参数的模型拥有更多自由参数，比复杂度较低的模型更容易过拟合数据。

还要注意，属性已根据其预测质量的重要性进行了排序。在列编号列表和相关的属性名称列表中，列表中的第一个是首先被选中的属性，第二个是其次，以此类推。使用的属性会以一个漂亮的有序列表形式输出。这是机器学习技术的一项重要且理想的特性。机器学习任务的早期阶段主要涉及寻找（或构建）用于预测的最佳属性集。拥有按重要性对属性进行排序的技术有助于这一过程。本书中开发的其他算法也将具备这一特性。

最后一个观察点是关于从机器学习技术生成的模型族中挑选模型。模型越复杂，其泛化能力越差。最好倾向于选择复杂度较低的模型。前面的例子表明，第 9 个（最佳）模型和第 10 个模型之间的性能几乎没有下降（第 4 位有效数字发生了变化）。最佳实践是移除那些属性，即使它们在第 4 位有效数字上表现更好，以保持保守策略。

### 通过惩罚回归系数控制过拟合——岭回归

本节介绍另一种修改普通最小二乘回归的方法，以控制模型复杂度并避免过拟合。该方法作为惩罚线性回归的初步介绍。你将在[第 4 章](#c04.xhtml)中看到更多相关内容。

普通最小二乘回归旨在寻找标量 $\beta_0$ 和向量 $\beta$，使其满足（参见[公式 3.14](#c03.xhtml#c03-fig-0029)）。

![公式 3.14：OLS 最小化问题](images/c03-disp-0015.png)

**公式 3.14**：OLS 最小化问题

表达式 `argmin` 意为“使表达式最小化的 $\beta_0$ 和 $\beta$ 的值”。得到的系数 $\beta_0^*, \beta^*$ 即为普通最小二乘解。最佳子集回归和前向逐步回归通过限制使用的属性数量来抑制普通回归。这等同于施加一个约束，即向量 $\beta$ 中的某些条目等于零。另一种方法称为*系数惩罚回归*。系数惩罚回归通过使所有系数变小（而不是使其中一些变为零）来实现相同目的。系数惩罚线性回归的一种版本称为*岭回归*。[公式 3.15](#c03.xhtml#c03-fig-0030) 展示了岭回归的问题公式化。

![公式 3.15：岭回归最小化问题](images/c03-disp-0016.png)

**公式 3.15**：岭回归最小化问题

[公式 3.15](#c03.xhtml#c03-fig-0030) 与普通最小二乘法（[公式 3.14](#c03.xhtml#c03-fig-0029)）的区别在于增加了 $\alpha \beta^T \beta$ 项。$\beta^T \beta$ 项是 $\beta$（系数向量）的欧几里得范数的平方。变量 $\alpha$ 是该问题公式化中的复杂度参数。如果 $\alpha = 0$，问题就变成了普通最小二乘回归。当 $\alpha$ 变大时，$\beta$（系数向量）趋近于零，只有常数项 $\beta_0$ 可用于预测标签 $y_i$。scikit-learn 中提供了岭回归。[清单 3.5](#c03.xhtml#c03-fea-0005) 展示了使用岭回归解决葡萄酒口感回归问题的代码。
