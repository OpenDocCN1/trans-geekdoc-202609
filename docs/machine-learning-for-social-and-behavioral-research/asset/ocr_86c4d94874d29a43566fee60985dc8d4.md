# 7.4.4 Factor Scores

Within the general latent variable modeling framework, a common goal is often to use a model with one or more latent variables to estimate factor scores for each observation, and then use this variable as a predictor or outcome, depending on the model. This is in contrast to using summed scores, which makes the fundamental assumption that each indicator is equally representative of the latent variable of interest.

Particularly if the model is large, this would be a computationally efficient strategy. However, the important unknown is what is lost by estimating a factor score and not keeping the model intact. This has been the subject of much past (e.g., Grice, 2001; Skrondal, & Laake, 2001) and recent (Devlier, Mayer, & Rossel, 2016; Devlier & Rossel, 2017; Mai, Zhang, & Wen, 2018) research. One of the consistent findings is that it can be efficient to compute factor scores when a complex SEM model has an insufficient sample size.

There are many proposed methods for factor score estimates. We just cover one, the ordinary least squares (also referred to as Thompson’s or Thorne’s method). This involves the use of SEM matrices, as well as the data matrix ($x_t$)

```
$f_{regression} = (I + \Lambda\Phi^{-1})^{-1}\Lambda^\Phi^{-1}x_t$
```

where $\Lambda$ is the full loading matrix and $\Phi$ is the variance-covariance matrix of the latent variables. Alternative factor score estimation methods, such as the Bartlett’s, have similar forms and typically result in factor scores that are highly correlated with one another. One caveat in the cave of factor scores is that using two-step procedures, such as creating factor scores in a first step and then entering these scores into SEM, can result in inaccurate parameter estimates and standard errors (e.g., Devlieger & Rossel, 2017).
