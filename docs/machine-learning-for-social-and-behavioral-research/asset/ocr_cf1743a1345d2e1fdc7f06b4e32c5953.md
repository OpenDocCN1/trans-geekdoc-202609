using decision trees, the question we have to ask ourselves how big of a tree is necessary? For instance, the tree structure in Figure 3.3 has three splits, and corresponds to the predicted curve in Figure 3.4.
To see the mapping from the tree structure in Figure 3.3, we can read the structure of the tree like a set of if/then statements: if an observation has an PHE exposure (apex) value greater or equal to 14.15, then they have a predicted full IQ of 50.41, if less than 14.15, then a predicted full scale IQ of 65.03, with the same process holding on the other side of the tree. However, this predicted tree matches our data to a reasonable extent, by MSE and R², a bigger tree, displayed in Figure 3.5, fits better. The MSE is 115.849, the R² is 0.800 for this tree, compared to a MSE of 130.348 and R² of 0.775 for the tree displayed in Figure 3.3. The predictions from the larger tree are displayed in Figure 3.6. Both trees fit the data better than the linear regression model, however choosing among them presents a challenge. Although the fit of the tree in Figure 3.5 is superior, it seems to fit “too closely” to the data, capitalizing on small numbers of observations to add additional curve to the predictions.
