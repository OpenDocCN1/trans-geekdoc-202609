# Introduction to Social Network Analysis

Betweenness measures the extent to which a node lies on the paths between two nodes. Nodes with high betweenness influence how information passes through the network. For some nodes, they may not have a large degree. However, they may be checkpoints through which information moves. If they are removed from the network, it can actually disrupt the communications among other nodes. A large betweenness indicates a more important node. For the WeChat network, Student 70 has the largest betweenness and Student 53 has the smallest. The histogram of betweenness is shown in Figure 12.5(c).

PageRank is most widely known for ranking the importance of web pages but is also a measure of the centrality of nodes in a network (Brin & Page, 1998). PageRank uses edges between nodes as a measure of importance. Unlike degree, it assigns a weight to the edge depending on the relative score of a node that it connects. A large PageRank indicates an important node. For the WeChat network, Student 70 has the largest PageRank and Student 53 has the smallest. The histogram of the PageRank of the network is shown in Figure 12.5(d).

# 12.4.3 Network Statistics for Dyads

For a pair of nodes, a dyad, in the network, network statistics can also be defined. The shortest path is probably the most widely used one (West et al., 1996). The shortest path between two nodes in a network is a path with the minimum number of edges. For example, if there is an edge between Node A and Node B, the shortest path between them is 1. If Node A has to go through another node to reach Node B, the shortest path between A and B is 2.

The shortest paths for all pairs of nodes in a network form a matrix. A heat map of the shortest paths of the WeChat network is given in Figure 12.6. In the plot, the color represents the largest shortest. Overall the shortest path is 4, implying that a student can get information to another student at most through three other students. The majority of dyads have a shortest path of 2 (67%) followed by 3 (30%). One of the most discussed network phenomena is the small-world effect. In most real networks, the typical shortest path is surprisingly short, in particular when compared with the number of nodes of the network (Milgram, 1967; Travers & Milgram, 1977). The WeChat network also reflects such an important observation in social network analysis.
