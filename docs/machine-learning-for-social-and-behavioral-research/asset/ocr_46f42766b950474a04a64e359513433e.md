As the number of trees increases in bagging, so does the fit of the result-predictions to the training dataset. To demonstrate this, we used the ECLS-K data, predicting science scores using reading, math, and knowledge scale scores, as well as socioeconomic status, weight, height, and income. The results are displayed in Figure 6.4, where we plotted the fit of predictions when increasing the number of trees. From this figure, we can see that it only takes a small number of bagged trees to improve the fit of decision trees on both the training and test datasets, with performance leveling off at approximately 100. Selecting the number of trees is the main parameter in bagging. Selecting too few trees results in underfitting, while there is typically less consequence for using too many trees. Typically, 500 trees work relatively well, while more trees may be required in the presence of many predictors.
