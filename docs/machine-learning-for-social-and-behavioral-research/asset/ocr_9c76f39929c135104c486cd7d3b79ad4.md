We first review different model fit statistics and then discuss our recommendations. Finite mixture models are typically estimated using a form of maximum likelihood estimation, the first model statistics include information criteria, such as the Akaike information criterion (AIC), the Bayesian information criterion, and variants of these criteria, as the sample size adjusted BIC and the corrected log-likelihood (AICc). Information criteria combine the model deviance (-2 log-likelihood [-LL]) to assess how well the model captures the data and a penalty for the number of estimated parameters. Information criteria vary in the size of the penalty. For example, the AIC is -2LL + 2p, where -2LL is the model's deviance and whereas the BIC is -2LL + In(N)p, where In(N) is the natural log of the sample size. Thus, the penalty for an estimated parameter in the AIC is 2, and the penalty in the BIC is favoring parsimonious models compared to AIC when sample size is greater than seven. Information criteria can be used to compare both nested and different parameter specifications. When using information criteria for comparing models, the model obtaining the lower information criteria value is considered the superior fitting model.

The second group of model fit statistics is the approximate likelihood ratio tests. Finite mixture models that only differ in the number of classes are considered; however, the difference in their variances under the null hypothesis are not asymptotically chi² distributed. Thus, corrections have been proposed, using the Vuong-Moendell-Rubin Approximate Likelihood Ratio Test and the Moendell-Rubin Adjusted Likelihood Ratio Test (Lo), Mendel, & Rubin, 2001). These likelihood ratio tests provide a statistic and associated p-value, which compares the fit of the specified model (the K classes) with the fit of the same type of model with one fewer class. In addition to approximate likelihood ratio statistics, there is the Bootstrap Likelihood Ratio Test (BLRT, McLaughlin, 1987). The BLRT repeatedly simulates data according to the specified model and the model with one fewer class, and then estimates the specified distribution of likelihood ratio under the null hypothesis. This distribution is then used as a comparison distribution to obtain the p-value for the observed likelihood ratio.
