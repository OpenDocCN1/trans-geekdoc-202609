# #9 Machine Learning with Mixed-Effects Models

When working with a univariate outcome, calculating predicted values from any of the machine learning techniques discussed so far is straightforward, and assessing the usefulness of the model can be determined through cross-validation (k-fold using a holdout sample). However, clustered data, sampled from hierarchically structured units (i.e., children within schools, repeated measures data, employees within units), pose challenges to the generation of predicted values and model evaluation due to the dependency present within the data. When analyzing clustered data model needs to be specified to distinguish the between-level from the within-level, obtain proper standard errors, and account for the potential issues present in clustered data (e.g., the number students sampled per school is different). While a variety of statistical models have been developed for the analysis of clustered data (i.e., fixed-effects regression models), we focus our attention on mixed-effects models, which are often referred to as random coefficients in economics and multilevel models in the social and behavioral sciences.

#  9.1 Key Terminology

+   - Random effect. A parameter coefficient that is allowed to vary across clusters (people or schools). In this chapter's example, this means that both the intercept and slope are person specific.
- Fixed effect. A parameter coefficient that is the same for each unit (not allowed to vary across people or schools).
- Multilevel/hierarchical/mixed-effects models. Models that contain a mixture of fixed and random effects.
