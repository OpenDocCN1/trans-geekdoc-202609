## 10.4 Summary

The most important distinction between mixture models and the use of trees is whether researchers believe heterogeneity can be attributed to unobserved or observed variables. Which covariates can be included in mixture models, it is typically preferable to not have them drive the class creation, necessitating the use of these three-step approaches. Given this, class construction is not specifically based on values of an observed variable, while trees, and specifically SEM trees, directly identifies groups based on covariate values. Oftentimes researchers may have some degree of uncertainty as to which approach is best. In this, we recommend running both mixtures and trees, using primarily theoretical judgment to discern which solution is chosen for interpretation. It is tricky to use free criteria to compare the results from mixtures and trees, as the resulting models are not nested. While trees are constrained to only finding groups based on the unique values of covariates, mixtures are only constrained by the number of groups, making them inherently more flexible. It is expected that mixture models will evidence better fitting values of information criteria. We can summarize the benefits and limitations to each approach in a manner of ways. Note that instead of limiting our discussion to SEM trees, which better envelopes the tree approaches in the previous chapter.

As alluded to this chapter, a number of algorithms are available to researchers for the identification or testing of heterogeneity. We notably omitted a number of these, specifically cluster analysis, which can be used in a very similar way to that of mixtures (see Faley & Rafferty, 1999, for generalizations of cluster analysis to incorporate outcome models), with the distinction being whether class membership is probabilistic (mixtures) or deterministic (cluster analysis). Additionally, while it was mentioned that decision trees specifically assign group membership on covariates, similar processes can be done with regression models (using a grouping variable in ANOVA or logistic regression instance). We summarize the methods that have been covered in Table 10.5.

The main distinction in Table 10.5 is whether the grouping (heterogeneity) is thought to be unobserved in the case of mixture models, or observed in tree methods or multiple group SEM. Additionally, the more advanced methods handle multiple variable types as outcomes, while SEM methods constrain the relations between these variables in some form of latent variable model (or path analysis, for instance with a mediation model as an outcome). Finally, we have focused on the use of methods to search for lately scenario, multiple group SEM can be seen as a generalization of ANOVA, where a grouping structure is specified based on theoretical consideration and determining whether the levels to that group are, in fact, different with respect to the outcome (continuous variable in ANOVA, any type of SEM in multiple group SEM).

## 10.4.2 Computational Time and Resources

For mixture models, we highly recommend using Mplus as it is the most comprehensive set of tools available and is among the most efficient piece of software for latent variable models.
