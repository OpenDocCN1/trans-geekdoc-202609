The decision to include interactions or not follow two types of restrictions. Strong hierarchy estimates an interaction between variables $X_j$ and $X_k$ only if $eta_j$ and $eta_k$ are both nonzero. Weak hierarchy requires only one of $eta_j$ or $eta_k$ to be nonzero. There are both statistical and practical considerations in choosing which type of hierarchy to impose. Given that two-way interactions represent a quadratic relationship between $X_j$ and $X_k$, if these main effects are small, it is unlikely that the interaction between variables will be of an appreciable magnitude. In social and behavioral science research, this is more likely the case than not, with a preponderance of small effects among variables. Given this, we advocate for its use and only discuss the application of the strong hierarchy restriction.

We do not examine the formulae implementation of the lasso applied to Equation 4.8. Instead, we demonstrate an application of the method to data from the ECLS-S with noise variables. To apply the hierarchical lasso, a number of packages in R exist to implement these methods, including hiernet (Bien & Tibirani, 2014) and FAMILY (Haris et al., 2016). In this application, we implement a two-step approach with strong hierarchy assumption and cross-validation to select main, and quadratic effects (default in package is to include quadratic effects, or diagonal of $\Theta_g$), and then rerun a linear regression model including the selected parameters from step 1. To accomplish this, because the ECLS-S is a large dataset ($N = 4,556$), we used the validation set approach, by running the hierarchical lasso on one half of the dataset, and then using the selected parameters in a linear regression run on the other half of the dataset.
