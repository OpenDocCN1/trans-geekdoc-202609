## 12.2.2 Network Data Structure

In regular data analysis, the data are often organized as a rectangular matrix with each column representing a variable and each row representing a participant or subject. For network data, they are often represented as an adjacency matrix or edge list matrix. The adjacency matrix, also called a sociatrix or connection matrix, represents the network data as an N × N matrix, with N being the total number of participants. Using the network lexicon, each participant is called a node or a vertex. For the WeChat network, there are a total of 165 nodes. The WeChat network can be represented by a 165 × 165 square matrix, with each row and column being student. For example, Table 12.2 shows the adjacency matrix of the first 100 students in the WeChat network data.

For the WeChat network, no self-loop is allowed, which means that a student cannot be a friend of himself or herself. For the off-diagonal values, 1 indicates that two students are WeChat friends and 0 indicates they are not. In network analysis, the relationship is also called an edge. For the WeChat data, if Student A reports B as a WeChat friend, Student A should also be a WeChat friend of Student B. Therefore, the adjacency matrix is symmetric. Such a network is called an undirected network. However, if A views B as a friend but B does not view A as a friend, one would have a directed network. In this situation, the convention is that rows indicate the starting node or “source,” and columns indicate the ending node or the "target."

The WeChat network is also a binary network, in which an edge either exists or not, representing a 1 or 0. Other values can be used to measure the strength of the edges. In this case, the adjacency matrix can take categorical and continuous values. Such a network is called a weighted or valued network.

The adjacency matrix can grow big quickly. For example, Facebook has more than 2.4 billion active users in 2019. To present the Facebook information, one would need a 2.4-billion by 2.4-billion adjacency matrix. However, on average, each Facebook user has around 338 Facebook friends. Therefore, the vast majority of the edges in the adjacency matrix would be 0 (about 99.99999%). A more economical way to store network data is to use the edge list matrix. In the simplest case, one only needs a K × 2 matrix to store the network, with K being the total number of edges in the network. The first column stores the index of the starting node and the second column stores the index of the ending node of an edge. For example, for the network in Table 12.2, K = 27 for a total of 27 friendships among the 10 students. Therefore, the adjacency matrix needs to store 10 × 10 = 100 values. However, the edge list only needs to store 27 × 2 = 54 values. For the whole network, the adjacency matrix is a 165 × 165 matrix and the edge list is 722 × 2 matrix, a saving of about 87%. For a sparse network such as Facebook, the saving is even more significant.

In addition to the network data, other information is often available in a network. The information that can be related to the nodes or the edges is called node attributes, or edge features.

## 12.3 Network Visualization

Visualizing a network is not only the first step but also a critical step of social network analysis. For a long time, network analysis research focused on how to represent a network. A large number of options are available to visualize a network—here we introduce the heat map and the network plot. Visualization makes the identification of the node relationships relatively easy.

### 12.3.1 Heat Map

A heat map can visualize any matrix of data, not only the network data. A heat map divides a plot area into small squares according to the number of rows and columns in the data matrix. Each square is colored according to the corresponding value in the matrix. For example, the heat map of the WeChat network is given in Figure 12.1. In this figure, the value 1 is represented by a black square and 0 by a gray square. Therefore, from the heat map, one can immediately see how many friendship relations are in the WeChat network.
