# Software

The first software package was developed by Abdoleol et al. (2002), who utilized the macro language in SAS and the PROC MIXED (Singer, 1998) procedure. Their implementation was then developed into the R package LongRPart (Stewart & Abdoleol, 2012), which paired the classification and regression tree algorithm from rpart (Therneau & Atkinson, 2019) with the lme function from the nlme (Pinheiro et al., 2017) package. While this package is no longer available in R, Jacobucci, Abdoleol, Serang, and Stemann (2017) updated this package, and it is available as the LongPart2 package, which also allows for nonlinear mixed-effects models through the integration with nlme package (Pinheiro et al., 2017). The GLM tree algorithm is available in the glmtree package, and combines the conditional inference tree algorithm from the partykit package (Hothorn et al., 2006) with the lme4 (Bates, Mechler, Bolker, Walker, 2015) package for mixed-effects models. The RE-EM tree algorithm from Sema and Simonoff (2012) is available in the REEMTree package, which uses the CART algorithm; however, adjustments can be made to integrate the conditional inference tree algorithm (see http://people.stern.nyu.edu/simon/unbiasedREEM). Lastly the MplusTrees package (Serang et al., 2020) is available in R, which integrates rpart with Mplus; however, the Mplus software (Mühen, Muthén, 2017) is necessary to use the MplusTrees package.

# 9.3.2 Algorithm

In this chapter, we focus on the standard recursive partitioning algorithm (from rpart) and allow for a researcher-specified mixed-effects model within each node (as opposed to the indicator approach in RE-EM tree). Given a mixed-effects model and a set of predictor (partitioning) variables, the algorithm proceeds in the following steps:

+   1. A stopping threshold $k$ is specified, where $k$ represents the minimum improvement in the -2LL to retain a partition data.

+   2. The mixed-effects model is estimated using the full sample and the -2LL is retained. This is referred to as the root (-2LL).

+   3. Set base(-2LL) to root (-2LL).
