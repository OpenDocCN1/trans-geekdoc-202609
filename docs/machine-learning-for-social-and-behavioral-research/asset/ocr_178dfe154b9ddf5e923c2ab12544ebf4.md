However, this can be viewed as a grand mean to be used as a comparison in the resulting SEM trees, as each derived subgroup is likely to have an estimated latent mean be different than zero. Thus, we can compare each mean estimate to identify which subgroups have lower or higher levels of each latent variable. Note that this procedure is not needed in longitudinal SEMs, as the observed variable means are set to zero in order to push the changes in means to the level. In most cross-sectional data it is not appropriate to constrain the observed variables to zero in the same way without centering the variables.

Going back to our example, we imposed invariance constraints on the factor loadings and unique variances, while also setting the variable means to zero. With this, we can use each of the personality and demographic predictors to identify subgroups that are maximally different with the latent means, variances, and covariance.
