# Decision Trees

The purpose of this demonstration is not necessarily to dissuade researchers from the use of decision trees, but instead to impart a degree of skepticism regarding the optimality of a single tree. Instability is not necessarily problematic for inferences within the sample, but instead for the assumption that a tree structure derived from this sample is likely to be the same or highly similar to an alternative tree. Each tree structure should be interpreted with some apprehension, as alternative structures may represent the data well.

# 5.5.4 Missing Data

Significant research evaluates various strategies for handling missing data in decision trees (e.g., Simonoff, 2010; He, 2006). Some tree methods have options for using surrogate splits in the presence of missing data. Surrogate splits work in the following way: After a primary split is found for a given node, surrogate splits can be found by reapplying the partitioning algorithm to predict the split. For example, if the primary split on education is between ≤ 12 and > 12, then this new variable becomes the outcome, with the remaining variables used as predictors. Those variables that perform best in predicting the primary split are retained (default in rpart) and used for cases that had missing values on the primary split. Earlier, if cognitive score is high values (> 12 years of education) and low values (< 12 years of education), then the use of surrogate splits is implemented in both rpart and partykit; however, in partytree, surrogate splits is only implemented when both variables are ordered. # 5.5.5 Variable Importance

Similar to linear regression, high correlations among covariates presents problems for decision trees. In tree building, at a given split two variables may produce almost identical in fit. To quantify how influential a variable is in predicting the outcome, one can also calculate the variable importance metric for a given tree. These metrics can be used to calculate how much improvement in fit would have occurred for a given variable if it was chosen. This allows us to quantify the importance of a variable even if it was not split at all. Although there are various ways to calculate this, which is not limited to decision trees, part purity creates an overall measure of variable importance that is the sum of the fit improvement for all splits plus the improvement in fit adjusted above baseline (Table & Atkinson, 1997).

As an example, we used the ECLS-K dataset to create an additional tree. Using both general knowledge and math predictors, we added a third variable by duplicating each observation's math score and adding a small amount of noise. This simulated math score had a correlation of 0.95 with the original math score. We expected that this would result in only one of the math variables being selected in the tree, but the variable importance should show roughly similar values for each math score.

As expected, one of the math scores was not used in the tree (the simulated math score). However, the variable importance metrics were: 39 for math, 33 for knowledge, and 28 for the simulated math score. Note that the variable importance metric is scaled up to 100. Despite not showing up in Figure 5.22, the simulated math score receives an importance score that is nonzero. This metric should not be interpreted with too high precision, as there are only so many splits in a tree, making it difficult to fully account for each variable's importance. In general, only the relative ranking of variables should be interpreted with respect to importance metrics (Strobl, Malley, & Tutz, 2009). In the next chapter, we will build variable importance metrics that are more robust, as we are using hundreds, if not thousands, of trees to average each variable's effect.

# Disadvantages:

- Instability.
- Collinearity presents problems.
- Relatively lower predictive performance.

Just as researchers need to understand the assumptions of linear models, and in what situations these models may not be appropriate, we urge them to just turn a blind eye and believe decision trees represent a panacea. As we have noted, there are some research contexts for which tree structures are appropriate, and there are underlying assumptions that can be violated. Decision trees should be viewed as complementary to the use of linear models, and in most cases we recommend using both methods to compare and contrast the different theoretical conclusions that they result.
