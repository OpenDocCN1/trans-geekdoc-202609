If three decimal places is not of interest, rounding the predictor values will increase the potential for creating stable trees, with the benefit of decreasing computational time.

To understand the degree of (in)stability to a tree structure

As an example of repeatedly creating tree structures, we used the stable function on the ECLS-K example with both math and knowledge predictors of science. In this, we compared the use of linear regression to the CART and CTree algorithms. Linear regression was used to compare performance using CV, while CART and CTree can be compared with respect to stability and other metrics.

Using 100 bootstrap samples, and 10-fold cross-validation to assess performance on each bootstrap sample, we see that both decision trees algorithms performed linear regression. This gives some degree of confidence in the utility of nonlinear relationships in examining this set of predictors and outcome. Each tree structure was compared to every other across both algorithms to assess stability. Even with rounding cutpoints to the nearest decimal place, each tree structure was unique. This can partly be attributed to the large trees, with an average number of nodes equal to 15.4 and 22.7 for CART and CTree, respectively.
